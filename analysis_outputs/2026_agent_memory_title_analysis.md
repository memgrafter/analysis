 ### Synthesis: What the Titles Collectively Argue

 Reading these ~100+ memory titles as a single argument:

 1. Vector stores are dead — The field has moved far beyond "embed and retrieve." Memory is now graph-structured, hierarchical, typed (episodic/semantic/procedural), and versioned.
 2. Forgetting is as important as remembering — FadeMem, admission control, compression papers signal that unbounded memory accumulation is a recognized failure mode.
 3. The retrieval problem is unsolved — Multiple papers on routing, cost-sensitive store selection, and diagnosing retrieval-vs-utilization bottlenecks show that having the right memory isn't enough if you can't find it.
 4. Memory is the bridge to long-horizon agency — The sheer density of "long-horizon" + "memory" co-occurrences in titles (Continuum Memory, MemEx-RL, TimeMem, MemPO) suggests the field believes memory is the bottleneck for agents that operate over hours/days rather than single turns.
 5. The brain is the dominant design metaphor — Hippocampus, cortex, cranial gating, sleep consolidation, spreading activation, Hebbian plasticity — these aren't casual analogies; they're structural design choices being imported wholesale.
 6. Cross-agent memory sharing is nascent but growing — MemCollab, LatentMem, AMA, and cross-modal compression papers hint at memory as a shared resource in multi-agent systems, not just a per-agent concern.
 7. Nobody agrees on how to evaluate it — Eight distinct memory benchmarks in one year, each measuring different aspects (episodic recall, over-personalization, emotion, multi-session, long-horizon utilization). The evaluation surface is fragmented.
