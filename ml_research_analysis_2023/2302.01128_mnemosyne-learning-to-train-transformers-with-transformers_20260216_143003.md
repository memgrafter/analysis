# Mnemosyne: Learning to Train Transformers with Transformers

## Quick Facts
- arXiv ID: 2302.01128

## Executive Summary
Mnemosyne introduces a learnable optimizer architecture based on low-rank implicit attention Transformers that can train entire neural network architectures without requiring task-specific tuning. The key innovation is using compact associative memory mechanisms with discounted kernel-based attention to avoid quadratic complexity while maintaining expressiveness. The optimizer demonstrates superior generalization compared to LSTM optimizers and can successfully train Vision Transformers on tasks it wasn't explicitly meta-trained on, matching hand-designed optimizer performance with improved stability and efficiency.

## Method Summary
Mnemosyne employs a Transformer-based optimizer architecture that uses discounted kernel-based attention mechanisms to update neural network parameters efficiently. The system leverages compact associative memory structures to avoid the quadratic complexity typically associated with Transformers, while maintaining the ability to capture long-range dependencies in the optimization process. The optimizer is meta-trained to learn general optimization strategies that can be applied across different architectures and tasks without requiring fine-tuning for specific problems.

## Key Results
- Successfully trains Vision Transformers on tasks it wasn't meta-trained on
- Matches hand-designed optimizer performance while being more stable and efficient
- Outperforms LSTM optimizers in generalization capabilities

## Why This Works (Mechanism)
Mnemosyne works by using low-rank implicit attention Transformers that maintain associative memory capabilities while avoiding the computational complexity typically associated with standard Transformer attention mechanisms. The discounted kernel-based attention allows the optimizer to efficiently update parameters by focusing on relevant historical information without examining all previous steps. This mechanism enables the system to learn general optimization strategies that can adapt to different architectures and tasks through meta-training.

## Architecture Onboarding

**Component Map:** Input gradients -> Discounted Kernel Attention -> Parameter Update -> Loss Evaluation -> Repeat

**Critical Path:** The optimization loop where parameter updates flow through the discounted kernel attention mechanism to produce updated weights that minimize loss.

**Design Tradeoffs:** The use of low-rank approximations reduces computational complexity but may limit the expressiveness of attention patterns. The discounted kernel approach balances efficiency with the ability to capture relevant historical information.

**Failure Signatures:** Poor optimization performance on tasks with extremely long-range dependencies, failure to converge on tasks with highly non-convex loss landscapes, or suboptimal performance when pattern separation assumptions are violated.
