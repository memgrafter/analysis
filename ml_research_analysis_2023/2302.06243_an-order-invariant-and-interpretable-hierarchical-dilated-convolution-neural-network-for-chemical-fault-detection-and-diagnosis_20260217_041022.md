# An Order-Invariant and Interpretable Hierarchical Dilated Convolution Neural Network for Chemical Fault Detection and Diagnosis

## Quick Facts
- arXiv ID: 2302.06243
- Source URL: https://arxiv.org/abs/2302.06243
- Reference count: 27
- Primary result: HDLCNN achieves 96.4% average fault detection accuracy on Tennessee Eastman dataset, outperforming CNN (91.3%) and DLCNN (94.0%)

## Executive Summary
This paper addresses fault detection and diagnosis in chemical processes, focusing on the sensitivity of CNN models to feature order in tabular data and their lack of interpretability. The authors propose an order-invariant and interpretable hierarchical dilated convolution neural network (HDLCNN) that combines feature clustering, dilated convolution, and SHAP-based interpretability. Feature clustering groups correlated features to reduce order sensitivity, dilated convolution expands the receptive field for better global feature extraction, and SHAP quantifies feature contributions to identify root-cause features. Evaluated on the Tennessee Eastman dataset, HDLCNN achieved 96.4% average fault detection accuracy for multi-class classification, outperforming CNN (91.3%) and DLCNN (94.0%). Root-cause analysis correctly identified key fault features (e.g., X(18) and X(9)) with high contribution scores, demonstrating the method's interpretability and practical value in real chemical process monitoring.

## Method Summary
The proposed HDLCNN combines feature clustering, dilated convolution, and SHAP-based interpretability to address fault detection and diagnosis in chemical processes. The method first applies hierarchical clustering to group highly correlated features, reducing sensitivity to input order. Dilated convolutions then expand the receptive field to capture long-range feature interactions without increasing parameters. After training, SHAP values are computed to quantify each feature's contribution to predictions, enabling root-cause identification. The approach is evaluated on the Tennessee Eastman dataset, showing improved accuracy and interpretability compared to standard CNN and dilated CNN baselines.

## Key Results
- HDLCNN achieved 96.4% average fault detection accuracy on Tennessee Eastman dataset for multi-class classification
- Outperformed CNN (91.3%) and DLCNN (94.0%) baselines in fault detection accuracy
- Correctly identified root-cause features X(18) and X(9) for fault 1 with high SHAP contribution scores
- Demonstrated order invariance by maintaining performance across different feature input orders

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hierarchical clustering groups highly correlated features before convolution, reducing sensitivity to input order.
- Mechanism: Features are first clustered into two groups based on correlation. Within each cluster, highly correlated features are close to each other. Dilated convolutions then operate on these clustered segments, so spatial relationships within a cluster reflect true feature correlations rather than arbitrary ordering.
- Core assumption: Correlated features in chemical processes tend to be close in the optimal ordering for CNNs, and clustering can approximate that ordering without enumeration.
- Evidence anchors:
  - [abstract] "The novelty of HDLCNN lies in its capability of processing tabular data with features of arbitrary order without seeking the optimal order, due to the ability to agglomerate correlated features of feature clustering..."
  - [section] "As a data pre-processing method, hierarchical clustering treats each input as a separate cluster and then sequentially merges similar clusters thus being unaffected on the order."
- Break condition: If feature correlations are not meaningful or stable across samples, clustering may group unrelated features, degrading performance.

### Mechanism 2
- Claim: Dilated convolutions expand the receptive field, allowing the network to capture long-range feature interactions without increasing parameters.
- Mechanism: Standard convolutions only aggregate local neighborhoods; dilated convolutions insert gaps ("holes") in the kernel, increasing coverage. This means each filter can capture global patterns and interactions among features that would otherwise be split across kernel boundaries.
- Core assumption: Chemical process features exhibit long-range dependencies that are relevant for fault detection, and a larger receptive field improves representation without overfitting.
- Evidence anchors:
  - [abstract] "Dilated convolution, a variant of CNN that expands the kernel by inserting holes between the kernel elements, is utilized in our method [4]. It is adopted to increase the receptive field size without increasing the number of model parameters."
  - [section] "This enables models to have a larger receptive field with the same number of parameters and computation costs."
- Break condition: If the dilation rate is too large relative to input size, the receptive field may exceed useful context, introducing noise.

### Mechanism 3
- Claim: SHAP values provide local and global interpretability by quantifying each feature's marginal contribution to predictions.
- Mechanism: SHAP combines DeepLIFT (a backpropagation-based importance method) with Shapley values from cooperative game theory. For each sample, SHAP computes how much each feature shifts the model output from a baseline; averaging over samples gives global importance rankings, enabling root-cause identification.
- Core assumption: Feature contributions are additive and the model's predictions can be decomposed into individual feature effects without losing interaction information.
- Evidence anchors:
  - [abstract] "SHAP quantifies feature contributions to identify root-cause features."
  - [section] "The SHAP method to interpret the model performance... quantify the contribution of each feature from each data sample to obtain local explanation."
- Break condition: If features are highly correlated, SHAP attributions may be unstable or misleading due to shared variance.

## Architecture Onboarding

- Component map:
  - Input: Tabular data (features x time steps)
  - Preprocessor: Hierarchical clustering (features → 2 clusters)
  - Encoder: Two parallel dilated conv layers (r=2) on clustered segments
  - Fusion: Concatenate feature maps
  - Decoder: Dilated conv (r=2) → MaxPool → Flatten → FC → Softmax
  - Explainer: Deep SHAP (post-hoc interpretability)

- Critical path:
  1. Cluster features → reorder input
  2. Feed reordered input to hierarchical dilated CNN
  3. Obtain class probabilities
  4. Apply SHAP to trained model for feature importance
  5. Identify root-cause feature as highest SHAP value

- Design tradeoffs:
  - Clustering reduces order sensitivity but may lose fine-grained ordering information.
  - Dilated convolutions increase receptive field but may skip relevant local patterns if dilation is too aggressive.
  - SHAP offers interpretability but adds computational overhead and may be unstable with correlated features.

- Failure signatures:
  - High variance in classification accuracy across different feature orders → clustering ineffective.
  - Low feature importance scores from SHAP → model may not be leveraging feature interactions.
  - Receptive field larger than input size → dilated conv ineffective or noisy.

- First 3 experiments:
  1. Train baseline CNN and DLCNN on close-correlated vs separate-correlated orders; measure accuracy drop to quantify order sensitivity.
  2. Replace hierarchical clustering with random feature grouping; compare HDLCNN performance to validate clustering benefit.
  3. Run SHAP on a trained HDLCNN; verify that top-ranked feature matches known root-cause for a fault with established ground truth.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the HDLCNN-SHAP method perform on real-world chemical process data with incomplete or missing features, as opposed to the simulated Tennessee Eastman dataset used in the experiments?
- Basis in paper: [inferred] The paper mentions "incomplete dataset" as a future work direction and uses a simulated dataset for experiments.
- Why unresolved: The current study only evaluates the method on a complete, simulated dataset, leaving its performance on real-world, potentially incomplete data untested.
- What evidence would resolve it: Experimental results comparing HDLCNN-SHAP performance on real-world chemical process data with missing features versus the simulated dataset.

### Open Question 2
- Question: Can the HDLCNN-SHAP method effectively identify root-cause features in scenarios where multiple features contribute to a fault, as opposed to the single root-cause feature analysis presented in the paper?
- Basis in paper: [explicit] The paper states "In our future work, we plan to focus on the faults with multiple root-cause features."
- Why unresolved: The current study only demonstrates root-cause identification for faults with single root-cause features, not addressing more complex multi-contributor scenarios.
- What evidence would resolve it: Experimental results showing HDLCNN-SHAP's ability to identify and rank multiple root-cause features in faults with multiple contributing factors.

### Open Question 3
- Question: How does the performance of HDLCNN-SHAP compare to ante-hoc interpretability methods like Bayesian Networks when applied to real chemical process fault detection and diagnosis?
- Basis in paper: [explicit] The paper contrasts post-hoc SHAP interpretability with ante-hoc Bayesian Network methods, noting the latter's requirement for prior knowledge.
- Why unresolved: The paper does not provide a direct comparison between SHAP-based interpretability and Bayesian Networks in real chemical process applications.
- What evidence would resolve it: Comparative study results showing HDLCNN-SHAP's performance versus Bayesian Network-based methods on the same real chemical process fault detection and diagnosis tasks.

## Limitations

- Performance claims rely on a single public dataset (Tennessee Eastman) without cross-validation on other chemical process datasets
- Hyperparameter choices for the dilated convolutions and clustering thresholds are not fully specified, making exact replication difficult
- The interpretability claims assume SHAP attributions remain stable across different random seeds, which is not demonstrated

## Confidence

- **High Confidence:** The mechanism of dilated convolutions expanding receptive field without increasing parameters is well-established in the literature and mathematically sound.
- **Medium Confidence:** The feature clustering approach for reducing order sensitivity is plausible but not extensively validated across diverse datasets or feature correlation structures.
- **Medium Confidence:** The combination of hierarchical clustering with dilated convolutions shows promise but requires more empirical validation to confirm the claimed benefits over simpler alternatives.

## Next Checks

1. **Ablation Study:** Compare HDLCNN performance with and without feature clustering on datasets with known feature correlations to quantify the clustering contribution.

3. **Cross-Dataset Generalization:** Evaluate HDLCNN on at least one additional chemical process dataset (e.g., benchmark process monitoring datasets) to assess generalizability beyond the Tennessee Eastman dataset.
