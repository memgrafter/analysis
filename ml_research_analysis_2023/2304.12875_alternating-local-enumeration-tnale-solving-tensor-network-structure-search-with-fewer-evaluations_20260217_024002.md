# Alternating Local Enumeration (TnALE): Solving Tensor Network Structure Search with Fewer Evaluations

## Quick Facts
- arXiv ID: 2304.12875
- Source URL: https://arxiv.org/abs/2304.12875
- Reference count: 40
- Key outcome: TnALE reduces evaluations from Ω(2^N) to O(N^2R) for tensor network structure search

## Executive Summary
This paper introduces TnALE, an algorithm that significantly improves the computational efficiency of tensor network structure search (TN-SS) by replacing random sampling with alternating local enumeration (ALE). TN-SS involves finding optimal tensor network structures to balance model complexity and expressiveness. TnALE achieves up to 10× fewer evaluations than state-of-the-art algorithms while maintaining practical performance on synthetic and real-world data, including natural images and regression tasks.

## Method Summary
TnALE solves TN-SS by alternately updating each structure-related variable within a neighborhood using local enumeration rather than random sampling. The algorithm follows a local-searching scheme where each variable (ranks, topology, permutations) is updated by enumerating all values within a defined neighborhood radius. This approach exploits the low-rank structure of the optimization landscape, requiring only O(N^2R) evaluations compared to Ω(2^N) for random sampling. The method uses the same objective function as TNLS but achieves better evaluation efficiency through deterministic enumeration.

## Key Results
- TnALE achieves evaluation efficiency of O(N^2R) versus Ω(2^N) for TNLS
- The algorithm finds practically good TN-ranks and permutations with up to 10× fewer evaluations
- Theoretical analysis shows TnALE can achieve linear convergence up to a constant when sufficient reduction is reached in each neighborhood
- Experiments validate performance on synthetic data (TR, PEPS, HT, MERA, TW topologies) and real-world applications (regression tasks, image compression)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Alternating Local Enumeration (ALE) achieves evaluation efficiency by exploiting low-rank structure in the optimization landscape
- Mechanism: ALE samples fibers along each dimension of the neighborhood tensor rather than randomly sampling points. This is equivalent to TT-cross approximation, which can recover the minimum entry using O(KIR) samples instead of O(2^K) samples needed for random sampling.
- Core assumption: The optimization landscape in the neighborhood of a TN structure is approximately low-rank in tensor train (TT) topology
- Evidence anchors:
  - [abstract] "O(N^2R) evaluations are sufficient in TnALE, where N denotes the tensor order and R reflects the 'low-rankness' of the neighborhood"
  - [section] "the proposed alternating local enumeration (ALE) is strongly related to TT-cross (Oseledets & Tyrtyshnikov, 2010) and TTOpt (Sozykin et al., 2022)"
  - [corpus] Weak evidence - no direct corpus papers discussing ALE or TNLS, but TTOpt paper discusses similar TT-cross approximation concepts
- Break condition: If the neighborhood landscape is not low-rank, the evaluation advantage degrades and may approach exponential sampling complexity

### Mechanism 2
- Claim: Local search with alternating variable updates achieves linear convergence up to a constant
- Mechanism: By updating each structure-related variable alternately within a neighborhood, the algorithm guarantees descent in each local step. The discrete convexity assumptions ensure that each update moves closer to the optimum.
- Core assumption: The objective function satisfies discrete analogues of strong convexity and smoothness with finite gradients
- Evidence anchors:
  - [abstract] "both algorithms can achieve linear convergence up to a constant if a sufficient reduction of the objective is reached in each neighborhood"
  - [section] "We establish for the first time the convergence analysis for both TNLS and TnALE, and rigorously prove their evaluation efficiency"
  - [corpus] Weak evidence - no direct corpus papers discussing convergence of TNLS or TnALE specifically
- Break condition: If sufficient reduction is not achieved in each neighborhood, the linear convergence guarantee breaks down

### Mechanism 3
- Claim: Alternating updates avoid combinatorial explosion while maintaining descent property
- Mechanism: Instead of evaluating all possible combinations of rank and permutation changes (which would be exponential), ALE updates one variable at a time while fixing others. This reduces the search space from O(2^K) to O(KI) where I is the neighborhood radius.
- Core assumption: Local improvements in individual variables lead to global improvement in the composite structure
- Evidence anchors:
  - [abstract] "TnALE, a new algorithm that updates each structure-related variable alternately by local enumeration, greatly reducing the number of evaluations compared to TNLS"
  - [section] "TnALE follows the 'local-searching' scheme as TNLS but alternately updates each variable of the TN structure by enumerating all values within a neighborhood"
  - [corpus] Weak evidence - no direct corpus papers discussing alternating update schemes for tensor network structure search
- Break condition: If variables are highly coupled such that individual updates cannot guarantee descent, the alternating scheme may fail

## Architecture Onboarding

- Component map: TnALE consists of three main components: 1) Alternating local enumeration (ALE) for sampling neighborhoods, 2) Objective function evaluation using the same loss function as TNLS, and 3) Update mechanism that selects the best structure from enumerated candidates. The algorithm replaces the random sampling component of TNLS with deterministic enumeration.

- Critical path: The core execution loop involves: initialize with random structure → enumerate neighborhood for each variable alternately → evaluate objective for each candidate → select best candidate → repeat until convergence. The bottleneck is the objective function evaluation, which TnALE reduces by avoiding random sampling.

- Design tradeoffs: TnALE trades stochastic exploration (used in TNLS) for deterministic exploitation of local structure. This provides faster convergence and fewer evaluations but may get stuck in local minima more easily than the stochastic approach.

- Failure signatures: TnALE may fail when: 1) The optimization landscape is not low-rank, requiring exponential samples, 2) Variables are too coupled for alternating updates to guarantee descent, or 3) Local minima trap the algorithm due to deterministic search pattern.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the low-rankness of the optimization landscape vary with tensor order and rank dimension in different tensor network topologies?
- Basis in paper: The authors empirically verify this with five synthetic tensors of order four and conjecture that in practice the low-rank structure of the landscape should be preserved.
- Why unresolved: The empirical verification is limited to order-4 tensors. The theoretical analysis in Proposition 4.10 requires low-rankness as a condition but doesn't prove it holds for arbitrary tensor orders and topologies.
- What evidence would resolve it: Systematic experiments measuring singular values of landscape tensors across various orders (4-10), different topologies (TR, PEPS, MERA, HT), and different rank dimensions would provide evidence for or against the conjecture.

### Open Question 2
- Question: What is the exact relationship between the convergence rate constant (7/8)K and the tensor order K, and can this be improved?
- Basis in paper: The authors prove a convergence rate with constant (7/8)K appearing in Theorem B.11: the convergence rate is formally close to being linear, but the constant (7/8)K appears on the right-hand side, dampening the search efficiency.
- Why unresolved: The analysis shows this constant arises from rounding operations and the discrete nature of the problem, but the exact scaling with K and potential improvements are not explored.
- What evidence would resolve it: Theoretical analysis showing tighter bounds on the rounding error or experimental results demonstrating how the constant scales with K for different problem instances would clarify this relationship.

### Open Question 3
- Question: How does the local convergence issue manifest in different tensor network topologies, and what strategies can effectively escape local minima?
- Basis in paper: The authors explicitly identify this as a limitation: the main limitation of TnALE is the local convergence issue and note that TnALE can easily drop in them referring to poor local minima in TN-TS experiments.
- Why unresolved: The authors acknowledge this problem but don't provide solutions: Solving this issue will be the direction of our future work. They contrast TnALE's local convergence with TNGA and TNLS's better global exploration due to stochastic elements.
- What evidence would resolve it: Comparative experiments showing the frequency and severity of local minima across different topologies, and evaluation of various escape strategies (multiple random restarts, simulated annealing, hybrid approaches) would address this question.

## Limitations
- Limited empirical validation of low-rankness assumption across diverse tensor structures
- Theoretical convergence guarantees rely on discrete convexity assumptions not extensively validated on real-world data
- Local convergence issue may trap algorithm in poor minima for certain tensor network topologies
