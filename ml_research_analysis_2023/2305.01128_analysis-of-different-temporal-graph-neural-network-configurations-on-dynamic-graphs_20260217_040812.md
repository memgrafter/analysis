# Analysis of different temporal graph neural network configurations on dynamic graphs

## Quick Facts
- arXiv ID: 2305.01128
- Source URL: https://arxiv.org/abs/2305.01128
- Reference count: 0
- Primary result: Comparative analysis of temporal graph neural networks (TGNs) on dynamic graphs, showing memory modules and attention mechanisms are crucial for performance.

## Executive Summary
This study performs a comparative analysis of temporal graph neural networks on dynamic graphs, examining both snapshot-based models (EvolveGCN-O/H, GConv-LSTM, GConv-GRU) for node regression and event-based models (TGN, TGAT) for edge prediction. The research identifies that memory modules are essential for retaining past information, attention-based embedding methods outperform alternatives, and single-layer architectures are often sufficient when combined with memory. The study uses EnglandCovid dataset for disease spread prediction and Wikipedia dataset for edge prediction tasks.

## Method Summary
The study evaluates temporal graph neural networks using two distinct approaches: snapshot-based models for node regression on the EnglandCovid dataset and event-based models for edge prediction on the Wikipedia dataset. For snapshot-based models, experiments were conducted with varying numbers of past windows (4 and 8) over 200 epochs, using 80% of data for training. For event-based models, TGN and TGAT were compared using attention-based embedding and memory modules. An extensive ablation study on TGN examined the impact of memory modules, embedding methods, and layer depth. The study also attempted to convert the snapshot-based EnglandCovid dataset to event-based format for TGN analysis.

## Key Results
- EvolveGCN-O achieves the best performance for node regression on EnglandCovid, with MSE decreasing from 0.15 to 0.05 when reducing past windows from 8 to 4
- TGN with attention-based embedding and memory module achieves highest validation precision (0.8623) and test AUC (0.8167) on Wikipedia dataset for edge prediction
- Single-layer TGN with memory module provides sufficient performance with lower computational cost compared to multi-layer alternatives

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Memory module is essential for retaining past information in TGN models.
- Mechanism: The memory module stores node embeddings updated by a recurrent GRU based on past interactions, allowing the model to retain long-term node states even during periods of inactivity.
- Core assumption: Past node states significantly influence future predictions in dynamic graphs.
- Evidence anchors:
  - [section] "The memory component plays an important role in retaining past long-term information about the nodes, thus preventing the loss of information. It can be seen that TGN-nomem which does not have the memory module has the lowest test-AUC in comparison to the models having the memory component."
  - [section] "Memory helps in retaining past information at a node based on its history, and the memory of each node is also referred to as the state of the node."
- Break condition: If node states change rapidly and past information becomes irrelevant, memory may introduce noise.

### Mechanism 2
- Claim: Attention-based embedding outperforms other methods in TGN models.
- Mechanism: Attention mechanisms allow the model to weight temporal neighbors differently based on their relevance, giving more importance to significant interactions rather than treating all neighbors equally.
- Core assumption: Not all temporal neighbors contribute equally to node representations.
- Evidence anchors:
  - [section] "Out of the different embedding modules tried, attention-based embedding is seen to have the best performance. Thus, giving more attention or importance to the more relevant temporal neighbors is crucial."
  - [section] "Attention mechanism used for aggregating neighbors performs significantly better than other aggregation methods like LSTM and mean."
- Break condition: If the attention mechanism overfits to training data or if temporal neighbors are uniformly relevant.

### Mechanism 3
- Claim: Single-layer TGN achieves comparable performance to multi-layer models with lower computational cost.
- Mechanism: The memory module captures past information, reducing the need for deep architectures to capture temporal dependencies.
- Core assumption: Temporal dependencies can be effectively captured with shallow networks when combined with memory.
- Evidence anchors:
  - [section] "Increasing the number of TGN layers seems to slightly improve the performance of the model. But it makes the computation much more expensive than that with one layer. Thus, the TGN model needs only 1 layer for performing sufficiently well with reasonable computations."
  - [section] "Models without memory like TGAT require two layers for a comparable performance with TGN with one layer."
- Break condition: If complex temporal patterns require deeper architectures that a single layer cannot capture.

## Architecture Onboarding

- Component map:
  Encoder -> Memory Module -> Message Module -> Embedding Module -> Mailbox Module

- Critical path:
  1. Event arrives at mailbox module
  2. Messages computed for involved nodes
  3. Memory module updates node states
  4. Embedding module generates current node representations
  5. Downstream prediction task uses embeddings

- Design tradeoffs:
  - Memory vs. computational efficiency: Memory modules improve performance but add complexity
  - Attention vs. simpler aggregation: Attention provides better performance but requires more computation
  - Single vs. multi-layer architectures: Single layers with memory often suffice, reducing computational cost

- Failure signatures:
  - Poor performance on inactive nodes: May indicate memory module issues
  - Overfitting with attention: Attention weights may be too specialized to training data
  - Slow training: May indicate inefficient implementation of memory updates

- First 3 experiments:
  1. Test TGN performance with and without memory module on a small dataset
  2. Compare attention-based embedding vs. mean aggregation on temporal neighbor information
  3. Evaluate single-layer vs. two-layer TGN performance to understand depth requirements

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Is the EnglandCovid dataset truly suitable for testing continuous-time dynamic graph (CTDG) models like TGN and TGAT, given that it naturally represents discrete-time dynamics?
- Basis in paper: [explicit] The authors note that "Whether the EnglandCovid dataset is a suitable choice to test the CTDG models is still a question" after attempting to convert it to event-based format and observing suboptimal results.
- Why unresolved: The conversion process from discrete-time to continuous-time format may have introduced artifacts or limitations that make the dataset unsuitable for testing CTDG models. The dataset's inherent discrete-time nature with aggregated daily snapshots conflicts with the event-based processing required by CTDG models.
- What evidence would resolve it: A comparative study using the same EnglandCovid dataset processed both as discrete-time (for DTDG models) and as attempted continuous-time (for CTDG models) would clarify whether the performance differences stem from model architecture or dataset format incompatibility. Additionally, testing CTDG models on other naturally event-based COVID-19 datasets would provide validation.

### Open Question 2
- Question: What is the optimal number of layers for temporal graph neural networks in different prediction tasks, and how does this vary between DTDG and CTDG models?
- Basis in paper: [explicit] The ablation study found that "TGN model needs only 1 layer for performing sufficiently well with reasonable computations" and that increasing to 2 layers "slightly improves the performance but makes computation much more expensive." For TGAT, at least 2 layers are needed "to append over the past information."
- Why unresolved: While the study identifies 1 layer as sufficient for TGN and 2 layers for TGAT on the Wikipedia dataset, this may not generalize across different tasks (node vs edge prediction), datasets, or dynamic graph characteristics. The trade-off between computational efficiency and marginal performance gains remains unclear.
- What evidence would resolve it: Systematic experiments varying the number of layers (1-4) across multiple datasets (both DTDG and CTDG) and prediction tasks would establish layer requirements. Ablation studies on model capacity versus dataset complexity would clarify when additional layers provide meaningful improvements versus computational overhead.

### Open Question 3
- Question: How critical is the memory module for TGN's performance, and can alternative memory mechanisms achieve similar or better results?
- Basis in paper: [explicit] The ablation study shows that TGN without memory ("TGN-nomem") has the "lowest test-AUC in comparison to the models having the memory component," indicating memory's importance in retaining past information and preventing information loss during periods of node inactivity.
- Why unresolved: While the study demonstrates that removing the memory module degrades performance, it only tests one type of memory mechanism (GRU-based). Alternative memory architectures, different update frequencies, or attention-based memory mechanisms could potentially offer improved performance or efficiency.
- What evidence would resolve it: Comparative experiments testing TGN with different memory architectures (LSTM, transformer-based memory, temporal attention memory) would identify whether GRU is optimal or if alternatives provide better retention of temporal information. Ablation studies varying memory update frequency and capacity would further clarify the memory module's role in different dynamic graph scenarios.

## Limitations
- Limited dataset diversity with only EnglandCovid and Wikipedia datasets used for evaluation
- Suboptimal results when converting EnglandCovid from snapshot-based to event-based format raises questions about dataset suitability
- Lack of detailed hyperparameter specifications for baseline models complicates exact reproduction

## Confidence

- **High confidence**: The performance improvements observed with memory modules in TGN models and the effectiveness of attention-based embedding methods are well-supported by experimental results and ablation studies.
- **Medium confidence**: The superiority of single-layer TGN models over multi-layer alternatives is supported but may vary with different dataset characteristics or task complexities.
- **Low confidence**: The generalizability of snapshot-based model performance on EnglandCovid to other dynamic graphs remains uncertain due to limited dataset diversity.
