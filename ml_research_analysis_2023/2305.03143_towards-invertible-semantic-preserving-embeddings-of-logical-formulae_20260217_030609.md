# Towards Invertible Semantic-Preserving Embeddings of Logical Formulae

## Quick Facts
- arXiv ID: 2305.03143
- Source URL: https://arxiv.org/abs/2305.03143
- Reference count: 40
- Key outcome: Bidirectional GAT encoder achieves 93.92% reconstruction accuracy for propositional logic formulae

## Executive Summary
This paper proposes LogicVAE, a graph variational autoencoder that learns invertible, semantic-preserving embeddings for propositional logic formulae. The model encodes formulae as abstract syntax trees into continuous vectors and decodes them back to discrete syntax trees, with a key innovation being the incorporation of semantic context via kernel embeddings during decoding. Extensive experiments demonstrate that the bidirectional Graph Attention Network (GAT) encoder achieves the highest reconstruction accuracy (93.92%) and semantic preservation among tested architectures, successfully generating novel, valid formulae and showing smooth interpolation in the learned latent space.

## Method Summary
The paper addresses the problem of learning invertible, semantic-preserving embeddings for propositional logic formulae using deep graph neural networks. The authors propose LogicVAE, a graph variational autoencoder model that encodes formulae represented as abstract syntax trees into continuous vectors and decodes them back to discrete syntax trees. A key innovation is incorporating semantic context via kernel embeddings during decoding to improve semantic preservation. Extensive experiments show that the bidirectional Graph Attention Network (GAT) encoder achieves the highest reconstruction accuracy (93.92%) and semantic preservation among tested architectures. The model successfully generates novel, valid formulae and demonstrates smooth interpolation in the learned latent space.

## Key Results
- Bidirectional GAT encoder achieves 93.92% reconstruction accuracy on propositional logic formulae
- Semantic context via kernel embeddings improves semantic preservation during decoding
- Model successfully generates novel, valid formulae and demonstrates smooth interpolation in latent space
- Decoder with syntactic constraints ensures 100% validity of generated formulae

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Bidirectional asynchronous message passing in the encoder captures both forward and backward dependencies in the abstract syntax tree (AST), improving reconstruction accuracy.
- Mechanism: The encoder processes nodes in topological order following the AST structure, allowing each node to aggregate information from its predecessors before updating its own state. The bidirectional variant reverses the graph direction and repeats the process, concatenating the final states of both passes. This dual traversal mimics the way a formula would be evaluated (forward for construction, backward for simplification), enabling the encoder to capture richer structural context.
- Core assumption: The syntactic dependencies in a propositional formula's AST are informative for semantic preservation, and processing them in both directions yields a more complete representation than a single direction.
- Evidence anchors:
  - [abstract]: "the bidirectional Graph Attention Network (GAT) encoder achieves the highest reconstruction accuracy (93.92%) and semantic preservation among tested architectures."
  - [section]: "we process nodes sequentially, i.e. we establish a topological order on the nodes of the input graph... possibly, this order can be reversed... originating what we refer to as a bidirectional architecture."
  - [corpus]: No direct corpus evidence; this is a novel architectural choice specific to the paper.
- Break condition: If the formula's AST does not exhibit meaningful asymmetry between forward and backward dependencies, or if the concatenation of bidirectional states introduces noise rather than useful information, the performance gain may diminish.

### Mechanism 2
- Claim: Incorporating semantic context via kernel embeddings during decoding conditions the generative process on semantic similarity, leading to semantically coherent reconstructions.
- Mechanism: The model computes a kernel embedding for each formula using a Boolean kernel defined over truth assignments. This embedding is reduced via PCA to a manageable dimension and concatenated to the latent vector before decoding. During decoding, the network samples from a conditional prior p(z|y) rather than an unconditional one, biasing generation toward formulas with similar semantics to the conditioning vector. This enforces semantic consistency beyond syntactic validity.
- Core assumption: The kernel embedding captures meaningful semantic structure of propositional formulas, and conditioning on it during generation preserves this structure in the latent space.
- Evidence anchors:
  - [abstract]: "A key innovation is incorporating semantic context via kernel embeddings during decoding to improve semantic preservation."
  - [section]: "we evaluate its semantic-context vector using the kernel of Section 2.1 and perform conditional decoding as described at the end of Section 3.2."
  - [corpus]: No direct corpus evidence; the kernel embedding approach is introduced in this work.
- Break condition: If the kernel embedding fails to capture the true semantic similarity (e.g., due to insufficient training data or poor kernel choice), conditioning on it may not improve semantic preservation and could even degrade reconstruction accuracy.

### Mechanism 3
- Claim: Architecturally enforcing syntactic constraints in the decoder prevents invalid formula generation and improves validity rates.
- Mechanism: The decoder generates nodes one at a time using a GRU-based update rule, but crucially it enforces arity constraints and expansion rules based on node types (e.g., binary operators must have two children, negation one, variables none). This is done by following a depth-first traversal and only expanding nodes according to their operator arity, stopping when all leaves are variables or a maximum node count is reached. This design choice eliminates the need for post-hoc validity checks and ensures all generated outputs are syntactically correct by construction.
- Core assumption: Syntactic validity is a hard constraint that must be enforced during generation, not after, and that architectural constraints can effectively encode these rules without sacrificing expressiveness.
- Evidence anchors:
  - [section]: "we decided... to design a decoder which implements syntactic rules architecturally, i.e. that does not allow the generation of invalid formulae."
  - [section]: "decoding thus results in the following top-down iterative algorithm... Nodes are expanded following a depth-first traversal of the tree, taking into account the arity of the operators represented by node types, this prevents the violation of syntactic constraints."
  - [corpus]: No direct corpus evidence; this is a design decision made in the paper.
- Break condition: If the syntactic constraints are too restrictive, the decoder may fail to generate valid but complex formulas, or if the constraints are not comprehensive, invalid formulas may still be produced.

## Architecture Onboarding

- Component map:
  - Input formula -> AST graph -> Bidirectional GAT encoder -> Latent distribution -> Sample latent vector -> GRU-based decoder with syntactic constraints -> Reconstructed AST

- Critical path:
  1. Input formula → AST graph
  2. Encoder processes AST (bidirectional if applicable) → latent distribution
  3. Sample latent vector (conditioned on semantic context if CVAE)
  4. Decoder generates nodes following syntactic rules → reconstructed AST
  5. Compute loss (reconstruction + KL divergence)
  6. Backpropagate and update parameters

- Design tradeoffs:
  - Bidirectional vs unidirectional encoding: Bidirectional improves accuracy but doubles computation.
  - GAT vs GCN vs GRU encoder: GAT achieves best accuracy but is more complex; GCN is simpler but slightly less accurate; GRU is recursive and less effective for this task.
  - Semantic conditioning: Improves semantic preservation but may reduce reconstruction accuracy; useful for generative tasks rather than exact reconstruction.
  - Maximum node count: Prevents infinite generation but may truncate complex formulas.

- Failure signatures:
  - Low reconstruction accuracy: Check encoder architecture, latent dimension, or semantic context quality.
  - Low validity: Ensure syntactic constraints are correctly implemented in decoder.
  - Poor semantic preservation: Verify kernel embedding captures true semantic similarity; check PCA dimensionality reduction.
  - Mode collapse: Ensure KL divergence is not overly weighted; check latent space diversity.

- First 3 experiments:
  1. Train LogicVAE with GAT encoder on a small dataset (3 variables) and evaluate reconstruction accuracy and validity.
  2. Compare bidirectional vs unidirectional GAT encoder on the same dataset to quantify the benefit of bidirectional processing.
  3. Train LogicVAE-CVAE with semantic conditioning and evaluate semantic preservation metrics (kernel similarity, distance from conditioning vector).

## Limitations

- Results are confined to propositional logic; extension to first-order or temporal logic remains theoretical
- Semantic preservation relies on a custom Boolean kernel without comparison to alternative semantic measures
- The decoder's syntactic constraints may limit expressiveness for complex formulae

## Confidence

- Reconstruction accuracy claims: High (directly measured on test set)
- Semantic preservation claims: Medium (dependent on kernel embedding quality)
- Bidirectional encoder benefits: Medium (marginal improvement with doubled computation)
