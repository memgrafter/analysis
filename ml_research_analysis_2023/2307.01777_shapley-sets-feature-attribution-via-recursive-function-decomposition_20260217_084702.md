# Shapley Sets: Feature Attribution via Recursive Function Decomposition

## Quick Facts
- arXiv ID: 2307.01777
- Source URL: https://arxiv.org/abs/2307.01777
- Reference count: 19
- Primary result: Feature interactions in models and data can mislead Shapley value attributions; Shapley Sets provides an alternative by grouping interacting features into non-separable variable groups

## Executive Summary
Shapley Sets addresses a fundamental limitation of Shapley value feature attributions: their vulnerability to feature interactions in both models and data. The method introduces a recursive function decomposition algorithm that identifies non-separable variable groups (NSVGs) in log-linear time. Rather than attributing value to individual features, Shapley Sets assigns attribution to groups of interacting features, ensuring that no feature receives attribution in isolation when it depends on others. The method is value function agnostic and theoretically proven to be equivalent to Shapley value over the transformed feature set, inheriting the same fairness axioms.

## Method Summary
Shapley Sets decomposes a model function into non-separable variable groups using a recursive decomposition algorithm based on the RDG method. The algorithm recursively tests whether adding a single variable changes the attribution of a group, using a fitness measure to detect interactions. Variables are merged into groups when interactions exceed a threshold epsilon. Each NSVG is then treated as a "super-feature" for Shapley value calculation. The method works with both on-manifold (conditional) and off-manifold (marginal) value functions, making it applicable to various attribution scenarios.

## Key Results
- Shapley Sets correctly identifies interacting feature groups in synthetic functions, attributing credit to groups rather than individual features
- On synthetic benchmarks with known ground truth, Shapley Sets achieves lower Mean Average Error than standard Shapley value methods
- When used with on-manifold value functions, Shapley Sets avoids the sensitivity failure that plagues individual feature attributions in the presence of data interactions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Recursive decomposition identifies non-separable variable groups in O(n log n) time
- Mechanism: The Shapley Sets fitness measure recursively tests whether adding a single variable changes the attribution of a group. If interaction exists (measured by exceeding threshold ε), variables are merged into a group; otherwise, they are kept separate. This process continues recursively until no further interaction is detected.
- Core assumption: The underlying function is partially separable, meaning it can be expressed as a sum of terms each depending on a non-overlapping subset of variables.
- Evidence anchors: [abstract]: "Shapley Sets decomposes the underlying model into non-separable variable groups using a recursive function decomposition algorithm with log linear complexity in the number of variables." [section]: "The runtime of SS is O(nlogn) as proven in [12]."
- Break condition: If the function is fully non-separable (cannot be decomposed into a sum of separable components), the recursive grouping will place all variables into a single set, eliminating the advantage of grouped attribution.

### Mechanism 2
- Claim: Shapley Sets attribution equals Shapley value over the transformed feature set
- Mechanism: By grouping interacting variables into non-separable variable groups (NSVGs), each group can be treated as a "super-feature." The Shapley value computed over these super-features yields exactly the same attribution as the original Shapley Sets calculation for each NSVG.
- Core assumption: Once NSVGs are identified, they behave as atomic features for the purpose of Shapley value calculation.
- Evidence anchors: [abstract]: "We show that Shapley Sets is equivalent to the Shapley value over the transformed feature set and thus benefits from the same axioms of fairness." [section]: "Proposition 2.2. If we model each NSVG, Xi ∈ {Xi, ..., Xm} as a super-feature Zi such that Z = {Zi, ..., Zm}, zi = xi and z = {z1, ..., zn} The Shapley value of each super feature ϕZi(v, z) is equivalent to v(z, Zi)"
- Break condition: If the decomposition into NSVGs is incorrect (e.g., due to mis-specified epsilon threshold), the equivalence to Shapley value over the transformed set will not hold.

### Mechanism 3
- Claim: Avoids sensitivity failure when used with on-manifold value functions
- Mechanism: By grouping interacting features (whether interaction is in data or model), Shapley Sets ensures that no individual feature within a group receives attribution in isolation. This prevents the "failure of sensitivity" where a feature with no direct impact on the model still gets non-zero attribution due to statistical dependence.
- Core assumption: The fitness measure correctly identifies all interacting features and groups them together.
- Evidence anchors: [abstract]: "Shapley Sets is value function agnostic and we show theoretically and experimentally how Shapley Sets avoids pitfalls associated with Shapley value based alternatives and are particularly advantageous for data types with complex dependency structure." [section]: "Used with vcond, as interacting features are placed in the same NSVG, the attributions resulting from SS do not suffer from the violation of sensitivity as described in Section 1.2."
- Break condition: If the epsilon threshold is set too high, some interactions may be missed, leading to incomplete grouping and potential sensitivity issues.

## Architecture Onboarding

- Component map: Model function f -> Recursive decomposition algorithm -> Non-separable variable groups (NSVGs) -> Value function calculator (vcond/vmarg) -> Attributions for each NSVG
- Critical path:
  1. Receive model and data
  2. Initialize recursive decomposition with first variable
  3. Iteratively test for interaction using fitness measure
  4. Group interacting variables into NSVGs
  5. Compute attributions for each NSVG using specified value function
  6. Return grouped attributions

- Design tradeoffs:
  - Runtime vs Accuracy: Lower epsilon values increase runtime but improve detection of weak interactions
  - Generality vs Specificity: Shapley Sets works with any value function but may produce different groupings depending on the function chosen
  - Simplicity vs Expressiveness: The recursive decomposition is simple to implement but may miss complex interaction patterns that aren't captured by the fitness measure

- Failure signatures:
  - All variables grouped into a single NSVG: May indicate overly sensitive fitness measure or fully non-separable function
  - Individual variables remain ungrouped despite known interactions: May indicate epsilon threshold too high
  - Attributions don't sum to prediction change: May indicate implementation error in value function calculation

- First 3 experiments:
  1. Test on synthetic function f(X) = X1 + X2*X3 with independent features to verify correct identification of {X2, X3} as NSVG
  2. Test on synthetic function f(X) = X1 + X2 where X2 = X3 to verify correct handling of data interaction
  3. Test on real dataset (e.g., Boston Housing) with both vcond and vmarg to compare attribution patterns and deletion scores

## Open Questions the Paper Calls Out

- Question: How can Shapley Sets be adapted to handle multiplicative separability in functions, beyond the current focus on additive separability?
  - Basis in paper: [explicit] The paper mentions that future work should consider function decomposition under a wider class of separability such as multiplicative separability, where associated algorithms decompose a function into its additive and multiplicative separable variable sets.
  - Why unresolved: The current implementation of Shapley Sets is based on additive separability, and extending it to handle multiplicative separability requires developing new decomposition algorithms and theoretical foundations.
  - What evidence would resolve it: Development of a theoretical framework and algorithm that can decompose functions into both additive and multiplicative separable variable sets, along with experimental validation showing improved performance over the current additive-only approach.

- Question: What is the optimal way to set the interaction threshold parameter (epsilon) in Shapley Sets to ensure robustness across different datasets and models?
  - Basis in paper: [explicit] The paper discusses the sensitivity of Shapley Sets to the setting of epsilon, particularly for the vcond value function, and suggests that future work should explore alternative methods of function decomposition that are less dependent on this parameter.
  - Why unresolved: The choice of epsilon significantly impacts the resulting variable groupings and attributions, and finding a universally optimal or adaptive method for setting this parameter remains an open challenge.
  - What evidence would resolve it: Development of an adaptive or data-driven method for setting epsilon that consistently produces robust and meaningful variable groupings across a wide range of datasets and model types.

- Question: How does the performance of Shapley Sets compare to other feature attribution methods in terms of computational efficiency and explanation quality for high-dimensional datasets?
  - Basis in paper: [inferred] While the paper shows that Shapley Sets has O(n log n) complexity, it does not directly compare its performance to other methods like SHAP or LIME in terms of computational efficiency or explanation quality for high-dimensional data.
  - Why unresolved: The computational efficiency and explanation quality of Shapley Sets in high-dimensional settings is not well-established, and there may be trade-offs between the two that are not yet understood.
  - What evidence would resolve it: Comprehensive benchmarking studies comparing Shapley Sets to other feature attribution methods on high-dimensional datasets, evaluating both computational efficiency and explanation quality metrics such as faithfulness and stability.

## Limitations
- Relies on the assumption that the underlying function is partially separable; fully non-separable functions result in all features being grouped together
- Performance is sensitive to the epsilon threshold parameter, with no established method for optimal selection
- Does not compare against all recent feature attribution techniques, limiting assessment of relative performance
