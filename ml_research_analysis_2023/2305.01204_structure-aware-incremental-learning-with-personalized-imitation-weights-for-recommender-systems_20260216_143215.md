# Structure Aware Incremental Learning with Personalized Imitation Weights for Recommender Systems

## Executive Summary
This paper addresses catastrophic forgetting in recommender systems by proposing an adaptive incremental learning framework that learns personalized imitation weights for each user. The method balances contributions from recent data and historical knowledge using a state vector to characterize user interest shifts between training blocks. The framework integrates with existing GNN-based incremental learning approaches and is trained end-to-end via backpropagation. Experiments across five diverse datasets demonstrate consistent performance improvements, with the best model achieving up to 19.3% improvement in recall@20 while requiring only 30% of the training time compared to full-batch retraining.

## Method Summary
The paper proposes an adaptive incremental learning method for recommender systems that learns personalized imitation weights to balance contributions from recent data and historical knowledge. The framework uses a state vector to characterize user interest shifts between training blocks and is compatible with existing GNN-based incremental learning approaches. The method is trained end-to-end via backpropagation and introduces additional hyperparameters (state vector size, adaptation rate) that require careful tuning for different datasets.

## Key Results
- Achieves up to 19.3% improvement in recall@20 over non-adaptive methods
- Requires only 30% of the training time compared to full-batch retraining
- Demonstrates consistent performance improvements across five diverse datasets

## Why This Works (Mechanism)
The method works by learning personalized imitation weights that adapt to individual user behavior patterns. The state vector captures user interest shifts between training blocks, allowing the model to dynamically balance historical knowledge with recent interactions. This adaptive weighting mechanism prevents catastrophic forgetting by ensuring that user-specific patterns are preserved while incorporating new information.

## Architecture Onboarding

Component Map:
Input Data -> State Vector Generator -> Personalized Weight Calculator -> GNN Backbone -> Output Layer

Critical Path:
State Vector Generator calculates user interest shifts → Personalized Weight Calculator generates adaptation weights → GNN Backbone applies weights during training → Output Layer produces recommendations

Design Tradeoffs:
- Higher state vector dimensions improve adaptation accuracy but increase computational overhead
- More frequent weight updates provide better adaptation but reduce training efficiency
- Stronger personalization improves individual user performance but may reduce overall model stability

Failure Signatures:
- Performance degradation on long-tail users indicates insufficient personalization
- Increasing training time suggests inefficient weight adaptation mechanisms
- Inconsistent results across datasets indicate hyperparameter sensitivity
