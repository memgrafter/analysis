# Differentiable Grey-box Modelling of Phaser Effects using Frame-based Spectral Processing

## Quick Facts
- arXiv ID: 2306.01332
- Source URL: https://arxiv.org/abs/2306.01332
- Reference count: 0
- Primary result: Differentiable DSP approach models phaser effects with interpretable parameters and optimal 5% LFO-period training windows

## Executive Summary
This paper presents a novel approach to modeling phaser audio effects by combining differentiable digital signal processing with frame-based spectral processing. The method addresses the challenge of capturing the time-varying behavior of phasers controlled by low-frequency oscillators (LFOs) through a spectral implementation that enables gradient-based optimization. The model jointly learns both the LFO control signal and the time-varying spectral response, achieving accurate emulation of both digital and analog phaser effects while maintaining interpretable and adjustable parameters.

## Method Summary
The approach employs frame-based spectral processing to implement time-varying filters in the frequency domain, with a transfer function derived from typical analog phaser circuit topology. A damped complex exponential generates the LFO control signal, while a multilayer perceptron (MLP) maps LFO output to normalized break frequency parameters. The model uses gradient descent optimization with Wirtinger derivatives to jointly learn the LFO parameters and spectral response. The training process minimizes error-to-signal ratio (ESR) on test data, with experiments showing optimal performance when the training window length is approximately 5% of the LFO period.

## Key Results
- Model accurately emulates both digital and analog phaser effects with interpretable parameters
- Optimal training window length is approximately 5% of the LFO period
- Inference frame length can be altered without significant loss in accuracy
- Model retains circuit-like parameter interpretability compared to black-box approaches

## Why This Works (Mechanism)
The spectral frame-based implementation enables gradient computation for time-varying systems by transforming the time-varying filter operations into the frequency domain where differentiability is preserved. The damped complex exponential LFO generator with Wirtinger derivatives allows gradient-based optimization of complex-valued parameters, while the MLP waveshaper provides flexible mapping from LFO output to filter control parameters. This combination captures both the periodic nature of the LFO and the nonlinear mapping to spectral characteristics.

## Architecture Onboarding

Component Map: LFO Generator -> MLP Waveshaper -> Transfer Function -> Frame-based Spectral Processing -> Overlap-Add Reconstruction

Critical Path: Training signal -> Spectral decomposition -> Time-varying filtering (learned LFO + transfer function) -> Spectral synthesis -> Output signal

Design Tradeoffs: Window length vs temporal resolution (shorter windows capture rapid changes but reduce frequency resolution), overlap percentage vs computational cost (higher overlap improves reconstruction but increases computation), filter cascade depth vs model complexity (more stages enable complex responses but increase parameters).

Failure Signatures: ESR > 10% indicates insufficient time-frequency resolution, noisy LFO estimation suggests training segments contain less than one LFO period, convergence failure may indicate improper initialization of MLP parameters.

## Limitations
- Optimal training window selection (5% of LFO period) derived from single chirp-train dataset without broader exploration
- Wirtinger derivative implementation lacks explicit gradient formulations for practical implementation
- MLP initialization sensitivity noted but specific strategies not provided
- Performance metrics focus solely on ESR without perceptual validation
