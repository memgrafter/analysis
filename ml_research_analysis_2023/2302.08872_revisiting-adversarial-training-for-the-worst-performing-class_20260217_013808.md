# Revisiting adversarial training for the worst-performing class

## Quick Facts
- **arXiv ID**: 2302.08872
- **Source URL**: https://arxiv.org/abs/2302.08872
- **Reference count**: 40
- **Key outcome**: CFOL improves worst-class accuracy in adversarial training through adaptive class sampling using the Exp3 bandit algorithm

## Executive Summary
This paper addresses a critical limitation in adversarial training: the tendency for certain classes to have significantly lower accuracy than others. The authors propose Class Focused Online Learning (CFOL), which learns an adaptive class sampling distribution using the Exp3 bandit algorithm, focusing training on the hardest classes. CFOL provides high-probability convergence guarantees for the worst class loss and can be easily integrated into existing adversarial training pipelines with minimal computational overhead.

## Method Summary
CFOL is a method that improves worst-class accuracy in adversarial training by adaptively reweighting the class sampling distribution based on observed losses. It learns a non-uniform distribution over classes using the Exp3 bandit algorithm, sampling harder classes more frequently to focus training on them. The method can be integrated into existing training setups with minimal computational overhead and provides theoretical convergence guarantees for the worst class loss.

## Key Results
- CFOL consistently improves worst class accuracy by 0.8% to 1.3% across CIFAR10, CIFAR100, and STL10 datasets
- The method also improves the 20% tail accuracy, with gains ranging from 0.5% to 2.3% depending on the dataset
- CFOL interpolates between average and worst-case accuracy by adjusting the mixing parameter γ, allowing users to trade off between average accuracy and worst-class performance

## Architecture Onboarding

- Component map:
  - Datasets -> Data augmentation -> Adversarial example generation -> CFOL class sampler -> Model training -> Evaluation

- Critical path:
  1. Initialize uniform class distribution and model parameters
  2. Sample class according to current distribution
  3. Generate adversarial example for sampled class
  4. Update model parameters using adversarial loss
  5. Update class distribution based on observed loss
  6. Repeat until convergence

- Design tradeoffs:
  - Uniform mixing parameter γ vs. pure adversarial sampling: Larger γ improves average accuracy but may reduce worst-class gains
  - Step size for adversarial distribution update: Smaller steps provide more stable learning but may converge slower
  - Mini-batch size: Larger batches provide better gradient estimates but increase computational cost

- Failure signatures:
  - Degenerate class distribution: If one class dominates sampling, the model may overfit to that class
  - Oscillating accuracy: If the class distribution changes too rapidly, the model may not converge
  - Computational overhead: If the class sampling mechanism is not efficiently implemented, training may become prohibitively slow

- First 3 experiments:
  1. Baseline comparison: Run CFOL-AT vs ERM-AT on CIFAR10 with standard hyperparameters to verify worst-class accuracy improvement
  2. Mixing parameter sweep: Test different γ values (0.1, 0.5, 0.9) on CIFAR10 to understand the interpolation property
  3. Transfer learning: Apply CFOL-AT to a different architecture (e.g., VGG-16) on CIFAR10 to verify architecture independence

## Limitations
- Theoretical convergence guarantees rely heavily on the mistake-bound assumption for model parameters, which may not hold for all architectures or loss functions
- The corpus evidence for CFOL's specific mechanisms is notably weak, with most supporting evidence coming from related but distinct papers on adversarial training and fairness
- The paper's evaluation is limited to specific attack configurations, leaving questions about CFOL-AT's robustness against a wider range of attacks

## Confidence
- **High confidence** in empirical results showing worst-class accuracy improvement on CIFAR10/CIFAR100/STL10
- **Medium confidence** in the theoretical convergence guarantees due to limited corpus evidence for the specific regret analysis
- **Medium confidence** in the interpolation property, as the CIFAR10 experiments show the effect but broader validation across datasets is limited
