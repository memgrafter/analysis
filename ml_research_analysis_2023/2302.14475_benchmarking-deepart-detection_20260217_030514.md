# Benchmarking Deepart Detection

## Quick Facts
- arXiv ID: 2302.14475
- Source URL: https://arxiv.org/abs/2302.14475
- Reference count: 23
- This paper establishes a benchmark database and series of benchmarks for deepart detection, introducing a novel continual learning scenario and prompt-tuning framework.

## Executive Summary
This paper introduces a comprehensive benchmark for deepart detection, establishing the Deepart Detection Database (DDDB) with high-quality conventional art images and deepfake art from five state-of-the-art generative models. The authors propose a novel continual learning scenario where a base session contains both deepart and conventional art classes, while subsequent sessions focus on deepart classes from different models. The paper demonstrates that a prompt-tuning framework effectively addresses the challenges of this scenario, enabling rehearsal-free methods to outperform their rehearsal-based counterparts.

## Method Summary
The paper establishes a benchmark database containing conventional art images from LAION-5B and deepfake art from five generative models (Stable Diffusion, DALL-E 2, Imagen, Midjourney, and Parti). For once-for-all detection (ODD), the method uses fine-tuning or prompt-tuning on vision transformer models. For continual deepart detection (CDD), the framework adapts rehearsal-based methods (iCaRL, BiC, GEM, Coil, Foster) and rehearsal-free methods (LwF, EWC, S-Prompts) with knowledge distillation, cosine normalization, and prompt-tuning. The CDD scenario involves sequential learning sessions where the base session contains both classes while subsequent sessions contain only deepart classes, with shared LAION-5B negatives across all sessions.

## Key Results
- The proposed prompt-tuning framework effectively addresses the challenging continual learning problem in deepart detection
- Rehearsal-free methods with the proposed transformation framework outperform rehearsal-based counterparts
- Comprehensive experiments demonstrate significant improvements over previous methods across multiple metrics

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The shared negative class (conarts from LAION-5B) across all sessions prevents catastrophic forgetting in continual learning
- Mechanism: By reusing the same negative samples (conarts) from the base session for all incremental sessions, the model maintains a consistent contrastive target across learning stages, stabilizing classifier heads
- Core assumption: The base session's negative samples are representative enough to serve as effective negatives for all future deepart classes
- Evidence anchors: [section] "we suggest sharing the stored negative samples for replay from the base session among all incremental sessions..." [abstract] "we suggest keeping the natural setup where most of deepart models have no officially released conarts... we suggest sharing the LAION-5B conarts as the negative samples for all the non-base sessions"
- Break condition: If LAION-5B conarts are not sufficiently diverse or representative compared to the actual training data used by newer deepart models, performance will degrade

### Mechanism 2
- Claim: Prompt-tuning reduces feature bias in continual learning by constraining parameter updates
- Mechanism: Instead of fine-tuning all network weights, prompt-tuning only updates small learnable tokens added to each transformer layer, forcing the model to adapt without drastically altering the feature space
- Core assumption: The pre-trained feature extractor is sufficiently general to handle new deepart classes with only minor prompt adjustments
- Evidence anchors: [section] "we suggest the use of the prompt-tuning technique... as we empirically find it is capable of addressing the feature bias issue while it has shown a superior efficiency for transfer learning." [section] "prompt-tuning needs more iterations to fit the training sets... the model only updates a few parameters on a new task, it can be forced to learn a classifier on a relatively good feature space."
- Break condition: If the domain shift between tasks is too large, prompt-tuning alone may not provide enough adaptation capacity

### Mechanism 3
- Claim: Cosine normalization equalizes classifier head magnitudes across incremental sessions, preventing head misalignment
- Mechanism: Normalizing both feature vectors and classifier weights before dot product ensures each head produces outputs on the same scale, reducing bias toward newer sessions
- Core assumption: Head magnitude imbalance is a primary cause of forgetting and poor performance in multi-head continual learning
- Evidence anchors: [section] "we suggest applying the Cosine Normalization (CN) technique... for a normalization of the separate classifier heads, to save the general rehearsal-free methods." [section] "magnitudes of both the weights and the biases of the linear classifier for the new session's classes are significantly higher than those for the classes for the old sessions."
- Break condition: If other factors (e.g., feature drift) dominate over head magnitude imbalance, cosine normalization alone won't solve forgetting

## Architecture Onboarding

- Component map: Input image tensor → ViT-B/16 backbone (frozen) → Prompt tokens (learnable) → Layer outputs → Cosine-normalized classifier heads → Softmax predictions
- Critical path: Prompt tokens → Feature extraction → Cosine normalization → Classification → Loss computation
- Design tradeoffs: Using shared LAION-5B negatives simplifies continual learning but may introduce domain mismatch; prompt-tuning limits adaptation capacity but reduces feature bias; cosine normalization adds computational overhead but stabilizes predictions
- Failure signatures: Poor performance on newer sessions suggests prompt-tuning capacity is insufficient; degraded performance on base session indicates feature bias or forgetting; random predictions suggest loss function collapse
- First 3 experiments: 1) Implement base session training with shared LAION-5B negatives and verify binary classification works; 2) Add prompt-tuning to first incremental session and measure feature space stability via t-SNE; 3) Apply cosine normalization and knowledge distillation to CDD3 setting and compare with baseline forgetting curves

## Limitations

- The effectiveness of shared LAION-5B negatives across all sessions may degrade as deepart generation technology evolves and introduces domain shifts
- The performance gains from the transformation framework components are not fully isolated, making it difficult to attribute improvements to specific mechanisms
- Limited evaluation on deepart models beyond the five studied leaves uncertainty about generalizability to newer generation models

## Confidence

- Database construction and baseline evaluations: High
- Continual learning framework effectiveness: Medium
- Prompt-tuning superiority claims: Medium
- Generalizability across deepart models: Low
