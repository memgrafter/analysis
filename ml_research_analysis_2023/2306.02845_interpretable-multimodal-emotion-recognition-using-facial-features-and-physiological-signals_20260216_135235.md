# Interpretable Multimodal Emotion Recognition using Facial Features and Physiological Signals

## Quick Facts
- arXiv ID: 2306.02845
- Source URL: https://arxiv.org/abs/2306.02845
- Reference count: 21
- Primary result: 54.61% accuracy on IEMOCAP dataset with 10 emotion classes

## Executive Summary
This paper presents a multimodal emotion recognition framework that combines facial features and rPPG signals to improve emotion classification performance. The framework uses Haar cascades for face detection, a pre-trained ResNet-34 model for facial landmarks, and implements both early and late fusion approaches. Through permutation feature importance analysis, the authors quantify the contributions of each modality, finding that visual features contribute 62.33% while rPPG signals contribute 37.67% to emotion recognition accuracy.

## Method Summary
The framework extracts rPPG signals using Haar cascades and facial landmarks using a pre-trained ResNet-34 model. Two fusion approaches are implemented: early fusion concatenates features before classification, while late fusion combines model outputs through weighted averaging. The models are trained on the IEMOCAP dataset for 50 epochs with batch size 32 and learning rate 0.001. Permutation feature importance analysis is used to compute modality contributions to overall performance.

## Key Results
- Early fusion achieved 54.61% accuracy compared to 41.17% for late fusion
- Visual modality contributions: 62.33%
- rPPG modality contributions: 37.67%
- Both modalities outperform individual models, demonstrating complementarity

## Why This Works (Mechanism)

### Mechanism 1
- Early fusion enables joint learning of spatial (facial landmarks) and temporal (physiological signals) emotion characteristics
- Core assumption: Spatial-temporal emotion aspects are best captured through feature-level integration
- Evidence: Early fusion (54.61%) significantly outperforms late fusion (41.17%)
- Break condition: Incompatible feature scales or noisy feature concatenation

### Mechanism 2
- PFI quantifies modality contributions by measuring performance degradation from random feature shuffling
- Core assumption: Permutation-based importance accurately reflects true modality contributions
- Evidence: Reported 37.67% (rPPG) and 62.33% (visual) contributions
- Break condition: Highly correlated features or model instability

### Mechanism 3
- Physiological and facial features provide complementary emotion information
- Core assumption: Emotions manifest through both physiological changes and facial expressions
- Evidence: Both modalities contribute meaningfully to classification
- Break condition: Corrupted physiological signals or controlled facial expressions
