# Larger language models do in-context learning differently

## Quick Facts
- arXiv ID: 2303.03846
- Source URL: https://arxiv.org/abs/2303.03846
- Reference count: 40
- Key outcome: Large language models can override semantic priors when given in-context exemplars with flipped or semantically-unrelated labels, while smaller models rely primarily on pretraining priors

## Executive Summary
This paper investigates how in-context learning (ICL) capabilities scale with model size across different language model families. The key finding is that the ability to override semantic priors based on in-context exemplars is an emergent property of larger models. Small models ignore flipped labels and rely on their pretraining priors, while large models can follow the in-context mappings even when they contradict strong semantic priors. The paper also shows that instruction-tuned models strengthen both semantic prior usage and the capacity to learn input-label mappings, though more so for the former.

## Method Summary
The authors conduct experiments across multiple model families (GPT-3, InstructGPT, Codex, PaLM, and Flan-PaLM) using two primary setups: ICL with flipped labels where exemplars have labels opposite to their semantic meaning, and ICL with semantically-unrelated labels (SUL-ICL) where labels are arbitrary tokens. They evaluate performance on sentiment classification and linear classification tasks, systematically varying model scale and comparing base models with instruction-tuned variants. The experiments measure how well models follow the in-context mapping versus relying on semantic priors from pretraining.

## Key Results
- Large models can override semantic priors when given in-context exemplars with flipped labels, while small models ignore flipped labels and rely on pretraining priors
- The ability to perform semantically-unrelated label ICL (SUL-ICL) emerges primarily with scale, with large-enough models capable of linear classification in SUL-ICL settings
- Instruction-tuned models strengthen both semantic prior usage and mapping learning capacity, but exhibit stronger improvement in semantic prior reliance

## Why This Works (Mechanism)
The mechanism appears to be an emergent capability where larger models develop sufficient capacity to maintain and selectively apply both semantic priors and in-context mappings simultaneously. As models scale up, they can better distinguish between the semantic content of inputs and the mapping information provided in demonstrations, allowing them to override strong priors when the context explicitly contradicts them. This suggests that scale enables more sophisticated meta-learning capabilities where models can learn to learn from demonstrations rather than relying solely on stored knowledge.

## Foundational Learning
- In-context learning (ICL): Why needed - core mechanism being studied; Quick check - ability to perform new tasks from demonstrations without weight updates
- Semantic priors: Why needed - baseline knowledge from pretraining that models use for predictions; Quick check - model performance when no in-context exemplars are provided
- Emergent scaling behavior: Why needed - central thesis about scale-dependent capabilities; Quick check - systematic variation of model size to identify threshold behaviors
- Linear classification: Why needed - simple task to isolate learning of input-label mappings; Quick check - performance on arbitrary label mappings

## Architecture Onboarding

Component map: Input tokens -> Embedding layer -> Transformer blocks -> Output logits -> Label prediction

Critical path: Input text → Tokenization → Embedding lookup → Multi-head attention + FFN layers → Layer normalization → Final linear projection → Softmax

Design tradeoffs: Larger models trade increased parameter count and computational cost for emergent capabilities like flexible in-context learning; instruction tuning trades pretraining generality for improved instruction following and prior strengthening

Failure signatures: Small models consistently ignore flipped labels and revert to semantic priors; models may show inconsistent behavior at intermediate scales; instruction-tuned models may over-rely on priors even when context suggests otherwise

None

## Limitations
- Limited task diversity (primarily sentiment and linear classification) may not generalize to other domains
- Focus on English-language tasks without multilingual validation
- Qualitative rather than quantitative measurement of semantic prior strength
- Instruction tuning effects not fully disentangled between semantic understanding and demonstration format learning

## Confidence
- **High** confidence in flipped-label ICL scale-emergent claims across multiple model families
- **Medium** confidence in SUL-ICL findings due to complex task variations
- **Medium** confidence in instruction tuning comparative analysis

## Next Checks
1. Replicate flipped-label experiments with additional semantic domains (topic classification, NLI) to test domain generality
2. Measure semantic prior strength quantitatively using probing techniques to validate qualitative characterization
3. Test multilingual generalization by repeating key experiments with non-English datasets to assess cross-lingual transfer of emergent behaviors
