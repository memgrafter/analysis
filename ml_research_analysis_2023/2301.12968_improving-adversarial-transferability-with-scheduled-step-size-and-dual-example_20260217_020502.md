# Improving Adversarial Transferability with Scheduled Step Size and Dual Example

## Quick Facts
- arXiv ID: 2301.12968
- Source URL: https://arxiv.org/abs/2301.12968
- Reference count: 40
- Primary result: Proposed method improves adversarial transferability by 19.4% over I-FGSM baseline on ImageNet

## Executive Summary
This paper addresses the challenge of improving adversarial example transferability across different deep neural network models. The authors observe that adversarial perturbations near the benign sample exhibit higher transferability, and propose a novel Scheduled Step Size and Dual Example (SD) strategy. By using an increasing step size schedule and a dual example approach that averages early gradients, the method effectively leverages the transferable information near the benign sample. The SD strategy is integrated with existing adversarial attack methods and demonstrates significant improvements in attack success rates under both white-box and black-box settings on the ImageNet dataset.

## Method Summary
The Scheduled Step Size and Dual Example (SD) strategy improves adversarial transferability by exploiting perturbations near the benign sample. The method maintains two examples throughout optimization: a decoy example that explores gradient directions, and a dual example that uses smoothed gradients from all previous iterations. An increasing step size schedule starts with small steps to sample near the benign sample where gradients are more consistent across models, then increases to fully utilize these directions. This approach is integrated with existing adversarial attack methods (I-FGSM, MI-FGSM, NI-FGSM, DIM, TIM, SIM) and evaluated on ImageNet using L-infinity bounded perturbations.

## Key Results
- SD improves I-FGSM average attack success rate by 19.4% compared to vanilla I-FGSM
- Method achieves higher attack success rates under both white-box and black-box settings
- Strong performance demonstrated against various advanced defense methods
- Significant improvements observed across multiple victim model architectures including ResNet, DenseNet, and Transformer models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The method improves adversarial transferability by exploiting perturbations near the benign sample, where the gradient directions are more consistent across models.
- Mechanism: Scheduled step size starts small to sample directions near the benign example, then increases to fully utilize these directions while maintaining diversity. The dual example approach aggregates early gradients to smooth out model-specific noise.
- Core assumption: Gradient directions near the benign sample are more transferable across different models than those far away.
- Evidence anchors:
  - [abstract] "we argue that the information of adversarial perturbations near the benign sample, especially the direction, benefits more on the transferability"
  - [section] "we notice that the transferability of adversarial examples generated by iterative fast gradient sign method (I-FGSM) exhibits a decreasing trend when increasing the number of iterations"
  - [corpus] Weak - corpus papers discuss transferability but not specifically near-benign-sample mechanisms
- Break condition: If model architectures produce vastly different feature maps even near the benign sample, the transferability advantage disappears.

### Mechanism 2
- Claim: The increasing step size schedule prevents the adversarial example from moving too far from the benign sample too quickly, maintaining transferability.
- Mechanism: Early iterations use small steps to explore the local neighborhood around the benign sample, capturing more transferable directions. Later iterations use larger steps to exploit these directions effectively.
- Core assumption: Small perturbations near the benign sample produce more consistent gradients across different models than larger perturbations far from the sample.
- Evidence anchors:
  - [section] "we use several kinds of decreasing sequence as the step sizes α to optimizexadv in (1)" followed by discussion of why increasing sequences work better
  - [abstract] "Our proposed strategy can be easily integrated with existing adversarial attack methods for better adversarial transferability"
  - [corpus] Weak - corpus papers discuss step size but not specifically increasing schedules for transferability
- Break condition: If the model landscape changes drastically with small perturbations, the small-step advantage may be lost.

### Mechanism 3
- Claim: The dual example approach averages early gradient directions to create a smoother optimization path that is more transferable across models.
- Mechanism: One example explores (decoy) while the other (dual) uses smoothed gradients from all previous iterations to update, reducing model-specific noise in the gradient.
- Core assumption: Averaging gradients from multiple iterations near the benign sample reduces model-specific features and increases transferability.
- Evidence anchors:
  - [section] "we average all the previous adversarial perturbations as an ensemble result to compute the update on the current iteration"
  - [abstract] "to fully utilize the adversarial information near the benign sample"
  - [corpus] Weak - corpus papers discuss ensemble methods but not specifically dual example approaches
- Break condition: If gradients from different iterations are highly correlated or if averaging reduces important directional information.

## Architecture Onboarding

- Component map:
  Input: Benign sample x, true label y, target model f, loss function L
  Core: Scheduled step size generator, dual example manager, gradient calculator
  Output: Adversarial example xadv with improved transferability

- Critical path:
  1. Initialize two examples (decoy and dual) at the benign sample
  2. For each iteration: calculate gradient on decoy, update dual using smoothed gradient
  3. Return final dual example as adversarial example

- Design tradeoffs:
  - Small initial steps preserve transferability but may slow convergence
  - Large final steps enable effective exploitation but risk reducing transferability
  - Dual example adds computation but provides significant transferability gains

- Failure signatures:
  - If transferability doesn't improve, check step size schedule and dual example averaging
  - If white-box performance degrades significantly, the method may be too conservative
  - If computational cost is prohibitive, consider reducing the number of iterations

  1. Compare I-FGSM vs. I-FGSM with increasing step size on a simple dataset (MNIST or CIFAR-10)

## Limitations
- Claims about near-benign-sample perturbations being more transferable lack rigorous theoretical justification
- Dual example approach adds computational overhead that isn't fully quantified against performance gains
- Method relies on empirical observations rather than established theory for its core mechanism

## Confidence
- Mechanism 1 (near-benign advantage): Medium - supported by empirical evidence but lacks theoretical grounding
- Mechanism 2 (increasing step size): High - intuitive and well-supported by ablation studies
- Mechanism 3 (dual example averaging): Medium - shows improvement but computational cost trade-offs need more analysis
