# DartsReNet: Exploring new RNN cells in ReNet architectures

## Quick Facts
- arXiv ID: 2304.05838
- Source URL: https://arxiv.org/abs/2304.05838

- This work addresses the problem of designing RNN cells specifically for image classification, which has been traditionally dominated by CNN architectures. The authors propose using the DARTS neural architecture search approach to find new RNN cell designs that are optimized for image-based domains, as opposed to standard RNN cells like LSTM and GRU that were designed for 1D sequential data. They apply this method to the ReNet architecture, which processes images using RNN cells. The resulting cells are deeper and more sequential compared to standard RNN cells. The proposed DartsReNet cells outperform standard RNN cells on both CIFAR-10 and SVHN datasets, with the Directional Weight Sharing variant achieving the best results on CIFAR-10 while using fewer parameters than the GRU baseline. ## Executive Summary
This paper addresses the problem of designing RNN cells specifically for image classification tasks, which have traditionally been dominated by CNN architectures. The authors propose using DARTS (Differentiable Architecture Search) to discover new RNN cell designs optimized for image data, as opposed to standard LSTM and GRU cells that were designed for 1D sequential data. They apply this approach to the ReNet architecture, which processes images using RNN cells, and demonstrate that the discovered cells outperform standard RNN cells on CIFAR-10 and SVHN datasets. The Directional Weight Sharing variant achieves the best results on CIFAR-10 while using fewer parameters than the GRU baseline, indicating that DARTS can effectively find RNN cell designs tailored for image classification tasks.

## Method Summary
The method uses DARTS to search for new RNN cell designs within the ReNet architecture. The search process alternates between optimizing network weights (θ) and architecture parameters (α) using gradient descent. Candidate activation functions include Sigmoid, Tanh, ReLU, and Identity. The discovered cells are evaluated on CIFAR-10 and SVHN datasets using a fixed network structure: 3 convolutional layers (7x7, 3x3, 3x3) followed by 3 ReNet layers with the discovered RNN cells, and a final fully connected layer. The Directional Weight Sharing variant shares weights between bidirectional RNNs to reduce parameters, while the Sigmoid Weighting variant implements a hard attention mechanism by learning weights for image patches.

## Key Results
- DARTS-discovered RNN cells outperform standard LSTM and GRU cells on CIFAR-10 and SVHN datasets
- The Directional Weight Sharing variant achieves the best results on CIFAR-10 while using fewer parameters than the GRU baseline
- The improvements generalize to SVHN despite the cells being derived from CIFAR-10 training data
- The discovered cells are deeper and more sequential compared to standard RNN cells

## Why This Works (Mechanism)

### Mechanism 1
- Claim: DARTS is able to discover RNN cell designs that are better suited for image data than standard LSTM/GRU cells.
- Mechanism: DARTS uses gradient descent to optimize the architecture parameters (α) that control which activation functions and connections are used in each vertex of the cell. This allows it to find cells with deeper, more sequential structures that capture image features better than traditional RNN cells designed for 1D sequences.
- Core assumption: The search space defined by DARTS (with candidate activation functions and connection patterns) is rich enough to find cells that outperform hand-designed cells for image classification.
- Evidence anchors:
  - [abstract] "We overcome this limitation by using DARTS to find new cell designs. We compare our results with ReNet that uses GRU and LSTM cells. Our found cells outperform the standard RNN cells on CIFAR-10 and SVHN."
  - [section] "DARTS derives the cell with gradient descent in the Architecture Search Space... It finds cells, which are smaller-sized structures that are usable in a Neural Network, using gradient descent"
  - [corpus] Weak evidence - corpus papers don't directly address DARTS for RNN cells in image classification
- Break condition: If the search space is too constrained or the optimization gets stuck in poor local minima, the discovered cells may not outperform standard designs.

### Mechanism 2
- Claim: The Directional Weight Sharing variant achieves better results with fewer parameters than the GRU baseline.
- Mechanism: By using the same weight matrix for both directions in a bidirectional RNN, the Directional Weight Sharing variant reduces the number of parameters while maintaining or improving performance. This acts as a form of regularization that prevents overfitting.
- Core assumption: The shared weights are sufficient to capture the necessary information from both directions without loss of representational power.
- Evidence anchors:
  - [abstract] "The improvements on SVHN indicate generalizability, as we derived the RNN cell designs from CIFAR-10 without performing a new cell search for SVHN."
  - [section] "The second variant combines the weights of the bidirectional RNNs in a ReNet layer similar to 'Directional Weight Sharing' proposed in ContextVP [3]."
  - [corpus] No direct evidence in corpus - this appears to be a novel contribution
- Break condition: If the directional information is crucial and cannot be adequately captured by shared weights, performance may degrade compared to separate weights.

### Mechanism 3
- Claim: The Sigmoid Weighting variant explores a new type of hard attention mechanism for ReNet.
- Mechanism: By calculating learnable weighting factors for each patch in the input sequence and applying sigmoid, the network can learn to weight the importance of different patches. This acts as a form of attention that helps the model focus on relevant regions of the image.
- Core assumption: The importance of image patches varies and can be learned effectively through sigmoid-weighted attention.
- Evidence anchors:
  - [section] "The idea behind Sigmoid Weighting is to explore a new type of hard attention, specifically in the case of ReNet"
  - [section] "We calculated a learnable weighting factor for each patch in the input sequence and took the Sigmoid of this value to let the network choose how vital the patch is."
  - [corpus] No direct evidence in corpus - this appears to be a novel contribution
- Break condition: If the attention mechanism doesn't learn meaningful weights or if uniform weighting would work equally well, the added complexity provides no benefit.

## Architecture Onboarding

- Component map: Input -> 3 Conv layers (7x7, 3x3, 3x3 with 256 filters) -> 3 ReNet layers with DARTS-discovered RNN cells -> Fully Connected layer (1024-dim) -> Output
- Critical path: The RNN cell design (found by DARTS) and the ReNet layer structure are the most important components. The convolutional layers serve as feature extractors but follow standard designs.
- Design tradeoffs: The main tradeoff is between cell depth/complexity and parameter efficiency. Deeper, more sequential cells may capture better representations but use more parameters. The Directional Weight Sharing variant attempts to balance this.
- Failure signatures: Poor performance on either CIFAR-10 or SVHN would indicate the discovered cells don't generalize well. Excessive overfitting on CIFAR-10 despite regularization would suggest the cells are too complex.
- First 3 experiments:
  1. Implement the basic ReNet architecture with standard LSTM/GRU cells as a baseline
  2. Run DARTS to discover a new RNN cell design on CIFAR-10 training data
  3. Evaluate the discovered cell on both CIFAR-10 and SVHN to test generalization

## Limitations

- The paper lacks detailed hyperparameter specifications, particularly learning rates and optimization settings for both the DARTS search phase and final evaluation
- The Sigmoid Weighting variant's implementation details are underspecified, making faithful reproduction challenging
- The generalizability claims based on SVHN performance are encouraging but limited to one additional dataset

## Confidence

- **High confidence**: The core mechanism of using DARTS to discover RNN cells for image classification is well-supported by the experimental results showing improved performance over standard LSTM/GRU cells on CIFAR-10 and SVHN.
- **Medium confidence**: The parameter efficiency claims for the Directional Weight Sharing variant are supported but would benefit from more extensive ablation studies comparing different weight sharing strategies.
- **Medium confidence**: The generalizability claims are supported by SVHN results but would be stronger with evaluation on additional datasets.

## Next Checks
