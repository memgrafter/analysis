# Uncertainty Quantification for Local Model Explanations Without Model Access

## Quick Facts
- arXiv ID: 2301.05761
- Source URL: https://arxiv.org/abs/2301.05761
- Reference count: 40
- Primary result: Bootstrap uncertainty intervals for local feature importance scores using only static input-output data, without requiring model access.

## Executive Summary
This paper introduces a model-agnostic algorithm for generating post-hoc explanations and uncertainty intervals for black-box models when only a static sample of inputs and outputs is available. The method employs local polynomial regression to construct feature importance scores and uses bootstrapping to quantify uncertainty in these explanations. Through simulation studies, the authors demonstrate that their bootstrap uncertainty intervals exhibit a favorable trade-off between interval width and coverage probability compared to naive frequentist confidence intervals and existing Bayesian approaches.

## Method Summary
The method fits a degree-k polynomial to the m nearest neighbors of a query instance in the static dataset, then computes feature importance as partial derivatives or function differences. Bootstrap resampling of the neighborhood generates an empirical distribution of feature importance scores, from which percentile-based uncertainty intervals are derived. The approach is validated on synthetic and real-world datasets, showing practical utility in quantifying explanation uncertainty and identifying features requiring further investigation.

## Key Results
- Bootstrap uncertainty intervals achieve better coverage-probability-to-interval-width trade-offs than naive frequentist intervals
- Polynomial regression of degree k > 1 improves local approximation fidelity compared to linear LIME assumptions
- Method successfully quantifies uncertainty in feature importance scores on COMPAS and German Credit datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The bootstrap method provides better coverage-probability-to-interval-width trade-offs than naive frequentist intervals because it captures the true sampling variability without assuming model specification.
- Mechanism: The bootstrap resamples the local neighborhood around the query point and refits the polynomial model multiple times, generating an empirical distribution of feature importance scores. Percentiles from this distribution form the uncertainty interval, which adapts to the actual variability in the data rather than relying on parametric assumptions.
- Core assumption: The local polynomial regression is a reasonable approximation of the black-box model's behavior in the neighborhood, and the bootstrap samples are representative of the underlying data-generating process.

### Mechanism 2
- Claim: Using polynomial regression of degree k > 1 improves local approximation fidelity compared to LIME's linear assumption, especially when the black-box model is not locally linear.
- Mechanism: By fitting a higher-degree polynomial (up to k ≤ 4 in experiments), the surrogate model can capture nonlinear behavior in the vicinity of the query point, leading to more accurate feature importance estimates.
- Core assumption: The black-box model's behavior can be reasonably approximated by a low-degree polynomial within a sufficiently small neighborhood.

### Mechanism 3
- Claim: Bootstrapping the local neighborhood (rather than the entire dataset) provides a more appropriate measure of uncertainty for explanations derived from fixed data.
- Mechanism: By resampling only from the m closest points to the query instance, the bootstrap captures variability specific to that local region, which is more relevant for the explanation than global variability.
- Core assumption: The m closest points are representative of the local behavior of the black-box model around the query point.

## Foundational Learning

- Concept: Local polynomial regression and its variance estimation
  - Why needed here: The method relies on fitting a polynomial to a local neighborhood and extracting feature importance as derivatives or function differences; understanding how to estimate the variance of these quantities is essential for constructing uncertainty intervals.
  - Quick check question: Given a fitted polynomial g(x) = β₀ + β₁x + β₂x², what is the derivative with respect to x, and how would you estimate its variance using the covariance matrix of the coefficients?

- Concept: Bootstrap resampling and percentile intervals
  - Why needed here: The bootstrap is used to generate an empirical distribution of feature importance scores, from which uncertainty intervals are derived; knowing how to implement and interpret bootstrap intervals is critical.
  - Quick check question: If you have 1,000 bootstrap samples of a feature importance score, how do you construct a 95% bootstrap percentile interval?

- Concept: Trade-off between interval width and coverage probability
  - Why needed here: The method's performance is evaluated not by whether intervals contain the true value at a fixed confidence level, but by the Pareto frontier of width vs. coverage; understanding this trade-off is key to hyperparameter selection.
  - Quick check question: If increasing the neighborhood size m decreases interval width but also decreases coverage, what does this imply about the bias-variance trade-off in the local approximation?

## Architecture Onboarding

- Component map: Data ingestion -> Neighborhood selection -> Polynomial fitting -> Feature importance extraction -> Bootstrap uncertainty -> Output
- Critical path: Neighborhood selection (O(dn + n log n)) -> Polynomial fitting (O(mq² + q³)) -> Bootstrap resampling and refitting (O(B(m'q² + q³))) -> Percentile computation
- Design tradeoffs:
  - m vs. k: larger m allows higher k but may include irrelevant points; smaller m may not support higher k
  - Weighted vs. unweighted regression: weighted can downweight distant points but adds O(m²q) cost
  - B vs. m': more bootstrap samples B improves interval stability but increases runtime; larger m' gives better coverage but wider intervals
- Failure signatures:
  - Very narrow intervals with poor coverage: likely due to too small m or k too low for the true model complexity
  - Very wide intervals with good coverage: likely due to too large m or k too high relative to neighborhood size
  - Unstable intervals across runs: likely due to too few bootstrap samples B or too small m'
- First 3 experiments:
  1. Run Algorithm 1 on a synthetic dataset with known ground truth and compare estimated feature importance to true values.
  2. Vary m and k systematically and plot the resulting Pareto frontier of average interval width vs. coverage probability.
  3. Compare bootstrap intervals to naive theoretical intervals on the same synthetic data to verify the claimed dominance.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can we extend the local polynomial regression approach to handle high-dimensional or structured data types like text and images, where polynomial bases become impractical?
- Basis in paper: [explicit] The paper discusses future work on extending the method to other data modalities such as text and images.
- Why unresolved: The current polynomial regression framework relies on explicit feature transformations that scale poorly with dimensionality and may not capture complex structures in non-tabular data.
- What evidence would resolve it: A successful extension would require demonstrating effective local surrogate modeling on high-dimensional datasets with clear uncertainty quantification.

### Open Question 2
- Question: How sensitive is the bootstrap uncertainty estimation to the choice of proximity function and neighborhood size, and can we develop adaptive methods to select these hyperparameters optimally?
- Basis in paper: [explicit] The paper discusses the trade-offs in choosing hyperparameters like neighborhood size m and proximity function πx∗(·), but does not provide a principled method for selection.
- Why unresolved: The current approach relies on manual tuning or heuristic rules, which may not generalize well across different datasets and models.
- What evidence would resolve it: A systematic study showing consistent performance across diverse datasets using an adaptive hyperparameter selection strategy.

### Open Question 3
- Question: How can we adapt the uncertainty quantification framework to handle ML models with stochastic outputs, such as generative models, where the output for a fixed input is not deterministic?
- Basis in paper: [explicit] The paper explicitly excludes ML models with stochastic outputs from consideration, noting that "We do not consider ML models with stochastic outputs, such as many generative models."
- Why unresolved: The bootstrap method relies on the assumption of deterministic outputs for a fixed input, which breaks down for stochastic models.
- What evidence would resolve it: A modified uncertainty quantification approach that successfully handles stochastic models and demonstrates valid coverage properties.

## Limitations
- Lack of direct empirical comparisons with existing uncertainty quantification methods
- Sensitivity of the method to hyperparameter choices (m, k, B, c) without clear guidance for practitioners
- Claims about improved coverage and interval width trade-offs are supported by simulation results but not validated on real-world datasets with known ground truth explanations

## Confidence
- **Medium** for the core claims about uncertainty quantification
- **Low** for claims of superiority over existing methods
