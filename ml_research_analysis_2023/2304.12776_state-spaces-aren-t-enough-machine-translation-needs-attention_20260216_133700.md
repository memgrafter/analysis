# State Spaces Aren't Enough: Machine Translation Needs Attention

## Quick Facts
- arXiv ID: 2304.12776
- Source URL: https://arxiv.org/abs/2304.12776
- Authors: Anonymous
- Reference count: 20
- Primary result: Attention-enhanced S4 models close the performance gap with Transformers on machine translation tasks

## Executive Summary
This paper investigates the application of Structured State Spaces for Sequences (S4) to machine translation. While S4 excels at language modeling, it struggles to match Transformer performance on MT tasks, particularly for long sentences. The authors identify that S4's compression of full input sequences into a single hidden state becomes insufficient for translation, where fine-grained token-level information is crucial. By incorporating attention mechanisms into S4 architectures, they demonstrate that the performance gap can be closed, achieving competitive results on benchmark datasets like WMT'14 and WMT'16.

## Method Summary
The study compares decoder-only S4 models (∅-S4) and encoder-decoder S4 models (S4-S4) against Transformer baselines on WMT'14 EN↔DE and WMT'16 EN↔RO datasets. S4 layers replace self-attention in standard Transformer architectures, with attention-enhanced variants (S4-S4A) adding cross-attention modules. Models are trained using ADAM optimizer with 4,000 warm-up steps and inverse square root learning rate scheduling. The key innovation is adding attention mechanisms to S4 to enable token-level retrieval of source information during decoding.

## Key Results
- Decoder-only S4 lags behind Transformers by ~4 BLEU points on MT tasks
- S4 struggles specifically with long sentences, showing decreasing performance as length increases
- Attention-enhanced S4 models (S4-S4A) achieve competitive performance with Transformers
- The gap is attributed to S4's inability to summarize full source sentences in a single hidden state

## Why This Works (Mechanism)

### Mechanism 1
- Claim: S4 compresses the full input sequence into a single hidden state, which becomes insufficient for long sequences in machine translation.
- Mechanism: The S4 state space formulation maintains a single latent vector that must encode the entire history of the input. As sequence length increases, this single vector cannot capture fine-grained token-level information needed for accurate translation.
- Core assumption: A fixed-size representation can adequately summarize variable-length input sequences for the task at hand.
- Evidence anchors:
  - [abstract]: "S4 lags behind the Transformer by approximately 4 BLEU points, and that it counter-intuitively struggles with long sentences"
  - [section 4.2]: "As the input length increases, it becomes increasingly hard for the model to accurately store the full source sentence in a single hidden state"
  - [corpus]: Weak - corpus neighbors discuss state spaces and long sequences but don't directly address the single-state compression limitation for MT
- Break condition: When the source sentence becomes too long for the fixed-size hidden state to adequately represent all necessary information

### Mechanism 2
- Claim: Attention mechanisms provide a retrieval mechanism that allows the model to access specific source token states during decoding.
- Mechanism: Cross-attention in the decoder allows direct access to encoder states at the token level, bypassing the need to compress all source information into a single state. This enables accurate retrieval of source information during generation.
- Core assumption: Direct access to token-level representations is more effective than compressed representations for translation tasks
- Evidence anchors:
  - [abstract]: "we show that this gap is caused by S4's inability to summarize the full source sentence in a single hidden state, and show that we can close the gap by introducing an attention mechanism"
  - [section 4.4]: "cross-attention is inserted above the 'Add & Norm' layer in the S4 block, followed by another 'Add & Norm' layer, similar to the Transformer architecture"
  - [corpus]: Weak - corpus neighbors discuss attention mechanisms but not specifically in the context of S4's limitations
- Break condition: When the attention mechanism itself becomes a bottleneck due to its quadratic complexity with sequence length

### Mechanism 3
- Claim: S4 is better suited for modeling self-dependencies within sequences than cross-dependencies between source and target sequences.
- Mechanism: S4's internal state space effectively captures temporal dependencies within a single sequence (as demonstrated in language modeling), but struggles with cross-sequence dependencies required for translation where source and target tokens need to be aligned.
- Core assumption: The mathematical formulation of S4 that works well for self-dependencies will also work for cross-dependencies
- Evidence anchors:
  - [abstract]: "we provide evidence that S4 learns self-dependencies, i.e. dependencies between the tokens of a single sequence, but struggles to capture cross-dependencies, i.e. dependencies between the tokens of two sequences"
  - [section 4.4]: "we use a method from He et al. (2019)... measure the relative change in the decoder's final layer activation caused by this intervention using L2 distance"
  - [corpus]: Weak - corpus neighbors discuss sequence modeling but don't specifically address the distinction between self and cross-dependencies
- Break condition: When the task requires extensive cross-sequence alignment, making the self-dependency modeling capability insufficient

## Architecture Onboarding

- Component map: Input → HiPPO kernel processing → MLP mixing → (optional cross-attention) → residual connection → normalization → next layer
- Critical path: Input features flow through HiPPO kernel computation, get mixed via MLP, optionally pass through cross-attention, then apply residual connections and normalization before proceeding to the next layer
- Design tradeoffs:
  - Single state vs. token-level representations: S4's compression efficiency vs. attention's retrieval capability
  - Computational efficiency: S4's linear complexity vs. attention's quadratic complexity
  - Model capacity: Number of S4 blocks per layer vs. number of layers
- Failure signatures:
  - Poor performance on long sentences with decoder-only S4
  - Blurry attention heatmaps showing inability to focus on specific source tokens
  - Significant BLEU score gap compared to Transformer baselines
- First 3 experiments:
  1. Compare decoder-only S4 (0-6 layers) vs Transformer base (6-6 layers) on WMT'14 EN→DE validation set
  2. Test S4 with varying numbers of blocks per layer (B=1,2,3,4,6,10) while keeping total parameters constant
  3. Implement attention-enhanced S4 (S4-S4A) and compare performance against Transformer on different sentence length buckets

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of S4 on machine translation change with varying state dimensions (e.g., larger than 64) while keeping the hidden size constant?
- Basis in paper: [inferred] The paper mentions that increasing the state dimension beyond 64 did not noticeably affect translation quality, but this was only tested up to a certain point.
- Why unresolved: The paper only tested state dimensions up to a certain size and found no significant improvement. It's unclear if larger state dimensions could potentially improve performance, especially for very long sentences.
- What evidence would resolve it: Experimenting with state dimensions significantly larger than 64 (e.g., 128, 256) while keeping the hidden size constant and comparing the results with the baseline S4 model.

### Open Question 2
- Question: How does the performance of S4 on machine translation change when using a bidirectional encoder with a decoder-only model (as opposed to just an encoder-decoder model)?
- Basis in paper: [inferred] The paper mentions that a bidirectional S4 encoder (S4BI) can narrow the performance gap to the Transformer, but it doesn't explore the possibility of using a bidirectional S4 encoder with a decoder-only model.
- Why unresolved: The paper only explores the use of a bidirectional S4 encoder with an encoder-decoder model. It's unclear if a bidirectional S4 encoder could also improve the performance of a decoder-only model.
- What evidence would resolve it: Implementing a decoder-only model with a bidirectional S4 encoder and comparing its performance with the baseline decoder-only model.

### Open Question 3
- Question: How does the performance of S4 on machine translation change when using different attention mechanisms (e.g., sparse attention, local attention) instead of the standard multi-head attention?
- Basis in paper: [inferred] The paper only explores the use of standard multi-head attention with S4. It's unclear if other attention mechanisms could potentially improve performance or reduce computational complexity.
- Why unresolved: The paper only tests one type of attention mechanism with S4. It's possible that other attention mechanisms could be more effective or efficient for machine translation tasks.
- What evidence would resolve it: Implementing S4 with different attention mechanisms (e.g., sparse attention, local attention) and comparing their performance with the baseline S4 model.

## Limitations

- The experimental design conflates multiple architectural changes, making it difficult to isolate the specific contribution of single-state compression to MT performance gaps
- Limited corpus evidence directly supports the proposed mechanisms about self-vs-cross dependencies and compression limitations
- Results may not generalize beyond standard MT datasets to other sequence-to-sequence tasks or domains

## Confidence

**High Confidence**: The empirical observation that S4 performs worse than Transformers on MT tasks, particularly for long sentences. The experimental results showing BLEU score differences between decoder-only S4 and Transformer baselines are clearly demonstrated and reproducible.

**Medium Confidence**: The hypothesis that S4's single-state compression is the primary limitation for MT. While the evidence shows performance degradation with sequence length and improvement with attention, the experimental design doesn't definitively prove this is the root cause versus other architectural differences.

**Low Confidence**: The claim that S4 learns self-dependencies but struggles with cross-dependencies. The intervention-based analysis provides some support, but the methodology has limitations in conclusively demonstrating this distinction, and the corpus lacks corroborating evidence.

## Next Checks

1. **Ablation study on compression mechanisms**: Create controlled experiments that isolate the single-state compression effect by implementing S4 variants with different state sizes and compression strategies, while keeping all other architectural components constant. This would help determine if state size alone explains the performance gap.

2. **Cross-domain dependency analysis**: Apply the same S4 architectures and attention mechanisms to non-MT sequence-to-sequence tasks (e.g., summarization, question answering) to test whether the self-vs-cross dependency distinction holds across different task types and data distributions.

3. **Attention mechanism efficiency evaluation**: Conduct a detailed analysis of the computational and memory overhead introduced by attention in S4 models, including runtime comparisons and memory usage profiling, to quantify the practical tradeoff between performance gains and efficiency costs.
