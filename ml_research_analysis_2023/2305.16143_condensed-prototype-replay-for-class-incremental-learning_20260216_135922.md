# Condensed Prototype Replay for Class Incremental Learning

## Quick Facts
- arXiv ID: 2305.16143
- Source URL: https://arxiv.org/abs/2305.16143
- Reference count: 40
- Key outcome: YONO learns one condensed prototype per class via attentional mean-shift, outperforming non-exemplar methods and matching exemplar-based approaches on CIFAR-100 and TinyImageNet.

## Executive Summary
This paper introduces YONO, a novel non-exemplar-based method for class-incremental learning that learns a single condensed prototype per class by moving samples to high-density regions using an attentional mean-shift algorithm. The approach maximizes class margins and reduces interference, mitigating catastrophic forgetting. YONO+ extends this by generating synthetic data from prototypes via random sampling in representation space, further improving performance. Extensive experiments demonstrate YONO/YONO+ outperform existing non-exemplar methods and even some exemplar-based approaches in terms of accuracy and forgetting.

## Method Summary
YONO addresses catastrophic forgetting in class-incremental learning by learning a condensed prototype for each class through an attentional mean-shift algorithm. This algorithm dynamically aggregates sample representations around each class prototype by computing learnable attention weights based on cosine similarity. The prototype is updated to move toward high-density regions, ensuring it better represents the class's central tendency. During training, only these condensed prototypes are replayed, eliminating the need for storing real samples. YONO+ extends this by generating synthetic data from prototypes via rotation and truncated Gaussian sampling, creating new points that preserve angular similarity to the prototype and expand class coverage without storage overhead.

## Key Results
- YONO achieves comparable results to YONO+ without synthetic data
- YONO/YONO+ outperform existing non-exemplar methods on CIFAR-100 and TinyImageNet
- YONO even outperforms some exemplar-based approaches in terms of accuracy and forgetting

## Why This Works (Mechanism)

### Mechanism 1
Moving class prototypes to high-density regions via attentional mean-shift reduces inter-class interference and mitigates forgetting. The attentional mean-shift algorithm dynamically aggregates sample representations around each class prototype by computing learnable attention weights based on cosine similarity between samples and the prototype. This moves the prototype toward regions of higher sample density, ensuring it better represents the class's central tendency. If the attention mechanism fails to capture meaningful similarity relationships or the representation space is too noisy for density estimation to be reliable, the mean-shift will converge to poor prototypes and class margins will not be maximized.

### Mechanism 2
Replaying only one condensed prototype per class is sufficient to retain class-specific information and mitigate catastrophic forgetting without synthetic data. By learning a compact, high-density prototype per class and enforcing samples to cluster tightly around it using Arcface loss, YONO ensures that each class forms a distinct, separable cluster. Replaying these prototypes during new task training provides a stable reference for the classifier, preventing drift away from previous class boundaries. If the class distribution is highly multimodal or elongated in representation space, a single prototype cannot capture the full structure, leading to poor generalization and increased forgetting.

### Mechanism 3
Generating synthetic data from prototypes via rotation and truncated Gaussian sampling improves YONO by covering the local neighborhood of each class without requiring storage of real samples. For each learned prototype, YONO+ synthesizes new points by rotating a truncated Gaussian-distributed vector around the prototype. This creates synthetic samples that preserve angular similarity to the prototype, effectively expanding the coverage of the class distribution while maintaining separation from other classes. If the prototype is poorly positioned or the class distribution is highly irregular, synthetic points may fall outside the true data manifold or overlap with neighboring classes, causing interference.

## Architecture Onboarding

- **Component map:** Feature extractor → Prototype memory bank → Attentional mean-shift module → Classifier → Synthetic data generator (YONO+) → Knowledge distillation
- **Critical path:** Feature extractor → prototype learning (mean-shift + Arcface) → classifier training (with replay) → model interpolation → store prototypes
- **Design tradeoffs:**
  - Memory vs. accuracy: YONO stores only one prototype per class vs. exemplar-based methods that store multiple samples
  - Simplicity vs. coverage: YONO uses one prototype, YONO+ adds synthetic data for better coverage at the cost of extra computation
  - Prototype quality vs. update speed: Mean-shift step size λ trades off between fast convergence and stable prototype positioning
- **Failure signatures:**
  - Rapidly degrading accuracy on early tasks → prototypes not well-positioned or classifier overfitting to new task
  - Synthetic data causing interference → prototypes too close to other classes or synthetic generation not preserving local geometry
  - High variance in results → unstable mean-shift or poor attention mechanism

## Limitations
- The attentional mean-shift algorithm's exact implementation details are underspecified, particularly the mini-batch version and how rotation matrices are computed for synthetic data generation
- The method's performance assumes well-separated class distributions in representation space, which may not hold for real-world datasets with overlapping classes or multimodal distributions
- The synthetic data generation strategy could fail if prototypes are poorly positioned or class boundaries are complex

## Confidence
- **High confidence**: YONO's core mechanism of learning condensed prototypes via mean-shift and using them for replay is technically sound and well-motivated by the catastrophic forgetting problem
- **Medium confidence**: The synthetic data generation in YONO+ improves performance as claimed, but the specific implementation details and hyperparameters significantly affect results
- **Low confidence**: The claim that YONO can outperform exemplar-based methods is compelling but depends heavily on the quality of the learned prototypes and may not generalize to all datasets
