# SemEval-2023 Task 2: Fine-grained Multilingual Named Entity Recognition (MultiCoNER 2)

## Quick Facts
- arXiv ID: 2305.06586
- Source URL: https://arxiv.org/abs/2305.06586
- Reference count: 40
- 842 submissions from 47 teams on fine-grained multilingual NER with 12 languages

## Executive Summary
The MultiCoNER 2 task focused on fine-grained multilingual named entity recognition across 12 languages, featuring 2.2 million instances with complex entity types and noisy data. The task attracted 842 submissions from 47 teams, with top-performing systems leveraging external knowledge sources like Wikipedia and Wikidata combined with transformer models and ensemble strategies. Fine-grained classes such as SCIENTIST, ARTWORK, and PRIVATECORP proved particularly challenging, and noisy data led to an average 10% performance drop across systems.

## Method Summary
The task employed transformer-based models, primarily XLM-RoBERTa, for multilingual NER with 33 fine-grained entity types. Top systems integrated external knowledge through retrieval-augmented approaches, fetching relevant Wikipedia or Wikidata content for entity disambiguation. Ensemble strategies combined multiple models to improve robustness. The evaluation used macro-averaged F1 scores with exact matching requirements for entity boundaries and types.

## Key Results
- MultiCoNER V2 dataset contains 2.2 million instances across 12 languages
- Top systems achieved 75.3 F1 using knowledge integration and ensemble approaches
- Noisy data caused an average 10% performance drop across all systems
- Fine-grained classes like SCIENTIST, ARTWORK, and PRIVATECORP remained challenging despite external knowledge integration

  - Performance drop on noisy subsets reveals insufficient robustness to input variations
