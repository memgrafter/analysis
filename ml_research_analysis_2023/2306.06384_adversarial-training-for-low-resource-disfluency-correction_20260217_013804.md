# Adversarial Training For Low-Resource Disfluency Correction

## Quick Facts
- arXiv ID: 2306.06384
- Source URL: https://arxiv.org/abs/2306.06384
- Reference count: 11
- Primary result: Seq-GAN-BERT achieves 6.15 F1 points improvement over baselines in Bengali, Hindi, and Marathi DC

## Executive Summary
This paper addresses disfluency correction (DC) in low-resource languages using an adversarially-trained sequence-tagging model. The proposed Seq-GAN-BERT leverages a small amount of labeled real disfluent data, large unlabeled data, and synthetic disfluent data to improve performance. The model achieves significant improvements in F1-scores across three Indian languages (Bengali, Hindi, Marathi) and establishes a new benchmark for English stuttering DC.

## Method Summary
The Seq-GAN-BERT model uses adversarial training with a BERT-based encoder, discriminator, and generator. It employs a rule-based approach to generate synthetic disfluent sentences by injecting disfluent elements into fluent sentences. The model is trained using real disfluent data, synthetic data, and unlabeled data from related languages to improve cross-lingual transfer. Performance is evaluated using F1-score for DC across multiple languages.

## Key Results
- Average 6.15 F1 points improvement over competitive baselines across Bengali, Hindi, and Marathi
- Achieves 83.74, 88.14, and 75.43 F1 scores for Bengali, Hindi, and Marathi respectively
- Establishes new benchmark with 87.68 F1 score for English stuttering DC

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Adversarial training forces the BERT encoder to generate higher quality representations for disfluency detection.
- Mechanism: The generator produces fake representations from noise that mimic the real data, while the discriminator learns to distinguish real from fake and classify tokens as disfluent/fluent. The competition between generator and discriminator compels the encoder to produce better representations.
- Core assumption: The generator can create synthetic representations that challenge the discriminator enough to improve the encoder's feature extraction.
- Evidence anchors:
  - [abstract] "The model employs synthetic disfluent data to improve performance."
  - [section 4.1] "The generator continuously improves during training and produces fake representations that resemble actual data."

### Mechanism 2
- Claim: Multilingual training improves performance by exposing the model to disfluency patterns across languages.
- Mechanism: The model uses disfluent sentences from one language as unlabeled data when training on another language, allowing cross-lingual transfer of disfluency detection patterns.
- Core assumption: Disfluency patterns share similarities across related languages, allowing knowledge transfer.
- Evidence anchors:
  - [section 5.2] "Our experiments show that the best model for Bengali uses real and synthetic Bengali sentences as labeled data and disfluent Hindi sentences as unlabeled data."
  - [section 6.2] "Our model performs best when we use synthetic Bengali disfluent sentences as unlabeled data."

### Mechanism 3
- Claim: Synthetic data augmentation helps overcome the data scarcity problem in low-resource languages.
- Mechanism: The rule-based system generates synthetic disfluent sentences by injecting disfluent elements into fluent sentences, expanding the training data.
- Core assumption: The synthetic disfluencies are realistic enough to improve model generalization.
- Evidence anchors:
  - [abstract] "The model employs synthetic disfluent data to improve performance."
  - [section 5.1] "We use 300, 150 and 250 real disfluent sentences in Bengali, Hindi and Marathi, respectively and generate 1000 synthetic disfluent sentences in Bengali and 500 synthetic disfluent sentences each in Hindi and Marathi each by infusing disfluent elements in fluent transcriptions using a rule-based approach."

## Architecture Onboarding

- Component map: MuRIL encoder -> Generator (noise to representations) -> Discriminator (token classification and real/fake discrimination)
- Critical path: 1. Encode input sequences with MuRIL 2. Generate fake representations with generator 3. Discriminator classifies tokens and identifies real/fake data 4. Backpropagate losses to update all components
- Design tradeoffs:
  - Using unlabeled data improves performance but increases training complexity
  - Synthetic data helps with data scarcity but may introduce noise if not realistic
  - Multilingual training leverages cross-lingual patterns but may introduce interference
- Failure signatures:
  - Generator produces poor quality synthetic data → discriminator doesn't improve → encoder representations don't improve
  - Synthetic data doesn't match real disfluencies → model learns incorrect patterns
  - Multilingual transfer fails → using data from other languages hurts performance
- First 3 experiments:
  1. Train baseline model without adversarial training or synthetic data
  2. Add synthetic data generation and training
  3. Add adversarial training with unlabeled data from related languages

## Limitations
- Reliance on rule-based synthetic data generation may not capture full complexity of real disfluencies
- Performance improvements should be interpreted cautiously given small test sets for Indian languages
- Generalizability to languages beyond tested Indian languages and English remains unproven

## Confidence
- High Confidence: Core methodology of using adversarial training with synthetic data for disfluency correction
- Medium Confidence: Specific F1-score improvements and their attribution to individual components
- Low Confidence: Generalizability to other languages and disfluency types not represented in synthetic data
