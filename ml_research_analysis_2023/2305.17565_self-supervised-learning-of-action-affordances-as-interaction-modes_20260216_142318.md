# Self-Supervised Learning of Action Affordances as Interaction Modes

## Quick Facts
- arXiv ID: 2305.17565
- Source URL: https://arxiv.org/abs/2305.17565
- Reference count: 40
- One-line primary result: ActAIM learns interaction modes for articulated objects from visual data alone, outperforming baselines on both mode discovery and goal-conditional manipulation.

## Executive Summary
ActAIM introduces a self-supervised approach for discovering interaction modes of articulated objects using only visual data. The method learns useful interaction priors without requiring object state labels or privileged information. By combining a generative model with a mode selector and point-wise action predictor, augmented with implicit neural geometry encoding, ActAIM can generalize across object categories. A novel adaptive data collection strategy using GMM clustering ensures balanced coverage of interaction modes, enabling effective goal-conditional manipulation.

## Method Summary
ActAIM uses a generative model that learns interaction modes through visual change vectors and GMM clustering. The system collects interaction data, computes visual change vectors as differences in autoencoder embeddings, and clusters these using GMMs to identify distinct interaction modes. A CVAE-based mode selector maps visual observations to latent interaction modes, while an implicit neural geometry encoder provides local geometric features to improve generalization. The method employs adaptive data collection, sampling more from underrepresented clusters to ensure balanced mode coverage. During inference, the model proposes interaction points and actions based on the predicted interaction mode and local geometry.

## Key Results
- ActAIM outperforms baselines like Where2Act on interaction mode discovery metrics including sample success rate and weighted modes ratio
- The method achieves higher sample success rates on goal-conditional manipulation tasks across unseen object instances
- Adaptive data collection strategy yields more diverse mode coverage compared to random policies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ActAIM learns interaction modes by clustering actions that produce similar visual state changes, without requiring object state labels.
- Mechanism: The model uses an autoencoder to embed depth images, computes the difference between before/after embeddings as a "change vector," and clusters these change vectors using GMMs to identify interaction modes.
- Core assumption: Visual change vectors can distinguish different interaction modes, and GMM clustering can separate these modes effectively.
- Evidence anchors:
  - [abstract] "we define a successful interaction as the one changing the visual environment substantially"
  - [section] "We define the effect of an executed action as, ˜τ = ED(D1) − ED(D0). At the start, we collect interaction data... We fit GMM only on data that leads to a change in the embedded space: {(D0, a, D1), |||˜τ ||2≥ λ}"
  - [corpus] Weak evidence - corpus papers focus on explicit state models or different clustering approaches, but don't directly validate the GMM-on-change-vectors approach

### Mechanism 2
- Claim: Implicit neural geometry encoding improves generalization across object categories by providing local geometric features.
- Mechanism: The ConvOnet-based implicit representation encodes local geometry features (vp) at interaction points, which are concatenated with interaction mode latents to predict actions.
- Core assumption: Local geometric features provide category-invariant information that helps the action predictor generalize across different object instances and categories.
- Evidence anchors:
  - [section] "We use an implicit neural geometry encoder that encodes local geometry features to improve the generalizability of the model over different categories of articulated objects"
  - [section] "vp = Θ(V, p) where V is the TSDF of the object and p is a queried point"
  - [corpus] Moderate evidence - [36] shows ConvOnet implicit representations work for grasping, but this is the first application to articulated object interaction modes

### Mechanism 3
- Claim: The adaptive data collection strategy using GMM clustering increases mode diversity and balances coverage across rare interaction modes.
- Mechanism: After initial random exploration, the system fits GMMs to cluster successful interactions, then samples more from underrepresented clusters in subsequent iterations.
- Core assumption: GMM clustering can identify distinct interaction modes, and oversampling rare modes will lead to more balanced coverage in the final dataset.
- Evidence anchors:
  - [section] "We sample ϵM interactions with a random policy and (1 − ϵ)M interactions from the GMM, and fit a GMM again over the collected data"
  - [section] "As shown in Fig.2, clustering using GMM discriminates among different interaction modes and this adaptive sampling strategy yields a more balanced coverage of interaction modes compared to a random policy"
  - [corpus] Weak evidence - while GMMs are common for clustering, the specific adaptive sampling loop for interaction mode discovery is novel and not validated in the corpus

## Foundational Learning

- Concept: Conditional Variational Autoencoders (CVAEs)
  - Why needed here: The mode selector P(z|o) needs to map visual observations to latent interaction modes in a probabilistic manner that can be sampled during inference
  - Quick check question: What's the difference between a standard VAE and a CVAE, and why is the conditional aspect important for mode selection?

- Concept: Implicit Neural Representations (INR)
  - Why needed here: The geometry encoder needs to provide continuous, local geometric features that generalize across different object instances without requiring explicit mesh or state information
  - Quick check question: How does ConvOnet's implicit representation differ from traditional voxel-based geometry encoding, and what advantages does this provide for generalization?

- Concept: Gaussian Mixture Models for Clustering
  - Why needed here: GMMs are used to cluster interaction data into distinct modes based on visual change vectors, enabling the adaptive data collection strategy
  - Quick check question: Why might GMMs be preferred over k-means for clustering interaction modes, and what assumptions does this make about the distribution of interaction modes?

## Architecture Onboarding

- Component map: Depth images → Autoencoder embedding → GMM clustering → CVAE mode selector → Implicit geometry encoder → Point scoring → Action prediction
- Critical path: During inference, the critical path is: depth image → CVAE mode selector → geometry encoder → point scoring → action prediction
- Design tradeoffs: The method trades explicit state knowledge for visual-only learning, which improves generalization but may reduce precision. The GMM clustering provides mode diversity but adds computational overhead. The implicit geometry encoding improves generalization but requires TSDF computation.
- Failure signatures: Common failure modes include: (1) Poor mode separation leading to blurry action proposals, (2) Geometry encoding failures on complex shapes, (3) GMM overfitting to training objects, (4) Point scoring producing false positives on non-interactive regions
- First 3 experiments:
  1. Test the autoencoder reconstruction quality on held-out depth images to ensure the embedding captures relevant visual information
  2. Verify GMM clustering produces distinct modes on a simple dataset with known ground truth
  3. Evaluate point scoring on synthetic data where ground truth interaction points are known

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does ActAIM's interaction mode discovery performance scale with increasing numbers of articulated object categories and instances?
- Basis in paper: [inferred] The paper mentions that ActAIM generalizes across different object categories and instances, but does not explore how performance scales with the number of categories or instances.
- Why unresolved: The paper only evaluates on a fixed set of 9 training categories and 3 test categories, without systematically varying the number of categories or instances.
- What evidence would resolve it: Experiments varying the number of object categories and instances in training, measuring performance metrics like sample success rate and weighted modes ratio as the diversity of training data increases.

### Open Question 2
- Question: Can ActAIM's learned interaction priors transfer to real-world articulated objects with different material properties or environmental conditions?
- Basis in paper: [inferred] The paper evaluates ActAIM in a simulated environment but does not test transfer to real-world settings or objects with different physical properties.
- Why unresolved: The evaluation is limited to simulated objects, and real-world factors like friction, material compliance, or sensor noise are not considered.
- What evidence would resolve it: Experiments applying ActAIM to real articulated objects (e.g., doors, drawers) with varying materials and environmental conditions, measuring success rates and mode coverage compared to simulation.

### Open Question 3
- Question: How sensitive is ActAIM's adaptive data collection strategy to the choice of hyperparameters like the GMM threshold λ or the random sampling ratio ϵ?
- Basis in paper: [explicit] The paper describes the adaptive data collection using GMM clustering but does not perform sensitivity analysis on hyperparameters.
- Why unresolved: The paper does not report how performance changes with different hyperparameter settings or provide guidance on tuning them.
- What evidence would resolve it: Experiments varying λ and ϵ systematically, showing how sample success rate, mode coverage, and training efficiency change with different values.

## Limitations

- The method's performance in real-world scenarios with sensor noise and varying environmental conditions is untested
- The exact hyperparameter values for GMM clustering and architectural choices are not specified, affecting reproducibility
- Evaluation is limited to simulated environments, with unknown transfer to physical articulated objects

## Confidence

**High Confidence**: The core mechanism of using visual change vectors and GMM clustering to discover interaction modes is well-supported by the paper's theoretical framework and basic implementation details. The claim that ActAIM outperforms baselines like Where2Act on interaction mode discovery metrics is supported by presented quantitative results.

**Medium Confidence**: The effectiveness of the implicit neural geometry encoding for improving generalization across object categories is demonstrated, but the specific contribution of this component versus the overall architecture is not fully isolated. The adaptive data collection strategy's ability to improve mode coverage is supported by qualitative visualizations but lacks rigorous ablation studies.

**Low Confidence**: The claim of true zero-shot generalization to unseen object categories is not fully validated, as the evaluation only tests on held-out instances within known categories. The computational efficiency of the method for real-time interaction is not discussed or benchmarked.

## Next Checks

1. **Ablation Study**: Run controlled experiments to isolate the contribution of each key component (implicit geometry encoding, GMM-based data collection, CVAE mode selector) by removing them individually and measuring the impact on sample success rate and mode coverage metrics.

2. **Real-World Transfer**: Implement the method on a physical robot interacting with a small set of articulated objects (e.g., doors, drawers) to validate that the visual-only learning approach transfers from simulation to reality, measuring success rates and failure modes.

3. **Category Generalization Stress Test**: Create a more challenging generalization test by evaluating on entirely new object categories (e.g., robotic arms, windows, appliances) not seen during training, and measure whether the method can discover and execute meaningful interaction modes without any category-specific fine-tuning.
