# Self-Supervised Pretraining on Paired Sequences of fMRI Data for Transfer Learning to Brain Decoding Tasks

## Quick Facts
- arXiv ID: 2305.09057
- Source URL: https://arxiv.org/abs/2305.09057
- Authors: 
- Reference count: 40
- Primary result: Multitask self-supervised pretraining on fMRI data achieves up to 98.25% validation accuracy on auditory brain decoding tasks

## Executive Summary
This work presents a novel self-supervised pretraining framework for transformers on fMRI data using two tasks: Next Thought Prediction and Masked Brain Modeling. The framework demonstrates that training on both tasks simultaneously provides synergistic benefits compared to single-task training. The pretraining results are successfully transferred to a supervised auditory brain decoding task, significantly improving accuracy on held-out runs and establishing a proof of concept for multitask pretraining on fMRI data.

## Method Summary
The method involves pretraining a transformer architecture on fMRI sequences using two self-supervised tasks: Next Thought Prediction (predicting whether one fMRI sequence follows another) and Masked Brain Modeling (reconstructing masked portions of fMRI sequences). The model uses a paired-sequence transformer without an embedding layer, processing sequences of 5 consecutive fMRI images from the left superior temporal gyrus region. After pretraining, the models are fine-tuned on a Same Genre classification task. The approach uses 10-fold cross-validation and compares multitask pretraining against single-task pretraining and fresh models.

## Key Results
- Multitask pretraining achieves 92-94.875% validation accuracy on pretraining tasks, outperforming single-task training
- Transfer learning improves supervised Same Genre classification accuracy up to 98.25%, significantly better than fresh models
- First demonstration of synergistic benefits from multitask training on fMRI data

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pretraining on NTP and MBM simultaneously creates synergistic benefits
- Mechanism: The tasks capture complementary temporal and spatial aspects of fMRI data
- Core assumption: Temporal and spatial aspects are sufficiently independent for additive learning
- Evidence: Multitask models achieved 92-94.875% accuracy vs 90.75% for NTP-only
- Break condition: Task interference or insufficient model capacity

### Mechanism 2
- Claim: Transformer can learn directly from fMRI voxel values without embedding layer
- Mechanism: MNI space mapping provides meaningful distributed representation
- Core assumption: MNI mapping constitutes sufficient semantic embedding
- Evidence: Successful training validates token implementation without embeddings
- Break condition: MNI mapping insufficient for semantic information

### Mechanism 3
- Claim: Self-supervised pretraining transfers effectively to supervised auditory decoding
- Mechanism: Pretraining teaches general patterns of auditory cortex activity
- Core assumption: Pretraining patterns are relevant and transferable
- Evidence: Pretrained models achieved up to 98.25% accuracy vs fresh models
- Break condition: Pretraining data/tasks too dissimilar from target task

## Architecture Onboarding

- Component map: fMRI sequences -> paired-sequence transformer (with CLS, SEP, MSK tokens) -> Output Block 1 (NTP classification) + Output Block 2 (MBM regression) + Output Block 3 (supervised task)
- Critical path: CLS token flows through transformer layers to Output Block 3 for supervised finetuning
- Design tradeoffs: Omitting embedding layer saves parameters but relies on MNI space quality; paired-sequence structure increases training diversity but may limit generalization
- Failure signatures: Poor pretraining performance suggests architecture/data issues; poor transfer suggests task mismatch
- First 3 experiments:
  1. Train NTP-only and evaluate on supervised task
  2. Train MBM-only and evaluate on supervised task
  3. Train both tasks simultaneously and evaluate for synergistic benefits

## Limitations

- Limited experimental validation with only 3 multitask runs showing small performance gaps
- Omitting embedding layer is theoretically justified but not empirically compared to embedding-based models
- Transfer learning tested on relatively simple binary classification task, uncertain generalization to more complex decoding tasks

## Confidence

- Multitask pretraining synergy: Medium - promising but limited validation
- Omitting embedding layer effectiveness: Medium - theoretical justification without empirical testing
- Transfer learning benefits: Medium - strong improvement but uncertain generalization
