# End-to-End Document Classification and Key Information Extraction using Assignment Optimization

## Quick Facts
- arXiv ID: 2306.00750
- Source URL: https://arxiv.org/abs/2306.00750
- Authors: 
- Reference count: 20
- Key outcome: Template-based document classification and assignment optimization achieve f1 scores of 0.97 for classification and 0.94 for KIE on noisy insurance claim forms

## Executive Summary
This paper presents an end-to-end system for document classification and key information extraction that leverages document templates and assignment optimization rather than deep learning training. The approach uses cosine similarity between vectorized text/layout representations for classification, followed by a mixed integer programming formulation to match entities to template value positions. The method achieves high accuracy on a dataset of noisy scanned insurance claim forms while being easily updatable for new document types without retraining.

## Method Summary
The system first classifies documents by computing cosine similarity between their vectorized representations (using USE or TF-IDF for text, LayoutLMv2 for layout) and template matrices. After selecting the appropriate template, documents undergo preprocessing including alignment via ORB feature matching and RANSAC, plus entity scaling to match template dimensions. Key information extraction is then performed using assignment optimization that formulates the problem as minimizing Euclidean distances between form entities and template value positions under assignment constraints, solved via mixed integer programming.

## Key Results
- Document classification achieves f1 score of 0.97 on 6-class insurance claim form dataset
- Key information extraction achieves mean f1 score of 0.94 across all form types
- Ablation studies show document preprocessing (rotation alignment and entity scaling) is critical for optimal performance
- Method successfully handles noisy scanned documents with rotation and scaling variations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using accurate document classification to select the correct template enhances KIE performance.
- Mechanism: The system first classifies a scanned form by computing cosine similarity between its vectorized text/layout representation and a set of document templates. This classification step ensures the correct template is chosen for the subsequent KIE task.
- Core assumption: Templates encode the expected structure and key-value positions for each form type, so using the right template is critical for accurate KIE.
- Evidence anchors:
  - [abstract] "Through accurate document classification we harness known information from templates to enhance KIE from forms."
  - [section] "Document classification is followed by KIE, where templates are constructed for each of the six document classes in our dataset."
- Break condition: If the classification is wrong, the wrong template will be used, leading to poor KIE performance.

### Mechanism 2
- Claim: Assignment optimization effectively matches entities in a new form to template value positions.
- Mechanism: The system formulates KIE as a binary optimization problem, minimizing the global distance between form entities and template value positions subject to assignment constraints. This allows entities to be assigned to the most appropriate template key based on geometric proximity.
- Core assumption: The relative positions of entities in a form correspond to the positions of value fields in the template for that form type.
- Evidence anchors:
  - [abstract] "We then demonstrate a novel application of mixed integer programming by using assignment optimization to extract key information from documents."
  - [section] "The optimization objective is to minimise the distance between entities in a new form and spaces in a form template where values are entered."
- Break condition: If entities are not positioned consistently with the template, the optimization may make incorrect assignments.

### Mechanism 3
- Claim: Document preprocessing (alignment and scaling) is essential for optimal KIE performance.
- Mechanism: The system preprocesses scanned documents by aligning them with the template images using feature matching, and scales entities to approximate template positions. This compensates for rotation and scaling differences between scans and templates.
- Core assumption: Scanned documents can have significant rotation and scaling differences compared to templates, which need to be corrected for accurate KIE.
- Evidence anchors:
  - [abstract] "Ablation results show that the method relies on document preprocessing techniques to mitigate Type II errors and achieve optimal performance."
  - [section] "To mitigate the effects of rotation variance, we implement document image alignment to rotate scanned documents to align with their corresponding template images."
- Break condition: If preprocessing is not done, the optimization will struggle with the geometric differences and make more errors.

## Architecture Onboarding

- Component map: Document classification → Template selection → Document preprocessing (alignment, scaling) → Assignment optimization → KIE output
- Critical path: Document classification must succeed before KIE can proceed, as the template selected by classification is used for KIE.
- Design tradeoffs: Using templates for KIE provides high accuracy for known form types but requires templates to be created and maintained. Template-free approaches are more flexible but may be less accurate.
- Failure signatures: Poor KIE performance could indicate issues with classification, preprocessing, or the optimization itself. Investigating each stage can help pinpoint the issue.
- First 3 experiments:
  1. Test classification accuracy on a held-out set of forms to ensure the correct templates are being selected.
  2. Visualize the alignment and scaling of preprocessed forms to templates to verify the preprocessing is working as expected.
  3. Run the optimization on a small set of forms with known answers to check if entities are being assigned correctly.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would incorporating semantic information (e.g., text embeddings) alongside positional information affect the accuracy and generalizability of the assignment optimization approach for key information extraction?
- Basis in paper: [explicit] The authors mention in Section 7 that "there is scope within this approach to add semantic information to the assignment of values to keys" and cite work like LAMBERT that uses word tokens alongside bounding boxes.
- Why unresolved: The current implementation relies solely on positional information. The paper acknowledges the potential benefit of incorporating semantic information but does not experimentally investigate this extension.
- What evidence would resolve it: Empirical comparison of KIE performance with and without semantic information, testing on diverse document types and layouts.

### Open Question 2
- Question: How robust is the method to handling documents with significantly different visual styles or layouts than the training templates, and what preprocessing or adaptation techniques could improve performance in such cases?
- Basis in paper: [inferred] The authors mention the method's limitations with densely-populated forms and documents with different visual styles in Section 6. They also note the importance of preprocessing steps like document alignment and entity scaling for optimal performance.
- Why unresolved: The current evaluation is limited to a specific dataset of insurance claim forms. The generalizability of the method to other document types and layouts is not fully explored.
- What evidence would resolve it: Experiments testing the method on diverse document datasets with varying layouts and visual styles, investigating the impact of different preprocessing and adaptation techniques.

### Open Question 3
- Question: How does the performance of the assignment optimization approach compare to deep learning-based methods for KIE, particularly in terms of accuracy, computational efficiency, and scalability to large datasets?
- Basis in paper: [explicit] The authors compare their method's F1 score to other KIE techniques like LayoutLM and LAMBERT in Section 5, but acknowledge that their approach is slightly inferior. They highlight the benefits of their approach being easily updated and not requiring large training data.
- Why unresolved: The paper does not provide a comprehensive comparison of the assignment optimization approach with deep learning methods in terms of computational efficiency and scalability.
- What evidence would resolve it: Systematic benchmarking of the assignment optimization approach against deep learning methods on various datasets, measuring accuracy, training/inference time, and resource requirements.

## Limitations

- The approach relies heavily on manually created and maintained document templates, limiting scalability to new form types
- System assumes consistent entity positioning across forms of the same type, which may not hold for real-world data with high variance
- Performance evaluation is limited to a single dataset of insurance claim forms, making generalizability to other domains uncertain

## Confidence

- **High confidence**: The template-based approach for KIE is well-established and the use of assignment optimization to match entities to template positions is a valid technique. The reported performance metrics (f1 scores of 0.97 for classification and 0.94 for KIE) are likely accurate for the evaluated dataset.
- **Medium confidence**: The effectiveness of the document preprocessing steps (alignment and scaling) is supported by the ablation study, but the specific implementation details and hyperparameters are not fully specified. The generalizability of the approach to other form types and domains is uncertain based on the single dataset evaluation.
- **Low confidence**: The impact of OCR quality on the overall system performance is not thoroughly analyzed. The paper does not discuss how errors in OCR (e.g., from Amazon Textract) propagate through the entity consolidation and classification steps. The robustness of the approach to significant layout variations within form types is also unclear.

## Next Checks

1. **Evaluate classification error impact**: Analyze the performance of the system on a held-out test set with known classification errors. Measure the drop in KIE f1 score when the wrong template is used due to misclassification. This will quantify the sensitivity of the system to classification errors.

2. **Test on forms with layout variations**: Create a set of forms for each type with significant layout variations (e.g., different field positions, font sizes). Run the system on these forms and measure the KIE performance. Compare to the performance on the original dataset to assess the robustness to layout variations.

3. **Analyze OCR error propagation**: Introduce controlled OCR errors into the test set (e.g., randomly changing characters, removing words). Measure the impact of these errors on entity consolidation, classification, and KIE performance. This will help identify the stages most sensitive to OCR quality and guide potential improvements.
