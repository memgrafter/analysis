# Proximity Forest 2.0: A new effective and scalable similarity-based classifier for time series
## Quick Facts
- arXiv ID: 2304.05800
- Source URL: https://arxiv.org/abs/2304.05800
- Reference count: 40
- PF 2.0 improves on original Proximity Forest with ADTW measure and pruning for better scalability

## Executive Summary
Proximity Forest 2.0 (PF 2.0) is an improved similarity-based time series classifier that addresses computational bottlenecks of the original Proximity Forest while maintaining or improving classification accuracy. The new version introduces three key advances: efficient early abandoning and pruning techniques for elastic similarity measures, a novel similarity measure called Amerced Dynamic Time Warping (ADTW), and systematic cost function tuning. PF 2.0 reduces the number of similarity measures from eight to three core measures while incorporating first derivative transforms. The implementation in C++ demonstrates significant computational efficiency gains while achieving competitive or superior accuracy on the UCR benchmark compared to state-of-the-art kernel, neural network, and hybrid methods.

## Method Summary
PF 2.0 is a tree-based ensemble classifier that leverages similarity measures to classify time series data. The classifier constructs multiple trees where each node uses a randomly selected similarity measure to partition the training data. Key innovations include the introduction of ADTW (Amerced Dynamic Time Warping) as a new similarity measure that combines DTW with cost considerations, efficient early abandoning techniques that terminate distance computations when partial results exceed current best matches, and pruning strategies that reduce the search space. The system uses only three core similarity measures (ADTW, constrained DTW, and Longest Common Subsequence) compared to the original eight, with all measures applied to first derivative transforms of the time series. The ensemble approach aggregates predictions from multiple trees to produce final classifications.

## Key Results
- PF 2.0 outperforms the original Proximity Forest on UCR benchmark datasets with reduced error rates
- Computational efficiency improves significantly through early abandoning and pruning techniques
- Achieves lower error rates than state-of-the-art kernel, neural network, and hybrid methods on specific datasets
- Maintains competitive accuracy while using only three similarity measures instead of eight

## Why This Works (Mechanism)
PF 2.0 works by combining the proven ensemble approach of tree-based classifiers with optimized similarity computations. The early abandoning technique terminates distance calculations when partial results exceed the current best match, avoiding unnecessary computations. Pruning strategies eliminate entire subtrees when they cannot contain better solutions. The ADTW measure introduces cost-aware comparisons that better capture the similarity between time series patterns. By using first derivative transforms, the classifier captures rate-of-change information that is often more discriminative than absolute values. The ensemble approach averages predictions across multiple trees, reducing variance and improving generalization.

## Foundational Learning
**Dynamic Time Warping (DTW)** - Elastic similarity measure that aligns time series by warping the time axis to minimize distance. Needed because real-world time series often have temporal misalignments. Quick check: Can handle sequences of different lengths and local time distortions.

**Early Abandoning** - Optimization technique that stops distance computations when partial results exceed current best matches. Needed to reduce computational complexity of similarity searches. Quick check: Must correctly identify when further computation cannot improve current best solution.

**First Derivative Transform** - Converts time series values to their rate of change. Needed because shape and pattern changes often carry more discriminative information than absolute values. Quick check: Should preserve temporal relationships while emphasizing dynamic behavior.

## Architecture Onboarding
**Component Map**: Time Series -> Derivative Transform -> Similarity Measure (ADTW/DTW/LCS) -> Tree Node -> Ensemble Aggregation -> Classification

**Critical Path**: Input time series → First derivative transformation → Similarity measure computation with early abandoning → Tree node decision → Ensemble voting → Final classification

**Design Tradeoffs**: Reduced similarity measure set (3 vs 8) improves efficiency but may miss domain-specific patterns; derivative transforms add discriminative power but may lose absolute value information; early abandoning improves speed but requires careful threshold tuning.

**Failure Signatures**: Degraded performance on datasets where absolute values matter more than patterns; increased error rates when temporal alignment is perfect (DTW unnecessary); potential overfitting with too many trees or insufficient pruning.

**First Experiments**: 1) Compare classification accuracy with and without derivative transforms on a simple dataset; 2) Measure computational speedup from early abandoning on varying time series lengths; 3) Test ADTW performance against standard DTW on temporally misaligned sequences.
