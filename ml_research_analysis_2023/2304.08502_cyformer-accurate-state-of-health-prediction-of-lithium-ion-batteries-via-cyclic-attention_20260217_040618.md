# CyFormer: Accurate State-of-Health Prediction of Lithium-Ion Batteries via Cyclic Attention

## Quick Facts
- **arXiv ID:** 2304.08502
- **Source URL:** https://arxiv.org/abs/2304.08502
- **Reference count:** 25
- **Key result:** CyFormer achieves MAE of 0.75% and MAPE of 0.89% on NASA Battery Data Set transfer learning task

## Executive Summary
This paper introduces CyFormer, a transformer-based architecture designed for accurate State-of-Health (SoH) prediction in lithium-ion batteries. The model leverages cyclic attention mechanisms to capture both intra-cycle and inter-cycle dependencies from battery aging data. Evaluated on the NASA Battery Data Set, CyFormer demonstrates superior performance compared to CNN-LSTM and CNN-Transformer baselines, achieving 0.75% MAE and 0.89% MAPE in a challenging transfer learning scenario where only 10% of target battery data is used for fine-tuning. The model is further optimized through pruning, reducing computational cost by 41% while maintaining accuracy.

## Method Summary
CyFormer employs a transformer architecture with specialized row-wise and column-wise attention blocks to process cyclic aging data from lithium-ion batteries. The model takes as input measured current, voltage, load current, load voltage, and temperature data, structured into sequences of 16 cycles with 32 sample points each. The architecture consists of an encoder with cyclic attention blocks and a decoder with cross-attention, trained on source batteries before fine-tuning on 10% of target battery data. The model is evaluated using MAE, MAPE, and RMSE metrics, with particular emphasis on transfer learning performance on the remaining 90% of target battery cycles.

## Key Results
- Achieves MAE of 0.75% and MAPE of 0.89% on NASA Battery Data Set transfer learning task
- Outperforms CNN-LSTM and CNN-Transformer baselines in SoH prediction accuracy
- Reduces computational cost by 41% through pruning while maintaining performance

## Why This Works (Mechanism)
CyFormer's effectiveness stems from its specialized attention mechanisms that capture both intra-cycle patterns (within individual charge-discharge cycles) and inter-cycle relationships (across the battery's aging timeline). The row-wise attention captures temporal dependencies within each cycle, while column-wise attention models the evolution of battery characteristics across cycles. This dual attention approach allows the model to learn complex degradation patterns that are critical for accurate SoH prediction, particularly in transfer learning scenarios where limited target data is available.
