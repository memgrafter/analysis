# MEMEX: Detecting Explanatory Evidence for Memes via Knowledge-Enriched Contextualization

## Quick Facts
- arXiv ID: 2305.15913
- Source URL: https://arxiv.org/abs/2305.15913
- Authors: 
- Reference count: 36
- Key outcome: MIME achieves 4% absolute improvement in F1-score over best baseline for MEMEX task

## Executive Summary
This paper introduces MEMEX, a novel task for detecting explanatory evidence sentences for memes from related documents. The authors develop MCC, a new dataset containing 3,400 memes and their contexts, along with human-annotated evidence sentences. To benchmark MCC, they propose MIME, a multimodal framework that uses knowledge-enriched meme representations and a layered approach to capture cross-modal semantic dependencies between memes and context. MIME outperforms several unimodal and multimodal baselines, achieving a 4% absolute improvement in F1-score over the best baseline. The paper also provides detailed analyses of MIME's performance and limitations.

## Method Summary
MIME is a multimodal neural framework for the MEMEX task that uses knowledge-enriched meme representation and a layered approach to capture cross-modal semantic dependencies. It first encodes the meme image and text using MMBT to get a multimodal representation. It then uses a pre-trained GCN over ConceptNet to extract semantic embeddings for the meme text words, averages them, and fuses this external knowledge representation with the multimodal meme representation using a gated multimodal fusion block. MIME uses a Meme-Aware Transformer (MAT) that generates query vectors from the context and key/value vectors conditioned on the meme representation, using multi-headed attention with meme-conditioned keys/values to aggregate context representations. It then uses a Meme-Aware LSTM (MA-LSTM) that sequentially processes the context representations while incorporating the meme representation via a gating mechanism. The final prediction uses the jointly contextualized meme and context representations.

## Key Results
- MIME surpasses several competitive and conventional baselines, adapted for the MEMEX task
- MIME yields absolute improvements of 5.34%, 3.97%, 4.26%, 2.31% and 8.00% in accuracy, F1 score, precision, recall, and exact match scores, respectively, over the best baseline, MMBT
- Adding external knowledge-based cues along with the MMBT representation via KME leads to an enhancement of 0.98%-2.91% and 5% across the first four metrics and the exact match, respectively

## Foundational Learning

- Concept: Multimodal representation learning
  - Why needed here: Memes are multimodal, consisting of images and overlaid text. MIME needs to learn effective joint representations of these modalities to understand the memes and their contexts.
  - Quick check question: How does MIME encode the meme image and text into a joint multimodal representation?

- Concept: Attention mechanisms for cross-modal alignment
  - Why needed here: To identify evidence sentences that explain the meme, MIME needs to align the meme representation with relevant context representations. Attention allows MIME to focus on context parts most relevant to the meme.
  - Quick check question: How does MIME's Meme-Aware Transformer use attention to integrate meme information into context representation?

- Concept: Recurrent neural networks for sequence modeling
  - Why needed here: Context documents consist of sequences of sentences. MIME needs to model the order and dependencies between sentences to identify explanatory evidence. MA-LSTM allows this while conditioning on the meme.
  - Quick check question: How does MIME's Meme-Aware LSTM process the sequence of context representations while incorporating meme information?

## Architecture Onboarding

- Component map: KME -> MAT -> MA-LSTM -> Prediction
- Critical path: KME -> MAT -> MA-LSTM -> Prediction
- Design tradeoffs: KME adds complexity but provides knowledge enrichment; MAT and MA-LSTM add layers but improve cross-modal alignment; all add parameters and training time
- Failure signatures: Poor performance if KME fails to enrich meme representation; if MAT fails to align meme and context; if MA-LSTM fails to model context sequence
- First 3 experiments:
  1. Replace KME with simple multimodal meme representation (e.g., MMBT) and measure performance drop
  2. Replace MAT with standard Transformer and measure performance drop
  3. Replace MA-LSTM with standard LSTM and measure performance drop

## Limitations

- MIME's generalizability beyond the MCC dataset remains uncertain, as the task formulation assumes explicit explanatory sentences exist in the context
- The knowledge enrichment mechanism relies heavily on ConceptNet's coverage and the quality of the pre-trained GCN, introducing potential brittleness
- Performance gains from meme-aware attention and recurrence could be partially attributed to architectural complexity rather than genuine cross-modal understanding

## Confidence

- MIME's superior performance over baselines (High) - supported by ablation study showing consistent improvements from each component
- Knowledge-enriched representation effectiveness (Medium) - relies on ConceptNet's coverage and GCN quality
- Meme-aware attention and recurrence effectiveness (Medium) - novel approach but performance gains could be partially due to increased model complexity
