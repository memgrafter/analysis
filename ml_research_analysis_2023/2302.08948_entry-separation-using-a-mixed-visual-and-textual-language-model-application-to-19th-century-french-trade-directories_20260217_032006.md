# Entry Separation using a Mixed Visual and Textual Language Model: Application to 19th century French Trade Directories

## Quick Facts
- arXiv ID: 2302.08948
- Source URL: https://arxiv.org/abs/2302.08948
- Reference count: 40
- Primary result: Achieves 99.0% F-score for entry separation in 19th century French Trade Directories using combined visual and textual information

## Executive Summary
This paper addresses the challenge of segmenting semantically consistent content blocks, such as entries in dictionaries or directories, from historical documents. Traditional approaches relied on visual clues, but this work proposes a novel method that combines both textual and visual information using a Named Entity Recognition (NER) approach adapted for this task. By injecting special visual tokens, such as indentation or breaks, into the text stream processed by the NER model, the system can leverage both types of information simultaneously. The method is evaluated on 19th century French Trade Directories, where it achieves an F-score of 99.0% for entry separation when using both textual and visual information.

## Method Summary
The approach extends BERT-based token classification by injecting visual tokens that encode layout information (indentation, breaks, spacing) into the text stream. These visual tokens are generated from OCR-extracted positional information and merged with textual content to create a unified token stream. The system uses a CamemBERT variant pretrained on noisy OCR text, fine-tuned for the combined entry separation and NER task. The output label space includes both entry boundary markers (EBEGIN, EEND) and named entity labels, allowing unified processing. Visual tokens are categorically encoded based on manual threshold determination from the training set, capturing essential spatial relationships needed for distinguishing entry boundaries.

## Key Results
- Text-only entry separation achieves 96.4% F-score as a solid baseline
- Progressive integration of visual tokens improves performance to 99.0% F-score
- The combined approach significantly outperforms text-only or visual-only methods
- Unified processing enables simultaneous entry separation and named entity recognition

- Mechanism: The approach converts visual layout cues (such as indentation, breaks, and spacing) into special text tokens that are injected into the regular text token stream. These tokens carry layout information as categorical encodings that the BERT model can process alongside regular text tokens.
- Core assumption: Visual layout information can be effectively encoded as discrete text tokens that capture the essential spatial relationships needed for entry separation.

- Claim: The approach enables unified processing of entry separation and named entity recognition in a single pass through the network.
- Mechanism: By designing the output label space to include both entry boundary markers (EBEGIN, EEND) and named entity labels, the same BERT-based model can simultaneously identify where entries begin and end while also extracting structured information within entries. - Core assumption: The BERT model can learn to distinguish between different types of labels in the output space and that visual tokens can be effectively used to simplify the labeling scheme.
- Evidence anchors:
  - [abstract]: "By injecting special visual tokens, coding, for instance, indentation or breaks, into the token stream of the language model used for NER purpose, we can leverage both textual and visual knowledge simultaneously."

## Architecture Onboarding

- Component map: OCR system -> Visual token generator -> Tokenizer -> BERT-based classifier -> Evaluation system

- Critical path:
  1. Run coarse layout detection to identify columns and reading order
  2. Extract text lines with positional information
  3. Generate visual tokens based on layout features
  4. Merge visual and textual content into unified token stream
  5. Tokenize using extended BERT tokenizer
  6. Process through BERT classifier
  7. Evaluate results against ground truth

- Design tradeoffs:
  - Using visual tokens vs. image-based approaches: Simpler, lighter, requires less annotation but may miss complex visual patterns
  - Unified vs. separate models: More efficient computation but potentially more complex training
  - Absolute vs. relative spacing measurements: Absolute provides clear thresholds, relative may capture relative changes better

- Failure signatures:
  - Poor entry separation: Visual tokens not capturing relevant layout features, or BERT not learning the relationship between visual tokens and entry boundaries
  - Low NER accuracy: Visual tokens interfering with textual context understanding, or insufficient training data for named entities
  - Training instability: Complex label space or insufficient regularization causing convergence issues

- First 3 experiments:
  1. Baseline text-only entry separation to establish performance floor
  2. Add visual break tokens to assess impact of basic structural information
  3. Add absolute left/right spacing tokens to evaluate contribution of indentation information

## Limitations
- The approach's effectiveness is demonstrated on a specific corpus (19th century French Trade Directories) with a relatively controlled layout structure
- Visual token generation relies on manual threshold determination for indentation categories, which may not generalize well to documents with different layout conventions
- The method assumes that visual layout information can be adequately captured through discrete token encodings, which may not hold for documents with more nuanced spatial relationships

## Confidence

**High confidence** in the core mechanism of combining visual and textual information for entry separation, supported by experimental results showing 99.0% F-score with combined modalities versus 96.4% with text-only.

**Medium confidence** in the generalization capability to other historical document types with different layout structures, as the method has only been validated on one specific document type with relatively uniform formatting.

**Low confidence** in the optimal granularity of visual token categories, as the threshold values were determined manually without systematic sensitivity analysis.

## Next Checks
1. **Cross-domain validation**: Test the approach on a different historical document type (e.g., 18th century British newspapers or 20th century German business directories) to assess generalization of the visual token injection method and identify necessary adaptations for different layout conventions.

2. **Visual token granularity analysis**: Systematically vary the number of categorical bins for indentation and spacing tokens (e.g., using 3, 5, 10, and 20 bins) to determine the optimal granularity that maximizes entry separation performance while maintaining model stability.

3. **Error case analysis**: Conduct detailed examination of false positives and false negatives in the entry separation task, particularly focusing on cases where text-only performance differs significantly from combined visual-textual performance, to identify specific layout patterns where visual tokens provide the most benefit.
