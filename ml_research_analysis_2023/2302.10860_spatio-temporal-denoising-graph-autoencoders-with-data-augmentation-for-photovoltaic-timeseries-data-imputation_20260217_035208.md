# Spatio-Temporal Denoising Graph Autoencoders with Data Augmentation for Photovoltaic Timeseries Data Imputation

## Quick Facts
- **arXiv ID**: 2302.10860
- **Source URL**: https://arxiv.org/abs/2302.10860
- **Reference count**: 40
- **Key outcome**: STD-GAE achieves 43.14% gain in imputation accuracy over state-of-the-art methods on PV timeseries data

## Executive Summary
This paper presents STD-GAE, a novel framework for imputing missing photovoltaic power data that integrates spatiotemporal graph autoencoders with denoising autoencoders and domain-knowledge-aware data augmentation. The framework addresses the challenge of sparse yet varied missing data scenarios in PV timeseries by leveraging both spatial correlations between neighboring inverters and temporal dependencies within each inverter. Experimental results on two real-world PV datasets demonstrate significant improvements in imputation accuracy while maintaining robustness across different missing rates, seasons, and missing scenarios.

## Method Summary
STD-GAE integrates a spatiotemporal graph autoencoder with a denoising autoencoder and incorporates a domain-knowledge-aware data augmentation module. The framework first uses baseline imputation methods (e.g., KNN) to fill missing values, then validates these estimates against physical constraints from PV domain knowledge (irradiance scaling, nameplate power limits). Missing masks are then generated according to configurable parameters to create corrupted training examples. The spatiotemporal graph autoencoder consists of temporal layers (gated 1D convolution) and spatial layers (ChebConv) that aggregate information across time and space. The model is trained using Adam optimizer with reconstruction loss minimization, and evaluated against multiple baselines including linear interpolation, KNN, MICE, and tensor-based methods.

## Key Results
- STD-GAE achieves a 43.14% gain in imputation accuracy compared to state-of-the-art methods
- The framework remains less sensitive to missing rate, different seasons, and various missing scenarios
- Domain-knowledge-aware augmentation prevents augmented values from deviating from realistic PV power output ranges

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Integrating denoising autoencoders with spatiotemporal graph convolutions allows robust learning from incomplete, noisy PV timeseries data
- Mechanism: The denoising autoencoder corrupts the augmented input, forcing the network to learn latent representations that generalize beyond immediate observations, while spatiotemporal graph convolutions aggregate temporal and spatial dependencies to recover missing values
- Core assumption: PV inverter outputs exhibit both strong temporal correlations within each inverter and spatial correlations across neighboring inverters
- Evidence anchors: [abstract] "STD-GAE incorporates a domain-knowledge-aware data augmentation module that creates plausible variations of missing data patterns" and [section] "To cope with sparse example, STD-GAE exploits a domain knowledge-aware data augmentation module"
- Break condition: If spatial or temporal correlations are weak or inconsistent across inverters, the model's aggregation may propagate noise instead of signal

### Mechanism 2
- Claim: Domain-knowledge-aware data augmentation improves model robustness to sparse and varied missing patterns
- Mechanism: Before training, the augmentation module uses baseline imputation methods to fill missing values, then validates these estimates against physical constraints from PV domain knowledge
- Core assumption: PV power output follows deterministic physical constraints that can be encoded as rules to validate augmented values
- Evidence anchors: [abstract] "STD-GAE incorporates a domain-knowledge-aware data augmentation module that creates plausible variations of missing data patterns" and [section] "STD-GAE leverages domain knowledge from PV scientists and engineers to prevent augmented values from deviating largely from reality"
- Break condition: If domain knowledge rules are too restrictive or inaccurate, augmentation may discard valid imputed values, reducing data richness

### Mechanism 3
- Claim: Configurable data corruption simulates realistic missing scenarios, enabling the model to generalize across MCAR and block missing patterns
- Mechanism: Missing masks are generated according to configurable parameters (missing rate, block length) to create corrupted training examples that mimic real-world missingness distributions
- Core assumption: The distribution of missing patterns in corrupted training data is representative of real-world scenarios
- Evidence anchors: [section] "Missing mask is characterized by a configuration tuple ('missing types', 'configuration')" and [section] "Fig. 3 shows an example of corruption phase using the above two missing patterns"
- Break condition: If corruption masks do not match actual missingness distribution in deployment, model may overfit to synthetic patterns and underperform on real data

## Architecture Onboarding

- **Component map**: Ingestion → Preprocessing → Data Augmentation (baseline imputations + domain validation) → Data Corruption (configurable missing masks) → Spatiotemporal Graph Autoencoder (spatial-temporal blocks) → Output Imputation
- **Critical path**: Data Augmentation → Data Corruption → Model Training (reconstruction loss minimization)
- **Design tradeoffs**: 
  - Depth of spatial-temporal blocks: More blocks increase expressiveness but may overfit or degrade performance
  - Sparsity parameter n: Controls edge density; higher n reduces edges, simplifying the graph but possibly losing long-range dependencies
  - Imputation library choice: Simpler methods (e.g., linear interpolation) are fast but less accurate; complex methods (e.g., MICE) are more accurate but computationally expensive
- **Failure signatures**:
  - High reconstruction loss on validation set: Possible overfitting or insufficient data augmentation
  - Imputation errors increase with missing rate: Model may not have learned robust spatial-temporal patterns
  - Imputed values violate physical constraints: Domain knowledge rules may be too strict or incorrectly specified
- **First 3 experiments**:
  1. Test baseline imputation accuracy (e.g., KNN, linear interpolation) on PV data without model training to establish a performance floor
  2. Train STD-GAE with MCAR corruption only, varying missing rate, and evaluate imputation accuracy on a held-out validation set
  3. Train STD-GAE with block missing corruption, varying block length, and compare performance against baseline imputation methods

## Open Questions the Paper Calls Out

- **Open Question 1**: How does the performance of STD-GAE change when trained on multi-year PV data spanning different seasons and weather patterns? The authors acknowledge the need to train STD-GAE on datasets covering at least three consecutive years to overcome limitations observed in current experiments.
- **Open Question 2**: How effective is combining STD-GAE with inverse probability weighting (IPW) for handling missing data in downstream tasks like PV Performance Loss Rate (PLR) Prediction? The authors propose integrating STD-GAE with IPW for PV PLR Prediction as a future direction.
- **Open Question 3**: How does the network sparsity parameter (n) impact STD-GAE's performance in PV networks with varying physical topologies (e.g., distant sites with similar environmental conditions)? The authors found that network sparsity affects imputation accuracy but suggest that distant sites might contribute to local imputation due to similar environmental conditions.

## Limitations

- The domain-knowledge-aware data augmentation module lacks explicit experimental validation to demonstrate its specific contribution to performance gains
- The physical constraints used for domain knowledge validation are not fully specified, making it difficult to assess their appropriateness
- The edge weight calculation between PV inverters relies on unspecified distance metrics and network sparsity parameters that could significantly impact model performance

## Confidence

- **High confidence**: The spatiotemporal graph autoencoder architecture and its integration with denoising autoencoders is well-specified and theoretically sound
- **Medium confidence**: The data augmentation approach combining baseline imputation with domain knowledge validation is plausible but lacks direct experimental validation
- **Low confidence**: The specific implementation details of domain knowledge rules and edge weight calculations are underspecified, making exact reproduction challenging

## Next Checks

1. **Domain Knowledge Impact Test**: Run ablation experiments comparing STD-GAE with and without domain knowledge validation in the augmentation module, using identical data corruption patterns, to quantify the specific contribution of domain constraints to imputation accuracy

2. **Edge Weight Sensitivity Analysis**: Systematically vary the edge weight calculation parameters (distance metrics, sparsity threshold n) and measure the impact on fleet-level and inverter-level imputation accuracy across different seasons and missing scenarios

3. **Real-world Missing Pattern Validation**: Apply STD-GAE to actual deployment data with naturally occurring missing patterns (not synthetically corrupted) and compare performance against the synthetic corruption benchmarks to assess generalizability
