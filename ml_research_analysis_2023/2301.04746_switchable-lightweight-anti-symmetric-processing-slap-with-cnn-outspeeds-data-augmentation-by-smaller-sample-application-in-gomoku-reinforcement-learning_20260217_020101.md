# Switchable Lightweight Anti-symmetric Processing (SLAP) with CNN Outspeeds Data Augmentation by Smaller Sample -- Application in Gomoku Reinforcement Learning

## Quick Facts
- arXiv ID: 2301.04746
- Source URL: https://arxiv.org/abs/2301.04746
- Reference count: 21
- SLAP improves CNN convergence speed by 83% with only 1/8 sample size compared to data augmentation in Gomoku

## Executive Summary
SLAP is a model-independent protocol that standardizes symmetry variants by always outputting the same variant regardless of input transformation, effectively concentrating learning experience. The method works by comparing all symmetry variants of a given input and selecting the lexicographically largest variant, creating a canonical representation for all symmetric forms of the same state. Experiments show SLAP improved CNN learning convergence speed by 83% with only one eighth of the sample size compared to data augmentation in Gomoku game states, though its benefits for reinforcement learning speed remain unclear.

## Method Summary
SLAP standardizes symmetry variants by always outputting the same variant regardless of input transformation, effectively concentrating experience in the learning process. The algorithm compares all symmetry variants of a given input (e.g., rotation and reflection of a Gomoku board state) and always selects the lexicographically largest variant. This creates a canonical representation for all symmetric forms of the same state, reducing redundancy in the training data. In experiments with synthetic Gomoku states, SLAP improved CNN learning convergence speed by 83% with only one eighth of the sample size compared to data augmentation. The method was also applied to reinforcement learning for Gomoku using AlphaGo Zero/AlphaZero algorithm, where it reduced the number of training samples by a factor of 8 while achieving similar winning rates.

## Key Results
- SLAP improved CNN convergence speed by 83% with only 1/8 sample size in synthetic Gomoku experiments
- In reinforcement learning, SLAP achieved similar winning rates to data augmentation with 8x fewer training samples
- SLAP-CC (for translation variants) worsened convergence speed by 30.7% compared to baseline in Gomoku

## Why This Works (Mechanism)

### Mechanism 1
SLAP standardizes symmetry variants by always outputting the same variant regardless of input transformation, effectively concentrating experience in the learning process. The algorithm compares all symmetry variants of a given input (e.g., rotation and reflection of a Gomoku board state) and always selects the lexicographically largest variant. This creates a canonical representation for all symmetric forms of the same state, reducing redundancy in the training data.

### Mechanism 2
By reducing the effective size of the training set through symmetry standardization, SLAP accelerates CNN convergence by concentrating learning experience on unique patterns. Data augmentation increases sample size by creating multiple variants of each training example, while SLAP does the opposite by mapping multiple variants to a single canonical form. This means the model sees fewer unique examples but learns the essential patterns more efficiently.

### Mechanism 3
SLAP maintains differentiability through its invariance property, allowing it to be integrated into differentiable learning pipelines without breaking gradient flow. While SLAP itself is not directly differentiable (it involves discrete operations like finding the maximum of flattened variants), the overall learning pipeline remains differentiable because the transformation information can be tracked and used to map gradients back appropriately during backpropagation.

## Architecture Onboarding

- Component map: Input preprocessing -> SLAP function -> Neural network -> MCTS -> Self-play buffer -> Weight updates
- Critical path: Generate symmetry variants of input state -> Apply SLAP to select canonical variant -> Feed canonical variant to neural network -> Process output through MCTS for action selection -> Store game state and outcome for training -> Update neural network weights based on stored experiences
- Design tradeoffs: Speed vs. sample size (SLAP reduces sample size but adds computational overhead in preprocessing); Invariance vs. expressiveness (SLAP assumes all symmetric variants are equivalent, which may not hold for all learning tasks); Simplicity vs. flexibility (SLAP is simple to implement but may not generalize to all types of symmetries or transformations)
- Failure signatures: Poor convergence despite reduced sample size (may indicate that the symmetry assumption is incorrect for the task); Instability in learning rate adjustments (could suggest that the accelerated learning from concentrated experience is causing optimization difficulties); Unexpected behavior in evaluation (might indicate issues with the transformation information being tracked and applied correctly)

## Open Questions the Paper Calls Out

### Open Question 1
Does SLAP improve reinforcement learning speed as it does for supervised learning with synthetic data? The paper states that SLAP improved CNN learning convergence speed by 83% in experiments with synthetic Gomoku game states, but it was not yet evident that it could speed up reinforcement learning. The reinforcement learning experiments showed SLAP achieved similar winning rates to data augmentation with 8x fewer training samples, but the speed improvement was not demonstrated.

### Open Question 2
How does SLAP perform for domains with groupoid symmetries (local but not global symmetry) like Gomoku translations? The paper mentions that Gomoku has "partially" translation invariant properties and introduces SLAP-CC to handle translation variants, but results showed SLAP-CC worsened convergence speed by 30.7% compared to baseline. The SLAP-CC variant performed worse than data augmentation for translation invariance, suggesting SLAP may not be optimal for groupoid symmetries.

### Open Question 3
Can SLAP be made differentiable to allow end-to-end training through neural network layers? The paper notes that SLAP was not applied to intermediate layers of neural networks, so its differentiability was not required. It mentions that approximation would be required to make it differentiable. The current implementation of SLAP is a pre-processing step applied to inputs only.

## Limitations
- SLAP-CC (for translation variants) worsened convergence speed by 30.7% compared to baseline in Gomoku
- Reinforcement learning speed improvements remain unclear despite sample efficiency gains
- Current implementation is not differentiable and cannot be applied to intermediate network layers

## Confidence
- CNN convergence claims: High confidence (controlled experiments with clear metrics)
- RL sample efficiency claims: Medium confidence (results show reduction but not speed improvement)
- Differentiability claims: Low confidence (acknowledged as requiring approximation)
- Generalization claims: Low confidence (only tested on Gomoku)
