# Improving Content Retrievability in Search with Controllable Query Generation

## Quick Facts
- arXiv ID: 2303.11648
- Source URL: https://arxiv.org/abs/2303.11648
- Reference count: 40
- Key outcome: CtrlQGen reduces retrievability bias by 10% Gini reduction and increases retrievability for 9% of entities

## Executive Summary
This paper addresses the problem of content retrievability bias in search systems, where popular items dominate results and obscure less popular but relevant content. The authors propose CtrlQGen, a controllable query generation technique that can create both narrow and broad queries for entities, addressing biased training data for dense retrieval models and the predominance of narrow user queries. Through experiments on three datasets (music, podcasts, and books), the method demonstrates significant improvements in retrievability metrics and offers a practical approach to surfacing underrepresented content in search results.

## Method Summary
The authors introduce CtrlQGen, a controllable query generation approach that addresses retrievability bias by creating synthetic queries that span different levels of specificity. The method generates both narrow and broad queries for entities, which are then used to train dense retrieval models and suggest to users. Two hypotheses are tested: that training on synthetic CtrlQGen queries reduces retrievability bias, and that suggesting broader queries from CtrlQGen further reduces this bias. The approach is evaluated on three datasets representing music, podcasts, and books, comparing retrieval performance against models trained on traditional click data.

## Key Results
- Fine-tuning dense retrieval models on CtrlQGen queries reduces retrievability bias by 10% Gini reduction
- Model trained on CtrlQGen queries increases retrievability for 9% of entities compared to click data models
- Suggesting broader queries from CtrlQGen further reduces retrievability bias by up to 9% and makes 12% of entities retrievable

## Why This Works (Mechanism)
The approach works by addressing the fundamental mismatch between user query distributions and content popularity distributions. By generating synthetic queries that cover both narrow and broad aspects of entities, CtrlQGen creates a more balanced training signal for retrieval models. This balanced training helps the model learn to retrieve both popular and niche content effectively. Additionally, by suggesting broader queries to users, the system can surface content that might otherwise remain hidden due to overly specific initial queries, effectively bridging the gap between user intent and content discoverability.

## Architecture Onboarding

Component map: User query -> CtrlQGen query generator -> Dense retrieval model -> Retrieved content -> User interaction

Critical path: User query → CtrlQGen generation → Dense retrieval → Content presentation → User engagement

Design tradeoffs: The system balances between query specificity and coverage, with CtrlQGen generating both narrow and broad queries to address the bias toward popular content. The approach trades computational overhead of generating synthetic queries for improved retrieval diversity.

Failure signatures: If the system overgenerates broad queries, users may experience decreased precision. If synthetic queries don't match real user language patterns, retrieval performance may suffer. If the model overfits to synthetic data, it may underperform on real user queries.

First experiments:
1. Generate synthetic queries for a small set of entities and verify they cover different specificity levels
2. Train a dense retrieval model on synthetic CtrlQGen queries and test retrieval performance on held-out data
3. Implement a basic query suggestion interface to test user engagement with broader queries

## Limitations
- Limited generalizability beyond music, podcasts, and books domains
- Long-term effectiveness unclear as user behavior may adapt to suggested broader queries
- Potential drawbacks of broader queries not explored (increased user effort, reduced precision)
- Offline evaluation only; no live production testing demonstrated
- Computational costs of generating and serving synthetic queries at scale not addressed

## Confidence
- High: CtrlQGen can generate both narrow and broad queries for entities
- High: Fine-tuning on CtrlQGen queries reduces retrievability bias in tested datasets
- Medium: Suggesting broader queries reduces retrievability bias
- Low: Long-term sustainability of improvements
- Low: Effectiveness in domains outside music, podcasts, and books

## Next Checks
