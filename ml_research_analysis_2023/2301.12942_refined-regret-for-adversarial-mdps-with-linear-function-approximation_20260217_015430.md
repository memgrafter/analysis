# Refined Regret for Adversarial MDPs with Linear Function Approximation

## Quick Facts
- arXiv ID: 2301.12942
- Source URL: https://arxiv.org/abs/2301.12942
- Reference count: 40
- Key result: Achieves O(sqrt(K)) regret for adversarial MDPs with linear function approximation, improving from the previous O(K^{2/3}) bound

## Executive Summary
This paper addresses the challenge of adversarial Markov Decision Processes (MDPs) with large state spaces under linear function approximation. The authors develop two algorithms that achieve O(sqrt(K)) regret, improving upon the best existing bound of O(K^{2/3}). The first algorithm uses a refined analysis of FTRL with the log-barrier regularizer, allowing loss estimators to be arbitrarily negative while maintaining convergence. The second algorithm introduces a magnitude-reduced loss estimator that removes the polynomial dependency on the number of actions, leading to an optimal regret bound. Additionally, the paper extends these results to simulator-free linear MDPs, achieving O(K^{8/9}) regret, a significant improvement over the previous O(K^{14/15}) bound.

## Method Summary
The paper presents two algorithms based on Follow-the-Regularized-Leader (FTRL) for adversarial MDPs with linear function approximation. The first algorithm uses the log-barrier regularizer, which allows loss estimators to be arbitrarily negative while maintaining the required regret bounds. The second algorithm employs a magnitude-reduced loss estimator with the negative entropy regularizer, effectively removing the polynomial dependency on the number of actions. Both algorithms build upon the dilated bonus framework to address the distribution mismatch problem between the learner's policy and the optimal policy. For simulator-free linear MDPs, the authors develop an alternative to Matrix Geometric Resampling using a multiplicative approximation for covariance matrix estimation, significantly reducing the sample complexity.

## Key Results
- Achieves O(sqrt(K)) regret for adversarial linear-Q MDPs with simulator access, improving from O(K^{2/3})
- Removes polynomial dependency on action space size in the regret bound through magnitude-reduced loss estimator
- Achieves O(K^{8/9}) regret for simulator-free linear MDPs, improving from O(K^{14/15})
- Demonstrates that a multiplicative approximation for covariance matrix estimation is sufficient for regret bounds, reducing sample complexity from O(epsilon^{-2} gamma^{-3}) to O(gamma^{-2})

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using log-barrier regularizers in FTRL allows loss estimators to be arbitrarily negative while maintaining convergence
- Mechanism: The log-barrier regularizer $\Psi(p) = \sum_{i=1}^A \ln \frac{1}{p_i}$ allows the regret bound to hold without requiring loss estimators to be bounded below by $-1/\eta$
- Core assumption: The log-barrier regularizer maintains the same $\sum_t x_{t,i} c_{t,i}^2$ bound as negative entropy while removing constraints on loss magnitudes
- Break condition: If the $\sum_t x_{t,i} c_{t,i}^2$ bound fails or if the log-barrier regularizer introduces instability in practice

### Mechanism 2
- Claim: The magnitude-reduced loss estimator prevents overly negative Q-function estimates while maintaining statistical efficiency
- Mechanism: By defining a modified estimator $\hat{Z} = Z - (Z)_- + \mathbb{E}[(Z)_-]$ where $(Z)_- = \min\{Z, 0\}$, we ensure the estimator is bounded below by $\mathbb{E}[(Z)_-]$ rather than potentially being very negative
- Core assumption: The modified estimator preserves the expected value while reducing the magnitude of negative values sufficiently to allow smaller learning rates
- Break condition: If the approximation $\mathbb{E}[(Z)_-]$ is poor or if the modified estimator introduces bias that cannot be controlled

### Mechanism 3
- Claim: Using a multiplicative approximation for covariance matrix inverse estimation is sufficient for regret bounds
- Mechanism: Instead of requiring an additive approximation, we only need a multiplicative bound $(1-\sqrt{\gamma})I \preceq \hat{\Sigma}^\dagger_h^{1/2}(\gamma I + \Sigma_h^\pi)\hat{\Sigma}^\dagger_h^{1/2} \preceq (1+\sqrt{\gamma})I$
- Core assumption: The multiplicative bound is sufficient for the bias analysis in the regret decomposition
- Break condition: If the multiplicative approximation introduces bias that grows with problem parameters or if the sample complexity becomes prohibitive

## Architecture Onboarding

- Component map: FTRL optimization -> Action selection -> Loss and transition observation -> Bonus and Q-function estimation -> Update FTRL distribution -> Next episode
- Critical path: Policy selection → Action execution → Loss and transition observation → Bonus and Q-function estimation → Update FTRL distribution → Next episode
- Design tradeoffs:
  - Log-barrier vs negative entropy: Log-barrier removes polynomial dependency on action space size but requires more careful handling of the regularizer's effect on the bias terms
  - Standard vs magnitude-reduced estimator: Standard estimator is simpler but requires larger learning rates; magnitude-reduced allows smaller learning rates but needs more samples
  - Additive vs multiplicative covariance approximation: Additive gives tighter bounds but needs more samples; multiplicative is sufficient for regret bounds with fewer samples
- Failure signatures:
  - Regret grows faster than $\tilde{O}(\sqrt{K})$: Indicates breakdown in either the regularizer analysis or the covariance estimation
  - High variance in Q-function estimates: Suggests the magnitude-reduced estimator isn't reducing variance effectively
  - Covariance estimation fails: Poor multiplicative approximation leading to biased Q-function estimates
- First 3 experiments:
  1. Implement FTRL with log-barrier on a simple linear bandit problem and verify the regret bound holds without constraining losses
  2. Compare standard vs magnitude-reduced estimators on a synthetic linear-Q MDP to confirm the reduction in negative magnitude
  3. Test the multiplicative covariance approximation on a small linear MDP to verify the $(1\pm\sqrt{\gamma})$ bound holds with the claimed sample complexity

## Open Questions the Paper Calls Out

- Question: Is it possible to achieve a regret bound of O(sqrt(K)) for adversarial MDPs with linear function approximation without assuming access to a simulator?
  - Basis in paper: The paper mentions that the authors achieve O(sqrt(K)) regret for adversarial linear-Q MDPs when a simulator is available, but it is an open question whether this can be achieved without a simulator
  - Why unresolved: The authors only provide a solution for simulator-free linear MDPs, which is a special case of linear-Q MDPs. The general case of linear-Q MDPs without a simulator remains unsolved
  - What evidence would resolve it: A proof showing that O(sqrt(K)) regret can be achieved for adversarial linear-Q MDPs without assuming access to a simulator

- Question: Can the log-barrier regularizer be used to achieve O(sqrt(K)) regret for adversarial linear-Q MDPs without introducing polynomial dependency on the number of actions?
  - Basis in paper: The authors mention that the log-barrier regularizer causes an O(sqrt(A)) factor in the regret bound, where A is the number of actions. They propose a magnitude-reduced loss estimator to remove this dependency
  - Why unresolved: The authors only provide a solution for the case with polynomial dependency on the number of actions using the log-barrier regularizer. It is an open question whether this dependency can be removed entirely
  - What evidence would resolve it: A proof showing that O(sqrt(K)) regret can be achieved for adversarial linear-Q MDPs using the log-barrier regularizer without introducing polynomial dependency on the number of actions

- Question: Is it possible to improve the regret bound for simulator-free linear MDPs beyond O(K^(8/9))?
  - Basis in paper: The authors achieve O(K^(8/9)) regret for simulator-free linear MDPs, which is an improvement over the best existing bound of O(K^(14/15)). However, they do not provide a lower bound for this setting
  - Why unresolved: The authors do not provide a lower bound for simulator-free linear MDPs, so it is unclear whether O(K^(8/9)) is the optimal regret bound or if it can be further improved
  - What evidence would resolve it: A proof showing either a lower bound for simulator-free linear MDPs or an algorithm achieving a regret bound better than O(K^(8/9))

## Limitations

- The log-barrier regularizer analysis relies on specific properties that may not generalize to other settings, with potential numerical stability issues in practice
- The magnitude-reduced estimator requires careful sampling to estimate the expected negative part accurately, with uncertain sample complexity in practice
- The extension to simulator-free linear MDPs achieves O(K^(8/9)) regret, which is an improvement but still not the optimal O(sqrt(K)) bound

## Confidence

- O(sqrt(K)) regret bounds: High confidence - follows from established techniques with rigorous proofs
- Log-barrier regularizer properties: Medium confidence - theoretically sound but implementation-dependent
- Magnitude-reduced estimator effectiveness: Medium confidence - novel approach with theoretical backing
- Multiplicative covariance approximation: High confidence - well-proven with explicit sample complexity
