# Automatic Gradient Descent: Deep Learning without Hyperparameters

## Quick Facts
- arXiv ID: 2304.05187
- Source URL: https://arxiv.org/abs/2304.05187
- Authors: 
- Reference count: 40
- Key outcome: Hyperparameter-free optimization algorithm for deep neural networks achieving performance comparable to tuned Adam/SGD

## Executive Summary
This paper introduces Automatic Gradient Descent (AGD), a first-order optimization algorithm that eliminates the need for learning rate tuning in deep neural network training. The method derives update rules explicitly tailored to neural architecture by combining Bregman divergences to characterize network-loss interactions with deep relative trust to bound weight-functional perturbations. AGD achieves competitive performance on standard benchmarks while providing theoretical convergence guarantees and handling architectures that standard optimizers fail to train with default hyperparameters.

## Method Summary
AGD combines Bregman divergences with deep relative trust bounds to create a majorization that can be minimized without learning rate tuning. The algorithm prescribes dimensional scaling where weight norms scale with square root of layer dimensions and updates scale with depth. Weight initialization uses orthogonal matrices rescaled by fan-in/fan-out ratios. For convolutional layers, a per-submatrix normalization scheme is employed. The optimizer computes a gradient summary to automatically determine learning rates through a logarithmic formula, enabling hyperparameter-free training across different architectures.

## Key Results
- Achieves 91.2% test accuracy on CIFAR-10 with ResNet-18 (vs 92.9% for tuned Adam/SGD)
- Trains networks that Adam/SGD with default hyperparameters fail to train
- Scales to ImageNet with 65.5% top-1 accuracy on ResNet-50
- Provides theoretical convergence rates inversely proportional to square root of iterations

## Why This Works (Mechanism)

### Mechanism 1
The algorithm achieves hyperparameter-free optimization by deriving update rules that directly account for the non-linear structure of neural networks. It combines Bregman divergences to characterize the loss-network interaction with deep relative trust to bound weight-functional perturbations, creating a majorization that can be minimized without learning rate tuning. Core assumption: The functional perturbation can be bounded by weight perturbations through deep relative trust, and the loss function's Bregman divergence provides a tractable form for the majorization. Break condition: The deep relative trust bound becomes invalid if weight perturbations grow too large relative to current weights, or if the Bregman divergence approximation fails for non-convex regions of the loss landscape.

### Mechanism 2
The algorithm automatically scales updates based on network architecture through dimensional scaling prescriptions. By prescribing that weight norms scale with the square root of layer dimensions and update norms scale with depth, the algorithm creates a self-tuning system where larger networks receive proportionally smaller updates. Core assumption: The prescribed dimensional scaling ensures that the telescoping product of weight norms remains bounded and that update sizes remain appropriate across different architectures. Break condition: The dimensional scaling breaks if network architectures deviate significantly from the prescribed form, or if the relationship between layer dimensions and optimal update sizes changes across different tasks.

### Mechanism 3
The algorithm converges to critical points at a rate inversely proportional to the square root of iterations. By bounding the gradient summary and showing it decreases as 1/√T, the algorithm guarantees convergence without requiring manual learning rate scheduling. Core assumption: The gradient summary provides a valid measure of progress toward critical points, and the bound on its decrease holds across different network architectures and datasets. Break condition: The convergence rate breaks if the gradient summary becomes dominated by noise, or if the network architecture creates pathological optimization landscapes that violate the underlying assumptions.

## Foundational Learning

- Concept: Bregman divergence and its properties in convex analysis
  - Why needed here: It provides the mathematical framework for measuring the difference between the actual loss and its linear approximation, which is essential for the majorization step
  - Quick check question: Can you explain why the Bregman divergence of a convex function is always non-negative?

- Concept: Matrix norms and singular value decomposition
  - Why needed here: The algorithm relies on operator norms and stable ranks to characterize weight matrices and their perturbations, which requires understanding how these norms relate to network behavior
  - Quick check question: Given a matrix with singular values 3, 1, 0.1, what are its operator norm, Frobenius norm, and stable rank?

- Concept: Deep relative trust and perturbation theory for compound operators
  - Why needed here: It provides the theoretical foundation for bounding how weight perturbations affect network outputs, which is crucial for deriving the automatic update rules
  - Quick check question: How does the deep relative trust bound change as network depth increases, assuming fixed weight norms?

## Architecture Onboarding

- Component map: Initialization (orthogonal weight matrices scaled by dimensional factors) -> Forward pass -> Loss computation -> Backward pass -> Gradient summary aggregation -> Learning rate calculation -> Weight update, repeated for each iteration
- Critical path: Forward pass → loss computation → backward pass → gradient summary aggregation → learning rate calculation → weight update, repeated for each iteration
- Design tradeoffs: The algorithm trades computational overhead (additional gradient norm calculations) for eliminating hyperparameter tuning, and sacrifices some flexibility in update rules for automatic scaling
- Failure signatures: Training stalls (learning rate collapses to zero), training diverges (learning rate grows uncontrollably), or poor generalization (network overfits despite automatic regularization absence)
- First 3 experiments:
  1. Train a 2-layer fully-connected network on MNIST with square loss, compare convergence to Adam with tuned learning rate
  2. Train a 4-layer fully-connected network on CIFAR-10 with varying widths, verify automatic scaling works across architectures
  3. Train a small convolutional network on CIFAR-10, test the per-submatrix normalization scheme for convolutional layers

## Open Questions the Paper Calls Out

### Open Question 1
How would AGD perform on transformer architectures, and what modifications would be needed to adapt the Bregman divergence approach? The paper suggests exploring more architectures like transformers in future work, noting that most neural networks resemble fully-connected networks as they are all just deep compound operators. This remains unresolved because the current theoretical framework is derived specifically for fully-connected networks, and extending it to attention-based architectures would require understanding how weight perturbations affect the self-attention mechanism.

### Open Question 2
What is the theoretical justification for the observed two-phase training behavior in larger networks, where the automatic learning rate initially increases slowly before rapidly decreasing? While the paper presents convergence rates, it does not explain the mechanism behind this specific two-phase behavior or why it correlates with reaching 100% training accuracy.

### Open Question 3
Can the Bregman divergence framework be extended to handle regularization terms without introducing hyperparameters? The paper explicitly states that regularization was not considered in the current work, noting that "when it comes to regularization at least one hyperparameter may become necessary." This remains unresolved because the current majorisation-minimisation framework focuses purely on the optimization structure and does not address how regularization terms like weight decay or dropout would fit into the Bregman divergence formulation.

### Open Question 4
What is the optimal way to handle batch normalization layers within the AGD framework? The paper disables affine parameters in batch normalization layers because AGD does not yet support them, and adopts a per-submatrix normalization scheme for convolutional layers. This remains unresolved because the current implementation sidesteps batch normalization rather than integrating it properly into the optimization framework.

## Limitations
- Theoretical convergence guarantees assume square loss while cross-entropy experiments lack corresponding theoretical backing
- Limited empirical validation of deep relative trust bound tightness across different architectures
- Computational overhead from additional gradient norm calculations and summary statistics not quantified

## Confidence

**High confidence:** The dimensional scaling prescriptions and their mathematical derivation (mechanism 2)

**Medium confidence:** The convergence rate analysis for square loss (mechanism 3)

**Low confidence:** The claim that AGD matches tuned optimizers on cross-entropy tasks without empirical validation of the underlying assumptions
