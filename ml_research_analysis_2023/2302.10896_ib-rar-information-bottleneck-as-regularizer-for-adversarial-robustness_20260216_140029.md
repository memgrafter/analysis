# IB-RAR: Information Bottleneck as Regularizer for Adversarial Robustness

## Quick Facts
- arXiv ID: 2302.10896
- Source URL: https://arxiv.org/abs/2302.10896
- Reference count: 40
- Primary result: IB-RAR achieves 3.07% average improvement against five adversarial attacks for VGG16 on CIFAR-10

## Executive Summary
This paper introduces IB-RAR, a method that leverages Information Bottleneck (IB) theory to enhance adversarial robustness for both adversarial training and standard training approaches. The core idea involves using IB as a regularizer in the loss function to filter out unnecessary features in intermediate network representations based on their mutual information with labels. Experimental results demonstrate that IB-RAR consistently improves accuracy on adversarial examples, achieving an average improvement of 3.07% against five adversarial attacks for the VGG16 network trained with three adversarial training benchmarks on the CIFAR-10 dataset.

## Method Summary
IB-RAR combines Information Bottleneck regularization with adversarial training by minimizing mutual information between inputs and intermediate features while maximizing relevance to targets. The method uses HSIC to compute mutual information terms I(X,Tl) and I(Y,Tl), applies IB loss to selected "robust layers," and filters feature channels based on their mutual information with labels. The approach can be naturally combined with existing adversarial training methods like PGD, TRADES, and MART, providing consistent improvements in adversarial accuracy.

## Key Results
- 3.07% average improvement against five adversarial attacks (PGD, CW, FGSM, FAB, NIFGSM) for VGG16 on CIFAR-10
- IB-RAR provides robustness for undefended methods, achieving 35.86% accuracy against PGD examples without adversarial training
- Using partial layers (robust layers) for IB regularization provides better adversarial robustness than using all layers

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Information Bottleneck regularization removes noise and irrelevant features from intermediate representations, improving adversarial robustness.
- Mechanism: The IB loss function minimizes mutual information between inputs and intermediate features (I(X,Tl)) while maximizing relevance to targets (I(Y,Tl)). This dual optimization compresses inputs to remove noise while preserving task-relevant information.
- Core assumption: Adversarial perturbations exploit non-robust features that are present in the network's intermediate representations.
- Evidence anchors:
  - [abstract] "Experimental results show that our method can be naturally combined with adversarial training and provides consistently better accuracy on new adversarial examples."
  - [section] "The IB is supposed to find the optimal trade-off between compression of input X and prediction of Y [22]."
  - [corpus] Weak - no direct evidence in corpus about IB removing noise, but related papers discuss IB objectives and regularization.
- Break condition: If adversarial attacks exploit features that are actually relevant to the task (not just noise), compression could harm accuracy.

### Mechanism 2
- Claim: Filtering feature channels based on mutual information with labels removes unnecessary features that could be exploited by adversarial attacks.
- Mechanism: After training with IB loss, feature channels are evaluated based on their mutual information with labels. Channels with low MI are removed using a mask, eliminating features that are not informative for classification.
- Core assumption: The network's feature channels have varying degrees of relevance to the classification task, and some can be safely removed without harming accuracy.
- Evidence anchors:
  - [section] "We evaluate feature channels given by the last convolutional layer according to their MI to the target Y."
  - [section] "Channels with MI less than the threshold are removed."
  - [corpus] Weak - corpus doesn't mention feature channel filtering, but related work discusses representation learning and feature selection.
- Break condition: If adversarial attacks can exploit the remaining high-MI features, or if the threshold selection removes too many useful features.

### Mechanism 3
- Claim: Using partial layers for IB regularization (robust layers) provides better adversarial robustness than using all layers.
- Mechanism: Different layers contribute differently to adversarial robustness. The method identifies "robust layers" that provide higher accuracy under attack, and applies IB regularization only to these layers.
- Core assumption: Not all intermediate representations are equally useful for defending against adversarial attacks; some layers are more critical than others.
- Evidence anchors:
  - [section] "We find that deploying IB to different hidden layers will provide different robustness... Using a part of hidden layers for IB can get higher adversarial robustness than all layers or a single layer."
  - [section] "We empirically show that using partial layers to compute IB loss is better."
  - [corpus] Weak - no direct evidence in corpus about layer selection, but related papers discuss layer-wise analysis and feature importance.
- Break condition: If the identification of "robust layers" is incorrect or if adversarial attacks can exploit features from non-robust layers.

## Architecture Onboarding

- Component map:
  Input data pipeline → Convolutional blocks → Fully connected layers → IB regularization modules → Loss function (CE + IB) → Mask generation → Feature channel filtering → Output

- Critical path:
  1. Forward pass through network to get intermediate representations
  2. Compute MI between representations and inputs/targets using HSIC
  3. Apply IB loss to robust layers
  4. Backpropagate combined loss (CE + IB)
  5. Generate mask based on final layer's feature channel MI
  6. Apply mask to filter features during inference

- Design tradeoffs:
  - Using all layers vs. partial layers for IB regularization (robust layers provide better results)
  - Threshold selection for feature channel removal (5% empirically works well)
  - Choice of MI estimation method (HSIC used instead of direct MI computation)

- Failure signatures:
  - Natural accuracy drops significantly after feature channel filtering
  - Adversarial accuracy doesn't improve or degrades after applying IB regularization
  - Network fails to converge during training

- First 3 experiments:
  1. Train VGG16 on CIFAR-10 with CE loss only, evaluate accuracy on clean and adversarial examples
  2. Apply IB regularization to all layers, compare performance with experiment 1
  3. Apply IB regularization only to robust layers (identified from experiment 2), compare with previous results and check feature channel removal effect

## Limitations
- Evaluation focuses primarily on VGG16 architecture and CIFAR-10 dataset, limiting generalizability
- Identification of "robust layers" is based on empirical observation rather than theoretical guarantees
- HSIC-based MI estimation introduces computational overhead and approximation errors
- Feature channel masking assumes that removing low-MI channels won't harm task-relevant information

## Confidence

- **High Confidence**: The core IB-RAR framework combining IB regularization with adversarial training shows consistent improvements across different benchmarks. The empirical results demonstrating 3.07% average improvement against five attacks are well-supported.
- **Medium Confidence**: The identification of robust layers as Conv Block 5, FullyC 1, and FullyC 2 is based on empirical observation for VGG16, but may not generalize to other architectures. The 5% threshold for feature channel removal works empirically but lacks theoretical justification.
- **Low Confidence**: The claim that IB-RAR provides robustness for undefended methods (CE-only training) achieving 35.86% accuracy is promising but based on limited experiments. The generalization to larger datasets and different network architectures remains uncertain.
