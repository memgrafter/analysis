# UniHD at TSAR-2022 Shared Task: Is Compute All We Need for Lexical Simplification?

## Quick Facts
- arXiv ID: 2301.01764
- Source URL: https://arxiv.org/abs/2301.01764
- Reference count: 22
- Beats competing approaches by wide margin in few-shot settings

## Executive Summary
This work presents a simple yet effective approach to lexical simplification using few-shot prompts from a very large language model (vLLM). The method achieves state-of-the-art results on the TSAR-2022 shared task by utilizing an ensemble of six different prompt templates with varying context levels, outperforming competing approaches in settings with few training instances. The approach is further extended to Spanish and Portuguese through minimal prompt adaptation, demonstrating effective cross-lingual transfer capabilities.

## Method Summary
The method employs few-shot prompting with GPT-3 text-davinci-002, using an ensemble of six different prompt templates with varying context levels and shot settings. Predictions are combined using a scoring function that weights suggestions based on their rank across templates. Post-filtering operations remove invalid suggestions including hallucinations, multi-word expressions, and identity predictions. For cross-lingual transfer, prompts are translated to Spanish or Portuguese while maintaining the same structure and constraints.

## Key Results
- Achieved state-of-the-art results on TSAR-2022 shared task across English, Spanish, and Portuguese
- Ensemble approach significantly outperforms individual prompt templates
- Cross-lingual transfer achieved with minimal prompt adaptation
- Computational cost remains a significant limitation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Large language models with sufficient parameters can perform lexical simplification tasks effectively without specialized training.
- Mechanism: The vLLM's emergent capabilities allow it to understand context and generate appropriate simpler alternatives for complex words through few-shot prompting.
- Core assumption: The model has learned sufficient semantic relationships and contextual understanding during pre-training to handle lexical simplification as a zero/few-shot task.
- Evidence anchors:
  - [abstract] "beat competing approaches by a wide margin in settings with few training instances"
  - [section] "utilizing few-shot prompts based on a vLLM with basic instructions on simplification"
- Break condition: If the model hasn't encountered sufficient training data covering the specific semantic relationships needed for simplification, or if the prompt template fails to properly communicate the task requirements.

### Mechanism 2
- Claim: Ensemble approaches with multiple prompt templates reduce variance and improve prediction quality.
- Mechanism: Different prompt templates (with/without context, different temperatures) generate diverse candidate suggestions, and the ensemble scoring function combines these to produce more reliable results.
- Core assumption: The variability between different prompt templates is complementary rather than redundant, and combining them produces better results than any single prompt.
- Evidence anchors:
  - [abstract] "Our best-performing submission to the English language track... consists of an 'ensemble' of six different prompt templates"
  - [section] "an ensemble of predictions from multiple different prompt templates was utilized to broaden the spectrum of possible generations"
- Break condition: If all prompt templates generate similar incorrect suggestions, or if the scoring function doesn't properly weight the contributions from different templates.

### Mechanism 3
- Claim: The model can transfer simplification capabilities across languages with minimal prompt adaptation.
- Mechanism: By changing only the prompt language instruction (e.g., "list ten alternative Spanish words"), the same model can perform lexical simplification in other languages.
- Core assumption: The model has been trained on sufficient multilingual data to understand cross-lingual semantic relationships and can apply English-based simplification knowledge to other languages.
- Evidence anchors:
  - [abstract] "a language transfer technique that allows simplification in languages other than English... Applied to the Spanish and Portuguese subset, we achieve state-of-the-art results"
  - [section] "Transferring the prompts to Spanish or Portuguese is surprisingly simple... we ensure that the suggestions match the expected results"
- Break condition: If the model lacks sufficient training data in the target language, or if the semantic relationships between languages don't align well enough for effective transfer.

## Architecture Onboarding

- Component map: Input layer -> Prompt generator -> API interface -> Parser/filter -> Scoring engine -> Output layer
- Critical path: Context sentence → Prompt template selection → API call → Response parsing → Filtering → Ensemble scoring → Output ranking
- Design tradeoffs:
  - Single prompt vs. ensemble: Single prompt is 6x cheaper but less robust; ensemble provides better coverage at higher cost
  - Context inclusion: Context-aware prompts may be more accurate but increase token count and cost
  - Filtering strictness: More aggressive filtering improves quality but may eliminate valid suggestions
- Failure signatures:
  - Low prediction diversity: Suggests prompt templates aren't generating sufficiently different outputs
  - High hallucination rate: Indicates filtering parameters need adjustment or prompts need restructuring
  - Language inconsistency: Shows transfer prompts aren't properly constraining output language
- First 3 experiments:
  1. Test single prompt with conservative temperature on 10 sample instances to establish baseline performance and identify filtering issues
  2. Run all 6 ensemble prompts on the same 10 samples to compare coverage and identify which templates perform best
  3. Test cross-lingual transfer by running English prompts (modified for Spanish) on Spanish samples to verify language transfer works as expected

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the computational cost of this approach be reduced while maintaining performance?
- Basis in paper: [explicit] The paper discusses computational limitations and costs as a significant concern, noting that each prediction requires a large budget and that the total cost for computing predictions across the test set was around $7-$10.
- Why unresolved: The paper acknowledges the computational cost but does not propose specific solutions or experiments to reduce it while maintaining the high performance achieved by the ensemble approach.
- What evidence would resolve it: Experiments demonstrating that alternative, less computationally expensive models or techniques can achieve similar performance metrics (ACC@1, MAP@k, etc.) as the ensemble approach while significantly reducing computational costs.

### Open Question 2
- Question: How does the variability in prompt templates affect the stability and reproducibility of results?
- Basis in paper: [explicit] The paper mentions that even slight alterations in prompt templates can lead to significant variability in results, including instances where the model predicts fewer than the requested number of answers.
- Why unresolved: The paper identifies the issue of variability in prompt templates but does not conduct a thorough investigation into how different prompt variations affect the consistency of results or propose methods to stabilize prompt performance.
- What evidence would resolve it: A systematic study comparing the performance of different prompt templates across multiple runs to quantify the variability and identify patterns or guidelines for creating stable and reproducible prompts.

### Open Question 3
- Question: What is the impact of hallucinations and multi-word expressions on the utility of the simplified words for the end user?
- Basis in paper: [explicit] The paper discusses hallucinations and the generation of multi-word expressions as errors, noting that while some expressions might be more helpful for understanding, they are not precisely matching expected outputs.
- Why unresolved: The paper identifies these issues but does not evaluate the actual usefulness of these generated expressions from the perspective of the end user or compare the comprehension level with simpler, more precise synonyms.
- What evidence would resolve it: User studies or comprehension tests comparing the effectiveness of single-word synonyms versus multi-word expressions in aiding understanding, to determine if the more descriptive but less precise expressions are actually beneficial for users.

## Limitations
- High computational cost makes the approach prohibitively expensive for large-scale applications
- Full prompt templates for Spanish/Portuguese are not provided in the paper
- Performance may not generalize well beyond the controlled shared task environment

## Confidence
- **High confidence**: The approach works effectively for English lexical simplification in the controlled shared task environment
- **Medium confidence**: Cross-lingual transfer capabilities for Spanish and Portuguese, while promising, were only tested on the specific shared task dataset
- **Low confidence**: Claims about the mechanism underlying few-shot learning effectiveness lack direct empirical support

## Next Checks
1. Ablation study on prompt templates: Run the system with individual prompt templates (rather than ensemble) on the same test set to quantify the marginal contribution of each template and validate the ensemble approach
2. Cost-performance tradeoff analysis: Measure accuracy degradation when reducing the number of prompt templates or shot settings, and establish minimum viable configurations for different budget constraints
3. Cross-domain generalization test: Evaluate the approach on a held-out dataset from a different domain (e.g., medical or technical text) to assess robustness beyond the shared task vocabulary and contexts
