# Uncovering the Background-Induced bias in RGB based 6-DoF Object Pose Estimation

## Quick Facts
- arXiv ID: 2304.08230
- Source URL: https://arxiv.org/abs/2304.08230
- Reference count: 38
- This study analyzes how ArUco markers in the Linemod dataset create background-induced bias in 6-DoF object pose estimation.

## Executive Summary
This paper investigates how ArUco markers in the Linemod dataset create a background-induced bias in RGB-based 6-DoF object pose estimation. The authors find that pose estimation models learn to use marker board geometry as a shortcut rather than inferring pose from object features alone. To address this, they create an ArUco-Free Linemod dataset by masking markers and demonstrate through Grad-CAM saliency maps that networks shift focus from object features to marker features when markers are present. Quantitative results show that training on marker-free data improves performance on marker-free test images, though full generalization remains challenging.

## Method Summary
The authors created an ArUco-Free Linemod dataset by masking ArUco markers using geometric tools based on ground truth 3D object poses. They trained EfficientPose models on both original and marker-free datasets, then evaluated performance using ADD and ADD-S metrics. Saliency maps (Vanilla Saliency and Grad-CAM) were generated to visualize network focus on markers versus objects. The study focused on object classes 1 (Ape), 5 (Can), and 11 (Glue) to analyze how marker presence affects pose estimation accuracy and generalization.

## Key Results
- Models trained on original Linemod with markers show significant performance degradation on marker-free test images
- Training on ArUco-free dataset improves performance on marker-free test images but full generalization remains incomplete
- Grad-CAM saliency maps reveal networks focus on markers rather than object features when markers are present
- The background-induced bias demonstrates that models exploit spatial shortcuts rather than learning object-specific pose features

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ArUco markers create a background-induced bias because the pose estimation network learns to use the marker board geometry as a shortcut rather than inferring object pose from object features alone.
- Mechanism: The marker board provides fixed spatial context (e.g., object always centered on the board, board pose recoverable from markers). The network exploits this shortcut by correlating board position with object pose, bypassing the need to learn object-specific features. This shortcut is not available in marker-free environments.
- Core assumption: The network is capable of learning shortcuts from dataset bias when they are consistently available during training.
- Evidence anchors:
  - [abstract] "We analyze how the presence of the markers affects the pose estimation accuracy, and how this bias may be mitigated through data augmentation and other methods."
  - [section] "We hypothesize that some models could leverage the aspect of other visible objects to infer the 6D pose for the target object in an unintended way."
- Break condition: If the object is never centered on the board or if markers vary in position/orientation relative to the object across training samples, the shortcut becomes unreliable and the network must learn object features.

### Mechanism 2
- Claim: Grad-CAM saliency maps reveal the bias by showing the network's focus shifts from object features to marker features when markers are present.
- Mechanism: Grad-CAM computes gradients of the pose regression output with respect to convolutional feature maps. When markers are present, these gradients highlight marker regions as important for pose prediction. When markers are masked, the saliency shifts to other regions, but often fails to consistently identify object features.
- Core assumption: The pose regression output is differentiable with respect to the feature maps, and the gradient magnitudes correlate with feature importance.
- Evidence anchors:
  - [section] "the saliency analysis showed that the network definitely utilizes 6D pose information from visible markers and background objects."
  - [section] "For object 1 the saliency is not on the markers, however, the network doesn't focus on the ape, looking for information in other background objects."
- Break condition: If the regression head uses non-differentiable operations or if the feature maps are too abstract for gradients to capture meaningful spatial information.

### Mechanism 3
- Claim: Training on an ArUco-free dataset reduces the background-induced bias by forcing the network to learn object features instead of relying on marker-based shortcuts.
- Mechanism: Removing markers eliminates the consistent spatial context that enabled the shortcut. The network must now learn to infer object pose from object appearance and geometry alone, leading to better generalization to marker-free test images.
- Core assumption: The network can learn to extract sufficient pose information from object features when marker-based shortcuts are unavailable.
- Evidence anchors:
  - [abstract] "Quantitative results show that training on the marker-free dataset improves performance on marker-free test images, but models still struggle to generalize fully."
  - [section] "the model trained on the dataset without markers achieves better results."
- Break condition: If the object appearance lacks sufficient discriminative features for pose estimation, the network cannot learn effective pose prediction even without markers.

## Architecture Onboarding

- Component map: Input RGB image -> Backbone feature extractor (EfficientNet) -> Detection head (class + bounding box) -> Rotation regression head (with iterative refinement) -> Translation regression head
- Critical path: Input RGB image → Backbone feature extraction → Rotation regression head → Saliency map computation via Grad-CAM → Pose estimation output
- Design tradeoffs: The paper chose to mask markers rather than remove them entirely, which may leave residual bias from the black squares. Alternative approaches could include using different marker styles or varying marker positions.
- Failure signatures: Performance collapse when testing on marker-free images after training on marker-present images, saliency maps focusing on markers rather than objects, inability to detect objects when markers are absent.
- First 3 experiments:
  1. Train EfficientPose on original Linemod dataset, test on both original and ArUco-free test sets, compare ADD(-S) metrics.
  2. Train EfficientPose on ArUco-free dataset, test on both original and ArUco-free test sets, compare ADD(-S) metrics.
  3. Compute Grad-CAM saliency maps for both models on both test sets, analyze focus regions and compare to ground truth object locations.

## Limitations
- Narrow focus on Linemod dataset and ArUco markers limits generalizability to other marker types or datasets
- Masking approach leaves residual bias from black square backgrounds rather than completely removing marker influence
- Does not explore alternative marker styles or varied marker positions that could provide stronger evidence for proposed mechanisms

## Confidence
- **High**: The existence of background-induced bias and its measurable impact on performance metrics (ADD/ADD-S)
- **Medium**: The mechanism by which markers create shortcuts in pose estimation, though the evidence is largely correlational
- **Medium**: The effectiveness of marker-free training in reducing bias, though generalization remains incomplete
