# Multilingual Word Error Rate Estimation: e-WER3

## Quick Facts
- arXiv ID: 2304.00649
- Source URL: https://arxiv.org/abs/2304.00649
- Reference count: 0
- Multilingual e-WER3 achieves up to 0.74 Pearson correlation for WER estimation

## Executive Summary
This paper introduces e-WER3, a multilingual framework for estimating word error rate (WER) in automatic speech recognition systems without requiring internal ASR states or manual transcriptions. The model jointly trains on acoustic and lexical representations, leveraging XLSR-53 for phoneme-aware speech features and XLM-RoBERTa for lexical embeddings. Evaluated across five languages (Arabic, English, Italian, Spanish, and Russian), e-WER3 demonstrates improved WER prediction accuracy with Pearson correlation coefficients up to 0.74, outperforming previous monolingual models by up to 9% absolute.

## Method Summary
e-WER3 is a multilingual regression model that estimates WER from raw audio and ASR transcriptions. The architecture combines acoustic features extracted using XLSR-53 with lexical embeddings from XLM-RoBERTa. Acoustic features pass through a BiLSTM layer, while lexical embeddings are averaged. These representations are concatenated and processed through two fully-connected layers before regression to predict WER values between 0 and 1. The model is trained jointly across multiple languages, allowing it to leverage shared latent spaces for improved performance on related languages.

## Key Results
- Multilingual e-WER3 achieves Pearson correlation coefficient of up to 0.74 across five languages
- Outperforms previous monolingual models (eWER and eWER2) by up to 9% absolute correlation improvement
- Demonstrates strong WER prediction at both utterance and aggregate levels
- Italian benefits more from English monolingual model (RMSE: 0.19) than Arabic model (RMSE: 0.32), indicating advantages of shared latent spaces for related languages

## Architecture Onboarding

- Component map: Raw audio → XLSR-53 → BiLSTM → Frame-wise representations; ASR transcription → XLM-RoBERTa → Averaged embeddings → Concatenation → 2 FC layers → WER prediction

- Critical path: Audio → XLSR-53 → BiLSTM → Concatenate with lexical → FC layers → WER prediction

- Design tradeoffs:
  - Using pre-trained models speeds up training but limits architectural flexibility
  - Joint training captures cross-modal information but increases model complexity
  - Multilingual approach benefits related languages but may dilute language-specific performance

- Failure signatures:
  - High RMSE but low PCC: Model predicts WER values with poor correlation but good absolute error
  - Low PCC: Model fails to capture the relationship between input features and WER
  - Discrepancy between utterance-level and aggregate WER: Model performs well on individual samples but poorly on overall metrics

## Limitations

- Evaluation covers only five languages with relatively small test sets (120-1037 utterances), limiting generalizability
- Reported improvements over previous models are based on within-paper comparisons without external validation
- Model's performance on distant language pairs shows mixed results, suggesting shared latent space benefits may not extend uniformly across all language combinations
