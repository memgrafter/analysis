# Accelerating Multi-Agent Planning Using Graph Transformers with Bounded Suboptimality

## Quick Facts
- arXiv ID: 2301.08451
- Source URL: https://arxiv.org/abs/2301.08451
- Reference count: 40
- Primary result: Graph Transformer heuristic accelerates CBS for non-grid MAPF with significant improvements in success rate and computation time while maintaining completeness and bounded-suboptimality

## Executive Summary
This paper addresses the challenge of multi-agent path finding (MAPF) in non-grid-based environments with dense graphs. The authors propose a novel approach that uses a Graph Transformer as a learned heuristic function within Conflict-Based Search (CBS) to guide the search towards promising nodes with feasible solutions. The method combines graph tokenization via Graph Neural Networks with attentive aggregation through Transformers, trained using a contrastive loss to rank solution feasibility. Experiments demonstrate significant performance improvements over state-of-the-art baselines while maintaining theoretical guarantees.

## Method Summary
The method accelerates CBS for non-grid MAPF by integrating a Graph Transformer as a heuristic function. The architecture consists of two stages: first, a Graph Neural Network tokenizes the graph vertices and edges into embeddings; second, a Transformer encoder models inter-agent interactions while handling variable-length inputs. The model is trained using a contrastive loss that ranks positive samples (nodes with feasible solutions) above negative samples based on their depth in the CBS search tree. Focal search maintains a fraction of leaf search nodes satisfying near-optimal solution quality, selecting nodes based on the learned heuristic ψ instead of solution cost. This approach guarantees completeness and bounded-suboptimality while significantly improving success rates and computation time.

## Key Results
- The Graph Transformer method outperforms CBS, ECBS, and ORCA baselines in success rate and computation time on dense graph environments
- The approach generalizes well to unseen instances with higher agent counts (tested up to 26 agents despite training on ≤4 agents)
- The method maintains theoretical guarantees of completeness and bounded-suboptimality while achieving practical speedups

## Architecture Onboarding

- Component map: Graph → GNN → Temporal Encoding → Agent Identifiers → Transformer → Prediction
- Critical path: Graph input passes through GNN for tokenization, then through temporal encoding and agent identifier concatenation, followed by Transformer encoder for attentive aggregation, and finally a prediction layer outputs the heuristic value
- Design tradeoffs:
  - Using a GNN for graph tokenization allows handling variable-sized graphs but may not capture long-range dependencies
  - Using a Transformer for attentive aggregation enables modeling inter-agent interactions but may be computationally expensive for large numbers of agents
- Failure signatures:
  - If the model fails to generalize to unseen instances, it may indicate overfitting or insufficient training data
  - If the model's predictions are inconsistent across different input permutations, it may indicate issues with the Transformer's invariance properties
- First 3 experiments:
  1. Test the model's ability to handle variable-sized graphs by training and evaluating on graphs with different numbers of vertices and edges
  2. Evaluate the model's generalization to unseen instances by training on a subset of instances and testing on the remaining instances
  3. Analyze the model's sensitivity to the temporal encoding and agent identifier components by training variants without these components and comparing their performance

## Limitations

- The Graph Transformer's performance with significantly larger agent counts (10x-100x) than tested remains unknown and is explicitly acknowledged as future work
- The computational overhead of Graph Transformer inference during CBS execution is not thoroughly analyzed
- The method has only been tested on dense graph environments, limiting generalizability to sparse or differently structured graphs
