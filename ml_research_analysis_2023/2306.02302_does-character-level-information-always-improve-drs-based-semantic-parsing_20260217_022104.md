# Does Character-level Information Always Improve DRS-based Semantic Parsing?

## Quick Facts
- arXiv ID: 2306.02302
- Source URL: https://arxiv.org/abs/2306.02302
- Reference count: 9
- Key outcome: Character-level information improves DRS parsing only in Italian, not in English or German, while Dutch models show no sensitivity to character order

## Executive Summary
This paper investigates whether character-level information contributes to semantic parsing performance in Discourse Representation Structures (DRS) across four languages: English, German, Dutch, and Italian. The study compares model performance using correct, shuffled, and randomized character sequences, as well as single-character and bigram character representations. The experiments reveal that character-level information does not consistently improve performance across languages, with notable differences between English/German (no improvement) and Italian (performance gains), while Dutch models show no sensitivity to character order manipulation.

## Method Summary
The study uses the Parallel Meaning Bank (PMB) release 3.0.0 gold test sets for evaluation across four languages. The model architecture consists of two bi-LSTM encoders: one for BERT/mBERT embeddings and semantic tags (for English), and another for character-level representations. The experiments include four character manipulation conditions (UNI, SHF-WORD, SHF-SENT, RND) and compare unigram versus bigram character representations. Models are evaluated using micro-averaged F1-scores with standard error across 15 runs, using Counter and Referee tools for evaluation.

## Key Results
- Character-level information does not improve DRS parsing performance in English and German
- Dutch models show no sensitivity to character order, maintaining stable performance across all character manipulation conditions
- Italian models show performance improvements when using character-level information, with sensitivity to character order
- Bigram character representations provide improvements in German, Dutch, and Italian compared to unigrams

## Limitations
- The study is limited to four languages from a single corpus, which may not generalize to other language families or domains
- The experimental design focuses on character-level representations without exploring alternative approaches such as morphological analysis or subword tokenization
- The study does not investigate the interaction between character-level information and different model architectures beyond the specific bi-LSTM + BERT/mBERT setup used

## Confidence
- High Confidence: Character-level information does not improve performance in English and German; Dutch models show no sensitivity to character order
- Medium Confidence: Performance improvements observed in Italian; character-level information importance is language-dependent
- Low Confidence: Specific mechanisms by which character-level information affects model performance; bigram effectiveness claims
