# GULP: Solar-Powered Smart Garbage Segregation Bins with SMS Notification and Machine Learning Image Processing

## Quick Facts
- arXiv ID: 2304.13040
- Source URL: https://arxiv.org/abs/2304.13040
- Reference count: 8
- Key outcome: Solar-powered smart bin with CNN-based image classification achieved 98% accuracy and ISO/IEC 25010 score of 4.55/5.0

## Executive Summary
This paper presents GULP, a solar-powered smart garbage bin that automatically segregates waste into biodegradable, non-biodegradable, and recyclable categories using machine learning image processing. The system employs a Raspberry Pi 4 with a Convolutional Neural Network (CNN) for real-time classification, ultrasonic sensors for fill-level monitoring, and GSM SMS notifications for staff alerts. Tested with 1,151 garbage images, the system achieved 98% prediction accuracy and received an excellent ISO/IEC 25010 evaluation score of 4.55/5.0. The bin operates autonomously using solar power with battery backup, providing an efficient and engaging waste management solution for institutional settings.

## Method Summary
The system was developed using an Agile methodology with six phases: planning, design, development, testing, release, and feedback. A Raspberry Pi 4 captures images of deposited waste, which are classified by a CNN trained on 1,151 labeled garbage images using Lobe.ai with a Resnet50-V2 architecture. Based on classification results, servo motors rotate to direct waste into the appropriate bin, while ultrasonic sensors monitor fill levels and trigger SMS alerts via a GSM module when bins reach capacity. The entire system is powered by a 200W solar panel charging a 105Ah battery through a PWM charge controller, with an inverter providing AC power to all components.

## Key Results
- Achieved 98% prediction accuracy on waste classification using 1,151 training images
- ISO/IEC 25010 evaluation score of 4.55/5.0 (excellent) across functionality, usability, reliability, and performance
- Autonomous operation using solar power with battery backup for 24/7 functionality

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Solar-powered operation eliminates dependence on grid electricity, enabling autonomous deployment.
- Mechanism: A 200W monocrystalline solar panel charges a 105Ah battery via a PWM charge controller. The inverter converts stored DC to AC to power Raspberry Pi, motors, and sensors. Battery protection board prevents over-discharge.
- Core assumption: Solar irradiance is sufficient to recharge the battery within daylight hours and maintain overnight operation.
- Evidence anchors:
  - [abstract]: "The bin operates independently using solar power with battery backup"
  - [section]: "Solar panels produce direct current (DC) electricity, which was transformed into alternating current (AC) electricity using the 12V DC to 220-230V AC Car Home Solar Power Inverter"
- Break condition: Persistent overcast weather or shading reduces charge rate below consumption, causing system shutdown.

### Mechanism 2
- Claim: Convolutional Neural Network image classification accurately segregates waste into biodegradable, non-biodegradable, and recyclable bins.
- Mechanism: Raspberry Pi 4 captures images, Lobe.ai trains ResNet50-V2 model on 1,151 labeled garbage images achieving 98% accuracy. Image fed to CNN, which outputs class probability; servo motor rotates to matching bin, LED indicator signals bin type.
- Core assumption: Training dataset covers sufficient variability in lighting, angle, and garbage appearance to generalize to real inputs.
- Evidence anchors:
  - [abstract]: "Testing with 1,151 garbage images showed 98% prediction accuracy"
  - [section]: "The system used a Convolutional Neural Network (ConvNet/CNN) for the image processing... Lobe.ai was used in training the data sets... utilizing the Resnet50-V2 architectural building block with substantially higher accuracy."
- Break condition: Unseen garbage types or poor lighting degrade classification accuracy below operational threshold.

### Mechanism 3
- Claim: Ultrasonic sensors combined with GSM module trigger SMS alerts when bins reach capacity, preventing overflow.
- Mechanism: Three ultrasonic sensors monitor fill level of each bin. When threshold is exceeded, Raspberry Pi sends SMS via SIM800L GSM module to utility staff. This ensures timely unloading.
- Core assumption: SMS delivery is reliable and staff respond promptly to notifications.
- Evidence anchors:
  - [abstract]: "ultrasonic sensors for bin level detection, and SMS notifications to alert staff when bins are full"
  - [section]: "Finally, the status of the bins will be determined by the ultrasonic sensors in each bin. The data will be sent back to the Raspberry Pi, where it will use the GSM/GPRS Module to generate an SMS alert message"
- Break condition: GSM network outage or invalid SIM prevents message delivery.

## Architecture Onboarding

- Component map: 200W solar panel → PWM charge controller → 105Ah battery → inverter → 12V rail → Raspberry Pi, motors, sensors → Pi camera → CNN inference → servo motor rotation → LED indicators → ultrasonic sensors → level threshold logic → GSM SMS trigger
- Critical path: Garbage placement → lid open → image capture → CNN classification → servo alignment → garbage deposit → LED feedback → ultrasonic check → SMS if full.
- Design tradeoffs: Solar power maximizes autonomy but limits energy budget; CNN accuracy balances speed vs. precision; GSM ensures notification but adds cost.
- Failure signatures:
  - Low battery voltage → system shutdown
  - CNN misclassification → wrong bin deposit
  - Ultrasonic sensor occlusion → false full alerts
  - GSM module fault → missed notifications
- First 3 experiments:
  1. Verify solar charging: measure battery voltage over 24h under various lighting.
  2. Validate ML accuracy: test CNN on held-out images from same distribution.
  3. Confirm SMS delivery: simulate full bin and check notification receipt.

## Limitations
- Long-term solar charging performance under variable weather conditions is not reported, limiting confidence in autonomous operation claims.
- No details on model robustness to out-of-distribution garbage types or adversarial inputs.
- SMS delivery reliability over extended deployments is unverified.

## Confidence
- **High**: Solar-powered operation with battery backup and basic system integration.
- **Medium**: 98% classification accuracy on test images from same distribution.
- **Low**: Sustained autonomous performance and real-world reliability under varying conditions.
