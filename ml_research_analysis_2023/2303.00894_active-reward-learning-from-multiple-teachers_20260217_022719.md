# Active Reward Learning from Multiple Teachers

## Quick Facts
- arXiv ID: 2303.00894
- Source URL: https://arxiv.org/abs/2303.00894
- Reference count: 40
- Key outcome: Bayesian algorithm for active teacher selection in multi-teacher reward learning that can query less rational teachers for more informative feedback

## Executive Summary
This paper addresses the challenge of learning reward functions from multiple human teachers with varying levels of rationality. Traditional reward learning methods typically assume a single teacher source, but practical systems often need to gather feedback from multiple sources to obtain sufficient data. The authors formalize this multi-teacher setting and develop a Bayesian algorithm that actively selects which teacher to query at each step based on their modeled rationality and the learner's current belief about the reward function. The approach is theoretically grounded, with a proof showing that the learner's belief distribution converges to the true reward function under their algorithm.

## Method Summary
The authors develop a Bayesian framework for multi-teacher reward learning that models each teacher's rationality as a latent variable. At each query step, the algorithm computes the expected information gain from querying each available teacher, taking into account both the current reward function belief and the teacher's rationality distribution. This allows the system to strategically select which teacher to query based on who is expected to provide the most informative feedback given the current state of learning. The approach handles uncertainty about both the reward function and teacher rationality, enabling more efficient reward function acquisition than naive approaches that always query the same teacher.

## Key Results
- The learner's belief distribution converges to the true reward function under the proposed algorithm
- Querying less rational teachers can sometimes provide more information than querying more rational ones, as teacher mistakes reveal information about relative values
- Experiments on a restaurant recommendation domain demonstrate that the teacher selection method outperforms baselines like always querying the most rational teacher

## Why This Works (Mechanism)
The algorithm works by maintaining a Bayesian posterior over both the reward function and each teacher's rationality. When a teacher provides feedback, the system updates beliefs about both the reward function and that teacher's rationality level. The active selection mechanism computes the expected information gain from each potential query, allowing the system to strategically choose teachers who will provide the most useful information given the current state of learning. This creates a feedback loop where teacher rationality estimates improve over time, leading to better query selection.

## Foundational Learning
- Bayesian inference: Used to maintain and update beliefs about reward functions and teacher rationality; needed to handle uncertainty in both the true reward and teacher behavior
- Information theory: Expected information gain calculations guide teacher selection; needed to quantify the informativeness of potential queries
- Multi-armed bandit problem: The teacher selection process is analogous to a bandit problem where each "arm" is a teacher with unknown rationality; needed to frame the active selection as an optimization problem

## Architecture Onboarding
**Component map**: Reward function belief -> Teacher rationality models -> Information gain computation -> Teacher selection -> Query execution -> Belief update

**Critical path**: The system iteratively cycles through: (1) compute information gain for each teacher, (2) select teacher with highest expected information gain, (3) query selected teacher, (4) update reward and rationality beliefs, (5) repeat

**Design tradeoffs**: The approach trades computational complexity (maintaining multiple teacher rationality models) for improved learning efficiency. Alternative designs could use simpler teacher selection heuristics but would likely converge more slowly or get stuck in suboptimal solutions.

**Failure signatures**: Poor performance may occur if teacher rationality is highly non-stationary, if there are too few teachers to reliably estimate rationality, or if the rationality model is misspecified relative to actual teacher behavior.

**Three first experiments**: 1) Test on a synthetic domain with known reward function and controlled teacher rationality levels, 2) Compare convergence rates with varying numbers of teachers, 3) Evaluate robustness to misspecified rationality models

## Limitations
- Assumes stationary rationality across teachers, which may not hold in practice
- Results are limited to a single benchmark domain (restaurant recommendation)
- Computational burden of maintaining and updating teacher rationality models in real-time
- Theoretical convergence proof assumes ideal conditions that may not hold with noisy feedback or non-stationary teacher behavior

## Confidence
High: The formalization of the multi-teacher reward learning problem and the Bayesian framework for teacher selection are well-founded theoretically. The convergence proof appears sound under stated assumptions.

Medium: The experimental results showing improved performance over baseline methods are promising but limited by the single benchmark domain. The restaurant recommendation task may not fully capture the complexity of real-world reward learning scenarios.

Low: The claim that querying less rational teachers can be more informative than querying highly rational ones requires further validation. This finding contradicts conventional wisdom and needs to be tested across multiple domains and with different types of rationality models.

## Next Checks
1. Implement and test the algorithm across multiple diverse domains beyond restaurant recommendation to assess generalizability
2. Conduct ablation studies to quantify the contribution of teacher rationality modeling versus active selection strategy
3. Design experiments to validate the counterintuitive finding about less rational teachers providing more information under various conditions
