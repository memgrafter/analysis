# Actor-Critic Methods using Physics-Informed Neural Networks: Control of a 1D PDE Model for Fluid-Cooled Battery Packs

## Quick Facts
- arXiv ID: 2305.10952
- Source URL: https://arxiv.org/abs/2305.10952
- Reference count: 34
- Key outcome: Hybrid-policy actor-critic combining PPO with HJB Value Iteration achieves higher average rewards than either method alone for controlling a 1D PDE model of fluid-cooled battery packs.

## Executive Summary
This paper proposes a hybrid-policy actor-critic algorithm that treats the value network as a Physics-Informed Neural Network (PINN) to solve the Hamilton-Jacobi-Bellman (HJB) equation for controlling a 1D PDE model of fluid-cooled battery packs. The algorithm combines policy optimization from PPO with value network updates from HJB Value Iteration, where the HJB equation is derived by discretizing the PDE system into an ODE. Experiments on the PackCooling environment show that the hybrid-policy model achieves higher average rewards compared to PPO and HJB Value Iteration alone, demonstrating the effectiveness of incorporating physics-informed updates into the value network for improved control of PDE systems.

## Method Summary
The method involves discretizing a 1D PDE model of a fluid-cooled battery pack into an ODE system, then deriving the corresponding HJB equation for optimal control. The value network is trained as a PINN to minimize the residual of the HJB equation using automatic differentiation. An optimal controller is derived analytically from the HJB equation and used alongside the PPO policy to select actions during training. The hybrid approach combines the physics-informed value updates from HJB with the policy optimization from PPO, with actions selected randomly between the PPO policy and the analytical controller.

## Key Results
- HJBPPO achieves higher average rewards than PPO alone and HJB Value Iteration alone in the PackCooling environment
- The hybrid approach successfully combines physics-informed value updates with data-driven policy optimization
- Analytical controller derived from HJB equation provides useful actions that complement the learned PPO policy

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The value network is treated as a PINN to directly solve the continuous-time HJB equation rather than the discrete-time Bellman optimality equation.
- Mechanism: By encoding the HJB equation as a loss function and using automatic differentiation, the value network's parameters are optimized to satisfy the HJB PDE residual, which represents the optimality condition for continuous control.
- Core assumption: The HJB equation accurately characterizes the optimal value function for the discretized PDE system.
- Evidence anchors:
  - [abstract]: "treats the value network as a Physics-Informed Neural Network (PINN) to solve for the continuous-time HJB equation rather than a discrete-time Bellman optimality equation"
  - [section 4.2]: Derivation of the HJB equation for the discretized ODE system and its use as a loss function
- Break condition: If the discretization of the PDE into an ODE introduces significant modeling error, or if the HJB equation cannot be accurately solved by the PINN due to approximation capacity limits.

### Mechanism 2
- Claim: The optimal controller is derived analytically from the HJB equation and used to generate training actions.
- Mechanism: The HJB equation provides a closed-form expression for the optimal control policy as a function of the value function's gradient, allowing direct computation of control actions without requiring a separate policy network.
- Core assumption: The optimal value function is known or can be accurately approximated, enabling the derivation of the optimal controller.
- Evidence anchors:
  - [section 4.2]: "Upon deriving the HJB equation, we also derive an optimal controller" and Corollary 4.2 providing the controller formula
  - [section 5.1]: Algorithm 1 uses the controller from equation (16)
- Break condition: If the value function approximation is poor, the derived controller will be suboptimal; or if the system dynamics are not perfectly captured by the HJB equation.

### Mechanism 3
- Claim: The hybrid-policy method combines the physics-informed value updates from HJB with policy optimization from PPO to achieve better performance than either method alone.
- Mechanism: The HJB equation provides accurate value function updates guided by physical laws, while PPO's policy updates ensure exploration and generalization beyond what the analytical controller provides.
- Core assumption: There exists a complementary relationship between physics-informed value updates and data-driven policy optimization.
- Evidence anchors:
  - [abstract]: "hybrid-policy model that updates the value network using the HJB equation and updates the policy network identically to PPO achieves the best results"
  - [section 5.2]: HJBPPO algorithm description combining PPO policy updates with HJB value updates
- Break condition: If the environment is partially observable or the physics model is inaccurate, the HJB updates may mislead the value function, negating the benefit of the hybrid approach.

## Architecture Onboarding

- Component map:
  - Value network (PINN) -> HJB loss function -> Optimal controller
  - Policy network -> PPO algorithm -> Action selection
  - PackCooling environment -> State observation -> Reward signal
  - Replay buffer -> Transition storage -> Training updates

- Critical path:
  1. State observation from environment
  2. Action selection (randomly choose between PPO policy or optimal controller)
  3. Environment step with selected action
  4. Store transition in replay buffer
  5. Periodically update value network using HJB loss
  6. Periodically update policy network using PPO algorithm
  7. Repeat

- Design tradeoffs:
  - Using analytical controller vs. learned policy: The analytical controller provides optimal actions when the value function is accurate, but limits exploration; the learned policy enables exploration but may be suboptimal
  - HJB equation discretization: Coarser discretization reduces computational cost but may introduce modeling error
  - Action selection probability: The 50/50 random selection balances exploitation of physics knowledge with exploration

- Failure signatures:
  - Value network fails to converge: HJB loss remains high, training curves plateau
  - Controller produces poor actions: Cumulative reward decreases when using analytical controller
  - Policy network ignores analytical controller: PPO policy consistently outperforms controller actions
  - Numerical instability: NaN values appear during training, likely due to discretization issues

- First 3 experiments:
  1. Run HJB Value Iteration alone to verify the value network can learn the HJB equation and produce reasonable controllers
  2. Run PPO alone to establish baseline performance without physics-informed updates
  3. Run HJBPPO with varying action selection probabilities (e.g., 0.2, 0.5, 0.8) to find optimal balance between exploration and exploitation

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How well would the HJBPPO algorithm perform in partially observable environments where the dynamics of the system are unknown?
- Basis in paper: [inferred] The authors mention that HJBPPO may not perform well in partially observable environments because the estimate of the dynamics of the system may be inaccurate.
- Why unresolved: The paper does not provide experimental results or analysis of HJBPPO's performance in partially observable environments.
- What evidence would resolve it: Experimental results comparing HJBPPO's performance in both fully observable and partially observable environments with unknown dynamics.

### Open Question 2
- Question: Can the HJB equation for continuous-time RL be extended to higher dimensional PDEs?
- Basis in paper: [explicit] The authors state "Currently existing works such as (Sirignano & Spiliopoulos (2018)) and (Kalise & Kunisch (2017)) solve the HJB equation for 1D PDEs by discretizing it in x. It will be interesting to see how HJB control can be extended to higher dimensional PDEs."
- Why unresolved: The paper only demonstrates the HJB equation for a 1D PDE model and does not explore higher dimensional cases.
- What evidence would resolve it: Development and experimental validation of HJB equations for higher dimensional PDE systems, such as 2D or 3D heat diffusion or fluid dynamics problems.

### Open Question 3
- Question: What are the potential benefits and challenges of using PINNs to solve the HJB equation and the PDE governing the dynamics of the system, rather than numerical methods?
- Basis in paper: [explicit] The authors mention "An area for further research may be the use of PINNs to solve for the HJB equation and the PDE that governs the dynamics of the system."
- Why unresolved: The paper uses numerical methods (Crank-Nicolson method and method of characteristics) to solve the PDE, but does not explore the use of PINNs for this purpose.
- What evidence would resolve it: Comparative studies demonstrating the accuracy, efficiency, and limitations of using PINNs versus numerical methods for solving the HJB equation and governing PDEs in RL control problems.

## Limitations

- The method requires accurate discretization of the PDE system, which may introduce modeling errors that propagate through the HJB equation and controller
- The approach is demonstrated only for 1D PDEs, and extending to higher dimensional systems remains an open challenge
- The performance in partially observable environments with unknown dynamics is uncertain and may be limited

## Confidence

**High confidence**: The hybrid-policy approach combining PPO with HJB Value Iteration improves performance over PPO alone in the specific PackCooling environment.

**Medium confidence**: The mechanism by which physics-informed updates improve value function learning is valid and transferable to other PDE control problems.

**Low confidence**: The analytical controller derived from the HJB equation will consistently outperform learned policies in complex, partially observable environments.
