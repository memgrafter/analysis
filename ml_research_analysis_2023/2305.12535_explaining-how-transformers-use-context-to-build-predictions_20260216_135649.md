# Explaining How Transformers Use Context to Build Predictions

## Quick Facts
- arXiv ID: 2305.12535
- Source URL: https://arxiv.org/abs/2305.12535
- Reference count: 21
- This paper introduces a method to analyze language generation models by combining residual stream analysis with interpretable attention decomposition.

## Executive Summary
This paper presents a novel approach for understanding how Transformer language models use context to build predictions. The method combines residual stream analysis with interpretable attention decomposition to measure how input tokens contribute to logit updates at each layer, then tracks these updates back to the input using contextual mixing information. The approach is evaluated on GPT-2 models across various linguistic phenomena, showing superior alignment with linguistic evidence compared to gradient- or perturbation-based baselines. The method also reveals the role of MLP layers in promoting grammatically acceptable predictions and demonstrates its applicability to Neural Machine Translation models.

## Method Summary
The proposed method measures logit updates caused by each token representation at each layer and tracks these contributions back to input tokens using contextual mixing information from ALTI (Attention with Linear Transformation and Interpretation). The approach decomposes transformer operations into interpretable components, allowing researchers to analyze how context flows through the model and contributes to final predictions. The method is evaluated using contrastive explanations that compare why a model predicted one token over another, using metrics like Mean Reciprocal Rank (MRR) for alignment with linguistic evidence and Alignment Error Rate (AER) for NMT tasks.

## Key Results
- The Logit and ALTI-Logit methods consistently align better with linguistic evidence than gradient- or perturbation-based baselines
- Layer-wise analysis shows models update more heavily on layers where alignment with linguistic rules is highest
- MLP layers help promote grammatically acceptable predictions in Transformers
- NMT models generate human-like source-target alignments for building translations

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Residual stream analysis combined with interpretable attention decomposition can track how input tokens contribute to predictions at each layer
- **Mechanism:** The method measures logit updates caused by each token representation at each layer, then tracks these updates back to input tokens using contextual mixing information from ALTI
- **Core assumption:** Token representations preserve their identity throughout the layers, or can be traced back using contextual mixing information
- **Evidence anchors:** [abstract] "Our approach measures the amount of logit (pre-activation of the softmax) added or subtracted by each token representation at each layer. We then track the logit contributions back to the model's input by aggregating across layers"
- **Break condition:** If contextual mixing is too complex or non-linear, tracking tokens back to input becomes unreliable

### Mechanism 2
- **Claim:** MLPs in Transformers learn features that help predict grammatically acceptable words
- **Mechanism:** MLP blocks act as key-value memories where values add to the residual stream, promoting predictions of words with similar semantic meaning
- **Core assumption:** MLP operations can be decomposed into sub-updates that can be analyzed for grammatical contribution
- **Evidence anchors:** [abstract] "Then, we investigate the role of MLPs inside the Transformer and show that they learn features that help the model predict words that are grammatically acceptable"
- **Break condition:** If MLP features are too distributed or non-interpretable, grammatical patterns become undetectable

### Mechanism 3
- **Claim:** NMT models generate human-like source-target alignments for building predictions
- **Mechanism:** By measuring how encoder token representations update the logits of reference words, we can explain which source words cause the final logit of the reference word
- **Core assumption:** Source token representations can be mapped to target predictions through logit updates
- **Evidence anchors:** [abstract] "Lastly, we apply our method to Neural Machine Translation models, and demonstrate that they generate human-like source-target alignments for building predictions"
- **Break condition:** If encoder-decoder attention patterns are too complex, source-target alignments become unreliable

## Architecture Onboarding

- **Component map:**
  Input tokens → Embedding layer → Residual stream → Self-attention blocks → MLP blocks → Output layer → Logits
  Key components: ALTI for contextual mixing tracking, logit decomposition for contribution measurement

- **Critical path:**
  1. Token embeddings enter residual stream
  2. Each layer updates residual stream through attention and MLP
  3. Final layer produces logits
  4. Method tracks logit updates back to input tokens

- **Design tradeoffs:**
  - Linearity assumption vs. non-linear transformer operations
  - Computational cost of tracking vs. interpretability gain
  - Granularity of explanation (token vs. phrase level)

- **Failure signatures:**
  - Low alignment between explanations and linguistic evidence
  - Inconsistent patterns across different model sizes
  - Breakdown when contextual mixing is too complex

- **First 3 experiments:**
  1. Apply method to simple subject-verb agreement task
  2. Compare alignment scores with baseline methods
  3. Analyze layer-wise contribution patterns

## Limitations
- The method relies on assumptions about token representation tracking that may not hold for deeper or more sophisticated models
- Analysis is primarily conducted on English language tasks, limiting generalizability to other languages or domains
- Computational feasibility of applying the method to very large models (e.g., GPT-3, GPT-4) remains untested

## Confidence

**Confidence Labels:**
- **High Confidence**: The method's ability to measure logit contributions at each layer (Section 2.3) and its application to simple linguistic phenomena like subject-verb agreement and reflexive anaphora (Section 5.1-5.2) are well-supported by experimental evidence
- **Medium Confidence**: Claims about MLP layers promoting grammatical predictions (Section 6) and NMT models generating human-like alignments (Section 7) are plausible but require more extensive validation across diverse tasks and languages
- **Low Confidence**: The method's scalability to larger models (e.g., GPT-3, GPT-4) and its robustness to non-linear operations in deeper layers remain untested and uncertain
