# Gradient Descent Converges Linearly for Logistic Regression on Separable Data

## Quick Facts
- arXiv ID: 2306.14381
- Source URL: https://arxiv.org/abs/2306.14381
- Reference count: 40
- Primary result: Gradient descent with variable learning rates achieves linear convergence for logistic regression on separable data, with loss decaying as 1.1·f(x*)+ε where ε decreases exponentially.

## Executive Summary
This paper establishes that gradient descent with variable learning rates achieves linear convergence for logistic regression on separable data. The key insight is that as the loss decreases, the objective becomes multiplicatively smoother, allowing larger step sizes. The analysis relies on two properties: second-order robustness and multiplicative smoothness of the logistic loss. This result improves upon prior work which required exponential dependence on the solution magnitude. The paper also applies these ideas to sparse logistic regression, achieving an exponential improvement in the sparsity-error tradeoff from O(m/ε) to O(log m/ε).

## Method Summary
The method implements gradient descent with variable learning rates inversely proportional to the current loss value. The algorithm uses second-order robustness to ensure the Hessian remains stable in small norm balls, enabling simpler Taylor expansions. For sparse logistic regression, an additional greedy coordinate selection mechanism with sparsity thresholds is employed. The approach requires bounded data entries and relies on empirical validation of multiplicative smoothness constants across datasets.

## Key Results
- Gradient descent with variable learning rates achieves linear convergence for logistic regression on separable data
- Loss decays as 1.1·f(x*)+ε where ε decreases exponentially in the number of iterations
- Sparse logistic regression variant achieves exponential improvement in sparsity-error tradeoff from O(m/ε) to O(log m/ε)

## Why This Works (Mechanism)

### Mechanism 1: Multiplicative Smoothness
As the loss decreases, the logistic regression objective becomes multiplicatively smoother, allowing larger step sizes. The function's local smoothness is proportional to its current loss value, enabling the use of increasing learning rates without overshooting. This property is bounded by βm⁻¹∥∇f(x)∥₂²/f(x). Break condition: If the empirical constant exceeds 1 for a given dataset, linear convergence is not guaranteed.

### Mechanism 2: Second-Order Robustness
Second-order robustness ensures the Hessian remains stable in small norm balls, enabling simpler Taylor expansions. The Hessian at any point x is spectrally close to the Hessian at nearby points within a 1/(2M) ℓ1-ball. Break condition: If data points have extremely large magnitudes (M is very large), the stable neighborhood becomes too small to be useful for practical step sizes.

### Mechanism 3: Self-Regulating Optimization Landscape
The sum of second derivatives is bounded by the function value itself, creating a self-regulating optimization landscape. As the loss decreases, the diagonal weights w(Ax) = σ(Ax)(1-σ(Ax)) decrease proportionally, making the quadratic term in the Taylor expansion smaller and allowing larger steps. Break condition: If data becomes nearly perfectly separable (f(x) approaches 0), numerical precision issues could cause the bound to fail.

  - Why needed here: Standard smoothness definitions don't capture how the logistic loss becomes smoother as we approach optimality, which is crucial for the linear convergence result
  - Quick check question: For a function with multiplicative smoothness μ, how does the step size η relate to the current function value f(x)?

  - Why needed here: Without this property, the Hessian could change dramatically between iterations, making the Taylor expansion analysis invalid

  - Why needed here: The paper connects optimization convergence to the implicit bias of gradient descent, which drives solutions toward maximum margin classifiers

- Critical path: Gradient computation → Step size calculation → Parameter update → (Optional) Sparsity check → Repeat

## Open Questions the Paper Calls Out

### Open Question 1
Does the multiplicative smoothness property hold for logistic regression with respect to the ℓ2 norm in practice, or is it just an assumption used in the analysis? The paper shows this for the ℓ1 norm but assumes it for ℓ2 in the dense case analysis. Further experiments on a wider range of datasets would resolve this question.

### Open Question 2
Can the convergence rate be improved beyond linear convergence for logistic regression on separable data? The paper shows linear convergence but doesn't explore whether accelerated methods could achieve faster rates. Analysis of alternative optimization methods would determine if faster convergence is possible.

### Open Question 3
How does the sparsity of the solution affect the convergence rate of gradient descent for logistic regression? The paper analyzes convergence for a fixed sparsity level but doesn't study how varying sparsity impacts the rate. Experiments varying the target sparsity level would reveal this relationship.

## Limitations
- Analysis critically depends on the multiplicative smoothness constant being ≤ 1 for all datasets
- Results apply specifically to separable data with linearly separable classification tasks
- Extension to non-separable cases remains unclear

## Confidence

- **High Confidence**: The main linear convergence result for gradient descent with variable learning rates on separable data, supported by both theoretical analysis and empirical validation across 15 datasets.
- **Medium Confidence**: The multiplicative smoothness property and second-order robustness assumptions, which are well-motivated but rely on dataset-specific constants that weren't fully characterized theoretically.
- **Medium Confidence**: The sparse logistic regression extension and its improved sparsity-error tradeoff, as the analysis builds on the separable case but introduces additional complexity through greedy coordinate selection.
