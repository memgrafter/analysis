# Discovering Individual Rewards in Collective Behavior through Inverse Multi-Agent Reinforcement Learning

## Quick Facts
- arXiv ID: 2305.10548
- Source URL: https://arxiv.org/abs/2305.10548
- Authors: 
- Reference count: 40

## Executive Summary
This paper introduces an off-policy inverse multi-agent reinforcement learning (IMARL) algorithm that automatically discovers individual reward functions in collective behavior systems. By combining Remember and Forget Experience Replay (ReF-ER) with Guided Cost Learning (GCL), the approach addresses the challenge of learning reward functions in continuous state-action spaces with multiple interacting agents. The method successfully recovers reward functions from observed trajectories in both standard OpenAI gym MuJoCo environments and particle models of schooling behavior, reproducing milling patterns with time-averaged rotation exceeding 0.8.

## Method Summary
The IMARL algorithm combines ReF-ER with Guided Cost Learning to learn reward functions and policies from observed trajectories. The method uses neural networks to approximate both the policy and reward function, iterating between solving the forward multi-agent reinforcement learning problem and optimizing the reward function using gradient ascent based on the log-likelihood of observed trajectories. The algorithm updates the reward function less frequently than the policy network during training and constrains the reward function to a bounded domain. Validation occurs on OpenAI gym MuJoCo environments and particle models of schooling behavior.

## Key Results
- Recovers 95% of environment returns in Swimmer-v4 and Hopper-v4 MuJoCo tasks
- Reproduces milling patterns in particle-based schooling models with time-averaged rotation exceeding 0.8
- Demonstrates successful learning of reward functions from demonstration data without prior specification

## Architecture Onboarding

- Component map:
  Policy Network -> ReF-ER Algorithm -> Reward Network -> Guided Cost Learning (GCL)
  Demo Trajectories -> Background Batch -> Log-Likelihood Estimation

- Critical path:
  1. Initialize policy and reward networks
  2. Collect demonstration trajectories
  3. Iterate between solving forward MARL and optimizing reward function using GCL
  4. Use learned reward function to generate new trajectories and compare with demonstration data

- Design tradeoffs:
  - Complexity vs. interpretability: Using neural networks for function approximation increases complexity but improves flexibility and scalability
  - Off-policy vs. on-policy learning: Off-policy learning allows for more efficient use of data but may introduce bias
  - Exploration vs. exploitation: Balancing exploration of new strategies and exploitation of learned policies is crucial for effective learning

- Failure signatures:
  - Poor performance on OpenAI gym MuJoCo tasks indicates issues with learning effective policies in continuous control
  - Inability to reproduce collective behavior suggests learned reward function doesn't capture individual objectives
  - Instability or divergence during training may indicate problems with off-policy learning or neural network approximation

- First 3 experiments:
  1. Test the algorithm on a simple single-agent control task (e.g., CartPole) to verify basic functionality
  2. Validate the algorithm on a multi-agent coordination task (e.g., simple predator-prey) to assess its ability to handle multiple interacting agents
  3. Apply the algorithm to a more complex collective behavior task (e.g., boids simulation) to evaluate its scalability and effectiveness in capturing individual objectives

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the state and action spaces be automatically determined for IMARL without user specification?
- Basis in paper: [explicit] The paper states that "one of the remaining challenges lies in determining the state and actions, which are typically required to be specified by the user."
- Why unresolved: While IMARL removes the need to specify reward functions, it still requires user-defined state and action spaces, which limits its full automation potential.
- What evidence would resolve it: Development and demonstration of IMARL algorithms that can autonomously identify relevant state and action spaces from raw observational data.

### Open Question 2
- Question: What are the optimal hyperparameter selection methods for IMARL to improve learning success and convergence speed?
- Basis in paper: [explicit] The paper notes that "selecting hyperparameters in IMARL requires careful consideration, as the learning success and convergence speed are highly sensitive to these choices."
- Why unresolved: The paper acknowledges the sensitivity to hyperparameters but does not provide a systematic method for their selection, relying instead on manual search.
- What evidence would resolve it: Creation of automated hyperparameter optimization techniques specifically tailored for IMARL that consistently achieve better performance than manual selection.

### Open Question 3
- Question: How can the interpretability of neural network-based reward functions in IMARL be improved?
- Basis in paper: [explicit] The paper states that "although employing a neural network for the reward function offers great flexibility, it comes at the cost of reduced interpretability in the obtained results."
- Why unresolved: The paper uses neural networks for reward function approximation but acknowledges their lack of interpretability as a limitation.
- What evidence would resolve it: Development of techniques that can extract human-understandable reward structures from neural network approximations, such as symbolic regression or feature importance analysis methods.

## Limitations
- Requires pre-collected demonstration trajectories, which may not always be available in real-world systems
- Performance on complex tasks like Walker2d-v4 (65% return recovery) suggests limitations in handling highly dynamic behaviors
- Particle model of schooling behavior represents a simplified abstraction of real collective systems

- **Low Confidence**: The approach generalizes effectively to real-world collective behavior systems with complex physical interactions
