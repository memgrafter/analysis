# Fortuna: A Library for Uncertainty Quantification in Deep Learning

## Quick Facts
- arXiv ID: 2302.04019
- Source URL: https://arxiv.org/abs/2302.04019
- Reference count: 13
- Fortuna improves calibration metrics (ECE, Brier score, NLL) on computer vision datasets using SWAG + temperature scaling

## Executive Summary
Fortuna addresses the problem of overconfident uncertainty estimates in deep learning models by providing a unified framework for advanced uncertainty quantification methods. The library supports three usage modes: starting from uncertainty estimates (for conformal prediction), starting from model outputs (for calibration), and starting from Flax models (for scalable Bayesian inference). Through experiments on multiple computer vision datasets, Fortuna's default settings (SWAG + temperature scaling) consistently improved calibration metrics compared to standard training.

## Method Summary
Fortuna provides three distinct usage modes for uncertainty quantification. The first mode takes pre-computed uncertainty estimates and applies conformal prediction methods to generate prediction sets with guaranteed coverage. The second mode accepts model outputs (logits or predictions) and applies calibration techniques like temperature scaling. The third mode integrates directly with Flax models to perform scalable Bayesian inference using methods like SWAG, MAP, ADVI, and Laplace approximation. The library is built on JAX for gradient computation and supports various Bayesian inference backends.

## Key Results
- Fortuna's default settings (SWAG + temperature scaling) improved predictive log likelihood across all tested datasets
- Expected Calibration Error (ECE) was consistently lower with Fortuna compared to standard training
- Brier score improvements demonstrated better uncertainty quantification in classification tasks
- Results were validated on CIFAR10, Fashion MNIST, MNIST, MNIST corrupted, and SVHN datasets

## Why This Works (Mechanism)

### Mechanism 1
Fortuna improves calibration by replacing point estimation with Bayesian inference (SWAG + temperature scaling). Bayesian methods capture epistemic uncertainty through posterior parameter distributions, while temperature scaling adjusts output confidences to match empirical accuracy. The core assumption is that the posterior distribution over parameters meaningfully represents uncertainty that standard training misses. Break condition: If the posterior distribution is too narrow or poorly approximated, epistemic uncertainty estimates will be unreliable and calibration gains disappear.

### Mechanism 2
Conformal prediction provides distribution-free coverage guarantees regardless of model correctness. Conformal methods calibrate prediction sets/intervals using held-out validation data to ensure coverage at a specified confidence level, independent of the underlying uncertainty estimates' quality. Core assumption: The validation data is exchangeable with test data and large enough to estimate quantiles accurately. Break condition: If validation and test data distributions differ, coverage guarantees fail and intervals become either too wide or too narrow.

### Mechanism 3
Temperature scaling corrects overconfidence by learning a single scaling parameter on held-out calibration data. A learnable temperature parameter divides logits before softmax, reducing peak probabilities when models are overconfident and increasing them when underconfident. Core assumption: Overconfidence is uniform across classes and can be corrected with a single scalar parameter. Break condition: If miscalibration is class- or input-dependent, a single temperature parameter cannot fully correct it.

## Architecture Onboarding

- Component map: Model definition -> Bayesian inference (SWAG/MAP/ADVI) -> Calibration (temperature scaling) -> Uncertainty quantification
- Critical path: For Bayesian inference: model definition → training loop with uncertainty → calibration post-processing; For conformal prediction: uncertainty estimates → validation split → conformal set generation
- Design tradeoffs: Flexibility vs. ease-of-use: three modes offer different levels of control; JAX dependency enables speed but requires functional programming style; Flax model requirement for Bayesian inference limits integration with non-Flax frameworks
- Failure signatures: Poor calibration despite Bayesian inference → posterior approximation inadequate; Overly conservative conformal sets → validation split too small or non-representative; Training instability in Bayesian mode → learning rate or prior specification problematic
- First 3 experiments: 1) MNIST classification with MLP: standard training vs. Fortuna default (SWAG + TS) to reproduce paper results; 2) CIFAR10 with WideResNet: test temperature scaling calibration on pre-trained model outputs; 3) Regression task with conformal quantile regression: verify coverage guarantees on synthetic heteroscedastic data
