# Learning Manner of Execution from Partial Corrections

## Quick Facts
- arXiv ID: 2302.03338
- Source URL: https://arxiv.org/abs/2302.03338
- Reference count: 6
- The paper proposes a method for learning which manner of execution to use in which context through interactive task learning using corrective feedback.

## Executive Summary
This paper introduces an approach for learning behavioral constraints through interactive task learning where a teacher provides corrective feedback. The agent uses coherence semantics to ground teacher utterances that contain unknown concepts, enabling it to learn both what contexts require certain behaviors and what those behaviors should be. The approach is demonstrated to be more data-efficient than learning from simple "no" responses alone.

## Method Summary
The approach uses a Bayes Net-based system that incrementally learns rules mapping contexts to manners of execution. When the teacher provides corrections, the agent uses coherence analysis to infer missing context information and update its beliefs about concept grounding and behavior generation. The system maintains a disentangled action space where different behavioral dimensions (like energy and orientation) can be controlled independently. Learning occurs incrementally through weighted kernel density estimation, with the agent updating its behavior model based on both corrections and assents.

## Key Results
- Learning from contentful corrections is more data-efficient than just learning from "no" responses
- The agent can learn new concepts and constraints through interactive correction-based learning
- Using both corrections and assents improves learning performance compared to using corrections alone

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Coherence-based corrections allow the agent to infer missing context from partial feedback
- Mechanism: When the teacher says "no, do it gently," coherence analysis requires the utterance to be relevant to the previous action, forcing the agent to infer that the current object matches the rule body
- Core assumption: The teacher's corrections are always coherent and true, following natural discourse patterns
- Evidence anchors:
  - [abstract] "through the semantics of coherence, our agent can perform the symbol grounding that's necessary for exploiting the teacher's feedback"
  - [section] "we will exploit the semantics of the coherence relation correction to inform our agent's inferences about the meaning of the teacher's utterance"
- Break condition: If the teacher provides incoherent feedback or the agent cannot establish relevance between correction and context

### Mechanism 2
- Claim: Learning from both corrections and assents provides complementary data for behavior modeling
- Mechanism: Corrections provide negative exemplars (what not to do) while assents provide positive exemplars, with the agent updating its behavior generation model using both types of data through weighted kernel density estimation
- Core assumption: Assents indicate the agent performed all constraints correctly, allowing extraction of positive behavior exemplars
- Evidence anchors:
  - [abstract] "We demonstrate that exploiting theories of discourse coherence... enhances the performance of the model"
  - [section] "we showed that to learn efficiently, the agent can and should use both the fact that corrections tell it about positive exemplars of a context and negative exemplars for the required manner"
- Break condition: If assents are sparse or ambiguous, preventing reliable positive exemplar extraction

### Mechanism 3
- Claim: Bayesian networks dynamically model uncertainty in concept grounding and rule application
- Mechanism: The agent constructs a Bayes Net with nodes for observable features, latent concepts, and behaviors, expanding the network and updating parameters incrementally as new concepts are introduced through corrections
- Core assumption: The relationships between concepts and behaviors follow conditional probability distributions that can be learned from interaction data
- Evidence anchors:
  - [section] "When the teacher mentions a new color term C... it triggers the introduction of a new Boolean chance node C"
  - [section] "When faced with the current object, the agent must choose the action it will perform (i.e., a point p on the action space). Its choice is made dependent on its current beliefs about the constraints on manner"
- Break condition: If concept relationships are non-probabilistic or violate conditional independence assumptions

## Architecture Onboarding

- Component map: Perception module (RGB detection) -> Bayes Net (knowledge representation) -> Action selection (point selection in behavior space) -> Teacher feedback parser (correction extraction) -> Learning module (parameter updates) -> Bayes Net parameter update
- Critical path: Perception → Bayes Net inference → Action selection → Teacher feedback → Learning update → Bayes Net parameter update
- Design tradeoffs: Incremental learning vs. batch training (favors online updates for dialogue), abstraction level (simplified 2D shapes vs. complex 3D environments), rule representation (separate vs. combined constraints)
- Failure signatures: High regret indicates poor concept grounding; Bayes Net divergence suggests incorrect probability assumptions; failure to learn from corrections points to coherence analysis issues
- First 3 experiments:
  1. Test learning from full corrections only with known colors and shapes
  2. Test learning from partial corrections with multiple rule possibilities
  3. Test ablation studies (no assent learning, no negative exemplars)

## Limitations
- The approach assumes teacher corrections follow natural coherence patterns, which may not hold in all teaching scenarios
- The Beta distribution update rules for rule learning from corrections are not fully specified
- The assumption that assents reliably indicate correct behavior across all constraint dimensions may not hold in more complex scenarios

## Confidence
- **High confidence:** The core mechanism of using coherence relations to infer context from partial corrections is well-grounded in discourse semantics literature
- **Medium confidence:** The Bayes Net approach for incremental learning shows promise, but implementation details could significantly impact performance
- **Low confidence:** The assumption that assents reliably indicate correct behavior across all constraint dimensions may not hold in more complex scenarios
