# HyperTuner: A Cross-Layer Multi-Objective Hyperparameter Auto-Tuning Framework for Data Analytic Services

## Quick Facts
- arXiv ID: 2304.10051
- Source URL: https://arxiv.org/abs/2304.10051
- Reference count: 40
- Optimizes both model hyperparameters and system parameters across multiple objectives

## Executive Summary
HyperTuner is a cross-layer multi-objective hyperparameter auto-tuning framework designed to optimize data analytic services. The framework addresses the challenge of simultaneously tuning model hyperparameters and system parameters to achieve multiple objectives including model accuracy, training time, and energy consumption. HyperTuner employs a two-step approach: first ranking parameter importance using the MOPIR algorithm, then efficiently solving the resulting high-dimensional optimization problem using the ADUMBO algorithm, which adaptively leverages uncertainty and predicted means across surrogate models.

## Method Summary
The framework operates by first using MOPIR (Multi-Objective Parameter Importance Ranking) to identify the most influential parameters for optimization. This ranked parameter set is then fed into ADUMBO (Adaptive Dynamic Uncertainty-based Multi-objective Bayesian Optimization), which handles the complex black-box optimization problem. ADUMBO leverages uncertainty estimates and predicted means from multiple surrogate models to guide the search process efficiently. This approach enables HyperTuner to find Pareto-optimal configurations that balance multiple competing objectives while maintaining computational efficiency.

## Key Results
- Outperforms four baseline algorithms in convergence and diversity of Pareto-optimal configurations
- Successfully adapts to different datasets, optimization objectives, and ML platforms
- Demonstrates effectiveness on both PyTorch and TensorFlow platforms
- Achieves balanced trade-offs between model accuracy, training time, and energy consumption

## Why This Works (Mechanism)
The framework's effectiveness stems from its two-phase approach that first reduces the search space complexity through parameter importance ranking, then applies sophisticated Bayesian optimization that explicitly accounts for uncertainty in predictions. By focusing computational resources on the most influential parameters and leveraging uncertainty-aware optimization, HyperTuner can efficiently navigate the complex trade-offs between multiple objectives in high-dimensional spaces.

## Foundational Learning
- Multi-objective optimization: Optimizing multiple competing objectives simultaneously is essential for real-world systems where performance, cost, and efficiency must be balanced
  - Why needed: Single-objective optimization fails to capture the complex trade-offs in practical deployment scenarios
  - Quick check: Can the framework handle scenarios where improving one objective degrades another?

- Bayesian optimization: A probabilistic approach to global optimization of expensive black-box functions
  - Why needed: Traditional grid search or random search become computationally prohibitive in high-dimensional spaces
  - Quick check: Does the algorithm efficiently explore the parameter space with limited function evaluations?

- Surrogate modeling: Using probabilistic models to approximate expensive objective functions
  - Why needed: Direct evaluation of ML training pipelines for every configuration is computationally prohibitive
  - Quick check: How accurate are the surrogate models in predicting actual training outcomes?

## Architecture Onboarding

Component Map: Data -> MOPIR -> Ranked Parameters -> ADUMBO -> Pareto-optimal Set -> Multi-objective Optimization

Critical Path: The primary execution flow follows: Input configuration space → MOPIR parameter ranking → ADUMBO optimization → Output Pareto-optimal configurations

Design Tradeoffs: The framework trades some precision in parameter importance ranking for significant computational efficiency gains. The MOPIR algorithm provides a reasonable approximation rather than exact ranking, enabling faster convergence in the subsequent ADUMBO phase.

Failure Signatures: Poor performance may manifest as: (1) convergence to suboptimal Pareto fronts when parameter correlations are strong, (2) slow adaptation when objective landscapes change significantly between iterations, (3) failure to discover diverse solutions when uncertainty estimates are overconfident
