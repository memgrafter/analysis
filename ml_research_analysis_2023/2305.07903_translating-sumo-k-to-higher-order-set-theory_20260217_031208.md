# Translating SUMO-K to Higher-Order Set Theory
## Quick Facts
- arXiv ID: 2305.07903
- Source URL: https://arxiv.org/abs/2305.07903
- Reference count: 34
- Primary result: Translation of SUMO-K fragment to higher-order set theory with formal semantics and proof generation

## Executive Summary
This paper presents a translation of SUMO-K, a fragment of the Suggested Upper Merged Ontology, into higher-order set theory. The authors develop a formal semantics for higher-order constructs in SUMO and demonstrate how this enables embedding a large common-sense ontology into a secure interactive theorem proving system. They prove 23 SUMO-K queries interactively and generate 4880 problems for automated theorem provers, evaluating the performance of current higher-order ATPs on these problems.

## Method Summary
The authors formalize a translation from SUMO-K to higher-order set theory, enabling a rigorous mathematical semantics for ontological constructs. They use an interactive theorem prover to prove 23 queries and extract subgoal problems from these proofs for automated theorem prover evaluation. The translation captures higher-order constructs while maintaining logical consistency, and the resulting problems are used to assess the current capabilities of higher-order automated reasoning systems.

## Key Results
- 23 SUMO-K queries proved interactively in the theorem prover
- 4880 problems generated for automated theorem provers
- Automated theorem provers show reasonable performance on subgoal problems extracted from interactive proofs
- Current higher-order ATPs cannot fully automatically prove the original queries

## Why This Works (Mechanism)
The translation succeeds by mapping SUMO-K's higher-order constructs into well-defined set-theoretic counterparts, providing a solid mathematical foundation for the ontology. The interactive theorem prover allows for human-guided reasoning through complex logical steps, while the extraction of subgoal problems creates more tractable challenges for automated systems.
