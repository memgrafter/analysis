# The Best of Both Worlds: Combining Human and Machine Translations for Multilingual Semantic Parsing with Active Learning

## Quick Facts
- arXiv ID: 2305.12737
- Source URL: https://arxiv.org/abs/2305.12737
- Authors: Multiple
- Reference count: 10
- Key outcome: Parser accuracy improves by up to 28% on multilingual GEOQUERY and 5% on NLM AP with only 16% human-translated data

## Executive Summary
This paper addresses data imbalance in multilingual semantic parsing by combining human and machine translations through active learning. The proposed HAT (Human and Automatic Translations) method iteratively adds small batches of human-translated utterances to machine-translated training data. An aggregated acquisition function (ABE) selects utterances that maximally reduce translation bias and errors. Experiments demonstrate that with only 16% of utterances manually translated, parser accuracy significantly improves compared to using only machine translations, achieving performance within 5% of an oracle trained on all human data.

## Method Summary
The HAT method combines human and machine translations for multilingual semantic parsing using active learning. The process begins with machine-translating all English training utterances to target languages and training an initial parser on this data. Active learning iteratively selects utterances for human translation using an aggregated acquisition function (ABE) that combines Translation Bias, Translation Error, Semantic Density, and Semantic Diversity metrics. After each round, human-translated utterances are added to the training data, the parser is re-trained, and performance is evaluated. This process continues through multiple rounds, gradually incorporating more human-translated data while maintaining high parser accuracy.

## Key Results
- Parser accuracy improves by up to 28% on multilingual GEOQUERY and 5% on NLM AP with only 16% human-translated data
- The method achieves performance within 5% of an oracle trained on all human data
- Aggregated acquisition function (ABE) outperforms individual acquisition functions in most sampling scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: HAT improves parser accuracy by combining human and machine translations through active learning
- Core assumption: Human translations are more accurate and less biased than machine translations
- Evidence: Parsers trained on human translations significantly outperform those trained on machine translations; active learning selects utterances that maximally reduce translation bias and errors

### Mechanism 2
- Claim: ABE effectively selects utterances that maximally reduce translation bias and errors
- Core assumption: Utterances with significant bias and errors in machine translations benefit most from human translation
- Evidence: Aggregated acquisition function combines four metrics (Translation Bias, Translation Error, Semantic Density, Semantic Diversity) to score utterances

### Mechanism 3
- Claim: Active learning with HAT and ABE improves parser performance compared to using only machine translations
- Core assumption: Active learning can effectively identify the most beneficial utterances for human translation
- Evidence: Iterative process of adding human translations improves parser performance over time

## Architecture Onboarding

- Component map: Human translations (HT) -> Machine translations (MT) -> Active learning (AL) algorithm -> Aggregated acquisition function (ABE) -> Multilingual parser
- Critical path: 1. Initialize training data with MT 2. AL selects utterances for HT 3. Add HT to training data 4. Train parser on updated data 5. Evaluate performance
- Design tradeoffs: Cost of HT vs. parser accuracy improvement; AL algorithm complexity vs. effectiveness; number of acquisition functions vs. accuracy
- Failure signatures: Parser performance doesn't improve with HT; AL selects non-beneficial utterances; ABE doesn't accurately identify beneficial utterances
- First 3 experiments: 1. Evaluate parser performance using only MT 2. Implement AL with simple acquisition function 3. Add HT to selected utterances and evaluate improvement

- Question: What is the optimal balance between Translation Error and Semantic Density terms?
- Basis: Ablation study shows combining these terms works best in low sampling regions
- Why unresolved: Paper doesn't provide clear optimal balance between these terms

## Limitations
- Performance improvements may not generalize to other semantic parsing tasks or languages with different structures
- Cost-benefit analysis of human translations versus machine translations is not explicitly quantified
- Potential biases introduced by the active learning selection process are not addressed
