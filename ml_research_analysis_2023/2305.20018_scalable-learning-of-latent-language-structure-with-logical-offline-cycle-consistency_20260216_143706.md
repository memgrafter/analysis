# Scalable Learning of Latent Language Structure With Logical Offline Cycle Consistency

## Quick Facts
- **arXiv ID**: 2305.20018
- **Source URL**: https://arxiv.org/abs/2305.20018
- **Reference count**: 40
- **Key outcome**: LOCCO achieves state-of-the-art semantic parsing performance on WebNLG, improving F1 by 1.3 points over previous best

## Executive Summary
This paper introduces Logical Offline Cycle Consistency Optimization (LOCCO), a scalable semi-supervised method for training neural semantic parsers. LOCCO leverages a count-based prior over valid formal meaning representations and a cycle-consistency score from a frozen text generation model to weight predictions, incentivizing coherent and structurally regular parses. The method approximates marginalization of latent structures through stochastic variational inference and requires negligible computational overhead compared to conventional self-learning. LOCCO achieves state-of-the-art semantic parsing performance on WebNLG, improving F1 by 1.3 points over previous best, and yields competitive text generation performance. On ATIS, LOCCO shows gains over supervised and self-learning settings without expensive online sampling.

## Method Summary
LOCCO uses stochastic variational inference to approximate marginalization over latent logical forms. It employs a score function estimator to enable backpropagation through discrete latent structures, using rewards that combine cycle-consistency scores from a frozen text generation model and a count-based prior over substructures. The method alternates between updating the semantic parser and updating the logic prior, using offline sampling to reduce variance and computational overhead. For WebNLG, it samples N=100 parses per text over K=30 iterations, while for ATIS it uses N=30 over K=20 iterations.

## Key Results
- Achieves state-of-the-art semantic parsing performance on WebNLG with 1.3 point F1 improvement
- Demonstrates competitive text generation performance when repurposing parser outputs
- Shows consistent gains on ATIS across multiple metrics compared to supervised and self-learning baselines
- Requires negligible computational overhead compared to conventional self-learning methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Offline reinforcement learning via score function estimator allows backpropagation through discrete latent structures
- Mechanism: Uses the score function estimator to approximate gradients of a reward function V(z, x) = log p(x|z) + log p(z) by sampling z ~ q(z|x; ϕi-1) and computing weighted gradients using the reward. This enables gradient updates despite the discrete, non-differentiable nature of the latent space.
- Core assumption: The offline assumption ϕi ≈ ϕi-1 holds, meaning sampling from the previous iteration's model approximates sampling from the current model for the purposes of gradient estimation.
- Evidence anchors:
  - [section] "We overcome this with the score function estimator [44] which yields following Monte Carlo approximation for the gradient"
  - [section] "This amounts to updating ϕi with the samples from the previous iteration model q(z|x; ϕi-1) as if they were gold but weighted by V(z, x)"
- Break condition: If ϕi changes significantly between iterations, the offline sampling assumption breaks down, leading to biased gradient estimates and poor optimization.

### Mechanism 2
- Claim: Count-based prior over substructures regularizes the semantic parser to produce structurally valid and common logical forms
- Mechanism: Maintains a count-based probability distribution p(z; θ) over substructures (e.g., individual triples) observed in the corpus. This prior upweights logical forms containing frequent, valid substructures, encouraging the parser to generate outputs that are both syntactically valid and semantically coherent with training data.
- Core assumption: The factorization into substructures (e.g., triples) is appropriate and captures the essential structure of the logical forms being generated.
- Evidence anchors:
  - [section] "p(z; θ) is a count-based model factorizing the space of possible substructures (e.g., into edges)"
  - [section] "It incorporates prior knowledge about the formal language, such as valid statements"
- Break condition: If the substructures are poorly chosen (e.g., too fine-grained or too coarse), the count-based model may fail to capture meaningful patterns or could over-regularize, hurting performance.

### Mechanism 3
- Claim: Cycle-consistency score from a frozen text generation model provides a strong signal of semantic faithfulness between text and logical forms
- Mechanism: Uses a separately initialized and frozen copy of the semantic parser as a text generation model to score the coherence of predicted logical forms with their source text. This cycle-consistency score log p(x|z) rewards logical forms that are faithful to their original text, improving annotation quality.
- Core assumption: The frozen text generation model provides meaningful cycle-consistency scores that correlate with semantic faithfulness.
- Evidence anchors:
  - [section] "a cycle-consistency score produced by a neural text generation model as additional signals"
  - [section] "both the prior and semantic parser are updated in an alternate fashion from full passes over the training data"
- Break condition: If the frozen text generation model is poorly trained or its scores don't correlate with semantic quality, the cycle-consistency signal becomes noisy and could mislead the parser.

## Architecture Onboarding

- Component map: Semantic parser q(z|x; ϕ) -> Text generation model p(x|z; ρ) -> Logic prior p(z; θ) -> Sampling and scoring pipeline

- Critical path:
  1. Initialize models and logic prior counts
  2. Alternate between updating semantic parser with weighted samples and updating logic prior with new counts
  3. Use final semantic parser for inference

- Design tradeoffs:
  - Offline sampling vs. online sampling: Offline is more parallelizable and has lower variance but requires more memory
  - Frozen text generation model vs. joint training: Frozen model provides stable cycle-consistency signal but can't adapt to parser improvements
  - Count-based prior vs. learned prior: Count-based is simpler and incorporates inductive biases but may be less flexible

- Failure signatures:
  - Semantic parser collapse: If cycle-consistency or prior weights become too extreme, the parser may degenerate
  - Logic prior overfitting: If counts become too skewed, the prior may over-regularize and hurt generalization
  - Memory issues: Large-scale offline sampling can consume significant storage for V(z, x) values

- First 3 experiments:
  1. Ablation study: Test semantic parser performance with only cycle-consistency, only prior, and both signals
  2. Iteration analysis: Track performance across training iterations to identify convergence behavior
  3. Data size sensitivity: Test performance with varying amounts of unlabeled data to understand scalability

## Limitations
- Performance gains are evaluated on only two datasets (WebNLG and ATIS), limiting generalizability
- Method's sensitivity to the number of unlabeled samples N and the number of training iterations K is not fully characterized
- Computational overhead of storing V(z, x) values for all sampled parses could become prohibitive at scale

## Confidence
- **High confidence**: The overall method framework and theoretical foundations (SVI, score function estimator) are well-established and correctly applied
- **Medium confidence**: The specific implementation details for cycle-consistency scoring and count-based prior updates, as exact formulas are not provided
- **Medium confidence**: The performance improvements, given evaluation on only two datasets and lack of ablation studies showing individual contribution of each component
