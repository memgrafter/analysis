# Those Aren't Your Memories, They're Somebody Else's: Seeding Misinformation in Chat Bot Memories

## Quick Facts
- arXiv ID: 2304.05371
- Source URL: https://arxiv.org/abs/2304.05371
- Authors: 
- Reference count: 24
- Key outcome: Long-term memory modules in chat bots can be exploited to inject misinformation by combining it with personal statements, leading to 76% memory creation rate and 328% increased misinformation recall.

## Executive Summary
This study reveals a significant vulnerability in memory-based chat bots where misinformation can be injected and subsequently recalled by combining it with personal statements during conversation. The research demonstrates that when misinformation is paired with personal utterances, the bot's memory module prioritizes storing this information, creating a vector for persistent misinformation. Through systematic testing across multiple chat bot models, the authors show that this vulnerability exists in practice and can be exploited through normal conversation patterns. The findings highlight critical security implications for chat bots that rely on long-term memory to maintain context and personalize interactions.

## Method Summary
The researchers conducted experiments by crafting 150 misinformation examples and combining them with 10 personal statements to create injection messages. These messages were sent to BlenderBot 2 chat bots with memory modules enabled, allowing the bots to generate and store memories. The team then conducted automated conversations with the bots, including both chit-chat and targeted retrieval queries about the misinformation topics. Responses were analyzed to determine if the injected misinformation was recalled. The study also tested various mitigation strategies including user authentication, memory de-duplication, and response filtering to assess their effectiveness at reducing the vulnerability.

## Key Results
- 114 out of 150 (76%) misinformation examples were remembered when paired with a personal statement
- The bot was 328% more likely to respond with misinformation if it was stored in memory
- Open-ended questions about misinformation topics were 84-74% effective at eliciting misinformation, compared to only 4-0% for direct questions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The long-term memory module prioritizes and stores personal information about the conversation partner, creating a bias toward remembering such statements.
- Mechanism: When the memory generation model is presented with a statement containing both personal and informative content, it selectively encodes and stores the personal component, but the informative content becomes attached to it.
- Core assumption: The memory generation model was trained on datasets emphasizing personal conversations, causing it to prioritize personal information.
- Evidence anchors:
  - [abstract]: "The bot is designed to extract knowledge of personal nature from their conversation partner, e.g., stating preference for a particular color."
  - [section 3.1]: "We loosely define a personal statement as any utterance that exhibits a preference or characteristic of the speaker... We found that by prepending the original COVID-19 rumor statements with a personal utterance... we greatly increase the number of memories generated (93.22%)."
- Break condition: The memory model could be retrained to treat personal and non-personal statements equally, or to de-duplicate memories that contain identical informative content.

### Mechanism 2
- Claim: The memory ranking and recall system retrieves top memories based on relevance, allowing injected misinformation to be recalled when the topic is discussed.
- Mechanism: When a user asks about a topic, the memory search component ranks all stored memories and returns the top 5. If the injected misinformation is among these, it will be included in the response generation.
- Core assumption: The relevance ranking is based on topic similarity and does not distinguish between truthful and false information.
- Evidence anchors:
  - [section 2.1]: "The second step is to recall valid memories. When the bot is tasked with generating a response, it will search the plain text long-term memories, rank all memories, and return a list of top 5 memories."
  - [section 4.1]: "The memory module can be implemented in a way to de-duplicate the memories... However, this can be circumvent by using different personal statements for the target misinformation."
- Break condition: Implement a verification system that checks retrieved memories against trusted sources before including them in responses.

### Mechanism 3
- Claim: Open-ended questions about the topic are more effective at eliciting misinformation than direct questions confirming the specific false statement.
- Mechanism: When presented with an open-ended question, the response generation model "fills in the gap" by including the misinformation from memory, while direct questions often trigger a denial response.
- Core assumption: The response generation model has been trained to provide complete information when asked open questions, leading it to supplement with stored memories.
- Evidence anchors:
  - [section 4.2]: "We found that direct questions about the misinformation... are significantly less effective than open questions... The direct variant... resulted in misinformation 4% and 0% of the time... while the open-ended variant lead to misinformation 84% and 74% of the time."
- Break condition: Modify the response generation to verify information against trusted sources before including it, especially for open-ended questions.

## Architecture Onboarding

- Component map:
  - User Interface → Dialogue History → Memory Module → Internet Search Module → Response Generator → Output
  - Memory Module: Memory Generation (summarizer), Memory Storage (100 memory limit), Memory Recall (ranking and retrieval)
  - Internet Search Module: Query Generator → Search Engine → Document Processor → Encoder → Decoder

- Critical path: User input → Dialogue History → Memory Generation → Memory Storage → Memory Recall (when relevant) → Response Generation → Output

- Design tradeoffs:
  - Memory capacity vs. relevance: Limited memory (100 entries) requires efficient ranking, but may lead to loss of important information
  - Personal information emphasis vs. general knowledge: Prioritizing personal info enhances conversation but creates vulnerability to misinformation injection
  - Memory determinism vs. context awareness: Deterministic memory generation simplifies debugging but may not capture nuanced context

- Failure signatures:
  - Unexpected responses containing misinformation when discussing certain topics
  - Memory retrieval returning irrelevant or outdated information
  - Inconsistent responses to similar questions over time

- First 3 experiments:
  1. Test memory generation with various statement types (personal, informative, combined) to verify the bias toward personal information.
  2. Inject misinformation using different personal statement combinations and measure memory creation success rate.
  3. Query the bot with open-ended vs. direct questions about the injected topic and compare misinformation recall rates.

## Limitations

- The exact implementation details of the memory generation model are not specified, making it difficult to determine if the vulnerability is architecture-specific
- The study uses a limited set of 150 misinformation examples and 10 personal statements, which may not represent the full diversity of potential attack vectors
- Manual annotation for evaluating responses could introduce subjective bias as it relies on human judgment

## Confidence

**High Confidence**: The core finding that combining misinformation with personal statements significantly increases the likelihood of memory creation (76% success rate) is well-supported by experimental data. The 328% increase in misinformation recall when the topic is queried is also robustly demonstrated across multiple bot models.

**Medium Confidence**: The mechanism explanation for why personal statements enhance memory creation is plausible but relies on assumptions about the training data and model architecture that are not directly verified. The effectiveness of mitigation strategies (authentication, de-duplication, filtering) is proposed but not thoroughly tested.

**Low Confidence**: The generalizability of these findings to other memory-based systems beyond the tested chat bots cannot be determined from the available information. The long-term persistence of injected misinformation and its potential impact on extended conversations is not explored.

## Next Checks
