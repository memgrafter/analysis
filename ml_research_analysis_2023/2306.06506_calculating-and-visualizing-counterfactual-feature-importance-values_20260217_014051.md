# Calculating and Visualizing Counterfactual Feature Importance Values

## Executive Summary
This paper addresses two critical limitations in counterfactual explanations: the inability to measure individual feature influence and the lack of effective visualization tools. The authors propose Counterfactual Feature Importance (CFI) values that quantify the contribution of each feature change in counterfactual explanations. They introduce two computational methods - a greedy approach and CounterShapley (which uses Shapley values) - along with three novel visualization techniques: Greedy chart, CounterShapley chart, and Constellation chart. The methods are demonstrated across various datasets and models, with an open-source implementation provided.

## Method Summary
The paper introduces CFI values to quantify feature importance in counterfactual explanations. Two methods are proposed: a computationally efficient greedy approach that sequentially selects feature changes, and CounterShapley which calculates Shapley values between factual and counterfactual pairs to capture feature interactions. Three visualization charts are introduced: Greedy chart showing sequential feature change paths, CounterShapley chart displaying importance scores, and Constellation chart visualizing all possible feature change combinations. The methods are implemented as an open-source tool compatible with any counterfactual explanation generator.

## Key Results
- Introduces CFI values addressing limitations in assessing individual feature influence in counterfactual explanations
- Proposes two calculation methods: greedy approach and CounterShapley using Shapley values
- Develops three visualization techniques: Greedy chart, CounterShapley chart, and Constellation chart
- Provides open-source implementation compatible with existing counterfactual explanation algorithms

## Why This Works (Mechanism)
The paper works by assigning importance values to individual feature changes in counterfactual explanations through two complementary approaches. The greedy method provides computational efficiency by sequentially selecting feature changes based on their immediate impact. CounterShapley captures feature interactions by calculating Shapley values, which fairly distribute importance among features based on their marginal contributions. The visualization charts translate these numerical values into interpretable formats that decision-makers can use to understand feature importance hierarchies and alternative paths to achieve desired outcomes.

- Feature interaction importance: why needed - captures how features jointly influence model predictions; quick check - can detect synergistic or redundant feature relationships
- Visualization hierarchy: why needed - transforms numerical importance scores into interpretable decision support; quick check - enables rapid comparison across multiple counterfactual explanations

## Architecture Onboarding

Component map:
User Input -> Counterfactual Generator -> CFI Calculator -> Visualization Engine -> Output Charts

Critical path:
Counterfactual pair generation → CFI calculation (greedy/CounterShapley) → Visualization chart rendering

Design tradeoffs:
- Greedy method: faster computation but may miss complex feature interactions
- CounterShapley method: captures interactions but computationally expensive for high dimensions
- Visualization complexity vs interpretability: more detailed charts provide richer information but may overwhelm users

Failure signatures:
- Greedy approach may converge to suboptimal solutions when feature interactions are important
- CounterShapley calculations become intractable for datasets with many features
- Visualization charts may become cluttered with too many feature combinations
