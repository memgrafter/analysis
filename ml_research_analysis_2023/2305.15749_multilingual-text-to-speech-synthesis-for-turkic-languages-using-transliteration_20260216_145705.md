# Multilingual Text-to-Speech Synthesis for Turkic Languages Using Transliteration

## Quick Facts
- arXiv ID: 2305.15749
- Source URL: https://arxiv.org/abs/2305.15749
- Reference count: 0
- One-line primary result: Proposed zero-shot TTS approach for Turkic languages achieves MOS of 3.25, 92% comprehension accuracy, and 41% intelligibility using IPA-based transliteration

## Executive Summary
This paper presents a novel approach to building text-to-speech (TTS) synthesis systems for lower-resourced Turkic languages using zero-shot learning. The method involves training a single TTS model on Kazakh data and then using an IPA-based transliteration approach to generate speech for other Turkic languages. By mapping letters from ten target Turkic language alphabets to IPA symbols and then to Kazakh alphabet letters, the approach enables a single model to synthesize speech across multiple languages. The subjective evaluation shows promising results with a MOS of 3.25, 92% comprehension accuracy, and 41% intelligibility on semantically unpredictable sentences.

## Method Summary
The method trains a Tacotron 2-based TTS model on the KazakhTTS2 corpus (approximately 58 hours of transcribed speech from Speaker M2). An IPA-based converter is implemented to map letters from target Turkic language alphabets to IPA symbols, then to Kazakh alphabet letters. The converted text is fed into the trained TTS model, and WaveGAN vocoder is used to generate the final waveform. Subjective evaluation includes comprehension tests with questions and intelligibility tests using semantically unpredictable sentences.

## Key Results
- Mean Opinion Score (MOS) of 3.25 for overall speech quality
- 92% comprehension accuracy across target languages
- 41% intelligibility rate on semantically unpredictable sentences
- Highest intelligibility achieved by Azerbaijani (72%) and lowest by Sakha (15%)

## Architecture Onboarding

- Component map: IPA converter → TTS model → WaveGAN vocoder → synthesized speech
- Critical path: IPA-based transliteration of target language text → input to Kazakh-trained TTS model → acoustic feature generation → WaveGAN vocoder → final speech output
- Design tradeoffs:
  - IPA complexity enables cross-linguistic generalization but adds conversion overhead
  - Single source language simplifies training but limits phonetic coverage
  - Subjective evaluation provides real-world insights but introduces rater variability
- Failure signatures:
  - Low MOS scores indicate poor speech quality
  - Low comprehension scores suggest IPA mapping or understandability issues
  - Low intelligibility scores may indicate phonetic representation or generalization problems
- First 3 experiments:
  1. Validate IPA mapping accuracy by synthesizing words from each target language and comparing with native speaker recordings
  2. Test TTS model on single target language (e.g., Turkish) before scaling to all ten languages
  3. Conduct small-scale subjective evaluation with native speakers to validate comprehensibility and intelligibility

## Limitations
- IPA-based transliteration may not capture all phonetic nuances across ten languages, particularly for language-specific sounds
- Subjective evaluation based on small number of raters (10) may not be fully representative of native speakers' perceptions
- Study doesn't address prosody, stress patterns, and intonation variations across different Turkic languages

## Confidence
- High confidence: IPA-based transliteration mechanism for zero-shot learning is sound and well-supported by experimental results
- Medium confidence: Assumption about shared linguistic features enhancing generalization is plausible but not quantitatively validated
- Low confidence: Scalability to non-Turkic languages or languages with different phonological systems is uncertain
