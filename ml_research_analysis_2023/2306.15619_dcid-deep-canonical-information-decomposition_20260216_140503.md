# DCID: Deep Canonical Information Decomposition

## Quick Facts
- arXiv ID: 2306.15619
- Source URL: https://arxiv.org/abs/2306.15619
- Authors: 
- Reference count: 40
- Primary result: DCID outperforms baseline models in extracting shared signal between univariate targets using high-dimensional observations

## Executive Summary
DCID addresses the challenge of identifying shared signals between two univariate target variables using high-dimensional observations. The method trains separate deep neural network classifiers for each target variable, extracts multivariate representations from their penultimate layers, and applies Canonical Correlation Analysis (CCA) to identify the most correlated components as the shared signal. DCID introduces the ICM score as a novel evaluation metric that quantifies informativeness, completeness, and minimality of learned shared features when ground-truth labels are available.

## Method Summary
DCID works by training separate DNN classifiers for two univariate target variables (Y1, Y2) using the same high-dimensional input X. The penultimate layer outputs of these classifiers provide k-dimensional latent representations (B1, B2) that serve as multivariate "views" of the originally univariate targets. CCA is then applied to these multivariate views to extract the most correlated components, which are selected based on a correlation threshold T to form the final shared representation Ẑ. The method is evaluated using the ICM score, which measures three aspects of learned shared features: informativeness (can Z be predicted from the learned representation?), completeness (can the learned representation be predicted from Z?), and minimality (does the learned representation only contain information about Z?).

## Key Results
- DCID outperforms multi-task learning, multi-task feature learning, and adversarial MTL baselines on synthetic data across various scenarios
- DCID shows superior performance in real-life applications on brain MRI data, extracting more accurate predictors of brain regions and obesity-related changes
- The ICM score provides a principled framework for evaluating shared feature recovery when ground truth is available

## Why This Works (Mechanism)

### Mechanism 1
- Claim: DCID leverages multivariate decompositions of univariate targets to enable CCA.
- Mechanism: The model trains separate DNN classifiers for each univariate target (Y1, Y2) using the same high-dimensional input X. The penultimate layer outputs of these classifiers provide k-dimensional latent representations (B1, B2) that act as multivariate "views" of the originally univariate targets. CCA is then applied to these multivariate views to extract the shared components.
- Core assumption: The penultimate layer of the DNN classifiers captures meaningful multivariate structure about the univariate targets that reflects their shared underlying signal.
- Evidence anchors:
  - [abstract]: "DCID trains separate DNN classifiers for each target variable, uses their penultimate layer outputs as multivariate representations, and applies CCA to identify the most correlated components as the shared signal."
  - [section]: "Specifically, we assume that both Yi can be approximated as transformations of X with functions hi(X) = Ŷi. We further assume they can be decomposed as hi = gi ◦ fi, where fi : Rl → Rk... The k-dimensional outputs of fi(X) = Bi constitute the multivariate decompositions of Yi."
- Break condition: If the DNN classifiers fail to learn meaningful latent representations that capture the shared structure between targets, the penultimate layer outputs will not provide useful multivariate views for CCA.

### Mechanism 2
- Claim: The ICM score provides a principled evaluation framework for shared feature recovery.
- Mechanism: The ICM score quantifies three aspects of learned shared features: informativeness (can Z be predicted from the learned representation?), completeness (can the learned representation be predicted from Z?), and minimality (does the learned representation only contain information about Z?). This allows systematic evaluation of how well models recover the true shared signal when ground truth is available.
- Core assumption: The three components of the ICM score (informativeness, completeness, minimality) capture the essential properties needed to evaluate shared feature recovery.
- Evidence anchors:
  - [abstract]: "We define the ICM score, which evaluates 3 aspects of learned shared features: informativeness, completeness, and minimality, when ground-truth labels are available."
  - [section]: "Inspired by the DCI score [15] from the field of disentangled representation learning, we define the following requirements for a learned representation Ẑ as correctly identifying the shared variable Z: 1. Informativeness... 2. Compactness... 3. Minimality..."
- Break condition: If the ground truth latent variables Z, Z1, Z2 are not accurately known or measured, the ICM score cannot be computed reliably.

### Mechanism 3
- Claim: The threshold-based selection of canonical components enables adaptive dimensionality for the shared representation.
- Mechanism: After applying CCA to the multivariate decompositions B1, B2, DCID selects the top n pairs of canonical variables with correlations above a threshold T. This adaptive selection ensures that only components with meaningful shared signal are included in the final representation Ẑ.
- Core assumption: Canonical components with higher correlation between B1 and B2 are more likely to represent the shared signal Z.
- Evidence anchors:
  - [abstract]: "We then take the Ẑ = 1/2(C1,1:n + C2,1:n) as our estimate of the shared Z."
  - [section]: "In order to extract the most informative features, we can select the n pairs of canonical variables with correlations above a certain threshold T: n = argmaxi∈|k| corr(C1,i, C2,i) > T"
- Break condition: If the correlation threshold T is set too high, important shared components may be excluded; if set too low, noise components may be included.

  - Quick check question: Why use the penultimate layer rather than the final output layer of the DNN classifiers?

  - Why needed here: Understanding how features can be shared across tasks helps contextualize why DCID aims to extract shared representations rather than just task-specific ones.

## Architecture Onboarding

- Component map: X -> DNN1 -> B1 -> CCA -> C1 -> Ẑ (and parallel path through DNN2)
- Critical path: X → DNN1 → B1 → CCA → C1 → Ẑ (and parallel path through DNN2)
- Design tradeoffs:
  - DNN architecture choice affects representation quality vs. computational cost
  - CCA threshold T trades off between including all potentially shared signal vs. filtering noise
  - Dimensionality of penultimate layer k affects expressiveness vs. overfitting risk
- Failure signatures:
  - Low informativeness score: DNN classifiers not capturing shared structure
  - Low completeness score: CCA not finding good linear mappings back to Z
  - High minimality score: Learned representation including task-specific information
- First 3 experiments:
  1. Train DCID on synthetic data where Z explains 90% of variance in both Y1 and Y2, verify ICM ≈ 1
  2. Train DCID on synthetic data where Z explains minimal variance, verify ICM ≈ 0
  3. Train DCID with different DNN architectures (e.g., ResNet vs. MobileNet) and compare ICM scores

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of DCID change when the shared signal Z is non-linearly related to the target variables Y1 and Y2?
- Basis in paper: [explicit] The paper mentions that the functions ψi and ϕi can be arbitrary functions from R^k to R, but DCID uses linear CCA on the penultimate layer outputs.
- Why unresolved: The paper only tests DCID with linear relationships between Z and Yi, leaving the non-linear case unexplored.
- What evidence would resolve it: Experiments testing DCID on synthetic data where Z relates non-linearly to Yi, comparing performance with different types of non-linear relationships.

### Open Question 2
- Question: What is the optimal number of shared components (n) to select in DCID, and how sensitive is the method to this choice?
- Basis in paper: [explicit] The paper selects components based on a correlation threshold T, but doesn't systematically explore how this choice affects performance.
- Why unresolved: The paper mentions using a threshold but doesn't provide guidance on how to set it or analyze its sensitivity.
- What evidence would resolve it: A systematic study varying T across different scenarios, showing how ICM scores change with different threshold values.

### Open Question 3
- Question: How does DCID perform when the individual variables Z1 and Z2 are correlated with each other?
- Basis in paper: [explicit] The paper assumes Z1 ⊥ Z2 in the model, but doesn't test what happens when this assumption is violated.
- Why unresolved: All synthetic experiments assume independence between Z1 and Z2, which may not reflect real-world scenarios.
- What evidence would resolve it: Experiments on synthetic data where Z1 and Z2 have varying degrees of correlation, measuring how this affects DCID's ability to recover the shared signal.

### Open Question 4
- Question: How does the dimensionality of the input observations X affect DCID's performance in recovering the shared signal?
- Basis in paper: [inferred] The paper uses high-dimensional images (64x64 pixels) but doesn't explore how performance changes with different input dimensionalities.
- Why unresolved: The paper doesn't test DCID on inputs with varying numbers of features or dimensions.
- What evidence would resolve it: Experiments varying the dimensionality of X while keeping the underlying signal structure constant, measuring how this affects ICM scores.

## Limitations
- The method requires ground truth labels for computing the ICM score, limiting applicability to scenarios where such labels are available
- Performance appears sensitive to the correlation threshold parameter T, with sudden performance drops at certain threshold values
- Claims of superior performance in real-life applications are limited by narrow validation scope and lack of comparison with alternative approaches

## Confidence

**High Confidence**: The mechanism by which DCID creates multivariate decompositions from univariate targets through DNN penultimate layers is well-founded and technically sound. The use of CCA for identifying shared components follows established statistical methodology.

**Medium Confidence**: The ICM score formulation provides a reasonable framework for evaluating shared feature recovery, though its practical utility depends on accurate ground truth measurements which may not always be available in real-world applications.

**Low Confidence**: The paper's claim of superior performance in real-life applications on brain MRI data is limited by the relatively narrow scope of validation and the lack of comparison with alternative methods that might achieve similar results through different approaches.

## Next Checks

1. **Threshold Sensitivity Analysis**: Systematically vary the correlation threshold T across its full range and document the ICM score behavior to identify the optimal threshold range and understand the cause of sudden performance drops.

2. **Cross-dataset Generalization**: Apply DCID to additional real-world datasets beyond brain MRI (e.g., multi-modal medical imaging, environmental sensor data) to assess the method's robustness across different domains and data characteristics.

3. **Alternative Representation Learning Comparison**: Compare DCID's performance against other representation learning approaches (e.g., variational autoencoders, contrastive learning) that could also extract shared features without requiring separate classifiers for each target.
