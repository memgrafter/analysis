# PartitionVAE -- a human-interpretable VAE

## Quick Facts
- arXiv ID: 2302.03689
- Source URL: https://arxiv.org/abs/2302.03689

## Executive Summary
This paper introduces PartitionVAE, a variant of variational autoencoders designed to create more interpretable latent representations by partitioning the latent space into disjoint sets of interconnected units. The core idea is to group together correlated features of the input space into partitions, making the latent representation more human-interpretable. The authors test their model on MNIST and a table tennis dataset from Sports10. On MNIST, the model successfully reconstructs digits and demonstrates that individual partitions perform comprehensible transformations on the output. However, on the more complex table tennis dataset, the model struggles to capture dynamic elements like player positions and viewing angles, producing blurry outputs that average out intra-class differences. While the model can distinguish between different games and capture static aspects like table position and background, it fails to efficiently compress the representation due to many partitions having little to no effect on the output.

## Method Summary
PartitionVAE modifies the standard VAE architecture by introducing a partition layer between the encoder and decoder. The encoder processes the input through convolutional layers, then passes the representation through multiple partitions, each containing neural networks that produce mean and log variance values. These partitions are disjoint sets of interconnected units that enforce correlation structure in the latent space. The decoder reconstructs the image from samples drawn from the partitioned latent space. The model uses a weighted sum of reconstruction loss (MSE) and KL divergence as its loss function, and implements subresolution output to reduce computational complexity.

## Key Results
- On MNIST, PartitionVAE successfully reconstructs digits and demonstrates interpretable transformations through individual partitions
- On the Sports10 table tennis dataset, the model struggles with dynamic elements like player positions and viewing angles, producing blurry averaged outputs
- The model can distinguish between different games and capture static features like table position and background, but many partitions have little effect on the output, suggesting inefficient compression

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Partitioning the latent space forces correlated input features to share partitions, improving interpretability
- Mechanism: By grouping neurons into partitions where each partition is connected to its own neural network, the model learns to map correlated input features to the same partition. This creates a structured latent space where each partition represents a coherent feature of the input.
- Core assumption: Input features can be meaningfully grouped by correlation, and these groups correspond to human-interpretable concepts
- Evidence anchors:
  - [abstract] "grouping together similar features (features of the input space with high correlation)"
  - [section 3] "Partitioning the representation layer into disjoint sets of interconnected units yields a prior that features of the input space to this new VAE...are grouped together by correlation"
  - [corpus] Weak - related papers focus on different VAE variants (CV-VAE, ESVAE) without addressing partitioning specifically

### Mechanism 2
- Claim: The KL divergence term maintains the normal distribution prior while partitions enforce feature correlation structure
- Mechanism: The standard VAE loss includes KL divergence to enforce normality in the latent space. PartitionVAE adds a structural constraint on top of this by forcing correlated features into the same partition, creating a hierarchical prior: normal distribution at the global level, but structured correlation within partitions
- Core assumption: The combination of normality prior and partition structure creates a more interpretable latent space than either alone
- Evidence anchors:
  - [abstract] "VAEs classically assume the latent space is normally distributed, though many distribution priors work, and they encode this assumption through a K-L divergence term in the loss function"
  - [section 3] "The loss function is a weighted sum of reconstruction loss and K-L divergence, the former to ensure the output resembles the input and the latter to maintain the prior that the representation is normally distributed"
  - [corpus] No direct evidence - related papers don't discuss this specific interaction between KL divergence and partition structure

### Mechanism 3
- Claim: Subresolution reduces computational complexity while maintaining reconstruction quality
- Mechanism: By outputting images at lower resolution and upscaling for loss calculation, the model reduces the number of pixels it needs to reconstruct, decreasing the decoder complexity and training time. The interpolation step fills in the missing detail
- Core assumption: The most important information in images is preserved at lower resolutions, and interpolation can reasonably approximate the missing detail
- Evidence anchors:
  - [abstract] "we attempt to decrease the complexity of the PVAE by outputting an image with dimensions scaled down from the input image by a constant factor"
  - [section 4.3] "we downscale the input image, and upsample at the end. We made this decision in order to speed up the training time and reduce the reliance on compute power"
  - [corpus] No direct evidence - related papers don't discuss this specific subresolution technique

## Architecture Onboarding

- Component map: Encoder -> Convolutional layers -> Flatten -> Linear layer -> Partition layer -> Linear layers (per partition) -> Decoder -> Linear layers -> Convolutional/deconvolutional layers -> Upsampling
- Critical path: Image -> Encoder -> Partition layer (sampling) -> Decoder -> Output image
- Design tradeoffs: More partitions -> better interpretability but potentially less efficient compression; subresolution -> faster training but lower detail; KL weight -> stronger normality prior but potentially worse reconstruction
- Failure signatures: Blurry outputs suggesting poor reconstruction; partitions with no visible effect suggesting inefficient representation; slow convergence suggesting architectural issues
- First 3 experiments:
  1. Train on MNIST with 3 partitions (sizes 4, 3, 3) to verify basic functionality and interpretability
  2. Test different partition sizes on MNIST to find optimal balance between interpretability and reconstruction quality
  3. Apply the best configuration from MNIST to a small subset of the table tennis dataset to test scalability to more complex data

- Why unresolved: The paper mentions this as a limitation but does not provide a specific solution or modification to address it.

### Open Question 2
- Question: What loss function modifications could help PVAE better distinguish between intra-class differences in complex scenes?
- Basis in paper: [explicit] The authors suggest that PVAE's tendency to average out differences within a class might be mitigated by structuring the loss function to better penalize stationary outputs.
- Why unresolved: The paper only proposes this idea but does not implement or test it.
- What evidence would resolve it: Quantitative comparison of reconstruction quality and interpretability metrics between the original loss function and modified versions that explicitly penalize averaging.

### Open Question 3
- Question: How does the number and size of partitions in the representation layer affect the interpretability and reconstruction quality of PVAE?
- Basis in paper: [explicit] The authors test different partition configurations but do not systematically analyze the relationship between partition structure and model performance.
- Why unresolved: The paper presents results with specific partition sizes but does not explore the full parameter space or provide guidelines for optimal partition design.
- What evidence would resolve it: A comprehensive study varying partition numbers and sizes, with quantitative metrics for both reconstruction accuracy and interpretability (e.g., human evaluation of partition-specific transformations).

## Limitations
