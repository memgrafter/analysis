# Mispronunciation Detection of Basic Quranic Recitation Rules using Deep Learning

## Quick Facts
- arXiv ID: 2305.06429
- Source URL: https://arxiv.org/abs/2305.06429
- Reference count: 40
- Primary result: LSTM model achieves 96%, 95%, and 96% accuracy for Separate stretching, Tight Noon, and Hide Tajweed rules respectively

## Executive Summary
This paper addresses the challenge of automatic mispronunciation detection for Quranic recitation rules (Tajweed) using deep learning. The authors propose an LSTM-based approach with MFCC features to leverage the temporal structure of speech signals. Experiments on the public QDAT dataset containing over 1500 audio samples demonstrate that LSTM models significantly outperform traditional machine learning methods, achieving high accuracy rates for three basic Tajweed rules.

## Method Summary
The proposed method uses Mel-Frequency Cepstral Coefficients (MFCC) extracted from audio signals as features, which are then fed into a Long Short-Term Memory (LSTM) neural network. The audio preprocessing includes pre-emphasis filtering (α=0.97), 32ms framing, and Hamming windowing. The LSTM architecture consists of three layers with 256 units each, followed by three fully connected layers with 16, 16, and 8 units, and dropout layers with a rate of 0.2. The model is trained using binary cross-entropy loss with the RMSprop optimizer (learning rate 0.0005) on a 90-10 train-test split of the QDAT dataset.

## Key Results
- LSTM model achieved 96% accuracy for Separate stretching rule
- LSTM model achieved 95% accuracy for Tight Noon rule
- LSTM model achieved 96% accuracy for Hide rule
- Performance significantly outperforms traditional machine learning approaches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LSTM networks effectively capture sequential dependencies in speech signals for Tajweed mispronunciation detection
- Mechanism: LSTM networks have internal memory cells that can retain information over long sequences, allowing them to consider the temporal structure of speech frames when making pronunciation judgments
- Core assumption: Mispronunciation in Tajweed rules manifests as patterns across consecutive speech frames rather than isolated frame errors
- Evidence anchors: Abstract mentions LSTM superiority with 96%, 95%, and 96% accuracy; Section 3.4 discusses LSTM applications in speech domains

### Mechanism 2
- Claim: MFCC feature extraction effectively represents acoustic characteristics relevant to Tajweed rules
- Mechanism: MFCC transforms speech signals into a compact representation that mimics human auditory perception, capturing the spectral envelope containing pronunciation information
- Core assumption: Key acoustic features distinguishing correct from incorrect Tajweed pronunciation are captured in the MFCC representation
- Evidence anchors: Section 3.3 states MFCC is the most widespread method for spectral feature extraction; Abstract mentions MFCC with LSTM

### Mechanism 3
- Claim: Using a public dataset enables reproducibility and benchmarking
- Mechanism: Public datasets allow other researchers to validate results, compare methods, and build upon existing work
- Core assumption: QDAT dataset adequately represents pronunciation pattern diversity needed for robust training
- Evidence anchors: Abstract mentions QDAT dataset with 1500+ voices; Section 3.1 notes it's the first work on this dataset

## Architecture Onboarding

- Component map: WAV audio files -> Pre-emphasis filter -> Framing with Hamming window -> MFCC extraction -> LSTM layers -> Fully connected layers -> Classification output

- Critical path: Audio preprocessing → MFCC feature extraction → LSTM sequence modeling → Classification layer → Prediction

- Design tradeoffs:
  - MFCC vs. other features: MFCC provides good balance of information and dimensionality but may miss some fine-grained acoustic details
  - LSTM vs. other sequence models: LSTMs handle vanishing gradients well but are more computationally intensive than simpler RNNs
  - Public vs. private dataset: Public enables reproducibility but may have less control over data quality

- Failure signatures:
  - High accuracy on training but low on test: Overfitting, consider regularization or data augmentation
  - Poor performance on specific rules: Rule-specific feature engineering or imbalanced dataset
  - Long training times: Consider reducing LSTM units or using smaller batch sizes

- First 3 experiments:
  1. Baseline comparison: Train the same LSTM architecture on MFCC features vs. raw audio features to validate the feature extraction step
  2. Ablation study: Remove LSTM layers and use only fully connected layers to demonstrate the importance of sequence modeling
  3. Data augmentation: Apply pitch shifting and time stretching to the audio data to test model robustness to pronunciation variations
