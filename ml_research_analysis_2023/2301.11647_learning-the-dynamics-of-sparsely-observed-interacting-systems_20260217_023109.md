# Learning the Dynamics of Sparsely Observed Interacting Systems

## Quick Facts
- **arXiv ID**: 2301.11647
- **Source URL**: https://arxiv.org/abs/2301.11647
- **Reference count**: 40
- **Key outcome**: Novel approach for learning dynamics of sparsely observed interacting systems by framing the task as linear regression in signature space, with statistical guarantees and demonstrated effectiveness on COVID-19 forecasting

## Executive Summary
This paper introduces a method for learning the dynamics of interacting systems where target time series are sparsely observed while feature time series are frequently measured. The authors cast this as learning the solution map of a controlled differential equation (CDE) and linearize it in the signature space, reducing the problem to high-dimensional linear regression. The resulting SigLasso algorithm provides statistical guarantees on prediction error that explicitly account for sampling irregularities and measurement noise, and outperforms existing methods on both simulated and real-world data.

## Method Summary
The approach models the target dynamics as a CDE driven by the feature path, then linearizes the solution map using the signature of the feature path. This linearization enables casting the non-linear problem as high-dimensional linear regression. The method computes signatures of normalized feature paths up to a chosen depth N, constructs a feature matrix from these signatures, and fits a regularized linear regression model (SigLasso with ℓ1 penalty) to estimate the dynamics. Cross-validation is used to select optimal signature depth and regularization strength.

## Key Results
- SigLasso achieves L2 reconstruction error of 0.7-1.6 on synthetic well-specified data
- Outperforms GRU and Neural CDE baselines on both synthetic and real-world COVID-19 hospitalization forecasting
- Provides oracle bounds on prediction error that explicitly depend on sampling irregularities and measurement noise

- Mechanism: The CDE solution map Ψ can be expressed as a linear product between the signature of the feature path and a time-independent parameter matrix θ* using Taylor expansion
- Core assumption: The vector field F governing the CDE dynamics is smooth enough for Taylor expansion convergence

## Architecture Onboarding

- Component map: Feature path → signature computation → feature matrix construction → regularized regression → parameter learning → target prediction
- Critical path: Feature path → signature computation → feature matrix construction → regularized regression → parameter learning → target prediction
- Design tradeoffs:
  - Signature depth N vs. truncation bias and computational cost (exponential growth in signature size)
  - Sampling frequency vs. discretization error (finer sampling reduces error but may increase noise effects)
  - Regularization strength vs. bias-variance tradeoff in parameter estimation
- Failure signatures:
  - Poor performance with highly noisy feature paths (signature amplification of noise)
  - Degradation with very irregular sampling patterns beyond interpolation capability
  - Failure to converge when vector field lacks smoothness
- First 3 experiments:
  1. Synthetic well-specified data: Generate ODE-driven target paths with known smooth vector field, test recovery accuracy
  2. Irregular sampling test: Compare performance across varying sampling densities and gaps in feature path
  3. Noise sensitivity test: Vary measurement noise levels on feature paths and observe performance degradation patterns

## Limitations
- Linearization mechanism has weak theoretical validation for Taylor expansion convergence
- Error bounds have unverified dependencies on signature order N
- Performance may degrade when feature paths cannot be reasonably interpolated
