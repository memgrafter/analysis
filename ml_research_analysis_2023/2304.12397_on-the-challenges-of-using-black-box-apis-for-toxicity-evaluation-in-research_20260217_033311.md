# On the Challenges of Using Black-Box APIs for Toxicity Evaluation in Research

## Quick Facts
- **arXiv ID**: 2304.12397
- **Source URL**: https://arxiv.org/abs/2304.12397
- **Reference count**: 23
- **Primary result**: Updates to the Perspective API caused a 49% relative decrease in toxic prompts and 34% reduction in average toxicity scores, affecting the reproducibility of language model toxicity evaluations.

## Executive Summary
This paper investigates the reproducibility challenges posed by updates to the Perspective API, a commercial black-box tool for detecting toxicity in text, on academic research comparing language models. The authors demonstrate that rescoring the RealToxicityPrompts dataset with a newer version of the API leads to significant changes in toxicity metrics and model rankings. When evaluating 37 widely used language models from the HELM benchmark, 13 models showed changes in toxicity scores, resulting in 24 changes in the Toxic Fraction metric ranking. The study also replicates six published toxicity mitigation techniques, finding that results from as recently as 2022 are affected by API updates. The authors recommend that authors release model generations and scores, always rescore open-source generations for fair comparison, and that benchmark maintainers establish control sets for rescoring. The study highlights the importance of accounting for API versioning in research using black-box toxicity evaluation tools to ensure reproducibility and fair comparison of techniques over time.

## Method Summary
The study rescored the RealToxicityPrompts dataset (25K prompts) and 37 language models from the HELM benchmark using the latest Perspective API version. Three toxicity metrics were computed: Expected Maximum Toxicity (EMT), Toxicity Probability (TP), and Toxic Fraction (TF). The authors compared model rankings before and after rescoring to identify changes. They also replicated six published toxicity mitigation techniques, generating new scores using the latest API version to assess the impact of API updates on previously published results.

## Key Results
- Rescoring RealToxicityPrompts with a newer API version led to a 49% relative decrease in toxic prompts and a 34% reduction in average toxicity scores.
- 13 out of 37 HELM models showed changes in toxicity scores, resulting in 24 changes in the Toxic Fraction metric ranking.
- Six published toxicity mitigation techniques were affected when rescored with the latest API version, with results from as recently as 2022 impacted.

## Why This Works (Mechanism)
The Perspective API is a black-box commercial tool, meaning researchers cannot access or control its internal models or version updates. When the API's toxicity detection model is updated, it can lead to changes in the scores assigned to text, even if the text itself remains unchanged. This creates a reproducibility challenge for research that relies on these scores to compare language models or evaluate toxicity mitigation techniques over time.

## Architecture Onboarding
**Component Map**: RealToxicityPrompts dataset -> Perspective API v1 -> Toxicity scores -> Language models -> HELM benchmark -> Rescoring with Perspective API v2 -> Updated toxicity scores -> Model rankings -> Published mitigation techniques -> Replication with updated scores

**Critical Path**: The study's main finding hinges on the rescoring of the RealToxicityPrompts dataset and HELM models with the latest Perspective API version, comparing the resulting toxicity scores and model rankings to the original scores.

**Design Tradeoffs**: Using a commercial black-box API like Perspective API offers convenience and scalability but introduces risks of score changes due to updates and lack of transparency. Open-source alternatives or human annotation could provide more control but may be less scalable or consistent.

**Failure Signatures**: Systematic shifts in toxicity scores across all models rather than individual anomalies, indicating API updates rather than model-specific issues. Missing or incomplete model generations for some HELM models, potentially skewing the analysis.

## Open Questions the Paper Calls Out
1. How do changes in the Perspective API's toxicity detection model affect the validity of previously published toxicity mitigation research results? The paper shows that research results from as recently as 2022 are affected when rescored with a more recent version of the Perspective API, posing a reproducibility challenge for papers that inherit scores to evaluate the merits of new techniques. A systematic study comparing the performance of toxicity mitigation techniques when evaluated with different versions of the Perspective API, along with guidelines for proper rescoring and versioning in future research, would resolve this question.

2. What are the long-term implications of using black-box commercial APIs for toxicity evaluation in research, and how can the research community mitigate these issues? The paper highlights the challenges of using black-box APIs like Perspective API for toxicity evaluation, including the lack of version control, poor communication of updates, and the impact on reproducibility and fair comparison of techniques over time. A comprehensive analysis of the benefits and drawbacks of using black-box APIs for toxicity evaluation, along with a comparison of alternative methods such as human annotation or open-source models, and guidelines for selecting the most appropriate evaluation approach, would resolve this question.

3. How can benchmark maintainers ensure the long-term reliability and reproducibility of toxicity evaluation results when using black-box APIs? The paper suggests that benchmark maintainers establish a control set of sequences that is rescored with Perspective API on every model addition, and if the toxicity metrics for that control set change, all previous models should be rescored. A case study of a benchmark implementing the recommended control set approach, along with an analysis of its effectiveness in maintaining result consistency and reproducibility, and a comparison with other potential strategies such as versioned APIs or open-source evaluation tools, would resolve this question.

## Limitations
- The study relies entirely on a commercial black-box API whose internal updates are opaque, creating fundamental uncertainty about what specific changes drive score variations.
- The analysis assumes the Perspective API v1-to-v2 update is the sole source of score changes, but cannot definitively attribute score differences to particular model refinements.
- The study focuses on language model toxicity evaluation, limiting generalizability to other domains using black-box APIs.

## Confidence
- **High Confidence**: The empirical demonstration that API updates cause measurable score changes across toxicity metrics and model rankings.
- **Medium Confidence**: The claim that 13 out of 37 HELM models showed changes in toxicity scores.
- **Medium Confidence**: The recommendation to always rescore open-source generations for fair comparison.
- **Low Confidence**: The generalizability of findings to other black-box APIs beyond Perspective API.
