# Multilingual Detection of Check-Worthy Claims using World Languages and Adapter Fusion

## Quick Facts
- **arXiv ID**: 2301.05494
- **Source URL**: https://arxiv.org/abs/2301.05494
- **Reference count**: 40
- **Key outcome**: Adapter fusion with world languages outperforms fully fine-tuned transformers for multilingual check-worthiness detection

## Executive Summary
This paper proposes a resource-efficient approach for detecting check-worthy claims across multiple languages, particularly addressing the challenge of low-resource languages where fact-checking expertise is scarce. The authors use adapter fusion to combine task adapters trained on English, Arabic, and Spanish, enabling detection of claims in zero-shot languages (Turkish, Bulgarian, Dutch) without requiring target language data. Their approach achieves competitive performance while being more parameter-efficient than full fine-tuning, and provides interpretable results showing which source languages contribute most to predictions in target languages.

## Method Summary
The method trains task adapters on world language datasets (English, Arabic, Spanish) for check-worthiness detection, then combines these adapters using adapter fusion to detect claims in zero-shot languages (Turkish, Bulgarian, Dutch). The approach uses multilingual transformers (mBERT, XLM-R) as base models, with language adapters pre-trained on Wikipedia text for each language. Adapter fusion learns attention weights to dynamically combine knowledge from the task adapters, enabling cross-lingual transfer without catastrophic forgetting. The system is evaluated on CLEF CheckThat! Lab datasets using F1 and MAP metrics, with additional topical analysis to distinguish global versus local claim detection performance.

## Key Results
- Adapter fusion outperforms fully fine-tuned transformers and other multilingual baselines in several zero-shot languages
- The approach achieves good performance on both global and local topical claims
- Attention weights provide interpretable insights into which source language adapters contribute most to target language predictions
- The method demonstrates effective cross-lingual knowledge transfer while being more parameter-efficient than full fine-tuning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Adapter fusion effectively transfers knowledge from world languages (WLs) to zero-shot languages by dynamically combining task adapters
- Mechanism: The adapter fusion module learns attention weights to dynamically combine knowledge from task adapters trained on WLs (English, Arabic, Spanish) when predicting claims in unseen languages (Turkish, Bulgarian, Dutch)
- Core assumption: Knowledge about check-worthiness can be transferred across languages through adapter fusion without catastrophic forgetting
- Evidence anchors:
  - [abstract] "cross-training adapters on a subset of world languages, combined by adapter fusion, to detect claims emerging globally in multiple languages"
  - [section] "AF is a method for combining multiple TAs, and mitigating the common issues of multi-task learning, such as catastrophic forgetting and complete model retraining for supporting new tasks"
  - [corpus] Weak evidence - only mentions related work on check-worthiness detection, no direct evidence about adapter fusion performance
- Break condition: If the attention weights learned by adapter fusion do not properly weight task adapters for zero-shot languages, performance would degrade significantly.

### Mechanism 2
- Claim: Adapter-based approaches are more resource-efficient than fully fine-tuning transformer models for multilingual check-worthiness detection
- Mechanism: Adapters require fewer parameters than full fine-tuning, allowing storage-efficient model updates and frequent retraining with limited computational resources
- Core assumption: The storage and computational savings from adapters outweigh any potential performance loss compared to full fine-tuning
- Evidence anchors:
  - [abstract] "With a vast number of annotators available for world languages and the storage-efficient adapter models, this approach is more cost efficient"
  - [section] "Adapters are lightweight and modular neural networks, learning tasks with fewer parameters and transferring knowledge across tasks"
  - [corpus] Weak evidence - related papers mention transformer models but don't provide direct comparisons with adapter-based approaches
- Break condition: If the performance gap between adapters and full fine-tuning becomes too large, the resource efficiency advantage may not justify the approach.

### Mechanism 3
- Claim: Adapter fusion provides interpretability by showing which source language adapters contribute most to predictions in target languages
- Mechanism: The attention weights in adapter fusion indicate the relative contribution of each task adapter, allowing analysis of which WLs are most useful for specific target languages
- Core assumption: The attention weights in adapter fusion are meaningful indicators of which source task adapters are most useful for specific target languages
- Evidence anchors:
  - [abstract] "Adapter fusion provides insights and allows for interpretation regarding the influence of each adapter model on a particular language"
  - [section] "By analyzing the attention weights of the AF, we could learn which source task adapter contributes more to test predictions"
  - [corpus] Weak evidence - related papers don't discuss interpretability of adapter fusion approaches
- Break condition: If the attention weights are not reliable indicators of adapter contribution, the interpretability benefit would be lost.

## Architecture Onboarding

- **Component map**: Base transformer (mBERT/XLM-R) → Language Adapters → Task Adapters → Adapter Fusion → Prediction layer
- **Critical path**: Training task adapters on WLs → Training adapter fusion to combine task adapters → Evaluating on zero-shot languages
- **Design tradeoffs**: Parameter efficiency vs. potential performance loss compared to full fine-tuning
- **Failure signatures**: Poor performance on zero-shot languages, high variance in attention weights, overfitting to source languages
- **First 3 experiments**:
  1. Train individual task adapters on each WL dataset and evaluate on same language to establish baseline performance
  2. Train adapter fusion with all WLs and evaluate on zero-shot languages to test cross-lingual transfer
  3. Compare adapter fusion with simple averaging of task adapter predictions to validate fusion approach

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the adapter fusion approach perform on detecting check-worthy claims in languages that are not world languages (e.g., low-resource languages like Finnish or Swahili) without any target language adapters?
- Basis in paper: [explicit] The paper mentions zero-shot learning experiments with Turkish, Bulgarian, and Dutch, which are not considered world languages, and shows good performance, but doesn't specifically test truly low-resource languages without any target language adapters
- Why unresolved: The paper only evaluates on languages with some available data and adapters, not on truly low-resource languages where no target language adapters could be obtained
- What evidence would resolve it: Testing the adapter fusion model on genuinely low-resource languages with no target language adapters, comparing against fully fine-tuned models and other baselines

### Open Question 2
- Question: How does the performance of the adapter fusion model change when the source language adapters have very different topical distributions from the target language?
- Basis in paper: [inferred] The paper discusses topical evaluation and shows attention weights can vary based on topical relationships, but doesn't systematically vary the topical distributions between source and target languages
- Why unresolved: While the paper shows topical relationships affect performance, it doesn't control for or vary the degree of topical mismatch between source and target languages
- What evidence would resolve it: Controlled experiments varying the topical overlap between source and target language datasets while measuring adapter fusion performance

### Open Question 3
- Question: What is the optimal number of world language adapters to include in the adapter fusion model for maximum performance across different target languages?
- Basis in paper: [explicit] The paper uses three world languages (English, Arabic, Spanish) but doesn't explore whether adding more world languages or using fewer would improve performance
- Why unresolved: The paper fixes the number of world language adapters at three without exploring the trade-off between model complexity and performance
- What evidence would resolve it: Systematic experiments varying the number of world language adapters in the fusion model and measuring performance on various target languages

## Limitations

- Evaluation limited to three zero-shot languages and three world languages, which may not generalize to other language families
- Interpretability claims through attention weights analysis lack rigorous validation and ablation studies
- Resource efficiency claims are supported by parameter counts but lack comprehensive runtime or memory usage comparisons

## Confidence

- **Performance claims**: Medium - competitive results shown but limited language coverage
- **Efficiency claims**: Medium - parameter efficiency demonstrated but runtime benchmarks incomplete
- **Interpretability claims**: Low - attention weight analysis promising but lacks validation

## Next Checks

1. **Cross-language generalization test**: Evaluate the adapter fusion approach on languages from different language families (e.g., Asian languages like Japanese or Korean) to test whether the cross-lingual transfer benefits extend beyond the current Indo-European and Semitic language pairs.

2. **Attention weight interpretability validation**: Conduct controlled experiments where task adapters are trained on semantically distinct topics, then verify whether the attention weights in adapter fusion correctly prioritize relevant adapters based on the topical content of target language claims.

3. **Resource efficiency benchmarking**: Implement comprehensive runtime and memory profiling comparing adapter fusion against full fine-tuning across different batch sizes and sequence lengths to validate the claimed computational efficiency benefits under realistic deployment scenarios.
