# Controlling Learned Effects to Reduce Spurious Correlations in Text Classifiers

## Quick Facts
- arXiv ID: 2305.16863
- Source URL: https://arxiv.org/abs/2305.16863
- Reference count: 23
- Key outcome: Introduces Riesz-based estimator for feature effects and Feature Effect Augmentation (FEAG) method to reduce spurious correlations while maintaining accuracy

## Executive Summary
This paper addresses spurious correlations in text classifiers by proposing a method that enforces learned feature effects to match their true causal effects. The authors introduce a novel Riesz-based estimator for feature effects that avoids the high variance issues of propensity-based methods, particularly in low-overlap settings. They then use these estimated effects to generate counterfactual augmentations that train models to learn the correct causal relationships rather than spurious correlations.

## Method Summary
The paper proposes Feature Effect Augmentation (FEAG), which first estimates feature effects using a Riesz-based estimator that directly learns the contribution of each sample without requiring inverse propensity weighting. These estimated effects are then used to generate counterfactual training examples with modified labels that reflect the true causal effect. The model is trained on both original and augmented data, forcing it to learn the correct feature effects rather than spurious correlations. The approach is evaluated on toxicity classification and movie review datasets.

## Key Results
- Riesz-based estimator outperforms Direct and Propensity-based estimators in ATE estimation accuracy on semi-synthetic CivilComments data
- FEAG achieves better overall accuracy while reducing spurious correlations compared to existing baselines on CivilComments and IMDB datasets
- The method provides a favorable trade-off between majority and minority group accuracy
- Feature effect estimator is useful for detecting annotator bias in datasets

## Why This Works (Mechanism)

### Mechanism 1
The Riesz-based estimator directly estimates the coefficient for each sample's contribution to the feature effect, avoiding high variance from inverse propensity weighting. Instead of estimating propensities P(T|X) and computing α=Ti/P(Xi) - (1-Ti)/(1-P(Xi)), the Riesz estimator learns αR(Z) directly through a loss that enforces E[αR(Z)f(Z)] = E[f(X,1)-f(X,0)] for any bounded f. This sidesteps the 1/P(X) terms that cause variance explosion when P(X) approaches 0 or 1.

### Mechanism 2
By augmenting training data with counterfactual examples labeled using estimated feature effects, the model learns the true causal effect rather than spurious correlations. For each feature T with estimated effect τ, the method creates counterfactual inputs ZC=(X,1-T) and assigns labels Y_C based on flipping labels with probability τ/(1-τ) when Y=1, and with probability τ when Y=0. Training on this augmented distribution forces the model to learn the true causal effect τ.

### Mechanism 3
By enforcing the learned feature effect to match the true effect through augmentation rather than removal, the model retains task-relevant information while reducing spurious correlations. Unlike methods that remove spurious features entirely (INLP, RemoveToken), FEAG modifies the training distribution so the model learns the correct weight for the feature. This allows the feature to contribute when truly informative while preventing over-reliance when spurious.

## Foundational Learning

- Concept: Average Treatment Effect (ATE) as E[Y|do(T=1)] - E[Y|do(T=0)]
  - Why needed here: ATE provides the formal definition of the causal effect we want the model to learn
  - Quick check question: How does ATE differ from P(Y|T=1) - P(Y|T=0)?

- Concept: Causal graphs with confounders (C → T, C → X, X → Y, T → Y)
  - Why needed here: Understanding the data generation process is essential for identifying when correlations are spurious
  - Quick check question: Why does the presence of confounder C make T and X correlated?

- Concept: Counterfactual augmentation and its relationship to causal inference
  - Why needed here: FEAG's augmentation strategy relies on understanding how to create inputs that differ only in the treatment
  - Quick check question: What makes ZC=(X,1-T) a valid counterfactual input?

## Architecture Onboarding

- Component map:
  Input: Text sequences with treatment token marked -> Shared BERT encoder -> sentence representations -> Two heads (classifier head g, Riesz estimator head αR) -> Augmentation module generates counterfactuals using τ estimates -> Training loop combines original and augmented data

- Critical path:
  1. Train shared BERT + heads to estimate feature effects
  2. Compute τ_j for each treatment feature
  3. Generate counterfactual examples with modified labels
  4. Train final classifier on combined original + augmented data

- Design tradeoffs:
  - Two-headed architecture shares parameters for better Riesz estimation but adds complexity
  - Augmentation weight λ=0.1 balances original vs counterfactual loss
  - Counterfactual generation assumes simple treatment flipping (token presence/absence)

- Failure signatures:
  - High variance in τ estimates suggests poor overlap or insufficient data
  - Model performance similar to direct training indicates augmentation isn't working
  - Degraded performance on minority groups suggests over-regularization

- First 3 experiments:
  1. Run Riesz estimator on CivilComments semi-synthetic data with varying overlap to verify it outperforms Direct and Propensity methods
  2. Apply FEAG(ate) to CivilComments subsampled dataset and compare group accuracies against baselines
  3. Test FEAG on IMDB dataset where causal graph assumptions may not hold, measuring tradeoff between total and group accuracy

## Open Questions the Paper Calls Out

### Open Question 1
The paper does not evaluate the Riesz estimator in settings with zero or near-zero overlap between treatment and control groups, leaving unclear how it performs compared to propensity-based methods in these challenging scenarios.

### Open Question 2
The paper does not systematically test FEAG's performance under various causal graph violations, such as when there are multiple confounders or non-linear relationships between variables.

### Open Question 3
The paper does not demonstrate FEAG's scalability to larger datasets or more complex feature sets beyond single tokens, leaving unclear how well it generalizes to real-world applications.

## Limitations
- Riesz estimator implementation details and counterfactual generation algorithm are not fully specified
- Empirical validation of Riesz estimator against propensity methods is limited to semi-synthetic data
- Method assumes simple treatment features (single tokens) that can be easily flipped

## Confidence

- **High**: Enforcing learned feature effects to match true causal effects through augmentation reduces spurious correlations while preserving useful information
- **Medium**: Riesz estimator provides more accurate feature effect estimates than propensity methods in low-overlap settings
- **Low**: Specific augmentation strategy based on estimated effects successfully trains models to learn correct causal relationships

## Next Checks

1. Implement and compare the Riesz estimator against propensity-based methods within the full FEAG pipeline on CivilComments semi-synthetic data, measuring both ATE estimation accuracy and downstream classification performance.

2. Systematically vary the overlap between treatment and control groups in synthetic data to identify the threshold where Riesz estimation breaks down compared to other methods.
