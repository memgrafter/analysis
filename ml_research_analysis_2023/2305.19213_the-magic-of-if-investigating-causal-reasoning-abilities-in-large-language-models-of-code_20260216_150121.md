# The Magic of IF: Investigating Causal Reasoning Abilities in Large Language Models of Code

## Quick Facts
- arXiv ID: 2305.19213
- Source URL: https://arxiv.org/abs/2305.19213
- Reference count: 21
- Primary result: Code-LLMs with code prompts significantly outperform text-only LLMs on causal reasoning tasks

## Executive Summary
This paper investigates whether large language models trained on code (Code-LLMs) can perform causal reasoning better than text-only LLMs by leveraging their familiarity with conditional statements. The authors design code prompts that explicitly represent causal structures through if/elif statements and evaluate them on abductive and counterfactual reasoning tasks. Experiments demonstrate that Code-LLMs with code prompts outperform text-only LLMs and previous methods across multiple evaluation metrics, particularly excelling at preserving original content in counterfactual scenarios.

## Method Summary
The paper uses two causal reasoning datasets: ART for abductive reasoning (3,561 instances) and TimeTravel for counterfactual reasoning (1,871 instances). Code-LLMs (specifically CODEX) are prompted with code containing conditional statements to represent causal structures, while text-only LLMs (DAVINCI 002/003) receive standard text prompts. The methodology compares automatic metrics (BLEU4, ROUGEL, CIDEr, BERTScore) and human evaluation across different prompt designs and interventions. The key innovation is converting causal reasoning inputs into code prompts that explicitly represent cause-and-effect relationships through programming conditionals.

## Key Results
- Code-LLMs with code prompts significantly outperform text-only LLMs on both abductive and counterfactual reasoning tasks
- Code-LLMs are highly sensitive to programming structure, particularly conditional statements
- Code-LLMs show robustness to format and language perturbations while maintaining strong performance
- Code prompts better preserve original content in counterfactual reasoning compared to text-only prompts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Code-LLMs outperform text-only LLMs on causal reasoning because code prompts explicitly represent causal structures through conditional statements
- Mechanism: The conditional statements (if/elif) in code prompts create a clear structural representation of cause-and-effect relationships that the model can directly parse and reason about
- Core assumption: Code-LLMs have been pre-trained on code containing abundant causal expressions and have learned to recognize and process these structures
- Evidence anchors: Programming code may express causal relations more often and explicitly with conditional statements like if; code prompts convert causal reasoning tasks into code form

### Mechanism 2
- Claim: The programming structure is more important than format or language in code prompts for causal reasoning
- Mechanism: Code-LLMs are sensitive to the logical flow and relationships expressed through conditional structures, but robust to superficial formatting differences
- Core assumption: The model's reasoning ability depends primarily on understanding the logical structure rather than syntax details
- Evidence anchors: Programming structure is crucial to performance; CODEX is quite robust towards format and language changes

### Mechanism 3
- Claim: Code prompts enable better preservation of original content in counterfactual reasoning compared to text-only prompts
- Mechanism: The explicit if-elif structure in code prompts helps the model maintain coherence between the original ending and the counterfactual context
- Core assumption: The structural clarity of code prompts helps the model track multiple possible outcomes and their relationships
- Evidence anchors: Code-LLMs outperform text-only LLMs in preserving original ending; human evaluation shows better preservation with code prompts

- Critical path: Design code prompts → Input to Code-LLMs → Generate output → Evaluate against ground truth

- Failure signatures: Poor performance on tasks requiring complex causal reasoning; inability to preserve original content in counterfactual reasoning; sensitivity to prompt formatting

## Open Questions the Paper Calls Out

- Question: How does the performance of Code-LLMs compare to text-only LLMs on other complex reasoning tasks, such as mathematical reasoning or logical inference?
- Basis in paper: The paper demonstrates that Code-LLMs outperform text-only LLMs on abductive and counterfactual reasoning tasks, but does not explore other reasoning domains
- Why unresolved: The study focuses specifically on causal reasoning tasks and does not provide evidence for Code-LLMs' performance on other reasoning tasks
- What evidence would resolve it: Experiments comparing Code-LLMs and text-only LLMs on a variety of complex reasoning tasks, including mathematical and logical inference

### Open Question 2
- Question: Can the code prompt design be further optimized to improve the performance of Code-LLMs on causal reasoning tasks?
- Basis in paper: The paper shows that Code-LLMs are sensitive to the programming structure and robust to format perturbations, suggesting that the prompt design could be refined
- Why unresolved: The study uses a manually designed code prompt without exploring prompt engineering techniques such as prompt search or optimization
- What evidence would resolve it: Experiments using prompt engineering techniques to optimize the code prompt design and evaluate its impact on Code-LLMs' performance

### Open Question 3
- Question: How do Code-LLMs perform on causal reasoning tasks in languages other than English?
- Basis in paper: The paper notes that most Code-LLMs are pre-trained on English programming languages and does not explore their performance on other languages
- Why unresolved: The study focuses on English language tasks and does not provide evidence for Code-LLMs' performance on causal reasoning tasks in other languages
- What evidence would resolve it: Experiments evaluating Code-LLMs on causal reasoning tasks in various languages, including non-English-based programming languages

### Open Question 4
- Question: What are the limitations of Code-LLMs in handling more complex causal structures, such as those involving nested conditionals or loops?
- Basis in paper: The paper demonstrates Code-LLMs' ability to handle basic causal structures using conditional statements but does not explore more complex structures
- Why unresolved: The study focuses on simple causal structures and does not provide evidence for Code-LLMs' performance on more complex structures
- What evidence would resolve it: Experiments evaluating Code-LLMs on causal reasoning tasks involving nested conditionals, loops, and other complex programming constructs

## Limitations

- Limited evaluation to only two datasets (ART and TimeTravel) may not capture the full scope of causal reasoning capabilities
- Human evaluation methodology lacks detailed rating criteria and sample size information
- Paper doesn't provide complete code prompt templates, making exact reproduction challenging

## Confidence

- Code-LLMs outperforming text-only LLMs on causal reasoning: High (supported by multiple metrics across both datasets)
- Programming structure being more important than format: Medium (based on intervention experiments but limited scope)
- Code prompts preserving original content better: Medium (human evaluation shows this but sample size and criteria unclear)
