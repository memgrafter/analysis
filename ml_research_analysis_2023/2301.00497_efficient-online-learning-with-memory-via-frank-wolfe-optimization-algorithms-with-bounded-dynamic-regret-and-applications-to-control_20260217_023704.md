# Efficient Online Learning with Memory via Frank-Wolfe Optimization: Algorithms with Bounded Dynamic Regret and Applications to Control

## Quick Facts
- arXiv ID: 2301.00497
- Source URL: https://arxiv.org/abs/2301.00497
- Reference count: 40
- Primary result: Meta-OFW achieves bounded dynamic regret in OCO-M and is ~3x faster than projection-based methods

## Executive Summary
This paper introduces Meta-OFW, the first projection-free algorithm for online convex optimization with memory (OCO-M) that guarantees bounded dynamic regret. The algorithm addresses the challenge of learning in dynamic environments where past decisions affect future outcomes, a critical requirement for control systems. By building on Online Frank-Wolfe (OFW) and Hedge algorithms, Meta-OFW eliminates the need for expensive projection operations while maintaining theoretical performance guarantees. The approach is particularly valuable for online non-stochastic control of linear time-varying systems, providing the first projection-free controller with memory and bounded dynamic regret against any optimal time-varying linear feedback control policy.

## Method Summary
Meta-OFW combines multiple OFW base-learners with different step sizes using a Hedge meta-learner to handle the memory effects in OCO-M. The algorithm operates by maintaining a set of OFW learners, each with a different step size parameter, and uses Hedge to combine their predictions. This meta-algorithm approach allows Meta-OFW to achieve O(√T(1+VT+DT+CT)) dynamic regret, where VT, DT, and CT represent variations in loss functions, comparator sequence, and gradient norms respectively. For control applications, the algorithm uses a Dynamic Affine Controller (DAC) parameterization and truncated loss functions to reduce the problem to OCO-M, enabling efficient online control without projections.

## Key Results
- Achieves bounded dynamic regret of O(√T(1+VT+DT+CT)) for OCO-M with memory
- Approximately 3x faster than state-of-the-art projection-based OCO-M algorithms
- Maintains comparable or superior loss performance in simulated online control of linear time-invariant systems
- First projection-free controller with memory for non-stochastic control of linear time-varying systems

## Why This Works (Mechanism)
Meta-OFW works by combining multiple OFW base-learners with different step sizes, allowing it to adapt to varying levels of loss function smoothness across time. The Hedge meta-learner selects the best-performing base-learner at each iteration, effectively handling the memory effects where past decisions influence future losses. This approach eliminates the need for projections while maintaining theoretical regret guarantees, making it computationally efficient for control applications where fast decision-making is critical.

## Foundational Learning
- **Online Convex Optimization (OCO)**: Sequential decision-making framework where decisions are made before observing the loss function; needed for modeling online learning scenarios
- **Dynamic Regret**: Measures performance against time-varying comparators; required for evaluating algorithms in non-stationary environments
- **Frank-Wolfe Optimization**: Projection-free method using linear programming; needed to reduce computational complexity in constrained optimization
- **Hedge Algorithm**: Meta-learning approach for combining multiple experts; required to select optimal step sizes dynamically
- **Non-stochastic Control**: Control systems without statistical assumptions; needed for realistic control scenarios with unpredictable disturbances

## Architecture Onboarding

**Component Map**: Data/State -> OFW Base-Learners -> Hedge Meta-Learner -> Decision Output -> Loss Evaluation

**Critical Path**: At each time step, compute gradient of loss function → update all OFW base-learners with different step sizes → Hedge meta-learner combines predictions → output final decision → observe loss and update weights

**Design Tradeoffs**: Projection-free efficiency vs. optimal regret bound (includes VT and DT terms); multiple base-learners increase memory usage but improve adaptivity; step size grid must balance coverage and computational cost

**Failure Signatures**: 
- Dynamic regret bounds not achieved: indicates incorrect step size selection or gradient computation errors
- Numerical instability in linear program: suggests loss function gradients are not properly bounded
- Poor performance in control: indicates DAC parameterization or truncated loss construction issues

**First Experiments**:
1. Implement basic OFW algorithm on simple convex problem to verify projection-free operation
2. Test Meta-OFW with 2-3 base-learners on OCO-M problem with memory effects
3. Apply Meta-OFW to linear time-invariant system control and compare with projection-based methods

## Open Questions the Paper Calls Out
The paper identifies three major open questions: (1) Whether Meta-OFW's regret bound can be improved to match the optimal Ω(√T(1+CT)) bound without projections, (2) How Meta-OFW would perform on real-world robotic systems like quadrotors under unpredictable disturbances, and (3) Whether Meta-OFW can be extended to partially-observed systems while maintaining bounded dynamic regret.

## Limitations
- Regret bound includes additional VT and DT terms that prevent matching optimal projection-based bounds
- Assumes linear loss functions and bounded gradients, limiting applicability to non-linear scenarios
- Comparison with state-of-the-art methods based on specific simulated scenarios only

## Confidence
- High: Theoretical guarantees of bounded dynamic regret are well-established
- Medium: Computational efficiency improvements are supported by numerical evaluations but may vary in different settings
- Low: Real-world applicability to robotic systems not yet demonstrated
