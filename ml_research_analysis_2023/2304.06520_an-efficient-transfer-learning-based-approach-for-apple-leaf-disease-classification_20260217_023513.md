# An Efficient Transfer Learning-based Approach for Apple Leaf Disease Classification

## Quick Facts
- arXiv ID: 2304.06520
- Source URL: https://arxiv.org/abs/2304.06520
- Reference count: 40
- Accuracy: 99.21% on apple leaf disease classification

## Executive Summary
This study proposes a transfer learning-based approach for automated classification of apple leaf diseases, achieving 99.21% accuracy. The method uses a pretrained EfficientNetV2S architecture for feature extraction, followed by a dense classifier block, and addresses class imbalance through runtime data augmentation. Evaluated on the PlantVillage dataset with four disease classes (Healthy, Apple Scab, Black Rot, Cedar Apple Rust), the approach outperforms existing methods and demonstrates the effectiveness of combining transfer learning with augmentation techniques for agricultural disease classification.

## Method Summary
The approach employs transfer learning with a pretrained EfficientNetV2S model as a feature extractor, which is fine-tuned on apple leaf disease images. A dense classifier block with batch normalization and dropout layers is added on top of the feature extractor. Runtime data augmentation techniques including rotation, flipping, shifting, and shearing are applied during training to address class imbalance in the dataset. The model is trained on 60% of the data, validated on 20%, and tested on the remaining 20%, using Adam optimizer with learning rate decay and early stopping.

## Key Results
- Accuracy of 99.21% on apple leaf disease classification
- Precision, recall, and F1-scores of 99.15%, 99.10%, and 99.12% respectively
- Outperforms existing methods on the PlantVillage dataset
- Effectively handles class imbalance through runtime augmentation

- Core assumption: The features learned by EfficientNetV2S on ImageNet are transferable and useful for apple leaf disease classification.

## Architecture Onboarding

- Component map: Preprocessed image (256x256x3) -> EfficientNetV2S feature extractor -> Dense classifier block -> Predicted class label

- Critical path: Image preprocessing → Feature extraction (EfficientNetV2S) → Classification (Dense block) → Output

- Design tradeoffs:
  - Using a pretrained model reduces training time but may limit customization.
  - Runtime augmentation improves robustness but may increase training time.
  - A shallow dense classifier is less prone to overfitting but may not capture complex relationships.

- Failure signatures:
  - Overfitting: High training accuracy but low validation/test accuracy
  - Underfitting: Low training, validation, and test accuracy
  - Class imbalance: Poor performance on minority classes

- First 3 experiments:
  1. Train the model without data augmentation to assess the impact of class imbalance.
