# Effective Medical Code Prediction via Label Internal Alignment

## Quick Facts
- arXiv ID: 2305.05162
- Source URL: https://arxiv.org/abs/2305.05162
- Reference count: 40
- Primary result: State-of-the-art ICD code prediction on MIMIC-III using label internal alignment

## Executive Summary
This paper introduces the Multi-view Attention Model (MV AM) for automatic ICD code prediction from clinical texts. The model addresses a key limitation in existing approaches by incorporating a self-attention encoder on the label embedding end to capture internal correlations among medical codes, rather than relying solely on document word embeddings. By leveraging label-level relationships, MV AM improves prediction accuracy across multiple evaluation metrics. The model demonstrates strong performance on both full-label and high-frequency label settings, establishing new state-of-the-art results on the MIMIC-III dataset.

## Method Summary
The proposed Multi-view Attention Model (MV AM) combines a convolutional neural network for clinical text encoding with a self-attention module for label encoding, connected through a per-label attention mechanism. The CNN processes clinical text to generate document representations, while the self-attention module captures internal correlations among ICD codes through their embeddings. The per-label attention mechanism then computes weighted representations of the text for each label, allowing the model to focus on relevant clinical information when predicting specific codes. This architecture enables the model to leverage both the document content and the inherent relationships among medical codes during prediction.

## Key Results
- Achieves state-of-the-art performance on MIMIC-III for ICD code prediction
- Demonstrates superior results on both full-label and high-frequency label settings
- Shows strong performance across multiple metrics including micro/macro F1 scores and precision@5/10

## Why This Works (Mechanism)
The model works by explicitly modeling the internal relationships among ICD codes through the label encoder's self-attention mechanism. This approach recognizes that medical codes are not independent labels but exist in a structured taxonomy with inherent relationships. By capturing these label-level correlations, the model can better understand which codes tend to co-occur and which clinical contexts are relevant for specific codes. The per-label attention mechanism then allows each code prediction to be informed by both the relevant clinical text and the learned label relationships, resulting in more accurate and context-aware predictions.

## Architecture Onboarding

**Component Map:** Clinical text -> CNN encoder -> Text representation -> Per-label attention -> Label representation (from self-attention) -> Prediction

**Critical Path:** Clinical text input flows through CNN encoder, then through per-label attention mechanism that combines with label representations from the self-attention encoder to produce final ICD code predictions

**Design Tradeoffs:** The model adds label encoder complexity to capture code relationships versus simpler approaches that treat codes independently; this improves accuracy but increases model complexity and training requirements

**Failure Signatures:** Poor performance on rare codes, inability to capture complex label dependencies beyond what self-attention can model, potential overfitting to MIMIC-III specific patterns
