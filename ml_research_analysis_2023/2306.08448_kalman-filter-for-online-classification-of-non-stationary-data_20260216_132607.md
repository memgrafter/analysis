# Kalman Filter for Online Classification of Non-Stationary Data

## Quick Facts
- arXiv ID: 2306.08448
- Source URL: https://arxiv.org/abs/2306.08448
- Reference count: 40
- Key outcome: Kalman filter-based method for online continual learning that adapts to non-stationary data using a deep neural network feature extractor and learned forgetting coefficient

## Executive Summary
This paper introduces a Kalman filter-based method for online continual learning that adapts to non-stationary data streams. The approach uses a deep neural network to extract features, which are then used in a linear Gaussian model with a "parameter drift" transition density. This transition density is parameterized by a forgetting coefficient γ that is learned online via SGD. The Kalman filter provides efficient Bayesian inference for the linear weights, while the online SGD updates on γ allow the model to adapt to changes in the data distribution. The method is extended to handle classification problems through a combination of approximate Gaussian likelihoods and calibration techniques.

## Method Summary
The method implements a Kalman filter for online continual learning with non-stationary data. It maintains a posterior distribution over linear weights using Kalman prediction and update steps, where the transition density includes a forgetting coefficient γ that adapts online via SGD. For classification, the approach uses an approximate Gaussian likelihood combined with a calibration parameter α that rescales logits. The method can optionally fine-tune the deep representation parameters θ jointly with the Kalman filter parameters. Experiments demonstrate competitive online classification accuracy on CIFAR-100 and CLOC datasets, particularly when combined with backbone fine-tuning and replay strategies.

## Key Results
- Kalman filter with learned forgetting coefficient effectively captures non-stationarity in data streams
- Combined approach with backbone fine-tuning and replay achieves competitive online classification accuracy
- The method outperforms static Kalman filter baselines on CIFAR-100 and CLOC datasets
- Online learning of γ allows adaptation to varying degrees of non-stationarity

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Kalman filter provides computationally efficient Bayesian inference over time-varying linear weights.
- Mechanism: The state space model with Gaussian transition density allows exact recursive updates via Kalman prediction and update steps, maintaining a posterior over weights at each time step.
- Core assumption: The feature space is low-dimensional and the transition dynamics are approximately linear-Gaussian.
- Evidence anchors:
  - [abstract] "Inference in the model is implemented with efficient Kalman filter recursions which track the posterior distribution over the linear weights"
  - [section 2] "exact online Bayesian inference over wn can be solved with standard recursions"
  - [corpus] Weak: Only one neighbor paper directly uses Kalman filtering for online neural network learning; others focus on general online learning or time series.

### Mechanism 2
- Claim: Online learning of the forgetting coefficient γ allows adaptation to varying degrees of non-stationarity.
- Mechanism: γn is parametrized as exp(-0.5δn) and updated via SGD to maximize the log predictive probability at each step, adjusting memory retention based on observed data drift.
- Core assumption: The degree of non-stationarity can be captured by a single scalar parameter per time step.
- Evidence anchors:
  - [abstract] "online SGD updates over the transition dynamics coefficient allows to adapt to the non-stationarity seen in data"
  - [section 2.1.1] "we apply an SGD update to change γn by maximizing the log predictive probability"
  - [corpus] Weak: No direct neighbor evidence; assumption relies on the paper's experimental results.

### Mechanism 3
- Claim: The calibration parameter α and fine-tuning of the deep representation improve predictive probability estimates.
- Mechanism: α rescales logits inside the softmax for Bayesian averaging, while joint optimization with representation parameters θ refines both the feature space and probability calibration.
- Core assumption: The Gaussian approximation to the softmax likelihood is reasonable locally, and calibration can correct systematic biases.
- Evidence anchors:
  - [section 2.1.2] "We improve this estimate by fine-tuning over a calibration parameter that is optimized with gradient steps"
  - [section 2.1.2] "This resembles the forward-calibration described in [7]"

## Architecture Onboarding

- Component map: Feature extractor -> Kalman filter recursion module -> Online learning module -> Calibration module
- Critical path: Input → Feature extraction → Kalman prediction → Log probability estimation → SGD update (γ, α, θ) → Kalman update
- Design tradeoffs:
  - Fixed vs. fine-tuned backbone: Fixed is faster but less adaptive; fine-tuning improves performance but increases computational cost.
  - Shared vs. per-class covariance: Shared covariance reduces complexity from O(Km²) to O(m²) but may be too restrictive.
  - Always Markov vs. Last Step Markov: Always Markov applies transitions at every data point; Last Step Markov only at chunk boundaries.
- Failure signatures:
  - Degraded accuracy with high-dimensional features: O(m²) complexity becomes prohibitive.
  - Poor adaptation with fixed γ: Cannot capture varying non-stationarity patterns.
  - Unstable training with aggressive fine-tuning: Overfitting to recent data, losing generalization.
- First 3 experiments:
  1. Implement Kalman filter on synthetic time series with known change-points; verify γ adaptation.
  2. Apply stationary Kalman filter (γ=1) to CIFAR-100 with frozen backbone; establish baseline.
  3. Extend to non-stationary CIFAR-100 with learned γ; compare to stationary baseline.

## Limitations
- The Gaussian approximation to the softmax likelihood may introduce significant errors, particularly for high-dimensional problems where the approximation may break down.
- The method's computational complexity is O(m²) per update, which becomes prohibitive for high-dimensional feature spaces.
- The online learning of γ relies on a single scalar parameter per time step, which may be insufficient to capture complex non-stationarity patterns.

## Confidence
- Kalman filter mechanism: Medium
