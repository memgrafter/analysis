## Executive Summary
This paper addresses the challenge of quantization effects on learned entropy coding in neural image and video compression systems. The authors propose a novel approach that transforms the entropy coding parameter σ into a new parameter u using a non-linear function T(u), which makes uniform quantization practically optimal for entropy coding. The transformation is derived mathematically to ensure constant average relative redundancy across different values of σ. The method demonstrates that networks can be trained to be minimally sensitive to quantization, with good coding performance achievable even with as low as 4 bits per network output, and practically no loss with 8 bits.

## Method Summary
The paper introduces a method to optimize learned entropy coding parameters for neural image and video compression by transforming the pdf parameter σ into a new parameter u ∈ [0,1] via a function T(u). This transformation is designed so that uniform quantization of u yields optimal entropy coding. The function T(u) is derived by solving an ordinary differential equation (ODE) d/du T(u) = √α/ψ(T(u)) with boundary conditions T(0)=σmin and T(1)=σmax. The neural network is then trained to output u instead of σ, and the transformation is applied during entropy coding. The method allows the same network to be used for different quantization precisions without retraining, and it can minimize memory requirements for storing entropy coding tables.

## Key Results
- Uniform quantization of the transformed parameter u becomes practically optimal for entropy coding
- Neural networks do not need to be retrained when quantization precision changes
- The proposed method can minimize memory requirements for storing entropy coding tables
- Good coding results can be obtained with precision as low as 4 bits per network output, and practically no loss with 8 bits
