# Learning-Based Heuristic for Combinatorial Optimization of the Minimum Dominating Set Problem using Graph Convolutional Networks

## Executive Summary
This paper proposes a novel graph machine learning framework to compute minimum dominating sets on arbitrary graphs using graph convolutional networks (GCNs). The GCN is trained to generate a diverse set of probability maps over the vertex set of the input graph, which are then used as heuristics to construct dominating sets. The approach is evaluated on a combination of randomly generated graphs and real-world graph datasets, and the results indicate that the proposed learning-based approach can outperform a classical greedy approximation algorithm. Furthermore, the GCN model demonstrates generalization capability across datasets and the ability to scale to graphs of higher order than those on which it was trained.

## Method Summary
The paper introduces a GCN-based framework that learns heuristics for the Minimum Dominating Set (MDS) problem. The method involves training a GCN to generate multiple probability maps for each graph, where each map represents the likelihood of vertices being part of an optimal dominating set. These maps serve as diverse heuristics in a greedy algorithm to construct candidate dominating sets, which are then pruned to remove redundant vertices. The approach is integrated into an iterative greedy framework, using the GCN's heuristics to improve both initial solution construction and reconstruction phases.

## Key Results
- The GCN-based heuristics consistently outperform classical greedy algorithms in constructing smaller dominating sets.
- The model demonstrates strong generalization, scaling effectively to graphs larger than those in the training set.
- Integration with the iterative greedy algorithm yields state-of-the-art performance in MDS computation.

## Architecture Onboarding

- Component map:
  - Dataset Generation -> GCN Model -> Training -> Heuristic Generation -> Pruning -> IG Framework

- Critical path:
  1. Generate diverse dataset with multiple labeled MDS solutions per graph.
  2. Train GCN to minimize hindsight loss on this dataset.
  3. Use trained GCN to generate probability maps for test graphs.
  4. Apply each probability map as a heuristic in Algorithm 1 to build candidate dominating sets.
  5. Prune each candidate set and select the smallest as the solution.

- Design tradeoffs:
  - Multiple probability maps increase diversity but also computational cost during inference.
  - Training on synthetic graphs may limit real-world generalization if the synthetic distribution is not representative.
  - Using GCNs allows handling arbitrary graph structures but requires more data and compute than simpler models.

- Failure signatures:
  - If GCN probability maps are uniform or random-like, the heuristics will perform no better than random selection.
  - If the hindsight loss does not converge, the GCN will not learn meaningful patterns.
  - If pruning is too aggressive, valid dominating sets may be destroyed.

- First 3 experiments:
  1. Train GCN on small synthetic graphs (n=50-100) and evaluate on hold-out graphs of the same size to verify basic learning.
  2. Test GCN generalization by evaluating on larger graphs (n=150-255) than those seen during training.
  3. Compare GCN heuristics against greedy and random heuristics on real-world graph datasets to assess practical performance.

## Limitations
- The approach relies on synthetic training data, which may not fully represent real-world graph diversity.
- Computational overhead of generating 32 probability maps per graph could limit scalability for very large graphs.
- The pruning step's effectiveness depends on the quality of initial GCN predictions, which may degrade on graphs with complex domination patterns.
