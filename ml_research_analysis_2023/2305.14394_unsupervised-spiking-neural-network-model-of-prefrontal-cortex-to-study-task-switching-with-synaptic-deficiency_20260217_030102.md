# Unsupervised Spiking Neural Network Model of Prefrontal Cortex to study Task Switching with Synaptic deficiency

## Quick Facts
- arXiv ID: 2305.14394
- Source URL: https://arxiv.org/abs/2305.14394
- Reference count: 33
- This paper presents a computational model of the prefrontal cortex (PFC) using spiking neural networks (SNN) to study task switching behavior and the effects of synaptic deficiencies.

## Executive Summary
This paper presents a biologically inspired spiking neural network model of the prefrontal cortex to study task switching behavior under normal and synaptic deficiency conditions. The model uses Leaky Integrate-and-Fire neurons with unsupervised STDP learning to process Fashion MNIST images, demonstrating sustained activity that enables working memory during task switching. Experiments show that the model achieves higher accuracy with longer delays and full synaptic connectivity, while simulated synaptic lesions impair learning and decision-making capabilities.

## Method Summary
The model implements a three-layer SNN architecture: Input Sensory layer (Poisson spike encoding of images), PFC Memory layer (LIF neurons with WTA lateral inhibition and self-excitation), and PFC Response layer (decision output). STDP learning adjusts synaptic weights based on spike timing without external supervision. The model is trained on Fashion MNIST with a 70/30 target/non-target ratio, testing task switching under different time delays and synaptic connectivity conditions by deactivating connections between layers.

## Key Results
- Model exhibits sustained activity in PFC Memory layer that enables working memory during task switching
- Higher task-switching accuracy achieved with longer delays (550ms vs 350ms) and full synaptic connectivity
- Synaptic lesions (partial deactivation) significantly impair learning and decision-making by reducing information flow

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sustained neural activity in the PFC Memory layer enables short-term/working memory that allows partial pattern reconstruction after stimulus removal.
- Mechanism: Self-excitatory connections within the Memory layer create attractor dynamics. When a stimulus is presented, neurons that win the lateral inhibition competition maintain firing through recurrent excitation even after the input ceases, preserving a trace of the learned pattern.
- Core assumption: The recurrent excitation strength and inhibitory balance are set such that attractor states are stable but not permanent, allowing decay over time.
- Evidence anchors:
  - [section] "This type of behavior dynamics is known as an attractor network [24]... These representations or knowledge are then maintained in a stable manner even after ceasing to activate the network using any input stimuli."
  - [abstract] "Our model is based on connectionist architectures and exhibits neural phenomena like sustained activity which helps in generating short-term or working memory."
- Break condition: If the excitatory strength is too weak or inhibition too strong, the sustained activity decays immediately and the model loses the memory trace before task switching.

### Mechanism 2
- Claim: STDP-based unsupervised learning adjusts synaptic weights to encode task-specific patterns without external supervision.
- Mechanism: When pre-synaptic spikes precede post-synaptic spikes, LTP increases synaptic weights (A+ mechanism). When post-synaptic spikes precede pre-synaptic spikes, LTD decreases weights (A- mechanism). This timing-dependent plasticity shapes receptive fields in the Memory layer.
- Core assumption: Spike timing differences are sufficiently large and consistent across trials to produce reliable weight changes.
- Evidence anchors:
  - [section] "Learning of patterns takes place by modification of synaptic weights in response to the firing times of pre and post-synaptic spikes... This leads to observing two neural phenomena namely, Long Term Potentiation (LTP) [11] which occurs when the neurons are learning patterns and Long Term Depression (LTD) [1], [11] which leads to forgetting of patterns in the network."
  - [abstract] "Our model is based on connectionist architectures and exhibits neural phenomena like sustained activity which helps in generating short-term or working memory."
- Break condition: If spike timing variability is too high or noise overwhelms signal, weight updates become random and the network fails to learn coherent task representations.

### Mechanism 3
- Claim: Synaptic lesions (partial deactivation) impair decision-making by reducing information flow from Input to Memory layer, degrading working memory and pattern recognition.
- Mechanism: Deactivating synapses between Input and Memory layers cuts off a fraction of the input signals, reducing the number of neurons that can be activated and maintained in the attractor state. This leads to incomplete pattern encoding and weaker sustained activity.
- Core assumption: The deactivated synapses are randomly distributed rather than systematically removing critical pathways.
- Evidence anchors:
  - [section] "We shift our focus to study the response accuracy of neurons for partial deactivation of synapses... This causes deficiency in the information being transmitted and is analogous to a lesion in the cortical regions of the brain [20]."
  - [abstract] "We use these features to simulate lesions by deactivating synaptic pathways and record the weight adjustments of learned patterns and capture the accuracy of learning tasks in such conditions."
- Break condition: If too many synapses are deactivated, the Memory layer receives insufficient input to trigger any sustained activity, causing complete failure of working memory.

## Foundational Learning

- Concept: Leaky Integrate-and-Fire (LIF) neuron dynamics
  - Why needed here: LIF neurons provide a computationally tractable model that captures spike timing and membrane potential dynamics essential for SNN-based task switching.
  - Quick check question: How does the membrane potential evolve over time in an LIF neuron with excitatory and inhibitory inputs?

- Concept: Spike Timing Dependent Plasticity (STDP)
  - Why needed here: STDP enables unsupervised learning of task patterns based on the temporal relationship between pre- and post-synaptic spikes, which is crucial for adapting to switched tasks without labeled data.
  - Quick check question: What happens to synaptic weight when a pre-synaptic spike precedes a post-synaptic spike versus the reverse order?

- Concept: Winner-Take-All (WTA) lateral inhibition
  - Why needed here: WTA ensures that only one neuron in the Memory layer remains highly active for a given input pattern, creating sparse and stable representations needed for working memory.
  - Quick check question: How does lateral inhibition among excitatory neurons in the Memory layer affect the selection of the winning neuron?

## Architecture Onboarding

- Component map: Input Sensory Layer -> PFC Memory Layer -> PFC Response Layer
- Critical path: Input → Memory (learning and sustained activity) → Response (decision output)
- Design tradeoffs:
  - Biological realism vs computational efficiency: LIF neurons are simpler than detailed Hodgkin-Huxley models but still capture spike timing
  - Unsupervised learning vs performance: STDP avoids need for labels but may learn slower or less accurately than supervised methods
  - Sustained activity duration vs memory decay: Longer sustained activity improves context-target accuracy but increases energy cost and risk of interference
- Failure signatures:
  - Low accuracy on Target stimulus: Indicates poor learning or insufficient LTP
  - High variability in accuracy across trials: Suggests excessive noise or unstable STDP updates
  - No sustained activity after stimulus removal: Points to inadequate self-excitation or excessive inhibition
- First 3 experiments:
  1. Train with full synaptic connectivity on Target/Non-target switching with short delays; measure accuracy and final synaptic weights
  2. Test context-target and context-non-target stimuli during sustained activity to evaluate working memory retrieval
  3. Simulate synaptic lesions by deactivating 50% of Input-Memory synapses; compare accuracy degradation and weight patterns

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the model's performance change when different learning rules (other than STDP) are used for training the spiking neural network?
- Basis in paper: [inferred] The paper primarily uses STDP for unsupervised learning but mentions that previous studies have used supervised learning with traditional neural networks.
- Why unresolved: The paper does not explore alternative learning rules or compare their effectiveness with STDP.
- What evidence would resolve it: Experiments comparing the model's performance using different learning rules (e.g., Hebbian learning, reinforcement learning) and analyzing their impact on accuracy and learning efficiency.

### Open Question 2
- Question: What is the impact of varying the parameters of the Leaky Integrate and Fire (LIF) neuron model on the model's ability to learn and switch tasks?
- Basis in paper: [explicit] The paper uses LIF neurons with parameters close to biological values but does not explore the effect of parameter variations.
- Why unresolved: The study does not investigate how changes in parameters like membrane time constants, threshold voltages, or refractory periods affect the model's performance.
- What evidence would resolve it: Systematic experiments varying LIF neuron parameters and analyzing their impact on task switching accuracy, learning speed, and sustained activity.

### Open Question 3
- Question: How does the model's performance scale with larger and more complex datasets beyond Fashion MNIST?
- Basis in paper: [explicit] The paper uses the Fashion MNIST dataset but does not test the model's scalability or performance on larger datasets.
- Why unresolved: The study does not explore the model's ability to handle more complex and larger datasets, which is crucial for real-world applications.
- What evidence would resolve it: Experiments using larger and more diverse datasets (e.g., ImageNet, CIFAR-100) and analyzing the model's performance, accuracy, and computational efficiency.

## Limitations
- The model relies on specific parameter tuning for sustained activity and STDP weight updates, with key parameters not explicitly specified
- Random synaptic deactivation as a simulation of cortical lesions oversimplifies complex neurological damage patterns
- Binary classification task (t-shirt vs ankle boot) may not fully capture the complexity of real PFC task switching

## Confidence
- **High confidence**: Sustained activity through self-excitation maintains working memory; STDP adjusts weights based on spike timing; synaptic lesions impair learning and decision-making
- **Medium confidence**: The three-layer architecture effectively models PFC task switching; lateral inhibition creates sparse, stable representations
- **Low confidence**: The model generalizes to more complex multi-task scenarios; biological realism of parameters fully captures human PFC function
