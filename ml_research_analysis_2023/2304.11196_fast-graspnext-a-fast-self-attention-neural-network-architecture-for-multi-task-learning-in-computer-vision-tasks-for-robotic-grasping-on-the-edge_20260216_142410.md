# Fast GraspNeXt: A Fast Self-Attention Neural Network Architecture for Multi-task Learning in Computer Vision Tasks for Robotic Grasping on the Edge

## Quick Facts
- arXiv ID: 2304.11196
- Source URL: https://arxiv.org/abs/2304.11196
- Reference count: 16
- Key outcome: Fast GraspNeXt achieves highest multi-task performance on MetaGraspNet with fewer parameters, lower FLOPs, and faster inference on embedded devices.

## Executive Summary
Fast GraspNeXt is a self-attention neural network architecture specifically designed for multi-task learning in computer vision tasks for robotic grasping on embedded devices. The architecture is created through a generative network architecture search strategy with constraints to balance multi-task learning performance and embedded inference efficiency. Fast GraspNeXt includes a self-attention backbone, feature pyramid network, and task-specific heads for predicting various outputs. Experimental results on the MetaGraspNet benchmark dataset demonstrate superior performance compared to other efficient multi-task network architectures while maintaining computational efficiency suitable for deployment on NVIDIA Jetson TX2 embedded processors.

## Method Summary
The paper proposes Fast GraspNeXt, which is created using a generative network architecture search strategy with architectural constraints to achieve a balance between multi-task learning performance and embedded inference efficiency. The architecture incorporates a self-attention backbone with attention condensers for improved attentional efficacy and efficiency, along with anti-aliased downsampling (AADS) to enhance network stability and robustness. The network is trained on the MetaGraspNet dataset using a multi-task loss function that combines object detection, segmentation, center of mass prediction, and suction grasp heatmap generation. Training uses SGD with learning rate decay at 67% and 92% epochs, batch size of 2, and image size of 1200x1200.

## Key Results
- Fast GraspNeXt achieves highest AP across all tasks (amodal bounding box, mask, center of mass, occlusion, suction grasp heatmap) compared to other efficient multi-task architectures
- The network has fewer parameters, lower FLOPs (<300B), and faster inference time than competing approaches on NVIDIA Jetson TX2
- Fast GraspNeXt demonstrates strong generalization capability using class-agnostic labels for deployment in industrial scenarios with novel, unseen items
