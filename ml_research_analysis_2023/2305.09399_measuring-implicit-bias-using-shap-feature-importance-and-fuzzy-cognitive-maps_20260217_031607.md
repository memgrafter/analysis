# Measuring Implicit Bias Using SHAP Feature Importance and Fuzzy Cognitive Maps

## Quick Facts
- arXiv ID: 2305.09399
- Source URL: https://arxiv.org/abs/2305.09399
- Reference count: 31
- The paper proposes a three-step methodology using SHAP feature importance to initialize FCM models for measuring implicit bias, showing that SHAP can underestimate bias when features interact non-linearly.

## Executive Summary
This paper addresses the challenge of quantifying implicit bias in pattern classification where seemingly neutral features can encode discriminatory beliefs correlated with protected attributes. The authors propose a three-step methodology combining classifier optimization, SHAP feature importance, and Fuzzy Cognitive Maps (FCM) to measure implicit bias. The approach demonstrates that features deemed unimportant by SHAP can still exhibit significant implicit bias when analyzed through FCM propagation, highlighting limitations of using feature importance as a direct bias proxy. The methodology is validated on German Credit and Adult datasets, showing consistent patterns of bias amplification through FCM reasoning.

## Method Summary
The methodology consists of three sequential steps: First, train and optimize a Random Forest classifier on training and validation data. Second, construct an FCM weight matrix using pairwise statistical associations (Pearson correlation for numeric-numeric pairs, Cramér's V for categorical-categorical, and fuzzy c-means clustering for numeric-categorical associations). Third, use SHAP local values to initialize FCM activations and run what-if simulations to measure implicit bias through the quasi-nonlinear reasoning rule. The approach automatically detects categories for numeric features using fuzzy c-means clustering, improving consistency in bias measurement.

## Key Results
- Protected features with low SHAP importance can show significant implicit bias through FCM propagation
- FCM models reveal non-linear bias patterns that SHAP's additive decomposition cannot capture
- Automatic fuzzy c-means clustering for numeric protected features improves bias measurement consistency
- The methodology successfully identifies bias patterns in both German Credit and Adult datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SHAP feature importance can underestimate implicit bias against protected features due to non-linear interactions
- Mechanism: FCM propagates initial SHAP activations through correlation-based weights, revealing bias paths that SHAP's additive decomposition cannot capture
- Core assumption: Statistical associations between features encode bias patterns that can be amplified through FCM reasoning
- Evidence anchors: Abstract states protected features deemed unimportant by SHAP exhibit significant implicit bias through FCM; Section 4 shows clear activation increases after iterations despite low initial SHAP values
- Break condition: If weight matrix lacks strong correlations between unprotected and protected features, FCM propagation won't amplify bias signals

### Mechanism 2
- Claim: Fuzzy c-means clustering improves implicit bias detection by automatically discovering categories for numeric protected features
- Mechanism: Numeric features are discretized into fuzzy clusters, then Cramér's V measures associations between clusters and categorical features
- Core assumption: Automatically discovered categories better reflect actual bias structure than arbitrary numeric encoding
- Evidence anchors: Section 3.2 describes transformation using fuzzy c-means; Section 4.1 explains difference from alternative approaches
- Break condition: If fuzzy partition coefficient fails to identify meaningful clusters, discretization may not improve bias measurement

### Mechanism 3
- Claim: Quasi-nonlinear FCM reasoning rule with re-scaled transfer function ensures convergence while capturing non-linear bias propagation
- Mechanism: φ parameter controls balance between linear (initial SHAP values) and non-linear (correlation-based interactions) components
- Core assumption: Unique fixed point or limit cycle represents stable state of implicit bias in feature space
- Evidence anchors: Section 2.1 presents novel reasoning rule with normalization-like transfer function; Section 4 shows consistent patterns across different φ values
- Break condition: If weight matrix has eigenvalues preventing convergence, model may enter limit cycles instead of reaching stable bias estimates

## Architecture Onboarding

- Component map: Data preprocessing → Classifier training (Random Forest) → Hyperparameter tuning → SHAP explainer fitting → FCM weight matrix construction → Cluster analysis for numeric features → Instance simulation with SHAP initialization

- Critical path: 1) Train and optimize classifier on training/validation sets; 2) Fit SHAP explainer on combined training/validation data; 3) Construct FCM weight matrix using appropriate association measures; 4) Apply fuzzy c-means clustering for numeric-protected feature associations; 5) Run simulations on test instances using SHAP values as initial activations

- Design tradeoffs: Using Random Forest vs. other classifiers provides good accuracy and SHAP compatibility but may be less interpretable; φ parameter selection affects non-linear interaction amplification; automatic cluster number determination vs. manual specification affects discretization quality

- Failure signatures: Poor classifier performance → Invalid SHAP values → Misleading bias measurements; Weight matrix with weak correlations → Minimal FCM propagation → No significant bias amplification; Non-convergent FCM iterations → Unstable bias estimates → Need to adjust φ or check weight matrix properties

- First 3 experiments: 1) Verify SHAP values align with known feature importance on simple synthetic dataset; 2) Test FCM convergence properties with controlled weight matrices of varying φ values; 3) Compare bias measurements using different discretization methods for numeric protected features on German Credit dataset

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different discretization strategies (other than fuzzy c-means) for numeric features affect measurement of implicit bias in FCM models?
- Basis in paper: Paper uses fuzzy c-means but discusses limitations and need to explore alternative discretization methods
- Why unresolved: Only tests fuzzy c-means clustering, leaving open whether other discretization strategies might yield different implicit bias measurements
- What evidence would resolve it: Comparative experiments applying multiple discretization methods to same datasets and analyzing resulting bias measurements

### Open Question 2
- Question: How does choice of φ (nonlinearity parameter) in FCM model affect stability and interpretability of implicit bias measurements?
- Basis in paper: Paper tests different φ values but doesn't provide systematic analysis of how φ affects bias measurement stability or interpretability
- Why unresolved: While paper shows φ affects activation values, it doesn't establish guidelines for selecting optimal φ values or analyze sensitivity across different bias patterns
- What evidence would resolve it: Systematic sensitivity analysis varying φ across multiple datasets with known bias patterns would establish stability thresholds and interpretation guidelines

### Open Question 3
- Question: Can FCM model detect and quantify reverse discrimination (bias against historically privileged groups) when such groups are treated as "protected"?
- Basis in paper: Paper focuses on detecting bias against traditionally protected groups but doesn't address whether methodology can detect bias in opposite direction
- Why unresolved: Methodology tested only on cases where traditionally protected features are examined, without exploring cases where historically privileged groups are labeled as protected
- What evidence would resolve it: Experiments applying methodology to cases where traditionally privileged groups are treated as protected features would demonstrate model's bidirectional capabilities

## Limitations
- The quasi-nonlinear FCM reasoning rule's convergence guarantees are theoretical; empirical validation across diverse datasets is needed
- The extent to which SHAP underestimation pattern generalizes beyond German Credit and Adult datasets remains unclear
- Automatic discretization of numeric protected features using fuzzy c-means may introduce artifacts if discovered clusters don't align with actual bias patterns

## Confidence

- **High**: The three-step methodology is clearly specified and reproducible
- **Medium**: The core claim that SHAP can underestimate implicit bias is supported by experiments on two datasets
- **Low**: The theoretical convergence properties of the quasi-nonlinear reasoning rule need empirical validation
