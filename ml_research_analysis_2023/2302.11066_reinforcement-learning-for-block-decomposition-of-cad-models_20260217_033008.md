# Reinforcement Learning for Block Decomposition of CAD Models

## Quick Facts
- arXiv ID: 2302.11066
- Source URL: https://arxiv.org/abs/2302.11066
- Reference count: 9
- This work demonstrates RL for decomposing 2D CAD models into blocks for meshing using axis-aligned cuts.

## Executive Summary
This paper presents a novel application of reinforcement learning to the problem of decomposing CAD models into quadrilateral blocks suitable for meshing. Using a Soft Actor-Critic (SAC) algorithm, the RL agent learns to select vertices and perform axis-aligned cuts that maximize rewards based on block quality metrics. The trained agent successfully generalizes to new shapes it didn't train on, demonstrating the potential for RL to automate the time-consuming block decomposition step in mesh generation.

## Method Summary
The method uses a Soft Actor-Critic (SAC) reinforcement learning framework to decompose 2D planar shapes into quadrilateral blocks. The agent selects vertices and performs axis-aligned cuts based on local observations that include geometric features. A reward function encourages quadrilateral shapes while penalizing cuts along edges, high area variance, and high aspect ratios. The SAC algorithm uses three neural networks (actor, critic, and value) with the value network implemented as a graph neural network to handle the varying number of vertices. The agent is trained on 37 shapes and tested on 12 unseen shapes.

## Key Results
- Agent's policy converges after approximately 1500 training episodes
- Trained agent successfully generalizes to new shapes not seen during training
- Method currently limited to 2D axis-aligned shapes but encapsulates principles for extension to complex 2D and 3D models

## Architecture Onboarding

- **Component map**: 
  Value network (GNN) -> Actor network -> Critic network -> Geometric modeler (OpenCascade) -> Environment

- **Critical path**:
  1. Load a geometric model.
  2. Triangulate the shape being processed.
  3. Run the value network on the triangulation to generate weights at mesh vertices.
  4. Select a model vertex based on value network outputs.
  5. Compile a local observation at the vertex.
  6. Choose a direction for a cut at the vertex based on actor network probability outputs.
  7. Split the geometric model into two or more parts along the chosen direction.
  8. Compute the new state and reward.
  9. Store sampled states, actions, and rewards in the replay buffer.
  10. Update parameters for every network following the gradient step.
  11. Repeat from step 2 until the input is decomposed into all quadrilateral blocks.

- **Design tradeoffs**:
  - Using a SAC algorithm instead of a deep Q-network allows for continuous actions and better exploration.
  - Restricting cuts to axis-aligned cuts from model vertices simplifies the problem but limits the agent's flexibility.
  - Treating each part as a new shape to explore sacrifices the full model view but makes the problem simpler and more robust.

- **Failure signatures**:
  - The agent fails to converge to a policy that maximizes rewards based on block quality metrics.
  - The agent's policy does not generalize to new shapes.
  - The agent gets stuck in a local optimum and fails to explore other solutions.

- **First 3 experiments**:
  1. Train the agent on a simple 2D shape and evaluate its performance on a held-out test set.
  2. Increase the complexity of the shapes and observe how the agent's performance scales.
  3. Experiment with different reward functions and observe their impact on the agent's learned policy.

## Open Questions the Paper Calls Out

### Open Question 1
- **Question**: Can the RL-based block decomposition method generalize to 3D shapes with curved boundaries?
- **Basis in paper**: [explicit] The paper discusses potential expansion to complex 2D and 3D shapes, mentioning the need for tetrahedral meshes, expanded observations, generalized reward functions, and more geometric modifications.
- **Why unresolved**: The current method is limited to 2D planar shapes with straight, axis-aligned edges. The paper suggests that expanding to 3D will require additional research and development.
- **What evidence would resolve it**: Demonstrating successful block decomposition of 3D CAD models with curved boundaries using the RL method.

### Open Question 2
- **Question**: How effective is the RL-based method in handling non-axis aligned 2D shapes?
- **Basis in paper**: [explicit] The paper mentions that tackling non-axis aligned 2D shapes will require continuous actions like cuts at arbitrary angles.
- **Why unresolved**: The current method is restricted to axis-aligned cuts. The paper suggests that handling arbitrary angles will require further development.
- **What evidence would resolve it**: Successful decomposition of 2D shapes with non-axis aligned edges using the RL method with arbitrary angle cuts.

### Open Question 3
- **Question**: What is the impact of the reward function design on the quality of the block decomposition?
- **Basis in paper**: [explicit] The paper discusses the reward function's role in encouraging quadrilateral parts, discouraging high variance in areas, and avoiding high aspect ratios.
- **Why unresolved**: The current reward function is tailored for 2D shapes with specific characteristics. The paper suggests that expanding to more complex shapes may require refined reward functions.
- **What evidence would resolve it**: Comparative analysis of block decomposition quality using different reward function designs for various types of shapes.

## Limitations
- Current method is limited to 2D axis-aligned shapes with straight edges, not real-world CAD models
- Generalization evidence is weak - test shapes come from same distribution as training set
- Geometric modeler integration with OpenCascade is not fully specified
- Reward function may not capture all relevant aspects of good block decomposition for practical meshing

## Confidence
- **High Confidence**: The agent successfully learns to decompose training shapes into quadrilateral blocks using the described SAC algorithm and reward structure. The convergence after ~1500 episodes is well-demonstrated.
- **Medium Confidence**: The agent generalizes to the 12 held-out test shapes from the same distribution. The claim that this demonstrates transferable policy learning is reasonable but requires more diverse testing.
- **Low Confidence**: The claim that the approach encapsulates principles needed for complex 2D/3D shapes. The limitation to axis-aligned cuts and 2D shapes means this remains speculative without further validation.

## Next Checks
1. **Generalization Stress Test**: Evaluate the trained agent on shapes with non-axis-aligned edges and curved boundaries (e.g., L-shapes, T-joints, circular cutouts) to assess true generalization beyond the training distribution.

2. **Reward Function Ablation**: Systematically vary the reward function weights (edge penalty, area variance, aspect ratio) and measure the impact on decomposition quality metrics (number of blocks, aspect ratios, mesh quality) to identify which components are most critical for good performance.

3. **3D Extension Feasibility**: Implement a simplified 3D version using axis-aligned cuts only on simple prisms (extruded rectangles) to empirically test whether the 2D policy can be extended to 3D, validating the claim about encapsulating generalizable principles.
