# A Novel Correlation-optimized Deep Learning Method for Wind Speed Forecast

## Quick Facts
- arXiv ID: 2306.01986
- Source URL: https://arxiv.org/abs/2306.01986
- Reference count: 40
- This paper introduces a correlation-optimized deep learning framework for wind speed forecasting that improves accuracy and stability compared to traditional models.

## Executive Summary
This paper presents a novel deep learning framework for wind speed forecasting that leverages correlation-optimized data preprocessing and a knowledge tree structure. The method uses Pearson correlation optimization to construct multi-layer knowledge trees from spatio-temporal wind data, which are then fed into a sequence-to-sequence model enhanced with cognition and memory units (CMU). Experimental results on three wind datasets demonstrate improved forecasting accuracy (up to 97% in some cases), lower RMSE, and faster convergence compared to traditional LSTM and LSTM/GRU-based Seq2Seq models.

## Method Summary
The proposed method transforms wind speed forecasting into a correlation optimization problem using Pearson correlation coefficients. An optimization model converts the correlation objective into a convex form for efficient computation, constructing multi-layer knowledge trees from spatio-temporal data. These knowledge trees serve as structured inputs to a Seq2Seq model enhanced with new cognition and memory units (CMU). The framework aims to improve both the accuracy and interpretability of wind speed predictions while maintaining training efficiency.

## Key Results
- Achieves up to 97% accuracy on tested wind datasets from a Chinese wind farm
- Demonstrates lower RMSE and faster convergence compared to traditional LSTM and LSTM/GRU models
- Provides interpretable, structured knowledge representations that aid in feature selection and model reliability
