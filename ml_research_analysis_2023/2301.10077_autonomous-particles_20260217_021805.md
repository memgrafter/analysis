# Autonomous particles

## Executive Summary
This paper presents a reinforcement learning framework for autonomous driving that leverages Galilean and permutation symmetries to dramatically reduce the dimensionality of the learning problem. By mapping high-dimensional environmental data to a small set of rotationally and translationally invariant scalar features, the framework enables effective collision avoidance and destination arrival using minimal computational resources. The approach demonstrates that only four invariant features and a small neural network are sufficient for 50 vehicles to learn effective driving behaviors in 2D simulations.

## Method Summary
The framework employs a neural network architecture with four key components: a detection layer that processes raw environmental information, an invariants layer that maps this information to rotationally and translationally invariant scalar features, a trainable network module that outputs desired positions and velocities, and an output layer. The method exploits physical symmetries to reduce the learning problem from high-dimensional raw data to a small set of scalar invariants derived from relative positions and velocities. In 2D simulations with 50 autonomous vehicles, the approach successfully achieves collision-free navigation and destination arrival while naturally developing traffic rules through decentralized learning.

## Key Results
- Demonstrated effective collision avoidance and destination arrival with only 4 invariants and a 30-neuron network in 2D simulations
- Learning converges rapidly, with average loss decaying within the first 1000 time steps
- Traffic rules (left or right-hand driving) emerge naturally through decentralized learning
- The framework successfully exploits Galilean and permutation symmetries to reduce dimensionality

## Why This Works (Mechanism)
The framework exploits fundamental physical symmetries (Galilean invariance and permutation symmetry) to reduce the dimensionality of the autonomous driving problem. By mapping raw environmental data to a small set of rotationally and translationally invariant scalar features, the network focuses learning on the essential information needed for collision avoidance and navigation. This dimensionality reduction allows effective learning with minimal computational resources while maintaining robustness to coordinate transformations.
