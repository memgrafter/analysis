# Regression-based Deep-Learning predicts molecular biomarkers from pathology slides

## Quick Facts
- arXiv ID: 2304.05153
- Source URL: https://arxiv.org/abs/2304.05153
- Reference count: 40
- Regression-based DL outperforms traditional classification approaches for predicting continuous molecular biomarkers from pathology slides

## Executive Summary
This study introduces CAMIL regression, a self-supervised attention-based weakly supervised regression method for predicting continuous molecular biomarkers directly from histopathology slides. The approach was evaluated across 11,671 patients from nine cancer types, demonstrating superior performance compared to classification-based methods for biomarkers including homologous recombination deficiency (HRD) score and tumor microenvironment markers. The regression approach showed enhanced interpretability through sharper attention heatmaps and improved prognostic value in survival analysis, particularly for immunologic biomarkers.

## Method Summary
The CAMIL regression method combines self-supervised contrastive clustering (RetCCL) for feature extraction with attention-based multiple instance learning to predict continuous molecular biomarkers from whole slide images. The pipeline processes WSIs through tessellation, Canny edge filtering, and Macenko color normalization, extracting 224x224 pixel patches. Features are then aggregated using an attention mechanism that learns to weight tiles based on their relevance to the target biomarker. The model was trained using site-aware 5-fold cross-validation on TCGA cohorts and compared against both classification approaches and previous regression methods, with external validation on DACHS cohort data.

## Key Results
- CAMIL regression achieved AUROC values of 0.78 for HRD prediction in breast cancer, outperforming classification-based methods
- Regression models produced sharper attention heatmaps that better highlighted clinically relevant regions, particularly for tumor-infiltrating lymphocytes
- In colorectal cancer survival analysis, regression-based prediction scores provided higher prognostic value than classification-based scores, with hazard ratios ranging from 1.10 to 1.49
- The approach demonstrated robust performance across multiple cancer types and biomarkers including proliferation, lymphocyte fraction, and stromal fraction

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Regression-based DL outperforms classification-based DL for continuous biomarkers because it preserves the full distribution of continuous ground truth values rather than losing information through binarization.
- Mechanism: By predicting continuous values directly, the model avoids the information loss inherent in threshold-based categorization, enabling richer signal extraction from histopathological features.
- Core assumption: The continuous biomarker ground truth contains more predictive signal than its binarized version, and this additional signal can be captured by DL models trained on histology images.

### Mechanism 2
- Claim: CAMIL regression's combination of self-supervised pre-training and attention-based multiple instance learning enables superior feature extraction and spatial localization compared to traditional approaches.
- Mechanism: The self-supervised contrastive clustering (RetCCL) pre-trains the feature extractor on large histopathology datasets, capturing domain-specific patterns before fine-tuning on biomarker prediction. The attention mechanism then aggregates tile-level features while highlighting clinically relevant regions.
- Core assumption: Self-supervised pre-training on large histopathology datasets provides better initialization than ImageNet weights for this domain-specific task.

### Mechanism 3
- Claim: Regression models provide superior interpretability through sharper attention heatmaps that better highlight clinically relevant regions compared to classification models.
- Mechanism: By predicting continuous values, regression models can express confidence gradients across the image, leading to more precise localization of biomarker-relevant features rather than binary importance scores.
- Core assumption: The continuous output of regression models enables more nuanced attention weight distributions that better reflect the underlying biological relevance of image regions.

## Foundational Learning

- Concept: Weakly supervised learning
  - Why needed here: The ground truth biomarkers are measured at the patient level, but the model processes individual image patches/tiles. The model must learn to aggregate tile-level information to predict patient-level outcomes without explicit tile-level labels.
  - Quick check question: If a patient has multiple WSIs, how would you aggregate predictions from each WSI to produce a single patient-level prediction?

- Concept: Attention-based multiple instance learning
  - Why needed here: Multiple instance learning addresses the problem of having labels at the bag (patient) level but features at the instance (tile) level. The attention mechanism learns which tiles are most relevant for predicting the patient-level biomarker.
  - Quick check question: What would happen to the model's performance if you replaced the attention mechanism with simple mean pooling of tile features?

- Concept: Self-supervised contrastive learning
  - Why needed here: Pre-training the feature extractor using contrastive clustering on large histopathology datasets provides better initialization than using ImageNet weights, as histopathology images have different characteristics than natural images.
  - Quick check question: How would you evaluate whether self-supervised pre-training on histopathology data actually improves downstream biomarker prediction performance?

## Architecture Onboarding

- Component map: WSI preprocessing pipeline -> tile extraction and filtering -> Color normalization module -> Macenko spectral matching -> Feature extractor (RetCCL) -> ResNet50 backbone with contrastive clustering -> Attention-based MIL head -> MLP with attention mechanism -> Regression head -> Custom head for continuous output -> Classification head -> Sigmoid output for binary classification

- Critical path: WSI -> tiles -> feature extraction -> attention aggregation -> prediction
  - The feature extractor and attention mechanism are the most critical components for performance

- Design tradeoffs:
  - Tile size (224x224) vs computational cost vs local feature resolution
  - Number of tiles per WSI vs memory constraints vs representation completeness
  - Self-supervised pre-training dataset size vs domain specificity vs computational cost
  - Attention mechanism complexity vs interpretability vs overfitting risk

- Failure signatures:
  - Poor performance on external validation sets -> overfitting to training site characteristics
  - Attention heatmaps highlighting irrelevant regions -> feature extractor not capturing relevant patterns
  - Regression outputs clustered around mean values -> optimizer not properly handling regression loss
  - AUROC improvement without meaningful separation in score distributions -> AUROC not capturing the right performance metric

- First 3 experiments:
  1. Ablation study: Replace self-supervised feature extractor with ImageNet-pretrained ResNet50 and compare performance on HRD prediction
  2. Sensitivity analysis: Vary tile size (128x128, 224x224, 512x512) and measure impact on AUROC and attention heatmap quality
  3. External validation: Deploy trained models on a held-out external dataset and compare classification vs regression performance across multiple biomarkers

## Limitations
- Performance comparisons are limited to a single regression baseline and one classification approach, which may not represent the full spectrum of possible methods
- Attention heatmap interpretability comparisons rely on qualitative descriptions rather than quantitative metrics
- Clinical significance of modest prognostic improvements (hazard ratios 1.10-1.49) requires larger validation studies
- Self-supervised pre-training evaluation is confined to the same study framework without comparison to other pre-training strategies

## Confidence

- **High confidence**: The core finding that regression-based approaches can outperform classification for continuous biomarker prediction from histopathology images. This is supported by multiple biomarkers across different cancer types and validated on external cohorts.
- **Medium confidence**: The superiority of CAMIL regression's attention-based weakly supervised approach specifically, as this combines multiple methodological innovations whose individual contributions are not fully disentangled.
- **Low confidence**: The clinical significance of the prognostic improvements, as the reported hazard ratios, while statistically significant, represent relatively modest effect sizes that require larger validation studies.

## Next Checks

1. **Ablation study**: Perform controlled experiments to isolate the contributions of self-supervised pre-training, attention mechanism, and regression loss function to the observed performance improvements.

2. **External clinical validation**: Test the regression models on completely independent patient cohorts from different institutions and geographic regions to assess generalizability and clinical utility.

3. **Interpretability quantification**: Develop quantitative metrics for comparing attention heatmap quality between regression and classification approaches, moving beyond qualitative descriptions of "sharper" heatmaps.
