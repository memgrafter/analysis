# CGDTest: A Constrained Gradient Descent Algorithm for Testing Neural Networks

## Quick Facts
- arXiv ID: 2304.01826
- Source URL: https://arxiv.org/abs/2304.01826
- Reference count: 31
- Primary result: Achieved up to 1500% improvement in PAR2 scores for non-ℓp constraints, matched top performance on ℓp-ball attacks, and ranked 5th in VNN-COMP 2022

## Executive Summary
CGDTest introduces a novel DNN testing algorithm that enables users to specify arbitrary logical constraints as part of the loss function when searching for adversarial inputs. Unlike existing methods limited to ℓp-ball constraints, CGDTest supports richer properties including disguised and flow-based adversarial constraints, and extends to NLP domains via embedding projections with syntactic/semantic constraints. The tool was evaluated against 32 state-of-the-art tools across vision and NLP tasks, demonstrating significant improvements in both expressibility and scalability.

## Method Summary
CGDTest uses constrained gradient descent to find adversarial inputs that satisfy user-defined logical constraints while causing misclassification. The method converts logical constraints into differentiable loss functions using Lukasiewicz t-norm relaxations, combines this with classification loss, and optimizes jointly via gradient descent. For NLP inputs, the tool projects discrete text to continuous embeddings and adds constraints to preserve syntax and semantics by restricting perturbations to non-named-entity regions. The approach scales to very large DNNs (up to 138M parameters) without requiring symbolic encoding, making it applicable to real-world models.

## Key Results
- Achieved up to 1500% improvement in PAR2 scores over next best tool for non-ℓp constraints
- Matched top performance on ℓp-ball adversarial attacks while outperforming competitors on disguised and flow constraints
- Ranked 5th in VNN-COMP 2022, the only incomplete solver in the top ranks
- Demonstrated strong scalability to models with 138 million parameters

## Why This Works (Mechanism)

### Mechanism 1
- Claim: CGDTest enables specification of arbitrary logical constraints in the loss function, expanding the space of adversarial inputs beyond ℓp-ball.
- Mechanism: The tool parses user-defined logical constraints into a differentiable constraint loss function using Lukasiewicz t-norm relaxations. This loss is combined with classification loss and optimized via gradient descent to find inputs satisfying both constraints and misclassification.
- Core assumption: Logical constraints can be accurately converted into smooth, differentiable functions that preserve the semantics of the original constraints.
- Evidence anchors: [abstract] "CGD converts a rich class of logical constraints into a differentiable loss function (called 'constraint loss') following the approach in Probabilistic Soft Logic"; [section] "The language of constraints in our setting consists of boolean combinations of comparisons between terms, where each term is either a constant or a differentiable function"

### Mechanism 2
- Claim: CGDTest scales to very large DNNs (138M parameters) while maintaining effectiveness on complex constraints.
- Mechanism: Uses gradient descent directly on the model without symbolic encoding, avoiding the scalability bottlenecks of verification methods. Projects NLP inputs to continuous embeddings with named entity constraints to handle discrete input spaces.
- Core assumption: Gradient-based methods can effectively explore large input and model spaces without symbolic bounds.
- Evidence anchors: [abstract] "can be applied to very large real-world models with up to 138 million parameters"; [section] "Unlike in the vision domain, gradient-based adversarial attacks do not typically work in the natural language processing domain because the inputs are discrete"

### Mechanism 3
- Claim: CGDTest achieves massive PAR2 improvements over competitors on non-ℓp constraints by directly optimizing for those properties.
- Mechanism: By incorporating the target constraint into the loss, CGDTest searches for adversarial examples that satisfy the constraint and cause misclassification, rather than just finding nearby ℓp-perturbed inputs.
- Core assumption: Optimizing joint constraint and misclassification loss is more effective than sequential or heuristic approaches.
- Evidence anchors: [abstract] "improvements in PAR2 scores of over 1500% in some cases over the next best tool"; [section] "CGDTest was found to have the lowest (i.e., the best) PAR2 score among all the tools on the disguised and flow adversarial constraints, with 309.13% and over 1500% improvement over the next best tool"

  - Why needed here: CGDTest handles NLP inputs by projecting to continuous embeddings and constraining perturbations to non-named-entity regions; understanding this is key to extending the method to other discrete domains.

## Architecture Onboarding

- Component map: Input parser -> Constraint loss converter -> Joint loss function -> Gradient descent optimizer -> Output validator
  - Supporting: TensorFlow/Keras model interface, NLP encoder/decoder pipeline, named entity recognizer

- Critical path:
  1. Parse and convert user constraints into differentiable loss
  2. Initialize input vector
  3. Compute combined loss and gradients
  4. Update input via gradient descent
  5. Check termination (constraints satisfied + misclassification)
  6. Return adversarial example or timeout

- Design tradeoffs:
  - Expressiveness vs. differentiability: More complex constraints may not yield smooth gradients
  - Scalability vs. accuracy: Larger models increase gradient computation cost
  - Domain generality vs. domain-specific optimization: Generic method works across domains but may be outperformed by specialized tools

- Failure signatures:
  - "Incomplete" return: timeout or no feasible input found
  - High constraint loss but low misclassification: constraints too strict
  - Low constraint loss but high misclassification: misclassification not optimized properly

- First 3 experiments:
  1. Test CGDTest on a small vision model with ℓp-ball constraints; compare PAR2 score to FGSM
  2. Apply CGDTest to an NLP model with named entity constraints; verify syntax preservation
  3. Run CGDTest on a medium-sized model with disguised constraints; measure PAR2 improvement over baseline

## Limitations

- The evaluation relies entirely on the authors' internal benchmarking against 32 tools, with no public replication dataset or source code available for independent verification.
- The 1500% PAR2 improvement claims for non-ℓp constraints, while impressive, cannot be externally validated without access to the exact constraint formulations and comparison baselines.
- The tool's performance on VNN-COMP 2022 occurred in a competition setting where full details of competing methods and problem instances are not publicly available.

## Confidence

- **High confidence**: CGDTest's basic approach of combining differentiable constraint loss with classification loss via gradient descent is well-founded and the scaling to 138M parameters is plausible given modern hardware.
- **Medium confidence**: The 1500% improvement claims for non-ℓp constraints and the ranking in VNN-COMP 2022, as these depend on specific experimental conditions not fully disclosed.
- **Low confidence**: The generalizability of results to domains and constraint types not tested, as the evaluation is limited to specific benchmark suites.
