# Agnostic PAC Learning of k-juntas Using L2-Polynomial Regression

## Quick Facts
- arXiv ID: 2303.04859
- Source URL: https://arxiv.org/abs/2303.04859
- Reference count: 40

## Executive Summary
This paper resolves a long-standing open problem in learning theory by proving that L2 polynomial regression is an optimal agnostic PAC learner for k-juntas. The authors demonstrate that taking the sign of the L2 polynomial regressor achieves a generalization error of opt + O(√(k2k log d/n) + √(log(1/δ)/2n)). They also present a Fourier-based algorithm that maintains the same error guarantees while improving computational efficiency. The key technical contribution is establishing tight bounds connecting 0-1 loss and square loss, showing that the minimum mean square estimator is a PAC learner for concept classes containing it.

## Method Summary
The paper establishes that L2 polynomial regression is an optimal agnostic PAC learner for k-juntas by taking the sign of the L2 polynomial regressor. The authors prove this approach achieves optimal generalization error bounds. They also develop a Fourier-based algorithm that provides the same error guarantees while improving computational complexity to O(nk dk/(k-1)!). The core technical advance lies in deriving tight bounds connecting the 0-1 loss and square loss, demonstrating that the sign of the minimum mean square estimator PAC learns concept classes containing it.

## Key Results
- L2 polynomial regression agnostically PAC learns k-juntas, resolving a 1993 open question
- Generalization error bound of opt + O(√(k2k log d/n) + √(log(1/δ)/2n))
- Fourier-based algorithm achieves same error guarantees with computational complexity O(nk dk/(k-1)!)
- Establishes tight bounds connecting 0-1 loss and square loss for k-juntas

## Why This Works (Mechanism)
The mechanism relies on the connection between L2 polynomial regression and the underlying structure of k-juntas. By minimizing the mean square error, the algorithm effectively learns the underlying k-junta function. The sign operation then converts the continuous regression output into a binary classifier that achieves the optimal agnostic PAC learning guarantee. The Fourier-based approach exploits the sparse Fourier representation of k-juntas to achieve computational efficiency.
