# An Expert System to Diagnose Spinal Disorders

## Quick Facts
- arXiv ID: 2302.03625
- Source URL: https://arxiv.org/abs/2302.03625
- Reference count: 0
- The system achieves 0.915-0.940 average accuracy in diagnosing spinal disorders using hybrid inference.

## Executive Summary
This paper presents an expert system for diagnosing spinal disorders using a hybrid inference algorithm combining Backward Chaining Inference with Theory of Uncertainty. The system was evaluated on real-world samples and medical records, demonstrating high accuracy in detecting various spinal abnormalities including cervical lordosis, swayback, kyphosis, flat back, and scoliosis. The system serves as both a diagnostic validation tool for specialists and an educational resource for medical students.

## Method Summary
The system employs a hybrid inference algorithm that integrates Backward Chaining Inference with Theory of Uncertainty. Backward chaining starts with the goal (diagnosis) and recursively seeks confirming rules, while certainty factors quantify symptom presence and combine evidence probabilistically. Expert knowledge is acquired through structured interviews with multiple specialists who classify symptoms, assign certainty factors, and iteratively refine the symptom lists. The system uses Java Drools for rule-based implementation and features a JavaFX-based GUI for user interaction.

## Key Results
- System achieves average accuracy values ranging from 0.915 to 0.940 for detecting various spinal disorders
- Successfully detects cervical lordosis, swayback, kyphosis, flat back, and scoliosis
- Certainty degree calculation provides risk assessment capability for each diagnosis

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The hybrid inference algorithm improves diagnostic accuracy by integrating Backward Chaining Inference with Theory of Uncertainty.
- Mechanism: Backward chaining starts with the goal (diagnosis) and recursively seeks rules that confirm the goal, while the Theory of Uncertainty uses certainty factors to quantify symptom presence and combine evidence probabilistically.
- Core assumption: Spinal disorder symptoms are not binary and can be represented by probability distributions and dependencies.
- Evidence anchors:
  - [abstract] "hybrid inference algorithm combining Backward Chaining Inference and Theory of Uncertainty"
  - [section 3.2] "Backward chaining begins with the evidence and progresses to the conclusions"
  - [section 3.4] "The certainty factor (CF) to implement the theory of uncertainty"
- Break condition: If symptom dependencies are too sparse or certainty factors are poorly calibrated, the combined inference may become unreliable.

### Mechanism 2
- Claim: Certainty effect factor reduces redundant rule firing and improves efficiency by pruning the inference chain.
- Mechanism: Each symptom is assigned a certainty effect value; during inference, only rules with symptom certainty effect above a threshold are considered, eliminating unnecessary questioning.
- Core assumption: Symptoms can be classified and aggregated into groups with a representative certainty effect without significant loss of diagnostic precision.
- Evidence anchors:
  - [section 5.2] "this factor helped to simplify the system design by integrating symptoms into some classes"
  - [section 5.2] "the method proposed in this study drew on the certainty effect factor"
- Break condition: If symptom distributions overlap heavily across disorders, the classification into classes may obscure critical distinctions.

### Mechanism 3
- Claim: Knowledge acquisition through structured interviews with multiple experts yields high-integrity diagnostic rules.
- Mechanism: Experts classify symptoms by importance, assign certainty factors, and iteratively refine symptom lists to capture all relevant indicators of each spinal anomaly.
- Core assumption: Expert consensus on symptom certainty factors is stable and representative of real-world diagnostic patterns.
- Evidence anchors:
  - [section 5.1] "experts were asked to classify the symptoms based on their importance and rate of occurrence"
  - [section 5.1] "the certainty factors assigned by the experts were summed, and the average value was considered"
- Break condition: If expert opinions diverge widely or are biased, the aggregated certainty factors may mislead the system.

## Architecture Onboarding

- Component map:
  - User Interface -> Inference Engine -> Knowledge Base -> Certainty Memory
- Critical path:
  1. User selects disorder type
  2. System queries symptom with highest certainty effect
  3. User inputs symptom presence certainty
  4. Update certainty memory and fire matching rules
  5. Compute certainty degree and repeat until no rules remain
- Design tradeoffs:
  - Hybrid inference vs pure forward chaining: higher accuracy but more complex implementation
  - Certainty effect pruning vs exhaustive questioning: faster but potential for missed rare symptoms
  - Expert consensus vs individual expert rules: more robust but slower knowledge acquisition
- Failure signatures:
  - High variance in expert-assigned certainty factors → unreliable thresholds
  - Symptom classes too broad → ambiguous diagnostic outcomes
  - Certainty memory not updated correctly → redundant questioning or skipped critical symptoms
- First 3 experiments:
  1. Unit test the certainty factor combination formulas with synthetic symptom data
  2. Simulate backward chaining on a minimal rule set to verify goal-driven flow
  3. Load a small expert-defined symptom set and run the inference engine to check certainty memory updates

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal cut-off value for certainty degree to reliably diagnose each spinal disorder (scoliosis, flat back, kyphosis, cervical lordosis, swayback)?
- Basis in paper: [explicit] The paper discusses cut-off values determined by experts but notes that even with these thresholds, some cases require further examination, indicating uncertainty about optimal values.
- Why unresolved: The experts agreed on three categories (true positive, true negative, further examination) but the certainty degree ranges for each category may vary between disorders and individual cases, making it difficult to establish universally optimal thresholds.
- What evidence would resolve it: A large-scale study comparing diagnostic accuracy using different cut-off values for each disorder, with ground truth established through comprehensive clinical examinations, would help determine optimal thresholds.

## Limitations

- Performance metrics lack details on test dataset size and diversity
- Reliance on expert consensus introduces potential bias in certainty factor assignments
- JavaFX-based implementation limits accessibility compared to web-based alternatives

## Confidence

- High confidence: The hybrid inference mechanism combining backward chaining and certainty factors is technically sound and well-documented in AI literature
- Medium confidence: Expert knowledge acquisition methodology is reasonable but lacks transparency in how consensus was achieved across multiple specialists
- Low confidence: Real-world validation metrics are limited; the reported accuracy ranges need verification on larger, more diverse patient populations
