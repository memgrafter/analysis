# Short Answer Grading Using One-shot Prompting and Text Similarity Scoring Model

## Quick Facts
- arXiv ID: 2305.18638
- Source URL: https://arxiv.org/abs/2305.18638
- Reference count: 5
- Accuracy: 0.67 on ASAP-SAS subset

## Executive Summary
This paper presents an automated short answer grading (ASAG) model that combines one-shot prompting with GPT-3.5 for justification key extraction and a text similarity scoring model for analytic and holistic scoring. The approach addresses the challenge of constructing large annotated datasets by using a small manually annotated dataset for domain adaptation while generating additional training data automatically. The model achieves accuracy of 0.67 and quadratic weighted kappa of 0.71 on a subset of the ASAP-SAS dataset, substantially outperforming the majority baseline of 0.53.

## Method Summary
The method uses GPT-3.5 text-davinci-003 for one-shot prompting to extract justification keys from student answers based on question sub-question text and demonstration examples. These keys are then scored using an adapted Sentence-BERT model that is fine-tuned on a small gold dataset (manually annotated answers) and a larger silver dataset (auto-labeled using the training partition). The analytic scores from each sub-question are summed to produce holistic scores. The approach requires minimal manual annotation while maintaining reasonable performance through domain adaptation.

## Key Results
- Model accuracy of 0.67 and quadratic weighted kappa of 0.71 on ASAP-SAS subset
- Justification key extraction accuracy of 90.3% using one-shot prompting
- Substantial improvement over majority baseline (accuracy 0.53)
- Domain adaptation was critical for performance, while reference answer augmentation had marginal impact

## Why This Works (Mechanism)

### Mechanism 1
- Claim: One-shot prompting with GPT-3.5 can accurately extract justification keys from student answers.
- Mechanism: The prompt uses the question's sub-question text as instructions and a single demonstration example to guide the LLM in identifying text spans relevant to each sub-question.
- Core assumption: GPT-3.5 can generalize from one demonstration to extract relevant text spans across diverse short answer questions.
- Evidence anchors:
  - [abstract] "The justification key extraction accuracy was high (90.3%)."
  - [section] "For each manual and system-based justification key pairs, if the system key contained the entire manual key or the word overlap between two keys was over 90%, we counted it as a correct case."
  - [corpus] Weak evidence; corpus shows related work on LLM-based ASAG but no direct validation of one-shot prompting accuracy.
- Break condition: If the demonstration example doesn't represent the answer structure well, or if the question phrasing is ambiguous, the LLM may extract irrelevant spans or miss key content.

### Mechanism 2
- Claim: SBERT with domain adaptation can effectively score semantic similarity between justification keys and reference answers.
- Mechanism: The model uses a pre-trained SBERT encoder fine-tuned on a small gold dataset and a large silver dataset generated from the training partition, allowing it to learn domain-specific similarity patterns.
- Core assumption: Even with limited manually annotated pairs, the silver dataset provides enough signal for effective domain adaptation.
- Evidence anchors:
  - [abstract] "The model achieved accuracy of 0.67 and quadratic weighted kappa of 0.71 on a subset of the ASAP-SAS dataset."
  - [section] "For the silver dataset was generated using the train-ing partition... A similarity score between the training sentence and the reference answer was calculated using the pre-trained SBERT cross-encoder."
  - [corpus] Weak evidence; corpus neighbors focus on other ASAG approaches but don't directly validate SBERT domain adaptation for this task.
- Break condition: If the silver dataset labels are noisy or unrepresentative, the adapted model may learn incorrect similarity patterns, hurting scoring accuracy.

### Mechanism 3
- Claim: Combining one-shot prompting for key extraction with SBERT scoring can achieve reasonable holistic grading without extensive manual annotation.
- Mechanism: Justification keys are first extracted by the LLM, then scored by SBERT against reference answers; analytic scores are summed to produce the holistic score.
- Core assumption: Accurate key extraction (90.3%) combined with effective similarity scoring is sufficient to produce valid holistic grades.
- Evidence anchors:
  - [abstract] "The model achieved accuracy of 0.67 and quadratic weighted kappa of 0.71 on a subset of the ASAP-SAS dataset, substantially improving over the majority baseline (accuracy 0.53)."
  - [section] "The accuracy of the justification key detection was high. Furthermore, most errors were from low-scoring answers where the justification keys did not contain correct content."
  - [corpus] Weak evidence; corpus shows related ASAG work but doesn't validate this specific pipeline's holistic grading performance.
- Break condition: If key extraction fails on complex answers or SBERT similarity scores are unreliable, the holistic score will deviate significantly from human ratings.

  - Why needed here: Reduces the need for large annotated datasets by allowing the model to learn from a single demonstration.

## Architecture Onboarding

- Component map: Input → GPT-3.5 one-shot prompt → Justification key extraction → SBERT similarity scoring → Analytic score generation → Holistic score generation
- Critical path: Justification key extraction → SBERT scoring → Analytic score generation (errors here directly affect final grade)
- Design tradeoffs: Limited annotations vs. model performance; one-shot prompting vs. few-shot or fine-tuning; semantic similarity vs. exact matching
- Failure signatures: Low justification key extraction accuracy (< 80%), SBERT scoring inconsistencies, analytic scores not summing to holistic scores correctly
- First 3 experiments:
  1. Test one-shot prompting accuracy on a small manually annotated set to confirm ~90% extraction rate.
  2. Compare SBERT performance with and without domain adaptation on a held-out similarity scoring task.
  3. Validate that analytic scores correctly sum to holistic scores across a sample of student answers.

## Limitations

- The approach relies heavily on GPT-3.5 for justification key extraction without validation of prompt robustness across different question types or demonstration examples.
- The reported 90.3% extraction accuracy uses a lenient evaluation metric (90% word overlap) that may not capture semantic relevance accurately.
- The ASAP-SAS subset used (only 4 questions) limits generalizability claims to other question types or domains.

## Confidence

- **High confidence**: The overall methodology pipeline (one-shot prompting + SBERT scoring) is technically sound and the improvement over majority baseline is statistically meaningful.
- **Medium confidence**: The reported accuracy (0.67) and kappa (0.71) values are reliable for the specific ASAP-SAS subset tested, but may not generalize to other question types or datasets.
- **Low confidence**: The 90.3% justification key extraction accuracy claim due to the lenient evaluation metric and lack of prompt template specification.

## Next Checks

1. **Prompt Robustness Testing**: Systematically vary the demonstration examples and question phrasing in the one-shot prompt across different answer structures to identify failure modes and establish reliability bounds for justification key extraction.

2. **Domain Adaptation Ablation**: Conduct controlled experiments comparing SBERT performance with and without domain adaptation on a held-out similarity scoring task using the same gold dataset to quantify the actual contribution of adaptation.

3. **Generalization Assessment**: Apply the complete pipeline to a different short answer grading dataset (e.g., Beetle or other ASAG benchmarks) to evaluate whether the reported accuracy and kappa scores are dataset-specific or represent generalizable performance.
