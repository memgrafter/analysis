# Does "Deep Learning on a Data Diet" reproduce? Overall yes, but GraNd at Initialization does not

## Quick Facts
- arXiv ID: 2303.14753
- Source URL: https://arxiv.org/abs/2303.14753
- Reference count: 5
- Primary result: EL2N metric successfully replicated; GraNd at initialization fails to reproduce

## Executive Summary
This reproduction study examines Paul et al.'s (2021) "Deep Learning on a Data Diet," which introduces EL2N and GraNd metrics for dataset pruning during neural network training. We successfully replicated the EL2N results but found that GraNd at initialization does not perform as originally reported. Our analysis reveals a strong correlation between GraNd at initialization and input norms, suggesting the latter could serve as a cheaper baseline for data pruning. Neither GraNd at initialization nor input norm outperforms random pruning, contradicting Paul et al.'s findings. We suspect a bug in the original JAX/FLAX code related to checkpoint restoring, fixed in April 2021.

## Method Summary
The paper introduces two dataset pruning metrics: EL2N (Euclidean norm of layer activations) and GraNd (gradient norm at initialization). We implemented both metrics following the original paper's methodology and tested them on CIFAR-10 with ResNet architectures. For EL2N, we computed activation norms after a few training epochs, while GraNd at initialization was computed before any training began. Both metrics were used to rank and prune datasets, comparing performance against random pruning baselines.

## Key Results
- EL2N metric successfully replicated with matching performance to original paper
- GraNd at initialization shows strong correlation with input norms (r > 0.9)
- Neither GraNd at initialization nor input norm outperforms random pruning
- GraNd scores after a few epochs perform similarly to EL2N scores

## Why This Works (Mechanism)
The EL2N metric works by measuring which training examples contribute most to activation growth during early training phases. These examples typically have features that align well with learned representations. GraNd at initialization attempts to measure gradient magnitudes before training begins, theoretically identifying samples that will be most influential. However, our findings suggest this metric is heavily biased by input feature magnitudes rather than learning dynamics.

## Architecture Onboarding

Component map:
Input data -> ResNet model -> Training loop -> Metric computation (EL2N/GraNd) -> Dataset pruning -> Retrained model

Critical path:
Data loading → Model initialization → Training (for EL2N) or Forward pass (for GraNd) → Metric calculation → Dataset ranking → Pruning → Retraining

Design tradeoffs:
- EL2N requires training epochs but captures learned dynamics
- GraNd at initialization is computationally cheap but may capture spurious correlations
- Random pruning serves as a simple baseline

Failure signatures:
- EL2N fails if training doesn't progress sufficiently before metric computation
- GraNd at initialization fails if input features have high variance
- Both metrics fail if pruning ratio is too aggressive

3. Compare all metrics against random pruning baseline

- Only tested pruning ratios used in original paper without exploring extremes
