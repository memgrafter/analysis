# Exact Subspace Diffusion for Decentralized Multitask Learning

## Quick Facts

- Source URL: https://arxiv.org/abs/2304.07358

## Executive Summary
This paper addresses decentralized multitask learning over networks where agents minimize heterogeneous objectives while maintaining relationships between local models. The authors develop an exact subspace diffusion algorithm that generalizes exact diffusion methods to subspace-constrained multitask learning. The algorithm removes bias present in approximate projection methods by employing primal-dual arguments and allows for multiple local updates between communication rounds. The key contribution is deriving a precise expression for the mean-squared deviation of the algorithm when using noisy gradient approximations.

## Method Summary
The algorithm introduces dual variables λ and an augmented Lagrangian formulation to enforce the exact subspace constraint through matrix B. The primal updates remain in the exact subspace R(U) at every iteration, eliminating projection approximation error. The method allows E local gradient steps before communication and aggregation. Theoretical analysis derives mean-squared deviation expressions that account for signal-to-noise ratio and subspace constraint structure. The approach requires closed-form projection matrices and satisfies regularity conditions including strong convexity and Lipschitz gradients.

## Key Results
- Exact subspace diffusion outperforms approximate projection methods, especially in low-noise regimes
- Allowing multiple local updates (E > 1) provides significant performance gains
- Theoretical mean-squared deviation expressions accurately predict empirical performance across various noise conditions
- The algorithm maintains exact subspace membership at every iteration through primal-dual enforcement
