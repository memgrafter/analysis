# InDL: A New Dataset and Benchmark for In-Diagram Logic Interpretation based on Visual Illusion

## Quick Facts
- arXiv ID: 2305.17716
- Source URL: https://arxiv.org/abs/2305.17716
- Authors: 
- Reference count: 40
- One-line primary result: The paper introduces InDL, a dataset using visual illusions to benchmark deep learning models' in-diagram logic interpretation, revealing a disconnect between ImageNet classification performance and logic interpretation capability.

## Executive Summary
This paper introduces InDL, a novel dataset designed to evaluate deep learning models' capacity for in-diagram logic interpretation using visual illusions. The authors establish a rigorous benchmark that tests whether models can correctly interpret logical relationships in images where perceptual distortions are present. Through systematic evaluation of 10 pre-trained models across six classic geometric optical illusions, the study reveals that high performance on standard classification benchmarks like ImageNet does not necessarily translate to enhanced capability for interpreting visual logic. An exception is the 2022 ConvNext model, which demonstrates strong performance across both tasks.

## Method Summary
The method involves creating the InDL dataset with 10,000 samples composed of six classic geometric optical illusions (Poggendorff, Zollner, Hering, Wundt, Muller-Lyer, Vertical-horizontal) in both illusion and non-illusion variants. The authors evaluate 10 pre-trained deep learning models using recall as the primary metric, measuring the proportion of actual positive cases that models correctly identify. The models are fine-tuned for one iteration using the AdamW optimizer on the InDL dataset, and their performance is compared against their ImageNet classification accuracy to establish the benchmark.

## Key Results
- ImageNet classification performance does not correlate with in-diagram logic interpretation capability
- ConvNext (2022) is the exception, performing well on both ImageNet and InDL tasks
- Model performance on in-diagram logic interpretation shows systematic degradation as illusion strength increases
- Recall is a more appropriate metric than accuracy for evaluating in-diagram logic interpretation

## Why This Works (Mechanism)

### Mechanism 1
Visual illusions serve as effective probes for distinguishing between perceptual patterns and logical reasoning in deep learning models. The dataset presents images where geometric configurations trigger perceptual distortions (illusions) but the underlying logical relationships remain constant. Models must override perceptual bias to correctly interpret logical structure.

### Mechanism 2
Performance on standard classification benchmarks (like ImageNet) doesn't correlate with in-diagram logic interpretation capability. Models trained on ImageNet learn features optimized for object recognition and scene categorization, which may not transfer to understanding abstract logical relationships embedded in visual configurations.

### Mechanism 3
Illusion strength modulates model performance in a predictable way, revealing different robustness levels across architectures. As the strength of visual illusions increases, models show varying degrees of susceptibility, with some maintaining performance across a wider range of illusion strengths.

## Architecture Onboarding

- **Component map**: Image preprocessing → illusion strength parameterization → ground truth logic annotation → forward pass → logic interpretation → recall calculation → statistical analysis of false negatives across illusion strengths

- **Critical path**: Load pre-trained model weights → preprocess images to match training conditions → generate predictions for logic interpretation → compare predictions to ground truth → calculate recall metrics → analyze performance across illusion strengths

- **Design tradeoffs**: Using pre-trained weights vs. training from scratch (pre-trained weights provide consistency but may limit discovery of novel capabilities); fixed vs. variable illusion strength (fixed strength simplifies analysis but misses the relationship between illusion strength and model performance); recall vs. other metrics (recall emphasizes detection capability but may miss precision considerations)

- **Failure signatures**: Uniform low recall across all illusion types suggests fundamental logic interpretation limitations; high recall on simple illusions but low recall on complex illusions suggests scalability issues; correlation between ImageNet accuracy and InDL performance suggests insufficient benchmark diversity

- **First 3 experiments**: 1) Run baseline Xception model on all InDL datasets and calculate overall recall; 2) Vary illusion strength parameters systematically and plot recall degradation curves; 3) Compare performance across different model families (CNNs, NAS, Transformers) on the same illusion tasks

## Open Questions the Paper Calls Out

### Open Question 1
To what extent do the observed discrepancies between ImageNet performance and in-diagram logic interpretation capabilities reflect fundamental limitations in deep learning architectures versus issues with training methodology or data representation? The paper identifies the phenomenon but doesn't investigate whether it stems from architectural constraints or training approaches.

### Open Question 2
How would performance change if models were trained specifically on datasets that combine both visual illusions and logical reasoning elements, rather than adapting pre-trained models? The current approach leverages pre-trained models which may carry biases affecting their performance on logic interpretation tasks.

### Open Question 3
What specific aspects of visual illusions (e.g., geometric properties, contextual cues, perceptual grouping) most strongly influence the performance of deep learning models in logic interpretation tasks? While the paper demonstrates that illusion strength affects performance, it doesn't isolate which specific illusion characteristics are most critical.

## Limitations
- Dataset construction details and preprocessing procedures are not fully specified, limiting reproducibility
- Only 10 pre-trained models evaluated on a single dataset of 10,000 samples, limiting generalizability
- Only one training iteration used for fine-tuning, which may be insufficient for proper adaptation to the task

## Confidence
- **High Confidence**: The core observation that ImageNet classification doesn't directly translate to in-diagram logic interpretation is well-supported by the data
- **Medium Confidence**: The ranking of models based on recall performance across illusion strengths is reasonable but depends on dataset quality
- **Low Confidence**: Generalizability of the classification-logic interpretation disconnect to other visual reasoning tasks remains uncertain

## Next Checks
