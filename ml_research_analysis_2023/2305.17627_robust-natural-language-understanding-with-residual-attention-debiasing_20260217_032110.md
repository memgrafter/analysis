# Robust Natural Language Understanding with Residual Attention Debiasing

## Quick Facts
- **arXiv ID**: 2305.17627
- **Source URL**: https://arxiv.org/abs/2305.17627
- **Reference count**: 24
- **Primary result**: READ improves BERT-based NLU robustness on OOD test sets: +12.9% accuracy on HANS, +11.0% accuracy on FEVER-Symmetric, and +2.7% F1 on PAWS

## Executive Summary
This paper introduces READ, an end-to-end debiasing method for natural language understanding models that addresses dataset biases by mitigating spurious patterns captured in attention mechanisms. The method combines one-stage product-of-experts with attention residual learning, where the main model learns to capture unbiased features by focusing on the residual of biased attention. Experiments on three NLU tasks demonstrate significant improvements in out-of-distribution performance where common shortcuts are removed, with only 4.8% additional parameters compared to baseline models.

## Method Summary
READ debiases BERT-based NLU models by learning the residual between biased and main model attention distributions. It uses a weight-sharing design where the biased and main models share all encoder layers except attention modules and classification heads. During training, ensemble attention (weighted average of biased and main attention) is used for main prediction while biased attention is used for biased prediction. During inference, only the debiased main attention is used. The method adds minimal parameters while effectively mitigating dataset biases through attention residual learning.

## Key Results
- READ achieves +12.9% accuracy improvement on HANS (MNLI OOD test set)
- READ achieves +11.0% accuracy improvement on FEVER-Symmetric (FEVER OOD test set)
- READ achieves +2.7% F1 improvement on PAWS (QQP OOD test set)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: READ mitigates dataset biases by learning the residual between biased and main model attention distributions.
- Mechanism: READ uses additive ensemble of attention distributions from biased and main models. The main model learns to focus on unbiased residual attention by computing the difference between ensemble attention and biased attention. During training, ensemble attention is used for main prediction and biased attention for biased prediction. During inference, only the debiased main attention is used.
- Core assumption: Biased attention and main attention capture similar spurious features in the same semantic space, making their residual free of such biases.
- Evidence anchors:
  - [abstract] "Experiments on three NLU tasks show that READ significantly improves the performance of BERT-based models on OOD data with shortcuts removed, including +12.9% accuracy on HANS, +11.0% accuracy on FEVER-Symmetric, and +2.7% F1 on PAWS."
  - [section 2.3] "The ensemble attention ae combines main attention am and biased attention ab with weighted average. This additive ensemble is inspired by the success of using the probability difference for post-hoc debiasing."
- Break condition: If biased and main attention distributions don't capture similar spurious features, or if they operate in different semantic spaces, the residual learning would fail to produce unbiased attention.

### Mechanism 2
- Claim: The weight-sharing design between biased and main models allows end-to-end debiasing with minimal additional parameters.
- Mechanism: READ shares all weights between biased and main models except attention modules and classification heads. This allows the main model to fit unbiased attention residual while maintaining parameter efficiency.
- Core assumption: Shared encoder layers can preserve useful features while distinct attention modules can capture different attention patterns.
- Evidence anchors:
  - [section 2.2] "This weight-sharing design makes it possible to debias the model end-to-end with a few additional parameters. However, shared layers result in shared biases in these layers."
  - [section 4.2] "Although the best-performing READ variant has few ensemble layers, the configuration where the biased and main models share all encoder layers is still effective on HANS and PAWS."
- Break condition: If shared layers propagate too much bias that cannot be corrected by attention residual learning, or if distinct attention modules cannot capture sufficiently different patterns.

### Mechanism 3
- Claim: READ's attention residual learning is more effective than previous ensemble-based debiasing methods that only address logits.
- Mechanism: Previous methods apply debiasing on top-level logits without directly addressing biased attention patterns. READ proactively mitigates attention biases through learning attention residual, preventing models from learning spurious shortcuts captured by attention.
- Core assumption: Attention serves as the main media for feature interactions in PLMs, and biased attention becomes the direct source of many spurious features.
- Evidence anchors:
  - [abstract] "Although the attention mechanism (Vaswani et al., 2017) is essential to the success of Transformer-based pretrained language models (PLMs), attention can also capture potentially spurious shortcut features leading to prediction biases."
  - [section 2.3] "To prevent the main model from learning biased attention, READ further conducts additive ensemble of the attention distributions of both the main and biased models."
- Break condition: If attention is not the primary source of dataset biases, or if residual learning on attention doesn't translate to better predictions.

## Architecture Onboarding

- Component map: Input → Shared encoder layers → Attention ensemble (main vs biased) → Ensemble attention → Main prediction, or Input → Shared encoder layers → Biased attention → Biased prediction

- Critical path: Input → Shared encoder layers → Attention ensemble (main vs biased) → Ensemble attention → Main prediction, or Input → Shared encoder layers → Biased attention → Biased prediction

- Design tradeoffs: Weight sharing reduces parameters but propagates shared biases. Additive attention ensemble is more stable than multiplicative but may under-debias. Using all encoder layers as biased model is more effective than using only bottom layers but increases computation.

- Failure signatures: Poor OOD performance indicates residual learning isn't capturing unbiased attention. Decreased in-distribution performance indicates over-debiasing. Training instability suggests attention ensemble ratio needs adjustment.

- First 3 experiments:
  1. Run READ with α=0.1 on MNLI and evaluate HANS performance to verify basic debiasing effectiveness
  2. Compare attention distributions on overlapping vs non-overlapping tokens to verify READ's attention pattern changes
  3. Test READ with different numbers of ensemble layers (0, 2, 4, 6, 8, 10, 12) to find optimal configuration for each task

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the attention debiasing mechanism in READ affect model performance on other NLU tasks beyond the three studied (MNLI, FEVER, QQP)?
- Basis in paper: [explicit] The paper states that READ's effectiveness on these three tasks suggests generalizability, but does not test other tasks or bias types.
- Why unresolved: The experiments are limited to natural language inference, fact verification, and paraphrase identification. The paper does not explore whether READ's attention debiasing generalizes to other NLU tasks like sentiment analysis, question answering, or summarization.
- What evidence would resolve it: Testing READ on a broader range of NLU tasks with different types of biases would demonstrate its generalizability. Success across diverse tasks would confirm that attention debiasing is broadly effective for mitigating dataset biases.

### Open Question 2
- Question: What is the optimal ensemble ratio (α) for READ across different NLU tasks and bias types?
- Basis in paper: [explicit] The paper uses a fixed α=0.1 across all tasks, but notes that "an appropriate coefficient can prevent over- or under-debiasing" without exploring optimal values.
- Why unresolved: The paper uses a single fixed value for α rather than performing sensitivity analysis or task-specific optimization. Different tasks may benefit from different ensemble ratios depending on the nature and severity of their biases.
- What evidence would resolve it: Systematic experimentation varying α across tasks and bias types would identify optimal values. Performance curves showing how debiasing effectiveness changes with α would reveal whether a universal optimal value exists or if task-specific tuning is needed.

### Open Question 3
- Question: How does READ's attention debiasing mechanism interact with other debiasing techniques like counterfactual data augmentation or feature disentanglement?
- Basis in paper: [inferred] The paper demonstrates READ's effectiveness but doesn't explore whether combining it with other debiasing methods would yield complementary benefits or create conflicts.
- Why unresolved: The paper focuses solely on READ's attention-based approach without examining potential synergies or conflicts with other debiasing methodologies. Ensemble-based methods could potentially be combined with data augmentation or representation learning techniques.
- What evidence would resolve it: Experiments combining READ with other debiasing methods would reveal whether they are complementary or redundant. Analysis of their interaction would show whether attention debiasing addresses fundamentally different aspects of bias than other approaches.

## Limitations

- Attention mechanism generalization to other types of biases beyond lexical overlap and heuristic shortcuts remains unclear
- Potential trade-off between in-distribution and out-of-distribution performance needs more extensive analysis
- Ensemble ratio sensitivity across different tasks and bias types is not comprehensively explored

## Confidence

**High Confidence Claims**:
- READ effectively mitigates attention-based biases in PLMs, as evidenced by consistent OOD improvements across three different NLU tasks
- The attention residual learning mechanism produces more balanced attention distributions, particularly increasing focus on non-overlapping tokens
- The weight-sharing design achieves parameter efficiency while maintaining debiasing effectiveness

**Medium Confidence Claims**:
- READ outperforms previous ensemble-based debiasing methods that only address logits
- The method remains effective even when biased and main models share all encoder layers
- The 4.8% additional parameter overhead is acceptable for practical applications

**Low Confidence Claims**:
- READ's generalizability to other types of dataset biases beyond lexical overlap
- The optimal ensemble ratio α=0.1 works universally across different tasks and domains
- The method's effectiveness scales to larger PLMs beyond BERT-base

## Next Checks

1. **Cross-Domain Robustness Test**: Apply READ to a new NLU task with different types of dataset biases (e.g., syntactic biases, semantic role labeling biases) to validate generalizability beyond lexical overlap biases.

2. **Ensemble Ratio Sensitivity Analysis**: Systematically vary α from 0.01 to 0.5 and measure the trade-off between in-distribution performance and OOD robustness across all three tasks to establish optimal selection criteria.

3. **Layer-wise Attention Analysis**: Compare attention patterns at different encoder layers (1, 6, 12) between READ and baseline models to determine which layers contribute most to debiasing and whether attention patterns stabilize at deeper layers.
