# Extrapolating Multilingual Understanding Models as Multilingual Generators

## Quick Facts
- arXiv ID: 2305.13140
- Source URL: https://arxiv.org/abs/2305.13140
- Reference count: 29
- Primary result: SGA approach outperforms initialization-based methods with gains of 9.4 BLEU on MT, 8.1 Rouge-L on QG, and 5.5 METEOR on story generation on XLM-R_large

## Executive Summary
This paper addresses the challenge of adapting multilingual understanding models (encoders) to multilingual generators with minimal additional parameters. The proposed semantic-guided alignment-then-denoising (SGA) approach leverages the denoising capabilities of pre-trained multilingual encoders through a two-stage generation process. By using prompt tuning for parameter-efficient adaptation, SGA achieves strong performance across machine translation, question generation, and story generation tasks while maintaining impressive zero-shot cross-lingual abilities.

## Method Summary
The SGA approach adapts pre-trained multilingual understanding models to generators using prompt tuning, which introduces a small number of new parameters (key-value pairs) concatenated with existing attention layers. The method employs a two-stage generation process: first, an alignment stage generates target tokens in parallel using semantic guidance from the source text (via CTC or Mask-Predict), and second, a denoising stage iteratively refines the generated text using the encoder's MLM-based denoising capabilities. This approach addresses the multi-modality problem in non-autoregressive generation while preserving the pre-trained knowledge.

## Key Results
- Achieves 9.4 BLEU improvement on machine translation over initialization-based methods
- Shows 8.1 Rouge-L improvement on question generation tasks
- Demonstrates 5.5 METEOR improvement on story generation tasks
- Outperforms mGPT + MSP by large margins in zero-shot cross-lingual translation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The semantic-guided alignment-then-denoising approach works because multilingual encoders already possess strong denoising capabilities from MLM pre-training, which can be leveraged for text generation.
- Mechanism: The pre-trained multilingual encoder (XLM-R) is adapted using prompt tuning to create a two-stage generation process. First, an alignment stage generates target tokens in parallel using semantic guidance from the source text. Then, a denoising stage iteratively refines the generated text using the encoder's MLM-based denoising capabilities.
- Core assumption: Multilingual encoders pre-trained with MLM objectives retain strong denoising abilities that can be effectively transferred to generation tasks with minimal additional parameters.
- Evidence anchors: [abstract] "Considering that encoder-based models have the advantage of efficient generation and self-correction abilities, this paper explores methods to empower multilingual understanding models the generation abilities"; [section 1] "Thanks to the denoising pre-training objective MLM, current language models can be easily adapted to a denoiser"
- Break condition: If the pre-trained encoder lacks sufficient denoising capability from MLM pre-training, or if the semantic guidance cannot effectively constrain the generation process.

### Mechanism 2
- Claim: The two-stage generation process (alignment-then-denoising) is more effective than direct initialization-based adaptation because it addresses the modality problem in non-autoregressive generation.
- Mechanism: The alignment stage uses parallel token generation (via CTC or Mask-Predict) to create an initial draft, while the denoising stage iteratively refines this draft. This two-stage approach avoids the multi-modality problem where multiple valid translations can exist for the same source, which confuses single-step NAR methods.
- Core assumption: Parallel generation followed by iterative refinement can better handle the multi-modality problem than direct initialization or single-step NAR methods.
- Evidence anchors: [section 1] "For free generation tasks, CTC loss performs poorly because free-generation tasks intensify the multi-modality problem"; [section 4.3] "Therefore, we use Mask-Predict, which is an iterative NAR generation method that sacrifices speed for performance"
- Break condition: If the denoising stage cannot effectively resolve the multi-modality problem or if the iterative refinement becomes too computationally expensive.

### Mechanism 3
- Claim: Prompt tuning provides an efficient parameter-efficient adaptation method that preserves the pre-trained knowledge while adding generation capabilities.
- Mechanism: Instead of fine-tuning all parameters, SGA introduces prompt parameters (key-value pairs) that are concatenated with existing attention layers. This allows adaptation with only a small number of new parameters while keeping the pre-trained knowledge intact.
- Core assumption: Adding prompt parameters to attention layers can effectively adapt the model to generation tasks without losing the pre-trained understanding capabilities.
- Evidence anchors: [section 2] "In this work, we follow this research thread for efficient adaptation and apply prompt-based approaches in our work"; [section 4.2] "These parameters are then concatenated with the key-value pairs of attention in each layer to extract the hidden representation of the source sequence"
- Break condition: If the prompt parameters cannot effectively guide the generation process or if the added parameters become too large relative to the benefits gained.

## Architecture Onboarding

- Component map: Encoder -> Semantic Encoding Unit -> Alignment Unit -> Denoising Unit -> Final output
- Critical path: Source text → Semantic Encoding → Alignment (parallel generation) → Denoising (iterative refinement) → Final output
- Design tradeoffs:
  - Speed vs. Quality: CTC-based alignment is faster but lower quality; Mask-Predict is slower but higher quality
  - Parameter efficiency vs. Performance: Prompt tuning preserves pre-trained knowledge but may limit adaptation capacity
  - Single-stage vs. Two-stage: Direct generation is simpler but struggles with multi-modality; two-stage handles multi-modality better
- Failure signatures:
  - Poor generation quality: May indicate semantic guidance is insufficient or denoising stage is ineffective
  - Slow inference: May indicate too many denoising iterations or inefficient implementation
  - Catastrophic forgetting: May indicate prompt tuning parameters are interfering with pre-trained knowledge
- First 3 experiments:
  1. Ablation study: Test SGA with and without denoising stage on translation task to verify denoising contribution
  2. Cross-lingual transfer: Test zero-shot translation performance on unseen language pairs to verify semantic guidance effectiveness
  3. Parameter efficiency: Compare SGA with different numbers of prompt parameters to find optimal tradeoff between efficiency and performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can multilingual understanding models be further improved to match or surpass the performance of autoregressive models in supervised fine-tuning settings?
- Basis in paper: [explicit] The paper states that "XLM-R is still inferior to mBART in supervised settings despite better results on zero-shot settings, indicating that more exploration is required to make understanding models strong generators."
- Why unresolved: While the paper proposes an effective adaptation method (SGA) that significantly improves performance, there remains a gap between the adapted understanding models and autoregressive models in supervised settings.
- What evidence would resolve it: Further research and experiments comparing different adaptation techniques, pre-training methods, or architectural modifications to determine the most effective approach for improving understanding models' performance in supervised fine-tuning.

### Open Question 2
- Question: How does the performance of the proposed SGA approach compare to other parameter-efficient adaptation methods, such as adapter-based methods or prompting-based methods, in multilingual generation tasks?
- Basis in paper: [explicit] The paper compares SGA to initialization-based methods and mGPT + MSP, but does not provide a comprehensive comparison with other parameter-efficient adaptation methods like adapter-based or prompting-based methods.
- Why unresolved: A thorough comparison with various parameter-efficient adaptation methods would provide insights into the relative strengths and weaknesses of SGA and help identify the most effective approach for adapting understanding models to generation tasks.
- What evidence would resolve it: Conducting experiments comparing SGA to other parameter-efficient adaptation methods (e.g., adapter-based, prompting-based) in various multilingual generation tasks and evaluating their performance, efficiency, and cross-lingual transfer abilities.

### Open Question 3
- Question: What is the impact of the proposed denoising technique on the quality of generated text in different multilingual generation tasks, and how does it compare to other denoising approaches?
- Basis in paper: [explicit] The paper introduces a semantic-guided denoising technique and demonstrates its effectiveness in improving generation quality, but does not provide a detailed analysis of its impact on different tasks or a comparison with other denoising approaches.
- Why unresolved: Understanding the specific benefits and limitations of the proposed denoising technique in various generation tasks would help refine the approach and potentially inspire new denoising strategies.
- What evidence would resolve it: Conducting experiments to evaluate the impact of the proposed denoising technique on different multilingual generation tasks (e.g., machine translation, question generation, story generation) and comparing its performance to other denoising approaches (e.g., iterative refinement, energy-based methods) in terms of quality, efficiency, and cross-lingual transfer.

## Limitations

- The evaluation focuses on specific language pairs and datasets, which may not generalize to all multilingual generation scenarios.
- The semantic guidance mechanism lacks detailed ablation studies showing its specific contribution versus the denoising stage.
- The parameter efficiency claims are based on comparisons with full fine-tuning approaches, not exploring the full spectrum of parameter-efficient methods.

## Confidence

**High Confidence**: The core experimental results showing SGA outperforming initialization-based methods on the tested datasets and metrics.

**Medium Confidence**: The mechanism explanations for why semantic-guided alignment-then-denoising works better than alternatives.

**Low Confidence**: The generalizability of the approach to completely unseen language families or domains not represented in the training data.
