# Online Spatio-Temporal Learning with Target Projection

## Quick Facts
- arXiv ID: 2304.05124
- Source URL: https://arxiv.org/abs/2304.05124
- Authors: 
- Reference count: 24
- Key outcome: OSTTP achieves competitive performance to BPTT on temporal tasks while enabling fully online training without weight symmetry or update-locking constraints

## Executive Summary
This paper introduces Online Spatio-Temporal Learning with Target Projection (OSTTP), a biologically-inspired training algorithm for recurrent neural networks that resolves key limitations of backpropagation through time (BPTT). OSTTP combines eligibility traces from online spatio-temporal learning with target projection signals, enabling fully online training using only locally available information. The algorithm achieves competitive performance on temporal tasks including music prediction and spoken digit classification while demonstrating applicability to memristive neuromorphic hardware.

## Method Summary
OSTTP implements a training algorithm that combines eligibility traces for temporal credit assignment with target projection using fixed random matrices for spatial learning signals. The method processes each time step sequentially, updating weights immediately without waiting for backward passes through time or across layers. The algorithm uses spiking neural units with different reset mechanisms depending on the task, and employs stochastic gradient descent or ADAM optimization depending on the specific benchmark.

## Key Results
- OSTTP achieves 77±0.8% accuracy on the Spiking Heidelberg Digits spoken digit classification task
- The algorithm demonstrates competitive performance to BPTT on music prediction using the JSB dataset
- Proof-of-concept implementation on memristive neuromorphic hardware validates the approach for resource-constrained AI devices

## Why This Works (Mechanism)

### Mechanism 1
- Claim: OSTTP resolves update-locking problems by computing layer-wise learning signals independently using projected target vectors
- Mechanism: The algorithm uses fixed random matrices to project target information directly to each layer, allowing weight updates without waiting for preceding layers to complete
- Core assumption: The random projection preserves sufficient information for effective learning despite not using true backward gradients
- Evidence anchors: Abstract states OSTTP alleviates weight symmetry and update-locking problems; section describes DECOLLE's local loss functions reducing performance compared to BPTT
- Break condition: If random projection matrices fail to capture essential gradient information, learning performance would degrade significantly

### Mechanism 2
- Claim: OSTTP combines eligibility traces with target projection to maintain temporal credit assignment while enabling online updates
- Mechanism: Eligibility traces capture temporal dependencies within each layer through recursive computation, while target projection provides spatial learning signals
- Core assumption: The combination of temporal eligibility traces and spatial target projections can approximate the full gradient information needed for effective learning
- Evidence anchors: Section states OSTTP combines eligibility traces of OSTL with target projection signals from DRTP; corpus mentions synthetic gradients and local learning rules
- Break condition: If temporal dependencies are too long-range or complex, eligibility traces may fail to capture sufficient information

### Mechanism 3
- Claim: OSTTP eliminates weight symmetry requirements through random feedback alignment
- Mechanism: By using fixed random matrices instead of transpose weight matrices for backward passes, OSTTP avoids the need for symmetric weights between forward and backward computations
- Core assumption: Random feedback alignment can provide sufficient gradient information despite not using true transpose weights
- Evidence anchors: Section describes how DRTP resolves update-locking by propagating target vector directly to individual layers using fixed random matrix; corpus mentions BP(λ) using synthetic gradients
- Break condition: If random feedback matrices introduce too much noise or fail to provide directional guidance, learning convergence may be severely impaired

## Architecture Onboarding

- Component map: Input -> Network Layers (with eligibility traces) -> Target Projection (random matrices) -> Parameter Updates
- Critical path: Forward pass through network layers → Eligibility trace updates for each layer → Target signal computation using random projection → Parameter updates, all operating in real-time
- Design tradeoffs: OSTTP trades exact gradient computation for online capability and hardware efficiency, introducing approximation error but enabling massive parallelization and eliminating weight symmetry constraints
- Failure signatures: Poor convergence due to inadequate random projection quality, vanishing eligibility traces for long temporal dependencies, numerical instability in eligibility trace accumulation, and suboptimal learning rates due to approximation error
- First 3 experiments:
  1. Implement OSTTP on a simple recurrent network for character-level language modeling, comparing convergence speed and final performance against BPTT
  2. Test OSTTP on a temporal XOR problem to evaluate temporal credit assignment capabilities with varying sequence lengths
  3. Implement OSTTP on a neuromorphic hardware simulator to verify elimination of weight symmetry requirements and parallel learning signal computation

## Limitations
- Lack of comprehensive ablation studies examining individual contributions of eligibility traces versus target projection mechanisms
- Incomplete mathematical proof that random projections preserve sufficient gradient information for effective learning
- Limited testing on tasks with longer temporal dependencies beyond the 100-timestep sequences used in experiments

## Confidence
- Update-locking resolution mechanism: Medium confidence - empirical evidence shows online capability but theoretical guarantees incomplete
- Gradient equivalence to BPTT: Low confidence - mathematical proof incomplete and sensitivity to hyperparameters unexplored
- Weight symmetry elimination: High confidence - well-established random feedback alignment technique with strong theoretical foundation
