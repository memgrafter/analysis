# ContraCluster: Learning to Classify without Labels by Contrastive Self-Supervision and Prototype-Based Semi-Supervision

## Quick Facts
- arXiv ID: 2304.09369
- Source URL: https://arxiv.org/abs/2304.09369
- Reference count: 40
- Achieves 90.8% accuracy on CIFAR-10 unsupervised

## Executive Summary
ContraCluster introduces a novel unsupervised image classification method that combines contrastive self-supervised learning with clustering. The method achieves state-of-the-art results on CIFAR-10, STL-10, and ImageNet-10 datasets by leveraging a three-stage pipeline that learns discriminative representations without using any labels. The approach combines SimCLR-based contrastive pre-training, UMAP-based prototype sampling, and FixMatch-based semi-supervised fine-tuning to achieve accuracy comparable to fully supervised learning.

## Method Summary
ContraCluster is a three-stage unsupervised image classification method. First, it performs contrastive self-supervised pre-training (CPT) using SimCLR to learn general representations from unlabeled data. Second, it applies contrastive prototype sampling (CPS) using UMAP dimensionality reduction and k-means clustering to select highly accurate prototypes. Third, it performs prototype-based semi-supervised fine-tuning (PB-SFT) using FixMatch consistency regularization with the selected prototypes as noisy labeled data. This approach leverages both small prototype sets and large amounts of unlabeled data to enhance classification accuracy without requiring any manual annotations.

## Key Results
- Achieves 90.8% accuracy on CIFAR-10, significantly outperforming previous methods like DAC (52.2%), IIC (61.7%), and SCAN (87.6%)
- Reaches accuracy comparable to supervised learning with full labels (95.8%) without using any labels
- Demonstrates effectiveness across CIFAR-10, STL-10, and ImageNet-10 datasets
- Shows superior performance through combining contrastive learning with prototype-based semi-supervision

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Contrastive self-supervised pre-training (CPT) produces linearly separable embeddings that preserve semantic structure.
- Mechanism: SimCLR maximizes similarity between differently augmented views of the same image while minimizing similarity across images, forcing the encoder to learn discriminative features.
- Core assumption: InfoMax principle ensures representations retain mutual information between views while discarding irrelevant variations.
- Evidence anchors: [abstract] "learns general representations from unlabeled data by using contrastive loss, which is based on the InfoMax principle"; [section] "SimCLR learns representations by simultaneously encouraging two objectives: (1) maximizing the similarity between different views ... and (2) minimizing the similarity between different views ... from different samples"
- Break condition: If augmentation pipeline fails to create sufficiently distinct views, the contrastive loss cannot enforce meaningful separation, leading to collapsed embeddings.

### Mechanism 2
- Claim: Non-linear dimensionality reduction (UMAP) enables accurate clustering by mitigating the curse of dimensionality.
- Mechanism: UMAP projects high-dimensional embeddings into a low-dimensional space where k-means clustering can effectively find cluster centroids that represent prototypical samples.
- Core assumption: Cluster centroids in the low-dimensional space approximate the most discriminative samples in the original embedding space.
- Evidence anchors: [section] "we conjecture that this is mainly due to the fact that classic clustering algorithms such as k-means suffer from the low accuracy problem because of the curse of dimensionality"; [section] "We have empirically found out that non-linear dimensionality reduction is essential to increase the accuracy"
- Break condition: If the embedding space is already intrinsically low-dimensional or linearly separable, UMAP adds unnecessary computation without accuracy gains.

### Mechanism 3
- Claim: Prototype-based semi-supervised fine-tuning (PB-SFT) leverages both highly accurate prototypes and unlabeled data to improve classification accuracy without overfitting.
- Mechanism: FixMatch consistency regularization encourages the model to predict consistently between weakly and strongly augmented versions of unlabeled data, while prototype cross-entropy loss provides high-quality supervision.
- Core assumption: The selected prototypes are sufficiently accurate (≈95%) to serve as reliable noisy labels for semi-supervised learning.
- Evidence anchors: [abstract] "We use sampled prototypes as noisy labeled data to perform semi-supervised fine-tuning (PB-SFT), leveraging small prototypes and large unlabeled data to further enhance the accuracy"; [section] "PB-SFT can further increase the accuracy by leveraging both small noisy labeled data (i.e., prototypes) and large unlabeled data"
- Break condition: If prototype accuracy drops below ~90%, the noisy labels become too unreliable, causing PB-SFT to degrade rather than improve performance.

  - Why needed here: CPS relies on UMAP and k-means to select prototypes, so understanding their strengths, limitations, and hyperparameters is essential

  - Why needed here: PB-SFT uses FixMatch's consistency regularization, so understanding how weak vs. strong augmentations and confidence thresholds interact is critical
  - Quick check question: What is the effect of increasing the confidence threshold c on the amount of unlabeled data used during training?

## Architecture Onboarding

- Component map: Data augmentation → Encoder (ResNet-50) → Projection head (2-layer MLP) → Contrastive loss (SimCLR) → Dimensionality reduction (UMAP) → Clustering (k-means) → Prototype selection → Classification head (2-layer MLP) → FixMatch consistency loss

- Critical path: CPT → CPS → PB-SFT. Each stage depends on the previous one, with CPT providing the embedding space, CPS selecting prototypes, and PB-SFT fine-tuning using both prototypes and unlabeled data.

- Design tradeoffs: Using UMAP adds computational overhead but enables accurate prototype selection; choosing more prototypes increases PB-SFT accuracy but requires more labeled data; higher confidence thresholds reduce unlabeled data usage but may miss valuable training signals.

- Failure signatures: Low prototype accuracy (<90%) indicates CPS failure; poor clustering in UMAP space suggests CPT didn't learn linearly separable features; no accuracy improvement after PB-SFT suggests prototypes are too noisy or FixMatch hyperparameters are suboptimal.

- First 3 experiments:
  1. Run CPT alone and visualize the embedding space with t-SNE/UMAP to verify linear separability before clustering
  2. Test CPS with varying numbers of prototypes and UMAP hyperparameters to find optimal prototype accuracy
  3. Evaluate PB-SFT with different confidence thresholds and unlabeled batch ratios to maximize accuracy improvement

## Limitations
- Performance on more complex, real-world datasets with higher intra-class variability remains untested
- Lack of ablation studies showing individual contribution of each component (UMAP, prototype sampling, FixMatch) to final accuracy
- Method still requires labeled prototypes during PB-SFT stage, even though these are automatically selected

## Confidence
- High confidence: ContraCluster's overall pipeline architecture and three-stage approach (CPT → CPS → PB-SFT) are sound and well-motivated
- Medium confidence: Specific hyperparameter choices (UMAP parameters, FixMatch confidence threshold, prototype sampling size) are optimal for tested datasets
- Low confidence: Claim that ContraCluster achieves "accuracy comparable to supervised learning without using any labels" may be overstated
