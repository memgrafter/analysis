# Efficient Latency-Aware CNN Depth Compression via Two-Stage Dynamic Programming

## Quick Facts
- arXiv ID: 2301.12187
- Source URL: https://arxiv.org/abs/2301.12187
- Reference count: 14
- Key result: Achieves 1.61× speed-up with 0.62%p accuracy drop in MobileNetV2-1.4 on ImageNet

## Executive Summary
This paper introduces a novel depth compression algorithm for convolutional neural networks that reduces inference latency by strategically removing inefficient activation layers and merging consecutive convolution operations. The approach formulates the problem as a subset selection task and solves it using a two-stage dynamic programming algorithm that can find optimal solutions within seconds. The method demonstrates superior performance compared to baseline approaches, achieving significant speed-ups with minimal accuracy loss on MobileNetV2 for ImageNet classification.

## Method Summary
The method uses two-stage dynamic programming to solve an NP-hard subset selection problem for CNN depth compression. In the first stage, it computes optimal merge patterns for all contiguous network blocks. In the second stage, it determines which activation layers to remove and the final merge pattern under a latency constraint. The approach replaces selected activation layers with identity functions and merges consecutive convolutions into equivalent shallower operations. The algorithm approximates importance values through short training runs and measures actual latency using TensorRT compilation for fair hardware-specific optimization.

## Key Results
- Achieves 1.61× speed-up with only 0.62% accuracy drop on MobileNetV2-1.4 ImageNet
- Outperforms baseline methods in both accuracy and inference speed
- Solves the NP-hard optimization problem within seconds using two-stage dynamic programming
- Validated on MobileNetV2 architecture with latency measured via TensorRT

- Core assumption: The merged network retains functional equivalence to the original, and latency reduction outweighs any minor accuracy loss.

## Limitations

- Surrogate Objective Accuracy: The paper relies on a surrogate objective that sums accuracy changes from individual blocks, with uncertainty about how well this approximation captures the true accuracy landscape when multiple blocks are modified simultaneously.

- Hardware-Specific Optimizations: Latency measurements using TensorRT may not generalize across different deployment environments, as the reported speed-ups are specific to TensorRT's optimization capabilities.

- Measurement Overhead: The algorithm requires measuring latency and importance for all contiguous blocks, which could introduce significant pre-processing overhead for large networks, though this cost is not discussed.

## Confidence

- High Confidence: The two-stage dynamic programming formulation is mathematically sound and the basic approach of depth compression through activation removal and convolution merging is valid.

- Medium Confidence: The specific implementation details for handling MobileNetV2's skip connections and the exact normalization procedure for importance values, as these are only briefly mentioned.

- Low Confidence: The generalizability of results across different network architectures beyond MobileNetV2 and the real-world deployment scenarios where TensorRT may not be available.
