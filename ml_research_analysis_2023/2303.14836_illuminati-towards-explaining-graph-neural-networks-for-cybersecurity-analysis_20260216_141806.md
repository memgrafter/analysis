# Illuminati: Towards Explaining Graph Neural Networks for Cybersecurity Analysis

## Quick Facts
- arXiv ID: 2303.14836
- Source URL: https://arxiv.org/abs/2303.14836
- Reference count: 40
- Achieves 87.6% Essentialness Percentage (EP) on vulnerability detection datasets

## Executive Summary
Illuminati is a novel method for explaining Graph Neural Network (GNN) predictions in cybersecurity applications, specifically addressing the challenge of interpreting positive alarms in vulnerability detection. The method learns importance scores for nodes, edges, and attributes jointly using edge masks and attribute masks, then aggregates these to compute node importance scores. Unlike previous approaches, Illuminati requires no prior knowledge of GNN models and provides comprehensive explanations by considering all graph factors simultaneously. Experiments on code vulnerability detection and smart contract vulnerability detection datasets demonstrate significant improvements over baseline methods, with Illuminati achieving 87.6% EP of explained subgraphs retaining original predictions.

## Method Summary
Illuminati learns importance scores for edges and node attributes collectively from the input graph and a pre-trained GNN. The method uses reparameterization with a hard concrete distribution to learn binary-like edge indicators while maintaining gradient flow for mask learning. Node importance scores are aggregated from outgoing and incoming message contributions, weighted by edge and attribute importance. The approach maximizes mutual information between the subgraph and the prediction, ensuring that the most relevant structure and features are retained. The final output is an explained subgraph with importance scores that highlights the critical factors contributing to the GNN's prediction.

## Key Results
- Achieves 87.6% Essentialness Percentage (EP) of explained subgraphs retaining original predictions
- Demonstrates 10.3% improvement over baseline methods on vulnerability detection tasks
- Shows 7.1% higher EP than GNNExplainer on node classification tasks
- Successfully identifies vulnerability factors through case studies on real-world datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The method jointly learns edge masks and attribute masks to capture the relative importance of different graph components for prediction.
- Mechanism: Edge masks determine the message-passing strength between nodes, while attribute masks modulate the contribution of each node's features. These masks are optimized to maximize mutual information between the subgraph and the prediction, ensuring that the most relevant structure and features are retained.
- Core assumption: The importance of a node for prediction can be inferred from the importance of its connected edges and its own attributes.
- Evidence anchors:
  - [abstract] "The core method learns importance scores for nodes, edges, and attributes jointly using edge masks and attribute masks"
  - [section] "ILLUMINATI learns the importance scores for edges and node attributes collectively from the input graph and the pre-trained GNN"
- Break condition: If the underlying GNN model does not rely on edge-based message passing or attribute features, the learned masks will not correlate with prediction importance.

### Mechanism 2
- Claim: Node importance scores are aggregated from outgoing and incoming message contributions, weighted by edge and attribute importance.
- Mechanism: For each node, the importance of its outgoing edges and attributes is aggregated to form an outgoing message importance, and the importance of its incoming edges is similarly aggregated. These two values are combined (e.g., via max pooling) to yield the final node importance score.
- Core assumption: The predictive power of a node depends on both the information it sends out and the information it receives from its neighbors.
- Evidence anchors:
  - [section] "the contribution from a node vi is quantified by: ωvi = ∏(i,j)∈E + i P ((i,j ))1/|E + i| ∏t∈xi P (t)1/|xi|"
  - [section] "We quantify the message importance through edge (i,j ) as: ω(i,j) =P ((i,j ))ωxi"
- Break condition: If the GNN architecture uses a different aggregation scheme (e.g., sum instead of mean), the importance calculation must be adapted.

### Mechanism 3
- Claim: Reparameterization with a hard concrete distribution allows binary-like edge selection while maintaining gradient flow for mask learning.
- Mechanism: Continuous mask values are passed through a sigmoid, then through a stretched concrete distribution to produce binary-like edge indicators (0 or 1). The continuous values are retained for gradient-based optimization.
- Core assumption: Binary edge indicators better reflect real-world subgraph explanations, but differentiability is required for learning.
- Evidence anchors:
  - [section] "Our solution is to reparameterize importance scores into binary as weights on the input graph, while the differentiable importance scores are still retained for importance estimation"
  - [section] "We rewrite the distribution for edges as: s =σ((logu− log(1−u) +m(E))/β)"
- Break condition: If the temperature β is set too high or low, the binary sampling becomes unstable or gradients vanish.

## Architecture Onboarding

- Component map:
  - Input: Attributed graph, pre-trained GNN model
  - Edge mask learner -> Attribute mask learner -> Node importance aggregator -> Subgraph extractor -> Output

- Critical path:
  1. Initialize edge and attribute masks
  2. Compute weighted graph using masks
  3. Pass weighted graph through pre-trained GNN
  4. Compute objective (mutual information) and backpropagate gradients to masks
  5. Aggregate learned masks into node importance scores
  6. Extract subgraph based on node importance scores

- Design tradeoffs:
  - Joint vs. separate learning of edge and attribute masks: Joint learning allows the model to capture interactions but increases complexity.
  - Binary vs. continuous importance scores: Binary scores are more interpretable but harder to optimize; continuous scores allow gradient-based learning but are less intuitive.

- Failure signatures:
  - Low EP (Essentialness Percentage): The explained subgraph does not retain the original prediction, indicating the learned masks are not capturing the truly important factors.
  - High EP but low sparsity: The explained subgraph is large but still retains the prediction, suggesting the method is not identifying the minimal set of important factors.

- First 3 experiments:
  1. Run ILLUMINATI on a small synthetic graph dataset with known important factors to verify that the method correctly identifies them.
  2. Compare the EP of ILLUMINATI with GNNExplainer and PGExplainer on a real-world graph classification dataset.
  3. Test the robustness of ILLUMINATI to edge perturbations by adding/removing edges and observing the stability of the explained subgraphs.

## Limitations

- Evaluation primarily focused on vulnerability detection tasks, limiting generalizability to other cybersecurity applications
- Mutual information maximization assumes correlation between predictive power and true important factors without empirical validation
- Comparison limited to only two baseline methods (GNNExplainer and PGExplainer)

## Confidence

- **Medium**: Methodology is well-grounded but empirical validation is somewhat narrow
- Claims about performance improvements are supported by experiments on specific datasets
- Theoretical foundation using established techniques (mutual information, reparameterization trick) provides credibility
