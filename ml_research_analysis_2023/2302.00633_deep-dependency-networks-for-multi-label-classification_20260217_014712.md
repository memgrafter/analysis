# Deep Dependency Networks for Multi-Label Classification

## Quick Facts
- arXiv ID: 2302.00633
- Source URL: https://arxiv.org/abs/2302.00633
- Reference count: 40
- One-line primary result: DDNs outperform baseline neural networks and MRF-based methods across all evaluation metrics on six datasets

## Executive Summary
This paper introduces Deep Dependency Networks (DDNs) for multi-label classification, addressing the challenge of capturing label dependencies in image and video data. DDNs combine neural networks with dependency networks, enabling joint learning of feature extraction and label relationships. Experiments on six datasets (three video, three image) demonstrate that jointly trained DDNs outperform baseline neural networks and Markov random field (MRF)-based methods across all evaluation metrics (mAP, LRAP, SA, JI). The results highlight the effectiveness of DDNs in improving multi-label classification accuracy while leveraging the strengths of both neural networks and probabilistic graphical models.

## Method Summary
Deep Dependency Networks (DDNs) combine a neural network feature extractor with a dependency network that models conditional label distributions. The neural network (e.g., SlowFast, InceptionV3, Q2L, MSRN) extracts features from input images or video segments. These features, along with other labels, are used by the dependency network (logistic regression or MLP classifiers) to compute local conditional distributions over each label. Gibbs sampling is then performed over the dependency network to generate samples and estimate posterior probabilities. DDNs can be trained using either pipeline learning (training neural network and dependency network separately) or joint learning (end-to-end training using conditional pseudo log-likelihood loss).

## Key Results
- DDNs outperform baseline neural networks and MRF+NN hybrid models across all metrics (mAP, LRAP, SA, JI) on six datasets
- Jointly trained DDNs show significant improvements over pipeline-trained DDNs, particularly on non-probabilistic metrics (JI, SA)
- Logistic regression and MLP dependency networks both work well, with MLPs providing slightly better performance but requiring more computation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: DDNs outperform pure neural networks by capturing label dependencies through Gibbs sampling over a dependency network
- Mechanism: The neural network extracts high-quality features, which are used by the dependency network to model conditional distributions of each label given other labels and features. Gibbs sampling then leverages these dependencies to produce better label predictions than independent neural network predictions
- Core assumption: The joint distribution over labels given features is better represented as a set of conditional distributions than as a single independent prediction per label
- Evidence anchors:
  - [abstract]: "DDNs combine neural networks with dependency networks, enabling joint learning of feature extraction and label relationships."
  - [section]: "The feature extractor converts the input image or video segment to a set of features, and the dependency network uses these features to define a local conditional distribution over each label given the features and other labels."
  - [corpus]: No strong evidence in corpus neighbors about Gibbs sampling specifically, but general support for dependency network benefits in multi-label tasks
- Break condition: If the dependency network learns inaccurate conditional distributions or if Gibbs sampling fails to converge, performance could degrade below the baseline neural network

### Mechanism 2
- Claim: Joint training of the neural network and dependency network yields better performance than pipeline training because feature extraction is tailored to the dependency network's needs
- Mechanism: During joint training, the neural network's feature extractor is optimized not just for label prediction but also for providing features that improve the dependency network's conditional distributions. This end-to-end learning allows the two components to adapt to each other
- Core assumption: Features that are optimal for independent neural network predictions are not necessarily optimal for a dependency network that reasons about label relationships
- Evidence anchors:
  - [abstract]: "We show that despite its simplicity, jointly learning this new architecture yields significant improvements in performance over the baseline neural network."
  - [section]: "This is because end-to-end (or joint) learning steers the feature selection process to provide tailored features for the DN, and learns a DN that is in-turn tailored to the output of this backbone."
  - [corpus]: No direct corpus evidence, but general understanding that joint training can optimize for task-specific feature representations
- Break condition: If the additional complexity of joint training leads to overfitting or if the dependency network's conditional distributions are too noisy to improve the joint optimization

### Mechanism 3
- Claim: The pseudo log-likelihood loss function used for joint training provides a good surrogate for the true likelihood, enabling effective backpropagation through the dependency network
- Mechanism: The conditional pseudo log-likelihood loss is computed by summing the log probabilities of each label given the other labels and features. This loss is differentiable and can be used with backpropagation to train both the neural network and dependency network simultaneously
- Core assumption: The pseudo log-likelihood is a reasonable approximation of the true likelihood for training the dependency network, and the gradients derived from it are meaningful for updating the neural network parameters
- Evidence anchors:
  - [section]: "For joint learning, we propose to use the conditional pseudo log-likelihood loss (CPLL) Besag [1975]."
  - [section]: "Then, we can use any gradient-based (backpropagation) method to minimize the loss function."
  - [corpus]: No specific corpus evidence, but the pseudo log-likelihood is a well-established method in graphical models literature
- Break condition: If the pseudo log-likelihood diverges significantly from the true likelihood, or if the gradients become too noisy due to the dependency network's conditional distributions, training could fail to converge

## Architecture Onboarding

- Component map:
  Input -> Neural Network (Feature Extractor) -> Dependency Network (Conditional Distributions) -> Gibbs Sampling -> Output (Predicted Labels)

- Critical path:
  1. Input data passes through the neural network to extract features
  2. Features are used by the dependency network's classifiers to compute conditional probabilities
  3. Gibbs sampling is performed over the dependency network to generate samples
  4. Posterior probabilities are estimated from the samples
  5. Final label predictions are made based on the posterior probabilities

- Design tradeoffs:
  - Joint vs. Pipeline Training: Joint training can yield better performance but is more computationally expensive. Pipeline training is faster but may not optimize features for the dependency network
  - Logistic Regression vs. MLP for Dependency Network: Logistic regression is simpler and faster to train but may have limited representational capacity. MLPs can model more complex relationships but require more data and computation
  - Number of Gibbs Sampling Iterations: More iterations can lead to better convergence but increase inference time. Fewer iterations are faster but may yield less accurate predictions

- Failure signatures:
  - Poor performance on non-probabilistic metrics (JI, SA) despite good mAP/LRAP scores: This could indicate that the dependency network is learning good posterior probabilities but the neural network's feature extraction is not capturing the right information for exact label matching
  - Joint training failing to converge or overfitting: This could happen if the dependency network's conditional distributions are too complex or if the neural network's feature extractor is being optimized for a surrogate loss that doesn't align with the true task objective
  - Gibbs sampling taking too long or not converging: This could be due to a dense dependency network or poor initialization of the conditional distributions

- First 3 experiments:
  1. Train a baseline neural network (e.g., SlowFast for Charades) and evaluate its performance on all metrics
  2. Train a DDN using the pipeline method with logistic regression for the dependency network and compare its performance to the baseline
  3. Train a DDN using joint training with MLP for the dependency network and compare its performance to both the baseline and the pipeline DDN

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of Deep Dependency Networks (DDNs) compare to other state-of-the-art methods for multi-label image classification (MLIC) tasks, such as those using transformers, attention modules, and graph attention networks (GAT)?
- Basis in paper: [explicit] The paper states that DDNs outperform methods using transformers, attention modules, and GAT on the MS-COCO and PASCAL VOC datasets
- Why unresolved: While the paper demonstrates that DDNs outperform these methods, it does not provide a comprehensive comparison of DDNs against all existing state-of-the-art methods for MLIC
- What evidence would resolve it: A thorough evaluation of DDNs against a wide range of state-of-the-art methods for MLIC on multiple datasets would provide a clearer picture of DDNs' performance relative to other approaches

### Open Question 2
- Question: How does the joint learning approach for DDNs compare to the pipeline approach in terms of training time and computational resources required?
- Basis in paper: [explicit] The paper mentions that the joint learning approach for DDNs is more computationally expensive than the pipeline approach, but it does not provide specific details on training time or resource requirements
- Why unresolved: The paper does not provide quantitative data on the training time and computational resources needed for the joint learning approach compared to the pipeline approach
- What evidence would resolve it: Conducting experiments to measure the training time and resource requirements for both the joint learning and pipeline approaches for DDNs would provide insights into their relative efficiency

### Open Question 3
- Question: Can DDNs be effectively applied to multi-label classification tasks in domains other than computer vision, such as natural language understanding or speech recognition?
- Basis in paper: [inferred] The paper suggests that DDNs can be applied to various multi-label classification tasks as long as a feature extractor can extract features from the data, but it does not provide evidence of DDNs' performance in non-vision domains
- Why unresolved: The paper only evaluates DDNs on multi-label classification tasks in computer vision, leaving the effectiveness of DDNs in other domains unexplored
- What evidence would resolve it: Applying DDNs to multi-label classification tasks in domains such as natural language understanding or speech recognition and evaluating their performance would demonstrate the versatility and effectiveness of DDNs in different contexts

## Limitations
- The computational overhead of joint training compared to pipeline methods wasn't thoroughly analyzed
- The choice of Gibbs sampling parameters (number of iterations, burn-in period) could significantly impact performance but wasn't systematically explored
- The comparison against modern transformer-based approaches is limited, as the paper primarily focuses on CNN-based architectures

## Confidence
- High confidence in the core claims about DDNs improving multi-label classification through joint learning of features and label dependencies
- Medium confidence in the mechanism explaining why pseudo log-likelihood serves as an effective surrogate loss for training
- Low confidence in the scalability of DDNs to very large datasets due to the computational complexity of joint training
