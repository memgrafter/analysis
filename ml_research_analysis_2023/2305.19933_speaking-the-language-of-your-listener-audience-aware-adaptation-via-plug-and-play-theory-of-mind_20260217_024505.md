# Speaking the Language of Your Listener: Audience-Aware Adaptation via Plug-and-Play Theory of Mind

## Quick Facts
- arXiv ID: 2305.19933
- Source URL: https://arxiv.org/abs/2305.19933
- Reference count: 18
- The paper proposes a plug-and-play adaptation mechanism that enables a speaker to adapt referring expressions to a listener's domain knowledge, achieving 71.77% accuracy in in-domain resolution and 26.74% in out-of-domain resolution.

## Executive Summary
This paper introduces a novel approach to audience-aware language generation in visually grounded referential games. The method uses a simulator module to predict how a listener with limited knowledge would resolve planned utterances, then iteratively updates the speaker's hidden state to steer language generation toward the listener's domain. Unlike traditional fine-tuning approaches, this plug-and-play mechanism adapts utterances on-the-fly without modifying the underlying language model. The results demonstrate that the speaker's utterances become more aligned with the listener's domain expertise, leading to improved communicative success while maintaining the speaker's original knowledge base.

## Method Summary
The approach models a referential game between a knowledgeable speaker and a listener with domain-specific knowledge. The speaker is a visually conditioned language model that generates referring expressions. A simulator module predicts how the listener would resolve these expressions, and this prediction guides an adaptation loop that updates the speaker's hidden state without fine-tuning the model. The adaptation process replaces information about the target image's domain with information about the listener's domain, as measured by probing analysis. The method is evaluated on the PhotoBook dataset across five visual domains, measuring resolution accuracy and analyzing vocabulary diversity and lexical alignment with the listener's domain.

## Key Results
- The speaker achieves 71.77% resolution accuracy in in-domain settings and 26.74% in out-of-domain settings after adaptation
- Type-utterance ratio and type-token ratio increase substantially with adaptation, indicating greater vocabulary diversity
- The rate of lexical choices from the listener's domain increases with adaptation while the rate from the target image domain remains stable

- Mechanism: The simulator takes as input both the planned utterance and the initial hidden state of the decoder. It predicts the listener's selection, and if incorrect, the cross-entropy loss between this prediction and the true target is backpropagated to update only the hidden state. This updated hidden state is then used to generate a new utterance.

## Architecture Onboarding

- Component map: Speaker (visually conditioned LSTM) -> Simulator (listener behavior predictor) -> Listener (discriminative image selector) -> Adaptation update -> New utterance generation
- Critical path: Speaker generates utterance → Simulator predicts listener response → Cross-entropy loss computed → Hidden state updated → New utterance generated
- Design tradeoffs: The plug-and-play approach avoids catastrophic forgetting but may lead to less stable adaptation. Using a simulator adds complexity but allows for more flexible adaptation.
- Failure signatures: If the simulator's predictions are inaccurate, the adaptation loop may fail to converge. If the adaptation process overfits to the listener's domain, the speaker may lose the ability to generate discriminative utterances.
- First 3 experiments:
  1. Test the simulator's ability to predict listener behavior on held-out data.
  2. Test the adaptation mechanism's ability to increase communicative success in a controlled setting (e.g., with a listener that has a known vocabulary gap).
  3. Analyze the effect of adaptation on the speaker's hidden state representations using probing techniques.

## Limitations

- The simulator's accuracy is relatively low (maximum 37.1% on in-domain data), which may limit adaptation quality in more complex scenarios.
- The controlled experimental setup with simulated listeners may not fully capture the complexity of real human communication, particularly regarding pragmatic inference and contextual understanding.
- The domain adaptation effect, while present, is moderate - in-domain resolution accuracy reaches only 71.77% even after adaptation.

## Confidence

**High Confidence:** The core mechanism of using a simulator to guide on-the-fly adaptation without fine-tuning the language model is well-supported by experimental results. The evidence for increased vocabulary diversity and lexical alignment with the listener's domain is robust across multiple metrics.

**Medium Confidence:** The claim that the adaptation process specifically replaces image domain information with listener domain information in the hidden state is supported by probing analysis but could benefit from additional validation. The connection between increased vocabulary diversity and communicative success, while plausible, is correlational rather than proven causal.

**Low Confidence:** The generalizability of the adaptation approach to more complex communication scenarios beyond the controlled referential game setting. The effectiveness of the simulator-based approach compared to other potential adaptation methods is not thoroughly explored.
