# APAM: Adaptive Pre-training and Adaptive Meta Learning in Language Model for Noisy Labels and Long-tailed Learning

## Quick Facts
- arXiv ID: 2302.03488
- Source URL: https://arxiv.org/abs/2302.03488
- Reference count: 22
- This paper proposes a framework for learning with noisy labels and long-tailed data in NLP, improving accuracy by 2.05% on a long-tailed and noisy Amazon annotation dataset.

## Executive Summary
This paper addresses the challenge of training language models on noisy and long-tailed data in NLP. The proposed APAM framework combines domain-adaptive pre-training through contrastive learning with an adaptive meta-learning approach for sample reweighting. The method leverages a small amount of clean data to guide the reweighting process, helping the model focus on reliable samples while handling class imbalance. Experiments on real-world datasets demonstrate that APAM outperforms baseline methods, achieving significant improvements in accuracy, precision, recall, and F1-score across multiple metrics.

## Method Summary
APAM is a two-stage framework for learning with noisy labels and long-tailed distributions. First, it performs domain-adaptive pre-training using contrastive learning (SimCSE) to learn domain-specific representations from unlabeled data. Second, it applies adaptive meta-learning to reweight instances during fine-tuning, using a small clean dataset to guide the reweighting process. The framework combines a polynomial expansion of cross-entropy loss with focal loss to create an adaptive loss function that emphasizes difficult samples while suppressing noisy ones. The meta-weight network automatically learns instance weights based on the clean data, helping the model handle both label noise and class imbalance during training.

## Key Results
- APAM outperforms baseline methods (BERT, MWN) on Amazon annotation dataset, improving accuracy by 2.05%
- The framework demonstrates robustness across different noise levels and imbalance factors
- Consistent performance improvements are observed on both Amazon Review and Amazon Annotation datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Meta-learning reweights samples using clean data to guide training on noisy long-tailed data
- Mechanism: Small clean dataset is used to update a meta-model that produces sample weights for the noisy dataset
- Core assumption: The optimal weights for clean data also improve performance on noisy data
- Evidence anchors:
  - [abstract]: "The method leverages a small amount of clean data to guide the re-weighting process"
  - [section]: "Inspired by some existing works... we use a MLP network... to automatically learn instance weights"
  - [corpus]: Found 5 related papers on meta-learning with noisy labels, supporting this mechanism exists in literature
- Break condition: Clean data is too small or unrepresentative, causing meta-model to learn incorrect weighting patterns

### Mechanism 2
- Claim: Contrastive pre-training improves robustness to long-tailed data distribution
- Mechanism: SimCSE contrastive learning pulls semantically similar sentences together and pushes apart different sentences
- Core assumption: Domain-specific representations learned through contrastive learning generalize better to long-tailed classes
- Evidence anchors:
  - [abstract]: "The model is adapted to the domain of problems in a contrastive learning manner"
  - [section]: "We utilize a simple contrastive learning of sentence embeddings (simCSE)... to learn domain specific representations"
  - [corpus]: Found 1 paper on contrastive learning for long-tailed problems, weak but supportive evidence
- Break condition: Contrastive learning fails to capture meaningful semantic similarities in the domain

### Mechanism 3
- Claim: Adaptive polynomial expansion of cross-entropy loss improves handling of both noise and class imbalance
- Mechanism: Loss function combines cross-entropy with polynomial term and focal loss to emphasize difficult samples while suppressing noisy ones
- Core assumption: Combining these loss components creates a balanced trade-off between learning from clean samples and handling class imbalance
- Evidence anchors:
  - [abstract]: "The framework further adapts weights of terms in the loss function through a combination of the polynomial expansion of cross-entropy loss and focal loss"
  - [section]: "Inspired by Polyloss... we use an adaptive polynomial term on cross-entropy loss"
  - [corpus]: No direct corpus evidence found for this specific combination
- Break condition: Polynomial weight (epsilon) is poorly tuned, causing either overfitting to noise or under-learning from minority classes

## Architecture Onboarding

- Component map: Encoder → Contrastive Pre-training → Meta-Weight Net → Adaptive Loss → Classifier
- Critical path: Clean data → Meta-weight training → Noisy data weighting → Model training
- Design tradeoffs: Requires clean data (vs fully unsupervised) but provides better performance; contrastive pre-training adds compute but improves robustness
- Failure signatures: Accuracy plateaus early (weighting not working), large gap between clean and noisy performance (weighting overfitting), minority class performance worse than baseline (weighting under-emphasizing tail)
- First 3 experiments:
  1. Run baseline BERT with cross-entropy on noisy data only to establish performance floor
  2. Run contrastive pre-training only (no meta-learning) to measure pre-training benefit
  3. Run meta-learning only with standard loss to measure weighting benefit before combining with pre-training

- Why unresolved: While the paper provides some comparisons, a more comprehensive evaluation against a wider range of state-of-the-art methods on various real-world datasets would provide a clearer picture of APAM's relative performance.

## Limitations

- The framework requires a small clean dataset for meta-training, which may not always be available in practice
- Performance heavily depends on the quality and representativeness of the clean data used for meta-learning
- The specific hyperparameter tuning for the polynomial expansion term requires careful optimization and may not generalize well across different domains

## Confidence

- Meta-learning sample weighting mechanism: Medium
- Contrastive pre-training improvement: Low
- Combined framework performance claims: Medium
