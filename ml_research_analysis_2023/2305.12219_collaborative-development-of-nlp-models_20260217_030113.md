# Collaborative Development of NLP models

## Executive Summary
This paper introduces CoDev, a framework for collaborative development of NLP models that allows multiple users to operationalize their concepts while avoiding interference. The framework learns a local model for each user's concept and a global model integrating all concepts, using disagreements between them to guide the generation of new examples via an LLM. CoDev addresses the challenge of multiple users working on the same dataset with different goals, where traditional single-model approaches may lead to interference between concepts.

The proposed approach consists of three main steps: finding disagreements between local and global models, generating examples that expose these disagreements, and fixing bugs by updating the local models with the generated examples. This iterative process allows the framework to discover and correct errors in individual concepts without negatively impacting other users' work. Experiments demonstrate that CoDev outperforms existing debugging tools like AdaTest in finding and fixing bugs without interference, even when starting from biased data. The framework also shows superior performance in selecting informative examples for teaching concepts to NLP models compared to random selection and uncertainty sampling baselines.

## Key Results

- CoDev outperforms random selection and uncertainty sampling baselines in selecting informative examples for teaching concepts to NLP models

## Why This Works (Mechanism)
CoDev works by maintaining separate local models for each user's concept while also learning a global model that integrates all concepts. The key insight is that disagreements between local and global models can be used to identify areas where individual concepts may be incorrect or incomplete. By generating new examples that expose these disagreements and using them to update the local models, the framework can iteratively improve each concept without interfering with others. The use of an LLM to generate challenging examples ensures that the local models are exposed to a diverse set of edge cases and potential errors, leading to more robust and accurate concept representations.

## Architecture Onboarding

### Component Map
User Concepts -> Local Models -> Global Model -> Disagreement Detection -> LLM Example Generation -> Updated Local Models

### Critical Path
The critical path in CoDev involves the iterative cycle of disagreement detection between local and global models, followed by LLM-generated example creation and local model updates. This process is repeated until the local models converge or a stopping criterion is met.

### Design Tradeoffs
- **Model Complexity vs. Efficiency:** Maintaining separate local models for each concept increases memory usage but allows for more fine-grained control over individual concepts.
- **LLM Integration:** Using an LLM for example generation provides diversity but may introduce computational overhead.
- **Global Model Updates:** Deciding when and how to update the global model based on improved local models is a key design consideration.

### Failure Signatures
- Local models consistently disagreeing with the global model may indicate fundamental concept conflicts
- LLM-generated examples consistently failing to improve local models could suggest issues with the example generation process
- Global model performance degrading over time might indicate insufficient integration of improved local models

## Limitations
