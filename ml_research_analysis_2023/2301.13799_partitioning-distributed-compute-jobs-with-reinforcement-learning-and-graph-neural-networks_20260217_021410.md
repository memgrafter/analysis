# Partitioning Distributed Compute Jobs with Reinforcement Learning and Graph Neural Networks

## Quick Facts
- arXiv ID: 2301.13799
- Source URL: https://arxiv.org/abs/2301.13799
- Reference count: 40
- Achieves up to 56.2% lower blocking rates compared to maximum parallelization baselines

## Executive Summary
PAC-ML introduces a reinforcement learning and graph neural network approach for partitioning distributed deep learning jobs across clusters. Unlike traditional methods that focus solely on minimizing job completion times, PAC-ML optimizes for user-defined blocking rates - the percentage of jobs that fail to meet completion time requirements. The method demonstrates significant improvements in job scheduling efficiency through automated learning of effective partitioning strategies without requiring hand-crafted heuristics.

## Method Summary
PAC-ML combines reinforcement learning with graph neural networks to learn optimal job partitioning strategies in distributed computing environments. The approach models the job scheduling problem as a Markov decision process where the agent learns to partition jobs across cluster resources to minimize blocking rates based on user-defined completion time requirements. The graph neural network component processes the topology and state of the distributed system to inform the RL agent's decisions about how to partition each incoming job.

## Key Results
- PAC-ML achieves up to 56.2% lower blocking rates compared to maximum parallelization baselines
- The method automatically learns effective partitioning strategies without hand-crafted heuristics
- Demonstrated effectiveness across five real deep learning models using optical network architecture

## Why This Works (Mechanism)
PAC-ML leverages reinforcement learning to discover optimal job partitioning strategies that balance computational resources against completion time requirements. The graph neural network component enables the agent to understand the complex relationships and dependencies within the distributed system topology, allowing it to make informed decisions about job placement and resource allocation. By optimizing for blocking rates rather than just completion times, the method better aligns with practical user requirements in production environments.

## Architecture Onboarding
The PAC-ML system consists of an RL agent that receives state representations from a GNN component, which processes the distributed system topology and current job queue. The agent outputs partitioning decisions that are executed by the cluster scheduler. Critical path involves GNN state processing -> RL policy decision -> job partitioning execution -> system state update. The main design tradeoff is between model complexity (for better state representation) and inference latency (for real-time scheduling decisions). Failure signatures include poor convergence during training or suboptimal partitioning decisions in production. Three first experiments would be: (1) validating GNN's ability to accurately represent system state, (2) testing RL agent convergence on simplified scheduling problems, and (3) benchmarking partitioning decisions against known optimal solutions for small-scale problems.
