# Enhancing Performance of Vision Transformers on Small Datasets through Local Inductive Bias Incorporation

## Quick Facts
- arXiv ID: 2305.08551
- Source URL: https://arxiv.org/abs/2305.08551
- Authors: 
- Reference count: 34
- One-line primary result: LIFE module improves ViT performance on small datasets by 10-20% accuracy through multi-scale depthwise separable convolutions that incorporate local context

## Executive Summary
This paper addresses the challenge of training vision transformers (ViTs) on small datasets by introducing the Local InFormation Enhancer (LIFE) module. ViTs typically lack the local inductive bias that makes convolutional neural networks effective on small datasets, leading to poor performance when data is limited. The LIFE module replaces the standard pointwise feedforward layer in ViTs with depthwise separable convolutions of increasing receptive fields (kernel sizes 1, 3, and 5), which generate multi-scale query, key, and value embeddings that incorporate local context from adjacent patches. This approach is modular, efficient, and flexible enough to work with various ViT architectures and auxiliary tokens.

## Method Summary
The LIFE module enhances vision transformers by replacing the pointwise feedforward layer with depthwise separable convolutions that have increasing receptive fields. Specifically, the module processes patch tokens through three convolutional layers with kernel sizes 1, 3, and 5, creating embeddings that capture information from different spatial scales simultaneously. Auxiliary tokens (classification and distillation) are processed separately using pointwise convolutions. The outputs from all scales are concatenated and reshaped to form query, key, and value embeddings for self-attention. This multi-scale approach is compared to single-scale methods and shown to provide over 20% improvement on small datasets while maintaining computational efficiency.

## Key Results
- LIFE improves DeiT-Tiny performance on CIFAR-100 by approximately 20% (51.45% → 71.74%)
- Significant improvements observed across multiple small datasets: CIFAR-10, CIFAR-100, Tiny-ImageNet, and ImageNet-100
- Gains are more pronounced for smaller models (DeiT-Tiny vs DeiT-Small) and more complex datasets
- LIFE extends to downstream tasks with improved performance on object detection (VOC) and semantic segmentation (Cityscapes)
- Multi-scale processing provides over 20% improvement over baseline, outperforming single-scale alternatives

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Replacing pointwise feedforward layers with multi-scale depthwise separable convolutions introduces locality bias into ViTs.
- Mechanism: The LIFE module uses hierarchical convolutional layers with increasing receptive fields (kernel sizes 1, 3, and 5) to generate query, key, and value embeddings that incorporate local context from adjacent patches. This contrasts with standard ViTs that use pointwise feedforward layers with only one-patch receptive fields.
- Core assumption: Local context information from adjacent patches is crucial for learning vision tasks with fewer data samples.
- Evidence anchors:
  - [abstract]: "Our proposed module is memory and computation efficient, as well as flexible enough to process auxiliary tokens such as the classification and distillation tokens."
  - [section]: "We hypothesize that by enriching the embeddings with this local context, vision transformer models (ViTs) will be able to learn the global context with fewer data points and perform better on smaller datasets."
  - [corpus]: Weak evidence - The corpus contains related papers on ViT efficiency and locality, but none specifically validate this exact mechanism of using multi-scale depthwise separable convolutions for local inductive bias incorporation.
- Break condition: If the receptive field sizes are too small or too large, or if the depthwise separable convolutions fail to capture meaningful local patterns, the locality bias may not improve performance.

### Mechanism 2
- Claim: Multi-scale information processing is more effective than single-scale locality incorporation.
- Mechanism: The LIFE module processes patch tokens through three convolutional layers with kernel sizes 1, 3, and 5, creating embeddings that capture information from different spatial scales simultaneously. This multi-scale approach is compared to single-scale methods like CvT which only uses a kernel size of 3.
- Core assumption: Different kernel sizes capture complementary local information that together provide better context than any single scale alone.
- Evidence anchors:
  - [section]: "To demonstrate the effectiveness of multiscale information, we considered a modified version of the LIFE module called LIFE-OneScale... Encoding multiscale information with three kernels of sizes 1, 3, and 5 resulted in over 20% improvement over the baseline."
  - [corpus]: Weak evidence - While the corpus mentions multi-scale approaches like Crossformer's CEL module, it doesn't provide direct evidence for the superiority of the specific three-scale approach used in LIFE.
- Break condition: If the computational overhead of processing multiple scales outweighs the benefits, or if the different scales don't provide complementary information.

### Mechanism 3
- Claim: LIFE module maintains flexibility to process auxiliary tokens while incorporating local information.
- Mechanism: The module uses pointwise convolutions for auxiliary tokens (classification and distillation tokens) while using depthwise separable convolutions for patch tokens. This allows LIFE to be integrated into various ViT architectures without breaking existing functionality.
- Core assumption: Auxiliary tokens need different processing than patch tokens, and this can be achieved without compromising the local information incorporation.
- Evidence anchors:
  - [abstract]: "Our proposed module is memory and computation efficient, as well as flexible enough to process auxiliary tokens such as the classification and distillation tokens."
  - [section]: "Unlike a standard convolution layer, a DSC layer performs the computations in two steps: a depth-wise convolution layer followed by a point-wise convolution layer, which is more computationally efficient. Note that auxiliary tokens, such as classication and distillation tokens, in ViTs, are processed by the pointwise convolution layer in the DSC."
  - [corpus]: No direct evidence - The corpus doesn't mention auxiliary token processing in the context of locality incorporation.
- Break condition: If the pointwise convolution processing of auxiliary tokens fails to maintain their intended functionality or if the distinction between token types breaks down during training.

## Architecture Onboarding

- Component map: Image patches → Patch embedding → LIFE module (multi-scale convolutions) → Rearrangement to Q/K/V → Self-attention → MLP → Classification
- Critical path: Image patches → Patch embedding → LIFE module (multi-scale convolutions) → Rearrangement to Q/K/V → Self-attention → MLP → Classification
- Design tradeoffs: Multi-scale processing provides better locality but increases computational cost slightly. Using depthwise separable convolutions mitigates this cost. The module must balance between capturing sufficient local context and maintaining efficiency.
- Failure signatures: If the module fails to improve performance, possible causes include: receptive fields too small to capture meaningful local context, computational overhead outweighing benefits, or improper integration with existing ViT architectures.

## Limitations

- Exact implementation details for auxiliary token processing are not fully specified, which could affect reproducibility
- Computational efficiency claims are based on empirical timing rather than theoretical analysis
- Downstream task experiments are limited to one dataset each (VOC and Cityscapes)
- The method's effectiveness on extremely small datasets (<5k images) is not tested
- No comparison with concurrent approaches that also incorporate locality into ViTs
