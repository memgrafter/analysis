# Adaptive Neural Networks Using Residual Fitting

## Quick Facts
- arXiv ID: 2301.05744
- Source URL: https://arxiv.org/abs/2301.05744
- Reference count: 15
- Primary result: Adaptive neural networks achieve performance comparable to much larger fixed networks with fewer parameters through residual fitting.

## Executive Summary
This paper introduces an adaptive neural network method that grows network capacity during training by fitting residuals. The approach trains a smaller residual network on the error of a base network, and if the combined network improves performance significantly, the two networks are fused. The method is tested across classification, imitation learning, and reinforcement learning tasks. Results show that the growing network can achieve performance comparable to much larger fixed networks, often with fewer parameters. For example, in CIFAR-10 classification using color histograms, the adaptive method achieved similar accuracy to larger networks. In imitation learning with PyUXV, the growing network trained faster and matched the performance of larger networks. In reinforcement learning using PPO, the adaptive value network approached the performance of large fixed networks. The method offers a computationally efficient alternative to neural architecture search and pruning, though further work is needed to improve weight initialization and control unnecessary growth.

## Method Summary
The adaptive neural network method grows network capacity during training by fitting residuals. The approach starts with a base MLP and trains it on the target task. A smaller residual network is then trained to predict the error (residual) between the base network's predictions and the true targets. If combining the base and residual networks significantly improves performance (measured by MSE improvement exceeding a threshold), the networks are fused into a larger network. This process repeats iteratively, with each iteration potentially adding more capacity to the network. The method is tested on classification tasks using CIFAR-10 color histogram data, imitation learning using the PyUXV navigation environment, and reinforcement learning using PPO on Mujoco Ant and Half Cheetah environments.

## Key Results
- In CIFAR-10 classification using color histograms, the adaptive method achieved similar accuracy to larger fixed networks.
- In imitation learning with PyUXV, the growing network trained faster and matched the performance of larger networks.
- In reinforcement learning using PPO, the adaptive value network approached the performance of large fixed networks.

## Why This Works (Mechanism)
The method works by continuously fitting residuals to the base network's errors and fusing networks when performance improves. This allows the network to grow capacity only when needed, rather than starting with a large fixed architecture. By training a separate residual network on the base network's errors, the method can identify where additional capacity is beneficial and add it selectively.

## Foundational Learning
- **Residual fitting**: Training a network to predict the error of another network; needed to identify where base network predictions can be improved; quick check: train residual network and verify it reduces base network's MSE.
- **Network fusion**: Combining two networks into one larger network; needed to increase capacity when residual fitting shows improvement; quick check: verify fused network performs better than base alone.
- **Growth threshold**: User-defined criterion for when to fuse networks based on MSE improvement; needed to control when network grows; quick check: monitor MSE improvement and ensure fusion only occurs when threshold is met.

## Architecture Onboarding

### Component Map
Base MLP -> Residual Network -> Fusion -> Larger MLP

### Critical Path
1. Train base MLP on task
2. Train residual network on base network's residuals
3. Combine networks if MSE improvement exceeds threshold
4. Repeat from step 2 with larger network

### Design Tradeoffs
- Width adjustment vs. depth adjustment: Current method only adjusts width, which is simpler but may be less efficient than depth variations.
- Growth frequency: Frequent growth can lead to overfitting, while infrequent growth may miss optimization opportunities.

### Failure Signatures
- Excessive growth without performance improvement: Network keeps growing but doesn't converge to better performance.
- Poor residual network training: Residual network fails to converge, preventing growth opportunities.
- Weight initialization issues: New weights initialized poorly, causing fused network to underperform.

### First Experiments
1. Implement base MLP and residual network architecture; train base network on CIFAR-10 histogram data for 10 epochs, record residuals, fit residual network, compute MSE improvement, fuse if threshold met.
2. Extend to PyUXV imitation learning using DAgger; train adaptive network with dropout to prevent overfitting, compare to fixed-size networks, track training speed and final score.
3. Apply method to PPO reinforcement learning; replace value network with adaptive version, train on Mujoco Ant and Half Cheetah, monitor growth behavior and final performance.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: What is the optimal criterion for deciding when to fuse the base network and residual network?
- Basis in paper: The paper mentions that growth occurs if the combined network's MSE improves by a user-defined threshold, but questions the effectiveness of this criterion.
- Why unresolved: The paper notes that without dropout, networks can experience continuing growth, even for large networks, suggesting the current criterion may be insufficient.
- What evidence would resolve it: Comparative studies testing different growth criteria (e.g., fixed MSE improvement thresholds vs. dynamic thresholds based on network size) across various tasks would clarify the optimal approach.

### Open Question 2
- Question: How can the initialization of new weights during network combination be improved to prevent the backpropagation algorithm from causing weights to remain equal to each other?
- Basis in paper: The paper states that initializing new weights to zero leads to the smallest MSE after growth, but the backpropagation algorithm causes these weights to remain equal.
- Why unresolved: The paper suggests initializing new weights randomly to one-tenth the magnitude of existing weights, but this approach may not be optimal.
- What evidence would resolve it: Experiments comparing different weight initialization strategies (e.g., zero initialization, random initialization with varying magnitudes, or methods like those in [8]) would identify the most effective approach.

### Open Question 3
- Question: Can the adaptive network method be extended to allow for varying network depth, similar to AdaNet, and what would be the impact on performance?
- Basis in paper: The paper mentions future work to implement growth with varying network depth like in AdaNet.
- Why unresolved: The current method only adjusts the width of the network, and the impact of allowing depth variations is unknown.
- What evidence would resolve it: Comparative studies applying the adaptive method with both width and depth variations versus width-only variations across different tasks would reveal the impact on performance and efficiency.

## Limitations
- The weight initialization scheme for fused layers is not fully specified, which could affect reproducibility.
- The specific growth thresholds and dropout rates vary across experiments but are not fully specified, making it difficult to precisely replicate the growth behavior.
- The method currently only adjusts network width, not depth, which may limit its efficiency compared to methods that vary both.

## Confidence

**High confidence**: The core concept of residual fitting for adaptive network growth and the overall experimental methodology are clearly described and well-founded.

**Medium confidence**: The results showing performance improvements over fixed networks are credible based on the described methodology, though exact quantitative comparisons are challenging without full implementation details.

**Low confidence**: The specific hyperparameter choices (threshold values, dropout rates) that govern the growth behavior are not fully specified, making it difficult to reproduce the exact growth patterns observed.
