# Provably Feedback-Efficient Reinforcement Learning via Active Reward Learning

## Quick Facts
- arXiv ID: 2304.08944
- Source URL: https://arxiv.org/abs/2304.08944
- Reference count: 40
- This paper proposes a theoretically grounded framework for incorporating human feedback into reinforcement learning, addressing the high feedback complexity issue.

## Executive Summary
This paper addresses the challenge of incorporating human feedback into reinforcement learning by proposing a two-phase approach that dramatically reduces the number of reward queries needed. The key insight is to separate exploration (without rewards) from reward learning, allowing the agent to first collect data through unsupervised exploration and then query a human teacher only for informative state-action pairs. The method is theoretically grounded and works with both binary and noisy human feedback, achieving query complexity that is independent of environmental complexity and only depends on the complexity of the reward function class.

## Method Summary
The proposed framework separates the reinforcement learning process into two distinct phases. In Phase 1, the agent performs reward-free exploration using an optimism-based algorithm to collect a dataset D that covers the state space. In Phase 2, active learning is used to query the human teacher for rewards at only the most informative state-action pairs from D, using an information gain bonus to guide query selection. The algorithm then performs planning with the learned reward function to produce a near-optimal policy. The approach works for both online and offline settings and handles noisy human feedback through a bounded noise assumption.

## Key Results
- The algorithm can learn an ε-optimal policy with only Õ(Hdim²(F)/∆²) reward queries, where H is the horizon, dim(F) is the eluder dimension of the reward function class, and ∆ is the noise margin.
- This is much more efficient than standard RL algorithms which require Ω(poly(d,1/ε)) reward queries, where d is the environmental complexity.
- The method works with both binary and noisy human feedback, and can be applied to both online and offline RL settings.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Separating exploration and reward learning phases reduces feedback complexity.
- Mechanism: In Phase 1, the agent explores the environment without reward signals, collecting a dataset D. In Phase 2, it uses active learning to query only informative state-action pairs from D, rather than querying rewards at every step during training.
- Core assumption: The environment is fixed and can be explored without knowing the reward function.
- Evidence anchors:
  - [abstract] "The key idea is to separate the learning process into two phases: an unsupervised exploration phase where the agent collects data without reward signals, and an active learning phase where the agent queries a human teacher for rewards at a small set of informative state-action pairs."
  - [section] "The algorithm possesses two phases: in phase I, it performs reward-free RL to explore the environment and collect the small but necessary amount of the information about the environment; in phase II, the algorithm performs active learning to query the human for the reward at only a few state-action pairs and then provide a near optimal policy for the tasks with high probability."
  - [corpus] Strong - the paper's central innovation and theoretical contribution.
- Break condition: If the environment changes during exploration, the collected dataset D becomes invalid and the separation fails.

### Mechanism 2
- Claim: Active learning with information gain bonus minimizes reward queries.
- Mechanism: At each query step k, the algorithm selects the state-action pair zk that maximizes the bonus function bk(z), which measures the maximum possible disagreement between reward functions in the hypothesis class F that are consistent with previous queries.
- Core assumption: The reward function class F has bounded complexity (eluder dimension).
- Evidence anchors:
  - [section] "For each z∈Z, we use the following bonus function to measure the information gain of querying z... We then simply choose zk to be arg maxz∈Z bk(z)."
  - [section] "We show that only ˜O(Hdim2R) queries need to be answered by the human teacher."
  - [corpus] Strong - the paper provides both algorithmic description and theoretical bounds.
- Break condition: If the true reward function is not in F (realizability assumption fails), the algorithm cannot guarantee correctness.

### Mechanism 3
- Claim: Optimism bonus ensures sufficient exploration coverage.
- Mechanism: During Phase 1 exploration, the algorithm uses an enlarged optimism bonus (3Γ or CS/Nk + 2Γ) to encourage visiting diverse state-action pairs, ensuring the collected dataset D covers the state space or latent state space adequately for reward generalization.
- Core assumption: The exploration bonus is sufficiently large to guarantee coverage.
- Evidence anchors:
  - [section] "bk h(·,·)← {3Γ(·,·), (Linear Case) C· H2S/Nk h(·,·) + 2Γk h(·,·), (Tabular Case)}"
  - [section] "We show that the dataset collected in the exploration phase essentially cover the state space (tabular case) or the latent state space."
  - [corpus] Strong - the paper explicitly describes the exploration bonus and its role.
- Break condition: If the bonus parameters (βlin, βtbl, C) are set too small, the agent may not explore enough to cover the state space.

## Foundational Learning

- Concept: Eluder dimension
  - Why needed here: Measures the complexity of the reward function class F, which determines the number of queries needed in active learning. The algorithm's query complexity bound is O(dim²(F)/∆²).
  - Quick check question: If F is the class of d-dimensional linear functions, what is dimE(F)?

- Concept: Linear MDP with non-negative features
  - Why needed here: Enables the use of latent state structure (soft state aggregation) to bound the generalization error of the learned reward function from the exploratory dataset.
  - Quick check question: In a linear MDP with non-negative features, how is the latent state space X related to the feature dimension d?

- Concept: Bounded noise (Massart noise) assumption
  - Why needed here: Ensures that when f*(z) is far from 1/2, it's easy to determine the true reward label, making active learning feasible. Without this, reward learning could be arbitrarily difficult.
  - Quick check question: If |f*(z) - 1/2| > ∆ for all z, what is the minimum number of queries needed to learn r(z) correctly?

## Architecture Onboarding

- Component map: Phase 1 (Exploration) -> Phase 2 (Active reward learning) -> Planning (Optimistic value iteration) -> Policy evaluation
- Critical path: Phase 1 → Active reward learning → Planning → Policy evaluation
- Design tradeoffs:
  - Exploration vs. exploitation: Phase 1 focuses solely on exploration, which may be inefficient if the reward function were known.
  - Query efficiency vs. accuracy: More queries (larger N) increase the chance of learning the correct reward, but also increase human burden.
  - Realizability assumption: Requires the true reward to be in the function class F, which may not hold in practice.
- Failure signatures:
  - Poor exploration coverage: The learned policy performs well on states in D but poorly on unseen states.
  - Insufficient queries: The learned reward function disagrees with the true reward on many state-action pairs.
  - Noisy feedback: High variance in human responses makes it difficult to learn the reward function accurately.
- First 3 experiments:
  1. Implement Algorithm 2 (UCBVI-Exploration) on a simple tabular MDP and verify that the collected dataset D covers the state space.
  2. Implement Algorithm 1 (Active Reward Learning) with a synthetic reward function and verify that it learns the correct reward with few queries.
  3. Combine both algorithms and verify that the final policy achieves near-optimal performance with fewer queries than standard RL.

## Limitations
- The realizability assumption (true reward in function class F) is critical and if violated, the algorithm cannot guarantee correctness.
- The bounded noise (Massart) assumption is restrictive, as real human feedback often exhibits unbounded noise.
- The separation of exploration and reward learning phases assumes a fixed environment, which may not hold in many real-world settings.

## Confidence
High - The theoretical guarantees are rigorously proven with clear mathematical bounds.
Medium - Practical performance may be limited by the strong assumptions about realizability and bounded noise.
