# In-Context Analogical Reasoning with Pre-Trained Language Models

## Quick Facts
- arXiv ID: 2305.17626
- Source URL: https://arxiv.org/abs/2305.17626
- Reference count: 21
- Pre-trained language models achieve up to 93.2% zero-shot accuracy on visual Raven's Progressive Matrices tasks using language-based abstractions

## Executive Summary
This paper investigates whether pre-trained language models (PLMs) can perform analogical reasoning on visual Raven's Progressive Matrices (RPM) tasks through intuitive language-based abstractions. The authors convert perceptual features of RPMs into structured language representations, enabling PLMs to solve these tasks without explicit training. Their approach achieves strong zero-shot performance, with GPT-3 reaching up to 93.2% accuracy on simpler tasks through decomposition abstractions. The results demonstrate that PLMs possess emergent analogical reasoning capabilities when provided with appropriate language representations of visual features.

## Method Summary
The method involves converting visual RPM matrices into language prompts by assigning names to entity attributes (shape, size, color) and decomposing complex tasks into simpler subproblems. The RA VEN dataset is preprocessed using naming and decomposition techniques to create language-based abstractions. PLMs (OPT and GPT-3 variants) are then prompted to complete the matrices in a zero-shot manner, with outputs selected based on token probabilities normalized by length. The approach leverages the PLMs' in-context learning capabilities, where performance improves as more context is provided through additional matrix rows.

## Key Results
- PLMs achieve up to 77.2% zero-shot accuracy on the simplest Center sub-task
- GPT-3 reaches 93.2% accuracy on Center using decomposition abstractions
- PLMs exceed human performance on complex 2x2Grid and 3x3Grid sub-tasks
- Performance improves with more context and larger model sizes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Large PLMs can perform analogical reasoning on RPM tasks through language-based abstractions of visual features
- Mechanism: Converting visual perceptual features into structured language representations allows PLMs to leverage pre-trained linguistic patterns for zero-shot reasoning
- Core assumption: Key perceptual features can be captured through language abstractions without losing critical information
- Evidence anchors:
  - [abstract]: "By simply encoding the perceptual features of the problem into language form, we find that PLMs exhibit a striking capacity for zero-shot relational reasoning"
  - [section]: "we explore the use of intuitive language-based abstractions to support analogy in AI systems"
- Break condition: If visual features cannot be adequately captured through language abstractions, or if abstractions introduce noise

### Mechanism 2
- Claim: Higher-level abstractions and decomposition improve PLM performance on RPM tasks
- Mechanism: Breaking complex RPM tasks into simpler subproblems helps PLMs handle working memory limitations and focus on individual attribute relations
- Core assumption: RPM tasks can be decomposed into independent subproblems without losing essential relational structure
- Evidence anchors:
  - [section]: "decomposition abstractions split the RPM into multiple sub-matrices by its independent features, then generate a separate prompt for each one"
  - [section]: "decomposition abstractions that break the task down into atomic parts conserve their working memory such that even smaller PLMs under 1B parameters can achieve competitive performance"
- Break condition: If decomposition breaks essential dependencies between attributes necessary for recognizing relations

### Mechanism 3
- Claim: PLMs exhibit in-context learning capabilities that allow them to improve performance as more context is provided
- Mechanism: Processing multiple rows of the RPM matrix enables PLMs to infer patterns through in-context learning, which improves with model size
- Core assumption: Patterns in RPM matrices can be recognized through sequential processing without explicit training
- Evidence anchors:
  - [section]: "the average model performance increases across all sizes and abstractions as rows are added to the matrix"
  - [section]: "we measure the model performance as we introduce rows to the matrices"
- Break condition: If in-context learning is insufficient to recognize patterns from limited examples

## Architecture Onboarding

- Component map: Input processing -> PLM core (OPT/GPT-3) -> Output decoding -> Abstraction layer
- Critical path:
  1. Convert RPM matrix to language prompt using appropriate abstraction level
  2. Feed prompt to PLM and obtain token probabilities
  3. Normalize by token length and select highest probability completion
  4. For decomposition: repeat for each sub-prompt and aggregate results
- Design tradeoffs:
  - Abstraction level vs. performance: Higher abstractions improve accuracy but may lose information
  - Model size vs. cost: Larger models perform better but are more expensive to run
  - Decomposition vs. complexity: Breaking tasks down helps smaller models but adds complexity
- Failure signatures:
  - Performance near chance level (12.5%): Likely issues with prompt encoding or model capability
  - Inconsistent results across runs: May indicate sensitivity to prompt formatting
  - Better performance on simpler tasks: Could indicate abstraction is insufficient for complex relations
- First 3 experiments:
  1. Verify basic functionality by running on Center sub-task with entity naming only
  2. Test decomposition benefits by comparing full decomposition vs. no decomposition on Center
  3. Evaluate in-context learning by testing performance with 1, 2, and 3 rows of context on Center

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the robustness of pre-trained language models to distracting attributes in analogical reasoning tasks scale with model complexity?
- Basis in paper: [explicit] The paper discusses the impact of distracting orientation attributes on model performance, noting that larger models showed improved performance with ordinal naming abstractions over random naming
- Why unresolved: The analysis provided in the paper is limited to a single attribute (orientation) and a single task (Center sub-task), without exploring a broader range of distractions or more complex tasks
- What evidence would resolve it: Systematic experiments varying the type, number, and complexity of distracting attributes across different tasks and model sizes would clarify how model complexity influences robustness to distractions

### Open Question 2
- Question: What role does in-context learning play in the ability of language models to solve analogical reasoning tasks without prior training?
- Basis in paper: [explicit] The paper shows that model performance improves as more rows of the matrix are introduced, suggesting significant contributions from in-context learning
- Why unresolved: The analysis does not deeply explore the mechanisms by which in-context learning aids reasoning or how it interacts with the models' prior knowledge
- What evidence would resolve it: Detailed ablation studies that isolate the effects of in-context learning from prior knowledge, and experiments that vary the context provided to the models, would elucidate the role of in-context learning

### Open Question 3
- Question: How do different levels of abstraction in language-based representations affect the analogical reasoning capabilities of language models?
- Basis in paper: [explicit] The paper evaluates the impact of naming and decomposition abstractions on model performance, finding that higher-level abstractions strengthen reasoning
- Why unresolved: The study does not fully explore the trade-offs between abstraction levels or how these abstractions might interact with model architecture and size
- What evidence would resolve it: Comparative studies that systematically vary abstraction levels and model architectures, along with evaluations of abstraction-induced biases, would clarify the optimal abstraction strategies for analogical reasoning

## Limitations

- Limited Visual Abstraction Scope: The approach relies on manually defined attribute mappings and may not generalize to other visual reasoning tasks without similar pre-defined abstractions
- Performance Variation Across Sub-Tasks: While strong on simpler tasks, performance degrades significantly on more complex 3x3Grid sub-tasks (34.0% accuracy)
- Potential Data Contamination: GPT-3's strong performance may be influenced by prior exposure to similar RPM-like patterns in training data

## Confidence

**High Confidence**: The core finding that PLMs can perform zero-shot analogical reasoning on RPM tasks through language abstractions is well-supported by systematic experiments across multiple model sizes and abstraction types

**Medium Confidence**: Claims about PLMs' robustness to distracting attributes and ability to improve with more context are supported but may not generalize to all reasoning tasks

**Low Confidence**: The assertion that PLMs have developed genuine analogical reasoning capabilities is not definitively established and cannot rule out pattern matching on memorized training data

## Next Checks

1. **Cross-Dataset Generalization Test**: Evaluate the same PLMs on RPM datasets with different visual feature distributions and complexity levels to assess whether performance improvements generalize beyond the RA VEN dataset

2. **Controlled Ablation Study**: Systematically remove or randomize specific attribute mappings in the language abstractions to determine which features are truly essential for performance versus those that PLMs may be inferring from context

3. **Training Data Analysis**: Conduct a thorough examination of PLM training data to identify potential exposure to RPM-like patterns, and perform controlled experiments with models trained on datasets specifically excluded from containing such patterns
