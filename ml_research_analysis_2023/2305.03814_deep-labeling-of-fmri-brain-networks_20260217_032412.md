# Deep Labeling of fMRI Brain Networks

## Quick Facts
- arXiv ID: 2305.03814
- Source URL: https://arxiv.org/abs/2305.03814
- Reference count: 0
- This study presents a deep learning approach for automatic labeling of resting state brain networks (RSNs) extracted from fMRI data

## Executive Summary
This study presents a deep learning approach for automatic labeling of resting state brain networks (RSNs) extracted from fMRI data. The authors propose using a Multi-Layer Perceptron (MLP) classifier trained on dual regression outputs from group ICA. They compare MLP performance with 2.5D and 3D CNNs, finding that MLP achieves the highest accuracy (100% on holdout and 98.3% on three external sites) while being significantly faster and more compact than CNN alternatives. The MLP requires only a small hidden layer to achieve high performance, making it practical for clinical deployment.

## Method Summary
The method uses Group ICA to extract 100 spatial components from concatenated fMRI data, then applies dual regression to back-project these components to individual subjects while maintaining consistent ordering. The resulting 3D activation maps serve as input features for an MLP classifier with 3 hidden layers (200 nodes each, 66% dropout after layer 2). The model is trained using SGD optimizer with learning rate 1e-5 on 72% of the Beijing dataset, validated on 8%, and tested on 20% plus three external cohorts (New York, Palo Alto, Bangor).

## Key Results
- MLP achieved 100% accuracy on holdout set and 98.3% on three external sites
- MLP was significantly faster and more compact than CNN alternatives while achieving equal or better accuracy
- The model successfully labeled 58 RSN categories across multiple acquisition sites

## Why This Works (Mechanism)

### Mechanism 1
- Group ICA with dual regression creates consistently aligned spatial maps across subjects
- Dual regression back-projects group-level ICA components to individual subjects, ensuring consistent component ordering
- Core assumption: Dual regression accurately maps group-level ICA components to individual subject data
- Break condition: If dual regression fails to properly align individual subject maps with group templates, the classifier would receive inconsistent input patterns

### Mechanism 2
- MLP architecture captures spatial features effectively without requiring complex temporal modeling
- The 3D activation maps from dual regression contain sufficient spatial information about brain network topology
- Core assumption: Spatial patterns in the dual regression maps are discriminative enough for classification
- Break condition: If spatial patterns become too similar between different RSNs, the MLP would struggle without more complex spatial feature extraction

### Mechanism 3
- Large number of training samples from dual regression enables effective learning despite limited subjects
- Each subject contributes 100 ICA components, so 198 subjects yield 19,800 training samples
- Core assumption: The 100 ICA components per subject capture sufficient variability to prevent overfitting
- Break condition: If dual regression produces highly redundant or correlated components across subjects, the effective sample size would be much smaller

## Architecture Onboarding

- Component map: fMRI preprocessing → Group ICA (100 components) → Dual regression → MLP classifier (3×200 nodes, 66% dropout) → 58-class softmax output

- Critical path: Group ICA computation on full cohort is most time-consuming, followed by dual regression for each subject. MLP training and inference are relatively fast once features are extracted.

- Design tradeoffs: MLP sacrifices spatial hierarchy learning for computational efficiency and reduced overfitting risk on small dataset. Dual regression ensures consistent spatial patterns but may introduce alignment errors.

- Failure signatures:
  - Poor test performance across sites suggests preprocessing or dual regression alignment issues
  - High variance between folds indicates insufficient training data or model capacity issues
  - Systematic misclassification of certain RSN pairs suggests feature similarity problems

- First 3 experiments:
  1. Test MLP performance with varying numbers of hidden nodes (2, 10, 20, 50, 100) to find optimal capacity
  2. Evaluate classification accuracy when training on individual ICA components versus group-ICA components
  3. Compare performance when using different numbers of ICA components (40, 60, 80, 100) as input features

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of the MLP model vary with different numbers of ICA components (e.g., 40, 60, 80 vs 100 components) in the group ICA step?
- Basis: The paper mentions ICA was performed with 40, 60, 80, and 100 components but only used 100 component maps for analysis
- Why unresolved: The paper does not compare model performance across different ICA component numbers
- What evidence would resolve it: Systematic evaluation of MLP accuracy, speed, and model size across datasets with different ICA component numbers

### Open Question 2
- Question: What is the effect of varying sampling rates (TR) on the accuracy of the MLP model for labeling RSNs?
- Basis: The paper only evaluated the model on datasets with fixed TR of 2 seconds
- Why unresolved: Performance with different sampling rates remains unknown
- What evidence would resolve it: Evaluation of MLP accuracy on datasets with varying TR values (1s, 2s, 3s)

### Open Question 3
- Question: How does the dual regression step impact the accuracy of RSN labeling, and can the accuracy be improved by developing confidence metrics for individual subject maps?
- Basis: The paper discusses potential dual regression errors but does not explore methods to quantify or mitigate these errors
- Why unresolved: While acknowledging potential for dual regression errors, the paper does not develop confidence metrics
- What evidence would resolve it: Development and evaluation of a confidence metric for dual regression maps

## Limitations
- Limited external validation with only 3 additional cohorts without systematic site-specific analysis
- Lack of detailed error analysis to understand systematic misclassifications
- Potential biases in the 1000 Functional Connectomes Project dataset limiting generalizability

## Confidence

- **High confidence**: Methodological approach of using dual regression with MLP for spatial pattern classification is technically sound
- **Medium confidence**: Reported accuracy metrics are internally consistent but lack independent validation and detailed error analysis
- **Low confidence**: Generalizability claims across different acquisition sites are based on limited external data without systematic analysis

## Next Checks
1. Test the MLP model on at least 5 additional independent cohorts with varying demographics and scanner parameters
2. Perform detailed confusion matrix analysis to identify systematically misclassified RSN pairs
3. Evaluate whether adding temporal convolutional layers or recurrent units to the MLP architecture improves performance on tasks requiring temporal discrimination
