# Improvement of Computational Performance of Evolutionary AutoML in a Heterogeneous Environment

## Quick Facts
- arXiv ID: 2301.05102
- Source URL: https://arxiv.org/abs/2301.05102
- Reference count: 39
- Key result: Hybrid CPU-GPU evaluation with caching and parallelization reduces AutoML computation time by 85-95% for large datasets while maintaining solution quality

## Executive Summary
This paper addresses the computational bottleneck in automated machine learning (AutoML) when evolving composite modeling pipelines. The authors propose a modular approach that combines four key techniques: parallelization of fitness function evaluation, partial caching of evaluated individuals, hybrid CPU-GPU evaluation, and integration with remote infrastructure. Implemented in the open-source FEDOT framework, these techniques significantly reduce computational time while maintaining or improving solution quality across various benchmark datasets. The approach demonstrates practical scalability improvements through heterogeneous computing and intelligent resource management.

## Method Summary
The authors implement a modular optimization strategy combining four parallelizable techniques: (1) parallel evaluation of fitness functions across multiple processes, (2) partial caching of previously evaluated individuals to avoid redundant computations, (3) hybrid CPU-GPU evaluation where computationally intensive model components are offloaded to GPUs while CPU handles preprocessing, and (4) integration with remote computing infrastructure for large-scale experiments. The method is implemented in the FEDOT framework and evaluated across multiple benchmark datasets with varying characteristics.

## Key Results
- Caching increased the number of evaluated pipelines by 14% through avoiding redundant computations
- Parallelization achieved near-linear speedup with 8 processes, reducing wall-clock time proportionally
- Heterogeneous GPU usage provided 85-95% improvement for large datasets, though overhead exceeded gains for smaller datasets
- Remote computing showed linear scaling with population size for large datasets, but overhead made it impractical for small datasets

## Why This Works (Mechanism)
The approach works by addressing the fundamental bottleneck in evolutionary AutoML: repeated evaluation of similar pipeline configurations. Caching eliminates redundant fitness calculations, parallelization distributes computational load across available cores, GPU acceleration handles matrix operations in computationally intensive models, and remote computing provides additional resources for large-scale problems. The modular design allows these techniques to be combined or used independently based on problem characteristics and available infrastructure.
