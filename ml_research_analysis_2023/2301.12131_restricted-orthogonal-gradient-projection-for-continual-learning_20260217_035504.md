# Restricted Orthogonal Gradient Projection for Continual Learning

## Quick Facts
- arXiv ID: 2301.12131
- Source URL: https://arxiv.org/abs/2301.12131
- Reference count: 35
- One-line primary result: ROGO improves forward knowledge transfer in continual learning by relaxing orthogonal gradient constraints while consolidating previous knowledge

## Executive Summary
This paper proposes Restricted Orthogonal Gradient prOjection (ROGO) to address the trade-off between preventing catastrophic forgetting and facilitating forward knowledge transfer in continual learning. Unlike traditional gradient projection methods that strictly constrain gradients to be orthogonal to frozen spaces, ROGO introduces a relaxing space within the frozen space where parameters can be updated more flexibly. This approach allows for better forward transfer while still consolidating previous knowledge through complementary regularization. The method demonstrates superior performance compared to state-of-the-art baselines across four benchmark datasets.

## Method Summary
ROGO modifies traditional gradient projection methods by introducing a relaxing space within the frozen space. For each task, the method searches for a subspace where gradients can be updated with less constraint, then jointly optimizes parameters in both the relaxing and original optimization spaces. A regularization term is added to consolidate previous knowledge within the relaxing space by constraining scale matrices. The approach is theoretically grounded and validated through extensive experiments on CIFAR-100 Split, MiniImageNet, Permuted MNIST, and Mixture benchmarks.

## Key Results
- ROGO achieves better average accuracy compared to state-of-the-art baselines across all four benchmarks
- The method shows improved forward transfer (Ωnew) while maintaining comparable backward transfer (BWT)
- Performance superiority is validated under both fixed network capacity and expansion settings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ROGO improves forward knowledge transfer by relaxing the strict orthogonal constraint to allow parameter updates in directions oblique to the frozen space.
- Mechanism: Instead of constraining gradients to be strictly orthogonal to the entire frozen space (preventing any interference), ROGO identifies a "relaxing space" within the frozen space where parameters can be updated with less constraint. This allows the model to explore a larger optimization space, facilitating learning of new tasks while still preserving previous knowledge through a complementary regularization term.
- Core assumption: The relaxing space can be identified in a way that balances plasticity (learning new tasks) and stability (preserving old knowledge), and that this space exists within the frozen space for each task.

## Architecture Onboarding

- Component map:
  - Input data flows through the network layers (Wl)
  - For each task, gradients are computed
  - Representation spaces (Rl,g,t) are constructed from gradients
  - Relaxing spaces (Vl,t) are searched within the frozen space (Ul,t-1)
  - Gradients are modified using scaled weight projection, considering both the remaining frozen space and the relaxing space
  - A regularization term is added to the loss to constrain the scale matrices within the relaxing space
  - The frozen space is updated with the new representation space after each task

- Critical path:
  1. Compute gradients for the current task
  2. Construct representation space from gradients
  3. Search for relaxing space within the frozen space
  4. Modify gradients using scaled weight projection
  5. Add regularization term to loss
  6. Update parameters and frozen space

- Design tradeoffs:
  - Relaxing space size vs. forgetting: A larger relaxing space allows more learning of new tasks but risks more forgetting
  - Regularization weight (β) vs. plasticity: Higher β constrains the relaxing space more, reducing forgetting but also potentially hindering new learning
  - Threshold (ζ) for relaxing space search vs. efficiency: A lower threshold finds a larger relaxing space but may be more computationally expensive

- Failure signatures:
  - If ROGO fails to improve forward knowledge transfer: The relaxing space might be too constrained, or the regularization might be too strong
  - If ROGO leads to significant forgetting: The relaxing space might be too large, or the regularization might be too weak
  - If ROGO is computationally expensive: The frozen space might be very large, leading to many iterations in the relaxing space search
