# Class-Distribution-Aware Pseudo Labeling for Semi-Supervised Multi-Label Learning

## Executive Summary
This paper addresses the challenge of semi-supervised multi-label learning (SSMLL), where the number of labels per instance is unknown. Existing pseudo-labeling methods often struggle with this setting, either missing true positives or introducing false positives. The proposed Class-Aware Pseudo Labeling (CAP) method introduces class-aware thresholds to better approximate the true class distribution. By assigning pseudo-labels per class, CAP ensures that the labeled set's class proportions closely approximate the true ones, even with very few labels. This approach not only improves empirical performance but also provides theoretical guarantees on generalization error.

## Method Summary
The proposed Class-Aware Pseudo Labeling (CAP) method addresses the challenge of semi-supervised multi-label learning by introducing class-aware thresholds for pseudo-label assignment. Unlike traditional pseudo-labeling methods that use a single global threshold, CAP assigns pseudo-labels per class based on class-specific thresholds. This approach ensures that the labeled set's class proportions closely approximate the true ones, even with very few labels. The method is theoretically grounded, with generalization error bounds that depend on pseudo-labeling error, which CAP minimizes. Empirically, CAP significantly outperforms state-of-the-art methods, especially when labeled data is scarce.

## Limitations
- The theoretical analysis relies on assumptions about the relationship between pseudo-labeling error and generalization bounds that may not hold in all settings, particularly when class distributions are highly imbalanced or when feature representations are poorly aligned with semantic classes.
- The method's performance gains are most pronounced when labeled data is scarce, but the paper does not thoroughly explore scenarios with larger labeled sets or different label imbalance patterns.
- While the proposed method addresses class-distribution awareness, it assumes access to an initial estimate of the true class distribution, which may not always be available in practice.
