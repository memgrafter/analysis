# eWaSR -- an embedded-compute-ready maritime obstacle detection network

## Quick Facts
- arXiv ID: 2304.11249
- Source URL: https://arxiv.org/abs/2304.11249
- Reference count: 40
- Achieves 93.02% F1 score at 10× faster inference than WaSR, enabling real-time maritime obstacle detection on embedded hardware

## Executive Summary
eWaSR introduces a novel maritime obstacle detection network specifically designed for deployment on low-power autonomous surface vehicles. The architecture builds upon the state-of-the-art WaSR framework by replacing computationally intensive modules with efficient transformer-based blocks, including a Light-weight Scale-Aware Semantic Extractor (LSSE) with Channel and Spatial Refinement Modules. This design enables real-time performance on embedded hardware while maintaining detection accuracy comparable to the original WaSR architecture.

## Method Summary
eWaSR adapts the WaSR maritime obstacle detection architecture for embedded deployment by integrating efficient transformer-based components. The network replaces WaSR's computationally expensive modules with a Light-weight Scale-Aware Semantic Extractor (LSSE) that incorporates Channel and Spatial Refinement Modules. This architectural modification reduces computational complexity while preserving semantic understanding capabilities essential for maritime obstacle detection. The design specifically targets deployment constraints of low-power autonomous surface vehicles, enabling operation on resource-constrained embedded platforms like the OAK-D.

## Key Results
- Achieves 93.02% F1 score, comparable to WaSR's 93.54%, while running 10× faster on GPU (8.70 ms vs 90.91 ms)
- Operates at 5.5 FPS on embedded hardware OAK-D, where WaSR cannot run due to memory constraints
- Outperforms other embedded-ready maritime obstacle detection architectures by over 9.74% F1 score

## Why This Works (Mechanism)
eWaSR achieves its performance gains through strategic architectural modifications that reduce computational overhead while preserving semantic understanding. The replacement of WaSR's complex modules with transformer-based components, particularly the Light-weight Scale-Aware Semantic Extractor, enables efficient feature extraction and refinement. The Channel and Spatial Refinement Modules specifically address scale variations common in maritime environments while maintaining computational efficiency. This targeted optimization allows the network to process maritime scenes at high frame rates on embedded hardware without sacrificing detection accuracy.

## Architecture Onboarding
Component map: Input Image -> LSSE -> Channel Refinement -> Spatial Refinement -> Detection Head
Critical path: The LSSE module serves as the core processing unit, with refinement modules operating sequentially to enhance feature quality before detection
Design tradeoffs: Prioritizes computational efficiency over model complexity, accepting slight accuracy reduction for significant speed gains
Failure signatures: Potential degradation in extreme weather conditions or when processing highly complex maritime scenes with multiple overlapping objects

## Limitations
- Evaluation restricted to a single maritime dataset, limiting generalizability claims
- Performance not validated under adverse weather conditions common in maritime environments
- Lacks comparison with recent transformer-based maritime detection methods developed after WaSR

## Confidence
- High: Computational efficiency improvements and embedded deployment capability are empirically validated (8.70 ms vs 90.91 ms on GPU, 5.5 FPS on OAK-D)
- Medium: Accuracy claims (93.02% F1 score vs 93.54% for WaSR) require verification across multiple maritime datasets
- Medium: 9.74% improvement over other embedded-ready architectures needs independent replication with diverse test conditions
