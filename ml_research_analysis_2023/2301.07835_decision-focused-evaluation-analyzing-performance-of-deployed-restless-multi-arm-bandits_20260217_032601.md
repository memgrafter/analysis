# Decision-Focused Evaluation: Analyzing Performance of Deployed Restless Multi-Arm Bandits

## Quick Facts
- arXiv ID: 2301.07835
- Source URL: https://arxiv.org/abs/2301.07835
- Reference count: 40
- Standard prediction accuracy metrics don't correlate with real-world RMAB system performance; decision-focused evaluation using top-k Whittle index errors provides better assessment

## Executive Summary
This paper presents a real-world study analyzing the relationship between prediction accuracy and overall performance of a Restless Multi-Arm Bandit (RMAB) system deployed for improving maternal and child health. The study reveals that standard prediction accuracy metrics like RMSE or MAE do not necessarily correlate with the system's real-world performance. To address this, the authors propose a decision-focused evaluation approach that measures errors in computing top-k Whittle indices, which better explains the system's performance. Using the Spearman's footrule measure, the analysis shows that errors in top-k Whittle indices provide a more meaningful evaluation of the predictive component and align better with the observed real-world performance of the RMAB system.

## Method Summary
The study analyzes a deployed RMAB system using data from ARMMAN's mMitra program across multiple field studies. The method involves predicting transition probabilities based on demographic features, computing Whittle indices for all arms, and selecting top-k arms for intervention each week. The evaluation compares standard prediction accuracy metrics (RMSE, MAE) with decision-focused metrics based on Spearman's footrule distance for top-k Whittle index errors. To handle missing data, beneficiaries are clustered based on passive transition probabilities to infer active transitions. The framework measures how prediction errors in the most important arms (top-k) affect real-world system performance.

## Key Results
- Standard prediction accuracy metrics (RMSE, MAE) do not correlate with RMAB system performance
- Decision-focused evaluation using Spearman's footrule for top-k Whittle indices better explains real-world performance
- Improving overall prediction accuracy can sometimes degrade system performance due to errors concentrating in top-k rankings
- January 2022 study showed highest prediction errors despite similar overall accuracy compared to other studies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Standard prediction accuracy metrics (RMSE, MAE) don't correlate with RMAB performance because they measure overall prediction errors rather than errors in critical decision-making components
- Mechanism: RMAB systems use Whittle indices to select top-k arms each week. Prediction accuracy metrics measure errors across all transition probabilities, but only top-k ranking matters for decision quality. Errors in non-top-k arms don't affect decisions.
- Core assumption: RMAB performance depends primarily on correctly identifying and ranking top-k arms, not overall prediction accuracy
- Evidence anchors: Abstract states improvement in overall accuracy may degrade RMAB performance; section shows errors in January 2022 study were highest despite similar accuracy metrics
- Break condition: If RMAB policy changes to consider more than top-k indices or depends on absolute values rather than rankings

### Mechanism 2
- Claim: Spearman's footrule distance for top-k Whittle indices provides more meaningful evaluation by capturing average shift in rankings of most important arms
- Mechanism: Unlike Kendall Tau which only counts discordant pairs, Spearman's footrule measures actual displacement of each arm's rank from true position, directly quantifying decision impact
- Core assumption: Impact of prediction errors on RMAB performance is proportional to how far predicted top-k arms are from true positions
- Evidence anchors: Section states Spearman's footrule is best suited for decision-focused evaluation; modification considers only top-k elements with normalization factor
- Break condition: If RMAB policy uses different decision rule that doesn't depend on rank ordering

### Mechanism 3
- Claim: Decision-focused evaluation reveals that improving overall prediction accuracy can degrade performance by introducing more errors in critical top-k rankings
- Mechanism: When prediction accuracy improves globally but errors concentrate in top-k rankings (perhaps due to overfitting to less important arms), overall system performance can worsen despite better RMSE/MAE scores
- Core assumption: Prediction errors are not uniformly distributed across all arms - some arms contribute more to decision quality than others
- Evidence anchors: Abstract states improvement in overall accuracy may be accompanied by degradation in performance; section shows January 2022 errors were highest
- Break condition: If prediction errors become uniformly distributed or top-k arms are always predicted most accurately

## Architecture Onboarding

- Component map: Data collection → Prediction model → Whittle index computation → Decision engine → Evaluation module → Performance monitoring
- Critical path: Prediction model → Whittle index computation → Decision engine → Real-world performance → Evaluation metrics → Model improvement
- Design tradeoffs: Prediction accuracy vs. decision quality (improving accuracy may not improve decisions if errors concentrate in top-k rankings); complexity vs. interpretability (decision-focused metrics are more complex but provide better diagnostic information); data requirements (decision-focused evaluation needs observed transition data for all arms, requiring clustering to handle missing data)
- Failure signatures: Global prediction accuracy improves but system performance degrades (errors concentrated in top-k rankings); decision-focused metrics show high errors but prediction accuracy looks good (misalignment between prediction errors and decision impact); performance varies across studies despite similar prediction accuracy (cohort-specific factors affecting top-k rankings)
- First 3 experiments: 1) Compare standard prediction accuracy metrics with decision-focused metrics across multiple weeks to verify lack of correlation; 2) Simulate scenarios where global prediction accuracy improves but top-k ranking errors increase, and measure impact on system performance; 3) Test different rank distance metrics (Kendall Tau vs. Spearman's footrule) on same data to demonstrate Spearman's footrule better explains performance variations

## Limitations
- Analysis based on single deployed system in specific healthcare domain, limiting generalizability to other RMAB applications
- Study demonstrates correlation between decision-focused metrics and system performance but cannot definitively establish causation due to observational nature of field data
- Clustering approach used to infer missing transition probabilities introduces assumptions that may affect accuracy of decision-focused metrics

## Confidence
- High confidence: The fundamental claim that standard prediction accuracy metrics don't necessarily correlate with RMAB system performance
- Medium confidence: The superiority of Spearman's footrule for top-k evaluation as the best decision-focused metric
- Medium confidence: The practical implications for RMAB system evaluation and improvement
