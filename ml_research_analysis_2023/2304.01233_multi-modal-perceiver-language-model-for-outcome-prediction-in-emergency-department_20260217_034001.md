# Multi-Modal Perceiver Language Model for Outcome Prediction in Emergency Department

## Quick Facts
- arXiv ID: 2304.01233

## Executive Summary
This paper introduces a multi-modal Perceiver language model for predicting patient outcomes in emergency departments using both chief complaint text and vital signs recorded at triage. The model adapts the Perceiver architecture to handle both modalities by removing position encoding for tabular vital signs to ensure permutation invariance. Evaluated on the MIMIC-IV ED dataset (120K visits), the multi-modal approach demonstrates improved prediction performance for diagnosis code classification compared to single-modality models, with particular gains for diseases like sepsis, atrial fibrillation, and cerebral infarction.

## Method Summary
The method adapts the Perceiver architecture to fuse text and tabular vital signs for ICD code prediction. Chief complaint text is embedded using a 16-dimensional vector, while vital signs are represented as an 8-dimensional array. The model uses 4 cross-attention blocks with a latent array of size 16 to merge modalities at multiple stages. A key modification is the removal of position encoding for the vital signs modality to ensure permutation invariance. The model is trained for 50 epochs on the MIMIC-IV ED dataset and evaluated using precision, recall, F1 score, accuracy, and AUC metrics.

## Key Results
- Multi-modal Perceiver outperforms models trained solely on text or vital signs for ICD code prediction
- Removing position encoding for vital signs ensures permutation invariance and improves performance
- Vital signs provide added predictive power for diseases with measurable physiological signatures like sepsis, atrial fibrillation, and cerebral infarction

- Claim: Removing position encoding for tabular vital signs enforces permutation invariance, improving model performance for tabular data.

## Architecture Onboarding

- Component map: Chief complaint text (16D) + vital signs array (8D) -> Perceiver (4 blocks, cross-attention + latent transformer) -> Classification head (ICD codes)

- Critical path:
  1. Preprocess chief complaint text (lowercase, tokenize, embed)
  2. Prepare vital signs as fixed-length 8D array
  3. Concatenate modalities and feed to Perceiver
  4. Extract latent representation from final block
  5. Apply classification layer to predict ICD codes

- Design tradeoffs:
  - Compact embedding size (16) balances computational efficiency with expressive power
  - Depth of 4 blocks limits model complexity but may restrict deeper fusion
  - No position encoding on vital signs trades off potential order information for permutation invariance

- Failure signatures:
  - If vital signs are missing or noisy, performance drops more for diseases reliant on physiological markers
  - Overfitting risk if training data is limited or imbalanced across ICD codes
  - Poor cross-attention patterns may indicate modality fusion is not learning useful joint representations

- First 3 experiments:
  1. Compare Perceiver with/without position encoding on vital signs to confirm permutation invariance benefit
  2. Ablation: Train separate models on text-only and vital signs-only, compare with multi-modal
  3. Analyze cross-attention weights to identify which vital sign features contribute most to specific ICD codes

## Limitations
- Evaluation is limited to MIMIC-IV ED dataset, which may not generalize to other healthcare settings
- Model focuses on top-50 ICD codes, potentially missing rare but clinically important diagnoses
- Absence of specific implementation details (e.g., exact hyperparameters) makes exact reproduction challenging

## Confidence

**High confidence**: The core claim that multi-modal Perceiver outperforms single-modality baselines is well-supported by the experimental results and ablation studies. The mechanism of permutation-invariant encoding for tabular data is clearly demonstrated.

**Medium confidence**: The identification of specific disease categories benefiting from multi-modality (sepsis, atrial fibrillation, cerebral infarction) is supported by results, but the clinical interpretation of cross-attention patterns could be more rigorously validated.

**Low confidence**: The generalizability of findings beyond MIMIC-IV ED and the optimal embedding size (16) for different clinical tasks remain uncertain without additional experiments on diverse datasets.
