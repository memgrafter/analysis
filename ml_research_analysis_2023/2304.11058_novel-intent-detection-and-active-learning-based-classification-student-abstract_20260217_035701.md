# Novel Intent Detection and Active Intent Detection and Active Learning Based Classification (Student Abstract)

## Executive Summary
This paper introduces NIDAL, a semi-supervised framework for novel intent detection and active learning in conversational agents. The system combines a neural intent classifier with out-of-domain sample detection and an active learning component to minimize manual annotation costs. By auto-correcting low-confidence predictions using XGBoost and selectively labeling remaining samples, NIDAL achieves significant performance improvements while reducing human effort.

## Method Summary
NIDAL operates as a hybrid semi-supervised learning framework that processes conversational utterances through multiple stages. The system first classifies intents using a neural model, then identifies out-of-domain samples that don't match known intents. For low-confidence predictions, an XGBoost model performs auto-correction. The active learning component then selectively labels the remaining uncertain samples, creating an efficient annotation pipeline that balances automation with human oversight.

## Key Results
- Achieves over 10% improvement in accuracy and macro-F1 compared to baseline methods
- Requires only 6-10% of unlabeled data to be manually annotated
- Validated across SNIPS, ATIS, and Facebook multilingual datasets

## Why This Works (Mechanism)
NIDAL's effectiveness stems from its multi-layered approach to intent classification. The neural model handles standard intent recognition, while the out-of-domain detection prevents misclassification of novel intents. The XGBoost auto-correction layer addresses the uncertainty inherent in low-confidence predictions without human intervention. Finally, the active learning component ensures that human annotation effort is focused on the most informative samples, maximizing the value of each manual label.

## Architecture Onboarding

**Component Map**: Neural Classifier -> OOD Detector -> XGBoost Auto-corrector -> Active Learning Sampler

**Critical Path**: Input utterance → Neural classification → Confidence scoring → Auto-correction (if low confidence) → Active learning selection → Final intent output

**Design Tradeoffs**: Automation vs. accuracy balance - fully automated correction risks error propagation but reduces costs; selective human annotation maintains quality while minimizing effort.

**Failure Signatures**: High false-positive rate in OOD detection indicates overly conservative thresholds; persistent low-confidence predictions suggest neural model inadequacy.
