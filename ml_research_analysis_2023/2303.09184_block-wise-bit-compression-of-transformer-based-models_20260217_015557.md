# Block-wise Bit-Compression of Transformer-based Models

## Quick Facts
- arXiv ID: 2303.09184
- Source URL: https://arxiv.org/abs/2303.09184
- Reference count: 24
- One-line result: Achieves <1% accuracy drop on GLUE tasks using block-wise quantization with int4/int8/fp8 compression

## Executive Summary
This paper introduces BBCT, a block-wise bit-compression method for Transformer-based models that achieves fine-grained compression across all model components including embedding, matrix multiplication, GELU, softmax, layer normalization, and intermediate results. The method employs shift quantization and lookup tables to compress different layers to low-precision data types (int4, int8, fp8) without requiring model retraining. Experimental results on GLUE datasets demonstrate that BBCT maintains accuracy within 1% of the original BERT model while offering hardware-friendly deployment benefits.

## Method Summary
BBCT implements block-wise quantization by dividing matrix multiplications into blocks, quantizing weights, biases, and intermediate results to lower precision using shift quantization. The method builds lookup tables with interpolation to approximate nonlinear operations like GELU, softmax, and layer normalization. Each layer is quantized independently, with different data types (int4, int8, fp8) potentially used for different layers based on their characteristics. The approach compresses the entire Transformer model end-to-end without retraining, making it suitable for efficient deployment on various hardware platforms.

## Key Results
- Achieves less than 1% accuracy drop on most GLUE datasets compared to original BERT model
- Outperforms previous quantization methods like Q8BERT and FQ-BERT in accuracy and computational efficiency
- Enables deployment of Transformer models on various chips without requiring retraining
- Provides fine-grained compression of the entire Transformer architecture including all intermediate results

- Mechanism: The method divides each matrix multiplication into blocks, quantizes the weight, bias, and intermediate results to lower precision (int4, int8, or fp8), and uses shift quantization to minimize accuracy loss
- Core assumption: The block-wise approach maintains sufficient precision within each block to avoid catastrophic accuracy degradation

### Mechanism 2
- Claim: BBCT uses lookup tables with interpolation to approximate nonlinear operations like GELU, softmax, and layer normalization
- Mechanism: Instead of quantizing nonlinear functions directly, BBCT builds a lookup table of 256 key-value pairs for int8 inputs and uses interpolation algorithms to estimate the output
- Core assumption: The lookup table and interpolation can approximate the nonlinear function with negligible accuracy loss
- Evidence anchors:
  - [section 3.2.1] "We can directly quantize the input and output of GELU, build the lookup table and use interpolation algorithm with negligible accuracy drop."

### Mechanism 3
- Claim: BBCT's block-wise compression strategy allows for better performance than previous quantization methods like Q8BERT and FQ-BERT
- Mechanism: By compressing each layer independently and considering correlations within blocks, BBCT can achieve lower accuracy drop than methods that only quantize parts of the model or use less fine-grained approaches
- Core assumption: The block-wise approach effectively captures and maintains the important correlations within each layer
