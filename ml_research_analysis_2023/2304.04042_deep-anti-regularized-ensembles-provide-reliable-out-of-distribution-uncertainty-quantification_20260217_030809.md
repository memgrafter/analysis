# Deep Anti-Regularized Ensembles provide reliable out-of-distribution uncertainty quantification

## Quick Facts
- arXiv ID: 2304.04042
- Source URL: https://arxiv.org/abs/2304.04042
- Authors:
- Reference count: 40
- Key outcome: DARE improves OOD uncertainty quantification in deep ensembles by encouraging large weights that activate weakly on in-distribution data but strongly on OOD inputs

## Executive Summary
This work addresses the problem of overconfident predictions from deep ensembles on out-of-distribution (OOD) data. The proposed Deep Anti-Regularized Ensembles (DARE) introduce a simple anti-regularization strategy that penalizes small weights during training and a control process that increases weights only when in-distribution loss is below a threshold. This approach encourages large weights that activate weakly for in-distribution data but strongly for OOD inputs, leading to higher prediction variance in those regions. Experiments on both regression (CityCam dataset) and classification (Fashion-MNIST/CIFAR10) tasks demonstrate that DARE significantly improves uncertainty estimates on OOD data compared to standard deep ensembles and other diversity-promoting methods, while maintaining competitive in-distribution performance.

## Method Summary
DARE modifies standard deep ensemble training by adding an anti-regularization term that penalizes small weights through a logarithmic penalty function. A control mechanism sets a binary parameter λ that activates this anti-regularization only when the training loss is below a threshold τ. This creates a water-filling optimization problem where weight variance is inversely related to input feature variance, encouraging large weights in front of weakly activated neurons. The method is applied to ensembles of fully-connected networks, with modifications for classification tasks by removing softmax activation and using mean-squared error loss.

## Key Results
- On CityCam regression dataset, DARE reduces NLL on OOD data by 25-40% compared to standard deep ensembles
- For Fashion-MNIST/CIFAR10 OOD detection, DARE achieves AUROC improvements of 5-15% over baseline deep ensembles
- DARE maintains competitive in-distribution performance while significantly improving uncertainty quantification on shifted domains

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Large weights activate weakly on in-distribution data but strongly on OOD inputs, increasing prediction variance in those regions
- Mechanism: The anti-regularization term penalizes small weights while the control process increases weights only when in-distribution loss is below threshold, forcing large weights in front of weakly activated neurons
- Core assumption: Weight variance is inversely proportional to input feature variance (Theorem 1), and variance increase when weights increase
- Evidence anchors:
  - [abstract]: "we show that an ensemble of networks with large weights fitting the training data are likely to meet these two objectives"
  - [section 4.1]: "the variance of the k-th weight component is expressed as follows: σ²ₖ = max[Cδτ/s²ₖ - θ*²ₖ, 0]"
  - [corpus]: Weak evidence - only one related paper directly addresses uncertainty quantification with ensembles for industrial image classification
- Break condition: If input feature variances are uniformly high across all dimensions, the inverse relationship breaks down and large weights won't preferentially activate on OOD

### Mechanism 2
- Claim: The control process maintains accurate in-distribution predictions while enabling weight increase
- Mechanism: λ is set to 1 (anti-regularization active) when loss ≤ threshold τ, and 0 otherwise, preventing weight increase when loss exceeds acceptable level
- Core assumption: The loss threshold τ can be chosen to maintain acceptable in-distribution performance while enabling sufficient weight increase
- Evidence anchors:
  - [section 2.2]: "λ = {1 if LS(hθ) ≤ τ, 0 if LS(hθ) > τ}"
  - [section 6.1]: "The parameter τ of DARE is chosen equal to 1 + δ times the DE validation loss"
  - [corpus]: No direct evidence in corpus about this specific control mechanism
- Break condition: If τ is set too low, weight increase never occurs; if too high, in-distribution accuracy degrades

### Mechanism 3
- Claim: The "water-filling" optimization distributes variance capacity among weights inversely proportional to feature variances
- Mechanism: The optimization problem maximizes log(θ*²ₖ + σ²ₖ) subject to s²ₖσ²ₖ ≤ δτ, creating a constrained allocation of variance
- Core assumption: The log function is strictly concave, ensuring a unique solution to the water-filling problem
- Evidence anchors:
  - [section 4.1]: "We show that the weight variance of the anti-regularized ensemble is solution of a 'water-filling' optimization problem"
  - [section 4.1]: "The water-filling interpretation of the DARE optimization (8) is very insightful: δτ is the 'global variance capacity'"
  - [corpus]: No direct evidence in corpus about water-filling optimization for this application
- Break condition: If the log function is replaced with a linear function, the solution degenerates to concentrating all variance in one component

## Architecture Onboarding

- Component map: Input data -> Fully-connected neural network -> Anti-regularization loss term -> Control mechanism (λ) -> Ensemble aggregation
- Critical path:
  1. Initialize network weights randomly
  2. For each batch, compute in-distribution loss
  3. If loss ≤ τ, apply anti-regularization; otherwise, train normally
  4. Repeat until convergence
  5. Ensemble predictions using variance across networks
- Design tradeoffs:
  - Weight increase vs in-distribution accuracy (controlled by τ)
  - Number of ensemble members vs computational cost
  - Choice of base network architecture (FC networks work best)
  - Linear vs softmax output activation (linear preferred for DARE)
- Failure signatures:
  - If λ never activates (always 0), DARE reduces to standard deep ensemble
  - If τ is too high, in-distribution performance degrades significantly
  - If base network has too few parameters, weight increase has limited effect
  - If input features have uniform high variance, OOD detection performance drops
- First 3 experiments:
  1. Implement DARE on 1D regression synthetic dataset and visualize confidence intervals vs standard deep ensemble
  2. Apply DARE to two-moons classification and compare OOD detection capability
  3. Test DARE on CityCam camera-shift experiment and measure NLL improvement on OOD data

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of DARE change with different choices of the threshold τ, and is there an optimal method to select this threshold without extensive validation?
- Basis in paper: [explicit] The paper discusses choosing τ = 1 + δ times the DE validation loss and mentions that a small penalty δ > 0 should be accepted to allow the weight increase, but it also notes that an ablation study of the impact of the δ parameter on DARE performances is presented in the appendix
- Why unresolved: The paper provides a heuristic for selecting τ but does not explore the sensitivity of DARE's performance to different τ values or provide a method to optimally select τ without extensive validation
- What evidence would resolve it: Empirical results showing DARE's performance across a range of τ values and a proposed method for optimally selecting τ based on in-distribution performance and OOD uncertainty

### Open Question 2
- Question: Can DARE be effectively extended to architectures beyond fully-connected neural networks, such as convolutional neural networks, and what modifications would be necessary?
- Basis in paper: [explicit] The paper notes that DARE's efficiency is limited to fully-connected neural networks with piece-wise linear activation and that a direct application of DARE to the CIFAR10 classification experiment led to negative results due to the softmax activation and convolutional layers
- Why unresolved: While the paper suggests using a fully-connected network head on top of deep features obtained with convolutions, it does not explore how DARE could be directly applied to convolutional architectures or what modifications would be necessary
- What evidence would resolve it: Successful application of DARE to convolutional neural networks with appropriate modifications, such as adapting the anti-regularization strategy for convolutional layers, and empirical results demonstrating improved OOD uncertainty quantification

### Open Question 3
- Question: What is the theoretical justification for the use of the logarithmic function in the regularization term R(θ), and how does it compare to other potential choices?
- Basis in paper: [explicit] The paper mentions that the use of the logarithmic function is motivated by the "water-filling" interpretation of DARE, and it notes that if the identity function were used instead, the solution would degenerate to assigning all weight variance to one component
- Why unresolved: The paper does not provide a detailed theoretical justification for why the logarithmic function is the optimal choice for R(θ) or compare its effectiveness to other potential choices
- What evidence would resolve it: A theoretical analysis comparing the logarithmic function to other potential choices for R(θ), such as polynomial functions, and empirical results demonstrating the impact of different choices on DARE's performance

## Limitations
- Theoretical water-filling framework assumes convex loss surfaces which may not hold for highly non-convex deep networks
- Limited ablation studies on hyperparameter sensitivity (δ, τ) across different architectures
- No detailed analysis of computational overhead compared to standard deep ensembles

## Confidence
- **High confidence**: OOD uncertainty improvement on CityCam dataset (regression task) - multiple metrics show consistent gains
- **Medium confidence**: OOD detection performance on Fashion-MNIST/CIFAR10 - AUROC improvements are substantial but depend on specific threshold choices
- **Low confidence**: Theoretical claims about inverse relationship between weight and feature variance - while mathematically derived, practical validation is limited
