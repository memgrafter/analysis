# Understanding and Detecting Hallucinations in Neural Machine Translation via Model Introspection

## Quick Facts
- **arXiv ID:** 2301.07779
- **Source URL:** https://arxiv.org/abs/2301.07779
- **Reference count:** 19
- **Primary result:** Lightweight hallucination detector achieves up to 90.9 F1 and 95.5 F1 on English-Chinese and German-English test sets

## Executive Summary
This paper systematically investigates neural machine translation (NMT) hallucinations - outputs completely unfaithful to the source - through model introspection. The authors analyze token contributions using Layerwise Relevance Propagation (LRP) between perturbed and non-hallucinated outputs, identifying two key hallucination symptoms: concentrated source token contributions (especially at sentence beginnings) and static source contribution distributions across decoding steps. These insights are leveraged to design a lightweight hallucination detector that significantly outperforms both model-free baselines and strong quality estimation or pre-trained model classifiers on manually annotated test sets, with particular effectiveness on English-Chinese and German-English pairs.

## Method Summary
The authors employ Layerwise Relevance Propagation (LRP) to analyze token contributions in NMT models, comparing perturbed versus non-hallucinated outputs to identify hallucination patterns. Through this analysis, they discover that hallucinated translations exhibit concentrated source token contributions, particularly at the beginning of sentences, and maintain static source contribution distributions across decoding steps. These patterns inform the design of a lightweight hallucination detector that uses these specific symptoms as features. The detector is evaluated against model-free baselines and strong quality estimation or pre-trained model classifiers on manually annotated English-Chinese and German-English test sets.

## Key Results
- LRP analysis reveals two key hallucination symptoms: concentrated source token contributions and static source contribution distributions
- Lightweight detector achieves up to 90.9 F1 (English-Chinese) and 95.5 F1 (German-English)
- Detector significantly outperforms model-free baselines and strong quality estimation or pre-trained model classifiers
- Detector shows robustness to domain shifts
- Ensemble of LRP-based and LASER classifiers further improves precision

## Why This Works (Mechanism)
The approach works by leveraging model introspection to identify systematic patterns in how NMT models generate hallucinated outputs. When hallucinations occur, the model relies heavily on its own internal representations rather than source information, creating observable patterns in token contribution distributions. The concentrated source contributions at sentence beginnings indicate the model's initial reliance on source context before diverging into hallucination. The static contribution distributions across decoding steps reveal the model's reduced dependence on source information as generation progresses. These patterns provide reliable signals for detecting when outputs have become unfaithful to the source.

## Foundational Learning

**Layerwise Relevance Propagation (LRP)**
- *Why needed:* To quantify the contribution of each source token to each generated token, enabling identification of patterns specific to hallucinated outputs
- *Quick check:* Verify that LRP scores sum to approximately 1 across source tokens for each generated token

**Neural Machine Translation Architecture**
- *Why needed:* Understanding how transformer-based NMT models process and generate sequences is essential for interpreting LRP results
- *Quick check:* Confirm encoder-decoder structure with attention mechanisms and generation through beam search or sampling

**Quality Estimation**
- *Why needed:* Provides baseline comparison for hallucination detection performance and context for evaluating the practical utility of the proposed approach
- *Quick check:* Ensure familiarity with sentence-level quality prediction metrics like BERTScore or COMET

## Architecture Onboarding

**Component Map**
Source Text -> NMT Model -> Generated Translation -> LRP Analysis -> Hallucination Detector

**Critical Path**
1. Generate translation using NMT model
2. Apply LRP to obtain token contribution scores
3. Compare contribution patterns against hallucination symptoms
4. Classifier determines if output is hallucinated

**Design Tradeoffs**
- Lightweight detector vs. comprehensive analysis: The detector prioritizes efficiency over exhaustive feature engineering
- Manual annotation vs. automated labeling: Human-labeled data provides ground truth but limits scalability
- Single perturbation method vs. multiple strategies: Simplicity of analysis vs. potential for richer insights

**Failure Signatures**
- False positives when normal translations happen to exhibit similar contribution patterns
- False negatives when hallucinations don't follow identified patterns
- Performance degradation on language pairs with different syntactic structures

**3 First Experiments**
1. Apply LRP to a non-hallucinated translation and verify expected contribution patterns
2. Generate a controlled hallucination (e.g., by masking source tokens) and observe contribution changes
3. Test detector on translations from a different domain to assess robustness

## Limitations
- Small-scale human annotations limit generalizability to broader translation scenarios
- Findings focused on English-Chinese and German-English pairs may not transfer to other language pairs
- Analysis based on transformer-based NMT models may not apply to other architectures
- Single perturbation method used may miss alternative hallucination patterns
- Static contribution assumption may not hold across all translation scenarios

## Confidence
- **High confidence:** Identification of two key hallucination symptoms is well-supported by analysis methodology
- **Medium confidence:** Detector effectiveness demonstrated but limited by small evaluation sets and single-language-pair focus
- **Medium confidence:** Domain robustness suggested but not comprehensively validated
