# Sentence-level Event Detection without Triggers via Prompt Learning and Machine Reading Comprehension

## Quick Facts
- arXiv ID: 2306.14176
- Source URL: https://arxiv.org/abs/2306.14176
- Reference count: 32
- Primary result: Trigger-free event detection model using prompt learning and machine reading comprehension achieves competitive performance on ACE2005 and MAVEN datasets

## Executive Summary
This paper introduces a novel approach to sentence-level event detection that eliminates the need for annotated trigger words. The proposed method transforms the task into a two-tower model combining machine reading comprehension and prompt learning. The first tower uses BERT to encode semantic relationships between input sentences and event type tokens, while the second tower employs prompt learning to predict event types by filling a [MASK] token. Experiments on ACE2005 and MAVEN datasets demonstrate that this trigger-free approach achieves performance comparable to traditional trigger-based methods, with F1 scores of 73.7% on ACE05-E and 73.9% on ACE05-E+. The model also shows strong performance on the larger MAVEN dataset with an F1 score of 73.3%.

## Method Summary
The proposed trigger-free event detection model consists of two main components: a reading comprehension encoder and an event type classifier. The reading comprehension encoder uses BERT to learn semantic relations between input sentences and event type tokens. The event type classifier employs prompt learning to predict event types by filling a [MASK] token with event type tokens. The model is trained using cross-entropy loss and evaluated on two benchmark datasets: ACE2005 and MAVEN. The approach aims to detect events without the need for annotated trigger words, which are typically required in traditional trigger-based methods. The model's performance is assessed using standard evaluation metrics such as precision, recall, and F1 scores.

## Key Results
- The trigger-free approach achieves competitive performance compared to existing trigger-based and trigger-free methods on ACE2005 and MAVEN datasets.
- The model demonstrates strong performance on the larger MAVEN dataset, achieving an F1 score of 73.3%.
- Further analysis shows that the model can effectively identify relationships between input sentences and events, and appropriate prompts can guide the model to predict correct events.

## Why This Works (Mechanism)
The proposed model works by leveraging the power of BERT for semantic understanding and prompt learning for event type prediction. The reading comprehension encoder captures the semantic relationships between input sentences and event type tokens, while the event type classifier uses prompt learning to predict event types by filling in a [MASK] token. This approach allows the model to detect events without relying on annotated trigger words, making it more flexible and potentially more applicable to real-world scenarios where trigger annotations may be scarce or unreliable.

## Architecture Onboarding
Component map: Input Sentence -> BERT Encoder -> [MASK] Token -> Prompt Learning -> Event Type Prediction

Critical path: The critical path involves encoding the input sentence using BERT, generating a [MASK] token, and using prompt learning to predict the event type based on the masked token.

Design tradeoffs: The model trades the need for explicit trigger annotations for the flexibility of prompt-based event detection. This approach may be more applicable to real-world scenarios but requires careful design of prompts and event type tokens.

Failure signatures: Potential failure modes include misinterpretation of semantic relationships between sentences and event types, incorrect prompt design leading to poor event type prediction, and inability to handle complex event detection scenarios involving nested or overlapping events.

## Limitations
- The model's performance is primarily evaluated on English datasets, raising questions about its generalizability to other languages or domains.
- The reliance on prompt learning and BERT-based encoders may limit the model's applicability in low-resource settings where large pre-trained models are unavailable.
- The evaluation metrics focus on F1 scores, which may not fully capture the model's ability to handle complex event detection scenarios involving nested or overlapping events.
