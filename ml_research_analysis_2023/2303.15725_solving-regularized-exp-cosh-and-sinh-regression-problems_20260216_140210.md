# Solving Regularized Exp, Cosh and Sinh Regression Problems

## Quick Facts
- arXiv ID: 2303.15725
- Source URL: https://arxiv.org/abs/2303.15725

- One-line primary result: An approximate Newton method algorithm that solves regularized exp, cosh, and sinh regression problems in input sparsity time with log(∥x₀ - x*∥₂/ε) iterations and Õ(nnz(A) + d^ω) time per iteration.

## Executive Summary
This paper studies the problem of solving regularized exponential, cosh, and sinh regression problems, which are convex optimization problems. The authors propose an algorithm that uses an approximate Newton method to solve the problem in input sparsity time. Specifically, the algorithm uses log(∥x₀ - x*∥₂/ε) iterations and Õ(nnz(A) + d^ω) time per iteration, where nnz(A) is the number of non-zero entries in matrix A, ω is the exponent of matrix multiplication, and ε is the accuracy error. The authors also prove that the Hessian of the loss function is positive definite and Lipschitz, which ensures the convergence of the algorithm. The proposed algorithm is more efficient than the naive Newton's method and can be used to solve attention computation problems in large language models.
