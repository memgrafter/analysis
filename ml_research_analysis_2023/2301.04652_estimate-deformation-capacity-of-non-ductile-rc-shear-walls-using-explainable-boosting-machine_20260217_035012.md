# Estimate Deformation Capacity of Non-Ductile RC Shear Walls using Explainable Boosting Machine

## Quick Facts
- arXiv ID: 2301.04652
- Source URL: https://arxiv.org/abs/2301.04652
- Reference count: 40
- Key outcome: EBM model predicts non-ductile RC shear wall deformation capacity with mean R² of 0.92 and prediction accuracy of 1.05

## Executive Summary
This study develops an explainable boosting machine (EBM) model to predict the ultimate displacement capacity of non-ductile reinforced concrete shear walls. The EBM approach provides transparent and interpretable predictions comparable to black-box methods while using wall design properties as inputs. The model achieves high accuracy metrics and enables engineers to observe relationships between wall properties and deformation capacity through quantified individual contributions and variable correlations.

## Method Summary
The study employs explainable boosting machine (EBM) methodology, which is a glass-box model that uses wall design properties including geometry and reinforcing ratio as inputs to predict ultimate displacement capacity. The EBM approach allows for transparent interpretation of feature relationships while maintaining high predictive accuracy. The model was trained and validated on a dataset of non-ductile RC shear walls, with performance evaluated using statistical metrics including R² and prediction accuracy.

## Key Results
- Achieved mean R² of 0.92 on test dataset for deformation capacity prediction
- Obtained mean prediction accuracy of 1.05 for the proposed EBM model
- Model provides exact intelligibility of relationships between wall properties and deformation capacity without requiring local explanation methods

## Why This Works (Mechanism)
The EBM methodology works effectively because it combines the predictive power of ensemble methods with inherent interpretability through additive models and feature interactions. By quantifying individual feature contributions and correlations among variables, the model provides engineers with both accurate predictions and actionable insights into the deformation behavior of non-ductile RC shear walls.
