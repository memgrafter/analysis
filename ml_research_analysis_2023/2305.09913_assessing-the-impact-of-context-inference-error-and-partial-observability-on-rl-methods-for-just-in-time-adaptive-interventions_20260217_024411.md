# Assessing the Impact of Context Inference Error and Partial Observability on RL Methods for Just-In-Time Adaptive Interventions

## Quick Facts
- arXiv ID: 2305.09913
- Source URL: https://arxiv.org/abs/2305.09913
- Reference count: 36
- Primary result: Policy gradient methods (REINFORCE) demonstrate robust performance under partial observability while value function methods (DQN) suffer significant degradation.

## Executive Summary
This paper investigates how context inference error and partial observability affect reinforcement learning methods for Just-in-Time Adaptive Interventions (JITAIs) in physical activity promotion. The authors develop a simulation environment capturing habituation and disengagement dynamics, then compare REINFORCE (policy gradient) and Dueling DQN (value function) under various observation scenarios. Their key finding is that policy gradient methods maintain robust performance even when critical psychological state variables are unobserved, while value function methods experience catastrophic performance degradation under the same conditions.

## Method Summary
The authors develop a physical activity JITAI simulation environment with true context (stressed/not stressed), habituation, disengagement risk, and step count rewards. Context inference probabilities are generated from noisy Gaussian features with varying uncertainty levels. Two RL algorithms are trained: REINFORCE (pure Monte Carlo policy gradient) and Dueling DQN (value function with experience replay). Agents are evaluated under different observation scenarios: full state observability (C-H-D), most likely context (L-H-D), context probabilities (P-H-D), and partial observability with/without habituation/disengagement variables.

## Key Results
- Policies using context inference probabilities significantly outperform those using only most likely context values, especially as context uncertainty increases
- REINFORCE maintains good performance under partial observability (achieving ~1500 reward vs ~3000 with full state) while DQN performance drops drastically
- When habituation and disengagement variables are unobserved, REINFORCE experiences only a small performance drop compared to full observability, while DQN's performance degrades catastrophically

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Policy gradient methods maintain robust performance under partial observability of psychological state variables.
- Mechanism: REINFORCE uses pure Monte Carlo updates with return-to-go estimates that do not require full state observability for convergence, unlike value function methods which rely on Bellman backups that break under partial observability with non-linear function approximation.
- Core assumption: The simulation environment's dynamics are Markovian with respect to the full state, but policy gradient methods can still learn effective policies using partial observations through credit assignment over complete trajectories.
- Evidence anchors:
  - [abstract] "policy gradient algorithms can provide remarkable robustness to partially observed behavioral state information"
  - [section 2.2] "REINFORCE as a pure Monte Carlo policy gradient method... convergence of the learning algorithm hold in the case where... we only have access to partially observed state vectors"
  - [section 4] "REINFORCE agent experiences a small drop in performance... vastly outperforming the DQN agent"
- Break condition: If the partial observability introduces non-Markovian dependencies that cannot be captured by trajectory-level credit assignment, or if the return signal becomes too noisy to provide useful gradients.

### Mechanism 2
- Claim: Access to context inference probabilities outperforms access to only the most likely context value, especially as context uncertainty increases.
- Mechanism: The policy network can explicitly reason about uncertainty by conditioning on the full probability distribution over contexts, allowing it to take more conservative actions when context is ambiguous rather than committing to potentially incorrect actions.
- Core assumption: The policy architecture can effectively utilize continuous probability inputs to modulate action selection based on context certainty.
- Evidence anchors:
  - [abstract] "policies that leverage context inference probabilities as features can significantly outperform policies that use only the most likely context value"
  - [section 4] "performance of the agents with access to pt clearly dominates the performance of agent with access to lt until the context inference error rate approaches the maximum value considered"
  - [section 4] "When given access to context inference probabilities, REINFORCE increasingly avoids taking the contextualized message actions 2 and 3 as the context uncertainty increases"
- Break condition: If the policy architecture cannot effectively process probability distributions, or if the computational overhead of using probabilities outweighs the performance benefit in practice.

### Mechanism 3
- Claim: Value function methods suffer catastrophic performance degradation under partial observability due to their reliance on Bellman backups with non-linear function approximation.
- Mechanism: DQN uses temporal difference learning with non-linear function approximation (neural networks) that requires full state observability for the Bellman equation to hold. Under partial observability, the learned Q-values become inconsistent and the policy derived from them becomes highly suboptimal.
- Core assumption: The Q-learning update rule assumes that the current estimate of Q-values is based on the true state, not a partial observation.
- Evidence anchors:
  - [abstract] "non-observability of psychological state variables has a drastic impact on the quality of policies learned using value function methods"
  - [section 2.2] "Q-learning methods have the significant drawback that their convergence is not guaranteed in a setting where the state is partially observed and state-action values are represented using non-linear function approximators"
  - [section 4] "performance of the DQN method suffers drastically under partial observability... the DQN method achieves an average total reward of approximately 1500 under partial observability compared to an average total reward of 3000 with fully observed state"
- Break condition: If state augmentation techniques (memory, recurrent networks) are employed to mitigate partial observability, or if the environment dynamics become approximately deterministic with respect to the observable features.

## Architecture Onboarding

- Component map:
  Simulation Environment -> Context Inference Module -> RL Agent Interface -> Performance Evaluation

- Critical path:
  1. Initialize simulation environment with parameters
  2. For each training episode:
     - Sample true context and generate context inference
     - Agent observes state features and selects action
     - Environment returns reward and next state
     - Store transition in replay buffer (DQN) or accumulate return (REINFORCE)
  3. Update agent parameters using selected algorithm
  4. Evaluate learned policy on test episodes

- Design tradeoffs:
  - REINFORCE: Higher sample complexity but more robust to partial observability; requires many episodes for convergence
  - DQN: More sample efficient with replay buffer but breaks under partial observability with non-linear function approximation
  - Context Probabilities: Better performance but requires architecture that can process probability inputs effectively
  - Partial Observability: More realistic but significantly degrades value function methods

- Failure signatures:
  - DQN performance collapse: Sharp drop in average reward when habituation/disengagement variables are unobserved
  - REINFORCE instability: High variance in training returns during early learning phases
  - Context inference error impact: Gradual performance degradation as feature uncertainty increases
  - Disengagement events: Episodes terminate early due to incorrect contextualized messages when context uncertainty is high

- First 3 experiments:
  1. Train DQN and REINFORCE with full state observability (C-H-D scenario) to establish baseline performance
  2. Train both agents with partial observability but using most likely context (L-T scenario) to observe DQN's vulnerability
  3. Train both agents with partial observability but using context probabilities (P-T scenario) to verify REINFORCE's robustness and context probability advantage

## Limitations
- The simulation environment uses simplified dynamics that may not fully capture real-world JITAI complexity
- Only one value function method (DQN) is tested, limiting generalizability to other value-based approaches
- The specific neural network architectures and hyperparameter settings are not fully detailed, making exact reproduction challenging

## Confidence
- High confidence: Context inference probability advantage
- Medium confidence: Policy gradient robustness to partial observability
- Medium confidence: Value function method failure under partial observability

## Next Checks
1. Conduct an ablation study to systematically remove habituation/disengagement from the state and isolate the impact of each missing variable on policy performance.
2. Test whether the context probability advantage persists when using a recurrent policy network that could potentially learn to track context uncertainty over time without explicit probability inputs.
3. Evaluate learned policies on environments with different transition dynamics (e.g., faster habituation rates) to assess whether the observed robustness properties generalize beyond the specific simulation parameters used.
