# Toward Data-Driven Glare Classification and Prediction for Marine Megafauna Survey

## Quick Facts
- arXiv ID: 2303.12730
- Source URL: https://arxiv.org/abs/2303.12730
- Authors: 
- Reference count: 40
- Primary result: 92.94% glare classification accuracy and 89.22% metadata-only glare prediction accuracy

## Executive Summary
This paper addresses glare in marine megafauna aerial surveys, which impacts population estimation accuracy. The authors develop a data-driven glare modeling system using semi-supervised learning to label a large dataset of survey images. A cascading random forest model pseudo-labels imagery, which is then used to train neural networks for glare classification and prediction. The system achieves 92.94% accuracy for glare classification and 89.22% for metadata-only glare prediction. This work establishes a foundation for data-driven mission planning to optimize flight paths and minimize glare during surveys.

## Method Summary
The authors leverage a small labelled dataset to perform semi-supervised learning on a much larger unlabelled dataset. A cascading random forest model is used to pseudo-label the large dataset, with probability thresholds applied to maintain quality. Features are extracted from both imagery (histograms, saturation, sun orientation) and metadata (sun position, aircraft orientation, wind speed, cloud cover). The pseudo-labelled data is used to train multilayer perceptron and recurrent neural network models for glare classification and prediction tasks.

## Key Results
- 92.94% accuracy achieved for glare classification using combined imagery and metadata features
- 89.22% accuracy achieved for glare prediction using only metadata features
- Metadata-only models perform nearly as well as image-feature models, suggesting astronomical and meteorological factors dominate glare severity

## Why This Works (Mechanism)

### Mechanism 1
The semi-supervised pseudo-labeling approach works because the Cascading Random Forest Model (CRFM) trained on the small FIT dataset achieves sufficiently high accuracy to generate reliable labels for the much larger CAM3 dataset. A three-class CRFM is trained on the small labelled FIT dataset, and its confidence scores are used to filter out low-confidence predictions, creating a pseudo-labelled CAM3 dataset that retains 84% of the original data while achieving ~90% accuracy on a held-out validation set. The core assumption is that the FIT dataset is representative of the CAM3 dataset's underlying distribution, so the CRFM can generalize and pseudo-label new data with acceptable error rates.

### Mechanism 2
Metadata-only glare prediction works because glare severity is primarily determined by predictable astronomical and meteorological factors, not image content. Features extracted from metadata (sun position, aircraft orientation, wind speed, cloud cover, etc.) are fed into a neural network that predicts glare severity with ~89% accuracy, even without image-based features. The core assumption is that the reflectance model accurately captures the physical relationship between environmental conditions and glare, so metadata alone is sufficient to predict glare.

### Mechanism 3
The neural network architecture achieves high classification accuracy because it combines imagery-derived features with environmental metadata in a way that captures both local image characteristics and global scene context. A Multilayer Perceptron with 27 input nodes (imagery features) and 22 input nodes (metadata features) is trained on the pseudo-labelled CAM3 dataset, achieving ~93% accuracy for glare classification. The core assumption is that the extracted features (e.g., histogram of I channel, saturation, sun orientation) are sufficient to capture the discriminative information needed to separate glare classes.

## Foundational Learning

Quick check question: Why might an RNN be considered for this task even though the data is not sequential in the traditional sense?

## Architecture Onboarding

- **Component map**: FIT dataset -> Feature extraction -> CRFM training -> CAM3 dataset -> Pseudo-labelling -> Feature extraction -> MLP/RNN training -> Evaluation

- **Critical path**: 
  1. Extract features from FIT and CAM3 datasets
  2. Train CRFM on FIT dataset and generate pseudo-labels for CAM3
  3. Train MLP/RNN models on pseudo-labelled CAM3 data
  4. Evaluate model performance on held-out test set

- **Design tradeoffs**: 
  - Using only metadata for prediction simplifies the pipeline and enables real-time glare forecasting, but may reduce accuracy compared to using image features
  - Pseudo-labeling introduces potential bias if the FIT dataset is not representative, but it enables training on much larger datasets
  - Three-class classification simplifies the problem and improves pseudo-labeling accuracy, but loses granularity needed for detection function tuning

- **Failure signatures**: 
  - Low pseudo-labeling accuracy indicates poor generalization from FIT to CAM3
  - Metadata-only models underperforming suggests important factors are missing from the feature set
  - High accuracy on training but low on test indicates overfitting or data leakage

- **First 3 experiments**: 
  1. Train and evaluate the CRFM on the FIT dataset with different confidence thresholds to determine optimal pseudo-labeling parameters
  2. Compare linear MLP (no activation) vs non-linear MLP on the full feature set to assess the need for non-linear modeling
  3. Evaluate metadata-only models (MLP and RNN) to establish the baseline performance for glare prediction without image features

## Limitations
- The small labelled dataset (FIT) used for pseudo-labeling may not be representative of the larger unlabelled dataset (CAM3), introducing potential bias
- Metadata-only glare prediction at 89.22% accuracy may not capture all factors influencing glare severity, such as local sea state variations and transient weather phenomena
- The three-class classification approach simplifies the glare severity spectrum, potentially limiting the granularity needed for precise detection function calibration

## Confidence
- **High confidence** in the technical methodology and implementation
- **Medium confidence** in the pseudo-labelling accuracy due to limited validation
- **Medium confidence** in metadata-only prediction performance, pending external validation
