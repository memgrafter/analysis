# Covert Communication Based on the Poisoning Attack in Federated Learning

## Quick Facts
- arXiv ID: 2306.01342
- Source URL: https://arxiv.org/abs/2306.01342
- Reference count: 40
- Primary result: Achieves 100% covert message transmission accuracy in federated learning using weight poisoning, with stealthiness against L2-norm and cosine similarity detection.

## Executive Summary
This paper proposes a novel covert communication method for federated learning systems that encodes secret messages into model weight updates through a poisoning attack. The sender controls specific weight directions during local training, while the receiver decodes the message by analyzing the global model's weight patterns after aggregation. The method demonstrates 100% transmission accuracy while maintaining stealthiness against common detection methods, with communication capacity up to 10,000 bits.

## Method Summary
The proposed method encodes binary message bits into model weight directions during local training by adjusting specific weights to positive or negative values based on the message content. The sender and receiver pre-agree on random weight positions for each round, and apply RMS scaling to mask the magnitude changes. The server performs standard FedAvg aggregation, while the receiver records and averages the global model weights over cycles to decode the message by checking the sign of the mean weight values. Periodic weight resetting mitigates initialization noise effects.

## Key Results
- Achieves 100% message transmission accuracy in federated learning scenarios
- Demonstrates stealthiness against L2-norm and cosine similarity-based detection methods
- Robust to noise injection with only 0.4% accuracy loss at 0.8 noise level
- Communication capacity reaches up to 10,000 bits, outperforming backdoor-based approaches

- Claim: Covert message bits can be encoded into model weight directions by controlling local updates
- Mechanism: The sender adjusts specific weights in local model updates to be positive or negative based on message bits, which survive aggregation through the server
- Core assumption: Federated learning aggregation preserves the relative direction of weight changes even after averaging with benign updates

- Mechanism: Instead of using fixed weights, the sender and receiver pre-agree on random weight positions for each round. A scaling factor (RMS of 500 random weights) is applied to mask the magnitude changes
- Core assumption: Random weight selection and scaling preserves message integrity while increasing indistinguishability from normal training dynamics

### Mechanism 3
- Claim: Zeroing back weights before sending signal reduces detection by resetting initialization noise

## Architecture Onboarding

- Component map: Sender -> Server (FedAvg aggregation) -> Receiver, with Benign clients participating in aggregation
- Critical path:
  1. Sender encodes message bits by adjusting weight directions
  2. All clients send local updates to server
  3. Server aggregates updates via FedAvg
  4. Receiver records global model weights
  5. Receiver decodes message by checking weight sign after averaging over cycles
- Design tradeoffs:
  - More weights used for encoding increases capacity but may affect model performance
  - Higher noise levels in defenses reduce transmission quality but increase robustness
  - More rounds per cycle increases stealth but slows communication
- Failure signatures:
  - Model accuracy drops significantly (indicates detection or poisoning failure)
  - Message decoding shows high error rate (indicates aggregation noise or defense interference)
  - Weight patterns become distinguishable from benign clients (indicates detection risk)

## Limitations

- The method's effectiveness heavily depends on the relative number of attacker vs. benign clients, with high proportions of benign clients potentially corrupting the message through averaging
- Specific implementation details for weight adjustment magnitude, scaling factors, and cycle timing are not fully specified, making exact reproduction challenging
- Long-term impact on model convergence and generalization when using this covert communication method remains unclear, as the paper focuses primarily on message accuracy rather than sustained model performance

## Confidence

- High Confidence: The core mechanism of encoding bits through weight direction control and decoding via mean sign over cycles is clearly articulated and demonstrated with 100% transmission accuracy in experiments
- Medium Confidence: The stealth improvements through random weight selection and RMS scaling are logically sound, but the specific parameter choices and their impact on different model architectures need further validation
- Low Confidence: The long-term impact on model convergence and generalization when using this covert communication method remains unclear, as the paper focuses primarily on message accuracy rather than sustained model performance across training epochs
