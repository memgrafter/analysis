# Manipulating Visually-aware Federated Recommender Systems and Its Countermeasures

## Quick Facts
- arXiv ID: 2305.08183
- Source URL: https://arxiv.org/abs/2305.08183
- Reference count: 40
- This paper identifies that incorporating visual information in federated recommender systems introduces new vulnerabilities to image poisoning attacks, which can be effectively mitigated using diffusion model-based defenses.

## Executive Summary
This paper explores the security vulnerabilities of visually-aware federated recommender systems (FedRecs) by demonstrating that while visual features can enhance robustness against model poisoning attacks, they also introduce new attack vectors through image poisoning. The authors propose PSMU(V) and PSMU++ attacks that manipulate item rankings by uploading poisoned images with human-imperceptible perturbations. To counter these threats, they introduce GDMPD, a diffusion model-based defense mechanism that purifies and detects adversarial images. Experiments on MovieLens-1M and Amazon Cell Phone datasets show that GDMPD effectively mitigates both attack types while visual information provides partial protection against model poisoning.

## Method Summary
The authors extended Fed-NCF and Fed-LightGCN models to incorporate visual features using CNN-based feature extraction and transformation matrices. They implemented PSMU(V) attacks by optimizing perturbations on item images to influence target item rankings, and PSMU++ by combining image and model poisoning strategies. For defense, they integrated a pretrained Denoising Diffusion Probabilistic Model (DDPM) to purify uploaded images and detect adversarial content using cosine similarity thresholds. Attacks were launched at the 8th global epoch, and defense effectiveness was measured using NDCG@20 and exposure rate metrics.

## Key Results
- Visual information in FedRecs reduces model poisoning effectiveness but introduces new vulnerabilities to image poisoning attacks
- PSMU(V) can successfully promote target items through image perturbations that are imperceptible to humans
- GDMPD effectively purifies and detects adversarial images, maintaining recommendation quality while mitigating both attack types
- PSMU++ (combined attack) shows enhanced effectiveness compared to either attack alone

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Visual information makes federated recommender systems more robust against model poisoning attacks
- Mechanism: Visual features provide richer, more complete item representations that reduce the sparsity and noise in collaborative data, making it harder for poisoned gradients to manipulate item rankings effectively
- Core assumption: Model poisoning attacks rely on exploiting data sparsity to influence user embeddings and item rankings
- Evidence anchors:
  - [abstract] "incorporating visual information can beat existing state-of-the-art attacks in reasonable settings"
  - [section] "We argue that these attacks are effective because of the data sparsity of collaborative signals"
- Break condition: If visual features are not sufficiently discriminative or if adversarial attacks can also manipulate visual features

### Mechanism 2
- Claim: Image poisoning attacks can effectively promote target items in visually-aware federated recommender systems by modifying item images with human-imperceptible perturbations
- Mechanism: Adversaries gradually add small perturbations to item images during training, which are amplified through the recommendation model to increase target items' exposure rates
- Core assumption: Visual features significantly influence item ranking in the recommendation model
- Evidence anchors:
  - [abstract] "adversaries can gradually modify the uploaded image to manipulate item ranks during FedRecs' training process"
  - [section] "adversaries can be item image providers who promote the target items by uploading images with human-imperceptible noise"
- Break condition: If image purification or detection mechanisms successfully remove or identify adversarial perturbations

### Mechanism 3
- Claim: Diffusion model-based defense (GDMPD) effectively mitigates image poisoning attacks by purifying and detecting adversarial images
- Mechanism: Diffusion models gradually add Gaussian noise to images during training and then remove it during the reverse process, which simultaneously destroys adversarial perturbations while preserving semantic content
- Core assumption: Adversarial perturbations are small and can be submerged by Gaussian noise added during the diffusion process
- Evidence anchors:
  - [abstract] "we employ a diffusion model in visually-aware FedRecs to purify each uploaded image and detect the adversarial images"
  - [section] "GDMPD leverages a pretrained Denoising Diffusion Probabilistic Model (DDPM) to purify all uploaded images with guidance"
- Break condition: If perturbations are too large or if the diffusion model cannot effectively remove all adversarial noise

## Architecture Onboarding

- Component map: Client → Gradient upload → Server aggregation → Model update → Recommendation generation
- Critical path: Client → Gradient upload → Server aggregation → Model update → Recommendation generation
- Design tradeoffs:
  - Model poisoning vs. image poisoning: Different attack vectors with different effectiveness and costs
  - Visual information: Improves robustness against model poisoning but introduces new vulnerabilities
  - GDMPD: Effective defense but adds computational overhead
- Failure signatures:
  - Model poisoning failure: Ineffective when visual information is incorporated
  - Image poisoning failure: Purified by GDMPD or detected by GDMPD
  - GDMPD failure: Cannot remove all adversarial perturbations or cannot detect all adversarial images
- First 3 experiments:
  1. Test effectiveness of model poisoning attacks in FedRecs with and without visual information
  2. Test effectiveness of image poisoning attacks in visually-aware FedRecs
  3. Test effectiveness of GDMPD in purifying and detecting adversarial images

## Limitations
- Limited real-world validation: Experiments rely on controlled settings with standard datasets rather than production environments
- Diffusion model dependency: Defense effectiveness depends on pretrained DDPM quality and may not generalize to all adversarial perturbations
- Computational overhead: GDMPD introduces additional processing at both client and server sides, potentially limiting scalability

## Confidence
- High confidence: Visual information improves robustness against model poisoning attacks in visually-aware FedRecs
- Medium confidence: Image poisoning attacks can effectively manipulate item rankings
- Medium confidence: GDMPD effectively mitigates both attack types

## Next Checks
1. **Real-world image diversity test**: Validate GDMPD's effectiveness on a dataset with varied image types (product photos, user-generated content, advertisements) to assess performance across realistic visual distributions
2. **Transferability evaluation**: Test whether defenses trained to counter model poisoning attacks maintain effectiveness against image poisoning attacks, and whether GDMPD's purification degrades recommendation quality for clean images
3. **Computational overhead analysis**: Measure GDMPD's impact on federated training efficiency, particularly the communication costs of transmitting diffusion-processed images and the additional computation at client devices
