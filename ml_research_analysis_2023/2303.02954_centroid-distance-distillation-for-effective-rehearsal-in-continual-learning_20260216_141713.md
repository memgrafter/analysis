# Centroid Distance Distillation for Effective Rehearsal in Continual Learning

## Quick Facts
- arXiv ID: 2303.02954
- Source URL: https://arxiv.org/abs/2303.02954
- Reference count: 0
- Primary result: CDD achieves 70.69% average accuracy on Split CIFAR, outperforming state-of-the-art methods

## Executive Summary
This paper addresses catastrophic forgetting in continual learning by targeting continual domain drift - a phenomenon where biased samples lead to unpredictable drifts in feature space during rehearsal. The proposed Centroid Distance Distillation (CDD) method introduces two key components: centroid-based sampling to reduce sample bias, and centroid distance distillation to store and enforce relative relationships among centroids. Experiments on four datasets demonstrate that CDD effectively mitigates domain drift and achieves superior performance compared to existing methods, with notable improvements in average accuracy, forgetting measure, and long-term remembering.

## Method Summary
CDD consists of two main components: centroid-based sampling and centroid distance distillation. Centroid-based sampling constructs centroids for each class and maintains a cache of nearest samples to reduce sampling bias. Centroid distance distillation stores pairwise cosine distances between centroids and enforces these relationships during new task learning to preserve old task decision boundaries. The method updates centroids online, selects representative samples for memory buffers, and computes centroid distance matrices for distillation. Training combines standard cross-entropy loss with centroid distance distillation loss to guide replay and reduce domain drift.

## Key Results
- CDD achieves 70.69% average accuracy on Split CIFAR, outperforming previous methods
- Significant improvements in forgetting measure (FT) and long-term remembering (LTR)
- t-SNE visualizations demonstrate effective reduction of continual domain drift
- Superior performance across all four benchmark datasets: Permuted MNIST, Split CIFAR, Split CUB, and Split AWA

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Centroid-based sampling reduces sample bias by selecting representative data points from constructed centroids.
- Mechanism: Builds centroids for each class and maintains a cache of nearest samples. During training, samples are selected based on centroid similarity, ensuring diversity and representativeness.
- Core assumption: Centroids accurately represent class distributions, and samples near centroids are representative.
- Evidence anchors:
  - [abstract]: "First, we propose a centroid caching mechanism for sampling data points based on constructed centroids to reduce the sample bias in rehearsal."
  - [section]: "We propose a simple yet effective Centroid Distance Distillation (CDD) for Rehearsal to mitigate the forgetting raised by continual domain drift."
- Break condition: If centroids become poorly representative of class distributions, the sampling bias may increase.

### Mechanism 2
- Claim: Centroid distance distillation reduces continual domain drift by storing and enforcing relative relationships among centroids.
- Mechanism: Stores pairwise cosine distances between centroids instead of raw features. During new task learning, this stored distance matrix regularizes the model, preserving old task decision boundaries.
- Core assumption: Relative distances between centroids encode sufficient information about task boundaries for effective distillation.
- Evidence anchors:
  - [abstract]: "Then, we present a centroid distance distillation that only stores the centroid distance to reduce the continual domain drift."
  - [section]: "We propose to only store the relative relationships among centroids, i.e., the Cosine similarity."
- Break condition: If centroid distances become unstable across tasks or fail to capture task boundaries, the distillation effect diminishes.

### Mechanism 3
- Claim: Centroid-based sampling and centroid distance distillation work synergistically to reduce both sample bias and domain drift.
- Mechanism: Centroid-based sampling selects diverse and representative samples, reducing initial bias. Centroid distance distillation then enforces stable relative relationships, preventing drift during rehearsal.
- Core assumption: The combination of unbiased sampling and stable distillation is more effective than either approach alone.
- Evidence anchors:
  - [abstract]: "The experiments on four continual learning datasets show the superiority of the proposed method, and the continual domain drift can be reduced."
  - [section]: "CDD contains two main steps... (1) Centroid-based sampling... (2) Centroid distance distillation..."
- Break condition: If either component fails, the overall effectiveness decreases.

## Architecture Onboarding

- Component map: Data -> Centroid construction module -> Cache management module -> Sampling module -> Memory buffer -> Distillation module -> Model training

- Critical path:
  1. Update centroids and caches with incoming data
  2. Select representative samples from caches for memory buffer
  3. Compute centroid distance matrix for current task
  4. During new task learning, enforce stored centroid distances via distillation loss

- Design tradeoffs:
  - Storage vs. performance: Storing centroid distances is more efficient than raw features but may lose some information
  - Cache size vs. bias: Larger caches reduce bias but increase storage and computation
  - Centroid distance threshold: Controls class separation; too small leads to many centroids, too large to poor representation

- Failure signatures:
  - High forgetting despite low domain drift: Sampling may be biased or centroids poorly representative
  - Stable performance but high domain drift: Distillation may be ineffective or distances unstable
  - Poor new task learning: Centroid constraints may be too restrictive or memory buffer insufficient

- First 3 experiments:
  1. Ablation study: Compare performance with and without centroid-based sampling and centroid distance distillation separately
  2. Hyperparameter sensitivity: Test different centroid distance thresholds and cache sizes on a validation set
  3. Domain drift analysis: Visualize t-SNE embeddings of old tasks before and after new task learning to measure drift
