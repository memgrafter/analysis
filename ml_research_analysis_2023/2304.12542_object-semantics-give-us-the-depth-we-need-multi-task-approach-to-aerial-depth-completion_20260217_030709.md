# Object Semantics Give Us the Depth We Need: Multi-task Approach to Aerial Depth Completion

## Quick Facts
- arXiv ID: 2304.12542
- Source URL: https://arxiv.org/abs/2304.12542
- Reference count: 23
- Multi-task learning network jointly performs depth completion and object detection for UAV applications, outperforming single-task baselines

## Executive Summary
This paper proposes a multi-task learning network for UAV applications that jointly performs depth completion and object detection using a shared encoder with two task-specific heads. The method fuses RGB images with sparse depth inputs, leveraging object semantics to guide depth prediction. Experimental results demonstrate that the multi-task network outperforms a single-task baseline, particularly under defective inputs, producing denser depth maps with lower uncertainty near detected objects.

## Method Summary
The method uses a shared encoder backbone (ResNet-34 based) to extract features from RGB images and sparse depth maps, which are then processed by two task-specific heads: a depth completion pathway (encoder-decoder with skip connections) and an object detection pathway (Faster R-CNN with FPN). The network is trained end-to-end using a weighted sum of depth consistency loss, depth smoothness loss, and object detection loss. Monte-Carlo dropout is employed during inference to generate uncertainty maps by computing variance across multiple forward passes.

## Key Results
- Multi-task network outperforms single-task baseline on depth completion accuracy
- Improved robustness to defective inputs (noisy or missing depth data)
- Lower uncertainty in depth predictions near detected objects
- Enhanced depth completion quality for object boundaries and surfaces

## Why This Works (Mechanism)

### Mechanism 1
Multi-task learning with object detection improves depth completion accuracy near detected objects by sharing semantic features that guide depth predictions for object boundaries and surfaces. The shared encoder extracts contextual information about object shapes and spatial relationships that benefit depth completion. This mechanism may break when objects are too small or have complex shapes that object detection cannot accurately identify.

### Mechanism 2
The multi-task network shows improved robustness to defective inputs by providing additional contextual cues through the object detection pathway. Object detection can identify structure locations even when depth data is missing or noisy, helping the depth completion pathway infer missing values. This benefit disappears when input defects are too severe for object detection to function.

### Mechanism 3
Monte-Carlo dropout provides reliable uncertainty estimation by generating multiple depth predictions through dropout-enabled forward passes, allowing variance calculation per pixel. The method assumes dropout layers can approximate Bayesian uncertainty at inference time. Reliability may suffer when dropout rate is improperly configured.

## Architecture Onboarding

- **Component map**: RGB + sparse depth → shared encoder (ResNet-34) → object detection pathway (Faster R-CNN with FPN) + depth completion pathway (encoder-decoder with skip connections) → depth predictions + uncertainty maps (Monte-Carlo dropout)

- **Critical path**: Input RGB and sparse depth maps → shared encoder extracts features → object detection pathway processes features through FPN and RPN → depth completion pathway upsamples and refines depth predictions → uncertainty module generates variance maps via multiple forward passes

- **Design tradeoffs**: Parameter sharing increases efficiency but may limit task-specific optimization; object detection chosen as auxiliary task for annotation efficiency over semantic segmentation; Monte-Carlo dropout adds computation at inference but provides valuable uncertainty estimates

- **Failure signatures**: Poor depth completion shows blurred object boundaries and missing depth values in structured areas; poor object detection results in missing or incorrect bounding boxes, especially for small objects; high uncertainty appears as high variance across entire depth map or in specific regions

- **First 3 experiments**: 1) Train single-task depth completion network and verify baseline performance on clean data; 2) Train multi-task network and compare depth completion quality on clean data; 3) Test both networks on depth maps with increasing Gaussian noise to evaluate robustness difference

## Open Questions the Paper Calls Out

### Open Question 1
How do the semantic object detection features specifically influence depth prediction accuracy in unseen infrastructure types beyond the annotated dataset? The current study uses a limited annotated dataset (1000 frames of buildings and bridges), which may not capture diverse semantic features for other infrastructure types. Testing the model on a more diverse, annotated dataset with various infrastructure types and comparing depth prediction accuracy and robustness would resolve this.

### Open Question 2
What is the impact of multi-task learning on computational efficiency compared to separate single-task models in real-time UAV applications? While the paper suggests efficiency gains, it lacks detailed metrics comparing computational load and inference speed between the multi-task and single-task models. Benchmarking the multi-task network against separate single-task models in terms of FLOPs, inference time, and memory usage under identical conditions would resolve this.

### Open Question 3
How does the uncertainty estimation method perform in dynamic environments with moving objects or changing lighting conditions? The study does not address the model's robustness to temporal changes or environmental variability, which are critical for UAV operations. Evaluating the uncertainty maps and depth predictions on video sequences or datasets with moving objects and varying illumination, comparing model reliability and uncertainty levels, would resolve this.

## Limitations
