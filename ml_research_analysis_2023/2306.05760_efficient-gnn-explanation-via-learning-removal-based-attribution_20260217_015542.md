# Efficient GNN Explanation via Learning Removal-based Attribution

## Quick Facts
- arXiv ID: 2306.05760
- Source URL: https://arxiv.org/abs/2306.05760
- Authors: Multiple authors
- Reference count: 40
- One-line primary result: LARA achieves 3.5× speedup and higher fidelity compared to state-of-the-art method

## Executive Summary
This paper proposes LARA, a framework for efficient and faithful Graph Neural Network (GNN) explanations. It addresses the challenge of simultaneously achieving high fidelity and low computational costs in generating explanations. LARA introduces removal-based attribution, which is theoretically and experimentally shown to be more consistent with interpretation fidelity than mutual information, especially on large graphs. The framework learns an amortized explainer to generate removal-based attribution, enabling efficient explanation generation through a feed-forward pass.

## Method Summary
LARA introduces removal-based attribution as an alternative to mutual information for guiding explanation generation. It defines this as the expected difference in model predictions when a neighbor node is removed, directly measuring a node's impact on predictions. The framework learns an amortized explainer - a graph neural network that takes subgraphs as input and generates node attributions as output. Once trained, this explainer can efficiently generate explanations for new graphs without iterative optimization. To improve scalability, LARA incorporates a subgraph sampling strategy during training, reducing memory requirements while maintaining explanation quality.

## Key Results
- LARA achieves 3.5× speedup compared to state-of-the-art methods
- Higher fidelity explanations demonstrated on six benchmark datasets
- Successfully scales to large real-world datasets (ogbn-arxiv with 160K+ nodes and 1M+ edges)
- Removal-based attribution shows better consistency with interpretation fidelity than mutual information

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Removal-based attribution is more consistent with interpretation fidelity than mutual information on large graphs
- Mechanism: Instead of using mutual information, the method defines removal-based attribution as the expected difference in model predictions when a neighbor node is removed, directly measuring node impact
- Core assumption: Change in model prediction when removing a node is a more reliable indicator of importance than mutual information
- Evidence anchors: Supported by abstract claim and section analysis showing limitation of MI value

### Mechanism 2
- Claim: The amortized explainer can efficiently generate explanations through feed-forward pass
- Mechanism: The explainer is a GNN that takes subgraphs as input and generates node attributions as output, eliminating need for iterative optimization
- Core assumption: The amortized explainer can learn to approximate removal-based attribution for any graph
- Evidence anchors: Supported by abstract and section descriptions of inference process

### Mechanism 3
- Claim: Subgraph sampling improves scalability of training process
- Mechanism: Instead of using entire graph during training, samples subgraphs containing target nodes and their neighbors
- Core assumption: Sampled subgraphs contain enough information to accurately estimate removal-based attribution
- Evidence anchors: Supported by abstract and section descriptions of subgraph sampling strategy

## Architecture Onboarding

- Component map: Target GNN -> Amortized Explainer -> Subgraph Sampler -> Removal-based Attribution
- Critical path: Train amortized explainer on training dataset using removal-based attribution as objective; use subgraph sampling for scalability; deploy trained explainer for new graphs

- Failure signatures: Low fidelity indicates explainer not learning removal-based attribution accurately; poor scalability suggests subgraph sampling not effective

## Limitations

- Evaluation focuses on synthetic datasets and single large real-world dataset, potentially limiting generalization
- Effectiveness of subgraph sampling strategy across different graph structures and sizes remains unclear
- Computational overhead of calculating removal-based attribution during training is not explicitly discussed

## Confidence

- **High Confidence**: Amortized explainer architecture and feed-forward explanation generation are well-established; 3.5× speedup claim supported by experiments
- **Medium Confidence**: Theoretical justification for removal-based attribution being more consistent with interpretation fidelity than mutual information is partially supported but needs further exploration
- **Low Confidence**: Scalability improvements from subgraph sampling demonstrated on tested datasets but may not generalize without additional validation
