# On graph-based reentrancy-free semantic parsing

## Quick Facts
- arXiv ID: 2302.07679
- Source URL: https://arxiv.org/abs/2302.07679
- Reference count: 37
- Primary result: Proposes graph-based semantic parsing without reentrancy, achieving state-of-the-art results on GeoQuery, Scan, and Clevr datasets

## Executive Summary
This paper introduces a novel approach to semantic parsing that eliminates reentrancy by reducing the problem to bi-lexical dependency parsing with crossing arcs. The method addresses two key limitations in the literature: the failure of seq2seq models on compositional generalization tasks and the inability of phrase structure parsers to cover all semantic parses in treebanks. The authors prove that both maximum a posteriori (MAP) inference and latent tag anchoring are NP-hard problems and propose two optimization algorithms based on constraint smoothing and conditional gradient to approximately solve these inference problems. The approach demonstrates state-of-the-art performance on multiple datasets, both for i.i.d. splits and splits designed to test compositional generalization.

## Method Summary
The method reduces semantic parsing without reentrancy to a bi-lexical dependency parsing problem, allowing crossing arcs to ensure coverage of all observed semantic structures. The approach formulates the problem as an integer linear program with constraints ensuring each cluster has exactly one incoming arc and satisfies valency constraints. Since MAP inference and latent tag anchoring are proven NP-hard, the authors propose an optimization algorithm that solves a linear relaxation of the problem using conditional gradient with constraint smoothing. For training, a variational approximation is used to handle the intractable partition function, decomposing the entropy term and using an outer approximation to the marginal polytope.

## Key Results
- State-of-the-art denotation accuracy on GeoQuery, Scan, and Clevr datasets
- Strong performance on both i.i.d. splits and compositional generalization splits
- Demonstrated coverage of all semantic parses observed in treebanks through the graph-based approach

## Architecture Onboarding

- Component map: Graph construction module -> Neural network -> Inference engine -> Training loop -> Executor

- Critical path: Sentence → Graph construction → Neural network → Conditional gradient inference → Output semantic program

- Design tradeoffs:
  - Coverage vs efficiency: Allowing crossing arcs covers more structures but increases complexity
  - Approximation quality vs tractability: The variational approximation is tractable but may be inconsistent
  - CPU vs GPU: Inference uses CPU for conditional gradient, limiting speed

- Failure signatures:
  - Low exact match but high denotation accuracy: Model finds semantically equivalent but syntactically different programs
  - Significant drop on length generalization: Model struggles with longer programs despite good overall performance
  - High variance across runs: The approximation algorithms may have unstable behavior

- CPU-based inference may limit scalability to larger datasets
