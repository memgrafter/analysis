# Clinical Concept and Relation Extraction Using Prompt-based Machine Reading Comprehension

## Quick Facts
- arXiv ID: 2303.08262
- Source URL: https://arxiv.org/abs/2303.08262
- Reference count: 0
- Key outcome: Unified prompt-based MRC architecture achieved F1-scores of 0.9059 (drug-ADE) and 0.8451 (SDoH) for concept extraction, and 0.8291/0.7426 for relation extraction, outperforming previous models by 0.7-2.4% while demonstrating superior cross-institution portability.

## Executive Summary
This study presents a unified prompt-based machine reading comprehension (MRC) architecture for clinical concept and relation extraction that addresses the challenges of nested/overlapped concepts and cross-institution generalizability. The method reformulates both tasks as question-answering problems using natural language prompts derived from annotation guidelines, leveraging transformer models including BERT, BERT-MIMIC, RoBERTa-MIMIC, and GatorTron. Evaluated on two benchmark datasets from the 2018 and 2022 National NLP Clinical Challenges, the proposed approach achieved state-of-the-art performance while demonstrating superior portability when applied to cross-institutional settings.

## Method Summary
The approach formulates clinical concept extraction and relation extraction as machine reading comprehension tasks by converting clinical text into question-answer pairs. For concept extraction, questions are generated from annotation guidelines to identify specific entity types (e.g., "What drug is mentioned in the text?"). For relation extraction, trigger concepts are first identified using concept-specific questions, then relation-specific questions are generated using these triggers (e.g., "What adverse drug event is caused by the drug?"). The method uses transformer-based models with two softmax classifiers to predict start and end positions of answer spans, followed by a start-end matching classifier to handle multiple answers. The approach is evaluated using strict and lenient F1-scores across drug-ADE and SDoH benchmark datasets.

## Key Results
- GatorTron-MRC achieved strict F1-scores of 0.9059 (drug-ADE) and 0.8451 (SDoH) for concept extraction, outperforming previous non-MRC transformer models by 1-3% and 0.7-1.3%
- For end-to-end relation extraction, GatorTron-MRC and BERT-MIMIC-MRC achieved F1-scores of 0.8291 and 0.7426, outperforming prior models by 0.9-2.4% and 10-11%
- In cross-institution evaluation, GatorTron-MRC outperformed traditional GatorTron by 6.4% for concept extraction and 16% for relation extraction
- Error analysis demonstrated the MRC architecture better handles overlapped/nested concepts compared to sequence labeling approaches

## Why This Works (Mechanism)

### Mechanism 1
Prompt-based MRC formulation allows unified handling of both concept and relation extraction in a single model architecture by reformulating them as question-answering tasks. This eliminates the need for separate pipelines for entity recognition and relation classification. The approach leverages the same transformer-based MRC framework to identify entities through concept-specific questions and relations through relation-specific questions. Core assumption: questions formulated from annotation guidelines can effectively capture the semantic definitions of concepts and relations. Break condition: if questions fail to capture semantic nuances, the MRC model will produce incorrect spans regardless of transformer architecture.

### Mechanism 2
MRC architecture naturally handles nested/overlapped concepts better than sequence labeling approaches through its independent start-end position prediction. The two softmax classifiers predict span boundaries independently, allowing multiple answer spans for a single input text. This naturally represents overlapping concepts where different phrases within the same sentence can be answers to different questions. Core assumption: independence of start/end position prediction enables the model to identify multiple valid spans without being constrained by BIO tagging rules. Break condition: if the start-end matching classifier fails to correctly pair spans, the model may produce spurious or incomplete extractions.

### Mechanism 3
Prompt-based learning provides superior cross-institution portability compared to traditional fine-tuning approaches by leveraging the transfer learning ability of pre-trained language models while requiring less adaptation to new institutional data patterns. The question-based formulation captures task semantics rather than memorizing specific data patterns. Core assumption: natural language questions capture generalizable semantic definitions that transfer better across institutional variations than learned embeddings from sequence labeling. Break condition: if institutional variations are too large or if prompts don't adequately capture semantic definitions, the transfer learning advantage may not materialize.

## Architecture Onboarding

- **Component map**: Input layer (clinical text + question pairs) -> Transformer encoder (GatorTron/BERT/RoBERTa variants) -> Start position classifier (binary classifier for span beginning) -> End position classifier (binary classifier for span ending) -> Start-end matcher (classifier to pair spans for multiple answers) -> Output layer (identified concept spans and relation triples)

- **Critical path**: 1. Convert clinical text to sentence-level MRC instances 2. Generate concept questions from annotation guidelines 3. Identify trigger concepts using concept-specific questions 4. Generate relation questions using identified trigger concepts 5. Extract relation arguments using relation-specific questions 6. Match start and end positions to form final extractions

- **Design tradeoffs**: Sentence-level vs document-level processing (sentence-level provides cleaner context but may miss cross-sentence relations); Natural language vs pseudo questions (natural language provides more semantic context but requires more engineering effort); Unified vs separate models (unified model simplifies deployment but may be harder to optimize for individual tasks)

- **Failure signatures**: Low precision but high recall (questions too broad, capturing irrelevant spans); High precision but low recall (questions too specific, missing valid spans); Poor cross-institution performance (prompts not capturing generalizable semantics); Slow inference (inefficient span matching for documents with many potential answers)

- **First 3 experiments**: 1. Validate question formulation: Test different question formulations on a small dataset to measure impact on precision/recall 2. Evaluate span matching: Test start-end matching classifier separately to ensure correct pairing of multiple spans 3. Cross-institution baseline: Compare MRC performance against traditional fine-tuning on MIMIC-to-UW transfer to quantify portability gains

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of prompt-based MRC models compare to sequence labeling approaches when handling extremely nested or overlapping clinical concepts that cross sentence boundaries? The paper discusses that MRC models handle nested/overlapped concepts better than sequence labeling approaches, but focuses on sentence-level sample construction and does not explicitly evaluate cross-sentence nesting. This remains unresolved because the study uses sentence-level preprocessing for MRC instances, limiting evaluation to concepts within single sentences. Direct comparison of MRC vs sequence labeling performance on clinical texts containing cross-sentence nested/overlapped concepts, with evaluation metrics for both strict and lenient matching, would resolve this question.

### Open Question 2
What is the impact of different prompt engineering strategies (natural language vs pseudo-questions) on the few-shot learning capabilities of MRC models when applied to new clinical domains? The paper compares natural language questions vs pseudo-questions and finds natural language performs better, but doesn't evaluate few-shot learning performance across different clinical domains. This remains unresolved because while the paper shows natural language questions work better within the same domain, it doesn't test how well these prompting strategies transfer when training data is limited in new clinical domains. Controlled experiments comparing MRC model performance with different prompt types when trained on limited data from new clinical domains would resolve this question.

### Open Question 3
How does the computational efficiency of the MRC-based relation extraction approach compare to traditional enumeration-based methods when scaling to datasets with hundreds of relation types? The paper mentions that MRC avoids time-consuming enumeration of concept combinations, but doesn't provide computational complexity analysis or timing comparisons for large relation type sets. This remains unresolved because the study only evaluates on datasets with 8 and 28 relation types, and doesn't report computational resource requirements or processing times compared to enumeration-based methods. Systematic benchmarking of MRC vs enumeration-based relation extraction methods across datasets with varying numbers of relation types would resolve this question.

## Limitations

- The performance of the prompt-based MRC approach is highly dependent on the quality of questions generated from annotation guidelines, with no detailed evaluation of how different question formulations impact model performance
- Cross-institution generalization validation is limited to a single source (MIMIC-III) and single target (UW) institution, restricting confidence in portability claims
- Evaluation focuses exclusively on two specific benchmark datasets (drug-ADE and SDoH) from n2c2 challenges, limiting generalizability to other clinical concept types and relation extraction scenarios

## Confidence

**High Confidence Claims**:
- The unified prompt-based MRC architecture successfully handles both concept and relation extraction within a single framework
- GatorTron-MRC outperforms previous transformer models on both benchmark datasets
- The MRC approach demonstrates superior cross-institution portability compared to traditional methods
- The method effectively handles nested/overlapped concepts better than sequence labeling approaches

**Medium Confidence Claims**:
- The 1-3% and 0.7-1.3% improvements over non-MRC transformers represent meaningful clinical utility gains
- The question-answering formulation provides more interpretable and controllable extraction process
- The start-end matching classifier effectively handles multiple answer spans without errors

**Low Confidence Claims**:
- The cross-institution performance improvements will generalize to other institution pairs beyond MIMIC-III to UW
- The question formulation process is scalable and requires minimal domain expertise
- The approach will maintain similar performance advantages on clinical domains not represented in the n2c2 datasets

Measure precision-recall trade-offs and identify optimal question patterns that maximize both metrics while minimizing manual effort.

Include institutions with varying documentation styles, EHR systems, and patient populations to assess robustness to different types of institutional variation.
