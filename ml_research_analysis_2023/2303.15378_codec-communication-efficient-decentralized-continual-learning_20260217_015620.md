# CoDeC: Communication-Efficient Decentralized Continual Learning

## Executive Summary
This paper introduces CoDeC, a novel approach to enable serverless training with spatially and temporally distributed data while preserving data privacy. The core method combines orthogonal gradient projection with gossip averaging across decentralized agents, along with a lossless communication compression scheme based on gradient subspaces. Experiments demonstrate that CoDeC successfully learns distributed continual tasks with minimal forgetting, achieving up to 4.8x reduction in communication costs while maintaining comparable performance to full communication baselines. The approach theoretically converges at a rate of O(1/√(NK)), matching state-of-the-art decentralized learning methods.

## Method Summary
CoDeC combines three key components: orthogonal gradient projection, gossip averaging, and lossless communication compression. The algorithm partitions each layer's gradient space into Core Gradient Space (CGS) and Residual Gradient Space (RGS), projecting updates for new tasks onto RGS to prevent catastrophic forgetting. Model updates are expressed as linear combinations of basis vectors spanning the RGS subspace, enabling lossless compression by communicating only coefficients. Gossip averaging maintains global consensus across decentralized agents without requiring a central parameter server. The method theoretically converges at O(1/√(NK)) while achieving up to 4.8x communication reduction.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Orthogonal gradient projection prevents catastrophic forgetting by constraining updates to lie in a subspace orthogonal to important gradients from previous tasks
- Mechanism: The algorithm partitions each layer's gradient space into Core Gradient Space (CGS) and Residual Gradient Space (RGS). Updates for new tasks are projected onto RGS, which is orthogonal to CGS, ensuring minimal interference with past knowledge
- Core assumption: Gradient updates for new tasks can be effectively constrained to a lower-dimensional subspace without significant loss in learning capability
- Evidence anchors: [abstract] "We mitigate catastrophic forgetting while learning a task sequence in a decentralized learning setup by combining orthogonal gradient projection with gossip averaging across decentralized agents."

### Mechanism 2
- Claim: Lossless communication compression is achieved by expressing model updates as linear combinations of basis vectors spanning the RGS subspace
- Mechanism: Since all model updates lie in the RGS subspace, they can be represented as a linear combination of basis vectors from this subspace. Only the coefficients need to be communicated, not the full gradient vectors, achieving lossless compression
- Core assumption: The gradient updates for new tasks consistently lie in the RGS subspace, which is a proper subset of the full gradient space
- Evidence anchors: [abstract] "Further, CoDeC includes a novel lossless communication compression scheme based on the gradient subspaces."

### Mechanism 3
- Claim: Gossip averaging maintains global consensus across decentralized agents without requiring a central parameter server
- Mechanism: Each agent communicates with its neighbors using a mixing matrix, updating its local model parameters by averaging with received updates. This distributed consensus mechanism converges to a global solution
- Core assumption: The mixing matrix is doubly stochastic and satisfies certain spectral properties that ensure convergence of the gossip averaging process
- Evidence anchors: [abstract] "The core method combines orthogonal gradient projection with gossip averaging across decentralized agents"

## Architecture Onboarding

- Component map: GPM -> Gossip averaging module -> Lossless compression module -> Decentralized optimizer
- Critical path: 1. Compute local gradient using current mini-batch, 2. Project gradient onto RGS using GPM, 3. Update local model parameters, 4. Compute model update (difference between old and new parameters), 5. Compress model update using RGS basis vectors, 6. Communicate compressed coefficients to neighbors, 7. Decompress received coefficients to reconstruct model updates, 8. Average with neighbors' updates, 9. Periodically update GPM with new basis vectors
