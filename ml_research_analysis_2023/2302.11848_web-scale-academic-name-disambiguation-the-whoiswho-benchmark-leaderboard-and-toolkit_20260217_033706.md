# Web-Scale Academic Name Disambiguation: the WhoIsWho Benchmark, Leaderboard, and Toolkit

## Quick Facts
- arXiv ID: 2302.11848
- Source URL: https://arxiv.org/abs/2302.11848
- Reference count: 40
- Over 1 million papers and 70K+ authors across 1000+ ambiguous names

## Executive Summary
This paper introduces WhoIsWho, a comprehensive benchmark for academic name disambiguation that addresses the challenge of identifying unique researchers sharing common names. The benchmark includes over 1 million papers and 70K+ authors across 1000+ ambiguous names, constructed through an innovative interactive annotation process. Two primary tasks are formalized: from-scratch clustering (SND) and real-time assignment (RND), with accompanying leaderboards and toolkits to advance research in this domain.

## Method Summary
The WhoIsWho benchmark employs an interactive annotation process to create high-quality labeled data at scale. The system utilizes a combination of multi-modal semantic features (titles, keywords, organizations) and relational features (co-author, co-venue) to disambiguate authors. Two main tasks are defined: from-scratch name disambiguation (SND) which clusters papers from scratch, and real-time name disambiguation (RND) which assigns incoming papers to existing clusters. The RND-all method is deployed online for daily arXiv paper assignments, demonstrating practical applicability of the approach.

## Key Results
- Achieves state-of-the-art results on both SND and RND tasks with strong baseline methods
- RND-all method successfully deployed online for daily arXiv paper assignments
- Empirical analysis shows combining multi-modal semantic and relational features yields optimal performance

## Why This Works (Mechanism)
The system's effectiveness stems from its comprehensive feature engineering that captures both semantic and relational information about authors. By combining paper titles, keywords, organizational affiliations with co-author and co-venue relationships, the approach creates rich representations that distinguish between authors sharing the same name. The interactive annotation process ensures high-quality training data, while the two-task framework addresses both historical data disambiguation and real-time assignment scenarios.

## Architecture Onboarding
Component map: Interactive annotation -> Feature extraction -> Clustering/Assignment -> Leaderboard evaluation

Critical path: Paper ingestion → Feature computation → Cluster assignment (SND/RND) → Evaluation metrics

Design tradeoffs: Interactive vs. fully automated annotation; real-time vs. batch processing; feature complexity vs. computational efficiency

Failure signatures: Cluster fragmentation (over-splitting authors), chain linking (incorrect author merging), temporal inconsistency in author evolution

First experiments:
1. Baseline clustering using only author names
2. Feature ablation study (semantic only vs. relational only vs. combined)
3. Online assignment latency and accuracy measurement

## Limitations
- Evaluation relies heavily on heuristic rules for initial clustering and active learning sample selection
- Dataset focuses exclusively on computer science publications, limiting generalizability
- Manual labeling process may introduce human bias despite interactive annotation improvements
