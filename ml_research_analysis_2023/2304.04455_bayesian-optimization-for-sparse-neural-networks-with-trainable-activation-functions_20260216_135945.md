# Bayesian optimization for sparse neural networks with trainable activation functions

## Quick Facts
- **arXiv ID:** 2304.04455
- **Source URL:** https://arxiv.org/abs/2304.04455
- **Authors:** 
- **Reference count:** 40
- **Key outcome:** MMeLU activation function achieves 94% accuracy on Fashion-MNIST with faster convergence than Adam optimizer

## Executive Summary
This paper introduces MMeLU, a novel trainable activation function that combines ReLU and Mexican hat function properties within a fully Bayesian framework. The method automatically estimates both network weights and activation parameters using MCMC-based Gibbs sampling, achieving superior performance on image classification tasks. MMeLU demonstrates up to 94% accuracy on Fashion-MNIST while converging faster than standard optimizers like Adam.

## Method Summary
The proposed method combines a hybrid activation function (MMeLU) with Bayesian inference for parameter estimation. MMeLU(x) = c·fγ,b(x) + (1-c)·ReLU(x) where fγ,b(x) is the Mexican hat function. A hierarchical Bayesian model treats all parameters as random variables with prior distributions, using MCMC sampling to estimate posterior distributions. The approach incorporates ℓ1 regularization to promote sparsity while automatically learning the activation function parameters c, γ, and b from data.

## Key Results
- MMeLU achieves 94% classification accuracy on Fashion-MNIST dataset
- Faster convergence compared to standard optimizers like Adam
- Robust performance across three datasets (COVID-19 CT images, Fashion-MNIST, CIFAR-10)
- Superior performance in challenging classification tasks with sparse regularization

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** MMeLU improves CNN performance by combining ReLU and Mexican hat function properties
- **Mechanism:** The mixture allows networks to benefit from ReLU's sparse activations for large inputs while maintaining the smooth, localized response of the Mexican hat function for small inputs. The parameter c controls the balance between these behaviors.
- **Core assumption:** Mexican hat function provides complementary non-linear properties to ReLU that are beneficial for image classification
- **Evidence anchors:** MMeLU outperforms other activation functions achieving higher accuracy and faster convergence
- **Break condition:** Datasets with very large or small input ranges where neither function is appropriate

### Mechanism 2
- **Claim:** Bayesian framework provides better parameter estimation than gradient-based methods
- **Mechanism:** Treats all parameters as random variables with prior distributions, using MCMC sampling to estimate posterior distributions and avoid local minima
- **Core assumption:** Hierarchical Bayesian model with appropriate priors accurately represents parameter uncertainty
- **Evidence anchors:** Fully Bayesian model automatically estimates both weights and activation parameters
- **Break condition:** Slow MCMC convergence or poor prior choices dominating posterior estimates

### Mechanism 3
- **Claim:** ℓ1 regularization combined with Bayesian inference promotes sparsity while maintaining generalization
- **Mechanism:** Hierarchical Bayesian model includes ℓ1 regularization terms that encourage many weights to be exactly zero
- **Core assumption:** Sparsity improves generalization by reducing overfitting
- **Evidence anchors:** Laplace distribution for weight vector W to promote sparsity
- **Break condition:** ℓ1 regularization too strong and eliminates important weights

## Architecture Onboarding

- **Component map:** Input layer → Convolutional layers (with MMeLU activation) → Max pooling → Batch normalization → Dropout → Fully connected layers → Output layer → Bayesian optimizer (MCMC sampler) → Updates weights and MMeLU parameters (c, γ, b) → Prior distributions → Likelihood function

- **Critical path:** 1. Initialize network weights and MMeLU parameters 2. Perform forward pass through network 3. Compute loss using Bayesian likelihood with ℓ1 regularization 4. Sample from conditional posteriors using Gibbs sampler 5. Update parameters and repeat until convergence

- **Design tradeoffs:** Computational cost vs. performance (Bayesian inference more expensive but may provide better estimates), model complexity vs. generalization (more complex activation functions may increase overfitting risk), sparsity vs. capacity (ℓ1 regularization promotes sparsity but may reduce learning complex patterns)

- **Failure signatures:** Poor convergence of MCMC sampler (chains not mixing well, high autocorrelation), overfitting despite ℓ1 regularization (large gap between training and test performance), computational cost too high for practical deployment, sensitivity to prior distribution choices

- **First 3 experiments:** 1. Test MMeLU performance on simple dataset (Fashion-MNIST) with shallow CNN architecture 2. Compare Bayesian inference vs. Adam optimizer on same architecture 3. Vary ℓ1 regularization strength to find optimal balance

## Limitations
- Theoretical guarantees for Gibbs sampler convergence in this specific hierarchical Bayesian model are lacking
- Computational complexity of MCMC-based approach compared to gradient-based methods not fully characterized
- Generalization performance across diverse datasets beyond the three tested remains unverified

## Confidence
- **High confidence**: MMeLU activation function improves classification accuracy (94% on Fashion-MNIST) and convergence speed
- **Medium confidence**: Bayesian framework provides better parameter estimation than gradient-based methods for this specific problem
- **Low confidence**: Claims about robustness to regularization are supported but not thoroughly validated across different regularization strengths and architectures
