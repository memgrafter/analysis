# Leveraging Cross-Utterance Context For ASR Decoding

## Quick Facts
- arXiv ID: 2306.16903
- Source URL: https://arxiv.org/abs/2306.16903
- Authors: 
- Reference count: 0
- Key outcome: Cross-utterance beam search reduces WER by 0.7% on AMI dev set and 0.3% on test set using 500 tokens of context

## Executive Summary
This paper demonstrates that incorporating cross-utterance context during beam search decoding significantly improves ASR performance compared to single-utterance decoding or post-hoc rescoring. The approach uses a transformer language model with key-value caching and multi-query attention to efficiently incorporate up to 500 tokens of preceding context during the initial decoding pass. Results on the AMI meeting corpus show consistent WER reductions across different context lengths, with beam search proving more effective than rescoring for utilizing contextual information.

## Method Summary
The method extends standard beam search decoding by incorporating a transformer language model that maintains and utilizes cross-utterance context through key-value caching. The system processes speech through a Conformer encoder with CTC, then performs beam search where TLM scores are combined with acoustic model scores at each decoding step. The TLM uses multi-query attention for efficiency and caches keys/values to avoid recomputation, enabling linear memory growth with context length. Context is incorporated by prepending previous utterance tokens to the current input sequence during decoding.

## Key Results
- AMI dev set: 0.7% absolute WER reduction using cross-utterance beam search vs single-utterance
- AMI test set: 0.3% absolute WER reduction with cross-utterance context
- 500 tokens of context provides optimal performance, with diminishing returns beyond this point
- Beam search outperforms n-best rescoring for cross-utterance context utilization

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Cross-utterance context improves ASR performance by providing additional linguistic context that helps disambiguate speech recognition hypotheses.
- Mechanism: The transformer language model (TLM) incorporates up to 500 tokens of preceding context during beam search decoding, allowing it to leverage information from previous utterances to inform current recognition decisions.
- Core assumption: Linguistic information from previous utterances remains relevant and helpful for recognizing current speech.
- Evidence anchors:
  - [abstract] "Results demonstrate that beam search allows for an improved use of cross-utterance context. When evaluating on the long-format dataset AMI, results show a 0.7% and 0.3% absolute reduction on dev and test sets compared to the single-utterance setting"
  - [section] "For both dev and test dataset on AMI when decoding via beams search we see around an additional 0.1% absolute decrease when using the GTH across all context lengths"
  - [corpus] Weak - corpus analysis shows related work on cross-utterance ASR but limited direct evidence for 500-token context effectiveness
- Break condition: Context becomes irrelevant when topic changes significantly, speaker changes occur, or errors in the context propagate incorrectly to current decoding.

### Mechanism 2
- Claim: Beam search outperforms n-best rescoring for incorporating cross-utterance context because it maintains multiple hypotheses throughout the search process.
- Mechanism: Beam search maintains a set of top hypothesis paths simultaneously, allowing the TLM to influence the search at each time step rather than just re-ranking post-hoc.
- Core assumption: Multiple hypothesis maintenance during search provides more opportunities for context to influence recognition decisions than post-hoc re-ranking.
- Evidence anchors:
  - [abstract] "Results demonstrate that beam search allows for an improved use of cross-utterance context"
  - [section] "For decoding via beam search on AMI we see sizeable improvement over re-scoring, both in the utilisation of context, and more generally in the single-utterance setting"
  - [corpus] Moderate - corpus shows prior work on cross-utterance rescoring but limited comparative evidence between beam search and rescoring approaches
- Break condition: When the hypothesis space becomes too large to maintain effectively, or when the first-pass model dominates decision-making sufficiently that second-pass context provides minimal benefit.

### Mechanism 3
- Claim: Key-value caching and multi-query attention make long-context decoding computationally feasible.
- Mechanism: By caching attention keys and values from previous tokens and using single-head attention for keys/values, the system avoids recomputing expensive attention operations while maintaining linear memory growth.
- Core assumption: Attention computations can be cached without loss of accuracy because the causal nature of language modeling prevents future tokens from updating past states.
- Evidence anchors:
  - [section] "This enables efficient cross-utterance decoding using TLMs with a linear increase in memory for each token in the cache"
  - [section] "When decoding incrementally with a batch size of 25 and cache/history size of 500 tokens, this improves our iteration time by 74%"
  - [corpus] Strong - related work on transformer-XL and efficient transformer decoding provides direct evidence for these architectural choices
- Break condition: When cache size exceeds available memory, or when the computational savings are outweighed by other bottlenecks in the system.

  - Quick check question: How does beam search balance between exploration (maintaining diverse hypotheses) and exploitation (focusing on high-scoring paths)?

  - Why needed here: The paper relies on transformer attention to propagate context information across utterances, requiring understanding of how attention weights are computed and how caching works

  - Why needed here: The system combines acoustic model scores with TLM scores using weighted addition, requiring understanding of how these different probability distributions are combined

## Architecture Onboarding

- Component map: Acoustic model (Conformer encoder with CTC) → Beam search decoder → Transformer language model (with key-value caching and multi-query attention) → Output hypotheses
- Critical path: Input speech → Acoustic model predictions → Beam search with TLM scores → Final hypothesis selection
- Design tradeoffs: Computational efficiency (caching, multi-query) vs. potential accuracy loss; context length (500 tokens) vs. memory usage; beam width (25) vs. search completeness
- Failure signatures: Degraded performance with long contexts (context becomes irrelevant); poor performance on Tedlium vs. AMI (dataset-specific factors); WER increases with 500 tokens on Tedlium (context errors propagate)
- First 3 experiments:
  1. Implement single-utterance beam search with TLM and verify baseline WER improvement over greedy decoding
  2. Add key-value caching and measure computational speedup while maintaining accuracy
  3. Extend to cross-utterance decoding with 50 tokens of context and measure performance gains over single-utterance baseline

## Limitations
- Results are primarily demonstrated on AMI meeting corpus and show smaller improvements on Tedlium-1, suggesting domain sensitivity
- No analysis of how context relevance degrades with distance or when context becomes irrelevant
- Limited investigation of error propagation from prior context to current decoding
- Findings may not generalize to domains with different conversational patterns or acoustic conditions

## Confidence

**High Confidence**: The computational efficiency claims regarding key-value caching and multi-query attention are well-supported by established transformer-XL literature and the reported 74% iteration time improvement provides concrete evidence.

**Medium Confidence**: The superiority of beam search over n-best rescoring for cross-utterance context utilization is demonstrated on AMI but requires validation on additional datasets and ASR architectures to establish generality.

**Medium Confidence**: The claim that 500 tokens represents an optimal context length is based on empirical observation but lacks theoretical justification or analysis of the trade-offs between context relevance, memory usage, and computational cost.

**Low Confidence**: The generalization of these findings to domains with different conversational patterns, acoustic conditions, or topic structures has not been established and may be limited.

## Next Checks

1. **Context Relevance Analysis**: Conduct ablation studies systematically varying context length (50, 100, 250, 500, 1000 tokens) across multiple diverse datasets to identify optimal context windows for different domain types and quantify the relationship between context distance and relevance decay.

2. **Error Propagation Characterization**: Implement error tracking mechanisms to measure how often and under what conditions errors in prior context propagate to current utterance recognition, and test whether error detection/correction mechanisms can mitigate this issue.

3. **Cross-Domain Robustness Testing**: Evaluate the cross-utterance beam search approach on challenging, diverse datasets including telephone speech, noisy environments, multi-speaker scenarios, and non-conversational domains to establish domain-specific performance bounds and identify failure modes.
