# MELT: Mutual Enhancement of Long-Tailed User and Item for Sequential Recommendation

## Quick Facts
- arXiv ID: 2304.08382
- Source URL: https://arxiv.org/abs/2304.08382
- Authors: 
- Reference count: 36
- Primary result: Achieves up to 24.5% and 14.6% improvements in Hit@10 for tail users and items respectively, without sacrificing head performance

## Executive Summary
MELT addresses the long-tailed user and item problems in sequential recommendation systems by introducing a model-agnostic framework that jointly alleviates both issues. The approach uses bilateral branches - one for users and one for items - that mutually enhance each other through iterative refinement. By leveraging knowledge from head users and items to improve representations of tail users and items, MELT significantly improves performance on the most challenging cases while maintaining strong results on well-represented cases. The framework is integrated with curriculum learning to stabilize training and ensure effective knowledge transfer.

## Method Summary
MELT is a model-agnostic framework that jointly addresses long-tailed user and item problems in sequential recommendation. It consists of two bilateral branches: a user branch that enhances tail user representations using knowledge from head users, and an item branch that enhances tail item representations using knowledge from head items. These branches are trained to mutually enhance each other through an iterative process where the user branch uses an item embedding generator trained on head items to enhance tail item representations in user sequences, and the item branch uses a user embedding generator trained on head users to enhance tail user representations in item subsequences. The framework employs curriculum learning to stabilize training by controlling the difficulty of examples based on interaction counts, gradually shifting focus from easy cases (head users/items with many interactions) to harder cases (tail users/items with few interactions). MELT can be seamlessly integrated with any sequential recommendation model by enhancing the embeddings used in the underlying model's prediction mechanism.

## Key Results
- Outperforms state-of-the-art baselines by up to 24.5% in Hit@10 on tail users
- Achieves up to 14.6% improvements in Hit@10 on tail items
- Maintains strong performance on head users and items, avoiding the typical trade-off between head and tail performance
- Validated across eight real-world datasets including Amazon, Foursquare, and Behance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Mutual enhancement between user and item branches allows each to improve the other's representation quality for tail cases.
- Mechanism: The user branch uses an item embedding generator trained on head items to enhance tail item representations in user sequences. Conversely, the item branch uses a user embedding generator trained on head users to enhance tail user representations in item subsequences. These updates occur iteratively in an end-to-end manner.
- Core assumption: The knowledge learned from head users/items can be effectively transferred to improve tail user/item representations through the embedding generators.
- Evidence anchors:
  - [abstract] "the branches are trained to mutually enhance each other, which is trained effectively by a curriculum learning-based training."
  - [section] "the user branch utilizes the knowledge contained in the item embedding generator... Similarly, the item branch utilizes the knowledge contained in the user embedding generator..."
- Break condition: If the knowledge transfer between branches fails or if the embedding generators cannot effectively capture the complementary information needed for mutual enhancement.

### Mechanism 2
- Claim: Curriculum learning stabilizes the knowledge transfer from head to tail cases by controlling the difficulty of training examples.
- Mechanism: The loss coefficients for head users and items are weighted based on the number of interactions (sequence length or number of subsequences). At early epochs, the model focuses more on head cases with many interactions, then gradually shifts attention to harder cases with fewer interactions as training progresses.
- Core assumption: Learning from easier cases first provides a better foundation for transferring knowledge to harder cases, preventing instability in the learning process.
- Evidence anchors:
  - [abstract] "which is trained effectively by a curriculum learning-based training."
  - [section] "we propose a curriculum learning (CL) strategy that gradually trains the model from easy (i.e., large |S_u|, |C_i|) to hard (i.e., small |S_u|, |C_i|)."
- Break condition: If the curriculum learning schedule doesn't align with the actual difficulty progression, or if early focus on easy cases creates a bias that's hard to overcome later.

### Mechanism 3
- Claim: Model-agnostic design allows MELT to be integrated with any sequential recommendation model without architectural constraints.
- Mechanism: MELT operates by enhancing the item embeddings in user sequences and user representations in item subsequences, then using these enhanced representations with any underlying sequential recommendation model's prediction mechanism. The enhancement process is independent of the specific sequence encoder used.
- Core assumption: The enhancement process can be applied regardless of how the underlying model generates user/item representations, as long as those representations can be accessed and modified.
- Evidence anchors:
  - [abstract] "MELT is model-agnostic in that it can be seamlessly integrated with existing SRS models."
  - [section] "MELT is a model-agnostic framework that is applicable to any SRS models to address the long-tailed problems."
- Break condition: If the underlying sequential recommendation model's architecture doesn't allow easy access to or modification of embeddings, or if the enhancement process conflicts with the model's internal representation learning.

## Architecture Onboarding

- Component map:
  - Sequence encoder (e.g., SASRec, FMLP) -> produces initial user/item representations
  - User branch -> embedding generator G_U that enhances tail user representations using head user knowledge
  - Item branch -> embedding generator G_I that enhances tail item representations using head item knowledge
  - Curriculum learning controller -> adjusts loss weights based on interaction counts
  - Mutual enhancement connections -> bidirectional flow between branches (Equations 10 and 12)

- Critical path: User sequence -> sequence encoder -> user representation -> (if tail user) G_U enhancement -> dot product with enhanced item representations -> recommendation score
- Design tradeoffs:
  - Single-layer vs multi-layer embedding generators (Figure 7 shows single-layer works well)
  - How to split head/tail (α=20% vs 50% as in paper)
  - Loss weight balance (λ_U and λ_I) between enhancement branches and recommendation loss
  - Random sampling parameters (R for subsequences, K for item interactions)

- Failure signatures:
  - Tail performance doesn't improve despite training - likely issue with embedding generators or mutual enhancement
  - Overall performance drops - curriculum learning schedule may be too aggressive or loss weights unbalanced
  - Head performance degrades significantly - mutual enhancement may be over-correcting or model complexity too high

- First 3 experiments:
  1. Baseline test: Run with all MELT components disabled (equivalent to SASRec/FMLP) to establish performance floor
  2. Single branch test: Enable only user branch or only item branch to measure isolated impact on tail users/items
  3. Mutual enhancement test: Enable both branches but disable the mutual enhancement (Equation 12) to measure its contribution to overall performance

## Limitations
- The curriculum learning schedule's effectiveness may depend heavily on dataset characteristics, with the choice of head/tail split ratio appearing somewhat arbitrary
- The embedding generators' architecture (single-layer feedforward networks) may be too simplistic to capture complex transfer patterns between head and tail cases
- Limited ablation studies on how sensitive the mutual enhancement is to curriculum learning schedule or head/tail split ratio
