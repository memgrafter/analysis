# SwinDepth: Unsupervised Depth Estimation using Monocular Sequences via Swin Transformer and Densely Cascaded Network

## Quick Facts
- arXiv ID: 2301.06715
- Source URL: https://arxiv.org/abs/2301.06715
- Reference count: 40
- Key outcome: Achieves Abs Rel of 0.106 on KITTI dataset, surpassing state-of-the-art unsupervised depth estimation methods while using fewer parameters

## Executive Summary
This paper addresses the challenge of unsupervised monocular depth estimation by introducing SwinDepth, a novel method that combines a hierarchical Swin Transformer with a Densely Cascaded Multi-scale Network (DCMNet). The approach leverages the Swin Transformer's window-based self-attention to capture both local geometric and global semantic features efficiently, while DCMNet improves feature interconnection through top-down cascade addition and dense concatenation. The method demonstrates superior performance on KITTI and Make3D datasets compared to existing state-of-the-art unsupervised depth estimation approaches.

## Method Summary
SwinDepth uses a convolution-free hierarchical Swin Transformer as the image feature extractor, replacing standard multi-head self-attention with window-based self-attention to reduce computational complexity while preserving both local geometric and global semantic features. The extracted features are then processed by DCMNet, which connects every feature map directly with another from different scales via a top-down cascade pathway and uses dense concatenation to reinforce decoding layer interconnections. The system jointly estimates depth maps and camera ego-motion using photometric reprojection loss, enabling training without ground truth depth labels.

## Key Results
- Achieves Abs Rel of 0.106, Sq Rel of 0.739, RMSE of 4.510, and RMSE log of 0.182 on KITTI dataset
- Outperforms competitive state-of-the-art methods including PackNet-SfM, ADORN, and Jacinle
- Demonstrates superior performance while using fewer model parameters than competing approaches
- Shows strong results on Make3D dataset with Abs Rel of 0.283 and RMSE of 7.560

- Mechanism: The Swin Transformer uses patch merging to progressively reduce feature resolution and calculates self-attention within fixed-size non-overlapping windows, limiting attention computation to linear complexity instead of quadratic
- Core assumption: Window-based self-attention can effectively capture necessary visual context for depth estimation without global attention

- Core assumption: Direct feature connections between different scales and layers preserve more information than traditional skip connections alone

## Architecture Onboarding

- Component map: RGB image → Swin Transformer → DCMNet → Depth maps + Pose network → Photometric loss calculation
- Critical path: Image → Swin Transformer → DCMNet → Depth maps + Pose network → Photometric loss calculation
- Design tradeoffs:
  - Swin Transformer vs ConvNet: Better feature representation vs established robustness
  - Window size (w=4): Computational efficiency vs context capture ability
  - Dense concatenation: Better feature flow vs increased parameter count
  - Multi-scale outputs: More comprehensive predictions vs training complexity
- Failure signatures:
  - Blurry object boundaries: Likely issues with window size or downsampling
  - Missing small objects: Feature resolution too coarse or attention windows too large
  - Texture copy artifacts: Photometric loss not handling occlusions properly
  - Scale ambiguity: Missing proper scale normalization in evaluation
- First 3 experiments:
  1. Replace Swin Transformer with ResNet-18 backbone while keeping DCMNet architecture identical to verify the feature extractor contribution
  2. Remove top-down cascade addition from DCMNet to measure its specific impact on performance
  3. Train with synthetic data containing known depth ground truth to validate the unsupervised training methodology independently
