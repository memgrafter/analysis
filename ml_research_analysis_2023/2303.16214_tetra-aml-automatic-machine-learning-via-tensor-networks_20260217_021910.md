# Tetra-AML: Automatic Machine Learning via Tensor Networks

## Quick Facts
- arXiv ID: 2303.16214
- Source URL: https://arxiv.org/abs/2303.16214
- Reference count: 0
- Primary result: Achieved 93.7% accuracy on CIFAR-10, outperforming Bayesian optimization (93.5%) and random search (92.8%) with same number of model runs

## Executive Summary
Tetra-AML is an automatic machine learning toolbox that automates neural architecture search and hyperparameter optimization using a tensor train optimization algorithm (TetraOpt). The framework also provides model compression through quantization, pruning, and tensor network decomposition. The authors demonstrate their approach on CIFAR-10 classification, achieving state-of-the-art performance while enabling significant model compression, reducing ResNet-18 memory by 14.5x with only 3.2% accuracy loss.

## Method Summary
Tetra-AML combines neural architecture search (NAS) and hyperparameter optimization (HPO) using TetraOpt, a tensor train-based black-box optimizer. The method searches through a predefined space of neural network architectures while optimizing hyperparameters in parallel. For model compression, Tetra-AML employs tensor network decomposition to break down large weight tensors into smaller interconnected tensors, achieving exponential parameter reduction. The framework supports hardware acceleration on GPUs and TPUs, with potential extension to quantum hardware.

## Key Results
- Achieved 93.7% accuracy on CIFAR-10 compared to 93.5% with Bayesian optimization and 92.8% with random search using the same number of model runs
- Compressed ResNet-18 networks to 14.5x less memory with only 3.2% accuracy loss
- Demonstrated hardware acceleration capabilities with GPUs and TPUs
- Framework is extensible to quantum and hybrid quantum-classical machine learning models

## Why This Works (Mechanism)

### Mechanism 1
TetraOpt's tensor train optimization achieves higher accuracy than Bayesian optimization and random search using the same number of model runs. The mechanism uses tensor train decomposition to represent and optimize the high-dimensional hyperparameter space efficiently, enabling better exploration and exploitation compared to traditional methods. Core assumption: tensor train representation can capture relevant correlations while maintaining computational tractability. Break condition: if decomposition fails to maintain sufficient accuracy in representing the hyperparameter space or if the optimization landscape becomes too complex.

### Mechanism 2
Tensor network compression significantly reduces model size while maintaining accuracy. The mechanism breaks down large weight tensors into smaller, interconnected tensors, reducing parameters exponentially while preserving essential information. Core assumption: decomposed tensor representation can approximate original weight tensor well enough to maintain performance. Break condition: if decomposition fails to maintain sufficient accuracy in approximating original weights or if overhead outweighs compression benefits.

### Mechanism 3
Tetra-AML can be extended to quantum and hybrid quantum-classical machine learning models. The mechanism adapts tensor train optimization to run on quantum hardware, leveraging quantum parallelism and entanglement for more efficient hyperparameter space exploration. Core assumption: quantum hardware can provide speedup for tensor train optimization and the algorithm can be mapped effectively onto quantum circuits. Break condition: if quantum hardware doesn't provide significant speedup or if the algorithm cannot be effectively mapped onto quantum circuits.
