# Do Machine Learning Models Learn Statistical Rules Inferred from Data?

## Quick Facts
- arXiv ID: 2303.01433
- Source URL: https://arxiv.org/abs/2303.01433
- Reference count: 9
- Primary result: Framework detects 1.5K-26K rule violations in state-of-the-art models and reduces violations by up to 68.7% with test-time adaptation

## Executive Summary
This paper introduces SQRL, a framework that automatically generates statistical quantile rules from training data to capture "common sense" patterns and identify violations in machine learning model predictions. The framework can synthesize up to 300K rules across vision, tabular, and language datasets, uncovering significant violations in state-of-the-art models. By adapting models at test time based on rule violations, SQRL reduces violations by up to 68.7% while improving performance by up to 32%.

## Method Summary
SQRL combines logic-based methods with statistical inference to automatically generate valid and expressive rules without human supervision. The framework generates rules by computing statistical thresholds over training data using rule schemas, then evaluates model predictions against these rules. During test-time adaptation, the model is fine-tuned only on batch normalization layers using a loss function based on rule violations. The approach works across diverse domains including vision, tabular, and language settings.

## Key Results
- Generated up to 300K rules across vision, tabular, and language datasets
- Uncovered 1.5K-26K violations in state-of-the-art models
- Test-time adaptation reduced violations by up to 68.7% while improving performance by up to 32%
- Successfully identified violations in complex tasks including bounding box aspect ratios and F1 scores

## Why This Works (Mechanism)

### Mechanism 1
- Quantile rules automatically capture valid and expressive "common sense" patterns without human supervision.
- The framework generates rules by computing statistical thresholds over training data, ensuring validity by construction (99th percentile bounds) and expressivity through complex statistics.
- Core assumption: Training data contains representative examples of valid patterns that can be captured by quantile statistics.

### Mechanism 2
- Test-time adaptation using rule violations can improve model performance while reducing rule violations.
- The framework computes a loss based on rule violations and performs back-propagation only on batch normalization layers to adapt the model at test time.
- Core assumption: Fine-tuning only batch normalization layers is sufficient to reduce rule violations without overfitting.

### Mechanism 3
- The framework can scale to generate hundreds of thousands of rules across diverse domains.
- Using rule schemas and logic-based enumeration followed by statistical inference, the framework automatically generates and validates rules without human supervision.
- Core assumption: The rule schema provides sufficient guidance to generate meaningful rules across different domains.

## Architecture Onboarding

- Component map: Rule generation module -> Rule evaluation module -> Test-time adaptation module
- Critical path:
  1. Generate rules from training data using schema
  2. Evaluate model predictions against rules
  3. Adapt model at test time to reduce violations
- Design tradeoffs:
  - Fine-tuning only batch normalization layers vs. whole model (faster, less overfitting vs. potentially more effective)
  - Rule schema expressiveness vs. computational complexity (more expressive schemas generate more rules but are slower)
- Failure signatures:
  - Few or no rules generated (schema too restrictive or data too noisy)
  - High rule violation rates (model doesn't capture common sense, or rules are too strict)
  - Adaptation doesn't reduce violations (model architecture incompatible, or rules not well-correlated with performance)
- First 3 experiments:
  1. Generate rules from a small, well-understood dataset and manually verify a sample for validity
  2. Evaluate a simple model (e.g., logistic regression) against generated rules and analyze violations
  3. Adapt the model at test time using the framework and measure reduction in rule violations

## Limitations
- Framework performance heavily depends on representativeness of training data for generating valid rules
- Effectiveness of test-time adaptation contingent on correlation between rule violations and model performance
- Restriction to batch normalization layer adaptation may limit ability to address fundamental model issues

## Confidence
- High: The framework can generate and apply quantile rules across diverse domains (vision, tabular, language)
- Medium: Test-time adaptation using batch normalization layers can reduce rule violations while improving performance
- Medium: The combination of logic-based methods and statistical inference enables automatic rule generation without human supervision
