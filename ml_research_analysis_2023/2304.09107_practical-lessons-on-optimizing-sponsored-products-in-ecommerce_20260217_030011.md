# Practical Lessons on Optimizing Sponsored Products in eCommerce

## Quick Facts
- arXiv ID: 2304.09107
- Source URL: https://arxiv.org/abs/2304.09107
- Reference count: 4
- Primary result: Framework improves AUROC/AUPRC for sponsored products while maintaining compatibility with existing ML models

## Executive Summary
This paper presents a practical machine learning framework for optimizing sponsored products in eCommerce that addresses three critical challenges: position-based bias, click-conversion multi-task learning, and pCTR calibration. The framework uses data and feature engineering approaches that work with existing models without requiring structural changes, making it compatible with both shallow models like GBDT and deep learning approaches. Evaluated on Walmart.com's traffic logs, the framework demonstrates improvements across multiple metrics including AUROC, AUPRC, expected CTR, cost per thousand views, return on ad spend, and diversity measures in both offline and online experiments.

## Method Summary
The framework tackles position-based bias through instance weighting using polynomial, logarithmic, or inverse propensity functions, combined with bucket-level history-based features at row and batch levels. For click-conversion multi-task learning, it implements stochastic label aggregation (randomly keeping one label between CTR and CTCVR) and instance weighting (reducing weight of clicked-but-not-converted items). Price squashing is applied to calibrate predicted click-through rates by adding an exponent to CTR values. The approach is model-agnostic, requiring no structural changes to existing ML models, and was trained on 23 days of Walmart.com traffic data with 7 days of testing.

## Key Results
- Offline experiments showed AUROC and AUPRC improvements for ads both among search results and below search results
- Online experiments with 30% traffic demonstrated framework outperformed production model across all evaluation metrics
- Improvements observed in expected CTR, cost per thousand views, return on ad spend, and diversity measures (distinct sellers and ad items)

## Why This Works (Mechanism)
The framework works by addressing systematic biases and learning challenges inherent in sponsored product advertising. Position-based bias is mitigated through instance weighting that adjusts for position effects, while bucket-level history features capture temporal patterns. Multi-task learning is stabilized through stochastic label aggregation and instance weighting, preventing model collapse to single-task optimization. Price squashing addresses the non-linear relationship between price and conversion likelihood, improving calibration of predicted CTR values.

## Architecture Onboarding
- **Component map**: Data preprocessing -> Instance weighting + bucket features -> Multi-task learning -> Price squashing -> Model training
- **Critical path**: The core pipeline flows from data preparation through position-based bias correction, multi-task learning optimization, and final calibration
- **Design tradeoffs**: Flexibility vs complexity tradeoff in choosing between stochastic aggregation and instance weighting for multi-task learning; simpler price squashing vs more complex calibration methods
- **Failure signatures**: Overfitting indicated by validation AUROC/AUPRC gap; poor calibration shown by mismatch between predicted and observed CTR; task collapse detected by one-sided performance improvement
