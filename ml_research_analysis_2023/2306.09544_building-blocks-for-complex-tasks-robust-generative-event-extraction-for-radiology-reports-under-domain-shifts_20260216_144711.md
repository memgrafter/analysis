# Building blocks for complex tasks: Robust generative event extraction for radiology reports under domain shifts

## Quick Facts
- **arXiv ID**: 2306.09544
- **Source URL**: https://arxiv.org/abs/2306.09544
- **Reference count**: 7
- **Primary result**: Generative event extraction method achieves comparable or better performance than larger models while using fewer decoding passes across three radiology modalities

## Executive Summary
This paper introduces a generative approach for event extraction from radiology reports that improves generalization across exam modalities while reducing inference costs. The method employs T5-based text-to-text generative models with a novel building block format that decomposes complex tasks into subtask blocks, enabling better performance with smaller models. The approach also incorporates target-domain contexts during inference to enhance domain adaptation. Experimental results on radiology reports from three modalities (CT, MRI, PET) show that the method achieves comparable or better performance than larger models while using fewer decoding passes, with particularly strong results on anatomy normalization tasks under domain shifts.

## Method Summary
The proposed method uses T5-based text-to-text generative models with a novel building block format for event extraction. This format decomposes complex extraction tasks into simpler subtask blocks, allowing smaller models to achieve competitive performance. The approach incorporates target-domain contexts during inference to improve domain adaptation. The method employs a block decomposition strategy where each block handles a specific aspect of the extraction task, such as anatomy identification or finding extraction. This modular approach enables the model to focus on simpler, more manageable subtasks rather than attempting to extract all information in a single pass. The building block format is designed to be flexible and adaptable to different domains and tasks while maintaining efficiency.

## Key Results
- The building block approach achieves comparable or better performance than larger models while using fewer decoding passes
- Strong performance on anatomy normalization tasks under domain shifts across CT, MRI, and PET modalities
- Target-domain contexts during inference significantly enhance domain adaptation performance
- The method reduces inference costs while maintaining or improving extraction quality

## Why This Works (Mechanism)
The building block format works by decomposing complex extraction tasks into simpler, more manageable subtasks that can be handled by smaller models. This decomposition allows the model to focus on specific aspects of the extraction task, reducing the cognitive load and enabling better generalization. The text-to-text generative approach allows for flexible output formats that can be tailored to specific extraction needs. By incorporating target-domain contexts during inference, the model can adapt to domain-specific terminology and patterns without requiring extensive retraining. The modular nature of the building blocks enables efficient processing and reduces the number of decoding passes needed for complete extraction.

- **Subtask decomposition**: Breaking down complex tasks into simpler components is a core principle that enables the building block approach.
- **Domain shift challenges**: Recognizing how distribution differences between training and target domains affect model performance is essential for understanding the problem being addressed.

## Architecture Onboarding

**Component Map**: Input text -> Building block decomposition -> T5 model processing -> Domain context integration -> Structured output generation

**Critical Path**: The critical path involves decomposing the input text into building blocks, processing each block through the T5 model, integrating domain contexts, and generating structured outputs. The most time-sensitive components are the model inference and domain context integration steps.

**Design Tradeoffs**: The approach trades model size for efficiency, using smaller models with the building block format rather than larger monolithic models. This reduces computational costs but may limit the model's ability to capture very complex relationships. The decomposition into subtasks may introduce some information loss compared to end-to-end approaches, but this is offset by improved generalization and efficiency.

**Failure Signatures**: Potential failures include incorrect decomposition of complex relationships, domain context integration errors, and performance degradation when tasks cannot be cleanly separated into subtasks. The method may struggle with highly interdependent extraction tasks that require holistic understanding.

## Limitations
- The evaluation is limited to three radiology modalities (CT, MRI, PET), which may not generalize to other medical domains or broader text extraction tasks
- The building block approach may face scalability challenges with more complex or interdependent extraction scenarios
- The comparison against larger models only evaluates a single size reduction path, leaving questions about performance at different model scales
- The method's effectiveness with tasks requiring complex inter-task dependencies has not been fully explored

## Confidence
- **High Confidence**: The core finding that target-domain contexts during inference improve domain adaptation performance is well-supported by the experimental results and aligns with established domain adaptation principles
- **Medium Confidence**: The claim about reduced inference costs through fewer decoding passes is supported but could benefit from more comprehensive timing benchmarks across different hardware configurations
- **Medium Confidence**: The assertion that the building block format enables better generalization under domain shifts is demonstrated but may be partially attributable to the specific task decomposition rather than the format itself
