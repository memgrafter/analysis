# Multi-Target Landmark Detection with Incomplete Images via Reinforcement Learning and Shape Prior

## Quick Facts
- **arXiv ID**: 2301.05392
- **Source URL**: https://arxiv.org/abs/2301.05392
- **Reference count**: 40
- **Primary result**: RL-based multi-agent framework achieves 2.29 cm error on body DXA with 80% missing training data

## Executive Summary
This paper introduces a novel reinforcement learning framework for detecting multiple anatomical landmarks in incomplete medical images. The approach employs a multi-agent system where each agent learns to navigate toward a specific landmark using a combination of visual observations and shape priors. The method alternates between training a DeepMaQ network for navigation policy and a DeepSSM network for shape guidance, enabling robust landmark detection even when up to 80% of training data is missing. Experiments across five clinical datasets demonstrate superior performance compared to traditional methods, with particular success in detecting landmarks outside the field of view.

## Method Summary
The proposed framework consists of a multi-agent reinforcement learning system where each agent is responsible for locating a specific anatomical landmark. Agents navigate through the image space using visual features extracted by a DeepMaQ network, which learns navigation policies through Q-learning. Simultaneously, a DeepSSM network captures shape constraints and guides the agents toward anatomically plausible landmark configurations. The two networks are trained alternately: DeepMaQ learns the navigation policy while DeepSSM learns shape priors, then DeepMaQ is updated using the shape guidance from DeepSSM. This iterative process allows the system to progressively refine both navigation strategies and shape understanding, resulting in robust landmark detection even with significant amounts of missing training data.

## Key Results
- Achieved 2.29 cm landmark detection error on body DXA with 80% missing training data
- Successfully detected landmarks outside the field of view with 6.84 mm error on 3D half-head CT
- Demonstrated robustness across five different clinical datasets with various incompleteness scenarios

## Why This Works (Mechanism)
The method works by decomposing the landmark detection problem into multiple reinforcement learning agents that learn both visual navigation and anatomical constraints. The DeepMaQ network enables agents to learn efficient search policies based on visual features, while the DeepSSM network captures global shape relationships between landmarks. The alternating training scheme allows each component to specialize: DeepMaQ becomes proficient at local navigation while DeepSSM learns global anatomical coherence. This separation of concerns enables the system to handle incomplete data by leveraging learned shape priors when visual information is missing, and to generalize to unseen landmarks by combining local visual search with global anatomical knowledge.

## Architecture Onboarding
**Component Map**: DeepMaQ -> DeepSSM -> Landmark Agents
**Critical Path**: Visual feature extraction → Q-learning navigation → Shape constraint application → Landmark prediction
**Design Tradeoffs**: Alternating training provides specialization but increases computational cost; separate networks enable modularity but require synchronization
**Failure Signatures**: Poor navigation policies when visual features are ambiguous; shape model failure when anatomical variability exceeds training coverage
**First Experiments**: 1) Single landmark detection with complete data, 2) Multi-landmark detection with synthetic missing data, 3) Cross-dataset generalization test
