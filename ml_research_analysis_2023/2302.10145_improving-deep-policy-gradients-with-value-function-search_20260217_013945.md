# Improving Deep Policy Gradients with Value Function Search

## Quick Facts
- arXiv ID: 2302.10145
- Source URL: https://arxiv.org/abs/2302.10145
- Reference count: 16
- One-line result: VFS improves sample efficiency and policy performance across PPO, DDPG, and TD3 by periodically searching for better value function approximations

## Executive Summary
This paper addresses the fundamental limitation of Deep Policy Gradient (PG) algorithms where value function approximation gets stuck in local optima, leading to suboptimal policy performance. The authors introduce Value Function Search (VFS), a gradient-free population-based approach that periodically generates perturbed value networks to search for better approximations. VFS uses two-scale perturbations - small-scale for local exploration and large-scale for escaping local optima - without requiring additional environment interactions or ensembles. Experiments on continuous control benchmarks demonstrate that VFS significantly improves sample efficiency and policy performance across PPO, DDPG, and TD3 algorithms.

## Method Summary
VFS periodically generates a population of perturbed value networks using two-scale Gaussian perturbations (small-scale σmin=0.000005 for local exploration, large-scale σmax=0.0005 for escaping local optima). Each perturbed network is evaluated using mean squared error on a batch of trajectories from the agent's buffer, and the best-performing network replaces the agent's critic. This process maintains the same convergence guarantees as baseline algorithms while improving value function approximation without additional environment interactions or computational overhead from ensembles.

## Key Results
- VFS-PPO achieves 26% return improvement and uses 33% fewer samples to reach peak performance compared to PPO
- VFS-DDPG and VFS-TD3 show similar improvements in sample efficiency and policy returns
- Analysis reveals VFS improves gradient estimates, reduces variance, and lowers value prediction errors
- VFS maintains the same convergence guarantees as baseline Deep PG algorithms

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Two-scale perturbations in VFS improve value function approximation by escaping local optima and refining local predictions.
- Mechanism: Small-scale perturbations (σmin) maintain similar value predictions to the original critic while exploring local parameter variations. Large-scale perturbations (σmax) explore diverse value predictions to escape local optima where standard value networks get stuck.
- Core assumption: Value networks in Deep PG algorithms get stuck in local optima and struggle to fit the actual return, limiting variance reduction efficacy.
- Evidence anchors: Abstract states value function approximation gets stuck in local optima; section describes expected behavior of σmin vs σmax perturbations.
- Break condition: If value networks consistently achieve low MSE without perturbations, or if perturbations consistently degrade performance.

### Mechanism 2
- Claim: VFS improves Deep PG primitives by reducing value prediction errors and gradient estimate variance.
- Mechanism: By periodically searching for better value network parameters using a population-based approach, VFS finds critics that better approximate the true value function. This leads to improved gradient estimates with lower variance and better correlation with the true gradient.
- Core assumption: Improving value function approximation directly translates to better policy performance through improved gradient estimates.
- Evidence anchors: Abstract mentions improved sample efficiency and policies with higher returns; section describes VFS's critic-based design addressing prior method limitations.
- Break condition: If improved value predictions do not translate to better gradient estimates or policy performance.

### Mechanism 3
- Claim: VFS maintains the same convergence guarantees as baseline Deep PG algorithms while improving performance.
- Mechanism: VFS uses the same objective (MSE) and data from the agent's buffer as standard Deep PG training. The perturbation annealing strategy allows VFS to match baseline convergence in the limit.
- Core assumption: Monte-Carlo value approximation converges to a local optimum even when using non-linear approximation, and VFS preserves this property.
- Evidence anchors: Section states Monte-Carlo value approximation converges to local optimum; worst-case scenario matches baseline local optima.
- Break condition: If VFS consistently converges to worse local optima than the baseline, or if annealing does not preserve convergence properties.

## Architecture Onboarding

- Component map:
  Deep PG agent (actor-critic) -> Value Function Search module (Population generator, Evaluation, Selection) -> Updated critic -> Policy training

- Critical path:
  1. Agent collects trajectories and updates policy/critic
  2. VFS periodically generates perturbed value networks
  3. Evaluate each perturbed network using MSE on batch from buffer
  4. Replace agent's critic with best-performing network
  5. Continue training with updated critic

- Design tradeoffs:
  - Population size vs. computational overhead
  - Perturbation scale (σmin vs. σmax) vs. exploration-exploitation balance
  - Frequency of VFS searches vs. training stability
  - Batch size for evaluation vs. robustness of error estimates

- Failure signatures:
  - Population search consistently fails to find better critics
  - Perturbations cause value predictions to diverge significantly
  - VFS increases training instability or reduces sample efficiency
  - Annealing perturbations leads to performance degradation

  3. Compare VFS with and without perturbation annealing to validate convergence claims

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does VFS's performance compare to ensemble methods like SUNRISE in terms of sample efficiency and final returns across a wider range of tasks?
- Basis in paper: The paper mentions comparing VFS to SUNRISE and achieving comparable or superior average performance, but the comparison is limited to specific environments and steps.
- Why unresolved: The paper only provides a limited comparison with SUNRISE, and a more comprehensive evaluation across diverse tasks would strengthen the case for VFS.
- What evidence would resolve it: Conducting experiments comparing VFS to SUNRISE on a wider range of continuous control benchmarks and reporting sample efficiency and final returns would provide a more definitive answer.

### Open Question 2
- Question: What is the theoretical relationship between the underlying theoretical framework of Deep PG and the practical tricks driving their performance, as suggested by the analysis of Deep PG primitives in VFS?
- Basis in paper: The paper mentions that the gap between the theoretical framework and practical implementation may be less significant than previously thought, but a deeper theoretical analysis is not provided.
- Why unresolved: The paper hints at a potential connection between theory and practice but does not delve into the theoretical underpinnings of this relationship.
- What evidence would resolve it: Developing a theoretical framework that bridges the gap between the theoretical assumptions of Deep PG and the practical considerations of VFS would provide a deeper understanding of the algorithm's effectiveness.

### Open Question 3
- Question: How does VFS perform in more complex tasks requiring high-dimensional DNNs or computationally demanding architectures, where parallelization may not be feasible?
- Basis in paper: The paper mentions that VFS is computationally efficient and does not require multiple training models or additional environment interactions, but its performance in highly complex tasks is not explored.
- Why unresolved: The paper focuses on standard continuous control benchmarks and does not address the scalability of VFS to more complex domains.
- What evidence would resolve it: Conducting experiments on challenging tasks with high-dimensional DNNs and evaluating VFS's performance and computational efficiency would provide insights into its scalability.

## Limitations

- Limited theoretical analysis of the relationship between Deep PG theory and practical implementation
- Performance evaluation restricted to standard continuous control benchmarks, not tested on highly complex tasks
- No comparison with other value function improvement methods beyond SUNRISE
