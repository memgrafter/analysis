# Learning the Relation between Similarity Loss and Clustering Loss in Self-Supervised Learning

## Quick Facts
- **arXiv ID**: 2301.03041
- **Source URL**: https://arxiv.org/abs/2301.03041
- **Reference count**: 40
- **Key outcome**: Combines similarity loss and cross-entropy loss in a new method called ICCL, achieving state-of-the-art results on ImageNet without needing centering or Sinkhorn-Knop algorithm, and showing less sensitivity to hyperparameters.

## Executive Summary
This paper analyzes the relationship between similarity loss and cross-entropy loss in self-supervised learning, proposing a new method called ICCL that combines both losses to improve representation learning. The authors show that their method outperforms state-of-the-art approaches like SwAV and DINO on ImageNet and other datasets while being simpler (no centering or Sinkhorn-Knop algorithm) and more robust to hyperparameter settings. The key insight is that cross-entropy loss can capture similarity between distinct images when the network has basic instance discrimination ability, and this can be combined effectively with similarity loss through appropriate temperature scaling.

## Method Summary
The ICCL method combines similarity loss (for instance-level discrimination) with a modified cross-entropy loss (for class-level information) in self-supervised learning. The approach uses a ResNet-50 backbone with projector and predictor MLPs, generating two augmented views per image. During training, it starts with similarity loss and transitions to a combined loss with adaptive temperature scaling (τ1 = ∥P(z2)∥) and a fixed temperature (τ2=0.07). The method also includes uniformity regularization and works without the centering mechanism used in DINO or the Sinkhorn-Knop algorithm used in SwAV.

## Key Results
- Achieves state-of-the-art performance on ImageNet, outperforming SwAV and DINO
- Works without centering mechanism (used in DINO) and Sinkhorn-Knop algorithm (used in SwAV)
- Shows less sensitivity to hyperparameters compared to existing methods
- Maintains strong performance across different batch sizes unlike pure contrastive methods

- Claim: Cross-entropy loss can capture similarity between distinct images if network has basic instance discrimination ability
- Mechanism: When minimizing cross-entropy, maximizing similarity between probability distributions of same-class instances is equivalent to capturing inter-instance similarity
- Core assumption: Network can already distinguish different instances at the feature level

## Architecture Onboarding

- Component map:
  - Input image → Two augmented views → Backbone (ResNet-50) → Projector MLP (3 layers, 256-dim) → Predictor MLP (2 layers, 256-dim) → Loss computation

- Critical path:
  1. Generate two augmented views of input image
  2. Pass through backbone → projector → predictor
  3. Compute similarity loss for initial training phase
  4. Switch to combined loss with adaptive temperature
  5. Apply uniformity regularization

- Design tradeoffs:
  - Simplicity vs performance: The method is simple but achieves SOTA results
  - Hyperparameter sensitivity: Adaptive temperature reduces sensitivity but requires careful tuning
  - Computational cost: No Sinkhorn-Knopf or centering mechanisms reduces computation

- Failure signatures:
  - Poor convergence: May indicate inappropriate temperature scaling

## Limitations

- The claim that cross-entropy loss can capture inter-instance similarity relies on the assumption that the network has basic instance discrimination ability, but this foundational capability is not empirically verified within the paper.
- The adaptive temperature scaling mechanism (τ1 = ∥P(z2)∥) lacks theoretical justification for why this specific form would reliably correlate gradient magnitudes between loss functions.
- The hyperparameter robustness claim is supported by experimental results but doesn't account for potential failure modes in different data regimes.
