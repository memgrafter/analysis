# Query-Dependent Video Representation for Moment Retrieval and Highlight Detection

## Quick Facts
- arXiv ID: 2303.13874
- Source URL: https://arxiv.org/abs/2303.13874
- Reference count: 40
- Primary result: Introduces QD-DETR with cross-attentive encoder, negative pair learning, and input-adaptive saliency predictor, achieving up to 11.84% improvement in moment retrieval mAP and 4.2% in highlight detection average mAP on benchmark datasets.

## Executive Summary
This paper addresses the problem of jointly performing video moment retrieval and highlight detection using natural language queries. The key limitation identified in existing transformer-based approaches is the insufficient use of query information for video representation, leading to poor alignment between query relevance and saliency scores. To tackle this, the authors propose Query-Dependent DETR (QD-DETR), which introduces a cross-attentive transformer encoder that explicitly injects query context into video features, negative pair learning to enforce distinct saliency predictions for relevant and irrelevant query-video pairs, and an input-adaptive saliency predictor based on a learnable saliency token. Extensive experiments show that QD-DETR significantly outperforms state-of-the-art methods on QVHighlights, TVSum, and Charades-STA datasets.

## Method Summary
The authors propose Query-Dependent DETR (QD-DETR), a transformer-based architecture that enhances query-video alignment for joint moment retrieval and highlight detection. The key innovations include a cross-attentive transformer encoder that injects query context into video features, negative pair learning that enforces distinct saliency predictions for relevant and irrelevant query-video pairs, and an input-adaptive saliency predictor based on a learnable saliency token. The architecture consists of a video encoder, cross-attentive encoder, saliency predictor, and output layers for moment retrieval and highlight detection. The model is trained end-to-end with a multi-task loss combining moment localization, saliency prediction, and contrastive loss for negative pairs.

## Key Results
- Achieves 11.84% improvement in moment retrieval mAP over state-of-the-art methods on QVHighlights dataset
- Improves highlight detection average mAP by 4.2% on QVHighlights benchmark
- Outperforms existing methods on TVSum and Charades-STA datasets with consistent gains across all metrics

## Why This Works (Mechanism)
The core insight is that existing transformer-based approaches insufficiently utilize query information for video representation, resulting in poor alignment between query relevance and saliency scores. QD-DETR addresses this by introducing a cross-attentive transformer encoder that explicitly injects query context into video features, allowing the model to dynamically adjust video representations based on the specific query. The negative pair learning component enforces distinct saliency predictions for relevant and irrelevant query-video pairs, creating a stronger contrastive signal. The input-adaptive saliency predictor with a learnable saliency token allows the model to generate query-specific saliency maps rather than using fixed attention patterns.

## Architecture Onboarding

Component map: Input video features -> Cross-attentive encoder -> Saliency predictor with learnable token -> Moment retrieval output + Highlight detection output

Critical path: The cross-attentive encoder is the critical component that enables query-dependent video representation. It takes video features and query embeddings as input, performs multi-head attention between them, and outputs enriched video features that explicitly incorporate query context. This enriched representation then flows to both the saliency predictor and the moment retrieval head.

Design tradeoffs: The authors trade increased model complexity (additional cross-attention layers and saliency token) for improved query-video alignment. The negative pair learning adds training complexity but provides stronger supervision. The input-adaptive saliency predictor requires additional parameters but enables query-specific highlight detection rather than fixed attention patterns.

Failure signatures: The model may struggle with ambiguous queries where multiple moments could be relevant, queries that require deep semantic understanding beyond visual features, or videos with complex temporal dynamics where highlight-worthy moments are subtle or distributed across long time spans.

## Limitations
- Generalizability across diverse video domains remains untested beyond the three evaluated datasets (instructional cooking videos, general web videos, and action-based videos)
- Computational efficiency considerations are not reported, leaving uncertainty about inference time and memory requirements
- Qualitative analysis gaps exist as the paper lacks detailed examples of challenging cases and failure modes

## Confidence
- High confidence: Architectural novelty is well-defined and technically sound with statistically significant experimental results on three benchmark datasets
- Medium confidence: State-of-the-art performance claims are well-supported for tested datasets but require validation on more diverse video domains
- Medium confidence: Ablation studies effectively demonstrate component contributions, though hyper-parameter sensitivity could be further explored
