# The challenge of redundancy on multi-agent value factorisation

## Quick Facts
- arXiv ID: 2304.00009
- Source URL: https://arxiv.org/abs/2304.00009
- Reference count: 10
- Primary result: RDN maintains consistent performance across varying redundancy levels in SMAC bane_vs_bane maps, while VDN and Qmix degrade

## Executive Summary
This paper addresses the problem of credit assignment inefficiency in cooperative multi-agent reinforcement learning when environments contain many redundant agents beyond those needed to optimally solve the task. The authors propose Relevance Decomposition Network (RDN), which uses layerwise relevance propagation (LRP) to separate joint value function learning from local reward generation. Unlike traditional methods like VDN and Qmix that rely on learned decomposition, RDN leverages LRP to decompose global rewards into agent-specific relevance scores based on local observations, actions, and identities. Experiments on SMAC bane_vs_bane map variants with varying numbers of redundant zerglings show that RDN maintains consistent performance regardless of redundancy levels, while VDN and Qmix performance degrades with increasing redundancy.

## Method Summary
RDN addresses credit assignment inefficiency in MARL by using LRP to decompose global rewards into agent-specific relevance scores based on local observations, actions, and identities. The method trains independent agent DQNs using these relevance scores as target Q-values, without learning value decomposition. RDN separates joint value function learning from local reward generation, using a critic network to estimate total Q-value and LRP to decompose this into agent-specific relevance scores. This two-stage process prevents the variance amplification seen in methods like VDN and Qmix, maintaining stable performance even with redundant agents.

## Key Results
- RDN maintains consistent winrates across SMAC bane_vs_bane map variants with 0, 10, 15, and original zergling counts
- VDN and Qmix performance degrades significantly as redundant zerglings increase
- RDN achieves this performance without using global state information, demonstrating robust credit assignment in highly redundant multi-agent settings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Layerwise Relevance Propagation (LRP) decomposes global reward into agent-specific relevance scores without learning value decomposition.
- Mechanism: LRP traces relevance backward through the critic network, assigning credit to input features based on their contribution to the final output. This produces stable, interpretable relevance scores for each agent's observation and action.
- Core assumption: The relationship between global and local rewards is approximately linear, allowing relevance propagation to approximate optimal credit assignment.
- Evidence anchors:
  - [abstract] "RDN leverages LRP to decompose global rewards into agent-specific relevance scores based on local observations, actions, and identities"
  - [section 2] "We use LRP to decompose the global reward calculated into local rewards for each agent"
  - [corpus] Weak evidence; LRP is mentioned in only one corpus neighbor with no direct comparison to RDN
- Break condition: If the global-local reward relationship becomes highly non-linear, LRP's linear assumptions fail and credit assignment becomes inaccurate.

### Mechanism 2
- Claim: Separating joint value function learning from local reward generation improves stability compared to end-to-end decomposition methods.
- Mechanism: RDN uses a critic network to estimate total Q-value, then applies LRP to decompose this into agent-specific targets. This two-stage process prevents the variance amplification seen in methods like VDN and Qmix.
- Core assumption: The critic network can accurately estimate total Q-value even with redundant agents, and this estimate is stable enough for LRP to produce meaningful decompositions.
- Evidence anchors:
  - [abstract] "RDN separates joint value function learning from local reward generation"
  - [section 2] "unlike most CTDE methods which use learned decomposition as an end-to-end system, RDN separates the learning of the global reward function from the local Q-values"
  - [corpus] No direct evidence; requires inference from methodology description
- Break condition: If the critic network cannot maintain accurate total Q-value estimates in highly redundant settings, the decomposed targets become unreliable.

### Mechanism 3
- Claim: RDN's performance is independent of redundancy levels because it doesn't rely on learned decomposition that struggles with varying agent importance.
- Mechanism: By using LRP instead of learned decomposition, RDN can assign appropriate credit to essential agents regardless of how many redundant agents are present, maintaining consistent performance.
- Core assumption: LRP can effectively distinguish between essential and redundant agents based on their contribution to the global reward.
- Evidence anchors:
  - [abstract] "RDN maintains consistent performance regardless of redundancy levels, while VDN and Qmix performance degrades"
  - [section 3] "From figure 1 we can see that across all maps RDN outperforms all baselines"
  - [corpus] No direct evidence; relies entirely on experimental results from the paper
- Break condition: If LRP cannot effectively separate essential from redundant agents (e.g., when all agents contribute equally), RDN's advantage disappears.

## Architecture Onboarding

- Component map:
  - Independent agent DQNs (DRQNs) for local action selection
  - Critic network for estimating total Q-value from concatenated observations/actions
  - LRP module for decomposing critic output into agent-specific relevance scores
  - Target networks for stable Q-learning updates

- Critical path:
  1. Agents observe environment and select actions using local DQNs
  2. Concatenated observations and actions fed to critic network
  3. Critic estimates total Q-value
  4. LRP decomposes total Q-value into agent-specific relevance scores
  5. Relevance scores become target Q-values for independent agent training

- Design tradeoffs:
  - Using LRP vs learned decomposition: RDN gains stability but may sacrifice some optimality if linear assumptions don't hold
  - Not using global state: RDN can work with only local observations but may miss some coordination signals
  - Two-stage vs end-to-end training: RDN separates concerns but requires maintaining additional components

- Failure signatures:
  - Poor credit assignment when LRP assumptions break (non-linear relationships)
  - Performance degradation if critic network cannot maintain accurate total Q estimates
  - Potential exploration issues when too many agents are removed (as noted in bane_no_z results)

- First 3 experiments:
  1. Reproduce baseline results on SMAC bane_vs_bane with varying zergling counts to confirm redundancy problem
  2. Implement RDN and verify performance stability across different redundancy levels
  3. Compare RDN performance with and without global state access to validate the local-only claim

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does RDN performance scale with the number of redundant agents beyond the tested range in SMAC bane_vs_bane variants?
- Basis in paper: [explicit] The paper tests 4 variants (original bane_vs_bane, bane_med with 15 zerglings, bane_small with 10 zerglings, and bane_no_z with no zerglings) but does not explore scenarios with significantly more redundant agents
- Why unresolved: The paper only examines scenarios with up to 20 redundant agents and does not test whether RDN maintains its advantage with substantially larger numbers of redundant agents
- What evidence would resolve it: Empirical results showing RDN performance with 50+ redundant agents compared to baseline methods, demonstrating whether the advantage persists or diminishes

### Open Question 2
- Question: What is the computational overhead of RDN compared to VDN and Qmix in terms of training time and memory usage?
- Basis in paper: [inferred] The paper focuses on performance outcomes but does not discuss computational efficiency or resource requirements
- Why unresolved: While RDN shows superior performance, the paper does not address the practical implementation costs, which are critical for real-world deployment
- What evidence would resolve it: Detailed benchmarking data comparing wall-clock training time, GPU memory consumption, and total computational cost across all methods

### Open Question 3
- Question: Does the presence of a small number of redundant agents (as suggested by the bane_no_z results) actually aid exploration, or is this an artifact of the specific environment?
- Basis in paper: [explicit] "We suspect that having a small number of extra agents may aid in exploration early in the training regime" based on the observation that "when no redundant agents are present at all in the bane_no_z map performance decreased across all algorithms when compared to bane_small"
- Why unresolved: This is presented as a hypothesis without systematic investigation or testing across multiple environments
- What evidence would resolve it: Controlled experiments varying the number of redundant agents across multiple different environment types, with analysis of exploration metrics and early-stage learning curves

## Limitations
- RDN's performance claims rely entirely on a single experimental setup (SMAC bane_vs_bane variants)
- The paper provides limited empirical validation of LRP's effectiveness for credit assignment quality in MARL
- The assumption of linear relationships between global and local rewards needs more rigorous testing across diverse environments

## Confidence

- **High Confidence**: RDN successfully maintains performance across varying redundancy levels on bane_vs_bane maps (demonstrated through winrate comparisons).
- **Medium Confidence**: RDN's advantage stems specifically from LRP-based credit assignment rather than other architectural differences (supported by mechanism descriptions but lacking ablation studies).
- **Low Confidence**: LRP's linear assumptions are sufficient for optimal credit assignment in complex multi-agent environments (largely theoretical, minimal empirical validation).
