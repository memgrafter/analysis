# Hierarchical Task Network Planning for Facilitating Cooperative Multi-Agent Reinforcement Learning

## Quick Facts
- arXiv ID: 2306.08359
- Source URL: https://arxiv.org/abs/2306.08359
- Reference count: 40
- Key outcome: SOMARL framework achieves higher rewards faster and maintains higher success rates in sparse reward environments with traps compared to state-of-the-art MARL and subgoal-based baselines.

## Executive Summary
This paper introduces SOMARL, a framework that integrates Hierarchical Task Network (HTN) planning with multi-agent reinforcement learning (MARL) to address challenges in sparse reward environments with traps. The key innovation is the combination of HTN planning with symbolic options, which enables better interpretability and data efficiency compared to existing methods. SOMARL employs a two-layer hierarchical structure consisting of an HTN planner and meta-controller at the higher level, and a MARL-based interactive module at the lower level. The framework is evaluated on two benchmarks, demonstrating superior performance over state-of-the-art MARL and subgoal-based baselines in terms of reward accumulation, success rate, and convergence speed.

## Method Summary
SOMARL operates through a two-layer hierarchical structure: a higher-level HTN planner and meta-controller, and a lower-level MARL-based interactive module. The HTN planner generates plans based on domain knowledge formalized through a TREE structure that maps MARL states to subgoals. The meta-controller selects symbolic options corresponding to these subgoals, which are then executed by low-level agents. The method incorporates intrinsic rewards into both the planning heuristic and the option policies to guide exploration toward valid subgoals while avoiding traps. The framework is evaluated on two benchmark environments (FindTreasure and MoveBox) with varying difficulty levels.

## Key Results
- SOMARL achieves higher cumulative average rewards faster than state-of-the-art MARL and subgoal-based baselines
- The framework maintains higher success rates in reaching goal states, particularly in environments with traps
- SOMARL demonstrates improved data efficiency and interpretability compared to purely learning-based approaches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The integration of HTN planning with symbolic options reduces the exploration space by guiding agents with precomputed symbolic subgoals.
- Mechanism: SOMARL constructs a TREE structure that maps MARL states to subgoals, then uses HTN planning (via HDDL) to generate sequences of subgoals. The meta-controller selects symbolic options corresponding to these subgoals, which are then executed by low-level agents. This guides exploration toward high-level task decomposition.
- Core assumption: There exists a bijective relationship between the knowledge representation (TREE) and the MARL environment, enabling symbolic options to be valid and executable.
- Evidence anchors:
  - [abstract] "symbolic knowledge is embedded using a tree structure to build a knowledge hierarchy"
  - [section] "we design a formal description TREE for the MARL environment...we define each node v in TREE to correspond to a state in the MARL environment"
- Break condition: If the TREE construction fails to capture valid subgoals or the bijective assumption breaks (e.g., environment changes dynamically), symbolic options become invalid and exploration guidance fails.

### Mechanism 2
- Claim: The improved HTN planner (pyHIPOP+) incorporates intrinsic rewards into its heuristic function to bias planning toward subgoals that are easier for low-level agents to achieve.
- Mechanism: The heuristic function hmadd(n) is extended to subtract cumulative intrinsic rewards Rk_m from the cost calculation. This rewards planning solutions that lead to symbolic options with higher intrinsic rewards, indicating better low-level policy performance.
- Core assumption: Intrinsic rewards accurately reflect the low-level policy's ability to achieve subgoals, and incorporating them into planning improves solution quality.
- Evidence anchors:
  - [section] "we improve the existing HTN planner to consider the intrinsic rewards of low-level agents when searching for solutions"
  - [section] "hmadd(n) = hf(n) + max′n∈Sub(n)hmax_add (′n) − Rk_m"
- Break condition: If intrinsic rewards are poorly calibrated or do not correlate with actual subgoal achievement, the planner may select suboptimal solutions.

### Mechanism 3
- Claim: The intrinsic reward function encourages exploration of valid subgoals while penalizing premature termination in traps, improving success rate.
- Mechanism: Intrinsic reward ri is defined as re + ϕ − n · c when the termination condition is met, where re is external reward, ϕ is a positive bonus, n is the count of negative external rewards, and c is a penalty coefficient. This rewards reaching subgoals while penalizing steps that lead to traps.
- Core assumption: The parameters ϕ and c can be tuned to balance exploration of subgoals versus avoidance of traps.
- Evidence anchors:
  - [section] "ri = (re + ϕ − n · c, βso(es) = True, 0, otherwise"
  - [section] "in order to improve the interaction efficiency of low-level agents, we use the intrinsic reward of the symbolic option to correct the planning solution"
- Break condition: If ϕ and c are poorly tuned, agents may either avoid necessary subgoals (over-penalizing) or fall into traps (under-penalizing).

## Architecture Onboarding

- Component map: Knowledge Module -> HTN Planner -> Meta-controller -> Multi-agent Module
- Critical path:
  1. Construct symbolic knowledge (TREE, HDDL, options)
  2. HTN planner generates planning solution using pyHIPOP+
  3. Meta-controller selects symbolic options and assigns to low-level agents
  4. Agents execute policies, receive rewards, and update option policies
  5. Meta-controller updates intrinsic rewards and feeds back to HTN planner
- Design tradeoffs:
  - Symbolic knowledge vs. learned policies: Symbolic knowledge provides interpretability and data efficiency but requires manual design of subgoals
  - HTN planning vs. neural networks: HTN planning is interpretable but may be less flexible than learned hierarchical policies
  - Intrinsic reward design: Requires careful tuning of ϕ and c to balance exploration and trap avoidance
- Failure signatures:
  - Low success rate: Indicates symbolic options are not guiding exploration effectively or intrinsic rewards are poorly calibrated
  - Unstable learning curves: Suggests meta-controller or option policies are not converging
  - Planner timeouts: Indicates the search space is too large or the heuristic is ineffective
- First 3 experiments:
  1. Validate TREE construction: Manually verify that subgoals in TREE correspond to valid states in a simple MARL environment
  2. Test HTN planner integration: Run pyHIPOP+ on a small domain and verify planning solutions match expected subgoal sequences
  3. Evaluate intrinsic reward: In a controlled environment, test whether intrinsic rewards guide agents away from traps and toward subgoals

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can symbolic knowledge be automatically learned for HTN planning in MARL environments rather than being pre-designed?
- Basis in paper: [explicit] The paper states "To further enhance the universality of SOMARL, it would be interesting to investigate automatically learning (HTN) domain knowledge" and references prior work on learning HTN domains.
- Why unresolved: The current framework requires manual design of symbolic knowledge (subgoals and TREE structure), which limits scalability and applicability to complex environments.
- What evidence would resolve it: A demonstration of an algorithm that can automatically discover and formalize hierarchical task structures from raw environment interactions, along with empirical validation showing performance comparable to manually-designed knowledge.

### Open Question 2
- Question: How can plan recognition be integrated with multi-agent reinforcement learning to improve coordination and goal achievement?
- Basis in paper: [explicit] The conclusion mentions "It would also be interesting to investigate the integration between plan recognition and multi-agent reinforcement learning."
- Why unresolved: While SOMARL uses HTN planning to guide exploration, it doesn't incorporate reasoning about other agents' intentions or plans, which could further enhance coordination in complex multi-agent scenarios.
- What evidence would resolve it: An integrated framework showing improved performance in multi-agent tasks where agents can recognize and adapt to each other's plans, with quantitative comparisons against SOMARL.

### Open Question 3
- Question: What is the optimal balance between exploration and exploitation when using intrinsic rewards to guide HTN planning in sparse reward environments?
- Basis in paper: [inferred] The paper introduces intrinsic rewards to constrain exploration and guide HTN planning, but doesn't systematically study the trade-off between exploration efficiency and getting trapped in suboptimal solutions.
- Why unresolved: The penalty coefficient c and reward ϕ are set heuristically (c=0.01, ϕ=5) without systematic analysis of how these parameters affect performance across different environments.
- What evidence would resolve it: A comprehensive ablation study varying intrinsic reward parameters across multiple environment types, showing how different balances affect convergence speed, success rate, and robustness to environmental changes.

## Limitations
- The TREE construction assumes a bijective mapping between symbolic subgoals and MARL states, which may not hold in more complex or dynamic environments
- Critical hyperparameters (ϕ and c for intrinsic rewards) are mentioned but not fully specified for all environments
- The HTN planner integration with MARL is described at a high level without implementation details

- Medium confidence: The TREE construction methodology and symbolic knowledge representation are well-described
