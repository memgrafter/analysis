# Benchmarks and Algorithms for Offline Preference-Based Reward Learning

## Quick Facts
- arXiv ID: 2301.01392
- Source URL: https://arxiv.org/abs/2301.01392
- Reference count: 20
- Key outcome: OPRL achieves policy performance comparable to ground-truth rewards using only 10-15 preference queries, significantly outperforming random query baselines.

## Executive Summary
Offline preference-based reward learning (OPRL) enables learning reward functions from human preferences without requiring environment interactions or simulators. The approach leverages offline datasets to select informative trajectory segment pairs for preference queries, learns a reward function from these preferences, and optimizes a policy via offline RL. Empirical results demonstrate that OPRL can learn novel behaviors not present in the offline data and achieves strong performance with minimal preference queries. The method identifies that domains with high data variability and multi-task datasets are best suited for offline reward learning.

## Method Summary
OPRL operates by first crafting preference queries from an offline dataset using active learning acquisition functions (ensemble disagreement or information gain). Human evaluators provide preference labels over trajectory segment pairs, which are used to train a reward model based on the Bradley-Terry pairwise preference model. The learned reward function is then used with an offline RL algorithm to optimize a policy. The approach employs ensemble or dropout-based uncertainty estimation to identify the most informative queries that maximize information gain and reduce uncertainty in the reward model.

## Key Results
- OPRL achieves policy performance comparable to ground-truth rewards using only 10-15 preference queries
- The method can learn novel behaviors not present in the offline data, such as counter-clockwise orbiting in a maze environment
- Ensemble disagreement outperforms dropout-based uncertainty estimation for active query selection
- Domains with high data variability and multi-task datasets are best suited for offline reward learning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Offline datasets contain sufficient diversity to enable reward learning for novel tasks through preference-based querying
- Mechanism: The algorithm searches for informative trajectory snippets within the offline dataset and uses active learning to select pairs that maximize uncertainty reduction. Ensemble disagreement or information gain acquisition functions identify the most informative comparisons, enabling the reward model to generalize beyond the observed data distribution
- Core assumption: The offline dataset contains sufficient variability and coverage of relevant state-action space to enable generalization through preference queries
- Evidence anchors:
  - [abstract] "surprisingly rich source of information for preference learning as well"
  - [section] "ability to stitch together incomplete segments from the original dataset to create one long trajectory for a new task during test time"
  - [corpus] Weak - corpus lacks specific evidence about offline dataset diversity requirements
- Break condition: If the offline dataset lacks sufficient variability or only contains data from a single narrow task distribution, the method cannot generalize to novel behaviors

### Mechanism 2
- Claim: Using trivial reward functions (all zeros or constant) often performs well in standard offline RL benchmarks, making them unsuitable for evaluating learned rewards
- Mechanism: Many offline RL algorithms behave similarly to behavioral cloning when rewards are constant, especially when datasets contain only expert demonstrations. This creates a ceiling effect where reward learning appears unnecessary
- Core assumption: The performance of offline RL algorithms is primarily determined by the quality and diversity of the dataset rather than the specific reward values
- Evidence anchors:
  - [section] "simply replacing all actual rewards in the offline dataset with zeros, or a constant, results in performance similar to, or better than, the performance obtained using the true rewards"
  - [section] "many offline RL domains, we find that simply using a trivial reward function results good policy performance"
  - [corpus] Weak - corpus lacks direct comparison of trivial reward performance across benchmarks
- Break condition: If the offline dataset contains diverse, multi-task data or random trajectories rather than expert demonstrations, trivial rewards will perform poorly and learned rewards will be necessary

### Mechanism 3
- Claim: Ensemble-based disagreement outperforms other uncertainty estimation methods for active query selection in offline preference learning
- Mechanism: Ensemble disagreement captures the variance in return estimates across multiple reward models, identifying query pairs where models strongly disagree. This maximizes information gain from each preference label
- Core assumption: Ensemble models trained on the same data with different random seeds produce diverse enough predictions to capture meaningful uncertainty
- Evidence anchors:
  - [section] "we investigate two different methods to represent uncertainty (ensembles and Bayesian dropout) along with two different acquisition functions (disagreement and information gain)"
  - [section] "ensemble disagreement is the best performing approach for both Maze2D-Umaze and Maze2D-Medium"
  - [corpus] Moderate - corpus contains related work on ensemble uncertainty but lacks direct comparison to dropout in offline setting
- Break condition: If the reward model architecture or training process produces highly correlated predictions across ensemble members, disagreement will not capture meaningful uncertainty

## Architecture Onboarding

- Component map: Offline dataset → Reward model (with ensemble/dropout uncertainty) → Active query selection (disagreement/info gain) → Preference labels → Updated reward model → Offline RL policy optimization
- Critical path: Reward model training → Active query selection → Preference collection → Policy optimization
- Design tradeoffs: Ensemble models provide better uncertainty estimation but require more computation; dropout is faster but may provide less reliable uncertainty estimates
- Failure signatures: Poor policy performance despite accurate reward predictions suggests issues with the offline RL algorithm or reward shaping; high variance in ensemble predictions may indicate insufficient training data

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What are the key factors that make some offline RL benchmarks unsuitable for offline reward learning, and how can we systematically identify such benchmarks?
- Basis in paper: The paper explicitly states that many offline RL benchmarks are ill-suited for evaluating learned rewards, as using trivial reward functions can lead to good performance. The authors identify high data variability and multi-task data as settings where reward learning is necessary for good policy learning
- Why unresolved: While the paper identifies some factors, a systematic method for identifying suitable benchmarks is not provided. The authors rely on empirical evaluation rather than a theoretical framework
- What evidence would resolve it: Developing a theoretical framework or set of criteria that can predict whether an offline RL benchmark is suitable for reward learning would be valuable. This could involve analyzing the structure of the dataset, the diversity of tasks, and the relationship between rewards and optimal behavior

### Open Question 2
- Question: How does the choice of policy optimization algorithm affect the performance of offline preference-based reward learning?
- Basis in paper: The paper uses AWR and CQL for policy optimization, but finds that the performance can vary depending on the algorithm. For example, when using CQL, dropout-based uncertainty representation performs better than ensemble-based methods, while the opposite is true for AWR
- Why unresolved: The paper does not provide a comprehensive analysis of the interaction between policy optimization algorithms and different uncertainty representation methods. The observed differences could be due to various factors, such as the specific hyperparameters or the nature of the tasks
- What evidence would resolve it: Conducting a systematic study comparing different policy optimization algorithms (e.g., AWR, CQL, BCQ) with various uncertainty representation methods (e.g., ensembles, dropout) across a range of tasks would provide insights into their interactions and help identify optimal combinations

### Open Question 3
- Question: Can offline preference-based reward learning be extended to handle more complex reward structures, such as those involving temporal logic or high-level objectives?
- Basis in paper: The paper focuses on learning reward functions from pairwise preferences over trajectory segments, which is a relatively simple reward structure. While the authors demonstrate that OPRL can learn novel behaviors not explicitly shown in the data, it is unclear how well it would perform on tasks with more complex reward structures
- Why unresolved: The paper does not explore the limitations of OPRL when dealing with more complex reward structures. Extending OPRL to handle such cases would require developing new methods for representing and learning these reward functions from preferences
- What evidence would resolve it: Evaluating OPRL on tasks with more complex reward structures, such as those involving temporal logic or high-level objectives, would provide insights into its capabilities and limitations. Developing new methods for representing and learning these reward functions from preferences would be necessary to extend OPRL to these cases

## Limitations

- The approach fundamentally depends on the offline dataset containing sufficient diversity to enable generalization to novel tasks through preference queries
- The computational overhead of ensemble-based uncertainty estimation may limit scalability to larger state spaces
- The comparison with trivial reward baselines, while insightful, requires more extensive validation across diverse benchmark suites

## Confidence

- High confidence: The core claim that OPRL can learn novel behaviors not present in the offline data using only 10-15 preference queries
- Medium confidence: The assertion that domains with high data variability are best suited for offline reward learning, as this requires more extensive benchmarking
- Medium confidence: The finding that ensemble disagreement outperforms dropout-based uncertainty estimation, pending more rigorous statistical comparison
