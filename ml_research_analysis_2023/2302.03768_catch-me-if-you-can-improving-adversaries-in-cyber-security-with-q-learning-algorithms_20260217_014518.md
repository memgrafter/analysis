# Catch Me If You Can: Improving Adversaries in Cyber-Security With Q-Learning Algorithms

## Quick Facts
- arXiv ID: 2302.03768
- Source URL: https://arxiv.org/abs/2302.03768
- Reference count: 1
- This work demonstrates that Double Q-Learning can achieve 70% success rate in data exfiltration while being detected only 37% of the time, even with global defender visibility.

## Executive Summary
This paper proposes using Q-Learning algorithms to model and improve the behavior of Advanced Persistent Threat (APT) attackers in cybersecurity scenarios. A Markov Decision Process (MDP) environment is constructed with a network topology and a defender that can detect attacker actions with a non-zero probability. Three variants of Q-Learning—basic Q-Learning, Naive Q-Learning, and Double Q-Learning—are trained to optimize an attacker's policy to exfiltrate data while minimizing detection. The results show that Double Q-Learning achieves the highest success rate, exfiltrating data in 70% of interactions while being detected in only 37%.

## Method Summary
The paper implements a custom network environment with five clients, five servers, and a router. The attacker starts with access to one client and knows the address of an external C&C server. The defender has a non-zero probability of detecting the attacker's actions. Three variants of Q-Learning are used: basic Q-Learning, Naive Q-Learning, and Double Q-Learning. The agents are trained using off-policy reinforcement learning, with an ε-greedy policy for exploration. The Q-values are updated based on the observed rewards and the estimated future rewards. The reward structure includes -1 for each action taken, -50 if detected, and +100 for successful exfiltration.

## Key Results
- Double Q-Learning achieved the highest success rate, exfiltrating data in 70% of interactions
- The agent was detected only 37% of the time despite global defender visibility
- Basic Q-Learning and Naive Q-Learning showed significantly lower performance compared to Double Q-Learning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Double Q-Learning avoids overestimation bias by using two independent Q-value estimates.
- Mechanism: Each Q-function is updated using the other's estimate for the next state, reducing overestimation from max operator bias.
- Core assumption: The two Q-functions are sufficiently independent to provide unbiased estimates.
- Evidence anchors:
  - [abstract]: "DoubleQ-Learning agent has the best overall performance rate by successfully achieving the goal in 70% of the interactions."
  - [section 4]: "Double Q-Learning (Hasselt, 2010; Jang et al., 2019b) proposes learning two Q-functions instead of one. Each Q-function gets the update from the other for the next state."
  - [corpus]: Weak - no direct corpus evidence on overestimation bias in this specific paper.
- Break condition: If the two Q-functions become correlated due to similar updates, overestimation bias may reappear.

### Mechanism 2
- Claim: Modeling defender as part of the environment simplifies the problem to single-agent RL.
- Mechanism: The defender is represented as a stochastic global entity with fixed detection probabilities, eliminating the need for opponent modeling.
- Core assumption: The defender's behavior is predictable and stationary based on action-level detection probabilities.
- Evidence anchors:
  - [section 3.2]: "the defender is modeled as a stochastic and global part of the environment."
  - [section 3.4]: "Given that the defender has full network visibility, there is a probability of detection for each action on all clients and servers."
  - [corpus]: No direct corpus evidence found for this simplification approach.
- Break condition: If defender adapts its detection strategy over time, the stationary assumption breaks down.

### Mechanism 3
- Claim: Negative reward per action incentivizes shortest path to goal.
- Mechanism: Small negative reward (-1) for each action taken encourages the agent to reach the goal in fewer steps.
- Core assumption: The agent can learn to balance exploration with exploitation to find the shortest path.
- Evidence anchors:
  - [section 3.6]: "The reward of the agent is constructed as: −1 for every action taken,−50 if the action is detected, and +100 if the goal state is reached."
  - [section 6]: "The small negative reward per action is intended to motivate the agent to find the shortest path to the goal."
  - [corpus]: No direct corpus evidence for this specific reward structure.
- Break condition: If detection probability is too high, the agent may learn to take longer paths to avoid detection.

  - Quick check question: Why is it important that the environment has the Markov property for Q-Learning to work effectively?

- Concept: Off-policy learning
  - Why needed here: Q-Learning is an off-policy algorithm that learns the optimal policy while following a different behavior policy (ε-greedy).
  - Quick check question: What's the difference between on-policy and off-policy learning, and why does Q-Learning use the off-policy approach?

- Concept: Action-value function (Q-value)
  - Why needed here: Q-values represent the expected return for taking an action in a given state, which is the core of the Q-Learning algorithm.
  - Quick check question: How does the Q-value update rule incorporate both immediate and future rewards?

## Architecture Onboarding

- Component map: Network topology (clients, servers, router) -> Environment state (discovered assets, controlled hosts) -> RL agent (Q-Learning variants) -> Action selection (ε-greedy) -> State transition -> Reward calculation
- Critical path: State observation -> Action selection -> Environment transition -> Reward feedback -> Q-value update -> Policy improvement
- Design tradeoffs: Single-agent vs multi-agent (simplified defender model), action granularity (5 actions vs full MITRE ATT&CK), reward shaping (negative per-step vs sparse rewards)
- Failure signatures: High variance in mean returns (stochastic environment), poor learning in early episodes (random initialization), detection rate approaching random baseline (ineffective exploration)
- First 3 experiments:
  1. Test Q-Learning vs Double Q-Learning on fixed starting position with known target
  2. Evaluate robustness by randomizing attacker starting position
  3. Measure performance degradation when detection probabilities are increased

## Limitations

- The network environment details and specific detection probabilities are not fully specified, making exact reproduction difficult
- The stationary defender assumption may not reflect real-world scenarios where defenders adapt to attacker behavior
- The approach is currently limited to small or medium-sized networks, with scalability to larger environments untested

## Confidence

- High Confidence: The mechanism of Double Q-Learning reducing overestimation bias is well-established in reinforcement learning literature and supported by the agent's superior performance in this work
- Medium Confidence: The claim that modeling the defender as part of the environment simplifies to single-agent RL is reasonable but untested against multi-agent approaches that could capture more complex defender behaviors
- Low Confidence: The assertion that negative per-step rewards reliably incentivize shortest path finding is questionable given the stochastic detection environment, where longer paths might actually be safer strategies

## Next Checks

2. **Transfer Learning Evaluation**: Train agents on one network topology and test their performance on structurally different networks to assess whether learned policies generalize beyond the specific environment used in training, addressing concerns about overfitting

3. **Multi-Agent Comparison**: Implement a simple defender agent that adapts its detection strategy based on observed attacker behavior and compare this against the stationary defender model to quantify the impact of the single-agent simplification on real-world applicability
