# Interpretable Linear Dimensionality Reduction based on Bias-Variance Analysis

## Quick Facts
- arXiv ID: 2303.14734
- Source URL: https://arxiv.org/abs/2303.14734
- Reference count: 40
- Key outcome: LinCFA reduces dimensionality while maintaining or improving regression performance compared to PCA and Supervised PCA, achieving lower MSE and higher R² scores.

## Executive Summary
This paper introduces Linear Correlated Features Aggregation (LinCFA), a dimensionality reduction method that preserves interpretability by aggregating highly correlated continuous features using their mean. The method uses a theoretically derived threshold based on bias-variance analysis to determine when aggregation is beneficial. LinCFA is particularly effective for datasets with small sample sizes relative to the number of features, addressing overfitting while maintaining or improving regression performance.

## Method Summary
LinCFA aggregates highly correlated continuous features by computing their mean, guided by a theoretical threshold that ensures aggregation reduces variance more than it increases bias. The method computes pairwise correlations between features and compares them against the threshold, which depends on noise variance and coefficient differences. By selectively aggregating only sufficiently correlated features, LinCFA achieves dimensionality reduction while preserving interpretability through averaging rather than arbitrary linear combinations.

## Key Results
- Aggregation reduces variance more than it increases bias when feature correlation exceeds the theoretical threshold
- LinCFA reduces dimensionality while maintaining or improving regression performance compared to PCA and Supervised PCA
- The method is particularly effective when the number of samples is small relative to the number of features

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Aggregating highly correlated features reduces variance more than it increases bias when correlation exceeds a theoretical threshold.
- **Mechanism:** The method computes a threshold based on the bias-variance decomposition. For two features x₁ and x₂, if their correlation ρ ≥ 1 - 2σ²/((n-1)(w₁-w₂)²), then aggregating them with their mean reduces overall MSE.
- **Core assumption:** The relationship between features and target is linear with Gaussian noise: y = w₁x₁ + w₂x₂ + ε, ε ~ N(0,σ²).
- **Evidence anchors:**
  - [abstract] "aggregation reduces variance more than it increases bias when the correlation exceeds the threshold"
  - [section] "Theoretical results to design an algorithm... which aggregates groups of continuous features with their average if their correlation is 'sufficiently large'"
  - [corpus] Weak - corpus doesn't contain direct evidence for this specific mechanism
- **Break condition:** If the noise variance σ² is very small or the coefficient difference |w₁-w₂| is large, the threshold approaches 1, making aggregation rarely beneficial.

### Mechanism 2
- **Claim:** The proposed algorithm preserves interpretability by averaging features rather than creating linear combinations.
- **Mechanism:** Instead of projecting features into a lower-dimensional space with arbitrary coefficients (like PCA), LinCFA aggregates correlated features by computing their mean, producing interpretable reduced features.
- **Core assumption:** Aggregated features must be continuous and homogeneous (same units/scale).
- **Evidence anchors:**
  - [abstract] "aggregates groups of continuous features with their average if their correlation is 'sufficiently large'"
  - [section] "Choosing the average to aggregate the features is to preserve interpretability (the resulting reduced feature is just the average of k original features)"
  - [corpus] Weak - corpus lacks direct comparison to PCA interpretability
- **Break condition:** When features have different units or are categorical, averaging becomes meaningless and interpretability is lost.

### Mechanism 3
- **Claim:** The algorithm reduces dimensionality while maintaining or improving regression performance compared to PCA and Supervised PCA.
- **Mechanism:** By selectively aggregating only highly correlated features, LinCFA reduces dimensionality more aggressively than PCA (which keeps all features) while preserving regression performance through bias-variance optimization.
- **Core assumption:** The dataset has many highly correlated features, making aggregation beneficial.
- **Evidence anchors:**
  - [abstract] "On real datasets, LinCFA reduces dimensionality while maintaining or improving regression performance compared to PCA and Supervised PCA, achieving lower MSE and higher R² scores"
  - [section] "the main result of this paper is able, in linear settings, to reduce the dimensionality of the input features improving (or not-worsening) the performance"
  - [corpus] Weak - corpus doesn't provide comparative performance data
- **Break condition:** When features are mostly uncorrelated, the algorithm won't aggregate much, providing minimal dimensionality reduction benefit.

## Architecture Onboarding

- **Component map:** Input D-dimensional feature matrix X and target vector y -> Correlation threshold computation and feature aggregation logic -> Output reduced d-dimensional feature matrix with d ≤ D

- **Critical path:**
  1. Compute pairwise correlations between all features
  2. For each feature, compare correlations with subsequent features
  3. Aggregate features when correlation exceeds threshold
  4. Compute mean for each aggregated group
  5. Return reduced feature set

- **Design tradeoffs:**
  - Linear vs non-linear relationships: Method assumes linearity, limiting applicability
  - Continuous vs categorical features: Only works with continuous features due to averaging
  - Computational cost: O(n·D²) for correlation computation, better than full regression O(n·D² + D³)

- **Failure signatures:**
  - No dimensionality reduction occurs: Features are mostly uncorrelated
  - Performance degradation: Threshold is set too low, aggregating dissimilar features
  - Interpretability loss: Aggregating heterogeneous features with different units

- **First 3 experiments:**
  1. Synthetic bivariate dataset with known coefficients and varying noise levels to verify threshold behavior
  2. Real dataset with known high correlations to test aggregation and interpretability preservation
  3. Comparison with PCA on same dataset to measure dimensionality reduction and performance tradeoffs

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the LinCFA method generalize to categorical or mixed-type features?
- Basis in paper: [explicit] The paper states "The main restriction of choosing the average to aggregate is that we will only consider continuous features since the mean is not well-defined for categorical features."
- Why unresolved: The current theoretical framework relies on computing correlations and means, which are not applicable to categorical features.
- What evidence would resolve it: Experiments applying LinCFA or a modified version to datasets with categorical features, showing whether performance degrades or if alternative aggregation methods can be used.

### Open Question 2
- Question: How robust is the correlation threshold to non-Gaussian noise distributions?
- Basis in paper: [inferred] The theoretical analysis assumes Gaussian noise, but real-world data often deviates from this assumption.
- Why unresolved: The threshold formulas (e.g., Equation 17, 24) are derived under Gaussian assumptions; their validity under heavy-tailed or skewed noise is untested.
- What evidence would resolve it: Synthetic experiments with non-Gaussian noise (e.g., Laplace, t-distribution) showing whether the threshold still predicts beneficial aggregation.

### Open Question 3
- Question: Can LinCFA be extended to non-linear relationships between features and target?
- Basis in paper: [explicit] The paper assumes "a linear dependence between the features X and the target Y" and focuses on linear regression.
- Why unresolved: Real-world relationships are often non-linear, and the current method may fail to capture complex dependencies.
- What evidence would resolve it: Application of LinCFA to non-linear models (e.g., kernel regression, neural networks) or modification of the method to account for non-linearity.

## Limitations
- Theoretical threshold derivation assumes linear relationships with Gaussian noise
- Method's effectiveness depends heavily on presence of highly correlated features
- Comparison with PCA and Supervised PCA lacks comprehensive experimental validation

## Confidence

**High Confidence**: The core mechanism of feature aggregation reducing variance while controlling bias is theoretically sound under the stated assumptions. The bias-variance tradeoff framework is well-established in statistical learning theory.

**Medium Confidence**: The practical performance claims on real datasets need more extensive validation. While the theoretical framework is robust, real-world datasets may violate the linearity and Gaussian noise assumptions.

**Low Confidence**: The interpretability preservation claim requires more rigorous validation, particularly regarding how the method handles features with different scales or units in practice.
