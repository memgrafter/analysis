# Quantification of Uncertainties in Deep Learning-based Environment Perception

## Quick Facts
- arXiv ID: 2306.03018
- Source URL: https://arxiv.org/abs/2306.03018
- Reference count: 25
- One-line primary result: Novel hybrid deterministic-probabilistic network achieves 37.2% mIoU while quantifying both epistemic and aleatoric uncertainties in radar-based environment perception

## Executive Summary
This paper presents a deep learning approach for environment perception using radar data that explicitly quantifies uncertainties in its predictions. The method segments the environment into grid cells and classifies each cell individually, capturing both epistemic (model-related) and aleatoric (data-related) uncertainties. The core innovation involves parameterizing network weights as Gaussian distributions, enabling the model to learn uncertainties in its parameters through variational inference. The approach is evaluated using radar and lidar data from a vehicle, demonstrating superior performance compared to traditional approaches and state-of-the-art implementations like MC Dropout and Bayesian SegNet.

## Method Summary
The method uses a hybrid deterministic-probabilistic neural network architecture where early layers perform deterministic feature extraction using ASPP (Atrous Spatial Pyramid Pooling) layers, while later classification layers use Gaussian-distributed weights to capture epistemic uncertainty. The model processes radar point clouds projected onto a 160x160 grid, extracting features and mapping them to class probabilities (free, occupied, moving object, unknown) with associated uncertainties. Training employs variational inference with a custom loss combining KL divergence and likelihood terms, optimized using Adam. Epistemic uncertainty is quantified through the distribution over weights, while aleatoric uncertainty is derived from predictive entropy.

## Key Results
- Achieves 37.2% mean Intersection over Union (mIoU) on test set, outperforming MC Dropout (35.7%) and Bayesian SegNet (36.7%)
- Hybrid architecture reduces parameters from 264.4K to 134.9K while maintaining similar performance
- Epistemic and aleatoric uncertainties are complementary, with one compensating for the other in many scenarios
- The model shows improved precision and reliability in predictions, particularly for occluded or unfamiliar objects

## Architecture Onboarding

- Component map:
  Input radar point cloud data -> Batch normalization and ASPP feature extraction layers -> Probabilistic classification head with Gaussian-distributed weights -> Output class probabilities with epistemic and aleatoric uncertainties

- Critical path:
  1. Pre-process radar data into grid cell features
  2. Extract features using deterministic ASPP layers
  3. Map features to class probabilities using probabilistic weights
  4. Calculate epistemic and aleatoric uncertainties
  5. Evaluate performance using mIoU and uncertainty-precision correlation

- Design tradeoffs:
  - Fully probabilistic vs hybrid: The hybrid approach reduces parameters from 264.4K to 134.9K while maintaining similar performance
  - Gaussian vs Bernoulli distributions: Gaussian distributions allow learning fine-grained uncertainties, while Bernoulli distributions (as in MC Dropout) are simpler but less expressive
  - Feature extraction vs classification: Placing probabilistic weights only in classification layers assumes feature extraction is more reliable than classification

- Failure signatures:
  - High aleatoric uncertainty across all cells: Indicates systematic data noise or sensor issues
  - High epistemic uncertainty on familiar scenarios: Suggests inadequate training data or model capacity
  - Low uncertainty but poor accuracy: Indicates overconfidence and potential safety issues
  - Correlation between epistemic and aleatoric uncertainties: May indicate model misspecification

- First 3 experiments:
  1. Implement deterministic baseline network and verify mIoU of ~36.7% on test set
  2. Replace all weights with Gaussian distributions and train with variational inference loss
  3. Implement hybrid architecture with probabilistic weights only in final layers and compare parameter count and performance to fully probabilistic version

## Limitations
- The uncertainty quantification approach relies on strong assumptions about Gaussian weight distributions and their ability to approximate true posterior distributions
- The hybrid architecture assumes epistemic uncertainty can be adequately captured only in later layers, potentially missing early-layer uncertainties
- The evaluation focuses primarily on mIoU performance without extensive validation of uncertainty calibration across diverse driving scenarios

## Confidence
- High confidence: The hybrid network architecture effectively reduces parameters while maintaining performance (134.9K vs 264.4K parameters with similar mIoU)
- Medium confidence: The complementarity between epistemic and aleatoric uncertainties is demonstrated but not extensively validated across different driving conditions
- Medium confidence: The superiority over MC Dropout and Bayesian SegNet is shown, but the evaluation could benefit from more diverse comparison metrics
