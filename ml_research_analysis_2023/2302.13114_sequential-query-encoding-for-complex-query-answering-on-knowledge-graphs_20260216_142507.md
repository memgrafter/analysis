# Sequential Query Encoding For Complex Query Answering on Knowledge Graphs

## Quick Facts
- arXiv ID: 2302.13114
- Source URL: https://arxiv.org/abs/2302.13114
- Reference count: 25
- Key outcome: Sequential query encoding achieves state-of-the-art performance on complex query answering across 29 query types on FB15k, FB15k-237, and NELL datasets

## Executive Summary
This paper introduces Sequential Query Encoding (SQE), a novel approach for complex query answering on knowledge graphs that linearizes query graphs into token sequences and uses sequence encoders to compute vector representations. Instead of parameterizing and executing computational graphs, SQE transforms complex queries into sequential embeddings that can retrieve answers through similarity scores in embedding space. The method demonstrates superior performance on standard benchmarks and shows promising generalization to out-of-distribution queries.

## Method Summary
SQE converts complex query graphs into sequential token representations, which are then processed by sequence encoders to produce query embeddings. These embeddings are used to retrieve answers from the embedding space based on similarity scores, bypassing the need to explicitly parameterize and execute computational graphs. The approach leverages the efficiency of sequence modeling techniques while maintaining the ability to handle complex query structures through careful linearization strategies.

## Key Results
- Achieves state-of-the-art performance on FB15k, FB15k-237, and NELL datasets
- Demonstrates effectiveness across twenty-nine types of in-distribution queries
- Shows comparable knowledge inference capability on out-of-distribution queries not seen during training

## Why This Works (Mechanism)
SQE works by transforming the structural complexity of query graphs into a sequential format that can be processed by well-established sequence encoding architectures. This linearization approach allows the model to leverage powerful sequence modeling techniques while avoiding the computational overhead of explicitly parameterizing and executing computational graphs. The vector representation produced by the sequence encoder serves as an efficient query embedding that can be compared against answer embeddings using similarity metrics, enabling fast and scalable query answering.

## Architecture Onboarding

Component Map: Query Graph -> Linearization -> Sequence Encoder -> Query Embedding -> Similarity Matching -> Answer Retrieval

Critical Path: The linearization process is critical as it determines how query structure is preserved in the sequential format. Any loss of structural information during linearization directly impacts the quality of query embeddings and subsequent answer retrieval performance.

Design Tradeoffs: SQE trades explicit computational graph execution for sequence encoding efficiency. While this provides computational advantages, it may lose some structural nuances inherent in graph representations. The linearization strategy must balance between preserving query semantics and creating efficient sequential representations.

Failure Signatures: Poor linearization strategies may lead to ambiguous query representations, resulting in incorrect answer retrieval. If the sequence encoder fails to capture complex query dependencies, the model will struggle with multi-hop reasoning tasks.

## Limitations

The evaluation on out-of-distribution queries lacks detailed metrics and statistical significance analysis, making it difficult to assess true generalization capability. The complexity and distribution of the twenty-nine query types within training data is not fully characterized. The linearization strategy may lose important structural information, but ablation studies on different linearization schemes are not provided.
