# Dense Network Expansion for Class Incremental Learning

## Quick Facts
- arXiv ID: 2303.12696
- Source URL: https://arxiv.org/abs/2303.12696

## Executive Summary
This paper addresses the challenge of class incremental learning (CIL), where models must learn new classes sequentially without forgetting previously learned ones. The authors propose Dense Network Expansion (DNE), a novel network expansion method that introduces dense connections between task expert networks using a cross-task attention mechanism based on a task attention block (TAB). Unlike traditional approaches that concatenate features from all tasks, DNE enables knowledge transfer between tasks by fusing information across task experts. The method demonstrates significant improvements in accuracy while maintaining efficient model complexity.

## Method Summary
Dense Network Expansion (DNE) is a network expansion method for class incremental learning that introduces dense connections between task expert networks. The core innovation is the task attention block (TAB), which implements a cross-task attention mechanism to fuse information across different task experts. Rather than simply concatenating features from all tasks, DNE creates a dense connection structure that allows for knowledge transfer between tasks. This approach aims to balance the trade-off between accuracy and model complexity in CIL scenarios, where traditional methods often struggle with catastrophic forgetting or inefficient resource utilization.

## Key Results
- DNE achieves 4% higher accuracy compared to state-of-the-art CIL methods
- Maintains similar or smaller model size compared to baseline approaches
- Demonstrates better trade-off between accuracy and model complexity in CIL scenarios

## Why This Works (Mechanism)
DNE works by creating dense connections between task expert networks through a cross-task attention mechanism implemented in the task attention block (TAB). This architecture enables knowledge transfer between different tasks by fusing information across task experts, rather than simply concatenating features. The dense connection pattern allows the model to leverage previously learned knowledge when learning new tasks, while the attention mechanism ensures that the most relevant information is emphasized during the fusion process. This approach addresses the fundamental challenge in CIL of balancing new learning with retention of old knowledge.
