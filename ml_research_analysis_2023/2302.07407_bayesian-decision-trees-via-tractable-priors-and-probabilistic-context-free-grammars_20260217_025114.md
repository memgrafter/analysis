# Bayesian Decision Trees via Tractable Priors and Probabilistic Context-Free Grammars

## Quick Facts
- **arXiv ID:** 2302.07407
- **Source URL:** https://arxiv.org/abs/2302.07407
- **Reference count:** 28
- **Primary result:** Introduces BCART-PCFG method achieving competitive accuracy with 20x smaller models

## Executive Summary
This paper introduces BCART-PCFG, a novel method for constructing Bayesian Decision Trees (BDTs) that overcomes the limitations of existing MCMC-based approaches. The key innovation is formulating the BDT sampling problem as inference over a probabilistic context-free grammar (PCFG), which allows for efficient sampling and MAP tree identification in polynomial time. The method achieves classification accuracy comparable to or better than standard greedily-constructed trees while producing significantly smaller models—sometimes up to 20x smaller. Experimental results on synthetic and real-world datasets demonstrate that BCART-PCFG outperforms both single greedily-constructed trees and random forests in terms of model size while maintaining competitive accuracy. The approach requires only a single hyperparameter and can be parallelized, making it practical for deployment.

## Method Summary
BCART-PCFG constructs Bayesian Decision Trees by modeling the tree generation process as a probabilistic context-free grammar. This formulation enables exact inference through dynamic programming, replacing traditional MCMC sampling with efficient polynomial-time algorithms. The method defines probability distributions over tree structures, split features, and threshold values, with priors that encourage smaller trees. By leveraging PCFG parsing algorithms, BCART-PCFG can sample from the posterior distribution and identify the maximum a posteriori tree efficiently. The approach incorporates both continuous and categorical features and handles missing data through appropriate likelihood formulations.

## Key Results

- Outperforms both single greedily-constructed trees and random forests in terms of model size while maintaining competitive accuracy
- Requires only a single hyperparameter and supports parallelization

## Why This Works (Mechanism)
BCART-PCFG works by transforming the Bayesian decision tree problem into a PCFG inference task. The key insight is that tree structures can be represented as derivations in a context-free grammar, where production rules correspond to node splitting operations. By defining appropriate probability distributions over these productions, the method can use well-established PCFG parsing algorithms to perform exact Bayesian inference. This avoids the computational intractability of traditional MCMC approaches while still capturing the full posterior distribution over trees. The PCFG framework naturally incorporates regularization through prior distributions, leading to smaller, more generalizable trees.

## Architecture Onboarding

**Component Map**
Grammar definition -> Prior specification -> Likelihood computation -> PCFG parsing -> Tree sampling

**Critical Path**
1. Define PCFG production rules for tree construction
2. Specify prior distributions over productions
3. Compute data likelihood for candidate trees
4. Perform PCFG parsing to identify MAP tree
5. Sample from posterior distribution

**Design Tradeoffs**
- Binary vs multiway splits (binary chosen for computational tractability)
- Feature independence assumption in priors (simplifies computation but may limit expressiveness)
- Maximum depth specification (controls model complexity but requires hyperparameter tuning)

**Failure Signatures**
- Poor performance on datasets with strong feature dependencies
- Suboptimal results when maximum depth is too restrictive
- Potential limitations on highly non-linear decision boundaries

**First 3 Experiments**
1. Compare classification accuracy on synthetic datasets with known ground truth
2. Evaluate model size reduction across diverse real-world datasets
3. Test sensitivity to maximum depth hyperparameter on benchmark datasets

## Limitations
- Restricted to binary trees, limiting expressiveness compared to multiway splits
- Assumes feature independence in leaf node priors, which may not hold for many real-world datasets
- Requires specifying maximum tree depth as a hyperparameter, which can impact model performance if poorly chosen
