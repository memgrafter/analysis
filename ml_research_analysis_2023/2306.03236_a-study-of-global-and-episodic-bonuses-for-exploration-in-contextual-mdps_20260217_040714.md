# A Study of Global and Episodic Bonuses for Exploration in Contextual MDPs

## Quick Facts
- **arXiv ID:** 2306.03236
- **Source URL:** https://arxiv.org/abs/2306.03236
- **Reference count:** 40
- **Key outcome:** This paper studies the use of global and episodic novelty bonuses for exploration in contextual Markov Decision Processes (CMDPs), finding that global bonuses work well when structure is shared across episodes, episodic bonuses work well when structure is limited, and multiplicative combination provides robust performance across varying degrees of shared structure.

## Executive Summary
This paper investigates exploration strategies for contextual Markov Decision Processes (CMDPs) where each episode corresponds to a different context with potentially shared structure. The authors study two types of exploration bonuses: global bonuses computed from all experience and episodic bonuses computed within each episode. Through theoretical analysis and empirical experiments, they demonstrate that global bonuses excel when value functions vary little across contexts, while episodic bonuses are superior when value functions differ substantially. They propose a multiplicative combination strategy that achieves robust performance across varying degrees of shared structure, achieving new state-of-the-art results on 16 MiniHack tasks.

## Method Summary
The method combines global novelty bonuses (computed from all agent experience) with episodic novelty bonuses (computed only from current episode experience) in a multiplicative fashion. The framework uses a feature extractor ψ to map states to a feature space where bonuses are computed. Global bonuses use techniques like Random Network Distillation (RND), while episodic bonuses employ methods like E3B's elliptical bonus. The combined bonus is added to the environment reward and optimized using IMPALA. The approach is evaluated across 16 MiniHack tasks with 50 million environment steps, tracking mean, median, and interquartile mean performance with 95% confidence intervals using stratified bootstrapping over 5 seeds.

## Key Results
- Global bonuses fail when value functions vary significantly across contexts, exhausting novelty in one context and missing opportunities in others
- Episodic bonuses succeed when value functions vary significantly but fail when knowledge transfer across episodes is crucial
- Multiplicative combination of global and episodic bonuses provides more robust performance across different degrees of shared structure
- The proposed method achieves new state-of-the-art results on 16 MiniHack tasks
- Results are validated across MiniHack, Habitat, and Montezuma's Revenge environments

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Global bonuses fail when value function varies significantly across contexts
- Mechanism: Global bonuses accumulate novelty signals across all episodes, so if high-value regions in state space differ substantially between contexts, the agent exhausts bonuses in one context and misses opportunities in others
- Core assumption: The feature extractor ψ maps states to a space where similarity correlates with value function similarity across contexts
- Evidence anchors:
  - [abstract]: "global bonuses are effective when there is shared structure across episodes, but fail when structure is limited"
  - [section 3.3]: "we show that global bonuses, which are commonly used in singleton MDPs, can be poorly suited for CMDPs that share little structure across episodes"
  - [corpus]: Weak evidence - corpus focuses on MDPs and posterior sampling rather than CMDPs with context-specific structure
- Break condition: If feature extractor ψ maps states to space where value function varies little across contexts, or if contexts share sufficient structural similarity

### Mechanism 2
- Claim: Episodic bonuses succeed when value function varies significantly across contexts
- Mechanism: Episodic bonuses encourage exploration within each episode independently, so the agent discovers high-value regions for each context without interference from previous contexts
- Core assumption: Agent can explore sufficiently within each episode to discover high-value regions despite resetting bonuses
- Evidence anchors:
  - [abstract]: "episodic bonuses being most effective when there is little shared structure across episodes"
  - [section 3.1]: "episodic bonuses, which are commonly used in CMDPs, can also fail in cases where knowledge transfer across episodes is crucial"
  - [corpus]: Weak evidence - corpus papers don't directly address episodic vs global bonus tradeoffs in CMDPs
- Break condition: If episode length is too short to explore relevant state space, or if value function structure is shared across contexts (making global bonuses more efficient)

### Mechanism 3
- Claim: Multiplicative combination provides robustness across varying degrees of shared structure
- Mechanism: Multiplication preserves effectiveness of both bonuses - when episodic bonus is dominant (little shared structure), global bonus has minimal effect, and vice versa; when both are informative, their product amplifies the signal
- Core assumption: The scale differences between global and episodic bonuses don't prevent effective multiplicative combination
- Evidence anchors:
  - [abstract]: "combining the two bonuses can lead to more robust performance across different degrees of shared structure"
  - [section 3.4]: "if we combine the two multiplicatively the global bonus will still have an effect regardless of its scale"
  - [corpus]: Weak evidence - corpus papers don't discuss multiplicative combination strategies
- Break condition: If one bonus type consistently dominates the other to the point of making the combination equivalent to using only that bonus

## Architecture Onboarding

- Component map:
  State observation -> Feature extractor ψ -> Global bonus module + Episodic bonus module -> Combined bonus (multiplicative) -> Policy network -> Action

- Critical path:
  1. State observation → ψ → feature representation
  2. Feature representation → global and episodic bonus modules
  3. Bonuses combined (multiplication preferred)
  4. Combined bonus added to environment reward
  5. Policy optimizes combined reward
  6. Agent experience stored for global bonus computation

- Design tradeoffs:
  - Count-based vs. function approximation bonuses: Counts scale poorly to high-dimensional spaces; function approximation requires learning but generalizes better
  - Additive vs. multiplicative combination: Addition may be dominated by larger bonus; multiplication preserves both but may amplify noise
  - Episodic vs. global scope: Episodic avoids cross-context interference but may miss transfer opportunities; global enables transfer but risks interference

- Failure signatures:
  - Poor performance despite exploration: Check if feature extractor ψ maps to space where value function varies little across contexts (favoring global bonuses) or significantly (favoring episodic)
  - Unstable training: Check bonus scales - if one bonus dominates by orders of magnitude, consider normalization or multiplicative combination
  - No improvement over baseline: Verify that the bonus is actually encouraging novel behavior rather than just adding noise

- First 3 experiments:
  1. Implement MiniHack MultiRoom with position-based global bonus vs episodic bonus to reproduce Section 3.1 results
  2. Implement combined multiplicative bonus on same environment to verify Section 3.4 claims
  3. Test on Habitat with RND vs E3B vs combined bonus to verify pixel-based generalization claims from Section 3.5

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the variance of the value function across contexts formally relate to the sample complexity of exploration algorithms?
- Basis in paper: [inferred] The paper develops a conceptual framework based on the variance of the value function across contexts (V*_ψ,c) to explain the effectiveness of global vs. episodic bonuses, but does not provide formal sample complexity bounds.
- Why unresolved: The paper provides empirical evidence and intuitive explanations but does not derive theoretical bounds connecting the variance of V*_ψ,c to sample complexity.
- What evidence would resolve it: Formal sample complexity bounds showing how the variance of V*_ψ,c across contexts affects the number of samples required for efficient exploration using global or episodic bonuses.

### Open Question 2
- Question: What is the optimal way to adaptively combine global and episodic bonuses during training rather than using a fixed multiplicative or additive combination?
- Basis in paper: [inferred] The paper shows that multiplicative combination of global and episodic bonuses is more robust than additive combination, but does not explore adaptive strategies for combining them based on environment interaction.
- Why unresolved: The paper only considers fixed combination strategies (multiplication or addition) and does not investigate whether the optimal combination ratio should change during training or based on the specific CMDP.
- What evidence would resolve it: Experimental results comparing adaptive combination strategies (e.g., learning the combination weight during training) against fixed combinations across various CMDPs with different degrees of shared structure.

### Open Question 3
- Question: How does the choice of feature extractor ψ impact the effectiveness of global vs. episodic bonuses in complex, high-dimensional environments?
- Basis in paper: [explicit] The paper states that "since V*_ψ,c and ψ both appear in the definition of V*_ψ,c in equation 7, the relative advantage of the global vs. episodic bonuses will depend both on the structure of the CMDP, and the feature extractor ψ used to compute the novelty bonus."
- Why unresolved: While the paper demonstrates the importance of ψ through experiments with different feature extractors (positions, messages), it does not systematically study how different choices of learned feature extractors affect the performance of global vs. episodic bonuses.
- What evidence would resolve it: A comprehensive study comparing different learned feature extractors (e.g., random networks, inverse dynamics models, contrastive learning) and their impact on the performance of global vs. episodic bonuses across various CMDPs.

## Limitations
- Limited experimental validation across diverse CMDP structures
- Theoretical framework's predictions remain largely untested
- Core mechanism explaining multiplicative combination superiority lacks rigorous mathematical proof
- Assumption about feature extractor's adequacy not empirically validated

## Confidence

- **High confidence:** The distinction between global and episodic bonus effectiveness based on shared structure (supported by abstract and section 3.1-3.3)
- **Medium confidence:** The multiplicative combination mechanism (supported by abstract and section 3.4 but lacks formal proof)
- **Low confidence:** Claims about pixel-based generalization without detailed architectural specifications
