# Probing Brain Context-Sensitivity with Masked-Attention Generation

## Quick Facts
- arXiv ID: 2305.13863
- Source URL: https://arxiv.org/abs/2305.13863
- Reference count: 4
- Most language-related brain regions are sensitive to contextual information, with the right hemisphere showing sensitivity to longer contexts than the left.

## Executive Summary
This study introduces masked-attention generation, a method that uses GPT-2 transformers to create word embeddings with controlled contextual information. By manipulating attention masks, the authors generated embeddings capturing different window sizes of context (1-45 tokens) and tested their ability to predict fMRI brain activity during naturalistic text listening. Results showed that most language-related brain regions are sensitive to contextual information, with the right hemisphere exhibiting sensitivity to longer contexts than the left. The study quantified the maximal context window size per voxel, revealing distinct patterns of context integration across brain regions.

## Method Summary
The method generates word embeddings using GPT-2 transformers with controlled context windows by applying binary attention masks that zero out attention weights for tokens outside the target window. These context-windowed embeddings are then used to predict fMRI brain activity through linear regression encoding models. The predictive performance (R scores) is evaluated across different window sizes to identify brain regions sensitive to context and determine the maximal context window size per voxel.

## Key Results
- Most language-related brain regions show sensitivity to contextual information
- The right hemisphere is more sensitive to longer contexts than the left hemisphere
- Distinct patterns of context integration are observed across brain regions, with maximal context sizes varying by location

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Masked-attention generation isolates context effects by removing cross-window interactions in GPT-2.
- Mechanism: The method applies a binary attention mask that zeros out attention weights for tokens outside the target window while preserving positional encoding, ensuring embeddings only integrate information within the specified range.
- Core assumption: Attention masks prevent information leakage across window boundaries despite model depth.
- Evidence anchors:
  - [abstract] "The attention mask removed interactions with words outside the window, while preserving interactions within the context window"
  - [section] "The attention mask is the same for all the tokens in the input sequence, modulo the incrementality. Otherwise, information could propagate outside the context window because of model's depth."
  - [corpus] Weak correlation (FMR=0.52) with context-windowing papers suggests this is a novel approach

### Mechanism 2
- Claim: fMRI encoding models can detect context sensitivity by measuring how predictive performance changes with window size.
- Mechanism: Linear regression models trained on context-windowed embeddings predict voxel responses; regions requiring long-range information show improved prediction with larger windows.
- Core assumption: Brain regions that integrate information beyond local context will show monotonic improvement in encoding model R-scores as window size increases.
- Evidence anchors:
  - [abstract] "If the model needs long-range information to build the embedding of a word, then the embedding won't be affected when using a small context size. However, if the model needs long-range information, the embedding will be 'damaged' when using a small context size."
  - [section] "Thus, increasing context size won't improve R scores in the brain regions well-fitted by features using short-range information. However, brain regions well-fitted by features using long-range information will benefit from increasing context size."
  - [corpus] FMR=0.63 with "large language models contexts" suggests relevance to window-size encoding approaches

### Mechanism 3
- Claim: Hemispheric differences in context integration reflect distinct neural computation strategies.
- Mechanism: The right hemisphere shows sensitivity to longer contexts than the left, suggesting specialized processing for extended temporal dependencies in language comprehension.
- Core assumption: Different brain regions integrate information over distinct temporal scales, with right hemisphere specialized for longer-range integration.
- Evidence anchors:
  - [abstract] "the right hemisphere is more sensitive to longer contexts than the left" and "brain regions integrating longer-context revolves around the Temporo-Parietal Junction, Superior frontal regions and medial regions"
  - [section] "This observation is consistent with other brain imaging studies that have supported the role of the right hemisphere in higher-level language tasks"
  - [corpus] FMR=0.68 with "retrieval-augmented generation" suggests relevance to context-length modeling

## Architecture Onboarding

- Component map: GPT-2 transformer (layer 9, dim=768) -> Attention mask generator -> Context-windowed embeddings -> Linear regression encoding models -> fMRI brain data -> Statistical analysis pipeline
- Critical path: Embedding generation with controlled context -> Encoding model training for each window size -> Performance evaluation (R scores) -> Statistical testing of context-sensitivity -> Maximal context-size determination
- Design tradeoffs: Layer 9 selection balances representational power with computational efficiency; 45-token maximum window captures most but not all linguistic dependencies; binary masks are simple but may not handle partial context elegantly
- Failure signatures: Low R scores across all window sizes suggest poor model-brain alignment; non-monotonic performance curves indicate masking failures or confounding factors; hemispheric differences that disappear with different statistical thresholds suggest measurement artifacts
- First 3 experiments:
  1. Verify masking by comparing embeddings with full vs. masked attention for a single sentence across different window sizes
  2. Test encoding model performance on a single subject to ensure the pipeline works before scaling to group analysis
  3. Compare left vs. right hemisphere context-sensitivity on a subset of language-related regions to validate the hemispheric difference before full atlas analysis

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the sensitivity to contextual information vary across different types of linguistic content (e.g., semantic vs syntactic vs pragmatic information)?
- Basis in paper: [inferred] The authors mention that information-restricted neural language models reveal different brain regions' sensitivity to semantics, syntax and context, but the current study does not directly examine this distinction.
- Why unresolved: The current study uses a general approach to measure context sensitivity without distinguishing between different types of linguistic information processed by the brain.
- What evidence would resolve it: A study using masked-attention generation with separate models trained to capture specific linguistic features (semantic, syntactic, pragmatic) and comparing their predictive power for different brain regions.

### Open Question 2
- Question: How does the temporal dynamics of context integration vary across brain regions?
- Basis in paper: [explicit] The authors note that previous studies have found brain regions with different temporal receptive fields, but their method only provides a static measure of maximal context window size.
- Why unresolved: The current study uses a fixed context window approach that doesn't capture the temporal dynamics of how context information is integrated over time.
- What evidence would resolve it: An extension of the masked-attention generation method to include time-varying context windows or dynamic neural network architectures that can model temporal receptive fields.

### Open Question 3
- Question: How do individual differences in language proficiency or cognitive abilities affect context sensitivity in the brain?
- Basis in paper: [inferred] The study uses data from 51 subjects but does not explore individual differences in context sensitivity patterns.
- Why unresolved: The current analysis aggregates data across subjects without examining potential individual variations in how different brain regions integrate contextual information.
- What evidence would resolve it: A study that correlates individual measures of language proficiency or cognitive abilities with the patterns of context sensitivity observed in different brain regions.

## Limitations

- The masked-attention generation method may not perfectly isolate context windows due to potential information leakage through residual connections or positional encoding dependencies
- The fMRI encoding approach assumes monotonic improvement in predictive performance with increasing context window size, which may not hold for all brain regions
- Hemispheric differences in context integration could be influenced by measurement artifacts, including differential signal-to-noise ratios between hemispheres

## Confidence

**High Confidence:** The core methodological contribution of masked-attention generation is well-specified and reproducible. The implementation details for attention masking and context-windowed embedding generation are clearly described, and the approach represents a novel contribution to controlled embedding generation.

**Medium Confidence:** The finding that language-related brain regions show sensitivity to contextual information is supported by the data, but the specific patterns of context integration and maximal context-window sizes per voxel require careful interpretation given potential confounding factors in the encoding model approach.

**Low Confidence:** The hemispheric differences in context integration (right hemisphere sensitivity to longer contexts) represent the most speculative claim, as these could arise from measurement artifacts, preprocessing differences, or statistical testing procedures rather than true neurobiological differences in computation strategies.

## Next Checks

1. **Masking Effectiveness Validation:** Test the attention mask implementation by comparing embeddings generated with full attention versus masked attention for identical sentences across all window sizes. Verify that information from outside the context window is truly excluded by measuring cross-window similarity correlations.

2. **Encoding Model Robustness:** Perform permutation tests where word order is shuffled while preserving local n-gram statistics to determine if observed context-sensitivity effects persist when local features are controlled. This would validate that the effects reflect true contextual integration rather than local linguistic patterns.

3. **Hemispheric Difference Replication:** Replicate the hemispheric analysis using different statistical thresholds (FDR q-values from 0.01 to 0.2) and different ROI definitions to test the robustness of the right hemisphere's enhanced context sensitivity. Additionally, test whether these differences persist when controlling for overall signal strength differences between hemispheres.
