# Counterfactual Formulation of Patient-Specific Root Causes of Disease

## Quick Facts
- arXiv ID: 2305.17574
- Source URL: https://arxiv.org/abs/2305.17574
- Reference count: 14
- Key outcome: Presents a counterfactual framework for identifying patient-specific root causes of disease using backtracking counterfactuals and Shapley values

## Executive Summary
This paper introduces a counterfactual framework for identifying patient-specific root causes of disease that aligns with clinical intuition. The method defines root causes as root vertices that significantly increase disease likelihood compared to a typical person. By using backtracking counterfactuals with fixed factual error terms and computing root causal contributions via Shapley values, the approach handles noisy diagnostic labels, adapts to disease prevalence changes, and achieves computational efficiency without requiring counterfactual simulation.

## Method Summary
The method leverages Structural Equation Models (SEMs) to recover error term values from observed patient data, then uses backtracking counterfactuals to maintain these error terms while computing disease likelihood. Root causal contributions are quantified using Shapley values from explainable AI, providing a consistent measure of individual variable contributions that satisfies local accuracy, missingness, and consistency desiderata.

## Key Results
- Defines root causes as root vertices with significant disease likelihood increase vs typical person
- Uses backtracking counterfactuals to preserve factual error terms during inference
- Employs Shapley values to assign unique, consistent root causal contribution scores
- Achieves computational efficiency by avoiding explicit counterfactual simulation
- Handles noisy labels and adapts to disease prevalence changes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The counterfactual formulation aligns with clinical intuition by preserving factual error term values during inference
- Mechanism: By setting the backtracking conditional P(ε* = ε | ε) = 1, the method ensures counterfactual worlds maintain the same error term values as the factual world, matching how clinicians reason from fixed patient data
- Core assumption: Clinicians' mental models of "typical persons" can be represented as distributions over error terms that preserve observed values
- Evidence anchors:
  - [abstract]: "The proposed counterfactual formulation of patient-specific root causes of disease accounts for noisy labels, adapts to disease prevalence and admits fast computation without the need for counterfactual simulation"
  - [section 3.4]: "Equations (4) and (5) thus ensure that we can identify ΦεD(ε) in Equation (3) and patient-specific root causes per Definition 2 without changing the error term values"
  - [corpus]: No direct evidence found in neighbors; corpus is weak here
- Break condition: The assumption fails if clinicians actually compare patients to imagined interventions rather than fixed data

### Mechanism 2
- Claim: Shapley values provide a unique, consistent measure of individual variable contributions
- Mechanism: The Shapley value formulation satisfies three desiderata (local accuracy, missingness, consistency) that make it both necessary and sufficient for root causal contribution measurement
- Core assumption: The total causal effect P(Ξ|ε) - P(Ξ) can be uniquely partitioned among variables without double-counting or omission
- Evidence anchors:
  - [section 4]: "The Shapley value is in fact the only value satisfying the above three desiderata [5], so the value is both a necessary and sufficient measure of root causal contribution"
  - [abstract]: "We then show how to assign a root causal contribution score to each variable using Shapley values from explainable artificial intelligence"
  - [corpus]: Weak evidence; no neighbor papers discuss Shapley value properties
- Break condition: The Shapley decomposition fails if variables have non-additive interactions or if the causal effect is non-linear in ways that violate the additivity assumption

### Mechanism 3
- Claim: The approach achieves computational efficiency by avoiding explicit counterfactual simulation
- Mechanism: By using backtracking counterfactuals with fixed error terms instead of interventional counterfactuals requiring new error term distributions, the method eliminates the need for Monte Carlo sampling or enumeration over all possible sets
- Core assumption: The invertible SEM structure allows recovery of error term values from observed data without simulation
- Evidence anchors:
  - [abstract]: "admits fast computation without the need for counterfactual simulation"
  - [section 4]: "our proposed Shapley values require enumeration over all possible sets or Monte Carlo sampling, whereas we can leverage existing algorithms for fast approximation even in the nonlinear case [4, 5]"
  - [corpus]: No direct evidence; neighbors don't discuss computational efficiency of counterfactual methods
- Break condition: Computational advantage disappears if the SEM is not invertible or if error term recovery requires expensive optimization

## Foundational Learning

- Concept: Pearl's Ladder of Causation (prediction → intervention → counterfactuals)
  - Why needed here: The paper explicitly claims to "climb to the third rung" by moving from interventional to counterfactual formulations
  - Quick check question: What distinguishes counterfactual reasoning from interventional reasoning in terms of what distributions need to be estimated?

- Concept: d-separation and the global Markov property
  - Why needed here: The method relies on conditional independence properties to identify root causes and compute causal effects
  - Quick check question: How does d-separation between a set of root vertices and the diagnosis imply that the set is not a root cause?

- Concept: Structural Equation Models and error term recovery
  - Why needed here: The approach requires identifying factual error term values from observed data using invertible SEMs
  - Quick check question: In an invertible SEM, how can you recover error term values from observed variables in both linear and nonlinear cases?

## Architecture Onboarding

- Component map: Patient data → SEM identification → Error term recovery → Predictive model P(Ξ|ε) → Shapley value computation → Root cause scores
- Critical path: The pipeline flows from raw patient data through causal structure learning to individual Shapley contributions; any failure in error term recovery blocks the entire analysis
- Design tradeoffs: Using backtracking counterfactuals preserves clinical intuition but requires invertible SEMs; using Shapley values ensures consistency but may miss complex non-additive interactions
- Failure signatures: Negative Shapley values (impossible by construction), inconsistent scores across prevalence changes, computational timeouts during enumeration
- First 3 experiments:
  1. Verify error term recovery on synthetic data with known SEM structure
  2. Test Shapley value computation on simple three-variable causal models
  3. Validate that scores remain stable across different disease prevalence rates in simulated populations

## Limitations
- Relies on invertible SEMs which may not hold with measurement error and unmeasured confounders
- Clinical validity of treating root causes as counterfactual comparisons to "typical persons" remains untested
- May miss complex non-additive interactions due to Shapley value additivity assumption

## Confidence

- High confidence: The Shapley value properties and their uniqueness guarantees (mechanism 2)
- Medium confidence: The computational efficiency claims via backtracking counterfactuals (mechanism 3)
- Low confidence: The clinical intuition alignment mechanism (mechanism 1), due to lack of empirical validation with medical practitioners
