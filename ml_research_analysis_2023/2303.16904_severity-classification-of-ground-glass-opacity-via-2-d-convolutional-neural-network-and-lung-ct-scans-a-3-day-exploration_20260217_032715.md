# Severity classification of ground-glass opacity via 2-D convolutional neural network and lung CT scans: a 3-day exploration

## Quick Facts
- arXiv ID: 2303.16904
- Source URL: https://arxiv.org/abs/2303.16904
- Reference count: 24
- This proof-of-concept framework classifies GGO severity in lung CT scans using 2D CNNs developed in three days

## Executive Summary
This study presents a rapid proof-of-concept framework for classifying ground-glass opacity severity in lung CT scans using 2D convolutional neural networks. Developed over three days as part of the ICASSP 2023 COVID-19 Competition, the approach fine-tunes various pre-trained architectures including DenseNet, ResNet, InceptionNet, VGG, and Vision Transformers. The framework achieves preliminary results comparable to baseline models from competition organizers. Source code is publicly available on GitHub.

## Method Summary
The framework leverages pre-trained 2D CNN architectures fine-tuned for GGO severity classification. ADAM optimization with a learning rate of 0.001 is used for training, with the best model state selected based on validation accuracy. The approach operates on 2D slices extracted from lung CT scans rather than volumetric 3D data. Various architectures including DenseNet, ResNet, InceptionNet, VGG, and Vision Transformers are explored, demonstrating the feasibility of rapid development for medical image classification tasks.

## Key Results
- Various pre-trained 2D CNNs achieved performance comparable to competition baseline models
- Best model states selected based on validation accuracy for classifying unseen samples
- Framework developed and evaluated within a three-day timeframe

## Why This Works (Mechanism)
The approach works by leveraging transfer learning from ImageNet-pretrained models, which capture general visual features that can be adapted to medical imaging tasks. 2D CNNs process individual CT slices, extracting hierarchical features from simple edges to complex patterns that distinguish GGO severity levels. Fine-tuning pre-trained models allows rapid adaptation to the specific domain of lung CT imaging with limited training data.
