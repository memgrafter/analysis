# Inseq: An Interpretability Toolkit for Sequence Generation Models

## Quick Facts
- arXiv ID: 2302.13942
- Source URL: https://arxiv.org/abs/2302.13942
- Reference count: 24
- Key outcome: Inseq is a Python library that provides an intuitive interface to apply feature attribution techniques to sequence generation models, enabling fair comparison of different methods for encoder-decoder and decoder-only Transformers.

## Executive Summary
Inseq is a Python library designed to make interpretability analyses of sequence generation models more accessible and efficient. The library provides optimized, batched feature attribution methods that can be applied to popular decoder-only and encoder-decoder Transformer architectures. By abstracting complex attribution computations into a simple interface, Inseq enables users to apply gradient-based, internals-based, and perturbation-based methods across datasets, making sequence models first-class citizens in interpretability research.

## Method Summary
Inseq combines sequence models sourced from Transformers with attribution methods from Captum to provide a flexible interface for interpretability analyses. The library allows users to attribute single examples or entire datasets, save resulting outputs and visualizations, and customize attribution targets through step functions. The modular architecture supports integration with different modeling frameworks and modalities, enabling advanced use cases like contrastive comparisons and uncertainty-weighted attribution using MC Dropout.

## Key Results
- Inseq provides optimized, batched feature attribution methods for sequence generation models, enabling efficient extraction of model internal information and feature importance scores.
- The library supports customizable attribution targets, allowing users to specify arbitrary step functions for advanced analyses like contrastive comparisons.
- Inseq's modular design enables easy extension to new modeling frameworks and modalities without substantial redesign.
