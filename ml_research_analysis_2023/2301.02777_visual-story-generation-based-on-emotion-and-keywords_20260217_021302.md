# Visual Story Generation Based on Emotion and Keywords

## Quick Facts
- arXiv ID: 2301.02777
- Source URL: https://arxiv.org/abs/2301.02777
- Reference count: 12
- Key outcome: Up to 62% better BLEU scores and 6.7% better BERT scores compared to baselines

## Executive Summary
This paper presents a pipeline for co-creating visual stories with users by combining text generation with image generation. The system generates the next sentence using user-specified keywords and emotion labels, then uses diffusion models to create corresponding images. Object detection on generated images provides additional keywords for future story development. The approach shows significant improvements over baseline models in BLEU, BERTScore, and other metrics, enabling more controlled and coherent story generation compared to text-only approaches.

## Method Summary
The method fine-tunes BERT on the Story Commonsense dataset for emotion prediction, then fine-tunes T5 using ROCStories with emotion and keyword prompts to generate next sentences. Diffusion models (Disco Diffusion or Stable Diffusion) create images corresponding to generated sentences, incorporating artist names and background information in prompts. YOLOv5 and Faster R-CNN detect objects in generated images to provide keywords for future story development. The system integrates these components into a pipeline where user input triggers emotion prediction, keyword extraction, story generation, image generation, and object detection in sequence.

## Key Results
- Up to 62% improvement in BLEU scores over baseline models
- 6.7% improvement in BERT scores
- Significant performance gains in METEOR and SacreBLEU metrics
- Effective integration of emotion and keyword prompts for controlled story generation

## Architecture Onboarding

- Component map: User Input -> Emotion Predictor (BERTNEXT EMO) -> Keyword Extractor (SceneGraphParser/YOLOv5/Faster R-CNN) -> Story Generator (T5BASE FINE-TUNED COMMON GEN) -> Image Generator (Disco Diffusion) -> Object Detection (YOLOv5/Faster R-CNN) -> Suggested Keywords

- Critical path: User input → Emotion prediction → Keyword extraction → Story generation → Image generation → Object detection → Suggested keywords for next iteration

- Design tradeoffs:
  - Using pre-trained models (BERT, T5, YOLO, Faster R-CNN) versus training from scratch
  - Artistic quality versus semantic accuracy in image generation
  - Number of keywords to suggest versus relevance
  - Generation speed versus quality

- Failure signatures:
  - Repeated or irrelevant sentences in story generation
  - Images that don't match the text prompt
  - Object detection that returns irrelevant or no objects
  - Emotion prediction that doesn't align with story context

- First 3 experiments:
  1. Test the prompt structure by comparing story generation with and without the KEYWORDS and EMOTION sections
  2. Validate image generation by checking if generated images match text prompts across different artists and styles
  3. Test object detection generalization by running YOLOv5 and Faster R-CNN on a small set of generated images and evaluating relevance of detected objects

## Limitations
- The system relies heavily on pre-trained models, limiting performance to their capabilities and generalization potential
- Evaluation focuses on text generation metrics without comprehensive human assessment of story coherence or visual-text alignment
- The system requires user input of keywords and emotions, which may not always be available or accurate
- Artistic image generation may prioritize style over semantic accuracy, potentially creating images that don't precisely match the text content

## Confidence

- **High confidence**: The core pipeline architecture (text generation → image generation → object detection) is technically sound and well-supported by existing research on each component. The integration of emotion and keyword prompts into story generation through structured T5 fine-tuning is well-established.
- **Medium confidence**: The claimed performance improvements (62% better BLEU scores, 6.7% better BERT scores) are based on reported metrics, but the evaluation lacks comprehensive human assessment of story coherence and visual-text alignment. The generalization of object detection models to artistic images is plausible but not extensively validated.
- **Medium confidence**: The assertion that the system enables more controlled and coherent story generation compared to text-only approaches is supported by the prompt structure methodology, but comparative human studies would strengthen this claim.
