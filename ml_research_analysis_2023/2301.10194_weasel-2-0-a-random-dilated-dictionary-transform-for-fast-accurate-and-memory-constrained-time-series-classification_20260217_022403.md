# WEASEL 2.0 -- A Random Dilated Dictionary Transform for Fast, Accurate and Memory Constrained Time Series Classification

## Quick Facts
- arXiv ID: 2301.10194
- Source URL: https://arxiv.org/abs/2301.10194
- Reference count: 39
- Key outcome: WEASEL 2.0 achieves highest median accuracy on 114 UCR datasets while reducing memory consumption by limiting feature space to 256 words per configuration

## Executive Summary
WEASEL 2.0 addresses the critical challenge of memory-constrained time series classification by introducing a novel dilated dictionary transform. The method combines dilation for multi-scale feature extraction with randomization-based ensembling, generating a fixed-size feature space that significantly reduces memory consumption compared to its predecessor while maintaining competitive accuracy. Through extensive experiments on 114 UCR datasets, WEASEL 2.0 demonstrates significantly higher accuracy than other dictionary methods and achieves the highest median accuracy overall.

## Method Summary
WEASEL 2.0 is a dictionary-based time series classification method that uses Symbolic Fourier Approximation (SFA) with a key innovation: dilation mapping for multi-scale feature extraction. The method generates randomized ensembles by varying hyper-parameters including window lengths and dilation factors, creating multiple SFA configurations each producing exactly 256 words. These configurations are then combined using Ridge regression for final classification. The approach addresses the memory limitations of the original WEASEL method while maintaining computational efficiency comparable to state-of-the-art kernel-based methods.

## Key Results
- Achieves highest median accuracy among all tested methods on 114 UCR datasets
- Reduces memory consumption by limiting feature space to 256 words per configuration (25-76k features total vs millions in previous methods)
- Maintains speed comparable to state-of-the-art kernel-based methods while significantly outperforming other dictionary approaches

## Why This Works (Mechanism)
WEASEL 2.0's effectiveness stems from its ability to capture multi-scale temporal patterns through dilation while maintaining computational efficiency. The randomized ensemble approach ensures robustness by exploring diverse feature representations across different scales and configurations. By constraining each configuration to exactly 256 words, the method prevents memory explosion that plagued earlier dictionary approaches, making it practical for large-scale applications. The combination of SFA for dimensionality reduction with Ridge regression provides both speed and accuracy in the classification pipeline.

## Foundational Learning
- **Symbolic Fourier Approximation (SFA)**: Converts time series to symbolic words using Fourier coefficients; needed for efficient dimensionality reduction and symbolic representation; quick check: verify word length=8 and alphabet size=2 in implementation
- **Dilation mapping**: Creates multi-scale features by sampling time series at different rates; needed to capture patterns at multiple temporal resolutions; quick check: ensure dilation factors vary systematically across ensemble members
- **Randomized ensembling**: Varies hyper-parameters across multiple runs; needed to explore diverse feature spaces and improve generalization; quick check: verify r_max parameter controls ensemble diversity
- **Ridge regression**: Regularized linear classifier for combining ensemble outputs; needed for stable predictions and handling correlated features; quick check: confirm regularization parameter is appropriately tuned

## Architecture Onboarding

**Component Map**: Time series -> Sliding windows -> Dilation mapping -> SFA transformation -> 256-word dictionary -> Feature vectors -> Ridge regression -> Classification

**Critical Path**: The core pipeline processes each time series through sliding window extraction, applies dilation mapping to create multi-scale representations, transforms these through SFA to generate symbolic words, counts word frequencies for feature vectors, and finally combines ensemble predictions via Ridge regression.

**Design Tradeoffs**: The 256-word constraint per configuration represents a deliberate tradeoff between expressive power and memory efficiency. While this limits the maximum possible accuracy compared to unbounded dictionary methods, it enables practical application to large datasets and ensures predictable memory usage. The randomization approach compensates for this constraint by exploring diverse feature spaces across the ensemble.

**Failure Signatures**: Memory issues may arise with extremely long time series or large numbers of ensemble members; suboptimality in accuracy may indicate incorrect SFA parameter settings (word length, alphabet size, Fourier selection criteria). Performance degradation typically manifests as either excessive memory consumption or failure to capture discriminative patterns at appropriate scales.
