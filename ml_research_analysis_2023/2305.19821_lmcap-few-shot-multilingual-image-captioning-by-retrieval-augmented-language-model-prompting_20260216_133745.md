# LMCap: Few-shot Multilingual Image Captioning by Retrieval Augmented Language Model Prompting

## Quick Facts
- arXiv ID: 2305.19821
- Source URL: https://arxiv.org/abs/2305.19821
- Reference count: 15
- One-line primary result: Achieves competitive performance against fully-supervised models without training data

## Executive Summary
LMCap introduces an image-blind few-shot multilingual image captioning approach that leverages retrieval-augmented language model prompting. The method retrieves captions from similar images using a multilingual CLIP model, then prompts an XGLM decoder to generate captions in the desired language. This approach works without any supervised training on captioning data and demonstrates competitive performance across multiple languages on the XM3600 dataset.

The key innovation is using retrieval-augmented prompting to provide visual context through retrieved captions rather than direct image processing. By formatting retrieved captions alongside few-shot examples into a prompt for a multilingual language model, LMCap can generate captions in any target language, excelling particularly on Chinese while remaining competitive on English, Spanish, and Hindi.

## Method Summary
LMCap operates through an image-blind retrieval-augmented prompting pipeline. Given an input image, it first retrieves the captions of similar images from a datastore using a multilingual CLIP encoder. These retrieved captions, representing visual information about the image, are formatted into a prompt alongside N-shot examples. The prompt is fed to an XGLM decoder, which generates captions in the desired language. After generating multiple caption candidates, the multilingual CLIP model performs a final image-text similarity step to select the most appropriate caption.

## Key Results
- Achieves competitive CIDEr scores against fully-supervised multilingual captioning models without requiring any supervised training data
- Particularly excels on Chinese captions while remaining competitive on English, Spanish, and Hindi
- Ablation studies demonstrate the importance of using multiple retrieved captions (K=4) and sufficient few-shot examples (N=3)
- Shows effectiveness of retrieval-augmentation in few-shot multilingual image captioning scenarios

## Architecture Onboarding

- Component map:
  - Input: Image to be captioned
  - Vision module: Multilingual CLIP encoder for image-text retrieval
  - Datastore: Collection of image-caption pairs (primarily COCO training captions)
  - Retrieval step: Finds K most similar captions to input image
  - Prompt assembly: Combines K retrieved captions with N-shot examples
  - Generation module: XGLM decoder generates c caption candidates
  - Reranking step: Multilingual CLIP scores and selects best caption
  - Output: Final caption in target language

- Critical path: Image → CLIP retrieval → Prompt assembly → XGLM generation → CLIP reranking → Final caption

- Design tradeoffs:
  - Retrieval vs. direct encoding: Image-blind approach saves computation but depends entirely on retrieval quality
  - Datastore size vs. relevance: Larger datastores may contain more noise, affecting retrieval quality
  - K retrieved captions vs. prompt coherence: More captions provide more context but may dilute the prompt signal
  - N-shot examples vs. prompt length: More examples improve demonstration quality but consume LM capacity

- Failure signatures:
  - Poor retrieval quality: Generated captions are irrelevant to the input image
  - Inadequate few-shot examples: Generated captions lack proper structure or contain errors
  - Cross-lingual transfer failure: Generated captions in target language are garbled or untranslated
  - Reranker miscalibration: Selected caption is not the most visually appropriate

- First 3 experiments:
  1. Vary K (number of retrieved captions) and observe impact on caption quality across languages
  2. Test different N-shot example counts to find optimal prompt structure
  3. Compare performance using datastore with only English captions vs. augmented with multilingual captions

## Limitations
- Performance highly dependent on retrieval quality from multilingual CLIP model
- Limited evaluation to only four languages despite 36-language dataset availability
- Unknown optimal prompt template and few-shot example selection strategy
- Potential bias toward languages with more pre-training data in the XGLM model

## Confidence
**High Confidence Claims:**
- The image-blind retrieval-augmented prompting approach is technically feasible and can generate multilingual captions without requiring training data
- The multilingual CLIP model can effectively retrieve captions from similar images across different languages
- The reranking step using image-text similarity improves caption selection

**Medium Confidence Claims:**
- LMCap achieves "competitive" performance against fully-supervised models (based on CIDEr scores)
- The model particularly excels on Chinese and is competitive on other tested languages
- Retrieval augmentation is effective for few-shot multilingual captioning

**Low Confidence Claims:**
- Claims about performance on languages not explicitly tested (beyond the four reported)
- Generalization to different image domains beyond the XM3600 dataset
- Scalability to significantly larger or more diverse datastores

## Next Checks
1. **Prompt Template Validation**: Implement and test multiple prompt template variations with different N-shot example counts and formats to identify the optimal configuration. This will validate the sensitivity of the approach to prompt engineering choices.

2. **Datastore Ablation Study**: Compare performance using different datastore compositions: (a) only English captions, (b) English plus multilingual captions, (c) captions from diverse image domains. This will reveal how datastore diversity affects cross-lingual generation quality.

3. **Cross-Lingual Transfer Analysis**: Systematically test the model's ability to generate captions in languages not present in the retrieved captions. For example, retrieve captions in languages A, B, and C, then attempt to generate in language D to quantify the cross-lingual transfer capabilities of the XGLM decoder.
