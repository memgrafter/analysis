# arXiVeri: Automatic table verification with GPT

## Quick Facts
- arXiv ID: 2306.07968
- Source URL: https://arxiv.org/abs/2306.07968
- Reference count: 40
- Novel task: Automatic table verification (AutoTV) using LLMs to cross-reference numerical data in tables with cited sources

## Executive Summary
This paper introduces the novel task of automatic table verification (AutoTV), which aims to verify the accuracy of numerical data in tables by cross-referencing cited sources. The authors propose a new benchmark called arXiVeri, consisting of tabular data from open-access academic papers on arXiv. They introduce evaluation metrics for table matching and cell matching, and leverage large language models (LLMs) like GPT-4 to establish baselines for table verification. The findings highlight the complexity of the task, even for state-of-the-art LLMs.

## Method Summary
The authors introduce the arXiVeri benchmark, which includes 3.8K target-source cell pairs and 158 target-source table pairs from arXiv papers. They develop evaluation metrics for table matching (identifying the source table in a cited document) and cell matching (locating shared cells between target and source tables). The approach leverages GPT-4 to perform table verification, using various techniques such as table format specification, cell indices, and temperature settings. Ablation studies are conducted to evaluate the importance of these components in improving GPT-4's performance.

## Key Results
- The arXiVeri benchmark comprises 3.8K target-source cell pairs and 158 target-source table pairs, showcasing diverse table sizes and structures.
- GPT-4 achieves reasonable performance on table verification tasks, but the results highlight the complexity of the task even for state-of-the-art LLMs.
- Ablation studies demonstrate the importance of table format specification, cell indices, and temperature settings in improving GPT-4's performance.

## Limitations
- The arXiVeri dataset may not fully capture the diversity of real-world table verification scenarios, particularly those involving proprietary or non-academic sources.
- The reliance on GPT-4 as the primary model for evaluation raises questions about generalizability to other LLMs or smaller models that might be more practical for widespread deployment.
- The evaluation metrics may not fully capture the nuances of table verification accuracy, especially in cases where tables have similar but not identical structures or content.
