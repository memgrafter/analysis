# Curriculum Based Multi-Task Learning for Parkinson's Disease Detection

## Quick Facts
- arXiv ID: 2302.13631
- Source URL: https://arxiv.org/abs/2302.13631
- Reference count: 0
- Primary result: Improved PD detection ROC-AUC from 0.604 to 0.653 using curriculum-based multi-task learning

## Executive Summary
Parkinson's disease detection from T1-weighted MRI remains challenging due to subtle brain differences in early stages. This work introduces a curriculum-based multi-task learning approach that leverages the Hoehn and Yahr staging system to define training difficulty, starting with more severely affected patients and progressing to milder cases. A 3D DenseNet121 backbone is pre-trained on UK Biobank data for sex classification and fine-tuned using multi-task learning (age, sex, diagnosis). The curriculum learning strategy improved PD classification ROC-AUC from 0.604 to 0.653 compared to standard training, with accuracy increasing from 0.653 to 0.674. Occlusion sensitivity analysis revealed improved localization of relevant brain regions, especially in earlier disease stages.

## Method Summary
The method employs a curriculum-based multi-task learning framework where training progresses through disease severity stages defined by the Hoehn and Yahr staging system. The approach uses a 3D DenseNet121 architecture pre-trained on UK Biobank data for sex classification, then fine-tuned for multi-task learning including age prediction, sex classification, and Parkinson's disease diagnosis. The curriculum strategy starts training with patients at more advanced disease stages (higher Hoehn and Yahr scores) before gradually incorporating milder cases. This progressive learning approach aims to leverage easier-to-classify severe cases first, building model capability before tackling more challenging early-stage discrimination.

## Key Results
- PD classification ROC-AUC improved from 0.604 to 0.653 using curriculum learning
- Classification accuracy increased from 0.653 to 0.674
- Occlusion sensitivity analysis showed improved localization of disease-relevant brain regions
- Benefits were particularly pronounced for early-stage disease detection

## Why This Works (Mechanism)
The curriculum learning approach works by gradually increasing task difficulty during training, allowing the model to first learn robust representations from clearly affected patients before tackling subtle differences in early-stage disease. By leveraging the Hoehn and Yahr staging system, the method creates a natural progression from easily distinguishable severe cases to more challenging mild cases. The multi-task learning component helps by forcing the model to learn representations that capture age-related and sex-related brain differences, which may share underlying patterns with Parkinson's pathology. The pre-training on healthy UK Biobank data provides a strong anatomical baseline before introducing disease-specific learning.

## Limitations
- Modest absolute improvement in ROC-AUC (0.049 increase) may not translate to clinical utility
- Single dataset (PPMI) used without external validation, limiting generalizability
- Hoehn and Yahr staging system has inter-rater variability that could affect curriculum reliability
- Pre-training on UK Biobank introduces potential domain shift when applied to PD patients
