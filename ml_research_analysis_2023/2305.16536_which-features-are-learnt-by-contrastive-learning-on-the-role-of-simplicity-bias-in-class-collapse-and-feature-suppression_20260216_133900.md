# Which Features are Learnt by Contrastive Learning? On the Role of Simplicity Bias in Class Collapse and Feature Suppression

## Quick Facts
- **arXiv ID**: 2305.16536
- **Source URL**: https://arxiv.org/abs/2305.16536
- **Reference count**: 40
- **Primary result**: First unified theoretical framework explaining class collapse and feature suppression in contrastive learning through simplicity bias

## Executive Summary
This paper provides the first unified theoretical framework to understand class collapse and feature suppression in contrastive learning (CL). The key insight is that the simplicity bias of (stochastic) gradient descent (SGD) plays a critical role in both phenomena. For class collapse, the authors prove that while not all global minimizers exhibit this behavior, the minimum norm minimizer does. Empirically, they show that SGD learns subclass features early in training but eventually unlearns them, leading to collapse. For feature suppression, the authors characterize two types: one due to limited embedding dimensionality and easy irrelevant features, and another due to imperfect data augmentations preserving irrelevant features. They prove that the minimum norm minimizer exhibits feature suppression in both cases. The paper also provides the first theoretical justification for combining supervised and unsupervised CL losses, showing that the joint loss avoids both class collapse and feature suppression.

## Method Summary
The authors analyze contrastive learning through matrix factorization theory, proving that the minimum norm solution found by SGD exhibits class collapse and feature suppression. They characterize two types of feature suppression: one due to limited embedding dimensionality forcing prioritization of discriminative features, and another due to imperfect data augmentations that preserve irrelevant features better than relevant ones. The theoretical analysis is supported by experiments on synthetic data with class/subclass/irrelevant features, MNIST RandBit, and CIFAR RandBit datasets using linear models and ResNet18 architectures with supervised, unsupervised, and joint contrastive losses.

## Key Results
- Class collapse occurs because minimum norm solutions suppress subclass features through SGD's simplicity bias
- Feature suppression happens in two scenarios: limited embedding dimensionality and imperfect augmentations preserving irrelevant features
- Joint supervised-unsupervised contrastive loss prevents both class collapse and feature suppression
- SGD learns subclass features early in training but unlearns them later due to the simplicity bias
- Minimum norm global minimizer exhibits feature suppression even with sufficient embedding size when augmentations are imperfect

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Simplicity bias of SGD is the primary driver of class collapse and feature suppression
- **Mechanism**: The minimum norm solution that SGD implicitly seeks suppresses subclass features and hard class-relevant features because they require more complex weight alignments to represent
- **Core assumption**: The implicit bias of SGD in matrix factorization settings is to find minimum norm solutions
- **Evidence anchors**: [abstract], [section 4.3]
- **Break condition**: If the implicit bias shifts toward minimum rank or another norm-based criterion

### Mechanism 2
- **Claim**: Insufficient embedding dimensionality causes feature suppression by forcing the model to prioritize discriminative features
- **Mechanism**: When embedding space is too small to represent all features, the model learns only the most discriminative ones (highest variance), suppressing less discriminative but semantically relevant features
- **Core assumption**: The embedding space has limited capacity relative to the number of semantically relevant features
- **Evidence anchors**: [section 5.1], [abstract]
- **Break condition**: If embedding dimensionality increases beyond the number of relevant features

### Mechanism 3
- **Claim**: Imperfect data augmentations that preserve irrelevant features better than relevant ones cause feature suppression
- **Mechanism**: When augmentations maintain the structure of irrelevant features while altering class-relevant features, the model learns to focus on the preserved irrelevant features for discrimination
- **Core assumption**: Data augmentation quality varies across feature types, with irrelevant features being more invariant to augmentation
- **Evidence anchors**: [section 5.2], [abstract]
- **Break condition**: If augmentations are improved to disrupt irrelevant feature structure

## Foundational Learning

- **Concept**: Matrix factorization and its relationship to contrastive learning
  - **Why needed here**: The contrastive loss can be reformulated as a matrix factorization objective, which helps understand the implicit bias of SGD
  - **Quick check question**: Can you express the supervised contrastive loss as a matrix factorization problem and identify what the learned matrix represents?

- **Concept**: Gradient descent implicit bias in overparameterized settings
  - **Why needed here**: Understanding how SGD's preference for simpler solutions affects feature learning is crucial for explaining class collapse and feature suppression
  - **Quick check question**: What is the implicit bias of SGD when minimizing the contrastive loss, and how does it relate to minimum norm solutions?

- **Concept**: High-dimensional geometry and random matrix theory
  - **Why needed here**: The analysis relies on properties of high-dimensional covariance matrices and their alignment with feature vectors
  - **Quick check question**: How does the kernel space of the covariance matrix behave in high dimensions, and what does this imply for feature alignment?

## Architecture Onboarding

- **Component map**: Data generation (class/subclass/irrelevant features + noise) → Data augmentation → Linear model (weights W, bias b) → Contrastive loss (supervised/unsupervised/joint) → (S)GD optimization → Analysis of learned weights and feature alignment

- **Critical path**: Data generation → Augmentation → Model training with (S)GD → Analysis of learned weights and feature alignment. Critical analysis points are early training (subclass learning) and late training (unlearning)

- **Design tradeoffs**: Balancing embedding dimensionality (more capacity vs. overfitting), augmentation quality (preserving relevant structure vs. disrupting irrelevant features), and loss weighting in joint training (β parameter)

- **Failure signatures**: Class collapse manifests as indistinguishable subclass embeddings; feature suppression appears as poor linear evaluation accuracy on suppressed features despite good overall performance

- **First 3 experiments**:
  1. Train with varying embedding sizes and measure feature suppression - expect alleviation with larger embeddings
  2. Compare augmentations with different invariance properties - expect better quality augmentations to reduce suppression
  3. Train with joint loss and different β values - expect improved performance when both supervised and unsupervised terms are present

## Open Questions the Paper Calls Out

### Open Question 1
- **Question**: How does the simplicity bias of SGD specifically contribute to unlearning subclass features during Phase II of training?
- **Basis in paper**: Explicit. The paper describes how the ratio of terms in the gradient decreases until it reaches a plateau around 1, coinciding with the peak of subclass feature alignment
- **Why unresolved**: The paper only provides intuition about how the second term's effect becomes more pronounced and reduces alignment with the subclass feature. A rigorous mathematical proof is needed
- **What evidence would resolve it**: A formal proof showing that the gradient dynamics cause the second term to eventually dominate over the first term for subclass features, while the first term remains dominant for class features

### Open Question 2
- **Question**: Under what specific conditions does increasing embedding dimensionality alleviate feature suppression in unsupervised contrastive learning?
- **Basis in paper**: Explicit. The paper proves that minimum norm minimizers exhibit feature suppression when embedding dimensionality is limited, and provides empirical evidence that increasing embedding size improves performance
- **Why unresolved**: The paper only considers a specific data distribution and augmentation strategy. It's unclear how these results generalize to other settings
- **What evidence would resolve it**: Theoretical analysis and experiments showing the relationship between embedding dimensionality, feature discriminability, and feature suppression across various data distributions and augmentation strategies

### Open Question 3
- **Question**: Can the negative impact of simplicity bias in contrastive learning be mitigated without increasing embedding dimensionality or improving data augmentations?
- **Basis in paper**: Explicit. The paper discusses the negative role of simplicity bias in class collapse and feature suppression, and suggests increasing embedding size and improving augmentations as solutions
- **Why unresolved**: The paper does not explore alternative approaches to mitigate the negative impact of simplicity bias
- **What evidence would resolve it**: Experiments and theoretical analysis demonstrating the effectiveness of other methods (e.g., regularization techniques, alternative loss functions) in mitigating simplicity bias without relying on embedding size or augmentations

## Limitations

- Analysis relies heavily on linear models and synthetic data distributions that may not capture real-world complexity
- Theoretical guarantees focus on global minima properties while practical training may differ due to optimization trajectories
- Empirical evaluation is limited to specific datasets (MNIST, CIFAR variants) and augmentation strategies

## Confidence

- **High confidence**: Theoretical analysis of class collapse under minimum norm solutions
- **Medium confidence**: Feature suppression mechanisms due to simplifying assumptions about data augmentations
- **Medium confidence**: Joint loss optimization benefits, limited by empirical evaluation scope
