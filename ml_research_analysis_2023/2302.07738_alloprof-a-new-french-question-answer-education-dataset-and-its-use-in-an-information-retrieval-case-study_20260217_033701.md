# Alloprof: a new French question-answer education dataset and its use in an information retrieval case study

## Quick Facts
- arXiv ID: 2302.07738
- Source URL: https://arxiv.org/abs/2302.07738
- Reference count: 29
- Primary result: Novel French educational dataset with 29,349 QA pairs and 58.5% retrieval accuracy

## Executive Summary
This paper introduces Alloprof, a new French question-answering dataset collected from the Alloprof educational website, containing 29,349 questions and explanations from 10,368 students across various school subjects. The dataset addresses the critical need for French language resources in education and includes multimodal content (text, images, formulas) with varying language proficiency levels. A case study applying this dataset to an information retrieval task demonstrates the practical utility of the resource, using transformer-based architectures to predict relevant documents for given student questions.

## Method Summary
The authors collected questions and answers from the Alloprof educational platform, resulting in 29,349 questions with explanations from 10,368 students across multiple subjects. They conducted an information retrieval case study using BERT-based transformer architectures to predict relevant documents (questions or reference pages) for given student questions. The study evaluated multiple models with different configurations, comparing prediction accuracy, MRR, and nDCG metrics while measuring inference times. The dataset includes multimodal content and covers varying language proficiency levels, making it suitable for developing algorithms for French education contexts.

## Key Results
- Best model achieved 58.5% prediction accuracy (MRR: 0.536, nDCG: 0.618) with 12.8s CPU inference time
- Faster model achieved 51.2% accuracy (MRR: 0.467, nDCG: 0.560) with 0.7s inference time
- Dataset contains 29,349 questions and explanations from 10,368 students across various school subjects

## Why This Works (Mechanism)
The BERT-based transformer architectures work by encoding student questions into contextualized embeddings, then computing similarity scores with document embeddings to rank and retrieve the most relevant educational content. The models leverage the self-attention mechanism to capture semantic relationships between question terms and document content, while the transformer architecture enables handling of long-range dependencies crucial for educational content comprehension.

## Architecture Onboarding

**Component Map:**
Student Question -> BERT Encoder -> Document Ranker -> Relevant Document Prediction

**Critical Path:**
Input question processing -> BERT embedding generation -> Document similarity scoring -> Top-K document retrieval

**Design Tradeoffs:**
The paper balances between model accuracy (58.5%) and inference speed (12.8s vs 0.7s), with faster models sacrificing approximately 7 percentage points in accuracy for a 18x speedup in inference time.

**Failure Signatures:**
- Poor performance on image-based questions
- Lower accuracy for questions with complex formulas
- Computational bottleneck for real-time applications
- Limited generalizability beyond Quebec educational context

## Limitations
- Dataset coverage limited to single educational platform (Alloprof) serving primarily Quebec students
- Moderate retrieval performance (58.5% accuracy) falls short of production-ready standards
- Multimodal comprehension capabilities not thoroughly demonstrated in reported results
