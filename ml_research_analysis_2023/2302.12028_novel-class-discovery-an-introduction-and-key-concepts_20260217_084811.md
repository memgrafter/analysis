# Novel Class Discovery: an Introduction and Key Concepts

## Executive Summary
This paper provides a comprehensive survey of Novel Class Discovery (NCD), where a labeled set of known classes and an unlabeled set of unknown classes are given during training. The goal is to discover the unknown classes in the unlabeled set. The paper categorizes NCD methods into two main approaches: two-stage methods that first learn a similarity function or latent space on the labeled data before applying it to the unlabeled data, and one-stage methods that jointly learn on both sets. Key techniques used in NCD include self-supervised learning for initialization, pseudo labeling to provide weak supervision, and contrastive learning to construct discriminative representations.

## Method Summary
The paper describes NCD as a problem where during training, a labeled set of known classes (Dl) and an unlabeled set of unknown classes (Du) are provided. The primary metric used to evaluate NCD models is clustering accuracy (ACC), with normalized mutual information (NMI) as another popular metric. Two main approaches are discussed: two-stage methods that first learn a similarity function or latent space on labeled data before applying it to unlabeled data, and one-stage methods that jointly learn on both sets. Key techniques include self-supervised learning (SSL) for initialization, pseudo labeling to provide weak supervision, and contrastive learning to construct discriminative representations.

## Key Results
- NCD methods are categorized into two-stage (similarity learning then clustering) and one-stage (joint learning) approaches
- SSL initialization helps avoid bias toward known classes by using both labeled and unlabeled data
- Pseudo labeling provides weak supervision but its accuracy is crucial for one-stage method success
- Performance is primarily measured using clustering accuracy (ACC) and normalized mutual information (NMI)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Transfer learning enables knowledge reuse from known to unknown classes.
- Mechanism: Labeled data provides class features or similarity patterns that guide clustering of unlabeled data.
- Core assumption: Known and unknown classes share high-level semantic features.
- Evidence anchors:
  - [abstract] "Novel Class Discovery (NCD) is a growing field where we are given during training a labeled set of known classes and an unlabeled set of different classes that must be discovered."
  - [section] "They first focus on Dl only (like a source dataset in TL) before exploring Du (similarly to a target dataset without labels in TL)."
- Break condition: Semantic features between known and unknown classes are too dissimilar.

### Mechanism 2
- Claim: One-stage methods jointly learn representations that benefit both classification and clustering.
- Mechanism: Shared encoder is trained with cross-entropy on labeled data and BCE on pseudo-labeled unlabeled data simultaneously.
- Core assumption: Joint optimization creates a latent space that represents both known and unknown classes effectively.
- Evidence anchors:
  - [abstract] "They either learn in two stages, by first extracting knowledge from the labeled data only and then applying it to the unlabeled data, or in one stage by conjointly learning on both sets."
  - [section] "Most one-stage methods jointly train two classiﬁcation networks... One predicts the labels of Dl and introduces the relevant features of the known classes, and the other partitions Du using pseudo labels..."
- Break condition: Pseudo labels are too noisy to provide meaningful supervision.

### Mechanism 3
- Claim: Self-supervised learning initializes representations that are less biased toward known classes.
- Mechanism: SSL pretext tasks (e.g., RotNet) use both labeled and unlabeled data to learn general features before supervised/fine-tuning.
- Core assumption: Features learned from pretext tasks generalize across known and unknown classes.
- Evidence anchors:
  - [section] "SSL allows the model to learn a robust representation that isn't biased towards the known classes, as all of the data (labeled and unlabeled) is used."
  - [section] "Many methods rely on similarity measures in the latent space to deﬁne pairwise relationships between unlabeled instances."
- Break condition: SSL pretext tasks are too domain-specific to generalize.

## Limitations

- Most methods rely heavily on strong assumptions about feature similarity between known and unknown classes
- Pseudo-label quality and noise levels vary significantly across datasets and methods
- Two-stage approaches may suffer from information loss during the separation of learning phases
- Limited empirical validation across diverse domain shifts and dataset types

## Confidence

- High confidence: The categorization of methods into two-stage vs one-stage approaches (supported by extensive literature review)
- Medium confidence: Effectiveness of self-supervised initialization (results vary significantly across implementations)
- Medium confidence: Pseudo-labeling reliability (quality highly dependent on threshold selection and dataset characteristics)
