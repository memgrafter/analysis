# Enhancing Grammatical Error Correction Systems with Explanations

## Quick Facts
- arXiv ID: 2305.15676
- Source URL: https://arxiv.org/abs/2305.15676
- Reference count: 14
- Primary result: Introduces EXPECT dataset for explainable GEC and achieves F0.5 score of 70.77 with interaction-based method

## Executive Summary
This paper introduces EXPECT, a large-scale dataset for explainable grammatical error correction (GEC) that provides evidence words and error types for each correction. The authors propose three baseline methods: generation-based, labeling-based, and interaction-based approaches to leverage this dataset. They also incorporate syntactic knowledge from dependency parsing to improve evidence word identification. Experiments show that the interaction-based method with syntactic knowledge achieves the best performance, and human evaluation verifies that the explainable GEC systems can help second-language learners understand corrections and associated grammar rules.

## Method Summary
The paper formulates evidence identification as a token classification task, where each token in the erroneous sentence is classified as an evidence word or not, and assigned an error type. Three baseline methods are proposed: generation-based (sequence-to-sequence), labeling-based (joint encoding with independent prediction), and interaction-based (bi-affine attention for explicit interaction between erroneous and corrected sentences). Syntactic knowledge is injected by extracting dependent words from dependency parse trees and mapping them to the erroneous sentence via word alignment. The models use BERT-large as the encoder with additional correction and syntactic embeddings.

## Key Results
- Interaction-based method with syntactic knowledge achieves best F0.5 score of 70.77 on EXPECT test set
- Correction embeddings improve performance by 2.64 F0.5 points on Dev set and 1.16 points on Test set
- Labeling-based methods show higher recall while interaction-based methods show higher precision

## Why This Works (Mechanism)

### Mechanism 1: Syntactic Knowledge Injection
The model incorporates dependency parsing information by extracting first and second-order dependent words from the corrected sentence's dependency parse tree and mapping them to the erroneous sentence via word alignment. This syntactic embedding is added to token representations, providing explicit syntactic context for evidence extraction. The approach assumes evidence words have strong syntactic relationships with correction words, though coverage is limited to 46.71% for first-order and 27.02% for second-order cases.

### Mechanism 2: Interaction-based Modeling
The interaction-based method uses bi-affine attention to capture multiplicative interactions between hidden representations of erroneous and corrected sentences. This joint reasoning about alignment and evidence extraction improves precision compared to independent prediction methods. The approach assumes that relationships between sentence pairs contain information that guides evidence identification.

### Mechanism 3: Correction Embeddings
Correction embeddings encode the position of correction words in both sentences, providing explicit positional information about corrections. These embeddings are added to token representations, giving the model awareness of where corrections occur. The approach assumes the model needs explicit positional information to effectively identify evidence words, resulting in measurable performance improvements across all model variants.

## Architecture Onboarding

- **Component map**: Input (concatenated erroneous and corrected sentences) → Embeddings (token, position, correction, syntactic) → Encoder (BERT-large) → Interaction (bi-affine attention for interaction-based method) → Classifier (linear layer with softmax) → Output (evidence words and error types for each token)

- **Critical path**: Input → Embeddings → Encoder → Interaction (if applicable) → Classifier → Output

- **Design tradeoffs**: 
  - Sequence-to-sequence vs. labeling approach: Labeling is more efficient but may capture less context
  - Interaction vs. independent prediction: Interaction improves precision but may reduce recall
  - Syntactic knowledge injection: Improves accuracy but depends on parser quality

- **Failure signatures**:
  - Poor evidence identification despite correct error type classification: Indicates issues with interaction mechanism or syntactic knowledge
  - High recall but low precision: Suggests the model is too permissive in identifying evidence words
  - Performance degradation on long sentences: Indicates limitations in capturing complex syntactic structures

## Limitations

- The dataset only annotates evidence words in the erroneous sentence, not in corrections, limiting the model's applicability to certain grammatical error types
- Syntactic knowledge injection has limited coverage, helping in only 46.71% of first-order and 27.02% of second-order cases
- The interaction-based method's precision-recall tradeoff is presented without systematic analysis of when each approach is preferable

## Confidence

**High confidence**: Core methodology of token classification for evidence identification and general BERT-based architecture with syntactic embeddings; performance improvements from correction embeddings are well-documented.

**Medium confidence**: Specific contribution of syntactic knowledge injection; while improvements are reported, limited coverage suggests the mechanism is not universally applicable.

**Low confidence**: Human evaluation methodology and generalizability; minimal detail on evaluation design, participant selection, or statistical significance of results.

## Next Checks

1. **Parser-robustness analysis**: Systematically evaluate model performance when injecting syntactic knowledge from different dependency parsers to quantify sensitivity to parser errors.

2. **Coverage expansion study**: Annotate instances where evidence words appear only in corrections, then retrain and evaluate to determine true impact of current annotation constraint.

3. **Precision-recall tradeoff analysis**: Conduct controlled experiments varying classification threshold to map full precision-recall curve for each method, providing quantitative guidance for deployment decisions.
