# Do Not Train It: A Linear Neural Architecture Search of Graph Neural Networks

## Quick Facts
- arXiv ID: 2305.14065
- Source URL: https://arxiv.org/abs/2305.14065
- Reference count: 40
- Key outcome: Proposes NAC algorithm that searches GNN architectures without updating GNN weights, achieving up to 200x speedup and 18.8% accuracy improvement

## Executive Summary
This paper introduces Neural Architecture Coding (NAC), a novel approach for graph neural network architecture search that leverages the built-in linearity and orthogonality of GNNs. The key insight is that randomly initialized GNN weights can form an orthogonal dictionary, allowing architecture search through sparse coding without updating the GNN parameters. This "no-update" scheme dramatically accelerates the search process while maintaining or improving performance. The method reformulates NAS-GNN as a sparse coding problem and proves that cross-entropy loss optimization satisfies conditions for l2-norm sparse coding, ensuring theoretical convergence.

## Method Summary
NAC reformulates neural architecture search for GNNs as a sparse coding problem by leveraging randomly initialized untrained GNNs. The search space is unified into a fixed dictionary format where architecture parameters α are learned through sparse coding optimization with L1 regularization. The GNN weights remain fixed at their random initialization throughout the search process, with only the output layer optionally updated. This approach eliminates the need for training GNN weights while searching for optimal architectures, resulting in dramatic computational speedup. The algorithm uses cross-entropy loss with L1 regularization to optimize architecture parameters α using gradient descent.

## Key Results
- Achieves up to 200x speedup compared to strong NAS baselines while maintaining or improving accuracy
- Demonstrates 18.8% accuracy improvement over state-of-the-art methods on benchmark datasets
- Theoretical analysis proves that untrained GNNs can achieve optimal performance under mild conditions
- Successfully handles 5/7 graph types in the unified search space with built-in sparsity

## Why This Works (Mechanism)

### Mechanism 1: Built-in Orthogonality of Untrained GNNs
- Claim: Untrained GNNs with random weights can achieve optimal performance due to built-in orthogonality
- Core assumption: The product of random weights QL l=1 Wl(0) must be full rank (invertible) and can be initialized as an orthogonal matrix
- Evidence anchors: "Theorem 3.1. Assume Wl(0) is randomly initialized for all l ∈ [1, L], if QL l=1 Wl(0) is full rank, there must exist a weight matrix for the output layer, i.e., ˜Wo, that makes the final output the same as the one from a well-trained network"
- Break condition: If the full rank assumption fails or if data complexity violates linear separability conditions

### Mechanism 2: NAS-GNN Reformulated as Sparse Coding
- Claim: NAS-GNN problem can be reformulated as a sparse coding problem using untrained GNNs
- Core assumption: Activation functions can be removed or simplified without affecting the theoretical analysis
- Evidence anchors: "Corollary 3.5. The search space of GNNs can be unified as PK k=0 Pk(L)XW k = DW when removing the activation function"
- Break condition: If activation functions significantly impact GNN performance beyond the simplified linear case

### Mechanism 3: Cross-Entropy Loss Satisfies Sparse Coding Conditions
- Claim: Cross-entropy loss optimization satisfies sufficient conditions for l2-norm sparse coding optimization
- Core assumption: Cross-entropy loss function is convex and smooth enough to satisfy the (α, β, γ)-correlation conditions
- Evidence anchors: "Theorem 3.7. The gradient from Cross-Entropy loss function is feasible to optimize an l2-norm objective in a gradient descent manner"
- Break condition: If cross-entropy loss violates convexity or smoothness assumptions required for convergence guarantees

## Architecture Onboarding

- Component map: Dictionary D (fixed GNN operators) -> Architecture parameters α (learned through sparse coding) -> Linear output layer Wo (optionally trainable)

- Critical path: 1) Initialize all GNN weights randomly (preferably orthogonal) 2) Compute feature aggregations using weighted combinations of all operators 3) Optimize architecture parameters α using sparse coding objective with L1 regularization 4) Optionally update output layer Wo 5) Select top-performing operators via argmax on α

- Design tradeoffs: The no-update scheme trades potential fine-tuning performance for significant computational speedup and optimization stability. The sparse coding approach sacrifices the ability to learn optimal operator weights in favor of faster architecture search and built-in sparsity.

- Failure signatures: Poor performance may indicate violated assumptions about weight orthogonality, data complexity exceeding linear separability conditions, or inadequate search space coverage. Slow convergence or instability suggests issues with initialization or hyperparameter selection.

- First 3 experiments:
  1. Verify built-in orthogonality by checking eigenvalue distribution of random weight initialization
  2. Test sensitivity to sparsity hyperparameter ρ by running with varying values [0.001, 10]
  3. Compare performance with and without training the output layer to validate no-update scheme effectiveness

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the proposed NAC method perform when applied to other types of neural networks beyond GNNs, such as CNNs or Transformers?
- Basis in paper: [inferred] The paper mentions that several promising directions can be considered, including exploring more deep neural networks that satisfy the mild conditions of NAC to extend its usability.
- Why unresolved: The current work focuses specifically on GNNs and their unique properties. Extending NAC to other architectures would require investigating whether those architectures also exhibit built-in linearity and orthogonality properties that make the no-update scheme effective.
- What evidence would resolve it: Empirical results showing NAC's performance on CNN and Transformer architectures, compared to traditional weight-sharing NAS methods, would demonstrate its generalizability.

### Open Question 2
- Question: What is the impact of using different types of regularization techniques in the sparse coding objective of NAC, and how do they affect the final architecture search results?
- Basis in paper: [explicit] The paper mentions that the sparsity regularization ||α||1 allows ranking the importance of operators directly and alleviates inaccurate gradient estimation.
- Why unresolved: While the paper uses L1 regularization, it does not explore other types of regularization techniques (e.g., L2, Elastic Net) and their effects on the search process and final architecture quality.
- What evidence would resolve it: Comparative experiments using different regularization techniques in the sparse coding objective, along with analysis of their impact on search efficiency and architecture performance, would provide insights into the optimal regularization strategy for NAC.

### Open Question 3
- Question: How does the proposed NAC method handle dynamic graphs or graphs with evolving structures, and what modifications are needed to adapt it for such scenarios?
- Basis in paper: [inferred] The current work focuses on static graph datasets and does not address the challenge of dynamic graphs. The paper mentions investigating how to jointly learn the search space and architectural representation to further enhance the expressive ability of searched architectures, which could potentially include dynamic graphs.
- Why unresolved: Dynamic graphs introduce additional complexity in terms of changing node relationships and feature distributions over time. Adapting NAC to handle such scenarios would require modifications to the search space definition and optimization process to account for temporal dependencies and evolving graph structures.
- What evidence would resolve it: Empirical results demonstrating NAC's performance on dynamic graph datasets, along with modifications to the algorithm that explicitly handle temporal aspects, would show its effectiveness in this challenging scenario.

## Limitations

- The theoretical guarantees rely on idealized assumptions about weight orthogonality and linear separability that may not hold in practice
- The method's effectiveness for dynamic graphs or graphs with evolving structures is not explored
- Limited empirical validation of the theoretical conversion from cross-entropy loss to l2-norm sparse coding objectives

## Confidence

**High Confidence**: The empirical performance improvements demonstrated on benchmark datasets are well-supported, with clear comparisons to strong baselines showing 18.8% accuracy improvements and 200x speedup.

**Medium Confidence**: The theoretical analysis connecting untrained GNNs to optimal performance through orthogonality properties is mathematically sound but relies on idealized assumptions.

**Low Confidence**: The conversion from cross-entropy loss to l2-norm sparse coding objectives lacks rigorous empirical validation, and the impact of activation functions on theoretical properties requires more thorough investigation.
