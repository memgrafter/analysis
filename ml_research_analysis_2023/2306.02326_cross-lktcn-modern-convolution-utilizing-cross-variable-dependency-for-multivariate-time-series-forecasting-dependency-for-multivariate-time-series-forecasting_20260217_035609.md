# Cross-LKTCN: Modern Convolution Utilizing Cross-Variable Dependency for Multivariate Time Series Forecasting Dependency for Multivariate Time Series Forecasting

## Quick Facts
- arXiv ID: 2306.02326
- Source URL: https://arxiv.org/abs/2306.02326
- Reference count: 40
- Primary result: State-of-the-art multivariate time series forecasting performance using pure convolution structure with depth-wise large kernel convolution and successive point-wise group convolution feed forward networks.

## Executive Summary
This paper introduces Cross-LKTCN, a modern pure convolution architecture for multivariate time series forecasting that effectively captures both cross-time and cross-variable dependencies. The model leverages depth-wise large kernel convolutions to model long-term temporal relationships and successive point-wise group convolution feed forward networks to capture dependencies among different variables. A patch-style embedding strategy is also employed to enhance locality and aggregate semantic information. Cross-LKTCN achieves state-of-the-art forecasting performance on real-world benchmarks, significantly outperforming existing convolutional-based models and cross-variable methods.

## Method Summary
Cross-LKTCN addresses multivariate time series forecasting by modeling both cross-time dependency (long-term temporal relationships) and cross-variable dependency (relationships among different variables) using a pure convolution architecture. The method employs depth-wise large kernel convolutions with kernel sizes of 31 or 51 to capture temporal dependencies by enlarging the receptive field. Two successive point-wise group convolution feed forward networks are used to capture cross-variable dependencies, with the first using M groups to learn new features for each variable and the second using D groups to capture interactions between variables. A patch-style embedding strategy divides the input time series into patches to enhance locality and aggregate semantic information. RevIN normalization is applied to mitigate distribution shift during training.

## Key Results
- Cross-LKTCN achieves state-of-the-art forecasting performance on real-world benchmarks including Weather, Traffic, Electricity, Exchange, ILI, and ETT datasets.
- The model significantly improves forecasting accuracy compared with existing convolutional-based models and cross-variable methods.
- Performance gains are demonstrated across multiple evaluation metrics including MSE and MAE.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Depth-wise large kernel convolution effectively captures long-term cross-time dependencies.
- Mechanism: Large kernel size (e.g., 31 or 51) expands the receptive field to aggregate information from distant time steps. Depth-wise separable structure decouples temporal and variable dimensions for efficient modeling.
- Core assumption: Larger kernels maintain sufficient resolution and can be optimized effectively using Structural Re-parameterization.
- Evidence anchors: [abstract] and [section 3.3] mention depth-wise large kernel convolution for enlarging receptive field and improving cross-time dependency modeling.
- Break condition: If kernel becomes too large relative to sequence length, padding artifacts and vanishing gradients could dominate.

### Mechanism 2
- Claim: Successive point-wise group convolution FFNs capture complex cross-variable dependencies efficiently.
- Mechanism: First group convolution (M groups) transforms each variable's features independently, while second (D groups) captures interactions between variables for each feature dimension.
- Core assumption: Grouping by M first and D second preserves variable-specific feature learning while enabling cross-variable interaction.
- Evidence anchors: [abstract] and [section 3.3] describe the two-stage point-wise group convolution for cross-variable dependency.
- Break condition: If M or D is too small, grouping provides no benefit; if too large, model may overfit.

### Mechanism 3
- Claim: Patch-style embedding enhances locality and aggregates semantic information from adjacent time points.
- Mechanism: Dividing time series into patches of size P with stride S treats local segments as tokens, enabling convolution to operate on semantically coherent units.
- Core assumption: Adjacent time points within a patch share meaningful local context that improves downstream dependency modeling.
- Evidence anchors: [section 3.2] and [abstract] mention patch-style embedding for enhancing locality and aggregating semantic information.
- Break condition: If patch size P is too large, locality is lost; if too small, embedding may not capture enough context.

## Architecture Onboarding

- Component map:
  Input → Patch-style embedding (1D conv with kernel=P, stride=S) → M × D × N embedding → Cross-LKTCN block (DW large kernel conv for cross-time + 2 successive PW group conv FFNs for cross-variable) → Output → Linear head + flatten → Final prediction → RevIN normalization applied before embedding and denormalization after prediction

- Critical path:
  1. Patch-style embedding transforms raw series into token-like patches.
  2. Cross-LKTCN block applies large kernel DW conv for temporal context.
  3. Successive PW group conv FFNs refine variable representations and capture cross-variable dependencies.
  4. Linear head maps final representation to predictions.

- Design tradeoffs:
  - Large kernel vs. receptive field: Larger kernels increase memory and computation but improve temporal modeling.
  - Group number choice (M vs D): Balances variable independence and cross-variable interaction modeling.
  - Patch size P vs stride S: Affects locality preservation and embedding granularity.

- Failure signatures:
  - Performance degrades with very large kernels without Structural Re-parameterization (optimization instability).
  - Cross-variable dependency not captured if group numbers are set incorrectly.
  - Patch embedding fails to improve performance if P is too large relative to sequence length.

- First 3 experiments:
  1. Vary kernel size (3, 31, 51) to confirm receptive field impact while keeping other hyperparameters fixed.
  2. Test group number configurations: (a) M groups then D groups, (b) M groups only, (c) D groups only, (d) no grouping, to validate the two-stage cross-variable modeling design.
  3. Compare RevIN vs no normalization to confirm its role in mitigating distribution shift.

## Limitations
- Specific implementation details of patch-style embedding strategy and Structural Re-parameterization technique are not fully specified, making exact reproduction challenging.
- Model's performance on very long sequences (>96 steps) is not demonstrated, though architectural design suggests potential limitations.
- The choice of kernel sizes (31, 51) and their impact on different dataset characteristics is not thoroughly explored beyond the ablation studies shown.

## Confidence

- **High confidence**: The general architectural framework and its core components (depth-wise separable convolutions, group convolutions, patch embeddings) are well-established techniques that can be validated through ablation studies.
- **Medium confidence**: The specific combination of these components and their arrangement in Cross-LKTCN is novel, but individual mechanisms have strong theoretical justification and preliminary experimental support.
- **Low confidence**: The exact performance improvements over state-of-the-art methods and the robustness of the model across diverse dataset characteristics require further validation.
