# Learning Fractals by Gradient Descent

## Quick Facts
- arXiv ID: 2303.12722
- Source URL: https://arxiv.org/abs/2303.12722
- Reference count: 13
- Key outcome: Learning fractal parameters via gradient descent for image reconstruction using differentiable IFS as RNNs

## Executive Summary
This paper introduces a novel approach to learning fractal parameters through gradient descent by treating iterated function systems (IFS) as recurrent neural networks (RNNs). The method implements IFS using modern deep learning frameworks with a differentiable rendering module that propagates gradients from images to generated points. Experimental results demonstrate that this approach can learn high-quality fractal parameters that reconstruct target images with low pixel-wise mean squared error. The method is also compatible with various loss functions, enabling potential applications such as pre-training neural networks.

## Method Summary
The paper proposes implementing IFS as a special RNN with identity activation functions and stochastic weights. The method uses a differentiable rendering module with RBF kernels to convert generated points to images and propagate gradients backward. Parameters are reparameterized to prevent exploding gradients during optimization. The approach is trained using Adam optimizer with learning rate decay and Gaussian noise injection to avoid local minima. The method is evaluated on multiple datasets including MNIST, FMNIST, KMNIST, and FractalDB.

## Key Results
- Learned fractal parameters can reconstruct target images with low pixel-wise MSE
- The method achieves 86.36% accuracy on CIFAR-10 when used as pre-training for CNNs
- GAN extension enables set-to-set learning for fractal generation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Viewing IFS as a special RNN enables gradient descent optimization
- Mechanism: The IFS update rule v(t) = A(t)v(t-1) + b(t) is structurally equivalent to an RNN step with identity activation. This allows leveraging automatic differentiation frameworks to compute gradients through the sequence of affine transformations.
- Core assumption: The affine transformation matrices and vectors can be treated as learnable parameters within a deep learning framework.
- Evidence anchors:
  - [abstract] "view an IFS as a recurrent neural network (RNN) with identity activation functions and stochastic weights"
  - [section 4.2] "an IFS can essentially be seen as a special recurrent neural network (RNN)"
  - [corpus] Weak - no direct evidence in corpus papers about IFS-RNN connection
- Break condition: If the framework cannot handle the stochastic sampling of transformations or the non-standard parameter structure.

### Mechanism 2
- Claim: Differentiable rendering with RBF kernel enables gradient flow from images to IFS points
- Mechanism: The rendering function maps 2D points to image intensities using an RBF kernel, creating a differentiable connection between generated points and pixel values. Gradients can flow backward through this mapping to update point positions.
- Core assumption: The RBF kernel provides smooth gradients that can effectively guide point positions toward target pixels.
- Evidence anchors:
  - [section 4.3] "we propose to draw the IFS points using an RBF kernel — every point 'diffuses' its mass to nearby pixels"
  - [section 4.3] "This module not only is differentiable w.r.t. v(t)"
  - [corpus] Weak - differentiable rendering is common in computer vision but not specifically cited for IFS
- Break condition: If the RBF bandwidth parameter is poorly chosen, gradients may vanish or explode.

### Mechanism 3
- Claim: Parameter reparameterization prevents exploding gradients in deep IFS iterations
- Mechanism: Decomposing affine matrices into rotation, scaling, and flipping components with bounded singular values prevents the amplification of gradients during backpropagation through many iterations.
- Core assumption: The maximum singular value of decomposed matrices remains bounded when scaling factors are constrained.
- Evidence anchors:
  - [section 4.4] "we leverage one important property — max(σ1,σ2) is exactly the maximum singular value of A — and clamp both σ1 and σ2 into [0, 1]"
  - [section 4.4] "To avoid it, we follow (Anderson and Farrell 2022) to decompose 'each' A in S into rotation, scaling, and flipping matrices"
  - [corpus] Weak - while fractal geometry papers discuss parameter constraints, the specific reparameterization for gradient stability is not directly cited
- Break condition: If the decomposition introduces too many parameters or the constraints are too restrictive.

## Architecture Onboarding

- Component map:
  - Fractal Embedding (FE) layer -> Differentiable rendering module -> Loss computation -> Parameter update loop

- Critical path:
  1. Initialize fractal parameters
  2. Generate point sequence through FE layer
  3. Render points to image via differentiable rendering
  4. Compute loss between rendered and target images
  5. Backpropagate gradients to update parameters
  6. Repeat with noise injection

- Design tradeoffs:
  - Stochastic vs. fixed sampling: Stochastic provides diversity but may converge slower; fixed sampling is deterministic but may limit expressiveness
  - RBF kernel bandwidth: Larger values create smoother gradients but may lose fine details; smaller values preserve details but may cause gradient instability
  - Parameter reparameterization: Prevents exploding gradients but adds implementation complexity

- Failure signatures:
  - Exploding gradients: Parameters grow uncontrollably during optimization
  - Vanishing gradients: Parameters stop updating despite poor reconstruction
  - Poor reconstruction: Generated images don't match target shapes even after convergence

- First 3 experiments:
  1. Reconstruct a simple fractal shape (like Sierpinski triangle) to verify basic functionality
  2. Reconstruct a non-fractal shape (like a circle) to test expressiveness limits
  3. Compare stochastic vs. fixed sampling on reconstruction quality and convergence speed

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the choice of the number of transformations N in the IFS parameters S affect the quality and expressiveness of the reconstructed images?
- Basis in paper: [explicit] The paper discusses using N = 10 transformations but also mentions an ablation study with N = 2, 6, 10, showing that MSE decreases as N increases.
- Why unresolved: The paper only provides a comparison of MSE values for different N values but does not explore the trade-offs between expressiveness and computational cost or the impact on more complex images.
- What evidence would resolve it: Experiments varying N across a wider range of image complexities and measuring both reconstruction quality and computational efficiency would clarify the optimal balance.

### Open Question 2
- Question: Can the differentiable rendering approach be extended to handle color images, or is it inherently limited to grayscale?
- Basis in paper: [inferred] The paper mentions that IFS itself cannot handle color images, suggesting a limitation in the current approach.
- Why unresolved: The paper does not propose or test any modifications to the differentiable rendering module to accommodate color images.
- What evidence would resolve it: Developing and testing an extension of the differentiable rendering module to process color channels independently or jointly would demonstrate the feasibility of handling color images.

### Open Question 3
- Question: What are the limitations of using gradient descent for learning fractal parameters in terms of capturing very detailed structures in images?
- Basis in paper: [explicit] The paper notes that the current approach is hard to recover very detailed structures, as evidenced by the examples in Figure 6.
- Why unresolved: The paper does not delve into the specific reasons why gradient descent struggles with detailed structures or propose solutions to this limitation.
- What evidence would resolve it: Investigating the impact of different loss functions, optimization techniques, or fractal parameterizations on the ability to capture detailed structures would identify potential improvements.

## Limitations
- The method struggles to capture very detailed structures in images
- Current implementation is limited to grayscale images, not supporting color
- Computational cost increases with higher iteration counts and more transformations
