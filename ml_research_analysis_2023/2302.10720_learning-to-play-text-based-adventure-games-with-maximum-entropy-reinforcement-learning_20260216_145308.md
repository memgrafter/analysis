# Learning to Play Text-based Adventure Games with Maximum Entropy Reinforcement Learning

## Quick Facts
- **arXiv ID**: 2302.10720
- **Source URL**: https://arxiv.org/abs/2302.10720
- **Reference count**: 15
- **Primary result**: SAC with reward shaping achieves higher scores than Q-learning in most games with half the training steps.

## Executive Summary
This paper applies soft-actor-critic (SAC) to text-based adventure games, achieving higher scores than previous Q-learning methods in several games while using only half the training steps. SAC is combined with potential-based reward shaping to address sparse extrinsic rewards. The shaping uses the soft state value function to generate dense reward signals, accelerating early learning and improving final scores in most games. Experimental results on difficult games show that SAC+reward shaping achieves higher or equal scores in seven out of eleven games, with reduced variance compared to SAC alone.

## Method Summary
The method adapts SAC for discrete action spaces in text-based games by using a sentencePiece tokenizer for text processing and separate GRUs for state and action embeddings. The agent uses epsilon-greedy action selection and incorporates reward shaping using the soft state value function as a potential function. N-step value function updates (N=32) are employed to stabilize training and improve convergence. The approach is evaluated on 11 difficult text-based games from the Jericho environment, with results compared to previous Q-learning baselines.

## Key Results
- SAC achieves higher scores than Q-learning methods on many games with only half the number of training steps
- Reward shaping accelerates learning and improves final scores in most games
- N-step updates (N=32) reduce variance and improve training stability compared to single-step updates

### Mechanism 1
- Claim: Soft Actor-Critic (SAC) is more stable and achieves higher scores than Q-learning in text-based games with half the training steps.
- Mechanism: SAC combines value-based and policy-based learning with entropy maximization, which encourages exploration and stability in discrete action spaces. This addresses the instability and high variance of Q-learning algorithms.
- Core assumption: The discrete adaptation of SAC (Christodoulou, 2019) is effective for text-based games with large, context-dependent action spaces.

### Mechanism 2
- Claim: Potential-based reward shaping (PBRS) accelerates learning and improves final scores by providing denser reward signals.
- Mechanism: PBRS modifies the original sparse rewards using a state-dependent potential function. Using the soft state value function as the potential function provides informative shaping rewards without requiring external knowledge or expert input.
- Core assumption: The soft state value function from SAC is a suitable potential function that maintains theoretical guarantees (policy invariance) while being dynamically learned during training.
- Evidence anchors:
  - [abstract]: "Moreover, we show that the reward shaping technique helps the agent to learn the policy faster and achieve higher scores."
  - [section 4]: "This allows us to use reward shaping without a separate neural network for the reward function. Experimentally, we found this also to perform similar to using a plain value function approximated using a neural network."
  - [corpus]: Weak evidence - corpus lacks studies using soft state value functions specifically for PBRS in text-based games.

### Mechanism 3
- Claim: N-step value function updates stabilize training and improve convergence compared to single-step updates.
- Mechanism: Instead of using the sample once to learn the TD update, the algorithm repeats the sample N times (N=32) to estimate the TD value, reducing variance and stabilizing learning.
- Core assumption: Multiple iterations of TD updates provide a better estimate of the value function, leading to more stable Q-value targets and policy updates.

## Architecture Onboarding

- Component map:
  - Jericho environment -> Agent (SAC) -> Replay buffer -> Neural networks (actor, critic, target) -> Reward shaping module

- Critical path:
  1. Agent receives observation, inventory, and look information from environment
  2. Input is tokenized and embedded using GRUs
  3. Actor network outputs action probabilities over valid actions
  4. Environment returns next state, reward, and terminal signal
  5. Experience is stored in replay buffer
  6. SAC update cycle: critic update → actor update → (optional) reward shaping update
  7. Target Q-networks updated periodically

- Design tradeoffs:
  - Using soft state value function vs. separate neural network for potential function: fewer parameters vs. potentially more stable approximation
  - N=32 steps vs. N=1: better stability and convergence vs. higher computational cost per update
  - Choice-based agent (using valid action space) vs. parser-based agent: simpler action space but requires valid action handicap

- Failure signatures:
  - High variance in training curves: may indicate unstable Q-value targets or poor exploration-exploitation balance
  - Agent gets stuck repeating the same actions: could be due to large valid action spaces or insufficient exploration
  - Scores plateau early: might suggest inadequate reward shaping or suboptimal policy network architecture

- First 3 experiments:
  1. Run SAC without reward shaping on a simple game (e.g., balances) to establish baseline performance and training stability
  2. Add reward shaping with N=1 to verify if shaping improves convergence speed, then increase N to 32 to test stability benefits
  3. Compare soft state value-based shaping vs. separate neural network-based shaping to evaluate parameter efficiency and performance trade-offs

## Limitations

- Experimental validation is limited to 11 out of 57 available text-based games, with mixed performance across different game types
- The use of Jericho's "valid action handicap" provides privileged information not available in real-world scenarios
- Neural network architectures are described only at a high level, leaving critical implementation details uncertain

## Confidence

- **SAC outperforms Q-learning with half the training steps (High)**: Well-supported by direct experimental comparisons showing higher scores with fewer training steps
- **Reward shaping accelerates learning and improves final scores (Medium)**: Supported by learning curves showing faster convergence and higher scores in most games, but effect varies significantly across games
- **N-step updates stabilize training and improve convergence (Medium)**: Evidence from learning curves shows reduced variance with N=32, but lacks ablation experiments comparing different N values
