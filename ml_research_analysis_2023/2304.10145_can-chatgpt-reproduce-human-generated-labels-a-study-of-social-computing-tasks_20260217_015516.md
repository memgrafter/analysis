# Can ChatGPT Reproduce Human-Generated Labels? A Study of Social Computing Tasks

## Quick Facts
- arXiv ID: 2304.10145
- Source URL: https://arxiv.org/abs/2304.10145
- Authors: 
- Reference count: 40
- Primary result: ChatGPT achieved average accuracy of 0.609 and weighted F1-score of 0.582 across five social computing annotation tasks

## Executive Summary
This paper investigates whether ChatGPT can reproduce human-generated labels for five social computing annotation tasks: stance detection, hate speech detection, sentiment analysis, bot detection, and Russo-Ukrainian sentiment. Using a standardized prompt template, the authors treated ChatGPT as a prediction engine and evaluated its performance using traditional classifier metrics. The results show that ChatGPT can partially replicate human annotation with varying success across tasks and individual labels, achieving highest performance in sentiment analysis (64.9% accuracy) and lowest in hate speech detection (57.1% accuracy). The study highlights both the potential and limitations of using large language models for automated annotation in social computing research.

## Method Summary
The study used ChatGPT API (gpt-3.5-turbo) to re-label five established Twitter datasets with human annotations. A standardized prompt template was created for each task, asking ChatGPT to classify tweets into predefined categories. The researchers extracted labels from the first sentence of ChatGPT's responses and compared them against human annotations using accuracy, weighted precision, weighted recall, and weighted F1-score. The datasets included COVID-19 stance detection (3,658 tweets), COVID hate speech detection (2,289 tweets), SemEval-2017 sentiment analysis (9,895 tweets), TweepFake bot detection (17,571 tweets), and a manually annotated Russo-Ukrainian sentiment dataset (2,205 tweets).

## Key Results
- ChatGPT achieved an average accuracy of 0.609 and weighted F1-score of 0.582 across all five tasks
- Best performance was in sentiment analysis with 64.9% accuracy, while worst was hate speech detection at 57.1% accuracy
- Performance varied substantially across individual labels within each task, with some labels showing significantly higher accuracy than others
- ChatGPT performed relatively weaker on bot detection, which the authors attribute to its limitation in incorporating social network features

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ChatGPT can generate usable labels by following structured prompt templates that specify the task topic and candidate label set.
- Mechanism: The prompt design leverages ChatGPT's ability to interpret declarative instruction templates, map tweet text to one of the predefined labels, and produce consistent output where the label appears in the first sentence.
- Core assumption: ChatGPT's response format is predictable enough that the label can be reliably extracted from the first sentence.
- Evidence anchors:
  - [abstract] states "we treat ChatGPT as a prediction engine, which we can then evaluate using traditional classifier metrics."
  - [section] describes the prompt template: "Give/Classify the tweet a label about[Topic] from/into [label1, label2, or label3]."
  - [corpus] neighbors include studies on "DEMASQ: Unmasking the ChatGPT Wordsmith" suggesting extraction reliability is an active concern.
- Break condition: If ChatGPT's response format changes (e.g., multi-sentence label candidates or non-first-sentence placement), the extraction fails.

### Mechanism 2
- Claim: ChatGPT's performance varies across individual labels within the same task, indicating that some label distinctions are easier for the model than others.
- Mechanism: The model's internal representations align more closely with certain label boundaries (e.g., "Hate" vs "Counterspeech") than others (e.g., "Neutral" vs "Hate"), leading to asymmetric precision/recall.
- Core assumption: Label ambiguity or subtlety in the task definition affects ChatGPT's ability to distinguish classes.
- Evidence anchors:
  - [abstract] notes "performance varies substantially across individual labels within each task."
  - [section] reports "ChatGPT achieves an F1-score of 0.733 for 'Pro-Russia', compared to 0.429 for 'Pro-Ukraine'."
  - [corpus] includes "Keeping Humans in the Loop: Human-Centered Automated Annotation with Generative AI," which implies human oversight is needed due to label variability.
- Break condition: If label definitions are too overlapping or context-dependent, performance disparity increases and overall utility drops.

### Mechanism 3
- Claim: ChatGPT performs better on tasks grounded in knowledge about events or sentiment than on tasks requiring subtle behavioral inference (e.g., bot detection).
- Mechanism: Event-based tasks rely on factual knowledge and polarity cues that ChatGPT's training data covered extensively, while behavioral inference tasks need context-specific metadata or interaction patterns not captured in text alone.
- Core assumption: ChatGPT's pretraining corpus included more explicit sentiment/stance content than social network behavioral cues.
- Evidence anchors:
  - [abstract] states "ChatGPT correctly annotates 64.9% of tweets" in sentiment analysis, the highest among tasks.
  - [section] notes "ChatGPT performs relatively weaker" on bot detection and attributes this to lack of incorporated social network features.
  - [corpus] neighbor "Can LLMs Demystify Bug Reports?" suggests LLM limitations on tasks needing deep domain-specific inference.
- Break condition: If tasks shift toward requiring real-time or context-rich inference beyond text, performance degrades.

## Architecture Onboarding

- Component map: Tweet text + prompt template -> ChatGPT API -> Response text -> First-sentence parsing -> Label extraction -> Metrics computation
- Critical path:
  1. Prompt generation per tweet
  2. API call to ChatGPT
  3. First-sentence parsing for label extraction
  4. Aggregation into confusion matrix and metrics
- Design tradeoffs:
  - Using only the first sentence for label extraction is fast but brittle; a multi-sentence parsing step could improve accuracy at the cost of latency.
  - Prompt template simplicity enables reuse across tasks but may miss task-specific nuances that improve performance.
- Failure signatures:
  - High rate of "not enough information" responses indicates ambiguous prompts or data quality issues.
  - Consistent mislabeling of one class (e.g., "Neutral" → "Hate") suggests prompt bias or model limitation.
- First 3 experiments:
  1. Vary prompt verb ("Classify" vs "Give") and measure impact on label extraction accuracy.
  2. Add a second API call to clarify ambiguous responses and compare F1-score improvement.
  3. Test domain-specific prompt enrichment (e.g., include example tweets) to reduce variability across labels.

## Open Questions the Paper Calls Out

- How would alternative prompt formulations affect ChatGPT's annotation accuracy across different tasks?
  - Basis in paper: [explicit] The paper notes that "Our future work will involve exploring alternative forms of prompt formulation and response mining" and acknowledges that "we only use a single prompt for annotation"
  - Why unresolved: The study used a standardized prompt template across all tasks without exploring variations in prompt structure, wording, or detail level that might optimize performance for specific tasks
  - What evidence would resolve it: Comparative experiments testing multiple prompt variations (e.g., different verbs, detail levels, formatting) across all five tasks to identify optimal prompt designs for each annotation task

- What is the impact of incorporating contextual information (e.g., tweet metadata, user profiles) on ChatGPT's annotation performance?
  - Basis in paper: [inferred] The paper states that "developing new ways to embed secondary data (e.g., context) in the prompts could improve results" and notes that in bot detection tasks, "ChatGPT's limitation in incorporating such information in inferences may explain the low scores"
  - Why unresolved: The current methodology only provided ChatGPT with tweet text without any supplementary contextual information that might enhance its understanding and accuracy
  - What evidence would resolve it: Controlled experiments comparing ChatGPT's performance with and without access to additional contextual information (user metadata, conversation threads, posting patterns) for each annotation task

- How does ChatGPT's performance on timely/emerging topics compare to its performance on established topics?
  - Basis in paper: [explicit] The authors observe that "ChatGPT's performance may be weaker in annotating data related to a new domain after its initial training" and note the contrast between COVID-19 stance detection (pre-training) and Russo-Ukrainian sentiment (post-training)
  - Why unresolved: The study only examined two temporal categories (pre-training COVID-19 and post-training Russo-Ukrainian), limiting understanding of how model age affects performance on emerging topics
  - What evidence would resolve it: Systematic analysis of ChatGPT's performance across multiple annotation tasks spanning different time periods relative to the model's training cutoff, controlling for topic complexity and data availability

## Limitations

- The zero-shot nature of the evaluation provides only a baseline assessment without exploring ChatGPT's potential with task-specific adaptation or fine-tuning
- Label extraction relies solely on the first sentence of responses, introducing brittleness when ChatGPT provides nuanced explanations or multiple candidate labels
- The study does not account for temporal changes in ChatGPT's performance across different API versions or fine-tuning updates to the underlying model

## Confidence

**High Confidence**: The comparative framework using established classification metrics is sound, and the general pattern of task-specific performance variation (better on sentiment/stance, worse on bot detection) aligns with known LLM limitations in behavioral inference.

**Medium Confidence**: The claim that ChatGPT can partially reproduce human labels is well-supported by the overall accuracy and F1-score metrics, though the substantial variation across individual labels within tasks suggests this capability is not uniform.

**Low Confidence**: The specific attribution of ChatGPT's weaker performance on bot detection solely to the lack of social network features may oversimplify the underlying causes, as this task likely requires different reasoning capabilities than text-based sentiment or stance detection.
