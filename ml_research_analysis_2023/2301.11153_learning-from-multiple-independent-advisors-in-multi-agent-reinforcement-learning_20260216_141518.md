# Learning from Multiple Independent Advisors in Multi-agent Reinforcement Learning

## Quick Facts
- arXiv ID: 2301.11153
- Source URL: https://arxiv.org/abs/2301.11153
- Authors: 
- Reference count: 40
- Primary result: MA-TLQL outperforms baselines in sample efficiency by learning from multiple independent advisors in MARL settings

## Executive Summary
This paper addresses sample inefficiency in multi-agent reinforcement learning (MARL) by proposing a method to learn from multiple independent advisors. The key innovation is a two-level Q-learning architecture that evaluates and integrates advice from multiple sub-optimal advisors, extending prior work to MARL settings. The approach uses a high-level Q-table to evaluate advisors and a low-level Q-table to learn action values, with an ensemble selection technique to resolve conflicts between advisors. The paper provides theoretical convergence and sample complexity guarantees, and experimentally validates the approach in three different test-beds (Pommerman, Pursuit, and Predator-Prey).

## Method Summary
The paper proposes Multi-Agent Two-Level Q-learning (MA-TLQL), which extends the single-agent TLQL framework to multi-agent settings. The algorithm maintains two Q-tables: a high-level Q-table that evaluates advisor performance at each state and joint action, and a low-level Q-table that learns action values based on the agent's own policy. An ensemble selection technique resolves conflicts between advisors by choosing actions based on the majority vote of advisors with the best high-Q estimates. The high-Q table is updated using an evaluation update that assigns the value of the advisor's suggested action from the low-Q table, allowing the algorithm to learn the true value of following each advisor's policy.

## Key Results
- MA-TLQL outperforms baseline methods (DQN, DQfD, CHAT, ADMIRAL-DM, TLQL) in sample efficiency across three test-beds
- The algorithm effectively integrates combined expertise of different advisors while learning to ignore bad advice
- Theoretical guarantees for convergence and sample complexity are provided, with experimental validation showing both training and execution phase improvements

## Architecture Onboarding

- Component map:
  - High-level Q-table -> Evaluates advisor performance at each state and joint action
  - Low-level Q-table -> Learns action values based on the agent's own policy
  - Ensemble selection technique -> Chooses actions based on majority vote of advisors with best high-Q estimates
  - Advisor evaluation update -> Updates high-Q table using value of advisor's suggested action from low-Q table
  - Control update -> Updates low-Q table using standard Q-learning Bellman update

- Critical path:
  1. Observe current state and joint actions of other agents
  2. Use high-level Q-table to evaluate advisors and select action using ensemble technique
  3. Execute chosen action and observe next state and reward
  4. Update low-level Q-table using control update
  5. If advisor was chosen, update high-level Q-table using evaluation update
  6. Decay hyperparameter controlling dependence on advisors over time

- Design tradeoffs:
  - Two-level architecture enables explicit advisor evaluation and conflict resolution but adds complexity
  - Ensemble selection helps early learning but may not always choose best advisor later
  - Assumes fully observable environments and discrete state/action spaces, limiting applicability

- Failure signatures:
  - Poor performance if high-level Q-table fails to accurately evaluate advisor performance
  - Instability if advisors provide conflicting advice that cannot be resolved by ensemble technique
  - Suboptimal policies if algorithm relies too heavily on advisors and fails to learn from environment

- First 3 experiments:
  1. Two-agent Pommerman with four sufficient advisors of different quality (Experiment 1)
  2. Two-agent Pommerman with four sufficient advisors of similar quality (Experiment 2)
  3. Two-agent Pommerman with four insufficient advisors of different quality (Experiment 3)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the performance of MA-TLQL change if the advisors were not fixed but continued learning during training?
- Basis in paper: [explicit] The paper mentions that while MA-TLQL is theoretically guaranteed to converge with fixed advisors, it can also be used with changing advisors experimentally, as shown in Appendix G.
- Why unresolved: The paper does not provide theoretical guarantees for convergence when advisors are learning, and the experimental results only show performance improvements, not convergence guarantees.
- What evidence would resolve it: Theoretical analysis proving convergence or non-convergence of MA-TLQL with learning advisors, or extensive experimental results showing consistent convergence or divergence patterns.

### Open Question 2
- Question: What is the impact of using opponent modeling techniques on the performance of MA-TLQL in more complex multi-agent environments?
- Basis in paper: [explicit] The paper mentions in Appendix H that MA-TLQL can be used with opponent modeling techniques and provides some experimental results showing performance improvements.
- Why unresolved: The experimental results in Appendix H are limited to two specific experiments and do not explore the impact of opponent modeling in more complex environments or different types of opponent modeling techniques.
- What evidence would resolve it: Extensive experimental results in various complex multi-agent environments with different opponent modeling techniques, showing consistent performance improvements or lack thereof.

### Open Question 3
- Question: How does the performance of MA-TLQL scale with an increasing number of advisors, especially when the advisors have overlapping expertise?
- Basis in paper: [explicit] The paper mentions in Appendix I that MA-TLQL performance can improve with the addition of better advisors and provides some experimental results in the Pursuit environment.
- Why unresolved: The experimental results in Appendix I are limited to the Pursuit environment and do not explore the impact of overlapping expertise among advisors or the scalability of MA-TLQL with a large number of advisors.
- What evidence would resolve it: Extensive experimental results in various environments with different numbers of advisors, including cases with overlapping expertise, showing consistent performance improvements or diminishing returns as the number of advisors increases.

## Limitations
- Relies on discrete state and action spaces with fully observable environments, significantly limiting practical applicability
- Function approximation implementation details are sparse, making it difficult to assess generalization to complex domains
- Convergence guarantees depend on strong assumptions about stochastic game structure that may not hold in practice

## Confidence
- High confidence in the algorithmic framework and basic mechanism (the two-level architecture and ensemble selection)
- Medium confidence in theoretical convergence guarantees (depends on assumptions that are difficult to verify)
- Medium confidence in experimental results (well-designed but limited to discrete test-beds)
