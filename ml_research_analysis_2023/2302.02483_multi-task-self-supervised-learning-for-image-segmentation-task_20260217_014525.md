# Multi-Task Self-Supervised Learning for Image Segmentation Task

## Quick Facts
- arXiv ID: 2302.02483
- Source URL: https://arxiv.org/abs/2302.02483
- Reference count: 16
- Primary result: Nash-MTL weighting achieves lower Delta-M metric than Uncertainty Weighting and single-task SegNet baseline for semantic segmentation

## Executive Summary
This work addresses the challenge of semantic segmentation by proposing a multi-task self-supervised learning approach that jointly trains for segmentation, depth prediction, and surface normal estimation. The authors introduce Nash-MTL, a principled weighting scheme based on Nash bargaining theory, and compare it against uncertainty weighting (UW) on the NYU-Depth V2 dataset. Their approach leverages self-supervised auxiliary tasks to improve semantic segmentation performance while maintaining computational efficiency through a shared U-Net architecture.

## Method Summary
The method uses a U-Net encoder-decoder architecture with ResNet backbone, trained on NYU-Depth V2 dataset for three tasks simultaneously: semantic segmentation, depth prediction, and surface normal estimation. The multi-task learning employs two weighting schemes - Nash-MTL based on Nash bargaining solution for gradient combination, and UW based on homoscedastic uncertainty. The model is trained for 200 epochs with task-specific loss functions combined through the weighting schemes to balance gradient updates across all tasks.

## Key Results
- Nash-MTL weighting achieves superior performance with lower Delta-M metric compared to UW and single-task SegNet baseline
- Multi-task learning with self-supervised depth and surface normal estimation improves semantic segmentation performance
- Uncertainty Weighting provides adaptive task balancing but underperforms the theoretically principled Nash-MTL approach

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Nash-MTL weighting achieves superior performance by treating multi-task gradient combination as a Nash bargaining game
- Mechanism: At each optimization step, task gradients are combined using the Nash Bargaining Solution (NBS), which finds a Pareto-optimal update direction that maximizes the product of task utility gains
- Core assumption: The Nash bargaining framework applies to multi-task gradient optimization, and the unique NBS solution exists and can be computed efficiently
- Evidence anchors:
  - [abstract] "Under certain assumptions, the bargaining problem has a unique solution known as the Nash Bargaining Solution, which we propose to use as a principled approach to multi-task learning."
  - [section III.A] "A common solution to this problem is to combine per-task gradients into a joint update direction using a specific heuristic. Here, we propose viewing the gradients combination step as a bargaining game in which tasks negotiate to reach an agreement on a joint parameter update direction."

### Mechanism 2
- Claim: Self-supervised depth and surface normal estimation provide rich auxiliary supervision that improves semantic segmentation performance
- Mechanism: By predicting depth and surface normals alongside segmentation, the model learns geometric and spatial relationships that are transferable to semantic understanding
- Core assumption: Depth and surface normal tasks share sufficient feature representations with semantic segmentation to provide meaningful auxiliary supervision
- Evidence anchors:
  - [section II.A.1] "Surface Normal prediction is the task of predicting the surface orientation of the objects present inside a scene."
  - [section II.A.2] "Predicting the depth is an indispensable task for understanding the 3d scene."

### Mechanism 3
- Claim: Uncertainty weighting (UW) provides adaptive task balancing based on homoscedastic uncertainty, though it underperforms Nash-MTL
- Mechanism: UW treats task losses as Gaussian likelihoods with different uncertainties, using these uncertainties as learned weights in the combined loss function
- Core assumption: Task uncertainties can be modeled as homoscedastic noise parameters that reflect relative task difficulty and confidence
- Evidence anchors:
  - [section III.B] "Task uncertainty captures the relative confidence between tasks, reflecting the uncertainty inherent in the regression or classification task."
  - [section V] "Nash MTL has smaller Delta-M in comparison to UW when Segnet is kept as the baseline for the comparison."

## Foundational Learning

- Concept: Multi-task learning optimization
  - Why needed here: The paper combines three different tasks (segmentation, depth, surface normals) that require careful gradient balancing to prevent any single task from dominating training
  - Quick check question: What happens to the combined loss function when one task's gradient magnitude is much larger than the others?

- Concept: Self-supervised learning objectives
  - Why needed here: Depth and surface normal predictions are self-supervised tasks that generate their own ground truth from image data, avoiding the need for expensive manual annotations
  - Quick check question: How are depth maps and surface normal maps generated as ground truth for training without manual labeling?

- Concept: Uncertainty modeling in deep learning
  - Why needed here: Both Nash-MTL and UW rely on quantifying and using task uncertainty, with UW directly parameterizing uncertainty as learnable weights
  - Quick check question: What's the difference between aleatoric and epistemic uncertainty, and which type is relevant for task weighting in multi-task learning?

## Architecture Onboarding

- Component map:
  - Input RGB image → ResNet encoder → Spatial Pooling Pyramid → U-Net decoder → Three parallel task heads (segmentation, depth, surface normal)

- Critical path:
  1. Input RGB image → ResNet encoder
  2. Feature pyramid generation
  3. Multi-scale features fed to U-Net decoder
  4. Three parallel task heads produce predictions
  5. Combined loss computed with task weights
  6. Backpropagation through all tasks simultaneously

- Design tradeoffs:
  - Single shared encoder vs. task-specific encoders: Shared encoder reduces parameters but may create interference
  - Nash-MTL vs. UW vs. fixed weights: Nash-MTL is theoretically principled but more complex; UW is simpler but slightly less effective
  - U-Net vs. other architectures: U-Net provides good feature preservation but may be slower than lighter alternatives

- Failure signatures:
  - High semantic segmentation loss with low auxiliary task losses: Tasks are imbalanced, consider adjusting weights
  - All losses plateau early: Learning rate may be too low or model capacity insufficient
  - One task's loss dominates: Check for gradient conflicts, consider Nash-MTL approach
  - Poor segmentation quality: Verify that auxiliary tasks are providing useful supervision

- First 3 experiments:
  1. Baseline single-task semantic segmentation using only SegNet architecture to establish performance floor
  2. Multi-task learning with UW weighting to verify that auxiliary tasks improve performance over baseline
  3. Multi-task learning with Nash-MTL weighting to test whether the principled approach outperforms simpler weighting schemes

### Open Question 2
- Question: How does Nash-MTL weighting compare to other multi-task learning weighting methods like GradNorm or dynamic weighting schemes on this task?
- Basis in paper: [explicit] The authors compare Nash-MTL to Uncertainty Weighting (UW) but do not compare it to other established multi-task weighting methods
- Why unresolved: The paper only provides a two-way comparison between Nash-MTL and UW, leaving other methods unexplored
- What evidence would resolve it: Head-to-head comparisons of Nash-MTL against GradNorm, dynamic weighting, and other state-of-the-art multi-task weighting methods using the same experimental setup

- Why unresolved: The paper focuses on accuracy improvements without measuring the computational cost of the multi-task approach
- What evidence would resolve it: Benchmarking experiments measuring inference time, memory usage, and accuracy trade-offs between single-task and multi-task models across different hardware configurations

## Limitations
- The Nash-MTL implementation details are not fully specified, particularly the exact computation of the Nash Bargaining Solution during gradient combination
- The comparison metrics and baseline results are not directly verifiable from the provided information, with modest differences between Nash-MTL and UW
- The experiments were conducted without data augmentation, potentially leaving performance improvements unexplored

## Confidence
- **High confidence**: The conceptual framework of using Nash Bargaining Solution for multi-task gradient combination is well-founded and theoretically sound, supported by game theory literature
- **Medium confidence**: The claim that self-supervised depth and surface normal tasks improve semantic segmentation is plausible based on geometric reasoning, but empirical validation in this specific setup is needed
- **Medium confidence**: The superiority of Nash-MTL over UW weighting is demonstrated in results, but the difference is modest and the practical significance for real-world applications requires further investigation
