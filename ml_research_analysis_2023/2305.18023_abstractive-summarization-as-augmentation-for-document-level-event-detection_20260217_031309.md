# Abstractive Summarization as Augmentation for Document-Level Event Detection

## Quick Facts
- arXiv ID: 2305.18023
- Source URL: https://arxiv.org/abs/2305.18023
- Reference count: 6
- Primary result: Abstractive summarization improves linear SVM performance by ~0.5% on document-level event detection

## Executive Summary
This paper addresses document-level event detection using abstractive summarization as augmentation for a linear SVM classifier. The authors tackle data scarcity and computational cost by generating summaries from low-resource classes using BART and testing four decoding methods. They demonstrate that including document titles improves classification performance by 2.04% and 3.19% for linear SVM and RoBERTa respectively, while summarization-based augmentation provides modest additional gains for the linear model.

## Method Summary
The approach uses the DocEE dataset with document text and titles as inputs, applying abstractive summarization via BART fine-tuned on CNN/DailyMail to generate augmentations for low-resource classes. A linear SVM with TF-IDF features serves as the primary classifier, with RoBERTa-base as a strong baseline. The method tests four decoding strategies (beam search, top-k sampling, top-p sampling, and contrastive search) for summarization quality and evaluates performance using macro F1-score across validation and test splits.

## Key Results
- Document titles improve classification performance by 2.04% (SVM) and 3.19% (RoBERTa) absolute macro F1-score
- Abstractive summarization augmentation improves linear SVM performance by approximately 0.5% absolute macro F1-score
- Performance gains vary slightly across decoding methods but remain modest overall
- Linear SVM performance remains significantly behind RoBERTa despite augmentation benefits

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using document titles as additional input improves classification performance.
- Mechanism: The title often encapsulates the core event, providing a high-level semantic cue that primes the model for the correct classification before it processes the full document text.
- Core assumption: Titles are strongly correlated with the main event type and contain minimal noise compared to the full text.
- Evidence anchors:
  - "We observe that document titles often provide additional context about the main event type that is present in the document."
  - "Using the document title offers 2.04% and 3.19% absolute improvement in macro F1-score for linear SVM and RoBERTa, respectively."
- Break condition: If titles are generic or unrelated to the main event, the additional signal may confuse the classifier instead of helping.

### Mechanism 2
- Claim: Abstractive summarization acts as label-preserving augmentation for low-resource classes.
- Mechanism: Summaries condense documents while retaining the main event type, effectively creating new, shorter examples that belong to the same class but reduce noise and redundancy.
- Core assumption: The summarization model (BART) preserves the dominant event information when generating summaries.
- Evidence anchors:
  - "We hypothesize that the performance can most easily be improved on classes comprising relatively few examples."
  - "We use abstractive summarization as an augmentation technique, which means that we generate abstractive summaries from the existing data examples and use those summaries as novel examples."
- Break condition: If the summarization model loses or misrepresents the main event type, the generated examples become mislabeled and harm performance.

### Mechanism 3
- Claim: Linear SVM with TF-IDF benefits modestly from summarization augmentation despite lower absolute performance than RoBERTa.
- Mechanism: Summarization reduces input dimensionality and noise, making linear models more effective by emphasizing discriminative terms.
- Core assumption: The TF-IDF representation of summaries captures class-relevant signals more clearly than the original document text.
- Evidence anchors:
  - "Augmentation via summarization further improves the performance of linear SVM by about 0.5%, varying slightly across decoding methods."
  - "We use linear SVM with TF-IDF document representations as inputs."
- Break condition: If the summary is too short or abstract, TF-IDF may fail to capture enough discriminative features, negating the benefit.

  - Why needed here: The setup uses BART fine-tuned on CNN/DailyMail without task-specific training; understanding zero-shot generation is critical.
  - Quick check question: Why does the paper use BART fine-tuned on CNN/DailyMail instead of training from scratch on DocEE?

- Concept: Decoding methods for language models (beam search, top-k, top-p, contrastive).
  - Why needed here: Different decoding strategies are tested for summarization quality and computational efficiency.
  - Quick check question: Which decoding method offers the best trade-off between speed and performance according to the results?

## Architecture Onboarding

- Component map: DocEE dataset -> BART summarization -> Generated summaries -> Linear SVM (TF-IDF) or RoBERTF-base -> Macro F1-score evaluation

- Critical path:
  1. Load DocEE data -> split into train/val/test
  2. Generate summaries for low-resource class examples using BART
  3. Train classifiers (SVM or RoBERTa) with/without titles
  4. Evaluate macro F1-score

- Design tradeoffs:
  - Speed vs. quality: Faster decoding (top-k/p) slightly reduces performance but saves computation
  - Model complexity: SVM is much cheaper than RoBERTa but lags in performance
  - Augmentation scope: Only low-resource classes are augmented, balancing effort and impact

- Failure signatures:
  - SVM performance close to random -> likely feature extraction or imbalance issue
  - No improvement from titles -> titles may be uninformative or misaligned
  - Summaries introduce noise -> BART fails to preserve event type

- First 3 experiments:
  1. Run SVM with TF-IDF on original data (no titles, no augmentation) -> baseline
  2. Add titles to SVM input -> check for title effect
  3. Generate summaries for low-resource classes using beam search, train SVM with them -> measure augmentation gain

## Open Questions the Paper Calls Out

- Question: How do different decoding hyperparameters impact the performance of summarization-based augmentation across various decoding methods?
  - Basis in paper: The authors mention that future work could explore the impact of hyperparameters on the performance of each decoding method since they used recommended defaults.
  - Why unresolved: The paper used default hyperparameter values for decoding methods without exploring their impact on augmentation performance.
  - What evidence would resolve it: Systematic experiments varying key hyperparameters (e.g., beam size, top-k/top-p values, alpha for contrastive search) and measuring their effect on classification performance.

- Question: Can supervised information about event types or event arguments improve the quality of generated summaries for augmentation compared to the current unsupervised approach?
  - Basis in paper: The authors suggest future work could explore using supervised information to perform guided summarization instead of the current fully unsupervised approach.
  - Why unresolved: The current augmentation setup utilizes no information about event types or arguments, relying entirely on unsupervised summarization.
  - What evidence would resolve it: Experiments comparing the current unsupervised augmentation approach with supervised approaches that incorporate event type or argument information during summarization.

- Question: Would deep models benefit more from summarization-based augmentation compared to the shallow models tested in this paper?
  - Basis in paper: The authors note that their augmentation approach is used for efficiency with shallow models, but suggest deep models might benefit more from high-level augmentation methods.
  - Why unresolved: The study only tested augmentation with a shallow SVM model, leaving the potential benefits for deep models unexplored.
  - What evidence would resolve it: Experiments applying the same summarization-based augmentation to deep transformer models (e.g., RoBERTa) and comparing performance improvements to those observed with the shallow model.

## Limitations
- Zero-shot summarization assumption is unverified - no fine-tuning on DocEE may limit summary quality
- No ablation study comparing augmented vs. random noise augmentation to isolate summarization benefit
- Computational efficiency claims lack quantification (no wall-clock timing or memory usage reported)
- Limited evaluation of decoding method trade-offs beyond reported F1 scores

## Confidence
- High confidence: Title augmentation consistently improves performance (2.04% and 3.19% gains for SVM and RoBERTa)
- Medium confidence: Summarization augmentation provides modest gains (~0.5% for SVM), but without proper baseline it's unclear if this is due to summarization quality
- Low confidence: The claim that zero-shot BART summarization is sufficient without domain adaptation is plausible but unverified

## Next Checks
