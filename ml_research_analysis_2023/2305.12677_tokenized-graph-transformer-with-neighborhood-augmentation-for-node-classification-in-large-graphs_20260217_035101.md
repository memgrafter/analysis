# Tokenized Graph Transformer with Neighborhood Augmentation for Node Classification in Large Graphs

## Quick Facts
- arXiv ID: 2305.12677
- Source URL: https://arxiv.org/abs/2305.12677
- Reference count: 40
- Key outcome: NAGphormer outperforms existing graph transformers and GNNs on node classification benchmarks

## Executive Summary
This paper introduces NAGphormer, a scalable graph transformer model that treats each node as a sequence of tokens constructed from its multi-hop neighborhoods. The key innovation is the Hop2Token module that aggregates neighborhood features from different hops into distinct token representations, enabling efficient mini-batch training. The model also introduces Neighborhood Augmentation (NrAug) that augments neighborhood information from both global and local perspectives. Experimental results on benchmark datasets demonstrate that NAGphormer consistently outperforms existing graph transformers and GNNs, with NrAug providing additional performance gains.

## Method Summary
NAGphormer represents each node as a sequence of tokens using the Hop2Token module, which aggregates neighborhood features from different propagation steps (hops) into separate token vectors. This sequence-based representation enables mini-batch training, addressing the quadratic complexity limitation of traditional graph Transformers. The model incorporates structural encoding based on Laplacian eigenvectors and uses a Transformer encoder to learn node representations through self-attention. An attention-based readout function adaptively aggregates information from different-hop neighborhoods. The Neighborhood Augmentation (NrAug) method enhances training by globally mixing information between nodes in the same batch and locally masking portions of the token sequence.

## Key Results
- NAGphormer consistently outperforms existing graph transformers and GNNs on benchmark datasets
- NrAug further boosts NAGphormer's performance through global and local neighborhood augmentation
- The model can scale to large graphs through mini-batch training enabled by the Hop2Token representation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: NAGphormer can scale to large graphs by treating each node as a sequence of tokens constructed from its multi-hop neighborhoods, enabling mini-batch training.
- Mechanism: Hop2Token aggregates neighborhood features from different hops into different token representations, producing a sequence of token vectors for each node. This sequence-based representation allows the model to be trained in mini-batches, overcoming the quadratic complexity of traditional graph Transformers.
- Core assumption: The sequence representation preserves sufficient neighborhood information for accurate node classification while enabling efficient mini-batch training.
- Evidence anchors:
  - [abstract]: "NAGphormer could be trained in a mini-batch manner and thus could scale to large graphs."
  - [section]: "Hop2Token is a non-parametric method. It can be conducted offline before the model training, and the output of Hop2Token supports mini-batch training."
  - [corpus]: Weak evidence, but supports the claim by mentioning "Node tokenized graph Transformers (GTs) have shown promising performance in node classification" and the need for scalable methods.
- Break condition: If the sequence representation loses critical neighborhood information or if the mini-batch training introduces significant information loss, the model's performance may degrade.

### Mechanism 2
- Claim: NAGphormer can learn more informative node representations from multi-hop neighborhoods compared to decoupled Graph Convolutional Networks (GCNs).
- Mechanism: NAGphormer utilizes a self-attention mechanism to learn representations of different-hop neighborhoods based on their semantic correlation. It then employs an attention-based readout function to adaptively aggregate information from different neighborhoods.
- Core assumption: The self-attention mechanism and attention-based readout function can capture the importance of different-hop neighborhoods and adaptively learn node representations.
- Evidence anchors:
  - [abstract]: "we mathematically show that compared to a category of advanced Graph Neural Networks (GNNs), called decoupled Graph Convolutional Networks, NAGphormer could learn more informative node representations from multi-hop neighborhoods."
  - [section]: "Fact 1 indicates that the decoupled GCN, an advanced category of GNN, only captures partial information of the multi-hop neighborhoods through the incomplete attention matrix."
  - [corpus]: No direct evidence, but supports the claim by mentioning the need for methods that can capture multi-hop neighborhood information
