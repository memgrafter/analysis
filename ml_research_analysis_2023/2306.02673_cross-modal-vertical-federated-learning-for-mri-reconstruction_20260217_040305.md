# Cross-Modal Vertical Federated Learning for MRI Reconstruction

## Quick Facts
- **arXiv ID**: 2306.02673
- **Source URL**: https://arxiv.org/abs/2306.02673
- **Reference count**: 14
- **Key outcome**: Introduces CMVFL framework with Fed-CRFD, achieving up to 1.88 dB PSNR improvement over FedAvg for MRI reconstruction across modalities

## Executive Summary
This paper addresses the challenge of cross-modal MRI reconstruction in federated learning settings where hospitals possess different MRI modalities. The proposed Fed-CRFD framework leverages intra-client feature disentanglement to separate modality-invariant and modality-specific features, combined with cross-client latent representation consistency for aligning features across institutions. The method demonstrates significant performance improvements over baseline federated learning approaches, particularly in handling domain shifts between different MRI modalities while maintaining data privacy.

## Method Summary
The Fed-CRFD framework implements cross-modal vertical federated learning through a two-stage approach. First, intra-client feature disentanglement separates each client's features into modality-invariant (shared across modalities) and modality-specific (unique to each modality) components. Second, cross-client latent representation consistency aligns these features for overlapping samples across different clients/hospitals. The framework uses a U-Net-based architecture for reconstruction, with the disentanglement achieved through adversarial training and consistency regularization. During federated learning, clients train locally on their data while sharing only the modality-invariant features, with a central server aggregating these shared representations to improve reconstruction quality across all modalities.

## Key Results
- Fed-CRFD achieves up to 1.88 dB improvement in PSNR compared to FedAvg baseline
- Strong performance in handling domain shifts between T1 and T2-weighted MRI modalities
- Demonstrates better generalization to downstream segmentation tasks compared to baseline methods
- Shows robustness across different client configurations and data distributions

## Why This Works (Mechanism)
The framework works by explicitly modeling the relationship between different MRI modalities through feature disentanglement. By separating modality-invariant features (which capture anatomical structures common across all MRI types) from modality-specific features (which capture unique tissue contrasts and acquisition characteristics), the model can learn shared representations that bridge the domain gap between different modalities. The cross-client consistency mechanism then ensures that when the same patient has scans at different hospitals, their representations are aligned, enabling knowledge transfer and improved reconstruction quality across all participating institutions.

## Architecture Onboarding

**Component Map**: Local Client (U-Net + Disentanglement) -> Central Server (Aggregation) -> Updated Global Model

**Critical Path**: Feature Extraction → Disentanglement (Invariant + Specific) → Cross-Client Consistency → Reconstruction → Loss Computation

**Design Tradeoffs**: The framework trades increased computational complexity (due to disentanglement and consistency mechanisms) for improved cross-modal performance and privacy preservation. This adds training overhead but eliminates the need for data sharing, making it suitable for clinical applications where privacy is paramount.

**Failure Signatures**: Performance degradation occurs when modality-specific features are poorly separated (leading to loss of important acquisition-specific information) or when cross-client consistency fails to properly align representations (resulting in poor reconstruction for patients with scans at multiple sites).

## Limitations
- Evaluation limited to T1 and T2-weighted MRI modalities, with uncertain effectiveness for more diverse modality combinations
- Experiments involve only two clients with moderate data sizes, raising questions about scalability to many heterogeneous clients
- No explicit privacy risk evaluation, such as membership inference or feature leakage analysis
- Computational overhead of the disentanglement and consistency mechanisms is not quantified

## Confidence
- **CMVFL Framework Effectiveness**: High - Supported by quantitative results showing consistent improvements over FedAvg and FedHVT
- **Cross-Modal Domain Adaptation**: Medium - Validated on limited modality pairs; broader generalization uncertain
- **Generalization to Unseen Data**: Medium - Tested on public and private datasets, but sample sizes and diversity are limited
