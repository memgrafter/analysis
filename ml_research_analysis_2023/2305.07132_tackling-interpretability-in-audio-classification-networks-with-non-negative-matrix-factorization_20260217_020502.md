# Tackling Interpretability in Audio Classification Networks with Non-negative Matrix Factorization

## Quick Facts
- arXiv ID: 2305.07132
- Source URL: https://arxiv.org/abs/2305.07132
- Authors: 
- Reference count: 40
- Key outcome: Holistic framework for interpretable audio classification using NMF to learn spectral patterns that regularize neural networks for both post-hoc and by-design interpretability

## Executive Summary
This paper proposes a comprehensive framework for interpretable audio classification that combines non-negative matrix factorization (NMF) with neural network regularization. The system learns a dictionary of spectral patterns through NMF and uses this dictionary to constrain a neural network's intermediate representations, forcing them to be both predictive of classifier outputs and capable of reconstructing the input spectrogram. This dual constraint yields interpretable models that generate listenable interpretations by highlighting relevant audio components. The framework is evaluated on three diverse audio datasets, demonstrating strong performance in both classification accuracy and interpretability metrics.

## Method Summary
The framework uses a pre-trained audio classifier whose hidden layer outputs are processed by an interpreter network (Ψ) to generate a time-activation matrix HI(x). This matrix is constrained through three loss functions: fidelity loss (cross-entropy between Θ(HI(x)) and classifier output f(x)), reconstruction loss (NMF-based reconstruction of input spectrogram X ≈ WHI(x)), and optional sparsity regularization. For post-hoc interpretation, only the interpreter is trained while the classifier remains fixed. For by-design interpretation, the classifier and interpreter are jointly trained with an additional classification loss on the classifier output. The learned NMF dictionary provides a parts-based decomposition of the input, enabling the generation of listenable interpretations by masking components based on their relevance to classification decisions.

## Key Results
- Achieves 87.2% top-1 accuracy on ESC-50 using by-design interpretation
- Generates high-fidelity interpretations with median probability drop of 0.35 when removing relevant components
- Successfully produces listenable interpretations that align with human perception of audio objects

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The interpreter learns to mimic classifier outputs by minimizing a fidelity loss, making the intermediate representation predictive of the classifier's decisions.
- Mechanism: The interpreter network Ψ processes hidden layer outputs from the classifier and produces a time-activation matrix HI(x). A second network Θ transforms HI(x) into class probabilities. A cross-entropy loss between Θ(HI(x)) and f(x) encourages the representation to align with the classifier's predictions.
- Core assumption: The hidden layer outputs contain sufficient information to reconstruct the classifier's decision when properly regularized.
- Evidence anchors:
  - [abstract] "an interpreter is trained to generate a regularized intermediate embedding from hidden layers of a target network, learnt as time-actractions of a pre-learnt NMF dictionary."
  - [section III-B] "To be able to identify the relevant signal for interpretation, we constrain HI(x) to approximate classifiers output probabilities f(x) through the function Θ."
  - [corpus] Weak - corpus papers discuss NMF in classification contexts but do not anchor this specific fidelity-loss approach.
- Break condition: If the classifier's hidden layers are too shallow or the classifier is too complex, the intermediate representation may not capture enough information to mimic the classifier output reliably.

### Mechanism 2
- Claim: The reconstruction loss via a pre-learnt NMF dictionary enforces that the intermediate representation can decompose the input spectrogram into interpretable spectral patterns.
- Mechanism: The time-activation matrix HI(x) is constrained to reconstruct the log-magnitude spectrogram X as X ≈ WHI(x), where W is a fixed NMF dictionary. This imposes a parts-based decomposition structure on HI(x).
- Core assumption: The fixed NMF dictionary W adequately represents the spectral patterns present in the input data.
- Evidence anchors:
  - [abstract] "Reconstruct the input through the help of a dictionary of spectral patterns. The latter loss and its design is strongly inspired by the structure in Non-negative Matrix Factorization (NMF)."
  - [section III-B] "We additionally constrain HI(x) to be able to reconstruct the input audio using pre-learnt dictionary W ∈ RF×K+. This constraint asks to decompose input log-magnitude spectrogram as X ≈ WHI(x)."
  - [corpus] Weak - corpus papers mention NMF-based reconstruction but do not validate this specific approach for interpretability.
- Break condition: If the dictionary W is not well matched to the data or is too small, reconstruction will be poor and the interpretation may not be meaningful.

### Mechanism 3
- Claim: The sparsity loss on HI(x) encourages a compact, well-behaved representation that improves interpretability.
- Mechanism: An ℓ1 regularization term β||HI(x)||1 is added to the loss, promoting sparse activations in the time-activation matrix.
- Core assumption: Sparse activations make it easier to identify which spectral patterns are important for a given class.
- Evidence anchors:
  - [section III-B] "In addition to LFID and LNMF, we impose ℓ1 regularization on HI(x) to encourage well-behavedness, especially for large dictionary sizes."
  - [section III-D] "NMF with sparsity loss is known to provide part-based decompositions."
  - [corpus] Weak - corpus papers mention sparsity in NMF but do not anchor its role in this specific interpretability context.
- Break condition: If sparsity is too strong, the model may lose expressiveness and fail to capture necessary detail for accurate reconstruction and fidelity.

## Architecture Onboarding

- Component map: Input spectrogram → Classifier (f) → Hidden layers → Interpreter Ψ → HI(x) → Θ → Class probabilities; HI(x) also reconstructs input via WHI(x)
- Critical path: Input → classifier hidden layers → Ψ → HI(x) → Θ → class probabilities (fidelity) and X ≈ WHI(x) (reconstruction)
- Design tradeoffs: Balancing fidelity loss (align with classifier) vs reconstruction loss (preserve input structure) vs sparsity (interpretability). Too much emphasis on one can degrade the others.
- Failure signatures: Poor fidelity (misaligned interpretations), poor reconstruction (noisy or incomplete interpretations), or overly dense HI(x) (hard to interpret).
- First 3 experiments:
  1. Train interpreter with only fidelity loss and no reconstruction or sparsity; measure fidelity vs classifier.
  2. Train interpreter with only reconstruction loss; measure reconstruction error and qualitative interpretability.
  3. Vary sparsity weight β; observe effects on fidelity, reconstruction, and interpretability.

## Limitations

- Key architectural details of the Ψ network (convolutional layer counts, filter sizes, channel dimensions) are not fully specified, creating potential reproducibility challenges.
- The sparsity regularization weight β appears arbitrary without sensitivity analysis, and its optimal value may vary across datasets.
- The framework's performance on the challenging SONYC-UST dataset with significant noise is not thoroughly analyzed, and learned dictionary components may capture noise rather than meaningful spectral patterns.

## Confidence

- **High confidence**: The core NMF-based reconstruction mechanism and the general interpreter architecture are well-described and theoretically sound
- **Medium confidence**: The fidelity loss mechanism should work as described, though exact hyperparameters may affect performance
- **Low confidence**: The interpretability claims, particularly for SONYC-UST dataset, may be over-stated given the noted challenges with noise and the absence of detailed ablation studies
