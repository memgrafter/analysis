# Cooperative Thresholded Lasso for Sparse Linear Bandit

## Quick Facts
- arXiv ID: 2305.19161
- Source URL: https://arxiv.org/abs/2305.19161
- Authors: 
- Reference count: 40
- Key outcome: Multi-agent sparse contextual linear bandit method using Lasso dimension reduction, achieving regret bound O(s₀ log d + s₀√T) with logarithmic communication cost.

## Executive Summary
This paper introduces a cooperative multi-agent approach for sparse contextual linear bandit problems, where each agent independently estimates the support set of relevant features using Thresholded Lasso regression and shares this information across the network. The method reduces communication costs by only exchanging support set indices rather than full parameter estimates, while maintaining strong theoretical regret guarantees. Two communication frameworks are proposed: a centralized star-shaped network with a server node and a decentralized peer-to-peer network with random neighbor communication.

## Method Summary
The approach employs periodic Lasso regression for dimension reduction, where each agent estimates the support set of the sparse parameter θ*. After thresholding to remove spurious features, agents share their support sets through the network (either via a central server or peer-to-peer communication). The supports are aggregated through union operations, and each agent performs ridge regression only on the reduced dimension space. The method achieves O(s₀ log d + s₀√T) regret with communication costs of O(s₀ log T) by synchronizing only at logarithmic intervals.

## Key Results
- Proposes novel cooperative algorithms for multi-agent sparse contextual linear bandits
- Achieves regret bound of O(s₀ log d + s₀√T) with high probability
- Reduces communication costs to O(s₀ log T) through support set sharing
- Validates effectiveness on both synthetic and real-world datasets
- Provides both centralized (star-shaped) and decentralized (peer-to-peer) communication frameworks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Dimension reduction via Lasso followed by thresholding improves support recovery in sparse linear bandit settings.
- Mechanism: Each agent runs Lasso regression periodically to estimate the support set of the sparse parameter. Thresholding removes spurious features, and agents share these reduced support sets across the network, improving collective accuracy.
- Core assumption: Lasso estimation can recover the support set with high probability when the compatibility condition and sparsity assumptions hold.
- Evidence anchors:
  - [abstract] "The proposed method employs Lasso regression for dimension reduction, allowing each agent to independently estimate an approximate set of main dimensions and share that information with others depending on the network's structure."
  - [section 4.1] "Lemma 1 represents an extension of the support recovery outcome of the Thresholded Lasso Bandit... to the circumstance of multiple agents exchanging information among each other."
  - [corpus] No direct corpus match for multi-agent thresholding; relies on [4] for single-agent baseline.
- Break condition: If the thresholding value is too low, false positives remain; if too high, true positives are lost.

### Mechanism 2
- Claim: Communication cost scales logarithmically with time horizon, reducing bandwidth requirements.
- Mechanism: Agents synchronize only at logarithmic intervals (when log_ξ(t) ∈ ℕ), sending only the indices of the estimated support set rather than full parameter estimates.
- Core assumption: Synchronization frequency can be sparse without significantly harming convergence because the support set stabilizes quickly.
- Evidence anchors:
  - [abstract] "The approaches effectively reduce communication costs while ensuring minimal cumulative regret per agent."
  - [section 3.1] "To save communication costs, agents only share their estimate of θ's support."
  - [corpus] Closest neighbor: "Cooperative Multi-agent Bandits: Distributed Algorithms with Optimal Individual Regret and Constant Communication Costs" (FMR=0.49) supports low-communication approaches.
- Break condition: If agents fall out of sync for too long, estimation drift can increase regret.

### Mechanism 3
- Claim: Federated ridge regression on reduced dimensions maintains low regret bounds comparable to centralized methods.
- Mechanism: After support sharing, each agent performs ridge regression only on the estimated support set, reducing the effective dimension from d to s₀ ≪ d, which lowers estimation error and regret.
- Core assumption: The empirical Gram matrix remains positive definite on the estimated support, ensuring stable ridge regression.
- Evidence anchors:
  - [abstract] "Each agent then resolves the problem with ridge regression focusing solely on the extracted dimensions."
  - [section 4.1] "Lemma 2... aims to establish the positive definiteness of ˆΣt,i, even when the underlying data generating process is not i.i.d."
  - [corpus] Weak match; no direct corpus paper addresses federated ridge on reduced support sets.
- Break condition: If support recovery fails, ridge regression will suffer from misspecification and higher regret.

## Architecture Onboarding

- Component map: Context sampler -> Lasso estimator -> Thresholder -> Support synchronizer -> Ridge solver -> Arm selector
- Critical path: 1. Sample contexts → 2. Lasso → 3. Threshold → 4. Share supports → 5. Union → 6. Ridge → 7. Select arm → 8. Observe reward
- Design tradeoffs:
  - Synchronization frequency (log_ξ(t) ∈ ℕ) vs. estimation accuracy
  - Threshold value vs. false positive/negative rates
  - Communication topology (star vs. peer-to-peer) vs. robustness
- Failure signatures:
  - Slow regret reduction → poor support recovery or too infrequent sync
  - Communication spikes → misconfigured synchronization schedule
  - Instability in arm selection → incorrect threshold or Gram matrix ill-conditioning
