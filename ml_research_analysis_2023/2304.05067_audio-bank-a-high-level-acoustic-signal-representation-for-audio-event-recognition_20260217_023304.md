# Audio Bank: A High-Level Acoustic Signal Representation for Audio Event Recognition

## Quick Facts
- arXiv ID: 2304.05067
- Source URL: https://arxiv.org/abs/2304.05067
- Reference count: 0
- Audio Bank features achieve 85-90% recognition accuracy on UPC-TALP dataset

## Executive Summary
This paper introduces Audio Bank, a high-level feature representation for audio event recognition that outperforms traditional low and mid-level features. The method represents each audio class with distinctive spectrogram-based detectors in frequency-temporal space, using Bhattacharyya coefficient for similarity measurement and max-pooling for feature construction. Non-negative matrix factorization reduces dimensionality while preserving discriminability. Experiments on 12 meeting-room audio classes show 85-90% recognition accuracy with various classifiers, demonstrating robustness to training data size and bank size variations.

## Method Summary
The Audio Bank method constructs distinctive spectrogram templates for each audio class using k-means clustering, then computes cross-correlation between these templates and input spectrograms using Bhattacharyya coefficient. Alternate max-pooling creates compact feature vectors, which are reduced in dimensionality via non-negative matrix factorization. The resulting features are classified using SVM, neural networks, Gaussian processes, or k-nearest neighbors. The approach emphasizes semantic richness and group sparsity to maintain performance even with small training sets or reduced bank sizes.

## Key Results
- Audio Bank features achieve 85-90% recognition accuracy on UPC-TALP dataset with 12 meeting-room classes
- SVM classifier performs best (90% accuracy), followed by NN, GP, and k-NN
- Method remains effective with 40% training data per class (>80% accuracy)
- Performance stable across bank sizes from 12 to 120 detectors
- Outperforms traditional low and mid-level features in all experimental conditions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Audio Bank achieves high recognition accuracy by using distinctive audio detectors that capture class-specific spectro-temporal patterns.
- Mechanism: Each audio class is represented by multiple spectrogram templates (detectors) that serve as basis functions in the audio space. The system computes cross-correlation between these detectors and the input signal's spectrogram using Bhattacharyya coefficient for distribution similarity. Max-pooling across correlation outputs creates compact, discriminative feature vectors.
- Core assumption: Distinctive spectro-temporal patterns exist for each audio class and can be captured by template matching.

## Architecture Onboarding

- Component map: Spectrogram extraction -> Bank detector selection -> Correlation computation -> Max-pooling -> NMF dimensionality reduction -> Classification
- Critical path: Spectrogram → Detector matching → Correlation → Max-pooling → NMF → Classification
- Design tradeoffs:
  - Detector selection: More detectors increase discriminability but computational cost; fewer detectors risk missing patterns
  - Feature dimensionality: Higher dimensions may capture more detail but risk curse of dimensionality; NMF balances this
  - Classifier choice: Simpler classifiers (k-NN) are faster but may underperform complex ones (NN) on high-dimensional data
- Failure signatures:
  - Poor AER performance: Likely indicates ineffective detector selection or correlation computation
  - High variance across runs: May indicate instability in detector selection or NMF decomposition
  - Computational bottlenecks: Correlation computation or NMF factorization are likely culprits
- First 3 experiments:
  1. Verify spectrogram extraction produces expected frequency-time representations for known audio events
  2. Test correlation computation between simple template spectrograms and input signals using Bhattacharyya coefficient
  3. Validate NMF decomposition preserves class discriminability by reconstructing features and measuring classification accuracy before/after reduction
