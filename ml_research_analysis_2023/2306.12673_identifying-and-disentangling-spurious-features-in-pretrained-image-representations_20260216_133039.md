# Identifying and Disentangling Spurious Features in Pretrained Image Representations

## Quick Facts
- arXiv ID: 2306.12673
- Source URL: https://arxiv.org/abs/2306.12673
- Reference count: 17
- Key outcome: Proposed method improves worst group accuracy on Waterbirds dataset from 60.2% to 81.7% by disentangling and removing spurious features from pretrained representations.

## Executive Summary
This paper addresses the challenge of spurious correlations in image representations by proposing a method to identify and remove spurious features from pretrained models. The authors focus on the Waterbirds dataset where background is spuriously correlated with bird labels, using representations from ResNet-50, RegNetY, and DINOv2. They demonstrate that spurious features are entangled in the representations and propose a linear autoencoder to separate them from core features. The method significantly improves worst group accuracy by removing neurons with high spuriousness attribution or by using the disentangled representation from the autoencoder.

## Method Summary
The proposed method uses a linear autoencoder to separate pretrained representations into three components: label-aware (core features), spurious features, and other features needed for reconstruction. The autoencoder is trained on an upsampled training set to minimize mutual information between the core and spurious parts. After disentanglement, two approaches are used to remove spurious features: either removing neurons with high spuriousness attribution using Captum, or training classifiers on the label-aware part of the disentangled representation. The method is evaluated on the Waterbirds dataset, where background (water/land) is spuriously correlated with bird species.

## Key Results
- Removing top 50 spurious neurons improves worst group accuracy from 60.2% to 67.7% for ResNet-50
- Autoencoder-based method further improves worst group accuracy to 81.7% for ResNet-50
- Method closes much of the gap between standard training and upper bound with unbiased data
- DINOv2 shows high baseline worst-group accuracy, making spurious feature removal less effective

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pretrained representations contain linearly entangled spurious and core features that can be disentangled by a linear transformation.
- Mechanism: Since both spurious features and class labels can be predicted well from the representation using linear layers, the authors hypothesize that a linear autoencoder can reverse this entanglement by splitting the representation into core, spurious, and other feature components.
- Core assumption: The spurious and core features are linearly entangled in the representation space.
- Evidence anchors:
  - [abstract] "Since both the spurious feature and the label can be predicted well from the representation with a linear layer, we hypothesize that the entanglement of core and spurious features is linear and can be reversed with a linear transformation."
  - [section 4] "We design a simple autoencoder where the linear encoder maps input z to three vectors: zy, zc and zn. We force zy and zc to contain information about the label and the background, respectively."
- Break condition: If the entanglement between spurious and core features is not linear, the linear autoencoder will not be able to effectively disentangle them.

### Mechanism 2
- Claim: Removing neurons with high spuriousness attribution can improve worst group accuracy by eliminating spurious features.
- Mechanism: Using Captum's Integrated Gradients method, the authors compute attribution heatmaps for each neuron, measuring how much each neuron responds to background versus foreground pixels. Neurons with high spuriousness scores are removed from the representation before training the classifier.
- Core assumption: Individual neurons in the representation can be attributed to specific image regions (foreground vs background).
- Evidence anchors:
  - [section 3] "We use Captum to find this attribution... We define spuriousness s(xj) ∈ Rd the following way... The spuriousness of the specific neuron zi is defined as the average spuriousness over the training set X."
  - [section 3] "Removing features that look mostly to background improves worst group accuracy... We sort the d neurons according to si and consider keeping only the top N neurons for the linear models."
- Break condition: If the individual neurons are not pure spurious or pure non-spurious (as suggested for DINOv2), this approach will not be effective.

### Mechanism 3
- Claim: Applying PCA to the label-aware part of the disentangled representation can further remove non-core features and improve worst group accuracy.
- Mechanism: After using the autoencoder to separate the representation into label-aware (zy) and spurious (zc) parts, PCA is applied to zy to reduce dimensionality while retaining the principal components that capture most variance, which is hypothesized to be along core features.
- Core assumption: Most of the variance in the label-aware part of the disentangled representation is along core features rather than spurious features.
- Evidence anchors:
  - [section 4] "We apply principal component analysis (PCA) on zy to further remove non-core features... We find that, indeed, training linear models on the N principal components of zy still improves the worst group accuracy for ResNet and RegNetY."
  - [section 4] "Unlike Captum, PCA does not require additional information from the data. We note that applying PCA directly on z does not help to identify core features."
- Break condition: If the label-aware part still contains significant spurious information, PCA may not effectively remove it and could potentially remove important core features as well.

## Architecture Onboarding

- Component map:
  Pretrained backbone (ResNet-50, RegNetY, DINOv2) -> Linear autoencoder -> Linear classifier
  Captum for neuron attribution -> PCA for dimensionality reduction

- Critical path:
  1. Load pretrained backbone and freeze weights
  2. Compute representations for training data
  3. Train linear autoencoder to separate core, spurious, and other features
  4. Train linear classifier on autoencoder outputs
  5. Evaluate worst group accuracy

- Design tradeoffs:
  - Using a linear autoencoder vs. more complex architectures
  - Trade-off between removing spurious features and retaining useful information
  - Computational cost of Captum attribution vs. potential performance gains

- Failure signatures:
  - No improvement in worst group accuracy after applying the method
  - Performance degradation compared to baseline
  - Autoencoder fails to separate features effectively (zy and zc remain correlated)

- First 3 experiments:
  1. Verify that the linear autoencoder can effectively separate the representation into label-aware and spurious parts by checking the correlation between zy and zc
  2. Test the Captum attribution method on a small subset of neurons to confirm it can identify spurious neurons
  3. Compare the performance of linear models trained on different parts of the disentangled representation (zy, zc, zn) to understand which components are most useful

## Limitations
- Method effectiveness varies significantly across different architectures (works well for ResNet-50 and RegNetY but less so for DINOv2)
- Focus on a single dataset (Waterbirds) limits generalizability of findings
- Assumes spurious features are linearly entangled, which may not hold for more complex scenarios

## Confidence
- High confidence: The empirical demonstration that removing high-spuriousness neurons improves worst-group accuracy
- Medium confidence: The linear autoencoder's ability to disentangle core and spurious features across different architectures
- Medium confidence: The generalizability of findings beyond the Waterbirds dataset
