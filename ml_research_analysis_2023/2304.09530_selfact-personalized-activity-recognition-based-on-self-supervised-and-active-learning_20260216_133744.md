# SelfAct: Personalized Activity Recognition based on Self-Supervised and Active Learning

## Quick Facts
- arXiv ID: 2304.09530
- Source URL: https://arxiv.org/abs/2304.09530
- Reference count: 37
- One-line primary result: Achieves F1 scores close to fully supervised methods with 98% fewer labeled samples

## Executive Summary
SelfAct addresses the challenge of personalized sensor-based human activity recognition on mobile devices, where high variability between and within users makes traditional supervised approaches impractical due to the large amount of labeled data required. The method combines self-supervised pre-training on multi-user unlabeled data with an unsupervised active learning strategy that selectively queries users for labels on the most representative samples. This approach achieves competitive performance (F1 scores of 0.9734 for HHAR and 0.9291 for MotionSense) while requiring dramatically fewer labeled samples (369 vs 25,053 for HHAR and 143 vs 5,304 for MotionSense).

## Method Summary
SelfAct uses a three-phase approach: first, a deep neural network is pre-trained using self-supervised learning on unlabeled sensor data from multiple users to learn meaningful latent representations. Second, when deployed on a new user's device, it accumulates unlabeled sensor data, reduces dimensionality using UMAP, and clusters the embeddings using HDBSCAN. Third, during real-time operation, it assigns incoming samples to clusters and triggers active learning queries when samples improve cluster density, minimizing user burden. The labeled samples collected through this process are used to dynamically build a classification head and fine-tune the model for personalized activity recognition.

## Key Results
- Achieves F1 score of 0.9734 on HHAR dataset with only 369 labeled samples (vs 25,053 for fully supervised)
- Achieves F1 score of 0.9291 on MotionSense dataset with only 143 labeled samples (vs 5,304 for fully supervised)
- Demonstrates 98% reduction in required labeled samples while maintaining competitive performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pre-training a deep network on unlabeled multi-user data creates a generalizable embedding space for new users.
- Mechanism: The self-supervised phase learns latent representations that cluster samples of the same activity pattern closely, regardless of the specific user, enabling effective personalization with minimal labeled data.
- Core assumption: Activity patterns are similar enough across users that embeddings learned from one user generalize to another.
- Evidence anchors:
  - [abstract] "SelfAct leverages a large pool of unlabeled data collected from many users to pre-train through self-supervision a DL model, with the goal of learning a meaningful and efficient latent representation of sensor data."
  - [section III-A] "The goal of the self-supervised phase is to train, in a self-supervised fashion, a deep learning model capable of transforming raw sensor data samples into an efficient latent representation (i.e., embeddings)."
- Break condition: If intra- and inter-user variability is too high, embeddings may not generalize well, reducing personalization effectiveness.

### Mechanism 2
- Claim: Unsupervised active learning queries only the most representative samples per cluster, minimizing user burden.
- Mechanism: By evaluating cluster density before triggering a query, SelfAct selects samples that improve cluster cohesion, ensuring each query provides maximal information gain for fine-tuning.
- Core assumption: Cluster density is a reliable proxy for sample representativeness and informativeness.
- Evidence anchors:
  - [section III-C] "An active learning process is started by evaluating whether a new reduced embeddings sample s improves the density of its cluster or not."
  - [algorithm 2] "If this average distance is lower than Tc, then s is considered highly representative of c and an active learning query is requested to the user."
- Break condition: If clusters are not well-formed or density does not correlate with informativeness, active learning may select suboptimal samples.

### Mechanism 3
- Claim: Dynamic creation of the Fine-Tuning Head based on collected labels allows adaptation to any activity set.
- Mechanism: Since the number and type of activities are unknown a priori, SelfAct builds the classification layer on-the-fly as labels are collected, ensuring the model can handle any discovered activity pattern.
- Core assumption: The set of activities is discoverable through clustering and active learning without prior knowledge.
- Evidence anchors:
  - [section III-D] "Since it is not possible to know in advance how many activities (and which) the user actually performed, the Fine-Tuning Head is created dynamically based on the number of activity classes in the labeled data."
- Break condition: If the discovered clusters do not align with true activity classes, the dynamic head may misclassify or fail to cover all activities.

## Foundational Learning

- Concept: Self-supervised learning
  - Why needed here: Enables learning useful representations from unlabeled data, critical when labeled data is expensive to obtain.
  - Quick check question: What is the main advantage of self-supervised learning over supervised learning in data-scarce domains?

- Concept: Active learning
  - Why needed here: Allows selective labeling of the most informative samples, reducing the burden on users while maximizing model performance.
  - Quick check question: How does active learning differ from passive learning in terms of data labeling strategy?

- Concept: Dimensionality reduction (UMAP)
  - Why needed here: Reduces the dimensionality of embeddings to improve clustering performance and efficiency in real-time scenarios.
  - Quick check question: Why might UMAP be preferred over t-SNE for real-time clustering in SelfAct?

## Architecture Onboarding

- Component map: Pre-trained feature extractor -> UMAP dimensionality reduction -> HDBSCAN clustering -> Active learning query engine -> Dynamic classification head

- Critical path:
  1. Pre-train feature extractor on unlabeled multi-user data.
  2. Accumulate unlabeled data from new user, reduce and cluster.
  3. In real-time, assign new samples to clusters and trigger queries based on density.
  4. Collect labeled samples, dynamically build classification head, fine-tune model.

- Design tradeoffs:
  - ACC T H (accumulation threshold) balances recognition rate and active learning rate.
  - Choice of clustering algorithm (HDBSCAN) avoids needing to know the number of clusters.
  - UMAP enables real-time dimensionality reduction; t-SNE would not be feasible.

- Failure signatures:
  - Low recognition rate despite many queries: clusters may not represent true activity patterns.
  - Very high active learning rate: clusters may be too sparse or fragmented.
  - Poor generalization across users: pre-trained embeddings may not capture shared activity patterns.

- First 3 experiments:
  1. Vary ACC T H (e.g., 50%, 75%, 95%) and measure impact on recognition rate and active learning rate.
  2. Replace HDBSCAN with K-means and evaluate recognition rate and number of queries.
  3. Test different dimensionality reduction methods (UMAP vs. PCA) and measure clustering quality and real-time performance.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the active learning query rate scale with larger unlabeled datasets in real-world scenarios?
- Basis in paper: [explicit] The paper mentions that in real-world scenarios with large amounts of unlabeled data, the active learning rate would be significantly lower, but this was not evaluated due to the small size of the datasets used.
- Why unresolved: The evaluation was limited to relatively small public datasets, preventing assessment of active learning rate with larger unlabeled data streams.
- What evidence would resolve it: Experiments using larger, more realistic unlabeled datasets collected over extended periods would demonstrate how active learning query rates scale.

### Open Question 2
- Question: Can SelfAct effectively distinguish between outliers and new activities during the fine-tuning phase?
- Basis in paper: [inferred] The paper mentions that an open question is whether SelfAct can truly assess its capability for activity discovery and domain adaptation, specifically distinguishing outliers from new activities.
- Why unresolved: The experiments used datasets with predefined activity labels, not allowing evaluation of outlier detection or new activity discovery.
- What evidence would resolve it: Experiments with datasets containing outliers or new activities not present in the pre-training data would demonstrate SelfAct's ability to distinguish between them.

### Open Question 3
- Question: What is the optimal strategy for determining when to switch from the accumulation phase to the active learning phase?
- Basis in paper: [explicit] The paper states that SelfAct assumes a fixed threshold to decide when switching from accumulation to active learning phase, and mentions investigating automatic methods based on the silhouette score of the clusters.
- Why unresolved: The paper used a fixed accumulation threshold and did not explore automatic methods for determining the optimal switch point.
- What evidence would resolve it: Comparative experiments evaluating different automatic strategies (e.g., silhouette score-based) against fixed thresholds would determine the optimal approach.

## Limitations

- The effectiveness of pre-training relies on strong assumptions about cross-user similarity that are not empirically validated across diverse user populations.
- The active learning mechanism's reliance on cluster density as a proxy for sample informativeness lacks direct validation and may select redundant samples.
- The method's performance with truly large-scale unlabeled data streams (days/weeks of sensor data) has not been evaluated, limiting understanding of real-world query rates.

## Confidence

- High Confidence: The experimental results showing significant reduction in labeled samples required (369 vs 25,053 for HHAR) while maintaining competitive F1 scores. The methodology description is sufficiently detailed to reproduce the core approach, and the results are internally consistent.
- Medium Confidence: The mechanism claims about why self-supervised pre-training enables effective personalization. While the paper provides theoretical justification and shows improved performance, it lacks ablation studies to isolate the specific contribution of pre-training versus other components.
- Low Confidence: The claim that cluster density reliably identifies the most informative samples for active learning. This is a core assumption of the method but is not empirically validated beyond the overall system performance.

## Next Checks

1. **Ablation on pre-training**: Run experiments comparing SelfAct against a baseline that skips the self-supervised pre-training phase but uses the same active learning strategy. This would isolate the contribution of pre-training to the overall performance gains.

2. **Cluster quality analysis**: Measure the alignment between discovered clusters and true activity labels using metrics like normalized mutual information or adjusted Rand index. This would validate whether clusters are actually representing meaningful activity patterns.

3. **Cross-user variability study**: Evaluate model performance when pre-training data comes from users with systematically different characteristics (age, fitness level, etc.) to understand the limits of cross-user generalization and identify when personalization fails.
