# A technical note on bilinear layers for interpretability

## Quick Facts
- arXiv ID: 2305.03452
- Source URL: https://arxiv.org/abs/2305.03452
- Reference count: 6
- Primary result: Bilinear layers can be expressed using only linear operations and third-order tensors, enabling formal analysis and interpretability.

## Executive Summary
This technical note examines bilinear layers as a more interpretable alternative to standard MLPs with elementwise activation functions. The key insight is that despite being nonlinear functions of the input vector, bilinear layers can be expressed using only linear operations and third-order tensors. This mathematical reformulation enables extending the mathematical framework for transformer circuits to transformers with both attention and MLP layers, not just attention-only transformers. The simplicity of bilinear layers makes formal analysis much easier than for standard MLPs, potentially opening new paths for mechanistic interpretability through understanding feature construction mechanisms.

## Method Summary
The paper presents a mathematical framework showing how bilinear layers can be reformulated using tensor operations. The core method involves expressing the bilinear layer computation (W1x ⊙ W2x) as a tensor inner product x·12 B·21 x, where B is a third-order tensor constructed from the weight matrices. This reformulation enables extending the path expansion methodology for transformer circuits to include bilinear MLP layers alongside attention layers. The analysis demonstrates that bilinear layers are "additively pairwise nonlinear," decomposing feature interactions into sums of pairwise interactions rather than requiring full all-to-all nonlinear interactions.

## Key Results
- Bilinear layers can be expressed using only linear operations and third-order tensors, making them mathematically tractable
- Despite being nonlinear functions, bilinear layers are "additively pairwise nonlinear," decomposing feature interactions into pairwise sums
- The tensor reformulation enables extending transformer circuit analysis frameworks to include both attention and MLP layers

## Why This Works (Mechanism)

### Mechanism 1: Tensor reformulation enables formal analysis
- Claim: Bilinear layers enable weight-based mechanistic interpretability by replacing nonlinear activations with linear operations and third-order tensors
- Mechanism: The bilinear layer computes (W1x) ⊙ (W2x), which can be rewritten as x·12 B·21 x where Bijk = W1(ij)W2(ik). This transformation from nonlinear to linear operations preserves the computational power while enabling formal analysis using tensor algebra
- Core assumption: The tensor inner product formulation accurately captures the bilinear layer's computation and can be integrated into existing mathematical frameworks for transformer circuits
- Evidence anchors:

  - [section] "they can be expressed using only linear operations and third order tensors"
  - [corpus] Weak evidence - only mentions bilinear MLPs but not the tensor formulation
- Break condition: If the tensor inner product formulation fails to preserve the computational properties of bilinear layers, or if the integration into transformer circuit frameworks proves intractable

### Mechanism 2: Linear modifier vector enables feature construction analysis
- Claim: Bilinear layers simplify feature construction analysis by making the modifier vector a linear function of input features
- Mechanism: In bilinear layers, the modifier vector m(x) = W1x is directly computable from input features, unlike standard MLPs where m(x) requires observing post-activation values. This allows studying feature construction through pairwise interactions between input features
- Core assumption: The modifier vector approach provides a meaningful decomposition of feature construction that reveals interpretable mechanisms
- Evidence anchors:
  - [section] "M LPBilinear (x) = m(x) ⊙ (W2x) where m(x) = W1x"
  - [section] "the modiﬁer vector is a linear function of the input!"
  - [corpus] Weak evidence - mentions bilinear MLPs but not the linear modifier vector property
- Break condition: If the linear modifier vector approach fails to capture meaningful feature construction mechanisms, or if pairwise interactions prove insufficient for understanding complex feature relationships

### Mechanism 3: Pairwise interaction decomposition reduces complexity
- Claim: Bilinear layers reduce the nonlinearity degree from fully nonlinear to additively pairwise nonlinear
- Mechanism: Standard MLPs require all-to-all nonlinear interactions between input features, while bilinear layers decompose feature construction into sums of pairwise interactions: (W1x) ⊙ (W2x) = Σi,j ai aj di ·12 B ·21 dj. This decomposition enables studying feature interactions through tensor analysis
- Core assumption: The pairwise interaction decomposition captures the essential computational properties while enabling tractable analysis
- Evidence anchors:
  - [section] "bilinear layers are additively pairwise nonlinear"

- Break condition: If the pairwise interaction decomposition proves insufficient for capturing important computational properties, or if tensor analysis of pairwise interactions remains intractable

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Do bilinear layers maintain their interpretability advantages when scaled to large model sizes beyond the 120M parameter models studied by Shazeer (2020)?
- Basis in paper: [explicit] The paper notes that bilinear layers' performance at scales larger than approximately 120M parameters remains untested, stating "it remains to be determined whether bilinear layers continue to perform competitively at larger scales."
- Why unresolved: Current research has only validated bilinear layers' effectiveness at relatively small scales. Large language models with billions of parameters may have different dynamics that could affect both performance and interpretability.
- What evidence would resolve it: Systematic experiments comparing bilinear MLP layers against standard MLPs and other architectures (like SwiGLU) in transformers with parameter counts ranging from 100M to 100B+ parameters, measuring both performance metrics and interpretability characteristics.

### Open Question 2
- Question: Can the feature construction mechanisms in bilinear layers be empirically verified to follow the "additive pairwise nonlinear" pattern described in the paper?
- Basis in paper: [explicit] The paper proposes that "bilinear layers are additively pairwise nonlinear" and suggests this makes them "significantly easier to analyze," but acknowledges this remains theoretical.
- Why unresolved: The paper presents the mathematical framework for understanding feature construction but hasn't yet conducted experiments to verify whether real networks actually organize features in this way or if this theoretical advantage translates to practical interpretability gains.
- What evidence would resolve it: Empirical studies using sparse probing techniques to identify individual input features and their pairwise interactions, then measuring whether output features can be decomposed into sums of these pairwise interactions rather than requiring full all-to-all interactions.

### Open Question 3
- Question: What is the relationship between superposition capacity and regularization in bilinear layers, and how does this affect both performance and interpretability?
- Basis in paper: [explicit] The paper mentions that constraining the L2 norm of W1x (making the modifier vector close to the one vector) could "control the amount of superposition a network is able to do," suggesting this as an experimental lever.
- Why unresolved: While the paper proposes this as an interesting experimental direction, it doesn't explore how varying superposition capacity through regularization affects the trade-off between model performance and interpretability.
- What evidence would resolve it: Training multiple bilinear networks with different levels of regularization on W1, then measuring: (1) performance degradation/gains, (2) feature sparsity in both input and output spaces, and (3) ease of interpreting feature construction mechanisms at each regularization level.

## Limitations

- The paper provides theoretical analysis without empirical validation of the mathematical claims
- The extension of transformer circuit frameworks to bilinear layers remains theoretical with no experimental verification
- The claim that bilinear layers offer a viable path for mechanistic interpretability is speculative without empirical demonstrations
