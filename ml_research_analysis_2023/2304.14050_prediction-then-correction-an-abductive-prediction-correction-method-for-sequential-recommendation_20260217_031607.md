# Prediction then Correction: An Abductive Prediction Correction Method for Sequential Recommendation

## Quick Facts
- arXiv ID: 2304.14050
- Source URL: https://arxiv.org/abs/2304.14050
- Reference count: 39
- Key outcome: APC framework improves sequential recommendation performance by 3-5% in Recall@10 and NDCG@10 on Amazon-Beauty and MovieLens-1M datasets using three backbone models.

## Executive Summary
This paper proposes an Abductive Prediction Correction (APC) framework for sequential recommendation that simulates human abductive reasoning to correct predictions made by sequential recommender models. The framework uses a reversed sequential model to infer the most probable historical interactions from future predictions, then minimizes the discrepancy between inferred and true historical interactions to adjust the predictions. Experiments demonstrate consistent performance improvements across three backbone models (SASRec, DualRec, Caser) on two real-world datasets.

## Method Summary
The APC framework introduces an abductive reasoning task where a reversed sequential model infers historical interactions from future predictions made by a recommender. The predictions are then corrected by minimizing the discrepancy between the inferred historical interactions and the true historical interactions. The framework focuses corrections on top-N' candidates to reduce computational cost and employs an information gain strategy to prevent over-correction. During inference, the framework iteratively adjusts prediction scores via gradient descent until convergence or a maximum iteration limit is reached.

## Key Results
- APC improves SASRec's Recall@10 from 0.0294 to 0.0325 and NDCG@10 from 0.0157 to 0.0176 on Amazon-Beauty dataset
- APC consistently improves performance across three backbone models (SASRec, DualRec, Caser) on both Amazon-Beauty and MovieLens-1M datasets
- The framework demonstrates effectiveness of abductive reasoning over analogical reasoning approaches like DTEC

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using abductive reasoning via a reversed sequential model allows correction of predictions without relying on training data prediction errors.
- Mechanism: The APC framework generates a dummy embedding from the top-N' prediction scores and injects it into a reversed sequence. The reversed model then infers the likelihood of each historical interaction. The discrepancy between inferred and actual historical interactions is minimized via gradient descent, adjusting the prediction scores.
- Core assumption: The reversed sequential model can effectively infer plausible historical interactions given future interactions predicted by the original model.
- Evidence anchors:
  - [abstract] "Our approach simulates abductive reasoning to correct predictions. Specifically, we design an abductive reasoning task that infers the most probable historical interactions from the future interactions predicted by a recommender, and minimizes the discrepancy between the inferred and true historical interactions to adjust the predictions."
  - [section] "we use the abductive model to infer the historical interactions that are most likely to have led to the predicted future interactions. The predictions can then be corrected by minimizing the discrepancy between the inferred historical interactions and the true historical interactions."
- Break condition: If the reversed model cannot infer meaningful historical interactions (e.g., when the prediction scores are noisy or uninformative), the correction process fails to provide useful updates.

### Mechanism 2
- Claim: Restricting corrections to top-N' prediction scores prevents over-correction and reduces computational cost.
- Mechanism: The APC framework defines V'_u as the set of items with top-N' initial prediction scores. Only these candidates are considered for correction, avoiding adjustments for low-confidence predictions.
- Core assumption: The top-N' items are most likely to benefit from correction and contain the most informative candidates for abductive inference.
- Evidence anchors:
  - [section] "we only focus on correcting the candidate items with top-N' (initial) prediction scores. That means, V'_u = {v | y_v ranks in the top N' among all candidate items}."
  - [section] "This strategy could also help reduce computation costs, which is crucial for recommendation since there are usually efficiency requirements during online serving."
- Break condition: If N' is too small, potentially useful corrections for items just outside the top-N' are missed. If N' is too large, the risk of over-correction increases.

### Mechanism 3
- Claim: The information gain-based strategy ensures corrections only occur when they improve abductive inference.
- Mechanism: After correction iterations, the framework recomputes the abductive loss ℓ. If ℓ > ℓ' (the loss without the dummy item), the correction is rejected and initial scores are restored.
- Core assumption: A lower abductive loss indicates that the corrected predictions better explain the historical sequence.
- Evidence anchors:
  - [section] "we compute ℓ defined in Equation (5) again and compare it with another ℓ' gotten with [v_T, ..., v_{t+1}]. Then, we reject the prediction correction if ℓ > ℓ', and recover the initial prediction scores."
- Break condition: If the information gain strategy is too conservative, potentially beneficial corrections might be rejected. If too lenient, unreliable corrections might be accepted.

## Architecture Onboarding

- Component map:
  Recommender model (e.g., SASRec, DualRec, Caser) -> Abductive model (reversed version) -> Dummy embedding generator -> Correction controller -> Prediction adjustment

- Critical path:
  1. Generate predictions using the recommender model
  2. Create dummy embedding from top-N' predictions
  3. Perform abductive inference using the reversed model
  4. Compute abductive loss
  5. Adjust predictions via gradient descent
  6. Check information gain; reject correction if no gain
  7. Repeat steps 3-6 until convergence
  8. Re-rank and select top-N recommendations

- Design tradeoffs:
  - N' size vs. computational cost vs. correction quality
  - Learning rate α vs. stability of correction vs. speed of convergence
  - Model architecture complexity vs. inference accuracy vs. training time

- Failure signatures:
  - Predictions become worse after correction (over-correction)
  - No change in predictions despite multiple iterations (under-correction or poor abductive inference)
  - Extremely slow convergence or divergence during adjustment
  - High computational cost due to large N'

- First 3 experiments:
  1. Verify that APC improves Recall@10 and NDCG@10 on a small dataset (e.g., Beauty) using SASRec as the backbone
  2. Test the effect of varying N' on recommendation performance to find the optimal value
  3. Compare APC with DTEC on the same datasets to demonstrate the superiority of abductive reasoning over analogical reasoning

## Limitations
- Generalizability across datasets: The reported improvements are based on two specific datasets (Amazon-Beauty and MovieLens-1M), limiting confidence in performance on other domains
- Computational overhead: The paper mentions efficiency considerations but lacks explicit analysis of runtime and memory usage compared to baseline models
- Sensitivity to hyperparameters: Optimal values for N' and learning rate α are not thoroughly explored, potentially impacting practical deployment

## Confidence
- High: The core abductive reasoning mechanism and its implementation are clearly described and theoretically sound
- Medium: The reported performance improvements on the tested datasets are credible, but generalizability needs further validation
