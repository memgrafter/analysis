# COCKATIEL: COntinuous Concept ranKed ATtribution with Interpretable ELements for explaining neural net classifiers on NLP tasks

## Quick Facts
- arXiv ID: 2305.06754
- Source URL: https://arxiv.org/abs/2305.06754
- Authors: [Not provided in source]
- Reference count: 24
- Key outcome: COCKATIEL is a post-hoc concept-based explainability technique for NLP models that discovers interpretable concepts through NMF, ranks their importance using Sensitivity Analysis, and generates instance-level explanations via Occlusion. Experiments show it outperforms state-of-the-art rationalization techniques on sentiment analysis tasks.

## Executive Summary
COCKATIEL is a post-hoc explainability technique designed to provide interpretable explanations for neural network classifiers on NLP tasks. The method leverages Non-Negative Matrix Factorization to discover concepts from model activations, Sensitivity Analysis to rank concept importance, and Occlusion to measure word importance for each concept. Unlike many existing approaches, COCKATIEL works as a black-box method that doesn't require model modification or access to attention mechanisms. The technique generates concept-based explanations that align with human annotations and demonstrates improved faithfulness compared to state-of-the-art rationalization methods.

## Method Summary
COCKATIEL operates through a three-stage pipeline to generate concept-based explanations for NLP classifiers. First, it applies Non-Negative Matrix Factorization to the model's last-layer activations to discover interpretable concepts without supervision. Second, it uses Total Sobol indices calculated through sensitivity analysis to rank the importance of each discovered concept for the model's predictions. Third, it employs Occlusion, a black-box attribution method, to measure the importance of individual words for each concept at the instance level. The method generates explanations by color-coding words based on their importance for each concept, providing users with both global concept importance rankings and instance-specific explanations that align with human understanding of the text.

## Key Results
- COCKATIEL discovers concepts that align with human annotations on sentiment analysis tasks (beer and IMDB datasets)
- The method provides faithful explanations to the underlying model, outperforming state-of-the-art rationalization techniques
- COCKATIEL achieves better concept alignment scores (precision, recall, F1) compared to existing post-hoc explainability methods
- The technique demonstrates improved explanation faithfulness through deletion and insertion metrics

## Why This Works (Mechanism)

### Mechanism 1
- Claim: COCKATIEL discovers model-learned concepts without supervision by factorizing the neural network's last-layer activations using Non-Negative Matrix Factorization (NMF).
- Mechanism: NMF decomposes the high-rank activation matrix A ∈ Rⁿ×ᵖ into two low-rank non-negative matrices U ∈ Rⁿ×ʳ and W ∈ Rᵖ×ʳ, where W's columns represent interpretable concepts and U contains concept activation coefficients. The non-negativity constraint encourages sparsity and interpretability.
- Core assumption: The model's last-layer activations can be meaningfully factorized into interpretable concepts, and the model's final classification function c only depends on these concepts through c(UWᵀ).

### Mechanism 2
- Claim: COCKATIEL accurately ranks concept importance using Total Sobol indices calculated through sensitivity analysis.
- Mechanism: Total Sobol indices measure the variance contribution of each concept (including interactions) to the model output. The method uses Quasi-Monte Carlo sampling with Jansen estimator to efficiently compute STᵢ = E[M~ᵢ(V_Mᵢ(Y|M~ᵢ))]/V(Y), where M are stochastic masks applied to concept coefficients.
- Core assumption: Concept importance can be measured by the variance in model output when concept coefficients are perturbed, and the Sobol decomposition provides a valid variance-based sensitivity measure.

### Mechanism 3
- Claim: COCKATIEL generates instance-level explanations by measuring word importance for each concept using Occlusion, a black-box attribution method.
- Mechanism: For each word in a sentence, Occlusion masks the word, recomputes the concept coefficients Uₖ, and measures the change φ(k,i,j) = Uₖᵢ - Ũₖᵢ₋ⱼ. This quantifies how much each word influences each concept's activation.
- Core assumption: The change in concept coefficients when masking words directly reflects the word's importance for that concept, and this black-box approach avoids the non-identifiability problems of transformer attention mechanisms.

## Architecture Onboarding

- Component map: Input processing (τ₁) -> Concept discovery (NMF) -> Concept ranking (Sobol indices) -> Instance explanation (Occlusion) -> Visualization
- Critical path: τ₁ → NMF → Sobol indices → Occlusion → Visualization
- Design tradeoffs:
  - τ₁ choice balances concept granularity vs. interpretability (full text vs. sentences vs. clauses)
  - Number of concepts l affects interpretability and computational cost
  - Occlusion granularity (words vs. clauses) impacts explanation detail level
  - Post-hoc nature trades model modification for broader applicability
- Failure signatures:
  - Poor concept alignment with human annotations indicates τ₁ or NMF parameters need adjustment
  - Low Sobol index values suggest concepts aren't actually used by the model
  - Unstable Occlusion results indicate sensitivity to input preprocessing or tokenization
- First 3 experiments:
  1. Run COCKATIEL on a simple RoBERTa model with l=5 concepts using sentence-level τ₁, verify concepts align with human annotations on the beer dataset
  2. Test different τ₁ functions (sentences vs. clauses) on the same model and compare concept interpretability and F1 scores
  3. Vary the number of concepts l from 5 to 20 and measure impact on concept alignment, model accuracy, and explanation quality
