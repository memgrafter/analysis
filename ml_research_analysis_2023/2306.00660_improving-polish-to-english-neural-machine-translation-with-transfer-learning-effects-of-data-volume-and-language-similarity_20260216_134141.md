# Improving Polish to English Neural Machine Translation with Transfer Learning: Effects of Data Volume and Language Similarity

## Quick Facts
- **arXiv ID**: 2306.00660
- **Source URL**: https://arxiv.org/abs/2306.00660
- **Reference count**: 7
- **Primary result**: More Polish data consistently improves translation quality, while related source languages (Czech) outperform unrelated ones (German) in low-resource settings, though this advantage diminishes as Polish data increases.

## Executive Summary
This study investigates transfer learning in machine translation, focusing on how data volume and language similarity affect performance when translating Polish to English. The researchers fine-tuned the mBART model using the OPus-100 dataset with different source languages (Czech, Russian, both, and German) and varying amounts of Polish data (from zero to 10,000 samples). They evaluated results using BLEU and METEOR metrics. The findings showed that more Polish data consistently improved translation quality, while the choice of source language mattered most in low-resource settings—related languages (Czech) outperformed unrelated ones (German) when little Polish data was available. However, this advantage diminished as Polish data increased, with all source languages eventually achieving similar results. This suggests that for low-resource languages, leveraging related languages is beneficial, but sufficient target language data can compensate for less related transfer sources.

## Method Summary
The researchers fine-tuned the mBART model using a parent-child configuration. First, they trained parent models on source languages (Czech, Russian, both, and German) to English using the OPus-100 dataset. Then, they fine-tuned these parent models on Polish-to-English translation with varying amounts of Polish data (0, 10, 100, 1000, and 10000 samples). The models were evaluated using BLEU and METEOR metrics to assess translation quality across different transfer learning configurations.

## Key Results
- Increasing Polish data volume consistently improved translation quality regardless of source language
- Related languages (Czech) significantly outperformed unrelated languages (German) in low-resource settings (0-100 samples)
- The advantage of related languages diminished as Polish data increased, with all source languages achieving similar performance at 10,000 samples

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Transfer learning performance improves when source languages are linguistically related to the target language, especially under low-resource conditions.
- Mechanism: Shared linguistic features (grammar, vocabulary, syntax) between related languages allow the model to transfer structural and semantic patterns effectively, reducing the need for extensive target-language data.
- Core assumption: The pre-trained mBART model captures generalizable linguistic representations that are transferable across related languages.
- Evidence anchors:
  - [abstract] "related languages can also be particularly effective when there is limited data available for a specific language pair, as the model can leverage the similarities between the languages to improve performance."
  - [section] "Relatedness between languages plays an important role in transfer learning for machine translation... Related languages share common features, such as grammatical structures and vocabulary, which can be exploited in transfer learning."
  - [corpus] Weak evidence - corpus neighbors are mostly about multilingual MT and cross-lingual transfer, but not directly supporting the specific linguistic relatedness mechanism.
- Break condition: When sufficient target language data is available, the advantage of related languages diminishes as the model can learn directly from the target language corpus.

### Mechanism 2
- Claim: Increasing the volume of target language data (Polish) consistently improves translation quality regardless of source language choice.
- Mechanism: Larger datasets enable the model to learn more patterns and generalizations from the target language, improving its ability to translate accurately and generalize to unseen data.
- Core assumption: The model benefits from exposure to more diverse examples in the target language, which outweighs the initial transfer advantage from related languages.
- Evidence anchors:
  - [abstract] "having more data generally leads to better performance, as it allows the model to learn more patterns and generalizations from the data."
  - [section] "Several studies have shown the effectiveness of increased data quantity for transfer learning in machine translation... more data provides the model with a larger and more diverse set of examples to learn from."
  - [corpus] Moderate evidence - corpus contains papers on data volume effects in MT, supporting the general principle.
- Break condition: Diminishing returns may occur when adding more data beyond a certain threshold, as noted in Koehn and Knowles (2017).

### Mechanism 3
- Claim: Using multiple related languages as transfer sources can be effective, but the advantage depends on the specific language combination and resource availability.
- Mechanism: Combining multiple related languages provides broader linguistic coverage and may capture different aspects of the language family, potentially improving transfer learning.
- Core assumption: The Slavic parent model (Czech + Russian) provides complementary linguistic information that could benefit Polish-English translation.
- Evidence anchors:
  - [section] "it has been shown that using multiple languages as the transfer source can lead to higher performance... both Maimati et al. (Maimaiti et al., 2019) and Chen et al. (Chen et al., 2019) showed that multi-source cross-lingual transfer can be very effective for machine translation."
  - [section] "The Slavic model is fine-tuned with twice the amount of data compared to other models as it uses both Czech and Russian data. Despite this, the performance is lower than using only Czech on zero-shot and few-shot cases..."
  - [corpus] Weak evidence - corpus neighbors don't directly address multi-source transfer effectiveness.
- Break condition: The effectiveness may be reduced if the additional languages introduce conflicting linguistic patterns or if the combined data dilutes the most relevant features for the target language.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the effectiveness of multiple transfer source languages depend on language family clustering, or can any combination of languages improve performance?
- Basis in paper: [inferred] The paper found that the Slavic parent model (Czech + Russian) underperformed compared to single-language models, contrary to expectations that more source data would help.
- Why unresolved: The paper only tested one combination of related languages (Slavic) versus single languages, leaving open whether clustering by language family matters or if the combination itself was problematic.
- What evidence would resolve it: Experiments testing multiple combinations of related vs. unrelated languages (e.g., Germanic, Romance, Turkic clusters) to determine if language family grouping affects transfer learning performance.

### Open Question 2
- Question: What is the minimum threshold of target language data where language similarity becomes irrelevant for transfer learning?
- Basis in paper: [explicit] The paper observed that as Polish data increased, the advantage of using Czech (related language) diminished, with all source languages eventually achieving similar results.
- Why unresolved: The paper only tested up to 10,000 Polish samples, leaving unclear at what point language similarity stops mattering and whether this threshold varies by language pair.
- What evidence would resolve it: Systematic testing with progressively larger Polish datasets (e.g., 50k, 100k, 1M samples) to identify the inflection point where language relatedness no longer impacts performance.

### Open Question 3
- Question: How do zero-shot and few-shot transfer learning results generalize across different language families and data domains?
- Basis in paper: [explicit] The paper found related languages were important in zero-shot and few-shot settings but only tested Polish-English with Slavic/Central European languages.
- Why unresolved: The study's limited scope to one language pair and dataset prevents conclusions about generalizability across typologically diverse languages and different domains (e.g., legal, medical, conversational).
- What evidence would resolve it: Replication studies across diverse language pairs (e.g., Japanese-English, Arabic-English, Swahili-English) and multiple domains to test if the relatedness effect holds universally.

## Limitations

- The study is limited to Polish-English translation and may not generalize to other language pairs or families.
- The investigation of multi-source transfer (Slavic parent model) showed unexpected results, but the reasons for this are not fully explored.
- The study uses a specific experimental setup with the mBART model and OPUS-100 dataset, which may not represent all possible configurations or datasets.

## Confidence

- **High Confidence**: Increasing Polish data volume consistently improves translation quality
- **Medium Confidence**: Related languages outperform unrelated languages in low-resource settings
- **Medium Confidence**: The advantage of related languages diminishes with sufficient Polish data
