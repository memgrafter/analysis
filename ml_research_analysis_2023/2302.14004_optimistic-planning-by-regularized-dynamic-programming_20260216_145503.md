# Optimistic Planning by Regularized Dynamic Programming

## Quick Facts
- arXiv ID: 2302.14004
- Source URL: https://arxiv.org/abs/2302.14004
- Reference count: 40
- Primary result: Achieves O(sqrt((d^2 H^3 + B^2 d H + H^4 log |A|) T)) regret bound for discounted linear kernel MDPs

## Executive Summary
This paper introduces a regularized dynamic programming approach for optimistic planning in infinite-horizon discounted Markov decision processes. The key innovation is incorporating regularization into Bellman updates, which enables the use of approximate transition functions estimated via least-squares procedures. This approach bypasses traditional requirements for contraction and monotonicity arguments in approximate dynamic programming. The algorithm is specifically designed for discounted linear kernel MDPs and achieves near-optimal statistical guarantees while maintaining computational efficiency.

## Method Summary
The method employs regularized dynamic programming by modifying Bellman updates with regularization terms, allowing the use of approximate transition functions estimated through least-squares procedures. This regularization enables optimistic planning in MDPs with linear function approximation without requiring contraction and monotonicity arguments. The algorithm is applied to discounted linear kernel MDPs, where it produces near-optimal statistical guarantees through this novel approach to dynamic programming.

## Key Results
- Achieves O(sqrt((d^2 H^3 + B^2 d H + H^4 log |A|) T)) expected regret bound
- Produces ε-optimal policy after approximately (B^2 d H + d^2 H^3 + H^4 log |A|)/ε^2 iterations
- Each policy update takes polynomial time in d, H, and T
- Avoids traditional contraction and monotonicity requirements in approximate dynamic programming

## Why This Works (Mechanism)
The regularization incorporated into Bellman updates stabilizes the dynamic programming process when using approximate transition functions. This allows the algorithm to maintain optimistic planning properties without requiring the strict mathematical conditions (contraction and monotonicity) typically needed in approximate dynamic programming. The least-squares estimation of transition functions provides sufficient accuracy for the regularized updates to converge to near-optimal policies.

## Limitations
- Restrictive assumptions of linear kernel MDPs limit generalizability
- Scalability concerns due to dependence on feature dimension d and effective horizon H
- Analysis focuses on expected regret without addressing variance or high-probability guarantees
- Least-squares estimation requirements may not hold in non-linear or high-dimensional settings
