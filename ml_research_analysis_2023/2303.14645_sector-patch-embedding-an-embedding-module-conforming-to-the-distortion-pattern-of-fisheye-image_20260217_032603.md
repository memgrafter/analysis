# Sector Patch Embedding: An Embedding Module Conforming to The Distortion Pattern of Fisheye Image

## Quick Facts
- arXiv ID: 2303.14645
- Source URL: https://arxiv.org/abs/2303.14645
- Reference count: 31
- Key outcome: SPE improves ViT and PVT classification accuracy by 0.75% and 2.8% on synthetic fisheye dataset

## Executive Summary
This paper addresses the challenge of image distortion in fisheye images for vision tasks by proposing a novel patch embedding method called Sector Patch Embedding (SPE). The method is designed to conform to the radial distortion pattern of fisheye images by using sector-shaped patches instead of traditional square patches. The authors also introduce a synthetic fisheye dataset based on ImageNet-1K and demonstrate that SPE improves classification performance on this dataset. The method can be easily integrated into existing Transformer-based models and shows better perception of distortion and feature extraction on fisheye images.

## Method Summary
The proposed method involves generating synthetic fisheye images from ImageNet-1K using coordinate transformation with parameters k and n, followed by circular sampling to remove invalid corner pixels. Sector Patch Embedding (SPE) creates sector-shaped patches that maintain constant area per patch to reduce distortion-induced aliasing. A polar position embedding scheme is used to encode angular and radial position information compatible with the SPE patches. The method is evaluated on Transformer models (ViT and PVT) with AdamW optimizer, batch size 64, 100 epochs, and cosine learning rate schedule.

## Key Results
- SPE improves ViT classification top-1 accuracy by 0.75% on synthetic fisheye dataset
- SPE improves PVT classification top-1 accuracy by 2.8% on synthetic fisheye dataset
- Adding polar position embedding to SPE further increases accuracy by 0.52%

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sector Patch Embedding improves classification accuracy by aligning patch geometry with fisheye distortion patterns
- Mechanism: SPE uses sector-shaped patches whose angular span compensates for increasing pixel density with radius, maintaining constant area per patch and reducing distortion-induced aliasing
- Core assumption: Fisheye distortion follows a predictable radial pattern that can be modeled with polar coordinates
- Evidence anchors: [abstract] "The classification top-1 accuracy of ViT and PVT is improved by 0.75% and 2.8% with SPE respectively" [section] "We propose a sampling method with a well-designed patch called Sector Patch Embedding (SPE). SPE is more suitable for the distortion pattern of fisheye images..."

### Mechanism 2
- Claim: Polar position embedding enhances semantic feature extraction by encoding angular and radial position information compatible with SPE patches
- Mechanism: Standard absolute position encoding treats pixels uniformly, ignoring distortion. Polar embedding assigns unique positional codes based on (r,θ) coordinates, so patches at same radius but different angles get similar radial modulation but distinct angular cues, preserving symmetry and distortion-aware context
- Core assumption: Positional encoding must match the sampling geometry to be effective
- Evidence anchors: [section] "Since the sampled points on the fisheye image are represented by polar coordinates, we have designed a polar coordinate position encoding method" [abstract] "If we add polar position embedding to SPVT, the accuracy can increase by 0.52"

### Mechanism 3
- Claim: Removing boundary pixels via circular sampling reduces noise and computational waste, improving model focus on informative regions
- Mechanism: Fisheye images have invalid pixels at the corners due to circular lens projection. Circular sampling excludes these, so downstream transformers process only valid data, reducing input sequence length and eliminating boundary artifacts that could mislead attention mechanisms
- Core assumption: Invalid pixels at image boundaries contribute no useful semantic information
- Evidence anchors: [section] "Compared to the original patch method, it can naturally filter out invalid pixels around the fisheye image" [abstract] "SPE can be easily adopted to other Transformer-based models"

## Architecture Onboarding

- Component map: Fisheye image → Circular sampling → Sector patch generation (CUDA) → Reshape to sequence → Polar position encoding → Transformer encoder → MLP → Prediction
- Critical path: Image → Circular sampling → Sector patches → Positional encoding → Transformer encoder → MLP → Prediction
- Design tradeoffs:
  - Fixed sector angles simplify patch generation but may not adapt to varying distortion strengths
  - CUDA acceleration speeds training but adds deployment complexity
  - Polar encoding preserves symmetry but may underperform on non-radially symmetric scenes
- Failure signatures:
  - Accuracy plateau: Check if invalid pixels still leak into patches
  - Training instability: Verify polar encoding scaling factors
  - GPU memory spikes: Inspect CUDA kernel launch parameters
- First 3 experiments:
  1. Ablation: Replace SPE with square patches on synthetic fisheye dataset; measure accuracy drop
  2. Encoding swap: Use standard sinusoidal positional encoding instead of polar; compare top-1 accuracy
  3. Distortion variation: Generate fisheye images with different k and n parameters; evaluate robustness of SPE across distortion strengths

## Limitations

- CUDA-based implementation adds deployment complexity and may limit adoption in resource-constrained environments
