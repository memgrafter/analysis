# Brain-Inspired Spiking Neural Network for Online Unsupervised Time Series Prediction

## Quick Facts
- **arXiv ID:** 2304.04697
- **Source URL:** https://arxiv.org/abs/2304.04697
- **Reference count:** 31
- **Primary result:** Unsupervised RSNN with topological loss outperforms supervised DNNs in online time series prediction, especially with limited data

## Executive Summary
This paper introduces an unsupervised recurrent spiking neural network (RSNN) for online time series prediction in evolving dynamical systems. The approach uses spike-timing-dependent plasticity (STDP) to continuously adapt to streaming data without supervision. By reconstructing the underlying dynamical system through random delay embedding and selecting neurons with highest betweenness centrality for prediction, the method achieves superior performance compared to supervised deep neural networks, particularly when data is limited or the system evolves over time.

## Method Summary
The proposed method employs an unsupervised recurrent spiking neural network that adapts to streaming time series data through STDP learning rules. The system first reconstructs the underlying dynamical system using random delay embedding, then samples neurons with highest betweenness centrality for prediction. A novel topological data analysis approach using Wasserstein distance between persistence homologies serves as the loss function for reconstruction. This allows the network to learn meaningful representations of the system's state space without requiring labeled training data.

## Key Results
- RSNN-based models (RMSE-CLURSNN and Wass-CLURSNN) outperform supervised DNN models for online prediction tasks
- Wass-CLURSNN converges faster and adapts better to evolving systems compared to online DNNs
- Superior performance especially notable when data is limited
- With repeated training data, DNNs eventually catch up to RSNN performance

## Why This Works (Mechanism)
The unsupervised RSNN approach works effectively because it learns the intrinsic structure of the dynamical system through topological features rather than requiring explicit target labels. The combination of STDP for adaptive learning, random delay embedding for state space reconstruction, and betweenness centrality for neuron selection creates a robust framework that captures the essential dynamics of evolving systems. The topological loss function based on Wasserstein distance between persistence homologies provides a meaningful similarity measure that aligns with the underlying system's structure.

## Foundational Learning

**Spiking Neural Networks (SNNs)**: Biological-plausible neural networks that communicate via discrete spikes rather than continuous values
- *Why needed*: Enable energy-efficient computation and temporal processing
- *Quick check*: Can model temporal dependencies in time series data

**Spike-Timing-Dependent Plasticity (STDP)**: Learning rule where synaptic strength changes based on relative timing of pre- and post-synaptic spikes
- *Why needed*: Provides unsupervised learning mechanism for adapting to streaming data
- *Quick check*: Can strengthen connections that capture temporal patterns

**Random Delay Embedding**: Technique for reconstructing state space from time series observations
- *Why needed*: Enables reconstruction of underlying dynamical system from scalar observations
- *Quick check*: Can capture system dynamics from single variable observations

**Betweenness Centrality**: Graph theory measure of node importance based on shortest path calculations
- *Why needed*: Identifies neurons that best represent system state
- *Quick check*: High centrality nodes capture information flow

**Topological Data Analysis (TDA)**: Mathematical framework for studying shape and connectivity of data
- *Why needed*: Provides robust similarity measures invariant to coordinate transformations
- *Quick check*: Can capture system topology independent of specific observation scale

**Wasserstein Distance**: Metric for comparing probability distributions
- *Why needed*: Quantifies similarity between persistence homologies for loss calculation
- *Quick check*: Provides differentiable measure for optimization

## Architecture Onboarding

**Component Map**: Raw time series -> Random Delay Embedding -> RSNN with STDP -> Betweenness Centrality Sampling -> Prediction

**Critical Path**: The essential sequence is embedding the time series, propagating through the RSNN with STDP learning, selecting high-centrality neurons, and generating predictions. The topological loss calculation runs in parallel but influences the STDP updates.

**Design Tradeoffs**: The method sacrifices the ability to learn complex nonlinear mappings that supervised DNNs can achieve in exchange for online adaptation without supervision. Random delay embedding parameters must be carefully chosen, and the computational cost of topological analysis is higher than standard loss functions.

**Failure Signatures**: Poor reconstruction of the underlying dynamical system will manifest as degraded prediction accuracy. If the betweenness centrality selection fails to identify meaningful neurons, the prediction quality will suffer. Excessive noise in the time series can overwhelm the topological analysis.

## Limitations
- Experimental validation limited to relatively simple synthetic systems (Lorenz63) and three real-world datasets
- Claims of superior online adaptation speed based on limited iterations may not hold for longer prediction horizons
- Comparison with supervised DNNs may not fully capture scenarios where supervised models with online learning could perform competitively

## Confidence
- **High**: Core methodological contribution of combining STDP with topological loss functions for unsupervised RSNN training
- **Medium**: Performance superiority claims over DNN baselines, particularly regarding online adaptation speed
- **Low**: Generalization of results to high-dimensional, noisy real-world systems beyond the tested datasets

## Next Checks
1. Test the proposed method on higher-dimensional chaotic systems (e.g., Lorenz96 or coupled oscillators) to evaluate scalability
2. Implement online learning variants of the DNN baselines (e.g., continual learning with experience replay) for fairer comparison
3. Conduct ablation studies isolating the contributions of random delay embedding versus betweenness centrality sampling versus topological loss functions
