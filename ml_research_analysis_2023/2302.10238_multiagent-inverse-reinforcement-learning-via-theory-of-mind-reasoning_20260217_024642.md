# Multiagent Inverse Reinforcement Learning via Theory of Mind Reasoning

## Quick Facts
- arXiv ID: 2302.10238
- Source URL: https://arxiv.org/abs/2302.10238
- Reference count: 31
- One-line primary result: MIRL-ToM recovers rewards used by agents interacting with both known and unknown teammates in a 2-player search-and-rescue task

## Executive Summary
This paper addresses the challenge of inferring individual reward functions in multiagent teams where agents have limited knowledge of their teammates' goals. The proposed approach combines theory of mind (ToM) reasoning with decentralized inverse reinforcement learning (IRL) to estimate reward functions from demonstrated team behavior. The method operates in two phases: first using ToM to estimate posterior distributions over baseline reward profiles, then performing decentralized MIRL via single-agent Maximum Entropy IRL conditioned on these beliefs. The approach is evaluated in a simulated 2-player search-and-rescue scenario and shows that MIRL-ToM can recover ground-truth rewards when interacting with both known and unknown teammates.

## Method Summary
The approach uses a two-phase method for multiagent inverse reinforcement learning. First, ToM reasoning estimates a posterior distribution over baseline reward profiles for each agent based on observed teammate behavior using Bayesian inference. Second, decentralized MIRL is performed where each agent uses single-agent Maximum Entropy IRL to infer its reward function while simulating teammates' behavior according to the time-varying belief distribution over profiles. This enables decentralized equilibrium computation without requiring centralized learning or prior knowledge of exact teammate reward functions.

## Key Results
- MIRL-ToM successfully recovers ground-truth rewards in a 2-player search-and-rescue task
- Choice of baseline profiles is crucial for reward recovery performance
- The method works with both known teammates (using profiles in the baseline set) and unknown teammates (using profiles outside the baseline set)
- Performance degrades gracefully when agents have imperfect models of their teammates

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ToM reasoning over baseline profiles enables decentralized MIRL without requiring a centralized learner or prior knowledge of teammates' exact reward functions.
- Mechanism: Each agent maintains and updates a belief distribution over a set of predefined baseline profiles based on observed teammate behavior. This belief is used during MaxEnt IRL to simulate teammate actions according to the current posterior, enabling decentralized equilibrium computation.
- Core assumption: Baseline profiles exist that sufficiently capture the space of possible teammate strategies; behavior can be distinguished among these profiles.
- Evidence anchors:
  - [abstract] "we first use ToM reasoning to estimate a posterior distribution over baseline reward profiles given the demonstrated behavior of each agent"
  - [section 4.1] "For each step of each trajectory, b_k(m) is updated via Bayesian inference"
- Break condition: If baseline profiles are too coarse or the true teammate reward function lies outside the profile set, belief updates cannot converge to the true model, leading to poor reward recovery.

### Mechanism 2
- Claim: Model inference via ToM provides sufficient information to enable accurate MaxEnt IRL reward recovery in the decentralized phase.
- Mechanism: By inferring a time-varying belief over teammate models, the algorithm conditions the simulation of teammate behavior in MaxEnt IRL on the perceived model distribution, thus approximating best-response strategies without centralized equilibrium solving.
- Core assumption: The belief update process correctly identifies which baseline profile best explains observed teammate behavior.
- Evidence anchors:
  - [section 4.2] "we perform MIRL via decentralized equilibrium by employing single-agent Maximum Entropy IRL to infer a reward function for each agent, where we simulate the behavior of other teammates according to the time-varying distribution over profiles"
  - [section 5.4] "our method can achieve very similar behavior (highlighted in bold), which denotes the importance of the model inference phase"
- Break condition: If observed behavior is ambiguous or noisy such that belief updates oscillate between multiple profiles, IRL estimation becomes unstable.

### Mechanism 3
- Claim: Decentralized MIRL via ToM reasoning generalizes to unknown teammates by adapting beliefs during task execution.
- Mechanism: Even when agents start with uniform priors over profiles, Bayesian updates during task execution allow the algorithm to discover the true teammate models and adjust reward inference accordingly, enabling recovery of rewards used by agents interacting with both known and unknown teammates.
- Core assumption: Teammate behavior provides sufficient signal for Bayesian inference to distinguish between profiles.
- Evidence anchors:
  - [abstract] "that MIRL-ToM is able to recover the rewards used by agents interacting with both known and unknown teammates"
  - [section 5.5] "even in the case where the demonstrations are generated by agents that have imperfect models of their teammates, our approach can recover similar behavior"
- Break condition: If teammates' behavior is too similar across profiles or the task provides limited interaction opportunities, belief updates may not converge, preventing reward recovery.

## Foundational Learning

- Concept: Maximum Entropy IRL
  - Why needed here: Provides a probabilistic framework to infer reward functions that best explain demonstrated behavior while avoiding overfitting to specific trajectories.
  - Quick check question: What principle does MaxEnt IRL use to resolve the ill-posed nature of IRL where multiple reward functions can explain the same behavior?

- Concept: Bayesian inference for belief updating
  - Why needed here: Enables agents to update their beliefs about teammates' reward functions as they observe behavior, capturing the dynamic nature of interactions.
  - Quick check question: How does the belief update equation in Section 4.1 incorporate both prior beliefs and observed actions to compute the posterior over profiles?

- Concept: Decentralized equilibrium computation
  - Why needed here: Allows each agent to independently compute its reward function by treating others' behavior as conditional on inferred beliefs, avoiding the need for centralized computation.
  - Quick check question: What role does the time-varying distribution over profiles play in the decentralized MIRL computation described in Section 4.2?

## Architecture Onboarding

- Component map:
  - Environment simulator (PsychSim) for generating and testing trajectories
  - Model inference module implementing Bayesian ToM updates
  - Decentralized IRL engine using MaxEnt IRL with belief-conditioned teammate simulation
  - Baseline profile library defining possible teammate reward functions
  - Evaluation pipeline comparing learned rewards to ground truth

- Critical path:
  1. Collect team trajectories with observed teammate behavior
  2. Perform model inference to compute belief distributions over profiles
  3. Run decentralized MaxEnt IRL for each agent using belief-conditioned teammate simulation
  4. Evaluate learned rewards against ground truth using feature count and policy divergence metrics

- Design tradeoffs:
  - More baseline profiles increase coverage but add computational cost and risk overfitting
  - Belief update frequency affects responsiveness to changing teammate strategies
  - Choice between uniform vs. informative priors impacts initial convergence

- Failure signatures:
  - Reward weights oscillating during IRL training (suggests contradictory models)
  - Belief distributions remaining uniform across all profiles (suggests insufficient behavioral signal)
  - High feature count differences between learned and demonstrated behavior (suggests poor reward recovery)

- First 3 experiments:
  1. Test model inference with known teammate profiles to verify belief convergence
  2. Compare reward recovery using different baseline profile sets (including vs. excluding ground truth)
  3. Evaluate performance with agents having opposite goals to test robustness to model errors

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the choice of baseline profiles affect the recovery of ground-truth rewards in MIRL-ToM?
- Basis in paper: [explicit] The paper states that "the choice of baseline profiles is paramount to the recovery of the ground-truth rewards" and shows experimental results with different profile sets (Gt, Op, Rd, Tk, Sc).
- Why unresolved: The paper provides empirical evidence that different profile sets lead to different recovery performance, but does not establish a theoretical framework for predicting which profile sets will work best for a given task.
- What evidence would resolve it: A comprehensive analysis of how profile characteristics (e.g., similarity to ground-truth, diversity of goals) correlate with recovery performance across multiple tasks and team sizes.

### Open Question 2
- Question: Can MIRL-ToM scale to larger teams with more than two agents?
- Basis in paper: [explicit] The paper mentions that "our framework can be applied to n-player, general-sum problems" but only evaluates on a 2-player scenario.
- Why unresolved: The computational complexity of model inference and decentralized MIRL may increase significantly with team size, and the effectiveness of ToM reasoning in larger groups is unknown.
- What evidence would resolve it: Experimental results showing successful recovery of rewards in teams of 3+ agents, along with analysis of computational scaling and model inference accuracy.

### Open Question 3
- Question: How robust is MIRL-ToM to noise in demonstrations and stochastic team dynamics?
- Basis in paper: [inferred] The paper mentions that "the assumptions formed by each individual regarding the teammates' goals and intentions... might be incorrect due to the noisy nature of human behavior" but does not test this scenario.
- Why unresolved: The current evaluation uses deterministic transitions and noise-free demonstrations from synthetic agents, which may not reflect real-world conditions.
- What evidence would resolve it: Experiments with noisy demonstrations and stochastic dynamics showing how recovery performance degrades and what noise thresholds the method can tolerate.

## Limitations
- The approach depends critically on the quality and coverage of the predefined baseline profile set
- Assumes perfect observation of teammate actions during execution, which may not hold in real-world scenarios
- Limited empirical validation to 2-agent teams in a controlled simulation environment

## Confidence
- **High confidence**: The theoretical framework combining ToM reasoning with decentralized MaxEnt IRL is sound and well-grounded in established reinforcement learning principles
- **Medium confidence**: The empirical validation shows promising results in the specific search-and-rescue scenario, but the limited scope (2 agents, 16 trajectories) and controlled simulation environment constrain generalizability
- **Medium confidence**: The claim that the method works with both known and unknown teammates is supported by the experiments, but the definition of "unknown" appears limited to agents using profiles within the predefined set rather than truly novel reward structures

## Next Checks
1. **Profile space coverage test**: Systematically evaluate reward recovery performance as a function of baseline profile set size and diversity, including cases where ground truth is excluded from the profile library
2. **Noise robustness evaluation**: Introduce observation noise and partial observability in teammate actions to assess how belief updates degrade and whether reward recovery remains accurate
3. **Scalability validation**: Extend experiments beyond 2 agents to test whether the decentralized approach maintains computational efficiency and learning quality as team size increases
