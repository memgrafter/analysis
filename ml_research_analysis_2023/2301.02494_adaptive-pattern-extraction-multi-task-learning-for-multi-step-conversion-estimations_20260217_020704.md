# Adaptive Pattern Extraction Multi-Task Learning for Multi-Step Conversion Estimations

## Quick Facts
- arXiv ID: 2301.02494
- Source URL: https://arxiv.org/abs/2301.02494
- Reference count: 30
- Key outcome: TAFE achieves 1.29% and 1.43% AUC gains on CTR and CVR tasks respectively in multi-step conversion estimation

## Executive Summary
This paper introduces the Task Aware Feature Extraction (TAFE) framework for sequential dependence multi-task learning in recommendation systems. The core innovation is selectively extracting task-specific features while learning shared representations across tasks. TAFE employs an Adaptive Sample-wise Representation Generator (ASRG) that uses dynamic activation layers and inducing points to learn hierarchical feature interactions, combined with a Task-Specific Adapter (TSA) that extracts explicit task-aware information using task indicator vectors. The framework also incorporates a sequence dependence learning loss to optimize the relationship between dependent tasks.

## Method Summary
TAFE is a multi-task learning framework designed for sequential conversion estimation tasks in recommendation systems. It consists of two main modules: the Adaptive Sample-wise Representation Generator (ASRG) that learns hierarchical feature interactions using a dynamic activation layer and inducing points, and the Task-Specific Adapter (TSA) that extracts explicit task-aware information using task indicator vectors. The framework also includes a sequence dependence learning loss that optimizes the relationship between dependent tasks. The model processes input features through the ASRG to create shared representations, then uses TSA to generate task-specific embeddings, and finally produces predictions through task-specific towers.

## Key Results
- TAFE outperforms state-of-the-art MTL methods by 1.29% and 1.43% AUC gains on CTR and CVR tasks respectively
- Online A/B test demonstrates a 9.22% CVR improvement in real-world applications
- Experiments show effective performance on both public and industrial datasets with millions of samples

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The dynamic selector layer in ASRG effectively separates task-irrelevant information by learning sample-specific interaction patterns.
- Mechanism: The dynamic activation function $f_D$ acts as a sparse mask over feature field interactions, where each sample's mask is learned through a transformation layer and updated during training. This allows selective engagement of inducing points based on sample characteristics.
- Core assumption: The sample-wise variation in feature importance is sufficient to distinguish task-relevant from task-irrelevant information.
- Evidence anchors:
  - [abstract]: "ASRG employs a dynamic selection mechanism to learn the hierarchical feature interaction from a sample-wise view to further separates the task-irrelevant information."
  - [section]: "Dynamic selector works as a information filter which selectively interacts with input from the sample-wise view due to the Transformation Layer."
- Break condition: When feature field interactions are too uniform across samples, making sample-wise selection ineffective.

### Mechanism 2
- Claim: The task indicator vectors in TSA enable explicit task-specific representation learning while maintaining separation from shared features.
- Mechanism: Each task indicator vector $\alpha_i$ interacts with the shared ASRG output through attention, allowing task-specific feature extraction without cross-task interference. The residual structure preserves information flow.
- Core assumption: Task-specific information can be effectively extracted through learned attention patterns between task indicators and shared features.
- Evidence anchors:
  - [abstract]: "explicit Pattern Selector is introduced to further enable selectively feature representation learning by adaptive task-indicator vectors."
  - [section]: "TSA utilizes parameterized task indicator vector to interact with previous sample-wise common shared info from ASRG, which is able to extract task-specific representation by directly optimizing respective task object."
- Break condition: When tasks have highly overlapping feature importance patterns, making task indicators redundant.

### Mechanism 3
- Claim: The sequence dependence learning loss provides unbiased optimization by correcting distribution shift between training and inference spaces.
- Mechanism: The loss function $L_{D-Task}$ accounts for the probability relationship between adjacent tasks, effectively weighting samples to compensate for the selection bias in local training spaces.
- Core assumption: The theoretical relationship between expected losses in reference and local spaces holds for the specific task dependencies in the problem.
- Evidence anchors:
  - [abstract]: "we design a dependence task learning loss to provide an unbiased optimizing object."
  - [section]: "Theorem 3.1 provides the theoretical relationship between expected losses in reference and local spaces, showing that L_{D-Task} can correct the bias."
- Break condition: When the sequential dependence relationship is weak or non-existent between tasks.

## Architecture Onboarding

- Component map:
  Input -> ASRG -> TSA -> Task tower -> Prediction

- Critical path: Input → ASRG → TSA → Task tower → Prediction
  The critical path for each task is the flow from input through ASRG and TSA to the task-specific tower.

- Design tradeoffs:
  - ASRG uses inducing points to reduce attention complexity from O(F²) to O(K×F), trading some expressiveness for efficiency
  - TSA uses separate task indicator vectors for explicit task-specific learning, increasing parameter count but improving separation
  - The sequence dependence loss adds computational overhead but provides unbiased optimization

- Failure signatures:
  - Poor performance on both tasks: Check if ASRG is effectively learning shared representations
  - Good performance on one task, poor on another: Check TSA task indicator vectors and task tower separation
  - Unstable training: Check sequence dependence loss weighting and its impact on gradients

- First 3 experiments:
  1. Train with ASRG only (no TSA, no sequence loss) to verify shared representation learning
  2. Train with TSA only (no ASRG, no sequence loss) to verify task-specific learning
  3. Train with both ASRG and TSA but no sequence loss to verify combined effect before adding complexity

## Limitations
- The dynamic activation function's effectiveness is largely theoretical with limited empirical validation
- Task indicator vectors may suffer from overfitting in high-dimensional feature spaces
- The sequence dependence learning loss assumes strong sequential relationships between tasks, which may not hold in all recommendation scenarios

## Confidence
- Mechanism 1 (ASRG dynamic selection): Medium confidence - The theoretical framework is sound, but empirical evidence for effective task-irrelevant information separation is limited
- Mechanism 2 (TSA task indicators): Medium confidence - While the attention-based approach is well-established, the specific formulation lacks detailed ablation analysis
- Mechanism 3 (Sequence dependence loss): Low confidence - The theoretical relationship is mathematically derived, but practical effectiveness depends heavily on the strength of sequential dependence
