# Adaptive Domain Generalization for Digital Pathology Images

## Quick Facts
- arXiv ID: 2305.05100
- Source URL: https://arxiv.org/abs/2305.05100
- Reference count: 0
- Primary result: Test Time Training with self-supervised tasks (RSP, SimCLR) failed to improve domain generalization in histopathology images

## Executive Summary
This thesis investigates Test Time Training (TTT) for improving domain generalization in histopathology images. TTT aims to adapt model parameters at test-time using secondary self-supervised tasks to improve robustness to domain shifts like stain and scanner variations. Experiments with two secondary tasks (RSP and SimCLR) show that TTT does not improve performance on shifted test data. The SimCLR task caused instability during test-time adaptation, with model performance degrading as adaptation step size increased. The RSP task showed tension between primary and secondary tasks during joint training.

## Method Summary
The method involves joint training of a model with primary classification task and secondary self-supervised task (either RSP or SimCLR), followed by test-time optimization of the secondary task on test batches. The model uses a shared encoder architecture with separate task heads. During test-time, only the encoder and secondary task head are optimized using the secondary loss, while the primary task head remains frozen. The approach was tested on prostate biopsy whole slide images with domain shifts from scanner variations and synthetic noise.

## Key Results
- TTT with SimCLR task caused instability during test-time adaptation, with performance degrading as step size increased
- RSP task showed tension between primary and secondary tasks during joint training
- Neither secondary task improved performance on shifted test data
- Unrestricted parameter updates at test-time may overfit to secondary task and destroy learned representations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Test Time Training (TTT) adapts model parameters at inference to reduce domain shift effects in histopathology.
- Mechanism: TTT uses a secondary self-supervised task (e.g., SimCLR or RSP) to optimize shared encoder parameters on test batches, aiming to align feature distributions between source and target domains.
- Core assumption: The secondary task provides a useful optimization signal that correlates with improving primary task performance under domain shift.
- Evidence anchors:
  - [abstract] "TTT aims to adapt model parameters at test-time using a secondary self-supervised task to improve robustness to domain shifts like stain and scanner variations."
  - [section] "TTT is a feature alignment-based approach to domain generalization that is reactive to domain shifts and requires only one domain for training."
- Break condition: If secondary task optimization does not correlate with primary task performance, or if weight updates drift too far from original encoder parameters, adaptation fails.

### Mechanism 2
- Claim: Joint training of primary and secondary tasks improves robustness compared to vanilla training.
- Mechanism: During training, the model jointly optimizes both primary (supervised) and secondary (self-supervised) losses, encouraging shared representations that generalize across domains.
- Core assumption: The secondary task provides regularization that improves generalization to unseen domains.
- Evidence anchors:
  - [abstract] "Experiments with two secondary tasks (RSP and SimCLR) show that TTT does not improve performance on shifted test data."
  - [section] "Without this step, there may be some low-hanging fruit for secondary task optimization during test-time, leading to undesirable and unpredictable gradients."
- Break condition: If the secondary task dominates training (e.g., λs too high), the primary task performance degrades.

### Mechanism 3
- Claim: Self-supervised tasks like SimCLR can create domain-invariant representations through contrastive learning.
- Mechanism: SimCLR generates positive pairs via augmentations and pulls their representations together while pushing apart negative pairs, encouraging invariant features.
- Core assumption: Contrastive learning on diverse augmentations captures domain-agnostic features useful for adaptation.
- Evidence anchors:
  - [section] "SimCLR contrastive task... uses simple image augmentations on a set of inputs, creating two augmented views of each image."
  - [section] "Using data augmentations to supplement training data in the normal training paradigm can be helpful, but augmentations have also found use in contrastive self-supervised learning."
- Break condition: If augmentations do not reflect real domain shifts, contrastive learning may not align with domain adaptation needs.

## Architecture Onboarding

- Component map:
  - Input images -> Shared encoder (512-dimensional latent space) -> Primary task head (Normal, Stroma, Cancer classification) and Secondary task head (RSP: 6 classes or SimCLR contrastive embedding)

- Critical path:
  1. Train model jointly on primary and secondary tasks
  2. At test time, optimize only encoder and secondary head on test batch using secondary loss
  3. Use updated encoder to make primary task predictions

- Design tradeoffs:
  - Higher λs improves secondary task performance but risks degrading primary task
  - More test samples reduce adaptation variance but increase latency
  - Constraining encoder updates improves stability but may limit adaptation strength

- Failure signatures:
  - Primary task loss increases during test-time adaptation
  - Secondary task loss plateaus early during training (indicating task is too easy)
  - No performance difference between adaptation step sizes

- First 3 experiments:
  1. Joint train with RSP task, sweep λs, monitor primary/secondary validation losses
  2. Joint train with SimCLR task, sweep λs, monitor primary/secondary validation losses
  3. Apply TTT with SimCLR model on scanner-shifted test set, vary step size, measure primary task performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Would constraining parameter updates during test-time training improve domain generalization performance in histopathology?
- Basis in paper: [explicit] The paper mentions that future work should investigate constraining parameter updates or exploring other domain generalization approaches, noting that modifying all parameters may be overfitting to the secondary task and destroying meaningful representations learned during joint training.
- Why unresolved: The experiments showed that unrestricted optimization of the secondary task at test time degraded primary task performance, but the paper didn't test specific constraints on parameter updates.
- What evidence would resolve it: Running experiments with constrained parameter updates (e.g., weight decay, limited parameter subsets, or gradient clipping) and comparing performance against unconstrained test-time training.

### Open Question 2
- Question: Are there self-supervised tasks more suitable than SimCLR and RSP for test-time training in histopathology domain generalization?
- Basis in paper: [explicit] The paper tested two secondary tasks (RSP and SimCLR) that were selected from self-supervised pretraining literature, but both showed tension between primary and secondary tasks during joint training, and neither improved performance during test-time adaptation.
- Why unresolved: The paper only tested two specific self-supervised tasks and concluded they weren't suitable, but didn't explore the broader space of potential tasks or task design principles.
- What evidence would resolve it: Testing multiple different self-supervised tasks (e.g., rotation prediction, jigsaw puzzles, contrastive tasks with different augmentations) and analyzing which task properties correlate with successful test-time training.

### Open Question 3
- Question: How can we measure or predict when domain shifts are too complex for test-time training to be effective?
- Basis in paper: [inferred] The experiments showed that test-time training failed on both a natural scanner domain shift and a synthetic noise domain shift, suggesting the technique may have fundamental limitations that weren't predicted by the paper's theoretical framework.
- Why unresolved: The paper demonstrated failure cases but didn't develop a framework for understanding the characteristics of domain shifts that make test-time training ineffective.
- What evidence would resolve it: Developing metrics to quantify domain shift complexity (e.g., feature distribution divergence, task correlation changes) and correlating these with test-time training performance across multiple domain shift types.

## Limitations

- The study relies on a proprietary model architecture without full specification of encoder design and primary task head configurations
- Secondary task optimization during test-time caused instability and degraded primary task performance
- Results are based on a specific dataset (prostate biopsy WSIs) and may not generalize to other histopathology tasks

## Confidence

- Primary Claim Cluster (TTT Effectiveness): Low confidence - TTT with both RSP and SimCLR tasks failed to improve performance on shifted test data
- Mechanism Understanding: Medium confidence - The study identifies task instability and tension issues but lacks detailed analysis of why these occur
- Future Direction Validity: High confidence - The recommendation to explore constrained parameter updates is well-supported by observed failures

## Next Checks

1. **Architecture Ablation**: Test TTT with a simplified, fully specified encoder architecture to isolate whether architectural complexity contributes to adaptation instability.

2. **Task Alignment Analysis**: Measure feature similarity between primary and secondary task gradients during joint training to quantify task alignment and identify optimization conflicts.

3. **Constrained Adaptation**: Implement parameter update constraints (e.g., small learning rates or projection onto original parameter space) during TTT to assess whether limiting adaptation range improves stability while maintaining performance.
