# Progressive Class-Wise Attention (PCA) Approach for Diagnosing Skin Lesions

## Quick Facts
- arXiv ID: 2306.07300
- Source URL: https://arxiv.org/abs/2306.07300
- Reference count: 40
- Achieves 97.40% accuracy on HAM10000 dataset and 94.9% on ISIC 2019 dataset

## Executive Summary
This paper introduces a progressive class-wise attention (PCA) approach for skin lesion classification that addresses key challenges in dermatological imaging: inter-class similarity, intra-class variation, and class imbalance. The method employs a novel class-wise attention mechanism applied progressively across multiple stages of a DenseNet-121 backbone, enabling the model to learn feature maps in a class-specific manner. The approach treats all skin lesion types equally while incorporating discriminative feature details from multi-scale features, achieving state-of-the-art performance that surpasses 15+ cutting-edge methods and leaderboard winners.

## Method Summary
The PCA approach introduces a progressive class-wise attention mechanism that applies attention modules at multiple stages of the DenseNet-121 backbone. Each attention module learns class-specific feature maps, allowing the network to handle the inter-class similarity and intra-class variation characteristic of skin lesions. The progressive application across stages incorporates multi-scale feature details, while the class-wise design addresses the class imbalance problem by ensuring equal treatment of all lesion types. The attention mechanism operates on feature maps from different scales, progressively refining the discriminative features needed for accurate classification of the seven skin lesion categories in the HAM10000 dataset.

## Key Results
- Achieves 97.40% accuracy on the HAM10000 dataset, outperforming 15+ baseline methods
- Achieves 94.9% accuracy on ISIC 2019 dataset, surpassing leaderboard winners
- Demonstrates superior performance in handling inter-class similarity and intra-class variation compared to existing approaches

## Why This Works (Mechanism)
The progressive class-wise attention mechanism works by applying class-specific attention modules at multiple stages of the DenseNet-121 architecture. At each stage, the attention module learns to weigh features differently for each class, effectively creating class-specific feature representations. The progressive application ensures that discriminative details from multiple scales are incorporated, while the class-wise design prevents dominant classes from overshadowing minority classes. This multi-stage, class-specific approach allows the network to capture both global and local discriminative features while maintaining balanced treatment across all skin lesion types, directly addressing the three main challenges of inter-class similarity, intra-class variation, and class imbalance.

**Class-Wise Processing**
- Why needed: Prevents class imbalance from biasing the model toward dominant categories
- Quick check: Ensure each class receives equal attention weight during training and inference

## Architecture Onboarding

**Component Map:**
DenseNet-121 backbone -> Progressive Class-Wise Attention Modules (Stage 1, Stage 2, Stage 3) -> Classification Head

**Critical Path:**
Input image → DenseNet feature extraction → Stage 1 attention → Stage 2 attention → Stage 3 attention → Feature concatenation → Classification head → Output probabilities

**Design Tradeoffs:**
- Progressive attention vs. single-stage attention: Progressive approach captures multi-scale details but increases computational cost
- Class-wise vs. global attention: Class-wise ensures balanced treatment but requires more parameters and computation
- DenseNet backbone vs. other architectures: DenseNet provides efficient feature reuse but may be outperformed by newer architectures

**Failure Signatures:**
- Over-attentiveness to background regions indicating attention mechanism instability
- Loss of fine details suggesting excessive downsampling between attention stages
- Class-wise attention maps showing similar patterns across different classes indicating insufficient specialization
