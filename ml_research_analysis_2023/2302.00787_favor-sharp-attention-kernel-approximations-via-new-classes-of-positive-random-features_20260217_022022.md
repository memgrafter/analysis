# FAVOR#: Sharp Attention Kernel Approximations via New Classes of Positive Random Features

## Quick Facts
- **arXiv ID**: 2302.00787
- **Source URL**: https://arxiv.org/abs/2302.00787
- **Reference count**: 40
- **Primary result**: Introduces dense-exponential random features (DERFs) for more precise kernel approximations, reducing variance by up to e10 over prior methods.

## Executive Summary
This paper introduces dense-exponential random features (DERFs), a new class of positive random features for approximating the Gaussian and softmax kernels in machine learning. DERFs generalize prior scalar-parameter approaches by using dense matrix parameters within the exponent, enabling more flexible and precise approximations. The authors identify that the earlier homogeneity heuristic corresponds to optimizing a shifted log-variance objective, and propose efficient, closed-form parameter optimization for several DERF variants (ADERFs, SDERFs, and SADERFs). In experiments, SDERFs achieve up to e10 variance reduction over baselines, improve kernel classification accuracy on UCI datasets, and enhance Transformer performance in both speech (LibriSpeech) and NLP (GLUE) tasks, with FAVOR# (DERF-based attention) achieving top results.

## Method Summary
The paper introduces dense-exponential random features (DERFs), which extend prior work by allowing dense matrix parameters within the exponential function for kernel approximation. This flexibility enables more precise tuning of kernel approximations than scalar-parameter methods. The authors show that the commonly used homogeneity heuristic corresponds to optimizing a shifted log-variance objective. They propose several DERF variants (ADERFs, SDERFs, SADERFs), each with efficient, closed-form parameter optimization, and demonstrate that these achieve significantly lower variance and improved performance across kernel classification and efficient Transformer tasks.

## Key Results
- SDERFs reduce variance by up to e10 compared to prior positive random feature methods.
- DERF-based kernel classification achieves higher accuracy across multiple UCI datasets.
- FAVOR# (DERF-based attention) improves Transformer performance on LibriSpeech speech modeling and GLUE NLP tasks.

## Why This Works (Mechanism)
DERFs enable more precise kernel approximation by allowing dense matrix parameters within the exponential, rather than just scalar parameters. This increased flexibility allows the approximation to better match the target kernel's properties, leading to reduced variance and improved downstream task performance. The closed-form optimization for SDERFs and other variants makes the method practical for large-scale applications.

## Limitations
- Empirical validation is limited to moderate-scale datasets (UCI, LibriSpeech, GLUE), with limited evaluation on large-scale vision or multi-modal tasks.
- No theoretical generalization bounds are provided for the new DERF variants.
- Limited ablation study on the relative contributions of ADERFs, SDERFs, and SADERFs to performance gains.
