# Constructing Code-mixed Universal Dependency Forest for Unbiased Cross-lingual Relation Extraction

## Quick Facts
- arXiv ID: 2305.12258
- Source URL: https://arxiv.org/abs/2305.12258
- Reference count: 40
- Primary result: Code-mixed UD forests improve cross-lingual relation extraction, especially for language pairs with larger linguistic differences

## Executive Summary
This paper addresses bias issues in universal dependency (UD) features for cross-lingual relation extraction (XRE) by proposing code-mixed UD forests. The approach merges source and target UD trees using word alignment to create unified syntactic representations that preserve complementary structural information from both languages. Experiments on ACE05 benchmark datasets demonstrate significant performance gains in XRE tasks, particularly for language pairs with larger linguistic differences.

## Method Summary
The method constructs code-mixed UD forests by translating source sentences to target language, parsing both into UD trees, computing word alignments, and merging trees based on alignment scores above threshold θ. These forests are encoded using Graph Attention Networks and decoded with biaffine classifiers for relation extraction. The approach integrates annotation projection and model transfer paradigms, reducing the gap between training and prediction phases.

## Key Results
- Code-mixed UD forests significantly improve XRE performance across language pairs
- Larger linguistic differences between source and target languages yield bigger performance boosts
- The method effectively closes gaps between training and predicting phases in UD-based XRE

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Code-mixed UD forests reduce linguistic bias by integrating complementary source and target language syntactic features
- Mechanism: The approach constructs a unified forest by merging source-/target-side UD structures as a unified code-mixed UD forest
- Core assumption: Parallel sentences in different languages share semantic structure despite syntactic differences
- Evidence anchors: [abstract] "merge the source-/target-side UD structures as a unified code-mixed UD forest"
- Break condition: If word alignment quality is poor or if languages have fundamentally incompatible syntactic structures

### Mechanism 2
- Claim: Code-mixed forests improve transfer by reducing the gap between training and prediction phases
- Mechanism: Training uses both source and target UD features while prediction uses target features, making the phases more consistent
- Core assumption: Exposure to both languages' features during training improves generalization to target language
- Evidence anchors: [abstract] "the gaps of UD-based XRE between the training and predicting phases can be effectively closed"
- Break condition: If the source language features are too different to be useful for the target language

### Mechanism 3
- Claim: Code-mixed forests are particularly effective for language pairs with larger linguistic differences
- Mechanism: The approach preserves more source language features when target features are significantly different
- Core assumption: Larger linguistic differences create more opportunities for complementary feature integration
- Evidence anchors: [section] "the larger the difference between SRC and TGT languages, the bigger the boosts offered by code-mixed forests"
- Break condition: If languages are so different that their features cannot be meaningfully integrated

## Architecture Onboarding

- Component map: Translation module -> Word alignment module -> UD parsing module -> Code-mixing algorithm -> GAT encoder -> Biaffine decoder

- Critical path:
  1. Translate source sentence to target language
  2. Parse both sentences into UD trees
  3. Compute word alignments
  4. Construct code-mixed forest via merging algorithm
  5. Encode forest with GAT
  6. Decode relations with biaffine classifier

- Design tradeoffs:
  - Threshold θ controls merging precision vs. recall
  - Translation quality vs. speed (Google API)
  - GAT complexity vs. performance
  - Source vs. target language feature balance

- Failure signatures:
  - Poor word alignment → noisy code-mixed forests
  - High θ threshold → insufficient merging
  - Low θ threshold → incorrect node merges
  - Translation errors → semantic drift in code-mixed text

- First 3 experiments:
  1. Verify code-mixed forest construction on a small parallel corpus
  2. Test GAT encoding performance with different forest sizes
  3. Compare relation extraction F1 scores with and without code-mixing on EN→ZH transfer

## Limitations

- The approach heavily depends on word alignment quality, which may be poor for languages with very different structures
- Translation quality directly impacts semantic accuracy of the code-mixed forests
- The method requires parallel sentences and UD annotations, limiting its applicability to languages without such resources

## Confidence

- High confidence: The general concept of using code-mixed UD forests for XRE transfer is technically sound and addresses a recognized gap in cross-lingual transfer research
- Medium confidence: The effectiveness for language pairs with larger linguistic differences is supported by experimental results but requires further validation on additional language pairs
- Medium confidence: The claim that code-mixed forests reduce training-prediction phase gaps is logically consistent but needs more direct empirical validation
