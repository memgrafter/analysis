# Personalised Federated Learning On Heterogeneous Feature Spaces

## Quick Facts
- arXiv ID: 2301.11447
- Source URL: https://arxiv.org/abs/2301.11447
- Reference count: 40
- First personalised federated learning framework designed to handle heterogeneous feature spaces across clients

## Executive Summary
This paper introduces FLIC, the first personalised federated learning framework designed to handle heterogeneous feature spaces across clients. Unlike existing approaches that assume a common feature space, FLIC learns local embedding functions to map each client's data into a shared latent space, using Wasserstein barycenters for distribution alignment. The method integrates seamlessly with standard personalised FL approaches like FedRep. Theoretical analysis provides non-asymptotic convergence guarantees in a simplified setting, showing that FLIC can recover the true latent subspace. Experiments on synthetic and real-world datasets (Digits and TextCaps) demonstrate superior performance compared to baselines, with accuracy gains of up to 4% over competing methods. The framework is robust to participation rates and effectively handles feature space heterogeneity without requiring data sharing.

## Method Summary
FLIC introduces a novel approach to personalized federated learning that addresses the challenge of heterogeneous feature spaces across clients. The method learns local embedding functions for each client to map their data into a shared latent space, using Wasserstein barycenters for distribution alignment. This allows FLIC to integrate seamlessly with standard personalized FL approaches like FedRep while handling feature space heterogeneity. The framework employs an alternating optimization strategy, updating local embeddings and model parameters iteratively across clients. Theoretical analysis provides non-asymptotic convergence guarantees in a simplified linear setting, demonstrating the method's ability to recover the true latent subspace. Empirically, FLIC shows superior performance on Digits and TextCaps datasets, with accuracy improvements of up to 4% compared to baselines.

## Key Results
- FLIC achieves up to 4% higher accuracy compared to baseline methods on Digits and TextCaps datasets
- The framework demonstrates robustness to varying participation rates in federated learning settings
- Theoretical analysis provides non-asymptotic convergence guarantees in a simplified linear setting

## Why This Works (Mechanism)
FLIC works by learning local embedding functions that map each client's heterogeneous feature space into a shared latent space. This approach addresses the fundamental challenge of federated learning where clients may have different feature spaces due to variations in data collection methods, sensor types, or preprocessing pipelines. By using Wasserstein barycenters for distribution alignment, FLIC ensures that the learned embeddings from different clients are aligned in a way that preserves the statistical properties of the data. The alternating optimization strategy allows for effective learning of both the local embeddings and the global model parameters. This mechanism enables FLIC to handle feature space heterogeneity without requiring data sharing between clients, which is crucial for privacy-preserving federated learning.

## Foundational Learning
- Federated Learning: Distributed machine learning paradigm where multiple clients collaborate to train a model without sharing raw data. Needed for understanding the collaborative nature of the approach and privacy constraints.
- Heterogeneous Feature Spaces: Situations where different clients have data with different feature representations or dimensions. Crucial for grasping the specific problem FLIC addresses.
- Wasserstein Barycenters: A method for computing the average of probability distributions, used here for aligning embeddings from different clients. Important for understanding how FLIC achieves distribution alignment across heterogeneous spaces.
- Alternating Optimization: An iterative optimization technique where different sets of variables are optimized in turn. Key to understanding FLIC's training procedure for learning both local embeddings and global model parameters.

## Architecture Onboarding

Component Map:
Client Embedding Function -> Shared Latent Space -> Global Model -> Client-specific Personalization

Critical Path:
Data (Client-specific) -> Local Embedding (Learned) -> Shared Latent Space (Aligned via Wasserstein) -> Global Model (Trained) -> Personalized Prediction

Design Tradeoffs:
FLIC trades increased model complexity (learning separate embeddings per client) for the ability to handle heterogeneous feature spaces. This approach allows for better personalization but increases the number of parameters to be learned and communicated in the federated setting.

Failure Signatures:
- Poor performance may indicate failure to align distributions in the shared latent space
- Convergence issues might suggest problems with the alternating optimization strategy
- Privacy leaks could occur if the learned embeddings inadvertently reveal information about the client's original feature space

## Limitations
- Theoretical analysis is limited to a simplified setting with linear models and assumes exact recovery of the true latent subspace
- Empirical validation relies on a limited number of datasets (Digits and TextCaps), which may not generalize to other domains
- The paper does not address potential privacy concerns related to learning local embedding functions
