# Personalized Predictive ASR for Latency Reduction in Voice Assistants

## Quick Facts
- arXiv ID: 2305.13794
- Source URL: https://arxiv.org/abs/2305.13794
- Reference count: 0
- Primary result: Predictive ASR system achieves 300 ms average latency reduction for 23% of utterances with 8% downstream cost increase

## Executive Summary
This paper introduces a predictive ASR system that reduces voice assistant latency by prefetching downstream results based on partial utterance predictions. The system demonstrates an average 300 ms latency reduction for 23% of utterances in a voice assistant dataset, while incurring only an 8% increase in downstream costs from failed prefetch attempts. The authors identify personalization as a critical factor for prediction accuracy and suggest that incorporating usage history and contextual features like time of day and device location could further improve performance.

## Method Summary
The authors propose a predictive ASR system that prefetches downstream results by predicting the complete utterance from partially spoken input. The system makes a single prefetch attempt per utterance, achieving a maximum 28% success rate. The prediction model leverages personalized information to improve accuracy, though the paper acknowledges that conditioning on usage history and contextual features could yield additional benefits. The approach balances latency reduction against increased downstream costs from failed prefetch attempts.

## Key Results
- Average 300 ms latency reduction for 23% of utterances in voice assistant dataset
- 8% increase in downstream costs due to failed prefetch attempts
- Maximum 28% prefetch success rate limited by single-attempt constraint

## Why This Works (Mechanism)
The system works by leveraging early predictions of complete utterances to prefetch downstream results before speech ends. By making these predictions personalized to individual users, the system can more accurately anticipate likely completion patterns. The predictive model analyzes partial speech input and generates hypotheses about the full utterance, allowing parallel processing of downstream tasks while the user continues speaking.
