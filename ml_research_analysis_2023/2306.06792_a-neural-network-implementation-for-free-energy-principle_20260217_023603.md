# A Neural Network Implementation for Free Energy Principle

## Quick Facts
- arXiv ID: 2306.06792
- Source URL: https://arxiv.org/abs/2306.06792
- Reference count: 31
- Primary result: Implements FEP via Helmholtz machine, achieving >99% accuracy through active inference

## Executive Summary
This paper bridges the Free Energy Principle and machine learning by implementing FEP through a classical neural network model, the Helmholtz machine. The Helmholtz machine minimizes variational free energy, aligning with FEP's objective, and serves as an ideal prototype for implementing FEP in a neural network fashion. The paper presents a detailed theoretical discussion and a preliminary experiment to validate the hypothesis, demonstrating that by fine-tuning the trained neural network through active inference, model performance can be promoted to accuracy above 99%.

## Method Summary
The method involves implementing a 4-layer Helmholtz machine with 10, 8, 5, and 3 neurons respectively, trained using a two-stage process. Stage I uses traditional data fitting on binary-valued input data designed with three well-formed rules inspired by musical gestalt. Stage II applies active inference to actively sample input sensations as salience and fine-tune the model, aiming to boost generation accuracy above 99% while maintaining generative diversity.

## Key Results
- Helmholtz machine trained via wake-sleep algorithm achieves FEP's variational free energy minimization objective
- Active inference fine-tuning in Stage II boosts model performance to accuracy above 99%
- Data distribution is continuously deformed to salience that conforms to model representation through active sampling

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Helmholtz machine's wake-sleep algorithm implements FEP by minimizing variational free energy through decoupled parameter updates.
- Mechanism: In the wake phase, bottom-up recognition weights encode sensory data into latent causes; in the sleep phase, top-down generative weights generate data from latent causes. This alternation minimizes the KL divergence between recognition and generative distributions.
- Core assumption: The generative model is parameterized and can be learned jointly with recognition weights via alternating EM updates.
- Evidence anchors:
  - [abstract] The Helmholtz machine is optimized by minimizing its free energy, the same objective as FEP.
  - [section] Equation (7): F = DKL[Qϕ(α|d)||Pθ(α, d)], and wake-sleep algorithm updates ϕ and θ alternatively.
- Break condition: If the wake-sleep updates do not converge or if the decoupling assumption fails.

### Mechanism 2
- Claim: Active inference in stage II actively samples salient data that conform to current latent representations, improving classification accuracy.
- Mechanism: After initial training, the model filters generated instances through well-formed rules, and more frequently generated instances become more salient in the evidence distribution.
- Core assumption: The data distribution can be modified by selective sampling based on model-generated samples, and this modification improves model performance.
- Evidence anchors:
  - [abstract] By fine-tuning the trained neural network through active inference, the model performance is promoted to accuracy above 99%.
  - [section] "In training stage II, we fine-tune the model trained in stage I by active inference, which boosted the generation accuracy to 0.99+..."
- Break condition: If active sampling does not improve accuracy or causes mode collapse.

### Mechanism 3
- Claim: The hierarchical structure with forward and backward connections in the Helmholtz machine mirrors cortical hierarchies in the brain, enabling predictive coding.
- Mechanism: Bottom-up connections convey prediction errors; top-down connections generate predictions. Local delta rules allow biologically plausible local credit assignment.
- Core assumption: The hierarchical message passing and local delta updates approximate the brain's predictive coding mechanisms.
- Evidence anchors:
  - [section] "It's contended extensively in FEP-related works that the cortical responses in our brain observe a hierarchical model with forward and backward connections..."
- Break condition: If the hierarchical approximation does not capture the nonlinear dynamics effectively.

## Architecture Onboarding

- Component map: Input layer (10 neurons) -> Hidden layer 1 (8 neurons) -> Hidden layer 2 (5 neurons) -> Latent layer (3 neurons) -> Generative reverse path
- Critical path:
  1. Forward pass: compute activations using current θ, generate latent states
  2. Backward pass: compute probabilities using current ϕ, reconstruct inputs
  3. Update θ in wake phase using local delta rule with recognition targets
  4. Update ϕ in sleep phase using generated samples as targets
- Design tradeoffs:
  - Stochastic binary neurons {−1, 1} vs deterministic activations: increases gradient diversity but adds sampling noise
  - Decoupled wake-sleep vs joint VAE training: simpler local updates but may converge slower
  - Active sampling vs random sampling: improves accuracy but risks overfitting to generated modes
- Failure signatures:
  - Vanishing gradients if neuron states saturate near ±1
  - Mode collapse if active sampling overfits to a narrow data subset
  - Poor convergence if wake-sleep alternation is imbalanced
- First 3 experiments:
  1. Train baseline Helmholtz machine on synthetic rhythmic data; measure accuracy and diversity
  2. Apply active inference sampling; track accuracy gain and changes in data distribution
  3. Visualize latent space and generated samples to verify hierarchical predictive coding behavior

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the Helmholtz machine's free energy objective compare to the traditional variational free energy in FEP when applied to machine learning tasks?
- Basis in paper: [explicit] The paper states that the Helmholtz machine uses variational free energy as its objective, which is in accord with FEP.
- Why unresolved: The paper presents a theoretical discussion but does not provide empirical comparisons or quantitative analyses of performance differences.
- What evidence would resolve it: Experiments comparing Helmholtz machine performance with other FEP-based methods on various machine learning tasks, along with analysis of free energy landscapes and convergence properties.

### Open Question 2
- Question: What are the implications of using a non-temporal Helmholtz machine as a prototype for implementing FEP, which is inherently temporal?
- Basis in paper: [explicit] The paper acknowledges that the Helmholtz machine is not temporal but argues it is an ideal prototype for implementing FEP in a neural network fashion.
- Why unresolved: The paper does not explore limitations or potential drawbacks of using a non-temporal model to approximate a temporal principle.
- What evidence would resolve it: Extensions of the Helmholtz machine to include temporal dynamics and comparisons with temporal FEP models on sequential data tasks.

### Open Question 3
- Question: How does the active inference mechanism in the Helmholtz machine influence the learned representations and the overall model performance?
- Basis in paper: [explicit] The paper describes how active inference is used to fine-tune the model by actively sampling input sensations as salience, which boosts model performance to above 99% accuracy.
- Why unresolved: The paper does not provide detailed analysis of how active inference affects internal representations or trade-offs between accuracy and diversity.
- What evidence would resolve it: In-depth studies of learned representations before and after active inference, including visualizations and analyses of changes in data distribution and impact on model generalization.

## Limitations

- Experimental validation is minimal, using only synthetic rhythmic data rather than real-world datasets
- Active inference mechanism lacks precise specification, particularly regarding how data distribution is deformed
- No direct corpus evidence supporting the specific Helmholtz machine implementation of FEP

## Confidence

- **High Confidence**: Theoretical alignment between Helmholtz machine free energy minimization and FEP's variational free energy objective
- **Medium Confidence**: Hierarchical predictive coding mechanism and wake-sleep algorithm implementation
- **Low Confidence**: Active inference mechanism and its claimed ability to boost accuracy above 99% while maintaining generative diversity
