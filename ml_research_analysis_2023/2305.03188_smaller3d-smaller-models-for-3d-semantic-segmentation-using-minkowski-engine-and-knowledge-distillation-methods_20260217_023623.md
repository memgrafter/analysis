# Smaller3d: Smaller Models for 3D Semantic Segmentation Using Minkowski Engine and Knowledge Distillation Methods

## Quick Facts
- arXiv ID: 2305.03188
- Source URL: https://arxiv.org/abs/2305.03188
- Authors: 
- Reference count: 39
- Primary result: Reduces 3D semantic segmentation model size by 4-16x while maintaining similar performance on ScanNet V2

## Executive Summary
This paper introduces a knowledge distillation framework for compressing 3D semantic segmentation models while preserving accuracy. The authors propose using feature map distillation with upsampling convolutions and temperature-scaled logit loss to transfer knowledge from large teacher models to smaller student models. Experiments on the ScanNet V2 dataset demonstrate that the proposed method achieves similar performance to state-of-the-art models while significantly reducing model size, enabling faster inference and lower computational requirements.

## Method Summary
The method applies knowledge distillation techniques to 3D sparse tensor representations using the Minkowski Engine. Teacher models (Res16UNet34C) are trained with Mix3D augmentation on ScanNet V2, then used to guide smaller student models (Res16UNet34CHalf/Quarter) through multiple loss functions. The training combines cross-entropy loss with ground truth, KL divergence between temperature-scaled logits, and mean squared error between upsampled student feature maps and teacher feature maps. This multi-loss approach aims to stabilize training and accelerate convergence while achieving substantial model compression.

## Key Results
- Achieves similar mIoU performance to state-of-the-art models with 4x smaller model size (difference of ~2.6%)
- Maintains acceptable performance with 16x smaller model size (difference of ~8%)
- Demonstrates faster inference and lower computational requirements compared to full-sized models
- Shows training stability improvements when using additional losses alongside standard knowledge distillation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Feature map distillation with upsampling reduces parameter count while preserving semantic detail.
- Mechanism: By adding upsampling convolutions on student encoder/decoder feature maps to match teacher dimensions, the student learns to represent compressed information that mirrors the teacher's richer feature space.
- Core assumption: Matching intermediate feature map dimensions forces the student to learn equivalent spatial-semantic representations despite fewer parameters.
- Evidence anchors:
  - [abstract] "we propose the application of knowledge distillation techniques, especially for sparse tensors in 3D deep learning, to reduce model sizes while maintaining performance"
  - [section] "To do so, we suggest using Upsampling Spatio Temporal convolutional layer on top of our selected feature map, to bring it to the same space as the teacher feature map"
  - [corpus] Weak - no direct neighbor evidence for 3D sparse tensor feature map distillation
- Break condition: If upsampling layers introduce noise or the student's feature space fundamentally differs from teacher, distillation fails.

### Mechanism 2
- Claim: Temperature-scaled logit distillation stabilizes class probability transfer.
- Mechanism: Applying temperature scaling softens teacher softmax outputs, creating "soft labels" that provide richer gradient signals than hard ground truth labels alone.
- Core assumption: Soft labels guide the student toward the teacher's decision boundaries more smoothly than binary cross-entropy alone.
- Evidence anchors:
  - [abstract] "Logit loss with temperature, to transfer knowledge from large teacher models to smaller student models"
  - [section] "Hinton, G., Vinyals, O., & Dean, J. (2015), suggest, that for Knowledge distillation, it is enough to use penalty only on the last layer output... use temperature for 'soft labels'"
  - [corpus] Weak - no direct neighbor evidence for temperature scaling in 3D semantic segmentation
- Break condition: If temperature is too high, gradients vanish; if too low, benefits of soft labeling disappear.

### Mechanism 3
- Claim: Multi-loss combination accelerates convergence and improves stability.
- Mechanism: Combining logit loss, feature map loss, and standard cross-entropy creates multiple gradient paths, preventing vanishing gradients and speeding training.
- Core assumption: Intermediate supervision provides earlier gradient signals that stabilize training dynamics.
- Evidence anchors:
  - [abstract] "Experiments also show that using additional loss along with Knowledge Distillation standard techniques relatively speeds up learning and makes the process stable"
  - [section] "In analysis, we found out, that as long as you increase control over the network, the training process becomes much more stable"
  - [corpus] Weak - no direct neighbor evidence for multi-loss stability in 3D distillation
- Break condition: If loss weights are poorly balanced, conflicting gradients can destabilize training.

## Architecture Onboarding

- Component map:
  Teacher: Res16UNet34C -> Student: Res16UNet34CHalf/Quarter -> Losses: logit loss (temperature-scaled), encoder feature map loss, decoder feature map loss, cross-entropy -> Data: ScanNet V2 point clouds with 5cm voxel size -> Engine: Minkowski Engine with sparse convolutions

- Critical path:
  1. Load teacher and student models
  2. Forward pass both through same batch
  3. Compute logit loss (temperature-scaled KL divergence)
  4. Compute feature map losses (upsample student to teacher size, MSE)
  5. Compute cross-entropy with ground truth
  6. Backpropagate combined loss
  7. Update student parameters only

- Design tradeoffs:
  - Smaller models → faster inference but potential accuracy loss
  - Feature map distillation → better accuracy but more memory/compute during training
  - Temperature scaling → smoother gradients but hyperparameter sensitivity
  - Upsampling convolutions → bridging dimension gaps but added complexity

- Failure signatures:
  - Training diverges → check loss weight balance and temperature value
  - Accuracy drops sharply → verify upsampling doesn't distort feature maps
  - Memory overflow → reduce batch size or remove feature map losses

- First 3 experiments:
  1. Train teacher Res16UNet34C with Mix3D augmentation on ScanNet V2; validate mIoU.
  2. Train student Res16UNet34CHalf with only logit loss (α=1, T=1); compare mIoU drop.
  3. Add feature map losses to student training; measure stability and accuracy improvement.
