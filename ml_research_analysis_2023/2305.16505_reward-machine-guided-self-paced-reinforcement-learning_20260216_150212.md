# Reward-Machine-Guided, Self-Paced Reinforcement Learning

## Quick Facts
- **arXiv ID**: 2305.16505
- **Source URL**: https://arxiv.org/abs/2305.16505
- **Reference count**: 10
- **Primary result**: RM-guided SPRL achieves optimal behavior in long-horizon tasks where state-of-the-art methods fail, reduces curriculum length by up to 25%, and decreases variance in curriculum generation by up to four orders of magnitude.

## Executive Summary
This paper introduces reward-machine-guided, self-paced reinforcement learning (RM-guided SPRL), a novel approach that integrates reward machines into both policy/value function updates and automated curriculum generation. The method leverages reward machines to encode non-Markovian reward functions and uses a reward-machine-context mapping to guide curriculum generation efficiently. Experiments on three environments (two-door, customized Swimmer-v3, and customized HalfCheetah-v3) demonstrate that RM-guided SPRL reliably achieves optimal behavior in long-horizon planning tasks where state-of-the-art methods fail.

## Method Summary
RM-guided SPRL integrates reward machines into self-paced reinforcement learning by using them to guide both policy updates and curriculum generation. The method maintains a reward-machine-context mapping that associates different contexts of the reward machine with corresponding curriculum tasks. During training, the algorithm selects tasks based on the current policy's performance and the reward machine's structure, allowing for more efficient exploration and learning of complex sequential behaviors. The approach combines elements of reward machine learning with curriculum learning to address the challenge of long-horizon planning in reinforcement learning.

## Key Results
- Achieves optimal behavior in long-horizon planning tasks where state-of-the-art methods fail
- Reduces curriculum length by up to 25% compared to baseline methods
- Decreases variance in curriculum generation by up to four orders of magnitude, demonstrating improved stability

## Why This Works (Mechanism)
RM-guided SPRL works by leveraging the structured representation provided by reward machines to guide the learning process. The reward machine encodes the task structure as a finite state machine where transitions correspond to high-level events. By mapping these machine states to curriculum contexts, the algorithm can generate a curriculum that naturally progresses through the task structure. This structured approach allows the agent to learn complex sequential behaviors more efficiently than unstructured exploration.

## Architecture Onboarding

**Component Map:**
Reward Machine -> Context Mapping -> Curriculum Generator -> Environment -> Policy Network -> Value Network

**Critical Path:**
The critical path flows from the reward machine through the context mapping to the curriculum generator, which selects tasks for the environment. The policy and value networks are updated based on experience collected from these tasks, and their performance influences future curriculum selection.

**Design Tradeoffs:**
The method trades increased computational overhead for structured exploration. While maintaining the reward-machine-context mapping and performing curriculum selection adds complexity, this overhead is offset by more efficient learning. The approach assumes reward machines are provided, which limits its applicability to domains where such machines can be easily specified or learned.

**Failure Signatures:**
- Poor curriculum generation leading to learning plateaus
- Inefficient exploration if context mapping is inaccurate
- Computational bottlenecks in maintaining and updating the context mapping
- Difficulty scaling to very large or complex reward machines

**First Experiments:**
1. Verify that the context mapping correctly associates reward machine states with appropriate curriculum tasks
2. Test curriculum generation on simple tasks with known optimal solutions
3. Validate that policy updates are properly guided by the reward machine structure

## Limitations
- Scalability to complex, real-world domains with high-dimensional state spaces is unproven
- Computational overhead of maintaining and updating the reward-machine-context mapping is not fully characterized
- Method assumes reward machines are provided rather than learned from data

## Confidence

**High confidence**: Claims regarding improved stability and efficiency in curriculum generation (reduced length by 25%, variance reduction up to 4 orders of magnitude) are well-supported by experimental results.

**Medium confidence**: The assertion that RM-guided SPRL "reliably achieves optimal behavior in long-horizon planning tasks where state-of-the-art methods fail" is supported by comparison with QRM, but evaluation is limited to three specific environments.

**Low confidence**: Claims about the method's ability to "learn the underlying task structure" are not directly validated; experiments assume reward machines are given rather than learned.

## Next Checks
1. Test RM-guided SPRL on environments where reward machines must be automatically inferred from demonstrations or experience, evaluating both accuracy and computational overhead.
2. Evaluate scalability by applying the method to high-dimensional continuous control tasks with longer horizons (e.g., robotic manipulation) and measure performance degradation.
3. Conduct ablation studies to quantify the individual contributions of reward-machine-guided policy updates versus automated curriculum generation to overall performance improvements.
