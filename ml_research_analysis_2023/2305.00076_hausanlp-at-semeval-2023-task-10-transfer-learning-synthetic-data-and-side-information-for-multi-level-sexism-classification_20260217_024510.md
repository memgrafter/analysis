# HausaNLP at SemEval-2023 Task 10: Transfer Learning, Synthetic Data and Side-Information for Multi-Level Sexism Classification

## Quick Facts
- arXiv ID: 2305.00076
- Source URL: https://arxiv.org/abs/2305.00076
- Reference count: 5
- Primary result: Ranked 49th in binary sexism classification with F1-score of 0.82

## Executive Summary
This paper presents the HausaNLP system submitted to SemEval-2023 Task 10 for detecting sexism in online text from Gab and Reddit. The authors fine-tuned two pre-trained language models, XLM-T and HateBERT, on a binary classification task to distinguish between sexist and non-sexist content. The system explored synthetic data generation and the use of parent class information to improve performance on multi-level sexism classification tasks. While achieving competitive results in the binary classification task (ranking 49th with F1-score of 0.82), the paper lacks detailed validation of claimed improvements for multi-level classification tasks and comprehensive error analysis.

## Method Summary
The HausaNLP system utilized transfer learning by fine-tuning pre-trained language models (XLM-T and HateBERT) on the binary classification task of detecting sexist content. The authors explored synthetic data generation and the incorporation of parent class information to enhance performance on multi-level sexism classification tasks. The approach aimed to leverage intermediary class information and synthetically generated examples to improve model performance beyond the binary classification task.

## Key Results
- Ranked 49th in binary sexism classification task with F1-score of 0.82
- Reported competitive performance, outperforming the best system by only 0.052%
- Claimed improvements in multi-level classification tasks through synthetic data and parent class information

## Why This Works (Mechanism)
The system's effectiveness stems from leveraging pre-trained language models fine-tuned on domain-specific data, allowing the models to capture nuanced patterns in sexist content. The use of synthetic data helps augment the training set, potentially improving model generalization. Incorporating parent class information provides additional context for multi-level classification tasks, enabling the model to make more informed decisions based on hierarchical relationships between classes.
