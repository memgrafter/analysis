# SSL-CPCD: Self-supervised learning with composite pretext-class discrimination for improved generalisability in endoscopic image analysis

## Quick Facts
- arXiv ID: 2306.00197
- Source URL: https://arxiv.org/abs/2306.00197
- Reference count: 40
- Achieves 79.77% Top 1 accuracy for ulcerative colitis classification, 88.62% mAP for polyp detection, and 82.32% dice similarity coefficient for segmentation

## Executive Summary
SSL-CPCD introduces a novel self-supervised learning approach for endoscopic image analysis that addresses the challenges of limited labeled data and poor generalization. The method combines image-level and patch-level instance-group discrimination losses with an additive angular margin in the cosine similarity metric. This architecture enables the model to learn semantically meaningful features while improving class separation. The approach demonstrates significant performance improvements across classification, detection, and segmentation tasks while showing superior generalization to unseen datasets.

## Method Summary
The SSL-CPCD framework employs a composite pretext-class discrimination strategy that operates at both global (image-level) and local (patch-level) feature spaces. The model uses an encoder to extract features from input images, which are then processed through separate branches for instance discrimination and group discrimination tasks. The instance discrimination component learns to distinguish between individual samples, while the group discrimination component organizes samples into semantically meaningful clusters. An additive angular margin is applied to the cosine similarity metric to enhance inter-class separation. The combined loss function balances these objectives to produce robust feature representations that transfer effectively to downstream tasks.

## Key Results
- Achieves 79.77% Top 1 accuracy for ulcerative colitis classification
- Demonstrates 88.62% mAP for polyp detection
- Shows 82.32% dice similarity coefficient for segmentation tasks
- Exhibits nearly 7% improvement in generalizability to unseen datasets

## Why This Works (Mechanism)
The effectiveness of SSL-CPCD stems from its multi-level discrimination strategy that captures both fine-grained instance-level differences and broader semantic groupings. The additive angular margin in the cosine similarity metric forces the model to create larger angular separations between different classes, improving discriminative power. By operating at both image and patch levels, the method captures both global context and local detail, which is crucial for the complex visual patterns in endoscopic imagery. The self-supervised pre-training allows the model to learn rich feature representations from unlabeled data, reducing dependency on expensive annotated datasets.

## Foundational Learning
- **Self-supervised learning**: Training models without manual labels by creating artificial pretext tasks; needed to leverage large amounts of unlabeled endoscopic data
- **Instance discrimination**: Learning to distinguish between individual samples; provides fine-grained feature learning
- **Group discrimination**: Organizing samples into semantic clusters; captures broader class relationships
- **Additive angular margin**: Increasing angular separation between classes; improves discriminative boundaries
- **Cosine similarity**: Measuring angular distance between feature vectors; provides scale-invariant comparison

## Architecture Onboarding

**Component map**: Input images → Encoder → Global branch → Instance discrimination loss + Group discrimination loss → Feature representations

**Critical path**: The encoder extracts features that flow through both instance and group discrimination branches, with losses combined to optimize the feature space for downstream tasks.

**Design tradeoffs**: The method balances between instance-level discrimination (which can lead to overfitting to specific samples) and group-level discrimination (which captures semantic relationships but may lose fine details). The additive angular margin increases inter-class separation but may require careful tuning to avoid excessive angular spread.

**Failure signatures**: Poor performance may manifest as: failure to distinguish between similar-looking pathologies, collapse of feature space where distinct classes map to similar regions, or excessive focus on texture over semantic content.
