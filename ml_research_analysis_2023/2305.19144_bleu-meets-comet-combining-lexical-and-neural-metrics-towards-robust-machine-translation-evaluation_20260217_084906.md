# BLEU Meets COMET: Combining Lexical and Neural Metrics Towards Robust Machine Translation Evaluation

## Quick Facts
- **arXiv ID**: 2305.19144
- **Source URL**: https://arxiv.org/abs/2305.19144
- **Reference count**: 15
- **Primary result**: Proposes methods combining lexical and neural metrics to improve MT evaluation robustness, especially for critical errors like entity and number deviations.

## Executive Summary
This paper addresses the challenge of improving robustness in neural machine translation evaluation metrics by integrating lexical information. The authors propose three complementary approaches: an ensemble of neural and lexical metrics, incorporating sentence-level lexical scores as features via a bottleneck layer in the COMET model, and using word-level OK/BAD tags derived from Levenshtein alignments. These methods aim to enhance the detection of critical errors (e.g., entity or number deviations) that neural metrics might miss. The proposed methods show improvements in correlation with human judgments and better performance on recent challenge sets (DEMETR and ACES) across multiple language pairs, with the word-level tag approach demonstrating the most consistent gains.

## Method Summary
The paper proposes three methods to enhance neural MT evaluation metrics. First, an ensemble approach combines neural metrics (COMET) with lexical metrics (BLEU, chrF) using either averaging or a learnable neural ensemble. Second, a bottleneck layer is added to the COMET model to incorporate sentence-level lexical scores as features, allowing the model to learn weighted combinations of neural and lexical information. Third, word-level OK/BAD tags are generated through Levenshtein alignments between hypotheses and references, then aggregated to sentence level and used as additional features in the COMET model. These approaches aim to improve the detection of critical errors like entity and number deviations that neural metrics might miss.

## Key Results
- The word-level OK/BAD tag approach shows the most consistent improvements across multiple language pairs and benchmarks
- All three proposed methods improve correlation with human judgments on WMT metrics shared tasks
- The methods demonstrate better performance on recent challenge sets (DEMETR, ACES) compared to baseline COMET
- Improvements are particularly notable for detecting critical errors like entity and number deviations

## Why This Works (Mechanism)
The proposed methods work by bridging the gap between neural and lexical evaluation approaches. Neural metrics like COMET excel at capturing semantic similarity but may struggle with surface-level precision errors, while lexical metrics like BLEU are sensitive to exact word matches but miss semantic equivalences. By combining these complementary strengths through ensemble methods, bottleneck layers, or word-level error tags, the evaluation metrics gain both semantic understanding and precision awareness. The word-level OK/BAD tags specifically help the model focus on critical surface-level errors that can significantly impact translation quality, even when semantic meaning is preserved.

## Foundational Learning

**Levenshtein Alignment**: Measures edit distance between hypothesis and reference to identify word-level matches/mismatches - needed to generate OK/BAD tags for training; quick check: verify alignment accuracy on sample sentence pairs.

**COMET Model Architecture**: Neural metric using multilingual pre-trained encoders to compute translation quality - needed as the baseline neural metric; quick check: confirm encoder architecture matches published specifications.

**BLEU and chrF Metrics**: Traditional lexical metrics based on n-gram precision and character n-grams - needed as complementary lexical signals; quick check: ensure consistent tokenization and smoothing parameters.

**Bottleneck Layer**: A compressed representation layer that forces the model to learn important feature combinations - needed to integrate lexical scores without overwhelming neural representations; quick check: verify bottleneck dimension is sufficiently small.

**Challenge Sets (DEMETR, ACES)**: Specialized test sets focusing on difficult translation phenomena - needed to evaluate robustness improvements; quick check: confirm test set version matches reported results.

## Architecture Onboarding

**Component Map**: Reference sentences -> Levenshtein alignment -> Word-level OK/BAD tags; Hypothesis sentences + reference sentences -> COMET encoder; Lexical metrics (BLEU, chrF) -> Sentence scores; All features -> Bottleneck layer -> Quality prediction

**Critical Path**: Reference and hypothesis -> Levenshtein alignment (for word tags) + COMET encoding (for neural features) + lexical metric computation -> Feature concatenation/ensemble -> Quality prediction

**Design Tradeoffs**: Ensemble methods offer simplicity but may not learn optimal feature combinations; bottleneck layer enables learned integration but adds model complexity; word-level tags provide granular error information but depend on alignment quality and may miss semantic equivalences.

**Failure Signatures**: Poor Levenshtein alignments leading to incorrect OK/BAD tags; bottleneck layer too restrictive causing information loss; ensemble methods failing to learn meaningful weight combinations; neural features dominating lexical signals in integrated models.

**First Experiments**: 1) Validate Levenshtein alignment accuracy on sample sentence pairs; 2) Test bottleneck layer with varying dimensions to find optimal compression; 3) Compare ensemble averaging vs. learned neural ensemble performance.

## Limitations
- Improvements are relatively modest in magnitude despite statistical significance
- Methods rely heavily on Levenshtein alignment quality, which may miss semantic equivalences
- Ensemble approach may face practical deployment challenges due to increased computational costs
- Evaluation primarily limited to WMT shared tasks and specific challenge sets
