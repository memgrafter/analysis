# Interpreting Deep Forest through Feature Contribution and MDI Feature Importance

## Quick Facts
- arXiv ID: 2305.00805
- Source URL: https://arxiv.org/abs/2305.00805
- Reference count: 3
- Key outcome: Proposes a two-step method to calculate feature contribution and MDI feature importance for deep forests, showing improved interpretability over random forest methods

## Executive Summary
This paper addresses the interpretability challenge of deep forests, which are powerful but non-differentiable deep models consisting of cascaded random forests. The authors propose a two-step method to calculate feature contribution and MDI feature importance for deep forests, overcoming the limitation that existing random forest interpretation tools cannot handle the new features generated by previous layers. The method uses an estimation step to trace the influence of new features back to original features through training samples, followed by a calibration step to ensure proper feature contribution measures. Experiments on both simulated and real-world data demonstrate that the proposed methods faithfully reflect feature influence and outperform random forest-based interpretation methods in identifying relevant features.

## Method Summary
The authors propose a two-step method to calculate feature contribution and MDI feature importance for deep forests. The estimation step links the influence of new features back to original features using training samples in decision nodes, while the calibration step ensures proper feature contribution measures by adjusting contributions so their sum equals the true average response change. Feature importance is calculated using covariance between feature contribution and labels, extending the standard MDI measure to deep forests. The method is evaluated on both simulated and real-world datasets including regression, classification, and bike sharing tasks.

## Key Results
- The proposed feature contribution method accurately decomposes predictions into individual feature impacts for deep forests
- MDI feature importance calculation effectively measures global feature impact, outperforming random forest-based interpretation methods
- The estimation-calibration approach successfully traces new feature influences back to original features through training samples

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The estimation step links new feature influence back to original features through training samples in decision nodes.
- Mechanism: For each node in a second-layer tree that splits on a new feature, the method traces back to the previous layer's forests and attributes the contribution of the new feature split to the original features by averaging the contributions of the training instances in that node.
- Core assumption: The average response of a node can be approximated using the predictions from the previous layer's forests.
- Evidence anchors:
  - [abstract] "The estimation step links the influence of new features back to original features using training samples"
  - [section] "Let ∆ˆµ(ti,k ) = 1/n(ti) ∑j:xj∈ti fF,k(xj) − 1/n(ti−1) ∑j:xj∈ti−1 fF,k(xj) denote the contribution of feature k in the estimated change of average response"
- Break Condition: If the previous layer's predictions are highly inaccurate or the new feature is a complex interaction that cannot be decomposed linearly.

### Mechanism 2
- Claim: The calibration step ensures that feature contributions sum to the actual prediction change.
- Mechanism: After estimating contributions through the previous layer, the method applies a calibration function that adjusts the estimated contributions so their sum equals the true average response change observed in the node.
- Core assumption: The sum of calibrated contributions should equal the actual change in average response from splitting.
- Evidence anchors:
  - [abstract] "The calibration step ensures proper feature contribution measures"
  - [section] "K∑k=1 ∆˜µ(ti,k ) = ∆µ(ti)" and "We only calibrate this subset of features S(ti) = {k : sign(∆ˆµ(ti,k )) = sign(∆µ(ti))}"
- Break Condition: If the calibration function overfits to the training data or the estimated contributions have opposite signs to the actual change.

### Mechanism 3
- Claim: Feature importance calculation uses covariance between feature contribution and labels.
- Mechanism: The method calculates feature importance by taking the covariance between the feature contribution (which now accounts for deep layers) and the actual labels, following the relation MDI(k,F) = 1/|D| ∑i∈D yi fF,k(xi).
- Core assumption: The covariance between feature contribution and label represents the feature's importance in building the model.
- Evidence anchors:
  - [section] "Li et al. [Li+19] disclose that the original expression of MDI as Eq. (7) can be written as MDI(k,T ) = 1/|D| ∑i∈D fT,k(xi) · yi = Cov(fT,k(xi),yi)"
  - [section] "Equation (13) enables us to compute feature importance by summing over instances, decoupling the computation of feature contribution from the tree training process"
- Break Condition: If the feature contributions are biased or the labels are noisy, the covariance measure may not accurately reflect true importance.

## Architecture Onboarding

- Component map:
  - Training data with original features -> Cascade forest layers (multiple forests per layer) -> Feature contribution calculation (estimation + calibration) -> Feature importance calculation (covariance-based MDI) -> Interpretation output (contributions and importances)

- Critical path: Data → Deep Forest Training → Feature Contribution Calculation → Feature Importance Calculation → Interpretation

- Design tradeoffs:
  - Accuracy vs. interpretability: The method trades some predictive accuracy for interpretability by decomposing new feature splits.
  - Complexity vs. comprehensibility: The two-step process (estimation + calibration) is more complex but yields more interpretable results than simple accuracy-based methods.

- Failure signatures:
  - Calibration errors accumulating through layers
  - Poor decomposition of complex feature interactions
  - Overfitting to training data in the estimation step

- First 3 experiments:
  1. Verify feature contribution calculation on a simple two-feature regression problem where the data generating function is known.

## Limitations
- Dependency on accurate training data to trace feature influences through cascade layers
- Potential accumulation of estimation errors through multiple cascade layers
- Assumption that feature contributions can be linearly decomposed may not hold for complex non-linear interactions
