# Computing large deviation prefactors of stochastic dynamical systems based on machine learning

## Quick Facts
- arXiv ID: 2306.11418
- Source URL: https://arxiv.org/abs/2306.11418
- Reference count: 31
- Proposes neural network framework for computing large deviation prefactors in stochastic dynamical systems

## Executive Summary
This paper introduces a neural network framework for computing large deviation prefactors in stochastic dynamical systems, addressing a key limitation of the Freidlin-Wentzell theory which only provides exponential estimates. The method decomposes the vector field into components orthogonal to the gradient of the quasipotential, using a neural network to learn both the quasipotential and rotational component. This enables accurate computation of mean exit times via integration along most probable paths, with numerical experiments showing errors below 0.1% compared to Monte Carlo simulations.

## Method Summary
The approach involves decomposing the vector field into gradient and rotational components relative to the quasipotential. A neural network is trained to learn both the quasipotential function and the orthogonal rotational component simultaneously. This decomposition allows for accurate computation of mean exit times by integrating along the most probable escape paths. The method is validated on a two-dimensional toy model, demonstrating its ability to capture rare event dynamics with high accuracy for both non-characteristic and characteristic boundaries.

## Key Results
- Learned quasipotential closely matches true quasipotential in 2D case
- Mean exit time estimates align with Monte Carlo simulations within 0.1% error
- Method validated for both non-characteristic and characteristic boundary conditions
- Demonstrates effectiveness in capturing rare event dynamics

## Why This Works (Mechanism)
The method works by decomposing the vector field into gradient and rotational components relative to the quasipotential. This decomposition allows the neural network to learn the quasipotential function while simultaneously capturing the rotational component orthogonal to the gradient. By integrating along the most probable escape paths determined by this decomposition, the approach can accurately compute mean exit times that go beyond the exponential estimates provided by Freidlin-Wentzell theory.

- Failure signatures: Poor convergence of network training; significant deviation from Monte Carlo estimates; incorrect quasipotential landscape
