# Improving Reliability of Fine-tuning with Block-wise Optimisation

## Quick Facts
- arXiv ID: 2301.06133
- Source URL: https://arxiv.org/abs/2301.06133
- Reference count: 40
- Key outcome: Block-wise optimisation achieves better performance and lower variance than traditional fine-tuning methods

## Executive Summary
This paper introduces a novel block-wise optimisation mechanism for fine-tuning pre-trained models, addressing the challenge of limited data in domain-specific tasks. The approach adapts weights of groups of layers rather than individual layers or entire models, using four different methods for selecting blocks. Tested on the Tf_flowers dataset with five pre-trained models, the block-wise approach consistently outperforms traditional fine-tuning methods in terms of classification accuracy and reliability.

## Method Summary
The paper proposes a block-wise optimisation mechanism that groups layers of pre-trained models into blocks for weight adaptation during fine-tuning. Four selection methods are introduced: layer-wise fine-tuning, block-based segmentation, sliding window grouping, and top-ranked layer selection. The approach aims to improve reliability by reducing variance in performance while maintaining or improving accuracy. The method is tested on the Tf_flowers dataset using VGG16, MobileNet-v1, MobileNet-v2, MobileNet-v3, and ResNet50v2 architectures.

## Key Results
- Block-wise approaches consistently outperform baseline fine-tuning methods in classification accuracy
- The proposed methods demonstrate the lowest variance among all tested approaches, indicating improved reliability
- All five tested pre-trained models show performance gains when using block-wise optimisation
- The sliding window grouping method achieves particularly strong results across multiple metrics

## Why This Works (Mechanism)
The block-wise optimisation approach works by strategically grouping layers into blocks and adapting their weights collectively rather than individually. This grouping reduces the number of parameters being updated simultaneously, which helps prevent overfitting on limited data. By treating blocks of layers as units, the method preserves learned representations from pre-training while allowing domain-specific adaptation. The variance reduction occurs because the block structure imposes a regularisation effect, preventing extreme weight updates that can lead to unstable fine-tuning.

## Architecture Onboarding

Component map:
Pre-trained Model -> Block Selection Method -> Weight Adaptation -> Performance Evaluation

Critical path:
Data preprocessing -> Model loading -> Block formation -> Fine-tuning process -> Performance measurement

Design tradeoffs:
- Granularity of blocks (layer-wise vs larger blocks) affects adaptation flexibility vs stability
- Block selection method impacts computational efficiency and performance
- Number of blocks influences the balance between preserving pre-trained knowledge and allowing domain adaptation

Failure signatures:
- High variance across runs indicates instability in fine-tuning
- Performance worse than baseline suggests poor block selection or grouping
- Extremely low variance with poor accuracy indicates over-regularisation

First experiments:
1. Compare variance across multiple runs for different block sizes on a small dataset
2. Test block-wise optimisation on a single pre-trained model with varying block selection methods
3. Measure performance degradation when using too few vs too many blocks

## Limitations
- Experimental scope limited to a single fine-grained dataset and computer vision models
- No statistical significance testing to validate reliability improvements
- Absence of comparisons with established parameter-efficient fine-tuning methods
- Limited exploration of computational efficiency trade-offs

## Confidence

- Low confidence in the generalizability of results to other domains and architectures
