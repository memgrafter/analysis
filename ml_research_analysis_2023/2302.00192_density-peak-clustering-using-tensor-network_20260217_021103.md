# Density peak clustering using tensor network

## Quick Facts
- arXiv ID: 2302.00192
- Source URL: https://arxiv.org/abs/2302.00192
- Reference count: 0
- Primary result: Tensor network clustering achieves 100% accuracy on 5 synthetic datasets and 97.8% accuracy on MNIST

## Executive Summary
This paper introduces a novel tensor network-based density clustering algorithm that leverages quantum-inspired matrix product states to perform density-based clustering without requiring prior knowledge of cluster numbers. The method maps classical data into quantum states and uses fidelity measures instead of traditional distance metrics to define density and cluster relationships. The algorithm was evaluated across multiple datasets including synthetic, real-world, and computer vision benchmarks, demonstrating competitive performance with state-of-the-art clustering methods.

## Method Summary
The algorithm uses tensor networks to represent data points as quantum states, training matrix product states (MPS) to capture cluster features. Unlike classical density peak clustering that relies on Euclidean distance measures, this approach defines density through fidelity measures between quantum states. The tensor network structure automatically identifies cluster centers and assigns points based on local density and minimum distance to higher-density points. The method operates without requiring a predetermined number of clusters, making it suitable for unsupervised learning scenarios.

## Key Results
- Achieved 100% clustering accuracy on five synthetic datasets
- Obtained 97.8% accuracy and 94.0% normalized mutual information on MNIST
- Demonstrated competitive performance on Fashion-MNIST and USPS datasets
- Successfully clustered data without prior knowledge of cluster numbers

## Why This Works (Mechanism)
The method works by mapping classical data points into quantum states represented by tensor networks, where density and distance relationships are captured through fidelity measures between these quantum states. Matrix product states learn to encode cluster-specific features, allowing the algorithm to identify high-density regions and cluster boundaries through quantum mechanical principles rather than classical geometric distances. This quantum-inspired approach enables more nuanced representation of data relationships and automatic discovery of cluster structures.

## Foundational Learning
- **Tensor networks**: Mathematical frameworks for representing high-dimensional data; needed to map classical data into quantum states for density calculations
- **Matrix product states (MPS)**: Specific tensor network architecture that efficiently represents quantum states; required for capturing cluster features in polynomial time
- **Fidelity measures**: Quantum mechanical similarity metrics; used instead of Euclidean distance to define density and cluster relationships
- **Density peak clustering**: Classical clustering method based on local density and minimum distances; serves as conceptual foundation for the tensor network approach
- **Quantum state mapping**: Process of encoding classical data into quantum state representations; essential for leveraging quantum-inspired clustering

## Architecture Onboarding

### Component Map
Classical data -> Quantum state mapping -> Matrix Product State training -> Density calculation (fidelity) -> Cluster center detection -> Cluster assignment

### Critical Path
The critical path involves quantum state mapping followed by MPS training, as these steps establish the foundation for all subsequent density calculations and clustering decisions. The fidelity-based density calculations depend entirely on successful quantum state representation.

### Design Tradeoffs
The method trades computational complexity for expressive power, using tensor networks to capture complex data relationships at the cost of increased training requirements. The quantum-inspired approach sacrifices interpretability of classical distance measures for potentially better handling of complex cluster shapes.

### Failure Signatures
The algorithm may fail when data points cannot be effectively mapped to meaningful quantum states, particularly with high-dimensional or noisy real-world data. Poor performance could indicate insufficient tensor network training or inappropriate choice of network dimensions.
