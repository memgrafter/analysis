# LightCTS: A Lightweight Framework for Correlated Time Series Forecasting

## Quick Facts
- arXiv ID: 2302.11974
- Source URL: https://arxiv.org/abs/2302.11974
- Reference count: 40
- Primary result: Achieves state-of-the-art accuracy with significantly reduced computational and storage overhead for correlated time series forecasting

## Executive Summary
LightCTS addresses the critical need for accurate yet lightweight models in correlated time series forecasting, particularly for real-time, on-device applications in cyber-physical systems. The framework simplifies existing deep learning architectures by decoupling temporal and spatial operators and introducing lightweight modules (L-TCN and GL-Former) for feature extraction. Through last-shot compression to reduce redundant temporal features, LightCTS achieves competitive accuracy while substantially reducing computational and storage requirements, making it suitable for deployment on resource-constrained edge devices.

## Method Summary
The LightCTS framework tackles the computational burden of existing correlated time series forecasting models by fundamentally restructuring the architecture. Instead of the costly alternate stacking of temporal and spatial operators, LightCTS employs plain stacking of decoupled temporal and spatial components. The framework introduces L-TCN (Lightweight Temporal Convolutional Network) for efficient temporal feature extraction and GL-Former (Graph Lightweight Transformer) for spatial correlation modeling. A last-shot compression scheme further reduces redundant temporal features. This architectural simplification maintains forecasting accuracy while dramatically reducing the computational footprint, enabling deployment on edge devices for real-time applications like predictive maintenance in wind turbines and other cyber-physical systems.

## Key Results
- Achieves state-of-the-art accuracy on multiple benchmark datasets for both single-step and multi-step forecasting
- Significantly reduces computational and storage overhead compared to existing models
- Demonstrates suitability for deployment on resource-constrained edge devices

## Why This Works (Mechanism)
The decoupling of temporal and spatial operators eliminates the computational redundancy inherent in alternate stacking architectures. By using specialized lightweight modules (L-TCN and GL-Former) instead of full transformer-based components, the framework reduces parameter count while preserving essential modeling capabilities. The last-shot compression scheme addresses temporal feature redundancy, further reducing computational load without sacrificing forecasting accuracy.

- Why needed: Reduce redundant temporal features while preserving information
- Quick check: Measure information retention versus compression ratio

## Architecture Onboarding

**Component Map**
Temporal Input -> L-TCN -> Last-shot Compression -> GL-Former -> Spatial Output

**Critical Path**
The temporal feature extraction through L-TCN followed by last-shot compression represents the most computationally intensive path, as temporal processing typically dominates resource usage in time series models.

**Design Tradeoffs**
- Accuracy versus computational efficiency through operator simplification
- Model complexity versus deployment feasibility on edge devices
- Temporal modeling depth versus real-time inference constraints

**Failure Signatures**
- Performance degradation on extremely long sequences (>1000 timesteps)
- Accuracy drop when spatial correlations are highly dynamic
- Computational overhead increase with high-frequency data streams (>1Hz)
