# Enhancing Speech-to-Speech Translation with Multiple TTS Targets

## Quick Facts
- arXiv ID: 2304.04618
- Source URL: https://arxiv.org/abs/2304.04618
- Reference count: 0
- One-line primary result: Multi-TTS framework improves S2ST by 2.8 BLEU over single TTS baseline

## Executive Summary
This paper investigates how different synthesized target speech from various TTS systems affect direct speech-to-speech translation (S2ST) models. It finds that simply combining target speech from multiple TTS systems can improve S2ST performance. Building on this, the paper proposes a multi-task framework that jointly optimizes the S2ST system with multiple targets from different TTS systems. Experiments on the Fisher Spanish-English dataset show the proposed framework achieves consistent improvements of 2.8 BLEU over the best baseline system with a single TTS target.

## Method Summary
The method employs a direct speech-to-speech translation (S2ST) model based on the S2UT architecture, using discrete units generated from HuBERT representations via K-Means clustering as target outputs. The proposed multi-task framework extends this by incorporating multiple decoder branches, each trained on discrete units from different TTS systems (TT2, FS2, VITS). During training, a special token indicates whether each target sequence is the "best" choice for that utterance based on ASR CER. During inference, the model predicts which decoder branch to use for each input utterance, allowing selection of the most appropriate acoustic variant. The framework uses discrete units to normalize vocoder differences while preserving linguistic content.

## Key Results
- Combining target speech from different TTS systems improves S2ST performance
- Proposed multi-task framework achieves 2.8 BLEU improvement over best single TTS baseline
- Different vocoders (PWG, HFG, SMG) achieve similar S2ST performance despite varying CERs, suggesting HuBERT units normalize vocoder differences
- Special token mechanism enables effective selection between multiple TTS targets during inference

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using multiple TTS systems for target speech synthesis improves S2ST performance by providing diverse acoustic representations that help the model learn more robust linguistic mappings.
- Mechanism: Different TTS systems generate target speech with varying acoustic characteristics. These differences create multiple discrete unit sequences for the same linguistic content. The S2ST model learns to map source speech to a shared linguistic representation that is consistent across these different acoustic variants.
- Core assumption: The discrete units generated from different TTS systems preserve the same underlying linguistic content and can be aligned to a common representation.
- Evidence anchors: Abstract finding on combining TTS targets; Pearson correlation analysis showing shared linguistic content despite different distributions; corpus evidence is weak.

### Mechanism 2
- Claim: The proposed multi-task framework with special tokens improves S2ST by learning to select the optimal TTS target for each utterance.
- Mechanism: The framework adds decoder branches for each TTS system, with a special token indicating whether that TTS system is the "best" choice for that utterance. During inference, the model predicts which decoder branch to use for each input utterance.
- Core assumption: Different TTS systems perform better on different types of utterances, and the model can learn to predict which system will work best for a given input.
- Evidence anchors: Abstract description of multi-task framework; section detailing special token mechanism; corpus evidence is weak.

### Mechanism 3
- Claim: Speech discrete units help normalize vocoder differences, allowing S2ST models to focus on linguistic content rather than acoustic artifacts.
- Mechanism: When different TTS systems with different vocoders generate speech, the resulting waveforms have distinct acoustic properties. However, when converted to discrete units via HuBERT clustering, the vocoder differences are largely normalized, leaving representations that focus on linguistic content.
- Core assumption: The discrete unit representation is robust to differences in vocoder implementation and speaker characteristics, preserving linguistic information while discarding acoustic style.
- Evidence anchors: Table 1 showing similar S2ST performance despite different CERs; Pearson coefficient analysis showing high correlation between vocoder distributions; corpus evidence is weak.

## Architecture Onboarding

- Component map: Source speech → Encoder (Conformer-wav2vec2.0 initialized) → Decoder(s) → Discrete units → Unit-based vocoder → Target speech. Multiple decoder branches for different TTS targets, with special token for branch selection.
- Critical path: Source speech input → Encoder processing → Decoder branch selection (based on special token probability) → Unit sequence generation → Vocoder synthesis.
- Design tradeoffs: Multiple decoder branches increase model size and inference complexity but allow selection of optimal TTS target per utterance. Simple data combination is lighter but loses the selection capability.
- Failure signatures: BLEU scores plateau or degrade with additional TTS targets, special token predictions become unreliable (high entropy across branches), or training becomes unstable with multiple decoder branches.
- First 3 experiments:
  1. Train baseline S2UT model with single best TTS target (VITS 0.95 speed factor) to establish performance floor.
  2. Train S2UT with simple combination of two TTS targets (e.g., VITS + FS2) to verify data combination benefit.
  3. Implement and train the multi-task framework with two TTS targets to test the special token selection mechanism.

## Limitations
- Corpus size and domain limitations: Results are based on the relatively small Fisher Spanish-English dataset of telephone conversations, raising questions about generalizability to larger, more diverse corpora.
- TTS system variability assumptions: The paper assumes different TTS systems capture complementary linguistic information, but doesn't rigorously validate whether systems are capturing different linguistic features versus different acoustic renderings.
- Evaluation methodology concerns: Use of ASR-based BLEU scoring introduces potential measurement noise, and the paper doesn't establish an upper bound by reporting BLEU scores on reference transcripts.

## Confidence

**High confidence** in the observation that combining target speech from multiple TTS systems can improve S2ST performance, directly demonstrated with clear numerical evidence in Table 1.

**Medium confidence** in the proposed multi-task framework's effectiveness, as the 2.8 BLEU improvement relies on assumptions about utterance-level TTS quality variation and special token prediction effectiveness that aren't fully validated.

**Low confidence** in the generalizability of results, as the paper doesn't test the approach on languages other than Spanish-English, larger datasets, or different speech domains.

## Next Checks

1. **Corpus size scaling experiment**: Replicate the multi-TTS approach on a larger S2ST dataset (e.g., VAST or CoVoST 2) to verify whether the 2.8 BLEU improvement scales with more training data or if it's specific to the Fisher corpus size.

2. **Ablation on TTS selection mechanism**: Remove the special token prediction and instead use oracle selection (choosing the best TTS target for each utterance based on ground truth) to determine whether the 2.8 BLEU improvement is due to the multi-task framework or simply having multiple target options available.

3. **Linguistic feature analysis**: Conduct a systematic analysis of what linguistic features are preserved or lost across different TTS systems by examining the discrete unit distributions for specific linguistic phenomena (prosody, emphasis, rare words).
