# UAV Path Planning Employing MPC- Reinforcement Learning Method Considering Collision Avoidance
## Quick Facts
- arXiv ID: 2302.10669
- Source URL: https://arxiv.org/abs/2302.10669
- Reference count: 0
- Primary result: Combines LSTM-MPC with DDPG for UAV path planning in complex environments with static and dynamic obstacles, achieving 95.1% success rate in simulations

## Executive Summary
This paper proposes a novel approach to UAV path planning that integrates Model Predictive Control (MPC) with reinforcement learning to navigate complex environments containing both static and dynamic obstacles. The method combines a Long Short-Term Memory network-based MPC (LSTM-MPC) as a deterministic policy within a Deep Deterministic Policy Gradient (DDPG) framework. By utilizing a predicting pool to store future states and actions, the approach demonstrates improved robustness and real-time performance in collision avoidance scenarios. The proposed solution addresses the challenge of high-dimensional state spaces and dynamic obstacle avoidance, showing superior performance compared to standard DDPG and TD3 algorithms in numerical simulations.

## Method Summary
The proposed method combines LSTM-MPC with DDPG reinforcement learning for UAV path planning. The LSTM-MPC acts as a deterministic policy within the DDPG framework, utilizing a predicting pool to store future states and actions. This integration allows for improved prediction of future states and actions, enhancing the system's ability to handle dynamic obstacles. The LSTM component of the MPC helps in capturing temporal dependencies in the environment, while the DDPG framework provides the reinforcement learning capability to adapt to changing conditions. The method was evaluated through numerical simulations, demonstrating its effectiveness in achieving high success rates and faster convergence compared to standard DDPG and TD3 algorithms.

## Key Results
- Achieved success rates up to 95.1% in UAV path planning simulations
- Demonstrated faster convergence compared to standard DDPG and TD3 algorithms
- Effectively handled high-dimensional state spaces and dynamic obstacle avoidance

## Why This Works (Mechanism)
The proposed method works by combining the predictive capabilities of LSTM-MPC with the adaptive learning of DDPG reinforcement learning. The LSTM component of the MPC captures temporal dependencies in the environment, allowing for more accurate predictions of future states. This is particularly useful in dynamic environments where obstacles may move unpredictably. The DDPG framework then uses these predictions to learn an optimal policy for navigating through the environment. The integration of a predicting pool to store future states and actions further enhances the system's ability to plan ahead and make more informed decisions. This combination of predictive control and reinforcement learning allows the UAV to adapt to changing conditions while maintaining real-time performance constraints.
