# Manipulating Federated Recommender Systems: Poisoning with Synthetic Users and Its Countermeasures

## Quick Facts
- arXiv ID: 2304.03054
- Source URL: https://arxiv.org/abs/2304.03054
- Authors: Multiple researchers
- Reference count: 40
- Primary result: Novel poisoning attack (PSMU) and defense (HiCS) for federated recommender systems with experimental validation on real-world datasets

## Executive Summary
This paper addresses the critical security challenge of poisoning attacks in federated recommender systems (FedRecs), where malicious users can manipulate recommendations by uploading poisoned gradients. The authors propose a new attack method called PSMU that generates synthetic malicious users to optimize target items' rankings through similarity-based optimization with real users' preferences. Additionally, they introduce HiCS, a defense mechanism that combines hierarchical gradient clipping with sparsified updating to mitigate poisoning attacks. Extensive experiments demonstrate that PSMU outperforms state-of-the-art attacks in effectiveness while requiring fewer malicious users and global training epochs.

## Method Summary
The paper introduces PSMU (Poisoning with Synthetic Malicious Users), a novel attack method that generates synthetic malicious users to optimize target items' ranks by leveraging the similarity between synthetic and real users' top-K recommendations. PSMU employs an iterative optimization strategy that alternates between updating synthetic user profiles and optimizing recommendation gradients. The defense mechanism, HiCS (Hierarchical Clipping and Sparsification), combines hierarchical gradient clipping with sparsified updating to defend against poisoning attacks by reducing the impact of malicious gradients while preserving useful information for model training.

## Key Results
- PSMU effectively promotes target items with fewer malicious users compared to state-of-the-art attacks
- PSMU achieves better performance with fewer global training epochs
- HiCS defense successfully mitigates all existing poisoned gradient attacks on FedRecs
- Experimental validation conducted on two widely used FedRecs across two real-world datasets

## Why This Works (Mechanism)
The PSMU attack works by generating synthetic malicious users whose preferences are optimized to maximize similarity with real users' top-K recommendations while simultaneously promoting target items. This approach exploits the federated learning aggregation mechanism by making the poisoned gradients appear legitimate and beneficial for the overall model. The HiCS defense works by applying hierarchical gradient clipping to bound the impact of potentially malicious updates, followed by sparsified updating that selectively incorporates only the most trustworthy gradient information, thereby reducing the effectiveness of poisoning attacks.

## Foundational Learning

1. **Federated Recommender Systems (FedRecs)**: Decentralized machine learning framework where user devices collaboratively train recommendation models without sharing raw data. Needed to understand the distributed learning context and attack surface.

2. **Gradient Poisoning Attacks**: Malicious manipulation of model updates during federated learning by uploading poisoned gradients. Quick check: Verify how gradients are aggregated and whether there are validation mechanisms.

3. **Synthetic User Generation**: Creation of artificial user profiles designed to optimize specific attack objectives. Quick check: Validate whether synthetic users can bypass detection mechanisms.

4. **Hierarchical Gradient Clipping**: Multi-level approach to bounding gradient updates based on different trust levels or sensitivity. Quick check: Confirm that clipping doesn't degrade legitimate model updates.

5. **Sparsified Updating**: Selective incorporation of gradient information based on trustworthiness or importance. Quick check: Ensure that sparsification doesn't discard critical learning signals.

## Architecture Onboarding

Component map: Client devices -> Local model updates -> Server aggregation -> Global model -> Client devices

Critical path: Synthetic user generation → Local gradient computation → Server aggregation → Model poisoning → Recommendation manipulation

Design tradeoffs: The PSMU attack trades computational overhead for attack effectiveness, while HiCS trades some model accuracy for security. The hierarchical approach in HiCS balances between being too permissive (vulnerable to attacks) and too restrictive (hindering legitimate updates).

Failure signatures: For PSMU, failure manifests as reduced promotion of target items or detection of synthetic user patterns. For HiCS, failure appears as successful poisoning attacks or degraded recommendation quality for legitimate users.
