# Optimal Approximation Complexity of High-Dimensional Functions with Neural Networks
## Quick Facts
- arXiv ID: 2301.13091
- Source URL: https://arxiv.org/abs/2301.13091
- Reference count: 22
- Neural networks with ReLU and x² activations achieve optimal approximation complexity for high-dimensional functions

## Executive Summary
This work establishes that neural networks combining ReLU and x² activation functions can optimally approximate high-dimensional smooth functions, achieving the theoretically minimal parameter complexity of O(ǫ⁻ᵈ/ⁿ) for accuracy ǫ. The key insight is using ReLU layers to partition input space and x² layers to efficiently compute localized high-degree polynomial approximations, avoiding the logarithmic depth penalty of ReLU-only networks. The results extend to analytic functions and functions supported on low-dimensional subspaces, effectively overcoming the curse of dimensionality in these settings.

## Method Summary
The paper develops a theoretical framework for analyzing neural network approximation complexity by introducing a mixed activation architecture. ReLU layers create adaptive partitions of the input space, while x² layers compute high-degree polynomial approximations within each partition. This combination achieves optimal parameter scaling by avoiding the depth penalty inherent in ReLU-only constructions while maintaining computational efficiency. The analysis proves matching upper and lower bounds for smooth, analytic, and low-dimensional functions.

## Key Results
- Neural networks with ReLU+x² activations achieve optimal O(ǫ⁻ᵈ/ⁿ) parameter complexity for smooth functions
- Analytic functions can be approximated with O(ǫ⁻ᵈ/² logᵈ/²(1/ǫ)) parameters
- Functions on low-dimensional subspaces achieve O(ǫ⁻ᵈᵉᶠᶠ/ⁿ) parameter complexity
- Results establish matching upper and lower bounds, proving optimality

## Why This Works (Mechanism)
The mixed activation architecture exploits the complementary strengths of ReLU and x² activations. ReLU layers efficiently partition the input space into regions where the function behaves smoothly, while x² layers compute high-degree polynomial approximations within each region. This avoids the exponential growth in parameters that would be required for global polynomial approximation in high dimensions. The construction ensures that the total number of parameters scales optimally with both the approximation accuracy and the intrinsic dimensionality of the function.

- **ReLU network limitations**: Pure ReLU networks face depth-dependent penalties in approximation; quick check: compare ReLU-only vs mixed activation scaling
- **Space partitioning**: Adaptive partitioning of input space enables localized approximation; quick check: confirm partition efficiency matches theoretical predictions

## Architecture Onboarding
- **Component map**: Input -> ReLU layers (space partitioning) -> x² layers (polynomial approximation) -> Output
- **Critical path**: The sequence of ReLU and x² layers forms the essential computational pathway for achieving optimal approximation
- **Design tradeoffs**: Mixed activation provides optimal scaling but requires careful coordination between partitioning and approximation layers; ReLU-only is simpler but suboptimal
- **Failure signatures**: Poor performance indicates either inadequate partitioning (ReLU layers too shallow) or insufficient approximation degree (x² layers too shallow)
