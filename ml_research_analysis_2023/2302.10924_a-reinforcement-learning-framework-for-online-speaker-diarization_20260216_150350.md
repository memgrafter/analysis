# A Reinforcement Learning Framework for Online Speaker Diarization

## Quick Facts
- arXiv ID: 2302.10924
- Source URL: https://arxiv.org/abs/2302.10924
- Reference count: 40
- This paper proposes a reinforcement learning framework for online speaker diarization, enabling real-time multi-speaker identification without prior registration or pretraining

## Executive Summary
This paper introduces a novel reinforcement learning framework for online speaker diarization that treats speaker identification as a real-time decision-making problem. The system learns to detect speaker identities dynamically through reward feedback, combining traditional components like embedding extraction, clustering, and resegmentation into a single adaptive system. The approach is particularly valuable for teleconferencing scenarios with dynamic participants and unknown speaker counts. The authors propose using RL to overcome limitations of traditional supervised approaches that require extensive pretraining and registration.

## Method Summary
The framework formulates speaker diarization as a Markov Decision Process where an RL agent makes online decisions about speaker identity assignments. The agent receives audio segments as states, selects speaker labels as actions, and learns through reward feedback. The system integrates embedding extraction, clustering, and resegmentation modules within the RL framework, using Q-learning with epsilon-greedy exploration. A key innovation is the extendable action space that starts with a single "new" action and dynamically expands as new speakers are identified, modeled as a bandit problem with infinitely many arms.

## Key Results
- Proposes the first RL approach applied to speaker diarization
- Enables real-time speaker identification without prior registration or pretraining
- Combines embedding extraction, clustering, and resegmentation into a single adaptive system
- Demonstrates proof of concept through a desktop application

## Architecture Onboarding

- Component map:
  Audio input -> Feature extractor (MFCC, embeddings) -> RL agent -> Speaker label output
  - Reward feedback loop (user or model-based)
  - Optional: Clustering and resegmentation modules integrated into RL decision-making

- Critical path: Audio feature extraction -> RL decision making -> Speaker label assignment -> Reward feedback -> Policy update

- Design tradeoffs:
  - Real-time performance vs. accuracy: More complex RL models may improve accuracy but increase latency
  - Exploration vs. exploitation: Need to balance trying new speaker assignments against sticking with known identities
  - Model complexity vs. training data: Deep RL approaches offer better performance but require more computational resources

- Failure signatures:
  - High error rate in speaker transitions indicates poor exploration strategy
  - System freezing or slow response suggests computational bottlenecks in feature extraction or RL decision making
  - Persistent incorrect speaker assignments indicate reward signal issues or insufficient exploration
