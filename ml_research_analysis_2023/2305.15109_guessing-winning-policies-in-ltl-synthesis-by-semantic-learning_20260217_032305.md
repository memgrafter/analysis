# Guessing Winning Policies in LTL Synthesis by Semantic Learning

## Quick Facts
- arXiv ID: 2305.15109
- Source URL: https://arxiv.org/abs/2305.15109
- Reference count: 40
- Primary result: Semantic labeling enables 85-95% immediate win rates in LTL synthesis

## Executive Summary
This paper introduces a machine learning approach for predicting winning strategies in LTL synthesis by leveraging semantic labeling from LTL-to-automata translations. The method extracts over 200 structural features from semantic labels to capture subgoal information and temporal structure, then uses MCTS and SVM classifiers to predict promising moves in parity games. Experimental results demonstrate significant improvements over previous trueness-based approaches, with the method achieving 85-95% immediate win rates on complex benchmarks while providing effective guidance when integrated with the Strix synthesis tool.

## Method Summary
The approach extracts over 200 structural features from semantic labeling of LTL formulas, capturing subgoal relationships and temporal structure through labels like "trans" and "final". These features are used with Monte Carlo Tree Search to approximate edge values in the game tree, and Support Vector Machine classifiers predict which edges are most promising for reaching winning states. The method trains on both synthesized instances and handcrafted benchmarks, evaluating performance through immediate win rates and comparison with previous trueness-based guessing strategies.

## Key Results
- Achieves 85-95% immediate win rates on complex benchmarks
- Significantly outperforms previous trueness-based approaches
- Provides effective guidance that speeds up solving when integrated with Strix
- Requires fewer corrections to recommended strategies compared to baseline methods

## Why This Works (Mechanism)
The semantic labeling captures subgoal relationships and temporal structure that Boolean trueness labels miss. By incorporating labels like "trans" and "final" from the automaton structure, the model can reason about the temporal progression required to satisfy the specification rather than just local trueness values. This structural information enables the learning algorithm to identify promising paths through the game tree that align with the underlying temporal logic requirements.

## Foundational Learning
- LTL synthesis and parity games: Understanding the connection between linear temporal logic specifications and two-player games is fundamental to the problem domain
- Semantic labeling in automata: Labels like "trans" and "final" encode structural information about the automaton's behavior that can guide strategy selection
- Monte Carlo Tree Search: Used to approximate edge values in the game tree when exact computation is infeasible
- Support Vector Machines for classification: Chosen for their effectiveness in high-dimensional feature spaces with limited training data
- Feature engineering from automata structure: Extracting over 200 features requires understanding how automaton components relate to temporal properties

## Architecture Onboarding
Component map: LTL formula -> LTL-to-automata translator -> Semantic labeling -> Feature extraction (200+ features) -> MCTS edge value approximation -> SVM classifier -> Strategy prediction

Critical path: The semantic labeling and feature extraction pipeline is critical, as missing or incomplete labels directly impact the quality of strategy predictions. The MCTS component must efficiently handle the game tree structure while the SVM classifiers must generalize well from limited training data.

Design tradeoffs: The choice of SVM over more complex models balances computational efficiency with the need to handle high-dimensional feature spaces. The reliance on external LTL-to-automata translators introduces dependencies but leverages existing optimized tools.

Failure signatures: Poor semantic labeling quality manifests as reduced win rates and increased strategy corrections. Overly complex features may cause overfitting, while insufficient features limit the model's ability to capture temporal structure.

First experiments: 1) Benchmark different LTL-to-automata translators to assess impact on labeling quality, 2) Perform ablation studies removing feature categories to identify most valuable semantic information, 3) Test the approach on formulas outside the training distribution to evaluate generalization.

## Limitations
- Performance heavily dependent on quality and completeness of semantic labeling from external translators
- May not fully capture complex temporal relationships despite semantic features
- Architectural mismatches with Strix limit integration effectiveness
- Focus on comparison with trueness-based methods rather than exploring alternative feature engineering approaches
