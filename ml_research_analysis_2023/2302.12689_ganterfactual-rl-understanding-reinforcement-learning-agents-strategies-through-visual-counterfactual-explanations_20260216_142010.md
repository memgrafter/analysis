# GANterfactual-RL: Understanding Reinforcement Learning Agents' Strategies through Visual Counterfactual Explanations

## Quick Facts
- arXiv ID: 2302.12689
- Source URL: https://arxiv.org/abs/2302.12689
- Reference count: 40
- Key outcome: GANterfactual-RL achieves 46-70% validity (vs 17-28% for CSE) and 1.65/3 understanding score in user study (vs 0.80/3 for no explanations)

## Executive Summary
This paper introduces GANterfactual-RL, a novel approach for generating counterfactual explanations for reinforcement learning agents with visual input. The method reformulates the counterfactual explanation problem as a domain transfer task using StarGAN, making it model-agnostic and simpler to train than previous methods. The approach is evaluated on Atari games, showing significant improvements over the previous CSE method in computational metrics (validity, proximity, sparsity, generation time) and demonstrating effectiveness in helping users understand agent strategies through a user study.

## Method Summary
GANterfactual-RL generates counterfactual explanations by formulating the problem as a domain transfer task using StarGAN architecture. The method takes preprocessed Atari frames (cropped RGB frames before agent preprocessing) and state-action pairs from trained RL agents as input. The StarGAN-based architecture incorporates adversarial loss, classification loss, and reconstruction loss to generate counterfactual examples that change agent actions while maintaining proximity to the original state. The approach is model-agnostic and simpler to train than previous methods. Evaluation uses metrics including validity (success rate), proximity, sparsity, and generation time, along with user study metrics measuring agent understanding, trust calibration, and satisfaction.

## Key Results
- GANterfactual-RL achieves 46-70% validity compared to 17-28% for CSE method
- User study shows 1.65/3 understanding score vs 0.80/3 for no explanations and 1.18/3 for CSE
- Computational evaluation demonstrates improvements across all metrics including generation time
- Explanations help understand agent strategies but do not improve trust calibration or satisfaction

## Why This Works (Mechanism)
The approach works by reframing counterfactual generation as a domain transfer problem, leveraging StarGAN's ability to translate between different visual domains. By treating counterfactuals as translations from one action domain to another, the method can generate diverse, valid counterfactuals efficiently. The combination of adversarial, classification, and reconstruction losses ensures that generated counterfactuals not only change the agent's action but also maintain visual similarity and action specificity. This formulation is particularly effective for visual RL agents where traditional perturbation-based methods struggle with high-dimensional image spaces.
