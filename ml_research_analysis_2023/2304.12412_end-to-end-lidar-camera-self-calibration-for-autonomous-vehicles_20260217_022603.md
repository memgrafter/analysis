# End-to-End Lidar-Camera Self-Calibration for Autonomous Vehicles

## Quick Facts
- **arXiv ID:** 2304.12412
- **Source URL:** https://arxiv.org/abs/2304.12412
- **Reference count:** 24
- **Key outcome:** End-to-end deep learning approach for joint intrinsic camera and extrinsic Lidar-camera calibration achieving 0.154° rotation and 0.059 m translation accuracy on KITTI dataset

## Executive Summary
This paper presents CaLiCaNet, an end-to-end deep learning approach for joint intrinsic camera and extrinsic Lidar-camera calibration. The network jointly predicts camera focal length and distortion parameters, along with Lidar-camera rotation and translation, by regressing feature correlations between camera images and Lidar point clouds. The architecture uses a Siamese-twin structure to constrain learning to mutually shared features, enforcing Lidar-camera alignment.

## Method Summary
CaLiCaNet uses a Siamese-twin network architecture that processes camera images and Lidar point clouds in parallel streams. The model extracts multi-scale features from both modalities and correlates them to predict six degrees of freedom for extrinsic calibration (rotation and translation) and three parameters for intrinsic camera calibration (focal length and distortion). The network is trained end-to-end on the KITTI dataset, learning to minimize reprojection error between projected Lidar points and image features. The Siamese structure enforces shared feature learning between modalities, while the correlation layer captures geometric correspondences necessary for accurate calibration.

## Key Results
- Achieves 0.154° rotation accuracy and 0.059 m translation accuracy
- Demonstrates 0.028 pixels reprojection error in single inference pass
- Ablation study shows 21% reduction in rotation loss with end-to-end training

## Why This Works (Mechanism)
The Siamese-twin architecture enables mutual feature learning between camera and Lidar modalities, creating shared representations that capture geometric correspondences. By regressing feature correlations rather than using explicit feature matching, the network learns implicit calibration relationships that generalize across different scenes. The end-to-end training allows gradient flow through both intrinsic and extrinsic calibration parameters, optimizing them jointly rather than in isolation.

## Foundational Learning
- **Siamese Networks:** Dual-stream architectures that learn shared feature representations - needed for modality alignment, check by verifying shared weights
- **Feature Correlation Layers:** Operations that compute similarity between feature maps - needed for geometric correspondence, check by examining correlation outputs
- **End-to-End Training:** Joint optimization of all network parameters - needed for mutual parameter refinement, check by monitoring loss convergence
- **Reprojection Error:** Distance between projected 3D points and 2D image features - needed for calibration accuracy metric, check by calculating pixel distances
- **Intrinsic Camera Parameters:** Focal length and distortion coefficients - needed for accurate projection, check by validating undistorted images

## Architecture Onboarding
- **Component Map:** Camera Image -> Feature Extractor -> Correlation Layer -> Calibration Regressor; Lidar Point Cloud -> Feature Extractor -> Correlation Layer -> Calibration Regressor
- **Critical Path:** Siamese feature extraction -> Correlation computation -> Parameter regression -> Reprojection error calculation
- **Design Tradeoffs:** Siamese structure provides modality alignment but increases parameter count; end-to-end training enables joint optimization but requires more complex loss functions
- **Failure Signatures:** High reprojection error indicates feature misalignment; inconsistent parameter predictions suggest correlation layer issues
- **First Experiments:** 1) Verify feature extractor outputs have matching dimensions, 2) Test correlation layer with synthetic correspondences, 3) Validate parameter regression on known calibration scenarios
