# Multi-Value Alignment in Normative Multi-Agent System: Evolutionary Optimisation Approach

## Quick Facts
- arXiv ID: 2305.07366
- Source URL: https://arxiv.org/abs/2305.07366
- Reference count: 40
- This paper proposes a multi-value promotion model using multi-objective evolutionary algorithms to produce an optimum parametric set of norms aligned with multiple simultaneous values of heterogeneous agents and the system.

## Executive Summary
This paper addresses the challenge of incorporating effective norms for single value alignment while considering agents' heterogeneity and the requirement of simultaneous promotion and alignment of multiple values. The authors formulate this problem as a multi-objective optimization problem and solve it using multi-objective evolutionary algorithms (MOEAs). The proposed model, NAO (Norm Alignment Optimizer), enables the alignment of independent sets of norms and values in normative multi-agent systems by treating norms as decision variables and values as objectives to be optimized. The model is evaluated using different scenarios, measuring the effect of using different combinations of values.

## Method Summary
The method involves formulating multi-value alignment as a multi-objective optimization problem where norms are defined as parametric norms with various parameters (tax rate, redistribution rate, catch rate, fine) and values are expressed as objective functions (equality, fairness, wealth, gained amount, collect portion). The NAO model uses MOEAs (NSGA-II, MOEA/DD, SPEA2, MOMBI2) to find Pareto-optimal solutions that represent trade-offs across multiple objectives. The approach is evaluated using a tax toy scenario with heterogeneous agents divided into wealth groups, where the optimization process searches for norm parameter values that best promote the desired values across all agent groups.

## Key Results
- MOEAs successfully find Pareto-optimal norm parameter sets that balance multiple values simultaneously
- Algorithm performance varies significantly: NSGA-II and MOEA/DD perform best for 2-objective problems, while SPEA2 outperforms others for 5-objective problems
- Selecting different evolutionary algorithms impacts the solution quality and trade-off relationships between values
- Understanding the relationship between values is crucial when prioritizing them in the optimization process

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multi-objective evolutionary algorithms (MOEAs) enable simultaneous optimization of multiple values regardless of their compatibility.
- Mechanism: The NAO model transforms each value (e.g., equality, fairness, wealth) into a separate objective function within a multi-objective optimization problem. MOEAs then search for solutions (sets of norm parameters) that represent Pareto-optimal trade-offs across all objectives.
- Core assumption: Values can be quantified and expressed as objective functions that can be optimized by evolutionary algorithms.
- Evidence anchors:
  - [abstract] "uses multi-objective evolutionary algorithms to produce the optimum parametric set of norms that is aligned with multiple simultaneous values"
  - [section] "we formalised the problem as a multi-objective optimization problem (MOP), in which we represented the values by objectives that need optimization, and modeled the norms as the decision variables."

### Mechanism 2
- Claim: Parameterized norms allow heterogeneous agents to have different norm values while optimizing for shared system values.
- Mechanism: Norms are defined with parameters (e.g., tax rate per wealth group) that can take different values for different agent groups. The optimization process finds parameter values that best align with the value objectives across all groups.
- Core assumption: The same norm structure can be parameterized to accommodate different agent groups' needs.
- Evidence anchors:
  - [section] "normals are defined as parametric norms, i.e. each norm nj has a set of parameters Pnj that can contain unbounded or constrained elements"
  - [section] "Although [19] overcomes this by defining parameterized norms that enable each heterogeneous group to have its own norm"

### Mechanism 3
- Claim: Separating norms and values as independent sets enables alignment without assuming direct correspondence.
- Mechanism: NAO treats norms as decision variables and values as objectives, allowing the optimization to discover how norm parameters should be set to promote desired values without presupposing a direct mapping.
- Core assumption: Norms and values can be independently defined and later aligned through optimization.
- Evidence anchors:
  - [abstract] "align independent sets of norms and values in NorMAS"
  - [section] "by defining the norms set as the decision variables set in the MOP and the values set as the objectives to be optimised NAO was able to separate the concept of norms and values"

## Architecture Onboarding

- Component map:
  - Regulative agent: Initializes norms, runs optimization, communicates results
  - Regular agents: Execute actions based on adopted norms, contribute to global state
  - MOEA engine: Performs multi-objective optimization to find Pareto-optimal norm parameters
  - Value functions: Calculate objective values from global state
  - Communication layer: Handles norm parameter updates between regulative and regular agents

- Critical path:
  1. Initialize norm parameters and agent properties
  2. Simulate agent actions and update global state
  3. Calculate value objective functions
  4. Run MOEA to optimize norm parameters
  5. Update agents with new norm parameters
  6. Repeat until convergence or stopping condition

- Design tradeoffs:
  - Parameter granularity vs. computational complexity
  - Number of objectives vs. algorithm performance (NSGA-II handles 2 objectives better than 5)
  - Online vs. offline optimization (current model is offline)

- Failure signatures:
  - MOEA converges to dominated solutions (MOMBI2 performance issues)
  - Pareto front becomes disconnected or sparse
  - Optimization fails to improve value objectives over iterations
  - Communication delays cause state inconsistencies

- First 3 experiments:
  1. Run NAO with 2 objectives (equality, fairness) using NSGA-II and verify convergence
  2. Add a third objective (wealth) and compare NSGA-II vs MOEA/DD performance
  3. Test parameterized norms with heterogeneous agent groups and validate different norm values per group

## Limitations
- Limited validation to a simplified tax scenario with predefined agent heterogeneity
- Offline optimization approach requiring periodic norm updates rather than continuous adaptation
- Simplified agent model that may not capture complex decision-making behaviors

## Confidence
- High confidence in the mathematical formulation and separation of norms as decision variables from values as objectives
- Medium confidence in practical applicability due to limited validation across diverse domains
- Low confidence in computational efficiency for large-scale systems and real-time applications
