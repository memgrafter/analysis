# ReadProbe: A Demo of Retrieval-Enhanced Large Language Models to Support Lateral Reading
## Quick Facts
- arXiv ID: 2306.07875
- Source URL: https://arxiv.org/abs/2306.07875
- Reference count: 22
- Won first prize in national AI misinformation hackathon

## Executive Summary
ReadProbe is a tool that uses large language models and web search to support lateral reading for evaluating online information credibility. The system generates questions about user-provided text, searches for relevant documents, and generates well-attributed answers to help assess credibility. A web-based demo application is provided as part of this work.

## Method Summary
ReadProbe combines question generation with web search functionality to support lateral reading practices. The system takes user-provided text, generates relevant questions, performs web searches to find supporting documents, and produces attributed answers that can help users evaluate the credibility of the original information. The approach won first prize in a national AI misinformation hackathon.

## Key Results
- First prize winner in national AI misinformation hackathon
- Web-based demo application available for lateral reading support
- Combines question generation with web search for information assessment

## Why This Works (Mechanism)
The approach works by leveraging large language models to generate probing questions about provided content, then using web search to find relevant documents that can help answer these questions. This creates a systematic process for lateral reading, where users can evaluate information credibility by examining external sources rather than just the original content.

   - Why needed: Guides the lateral reading process and identifies key verification points

## Architecture Onboarding
Component map: User Input -> Question Generator -> Web Search -> Answer Generator -> Output
Critical path: User provides text → System generates questions → Web search retrieves documents → System generates attributed answers
Design tradeoffs: Real-time web search vs. response speed, comprehensive coverage vs. focused verification
Failure signatures: Hallucination of sources, outdated information from search, irrelevant question generation
First experiments:
1. Test question generation accuracy on sample texts
2. Verify web search returns relevant documents for generated questions
3. Validate attribution accuracy in generated answers
