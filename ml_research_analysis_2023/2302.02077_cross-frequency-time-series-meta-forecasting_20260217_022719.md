# Cross-Frequency Time Series Meta-Forecasting

## Quick Facts
- arXiv ID: 2302.02077
- Source URL: https://arxiv.org/abs/2302.02077
- Reference count: 22
- Primary result: CFA model significantly outperforms LSTM and NBEATS baselines in frequency generalization tasks

## Executive Summary
This paper introduces the Continuous Frequency Adapter (CFA), a novel approach for frequency generalization in time series meta-forecasting. The model addresses the challenge of training on time series data with known frequencies and generalizing to unseen frequencies at test time. CFA leverages continuous domain adaptation through adversarial training and Fourier transform analysis to create frequency-invariant representations while maintaining forecasting accuracy. The method shows substantial improvements over baseline models on both synthetic sinusoidal data and real-world datasets with different sampling frequencies.

## Method Summary
CFA uses continuous domain adaptation to adapt to new sampling frequencies in time series forecasting. The model extracts signal frequencies via FFT and uses them to define continuous domain indices. During training, a discriminator predicts these frequencies from the encoded representations, while the encoder and decoder are trained to minimize forecasting error. The adversarial setup forces the encoder to produce frequency-invariant keys and queries while allowing values to retain frequency-specific information. This architecture enables CFA to generalize to unseen frequencies during testing without requiring retraining.

## Key Results
- CFA achieves significantly lower MSE on synthetic data compared to LSTM and NBEATS baselines when generalizing to unseen frequencies
- On real-world datasets (elec, uber, tourism_monthly, tourism_quarterly), CFA shows improved Normalized Deviation compared to baseline models
- The model successfully transfers knowledge across different frequency domains (hourly to monthly, daily to quarterly)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Continuous domain adaptation via adversarial training enforces frequency-invariant hidden states
- Mechanism: CFA uses a discriminator that predicts top k frequencies from FFT amplitudes, forcing the encoder to produce frequency-invariant keys and queries
- Core assumption: Attention weights can capture signal phase independent of frequency while values contain frequency-specific information
- Evidence: [abstract] CFA uses continuous domain adaptation to adapt to new sampling frequencies; [section] The adversarial setup trains D to minimize Ld while E and F minimize forecasting loss and maximize Ld

### Mechanism 2
- Claim: Using continuous domain indices from FFT allows generalization to unseen frequencies
- Mechanism: Instead of discrete frequency buckets, CFA uses continuous domain indices derived from FFT period lengths
- Core assumption: Seasonal time series of different frequencies appear similar, enabling transferable representations
- Evidence: [abstract] CFA uses continuous domain indices obtained from Fourier transform; [section] Unlike DAF, CFA outputs continuous responses matching continuous domain index

### Mechanism 3
- Claim: Separating frequency-invariant keys/queries from frequency-specific values enables effective forecasting
- Mechanism: Self-attention uses frequency-invariant keys and queries for attention weighting while values retain frequency-specific information
- Core assumption: Attention weights can be frequency-invariant while capturing temporal relationships needed for forecasting
- Evidence: [section] Keys and queries generate attention weights capturing signal phase independent of frequency; values learn frequency-dependent information

## Architecture Onboarding

- Component map: Encoder (MLP + conv layers) -> Self-attention (keys/queries to discriminator, all to values) -> Decoder (MLP) -> Forecast loss; Discriminator (MLP) -> Frequency prediction loss

- Critical path: Encoder processes input -> generates keys, queries, values -> self-attention block uses frequency-invariant keys/queries for attention weights while all components contribute to values -> decoder generates forecast -> forecast loss computed; simultaneously discriminator predicts frequencies from keys/queries

- Design tradeoffs:
  - Continuous vs discrete frequency indices: Continuous allows handling any frequency within range but requires more sophisticated discriminator
  - Frequency-invariant vs frequency-specific components: Balances generalization with specificity
  - Adversarial training complexity vs performance: Adds training complexity but enables frequency generalization

- Failure signatures:
  - Poor performance on unseen frequencies despite good source performance: Indicates discriminator isn't effectively enforcing frequency invariance
  - Training instability or slow convergence: Common with adversarial training; may need learning rate adjustments
  - Values becoming too frequency-specific: May indicate need to adjust the adversarial loss weighting

- First 3 experiments:
  1. Train CFA on synthetic data with one frequency range and test on a slightly different frequency range to verify basic functionality
  2. Compare CFA performance against LSTM baseline on the same synthetic data setup to validate the frequency generalization improvement
  3. Test CFA on real-world datasets with different frequencies (e.g., elec → tourism_monthly) to verify cross-frequency transfer on practical data

## Limitations
- Core mechanism assumes attention weights can be made frequency-invariant while capturing temporal patterns, but this is not empirically validated
- Evaluation only compares against basic baselines (LSTM, NBEATS) without testing against more sophisticated frequency generalization approaches
- Synthetic data uses simple sinusoidal signals that may not capture real-world time series complexity
- Adversarial training component introduces additional complexity and potential training instability not thoroughly discussed

## Confidence

- Mechanism 1 (adversarial frequency invariance): Medium - theoretical framework is sound but lacks direct empirical validation
- Mechanism 2 (continuous domain indices): Medium - approach is novel but boundaries of generalization capability unexplored
- Performance claims: Medium - significant improvements shown but only against basic baselines

## Next Checks
