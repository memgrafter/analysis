# Have Large Language Models Developed a Personality?: Applicability of Self-Assessment Tests in Measuring Personality in LLMs

## Quick Facts
- arXiv ID: 2305.14693
- Source URL: https://arxiv.org/abs/2305.14693
- Reference count: 40
- Key outcome: Self-assessment personality tests designed for humans fail to reliably measure personality in LLMs due to lack of option-order symmetry and inherent model biases that cause fixation on single responses regardless of situational context.

## Executive Summary
This study investigates whether traditional self-assessment personality tests, which measure human personality traits using the Big Five (OCEAN) framework, can be applied to Large Language Models (LLMs). The researchers propose option-order symmetry as a necessary condition for valid personality measurement and test five LLMs ranging from 1.5B to 30B parameters using the MPI-1K dataset. Their findings reveal that while some models exhibit option-order symmetry, they consistently choose the same response regardless of the situational statement, indicating that self-assessment tests are unreliable for measuring LLM personality. The study identifies inherent biases in LLMs as the root cause of this phenomenon and suggests developing new tools specifically designed for machine personality evaluation.

## Method Summary
The study uses the MPI-1K dataset containing 1K self-assessment questions across the five OCEAN personality traits. Five LLMs (GPT2-XL-1.5B, GPT-Neo-2.7B, GPT-NeoX-20B, OPT-13B, OPT-30B) are tested using two template types: MCP-I NDEXED (with option indices) and MCP-N ON-I NDEXED (without indices). The researchers administer personality tests using beam search for multiple-choice question answering, then analyze option-order symmetry by reversing and shuffling option orders. They also identify content-free template biases and recalibrate outputs using content-free probabilities to isolate inherent model biases.

## Key Results
- LLMs exhibit option-order symmetry in some cases but consistently select the same response regardless of situational context
- Inherent biases in LLMs cause fixation on specific response options, making self-assessment tests unreliable
- Traditional human-designed self-assessment tests are unsuitable for measuring personality in LLMs due to their reactive nature and lack of introspection capabilities

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Option-order symmetry is a necessary condition for valid self-assessment personality tests when applied to LLMs.
- Mechanism: Option-order symmetry ensures test responses are invariant to option presentation order. If responses change with option order, the test measures artifacts of model processing rather than personality.
- Core assumption: Human personality test responses preserve option-order symmetry, so LLM responses should too for validity.
- Evidence anchors: Abstract states answer invariance to option order is required; paper proposes option-order symmetry as reliability condition.
- Break condition: If LLM response changes with option order, test results are unreliable.

### Mechanism 2
- Claim: LLMs exhibit inherent biases that make self-assessment tests unreliable.
- Mechanism: Biases cause LLMs to fixate on single responses regardless of situational context, indicating they're following predetermined patterns rather than introspecting.
- Core assumption: LLM biases are significant enough to override situational context in test questions.
- Evidence anchors: Abstract identifies inherent biases as root cause; paper states biases drive inherent preferences for certain choices.
- Break condition: If LLM response varies significantly with situational statement, test results may be reliable.

### Mechanism 3
- Claim: Human-designed self-assessment tests are unsuitable for LLMs due to lack of introspection skills.
- Mechanism: Self-assessment tests require introspection and self-reflection, which LLMs may lack. Situational reaction tests might be more appropriate for reactive agents.
- Core assumption: LLMs cannot introspect and self-reflect like humans do.
- Evidence anchors: Paper focuses on measuring personality rather than underlying mechanisms; questions whether LLMs can introspect.
- Break condition: If LLMs demonstrate introspection ability, human tests might become more applicable.

## Foundational Learning

- Concept: Option-Order Symmetry
  - Why needed here: Determines validity of self-assessment tests for LLMs by ensuring responses aren't artifacts of option presentation.
  - Quick check question: If LLM answers change when options A,B,C,D become D,C,B,A, does the test preserve option-order symmetry?

- Concept: LLM Biases
  - Why needed here: Explains why LLMs fixate on responses regardless of context, making tests unreliable.
  - Quick check question: If LLM consistently chooses same option regardless of situational statement, what does this indicate about its biases?

- Concept: Self-Assessment vs. Situational Reaction Tests
  - Why needed here: Distinguishes appropriate testing methods for LLMs versus humans.
  - Quick check question: Why might situational reaction tests be more appropriate than introspection-based tests for LLMs?

## Architecture Onboarding

- Component map: MPI-1K dataset (1K questions) -> Five LLMs (1.5B-30B params) -> Two templates (MCP-I NDEXED, MCP-N ON-I NDEXED) -> Beam search generation -> Option-order symmetry analysis -> Bias identification
- Critical path: 1) Select prompt template 2) Administer self-assessment test 3) Analyze option-order symmetry 4) Identify and evaluate inherent biases
- Design tradeoffs: Indexed templates may introduce multiple-choice symbol-binding bias; non-indexed templates eliminate this but may still have other biases
- Failure signatures: Lack of option-order symmetry, consistent single-option selection regardless of context, inability to introspect when responding
- First 3 experiments: 1) Test five LLMs with MCP-I NDEXED templates for option-order symmetry 2) Test five LLMs with MCP-N ON-I NDEXED templates for response patterns 3) Analyze content-free templates to identify inherent biases

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can personality in LLMs be reliably measured given that self-assessment tests fail due to option-order symmetry issues and lack of situational awareness?
- Basis in paper: [explicit] Paper demonstrates self-assessment tests are unreliable due to lack of option-order symmetry and models' tendency to ignore situational context.
- Why unresolved: Current tools are inadequate; paper calls for developing new methods specifically designed for machine personality measurement.
- What evidence would resolve it: Development and validation of new personality assessment tools for LLMs that account for their reactive nature and lack of introspection, demonstrating consistent and meaningful personality measurement.

### Open Question 2
- Question: Do LLMs possess emergent personality traits that differ from human personality dimensions, and if so, what are the appropriate traits to measure?
- Basis in paper: [inferred] Paper suggests traditional human personality traits (OCEAN) may not be suitable for measuring machine personality and proposes rethinking evaluation traits.
- Why unresolved: Unclear whether LLMs develop personality traits analogous to human traits or entirely different ones, and how these would manifest behaviorally.
- What evidence would resolve it: Empirical studies identifying consistent behavioral patterns in LLMs across various tasks and contexts, leading to new taxonomy of machine personality traits.

### Open Question 3
- Question: What are the underlying mechanisms in LLM architectures that lead to inherent biases influencing their responses in self-assessment tests?
- Basis in paper: [explicit] Paper identifies inherent biases in LLMs that cause fixation on certain response options regardless of situational statement.
- Why unresolved: Paper does not delve into specific mechanisms causing these biases, such as architectural features, training objectives, or data influences.
- What evidence would resolve it: Detailed analysis of LLM training processes, architectural components, and response generation mechanisms to pinpoint sources of bias and their impact on personality assessment.

## Limitations

- Findings based on limited dataset (MPI-1K) and five specific LLMs, may not generalize to other models or test formats
- Core assumption that option-order symmetry is necessary for valid personality assessment requires further validation in human psychology literature
- Study only addresses self-assessment tests and does not explore alternative personality measurement frameworks or behavioral observation methods

## Confidence

- High confidence: LLMs consistently fixate on single responses regardless of situational context across all tested models
- Medium confidence: Self-assessment tests are unreliable for measuring LLM personality, though based on specific assumption about option-order symmetry
- Low confidence: Broader implication that LLMs fundamentally cannot possess measurable personality in any form

## Next Checks

1. **Cross-dataset validation**: Test the same five LLMs using multiple personality assessment datasets beyond MPI-1K to determine if observed patterns are consistent across different test formats and question styles.

2. **Human baseline comparison**: Administer the same personality tests to human subjects and analyze their option-order symmetry properties to verify whether this is indeed a universal requirement for valid personality assessment.

3. **Alternative measurement framework testing**: Develop and test situational reaction tests where LLMs respond to personality-relevant scenarios rather than self-assessing, to determine if this approach yields more meaningful personality indicators.
