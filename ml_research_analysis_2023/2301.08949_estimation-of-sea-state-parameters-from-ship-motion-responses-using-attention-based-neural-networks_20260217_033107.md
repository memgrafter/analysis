# Estimation of Sea State Parameters from Ship Motion Responses Using Attention-based Neural Networks

## Quick Facts
- arXiv ID: 2301.08949
- Source URL: https://arxiv.org/abs/2301.08949
- Reference count: 21
- Key outcome: Attention-based neural network reduces sea state estimation MSE by up to 94% and MAE by up to 70% compared to state-of-the-art models

## Executive Summary
This study presents an attention-based neural network (AT-NN) for estimating sea state parameters (wave height, zero-crossing period, and relative wave direction) from ship motion responses. The model processes raw time-series data of pitch, heave, and roll motions to predict sea state characteristics with significantly improved accuracy compared to traditional CNN and LSTM approaches. The research introduces a novel uncertainty quantification method using Monte-Carlo dropout, enhancing the model's trustworthiness for maritime applications. Results demonstrate that attention mechanisms effectively capture long-range temporal dependencies in ship motion data, enabling more accurate sea state estimation for improved navigation system performance.

## Method Summary
The AT-NN model processes 3-DOF ship motion responses (pitch, heave, roll) through a 2D convolutional layer followed by two self-attention blocks with multi-head attention. The architecture includes positional encoding, normalization layers, and dense layers (128→64→3 neurons) to output sea state parameters. Data augmentation through signal shuffling increases dataset diversity. The model is trained on numerically simulated data from a 20,000DWT Bulk Carrier ship using Latin hypercube sampling of sea state parameters. Monte-Carlo dropout enables uncertainty estimation during inference.

## Key Results
- AT-NN reduced estimation MSE by up to 94% and MAE by up to 70% compared to state-of-the-art CNN and LSTM models
- Data augmentation improved model accuracy by approximately 23% in MSE reduction
- Monte-Carlo dropout provided reliable uncertainty estimates for sea state parameter predictions
- The model maintained performance when reducing input DOF from 3 to 2, indicating robustness to data availability

## Why This Works (Mechanism)

### Mechanism 1
- Attention-based neural networks outperform traditional CNN and LSTM models for sea state estimation by capturing long-range temporal dependencies in ship motion data.
- The AT-NN uses self-attention blocks with multi-head attention layers to learn complex relationships between tokens (windowed segments of motion signals), which CNNs and LSTMs struggle to capture due to their fixed receptive fields or limited memory.
- Core assumption: Ship motion signals contain scattered, non-local information patterns that are critical for accurate sea state parameter estimation.
- Evidence anchors: Abstract states AT-NN outperformed all tested methods reducing estimation MSE by up to 94% and MAE by up to 70%. Section states AT-NN can seize interaction and correlation between different parts of input signals using self-attention module.
- Break condition: If ship motion patterns are purely local and short-term, CNNs with appropriate kernel sizes would match or exceed attention-based performance.

### Mechanism 2
- Data augmentation through signal shuffling improves model generalization and reduces overfitting in sea state estimation tasks.
- Row-wise and batch-wise data augmentation methods increase dataset diversity by creating variations of input signals, helping models learn invariant features rather than memorizing specific sequences.
- Core assumption: The original dataset, while containing 13,000 samples, lacks sufficient diversity to prevent overfitting in deep neural networks.
- Evidence anchors: Section states data augmentation strategies are employed to increase accuracy and eliminate overfitting. Trained models always outperformed those not using augmentations.
- Break condition: If the model architecture is sufficiently simple or the dataset is already large and diverse, augmentation may provide minimal benefit or could introduce harmful noise.

### Mechanism 3
- Monte-Carlo dropout sampling provides reliable uncertainty estimates for sea state parameter predictions, enhancing model trustworthiness.
- By repeatedly sampling the model with dropped neurons during inference, AT-NN generates a distribution of predictions that approximates Bayesian inference, quantifying prediction confidence.
- Core assumption: The dropout layers in the fully connected blocks of AT-NN create a valid approximation of a Gaussian process for uncertainty quantification.
- Evidence anchors: Abstract mentions novel approach for interpreting uncertainty estimation using Monte-Carlo dropout. Section states sampled NNs can be treated as approximate Bayesian inference in deep Gaussian processes.
- Break condition: If dropout layers are insufficient in number or poorly placed, uncertainty estimates may be unreliable or misleading.

## Architecture Onboarding

- **Component map**: Input → 2D convolution (3×125 kernel) → Positional encoding → Two self-attention blocks (each with MHA + normalization) → Flatten → Dense layers (128→64→3 neurons) → Output (Hs, Tz, )
- **Critical path**: The attention mechanism and fully connected layers are most critical; convolution and positional encoding are preparatory steps.
- **Design tradeoffs**: Wider attention blocks (more heads, embeddings) vs. computational cost; dropout probability (0.1) vs. regularization effectiveness.
- **Failure signatures**: Poor generalization (overfitting) indicated by large gap between validation and test performance; instability in uncertainty estimates suggests issues with dropout configuration.

## Limitations

- The study relies on numerically simulated ship motion data rather than real-world measurements, which may not fully capture complex hydrodynamic interactions and measurement noise present in operational environments.
- The generalizability of the AT-NN model to different ship types and sea conditions beyond the Bulk Carrier configuration requires further validation.
- The computational efficiency of the attention-based approach compared to simpler models for real-time deployment was not explicitly addressed.

## Confidence

- **High confidence**: Superior performance of AT-NN over baseline models for specific simulation conditions tested, supported by clear quantitative improvements (94% MSE reduction, 70% MAE reduction)
- **Medium confidence**: Uncertainty estimation method, as Monte-Carlo dropout approach shows theoretical promise but practical validation across diverse operational scenarios is needed
- **Medium confidence**: Data augmentation benefits, as improvements were demonstrated within simulation framework but real-world applicability requires verification
