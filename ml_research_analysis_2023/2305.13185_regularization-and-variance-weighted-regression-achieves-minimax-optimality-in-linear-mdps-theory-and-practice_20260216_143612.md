# Regularization and Variance-Weighted Regression Achieves Minimax Optimality in Linear MDPs: Theory and Practice

## Quick Facts
- arXiv ID: 2305.13185
- Source URL: https://arxiv.org/abs/2305.13185
- Reference count: 40
- Primary result: Mirror descent value iteration with variance-weighted least-squares achieves near-minimax optimal sample complexity for linear MDPs

## Executive Summary
This work establishes that mirror descent value iteration (MDVI) with variance-weighted least-squares regression achieves near-minimax optimal sample complexity for infinite-horizon linear MDPs. The key innovation is introducing a weighted Kiefer-Wolfowitz theorem and total variance technique compatible with function approximation, enabling the first theoretical algorithm (VWLS-MDVI) to attain minimax optimality in this setting. The authors also propose a practical deep RL extension (DVW) that improves performance of value-based deep RL algorithms on MinAtar benchmarks. Empirical results show that DVW achieves near-oracle performance in both model-based and online RL settings.

## Method Summary
The authors introduce VWLS-MDVI, which combines mirror descent value iteration with variance-weighted least-squares regression. The algorithm estimates the transition model using weighted regression based on action-value function variance, then performs model-based planning with the estimated model. The variance weighting follows from a weighted version of the Kiefer-Wolfowitz theorem, which shows that the total variance of a sum of random variables can be minimized by choosing appropriate weights. This leads to a model-based planning algorithm with optimal sample complexity. The practical extension (DVW) applies this variance-weighted principle to deep RL by weighting TD errors during training, implemented as a simple modification to existing value-based algorithms.

## Key Results
- VWLS-MDVI achieves near-minimax optimal sample complexity for linear MDPs
- DVW extension improves performance of value-based deep RL algorithms on MinAtar benchmarks
- Empirical results show DVW achieves near-oracle performance in both model-based and online RL settings

## Why This Works (Mechanism)
The core mechanism relies on variance-weighted regression to optimally trade off exploration and exploitation. By weighting the regression of transition dynamics by the variance of action values, the algorithm focuses on learning transitions that matter most for value estimation. The Kiefer-Wolfowitz theorem provides the theoretical foundation, showing that this weighting minimizes the total variance in the value function estimates. This variance-aware learning strategy naturally balances the need to explore uncertain regions of the state space while exploiting known good actions.

## Architecture Onboarding

**Component Map:**
Input features -> Feature map φ -> Value function approximator Q_φ -> Variance estimator → Weighted regression → Transition model → Model-based planning → Updated value function

**Critical Path:**
The critical computational path involves: 1) Computing value function variance estimates, 2) Performing weighted regression to estimate transition dynamics, 3) Using the estimated model for planning via mirror descent, and 4) Updating the value function. Each iteration requires O(d^3) time for regression and O(d^2|S|) for planning, where d is the feature dimension and |S| is the number of discrete states.

**Design Tradeoffs:**
The algorithm trades computational complexity for statistical efficiency. The variance-weighted regression requires additional computation to estimate action-value variances and perform weighted least-squares, but this investment pays off in improved sample efficiency. The regularization parameter controls the bias-variance tradeoff in the regression, while the mirror descent step size affects convergence speed versus stability.

**Failure Signatures:**
- High variance in value estimates despite many samples suggests poor feature representation or insufficient regularization
- Degraded performance with increased regularization indicates underfitting
- Numerical instability in regression suggests ill-conditioned feature matrices, requiring feature normalization

## Limitations
- Theoretical analysis relies on specific assumptions about linear MDP structure and bounded features
- Practical performance gains demonstrated primarily on MinAtar may not generalize to more complex environments
- Deep RL extension (DVW) lacks theoretical guarantees in the function approximation setting

## Confidence

**Theoretical Optimality of VWLS-MDVI: High**
- Proof techniques are rigorous and build on established statistical learning theory
- Sample complexity bounds match known lower bounds up to logarithmic factors

**Practical Effectiveness of DVW: Medium**
- Demonstrated improvements on MinAtar benchmarks
- Limited testing on more complex or continuous control tasks

**Generality of Variance-Weighted Approach: Medium**
- Strong theoretical foundation in linear settings
- Empirical success in deep RL, but theoretical understanding incomplete
