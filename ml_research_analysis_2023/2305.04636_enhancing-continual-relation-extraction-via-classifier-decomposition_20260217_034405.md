# Enhancing Continual Relation Extraction via Classifier Decomposition

## Quick Facts
- arXiv ID: 2305.04636
- Source URL: https://arxiv.org/abs/2305.04636
- Reference count: 15
- Key outcome: Proposed classifier decomposition framework achieves 84.6% accuracy on FewRel and 78.6% on TACRED, outperforming state-of-the-art CRE models.

## Executive Summary
This paper addresses catastrophic forgetting in continual relation extraction (CRE) by identifying two key biases: classifier bias (forgetting previous relation knowledge) and representation bias (overlapping representations). The authors propose a classifier decomposition framework that splits the final feed-forward network (FFN) layer into separate classifiers for previous and current relations. Two strategies are introduced: empirical initialization (freezing and reusing previous classifier nodes) and adversarial tuning (slowing previous classifier updates to encourage distinct representations). Experiments on FewRel and TACRED benchmarks demonstrate consistent improvements over state-of-the-art CRE models.

## Method Summary
The method involves a two-stage training paradigm where Stage 1 trains only on new data to rapidly learn current relations, while Stage 2 uses memory replay to balance performance across all seen relations. The core innovation is splitting the final FFN layer into separate classifiers for previous and current relations. Empirical initialization freezes well-learned previous classifier nodes from earlier tasks and reuses them in Stage 2. Adversarial tuning applies a lower learning rate to previous classifier weights during Stage 1, creating adversarial signals that encourage learning more distinct representations for current relations.

## Key Results
- Achieves 84.6% accuracy on FewRel benchmark, outperforming state-of-the-art CRE models
- Achieves 78.6% accuracy on TACRED benchmark with significant improvements
- Successfully mitigates both classifier and representation biases that cause catastrophic forgetting

## Why This Works (Mechanism)

### Mechanism 1: Classifier Decomposition with Empirical Initialization
- Claim: Freezing and reusing well-learned previous classifier nodes alleviates classifier bias
- Mechanism: Final FFN layer is split into separate classifiers for previous and current relations; frozen previous classifier weights are preserved and reused
- Core assumption: Previous classifier weights capture valuable knowledge about previous relations
- Break condition: Previous classifier weights become stale compared to new data distribution

### Mechanism 2: Adversarial Tuning for Robust Representations
- Claim: Slowing previous classifier updates encourages learning of more distinct representations
- Mechanism: Lower learning rate applied to previous classifier weights during Stage 1 creates adversarial signals
- Core assumption: Slowly updating previous classifier weights force model to find more distinct representations for current relations
- Break condition: Learning rate for previous classifier weights set too low, completely freezing them

### Mechanism 3: Two-Stage Training Paradigm
- Claim: Separating training into two stages effectively handles data imbalance in CRE
- Mechanism: Stage 1 trains only on new data; Stage 2 trains on memory-replayed data to balance performance
- Core assumption: Two-stage approach prevents overfitting to imbalanced distribution
- Break condition: Memory buffer too small or unrepresentative, insufficient balancing effect

## Architecture Onboarding

- Component map: BERT encoder -> Classifier decomposition layer -> Memory module -> Training scheduler
- Critical path: Encoder → Classifier decomposition → Prediction → Loss calculation → Parameter updates (with different learning rates for previous vs current classifiers)
- Design tradeoffs:
  - Splitting classifier adds complexity but provides bias mitigation
  - Freezing previous classifier weights preserves knowledge but may reduce flexibility
  - Lower learning rate for previous classifier encourages robustness but risks underfitting
- Failure signatures:
  - Classifier bias persists: Previous relations show degraded performance despite empirical initialization
  - Representation bias persists: Similar relations remain overlapping in embedding space despite adversarial tuning
  - Training instability: Learning rate mismatch causes optimization issues
- First 3 experiments:
  1. Test empirical initialization alone by training with frozen previous classifier weights
  2. Test adversarial tuning alone by applying different learning rates and visualizing representation separation
  3. Test full framework with both strategies and compare against baseline CRE models

## Limitations
- Exact implementation details of FFN layer splitting mechanism are not fully specified
- Adversarial tuning effectiveness relies on hyperparameter tuning that may not generalize
- Two-stage training assumes sufficient memory capacity and representative sampling
