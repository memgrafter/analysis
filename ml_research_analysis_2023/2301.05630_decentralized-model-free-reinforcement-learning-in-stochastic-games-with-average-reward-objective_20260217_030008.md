# Decentralized model-free reinforcement learning in stochastic games with average-reward objective

## Quick Facts
- arXiv ID: 2301.05630
- Source URL: https://arxiv.org/abs/2301.05630
- Reference count: 40
- Primary result: First model-free algorithm for decentralized learning in infinite-horizon average-reward stochastic games with sublinear regret bounds

## Executive Summary
This paper introduces DONQ-learning, a novel model-free algorithm for decentralized learning in infinite-horizon average-reward stochastic games. The algorithm leverages an artificial discounted setting to apply optimistic Q-learning techniques, achieving sublinear regret performance against arbitrary opponents. The approach offers a significant advancement over prior model-based methods by providing lower computational complexity and memory requirements while maintaining theoretical guarantees.

## Method Summary
The paper proposes DONQ-learning, which adapts optimistic Q-learning to the average-reward setting by first solving an artificial discounted problem. The algorithm operates in a decentralized manner, allowing agents to learn optimal policies without knowledge of opponents' strategies. By using a carefully constructed discounted approximation, the method achieves sublinear regret bounds while avoiding the computational burden of model-based approaches. The theoretical analysis provides both high-probability and expected regret bounds, demonstrating the algorithm's robustness to different opponent behaviors.

## Key Results
- High-probability regret bound of order T^(3/4)
- Expected regret bound of order T^(2/3)
- Lower computational complexity and memory requirements compared to prior model-based approaches

## Why This Works (Mechanism)
The algorithm works by transforming the average-reward stochastic game into an artificial discounted setting, where optimistic Q-learning techniques can be effectively applied. This transformation allows the use of established theoretical tools while maintaining the ability to handle the average-reward objective. The decentralized nature of the algorithm enables agents to learn without requiring knowledge of opponents' strategies, making it practical for real-world applications.

## Foundational Learning
- Stochastic games: Multi-agent environments where agents' rewards depend on joint actions
  * Why needed: The problem setting involves multiple agents interacting in a shared environment
  * Quick check: Agents' rewards should depend on both their own actions and others' actions

- Average-reward objective: Long-term performance measure over infinite horizons
  * Why needed: The problem considers infinite-horizon games rather than finite episodes
  * Quick check: The objective should be time-averaged rather than cumulative

- Optimistic Q-learning: Exploration technique that encourages trying potentially better actions
  * Why needed: Enables efficient exploration in the discounted setting
  * Quick check: The algorithm should exhibit optimism in the face of uncertainty

## Architecture Onboarding
Component map: DONQ-learning -> Artificial Discounted Setting -> Optimistic Q-learning -> Average-reward Regret Bounds

Critical path: The algorithm transforms the average-reward problem into a discounted setting, applies optimistic Q-learning, and then translates the results back to obtain regret bounds for the original problem.

Design tradeoffs: The approach trades exact knowledge of the game structure (required by model-based methods) for computational efficiency, accepting the complexity of working with an artificial discounted setting.

Failure signatures: Poor performance may arise if the discounted approximation is too loose, if the optimistic exploration is too aggressive, or if the opponent employs particularly adversarial strategies that exploit the decentralized learning approach.
