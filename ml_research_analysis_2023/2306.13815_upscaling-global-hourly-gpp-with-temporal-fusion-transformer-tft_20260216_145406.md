# Upscaling Global Hourly GPP with Temporal Fusion Transformer (TFT)

## Quick Facts
- **arXiv ID:** 2306.13815
- **Source URL:** https://arxiv.org/abs/2306.13815
- **Reference count:** 36
- **Primary result:** Achieved 0.704 NSE and 3.54 RMSE for global hourly GPP upscaling using feature-engineered Random Forest with top 9 features

## Executive Summary
This study addresses the challenge of scaling sparse eddy covariance tower Gross Primary Productivity (GPP) measurements to global, hourly resolutions using machine learning. The authors developed and compared multiple approaches including Temporal Fusion Transformer (TFT), Random Forest, and XGBoost models, with and without hybrid configurations. The best upscaling performance came from a feature-engineered Random Forest model using the top 9 features, while the GPP-TFT model demonstrated strong performance but couldn't scale globally due to missing meteorological inputs.

## Method Summary
The study employed multiple machine learning approaches to upscale GPP measurements: Random Forest (RF), XGBoost, and Temporal Fusion Transformer (TFT) models. The authors conducted comprehensive feature selection and engineering, comparing pure machine learning approaches with hybrid configurations. They evaluated models across different temporal resolutions and land cover types, using eddy covariance tower data as ground truth. A novel visual-analytical approach was developed to interpret TFT model behavior by analyzing temporal dynamics of feature importance across different land cover types and seasons.

## Key Results
- Best upscaling model achieved NSE of 0.704 and RMSE of 3.54 using feature-engineered Random Forest with top 9 features
- GPP-TFT model achieved strong performance (0.886 NSE, 2.132 RMSE) but couldn't scale globally due to missing meteorological inputs
- Novel visual-analytical approach revealed temporal importance patterns of features across land cover types and seasons
- Random Forest outperformed more complex models for the upscaling task, suggesting feature selection may be more critical than temporal modeling for this application

## Why This Works (Mechanism)
The success of feature-engineered Random Forest over more complex temporal models suggests that GPP upscaling is primarily driven by static feature relationships rather than temporal dynamics. The GPP-TFT model's strong performance indicates that temporal fusion transformers can effectively capture temporal patterns when meteorological inputs are available, but the missing data for global scaling creates a fundamental limitation. The visual-analytical approach provides interpretable insights into model behavior by tracking how feature importance changes across different temporal and spatial contexts.
