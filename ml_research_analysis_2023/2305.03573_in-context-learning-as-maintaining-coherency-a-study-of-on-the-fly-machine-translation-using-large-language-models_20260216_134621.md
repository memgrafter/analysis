# In-context Learning as Maintaining Coherency: A Study of On-the-fly Machine Translation Using Large Language Models

## Quick Facts
- arXiv ID: 2305.03573
- Source URL: https://arxiv.org/abs/2305.03573
- Reference count: 11
- Primary result: Moving window of previous gold translations improves BLEU scores by up to 2.6 points compared to similarity-based retrieval in in-context machine translation

## Executive Summary
This work investigates in-context learning for on-the-fly machine translation, framing it as maintaining coherency between the prompt context and test sentence. Experiments across three large language models (GPTNeo2.7B, Bloom3B, XGLM2.9B) and three translation directions (en→pt, de, fr) demonstrate that using a moving window of previous gold translations significantly improves performance compared to similarity-based retrieval methods. The findings highlight that coherency of the context with the test sentence is a more critical factor than semantic or surface similarity, offering insights into effective prompt selection strategies for in-context machine translation.

## Method Summary
The study evaluates in-context translation performance using three pre-trained LLMs (GPTNeo2.7B, Bloom3B, XGLM2.9B) on three language pairs with datasets from four domains (MED, MTNT, FLORES, TED). No model training is performed; instead, the focus is on prompt selection strategies for zero-shot translation. The experiments compare five methods: random sampling, domain-matched sampling, moving window of gold translations, and similarity-based retrieval (BM25, BM25-s, nn). Translation quality is measured using SacreBLEU scores, with conditional source sentence perplexity used as a coherence proxy. A greedy submodular algorithm controls for prompt length to isolate the effect of coherence from length.

## Key Results
- Moving window method outperforms all baselines across 3 models and 3 language directions, improving BLEU scores by up to 2.6 points
- Coherence-based prompt selection shows stronger correlation with translation quality than surface or semantic similarity methods
- Domain coherence is effective: sampling prompts from the same domain as the test sentence yields highest performance
- The relationship between source perplexity and BLEU is negative (r = -0.22) but noisy, suggesting indirect or non-linear effects

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Coherent prompts (same domain or moving window) improve translation performance by maintaining semantic and syntactic consistency with the test sentence
- Mechanism: The LLM implicitly uses prompt context to condition generation, so coherent context reduces surprisal and guides better translation
- Core assumption: Coherence can be approximated by domain matching and local context continuity; the model can leverage these signals without explicit fine-tuning
- Evidence anchors:
  - "the long-term coherency of the prompts and the test sentence is a good indicator of downstream translation performance"
  - "sampling and testing within the same domain mostly results in the highest performance column-wise"
  - "The moving window (window) outperforms all other baselines across the 3 models and 3 language directions"

### Mechanism 2
- Claim: Prompt selection based on surface similarity (BM25) or semantic similarity (sentence embeddings) is less effective than coherence because similarity metrics do not capture the broader discourse context needed for fluent translation
- Mechanism: BM25 and embedding similarity focus on local lexical overlap or embedding proximity, missing discourse-level cues that coherence provides
- Core assumption: High lexical overlap or embedding similarity does not guarantee discourse coherence or translation quality
- Evidence anchors:
  - "coherency of the context with the test sentence is a more critical factor than semantic or surface similarity"
  - "Importantly, coverage and L2 shows that the performance is not due to similarity or word overlap"
  - "We observe that there is a negative relationship between source perplexity and Sentence BLEU... but very noisy relationship between Sentence BLEU and word overlap"

### Mechanism 3
- Claim: Using previously translated gold sentence pairs as a moving window provides local coherence that guides the model to produce translations consistent with the surrounding document
- Mechanism: The moving window acts as a dynamic, context-aware prompt that keeps the translation style and terminology consistent within a document
- Core assumption: The moving window of gold translations is available and of high quality; the LLM can generalize from this recent context to unseen sentences
- Evidence anchors:
  - "Within the TED talks domain, we investigate local coherence using document-level translation experiments, by adopting a moving window directly preceding the test source sentence to be translated"
  - "Interestingly, shuffling the set of prompts within the moving window which breaks the natural ordering of the document does not deteriorate in-context translation performance"
  - "The moving window (window) outperforms all other baselines across the 3 models and 3 language directions"

## Architecture Onboarding

- Component map: Data loading and preprocessing -> Prompt selection module (random, BM25, BM25-s, NN, window) -> Translation inference with LLM (GPTNeo, Bloom, XGLM) -> Evaluation (BLEU, perplexity, coverage, L2) -> Budget controller (length constraint algorithm)

- Critical path: Load prompt bank and test set -> For each test sentence, select prompts according to method -> Construct prompt string with instructions and examples -> Run inference with LLM -> Compute evaluation metrics

- Design tradeoffs:
  - Prompt length vs. number of examples (budget constraint)
  - Speed vs. quality (similarity search vs. simple random sampling)
  - Generalization vs. specificity (domain matching vs. universal prompts)

- Failure signatures:
  - BLEU drops sharply when prompt bank domain does not overlap with test domain
  - Perplexity increases when prompt examples are too dissimilar or too similar but incoherent
  - Memory errors if prompt length exceeds model context window

- First 3 experiments:
  1. Run domain coherence test: sample prompts from each domain and test on each test domain, report BLEU differences
  2. Run local coherence test: use moving window within a document, compare to random and similarity-based methods, report BLEU
  3. Run length control test: filter prompts by word count (5-10 vs 15-20), compare BLEU to no-filter baseline

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the optimal prompt selection strategy differ for larger language models beyond the 3B-parameter models tested?
- Basis in paper: The paper tested GPTNeo2.7B, Bloom3B, and XGLM2.9B but explicitly notes "Due to GPU memory limitations we did not study larger models and it is not clear whether findings generalise to even larger models."
- Why unresolved: The study's hardware constraints prevented testing larger models, leaving open whether the observed coherency advantages would scale with model size
- What evidence would resolve it: Experiments comparing moving window and similarity-based retrieval methods across a range of model sizes (e.g., 7B, 13B, 175B parameters) would reveal whether the coherency advantage persists or changes with scale

### Open Question 2
- Question: What is the precise relationship between source sentence perplexity and translation quality in in-context learning?
- Basis in paper: The paper finds a negative correlation (Pearson's r = -0.22) between source perplexity and BLEU scores, but notes the relationship is "very noisy" and "indirect or non-linear"
- Why unresolved: While perplexity is used as a coherence measure, the weak and noisy correlation suggests other factors influence translation quality beyond what perplexity captures
- What evidence would resolve it: Controlled experiments manipulating sentence complexity while holding coherence constant, combined with fine-grained analysis of attention patterns during generation, could clarify how perplexity relates to actual translation performance

### Open Question 3
- Question: Does local coherence affect formal versus informal language differently in in-context machine translation?
- Basis in paper: The paper notes the TED talks dataset contains both formal language and informal text, but states "we did not quantify whether coherence is more likely to affect formal or informal language and might be studied with other datasets"
- Why unresolved: The dataset contains mixed language styles, but no analysis was performed to determine if coherence effects vary across these styles
- What evidence would resolve it: Experiments using datasets with clearly demarcated formal and informal domains, measuring coherence effects separately for each style, would reveal whether local coherence has differential impact on translation quality

## Limitations
- Limited to three specific language pairs and three model architectures, which may not capture full diversity of translation scenarios
- Reliance on TED talks for document-level coherence analysis may introduce domain-specific biases that don't generalize to other text types
- Moving window approach assumes availability of high-quality gold translations preceding the test sentence, which may not be practical in real-world deployment

## Confidence
**High Confidence**: The core finding that coherence-based prompt selection (particularly the moving window method) outperforms similarity-based methods across multiple models and language pairs is well-supported by the experimental results, with consistent improvements in BLEU scores and the relationship between perplexity and translation quality.

**Medium Confidence**: The claim that coherence is more important than semantic or surface similarity is supported by the data, but the relationship between coherence and translation quality shows significant variance across different model-language combinations, suggesting the effect may be model-dependent.

**Low Confidence**: The assertion that shuffling prompts within the moving window does not affect performance needs more rigorous validation, as the current evidence is based on limited observations in section 6.2 without comprehensive statistical analysis.

## Next Checks
1. **Cross-domain generalization test**: Evaluate the moving window method on a completely different domain (e.g., legal or technical documentation) to verify if coherence benefits extend beyond the TED talks domain

2. **Prompt order sensitivity analysis**: Systematically test different permutations of the moving window prompts to determine if there are optimal arrangements that maximize translation performance

3. **Real-time performance evaluation**: Implement a practical version of the moving window method using machine-generated translations (rather than gold translations) to assess degradation in performance and determine acceptable quality thresholds for the window content
