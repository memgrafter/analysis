# Time Series Forecasting via Semi-Asymmetric Convolutional Architecture with Global Atrous Sliding Window

## Quick Facts
- arXiv ID: 2301.13691
- Source URL: https://arxiv.org/abs/2301.13691
- Reference count: 40
- Key outcome: Novel method achieves state-of-the-art performance on most time series datasets by capturing both local and global information

## Executive Summary
This paper introduces a novel time series forecasting architecture that combines difference sequence transformation, global atrous sliding windows, and semi-asymmetric convolution to capture both local patterns and global context. The method transforms the original series into a difference sequence, partitions it into overlapping windows with positional encoding, and applies a central-bidirectional atrous algorithm followed by semi-asymmetric convolution layers. Experimental results on 43 datasets from the Monash Time Series Forecasting Archive demonstrate state-of-the-art performance compared to competitive modern models.

## Method Summary
The proposed method transforms time series into first-order difference sequences, partitions them into overlapping windows, and reconstructs each window with positional encoding relative to the entire series. A central-bidirectional atrous algorithm expands the receptive field while preserving resolution, and semi-asymmetric convolution layers with adjustable horizontal and vertical filters extract relationships between adjacent elements and their global features. The model is trained for 500 epochs using NAdam optimizer, ReduceLROnPlateau scheduler, and L1Loss function, with performance evaluated using MAE and RMSE metrics.

## Key Results
- Achieves state-of-the-art performance on most time series datasets compared to competitive modern models
- Demonstrates effectiveness of difference sequence transformation in facilitating learning
- Shows the global atrous sliding window successfully associates global information with temporal data
- Semi-asymmetric convolution provides flexible extraction of relationships in adjacent elements and global features

## Why This Works (Mechanism)

### Mechanism 1
Transforming the original time series into a difference sequence enables the model to learn more easily by reducing non-stationarity and making local patterns more stable. The first-order difference operation, defined as Δy = y(t+1) - y(t), removes trend components and emphasizes short-term variations, which are easier for convolutional filters to capture. The core assumption is that the first-order difference sufficiently linearizes the series so that local patterns are preserved and more learnable by CNNs. If the series has high noise or very short-term dependencies, differencing may amplify noise and hurt learning.

### Mechanism 2
The global atrous sliding window provides a way to incorporate global contextual information without losing resolution. The method partitions the difference series into overlapping windows and reconstructs each window's elements with positional encoding relative to the entire series, then applies dilated convolutions that span across this expanded window. The core assumption is that associating each local element with its global position retains enough semantic context for long-range forecasting. If the series is too short or the window size too large, the encoding becomes sparse and uninformative.

### Mechanism 3
The semi-asymmetric convolution flexibly extracts relationships in adjacent elements and associated global features with adjustable ranges on vertical and horizontal directions. Decomposing the kernel into horizontal and vertical filters of possibly different lengths allows capturing different scales of temporal and positional dependencies in a single layer. The core assumption is that the two-dimensional structure of the reconstructed window (time x position) can be meaningfully convolved with separable filters to extract richer patterns than a standard 1D conv. If the decomposed filters become too narrow, the advantage over standard asymmetric convs disappears.

- Component map: Input difference sequence → Sliding window segmentation → Positional encoding reconstruction → Central-bidirectional atrous algorithm → Semi-asymmetric convolution blocks → Linear layers → Prediction restoration
- Critical path: The encoder (steps 3.2-3.3) and the SACNN (step 3.4) are the two core modules that must be correct; errors here propagate through the entire model
- Design tradeoffs: Larger window size increases global context but may reduce local detail; more asymmetric filter dimensions increase parameter count but improve flexibility
- Failure signatures: Poor MAE but good RMSE suggests outliers are poorly handled; large window size but no performance gain suggests positional encoding is ineffective

## Limitations

- Performance claims rely primarily on comparisons with existing models rather than ablation studies isolating individual contributions
- Effectiveness depends heavily on proper tuning of asymmetric filter dimensions, which may not transfer well across domains
