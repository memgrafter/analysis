# Evaluating counterfactual explanations using Pearl's counterfactual method

## Quick Facts
- arXiv ID: 2301.02499
- Source URL: https://arxiv.org/abs/2301.02499
- Reference count: 13
- Key outcome: This paper presents a method for evaluating counterfactual explanations using Pearl's counterfactual method. The problem is that current counterfactual explanation methods are generated using machine learning models that do not necessarily take into account the true causal structure in the data, leading to erroneous estimations of the counterfactuals. The proposed method uses Pearl's method to evaluate and test current counterfactual explanation methods. The method was evaluated on three different causal structures (chains, forks, and colliders) and showed that 30% of the counterfactual explanations conflicted with those computed by Pearl's method. The results suggest that different causal structures affect the counterfactual explanations generated and that it is vital to understand the true underlying causal structure before blindly computing counterfactuals using the original machine learning model.

## Executive Summary
This paper addresses a critical gap in counterfactual explanation methods by evaluating whether machine learning-generated counterfactuals align with true causal relationships. The author proposes using Pearl's Structural Causal Model (SCM) approach to evaluate counterfactual explanations, revealing that 30% of ML-generated counterfactuals conflict with those derived from proper causal reasoning. The study demonstrates that ignoring causal structure in data generation leads to erroneous counterfactuals, particularly when dealing with complex causal relationships like chains, forks, and colliders.

## Method Summary
The method evaluates counterfactual explanations by comparing ML-generated counterfactuals (using DiCE) with those computed via Pearl's Structural Causal Model approach. The process involves generating synthetic datasets based on three causal structures (chains, forks, colliders), training logistic regression models, and generating counterfactual explanations using DiCE. Pearl's method then computes counterfactuals through an Abduction-Action-Prediction pipeline, where exogenous variables are computed from factual data, interventions remove parent-child relationships, and predictions are made using modified SCMs. The output classes from both methods are compared to identify conflicts.

## Key Results
- 30% of ML-generated counterfactual explanations conflicted with those computed using Pearl's method
- Collider causal structures showed the highest conflict rate at 50% with DiCE explanations
- Different causal structures (chains, forks, colliders) produce systematically different counterfactual outcomes when evaluated using proper causal reasoning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Counterfactual explanations generated by ML models can differ from those generated using Pearl's SCM-based method due to ignoring true causal structure.
- Mechanism: The ML model treats all features as independent predictors without considering causal relationships (chains, forks, colliders), while Pearl's method incorporates the true data generating process via SCMs and do-calculus.
- Core assumption: The true causal structure in the data is known or can be accurately discovered.
- Evidence anchors:
  - [abstract] "CEs are currently generated from machine learning models that do not necessarily take into account the true causal structure in the data."
  - [section] "Whereas computing CEs from machine learning models would not necessarily incorporate causal relationships, Pearl’s method does."
- Break condition: If the true causal structure is unknown or incorrectly specified, Pearl's method will produce invalid counterfactuals.

### Mechanism 2
- Claim: Different causal structures (chains, forks, colliders) produce different counterfactual outcomes when evaluated using Pearl's method.
- Mechanism: Each causal structure affects how intervening on a feature changes the output differently - chains propagate effects through mediators, forks show spurious correlation when confounders are ignored, and colliders create bias when conditioning on common effects.
- Core assumption: The SCM correctly represents the true data generating process for each causal structure.
- Evidence anchors:
  - [section] "Using this method, I show how the CEs generated using current methods conflicted with those computed via Pearl’s method and how different causal structures affect the results."
  - [section] "the collider causal structure counterfactuals showed 50% conflict with the DiCE CEs."
- Break condition: If the causal structure is mis-specified, the evaluation will not reflect true counterfactual behavior.

### Mechanism 3
- Claim: Abduction-Action-Prediction steps in Pearl's method ensure counterfactuals maintain consistency with the original world except for the intervened feature.
- Mechanism: Abduction computes exogenous variables from factual data, Action intervenes by removing parent-child relationships for the counterfactual feature, and Prediction uses modified SCM to compute new outcomes while keeping other factors constant.
- Core assumption: Exogenous variables can be accurately computed from observed data.
- Evidence anchors:
  - [section] "We need to compute these variables first because they describe the 'situation' of an individual unit that must remain the same in both the factual and counterfactual worlds."
  - [section] "When we apply a counterfactual, we remove the relationship the feature has with its parents."
- Break condition: If exogenous variables cannot be accurately estimated, the counterfactual predictions will be invalid.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the true causal structure in real-world datasets used for counterfactual explanations?
- Basis in paper: [explicit] The paper mentions causal discovery as a way to find the true causal structure in real-life data, but notes that this is left for future work.
- Why unresolved: Causal discovery is a challenging problem and there is no universally accepted method to determine the true causal structure from observational data.
- What evidence would resolve it: Successfully applying causal discovery algorithms to real-world datasets used for counterfactual explanations and comparing the discovered structure with domain knowledge or experimental interventions.

### Open Question 2
- Question: How does the performance of counterfactual explanations generated by machine learning models compare to those generated by Pearl's method on real-world data?
- Basis in paper: [inferred] The paper shows some conflict between DiCE CEs and PCM on simulated data, suggesting that ML models may introduce errors. It suggests applying this method to real data with known causal structure.
- Why unresolved: The paper only tests on simulated data. Real-world data may have more complex causal structures and confounding factors that could affect the comparison.
- What evidence would resolve it: Conducting a study comparing ML-generated CEs and PCM-generated CEs on real-world datasets where the true causal structure is known or can be validated.

### Open Question 3
- Question: What is the optimal balance between preserving causal relationships and allowing counterfactual features to be independent of their parents?
- Basis in paper: [explicit] The paper discusses a tension between preserving causal constraints (as suggested by Mahajan et al. and Guidotti) and the need to intervene on features (as per Pearl's method) when generating counterfactuals.
- Why unresolved: This is a conceptual question about the nature of counterfactuals and how they should be generated. Different definitions and applications of counterfactuals may require different balances.
- What evidence would resolve it: Empirical studies comparing the performance and interpretability of CEs generated under different levels of causal constraint, and theoretical analysis of the trade-offs involved.

## Limitations
- The evaluation relies entirely on synthetic data with known causal structures, which may not capture real-world complexity
- Causal discovery is challenging and the method assumes true causal structure is known or can be discovered
- The 30% conflict rate may not generalize to complex, high-dimensional real-world scenarios

## Confidence
- High confidence: The theoretical framework connecting Pearl's SCM-based counterfactuals to ML model limitations is sound and well-established in causal inference literature
- Medium confidence: The empirical results showing 30% conflict rates are valid within the synthetic experimental setup but require validation on real-world data
- Low confidence: The generalizability of findings to complex, high-dimensional real-world scenarios with unknown causal structures
