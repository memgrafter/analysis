# A Symmetric Dual Encoding Dense Retrieval Framework for Knowledge-Intensive Visual Question Answering

## Quick Facts
- arXiv ID: 2304.13649
- Source URL: https://arxiv.org/abs/2304.13649
- Authors: 
- Reference count: 40
- Key outcome: DEDR achieves 11.6% and 30.9% MRR gains on retrieval and 5.5% and 8.5% accuracy gains on QA for OK-VQA and FVQA datasets.

## Executive Summary
This paper introduces DEDR, a dense retrieval framework for knowledge-intensive visual question answering (KI-VQA) that bridges uni-modal and multi-modal representation spaces through iterative knowledge distillation. The method employs symmetric dual encoding with separate uni-modal (text-based) and multi-modal encoders, transferring knowledge between them to leverage complementary information. To generate answers, the authors propose MM-FiD, a multi-modal extension of Fusion-in-Decoder that aggregates knowledge from retrieved passages. Experiments demonstrate significant improvements over state-of-the-art baselines on both OK-VQA and FVQA datasets.

## Method Summary
DEDR uses symmetric dual encoding with two bi-encoder models: one using uni-modal encoding (BERT) that processes image captions concatenated with questions, and one using multi-modal encoding (LXMERT) that processes both text and images. The framework performs iterative knowledge distillation where the better-performing encoder acts as teacher to transfer knowledge to the student encoder. For answer generation, MM-FiD extends the Fusion-in-Decoder architecture to handle multi-modal inputs by aggregating information from multiple retrieved passages. The approach also introduces PEMIR (Passage Expansion using Masked Image Representation) to enable text-only passages to be processed by multi-modal encoders.

## Key Results
- DEDR achieves 11.6% and 30.9% MRR gains on retrieval compared to state-of-the-art baselines for OK-VQA and FVQA respectively
- MM-FiD improves answer generation accuracy by 5.5% and 8.5% compared to state-of-the-art methods on OK-VQA and FVQA
- DEDR outperforms isolated uni-modal and multi-modal encoders, validating the effectiveness of knowledge distillation
- The framework demonstrates particular effectiveness on FVQA, which has a smaller training set

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Iterative knowledge distillation between symmetric uni-modal and multi-modal encoders improves retrieval performance by aligning their representation spaces.
- Mechanism: The DEDR framework trains two symmetric bi-encoder models separately - one using uni-modal encoding (𝐸𝑇) and one using multi-modal encoding (𝐸𝑀𝑀). Then it performs iterative knowledge distillation where one model acts as teacher and the other as student, transferring knowledge about how to score passages between the two different embedding spaces.
- Core assumption: Uni-modal and multi-modal encoders capture complementary information about KI-VQA inputs, and transferring knowledge between them helps each model learn the perspective of the other.
- Evidence anchors:
  - [abstract] "We introduce an iterative knowledge distillation approach that bridges the gap between the representation spaces in these two encoders."
  - [section 4.3] "In this method, we first use the more effective encoder, based on the performance of the validation set, as the teacher and the other encoder as the student."
  - [corpus] Weak - corpus neighbors discuss retrieval and encoding but not specifically knowledge distillation between uni-modal and multi-modal spaces.
- Break condition: If the uni-modal and multi-modal encoders learn similar representations or if one consistently outperforms the other across all queries, knowledge distillation would provide diminishing returns.

### Mechanism 2
- Claim: Converting images to text descriptions and using symmetric uni-modal encoding preserves relevant information while enabling shared representation spaces.
- Mechanism: The uni-modal encoding approach uses ExpansionNet v2 to generate textual descriptions of images, then concatenates these captions with questions and encodes everything using BERT. This allows the same text encoder to process both queries and passages in a shared embedding space.
- Core assumption: Image captioning can generate sufficient textual descriptions to capture the visual information needed for KI-VQA tasks.
- Evidence anchors:
  - [section 4.1] "we use the ExpansionNet v2 [18] architecture to implement 𝜙𝐼 →𝑇" and "Expansion V2 is an encoder-decoder architecture designed on top of the Swin-Transformer [33]"
  - [section 6.3] "This highlights the importance of representing images in KI-VQA tasks" and "sparse retrieval models achieve higher MRR on FVQA than on OK-VQA"
  - [corpus] Weak - corpus neighbors don't discuss image-to-text conversion for retrieval.
- Break condition: If the generated captions miss critical visual details or if the image content is too complex to be captured in text form, the uni-modal approach would fail to represent the query adequately.

### Mechanism 3
- Claim: Multi-modal encoding with masked image representation (PEMIR) enables text-only passages to be processed by multi-modal encoders without losing information.
- Mechanism: For passages that contain only text, PEMIR feeds the passage as text input and uses masked image tokens (bounding boxes of [0.0, 0.0, 1.0, 1.0]) to create a multi-modal representation. This forces the model to generate visual representations based on the textual content.
- Core assumption: LXMERT's pre-training with Masked Object Prediction enables it to effectively generate meaningful visual representations from text alone.
- Evidence anchors:
  - [section 4.2] "we propose a simple yet effective technique that we call Passage Expansion using Masked Image Representation (PEMIR)" and "Since LXMERT has been pre-trained with different pre-training objectives, including Masked Object Prediction, it is a perfect fit for our unified multi-modal representation learning."
  - [section 6.3] "Interestingly, sparse retrieval models achieve higher MRR on FVQA than on OK-VQA, while dense retrieval models perform significantly better on the OK-VQA dataset."
  - [corpus] Weak - corpus neighbors discuss multi-modal retrieval but not masked image techniques for text processing.
- Break condition: If the masked image tokens don't effectively force the model to create meaningful visual representations from text, or if LXMERT's pre-training doesn't generalize well to this novel use case.

## Architecture Onboarding

- Component map:
  - Image Captioner (ExpansionNet v2) -> Uni-modal Encoder (BERT) -> Knowledge Distillation -> Aggregation -> Retrieval -> MM-FiD -> Answer Generation
  - Multi-modal Encoder (LXMERT) -> Knowledge Distillation -> Aggregation -> Retrieval -> MM-FiD -> Answer Generation

- Critical path: Image → Captioner → Uni-modal Encoder → Knowledge Distillation → Aggregation → Retrieval → MM-FiD → Answer Generation

- Design tradeoffs:
  - Symmetric vs. asymmetric architectures: DEDR uses symmetric dual encoding while baselines like BERT-LXMERT use asymmetric approaches
  - Knowledge distillation vs. joint training: DEDR uses iterative knowledge distillation instead of training both encoders jointly
  - Image captioning vs. object detection: DEDR uses open-ended captions rather than predefined object categories

- Failure signatures:
  - Poor retrieval performance on validation set indicates issues with either encoder or knowledge distillation
  - Disparity between 𝐸𝑇 and 𝐸𝑀𝑀 performance suggests complementary information exists (good) or fundamental representation mismatch (bad)
  - MM-FiD accuracy plateaus despite increasing number of retrieved passages suggests retrieval quality ceiling

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of DEDR and MM-FiD scale with increasing dataset sizes, particularly for the FVQA dataset which has a smaller training set compared to OK-VQA?
- Basis in paper: [inferred] The paper notes that "asymmetric models often require more training data" and observes larger gains on FVQA, which has a smaller training set, suggesting a potential dataset size sensitivity.
- Why unresolved: The paper only reports results on the provided datasets and does not conduct experiments with artificially scaled dataset sizes or explore the relationship between dataset size and model performance.
- What evidence would resolve it: Experiments varying the training set size for both OK-VQA and FVQA, plotting performance metrics against dataset size, and analyzing the learning curves of DEDR and MM-FiD.

### Open Question 2
- Question: What is the impact of different pre-training objectives and data on the representation spaces of uni-modal (BERT) and multi-modal (LXMERT) language models, and how does this influence the effectiveness of the proposed iterative knowledge distillation approach?
- Basis in paper: [explicit] The paper states that "𝐸𝑇 and 𝐸𝑀𝑀 represent the KI-VQA inputs from different perspectives; 𝐸𝑇 only considers the textual representation of the inputs, while 𝐸𝑀𝑀 considers their multi-modal representations. These models also use unique pre-training data and objectives."
- Why unresolved: While the paper hypothesizes that these differences provide complementary information and validates this through experiments, it does not delve into the specific characteristics of the pre-training objectives and data that contribute to this complementarity.
- What evidence would resolve it: A detailed analysis of the pre-training objectives and data used for BERT and LXMERT, identifying the key differences and their impact on the learned representations. This could involve visualizing the embedding spaces, analyzing the attention patterns, and conducting ablation studies on the pre-training components.

### Open Question 3
- Question: Can the proposed DEDR and MM-FiD framework be extended to other knowledge-intensive multi-modal tasks beyond visual question answering, such as knowledge-intensive visual dialogue or knowledge-intensive image retrieval?
- Basis in paper: [explicit] The paper concludes by stating, "We further plan to expand the applications of knowledge-intensive multi-modal tasks beyond question answering."
- Why unresolved: The paper focuses solely on knowledge-intensive visual question answering and does not explore the applicability of the proposed framework to other related tasks.
- What evidence would resolve it: Adapting DEDR and MM-FiD to other knowledge-intensive multi-modal tasks, evaluating their performance on benchmark datasets, and comparing the results to state-of-the-art methods. This would involve modifying the input and output formats, adjusting the training objectives, and potentially incorporating task-specific components.

## Limitations

- Knowledge Distillation Stability: The paper doesn't analyze convergence behavior or sensitivity to hyperparameters like teacher-student selection frequency and iteration count.
- Image Captioning Quality Impact: The approach heavily relies on ExpansionNet v2 for image-to-text conversion, but lacks quantitative analysis of caption quality impact on end-to-end performance.
- PEMIR Generalization: The masked image representation technique assumes LXMERT's pre-training enables effective visual representation generation from text alone, which may not hold for all question types.

## Confidence

**High Confidence**: The core claim that DEDR improves retrieval performance over baseline methods (11.6% MRR gain on OK-VQA) is supported by experimental results with clear metrics and statistical significance.

**Medium Confidence**: The mechanism claims about knowledge distillation bridging representation spaces are plausible given the iterative training procedure, but lack detailed analysis of what knowledge is actually transferred between modalities.

**Low Confidence**: The claim that image captioning is sufficient for representing visual information in KI-VQA tasks lacks direct evidence - the paper doesn't compare against alternative approaches like object detection or region-based features.

## Next Checks

1. **Convergence Analysis**: Track and visualize the knowledge distillation process by measuring encoder agreement (e.g., cosine similarity of top-10 retrieved passages) across iterations to identify optimal stopping points and verify that knowledge is actually being transferred.

2. **Caption Quality Impact Study**: Implement an ablation study where different image captioning methods (from simple object detection to open-ended captions) are evaluated to quantify the impact of caption quality on final KI-VQA performance.

3. **Cross-Dataset Generalization Test**: Evaluate DEDR on a held-out subset of OK-VQA questions that require specific visual attributes (color, spatial relationships, fine-grained details) to test whether PEMIR can handle diverse visual reasoning requirements.
