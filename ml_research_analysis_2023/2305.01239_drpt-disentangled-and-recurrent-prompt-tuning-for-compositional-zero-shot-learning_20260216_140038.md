# DRPT: Disentangled and Recurrent Prompt Tuning for Compositional Zero-Shot Learning

## Quick Facts
- arXiv ID: 2305.01239
- Source URL: https://arxiv.org/abs/2305.01239
- Authors: 
- Reference count: 40
- Key outcome: DRPT significantly outperforms state-of-the-art methods on benchmark datasets UT-Zappos, AO-Clevr, and C-GQA, achieving higher accuracy and efficiency

## Executive Summary
This paper introduces DRPT, a novel Disentangled and Recurrent Prompt Tuning framework for Compositional Zero-Shot Learning (CZSL). CZSL aims to recognize novel concepts composed of known knowledge without training samples, but existing methods either fail to utilize the intrinsic relationship between state and object or cannot generalize well to unseen concepts. DRPT treats states and objects as learnable tokens embedded in prompts and uses a disentangled and recurrent tuning strategy to optimize token parameters. Experiments show DRPT significantly outperforms state-of-the-art methods on benchmark datasets, achieving higher accuracy and efficiency.

## Method Summary
DRPT uses pre-trained CLIP vision-language models with learnable prompt embeddings for state and object tokens. The method employs a progressive three-phase tuning strategy: first optimizing object tokens while freezing state tokens, then optimizing state tokens while freezing object tokens, and finally jointly optimizing both. The framework also quantifies entanglement between states and objects using novel metrics (average entanglement rate, variance per state/object) and applies reweighting to the classification loss to mitigate long-tail distribution effects.

## Key Results
- DRPT improves AUC by +5.5%, +1.7%, and +0.6% on UT-Zappos, AO-Clevr, and C-GQA respectively
- DRPT improves HM by +4.5% on UT-Zappos compared to baseline methods
- The disentangled tuning strategy effectively reduces entanglement bias and improves generalization to unseen compositions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The disentangled and recurrent tuning strategy prevents prompt parameters from being trapped in local optima due to uneven entanglement traction forces.
- Mechanism: By alternating between freezing and updating state or object tokens in a progressive sequence (object → state → object+state), the model allows each token type to learn more independent and clean feature parameters before joint optimization. This reduces mutual interference during parameter updates.
- Core assumption: Entanglement between state and object tokens causes them to pull each other's optimization trajectory toward suboptimal regions; decoupling the update schedule can break this pattern.
- Evidence anchors:
  - [abstract] "instead of jointly tuning state and object, we devise a disentangled and recurrent tuning strategy to suppress the traction force caused by entanglement and gradually optimize the token parameters"
  - [section 3.3] "By freezing the parameters of some prompt embeddings, the other embeddings could learn their feature space more independently"
- Break condition: If entanglement is uniform or negligible, the benefit of this sequential freezing strategy may disappear, and joint training could suffice.

### Mechanism 2
- Claim: Quantifying entanglement and rebalancing the classification loss mitigates long-tail distribution effects that otherwise bias optimization toward highly entangled compositions.
- Mechanism: Compute entanglement statistics (average entanglement rate, variance per state/object), then reweight the cross-entropy loss so that low-entanglement compositions receive stronger gradient signals and high-entanglement ones are dampened, preventing dominant prompts from overwhelming updates.
- Core assumption: Entanglements are not uniformly distributed; some states/objects participate in many compositions while others in few, creating an imbalance that harms learning.
- Evidence anchors:
  - [section 3.3] "we design two new metrics to quantify the entanglement between them" and "reweight the cross entropy loss of classification loss"
  - [section 3.3] Equations for computing average entanglement rate and variance
- Break condition: If the dataset has balanced composition frequencies, reweighting may be unnecessary and could even hurt performance.

### Mechanism 3
- Claim: Treating state and object as learnable tokens within prompts leverages the generalization ability of pre-trained vision-language models while allowing compositional flexibility.
- Mechanism: Initialize prompts with a template like "a photo of [state] [object]" where [state] and [object] are learnable embedding parameters; fine-tune only these parameters on seen compositions so the model can generalize to unseen compositions without retraining the entire CLIP backbone.
- Core assumption: CLIP's pre-trained text encoder can map arbitrary token sequences into meaningful semantic space, and fine-tuning just the prompt tokens is sufficient to adapt to new compositional tasks.
- Evidence anchors:
  - [abstract] "the state and object primitives are deemed as learnable tokens of vocabulary embedded in prompts"
  - [section 3.2] "the two vocabulary [state] and [object] are learnable during training on the seen text-image pairs"
- Break condition: If the pre-trained CLIP text encoder is not sufficiently aligned with the compositional semantics of the dataset, prompt tuning alone may fail to capture necessary discriminative features.

## Architecture Onboarding

- Component map: Pre-trained CLIP image and text encoders (frozen) → Learnable prompt embeddings for state and object tokens → Cosine similarity scoring → Cross-entropy classification loss with entanglement-aware reweighting → Progressive tuning scheduler controlling which tokens are frozen/unfrozen
- Critical path: Input image → CLIP image encoder → Image feature → Cosine similarity with → CLIP text encoder applied to prompts → Prompt embeddings (state/object) → Classification score → Loss → Backward pass → Prompt parameter updates
- Design tradeoffs: Freezing encoder parameters saves compute and avoids overfitting but limits adaptation; disentangled tuning increases training complexity but reduces entanglement bias; reweighting helps long-tail but may underfit frequent compositions
- Failure signatures: High HM but low Unseen accuracy indicates bias toward seen compositions; low overall accuracy suggests poor prompt embedding initialization or inappropriate disentanglement schedule; unstable training may indicate incorrect entanglement weighting
- First 3 experiments:
  1. Baseline: Joint prompt tuning (no disentanglement) on UT-Zappos, measure S/U/HM/AUC
  2. Disentangled tuning only (object→state→joint, no reweighting) on UT-Zappos, compare to baseline
  3. Full DRPT (disentangled + entanglement reweighting) on UT-Zappos, compare to previous runs and CSP baseline

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the entanglement strength vary across different types of visual concepts (e.g., animate vs inanimate objects)?
- Basis in paper: [explicit] The paper quantifies entanglement using metrics like 𝐸𝑛𝑡𝑎𝑣𝑔, 𝐸𝑛𝑡 𝑎𝑣𝑎𝑟, and 𝐸𝑛𝑡𝑜𝑣𝑎𝑟, and mentions that objects like "tiger" may have different entanglement patterns compared to objects like "apple."
- Why unresolved: The paper analyzes entanglement generally but doesn't specifically investigate whether different categories of objects exhibit systematically different entanglement patterns.
- What evidence would resolve it: Detailed analysis of entanglement metrics broken down by object categories (e.g., animals vs vehicles vs clothing) across multiple datasets.

### Open Question 2
- Question: Can the progressive tuning strategy be extended to more than three phases, and would additional phases improve performance?
- Basis in paper: [explicit] The paper proposes a three-phase tuning strategy (object→state→object+state) but mentions that "the dynamic transformation of sequences can be further studied in future work, such as dynamic 𝐾 value and automatic status switching."
- Why unresolved: The paper only tests a fixed three-phase approach and suggests but doesn't investigate more complex tuning schedules.
- What evidence would resolve it: Experiments comparing performance with 4+ phase tuning strategies, including automatically determined transition points.

### Open Question 3
- Question: How does the entanglement quantification method generalize to other zero-shot learning tasks beyond CZSL?
- Basis in paper: [inferred] The paper introduces novel metrics for quantifying entanglement in CZSL and mentions "DRPT is an illuminating strategy for both quantifying entanglement and fine-tuning," suggesting broader applicability.
- Why unresolved: The paper focuses exclusively on CZSL applications and doesn't demonstrate whether the entanglement metrics work for other zero-shot learning scenarios.
- What evidence would resolve it: Application of the 𝐸𝑛𝑡𝑎𝑣𝑔, 𝐸𝑛𝑡 𝑎𝑣𝑎𝑟, and 𝐸𝑛𝑡𝑜𝑣𝑎𝑟 metrics to standard zero-shot learning tasks and evaluation of their predictive power for model performance.

## Limitations

- The effectiveness of disentangled tuning depends heavily on the specific degree of entanglement present in each dataset
- The sequential freezing approach may be overfit to particular datasets where states and objects exhibit strong compositional bias
- The entanglement quantification and reweighting scheme requires careful hyperparameter tuning (reweighting coefficient α) that isn't fully specified

## Confidence

- **High confidence**: Using pre-trained CLIP with learnable prompt tokens for compositional adaptation (Mechanism 3)
- **Medium confidence**: Disentangled progressive tuning schedule and entanglement-aware reweighting (Mechanisms 1 and 2)
- **Low confidence**: Claims about "suppressing traction forces" are somewhat metaphorical and lack rigorous mathematical formulation

## Next Checks

1. **Ablation on tuning schedule**: Run experiments with only the object→state phase (skipping the final joint tuning) and with random instead of progressive freezing schedules to quantify the true benefit of the proposed disentangled approach versus simple prompt tuning.

2. **Entanglement sensitivity analysis**: Vary the reweighting coefficient α across a wide range (e.g., 0.1 to 10.0) and measure how HM and AUC scores change; this would reveal whether the entanglement-aware reweighting is robust or requires precise calibration.

3. **Cross-dataset generalization**: Train DRPT on one dataset (e.g., UT-Zappos) and test zero-shot compositional generalization on another (e.g., AO-Clevr) without fine-tuning to evaluate whether learned disentangled prompts truly capture compositional semantics or merely memorize dataset-specific patterns.
