# Reinforcement Learning with Simple Sequence Priors

## Quick Facts
- arXiv ID: 2305.17109
- Source URL: https://arxiv.org/abs/2305.17109
- Reference count: 40

## Executive Summary
This paper introduces a novel approach to reinforcement learning that encourages agents to solve tasks using simple, compressible action sequences. The authors propose two methods: LZ-SAC, which uses an off-the-shelf compression algorithm (LZ4) as a prior, and SPAC, which uses a learned sequence prior in the form of a causal transformer. These methods augment the reward function to incentivize policies that produce action sequences that are easier to compress, leading to more information-efficient and robust policies. Experiments on continuous control tasks demonstrate that LZ-SAC outperforms state-of-the-art model-free RL algorithms, while both methods lead to improved robustness to noisy observations and open-loop control capabilities.

## Method Summary
The authors propose two approaches to incorporate sequence priors into reinforcement learning: SPAC and LZ-SAC. SPAC uses a learned sequence prior in the form of a causal transformer model, while LZ-SAC uses an off-the-shelf compression algorithm (LZ4). Both methods augment the reward function to encourage policies that produce action sequences that are easier to compress. The compressibility term is computed using the difference in encoded length when adding the next action to the sequence. The augmented reward function is then used to update the actor and critic networks in an off-policy manner, building upon the Soft Actor-Critic (SAC) algorithm. The authors demonstrate the effectiveness of their approach on continuous control tasks from the DeepMind Control Suite, showing improved learning speed, final performance, and robustness to noisy observations.

## Key Results
- LZ-SAC consistently outperforms state-of-the-art model-free RL algorithms in terms of learning speed and final performance on continuous control tasks
- The learned sequence priors lead to more information-efficient policies that use fewer bits of information to collect a certain amount of reward
- The approach demonstrates improved robustness to noisy observations and enables open-loop control capabilities

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LZ-SAC learns to solve tasks with compressible action sequences by using an off-the-shelf compression algorithm (LZ4) to regularize the reward function.
- Mechanism: The LZ4 algorithm compresses action sequences by replacing repeating subsequences with references to earlier occurrences. By rewarding policies that produce sequences that are easier to compress (measured by the reduction in encoded length when adding the next action), LZ-SAC incentivizes the agent to discover and exploit temporal regularities and repetitions in its behavior.
- Core assumption: Tasks can be solved using action sequences that contain repetitive or periodic patterns that are compressible with standard compression algorithms.
- Evidence anchors:
  - [abstract]: "We explore two possible sources of simple action sequences: Sequences that can be learned by autoregressive models, and sequences that are compressible with off-the-shelf data compression algorithms."
  - [section 3.2]: "Since compression algorithms like LZ4 are fast, the sequence prior can be implemented with little computational overhead."
- Break condition: If tasks require highly complex, non-repetitive action sequences to maximize reward, or if the compression algorithm fails to capture the relevant structure in the action sequences.

### Mechanism 2
- Claim: SPAC learns to solve tasks with compressible action sequences by using a learned sequence prior in the form of a causal transformer model.
- Mechanism: The causal transformer is trained to predict future actions based on past actions. By augmenting the reward function to encourage policies that produce action sequences that are predictable by the transformer, SPAC incentivizes the agent to discover and exploit temporal regularities and patterns in its behavior.
- Core assumption: Tasks can be solved using action sequences that contain structure and regularity that can be learned by an autoregressive sequence model.
- Evidence anchors:
  - [abstract]: "We explore two possible sources of simple action sequences: Sequences that can be learned by autoregressive models..."
  - [section 3.1]: "Optimizing this objective, the agent will get rewarded for performing behaviors that the sequence model can predict better."
- Break condition: If tasks require highly complex, non-repetitive action sequences to maximize reward, or if the transformer fails to learn the relevant structure in the action sequences.

### Mechanism 3
- Claim: The sequence priors lead to information-regularized policies that are more robust to noisy observations and can perform open-loop control.
- Mechanism: By encouraging policies to produce action sequences that are predictable (either by a learned model or a compression algorithm), the sequence priors effectively regularize the mutual information between states and actions. This means the policies use fewer bits of information to make decisions, which makes them more robust to noise and enables them to generate rewarding behaviors in an open-loop setting.
- Core assumption: Information-regularized policies are more robust to noise and can generalize better to open-loop control.
- Evidence anchors:
  - [abstract]: "These priors also produce a powerful information-regularized agent that is robust to noisy observations and can perform open-loop control."
  - [section 5]: "This indicates that action sequence compression is a powerful information-regularizer, allowing agents to find policies that use significantly fewer bits of information to collect a certain amount of reward than the competitor approaches."
- Break condition: If the tasks do not benefit from information regularization, or if the noise levels are too high for the regularized policies to cope with.

## Architecture Onboarding

- Component map:
  Environment -> Policy Network -> Q-Network -> Sequence Prior -> Replay Buffer

- Critical path:
  1. Agent interacts with the environment, collecting state-action-reward-next state tuples.
  2. Action sequences are stored in the replay buffer along with the corresponding states and rewards.
  3. The sequence prior (transformer or LZ4) is used to compute the compressibility of the action sequences.
  4. The compressibility term is used to augment the reward function.
  5. The actor and critic networks are updated using the augmented rewards.

- Design tradeoffs:
  - SPAC vs. LZ-SAC: SPAC learns a sequence prior from scratch, which can capture more complex patterns but requires additional training and may not be as immediately effective as LZ-SAC. LZ-SAC uses an off-the-shelf compression algorithm, which is computationally efficient but may not capture all relevant structure.
  - Fixed vs. Adaptive Prior: LZ-SAC uses a fixed prior (LZ4), while SPAC adapts the prior during training. Fixed priors are more stable but may be less effective at capturing task-specific structure.

- Failure signatures:
  - If the agent fails to learn: Check if the sequence prior is correctly implemented and if the hyperparameters (e.g., α, context length) are properly tuned.
  - If the agent learns but performs poorly: Check if the sequence prior is capturing the relevant structure in the action sequences and if the augmented reward function is properly balancing the extrinsic reward and the compressibility term.
  - If the agent is not robust to noise: Check if the information regularization is sufficient and if the noise levels are within the range the agent can handle.

- First 3 experiments:
  1. Train LZ-SAC and SAC on a simple control task (e.g., cartpole) and compare their learning curves and final performance.
  2. Train SPAC and SAC on a task with clear periodic patterns (e.g., hopper hop) and analyze the learned action sequences for compressibility.
  3. Evaluate the robustness of LZ-SAC and SAC to observation noise by adding Gaussian noise to the observations and measuring the impact on performance.

## Limitations
- The approach may not scale well to tasks requiring highly complex, non-repetitive action sequences
- The effectiveness of LZ4 in capturing task-relevant structure depends on the presence of periodic patterns in the action sequences
- The information regularization claims need more rigorous testing across diverse task types
