# TempT: Temporal consistency for Test-time adaptation

## Quick Facts
- arXiv ID: 2303.10536
- Source URL: https://arxiv.org/abs/2303.10536
- Reference count: 27
- Primary result: Achieved F1 scores of 0.323 (ResNet-18) and 0.345 (SE-ResNext-101) on AffWild2 after test-time adaptation

## Executive Summary
TempT introduces a test-time adaptation method for video-based facial expression recognition that leverages temporal consistency across sequential frames as a self-supervision signal. The approach adapts 2D CNN models at test time by minimizing prediction differences after temporal smoothing, using a median filter-based loss function to update batch normalization parameters. Evaluated on the AffWild2 dataset, TempT achieved competitive performance compared to previous work while demonstrating that temporal coherence can effectively enhance model performance without additional supervision.

## Method Summary
TempT performs test-time adaptation for video-based facial expression recognition by enforcing temporal consistency across sequential frames. The method pretrains a 2D CNN (ResNet-18 or SE-ResNext-101) on combined datasets (AffWild2, RAF-DB, Affectnet) using LDAM loss, then adapts at test time by temporally smoothing predictions with a median filter and minimizing MSE between original and smoothed predictions. Adaptation updates only the weight and bias terms in batch normalization layers while freezing running statistics, following the analysis that this subset provides sufficient expressivity while preventing overfitting. The approach focuses on unimodal visual data and achieves F1 scores of 0.323 with ResNet-18 and 0.345 with SE-ResNext-101 after adaptation.

## Key Results
- Achieved F1 score of 0.323 with ResNet-18 backbone after adaptation
- Achieved F1 score of 0.345 with SE-ResNext-101 backbone after adaptation
- Demonstrated competitive performance compared to previous years' reported results on AffWild2
- Showed that temporal coherence can enhance model performance without additional supervision

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Temporal smoothing of predictions reduces high-frequency noise and enforces consistency across sequential frames
- Mechanism: The method applies a median filter to temporally smooth prediction sequences, creating a more stable target signal that the model learns to match
- Core assumption: Prediction sequences contain high-frequency components that can be smoothed without losing essential expression information
- Evidence anchors:
  - [section] "Empirically we found these time series to contain strong high-frequency components and when they are subject to a low pass filter, the results look more desirable."
  - [abstract] "Our approach focuses solely on the unimodal visual aspect of the data and utilizes a popular 2D CNN backbone in contrast to larger sequential or attention-based models used in other approaches."
  - [corpus] Weak evidence - corpus papers focus on domain adaptation and video editing but don't specifically discuss temporal smoothing for FER

### Mechanism 2
- Claim: Updating batch normalization parameters provides sufficient model expressivity while preventing overfitting during test-time adaptation
- Mechanism: The loss function enables backpropagation to update only the weight and bias terms in batch normalization layers, while freezing running statistics
- Core assumption: Batch normalization parameters can capture domain shift without requiring full model fine-tuning
- Evidence anchors:
  - [section] "Following the analysis in [7], we select this subset to be the weight and bias terms in batch normalization layers, while freezing the running statistics. This has been shown to yield enough expressivity while preventing overfitting."
  - [abstract] "Our experimental results demonstrate that TempT has competitive performance in comparison to previous years' reported performances"
  - [corpus] Weak evidence - corpus papers discuss domain adaptation but don't specifically validate batch norm parameter updates for temporal consistency

### Mechanism 3
- Claim: Self-supervised temporal consistency loss enables adaptation without requiring labeled target data
- Mechanism: The MSE between original predictions and temporally smoothed predictions creates a self-supervision signal that drives adaptation
- Core assumption: Temporal consistency is a valid proxy for correct expression classification when labels are unavailable
- Evidence anchors:
  - [section] "We calculate the mean-squared error between the original and target signals and use back-propagation to update a subset of model parameters."
  - [abstract] "Our approach focuses solely on the unimodal visual aspect of the data and utilizes a popular 2D CNN backbone"
  - [corpus] Weak evidence - corpus papers discuss self-supervision but don't specifically validate temporal consistency for FER

## Architecture Onboarding

- Component map:
  Input (112×112×3 RGB frames) → CNN backbone (ResNet-18 or SE-ResNext-101) → FC layers with weight normalization → Predictions → Temporal smoothing → MSE loss → Batch norm parameter updates

- Critical path: Frame → CNN backbone → FC layers → Predictions → Temporal smoothing → MSE loss → Batch norm parameter updates

- Design tradeoffs:
  - Using 2D CNNs instead of 3D/attention models trades temporal modeling capability for computational efficiency
  - Updating only batch norm parameters limits expressivity but reduces overfitting risk
  - Random frame sampling introduces stochasticity that requires multiple runs for reliable evaluation

- Failure signatures:
  - Performance degradation when expression changes are rapid or non-smooth
  - Limited adaptation when domain shift is too large for batch norm parameters to capture
  - High variance in results due to stochastic sampling

- First 3 experiments:
  1. Verify temporal smoothing effect by plotting prediction sequences before and after median filtering
  2. Test adaptation on a single video with known temporal patterns to validate the consistency enforcement
  3. Compare performance with different low-pass filters (median vs. Gaussian) to assess filter choice impact

## Limitations
- The method's effectiveness is constrained by the assumption of relatively smooth facial expression transitions, which may not hold for rapid or complex emotional displays
- Updating only batch normalization parameters limits adaptation capacity compared to full fine-tuning approaches, potentially restricting performance gains on challenging domain shifts
- The stochastic nature of random frame sampling introduces significant variance in results, requiring multiple runs for reliable evaluation

## Confidence
**High Confidence:** The core mechanism of using temporal smoothing for consistency enforcement is well-supported by empirical observations in the paper and is theoretically sound.

**Medium Confidence:** The choice of batch normalization parameters for adaptation is supported by previous literature [7], but the specific effectiveness for FER applications requires further validation.

**Low Confidence:** The assertion that temporal consistency alone provides sufficient adaptation capability is questionable, given that the method achieves moderate F1 scores that lag behind some supervised approaches.
