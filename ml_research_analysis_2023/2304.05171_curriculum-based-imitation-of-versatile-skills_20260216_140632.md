# Curriculum-Based Imitation of Versatile Skills

## Quick Facts
- arXiv ID: 2304.05171
- Source URL: https://arxiv.org/abs/2304.05171
- Reference count: 28
- Primary result: Proposed ML-Cur method significantly improves valid strike rates and reduces distance errors in robot control tasks compared to state-of-the-art baselines.

## Executive Summary
This paper addresses the challenge of learning from multi-modal human demonstrations for robot control, where traditional maximum likelihood approaches struggle with mode averaging and outlier sensitivity. The proposed ML-Cur method introduces a curriculum-based approach using per-component weights and Gaussian context distributions within a Mixture of Experts framework. By allowing each expert to specialize on local context regions while incentivizing broader data coverage via an entropy bonus, ML-Cur achieves significant improvements in robot control tasks like table tennis and obstacle avoidance.

## Method Summary
ML-Cur employs a Mixture of Experts (MoE) framework with per-component weights and Gaussian context distributions to learn from multi-modal demonstrations. Each expert specializes on data it can represent well while the entropy bonus encourages coverage of diverse data points. The method optimizes a weighted likelihood objective with responsibilities and entropy terms, enabling specialized behavior in local context regions and preventing outlier sensitivity. The approach is evaluated on simulated and real robot tasks, showing significant improvements over state-of-the-art baselines.

## Key Results
- Significant improvements in valid strike rates and mean distance errors compared to EM, EIM, MDN, and KNN baselines
- Successful application to both simulated table tennis and real robot obstacle avoidance tasks
- Ablation studies confirm the importance of data weights, locality constraints, and responsibility terms

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The per-component data weight ν allows each expert to specialize on data points it can represent well, avoiding outlier-sensitivity.
- Mechanism: Each component assigns high weights to demonstrations where its current model likelihood and context fit are high. This means poor-fit or outlier data points get low weights and minimal influence.
- Core assumption: Data weights can be learned jointly with model parameters without destabilizing the optimization.
- Evidence anchors:
  - [abstract] "allowing the model to specialize on data it can represent while incentivizing it to cover as much data as possible by an entropy bonus"
  - [section IV] "By introducing a weight νi for each demonstration the component is able to only consider a relevant subset of the given demonstrations, i.e., its curriculum, allowing the component to ignore outliers or data points from other modes."
- Break condition: If entropy bonus α is too small, weights collapse to a single sample; if too large, weights become uniform and outlier-sensitivity returns.

### Mechanism 2
- Claim: The per-component Gaussian context distribution pη(c|o) prevents locality violations, enabling specialized behavior in local context regions.
- Mechanism: Each expert learns a Gaussian over contexts it covers. During training, only data points near this context mean get high weight, forcing the expert to learn a specialized policy for that region.
- Core assumption: Context space can be meaningfully partitioned into local Gaussian regions that each expert can cover.
- Evidence anchors:
  - [abstract] "preventing locality-violations in the context space and allows each component to learn specialized behavior for a region of the context space."
  - [section IV] "a per-component Gaussian context distribution pη(c|o) restricting the component to a local subspace of the context and enables the component to learn more specialized behavior"
- Break condition: If context space is too high-dimensional or samples are too sparse, Gaussian fits become poor and locality benefits vanish.

### Mechanism 3
- Claim: The entropy bonus over data weights prevents mode averaging by encouraging each component to cover a distinct curriculum.
- Mechanism: Maximizing entropy of per-component weights forces experts to spread over many samples, but the weighted likelihood update keeps them focused on the data they can represent. The responsibilities term (1/α * log ν) in the lower bound further pushes components apart.
- Core assumption: Weighted likelihood + entropy bonus is a stable objective that balances coverage vs. specialization.
- Evidence anchors:
  - [abstract] "while still incentivizing a larger coverage of data points through an entropy bonus."
  - [section IV] "By introducing an entropy bonus over the data weights H [ν] =−∑iνi logνi, yielding the single component objective"
- Break condition: If α is mis-tuned (too small/large) or responsibilities are ignored, components overlap and mode averaging reoccurs.

  - Why needed here: Lets each expert "choose" its own training subset, avoiding outliers and mode averaging.

## Architecture Onboarding

- Component map:
  Input: Context vector c (environment state, goal) -> K MoE components -> Output: ProMP parameter distribution p(ω|c)

- Critical path:
  1. Transform demos to ProMP weights
  2. Initialize MoE parameters
  3. Iterate: (a) update θ, η, λ via weighted ML; (b) update νo,i via closed form; (c) optionally autotune αo

- Design tradeoffs:
  - Linear experts: fast, interpretable, but limited expressiveness
  - Number of components K: more = finer specialization but more parameters and risk of overlap
  - Entropy scaling α: balances coverage vs. specialization

- Failure signatures:
  - Low valid strike rate + high distance error: mode averaging
  - High collision rate: locality violations or outlier inclusion
  - Degenerate weights (all mass on one sample): α too small

- First 3 experiments:
  1. Planar reacher toy task (visualize context ellipses, check locality)
  2. Table tennis simulation (measure valid strike rate, MDE)
  3. Real robot obstacle avoidance (evaluate collision rate, distance error)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the linear expert assumption be relaxed to handle higher-dimensional contexts like images or point clouds while maintaining computational tractability?
- Basis in paper: [explicit] "A limitation of our current approach is the linearity of the experts. While using a mixture of movement primitives still allows us to represent complex behavior it also limits our choice of the context space. Hence, the experiments in this paper do not consider high dimensional context, e.g., images or point clouds. However, for higher dimensional contexts, the linear representation would not be sufficient, and we would need to work with nonlinear experts."
- Why unresolved: The paper acknowledges the limitation but does not propose a specific method to extend the approach to nonlinear experts or high-dimensional contexts.
- What evidence would resolve it: A demonstration of the method applied to high-dimensional contexts with nonlinear experts, showing maintained performance and computational efficiency.

### Open Question 2
- Question: What is the optimal strategy for selecting the minimum number of effective samples per component (neff) in the autotuned entropy scaling approach?
- Basis in paper: [explicit] "A good choice is to set Hmin = log neff, where neff is the desired number of effective samples per component."
- Why unresolved: The paper suggests a heuristic for choosing neff but does not provide empirical evidence or a principled method for determining the optimal value across different tasks.
- What evidence would resolve it: A systematic study across diverse tasks showing the relationship between neff and performance, potentially leading to a principled selection method.

### Open Question 3
- Question: How does the method perform when the number of modes in the demonstrations exceeds the number of components in the mixture model?
- Basis in paper: [explicit] "If the number of components is less than the unknown number of modes present in the demonstrations, this problem even exists for mixture models that are optimized using common approaches such as EM and other likelihood-based methods."
- Why unresolved: The paper does not address the scenario where the number of modes exceeds the number of components, which could lead to mode averaging or poor coverage.
- What evidence would resolve it: Experimental results showing the method's performance with varying numbers of components relative to the number of modes, and analysis of how the method handles under-specification.

## Limitations

- The approach relies on Gaussian context distributions which may not capture complex, non-Gaussian patterns in the data
- The method's scalability to high-dimensional contexts or large numbers of components is not thoroughly discussed
- The evaluation focuses on specific tasks (table tennis, obstacle avoidance) and may not generalize to all robot control scenarios

## Confidence

- **High**: The core claim that ML-Cur improves upon state-of-the-art baselines in terms of valid strike rates and distance errors is supported by the experimental results.
- **Medium**: The mechanism by which the entropy bonus prevents mode averaging is plausible but not fully proven, as the exact form of the responsibility term is not specified.
- **Low**: The generalizability of the approach to high-dimensional contexts or large numbers of components is uncertain due to the lack of thorough discussion in the paper.

## Next Checks
