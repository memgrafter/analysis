# Towards predicting Pedestrian Evacuation Time and Density from Floorplans using a Vision Transformer

## Quick Facts
- arXiv ID: 2306.15318
- Source URL: https://arxiv.org/abs/2306.15318
- Reference count: 1
- Key outcome: Vision Transformer-based deep learning approach predicts pedestrian density heatmaps and evacuation time from building floorplans with 90%+ accuracy (MAE=4.65s, RE=8.62%)

## Executive Summary
This paper presents a Vision Transformer-based deep learning approach for predicting pedestrian density heatmaps and total evacuation time from building floorplans. The key contribution is developing a synthetic dataset generator using parametric BIM models and a conventional pedestrian simulator, enabling training of the network without requiring large real-world datasets. The architecture combines image processing with additional simulation parameters through self- and cross-attention mechanisms. Trained on 130,356 evacuation scenarios, the model achieves 90%+ accuracy in predicting total evacuation time and performs cell-wise density classification. The approach is integrated into the BIM-authoring tool Dynamo, providing instant simulation results without manual export or conversion steps, significantly accelerating the building design process.

## Method Summary
The method uses a Vision Transformer architecture that processes 640x640 pixel floorplan images divided into 16x16 pixel patches, combined with simulation parameters (origin/destination areas, agent counts, velocities) through cross-attention mechanisms. The model is trained on a synthetic dataset of 130,356 scenarios generated from three parametric BIM models with varied geometries. The network includes self-attention and cross-attention layers, a UPerNet decoder for density heatmap prediction across eight equitemporal frames, and a linear layer for evacuation time regression. Training uses a combined MSE and Tversky loss to handle both regression and classification tasks while addressing severe class imbalance where >95% of cells are empty.

## Key Results
- Achieved 90%+ accuracy in predicting total evacuation time with MAE=4.65s and RE=8.62%
- Successfully classified cell-wise density into four categories (0-3 agents) with Tversky loss handling >95% class imbalance
- Generated 130,356 synthetic evacuation scenarios from three parametric BIM models for training
- Integrated into Dynamo BIM tool for instant simulation results without manual export/conversion

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Vision Transformers effectively capture spatial relationships in floorplans that correlate with pedestrian flow patterns
- Mechanism: The ViT architecture processes 16x16 pixel patches of floorplan images through self-attention layers, allowing the model to learn hierarchical spatial representations that encode building layout features affecting pedestrian movement
- Core assumption: Floorplan spatial configurations contain sufficient information to predict density patterns and evacuation times
- Evidence anchors:
  - [abstract] "deep learning-based approach based on a Vision Transformer to predict density heatmaps over time"
  - [section] "basis of the model is the self- and cross-attention mechanisms that are commonly used in Vision Transformer models"
- Break condition: If floorplan features become too complex or multi-story, spatial correlations may weaken and require architectural modifications

### Mechanism 2
- Claim: Cross-attention between image features and simulation parameters enables context-aware predictions
- Mechanism: The cross-attention modules allow the model to weigh image features differently based on simulation parameters like agent count and velocity, creating parameter-conditioned density predictions
- Core assumption: Simulation parameters meaningfully modulate the relationship between floorplan features and pedestrian behavior
- Evidence anchors:
  - [section] "cross-attention mechanisms that are commonly used in Vision Transformer models" and "cross-attentional modules also take as input the shared layer feature vectors"
  - [section] "additional simulation information in the shape of vectors to the network, consisting of the numbers of (1) origins, (2) destinations and (3) agents per origin"
- Break condition: If parameter distributions in training data don't match real-world scenarios, cross-attention may learn spurious correlations

### Mechanism 3
- Claim: Synthetic data generation with parametric BIM models provides sufficient diversity for robust generalization
- Mechanism: The pipeline generates 130,356 scenarios across three parametric models with varied geometries and simulation parameters, creating a large synthetic dataset that captures the space of possible evacuation scenarios
- Core assumption: Synthetic scenarios adequately represent real-world evacuation conditions
- Evidence anchors:
  - [abstract] "implement a parametric data generation pipeline including a conventional simulator. This enables us to build a large synthetic dataset"
  - [section] "combinations of all parameter values amount to a total of 130,356 simulations"
- Break condition: If real-world scenarios contain patterns not represented in synthetic data (e.g., irregular room shapes, complex furniture layouts), model performance may degrade

## Architecture Onboarding

- Component map: Input -> Patch Embedding (16x16) -> Transformer Encoder (6 layers, self+cross-attention) -> UPerNet Decoder -> Density Heatmaps (8 frames) + Linear Layer -> Evacuation Time
- Critical path: Floorplan image -> patch embeddings -> self-attention -> cross-attention with simulation parameters -> decoder -> predictions
- Design tradeoffs:
  - Image size 640x640 vs. computational cost: Larger images capture more detail but increase training time and memory usage
  - Grid cell size 0.4x0.4m vs. accuracy: Smaller cells provide finer resolution but increase classification complexity and class imbalance
  - Tversky loss parameters α=0.1, β=0.9 vs. standard cross-entropy: Better handles class imbalance but requires careful tuning
- Failure signatures:
  - Poor evacuation time prediction: Check regression loss weighting (λT) and ensure sufficient parameter variation in training data
  - Dense class predictions missing: Verify class imbalance handling and Tversky loss parameters
  - General poor performance: Examine whether floorplan features are being adequately captured by patch embeddings
- First 3 experiments:
  1. Vary λT to balance classification vs. regression loss and observe effects on both metrics
  2. Test different patch sizes (8x8 vs 16x16) to see impact on spatial feature resolution
  3. Modify Tversky parameters (α, β) to explore class imbalance handling effectiveness

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the model's performance scale with increasingly complex building geometries beyond the simple office layouts tested?
- Basis in paper: [explicit] The authors note that their current parametric models are simple office buildings and acknowledge that runtime and accuracy may vary with more complex geometries, but do not test this
- Why unresolved: The evaluation only covers simple parametric models; no testing was done on real-world complex buildings with irregular shapes, multiple stories, or intricate architectural features
- What evidence would resolve it: Empirical testing on diverse real-world building datasets with varying complexity levels, measuring both accuracy and inference time compared to conventional simulators

### Open Question 2
- Question: What is the optimal cell size for density prediction across different building types and evacuation scenarios?
- Basis in paper: [explicit] The authors chose 0.4x0.4m cells based on common practice but acknowledge this as a design choice that could affect performance
- Why unresolved: The paper tests only one cell size without exploring how different resolutions affect accuracy, computational efficiency, or applicability to different building scales
- What evidence would resolve it: Systematic ablation studies varying cell sizes across multiple building types, measuring trade-offs between resolution, accuracy, and computational cost

### Open Question 3
- Question: How does the model generalize to different cultural or regional building layouts and pedestrian behaviors not represented in the synthetic dataset?
- Basis in paper: [explicit] The dataset is generated synthetically from parametric models, and the authors note limited availability of public datasets for training
- Why unresolved: The model is trained exclusively on synthetic data from office building layouts in one cultural context, with no validation on real-world data from diverse architectural traditions or pedestrian behavior patterns
- What evidence would resolve it: Testing on real-world evacuation data from diverse building types across different countries and cultures, comparing prediction accuracy against the synthetic-trained model

## Limitations
- Synthetic data validity: Model performance relies entirely on synthetic data from parametric BIM models, which may not capture real-world building evacuation complexities
- Limited architectural diversity: Three parametric models may not represent the full diversity of building types encountered in practice
- Generalization uncertainty: High accuracy on test set may not translate to completely unseen building types and evacuation scenarios

- The Tversky loss function effectively handles severe class imbalance in density predictions

**Medium Confidence (Level 2):**
- The model achieves 90%+ accuracy in evacuation time prediction (given limited real-world validation)
- Cross-attention mechanisms meaningfully improve prediction accuracy over self-attention alone

- The model generalizes to completely unseen building types and evacuation scenarios
- The 8.62% relative error in evacuation time prediction meets safety-critical requirements
- Synthetic data diversity sufficiently captures real-world pedestrian behavior complexity
