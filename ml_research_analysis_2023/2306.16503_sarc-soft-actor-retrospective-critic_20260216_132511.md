# SARC: Soft Actor Retrospective Critic

## Quick Facts
- arXiv ID: 2306.16503
- Source URL: https://arxiv.org/abs/2306.16503
- Reference count: 32
- Key outcome: SARC consistently improves SAC performance across 10/11 tasks with minimal code changes

## Executive Summary
SARC (Soft Actor Retrospective Critic) introduces a retrospective loss term to accelerate critic convergence in Soft Actor-Critic algorithms. The method pulls critic parameters toward optimal values while pushing them away from previous values, inspired by supervised learning techniques. The authors validate SARC across 11 continuous control environments, showing consistent improvements in both sample efficiency and final returns compared to SAC baseline.

## Method Summary
SARC modifies the SAC critic loss by adding a retrospective regularization term that simultaneously pulls parameters toward better predictions and pushes them away from previous values. The method uses a fixed κ=2 hyperparameter for the retrospective strength across all tasks. Implementation requires minimal changes to existing SAC code - primarily adding the retrospective loss computation to the critic update step. The authors use standard SAC hyperparameters and test across DeepMind Control Suite and PyBullet environments with identical network architectures for actor and critic.

## Key Results
- SARC achieves higher average returns than SAC on 10 of 11 tasks after 2 million timesteps
- Notable improvements on Walker-Stand (970.8 vs 697.33), Walker-Walk (961.67 vs 886.28), and Finger-Spin (970.94 vs 315.28)
- SARC shows consistent performance across different network sizes and entropy regularization strengths
- Requires minimal code changes to existing SAC implementations

## Why This Works (Mechanism)

### Mechanism 1
The retrospective loss accelerates critic convergence by pulling current parameters toward optimal values while pushing them away from past parameter values. This dual optimization pressure creates faster convergence through forward-looking and backward-looking regularization terms.

### Mechanism 2
Faster critic convergence leads to better policy gradient estimates for the actor. Since actor learning depends on critic value function estimates, more accurate and stable critics provide higher-quality gradient signals that compound over training iterations.

### Mechanism 3
Retrospective regularization provides consistent improvements across different entropy regularization strengths and network architectures. The retrospective loss operates independently of SAC's entropy term, providing complementary regularization that scales with network complexity.

## Architecture Onboarding

- **Component map**: Environment → Store transition → Sample batch → Compute targets → Update critics with retrospective loss → Update actor → Update target networks

- **Critical path**: Environment → Store transition → Sample batch → Compute targets → Update critics with retrospective loss → Update actor → Update target networks

- **Design tradeoffs**: κ (retrospective strength) must be tuned - too low provides no benefit, too high destabilizes learning; update frequency can be optimized separately from SAC defaults; network architecture choices affect retrospective loss effectiveness

- **Failure signatures**: High variance in training returns indicates κ may be too aggressive; degraded performance vs SAC suggests update frequency or κ mismatch; critic collapse occurs if retrospective pull overwhelms TD learning signal

- **First 3 experiments**:
  1. Run SAC vs SARC on Walker-Stand with default hyperparameters to verify baseline improvement
  2. Vary κ from 0.5 to 4.0 to find optimal retrospective strength for Finger-Spin
  3. Compare SARC with "delayed SAC" (critics updated twice as often) on Walker-Walk to validate retrospective loss advantage

## Open Questions the Paper Calls Out

The paper explicitly notes that retrospective regularization can potentially be incorporated with other actor-critic methods beyond SAC, suggesting this as an interesting direction for future exploration. The authors do not test SARC on algorithms like PPO, TD3, or DDPG, leaving open whether the retrospective loss mechanism generalizes to other actor-critic frameworks.

## Limitations

- Retrospective loss mechanism relies on unproven assumption that optimal critic parameters lie between current and previous values
- Ablation studies limited to narrow κ range (1.0, 2.0, 4.0) without full hyperparameter exploration
- Delayed SAC comparison only tests one update ratio (2x) without examining alternative ratios

## Confidence

- **High confidence**: SARC consistently improves SAC performance across 10/11 tasks
- **Medium confidence**: Retrospective loss mechanism accelerates critic convergence (lacks comprehensive ablation on κ tuning)
- **Low confidence**: The orthogonal relationship between retrospective loss and entropy regularization (not systematically tested)
