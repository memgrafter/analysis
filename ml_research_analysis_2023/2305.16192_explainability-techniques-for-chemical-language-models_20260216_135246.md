# Explainability Techniques for Chemical Language Models

## Quick Facts
- arXiv ID: 2305.16192
- Source URL: https://arxiv.org/abs/2305.16192
- Reference count: 40
- Primary result: Introduces visualization method for chemical language models that attributes atomic-level relevance to predictions using Transformer attention mechanisms

## Executive Summary
This paper presents a novel explainability technique for chemical language models that visualizes atomic-level contributions to molecular property predictions. The method extends a pretrained Transformer encoder with a special <REG> token to aggregate relevance scores from attention mechanisms, then backpropagates through layers to obtain per-atom importance weights. Tested on aqueous solubility prediction, the approach achieves competitive accuracy while providing interpretable heatmaps that reveal which molecular regions most influence model predictions.

## Method Summary
The method finetunes a pretrained chemical language model (MegaMolBART) with a regression head on solubility datasets, then extracts attention scores and gradients during inference. A special <REG> token is prepended to SMILES strings and its feature vector is processed through the regression head, allowing the extraction of pairwise attention weights between <REG> and all other tokens. These attention scores are aggregated across Transformer layers using a layerwise update rule that incorporates gradients. The resulting relevance matrices are mapped to 2D molecular structure diagrams using RDKit, with color intensity representing attributed importance for each atom.

## Key Results
- Achieves MAE of 0.475 on aqueous solubility prediction test set
- Visualizations reveal model focuses on chemically meaningful functional groups like hydroxyl and amine groups
- Demonstrates strong transferability from pretraining while providing interpretable explanations
- Shows competitive performance compared to specialized GNN approaches despite simpler architecture

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The special <REG> token aggregates relevance from all input tokens through attention scores
- Mechanism: The <REG> token is prepended to the SMILES string and its feature vector is processed through the regression head. By extracting attention scores between <REG> and all other tokens from each Transformer layer, the method backpropagates gradients to attribute relevance to input tokens
- Core assumption: Attention scores between <REG> and other tokens capture the relevance of those tokens to the final prediction
- Evidence anchors:
  - "We avoid this pooling step by prepending a <REG> token to the tokenized SMILES string, which aggregates information throughout the encoder"
  - "Only the feature vector of this <REG> token is processed in the regression head, which allows us to obtain the relevance of all other token to the <REG> token from the pairwise attention weights"

### Mechanism 2
- Claim: Relevance is aggregated through all Transformer layers using attention scores and gradients
- Mechanism: Starting with identity matrix R0, the method updates relevance matrices Rl using attention scores Al and their gradients ∇Al across all layers. The update rule Rl = Rl-1 + ¯Al · Rl-1 incorporates both current layer attention and previous layer relevance
- Core assumption: Layerwise aggregation of attention scores with gradients preserves and contextualizes relevance information
- Evidence anchors:
  - "The attention scores Al of each Transformer layer l ∈ L are saved during the models' forward call, while the prediction's gradients∇Al := ∂y/∂Al are evaluated and saved during the backward call"
  - "The previous layers' relevance matrixRl−1 contextualizes the current layers attention mechanism, thus it is matrix multiplied with the layer's contribution¯Al and added element-wise to Rl-1"

### Mechanism 3
- Claim: Visualizing atom token relevance on 2D structure diagrams enables intuitive interpretation
- Mechanism: After obtaining relevance weights for atom tokens, the method maps these weights to 2D structure diagrams using RDKit's MolDraw2DCairo and DrawMoleculeWithHighlights functions, with color intensity representing attributed importance
- Core assumption: Mapping relevance weights to 2D structures provides intuitive understanding for chemists
- Evidence anchors:
  - "All atom token relevance weights are then visualized on the molecules' 2D structure diagram to aid human intuition"
  - "The light color palette 'green' of the seaborn library is chosen as the most intuitive"

## Architecture Onboarding

- Component map: SMILES string -> Tokenizer -> Tokenized input -> Transformer layers with attention mechanisms -> <REG> token processing -> Attention score extraction -> Gradient computation -> Relevance aggregation -> 2D visualization

- Critical path: SMILES string -> Tokenization -> Transformer encoding -> <REG> token processing -> Attention score extraction -> Gradient computation -> Relevance aggregation -> 2D visualization

- Design tradeoffs:
  - Using <REG> token vs. average pooling: <REG> enables per-token relevance attribution but requires extending tokenizer vocabulary
  - Layerwise aggregation vs. final layer only: Layerwise aggregation captures more context but requires more computation
  - 2D visualization vs. other formats: 2D structures are intuitive but may not capture all token types

- Failure signatures:
  - Uniform relevance across all tokens (indicates pooling issue)
  - Missing relevance for non-atom tokens (indicates mapping limitation)
  - Inconsistent relevance for symmetric molecules (indicates symmetry handling issue)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the explainability technique be extended to attribute relevance to non-atomic tokens in SMILES strings while maintaining accurate visualizations?
- Basis in paper: The paper explicitly states this as a limitation, noting that "SMILES strings contain tokens which do not directly correspond to atoms or bonds, and thus do not have an explicit correspondence to structure diagrams."
- Why unresolved: The paper acknowledges this is a significant limitation but does not provide a definitive solution, stating that "no ground truth relevancy labels exist, which makes validation of one approach over alternatives difficult."
- What evidence would resolve it: A validated methodology that successfully maps non-atomic token relevance to 2D structure diagrams with comparable accuracy to atomic token attribution would resolve this question.

### Open Question 2
- Question: What modifications to the explainability technique would be required to handle cross-attention architectures in Transformer models?
- Basis in paper: The paper mentions that "separate attention scores and gradients need to be stored to obtain relevancy matrices Rsolute and Rsolvent" for cross-attention models, requiring "extensions to the propagation rules."
- Why unresolved: While the paper identifies the need for modifications, it does not specify the exact algorithmic changes required to adapt the <REG> token approach for cross-attention architectures.
- What evidence would resolve it: A working implementation of the explainability technique for cross-attention models with demonstrated accuracy in visualizing solute-solvent interactions would resolve this question.

### Open Question 3
- Question: Why does the MegaMolBART model frequently attribute high relevance to molecular carbon backbones, and how can this be addressed?
- Basis in paper: The paper observes that "the model frequently attributes high relevance to the molecules' carbon backbone, which dictates the structure of the molecule but does not by itself influence solubility" and suggests this may be "a result from the pretraining regiment of MegaMolBART."
- Why unresolved: The paper identifies this as a potential issue stemming from pretraining but does not explore its root cause or propose solutions.
- What evidence would resolve it: Experiments comparing different pretraining strategies or architectural modifications that reduce backbone attribution while maintaining predictive accuracy would resolve this question.

## Limitations
- Method only attributes relevance to atom tokens, not bond or other token types, limiting interpretability for molecules where bonds are chemically important
- Reliance on attention scores as proxies for relevance, though attention mechanisms have known limitations in capturing true model reasoning
- Visualizations may be misleading for molecules with symmetric structures as the method does not account for symmetry when mapping relevance to 2D diagrams

## Confidence
- **High Confidence**: The basic mechanism of using attention scores and gradients for relevance attribution is sound and well-established in the explainability literature
- **Medium Confidence**: The specific implementation details for chemical SMILES and the layerwise aggregation rule appear correct based on the described methodology
- **Low Confidence**: The claim that visualizations reveal "chemically meaningful" patterns is largely qualitative and would benefit from systematic validation against chemical knowledge bases
