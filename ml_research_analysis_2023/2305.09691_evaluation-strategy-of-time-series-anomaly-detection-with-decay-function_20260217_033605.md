# Evaluation Strategy of Time-series Anomaly Detection with Decay Function

## Quick Facts
- arXiv ID: 2305.09691
- Source URL: https://arxiv.org/abs/2305.09691
- Reference count: 26
- Introduces PAdf protocol for time-series anomaly detection evaluation with decay function

## Executive Summary
This paper addresses a critical limitation in existing time-series anomaly detection evaluation protocols by introducing the PAdf (Point-Adjusted with decay function) protocol. The key innovation lies in incorporating a decay function that rewards early detection of anomalies within contiguous segments, solving the over-estimation problem of traditional Point-Adjusted protocols that treat all detections equally regardless of timing. Through theoretical analysis and experiments on four benchmark datasets (MSL, SMAP, SWaT, and HEX/UCR), the authors demonstrate that PAdf provides more realistic performance evaluation by considering both detection quantity and speed.

## Method Summary
The PAdf protocol builds upon existing Point-Adjusted (PA) evaluation methods by introducing a decay function that assigns higher scores to earlier detections within anomaly segments. The protocol satisfies three key requirements: (R.1) no missing anomalies, (R.2) quick detection, and (R.3) low false alarms. The decay rate parameter d is recommended to be set to 0.9 by default but should be adjusted based on the specific loss caused by late anomaly detection. The protocol mathematically rewards models that detect anomalies earlier within contiguous segments while maintaining the core principle of PA protocols in handling false alarms.

## Key Results
- PAdf protocol addresses the timing-blindness issue in PA protocols by rewarding early anomaly detection
- State-of-the-art models that perform well under PA protocols often show delayed detection when evaluated with PAdf
- Experimental results on MSL, SMAP, SWaT, and HEX/UCR datasets demonstrate PAdf's ability to provide more realistic performance evaluation
- The protocol maintains all three ideal requirements while adding temporal sensitivity to anomaly detection timing

## Why This Works (Mechanism)
The decay function works by assigning exponentially decreasing scores to detections within contiguous anomaly segments, where earlier detections receive higher scores. This mechanism naturally penalizes delayed detection while still rewarding successful detection of the entire segment. The decay function ensures that models cannot achieve high scores by simply detecting anomalies at the end of segments, creating a more stringent evaluation that reflects real-world requirements for timely anomaly detection.

- Inconsistent performance across different decay rates
