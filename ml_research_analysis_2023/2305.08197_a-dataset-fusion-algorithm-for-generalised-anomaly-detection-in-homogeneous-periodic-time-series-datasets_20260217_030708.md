# A Dataset Fusion Algorithm for Generalised Anomaly Detection in Homogeneous Periodic Time Series Datasets

## Quick Facts
- arXiv ID: 2305.08197
- Source URL: https://arxiv.org/abs/2305.08197
- Reference count: 40
- Primary result: Dataset Fusion algorithm improves anomaly detection F1 score to 0.879 on 3-phase current data

## Executive Summary
This paper introduces a Dataset Fusion algorithm to address the challenge of generalizing deep learning models across multiple homogeneous time-series datasets. The method combines periodic signals from different sources into a unified dataset while preserving unique features for anomaly detection. When tested on 3-phase current data from two Induction Motor fault datasets using an unsupervised LSTMCaps neural network, the approach significantly outperformed conventional training methods.

The research demonstrates both technical and environmental benefits. The fusion technique maintains high detection accuracy (F1 score of 0.879) while substantially reducing computational requirements - achieving only a 4.04% performance decrease when using just 6.25% of the training data, corresponding to a 93.7% reduction in computational power. This aligns with Green AI principles, making the approach particularly suitable for practical real-world applications.

## Method Summary
The proposed Dataset Fusion algorithm addresses the challenge of generalizing deep learning models to multiple homogeneous time-series datasets by combining periodic signals from different sources into a unified dataset. The method preserves unique features across datasets while creating a cohesive training set for anomaly detection. The approach was tested using an unsupervised LSTMCaps neural network on 3-phase current data from two Induction Motor fault datasets. The algorithm processes periodic time-series data from homogeneous sources, aligns them temporally, and merges them while maintaining distinctive characteristics that aid in anomaly detection.

## Key Results
- Achieved an average F1 score of 0.879 on 3-phase current data from Induction Motor fault datasets
- Demonstrated only 4.04% performance decrease when using 6.25% of training data
- Showed 93.7% reduction in computational power requirements
- Proved robustness under non-ideal conditions

## Why This Works (Mechanism)
The Dataset Fusion algorithm succeeds by leveraging the complementary information present across multiple homogeneous datasets while maintaining their distinctive characteristics. By combining periodic signals from different sources, the algorithm creates a richer training dataset that captures a broader range of normal operating conditions and fault patterns. The temporal alignment and careful merging process ensures that unique features from each dataset are preserved, allowing the LSTMCaps neural network to learn more comprehensive representations of both normal and anomalous behavior. This approach effectively expands the model's exposure to diverse scenarios without requiring additional data collection from individual sources.

## Architecture Onboarding

Component map: Raw datasets -> Preprocessing -> Dataset Fusion -> LSTMCaps Network -> Anomaly Detection

Critical path: The fusion process is the critical component, as it determines the quality and comprehensiveness of the training data. The LSTMCaps network then learns from this fused dataset to detect anomalies.

Design tradeoffs: The algorithm balances between maintaining dataset uniqueness and creating a cohesive training set. A higher emphasis on uniqueness may lead to better anomaly detection but could reduce generalization. Conversely, prioritizing cohesion might improve generalization but potentially miss subtle anomalies.

Failure signatures: Poor temporal alignment between datasets could lead to feature misalignment, reducing detection accuracy. Overly aggressive fusion might smooth out important distinctive features, while insufficient fusion could result in redundant or conflicting information.
