# Towards Alleviating the Object Bias in Prompt Tuning-based Factual Knowledge Extraction

## Quick Facts
- arXiv ID: 2306.03378
- Source URL: https://arxiv.org/abs/2306.03378
- Reference count: 2
- Key outcome: MeCoD increases object bias entropy by 22-27% and improves P@1 by 2-4% on the LAMA benchmark.

## Executive Summary
This paper addresses a critical object bias problem in prompt tuning methods for factual knowledge extraction from pretrained language models. When subjects are masked, optimized prompts exhibit a strong preference for certain objects, leading to inaccurate predictions. The authors propose MeCoD, a novel framework that combines maximum entropy-based object equalization with contrastive learning-based biased object obstruction to achieve more balanced predictions. Experimental results demonstrate significant improvements in both reducing object bias and enhancing extraction accuracy compared to baseline methods.

## Method Summary
MeCoD is a prompt tuning framework that addresses object bias through three key modules: a Prompt Encoder that generates embeddings for subject-masked prompts, an Object Equalization module that applies maximum entropy loss to force uniform probabilities across relevant objects, and a Biased Object Obstruction module that uses contrastive learning to push away from biased objects while pulling toward ground-truth objects. The framework jointly optimizes these components with a loss function combining MLM loss, maximum entropy loss, and contrastive loss. The approach is evaluated on the LAMA benchmark using BERT and RoBERTa as backbone PLMs, showing significant improvements in both object bias entropy and knowledge extraction accuracy.

## Key Results
- MeCoD increases object bias entropy by 22-27% compared to baseline methods
- Improves P@1 by 2-4% on the LAMA benchmark
- Demonstrates effectiveness across both discrete and continuous prompt tuning methods

## Why This Works (Mechanism)

### Mechanism 1: Maximum Entropy for Object Equalization
The Object Equalization module applies maximum entropy loss to subject-masked logits, forcing the model to treat all relevant objects equally when no subject context is provided. This works by pushing the probability distribution toward uniformity, which directly counters the object bias that would otherwise concentrate probability mass on specific objects.

### Mechanism 2: Contrastive Learning for Biased Object Obstruction
The Biased Object Obstruction module uses contrastive learning to create a representation gap between biased objects and the ground truth. By simultaneously minimizing the distance between the masked token and the correct object while maximizing the distance to biased objects, the model learns to distinguish between legitimate predictions and biased ones.

### Mechanism 3: Prompt Encoder Optimization
The Prompt Encoder is optimized to generate embeddings that, when combined with PLMs, produce more balanced predictions. By taking both original and subject-masked prompts as input, it learns to encode information that helps the model maintain accuracy while reducing bias across different masking scenarios.

## Architecture Onboarding

- **Component map**: Prompt Encoder → PLMs → Object Equalization & Biased Object Obstruction → Loss calculation → Backpropagation to Prompt Encoder
- **Critical path**: The prompt embeddings flow through PLMs to generate predictions, which are then evaluated by the object equalization and biased obstruction modules to compute losses that guide the prompt encoder optimization.
- **Design tradeoffs**: Balancing the weights of the three loss components (Lmlm, Lme, Lcl), choosing the number of objects to consider for equalization, and deciding on the temperature parameter in contrastive loss.
- **Failure signatures**: Performance degradation on knowledge extraction accuracy, no improvement or increase in object bias entropy, training instability or divergence.
- **First 3 experiments**:
  1. Implement the Prompt Encoder with basic MLP and test with LMLM loss only to establish baseline.
  2. Add Object Equalization module and observe changes in object bias entropy.
  3. Introduce Biased Object Obstruction and evaluate combined effect on both bias and accuracy.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the MeCoD framework perform when applied to generative pre-trained models like GPT-2 or GPT-3, compared to masked language models like BERT and RoBERTa?
- Basis in paper: The authors mention in the limitations section that they focus on masked language models and acknowledge the need to investigate generative pre-trained models in future work.
- Why unresolved: The current study does not include experiments or analysis on generative pre-trained models, leaving a gap in understanding the framework's applicability and performance in this context.
- What evidence would resolve it: Conducting experiments using MeCoD on GPT-2 or GPT-3 and comparing the results with those obtained from BERT and RoBERTa would provide insights into the framework's performance across different types of language models.

### Open Question 2
- Question: What is the precise mechanism by which shallow literal correlations in prompt tuning methods lead to object bias, and how can this be rigorously proven?
- Basis in paper: The authors discuss their findings on the nearest neighbors of prompt token embeddings and the MLM candidate words, suggesting that shallow correlations might be a potential cause of object bias. However, they acknowledge that this needs to be demonstrated by rigorous experiments and analysis.
- Why unresolved: The paper provides preliminary observations but lacks a rigorous experimental or analytical proof of the causal relationship between shallow correlations and object bias.
- What evidence would resolve it: Designing and conducting experiments that isolate and manipulate the shallow correlations in prompt tuning methods, then measuring the resulting object bias, would provide empirical evidence for the causal relationship. Additionally, developing a theoretical framework to explain how shallow correlations lead to object bias would strengthen the argument.

### Open Question 3
- Question: How does the performance of MeCoD vary with different hyperparameter settings, such as the coefficients λ1 and λ2, and the temperature τ in the Biased Object Obstruction module?
- Basis in paper: The authors mention that they set λ1 and λ2 to 0.2 and 0.1, respectively, and use a temperature τ in the Biased Object Obstruction module. However, they do not explore the impact of varying these hyperparameters on the performance of MeCoD.
- Why unresolved: The current study does not provide a sensitivity analysis of MeCoD's performance to changes in these hyperparameters, leaving uncertainty about the optimal settings and their impact on the framework's effectiveness.
- What evidence would resolve it: Conducting a comprehensive hyperparameter search or sensitivity analysis, where λ1, λ2, and τ are varied systematically, and the resulting performance of MeCoD is measured, would reveal the impact of these hyperparameters on the framework's effectiveness. This would help identify the optimal settings and understand their influence on the object bias alleviation and knowledge extraction accuracy.

## Limitations
- The Object Selector module implementation is not fully specified, particularly regarding the threshold for selecting objects to equalize
- Evaluation is limited to the LAMA benchmark, which may not fully capture generalization to other factual knowledge extraction tasks
- The contrastive learning approach assumes biased objects can be reliably identified, but this assumption lacks extensive validation

## Confidence

- **High Confidence**: The experimental results showing MeCoD's effectiveness in reducing object bias and improving P@1 on the LAMA benchmark
- **Medium Confidence**: The proposed mechanisms (Maximum Entropy for Object Equalization, Contrastive Learning for Biased Object Obstruction, and Prompt Encoder Optimization) are logically sound but depend on correct implementation details
- **Low Confidence**: The claim that MeCoD is a general solution to object bias in prompt tuning methods across all scenarios
