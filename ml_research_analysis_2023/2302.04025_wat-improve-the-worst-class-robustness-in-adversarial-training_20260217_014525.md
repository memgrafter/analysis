# WAT: Improve the Worst-class Robustness in Adversarial Training

## Quick Facts
- arXiv ID: 2302.04025
- Source URL: https://arxiv.org/abs/2302.04025
- Authors: 
- Reference count: 40
- Primary result: Proposed worst-class adversarial training (WAT) framework improves worst-class robust accuracy by at least 2.8% on CIFAR-10 and 1.0% on CIFAR-100 while achieving better trade-off between average and worst-class accuracies.

## Executive Summary
This paper addresses the critical issue of robustness disparity among classes in adversarial training (AT) by proposing a novel framework called worst-class adversarial training (WAT). The framework formulates a min-max learning problem and leverages no-regret dynamics to achieve a classifier with excellent performance on the worst-class while maintaining reasonable average robust accuracy. The authors provide rigorous theoretical analysis and demonstrate through extensive experiments on CIFAR-10 and CIFAR-100 that WAT significantly outperforms state-of-the-art approaches, improving worst-class robust accuracy by at least 2.8% on CIFAR-10 and 1.0% on CIFAR-100.

## Method Summary
WAT addresses robustness disparity by formulating a min-max learning problem where the objective is to minimize the worst-class robust risk. The method uses no-regret dynamics, specifically the Hedge algorithm, to maintain a distribution over classes and update model parameters by weighting gradient updates from each class based on their validation loss. Classes with higher validation loss receive more weight in the next update, creating a dynamic rebalancing effect. The framework includes theoretical guarantees on worst-class robust risk generalization and is evaluated on CIFAR-10 and CIFAR-100 datasets with ResNet-18 and WideResNet-34-10 architectures.

## Key Results
- WAT improves worst-class robust accuracy by at least 2.8% on CIFAR-10 and 1.0% on CIFAR-100 compared to state-of-the-art methods
- WAT achieves the best trade-off between average and worst-class accuracies, with the highest ρ measurement on both datasets
- Extensive experiments under PGD-100, CW, and AutoAttack show consistent improvements across different attack types and model architectures

## Architecture Onboarding

- Component map:
  - Data pipeline: Training data, validation data, test data
  - Model: Base classifier (e.g., ResNet-18, WideResNet-34-10)
  - Training loop: Adversarial example generation, weighted gradient updates, validation loss computation
  - Evaluation: Class-wise accuracy metrics, ρ measurement

- Critical path:
  1. Initialize model and weights
  2. For each epoch:
     - Generate adversarial examples for each class
     - Compute weighted gradient update using current class weights
     - Update model parameters
     - Evaluate validation loss for each class
     - Update class weights using multiplicative weight update rule
  3. Output final model

- Design tradeoffs:
  - Weight update frequency: More frequent updates allow faster adaptation but increase computational cost
  - η parameter: Controls the aggressiveness of weight updates; too high causes instability, too low causes slow convergence
  - Validation set size: Larger validation sets provide more reliable loss estimates but increase memory usage

- Failure signatures:
  - Weights collapsing to zero for some classes: Indicates η is too high or validation loss is too noisy
  - No improvement in worst-class accuracy: Could indicate poor choice of base model or insufficient training
  - Degraded average accuracy: Suggests the weighting scheme is too aggressive in favoring worst-class performance

- First 3 experiments:
  1. Baseline comparison: Run WAT vs TRADES on CIFAR-10 with ResNet-18, measure worst-class robust accuracy under PGD-100 attack
  2. Hyperparameter sensitivity: Vary η from {0.01, 0.05, 0.1, 0.5} and observe the trade-off between average and worst-class accuracy
  3. Class-wise analysis: Plot class-wise robust accuracy curves for WAT vs baselines to visualize the disparity reduction

## Limitations

- The theoretical guarantees assume bounded losses and well-behaved Rademacher complexity, which may not hold in practice for complex models or datasets
- The effectiveness of the weighting mechanism depends heavily on the reliability of validation loss as a proxy for true worst-class robust risk
- Experiments are limited to CIFAR-10 and CIFAR-100 datasets with specific architectures, raising questions about generalizability to larger-scale problems or different domains

## Confidence

- Mechanism 1 (no-regret dynamics for worst-class focus): Medium - The theory is sound but relies on strong assumptions about validation loss reliability
- Mechanism 2 (multiplicative weight convergence): Medium - Theoretical convergence is proven but practical stability depends heavily on η tuning
- Mechanism 3 (generalization bounds): Low - The worst-class Rademacher complexity bounds are novel but may not translate to tight practical guarantees
