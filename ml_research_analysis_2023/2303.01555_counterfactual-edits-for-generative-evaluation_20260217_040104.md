# Counterfactual Edits for Generative Evaluation

## Quick Facts
- arXiv ID: 2303.01555
- Source URL: https://arxiv.org/abs/2303.01555
- Authors: 
- Reference count: 40
- Key outcome: Proposes a novel framework for generative evaluation using conceptual edits as counterfactual explanations, revealing model capabilities and biases through knowledge-based counterfactual edits

## Executive Summary
This paper addresses the challenge of evaluating generative models by proposing a novel framework based on conceptual edits as counterfactual explanations. The framework leverages knowledge-based counterfactual edits to identify minimal changes needed in generated images to match their ground truth conditioning, revealing the model's capabilities and biases. It is model-agnostic and focuses on input and output concept sets rather than the model's inner workings, providing both local and global explanations for model behavior.

## Method Summary
The proposed method treats generative models as black boxes and evaluates them based on conceptual edits needed to transform generated outputs to match conditioning. It uses Concept Set Edit Distance (CSED) calculated via object detection and semantic extraction to quantify the semantic distance between generated and target concept sets. The framework applies this to two tasks: Story Visualization (CLEVR-SV dataset) and Scene Generation (COCO dataset), computing metrics like Story Loss, Consistency Loss, and Global Story Loss to evaluate faithfulness and consistency.

## Key Results
- The proposed metrics provide explainable insights into models' performance and reveal semantic misconceptions and biases
- Global explanations automatically reveal concepts that a model cannot generate or preserve
- The framework is model-agnostic and only requires generated outputs and conditioning, not access to model internals

- Claim: The method identifies minimal concept-level edits needed to transform generated image semantics to match conditioning
- Mechanism: Uses Concept Set Edit Distance (CSED) as a shortest-path problem in concept space, quantifying semantic distance between generated and target concept sets
- Core assumption: Semantic distance between concepts can be meaningfully defined using hierarchical knowledge structures like WordNet

- Claim: The framework provides both local and global explanations for model behavior

- Core assumption: Aggregating individual edit operations across a dataset reveals meaningful patterns about model capabilities and limitations
- Evidence anchors:
  - [abstract]: "Moreover, global explanations produced by accumulating local edits can also reveal what concepts a model cannot generate in total."

- Claim: The method is model-agnostic and only requires generated outputs and conditioning

- Component map: Conditioning → Concept extraction → CSED calculation → Edit path generation → Explanation aggregation

## Limitations
- The framework's effectiveness depends heavily on the quality of concept extraction and the appropriateness of the semantic hierarchy used
- Object detectors may miss objects or produce false positives, and WordNet may not capture all relevant semantic relationships
- The method's reliance on pre-trained object detectors and NLP tools introduces potential failure points if these components are not well-suited to the specific domain or generative model outputs

## Confidence

- **High Confidence**: The core mechanism of using CSED for semantic evaluation is well-founded and novel
