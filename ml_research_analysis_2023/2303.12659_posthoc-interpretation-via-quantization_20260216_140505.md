# Posthoc Interpretation via Quantization

## Quick Facts
- arXiv ID: 2303.12659
- Source URL: https://arxiv.org/abs/2303.12659
- Reference count: 17
- Primary result: PIQ generates more interpretable explanations than baseline methods through class-specific vector quantization bottlenecks

## Executive Summary
This paper introduces PIQ, a post-hoc neural network interpretation method that uses vector quantization to create class-specific codebooks. These codebooks act as bottlenecks, forcing the interpreter to focus on parts of the input data relevant to the classifier's decision. The method discretizes classifier representations into a class-specific latent space and is evaluated through quantitative and qualitative studies on black-and-white images, color images, and audio. Results show that PIQ generates interpretations that are more easily understood by users compared to several other interpretation methods in the literature.

## Method Summary
PIQ trains an interpreter on classifier representations using vector quantization with class-specific codebooks. The interpreter learns to reconstruct classifier-relevant parts of the input through a discrete bottleneck. The method uses VQ-VAE formulation with reconstruction error minimization and quantization objectives. Different output modes are employed depending on data type: continuous outputs for FashionMNIST and binary masking for MNIST, Quickdraw, and audio data. The interpreter is trained on the same dataset as the classifier without input manipulation.

## Key Results
- PIQ demonstrates superior performance in generating human-understandable interpretations compared to baseline methods
- The method maintains high fidelity-to-input scores while producing interpretable explanations
- Quantitative evaluation using FID and faithfulness metrics shows consistent improvement over existing methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: PIQ generates interpretable explanations by constraining the decoder to reconstruct only parts of the input deemed relevant by the classifier.
- Mechanism: The vector quantization bottleneck forces the decoder to focus on classifier-relevant features. The class-specific codebooks act as a discrete bottleneck that limits the decoder's access to only the parts of the input that align with the classifier's decision.
- Core assumption: The classifier's intermediate representation contains separable, class-relevant features that can be reconstructed through quantization.
- Evidence anchors:
  - [abstract] "The class-specific codebooks act as a bottleneck that forces the interpreter to focus on the parts of the input data deemed relevant by the classifier for making a prediction."
  - [section] "This discrete space acts as a bottleneck that forces the interpreter to focus on the parts of the input that are relevant to the classifier's decision."
- Break condition: If the classifier's intermediate representation is too entangled or lacks class-specific structure, the quantization cannot effectively isolate relevant features.

### Mechanism 2
- Claim: PIQ produces human-understandable interpretations by maintaining fidelity to the original data distribution.
- Mechanism: The reconstruction error minimization combined with the vector quantization objective ensures that generated interpretations remain close to the original data distribution while highlighting classifier-relevant regions.
- Core assumption: Human interpretability correlates with visual/audio similarity to original data distribution while emphasizing decision-relevant features.
- Evidence anchors:
  - [section] "we propose to use the Frechet-Inception Distance (FID) Heusel et al. [2017] between the produced interpretations and the input data as an additional metric to describe the quality of interpretations."
  - [section] "PIQ demonstrates superior performance in generating human-understandable interpretations."
- Break condition: If the reconstruction error minimization conflicts with highlighting relevant features, interpretations may become either too faithful or too distorted.

### Mechanism 3
- Claim: PIQ outperforms baseline methods by learning class-specific concepts rather than relying on relevance estimates.
- Mechanism: The vector quantization dictionary stores discrete class-specific concepts that can be directly used for reconstruction, avoiding the need for auxiliary classifiers or relevance estimation.
- Core assumption: Discrete class-specific concepts can be effectively learned and stored in the vector quantization dictionary for direct reconstruction.
- Evidence anchors:
  - [section] "We however observe that PIQ produces explanations that generally correlate well with the classification decisions of the classifier."
  - [section] "Our method is similar in that we also keep a set of features (i.e., the vector quantization dictionary), but we differ in the way we assign dictionary elements to concepts and do not require a relevance estimate or an auxiliary classifier."
- Break condition: If the class-specific dictionary becomes too large or sparse, the method may fail to capture meaningful concepts.

  - Dictionary size vs. computational cost

  - Continuous vs. binary output mode for different data types

- Failure signatures:
  - Poor reconstruction quality (high FID scores)
  - Low fidelity-to-input scores (interpretations change classifier predictions)
  - Noisy or incoherent interpretations (vector quantization fails to capture concepts)
