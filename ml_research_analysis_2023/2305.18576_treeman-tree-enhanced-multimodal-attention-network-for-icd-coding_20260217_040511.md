# TreeMAN: Tree-enhanced Multimodal Attention Network for ICD Coding

## Quick Facts
- arXiv ID: 2305.18576
- Source URL: https://arxiv.org/abs/2305.18576
- Reference count: 40
- Key outcome: TreeMAN achieves AUC scores of 0.937 and 0.729, F1 scores of 0.953 and 0.682, and Precision@5 scores of 0.690 and 0.479 on MIMIC-III 50 and MIMIC-II 50 datasets respectively

## Executive Summary
TreeMAN introduces a novel multimodal attention network for automatic ICD coding that integrates structured medical data with text representations. The method constructs tree-based features from structured medical data using decision trees and fuses them with text representations via an attention mechanism to generate multimodal representations for multi-label classification. Experimental results on two MIMIC datasets demonstrate that TreeMAN outperforms prior state-of-the-art ICD coding methods.

## Method Summary
TreeMAN employs a tree-enhanced multimodal attention network that combines structured medical data with text representations for ICD coding. The framework first constructs tree-based features from structured medical data using decision trees, then fuses these with text representations through an attention mechanism. This multimodal representation is subsequently used for multi-label classification to predict ICD codes. The attention mechanism allows the model to dynamically weigh the importance of different modalities (text and structured data) when making predictions.

## Key Results
- AUC scores: 0.937 (MIMIC-III 50) and 0.729 (MIMIC-II 50)
- F1 scores: 0.953 (MIMIC-III 50) and 0.682 (MIMIC-II 50)
- Precision@5 scores: 0.690 (MIMIC-III 50) and 0.479 (MIMIC-II 50)
