# Detecting Adversarial Faces Using Only Real Face Self-Perturbations

## Quick Facts
- **arXiv ID:** 2304.11359
- **Source URL:** https://arxiv.org/abs/2304.11359
- **Reference count:** 30
- **Primary result:** Proposes an attack-agnostic adversarial face detection method using only real face self-perturbations, achieving high AUC scores on unseen attacks.

## Executive Summary
This paper addresses the challenge of detecting adversarial faces in facial recognition systems, which are vulnerable to various attack methods. The proposed approach generates pseudo adversarial faces by perturbing real faces with three heuristically designed noise patterns, then trains a detector using only real faces and their self-perturbations. This attack-agnostic method is effective against both gradient-based and GAN-based adversarial attacks without requiring access to the victim facial recognition system. The cascaded detection system combines self-perturbation generation, decision boundary regularization, and a max-pooling-based classifier focused on abnormal local color aberrations.

## Method Summary
The method generates pseudo adversarial faces by applying three types of self-perturbations to real face images: point-wise noise patterns for gradient-based attacks, block-wise patterns, and GAN-based perturbations. A convolutional neural network (XceptionNet) is trained on real faces and their self-perturbations to learn generic adversarial face representations. Decision boundary regularization treats adversarial faces as out-of-distribution data, incorporating uncertainty loss to narrow the model's decision boundary. A max-pooling classifier focuses on detecting abnormal local color aberrations in high-frequency regions characteristic of GAN-based attacks. The entire system is trained without access to real adversarial examples or the victim facial recognition system.

## Key Results
- Achieved high AUC scores for detecting adversarial faces from unseen attacks
- Effective against both gradient-based (8 types) and GAN-based (2 types) attacks
- Demonstrated domain-agnostic performance across LFW and CelebA-HQ datasets
- Successfully detects adversarial faces without requiring access to victim FRS

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Adversarial faces share universal noise patterns across different attack methods
- **Mechanism:** Self-perturbed faces mimic adversarial noise patterns, enabling the model to learn generic representations
- **Core assumption:** Adversarial noises have intrinsic similarities across recent attack methods
- **Evidence anchors:** Abstract mentions three self-perturbation types for gradient and GAN-based faces; section notes detector generalizability across attacks except GANs
- **Break condition:** If attacks evolve with completely novel noise patterns, self-perturbation approach may fail

### Mechanism 2
- **Claim:** GAN-based adversarial faces exhibit abnormal local color aberrations in high-frequency regions
- **Mechanism:** Max-Pooling Classifier detects these aberrations by analyzing local features in high-frequency regions
- **Core assumption:** GAN attacks modify high-frequency regions while preserving visual quality, creating detectable color aberrations
- **Evidence anchors:** Abstract identifies abnormal color aberrations in GAN-made adv-faces; section notes GAN faces manipulate classification while maintaining perceptual invariance
- **Break condition:** If GAN attacks improve to generate natural-looking faces without detectable color aberrations

### Mechanism 3
- **Claim:** Decision boundary regularization improves detection of adversarial faces far from self-perturbed distribution
- **Mechanism:** Treats adversarial faces as out-of-distribution data, incorporating uncertainty loss to narrow real face class boundary
- **Core assumption:** Adversarial faces can be regarded as out-of-distribution data from shifted data manifold
- **Evidence anchors:** Abstract discusses treating adv-faces as OOD data; section explains uncertainty loss regularizes low OOD scores for ID data
- **Break condition:** If adversarial face distribution shifts dramatically or becomes multimodal beyond regularization's accounting

## Architecture Onboarding

- **Component map:** Real face → Self-perturbation → CNN feature extraction → Max-Pooling classification → Decision boundary regularization → Adversarial face detection
- **Critical path:** Real face images undergo self-perturbation, pass through CNN backbone for feature extraction, are classified by Max-Pooling layer, and benefit from decision boundary regularization during training
- **Design tradeoffs:** Self-perturbations enable attack-agnostic detection but sacrifice specificity; Max-Pooling focuses on local features (effective for GAN attacks) but may miss global patterns; regularization improves distant adversarial face detection but may increase false positives
- **Failure signatures:** High false negative rate with novel attack patterns; decreased performance on high-resolution datasets; sensitivity to hyperparameter choices like perturbation magnitude

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** How does performance compare when using larger perturbation magnitudes (e.g., ϵ = 10/255 or 15/255) instead of small ϵ = 5/255?
- **Basis in paper:** Explicit mention that larger ϵ values may improve attack success rates and impact detection effectiveness
- **Why unresolved:** Experiments conducted only with ϵ = 5/255, no results for larger magnitudes
- **What evidence would resolve it:** Experiments with larger perturbation magnitudes comparing detection performance to ϵ = 5/255 results

### Open Question 2
- **Question:** How does the method perform on datasets with significantly different characteristics (low-resolution vs high-resolution) compared to LFW and CelebA-HQ?
- **Basis in paper:** Inferred from mention that CelebA-HQ's high resolution and diversified background increases detection difficulty; domain-agnostic claim based on CIFAR10 and ImageNet experiments
- **Why unresolved:** Experiments conducted only on LFW and CelebA-HQ, no results for significantly different datasets
- **What evidence would resolve it:** Experiments on varying characteristic datasets (low-resolution, high-resolution, different content) comparing performance to LFW and CelebA-HQ results

### Open Question 3
- **Question:** How does the method perform on adversarial faces from attack methods not gradient-based or GAN-based (e.g., physical-world attacks or attribute manipulation without GANs)?
- **Basis in paper:** Explicit focus on gradient-based and GAN-based attacks; mention of method's agnosticism to specific attack methods
- **Why unresolved:** Experiments conducted only with gradient-based and GAN-based attacks, no results for other attack types
- **What evidence would resolve it:** Experiments using non-gradient/GAN attack methods comparing detection performance to gradient-based and GAN-based results

## Limitations

- Limited evaluation scope with only 8 gradient-based and 2 GAN-based attacks tested
- No analysis of false positive rates on benign faces with various post-processing operations
- Unclear sensitivity to hyperparameter choices like perturbation magnitude
- No real-world deployment considerations or runtime analysis provided

## Confidence

- **Attack-agnostic detection claims:** Low confidence - weak experimental evidence for universal noise pattern assumption
- **GAN color aberration hypothesis:** Low confidence - lacks direct validation and forensic analysis
- **Decision boundary regularization effectiveness:** Low confidence - speculative effectiveness on truly out-of-distribution faces
