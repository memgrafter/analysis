# Mitigating Catastrophic Forgetting in Task-Incremental Continual Learning with Adaptive Classification Criterion

## Quick Facts
- arXiv ID: 2305.12270
- Source URL: https://arxiv.org/abs/2305.12270
- Authors: [Not specified in source]
- Reference count: 11
- Primary result: Achieves state-of-the-art performance on GLUE benchmark tasks with average accuracy improvements of 2.37%-3.28% over continual learning baselines

## Executive Summary
This paper addresses catastrophic forgetting in task-incremental continual learning by proposing a supervised contrastive learning framework that maintains task-specific representations across task transitions. The method uses contrastive learning to learn discriminative representations, saves limited samples as dynamic classification criteria, and employs instance-wise relation distillation to preserve similarity structures. Experimental results on GLUE benchmark tasks demonstrate superior performance compared to existing continual learning baselines, with average accuracy improvements of 2.37%-3.28% and backward transfer values ranging from -3.75% to 0.57%, indicating reduced forgetting.

## Method Summary
The method combines supervised contrastive learning with kNN classification, where contrastive loss creates well-separated class clusters and kNN uses saved samples as dynamic classification criteria. After training on each task, K-means clustering selects representative samples that capture the label distribution, which are then replayed during training on new tasks. An instance-wise relation distillation regularization term preserves similarity relationships between current and previous model representations by minimizing KL divergence between their similarity distributions. The approach uses a pre-trained RoBERTa-base model, trains each task for 10 epochs with Adam optimizer (lr=3e-5, batch size=96), and saves 200 memory samples per task for replay.

## Key Results
- Achieves average accuracy (ACC) improvements of 2.37%, 0.9%, 0.66%, 3.28%, 2.49%, and 2.40% over second-best continual learning baselines across 6 different task orders
- Backward transfer (BWT) values range from -3.75% to 0.57%, demonstrating reduced catastrophic forgetting compared to classification baselines
- Outperforms standard fine-tuning, EWC, and other continual learning methods on GLUE benchmark tasks including CoLA, MNLI, QNLI, QQP, Yelp, and AG

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Supervised contrastive learning with kNN classification maintains task representations better than standard CE training in continual learning.
- Mechanism: The contrastive loss pulls representations of same-class samples together and pushes different-class samples apart, creating well-separated clusters. The kNN classifier then uses these stable clusters as classification criteria, avoiding the catastrophic forgetting that occurs when updating a fixed classification layer.
- Core assumption: The learned representations remain discriminative across task transitions even as the model parameters change.
- Evidence anchors:
  - [abstract]: "In our method, a contrastive loss is used to directly learn representations for different tasks and a limited number of data samples are saved as the classification criterion."
  - [section]: "Seldom considers adapting the classification criterion for the newly learned representations... After learning the new task, we can feed the saved sample into models for new classification criteria and mitigate the problem of CF."
  - [corpus]: Weak evidence - neighboring papers focus on different approaches (weight consolidation, density propagation) without directly addressing the contrastive-kNN combination.
- Break condition: If the contrastive loss fails to maintain clear separation between classes, or if the kNN classifier becomes too sensitive to representation drift.

### Mechanism 2
- Claim: Instance-wise relation distillation (IRD) regularization mitigates representation drift by preserving similarity structure from previous tasks.
- Mechanism: IRD computes instance-wise similarity matrices between current and previous model representations, then adds a regularization term to minimize the KL divergence between these similarity distributions, effectively constraining how much representations can change.
- Core assumption: Maintaining similarity relationships between instances is more important than preserving exact parameter values for preventing forgetting.
- Evidence anchors:
  - [abstract]: "To mitigate CF, we further use an instance-wise relation distillation regularization term and a memory replay module to maintain the information of previous tasks."
  - [section]: "During the learning on task T_i,i > 1, the normalized instance-wise similarity in the mini-batch A is calculated... The IRD regularization term aims to estimate the discrepancy of current representations to those learned in the previous model, and mitigate the representation drift through optimization."
  - [corpus]: No direct evidence found in neighboring papers - they focus on different regularization approaches.
- Break condition: If the similarity preservation conflicts with learning new tasks, or if the temperature parameter causes instability in similarity distributions.

### Mechanism 3
- Claim: Memory replay with selected samples maintains the classification criterion distribution across task transitions.
- Mechanism: After training on each task, K-means clustering selects representative samples that capture the label distribution. These samples are saved and later replayed during training on new tasks, providing both regularization and updated classification criteria through the current model.
- Core assumption: A small set of well-chosen samples can effectively represent the full label distribution for maintaining classification boundaries.
- Evidence anchors:
  - [abstract]: "During inference, the saved data samples are fed into the current model to obtain updated representations, and a k Nearest Neighbour module is used for classification."
  - [section]: "We adopt a K-means module to aggregate the data Di(c) of each label (c∈Ci) to clusters. Then we randomly select samples according to the data density to keep representation distribution."
  - [corpus]: Weak evidence - neighboring papers discuss replay strategies but don't specifically address the combination with K-means selection and kNN inference.
- Break condition: If the selected samples become unrepresentative due to distribution shift, or if replay frequency is insufficient to maintain performance.

## Architecture Onboarding

- Component map: Pre-trained RoBERTa-base encoder -> Supervised contrastive learning module -> Instance-wise relation distillation module -> Memory replay module -> kNN inference module -> K-means clustering module
- Critical path: Contrastive learning → Sample selection → IRD regularization → Memory replay → kNN inference
- Design tradeoffs:
  - Memory buffer size vs. representation coverage: Smaller buffers save memory but may miss important distribution regions
  - kNN k value vs. robustness: Larger k values smooth decisions but may blur class boundaries
  - Replay frequency vs. training efficiency: More frequent replay helps retention but slows training
- Failure signatures:
  - Accuracy drops across all tasks indicate catastrophic forgetting despite all mechanisms
  - High variance across task orders suggests order sensitivity in sample selection
  - Performance degradation with increasing k in kNN suggests representation drift
- First 3 experiments:
  1. Test with varying memory buffer sizes (50, 200, 500 samples per task) to find optimal trade-off between memory usage and performance
  2. Compare performance with and without IRD regularization to isolate its contribution to mitigating forgetting
  3. Test different k values in kNN (5, 10, 15) to determine sensitivity to nearest neighbor count

## Limitations

- The paper lacks ablation studies isolating the contributions of each component (contrastive learning, IRD regularization, memory replay)
- The selection of memory samples using K-means clustering could introduce bias if the clustering doesn't capture the full representation distribution
- The method's performance on non-NLP tasks and with different backbone architectures remains unexplored

## Confidence

- **High confidence**: The core mechanism of using contrastive learning with kNN classification is theoretically sound and the experimental results show consistent improvements over baselines across multiple task orders
- **Medium confidence**: The IRD regularization and memory replay components show promise, but their individual contributions are not well-isolated through ablation studies
- **Low confidence**: The claim that this approach is universally superior to all existing continual learning methods is overstated without broader empirical validation across different domains and architectures
