# ChatGPT or Grammarly? Evaluating ChatGPT on Grammatical Error Correction Benchmark

## Quick Facts
- arXiv ID: 2303.13648
- Source URL: https://arxiv.org/abs/2303.13648
- Authors: 
- Reference count: 6
- Key outcome: ChatGPT achieves an F0.5 score of 53.1 on CoNLL2014, lower than Grammarly (63.3) and GECToR (60.8), but produces fewer under/mis-corrections in human evaluation

## Executive Summary
This study evaluates ChatGPT's performance on grammatical error correction using the CoNLL2014 benchmark dataset and compares it with Grammarly and GECToR. While ChatGPT achieves lower F0.5 scores than the baseline systems, particularly on long sentences, human evaluation reveals it produces fewer under-correction and mis-correction issues. The paper argues that automatic evaluation metrics may underestimate ChatGPT's potential as a GEC tool because it tends to make structural changes and surface-level modifications beyond minimal corrections.

## Method Summary
The study evaluates ChatGPT, Grammarly, and GECToR on 100 sentences from the CoNLL2014 test set. ChatGPT was manually queried with a specific prompt, Grammarly was used via its commercial interface, and GECToR used a pre-trained RoBERTa model. All systems' outputs were evaluated using Precision, Recall, and F0.5 metrics, with human evaluation conducted on 20 sampled sentences to assess under-correction, mis-correction, and over-correction types.

## Key Results
- ChatGPT achieves F0.5 score of 53.1, lower than Grammarly (63.3) and GECToR (60.8)
- ChatGPT produces fewer under-corrections and mis-corrections but more over-corrections than baselines
- Performance gap narrows significantly on shorter sentences (F0.5 of 57.3 vs Grammarly's 61.1)
- ChatGPT makes structural changes and surface-level modifications while maintaining grammatical correctness

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ChatGPT performs worse than baselines on automatic metrics due to structural and surface-level changes rather than minimal corrections
- Mechanism: Automatic metrics (Precision, Recall, F0.5) measure exact token-level matches with reference corrections. ChatGPT's generative approach allows restructuring and rephrasing that deviates from references but maintains grammatical correctness
- Core assumption: Reference corrections represent the "correct" way to fix errors, and deviations are penalized
- Evidence anchors: [abstract] "ChatGPT goes beyond one-by-one corrections by introducing more changes to the surface expression"; [section] "ChatGPT is not limited to correcting errors in one-by-one fashion"
- Break condition: If metrics account for semantic equivalence rather than exact token matching

### Mechanism 2
- Claim: ChatGPT produces fewer under-corrections and mis-corrections but more over-corrections
- Mechanism: ChatGPT's generative approach identifies and corrects more errors (reducing under-corrections) and tends to correct correctly when it does (reducing mis-corrections). Its tendency to make additional changes leads to over-corrections
- Core assumption: Human evaluation methodology accurately captures under/mis/over-correction distinctions
- Evidence anchors: [abstract] "ChatGPT produces less under-correction or mis-correction issues but more over-corrections"; [section] "Table 6 shows ChatGPT has the least number of under-corrections"
- Break condition: If human evaluation methodology is flawed or biased

### Mechanism 3
- Claim: Performance gap narrows on shorter sentences
- Mechanism: Shorter sentences have fewer opportunities for ChatGPT to make structural changes, so corrections align more closely with reference corrections that automatic metrics measure
- Core assumption: Sentence length categorization effectively captures relationship between complexity and correction approach
- Evidence anchors: [section] "Table 3 shows gap between ChatGPT and Grammarly is significantly bridged on short sentences"; [abstract] "particularly on long sentences"
- Break condition: If sentence length isn't the primary factor affecting alignment with reference corrections

## Architecture Onboarding

- Component map: CoNLL2014 dataset -> ChatGPT query interface -> Grammarly API -> GECToR model -> Automatic evaluation (Precision, Recall, F0.5) -> Human evaluation (under/mis/over-correction)
- Critical path: The evaluation pipeline flows from dataset loading → system correction → automatic metric calculation → human evaluation. The most critical path is the human evaluation process.
- Design tradeoffs: Trades comprehensive dataset coverage (only 100 sentences) for detailed analysis; trades automated evaluation (faster but potentially misleading) for human evaluation (slower but more accurate)
- Failure signatures: If automatic metrics significantly diverge from human judgment, this indicates metrics may not capture full correction quality. If ChatGPT's performance doesn't improve on shorter sentences, this challenges the sentence-length hypothesis.
- First 3 experiments:
  1. Re-run evaluation with modified prompts for ChatGPT to test if different prompting strategies affect structural change tendency
  2. Implement semantic equivalence metric alongside token-level metrics to quantify how much ChatGPT's changes maintain meaning while improving grammar
  3. Conduct ablation studies on sentence length by creating controlled datasets with varying complexity levels

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does ChatGPT's performance on GEC tasks vary when using different prompts or in-context learning techniques?
- Basis in paper: [explicit] The paper mentions only one prompt was used and suggests exploring in-context learning methods like providing demonstration examples or chain-of-thought prompting
- Why unresolved: The study used a single prompt and did not explore the potential of in-context learning, which could significantly impact ChatGPT's performance
- What evidence would resolve it: Conducting experiments with various prompts and in-context learning techniques to compare their effects on ChatGPT's GEC performance

### Open Question 2
- Question: How does ChatGPT's performance on GEC tasks compare when evaluated using more comprehensive metrics beyond Precision, Recall, and F0.5?
- Basis in paper: [explicit] The paper suggests using more evaluation metrics, such as pretraining-based metrics, to comprehensively evaluate performance
- Why unresolved: The study only used traditional metrics, which may not fully capture ChatGPT's capabilities in GEC tasks
- What evidence would resolve it: Applying additional evaluation metrics to assess ChatGPT's performance and comparing results with traditional metrics

### Open Question 3
- Question: How does ChatGPT's performance on GEC tasks differ when evaluated on various datasets beyond the CoNLL-2014 test set?
- Basis in paper: [explicit] The paper mentions the limitation of only using the CoNLL-2014 test set and suggests conducting experiments on more datasets
- Why unresolved: The study's evaluation was limited to a single dataset, which may not represent ChatGPT's performance across different contexts and error types
- What evidence would resolve it: Testing ChatGPT on multiple GEC datasets to determine performance across diverse contexts and error types

## Limitations
- Small sample size of only 100 sentences from CoNLL2014 test set may not provide sufficient statistical power
- Manual querying approach for ChatGPT introduces potential variability that isn't controlled or reported
- Human evaluation conducted on only 20 sentences, further limiting generalizability of findings

## Confidence

**High Confidence Claims:**
- ChatGPT achieves lower F0.5 scores than both Grammarly and GECToR on CoNLL2014 benchmark
- ChatGPT produces fewer under-corrections and mis-corrections compared to baseline systems
- Performance gap between ChatGPT and baselines is smaller on shorter sentences

**Medium Confidence Claims:**
- Automatic metrics underestimate ChatGPT's true correction quality due to its structural changes
- ChatGPT's diverse generation leads to more over-corrections
- ChatGPT goes beyond minimal corrections by restructuring sentences

**Low Confidence Claims:**
- ChatGPT is a promising tool for GEC despite lower automatic scores
- The under-correction/mis-correction/over-correction framework fully captures differences between systems
