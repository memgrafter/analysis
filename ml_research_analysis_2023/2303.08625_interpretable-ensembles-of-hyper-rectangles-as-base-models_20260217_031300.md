# Interpretable Ensembles of Hyper-Rectangles as Base Models

## Quick Facts
- arXiv ID: 2303.08625
- Source URL: https://arxiv.org/abs/2303.08625
- Reference count: 40
- Primary result: GBM-HRBM outperforms RF and ERT on 13/17 regression datasets and 12/14 classification datasets with statistical significance

## Executive Summary
This paper introduces GBM-HRBM, a novel ensemble model that uses axis-parallel hyper-rectangles as base models within gradient boosting machines. The approach combines interpretability with strong predictive performance by constructing interpretable base models that can be directly visualized and explained. The authors propose two types of hyper-rectangles (closed rectangles and corners) and introduce new regularization techniques including a "step height penalty" to improve model performance. The method demonstrates superior performance compared to standard ensemble models while maintaining computational efficiency through modified SHAP calculations.

## Method Summary
The core innovation involves using uniformly generated axis-parallel hyper-rectangles as base models in gradient boosting machines. The model employs two types of HRBMs: closed rectangles that cover regions of the feature space, and corners that capture specific vertex patterns. The approach includes methods for optimal regularization parameter selection at each GBM iteration, with propositions providing analytical solutions for parameter tuning. A new step height penalty regularization is introduced to further improve model performance. The interpretability is achieved through modifications to SHAP values, allowing for both model-based and data-based interpretations that are computationally more efficient than standard SHAP calculations.

## Key Results
- GBM-HRBM outperforms RF and ERT on 13 out of 17 regression datasets with p=0.045
- For classification, GBM-HRBM achieves better performance on 12 out of 14 datasets with p=0.0066
- Both model-based and data-based SHAP modifications provide similar Shapley values while being computationally more efficient
- The method maintains interpretability through directly visualizable hyper-rectangle base models

## Why This Works (Mechanism)
The approach works by leveraging the geometric properties of hyper-rectangles to create interpretable base models that can capture local patterns in the data. By using axis-parallel rectangles, the model maintains simplicity while achieving strong predictive performance through ensemble methods. The regularization techniques, including the novel step height penalty, help prevent overfitting and improve generalization. The SHAP modifications preserve interpretability while reducing computational complexity, making the model practical for real-world applications.

## Architecture Onboarding

**Component Map:** Data -> Rectangle Generation -> GBM Iterations -> Regularization -> Prediction -> SHAP Interpretation

**Critical Path:** The most critical sequence is Rectangle Generation → GBM Iterations → Regularization, as errors in base model construction propagate through the boosting process and affect final performance.

**Design Tradeoffs:** The model trades some predictive flexibility (compared to complex trees) for interpretability and computational efficiency. The axis-aligned constraint simplifies visualization but may miss diagonal patterns in the data.

**Failure Signatures:** Poor performance typically manifests as:
- Rectangles not covering relevant regions of feature space
- Numerical instability in regularization parameter optimization
- SHAP values that don't align with intuitive feature importance
