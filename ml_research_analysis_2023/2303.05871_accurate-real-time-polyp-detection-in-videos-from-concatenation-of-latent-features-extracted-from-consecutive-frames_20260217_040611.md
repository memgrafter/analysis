# Accurate Real-time Polyp Detection in Videos from Concatenation of Latent Features Extracted from Consecutive Frames

## Quick Facts
- arXiv ID: 2303.05871
- Source URL: https://arxiv.org/abs/2303.05871
- Reference count: 22
- Sensitivity: 90.94%, Precision: 90.53%, Specificity: 92.46%

## Executive Summary
This paper addresses the challenge of detecting polyps in colonoscopy videos, where small changes in lighting, camera pose, and specular reflections can cause convolutional neural networks to miss polyps that are present in consecutive frames. The authors propose a method that concatenates feature maps from consecutive frames at the bottleneck layer of a 2D CNN encoder-decoder model, leveraging temporal information to improve detection stability. The approach achieves high sensitivity, precision, and specificity while maintaining real-time performance suitable for clinical deployment.

## Method Summary
The method uses an encoder-decoder architecture based on AlbuNet34, where feature maps from the current frame and up to three previous frames are extracted and concatenated at the bottleneck layer. This temporal feature integration helps the model maintain consistent polyp detection despite small changes between frames. Instead of using binary masks for ground truth, the model is trained to predict 2D Gaussian shapes around polyp regions, which eliminates the need for non-maximum suppression at inference time and enables direct bounding box generation. The bottleneck layer is split equally among the concatenated frames to prevent computational complexity increase, allowing the model to run at approximately 11±1 msec per frame on a NVIDIA GeForce RTX 3090 GPU.

## Key Results
- Achieved sensitivity of 90.94%, precision of 90.53%, and specificity of 92.46% on the ASU-Mayo Clinic dataset
- Successfully reduced false positives by maintaining consistent detection across consecutive frames with similar visual content
- Maintained real-time performance (11±1 msec per frame) while incorporating temporal information

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Concatenating feature maps from consecutive frames at the bottleneck layer improves detection stability by integrating temporal context.
- Mechanism: Neighboring frames in colonoscopy videos contain highly correlated visual information. By extracting feature maps from both the current frame and previous frames and concatenating them at the bottleneck layer, the model can leverage complementary temporal information to maintain consistent polyp detection despite small changes in lighting, camera pose, or specular reflections.
- Core assumption: Extracted feature maps from consecutive frames contain similar and complementary information that can be effectively combined to improve detection robustness.
- Evidence anchors:
  - [abstract] "The hypothesis is that neighboring frames are closely related to each other, and thus their extracted CNN features should be closely similar and contain complementary information."

- Break condition: If temporal consistency between frames is disrupted by rapid scope movement or scene changes, concatenated features may introduce noise rather than benefit.

### Mechanism 2
- Claim: Using 2D Gaussian shapes instead of binary masks for ground truth improves training efficiency and real-time performance.
- Mechanism: Training the model to predict 2D Gaussian shapes around polyp regions reduces the emphasis on precise boundary detection and allows the network to focus on learning polyp surface patterns. This approach eliminates the need for non-maximum suppression (NMS) at inference time, enabling direct bounding box generation from predicted Gaussian strengths.
- Core assumption: 2D Gaussian shapes provide a more robust representation of polyp regions than binary masks, and the Gaussian strength can directly serve as confidence values for detection.
- Evidence anchors:
  - [abstract] "We enforce the decoder part to predict 2D Gaussian shapes for polyp regions presented in the current input frames from the concatenated features."
  - [section] "Using 2D Gaussian shapes can also help to realize polyp detection in real-time. We can generate all detected bounding boxes directly from the predicted 2D Gaussian shapes without the need for computing non-maximum suppression (NMS) to eliminate overlapping bounding boxes."
  - [corpus] Weak - no direct corpus evidence found supporting Gaussian shape training approach.
- Break condition: If polyp boundaries are irregular or the Gaussian assumption doesn't match actual polyp morphology, detection accuracy may suffer.

### Mechanism 3
- Claim: Splitting the bottleneck layer equally based on the number of frames prevents model complexity increase while incorporating temporal information.
- Mechanism: By dividing the 256 activation maps in the bottleneck layer equally among the current frame and N previous frames, the model maintains constant computational complexity regardless of how many frames are concatenated. This ensures real-time performance is preserved while adding temporal context.
- Core assumption: Equal division of activation maps provides sufficient representational capacity for each frame's features while maintaining manageable computational load.
- Evidence anchors:
  - [section] "We equally divide the bottleneck layer into N slots of 256/N activation maps based on the number of previous frames involved."
  - [section] "This way, we avoid increasing the number of activation maps in the bottleneck layer and thus avoid extra mathematical operations."
  - [corpus] Weak - no direct corpus evidence found supporting this specific architectural design choice.
- Break condition: If the number of concatenated frames exceeds what can be adequately represented by 256/N activation maps, feature quality may degrade.

## Architecture Onboarding

- Component map: RGB image frames (512x512) -> ResNet34 encoder -> Bottleneck (256 activation maps, split equally) -> UNet-like decoder -> 2D Gaussian shape predictions
- Critical path: Input frames → Encoder feature extraction → Bottleneck concatenation → Decoder interpretation → 2D Gaussian output → Bounding box generation
- Design tradeoffs:
  - Temporal information vs. computational complexity: The equal splitting of bottleneck maps ensures constant complexity
  - Frame history length vs. feature quality: More frames provide better temporal context but may introduce noise if frames are too dissimilar
  - Gaussian approximation vs. precise boundary detection: Gaussian shapes simplify training and inference but may lose boundary detail
- Failure signatures:
  - Rapid scope movement causing dramatic scene changes between frames
  - High polyp motion or deformation between consecutive frames
  - Insufficient feature representation when too many frames are concatenated (small activation maps per frame)
- First 3 experiments:
  1. Baseline test: Run the model with only current frame (f(t)) to establish performance metrics
  2. Single previous frame test: Add f(t-1) features to bottleneck and measure improvement in sensitivity/precision
  3. Multiple frames test: Incrementally add f(t-2), f(t-3) features to identify optimal number of frames for concatenation
