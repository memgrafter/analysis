# UnbiasedNets: A Dataset Diversification Framework for Robustness Bias Alleviation in Neural Networks

## Quick Facts
- arXiv ID: 2302.12538
- Source URL: https://arxiv.org/abs/2302.12538
- Reference count: 12
- Primary result: UnbiasedNets significantly reduces robustness bias in neural networks by generating balanced datasets through synthetic data generation and redundancy minimization

## Executive Summary
UnbiasedNets addresses robustness bias in neural networks, where networks exhibit significantly different noise tolerance across output classes due to imbalanced training datasets. The framework leverages K-means clustering and neural network noise tolerance to diversify training datasets, generating balanced datasets even from smaller, imbalanced ones. By relaxing feature bounds using noise tolerance and removing redundant inputs, UnbiasedNets creates more representative training data that leads to neural networks with equal robustness to noise across all output classes.

## Method Summary
UnbiasedNets works by first detecting bias through noise injection and misclassification analysis, then determining feature bounds for each class using training data and noise tolerance levels. The framework relaxes these bounds to generate synthetic inputs proportional to misclassification rates, ensuring balanced representation across classes. After synthetic data generation, redundancy minimization via K-means clustering removes similar inputs while maintaining diversity. The final diversified dataset is validated through feature correlation checks before retraining the neural network.

## Key Results
- Significantly reduces robustness bias ratio (BR) across multiple datasets including binary and multi-label classifiers
- Outperforms existing balanced dataset generation tools in bias reduction effectiveness
- Successfully generates balanced datasets even from smaller, imbalanced training data through synthetic input generation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Robustness bias arises from imbalanced datasets where output classes are unequally represented
- Mechanism: Uses K-means clustering and noise tolerance analysis to diversify training datasets by generating synthetic inputs that balance class representation
- Core assumption: Balanced datasets with equal class representation lead to equal noise robustness across all output classes
- Evidence anchors:
  - [abstract] "This bias is shown to result from imbalanced datasets, i.e., the datasets where all output classes are not equally represented."
  - [section] "Definition 1 (Balanced Dataset) Given a dataset X with L output classes... the dataset is said to be balanced/the output classes are equally represented iff density ρ of inputs from each class in the input hyperspace is (approximately) equal."
- Break condition: Extremely imbalanced datasets or very low noise tolerance limit synthetic input generation effectiveness

### Mechanism 2
- Claim: Noise tolerance provides practical bounds for generating realistic synthetic inputs
- Mechanism: Determines maximum noise level (∆xmax) a network can tolerate without misclassification, then expands feature bounds within this tolerance to generate valid synthetic inputs
- Core assumption: Inputs within noise tolerance bounds remain correctly classified, making synthetic inputs within these bounds valid for training
- Evidence anchors:
  - [abstract] "This framework leverages K-means clustering and the NN's noise tolerance to diversify the given training dataset."
  - [section] "Theorem 1 (Bound Relaxation using Noise Tolerance)... the application of noise within the tolerance of the network does not change the output classification."
- Break condition: Very low noise tolerance collapses expanded bounds to original feature extrema, negating benefits

### Mechanism 3
- Claim: Redundancy minimization via K-means clustering improves dataset diversity and reduces overfitting
- Mechanism: Clusters inputs within each class and retains only one representative per cluster after synthetic input generation
- Core assumption: Removing similar inputs reduces overfitting and forces the network to learn more generalizable features
- Evidence anchors:
  - [abstract] "UnbiasedNets combines synthetic input generation with redundancy minimization to diversify and generate potentially balanced and equally-represented datasets."
  - [section] "x% closely resembling inputs from each class are removed to minimize the redundancy in the diversified training dataset... generating 1/x clusters for each output class and then retaining a single input from each cluster."
- Break condition: Oversized or undersized clusters may lose important variations or fail to reduce redundancy effectively

## Foundational Learning

- Concept: K-means clustering
  - Why needed here: Segments input features by class and minimizes redundancy by grouping similar inputs
  - Quick check question: How does K-means determine cluster centroids, and what distance metric does it use by default?

- Concept: Noise tolerance (∆xmax)
  - Why needed here: Defines maximum noise perturbation a network can tolerate without misclassification; used to expand feature bounds for synthetic input generation
  - Quick check question: What is the difference between noise tolerance and robustness in neural networks?

- Concept: Feature correlation
  - Why needed here: Ensures synthetic inputs respect realistic relationships between features observed in original data
  - Quick check question: Why is Pearson correlation used to validate synthetic inputs, and what does a large percentage difference indicate?

## Architecture Onboarding

- Component map: Bias Detection -> Bound Determination -> Synthetic Input Generation -> Redundancy Minimization -> Dataset Validation
- Critical path: Bias Detection → Bound Determination → Synthetic Input Generation → Redundancy Minimization → Dataset Validation
- Design tradeoffs: Larger ∆xmax allows more synthetic input generation but may introduce unrealistic samples; aggressive redundancy minimization may lose rare variations
- Failure signatures: High BR after diversification indicates insufficient balancing; validation failure suggests synthetic inputs violate feature correlations
- First 3 experiments:
  1. Run bias detection on small binary-class dataset to observe BR and identify misclassified classes
  2. Generate synthetic inputs for minority class using noise tolerance bounds and validate feature correlations
  3. Apply redundancy minimization and retrain network to compare BR before and after

## Limitations
- Effectiveness depends heavily on availability of noise tolerance information and sufficient training data per class
- Framework may struggle with extremely imbalanced datasets or networks with very low noise tolerance
- Pearson correlation threshold for synthetic data validation is not precisely specified, affecting reproducibility

## Confidence

- **High Confidence:** Core premise that dataset imbalance causes robustness bias is well-supported by experimental results across multiple datasets
- **Medium Confidence:** Synthetic data generation mechanism works as described, though impact varies with dataset characteristics
- **Low Confidence:** Exact threshold values (particularly for feature correlation validation) and their sensitivity to different datasets are not clearly specified
