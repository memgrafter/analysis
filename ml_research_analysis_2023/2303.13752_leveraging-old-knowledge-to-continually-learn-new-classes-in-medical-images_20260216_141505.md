# Leveraging Old Knowledge to Continually Learn New Classes in Medical Images

## Quick Facts
- arXiv ID: 2303.13752
- Source URL: https://arxiv.org/abs/2303.13752
- Reference count: 8
- One-line primary result: Dynamic architecture with expanding representations achieves superior class-incremental learning performance on three medical datasets while preventing catastrophic forgetting.

## Executive Summary
This paper addresses class-incremental continual learning in medical image classification, where models must learn new disease classes without forgetting previously learned ones. The authors propose a dynamic architecture with expanding representations that reuses old features while learning new ones, and a training strategy that alternates between two objectives: one focused on new classes and another emphasizing under-represented old classes. Experiments on three medical datasets (CCH5000, EyePACS, HAM10000) demonstrate that the proposed approach achieves superior performance over state-of-the-art baselines in terms of class accuracy and forgetting. Notably, the method shows significant improvements especially when dealing with highly skewed class distributions and small incremental class settings.

## Method Summary
The proposed method employs a dynamic architecture that shares a single low-level feature extractor across all classes while incrementally adding high-level feature extractors for new classes. A unified classifier expands row-wise to accommodate new classes and column-wise to include new features from each high-level extractor. The training strategy alternates between two objectives: Lnew focuses on learning discriminative features for new classes with classification, auxiliary, distillation, and margin losses, while Lold emphasizes under-represented old classes by assigning higher penalties for misclassified samples while freezing new parameters. The method uses class-balanced focal loss and cost-sensitive learning to handle class imbalance, and maintains a memory buffer for data replay of old classes.

## Key Results
- Achieves superior performance over state-of-the-art baselines in class-incremental learning on three medical datasets
- Demonstrates significant improvements when dealing with highly skewed class distributions
- Achieves negative forgetting in some cases, where newly learned knowledge improves classification of previous classes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Freezing old feature extractors while adding new ones prevents catastrophic forgetting of previously learned representations.
- Mechanism: By freezing the parameters of low-level and high-level feature extractors learned in previous steps, the model preserves the feature space that was useful for old classes. New feature extractors are added incrementally to learn features specific to new classes without modifying the old feature space.
- Core assumption: Old features remain relevant and useful for classifying old classes even after learning new classes.
- Evidence anchors: "The proposed architecture has a single low-level feature extractor shared across all classes, which helps to promote utilization of previously learned knowledge." "To alleviate forgetting, we freeze the set of old parameters {θL,θH1,..., θHt−1 }."

### Mechanism 2
- Claim: Alternating between Lnew and Lold objectives balances learning new features while maintaining performance on old classes.
- Mechanism: Lnew focuses on learning discriminative features for new classes with classification, auxiliary, distillation, and margin losses. Lold focuses on under-represented old classes by assigning higher penalties for misclassified samples, while freezing new parameters to prevent forgetting. This alternation ensures neither objective dominates.
- Core assumption: The model can effectively learn new features without forgetting old ones when given alternating optimization objectives that emphasize different aspects of the learning problem.
- Evidence anchors: "We propose a new training strategy that alternates between two objective functions, one focusing on new classes and the other on the old." "We design two objectives Lnew and Lold and use them alternately during each training step."

### Mechanism 3
- Claim: Dynamic architecture expansion with unified classifier allows seamless integration of new classes while reusing old knowledge.
- Mechanism: The unified classifier expands row-wise to accommodate new classes and column-wise to include new features from each high-level extractor. This allows the model to use both old and new features for classification decisions, leveraging shared low-level features across all classes.
- Core assumption: A unified classifier that incorporates both old and new features can make better decisions than separate classifiers for old and new classes.
- Evidence anchors: "We employ a dynamic architecture that allows features from the old classes to be reused while expanding the set of feature extractors to learn novel features from the new classes." "The unified classifier Ft is a single layer with weight matrix Wt comprising of vectors wt,i for each class i ∈ Y[1:t]."

## Architecture Onboarding

- Component map: L -> {H1,...,Ht} -> Ft (unified classifier)
- Critical path:
  1. Initialize with L, H1, F1 using D1
  2. For each incremental step t: Add new high-level feature extractor Ht, expand classifier Ft, construct memory buffer Mt-1, alternate training between Lnew and Lold objectives
  3. Evaluate on all seen classes after each step
- Design tradeoffs:
  - Memory vs. performance: Limited memory buffer means fewer old samples for replay, potentially affecting old class performance
  - Model complexity vs. effectiveness: More high-level feature extractors increase model capacity but also computational cost
  - Training time vs. stability: More frequent alternation between objectives may improve stability but increase training time
- Failure signatures:
  - Performance degradation on old classes despite freezing parameters
  - Inability to learn new classes effectively due to frozen parameters
  - Classifier confusion between old and new classes due to feature overlap
  - Memory buffer imbalance leading to biased training
- First 3 experiments:
  1. Test baseline performance on CCH5000 with 1 new class per step to establish upper bound
  2. Implement ablation study removing Lold to verify its importance in preserving old knowledge
  3. Test on EyePACS with 1 new class per step to evaluate performance on highly skewed class distribution

## Open Questions the Paper Calls Out
- The paper mentions that "Future work includes investigating the need to expand the model when new classes are introduced" in the conclusion section, highlighting uncertainty about optimal timing for model expansion in class-incremental learning scenarios.

## Limitations
- The approach assumes old features remain relevant and concept drift does not occur between incremental steps, which may not hold in evolving medical scenarios.
- The memory buffer mechanism may be insufficient for highly imbalanced datasets where old classes have vastly different sample distributions.
- The alternating optimization strategy could be sensitive to hyperparameter tuning, particularly the frequency of alternation between Lnew and Lold objectives.

## Confidence
- High confidence: The effectiveness of freezing old feature extractors to prevent catastrophic forgetting is well-established in continual learning literature and supported by experimental results.
- Medium confidence: The alternating objectives strategy shows promise but requires careful tuning of alternation frequency and weights to maintain balance.
- Medium confidence: The dynamic architecture expansion is theoretically sound but may face scalability challenges with a large number of incremental classes.

## Next Checks
1. Conduct experiments with varying memory buffer sizes (e.g., 10, 20, 50 samples per class) to determine the minimum effective buffer size for maintaining old class performance.
2. Test the approach with concept drift scenarios by gradually modifying the distribution of old class samples in the memory buffer over incremental steps.
3. Evaluate the impact of different alternation frequencies between Lnew and Lold objectives (e.g., 1:1, 2:1, 3:1 ratios) on both old and new class performance to identify optimal training schedules.
