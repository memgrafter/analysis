# Hierarchical Graph Neural Networks for Causal Discovery and Root Cause Localization

## Quick Facts
- arXiv ID: 2302.01987
- Source URL: https://arxiv.org/abs/2302.01987
- Reference count: 40
- Key result: Achieves up to 84% Precision@10 and 92% MAP@10 on AIOps dataset for root cause localization

## Executive Summary
This paper introduces REASON, a hierarchical graph neural networks-based framework for root cause localization in complex systems with interdependent network structures. The framework addresses the challenge of discovering both intra-level and inter-level causal relationships by integrating topological causal discovery (using hierarchical GNN and random walk with restart) and individual causal discovery (using Extreme Value theory). Experiments on three real-world datasets demonstrate that REASON significantly outperforms baseline methods, achieving strong performance metrics including high precision and MAP scores.

## Method Summary
REASON is a hierarchical graph neural networks-based framework that combines topological and individual causal discovery for root cause localization. The method uses separate GNN modules for low-level and high-level nodes to learn causal relationships within and across network levels. After learning the causal structure, it applies random walk with restart on the transposed network to model fault propagation. Individual causal scores are computed using Extreme Value Theory to analyze temporal patterns in metric data. The final root cause ranking integrates both topological and individual scores through a weighted combination.

## Key Results
- Achieves up to 84% Precision@10 and 92% MAP@10 on AIOps dataset
- Significantly outperforms baseline methods across three real-world datasets (AIOps, WADI, and Swat)
- Ablation studies confirm effectiveness of each component, particularly the integration of topological and individual causal analysis

### Mechanism 1
- Claim: Hierarchical GNN architecture enables learning of both intra-level and inter-level causal relationships in interdependent networks.
- Mechanism: The framework uses separate GNN modules for low-level and high-level nodes, with inter-level learning that aggregates low-level information into high-level embeddings. This creates a hierarchical structure that captures causality within networks and across network boundaries.
- Core assumption: System metrics can be modeled as time series data where causality propagates through hierarchical network structures.

- Break condition: If system metrics do not exhibit hierarchical causal structures or if the aggregation of low-level to high-level information does not preserve causal information.

### Mechanism 2
- Claim: Random walk with restart on transposed interdependent causal networks effectively models fault propagation and identifies root causes.
- Mechanism: After learning the causal structure, the network is transposed and a random walk with restart is applied. This simulates tracing back from system KPI through the causal network to identify likely root causes based on visitation probabilities.
- Core assumption: Fault propagation follows the learned causal structure and can be modeled as a diffusion process on the network.
- Evidence anchors:
  - [abstract] "we then leverage random walk with restarts to model the network propagation of a system fault"

- Break condition: If the causal relationships learned are incorrect or if the fault propagation patterns differ significantly from the assumed diffusion model.

- Mechanism: The framework divides metric time series into initialization and detection segments, estimates boundaries for normal values using Extreme Value Theory, and assigns individual causal scores based on the magnitude of deviations from these boundaries.

## Open Questions the Paper Calls Out

- Question: How does the REASON framework perform when applied to systems with more than two levels of interdependence (e.g., triple-layer or deeper hierarchical structures)?
- Basis in paper: [explicit] The paper focuses on two levels of system entities and does not evaluate performance on deeper hierarchical structures.
- Why unresolved: The methodology and experiments are designed specifically for two-level systems, leaving the scalability to deeper hierarchies unexplored.
- What evidence would resolve it: Experimental results on datasets with three or more levels of interdependence, showing whether the hierarchical GNN and causal discovery components scale effectively.

## Limitations

- Effectiveness depends on the assumption that system metrics exhibit clear hierarchical causal structures and follow extreme value distributions during failures
- Experimental results lack broader validation across diverse system architectures beyond the three tested datasets
- Paper does not provide detailed runtime complexity analysis or scalability assessments for very large interdependent networks

## Confidence

- **High Confidence**: The basic framework architecture and methodology description are well-defined and reproducible. The use of hierarchical GNNs for causal discovery in network structures is a sound approach that aligns with established literature.
- **Medium Confidence**: The experimental results showing performance improvements over baselines are likely valid for the tested datasets, but generalization to other systems remains uncertain. The effectiveness of the Extreme Value Theory component is moderately supported but lacks extensive validation.
- **Low Confidence**: Claims about the framework's applicability to arbitrary interdependent network structures and its robustness to various failure patterns are not sufficiently supported by the evidence presented.
