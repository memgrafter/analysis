# Scalable Object Detection on Embedded Devices Using Weight Pruning and Singular Value Decomposition

## Quick Facts
- arXiv ID: 2303.02735
- Source URL: https://arxiv.org/abs/2303.02735
- Reference count: 14
- Optimized YOLOv7-tiny achieves 0.724 mAP@50 at 1.48 FPS with 12.1 MB weight size on custom street work dataset

## Executive Summary
This paper proposes a method to optimize object detection models for deployment on embedded devices by combining weight pruning and singular value decomposition (SVD). The authors evaluated their approach on a custom street work dataset with 7 object classes using the YOLOv7-tiny architecture. The proposed weight pruning + SVD model achieved 0.724 mAP@50 at 1.48 FPS with 12.1 MB weight size, outperforming the original unoptimized model (0.717 mAP@50, 1.50 FPS, 12.3 MB). The results demonstrate that weight pruning and SVD can effectively compress object detection models while maintaining or improving accuracy, enabling deployment on resource-constrained devices like the Raspberry Pi.

## Method Summary
The proposed method combines weight pruning and singular value decomposition (SVD) to compress object detection models for embedded deployment. Weight pruning removes redundant connections in the neural network by eliminating weights below a certain threshold, reducing the total number of parameters. SVD then decomposes the remaining weight matrices into lower-rank approximations, further compressing the model while preserving essential information. This two-stage optimization process reduces both memory footprint and computational requirements without significant accuracy loss.

## Key Results
- Weight pruning + SVD model achieves 0.724 mAP@50 at 1.48 FPS with 12.1 MB weight size
- Original YOLOv7-tiny: 0.717 mAP@50, 1.50 FPS, 12.3 MB weight size
- Combined approach shows 0.1% mAP improvement while reducing model size by 1.6%

## Why This Works (Mechanism)
Weight pruning removes redundant connections in the neural network, eliminating weights that contribute minimally to the output. This reduces the total number of parameters and computations required during inference. SVD then factorizes the remaining weight matrices into lower-rank approximations, decomposing them into orthogonal matrices that capture the most important information with fewer parameters. The combination exploits complementary compression mechanisms: pruning removes unnecessary weights while SVD efficiently represents the remaining weights in a compact form.

## Foundational Learning
1. **Weight Pruning**: Removes weights below a threshold to reduce model size
   - Why needed: Eliminates redundant parameters that don't contribute to accuracy
   - Quick check: Verify that pruned weights are close to zero or have minimal gradient contribution

2. **Singular Value Decomposition**: Factorizes matrices into orthogonal components
   - Why needed: Provides optimal low-rank approximation for matrix compression
   - Quick check: Confirm that truncated SVD retains sufficient singular values for accuracy

3. **Model Compression Trade-offs**: Balance between accuracy, speed, and size
   - Why needed: Embedded devices have strict resource constraints
   - Quick check: Monitor accuracy drop versus compression ratio on validation set
