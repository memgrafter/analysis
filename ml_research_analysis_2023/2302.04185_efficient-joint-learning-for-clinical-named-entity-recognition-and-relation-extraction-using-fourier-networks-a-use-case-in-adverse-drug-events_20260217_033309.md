# Efficient Joint Learning for Clinical Named Entity Recognition and Relation Extraction Using Fourier Networks: A Use Case in Adverse Drug Events

## Quick Facts
- arXiv ID: 2302.04185
- Source URL: https://arxiv.org/abs/2302.04185
- Reference count: 15
- Key outcome: JNRF outperforms rolling window BERT with selective pooling by 0.42% F1-score while being twice as fast to train

## Executive Summary
This paper introduces JNRF, a joint named entity recognition and relation extraction model designed to overcome the computational and memory limitations of current approaches when processing large-scale electronic health records. The model leverages Fourier networks with positional encoding, selective pooling strategies, and distance-aware attention mechanisms to achieve efficient processing of variable-length clinical documents. JNRF demonstrates superior performance on the 2018 N2C2 ADE benchmark while significantly reducing training time and memory consumption compared to both BERT-based and BiLSTM-CRF architectures.

## Method Summary
The JNRF model addresses the computational bottlenecks in clinical NER+RE by employing a Fourier network layer for efficient token mixing with low complexity, combined with selective pooling and distance-aware attention for relation extraction. The architecture processes variable-length documents through positional encoding and unitary batch sizes, eliminating the need for rolling windows. This approach enables processing of complete clinical documents without external tools, hand-crafted rules, or post-processing, achieving a favorable balance between performance and efficiency.

## Key Results
- JNRF achieves 0.42% higher F1-score than rolling window BERT with selective pooling on the 2018 N2C2 ADE benchmark
- Trains 22 times faster than state-of-the-art BiLSTM-CRF architectures while maintaining 90% of their performance
- Reduces GPU memory consumption by 1.75x compared to BiLSTM-CRF models
- Eliminates need for external tools, hand-crafted rules, or post-processing

## Why This Works (Mechanism)
The model's efficiency stems from replacing traditional transformer-based token mixing with Fourier networks, which provide low-complexity token interactions while maintaining expressiveness. The selective pooling strategy combined with distance-aware attention weights enables effective relation extraction without requiring computationally expensive pairwise comparisons across all token combinations. The unitary batch size processing of complete documents eliminates the overhead associated with rolling window approaches.
