# Friend Ranking in Online Games via Pre-training Edge Transformers

## Quick Facts
- arXiv ID: 2302.10043
- Source URL: https://arxiv.org/abs/2302.10043
- Reference count: 18
- Primary result: Proposes Edge Transformer for friend recall in online games, achieving higher ranking performance, click rate, return rate, and conversion rate compared to baselines.

## Executive Summary
This paper introduces Edge Transformer, a novel model for friend recall in online games. The approach treats friend recall as a link prediction problem, utilizing features of both active and lost players, as well as historical events. The Edge Transformer model is pre-trained using masked auto-encoders on massive unlabeled edges to improve performance. The proposed method outperforms state-of-the-art link prediction models and traditional methods in offline experiments and online A/B tests across three Tencent games.

## Method Summary
The Edge Transformer model takes features of active players, lost players, and their interactions as input tokens to a standard Transformer encoder. It predicts the probability of successful invitations, treating friend recall as a link prediction problem. The model is pre-trained using Edge MAE, which masks a proportion of input tokens and trains the encoder to reconstruct the original features. This pre-training on unlabeled data improves the model's performance on the link prediction task.

## Key Results
- Outperforms state-of-the-art link prediction models and traditional methods in offline experiments
- Achieves higher ranking performance, click rate, return rate, and conversion rate in online A/B tests across three Tencent games
- Demonstrates the effectiveness of pre-training with masked auto-encoders on unlabeled data

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Treating friend recall as a link prediction problem enables the model to utilize both active and lost player features, as well as historical event data.
- Mechanism: The Edge Transformer model takes features of both active and lost players, along with edge features (intimacy scores), as input tokens to a standard Transformer encoder. This allows the model to learn rich representations of the relationships between players.
- Core assumption: The link between an active player and a lost player can be effectively modeled as a prediction problem using their features and interaction history.
- Evidence anchors:
  - [abstract] "we treat friend recall as a link prediction problem and explore several link prediction methods which can use features of both active and lost players, as well as historical events."
  - [section] "In this work, we overcome the above limitations by treating friend recall as a link prediction problem. The problem is to predict the edge existing probability in a bipartite graph."
- Break condition: If the features of active and lost players are not informative enough to distinguish likely successful invitations from unsuccessful ones, or if historical event data is not available or reliable.

### Mechanism 2
- Claim: Pre-training the Edge Transformer with masked auto-encoders on massive unlabeled edges improves performance.
- Mechanism: A proportion of input tokens are randomly masked, and the encoder is trained to reconstruct the original features of the masked tokens. This allows the model to learn useful representations of player features and interactions from unlabeled data.
- Core assumption: There is enough structure in the unlabeled edges (i.e., player features and interactions) to learn useful representations that generalize to the link prediction task.
- Evidence anchors:
  - [abstract] "Furthermore, we propose a novel Edge Transformer model and pre-train the model via masked auto-encoders."
  - [section] "Inspired by MAE [7] in CV which pre-trains masked auto-encoders on unlabeled images, we propose to improve Edge Transformer with an Edge MAE model."
- Break condition: If the unlabeled data is too noisy or unrepresentative of the labeled data distribution, pre-training may not provide benefits or could even hurt performance.

### Mechanism 3
- Claim: The self-attention mechanism in the Transformer allows the model to integrate information across nodes and edges.
- Mechanism: The Transformer encoder uses multi-head self-attention to compute representations of each token (active player feature, edge feature, lost player feature) based on all other tokens in the sequence. This allows the model to capture complex relationships between players and interactions.
- Core assumption: The relationships between players and their interactions are sufficiently complex to benefit from a global, context-aware attention mechanism.
- Evidence anchors:
  - [section] "The encouraging results showcase the effectiveness of the Transformer model and masked pre-training with massive unlabeled data."
  - [section] "Self-attention allows Edge Transformer to integrate information across nodes and edges."
- Break condition: If the relationships between players and interactions are simple or local, the complexity of self-attention may not be necessary and could lead to overfitting.

## Architecture Onboarding

- Component map: Active player features -> Edge Transformer -> Output probability
- Critical path: Input features (active player, edge, lost player) -> Edge Transformer -> Output probability
- Design tradeoffs:
  - Using a standard Transformer vs. a graph-specific architecture: Standard Transformer allows reusing existing implementations but may not capture graph structure as well.
  - Pre-training on unlabeled data vs. training only on labeled data: Pre-training can improve performance but requires more computation and may not always generalize well.
- Failure signatures:
  - Poor performance on validation data: Could indicate issues with feature engineering, model capacity, or overfitting.
  - Slow convergence or instability during training: Could be due to learning rate, batch size, or initialization issues.
  - Large gap between offline and online performance: Could indicate overfitting to the validation set or issues with the online deployment.
- First 3 experiments:
  1. Ablation study: Compare Edge Transformer with and without pre-training on unlabeled data to assess the impact of pre-training.
  2. Hyperparameter tuning: Systematically vary learning rate, batch size, and number of layers to find optimal settings.
  3. Feature importance analysis: Analyze the contribution of different features (active player, edge, lost player) to the model's predictions using techniques like permutation importance or SHAP values.
