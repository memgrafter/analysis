# Investigating Group Distributionally Robust Optimization for Deep Imbalanced Learning: A Case Study of Binary Tabular Data Classification

## Executive Summary
This paper investigates Group Distributionally Robust Optimization (gDRO) for handling class imbalance in deep learning, focusing on binary tabular datasets. Unlike standard Empirical Risk Minimization (ERM), which minimizes average loss, gDRO minimizes the worst-case loss across classes. The method was evaluated on 19 binary imbalanced datasets using 10-fold cross-validation and compared to ERM and classical imbalance techniques (ROS, RUS, COST, RUSROS). gDRO achieved the highest overall ROC-AUC (85.55%) and g-mean (84.28%), demonstrating robust performance across varying imbalance ratios. ERM excelled in PR-AUC (73.07%), while ROS led in F1-score (65.07%). Statistical analysis confirmed the significance of gDRO's performance gains. The results suggest gDRO is effective for learning robust models on imbalanced tabular data.

## Method Summary
The study compares gDRO against ERM and classical imbalance methods (ROS, RUS, COST, RUSROS) on 19 binary imbalanced tabular datasets. A deep fully connected neural network (MLP) with ReLU activations, batch normalization, and dropout was used. Network depth (2-6) and width (32-512) were optimized via grid search and 5-fold cross-validation. The final evaluation used 10-fold cross-validation with early stopping and the Adam optimizer. Performance was assessed using ROC-AUC, PR-AUC, F1-score, and g-mean, with statistical significance evaluated using Friedman and Wilcoxon signed-rank tests.

## Key Results
- gDRO achieved the highest overall ROC-AUC (85.55%) and g-mean (84.28%) across 19 binary imbalanced datasets.
- ERM excelled in PR-AUC (73.07%), while ROS led in F1-score (65.07%).
- Statistical analysis confirmed the significance of gDRO's performance gains across varying imbalance ratios.

## Why This Works (Mechanism)
Assumption: gDRO's effectiveness stems from its worst-case optimization over class groups, which directly addresses the imbalanced data challenge by preventing the model from focusing solely on the majority class. By minimizing the maximum loss across groups, gDRO ensures balanced performance, improving metrics like g-mean and ROC-AUC that are sensitive to minority class performance. This mechanism contrasts with ERM's average loss minimization, which can be biased toward majority classes in imbalanced scenarios.

## Foundational Learning
- **Distributionally Robust Optimization (DRO)**: A framework that minimizes the worst-case expected loss over a family of distributions, providing robustness against distributional shifts. Needed to handle class imbalance by focusing on worst-case performance across classes.
- **Group DRO (gDRO)**: Extends DRO by explicitly grouping data (e.g., by class) and optimizing for the worst-case group, ensuring balanced performance across imbalanced classes.
- **Imbalance Ratio (IR)**: The ratio between the majority and minority class sizes, directly affecting model bias and evaluation metrics.
- **Silhouette Coefficient**: Measures class overlap and cluster separation, influencing the difficulty of classification tasks in imbalanced datasets.
- **Statistical Tests (Friedman, Wilcoxon)**: Used to assess the significance of performance differences across multiple datasets and methods, ensuring robust conclusions.
