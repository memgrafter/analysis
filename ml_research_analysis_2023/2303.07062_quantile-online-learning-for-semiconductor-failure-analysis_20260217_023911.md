# Quantile Online Learning for Semiconductor Failure Analysis

## Quick Facts
- arXiv ID: 2303.07062
- Source URL: https://arxiv.org/abs/2303.07062
- Reference count: 0
- Key result: 86.66% overall accuracy on semiconductor defect detection

## Executive Summary
This paper introduces a novel quantile-based online learning method specifically designed for semiconductor failure analysis. The approach addresses the challenge of detecting defects in a single-pass online fashion by transforming raw features into quantile numbers, making it robust to varying feature ranges typical in semiconductor datasets. The method incorporates a discount factor to balance local and global information in the statistical calculations, achieving superior performance on semiconductor device-level defects.

## Method Summary
The proposed method transforms raw semiconductor features into quantile representations to handle varying feature ranges and introduces a discount factor that controls the proportion of local versus global information in the statistical calculations. This online learning framework processes data sequentially without requiring multiple passes, making it suitable for real-time semiconductor failure analysis applications. The approach is specifically tailored to handle the unique characteristics of semiconductor datasets, including non-normal distributions and varying scales across different measurement parameters.

## Key Results
- Achieves 86.66% overall accuracy in semiconductor defect detection
- Outperforms the second-best existing method by 15.50% on GAA-FET dislocation defect dataset
- Successfully applied to both semiconductor device-level defects and public database scenarios

## Why This Works (Mechanism)
The quantile transformation converts raw feature values into their corresponding quantile ranks, effectively normalizing the data distribution and making it invariant to scale differences across features. This is particularly important for semiconductor datasets where different measurement parameters (voltage, current, temperature) have vastly different scales. The discount factor λ controls the temporal weighting of observations, allowing the algorithm to balance between rapidly adapting to new defect patterns (high λ) and maintaining stable statistics from historical data (low λ).

Design tradeoffs: Single-pass processing (efficiency) vs batch processing (accuracy), fixed vs adaptive λ parameter, memory requirements for maintaining statistics

Failure signatures: Poor performance on correlated features, sensitivity to λ parameter selection, degradation with highly non-stationary data distributions

## Limitations
- Evaluation primarily on single semiconductor dataset and one public database limits generalizability
- Quantile-based transformation may not capture complex feature relationships in highly correlated datasets
- Computational efficiency and memory requirements for large-scale datasets not explicitly addressed
