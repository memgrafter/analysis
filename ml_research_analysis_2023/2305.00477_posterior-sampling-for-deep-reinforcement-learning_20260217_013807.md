# Posterior Sampling for Deep Reinforcement Learning

## Quick Facts
- **arXiv ID:** 2305.00477
- **Source URL:** https://arxiv.org/abs/2305.00477
- **Reference count:** 19
- **Primary result:** First scalable approximation of PSRL for complex environments, significantly outperforming prior randomized value function methods on 55 Atari games

## Executive Summary
This paper introduces Posterior Sampling for Deep Reinforcement Learning (PSDRL), the first scalable approximation of Posterior Sampling for Reinforcement Learning (PSRL) for complex environments. PSDRL combines efficient uncertainty quantification over latent state space models with a continual planning algorithm based on value-function approximation, addressing key challenges in scaling up PSRL including recency bias and status quo bias. The method encodes high-dimensional states into lower-dimensional latent states and represents uncertainty through a Bayesian neural network over forward model parameters.

## Method Summary
PSDRL encodes high-dimensional states into lower-dimensional latent states to enable efficient planning in latent space. The method uses an autoencoder to compress 64x64 grayscale images into 1536-dimensional latent states, then learns a forward model that predicts transitions in this latent space. Uncertainty over the forward model parameters is maintained through a Bayesian neural network, enabling posterior sampling for exploration. Rather than training a fresh value network for each sampled model (which would introduce recency bias), PSDRL continues training a single value network across multiple sampled models while still incorporating feedback from the current sampled model through one-step returns. This addresses both recency bias and status quo bias while maintaining sample efficiency.

## Key Results
- PSDRL significantly outperforms Bootstrapped DQN with randomized priors and Successor Uncertainties on 55 Atari games
- PSDRL achieves competitive performance with DreamerV2 in both sample efficiency and computational efficiency
- Ablation studies confirm the importance of retaining planning information across sampled models and the superiority of posterior sampling over naive exploration approaches

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** PSDRL achieves sample efficiency by encoding high-dimensional states into lower-dimensional latent states, enabling efficient planning over latent state space models.
- **Mechanism:** The autoencoder compresses 64x64 grayscale images into 1536-dimensional latent states, which are then used for planning. This dimensionality reduction allows the forward model to predict transitions more efficiently than operating directly on high-dimensional pixel space.
- **Core assumption:** Latent state representations capture sufficient information for effective planning while being computationally cheaper to work with than raw pixels.
- **Evidence anchors:**
  - [abstract] "PSDRL encodes a high-dimensional state into a lower-dimensional latent state to enable predicting transitions in latent state space"
  - [section] "The autoencoder is convolutional... Encoding a state space into a lower dimensional latent state space enables more efficient planning"
  - [corpus] No direct evidence found in related papers about specific latent state dimensions or their sufficiency.
- **Break condition:** If the autoencoder fails to capture critical information needed for planning (e.g., small visual differences between enemies in BEAM RIDER), the method's sample efficiency degrades.

### Mechanism 2
- **Claim:** Posterior sampling over forward model parameters provides efficient exploration by balancing exploitation and exploration naturally.
- **Mechanism:** The neural-linear approach maintains a distribution over output layer parameters of the forward model. By sampling from this posterior and using the sampled model for planning, the agent explores actions that are valuable under different plausible environment models.
- **Core assumption:** The uncertainty in the forward model parameters correlates with uncertainty about which actions will yield high returns.
- **Evidence anchors:**
  - [abstract] "PSDRL represents uncertainty through a Bayesian neural network that maintains a distribution over the parameters of this transition model"
  - [section] "This approach achieves remarkable success when combined with posterior sampling in the contextual bandits setting"
  - [corpus] Weak evidence - related papers discuss posterior sampling but not specifically the neural-linear combination.
- **Break condition:** If the neural-linear approximation poorly represents the true posterior uncertainty, exploration becomes inefficient.

### Mechanism 3
- **Claim:** Continual value function approximation across sampled models addresses recency bias while avoiding status quo bias.
- **Mechanism:** Instead of training a fresh value network for each sampled model (which would forget previous planning results), PSDRL continues training a single value network across multiple sampled models. This retains planning information from previous models while still incorporating feedback from the current sampled model through one-step returns.
- **Core assumption:** The value function learned for one sampled model provides a useful initialization for learning the value function of a new sampled model.
- **Evidence anchors:**
  - [section] "PSDRL addresses this recency bias by retaining information obtained from previous sampled models in a value network through continual training"
  - [section] "Training a value function approximator across sampled models introduces another potential pitfall... PSDRL addresses this status quo bias by choosing actions that maximize the one-step return"
  - [corpus] No direct evidence in related papers about this specific continual approach.
- **Break condition:** If the value network becomes too biased toward previous models, it may fail to explore sufficiently under the current sampled model.

## Foundational Learning

- **Concept:** Bayesian neural networks for uncertainty quantification
  - **Why needed here:** PSDRL needs to represent uncertainty over forward model parameters to enable posterior sampling. Bayesian neural networks provide a principled way to maintain this uncertainty.
  - **Quick check question:** What is the key difference between a standard neural network and a Bayesian neural network in the context of PSDRL?

- **Concept:** Latent variable models for state representation
  - **Why needed here:** Raw pixel observations are high-dimensional and redundant. A latent variable model learns compressed representations that are sufficient for planning.
  - **Quick check question:** Why might a 1536-dimensional latent state be preferable to 64x64=4096-dimensional pixel space for planning?

- **Concept:** Model-based reinforcement learning planning
  - **Why needed here:** PSDRL uses sampled environment models to plan without interacting with the real environment, which should be more sample-efficient than model-free methods.
  - **Quick check question:** What is the key advantage of planning with a model versus learning a policy directly from environment interactions?

## Architecture Onboarding

- **Component map:** Observation → Autoencoder (Eχ, Dχ) → Forward model (fθ) with GRU → Termination model (ων) → Value network (Vψ) → Action selection → Environment interaction → Data collection → Model updates

- **Critical path:** Observation → Encoding → Forward model prediction → Value network evaluation → Action selection → Environment interaction → Data collection → Model updates

- **Design tradeoffs:**
  - Latent state dimensionality vs. information retention: Higher dimensions capture more information but increase computational cost
  - Planning horizon: Longer horizons could improve planning but increase computational cost exponentially
  - Value network updates: More frequent updates improve planning quality but increase computation time

- **Failure signatures:**
  - Poor reconstruction quality in autoencoder indicates loss of critical information
  - Value network converging to near-zero values suggests planning failure
  - High variance in decoded predictions from sampled models indicates poor uncertainty quantification

- **First 3 experiments:**
  1. Verify autoencoder reconstruction quality on held-out states
  2. Test forward model prediction accuracy on validation trajectories
  3. Compare exploration efficiency with and without posterior sampling (ϵ-greedy baseline)

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** What is the precise impact of using a latent state space model architecture on sample efficiency compared to directly learning in the high-dimensional pixel space?
- **Basis in paper:** [explicit] The paper discusses using a latent state space transition model and cites recent successes of latent space models in model-based reinforcement learning, but doesn't provide a direct comparison to algorithms that operate directly on pixels.
- **Why unresolved:** The paper doesn't include experiments comparing PSDRL with latent state representations to a variant that learns directly from pixels, which would isolate the contribution of the latent space architecture.
- **What evidence would resolve it:** Experiments comparing PSDRL with identical hyperparameters but using pixel inputs directly versus latent state representations, measuring sample efficiency and performance on the same benchmark.

### Open Question 2
- **Question:** How does the computational efficiency of PSDRL scale with the dimensionality of the latent state space?
- **Basis in paper:** [inferred] The paper mentions that encoding into lower-dimensional latent states enables more efficient planning, but doesn't systematically explore how the latent space dimensionality affects computational requirements or performance.
- **Why unresolved:** The paper uses a fixed latent state dimension (1536) without exploring how varying this parameter affects both computational efficiency and learning performance.
- **What evidence would resolve it:** Systematic experiments varying the latent state dimension (e.g., 512, 1024, 2048) while measuring training time, memory usage, and performance across multiple Atari games.

### Open Question 3
- **Question:** What is the optimal frequency for updating the posterior distribution over forward model parameters?
- **Basis in paper:** [explicit] The paper mentions that forward models are sampled every m time steps (with m=1000 for most steps) and discusses the trade-off between recency bias and computational cost, but doesn't systematically explore different sampling frequencies.
- **Why unresolved:** The paper uses a fixed sampling frequency without investigating whether this is optimal or how different frequencies affect exploration, sample efficiency, and computational requirements.
- **What evidence would resolve it:** Experiments varying the sampling frequency (e.g., m=250, 500, 2000) while measuring performance, exploration behavior, and computational efficiency across multiple games and training regimes.

## Limitations
- Neural-linear uncertainty quantification effectiveness primarily validated through empirical Atari performance rather than theoretical guarantees
- 1536-dimensional latent states choice not justified through ablation studies
- Method's behavior on non-visual control tasks remains unknown
- Continual planning approach's sensitivity to sampling frequency parameter (m) not thoroughly explored

## Confidence

- **Mechanism 1 (latent state encoding):** High confidence - the computational benefits are clear and the reconstruction quality is verified
- **Mechanism 2 (posterior sampling):** Medium confidence - effective empirically but neural-linear approximation limitations not fully characterized  
- **Mechanism 3 (continual planning):** Medium confidence - the approach addresses known biases but alternative strategies are not compared
