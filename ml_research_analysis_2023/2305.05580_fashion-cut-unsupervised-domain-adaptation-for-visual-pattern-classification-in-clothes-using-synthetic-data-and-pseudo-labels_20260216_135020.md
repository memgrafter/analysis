# Fashion CUT: Unsupervised domain adaptation for visual pattern classification in clothes using synthetic data and pseudo-labels

## Quick Facts
- arXiv ID: 2305.05580
- Source URL: https://arxiv.org/abs/2305.05580
- Reference count: 27
- Key outcome: Fashion CUT achieves 0.628 accuracy on real-world fashion pattern classification, outperforming other domain adaptation methods and requiring at least 5,000 synthetic images for optimal performance.

## Executive Summary
This paper addresses the challenge of fashion pattern classification in e-commerce where labeled real-world datasets are expensive to obtain. The authors propose Fashion CUT, a method that combines synthetic data generation with unsupervised domain adaptation using CUT (Contrastive Unpaired Translation) and a classifier trained jointly with pseudo-labels. By translating synthetic fashion images to realistic ones while preserving pattern labels, and introducing real-world pseudo-labels during training, the approach achieves state-of-the-art performance on the Zalando SDG dataset. The method requires no real-world annotations while outperforming existing domain adaptation algorithms.

## Method Summary
Fashion CUT jointly trains a CUT-based image translation model with a ResNet50 classifier to adapt synthetic fashion pattern data to real-world images without labels. The generator translates synthetic images to realistic ones while the classifier enforces pattern label preservation during translation. In later training stages, real-world images are included with pseudo-labels predicted by the classifier to improve generalization. The loss function combines GAN loss, classifier cross-entropy loss, and contrastive losses for spatial consistency. Experiments use 5,000+ synthetic images generated in Blender and 334,165 unlabeled real images for training.

## Key Results
- Fashion CUT achieves 0.628 accuracy on real-world test set, outperforming BSP (0.613), MDD (0.589), and AFN (0.596)
- At least 5,000 synthetic images are required for optimal performance
- Using pseudo-labels during training improves results by 0.015 accuracy points compared to Fashion CUT without pseudo-labels
- The method preserves pattern labels during translation while producing realistic images

## Why This Works (Mechanism)

### Mechanism 1
Jointly training a generative image translation model with a classifier enforces label consistency and improves domain adaptation performance. The generator (CUT) translates synthetic images to realistic ones, while the classifier (ResNet50) enforces that the translated images preserve the original pattern class. This dual optimization ensures that the synthetic data remains informative for the classifier after domain adaptation.

### Mechanism 2
Using pseudo-labels from the classifier during training improves generalization to real-world data by reducing synthetic bias. In later stages of training, real-world images are included with pseudo-labels predicted by the classifier, helping the model learn to generalize to real-world data distributions.

### Mechanism 3
Using an unpaired image translation method (CUT) allows effective domain adaptation without requiring paired synthetic-real image data. CUT learns to translate unpaired images from the synthetic domain to the real domain using contrastive learning on patches, avoiding the need for expensive paired data collection.

- Component map:
  Generator (CUT) -> Realistic images + Classifier -> Pseudo-labeled real images -> Improved classifier

- Critical path: Synthetic images → Generator → Realistic images + Classifier → Pseudo-labeled real images → Improved classifier

- Design tradeoffs:
  - Memory efficiency: CUT uses less memory than CycleGAN, enabling joint training
  - Translation quality vs. label preservation: Balancing generator and classifier losses
  - Pseudo-label timing: When to introduce real-world pseudo-labels during training

- Failure signatures:
  - Generator produces unrealistic images (check discriminator loss)
  - Classifier fails to preserve patterns (check classification accuracy on translated images)
  - Pseudo-labels are inaccurate (check classifier confidence on real images)

## Limitations

- Single dataset evaluation limits generalizability across different fashion domains or pattern types
- Performance improvements over baselines are modest (0.628 vs 0.613 accuracy)
- Optimal pseudo-label timing is determined empirically without theoretical justification
- Minimum synthetic data threshold of 5,000 images may vary with different pattern complexities

## Confidence

- High confidence in the core methodology and experimental setup
- Medium confidence in the generalizability of results across different datasets
- Medium confidence in the claimed performance improvements over baselines
