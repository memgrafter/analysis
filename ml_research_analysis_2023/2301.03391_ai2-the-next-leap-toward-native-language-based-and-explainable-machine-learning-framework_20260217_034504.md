# AI2: The next leap toward native language based and explainable machine learning framework

## Quick Facts
- arXiv ID: 2301.03391
- Source URL: https://arxiv.org/abs/2301.03391
- Reference count: 40
- Primary result: Novel ML framework with natural language interface enabling non-experts to interact with ML algorithms using English commands

## Executive Summary
AI2 is a novel machine learning framework that introduces a natural language interface, allowing users to interact with ML algorithms using English commands. The framework integrates four key modules: preprocessing, machine learning algorithms, greenhouse gas awareness, and explainability. By combining these elements, AI2 addresses accessibility challenges for non-experts while promoting ethical AI development through environmental consciousness and transparent decision-making processes.

## Method Summary
AI2 implements a comprehensive ML framework with a BERT-based chatbot for natural language command processing, preprocessing capabilities for dataset configuration, and integration of various ML algorithms (classification, regression, clustering, etc.). The framework incorporates CodeCarbon library for GHG monitoring and employs clustering algorithms to suggest energy-efficient alternatives. Explainability is achieved through systematic generation of graphics, tables, and LaTeX-formatted texts for ML results.

## Key Results
- Successfully demonstrates five use cases validating framework effectiveness
- Achieves accurate GHG prediction and alternative suggestion capabilities
- Provides comprehensive explanations for ML results through multiple visualization formats

- Core assumption: The BERT model can accurately parse user intent and extract relevant information from English commands.

### Mechanism 2
- Claim: AI2's GHG awareness module predicts carbon emissions and suggests alternatives to reduce environmental impact.
- Mechanism: The framework integrates CodeCarbon library functions, uses historical data to train an MLP for GHG prediction, and employs k-means clustering to group similar requests and suggest alternatives.
- Core assumption: Historical data can accurately predict future GHG emissions for machine learning algorithms.
- Evidence anchors:
  - [abstract] "The second contribution is greenhouse gas (GHG) awareness. It has some strategies to evaluate the GHG generated by the algorithm to be called and to propose alternatives..."
  - [section] "Based on the CodeCarbon library [22], those functions compute the generated GHG for each request."
  - [corpus] Weak evidence - corpus papers don't discuss GHG awareness in machine learning frameworks.
- Break condition: If the GHG prediction model is inaccurate or the clustering of similar requests fails to identify truly equivalent alternatives, the framework's environmental impact reduction efforts would be ineffective.

### Mechanism 3
- Claim: AI2's explainability module systematically provides detailed explanations for machine learning results.
- Mechanism: The framework generates graphics, tables, and LaTeX-formatted texts for each algorithm's results, addressing the "black box" problem in machine learning.
- Core assumption: Visual and textual explanations can effectively communicate complex machine learning processes to users.
- Evidence anchors:
  - [abstract] "The last contribution of this paper is about explainability... The proposed framework explains the algorithm's process with the proper texts, graphics and tables."

## Architecture Onboarding

- Component map:
  - NLP Interface (BERT-based chatbot) -> Preprocessing Module -> Machine Learning Algorithms (Supervised and Unsupervised) -> GHG Awareness Module (CodeCarbon integration) -> Explainability Module -> Parameters.csv file for command parsing

- Critical path: User command → NLP parsing → Parameter extraction → Algorithm execution → Result generation → Explanation creation

- Design tradeoffs:
  - NLP accuracy vs. user flexibility in command structure
  - GHG prediction accuracy vs. computational overhead
  - Explanation detail vs. performance impact

- Failure signatures:
  - NLP parsing errors leading to incorrect parameter extraction
  - Inaccurate GHG predictions resulting in unnecessary algorithm executions
  - Overly complex or insufficient explanations failing to address user needs
