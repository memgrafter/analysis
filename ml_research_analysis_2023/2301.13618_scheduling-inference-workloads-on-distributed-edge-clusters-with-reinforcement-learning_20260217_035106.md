# Scheduling Inference Workloads on Distributed Edge Clusters with Reinforcement Learning

## Quick Facts
- arXiv ID: 2301.13618
- Source URL: https://arxiv.org/abs/2301.13618
- Reference count: 38
- Key outcome: RL-based scheduling algorithm ASET achieves up to 30% higher query success rates compared to static approaches in distributed edge environments

## Executive Summary
This paper presents ASET, a reinforcement learning-based scheduling algorithm designed to optimize inference workloads across distributed edge computing clusters. The algorithm addresses the challenge of efficiently allocating heterogeneous inference queries to edge resources while satisfying application-specific constraints on latency, accuracy, and throughput. By leveraging Deep Q-Learning, ASET dynamically adapts scheduling policies based on real-time system conditions and network topology, offering significant improvements over traditional static scheduling approaches in distributed edge environments.

## Method Summary
ASET employs reinforcement learning to learn optimal scheduling policies for inference workloads in distributed edge computing environments. The algorithm uses Deep Q-Learning to train an agent that selects scheduling actions based on the current state of the system, which includes network conditions, resource availability, and workload characteristics. The learning process optimizes for query success rates while considering constraints such as latency, accuracy requirements, and throughput targets. The trained model can then dynamically adapt to changing conditions in real-time, making intelligent decisions about where to place inference queries across the distributed edge infrastructure.

## Key Results
- ASET achieves up to 30% higher query success rates compared to static scheduling policies
- The algorithm demonstrates strong adaptability to varying network topologies and workload patterns
- Performance improvements are most pronounced when resources are distributed across the edge network

## Why This Works (Mechanism)
ASET works by learning to map complex system states to optimal scheduling decisions through reinforcement learning. The Deep Q-Learning approach enables the agent to capture non-linear relationships between system conditions and scheduling outcomes that would be difficult to model with traditional heuristic approaches. By training on realistic network topologies and diverse workload patterns, the algorithm develops a nuanced understanding of how different scheduling decisions affect query success rates under varying conditions.

## Architecture Onboarding

Component map: Edge nodes -> Network layer -> RL scheduler -> Workload dispatcher -> Application layer

Critical path: Application generates inference query → Network layer reports conditions → RL scheduler evaluates state → Scheduling decision made → Query dispatched to selected edge node → Result returned

Design tradeoffs: The paper trades off computational overhead of running the RL model against scheduling performance gains; while the RL approach adds latency for decision-making, this is offset by better resource utilization and higher success rates

Failure signatures: Performance degradation occurs when network conditions change faster than the RL model can adapt; suboptimal scheduling decisions when encountering workload patterns not seen during training

## Limitations
- Evaluation relies on simulated environments rather than real-world deployments, raising questions about real-world applicability
- Focus is limited to inference workloads without addressing training or hybrid workload scenarios
- Comparison is limited to static scheduling policies without benchmarking against other adaptive approaches
