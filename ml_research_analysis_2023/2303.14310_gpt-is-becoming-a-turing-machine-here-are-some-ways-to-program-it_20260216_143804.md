# GPT is becoming a Turing machine: Here are some ways to program it

## Quick Facts
- arXiv ID: 2303.14310
- Source URL: https://arxiv.org/abs/2303.14310
- Reference count: 23
- Key outcome: GPT-3 can execute iterative algorithms like Bubble Sort and dynamic programming through structured prompts that regiment self-attention, leading to large accuracy gains over standard prompting

## Executive Summary
This paper demonstrates that Large Language Models (LLMs) like GPT-3 can be triggered to execute iterative algorithms through careful prompt design. The technique, called Iteration by Regimenting Self-Attention (IRSA), uses highly structured prompts that show execution paths for one example, enabling the model to unroll loops and produce correct outputs for new inputs. This approach leads to significant accuracy improvements over standard prompting methods and even outperforms GPT-4 on certain algorithmic tasks.

## Method Summary
The authors developed IRSA by creating prompts that regiment the self-attention mechanism of LLMs. They provided highly structured examples showing complete execution paths for one input, then tested whether the model could generalize this pattern to new inputs. The technique involves fragmenting prompts and forcing skip-to-state attention patterns to improve performance on iterative algorithms like Bubble Sort and dynamic programming problems.

## Key Results
- IRSA leads to large accuracy gains over standard prompting for algorithmic tasks
- The technique outperforms GPT-4 on certain specific tasks despite using GPT-3
- Fragmented prompts and forced skip-to-state attention further improve performance
- LLMs can be disciplined to execute arbitrary code through careful prompt engineering

## Why This Works (Mechanism)
The mechanism relies on structuring prompts to guide the LLM's self-attention in a way that mimics algorithmic execution. By showing complete execution traces for one example, the model learns to follow similar attention patterns for new inputs. The regimented self-attention forces the model to maintain and update state information across multiple steps, effectively unrolling loops and executing iterative processes.

## Architecture Onboarding

**Component Map:** Prompt structure -> Self-attention pattern -> State maintenance -> Output generation

**Critical Path:** Structured prompt design → Attention pattern regularization → State tracking across steps → Correct algorithmic output

**Design Tradeoffs:** Structured prompts require more engineering effort but yield better performance; simpler prompts are easier to create but less effective

**Failure Signatures:** Incorrect attention patterns leading to wrong state updates; inability to maintain context across multiple steps; overfitting to specific examples
