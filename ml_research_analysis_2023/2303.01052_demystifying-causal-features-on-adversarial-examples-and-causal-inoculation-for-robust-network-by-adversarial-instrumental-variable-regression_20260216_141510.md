# Demystifying Causal Features on Adversarial Examples and Causal Inoculation for Robust Network by Adversarial Instrumental Variable Regression

## Quick Facts
- arXiv ID: 2303.01052
- Source URL: https://arxiv.org/abs/2303.01052
- Reference count: 40
- This paper proposes a causal perspective using adversarial instrumental variable (IV) regression to estimate causal relations of adversarial prediction under an unbiased environment dissociated from unknown confounders, achieving up to 2.9% improvement over state-of-the-art defense baselines on CIFAR-10, SVHN, and Tiny-ImageNet datasets.

## Executive Summary
This paper addresses the fundamental challenge of understanding why deep neural networks are vulnerable to adversarial examples by taking a causal perspective. The authors propose a novel method that uses adversarial instrumental variable regression to estimate causal features on adversarial examples while eliminating spurious correlations from unknown confounders. By leveraging a zero-sum optimization game between a hypothesis model and worst-case counterfactuals, the approach discovers features that are genuinely causal to correct prediction rather than spuriously correlated. The paper also presents a causal inoculation technique that transfers these learned causal features into defense networks, demonstrating significant improvements in adversarial robustness across multiple datasets and network architectures.

## Method Summary
The approach consists of two main components: adversarial instrumental variable regression for causal feature discovery and causal inoculation for defense network improvement. The method first extracts feature variations between natural and adversarial examples, then uses these as instruments in a zero-sum game between a hypothesis model and test function to estimate causal features. These causal features are then inverted back to the input domain and used as a regularizer during defense network training. The entire process is formulated as a combination of empirical risk minimization with a causal regularizer that minimizes the KL divergence between causal and adversarial features, resulting in networks that are more robust to adversarial attacks.

## Key Results
- Causal features estimated through adversarial IV regression show high correlation with correct prediction for adversarial robustness
- Counterfactuals generated by the test function exhibit extreme features significantly deviating from correct prediction
- Causal inoculation (CAFE) achieves up to 2.9% improvement over state-of-the-art defense baselines on CIFAR-10, SVHN, and Tiny-ImageNet datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Instrumental variable (IV) regression eliminates spurious correlation from unknown confounders in adversarial feature learning.
- Mechanism: By using feature variation (Z) as an instrument that is causally linked to adversarial features (T) but not directly to outcomes (Y), the backdoor path created by unknown confounders is blocked. This allows the hypothesis model to estimate causal features on adversarial examples without bias from confounding factors.
- Core assumption: The feature variation Z satisfies the three IV conditions: relevance (Z influences T), exclusion restriction (Z does not directly affect Y), and unconfoundedness (Z is independent of the outcome error).
- Evidence anchors:
  - [abstract] The paper proposes "adversarial instrumental variable (IV) regression" to estimate the "causal relation of adversarial prediction under an unbiased environment dissociated from unknown confounders."
  - [section] The authors verify that feature variation satisfies the IV conditions empirically: relevance through high correlation between Z and T, exclusion restriction by showing Z alone has no predictive power, and unconfoundedness through adversarial training.
- Break condition: If the feature variation Z becomes correlated with the outcome error (e.g., if adversarial perturbation patterns leak target information), the IV assumptions break down and spurious correlation re-enters the estimation.

### Mechanism 2
- Claim: The zero-sum game between hypothesis model and test function enables robust causal feature discovery under worst-case perturbations.
- Mechanism: The hypothesis model (h) tries to extract causal features that maintain correct prediction under adversarial attacks, while the test function (g) generates worst-case counterfactuals that maximize the moment restriction violation. This adversarial setup forces the hypothesis model to find features that are genuinely causal rather than spuriously correlated.
- Core assumption: The test function can generate counterfactuals that represent the complete space of adversarial perturbations, allowing the hypothesis model to learn features robust to any attack within the feature bounds.
- Evidence anchors:
  - [abstract] The approach "leverages a zero-sum optimization game between a casual feature estimator (i.e., hypothesis model) and worst-case counterfactuals (i.e., test function) disturbing to find causal features."
  - [section] The paper demonstrates that adversarial causal features (AC) show significantly better robustness than adversarial features (Adv) across multiple attack types, validating that the game-based learning approach finds genuinely robust features.
- Break condition: If the test function cannot explore the full space of adversarial perturbations (e.g., limited by architectural constraints or training data), the hypothesis model may overfit to specific attack patterns rather than learning truly causal features.

### Mechanism 3
- Claim: Causal inoculation via feature inversion transfers learned causal features to improve defense network robustness.
- Mechanism: The causal inversion technique maps estimated causal features back to the input domain while preserving their causal properties, then uses these inverted features as a regularizer to train defense networks. This ensures that the learned weights are biased toward features that are causally related to correct prediction rather than spurious correlations.
- Core assumption: The causal inversion can accurately reconstruct inputs that preserve the causal feature properties without introducing new vulnerabilities or losing essential information.
- Evidence anchors:
  - [abstract] The paper presents "how to effectively inoculate CAusal FEatures (CAFE) into defense networks for improving adversarial robustness" with up to 2.9% improvement over state-of-the-art defenses.
  - [section] The causal inoculation is formulated as an empirical risk minimization problem with a causal regularizer that minimizes the KL divergence between causal features and adversarial features.
- Break condition: If the causal inversion process introduces significant information loss or distortion, the inoculated features may not effectively transfer the causal properties, limiting the defense improvement.

## Architecture Onboarding

- Component map: Natural input X and adversarial example Xϵ → Feature extractor fl → Intermediate features (Fnatural, Fadv) → Feature variation calculator Z = Fadv - Fnatural → Hypothesis model h and test function g (zero-sum game) → Causal feature estimator h(Z) → Causal inversion module → Defense network trainer with CAFE
- Critical path: Natural input → Feature variation → Zero-sum game (h,g) → Causal features → Causal inversion → Defense network
  - The most critical path is from feature variation through the zero-sum game to causal features, as this determines the quality of the causal features that drive all downstream improvements
- Design tradeoffs:
  - Using higher-level features for causal estimation provides more semantic information but may be less robust to perturbations
  - More complex test functions can explore larger counterfactual spaces but increase computational cost and risk of overfitting
  - Causal inversion precision versus computational efficiency: more accurate inversion improves defense but requires more optimization iterations
- Failure signatures:
  - Poor adversarial robustness improvement indicates the causal features may not be capturing genuine causal relationships
  - High variance in Rademacher distance across runs suggests instability in the zero-sum game equilibrium
  - Semantic inconsistency in feature visualization indicates the causal features may be learning spurious patterns
- First 3 experiments:
  1. Verify IV conditions: Measure correlation between feature variation Z and adversarial features T, test that Z alone has no predictive power, and confirm adversarial training independence
  2. Validate zero-sum game dynamics: Plot adversarial robustness of CC vs CF features across training epochs to ensure the hypothesis model is learning causal features
  3. Test causal inversion quality: Compare KL divergence between causal features and their inversions under different perturbation budgets to find the optimal balance between preservation and imperceptibility

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do causal features on adversarial examples generalize across different network architectures and dataset complexities?
- Basis in paper: [explicit] The paper mentions evaluating the approach on CIFAR-10, SVHN, and Tiny-ImageNet with VGG-16, ResNet-18, and WideResNet-34-10 architectures.
- Why unresolved: While the paper shows improvements in adversarial robustness across these datasets and architectures, the underlying mechanisms by which causal features contribute to robustness across varying model complexities and data distributions are not fully explained.
- What evidence would resolve it: A systematic study varying network depth, width, and dataset size while measuring causal feature consistency and robustness impact.

### Open Question 2
- Question: What is the precise relationship between the estimated causal features and the network's internal feature representations at different layers?
- Basis in paper: [explicit] The paper analyzes feature representations at the last convolutional layer and mentions the high-level object concepts present there, but does not fully explore the causal feature relationships across multiple layers.
- Why unresolved: The paper focuses on causal features at a specific layer without examining how these features relate to representations at other layers or how this relationship affects overall network robustness.
- What evidence would resolve it: Layer-wise analysis of causal feature propagation and its correlation with robustness across different network depths.

### Open Question 3
- Question: How do the adversarial instrumental variable regression method and causal inoculation approach scale to larger, more diverse datasets and real-world applications?
- Basis in paper: [inferred] The paper demonstrates effectiveness on three datasets but does not explore scalability or real-world deployment challenges.
- Why unresolved: The computational complexity of the adversarial instrumental variable regression method and the practical feasibility of implementing causal inoculation in large-scale systems are not addressed.
- What evidence would resolve it: Empirical studies on larger datasets, real-world scenarios, and performance comparisons with state-of-the-art methods under resource constraints.

## Limitations
- The validity of instrumental variable assumptions in real-world adversarial settings remains empirically uncertain, particularly regarding unconfoundedness of feature variation
- The causal inversion method's ability to perfectly preserve causal properties during reconstruction is not fully verified
- The approach's scalability to larger, more complex architectures and datasets beyond CIFAR-10, SVHN, and Tiny-ImageNet is untested

## Confidence
- High confidence in the mathematical formulation of adversarial IV regression and zero-sum game optimization
- Medium confidence in the empirical validation of IV conditions and causal feature quality
- Low confidence in the generalizability of causal inoculation results to diverse network architectures and attack scenarios
