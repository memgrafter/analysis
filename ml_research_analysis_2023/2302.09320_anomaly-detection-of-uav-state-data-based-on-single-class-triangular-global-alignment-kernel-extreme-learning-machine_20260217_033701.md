# Anomaly Detection of UAV State Data Based on Single-class Triangular Global Alignment Kernel Extreme Learning Machine

## Quick Facts
- arXiv ID: 2302.09320
- Source URL: https://arxiv.org/abs/2302.09320

## Executive Summary
This study addresses the challenge of detecting anomalous data in unmanned aerial vehicles (UAVs) to enhance their safety. The authors propose a novel anomaly detection strategy called FastICA-TGAK-OCELM, which combines Fast Independent Component Analysis (FastICA) for data reconstruction, Triangular Global Alignment Kernel (TGAK) for improved kernel function, and One-Class Extreme Learning Machine (OCELM) for anomaly detection. The method was validated on both UCI and Aeronautical Laboratory Failures and Anomalies (ALFA) datasets. Results show that the proposed approach achieves more than 30% improvement in accuracy compared to other methods and effectively detects point anomalies. The FastICA-TGAK-OCELM method demonstrates superior performance in detecting UAV anomalies across different fault types, significantly improving drone safety.

## Method Summary
The FastICA-TGAK-OCELM method combines three key components: FastICA for independent component analysis-based data reconstruction, TGAK as a kernel function replacement for improved computational efficiency and performance, and OCELM for one-class anomaly detection. The approach uses normal UAV flight data to train the model without requiring labeled anomalies. FastICA decorrelates mixed sensor signals to reveal underlying failure modes, while TGAK provides a positive definite kernel function that focuses on diagonal alignment paths. OCELM then learns decision boundaries from the processed data to detect anomalies in test instances.

## Key Results
- FastICA-TGAK-OCELM achieves more than 30% improvement in accuracy compared to other methods
- The method effectively detects point anomalies in UAV sensor data
- Superior performance across different fault types in the ALFA dataset
- Demonstrated effectiveness on both UCI and ALFA datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Replacing the RBF kernel with TGAK in OCKELM improves anomaly detection accuracy.
- Mechanism: TGAK incorporates triangular constraints that focus similarity calculations on the diagonal region of the kernel matrix, reducing noise from irrelevant alignment paths while preserving positive semi-definiteness required by Mercer's theorem.
- Core assumption: The UAV sensor data exhibits local temporal alignment that benefits from triangular weighting rather than global DTW alignment.
- Evidence anchors:
  - [abstract] "To improve the performance of OCKELM, we choose a Triangular Global Alignment Kernel (TGAK) instead of an RBF Kernel..."
  - [section 3.1] "TGAK is not only positive definite; it is faster to compute than GAK."
  - [corpus] Weak - no direct corpus matches for TGAK in UAV context.
- Break condition: If UAV data lacks clear temporal alignment structure, TGAK's diagonal focus may discard useful global patterns.

### Mechanism 2
- Claim: FastICA reconstruction enhances feature separability for anomaly detection.
- Mechanism: FastICA performs independent component analysis to decorrelate mixed sensor signals, producing statistically independent components that reveal underlying failure modes not visible in raw measurements.
- Core assumption: UAV sensor measurements are linear or near-linear mixtures of independent physical processes, and independent components correspond to meaningful failure signatures.
- Evidence anchors:
  - [abstract] "...introduce the Fast Independent Component Analysis (FastICA) algorithm to reconstruct UAV data."
  - [section 3.2] "FastICA algorithm maximizes the non-Gaussian property of the vector 𝒘#𝒙..."
  - [corpus] Weak - corpus contains no FastICA-specific UAV applications.
- Break condition: If sensor data is highly nonlinear or the mixing matrix is poorly conditioned, FastICA may produce unstable or non-interpretable components.

### Mechanism 3
- Claim: One-class ELM avoids overfitting to limited abnormal samples while maintaining fast inference.
- Mechanism: OCKELM uses random hidden layer weights with analytical output weight calculation, eliminating iterative training while learning boundaries from normal data only.
- Core assumption: Normal UAV flight states form a compact, convex-like region in feature space, while anomalies lie outside this region.
- Evidence anchors:
  - [abstract] "We deployed a one-class kernel extreme learning machine (OCKELM) to detect anomalies in drone data."
  - [section 3.1] "As a single-class classifier, OCKELM has the same function as OCSVM and autoencoder, and uses normal data to train the model. But the advantage of OCKELM is that for the weight, it does not need to be iteratively calculated..."
  - [corpus] Weak - corpus lacks direct ELM-based UAV anomaly detection comparisons.
- Break condition: If normal data distribution is highly multimodal or contains overlapping regions, single-class boundaries may include abnormal patterns.

## Architecture Onboarding

- Component map: Raw UAV sensor data → FastICA preprocessing → TGAK kernel matrix → OCKELM training → Anomaly scoring → Decision output
- Critical path: FastICA reconstruction → TGAK kernel computation → OCKELM boundary training → Test instance kernel evaluation → Threshold comparison
- Design tradeoffs: TGAK provides computational efficiency but may lose global alignment information; FastICA adds preprocessing overhead but can improve detection accuracy; OCKELM offers fast inference but may struggle with complex multi-modal normal distributions
- Failure signatures: Degraded accuracy on datasets with non-temporal features, poor performance when normal data has large variance, instability with small training sets
