# Everybody Compose: Deep Beats To Music

## Quick Facts
- arXiv ID: 2306.06284
- Source URL: https://arxiv.org/abs/2306.06284
- Reference count: 18
- Primary result: Novel approach to generate monophonic melodies from input beats using four deep learning models, achieving validation accuracies of 37.97%-50.77%

## Executive Summary
This paper introduces a novel approach to music generation where monophonic melodies are created from input beats using deep learning models. The authors propose three methods: LSTM with Full Attention, LSTM with Local Attention, and Transformer with Relative Position Representation, along with a baseline Decoder-Only Vanilla RNN. These models enable amateurs and professionals to compose music by tapping keyboards or "recoloring" beat sequences from existing works. The models are trained on the MAESTRO dataset and achieve validation accuracies ranging from 37.97% to 50.77%, with the LSTM with Local Attention model performing best overall.

## Method Summary
The paper presents four neural network architectures for generating monophonic melodies from input beats: a baseline Decoder-Only RNN, LSTM with Full Attention, LSTM with Local Attention, and Transformer with Relative Position Representation. The models are trained on the MAESTRO dataset, where beats are represented as (rest time, note duration) tuples and notes as pitches. A hybrid beam search algorithm combines stochastic sampling with beam search modes to balance creativity and likelihood maximization. The generated melodies are evaluated on validation accuracy and qualitative musical quality measures including variation, harmony, and long-term coherence.

## Key Results
- LSTM with Local Attention achieves the highest overall musical quality among all models
- Validation accuracies range from 37.97% to 50.77% across the four models
- The proposed approach enables music composition through keyboard input or beat sequence modification
- Relative position representation in the Transformer improves long-range coherence

## Why This Works (Mechanism)

### Mechanism 1: Local Attention for Beat-Note Correspondence
The LSTM with Local Attention model achieves optimal musical quality by establishing a one-to-one correspondence between beats and notes. The bidirectional LSTM encoder creates a context sequence where each timestep's hidden state directly corresponds to the same timestep in input beats. The decoder initializes its hidden state with the final encoder state, maintaining awareness of overall beat structure while focusing on local context. This approach works because beats and notes have a strong one-to-one relationship, unlike machine translation where target words may correspond to different positions in source words.

### Mechanism 2: Relative Position Representation in Transformers
The Transformer model with relative position representation improves long-range coherence by learning pairwise relationships between notes based on their relative distances rather than absolute positions. Instead of using absolute sinusoidal positional encodings, the model learns separate relative position embeddings for each possible pairwise distance, separately for each attention head. This allows the model to capture musical relationships based on how notes relate to each other temporally rather than their absolute positions in the sequence.

### Mechanism 3: Hybrid Beam Search for Balanced Generation
The hybrid beam search algorithm balances creativity and likelihood maximization by alternating between beam mode (selecting top N sequences based on likelihood) and stochastic mode (randomly sampling from the distribution with heuristics). This approach combines the high-quality sequences from beam search with the creative variations from stochastic sampling, addressing the limitations of both pure approaches - beam search being too predictable and random sampling producing too low-quality results.

## Architecture Onboarding

- **Component map**: MIDI file conversion -> Note interval representation -> Model training -> Sampling algorithm -> MIDI generation
- **Critical path**: 1) Load and preprocess MAESTRO dataset (convert MIDI to note intervals, apply melody inference) 2) Train one of four model architectures on processed data 3) Use trained model with sampling algorithms to generate melodies from user-inputted beats 4) Convert generated notes to MIDI format and play using SuperCollider
- **Design tradeoffs**: Model complexity vs. training time (Transformers require more compute but capture long-range dependencies better), attention type (full attention captures more context but is computationally expensive; local attention is efficient but may miss some dependencies), sampling method (beam search produces high-likelihood sequences but may lack creativity; stochastic sampling adds variety but may produce lower-quality results)
- **Failure signatures**: Model convergence issues (check learning rate and embedding dimensions if training/validation accuracy plateaus early), poor musical quality (adjust sampling hyperparameters like temperature, top-p, repeat decay if generated melodies lack harmony or structure), long training times (consider reducing sequence length or using simpler architecture if models take too long to train)
- **First 3 experiments**: 1) Train baseline decoder-only RNN on small MAESTRO subset and evaluate ability to generate simple melodies from basic beat patterns 2) Implement and test LSTM with Local Attention model, comparing performance to baseline on same dataset 3) Add relative position representation to Transformer model and evaluate whether it improves long-range coherence compared to absolute position version

## Open Questions the Paper Calls Out

- How does the quality of generated melodies vary across different musical genres beyond Classical, given the model was trained exclusively on the MAESTRO dataset?
- What is the impact of extending the model output space from notes to chords on the variation and diversity of generated music?
- How do different sampling heuristics (top-p, top-k, temperature, repeat decay) individually and collectively affect the quality and creativity of generated melodies?

## Limitations

- The study relies on subjective assessment of musical quality rather than standardized quantitative metrics beyond validation accuracy
- The model's performance is only evaluated on the piano-centric MAESTRO dataset, limiting generalizability to other musical genres and instruments
- The paper lacks empirical validation comparing the hybrid sampling algorithm to pure beam search or pure stochastic approaches

## Confidence

- **High Confidence**: Technical implementation of LSTM and Transformer architectures with attention mechanisms is well-established and correctly described
- **Medium Confidence**: Claim about relative position representation improving long-range coherence is supported by architectural description but lacks comparative experiments
- **Low Confidence**: Assertion that hybrid sampling algorithm meaningfully balances creativity and likelihood is not empirically validated against alternative approaches

## Next Checks

1. Implement standardized metrics for evaluating generated music (inter-onset intervals, pitch class distribution, harmonic complexity) to complement validation accuracy and provide objective measures of musical quality
2. Train a version of the Transformer model with absolute positional encoding and compare its performance to the relative position version on both validation accuracy and musical quality metrics
3. Evaluate all models on multiple musical genres beyond classical piano (jazz, pop, electronic) to assess whether claimed performance advantages hold across diverse musical styles and whether the one-to-one beat-note correspondence assumption remains valid
