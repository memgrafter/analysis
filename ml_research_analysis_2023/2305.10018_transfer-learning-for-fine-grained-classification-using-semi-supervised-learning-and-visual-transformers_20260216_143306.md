# Transfer Learning for Fine-grained Classification Using Semi-supervised Learning and Visual Transformers

## Quick Facts
- arXiv ID: 2305.10018
- Source URL: https://arxiv.org/abs/2305.10018
- Reference count: 40
- Key outcome: Semi-ViT significantly outperforms ResNet and ViT on fine-grained e-commerce classification, especially with limited labeled data

## Executive Summary
This paper explores the use of semi-supervised learning with visual transformers for fine-grained classification of e-commerce data. The authors collect three datasets with labeled and unlabeled images for tasks like predicting vest neck style and phone case patterns. They fine-tune a ResNet CNN, a ViT, and a Semi-ViT model on varying amounts of labeled data and compare their performance. The key finding is that Semi-ViT, which leverages semi-supervised learning techniques, significantly outperforms the other models, especially when labeled data is scarce. For example, Semi-ViT with 25% labeled data achieves comparable accuracy to ViT with 50% labeled data. The authors also investigate the effect of increasing unlabeled data on Semi-ViT's performance, finding that up to 300% more unlabeled data improves results, but 400% degrades them.

## Method Summary
The authors fine-tune three models - ResNet18, ViT-Base, and Semi-ViT - on three e-commerce datasets for fine-grained classification tasks. Semi-ViT incorporates semi-supervised learning techniques, including an EMA-Teacher framework and probabilistic pseudo mixup, to leverage both labeled and unlabeled data. The models are trained on varying amounts of labeled data (100%, 75%, 50%, and 25%) and their performance is evaluated on a held-out test set.

## Key Results
- Semi-ViT significantly outperforms ResNet and ViT on all three fine-grained classification tasks
- Semi-ViT with 25% labeled data achieves comparable accuracy to ViT with 50% labeled data
- Increasing unlabeled data up to 300% improves Semi-ViT's performance, but 400% degrades it
