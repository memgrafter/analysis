# Enhancing In-Context Learning with Answer Feedback for Multi-Span Question Answering

## Quick Facts
- arXiv ID: 2306.04508
- Source URL: https://arxiv.org/abs/2306.04508
- Reference count: 36
- Key outcome: FBPrompt significantly improves ChatGPT performance on multi-span question answering tasks, outperforming previous LLM-based methods

## Executive Summary
This paper introduces FBPrompt, a novel prompting strategy that enhances large language models' performance on multi-span question answering (MSQA) tasks by incorporating answer feedback. The method uses an off-the-shelf QA model to generate predictions for demonstration examples, compares these predictions with ground truth answers, and creates structured feedback (correct, incorrect, or missing). This feedback is then integrated into the prompt alongside demonstration examples to guide the LLM's reasoning process. Experiments on three MSQA datasets and one keyphrase extraction dataset demonstrate significant performance improvements, with FBPrompt achieving state-of-the-art results among LLM-based methods.

## Method Summary
FBPrompt enhances in-context learning for MSQA by constructing answer feedback from an off-the-shelf model's predictions on demonstration examples. The process involves retrieving relevant demonstration examples using BM25, generating predictions with a T5-base MSQA model, creating feedback by comparing predictions to ground truth, and constructing an enhanced prompt that combines demonstrations with feedback. This enriched prompt is then fed to an LLM (gpt-3.5-turbo-0301) for inference. The method aims to provide more insightful information than traditional question-answer pair demonstrations, helping LLMs distinguish between correct and incorrect predictions.

## Key Results
- FBPrompt achieves significant improvements in Exact Match F1 and Partial Match F1 scores across three MSQA datasets (MultiSpanQA, QUOREF, DROP)
- The method outperforms previous LLM-based approaches by a large margin, demonstrating the effectiveness of answer feedback in enhancing in-context learning
- Ablation studies show that feedback type and number of demonstration examples significantly impact performance, with the optimal configuration using 3-4 demonstrations with mixed feedback types

## Why This Works (Mechanism)

### Mechanism 1
- Claim: FBPrompt improves LLM performance by providing explicit feedback on demonstration examples, helping the model distinguish between correct and incorrect predictions.
- Mechanism: The method uses an off-the-shelf QA model to generate predictions on demonstration examples, compares them with ground truth answers, and creates feedback indicating which answers are correct, incorrect, or missing. This feedback is then incorporated into the prompt to guide the LLM's reasoning process.
- Core assumption: The LLM can effectively utilize structured feedback about answer quality to improve its in-context learning performance on MSQA tasks.
- Evidence anchors:
  - [abstract] "by extending demonstration examples with feedback about answers predicted by an off-the-shelf model, e.g., correct, incorrect, or incomplete"
  - [section] "we obtain answer feedback by comparing the prediction results on the demonstration example with the labeled answers, and use it to enrich in-context learning with more insightful information obtained from the corrected answers"
- Break condition: If the off-the-shelf model's predictions are too noisy or the LLM cannot effectively process the feedback format, the mechanism would fail to improve performance.

### Mechanism 2
- Claim: The feedback mechanism provides negative examples that help the LLM avoid common mistakes during inference.
- Mechanism: By explicitly showing incorrect answers and missing answers from the off-the-shelf model's predictions, the LLM learns to avoid these specific error patterns when generating its own answers.
- Core assumption: LLMs can learn from negative examples presented in the context, not just from correct demonstrations.
- Evidence anchors:
  - [section] "some works designed methods to improve the performance of LLMs on specific QA tasks... However, as an important and realistic QA task, Multi-Span QA (MSQA) currently lacks dedicated research based on LLMs"
  - [section] "the common practice of constructing a demonstration context is still concatenating questions and labeled answers through simple templates. We argue that only showing demonstration questions with correct answers may not guide LLMs to think deeply about demonstration examples"
- Break condition: If the LLM's attention mechanism cannot effectively distinguish between correct and incorrect feedback examples, or if the negative examples overwhelm the learning process.

### Mechanism 3
- Claim: The structured feedback provides more information than simple question-answer pairs, enabling deeper understanding of the task.
- Mechanism: The feedback categorizes answers into three types (correct, incorrect, missing), providing the LLM with a more complete picture of the answer space and helping it understand not just what to answer but also what not to answer.
- Core assumption: More structured information in the prompt leads to better performance than unstructured information.
- Evidence anchors:
  - [section] "Our Work: In this paper, we propose to enhance in-context learning with diverse information derived from labeled answers to improve their utilization"
  - [section] "the clue generated by LLM often contains mistakes, which also causes some loss of label information, and it is very expensive to interact every demonstration example with LLM"
- Break condition: If the additional structure in the prompt causes information overload or if the LLM cannot effectively process the multiple feedback categories.

## Architecture Onboarding

- Component map:
  Retrieval module (BM25) -> Off-the-shelf QA model (T5-base) -> Feedback generation component -> Prompt construction module -> LLM inference engine (gpt-3.5-turbo-0301)

- Critical path:
  1. Retrieve relevant demonstration examples using BM25
  2. Generate predictions for demonstration examples using off-the-shelf model
  3. Create feedback by comparing predictions to ground truth
  4. Construct enhanced prompt with demonstrations and feedback
  5. Feed prompt to LLM for inference

- Design tradeoffs:
  - Using an off-the-shelf model adds computational overhead but provides valuable feedback
  - The three-category feedback system provides more information but increases prompt complexity
  - BM25 retrieval is simple but may miss semantically relevant examples

- Failure signatures:
  - Poor retrieval quality leading to irrelevant demonstration examples
  - Off-the-shelf model predictions that are too noisy or biased
  - LLM unable to effectively process the feedback format
  - Prompt becoming too long or complex for effective LLM processing

- First 3 experiments:
  1. Compare FBPrompt performance against baseline BM25 on a small subset of data to validate the feedback mechanism
  2. Test different numbers of demonstration examples (1-4) to find the optimal balance
  3. Evaluate the impact of using only one type of feedback (correct, incorrect, or missing) to understand their individual contributions

## Limitations
- The method's performance is heavily dependent on the quality of the off-the-shelf model used for generating feedback, which could introduce errors if the model is not sufficiently accurate
- The paper does not thoroughly investigate how FBPrompt scales with longer documents or more complex question types, potentially limiting its practical applicability
- Evaluation focuses primarily on standard MSQA datasets, leaving questions about performance on real-world, noisy data unaddressed

## Confidence

- **High Confidence**: The core claim that structured feedback improves LLM performance on MSQA tasks is well-supported by experimental results showing consistent improvements across multiple datasets and evaluation metrics.

- **Medium Confidence**: The claim that FBPrompt outperforms previous LLM-based methods by a large margin is supported by ablation studies, but the comparison baseline (BM25-based LLM prompting) may not represent the full state-of-the-art in LLM prompting strategies.

- **Low Confidence**: The paper's assertion that the three-category feedback system is optimal is not thoroughly validated, as the ablation studies focus on the number of demonstrations rather than exploring alternative feedback structures or granularities.
