# FedIL: Federated Incremental Learning from Decentralized Unlabeled Data with Convergence Analysis

## Quick Facts
- arXiv ID: 2302.11823
- Source URL: https://arxiv.org/abs/2302.11823
- Reference count: 38
- Primary result: Achieves 61.31% accuracy on CIFAR10 with only 0.1 label rate using federated semi-supervised learning

## Executive Summary
This paper addresses federated semi-supervised learning (FSSL) where clients have only unlabeled data while the server has a small labeled dataset. The proposed Federated Incremental Learning (FedIL) framework introduces Iterative Similarity Fusion to enforce consistency between server and client predictions, and Incremental Credibility Learning to generate high-quality pseudo-labels incrementally. The method achieves state-of-the-art performance on standard benchmarks while providing theoretical convergence guarantees based on weight difference rather than loss functions.

## Method Summary
FedIL operates in a federated setting where clients perform semi-supervised learning on unlabeled data while the server maintains a labeled dataset. The framework uses KL divergence loss to enforce consistency between server and client predictions on unlabeled data, while clients build credible pseudo-label sets through repeated stable predictions. Weight aggregation uses cosine similarity with normalization to select client updates aligned with the server's learning direction. Convergence is guaranteed when weight update norms decrease monotonically, proven using Banach Fixed Point Theorem.

## Key Results
- Achieves 61.31% accuracy on CIFAR10 with only 0.1 label rate
- Outperforms state-of-the-art FSSL methods across MNIST, CIFAR10, and CIFAR100
- Demonstrates faster convergence through cosine similarity-based weight aggregation
- Shows robustness to non-IID data distributions in federated settings

## Why This Works (Mechanism)

### Mechanism 1
The Incremental Credibility Learning ensures that pseudo-labels are only used when consistently stable across training iterations. Each unlabeled sample is tracked over T consecutive training rounds. If the predicted class remains the same for T times and matches the server's reference prediction, the sample is moved to a pseudo-label set with fixed label. This creates a growing set of high-confidence pseudo-labels that reduce labeling noise.

### Mechanism 2
Cosine Similarity with normalization in weight aggregation accelerates convergence by selecting client updates that align with the server's learning direction. After client training, the server computes the cosine similarity between client and server weight updates, aggregating only those in the same direction. This focuses learning on shared features and reduces divergence.

### Mechanism 3
The Banach Fixed Point Theorem convergence proof ensures that the FedIL system will converge when the weight increment norm decreases monotonically. The theorem shows that if ||∆θ(t)|| decreases over time, the global weight θ'(t) will converge to a fixed point θ*. This replaces loss-based convergence criteria with a weight-difference-based criterion.

  - Why needed: These techniques help the model learn robust features from unlabeled data by enforcing that different views of the same sample have similar representations

## Architecture Onboarding

- **Component map**: Server (labeled data, global model) -> Clients (unlabeled data, local models) -> Server (weight aggregation)
- **Critical path**: Server initializes model → selects clients → broadcasts model → clients train with pseudo-labels → upload weights → server aggregates with cosine similarity → update global model → repeat
- **Design tradeoffs**: Pseudo-label set growth rate vs. training stability; number of clients per round vs. communication efficiency; KL loss weight vs. learning speed
- **Failure signatures**: Accuracy plateaus early (low pseudo-label quality); accuracy fluctuates (inconsistent client updates); very slow convergence (||∆θ(t)|| not decreasing)
- **First 3 experiments**: 1) Run FedIL on MNIST with γ=0.1, track pseudo-label set size and accuracy; 2) Compare FedIL vs. FedAvg with FixMatch on CIFAR10 IID/non-IID; 3) Test FedIL without cosine similarity aggregation

## Open Questions the Paper Calls Out

### Open Question 1
How does FedIL scale to larger datasets like ImageNet compared to smaller datasets like CIFAR-10? The paper mentions future work will investigate this but provides no experimental results.

### Open Question 2
What is the impact of varying the number of clients participating in each training round on convergence and performance? While some analysis is provided, a comprehensive study is needed.

### Open Question 3
How do the choice of threshold τ and count of successive labeling k affect pseudo-label quality and overall performance? The paper uses fixed values but doesn't explore the full parameter space.

## Limitations

- Theoretical convergence relies on assumptions about weight update behavior that may not hold in practice
- Pseudo-label quality thresholds are fixed parameters that may not generalize across datasets
- Limited validation on highly non-IID data distributions where clients have very skewed class distributions

## Confidence

- **High confidence**: Experimental methodology and baseline comparisons are well-specified and reproducible
- **Medium confidence**: Theoretical convergence analysis is mathematically sound but may have limited practical applicability
- **Low confidence**: Generalization to highly non-IID distributions hasn't been thoroughly validated

## Next Checks

1. **Convergence robustness test**: Vary learning rates and client participation rates to empirically verify ||∆θ(t)|| decreases monotonically
2. **Pseudo-label quality validation**: Implement an oracle to compare pseudo-labels against ground truth labels, measuring precision/recall
3. **Non-IID stress test**: Evaluate FedIL on highly skewed data distributions where each client has samples from only 1-2 classes
