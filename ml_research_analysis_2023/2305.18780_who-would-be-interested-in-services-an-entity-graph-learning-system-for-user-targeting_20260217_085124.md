# Who Would be Interested in Services? An Entity Graph Learning System for User Targeting

## Quick Facts
- arXiv ID: 2305.18780
- Source URL: https://arxiv.org/abs/2305.18780
- Reference count: 40
- Primary result: EGL System achieves 97%+ accuracy in entity graph construction and 23% conversion rate improvement

## Executive Summary
This paper presents the EGL System for user targeting, which automatically discovers target users interested in specific services through graph reasoning. The system employs a hybrid online-offline architecture where the offline phase constructs a high-quality entity graph and learns user entity preferences, while the online phase performs real-time reasoning for user targeting. The core innovation is the Three-stage Relation Mining Procedure (TRMP) that includes Candidate Generation, Ranking with an Adaptive Threshold Link Prediction with Contrastive learning (ALPC) model, and an Ensemble stage. Extensive offline experiments demonstrate 97%+ accuracy in entity graph construction, while online A/B testing shows an average 23% improvement in conversion rate and 3x faster execution time compared to baseline methods.

## Method Summary
The EGL System uses a hybrid online-offline architecture to achieve scalable and timely user targeting. In the offline stage, it extracts entity sequences from user behavior logs using BERT-CRF, constructs entity graphs through the Three-stage Relation Mining Procedure (TRMP), and learns user entity preferences. The TRMP consists of Candidate Generation using Skip-gram and BERT for semantic mining, Ranking with the ALPC model that handles score distribution differences through adaptive thresholds and improves negative sampling via contrastive learning, and an Ensemble stage that stabilizes predictions using multi-head attention across weekly models. The online stage then performs real-time user targeting by traversing the entity graph and computing entity score distributions for target users.

## Key Results
- TRMP achieves 97%+ accuracy in entity graph construction
- Online A/B testing demonstrates 23% improvement in conversion rate
- Execution time reduced by 3x compared to baseline
- Successfully deployed in Alipay's production environment

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The hybrid offline-online architecture enables both scalability and timeliness in user targeting.
- Mechanism: Offline phase builds entity graph and user preferences, while online phase performs real-time reasoning using pre-computed data.
- Core assumption: The offline graph construction and user preference computation can be done in advance without losing relevance.
- Evidence anchors:
  - [abstract] "EGL System follows the hybrid online-offline architecture to satisfy the requirements of scalability and timeliness."
  - [section II-A] "The offline stage... focuses on the heavyweight entity graph construction and user entity preference learning"
  - [section II-B] "the online stage... offers the ability of user targeting in real-time based on the entity graph from the offline stage"
- Break condition: If the entity graph becomes stale or user preferences become outdated, the online reasoning would lose accuracy.

### Mechanism 2
- Claim: TRMP's adaptive threshold and contrastive learning tasks improve link prediction accuracy by handling score distribution differences and enhancing negative sampling.
- Mechanism: Adaptive threshold task learns personalized thresholds for each source entity to handle skewed score distributions; contrastive learning task uses semantic information to create better negative samples.
- Core assumption: Different source entities have different score distributions, and semantically similar entities can provide useful negative samples.
- Evidence anchors:
  - [section III-B-2] "Different source entities have different correlated target entities, and the distribution of the predicted correlation scores... is different"
  - [section III-B-2] "we propose a novel link prediction model ALPC to tackle both challenges"
  - [section III-B-2] "our contrastive learning objective is to minimize the following function based on InfoNCE"
- Break condition: If the semantic similarity measure fails to capture meaningful negative samples, or if the adaptive threshold becomes unstable.

### Mechanism 3
- Claim: The ensemble stage with multi-head attention improves stability of entity graph construction by integrating multiple weekly models.
- Mechanism: Multiple ALPC models trained on different weeks are combined using concatenation and multi-head attention to produce stable predictions.
- Core assumption: Weekly fluctuations in data distribution can be mitigated by combining multiple models' representations.
- Evidence anchors:
  - [section III-B-3] "Due to the change in data distribution of upstream data sources... the ranking model ALPC's performance is not stable enough"
  - [section III-B-3] "we add the ensemble stage... to improve the stability of the accuracy"
  - [section III-B-3] "It consists of an embedding extractor, a multi-head attention encoder, and MLP modules"
- Break condition: If the weekly data distributions become too different or if model drift occurs faster than weekly retraining can address.

## Limitations

- The 97%+ accuracy claim for entity graph construction lacks detailed methodology and ground truth dataset specification
- Online A/B testing results showing 23% conversion rate improvement are presented without statistical significance measures or confidence intervals
- System performance heavily depends on entity extraction quality, but paper doesn't provide detailed error analysis for the NER component

## Confidence

- **High confidence**: The hybrid online-offline architecture design and its components (offline graph construction, online real-time reasoning) are well-established patterns in industrial systems. The use of contrastive learning for better negative sampling in link prediction is theoretically sound and aligns with current best practices.

- **Medium confidence**: The claimed accuracy improvements and conversion rate gains are plausible given the sophisticated methodology, but the lack of detailed experimental methodology and statistical validation makes it difficult to fully verify these claims. The ensemble approach using weekly models is a reasonable solution to data distribution shifts.

- **Low confidence**: The specific implementation details of the ALPC model (adaptive threshold mechanism, contrastive learning parameters) are not fully specified, making it difficult to assess whether the implementation achieves the theoretical benefits described.

## Next Checks

1. **Statistical validation of online results**: Request statistical significance testing and confidence intervals for the 23% conversion rate improvement from the online A/B test, including power analysis and p-values.

2. **Entity extraction error analysis**: Examine the false positive and false negative rates of the BERT-CRF entity extractor on a manually labeled sample of user behavior logs to understand error propagation.

3. **Robustness testing**: Conduct cross-validation with different dataset splits and time periods to assess whether the 97%+ accuracy claim holds across different data distributions and whether the ensemble stage truly stabilizes performance.
