# Debiased Contrastive Learning for Sequential Recommendation

## Quick Facts
- arXiv ID: 2303.11780
- Source URL: https://arxiv.org/abs/2303.11780
- Reference count: 40
- This paper proposes DCRec, a debiased contrastive learning framework for sequential recommendation that addresses the popularity bias problem in existing contrastive learning methods.

## Executive Summary
This paper introduces DCRec, a novel debiased contrastive learning framework designed to address popularity bias in sequential recommendation systems. The core innovation lies in disentangling user conformity from genuine interests through a multi-channel conformity weighting network that adaptively adjusts the regularization strength based on interaction-level conformity. By unifying sequential and collaborative views while incorporating adaptive contrastive learning with KL-regularized conformity distributions, DCRec demonstrates significant improvements over state-of-the-art methods, particularly for cold-start users and sparse items.

## Method Summary
DCRec employs a debiased contrastive learning framework that addresses popularity bias through interaction-level conformity weighting. The method constructs both item transition and co-interaction graphs, encodes them using Transformer and GNN encoders respectively, and computes conformity weights via a multi-channel network. These weights are normalized using KL divergence loss and used to adaptively scale the contrastive loss. The framework is trained using a multi-task approach that combines recommendation loss with self-supervised contrastive losses, with experiments conducted on four real-world datasets showing up to 10.29% relative improvement in HR@1.

## Key Results
- DCRec significantly outperforms state-of-the-art sequential recommendation methods, achieving up to 10.29% relative improvement in HR@1 on the Sports dataset.
- The method demonstrates effectiveness on cold-start users and sparse items, addressing key challenges in real-world recommendation systems.
- Experiments on four real-world datasets (Reddit, Beauty, Sports, Movielens-20M) validate the framework's robustness across different data characteristics.

- Claim: DCRec disentangles user conformity from genuine interest to improve contrastive learning.
- Mechanism: The model computes interaction-level conformity weights using a multi-channel network that considers user-specific influence, consistency with other users, and subgraph isomorphism. These weights are then used to adaptively scale the contrastive loss.
- Core assumption: Conformity can be estimated at the interaction level and that weighting contrastive samples by conformity reduces popularity bias.

### Mechanism 2
- Claim: Unifying sequential and collaborative views improves representation learning for sparse data.
- Mechanism: DCRec constructs both an item transition graph and a co-interaction graph, then uses graph neural networks to encode item embeddings from both views. These are contrasted with sequential encoder outputs.
- Core assumption: Global collaborative signals can compensate for sparsity in individual sequences and improve item representations.
- Evidence anchors:
  - [abstract] "Our debiased contrastive learning framework effectively captures both the patterns of item transitions within sequences and the dependencies between users across sequences"

## Architecture Onboarding

- Component map:
  - Sequential Pattern Encoder (Transformer) -> Graph Neural Network Encoder (for item transition and co-interaction graphs) -> Multi-Channel Conformity Weighting Network -> Adaptive Cross-View Contrastive Learning Module -> Attentive View Aggregation Layer

- Critical path:
  1. Build graphs from user sequences
  2. Encode views via Transformer and GNN
  3. Compute conformity weights
  4. Apply adaptive contrastive learning
  5. Aggregate views and predict next item

- Design tradeoffs:
  - Graph density vs. noise: Top-k filtering in co-interaction graph balances signal quality
  - Conformity regularization vs. flexibility: KL divergence constrains but stabilizes weighting
  - Parallel vs. sequential encoding: Allows speed-up but requires careful synchronization

- Failure signatures:
  - Poor performance on sparse datasets: Graph construction fails to capture meaningful relations
  - Degraded performance when removing adaptive weighting: Conformity estimation inaccurate
  - Instability during training: KL regularization too weak or too strong

## Open Questions the Paper Calls Out

The paper identifies several key limitations that remain open questions:

1. How the proposed multi-channel conformity weighting network handles cases where user conformity and real interest are highly entangled, making it difficult to disentangle the two. The paper acknowledges this challenge but doesn't provide detailed explanation of how the network handles high entanglement scenarios.

2. How the proposed method performs on extremely sparse datasets where the number of interactions per user is very low. While the paper mentions effectiveness for cold-start users, it doesn't provide specific results or analysis for datasets with very low interaction density.

3. How the proposed method handles cases where the conformity weights learned by the multi-channel conformity weighting network are not accurate or reliable. The paper mentions that conformity weights are estimated but doesn't discuss how the method handles cases of inaccurate or unreliable weights.

## Limitations
- The effectiveness of conformity estimation at scale remains uncertain, particularly for datasets with different bias distributions.
- The reliance on graph-based methods introduces sensitivity to graph construction quality, which may degrade in extremely sparse scenarios.
- The architectural complexity of combining multiple encoders and weighting mechanisms increases the risk of overfitting and reduces interpretability.
