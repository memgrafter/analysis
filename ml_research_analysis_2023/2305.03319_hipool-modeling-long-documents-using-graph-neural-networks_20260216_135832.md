# HiPool: Modeling Long Documents Using Graph Neural Networks

## Quick Facts
- arXiv ID: 2305.03319
- Source URL: https://arxiv.org/abs/2305.03319
- Authors: 
- Reference count: 17
- Key outcome: HiPool achieves 2.6% overall F1 score improvement and 4.8% on longest sequence datasets for long document classification

## Executive Summary
This paper addresses the challenge of encoding long documents in NLP tasks, where transformers face quadratic complexity and fixed length limits. The authors propose HiPool, a hierarchical graph-based method that chunks documents into fixed-length sequences, encodes them with a pretrained language model, and applies a graph neural network to model intra- and cross-sentence correlations. The approach introduces a new attention mechanism to capture inter-hierarchy relationships. Evaluated on a newly proposed benchmark with six datasets totaling up to 53k samples and 4034 average tokens, HiPool surpasses competitive baselines by 2.6% in F1 score overall and by 4.8% on the longest sequence dataset, demonstrating superior performance and scalability compared to sequential models.

## Method Summary
HiPool uses a hierarchical graph-based approach to encode long documents by first chunking them into fixed-length sequences (300 tokens) with 50% overlap, then encoding each chunk using a pretrained language model like BERT or RoBERTa. The method constructs a graph with low-level nodes representing chunk encodings and high-level nodes aggregating clusters, applying a graph neural network with a novel heterogeneous attention mechanism to model both intra- and cross-sentence correlations. This graph encoder captures long-range dependencies more efficiently than sequential approaches by leveraging the hierarchical structure to aggregate local sentence information and strengthen connections across different clusters through attention-based message passing.

## Key Results
- Achieves 2.6% overall F1 score improvement over competitive baselines
- Shows 4.8% performance gain specifically on the longest sequence dataset
- Demonstrates better scalability than sequential models for long document classification

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The graph-based hierarchy alleviates long dependency issues that sequential models face with long documents
- Mechanism: By chunking documents into fixed-length segments and encoding them with a pretrained model, then using a graph neural network (GNN) to model intra- and cross-sentence correlations, the model can capture long-range dependencies more efficiently than sequential approaches
- Core assumption: Graph-based models can represent and propagate information across non-adjacent segments more effectively than sequential models
- Evidence anchors: [abstract] "we alleviate these issues through a graph-based method" and "our method is shown to outperform hierarchical sequential models"; [section] "we apply a graph neural network (GNN) to model the upper-level hierarchy to aggregate local sentence information"

### Mechanism 2
- Claim: The heterogeneous attention mechanism captures inter-hierarchy relationships that sequential models miss
- Mechanism: The model introduces an edge type connecting external cluster low-level nodes to each high-level node, using attention to obtain cross-sentence information
- Core assumption: Cross-sentence information is crucial for understanding long documents, and attention mechanisms can effectively model these relationships in a hierarchical graph structure
- Evidence anchors: [abstract] "we propose a new heterogeneous attention mechanism to consider intra- and cross-sentence correlations"; [section] "we propose an attention mechanism to obtain cross-sentence information"

### Mechanism 3
- Claim: Overlapping sequence encoding preserves context between chunks, improving overall document understanding
- Mechanism: By using an overlapping window size when chunking documents, each chunk carries information from its adjacent chunks, preventing information isolation
- Core assumption: Adjacent chunks contain overlapping semantic content that, when encoded together, provides better context for understanding each individual chunk
- Evidence anchors: [section] "Overlapping encoding makes it possible for a chunk to carry information from its adjacent chunks but not isolated"

## Architecture Onboarding

- Component map: Document → Chunks → Pretrained Encoder → GNN with Attention → Linear → Classification
- Critical path: Document is chunked with overlap → each chunk encoded with BERT/RoBERTa → GNN with heterogeneous attention models hierarchical relationships → linear layer produces classification
- Design tradeoffs:
  - Fixed vs. variable chunk size: Fixed size simplifies implementation but may not align with natural sentence boundaries
  - Overlap size: Larger overlap preserves more context but increases computation
  - Number of GNN layers: More layers can capture more complex relationships but may overfit
- Failure signatures:
  - Performance drops significantly with longer documents
  - Model struggles with documents containing very long sentences
  - Attention weights become uniform, indicating the attention mechanism isn't learning
- First 3 experiments:
  1. Test different chunk sizes (e.g., 200, 300, 400 tokens) to find optimal balance between context preservation and computational efficiency
  2. Compare overlapping vs. non-overlapping chunking to quantify the benefit of the overlapping approach
  3. Experiment with different GNN architectures (GCN, GAT, PNA) to find the best performer for this task

## Open Questions the Paper Calls Out
- How would performance change with different GNN architectures (e.g., Graph Attention Networks, GraphSAGE) instead of the current HiPool graph encoder?
- How would performance be affected when trained on multilingual or non-English corpora?
- What is the impact of different chunk lengths (L) and overlapping lengths (Lolp) on performance?

## Limitations
- Experimental scope limited to six datasets totaling 53k samples, with two critical datasets not publicly available
- Scalability to documents significantly longer than 4034 tokens remains unverified
- Computational complexity of the heterogeneous attention mechanism for very long documents is not thoroughly analyzed

## Confidence

**High Confidence**: Hierarchical graph-based approaches outperform sequential models for long document classification (2.6% F1 improvement, reproducible methodology)

**Medium Confidence**: The heterogeneous attention mechanism captures inter-hierarchy relationships that improve performance (overall effectiveness demonstrated, but lacks detailed mechanism analysis)

**Low Confidence**: Scalability advantages over sequential models are weakly supported (tested only up to ~4000 tokens, no theoretical complexity analysis)

## Next Checks

1. **Benchmark Expansion**: Replicate experiments on publicly available datasets while systematically varying chunk size (200, 300, 400 tokens) and overlap percentage (0%, 25%, 50%, 75%) to quantify design choice contributions and establish hyperparameter sensitivity

2. **Attention Mechanism Analysis**: Conduct ablation studies by removing the heterogeneous attention component and comparing performance, plus visualize attention weight distributions across document lengths to verify meaningful cross-sentence relationships

3. **Scalability Stress Test**: Extend evaluation to artificially generated documents of 8000+ tokens by concatenating existing documents, measuring performance degradation and computational overhead, then compare against competitive baselines like Longformer and BigBird to validate scalability claims beyond current dataset limits
