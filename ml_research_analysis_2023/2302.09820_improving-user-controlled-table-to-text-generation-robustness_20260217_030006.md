# Improving User Controlled Table-To-Text Generation Robustness

## Quick Facts
- arXiv ID: 2302.09820
- Source URL: https://arxiv.org/abs/2302.09820

## Executive Summary
This paper addresses the robustness of table-to-text generation models when users interact with tables by selecting cells to generate natural language descriptions. The authors propose a fine-tuning regime that includes user-simulated noisy cell selections to improve model robustness. By training models on both clean and noisy data, they achieve significant improvements in BLEU scores on both clean and noisy test cases, while also maintaining state-of-the-art performance on the ToTTo dataset.

## Method Summary
The authors propose a two-stage fine-tuning approach for improving the robustness of table-to-text generation models. First, they create an augmented training dataset by combining the original clean ToTTo data with four types of user-simulated noisy cell selections. Then, they fine-tune BART models using a conditional language modeling objective followed by reinforcement learning fine-tuning with a BLEU-based reward function. This approach aims to improve model robustness to noisy cell selections while maintaining performance on clean inputs.

## Key Results
- Models fine-tuned with the proposed regime gain 4.85 BLEU points on user noisy test cases and 1.4 on clean test cases.
- BART-LARGE + RL (Df inal) achieves the highest BLEU scores on both clean and noisy test sets.
- The proposed approach maintains state-of-the-art performance on the ToTTo dataset while improving robustness to user noise.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Fine-tuning with simulated noisy cell selections improves model robustness to real user noise.
- Mechanism: The model learns to generate coherent text even when irrelevant cells are included or relevant cells are missing, by being exposed to such scenarios during training.
- Core assumption: Simulated noise types (Noise 1-4) adequately represent real user selection errors.
- Evidence anchors:
  - [abstract] Models fine-tuned with the proposed regime gain 4.85 BLEU points on user noisy test cases and 1.4 on clean test cases.
  - [section 2.2] Four noise types are described that mimic real user behaviors like accidental selection of unrelated cells or missing relevant ones.
  - [corpus] Weak corpus evidence; neighbors discuss general table-to-text generation but not specifically noise robustness.
- Break condition: If the noise simulation does not match actual user behavior, the robustness gain may not transfer to real-world usage.

### Mechanism 2
- Claim: Reinforcement learning fine-tuning further improves robustness by optimizing sequence-level similarity to reference text.
- Mechanism: The RL objective (Equation 1) rewards outputs that are closer to reference texts, implicitly aligning outputs from noisy and clean cell selections.
- Core assumption: BLEU-based reward captures the desired similarity between generated and reference texts across both clean and noisy cases.
- Evidence anchors:
  - [section 2.4] Equation 1 defines the RL training objective using BLEU as the reward function.
  - [section 3] Models fine-tuned with RL (BART-BASE + RL (Df inal)) achieve the highest BLEU scores on both clean and noisy test sets.
  - [corpus] Weak corpus evidence; neighbors focus on table-to-text generation but not on RL for robustness.
- Break condition: If the reward function does not correlate well with human judgment of quality, RL may not improve real-world robustness.

### Mechanism 3
- Claim: Augmenting the training set with noisy examples significantly improves model generalization compared to training only on clean data.
- Mechanism: By including both clean and noisy cell selections in the training set (Df inal), the model learns to handle a wider variety of input patterns, reducing the performance gap between clean and noisy test cases.
- Core assumption: The size of the augmented dataset (five times the original) is sufficient to cover the variability in user selections.
- Evidence anchors:
  - [section 2.3] The training set Df inal is created by combining the original clean data with four types of noisy data.
  - [section 3] Models trained on Df inal show significant BLEU score improvements on noisy test cases (4.03 points on average) compared to models trained only on clean data.
  - [corpus] Weak corpus evidence; neighbors discuss data augmentation but not specifically for noise robustness in table-to-text generation.
- Break condition: If the augmented dataset is too small or the noise types do not represent real user behavior, the generalization benefit may be limited.

## Limitations

- The simulated noise patterns may not accurately reflect real user behavior in table cell selection.
- The paper relies heavily on BLEU score as the sole evaluation metric, which may not fully capture semantic quality and coherence.
- The computational requirements for RL fine-tuning may pose practical challenges for deployment in resource-constrained environments.

## Confidence

- Robustness improvement claims: Medium
- State-of-the-art performance claims: Medium
- Noise simulation validity: Low
