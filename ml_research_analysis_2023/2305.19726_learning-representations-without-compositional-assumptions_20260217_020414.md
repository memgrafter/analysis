# Learning Representations without Compositional Assumptions

## Quick Facts
- arXiv ID: 2305.19726
- Source URL: https://arxiv.org/abs/2305.19726
- Reference count: 32
- Key outcome: LEGATO achieves AUROC improvements of 2.3-3.1% on medical datasets and accuracy improvements of 2.2-3.9% on classification tasks compared to seven state-of-the-art benchmarks

## Executive Summary
This paper addresses unsupervised representation learning for tabular multi-view data where feature sets are generated by distinct measurement sources. Traditional multi-view methods rely on compositional assumptions that information is globally shared across views, but these assumptions fail for real-world data with complex, localized dependencies between feature sets. The proposed LEGATO method learns feature set dependencies by representing views as graph nodes with learnable edges, then uses a hierarchical graph autoencoder to dynamically aggregate information into a smaller latent graph. This approach results in latent graph components that specialize in capturing localized information from different input regions, achieving superior downstream performance on medical and classification tasks.

## Method Summary
LEGATO represents K input views as graph nodes and learns their dependencies through a graph structure learner that creates an adjacency matrix. The method employs a hierarchical graph autoencoder that pools information from K input views into K' < K latent nodes, where each latent node aggregates information from locally related input views. The pooling operation uses a graph coarsening technique that preserves local structures while creating a smaller, more manageable representation. An orthogonality regularization ensures the latent components remain distinct and capture different aspects of the input. The entire model is trained end-to-end using a reconstruction loss, allowing the structure learning, pooling strategy, and latent representations to be jointly optimized.

## Key Results
- AUROC improvements of 2.3-3.1% on TCGA and UK Biobank medical datasets compared to seven state-of-the-art benchmarks
- Accuracy improvements of 2.2-3.9% on UCI-MFS classification tasks
- Learned graph structures successfully capture localized dependencies rather than global sharing patterns
- Performance benefits maintained across different dataset types and downstream tasks

## Why This Works (Mechanism)

### Mechanism 1
LEGATO learns localized information aggregation by dynamically learning view dependencies as graph edges. The method represents feature sets as graph nodes and learns adjacency matrix A(0) through inner product of transformed view embeddings, capturing which views share information locally rather than assuming global sharing. The learned graph structure guides the pooling operation to aggregate information from related views. This works because real-world tabular multi-view data contains localized clusters of views with shared information rather than uniform global patterns.

### Mechanism 2
The hierarchical graph autoencoder learns a smaller latent graph that creates decomposable representations. LEGATO pools information from K input views into K' < K latent nodes, where each latent node aggregates information from locally related input views, creating specialized components. The orthogonality regularization ensures these components remain distinct and capture different aspects of the input. This decomposition is effective because a smaller, pooled graph can effectively capture essential localized information while reducing redundancy.

### Mechanism 3
The end-to-end training of the complete graph autoencoder optimizes both structure learning and information aggregation. The model jointly learns view dependencies (graph structure), pooling strategy, and latent representations through a reconstruction loss. The hierarchical process (pool → encode → unpool) is fully differentiable, allowing gradient signals to optimize all components simultaneously. This joint optimization leads to better aggregation strategies than pre-defining either the structure or the representation separately.

## Architecture Onboarding

- **Component map**: Input Views → GRAPHLEARNER → POOL → Latent Graph → UNPOOL → View Decoders → Reconstruction Loss
- **Critical path**: GRAPHLEARNER → POOL → Latent Graph → UNPOOL → View Decoders → Reconstruction Loss
- **Design tradeoffs**: 
  - K' (latent graph size): Smaller values increase specialization but risk information loss; larger values preserve more information but reduce decomposability
  - Sparsity threshold: Higher thresholds create sparser graphs but might miss subtle dependencies; lower thresholds capture more relationships but risk overfitting
  - Orthogonality weight: Higher weights enforce more distinct components but might force artificial separation; lower weights allow more flexibility but reduce specialization
- **Failure signatures**:
  - Fully connected learned graph: Indicates the model failed to identify localized dependencies and defaulted to global aggregation
  - Identical latent node embeddings: Suggests orthogonality regularization is too weak or the pooling strategy isn't learning meaningful groupings
  - Poor reconstruction despite good downstream performance: Might indicate the model is learning useful representations that aren't fully captured by reconstruction
- **First 3 experiments**:
  1. Verify learned graph structure on a simple synthetic dataset with known local correlations (e.g., views 1-3 correlated, views 4-6 correlated, views 7-9 correlated)
  2. Test effect of K' size on downstream performance using a benchmark dataset with moderate number of views
  3. Compare performance with and without orthogonality regularization on a dataset known to have complex view dependencies

## Limitations

- The paper's claims about localized information aggregation depend heavily on the assumption that real-world tabular multi-view data exhibits localized dependencies rather than global patterns, which requires broader empirical validation
- The choice of K' (latent graph size) appears somewhat heuristic, and the sensitivity analysis for this hyperparameter is not thoroughly explored
- The method's computational complexity for large numbers of views or high-dimensional features is not discussed, which could limit practical applicability

## Confidence

- **High confidence**: The core mechanism of learning graph structures for multi-view data aggregation and the demonstration of improved downstream performance on benchmark datasets
- **Medium confidence**: The claim that traditional compositional assumptions are universally inadequate for real-world tabular data, as this requires broader empirical validation across more domains
- **Medium confidence**: The orthogonality regularization's contribution to performance improvements, as ablation studies show benefits but don't fully quantify the tradeoff between specialization and information preservation

## Next Checks

1. **Synthetic data testing**: Create synthetic multi-view datasets with varying correlation patterns (global vs. local) to systematically evaluate whether LEGATO correctly identifies and leverages localized dependencies while avoiding spurious global correlations
