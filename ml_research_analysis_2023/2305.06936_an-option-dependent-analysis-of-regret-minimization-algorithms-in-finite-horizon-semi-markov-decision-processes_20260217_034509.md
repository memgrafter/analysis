# An Option-Dependent Analysis of Regret Minimization Algorithms in Finite-Horizon Semi-Markov Decision Processes

## Quick Facts
- arXiv ID: 2305.06936
- Source URL: https://arxiv.org/abs/2305.06936
- Reference count: 25
- This paper analyzes regret minimization algorithms in finite-horizon semi-Markov decision processes using options-based hierarchical reinforcement learning

## Executive Summary
This paper presents a theoretical analysis of regret minimization in finite-horizon semi-Markov decision processes (SMDPs) using options-based hierarchical reinforcement learning. The authors propose a new algorithm FH-SMDP-UCRL that exploits pre-trained options and derive an option-dependent upper bound on its regret. The key insight is that using options reduces the effective planning horizon from H to approximately H/τ̄, where τ̄ is the average option duration. This work provides theoretical justification for using options in finite-horizon problems and offers insights into when hierarchical approaches are preferable to flat ones.

## Method Summary
The authors develop FH-SMDP-UCRL, a regret minimization algorithm for finite-horizon SMDPs that leverages pre-trained options. The algorithm maintains confidence intervals over both primitive actions and options, using these to guide exploration and exploitation. The method builds on UCRL (Upper Confidence Reinforcement Learning) but extends it to the semi-Markov setting with hierarchical options. The analysis shows that when options are available, the algorithm can achieve better regret bounds than flat approaches by effectively reducing the planning horizon through option execution.

## Key Results
- Proposes FH-SMDP-UCRL algorithm that exploits pre-trained options
- Derives regret bound scaling as Õ((√(SOd²))(T + √(SH)))
- Shows effective planning horizon reduces from H to H/τ̄ using options
- Demonstrates hierarchical learning from scratch can outperform flat approaches in certain settings

## Why This Works (Mechanism)
The mechanism works by exploiting the temporal abstraction provided by options. When an option is executed, it performs a sequence of primitive actions over multiple time steps without requiring high-level decisions. This reduces the number of decisions the high-level policy needs to make, effectively shortening the planning horizon. The algorithm maintains confidence intervals over both primitive actions and options, allowing it to balance exploration and exploitation while accounting for the semi-Markov nature of option execution.

## Architecture Onboarding

Component map:
Options -> SMDP model -> Confidence intervals -> Regret bound calculation

Critical path:
Pre-trained options -> SMDP-UCRL extension -> Option-dependent confidence intervals -> Regret analysis

Design tradeoffs:
The algorithm trades off between maintaining primitive action confidence intervals versus option-level intervals. Using options reduces the effective horizon but requires additional bookkeeping for option-specific statistics. The choice of option set affects both computational complexity and regret bounds.

Failure signatures:
- Poor regret performance when option durations have high variance (large T term)
- Computational inefficiency if number of options grows exponentially with state space
- Suboptimal performance when pre-trained options don't match the true optimal structure

## Limitations
- Assumes known, pre-trained options which may not reflect realistic learning scenarios
- Regret bounds depend on average option duration τ̄, but relationship to problem structure is not fully characterized
- Results focus on finite-horizon settings, limiting generalization to infinite-horizon problems
