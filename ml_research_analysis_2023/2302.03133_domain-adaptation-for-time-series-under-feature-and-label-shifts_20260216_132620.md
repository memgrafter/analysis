# Domain Adaptation for Time Series Under Feature and Shifts

## Quick Facts
- arXiv ID: 2302.03133
- Source URL: https://arxiv.org/abs/2302.03133
- Reference count: 40
- Primary result: RAINCOAT improves domain adaptation accuracy by up to 16.33% over 13 baselines for time series with feature and label shifts

## Executive Summary
RAINCOAT addresses unsupervised domain adaptation for time series data under both feature and label shifts, including closed-set and universal domain adaptation scenarios. The method combines time and frequency domain feature representations, aligns them using Sinkhorn divergence, and includes a correction step to detect private target classes in universal DA. Experiments on five benchmark datasets (HAR, HHAR, WISDM, Sleep-EDF, Boiler) demonstrate improvements of up to 16.33% over 13 baselines, with H-scores reaching 0.8266 for universal DA.

## Method Summary
RAINCOAT operates through an align-then-correct framework that first extracts joint time-frequency features using CNN for time features and DFT for frequency features, then aligns source and target domains using Sinkhorn divergence with regularization parameter 1e-3. For universal domain adaptation, it detects private target classes by analyzing feature movement before and after correction. The method handles both closed-set DA (measuring accuracy and macro-F1) and universal DA (using H-score as harmonic mean of accuracy on common and private classes). Training involves separate alignment, correction, and inference stages with dataset-specific hyperparameters.

## Key Results
- Improves accuracy by up to 16.33% over 13 baselines on five time series datasets
- Achieves H-scores of 0.8266 for universal domain adaptation on Sleep-EDF dataset
- Demonstrates effectiveness across different types of shifts including feature, label, and conditional shifts
- Shows consistent improvements across both closed-set and universal domain adaptation settings

## Why This Works (Mechanism)
RAINCOAT's effectiveness stems from its joint time-frequency feature representation that captures both temporal patterns and spectral characteristics of time series data. The Sinkhorn divergence alignment preserves the geometric structure of frequency features while reducing domain discrepancy, addressing the challenge that traditional MMD-based methods struggle with frequency domain alignment. The correction step in universal DA specifically handles label shifts by detecting private target classes through feature reconstruction and bimodality testing, ensuring that discriminative target features are preserved while aligning common classes.

## Foundational Learning
- **Sinkhorn Divergence**: Optimal transport-based divergence that provides smoother gradients than MMD for distribution alignment; needed for robust frequency feature alignment across domains
- **DFT-based Frequency Features**: Discrete Fourier Transform extracts spectral information; needed because time series often contain periodic patterns not captured by temporal features alone
- **Bimodality Testing**: Statistical test to detect whether a feature distribution has two distinct modes; needed to identify private target classes in universal domain adaptation
- **Time-Frequency Joint Encoding**: Combining temporal CNN features with spectral DFT features; needed because both representations capture complementary information about time series structure

## Architecture Onboarding

Component Map:
Time Feature CNN -> Sinkhorn Alignment -> Label Prediction
Frequency Feature DFT -> Sinkhorn Alignment -> Correction Step -> Private Class Detection

Critical Path:
1. Extract time features using CNN from both source and target domains
2. Extract frequency features using DFT with smoothing windows
3. Align both feature sets using Sinkhorn divergence
4. For universal DA: detect private classes via feature movement analysis
5. Train classifier on aligned source features and predict on aligned target features

Design Tradeoffs:
- Joint time-frequency features vs. single domain features: Joint encoding captures more comprehensive information but increases computational complexity
- Sinkhorn divergence vs. MMD: Sinkhorn provides better frequency alignment but requires solving optimal transport problems
- Correction step vs. pure alignment: Correction handles label shifts but adds complexity and potential instability

Failure Signatures:
- Poor alignment manifests as degraded accuracy on common classes and low H-scores
- Incorrect private class detection shows as either missing true private classes or falsely identifying common classes as private
- Frequency leakage due to inadequate smoothing produces noisy spectral features and unstable alignment

First Experiments:
1. Validate Sinkhorn divergence implementation on synthetic Gaussian distributions with known Wasserstein distance
2. Test frequency feature extraction consistency across different time series lengths and sampling rates
3. Verify private class detection mechanism on synthetic universal DA data with known label shifts

## Open Questions the Paper Calls Out

### Open Question 1
How do different smoothing functions (e.g., Hann vs cosine window) impact the effectiveness of frequency feature extraction in RAINCOAT?
The paper mentions using a smoothing function before applying DFT to prevent frequency leakage, with options like cosine or Hann window, but does not compare their effectiveness. Comparative experiments evaluating RAINCOAT's performance using different smoothing functions on the same datasets would clarify their relative impact.

### Open Question 2
What is the impact of frequency mode selection on RAINCOAT's performance for different types of time series data?
The paper mentions using different numbers of Fourier frequency modes for different datasets but does not explain how these were chosen or explore the sensitivity to this choice. Experiments varying the number of frequency modes across different datasets while measuring performance would reveal the importance of this hyperparameter.

### Open Question 3
How does RAINCOAT's performance scale with the complexity and length of time series data?
While the paper evaluates on datasets with different characteristics, there is no explicit analysis of how RAINCOAT's performance changes with time series length or complexity. Controlled experiments varying time series length and complexity while measuring performance would reveal scaling properties.

### Open Question 4
Could alternative divergence measures besides Sinkhorn provide better alignment for certain types of time series feature shifts?
While Sinkhorn is justified theoretically and compared to MMD, other divergence measures like sliced Wasserstein or energy distance are not explored. Comparative experiments testing RAINCOAT with alternative divergence measures on datasets with different types of feature shifts would identify optimal choices for specific scenarios.

## Limitations
- Missing critical implementation details for CNN architecture and decoder specifications
- Dataset-specific hyperparameter tuning required without clear selection methodology
- Limited analysis of how performance scales with time series length and complexity
- No comparison against alternative divergence measures beyond MMD

## Confidence
High confidence in the core innovation of joint time-frequency features with Sinkhorn alignment. Medium confidence in universal DA correction mechanism due to unspecified clustering thresholds. Low confidence in hyperparameter selection strategy across different datasets.
