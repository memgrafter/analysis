# Mask The Bias: Improving Domain-Adaptive Generalization of CTC-based ASR with Internal Language Model Estimation

## Quick Facts
- **arXiv ID**: 2305.03837
- **Source URL**: https://arxiv.org/abs/2305.03837
- **Reference count**: 0
- **Primary result**: ILME improves WER by up to 9.8% and OOV F1-score by up to 24.6% relative to shallow fusion in domain-adaptive ASR

## Executive Summary
This paper addresses the challenge of domain-adaptive generalization in CTC-based automatic speech recognition (ASR) systems by proposing a novel internal language model estimation (ILME) technique. The method iteratively masks audio timesteps to estimate a pseudo log-likelihood of the internal language model, thereby reducing source domain bias. Experiments demonstrate that the proposed approach significantly improves word error rate (WER) and out-of-vocabulary (OOV) F1-score across multiple out-of-domain datasets, outperforming shallow fusion both when target domain text data is available and in zero-shot adaptation scenarios.

## Method Summary
The method involves a conformer-based CTC model trained on 50k+ hours of paired audio-text data, using an iterative input masking approach for ILME. The core technique divides audio timesteps into K partitions, masks each partition iteratively, and computes log-posteriors only for masked timesteps. By accumulating these masked log-posteriors and comparing them to unmasked predictions, the method identifies timesteps where the model relies on learned language patterns rather than acoustic input. During beam search decoding, the ILM pseudo log-likelihood is subtracted for timesteps where masking significantly changes log-posterior distributions, while selective blank token filtering prevents degradation of CTC decoding performance.

## Key Results
- Improves WER by up to 9.8% relative to shallow fusion when target domain text data is available
- Improves OOV F1-score by up to 24.6% relative to shallow fusion in text-only domain adaptation
- Outperforms shallow fusion in zero-shot domain adaptation, improving WER by up to 9.3% relative

## Why This Works (Mechanism)

### Mechanism 1
Iterative masking isolates internal LM bias by forcing the model to predict without full acoustic context. The method divides audio timesteps into K partitions, masks each partition iteratively, and computes log-posteriors only for masked timesteps. By accumulating these masked log-posteriors and comparing them to unmasked predictions, the method identifies timesteps where the model relies on learned language patterns rather than acoustic input. Core assumption: CTC models, despite being non-autoregressive, still learn internal language patterns through self-attention and convolution mechanisms that create sequence-level interdependence.

### Mechanism 2
Dynamic thresholding based on log-posterior differences identifies timesteps contributing to internal LM bias. For each masked timestep, the method computes element-wise absolute difference between masked and unmasked log-posteriors (ϵk_t). It takes the maximum difference across vocabulary items (δk_t), normalizes across timesteps (ˆδk_t), and includes the log-posterior in ILM computation only if ˆδk_t exceeds threshold γ. Core assumption: Timesteps where masking significantly changes log-posterior distributions indicate the model is relying on learned language patterns rather than acoustic evidence.

### Mechanism 3
Selective blank token filtering prevents ILM subtraction from degrading CTC decoding performance. The method only subtracts ILM pseudo log-likelihood for timesteps where the model assigns low probability to the blank token (below threshold β). For high-blank-probability timesteps, it keeps the original CTC scores. Core assumption: Blank tokens in CTC models are purely functional and don't correspond to language semantics, so ILM subtraction on blank-heavy timesteps would be harmful.

## Architecture Onboarding

- **Component map**: Conformer encoder -> CTC head -> Masking module -> ILM computation -> Modified beam search decoder
- **Critical path**: 
  1. Forward pass with original input to get baseline log-posteriors
  2. K forward passes with masked inputs to get masked log-posteriors
  3. Element-wise difference computation and thresholding
  4. ILM pseudo log-likelihood computation via weighted sum
  5. Modified beam search with ILM subtraction for selected timesteps
  6. Output generation
- **Design tradeoffs**: 
  - K partitions vs. computational cost: More partitions provide better ILM estimation but linearly increase inference time
  - Threshold γ vs. ILM signal quality: Higher thresholds reduce noise but may exclude valid ILM signals
  - Threshold β vs. blank token handling: Lower thresholds include more timesteps in ILM subtraction but risk degrading blank-heavy regions
- **Failure signatures**: 
  - Performance degradation when using source LM in zero-shot adaptation indicates ILM subtraction is removing useful acoustic information
  - Inconsistent OOV F1 improvements across datasets suggest masking strategy isn't optimal for all domains
  - High computational overhead with large K indicates need for optimization or alternative masking strategies
- **First 3 experiments**:
  1. Vary K from 1 to 10 on LibriSpeech test-clean to find optimal tradeoff between ILM quality and computational cost
  2. Sweep γ from 0.1 to 0.5 to find threshold that maximizes OOV F1 while maintaining WER improvements
  3. Compare equal-length masking vs. word-boundary masking on VoxPopuli to validate which masking strategy works better for named entities and rare words

## Limitations
- Method introduces significant computational overhead requiring K+1 forward passes per inference
- Equal-length masking may not be optimal for handling named entities and rare words
- Performance heavily depends on hyperparameter tuning (K, γ, β values)

## Confidence
