# CAPRI: Context-Aware Interpretable Point-of-Interest Recommendation Framework

## Quick Facts
- arXiv ID: 2306.11395
- Source URL: https://arxiv.org/abs/2306.11395
- Reference count: 39
- Primary result: CAPRI integrates context-aware models with fusion strategies for multi-dimensional POI recommendation evaluation.

## Executive Summary
CAPRI is an open-source Python framework designed for evaluating and benchmarking point-of-interest (POI) recommendation systems. It integrates context-aware models such as GeoSoCa, LORE, and USG, and introduces efficient strategies for merging contextual information. CAPRI extends evaluation beyond accuracy to include novelty, personalization, diversity, and fairness metrics. The framework provides reproducibility through configurable experiments and supports multiple datasets and models. Initial benchmarking on the Yelp dataset shows that context fusion methods like sum and weighted sum improve performance, particularly in beyond-accuracy metrics. CAPRI aims to standardize POI recommendation evaluation and is publicly available on GitHub.

## Method Summary
CAPRI framework integrates context-aware POI recommendation models (GeoSoCa, LORE, USG) with context fusion strategies (sum, product, weighted sum) to generate ranked POI recommendations. The framework supports multi-dimensional evaluation including accuracy metrics (Precision@k, Recall@k, mAP@k, nDCG@k), beyond-accuracy metrics (List Diversity, Novelty, Catalog Coverage, Personalization), and fairness metrics (MADr and GCE). CAPRI operates on three popular check-ins datasets (Gowalla, Yelp, and Foursquare) with configurable experiments through a config.py file. The framework provides reproducible benchmarking and analysis of model performance across different evaluation dimensions.

## Key Results
- Context fusion strategies (sum, weighted sum) significantly improve beyond-accuracy metrics on Yelp dataset
- CAPRI successfully integrates multiple context-aware models with configurable fusion rules
- Multi-dimensional evaluation reveals trade-offs between accuracy and beyond-accuracy metrics

## Why This Works (Mechanism)
CAPRI works by systematically integrating contextual information from multiple sources (geographical, social, temporal) through fusion strategies, then evaluating recommendations across multiple dimensions beyond simple accuracy. The framework's modular design allows flexible combination of context-aware models with different fusion rules, enabling comprehensive benchmarking of POI recommendation approaches.
