# Towards Argument-Aware Abstractive Summarization of Long Legal Opinions with Summary Reranking

## Quick Facts
- arXiv ID: 2306.00672
- Source URL: https://arxiv.org/abs/2306.00672
- Reference count: 27
- Key outcome: Argument-aware abstractive summarization with reranking improves legal opinion summarization by aligning summaries with document argumentative structure

## Executive Summary
This paper presents a framework for abstractive summarization of long legal opinions that leverages the document's argument structure. The approach uses argument role information to generate multiple candidate summaries, then rerank these candidates based on alignment with the document's argument structure. The method involves using the Longformer-Encoder-Decoder (LED) model to generate multiple candidate summaries by training it on various input formats, including argument-aware formats, and using beam search to further diversify the output. The best candidate summary is selected based on its lexical similarity to the input's main arguments. The approach was evaluated on a dataset of long legal opinions and showed improved performance over several strong baselines, with ROUGE and BERTScore results indicating that considering the argumentative coverage of the original opinions can lead to a more effective selection of summaries.

## Method Summary
The proposed method combines argument-aware input formatting with diverse beam decoding to generate multiple candidate summaries from long legal opinions. Three input representations are used: raw text, binary argument markers, and fine-grained argument markers. The LED-base model is fine-tuned on each format, then during inference, diverse beam search generates multiple candidates from each format. An argument role classifier predicts which sentences contain main arguments (Issues, Reasons, Conclusions), and candidates are reranked based on lexical similarity to these argumentative sentences using ROUGE-1 F1-score. The highest-scoring candidate is selected as the final summary.

## Key Results
- The argument-aware LED model with diverse beam decoding outperforms baselines including LED-base, BART, and T5 on ROUGE-1, ROUGE-2, ROUGE-L, and BERTScore metrics
- Reranking candidates based on argumentative alignment shows consistent improvements across all metrics
- The performance gap between oracle and predicted argument markers is significantly reduced through diverse decoding, with gaps reduced to -0.02-0.66 in ROUGE and -0.03 in BERTScore
- Cross-validation across five folds shows stable performance improvements, indicating robustness to dataset variations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Combining multiple argument-aware input formats with diverse beam decoding generates more effective summary candidates that capture different aspects of the legal opinion's argumentative structure.
- Mechanism: Training the LED model on three distinct input representations (raw text, binary argument markers, fine-grained argument markers) creates diverse decoding paths. During inference, these varied inputs produce different candidate summaries that emphasize different argumentative elements, increasing the likelihood that at least one candidate captures the document's main arguments.
- Core assumption: Different input formats highlight different argumentative aspects, and diverse beam decoding further diversifies output without losing coherence.
- Evidence anchors: [abstract], [section 4.1], [corpus]

### Mechanism 2
- Claim: Reranking candidates based on lexical similarity to predicted argumentative sentences effectively selects summaries that align with the document's main argument points.
- Mechanism: The scoring function µ = ROUGE1( ˆXargs, ˆS) measures how well each candidate summary captures the argumentative content extracted from the input. This alignment-based ranking ensures the selected summary reflects the document's argumentative structure rather than just surface-level salience.
- Core assumption: Lexical overlap between candidate summaries and extracted argumentative sentences is a reliable proxy for argumentative alignment.
- Evidence anchors: [abstract], [section 4.2], [corpus]

### Mechanism 3
- Claim: Using predicted argument markers instead of oracle markers during inference reduces the performance gap between training and deployment conditions.
- Mechanism: By training on oracle markers but inferring with predicted markers, the model learns to generalize from noisy predictions. The combination of diverse input formats and beam decoding creates robustness to marker prediction errors.
- Core assumption: The model can learn to be robust to prediction errors when trained on clean data but evaluated on noisy data.
- Evidence anchors: [abstract], [section 6], [corpus]

## Architecture Onboarding

- Component map: Input processing -> LED-base finetuning -> Diverse beam decoding -> Argument role classification -> Reranking -> Best candidate selection
- Critical path: Input → Argument role prediction → Candidate generation (3 formats × diverse beams) → Scoring (argumentative alignment) → Best candidate selection
- Design tradeoffs:
  - Multiple input formats increase training complexity but improve candidate diversity
  - Using predicted vs oracle markers affects robustness vs accuracy
  - Beam width impacts diversity vs computational cost
- Failure signatures:
  - Poor ROUGE scores indicate argument role prediction errors
  - Inconsistent performance across folds suggests data quality issues
  - Large gap between oracle and predicted results indicates model brittleness
- First 3 experiments:
  1. Train LED-base on raw text only and compare ROUGE scores to establish baseline
  2. Add binary argument markers and measure improvement in argumentative coverage
  3. Implement diverse beam decoding and evaluate if it improves candidate quality without hurting coherence

## Limitations
- Limited dataset size with only 1,049 annotated legal opinion/summary pairs raises concerns about generalizability
- Performance gap between oracle and predicted argument markers reveals potential brittleness in real-world deployment
- Reliance solely on ROUGE and BERTScore metrics without human evaluation limits assessment of argumentative quality

- High confidence: Basic premise that argument-aware summarization improves legal opinion summaries
- Medium confidence: Specific reranking mechanism and its effectiveness in selecting argumentative summaries
- Medium confidence: Diverse beam decoding's ability to mitigate oracle-predicted performance gap
