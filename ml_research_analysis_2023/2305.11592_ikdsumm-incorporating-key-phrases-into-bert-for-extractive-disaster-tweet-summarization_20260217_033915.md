# IKDSumm: Incorporating Key-phrases into BERT for extractive Disaster Tweet Summarization

## Quick Facts
- arXiv ID: 2305.11592
- Source URL: https://arxiv.org/abs/2305.11592
- Reference count: 40
- Primary result: Outperforms 8 state-of-the-art techniques by 2-79% in ROUGE-N F1-score

## Executive Summary
This paper introduces IKDSumm, a disaster tweet summarization framework that leverages domain knowledge to extract key-phrases without human intervention. The approach combines a modified version of RAKE with disaster-specific ontology to identify key-phrases, then uses these key-phrases along with BERT embeddings to predict tweet salience scores and select the most important tweets for the summary. The framework ensures information coverage, relevance, and diversity in the summary. Experiments on 12 disaster datasets show that IKDSumm outperforms 8 state-of-the-art techniques by 2-79% in terms of ROUGE-N F1-score.

## Method Summary
IKDSumm is a BERT-based extractive summarization framework that incorporates key-phrases for disaster tweet summarization. The framework uses a modified RAKE algorithm (DRAKE) that leverages disaster-specific ontology to extract key-phrases without human intervention. These key-phrases are then used alongside BERT embeddings to predict salience scores for individual tweets. The framework selects tweets for the summary based on these scores while ensuring coverage of information, relevance to the disaster context, and diversity in the selected tweets. The approach addresses the challenge of information overload during disaster events by automatically generating concise, informative summaries from large volumes of social media data.

## Key Results
- Outperforms 8 state-of-the-art techniques by 2-79% in terms of ROUGE-N F1-score
- DRAKE key-phrase extraction method performs 4.02-27.83% better than existing methods in IOU and Jaccard Similarity
- Validated on 12 disaster datasets with consistent performance improvements

## Why This Works (Mechanism)
The framework works by combining domain-specific knowledge (disaster ontology) with advanced language models (BERT) to create more contextually relevant summaries. The key-phrase extraction identifies important concepts specific to disaster contexts, which are then used to weight the importance of tweets. This domain-aware approach allows the system to better capture the salience of disaster-related information compared to generic summarization methods.

## Architecture Onboarding

**Component Map**: Twitter Data -> DRAKE -> Key-phrases -> BERT Embeddings -> Salience Scoring -> Diversity Coverage Optimization -> Summary

**Critical Path**: Data preprocessing (POS tagging, stemming) → DRAKE key-phrase extraction → BERT embedding generation → Salience score calculation → Diversity-aware selection → Summary generation

**Design Tradeoffs**: The framework trades computational efficiency for accuracy by using BERT embeddings and comprehensive key-phrase analysis. While this increases processing time, it improves the quality and relevance of summaries for critical disaster response scenarios.

**Failure Signatures**: 
- Poor performance on novel disaster types not well-represented in the ontology
- Reduced effectiveness with highly informal or non-standard Twitter language
- Computational bottlenecks when processing very large tweet volumes

## Limitations
- Evaluation focuses exclusively on extractive summarization using ROUGE metrics, which may not capture practical utility for disaster response
- DRAKE method relies on disaster-specific ontology that may limit generalizability across different disaster types
- CoreNLP dependency for POS tagging introduces computational overhead and potential brittleness with informal Twitter language
