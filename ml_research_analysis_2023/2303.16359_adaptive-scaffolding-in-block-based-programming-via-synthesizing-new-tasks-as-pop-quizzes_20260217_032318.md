# Adaptive Scaffolding in Block-Based Programming via Synthesizing New Tasks as Pop Quizzes

## Quick Facts
- arXiv ID: 2303.16359
- Source URL: https://arxiv.org/abs/2303.16359
- Reference count: 40
- This paper presents PQ UIZ SYN, an algorithm that synthesizes adaptive programming tasks as multi-choice pop quizzes to provide scaffolding in block-based programming environments.

## Executive Summary
This paper introduces PQ UIZ SYN, a framework that generates adaptive pop quizzes as scaffolding for students working on block-based programming tasks. The algorithm synthesizes new programming tasks based on a student's current attempt, using symbolic reasoning and graph-based code representations to create questions that are appropriately challenging, comprehensible, and that conceal the solution. The framework was evaluated on real-world programming tasks from Code.org and CodeHS, demonstrating the ability to generate hundreds of adaptive pop quizzes that outperform baseline methods across multiple quality dimensions.

## Method Summary
PQ UIZ SYN generates pop quizzes by first representing the student's current code attempt and the correct solution as graph structures. It then identifies key differences between these representations to create new, related programming tasks that test understanding of specific concepts without revealing the solution. The algorithm uses symbolic reasoning to ensure the generated tasks are appropriately challenging for the student's current level while remaining comprehensible and non-revealing. The framework was implemented and evaluated on an online platform where students could receive pop quiz feedback while working on programming assignments.

## Key Results
- PQ UIZ SYN generated hundreds of pop quizzes when evaluated on real-world programming tasks from Code.org and CodeHS
- Expert ratings using a multi-dimensional rubric showed PQ UIZ SYN outperformed baseline methods across adaptive, comprehensible, and concealing attributes
- An initial user study with 12 participants demonstrated the utility of pop quiz-based feedback compared to next-step hints and no feedback

## Why This Works (Mechanism)
The framework works by creating a bridge between a student's current understanding (represented by their code attempt) and the target solution. By synthesizing new tasks that test specific concepts needed to complete the original problem, the pop quizzes provide targeted practice that addresses knowledge gaps without giving away the solution. The symbolic reasoning approach ensures that the generated questions are pedagogically meaningful and appropriately scaffolded to the student's current level.

## Architecture Onboarding

Component map:
Student code attempt -> Graph representation -> Symbolic reasoning engine -> Task synthesis module -> Multi-choice question generator -> Pop quiz output

Critical path:
The most critical path involves transforming the student's code attempt into a graph representation, running symbolic reasoning to identify knowledge gaps, and synthesizing a new task that addresses those gaps while maintaining appropriate difficulty and concealment.

Design tradeoffs:
The framework trades off computational complexity for pedagogical precision - more sophisticated symbolic reasoning enables better task synthesis but requires more processing time. The multi-choice format enables automated grading but may not capture all aspects of programming understanding.

Failure signatures:
The system may fail when student code is too far from any valid solution path, when symbolic reasoning cannot identify meaningful differences, or when the synthesized tasks become too complex to remain comprehensible.

First experiments:
1. Generate pop quizzes for a simple "draw a square" block-based task
2. Test task synthesis on code with multiple valid solution approaches
3. Evaluate whether generated quizzes maintain solution concealment across different student skill levels

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but potential areas for future work include investigating the long-term learning impacts of pop quiz scaffolding, extending the framework to text-based programming languages, and exploring different quiz formats beyond multi-choice questions.

## Limitations
- The evaluation focuses on task generation quality rather than direct learning outcome measurements
- The user study sample size was relatively small (N=12) and conducted online rather than in authentic classroom settings
- The framework assumes access to correct solutions, which may not always be available in real educational contexts
