# Coherence and Diversity through Noise: Self-Supervised Paraphrase Generation via Structure-Aware Denoising

## Quick Facts
- arXiv ID: 2302.02780
- Source URL: https://arxiv.org/abs/2302.02780
- Reference count: 40
- Primary result: Two-stage unsupervised framework for paraphrasing algebraic word problems using noise injection and self-supervised learning

## Executive Summary
This paper introduces SCANING, a two-stage unsupervised framework for paraphrasing algebraic word problems (AWPs). The approach combines noise injection techniques (templatization, synonym substitution, sentence permutation, phrase shuffling) with self-supervised learning through a denoiser (STEAD) and paraphraser (PAP). The framework aims to generate diverse paraphrases while preserving critical information needed for solution consistency.

## Method Summary
SCANING employs a two-stage approach for unsupervised paraphrase generation. The first stage uses STEAD, a denoiser that learns to reconstruct inputs corrupted with contextual and syntactic noise functions. The second stage employs PAP, which uses STEAD's outputs as weakly-supervised targets for learning a paraphrasing function. The framework incorporates prompt-aware denoising and controlled noise injection to balance diversity and coherence in generated paraphrases.

## Key Results
- SCANING significantly outperforms baselines on semantic preservation metrics
- The framework achieves better diversity scores compared to existing methods
- Experimental results on four datasets demonstrate effectiveness of the noise injection approach

## Why This Works (Mechanism)
The framework leverages controlled noise injection to create weakly-supervised training signals for paraphrase generation. By corrupting input text with various noise functions and training a denoiser to reconstruct the original, the system learns robust representations that preserve semantic content while allowing for structural variation. This self-supervised approach enables learning without requiring parallel paraphrase pairs.

## Architecture Onboarding

**Component Map**: AWP Input -> STEAD (Denoiser) -> PAP (Paraphraser) -> Output

**Critical Path**: The core pipeline flows from original problem text through STEAD for denoising, then to PAP for paraphrase generation. STEAD's output quality directly impacts PAP's ability to generate semantically faithful paraphrases.

**Design Tradeoffs**: The framework trades labeled paraphrase data for synthetic noise-based training signals. This enables unsupervised learning but requires careful noise function design to preserve mathematical relationships critical for problem solutions.

**Failure Signatures**: 
- Excessive noise injection may destroy solution-critical information
- Insufficient diversity in noise functions may limit paraphrase variety
- Error accumulation from STEAD to PAP can degrade final output quality
- Poor denoiser training may lead to low-quality weakly-supervised targets
