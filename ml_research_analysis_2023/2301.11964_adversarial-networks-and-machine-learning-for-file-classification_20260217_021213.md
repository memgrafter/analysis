# Adversarial Networks and Machine Learning for File Classification

## Quick Facts
- **arXiv ID**: 2301.11964
- **Source URL**: https://arxiv.org/abs/2301.11964
- **Reference count**: 31
- **Primary result**: SGAN achieves 97.6% accuracy on file type classification using byte frequency histograms, remaining highly accurate (82%) with only 50 labeled samples

## Executive Summary
This paper introduces a semi-supervised generative adversarial network (SGAN) for file type classification based on byte frequency distributions, demonstrating effectiveness even when file headers and extensions are obfuscated. The approach converts files to normalized 256-bin histograms representing byte value frequencies, then trains an SGAN architecture where the discriminator also serves as a classifier. The method achieves superior accuracy compared to traditional machine learning algorithms, particularly in low-supervision scenarios, with 97.6% accuracy when fully supervised and 82% accuracy with only 50 labeled samples out of thousands.

## Method Summary
The authors propose using a semi-supervised GAN architecture where files are converted to normalized 256-bin histograms representing byte frequency distributions. The model consists of a generator network that creates synthetic histograms from random noise, and a discriminator/classifier network that both distinguishes real from fake samples and classifies file types. The discriminator uses 4 hidden layers (512, 256, 128, 64 nodes) with ReLU activations and dropout, outputting both an 11-class classifier (for the file types) and a 1-class discriminator. The generator uses 3 hidden layers (32, 64, 128 nodes) with ReLU and dropout, outputting 256 nodes representing the histogram. Training uses Adam optimizer with learning rate 0.0005, batch size 32, and up to 300 epochs.

## Key Results
- SGAN achieved 97.6% classification accuracy across 11 file types with full supervision
- Maintained 82% accuracy even with only 50 labeled samples out of thousands
- Outperformed traditional standalone neural networks and three other machine learning algorithms
- Showed robustness to header obfuscation, with minimal accuracy degradation when first 6 bytes were replaced

## Why This Works (Mechanism)

### Mechanism 1
Byte value distributions preserve file type information even when headers are obfuscated. Files of the same type share consistent statistical patterns in byte frequency histograms, enabling classification without relying on headers or extensions. The core assumption is that byte distribution patterns are sufficiently stable within file types to be discriminative across different obfuscation methods.

### Mechanism 2
Semi-supervised GANs can effectively classify files with minimal labeled data. The discriminator/classifier network learns from both labeled samples and generated samples, improving classification accuracy even when most training data lacks labels. The core assumption is that the generator's ability to create realistic synthetic samples provides useful training signal to the discriminator/classifier.

### Mechanism 3
Adversarial training improves classification performance over traditional supervised learning. The competition between generator and discriminator forces the discriminator/classifier to learn more robust features that generalize better to unseen data. The core assumption is that the adversarial objective creates a more challenging training environment that yields better feature representations.

## Architecture Onboarding

- **Component map**: Generator -> Discriminator/Classfier (shared network) -> Classification output and Real/Fake output
- **Critical path**: Preprocess files into normalized 256-bin histograms → Train SGAN with alternating generator and discriminator updates → Use classifier portion of D/C for final predictions
- **Design tradeoffs**: Complex training process vs. superior accuracy, higher computational requirements vs. fewer labeled samples needed, potential instability in adversarial training vs. robust feature learning
- **Failure signatures**: Mode collapse in generator producing limited variety of samples, discriminator overfitting to training data, poor separation between real and fake samples during training
- **First 3 experiments**: Train SGAN with full supervision (all samples labeled) and measure accuracy, reduce labeled samples to 50 and compare performance degradation, replace SGAN with standalone MLP using same architecture and compare results

## Open Questions the Paper Calls Out

### Open Question 1
How would the SGAN classifier perform with a larger, more diverse dataset that includes more file types and greater representation across classes? The study only used a subset of the Govdocs1 corpus, and performance on a more comprehensive dataset remains untested.

### Open Question 2
How sensitive is the SGAN's classification accuracy to adversarial modifications of file byte distributions, such as deliberate obfuscation or corruption? The robustness of the model to various forms of byte-level tampering or adversarial attacks is not fully characterized.

### Open Question 3
Can the generator component of the SGAN be leveraged to improve the performance of other machine learning algorithms through data augmentation? The potential benefits of using GAN-generated synthetic samples for training non-GAN classifiers are hypothesized but not demonstrated.

## Limitations
- Limited evaluation scope: Only tested on 11 file types from the Govdocs1 dataset with 2,860 total samples
- Ablation studies incomplete: Lacks experiments comparing pure supervised GAN vs semi-supervised GAN performance
- Real-world obfuscation scenarios not tested: Only basic header modification was evaluated

## Confidence
- **High confidence**: SGAN achieves state-of-the-art accuracy (97.6%) on the tested dataset when fully supervised
- **Medium confidence**: Semi-supervised performance claims (82% with 50 labeled samples) due to lack of comparison with other semi-supervised baselines
- **Medium confidence**: Adversarial training advantage over traditional ML, as the comparison was limited to 4 other algorithms without broader benchmark context

## Next Checks
1. **Cross-dataset validation**: Test the SGAN on alternative file corpora (e.g., different document collections or malware datasets) to assess generalization
2. **Semi-supervised ablation**: Compare SGAN performance against a purely supervised GAN and traditional semi-supervised learning approaches on the same data
3. **Robustness testing**: Evaluate classification accuracy against various obfuscation methods including encryption, compression, and polymorphic file generation
