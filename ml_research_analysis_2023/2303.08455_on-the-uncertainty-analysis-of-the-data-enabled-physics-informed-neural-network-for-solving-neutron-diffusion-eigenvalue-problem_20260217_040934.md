# On the uncertainty analysis of the data-enabled physics-informed neural network for solving neutron diffusion eigenvalue problem

## Quick Facts
- arXiv ID: 2303.08455
- Source URL: https://arxiv.org/abs/2303.08455
- Reference count: 37
- This paper examines the robustness of DEPINN for neutron diffusion eigenvalue problems with noisy prior data

## Executive Summary
This paper investigates the performance of the data-enabled physics-informed neural network (DEPINN) when solving neutron diffusion eigenvalue problems with noisy prior data. The authors propose an innovative interval loss function that transforms the original PDE system into an inequality-constrained system, allowing for uncertainty in prior data without forcing convergence to noisy values. The study demonstrates that this approach, combined with adaptive weighting based on noise levels, significantly improves the robustness and accuracy of DEPINN in handling noisy measurements from reactor detectors.

## Method Summary
The paper presents a DEPINN framework that incorporates interval loss functions to handle noisy prior data in neutron diffusion eigenvalue problems. The method transforms the original PDE system into an inequality-constrained system by constraining predictions to lie within bounds derived from noisy data. Adaptive weights inversely proportional to noise variance are applied to prior loss terms. The approach is validated on two benchmark reactor physics problems (spherical and cylindrical geometries) with various noise levels (0-20%) and compared against standard SSE loss functions.

## Key Results
- Interval loss functions reduce noise effects and improve utilization of noisy prior data in DEPINN
- Adaptive weighting based on noise levels enhances model robustness and prediction accuracy
- The proposed method maintains feasibility for practical engineering applications in nuclear reactor physics
- DEPINN with interval loss outperforms standard SSE loss on benchmark problems with various noise scales

## Why This Works (Mechanism)

### Mechanism 1
The interval loss function reduces noise effects by constraining predictions to lie within bounds [1/(1+σi) φp(xi), 1/(1-σi) φp(xi)] derived from noisy data rather than penalizing direct deviation. This allows for uncertainty without forcing convergence to noisy values. The core assumption is that noise levels σi are known and the true solution lies within computed interval bounds.

### Mechanism 2
Adaptive weighting based on noise level improves robustness by emphasizing higher-confidence data points. Weights are set inversely proportional to noise level (1/σ²ᵢ, capped at 10,000), giving more influence to low-noise measurements. This requires noise variance to be known for each data point and independent across points.

### Mechanism 3
Transforming the PDE system into an inequality-constrained system via interval loss improves training stability. By enforcing inequality constraints instead of exact equality on noisy data, the optimization landscape becomes less sensitive to noise, enabling better convergence. The optimization algorithm must find parameters satisfying inequality constraints while minimizing residual and boundary losses.

## Architecture Onboarding

- Component map: Benchmark problem generation -> Prior data sampling with noise -> Interval loss computation -> Adaptive weighting -> PINN training with Adam/LBFGS -> Evaluation metrics
- Critical path: 1) Load benchmark problem and generate analytical solution 2) Sample prior points and inject synthetic noise 3) Compute interval bounds based on noise levels 4) Train PINN using interval loss with adaptive weights 5) Evaluate predictions against analytical solution
- Design tradeoffs: Interval loss vs SSE (robust to noise but requires accurate noise estimates vs simpler but sensitive to outliers); Fixed vs adaptive weights (improves robustness but adds complexity); Number of prior points (more improve accuracy but increase cost)
- Failure signatures: High variance in predictions across runs (interval bounds too wide or weights poorly calibrated); Systematic bias from true solution (noise estimates underestimated or model underconstrained); Training instability or divergence (learning rates too high or loss components poorly balanced)
- First 3 experiments: 1) Run DEPINN on Case-1 with σ=0.01 noise and SSE loss to establish baseline performance 2) Repeat with interval loss and compare variance and accuracy metrics 3) Test adaptive weighting by varying noise levels across prior points and observing error reduction

## Open Questions the Paper Calls Out

### Open Question 1
How does the interval loss function perform on real-world experimental data with noise compared to synthetic noise models? The paper demonstrates effectiveness on benchmark problems with synthetic noise but does not test it on actual experimental data, leaving uncertainty about real-world performance.

### Open Question 2
What is the optimal number of prior data points for balancing prediction accuracy and computational cost in DEPINN? The paper shows increasing prior points improves performance but notes the high cost of obtaining more data points in engineering experiments without providing clear guidelines.

### Open Question 3
How does the adaptive weighting method for prior loss terms perform with non-uniform noise distributions? The paper proposes adaptive weighting based on noise levels but only tests with uniform noise distributions, leaving the effectiveness under non-uniform distributions unexplored.

### Open Question 4
Can the interval loss function be extended to handle multi-group diffusion equations in nuclear reactor physics? The paper demonstrates the interval loss function on mono-energetic diffusion equations but does not explore its application to more complex multi-group equations.

## Limitations
- Noise level estimation is assumed known, which rarely holds in practice
- Only synthetic benchmark problems tested, not real reactor data
- Limited comparison to alternative uncertainty handling methods in PINNs
- No sensitivity analysis on neural network architecture choices
