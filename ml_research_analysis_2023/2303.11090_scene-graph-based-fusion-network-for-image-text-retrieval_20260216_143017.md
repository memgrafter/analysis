# Scene Graph Based Fusion Network For Image-Text Retrieval

## Quick Facts
- arXiv ID: 2303.11090
- Source URL: https://arxiv.org/abs/2303.11090
- Reference count: 0
- Primary result: SGFN outperforms state-of-the-art methods on Flickr30K and MSCOCO datasets with significant recall rate improvements

## Executive Summary
This paper introduces a Scene Graph based Fusion Network (SGFN) for image-text retrieval that leverages hierarchical attention mechanisms to fuse intra-modal and cross-modal features. The approach constructs scene graphs for both images and texts, then uses global agent vectors to guide the fusion process. SGFN demonstrates superior performance on benchmark datasets compared to existing methods, with particular emphasis on incorporating semantic contexts like objects, attributes, and relationships into feature representations.

## Method Summary
SGFN constructs scene graphs for images and texts to capture semantic relationships between objects, attributes, and interactions. The method employs hierarchical attention fusion that operates at multiple levels: first performing intra-modal fusion within each modality to enhance local feature representations, then conducting cross-modal fusion to align image and text features in a shared semantic space. Global agent vectors are used to guide the cross-modal fusion process, ensuring that contextual information is properly incorporated. The network is trained end-to-end using contrastive loss to maximize the similarity between matched image-text pairs while minimizing similarity for mismatched pairs.

## Key Results
- SGFN achieves state-of-the-art performance on Flickr30K and MSCOCO datasets
- Significant improvements in recall rates compared to baseline methods
- Ablation studies confirm the effectiveness of both intra-modal and cross-modal fusion components
- The hierarchical attention mechanism contributes substantially to retrieval accuracy

## Why This Works (Mechanism)
The method works by creating structured representations of visual and textual content through scene graphs, which capture fine-grained semantic relationships. By incorporating objects, attributes, and relationships into the feature vectors, SGFN creates richer representations that better align across modalities. The hierarchical attention fusion allows the network to selectively focus on relevant semantic elements while suppressing noise. The use of global agent vectors provides a contextual framework that guides the cross-modal alignment process, ensuring that the fused representations maintain coherent semantic meaning across image and text modalities.
