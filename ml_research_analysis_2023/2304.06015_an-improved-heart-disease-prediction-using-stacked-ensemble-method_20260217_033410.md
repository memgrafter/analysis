# An Improved Heart Disease Prediction Using Stacked Ensemble Method

## Quick Facts
- arXiv ID: 2304.06015
- Source URL: https://arxiv.org/abs/2304.06015
- Reference count: 32
- Primary result: Stacked ensemble achieved 91.06% accuracy on heart disease prediction, outperforming individual models like RF (89.36%) and XGBoost (89.78%)

## Executive Summary
This study proposes a stacked ensemble method for heart disease prediction that combines nine classification algorithms to improve predictive accuracy. The ensemble approach integrates Random Forest, Multi-Layer Perceptron, K-Nearest Neighbors, Extremely Randomized Trees, XGBoost, Support Vector Classifier, AdaBoost, Decision Tree, and Gradient Boosting Machine. The methodology includes preprocessing steps such as outlier removal, missing value handling, and feature normalization to enhance model performance.

The proposed stacked classifier achieved superior performance metrics including 91.06% accuracy, 0.934 sensitivity, 0.883 specificity, 0.916 F1 score, 0.909 ROC, and 3.086 log loss. These results demonstrate the effectiveness of ensemble methods in improving heart disease classification accuracy compared to individual models.

## Method Summary
The core methodology employs a stacked ensemble approach that combines nine different classification algorithms: Random Forest, Multi-Layer Perceptron, K-Nearest Neighbors, Extremely Randomized Trees, XGBoost, Support Vector Classifier, AdaBoost, Decision Tree, and Gradient Boosting Machine. The preprocessing pipeline includes outlier removal, missing value imputation, and feature normalization to prepare the data for model training. The stacked ensemble is designed to leverage the strengths of multiple algorithms while mitigating their individual weaknesses through meta-learning.

## Key Results
- Stacked ensemble achieved 91.06% accuracy, outperforming individual models RF (89.36%) and XGBoost (89.78%)
- Sensitivity reached 0.934 and specificity achieved 0.883, indicating strong performance on both positive and negative cases
- F1 score of 0.916 demonstrates balanced precision and recall in the classification task

## Why This Works (Mechanism)
The stacked ensemble method works by combining multiple diverse base learners, each capturing different patterns and relationships in the heart disease data. Random Forest and XGBoost handle non-linear relationships, while MLP captures complex feature interactions. The ensemble approach reduces variance through averaging predictions and mitigates individual model biases. Meta-learning in the stacking layer learns optimal weightings for combining base model predictions, leading to improved overall performance.
