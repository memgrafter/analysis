# T2Ranking: A large-scale Chinese Benchmark for Passage Ranking

## Quick Facts
- **arXiv ID**: 2304.03679
- **Source URL**: https://arxiv.org/abs/2304.03679
- **Reference count**: 33
- **Primary result**: T2Ranking is a large-scale Chinese benchmark for passage ranking with 300K+ queries and 2M+ passages, featuring 4-level fine-grained relevance annotations and active learning-based data collection

## Executive Summary
T2Ranking addresses the critical need for high-quality Chinese passage ranking datasets by providing a large-scale benchmark with over 300K queries and 2M passages. The dataset features fine-grained 4-level relevance annotations and employs advanced data collection techniques including model-based passage segmentation, clustering-based de-duplication, and active learning for efficient annotation. Experimental results show the dataset is challenging for both retrieval and re-ranking tasks, with dense retrievers achieving MRR@10 of 0.519 and cross-encoders reaching nDCG@20 of 0.515. The benchmark provides a robust resource for developing and evaluating Chinese information retrieval systems.

## Method Summary
T2Ranking employs a multi-stage data collection pipeline starting with query sampling from search engines, followed by document retrieval and model-based passage segmentation. Hierarchical clustering removes duplicate passages while preserving diversity, and active learning efficiently selects informative samples for expert annotation. The resulting dataset contains 307K queries and 2.3M passages with 4-level fine-grained relevance annotations. Both retrieval and re-ranking tasks are supported, with evaluation using standard IR metrics including MRR, Recall, and nDCG.

## Key Results
- Dense retrievers (DE w/ Mined Neg) achieve MRR@10 of 0.519 and Recall@50 of 0.736
- Cross-encoders reach nDCG@20 of 0.515 for re-ranking
- BM25 sparse retriever achieves MRR@10 of 0.324 and Recall@50 of 0.612
- The dataset demonstrates significant challenges for both retrieval and re-ranking models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Active learning improves annotation efficiency by focusing on uncertain samples
- Mechanism: The model selects query-passage pairs with low confidence scores for annotation, avoiding redundant high-confidence or noisy low-confidence samples
- Core assumption: Model uncertainty correlates with annotation value
- Evidence anchors:
  - [section] "pairs with low confidence scores, which are typically considered noise samples, are also eliminated"
  - [section] "pairs with the highest uncertainty or informativeness are selected for annotation"
- Break condition: If model confidence scores become uniformly distributed, active learning loses its selection advantage

### Mechanism 2
- Claim: Model-based passage segmentation preserves semantic integrity better than heuristic methods
- Mechanism: A segmentation model trained on well-written documents (Baidu Baike, Sogou Baike, Wikipedia) predicts paragraph boundaries based on semantic coherence
- Core assumption: Well-written documents have clear semantic boundaries that generalize to web documents
- Evidence anchors:
  - [section] "we employ a model-based method for passage segmentation to maximize the preservation of complete semantics in each passage"
  - [section] "Given a web document d = {wd} |d| d=1, we utilize a segmentation model Seg(·) to determine whether a given word wd should be separated"
- Break condition: If test documents have significantly different writing styles than training documents, segmentation quality degrades

### Mechanism 3
- Claim: Clustering-based de-duplication improves annotation diversity while maintaining efficiency
- Mechanism: Hierarchical clustering (Ward algorithm) groups similar passages, selecting one representative from each cluster for annotation
- Core assumption: Passages within the same cluster are nearly identical and provide minimal additional information
- Evidence anchors:
  - [section] "we employ a hierarchical clustering algorithm, Ward [26], to unsupervisedly cluster similar passages together"
  - [section] "passages that are nearly identical under a specific query provide little information gain to a ranking model compared to passages with significant differences"
- Break condition: If clustering threshold is too high, diverse passages may be incorrectly grouped together

## Architecture Onboarding

- Component map: Query pool → Document retrieval (Sogou, Baidu, Google) → Model-based passage segmentation → Clustering-based de-duplication → Active learning-based sampling → Expert annotation → Dataset construction
- Critical path: Query sampling → Document retrieval → Passage extraction → Relevance annotation
- Design tradeoffs: 
  - More documents retrieved increases recall but also annotation cost
  - Lower clustering thresholds reduce redundancy but may lose diversity
  - Higher active learning selection confidence reduces annotation but may miss informative samples
- Failure signatures:
  - Low diversity in final dataset suggests clustering threshold too high
  - Poor retrieval performance suggests passage segmentation issues
  - High annotation cost suggests active learning not effectively filtering samples
- First 3 experiments:
  1. Run segmentation model on sample documents and verify semantic coherence
  2. Test clustering on sample passages to find optimal similarity threshold
  3. Validate active learning selection by comparing annotated vs. non-annotated sample quality

## Limitations
- Annotation quality depends on expert annotator consistency, but no inter-annotator agreement data is provided
- The benchmark focuses specifically on Chinese web documents, limiting generalizability to other languages or domains
- The effectiveness of different negative mining strategies is not thoroughly analyzed

## Confidence
- High confidence: Dataset size and annotation quality claims
- Medium confidence: Active learning efficiency claims (mechanism sound but not empirically validated)
- Medium confidence: Clustering-based de-duplication effectiveness (mechanism clear but parameter sensitivity not fully explored)

## Next Checks
1. Run ablation studies on clustering threshold: Systematically vary the similarity threshold used in hierarchical clustering to quantify the tradeoff between annotation efficiency and dataset diversity.

2. Evaluate segmentation quality across document types: Test the passage segmentation model on documents from different domains (news, forums, academic) to measure performance degradation and identify failure modes.

3. Analyze active learning selection quality: Compare the distribution of relevance scores in samples selected by active learning versus random sampling to verify that the method is indeed selecting more informative instances.
