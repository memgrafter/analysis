# Unpaired Translation from Semantic Label Maps to Images by Leveraging Domain-Specific Simulations

## Quick Facts
- arXiv ID: 2302.10698
- Source URL: https://arxiv.org/abs/2302.10698
- Reference count: 40
- Primary result: Outperforms state-of-the-art unpaired translation methods on laparoscopy, ultrasound, and driving scene datasets while providing approximate semantic segmentation of real images without annotations.

## Executive Summary
This work addresses the challenge of generating photorealistic images from semantic label maps when paired data is unavailable. The proposed method leverages domain-specific simulations by using simulated images as surrogate targets for a contrastive loss, while ensuring content preservation through a reverse translation network. This approach enables bidirectional label-image translations without requiring complex simulations during inference. The method demonstrates superior performance across laparoscopy, ultrasound, and driving scene datasets, generating realistic and scene-accurate translations while also providing approximate semantic segmentation of real images without requiring annotations.

## Method Summary
The method addresses unpaired translation from semantic label maps to photorealistic images by leveraging available domain-specific simulations. It uses simulated images as surrogate targets for a contrastive loss, where the forward generator translates labels to images and the reverse generator translates images to labels. The contrastive loss aligns features between translated images and their paired simulated images, while cycle consistency ensures bidirectional feature alignment. Patch-based contrastive loss is employed to be less sensitive to appearance shifts between simulated and real domains. The architecture consists of two generators (label-to-image and image-to-label), two discriminators, and projection heads for the contrastive space, trained with alternating objectives including GAN loss, contrastive loss, and cycle consistency loss.

## Key Results
- Outperforms state-of-the-art unpaired translation methods in realism (FID, KID) and content preservation (SSIM, IoU, mAP/pixAcc/classAcc) across laparoscopy, ultrasound, and gaming datasets
- Provides approximate semantic segmentation of real images without requiring annotations, achieving F1 scores of 72.7 on CholecSeg8k and 53.3 on Cityscapes
- Ablation study demonstrates that the simulation surrogate (SimIT-C) is crucial for content preservation, with SimIT-CS producing content hallucination without it

## Why This Works (Mechanism)

### Mechanism 1
The contrastive loss between simulated images and translated images preserves semantic content while allowing style transfer. Simulated images paired with label-maps act as surrogate ground truth for the contrastive loss, aligning translated features with semantically consistent but visually different simulated features. This works because simulated and real images share the same semantic content despite differing appearance, and patch-level features can be meaningfully contrasted. If simulated images contain content that does not align with real images, the contrastive loss will pull the wrong features together, degrading content preservation.

### Mechanism 2
Cycle consistency with an image-to-label translator provides bidirectional feature alignment, improving content preservation over unidirectional approaches. The reverse translation network (image-to-label) extracts features that are domain-consistent with images, allowing the contrastive loss to pull features from both domains toward each other, ensuring that the forward translation (label-to-image) preserves content. This assumes features extracted from the reverse translation network are better aligned with image features than features from the label-to-image encoder. If the cycle loss is too weak or the reverse network fails to extract meaningful features, the bidirectional benefit disappears.

### Mechanism 3
Patch-based contrastive loss is less sensitive to appearance shifts than pixel-wise losses, making it suitable for bridging the appearance gap between simulated and real images. By contrasting patches rather than pixels, the loss focuses on local structural consistency and semantic alignment, ignoring global appearance differences like lighting and texture. This works because local patches in simulated and real images with the same semantic content will have similar feature representations in the learned space. If the feature space learned by the projection head does not align semantically similar patches, the loss will fail to enforce content preservation.

## Architecture Onboarding

- Component map:
  Generator G (Label-to-image): LS_S -> GE -> feature -> GD -> IS
  Generator F (Image-to-label): IR_RR -> FE -> feature -> FD -> label
  Discriminator DI: Real/fake image discriminator
  Discriminator DL: Real/fake label discriminator
  Projection heads HG, HF: Map encoder features to contrastive space

- Critical path:
  1. Forward pass: Label LS -> GE -> feature -> GD -> translated image IS
  2. Contrastive pass: Extract features from IS and paired simulated image IS, compute NCE loss
  3. Cycle pass: Image IR -> FE -> feature -> FD -> label, then reconstruct image, compute NCE loss
  4. Adversarial pass: DI and DL distinguish real from fake in both directions

- Design tradeoffs:
  Using simulated images as surrogate targets avoids needing paired real-label data but assumes simulation and real content alignment. Patch-based contrastive loss is robust to appearance shifts but may miss global structure. Bidirectional training improves content preservation but doubles model complexity and training time.

- Failure signatures:
  Content hallucination: If contrastive loss fails, translated images will contain structures not present in input labels. Mode collapse: If discriminators overpower generators, outputs may become repetitive or unrealistic. Feature misalignment: If projection heads do not learn meaningful embeddings, contrastive loss will not enforce content preservation.

- First 3 experiments:
  1. Train SimIT-CS (no simulation surrogate) on a small dataset; observe content hallucination in outputs
  2. Train SimIT-C (with simulation surrogate, no cycle loss) and compare content preservation to SimIT-CS
  3. Train full SimIT and evaluate segmentation quality on real images without labels

## Limitations
- Limited scalability claim across diverse domains, as experiments cover only three specific domains with limited dataset sizes
- Confidence is Medium for patch-based contrastive loss being inherently more robust to appearance shifts than pixel-wise losses
- Computational efficiency compared to traditional rendering methods is not directly evaluated

## Confidence
- High: Using simulated images as surrogate targets for contrastive loss enables content preservation during unpaired translation
- Medium: Patch-based contrastive loss is inherently more robust to appearance shifts than pixel-wise losses
- Low: Scalability across diverse domains beyond the three studied (laparoscopy, ultrasound, gaming)

## Next Checks
