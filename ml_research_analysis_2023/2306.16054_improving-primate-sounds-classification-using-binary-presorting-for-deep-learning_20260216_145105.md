# Improving Primate Sounds Classification using Binary Presorting for Deep Learning

## Quick Facts
- arXiv ID: 2306.16054
- Source URL: https://arxiv.org/abs/2306.16054
- Reference count: 40
- Achieved 91.72% UAR on ComparE 2021 primate sounds dataset test set

## Executive Summary
This paper presents a binary presorting approach to improve primate sound classification from the challenging ComparE 2021 dataset. The method first trains a binary classifier to distinguish primate sounds from background noise on spectrogram images, then uses this model to re-label noisy segments before training the final multi-class classifier. The approach incorporates data augmentation and local adaptive thresholding techniques. Results demonstrate significant improvement over baseline models, achieving 91.72% UAR compared to 82.86% on the test set.

## Method Summary
The binary presorting approach addresses the challenges of noisy, weakly labeled, and imbalanced primate sound data by first segmenting audio into fixed-length segments and converting them to spectrograms. A binary classifier is trained to distinguish between background noise and primate sounds, which is then used to re-label uncertain segments. This re-labeled data is used to train the final multi-class classifier. The method employs data augmentation techniques including pitch shifting, time stretching, and noise addition to improve model robustness. Local adaptive thresholding is applied to enhance spectrogram quality and reduce noise artifacts.

## Key Results
- Binary presorting achieved 91.72% UAR on test set versus 82.86% for baseline
- Data augmentation contributed to performance improvements
- Local adaptive thresholding enhanced spectrogram quality
- Binary presorting serves as effective pretraining for multi-class tasks

## Why This Works (Mechanism)
Binary presorting works by first separating signal from noise at a coarse level, which reduces the burden on the subsequent multi-class classifier. By training on cleaner, more reliably labeled data, the final model can focus on distinguishing between primate species rather than filtering out noise. This two-stage approach effectively reduces the complexity of the classification task by transforming a noisy multi-class problem into a cleaner binary-to-multi-class pipeline.

## Architecture Onboarding

Component Map:
Audio segmentation -> Spectrogram conversion -> Binary classification -> Segment re-labeling -> Multi-class classification -> Performance evaluation

Critical Path:
Audio preprocessing (segmentation + spectrogram) -> Binary classifier training -> Segment re-labeling -> Multi-class classifier training -> Evaluation

Design Tradeoffs:
- Fixed segment length vs. variable-length analysis: fixed length simplifies processing but may cut through sounds
- Binary classifier complexity vs. speed: more complex models may improve accuracy but increase training time
- Augmentation intensity vs. signal preservation: aggressive augmentation improves robustness but may distort genuine features

Failure Signatures:
- High false positive rate in binary classifier indicates poor noise detection
- Low multi-class accuracy despite good binary performance suggests re-labeling errors
- Performance degradation with new datasets indicates overfitting to training conditions

First Experiments:
1. Test binary classifier accuracy on held-out noise segments
2. Measure improvement in multi-class performance when using re-labeled vs. original labels
3. Evaluate different segment lengths to optimize trade-off between context and processing efficiency

## Limitations
- Effectiveness may be dataset-specific to ComparE 2021 characteristics
- Methodology relies on spectrogram segmentation that could introduce processing variability
- Limited exploration of different deep learning architectures beyond tested models
- Data augmentation contributions not comprehensively validated

## Confidence
High confidence in binary presorting effectiveness for this specific dataset and task.
