# A Framework for Learning from Demonstration with Minimal Human Effort

## Quick Facts
- arXiv ID: 2306.09211
- Source URL: https://arxiv.org/abs/2306.09211
- Reference count: 33
- Key outcome: Achieved 758 cumulative cost (vs 934-1613 for baselines) in block pushing task over 1200 episodes by minimizing human effort through selective controller choice

## Executive Summary
This paper presents a framework for robot learning from demonstration (LfD) in shared autonomy settings that minimizes human effort. The approach uses contextual multi-armed bandits with continuous correlated beta processes to estimate success probabilities for different controllers (human teleoperation and autonomous) given initial states. An autonomous controller is learned online using deep deterministic policy gradients with demonstrations. The framework is evaluated on simulated block pushing and navigation tasks, plus one real-world navigation task, showing reduced human cost compared to baselines while improving autonomous performance over time.

## Method Summary
The framework addresses shared autonomy by predicting success probabilities for autonomous controllers and using contextual multi-armed bandits for controller selection. It employs continuous correlated beta processes to estimate success probabilities and uncertainties for each controller given initial states. The contextual MAB algorithm selects between human teleoperation and autonomous controllers based on these estimates. An autonomous controller is learned online using DDPG with demonstrations, incorporating behavior cloning and a Q-filter. The system uses a sliding window approach to handle non-stationary controller performance during learning.

## Key Results
- Block pushing task: Contextual MAB achieved 758 cumulative cost vs 934-1613 for baselines over 1200 episodes
- Simulated navigation: Human demonstrations reduced failures by 23% compared to autonomous controller alone
- Real-world navigation: System successfully reduced human effort while maintaining task performance across 300 episodes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Contextual multi-armed bandit with upper confidence bounds enables selective controller choice that minimizes total human cost.
- Mechanism: The framework estimates success probabilities and uncertainties for each controller given the initial state. It then selects the controller with minimum optimistic cost estimate (Equation 8), balancing exploration and exploitation to reduce failures and human demonstrations.
- Core assumption: The probability of success for each controller varies smoothly across the state space, enabling accurate estimation with limited data.
- Evidence anchors:
  - [abstract] "A continuous correlated beta process estimates these probabilities while accounting for uncertainty"
  - [section IV-B] "In a CCBP we assume p(s) is a smooth function, such that the Bernoulli trials are correlated, and experience can be shared between them"
  - [corpus] Weak - no direct evidence in related papers about this specific mechanism
- Break condition: If the state space is not smooth or if controller performance changes abruptly between episodes, the CCBP estimates become unreliable and controller selection degrades.

### Mechanism 2
- Claim: Learning an autonomous controller online with demonstrations and reinforcement learning reduces reliance on human teleoperation over time.
- Mechanism: The framework uses DDPG with demonstrations where successful episodes from all controllers are added to replay buffer, and demonstrations are incorporated via behavior cloning with Q-filter. This allows the autonomous policy to improve from both human demonstrations and its own experience.
- Core assumption: The autonomous controller can learn from demonstrations and improve its performance through reinforcement learning.
- Evidence anchors:
  - [abstract] "A controller is learnt online from demonstrations and reinforcement learning so that autonomous performance improves"
  - [section IV-C] "We adapt the approach from [3] to incorporate demonstrations into DDPG using behaviour cloning and a Q-filter"
  - [corpus] Weak - related papers focus on imitation learning but don't specifically address this combined DDPG+demonstration approach
- Break condition: If the demonstrations are poor quality or the task is too complex to learn from limited data, the autonomous controller may not improve sufficiently to reduce human reliance.

### Mechanism 3
- Claim: Using a sliding window for recent outcomes in the CCBP accounts for non-stationary controller performance during learning.
- Mechanism: For the controller being learned online, only the most recent m episodes are considered in the CCBP estimation. This ensures that outdated performance estimates don't influence current controller selection.
- Core assumption: The policy changes gradually, such that recent outcomes approximate the performance of the current controller.
- Evidence anchors:
  - [section IV-B] "We follow the approach taken for GP value functions [30] and non-stationary MABs [27], and only consider recent data in the CCBP"
  - [abstract] "A continuous correlated beta process estimates these probabilities while accounting for uncertainty"
  - [corpus] Weak - related papers don't specifically discuss this sliding window approach for non-stationary MABs
- Break condition: If the policy changes rapidly or discontinuously, the sliding window may not capture current performance accurately, leading to poor controller selection.

## Architecture Onboarding

- Component map: CCBP probability estimator → Contextual MAB controller selector → Controller executor (human or autonomous) → Environment → Feedback loop with outcomes
- Critical path: Initial state → CCBP estimation → MAB selection → Controller execution → Outcome → Update CCBP → Next episode
- Design tradeoffs: Sliding window size m balances between capturing current policy performance vs having enough data for reliable estimates; α value in MAB balances between asking for demonstrations vs exploring autonomous controllers
- Failure signatures: High variance in CCBP estimates indicates insufficient data; consistently choosing human controller suggests poor autonomous learning; increasing failures despite demonstrations suggests demonstrations are not informative
- First 3 experiments:
  1. Implement CCBP with synthetic data to verify probability estimation and uncertainty quantification
  2. Implement contextual MAB selection with fixed controller success probabilities to verify cost minimization
  3. Implement DDPG with demonstrations on a simple control task to verify learning from both sources

## Open Questions the Paper Calls Out

- How does the choice of the length scale hyperparameter l affect the performance of the Continuous Correlated Beta Process (CCBP) in predicting controller success probabilities across different domains? The paper mentions different values were found for different domains but doesn't analyze sensitivity to this hyperparameter.

- How does the performance of the proposed framework compare to other approaches when the human operator is prone to making mistakes? The current framework assumes perfect human performance, but the authors plan to apply it to problems with imperfect human operators.

- How does the proposed framework perform when extended to sequential decision-making problems involving multiple controller selections? The current framework is evaluated in episodic settings, but the authors plan to extend it to sequential decision-making problems.

## Limitations

- The framework's effectiveness depends heavily on the smoothness assumption of controller performance across the state space, which may not hold in all domains.
- The real-world validation is limited to one navigation task, which may not generalize to more complex or diverse robotic applications.
- The paper doesn't fully explore how the sliding window size for non-stationary performance affects overall system performance.

## Confidence

- High confidence in the core mechanism of using contextual multi-armed bandits for controller selection, as this is a well-established approach in decision-making under uncertainty.
- Medium confidence in the continuous correlated beta process implementation, as the paper provides theoretical justification but limited empirical validation of its effectiveness.
- Medium confidence in the DDPG with demonstrations approach, as the specific implementation details are not fully specified and may require significant tuning for different domains.

## Next Checks

1. Conduct ablation studies varying the sliding window size m in the CCBP to quantify its impact on controller selection accuracy and overall cost minimization across different task complexities.

3. Compare the proposed approach against alternative controller selection strategies (e.g., Thompson sampling, epsilon-greedy) in terms of sample efficiency and total cost, to validate the superiority of the contextual MAB approach with upper confidence bounds.
