# Small-footprint slimmable networks for keyword spotting

## Quick Facts
- arXiv ID: 2304.12183
- Source URL: https://arxiv.org/abs/2304.12183
- Reference count: 0
- Primary result: Slimmable neural networks can match or outperform individually trained models for keyword spotting while enabling efficient training of multiple model sizes simultaneously

## Executive Summary
This paper introduces slimmable neural networks for small-footprint keyword spotting, enabling a single super-network to generate sub-networks of varying sizes for different memory and compute constraints. The approach works by sharing weights across different widths during training, with each width computing gradients on the same batch and summing them to update the full network. Experiments on both in-house and Google Speech Commands datasets demonstrate that slimmable models can match or outperform models trained from scratch, while reducing training time per step by a factor of 4 compared to training individual models.

## Method Summary
The method trains a single super-network that can derive sub-networks of varying sizes through weight sharing across different widths. During training, a width list (1.0, 0.75, 0.50, 0.25) defines the available model sizes. Each width computes predictions and gradients on the same batch, with gradients aggregated across all widths to update shared parameters. Switchable batch normalization layers are used for each width to maintain proper normalization statistics. For CNNs, weights are shared across convolution layers by dropping kernels, while for Transformers, weights are shared across dense layers in each block. This approach enables efficient training of multiple model sizes simultaneously while maintaining performance comparable to individually trained models.

## Key Results
- Slimmable models match or outperform individually trained models on both in-house and Google Speech Commands datasets
- Training time per step is reduced by a factor of 4 compared to training individual models
- Slimmable CNNs with 5 layers and 199k parameters achieve strong performance on keyword spotting tasks
- Slimmable Transformers based on KWT architecture with 120k parameters also demonstrate effectiveness

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Weight sharing across different widths during training allows a single super-network to generate multiple sub-networks with varying computational requirements.
- Mechanism: The slimmable training approach trains all widths simultaneously by computing gradients for each width on the same batch and summing them to update the full network. This creates a shared parameter space where smaller widths drop kernels or neurons while maintaining weight connections to the larger network.
- Core assumption: Gradients computed at different widths are compatible and can be meaningfully summed to update shared parameters.

### Mechanism 2
- Claim: Switchable batch normalization layers enable proper normalization for each width configuration during both training and inference.
- Mechanism: Each width has its own batch normalization layer that activates based on the current width setting. This prevents normalization statistics from one width interfering with another width's training dynamics.
- Core assumption: Separate batch normalization parameters for each width don't significantly increase memory overhead and maintain consistent statistical properties.
- Evidence anchors:
  - [section 3.1] "We also used switchable BatchNorm which assigns a separate BatchNorm layer [2] for each width."
  - [section 3.2] "For each width, a separate LayerNorm layer is used such that a particular layer that is assigned to that width is selected at run-time."

### Mechanism 3
- Claim: The distillation effect from shared weights across widths improves performance of sub-networks compared to individually trained models of the same size.
- Mechanism: During training, each sub-network benefits from knowledge contained in the larger network through shared parameters, creating an implicit knowledge distillation process where smaller widths learn from the representational capacity of larger ones.
- Core assumption: Knowledge transfer through shared weights provides meaningful inductive bias that improves generalization of sub-networks.
- Evidence anchors:
  - [abstract] "Slimmable models can match (and in some cases, outperform) models trained from scratch."
  - [section 4.2] "For the slimmable transformer, this pattern also holds true" - referring to slimmable models being slightly better than individually trained models.
  - [corpus] Weak - corpus papers discuss knowledge distillation and continual learning but don't specifically address the distillation effect in slimmable networks.

## Architecture Onboarding

- Component map:
  Super-network -> Width list [1.0, 0.75, 0.50, 0.25] -> Switchable normalization layers -> Slimmable layers -> Gradient aggregation system

- Critical path:
  1. Initialize super-network with shared weights and switchable layers
  2. During training: iterate through width list, compute predictions and gradients for each width
  3. Aggregate gradients across all widths
  4. Update shared parameters with aggregated gradients
  5. During inference: select appropriate width and corresponding normalization parameters

- Design tradeoffs:
  - Wider width ranges provide more deployment flexibility but may reduce performance of individual sub-networks
  - More widths increase training time per step but provide finer-grained control over resource-accuracy tradeoffs
  - Switchable normalization adds memory overhead but is essential for stable training

- Failure signatures:
  - Degraded performance on narrower widths may indicate gradient aggregation issues
  - Training instability could suggest batch normalization statistics are diverging across widths
  - Sub-networks performing worse than individually trained models might indicate poor width list selection

- First 3 experiments:
  1. Train a simple CNN with two widths (1.0 and 0.5) on a small dataset to verify basic weight sharing and gradient aggregation works
  2. Compare performance of slimmable model vs individually trained models at each width to confirm distillation effect
  3. Profile training time per step for increasing numbers of widths to verify the claimed efficiency gains

## Limitations

- Empirical validation limited to specific architecture configurations and width lists
- Training efficiency claims based on per-step comparisons without accounting for potential convergence differences
- Results confined to small-footprint keyword spotting tasks with limited model sizes
- No exploration of depth slimming as an alternative or complementary approach to width slimming

## Confidence

- Confidence in core weight sharing mechanism: High
- Confidence in specific architectural implementations: Medium  
- Confidence in generalization to other tasks: Low

## Next Checks

1. Test slimmable networks with alternative width lists (e.g., [1.0, 0.8, 0.6, 0.4]) to assess sensitivity to width configuration choices and identify optimal spacing between widths.
2. Compare convergence curves and total training time (not just per-step time) between slimmable training and training individual models to validate the claimed efficiency benefits.
3. Evaluate performance degradation when using a single batch normalization layer across all widths instead of switchable normalization to quantify the importance of this design choice.
