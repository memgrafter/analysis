# Learning in Factored Domains with Information-Constrained Visual Representations

## Quick Facts
- arXiv ID: 2303.17508
- Source URL: https://arxiv.org/abs/2303.17508
- Reference count: 18
- Models with smaller latent spaces learned factored reward structures faster in a contextual bandit task

## Executive Summary
This paper proposes a reinforcement learning model that uses β-VAEs to learn compressed, disentangled visual representations for efficient hypothesis generation in factored domains. The model generates and evaluates hypotheses about reward structures based on latent representations learned from visual stimuli. In a bandit task with face images wearing glasses or hats, the model demonstrated faster learning with smaller latent spaces by quickly identifying which features (glasses, hats) determine rewards. However, this came at the cost of reduced reconstruction accuracy, revealing a fundamental tradeoff between learning speed and visual fidelity in compressed representations.

## Method Summary
The RLβ-VAE model extends β-VAE to jointly learn visual representations and reward predictions. It uses the learned latent representations to generate hypotheses about factored reward structures through exhaustive search over possible feature partitions. The model evaluates these hypotheses using mean-squared error between predicted and observed rewards, selecting the best-fitting structure. Training involves optimizing the β-VAE objective with an additional reward prediction term, while hypothesis generation occurs after observing reward feedback. The model operates in a contextual bandit setting where faces wearing glasses, hats, or both receive different point values.

## Key Results
- Models with smaller latent spaces achieved high reward prediction accuracy after only 2 experiences
- Smaller latent dimensions resulted in significantly worse stimulus reconstructions
- The model successfully learned to predict rewards by summing linear functions of latent features representing glasses and hats
- The β parameter controlled the information bottleneck, trading off learning speed against reconstruction quality

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Compressed latent representations allow faster learning by enabling hypothesis generation in a reduced hypothesis space
- Mechanism: The model uses β-VAE to learn disentangled latent representations of visual stimuli. These representations are then used to generate and evaluate hypotheses about the reward structure. By working in a compressed latent space, the model can quickly form hypotheses about which features (e.g., glasses, hats) are relevant to rewards.
- Core assumption: The latent features learned by β-VAE are sufficiently disentangled to allow linear separation of reward-relevant factors.

### Mechanism 2
- Claim: Smaller latent spaces enable faster learning but reduce reconstruction accuracy
- Mechanism: The β-VAE's β parameter controls the information bottleneck, forcing the model to compress information into fewer latent dimensions. This compression makes hypothesis generation computationally cheaper and faster, but at the cost of losing fine-grained visual details needed for accurate reconstructions.
- Core assumption: There exists a tradeoff between the speed of learning and the accuracy of reconstructions that can be controlled via the β parameter.
- Evidence anchors:
  - [abstract]: "Modelling results demonstrate a trade-off in the informational complexity of model latent dimension spaces, between the speed of learning and the accuracy of reconstructions"
  - [section]: "These results demonstrate a lower end of training reconstruction accuracy from models with smaller latent spaces. While these small latent dimensions are useful for quick hypothesis generation, they make accurate reconstruction of stimuli more difficult"

- Core assumption: The reward structure can be factored into linear functions of latent features, and hypothesis evaluation can be done via mean-squared error.

## Architecture Onboarding

- Component map:
  - β-VAE encoder → latent representation
  - β-VAE decoder ← latent representation
  - Latent representation + action → reward predictor → predicted reward
  - Latent representation → hypothesis generator → set of hypotheses
  - Hypotheses + experience → hypothesis evaluator → ranked hypotheses

- Critical path:
  1. Visual stimuli → β-VAE encoder → latent representation
  2. Latent representation + action → reward predictor → predicted reward
  3. Latent representation → hypothesis generator → set of hypotheses
  4. Hypotheses + experience → hypothesis evaluator → ranked hypotheses
  5. Best hypothesis → factored reward structure

- Design tradeoffs:
  - β parameter: Controls information bottleneck (higher β = more compression, faster learning, worse reconstruction)
  - Latent dimension size: More dimensions = better reconstruction, slower learning; fewer dimensions = faster learning, worse reconstruction
  - Hypothesis complexity: Simpler hypotheses = faster evaluation, may miss complex reward structures; more complex hypotheses = slower evaluation, better capture of true reward structure

- Failure signatures:
  - High reconstruction error: Indicates too tight information bottleneck or insufficient model capacity
  - Poor reward prediction: Indicates latent representations not capturing reward-relevant features or incorrect hypothesis structure
  - Slow learning: Indicates either too loose information bottleneck (not enough compression) or overly complex hypothesis space

- First 3 experiments:
  1. Vary β parameter: Train models with different β values (e.g., 0.1, 1.0, 10.0) and compare learning speed and reconstruction accuracy
  2. Vary latent dimension size: Train models with different latent dimension sizes (e.g., 2, 5, 10) and compare learning speed and reconstruction accuracy
  3. Change reward structure: Modify the bandit task to have non-linear reward functions (e.g., multiplicative interactions between features) and test if the hypothesis generation method can still discover the correct structure

## Limitations
- The model assumes a known factored structure for the reward function, which may not hold in real-world scenarios
- The hypothesis generation method relies on exhaustive search over possible factorizations, which becomes computationally intractable as the number of latent features grows
- The results are based on a single synthetic task, limiting generalizability

## Confidence
The proposed mechanism linking compressed latent representations to faster hypothesis generation shows **Medium confidence** based on the evidence. While the theoretical framework connecting β-VAEs to efficient learning in factored domains is well-established, the empirical validation relies on a relatively simple synthetic task (face images with glasses/hats). The core claim that smaller latent spaces enable faster learning through compressed hypothesis spaces is supported by the results, but the evidence is primarily correlational rather than demonstrating direct causation.

The proposed tradeoff between learning speed and reconstruction accuracy demonstrates **Medium confidence**. The paper shows this relationship in controlled experiments, but doesn't fully explore the boundaries of this tradeoff or how it might manifest in more complex, real-world scenarios. The assumption that linear summation of latent features can capture reward structure is a simplifying assumption that may not hold in more complex domains.

## Next Checks
1. **Stress-test the information bottleneck tradeoff**: Systematically vary both the β parameter and latent dimension size across multiple orders of magnitude to identify the precise boundaries where learning speed and reconstruction accuracy begin to degrade catastrophically.

2. **Test non-linear reward structures**: Modify the bandit task to include non-linear reward functions (e.g., multiplicative interactions, threshold effects) to determine whether the hypothesis generation method can discover complex causal structures beyond simple linear summation.

3. **Evaluate scaling properties**: Apply the model to multi-object or sequential decision-making tasks with hundreds of latent features to assess how the computational complexity of hypothesis generation scales and whether approximation methods are needed.
