# Uncertainty Aware Active Learning for Reconfiguration of Pre-trained Deep Object-Detection Networks for New Target Domains

## Executive Summary
This paper proposes an active learning algorithm for object detection that efficiently queries frames from video data for annotation. The algorithm measures both classification and localization informativeness of unlabelled frames using three novel score functions, and aggregates them based on their inconsistency. A weight curve is introduced to avoid querying adjacent frames. The algorithm is compatible with any object detection model with regular output format. Experiments on MuPoTS and FootballPD datasets show that the proposed algorithm outperforms baseline methods, achieving higher mean average precision (mAP) with lower annotation cost. The inconsistency-based aggregation method and weight curve further improve performance. The algorithm is particularly effective for videos with more objects and higher occlusion.

## Method Summary
The proposed method measures informativeness using three score functions: classification uncertainty (entropy of class probabilities), localization uncertainty from instance count discontinuity (deviation from estimated instance curve), and localization uncertainty from bounding box changes (IoU-based). These scores are aggregated using an inconsistency-based function that computes the absolute difference between the maximum localization score and a weighted classification score. A weight curve biases the selection toward frames further from annotated ones to avoid redundancy. The process iterates: detect objects, calculate scores, aggregate with weights, select top frames for annotation, retrain model, and repeat until sufficient coverage.

- Outperforms baseline methods (Passive Selection and Classification only) on MuPoTS and FootballPD datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using temporal discontinuity in detected instance counts to measure localization uncertainty improves query efficiency.
- Mechanism: The algorithm fits an estimated instance curve based on initial guiding frames. Frames where the detected instance count deviates from this curve are flagged as having high localization uncertainty. This exploits the temporal continuity of object presence in videos.
- Core assumption: Object instances in video frames change smoothly over time, so sudden jumps in detected instance count indicate model uncertainty.

  - [corpus]: Weak evidence - the corpus contains related active learning papers but none specifically use temporal discontinuity in instance counts as described.
- Break condition: If objects frequently appear/disappear due to occlusion or scene changes, the assumption of temporal continuity breaks down.

### Mechanism 2
- Claim: Aggregating localization and classification uncertainty using inconsistency outperforms simple maximum or sum aggregation.
- Mechanism: Instead of adding or taking the maximum of classification and localization scores, the algorithm computes the absolute difference between the maximum of localization scores and a weighted classification score. This highlights frames where the model is uncertain in different ways simultaneously.
- Core assumption: High inconsistency between localization and classification uncertainty indicates a more informative frame than high values of either alone.

  - [abstract]: "Furthermore, a weight curve is proposed to avoid querying adjacent frames."
  - [corpus]: Weak evidence - the corpus has active learning papers but none explicitly test inconsistency-based aggregation as described.
- Break condition: If localization and classification uncertainty are always highly correlated, the inconsistency measure provides no additional information.

### Mechanism 3
- Claim: The weight curve prevents querying adjacent frames, improving training efficiency.
- Mechanism: A weight is assigned to each frame based on its distance from the nearest annotated frame. The weight is 0 at annotated frames and increases to 1 at midpoints between them. This biases the query selection toward frames that are further apart temporally.
- Core assumption: Adjacent frames contain redundant information, so spreading out annotated frames maximizes the information gained per annotation.
- Evidence anchors:
  - [section]: "Since the consecutive frames are likely to contain similar information, we proposed a weight curve to control the likelihood of selecting frames."
  - [abstract]: "Furthermore, a weight curve is proposed to avoid querying adjacent frames."
  - [corpus]: No direct evidence - the corpus contains active learning papers but none mention weight curves for avoiding adjacent frames.
- Break condition: If the video has rapidly changing scenes, the assumption that adjacent frames are similar may not hold.

## Architecture Onboarding

- Component map:
  Object detection model -> Score function calculators (classification uncertainty, localization uncertainty from instance count discontinuity, localization uncertainty from bounding box IoU) -> Aggregator (inconsistency-based function with dynamic balancing parameter) -> Weight curve generator -> Query selector

- Critical path:
  1. Run object detection on unannotated frames
  2. Calculate three informativeness scores for each frame
  3. Aggregate scores using inconsistency measure
  4. Apply weight curve to avoid adjacent frames
  5. Select top frames for annotation
  6. Annotate selected frames and add to training set
  7. Retrain object detection model

- Design tradeoffs:
  - Using temporal information vs. requiring video data (limits applicability to static images)
  - Complexity of three score functions vs. potential accuracy improvement
  - Dynamic balancing parameter vs. fixed parameter (adds computation but adapts to data)

- Failure signatures:
  - Poor performance on videos with frequent occlusion or scene changes (temporal continuity assumption breaks)
  - Weight curve causing large gaps in annotated frames (if video changes rapidly)
  - Aggregation function not improving over simple max/sum (if localization and classification uncertainty are highly correlated)

- First 3 experiments:
  1. Run on a simple video with few objects and minimal occlusion to verify basic functionality
  2. Test on a video with heavy occlusion to evaluate robustness to temporal discontinuity
  3. Compare performance with and without weight curve on a video with rapid scene changes

## Limitations
- Effectiveness depends on temporal continuity assumptions in videos, which may break down with frequent occlusion or rapid scene changes
- Specific weight curve parameters and shape not fully detailed, affecting reproducibility
- No rigorous theoretical proof that inconsistency-based aggregation outperforms simpler methods

## Confidence
**High Confidence**: The basic framework of using temporal information for active learning in object detection, and the general effectiveness of the proposed approach compared to baseline methods.

**Medium Confidence**: The specific mechanisms of the three informativeness score functions and their aggregation through inconsistency measurement. While the paper provides theoretical justification, the empirical validation could be more comprehensive.

**Low Confidence**: The robustness of the approach to videos that violate temporal continuity assumptions, and the optimality of the weight curve design.

## Next Checks
1. **Temporal Continuity Test**: Evaluate the algorithm on videos with controlled temporal discontinuities (e.g., inserted frames with different objects) to measure how performance degrades when the temporal continuity assumption is violated.

2. **Aggregation Method Comparison**: Conduct ablation studies comparing the inconsistency-based aggregation with maximum and sum aggregation methods across diverse video datasets to quantify the specific benefit of the proposed approach.

3. **Weight Curve Sensitivity Analysis**: Systematically vary the weight curve parameters (shape, gradient) and measure the impact on annotation efficiency and final mAP to determine the optimal configuration for different video characteristics.
