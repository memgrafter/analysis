# Counterfactual Explanations of Neural Network-Generated Response Curves

## Quick Facts
- arXiv ID: 2304.04063
- Source URL: https://arxiv.org/abs/2304.04063
- Reference count: 20
- Primary result: A method using counterfactual explanations and genetic algorithms identifies passive features with greatest impact on response curve shapes generated by neural networks

## Executive Summary
This paper introduces a novel method for analyzing the impact of passive features on neural network-generated response curves using counterfactual explanations. The approach employs a genetic algorithm to solve a multi-objective optimization problem that finds the minimal subset of passive features whose modification alters the shape of response curves. The method was validated on both synthetic and real-world crop yield prediction datasets, demonstrating its ability to identify feature combinations with the highest impact on responsivity.

## Method Summary
The proposed method involves training neural networks to generate response curves for an active feature, then using functional principal component analysis (fPCA) to transform these curves into a reduced dimensional space. A genetic algorithm (NSGA-II) is employed to solve a multi-objective optimization problem that finds the minimum number of passive features to modify such that the shape difference between original and counterfactual response curves exceeds a threshold. Global explanations are derived by aggregating local explanations across all samples based on feature modification frequencies.

## Key Results
- The method successfully identified feature combinations with highest impact on response curve shape in synthetic datasets, matching ground truth analysis
- On crop yield datasets, feature impact on fertilizer responsivity varied depending on terrain characteristics of each field
- The approach demonstrated ability to generate counterfactual explanations that meaningfully alter response curve shapes while minimizing feature modifications

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Counterfactual explanations identify passive features whose modification changes response curve shapes
- Mechanism: Genetic algorithm-based multi-objective optimization finds minimal passive feature subsets to perturb so curve shape distance exceeds threshold
- Core assumption: Passive feature modifications can alter response curve shapes beyond vertical shifts
- Evidence anchors:
  - [abstract] "a CFE finds the minimum combination of passive features that need to be modified to alter the shape of the response curve."
  - [section] "we propose to use counterfactual explanations (CFEs) for the identification of the features with the highest relevance on the shape of response curves generated by neural network black boxes."
- Break condition: If passive features only cause vertical shifts or fPCA cannot capture shape differences

### Mechanism 2
- Claim: Aligned approximate response curves focus comparison on shape differences
- Mechanism: Response curves aligned by subtracting minimum value to remove vertical shifts
- Core assumption: Absolute values less important than relative shape for understanding responsivity
- Evidence anchors:
  - [section] "we get rid of any vertical shifts and obtain the aligned approximate response curve by subtracting from its minimum value."
- Break condition: If minimum value subtraction fails to preserve meaningful shape information

### Mechanism 3
- Claim: Global explanations derived by aggregating local explanations across samples
- Mechanism: Local explanations (modified feature sets) aggregated via frequency counting to compute global relevance scores
- Core assumption: Frequent modification of features indicates high relevance to response curve shape
- Evidence anchors:
  - [section] "we also report the five most repeated feature combinations... we restrict the number of reported feature combinations to five for conciseness."
- Break condition: If local explanations are inconsistent or frequency aggregation masks important interactions

## Foundational Learning

- Concept: Counterfactual explanations
  - Why needed here: Generating counterfactual samples with different response curve shapes requires understanding how small input changes affect outputs
  - Quick check question: What distinguishes counterfactual explanations that change class labels from those changing response curve shapes?

- Concept: Functional principal component analysis (fPCA)
  - Why needed here: fPCA transforms response curves into reduced basis functions enabling shape distance measurement
  - Quick check question: How does fPCA facilitate comparing response curve shapes rather than absolute values?

- Concept: Multi-objective optimization
  - Why needed here: CFE generation involves three competing objectives requiring techniques like NSGA-II
  - Quick check question: Why is single-objective optimization insufficient for solving the CFE generation problem?

## Architecture Onboarding

- Component map: Input data preprocessing -> Neural network training -> Response curve generation -> fPCA transformation -> CFE generation (NSGA-II) -> Local/global explanation extraction
- Critical path: 1) Train neural network on input data 2) Generate aligned response curves for all samples 3) Apply fPCA to transform curves 4) Run NSGA-II for each sample to find minimal passive feature modifications 5) Aggregate local explanations to compute global relevance scores
- Design tradeoffs: Population size vs. convergence speed in NSGA-II, number of fPCs vs. shape information retention, threshold ϵ vs. sensitivity to shape differences, distance metric choice
- Failure signatures: Neural network fails to learn meaningful relationships, fPCA fails to capture shape differences, NSGA-II converges to trivial solutions, local explanations are inconsistent
- First 3 experiments: 1) Train neural network on synthetic dataset and verify MSE meets target 2) Generate response curves and apply fPCA, check variance explained 3) Run CFE generation on one sample with small dataset, verify shape change exceeds threshold

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How to determine statistical significance of responsivity differences between response curves without relying on threshold hyperparameter?
- Basis in paper: [explicit] "Future work will focus on designing tests that will determine if the responsivity of two or more response curves is statistically significant."
- Why unresolved: Current method uses fixed subjective threshold that may not be optimal across datasets
- What evidence would resolve it: Development and validation of statistical tests determining significant responsivity differences without fixed thresholds

### Open Question 2
- Question: How can equation discovery approaches retrieve approximate parametric equations for crop production response curves?
- Basis in paper: [explicit] "We also plan to use equation discovery approaches to retrieve approximate parametric equations for crop production."
- Why unresolved: Current non-parametric neural networks don't provide interpretable parametric equations
- What evidence would resolve it: Successful application of equation discovery techniques to derive accurate parametric equations validated against ground truth

### Open Question 3
- Question: How does active feature selection impact analysis of feature relevance and combinations?
- Basis in paper: [inferred] Methodology treats active feature as given without exploring how different selections might affect conclusions
- Why unresolved: Current approach may bias analysis through specific active feature choice
- What evidence would resolve it: Systematic analysis using different active features revealing patterns or dependencies in feature relevance rankings

## Limitations
- The method assumes fPCA can adequately capture shape differences, which may not hold for all functional relationships
- Aggregation of local explanations through frequency counting may oversimplify complex feature interactions
- Validation on real-world crop yield datasets is more challenging than synthetic datasets with ground truth

## Confidence
- Synthetic dataset results: Medium confidence (ground truth comparisons possible)
- Real-world crop yield datasets: Low confidence (challenging validation)
- Method effectiveness overall: Medium confidence based on synthetic dataset validation
