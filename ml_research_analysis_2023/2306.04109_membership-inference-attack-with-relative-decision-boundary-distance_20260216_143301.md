# Membership inference attack with relative decision boundary distance

## Quick Facts
- arXiv ID: 2306.04109
- Source URL: https://arxiv.org/abs/2306.04109
- Reference count: 39
- This paper proposes a multi-class adaptive membership inference attack that uses multi-targeted HopSkipJump algorithm and relative decision boundary distances, achieving higher true positive rates at low false positive rates on CIFAR datasets.

## Executive Summary
This paper addresses the challenge of membership inference attacks in machine learning, specifically focusing on label-only settings where the adversary can only access predicted labels. The authors propose a novel multi-class adaptive membership inference attack (MIA) that utilizes a multi-targeted HopSkipJump algorithm to obtain stable and minimum decision boundary distances. The attack also employs relative decision boundary distances as membership scores, which outperform single boundary distances in distinguishing members from nonmembers. The evaluation shows that the proposed method achieves higher true positive rates at low false positive rates compared to existing label-only MIAs on CIFAR-10 and CIFAR-100 datasets.

## Method Summary
The paper proposes a multi-class adaptive membership inference attack that combines a multi-targeted HopSkipJump algorithm with relative decision boundary distances. The multi-targeted approach traverses all initial target classes to find stable minimum boundary distances, addressing the instability of untargeted methods. Relative distances are computed as the difference between a sample's boundary distance and the average of its neighboring points, creating sample-specific adaptive thresholds. The method is evaluated on CIFAR-10 and CIFAR-100 datasets using true positive rate at low false positive rate and log-scale ROC curves.

## Key Results
- Multi-targeted HSJA produces more stable and accurate minimum boundary distances than untargeted HSJA
- Relative decision boundary distances outperform single boundary distances in membership classification
- The proposed method achieves higher TPR at low FPR compared to existing label-only MIAs on CIFAR datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Decision boundary distances obtained by untargeted HopSkipJump are unstable due to random initial target class selection, leading to inconsistent membership inference results.
- Mechanism: The untargeted HopSkipJump algorithm randomly selects an initial target class distinct from the source class, which can result in different minimum perturbed points for the same sample across multiple runs, causing high standard deviation in boundary distances.
- Core assumption: The initial target class significantly influences the final decision boundary distance obtained through iterative gradient descent.
- Evidence anchors:
  - [abstract] "since the decision boundary distance, which measures robustness, is strongly affected by the random initial image, the adversary may get opposite results even for the same input samples"
  - [section] "we performed untargeted HSJA ten times on a cbalanced set... discovered that samples with the same target class were more likely to acquire stable boundary distances"
  - [corpus] Weak evidence - no direct corpus support for initial class effect, but related works on HSJA stability exist
- Break condition: If the gradient descent landscape is flat or symmetric enough that initial target class doesn't materially affect the minimum distance, the instability claim weakens.

### Mechanism 2
- Claim: Relative decision boundary distances (difference between sample and neighboring points) are more discriminative than absolute distances for membership inference.
- Mechanism: Instead of using a single absolute boundary distance, the method computes the average difference between the sample's boundary distance and those of its neighboring points (obtained via small translations), creating a sample-specific adaptive threshold.
- Core assumption: For non-member samples, the neighboring points are in the same distribution and will have similar boundary distances, making the relative distance small; for member samples, the relative distance will be larger on average.
- Evidence anchors:
  - [abstract] "the relative boundary distance between samples and neighboring points has also been employed as a new membership score to distinguish between member samples inside the training set and nonmember samples outside the training set"
  - [section] "the relative decision boundary distance denotes the change in decision boundary distance caused by a sample's absence from training"
  - [corpus] Weak evidence - no direct corpus support for relative distance calibration, but similar concepts exist in difficulty calibration literature
- Break condition: If the neighboring points' boundary distances are highly variable or if the translation doesn't preserve the non-member distribution property, the relative distance may not be discriminative.

### Mechanism 3
- Claim: Multi-targeted HopSkipJump (traversing all initial target classes) produces more stable and accurate minimum boundary distances than untargeted HSJA.
- Mechanism: Instead of randomly selecting one initial target class, the method runs targeted HSJA for each possible target class (fixing the initial image for each) and selects the shortest resulting boundary distance, ensuring the global minimum is found.
- Core assumption: The true minimum boundary distance is achieved when the initial target class is chosen such that the gradient descent path leads to the closest decision boundary.
- Evidence anchors:
  - [section] "we propose a multi-targeted HSJA instead of untargeted HSJA to generate the stable and minimum decision boundary distance for each sample"
  - [section] "traversing the initial images of all labels is required to determine the minimum perturbation points"
  - [corpus] Weak evidence - no direct corpus support for multi-targeted approach, but related works on HSJA variants exist
- Break condition: If the computational cost of traversing all classes is prohibitive or if the gradient descent is not sensitive to initial class choice, the benefit diminishes.

## Architecture Onboarding

- Component map: Target model -> Multi-targeted HSJA -> Neighboring points generator -> Relative distance calculator -> Membership score
- Critical path:
  1. Generate neighboring points via small translations of each sample
  2. For each sample and each target class, run targeted HSJA to find boundary distance
  3. Select minimum boundary distance across all target classes
  4. Compute relative distance by subtracting average neighboring distances
  5. Apply threshold or use as continuous score for membership classification
- Design tradeoffs:
  - Multi-targeted vs. untargeted: Higher query cost but more stable and accurate distances
  - Absolute vs. relative distance: Simpler but less discriminative vs. more complex but better calibrated
  - Fixed vs. adaptive threshold: Simpler but may not generalize vs. more robust but requires more computation
- Failure signatures:
  - High standard deviation in boundary distances across runs → HSJA instability
  - Similar relative distance distributions for members and nonmembers → Calibration failure
  - Very high query cost → Multi-targeted approach may be impractical for large class sets
- First 3 experiments:
  1. Run untargeted HSJA 10 times on same samples and measure standard deviation to confirm instability
  2. Implement multi-targeted HSJA and compare minimum distances to untargeted results on a small test set
  3. Generate neighboring points via translations and compute relative distances, then plot histograms for members vs. nonmembers to verify separation

## Limitations

- The computational cost of multi-targeted HSJA may be prohibitive for datasets with many classes
- Evaluation only on CIFAR datasets limits generalizability to more complex data
- Assumes neighboring translations preserve non-member distribution properties
