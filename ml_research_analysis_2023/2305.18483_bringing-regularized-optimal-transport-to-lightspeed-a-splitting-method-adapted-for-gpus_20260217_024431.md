# Bringing regularized optimal transport to lightspeed: a splitting method adapted for GPUs

## Quick Facts
- arXiv ID: 2305.18483
- Source URL: https://arxiv.org/abs/2305.18483
- Reference count: 40
- One-line primary result: GPU-accelerated Douglas-Rachford splitting algorithm for regularized optimal transport achieves up to 100x speedup over Sinkhorn-Knopp in practical applications

## Executive Summary
This paper presents RDROT, a novel Douglas-Rachford splitting algorithm for solving regularized optimal transport problems that achieves significant computational speedup through GPU acceleration. The key innovation lies in exploiting the structure of sparsity-promoting regularizers to enable efficient proximal operator computations, allowing the algorithm to handle a broad class of regularizers while maintaining competitive per-iteration performance with the classic Sinkhorn-Knopp algorithm. Theoretical analysis establishes a two-phase convergence behavior with sublinear initial convergence followed by fast linear convergence once the sparsity pattern is identified, supported by extensive empirical validation across domain adaptation and generative modeling applications.

## Method Summary
RDROT implements a Douglas-Rachford splitting algorithm that reformulates regularized optimal transport as a constrained convex optimization problem, separating the entropy-like regularizer from the transport cost through auxiliary variables. The algorithm exploits sparsity-promoting properties of regularizers to compute proximal operators efficiently via simple projection operations onto non-negative matrices. A GPU implementation parallelizes matrix operations and prox-mapping computations, achieving significant speedups over CPU implementations and competitive performance with Sinkhorn-Knopp per iteration while converging to higher-quality solutions in practical applications.

## Key Results
- GPU implementation achieves competitive per-iteration runtime with Sinkhorn-Knopp algorithm
- Up to 100x faster in domain adaptation and generative modeling applications
- Sublinear convergence rate transitions to fast linear rate after sparsity pattern identification

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Douglas-Rachford splitting can efficiently handle sparsity-promoting regularizers in optimal transport.
- Mechanism: By exploiting the non-negativity constraint and the structure of sparsity-promoting regularizers, the proximal operator of the composite function can be computed efficiently as the proximal of the regularizer applied to the projection onto non-negative matrices.
- Core assumption: The regularizer h is sparsity-promoting (Definition 2.1) and closed, convex, and proper over the feasible set.
- Evidence anchors:
  - [abstract]: "The algorithm integrates a broad class of regularizers into the OT solver by exploiting the sparsity-promoting properties of the regularizers, enabling efficient computation of the prox-mapping."
  - [section 3]: "Lemma 3.1 enables us to integrate the regularizer into the algorithm with only a minor update."
  - [corpus]: Weak evidence. No direct mention of Douglas-Rachford splitting or sparsity-promoting regularizers.
- Break condition: If the regularizer is not sparsity-promoting, the proximal operator becomes computationally expensive or intractable.

### Mechanism 2
- Claim: The algorithm exhibits a two-phase convergence behavior with a sublinear rate followed by a fast linear rate.
- Mechanism: The sparsity pattern of the optimal solution is identified in finitely many iterations (Theorem 1), after which a local linear convergence rate takes over (Theorem 2).
- Core assumption: Assumption 1 holds, which is a non-degeneracy condition on the optimal solution.
- Evidence anchors:
  - [abstract]: "Theoretical analysis establishes a sublinear convergence rate until the correct sparsity pattern is identified, followed by a fast local linear rate."
  - [section 3.1]: "The stopping criterion decays as O(1/k) during the initial steps of the RDROT algorithm, but then begins to converge at a fast linear rate."
  - [corpus]: Weak evidence. No direct mention of convergence rates or sparsity pattern identification.
- Break condition: If Assumption 1 is violated, the local linear convergence rate may not hold, and the algorithm may exhibit slower convergence.

### Mechanism 3
- Claim: The GPU implementation achieves competitive per-iteration runtime with Sinkhorn and is significantly faster in practice.
- Mechanism: The algorithm is designed to be highly parallelizable, with the main computation being matrix-vector products and element-wise operations that can be efficiently executed on a GPU.
- Core assumption: The regularizer is sparsity-promoting and its prox-mapping is simple to evaluate.
- Evidence anchors:
  - [abstract]: "A GPU implementation achieves competitive per-iteration runtime with the Sinkhorn-Knopp algorithm and is up to 100x faster in applications like domain adaptation and generative modeling."
  - [section 3.2]: "The RDROT algorithm can be easily parallelized on a GPU, as long as the regularizer is sparsity promoting and its prox-mapping is simple to evaluate."
  - [corpus]: Weak evidence. No direct mention of GPU implementation or parallelization.
- Break condition: If the regularizer is not sparsity-promoting or its prox-mapping is computationally expensive, the GPU implementation may not achieve significant speedup.
