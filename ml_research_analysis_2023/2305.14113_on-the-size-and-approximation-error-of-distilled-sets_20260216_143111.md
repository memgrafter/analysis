# On the Size and Approximation Error of Distilled Sets

## Quick Facts
- arXiv ID: 2305.14113
- Source URL: https://arxiv.org/abs/2305.14113
- Reference count: 12
- Primary result: A distilled set of size linear in effective degrees of freedom exists with approximation error bounded by λ for kernel ridge regression

## Executive Summary
This paper establishes the first theoretical guarantees for dataset distillation in kernel ridge regression (KRR). By transforming the problem into Random Fourier Feature (RFF) space, the authors prove that a small distilled set of size linear in the effective degrees of freedom exists that approximates the full dataset solution. The distilled set achieves an approximation error bounded by the regularization parameter λ. Experimental validation on synthetic and real datasets confirms that the theoretical bounds accurately predict actual distillation performance.

## Method Summary
The authors transform KRR into RFF space, where finding a small distilled set becomes equivalent to finding a small set of points whose RFF-space solution matches the full dataset solution. Using weighted RFF approximations and a constrained optimization framework, they prove existence of distilled sets with linear size in effective degrees of freedom. The distillation algorithm uses Adam optimization to minimize prediction error between original and distilled datasets, validated on Gaussian random fields, two-cluster classification, and MNIST binary classification.

## Key Results
- A distilled set of size linear in effective degrees of freedom d_λ^k exists for shift-invariant kernels
- The approximation error is bounded by 2λ (or 8λ in worst case) relative to the full dataset solution
- Experimental validation shows theoretical bounds accurately predict actual distillation loss across synthetic and real datasets
- The method achieves compression ratios of 40x while maintaining small prediction errors

## Why This Works (Mechanism)

### Mechanism 1
- Claim: A small distilled set of size linear in d_λ^k exists that approximates the full dataset solution in KRR.
- Mechanism: By transforming ridge regression into RFF space, the problem becomes finding a small set of points whose RFF-space solution matches the full dataset solution. Theorem 3 proves existence of such a set S and corresponding labels y_S, with size linear in the RFF dimension s_ϕ, which is linear in d_λ^k.
- Core assumption: The kernel is shift-invariant and satisfies Assumption 1 (existence of a minimizer f* with bounded function space norm, bounded y, and regularization parameter constraint).
- Evidence anchors:
  - [abstract] "we provide the first proof of the existence of small (size) distilled datasets and their corresponding excess risk for shift-invariant kernels."
  - [section 4] "Theorem 3 (On the existence of some distilled data)...there exists a matrix S ∈ R(sϕ+1)×d and a label vector yS such that...the weighted RFF mapping eS ∈ R(sϕ+1)×(sϕ) of S, satisfies that..."
- Break condition: If the kernel is not shift-invariant, or if the regularization parameter λ violates the constraint in Assumption 1 (nλ > λ₁), the proof breaks.

### Mechanism 2
- Claim: The approximation error of the distilled set is bounded by a function of the regularization parameter λ.
- Mechanism: Lemma 1 shows that for any function in the Hilbert space with bounded norm, there exists a query β in RFF space achieving approximation error at most 2λ. Theorem 3 uses this to bound the in-sample prediction error between the full dataset solution and the distilled set solution.
- Core assumption: The function space norm is bounded by 1 (Assumption II) and the approximation quality in RFF space (Lemma 1).
- Evidence anchors:
  - [section 4] "Lemma 1 (Restatement of Lemma 6 [LTOS21])...inf√sϕ∥β∥≤√2 β∈Rsϕ n∑i=1 1n |f(Xi*)−eXi*β|²≤ 2λ."
  - [section 4] "1/n∑ni=1 |fλ[X,y,k](Xi*)−fλ,X,y[S,yS,k](Xi*)|²≤ minτ∈Υ 2max{τ,4/τ²}λ+2min{1+τ,4(1+τ)/3τ}λ"
- Break condition: If the function space norm exceeds 1, or if the RFF approximation quality degrades (larger s_ϕ needed), the error bound may increase.

### Mechanism 3
- Claim: The distilled set size and error bounds hold in practice for real and synthetic datasets.
- Mechanism: Experimental validation in section 5 shows that for Gaussian random fields, two-cluster classification, and MNIST binary classification, the predicted upper bounds accurately capture the actual distillation loss.
- Core assumption: The experimental protocol (distillation with Adam optimizer, fixed hyperparameters) produces distilled sets that achieve the theoretical approximation.
- Evidence anchors:
  - [section 5] "To validate our theoretical bounds, we performed distillation on three datasets...showing that in all scenarios our bounds accurately predict the error associated with distillation."
  - [section 5] "Our predicted upper bound accurately bounds the actual distillation loss." (multiple instances)
- Break condition: If the experimental setup deviates significantly from theoretical assumptions (e.g., different kernel, non-shift-invariant kernels, or insufficient optimization), the empirical results may not match theoretical predictions.

## Foundational Learning

- Concept: Kernel Ridge Regression (KRR)
  - Why needed here: The paper studies dataset distillation specifically in the KRR setting, where the goal is to find a small subset approximating the KRR solution on the full dataset.
  - Quick check question: What is the objective function minimized in KRR, and how does the regularization parameter λ affect the solution?

- Concept: Random Fourier Features (RFF)
  - Why needed here: RFF is used to transform the problem into a lower-dimensional space where a small distilled set can be found. The paper leverages RFF approximation properties to prove existence of small distilled sets.
  - Quick check question: How does the RFF approximation relate to the original kernel function, and what is the trade-off between the number of RFF features and approximation quality?

- Concept: Effective Degrees of Freedom (d_λ^k)
  - Why needed here: The size of the guaranteed distilled set is linear in d_λ^k, which is a function of the kernel, number of data points, and regularization parameter λ. Understanding this concept is crucial for interpreting the theoretical bounds.
  - Quick check question: How is d_λ^k defined in terms of the kernel matrix K and regularization parameter λ, and what does it represent in the context of KRR?

## Open Questions the Paper Calls Out
- The paper doesn't explicitly call out open questions but identifies a gap between theoretical upper bounds and empirical distillation losses in section 5, suggesting the current mathematical framework may be too pessimistic

## Limitations
- The proof relies heavily on shift-invariant kernels and may not extend to non-shift-invariant kernels
- Theoretical bounds appear conservative compared to empirical results, suggesting potential for tighter analysis
- The specific construction of distilled sets from Theorem 3 lacks detailed implementation guidance

## Confidence
- **High**: The existence of small distilled sets (Theorem 3) and the approximation error bound (Lemma 1) - well-supported by theoretical proofs and experimental validation
- **Medium**: The practical applicability of the bounds to real-world datasets - experiments show good results but generalizability to larger problems is uncertain
- **Low**: The exact implementation details for constructing S and yS from Theorem 3 - the paper provides theoretical framework but lacks specific algorithmic details
