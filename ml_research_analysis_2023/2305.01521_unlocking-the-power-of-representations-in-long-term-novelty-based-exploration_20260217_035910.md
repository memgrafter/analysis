# Unlocking the Power of Representations in Long-term Novelty-based Exploration

## Executive Summary
RECODE introduces a novel approach to long-term novelty-based exploration in deep reinforcement learning by combining non-parametric clustering-based density estimation with learned state representations. The method addresses the fundamental challenge of efficiently tracking state visitation counts in non-stationary online RL environments, where traditional parametric methods struggle to adapt over thousands of episodes. By leveraging state similarity through learned embeddings and introducing a slot-based memory system, RECODE enables efficient generalization in large or continuous state spaces while maintaining computational tractability.

The method's effectiveness is demonstrated through superior performance on challenging exploration benchmarks, including the first reported completion of "Pitfall!" on Atari and new state-of-the-art results on the DM-HARD-8 suite. RECODE's design as a flexible, drop-in exploration method makes it applicable to diverse RL agents, while its robustness to noisy observations and ability to improve with better representations positions it as a significant advancement in exploration strategies for deep reinforcement learning.

## Method Summary
RECODE employs a clustering-based approach to density estimation for tracking state visitation counts in long-horizon RL tasks. The core innovation lies in adapting classical clustering techniques to handle the non-stationary nature of online RL, where the state distribution evolves as the agent learns. A slot-based memory structure maintains counts of state visits, allowing the method to estimate novelty without requiring expensive parametric density models. The approach leverages learned state representations to measure similarity between states, enabling efficient generalization across similar states in continuous or high-dimensional spaces.

The method introduces CASM (Contrastive Adaptive State Modeling), a multi-step representation learning technique using masked transformers. CASM enhances state representations by learning temporal dynamics and state relationships, which in turn improves the clustering-based novelty estimation. This representation learning component is crucial for handling the large state spaces typical in modern RL problems while maintaining the ability to detect genuinely novel states that drive exploration.

## Key Results
- Achieves state-of-the-art performance on hard exploration Atari games, including first completion of "Pitfall!"
- Sets new benchmarks on 3D DM-HARD-8 suite, outperforming prior methods like NGU and BYOL-Explore
- Demonstrates robustness to noisy observations and improved performance with more powerful representations

## Why This Works (Mechanism)
RECODE works by addressing the fundamental challenge of long-term novelty detection in non-stationary environments through a combination of efficient density estimation and powerful representations. The clustering-based approach provides a non-parametric way to estimate state visitation counts without requiring explicit density modeling, which is computationally prohibitive for large state spaces. By using learned embeddings to measure state similarity, the method can generalize across similar states, dramatically reducing the memory and computational requirements compared to maintaining individual counts for each unique state.

The slot-based memory mechanism allows RECODE to maintain a fixed computational footprint while adapting to changing state distributions over time. As the agent explores and the state visitation patterns shift, the clustering approach naturally reorganizes to reflect current visitation frequencies. The CASM representation learning component further enhances this process by providing embeddings that capture temporal relationships and state dynamics, making the novelty estimation more sensitive to genuinely new experiences rather than minor variations in similar states.

## Architecture Onboarding
Component map: State Representations -> Clustering Engine -> Slot Memory -> Novelty Signal -> RL Agent

Critical path: Raw observations → Representation Learning (CASM) → Clustering-based Density Estimation → Novelty Computation → Exploration Bonus

Design tradeoffs: The method trades off between memory efficiency (through clustering) and potential loss of fine-grained novelty information. The slot-based memory provides computational tractability but may miss subtle distinctions between states. The representation learning component adds complexity but enables better generalization across similar states.

Failure signatures: Poor representations lead to ineffective clustering and missed novelty opportunities. Overly aggressive clustering may cause the method to overlook genuinely novel states. Insufficient memory slots can lead to premature overwriting of important visitation information.

First experiments: 1) Test clustering performance on synthetic state distributions with known visitation patterns, 2) Evaluate representation learning quality on standard RL benchmarks, 3) Validate slot memory efficiency and adaptation to non-stationary distributions
