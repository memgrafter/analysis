# Taught by the Internet, Exploring Bias in OpenAIs GPT3

## Quick Facts
- arXiv ID: 2306.02428
- Source URL: https://arxiv.org/abs/2306.02428
- Reference count: 0
- Key outcome: Base GPT-3 model shows minimal gender bias in ATS ranking, but fine-tuning methods amplify bias

## Executive Summary
This study examines gender bias in OpenAI's GPT-3 when used as an Applicant Tracking System (ATS) for resume screening. The research tests three approaches: a base model, traditionally fine-tuned model, and a value-added statement fine-tuned model. Results show the base model performs best with minimal gender bias, while fine-tuning increases bias. The study concludes that GPT-3's base model is relatively unbiased, but fine-tuning methods may unintentionally amplify biases in hiring scenarios.

## Method Summary
The study used LinkedIn resumes to evaluate three GPT-3 models in an ATS scenario. The base model (Davinci-002) was compared against traditionally fine-tuned and value-added statement fine-tuned models. Bias was measured through ranking scores (comparing male vs. female candidate scores) and content generation bias (using a lexicon-based approach to score generated text for gendered terminology). Statistical significance was assessed using t-tests to determine if observed differences were meaningful.

## Key Results
- Base GPT-3 model showed minimal gender bias in both ranking and content generation
- Traditional fine-tuning increased gender bias compared to base model
- Value-added statement fine-tuning slightly worsened bias toward females in female-dominated professions like teaching
- In male-dominated professions like medicine, fine-tuning introduced notable male bias
- Base model demonstrated resilience to gender bias compared to fine-tuned variants

## Why This Works (Mechanism)

### Mechanism 1
Fine-tuning GPT-3 on resumes increases gender bias compared to the base model because traditional fine-tuning trains the model to replicate annotator scoring patterns, which may contain inherent human biases. The fine-tuning process amplifies these biases because the model learns to weight features that correlate with gender stereotypes in the training data.

### Mechanism 2
Value-Added Statements (VAS) intended to reduce bias can paradoxically amplify it in gender-imbalanced professions because VAS disproportionately emphasize gender equality concepts, which shift the model's learned associations toward overcompensating in the opposite direction. In female-dominated fields like teaching, this leads to inflated scores for females; in male-dominated fields like medicine, it reinforces male preferences.

### Mechanism 3
Base GPT-3 model (Davinci-002) exhibits minimal gender bias because it was pre-trained on diverse web data with implicit de-biasing. The base model benefits from large-scale pre-training that averages out gender associations across many contexts, and OpenAI's internal alignment processes reduce stereotypical patterns before release.

## Architecture Onboarding

- **Component map:** LinkedIn resume data ingestion → Resume preprocessing → ATS simulation → GPT-3 API calls (base/fine-tuned/VAS) → Score extraction → Bias analysis pipeline

- **Critical path:** Resume data → ATS scoring → GPT-3 response → Bias measurement. Any failure in GPT-3 API response or scoring logic breaks the analysis.

- **Design tradeoffs:** Using fine-tuning provides better task-specific performance but amplifies bias; VAS fine-tuning attempts mitigation but can overcorrect; base model is safer for bias but may lack domain specificity

- **Failure signatures:** High variance in scores across runs suggests instability in fine-tuning; lexicon matching produces many false positives if domain-specific terms aren't filtered; statistical tests showing significance at exactly 95% may indicate borderline results

- **First 3 experiments:**
  1. Run base model on 100 resumes from each profession, verify score distributions are similar across genders
  2. Apply traditional fine-tuning on 200 annotated resumes, measure change in gender bias significance
  3. Apply VAS fine-tuning with 40 value statements, compare bias metrics to traditional fine-tuning results

## Open Questions the Paper Calls Out

- **Open Question 1:** Does the debiasing effectiveness of GPT-3's PALMS approach scale to much larger datasets than the 400 samples used in this study? The study only tested with 400 samples, which is relatively small compared to production-scale datasets.

- **Open Question 2:** How does GPT-3's base model bias performance compare to other large language models of similar size when applied to real-world ATS scenarios? The study focused exclusively on GPT-3 and made no comparative analysis.

- **Open Question 3:** Would industry-specific or role-specific fine-tuning of GPT-3 produce better bias outcomes than general fine-tuning for ATS applications? The study only used generalized fine-tuning approaches and didn't test specialization.

## Limitations

- Limited contextual understanding in bias measurement through lexicon-based approach that may miss nuanced gender associations
- Annotation quality concerns with human annotators whose consistency and potential biases are not quantified
- GPT-3 API variability creates uncertainty due to inherent variability in model outputs and lack of reproducibility

## Confidence

- **High Confidence:** Base GPT-3 model exhibits minimal gender bias in ranking scores, well-supported by multiple statistical tests
- **Medium Confidence:** Fine-tuning amplifies gender bias is plausible given learning from potentially biased human annotations
- **Low Confidence:** VAS fine-tuning results showing gender-specific amplification in female-dominated vs. male-dominated professions are based on limited significance levels (92%)

## Next Checks
