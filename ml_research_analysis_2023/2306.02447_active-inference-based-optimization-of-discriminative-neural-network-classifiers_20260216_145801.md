# Active Inference-Based Optimization of Discriminative Neural Network Classifiers

## Quick Facts
- arXiv ID: 2306.02447
- Source URL: https://arxiv.org/abs/2306.02447

## Executive Summary
This paper addresses critical challenges in discriminative neural network classifiers, particularly those arising from imbalanced class distributions and label noise. The authors propose a novel optimization framework that integrates active inference principles with the generalized Kelly criterion to improve classification performance and robustness. The method introduces an algorithm for computing candidate labels from prior probabilities and network posteriors, coupled with a new objective function based on expected free energy. This approach aims to reduce classification biases by incorporating prior probabilities and handling class imbalances through precision and recall metrics. Experimental results on 3D volumetric segmentation tasks demonstrate superior performance compared to traditional cross-entropy and metric-based losses.

## Method Summary
The paper proposes a novel optimization process for discriminative neural network classifiers that combines active inference principles with the generalized Kelly criterion. The method introduces an algorithm to compute candidate labels from prior probabilities and network posteriors, along with a new objective function based on expected free energy. This approach incorporates prior probabilities to focus network attention on minority foreground classes, reducing classification biases. The objective function handles class imbalances by emphasizing precision and recall metrics. The method is evaluated on 3D volumetric segmentation tasks, showing improved performance over traditional cross-entropy and metric-based losses.

## Key Results
- The proposed method outperforms traditional cross-entropy and metric-based losses on 3D volumetric segmentation tasks.
- Improved robustness against class imbalances by incorporating prior probabilities and emphasizing precision and recall metrics.
- Potential for handling reference label errors, although not empirically demonstrated in the paper.

## Why This Works (Mechanism)
The proposed method works by integrating active inference principles with the generalized Kelly criterion to optimize discriminative neural network classifiers. Active inference provides a framework for decision-making under uncertainty, allowing the model to incorporate prior knowledge and update beliefs based on observations. The generalized Kelly criterion, typically used in information theory and gambling, is adapted to guide the optimization process by balancing exploration and exploitation. By computing candidate labels from prior probabilities and network posteriors, the method can focus attention on minority classes and handle class imbalances more effectively. The expected free energy-based objective function further enhances the model's ability to generalize by considering both accuracy and uncertainty.
