# A Rule Based Theorem Prover: an Introduction to Proofs in Secondary Schools

## Quick Facts
- arXiv ID: 2303.05863
- Source URL: https://arxiv.org/abs/2303.05863
- Reference count: 32
- Primary result: Introduces a rule-based theorem prover for secondary school geometric proofs using curriculum-aligned inference rules

## Executive Summary
This paper presents a rule-based theorem prover designed to introduce formal geometric proofs in secondary schools. The approach uses inference rules adapted to the 7th year curriculum, implemented through the geometry deductive databases method (GDDM). The system generates synthetic proofs using forward chaining reasoning that can be rendered in natural language, making them more accessible to students. Two examples demonstrate the approach: proving opposite sides of a parallelogram are equal, and diagonals of a rectangle are equal. The work aims to bridge the gap between automated provers and normal proof practice in schools by using a rule set more aligned with student knowledge.

## Method Summary
The method employs a set of inference rules specifically adapted to the 7th year curriculum and implemented using the geometry deductive databases method (GDDM). The approach uses forward chaining reasoning to generate synthetic proofs, which are then rendered in natural language. The system is designed to work in conjunction with dynamic geometry software, allowing students to explore geometric conjectures visually before engaging with formal proofs. Two specific geometric theorems are used as examples: proving opposite sides of a parallelogram are equal, and proving diagonals of a rectangle are equal.

## Key Results
- Successfully demonstrates proof generation for parallelogram opposite sides equality
- Shows proof generation for rectangle diagonal equality
- Generates synthetic proofs using forward chaining reasoning
- Creates natural language renderings of formal proofs aligned with curriculum

## Why This Works (Mechanism)
The approach works by aligning the inference rules with the specific knowledge students have at the 7th-year level, making the proofs more accessible and understandable. The use of forward chaining reasoning ensures that proofs are generated in a step-by-step manner that follows logical progression. The natural language rendering of proofs bridges the gap between formal mathematical notation and student comprehension. The integration with dynamic geometry software provides visual context that supports the formal reasoning process.

## Architecture Onboarding

Component Map:
GDDM Database -> Inference Rule Engine -> Forward Chaining Algorithm -> Natural Language Renderer -> Student Interface

Critical Path:
1. User inputs geometric problem
2. GDDM retrieves relevant geometric facts
3. Inference rule engine applies applicable rules
4. Forward chaining algorithm generates proof steps
5. Natural language renderer formats proof
6. Proof displayed to student

Design Tradeoffs:
- Formal vs. informal proof presentation
- Rule complexity vs. student comprehension
- Computational efficiency vs. proof completeness
- Integration depth with dynamic geometry software

Failure Signatures:
- Rules not matching curriculum knowledge level
- Natural language rendering producing unclear explanations
- Forward chaining getting stuck in infinite loops
- Database queries returning incomplete results

First Experiments:
1. Test proof generation on simple geometric theorems
2. Evaluate natural language rendering quality with sample proofs
3. Verify rule application matches curriculum expectations
