# Response-conditioned Turn-taking Prediction

## Quick Facts
- arXiv ID: 2305.02036
- Source URL: https://arxiv.org/abs/2305.02036
- Reference count: 9
- Primary result: RC-TurnGPT outperforms baseline TurnGPT across all five turn-level metrics by conditioning turn-shift predictions on both conversation history and intended response

## Executive Summary
This paper addresses turn-taking prediction in conversational systems by proposing a response-conditioned approach that conditions turn-shift decisions on both conversation history and the intended response. The authors extend the TurnGPT model with a novel training objective that permutes sequence order to {Response, History, Current Utterance} while masking loss over the response and history. This allows the model to use future semantic information when predicting turn-shifts. The model is trained on two types of dialogue datasets and evaluated using five turn-level metrics, showing consistent improvement over the baseline model, particularly in scenarios involving questions and semantic matching.

## Method Summary
RC-TurnGPT extends the TurnGPT architecture by introducing response conditioning through a modified training objective. The model permutes sequence order to {Response, History, Current Utterance} and applies masking over the response and history during training, while maintaining left-to-right token prediction. This allows the model to learn turn-shift predictions conditioned on the next response. The training uses dialog corpora with clear turn boundaries, applying a sliding window approach to extract turn-based sequences. Evaluation employs five turn-level metrics: turn-level accuracy, no response rate, barge-in rate, response perplexity, and ordinal spike rate.

## Key Results
- RC-TurnGPT outperforms baseline TurnGPT across all five evaluation metrics
- Most significant improvements occur when current utterance contains statements followed by questions
- Improvements are also prominent when end of current utterance semantically matches the response
- Response quality (measured by perplexity) improves when turn-taking predictions differ between models

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Conditioning turn-taking prediction on the response allows the model to delay turn-shifts until after semantically relevant content is stated.
- **Mechanism**: By permuting the sequence order to {Response, History, Current Utterance} and masking loss over the response and history, the model learns to use future semantic information when predicting turn-shifts in the current utterance.
- **Core assumption**: The response contains semantically relevant information that should influence when a turn-shift is appropriate.

### Mechanism 2
- **Claim**: Response conditioning prevents premature turn-taking when the current utterance contains statements followed by questions.
- **Mechanism**: The model learns that when a question appears later in an utterance, it should wait for the question to be completed before predicting a turn-shift, using the response to infer that a question-answer pair is expected.
- **Core assumption**: Questions are typically followed by responses, and the model can use this pattern to improve turn-taking prediction.

## Limitations

- The model is evaluated only on written dialog datasets, limiting generalizability to spoken conversations with disfluencies
- Evidence for proposed mechanisms is primarily qualitative examples rather than quantitative validation
- Response quality measurement relies on perplexity, which may not accurately reflect conversational appropriateness

## Confidence

**High confidence**: The overall claim that RC-TurnGPT outperforms baseline TurnGPT across all five metrics is well-supported by the results section and evaluation methodology.

**Medium confidence**: The two specific scenarios where improvement is most prominent (statements followed by questions, semantic matching between current utterance and response) are identified, but the evidence for these is primarily qualitative examples rather than systematic analysis.

**Low confidence**: The three proposed mechanisms explaining why response conditioning works are speculative, with the paper providing illustrative examples but lacking quantitative validation that these mechanisms are actually responsible for the observed improvements.
