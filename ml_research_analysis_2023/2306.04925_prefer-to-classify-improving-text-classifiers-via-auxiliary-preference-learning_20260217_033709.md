# Prefer to Classify: Improving Text Classifiers via Auxiliary Preference Learning

## Quick Facts
- **arXiv ID**: 2306.04925
- **Source URL**: https://arxiv.org/abs/2306.04925
- **Reference count**: 40
- **Key outcome**: Multi-task learning framework using task-specific preferences between text pairs improves classification accuracy and calibration across ten datasets

## Executive Summary
This paper introduces the Prefer-to-Classify (P2C) framework that improves text classification by incorporating task-specific preferences between pairs of texts as auxiliary annotations. The framework jointly trains a classifier on both the original classification task and preference learning, using consistency regularization to align classification confidence with preference predictions. Three methods for obtaining preference labels are explored: extractive from existing annotation records, generative from large language models like GPT-3, and subjective from crowd workers. Experiments on ten text classification datasets show consistent improvements in accuracy and calibration, with extractive preferences achieving strong performance without additional annotation costs.

## Method Summary
The P2C framework jointly trains a transformer-based model on classification and preference learning tasks. It uses multiple preference heads with diversity regularization to capture different aspects of the preference space, and consistency regularization to align classification confidence with preference predictions. Preference labels are obtained through three methods: extractive (leveraging existing annotation records), generative (using GPT-3 to generate preferences), or subjective (collecting from crowd workers). The framework also employs advanced sampling schemes to select informative text pairs for preference learning. Experiments are conducted on ten text classification datasets using RoBERTa-base, with evaluation metrics including accuracy, balanced accuracy, worst-group accuracy, and Expected Calibration Error (ECE).

## Key Results
- P2C consistently improves classification accuracy across ten text classification datasets compared to baselines
- Extractive preference labels achieve strong performance without additional annotation costs
- The framework demonstrates improvements in both accuracy and calibration metrics
- P2C generalizes to image classification tasks beyond text

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multiple preference heads with diversity regularization capture richer preference signal than a single head
- Mechanism: Multiple heads learn diverse representations of the preference space when diversity is enforced, preventing collapse
- Core assumption: Different initializations learn complementary aspects of the preference signal
- Evidence anchors: Section 2.2 describes multiple preference heads with KL-divergence regularization for diversity
- Break condition: Limited or noisy preference labels may cause heads to learn contradictory signals

### Mechanism 2
- Claim: Consistency regularization aligns classification confidence with relative ordering
- Mechanism: Higher classification confidence is explicitly trained to correspond to preferred instances
- Core assumption: Classification confidence should correlate with being more preferred
- Evidence anchors: Section 2.2 and abstract mention consistency regularization between classification and preference learning
- Break condition: Preferences based on non-semantic criteria may make regularization harmful

### Mechanism 3
- Claim: Different preference collection methods provide varying quality signals at different costs
- Mechanism: Generative preferences offer low-cost approximation, extractive leverages existing data, subjective provides highest quality
- Core assumption: Preference labels capture complementary information to instance-wise labels
- Evidence anchors: Section 3 describes three preference collection methods and their characteristics
- Break condition: Systematically biased or uncorrelated preference labels may not improve classification

## Foundational Learning

  - Why needed here: Combines classification and preference learning to leverage complementary training signals
  - Quick check question: How does multi-task learning with auxiliary objectives typically affect model generalization?

- Concept: Preference learning and ranking
  - Why needed here: Learns to predict relative preferences between pairs of texts, fundamentally different from standard classification
  - Quick check question: What's the key difference between predicting class labels versus predicting preferences between pairs?

- Concept: Consistency regularization
  - Why needed here: Enforces alignment between classification confidence and preference predictions
  - Quick check question: How does consistency regularization typically affect calibration and confidence calibration?

## Architecture Onboarding

- Component map: Main classifier head (Wtask) → Transformer backbone (gϕ) ← Multiple preference heads (Wpref) with diversity regularization, all trained with consistency regularization
- Critical path: Input text → Transformer backbone → Classification head + Preference heads → Loss computation (classification + preference + consistency + diversity) → Parameter updates
- Design tradeoffs: Multiple heads add complexity but capture richer signals; consistency regularization improves alignment but may constrain the model
- Failure signatures: Performance degradation with noisy preferences; training instability with high diversity regularization; no improvement with uncorrelated preference signal
- First 3 experiments:
  1. Ablation study: Remove consistency regularization to verify its contribution
  2. Sensitivity analysis: Vary number of preference heads (T) to find optimal configuration
  3. Sampling strategy comparison: Test random vs. disagreement-based vs. inconsistency-based sampling

## Open Questions the Paper Calls Out

- How does P2C performance scale with preference dataset size? Is there diminishing returns?
- How robust is P2C to noise in preference labels, especially for generative preferences?
- Can P2C be extended to multi-label classification or other structured prediction tasks?

## Limitations

- The framework's performance on datasets with limited preference signal or misaligned preferences remains uncertain
- The diversity regularization mechanism assumes different initializations learn complementary representations without empirical validation
- The consistency regularization assumes a correlation between confidence and preference ordering that may not hold for all task types

## Confidence

- Core claim (auxiliary preference learning improves classification): **High**
- Performance consistency across datasets: **Medium**
- Generalizability to other task types: **Medium**

## Next Checks

1. **Head Ablation Study**: Systematically remove individual preference heads to quantify marginal contributions and validate diversity regularization

2. **Preference Quality Analysis**: Compare extractive, generative, and subjective preferences on the same dataset to isolate impact of quality vs. quantity

3. **Cross-Domain Transfer**: Test framework on tasks where preferences are explicitly misaligned with classification objectives to identify conditions where consistency regularization becomes harmful
