# Planning for Learning Object Properties

## Executive Summary
This paper presents a novel approach to automatically learn object properties using symbolic planning techniques. The key idea is to formalize the problem of training neural networks to recognize object properties as a symbolic planning problem using PDDL. The approach extends a base planning domain with new actions and predicates for learning properties, enabling the agent to plan for collecting training examples and learning the neural network. Experiments in both simulated and real environments demonstrate the effectiveness of the method, with precision and recall metrics ranging from 0.57 to 0.99 for various object properties.

## Method Summary
The proposed method extends a base planning domain with new actions and predicates for learning properties, enabling the agent to plan for collecting training examples and learning the neural network. The approach uses a top-level policy to decide whether to perform an action or plan for an observation based on the state of the planner. The policy is trained using reinforcement learning, with the reward function based on the accuracy of the learned object properties. The method also includes a meta-learning component to adapt the policy to new object properties. Experiments are conducted in both simulated and real environments, using a robot arm and a camera to collect data.

## Key Results
- Precision and recall metrics range from 0.57 to 0.99 for various object properties
- The approach successfully learns to recognize new object properties without requiring pre-trained models for all possible environments
- Performance is demonstrated in both simulated and real environments

## Limitations
- The method requires a planning domain to be manually defined for each new environment, which may not scale well to highly diverse or unstructured settings
- The experimental evaluation focuses primarily on a limited set of object properties and does not address more complex or abstract properties
- The real-world experiments are conducted in controlled environments with specific object types, raising questions about generalization to novel objects and environmental conditions
