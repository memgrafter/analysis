# Self-Supervised learning for Neural Architecture Search (NAS)

## Quick Facts
- **arXiv ID**: 2304.01023
- **Source URL**: https://arxiv.org/abs/2304.01023
- **Reference count**: 32
- **Key outcome**: Self-supervised NAS approach achieves competitive semantic segmentation accuracy while requiring significantly less labeled data

## Executive Summary
This paper presents a self-supervised learning approach for neural architecture search (NAS) applied to semantic segmentation. The method leverages unlabelled data through multiple pretext tasks (inpainting, denoising, colorization, jigsaw) to improve segmentation performance while requiring minimal labeled data. The approach uses switchable normalization and is evaluated using mean Intersection over Union (mIoU) on semantic segmentation benchmarks, demonstrating competitive accuracy compared to fully supervised methods.

## Method Summary
The approach involves training a network using multiple self-supervised pretext tasks in a semi-supervised manner. The network is trained simultaneously on tasks like inpainting, denoising, colorization, and jigsaw while also learning the target segmentation task. A shared encoder extracts features useful for all tasks, with task-specific decoders handling different output requirements. Key hyperparameters including normalization techniques (switchable normalization), losses (cross-entropy, MSE), and learning rate schedules are carefully tuned to optimize performance.

## Key Results
- Achieves competitive semantic segmentation accuracy with significantly less labeled data
- Leverages unlabelled data through self-supervised tasks to improve segmentation performance
- Demonstrates effectiveness of multi-task learning with self-supervised pretext tasks as regularizers

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Self-supervised pretext tasks enable the network to learn useful representations from unlabelled data, improving downstream semantic segmentation performance.
- **Mechanism**: The network is trained simultaneously on multiple self-supervised tasks and the target segmentation task. The shared encoder extracts features useful for all tasks, while task-specific decoders handle different output requirements. Pretext tasks create artificial supervision signals from unlabelled data, allowing the model to learn general image representations before fine-tuning on limited labelled segmentation data.
- **Core assumption**: Features learned from self-supervised pretext tasks transfer beneficially to the semantic segmentation task.
- **Break condition**: If pretext tasks do not share sufficient structural similarity with segmentation, or if labelled data is too limited to adapt learned features effectively.

### Mechanism 2
- **Claim**: Switchable Normalization improves model generalization by adaptively combining batch, instance, and layer normalization statistics.
- **Mechanism**: Switchable Normalization computes weighted averages of normalization statistics from different methods, allowing the model to automatically select the most appropriate normalization strategy for each layer and batch size.
- **Core assumption**: The optimal normalization strategy varies across layers and batch sizes, and can be learned during training.
- **Break condition**: If learned weights for combining normalization statistics converge to extreme values, reducing to a single normalization method.

### Mechanism 3
- **Claim**: Multi-task learning with self-supervised pretext tasks regularizes the model and improves generalization to the target segmentation task.
- **Mechanism**: Training on multiple related tasks simultaneously helps the model learn shared representations that capture common image structures while also learning task-specific features.
- **Core assumption**: Pretext tasks and segmentation task share sufficient structural and semantic similarities for knowledge transfer.
- **Break condition**: If pretext tasks are too dissimilar from segmentation, or if computational overhead outweighs regularization benefits.
