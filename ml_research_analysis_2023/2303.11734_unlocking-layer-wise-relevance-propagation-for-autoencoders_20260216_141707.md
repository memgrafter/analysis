# Unlocking Layer-wise Relevance Propagation for Autoencoders

## Quick Facts
- **arXiv ID**: 2303.11734
- **Source URL**: https://arxiv.org/abs/2303.11734
- **Reference count**: 16
- **Primary result**: Novel LRP extension for autoencoders achieves 3-4 orders of magnitude faster explanations than SHAP while maintaining comparable quality on anomaly detection tasks.

## Executive Summary
This paper addresses the challenge of interpreting autoencoder models, particularly for anomaly detection where reconstructions fail. The authors extend Layer-wise Relevance Propagation (LRP) with Deep Taylor Decomposition to propagate reconstruction errors backward through autoencoder architectures. They introduce novel LRP rules for both L1 and L2 reconstruction loss functions that satisfy conservation properties. The approach is validated on SQL workload logs and the MVTec image dataset, showing significant performance improvements over baseline residual explanations while achieving comparable quality to SHAP at much faster speeds.

## Method Summary
The authors propose extending LRP to autoencoders by using Deep Taylor Decomposition to derive propagation rules for reconstruction losses. They formulate novel LRP rules for L1 and L2 reconstruction losses using first and second-order Taylor expansions respectively, ensuring conservation properties are maintained. A self-supervised corruption-based validation method is developed for SQL logs without ground truth explanations. The approach is tested on both SQL workload logs and MVTec image datasets using modified convolutional autoencoder architectures.

## Key Results
- LRP-based explanations are 3-4 orders of magnitude faster than SHAP while maintaining comparable quality
- On image anomaly detection, the method achieves higher average precision (0.328-0.304) compared to residual methods (0.298-0.298)
- Explanations more accurately focus on damaged areas rather than object borders in MVTec images
- Successfully validates on both SQL workload logs and MVTec image dataset with self-supervised corruption method

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: LRP propagation rules satisfy conservation properties that ensure relevance scores remain interpretable and meaningful throughout the network.
- **Mechanism**: The conservation property ensures that the sum of relevance scores at any layer equals the sum at the output layer, maintaining a consistent explanation throughout the network.
- **Core assumption**: The LRP propagation rules correctly implement the conservation property as defined in the equations (Eq. 1, 2, 3, 4).

  - [corpus] Weak - the corpus mentions LRP but doesn't specifically address conservation properties
- **Break condition**: If the propagation rules are incorrectly implemented or if the network architecture introduces connections that violate the layer-wise decomposition assumption.

### Mechanism 2
- **Claim**: Deep Taylor Decomposition provides a principled way to derive LRP rules for reconstruction loss functions by finding root points where the reconstruction error is zero.
- **Mechanism**: By decomposing the reconstruction error function around root points (the input feature vector itself), relevance can be propagated backward through the autoencoder's reconstruction layer.
- **Core assumption**: The reconstruction error function can be locally approximated by Taylor expansion around the input feature vector.
- **Evidence anchors**:
  - [abstract] "We propose a novel LRP-based explainability approach specific to Autoencoders, that allows the propagation of reconstruction errors"
  - [section] "Based on the above assumptions, the only solution is the input feature vector, which is also the optimal solution for Eq. (8)."
  - [corpus] Weak - the corpus mentions Taylor decomposition but not specifically for reconstruction errors
- **Break condition**: If the reconstruction error function is not differentiable or if the Taylor approximation is poor around the root point.

### Mechanism 3
- **Claim**: The proposed LRP rules for L1 and L2 reconstruction losses preserve the conservation property while providing meaningful explanations.
- **Mechanism**: The L1 and L2 reconstruction loss functions are decomposed using first and second-order Taylor expansions respectively, yielding propagation rules that maintain the conservation property.
- **Core assumption**: The Taylor expansion of the reconstruction loss functions can be computed analytically and satisfies the required properties.
- **Evidence anchors**:
  - [abstract] "We propose a novel LRP-based explainability approach specific to Autoencoders"
  - [section] "It is important to mention that for any input sample both of these propagation rules preserve the conservation property"
  - [corpus] Weak - the corpus doesn't mention specific LRP rules for reconstruction losses
- **Break condition**: If the Hessian matrix of the L2 loss is not positive semi-definite or if the L1 loss has discontinuities that prevent meaningful Taylor expansion.

## Architecture Onboarding

- **Component map**: Input layer → Encoder layers → Decoder layers → Output layer → Reconstruction loss layer → LRP backpropagation → Input relevance scores

- **Critical path**: Input → Encoder → Decoder → Output → Reconstruction Loss → LRP Backpropagation → Input Relevance Scores

- **Design tradeoffs**:
  - Computational efficiency vs. explanation quality: The proposed method is 3-4 orders of magnitude faster than SHAP while maintaining comparable quality
  - Model-specific vs. model-agnostic: LRP requires knowledge of the autoencoder architecture but provides faster explanations than model-agnostic methods
  - First-order vs. second-order Taylor expansion: L2 loss uses second-order expansion for zero first-order derivative, while L1 loss uses first-order expansion

- **Failure signatures**:
  - Poor conservation property adherence: Relevance scores don't sum to the reconstruction error
  - Noisy explanations: Relevance scores highlight irrelevant features
  - Slow performance: Explanation generation takes too long compared to baseline methods

- **First 3 experiments**:
  1. Implement LRP for a simple autoencoder with L2 loss and verify conservation property holds
  2. Apply the proposed LRP rules to a SQL workload log dataset and compare with residual explanations
  3. Generate explanations for the MVTec image dataset and validate against ground truth damaged areas

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can we develop a more appropriate evaluation metric for explainability methods beyond average precision?
- Basis in paper: [inferred] The authors note that "the AP metric might not be ideal for evaluation of explainability approaches" and that "developing an appropriate metric is out of the scope of this work, but it is an interesting direction for future research."
- Why unresolved: Current evaluation relies on AP which may not capture the quality of explanations well, particularly when explanations highlight areas adjacent to ground truth damage.
- What evidence would resolve it: A new evaluation metric that better captures the relevance and focus of explanations, validated through experiments showing improved correlation with human judgment of explanation quality.

### Open Question 2
- Question: Can the proposed LRP method be extended to other autoencoder architectures beyond convolutional autoencoders?
- Basis in paper: [explicit] The authors state "the proposed propagation rules for the L1 and L2 reconstruction loss functions allow us to extend the LRP approach to Autoencoders" but only demonstrate this on convolutional architectures.
- Why unresolved: The paper only validates the approach on convolutional autoencoders for image anomaly detection and fully-connected autoencoders for SQL logs, leaving uncertainty about applicability to other architectures.
- What evidence would resolve it: Successful application and validation of the proposed LRP rules on diverse autoencoder architectures (e.g., variational autoencoders, denoising autoencoders) across different domains.

### Open Question 3
- Question: How sensitive are the explanations to different choices of root points in the Deep Taylor Decomposition framework?
- Basis in paper: [explicit] The authors mention that "root points" are chosen based on layer input domains and that the Taylor decomposition depends on these choices, but don't systematically explore sensitivity to different root point selections.
- Why unresolved: The choice of root point could significantly affect the resulting explanations, but the paper doesn't investigate this sensitivity or provide guidance on optimal root point selection.
- What evidence would resolve it: Systematic experiments comparing explanations generated using different root point selection strategies, showing how explanation quality varies with root point choice.

## Limitations

- The self-supervised validation method relies on synthetic corruption which may not fully capture real-world anomaly patterns
- Limited comparison with SHAP only covers specific datasets and metrics
- Conservation property claims are theoretically sound but not empirically verified across diverse autoencoder architectures

## Confidence

- **Conservation property adherence**: High - mathematically proven and consistent with LRP theory
- **Computational efficiency gains**: High - quantitative comparison shows 3-4 orders of magnitude improvement
- **Explanation quality vs. SHAP**: Medium - comparable performance but limited to specific datasets
- **Generalization to different autoencoder architectures**: Low - experiments focus on specific architectures without broader validation
