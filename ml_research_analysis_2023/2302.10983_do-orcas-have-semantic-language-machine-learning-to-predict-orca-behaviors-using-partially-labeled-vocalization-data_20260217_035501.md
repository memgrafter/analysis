# Do Orcas Have Semantic Language? Machine Learning to Predict Orca Behaviors Using Partially Labeled Vocalization Data

## Quick Facts
- arXiv ID: 2302.10983
- Source URL: https://arxiv.org/abs/2302.10983
- Reference count: 12
- Primary result: 96.4% classification accuracy in predicting orca behaviors from vocalizations using partially labeled learning

## Executive Summary
This study investigates whether killer whale vocalizations convey semantic meaning by predicting behavior from sound segments. The researchers developed a deep learning pipeline using a modified ResNet-34 CNN and a custom loss function designed for partially labeled learning. By analyzing 518 segmented vocalizations from McMurdo Sound orcas, they achieved 96.4% classification accuracy in predicting four behaviors (traveling, foraging, socializing, milling/resting). This high accuracy suggests orcas use a semantic language, as vocalizations reliably indicate behavior despite the challenge of partially labeled training data where segments inherit behavior labels from entire recordings.

## Method Summary
The researchers created a deep learning pipeline that processes orca vocalization spectrograms through a modified ResNet-34 convolutional neural network architecture. The key innovation was developing a custom loss function specifically designed for partially labeled learning, where entire recordings are labeled with behavior types but individual sound segments must inherit these labels. The pipeline processes spectrogram images of vocalizations, extracting acoustic features through the CNN layers to predict the behavioral context. The dataset consisted of 518 vocalization segments collected from orcas in McMurdo Sound, Antarctica, representing four distinct behavioral categories.

## Key Results
- Achieved 96.4% classification accuracy in predicting four orca behaviors from vocalizations
- Successfully implemented partially labeled learning approach for acoustic classification
- Demonstrated that orca vocalizations contain predictive information about behavioral context
- Modified ResNet-34 architecture proved effective for orca vocalization analysis

## Why This Works (Mechanism)
The high classification accuracy suggests that orca vocalizations contain acoustic features that reliably encode information about the animal's current behavioral state. The partially labeled learning approach works by assuming that sound segments within a recording share the same behavioral context as the overall recording, allowing the model to learn patterns even when individual segments lack explicit labels. The modified ResNet-34 architecture effectively extracts hierarchical acoustic features from spectrogram representations, capturing both fine-grained and abstract patterns that distinguish different behavioral contexts.

## Architecture Onboarding

**Component map**: Raw audio -> Spectrogram generation -> ResNet-34 CNN -> Feature extraction -> Custom loss function -> Behavior classification

**Critical path**: Spectrogram generation -> ResNet-34 feature extraction -> Custom loss computation -> Final classification layer

**Design tradeoffs**: The modified ResNet-34 trades computational efficiency for deeper feature extraction capability, while the custom loss function sacrifices simplicity for proper handling of label uncertainty. The partially labeled approach prioritizes practical data utilization over perfectly supervised training.

**Failure signatures**: Poor classification accuracy indicates either inadequate feature extraction (CNN layers not capturing relevant patterns) or improper label assignment (partially labeled assumptions invalid). Training instability suggests loss function formulation issues. Low validation accuracy relative to training accuracy indicates overfitting to training data distribution.

**First experiments**: (1) Train on fully labeled subset to establish upper performance bound, (2) Perform ablation study removing custom loss components to verify their contribution, (3) Test alternative CNN architectures (VGG, Inception) for comparative performance

## Limitations
- Small dataset of only 518 vocalizations from single population limits generalizability
- Partially labeled approach assumes segments accurately represent recording-wide behavior
- Modified ResNet-34 architecture not benchmarked against alternative deep learning models
- High accuracy demonstrates predictive relationships but cannot definitively prove semantic meaning
