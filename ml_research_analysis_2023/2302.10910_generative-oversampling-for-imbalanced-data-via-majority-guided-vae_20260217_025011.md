# Generative Oversampling for Imbalanced Data via Majority-Guided VAE

## Quick Facts
- arXiv ID: 2302.10910
- Source URL: https://arxiv.org/abs/2302.10910
- Reference count: 26
- Introduces MGVAE, a VAE-based generative oversampling method using majority-guided priors

## Executive Summary
This paper addresses the class imbalance problem in deep learning by introducing Majority-Guided VAE (MGVAE), a generative oversampling method that leverages a majority-based prior to generate diverse minority class samples. MGVAE employs a pre-training and fine-tuning framework with Elastic Weight Consolidation (EWC) regularization to prevent model collapse when dealing with limited minority class data. The method demonstrates competitive performance improvements over existing oversampling techniques on benchmark image datasets and real-world tabular data.

## Method Summary
MGVAE generates new minority class samples by pre-training a variational autoencoder on the majority class and then fine-tuning it on minority class samples with EWC regularization. The method uses a majority-based prior to guide the generation process, inheriting the diversity and richness of the majority class. During fine-tuning, EWC helps preserve knowledge learned from the majority class while adapting to minority class characteristics. The framework consists of two main phases: pre-training on majority samples to learn rich feature representations, followed by fine-tuning on minority samples with regularization to prevent catastrophic forgetting.

## Key Results
- MGVAE achieves competitive improvements over other over-sampling methods in downstream classification tasks
- The method demonstrates effectiveness on both benchmark image datasets (MNIST, FashionMNIST, CelebA) and real-world tabular data (Musk, Water Quality, Isolet)
- MGVAE shows better performance than baselines at extreme imbalance ratios (ρ = 600), though performance degrades as imbalance increases

## Why This Works (Mechanism)
The core insight is that using a majority-based prior allows the VAE to generate minority samples with greater diversity by leveraging the richer feature space of the majority class. The EWC regularization during fine-tuning prevents the model from forgetting useful representations learned from the majority class while adapting to the minority class, addressing the common problem of model collapse when training on limited data.

## Architecture Onboarding

**Component Map**: Data -> Pre-training (Majority) -> Fine-tuning (Minority + EWC) -> Sample Generation -> Classification Evaluation

**Critical Path**: The most critical sequence is pre-training on majority samples to establish rich feature representations, followed by fine-tuning with EWC to adapt to minority class while preserving majority knowledge.

**Design Tradeoffs**: 
- Tradeoff between diversity of generated samples (favoring majority prior) and class-specific characteristics (favoring minority fine-tuning)
- EWC regularization strength vs. adaptation flexibility during fine-tuning

**Failure Signatures**: 
- Mode collapse during generation (all samples look similar)
- Overfitting to minority class during fine-tuning (training loss decreases but validation performance plateaus)
- Poor diversity in generated samples (low entropy in latent space)

**First Experiments**:
1. Verify VAE reconstruction quality on majority class before fine-tuning
2. Compare sample diversity with and without majority-based prior
3. Evaluate classification performance with different EWC regularization strengths

## Open Questions the Paper Calls Out
The paper explicitly identifies three key open questions:

1. How does MGVAE's performance scale with increasingly large imbalance ratios beyond the tested range (currently tested up to ρ = 600)?
2. What is the computational overhead of MGVAE compared to simpler oversampling methods like SMOTE?
3. How sensitive is MGVAE to the choice of majority class for the prior when multiple majority classes exist in multi-class settings?

## Limitations
- Exact architectural details for MLP and CNN layers are not fully specified
- Hyperparameter values (learning rates, batch sizes, EWC regularization weights) are not provided for individual datasets
- Performance degrades at extreme imbalance ratios, though still better than baselines
