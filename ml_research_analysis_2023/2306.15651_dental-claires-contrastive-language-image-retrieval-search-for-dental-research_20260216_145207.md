# Dental CLAIRES: Contrastive LAnguage Image REtrieval Search for Dental Research

## Quick Facts
- arXiv ID: 2306.15651
- Source URL: https://arxiv.org/abs/2306.15651
- Reference count: 0
- Dental CLAIRES achieves 96% hit@3 and 0.82 MRR for radiograph retrieval

## Executive Summary
Dental CLAIRES introduces a contrastive learning-based search engine for retrieving periapical radiographs using natural language queries. The system jointly embeds text descriptions and dental images into a shared vector space, enabling semantic matching between radiographic findings and clinical descriptions. By training on 50,000 curated periapical radiographs with associated periodontal diagnosis data, the model learns to align visual and textual representations. This approach enables clinicians and researchers to query dental images using descriptive text, potentially improving diagnostic workflows and research efficiency.

## Method Summary
The system employs a dual-encoder architecture with separate transformer-based models for text and image processing. Both encoders are trained using contrastive loss to map corresponding image-text pairs close together in the embedding space while pushing non-matching pairs apart. The text encoder processes descriptions containing periodontal diagnosis, region, and demographic information, while the image encoder extracts features from periapical radiographs. During inference, new queries are encoded and compared against the database using cosine similarity to retrieve the most relevant radiographs. The model is trained on a curated dataset of 50,000 periapical radiographs with corresponding clinical annotations.

## Key Results
- Achieved 96% hit@3 ratio, meaning 96% of correct radiographs appear in top 3 results
- Obtained Mean Reciprocal Rank of 0.82 across all test queries
- Demonstrated superior performance compared to unimodal retrieval approaches using either text or images alone

## Why This Works (Mechanism)
The contrastive learning framework enables Dental CLAIRES to learn meaningful semantic relationships between radiographic features and clinical descriptions. By optimizing the model to align corresponding image-text pairs while distinguishing non-matching pairs, the system develops a joint representation space where similar clinical findings are positioned close together regardless of whether they are expressed visually or textually. This cross-modal understanding allows the model to handle natural language queries that may use different terminology or descriptions than the original annotations while still retrieving relevant radiographs.

## Foundational Learning
- **Contrastive Learning**: Trains models to map similar items close together and dissimilar items far apart in embedding space. Needed to create meaningful cross-modal representations between images and text.
- **Transformer Architecture**: Self-attention mechanisms that capture long-range dependencies in both text and image data. Essential for understanding complex relationships in dental radiographs and clinical descriptions.
- **Cross-Modal Retrieval**: The task of finding relevant items across different data types (text-to-image or image-to-text). Critical for enabling natural language search over visual medical data.
- **Periapical Radiography**: Intraoral X-rays showing entire tooth from crown to root tip and surrounding bone. The specific imaging modality used, requiring domain-specific feature extraction.
- **Periodontal Diagnosis**: Clinical assessment of gum and supporting structure health. Provides the semantic labels needed for supervised contrastive learning.

## Architecture Onboarding

**Component Map**
Text Encoder -> Embedding Space <- Image Encoder

**Critical Path**
Query text → Text Encoder → Text Embedding → Cosine Similarity → Ranked Results

**Design Tradeoffs**
- Chose dual-encoder over cross-attention to enable efficient retrieval at scale
- Used periapical radiographs specifically rather than general dental images for focused domain adaptation
- Selected contrastive learning over supervised classification to enable flexible text queries beyond predefined categories

**Failure Signatures**
- Poor retrieval when clinical descriptions use terminology not present in training data
- Reduced accuracy for radiographs with unusual angles or poor image quality
- Potential bias toward demographic groups overrepresented in training data

**First 3 Experiments**
1. Retrieve radiographs using simple diagnostic terms like "severe periodontitis" or "healthy periodontium"
2. Query by anatomical region descriptions such as "upper right molar" or "lower anterior teeth"
3. Test demographic-based queries like "elderly patient" or "young adult" to evaluate metadata integration

## Limitations
- Performance evaluated only on curated subset of 50,000 radiographs, limiting generalizability
- Results may not transfer to other dental imaging modalities or diverse clinical populations
- Potential biases in training data could affect retrieval fairness across different patient demographics
