# A Concept Knowledge Graph for User Next Intent Prediction at Alipay

## Quick Facts
- arXiv ID: 2301.00503
- Source URL: https://arxiv.org/abs/2301.00503
- Reference count: 35
- Primary result: Achieves 53.3% Recall@1 and 85.3% Recall@10 for online next intent prediction, with 90.64% micro-F1 offline

## Executive Summary
This paper presents AlipayKG, a concept knowledge graph-based system for predicting user next intent deployed at Alipay, serving over 100 million daily active users. The system explicitly models user historical behaviors, rich content interactions, and relations in the Life-Service domain through a structured knowledge graph. A Transformer-based Informer model integrates expert rules from AlipayKG to infer online user's next intent, achieving strong performance in both offline evaluation (90.64% micro-F1 for item-intent understanding) and online deployment (53.3% Recall@1, 85.3% Recall@10 for next intent prediction). The system demonstrates significant improvements in downstream applications including home recommendation, risk management, and search.

## Method Summary
The system constructs AlipayKG, an offline concept knowledge graph in the Life-Service domain, by mining intent nodes from multi-source content and building isA and Consequent relations. An item-intent understanding model uses a multi-modal approach (ResNet for images, StructBERT for text) to predict intent labels for user interacted items. The online next intent prediction model employs an Informer architecture with inputs including intent timestamp, location timestamp, and global timestamp, integrating AlipayKG through GCN and applying mined rules for post-processing. The system is deployed in downstream applications including recall and ranking modules for recommendations.

## Key Results
- Item-intent understanding model achieves 90.64% micro-F1 in offline evaluation
- Online next intent prediction model reaches 53.3% Recall@1 and 85.3% Recall@10
- Deployed system increases CTR by 1.61% for home recommendation
- Risk management coverage of low-risk transactions increases by 100%
- Search CTR improves by 5.8% after deployment

## Why This Works (Mechanism)

### Mechanism 1: Knowledge Graph Structure
AlipayKG explicitly models user intent through a concept knowledge graph with "Intent," "Function," "Product," and "Sememe" nodes connected by "isA" and "Consequent" relations. This structure enables unified representation of heterogeneous user behaviors and improves downstream task performance by mapping diverse interactions into a common semantic space.

### Mechanism 2: Transformer-Based Forecasting
The Informer model, optimized for long sequence forecasting, ingests user intent history, spatial-temporal features, and global time signals. AlipayKG rules (e.g., "take an internet taxi -consequent- buy movie tickets") are injected during post-processing to boost accuracy and interpretability of next intent predictions.

### Mechanism 3: Multi-Modal Item Understanding
A multi-modal model (ResNet + StructBERT) encodes heterogeneous item content (text + images) into unified representations, matched against intent embeddings generated via GCN over AlipayKG. This allows labeling of items with relevant intents offline, improving matching between user interactions and intents.

## Architecture Onboarding

**Component map:**
User behavior -> AlipayKG enrichment -> item-intent labeling -> next intent prediction -> downstream recall/ranking

**Critical path:**
User behavior → AlipayKG enrichment → item-intent labeling → next intent prediction → downstream recall/ranking

**Design tradeoffs:**
Explicit knowledge graph increases interpretability but requires manual ontology curation; multi-modal models increase accuracy but add computational cost; Informer supports long sequences but may be less efficient than simpler models

**Failure signatures:**
Low intent recall if ontology is outdated; prediction latency spikes if GCN/graph updates are slow; downstream CTR drops if intent predictions misalign with user needs

## Limitations
- No ablation studies isolating the contribution of AlipayKG rules from Informer model performance
- Lack of validation for ontology coverage and adaptability to emerging user intents over time
- Missing details on exact mechanism for integrating AlipayKG rules into Informer model
