# APPRAISER: DNN Fault Resilience Analysis Employing Approximation Errors

## Quick Facts
- arXiv ID: 2305.19733
- Source URL: https://arxiv.org/abs/2305.19733
- Reference count: 14
- One-line primary result: Novel method for rapid DNN fault resiliency analysis using approximate computing errors instead of fault injection

## Executive Summary
APPRAISER introduces a novel approach for analyzing DNN fault resilience by leveraging approximate computing errors rather than traditional fault injection methods. The technique substitutes exact hardware units with approximate ones in target layers, executes inference once on validation data, and analyzes accuracy degradation and error propagation patterns. This method eliminates the need for complex fault injection controllers, maintains the inference pipeline integrity, and avoids iterative injection for each fault location. The approach achieves comparable accuracy and error propagation trends to state-of-the-art fault injection while providing significant speedup in the analysis process.

## Method Summary
The APPRAISER method works by systematically replacing exact computing units with approximate ones in specified DNN layers. During inference execution on validation data, the method monitors accuracy degradation and traces error propagation through subsequent layers. Unlike traditional fault injection that requires multiple iterations and complex control mechanisms, APPRAISER performs a single inference pass to gather comprehensive resilience metrics. The approach maintains the original DNN architecture and inference pipeline while substituting approximate computing units that introduce controlled errors, enabling rapid assessment of fault tolerance characteristics across different network configurations.

## Key Results
- Achieves 4,824x speedup compared to traditional fault injection methods
- Provides similar accuracy degradation patterns and error propagation trends as fault injection
- Enables efficient exploration of network architecture, training strategies, and dataset choices for fault resiliency analysis

## Why This Works (Mechanism)
The method exploits the mathematical relationship between approximate computing errors and hardware fault manifestations. By carefully selecting approximate computing units that introduce errors similar to those caused by soft errors in hardware, the approach creates a representative fault model without requiring actual fault injection. The single-pass analysis captures the cumulative effect of errors as they propagate through the network, providing insights into resilience patterns that would traditionally require extensive fault injection campaigns.
