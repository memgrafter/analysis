# Finding Similar Exercises in Retrieval Manner

## Quick Facts
- arXiv ID: 2303.11163
- Source URL: https://arxiv.org/abs/2303.11163
- Reference count: 12
- Primary result: Multi-modal exercise retrieval system achieving 92.68% precision@1 and 88.94% recall@100

## Executive Summary
This paper presents a multi-stage semantic retrieval framework for finding similar exercises in large-scale educational content banks. The system combines a novel Exercise Semantic Representation Model (ESRM) with recall, ranking, and re-ranking stages to achieve high-precision exercise similarity matching. The approach handles multi-modal exercise data (text, images, formulas) and addresses label noise through confidence learning, achieving significant improvements in both offline metrics and online A/B testing.

## Method Summary
The system employs a three-stage retrieval pipeline: recall (text and embedding matching), ranking (multi-task learning with auxiliary tasks), and re-ranking (filtering and personalization). The ESRM model uses a transformer encoder pre-trained on general text, then fine-tuned with multi-modal multi-task pre-training (MMP) and supervised fine-tuning (SFT). The ranking module uses Mixture of Experts (MoE) for dynamic task weighting and confidence learning to handle noisy expert labels. The framework was validated on 350K+ exercises from Tencent's education platform with 23K labeled similar pairs.

## Key Results
- Achieved 92.68% precision@1 and 88.94% recall@100 in offline experiments
- 15.98% improvement in online A/B testing for user acceptance rate and precision
- Effective handling of multi-modal exercise data and label noise
- Demonstrated complementarity between text and embedding matching methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multi-stage retrieval effectively handles scale and personalization
- Mechanism: Layered refinement through recall → ranking → re-ranking stages
- Core assumption: Exercise similarity is best modeled through incremental refinement
- Evidence anchors: [abstract] "define 'similar exercises' as a retrieval process of finding a set of similar exercises based on recall, ranking and re-rank procedures" [section] "A few hundreds similar exercises are retrieved from millions of exercises in the recall module... Dozens of similar exercises are ranked in the ranking module"

### Mechanism 2
- Claim: Multi-modal multi-task pre-training improves semantic representation
- Mechanism: SOP, MLM, contrastive learning, and metadata prediction tasks on unlabeled exercises
- Core assumption: Structural relationships within exercise components are learnable
- Evidence anchors: [section] "multi-modal multi-task pre-training (MMP) → supervised fine-tuning (SFT) learning approach... SOP can be used to learn causal relationships in exercise text while MLM is beneficial for enhancing the representation of subject-specific terminology" [section] "The objective of the contrastive learning is to make es_i and ea_i more similar than es_i and ea_j"

### Mechanism 3
- Claim: Confidence learning reduces noise in expert-labeled pairs
- Mechanism: Joint probability estimation of noisy and true labels, pruning low-confidence samples
- Core assumption: Annotation noise is systematic enough to model and filter
- Evidence anchors: [section] "The consistency rate of annotating samples is usually between 80-85%, so there are some noises in the labeled samples... confidence learning (Northcutt, Jiang, and Chuang 2021) to resolve this problem" [section] "Confidence Learning aims to prune train-set and gains further improvement"

## Architecture Onboarding

- Component map: Pre-training → MMP (SOP, MLM, contrastive, metadata) → SFT → Recall (text + embedding) → Ranking (MTL + MoE) → Re-rank (filtering)
- Critical path: Exercise → ESRM encoding → Recall (top-100) → Ranking (top-20) → Re-rank (final list)
- Design tradeoffs:
  - Multi-task vs. single-task: More tasks improve robustness but increase complexity
  - Exact text match vs. embedding match: Complementary; trade-off between precision and recall
  - MoE gating vs. fixed weights: Dynamic adaptation vs. added complexity
- Failure signatures:
  - Recall stage: Low recall@100 → poor text match or embedding quality
  - Ranking stage: Low precision@5 → overfitting, noise, or poor task alignment
  - Re-rank stage: Wrong personalization → filtering rules too strict or model miscalibrated
- First 3 experiments:
  1. Evaluate ESRM+R@100 with and without exact text matching
  2. Ablate auxiliary tasks (T2, T3) in MTL to measure semantic understanding gain
  3. Test confidence learning pruning threshold on validation set

## Limitations
- Generalizability beyond Chinese education context uncertain
- Results dependent on quality of 23K labeled exercise pairs
- Confidence learning assumes predictable noise patterns
- High computational requirements for pre-training and fine-tuning

## Confidence
- Multi-stage retrieval effectiveness: High
- Pre-training transfer benefits: Medium
- Confidence learning noise reduction: Medium
- Online A/B testing improvements: High
