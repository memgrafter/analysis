# Logic Diffusion for Knowledge Graph Reasoning

## Quick Facts
- arXiv ID: 2306.03515
- Source URL: https://arxiv.org/abs/2306.03515
- Reference count: 40
- Key outcome: LoD achieves gains of 1.6%, 1.2%, 1.4% and 1.5% in average MRR on FB15k, FB15k-237, NELL995 and WN18 respectively.

## Executive Summary
This paper introduces Logic Diffusion (LoD), a plug-in module for knowledge graph reasoning that addresses two major challenges: discovering unseen first-order logical (FOL) paradigms and learning non-duality logic in noisy data. LoD uses relation diffusion and random walking to generate unseen FOL patterns, along with a novel loss function to handle noisy data. Experiments on four public datasets show that LoD significantly improves the performance of mainstream KGR models, particularly on unseen FOL paradigms.

## Method Summary
LoD consists of three main components: Hierarchical Conjunctive Query for discovering unseen FOL through relation diffusion and random walking, Logic Specific Prompt for distinguishing FOL patterns, and Gradient Adaption for balancing learning across different patterns. The method uses a novel LoD Loss function that handles noisy data by distinguishing duality vs non-duality logic through forward and backward relational paths. During training, LoD slightly suppresses the gradient on the fastest-converging FOL pattern to balance learning across diverse paradigms.

## Key Results
- LoD achieves 1.6%, 1.2%, 1.4% and 1.5% average MRR gains on FB15k, FB15k-237, NELL995 and WN18 respectively
- Significant improvements on unseen FOL paradigms across all four datasets
- Ablation study proves the general effectiveness of LoD on noise-rich knowledge graphs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Logic Diffusion (LoD) improves unseen FOL generalization by discovering new query patterns through hierarchical conjunctive query expansion and random walking.
- Mechanism: The LoD architecture constructs a multi-level reasoning sub-graph starting from atomic queries. At each level, it diffuses the sub-graph by sampling neighbors via random walks, effectively generating new, unseen logical patterns that extend beyond the training distribution.
- Core assumption: Unseen FOL queries can be synthesized by structural diffusion from seen queries without losing semantic validity.
- Evidence anchors:
  - [abstract] "The basic idea of LoD is relation diffusion and sampling sub-logic by random walking"
  - [section 4.1] "The middle layer of Hierarchical Conjunctive Query contains the extensions and permutations of Atomic Queries" and "The top layer contains unseen FOL which are not present in the training set"
- Break condition: If the diffusion process generates logically invalid or semantically meaningless queries, the benefit vanishes and may degrade performance.

### Mechanism 2
- Claim: LoD's gradient adaptation mechanism balances learning across diverse FOL paradigms, preventing dominance of simple or frequent patterns.
- Mechanism: During training, the gradient for the fastest-converging FOL pattern is slightly suppressed (attenuation factor z=0.05), allowing harder or long-tail patterns more training opportunity early on.
- Core assumption: Different FOL patterns have different learning difficulty, and gradient suppression can effectively balance their convergence without hurting the overall training dynamics.
- Evidence anchors:
  - [section 4.1] "the model tends to learn dominant or simple FOL, which is detrimental to the overall performance. Thus, we design a training mechanism called Gradient Adaption"
  - [section 4.1] "The key idea of Gradient Adaption is to slightly suppress the gradient on the fastest converging FOL"
- Break condition: If the suppression factor is too aggressive, it could slow down learning for easy patterns and degrade overall convergence.

### Mechanism 3
- Claim: The LoD loss function enforces duality logic during reasoning, enabling robust handling of noisy data with non-duality logic.
- Mechanism: The loss extends forward reasoning with a backward reasoning pass (inverse mapping) and uses a distance threshold to filter out non-duality noisy data, ensuring that only logically consistent query-answer pairs contribute to training.
- Core assumption: Duality (bidirectional mapping) between queries and answers is essential for robust reasoning, and non-duality can be detected and filtered by score-based thresholding.
- Evidence anchors:
  - [abstract] "LoD is accompanied by a novel loss function to further achieve the robust logical diffusion when facing noisy data in training or testing sets"
  - [section 4.2] "we generate backward relational paths with a similar strategy... LoD Loss as follows"
  - [section 4.2] "The noisy data with non-duality logic can be distinguished by score(𝜚 −1, a) with the distance threshold 𝜍"
- Break condition: If the threshold 𝜍 is poorly calibrated, it could incorrectly filter valid data or retain too much noise.

## Architecture Onboarding

- Component map:
  Input: FOL queries (atomic, further, unseen) → Hierarchical Conjunctive Query → Logic Specific Prompt → Gradient Adaption → LoD Loss → Trained model

- Critical path: Query → Hierarchical Conjunctive Query → Logic Specific Prompt → Gradient Adaption → LoD Loss → Trained model

- Design tradeoffs:
  - Random walking increases logical diversity but risks generating invalid queries
  - Gradient suppression balances learning but may slow down convergence on simple patterns
  - LoD Loss adds backward reasoning overhead but improves robustness to noise

- Failure signatures:
  - No improvement on unseen FOL: diffusion may not be generating valid patterns
  - Degraded performance on clean data: LoD Loss may be over-filtering or gradient suppression too aggressive
  - Slow training: excessive random walking or overly complex prompt generation

- First 3 experiments:
  1. Baseline ablation: Run LoD with only hierarchical conjunctive query (no prompt, no gradient adaption) to measure raw diffusion benefit
  2. Noise robustness test: Apply LoD Loss on a noisy KG dataset and compare MRR vs. baseline without LoD Loss
  3. Unseen FOL evaluation: Train on atomic queries only, then test on unseen FOL, comparing LoD vs. non-LoD models

## Limitations
- The effectiveness of random walking for generating semantically valid unseen FOL queries is not thoroughly validated
- Gradient adaption's attenuation factor (z=0.05) may not generalize across different KG datasets
- LoD Loss function's distance threshold for distinguishing non-duality noisy data needs more exploration across diverse noise types

## Confidence
- High confidence in Mechanism 1: The diffusion process via random walking is a well-established technique in graph reasoning, and the hierarchical conjunctive query expansion is clearly described.
- Medium confidence in Mechanism 2: Gradient adaption is theoretically sound, but its effectiveness may vary depending on the dataset and model architecture.
- Medium confidence in Mechanism 3: The LoD Loss function addresses a real problem in noisy KG reasoning, but its robustness across diverse noise types needs further validation.
