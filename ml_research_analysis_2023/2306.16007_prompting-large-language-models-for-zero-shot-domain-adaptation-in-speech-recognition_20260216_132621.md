# Prompting Large Language Models for Zero-Shot Domain Adaptation in Speech Recognition

## Quick Facts
- arXiv ID: 2306.16007
- Source URL: https://arxiv.org/abs/2306.16007
- Reference count: 0
- Key outcome: Two zero-shot ASR domain adaptation methods using LLaMA achieve 6.6% and 7.7% relative WER reductions on out-of-domain TED and financial speech datasets.

## Executive Summary
This paper presents two zero-shot domain adaptation approaches for ASR using a 7B-parameter LLaMA LLM. The first method re-ranks N-best hypotheses from a baseline ASR system using domain-specific prompts, while the second integrates LLaMA into the ASR decoder via gated cross-attention. Both methods require only text prompts for adaptation without ASR model retraining. Experiments demonstrate significant WER reductions and improved entity/OOV word recall on out-of-domain speech datasets.

## Method Summary
The paper proposes two zero-shot domain adaptation methods using LLaMA-7B. The first approach performs second-pass rescoring, where LLaMA re-ranks N-best hypotheses from a HuBERT-CTC ASR system using domain-specific prompts. The second approach, deep LLM-fusion, integrates LLaMA into an encoder-decoder ASR decoder using gated cross-attention modules that merge frozen HuBERT features with LLaMA hidden states. Training uses long-form history prompts derived from previous utterances to improve generalization. Both methods are evaluated on out-of-domain TED and financial speech datasets without additional ASR training.

## Key Results
- Second-pass rescoring achieves 6.6% relative WER reduction on TedLium-2 and 3.3% on SPGISpeech
- Deep LLM-fusion achieves 7.7% relative WER reduction on TedLium-2 and 5.2% on SPGISpeech
- Deep fusion significantly improves entity and OOV word recall compared to baseline ASR
- History-based long-form training outperforms global descriptive prompts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Domain-specific prompts enable LLaMA to adapt to new ASR domains without ASR retraining
- Mechanism: LLaMA re-ranks N-best hypotheses using in-context language model probabilities conditioned on domain prompts
- Core assumption: Domain prompts provide sufficient context for distinguishing domain-appropriate word sequences
- Evidence anchors: Abstract mentions "zero-shot ASR domain adaptation methods using LLaMA"; Section 1 reports WER reductions of 6.6% and 3.3%; weak literature support for LLM prompting in ASR
- Break condition: Generic or unrelated prompts fail to improve baseline ASR performance

### Mechanism 2
- Claim: Gated cross-attention integrates LLaMA into ASR decoder, conditioning on speech features
- Mechanism: HuBERT features serve as keys/values while LLaMA hidden states act as queries in gated attention modules
- Core assumption: Gated attention can merge speech features into LLaMA's representation space without disrupting language knowledge
- Evidence anchors: Abstract describes "deep LLM-fusion: incorporating LLM into the decoder"; Section 3.2.1 details gated-XATT-FFN module; limited ASR literature on LLM decoder fusion
- Break condition: Gating collapse or large modality mismatch degrades language modeling ability

### Mechanism 3
- Claim: Long-form training with history transcriptions improves ASR generalization
- Mechanism: Previous utterance ground-truth transcriptions serve as prompts instead of global descriptive prompts
- Core assumption: Local history context is more relevant than generic prompts for topic coherence
- Evidence anchors: Section 3.2.3 describes long-form training approach; Section 5.2 shows history prompts outperform global prompts; moderate evidence from dialogue modeling literature
- Break condition: Unrelated or noisy history prompts mislead rather than help the model

## Architecture Onboarding

- Component map: ASR base model (HuBERT-CTC or encoder-decoder) → Optional N-best generation → LLaMA LLM (frozen) → Domain prompt (text) → Gated cross-attention modules (optional) → Output transcription
- Critical path: Reranking: ASR decode → LLaMA rescore → select best; Deep fusion: speech encode → gated cross-attention → LLM decode → output
- Design tradeoffs: Reranking is simpler but limited by N-best quality; deep fusion requires joint training but better recovers rare words/entities
- Failure signatures: Reranking fails with poor N-best hypotheses or ineffective prompts; deep fusion fails with gating collapse or modality mismatch
- First 3 experiments:
  1. Run baseline HuBERT-CTC decode on TedLium-2 and SPGISpeech to establish WER
  2. Implement LLaMA reranking with and without prompts; measure WER and entity/OOV recall
  3. Implement deep LLM-fusion with frozen LLaMA and gated cross-attention; train on LibriSpeech with long-form prompts; evaluate on domain datasets
