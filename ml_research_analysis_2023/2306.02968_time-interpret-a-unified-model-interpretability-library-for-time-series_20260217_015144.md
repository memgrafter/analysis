# Time Interpret: a Unified Model Interpretability Library for Time Series

## Quick Facts
- arXiv ID: 2306.02968
- Source URL: https://arxiv.org/abs/2306.02968
- Reference count: 9
- Primary result: time_interpret is a PyTorch-based library extending Captum with methods specifically designed for explaining predictions on time series data.

## Executive Summary
Time Interpret is a PyTorch-based library that extends Captum to provide interpretability methods specifically designed for time series data. The library introduces several novel temporal attribution methods including Temporal Integrated Gradients (TIG), Time Forward Tunnel, and LOF-weighted LIME and KernelSHAP. It supports both white-box and black-box evaluation scenarios with metrics for when true saliency is known (AUP, MSE) or unknown (perturbation-based metrics). The library includes synthetic and real-world datasets, model implementations, and evaluation tools for comprehensive time series interpretability research.

## Method Summary
Time Interpret implements attribution methods by extending Captum to handle temporal data through cropping and interpolation strategies. TIG computes attributions by only interpolating on the last temporal point, Time Forward Tunnel enables any Captum method to work temporally by iteratively cropping input data, and LOF-weighted variants use outlier detection scores as similarity weights. The library provides evaluation metrics including AUP, MSE, accuracy, comprehensiveness, sufficiency, and perturbation-based metrics that measure prediction shifts after masking important features. It supports various PyTorch models including MLPs, CNNs, RNNs, Transformers, and HuggingFace language models.

## Key Results
- TIG computes attributions by only interpolating on the last temporal point, keeping baseline closer to original input
- Time Forward Tunnel enables any Captum method to be used temporally by iteratively cropping input data
- LOF-weighted LIME and KernelSHAP use Local Outlier Factor scores as similarity weights to reduce sensitivity to outliers

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Temporal Integrated Gradients (TIG) improves attribution accuracy by only interpolating on the last temporal point
- Mechanism: By cropping the temporal sequence up to time t and only computing interpolations on the last data point, TIG keeps the baseline closer to the original input data while removing future data points that could influence the attribution
- Core assumption: Future data points at time t should not influence the attribution of the data point at time t
- Evidence anchors:
  - [abstract] "Temporal Integrated Gradients (TIG), which computes attributions by only interpolating on the last temporal point"
  - [section] "we crop the temporal sequence up to a specific time t. Then, we keep all the data points in time fixed, only computing interpolations on the last data point at time t"
- Break condition: If temporal dependencies require future context for accurate attribution, TIG would produce incorrect results

### Mechanism 2
- Claim: Time Forward Tunnel enables any Captum method to be used temporally by iteratively cropping input data
- Mechanism: The method computes attribution iteratively by cropping the input data up to time t and performing the passed feature attribution method, preventing future data from influencing the attribution
- Core assumption: Any feature attribution method can be adapted to temporal data by simply cropping the input sequence
- Evidence anchors:
  - [abstract] "Time Forward Tunnel, which enables any Captum method to be used temporally"
  - [section] "This method expands the work of (Dombrowski et al., 2019), by replacing some of a model's modules before computing feature attributions"
- Break condition: If the attribution method requires full temporal context, cropping would eliminate necessary information

### Mechanism 3
- Claim: LOF-weighted LIME and KernelSHAP reduce sensitivity to outliers by using Local Outlier Factor scores as similarity weights
- Mechanism: The methods use the LOF score as an indication of similarity between masked data and original data, weighting samples by their outlier status rather than their distance
- Core assumption: Samples that are outliers relative to the data distribution should have less influence on the attribution explanation
- Evidence anchors:
  - [abstract] "Local Outlier Factor-weighted LIME and KernelSHAP"
  - [section] "SimilarityScore is lower when x is an outlier" and "These methods should therefore be less sensitive to outliers"
- Break condition: If the data contains no outliers or outliers are meaningful features, LOF weighting could suppress important information

## Architecture Onboarding

- Component map: Attribution methods -> Datasets -> Model prediction -> Attribution computation -> Evaluation
- Critical path: Attribution method → Dataset preprocessing → Model prediction → Attribution computation → Evaluation
- Design tradeoffs: The library prioritizes temporal specificity over generality, extending Captum rather than replacing it, which means maintaining compatibility with existing Captum methods while adding temporal variants
- Failure signatures: Incorrect temporal cropping leading to attribution leakage from future data, baseline selection causing out-of-distribution samples, LOF requiring sufficient data points for meaningful outlier detection
- First 3 experiments:
  1. Run Temporal Integrated Gradients on a simple ARMA dataset with known saliency to verify it correctly attributes to the last temporal point
  2. Test Time Forward Tunnel with Integrated Gradients on a time series to confirm future data is excluded from attributions
  3. Apply LOF-LIME to a dataset with clear outliers to verify outlier samples are downweighted in the attribution process

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the Local Outlier Factor (LOF) weighting in LIME and KernelSHAP affect attribution quality compared to vanilla methods across diverse datasets?
- Basis in paper: [explicit] The paper introduces LOF-based LIME and KernelSHAP methods, claiming they should be less sensitive to outliers by weighting based on LOF scores rather than similarity.
- Why unresolved: The paper presents these methods as novel but does not provide empirical comparisons with standard LIME/KernelSHAP on benchmark datasets to validate their claimed advantages.
- What evidence would resolve it: Quantitative evaluations comparing attribution quality metrics (like AUP, MSE) between LOF-weighted and standard LIME/KernelSHAP across multiple datasets, with statistical significance testing.

### Open Question 2
- Question: Does the Temporal Integrated Gradients (TIG) method provide more accurate feature attributions than standard Integrated Gradients for time series data?
- Basis in paper: [explicit] TIG is presented as a novel adaptation of Integrated Gradients specifically for temporal data, computing attributions by only interpolating on the last temporal point.
- Why unresolved: While the paper describes TIG theoretically, it doesn't include experimental results comparing its performance to standard Integrated Gradients on time series benchmarks.
- What evidence would resolve it: Empirical studies measuring attribution accuracy using metrics like AUP or MSE on synthetic datasets (e.g., ARMA, HMM) where true saliency is known, comparing TIG to standard Integrated Gradients.

### Open Question 3
- Question: How does the Time Forward Tunnel method's ability to handle various prediction tasks (binary, multilabel, multiclass, regression) impact attribution quality compared to task-specific approaches?
- Basis in paper: [explicit] The paper states Time Forward Tunnel allows any Captum method to be used on temporal data and supports multiple task types by using model predictions at time t as target.
- Why unresolved: The paper describes the method's flexibility but doesn't demonstrate whether this general approach performs as well as methods specifically designed for each task type.
- What evidence would resolve it: Comparative studies evaluating attribution quality across different task types using both Time Forward Tunnel and task-specific attribution methods, with ablation studies showing the impact of using predictions vs. explicit targets.

## Limitations

- The paper lacks quantitative evaluation comparing TIG and Time Forward Tunnel against baseline attribution methods on standard time series benchmarks
- No ablation studies are provided showing the impact of LOF weighting on attribution quality
- The temporal specificity of these methods may not generalize well to irregular or multi-scale time series data

## Confidence

The library's claims are **Medium confidence** overall. While the architectural design extending Captum for temporal data is well-founded, several key uncertainties limit confidence:

**Major Uncertainties:**
1. The paper lacks quantitative evaluation comparing TIG and Time Forward Tunnel against baseline attribution methods on standard time series benchmarks
2. No ablation studies are provided showing the impact of LOF weighting on attribution quality
3. The temporal specificity of these methods may not generalize well to irregular or multi-scale time series data

**Critical Assumptions:**
- Temporal cropping at time t sufficiently preserves information for accurate attribution
- LOF-based weighting improves robustness without suppressing meaningful outliers
- Captum's core assumptions hold when extended to temporal contexts
