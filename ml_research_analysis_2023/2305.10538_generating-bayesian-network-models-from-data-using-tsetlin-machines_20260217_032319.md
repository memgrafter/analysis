# Generating Bayesian Network Models from Data Using Tsetlin Machines

## Quick Facts
- arXiv ID: 2305.10538
- Source URL: https://arxiv.org/abs/2305.10538
- Reference count: 13
- Key outcome: The paper introduces a method for constructing Bayesian network structures from data using Tsetlin Machines (TMs). TMs are interpretable machine learning models that learn patterns using conjunctive clauses in propositional logic. The authors propose using TM-derived global feature importance scores to identify parent-child relationships between variables, forming a directed acyclic graph (DAG) that approximates the underlying Bayesian network. The method involves training TMs for each variable as a target, extracting top predictive features via a global strength indicator, and assembling these into a network structure while avoiding cycles. Validation on synthetic data from known Bayesian networks shows the method can produce structures with high similarity (0.75–0.98) to ground truth, depending on network size and TM hyperparameters. Applications to real-world supply chain and customer churn datasets demonstrate practical utility, yielding interpretable dependency structures even with limited data. The approach is fast, interpretable, and scalable, with potential for hybrid extensions.

## Executive Summary
This paper presents a novel method for constructing Bayesian network structures from data using Tsetlin Machines. The approach leverages the interpretability of TMs to extract global feature importance scores, which are then used to identify parent-child relationships between variables. By training an ensemble of TMs for each variable as a target and aggregating the feature strengths, the method proposes a set of candidate parents for each node. These proposals are assembled into a directed acyclic graph, with cycles resolved using a strength-based pruning strategy. The method is validated on synthetic data from known Bayesian networks and applied to real-world datasets, demonstrating its ability to produce interpretable dependency structures efficiently.

## Method Summary
The proposed method involves training Tsetlin Machines for each variable in the dataset, treating it as the target output. An ensemble of TMs with different hyperparameters is used to improve robustness. For each TM, the global feature strength indicator is computed by aggregating clause weights and literal frequencies across all clauses. The top K features with the highest strength scores are proposed as candidate parents for the target variable. These proposals are then assembled into a directed acyclic graph, with cycles resolved by removing the lowest strength edge in each detected cycle. The final DAG approximates the underlying Bayesian network structure.

## Key Results
- The method achieves high similarity scores (0.75–0.98) when compared to ground truth Bayesian network structures on synthetic data.
- Validation on real-world supply chain and customer churn datasets demonstrates practical utility and interpretability.
- The approach is fast and scalable, handling small datasets effectively.
- Ensemble TMs with different hyperparameters improve robustness in identifying true parent-child relationships.

## Architecture Onboarding

- Component map:
  - Data preprocessing: Discretize continuous variables, handle missing values
  - TM training module: Train ensemble of TMs for each variable as target
  - Feature strength aggregation: Aggregate clause weights and literal frequencies across rounds
  - Parent-child proposal engine: Select top K features as parents for each variable
  - DAG construction module: Build initial graph, resolve cycles using strength-based pruning
  - Validation and comparison: Use graph kernels to compare generated DAG with ground truth

- Critical path:
  1. For each variable in dataset:
     a. Train ensemble of TMs with variable as target
     b. Extract and aggregate global feature strengths
     c. Select top K features as parent candidates
  2. Build initial DAG from parent-child proposals
  3. Remove cycles using lowest strength direction
  4. Validate structure using graph kernel similarity scores

- Design tradeoffs:
  - Number of TM training rounds vs. computational cost
  - Ensemble size vs. robustness of feature rankings
  - K value for top features vs. completeness of DAG
  - Cycle removal strategy vs. preservation of important dependencies

- Failure signatures:
  - Low graph kernel similarity scores compared to ground truth
  - Presence of cycles that cannot be resolved without removing critical edges
  - Feature rankings that are unstable across training rounds or ensemble members
  - DAG structures that violate known domain constraints (e.g., parameters with dependencies)

- First 3 experiments:
  1. Validate on synthetic data from known Bayesian networks (e.g., Asia, Child networks) with varying sizes and compare similarity scores
  2. Test robustness by varying ensemble size and number of training rounds on the same dataset
  3. Apply to real-world datasets (e.g., supply chain, customer churn) and validate structural plausibility against domain knowledge

## Limitations
- The method assumes that top predictive features are true parents, which may not hold in presence of confounding variables.
- Cycle removal strategy may arbitrarily eliminate important dependencies if all edges have similar strengths.
- The approach has not been validated against established Bayesian network structure learning algorithms like PC or GES.
