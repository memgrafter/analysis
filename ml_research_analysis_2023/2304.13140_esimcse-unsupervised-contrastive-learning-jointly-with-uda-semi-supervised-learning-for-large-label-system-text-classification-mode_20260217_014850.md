# ESimCSE Unsupervised Contrastive Learning Jointly with UDA Semi-Supervised Learning for Large Label System Text Classification Mode

## Quick Facts
- arXiv ID: 2304.13140
- Source URL: https://arxiv.org/abs/2304.13140
- Reference count: 0
- Primary result: 8-15% accuracy improvement over baseline on Reuters and operational datasets

## Executive Summary
This paper addresses the challenges of large tag system text classification, including tag system complexity, imbalanced data distribution, and high noise. The authors propose a joint training framework that combines ESimCSE unsupervised contrastive learning with UDA semi-supervised contrastive learning, along with adversarial training techniques (FGM and PGD). The method shows significant improvements in accuracy and robustness compared to baseline approaches on both public and operational datasets.

## Method Summary
The proposed method jointly trains ESimCSE unsupervised contrastive learning with UDA semi-supervised contrastive learning on a shared RoBERTa backbone. ESimCSE uses word repetition to create positive pairs and a momentum queue to expand negative samples for learning semantic representations. UDA applies data augmentation (back-translation and TF-IDF word repetition) to unlabeled data and enforces consistency through KL divergence. Adversarial training using FGM and PGD further enhances model robustness. The model is trained on both labeled data (supervised loss) and unlabeled data (unsupervised and consistency losses) simultaneously.

## Key Results
- 8% accuracy improvement over baseline on Reuters dataset
- 10% accuracy improvement over baseline on operational dataset
- 15% improvement in manual validation accuracy on operational dataset

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ESimCSE unsupervised contrastive learning improves semantic representation quality in large tag systems by learning to distinguish similar vs. dissimilar sentences.
- Mechanism: The model uses word repetition to construct positive pairs and maintains a momentum queue to expand negative samples, allowing it to learn fine-grained semantic differences between text with high similarity in tree tag structures.
- Core assumption: The similarity between leaf nodes in the same subtree can be effectively captured through contrastive learning with dynamically expanded negative samples.
- Evidence anchors:
  - [abstract] "ESimCSE model efficiently learns text vector representations using unlabeled data to achieve better classification results"
  - [section] "为了解决子树上面叶子节点数值高相似度的问题，我们引入了无监督动量对比学习 ESimCSE 模型来对句子进行编码"

### Mechanism 2
- Claim: UDA semi-supervised learning improves model performance by leveraging unlabeled data through consistency regularization and data augmentation.
- Mechanism: UDA applies strong data augmentation (back translation, TF-DF word repetition) to unlabeled data, then enforces consistency between predictions on original and augmented versions using KL divergence, while also applying adversarial training for robustness.
- Core assumption: The augmented versions of unlabeled data maintain the same semantic label as the original, allowing consistency regularization to be effective.
- Evidence anchors:
  - [abstract] "UDA is trained using unlabeled data through semi-supervised learning methods to improve the prediction performance of the models and stability"
  - [section] "我们通过引入 google 半监督训练方法 UDA 来对数据增强并进行半监督训练以解决多标签文本分类任务中的文本不均衡问题"

### Mechanism 3
- Claim: Adversarial training (FGM and PGD) enhances model robustness and generalization by exposing the model to worst-case perturbations during training.
- Mechanism: The model generates adversarial examples by adding small perturbations to input embeddings in the direction that maximizes loss, then trains on both clean and adversarial examples to improve robustness.
- Core assumption: The perturbations added during adversarial training remain imperceptible to humans while still challenging the model enough to improve generalization.
- Evidence anchors:
  - [abstract] "adversarial training techniques FGM and PGD are used in the model training process to improve the robustness and reliability of the model"

## Architecture Onboarding

- Component map: Input text -> RoBERTa encoder -> ESimCSE contrastive loss computation -> UDA consistency regularization on augmented data -> Adversarial example generation and training -> Classification head for tag prediction

- Critical path:
  1. Input text → RoBERTa encoder
  2. ESimCSE contrastive loss computation
  3. UDA consistency regularization on augmented data
  4. Adversarial example generation and training
  5. Classification head for tag prediction

- Design tradeoffs:
  - Memory vs. performance: Momentum queue increases memory usage but improves negative sample diversity
  - Training stability vs. robustness: Adversarial training can make training unstable but improves generalization
  - Complexity vs. interpretability: Multiple training objectives make the model more powerful but harder to debug

- Failure signatures:
  - Loss oscillation during training (may indicate adversarial training issues)
  - Very low variance in learned embeddings (may indicate insufficient contrastive signal)
  - Performance gap between labeled and unlabeled data (may indicate UDA consistency issues)

- First 3 experiments:
  1. Train baseline RoBERTa classifier on labeled data only
  2. Add ESimCSE module with contrastive learning objective
  3. Add UDA semi-supervised learning with data augmentation
