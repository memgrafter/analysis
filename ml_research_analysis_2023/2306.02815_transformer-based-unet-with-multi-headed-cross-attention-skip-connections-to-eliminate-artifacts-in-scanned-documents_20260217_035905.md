# Transformer-Based UNet with Multi-Headed Cross-Attention Skip Connections to Eliminate Artifacts in Scanned Documents

## Quick Facts
- arXiv ID: 2306.02815
- Source URL: https://arxiv.org/abs/2306.02815
- Reference count: 28
- Primary result: 53.9% reduction in word error rate on synthetic data for noise removal using Swin Transformer-based UNet with cross-attention skip connections

## Executive Summary
This paper presents a novel UNet architecture that leverages Swin Transformers and multi-headed cross-attention skip connections to remove artifacts from scanned documents. The approach addresses the critical challenge of poor OCR quality caused by compression errors, pixelation, and noise in scanned documents. The model is pre-trained on synthetic datasets containing various artifacts and can be fine-tuned for new artifact types. The cross-attention mechanism enables selective feature learning and incorporates textual commands to control model behavior, achieving significant improvements in artifact removal across multiple degradation types.

## Method Summary
The proposed method employs a Swin Transformer-based UNet architecture with multi-headed cross-attention skip connections. The model is pre-trained on a synthetic dataset containing documents with various artifacts (noise, pixelation, compression) paired with their clean counterparts. The cross-attention skip connections allow the model to selectively learn features and incorporate textual information for task control. The architecture enables the model to converge faster during training compared to conventional skip connections and facilitates learning of opposing tasks (cleaning vs. inversion) using textual commands. The approach achieves state-of-the-art performance in removing different types of document artifacts.

## Key Results
- 53.9% reduction in word error rate on synthetic data for noise removal
- 37.1% improvement for pixelation artifact removal
- 36.0% improvement for compression artifact removal
- Faster convergence during training compared to conventional skip connections

## Why This Works (Mechanism)
The model works by combining the hierarchical feature extraction capabilities of Swin Transformers with the skip connection architecture of UNet. The multi-headed cross-attention skip connections enable selective feature learning by allowing the model to focus on relevant information while ignoring artifacts. The cross-attention mechanism incorporates textual commands that control the model's behavior, enabling it to switch between cleaning and artifact generation tasks. This selective attention approach, combined with the transformer's ability to capture long-range dependencies in document images, results in superior artifact removal performance compared to conventional methods.

## Architecture Onboarding

Component Map:
Input Image -> Encoder (Swin Transformer) -> Cross-Attention Skip Connections -> Decoder -> Output Image

Critical Path:
Input image → Swin Transformer encoder → Cross-attention skip connections → Decoder → Cleaned output

Design Tradeoffs:
- Transformer-based encoder provides better feature extraction but increases computational complexity
- Cross-attention skip connections improve selective learning but add architectural complexity
- Pre-training on synthetic data enables better generalization but may introduce domain shift
- Textual command incorporation adds flexibility but requires additional training data

Failure Signatures:
- Over-smoothing of text details in artifact removal
- Incomplete removal of compression artifacts
- Model confusion when given contradictory textual commands
- Performance degradation on documents with complex layouts

First Experiments:
1. Test artifact removal on synthetic documents with single artifact types
2. Evaluate model's ability to handle multiple artifact types simultaneously
3. Assess performance on real-world scanned documents with varying quality
