# Preventing Catastrophic Forgetting in Continual Learning of New Natural Language Tasks

## Quick Facts
- arXiv ID: 2302.11074
- Source URL: https://arxiv.org/abs/2302.11074
- Authors: 
- Reference count: 40
- Key outcome: Reduces performance drops on old tasks (by up to 20%) while maintaining accuracy on new tasks, matching multi-task learning results without retraining from scratch

## Executive Summary
This paper addresses catastrophic forgetting in NLP when extending multi-task models to new tasks. The authors propose using unlabeled data from original task distributions to distill knowledge from a teacher model into a student model for new tasks. Experiments on GLUE and voice assistant datasets demonstrate that this approach significantly reduces performance degradation on previously learned tasks while maintaining strong performance on new tasks, achieving results comparable to fully retrained multi-task learning models.

## Method Summary
The proposed approach uses knowledge distillation from a frozen teacher model (trained on previous tasks) to a student model (with additional output layer for new task). The student is trained using a combined loss function that includes both the new task loss on labeled data and a distillation loss computed on unlabeled data from the original task distributions. This allows the model to learn new tasks while preserving knowledge of old tasks, preventing catastrophic forgetting without requiring access to the original training data for old tasks.

## Key Results
- Prevents up to 20% performance drops on old tasks while maintaining good performance on incrementally added tasks
- Outperforms traditional knowledge distillation (TKD) that uses only new task data for distillation
- Achieves performance comparable to fully retrained multi-task learning models without retraining from scratch
- Shows effectiveness on both public benchmarks (GLUE) and real-world voice assistant data

## Why This Works (Mechanism)

### Mechanism 1
Using unlabeled data from the original task distributions prevents catastrophic forgetting by allowing the student model to match the teacher's predictions on data resembling the old tasks. The student model is trained to minimize the cross-entropy between its predictions and the teacher's soft predictions on unlabeled data from the same distribution as the old tasks. This creates a distillation loss that preserves the knowledge of the old tasks even as the model learns new tasks.

### Mechanism 2
The approach maintains the general linguistic knowledge learned in language model pretraining, allowing the model to learn new tasks without losing the ability to handle old ones. By preventing catastrophic forgetting of old tasks through distillation, the model retains its general linguistic capabilities, which can be transferred to new tasks rather than being overwritten during fine-tuning.

### Mechanism 3
The proposed approach allows updating an existing MTL model for new tasks while preventing catastrophic forgetting, achieving performance comparable to fully retrained MTL models. By distilling knowledge from the teacher model on unlabeled data from old task distributions while learning new tasks on labeled data, the student model can simultaneously maintain performance on old tasks and learn new tasks effectively.

## Architecture Onboarding

- **Component map**: Teacher model (pre-trained on existing tasks, frozen) -> Student model (copy of teacher with additional output layer for new task) -> Distillation loss (cross-entropy between teacher and student predictions on unlabeled data from old task distributions) -> New task loss (cross-entropy between student predictions and ground truth labels on new task data) -> Overall loss (sum of distillation loss and new task loss)

- **Critical path**: 1) Create student model by copying teacher and adding new output layer 2) Collect unlabeled data from old task distributions 3) Generate soft targets from teacher model on unlabeled data 4) Train student model to minimize combined loss (distillation + new task) 5) Evaluate performance on both old and new tasks

- **Design tradeoffs**: Using unlabeled data from original distributions vs. using new task data for distillation; Temperature setting for soft targets (affects smoothness of output distribution); Balance between distillation loss and new task loss (affects forgetting vs. learning new tasks)

- **Failure signatures**: Large performance drop on old tasks indicates insufficient distillation; Poor performance on new tasks indicates overemphasis on distillation; Instability during training might indicate improper temperature or loss weighting

- **First 3 experiments**: 1) Add a second task to a model trained on a single task using the proposed approach with unlabeled data from the original task distribution 2) Compare the proposed approach with traditional knowledge distillation using only new task data for distillation 3) Incrementally add multiple tasks to a model and evaluate the cumulative effect on performance across all tasks

## Limitations

- The approach requires access to unlabeled data from original task distributions, which may not always be available in practice
- Experiments primarily focus on BERT-based models and NLP tasks, leaving uncertainty about effectiveness on other model architectures or task types
- The paper doesn't address potential privacy concerns or computational overhead associated with maintaining and using unlabeled data from old task distributions

## Confidence

- **High confidence**: The core claim that using unlabeled data from original task distributions improves knowledge distillation for continual learning is well-supported by the experimental results
- **Medium confidence**: The assertion that the approach preserves general linguistic knowledge learned during pretraining is plausible but not directly measured
- **Medium confidence**: The claim that the approach achieves performance comparable to fully retrained MTL models is supported for tested tasks but may not generalize to more diverse task combinations
