# GNN-Ensemble: Towards Random Decision Graph Neural Networks

## Quick Facts
- arXiv ID: 2303.11376
- Source URL: https://arxiv.org/abs/2303.11376
- Reference count: 40
- Primary result: GNN-Ensemble improves node classification F1 scores by 1-2% on benchmark datasets

## Executive Summary
This paper introduces GNN-Ensemble, a method that constructs ensembles of random decision graph neural networks to improve accuracy, reduce overfitting, and enhance adversarial robustness in graph neural networks. The approach involves training multiple GNN models on randomly sampled substructures of the graph and subfeatures of node features, then combining their predictions via voting. Experimental results on four benchmark datasets (Cora, PubMed, PPI, Reddit) show that GNN-Ensemble consistently outperforms single GNN models and improves node classification F1 scores by 1-2% in transductive settings and around 1% in inductive settings.

## Method Summary
The GNN-Ensemble method constructs an ensemble of graph neural networks by training multiple base GNN models on randomly sampled substructures and subfeatures of the original graph. For each base model, the method randomly selects a subset of nodes (and corresponding edges) to create a sampled subgraph, and simultaneously selects a subset of node feature dimensions. Each base GNN is then trained on its unique combination of subgraph and subfeatures. During inference, predictions from all base models are aggregated using soft voting (averaging the prediction probability vectors) to produce the final output. This random decision framework introduces diversity among base models while maintaining the core graph structure information.

## Key Results
- GNN-Ensemble improves node classification F1 scores by 1-2% on Cora and PubMed datasets
- Improves PPI and Reddit datasets by approximately 1% in inductive settings
- Effectively reduces overfitting compared to single GNN models
- Significantly enhances robustness against adversarial attacks compared to existing defense approaches

## Why This Works (Mechanism)
GNN-Ensemble works by introducing diversity among base models through random sampling of graph substructures and node features. This diversity reduces overfitting to specific graph patterns and node feature combinations, while the ensemble voting mechanism aggregates multiple perspectives to improve overall prediction accuracy. The random sampling acts as a form of regularization, forcing each base model to learn from different aspects of the graph data, which collectively provides a more robust representation for node classification tasks.

## Foundational Learning
- Graph Neural Networks (GNNs): Neural networks designed to operate on graph-structured data, aggregating information from neighboring nodes through message passing. Why needed: Forms the base model architecture for ensemble learning.
- Ensemble Learning: Machine learning technique that combines multiple models to improve overall performance. Why needed: Provides the theoretical foundation for combining multiple GNN predictions.
- Subgraph Sampling: Technique of selecting subsets of nodes and edges from a larger graph. Why needed: Creates diversity among base models in the ensemble.
- Node Feature Selection: Process of selecting subsets of feature dimensions for training. Why needed: Further increases diversity among base models.
- Soft Voting: Ensemble aggregation method that averages prediction probability vectors. Why needed: Combines predictions from multiple models in a probabilistic manner.

## Architecture Onboarding

**Component Map:** Graph Data -> Substructure Sampler -> Subfeature Sampler -> Base GNN Model -> Predictions -> Soft Voting Aggregator -> Final Prediction

**Critical Path:** Input Graph -> Random Substructure Sampling (70% nodes) -> Random Subfeature Sampling (50% features) -> Train Base GNN -> Collect Predictions -> Soft Voting Aggregation -> Output

**Design Tradeoffs:** The sampling ratios for substructures (nodes) and subfeatures (dimensions) represent a key tradeoff between model diversity and information retention. Higher sampling ratios preserve more information but reduce diversity, while lower ratios increase diversity but may lose critical structural information.

**Failure Signatures:** Poor performance may indicate overly aggressive sampling (e.g., <30% node sampling) that destroys graph connectivity, or insufficient base models (fewer than 50) that don't provide adequate diversity. Underfitting may occur with very low feature sampling percentages.

**First Experiments:**
1. Start with 70% node sampling and 50% feature sampling, training 50 base models, and compare with a single GNN baseline
2. Vary the sampling ratios systematically (60%, 70%, 80% for nodes; 40%, 50%, 60% for features) to find optimal parameters
3. Test ensemble performance with different base GNN architectures (GraphSage, GAT, GCN) to verify architecture independence

## Limitations
- Lacks specific implementation details on random seed settings and exact sampling strategies
- Claims of consistent 1-2% improvement may be influenced by particular sampling parameter choices
- No ablation studies to validate individual contributions of substructure vs subfeature sampling
- Limited analysis of optimal sampling ratios for different dataset characteristics
