# Sentiment Perception Adversarial Attacks on Neural Machine Translation Systems

## Quick Facts
- **arXiv ID**: 2305.01437
- **Source URL**: https://arxiv.org/abs/2305.01437
- **Reference count**: 7
- **Primary result**: Sentiment perception of NMT outputs can be significantly altered with small input changes using saliency-based synonym substitution

## Executive Summary
This work introduces a novel adversarial attack framework targeting the perceived sentiment of neural machine translation outputs rather than their literal content. Unlike traditional adversarial attacks that aim to change the translation itself, this approach modifies input text to cause the NMT system to produce translations that humans perceive as having different sentiment (e.g., making neutral text appear more positive or negative). The method uses saliency-based synonym substitution with constraints ensuring imperceptibility through visual similarity, semantic similarity, and perplexity bounds. Experiments across four language pairs demonstrate that small, imperceptible input perturbations can significantly shift the perceived sentiment of NMT outputs.

## Method Summary
The attack uses a saliency-based synonym substitution approach where sentiment saliency is calculated for each word based on the change in output sentiment when that word is removed. The top N most salient words are substituted with synonyms while maintaining constraints: visual similarity (Levenshtein distance), semantic similarity (synonym substitution), and perplexity bounds. Sentiment classifiers serve as proxies for human perception. The framework is evaluated on four language pairs using WMT19 test sets and Facebook FAIR's NMT models, with sentiment classification accuracy as the primary metric.

## Key Results
- Sentiment perception of NMT outputs can be changed by -18.0% to -33.3% with small input perturbations
- In some cases, attacking the NMT system is more effective than directly attacking the sentiment classifier
- The attack maintains translation quality (BLEU, CHRF, TER scores remain stable) while altering perceived sentiment

## Why This Works (Mechanism)

### Mechanism 1
The attack changes output sentiment perception without altering the source sequence's sentiment by making small, imperceptible input perturbations (synonym substitutions) that cause the NMT model to produce translations with exaggerated positive/negative sentiment. This works because NMT models map semantically similar inputs to semantically similar outputs, and subtle input changes can cause disproportionate output sentiment shifts.

### Mechanism 2
Using sentiment classifiers as proxies for human perception is valid because high-performance transformer-based sentiment classifiers accurately reflect human judgment of sentiment in NMT outputs. Human evaluation shows 89-93% accuracy of classifiers on original translations and 87-89% on adversarial translations, indicating strong alignment with human perception.

### Mechanism 3
Saliency-based synonym substitution is effective at finding vulnerable words because words with high sentiment saliency contribute most to the output sentiment, and substituting them with synonyms yields the largest sentiment change. Sentiment saliency correctly identifies the words whose substitution most influences the NMT output sentiment.

## Architecture Onboarding

- **Component map**: Input text -> Sentiment saliency calculation -> Synonym substitution -> NMT model (encoder-decoder) -> Sentiment classifier (proxy) -> Evaluation metrics

- **Critical path**: 1) Calculate sentiment saliency for each word in the input, 2) Select top N salient words for substitution, 3) Find synonyms that satisfy imperceptibility constraints, 4) Generate adversarial input by substituting selected words, 5) Translate adversarial input using NMT model, 6) Evaluate output sentiment using sentiment classifier

- **Design tradeoffs**: Trade-off between attack strength (number of substitutions) and imperceptibility; choice of sentiment classifier affects proxy accuracy; synonym selection must balance semantic similarity and sentiment impact

- **Failure signatures**: Low attack success rate despite high saliency scores; input sentiment changes despite constraints; high perplexity in adversarial examples

- **First 3 experiments**: 1) Validate saliency calculation by manually checking top-ranked words for sentiment impact, 2) Test synonym substitution on a small dataset to ensure imperceptibility constraints are met, 3) Compare attack success rate using different sentiment classifiers as proxies

## Open Questions the Paper Calls Out
- What are the effectiveness and limitations of perception-based adversarial attacks across different sequence-to-sequence tasks beyond machine translation, such as text summarization or dialogue generation?
- How do perception-based adversarial attacks scale when targeting multiple aspects of output perception simultaneously (e.g., changing both sentiment and fluency at once)?
- What is the relationship between the imperceptibility constraints used in perception-based attacks and the actual human perception of output quality, particularly for languages with significantly different morphologies?

## Limitations
- Reliance on sentiment classifiers as proxies for human perception without direct human evaluation of translation sentiment shifts
- Use of synonym substitution as the sole attack method, which may not generalize to other perturbation types
- Heuristic imperceptibility constraints that may not fully capture human perception of text naturalness

## Confidence
- **High confidence**: Sentiment perception can be altered with small input changes (well-supported by experimental results showing significant drops in sentiment classification accuracy)
- **Medium confidence**: Attacking NMT systems is more effective than direct attacks on sentiment classifiers in some cases (effect not consistent across all language pairs)
- **Low confidence**: Attacks maintain semantic meaning and fluency (only indirect evidence through perplexity constraints and BLEU scores)

## Next Checks
1. Conduct human evaluation validation where native speakers rate the sentiment of original vs. adversarial translations to verify classifier-detected sentiment shifts align with human perception

2. Test whether the saliency-based approach generalizes to other perturbation types (character-level edits, paraphrasing, back-translation) and whether identified salient words remain vulnerable across different attack vectors

3. Evaluate the attack's effectiveness against common NMT defenses such as adversarial training, input denoising, or ensemble methods to test practical threat level
