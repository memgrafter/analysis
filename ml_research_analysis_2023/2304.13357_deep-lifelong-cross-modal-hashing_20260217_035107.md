# Deep Lifelong Cross-modal Hashing

## Quick Facts
- arXiv ID: 2304.13357
- Source URL: https://arxiv.org/abs/2304.13357
- Reference count: 40
- Key outcome: Proposes a method to reduce training time by over 80% and improve retrieval accuracy by over 20% for continuous cross-modal hashing with new categories.

## Executive Summary
This paper addresses catastrophic forgetting in cross-modal hashing when new data with additional categories arrives continuously. The proposed method, Deep Lifelong Cross-modal Hashing (DLCH), introduces a lifelong learning strategy that directly learns and updates hash functions for incremental data without retraining on all accumulated data. It incorporates a lifelong hashing loss to preserve original hash code quality while learning new codes, and uses multi-label semantic similarity to improve retrieval precision. Experimental results show that DLCH achieves competitive performance compared to state-of-the-art methods while significantly reducing training time and mitigating catastrophic forgetting.

## Method Summary
The method consists of two phases: original learning and lifelong learning. In the original learning phase, LabelNet, ImgNet, and TxtNet are trained to generate hash representations using multi-label semantic similarity and original hash loss. The lifelong learning phase updates hash functions using a sampled training set from original and incremental data, with lifelong loss preserving similarity between original and incremental hash codes. The incremental hash codes are learned bit by bit using discrete cyclic coordinate descent. The method uses alternating optimization and backpropagation for training.

## Key Results
- Achieves comparative performance to state-of-the-art cross-modal hashing methods.
- Reduces training time by over 80% when new data arrives continuously.
- Improves retrieval accuracy by over 20% compared to existing methods.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Lifelong hashing loss enables original hash codes to remain invariant while incremental hash codes are learned, preventing catastrophic forgetting.
- Mechanism: The lifelong hashing loss function is split into two parts: one that preserves similarity between original hash codes and training data (Jold), and one that preserves similarity between incremental hash codes and training data (Jnew). The original hash codes are held fixed during optimization.
- Core assumption: The original hash codes capture sufficient discriminative information to serve as anchors for incremental learning.
- Evidence anchors:
  - [abstract] "Then, we propose lifelong hashing loss to enable original hash codes participate in lifelong learning but remain invariant, and further preserve the similarity and dis-similarity among original and incremental hash codes to maintain performance."
  - [section] "To avoid performance degradation when training on incremental data and keep the learned hash function continuously usable, we design lifelong hashing loss which contains original similarity preserving loss and incremental similarity preserving loss."
- Break condition: If the original hash codes are too rigid or miss important discriminative information for new categories, the incremental learning will be limited.

### Mechanism 2
- Claim: Multi-label semantic similarity improves retrieval precision by capturing richer semantic relationships than single-label similarity.
- Mechanism: Multi-label similarity is defined as the normalized inner product of label vectors, capturing the degree of label overlap. This leads to smaller Hamming distances between truly relevant instances.
- Core assumption: The dataset contains multi-label annotations that can be leveraged to compute meaningful similarity.
- Evidence anchors:
  - [abstract] "Additionally, considering distribution heterogeneity when new data arriving continuously, we introduce multi-label semantic similarity to supervise hash learning, and it has been proven that the similarity improves performance with detailed analysis."
  - [section] "As mentioned before, the existing online cross-modal hashing methods utilize single-label similarity to evaluate correlation of two instances, i.e., they are considered as similar as long as two instances have one common label."
- Break condition: If the dataset only has single labels or the multi-label annotations are noisy, the benefit will diminish.

### Mechanism 3
- Claim: Direct learning of incremental hash codes (instead of retraining all accumulated data) drastically reduces training time.
- Mechanism: The lifelong learning strategy only samples a subset of data from both original and incremental sets to form a training set. The hash functions are updated using this small training set, and the incremental hash codes are learned bit by bit.
- Core assumption: The hash functions learned from the original data generalize well enough to serve as a starting point for incremental learning.
- Evidence anchors:
  - [abstract] "Speciﬁcally, we design lifelong learning strategy to update hash functions by directly training the incremental data instead of retraining new hash functions using all the accumulated data, which signiﬁcantly reduce training time."
  - [section] "We design lifelong learning strategy to directly learn and update hashing function of incremental data with new categories. Then, multi-label semantic similarity and self-supervised strategy are proposed to obtain high-quality hash codes."
- Break condition: If the incremental data distribution shifts drastically from the original data, the hash functions may need more extensive retraining.

## Architecture Onboarding

- Component map: Original learning phase -> LabelNet, ImgNet, TxtNet trained with multi-label semantic similarity and original hash loss. Lifelong learning phase -> hash functions updated using lifelong loss and sampled training set, incremental hash codes learned bit by bit.
- Critical path: The optimization of the hash functions and hash codes using backpropagation and alternating optimization.
- Design tradeoffs: Preserving original hash codes to prevent catastrophic forgetting vs. learning new hash codes for incremental data to adapt to new categories. Adding complexity with multi-label semantic similarity to improve retrieval precision.
- Failure signatures: Catastrophic forgetting (performance degradation on original data), poor retrieval precision (due to inadequate semantic similarity), and high training time (due to inefficient learning strategy).

## Limitations

- The specific values of hyperparameters (α, β, γ, λ, µ) and the exact implementation details of the discrete cyclic coordinate descent algorithm are not fully specified, which could impact reproducibility.
- The effectiveness of the lifelong hashing loss in truly preserving original hash code quality while learning incremental codes remains to be rigorously tested across diverse domain shifts.
- The computational efficiency gains, while promising, need benchmarking against a wider range of online and non-continuous methods under varying data stream conditions.

## Confidence

- **High Confidence**: The core methodology of using multi-label semantic similarity for hash learning is well-founded and likely to improve retrieval precision.
- **Medium Confidence**: The lifelong learning strategy for preventing catastrophic forgetting and reducing training time is theoretically sound but requires more extensive empirical validation across diverse datasets and domain shifts.
- **Low Confidence**: The specific values of hyperparameters (α, β, γ, λ, µ) and the exact implementation details of the discrete cyclic coordinate descent algorithm are not fully specified, which could impact reproducibility.
