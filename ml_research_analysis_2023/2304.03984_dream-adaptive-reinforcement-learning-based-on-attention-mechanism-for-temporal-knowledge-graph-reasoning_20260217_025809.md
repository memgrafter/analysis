# DREAM: Adaptive Reinforcement Learning based on Attention Mechanism for Temporal Knowledge Graph Reasoning

## Quick Facts
- arXiv ID: 2304.03984
- Source URL: https://arxiv.org/abs/2304.03984
- Reference count: 40
- Key outcome: Achieves up to 51.7% MRR and 72.4% H@10 on ICEWS14 dataset

## Executive Summary
This paper introduces DREAM, an adaptive reinforcement learning model for temporal knowledge graph reasoning that addresses key limitations of existing RL-based approaches. DREAM combines a multi-faceted attention mechanism to capture both temporal evolution and semantic dependence, along with an adaptive reward learning framework that reduces reliance on handcrafted rewards. The model demonstrates substantial performance improvements on four benchmark datasets, particularly achieving state-of-the-art results on ICEWS14 with up to 51.7% MRR and 72.4% H@10.

## Method Summary
DREAM employs a multi-faceted attention representation method that simultaneously captures temporal evolution and semantic dependence in temporal knowledge graphs. The model uses an adaptive reinforcement learning framework that learns rewards directly from expert demonstrations rather than relying on manually designed reward functions. This approach allows the system to adapt to different temporal patterns and domain-specific characteristics without requiring extensive domain expertise for reward engineering.

## Key Results
- Achieves up to 51.7% MRR on ICEWS14 dataset
- Achieves 72.4% H@10 on ICEWS14 dataset
- Outperforms state-of-the-art models across four benchmark datasets

## Why This Works (Mechanism)
The paper addresses the fundamental challenge of capturing both temporal evolution and semantic dependence in temporal knowledge graph reasoning. Traditional RL-based methods struggle because they either focus on one aspect (temporal or semantic) or require complex handcrafted rewards that don't generalize well. DREAM's multi-faceted attention mechanism allows it to simultaneously model how relationships evolve over time while maintaining semantic coherence. The adaptive reward learning component eliminates the need for domain-specific reward engineering by learning from expert demonstrations, making the approach more robust and generalizable across different temporal knowledge graph domains.

## Architecture Onboarding

Component Map: Input Data -> Temporal Attention -> Semantic Attention -> Adaptive Reward Learner -> RL Agent -> Output Predictions

Critical Path: Temporal Attention and Semantic Attention features are combined and fed into the Adaptive Reward Learner, which generates rewards for the RL Agent. The RL Agent uses these rewards to learn optimal reasoning strategies for predicting missing elements.

Design Tradeoffs: The multi-faceted attention approach trades computational complexity for improved feature capture, while adaptive reward learning trades initial training overhead for better generalization. The model prioritizes accuracy over inference speed.

Failure Signatures: Poor performance may result from insufficient expert demonstrations for reward learning, or from temporal patterns that don't align well with the attention mechanism's assumptions. Overfitting to specific temporal patterns in training data is also a potential failure mode.
