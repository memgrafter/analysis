# Text Classification in the Wild: a Large-scale Long-tailed Name Normalization Dataset

## Quick Facts
- arXiv ID: 2302.09509
- Source URL: https://arxiv.org/abs/2302.09509
- Reference count: 0
- Primary result: Introduces LoT-insts dataset with 25k classes and achieves 83.73% accuracy, 65.90% macro-F1

## Executive Summary
This paper introduces LoT-insts, a large-scale long-tailed institution name normalization dataset containing over 25k classes. The dataset exhibits a naturally long-tailed distribution, distinguishing it from synthetic alternatives, and includes a carefully constructed test set with four distinct subsets: many-shot, medium-shot, few-shot, and zero-shot open set. The authors propose a specially pretrained BERT-based model that demonstrates superior out-of-distribution generalization on few-shot and zero-shot test sets. The dataset is one order of magnitude larger than existing long-tailed datasets and represents a significant contribution to the field of text classification in realistic, challenging scenarios.

## Method Summary
The authors construct the LoT-insts dataset from a large-scale institution name corpus, leveraging natural long-tail distribution rather than synthetic construction. They develop a specially pretrained BERT model that undergoes additional pretraining on institution-related text before fine-tuning on the target task. The evaluation framework is carefully designed with four test subsets to isolate different learning scenarios: many-shot (classes with abundant examples), medium-shot, few-shot (limited examples per class), and zero-shot open set (classes absent from training). Multiple baseline methods are implemented, including search-based approaches and standard BERT fine-tuning, providing comprehensive comparison points for the proposed method.

## Key Results
- Dataset contains over 25k classes with naturally long-tailed distribution
- Proposed BERT-based model achieves 83.73% accuracy and 65.90% macro-F1 on overall test set
- Outperforms other baseline methods, particularly on few-shot and zero-shot test subsets

## Why This Works (Mechanism)
The proposed approach leverages the inherent structure of institution names and their semantic relationships. By performing additional pretraining on institution-related text, the model develops specialized representations for organizational entities. The carefully designed test subsets isolate different generalization challenges, allowing the model to demonstrate its ability to handle both seen and unseen categories. The naturally long-tailed distribution better reflects real-world scenarios where some institutions are frequent while others are rare or completely absent from training data.

## Architecture Onboarding
Component map: Raw text -> Text normalization -> BERT encoder -> Classification head -> Output predictions

Critical path: Input text undergoes normalization, is encoded by BERT, and passes through a classification layer to produce predictions. The specially pretrained BERT component is critical for capturing institution-specific semantics.

Design tradeoffs: The authors chose additional pretraining on institution text over domain-specific architectural modifications, prioritizing transfer learning efficiency over specialized design. This trades some potential specialization for broader applicability and easier implementation.

Failure signatures: Performance degradation on few-shot and zero-shot subsets indicates insufficient generalization. Poor results on similar institution names suggest the model struggles with fine-grained distinctions. High variance in predictions across different name formats points to normalization issues.

First experiments: 1) Test baseline BERT performance without institution-specific pretraining; 2) Evaluate class-wise accuracy to identify problematic categories; 3) Measure calibration of confidence scores on few-shot and zero-shot subsets.
