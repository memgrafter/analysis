# Playing the Werewolf game with artificial intelligence for language understanding

## Quick Facts
- arXiv ID: 2302.10646
- Source URL: https://arxiv.org/abs/2302.10646
- Reference count: 8
- Deep Wolf AI agent performs comparably to average human players in villager and betrayer roles, but inferior in werewolf and seer roles

## Executive Summary
This study developed Deep Wolf, an AI agent capable of playing the social deduction game Werewolf through natural language conversations. The core method involved fine-tuning a Transformer-based language model (Longformer) to create a value network that predicts the probability of winning given the game state and candidate actions. The AI agent was evaluated by having it play with human players, demonstrating that current language models can understand statements, tell lies, and detect lies in conversations, though there is still room for improvement in more complex roles.

## Method Summary
Deep Wolf uses a fine-tuned Longformer model as a value network to predict win probabilities from game conversation logs. The system generates candidate actions, scores them using the value network, and selects the highest-scoring action. To handle the agent's changing identity during games, the researchers built 20 separate value networks, one for each combination of role and player number. Game logs were augmented by permuting player number pronouns in all 24 possible patterns to ensure role-invariant learning.

## Key Results
- Deep Wolf achieved win rates comparable to average human players in villager and betrayer roles
- Performance was inferior in werewolf and seer roles, highlighting limitations in handling complex strategic reasoning
- The system successfully engaged in natural language conversations while playing Werewolf, demonstrating capabilities in understanding statements, telling lies, and detecting lies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The fine-tuned Longformer-based value network predicts the probability of winning given a game state and candidate action, enabling optimal voting decisions.
- Mechanism: The model maps natural language conversation history to a win probability via a regression head trained on human game logs. This probability is used as a score for candidate actions, and the highest-scoring action is chosen.
- Core assumption: Natural language inputs fully encode the game state and strategic considerations for the agent's role.
- Evidence anchors:
  - [abstract] "fine-tuned a Transformer-based pretrained language model to construct a value network that can predict a posterior probability of winning a game at any given phase of the game and given a candidate for the next action."
  - [section 3.2] "We built a regression model that can calculate the posterior probability of winning a game given an intermediate log at any given game phase from the viewpoint of any player role."
  - [corpus] Weak evidence - no direct citation; corpus neighbors are recent, uncited papers.
- Break condition: If the conversation history omits critical private information (e.g., a werewolf's knowledge of other werewolves), the probability estimate will be inaccurate.

### Mechanism 2
- Claim: Augmenting logs with all permutations of player number pronouns ensures the model learns role-invariant strategic reasoning.
- Mechanism: By swapping number-based pronouns in all 4! = 24 patterns, the agent cannot overfit to specific player IDs and must learn general patterns for each role.
- Core assumption: Role-specific behavior is independent of the numeric identifier assigned to the player.
- Evidence anchors:
  - [section 3.1] "We further augmented each game log by swapping number-based pronouns of coplayers in all possible 4! = 24 patterns so that our AI agent could learn an immutable structure irrelevant to the replacement of player numbers."
  - [abstract] Indirectly supported by the claim that Deep Wolf can play as a villager or betrayer comparably to humans.
  - [corpus] No supporting evidence; corpus contains newer, uncited work.
- Break condition: If the number assignment carries implicit biases (e.g., order of speaking), the augmentation may not fully remove the dependency.

### Mechanism 3
- Claim: Training 20 separate value networks, one per role-player-number combination, avoids confusion about the agent's current identity during inference.
- Mechanism: Each network is dedicated to a specific role and player number, so the input does not need to disambiguate identity and can focus on predicting win probability.
- Core assumption: The agent's identity is static during a game, so a dedicated network per identity is feasible and beneficial.
- Evidence anchors:
  - [section 3.2] "we noticed that our network sometimes made mistakes about its current role and player number. To work around this, we decided to build 20 independent value networks dedicated to each combination of four different roles and five different player numbers."
  - [abstract] Supported by the claim of competitive performance in certain roles.
  - [corpus] No supporting evidence; corpus lacks older, foundational work on identity disambiguation.
- Break condition: If the number of roles or players increases, the O(R x P) network count becomes impractical.

## Foundational Learning

- Concept: Transformer-based language modeling and fine-tuning
  - Why needed here: Enables mapping of natural language game states to win probabilities without hand-crafting features.
  - Quick check question: What is the difference between pretraining and fine-tuning in the context of a language model?

- Concept: Value network regression for decision-making
  - Why needed here: Provides a scalar score for each candidate action so the agent can select the optimal move without explicit tree search.
  - Quick check question: How does a value network differ from a policy network in reinforcement learning?

- Concept: Role-based game mechanics and information asymmetry
  - Why needed here: Werewolf involves hidden roles and private knowledge; the agent must infer roles from public conversation alone.
  - Quick check question: Why is Werewolf considered an imperfect information game?

## Architecture Onboarding

- Component map:
  - Data collector: Web-based Werewolf platform logs
  - Translator & cleaner: Japanese→English, normalization
  - Value network trainer: Longformer fine-tuned with cross-entropy loss
  - Action selector: Candidate utterance generator + value network inference
  - Game runner: Chat interface + voting automation

- Critical path:
  1. Receive conversation history → 2. Select role-specific value network → 3. Generate candidate actions → 4. Score each with value network → 5. Execute highest-scoring action

- Design tradeoffs:
  - Fixed candidate set vs. generative model: Reduces inference time but limits creativity.
  - 20 separate networks vs. single conditional network: Avoids identity confusion but scales poorly.
  - Cross-entropy loss vs. other losses: Standard for binary win/loss labels; ignores game length or margin.

- Failure signatures:
  - Repeated utterances in a game → candidate set too small or filtering too strict.
  - Sudden drops in win probability mid-game → value network overfits to short-term patterns.
  - Identical action scores across candidates → model not learning or candidates too similar.

- First 3 experiments:
  1. Ablate the pronoun-permutation augmentation: Train without swapping player numbers and compare win rates.
  2. Merge the 20 networks into a single conditional network that takes role and player number as input tokens.
  3. Increase the candidate set size by including more diverse human utterances and measure impact on diversity of Deep Wolf's speech.

## Limitations
- Evaluation relied on a relatively small human trial (30 games), limiting statistical power and generalizability
- Performance gap in werewolf and seer roles suggests limitations in handling complex strategic reasoning and information asymmetry
- Fixed candidate action set constrains the agent's ability to generate novel strategies

## Confidence
- **High confidence**: The mechanism of using a fine-tuned language model as a value network for win probability prediction is well-established and technically sound.
- **Medium confidence**: The augmentation strategy (24 pronoun permutations) improves role invariance, though this could be validated through ablation studies.
- **Low confidence**: The comparative performance claims against human players lack rigorous statistical validation and controlled experimental conditions.

## Next Checks
1. Conduct a larger-scale evaluation with 100+ games against human players of varying skill levels, with blind conditions where human participants don't know they're playing against an AI.
2. Perform systematic ablation studies: train without pronoun permutation augmentation and with a single conditional network instead of 20 separate networks to quantify the contribution of each design choice.
3. Analyze failure cases in werewolf and seer roles by examining specific game logs where Deep Wolf underperformed, categorizing the types of strategic reasoning it failed to execute (e.g., tracking inconsistent statements, coordinating with teammates).
