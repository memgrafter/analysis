# Upcycling Models under Domain and Category Shift

## Quick Facts
- arXiv ID: 2303.07110
- Source URL: https://arxiv.org/abs/2303.07110
- Reference count: 40
- This paper addresses source-free universal domain adaptation under both domain and category shift using global and local clustering

## Executive Summary
This paper proposes a novel Global and Local Clustering (GLC) technique for source-free universal domain adaptation (SF-UniDA) that can identify "known" and reject "unknown" data samples under both domain and category shift. The method combines an adaptive one-vs-all global clustering algorithm for pseudo-labeling with a local k-NN clustering strategy to mitigate negative transfer. Extensive experiments on four benchmarks demonstrate state-of-the-art performance across various category-shift scenarios, with GLC achieving 14.8% improvement over UMAD on VisDA in the most challenging open-partial-set scenario.

## Method Summary
The GLC method operates by first initializing a target feature module through fine-tuning the frozen source model on unlabeled target data. It then uses Silhouette criterion to adaptively estimate the number of target categories, applies one-vs-all global clustering with source-private suppression to assign pseudo-labels, and refines these labels using local k-NN consensus clustering. The target model is optimized using combined global and local clustering losses, with entropy thresholding during inference to separate known and unknown samples.

## Key Results
- Achieves state-of-the-art performance across partial-set, open-set, and open-partial-set domain adaptation scenarios
- Outperforms UMAD by 14.8% on VisDA benchmark in open-partial-set DA
- Demonstrates consistent improvements on Office-31, VisDA, and DomainNet benchmarks
- Effectively identifies and rejects unknown categories while maintaining high accuracy on known categories

## Why This Works (Mechanism)

### Mechanism 1
The adaptive one-vs-all global clustering algorithm distinguishes "known" vs "unknown" samples without prior knowledge of category shift by aggregating top-K target samples with highest predicted probability for each source category, finding positive and negative prototypes using K-means, and classifying based on nearest centroid similarity with source-private suppression. The core assumption is that source-private categories have lower mean prediction confidence on target samples than shared categories.

### Mechanism 2
Local k-NN clustering mitigates negative transfer from semantically incorrect pseudo-labels by maintaining a memory bank of target features and predictions, using cosine similarity to find nearest neighbors, and minimizing cross-entropy loss between each sample and its neighbors to encourage local semantic consensus. This assumes the target domain has inherent local structure where semantically similar samples cluster together in feature space.

### Mechanism 3
Silhouette criterion enables adaptive estimation of target domain category count without prior knowledge by enumerating possible category counts, applying K-means clustering, and using Silhouette score to select the configuration with best separation and cohesion. This assumes the true number of target categories will produce clusters with higher Silhouette scores than incorrect numbers.

## Architecture Onboarding

- Component map:
  - Source model (frozen): feature extractor gs and classifier hs
  - Target feature module gt (learned): adapted from gs
  - Global clustering module: one-vs-all clustering with source-private suppression
  - Local clustering module: k-NN consensus clustering
  - Memory bank: stores target features and predictions
  - Silhouette estimator: determines number of target categories

- Critical path:
  1. Initialize target feature module gt by fine-tuning gs
  2. Use Silhouette criterion to estimate target category count Ct
  3. Apply one-vs-all global clustering to assign pseudo-labels
  4. Apply local k-NN clustering to refine pseudo-labels
  5. Optimize target model with combined global and local losses
  6. Use entropy threshold during inference to separate known/unknown

- Design tradeoffs:
  - Global vs local clustering: Global provides semantic separation but may have incorrect assignments; local refines but may not capture global structure
  - K value in one-vs-all: Larger K includes more diverse positives but may include noise; smaller K is more selective but may miss hard samples
  - Number of negative prototypes M: More prototypes better represent negatives but increase computation; fewer are faster but may oversimplify

- Failure signatures:
  - Poor H-score: Likely issues with pseudo-label quality or clustering configuration
  - High entropy on known samples: Classifier confidence threshold may be too high
  - Low Silhouette scores: Clustering algorithm not finding meaningful structure
  - Performance degradation: Local clustering may be overfitting or memory bank outdated

- First 3 experiments:
  1. Ablation study: Run GLC with only global clustering (no local k-NN) to measure contribution of each component
  2. Hyperparameter sensitivity: Test different values of ρ (source-private suppression weight) and η (loss weighting) on validation set
  3. Cluster number estimation: Visualize clustering results for different estimated category counts to verify Silhouette criterion effectiveness

## Open Questions the Paper Calls Out
- How does the performance of GLC scale with increasingly large domain shifts between source and target domains?
- What is the theoretical guarantee that the one-vs-all global clustering approach will correctly identify unknown categories when the target domain has a complex multi-modal distribution?
- How sensitive is GLC to the choice of k in the local k-NN consensus clustering, and what is the optimal selection strategy for different domain adaptation scenarios?
- Can GLC be extended to handle open-set domain adaptation scenarios where unknown categories appear gradually over time (incremental/unsupervised open-set adaptation)?

## Limitations
- The method relies heavily on Silhouette criterion for determining target domain category count, which may fail on datasets with non-convex cluster shapes or overlapping categories.
- The adaptive one-vs-all clustering assumes that source-private categories have systematically lower prediction confidence, which may not hold for all domain shifts.
- The k-NN local clustering depends on maintaining an effective memory bank that may become outdated during adaptation.

## Confidence
- Mechanism 1 (Global clustering distinction): Medium - While the confidence-based source-private suppression shows promise, its effectiveness across diverse domain shifts needs broader validation
- Mechanism 2 (Local k-NN clustering): High - The consensus-based approach is well-established in semi-supervised learning, though its adaptation to UDA needs more empirical verification
- Overall performance claims: Medium - Results show significant improvements over baselines, but the most dramatic gains (14.8% on VisDA) require independent replication

## Next Checks
1. Robustness testing: Evaluate GLC on synthetic datasets with controlled category overlaps to test the limits of Silhouette-based cluster estimation
2. Memory bank analysis: Measure the impact of memory bank staleness by varying update frequencies and tracking pseudo-label stability
3. Cross-dataset generalization: Test the method's performance when source models are trained on different architectures (e.g., VGG, DenseNet) to assess architectural dependence
