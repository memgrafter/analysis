# LEAN: Light and Efficient Audio Classification Network

## Quick Facts
- arXiv ID: 2305.12712
- Source URL: https://arxiv.org/abs/2305.12712
- Reference count: 37
- Primary result: mAP of 0.445 on FSD50K with 4.5MB model size

## Executive Summary
LEAN is a lightweight audio classification model designed for on-device deployment, achieving competitive performance with minimal computational resources. The architecture combines a trainable Wave Encoder (BiLSTM) for raw waveform temporal features with frozen YAMNet embeddings for frequency features, using cross-attention for temporal realignment. The model demonstrates a 22% improvement over baseline on-device approaches while maintaining a compact 4.5MB footprint.

## Method Summary
LEAN processes 1-second audio clips (16kHz) through two parallel feature extraction paths: a Wave Encoder using BiLSTM layers to capture temporal patterns from raw waveforms, and frozen YAMNet embeddings for frequency-domain features. Cross-attention realigns the temporal features by computing attention scores between YAMNet embeddings and Wave Encoder hidden states. The aligned features are concatenated and passed through a classification head for multi-label prediction. The model is trained with binary cross-entropy loss for 40 epochs, achieving 0.4677 mAP on GPU and 0.445 mAP on-device after quantization.

## Key Results
- Achieves 0.445 mAP on FSD50K with 4.5MB model size
- 22% improvement over baseline on-device model
- Cross-attention improves performance on 48% of FSD50K classes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Combining raw waveform temporal features with pretrained YAMNet's frequency features via cross-attention improves audio classification accuracy.
- Mechanism: Wave Encoder extracts temporal patterns from raw waveforms using BiLSTM layers, while YAMNet provides spatial-frequency embeddings. Cross-attention realigns temporal sequences by computing attention scores between YAMNet embeddings and Wave Encoder hidden states, allowing the model to focus on temporally relevant features.
- Core assumption: Temporal and frequency-domain features contain complementary information that can be effectively fused through attention mechanisms.
- Evidence anchors: [abstract] "using a combination of trainable wave encoder, Pretrained YAMNet along with cross attention-based temporal realignment, results in competitive performance"; [section] "We propose to use raw waveform input to capture time-domain features... In contrast, the proposed Wave Encoder is a Bidirectional LSTM-based network."; [corpus] Weak evidence; no corpus papers directly discuss this specific cross-attention fusion approach.
- Break condition: If the attention mechanism fails to learn meaningful alignment, the fusion provides no benefit over simple concatenation, and performance degrades to baseline levels.

### Mechanism 2
- Claim: Using pretrained YAMNet as a frozen feature extractor with a lightweight trainable Wave Encoder keeps model size small while maintaining accuracy.
- Mechanism: YAMNet's pretrained weights (3.7M parameters) are kept frozen during training, providing rich frequency-domain embeddings. The Wave Encoder (BiLSTM layers totaling ~0.88M parameters) learns temporal features on top of this. The combination achieves competitive mAP (0.4677) with only 4.58M total parameters.
- Core assumption: Pretrained frequency features from YAMNet are sufficiently general to transfer to FSD50K, and temporal features can be learned efficiently without full end-to-end retraining.
- Evidence anchors: [section] "YAMNet is mobilenet based architecture... trained on the AudioSet dataset and achieved .306 mAP on the evaluation set."; [section] "Our proposed system achieves on-device mean average precision(mAP) of .445 with a memory footprint of a mere 4.5MB"; [corpus] Weak evidence; corpus papers mention YAMNet transfer learning but not this specific lightweight combination.
- Break condition: If YAMNet's pretrained features are too domain-specific or incompatible with FSD50K, fine-tuning becomes necessary, increasing model size and complexity.

### Mechanism 3
- Claim: Temporal realignment via cross-attention improves class-level performance on 48% of FSD50K classes compared to simple concatenation.
- Mechanism: Cross-attention computes affinity scores between YAMNet embeddings and Wave Encoder hidden states, creating an attentive context vector. This vector is concatenated with YAMNet embeddings, emphasizing temporally relevant features. The mechanism improves mAP from 0.4609 (Joint Model) to 0.4677 (LEAN).
- Core assumption: Certain audio classes benefit more from temporally aligned features, and attention can identify these patterns without significant parameter overhead.
- Evidence anchors: [section] "we use pretrained YAMNet embeddings to realign Wave Encoder output using cross attention... we see an improvement in 70% of the classes compare to YAMNet and further improvement is seen in 48% classes by the realignment scheme."; [section] "Table III captures our various architecture experiments as ablation study... Joint Model + Bahdanau Cross Attention (LEAN) 0.4677 0.944 2.251 4.58M"; [corpus] Weak evidence; corpus papers don't discuss this specific class-level impact analysis.
- Break condition: If cross-attention weights become uniform or random, the realignment provides no benefit, and performance reverts to the Joint Model baseline.

## Architecture Onboarding

- Component map: Raw waveform → Wave Encoder (BiLSTM) → BiLSTM output → Cross-Attention → Concatenation with YAMNet → Classification Head
- Critical path: Raw waveform → Wave Encoder → BiLSTM output → Cross-Attention → Concatenation with YAMNet → Classification
- Design tradeoffs:
  - Model size vs. accuracy: Using frozen YAMNet keeps parameters low (4.58M) but may limit adaptation to FSD50K
  - Temporal resolution: 1-second input provides real-time capability but may miss longer-term dependencies
  - Attention complexity: Bahdanau-style attention adds parameters but improves alignment over simple affinity scores
- Failure signatures:
  - Low mAP (<0.4) suggests issues with feature fusion or attention mechanism
  - High memory usage (>5MB) indicates problems with quantization or model architecture
  - Class imbalance in results suggests inadequate handling of FSD50K's label distribution
- First 3 experiments:
  1. Train Joint Model (Wave Encoder + YAMNet without attention) to establish baseline performance (target: mAP ~0.46)
  2. Add affinity-based cross-attention to Joint Model (target: mAP improvement of ~0.005)
  3. Replace affinity attention with Bahdanau-style attention and tune dense layer units (target: mAP ~0.467)

## Limitations
- Weak external validation of cross-attention mechanism compared to alternative approaches
- Reliance on frozen YAMNet weights may limit adaptation to FSD50K's specific characteristics
- No comparison with other lightweight audio classification architectures

## Confidence
- High Confidence: Model architecture specification and FSD50K benchmark results (mAP: 0.445 on-device, 0.4677 GPU)
- Medium Confidence: 22% improvement claim over baseline lacks external validation on other datasets
- Low Confidence: Cross-attention superiority assertion not empirically validated against other attention mechanisms

## Next Checks
1. Cross-Attention Ablation: Replace Bahdanau-style attention with transformer self-attention and simple concatenation baselines to quantify the specific contribution of the proposed attention mechanism.
2. Domain Generalization: Evaluate LEAN on additional audio classification datasets (e.g., ESC-50, UrbanSound8K) to assess performance consistency across domains and label distributions.
3. Efficiency Analysis: Quantify the trade-off between model size reduction and accuracy loss by comparing LEAN's performance to other lightweight architectures (e.g., MobileNetV2, SqueezeNet) on the same FSD50K benchmark.
