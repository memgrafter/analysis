# Pelphix: Surgical Phase Recognition from X-ray Images in Percutaneous Pelvic Fixation

## Quick Facts
- arXiv ID: 2304.09285
- Source URL: https://arxiv.org/abs/2304.09285
- Reference count: 0
- Key outcome: Pelphix achieves 93.8% accuracy on simulated X-ray sequences and 67.57% on real cadaver data for surgical phase recognition

## Executive Summary
Pelphix introduces the first approach to surgical phase recognition (SPR) for X-ray-guided percutaneous pelvic fracture fixation. The method addresses the data scarcity problem by using Markov-based simulation to generate realistic annotated training data from CT images with anatomical landmarks and bony corridor annotations. A transformer architecture with added spatial supervision learns to recognize surgical phases at four granularity levels (corridor, activity, view, and frame) from the generated synthetic sequences.

The approach demonstrates strong performance on simulated data (93.8% accuracy) and reasonable transfer to real cadaveric X-ray sequences (67.57% accuracy), with up to 88% accuracy for the target corridor level on real data. This work establishes the feasibility of X-ray-based SPR and provides a framework for categorizing phases in X-ray-guided surgery while simulating realistic image sequences.

## Method Summary
Pelphix uses a transformer-based architecture with a U-Net encoder-decoder that receives cross-frame channel polling (previous, current, and next frames) as input. The model is trained on synthetic X-ray sequences generated through Markov-based simulation of surgical workflows, where procedural states are modeled as Markov processes with transitions depending on current state evaluation. Spatial supervision is added through 7 anatomical segmentations, 8 bony corridor masks, 2 tool masks, and 16 landmark heatmaps learned via DICE and NCC losses. The trained model is then applied to real X-ray sequences without fine-tuning.

## Key Results
- 93.8% average accuracy on simulated sequences across all granularity levels
- 67.57% average accuracy on cadaver data across all granularity levels
- Up to 88% accuracy for the target corridor level on real data
- Successful transfer from simulation to real data without fine-tuning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Transformer with cross-frame channel polling captures temporal dependencies needed for X-ray SPR
- Mechanism: By stacking previous, current, and next frames in the channel dimension before encoding, the model learns local temporal patterns that help distinguish between similar-looking frames from different phases
- Core assumption: Local temporal context is sufficient for distinguishing surgical phases in X-ray sequences
- Evidence anchors: Abstract states "Using added supervision from detection of bony corridors, tools, and anatomy, we learn image representations that are fed into a transformer model to regress surgical phases at the four granularity levels"; Section explains cross-pollinating adjacent frames to encourage local temporal features

### Mechanism 2
- Claim: Markov process simulation provides realistic phase transition modeling for training
- Mechanism: The simulation models each procedural state as a Markov process where transitions depend on current state evaluation and adjustment factor, creating realistic variations in workflow while maintaining procedural constraints
- Core assumption: Surgical workflows can be accurately modeled as Markov processes
- Evidence anchors: Section states "We model the procedure as a Markov random process, where transition probabilities depend on realistic evaluation of the current frame"; Simulation proceeds by randomly aligning virtual K-wires and screws with annotated corridors

### Mechanism 3
- Claim: Added spatial supervision improves phase recognition through better feature learning
- Mechanism: The U-Net encoder-decoder provides 7 anatomical segmentations, 8 bony corridor masks, 2 tool masks, and 16 landmark heatmaps as additional training objectives, which forces the encoder to learn anatomically meaningful features
- Core assumption: Features useful for anatomical segmentation and landmark detection are also useful for phase recognition
- Evidence anchors: Abstract mentions "Using added supervision from detection of bony corridors, tools, and anatomy, we learn image representations"; Section describes these spatial annotations provide additional supervision trained with DICE loss for segmentation channels

## Limitations
- Substantial performance drop from 93.8% to 67.57% when moving from simulated to real data
- Limited validation on real data with only 257 images from a cadaver dataset
- Markov simulation assumptions may not fully capture complex surgical workflows and variations
- No comparison to clinical intraoperative X-ray sequences

## Confidence
- **High confidence**: The transformer architecture with spatial supervision effectively learns anatomical features from simulated data, as evidenced by strong performance on the withheld validation set (93.8% accuracy)
- **Medium confidence**: The Markov-based simulation realistically models surgical workflows and provides sufficient variation for training, though this depends on specific parameter choices
- **Low confidence**: The approach generalizes well to real clinical scenarios, given the substantial performance drop and limited real-world validation dataset

## Next Checks
1. **Clinical validation**: Test the trained model on intraoperative X-ray sequences from actual surgical cases to assess real-world performance and identify failure modes specific to clinical environments
2. **Ablation study on spatial supervision**: Train models with and without the anatomical segmentation and landmark detection objectives to quantify their contribution to phase recognition performance on real data
3. **Temporal dependency analysis**: Evaluate the impact of varying the number of frames used in cross-frame polling (e.g., using 5 or 7 frames instead of 3) to determine if longer-range temporal context improves phase distinction
