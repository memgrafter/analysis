# Kernel Interpolation with Sparse Grids

## Quick Facts
- arXiv ID: 2305.14451
- Source URL: https://arxiv.org/abs/2305.14451
- Reference count: 40
- Primary result: Sparse-grid SKI achieves competitive regression accuracy on 8-10 dimensional UCI datasets while scaling efficiently, with up to 4 orders of magnitude speedup over Simplex-GP

## Executive Summary
This paper introduces sparse grids to the SKI framework for scalable Gaussian process inference. SKI accelerates GP inference by interpolating kernel functions onto dense grids of inducing points, but scales poorly with input dimension due to exponential grid growth. Sparse grids mitigate this by using unions of lower-resolution grids, reducing the number of inducing points from O(2^(ℓd)) to O(2^ℓ ℓ^(d-1)) while maintaining interpolation accuracy under smoothness assumptions.

The key contributions are: (1) a nearly linear-time matrix-vector multiplication algorithm for sparse grid kernel matrices, leveraging recursive decomposition and Kronecker structure; (2) simplicial interpolation, which reduces interpolation density from O(2^d) or O(4^d) to O(d^2), avoiding exponential growth in memory and computation. Experiments show the proposed sparse-grid SKI (with simplicial interpolation) achieves competitive regression accuracy on UCI datasets with 8-10 dimensions compared to state-of-the-art methods, while scaling efficiently in both dimension and dataset size. On large-scale datasets, sparse-grid SKI is up to 4 orders of magnitude faster than Simplex-GP while maintaining accuracy.

## Method Summary
The paper introduces sparse grids to SKI by constructing inducing point sets as unions of lower-resolution rectilinear grids, reducing complexity from O(2^(ℓd)) to O(2^ℓ ℓ^(d-1)). A recursive matrix-vector multiplication algorithm exploits Kronecker structure from product kernels, achieving near-linear O(ℓ d 2^ℓ) complexity. Simplicial interpolation further reduces interpolation matrix density from exponential to quadratic growth by partitioning space into simplices. The method is integrated with conjugate gradient solvers for scalable GP inference, tested on UCI datasets with 8-10 dimensions.

## Key Results
- Sparse-grid SKI achieves competitive RMSE on 8-10 dimensional UCI datasets compared to state-of-the-art methods
- On large-scale datasets, sparse-grid SKI is up to 4 orders of magnitude faster than Simplex-GP while maintaining accuracy
- Simplicial interpolation reduces interpolation density from O(2^d) or O(4^d) to O(d^2), enabling scaling to higher dimensions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sparse grids reduce the number of inducing points from exponential to polynomial growth in dimension.
- Mechanism: Instead of using a single dense grid, sparse grids use a union of lower-resolution rectilinear grids whose total resolution is bounded. This limits the number of grid points to O(2^ℓ ℓ^(d-1)) instead of O(2^(ℓd)).
- Core assumption: The kernel function has sufficient smoothness to allow accurate interpolation with fewer points.
- Evidence anchors:
  - [abstract] "sparse grids mitigate this by using unions of lower-resolution grids, reducing the number of inducing points from O(2^(ℓd)) to O(2^ℓ ℓ^(d-1))"
  - [section] "Sparse grids have interpolation accuracy comparable to dense grids under certain smoothness assumptions"
- Break condition: If the kernel lacks smoothness, interpolation accuracy degrades despite the reduced point count.

### Mechanism 2
- Claim: Recursive decomposition enables near-linear matrix-vector multiplication for sparse grid kernel matrices.
- Mechanism: The sparse grid structure allows decomposition into smaller dense grids, enabling recursive application of Kronecker structure and selection operators. This reduces complexity from O(m²) to O(ℓ d 2^ℓ).
- Core assumption: The kernel is a product kernel (shift-invariant or stationary), preserving tensor structure across dimensions.
- Evidence anchors:
  - [abstract] "we contribute a novel nearly linear time matrix-vector multiplication algorithm for the sparse grid kernel matrix, leveraging recursive decomposition and Kronecker structure"
  - [section] "our algorithm is recursive, and critically leverages the fact that sparse grids can be constructed from smaller dense grids"
- Break condition: For non-product kernels, the Kronecker structure is lost, and the near-linear advantage disappears.

### Mechanism 3
- Claim: Simplicial interpolation reduces interpolation density from exponential to quadratic growth.
- Mechanism: Instead of using O(2^d) or O(4^d) points per row in the interpolation matrix W, simplicial interpolation uses only O(d²) points by interpolating within simplices whose extreme points lie on the grid.
- Core assumption: The interpolation domain can be partitioned into simplices whose vertices belong to the grid.
- Evidence anchors:
  - [abstract] "simplicial interpolation, which reduces interpolation density from O(2^d) or O(4^d) to O(d^2)"
  - [section] "we take an approach similar to that of Kapoor et al. [13] and employ simplicial basis functions for interpolation, whose support grows linearly with d"
- Break condition: If the simplex partitioning is too coarse or poorly chosen, interpolation accuracy suffers despite the reduced density.

## Architecture Onboarding

- Component map:
  Sparse grid generator -> Kernel matrix builder -> Simplicial interpolator -> MVM engine -> GP inference wrapper

- Critical path:
  1. Generate sparse grid inducing points
  2. Compute kernel matrix via recursive decomposition
  3. Build simplicial interpolation matrix W
  4. Perform CG iterations: W * (K_sparse * W^T * v)
  5. Optimize hyperparameters via marginal likelihood

- Design tradeoffs:
  - Sparse grids vs dense grids: Accuracy vs memory and compute scaling
  - Simplicial vs cubic interpolation: Speed vs interpolation smoothness
  - Precompute vs on-the-fly: Memory usage vs repeated computation cost

- Failure signatures:
  - Memory overflow: Grid too large for available RAM, especially in high dimensions
  - Slow MVM: Missing batching optimization or incorrect recursive decomposition
  - Poor accuracy: Insufficient resolution or inappropriate simplex partitioning

- First 3 experiments:
  1. Verify sparse grid construction: Compare |G_ℓ,d| against theoretical O(2^ℓ ℓ^(d-1)) bound
  2. Test MVM complexity scaling: Measure runtime of KG_sparse * v vs naive O(m²) baseline
  3. Validate simplicial interpolation: Interpolate a known smooth function and measure L2 error vs cubic interpolation

## Limitations

- Dimensional scaling limits: The ℓ^(d-1) term still grows polynomially with dimension, potentially making the method impractical for dimensions beyond 15-20
- Interpolation accuracy assumptions: Performance relies on smoothness assumptions that may not hold for all kernels, particularly non-smooth kernels like Matérn with low ν
- Computational complexity constants: The near-linear O(ℓ d 2^ℓ) complexity has unspecified constants from recursive decomposition and batching that could impact practical performance

## Confidence

- **High confidence**: The core algorithmic contributions (sparse grid construction, recursive MVM algorithm, simplicial interpolation) are well-specified and the theoretical complexity improvements are mathematically sound. The UCI experiment results showing 4 orders of magnitude speedup are internally consistent.
- **Medium confidence**: The interpolation accuracy claims and dimensional scaling behavior are supported by theory and experiments, but rely on smoothness assumptions that aren't fully validated across kernel types. The method appears robust for RBF kernels but generalization to other kernels needs verification.
- **Low confidence**: The exact implementation details of the recursive MVM algorithm and batching optimizations are not fully specified, making exact reproduction challenging. The paper mentions "advanced batching techniques" without detailed description.
