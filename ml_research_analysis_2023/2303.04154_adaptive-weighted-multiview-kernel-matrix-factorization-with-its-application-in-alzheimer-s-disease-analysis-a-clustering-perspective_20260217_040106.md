# Adaptive Weighted Multiview Kernel Matrix Factorization with its application in Alzheimer's Disease Analysis -- A clustering Perspective

## Quick Facts
- arXiv ID: 2303.04154
- Source URL: https://arxiv.org/abs/2303.04154
- Reference count: 40
- Primary result: Proposed method achieves 54.78% clustering accuracy on ADNI dataset, outperforming baseline methods

## Executive Summary
This paper addresses Alzheimer's disease clustering using multi-view data (imaging and genetic) by proposing an adaptive weighted kernel non-negative matrix factorization method. The method extends traditional NMF by incorporating kernel mappings to handle non-linear data structures and adaptively learning weights for different data views. Using the ADNI dataset with 4 views (VBM, FreeSurfer, FDG-PET, SNPs), the proposed approach achieves clustering accuracy of 54.78%, outperforming baselines like single-view NMF (43.25%), feature concatenation (43.65%), and multi-view NMF (48.97%). The method also identifies important genetic and imaging biomarkers associated with Alzheimer's disease, demonstrating its effectiveness for multi-modal AD analysis.

## Method Summary
The proposed Adaptive Weighted Multiview Kernel Matrix Factorization method combines kernel transformations with multi-view non-negative matrix factorization to handle non-linear data structures and learn view-specific importance weights. The algorithm applies kernel mappings to each view independently, then performs joint factorization across all views while learning adaptive weights that reflect each view's contribution to clustering. The optimization framework uses alternating direction method of multipliers (ADMM) to solve the non-convex problem, iteratively updating the consensus matrix, view-specific representations, and weights. The method integrates graph regularization to preserve local structure and uses L1-norm regularization to encourage sparse weight learning.

## Key Results
- Clustering accuracy of 54.78% on ADNI dataset with 4 views (VBM, FreeSurfer, FDG-PET, SNPs)
- Outperforms single-view NMF (43.25%), feature concatenation (43.65%), and multi-view NMF (48.97%)
- Identifies hippocampal measures and APOE-ε4 as important biomarkers consistent with AD pathology
- Demonstrates effectiveness of kernel methods in capturing non-linear relationships in AD data

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Kernel mapping allows the method to handle non-linear data structures that vanilla NMF cannot separate
- Mechanism: By mapping data into higher-dimensional space Φ: R^d → R^p (possibly infinite with Gaussian kernels), linear separability is achieved in transformed space while maintaining computational efficiency through kernel trick
- Core assumption: The data contains non-linear patterns that become linearly separable after appropriate kernel transformation
- Evidence anchors:
  - [abstract]: "Different from previous vanilla Non-negative Matrix Factorization which assumes data is linearly separable, we propose a simple yet efficient method based on kernel matrix factorization, which is not only able to deal with non-linear data structure but also can achieve better prediction accuracy"
  - [section 3.2]: "Most traditional NMF and existing multi-view methods make the clustering/classification analysis based on original data directly, where the accuracy highly relies on the assumption that it is linearly separable in original space"

### Mechanism 2
- Claim: Adaptive weighting learns the relative importance of different data views automatically
- Mechanism: The method learns weights β_a for each view through optimization, allowing views with better clustering performance to contribute more to the final consensus
- Core assumption: Different data modalities have varying relevance to the Alzheimer's disease clustering task
- Evidence anchors:
  - [abstract]: "To perform better clustering in AD analysis, in this paper we propose a novel model to leverage data from all different modalities/views, which can learn the weights of each view adaptively"
  - [section 3.1]: "Eq. (2) utilizes all the data from different views with a consensus G*, and treat each view of the same importance. However, in practice, different views may have various weights, which inspires us to propose a formulation that can learn the weights accordingly"

### Mechanism 3
- Claim: The combination of kernel mapping and adaptive weighting addresses both non-linearity and view heterogeneity simultaneously
- Mechanism: By applying kernel transformation to each view independently and then learning both the transformed representations and view weights, the method can capture complex patterns while emphasizing the most informative modalities
- Core assumption: Alzheimer's disease manifests through both non-linear relationships in individual modalities and heterogeneous importance across modalities
- Evidence anchors:
  - [abstract]: "Experimental results on ADNI dataset demonstrate the effectiveness of our proposed method, which indicate promising prospects of kernel application in AD analysis"
  - [section 5.3]: "We observe that hippocampal measures (LHippocampus, RHippocampus, LHippV ol and RHippV ol) are also identified, which is in accordance with the fact that in the pathological pathway of AD, medial temporal lobe including hippocampus is firstly affected"

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the choice of kernel function (linear, polynomial, Gaussian) affect the clustering accuracy and biomarker identification in the proposed adaptive weighted kernel multi-view NMF framework?
- Basis in paper: [explicit] The paper mentions using different kernels (linear, polynomial, Gaussian) but only provides results for a linear kernel in the biomarker identification section.
- Why unresolved: The paper only briefly mentions kernel choice without systematically comparing their effects on clustering performance and biomarker discovery.
- What evidence would resolve it: A comprehensive comparison of clustering accuracy (using metrics like NMI, Rand Index) and biomarker identification quality across different kernel functions on the same ADNI dataset.

### Open Question 2
- Question: What is the optimal value of the hyperparameter γ in the adaptive weight learning mechanism, and how does it impact the stability and convergence of the algorithm?
- Basis in paper: [explicit] The paper states "γ plays a key factor to learn the adaptive weights" and mentions γ = 2 was used in experiments, but does not explore the sensitivity to this parameter.
- Why unresolved: The paper sets γ = 2 without justification and does not investigate how different values affect the algorithm's performance or convergence behavior.
- What evidence would resolve it: A sensitivity analysis showing clustering accuracy and convergence speed across a range of γ values (e.g., 0.5, 1, 1.5, 2, 2.5, 3) on the ADNI dataset.

### Open Question 3
- Question: How does the proposed method handle missing data or incomplete samples across different views, and what is the impact on clustering performance?
- Basis in paper: [inferred] The paper mentions removing incomplete samples from the ADNI dataset but does not discuss how the method handles missing data within the framework.
- Why unresolved: Real-world multi-view datasets often contain missing values, and the paper does not address this common issue or evaluate the method's robustness to incomplete data.
- What evidence would resolve it: Experiments comparing clustering performance with varying levels of missing data (e.g., 10%, 20%, 30% missing) using data imputation strategies or model modifications that handle missing values directly.

## Limitations
- Performance claims are based on a single dataset (ADNI), limiting generalizability
- Choice of kernel parameters (σ for Gaussian kernels, degree d for polynomial kernels) affects results but optimal selection criteria are not fully specified
- Computational complexity increases with number of views, potentially limiting scalability

## Confidence

- High confidence: The fundamental mechanism of combining kernel methods with NMF for non-linear pattern discovery
- Medium confidence: The adaptive weighting approach for view importance learning, as empirical validation across multiple datasets is limited
- Medium confidence: The identified biomarkers (hippocampal measures, APOE-ε4) align with established AD pathology, though statistical significance of these associations is not explicitly reported
