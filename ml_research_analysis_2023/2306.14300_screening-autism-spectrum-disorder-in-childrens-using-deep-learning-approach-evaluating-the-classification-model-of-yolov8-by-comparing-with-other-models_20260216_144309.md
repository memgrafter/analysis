# Screening Autism Spectrum Disorder in childrens using Deep Learning Approach : Evaluating the classification model of YOLOv8 by comparing with other models

## Quick Facts
- arXiv ID: 2306.14300
- Source URL: https://arxiv.org/abs/2306.14300
- Reference count: 0
- This study proposes using YOLOv8 for screening Autism Spectrum Disorder (ASD) in children by analyzing facial images, achieving 89.64% accuracy.

## Executive Summary
This study proposes using YOLOv8, a deep learning model primarily designed for object detection, to screen Autism Spectrum Disorder (ASD) in children by analyzing facial images. The researchers trained and tested the model on a Kaggle dataset containing over 3,000 images, categorized into autistic and non-autistic groups. The model achieved a classification accuracy of 89.64% and an F1-score of 0.89. The results demonstrate that deep learning models like YOLOv8 can effectively screen ASD in children using facial features, potentially providing a cost-effective and efficient solution for early detection and intervention.

## Method Summary
The study utilized YOLOv8, a deep learning model typically used for object detection, and adapted it for classification tasks in ASD screening. The model was trained and tested on a dataset of over 3,000 facial images obtained from Kaggle, divided into autistic and non-autistic categories. The researchers evaluated the model's performance using standard metrics such as classification accuracy and F1-score.

## Key Results
- YOLOv8 achieved a classification accuracy of 89.64% for screening Autism Spectrum Disorder in children using facial images
- The model obtained an F1-score of 0.89, indicating good precision and recall in its classifications
- Deep learning models like YOLOv8 can be effectively applied to classification problems in medical screening applications, despite being primarily designed for object detection

## Why This Works (Mechanism)
The study's success in using YOLOv8 for ASD screening is attributed to the model's ability to learn and identify subtle facial features associated with autism. The deep learning approach allows the model to process and analyze complex patterns in facial images that may be indicative of ASD, which might not be easily discernible to human observers. By training on a large dataset of labeled images, the model learns to distinguish between autistic and non-autistic facial features, potentially capturing nuanced characteristics that correlate with ASD diagnosis.
