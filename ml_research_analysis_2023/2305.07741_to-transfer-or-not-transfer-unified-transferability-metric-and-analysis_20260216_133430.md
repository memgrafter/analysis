# To transfer or not transfer: Unified transferability metric and analysis

## Quick Facts
- arXiv ID: 2305.07741
- Source URL: https://arxiv.org/abs/2305.07741
- Reference count: 34
- Introduces WDJE metric for unified transferability assessment across classification and regression tasks

## Executive Summary
This paper introduces WDJE (Wasserstein Distance based Joint Estimation), a new metric for estimating transferability in transfer learning that works across both classification and regression tasks. WDJE leverages Wasserstein distances to capture both domain and task differences in a unified framework, providing a theoretically grounded bound that can be computed even with limited or no target labels. The method addresses a key limitation of existing approaches by enabling decision-making on whether to transfer without requiring extensive target domain data.

## Method Summary
WDJE computes a transferability score by comparing the upper bound of target risk with transfer against the target risk without transfer. The metric uses Wasserstein distances to quantify both domain differences (feature distribution differences) and task differences (label distribution differences). When target labels are scarce, WDJE approximates task differences using source label distribution, allowing bound computation without extensive target labeling. The method trains source models on source domains, calculates Wasserstein distances between source and target distributions, computes the WDJE score, and validates against empirical target loss after fine-tuning.

## Key Results
- WDJE provides superior approximations of target performance compared to state-of-the-art metrics across image classification and regression tasks
- The metric effectively determines when transfer learning should be applied, with consistency index measuring prediction accuracy against empirical transferability
- WDJE works even with limited target labels by approximating task differences using source label distribution

## Why This Works (Mechanism)

### Mechanism 1
- Claim: WDJE determines whether to transfer by comparing the upper bound of target risk with transfer against the target risk without transfer
- Mechanism: The metric computes Trs,t = sup{RDT(h(DS,DT),fT)} - RDT(h(∅,DT),fT), where a negative value indicates transfer is beneficial and positive value indicates transfer should be avoided
- Core assumption: The upper bound on target risk can be computed from source model performance, domain differences, and task differences without needing to train on target data
- Evidence anchors:
  - [abstract]: "The WDJE facilitates decision-making on whether to transfer or not by comparing the target risk with and without transfer."
  - [section]: "If Trs,t < 0, it suggests that the transfer task is worth being conducted because the transfer is likely to generate performance gains. Conversely, if Trs,t≥ 0, it is not recommended to conduct the transfer because the transfer is likely to not provide any benefits."

### Mechanism 2
- Claim: Wasserstein distance can quantify both domain and task differences for both classification and regression problems
- Mechanism: W[pS(x),pT(x)] measures feature distribution differences and W[pS(y),pT(y)] measures label distribution differences, working for both discrete and continuous spaces
- Core assumption: Wasserstein distance provides meaningful distance measures between arbitrary distributions without requiring shared support
- Evidence anchors:
  - [abstract]: "The proposed bound relates the target risk to source model performance, domain and task differences based on Wasserstein distance."
  - [section]: "The Wasserstein distance can be computed by either solving the Monge problem, which aims to find an optimal transport plan, or solving the Kantorovich problem, which aims to find the optimal coupling of the measures."
  - [corpus]: Weak evidence - corpus neighbors discuss domain adaptation but don't explicitly validate Wasserstein distance for task differences

### Mechanism 3
- Claim: The proposed bound can be computed with limited or no target labels by approximating task differences using source label distribution
- Mechanism: When target labels are scarce, W[pS(y),pT(y)] is approximated as E[yS∼pS2(y)][|yS|p]1/p, allowing bound computation without extensive target labeling
- Core assumption: Source label distribution provides sufficient information to approximate task differences when target labels are limited

## Open Questions the Paper Calls Out
- How can WDJE be extended to multi-source transfer learning scenarios? The authors mention extending the metric to multi-source scenarios in the future, but the paper focuses on single-source transfer learning without exploring how WDJE would perform with multiple sources.
- How does WDJE perform when applied to guide model design and training processes in classification and regression problems with domain and task differences? The paper demonstrates WDJE's effectiveness in estimating transferability but doesn't investigate whether the metric can be used as a practical tool during model development.
- How does WDJE compare to other transferability metrics when the number of target labels is extremely limited or zero (fully unsupervised)? While the theoretical extension to unsupervised settings is provided, the paper doesn't provide comparative experiments with other metrics in this extreme scenario.

## Limitations
- Computational complexity becomes significant for high-dimensional data when computing Wasserstein distances
- The approximation of task differences using source label distributions may not hold for significantly different tasks
- Limited ablation studies on how different components of the WDJE metric contribute to final performance

## Confidence
**Confidence: Medium** - While the theoretical framework is well-established, practical implementation faces significant challenges including computational expense for high-dimensional data and potential unreliability of the bound when source and target tasks are fundamentally different.

**Confidence: Low** - The paper provides limited ablation studies on how different components of the WDJE metric contribute to final performance, and the computational complexity and scalability for large-scale transfer learning scenarios remains unclear.

## Next Checks
1. **Cross-dataset robustness test**: Validate WDJE's consistency across diverse domain pairs beyond the current image classification and RUL prediction tasks, including natural language and time-series datasets.
2. **Label scarcity analysis**: Systematically vary the number of target labels available and measure how WDJE's approximation quality degrades, particularly testing the claim about limited target labels.
3. **Computational complexity benchmarking**: Compare WDJE's runtime and memory requirements against state-of-the-art metrics like NCE and H scores across different dataset sizes and dimensionalities.
