# Listener Model for the PhotoBook Referential Game with CLIPScores as Implicit Reference Chain

## Quick Facts
- arXiv ID: 2306.09607
- Source URL: https://arxiv.org/abs/2306.09607
- Reference count: 24
- Key outcome: Achieves >77% accuracy on unseen images/game themes, outperforming baseline by >17 percentage points

## Executive Summary
This paper introduces a listener model for the PhotoBook referential game that predicts whether images are shared with a partner by directly assessing utterance-image relevance using CLIPScore features, eliminating the need for extracted reference chains. The model employs a DeBERTa Transformer with dense learning signals, achieving state-of-the-art performance without requiring explicit reference chain extraction. The approach leverages CLIPScore's semantic similarity between utterances and images to create implicit reference chains, while dense label construction at every timestep forces the model to track dialogue context continuously.

## Method Summary
The model uses a DeBERTa-based Transformer that reads full dialogue and incorporates CLIPScore features to assess utterance-image relevance. CLIPScores are computed between each utterance and the 6 context images, then projected and infused with DeBERTa hidden states at all layers. The model employs dense learning signals by constructing labels for every timestep, requiring predictions about each target image's status (undecided, common, different) throughout the dialogue. A 2-layer MLP classifier produces final predictions, and the model is trained with maximum likelihood estimation using AdamW optimizer.

## Key Results
- Achieves >77% accuracy on test set for predicting shared images
- Outperforms baseline by over 17 percentage points
- Successfully handles unseen images and game themes without reference chain extraction
- Ablation studies confirm both CLIPScore inputs and dense learning signals are essential for performance

## Why This Works (Mechanism)

### Mechanism 1
- CLIPScore vectors provide implicit reference chains by capturing utterance-image relevance
- CLIPScore measures semantic similarity between utterances and images, creating high scores when an utterance describes an image
- Core assumption: CLIPScore peaks correlate with images being referred to in dialogue
- Evidence: "In our pilot study, we find that the CLIPScore of an utterance-image pair is particularly high when the utterance describes the image"
- Break condition: If CLIPScore fails to capture semantic similarity for PhotoBook images

### Mechanism 2
- Dense learning signals improve accuracy by forcing continuous prediction
- Labels are constructed for every timestep, requiring the model to judge image status throughout dialogue
- Core assumption: Continuous prediction forces the model to track dialogue context more carefully
- Evidence: "we construct labels for all timesteps, forming a label sequence...At each timestep t, the label of a target image, yj,t ∈ L, is one of {undecided, common, different}"
- Break condition: If dialogue becomes too long and dense, continuous prediction might overwhelm the model

### Mechanism 3
- DeBERTa with CLIPScore infusion captures multimodal context without explicit reference chains
- CLIPScore vectors are projected and summed with DeBERTa hidden states at all layers
- Core assumption: CLIPScore vectors contain sufficient information about which images are being discussed
- Evidence: "utterance-level CLIPScores are projected and summed with DeBERTa hidden states at all layers"
- Break condition: If CLIPScore vectors become too noisy or fail to distinguish between similar images

## Architecture Onboarding

- Component map: Tokenized dialogue utterances → DeBERTa encoding → CLIPScore infusion → MLP classification → Target image prediction
- Critical path: Dialogue tokens → DeBERTa encoding → CLIPScore infusion → MLP classification → Target image prediction
- Design tradeoffs:
  - Using CLIPScore vs explicit reference chains: avoids extraction errors but depends on CLIPScore quality
  - Dense vs sparse labels: provides richer learning signals but increases computational cost
  - DeBERTa vs vision-language Transformers: avoids pretraining domain mismatch but requires explicit multimodal fusion
- Failure signatures:
  - Overfitting on image combinations
  - Poor performance on visually similar images (cup/dining table and car/motorcycle themes)
  - Degradation when removing CLIPScore or dense learning signals
- First 3 experiments:
  1. Verify CLIPScore correlates with utterance-image relevance by computing CLIPScore peaks for reference utterances
  2. Test DeBERTa with and without CLIPScore infusion to measure impact on accuracy
  3. Compare dense vs sparse label construction by training models with different label schemes

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the model perform if trained on a dataset with more diverse image combinations and themes?
- Basis: The paper discusses overfitting behavior due to the limited number of images (360) and image combinations in the PhotoBook dataset
- Why unresolved: The authors hypothesize that limited dataset size leads to overfitting but don't provide evidence by training on a more diverse dataset
- What evidence would resolve it: Training the model on a larger, more diverse dataset and comparing performance would provide evidence for or against the overfitting hypothesis

### Open Question 2
- Question: What is the impact of using different vision-and-language models (e.g., ViLBERT) instead of CLIPScore for assessing utterance-image relevance?
- Basis: The paper uses CLIPScore but mentions other vision-and-language Transformers are pretrained on 'single image-short text' pairs
- Why unresolved: The authors do not explore other vision-and-language models or compare their performance to CLIPScore
- What evidence would resolve it: Implementing the model with different vision-and-language models and comparing performance would provide evidence for the best approach

### Open Question 3
- Question: How would the model perform if it could process the entire game (all 5 rounds) instead of just one round?
- Basis: The authors mention that processing the entire game would lead to sequence lengths longer than most pretrained Transformers have seen
- Why unresolved: The authors leave this setting for future endeavors
- What evidence would resolve it: Implementing a memory mechanism or adapting the model to process the entire game and comparing performance would provide evidence for the importance of full game context

## Limitations
- Relies on CLIPScore's ability to capture utterance-image relevance, which may not generalize to all image types
- Limited dataset size may lead to overfitting, particularly on visually similar image categories
- Performance degrades on highly similar images (cups/dining tables, cars/motorcycles)

## Confidence

**High Confidence**: The model architecture and implementation details are clearly specified, with well-defined components and strong ablation study evidence.

**Medium Confidence**: The claim that CLIPScore acts as an implicit reference chain is supported by pilot study observations but lacks comprehensive validation across all dialogue types and image categories.

**Low Confidence**: The assertion that this approach completely eliminates the need for reference chain extraction is overstated, as the model still depends on CLIPScore's implicit tracking.

## Next Checks

1. **CLIPScore Alignment Verification**: Conduct systematic analysis measuring correlation between CLIPScore peaks and actual reference events across the full dataset, stratified by image category and dialogue complexity.

2. **Visual Similarity Stress Test**: Design controlled evaluation using highly similar images to measure performance degradation and identify failure patterns.

3. **Generalization Benchmark**: Test the model on dialogue datasets from different domains to assess whether the CLIPScore-based approach generalizes beyond the PhotoBook corpus.
