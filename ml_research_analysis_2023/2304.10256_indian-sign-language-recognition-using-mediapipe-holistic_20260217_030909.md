# Indian Sign Language Recognition Using Mediapipe Holistic

## Executive Summary
This study addresses the communication challenges faced by deaf and hard-of-hearing individuals in India by developing a robust Indian Sign Language (ISL) recognition system. The authors propose a method that leverages MediaPipe Holistic to capture hand, face, and pose landmarks, eliminating the need for video storage and reducing computational complexity. Two machine learning models are evaluated: CNN for static sign recognition and LSTM for gesture-based sign recognition. The CNN model achieves an F1 score of 0.9775 for static signs, while the LSTM model achieves 100% accuracy for gesture signs. The system is implemented in a Django web application with text-to-sign and speech-to-sign conversion capabilities, using a speech recognition API. The research highlights the importance of selecting appropriate models for different sign language categories and demonstrates the potential of technology to improve accessibility and communication for the deaf community.

## Method Summary
The authors developed an ISL recognition system using MediaPipe Holistic to extract hand, face, and pose landmarks from videos, storing only 1662 keypoints per frame as numpy arrays. They collected 60 videos for each of 26 static alphabet signs and 5 gesture-based words, with 30 frames per video. The dataset was split 80/20 for training and testing. For static signs, a CNN model with three Conv2D layers, MaxPooling, and dense layers was trained using Adam optimizer and sparse categorical cross-entropy loss. For gesture signs, an LSTM model with three LSTM layers, batch normalization, dropout, and dense layers was trained using Adam optimizer and categorical cross-entropy loss. The models achieved high accuracy on their respective sign categories and were deployed in a Django web application with text-to-sign and speech-to-sign conversion features.

## Key Results
- CNN model achieves F1 score of 0.9775 for static ISL sign recognition
- LSTM model achieves 100% accuracy for gesture-based ISL sign recognition
- Django web application successfully implements text-to-sign and speech-to-sign conversion

## Limitations

- Limited dataset size with only 26 static signs and 5 gesture words, lacking diversity in signers and environmental conditions
- Dual-model approach requires manual classification of signs as static or gesture, which could introduce errors
- Performance heavily dependent on MediaPipe Holistic's landmark extraction accuracy, which may degrade under poor lighting or occlusion conditions
