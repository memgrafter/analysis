# Towards Foundation Models for Scientific Machine Learning: Characterizing Scaling and Transfer Behavior

## Quick Facts
- arXiv ID: 2306.00258
- Source URL: https://arxiv.org/abs/2306.00258
- Reference count: 40
- Key outcome: Pre-training neural operators on diverse PDE systems enables few-shot learning with orders of magnitude less data than training from scratch

## Executive Summary
This paper investigates the potential of pre-train and fine-tune paradigms for scientific machine learning by studying transfer learning behavior in neural operators. The authors systematically examine how pre-training on multiple PDE systems (Poisson's, Advection-Diffusion, and Helmholtz equations) affects transfer performance when adapting to downstream tasks. Through controlled experiments varying model size, dataset size, and physics parameters, they demonstrate that pre-trained models significantly outperform training from scratch, requiring substantially less data to achieve target accuracy levels. The work provides empirical evidence that the pre-train and fine-tune approach, successful in general ML, can be effectively applied to scientific domains with neural operators.

## Method Summary
The paper uses Fourier Neural Operators (FNO) as the model architecture for learning solution operators of partial differential equations. Pre-training involves minimizing mean-squared error between predicted and ground truth PDE solutions on a diverse dataset containing multiple PDE systems with varying coefficients and source functions. The model incorporates per-instance normalization based on relative source function norms to handle different physical scales. For downstream tasks, the pre-trained model is either directly evaluated (zero-shot) or fine-tuned using Adam optimizer with cosine learning rate decay. The experiments systematically scale model size, dataset size, and out-of-distribution shifts in physics parameters to characterize transfer behavior.

## Key Results
- Pre-trained models achieve desired accuracy levels with orders of magnitude less downstream data compared to training from scratch
- Larger pre-trained model sizes consistently improve transfer performance across all downstream tasks
- Zero-shot transfer works well for in-distribution parameter ranges but degrades with significant out-of-distribution shifts
- Cross-operator transfer (e.g., pre-training on Poisson's equation, fine-tuning on Helmholtz) shows promising results, though performance varies by operator pair

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pre-training on diverse PDE systems creates shared feature representations that generalize across different physics problems
- Mechanism: The Fourier Neural Operator learns spectral kernels that capture universal solution patterns across different PDE operators, allowing knowledge transfer between problems like Poisson's and Helmholtz equations
- Core assumption: The solution operators for different PDEs share sufficient mathematical structure (e.g., differential operators, boundary conditions) that can be exploited through spectral methods
- Evidence anchors:
  - [abstract] "We study the transfer behavior of these models as (i) the pre-trained model size is scaled, (ii) the downstream training dataset size is scaled, (iii) the physics parameters are systematically pushed out of distribution"
  - [section] "We include the coefficient/source functions for all the operators as inputs to the model, with zero values if those terms do not exist in a given PDE instance"
  - [corpus] Weak - corpus doesn't specifically address PDE transfer learning mechanisms
- Break condition: When downstream problems involve fundamentally different mathematical structures (e.g., hyperbolic vs elliptic PDEs) that don't share spectral properties

### Mechanism 2
- Claim: Input normalization based on relative source function norms enables robust transfer across problems with different physical scales
- Mechanism: Normalizing inputs by the median source norm creates scale-invariant representations that prevent parameter magnitude mismatches between pre-training and downstream tasks
- Core assumption: The relative scaling between source functions and PDE coefficients carries meaningful physical information that should be preserved during transfer
- Evidence anchors:
  - [section] "We first normalize every training example source and coefficient inputs with respect to a reference source value defined as the median source norm over the training dataset"
  - [section] "This ensures the source norms are within a reasonable scale range" and "scaling both coefficients as well as source functions of the inputs by a constant yields the same inputs to the neural operator"
  - [corpus] Weak - corpus doesn't address normalization strategies for scientific transfer learning
- Break condition: When source function norms vary by orders of magnitude within a single problem domain, making median-based normalization ineffective

### Mechanism 3
- Claim: Zero-shot performance demonstrates that pre-trained models capture generalizable solution patterns that don't require fine-tuning for in-distribution tasks
- Mechanism: The FNO learns frequency-domain representations of solution operators that encode fundamental relationships between inputs and outputs, enabling direct application to new instances of the same PDE class
- Core assumption: The Fourier basis provides a natural representation for PDE solutions that captures essential physics independent of specific parameter values
- Evidence anchors:
  - [abstract] "We observe excellent zero-shot and few-shot TL performance of the pre-trained model despite the modest OOD shifts"
  - [section] "We consider zero-shot adaptation where the pre-trained model is tested on a downstream application without any fine-tuning"
  - [corpus] Weak - corpus focuses on foundation models generally but not specifically on zero-shot scientific transfer
- Break condition: When downstream tasks involve significant distribution shifts that require learning entirely new solution patterns not captured in pre-training

## Foundational Learning

- Concept: Transfer learning in scientific contexts
  - Why needed here: Scientific problems often have limited labeled data but rich underlying physics that can be leveraged from related problems
  - Quick check question: Can you explain why pre-training on multiple PDE systems might help with solving a new, related PDE?

- Concept: Out-of-distribution generalization
  - Why needed here: Scientific applications frequently require models to extrapolate beyond the exact parameter ranges seen during training
  - Quick check question: How would you design an experiment to test whether a pre-trained model can handle parameter ranges outside its training distribution?

- Concept: Spectral methods for PDE solution operators
  - Why needed here: Fourier-based neural operators exploit the inherent spectral properties of many PDEs, enabling efficient learning of solution mappings
  - Quick check question: What advantages does working in Fourier space provide when learning PDE solution operators compared to spatial domain approaches?

## Architecture Onboarding

- Component map: Input normalization -> Fourier transform -> Spectral convolution blocks -> Output prediction
- Critical path: Input normalization → Fourier transform → Spectral convolution blocks → Output prediction
- Design tradeoffs:
  - Model size vs. data efficiency: Larger models show better transfer performance but require more computational resources
  - Fourier mode cutoff vs. generalization: Higher cutoffs capture more detail but increase overfitting risk
  - Input normalization strategy vs. physical interpretability: Different normalization schemes affect both performance and physical meaning of learned representations
- Failure signatures:
  - Poor zero-shot performance on in-distribution tasks indicates insufficient feature sharing during pre-training
  - Degraded performance with increasing OOD shift suggests limited extrapolation capability
  - Training instability with small downstream datasets points to overfitting in fine-tuning phase
- First 3 experiments:
  1. Train FNO on SYS-1 (Poisson's equation) with varying diffusion coefficients, then test zero-shot on held-out coefficient ranges
  2. Fine-tune pre-trained model on SYS-2 (Advection-Diffusion) with different advection-to-diffusion ratios, comparing data efficiency vs. training from scratch
  3. Test same pre-trained model on SYS-3 (Helmholtz) to evaluate cross-operator transfer capability

## Open Questions the Paper Calls Out
- How does the performance of pre-trained neural operators generalize to 3D spatial systems and spatio-temporal PDEs?
- What is the impact of incorporating self-supervision with PDE loss penalty during pre-training on the transfer learning performance?
- How do different neural operator architectures (e.g., DeepONet, U-FNO) compare in terms of their scaling and transfer learning behavior?

## Limitations
- Findings are based on only three specific PDE systems, limiting generalizability to other scientific domains
- Input normalization strategy may break down for datasets with extreme value distributions
- Scaling experiments focus on model size but don't comprehensively explore the interaction between dataset diversity and transfer performance

## Confidence

**High confidence**: Core finding that pre-training improves data efficiency for neural operators
- Well-validated through systematic experiments across multiple PDE systems and parameter ranges
- Pre-trained models require orders of magnitude less data than training from scratch

**Medium confidence**: Mechanism explanations for why transfer works
- Mathematical intuition for spectral kernel transfer is sound
- Limited prior literature specifically validating these mechanisms for scientific ML

**Low confidence**: Generalizability to entirely different PDE classes
- Experimental validation focused on three related PDE types
- Unclear how well mechanisms extend to hyperbolic vs elliptic systems

## Next Checks
1. **Cross-PDE Class Transfer**: Test the pre-trained model on hyperbolic PDEs (e.g., wave equation) to validate whether the spectral kernel transfer mechanism extends beyond elliptic/parabolic systems.

2. **Normalization Robustness**: Design experiments with source function norms varying by 10⁶ within the same dataset to test whether median-based normalization breaks down under extreme scaling.

3. **Dataset Diversity vs. Size Tradeoff**: Systematically vary both the diversity of pre-training data (mixing different PDE types) and the total dataset size to identify optimal pre-training strategies for downstream transfer performance.
