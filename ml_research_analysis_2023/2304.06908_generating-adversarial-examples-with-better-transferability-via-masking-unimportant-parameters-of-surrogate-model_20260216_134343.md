# Generating Adversarial Examples with Better Transferability via Masking Unimportant Parameters of Surrogate Model

## Quick Facts
- arXiv ID: 2304.06908
- Source URL: https://arxiv.org/abs/2304.06908
- Authors: 
- Reference count: 23
- Key outcome: Improves transfer-based adversarial attack success rates by 2.9-4.9% on average when masking unimportant parameters in surrogate models

## Executive Summary
This paper proposes Masking Unimportant Parameters (MUP), a technique that improves the transferability of adversarial examples by identifying and masking unimportant parameters in surrogate models during adversarial generation. Using a Taylor expansion-based metric to evaluate parameter importance, MUP can be naturally combined with existing gradient-based optimizers like MIM, SIM, and TAIG-R. Extensive experiments demonstrate that MUP consistently improves attack success rates across multiple surrogate-victim model pairs on the ImageNet-compatible dataset.

## Method Summary
MUP refines pretrained surrogate models by masking unimportant parameters during adversarial example generation. The method calculates parameter importance scores using a Taylor expansion-based metric that approximates the change in loss when each parameter is set to zero. Based on a masking ratio, unimportant parameters receive a binary mask of zero during gradient computation. This process can be integrated with any gradient-based optimizer without modifying its core mechanics, effectively creating a refined surrogate model that focuses on more generalizable features.

## Key Results
- MUP-TAIG-R improves attack success rates by 4.9%, 4.2%, and 2.9% on average when using Inc-v3, Inc-v4, and DN121 as surrogate models
- MUP consistently outperforms baseline methods (MIM, SIM, TAIG-R) and the comparative work GN
- Ablation study shows the Taylor expansion-based metric outperforms the absolute value-based alternative

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Masking unimportant parameters in the surrogate model improves adversarial example transferability by reducing overfitting to surrogate-specific features.
- Mechanism: The surrogate model contains redundant parameters that are unimportant for prediction but can be exploited to generate adversarial examples that overfit the surrogate's decision boundary. By masking these parameters during adversarial generation, the attack focuses on the more generalizable, important features, leading to adversarial examples that transfer better to unseen victim models.
- Core assumption: The surrogate model has a significant number of unimportant parameters whose gradients can be identified and masked without severely degrading the model's core predictive capability.
- Evidence anchors:

  - [section] "Our motivation comes from the phenomenon observed in the field of network pruning, where a DNN often has a large number of unimportant parameters."

- Break condition: If the surrogate model has very few unimportant parameters (e.g., highly optimized small models), masking will provide little benefit and may hurt performance.

### Mechanism 2
- Claim: The Taylor expansion-based metric accurately identifies parameters that contribute least to the loss when perturbed, making it a good proxy for parameter importance in adversarial settings.
- Mechanism: The metric approximates the change in loss when a parameter is set to zero using first-order gradient information. Parameters with small importance scores contribute minimally to the loss and can be masked without significantly affecting the model's ability to generate adversarial examples.
- Core assumption: First-order gradient information is sufficient to approximate parameter importance for adversarial example generation.
- Evidence anchors:
  - [section] "Vi = |∂L(x,y,θ)/∂θi θi|" (Taylor expansion-based metric definition)

- Break condition: If the loss landscape is highly non-linear or if second-order effects dominate, the first-order Taylor approximation may misidentify important parameters.

### Mechanism 3
- Claim: MUP is compatible with and enhances existing gradient-based adversarial attack optimizers by refining the surrogate model's parameter space.
- Mechanism: Instead of modifying the optimizer's update rules, MUP modifies the surrogate model itself by masking unimportant parameters during each gradient computation. This can be applied to any optimizer (MIM, SIM, TAIG-R) without changing their core mechanics.
- Core assumption: Masking parameters at each iteration during adversarial generation is equivalent to using a refined surrogate model that generalizes better.
- Evidence anchors:

## Architecture Onboarding

- Component map:
  - Surrogate model (pretrained DNN) -> Parameter importance scoring module (Taylor expansion-based) -> Binary mask generator (based on masking ratio) -> Adversarial example generator (any gradient-based optimizer) -> Victim models (for evaluation only)

- Critical path:
  1. Load pretrained surrogate model
  2. For each adversarial example generation iteration:
     a. Compute parameter importance scores
     b. Generate binary mask
     c. Apply mask to surrogate model
     d. Compute gradients using masked model
     e. Update adversarial example
  3. Evaluate transferability against victim models

- Design tradeoffs:
  - Masking ratio: Higher ratios increase transferability but risk degrading the surrogate model's predictive capability
  - Metric choice: Taylor expansion-based vs. absolute value-based (as shown in ablation study)
  - Computational overhead: MUP adds one backpropagation pass per iteration for importance scoring

- Failure signatures:
  - If attack success rates decrease with MUP enabled: Masking ratio may be too high or metric may be misidentifying important parameters
  - If MUP provides no improvement over baseline: Surrogate model may have few unimportant parameters, or victim models may be too similar to surrogate
  - If MUP works well on one victim but poorly on others: The masking may be removing surrogate-specific features that happen to generalize to some victims but not others

- First 3 experiments:
  1. Implement MUP-MIM with masking ratio 0% (baseline) vs. 15% on Inc-v3 surrogate, evaluate against Inc-v4 victim
  2. Implement MUP-SIM with different masking ratios (10%, 20%, 30%) on Inc-v4 surrogate, evaluate against multiple victims
  3. Compare MUP-TAIG-R with absolute value-based metric vs. Taylor expansion-based metric on DN121 surrogate

## Limitations
- Computational overhead of per-iteration parameter importance scoring may become prohibitive for extremely large models
- Limited theoretical justification for why the Taylor expansion-based metric captures adversarial-relevant importance
- Effectiveness may be reduced if surrogate model has few unimportant parameters or victim models are too similar to surrogate
