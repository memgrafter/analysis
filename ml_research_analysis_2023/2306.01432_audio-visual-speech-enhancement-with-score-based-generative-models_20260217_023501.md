# Audio-Visual Speech Enhancement with Score-Based Generative Models

## Quick Facts
- **arXiv ID**: 2306.01432
- **Source URL**: https://arxiv.org/abs/2306.01432
- **Reference count**: 39
- **Key outcome**: Proposed AV speech enhancement system using score-based generative models with visual embeddings shows improved POLQA/PESQ scores and reduced WER compared to audio-only baseline

## Executive Summary
This paper presents an audio-visual speech enhancement system that leverages score-based generative models conditioned on visual information. The method uses audio-visual embeddings from a self-supervised learning model fine-tuned on lipreading, which are incorporated into a noise conditional score network. Experimental results show the proposed system yields improved speech quality compared to its audio-only counterpart, with higher POLQA and PESQ scores. The system also reduces generative artifacts such as phonetic confusions, as evidenced by lower word error rates from a downstream ASR model, particularly at low input signal-to-noise ratios. The audio-visual approach outperforms an audio-only baseline and is competitive with an audio-visual speech separation baseline.

## Method Summary
The proposed system employs a score-based generative model that incorporates visual embeddings from a self-supervised lipreading model. These audio-visual embeddings are used to condition a noise conditional score network for speech enhancement. The model is trained to denoise speech signals by learning the gradient of the log probability density function of clean speech, conditioned on both audio and visual information. This approach allows the model to leverage visual cues from lip movements to guide the enhancement process, particularly in challenging acoustic environments.

## Key Results
- Improved POLQA and PESQ scores compared to audio-only counterpart
- Lower word error rates from downstream ASR model, especially at low SNR
- Competitive performance with audio-visual speech separation baseline

## Why This Works (Mechanism)
The system works by combining audio and visual information through a score-based generative model. Visual embeddings provide additional context about the speaker's mouth movements, which helps guide the denoising process. This is particularly effective when the audio signal is corrupted, as visual information can disambiguate between similar-sounding phonemes. The score-based approach allows for iterative refinement of the speech signal, with each step guided by both the current estimate and the visual context.

## Foundational Learning

**Score-based generative models**
- *Why needed*: Enable iterative refinement of speech signals through denoising diffusion processes
- *Quick check*: Model learns to predict gradients of log probability density

**Noise conditional score networks**
- *Why needed*: Allow conditioning on external information (visual embeddings) during denoising
- *Quick check*: Network architecture can incorporate multimodal conditioning

**Self-supervised visual embeddings**
- *Why needed*: Provide rich visual features without requiring explicit lipreading labels
- *Quick check*: Visual model can be pre-trained on large-scale unlabeled video data

## Architecture Onboarding

**Component map**: Visual model -> Audio-visual embeddings -> Noise conditional score network -> Enhanced speech

**Critical path**: Input audio and video → Visual feature extraction → Score network denoising → Output enhanced audio

**Design tradeoffs**: The system balances between leveraging visual information for improved enhancement and maintaining computational efficiency. Using self-supervised visual features reduces the need for labeled lipreading data but may introduce some visual information loss compared to fully supervised approaches.

**Failure signatures**: The system may struggle with occluded faces, unusual mouth movements, or when visual information is degraded or misaligned with audio.

**First experiments**:
1. Test audio-only baseline to establish performance floor
2. Evaluate with clean visual input to assess visual contribution
3. Test with degraded visual input to measure robustness

## Limitations

- Performance improvements primarily demonstrated through objective metrics; subjective perceptual quality remains unclear
- Evaluation focuses on clean visual conditions without exploring robustness to degraded or misaligned visual input
- Computational efficiency and real-time feasibility not discussed, which are critical for practical deployment

## Confidence

*High confidence*: The proposed architecture (audio-visual embeddings + noise conditional score network) is technically sound and follows established methodologies in the field. The reported objective metric improvements over the audio-only baseline are statistically valid based on the presented results.

*Medium confidence*: The claim that the system is "competitive with an audio-visual speech separation baseline" is based on indirect comparisons, as the exact metrics for the separation baseline are not provided in the paper. The reduction in generative artifacts (phonetic confusions) is inferred from WER improvements but not directly analyzed.

*Low confidence*: The practical utility and perceptual quality improvements in real-world scenarios remain uncertain without user studies or evaluations under challenging visual conditions.

## Next Checks

1. Conduct subjective listening tests to validate whether objective metric improvements correspond to perceptible quality gains for human listeners.

2. Perform ablation studies removing visual components and testing with occluded/impaired visual input to quantify the visual information's contribution and failure modes.

3. Evaluate computational requirements and latency to assess real-time feasibility and practical deployment constraints.
