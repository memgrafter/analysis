# CLARE: Conservative Model-Based Reward Learning for Offline Inverse Reinforcement Learning

## Quick Facts
- arXiv ID: 2302.04782
- Source URL: https://arxiv.org/abs/2302.04782
- Reference count: 40
- Authors: None provided
- Key outcome: Proposes CLARE, an offline IRL algorithm that addresses reward extrapolation error through conservatism, dynamics models, and pointwise weight parameters

## Executive Summary
CLARE is an offline inverse reinforcement learning algorithm that addresses the reward extrapolation error problem by integrating conservatism into the learned reward function. The method uses a dynamics model and introduces pointwise weight parameters for state-action pairs to balance exploiting offline data and exploring model-based rollouts. Through iterative updates that increase values on expert and diverse data while penalizing model rollouts, CLARE aims to minimize the return gap between learned and expert policies. The algorithm demonstrates superior performance on MuJoCo tasks, particularly with small offline datasets.

## Method Summary
CLARE addresses offline IRL challenges by combining a learned reward function with a dynamics model and conservatism principles. The algorithm introduces pointwise weight parameters that capture the tradeoff between offline data exploitation and model-based exploration. These weights are updated iteratively to increase values on expert and diverse state-action pairs while penalizing those from model rollouts. Theoretical analysis provides an upper bound on the return gap between the learned policy and expert policy, which guides the optimal weight derivation to minimize this gap. The method specifically targets reward extrapolation errors common in offline settings.

## Key Results
- Outperforms existing offline IRL and imitation learning algorithms on MuJoCo tasks
- Demonstrates superior performance especially with small offline datasets
- Learns reward functions that effectively explain expert behavior
- Shows the learned rewards are highly instructive for further learning

## Why This Works (Mechanism)
CLARE works by introducing conservatism into the reward learning process through pointwise weight parameters that balance between exploiting offline data and exploring model-based rollouts. The key mechanism is the iterative update of these weights to increase values on expert and diverse data while penalizing model-generated state-action pairs. This creates a conservative learning process that avoids overfitting to potentially incorrect model predictions while still leveraging the model for exploration. The theoretical framework provides an upper bound on the return gap, ensuring that the learned policy stays close to expert performance.

## Architecture Onboarding

**Component Map:** Dynamics Model -> Reward Function Learner -> Weight Parameter Updater -> Policy Optimizer -> Value Estimator

**Critical Path:** Dynamics model rollouts → reward function updates → weight parameter adjustments → policy optimization → value estimation

**Design Tradeoffs:** Balances conservatism (preventing overfitting to model errors) against exploration (leveraging model for generalization), with weight parameters controlling this tradeoff

**Failure Signatures:** Poor performance with noisy offline data, degraded results when model errors compound, suboptimal results with inadequate weight tuning
