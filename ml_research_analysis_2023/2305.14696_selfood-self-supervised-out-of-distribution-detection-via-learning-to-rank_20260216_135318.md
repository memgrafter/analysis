# SELFOOD: Self-Supervised Out-Of-Distribution Detection via Learning to Rank

## Quick Facts
- arXiv ID: 2305.14696
- Source URL: https://arxiv.org/abs/2305.14696
- Reference count: 14
- Primary result: Achieves up to 82-point improvements in FPR95 and perfect OOD detection scores compared to cross-entropy baselines

## Executive Summary
This paper introduces SELF OOD, a self-supervised method for detecting out-of-distribution (OOD) samples in text classification without requiring expensive OOD annotations. The approach reframes OOD detection as an inter-document intra-label ranking problem, training classifiers to rank in-distribution samples higher than OOD samples within each label. By using a novel IDIL loss function that directly optimizes this ranking objective, the method achieves significant improvements in OOD detection performance while only requiring in-distribution supervision. Experiments with BERT and RoBERTa classifiers demonstrate substantial gains over traditional cross-entropy loss approaches across multiple text classification datasets.

## Method Summary
The SELF OOD method addresses OOD detection by casting it as an inter-document intra-label (IDIL) ranking problem. The core innovation is the IDIL loss function, which uses pairwise ranking between documents to ensure in-distribution samples receive higher confidence scores than OOD samples for their respective labels. Unlike cross-entropy loss, IDIL loss minimizes when the desired ranking is achieved and backpropagates gradients to decrease incorrect label probabilities rather than continuously increasing correct label probabilities. The method requires only in-distribution documents with labels, making it practical for real-world applications where OOD samples are unavailable during training.

## Key Results
- Achieves up to 82-point improvements in FPR95 (False Positive Rate at 95% True Positive Rate) compared to cross-entropy loss
- Perfect OOD detection scores (FPR95 = 0) on several dataset pairs including 20News/NYT and AGNews/NYT
- Consistent improvements across multiple datasets including IMDB, Yelp, Amazon, and Yahoo
- Superior performance compared to correctness ranking loss baseline while requiring only in-distribution supervision

## Why This Works (Mechanism)

### Mechanism 1
The IDIL loss directly optimizes ordinal ranking of confidence scores between in-distribution documents from different classes. For each label, the model learns to rank documents belonging to that label higher than documents not belonging to it, creating a margin between in-distribution and OOD samples. OOD documents do not belong to any in-distribution label, so they will naturally receive lower scores than in-distribution documents when trained with this inter-document ranking objective. This mechanism assumes that OOD samples are semantically distinct from all in-distribution labels.

### Mechanism 2
The IDIL loss avoids overconfidence by reaching zero when desired ranking is achieved, rather than continuously increasing correct label probabilities. The SiLU-based pairwise ranking loss stops optimizing once the relative ordering between documents is correct, preventing the logit magnitudes from growing unboundedly. This contrasts with cross-entropy loss, which's continuous optimization of correct label probabilities leads to poor calibration and overconfidence in both correct and incorrect predictions. The mechanism assumes that preventing logit magnitude growth improves OOD detection calibration.

### Mechanism 3
Gradient flow direction in IDIL loss specifically decreases probabilities for incorrect labels rather than increasing correct label probabilities. By detaching gradients from the correct label document and only backpropagating through the incorrect label document, the model learns to suppress non-relevant class scores. This approach assumes that explicitly decreasing incorrect label probabilities is more effective for OOD detection than increasing correct label probabilities, which may not generalize well to unseen distributions.

## Architecture Onboarding

- **Component map**: Base classifier (BERT/RoBERTa) with softmax head -> IDIL loss function with SiLU activation -> Mini-batch bucketing mechanism by label -> Gradient manipulation layer (gradient detachment)

- **Critical path**: Input documents → Base classifier → Softmax scores → Mini-batch documents → Bucket by label → Pairwise comparisons within buckets → IDIL loss computation → Gradient detachment and backpropagation → Parameter updates

- **Design tradeoffs**:
  - Batch size vs. computational cost: Larger batches enable more document pairs but increase memory usage
  - Ranking vs. classification performance: IDIL loss optimizes for OOD detection at the expense of classification accuracy
  - Gradient manipulation complexity vs. stability: Selective gradient flow adds implementation complexity but improves performance

- **Failure signatures**:
  - Poor OOD detection despite good classification accuracy
  - Unstable training with exploding or vanishing gradients
  - Overfitting to in-distribution data without generalizing to OOD detection

## Open Questions the Paper Calls Out

### Open Question 1
Does the IDIL loss formulation inherently limit the model's classification accuracy, or could a hybrid approach combining inter-document and intra-document ranking achieve both strong OOD detection and classification performance? The paper acknowledges that SELF OOD is a poor text classifier compared to CE Loss, attributing this to the inter-document intra-label ranking formulation which prioritizes OOD detection over classification accuracy. A systematic investigation of hybrid ranking approaches balancing both tasks is needed.

### Open Question 2
How does the performance of SELF OOD scale with increasingly subtle OOD detection tasks, such as distinguishing between closely related domains or fine-grained class distinctions within the same domain? The paper mentions exploring fine-grained OOD detection with NYT as in-distribution and AGNews/20News as OOD datasets, achieving near-perfect scores on AGNews, but doesn't thoroughly investigate the limits of this capability. The method's effectiveness for detecting subtle distributional shifts within similar domains remains unexplored.

### Open Question 3
What is the theoretical relationship between minimizing IDIL loss and achieving good OOD detection performance, and how does this differ from the theoretical guarantees of CE loss? The paper states that "the perfect model trained using the CE loss is a solution to our ranking problem" but notes that empirically the ranking objective leads to different solutions, demonstrating the importance of the optimization procedure. A formal theoretical analysis comparing the optimization landscapes and convergence properties of IDIL loss versus CE loss would clarify the theoretical foundations.

## Limitations

- Requires larger batch sizes to generate sufficient document pairs, increasing computational costs
- Assumes OOD samples do not belong to any in-distribution label, which may not hold in all scenarios
- Gradient manipulation technique introduces implementation complexity that could affect training stability

## Confidence

**High Confidence**: The core mechanism of inter-document intra-label ranking and the empirical improvements in OOD detection metrics are well-supported by the experimental results.

**Medium Confidence**: The claim that explicitly decreasing incorrect label probabilities is superior to increasing correct label probabilities for OOD detection, while supported by results, could benefit from additional theoretical analysis.

**Medium Confidence**: The assumption that OOD documents will naturally receive lower scores than in-distribution documents may not hold in cases where OOD samples share semantic similarity with in-distribution samples.
