# Depression detection in social media posts using affective and social norm features

## Quick Facts
- arXiv ID: 2303.14279
- Source URL: https://arxiv.org/abs/2303.14279
- Reference count: 0
- Multimodal BERT-based architecture with emotion, profanity, and morality features achieves state-of-the-art performance

## Executive Summary
This paper presents a deep learning approach for detecting depression in social media posts by combining BERT-based text representations with affective and social norm features. The model integrates emotion detection scores, profanity metrics, and morality-based features extracted from a moral foundations lexicon with BERT embeddings. The hierarchical architecture with attention mechanisms fuses these multimodal features to improve depression detection accuracy. The approach achieves state-of-the-art results on two major depression detection datasets, demonstrating the effectiveness of incorporating psychological insights into the feature engineering process.

## Method Summary
The proposed method combines BERT-based text representations with additional psychological features to detect depression in social media posts. The architecture uses a hierarchical attention mechanism to fuse BERT embeddings with emotion detection features, profanity scores, and morality features extracted from a moral foundations lexicon. The profanity and morality features are motivated by psychological research linking these aspects to depression. The model employs a dual-level classification approach: post-level classification for individual posts and user-level classification by aggregating predictions across a user's posts. The attention mechanism learns to weight different feature types based on their relevance to depression detection, while the hierarchical structure captures both local (post-level) and global (user-level) patterns of depressive behavior.

## Key Results
- F1-score improvement of 2.65% on the Pirina dataset (post-level classification)
- F1-score improvement of 6.73% on the RSDD dataset (user-level classification)
- Achieves state-of-the-art performance on both datasets
- Profanity scores identified as particularly important for detection performance

## Why This Works (Mechanism)
The multimodal approach works by incorporating psychological insights about depression into the feature engineering process. Depression manifests through various linguistic and behavioral patterns that extend beyond pure text semantics. Emotion detection captures the affective state of users, while profanity scores reflect emotional dysregulation and impulsivity commonly associated with depression. Morality features extracted from the moral foundations lexicon capture shifts in value systems and social norm adherence that occur during depressive episodes. By combining these psychological features with BERT's semantic understanding, the model gains a more comprehensive view of depressive patterns that pure text analysis might miss.

- Emotion detection features: Capture affective states associated with depression - needed because depression significantly alters emotional expression; check by correlating emotion scores with depression severity
- Profanity scores: Reflect emotional dysregulation and impulsivity - needed as depression often manifests through increased use of negative language; check by analyzing profanity distribution across depressed vs. non-depressed users
- Morality features: Capture shifts in value systems and social norm adherence - needed because depression affects moral reasoning and social behavior; check by examining moral foundation usage patterns in depressed populations
- Hierarchical attention: Enables learning of both local and global depression patterns - needed for aggregating post-level signals to user-level predictions; check by visualizing attention weights across different feature types

## Architecture Onboarding

Component Map:
BERT -> Attention Layer -> Classification Layer
Psychological Features -> Attention Layer -> Classification Layer
Post-level Predictions -> User-level Aggregation -> Final Classification

Critical Path:
1. Text preprocessing and feature extraction
2. BERT embedding generation
3. Psychological feature computation (emotion, profanity, morality)
4. Hierarchical attention fusion of multimodal features
5. Classification and prediction aggregation

Design Tradeoffs:
- BERT vs. smaller language models: BERT provides better semantic understanding but increases computational cost
- Feature selection: Including more psychological features could improve performance but risks overfitting
- Attention vs. simple concatenation: Attention allows learned weighting but adds complexity

Failure Signatures:
- Overreliance on profanity features may indicate dataset bias
- Poor user-level performance despite good post-level results suggests aggregation issues
- Attention weights heavily skewed toward one feature type may indicate imbalance

First Experiments:
1. Ablation study removing one feature type at a time to measure individual contributions
2. Cross-validation across different user demographics to test generalizability
3. Visualization of attention weights to understand feature importance patterns
