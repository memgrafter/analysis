# Domain adaptation using optimal transport for invariant learning using histopathology datasets

## Quick Facts
- arXiv ID: 2303.02241
- Source URL: https://arxiv.org/abs/2303.02241
- Reference count: 20
- Key outcome: Optimal transport (OT) loss improves domain adaptation in histopathology by comparing batches of images, achieving higher validation (89.1%) and test accuracy (85.0%) than standard DANN.

## Executive Summary
Histopathology models struggle to generalize across institutions due to batch effects from different scanners and preparation protocols. This paper introduces an optimal transport (OT) loss that compares batches of images rather than individual samples, encouraging invariant feature learning across domains. The approach extends adversarial domain adaptation by aligning image distributions using regularized OT. On the Camelyon17-WILDS dataset, the OT-regularized model achieves higher validation accuracy (89.1%) and test accuracy (85.0%) than standard DANN (87.3% and 79.6%, respectively), particularly improving classification of rare phenotypes. Visualizations show the OT loss better captures distributional differences in biological features. The method generalizes well even when the validation and test institutions are swapped.

## Method Summary
The method combines cross-entropy loss with an optimal transport (OT) loss that compares batches of feature embeddings from different institutions during training. Using a ResNet-50 backbone with Instance Normalization, the model extracts features from 96x96 histopathology patches. The OT loss is computed using the Sinkhorn algorithm between batches from training and validation institutions, encouraging invariant feature learning. The combined loss is trained with SGD for 5 epochs with batch size 128, and the regularization parameter α is tuned on the validation set (best at 0.1). The approach is evaluated on the Camelyon17-WILDS dataset against DANN, ERM, CORAL, IRM, Group DRO, MBDG, and SGD baselines.

## Key Results
- OT-regularized model achieves higher validation accuracy (89.1%) than standard DANN (87.3%) on Camelyon17-WILDS
- Test accuracy improves from 79.6% (DANN) to 85.0% with OT loss
- OT loss particularly improves classification of rare phenotypes compared to adversarial methods
- Method generalizes well when validation and test institutions are swapped

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Optimal transport (OT) loss improves domain adaptation by aligning the distributions of feature representations across batches rather than individual samples.
- Mechanism: The OT loss compares batches of images from different institutions and penalizes differences in their feature distributions, encouraging the model to learn invariant features that are robust to institutional variations.
- Core assumption: Batch-level distributional differences better capture the underlying technical variations (e.g., staining, scanning) that cause domain shifts in histopathology data.
- Evidence anchors:
  - [abstract] "Unlike previous methods, which operate on single samples, our loss accounts for distributional differences between batches of images."
  - [section] "Our OT-based loss allows us to compare if the distributions of two sets of images are different, which we use to quantify and penalize representational differences in images between institutions."

### Mechanism 2
- Claim: OT loss is more effective than adversarial methods like DANN in handling subpopulation shifts within domains.
- Mechanism: By considering batches of images, OT loss can capture and align the full distribution of image features, including rare phenotypes that may be underrepresented in the training set.
- Core assumption: Adversarial methods focusing on individual samples are prone to overfitting to the most frequent differences between datasets, missing subtle subpopulation shifts.
- Evidence anchors:
  - [abstract] "While both methods can adapt to global differences in color distribution, only our OT loss can reliably classify a cancer phenotype unseen during training."
  - [section] "We observe that particularly in the feature space of cluster 3, DANN has a much higher failure rate while the OT method succeeds, suggesting that our OT method may be better able to capture the full distribution of image variability on the feature representation level."

### Mechanism 3
- Claim: Incorporating OT loss during training is critical for model generalization, rather than just using OT for post-hoc alignment.
- Mechanism: The OT loss is integrated into the training objective, encouraging the model to learn invariant features from the start, rather than trying to align features after the model has already been trained.
- Core assumption: Learning invariant features during training is more effective than aligning features post-hoc because the model can leverage these features for better classification.
- Evidence anchors:
  - [section] "We have used Sinkhorn algorithm with the regularization value of 2... However, this does not guarantee that the classification will be good, as the validation and test accuracy only slightly improve, with values of 0.855 and 0.711, respectively."
  - [section] "Therefore, having a cross-entropy and OT loss function at training time will enhance discrimination power, and therefore prediction accuracy."

## Architecture Onboarding

- Component map: ResNet-50 backbone -> Feature extraction -> OT loss module -> Classification layer
- Critical path:
  1. Extract features from input images using the ResNet-50 backbone
  2. Compute OT loss between batches of features from different institutions
  3. Combine OT loss with cross-entropy loss for the final training objective
  4. Train the model to minimize the combined loss
- Design tradeoffs:
  - Using OT loss vs. adversarial methods (e.g., DANN) for domain adaptation
  - Batch size and composition for computing OT loss
  - Regularization strength (α) for balancing OT loss and cross-entropy loss
- Failure signatures:
  - Poor generalization to unseen institutions despite high validation accuracy
  - Model overfitting to specific institutional characteristics
  - Instability in training due to improper OT loss computation or regularization
- First 3 experiments:
  1. Compare OT loss with adversarial methods (e.g., DANN) on a small subset of the data to validate the effectiveness of OT loss.
  2. Analyze the impact of batch size and composition on the OT loss computation and model performance.
  3. Perform ablation studies to determine the optimal regularization strength (α) for the combined loss function.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the optimal transport (OT) loss improve performance on histopathology datasets with more severe distribution shifts or across more institutions than the Camelyon17 dataset?
- Basis in paper: [inferred] The paper shows improved performance on Camelyon17-WILDS but notes future work could explore larger fields-of-view, more challenging tasks, and more unseen domains.
- Why unresolved: The current study only evaluated on a single dataset with 5 institutions, limiting generalizability to other settings with potentially larger distribution shifts.
- What evidence would resolve it: Testing the OT loss on other histopathology datasets with more institutions or greater domain shifts would show if improvements generalize.

### Open Question 2
- Question: Can the OT loss be combined with other domain adaptation methods like stain augmentation or synthetic data generation to achieve further improvements?
- Basis in paper: [explicit] The discussion section suggests opportunities for synergy between OT loss and approaches like stain augmentation or synthetic data.
- Why unresolved: The paper only compared OT loss to standard adversarial methods and other domain adaptation baselines, not combinations with other techniques.
- What evidence would resolve it: Evaluating the OT loss in combination with stain augmentation or synthetic data on the Camelyon17 dataset would show if performance improves further.

### Open Question 3

## Limitations
- Evaluation limited to single binary classification task on Camelyon17 dataset
- Claims about subpopulation shift handling rely on qualitative feature space analysis rather than rigorous statistical testing
- Different training epochs for OT (5) vs DANN (10) may confound performance comparison

## Confidence
- High confidence: OT loss improves validation accuracy over ERM baseline (89.1% vs 86.7%)
- Medium confidence: OT outperforms DANN on test accuracy (85.0% vs 79.6%) given epoch discrepancy
- Medium confidence: OT better captures subpopulation shifts based on qualitative feature analysis
