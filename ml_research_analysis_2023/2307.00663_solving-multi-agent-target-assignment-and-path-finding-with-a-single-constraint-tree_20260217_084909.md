# Solving Multi-Agent Target Assignment and Path Finding with a Single Constraint Tree

## Executive Summary
This paper introduces ITA-CBS, an algorithm that solves the Combined Target-Assignment and Path-Finding (TAPF) problem by maintaining a single search tree and incrementally updating target assignments. The key innovation is avoiding duplicated collision resolution across multiple search trees and expensive K-best assignment computations by using dynamic Hungarian algorithm updates. Experimental results show ITA-CBS outperforms the state-of-the-art CBS-TA algorithm in both success rate and runtime efficiency.

## Method Summary
ITA-CBS solves TAPF by generating a single constraint tree and incrementally computing new 1-best target assignments during the search. When a new constraint is added, only the affected row in the cost matrix is updated, and the dynamic Hungarian algorithm efficiently recalculates the optimal assignment. The algorithm maintains a priority queue of CT nodes based on cost estimates that serve as lower bounds on flowtime. This approach eliminates the need for K-best assignment computations while preserving optimality guarantees through careful constraint propagation and cost matrix management.

## Key Results
- ITA-CBS found optimal solutions faster than CBS-TA in 96.1% of 6,334 effective test cases
- 38.7% of cases were 5 times faster, and 5.6% were 100 times faster
- Success rate of 97.6% compared to CBS-TA's 94.5%
- Runtime improvement from 22.41 seconds to 7.36 seconds on average

- Claim: Incremental target assignment avoids redundant collision resolution across multiple search trees.
- Mechanism: By maintaining a single search tree and incrementally updating the target assignment matrix when a new constraint is added, the algorithm eliminates the need to recompute the entire assignment from scratch.
- Core assumption: Each new constraint affects only one row in the cost matrix, allowing efficient incremental updates via dynamic Hungarian algorithm.

### Mechanism 2
- Claim: Dynamic Hungarian algorithm reduces target assignment computation time from O(M³) to O(M²).
- Mechanism: The dynamic algorithm reuses the previous assignment and adjusts only the affected vertices when the cost matrix changes, rather than recomputing the entire assignment.
- Core assumption: The Hungarian algorithm's vertex labeling and subgraph matching properties allow for incremental updates without losing optimality.
- Evidence anchors:
  - [section IV-A] "The complexity will be O(kM²) to get a new optimal matching. In ITA-CBS, time complexity is O(M²) since a new conflict only impacts one row in M."

## Architecture Onboarding

- Component map: Priority Queue -> Cost Matrix -> Dynamic Hungarian -> Low-level Path Finder -> Conflict Detector
- Critical path:
  1. Initialize with empty constraints and compute initial cost matrix
  2. Assign targets using dynamic Hungarian algorithm
  3. Check for conflicts and generate new constraints
  4. Update cost matrix and reassign targets
  5. Repeat until conflict-free solution found
- Design tradeoffs:
  - Single vs multiple search trees: Reduces memory but requires careful constraint management
  - Incremental vs full recomputation: Faster updates but more complex implementation
  - Priority queue management: Balancing between exploration and exploitation
- Failure signatures:
  - Memory exhaustion: Too many CT nodes in the priority queue
  - Timeout: Excessive constraint propagation without finding solution
  - Suboptimal results: Cost estimation becoming too loose

  1. Compare ITA-CBS vs CBS-TA on small grid maps with varying agent counts
  2. Measure dynamic Hungarian update time vs full Hungarian recomputation
  3. Test scalability on warehouse-like maps with increasing target locations

## Limitations

- The scalability of the dynamic Hungarian algorithm implementation is uncertain, particularly when multiple agents experience constraint changes simultaneously.
- The computational complexity analysis focuses on worst-case scenarios without empirical validation across diverse problem instances.
- The algorithm assumes that new constraints affect only single rows in the cost matrix, which may not hold in dense scenarios with frequent multi-agent conflicts.

## Confidence

- **High Confidence**: The single search tree architecture effectively reduces memory overhead compared to multiple tree approaches. The experimental results showing ITA-CBS outperforming CBS-TA in 96.1% of cases are well-supported by the presented data.
- **Medium Confidence**: The dynamic Hungarian algorithm provides the claimed O(M²) complexity improvement over O(M³) for K-best assignments. While theoretically sound, the practical implementation details are not fully specified.
- **Low Confidence**: The claim that incremental target assignment completely eliminates duplicated collision resolution across multiple search trees requires further validation, particularly in scenarios with complex constraint interactions.
