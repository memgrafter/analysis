# Optimizing fairness tradeoffs in machine learning with multiobjective meta-models

## Quick Facts
- **arXiv ID**: 2304.12190
- **Source URL**: https://arxiv.org/abs/2304.12190
- **Reference count**: 40
- **Primary result**: FOMO outperforms GerryFair on hypervolume metrics for fairness-accuracy Pareto frontiers (p ≤ 0.05)

## Executive Summary
This work introduces FOMO, a method for optimizing fairness tradeoffs in machine learning by using multiobjective optimization to directly search the space of sample weights used to train classifiers. Unlike traditional approaches that tune a single fairness parameter, FOMO jointly optimizes accuracy and fairness metrics via evolutionary algorithms, enabling exploration of the full Pareto frontier. The method uses a meta-model to map protected attributes to sample weights, reducing parameter complexity and potentially improving generalization. FOMO was evaluated against GerryFair on four real-world datasets using logistic regression and gradient boosted models, showing significantly better hypervolume scores for Pareto-optimal solutions.

## Method Summary
FOMO addresses fairness-accuracy tradeoffs by framing the problem as multiobjective optimization over sample weights. Instead of tuning a single tradeoff parameter, FOMO uses NSGA2 to search for weight vectors that jointly optimize accuracy and fairness metrics. To reduce dimensionality and improve scalability, FOMO introduces a meta-model that learns to map protected attributes to sample weights, replacing O(N) sample weights with O(p) parameters. The method is implemented as an interface between pymoo and scikit-learn, supporting any weighted classifier and user-defined fairness metrics. FOMO was tested on four datasets (Communities, Adult, Lawschool, Student) optimizing for subgroup fairness (both FPR and FNR) and AUC, comparing direct and meta-model encodings against GerryFair.

## Key Results
- FOMO found significantly better Pareto-optimal solution sets than GerryFair for both logistic regression and XGBoost (p ≤ 0.05)
- Meta-model encoding did not improve performance over direct encoding in the studied problems
- FOMO's hypervolume scores were consistently higher across all datasets and learner combinations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multiobjective optimization over sample weights produces better Pareto frontiers than single-parameter tradeoffs.
- Mechanism: FOMO treats each sample's weight as a decision variable, jointly optimizing accuracy and fairness metrics in one run.
- Core assumption: The sample weight space is rich enough to represent good fairness-accuracy tradeoffs without overfitting.
- Evidence anchors:
  - [abstract]: "We propose instead to directly optimize the error-fairness tradeoff by using multi-objective optimization."
  - [section]: "We use multiobjective optimization to define the sample weights used in model training for a given machine learner."
- Break condition: If the sample weight space is too large or noisy, search may not converge or overfit.

### Mechanism 2
- Claim: Meta-model encoding reduces parameters and improves generalization.
- Mechanism: Maps protected attributes to weights using a low-dimensional model (linear or small NN), reducing search space from O(N) to O(p).
- Core assumption: Fairness-relevant information can be captured by protected attributes alone.
- Evidence anchors:
  - [section]: "To reduce the number of optimized parameters... we propose a novel meta-model approach that learns to map protected attributes to sample weights."
- Break condition: If meta-model is too simple, it may miss important patterns; if too complex, it may overfit.

### Mechanism 3
- Claim: FOMO's agnosticism to base learner and fairness metric enables broader applicability.
- Mechanism: Implemented as interface between pymoo and scikit-learn, supporting any weighted classifier and user-defined fairness metric.
- Core assumption: Weighted classification framework is sufficient to express fairness constraints.
- Evidence anchors:
  - [section]: "FOMO is the only fair ML method that 1) adapts a model's training process, 2) pairs with (nearly) any ML method..."
- Break condition: If a fairness constraint cannot be expressed as a loss function over weighted samples, FOMO cannot handle it directly.

## Architecture Onboarding

- Component map:
  - FOMO core: pymoo NSGA2 optimizer + sample weight encoding (direct or meta-model)
  - Learner interface: any scikit-learn-compatible classifier with sample_weight support
  - Metrics module: user-defined accuracy and fairness loss functions
  - Evaluation pipeline: train/test split, hypervolume calculation, statistical comparison

- Critical path:
  1. Define dataset, protected attributes, and fairness metrics
  2. Choose encoding (direct or meta-model) and base learner
  3. Configure pymoo (population size, generations, objectives)
  4. Run optimization, collect Pareto set
  5. Evaluate on test set, compute hypervolume

- Design tradeoffs:
  - Direct encoding: higher dimensionality, more expressive, but slower and prone to overfitting
  - Meta-model encoding: lower dimensionality, faster, better generalization, but may underfit
  - Base learner choice: linear models are faster but less flexible; tree/GBDT models can capture non-linearities but are slower

- Failure signatures:
  - Hypervolume does not improve over GerryFair: likely issue with weight encoding or MOO configuration
  - Pareto set collapses to a single point: objectives may be too conflicting or optimization terminated too early
  - Meta-model overfits: check train/test gap, reduce model complexity or add regularization

- First 3 experiments:
  1. Compare FOMO-LR direct vs GerryFair-LR on Adult dataset, FN subgroup fairness, AUROC; record hypervolume and runtime.
  2. Compare FOMO-LR meta vs FOMO-LR direct on Communities dataset; check if meta-model improves generalization.
  3. Swap XGBoost for LR in FOMO; compare Pareto frontiers for both FN and FP subgroup fairness scenarios.

## Open Questions the Paper Calls Out

- Does FOMO outperform other fairness methods (beyond GerryFair) in real-world applications with larger, more diverse datasets?
  - Basis: Experiments were limited to relatively small datasets; additional evaluation on larger datasets is needed.
  - Why unresolved: Current study only tested on small datasets (hundreds to thousands of samples).
  - What evidence would resolve it: Comparative experiments on large-scale, diverse datasets with robust subgroup representation.

- Does the meta-model approach in FOMO consistently improve generalization of fairness measures across different problem domains?
  - Basis: Paper hypothesized meta-model would improve FOMO but found no significant improvement in studied problems.
  - Why unresolved: Meta-model may only be beneficial in specific problem contexts or with different architectures.
  - What evidence would resolve it: Systematic testing of FOMO with meta-model encoding across diverse problem domains.

- What is the optimal balance between model complexity and fairness constraints when using FOMO?
  - Basis: Paper notes meta-model constrains complexity and may act as regularizer but doesn't explore this balance.
  - Why unresolved: Relationship between model complexity, fairness constraints, and generalization is complex and problem-dependent.
  - What evidence would resolve it: Controlled experiments varying model complexity and fairness constraints across different datasets.

## Limitations
- Meta-model encoding did not improve performance over direct encoding in studied problems
- Experiments limited to relatively small datasets (hundreds to thousands of samples)
- Only tested two learners (logistic regression, XGBoost) and simple binary protected attributes

## Confidence
- **High confidence**: FOMO's ability to outperform GerryFair on hypervolume metrics for both logistic regression and XGBoost (p ≤ 0.05)
- **Medium confidence**: The claim that the meta-model does not improve performance, based on experimental results but lacking deeper analysis
- **Low confidence**: The generality claim that FOMO can handle "nearly any ML method" and "complex group definitions," as experiments only tested two learners and simple attributes

## Next Checks
1. **Hyperparameter sensitivity**: Run FOMO with a grid of population sizes and generations to determine if reported hypervolume improvements are robust to these settings.
2. **Meta-model ablation**: Systematically compare meta-model vs. direct encoding across all datasets and learners to see if the meta-model ever provides benefits.
3. **Alternative fairness metrics**: Evaluate FOMO using equalized odds and demographic parity to test if the approach generalizes beyond subgroup fairness for FPR/FNR.
