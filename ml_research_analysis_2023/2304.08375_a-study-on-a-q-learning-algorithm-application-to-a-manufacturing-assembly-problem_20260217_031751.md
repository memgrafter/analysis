# A study on a Q-Learning algorithm application to a manufacturing assembly problem

## Quick Facts
- arXiv ID: 2304.08375
- Source URL: https://arxiv.org/abs/2304.08375
- Authors: 
- Reference count: 27
- Primary result: Q-Learning achieves 98.3% success in learning optimal assembly sequence for toy airplane with 8 tasks

## Executive Summary
This study applies Q-Learning to optimize the assembly sequence of a toy airplane, aiming to minimize assembly time. The method formulates the problem as a Markov Decision Process, using a Q-table to learn the optimal assembly sequence through trial-and-error interactions. Three scenarios with increasing complexity assess the impact of algorithm parameters and rewards. The approach achieves 98.3% success in learning the optimal assembly sequence, requiring 780 episodes, which is only 21.7% of all possible sequences. This demonstrates the potential of Q-Learning to optimize complex assembly processes, though scalability challenges exist for more intricate assemblies.

## Method Summary
The study applies a model-free Q-Learning algorithm to a toy airplane assembly problem with 8 tasks and 256 possible states. The problem is formulated as a Markov Decision Process where states represent task completion status, actions are assembly tasks, and rewards reflect assembly time efficiency. The agent learns through epsilon-greedy exploration, updating Q-values using the Bellman equation. Three scenarios test different reward structures and action restrictions, with performance measured by accumulated reward and percentage of optimal sequences learned.

## Key Results
- Q-Learning algorithm achieves 98.3% success rate in learning optimal assembly sequences
- Optimal sequence requires only 780 episodes, representing 21.7% of all possible sequences
- Proper reward parameter tuning and impossible action restrictions significantly improve learning efficiency

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Q-learning algorithm successfully learns the optimal assembly sequence by maximizing accumulated reward over episodes.
- Mechanism: The algorithm iteratively updates Q-values using the Bellman equation, where each state-action pair's value is adjusted based on the immediate reward and the estimated optimal future reward. By exploring possible actions and exploiting learned Q-values, the agent converges to a policy that minimizes assembly time.
- Core assumption: The Markov property holds—future states depend only on the current state and action, not the full history.

### Mechanism 2
- Claim: Proper tuning of reward parameters (reward shift, multiplier, penalty) significantly improves learning efficiency and success rate.
- Mechanism: Adjusting the reward shift centers the reward distribution, the multiplier scales the reward impact, and the penalty discourages impossible actions. Together, these parameters shape the reward landscape so that optimal sequences yield higher accumulated rewards, guiding the agent toward them.
- Core assumption: The reward function accurately reflects the true objective (minimizing assembly time) and is sensitive enough to distinguish between good and bad sequences.

- Break condition: If rewards are too sparse or improperly scaled, the agent may not receive sufficient feedback to learn effectively.

- Claim: Restricting impossible actions (rather than penalizing them) reduces the number of episodes needed to learn the optimal sequence.
- Mechanism: By eliminating invalid state-action transitions from the agent's choice set, the search space is reduced, allowing the agent to focus exploration on feasible sequences and converge faster.

## Architecture Onboarding

- Component map:
  - Environment: Simulates the assembly process, defines states, actions, rewards, and transitions
  - Agent: Implements Q-learning, maintains Q-table, selects actions, and updates Q-values
  - Reward function: Encodes task times and penalties, shaping the learning objective
  - Precedence constraints: Define valid task sequences and impossible actions

- Critical path:
  1. Initialize Q-table and parameters (learning rate, discount factor, epsilon, rewards)
  2. For each episode, start from initial state and select actions using epsilon-greedy policy
  3. Observe reward and next state, update Q-value using Bellman equation
  4. Repeat until convergence or max episodes reached
  5. Extract optimal policy from learned Q-table

- Design tradeoffs:
  - Exploration vs. Exploitation: Higher epsilon encourages exploration but may slow convergence; lower epsilon speeds up but risks local optima
  - Reward shaping: Careful tuning needed to ensure meaningful gradients toward optimal sequences
  - State representation: Binary encoding of task completion is compact but may limit expressiveness for more complex assemblies

- Failure signatures:
  - Slow or no convergence: Likely due to poor reward design, insufficient exploration, or overly large state space
  - Learning suboptimal sequences: May indicate reward misalignment or premature exploitation
  - High percentage of failed episodes: Often caused by unrealistic penalties or overly restrictive action sets

- First 3 experiments:
  1. Run Q-learning with default parameters on a simplified assembly (fewer tasks) to verify basic functionality and convergence
  2. Vary the reward shift parameter systematically and observe impact on mean accumulated reward and success rate
  3. Compare learning with and without impossible action restrictions to quantify efficiency gains

## Limitations
- Scalability limitations: State space grows exponentially with task count, making approach potentially infeasible for complex assemblies
- Simplified reward function: May not capture real-world variability, quality considerations, or practical constraints beyond simple precedencies
- Limited validation: Only tested on toy airplane assembly with 8 tasks, not on industrial manufacturing scenarios

## Confidence
- High Confidence: The Q-learning algorithm successfully learns optimal assembly sequences for the toy airplane problem as demonstrated by the 98.3% success rate and convergence to optimal accumulated reward of -64 within 780 episodes.
- Medium Confidence: The reward parameter tuning significantly impacts learning efficiency, though the specific optimal values may be problem-dependent and require recalibration for different assembly scenarios.
- Low Confidence: The approach scales effectively to industrial manufacturing problems with significantly larger state spaces and more complex constraints beyond simple task precedencies.

## Next Checks
1. **Scalability Test**: Apply the same Q-learning framework to assembly problems with 12-16 tasks and measure how episode count and success rate degrade as state space complexity increases exponentially.
2. **Reward Robustness Test**: Introduce realistic variability in task times (e.g., ±30% deviation from averages) and evaluate whether the learned policies remain optimal or if the agent can adapt to stochastic environments.
3. **Constraint Generalization Test**: Extend the model to include resource constraints (multiple workers, tool availability) and quality dependencies between tasks, then assess whether Q-learning can still effectively optimize assembly sequences under these additional real-world constraints.
