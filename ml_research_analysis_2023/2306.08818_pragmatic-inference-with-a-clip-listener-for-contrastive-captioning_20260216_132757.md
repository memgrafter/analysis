# Pragmatic Inference with a CLIP Listener for Contrastive Captioning

## Quick Facts
- arXiv ID: 2306.08818
- Source URL: https://arxiv.org/abs/2306.08818
- Reference count: 19
- Primary result: Generates discriminative captions that help people identify target images from similar distractors with 11-15% better human evaluation scores

## Executive Summary
This paper introduces PICL, a method for generating discriminative captions that help distinguish target images from similar distractor images. PICL uses pragmatic inference with a CLIP-based listener to evaluate informativeness and a standard captioning model for fluency. The method outperforms previous approaches by 11-15% in human evaluations, producing captions that are more effective at helping people identify target images. PICL is also notably more robust to hyperparameter selection than prior methods, which often generate disfluent captions when optimizing for informativeness.

## Method Summary
PICL uses incremental pragmatic inference to generate captions that distinguish target images from similar distractors. The method combines a base speaker (OFA image captioning model) with a CLIP-based listener to evaluate partial captions against all images at each decoding step. During beam search, the model scores candidate token continuations by combining speaker likelihood with CLIP-based similarity to the target and distractor images. This allows early correction of potentially misleading token choices before they become embedded in full captions. The approach requires no training beyond fine-tuning the base captioning model, making it fully inference-time.

## Key Results
- Human evaluation shows 11-15% improvement in informativeness and fluency compared to previous methods
- PICL achieves 66.2% ALBEF retrieval accuracy vs 62.1% for previous best method
- Method is substantially more robust to informativity hyperparameter than prior approaches
- Automatic evaluation (ALBEF) correlates well with human judgments of informativeness

## Why This Works (Mechanism)

### Mechanism 1
Using CLIP as listener leverages rich vision-language representations for discriminative captioning. CLIP's embeddings provide more discriminative features than the captioning model's internal representations when evaluating partial captions against distractors. This works because CLIP's learned representations capture semantic similarity between images and text more effectively than the speaker model's representations.

### Mechanism 2
Incremental pragmatic inference with beam search allows early correction of misleading token choices. At each decoding step, the model scores partial captions against all images using CLIP similarity, enabling optimization of token selection before completing full captions. This prevents the model from committing to suboptimal caption paths that would be difficult to recover from later.

### Mechanism 3
CLIP-based listener creates a smoother optimization landscape for the informativity hyperparameter. The combination of CLIP listener and pragmatic speaker avoids pushing the model into highly disfluent regions when maximizing informativeness, allowing automatic optimization without manual tuning.

## Architecture Onboarding

- Component map:
  - Base speaker: OFA image captioning model (pretrained, finetuned on COCO)
  - Base listener: Zero-shot CLIP model
  - Pragmatic speaker: Combines base speaker and listener using informativity hyperparameter
  - Evaluating listener: ALBEF model (separate from CLIP for unbiased evaluation)
  - Fluency evaluator: GPT-2 language model

- Critical path:
  1. Initialize beam with start token
  2. Generate N candidate tokens from base speaker
  3. Score each partial caption using CLIP similarity to all images
  4. Combine speaker and listener scores with informativity parameter
  5. Select top B candidates and continue decoding
  6. Output final caption after reaching maximum length

- Design tradeoffs:
  - Using CLIP vs. deriving listener from speaker model: Better representations vs. computational efficiency
  - Beam width N vs. computational cost: Wider search vs. slower inference
  - Informativity parameter optimization: Automatic vs. manual tuning

- Failure signatures:
  - High GPT-2 perplexity: Captions are disfluent or ungrammatical
  - Low ALBEF accuracy: Captions are not discriminative
  - Low human accuracy: Captions are misleading despite high ALBEF scores (codebooking)

- First 3 experiments:
  1. Run PICL with informativity parameter set to 0 (base speaker only) and 1 (listener only) to establish baseline performance
  2. Compare PICL against E-S and Incre-RSA with automatic informativity optimization
  3. Test PICL with different beam widths (B=8, 16, 32) to find optimal balance between performance and speed

## Open Questions the Paper Calls Out

The paper does not explicitly call out specific open questions, but several unresolved issues emerge from the analysis:

- How does the CLIP listener's performance degrade with more distractor images, and is there an optimal number of distractors for maximizing discriminative captioning performance?
- Would using a different vision-language model (e.g., Flamingo, BLIP) as the listener instead of CLIP improve PICL's performance or robustness?
- How does PICL's performance scale with the size and diversity of the training data for the base captioning model?

## Limitations

- Evaluation relies heavily on ALBEF model, which was trained on datasets overlapping with base speaker training data
- Human evaluation uses only 3 evaluators per caption and a small subset of 50 target images
- Claims about CLIP superiority not tested against alternative vision-language models
- Robustness to informativity hyperparameter only compared against two specific prior methods

## Confidence

- High confidence: PICL generates captions with significantly better human-judged informativeness and fluency compared to prior methods (11-15% improvement)
- Medium confidence: The incremental pragmatic inference approach with CLIP listener is the primary driver of PICL's performance gains
- Medium confidence: PICL's robustness to the informativity hyperparameter is a significant practical advantage over prior methods
- Low confidence: ALBEF retrieval accuracy accurately reflects human ability to distinguish target images from distractors

## Next Checks

1. **Cross-dataset validation**: Evaluate PICL on a held-out dataset that shares no training data with the COCO and Flickr30k datasets used for the base speaker and ALBEF listener.

2. **Ablation study on listener components**: Systematically replace the CLIP listener with alternative vision-language models (e.g., BLIP, ALIGN) and with listener models derived from the speaker architecture itself.

3. **Controlled human evaluation**: Conduct a more extensive human evaluation with 10+ evaluators per caption and a stratified sample covering the full range of image similarity difficulty levels in ImageCoDe.
