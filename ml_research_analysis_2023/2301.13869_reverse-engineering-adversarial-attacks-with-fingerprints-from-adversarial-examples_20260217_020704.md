# Reverse engineering adversarial attacks with fingerprints from adversarial examples

## Quick Facts
- arXiv ID: 2301.13869
- Source URL: https://arxiv.org/abs/2301.13869
- Reference count: 29
- This paper formulates reverse engineering adversarial attacks as a supervised learning problem, achieving 99.4% accuracy when perturbations are available and 85.05% accuracy using fingerprinting approaches.

## Executive Summary
This paper introduces a novel framework for reverse engineering adversarial attacks by treating attack classification as a supervised learning problem. The authors demonstrate that adversarial examples contain identifiable signatures that reveal both the attack algorithm and its parameters. They achieve 99.4% accuracy in classifying 17 attack variants when perturbations are directly available, and develop a fingerprinting approach using signal processing methods that achieves 85.05% accuracy without access to perturbations. The work establishes a strong baseline for future research in attack attribution and provides insights into the inherent properties of adversarial examples.

## Method Summary
The authors formulate attack reverse engineering as a supervised classification problem where the goal is to assign adversarial examples to classes representing attack algorithms and parameters. They train deep neural networks to classify perturbations directly, achieving high accuracy (99.4%) on a 17-class dataset. When perturbations are unavailable, they employ signal processing algorithms to estimate them, an approach they call "fingerprinting." The JPEG compression algorithm emerges as a particularly effective fingerprinter, demonstrating that simple methods can capture attack-specific characteristics in adversarial examples.

## Key Results
- Achieves 99.4% accuracy in classifying adversarial examples when perturbations are directly available
- JPEG fingerprinting achieves 85.05% accuracy without access to perturbations
- Demonstrates that adversarial examples contain identifiable signatures revealing attack algorithms and parameters
- Establishes a strong baseline for future work in attack attribution and reverse engineering

## Why This Works (Mechanism)
Adversarial examples, while designed to fool neural networks, inadvertently retain distinctive patterns or fingerprints that correlate with their generation process. These patterns stem from the mathematical operations used in different attack algorithms (such as gradient-based perturbations, random noise, or optimization procedures) and are influenced by attack parameters like epsilon values. When perturbations are available, these patterns can be directly learned through supervised classification. When perturbations are not accessible, signal processing methods can estimate them by exploiting the differences between clean and adversarial images, with simple transformations like JPEG compression proving surprisingly effective at capturing these distinguishing features.

## Foundational Learning
- Supervised classification for attack attribution: Needed to map adversarial examples to attack classes; Quick check: Does the model converge and achieve high accuracy on the training set?
- Perturbation estimation via signal processing: Required for fingerprinting when perturbations are unavailable; Quick check: Can estimated perturbations reconstruct the original adversarial image?
- JPEG compression as a feature extractor: Demonstrates that simple transforms can capture attack signatures; Quick check: Does JPEG achieve better accuracy than random transforms?
- Dataset balancing across attack types: Ensures fair evaluation across different attacks; Quick check: Are all attack classes equally represented in train/test splits?

## Architecture Onboarding

### Component Map
ResNet50 (or similar CNN) -> Classification Head -> Attack Class Prediction
Signal Processing Module -> Perturbation Estimation -> CNN Classifier

### Critical Path
1. Generate or obtain adversarial examples
2. Extract perturbations (direct access) OR estimate perturbations via fingerprinting
3. Train CNN classifier on perturbation data
4. Evaluate classification accuracy on held-out adversarial examples

### Design Tradeoffs
- Direct perturbation access vs. fingerprinting: Direct access yields higher accuracy but may not be realistic; fingerprinting is more practical but less accurate
- CNN architecture choice: Deeper models like ResNet50 offer better accuracy but increase computational cost
- Dataset size and diversity: Larger, more diverse datasets improve generalization but require more resources

### Failure Signatures
- Low accuracy across all attack classes suggests poor feature extraction or insufficient model capacity
- High accuracy on some attacks but poor on others indicates class imbalance or attack-specific feature challenges
- Degradation in fingerprinting accuracy suggests the signal processing method is not capturing attack signatures effectively

### 3 First Experiments
1. Train a CNN to classify perturbations from a small subset of attacks with known parameters
2. Apply JPEG compression to clean and adversarial image pairs and measure the difference as an estimated perturbation
3. Evaluate classification accuracy when training on perturbations from one dataset but testing on perturbations from a different dataset

## Open Questions the Paper Calls Out
None

## Limitations
- Evaluation limited to specific set of 5 attack algorithms and 4 epsilon values each
- JPEG fingerprinting may not be robust across different datasets or image types
- Assumes access to labeled dataset of adversarial examples
- Does not address potential defenses that could obscure attack fingerprints

## Confidence
- High confidence in classification performance when perturbations are available
- Medium confidence in fingerprinting approach robustness
- Low confidence in real-world applicability without further testing

## Next Checks

2. Evaluate robustness of attack classification when adversarial examples are subjected to common image transformations or defenses
3. Assess method's performance on larger, more diverse datasets beyond the standard benchmark used
