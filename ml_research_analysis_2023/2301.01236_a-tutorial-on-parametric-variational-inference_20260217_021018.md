# A Tutorial on Parametric Variational Inference

## Quick Facts
- arXiv ID: 2301.01236
- Source URL: https://arxiv.org/abs/2301.01236
- Reference count: 1

## Executive Summary
This tutorial provides a comprehensive introduction to parametric variational inference, an optimization-based approach for approximating intractable posterior distributions in Bayesian models. The method replaces intractable integration with tractable optimization by maximizing the evidence lower bound (ELBO), which provides a lower bound on the log marginal likelihood. The tutorial emphasizes the parametric approach using parameterized distributions like neural networks, contrasting it with traditional mean-field methods, and covers both the reparameterization trick for efficient gradient estimation and black-box variational inference for more general cases.

## Method Summary
The tutorial introduces parametric variational inference as a framework for approximating intractable posterior distributions by optimizing parameterized variational distributions to maximize the ELBO. The method involves defining a model with latent variables, choosing a variational family, and then optimizing the ELBO using gradient-based methods. Key techniques include the reparameterization trick for low-variance gradient estimation when applicable, and black-box variational inference as a more general approach. The tutorial also covers amortized variational inference for handling local latent variables in large datasets by sharing variational parameters across data points through a neural network encoder.

## Key Results
- The reparameterization trick enables low-variance gradient estimation by decoupling randomness from parameters through deterministic transformations
- Amortized variational inference scales to large datasets by predicting variational parameters from data points using shared neural network models
- The ELBO provides a tractable objective function that avoids direct computation of the intractable marginal likelihood

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The reparameterization trick enables low-variance gradient estimation for variational inference.
- Mechanism: The reparameterization trick decouples randomness from parameters by expressing a sample from a variational posterior as a deterministic transformation of a noise variable. This allows gradients to be computed via Monte Carlo sampling by moving the gradient inside the expectation.
- Core assumption: The variational posterior can be expressed as a differentiable transformation of a simple noise distribution.
- Evidence anchors:
  - [abstract] The tutorial covers the reparameterization trick for efficient gradient estimation.
  - [section] "The reparameterization trick was popularized in the work introducing the variational autoencoder... The idea is to decouple the source of randomness from the parameters by cleverly reformulating the random variable z ~ q_θ(z) as a parameterized transformation z = g_θ(ε) of another random variable ε ~ p(ε)."
  - [corpus] The corpus contains related papers discussing gradient estimation and variance reduction in variational inference.
- Break condition: The reparameterization trick fails when the variational posterior cannot be expressed as a differentiable transformation of a simple noise distribution (e.g., discrete distributions).

### Mechanism 2
- Claim: The evidence lower bound (ELBO) provides a tractable objective for variational inference by avoiding direct computation of the intractable marginal likelihood.
- Mechanism: The ELBO is derived by introducing a variational posterior q(z) and using the non-negativity of the KL divergence to obtain a lower bound on the log marginal likelihood. This allows optimization of the variational parameters without needing to compute the intractable integral.
- Core assumption: The KL divergence between the variational posterior and true posterior is non-negative.
- Evidence anchors:
  - [abstract] The tutorial introduces variational inference as maximizing the evidence lower bound (ELBO).
  - [section] "The key idea in variational inference is to replace the intractable marginal likelihood with a tractable lower bound that we then maximize... Because the KL divergence is always nonnegative, the first term lower bounds the log marginal likelihood... Hence—recalling that the KL divergence is nonnegative—we conclude that maximizing the ELBO is equivalent to minimizing the KL divergence."
  - [corpus] The corpus contains papers discussing variational inference and the ELBO, indicating its importance in the field.
- Break condition: The ELBO approximation becomes poor when the variational family is too restrictive to capture the true posterior.

### Mechanism 3
- Claim: Amortized variational inference scales to large datasets by sharing variational parameters across data points.
- Mechanism: Instead of learning separate variational parameters for each data point, a neural network (the encoder) is trained to predict variational parameters from data points. This reduces the number of optimization variables and allows the use of stochastic gradient descent.
- Core assumption: The variational parameters for different data points can be predicted from the data points themselves using a shared model.
- Evidence anchors:
  - [abstract] The tutorial discusses amortized variational inference for handling local latent variables in large datasets.
  - [section] "Many probabilistic models have local latent variables z_i associated with each data point x_i... Since the optimization variables are θ = {θ_1, ..., θ_N}, large datasets amount to large optimization problems... This led to the idea of amortized variational inference... wherein a machine learning model (often a neural network) is trained to directly predict the solution θ* of this optimization problem."
  - [corpus] The corpus contains papers on deep Gaussian processes and variational autoencoders, which are related to amortized variational inference.
- Break condition: Amortized variational inference may underperform when the relationship between data points and variational parameters is complex and cannot be captured by the shared model.

## Architecture Onboarding

- Component map:
  - Model (defines joint distribution p(x, z)) -> Variational family (specifies family Q) -> Variational posterior (specific q(z) from family) -> ELBO (objective function) -> Optimization method (reparameterization trick or black-box VI) -> Amortized inference (optional, for large datasets)

- Critical path:
  1. Define the model and choose a variational family
  2. Derive the ELBO as a function of the variational parameters
  3. Choose an optimization method (e.g., gradient descent, reparameterization trick, or black-box variational inference)
  4. Optimize the ELBO to find the best variational posterior
  5. (Optional) Implement amortized variational inference for large datasets

- Design tradeoffs:
  - Expressiveness vs. tractability: More expressive variational families can better approximate the true posterior but may be harder to optimize
  - Reparameterization vs. black-box: The reparameterization trick provides lower-variance gradients but is only applicable to certain distributions
  - Amortized vs. non-amortized: Amortized variational inference scales better to large datasets but may sacrifice some accuracy

- Failure signatures:
  - Poor approximation: The variational posterior does not closely match the true posterior, leading to suboptimal results
  - High variance: Gradient estimates have high variance, slowing down optimization
  - Mode collapse: The variational posterior focuses on a single mode of the true posterior, missing other important regions
