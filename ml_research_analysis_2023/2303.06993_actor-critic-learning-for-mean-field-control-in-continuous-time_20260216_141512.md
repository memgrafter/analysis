# Actor-Critic learning for mean-field control in continuous time

## Quick Facts
- arXiv ID: 2303.06993
- Source URL: https://arxiv.org/abs/2303.06993
- Reference count: 30
- One-line primary result: Actor-critic algorithms can learn optimal policies and value functions for mean-field control problems in continuous time from observation samples without requiring model coefficients

## Executive Summary
This paper develops actor-critic algorithms for mean-field control problems in continuous time using reinforcement learning. The authors introduce entropy regularization to derive a policy gradient representation that can be estimated from observation samples without knowledge of environment coefficients. The algorithms learn optimal policies and value functions by alternately updating the actor and critic using model-free estimation of the population state distribution. The paper provides theoretical analysis and numerical experiments on linear-quadratic mean-field control problems, showing that the proposed algorithms can learn near-optimal policies.

## Method Summary
The method involves developing policy gradient theorems for mean-field control in continuous time using entropy regularization and randomized policies. The gradient representation is derived such that it only requires observation samples of states, actions, rewards, and population distributions, not the model coefficients. Two actor-critic algorithms are proposed: an offline algorithm that uses all trajectories at once and an online algorithm that updates parameters incrementally. The algorithms estimate the population state distribution from observation samples using a weighted combination of empirical measures. For linear-quadratic problems, exact parametric forms for the actor and critic functions are derived based on matrix Riccati equations.

## Key Results
- Policy gradient representation with entropy regularization enables model-free learning without requiring environment coefficients
- Explicit solutions for linear-quadratic mean-field control problems provide benchmarks and guide parametric actor-critic function design
- Algorithms demonstrate convergence to optimal parameters and cost values in numerical experiments on systemic risk and optimal trading problems
- Neural network parameterizations achieve good performance comparable to exact forms

## Why This Works (Mechanism)

### Mechanism 1
The policy gradient theorem for mean-field control in continuous time can be derived using entropy regularization and randomized policies, allowing model-free learning without explicit knowledge of environment coefficients. By introducing entropy regularization to the cost function, the gradient ∇θJ(θ) can be expressed as an expectation involving only state samples, actions, and rewards - not requiring the model coefficients b, σ, f, g. This enables actor-critic algorithms that learn optimal policies from observation samples.

### Mechanism 2
The Wasserstein space framework allows handling the population state distribution in a principled way, enabling model-free estimation from observation samples. Instead of assuming access to a simulator of the state distribution, the paper estimates the population state distribution from observation of the representative player using a weighted combination of empirical measures. The propagation of chaos ensures that as the number of episodes grows, the empirical distribution converges to the true mean-field distribution.

### Mechanism 3
The linear-quadratic (LQ) mean-field control problem admits an explicit solution that can serve as a benchmark and guide the design of parametric actor-critic functions. For the LQ case with linear dynamics and quadratic costs, the optimal value function and randomized policy have specific structural forms involving matrix Riccati equations. The paper derives these explicit solutions and uses them to propose exact parametrizations for the critic and actor functions in the RL algorithms.

## Architecture Onboarding

- Component map:
  - State dynamics: dX_s = b(X_s, P_{X_s}, α_s)ds + σ(X_s, P_{X_s}, α_s)dW_s
  - Policy: πθ(.|t,x,µ) - randomized policy with parameter θ
  - Value function: Vπ(t,x,µ) - cost-to-go function for policy π
  - Critic function: Jη(t,x,µ) - parametric approximation of Vπ
  - Population distribution: µ - estimated from observation samples
  - Actor-critic algorithms: alternating updates of πθ and Jη

- Critical path:
  1. Initialize policy πθ and critic Jη
  2. For each episode:
     a. Sample initial state X0 ~ µ0
     b. For each time step tk:
        - Update population distribution µtk
        - Sample action αtk ~ πθ(.|tk,Xtk,µtk)
        - Observe next state Xtk+1 and cost ftk
        - Update critic Jη (policy evaluation)
        - Update policy πθ (policy gradient)
  3. Return learned Jη and πθ

- Design tradeoffs:
  - Online vs. offline learning: Online learning updates parameters incrementally using past samples, while offline learning uses all trajectories at once. Online is more suitable for real-time applications but may have higher variance.
  - Exact vs. neural network parametrizations: Exact parametrizations (based on LQ solutions) can provide better initializations and convergence guarantees but are only applicable to specific problem structures. Neural networks are more flexible but require more data and may have convergence issues.

- Failure signatures:
  - Slow convergence or divergence of the actor-critic updates
  - Large variance in the estimated gradients or value function
  - Poor performance on the LQ benchmark (if applicable)
  - Sensitivity to hyperparameters (learning rates, entropy regularization, etc.)

- First 3 experiments:
  1. Implement the offline actor-critic algorithm (Algorithm 1) for the mean-field systemic risk example with exact parametrization. Verify that the learned parameters match the optimal values and that the learned policy achieves similar performance to the optimal one.

## Limitations

- The approach relies heavily on the propagation of chaos assumption for the mean-field limit, which may not hold in systems with strong finite-size effects
- Theoretical analysis provides bounds on convergence but these depend on problem-specific constants that are not explicitly computed
- Numerical experiments focus on linear-quadratic cases where analytical solutions exist, limiting demonstration of performance on more complex, nonlinear problems

## Confidence

- High confidence: The policy gradient theorem derivation and the explicit solution for the linear-quadratic case are mathematically rigorous and well-supported
- Medium confidence: The model-free estimation of the population state distribution from observation samples is based on standard techniques but performance in more complex settings remains to be verified
- Low confidence: The generalization of the proposed algorithms to non-linear mean-field control problems and their performance relative to model-based approaches are not extensively explored
