# Sample Efficient Multimodal Semantic Augmentation for Incremental Summarization

## Quick Facts
- arXiv ID: 2303.04361
- Source URL: https://arxiv.org/abs/2303.04361
- Authors: 
- Reference count: 24
- One-line primary result: Improves ROUGE scores for video summarization by extracting semantic concepts from video frames and using them as additional input to BART

## Executive Summary
This paper introduces a multimodal semantic augmentation approach for incremental summarization of task videos. The method extracts semantic concepts from video frames using a pre-trained CLIP model extended with a perceiver resampler, then uses these concepts alongside video transcripts to enrich summaries generated by a BART model. The approach demonstrates improved summarization performance on the YouCook2 dataset through richer visual context incorporation.

## Method Summary
The method follows a two-stage process: first, it extracts semantic concepts from video frames using a modified CLIP model with perceiver resampler to handle variable-length inputs efficiently. Second, it implements a clustering-based batch creation approach to maintain diversity during training. These extracted semantic concepts are then used as additional input alongside video transcripts to a pre-trained BART model for generating enriched summaries. The entire pipeline is designed to be sample-efficient, requiring fewer training examples while maintaining performance.

## Key Results
- Improves ROUGE scores compared to baseline BART model without semantic augmentation
- Demonstrates effectiveness of semantic concept extraction from video frames for summarization
- Shows potential of incorporating richer visual context through semantic concepts

- Design tradeoffs:

  - Poor semantic concept extraction: Low accuracy in predicting annotations from video frames
