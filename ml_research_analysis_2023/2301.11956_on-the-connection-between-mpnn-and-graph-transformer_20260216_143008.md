# On the Connection Between MPNN and Graph Transformer

## Quick Facts
- arXiv ID: 2301.11956
- Source URL: https://arxiv.org/abs/2301.11956
- Reference count: 40
- Key outcome: MPNN with virtual node can approximate self-attention layers in linear transformers using O(1) depth and width, and can approximate full transformers with O(nd) width and O(1) depth or O(n) depth and O(1) width under certain assumptions

## Executive Summary
This paper establishes a theoretical connection between Message Passing Neural Networks (MPNN) and Graph Transformers (GT) by proving that MPNN with a virtual node (VN) can approximate self-attention layers in both linear transformers and full transformers. While previous work showed GT can approximate MPNN, this study proves the inverse relationship. The authors demonstrate that MPNN+VN can approximate self-attention in linear transformers like Performer and Linear Transformer using constant depth and width, and can approximate full transformers with either constant depth and O(nd) width or linear depth and constant width under specific assumptions about feature spaces.

## Method Summary
The paper introduces MPNN+VN, which adds a virtual node connected to all graph nodes, enabling global information aggregation and sharing. The method uses message passing between graph nodes and the virtual node, with the virtual node computing and distributing aggregated features across the graph. The theoretical analysis leverages DeepSets universality to prove approximation capabilities, while empirical evaluation compares MPNN+VN against GT, Linear Transformer, and standard MPNN on OGB datasets, Long Range Graph Benchmark (LRGB), and climate modeling tasks. The implementation uses 3 message passing layers with 256 hidden dimensions and MLPs with 512 neurons.

## Key Results
- MPNN+VN outperforms GT on Long Range Graph Benchmark datasets
- MPNN+VN improves over existing implementations on OGB datasets
- MPNN+VN outperforms Linear Transformer and MPNN on climate modeling tasks

## Why This Works (Mechanism)

### Mechanism 1
MPNN with virtual node can approximate self-attention layers in linear transformers using O(1) depth and width. The virtual node acts as global memory computing and sharing ∑n j=1 φ(kj) and ∑n j=1 φ(kj) ⊗ vj across all nodes, implementing linear attention computation. This relies on MLPs' ability to approximate feature maps and aggregation operations on compact domains.

### Mechanism 2
MPNN+VN can approximate full transformers with O(nd) width and O(1) depth via DeepSets connection. The architecture exactly simulates equivariant DeepSets, which are permutation equivariant universal, allowing approximation of any continuous permutation equivariant function including self-attention and full transformers.

### Mechanism 3
MPNN+VN with O(n) depth and O(1) width can approximate self-attention under strong feature space assumptions. The virtual node uses attention to sequentially select and process each node feature, building up attention computation across layers while maintaining constant width.

## Architecture Onboarding

- **Component map**: Graph nodes → Virtual node (global memory) → Message functions (φ(k)vn-gn, φ(k)gn-vn) → Update functions (γ(k)vn, γ(k)gn) → Attention mechanism (αvn)

- **Critical path**: Message passing from graph nodes to virtual node → Aggregation in virtual node → Message passing back to graph nodes → Update of graph node features

- **Design tradeoffs**: Depth vs width (O(1) depth with O(nd) width vs O(n) depth with O(1) width), computational efficiency (linear complexity vs quadratic self-attention), expressiveness (virtual node increases expressiveness but may introduce optimization challenges)

- **Failure signatures**: Over-smoothing from too many message passing iterations, under-reaching from insufficient depth, approximation error accumulation across layers

- **First 3 experiments**: 1) Verify MPNN+VN approximates self-attention in Performer/Linear Transformer on synthetic graphs, 2) Test MPNN+VN on OGB datasets against standard MPNN, 3) Evaluate MPNN+VN on LRGB for long-range modeling capabilities

## Open Questions the Paper Calls Out

1. **Can MPNN with virtual node approximate transformers beyond self-attention layers?** The paper demonstrates approximation of self-attention layers but leaves open whether MPNN+VN can approximate more complex transformer components like multi-head attention or position-wise feed-forward networks.

2. **What is the computational complexity trade-off between MPNN+VN and graph transformers for large-scale graphs?** While theoretical approximation is shown, the paper doesn't provide detailed complexity analysis comparing implementations across different graph sizes and feature dimensions.

3. **Can we characterize tasks requiring effective long-range interaction modeling where GT outperforms MPNN+VN?** The paper notes the lack of good benchmark datasets where GT significantly outperforms MPNN+VN and emphasizes understanding the inductive biases of both architectures.

## Limitations

- Theoretical claims rely on strong assumptions about feature space separability that may not hold in practice
- Proof assumes idealized conditions that real-world graphs and attention mechanisms may not satisfy
- Evaluation scope is limited to specific datasets and tasks, with specialized graph construction in climate modeling experiments

## Confidence

- MPNN+VN can approximate self-attention in linear transformers with O(1) depth/width: **Medium**
- MPNN+VN can approximate full transformers with O(nd) width and O(1) depth: **Medium**
- MPNN+VN outperforms GT on OGB and LRGB datasets: **High**
- MPNN+VN improves over Linear Transformer on climate modeling: **Medium**
