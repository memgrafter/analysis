# Theory on Forgetting and Generalization of Continual Learning

## Quick Facts
- arXiv ID: 2302.05836
- Source URL: https://arxiv.org/abs/2302.05836
- Reference count: 40
- Key outcome: First-known explicit theoretical results on expected forgetting and generalization error in continual learning under overparameterized linear models with i.i.d. Gaussian features and noise.

## Executive Summary
This paper provides the first-known explicit theoretical analysis of forgetting and generalization error in continual learning under overparameterized linear models with i.i.d. Gaussian features and noise. The authors derive closed-form expressions that capture dependencies on system parameters like overparameterization ratio, task similarity, and task ordering. Key findings include that overparameterization can lead to zero forgetting, generalization error decreases with task similarity while forgetting may not, and optimal task ordering tends to diversify tasks early while learning dissimilar tasks adjacently. Experiments with deep neural networks corroborate these insights, demonstrating applicability to practical CL setups.

## Method Summary
The paper analyzes continual learning under overparameterized linear models with i.i.d. Gaussian features and noise. For each task, they derive closed-form expressions for expected forgetting E[FT] and generalization error E[GT] when using SGD to find minimum-norm solutions. The analysis considers different overparameterization ratios (p/n), task similarities measured by optimal model gap, and task orderings. The theoretical framework is validated through experiments on real datasets using deep neural networks.

## Key Results
- Overparameterization can lead to zero forgetting and alleviate negative impacts of task dissimilarity on generalization error
- Generalization error monotonically decreases with task similarity, while forgetting may not follow this pattern
- Optimal task order tends to diversify tasks early and learn dissimilar tasks adjacently
- Benign overfitting exists under large noise or low task similarity

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Overparameterization can lead to zero forgetting in continual learning under certain conditions.
- Mechanism: As the number of parameters p increases beyond the number of samples n, the forgetting term in the closed-form expression approaches zero because the coefficients associated with task dissimilarity diminish.
- Core assumption: The model is overparameterized (p > n) and the training uses stochastic gradient descent that converges to the minimum-norm solution.
- Evidence anchors:
  - [abstract]: "More parameters in the overparameterized regime can lead to zero forgetting and alleviate the negative impact of task dissimilarity on generalization error"
  - [section]: "when p→∞ , we can have that E[FT ]→ 0"
- Break condition: This mechanism breaks when p is not sufficiently large relative to n, or when the noise level is extremely high, or when tasks are highly dissimilar.

### Mechanism 2
- Claim: Task similarity affects generalization error monotonically, but forgetting may not follow this pattern.
- Mechanism: The generalization error term G2 in the closed-form expression decreases when tasks become more similar (smaller ∥w*_k - w*_i∥^2). However, forgetting F2 contains coefficients c_ij that can be negative, allowing forgetting to decrease when tasks become less similar under certain conditions.
- Core assumption: The relationship between task similarity and forgetting depends on the specific coefficient structure in the closed-form expression.
- Evidence anchors:
  - [abstract]: "Generalization error monotonically decreases with task similarity, while forgetting may not"
  - [section]: "the generalization error GT (wT ) decreases when ∥w*_k - w*_i∥^2 for any two different tasks k and i decreases... In contrast, the forgetting FT may not change monotonically"
- Break condition: This mechanism breaks when the coefficient structure changes significantly, such as with very different task ordering or when the model is not in the overparameterized regime.

### Mechanism 3
- Claim: The optimal task order for minimizing forgetting tends to diversify tasks early and learn dissimilar tasks adjacently.
- Mechanism: The closed-form expression shows that coefficients c_ij are smaller when i and j are smaller and closer, implying that tasks with larger ∥w*_i - w*_j∥^2 should be learned adjacently with higher priority. Special cases like alternating orders between task categories minimize forgetting.
- Core assumption: The optimal task order can be determined by analyzing the coefficient structure in the closed-form forgetting expression.
- Evidence anchors:
  - [abstract]: "The optimal task order to minimize forgetting tends to diversify tasks early and learn dissimilar tasks adjacently"
  - [section]: "tasks with larger ∥w*_i - w*_j∥^2 should be learnt adjacently with higher priority in CL, in order to minimize the impact of the task dissimilarity"
- Break condition: This mechanism breaks when task similarity structure is uniform across all tasks, or when the task ordering cannot be controlled.

## Architecture Onboarding

- Component map: Linear regression models for each task → i.i.d. Gaussian features and noise → SGD training to find minimum-norm solutions → Performance evaluation using forgetting and generalization error metrics
- Critical path: 1) Define linear ground truth for each task, 2) Generate i.i.d. Gaussian features and noise, 3) Train each task sequentially using minimum-norm solution, 4) Compute forgetting and generalization error using closed-form expressions
- Design tradeoffs: The linear model assumption simplifies analysis but may not capture all aspects of deep neural networks. The i.i.d. Gaussian assumption enables closed-form solutions but may not reflect real-world data distributions.
- Failure signatures: If p < n+2, the closed-form expressions don't hold. If tasks have very different feature sets that violate the union assumption, the analysis needs modification. If noise levels vary significantly across tasks, the simplified expressions may not be accurate.
- First 3 experiments:
  1. Verify the closed-form expressions for E[FT] and E[GT] by comparing theoretical predictions with simulation results for T=2 tasks.
  2. Test the impact of overparameterization by varying p while keeping n fixed and observing the forgetting and generalization error trends.
  3. Examine the impact of task ordering by creating tasks with known optimal model gaps and testing different orderings to verify the theoretical predictions about optimal task sequences.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do the theoretical results on forgetting and generalization error extend to non-linear models beyond the overparameterized linear regression setup?
- Basis in paper: [explicit] The paper mentions that their insights for linear models are applicable to practical CL setups with DNNs, but doesn't provide theoretical extensions.
- Why unresolved: The current theoretical framework is specific to linear models with Gaussian features and noise, making generalization to non-linear models challenging.
- What evidence would resolve it: Formal theoretical analysis showing how the key parameters (overparameterization ratio, task similarity, task ordering) affect forgetting and generalization in non-linear models.

### Open Question 2
- Question: What is the exact mathematical relationship between the task similarity metric (optimal model gap) used in the paper and practical task similarity metrics used in empirical CL studies?
- Basis in paper: [explicit] The paper uses ∥w_i* - w_j*∥² as the task similarity metric and mentions that recent studies found "intermediate task similarity" leads to worst forgetting, but doesn't formally connect these metrics.
- Why unresolved: The paper identifies that forgetting can increase when adjacent tasks become more similar, but doesn't provide a precise mathematical characterization of this relationship across different similarity metrics.
- What evidence would resolve it: Mathematical proofs showing how different task similarity metrics relate to the optimal model gap and affect forgetting/generization performance.

### Open Question 3
- Question: How does the optimal task ordering change when the ground truth models have different norms (∥w_i*∥²) across tasks rather than being equal as assumed in Section 4.3?
- Basis in paper: [explicit] The analysis of optimal task ordering in Section 4.3 assumes ∥w_i*∥² = w for all tasks, but notes this assumption may not hold in practice.
- Why unresolved: The current analysis only considers the case where all tasks have equal model norms, making it difficult to determine optimal ordering when tasks have varying complexity or importance.
- What evidence would resolve it: Extended theoretical analysis showing how varying task model norms affect the optimal task ordering for minimizing forgetting and generalization error.

## Limitations
- Theoretical analysis is limited to overparameterized linear models with i.i.d. Gaussian features and noise
- Minimum-norm solution assumption from SGD may not hold for all optimization algorithms
- Theoretical predictions may not hold for finite p/n ratios, only asymptotic limits

- Claims about task similarity and generalization error: Medium-High
