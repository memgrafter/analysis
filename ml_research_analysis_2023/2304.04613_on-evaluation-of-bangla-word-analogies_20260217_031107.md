# On Evaluation of Bangla Word Analogies

## Quick Facts
- arXiv ID: 2304.04613
- Source URL: https://arxiv.org/abs/2304.04613
- Reference count: 18
- This paper introduces high-quality datasets for evaluating Bangla word embeddings, addressing the challenges of this low-resource language.

## Executive Summary
This paper presents two datasets for evaluating Bangla word embeddings: a Mikolov-style word analogy set with 16,678 samples and a translated/cleaned version of the Mikolov dataset with 10,594 samples. The datasets cover both semantic and syntactic analogies, with special attention to Bangla's unique morphological features like gender forms, number-ordinal transformations, and colloquial variants. Experiments with state-of-the-art embedding models reveal that Bangla embeddings still struggle with high accuracy, highlighting the need for larger training datasets and consideration of Bangla's morphological richness.

## Method Summary
The authors created a Bangla-specific word analogy dataset through manual construction of analogy pairs reflecting Bangla linguistic phenomena, and translated/curated the English Mikolov dataset for cross-lingual benchmarking. They evaluated multiple embedding models including Word2Vec, GloVe, fastText, LASER, LaBSE, bnBERT, and bnBART using Top-1 and Top-5 accuracy metrics. The evaluation pipeline involves computing target vectors for each analogy and finding nearest neighbors in embedding space.

## Key Results
- Current state-of-the-art embeddings struggle with high accuracy on Bangla word analogies
- Bangla has unique morphological characteristics that challenge standard embedding approaches
- Training data diversity (multilingual vs monolingual) significantly impacts embedding quality
- The created datasets enable both native and cross-lingual evaluation of Bangla embeddings

## Architecture Onboarding

- Component map:
  Dataset creation -> analogy pair generation (manual + automated) -> translation & curation -> embedding evaluation pipeline
  Embedding models: Word2Vec, GloVe, fastText, LASER, LaBSE, bnBERT, bnBART
  Evaluation: Top-1 and Top-5 accuracy on semantic and syntactic analogy sets

- Critical path:
  1. Construct Bangla-specific analogy pairs
  2. Translate and clean Mikolov dataset for cross-lingual evaluation
  3. Load embeddings from various models
  4. For each analogy, compute the target vector and find nearest neighbor
  5. Aggregate accuracy metrics

- Design tradeoffs:
  - Manual dataset creation is labor-intensive but ensures linguistic accuracy
  - Using translated datasets risks semantic drift but enables cross-lingual benchmarking
  - Multilingual models may generalize better but could dilute language-specific nuances

- Failure signatures:
  - Low accuracy across all models → dataset issues or embeddings fundamentally misaligned
  - High variance between semantic and syntactic accuracy → embeddings capture one type better than the other
  - Cross-lingual dataset performance much lower than native → translation quality or analogy type mismatch

- First 3 experiments:
  1. Run analogy evaluation on a small subset of the dataset with Word2Vec and bnBERT to verify pipeline correctness
  2. Compare performance on translated vs native Mikolov analogies to assess cross-lingual validity
  3. Test effect of embedding dimensionality by training a simple Word2Vec model with varying dimensions on the same corpus
