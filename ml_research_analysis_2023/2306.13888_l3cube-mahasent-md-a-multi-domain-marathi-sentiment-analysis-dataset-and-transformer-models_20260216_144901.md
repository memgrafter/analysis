# L3Cube-MahaSent-MD: A Multi-domain Marathi Sentiment Analysis Dataset and Transformer Models

## Quick Facts
- arXiv ID: 2306.13888
- Source URL: https://arxiv.org/abs/2306.13888
- Reference count: 13
- Primary result: Multi-domain Marathi sentiment analysis dataset with 60,000 samples across 4 domains; MahaBERT achieves 80.13% accuracy

## Executive Summary
This paper introduces L3Cube-MahaSent-MD, a multi-domain sentiment analysis dataset for Marathi containing approximately 60,000 manually annotated samples across four domains: movie reviews, general tweets, TV show subtitles, and political tweets. The dataset covers three sentiment classes (positive, negative, neutral) and addresses the critical need for low-resource language datasets that capture domain-specific sentiment expressions. The authors fine-tune four BERT-based models (mBERT, IndicBERT, MuRIL, and MahaBERT) and demonstrate that domain-specific models do not generalize well across domains, while the MahaBERT model trained on all domains achieves the best overall performance at 80.13% accuracy.

## Method Summary
The authors created a multi-domain Marathi sentiment analysis dataset through web scraping, translation, and tweet collection across four domains. They employed three native Marathi speakers for manual annotation using domain-specific guidelines, achieving Cohen's Kappa of 0.86. The dataset was preprocessed by removing hashtags, mentions, symbols, and emoticons for certain domains. Four BERT models were fine-tuned on these datasets: mBERT, IndicBERT, MuRIL, and MahaBERT (a Marathi-specific model trained on 752M tokens). Models were evaluated on both in-domain and cross-domain test sets to assess generalization capabilities.

## Key Results
- L3Cube-MahaSent-MD contains 60,000 manually tagged Marathi samples across 4 domains
- MahaBERT-All model achieves highest accuracy of 80.13% when trained on all domains
- Domain-specific models show poor cross-domain generalization (e.g., MahaBERT-PT achieves only 64.93% on MahaSent-GT test set)
- Manual annotation is crucial as out-of-domain pseudo-labeling achieves only 60-70% accuracy

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MahaBERT outperforms multilingual models because it is trained specifically on Marathi text
- Mechanism: MahaBERT leverages a large monolingual Marathi corpus (752M tokens) for pretraining, learning domain-specific linguistic features that multilingual models miss
- Core assumption: Monolingual pretraining on substantial target language corpus is more effective than multilingual pretraining for that language's tasks
- Evidence anchors: MahaBERT achieves highest accuracies for MahaSent-PT, MahaSent-GT, and MahaSent-MR compared to MuRIL and other BERT-based models
- Break condition: If monolingual corpus is too small or lacks domain diversity, model may not generalize well

### Mechanism 2
- Claim: Multi-domain training improves model generalization compared to domain-specific models
- Mechanism: MahaBERT-All learns shared features across domains while maintaining domain-specific knowledge, resulting in better performance on both in-domain and cross-domain test sets
- Core assumption: Different text domains share underlying linguistic patterns that can be learned jointly
- Evidence anchors: MahaBERT-All exhibits highest accuracy scores for both MahaSent-ST and MahaSent-All datasets, indicating remarkable ability to generalize across various datasets
- Break condition: If domains are too dissimilar, joint training might dilute domain-specific signals

### Mechanism 3
- Claim: Manual annotation with domain-specific guidelines improves model performance compared to pseudo-labeling
- Mechanism: Human annotators apply nuanced understanding of domain-specific sentiment expressions, while out-of-domain models achieve only 60-70% accuracy
- Core assumption: Sentiment expression varies significantly across domains, requiring human judgment to capture subtle contextual cues
- Evidence anchors: Dataset consists of 60,000 manually tagged samples; out-domain models utilized for pseudo-labeling achieved 60-70% accuracy
- Break condition: If annotation guidelines are inconsistent or annotators lack domain expertise, manual annotation could introduce more noise

## Architecture Onboarding

- Component map: Data collection pipeline (web scraping, translation, tweet collection) → Annotation pipeline (manual labeling with domain-specific guidelines) → Preprocessing pipeline (cleaning tweets, subtitles, reviews) → Model training pipeline (fine-tuning BERT variants) → Evaluation pipeline (in-domain and cross-domain accuracy measurement)
- Critical path: Data collection → Manual annotation → Preprocessing → Model fine-tuning → Evaluation. Manual annotation is the bottleneck due to need for native Marathi speakers and domain expertise
- Design tradeoffs: Creating multi-domain dataset rather than focusing on single domain trades depth for breadth across multiple domains, enabling cross-domain analysis but potentially resulting in less specialized models
- Failure signatures: Domain-specific models performing poorly on out-domain data (MahaBERT-PT on MahaSent-GT test set), pseudo-labeling accuracy dropping below 60%, Cohen's Kappa falling below acceptable thresholds
- First 3 experiments:
  1. Fine-tune mBERT on MahaSent-PT and evaluate on MahaSent-PT test set to establish baseline multilingual performance
  2. Fine-tune MahaBERT on MahaSent-PT and evaluate on MahaSent-PT test set to compare monolingual vs multilingual performance
  3. Fine-tune MahaBERT on all domains (MahaSent-All) and evaluate cross-domain performance on MahaSent-GT and MahaSent-ST test sets

## Open Questions the Paper Calls Out

- How do the performance of multilingual and monolingual BERT models compare when trained on datasets from other low-resource languages besides Marathi?
- How does the inclusion of additional domains in the sentiment analysis dataset impact the performance of BERT models across various tasks?
- How do domain-specific models perform on sentiment analysis tasks in other languages, and can a multi-domain model trained on a diverse set of languages outperform these domain-specific models?

## Limitations

- The dataset contains only 60,000 samples across four domains, which is relatively small for training robust deep learning models
- Manual annotation relied on a small team of three native Marathi speakers, potentially limiting annotation consistency across domains
- Cross-domain performance analysis shows domain-specific models perform significantly worse on out-of-domain test sets, highlighting fundamental domain adaptation challenges

## Confidence

**High Confidence**: The core claim that domain-specific sentiment models do not generalize well across domains is well-supported by cross-domain accuracy results. Manual annotation process and quality metrics are clearly documented.

**Medium Confidence**: The claim that MahaBERT outperforms multilingual models is supported by experimental results, but comparison lacks detailed analysis of pretraining corpus sizes and specific advantages of monolingual vs multilingual pretraining strategies.

**Low Confidence**: The assertion that multi-domain training provides superior generalization is based on limited evidence, with significant variation in individual domain dataset sizes potentially confounding the analysis.

## Next Checks

1. Conduct ablation studies to determine which linguistic features transfer across domains by analyzing feature importance and attention patterns in MahaBERT-All model when evaluated on different domain test sets.

2. Perform additional inter-annotator agreement studies with a larger pool of annotators to ensure manual annotation quality is consistent across all four domains, particularly for the smaller MahaSent-MR dataset.

3. Obtain and analyze the Marathi-specific pretraining data used for multilingual models (mBERT, IndicBERT, MuRIL) to quantify differences in corpus size and domain coverage compared to the 752M tokens used for MahaBERT pretraining.
