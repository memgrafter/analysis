# CL-UZH at SemEval-2023 Task 10: Sexism Detection through Incremental Fine-Tuning and Multi-Task Learning with Label Descriptions

## Quick Facts
- arXiv ID: 2306.03907
- Source URL: https://arxiv.org/abs/2306.03907
- Reference count: 26
- Key outcome: Multi-task learning with label descriptions achieves F1 85.9% (rank 13/84) on binary sexism detection

## Executive Summary
This paper presents a multi-task learning approach for sexism detection and categorization in social media posts. The method reformulates each task as binary pairwise text classification with label descriptions and dataset identifiers as inputs. The model is trained in three phases: general multi-task training on related abusive language datasets, fine-tuning on all EDOS subtasks, and final fine-tuning on the target subtask. The approach achieves strong performance on binary sexism detection and moderate results on categorization tasks, with multi-task learning significantly improving performance over single-task baselines.

## Method Summary
The method reformulates multi-class and multi-label classification tasks as binary pairwise classification by conditioning the model on dataset identifiers and label descriptions. It uses DeBERTa-V3-large fine-tuned on NLI datasets as the backbone model. The training follows a three-phase incremental fine-tuning strategy: (1) general multi-task training on abusive language datasets, (2) fine-tuning on all EDOS subtasks, and (3) final fine-tuning on the target subtask. The model takes dataset identifier + label description as the first input sequence and text as the second sequence, enabling multi-task learning without multiple model heads.

## Key Results
- Binary sexism detection: F1 85.9%, rank 13/84
- Coarse-grained categorization: F1 64.8%, rank 19/69
- Fine-grained categorization: F1 44.9%, rank 26/63
- Multi-task learning with label descriptions significantly improves performance over single-task baselines
- Model performs better with fewer classes during inference (F1 48.5% with 4 classes vs 41.1% with 10 classes)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multi-task learning via label descriptions improves performance by providing semantic context to the model
- Mechanism: The model receives dataset identifier + label description as first input sequence and text as second sequence, allowing it to learn task-specific patterns through context
- Core assumption: Label descriptions provide sufficient semantic information for the model to distinguish between different tasks and classes
- Evidence anchors:
  - [abstract]: "We implement multi-task learning via manipulation of the input, concretely by adding label descriptions, and dataset identifiers"
  - [section 4.1]: "This allows us to simultaneously train on multiple datasets with different labeling schemes and a different number of distinct labels without adjusting the model architecture"

### Mechanism 2
- Claim: Incremental fine-tuning strategy improves adaptation to target task
- Mechanism: Three-phase training (general multi-task → EDOS multi-task → target subtask) allows progressive specialization
- Core assumption: Each training phase builds on knowledge from previous phases without catastrophic forgetting
- Evidence anchors:
  - [section 4.4]: "Our method involves a three-stage training process. As a first step, we train a general abusive language detection model using all available training data. In the second step, we further fine-tune this model on all three EDOS subtasks, and finally, in the third step, we fine-tune the model only on the target subtask"
  - [section 5.1]: "+ single task fine-tuning" shows performance increases on subtasks B and C after additional fine-tuning

### Mechanism 3
- Claim: Starting from NLI-fine-tuned model provides better foundation for text classification tasks
- Mechanism: Pre-trained DeBERTa-V3 model already fine-tuned on NLI datasets provides stronger text-pair understanding
- Core assumption: NLI fine-tuning improves the model's ability to understand relationships between text pairs
- Evidence anchors:
  - [section 4.1]: "We use DeBERTa (He et al., 2020), specifically DeBERTa-V3-large (He et al., 2021) fine-tuned on a range of natural language inference (NLI) datasets"
  - [section 5.1]: "+ NLI fine-tuning" shows consistent performance improvements across all subtasks

## Architecture Onboarding

- Component map: Input formatting → DeBERTa encoding → Binary classification → Multi-task training
- Critical path: Input formatting → DeBERTa encoding → Binary classification → Multi-task training
- Design tradeoffs:
  - Using label descriptions instead of multiple heads simplifies architecture but requires careful prompt engineering
  - Incremental fine-tuning improves adaptation but increases training time
  - Dataset identifiers help distinguish similar labels across datasets but add complexity to input formatting
- Failure signatures:
  - Poor performance on multi-class tasks indicates label descriptions may be too ambiguous
  - Catastrophic forgetting suggests fine-tuning steps are too aggressive
  - Inconsistent results across runs may indicate insufficient training data or improper hyperparameter tuning
- First 3 experiments:
  1. Test single-task performance with and without label descriptions to verify their contribution
  2. Compare multi-task learning with single-task learning on EDOS data only
  3. Evaluate the impact of dataset identifiers by training with and without them on auxiliary tasks

## Limitations
- Consistent under-prediction of scarce classes significantly impacts macro-F1 performance, particularly in fine-grained categorization
- Performance degrades substantially when using more classes during inference (F1 41.1% with 10 classes vs 48.5% with 4 classes)
- Evidence for multi-task learning benefits is limited to ablation studies on development set

## Confidence

**High confidence**: Binary sexism detection performance (F1 85.9%, rank 13/84) - this represents the strongest result with clear ranking in the competition and consistent improvements from the proposed multi-task approach.

**Medium confidence**: Multi-task learning benefits - while improvements are observed, the evidence comes primarily from ablation studies on the development set, and the specific contributions of individual components (label descriptions vs dataset identifiers) are not fully isolated.

**Low confidence**: Fine-grained categorization performance (F1 44.9%, rank 26/63) - this result shows significant room for improvement and may be influenced by the model's tendency to under-predict scarce classes, making it difficult to assess the true capability of the approach.

## Next Checks

1. **Class imbalance analysis**: Conduct a detailed breakdown of predictions across all classes to quantify the extent of under-prediction for scarce classes and test whether class weighting or sampling techniques during training improve macro-F1 scores.

2. **Label description ablation**: Systematically test the approach with simplified label descriptions (e.g., single keywords vs full descriptions) to determine the minimum semantic information required for effective task discrimination and identify potential overfitting to verbose descriptions.

3. **Cross-dataset generalization**: Evaluate the model's performance on held-out samples from the auxiliary datasets not used during training to verify that multi-task learning provides genuine generalization benefits rather than overfitting to the specific EDOS task structure.
