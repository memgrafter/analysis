# Investigating Conversational Search Behavior For Domain Exploration

## Quick Facts
- **arXiv ID**: 2301.04098
- **Source URL**: https://arxiv.org/abs/2301.04098
- **Reference count**: 24
- **Primary result**: Laboratory study analyzing 669 dialogue messages from 26 participants exploring five domains using text chat interface

## Executive Summary
This paper presents a laboratory study investigating conversational search behavior for domain exploration through text-based dialogue systems. The research addresses the challenge of designing conversational interfaces for exploratory search where users have unclear information goals in unfamiliar domains. The study analyzes dialogue patterns across five domains (countries, climate, music, vacations, football) to understand how users interact with conversational search systems and what dialogue acts enable effective domain knowledge discovery.

The analysis reveals that effective exploratory search depends on proactive agents that can familiarize users with domains through iterative interactions involving metadata exploration, aggregated data queries, and user feedback mechanisms. The study provides empirical evidence for the distribution of dialogue acts and their interrelations, offering concrete design implications for conversational search systems that support domain exploration.

## Method Summary
The study employed a laboratory experiment with 26 participants engaging in open-ended exploratory search dialogues across five domains using a text chat interface. Participants interacted with a conversational search system while exploring topics in countries, climate, music, vacations, and football. The researchers collected and analyzed 669 dialogue messages using statistical analysis and process mining techniques. Dialogue acts were coded and categorized to identify patterns in user-system interactions, with particular attention to how users formulate requests, provide feedback, and engage with system responses during exploratory search tasks.

## Key Results
- Dialogue acts distribution: requests (32%), descriptions (19.3%), acknowledgments (8.1%), lists (7.0%), ranks (6.7%)
- Identification of core dialogue acts and their interrelations enabling domain knowledge discovery
- Derivation of design suggestions for conversational search systems supporting exploratory search

## Why This Works (Mechanism)
The study demonstrates that effective conversational search for domain exploration works through iterative interactions where users gradually build understanding through metadata exploration, aggregated data queries, and feedback mechanisms. The proactive agent behavior that anticipates user needs and provides structured responses enables users to navigate unfamiliar domains effectively. The text-based interface allows for precise analysis of dialogue patterns while maintaining sufficient flexibility for natural conversation flow.

- **User feedback mechanisms**: Important for adaptive system responses; quick check measures response accuracy and user satisfaction

## Architecture Onboarding
- **Component map**: User Interface -> Dialogue Manager -> Knowledge Base -> Response Generator -> User Interface
- **Critical path**: User query -> Dialogue interpretation -> Knowledge retrieval -> Response formulation -> User feedback
- **Design tradeoffs**: Text vs. voice interface (precision vs. natural interaction), proactive vs. reactive agent behavior (guidance vs. user control), structured vs. open-ended responses (clarity vs. flexibility)
- **Failure signatures**: User confusion indicated by repeated similar queries, system misunderstanding shown by irrelevant responses, exploration breakdown evidenced by conversation abandonment
- **First experiments**: 1) A/B test text vs. voice interface with same dialogue system, 2) Compare proactive vs. reactive agent behaviors in domain exploration tasks, 3) Test structured response templates against free-form responses for effectiveness

## Limitations
- Sample size of 26 participants may not capture full diversity of conversational search patterns
- Controlled laboratory setting constrains ecological validity compared to real-world voice-based systems
- Analysis limited to five specific domains that may not represent all exploratory search contexts

## Confidence
- **High confidence**: Descriptive statistics for dialogue acts (requests 32%, descriptions 19.3%, acknowledgments 8.1%, lists 7.0%, ranks 6.7%) based on concrete data from 669 messages
- **Medium confidence**: Identification of core dialogue acts and interrelations using process mining techniques with interpretive pattern identification
- **Medium confidence**: Design suggestions derived from observed patterns requiring validation in deployed systems
