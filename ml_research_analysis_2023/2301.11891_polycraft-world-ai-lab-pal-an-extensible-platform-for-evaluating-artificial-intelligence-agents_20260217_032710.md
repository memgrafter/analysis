# Polycraft World AI Lab (PAL): An Extensible Platform for Evaluating Artificial Intelligence Agents

## Quick Facts
- arXiv ID: 2301.11891
- Source URL: https://arxiv.org/abs/2301.11891
- Reference count: 36
- Key outcome: PAL is a versatile platform for evaluating AI agents in complex, open-world tasks using Minecraft mod Polycraft World, with an API enabling flexible task creation and agent evaluation

## Executive Summary
The Polycraft World AI Lab (PAL) is a versatile platform for evaluating artificial intelligence agents in complex, open-world tasks. Built on the Minecraft mod Polycraft World, PAL offers an API that allows agents with different architectures to easily interact with the environment, train, and be evaluated. PAL enables flexible task creation and manipulation, with all actions logged for streamlined evaluation. Two custom tasks were implemented: a multi-step planning task (POGO) and a navigation task (HUGA). Agents were developed and evaluated on each task, with the HUGA agent achieving a ~94% success rate. PAL's extensibility allows for increased task complexity, making it a valuable tool for fundamental AI research.

## Method Summary
PAL was developed as an API-based platform built on top of the Minecraft mod Polycraft World. The platform provides a standardized interface for AI agents to interact with the environment, supporting different agent architectures and training methodologies. The system includes comprehensive logging capabilities to track agent actions and facilitate evaluation. Two specific tasks were implemented to demonstrate the platform's capabilities: POGO, a multi-step planning task, and HUGA, a navigation task. Custom agents were developed and trained for each task, with performance metrics collected to assess their effectiveness.

## Key Results
- PAL provides an extensible API for AI agent evaluation in Minecraft-based environments
- Two custom tasks (POGO and HUGA) were successfully implemented and evaluated
- HUGA navigation task achieved approximately 94% success rate
- Platform supports flexible task creation and comprehensive logging for evaluation

## Why This Works (Mechanism)
PAL leverages the complex, open-world nature of Minecraft and Polycraft World to provide challenging environments for AI agent evaluation. The platform's API design allows agents to interact with the environment through standardized interfaces, enabling easy integration of different agent architectures. The logging system captures all agent actions, providing rich data for performance analysis and evaluation. The combination of complex environments, flexible API design, and comprehensive evaluation tools creates a robust platform for testing and comparing different AI approaches.
