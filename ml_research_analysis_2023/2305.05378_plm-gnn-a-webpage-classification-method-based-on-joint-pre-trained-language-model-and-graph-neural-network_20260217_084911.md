# PLM-GNN: A Webpage Classification Method based on Joint Pre-trained Language Model and Graph Neural Network

## Quick Facts
- **arXiv ID**: 2305.05378
- **Source URL**: https://arxiv.org/abs/2305.05378
- **Reference count**: 0
- **Primary result**: Achieves accuracy of 1.000 on KI-04, 0.902 on SWDE, and 0.992-1.000 on AHS datasets

## Executive Summary
PLM-GNN is a novel webpage classification method that combines pre-trained language models (PLMs) with graph neural networks (GNNs) to leverage both textual content and HTML DOM tree structure. The method addresses automatic webpage classification by extracting text from web pages for PLM processing while simultaneously constructing graphs from DOM trees using XPath information for GNN processing. These complementary representations are then concatenated and classified using an MLP. The approach demonstrates strong performance across multiple benchmark datasets, achieving near-perfect accuracy in most cases.

## Method Summary
The PLM-GNN method operates by first extracting textual content from web pages and feeding it into a pre-trained language model to obtain rich text representations. Simultaneously, it constructs a graph representation from the HTML DOM tree using XPath information to capture structural relationships. GNNs are then applied to learn meaningful structural features from the graph representation. The text and graph representations are concatenated and passed through a multilayer perceptron classifier to produce final classification results. This dual approach allows the model to capture both semantic meaning from text and structural patterns from HTML organization.

## Key Results
- Achieves perfect accuracy (1.000) on the KI-04 benchmark dataset
- Demonstrates strong performance on SWDE with 0.902 accuracy
- Shows excellent results on practical dataset AHS with 0.992-1.000 accuracy
- Ablation studies confirm that both text and DOM tree features contribute significantly to classification performance

## Why This Works (Mechanism)
The method's effectiveness stems from its ability to capture complementary information sources: textual semantics from PLMs and structural relationships from GNNs. Web pages contain rich semantic content in their text that PLMs excel at processing, while their HTML DOM structure encodes important organizational patterns that GNNs can exploit. By jointly learning from both representations, PLM-GNN achieves superior classification performance compared to using either modality alone.

## Architecture Onboarding

**Component Map**: Text Extraction -> PLM -> Text Representation; DOM Graph Construction -> GNN -> Graph Representation; Concatenation -> MLP -> Classification

**Critical Path**: The most critical sequence is Text Extraction → PLM → Concatenation → MLP, as text features typically carry the primary classification signal, with DOM structure providing supplementary information.

**Design Tradeoffs**: The main tradeoff involves balancing PLM complexity (computational cost) against GNN depth (structural learning capacity). Using larger PLMs improves text understanding but increases inference time, while deeper GNNs better capture complex DOM relationships but risk overfitting on simpler webpages.

**Failure Signatures**: Performance degradation typically occurs when text extraction fails to capture key content, DOM graphs become too sparse or disconnected, or the two modalities provide conflicting signals during fusion.
