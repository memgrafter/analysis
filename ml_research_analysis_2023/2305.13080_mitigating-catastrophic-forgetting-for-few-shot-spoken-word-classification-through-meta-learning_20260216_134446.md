# Mitigating Catastrophic Forgetting for Few-Shot Spoken Word Classification Through Meta-Learning

## Quick Facts
- arXiv ID: 2305.13080
- Source URL: https://arxiv.org/abs/2305.13080
- Reference count: 0
- Key outcome: MAMLCon consistently outperforms another MAML extension (OML) in few-shot continual learning for spoken word classification, achieving 77.0% accuracy vs. 64.5% for OML on a 50-class FACC setup.

## Executive Summary
This paper addresses the problem of few-shot spoken word classification in a continual learning setting, where a model is incrementally introduced to new word classes and may suffer from catastrophic forgetting of earlier words. The authors propose MAMLCon, an extension to model-agnostic meta-learning (MAML), which adds a single gradient update step using stored templates from all previously seen classes at the end of each inner learning loop. This allows the model to learn how to continually learn new classes while retaining knowledge of earlier ones. Experiments on Google Commands and FACC datasets show that MAMLCon consistently outperforms another MAML extension (OML) in terms of overall accuracy across various continual learning scenarios with different numbers of shots, update frequencies, and final class counts.

## Method Summary
MAMLCon extends MAML by explicitly doing meta-learning of an increasing number of new classes in the inner loop of the algorithm. At the end of the inner loop, a single weight update is performed on a previously seen template from each class, enabling the model to leverage its prior knowledge. The method differs from OML in several ways: updating the entire network in the inner loop, allowing access to a single example of a previously seen class during the inner-loop training phase, and performing meta-test on all classes seen up to that point rather than a random sample. This approach enables the model to continually learn new classes while retaining knowledge of earlier ones.

## Key Results
- MAMLCon achieves 77.0% accuracy vs. 64.5% for OML on a 50-class FACC setup.
- MAMLCon consistently outperforms OML in overall accuracy across various continual learning scenarios with different numbers of shots, update frequencies, and final class counts.
- The method shows effectiveness in mitigating catastrophic forgetting in few-shot continual learning for spoken word classification.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MAMLCon mitigates catastrophic forgetting by performing a single gradient update using stored templates from all previously seen classes at the end of each inner learning loop.
- Mechanism: After learning new classes in the inner loop, the model updates its weights using a single example (template) from each previously learned class. This update step ensures the model retains knowledge of earlier classes while adapting to new ones.
- Core assumption: A single gradient update on a stored template is sufficient to maintain performance on previously learned classes without overwriting new learning.
- Evidence anchors:
  - [abstract] "each inner learning loop—where a model 'learns how to learn' new classes—ends with a single gradient update using stored templates from all the classes that the model has already seen (one template per class)."
  - [section] "At the end of the inner loop, a single weight update is performed on a previously seen template from each class, enabling the model to leverage its prior knowledge."
- Break condition: If the stored template becomes outdated or unrepresentative of the class distribution, the single update may not adequately preserve knowledge, leading to forgetting.

### Mechanism 2
- Claim: MAMLCon formulates the continual learning problem itself as a meta-learning task, allowing the model to learn how to continually learn new classes efficiently.
- Mechanism: During training, MAMLCon simulates continual learning scenarios by sequentially training on new classes and performing meta-updates. This meta-learning process optimizes the initial weights to facilitate few-shot continual learning at test time.
- Core assumption: Simulating continual learning scenarios during training prepares the model to handle real-world incremental class additions effectively.
- Evidence anchors:
  - [abstract] "MAMLCon extends MAML by explicitly doing meta-learning of an increasing number of new classes in the inner loop of the algorithm."
  - [section] "Because with MAMLCon the model has seen incremental learning during training, these weights are optimised to facilitate few-shot continual learning."
- Break condition: If the simulated training scenarios do not accurately reflect real-world class addition patterns, the model may not generalize well to actual continual learning tasks.

### Mechanism 3
- Claim: MAMLCon outperforms OML by updating the entire network in the inner loop and allowing access to a single example of a previously seen class during training.
- Mechanism: Unlike OML, which only updates the prediction network and samples random batches for meta-testing, MAMLCon updates the full network and uses stored templates from all seen classes for meta-testing, leading to better retention of knowledge.
- Core assumption: Updating the entire network and using relevant templates provides more effective learning and retention than partial updates and random sampling.
- Evidence anchors:
  - [section] "Our method differs from OML in several ways. Firstly, in the inner loop, we update the entire network and not just the prediction network. Secondly, we allow the model to access a single example of a previously seen class during the inner-loop training phase."
  - [section] "Finally, in contrast to OML, we do not perform the meta-test on a random sample of classes, but instead on all classes seen up to that point."
- Break condition: If the computational cost of updating the entire network is prohibitive, or if stored templates are not representative, the benefits may not outweigh the increased complexity.

## Architecture Onboarding

- Component map:
  - Input Layer: MFCCs with delta and delta-delta features.
  - Feature Extraction: 3-layer 2D convolutional neural network.
  - Classification Layer: Single fully connected layer.
  - Optimizer: Adam optimizer with different learning rates for inner and outer loops.
  - Template Storage: Mechanism to store one example per class for future updates.

- Critical path:
  1. Sample meta-support and meta-test sets from training data.
  2. Sequentially train on new classes in the inner loop.
  3. Perform a single gradient update using stored templates from all seen classes.
  4. Evaluate performance on meta-test set in the outer loop.
  5. Update initial weights based on outer loop performance.

- Design tradeoffs:
  - Storing templates increases memory usage but helps prevent forgetting.
  - Updating the entire network is more computationally expensive than partial updates but may lead to better performance.
  - Using a single example per class for updates is efficient but may be less effective if the example is not representative.

- Failure signatures:
  - Degradation in accuracy on previously learned classes indicates forgetting.
  - Overfitting to new classes if too many gradient steps are taken without incorporating templates.
  - Poor performance if stored templates are not representative of class distributions.

- First 3 experiments:
  1. Implement MAMLCon and verify it performs similarly to MAML on a static few-shot learning task.
  2. Test MAMLCon in a simple continual learning scenario with two class additions, comparing performance to MAML.
  3. Evaluate the impact of varying the number of stored templates (e.g., using more than one example per class) on retention and performance.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal number of shots (K) for MAMLCon to balance between sample complexity and catastrophic forgetting?
- Basis in paper: [explicit] The paper states that "as K increases beyond this point, the weight updates for the new classes may become excessive, resulting in the model forgetting previously learned information."
- Why unresolved: The paper identifies a trade-off but does not determine the exact optimal K value for all scenarios.
- What evidence would resolve it: Systematic experiments varying K across different datasets, word counts, and update frequencies to identify the point where accuracy plateaus or begins to decline.

### Open Question 2
- Question: How does MAMLCon's performance scale with significantly larger vocabulary sizes (e.g., 100+ classes) compared to other continual learning methods?
- Basis in paper: [inferred] The paper tests up to 50 classes but shows accuracy degradation as class count increases, particularly for OML. This suggests potential limitations that need exploration.
- Why unresolved: The paper only tests up to 50 classes, leaving open questions about scalability to real-world applications with much larger vocabularies.
- What evidence would resolve it: Experiments testing MAMLCon on datasets with 100+ classes and comparing its performance degradation rate to baseline methods.

### Open Question 3
- Question: What is the impact of template quality and selection strategy on MAMLCon's performance in continual learning?
- Basis in paper: [explicit] The paper mentions using "a single stored example for each of the 'hello', 'drop', 'greetings' classes" as templates but doesn't explore how template selection affects performance.
- Why unresolved: The paper uses a simple strategy (first example per class) without investigating whether more sophisticated template selection could improve retention.
- What evidence would resolve it: Experiments comparing different template selection strategies (random sampling, exemplar selection, feature-based selection) and their impact on retention of early classes versus later classes.

## Limitations
- The method relies on a single template per class for gradient updates, which may not be sufficient to maintain class knowledge if templates are unrepresentative or the class distribution shifts.
- Evaluation focuses on classification accuracy but does not provide detailed analysis of how performance degrades across different class groups over time.
- Experiments use relatively small datasets (Google Commands and FACC), so scalability and robustness in more complex, larger-scale scenarios remain unclear.

## Confidence
- **High** confidence in the core mechanism of MAMLCon and its improvement over OML in controlled experiments.
- **Medium** confidence in the generalizability of results due to limited dataset size and scope of evaluation metrics.
- **Low** confidence in the long-term stability of the method under realistic continual learning conditions with frequent class additions and potential distribution shifts.

## Next Checks
1. Conduct experiments using multiple templates per class (e.g., 5 or 10) to evaluate whether increasing the number of stored examples per class improves retention and reduces catastrophic forgetting.
2. Perform an ablation study where the single gradient update using stored templates is omitted to quantify the specific contribution of this step to overall performance.
3. Test MAMLCon on a larger-scale dataset with more diverse word classes (e.g., LibriSpeech or a custom dataset) to assess scalability and robustness under more challenging continual learning conditions.
