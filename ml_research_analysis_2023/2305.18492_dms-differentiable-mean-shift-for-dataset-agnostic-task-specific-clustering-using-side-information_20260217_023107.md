# DMS: Differentiable Mean Shift for Dataset Agnostic Task Specific Clustering Using Side Information

## Quick Facts
- arXiv ID: 2305.18492
- Source URL: https://arxiv.org/abs/2305.18492
- Reference count: 40
- Primary result: Introduces DMS, a clustering method that learns from pairwise similarity labels without requiring cluster count or distance metrics, outperforming current methods on both intrinsic and non-intrinsic tasks.

## Executive Summary
DMS (Differentiable Mean Shift) is a novel clustering approach that directly learns pairwise similarity from side information, replacing traditional distance-based mean shift kernels with a neural network. By iteratively finding cluster centers and refining inlier predictions, DMS can cluster the same dataset in multiple ways depending on the provided side information. Experiments demonstrate superior performance on both intrinsic (by class) and non-intrinsic (by other attributes) clustering tasks, with the ability to identify novel, unseen classes at inference time.

## Method Summary
DMS adapts the mean shift algorithm by replacing distance-based kernels with a learnable neural network KD that maps input pairs to similarity scores in [0,1]. The method iteratively updates sample means using KD predictions as weights until convergence, without requiring fixed neighborhood radii or distance thresholds. Training uses a small set of pairwise similarity labels, enabling task-specific clustering without prior knowledge of cluster count or distance metrics. DMS consists of two stages: iterative cluster center finding and refined inlier prediction, followed by assignment of remaining points to the nearest cluster center.

## Key Results
- DMS outperforms current clustering methods on both intrinsic and non-intrinsic dataset tasks
- DMS can identify novel, unseen classes at inference time without requiring all classes during training
- The method demonstrates strong performance with minimal side information (as low as 0.7% of data for some datasets)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The differentiable kernel directly learns similarity instead of relying on distance proxies, allowing flexible and task-specific clustering without prior knowledge of cluster count or distance metrics.
- Mechanism: A neural network KD maps input pairs to a similarity score in [0,1], replacing the flat or Gaussian kernels in classical mean shift. This enables asymmetric treatment of feature dimensions and context-aware similarity evaluation.
- Core assumption: Pairwise similarity labels are sufficient to train a robust similarity kernel that generalizes to unseen classes.
- Evidence anchors:
  - [abstract] "uses a neural network-based similarity kernel to evaluate pairwise similarity directly, rather than using distance as a proxy"
  - [section 3.1] "Instead of using distance as a proxy for similarity we propose a differentiable kernel based on a neural network"
  - [corpus] Weak - no direct mention of kernel learning or similarity-based clustering in neighboring papers.
- Break condition: If pairwise similarity labels are insufficient to capture task-relevant distinctions, the learned kernel may fail to generalize.

### Mechanism 2
- Claim: Iterative cluster center finding with weighted averaging based on inlier confidence replaces the need for fixed neighborhood radii and enables convergence without distance thresholds.
- Mechanism: DMS iteratively updates sample means using KD predictions as weights until consecutive iterations agree on inlier assignments, at which point the center is fixed.
- Core assumption: KD's confidence scores are reliable enough to determine convergence without a distance tolerance.
- Evidence anchors:
  - [section 3.2] "we do not determine convergence by defining a distance tolerance between the centers found in consecutive iterations"
  - [section 3.2] "we use the prediction of inliers given the current and previous sample mean"
  - [corpus] Weak - no explicit discussion of convergence criteria in neighboring works.
- Break condition: If KD predictions are noisy or overconfident, convergence may be premature or oscillate.

### Mechanism 3
- Claim: Training on a small set of pairwise similarity labels enables clustering without requiring all classes to be present, allowing identification of novel, unseen classes at inference time.
- Mechanism: Training instances are built from a positive category, a set of positive and negative samples, and unlabelled data. Loss is computed only on labeled pairs, letting the model learn similarity independent of specific class identities.
- Core assumption: The similarity kernel generalizes across classes not seen during training.
- Evidence anchors:
  - [abstract] "DMS outperforms current methods in both the intrinsic and non-intrinsic dataset tasks"
  - [section 3.3] "The use of side information instead of the specific class label during training allows the clustering network to learn a class independent representation of similarity"
  - [corpus] Weak - neighboring papers do not discuss side-information-based training or generalization to unseen classes.
- Break condition: If the similarity kernel overfits to the training classes, it may fail to recognize new clusters.

## Architecture Onboarding

- Component map: Data points → KD (pairwise similarity network) → iterative mean shift (center finding) → confidence matrix → cluster assignment. Training loop: Generate instances from labeled and unlabeled data → compute BCE loss on labeled pairs → update KD weights.
- Critical path: KD network → iterative center refinement → final cluster assignment. Failure here breaks DMS entirely.
- Design tradeoffs: Concatenation-based KD can capture more information but may overfit; subtraction-based KD generalizes better to unseen classes. Training with fewer iterations risks underfitting; too many iterations may overfit.
- Failure signatures: Low clustering accuracy with high variance; slow or unstable convergence; inability to generalize to new classes.
- First 3 experiments:
  1. Train DMS on MNIST with 5% labeled pairs; evaluate ACC/NMI vs baseline k-means.
  2. Test DMS's ability to cluster COIL100 by object color vs object class (intrinsic vs non-intrinsic task).
  3. Vary number of training iterations in KD; measure effect on convergence speed and clustering quality.
