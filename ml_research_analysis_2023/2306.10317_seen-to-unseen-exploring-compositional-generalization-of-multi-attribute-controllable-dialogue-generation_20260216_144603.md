# Seen to Unseen: Exploring Compositional Generalization of Multi-Attribute Controllable Dialogue Generation

## Quick Facts
- arXiv ID: 2306.10317
- Source URL: https://arxiv.org/abs/2306.10317
- Reference count: 26
- Key outcome: This paper studies compositional generalization for multi-attribute controllable dialogue generation, where models learn from seen attribute values and generalize to unseen combinations. The authors propose a prompt-based disentangled controllable generation model (DCG) that uses attribute-oriented prompts to capture instance-specific control signals and task-oriented prompts to provide global features. A disentanglement loss is introduced to separate desired attribute combinations from others. The authors also design a unified reference-free evaluation framework (MAE) to measure consistency between desired attribute combinations and generated responses. Experiments on two benchmarks show that DCG outperforms existing methods in attribute controllability and text quality, with MAE showing higher correlation with human judgments for evaluation. The paper addresses the challenge of lacking sufficient annotated attribute-specific data and proposes an effective solution for multi-attribute controllable dialogue generation.

## Executive Summary
This paper addresses the challenge of compositional generalization in multi-attribute controllable dialogue generation, where models must learn from seen attribute values and generalize to unseen combinations. The authors propose a prompt-based disentangled controllable generation model (DCG) that uses attribute-oriented prompts for instance-specific control and task-oriented prompts for global features, along with a disentanglement loss to improve generalization. They also introduce a unified reference-free evaluation framework (MAE) that converts attribute evaluation into text-to-text generation tasks. Experiments on DailyDialog and ConvAI2 benchmarks demonstrate that DCG outperforms existing methods in both attribute controllability and text quality, while MAE shows higher correlation with human judgments compared to traditional reference-based metrics.

## Method Summary
The DCG model addresses compositional generalization by learning attribute concept composition through attribute-oriented prompt vectors while using task-oriented prompts for global features. The model generates prompts using a shared MLP layer on concatenated attribute values, rather than learning independent prompts for each value, making it more parameter-efficient. A disentanglement loss is introduced to maximize the likelihood of generating the desired response for the correct attribute combination over pseudo combinations, forcing the model to learn distinct representations for each attribute value and their interactions. For evaluation, the authors propose MAE (Multi-Attribute Evaluation), a unified reference-free framework that converts attribute evaluation into text-to-text generation tasks using T5 with handcrafted templates and trainable continuous prompts to assess controllability across different granularities.

## Key Results
- DCG outperforms existing methods on both DailyDialog-CG and ConvAI2-CG benchmarks in attribute controllability metrics (E-ACC, A-ACC, P-SIM, P-NLI)
- DCG achieves better or comparable text quality (BLEU-1, BLEU-2, METEOR) compared to baseline methods
- MAE evaluation framework shows higher correlation with human judgments than traditional reference-based metrics
- Disentanglement loss significantly improves generalization to unseen attribute combinations
- Prompt-tuning approach with shared MLP is more parameter-efficient than learning independent prompts for each attribute value

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Disentangled prompt embeddings allow the model to learn compositional generalization by separating attribute concepts across combinations.
- **Mechanism:** Attribute-oriented prompts encode instance-specific attribute combinations, while task-oriented prompts provide global features. A disentanglement loss maximizes the likelihood of generating the desired response for the correct attribute combination over pseudo combinations, forcing the model to learn distinct representations for each attribute value and their interactions.
- **Core assumption:** Learning shared prompt embeddings for all instances of the same attribute value enables knowledge transfer from seen to unseen combinations.
- **Evidence anchors:**
  - [abstract]: "learns attribute concept composition by generating attribute-oriented prompt vectors and uses a disentanglement loss to disentangle different attributes for better generalization"
  - [section 4.1.2]: "To force the model to distinguish different combinations of multiple attribute values, we design some pseudo combinations to enhance the diversity of the prompts... maximize the generated likelihood of the desirable positive combination P (r|d, c) against the generated likelihood of pseudo combinations P (r|d, c′)"
  - [corpus]: Weak - no direct evidence, but related works on compositional generalization support this mechanism.
- **Break condition:** If pseudo combinations are not diverse enough or if the disentanglement loss weight is too low, the model may fail to learn distinct attribute representations.

### Mechanism 2
- **Claim:** A unified reference-free evaluation framework (MAE) enables consistent assessment of multi-attribute controllability across different granularities.
- **Mechanism:** MAE converts the evaluation of each attribute into a text-to-text generation task using T5. A template is designed as discrete prompts, and a trainable continuous prompt is added to improve stability and robustness. The probability of generating "yes" corresponding to the [MASK] token is regarded as the controllability score.
- **Core assumption:** The controllability of each attribute can be evaluated independently and then combined to assess the overall multi-attribute controllability.
- **Evidence anchors:**
  - [abstract]: "we design a unified reference-free evaluation framework for multiple attributes with different levels of granularities"
  - [section 5]: "Specifically, the evaluation of each attribute is converted to a text-to-text generation task based on T5 (Raffel et al., 2020) with handcrafted templates"
  - [corpus]: Weak - no direct evidence, but related works on reference-free evaluation support this mechanism.
- **Break condition:** If the handcrafted templates are not appropriate for the attribute being evaluated, or if the continuous prompt is not effective in improving stability, MAE may fail to provide accurate controllability scores.

### Mechanism 3
- **Claim:** Prompt tuning with attribute-oriented prompts is more parameter-efficient and effective than learning independent prompts for each attribute value.
- **Mechanism:** Instead of learning an independent prompt representation for each attribute value (as in CatPrompt), DCG uses a shared MLP layer to generate prompt embeddings from the control codes. This allows the model to learn attribute concepts from seen values and generalize to unseen combinations.
- **Core assumption:** A shared mapping can effectively capture the underlying structure of attribute concepts, enabling knowledge transfer.
- **Evidence anchors:**
  - [abstract]: "learns attribute concept composition by generating attribute-oriented prompt vectors"
  - [section 4.1.1]: "Here, the controlled attribute values are discrete attribute labels in DailyDialog or continuous attribute descriptions in ConvAI2. The multiple attribute values ai,· in the corresponding combination c are simply concatenated as an attribute-oriented prompt sequence"
  - [corpus]: Weak - no direct evidence, but related works on prompt tuning support this mechanism.
- **Break condition:** If the shared mapping is not expressive enough to capture the nuances of different attribute values, or if the attribute combinations are too complex, the model may fail to generalize effectively.

## Foundational Learning

- **Concept:** Compositional generalization
  - **Why needed here:** The paper focuses on multi-attribute controllable dialogue generation, where the model needs to learn from seen attribute values and generalize to unseen combinations. Compositional generalization is the ability of a model to understand and generate new combinations of concepts it has seen separately during training.
  - **Quick check question:** What is the difference between single-attribute and multi-attribute controllable dialogue generation?
- **Concept:** Prompt tuning
  - **Why needed here:** Prompt tuning is used to guide the language model to focus on the controlled information in the dialogue. It involves prepending continuous prompts to the input embeddings of the language model, which can be learned during training.
  - **Quick check question:** How does prompt tuning differ from traditional fine-tuning?

  - **Why needed here:** Disentanglement learning is used to separate different attribute values and their combinations, which helps the model learn distinct representations for each attribute and improve generalization.

## Architecture Onboarding

- **Component map:** Attribute-oriented prompt generation -> Disentanglement loss -> MAE evaluation framework
- **Critical path:** Attribute-oriented prompt generation → Disentanglement loss → MAE evaluation framework

- **Failure signatures:** Poor controllability scores, especially on unseen attribute combinations; low BLEU scores indicating poor text quality; high variance in MAE evaluation scores across different templates.

## Limitations

- The pseudo combination generation method for the disentanglement loss lacks precise specification, which could significantly impact the model's ability to learn distinct attribute representations.
- The MAE evaluation framework relies on handcrafted templates that may not fully capture the nuances of all attribute combinations, limiting its reliability across different attribute types and dialogue domains.
- The paper's focus on two specific datasets (DailyDialog and ConvAI2) may limit the generalizability of the findings to other dialogue domains or attribute types.

## Confidence

**High Confidence:** The core mechanism of using attribute-oriented and task-oriented prompts for compositional generalization is well-supported by the experimental results. The improvements in both attribute controllability and text quality metrics over baseline methods are substantial and consistent across datasets.

**Medium Confidence:** The effectiveness of the disentanglement loss in improving generalization to unseen attribute combinations is supported by the results, but the exact contribution of this component is difficult to isolate from other aspects of the model architecture.

**Low Confidence:** The unified reference-free evaluation framework (MAE) shows promise in correlating with human judgments, but its reliability across different attribute types and dialogue domains remains uncertain without further validation.
