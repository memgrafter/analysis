# Diffusing Graph Attention

## Executive Summary
This paper introduces Graph Diffuser (GD), a method that learns to extract structural and positional relationships between distant nodes in a graph. GD constructs virtual edges by combining information from multiple powers of a learned adjacency matrix and uses these edges to direct attention and node representations in a Transformer architecture. The authors demonstrate that GD can capture long-range interactions that existing GNNs and Graph Transformers struggle with, using a synthetic grid histogram counting task. They evaluate GD on eight benchmarks spanning different domains, showing that it outperforms the state-of-the-art on six of them, including ZINC, OGBG-ppa, ogbg-code2, ogbg-molpcba, Peptides-func, Peptides-struct, and PCQM-Contact, without any hyperparameter tuning.
