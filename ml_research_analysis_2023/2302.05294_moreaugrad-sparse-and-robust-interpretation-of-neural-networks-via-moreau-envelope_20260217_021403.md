# MoreauGrad: Sparse and Robust Interpretation of Neural Networks via Moreau Envelope

## Quick Facts
- arXiv ID: 2302.05294
- Source URL: https://arxiv.org/abs/2302.05294
- Reference count: 40
- Key outcome: MoreauGrad improves gradient-based interpretation robustness and sparsity using Moreau envelope smoothing with L1/L2,1 regularization

## Executive Summary
This paper introduces MoreauGrad, a novel interpretation method for deep neural networks that leverages the Moreau envelope to produce smooth, robust, and sparse saliency maps. The method addresses key limitations of standard gradient-based interpretation techniques by smoothing the classifier's gradient through an optimization problem, making interpretations more stable under input perturbations. MoreauGrad can be efficiently computed using first-order optimization methods and naturally incorporates sparsity-inducing regularization to produce interpretable feature attributions.

## Method Summary
MoreauGrad computes interpretations by taking the gradient of a smoothed version of the classifier's prediction score, where smoothing is achieved through the Moreau envelope. The method introduces two variants: Sparse MoreauGrad using L1-norm regularization and Group-Sparse MoreauGrad using L2,1-norm regularization to produce sparse or structured sparse interpretations. The core optimization problem is solved via gradient descent, with the final interpretation being the gradient of the Moreau envelope with respect to the input. The method is theoretically grounded with proofs showing smoothness and robustness under bounded perturbations when regularization parameters are properly chosen.

## Key Results
- MoreauGrad outperforms standard gradient-based methods in visual quality, sparsity, and robustness on CIFAR-10, Tiny-ImageNet, and ImageNet
- The method achieves state-of-the-art performance in robustness metrics including normalized distance, top-k intersection ratio, and SSIM
- Sparse and Group-Sparse variants successfully produce sparse interpretations while maintaining robustness to input perturbations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MoreauGrad's robustness comes from the Moreau envelope smoothing the classifier's gradient, reducing sensitivity to small input perturbations.
- Mechanism: The Moreau envelope optimization problem smooths the classifier's prediction score function by penalizing distance from the input, ensuring the gradient (MoreauGrad) changes smoothly with input changes.
- Core assumption: The prediction score function is weakly convex and the regularization parameter ρ is chosen small enough to dominate the weakly-convexity degree.
- Evidence anchors:

- Core assumption: The prediction score function is weakly convex and the regularization parameters ρ and η are chosen appropriately.
- Evidence anchors:
