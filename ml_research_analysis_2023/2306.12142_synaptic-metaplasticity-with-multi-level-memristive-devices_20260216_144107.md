# Synaptic metaplasticity with multi-level memristive devices

## Quick Facts
- arXiv ID: 2306.12142
- Source URL: https://arxiv.org/abs/2306.12142
- Reference count: 24
- Primary result: 97% MNIST and 86% Fashion-MNIST accuracy with metaplasticity in QNNs using 16 kbit memristor crossbar

## Executive Summary
This paper presents a solution to catastrophic forgetting in neural networks by extending synaptic metaplasticity from binarized neural networks to quantized neural networks (QNNs) and implementing it on a memristor-based hardware platform. The key innovation is a mixed-precision architecture that stores quantized weights in analog multi-level memristors while handling high-precision metaplastic variables in a digital processing unit. The approach was experimentally validated using a 16 kbit crossbar array fabricated in 130 nm CMOS technology, achieving 97% accuracy on MNIST and 86% on Fashion-MNIST in sequential training while demonstrating resilience to analog device imperfections and achieving a 15× reduction in memory footprint compared to BNN implementations.

## Method Summary
The method extends synaptic metaplasticity from BNNs to QNNs by using a mixed-precision architecture where memristors store quantized weights in analog multi-level fashion while a digital processing unit handles high-precision metaplastic variables. The approach uses a metaplasticity rule that modulates weight updates based on proximity to quantized levels, preventing overwriting of consolidated knowledge. The network was implemented on a 16 kbit crossbar array with 512 neurons per layer, using Adam optimizer and 17 quantization levels in the range [-1.5, 1.5]. The metaplasticity parameter m* was set to 3, and the network was trained sequentially on MNIST (epochs 1-50) followed by Fashion-MNIST (epochs 51-100).

## Key Results
- Achieved 97% accuracy on MNIST and 86% on Fashion-MNIST in sequential training
- Demonstrated immunity to catastrophic forgetting with metaplasticity
- Validated on a 16 kbit crossbar array fabricated in 130 nm CMOS technology
- Achieved 15× memory footprint reduction compared to BNN implementations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The metaplasticity rule modulates weight updates based on proximity to quantized levels, preventing overwriting of consolidated knowledge.
- Mechanism: When a hidden weight is close to a quantized level, the metaplastic function M(WH) decreases, reducing the effective learning rate for that weight. This allows the network to "lock in" previously learned features while still adapting to new tasks.
- Core assumption: The metaplastic function M(WH) = 1 - tanh²(2m* / I_D,i * |WH - WS| - m*) correctly implements the desired proximity-dependent consolidation behavior.
- Evidence anchors:
  - [section]: "The M(WH ) function modulates the strength of the updates: when M(WH ) is low, the hidden weight is consolidated at its current level, while when it is high it is updated according to the stochastic gradient descent learning algorithm"
  - [section]: "In the interval between two adjacent quantized levels, I_D,i = Q_i+1 - Q_i, the metaplastic function is defined as a function of the hidden weight value"
- Break condition: If the metaplastic function doesn't properly capture the desired consolidation behavior, or if the network experiences catastrophic forgetting despite using the function.

### Mechanism 2
- Claim: The mixed-precision architecture separates quantized weights (for inference and forward/backward pass) from high-precision metaplastic variables (for weight updates), enabling both hardware efficiency and learning capability.
- Mechanism: Memristors store quantized weights in analog multi-level fashion for compact storage and efficient matrix-vector multiplication. A digital processing unit handles the high-precision hidden weights and metaplastic variables needed for weight updates, combining the benefits of both analog and digital computation.
- Core assumption: The memristor crossbar array can reliably store and read quantized weights, and the digital unit can perform the necessary high-precision calculations for weight updates.
- Evidence anchors:
  - [section]: "We propose a hardware architecture that integrates quantized weights in memristor devices programmed in an analog multi-level fashion with a digital processing unit for high-precision metaplastic storage"
  - [section]: "Memristors can store intermediate conductance levels, unlike CMOS-based memories (SRAM or DRAM) which store one bit per cell"
- Break condition: If the memristor conductance variability becomes too large to reliably store quantized weights, or if the digital unit cannot keep up with the computational demands of high-precision metaplastic variables.

### Mechanism 3
- Claim: The use of quantized weights in memristors and high-precision hidden weights in digital memory allows the network to achieve good accuracy while reducing memory footprint compared to binarized neural networks.
- Mechanism: By storing quantized weights in multi-level memristors, the network can achieve higher precision than binarized networks without requiring a separate memristor for each bit. The high-precision hidden weights in digital memory allow for fine-grained updates during training.
- Core assumption: The quantization levels chosen for the weights are sufficient to maintain good accuracy while still providing a significant reduction in memory compared to binarized networks.
- Evidence anchors:
  - [abstract]: "The architecture achieves a 15× reduction in memory footprint compared to BNN implementations"
  - [section]: "Since each memristor can be programmed into nine levels (8 HCS levels and 1 LCS level), each weight can be represented by 17 levels, with the 'zero' level obtained by matching the conductance of two memristors in two adjacent cells"
- Break condition: If the chosen quantization levels are too coarse, leading to significant accuracy loss, or if the memory savings are not sufficient to justify the additional complexity of the mixed-precision architecture.

## Architecture Onboarding

- Component map: Input data → Memristor crossbar array (quantized weights) → Digital processing unit (hidden weights/metaplastic variables) → Output

- Critical path:
  1. Forward propagation: Input data → memristor crossbar (matrix-vector multiplication) → output
  2. Backward propagation: Error calculation → gradient computation on quantized weights → hidden weight updates in digital memory
  3. Weight quantization: Hidden weights → quantized weights using Eq. 1 → memristor programming if needed

- Design tradeoffs:
  - Analog vs. digital computation: Analog memristor crossbars offer high density and energy efficiency but are subject to device variability; digital processing provides high precision but requires more area and power.
  - Quantization level: Higher quantization levels allow for better accuracy but require more memristor conductance levels and increase memory usage.
  - Metaplasticity parameters: The choice of m* affects the balance between retaining old knowledge and learning new tasks; finding the optimal value requires experimentation.

- Failure signatures:
  - High memristor conductance variability leading to incorrect quantized weight values
  - Digital processing unit unable to keep up with computational demands of high-precision metaplastic variables
  - Suboptimal choice of quantization levels or metaplasticity parameters resulting in poor accuracy

- First 3 experiments:
  1. Characterize memristor conductance levels and variability to determine achievable quantization levels and expected accuracy.
  2. Implement the metaplasticity rule in software using a simulated memristor crossbar to validate the approach before hardware implementation.
  3. Train the network on MNIST and Fashion-MNIST sequentially with different metaplasticity parameters to find the optimal configuration for the hardware implementation.

## Open Questions the Paper Calls Out

- Question: What is the maximum number of tasks that can be learned sequentially using this metaplasticity approach before performance degradation occurs?
  - Basis in paper: [inferred] The paper demonstrates sequential learning of two tasks (MNIST and Fashion-MNIST) with maintained accuracy, but does not explore limits of scalability to more tasks.
  - Why unresolved: The experimental validation only tested two consecutive tasks. Scaling to more tasks would require additional experiments to determine when catastrophic forgetting reappears or accuracy drops significantly.
  - What evidence would resolve it: Experimental results showing accuracy retention across 3, 5, 10+ sequential tasks would establish the approach's limits and scalability.

- Question: How does the metaplasticity approach perform on more complex network architectures beyond the two-layer perceptron used in this study?
  - Basis in paper: [explicit] The paper states "These results match those obtained using a two-layer BNN with 4096 neurons per layer in previous studies [5]" but does not explore deeper or more complex architectures.
  - Why unresolved: The validation was limited to a simple two-layer perceptron. Modern deep learning applications often require deeper networks with convolutional or recurrent layers.
  - What evidence would resolve it: Training experiments using deeper networks (3+ layers), convolutional neural networks, or recurrent architectures on sequential tasks would demonstrate the approach's applicability to more complex scenarios.

- Question: What is the impact of different memristor technologies (beyond HfO₂) on the performance and efficiency of this metaplasticity implementation?
  - Basis in paper: [explicit] The paper validates the approach using HfO₂ memristors fabricated in 130 nm CMOS technology, but does not compare with other memristor materials or technologies.
  - Why unresolved: Different memristor technologies have varying conductance levels, endurance, variability, and programming characteristics that could affect the approach's performance.
  - What evidence would resolve it: Comparative experiments using different memristor technologies (e.g., TaOₓ, TiO₂, phase-change memory) measuring accuracy, memory footprint, and endurance would reveal which technologies are most suitable for this approach.

## Limitations

- Experimental validation limited to two specific tasks (MNIST and Fashion-MNIST) without testing generalizability to other task pairs
- Only tested on simple two-layer perceptron architecture without exploring deeper or more complex network structures
- Real-world memristor variability and drift over thousands of cycles were not quantified in the experimental validation

## Confidence

- Metaplasticity rule effectiveness on sequential tasks: High
- Hardware implementation feasibility: Medium
- Memory reduction claims: Medium
- Generalization to other tasks/architectures: Low
