# PuMer: Pruning and Merging Tokens for Efficient Vision Language Models

## Quick Facts
- **arXiv ID**: 2305.17530
- **Source URL**: https://arxiv.org/abs/2305.17530
- **Reference count**: 18
- **Key outcome**: PuMer achieves up to 2x speedup and 50% memory reduction with <1% accuracy drop by progressively pruning irrelevant image tokens using text guidance and merging similar tokens within each modality

## Executive Summary
PuMer introduces a framework for efficient vision-language models that reduces token count through text-informed pruning and modality-aware merging. The method leverages cross-attention scores to identify and remove irrelevant image tokens while preserving task-relevant information, then merges similar tokens within each modality to further reduce computation. By scattering lightweight token reducers across cross-modal layers in a cascaded fashion, PuMer achieves significant efficiency gains without requiring learned parameters. Evaluation on ViLT and METER across five vision-language tasks demonstrates substantial speed and memory improvements while maintaining accuracy.

## Method Summary
PuMer implements token reduction through two complementary approaches: text-informed image pruning and modality-aware merging. For pruning, it uses the text-to-image cross-attention scores already computed in VL models to identify and remove image tokens with low relevance to the input text. For merging, it employs bipartite soft matching to find semantically similar tokens within each modality and averages their representations. The token reducers are inserted at multiple cross-modal layers and applied progressively to avoid abrupt information loss. The framework is trained using knowledge distillation to minimize accuracy degradation when tokens are reduced.

## Key Results
- Achieves up to 2x inference speedup and 50% memory reduction across five VL tasks
- Maintains accuracy within 1% of original models while reducing tokens
- Outperforms existing token reduction methods like DynamicViT and ToMe on both efficiency and accuracy metrics

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Text-informed image pruning selectively removes image tokens irrelevant to the input text while preserving task-relevant visual information
- Mechanism: Uses text-to-image cross-attention scores already computed in VL models to calculate text-saliency scores for each image token, then prunes tokens with lowest scores
- Core assumption: Cross-attention scores accurately reflect which image tokens are most relevant to the input text for the task
- Evidence anchors:
  - [abstract] "PuMer learns to keep salient image tokens related to the input text and merges similar textual and visual tokens"
  - [section 4.1] "we take a different but faster approach without using any parameters. The key idea is to use the text-to-image cross-attention scores that are already available in the VL model to compute how important each image token is to the text"
  - [corpus] Weak - neighboring papers focus on different pruning approaches without leveraging cross-attention scores

### Mechanism 2
- Claim: Modality-aware merging reduces redundancy within each modality without mixing text and image representations
- Mechanism: Uses bipartite soft matching to find semantically similar tokens within each modality (image tokens merged with image tokens, text with text) and averages their representations
- Core assumption: Similar tokens within the same modality can be merged without significant information loss
- Evidence anchors:
  - [abstract] "merges similar textual and visual tokens by adding lightweight token reducer modules at several cross-modal layers"
  - [section 4.2] "our method merges semantically similar image tokens Vp into a single image token and similar text tokens T into a single text token to further reduce the number of tokens. We specifically merge tokens within each modality"
  - [corpus] Weak - neighboring papers don't discuss modality-aware merging specifically

### Mechanism 3
- Claim: Cascaded token reduction across multiple layers achieves better accuracy-efficiency tradeoff than single-layer reduction
- Mechanism: Scatters lightweight token reducers across different cross-modal layers, progressively reducing tokens to avoid abrupt information loss
- Core assumption: Gradual reduction is more effective than removing many tokens at once
- Evidence anchors:
  - [abstract] "We scatter the token reducers at different cross-modal layers in the VL model and reduce the tokens in a cascaded fashion"
  - [section 4] "reducing at early layers in the cross-modal encoder will have higher inference efficiency but may have bigger performance loss and vice versa"
  - [corpus] Weak - neighboring papers don't discuss cascaded reduction approaches

## Architecture Onboarding

- Component map: Text tokens → Image tokens → Cross-modal encoder with PuMer token reducers → Reduced token set → Prediction
- Critical path: Text→Image encoding→Cross-modal encoding with token reducers→Prediction
- Design tradeoffs:
  - Early reduction layers: Higher efficiency but larger accuracy loss
  - Late reduction layers: Better accuracy but smaller efficiency gains
  - Aggressive ratios: More reduction but higher risk of information loss
  - Conservative ratios: Less reduction but better preservation of information
- Failure signatures:
  - Accuracy drops >1%: Likely too aggressive pruning/merging or poor reduction layer placement
  - Minimal speedup: Reduction ratios too conservative or reducers in wrong layers
  - Training instability: Distillation loss not properly configured
- First 3 experiments:
  1. Baseline: Run original VL model without any token reduction
  2. Single-layer reduction: Add one token reducer at different cross-modal layers to find optimal placement
  3. Cascaded reduction: Implement 2-3 token reducers with conservative ratios to validate gradual reduction approach

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but several areas remain unexplored. The approach focuses on cross-modal encoders and does not investigate token reduction in vision encoders, which could provide additional efficiency gains for models like ALBEF and X-VLM. The optimal number and placement of token reduction layers is discussed as a tradeoff without a definitive answer. The performance on VL models with region-based features versus patch-based features remains unexplored, leaving uncertainty about generalizability across different architectural paradigms.

## Limitations
- Relies on cross-attention scores as proxies for token relevance without direct validation of this correlation
- Does not thoroughly analyze what types of visual information are lost during token merging operations
- Focuses only on cross-modal encoders, missing potential efficiency gains from reducing tokens in vision encoders
- Does not explore how the approach performs on models with region-based features versus patch-based features

## Confidence

**High Confidence**: The efficiency metrics showing 2x speedup and 50% memory reduction appear well-supported by the experimental results. The cascaded reduction approach and its placement across cross-modal layers is clearly described and implemented.

**Medium Confidence**: The claim of "less than 1% accuracy drop" across all tasks is supported by results but requires more detailed error analysis to understand which types of examples suffer most from token reduction. The effectiveness of modality-aware merging versus mixed-modal merging is plausible but not conclusively proven.

**Low Confidence**: The assumption that cross-attention scores are reliable indicators of token importance lacks direct validation. The claim that non-parametric reducers are sufficient without learned parameters is reasonable but not thoroughly tested against parametric alternatives.

## Next Checks

1. **Cross-Attention Correlation Analysis**: Conduct experiments to directly measure the correlation between cross-attention scores and actual task performance when tokens are pruned. Systematically vary the pruning threshold and measure how well attention scores predict which tokens can be safely removed without affecting accuracy.

2. **Information Loss Quantification**: Implement gradient-based attribution methods to identify which types of visual features (object boundaries, textures, color information, etc.) are most affected by the merging operation. Compare this against token saliency maps to understand what information is being lost.

3. **Ablation of Reduction Layer Placement**: Perform a systematic sweep across different cross-modal layer positions for token reducers, varying both the number of reducers and their placement order. Measure the accuracy-efficiency tradeoff curve to identify if the current placement strategy is truly optimal or if alternative configurations could yield better results.
