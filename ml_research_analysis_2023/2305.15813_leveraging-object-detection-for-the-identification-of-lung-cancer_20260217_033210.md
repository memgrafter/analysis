# Leveraging object detection for the identification of lung cancer

## Quick Facts
- arXiv ID: 2305.15813
- Source URL: https://arxiv.org/abs/2305.15813
- Reference count: 0
- Primary result: YOLOv5 object detection achieved 94% sensitivity and 90.5% specificity for lung cancer lesions in chest X-rays

## Executive Summary
This study applies YOLOv5 object detection to identify lung cancer lesions in chest X-ray images, using a dataset of 1500 annotated images from Kaggle. The model was trained on 1000 images, validated on 300, and tested on 100, with image preprocessing, augmentation, and hyperparameter tuning. YOLOv5 demonstrated high sensitivity (94%), specificity (90.5%), precision (100%), and overall accuracy (91%), achieving real-time computational efficiency suitable for clinical integration. The approach outperformed previous techniques and showed strong performance in detecting malignant regions, offering a promising tool to assist radiologists in early lung cancer diagnosis and improving patient outcomes.

## Method Summary
The study employs YOLOv5s object detection model trained on 1500 chest X-ray images from Kaggle, split into 1000 training, 300 validation, and 100 test images. Images were preprocessed to 416x416 pixels, normalized, and augmented before training for 50 epochs with batch size 32 and learning rate 0.002. The YOLOv5 architecture combines a CSPDarknet backbone with spatial pyramid pooling and PANet neck for multi-scale feature extraction. The model was evaluated using sensitivity, specificity, precision, accuracy, F1 score, and precision-recall metrics.

## Key Results
- YOLOv5 achieved 94% sensitivity and 90.5% specificity in detecting lung cancer lesions
- The model demonstrated 100% precision and 91% overall accuracy
- Real-time computational efficiency was achieved, suitable for clinical integration
- YOLOv5 outperformed previous detection techniques in lung cancer identification
