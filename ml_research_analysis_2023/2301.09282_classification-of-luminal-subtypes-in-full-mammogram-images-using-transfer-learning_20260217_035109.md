# Classification of Luminal Subtypes in Full Mammogram Images Using Transfer Learning

## Quick Facts
- arXiv ID: 2301.09282
- Source URL: https://arxiv.org/abs/2301.09282
- Reference count: 0
- Primary result: Transfer learning from multi-label abnormality classification to luminal subtype classification improves AUC from 0.5358 to 0.6688 and F1 from 0.4987 to 0.6693 (p<0.0001)

## Executive Summary
This paper presents a transfer learning approach for classifying luminal versus non-luminal breast cancer subtypes directly from full mammogram images. The method leverages knowledge from a multi-label multi-class abnormality classification task to improve performance on the more challenging receptor status classification problem. Using a ResNet-18 architecture and the CMMD dataset, the approach demonstrates statistically significant improvements over baseline models trained directly on the target task. The work addresses the practical challenge of using only image-level labels while achieving clinically relevant classification performance.

## Method Summary
The proposed method employs transfer learning from a pre-trained multi-label multi-class abnormality classifier to a binary luminal versus non-luminal subtype classifier. The approach uses a ResNet-18 backbone architecture, leveraging ImageNet pre-training as initialization. The model is trained on the CMMD dataset using image-level labels without requiring pixel-level annotations. The transfer learning strategy involves fine-tuning the pre-trained weights on the target classification task while preserving learned feature representations from the source abnormality classification task. Evaluation metrics include AUC and F1 scores computed on a held-out test set.

## Key Results
- Transfer learning improves mean AUC from 0.5358 to 0.6688 on test data
- Transfer learning improves mean F1 score from 0.4987 to 0.6693 on test data
- Performance improvements are statistically significant (p<0.0001)

## Why This Works (Mechanism)
The transfer learning approach works by leveraging shared visual features between breast abnormalities and luminal subtype characteristics. The pre-trained model has learned to recognize patterns associated with various breast pathologies, which likely overlap with the visual cues distinguishing luminal from non-luminal subtypes. This shared representation space allows the model to start from a more informative initialization than random weights, requiring less data and training time to achieve good performance on the target task.

## Architecture Onboarding

Component map: Input image -> ResNet-18 feature extractor -> Classification head -> Output probabilities

Critical path: Image preprocessing → ResNet-18 backbone → Global average pooling → Fully connected layer → Sigmoid activation → Binary classification output

Design tradeoffs: ResNet-18 chosen for balance between model complexity and computational efficiency versus deeper architectures like ResNet-50; simpler model reduces overfitting risk on limited medical imaging data but may miss subtle subtype-specific features.

Failure signatures: Overfitting indicated by large train-test performance gap; underfitting indicated by uniformly low performance across metrics; class imbalance issues indicated by skewed precision-recall curves.
