# Sensitivity Analysis of RF+clust for Leave-one-problem-out Performance Prediction

## Quick Facts
- arXiv ID: 2305.19375
- Source URL: https://arxiv.org/abs/2305.19375
- Reference count: 26
- Primary result: Weighted RF+clust variants improve predictions when more similar problems are found, but can worsen predictions when important features fail to capture algorithm behavior differences.

## Executive Summary
This paper investigates the sensitivity of the RF+clust method for leave-one-problem-out (LOPO) performance prediction in black-box optimization. The RF+clust approach combines a random forest regression model with a calibration step using algorithm performance on training problems similar to the test problem, measured by cosine similarity. The authors propose two weighted variants of RF+clust that adjust the similarity measure by incorporating feature importance, using either unsupervised clustering or permutation-based methods. Empirical evaluation on the CEC 2014 benchmark suite shows that the weighted RF+clust variants improve predictions for problems where more or new similar problems are found compared to the original approach. However, for some problems, the proposed methods lead to worse predictions, indicating that even the most important features may not be expressive enough to distinguish problems with significantly different algorithm behavior. The results suggest that using feature importance as weights can enhance RF+clust performance, but more robust problem representations are needed to capture the relationship between the problem and performance spaces.

## Method Summary
The paper evaluates two weighted variants of RF+clust that incorporate feature importance into the similarity measure for LOPO performance prediction. The method uses the CEC 2014 benchmark suite with 30 problems, 3 Differential Evolution configurations, and 64 ELA features. Feature selection removes highly correlated features using Pearson correlation threshold of 0.9 and RF-based selection. The weighted cosine similarity is calculated using either unsupervised clustering-based feature importance or permutation feature importance. Models are trained in a 30-fold LOPO setting and performance is measured using Mean Absolute Error (MAE) of predicted log10-transformed median precision values.

## Key Results
- Weighted RF+clust variants improve predictions for problems where more similar problems are found compared to uniform weighting
- For some problems, weighted approaches lead to worse predictions when important features fail to capture algorithm behavior differences
- Permutation feature importance provides more stable weights across folds compared to unsupervised clustering method
- Using uncorrelated features slightly degrades performance compared to using all features but reduces overfitting risk

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using feature importance weights in the similarity measure improves the identification of truly similar problems for calibration.
- Mechanism: The weighted cosine similarity prioritizes features that are more predictive of algorithm performance, leading to better matching of problems with similar algorithm behavior.
- Core assumption: Features with higher importance for performance prediction are also more relevant for distinguishing between problems with different algorithm behavior.
- Evidence anchors:
  - [abstract] "the authors propose two weighted variants of RF+clust that adjust the similarity measure by incorporating feature importance"
  - [section] "We evaluate the performance of two weighted RF+clust variants that incorporate feature importance in the similarity measure as weights."
  - [corpus] Weak evidence - no direct citations in related papers, but the concept aligns with general feature importance literature.
- Break condition: If the most important features are not expressive enough to capture differences in algorithm behavior, the weighted approach may perform worse than uniform weighting.

### Mechanism 2
- Claim: The permutation feature importance method provides more stable weights across folds compared to the unsupervised clustering method.
- Mechanism: Permutation feature importance measures the drop in model performance when features are randomly shuffled, providing a more consistent estimate of feature relevance across different training sets.
- Core assumption: The relationship between features and performance is stable enough that shuffling provides a meaningful importance measure.
- Evidence anchors:
  - [abstract] "we consider a weighted distance measure, with weights depending on the relevance of the feature for the regression model."
  - [section] "The permutation feature importance, perm, is defined to be the amount by which a model's performance drops when single feature values are randomly shuffled"
  - [corpus] Weak evidence - no direct citations, but permutation importance is a well-established method in ML literature.
- Break condition: If the relationship between features and performance is highly non-linear or unstable across folds, permutation importance may not provide consistent weights.

### Mechanism 3
- Claim: The RF+clust approach can improve predictions for problems where no similar problems were found using uniform weighting.
- Mechanism: By adjusting the similarity measure with feature importance, previously dissimilar problems can become similar, allowing for better calibration of predictions.
- Core assumption: Problems that appear dissimilar under uniform weighting may be similar when considering only the most relevant features.
- Evidence anchors:
  - [abstract] "However, for some problems, the proposed methods lead to worse predictions, indicating that even the most important features may not be expressive enough to distinguish problems with significantly different algorithm behavior."
  - [section] "For the 18th and 25th problems and similarity threshold 0.5 we seem to detect five similar problems...with weighted cosine similarity and improve the model performance prediction quite a lot"
  - [corpus] Weak evidence - no direct citations, but aligns with general concepts of feature selection in ML.
- Break condition: If the feature importance does not correlate with actual algorithm behavior differences, the approach may introduce noise rather than improve predictions.

## Open Questions the Paper Calls Out

- Concept: Sensitivity of weighted similarity methods to feature importance calculation
  - Why needed here: The paper shows that the choice between unsupervised clustering and permutation methods affects the number of similar problems identified and prediction accuracy, but doesn't systematically analyze which method works better for which problem types
  - Open question: How does the choice of feature importance method (unsupervised clustering vs. permutation) impact the performance of RF+clust across different problem classes in black-box optimization?
  - What evidence would resolve it: A comprehensive study analyzing the performance of both methods across diverse problem classes and correlating results with problem characteristics

- Concept: Alternative similarity measures beyond weighted cosine similarity
  - Why needed here: The paper acknowledges that even the most important features may not be expressive enough to distinguish problems with significantly different algorithm behavior
  - Open question: Can alternative similarity measures or distance metrics in the feature space further improve the performance of RF+clust for LOPO prediction?
  - What evidence would resolve it: An empirical comparison of RF+clust performance using various similarity measures across diverse problem classes and algorithm portfolios

- Concept: Impact of different feature selection strategies
  - Why needed here: The paper uses uncorrelated features but notes that the selected feature portfolio varies for different algorithms and folds
  - Open question: How does the selection of feature portfolios (e.g., using all features vs. uncorrelated features) impact the performance of RF+clust and its weighted variants for LOPO prediction?
  - What evidence would resolve it: A comprehensive study comparing the performance of RF+clust and its weighted variants using various feature selection strategies across diverse algorithm portfolios and problem classes

## Limitations
- Performance improvements are highly problem-dependent, with weighted approaches sometimes worsening predictions
- Evaluation restricted to CEC 2014 benchmark suite, limiting generalizability to other problem domains
- No comparative analysis with alternative performance prediction methods like transfer learning approaches

## Confidence
- Medium: Empirical results are well-documented and mechanisms are theoretically sound, but variability across problems and lack of comparative analysis limits confidence in relative effectiveness
