# Defect detection using weakly supervised learning

## Quick Facts
- arXiv ID: 2303.15092
- Source URL: https://arxiv.org/abs/2303.15092
- Reference count: 24
- Primary result: Weakly supervised method achieves 93.42% accuracy with only 30% labeled data, approaching supervised performance (91.5% with 100% labeled data)

## Executive Summary
This paper addresses defect detection in industrial components using weakly supervised learning, specifically a PU (positive-unlabeled) learning framework. The proposed method significantly reduces labeling requirements by training with only a small fraction of labeled positive (non-defective) samples while using unlabeled data to construct a counter-example class. Using a pre-trained VGG16 feature extractor, Isolation Forest for anomaly scoring, and another VGG16 for binary classification, the approach achieves state-of-the-art results on ball screw surface images. The method demonstrates that weakly supervised learning can approach supervised-level performance while dramatically reducing labeling effort.

## Method Summary
The proposed method employs a two-stage approach based on PU learning for defect detection. First, a feature extractor (pre-trained VGG16) extracts image features from the dataset. These features are then used by an Isolation Forest to score and rank the unlabeled data, creating a pseudo-negative class. Finally, a binary classifier (another VGG16) is trained using the labeled positive samples and the ranked unlabeled data as the negative class. The method is evaluated on the BSD dataset containing 21,835 images of ball screw surfaces, comparing performance across different labeling ratios (100%, 30%, and 5% labeled data).

## Key Results
- With 100% labeled data, supervised model achieves 91.5% accuracy
- With only 30% labeled data, weakly supervised method reaches 93.42% accuracy
- With just 5% labeled data, method achieves 80.35% accuracy
- Weakly supervised approach outperforms fully supervised baseline when using only 30% labeled data

## Why This Works (Mechanism)
The PU learning framework works by leveraging the assumption that unlabeled data contains mostly negative examples (defects), allowing the model to learn from both labeled positives and unlabeled data without requiring extensive manual labeling. The Isolation Forest effectively identifies anomalous (defective) samples by isolating observations through random partitioning, creating a reliable ranking of potential defects. This ranking enables the construction of a pseudo-negative class that, combined with the limited labeled positive samples, allows effective binary classification with minimal supervision.

## Foundational Learning
- **PU Learning**: Why needed - enables training with limited labeled data by leveraging unlabeled examples; Quick check - verify unlabeled data contains mostly negative examples
- **Isolation Forest**: Why needed - creates anomaly scores to rank unlabeled data for pseudo-negative class construction; Quick check - ensure forest depth and tree count are sufficient for anomaly detection
- **Transfer Learning**: Why needed - pre-trained VGG16 provides strong feature extraction without requiring large labeled datasets; Quick check - verify feature extractor captures relevant defect characteristics
- **Binary Classification**: Why needed - final decision boundary between defective and non-defective classes; Quick check - validate classifier performance on held-out validation set

## Architecture Onboarding

**Component Map:**
Pre-trained VGG16 -> Feature Extraction -> Isolation Forest -> Anomaly Scoring -> Ranked Unlabeled Data -> VGG16 Classifier -> Binary Classification Output

**Critical Path:**
Feature extraction (VGG16) → Isolation Forest anomaly scoring → Binary classification (VGG16) → Defect detection output

**Design Tradeoffs:**
The approach trades potential accuracy loss from using unlabeled data as pseudo-negatives against significant reduction in labeling effort. Using pre-trained VGG16 avoids training from scratch but may limit adaptation to domain-specific defect patterns. Isolation Forest provides fast anomaly detection but may struggle with subtle defects or complex defect distributions.

**Failure Signatures:**
Poor performance may manifest as high false positive rates (non-defects flagged as defects) or high false negative rates (defects missed). These failures could stem from incorrect assumptions about unlabeled data composition, insufficient feature extraction capability, or inadequate anomaly scoring thresholds.

## Limitations
- Experimental validation limited to single dataset (BSD) of ball screw surfaces, limiting generalizability
- Assumes all unlabeled data contains defects, which may not hold in real-world scenarios
- Comparison methodology may favor weakly supervised approach due to different data utilization (full dataset vs. subset)

## Confidence

**High confidence**: Experimental methodology is sound and PU learning framework is appropriately applied
**Medium confidence**: Reported accuracy improvements are likely valid for this specific dataset and defect type
**Medium confidence**: Claim that weakly supervised learning can approach supervised-level performance with reduced labeling effort is supported but may not generalize broadly

## Next Checks
