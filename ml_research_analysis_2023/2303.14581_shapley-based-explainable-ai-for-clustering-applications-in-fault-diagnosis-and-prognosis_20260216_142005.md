# Shapley-based Explainable AI for Clustering Applications in Fault Diagnosis and Prognosis

## Quick Facts
- arXiv ID: 2303.14581
- Source URL: https://arxiv.org/abs/2303.14581

## Executive Summary
This paper presents a novel Shapley-based explainable AI framework for semi-supervised fault diagnosis and prognosis in manufacturing. The method addresses challenges of class imbalance and weakly labeled datasets by using SHAP or Monte Carlo-based Shapley value analysis to transform feature spaces, followed by UMAP dimensionality reduction and HDBSCAN clustering. Applied to two industrial case studies—a semiconductor manufacturing heatmap dataset and a turbofan engine prognostics benchmark—the approach significantly improves clustering quality over purely unsupervised methods, producing clusters with high-precision decision rules (precision > 0.85 for 12 out of 16 clusters) based on original feature values.

## Method Summary
The framework combines Shapley value analysis with dimensionality reduction and clustering to create explainable fault diagnosis systems. It transforms input features using SHAP values to capture feature importance, applies UMAP for dimensionality reduction, and uses HDBSCAN for clustering. The method leverages weakly labeled data to guide the feature transformation process, enabling the creation of interpretable clusters with decision rules based on original feature values. This semi-supervised approach addresses class imbalance issues common in manufacturing datasets while maintaining explainability through transparent feature attribution.

## Key Results
- Framework significantly improves clustering quality over purely unsupervised methods
- Achieves high-precision decision rules (precision > 0.85 for 12 out of 16 clusters)
- Successfully applied to both semiconductor manufacturing heatmap data and turbofan engine prognostics

## Why This Works (Mechanism)
The Shapley-based approach works by transforming feature spaces to emphasize diagnostically relevant patterns while maintaining interpretability. By using SHAP values to weight features, the method captures feature importance in fault conditions, which guides the clustering process toward meaningful groupings. The combination of UMAP dimensionality reduction preserves local and global structure in the transformed space, while HDBSCAN's density-based approach naturally handles clusters of varying densities and noise. This creates clusters that align with actual fault patterns while producing interpretable decision rules based on original feature values.

## Foundational Learning
- **Shapley Values**: Measure feature importance by quantifying each feature's contribution to model predictions across all possible feature combinations. Needed to transform features based on their diagnostic relevance. Quick check: Verify SHAP values align with domain expert knowledge of fault signatures.
- **UMAP Dimensionality Reduction**: Preserves both local and global structure while reducing dimensions for clustering. Needed to maintain meaningful relationships in high-dimensional manufacturing data. Quick check: Validate UMAP preserves known fault patterns in reduced space.
- **HDBSCAN Clustering**: Density-based clustering that handles varying cluster densities and noise. Needed for robust clustering in industrial datasets with mixed signal qualities. Quick check: Test clustering stability across different density thresholds.

## Architecture Onboarding

**Component Map**: Raw Data -> SHAP Transformation -> UMAP Reduction -> HDBSCAN Clustering -> Decision Rules

**Critical Path**: The SHAP transformation to clustering pipeline represents the critical path, as feature importance directly influences cluster formation and subsequent decision rule quality.

**Design Tradeoffs**: The framework trades computational complexity (SHAP calculation) for improved clustering interpretability and quality. Alternative approaches might use simpler feature selection but would sacrifice the nuanced understanding of feature contributions.

**Failure Signatures**: Poor SHAP value stability in high-dimensional spaces may lead to unstable clusters. UMAP parameter sensitivity can create inconsistent dimensionality reduction. HDBSCAN may fail to identify meaningful clusters if density parameters are poorly chosen.

## Limitations
- Reliance on weakly labeled data quality assumes labels are sufficiently informative for feature transformation
- SHAP-based feature transformation introduces computational overhead and potential instability in high-dimensional spaces
- Clustering evaluation metrics may not fully capture real-world diagnostic accuracy
- Precision values reported lack detailed error analysis or false positive/negative breakdowns
