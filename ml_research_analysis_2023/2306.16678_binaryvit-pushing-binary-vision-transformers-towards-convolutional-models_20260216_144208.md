# BinaryViT: Pushing Binary Vision Transformers Towards Convolutional Models

## Quick Facts
- arXiv ID: 2306.16678
- Source URL: https://arxiv.org/abs/2306.16678
- Reference count: 40
- Key outcome: BinaryViT achieves 67.7% top-1 accuracy on ImageNet-1k, competitive with state-of-the-art binary CNN models while maintaining similar parameter and operation counts.

## Executive Summary
This work addresses the accuracy gap between binary vision transformers (ViTs) and binary convolutional neural networks (CNNs) on large-scale classification tasks like ImageNet-1k. The authors analyze that pure ViTs lack architectural properties present in CNNs that enhance the representational capability of binary networks. To bridge this gap, they propose BinaryViT, which incorporates CNN-inspired operations into a pure ViT architecture without using convolutions. These include replacing token pooling with global average pooling, adding multi-branch average pooling layers, introducing affine transformations before residual connections, and adopting a pyramid structure. Experiments show that BinaryViT achieves 67.7% top-1 accuracy on ImageNet-1k, competitive with state-of-the-art binary CNN models, while maintaining similar parameter and operation counts.

## Method Summary
The method involves designing a baseline binary ViT using DeiT-S architecture with existing binarization techniques, then incorporating four key architectural modifications inspired by CNNs: global average pooling replacing token pooling, multi-branch average pooling blocks, affine transformations before residual connections, and a 4-stage pyramid structure. The model is trained on ImageNet-1k using Adam optimizer for 300 epochs with batch size 512, learning rate 5e-4, and cosine decay scheduler, using knowledge distillation from full-precision DeiT-S as teacher model.

## Key Results
- BinaryViT achieves 67.7% top-1 accuracy on ImageNet-1k
- The proposed architecture maintains similar parameter and operation counts as baseline binary ViT
- Global average pooling increases representational capability by up to 196× compared to token pooling
- BinaryViT achieves competitive performance with state-of-the-art binary CNN models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BinaryViT improves representational capability by replacing token pooling with global average pooling.
- Mechanism: Token pooling only considers the [CLS] token, while global average pooling aggregates information from all tokens/patches, increasing the element-wise representational capability by up to 196×.
- Core assumption: Binary transformers have limited representational capability per token compared to full-precision models.
- Evidence anchors:
  - [abstract]: "these include an average pooling layer instead of a token pooling layer"
  - [section]: "Using a single cls-token pooling layer prevents the information from all tokens from being taken into account."
  - [corpus]: Weak - corpus papers focus on hybrid architectures but don't directly address pooling mechanisms in binary transformers.
- Break condition: If the global average pooling layer causes excessive information loss or computational overhead that outweighs the representational benefits.

### Mechanism 2
- Claim: Multi-branch average pooling compensates for the limited representational capability of binary fully connected layers.
- Mechanism: By adding 4 average pooling branches with different kernel sizes (1×3, 3×1, 1×5, 5×1), the model increases representational capability without significantly increasing parameters or operations.
- Core assumption: Binary convolutions have higher representational capability than binary fully connected layers with equivalent parameters.
- Evidence anchors:
  - [abstract]: "a block that contains multiple average pooling branches"
  - [section]: "inspired by [43], we decided to add 4 branches right beside each FFN block"
  - [corpus]: Weak - corpus papers mention hybrid architectures but don't specifically address multi-branch pooling in binary transformers.
- Break condition: If the multi-branch structure introduces too much computational complexity or if the representational gains don't translate to accuracy improvements.

### Mechanism 3
- Claim: Affine transformations before residual connections prevent information loss in deeper layers.
- Mechanism: Adding scaling factors (α1, α2) and bias terms (β1, β2) before residual connections prevents the scale of main branches from overwhelming residual branches.
- Core assumption: In pre-norm architectures, the scale of hidden states grows with depth, potentially causing information loss.
- Evidence anchors:
  - [abstract]: "an affine transformation right before the addition of each main residual connection"
  - [section]: "networks tested for binarization problems... tend to have a batch-normalization layer right before being added by a residual connection"
  - [corpus]: Weak - corpus papers discuss normalization in transformers but don't specifically address affine transformations in binary networks.
- Break condition: If the affine transformations introduce instability during training or if the representational gains are negligible.

## Limitations

- The paper lacks comprehensive ablation studies to isolate the contribution of each architectural modification to the final 67.7% accuracy.
- The analysis of representational capability improvements is somewhat speculative without concrete measurements of information retention or loss.
- The study does not explore the performance of BinaryViT on other large-scale datasets or downstream tasks beyond image classification.

## Confidence

- **High Confidence**: The overall framework of incorporating CNN-inspired architectural properties into binary ViTs is well-founded, given the extensive prior work on binary networks and hybrid architectures.
- **Medium Confidence**: The individual mechanisms proposed (global average pooling, multi-branch pooling, affine transformations) have theoretical justification and are inspired by successful practices in related architectures.
- **Low Confidence**: The claim that BinaryViT achieves competitive performance with state-of-the-art binary CNN models without extensive ablation studies or comparisons to other binary ViT approaches.
