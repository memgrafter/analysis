# Probabilistic Neural Data Fusion for Learning from an Arbitrary Number of Multi-fidelity Data Sets

## Quick Facts
- arXiv ID: 2301.13271
- Source URL: https://arxiv.org/abs/2301.13271
- Reference count: 40
- Primary result: Pro-NDF outperforms existing neural network approaches and matches state-of-the-art Gaussian process methods for multi-fidelity modeling while providing improved scalability to high dimensions and large data sets.

## Executive Summary
This paper introduces Pro-NDF, a probabilistic neural network architecture for multi-fidelity modeling from an arbitrary number of data sources. The key innovation is converting multi-fidelity modeling into a nonlinear manifold learning problem by mapping a categorical source indicator variable to a low-dimensional probabilistic latent space. This enables the network to learn and visualize the relative accuracy of different sources without requiring hierarchical relationships. The architecture consists of three blocks: a Bayesian NN that learns the fidelity manifold, a deterministic NN that learns a categorical manifold, and a deterministic NN with probabilistic output that maps numerical inputs and latent variables to a parametric distribution. Pro-NDF outperforms existing neural network approaches and matches the performance of state-of-the-art Gaussian process methods while providing improved scalability to high dimensions and large data sets.

## Method Summary
Pro-NDF uses a three-block neural network architecture where the first block is a Bayesian NN mapping source indicators to a 2D fidelity manifold, the second block (optional) is a deterministic NN mapping categorical inputs to a 2D manifold, and the third block is a deterministic NN with probabilistic output. The architecture learns source relationships in a visualizable manifold without requiring hierarchical relationships. Training uses a custom loss function combining negative log-likelihood, KL divergence, interval score, and L2 regularization terms. The Bayesian treatment in the first block enables uncertainty quantification while maintaining computational efficiency.

## Key Results
- Pro-NDF outperforms existing neural network approaches on multi-fidelity benchmark problems
- Performance matches state-of-the-art Gaussian process methods (LMGP) while providing better scalability
- The learned fidelity manifold provides interpretable visualization of source accuracy relationships
- Pro-NDF handles an arbitrary number of data sources without requiring hierarchical relationships

## Why This Works (Mechanism)

### Mechanism 1
Converting multi-fidelity modeling into a nonlinear manifold learning problem enables joint fusion of arbitrary numbers of data sources without requiring hierarchical relationships. By appending a categorical source indicator variable to all data and mapping it through a Bayesian neural network to a low-dimensional probabilistic latent space, the architecture learns relative distances that encode source accuracy relationships. Sources producing similar outputs are encoded close together in the manifold.

### Mechanism 2
Making Block 1 and the final output probabilistic enables quantification of both epistemic and aleatoric uncertainties while allowing the use of proper scoring rules in training. The Bayesian neural network in Block 1 learns a distribution over latent fidelity representations, capturing uncertainty about source relationships. The probabilistic output captures aleatoric uncertainty in predictions. This dual probabilistic treatment allows the loss function to incorporate interval score, which rewards accurate prediction intervals.

### Mechanism 3
The custom loss function combining negative log-likelihood, KL divergence, and interval score improves robustness and accuracy on unseen high-fidelity data. The multi-task loss balances fitting the data (NLL), keeping the posterior close to the prior (KL), and producing well-calibrated prediction intervals (IS). This prevents overfitting on small, unbalanced data while ensuring uncertainty quantification quality.

  - Why needed here: The core innovation converts multi-fidelity modeling to manifold learning, requiring understanding how categorical variables can be mapped to continuous latent spaces
  - Quick check question: How does the Euclidean distance in the latent space relate to the correlation between data sources in the original space?

- Concept: Proper scoring rules and uncertainty quantification
  - Why needed here: The interval score term in the loss function requires understanding how to evaluate probabilistic predictions and why proper scoring rules are important for calibration
  - Quick check question: Why is interval score a "strictly proper" scoring rule, and what advantage does this provide over other evaluation metrics?

## Architecture Onboarding

- Component map: Source indicator → Block 1 (Bayesian NN) → latent fidelity representation → Block 3 (deterministic NN with probabilistic output)
- Critical path: The fidelity manifold learned in Block 1 is the key innovation that enables multi-fidelity fusion
- Design tradeoffs:
  - Probabilistic vs deterministic: Only Block 1 is Bayesian to reduce computational cost while still capturing source uncertainty
  - Manifold dimension: Fixed at 2 for visualization and to prevent overfitting on small data
  - Loss function complexity: Multi-term loss balances multiple objectives but requires careful hyperparameter tuning
- Failure signatures:
  - Wide distributions in fidelity manifold → insufficient data or poor fit to relationships
  - All sources clustered at same point → network failed to learn source distinctions
  - Poor HF prediction despite good manifold → Block 3 not properly leveraging learned relationships
- First 3 experiments:
  1. Train on Rational problem with 5 HF samples and 3 LF sources to verify basic functionality
  2. Compare learned fidelity manifold against known source relationships in Wing-weight problem
  3. Test ablation study by removing LIS term from loss and measuring impact on uncertainty quantification

## Open Questions the Paper Calls Out

### Open Question 1
How do Pro-NDF's probabilistic fidelity manifolds directly relate to correlation measures between data sources? The paper notes that the learned distances in the manifold do not directly link correlation between sources, but observes that Pro-NDF and LMGP's manifolds look similar without establishing a direct mathematical relationship.

### Open Question 2
What is the optimal iterative approach for automatically identifying and excluding inaccurate low-fidelity sources using Pro-NDF's fidelity manifold? The paper acknowledges the iterative approach is inefficient and suggests developing an automated mechanism but does not provide such a mechanism.

### Open Question 3
How does the performance of Pro-NDF scale with increasing numbers of data sources compared to LMGP? While the paper compares Pro-NDF and LMGP on problems with 3-5 data sources, it does not systematically explore how their relative performance changes as the number of sources increases beyond this range.

## Limitations
- The approach assumes source relationships can be meaningfully represented in a 2D continuous manifold, which may not hold for complex source dependencies
- Performance degrades when high-fidelity data is too scarce relative to low-fidelity data or when there are very inaccurate low-fidelity sources
- The fixed architecture hyperparameters (2D manifold, layer sizes) may not be optimal across diverse domains and are presented as reasonable choices rather than rigorously optimized decisions

## Confidence

- **High confidence** in the core mechanism: Converting multi-fidelity modeling to manifold learning is well-grounded in existing literature and the mathematical formulation is sound
- **Medium confidence** in specific architectural choices: The three-block design is justified but fixed dimensionality of 2 and specific layer sizes are reasonable choices rather than rigorously optimized decisions
- **Low confidence** in scalability claims: The paper states improved scalability to high dimensions and large datasets, but only tests on problems with relatively modest input dimensions (up to 20) and sample sizes

## Next Checks

1. **Ablation study validation**: Systematically remove each component (Bayesian block, interval score term, categorical manifold block) and test performance degradation across all four benchmark problems to identify which innovations drive improvements.

2. **Scalability stress test**: Evaluate Pro-NDF on a high-dimensional problem (d > 50) with large sample sizes (n > 10,000) to verify computational efficiency claims and assess whether the Bayesian block becomes a bottleneck.

3. **Source relationship complexity test**: Construct a synthetic problem where source relationships require >2 dimensions to represent accurately, then measure Pro-NDF's performance degradation compared to problems where 2D representation suffices.
