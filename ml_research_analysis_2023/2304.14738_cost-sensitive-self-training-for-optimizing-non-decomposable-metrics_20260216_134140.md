# Cost-Sensitive Self-Training for Optimizing Non-Decomposable Metrics

## Quick Facts
- arXiv ID: 2304.14738
- Source URL: https://arxiv.org/abs/2304.14738
- Reference count: 40
- Primary result: CSST framework improves non-decomposable metrics in semi-supervised learning

## Executive Summary
This paper introduces a Cost-Sensitive Self-Training (CSST) framework for optimizing non-decomposable metrics in semi-supervised learning scenarios with limited labeled data. The authors extend traditional self-training by incorporating weighted consistency regularization and novel thresholding mechanisms specifically designed for non-decomposable metrics like worst-case recall and coverage constraints. CSST is applied to practical methods such as FixMatch and UDA, demonstrating significant performance gains across various datasets and tasks while maintaining competitive accuracy levels.

## Method Summary
CSST extends self-training by introducing a weighted consistency regularizer that accounts for the specific non-decomposable metric's gain matrix, ensuring more stringent regularization for classes important to the target metric. The framework employs a KL-divergence based thresholding mechanism to select unlabeled samples based on their alignment with the desired metric rather than confidence alone. A hybrid loss function combining logit adjustment and loss re-weighting ensures calibration for the given gain matrix, crucial for optimizing complex metrics like worst-case recall.

## Key Results
- CSST achieves improvements over state-of-the-art methods across multiple datasets and objectives
- KL-based thresholding plays a major role in improving performance over supervised learning for non-diagonal gain matrices
- The framework maintains competitive accuracy while optimizing non-decomposable metrics

## Why This Works (Mechanism)

### Mechanism 1
- Claim: CSST improves non-decomposable metrics by leveraging unlabeled data through weighted consistency regularization
- Mechanism: Weighted consistency regularizer accounts for the specific non-decomposable metric's gain matrix, applying more stringent regularization to important classes
- Core assumption: Similar data distributions between labeled and unlabeled data
- Evidence anchors: Abstract shows improvement over state-of-the-art; section 3.3 proves better performance under similar assumptions
- Break condition: If unlabeled data distribution significantly differs from labeled data

### Mechanism 2
- Claim: KL-based thresholding improves non-decomposable metrics by better sample selection
- Mechanism: Uses KL divergence between model prediction and optimal distribution defined by gain matrix instead of confidence
- Core assumption: Gain matrix accurately reflects relative importance of different classes
- Evidence anchors: Section 4 proposes KL-divergence thresholding; section 5 shows major role in improving performance
- Break condition: If gain matrix is diagonal, benefit is minimal

### Mechanism 3
- Claim: Logit-adjusted loss functions are calibrated for non-decomposable metrics
- Mechanism: Hybrid loss combines logit adjustment and loss re-weighting to ensure Bayes-optimal classifier
- Core assumption: Model output can approximate optimal distribution for given gain matrix
- Evidence anchors: Section 2.2 introduces calibrated loss functions; section 2.1 proves hybrid loss is calibrated
- Break condition: If model output cannot approximate optimal distribution

## Architecture Onboarding

- Component map: Pseudo-labeler -> Weighted consistency regularizer -> KL-thresholding mechanism -> Loss function

- Critical path:
  1. Train initial model on labeled data
  2. Generate pseudo-labels for unlabeled data
  3. Apply weighted consistency regularizer between augmentations
  4. Use KL-based thresholding to select samples
  5. Update model using combined loss function

- Design tradeoffs:
  - Gain matrix choice determines target metric but may require tuning
  - KL-thresholding is computationally more expensive than confidence-based
  - Weighted regularizer may need more unlabeled data to be effective

- Failure signatures:
  - Overfitting to unlabeled data if distributions differ significantly
  - Optimizing wrong metric if gain matrix not well-calibrated
  - Under/over-utilization of unlabeled data if threshold improperly set

- First 3 experiments:
  1. Implement CSST on CIFAR-10 with diagonal gain matrix for worst-case recall vs vanilla self-training
  2. Test different KL-thresholding thresholds on their impact to target metric
  3. Apply CSST to non-diagonal gain matrix dataset for recall under coverage constraints vs baselines

## Limitations
- Assumes similar data distributions between labeled and unlabeled data
- Cannot handle non-decomposable metrics that aren't linear combinations of confusion matrix entries
- Implementation details for weighted consistency regularization not fully specified
