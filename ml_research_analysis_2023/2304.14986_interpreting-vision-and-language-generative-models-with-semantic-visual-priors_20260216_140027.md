# Interpreting Vision and Language Generative Models with Semantic Visual Priors

## Quick Facts
- arXiv ID: 2304.14986
- Source URL: https://arxiv.org/abs/2304.14986
- Reference count: 8
- Key outcome: A framework generating global, sentence-level visual explanations for vision-to-text generative models, addressing limitations of token-by-token explanations in computational cost and semantic expressiveness.

## Executive Summary
This paper addresses the challenge of interpreting vision-to-text generative models, particularly image captioning systems, by proposing a framework for generating sentence-level visual explanations. Traditional approaches using token-by-token explanations are computationally expensive and lack comprehensive semantic understanding. The authors introduce a method that leverages SHAP values with semantic priors extracted through Deep Feature Factorization (DFF), enabling more efficient and semantically meaningful attributions. The framework is evaluated against traditional superpixel-based methods, demonstrating superior performance in both semantic expressiveness and computational efficiency, validated through human evaluation.

## Method Summary
The framework generates sentence-level visual explanations by computing Shapley values over semantic features extracted from the visual backbone using Deep Feature Factorization (DFF). The method uses semantic embeddings to measure caption meaning variations under image perturbations, aggregates these across the full caption context, and prioritizes high-weight coalitions during KernelSHAP sampling to improve estimation accuracy. The approach is modular and can adapt to various visual backbones and explainability methods, with an alternative option to use STEGO for semantic feature extraction when DFF is not applicable.

## Key Results
- Sentence-level explanations capture semantic coherence better than token-level explanations
- DFF produces semantically meaningful visual features by clustering model activations into interpretable regions
- Sampling coalitions by decreasing KernelSHAP weight order yields more accurate Shapley value estimates with fewer model evaluations

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Sentence-level explanations capture semantic coherence better than token-level explanations in vision-to-text generative models.
- **Mechanism:** By measuring semantic variation of the entire generated caption using cosine distance between reference and perturbed caption embeddings, the method aggregates visual importance across the full linguistic context rather than decomposing it into individual token contributions.
- **Core assumption:** The semantic meaning of a caption can be adequately represented as a single embedding vector whose perturbations reflect meaningful changes in model grounding.
- **Evidence anchors:**
  - [abstract] "leverage the meaning representation of the output sequence as a whole"
  - [section 3.2] "we measure variations of the caption meaning representation when perturbations are applied to the image"
  - [corpus] Weak: no direct citation; inference based on semantic similarity frameworks.
- **Break condition:** If caption embeddings fail to capture global semantic meaning (e.g., due to polysemy or context-dependent meaning), the sentence-level attribution will be misleading.

### Mechanism 2
- **Claim:** Deep Feature Factorization (DFF) produces semantically meaningful visual features by clustering model activations into interpretable regions.
- **Mechanism:** NMF on the last CNN layer activations factorizes the feature space into components (heatmaps) that correspond to semantically coherent image regions, which then serve as interpretable input features for Shapley value computation.
- **Core assumption:** The visual backbone's learned activations encode semantically meaningful concepts that can be factorized into interpretable clusters.
- **Evidence anchors:**
  - [section 3.3] "DFF is an unsupervised method allowing concept discovery from the feature space of CNN-based models"
  - [section 4.4.1] "features 1, 2, and 8 can be associated with three main semantic objects and entities of the image, namely face, glass and shirt"
  - [corpus] Weak: limited direct evidence; relies on Collins et al. (2018) citation.
- **Break condition:** If the visual backbone does not learn meaningful semantic abstractions, DFF will produce uninterpretable or noisy features.

### Mechanism 3
- **Claim:** Sampling coalitions by decreasing KernelSHAP weight order yields more accurate Shapley value estimates with fewer model evaluations.
- **Mechanism:** Prioritizing high-weight coalitions during Monte Carlo sampling ensures that the most influential feature interactions are evaluated first, reducing estimation variance compared to random sampling.
- **Core assumption:** Coalition weights computed by the KernelSHAP formula are good proxies for the importance of evaluating those coalitions.
- **Evidence anchors:**
  - [section 3.1.1] "we prioritize the high-weight coalitions, whose weight is computed by Eq. 2, when applying a certain sampling budget"
  - [Figure 2] Shows MSE reduction for high-weight priority sampling vs. Monte Carlo
  - [corpus] Weak: no external validation; method is internally motivated.
- **Break condition:** If coalition weights poorly correlate with Shapley value sensitivity, prioritization will not improve accuracy.

  - Why needed here: Enables sentence-level explanations by quantifying caption meaning change through cosine distance between embeddings.

## Architecture Onboarding

- **Component map:** Vision backbone (CNN/ViT/FRCNN) → Activation tensor extraction → DFF or segmentation → Binary feature masks → Image perturbation pipeline → Caption generation → Caption embedding → Cosine distance computation → KernelSHAP sampling → Shapley value attribution → Visualization
- **Critical path:** Vision backbone → Feature extraction → SHAP computation → Attribution visualization
- **Design tradeoffs:**
  - DFF vs superpixels: semantic coherence vs computational simplicity
  - Sentence-level vs token-level: global coherence vs fine-grained grounding
  - Number of features: computational cost vs semantic detail
- **Failure signatures:**
  - Noisy or uninformative heatmaps from DFF → poor semantic feature quality
  - High MSE between estimated and full Shapley values → insufficient sampling budget
  - Inconsistent attributions across similar images → embedding instability
- **First 3 experiments:**
  1. Validate DFF feature quality by visualizing activation heatmaps and checking for semantic coherence.
  2. Compare sentence-level vs token-level explanations on a small dataset for qualitative assessment.
  3. Benchmark KernelSHAP sampling with priority vs random sampling on a fixed compute budget.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What are the limitations of using STEGO for semantic feature extraction in the proposed framework?
- Basis in paper: [explicit] The authors mention that STEGO can be used as an alternative for semantic feature extraction when the visual backbone does not permit an application of bottom-up, unsupervised methods such as DFF. However, they also note that STEGO does not necessarily reflect the visual priors of the V&L model itself.
- Why unresolved: The paper does not provide a detailed analysis of the limitations of using STEGO, such as its computational cost, the quality of the extracted features, or its performance compared to DFF.
- What evidence would resolve it: A comprehensive evaluation of STEGO's performance in terms of computational cost, feature quality, and comparison with DFF on a variety of V&L tasks and models would provide insights into its limitations.

## Limitations

- Semantic embedding-based explanation framework assumes caption embeddings adequately capture semantic meaning changes, but this assumption lacks thorough validation
- DFF method's performance depends heavily on quality of semantic concepts learned by visual backbone, which may not transfer across different architectures
- Human evaluation involved only 14 AI researchers, limiting statistical power and potential bias assessment

## Confidence

- **High confidence**: Sentence-level explanations reduce computational cost compared to token-level methods (mechanistically sound and directly measured)
- **Medium confidence**: Semantic expressiveness of explanations is superior (supported by human evaluation but limited sample size)
- **Low confidence**: Generalizability to other vision-language tasks beyond image captioning (not empirically validated)
