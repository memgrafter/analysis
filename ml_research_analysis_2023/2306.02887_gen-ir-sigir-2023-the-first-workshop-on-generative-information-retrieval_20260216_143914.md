# Gen-IR @ SIGIR 2023: The First Workshop on Generative Information Retrieval

## Quick Facts
- arXiv ID: 2306.02887
- Source URL: https://arxiv.org/abs/2306.02887
- Reference count: 30
- The first workshop on Generative Information Retrieval (Gen-IR) was held at SIGIR 2023, bringing together researchers to explore whether end-to-end generative models represent a paradigm change for information retrieval

## Executive Summary
The Gen-IR workshop at SIGIR 2023 marked the first dedicated forum for exploring generative approaches to information retrieval. The event aimed to investigate whether end-to-end generative models represent a fundamental shift in IR paradigms by convening researchers from multiple communities. The workshop featured an interactive format with panels, poster sessions, and breakout discussions organized around four key pillars: model architecture, training, evaluation, and applications. While focusing on established techniques like document retrieval and grounded answer generation, the workshop also explored generative IR applications in new domains.

## Method Summary
The workshop employed an interactive format designed to foster cross-community collaboration and discussion. The day-long event was structured around multiple sessions featuring panel discussions, poster presentations, and breakout groups. The organizers compiled relevant literature and assembled a program committee to guide the workshop's direction. Four thematic pillars—model architecture, training, evaluation, and applications—served as organizing principles for the discussions and activities. The format encouraged both formal presentations and informal exchanges between academic and industry researchers interested in generative IR approaches.

## Architecture Onboarding
Component map: Data Preprocessing -> Model Architecture -> Training Pipeline -> Evaluation Framework -> Application Layer
Critical path: The training pipeline represents the most critical component, as it directly determines model capabilities and generalization to new domains. The evaluation framework is equally critical for establishing whether generative approaches outperform traditional IR methods.
Design tradeoffs: End-to-end generative models sacrifice interpretability and computational efficiency for potentially more natural responses, while traditional retrieve-then-generate approaches offer better control but may produce less coherent outputs. The choice depends on application requirements for accuracy, latency, and user experience.
Failure signatures: Common failures include hallucination of non-existent information, inability to handle rare queries, computational resource constraints, and degradation of performance on long-tail queries. These manifest as either completely fabricated responses or complete failure to generate relevant content.

2. Evaluate hallucination rates by checking factual consistency against source documents
3. Measure computational efficiency (latency, memory usage) for different model sizes and inference strategies
