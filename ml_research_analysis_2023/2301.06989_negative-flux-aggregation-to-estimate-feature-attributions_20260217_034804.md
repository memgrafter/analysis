# Negative Flux Aggregation to Estimate Feature Attributions

## Quick Facts
- arXiv ID: 2301.06989
- Source URL: https://arxiv.org/abs/2301.06989
- Reference count: 6
- Primary result: NeFLAG outperforms baseline attribution methods on ImageNet using deletion and insertion scores

## Executive Summary
This paper proposes Negative Flux Aggregation (NeFLAG), a novel method for interpreting deep neural network predictions by reformulating gradient accumulation as divergence and applying the divergence theorem. The key innovation eliminates the need for path integration by converting volume integration of second-order gradients to surface integration of first-order gradients. The method efficiently approximates feature attributions using only first-order gradient information on a sphere surface around the input, providing both qualitative and quantitative improvements over baseline methods on ImageNet.

## Method Summary
NeFLAG reformulates gradient accumulation as divergence and uses the divergence theorem to convert volume integration of second-order gradients to surface integration of first-order gradients. This allows efficient approximation of feature attributions without path integration. The method aggregates negative fluxes on an N-dimensional sphere around the input point, where negative fluxes represent the direction towards the decision boundary. The algorithm uses a recurrence relation to find local minima on the sphere surface and aggregates the corresponding gradient vectors to create attribution maps.

## Key Results
- NeFLAG achieves superior deletion and insertion scores compared to baseline methods on ImageNet
- The method provides qualitatively better attribution maps across various DNN architectures including InceptionV3, ResNet152, and VGG19
- Computational efficiency is demonstrated by eliminating the need for path integration and second-order gradient computations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Negative Flux Aggregation eliminates the need for path integration by converting volume integration of second-order gradients into surface integration of first-order gradients.
- Mechanism: The divergence theorem transforms the volume integral of divergence (requiring second-order gradients) into a surface integral of flux (requiring only first-order gradients). By reformulating gradient accumulation as divergence, NeFLAG efficiently approximates feature attributions using only first-order gradient information.
- Core assumption: The DNN's gradient field is continuously differentiable within a small neighborhood around the input point.
- Evidence anchors: The abstract states the reformulation converts volume integration of second-order gradients to surface integration of first-order gradients.
- Break condition: Non-differentiable points within the analysis neighborhood prevent divergence theorem application.

### Mechanism 2
- Claim: Negative fluxes provide more interpretable information than positive fluxes for DNN interpretation.
- Mechanism: Positive fluxes point outward representing confidence gain, while negative fluxes point inward representing confidence loss. For a given input predicted as class A, negative fluxes indicate what would make the prediction less likely to be A, providing interpretable information about the decision boundary.
- Core assumption: Negative gradient directions provide more meaningful interpretation for understanding predictions.
- Evidence anchors: The paper explains that negative fluxes represent confidence loss of the prediction.
- Break condition: If interpretation goals focus on supporting evidence rather than opposing factors, positive fluxes may be more informative.

### Mechanism 3
- Claim: The approximation algorithm efficiently finds points with negative fluxes by leveraging local DNN behavior.
- Mechanism: Since DNNs are locally smooth near the input, the algorithm uses a recurrence relation to find local minima on the sphere surface. The approximation f(x̃) - f(x) ≈ ϵ · F(x̃) · n̂ allows identification of negative flux points by finding points where f(x̃) < f(x).
- Core assumption: DNN outputs are locally smooth enough that points with lower function values guarantee negative flux.
- Evidence anchors: The paper discusses using local smoothness to approximate the gradient for negative flux detection.
- Break condition: Highly non-convex local behavior or uncertain predictions make negative flux detection unreliable.

## Architecture Onboarding

- Component map: Input preprocessing -> Gradient computation module -> Sphere sampling module -> Flux evaluation module -> Vector aggregation module -> Output visualization

- Critical path:
  1. Receive input x and target class
  2. Compute f(x) for the target class
  3. Sample n points on the ϵ-sphere around x
  4. For each point, use the recurrence relation to find local minima
  5. Evaluate which points have negative flux (f(x̃) < f(x))
  6. Aggregate the gradient vectors at these points using element-wise product
  7. Generate attribution heatmap from the aggregated vector

- Design tradeoffs:
  - ϵ radius vs accuracy: Smaller ϵ provides better local approximation but may miss some negative flux points; larger ϵ covers more area but may include non-local behavior
  - Number of samples n vs computational cost: More samples provide better coverage of the sphere but increase computation linearly
  - Sphere vs other shapes: Sphere ensures symmetry in the approximation, but other shapes might capture different aspects of local behavior

- Failure signatures:
  - Sparse or noisy attribution maps: May indicate too small ϵ radius or insufficient number of samples
  - Attribution maps focusing on background: May indicate the DNN has learned spurious correlations or the input is uncertain
  - Computational instability: May occur if the DNN has very sharp gradients or the ϵ-sphere intersects non-differentiable regions

- First 3 experiments:
  1. Implement the basic NeFLAG algorithm with a single negative flux sample (n=1) on a simple linear model to verify it recovers the weight vector
  2. Test the approximation algorithm on a small DNN (e.g., 2-layer MLP) with known decision boundaries to validate the negative flux detection
  3. Compare NeFLAG attribution maps with Integrated Gradients on a pre-trained CNN using a simple dataset (e.g., MNIST) to observe qualitative differences

## Limitations

- The method relies heavily on the assumption of local smoothness around input points, which may not hold for networks with sharp decision boundaries
- Critical hyperparameters (sphere radius ϵ and number of samples n) lack systematic guidelines for optimal selection across different architectures and tasks
- The superiority of negative fluxes over positive fluxes depends on interpretation goals and may vary across applications
