# Reference-based Image Composition with Sketch via Structure-aware Diffusion Model

## Quick Facts
- arXiv ID: 2304.09748
- Source URL: https://arxiv.org/abs/2304.09748
- Reference count: 19
- Primary result: Structure-aware diffusion model enabling fine-grained editing with sketch and reference image guidance, achieving FID of 5.716

## Executive Summary
This paper introduces a structure-aware diffusion model that enables fine-grained image editing by incorporating sketches alongside reference images. The method fine-tunes a pre-trained diffusion model to complete missing regions using reference images while maintaining sketch guidance. A novel sketch plug-and-drop strategy is employed during inference to relax sketch guidance when needed, offering flexibility for complex structures. The model demonstrates superior performance compared to baseline methods in reference-based image composition tasks.

## Method Summary
The method fine-tunes a pre-trained latent diffusion model (Stable Diffusion) using self-supervised training with random masks and reference image crops. It encodes sketches as binary edge maps and reference images through a CLIP image encoder with an MLP transformation. The model is trained for 40 epochs using AdamW optimizer with a learning rate of 1e-5. During inference, a sketch plug-and-drop strategy adjusts the infusion steps of sketch conditions to relax overly constrained guidance. A self-reference generation strategy is also employed when suitable reference images are difficult to obtain.

## Key Results
- Achieves superior performance with FID of 5.716 and L1/L2 errors of 0.0680 and 0.2393, respectively
- Enables fine-grained editing of arbitrary scenes with user-driven modifications
- Demonstrates effectiveness in background scene editing, object shape editing, and object changes

## Why This Works (Mechanism)

### Mechanism 1
The model accurately edits specific image regions using sketch guidance and reference images by fine-tuning a pre-trained diffusion model. The pre-trained model's general image generation capabilities are adapted for region-specific editing through appropriate conditioning with sketches and reference images.

### Mechanism 2
The sketch plug-and-drop strategy improves generation quality by allowing flexibility in sketch guidance during inference. By adjusting the time-step of sketch conditions, the model can relax overly constrained guidance when dealing with complex structures like clouds.

### Mechanism 3
The self-reference generation strategy helps when suitable reference images are difficult to obtain by using certain parts of the initial image as alternative references. This maintains visual consistency with the masked part while simplifying the reference image acquisition process.

## Architecture Onboarding

- Component map: Pre-trained diffusion model -> Sketch encoder (binary edge map) -> Reference image encoder (CLIP + MLP) -> Mask generator -> Fine-tuning module -> Sketch plug-and-drop strategy
- Critical path: 1) Initialize with pre-trained Paint-by-Example weights, 2) Generate random mask and reference crop, 3) Encode sketch and reference image, 4) Concatenate masked image with conditions, 5) Pass through diffusion model, 6) Apply sketch plug-and-drop strategy during inference
- Design tradeoffs: Using pre-trained weights accelerates convergence but may limit learning new editing styles; sketch plug-and-drop adds flexibility but may reduce structural control; self-reference generation simplifies process but may not always provide suitable references
- Failure signatures: Poor quality when sketch and reference content are incompatible; loss of structural control when plug-and-drop is over-applied; visible artifacts at edited region boundaries
- First 3 experiments: 1) Test simple shape completion with basic sketch and reference, 2) Evaluate sketch plug-and-drop strategy for complex structures like clouds, 3) Assess self-reference generation by editing specific object parts using initial image crops

## Open Questions the Paper Calls Out

### Open Question 1
How does the model perform when using sketches with varying levels of detail or abstraction? The paper mentions difficulties with overly simplified sketches but lacks extensive experiments on varying sketch complexity.

### Open Question 2
Can the model be extended to handle more complex editing tasks like changing character poses or expressions in cartoon scenes? The paper focuses on simpler editing tasks without exploring more complex scenarios.

### Open Question 3
How does the model's performance compare to other image editing techniques when dealing with real-world images or non-cartoon content? The paper only demonstrates results on cartoon scenes without exploring real-world image applicability.

## Limitations

- Requires substantial computational resources for fine-tuning pre-trained diffusion models
- Effectiveness of sketch plug-and-drop strategy varies significantly with sketch quality and complexity
- Self-reference generation strategy may not work well for all object types or when initial image lacks suitable reference regions

## Confidence

- High confidence in overall framework design and ability to combine sketch guidance with reference images
- Medium confidence in effectiveness of sketch plug-and-drop strategy due to reliance on empirical observations
- Medium confidence in self-reference generation strategy due to dependence on initial image content availability
