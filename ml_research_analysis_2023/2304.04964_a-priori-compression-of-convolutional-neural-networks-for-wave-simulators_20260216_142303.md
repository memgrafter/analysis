# A priori compression of convolutional neural networks for wave simulators

## Quick Facts
- arXiv ID: 2304.04964
- Source URL: https://arxiv.org/abs/2304.04964
- Reference count: 3
- One-line primary result: Proposed a priori decomposition of convolutional kernels reduces trainable parameters from 7 million to 1 million while maintaining equivalent performance on 2D wave equation FE data.

## Executive Summary
This paper introduces a novel approach for compressing convolutional neural networks by performing a priori decomposition of convolutional kernels before training. The method replaces traditional 3-way or 2-way convolutional kernels with sequential one-way filters using Canonical Polyadic Decomposition (CPD). Applied to physical data from a 2D wave equation finite element model, the approach demonstrates equivalent performance to classical convolutional layers while significantly reducing the number of trainable parameters from 7 million to 1 million.

## Method Summary
The method performs a priori decomposition of convolutional kernels using Canonical Polyadic Decomposition (CPD) via Singular Value Decomposition (SVD). Instead of computing decomposition on already trained CNN weights, the network is constructed from decomposed layers from the start. The approach replaces d-way convolutions with sequential 1D convolutions separated by reshape/transpose operations. Weight sharing across models predicting related physical fields further reduces parameters. The method is validated on 2D wave equation FE model outputs with 100 training samples and 25 test samples.

## Key Results
- Classical approach requires 7 million parameters while decomposed approach needs only 1 million parameters
- Achieved equivalent performance measured by relative error over time and space grids
- Weight sharing across coupled models reduces first-layer parameters by half while predicting different physical fields

## Why This Works (Mechanism)

### Mechanism 1
Replacing 3-way/2-way convolutional kernels with one-way filters reduces trainable parameters while preserving performance. CPD decomposes high-dimensional kernels into rank-one tensors represented by one-way filters, transforming d-way convolution into d sequential 1D convolutions. Core assumption: original kernel information can be approximated by low-rank decomposition of one-way filters. Break condition: if CPD rank is too low, approximation error becomes large, degrading performance.

### Mechanism 2
A priori decomposition during model construction avoids post-hoc compression overhead and overfitting. The model is built from decomposed layers from the start, so gradients flow through factorized representation directly, learning decomposed components end-to-end. Core assumption: dimensional separability of problem allows learning separable factors rather than joint high-dimensional weights. Break condition: if problem is not dimensionally separable, decomposition fails to capture interactions between dimensions.

### Mechanism 3
Weight sharing across models predicting related physical fields reduces parameters and improves generalization. Multiple models share initial layers (Ns), each model's final layers (Nd, Nv) specialize for their output. Gradients from all outputs update shared weights, reducing redundancy. Core assumption: different outputs share useful low-level features from same input parameters. Break condition: if outputs require very different feature representations, shared layers become a bottleneck.

  - Why needed here: Practical method to compute CPD rank-one components for each kernel before training

- Concept: Backpropagation through factorized layers
  - Why needed here: Ensures gradients update decomposed components correctly during training
  - Quick check question: In a two-layer decomposition (temporal then spatial), through which intermediate tensor do gradients flow back to original kernel?

## Architecture Onboarding

- Component map:
  Input (3D tensor) -> Decomposed conv layers (1D convs with reshape/transpose) -> Optional BatchNorm/Euler regularization -> Output (predicted physical field)

- Critical path:
  1. Load FE-generated data (p, U(p))
  2. Preprocess: scaling, reshape to 3D
  3. Forward pass through decomposed conv layers
  4. Compute loss (MSE + optional regularization)
  5. Backprop through decomposed path
  6. Update parameters (Adam optimizer)

- Design tradeoffs:
  - More CPD rank → better accuracy, more parameters
  - Fewer epochs + high LR → risk of poor convergence without BatchNorm
  - Weight sharing → fewer params but potential bottleneck for dissimilar outputs

- Failure signatures:
  - High training loss but low test loss → overfitting, reduce model size
  - High loss on both → poor decomposition rank or wrong CPD rank choice
  - Slow convergence → learning rate too high/low, missing BatchNorm

- First 3 experiments:
  1. Baseline: 3D conv layer (no decomposition) on full dataset, measure params vs accuracy
  2. Decomposed 2.5D model (temporal 1D + spatial 1D) with rank=1, compare params vs baseline
  3. Shared-layer variant predicting displacement & velocity, measure parameter reduction and generalization

## Open Questions the Paper Calls Out

### Open Question 1
How does the proposed a priori compression technique scale to higher-dimensional tensor data (e.g., 4D or 5D)? The paper mentions the method can be applied to higher-dimensional tensor data since complexity is linearly dependent on dimension, but provides no experimental evidence or theoretical analysis. Unresolved because only 2D wave equation data is validated. Would require experimental results on higher-dimensional data like 3D medical imaging or 4D climate data.

### Open Question 2
What is the impact of the choice of singular values used in the decomposition on accuracy and efficiency of compressed models? The paper mentions decomposition can be performed using different numbers of singular values but doesn't analyze how this choice affects performance. Unresolved because the paper doesn't explore the trade-off between accuracy and efficiency when choosing singular values. Would require systematic study of impact on accuracy and efficiency including trade-off analysis.

### Open Question 3
How does the proposed method compare to other compression techniques like quantization or pruning in terms of accuracy, efficiency, and computational complexity? The paper mentions other compression techniques but doesn't provide direct comparison with the proposed method. Unresolved because no comprehensive comparison with state-of-the-art compression techniques is provided. Would require comparative study with quantitative analysis of accuracy, efficiency, and computational complexity.

## Limitations
- Specific discretization parameters (Nx, Ny, Nt, spatial/temporal domains, wave speed) for 2D wave equation are not provided, critical for exact reproduction
- Exact network architectures for all model variants are not fully specified, making direct comparison challenging
- Corpus analysis revealed no related work on CPD or tensor decomposition for CNN compression, suggesting novel approach without direct literature validation

## Confidence

- **High Confidence:** The core mechanism of a priori kernel decomposition using CPD is well-explained and theoretically sound
- **Medium Confidence:** The claim of achieving equivalent performance with significantly fewer parameters (7 million to 1 million) is supported by paper's results but lacks detailed architectural specifications for independent verification
- **Low Confidence:** The generalization of the approach to other physical data and wave simulators beyond the specific 2D wave equation case is not demonstrated or discussed
