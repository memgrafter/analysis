# Lightweight Machine Learning for Digital Cross-Link Interference Cancellation with RF Chain Characteristics in Flexible Duplex MIMO Systems

## Quick Facts
- arXiv ID: 2304.11559
- Source URL: https://arxiv.org/abs/2304.11559
- Reference count: 13
- Primary result: ML-based CLI cancellers achieve up to 35.9 dB improvement with 62.2% reduced computational complexity versus polynomial approaches

## Executive Summary
This paper addresses cross-link interference (CLI) cancellation in flexible duplex MIMO systems by incorporating realistic radio frequency (RF) chain characteristics into channel modeling. The authors propose a hardware-dependent channel model that accounts for RF chain nonlinearities (IQ mixer gain/phase imbalance and PA nonlinearity) and develop three digital CLI cancellers: a polynomial canceller (PC), a neural network canceller (NNC), and a hybrid canceller (HC). The lightweight ML-based cancellers (NNC and HC) achieve significant computational complexity reduction (over 62.2%) while maintaining or improving CLI cancellation performance compared to the PC approach.

## Method Summary
The paper establishes a realistic BS-to-BS MIMO channel model that incorporates RF chain characteristics, including PA nonlinearity modeled via a parallel Hammerstein model and IQ mixer effects. Three digital CLI cancellers are introduced: a polynomial canceller that estimates polynomial coefficients, a neural network canceller using a feedforward neural network to learn nonlinear mappings, and a hybrid canceller that combines traditional linear cancellation with ML-based nonlinear component estimation. Training data is collected via backhaul coordination between BSs, enabling the ML models to learn the interference characteristics.

## Key Results
- ML-based cancellers (NNC and HC) achieve up to 35.9 dB CLI cancellation improvement over PC
- Computational complexity reduced by over 62.2% compared to polynomial cancellers
- Hybrid canceller (HC) achieves highest cancellation performance with lowest complexity by separating linear and nonlinear interference components
- Channel model incorporating RF chain nonlinearity significantly improves cancellation accuracy versus linear models

## Why This Works (Mechanism)

### Mechanism 1
Incorporating RF chain nonlinearity into the channel model significantly improves CLI cancellation performance. The realistic BS-to-BS channel model accounts for IQ mixer gain/phase imbalance and PA nonlinearity via parallel Hammerstein model, capturing hardware-dependent distortions that linear models miss.

Core assumption: RF chain nonlinearities significantly impact CLI and can be effectively modeled
Break condition: If RF chain nonlinearities are negligible or PA model parameters cannot be accurately estimated

### Mechanism 2
Lightweight ML-based cancellers achieve better CLI cancellation with dramatically reduced computational complexity. The feedforward neural network learns complex nonlinear relationships without explicit polynomial expansion, reducing parameter count and operations while maintaining or improving performance.

Core assumption: ML model can effectively approximate nonlinear channel behavior without explicit polynomial expansion
Break condition: If FNN cannot adequately learn the nonlinear mapping or training data quality is poor

### Mechanism 3
Hybrid canceller achieves highest CLI cancellation performance by separately handling linear and nonlinear components. HC first uses traditional cancellation to estimate linear part, then applies ML to estimate only the residual nonlinear part.

Core assumption: Linear and nonlinear components can be effectively separated and processed differently
Break condition: If linear component estimation is inaccurate or nonlinear component is too small to effectively train ML model

## Architecture Onboarding

- Component map: BS antennas -> RF chain model -> Channel model -> CLI cancellers (PC/NNC/HC) -> Interference subtraction

- Critical path:
  1. Model RF chain characteristics in channel model
  2. Generate training data via backhaul coordination
  3. Train NNC or HC during offline phase
  4. Deploy trained models for real-time interference cancellation
  5. Subtract estimated interference from received signal

- Design tradeoffs:
  - Model complexity vs. computational efficiency: More detailed RF models improve accuracy but increase complexity
  - Training data quality vs. performance: Better training data leads to more accurate ML models
  - Generalization vs. specialization: Models trained on specific hardware may not generalize well to different RF chains

- Failure signatures:
  - Poor cancellation performance: Indicates inaccurate channel modeling or insufficient ML training
  - High computational load: Suggests polynomial order is too high or ML model is too complex
  - Training instability: Points to inadequate data normalization or inappropriate learning rates

- First 3 experiments:
  1. Compare PC cancellation performance vs. polynomial order P to identify optimal tradeoff
  2. Evaluate NNC performance sensitivity to number of hidden nodes and training epochs
  3. Test HC performance when linear component estimation error varies

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of the proposed lightweight ML-based CLI cancellers scale with increasing numbers of BSs and antennas in large-scale MIMO systems? The paper only simulates a simple 2-BS scenario and does not investigate performance and complexity trade-offs as the system scales up.

### Open Question 2
What is the impact of imperfect CSI on the performance of the proposed channel model and CLI cancellers? The paper assumes ideal CSI is available but does not address performance under CSI errors.

### Open Question 3
How do the proposed CLI cancellers perform under different RF chain non-idealities beyond PA nonlinearity, such as IQ imbalance and memory effects? The paper incorporates PA nonlinearity but assumes ideal IQ mixer and other RF components.

## Limitations

- Performance claims are based on specific parameter settings that may not generalize optimally across different system configurations
- Backhaul-based training data collection introduces coordination overhead that may not be practical in all deployment scenarios
- Computational complexity comparisons assume ideal hardware implementations that may vary significantly with actual processing platforms

## Confidence

**High Confidence**: Incorporating RF chain nonlinearity improves CLI cancellation (Mechanism 1); lightweight ML approaches achieve reduced computational complexity (Mechanism 2)

**Medium Confidence**: Hybrid canceller's superior performance (Mechanism 3); specific performance numbers (35.9 dB improvement)

## Next Checks

1. **Hardware-in-the-loop validation**: Implement the proposed cancellers on actual RF hardware to verify that performance gains observed in simulations translate to real-world conditions with hardware imperfections.

2. **Parameter sensitivity analysis**: Conduct systematic sweep of polynomial order P, hidden nodes Nh, and nonlinearity order α to establish performance/complexity tradeoffs across full parameter space.

3. **Generalization testing**: Evaluate cancellers across different RF chain configurations (different PA models, varying gain/phase imbalances) to assess robustness and identify limits of proposed channel model's applicability.
