# AI Coach Assist: An Automated Approach for Call Recommendation in Contact Centers for Agent Coaching

## Quick Facts
- arXiv ID: 2305.17619
- Source URL: https://arxiv.org/abs/2305.17619
- Reference count: 11
- Key outcome: DialogLED model achieves 70.52% accuracy and 67.92% precision on real-world dataset for identifying coachable calls

## Executive Summary
This paper presents AI Coach Assist, a system that uses transformer-based models to recommend calls to contact center managers for agent coaching. The system determines whether a call is coachable or not by analyzing call transcripts and QA questions using pre-trained language models. By leveraging DialogLED, which can process long text sequences up to 1024 tokens, the system outperforms general-purpose models like DistilBERT. The approach aims to improve the coaching process by recommending calls most relevant for coaching, ultimately enhancing agent performance and customer satisfaction.

## Method Summary
The method fine-tunes pre-trained transformer models (DialogLED and DistilBERT) on a QA Scorecard dataset containing customer-agent call conversation transcripts and annotations. The input consists of concatenated question and transcript sequences for text classification. Models are evaluated on their ability to predict whether a call is coachable or not, using precision, recall, F1, and accuracy metrics. The DialogLED model's ability to process longer sequences (up to 1024 tokens) provides an advantage over models with standard 512-token limits.

## Key Results
- DialogLED achieves 70.52% accuracy and 67.92% precision on the test set
- DialogLED outperforms DistilBERT baseline (66.25% accuracy, 62.53% precision)
- Performance drops significantly when input sequence length is reduced from 1024 to 512 or 256 tokens
- Query-transcript concatenation is essential for model performance
