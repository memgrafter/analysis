# TriDet: Temporal Action Detection with Relative Boundary Modeling

## Executive Summary
This paper introduces TriDet, a one-stage temporal action detection framework that addresses the problem of imprecise boundary predictions in videos, which often suffer from ambiguous action boundaries. The core innovation is the Trident-head, which models action boundaries via an estimated relative probability distribution around the boundary, rather than direct regression. This approach improves localization accuracy by considering the relation of features in a certain period. Additionally, TriDet employs a Scalable-Granularity Perception (SGP) layer in its feature pyramid to mitigate the rank loss problem of self-attention in video features and to aggregate information across different temporal granularities.

## Method Summary
TriDet introduces a one-stage temporal action detection framework that improves boundary localization accuracy through innovative architectural components. The Trident-head predicts action boundaries by modeling relative probability distributions around boundaries rather than direct regression, which better captures the ambiguous nature of action boundaries in videos. The Scalable-Granularity Perception (SGP) layer addresses self-attention rank loss in video features while enabling cross-granularity information aggregation. These innovations enable TriDet to achieve state-of-the-art performance on three challenging benchmarks while maintaining computational efficiency.

## Key Results
- Achieves 69.3% mAP on THUMOS14, outperforming previous best by 2.5%
- Maintains only 74.6% of previous best model's latency while achieving superior performance
- Demonstrates consistent improvements across THUMOS14, HACS, and EPIC-KITCHEN 100 benchmarks

## Why This Works (Mechanism)
The Trident-head's relative boundary modeling approach works by estimating probability distributions around action boundaries rather than directly regressing boundary positions. This captures the inherent ambiguity in action boundaries where the exact start and end points may be unclear. By modeling the relationship of features within a certain temporal period around the boundary, the approach better handles the gradual nature of many action transitions. The SGP layer's multiscale temporal aggregation enables the model to effectively process actions of varying durations while maintaining temporal coherence, addressing the rank loss problem that typically affects self-attention mechanisms in long video sequences.

## Architecture Onboarding

Component map: Input video -> Feature extraction -> Feature pyramid with SGP -> Trident-head -> Boundary probability outputs

Critical path: Feature pyramid (with SGP) -> Trident-head -> Boundary predictions

Design tradeoffs: The Trident-head prioritizes boundary localization accuracy over direct regression speed, while the SGP layer adds computational overhead for improved feature representation

Failure signatures: Poor performance on very long videos, degraded accuracy on actions with extremely rapid transitions

## Limitations
- Scalability to extremely long videos (hours-long content) remains untested
- Limited ablation studies on SGP layer necessity versus alternative solutions
- Performance on videos with significantly different frame rates and action duration distributions not extensively validated

## Confidence
High confidence in core performance claims on established benchmarks (THUMOS14, HACS, EPIC-KITCHEN 100) due to substantial and consistent mAP improvements. Medium confidence in Trident-head's theoretical advantages for relative boundary modeling, supported by strong intuition but limited failure case analysis. Low confidence in generalization to untrimmed videos with different characteristics without additional validation.
