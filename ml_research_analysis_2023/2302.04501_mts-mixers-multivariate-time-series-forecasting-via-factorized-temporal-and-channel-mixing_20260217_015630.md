# MTS-Mixers: Multivariate Time Series Forecasting via Factorized Temporal and Channel Mixing

## Quick Facts
- arXiv ID: 2302.04501
- Source URL: https://arxiv.org/abs/2302.04501
- Reference count: 40
- Primary result: Achieves up to 15.4% MSE and 12.9% MAE reduction compared to Transformer-based models

## Executive Summary
This paper proposes MTS-Mixers, a general framework for multivariate time series forecasting that factorizes temporal and channel dependencies. The authors challenge the necessity of attention mechanisms for capturing temporal dependencies in time series data, demonstrating that factorized approaches using Fourier Transform or random matrices can achieve superior or comparable performance. By leveraging the low-rank property of time series data, MTS-Mixers reduce redundancy and improve efficiency while maintaining strong forecasting accuracy across multiple benchmark datasets.

## Method Summary
MTS-Mixers decompose multivariate time series forecasting into separate temporal and channel interaction modules, using factorized approaches to capture dependencies. The framework employs downsampling strategies for temporal factorization (creating interleaved subsequences) and matrix decomposition or MLPs for channel factorization. This design reduces model complexity while maintaining performance, with parameter sharing strategies that further improve efficiency. The model is trained using L2 loss with Adam optimizer and early stopping within 10 epochs.

## Key Results
- Outperforms existing Transformer-based models on multiple real-world datasets
- Achieves up to 15.4% MSE and 12.9% MAE reduction on average
- Demonstrates superior efficiency with fewer parameters than attention-based approaches
- Random matrix MTS-Mixers show better performance than attention-based models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Attention is not necessary for capturing temporal dependencies in time series forecasting
- Mechanism: Replacing attention with Fourier Transform or random matrices maintains or improves forecasting performance, suggesting temporal dependencies can be captured through factorized approaches
- Core assumption: Temporal dependencies in time series can be captured through factorized approaches rather than complex attention mechanisms
- Evidence anchors: [abstract] "attention is not necessary for capturing temporal dependencies"; [section] "directly replacing the attention layer with Fourier Transform maintains the forecasting performance"

### Mechanism 2
- Claim: The low-rank property of time series data allows for factorized temporal and channel mixing strategies
- Mechanism: By recognizing that time series data often has low-rank properties (rank(X) ≪ min(n,c)), the authors can decompose data into temporal and channel components separately, reducing redundancy and improving efficiency
- Core assumption: Time series data exhibits inherent redundancy in both temporal and channel dimensions
- Evidence anchors: [section] "Given the low-rank property of time series data described in Section 1, we design the factorized temporal and channel mixing strategies"

### Mechanism 3
- Claim: Decoupling temporal and channel dependencies improves forecasting performance
- Mechanism: Separating temporal interactions from channel interactions allows the model to focus on each aspect independently, reducing interference and redundancy
- Core assumption: Temporal and channel dependencies can be effectively learned separately without losing important interactions
- Evidence anchors: [section] "individually capturing temporal and channel dependencies may bring extra improvement"

## Architecture Onboarding

- Component map: Input → Temporal Factorization → Temporal Interaction → Channel Factorization → Channel Interaction → Linear Projection → Output
- Critical path: Input → Temporal Factorization → Temporal Interaction → Channel Factorization → Channel Interaction → Linear Projection → Output
- Design tradeoffs:
  - Factorized approaches reduce parameters but may lose some complex interactions
  - Parameter sharing in temporal factorization reduces memory but may limit learning capacity
  - Choice between attention, random matrix, or MLP for temporal interaction affects performance and efficiency
- Failure signatures:
  - Poor performance with high-rank time series data where factorization is not beneficial
  - Overfitting when temporal factorization parameter sharing is too aggressive
  - Underfitting when the factorized components are too simple to capture complex dependencies

## Limitations
- The claim that attention is not necessary for temporal dependencies lacks theoretical justification for why Fourier Transform or random matrices can effectively replace attention in all scenarios
- The effectiveness of low-rank factorization assumes time series data consistently exhibits low-rank properties across different domains
- The paper does not thoroughly explore limitations of factorized approaches when dealing with high-rank or complex temporal patterns requiring long-range dependencies

## Confidence
- **High confidence**: Experimental results showing MTS-Mixers outperforming Transformer-based models on benchmark datasets
- **Medium confidence**: Theoretical foundation for why factorized approaches work is reasonable but not fully proven
- **Low confidence**: Claim that attention can be completely replaced without loss of performance is based on limited comparisons
