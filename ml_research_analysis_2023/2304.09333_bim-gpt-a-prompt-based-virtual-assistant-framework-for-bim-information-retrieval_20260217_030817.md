# BIM-GPT: a Prompt-Based Virtual Assistant Framework for BIM Information Retrieval

## Quick Facts
- arXiv ID: 2304.09333
- Source URL: https://arxiv.org/abs/2304.09333
- Reference count: 0
- Primary result: Achieved 99.5% accuracy on BIM queries with 2% data in prompts

## Executive Summary
BIM-GPT introduces a prompt-based virtual assistant framework that integrates building information models with generative pre-trained transformer technologies for efficient natural language information retrieval. The framework employs a prompt manager and dynamic template system to generate context-specific prompts that enable GPT models to interpret user queries, summarize retrieved results, and provide comprehensive BIM-related answers. A prototype was successfully implemented for a hospital building case study, demonstrating the practical applicability of the approach.

## Method Summary
The framework utilizes a prompt manager component that dynamically generates prompts based on user queries and available BIM data. When users submit natural language queries about BIM elements, the system constructs context-aware prompts incorporating relevant building information, then sends these to GPT models for processing. The dynamic template system allows for flexible prompt construction that can incorporate varying amounts of BIM data depending on query complexity. The approach leverages zero-shot and few-shot learning capabilities of GPT models to handle queries without requiring extensive fine-tuning on BIM-specific datasets.

## Key Results
- Achieved 83.5% accuracy classifying queries with no BIM data incorporated
- Achieved 99.5% accuracy with 2% BIM data incorporated in prompts
- Successfully implemented VA prototype for hospital building case study

## Why This Works (Mechanism)
The framework leverages GPT's natural language understanding capabilities by providing contextually rich prompts that bridge the semantic gap between user queries and BIM data structures. The prompt manager intelligently selects and formats relevant BIM information to create effective prompts, allowing GPT to reason about building elements, relationships, and attributes without requiring domain-specific fine-tuning.

## Architecture Onboarding

**Component Map**: User Query -> Prompt Manager -> Dynamic Template -> GPT Model -> Response

**Critical Path**: The primary workflow flows from user query input through prompt generation to GPT processing and response delivery. The prompt manager serves as the central component, orchestrating template selection and data incorporation.

**Design Tradeoffs**: The framework prioritizes flexibility and minimal data requirements over absolute precision, trading some control over reasoning for broader applicability across BIM domains.

**Failure Signatures**: Poor performance typically manifests as irrelevant responses when prompts fail to capture query intent or when BIM data extraction is incomplete. API failures or timeouts can interrupt the workflow.

## Limitations
- Experimental validation limited to single hospital building case study
- Accuracy metrics lack confidence intervals and statistical significance testing
- Framework dependency on external GPT APIs introduces cost and latency concerns
- Black-box nature of GPT reasoning limits transparency in decision-making

## Confidence
- High Confidence: Framework architecture combining prompt management with GPT is technically sound
- Medium Confidence: Accuracy improvements require broader validation across diverse BIM datasets
- Low Confidence: Claims about dramatically reduced data requirements need comparative studies with different model sizes
