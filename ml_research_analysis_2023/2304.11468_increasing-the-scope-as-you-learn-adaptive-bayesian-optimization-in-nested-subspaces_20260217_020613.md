# Increasing the Scope as You Learn: Adaptive Bayesian Optimization in Nested Subspaces

## Quick Facts
- arXiv ID: 2304.11468
- Source URL: https://arxiv.org/abs/2304.11468
- Reference count: 40
- One-line primary result: BA XUS adaptively expands target subspace dimensionality, achieving state-of-the-art performance on high-dimensional Bayesian optimization benchmarks with theoretical guarantees of global convergence.

## Executive Summary
This paper introduces BA XUS, a novel approach for high-dimensional Bayesian optimization that adaptively expands the dimensionality of the target subspace it optimizes over. By leveraging a nested family of random embeddings, BA XUS starts with a low-dimensional embedding and increases the dimensionality exponentially as more data is collected, ensuring that the subspace eventually contains the global optimum. The proposed embedding has stronger theoretical guarantees than existing methods, with a higher worst-case success probability of containing a global optimum. Experimental results demonstrate that BA XUS consistently outperforms state-of-the-art HDBO methods across diverse benchmarks.

## Method Summary
BA XUS combines adaptive subspace expansion with trust-region Bayesian optimization. The algorithm starts with a low-dimensional embedding and increases the target dimensionality exponentially by splitting each dimension into multiple bins as data is collected. It uses Gaussian Process surrogates with Matérn 5/2 ARD kernels and Thompson sampling for optimization within trust regions. The adaptive expansion mechanism ensures that the global optimum is guaranteed to be found in the limit, while the nested random embedding structure provides stronger theoretical guarantees than existing approaches like HESBO.

## Key Results
- BA XUS outperforms state-of-the-art HDBO methods (TURBO, SAASBO, ALEBO, HESBO, CMA-ES) on diverse benchmarks
- Achieves excellent solutions on high-dimensional tasks with up to 1000 dimensions
- Demonstrates superior performance on problems with low effective dimensionality relative to input dimension
- Provides theoretical guarantees of global convergence through adaptive subspace expansion

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: BAXUS adaptively increases target subspace dimensionality, ensuring eventual containment of the global optimum
- **Mechanism**: Starts with low-dimensional embedding, exponentially increases dimensionality by splitting each target dimension into multiple bins as data is collected
- **Core assumption**: Global optimum lies in low-dimensional active subspace, or algorithm will expand to full input space
- **Evidence anchors**: [abstract] "leverages a novel family of nested random subspaces to adapt the space it optimizes over"; [section 3.1] "We update the embedding matrix such that contributing input dimensions of the target dimension are re-assigned to the current bin and b new bins"
- **Break condition**: If function has no low-dimensional structure and budget exhausted before full dimensionality, algorithm may fail

### Mechanism 2
- **Claim**: BAXUS embedding has higher worst-case success probability than HESBO
- **Mechanism**: Forces each bin of target dimension to have roughly same number of contributing input dimensions, maximizing probability all active dimensions map to distinct target dimensions
- **Core assumption**: Function has active subspace with dimensionality de, embedding can capture this subspace
- **Evidence anchors**: [section 3.1] "Theorem 1 (Worst-case success probability of the BAXUS embedding)"; [section 3.1] "Corollary 2... no sparse embedding has a higher worst-case success probability"
- **Break condition**: If effective dimensionality de is very close to input dimensionality D, advantage over HESBO diminishes as D grows

### Mechanism 3
- **Claim**: Trust regions enable effective optimization in high-dimensional spaces by focusing on promising regions
- **Mechanism**: Uses TRs that adapt size based on function evaluations - shrinking when progress stalls, expanding when improvements found
- **Core assumption**: Function has smooth regions where local search can make progress
- **Evidence anchors**: [section 3.2] "Similar to TURBO [22], BAXUS operates in trust regions"; [section 3.2] "TRs are an essential component of BAXUS because the target dimensionality usually grows exponentially"
- **Break condition**: If function is highly non-smooth or has many local optima, TRs may get stuck in suboptimal regions

## Architecture Onboarding

- **Component map**: Nested random embeddings -> Trust regions -> Gaussian Process surrogate -> Thompson sampling -> Adaptive expansion mechanism

- **Critical path**:
  1. Initialize with low-dimensional embedding and initial data
  2. Optimize in current target space using trust regions and Thompson sampling
  3. When trust region becomes too small, split dimensions and increase target dimensionality
  4. Repeat until evaluation budget exhausted or full dimensionality reached
  5. Return best observed point

- **Design tradeoffs**:
  - Early vs. late expansion of target dimensionality: Earlier expansion may find better optima but increases computational cost
  - Number of new bins per split: More bins increase expansion speed but may require more evaluations per dimension
  - Trust region parameters: Balance between exploration and exploitation in high-dimensional spaces

- **Failure signatures**:
  - Stagnation in suboptimal solutions despite budget remaining
  - Rapid growth in target dimensionality without corresponding improvement in function values
  - Memory issues due to high-dimensional GP surrogates

- **First 3 experiments**:
  1. Run BAXUS on synthetic function with known active subspace (e.g., shifted Ackley with dummy dimensions) to verify adaptive expansion works
  2. Compare BAXUS with fixed-dimensional embeddings on benchmark to demonstrate benefit of adaptive expansion
  3. Test BAXUS on real-world high-dimensional problem (e.g., SVM hyperparameter optimization) to validate practical performance

## Limitations

- Theoretical guarantees rely heavily on assumption that function has active subspace structure
- Adaptive expansion mechanism may be computationally expensive for very high-dimensional problems
- Trust region approach may struggle with highly non-smooth functions or those with many local optima

## Confidence

- **High Confidence**: Experimental results showing BAXUS outperforming state-of-the-art methods on diverse benchmarks are well-supported by data presented
- **Medium Confidence**: Theoretical analysis of BAXUS embedding's worst-case success probability is rigorous but relies on idealized assumptions about function structure
- **Medium Confidence**: Adaptive expansion mechanism is theoretically sound but may face practical limitations in very high-dimensional spaces
