# Language Instructed Reinforcement Learning for Human-AI Coordination

## Quick Facts
- arXiv ID: 2304.07297
- Source URL: https://arxiv.org/abs/2304.07297
- Authors: 
- Reference count: 18
- Primary result: instructRL uses LLM-generated priors to guide RL agents toward human-preferred equilibria in human-AI coordination tasks

## Executive Summary
This paper addresses the challenge of human-AI coordination in multi-agent environments, where standard reinforcement learning often fails to converge to human-preferred equilibria. The proposed solution, instructRL, leverages large language models to generate a prior policy conditioned on human-provided natural language instructions, which is then used to regularize the RL objective. This approach guides the agent to learn policies that align with human preferences and improves coordination performance. The method is evaluated in both a simple toy game and the complex Hanabi benchmark, demonstrating that instructRL can produce policies satisfying language instructions and significantly improve human-AI coordination when the instruction is known.

## Method Summary
The instructRL method uses a large language model to generate a prior policy based on natural language instructions provided by humans. This prior policy is then used to regularize the RL objective through either a KL penalty term (for policy-based methods like PPO) or a Q-value augmentation term (for value-based methods like Q-learning). The approach is tested in the Hanabi environment with two players, using natural language instructions such as "If my partner tells me the 'color' of some of my cards, I should 'play' those specific cards." The method is evaluated on self-play performance, intra-algorithm cross-play performance, and human evaluation scores. The LLM prior is generated using GPT-3.5 and cached before training, with λ annealing from 0.05 to 0.01 over 750K mini-batches.

## Key Results
- instructRL produces policies satisfying language instructions in both toy games and Hanabi
- Human evaluations show significantly improved coordination when humans know the instruction
- The method achieves better performance than standard RL baselines in human-AI coordination tasks

## Why This Works (Mechanism)
The effectiveness of instructRL stems from incorporating human preferences directly into the learning process through LLM-generated priors. By conditioning the prior policy on natural language instructions, the method provides a structured way to bias the RL agent toward human-preferred equilibria without requiring extensive human-in-the-loop training. The regularization term ensures that the learned policy remains close to the instruction-aligned prior while still optimizing for task performance. This dual objective allows the agent to balance task-specific rewards with human preference alignment, resulting in better coordination outcomes when the instruction is known.

## Architecture Onboarding

**Component Map:**
Hanabi Environment -> OBL Level 1 Policy -> GPT-3.5 LLM -> Prior Policy Cache -> instructPPO/Q-learning -> Trained Policy

**Critical Path:**
Instruction input -> LLM prior generation -> Policy regularization -> RL training -> Evaluation (self-play, cross-play, human)

**Design Tradeoffs:**
- Using a 175B parameter LLM provides high-quality priors but requires significant computational resources
- Caching LLM logits before training avoids repeated API calls but increases memory requirements
- KL regularization vs Q-value augmentation offers flexibility in choosing RL algorithm

**Failure Signatures:**
- Poor performance due to suboptimal prompt engineering (check LLM prior accuracy against rule-based oracle)
- Training instability from improper λ scheduling (monitor cross-play scores during training)
- Limited generalization to complex instructions beyond simple color/rank-based rules

**First Experiments:**
1. Verify LLM prior accuracy by comparing against rule-based oracle in simple instruction scenarios
2. Test instructPPO with KL regularization on toy games before moving to Hanabi
3. Evaluate cross-play performance during training to detect instability early

## Open Questions the Paper Calls Out
The paper identifies several open questions, including: How can instructRL scale to more complex environments and instruction types beyond simple color/rank-based rules? What is the optimal way to balance task performance with instruction adherence in the regularization term? Can the method generalize to multi-turn instructions or sequential decision-making tasks? How does the approach perform with smaller LLMs or alternative language models? These questions highlight opportunities for future research to expand the method's capabilities and applicability.

## Limitations
- Heavy reliance on a 175B parameter LLM creates practical deployment barriers
- Evaluation focuses primarily on a single environment (Hanabi) with two specific instruction types
- Human evaluation uses a small participant pool (15 humans) without accounting for familiarity bias

## Confidence

- Medium confidence in human evaluation findings given the limited sample size
- Low confidence in scalability claims to more complex instruction types or environments

## Next Checks
1. Test instructRL with additional instruction types in Hanabi (e.g., multi-card plays, discard strategies) to verify generalization

3. Benchmark computational overhead of LLM-based prior generation against alternative methods like rule-based priors or smaller model approximations
