# Robust Representation Learning with Reliable Pseudo-labels Generation via Self-Adaptive Optimal Transport for Short Text Clustering

## Quick Facts
- arXiv ID: 2305.16335
- Source URL: https://arxiv.org/abs/2305.16335
- Reference count: 40
- Primary result: RSTC achieves up to 8.34% accuracy and 5.96% NMI improvement over state-of-the-art methods

## Executive Summary
This paper addresses the challenge of short text clustering, which is complicated by data imbalance and noise. The authors propose RSTC, a framework that combines self-adaptive optimal transport for pseudo-label generation with dual contrastive learning for robust representation learning. The method generates reliable pseudo-labels that account for imbalanced data distributions while using both class-wise and instance-wise contrastive learning to handle noise and overlapping clusters. Experiments on eight datasets demonstrate significant improvements over existing methods, with RSTC achieving up to 8.34% accuracy and 5.96% NMI gains.

## Method Summary
RSTC consists of two main modules: pseudo-label generation and robust representation learning. The pseudo-label generation uses self-adaptive optimal transport (SAOT) to estimate real class distributions rather than assuming uniform distributions, addressing data imbalance. The robust representation learning module employs both class-wise and instance-wise contrastive learning, where class-wise learning uses pseudo-labels to separate clusters and instance-wise learning handles overlapping instances through data augmentation. The framework operates iteratively, with better representations leading to better pseudo-labels in a virtuous circle.

## Key Results
- RSTC outperforms state-of-the-art methods by up to 8.34% in accuracy and 5.96% in NMI
- Significant improvements over baseline SCCL and other clustering methods
- Ablation studies confirm the effectiveness of each component (SAOT, class-wise contrastive, instance-wise contrastive)
- Visualizations show RSTC forms well-separated clusters while addressing degeneracy problems

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Self-adaptive optimal transport generates reliable pseudo-labels by estimating real class distribution rather than assuming uniform distribution
- Mechanism: SAOT uses a penalty function that encourages estimated class distribution to be uniform while allowing adaptation to imbalanced data through the cost matrix
- Core assumption: Cluster predictions contain information about true class distribution extractable through optimal transport
- Evidence anchors:
  - [abstract] "To provide robustness against the imbalance in data, we propose self-adaptive optimal transport in the pseudo-label generation module"
  - [section] "We expect to minimize the cross entropy loss to generate the pseudo-labels by solving a discrete OT problem"
  - [corpus] Weak - no direct corpus evidence supporting SAOT's effectiveness
- Break condition: If penalty function parameter ϵ2 is poorly tuned, method may collapse to uniform distribution or allow degenerate solutions

### Mechanism 2
- Claim: Combining class-wise and instance-wise contrastive learning provides robustness against noise in data
- Mechanism: Class-wise contrastive learning uses pseudo-labels to pull same-cluster representations together and push different clusters apart, while instance-wise contrastive learning separates individual instances to handle overlapping clusters
- Core assumption: Pseudo-labels generated by SAOT are sufficiently accurate to serve as supervision for contrastive learning
- Evidence anchors:
  - [abstract] "To improve robustness against the noise in data, we further introduce both class-wise and instance-wise contrastive learning in the robust representation learning module"
  - [section] "The class-wise contrastive learning aims to use the pseudo-labels as supervision for achieving smaller intra-cluster distance and larger inter-cluster distance"
  - [corpus] Weak - no direct corpus evidence supporting the dual contrastive approach
- Break condition: If pseudo-labels are too noisy, class-wise contrastive loss will reinforce incorrect cluster assignments

### Mechanism 3
- Claim: The iterative training process forms a virtuous circle where better representations lead to better pseudo-labels which lead to better representations
- Mechanism: Initial pseudo-labels generated via k-means, then refined through SAOT. These pseudo-labels supervise contrastive learning, which produces better representations. Better representations feed back into SAOT for more accurate pseudo-labels
- Core assumption: Closed-loop system has stable fixed points where representations and pseudo-labels mutually reinforce each other
- Evidence anchors:
  - [abstract] "The better cluster predictions in turn can be conductive to generate more reliable pseudo-labels. The iterative training process forms a virtuous circle"
  - [section] "Specifically, we firstly initialize the pseudo-labels Q by performing k-means on text representations. Next, we train the robust representation learning module by batch with the supervision of pseudo-labels"
  - [corpus] Weak - no direct corpus evidence of the virtuous circle mechanism
- Break condition: If learning rates or update frequencies are mismatched, system may oscillate or diverge rather than converge

## Architecture Onboarding

- Component map: Input → SBERT Encoder → Cluster Assignment → SAOT → Pseudo-labels → Class-wise Contrastive Loss + Instance-wise Contrastive Loss → Representations → Output
- Critical path: Pseudo-label generation (SAOT) → Class-wise contrastive learning → Instance-wise contrastive learning
- Design tradeoffs: SAOT handles imbalance but adds computational overhead (O(n²)); dual contrastive learning handles noise but requires careful hyperparameter tuning
- Failure signatures: Degenerate solutions (all instances in one cluster), poor separation of overlapping clusters, slow convergence

## Limitations

- SAOT computational complexity of O(n²) adds significant overhead for large datasets
- The method's effectiveness on extremely severe class imbalance (beyond what was tested) is not established
- The paper lacks analysis of the convergence properties and stability of the iterative training process

## Confidence

- **High Confidence**: The overall framework architecture and experimental results showing RSTC outperforms baselines (8.34% accuracy improvement, 5.96% NMI improvement)
- **Medium Confidence**: The SAOT mechanism's ability to handle imbalanced data through adaptive class distribution estimation
- **Low Confidence**: The claim that the iterative training process forms a stable "virtuous circle" - this is stated but not empirically validated through convergence analysis
