# Neural Preset for Color Style Transfer

## Quick Facts
- arXiv ID: 2303.13511
- Source URL: https://arxiv.org/abs/2303.13511
- Reference count: 40
- Achieves 28× speedup on Nvidia RTX3090 GPU for photorealistic color style transfer

## Executive Summary
This paper introduces a novel method for photorealistic color style transfer that addresses limitations of existing approaches through Deterministic Neural Color Mapping (DNCM). The technique operates on each pixel independently using an image-adaptive color mapping matrix, avoiding visual artifacts while maintaining a small memory footprint. A two-stage pipeline divides the task into color normalization and stylization, enabling efficient style switching through reusable presets. The method achieves real-time 4K color style transfer on modern GPUs and demonstrates strong generalization across multiple image enhancement applications without requiring task-specific fine-tuning.

## Method Summary
The proposed approach employs Deterministic Neural Color Mapping (DNCM) that operates pixel-wise using image-adaptive color mapping matrices, distinguishing it from traditional CNN-based methods. The two-stage pipeline first normalizes input images to a standard color space, then applies stylization using extracted color presets. This architecture enables style switching by extracting color styles as presets and reusing them across different normalized inputs. Due to the lack of pairwise datasets for supervised training, the authors implement a self-supervised training strategy that learns to map between unpaired color styles. The method processes high-resolution images efficiently while maintaining photorealistic quality and supporting multiple downstream applications including low-light enhancement, underwater correction, dehazing, and image harmonization.

## Key Results
- Achieves approximately 28× speedup compared to existing approaches on Nvidia RTX3090 GPU
- Enables stable real-time 4K color style transfer without visual artifacts
- Demonstrates natural support for multiple applications (low-light enhancement, underwater correction, dehazing, harmonization) without fine-tuning

## Why This Works (Mechanism)
The DNCM approach works by operating on each pixel independently using an image-adaptive color mapping matrix, which avoids the spatial correlation artifacts common in traditional CNN-based style transfer methods. This pixel-wise operation combined with the two-stage pipeline (normalization followed by stylization) enables efficient style switching through reusable presets. The self-supervised training strategy allows learning effective color mappings without requiring paired datasets, making the approach more practical and scalable.

## Foundational Learning
- **Deterministic Neural Color Mapping (DNCM)**: A pixel-wise color transformation method that uses image-adaptive matrices to avoid spatial artifacts - needed for photorealistic results without common CNN-based artifacts
- **Self-supervised training**: Learning strategy that works with unpaired data by reconstructing target styles from source images - needed due to unavailability of pairwise datasets
- **Two-stage pipeline**: Color normalization followed by stylization - needed to enable efficient style switching through reusable presets
- **Image-adaptive color mapping matrices**: Dynamic transformation matrices that adjust based on input image characteristics - needed for flexible, photorealistic color transfer
- **Preset-based style switching**: Extracting and storing color styles as reusable presets - needed for efficient multi-style applications

## Architecture Onboarding
Component map: Input Image -> Color Normalization -> Style Extraction -> Preset Storage -> Stylization -> Output Image
Critical path: Input -> DNCM (pixel-wise color mapping) -> Output, with style switching via preset reuse
Design tradeoffs: Pixel-wise operation trades spatial context awareness for artifact-free results and memory efficiency
Failure signatures: Poor style transfer quality when input and target styles have vastly different color distributions; performance degradation on extremely low-light or severely degraded images
First experiments: 1) Verify pixel-wise DNCM operation correctness on synthetic test patterns, 2) Test style extraction and preset storage functionality with multiple styles, 3) Benchmark memory usage and speed on progressively larger images
