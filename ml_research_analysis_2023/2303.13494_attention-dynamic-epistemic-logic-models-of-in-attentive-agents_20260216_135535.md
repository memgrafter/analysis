# Attention! Dynamic Epistemic Logic Models of (In)attentive Agents

## Quick Facts
- arXiv ID: 2303.13494
- Source URL: https://arxiv.org/abs/2303.13494
- Reference count: 23
- Key outcome: Dynamic epistemic logic framework for attention-based belief dynamics with exponential succinctness improvements

## Executive Summary
This paper introduces a dynamic epistemic logic framework for modeling how agents update beliefs based on selective attention to propositions. The authors address limitations in prior models that only captured fully attentive or fully inattentive agents by allowing agents to pay attention to subsets of atomic propositions. They develop a generalized event model representation using "edge principles" that capture attention-dependent belief updates, and introduce a syntactic event model language that achieves exponential succinctness compared to traditional semantic event models.

## Method Summary
The authors formalize attention-based belief dynamics using Dynamic Epistemic Logic (DEL), introducing attention atoms to represent whether agents attend to specific propositions. They define edge principles (Basic Attentiveness, Inertia, Attentiveness, Defaulting) that specify how agents transition between events based on their attention states. The framework includes both semantic event models and a novel syntactic representation using logical formulas, achieving linear representation size versus exponential growth in traditional approaches. The authors prove soundness and completeness of their axiomatization and extend the model to incorporate default values for unattended propositions.

## Key Results
- Generalized event model representation with edge principles captures attention-based belief updates more compactly
- Syntactic event models achieve exponential succinctness (linear vs exponential representation size)
- Extension to default values enables cognitively plausible modeling of inattentional blindness
- Soundness and completeness of the propositional attention logic axiomatization proven

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Generalized event model with edge principles allows compact representation of attention-based belief updates
- Mechanism: Edge principles encode agent attention states as logical formulas, defining possible transitions based on what agents attend to
- Core assumption: Agents update beliefs solely based on attended content, with unattended propositions handled by inertia or default values
- Evidence anchors:
  - Abstract: "exponentially more succinct representations compared to standard semantic event models"
  - Section 3.1: "Compare the edge specification from E (𝜑) with the one from E ′(𝜑)... It is simply two basic principles..."

### Mechanism 2
- Claim: Syntactic event model language provides exponential succinctness over semantic models
- Mechanism: Logical formulas specify events and transitions instead of explicit enumeration, reducing representation from exponential to linear
- Core assumption: Events can be represented as conjunctions of literals, with transitions describable by logical formulas
- Evidence anchors:
  - Abstract: "exponentially more succinct representations compared to standard semantic event models"
  - Section 6: "We show exponential succinctness of these syntactic event models as compared to standard (semantic) event models"

### Mechanism 3
- Claim: Default values for unattended propositions enable cognitively plausible inattentional blindness modeling
- Mechanism: Agents use prior beliefs (true, false, or preserve) for unattended propositions rather than maintaining uncertainty
- Core assumption: Strong prior beliefs override uncertainty when evidence is absent
- Evidence anchors:
  - Abstract: "extend the framework to account for inattentive agents that... may default to a specific truth-value"
  - Section 5: "agents seem to update their beliefs with respect to unattended events as well, regardless of whether their experience... contained any evidence"

## Architecture Onboarding

- Component map: Kripke models (beliefs/attention) -> Event models (updates) -> Edge principles (transition logic) -> Product update -> Updated Kripke models
- Critical path: Kripke model → Event model (semantic/syntactic) → Product update → Updated Kripke model
- Design tradeoffs:
  - Semantic vs. syntactic event models: General vs compact (exponential vs linear size)
  - Default values vs. uncertainty: Cognitive plausibility vs. actual uncertainty representation
  - Edge principle expressiveness: Rich behavior vs. complexity
- Failure signatures:
  - Exponential blowup indicates need for syntactic representation
  - Inconsistent updates suggest incorrect edge principle formulation
  - Inability to represent scenarios indicates model limitations

## Limitations
- Exponential succinctness claim relies on assumption that all events can be expressed as conjunctions of literals
- Completeness proof for default attention logic is more complex with some technical details deferred
- Practical applicability to real-world attention phenomena requires further validation

## Confidence
- **High confidence**: Basic framework for generalized attention models and soundness of axiomatization for standard propositional attention
- **Medium confidence**: Exponential succinctness result for syntactic event models and extension to default attention values
- **Medium confidence**: Practical applicability to modeling real-world attention phenomena like inattentional blindness
