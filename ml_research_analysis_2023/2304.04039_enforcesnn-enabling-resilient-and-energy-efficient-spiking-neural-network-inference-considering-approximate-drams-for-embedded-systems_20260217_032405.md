# EnforceSNN: Enabling Resilient and Energy-Efficient Spiking Neural Network Inference considering Approximate DRAMs for Embedded Systems

## Quick Facts
- arXiv ID: 2304.04039
- Source URL: https://arxiv.org/abs/2304.04039
- Reference count: 23
- Achieves up to 84.9% DRAM energy savings while maintaining accuracy for bit error rates up to 10^-3

## Executive Summary
EnforceSNN introduces a framework that enables energy-efficient Spiking Neural Network (SNN) inference on embedded systems by leveraging approximate DRAM with reduced supply voltage. The approach combines quantization, error-aware DRAM mapping, and fault-aware training to maintain SNN accuracy while significantly reducing DRAM energy consumption. This is particularly important for embedded systems where memory access energy dominates total system power.

## Method Summary
The EnforceSNN framework employs a multi-pronged approach to maintain accuracy while reducing DRAM energy. It uses quantization to reduce data precision requirements, implements error-aware DRAM mapping to strategically place sensitive data, and applies fault-aware training to make the network resilient to bit errors. By reducing DRAM supply voltage, the system achieves substantial energy savings while the error mitigation techniques preserve classification accuracy even at high bit error rates.

## Key Results
- Achieves up to 84.9% DRAM energy savings compared to baseline SNN with accurate DRAM
- Delivers 4.1x speed-up in DRAM data throughput
- Maintains accuracy with no loss for bit error rates up to 10^-3 across different network sizes

## Why This Works (Mechanism)
The framework exploits the inherent sparsity and fault tolerance of spiking neural networks to tolerate DRAM bit errors that occur when voltage is reduced. The quantization reduces sensitivity to errors, while error-aware mapping ensures critical data is placed in more reliable DRAM regions. Fault-aware training further enhances resilience by exposing the network to simulated errors during training, allowing it to learn robust representations.

## Architecture Onboarding
Component map: Input Data -> Quantizer -> SNN Layer -> DRAM -> Error-aware Mapping -> SNN Layer -> Output

Critical path: Data flows from input through quantized SNN layers, with DRAM accesses mediated by error-aware mapping. The fault-aware training component modifies the network weights during training phase.

Design tradeoffs: Higher voltage reduction yields more energy savings but increases error rates; aggressive quantization saves memory but may hurt accuracy; complex mapping schemes improve resilience but add overhead.

Failure signatures: Accuracy degradation when bit error rates exceed 10^-3 threshold; potential timing violations if DRAM access patterns change; possible training instability with aggressive error injection.

First experiments: 1) Measure baseline SNN accuracy and DRAM energy consumption; 2) Implement quantization and measure impact on accuracy and memory usage; 3) Test error-aware mapping with simulated bit errors and measure accuracy preservation.

## Open Questions the Paper Calls Out
The paper acknowledges that validation is limited to 1-3 layer SNNs and MNIST/Fashion-MNIST datasets, which may not represent performance on deeper networks or more complex tasks. The assumed sparsity of network activity that enables DRAM voltage reduction may not hold for all SNN architectures. The quantization scheme's effectiveness could be compromised if bit errors exceed the 10^-3 threshold, though this boundary is not extensively tested.

## Limitations
- Focus on 1-3 layer SNNs limits generalizability to deeper networks common in modern applications
- Validation on MNIST/Fashion-MNIST may not represent performance on complex vision or non-vision tasks
- Assumes network activity is sufficiently sparse to benefit from DRAM voltage reduction
- Quantization effectiveness could be compromised if bit errors exceed 10^-3 threshold

- 4.1x speed-up: Medium confidence - may vary with DRAM controller implementation
