# Two-Memory Reinforcement Learning

## Quick Facts
- arXiv ID: 2304.10098
- Source URL: https://arxiv.org/abs/2304.10098
- Reference count: 23
- Primary result: 2M agent combines episodic memory and reinforcement learning to achieve better data efficiency and performance than either approach alone

## Executive Summary
This paper introduces the Two-Memory reinforcement learning agent (2M) that combines episodic memory and reinforcement learning to leverage the strengths of both approaches. The 2M agent uses episodic memory for fast initial learning based on past high-reward trajectories while reinforcement learning provides optimal value estimates through gradual updates. The approach is evaluated on five MinAtar games and demonstrates improved data efficiency and performance compared to pure episodic memory, pure reinforcement learning, and a state-of-the-art memory-augmented RL agent.

## Method Summary
The 2M agent integrates Model Free Episodic Control (MFEC) as the episodic memory component with Deep Q-Networks (DQN) as the reinforcement learning component. Both components share a common experience replay buffer, allowing data collected by the episodic memory to benefit the reinforcement learning component. A switching probability `pec` controls the selection between the two memory systems for action selection, with a scheduling mechanism that decays from favoring episodic memory to favoring reinforcement learning over time. During evaluation, the agent greedily selects between memories based on recent performance.

## Key Results
- 2M agent outperforms both pure episodic memory and pure reinforcement learning on all five MinAtar games tested
- Data sharing between components results in faster learning of state-action values compared to using RL data alone
- The switching mechanism successfully transitions from fast but sub-optimal episodic control to slower but optimal reinforcement learning
- 2M achieves better asymptotic performance than EMDQN, a state-of-the-art memory-augmented RL agent

### Mechanism 1
- Claim: The 2M agent combines fast episodic memory with slow reinforcement learning to achieve both quick initial learning and good long-term performance.
- Mechanism: The agent uses episodic memory for rapid action selection based on past high-reward trajectories, while reinforcement learning provides optimal value estimates through gradual updates. The switching probability `pec` controls the transition from fast but sub-optimal episodic control to slow but optimal reinforcement learning.
- Core assumption: The episodic memory can quickly find good but sub-optimal solutions, and the reinforcement learning component can eventually find optimal solutions if given enough data.

### Mechanism 2
- Claim: Data sharing between episodic memory and reinforcement learning components improves learning efficiency.
- Mechanism: Data collected by the episodic memory component is used to update the reinforcement learning component through the experience replay buffer. This allows the reinforcement learning component to learn from diverse trajectories discovered by the episodic memory.
- Core assumption: Data collected by episodic memory is at least somewhat correlated to the optimal policy, providing useful learning signals for reinforcement learning.
- Evidence anchors:
  - [section]: "The right panel of Fig. 5 shows that using mixed data to train the RL agent (2M-RL) can indeed result in faster learning of state-action values compared to using data solely collected by RL."

- Break condition: If the episodic memory component consistently finds poor trajectories or if the reinforcement learning component cannot benefit from non-optimal data.

### Mechanism 3
- Claim: The switching mechanism allows the agent to leverage the strengths of both memory systems at different stages of learning.
- Mechanism: The switching probability `pec` is scheduled to decay over time, starting with high preference for episodic memory and gradually shifting to reinforcement learning. During evaluation, the agent chooses the memory system that performed better recently.
- Core assumption: The optimal memory system changes over time, with episodic memory being more useful early in learning and reinforcement learning becoming more valuable as it learns better representations.
- Evidence anchors:
  - [section]: "During evaluation, we exploit knowledge stored in both memories in a greedy manner. However, we still need to decide which memory to use during evaluation."

## Architecture Onboarding

- Component map:
  - Episodic Memory Component (2M-EC) -> Reinforcement Learning Component (2M-RL) -> Experience Replay Buffer -> Switching Mechanism -> Episodic Memory Component

- Critical path: State → Action Selection (based on current memory choice) → Environment Interaction → Data Collection → Update Both Components → Switching Decision → Repeat

- Design tradeoffs:
  - Fast initial learning vs. asymptotic optimality: Episodic memory provides quick results but may converge to sub-optimal solutions
  - Data efficiency vs. computational complexity: Sharing data between components improves learning but requires managing a shared replay buffer
  - Exploration vs. exploitation: The switching mechanism must balance between using known good trajectories and discovering better ones

- Failure signatures:
  - Poor performance despite adequate training: Indicates issues with either component or the switching mechanism
  - Rapid initial improvement followed by plateau: Suggests episodic memory is finding local optima without transitioning to reinforcement learning
  - Slow learning throughout: Indicates problems with data sharing or component integration

## Limitations

- The switching mechanism's effectiveness relies on the assumption that the optimal memory system changes predictably over time, which may not hold in non-stationary environments
- Experimental validation is limited to relatively simple Atari games, leaving scalability to more complex, high-dimensional environments untested
- The paper does not address potential computational overhead from maintaining two separate memory systems and the shared experience replay buffer

## Confidence

- High: The core mechanism of combining episodic memory with reinforcement learning for improved data efficiency is well-supported by the experimental results.
- Medium: The switching mechanism's effectiveness is demonstrated but may be sensitive to hyperparameter choices and environment characteristics.
- Medium: The data sharing benefits are shown in experiments but the long-term impact on learning stability requires further investigation.
