# Derivative-based Shapley value for global sensitivity analysis and machine learning explainability

## Quick Facts
- arXiv ID: 2303.15183
- Source URL: https://arxiv.org/abs/2303.15183
- Reference count: 19
- One-line primary result: DerSHAP provides computationally efficient Shapley values with linear complexity in feature count versus exponential complexity of traditional methods

## Executive Summary
This paper introduces DerSHAP, a derivative-based Shapley value method that achieves linear computational complexity in the number of features by leveraging partial derivatives rather than exhaustive subset enumeration. The method captures both first-order effects and second-order interaction terms through mixed partial derivatives, providing more comprehensive feature importance analysis than traditional activity scores. Numerical experiments on biological models and real-world datasets demonstrate DerSHAP's computational efficiency (3-5x faster than KernelSHAP) and ability to handle both independent and dependent input features.

## Method Summary
DerSHAP computes feature importance by estimating expectations of squared partial derivatives (E[∂f²ᵢ]) and absolute values of mixed partial derivatives (|E[∂fi∂fj]|) using Monte Carlo sampling. The method replaces the exponential complexity of traditional Shapley value computation (2^d subset evaluations) with linear complexity (dN derivative evaluations), where d is the number of features and N is the number of Monte Carlo samples. For high-dimensional problems, DerSHAP can use eigenvalue decomposition of the gradient covariance matrix to further reduce computational cost. The method works for both independent and dependent input features by sampling from the appropriate joint distribution.

## Key Results
- DerSHAP reduces computational complexity from O(2^d) to O(dN) by using partial derivatives instead of subset enumeration
- On Ebola and HIV models, DerSHAP produces different importance rankings than activity scores due to inclusion of second-order interaction effects
- Applied to Amazon stock and Boston housing datasets, DerSHAP is 3-5x faster than KernelSHAP while providing comparable or superior feature importance rankings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: DerSHAP reduces computational complexity from exponential to linear by using partial derivatives instead of power set enumeration.
- Mechanism: Instead of computing Shapley values by evaluating all 2^d subsets of features (as in traditional methods), DerSHAP computes expectations of partial derivatives (∂f/∂xi)² and |∂fi∂fj| for all pairs of features. This requires only dN computations (d derivatives for each of N Monte Carlo samples) versus 2^d subset evaluations.
- Core assumption: First-order partial derivatives exist and are square-integrable for the function f.
- Evidence anchors:
  - [abstract] states "The computational complexity of the method is linear in dimension (number of features), as opposed to the exponential complexity of other Shapley value approaches"
  - [section 4] states "The derivative-based Shapley (DerSHAP) value involves the summation of d terms where each summand is an expectation that can be approximated using Monte Carlo. Therefore the complexity of the method is O(dN)"
  - [corpus] shows related work on computing exact Shapley values in polynomial time for specific cases
- Break condition: If partial derivatives do not exist or are not square-integrable, the method cannot be applied.

### Mechanism 2
- Claim: DerSHAP captures second-order interaction effects through mixed partial derivatives, providing more accurate feature importance rankings than activity scores.
- Mechanism: DerSHAP's importance function includes both first-order terms (E[∂f²ᵢ]) and second-order interaction terms (|E[∂fi∂fj]|). This captures how pairs of features interact in affecting the output, which activity scores miss since they only consider first-order terms.
- Core assumption: Second-order mixed partial derivatives exist and can be estimated reliably.
- Evidence anchors:
  - [section 4] states "imp(u) = ∑ᵢ∈ᵤ E[∂f²ᵢ] + ∑ᵢ,ⱼ∈ᵤ,ⱼ>ᵢ |E[∂fi∂fj]|"
  - [section 5.1] shows DerSHAP produces different importance rankings than activity scores due to inclusion of interaction effects
  - [section 5.1] states "These differences are due to the fact that DerSHAP takes into account the 2nd order interactions ∂fi∂fj for i≠j, whereas the activity score only considers ∂f²ᵢ"
- Break condition: If interaction effects are negligible or if mixed partial derivatives cannot be reliably estimated, the added complexity may not provide meaningful improvements.

### Mechanism 3
- Claim: DerSHAP can handle both independent and dependent input features by using Monte Carlo estimation with appropriate sampling distributions.
- Mechanism: By generating Monte Carlo samples from the joint distribution of inputs (whether independent or dependent), DerSHAP can estimate expectations of derivatives under any dependency structure. This is in contrast to methods like SHAP and KernelSHAP that assume feature independence.
- Core assumption: The joint distribution of input features can be characterized or sampled from.
- Evidence anchors:
  - [section 5.4] demonstrates DerSHAP applied to Boston housing data with both independent and dependent input assumptions
  - [section 5.4] states "An advantage of DerSHAP is it can be used with dependent data, unlike KernelSHAP"
  - [section 4] states "In contrast, the original Shapley value formulation requires a summation of 2ᵈ terms"
- Break condition: If the joint distribution is unknown and cannot be estimated from data, the method's performance may degrade.
