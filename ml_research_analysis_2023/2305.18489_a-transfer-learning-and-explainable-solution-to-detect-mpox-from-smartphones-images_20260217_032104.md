# A Transfer Learning and Explainable Solution to Detect mpox from Smartphones images

## Quick Facts
- arXiv ID: 2305.18489
- Source URL: https://arxiv.org/abs/2305.18489
- Reference count: 40
- Primary result: MobileNetV3Large achieves 0.928 accuracy in binary classification (mpox vs others) on smartphone images

## Executive Summary
This paper presents a mobile health system for detecting mpox infections using smartphone images of skin lesions. The system leverages transfer learning with five state-of-the-art CNNs optimized for mobile deployment through quantization. A new dataset called Mpox Close Skin Images (MCSI) is created with 400 homogeneous images equally distributed across four classes. The approach combines technical performance with clinical validation through eXplainable AI techniques, achieving 0.928 accuracy in binary classification and 0.882 accuracy in multiclass classification.

## Method Summary
The methodology involves transfer learning from five pre-trained CNNs (VGG16, InceptionResNetV2, NASNetMobile, MobileNetV3Small, MobileNetV3Large) fine-tuned on the MCSI dataset using 10-fold stratified cross-validation. Data augmentation techniques are applied to training folds, and Hyperband is used for hyperparameter tuning. The models are optimized for mobile deployment through quantization, reducing memory footprint by 4×. Grad-CAM is employed to generate explainable heatmaps for clinical validation of predictions.

## Key Results
- MobileNetV3Large achieves best performance: 0.928 accuracy in binary classification (mpox vs others) and 0.882 accuracy in multiclass classification
- Quantization reduces model size by 4× without significant accuracy loss
- Inference time remains under one second on commercial smartphones
- Grad-CAM provides clinically interpretable explanations for model predictions

## Why This Works (Mechanism)

### Mechanism 1
Transfer learning from ImageNet to skin lesion classification is effective because learned visual features transfer across domains. CNNs pretrained on ImageNet learn low-level visual features (edges, textures, shapes) that are broadly applicable to medical imaging, allowing the model to reuse these features and only fine-tune classification layers. Core assumption: Low-level visual features learned on general images are similar to those needed to detect skin lesion patterns.

### Mechanism 2
Mobile optimization through quantization reduces model size by 4× without significant accuracy loss. Converting 32-bit floating point weights to 8-bit integers reduces memory footprint while maintaining most of the model's representational capacity. Core assumption: The precision reduction from 32-bit to 8-bit floats does not eliminate important information needed for classification.

### Mechanism 3
Grad-CAM provides clinically interpretable explanations that validate model predictions. Grad-CAM computes gradients of the target class with respect to feature maps in the last convolutional layer, highlighting regions most influential in the prediction. Core assumption: The regions highlighted by Grad-CAM correspond to clinically relevant features that medical experts would use for diagnosis.

## Open Questions the Paper Calls Out

### Open Question 1
How effective would federated learning be for improving the mpox detection system's accuracy while preserving user privacy? The paper mentions federated learning as a future research direction, noting it could enable collaborative training without sharing user data and potentially improve accuracy by incorporating diverse data.

### Open Question 2
What is the optimal dataset size and diversity needed to significantly improve the model's performance for mpox detection across different populations? The authors acknowledge the primary limitation is the paucity of public training data and suggest collaboration with healthcare experts to create a more diverse dataset.

### Open Question 3
Which data augmentation techniques beyond the standard 6 explored would be most effective for improving mpox detection performance? The paper notes that data augmentation did not lead to significant performance improvements, suggesting the need for more sophisticated approaches.

## Limitations
- Small and homogeneous dataset (400 images across 4 classes) may not capture full variability of mpox presentations
- Balanced class distribution may not reflect real-world prevalence patterns
- Mobile deployment validation was theoretical rather than tested on actual devices

## Confidence

**High Confidence**: The methodological approach (transfer learning with cross-validation) is well-established and correctly applied. The reported performance metrics are internally consistent with the experimental setup described.

**Medium Confidence**: The effectiveness of quantization for 4× size reduction without significant accuracy loss, as this depends heavily on the specific model architecture and dataset characteristics. The Grad-CAM explanations are methodologically sound but require clinical validation.

**Low Confidence**: Real-world clinical utility and mobile deployment performance, as these were not empirically validated beyond theoretical optimization.
