# Query-specific Variable Depth Pooling via Query Performance Prediction towards Reducing Relevance Assessment Effort

## Quick Facts
- arXiv ID: 2304.11752
- Source URL: https://arxiv.org/abs/2304.11752
- Reference count: 32
- Key outcome: Variable depth pooling reduces annotation effort while maintaining evaluation quality

## Executive Summary
This paper addresses the challenge of reducing manual annotation effort in information retrieval system evaluation. The authors propose a query-specific variable depth pooling approach that determines pool depth for each query based on its estimated number of relevant documents. By using query performance prediction techniques, particularly Normalized Query Commitment (NQC), the method adapts pool depths to query difficulty, achieving significant reductions in average pool size while maintaining high correlation in system rankings and coverage of relevant documents.

## Method Summary
The proposed approach uses query performance prediction (QPP) to estimate the number of relevant documents for each query. The method employs either an inverse-linear or linear dependence between the QPP score and the pool depth, allowing for lower depths for queries with fewer relevant documents and higher depths for those with more. This query-specific variable depth pooling is evaluated on TREC Robust and TREC DL datasets, comparing system rankings and coverage against standard fixed-depth pooling.

## Key Results
- Variable depth pooling significantly reduces annotation effort (average pool size) compared to fixed-depth pooling
- High correlation in system rankings maintained (Pearson's and Kendall's tau)
- Good coverage of relevant documents preserved across different depth configurations

## Why This Works (Mechanism)
The approach works by leveraging the relationship between query difficulty and the number of relevant documents. Queries predicted to have fewer relevant documents require smaller pool depths to capture all relevant items, while difficult queries with more relevant documents need deeper pools. This adaptive strategy optimizes the trade-off between evaluation completeness and annotation effort.

## Foundational Learning
- Query Performance Prediction (QPP): Predicting retrieval effectiveness for specific queries
  - Why needed: To estimate relevance distribution without exhaustive assessment
  - Quick check: Compare QPP scores against actual relevant document counts
- Pool depth optimization: Determining appropriate retrieval cutoff for evaluation
  - Why needed: Fixed depths either waste effort or miss relevant documents
  - Quick check: Measure coverage vs. annotation cost across depth ranges
- System ranking correlation: Maintaining evaluation quality with reduced data
  - Why needed: Ensure reduced effort doesn't compromise effectiveness measurement
  - Quick check: Compare Pearson's and Kendall's tau with fixed-depth baselines

## Architecture Onboarding

**Component map:** Query -> QPP Score -> Pool Depth Assignment -> Retrieval Pool -> Assessment

**Critical path:** QPP score calculation → Pool depth determination → Document retrieval → Relevance assessment

**Design tradeoffs:** Fixed-depth pooling offers simplicity but wastes effort on easy queries while missing relevant documents on hard queries. Variable depth pooling optimizes per-query but requires reliable QPP and introduces complexity in depth determination.

**Failure signatures:** Poor QPP scores lead to insufficient pool depths missing relevant documents. Overly conservative depth assignments fail to reduce effort. Mismatched linear/inverse-linear relationships degrade evaluation quality.

**Three first experiments:** 1) Compare NQC against alternative QPP methods for depth prediction accuracy. 2) Evaluate different depth-to-QPP mapping functions (linear, inverse-linear, threshold-based). 3) Test robustness across varying collection sizes and query distributions.

## Limitations
- Generalizability across different IR tasks and domains beyond TREC datasets
- Reliance on QPP techniques may not translate well to queries with different characteristics
- Method effectiveness assumes stable relationship between QPP scores and relevant document counts

## Confidence
- Reduced annotation effort and maintained evaluation quality: High
- Broader applicability across diverse datasets and query types: Medium

## Next Checks
1. Evaluate the variable depth pooling method on additional IR test collections with different characteristics (e.g., web search, medical IR) to assess generalizability.
2. Compare the performance of multiple QPP techniques (beyond NQC) in determining pool depths to identify the most robust approach across diverse query types.
3. Conduct a user study with human assessors to validate the practical reduction in annotation effort and any potential impact on assessment quality or consistency.
