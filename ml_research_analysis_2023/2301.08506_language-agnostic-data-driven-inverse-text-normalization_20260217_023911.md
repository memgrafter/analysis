# Language Agnostic Data-Driven Inverse Text Normalization

## Quick Facts
- arXiv ID: 2301.08506
- Source URL: https://arxiv.org/abs/2301.08506
- Reference count: 0
- Primary result: Proposed method improves low-resource ITN accuracy by 37.69% for Kazakh while maintaining competitive performance on high-resource languages

## Executive Summary
This paper addresses the challenge of inverse text normalization (ITN) for non-English languages by proposing a language-agnostic data-driven framework. The method uses data augmentation via text normalization and neural machine translation to generate spoken-written pairs for low-resource languages. The authors introduce a novel evaluation methodology for ITN models when only English data is available, and demonstrate significant improvements in ITN performance across 12 languages, particularly for low-resource languages like Kazakh.

## Method Summary
The proposed approach uses a multilingual model trained on augmented data to handle ITN across different languages. The method generates synthetic training data through two augmentation strategies: text normalization to create spoken-written pairs, and neural machine translation to translate English ITN data into target languages. The paper experiments with both LSTM-based Seq2Seq and Transformer architectures, with the LSTM-based model achieving the best results. A novel monolingual evaluation setup is introduced where models are trained on English data and tested on target languages.

## Key Results
- 37.69% accuracy improvement for Kazakh ITN using MetaNMT data augmentation
- Multilingual model achieves competitive performance on high-resource languages
- LSTM-based Seq2Seq architecture outperforms Transformer model
- Proposed evaluation method enables testing on languages with no native ITN data

## Why This Works (Mechanism)
The approach leverages data augmentation to overcome the scarcity of labeled spoken-written text datasets for non-English languages. By generating synthetic data through text normalization and NMT, the model can learn patterns for inverse text normalization even when limited native data exists. The multilingual training allows the model to transfer knowledge across languages, improving performance on low-resource languages while maintaining competitive results on high-resource languages.

## Limitations
- The monolingual evaluation setup lacks rigorous justification for representing realistic low-resource scenarios
- Performance claims for low-resource languages should be interpreted cautiously due to small test sets
- Absence of comparison to recent advanced ITN approaches limits benchmarking claims

## Confidence
- High: The multilingual model's competitive performance on high-resource languages
- Medium: The LSTM-based Seq2Seq architecture's superior results
- Low: The low-resource language results, particularly for MetaNMT augmentation method
