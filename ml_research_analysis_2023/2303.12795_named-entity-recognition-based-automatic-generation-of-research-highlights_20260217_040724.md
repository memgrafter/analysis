# Named Entity Recognition Based Automatic Generation of Research Highlights

## Quick Facts
- arXiv ID: 2303.12795
- Source URL: https://arxiv.org/abs/2303.12795
- Reference count: 8
- Key outcome: NER-based preprocessing improves pointer-generator network performance for research highlight generation

## Executive Summary
This paper proposes a method for automatically generating research highlights from scientific papers by combining named entity recognition (NER) with pointer-generator networks. The approach treats named entities as single tokens during preprocessing, which prevents their fragmentation and improves embedding quality. The authors evaluate four model variants: pointer-generator network (PGM), PGM with coverage mechanism, NER-enhanced PGM, and NER-enhanced PGM with coverage. Experiments on the CSPubSumm dataset show that adding named entity information improves performance across ROUGE, METEOR, and BERTScore metrics.

## Method Summary
The method uses scientific paper sections (abstract, conclusion, introduction) as input and generates highlights using a pointer-generator network. Named entities are identified using spaCy's NER and merged into single tokens before being fed to the model. Four model variants are trained: PGM, PGM with coverage mechanism, NER-enhanced PGM, and NER-enhanced PGM with coverage. The models are evaluated on the CSPubSumm dataset using ROUGE-1, ROUGE-2, ROUGE-L, METEOR, and BERTScore metrics.

## Key Results
- NER-based preprocessing improves pointer-generator network performance for highlight generation
- Combining NER with coverage mechanism further enhances semantic validity and reduces repetition
- Different input types (abstract only, abstract+conclusion, introduction+conclusion) show varying performance levels

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Treating named entities as single tokens prevents their fragmentation in generated highlights
- Mechanism: NER-based tokenizer merges all tokens within a named entity into one token, ensuring decoder generates the entire entity as a coherent unit
- Core assumption: Named entities are critical for meaning and their fragmentation leads to semantic corruption
- Evidence anchors: Abstract states incorrect generation of single words within multi-word entities may corrupt meaning; section describes NER tokenization process
- Break condition: If NER model fails to recognize entities correctly or entities aren't critical for highlight meaning

### Mechanism 2
- Claim: NER-based preprocessing improves embedding quality for named entities
- Mechanism: Unified embedding for named entities captures semantic meaning more effectively than separate embeddings for component words
- Core assumption: Single unified embedding is more semantically meaningful than separate embeddings
- Evidence anchors: Abstract mentions treating named entities as single tokens; section describes passing NER-based tokens to encoder
- Break condition: If NER model is inaccurate or named entity isn't a key highlight component

### Mechanism 3
- Claim: NER-based preprocessing combined with coverage mechanism reduces repetition
- Mechanism: Coverage mechanism tracks input attention to prevent repeated generation; combined with NER ensures correct entity generation
- Core assumption: Coverage mechanism effectively prevents repetition, enhanced by NER preprocessing
- Evidence anchors: Abstract discusses incorrect generation of single words within entities; section describes augmenting models with NER features
- Break condition: If coverage mechanism is ineffective or NER model fails to recognize entities
