# Towards AGI in Computer Vision: Lessons Learned from GPT and Large Language Models

## Quick Facts
- arXiv ID: 2306.08641
- Source URL: https://arxiv.org/abs/2306.08641
- Reference count: 40
- Primary result: Proposes pipeline for advancing computer vision towards AGI through interactive 3D environments, generative pre-training, and instruction fine-tuning

## Executive Summary
This paper identifies a fundamental gap between current computer vision approaches and the success of large language models like GPT: vision lacks an interactive environment for learning. The authors argue that CV's reliance on proxy tasks (like image classification) and static datasets prevents the development of truly general vision systems. They propose a pipeline inspired by GPT's success, where vision agents learn through interaction with 3D environments, predict future frames based on their actions, and are fine-tuned with human instructions. This approach aims to unify vision tasks and enable agents to learn from exploration rather than static proxy tasks.

## Method Summary
The proposed pipeline consists of three main stages: (1) establishing abundant, fidelitous, and interactable 3D environments where vision agents can explore and interact; (2) pre-training vision agents to predict future frames based on their actions within these environments using generative objectives; and (3) fine-tuning these pre-trained agents with human instructions to accomplish various vision tasks. The method draws inspiration from GPT's chat environment, where agents learn through interaction and feedback, and attempts to map this paradigm to computer vision by creating virtual worlds where vision agents can take actions, observe consequences, and learn from experience rather than static data.

## Key Results
- Current CV approaches rely on proxy tasks that have diminishing returns for AGI progress
- Vision lacks interactive learning environments unlike NLP which benefits from chat-based interaction
- Proposed pipeline unifies vision tasks through generative pre-training and instruction fine-tuning
- Environment-based learning could enable exploration-driven development rather than proxy task optimization

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Vision models lack interactive environments for learning, unlike NLP models which learn through chat-based interaction.
- Mechanism: The paper proposes creating abundant, fidelitous, and interactable 3D environments where vision agents can explore and predict future frames based on their actions, then fine-tune with human instructions.
- Core assumption: Interactive environments are necessary for developing AGI in computer vision.
- Evidence anchors:
  - [abstract] "CV is still far from a system like GPT that naturally integrates all tasks. We point out that the essential weakness of CV lies in lacking a paradigm to learn from environments"
  - [section 4.3.2] "The CV community has taken an alternative solution which is to sample the world. It involves two major steps, namely, image/video data collection and semantic annotation."
  - [corpus] Weak - corpus neighbors focus on AGI applications but don't provide specific evidence about the environment learning mechanism.

### Mechanism 2
- Claim: GPT's success in NLP stems from establishing an environment (chat) where agents learn through interaction with humans and feedback.
- Mechanism: The paper maps GPT's components to environment elements: state=prompting mechanism, action=desired target, reward=feedback from users, suggesting CV needs similar mapping.
- Core assumption: The chat environment structure can be mapped to vision tasks.
- Evidence anchors:
  - [section 4.3.1] "GPT defined such an environment with the chat task. Note that, in a pure-text world, chat is the perfect task for an agent to learn from interaction"
  - [abstract] "We then imagine a pipeline that puts a CV algorithm (i.e., an agent) in world-scale, interactable environments, pre-trains it to predict future frames with respect to its action"
  - [corpus] Weak - corpus doesn't provide direct evidence for this specific mapping mechanism.

### Mechanism 3
- Claim: Proxy tasks in computer vision are becoming less effective for achieving AGI as models reach near-perfect performance.
- Mechanism: The paper argues that improving proxy task performance (like image classification accuracy) drives research away from AGI goals, creating a tradeoff between task performance and generalization.
- Core assumption: Proxy tasks are inadequate for measuring progress toward AGI in vision.
- Evidence anchors:
  - [section 4.3.3] "The proxy tasks have been vastly improved in the past decade... Nevertheless, many research papers have been still pursuing higher accuracy on this dataset."
  - [section 4.3.3] "Let us assume that AGI of vision and perfect performance of proxy tasks are two goals in the space of algorithms. In the pre-deep learning era, CV algorithms are mostly weak, so setting the goal to be high proxy task performance is reasonable."
  - [corpus] Weak - corpus neighbors discuss AGI but don't specifically address the proxy task limitation argument.

## Architecture Onboarding

- Component map: Environment Establishment -> Generative Pre-training -> Instruct Fine-tuning -> Optional Downstream Perception
- Critical path: Establish environments → Pre-train frame prediction → Fine-tune with instructions → Optional task-specific adaptation
- Design tradeoffs: Abundance vs. fidelity in environments, computational cost of frame prediction vs. learning efficiency, instruction data collection vs. model generalization
- Failure signatures: Environment quality issues manifest as poor transfer to real-world tasks, pre-training failures show as inability to predict reasonable future frames, fine-tuning issues appear as poor instruction following
- First 3 experiments:
  1. Test frame prediction in simple 3D environments with known dynamics
  2. Evaluate instruction following in constrained environments before scaling up
  3. Compare different environment generation approaches (scanned vs. procedural) on learning efficiency

## Limitations
- Environment fidelity and scale requirements are not specified, creating uncertainty about practical implementation
- Reward structure definition for vision environments remains unclear and potentially problematic
- Computational feasibility of frame prediction at scale is not addressed, suggesting significant resource requirements

## Confidence
- High Confidence: Current CV approaches rely on proxy tasks with diminishing returns for AGI progress
- Medium Confidence: Interactive environments are necessary for CV AGI development
- Low Confidence: Specific mapping between GPT's chat environment and proposed vision environment elements

## Next Checks
1. **Environment Transfer Experiment**: Train a vision agent in a simple 3D environment (e.g., AI2-THOR kitchen) to predict future frames based on actions, then test whether this agent shows improved performance on real-world vision tasks compared to models trained only on static image datasets.

2. **Reward Signal Validation**: Design a small-scale experiment where multiple reward structures are tested in a controlled 3D environment, measuring which reward designs lead to more generalizable vision capabilities and better transfer to downstream tasks.

3. **Computational Scaling Analysis**: Conduct a pilot study measuring the relationship between environment complexity, frame prediction accuracy, and computational cost, establishing practical limits and identifying potential efficiency optimizations for the proposed approach.
