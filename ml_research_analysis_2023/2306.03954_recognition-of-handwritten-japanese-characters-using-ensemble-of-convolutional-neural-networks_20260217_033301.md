# Recognition of Handwritten Japanese Characters Using Ensemble of Convolutional Neural Networks

## Quick Facts
- arXiv ID: 2306.03954
- Source URL: https://arxiv.org/abs/2306.03954
- Reference count: 17
- Top 150 classes from K-Kanji dataset used due to class imbalance

## Executive Summary
This study presents an ensemble of three convolutional neural networks (CNNs) for recognizing handwritten Japanese characters, specifically Kanji. The approach combines three CNN architectures with distinct structures and utilizes transfer learning in one model. The ensemble achieves classification accuracies of 99.4%, 96.4%, 95.0%, and 96.4% on MNIST, K-MNIST, K-49, and K-Kanji datasets respectively. The results demonstrate the feasibility of using the proposed CNN-ensemble architecture for recognizing handwritten Japanese characters, with the ensemble outperforming individual models and providing a benchmark for future research on the challenging K-Kanji dataset.

## Method Summary
The method employs an ensemble of three CNN architectures (CNN-1, CNN-2, CNN-3) with different convolutional layer arrangements and transfer learning strategies. Each model was trained individually on four datasets: MNIST, K-MNIST, K-49, and K-Kanji. Predictions were aggregated via voting to produce the final ensemble output. The K-Kanji dataset evaluation was limited to the top 150 classes due to class imbalance.

## Key Results
- Ensemble achieved 99.4% accuracy on MNIST dataset
- Ensemble achieved 96.4% accuracy on K-MNIST dataset
- Ensemble achieved 95.0% accuracy on K-49 dataset
- Ensemble achieved 96.4% accuracy on K-Kanji dataset (top 150 classes)

- Mechanism: Each CNN uses a different convolutional layer arrangement and/or transfer learning strategy, capturing distinct aspects of character shape and structure. The voting aggregation reduces individual model bias/variance.
- Core assumption: Model diversity translates into complementary error patterns that ensemble voting can correct.

### Mechanism 2
- Claim: Transfer learning from related character datasets (MNIST, K-MNIST) accelerates convergence and boosts accuracy on target datasets (K-49, K-Kanji).
- Mechanism: Pre-trained base models in CNN-3 learn general image features (edges, curves) that transfer to more complex Japanese character datasets, reducing training time and improving performance.
- Core assumption: Feature representations useful for Latin/Hiragana digits are partially transferable to Kanji shapes.
- Evidence anchors:
  - [section] "The base model for Kanji included an additional pooling layer because of the increased sample size... This extra layer is likely the contributing factor to the great success of the Kanji transfer learning model"

### Mechanism 3
- Claim: Dataset-specific architectural tweaks (pooling layers, filter counts) accommodate character complexity and image resolution differences.
- Mechanism: CNN-3 adds average pooling for Kanji (64x64) vs smaller datasets (28x28) to reduce computational cost and manage larger feature maps; CNN-1 uses average pooling to increase generalization.
- Core assumption: Larger images benefit from more aggressive dimensionality reduction without losing discriminative detail.

- Break condition: Excessive pooling may discard fine-grained stroke details critical for character distinction.

## Architecture Onboarding

- Component map:
  - CNN-1: Conv → AvgPool → Conv → AvgPool → Conv → Flatten → Dense
  - CNN-2: Conv → Conv → AvgPool → Conv → Flatten → Dense
  - CNN-3: Base model (pre-trained) → Conv → Dropout → Conv → AvgPool → Flatten → Dense
  - Ensemble layer: Voting aggregation of CNN-1, CNN-2, CNN-3 outputs

- Critical path:
  1. Pre-train CNN-3 base model on appropriate source dataset (MNIST for K-MNIST eval, K-MNIST for K-49 eval, K-49 for K-Kanji eval).
  2. Train CNN-1, CNN-2, CNN-3 individually on target dataset.
  3. Aggregate predictions via voting to produce ensemble output.

- Design tradeoffs:
  - More complex CNN-3 base models improve accuracy but increase training time and risk overfitting on small datasets.
  - Average pooling improves generalization but may lose fine stroke details.
  - Ensemble voting simple but ignores confidence scores; weighted voting could be more nuanced but requires calibration.

- Failure signatures:
  - Low ensemble improvement over individual models: indicates insufficient diversity or overfitting across CNNs.
  - Degraded performance when adding CNN-3: suggests poor transfer learning fit or data mismatch.
  - High variance in individual CNN accuracies: indicates instability or need for regularization.

- First 3 experiments:
  1. Train and evaluate CNN-1 alone on K-MNIST; record accuracy and training time.
  2. Train CNN-3 with transfer learning from MNIST on K-MNIST; compare performance and training time to CNN-1.
  3. Build ensemble of CNN-1 and CNN-3; verify accuracy improvement and analyze voting patterns.
