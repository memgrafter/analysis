# Few-shot Unified Question Answering: Tuning Models or Prompts?

## Quick Facts
- arXiv ID: 2305.14569
- Source URL: https://arxiv.org/abs/2305.14569
- Authors: Yunmo Chen, Priyang Agarwal, Shuohang Wang, Chenguang Zhu
- Reference count: 40
- Primary result: Prompt tuning with proper initialization performs as well as model tuning in few-shot unified QA scenarios

## Executive Summary
This paper presents a comprehensive comparison between model-tuning and prompt-tuning paradigms for unified question answering under low-resource settings. The authors evaluate these approaches across 16 diverse QA datasets spanning different domains and reasoning skills. Through extensive experimentation with 7 different tuning paradigms, they demonstrate that prompt tuning can achieve performance parity with model tuning when provided with appropriate initialization strategies. The study reveals nuanced trade-offs between the two paradigms, showing that parameter-sharing techniques benefit few-shot learning but can degrade performance in full-shot scenarios, while pre-training significantly enhances prompt tuning effectiveness in low-resource regimes.

## Method Summary
The study evaluates seven different tuning paradigms for unified QA, including standard fine-tuning, multi-task fine-tuning with parameter sharing, and various prompt tuning approaches. Using T5-base as the backbone, the authors pretrain on diverse source datasets before evaluating on target datasets with varying shot sizes (16 to 1024 examples). Prompt initialization strategies include random initialization, format-based selection, and complete-set selection using similarity metrics. The evaluation covers multiple QA formats including extractive, abstractive, multiple-choice, and yes/no questions, measuring performance through F1 scores and accuracy metrics.

## Key Results
- Prompt tuning achieves parity with model tuning in few-shot settings when using proper initialization
- Parameter-sharing improves few-shot performance but degrades results in full-shot scenarios
- Simple prompt initialization methods (format-based) perform as well as complex approaches (complete-set selection)
- Pre-training significantly boosts prompt tuning performance in low-resource regimes

## Why This Works (Mechanism)

### Mechanism 1
Prompt tuning captures task-specific knowledge through soft prompts without modifying underlying model parameters, enabling efficient adaptation. When initialized from semantically similar tasks, the prompt space starts close to optimal solutions, reducing optimization burden in low-data regimes. This works because the prompt initialization method effectively transfers relevant knowledge from source to target tasks.

### Mechanism 2
Parameter sharing improves few-shot learning by transferring knowledge from high-resource to low-resource tasks, but degrades in full-shot scenarios due to negative interference from unrelated tasks. The mechanism involves conflicting gradients when task distributions overlap insufficiently, causing performance degradation as more data becomes available.

### Mechanism 3
Pre-training provides strong inductive bias by exposing models to varied formats and reasoning skills, creating generalizable representations. This benefits prompt tuning more than model tuning because prompts can better leverage diverse knowledge encoded in pre-trained models, particularly when source tasks cover broad domains relevant to targets.

## Foundational Learning

  - Quick check question: What is the primary challenge when training models with only a handful of examples per task?

- Concept: Parameter-efficient tuning
  - Why needed here: The comparison between model tuning (updates all parameters) and prompt tuning (updates only soft prompt tokens) requires understanding trade-offs in computational efficiency and effectiveness
  - Quick check question: How does updating only a small fraction of model parameters affect training speed and memory usage compared to full fine-tuning?

- Concept: Knowledge transfer and negative interference
  - Why needed here: The paper investigates how sharing parameters or prompts across tasks can either help (knowledge transfer) or hurt (negative interference) model performance depending on data regime
  - Quick check question: Under what conditions does multi-task learning improve performance, and when does it degrade it?

## Architecture Onboarding

- Component map:
  Pre-trained language model (T5-base) -> Soft prompt tokens (k=100 tokens, d=768) -> Prompt initialization module -> Attention-based prompt transfer module -> Training loop with parameter freezing strategies

- Critical path:
  1. Load pre-trained model and initialize soft prompts
  2. Select initialization strategy (random, format-based, or complete-set)
  3. Train soft prompts while freezing model parameters
  4. Evaluate on target datasets and select best checkpoint
  5. Analyze performance across different shot settings

- Design tradeoffs:
  Prompt tuning vs model tuning: Parameter efficiency vs potential performance ceiling
  Format-based vs complete-set initialization: Simplicity vs potential for better cross-format transfer
  Shared vs task-specific attention modules: Scalability vs risk of negative interference

- Failure signatures:
  Prompt tuning fails to converge: Likely due to poor initialization or insufficient similarity between source and target tasks
  Model tuning overfits in few-shot: Indicates need for regularization or parameter-efficient alternatives
  Multi-task training shows negative interference: Suggests task incompatibility or need for better task balancing

## Open Questions the Paper Calls Out

### Open Question 1
How does the effectiveness of prompt tuning scale with larger model sizes beyond T5-Large (e.g., T5-3B, T5-11B)? The paper only tested T5-base and T5-large due to computational constraints, leaving the trend with extremely large models unknown.

### Open Question 2
How well do the findings generalize to cross-lingual and cross-modal question answering scenarios? All experiments used English QA datasets, so effectiveness for non-English languages or other modalities remains unexplored.

### Open Question 3
What is the impact of using alternative prompt injection methods and knowledge transfer approaches? The study only examined one prompt injection method and two knowledge transfer approaches, missing recent alternatives like Liu (2022) and Zhong et al. (2022a).

## Limitations
- Experiments limited to English QA datasets, hindering generalizability to cross-lingual and cross-modal scenarios
- Only two model sizes tested (T5-base and T5-large) due to computational constraints
- Evaluation focused on a limited number of prompt-tuning and knowledge transfer methods

## Confidence

**High Confidence**: Pre-training significantly improves performance in low-resource settings - well-supported by experimental results and aligned with established transfer learning literature.

**Medium Confidence**: Prompt tuning matches model tuning in few-shot scenarios with good initialization - supported by results but dependent on initialization quality, introducing variability.

**Low Confidence**: Explanation for why parameter sharing helps in few-shot but hurts in full-shot settings - while the trend is observed, the mechanistic details and specific conditions for negative interference are not thoroughly explored.

## Next Checks

1. **Initialization Robustness Test**: Systematically vary the number of source prompts used for initialization (1, 3, 5, 10) and measure impact on target task performance across different similarity levels between source and target tasks.

2. **Negative Interference Analysis**: Design experiments that control for task similarity in multi-task settings, measuring performance degradation as a function of task dissimilarity and dataset size to understand mechanisms behind negative interference.

3. **Cross-Domain Generalization**: Evaluate proposed methods on QA datasets from domains not represented in the original 16 datasets to test generalizability of findings about prompt tuning and parameter sharing across different application areas.
