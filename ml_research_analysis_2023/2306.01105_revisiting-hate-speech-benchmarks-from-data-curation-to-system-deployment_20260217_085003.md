# Revisiting Hate Speech Benchmarks: From Data Curation to System Deployment

## Quick Facts
- arXiv ID: 2306.01105
- Source URL: https://arxiv.org/abs/2306.01105
- Reference count: 40
- Introduces GOTHate, a 51k tweet, code-mixed, neutrally-seeded dataset spanning seven socio-political topics and three languages for hate speech detection.

## Executive Summary
This work addresses limitations in current hate speech detection benchmarks by introducing GOTHate, a large-scale, code-mixed dataset of 51k tweets across seven socio-political topics and three languages. Unlike existing benchmarks that rely on hate lexicons, GOTHate captures nuanced hate speech dynamics using diverse topics and linguistic variation. The authors propose HEN-mBERT, a modular mixture-of-experts model that enhances multilingual BERT with endogenous signals (user timeline history, ego network topology, and exemplar-based similarity) via cross-modal attention. HEN-mBERT improves macro-F1 by 2.5% and hate class F1 by 5% over the best baseline, demonstrating that auxiliary signals significantly boost detection performance, particularly for hard-to-classify classes like hate and provocation.

## Method Summary
The study introduces GOTHate, a 51k tweet dataset spanning seven socio-political topics and three languages, curated using a neutrally-seeded approach to avoid bias from hate lexicons. The dataset is designed to capture code-mixing and linguistic complexity, making it more challenging to classify than existing benchmarks. The authors propose HEN-mBERT, a modular mixture-of-experts model that enhances multilingual BERT with endogenous signals—user timeline history, ego network topology, and exemplar-based similarity—via cross-modal attention. The model is trained and evaluated on the GOTHate dataset, with performance measured using macro-F1 and hate class F1 scores.

## Key Results
- GOTHate dataset: 51k tweets across three languages and seven socio-political topics.
- HEN-mBERT improves macro-F1 by 2.5% and hate class F1 by 5% over the best baseline.
- Auxiliary signals (user timeline, ego network, exemplar similarity) significantly boost detection performance, especially for hate and provocation classes.

## Why This Works (Mechanism)
The paper demonstrates that hate speech detection can be significantly improved by incorporating auxiliary signals beyond text content. HEN-mBERT leverages user timeline history, ego network topology, and exemplar-based similarity through cross-modal attention to capture contextual and behavioral cues. This approach addresses the limitations of traditional lexicon-based methods, which struggle with code-mixing and nuanced hate speech. The modular mixture-of-experts architecture allows the model to dynamically weight these signals, enhancing its ability to classify complex hate speech patterns.

## Foundational Learning
- **Code-mixing**: Mixing of multiple languages in a single utterance; needed to handle real-world linguistic diversity; quick check: verify dataset includes code-mixed examples.
- **Cross-modal attention**: Mechanism to align different input modalities (text, user data, network features); needed to integrate auxiliary signals; quick check: confirm attention weights are interpretable.
- **Ego network topology**: Structural features of a user's immediate social connections; needed to capture contextual influence; quick check: validate network features are informative.
- **Neutrally-seeded dataset curation**: Avoiding bias from hate lexicons by starting with neutral seeds; needed to ensure dataset representativeness; quick check: audit seed selection process.

## Architecture Onboarding
- **Component map**: Text features -> mBERT -> Cross-modal attention -> User timeline/ego network/exemplar signals -> HEN-mBERT -> Output
- **Critical path**: Text features → mBERT → Cross-modal attention → Auxiliary signals → HEN-mBERT → Classification
- **Design tradeoffs**: Modular mixture-of-experts allows dynamic weighting of signals but increases model complexity; cross-modal attention improves context understanding but requires careful alignment of modalities.
- **Failure signatures**: Poor performance on code-mixed examples, failure to generalize to new platforms, or overfitting to user-specific patterns.
- **First experiments**: 1) Test model on hate speech datasets from other platforms (e.g., Reddit, Facebook). 2) Conduct ablation studies to isolate the contribution of each auxiliary signal. 3) Evaluate model robustness to temporal shifts by testing on tweets from 2024.

## Limitations
- Dataset validation limited to Twitter data from 2021-2023, which may not generalize to newer platforms or emerging linguistic trends.
- Incremental performance gains (2.5% macro-F1, 5% hate class F1) suggest room for further improvement.
- Absence of cross-platform validation introduces uncertainty about external validity.

## Confidence
- Dataset quality: Medium-High (semi-automated pipeline with Wipro AI, neutrality seeding)
- Model performance: Medium (architectural improvements are sound but gains are incremental)
- External validity: Low (no cross-platform or temporal validation)
