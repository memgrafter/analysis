# Joint 2D-3D Multi-Task Learning on Cityscapes-3D: 3D Detection, Segmentation, and Depth Estimation

## Quick Facts
- arXiv ID: 2304.00971
- Source URL: https://arxiv.org/abs/2304.00971
- Reference count: 4
- Key outcome: TaskPrompter framework outperforms single-task methods on 3D detection and depth estimation while maintaining competitive semantic segmentation performance

## Executive Summary
This paper introduces MTCityscapes-3D, a new multi-task benchmark combining monocular 3D vehicle detection, semantic segmentation, and depth estimation on the Cityscapes-3D dataset. The authors propose TaskPrompter, an innovative multi-task prompting framework that unifies task-generic representations, task-specific representations, and cross-task interactions through a single module. This approach eliminates manual module design and significantly enhances representation learning capabilities. The framework demonstrates state-of-the-art performance on challenging 3D detection and depth estimation tasks while showing competitive results on semantic segmentation.

## Method Summary
The authors present TaskPrompter, a multi-task prompting framework designed to unify learning across different perception tasks. The framework integrates task-generic representations (shared across all tasks), task-specific representations (unique to each task), and cross-task interactions into a single prompting module. This eliminates the need for manually designing or intensively searching for modules tailored to different objectives. The approach leverages transformer-based architectures and is evaluated on the newly introduced MTCityscapes-3D benchmark, which requires simultaneous predictions for monocular 3D vehicle detection, semantic segmentation, and depth estimation using the Cityscapes-3D dataset.

## Key Results
- TaskPrompter outperforms state-of-the-art single-task methods on 3D detection and depth estimation tasks
- Competitive performance on semantic segmentation (2.3% mIoU drop when combined with 3D detection)
- 3D detection shows 1.6 mAP drop compared to single-task baselines
- Framework demonstrates effective adaptation to other transformer models and task sets

## Why This Works (Mechanism)
TaskPrompter's effectiveness stems from its unified prompting mechanism that simultaneously learns task-generic, task-specific, and cross-task representations. By incorporating all three types of representations into a single module, the framework enables more efficient knowledge sharing between tasks while maintaining task-specific capabilities. The prompting approach allows the model to dynamically adjust representations based on task requirements without requiring separate specialized modules for each objective.

## Architecture Onboarding

**Component Map:** Input images -> Shared encoder -> TaskPrompter module -> Task-specific heads -> 3D detection, semantic segmentation, depth estimation outputs

**Critical Path:** The TaskPrompter module is the critical component that transforms shared encoder features into task-specific representations while maintaining cross-task interactions. This module directly impacts all three downstream tasks.

**Design Tradeoffs:** The unified prompting approach reduces manual design overhead but adds computational complexity compared to separate task-specific modules. The framework prioritizes flexibility and adaptability over task-specific optimization.

**Failure Signatures:** Performance degradation in semantic segmentation (2.3% mIoU drop) when combined with 3D detection indicates task interference. The 1.6 mAP drop in 3D detection suggests the multi-task setup may not optimize for all individual tasks simultaneously.

## Limitations
- Task interference effects are evident, with semantic segmentation suffering a 2.3% mIoU drop when combined with 3D detection tasks
- 3D detection performance drops by 1.6 mAP compared to single-task baselines
- Computational overhead and complexity of TaskPrompter's prompting mechanism are not fully analyzed
- Limited experimental evidence for claims about generalizability to other transformer models and task sets
