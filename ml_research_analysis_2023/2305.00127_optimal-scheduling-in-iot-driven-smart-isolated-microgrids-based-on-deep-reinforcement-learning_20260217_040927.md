# Optimal Scheduling in IoT-Driven Smart Isolated Microgrids Based on Deep Reinforcement Learning

## Quick Facts
- arXiv ID: 2305.00127
- Source URL: https://arxiv.org/abs/2305.00127
- Reference count: 40
- Key outcome: Proposes HAFH-RDPG algorithm that integrates DQN and RDPG for optimal diesel generator scheduling in IoT-driven microgrids, outperforming benchmark algorithms in average cumulative reward and convergence speed

## Executive Summary
This paper addresses the challenge of optimal scheduling for diesel generators in isolated microgrids with uncertain renewable generation and load demand. The authors propose a novel deep reinforcement learning approach that learns optimal scheduling policies directly from historical data without requiring prediction models. The key innovation is the HAFH-RDPG algorithm that handles the discrete-continuous hybrid action space by seamlessly integrating deep Q-network (DQN) and recurrent deterministic policy gradient (RDPG) algorithms within a finite-horizon dynamic programming framework. The method is evaluated using real-world data from an IoT-driven microgrid, demonstrating superior performance in terms of average cumulative reward and convergence speed compared to benchmark algorithms.

## Method Summary
The HAFH-RDPG algorithm addresses the hybrid action space problem in microgrid scheduling by combining actor-critic (RDPG) and value-based (DQN) approaches within a finite-horizon dynamic programming framework. The method learns optimal policies from historical renewable and load data without requiring prediction models, making it robust to prediction errors. The algorithm uses backward induction over daily cycles, with LSTM layers to handle partial observability from limited state observations. The approach incorporates a spinning reserve penalty in the reward function rather than treating it as a hard constraint, allowing the agent to learn optimal reserve levels through trial and error.

## Key Results
- HAFH-RDPG outperforms benchmark algorithms in average cumulative reward and convergence speed
- The algorithm demonstrates robustness to inter-day power fluctuations without requiring prediction models
- HAFH-RDPG achieves better results than discretization-based approaches for handling the hybrid action space

## Why This Works (Mechanism)

### Mechanism 1
- Claim: HAFH-RDPG effectively handles the discrete-continuous hybrid action space by integrating DQN and RDPG within finite-horizon dynamic programming
- Mechanism: The algorithm uses actor-critic RDPG to select optimal continuous ED actions for each discrete switching action, then uses value-based DQN to select the best switching action based on evaluated ED actions
- Core assumption: Actor-critic framework can accurately approximate optimal continuous ED action for each discrete switching action
- Evidence anchors:
  - [abstract] "HAFH-RDPG seamlessly integrates two classical DRL algorithms, i.e., deep Q-network (DQN) and recurrent deterministic policy gradient (RDPG)"
  - [section IV.A] "Our algorithm adopts the actor-critic framework to calculate the optimal ED action aED k *"

### Mechanism 2
- Claim: Finite-horizon POMDP model with spinning reserve penalty enables learning optimal scheduling policies that maintain energy balance while minimizing costs
- Mechanism: Instead of hard constraints, the model incorporates penalty for energy imbalance in reward function, allowing agent to learn optimal reserve levels through trial and error
- Core assumption: Agent can effectively learn from penalty signal to balance operating costs and energy balance requirements
- Evidence anchors:
  - [abstract] "A novel partial observable Markov decision process (POMDP) model is conceived considering the spinning reserve"
  - [section III.D] "The optimization objective in the IoT-driven MG system is to minimize the operating cost within the considered time horizon"

### Mechanism 3
- Claim: Learning from historical data without prediction models makes the approach robust to prediction errors and inter-day fluctuations
- Mechanism: Direct learning from historical data avoids limitations of forecast-based approaches, with finite-horizon setting providing stability
- Core assumption: Historical data contains sufficient information to learn policies that generalize to future days with similar statistical properties
- Evidence anchors:
  - [abstract] "The DRL agent learns an optimal policy from history renewable and load data of previous days"
  - [section V.C.2] "Although the PV and load power of the current time step cannot be obtained by HAFH-RDPG, Fig. 6(g) shows that this algorithm still outperforms DDP"

## Architecture Onboarding

- Component map: POMDP Environment -> HAFH-RDPG Algorithm -> Training Pipeline -> Policy Evaluation
- Critical path:
  1. Initialize 2D actor-critic pairs and value network
  2. For each time step (backward induction): sample experience, update critic networks, update actor networks, update target networks
  3. Map simplified actions to actual DG switching decisions
- Design tradeoffs:
  - Hybrid action space handling: RDPG+DQN integration vs. discretization (accuracy vs. complexity)
  - Historical data length: Longer windows provide more information but increase computational complexity
  - DG selection strategy: Priority-based mapping reduces complexity but may not always find global optimum
- Failure signatures:
  - Convergence issues: Oscillating or non-improving performance during training
  - Suboptimal policies: High spinning reserve costs or frequent DG switching
  - Computational bottlenecks: Training time exceeding practical limits for real-time deployment
- First 3 experiments:
  1. Verify basic functionality: Train on simple synthetic data with known optimal policy
  2. Test hybrid action handling: Compare performance with discretized action space baseline
  3. Evaluate robustness: Train on one day's data and test on slightly different day patterns

## Open Questions the Paper Calls Out

## Limitations
- Parameter sensitivity: Algorithm performance depends heavily on careful hyperparameter tuning without systematic sensitivity analysis
- Data dependency: Performance may degrade if future conditions significantly differ from training data patterns
- Computational complexity: Training 2D actor-critic pairs may become prohibitive with increasing numbers of DGs

## Confidence

- High confidence: Algorithm successfully handles hybrid action space through RDPG-DQN integration
- Medium confidence: Claim of robustness to inter-day fluctuations supported by limited test data
- Medium confidence: Avoidance of prediction models is valid for training approach
