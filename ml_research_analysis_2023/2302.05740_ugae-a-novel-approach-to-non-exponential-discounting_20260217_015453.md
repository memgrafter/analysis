# UGAE: A Novel Approach to Non-exponential Discounting

## Quick Facts
- arXiv ID: 2302.05740
- Source URL: https://arxiv.org/abs/2302.05740
- Reference count: 40
- This paper introduces UGAE, enabling non-exponential discounting in modern RL algorithms

## Executive Summary
This paper presents Universal Generalized Advantage Estimation (UGAE), a method that reformulates Generalized Advantage Estimation to work with arbitrary discounting mechanisms beyond traditional exponential discounting. UGAE overcomes the limitations of exponential discounting by introducing a vectorized formulation that accepts any discount vector. The authors propose Beta-weighted discounting, a novel approach using Beta distribution moments to interpolate between exponential and hyperbolic discounting. Experimental results demonstrate that UGAE with Beta-weighted discounting outperforms Monte Carlo advantage estimation on standard RL benchmarks while maintaining computational efficiency comparable to standard GAE.

## Method Summary
UGAE reformulates GAE to accept arbitrary discount vectors rather than being limited to exponential discounting. It replaces the recursive computation with a vectorized formulation using Hadamard products and scalar products, computing advantages as -V(st) + (λλλ ⊙ ΓΓΓ)·rrrt + (1-λ)(λλλ ⊙ ΓΓΓ')·VVVt+1 where Γ(t) is any arbitrary discount function. Beta-weighted discounting provides a continuous interpolation between exponential and hyperbolic discounting through Beta distribution moments. The method is designed to be simple to integrate into existing advantage-based algorithms like PPO.

## Key Results
- UGAE with Beta-weighted discounting outperforms Monte Carlo advantage estimation on standard RL benchmarks
- The method achieves significant performance improvements in tasks like Inverted Double Pendulum and Humanoid Standup
- Computational efficiency remains comparable to standard GAE despite the more flexible discounting mechanism

## Architecture Onboarding

- Component map:
  - Environment interaction -> UGAE function -> Policy gradient algorithm -> Policy update

- Critical path:
  1. Environment generates trajectory (states, actions, rewards)
  2. UGAE computes advantages using arbitrary discount vector
  3. Policy gradient algorithm uses advantages for policy update
  4. Process repeats for multiple iterations

- Design tradeoffs:
  - Computational complexity: UGAE increases from O(T) to O(LT) where L is truncation length
  - Flexibility vs. simplicity: UGAE enables arbitrary discounting but adds implementation complexity
  - Parameter tuning: Beta-weighted discounting adds η parameter but provides more control over temporal preferences

- Failure signatures:
  - Numerical instability when discount vectors contain very small values
  - Poor performance if η parameter is poorly chosen (too close to 0 or 1)
  - Increased computation time for very long episodes (>10^4 steps)

- First 3 experiments:
  1. Replace standard GAE with UGAE using exponential discounting (η=0) to verify correctness
  2. Test Beta-weighted discounting with η=1 (hyperbolic) on a simple environment to observe behavior differences
  3. Compare UGAE performance with Monte Carlo baseline on Inverted Double Pendulum environment
