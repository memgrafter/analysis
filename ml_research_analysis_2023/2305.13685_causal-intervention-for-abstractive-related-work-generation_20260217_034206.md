# Causal Intervention for Abstractive Related Work Generation

## Quick Facts
- **arXiv ID:** 2305.13685
- **Source URL:** https://arxiv.org/abs/2305.13685
- **Reference count:** 12
- **Primary result:** Proposes a causal intervention module that outperforms state-of-the-art approaches on related work generation tasks by addressing spurious correlations

## Executive Summary
This paper addresses the problem of spurious correlations in abstractive related work generation by introducing a causal intervention module. The authors model the relationships between sentence order, document relation, and transitional content using a causal graph, then apply do-calculus to derive conditional probabilities and identify causal effects. The proposed method, which fuses this causal intervention with a Transformer architecture, demonstrates superior performance on two real-world datasets compared to existing approaches. The work contributes both a novel theoretical framework for handling spurious correlations in text generation and practical improvements in generating coherent related work sections.

## Method Summary
The method introduces a Causal Intervention Module (CaM) that integrates with Transformer to generate related work with improved quality and coherence. The approach models sentence order (c), document relation (x), and transitional content (y) as a causal graph, then uses do-calculus to cut the spurious correlation path c → x. The implementation involves three key components: Primitive Intervention applies do-calculus to remove spurious paths; Context-aware Remapping smooths intervened embeddings using sliding window and multi-head attention; and Optimal Intensity Learning dynamically balances contributions from original, intervened, and remapped embeddings through learned sigmoid weights. The model is trained with cross-entropy loss and evaluated on two datasets derived from S2ORC and Delve.

## Key Results
- The proposed method outperforms state-of-the-art approaches on two real-world datasets for related work generation
- Ablation studies show that the Causal Intervention Module contributes significantly to performance improvements
- The method demonstrates effectiveness in generating more coherent and high-quality related work sections compared to baseline Transformer models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Causal intervention using do-calculus removes spurious correlations by cutting off the path c → x in the causal graph
- Mechanism: The method models sentence order (c), document relation (x), and transitional content (y) as a causal graph. By applying do-calculus and backdoor criterion, it cuts off the confounder path c → x, allowing the model to focus on genuine causalities c → y and x → y
- Core assumption: Sentence order acts as a confounder that induces spurious correlations with transitional content, and removing this path will improve generation quality
- Evidence anchors: [abstract] "Then, to implement the causal intervention and mitigate the negative impact of spurious correlations, we use do-calculus to derive ordinary conditional probabilities and identify causal effects through CaM."

### Mechanism 2
- Claim: Context-aware remapping smooths intervened embeddings and preserves contextual information
- Mechanism: After primitive intervention, embeddings may be disjointed. Context-aware remapping uses a sliding window and multi-head attention to update embeddings while preserving the intervened ones, ensuring smooth information flow
- Core assumption: Intervention on individual words damages context, and remapping can recover contextual smoothness without losing causal information
- Evidence anchors: [section 3.2.2] "Intervention on individual words may damage the context along with the order-enhanced embedding. To solve these two problems, we propose the Context-aware Remapping mechanism."

### Mechanism 3
- Claim: Optimal intensity learning dynamically balances contributions from original, intervened, and remapped embeddings
- Mechanism: The model learns sigmoid-based weights for each embedding type and uses softmax to create a weighted sum, allowing the model to adaptively choose the best combination
- Core assumption: Not all interventions are beneficial; optimal weighting improves robustness, especially when combined with pre-trained models
- Evidence anchors: [section 3.2.3] "To guarantee performance improvement, we propose Optimal Intensity Learning."

## Architecture Onboarding

- Component map: Reference abstracts -> Primitive Intervention -> Context-aware Remapping -> Optimal Intensity Learning -> Transformer decoder -> Generated related work
- Critical path:
  1. Encode reference abstracts
  2. Generate sentence-start word masks
  3. Apply Primitive Intervention to masked positions
  4. Apply Context-aware Remapping to smooth embeddings
  5. Apply Optimal Intensity Learning to fuse embeddings
  6. Feed to Transformer decoder for final generation
- Design tradeoffs:
  - Intervening only on sentence-start words limits scope but ensures focus on transitions
  - Using fixed window size (nw) for remapping may miss long-range dependencies
  - Optimal intensity adds parameters but improves adaptability
- Failure signatures:
  - Performance drop when test set distribution differs significantly from training
  - Over-smoothing embeddings leading to loss of specificity
  - Learned weights collapsing to one extreme (all original or all intervened)
- First 3 experiments:
  1. Ablation study: Remove each CaM component (PI, RMP, OPT) and compare ROUGE scores
  2. Robustness test: Randomly reorder reference papers and measure coherence preservation
  3. Fusing strategy: Vary number of CaM modules inserted into Transformer and find optimal placement

## Limitations

- The causal modeling approach relies heavily on the assumed causal graph structure, which is not empirically validated through ablation studies
- The effectiveness of the intervention depends on sentence order being a genuine confounder, yet no experiments test this assumption directly
- The individual contributions of Context-aware Remapping and Optimal Intensity Learning to performance gains are not clearly isolated through ablation evidence

## Confidence

- **High confidence:** The overall experimental methodology and dataset construction appear sound, with appropriate metrics (ROUGE) and human evaluation protocols
- **Medium confidence:** The causal intervention concept is theoretically grounded, but its practical implementation details (specific do-calculus computation) are underspecified
- **Low confidence:** The individual contributions of Context-aware Remapping and Optimal Intensity Learning to the reported performance improvements are not clearly isolated through ablation studies
