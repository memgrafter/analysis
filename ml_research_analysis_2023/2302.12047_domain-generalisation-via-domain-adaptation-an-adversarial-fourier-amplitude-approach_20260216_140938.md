# Domain Generalisation via Domain Adaptation: An Adversarial Fourier Amplitude Approach

## Quick Facts
- arXiv ID: 2302.12047
- Source URL: https://arxiv.org/abs/2302.12047

- Reference count: 40

## Executive Summary
This paper proposes AGFA (Adversarial Generalized Fourier Amplitude), a novel approach to domain generalization that combines Fourier amplitude image synthesis with Bayesian maximum classifier discrepancy. The method generates adversarial Fourier amplitude images that preserve semantic content while altering style, then combines these with source domain phase images to create challenging target domains. By training models to be robust to these worst-case domains using a supervised MCD objective, AGFA significantly improves generalization performance across multiple benchmark datasets.

## Method Summary
AGFA addresses domain generalization by generating synthetic target domains through adversarial Fourier amplitude synthesis. The approach uses a Fourier transform to separate source images into phase (semantic) and amplitude (style) components, then generates adversarial amplitude images that maximize classifier discrepancy while preserving semantic content through the phase component. The method employs Bayesian hypothesis modeling to compute maximum classifier discrepancy without requiring target domain data, and modifies MCD to incorporate induced target class labels for supervised learning. The model is trained using an alternating optimization scheme between minimizing the ELBO loss with supervised MCD and maximizing MCD through the adversarial amplitude generator.

## Key Results
- Achieves 68.0% average accuracy on DomainBed benchmark across five datasets
- Outperforms previous best method (SWAD) by 1.1 percentage points
- Shows consistent improvements across all tested datasets: PACS (89.1%), VLCS (74.8%), OfficeHome (69.8%), TerraIncognita (54.8%), and DomainNet (44.3%)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Adversarial Fourier amplitude synthesis preserves semantic content while creating challenging style variations for robust learning.
- Mechanism: The method generates amplitude images adversarially and combines them with phase images from source domains. Since phase spectra capture semantic information while amplitude spectra capture style, this approach maintains semantic consistency while introducing diverse style variations.
- Core assumption: Fourier phase spectra primarily capture image semantics while amplitude spectra primarily capture style information.
- Evidence anchors:
  - [abstract]: "we generate Fourier amplitude images and combine them with source domain phase images, exploiting the widely believed conjecture from signal processing that amplitude spectra mainly determines image style, while phase data mainly captures image semantics."
  - [section]: "the widely believed conjecture from signal processing that amplitude spectra mainly determines image style, while phase data mainly captures image semantics."
  - [corpus]: Weak evidence - no direct corpus support for this specific Fourier phase/amplitude semantic separation claim.
- Break condition: If the phase/amplitude semantic separation conjecture is invalid, the method would fail to preserve semantic content during adversarial amplitude synthesis.

### Mechanism 2
- Claim: Bayesian hypothesis modeling enables tractable computation of Maximum Classifier Discrepancy (MCD) for domain generalization.
- Mechanism: The approach models the hypothesis space as a posterior distribution over classifiers given source domains, allowing MCD computation without requiring target domain data.
- Core assumption: The Bayesian posterior distribution over classifiers can effectively represent the model hypothesis space.
- Evidence anchors:
  - [abstract]: "By Bayesian hypothesis modeling, we express the model hypothesis space effectively as a posterior distribution over classifiers given the source domains, making adversarial MCD minimisation feasible."
  - [section]: "we adopt the Bayesian hypothesis modeling approach of (Kim et al., 2019). In the next section, we describe our approach in greater detail."
  - [corpus]: Moderate evidence - MCD is well-established in domain adaptation literature, but Bayesian formulation for DG is less common.
- Break condition: If the Bayesian approximation becomes too coarse or if the hypothesis space cannot be adequately captured by the posterior, MCD computation would lose effectiveness.

### Mechanism 3
- Claim: Supervised MCD (SMCD) loss leverages induced target domain class labels to improve learning efficiency.
- Mechanism: The method modifies traditional MCD to incorporate target domain class labels induced from phase information, enabling supervised learning on generated target data.
- Core assumption: Phase information from source domains can reliably induce correct class labels for generated target domains.
- Evidence anchors:
  - [abstract]: "we modify the MCD loss by incorporating the target class labels. In the following we provide concrete derivations using the variational posterior inference, and propose a modified MCD loss that takes into account the induced target class labels."
  - [section]: "Since the MCD loss in DA can be computed without the target domain labels (recall the definition (2)), in our DG case the class labels for the generated target data are available, as induced from the phasePS (i.e.,y =yS in step 4)."
  - [corpus]: Weak evidence - the assumption that phase information preserves class labels is not well-supported in corpus.
- Break condition: If phase information fails to preserve class labels during Fourier synthesis, the SMCD loss would train on incorrect labels.

## Limitations
- The approach relies heavily on the assumption that Fourier phase spectra capture semantic information while amplitude spectra capture style information, which lacks strong empirical validation.
- The method assumes adversarial amplitude generation can effectively create worst-case target domains without access to actual target data, which may not generalize to highly diverse scenarios.
- The claim that this approach will generalize to real-world applications with highly complex domain shifts is not well-supported by current experiments limited to benchmark datasets.

## Confidence

- **High Confidence**: The experimental results on DomainBed benchmark are reproducible and the method shows consistent improvements across multiple datasets. The theoretical framework using Bayesian hypothesis modeling and MCD is well-grounded.
- **Medium Confidence**: The Fourier-based domain synthesis approach is novel and shows promise, but the fundamental assumption about phase/amplitude separation requires further validation. The effectiveness may be dataset-dependent.
- **Low Confidence**: The claim that this approach will generalize to real-world applications with highly complex domain shifts is not well-supported by the current experiments, which are limited to relatively controlled benchmark datasets.
