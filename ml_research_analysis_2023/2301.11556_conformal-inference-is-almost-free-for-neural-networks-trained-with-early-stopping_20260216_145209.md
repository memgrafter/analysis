# Conformal inference is (almost) free for neural networks trained with early stopping

## Quick Facts
- arXiv ID: 2301.11556
- Source URL: https://arxiv.org/abs/2301.11556
- Reference count: 40
- One-line primary result: A method that combines early stopping with conformal calibration using the same hold-out data, achieving valid predictive inferences without multiple data splits or overly conservative adjustments.

## Executive Summary
This paper addresses the challenge of combining early stopping with conformal calibration to produce models that are both accurate and able to provide exact predictive inferences. The key innovation is a method that blends model training with early stopping and conformal calibration using the same hold-out data, avoiding the need for multiple data splits. This approach maintains validity through careful handling of exchangeability between test points and calibration data during the early stopping process.

The proposed Conformalized Early Stopping (CES) method is demonstrated across three tasks: outlier detection, multi-class classification, and regression. Results show CES achieves the highest true positive rate for outlier detection, smallest prediction sets for classification, and shortest prediction intervals while maintaining approximately valid conditional coverage for regression, outperforming traditional approaches that require separate data splits for calibration.

## Method Summary
CES combines early stopping with conformal calibration by storing intermediate models during training and selecting the best model using augmented loss that includes the test point exchangeably with calibration data. For regression, it computes the lower envelope of squared-error loss curves across candidate models to find optimal predictions for any test outcome. For classification, it uses all calibration data to compute conformal p-values, improving statistical efficiency compared to label-conditional approaches. The method maintains validity by ensuring the test point is included in the early stopping decision process, preserving exchangeability with calibration data.

## Key Results
- Achieves highest true positive rate for outlier detection compared to traditional conformal methods
- Produces smallest prediction sets for multi-class classification tasks
- Generates shortest prediction intervals while maintaining valid conditional coverage for regression
- Avoids multiple data splits by reusing hold-out data for both early stopping and calibration

## Why This Works (Mechanism)

### Mechanism 1
- Claim: CES achieves valid predictive inferences without extra data by reusing hold-out data for both early stopping and calibration, provided the test point is included exchangeably in the early stopping rule.
- Mechanism: The method stores intermediate models during training and selects the best one by minimizing the loss on augmented hold-out data that includes the test point. This ensures exchangeability between the test point and calibration data, preserving validity of conformal inference.
- Core assumption: Exchangeability of the test point with calibration data is maintained when the test point is included in the early stopping decision process.
- Evidence anchors: [abstract] "blends model training with early stopping and conformal calibration using the same hold-out samples"; [section] "as long as the test sample Zn+1 is also involved in the early stopping rule exchangeably with all other samples in Des-cal"
- Break condition: If exchangeability is broken—e.g., by non-random selection of test points or by non-additive loss functions—validity of conformal inference is lost.

### Mechanism 2
- Claim: CES efficiently computes the lower envelope of squared-error loss curves for regression to find the best model for any test outcome value.
- Mechanism: For each candidate model, the squared-error loss as a function of the test outcome forms a parabola. CES finds the lower envelope of these parabolas, identifying which model is optimal for each interval of possible test outcomes, and then applies conformal prediction within each interval.
- Core assumption: The loss function is quadratic in the test outcome (e.g., squared-error loss), allowing the use of geometric algorithms to compute the lower envelope efficiently.
- Evidence anchors: [section] "Each intermediate interval ˆCα(Xn+1,Bl)...can be thought of as being computed by applying, under the null hypothesis that Yn+1∈Bl, the classification method from Section 2.4"; [section] "the lower envelope of a family of parabolas [47, 48]"
- Break condition: If the loss is not quadratic (e.g., absolute error, quantile regression loss), the lower envelope computation no longer applies and alternative methods are needed.

### Mechanism 3
- Claim: For multi-class classification, CES achieves marginal coverage by computing conformal p-values using all calibration data, not just data with the same label, improving statistical efficiency.
- Mechanism: Instead of conditioning on the label for conformal calibration, CES uses the entire calibration set to compute p-values for each possible label, reducing aleatoric uncertainty and avoiding overly conservative corrections.
- Core assumption: Using a larger calibration set for p-value computation reduces variance and leads to tighter prediction sets while still maintaining marginal coverage.
- Evidence anchors: [section] "utilizes all calibration data inDes-cal to compute each conformal p-value ˆuy(Xn+1)"; [section] "conformal p-values based on a larger calibration samples are less aleatoric [24] and require less conservative finite-sample corrections"
- Break condition: If label-conditional coverage is required, this approach may produce sets that are too large or fail to cover the true label conditionally.

## Foundational Learning

- Concept: Exchangeability
  - Why needed here: The validity of conformal inference depends on the exchangeability of the test point with the calibration data. CES explicitly maintains this by including the test point in the early stopping process.
  - Quick check question: If the test point is not exchangeable with calibration data, what happens to the coverage guarantee of conformal prediction?

- Concept: Early stopping with hold-out validation
  - Why needed here: Early stopping is used to prevent overfitting by selecting a model that performs well on hold-out data. CES integrates this with conformal calibration to avoid needing separate calibration data.
  - Quick check question: Why can't we naively use the same hold-out data for both early stopping and conformal calibration without adjustment?

- Concept: Conformal prediction and p-values
  - Why needed here: Conformal prediction provides distribution-free coverage guarantees. CES constructs valid p-values by ranking the test point against calibration data under the null hypothesis.
  - Quick check question: What is the relationship between the rank of a test point among calibration nonconformity scores and its conformal p-value?

## Architecture Onboarding

- Component map: Training loop -> Early stopping selector -> Conformal calibrator -> Output generator
- Critical path:
  1. Split data into train and hold-out sets
  2. Train model, storing intermediate models
  3. For each test point, select model using augmented loss including the test point
  4. Compute nonconformity scores and p-values
  5. Generate prediction sets/intervals
- Design tradeoffs:
  - Memory vs. accuracy: Smaller τ increases memory cost but may improve model selection
  - Coverage vs. informativeness: Marginal coverage is easier to achieve than label-conditional coverage, but sets may be larger
  - Computational cost: Finding lower envelope of parabolas is O(T log T), feasible for moderate T
- Failure signatures:
  - Empty prediction intervals in regression: May occur if no model covers the test point; handled by fallback to naive method
  - Conservative prediction sets: May happen if calibration set is too small or exchangeability is weakly satisfied
  - Overfitting despite early stopping: If model capacity is too high or early stopping criterion is not effective
- First 3 experiments:
  1. Implement CES for outlier detection on synthetic data; verify FPR ≤ 0.1 and measure TPR
  2. Implement CES for multi-class classification on MNIST; compare cardinality of prediction sets to naive early stopping
  3. Implement CES for regression on UCI bike dataset; compare prediction interval widths and coverage to standard methods

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the memory cost of CES scale with the number of candidate models T and storage period τ, and what are the practical limits of this scaling in large-scale deep learning applications?
- Basis in paper: [explicit] The paper discusses that CES requires storing T candidate models, where T = ⌊tmax/τ⌋, and mentions this is not prohibitively expensive for reasonable choices of τ.
- Why unresolved: The paper does not provide empirical data on the actual memory usage or performance degradation when T becomes very large.
- What evidence would resolve it: Empirical studies showing memory usage and training/inference time as functions of T and τ for various model sizes and architectures.

### Open Question 2
- Question: Can CES be effectively extended to other loss functions beyond squared-error loss, such as the pinball loss for quantile regression or other non-standard losses?
- Basis in paper: [explicit] The paper mentions this as a potential future direction, noting that CES was implemented using classical nonconformity scores and discussing the possibility of extending to other scores.
- Why unresolved: The paper only demonstrates CES with squared-error loss and does not explore its performance with alternative loss functions.
- What evidence would resolve it: Experimental results comparing CES performance across different loss functions on various regression tasks.

### Open Question 3
- Question: How does CES perform in settings with heteroscedastic data, and can it be adapted to produce more efficient prediction intervals in such scenarios?
- Basis in paper: [explicit] The paper notes that the current implementation using classical nonconformity scores is not designed to deal efficiently with heteroscedastic data.
- Why unresolved: The paper does not provide any empirical results or theoretical analysis of CES performance on heteroscedastic data.
- What evidence would resolve it: Experiments comparing CES with heteroscedastic-aware conformal methods on datasets with known heteroscedasticity patterns.

### Open Question 4
- Question: What is the theoretical relationship between the coverage guarantees of CES and the quality of the underlying model, particularly in the regression setting?
- Basis in paper: [explicit] The paper mentions that model quality affects reliability and usefulness of conformal inferences but does not provide a theoretical framework linking model accuracy to coverage properties in CES.
- Why unresolved: While the paper proves CES provides valid coverage, it does not analyze how coverage relates to model performance metrics.
- What evidence would resolve it: Theoretical bounds or empirical studies showing how model accuracy metrics (e.g., RMSE) relate to actual coverage rates achieved by CES.

## Limitations

- Exchangeability assumption: The validity of CES critically depends on exchangeability between test points and calibration data, which may be violated in real-world scenarios with non-iid data or complex selection biases.
- Computational overhead: Storing and evaluating multiple intermediate models increases memory usage, which could become prohibitive for very deep networks or long training runs, though scaling analysis is limited.
- Fallback mechanisms: The paper mentions using naive conformal intervals as fallback for empty prediction intervals in regression, but implementation details and empirical performance of these fallbacks are not extensively discussed.

## Confidence

- High confidence: The theoretical framework for combining early stopping with conformal calibration using exchangeability principles is well-established and the paper provides rigorous proofs. The empirical demonstrations on three distinct tasks (outlier detection, multi-class classification, regression) are compelling and show consistent improvements.
- Medium confidence: The practical utility claims depend on specific implementation details (storage frequency τ, model architectures, data preprocessing) that are not fully specified in the paper. The reported improvements over baselines are significant but the exact replication setup requires assumptions.
- Low confidence: Claims about computational efficiency relative to standard conformal methods are not fully substantiated with runtime comparisons. The memory requirements for storing intermediate models across different network architectures and training regimes are not quantified.

## Next Checks

1. **Exchangeability sensitivity analysis**: Systematically test CES performance when the test point is drawn from different distributions than the calibration data (e.g., covariate shift scenarios) to quantify the robustness of the exchangeability assumption.
2. **Memory scaling benchmarks**: Measure the memory footprint of storing intermediate models for various architectures (CNN, Transformer, MLP) and training durations to establish practical limits and identify optimal storage frequencies τ.
3. **Cross-dataset generalization**: Apply CES trained on one dataset (e.g., CIFAR-10) to test data from related distributions (e.g., CIFAR-100, Tiny ImageNet) to evaluate how well the early stopping selection transfers across domains and whether conformal coverage degrades.
