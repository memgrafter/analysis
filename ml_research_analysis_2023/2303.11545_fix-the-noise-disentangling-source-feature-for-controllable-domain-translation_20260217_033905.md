# Fix the Noise: Disentangling Source Feature for Controllable Domain Translation

## Quick Facts
- **arXiv ID:** 2303.11545
- **Source URL:** https://arxiv.org/abs/2303.11545
- **Reference count:** 40
- **Primary result:** Single-model controllable domain translation through noise-fixed feature disentanglement

## Executive Summary
This paper addresses the limitation of existing domain translation methods that require multiple models or have restricted control steps by introducing a single-model approach for controllable translation. The key innovation is preserving source features within a disentangled subspace of the target feature space by fixing noise input during feature matching. This enables smooth control over the degree of source feature preservation through noise interpolation. The method demonstrates superior performance compared to prior works on FFHQ → MetFaces and other domain pairs, achieving better FID scores and smoother visual interpolation.

## Method Summary
The proposed method uses a single generator model with noise-fixing mechanism to enable controllable domain translation. During training, the model learns to disentangle source and target features by matching features while keeping noise fixed, creating a structured feature space where source characteristics can be preserved or removed through interpolation. The generator takes both source and target domain images as input along with noise vectors, and during inference, interpolation between different noise vectors controls the degree of source feature preservation in the translated output.

## Key Results
- Achieves FID of 19.68 on FFHQ → MetFaces when α=0 (target only)
- Achieves LPIPS of 0.536 on FFHQ → MetFaces when α=1 (source only)
- Outperforms competing methods in both visual quality and smooth interpolation across domain pairs

## Why This Works (Mechanism)
The method works by creating a disentangled feature space where source and target domain characteristics are separated. By fixing noise during feature matching during training, the model learns to encode source-specific information in a structured manner that can be controlled through noise interpolation during inference. This noise-fixing mechanism acts as a regularizer that forces the model to learn meaningful feature separations rather than conflating domain characteristics.

## Foundational Learning
- **Feature disentanglement:** Separating different characteristics (style, content, domain) into distinct subspaces - needed for controllable translation where different aspects should be independently modifiable
- **Noise injection in GANs:** Using stochastic noise vectors as input to generators - needed to introduce variability and enable interpolation-based control
- **Feature matching loss:** Minimizing distance between features of real and generated images - needed to stabilize training and ensure realistic outputs
- **Domain translation vs domain transfer:** Translation preserves domain characteristics while transfer changes them - needed to understand the controllability objective
- **Interpolation in latent space:** Linearly interpolating between latent vectors - needed to achieve smooth control over translation degree

## Architecture Onboarding

**Component map:** Source Image + Noise -> Generator -> Feature Extractor -> Loss Computation -> Updated Generator

**Critical path:** During training, source and target images are encoded with fixed noise vectors, features are extracted and matched, losses are computed and backpropagated to update the generator weights.

**Design tradeoffs:** Single-model approach trades off some performance potential for flexibility and reduced model complexity compared to multi-model approaches.

**Failure signatures:** Loss of source feature preservation at extreme interpolation values, mode collapse if noise fixing is too restrictive, or feature space entanglement if matching is insufficient.

**First experiments:** 1) Test interpolation behavior at different alpha values on a simple domain pair 2) Conduct ablation study removing noise fixing to observe feature entanglement 3) Evaluate feature preservation quality using LPIPS metrics across the interpolation spectrum

None

## Limitations
- Limited theoretical justification for why noise fixing preserves source features
- Performance metrics presented without statistical significance testing
- Comparison limited to only three domain pairs

## Confidence

**High confidence:** Empirical superiority over baseline methods on tested domain pairs, technical feasibility of the noise-fixing approach, visual quality of generated samples

**Medium confidence:** Claim of achieving "smooth" control across interpolation steps, generalization to unseen domain pairs, robustness to different noise distributions

**Low confidence:** Theoretical understanding of noise-fixing mechanism, behavior at extreme alpha values, scalability to domains with complex feature relationships

## Next Checks

1. Conduct ablation studies systematically varying noise dimensionality and distribution to determine sensitivity of feature preservation to these hyperparameters

2. Perform user studies measuring perceptual consistency of source feature preservation across the interpolation spectrum, comparing against objective metrics

3. Test the method on additional domain pairs with varying degrees of semantic overlap (e.g., artistic styles, seasonal variations) to assess generalizability beyond the three presented cases
