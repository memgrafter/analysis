# Kernel Support Vector Machine Classifiers with the $\ell_0$-Norm Hinge Loss

## Quick Facts
- arXiv ID: 2306.13991
- Source URL: https://arxiv.org/abs/2306.13991
- Reference count: 39
- Key outcome: This paper develops a kernel support vector machine (KSVM) classifier using the $\ell_0$-norm hinge loss, called $\ell_0$-KSVM. The $\ell_0$-norm hinge loss is a nonconvex and nonsmooth function that can overcome the sensitivity to label noise and instability for resampling in standard hinge loss. The authors first characterize the limiting subdifferential of the $\ell_0$-norm hinge loss and derive the equivalent relationship among the proximal stationary point, the Karush-Kuhn-Tucker point, and the local optimal solution of $\ell_0$-KSVM. Secondly, they develop an ADMM algorithm for $\ell_0$-KSVM and prove that any limit point of the sequence generated by the proposed algorithm is a locally optimal solution. ## Executive Summary
This paper proposes a novel kernel support vector machine (KSVM) classifier using the $\ell_0$-norm hinge loss, called $\ell_0$-KSVM. The $\ell_0$-norm hinge loss is a nonconvex and nonsmooth function that can overcome the sensitivity to label noise and instability for resampling in standard hinge loss. The authors first characterize the limiting subdifferential of the $\ell_0$-norm hinge loss and derive the equivalent relationship among the proximal stationary point, the Karush-Kuhn-Tucker point, and the local optimal solution of $\ell_0$-KSVM. Secondly, they develop an ADMM algorithm for $\ell_0$-KSVM and prove that any limit point of the sequence generated by the proposed algorithm is a locally optimal solution. Lastly, the experiments on synthetic and real datasets show that $\ell_0$-KSVM can achieve comparable accuracy compared with the standard KSVM while the former generally enjoys fewer support vectors.

## Method Summary
The paper develops $\ell_0$-KSVM by formulating the problem as a nonconvex optimization problem with $\ell_0$-norm hinge loss. The authors characterize the limiting subdifferential of the $\ell_0$-norm hinge loss and derive the equivalent relationship among the proximal stationary point, the Karush-Kuhn-Tucker point, and the local optimal solution. They then develop an ADMM algorithm to solve the $\ell_0$-KSVM problem and prove that any limit point of the sequence generated by the proposed algorithm is a locally optimal solution. The algorithm is tested on both synthetic and real datasets, demonstrating comparable accuracy to standard KSVM while using fewer support vectors.

- Core assumption: The $\ell_0$-norm hinge loss can be optimized effectively despite being nonconvex and nonsmooth.
