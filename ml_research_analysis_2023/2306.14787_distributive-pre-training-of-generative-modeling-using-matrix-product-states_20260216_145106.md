# Distributive Pre-Training of Generative Modeling Using Matrix-Product States

## Quick Facts
- arXiv ID: 2306.14787
- Source URL: https://arxiv.org/abs/2306.14787
- Reference count: 33
- One-line primary result: Parallel compression algorithm achieves >95% test accuracy on MNIST using compressed MPS states despite small overlap with exact states

## Executive Summary
This paper introduces a parallel pre-training algorithm for matrix product state (MPS) models using tensor network operations. The method compresses superposition states of all training data into MPS representations with fixed bond dimension through a tree-based reduction approach. Applied to MNIST, the algorithm achieves over 95% test accuracy for classification and produces reasonable generative samples, even though compressed states have significantly smaller overlap with exact uncompressed states due to reduced entanglement.

## Method Summary
The method involves preprocessing MNIST images as continuous variable vectors, applying orthonormal feature maps to create discrete wavefunction representations, constructing superposition states for each digit class, and performing iterative tensor network compression through parallel summation and truncation operations. The resulting compressed MPS models serve as initialization for both supervised classification and unsupervised generative modeling tasks.

## Key Results
- Achieved >95% test accuracy on MNIST classification using compressed MPS states with bond dimension χ=50
- Generated reasonable MNIST samples from compressed states despite small overlap with exact wavefunctions
- Demonstrated potential exponential speedup through parallel compression algorithm compared to serial gradient descent methods
