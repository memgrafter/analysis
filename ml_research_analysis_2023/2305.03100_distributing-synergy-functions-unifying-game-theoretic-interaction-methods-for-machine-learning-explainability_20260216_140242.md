# Distributing Synergy Functions: Unifying Game-Theoretic Interaction Methods for Machine-Learning Explainability

## Quick Facts
- arXiv ID: 2305.03100
- Source URL: https://arxiv.org/abs/2305.03100
- Reference count: 40
- Primary result: The paper presents a unifying framework for game-theoretic attribution and interaction methods, showing that various existing methods are characterized by how they distribute synergy functions.

## Executive Summary
This paper develops a unifying framework for game-theoretic attribution and interaction methods in machine learning explainability. The authors demonstrate that synergy functions provide a unique accounting of all interactions between features in continuous-input settings. By analyzing how different methods distribute these synergies, they show that various existing attribution methods (Shapley Value, Integrated Gradients, etc.) are characterized by their policies for distributing synergies. The work bridges discrete game-theoretic methods with gradient-based continuous methods, revealing that gradient methods are uniquely characterized by their actions on monomials under natural continuity criteria.

## Method Summary
The authors introduce a synergy function framework based on the Möbius transform of binary functions, which decomposes any function into pure interaction components. They analyze how different attribution methods distribute these synergies through various policies: top-distributing (Shapley-Taylor), recursive (Shapley Value), and gradient-based methods (Integrated Gradients, Integrated Hessian). The framework connects discrete game-theoretic axioms with continuous gradient methods through Taylor approximation and linearity conditions. The key insight is that method selection depends on the combination of axioms imposed and the desired distribution policy for synergies.

## Key Results
- Synergy functions provide a unique full account of interactions between features in continuous-input settings
- Gradient-based methods are characterized by their actions on monomials under natural continuity criteria
- Different combinations of axioms uniquely define attribution/interaction methods, making method selection context-dependent

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The synergy function provides a unique full account of interactions between features in continuous-input settings.
- Mechanism: By using the Möbius transform of the binary function F(xS), the synergy function φS(F)(x) = a(F(x(·)))(S) decomposes any function F into pure interaction functions ΦS that vary only in features S and are zero when any feature in S takes its baseline value.
- Core assumption: F can be evaluated at all points {xS : S ⊆ N} and the Möbius transform is well-defined for these binary functions.
- Evidence anchors:
  - [abstract]: "we show that, given modest assumptions, a unique full account of interactions between features, called synergies, is possible in the continuous input setting."
  - [section 3.2]: "We turn to explicitly defining this interaction function. For a fixed x and implicit x′, note that F(xS) is a binary function."
  - [corpus]: Weak evidence - no direct citations about Möbius transforms in continuous settings.
- Break condition: If F cannot be evaluated at all xS points or the Möbius transform is not applicable to the resulting binary functions.

### Mechanism 2
- Claim: Gradient-based methods are uniquely characterized by their actions on monomials under natural continuity criteria.
- Mechanism: For analytic functions, the Taylor expansion allows any function to be approximated by polynomials. Under linearity and continuity of Taylor approximation, the interaction method is uniquely determined by how it distributes monomial functions centered at the baseline.
- Core assumption: The function class is restricted to analytic functions Cω where Taylor expansions converge uniformly.
- Evidence anchors:
  - [abstract]: "we also demonstrate that gradient-based methods are characterized by their actions on monomials, a type of synergy function"
  - [section 5.1]: "We now move to more rigorously develop the connection between gradient-based methods and to monomials. To connect the action of attributions and interactions on monomials to broader functions, we now move towards defining the notion of an interaction being continuous in F."
  - [corpus]: Weak evidence - no direct citations about continuity conditions for gradient methods.
- Break condition: If the function is not analytic or the Taylor approximation does not converge uniformly.

### Mechanism 3
- Claim: Different axiom combinations lead to unique attribution/interaction methods, making method selection context-dependent.
- Mechanism: Each set of axioms (completeness, linearity, null feature, symmetry, etc.) constrains the distribution of synergies in specific ways. Different axiom combinations produce unique methods like Shapley Value, Shapley-Taylor, Recursive Shapley, and various gradient-based methods.
- Core assumption: The axioms are internally consistent and collectively sufficient to uniquely characterize methods.
- Evidence anchors:
  - [abstract]: "We show that the combination of various criteria uniquely defines the attribution/interaction methods."
  - [section 3.4]: "Now that we have the notion of pure interactions by way of the synergy function, we comment on the interplay between axioms and synergy functions."
  - [corpus]: Moderate evidence - multiple related papers discuss axiom-based unification of attribution methods.
- Break condition: If axiom sets are inconsistent or insufficient to uniquely characterize methods.

## Architecture Onboarding

- Component map:
  Synergy function φS(F) -> Monomial distribution rules -> Axiom constraint system -> Taylor approximation module -> Baseline handling system

- Critical path:
  1. Input function F and baseline x'
  2. Compute synergy decomposition φS(F) for all S
  3. Apply chosen axiom set to constrain distribution
  4. Select method (Shapley, Shapley-Taylor, IG, etc.) based on goals
  5. Generate attributions/interactions

- Design tradeoffs:
  - Binary features vs gradient-based: Binary is simpler but less sophisticated; gradient-based can distinguish feature contributions but requires analytic functions
  - Top-distributing vs recursive: Top-distributing emphasizes k-th order interactions; recursive distributes to all subsets
  - Completeness vs other axioms: Completeness ensures full accounting but may conflict with other desirable properties

- Failure signatures:
  - Method produces zero attributions for non-zero function changes
  - Numerical instability in Taylor approximation for non-analytic functions
  - Inconsistent results when permuting feature indices (symmetry violation)
  - Non-zero interactions for features that don't affect the function (null feature violation)

- First 3 experiments:
  1. Verify synergy decomposition on F(x1,x2) = x1·x2 with baseline x' = 0
  2. Compare Shapley Value vs Integrated Gradients on monomial F(x) = x1^100·x2
  3. Test continuity condition by comparing IH on F and its Taylor approximations

## Limitations

- The framework assumes functions can be evaluated at all subset points {xS : S ⊆ N}, which becomes computationally infeasible for high-dimensional continuous functions
- Continuity conditions for gradient-based methods rely on uniform convergence of Taylor approximations, which may not hold for all analytic functions
- The claim that axiom combinations uniquely define attribution methods needs more empirical validation and exploration of potential axiom conflicts

## Confidence

- Mechanism 1 (Synergy function uniqueness): Medium confidence - well-founded mathematically but assumes practical computability
- Mechanism 2 (Gradient characterization): Medium confidence - relies on strong continuity assumptions
- Mechanism 3 (Axiom uniqueness): Low confidence - theoretical claim needs more empirical validation
