# Preserving Fairness in AI under Domain Shift

## Quick Facts
- arXiv ID: 2301.12369
- Source URL: https://arxiv.org/abs/2301.12369
- Reference count: 37
- Key outcome: Algorithm preserves fairness under domain shift using Sliced Wasserstein Distance adaptation

## Executive Summary
This paper tackles the critical problem of maintaining fairness in machine learning models when input data distributions change after initial training. The authors develop an unsupervised domain adaptation algorithm that takes a pre-trained fair model and adapts it to remain fair on new, unannotated data from a shifted domain. By minimizing the Sliced Wasserstein Distance between source and target domains in a shared embedding space, the method ensures that the model's internal representation of data remains unbiased despite distributional shifts.

The proposed approach is evaluated on three widely used fairness datasets (Adult, COMPAS, and German), demonstrating effectiveness in preserving multiple fairness metrics while maintaining competitive accuracy compared to state-of-the-art fairness-preserving methods. The results show that existing fairness methods struggle with domain shift, while the proposed algorithm successfully mitigates bias introduced by distribution shifts.

## Method Summary
The authors propose an algorithm that adapts a pre-trained fair model to new, unannotated data from a shifted domain. The core mechanism uses unsupervised domain adaptation by minimizing the Sliced Wasserstein Distance between source and target domains in a shared embedding space. This approach ensures that the model's internal representation remains unbiased despite distributional shifts. The method is tested on three fairness datasets (Adult, COMPAS, and German) and demonstrates effectiveness in preserving fairness metrics while maintaining competitive accuracy compared to existing methods.

## Key Results
- Algorithm successfully preserves fairness metrics (demographic parity, equalized odds, averaged odds) under domain shift
- Maintains competitive accuracy compared to state-of-the-art fairness-preserving methods
- Demonstrates that existing fairness methods struggle with domain shift while the proposed approach effectively mitigates bias

## Why This Works (Mechanism)
The method works by aligning the feature distributions of source and target domains through Sliced Wasserstein Distance minimization. This distributional alignment ensures that the model's internal representations remain consistent across domains, preventing bias amplification when the input data distribution shifts. The unsupervised nature allows adaptation without requiring labeled data in the target domain, making it practical for real-world scenarios where labeled data may be scarce or expensive to obtain.

## Architecture Onboarding

**Component Map**: Pre-trained fair model -> Embedding layer -> Sliced Wasserstein Distance module -> Adapted model

**Critical Path**: The algorithm follows a pipeline where a pre-trained fair model's embeddings are compared against target domain embeddings using Sliced Wasserstein Distance, which then guides the adaptation process to minimize distributional differences while preserving fairness constraints.

**Design Tradeoffs**: The approach trades computational complexity for fairness preservation under domain shift. While more computationally intensive than simple fine-tuning, it provides stronger guarantees for fairness maintenance. The method also requires careful selection of embedding dimensions and distance thresholds.

**Failure Signatures**: The algorithm may fail when the domain shift is too extreme, making distributional alignment impossible. Additionally, if the embedding space doesn't capture relevant fairness-related features, the adaptation may not effectively preserve fairness. Computational bottlenecks can occur with very high-dimensional embeddings.
