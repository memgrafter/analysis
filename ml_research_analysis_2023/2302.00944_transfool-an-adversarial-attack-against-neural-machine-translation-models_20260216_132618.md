# TransFool: An Adversarial Attack against Neural Machine Translation Models

## Quick Facts
- arXiv ID: 2302.00944
- Source URL: https://arxiv.org/abs/2302.00944
- Reference count: 40
- Primary result: TransFool achieves state-of-the-art adversarial attack success rates against NMT models while maintaining semantic similarity and fluency

## Executive Summary
This paper introduces TransFool, a novel adversarial attack method specifically designed for Neural Machine Translation (NMT) models. The method addresses the unique challenges of attacking sequence-to-sequence models by formulating a multi-term optimization problem that balances adversarial effectiveness with semantic preservation and fluency. TransFool operates by perturbing input embeddings in continuous space and projecting them to valid tokens, enabling efficient gradient-based optimization for NMT attacks.

The key innovation lies in the integration of three loss components: an adversarial loss that maximizes translation error, a similarity constraint using language model embeddings to preserve semantic meaning, and a language model loss to ensure fluent adversarial examples. The method demonstrates effectiveness across multiple language pairs (English-French, English-German, English-Chinese) and NMT architectures, outperforming existing approaches in both white-box and black-box settings.

## Method Summary
TransFool formulates adversarial attack generation as a gradient-based optimization problem in continuous embedding space. The method uses gradient projection to iteratively perturb input tokens while ensuring they remain valid vocabulary items. The optimization balances three objectives: maximizing translation error (adversarial loss), preserving semantic similarity through language model embeddings, and maintaining fluency via language model perplexity. For black-box attacks, the method employs a substitute model fine-tuned with a linear layer to approximate the target model's behavior. The algorithm operates token-by-token, projecting perturbed embeddings to their nearest valid vocabulary items at each iteration.

## Key Results
- Achieves attack success rates of 97.2%, 95.5%, and 95.1% on En-Fr, En-De, and En-Zh translation tasks respectively
- Outperforms kNN and Seq2Sick baselines by 5-15% in attack success rate while maintaining higher semantic similarity
- Successfully attacks both transformer-based and RNN-based NMT architectures in white-box and black-box settings
- Maintains semantic similarity scores above 0.85 (using universal sentence encoder) while achieving high attack success

## Why This Works (Mechanism)
The effectiveness of TransFool stems from its careful balance of three competing objectives through gradient-based optimization. By operating in continuous embedding space, the method can leverage efficient gradient computations while the projection step ensures valid token outputs. The use of language model embeddings for semantic similarity constraint is particularly effective because it captures contextual meaning beyond simple word-level similarity. The language model loss component ensures that adversarial examples remain fluent and natural, avoiding obvious artifacts that might trigger defenses. The iterative gradient projection approach allows for fine-grained control over the perturbation process, enabling the generation of subtle yet effective adversarial examples.

## Foundational Learning

**Gradient Projection Optimization** - A technique for constrained optimization where gradients are projected onto a feasible set to maintain constraints. Needed for ensuring perturbed embeddings map to valid vocabulary items while following the optimization direction.

**Language Model Embeddings** - Vector representations from pre-trained language models used to capture semantic meaning. Required for the similarity constraint to ensure semantic preservation in adversarial examples.

**Continuous Embedding Space** - The real-valued vector space where token embeddings reside, allowing for gradient-based optimization. Essential for enabling efficient computation of adversarial perturbations.

**Token Error Rate** - A metric measuring the percentage of tokens that differ between original and adversarial translations. Used to quantify the magnitude of perturbations introduced by the attack.

**Perplexity** - A measure of language model confidence, used here to assess the fluency of generated adversarial examples. Critical for ensuring attacks produce natural-sounding text.

**Universal Sentence Encoder** - A pre-trained model that generates fixed-length sentence embeddings for semantic similarity comparison. Used to verify that adversarial examples preserve the original meaning.

## Architecture Onboarding

**Component Map**: Input Sentence -> NMT Model -> Translation -> Adversary (TransFool) -> Perturbed Input -> NMT Model -> Adversarial Translation

**Critical Path**: The core attack generation involves token-level perturbation through gradient projection, making each token's processing critical to overall success. The language model embedding computation for similarity constraint and the NMT forward pass for gradient calculation form the computational bottleneck.

**Design Tradeoffs**: The method trades computational efficiency for attack effectiveness by using iterative gradient projection instead of one-shot attacks. The continuous embedding space approach enables gradient computation but requires careful projection to valid tokens. Using language model embeddings for similarity adds computational overhead but provides better semantic preservation than word-level metrics.

**Failure Signatures**: Poor attack success indicates issues with hyperparameter tuning (α, β, γ) or gradient projection implementation. High semantic similarity but low attack success suggests the similarity constraint is too strong. Low fluency scores indicate problems with the language model loss component or projection quality.

## Limitations
- Attack effectiveness highly sensitive to hyperparameter tuning, particularly α, β, and γ values
- Computational intensity of iterative gradient projection limits scalability to long sequences
- Reliance on pre-trained language models for similarity and fluency constraints may not generalize across all domains
