# How (Implicit) Regularization of ReLU Neural Networks Characterizes the Learned Function -- Part II: the Multi-D Case of Two Layers with Random First Layer

## Quick Facts
- arXiv ID: 2303.11454
- Source URL: https://arxiv.org/abs/2303.11454
- Reference count: 40
- Primary result: Extends analysis of implicit regularization in wide ReLU networks from univariate to multivariate settings, showing convergence to adapted Infinite Generalized Additive Models in the infinite-width limit.

## Executive Summary
This paper extends prior work on implicit regularization in ReLU neural networks to the multivariate case, focusing on randomized shallow networks (RSNs) with a random first layer and trained output layer. In the infinite-width limit, the authors prove that an ℓ2-regularized RSN converges to an adapted Infinite Generalized Additive Model (IGAM), a function class defined via a regularization functional on second derivatives. For least-squares loss, gradient descent training without explicit regularization implicitly achieves the same effect, converging to a diminishingly penalized IGAM. The results hold for general input/output dimensions and broad loss classes, providing a precise functional-space characterization of regularization in wide RSNs.

## Method Summary
The authors analyze randomized shallow ReLU networks (RSNs) where the first layer is randomly initialized and fixed, while only the output layer is trained. They establish a functional-space characterization by showing that, in the infinite-width limit, the RSN with ℓ2-regularization on the output layer converges to an adapted Infinite Generalized Additive Model (IGAM). For least-squares loss, they prove that gradient descent without explicit regularization implicitly achieves the same limiting behavior through a diminishingly penalized IGAM. The analysis extends from univariate to multivariate settings and applies to general input/output dimensions and broad loss classes.

## Key Results
- In the infinite-width limit, an ℓ2-regularized RSN converges to an adapted Infinite Generalized Additive Model (IGAM).
- For least-squares loss, gradient descent training without explicit regularization implicitly achieves the same limiting behavior via a diminishingly penalized IGAM.
- The functional characterization holds for general input/output dimensions and broad loss classes, extending prior univariate results to the multivariate case.

## Why This Works (Mechanism)
The mechanism relies on the random projection property of wide neural networks, where in the infinite-width limit, the network output can be expressed as a linear combination of random features. The implicit regularization effect emerges from the gradient descent dynamics on these features, which naturally biases the solution toward functions with small second derivatives in the adapted IGAM sense. This regularization functional on second derivatives controls the smoothness and complexity of the learned function, effectively preventing overfitting even without explicit regularization terms.

## Foundational Learning
- **Randomized Shallow Networks (RSNs)**: Networks with randomly initialized and fixed first layer, trained only on output layer weights. Needed to decouple feature learning from output adaptation. Quick check: Verify first layer weights remain fixed during training.
- **Infinite Width Limit**: Asymptotic regime where network width approaches infinity. Needed to invoke random feature theory and concentration results. Quick check: Confirm width is sufficiently large for theoretical predictions to hold.
- **Adapted Infinite Generalized Additive Models (IGAM)**: Function class defined via regularization functional on second derivatives. Needed to characterize the implicit bias of RSNs. Quick check: Ensure the learned function exhibits the expected second-derivative structure.
- **Implicit Regularization**: Regularization effect arising from optimization dynamics rather than explicit penalty terms. Needed to explain generalization without explicit regularization. Quick check: Compare training with and without explicit regularization to observe similar behavior.
- **Random Feature Theory**: Framework for analyzing neural networks with random first layers. Needed to connect finite networks to their infinite-width limits. Quick check: Verify random feature approximation accuracy for given network width.
- **Second Derivative Regularization**: Functional that penalizes rapid changes in gradients. Needed to control function smoothness and complexity. Quick check: Measure second derivatives of learned functions to confirm regularization effect.

**Failure Signatures**: Poor generalization if width is insufficient; deviation from IGAM characterization if initialization is non-i.i.d.; breakdown of implicit regularization if optimization path is altered.

## Limitations
- Analysis assumes infinite-width limit, with unclear correspondence to practical finite-width networks.
- Theoretical results rely on i.i.d. initialization and specific optimization dynamics, without quantifying sensitivity to deviations.
- Empirical validation on finite networks is absent, limiting practical applicability assessment.

## Confidence
- High: formal convergence results in the infinite-width limit, mathematical derivation of the IGAM characterization, validity of the regularization functional framework
- Medium: applicability of results to finite-width networks, practical implications of implicit regularization
- Low: exact correspondence between theoretical predictions and finite-sample performance, robustness to initialization variations
