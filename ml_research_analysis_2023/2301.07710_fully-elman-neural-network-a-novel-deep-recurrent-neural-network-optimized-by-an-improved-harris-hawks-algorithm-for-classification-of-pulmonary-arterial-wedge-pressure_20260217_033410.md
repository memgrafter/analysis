# Fully Elman Neural Network: A Novel Deep Recurrent Neural Network Optimized by an Improved Harris Hawks Algorithm for Classification of Pulmonary Arterial Wedge Pressure

## Quick Facts
- arXiv ID: 2301.07710
- Source URL: https://arxiv.org/abs/2301.07710
- Reference count: 40
- Primary result: CNN-FENN-HHO+ achieved 78% accuracy, 79% sensitivity, 76% specificity on imbalanced PAWP classification dataset

## Executive Summary
This study addresses the challenge of non-invasive classification of normal and abnormal pulmonary arterial wedge pressure (PAWP) in heart failure patients with implanted left ventricular assist devices (LVADs). The proposed solution combines a convolutional neural network (CNN) with a novel fully Elman neural network (FENN) architecture, optimized using an improved Harris Hawks optimization algorithm (HHO+). The approach aims to detect abnormal PAWP conditions that could lead to life-threatening events like pulmonary congestion and ventricular suction, enabling timely clinical interventions.

## Method Summary
The method integrates a 4-layer CNN for feature extraction from pump flow segments, followed by a fully Elman neural network for temporal modeling of extracted features. Hyperparameter optimization is performed using an improved Harris Hawks optimizer (HHO+) that combines improved exploration/exploitation adaptation (IEEA) and quasi-oppositional learning (QOBL). A weighted cross-entropy loss function addresses the class imbalance in the clinical dataset. The model is evaluated using 5-fold cross-validation on data from LVAD patients.

## Key Results
- CNN-FENN-HHO+ achieved 78% average accuracy on PAWP classification
- Sensitivity of 79% indicates strong detection of abnormal PAWP cases
- Specificity of 76% demonstrates good discrimination between normal and abnormal classes
- Results show statistically significant improvement over baseline methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Fully Elman Neural Network (FENN) improves classification by explicitly modeling temporal dependencies through multiple recurrent connections
- Mechanism: FENN adds recurrent connections between consecutive time points for both hidden and output layers, plus cross-connections between input-to-output and output-to-hidden. This structure allows the network to retain and reuse past state information more effectively than standard Elman networks
- Core assumption: Long-term and spatial-temporal information in PAWP and pump flow signals is critical for accurate classification and is not fully captured by standard RNN architectures
- Evidence anchors: [abstract] "novel fully Elman neural network (FENN) is proposed to improve the classification performance", [section] "In the standard ENN, there is only one feedback between the context layer and hidden layer at time 𝑡. This feedback is not able to fully use the long-term, spatial and temporal information of the input and output variables"

### Mechanism 2
- Claim: Improved Harris Hawks Optimizer (HHO+) enhances global search and avoids premature convergence in hyperparameter tuning
- Mechanism: HHO+ integrates improved exploration/exploitation (IEEA) and quasi-oppositional learning (QOBL) into the base HHO. IEEA adapts exploration/exploitation balance based on hawk/rabbit velocity dynamics, while QOBL generates quasi-opposite solutions to increase diversity and avoid local optima
- Core assumption: Standard HHO can stagnate in local optima and its exploration/exploitation phases are too coarse for complex hyperparameter spaces
- Evidence anchors: [abstract] "improved Harris Hawks optimizer algorithm called HHO+ is presented", [section] "HHO can fail in providing optimal solutions in some cases" and "proposed HHO+ is made by combining HHO, IEEA, and QOBL"

### Mechanism 3
- Claim: Weighted cross-entropy loss mitigates class imbalance impact, improving sensitivity without sacrificing specificity
- Mechanism: Assigns higher weights to minority class samples in the loss function, forcing the network to pay more attention to abnormal PAWP samples during training
- Core assumption: The imbalanced dataset (459 abnormal vs 1338 normal) biases the network toward the majority class, leading to poor detection of abnormal cases
- Evidence anchors: [abstract] "imbalanced clinical dataset" and "weighted cross-entropy loss function is described", [section] "The classical cross-entropy function is not a suitable loss function due to the imbalanced clinical dataset" and "weighted cross-entropy loss function [73] was employed"

## Architecture Onboarding

- Component map: Pump flow segments -> 4-layer CNN -> FENN (20 hidden neurons) -> 2 output neurons (softmax) -> Weighted cross-entropy loss -> Adam optimizer

- Critical path: Data preprocessing → CNN feature extraction → FENN temporal modeling → Classification → Weighted loss → Adam optimization → Cross-validation

- Design tradeoffs:
  - FENN adds recurrent depth for temporal modeling vs. risk of overfitting on small dataset
  - HHO+ hyperparameter search improves accuracy but increases offline training time
  - Weighted loss improves sensitivity vs. potential decrease in specificity if not tuned properly

- Failure signatures:
  - Low sensitivity despite high accuracy → class imbalance not properly handled
  - Overfitting → reduce FENN size or add dropout
  - Slow convergence → adjust HHO+ parameters or switch optimizer

- First 3 experiments:
  1. Train CNN-FENN without HHO+ (use default Adam hyperparameters) to establish baseline performance
  2. Train CNN-MLP with same CNN layers but standard MLP classifier to compare temporal modeling impact
  3. Train CNN-FENN with weighted loss disabled to measure impact of imbalance handling
