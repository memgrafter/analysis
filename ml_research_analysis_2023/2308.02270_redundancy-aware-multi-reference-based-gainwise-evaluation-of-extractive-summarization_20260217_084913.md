# Redundancy Aware Multi-Reference Based Gainwise Evaluation of Extractive Summarization

## Quick Facts
- arXiv ID: 2308.02270
- Source URL: https://arxiv.org/abs/2308.02270
- Reference count: 40
- Introduces a redundancy-aware Sem-nCG metric that improves coherence evaluation correlation by up to 25% over baseline metrics

## Executive Summary
This paper addresses critical limitations in the Sem-nCG metric for extractive summarization evaluation, specifically its lack of redundancy awareness and inability to handle multiple reference summaries. The authors propose a novel redundancy-aware variant that incorporates a self-referenced redundancy score using ROUGE-L, and extend the metric to support multiple references by inferring a unique ground-truth ranking through STSb-distilbert similarity scoring. Through extensive experiments on the SummEval dataset across consistency, relevance, and coherence dimensions, the new metric demonstrates stronger correlation with human judgments than both the original Sem-nCG and established metrics like ROUGE and BERTScore. The proposed approach particularly excels in coherence evaluation when handling multiple reference summaries, achieving up to 25% improvement over baseline metrics.

## Method Summary
The paper introduces a redundancy-aware extension to the Sem-nCG metric by incorporating a self-referenced redundancy penalty that penalizes summaries containing redundant information. This penalty is calculated using ROUGE-L scores between summary pairs, with a weighting parameter λ = 0.5 balancing the original Sem-nCG score and the redundancy penalty. For multi-reference evaluation, the authors propose inferring a ground-truth ranking by computing pairwise similarities between all summary-reference pairs using STSb-distilbert, then averaging these similarities to create a unified ranking. The final metric combines the original gainwise evaluation framework with these enhancements, allowing it to handle multiple reference summaries while maintaining redundancy awareness. Experimental validation was conducted on the SummEval dataset across three dimensions: consistency, relevance, and coherence, with results showing improved correlation with human judgments across all metrics.

## Key Results
- The redundancy-aware Sem-nCG shows up to 25% improvement in coherence correlation compared to baseline metrics when evaluating multiple reference summaries
- The metric demonstrates stronger overall correlation with human judgments across consistency, relevance, and coherence dimensions compared to original Sem-nCG, ROUGE, and BERTScore
- Optimal performance achieved with λ = 0.5 for redundancy penalty weighting, STSb-distilbert for ground-truth ranking, and ROUGE for redundancy calculation

## Why This Works (Mechanism)
The proposed approach works by addressing two fundamental limitations in existing summarization metrics. First, the redundancy penalty component effectively captures semantic overlap within summaries by computing pairwise ROUGE-L scores between summary sentences, preventing inflated scores for summaries that repeat information. Second, the multi-reference extension solves the grounding problem by inferring a consensus ranking from multiple human references, using semantic similarity scores from STSb-distilbert to create a unified ground truth. This combination allows the metric to better align with human judgment patterns, particularly in coherence assessment where redundancy and information distribution are critical factors.

## Foundational Learning

1. **Gainwise Evaluation Framework**
   - *Why needed:* Provides a reference-based evaluation method that accounts for partial credit when summaries partially match reference content
   - *Quick check:* Verify that gainwise scoring correctly handles cases where summary contains some but not all reference information

2. **Semantic Similarity with STSb-distilbert**
   - *Why needed:* Enables semantic matching between summaries and references beyond exact string matching
   - *Quick check:* Ensure semantic similarity scores capture paraphrases and semantically equivalent expressions

3. **Redundancy Detection via ROUGE-L**
   - *Why needed:* Identifies repeated information within summaries that may artificially inflate quality scores
   - *Quick check:* Validate that ROUGE-L penalty correctly identifies both exact and near-repetitions

4. **Ground-Truth Ranking Inference**
   - *Why needed:* Creates a unified evaluation target when multiple human references exist
   - *Quick check:* Confirm that averaged similarity scores produce sensible rankings across diverse summary sets

5. **Weighting Parameter λ**
   - *Why needed:* Balances original Sem-nCG score against redundancy penalty for optimal correlation
   - *Quick check:* Test sensitivity of results to λ values across different λ ranges

## Architecture Onboarding

**Component Map:** Summary -> [Redundancy Detector (ROUGE-L)] -> [Sem-nCG Calculator] -> [Final Score]; Multiple References -> [Similarity Matrix (STSb-distilbert)] -> [Ground-Truth Ranking] -> [Evaluation]

**Critical Path:** Input summaries → ROUGE-L pairwise computation → Sem-nCG scoring → λ-weighted combination → Final metric output

**Design Tradeoffs:** Uses ROUGE-L for redundancy detection (fast but may miss semantic redundancy) versus more computationally expensive semantic methods; employs averaged STSb-distilbert scores for ranking (simple but assumes equal reference quality)

**Failure Signatures:** Low correlation with human judgments when summaries contain semantic redundancy not captured by ROUGE-L; ranking instability when reference summaries have conflicting quality judgments

## Limitations
- Redundancy penalty using ROUGE-L may not capture all forms of semantic redundancy, particularly for abstractive summaries
- Ground-truth ranking inference assumes equal weighting of multiple references, potentially overlooking reference quality variations
- Hyperparameter selection (λ = 0.5, STSb-distilbert, ROUGE) based on empirical observation without theoretical justification

## Confidence
- Single-reference correlation improvements: High
- Multi-reference coherence correlation: Medium (substantial gains but modest absolute values)
- Hyperparameter generalizability: Low to Medium
- Redundancy penalty effectiveness: Medium
