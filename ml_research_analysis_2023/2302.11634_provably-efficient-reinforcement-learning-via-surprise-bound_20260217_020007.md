# Provably Efficient Reinforcement Learning via Surprise Bound

## Quick Facts
- **arXiv ID:** 2302.11634
- **Source URL:** https://arxiv.org/abs/2302.11634
- **Reference count:** 40
- **Key outcome:** Achieves regret bounds that depend polynomially on the surprise bound and log-covering numbers for general value function approximation

## Executive Summary
This paper proposes a novel algorithm for provably efficient reinforcement learning with general value function approximation. The algorithm uses optimistic least-squares value iteration combined with a doubling epoch schedule and uniform sampling to reduce computational complexity. A key innovation is the use of the surprise bound as a distribution-dependent complexity measure, which can be significantly smaller than worst-case measures like eluder dimension. The algorithm achieves regret bounds of Õ(poly(ιH)√T) where ι is the product of the surprise bound and log-covering numbers, and demonstrates reasonable regret bounds for linear and sparse high-dimensional linear settings.

## Method Summary
The algorithm employs a doubling epoch schedule where each epoch uses optimistic least-squares value iteration (LSVI) to compute Q-functions. The key innovation is using uniform sampling to reduce the complexity of the replay buffer from O(T) to O(log T), making it computationally efficient. For each epoch, the algorithm solves O(H log K) empirical risk minimization problems instead of O(HK) problems. The bonus function is computed using the width function, which measures the maximum difference between functions in the confidence region. The algorithm relies on the Bellman-completeness assumption and achieves low regret by ensuring that the estimated Q-functions are upper bounds on the true optimal Q-functions.

## Key Results
- Achieves Õ(poly(ιH)√T) regret bound where ι combines surprise bound and log-covering numbers
- Only needs to solve O(H log K) empirical risk minimization problems, more efficient than Ω(HK) in previous methods
- Achieves reasonable regret bounds for both linear and sparse high-dimensional linear settings
- Uses uniform sampling which is conceptually simpler than sensitivity sampling or star hull methods

## Why This Works (Mechanism)

### Mechanism 1: Doubling Epoch Schedule with Optimistic LSVI
- **Claim:** The algorithm achieves low regret by using a doubling epoch schedule combined with optimistic least-squares value iteration (LSVI).
- **Mechanism:** The doubling epoch schedule reduces the computational burden by solving only O(H log K) empirical risk minimization (ERM) problems instead of O(HK) problems. The optimistic LSVI ensures that the estimated Q-functions are upper bounds on the true optimal Q-functions, which enables regret decomposition into bonus terms.
- **Core assumption:** Bellman-completeness assumption holds for the function class F.
- **Break condition:** If the function class F does not satisfy Bellman-completeness, the optimism property fails and the regret bound no longer holds.

### Mechanism 2: Surprise Bound Complexity Measure
- **Claim:** The surprise bound provides a distribution-dependent complexity measure that can be smaller than worst-case eluder dimension.
- **Mechanism:** The surprise bound L1 measures how much two functions can differ on any state-action pair relative to their expected squared difference under any policy. This allows the algorithm to adapt to the specific problem instance rather than worst-case scenarios.
- **Core assumption:** The surprise bound L1 is bounded for the function class F.
- **Break condition:** If L1 grows too large (e.g., exponentially in problem parameters), the regret bound becomes vacuous.

### Mechanism 3: Uniform Sampling for Replay Buffer
- **Claim:** Uniform sampling reduces the complexity of the replay buffer without sacrificing theoretical guarantees.
- **Mechanism:** The algorithm uses uniform sampling to reduce the size of the replay buffer from O(T) to O(log T) while maintaining the concentration properties needed for the bonus function calculation. This is simpler than sensitivity sampling or star hull methods used in previous work.
- **Core assumption:** The trajectories in the replay buffer are sufficiently diverse and the doubling epoch schedule stabilizes adjacent trajectories.
- **Break condition:** If the uniform sampling fails to preserve the necessary concentration properties, the bonus function becomes too optimistic or too pessimistic.

## Foundational Learning

- **Concept:** Bellman-completeness
  - Why needed here: The algorithm relies on being able to find a function fV in F that satisfies the Bellman equation for any value function V. This property ensures that the empirical risk minimization can find good approximations to the optimal value functions.
  - Quick check question: Can you write the Bellman equation for a value function V and explain what it means for a function class to be Bellman-complete?

- **Concept:** Covering numbers and log-covering numbers
  - Why needed here: The regret bound depends on the log-covering numbers of both the function class F and the state-action space S×A. These measure the complexity of the function class and are used in the union bounds that establish concentration.
  - Quick check question: How would you compute or estimate the log-covering number of a d-dimensional linear function class with bounded weights?

- **Concept:** Eluder dimension vs surprise bound
  - Why needed here: Understanding the difference between these two complexity measures helps explain why the algorithm can achieve better regret bounds. The eluder dimension considers worst-case scenarios over all possible histories, while the surprise bound is distribution-dependent.
  - Quick check question: Can you construct an example where the surprise bound is significantly smaller than the eluder dimension for the same function class?

## Architecture Onboarding

- **Component map:**
  - Main algorithm (Algorithm 1) -> Uniform sampling (Algorithm 2) -> Bonus function (Algorithm 3) -> ERM solver -> Width function calculator

- **Critical path:**
  1. Initialize with warm-up epochs using random policy
  2. For each epoch m ≥ M0:
     - Collect trajectories using current policy πm
     - Compute best-fit functions fm using ERM on replay buffer
     - Compute bonus functions bm using uniform sampling
     - Construct optimistic Q-functions Qm
     - Update policy to be greedy with respect to Qm
  3. Return the final policy after K episodes

- **Design tradeoffs:**
  - Uniform sampling vs sensitivity sampling: Simpler implementation but requires doubling epoch schedule for stability
  - Optimism vs pessimism: Optimism enables efficient exploration but requires careful bonus design
  - Function class complexity: Richer function classes enable better approximation but increase regret bounds

- **Failure signatures:**
  - If the function class is not Bellman-complete: The algorithm will fail to find good approximations to the optimal value functions
  - If L1 is too large: The regret bound becomes vacuous even if the algorithm works in practice
  - If the doubling epoch schedule is not used: The uniform sampling may not preserve concentration properties

- **First 3 experiments:**
  1. Test on a simple tabular MDP where F is the set of all value functions to verify the algorithm recovers optimal performance
  2. Test on a linear MDP with known feature map to verify the regret scales as O(d²H³/²√T)
  3. Test on a misspecified problem where Bellman-completeness only approximately holds to verify robustness to model misspecification

## Limitations

- The Bellman-completeness assumption is restrictive and may fail when using expressive function classes like neural networks
- The regret bound depends polynomially on the surprise bound L1, which could grow exponentially with problem parameters in worst cases
- The doubling epoch schedule may lead to suboptimal exploration in some scenarios
- Theoretical guarantees are primarily asymptotic and may not translate to strong finite-sample performance
