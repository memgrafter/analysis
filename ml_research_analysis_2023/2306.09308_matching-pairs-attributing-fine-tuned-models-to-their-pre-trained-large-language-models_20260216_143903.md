# Matching Pairs: Attributing Fine-Tuned Models to their Pre-Trained Large Language Models

## Quick Facts
- arXiv ID: 2306.09308
- Source URL: https://arxiv.org/abs/2306.09308
- Reference count: 40
- Primary result: First systematic approach to attributing fine-tuned LLMs to pre-trained base models, achieving 8/10 correct attributions under restricted knowledge settings

## Executive Summary
This paper introduces the first systematic method for attributing fine-tuned large language models back to their pre-trained base models. The approach formulates attribution as a binary classification problem where, for each base model, a classifier learns to distinguish its responses from those of other models. The study explores multiple input representations and prompt selection strategies, including using responses from both base and fine-tuned models and optimizing prompts via reinforcement learning. Results show that pre-training classifiers on large prompt sets improves attribution accuracy, and that similarity between fine-tuning data and pre-training data matters more than the amount of fine-tuning applied.

## Method Summary
The attribution problem is formulated as a binary classification task where, for each base model, a classifier is trained to distinguish its responses from those of other base models. The study experiments with different input representations including base model responses, fine-tuned model responses, and combinations thereof. Prompt selection strategies are explored, including reinforcement learning-based optimization to generate distinguishing prompts. The approach is evaluated under both full knowledge (access to all base model responses) and restricted knowledge settings, with the latter more closely mimicking real-world scenarios where only fine-tuned model outputs are available.

## Key Results
- Best approach achieves 8 out of 10 correct attributions under restricted knowledge settings
- Pre-training classifiers on large prompt sets significantly improves attribution accuracy
- Similarity between fine-tuning dataset and pre-training data has greater impact than fine-tuning dataset size

## Why This Works (Mechanism)
The attribution works because fine-tuning introduces subtle but detectable changes in model behavior that reflect the characteristics of the base model's pre-training. These changes are preserved enough in the fine-tuned model's responses to be distinguishable from other base models. The binary classification approach effectively learns these distinguishing patterns by comparing response distributions across different base models.

## Foundational Learning
- **Binary classification for attribution**: Needed to frame the attribution problem as a learnable task; quick check: verify classifier performance on balanced datasets
- **Reinforcement learning prompt optimization**: Required to generate maximally distinguishing prompts; quick check: measure prompt diversity and attribution improvement
- **Response representation selection**: Critical for capturing model-specific characteristics; quick check: compare attribution accuracy across different input representations
- **Knowledge setting distinction**: Important for practical applicability; quick check: test both full and restricted knowledge scenarios
- **Pre-training data influence**: Fundamental to understanding fine-tuning effects; quick check: analyze attribution accuracy across domains with varying similarity to pre-training data

## Architecture Onboarding

**Component Map**: Base Model Responses -> Feature Extraction -> Binary Classifier -> Attribution Decision

**Critical Path**: Prompt Generation -> Model Response Collection -> Feature Representation -> Classification -> Attribution Output

**Design Tradeoffs**: 
- Using only fine-tuned model responses (restricted knowledge) vs. both base and fine-tuned responses (full knowledge) trades accuracy for practicality
- Reinforcement learning prompt optimization increases computational cost but improves distinguishing power
- Larger prompt sets improve classifier pre-training but increase data collection overhead

**Failure Signatures**:
- Low attribution accuracy when fine-tuning domains are highly dissimilar from pre-training data
- Performance degradation when fine-tuning datasets are too small to capture base model characteristics
- Classification confusion when base models have similar pre-training corpora or architectures

**First 3 Experiments**:
1. Test attribution accuracy baseline using random prompts without optimization
2. Compare attribution performance across different input representations (base only, fine-tuned only, combined)
3. Evaluate the impact of prompt set size on classifier pre-training effectiveness

## Limitations
- Best model achieves only 8/10 correct attributions under restricted knowledge settings, indicating imperfect performance
- Evaluation relies on relatively small sample of 50 prompts per base model, potentially missing usage pattern diversity
- Proprietary models and commercial fine-tuning services limit reproducibility and generalizability to open-source alternatives

## Confidence
- **High confidence**: The core methodology of using binary classification for attribution is sound and technically valid
- **Medium confidence**: The observation that pre-training data similarity matters more than fine-tuning dataset size is plausible but needs broader validation across different model families
- **Medium confidence**: The effectiveness of RL-based prompt optimization shows promise but requires more extensive testing

## Next Checks
1. Replicate the attribution accuracy on open-source model pairs (e.g., LLaMA → Alpaca, Falcon → Finetuned Falcon) to test generalizability beyond proprietary models
2. Evaluate performance using a larger and more diverse prompt set (e.g., 500+ prompts) to assess robustness to prompt variability
3. Test attribution accuracy when fine-tuning datasets are drawn from domains dissimilar to pre-training data (e.g., medical vs. general web text) to validate the pre-training data similarity hypothesis
