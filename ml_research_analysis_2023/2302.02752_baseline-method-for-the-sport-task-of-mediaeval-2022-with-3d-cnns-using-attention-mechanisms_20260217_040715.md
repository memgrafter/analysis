# Baseline Method for the Sport Task of MediaEval 2022 with 3D CNNs using Attention Mechanisms

## Quick Facts
- arXiv ID: 2302.02752
- Source URL: https://arxiv.org/abs/2302.02752
- Reference count: 23
- Primary result: 86.4% accuracy for stroke classification using V2 model with Gaussian window decision

## Executive Summary
This paper presents a baseline method for the Sports Video task of MediaEval 2022, addressing both stroke classification from trimmed videos and stroke detection from untrimmed videos. The approach employs two types of 3D-CNN architectures using spatio-temporal convolutions and attention mechanisms, with each architecture tailored to its respective subtask. The method uses RGB information from videos with data augmentation techniques applied, and is publicly available to assist participants in their submissions.

## Method Summary
The baseline method employs 3D-CNN architectures with attention mechanisms to process RGB video data for both classification and detection tasks. Two distinct model architectures are developed: one optimized for trimmed video classification and another for untrimmed video detection. Data augmentation techniques are applied to enhance model robustness, and the approach leverages spatio-temporal convolutions to capture both spatial and temporal patterns in the sports videos.

## Key Results
- Classification subtask: 86.4% accuracy achieved using V2 model with Gaussian window decision method
- Detection subtask: mAP of 0.131 and IoU of 0.515 achieved using V1 model with sliding window segmentation method
- Both models utilize attention mechanisms to enhance spatio-temporal feature extraction

## Why This Works (Mechanism)
The 3D-CNN architecture with attention mechanisms effectively captures spatio-temporal patterns in sports videos by processing sequences of frames through convolutional layers that operate across both spatial and temporal dimensions. The attention mechanisms help the model focus on relevant regions and moments within the video sequences, improving the discrimination between different stroke types. The use of two specialized architectures allows each model to be optimized for its specific task requirements - classification from trimmed videos versus detection from untrimmed videos.

## Foundational Learning

1. **3D Convolutional Neural Networks**
   - Why needed: Capture spatio-temporal features in video data by extending 2D convolutions to 3D space-time volumes
   - Quick check: Verify that temporal kernel size is appropriately set (e.g., 3-5 frames) to capture motion without excessive computational cost

2. **Attention Mechanisms in Video Processing**
   - Why needed: Enable models to dynamically focus on salient spatial regions and temporal segments relevant to the task
   - Quick check: Confirm attention weights are interpretable and highlight meaningful regions during video sequences

3. **Sliding Window Segmentation for Detection**
   - Why needed: Enable frame-level stroke detection from untrimmed videos by analyzing overlapping temporal windows
   - Quick check: Ensure window overlap ratio is sufficient (typically 50-75%) to avoid missing strokes between windows

## Architecture Onboarding

**Component Map:**
Raw Video -> Data Augmentation -> 3D CNN Backbone -> Attention Layer -> Classification/Detection Head

**Critical Path:**
Input frames → 3D convolution blocks → Attention mechanism → Decision layer → Output

**Design Tradeoffs:**
- RGB-only input vs. multi-modal approaches (pose, optical flow)
- 3D convolutions vs. 2D+optical flow for computational efficiency
- Sliding window overlap vs. detection granularity

**Failure Signatures:**
- Poor detection performance on videos with high stroke density
- Attention maps focusing on irrelevant background regions
- Classification errors when stroke appearance varies significantly

1. Test model performance on validation set with varying stroke durations

## Limitations
- Relies exclusively on RGB information, potentially missing complementary cues from pose estimation or optical flow
- Performance gap between classification (86.4%) and detection (mAP 0.131) tasks suggests detection approach may need refinement
- Data augmentation strategy may not fully address challenges of limited training data in specialized sports domains
