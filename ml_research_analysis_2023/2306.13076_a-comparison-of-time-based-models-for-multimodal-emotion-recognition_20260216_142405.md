# A Comparison of Time-based Models for Multimodal Emotion Recognition

## Quick Facts
- arXiv ID: 2306.13076
- Source URL: https://arxiv.org/abs/2306.13076
- Reference count: 0
- Key outcome: Different sequence models (GRU, LSTM, Transformer, Max Pooling) perform similarly when combined with the same CNN feature extractor for multimodal emotion recognition

## Executive Summary
This study systematically compares four sequence models for multimodal emotion recognition using audio (MFCC features) and video (face images) inputs. All models share an identical 3-layer CNN backbone that extracts features from both modalities, with the key finding being that sequence model choice has minimal impact on performance. The experiments on the CREMA-D dataset show that GRU, LSTM, Transformer, and Max Pooling achieve comparable results when combined with the same CNN features, suggesting that feature extraction quality may be more important than temporal modeling sophistication for basic emotion recognition tasks.

## Method Summary
The approach processes audio and video through separate 3-layer CNN models that share the same architecture, then feeds their outputs into various sequence models: GRU, Transformer, LSTM, or Max Pooling. Audio inputs are converted to MFCC features while video frames are face-cropped to 64x64. All sequence models are trained with the same CNN backbone using Adam optimizer (lr=1e-4), batch size 16, and early stopping after 15 epochs. The models are evaluated on the CREMA-D dataset using accuracy, precision, sensitivity, and F1 score per emotion class.

## Key Results
- GRU achieved the best F1 score (0.640) among all sequence models
- LSTM achieved the best precision (0.699) for emotion classification
- Max Pooling achieved the best sensitivity (0.620) and performed competitively overall
- All four sequence models (GRU, LSTM, Transformer, Max Pooling) showed comparable performance when using the same CNN features

## Limitations
- Limited to CREMA-D dataset with specific preprocessing choices (64x64 face crops, MFCC features, 5-second clips)
- Only tested one specific CNN architecture configuration (3-layer with 32 filters)
- Does not explore scenarios where emotional expressions evolve gradually over time

## Confidence
- High confidence: Sequence model choice has minimal impact when using the same CNN features
- Medium confidence: CNN architecture superiority claims
- Low confidence: Temporal modeling is unnecessary for emotion recognition
