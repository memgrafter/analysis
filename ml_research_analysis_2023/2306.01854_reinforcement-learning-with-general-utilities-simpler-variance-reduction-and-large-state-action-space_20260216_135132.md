# Reinforcement Learning with General Utilities: Simpler Variance Reduction and Large State-Action Space

## Quick Facts
- **arXiv ID**: 2306.01854
- **Source URL**: https://arxiv.org/abs/2306.01854
- **Reference count**: 40
- **One-line primary result**: Achieves Õ(ε⁻³) and Õ(ε⁻²) sample complexities for ε-first-order stationarity and ε-global optimality respectively in RL with general utilities

## Executive Summary
This paper proposes a novel normalized variance-reduced policy gradient algorithm (N-VR-PG) for reinforcement learning with general utilities. The method achieves sample-efficient learning without requiring large batches or checkpoints, making it practical for real-world applications. The key innovation is a recursive variance reduction mechanism that works with a single trajectory per iteration while maintaining theoretical guarantees. The approach is further extended to handle large state-action spaces through linear function approximation of the occupancy measure.

## Method Summary
The paper presents N-VR-PG, a normalized variance-reduced policy gradient algorithm that uses recursive momentum for both policy gradient and occupancy measure estimation. The method employs a single trajectory per iteration and avoids gradient truncation by using a normalized update rule that controls importance sampling weights. For large state-action spaces, the algorithm extends to use linear function approximation of the occupancy measure through least-mean-squares solvers, enabling scalability while maintaining theoretical guarantees.

## Key Results
- Achieves Õ(ε⁻³) sample complexity for ε-first-order stationarity in general utilities
- Achieves Õ(ε⁻²) sample complexity for ε-global optimality under concave reparametrization
- Extends to large state-action spaces with Õ(ε⁻⁴) sample complexity using linear function approximation

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Normalized policy gradient update bounds importance sampling weights without truncation
- **Mechanism**: Normalization ensures bounded ratio of consecutive policy parameters, which bounds the product of policy ratios in importance sampling weights
- **Core assumption**: Smooth policy parametrization (softmax/Gaussian) with controlled step size
- **Evidence anchors**: Abstract states "no additional gradient truncation hyperparameter is needed"; Lemma 4.3 shows w(τ|θt, θt+1) ≤ exp{2Hl ψαt}
- **Break condition**: Fails if policy parametrization is non-smooth or update step size is too large

### Mechanism 2
- **Claim**: Recursive variance reduction using momentum improves sample efficiency
- **Mechanism**: Maintains recursive estimates of both policy gradient and occupancy measure to reduce variance over iterations
- **Core assumption**: Stationary MDP with smooth enough policy updates for correlated consecutive estimates
- **Evidence anchors**: Abstract mentions "recursive momentum variance reduction mechanism"; Algorithm 1 uses recursive updates for both estimates
- **Break condition**: Ineffective if MDP is non-stationary or policy updates are too large

### Mechanism 3
- **Claim**: Linear function approximation scales to large state-action spaces
- **Mechanism**: Approximates occupancy measure using linear combination of pre-selected basis functions
- **Core assumption**: Feature map ϕ captures essential state-action characteristics with bounded approximation error
- **Evidence anchors**: Abstract discusses "linear combination of pre-selected basis functions"; Section 5.1 defines λπθ = ⟨ϕ(s,a), ωθ⟩
- **Break condition**: Fails if feature map is not expressive enough or approximation error is too large

## Architecture Onboarding

- **Component map**: Policy parametrization (softmax/Gaussian) -> Recursive variance reduction -> Linear function approximation -> Importance sampling weight control
- **Critical path**: 
  1. Initialize policy parameters θ0
  2. Sample trajectory τt from MDP using current policy
  3. Update occupancy measure estimate λt using recursive formula
  4. Compute stochastic policy gradient g(τt, θt, rt-1)
  5. Update policy parameters using normalized gradient
  6. Repeat until convergence

- **Design tradeoffs**: 
  - Single-loop vs. double-loop: N-VR-PG uses single loop for simplicity and efficiency
  - Batch size: Uses single trajectory per iteration, reducing memory requirements
  - Function approximation: Linear approximation enables scaling but introduces approximation error

- **Failure signatures**:
  - High variance in policy gradient estimates: Issues with variance reduction or importance sampling weight control
  - Slow convergence: Policy parametrization or function approximation not expressive enough
  - Divergence: Step size too large or MDP non-stationary

- **First 3 experiments**:
  1. Implement N-VR-PG with softmax policy parametrization on small MDP to verify convergence
  2. Test importance sampling weight control by varying step size and observing bounds
  3. Apply linear function approximation to large MDP and compare with tabular methods

## Open Questions the Paper Calls Out

- **Open Question 1**: Can convergence guarantees extend to non-concave general utilities without reparametrization assumption?
  - Basis in paper: Assumption 4.10 and global optimality section
  - Why unresolved: Achieves O(ε⁻²) only under concave reparametrization assumption
  - What evidence would resolve it: Proving global optimality guarantees for general utilities without requiring concavity

- **Open Question 2**: How does N-VR-PG perform in large-scale problems with continuous state-action spaces?
  - Basis in paper: Section 5 mentions extension to large spaces but only addresses large finite spaces
  - Why unresolved: Paper lacks theoretical or empirical results for continuous state-action spaces
  - What evidence would resolve it: Theoretical analysis and experimental results for continuous state-action spaces

- **Open Question 3**: Can sample complexity for large state-action space be improved beyond O(ε⁻⁴)?
  - Basis in paper: Corollary 5.6 establishes O(ε⁻⁴) sample complexity
  - Why unresolved: Paper doesn't explore whether O(ε⁻⁴) is optimal
  - What evidence would resolve it: Developing algorithm with improved sample complexity (e.g., O(ε⁻³))

## Limitations

- Strong assumptions about MDP being stationary and policy parametrization being smooth may not hold in practice
- Linear function approximation introduces approximation error that is not fully characterized
- Theoretical guarantees require specific assumptions about utility function structure

## Confidence

- **Practical applicability**: Medium (single trajectory per iteration is promising but assumptions may be restrictive)
