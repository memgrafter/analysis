# BM25 Query Augmentation Learned End-to-End

## Quick Facts
- arXiv ID: 2305.14087
- Source URL: https://arxiv.org/abs/2305.14087
- Reference count: 11
- Primary result: End-to-end learned BM25 query augmentation and reweighting improves retrieval performance while maintaining speed

## Executive Summary
This paper introduces a neural network approach to augment and reweight BM25's sparse query representation in an end-to-end fashion. By generating additive query augmentation and multiplicative weighting vectors, the method enables contrastive loss training while preserving BM25's computational efficiency. At retrieval time, the learned augmentations can be extracted as discrete tokens and applied using standard BM25 tools with a modified IDF vector.

## Method Summary
The approach uses a neural network to generate two vectors: an additive query augmentation vector and a multiplicative weighting vector. These vectors are applied to BM25's query and IDF vectors, respectively. The model is trained end-to-end using a contrastive loss function. During inference, the learned augmentation can be extracted as discrete tokens, allowing retrieval with standard BM25 tools using the modified IDF vector.

## Key Results
- Improves over standard BM25 on Natural Questions, EntityQuestions, and MSMARCO datasets
- Retains BM25's speed advantage during retrieval
- Learned augmentations and reweightings transfer well to unseen datasets

## Why This Works (Mechanism)
The paper proposes an end-to-end learned approach to augmenting and reweighting BM25's sparse query representation. The core idea is to use a neural network to generate an additive query augmentation vector and a multiplicative weighting vector that can be applied to BM25's query and IDF vectors, enabling end-to-end training with a standard contrastive loss.

- Critical path: Neural network generates vectors → Vectors modify BM25 components → Retrieval with modified vectors
- Design tradeoffs: End-to-end learning vs. interpretability; Learned augmentations vs. manual query expansion
- Failure signatures: Poor performance on unseen datasets; Significant speed degradation compared to standard BM25
