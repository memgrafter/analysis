# Contrastive Hierarchical Discourse Graph for Scientific Document Summarization

## Quick Facts
- arXiv ID: 2306.00177
- Source URL: https://arxiv.org/abs/2306.00177
- Authors: Not specified in source
- Reference count: 12
- Primary result: CHANGES achieves best ROUGE-1, ROUGE-2, and ROUGE-L scores on PubMed and arXiv benchmark datasets

## Executive Summary
This paper introduces CHANGES, a contrastive hierarchical graph neural network for extractive scientific paper summarization. The method represents scientific papers as hierarchical discourse graphs, capturing both local intra-section and global inter-section sentence relations. Through dedicated hierarchical graph information aggregation and a graph contrastive learning module, CHANGES learns effective sentence representations that achieve state-of-the-art performance on PubMed and arXiv benchmark datasets.

## Method Summary
CHANGES constructs a hierarchical discourse graph where sentences are nodes connected by edges within sections (Esen) and between sections (Esec). The model uses Graph Attention Networks for intra-section message passing and cross-level information aggregation between sentence and section nodes. A graph contrastive learning module learns global theme-aware representations by pulling semantically similar sentences together and pushing dissimilar ones apart. Hierarchical position encoding preserves sequential order information within the document structure.

## Key Results
- Achieves best ROUGE-1 scores on both PubMed and arXiv datasets compared to baseline methods
- Achieves best ROUGE-2 scores on both benchmark datasets
- Achieves best ROUGE-L scores on both datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The hierarchical discourse graph captures both local intra-section and global inter-section sentence relations
- Mechanism: By constructing edges between sentences within the same section (Esen) and between sections (Esec), the model can iteratively update sentence representations through both local and global message passing
- Core assumption: Scientific papers follow a predictable hierarchical structure that can be effectively modeled as a graph
- Evidence anchors: [abstract] "CHANGES represents a scientific paper with a hierarchical discourse graph and learns effective sentence representations with dedicated designed hierarchical graph information aggregation"
- Break condition: If scientific papers don't follow predictable section structures or if the section boundaries are too ambiguous

### Mechanism 2
- Claim: Graph contrastive learning learns global theme-aware sentence representations
- Mechanism: By using a contrastive loss that pulls semantically similar sentences together and pushes dissimilar ones apart, the model learns which sentences are most representative of the document's main themes
- Core assumption: A good summary sentence should be more semantically similar to the source document than other sentences
- Evidence anchors: [abstract] "We also propose a graph contrastive learning module to learn global theme-aware sentence representations"
- Break condition: If the assumption about semantic similarity to the document doesn't hold, or if the contrastive loss doesn't effectively distinguish salient from non-salient sentences

### Mechanism 3
- Claim: Hierarchical position encoding preserves sequential order information within the complex document structure
- Mechanism: By encoding both the section index and the sentence index within that section, the model maintains awareness of where sentences appear in the document hierarchy
- Core assumption: The position of sentences within sections matters for their importance in summarization
- Evidence anchors: [section] "In addition to the semantic representation of sentences, we also inject positional encoding following Transformer to preserve the sequential order information"
- Break condition: If sentence position within sections doesn't correlate with importance, or if the hierarchical encoding doesn't improve over flat position encoding

## Architecture Onboarding

- Component map: Input (Scientific paper) -> Graph Construction -> Graph Contrastive Module -> Hierarchical Graph Layers -> Output (Confidence scores)
- Critical path: Input → Graph Construction → Graph Contrastive Module → Hierarchical Graph Layers → Output
- Design tradeoffs:
  - Unweighted vs weighted edges: Unweighted edges simplify the model but may lose some semantic information
  - BERT as fixed encoder: Reduces computation but doesn't fine-tune on the specific summarization task
  - Number of hierarchical layers: More layers capture more complex relationships but increase computation
- Failure signatures:
  - Poor performance on documents with unusual structures
  - Overfitting to specific section types in training data
  - Sensitivity to hyperparameters like λ (loss scaling factor)
- First 3 experiments:
  1. Ablation study: Remove graph contrastive module and compare performance
  2. Ablation study: Remove hierarchical graph layers and compare performance
  3. Sensitivity analysis: Vary the number of hierarchical graph layers and measure impact on ROUGE scores

## Limitations
- Reliance on fixed document structures and specific assumptions about scientific paper formatting
- Use of BERT as a fixed encoder may limit adaptation to domain-specific language patterns
- Contrastive learning assumption that semantic similarity indicates summary-worthiness may not always hold

## Confidence

**High Confidence**: The hierarchical graph construction methodology and its implementation using Graph Attention Networks. The paper provides clear architectural details and the approach aligns well with established graph neural network principles.

**Medium Confidence**: The effectiveness of the graph contrastive learning module. While the theoretical justification is sound and experimental results are promising, the contrastive learning approach's benefits over simpler alternatives are not fully explored.

**Medium Confidence**: The superiority of the hierarchical approach over flat or sequential models. The ablation studies support this claim, but the comparison could be strengthened by testing against more diverse baseline architectures.

## Next Checks

1. **Cross-domain robustness test**: Evaluate CHANGES on scientific papers from multiple disciplines (e.g., biology, computer science, social sciences) to verify that the hierarchical structure assumptions hold across different scientific writing conventions.

2. **Ablation of position encoding**: Conduct an ablation study specifically testing whether the hierarchical position encoding provides significant improvements over simpler position encoding schemes, isolating its contribution to overall performance.

3. **Human evaluation of summary quality**: Beyond ROUGE scores, perform a human evaluation comparing summaries generated by CHANGES against those from strong baselines, focusing on criteria like coherence, coverage of key points, and readability.
