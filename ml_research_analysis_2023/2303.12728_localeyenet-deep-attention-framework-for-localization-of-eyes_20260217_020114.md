# LocalEyenet: Deep Attention framework for Localization of Eyes

## Quick Facts
- arXiv ID: 2303.12728
- Source URL: https://arxiv.org/abs/2303.12728
- Authors: 
- Reference count: 40
- Primary result: Achieves NME of 0.0047 on 300W and 0.2635 on 300VW datasets for eye landmark localization

## Executive Summary
This paper proposes LocalEyenet, a deep attention framework for accurate and efficient eye localization in facial images. The method uses stacked hourglass networks as a backbone and incorporates deep layer aggregation units (DLAUs) to improve feature fusion across layers. A self-attention module is added between hourglass modules to capture spatial dependencies, and a differentiable soft-argmax layer enables end-to-end training. The model is trained on the 300W dataset and tested on both 300W and 300VW datasets. LocalEyenet achieves a normalized mean error (NME) of 0.0047 on 300W and 0.2635 on 300VW, outperforming other state-of-the-art heatmap regression methods. The model also shows good generalization in cross-dataset evaluation and real-time localization with an inference speed of 32 fps.

## Method Summary
LocalEyenet uses a stacked hourglass network backbone with three hourglass modules. Each hourglass module incorporates Deep Layer Aggregation Units (DLAUs) that iteratively merge deep and shallow features using depth-wise convolution and concatenation. Self-attention modules are placed between hourglass modules to capture spatial dependencies by computing similarity maps using embedded Gaussian at each pixel location. The model generates 12 heatmaps (one per eye landmark) using Gaussian filters centered at ground truth positions. A differentiable soft-argmax layer enables end-to-end training by providing continuous, differentiable coordinate estimation from heatmaps. The model is trained on 300W dataset with MSE loss using RMSprop optimizer and evaluated on both 300W and 300VW datasets using normalized mean error (NME), area under curve (AUC), and failure rate metrics.

## Key Results
- Achieves NME of 0.0047 on 300W dataset and 0.2635 on 300VW dataset
- Outperforms state-of-the-art heatmap regression methods in eye landmark localization
- Demonstrates good generalization in cross-dataset evaluation with inference speed of 32 fps

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Self-attention modules between hourglass modules preserve spatial dependencies and improve feature fusion
- Mechanism: The self-attention module computes similarity maps using embedded Gaussian at each pixel location and refines the feature maps by combining global and local attention
- Core assumption: Spatial dependencies learned at intermediate stages can be effectively combined with coarse predictions to improve localization accuracy
- Evidence anchors:
  - [abstract] "We have defined a self-attention module between the individual hourglasss modules, which learns the local spatial attention and the global attention to estimate the precise location of the landmarks."
  - [section 3.1.2] "The attention in feature maps, generated by intermediate hourglass modules, are computed and incorporated with the coarse predictions at each stage. This helps in understanding the spatial dependencies and correlation in images."

### Mechanism 2
- Claim: Deep Layer Aggregation Units (DLAUs) minimize loss of attention over depth and improve feature combination
- Mechanism: DLAUs iteratively merge deep and shallow features using depth-wise convolution and concatenation, providing better aggregation than standard residual blocks
- Core assumption: Iterative feature merging across network depth preserves more information than single skip connections
- Evidence anchors:
  - [abstract] "We have incorporated deep layer aggregation in each hourglass to minimize the loss of attention over the depth of architecture."
  - [section 3.1.1] "The concept of layer aggregation has been incorporated by designing deep layer aggregation schematics such as Iterative Deep Aggregation (IDA) as proposed in [64]. We have adopted the concept and designed a Deep layer aggregation unit (DLAU) that maps the features in an iterative manner."

### Mechanism 3
- Claim: Differentiable soft-argmax enables end-to-end training and precise landmark localization from heatmaps
- Mechanism: Soft-argmax computes coordinates (x, y) from attention heatmaps using a continuous, differentiable function instead of non-differentiable argmax
- Core assumption: Using a differentiable approximation of argmax maintains training stability while providing accurate coordinate estimation
- Evidence anchors:
  - [abstract] "a differentiable softargmax layer enables end-to-end training."
  - [section 3.1] "Since argmax is non-differentiable, we have used the softargmax [11] method which is a continuous function at each point and is thus differentiable. This allows us to train the network end to end and estimates the probability of the landmark positions on the attention heatmap in a single go."

## Limitations

- Evaluation limited to only two datasets (300W and 300VW), with limited demonstration of robustness across diverse real-world conditions
- Inference speed of 32 fps is adequate but not compared against state-of-the-art real-time methods
- Model complexity introduced by DLAUs and self-attention modules may limit practical deployment on resource-constrained devices

## Confidence

- **High Confidence**: The architectural components (stacked hourglass networks, self-attention, DLAUs) are well-established in the literature, and the methodology follows standard practices for heatmap-based landmark detection
- **Medium Confidence**: The reported performance metrics (NME of 0.0047 on 300W) are impressive but lack comparison with other heatmap regression methods on the same metrics, making direct performance claims difficult to verify
- **Low Confidence**: The exact implementation details of DLAUs and self-attention modules are not fully specified, which could significantly impact reproducibility and performance
