# An Inception-Residual-Based Architecture with Multi-Objective Loss for Detecting Respiratory Anomalies

## Quick Facts
- arXiv ID: 2303.04104
- Source URL: https://arxiv.org/abs/2303.04104
- Reference count: 22
- Achieved up to 17.8% improvement over baseline with best Score of 74.5% in Task 2-1 of IEEE BioCAS 2022 challenge

## Executive Summary
This paper presents a deep learning system for detecting respiratory anomalies from audio recordings. The approach extracts spectrogram features using Gammatone and Continuous Wavelet transforms, processes them through an Inception-residual backbone with multi-head attention, and employs a learned linear combination to fuse features from different spectrograms. Evaluated on the SPRSound dataset in the IEEE BioCAS 2022 challenge, the system achieved significant improvements—up to 17.8%—over the baseline and reached top-1 performance in two tasks.

## Method Summary
The system extracts Gammatone and Continuous Wavelet spectrogram features from respiratory audio recordings. These features are processed by an Inception-residual backbone enhanced with multi-head attention mechanisms. Instead of simple concatenation, the method uses a learned linear combination to fuse embedding features from different spectrograms. The architecture is trained using a multi-objective loss function to optimize detection performance.

## Key Results
- Achieved up to 17.8% improvement over baseline on SPRSound dataset
- Reached top-1 performance in two tasks of IEEE BioCAS 2022 challenge
- Best Score of 74.5% achieved in Task 2-1

**Multi-head attention** - Why needed: Captures long-range dependencies and interactions between different frequency components. Quick check: Test attention weights for interpretability of important features.

**Multi-objective loss** - Why needed: Balances multiple detection tasks simultaneously for better overall performance. Quick check: Analyze individual task performance contributions.

## Architecture Onboarding

**Component map**: Gammatone/CWT transforms -> Inception-residual backbone -> Multi-head attention -> Linear combiner -> Output layer

**Critical path**: Feature extraction (Gammatone/CWT) → Inception-residual processing → Multi-head attention → Linear feature fusion → Classification

**Design tradeoffs**: Uses learned linear combination instead of simple concatenation for feature fusion, adding complexity but potentially improving performance; multi-objective loss balances multiple tasks but increases training complexity.

**Failure signatures**: Poor performance on recordings with significant background noise; potential overfitting to specific frequency ranges captured by chosen transforms; sensitivity to recording quality variations.
