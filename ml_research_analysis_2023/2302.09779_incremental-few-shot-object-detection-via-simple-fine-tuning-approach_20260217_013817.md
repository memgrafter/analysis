# Incremental Few-Shot Object Detection via Simple Fine-Tuning Approach

## Quick Facts
- **arXiv ID**: 2302.09779
- **Source URL**: https://arxiv.org/abs/2302.09779
- **Reference count**: 32
- **Primary result**: Achieves 4.3 AP on 1-shot, 9.9 AP on 5-shot, and 11.8 AP on 10-shot novel classes on COCO, outperforming previous iFSD methods

## Executive Summary
This paper tackles incremental few-shot object detection (iFSD), which requires incrementally learning new object classes from very few examples without re-training on the base classes. The proposed Incremental Two-stage Fine-tuning Approach (iTFA) is a simple fine-tuning strategy based on Faster R-CNN that addresses the challenge of catastrophic forgetting in iFSD. iTFA first trains the detector on abundant base classes using a class-agnostic box regressor, then separates the RoI feature extractor and classifier into base and novel branches, and finally fine-tunes only the novel branch with the few novel class examples. This approach prevents catastrophic forgetting by preserving the base knowledge and achieves competitive performance on the COCO, LVIS, and cross-dataset from COCO to PASCAL VOC benchmarks.

## Method Summary
The Incremental Two-stage Fine-tuning Approach (iTFA) modifies Faster R-CNN for incremental few-shot object detection through three key steps: 1) Base training with abundant base class data using a class-agnostic box regressor instead of class-specific regression, 2) Separation of the RoI feature extractor and classifier into base and novel branches, freezing the base branch to preserve knowledge, and 3) Fine-tuning only the novel branch (specifically W_N_fc2 and W_N_cls) with few-shot novel class examples. The method uses a linear classifier for better compatibility with separated feature spaces and employs a class-agnostic box regressor to prevent overfitting to novel classes while maintaining general localization ability.

## Key Results
- Achieves 4.3 AP on 1-shot, 9.9 AP on 5-shot, and 11.8 AP on 10-shot novel classes on COCO
- Significantly outperforms previous iFSD methods while maintaining base class performance
- Demonstrates effectiveness across COCO, LVIS, and cross-dataset from COCO to PASCAL VOC benchmarks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The class-agnostic regressor prevents overfitting on novel classes and preserves base knowledge by freezing its weights during fine-tuning.
- Mechanism: By removing class-specific bounding box parameters and using a single regressor trained on abundant base classes, the model gains a generic localization ability that generalizes to novel classes without requiring novel-class-specific tuning.
- Core assumption: The base-class training data contains sufficient diversity in object shapes and scales to cover the novel class distribution.
- Evidence anchors:
  - [abstract] "We train the object detector with a class-agnostic regressor using abundant base class data."
  - [section] "We change the class-specific regressor to the class-agnostic box regressor in the base training stage and use it to predict the bounding boxes of both base and novel classes."
  - [corpus] Weak. No direct corpus evidence supporting this claim; assumption is largely based on model design.
- Break condition: If novel classes contain object types with bounding box distributions vastly different from base classes, the frozen regressor will underfit or produce poor localization.

### Mechanism 2
- Claim: Separating the RoI feature extractor and classifier into base and novel branches prevents catastrophic forgetting by isolating feature learning for novel classes.
- Mechanism: By freezing the base branch and training only the novel branch, the model can adapt to new classes without modifying the feature space that supports base classes, maintaining classification boundaries for them.
- Core assumption: Base class feature space is sufficiently general and well-aligned to support both base and novel classes without realignment.
- Evidence anchors:
  - [abstract] "We separate the RoI feature extractor and classifier into the base and novel class branches for preserving base knowledge."
  - [section] "We first separate the base and novel classifiers and then freeze the base classifier and fine-tune only the novel classifier."
  - [corpus] No direct corpus evidence; assumption derived from the proposed method.
- Break condition: If the novel classes require fundamentally different feature representations not covered by the base feature space, performance will degrade on both base and novel classes.

### Mechanism 3
- Claim: Fine-tuning only the second fully connected layer (W_N_fc2) of the novel RoI feature extractor, rather than all layers, improves novel class feature alignment while preserving base knowledge.
- Mechanism: Freezing W_N_fc1 retains the general feature extraction capability from base training, while fine-tuning W_N_fc2 allows adaptation to novel class-specific feature nuances without disturbing the broader feature space.
- Core assumption: The first fully connected layer captures general object features that transfer across classes, while the second layer is more class-specific and benefits from fine-tuning.
- Evidence anchors:
  - [abstract] "We empirically explore compatibility between the fine-tuning layer and classifier for the accurate performance on novel classes."
  - [section] "We only separate the RoI feature extractor because the RoI features generated from the backbone and RPN have sufficient information about the objects in the image due to being trained with abundant base classes."
  - [corpus] No direct corpus evidence; this is an empirical observation from the ablation study.
- Break condition: If novel classes require significant feature space transformation beyond what W_N_fc2 can provide, fine-tuning only this layer will be insufficient.

## Architecture Onboarding

- Component map: Backbone (ResNet-50/101) -> RPN -> Base RoI Feature Extractor + Novel RoI Feature Extractor -> Base Classifier + Novel Classifier -> Class-agnostic Box Regressor

- Critical path:
  1. Backbone + RPN process input image to generate region proposals
  2. Each proposal goes through both base and novel RoI feature extractors
  3. Base features go through frozen base classifier
  4. Novel features go through fine-tuned novel classifier
  5. Class-agnostic regressor predicts bounding boxes
  6. Outputs combined predictions from both branches

- Design tradeoffs:
  - Separating branches adds model complexity and computation but prevents forgetting
  - Using class-agnostic regressor simplifies localization but may underperform class-specific regressor on highly diverse novel classes
  - Fine-tuning only W_N_fc2 preserves base knowledge but may limit novel class adaptation

- Failure signatures:
  - Poor base class performance indicates base branch interference
  - Poor novel class performance indicates insufficient novel branch adaptation
  - Inconsistent bounding boxes suggest class-agnostic regressor limitations
  - High computational cost suggests inefficiency in dual-branch processing

- First 3 experiments:
  1. Ablation study on fine-tuning layer selection (freeze all, fine-tune fc1 only, fine-tune fc2 only, fine-tune both)
  2. Comparison of class-specific vs. class-agnostic regressor performance
  3. Evaluation of linear vs. cosine classifier compatibility with separated feature spaces

## Limitations
- The class-agnostic regressor approach may underperform on novel classes with bounding box distributions vastly different from base classes
- The effectiveness of branch separation relies on base feature space being sufficiently general for novel classes
- The method's performance across multiple incremental learning stages has not been evaluated

## Confidence
- High: The general approach of using class-agnostic regression and branch separation is well-grounded in object detection literature
- Medium: The empirical results showing competitive performance on standard benchmarks
- Low: The long-term stability of the approach across multiple incremental learning stages
