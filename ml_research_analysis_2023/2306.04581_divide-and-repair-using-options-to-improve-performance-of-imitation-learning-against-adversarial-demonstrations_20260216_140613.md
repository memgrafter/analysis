# Divide and Repair: Using Options to Improve Performance of Imitation Learning Against Adversarial Demonstrations

## Quick Facts
- **arXiv ID:** 2306.04581
- **Source URL:** https://arxiv.org/abs/2306.04581
- **Reference count:** 40
- **Key outcome:** Options-based trajectory repair improves imitation learning robustness against adversarial demonstrations, achieving up to 400% reward improvement in LunarLander.

## Executive Summary
This paper addresses the vulnerability of imitation learning to adversarial demonstrations by proposing a trajectory repair technique using temporally extended policies (options). The approach partitions trajectories into segments, uses divergence measures to identify and discard adversarially modified parts, and trains options on the remaining segments. Theoretical analysis and experiments demonstrate that this method can effectively prevent performance degradation when learning from corrupted demonstrations.

## Method Summary
The proposed method consists of two main steps: (1) defining a trajectory divergence measure using occupancy measures and Fréchet distance to detect adversarially modified trajectory parts, and (2) using an options-based algorithm to partition trajectories and learn policies only from the accepted (non-adversarial) parts. The approach includes a return ratio condition to prevent false positives in the classification process, ensuring novel but valid strategies aren't discarded.

## Key Results
- Achieves up to 400% improvement in rewards compared to baseline imitation learning without repair
- Successfully identifies and discards adversarially modified trajectory parts
- Maintains learning performance even with significant trajectory corruption
- Classification accuracy of trajectory acceptance/rejection is high for most attack scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Trajectory partitioning prevents degradation by isolating adversarial segments
- Mechanism: Divides trajectories into M equal parts, computes divergence measures per part, accepts only admissible parts for training
- Core assumption: Adversarial modifications are localized within trajectory segments

- Break condition: If adversarial changes are uniformly distributed across all parts

### Mechanism 2
- Claim: Divergence-based classification effectively distinguishes benign from adversarial trajectory parts
- Mechanism: Uses occupancy measure (OC) and Fréchet distance (FD) metrics with supervised classifier
- Core assumption: Benign and adversarial parts have statistically separable OC/FD distributions
- Evidence anchors: [abstract], [section], [corpus] Weak external validation
- Break condition: If adversarial parts mimic benign OC/FD patterns

### Mechanism 3
- Claim: Return ratio condition prevents false positives from divergence metrics
- Mechanism: Accepts parts with high return even if OC/FD indicate high divergence
- Core assumption: Reward return is reliable proxy for task correctness
- Evidence anchors: [abstract], [section], [corpus] Weak evidence for heuristic
- Break condition: If reward function is manipulated or return is noisy

## Architecture Onboarding

- **Component map:**
  - Clean trajectory set (T_clean) -> Trajectory partitioner -> Divergence measure module -> Classifier -> Return ratio guard -> Options learner -> Option chainer

- **Critical path:**
  1. Partition all trajectories into M parts
  2. Compute OC and FD for each part
  3. Classify each part as Accept/Reject
  4. Override Reject if return ratio > 1−ϵ_p
  5. Train options on accepted parts
  6. Execute chained options at runtime

- **Design tradeoffs:**
  - Coarse partitioning (small M) vs. fine partitioning (large M): trade accuracy vs. computational overhead
  - Classifier complexity vs. sample size: more complex models need more labeled data
  - Strict divergence threshold vs. flexible threshold: stricter reduces false positives but may discard useful novel trajectories

- **Failure signatures:**
  - High variance in rewards after training → possible misclassification of adversarial parts
  - No learning progress despite clean data → option chaining broken or all parts rejected
  - Classifier rejects all parts → divergence metrics too strict or training data mismatched

- **First 3 experiments:**
  1. Validate partitioning by training with clean trajectories split into 2 vs. 3 parts and comparing reward
  2. Train the classifier on synthetic OC/FD data with known labels; measure accuracy
  3. Test trajectory repair on a small set of adversarially perturbed trajectories; check if reward returns to clean level

## Limitations
- Assumes adversarial modifications are localized within trajectory segments; may not work if attacks are uniformly distributed
- Classifier accuracy depends on data quality and may not generalize to real-world adversarial distributions
- Return ratio guard relies on reward being a reliable proxy for task correctness, which may not hold if reward function is manipulated

## Confidence
- **High**: The partitioning + options framework is well-defined and can be reproduced given the specifications
- **Medium**: The divergence measures (OC, FD) are theoretically sound, but classifier performance depends on data quality
- **Low**: Claims about 400% reward improvement lack independent verification; results may be sensitive to hyperparameter choices
