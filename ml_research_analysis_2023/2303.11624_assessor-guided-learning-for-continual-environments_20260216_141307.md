# Assessor-Guided Learning for Continual Environments

## Quick Facts
- arXiv ID: 2303.11624
- Source URL: https://arxiv.org/abs/2303.11624
- Reference count: 40
- One-line primary result: AGLA achieves 1-4% improvements in average accuracy across four datasets compared to ten baseline algorithms.

## Executive Summary
This paper addresses the challenge of catastrophic forgetting in continual learning by introducing Assessor-Guided Learning Approach (AGLA). The method uses a sequence-aware assessor to dynamically weight loss functions for each sample, balancing plasticity and stability through meta-learning. A compensated over-sampling strategy addresses class imbalance in memory buffers. Evaluated on four datasets under class-incremental and task-incremental settings, AGLA outperforms ten baselines with consistent improvements in average accuracy while maintaining competitive forgetting rates.

## Method Summary
AGLA introduces a bi-level optimization framework where an LSTM-based assessor generates meta-weights for three loss functions (cross-entropy, dark experience replay, and distillation) to guide the base learner. The assessor is trained via meta-learning to minimize validation loss of the base learner. A compensated over-sampling strategy augments memory samples with self-correcting transformations weighted by feature space distance to prevent class imbalance. The approach is evaluated on four datasets (Split MNIST, Split CIFAR-10, Split CIFAR-100, Split Mini-ImageNet) using ResNet18 as the base model.

## Key Results
- AGLA achieves 1-4% improvements in average accuracy across all four datasets compared to ten baseline algorithms
- Maintains competitive average forgetting rates while improving forward and backward transfer
- Performance remains stable with varying memory sizes, demonstrating robustness to memory budget constraints

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Assessor-guided learning uses a sequence-aware assessor to dynamically weight loss functions per sample, achieving a balance between plasticity and stability.
- Mechanism: The assessor produces three meta-weights (α, β, γ) for each sample, controlling the influence of cross-entropy loss (current task), DER loss (past task preservation), and distillation loss (model knowledge retention). These weights are learned via meta-training using a bi-level optimization scheme where the assessor is updated to minimize validation loss of the base learner.
- Core assumption: The assessor can learn to distinguish high-quality samples (promoting forward/backward transfer) from poor samples (causing catastrophic forgetting) through meta-learning.
- Evidence anchors: [abstract] "The assessor is trained in a meta-learning manner with a meta-objective to boost the learning process of the base learner." [section 4.2] "The training process of the base learner and the assessor is formulated as a bi-level optimization problem."
- Break condition: If the meta-weights converge to uniform values, the assessor fails to distinguish sample quality, leading to degraded performance.

### Mechanism 2
- Claim: Compensated over-sampling (COS) addresses class imbalance by augmenting memory samples with self-correcting transformations.
- Mechanism: COS augments old samples from memory using random transformations, then applies likelihood-ratio weighting based on feature space distance to compensate for out-of-distribution augmented samples. This prevents bias toward new classes while avoiding distributional shift.
- Core assumption: The feature space distance metric (using Gaussian likelihood ratio) can effectively identify and down-weight out-of-distribution augmented samples.
- Evidence anchors: [abstract] "A compensated over-sampling (COS) strategy is developed to overcome the class imbalanced problem of the episodic memory due to limited memory budgets." [section 4.3] "A compensated over-sampling (COS) strategy for continual learning where the learning process of augmented samples is compensated to offset out-of-distribution samples."
- Break condition: If the transformation space is not well-covered or the likelihood ratio estimation is inaccurate, COS may fail to prevent bias.

### Mechanism 3
- Claim: The bi-level optimization framework ensures the assessor learns to improve base learner performance by minimizing validation loss.
- Mechanism: The outer loop updates the assessor to minimize validation loss on transformed samples, while the inner loop updates the base learner using the meta-weights from the updated assessor. This creates a joint optimization where the assessor directly optimizes for base learner generalization.
- Core assumption: The validation set created through random transformations is representative enough to guide assessor training.
- Evidence anchors: [abstract] "The assessor is trained with a meta-objective to boost the learning process of the base learner." [section 4.2] "The training process of the base learner and the assessor is formulated as a bi-level optimization problem."
- Break condition: If the validation set transformation is too dissimilar from real data, the assessor may learn suboptimal meta-weights.

## Architecture Onboarding

- Component map: Input → Feature extraction → Assessor weight generation → Weighted loss computation → Parameter update → Memory augmentation → Next task

- Critical path: Input samples flow through the feature extractor, then the assessor generates meta-weights for the three loss components, which are combined to update the base learner parameters, followed by memory buffer updates with COS augmentation.

- Design tradeoffs:
  - Memory size vs. performance: Larger memory buffers improve performance but increase computational cost
  - Assessor complexity vs. training time: More complex assessors may provide better meta-weighting but require more training resources
  - Transformation diversity vs. augmentation quality: More diverse transformations improve generalization but may introduce noise

- Failure signatures:
  - Uniform meta-weights across all samples indicate assessor is not learning to distinguish quality
  - Performance degradation on old tasks with minimal improvement on new tasks suggests stability-plasticity imbalance
  - High variance in meta-weights across similar samples indicates assessor instability

- First 3 experiments:
  1. Compare AGLA with and without assessor on a simple class-incremental task (e.g., Split MNIST) to verify the assessor's contribution
  2. Test COS with different transformation sets to find the optimal balance between augmentation diversity and quality
  3. Evaluate memory size sensitivity by running AGLA with varying memory budgets on Split CIFAR-10

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can assessor-guided learning be effectively extended to few-shot continual learning scenarios where each task has only a limited number of samples?
- Basis in paper: [explicit] The paper mentions that existing approaches, including AGLA, "function with a large number of samples and over-fits quickly in the case of few samples in each task." It also states that "Our future work is directed to answer the few-shot continual learning problems handling a limited sample problem."
- Why unresolved: The current AGLA framework relies on having sufficient samples per task to train both the base learner and the assessor effectively. With few-shot scenarios, the meta-training strategy and the ability to distinguish between positive and negative samples through the assessor may be compromised.
- What evidence would resolve it: Developing and evaluating a variant of AGLA that incorporates techniques like meta-learning or episodic training specifically designed for few-shot learning, and demonstrating its effectiveness on benchmark few-shot continual learning datasets.

### Open Question 2
- Question: Can the assessor-guided learning framework be adapted to handle unsupervised continual learning, where task labels are not available during training?
- Basis in paper: [explicit] The paper states that "Our future work is also directed to unsupervised few-shot continual learning problems to address unavailable labels in the dynamic environment."
- Why unresolved: The current AGLA framework relies on labeled data to compute the loss functions (cross-entropy, DER, and distillation) and train the assessor. In an unsupervised setting, alternative objectives would need to be defined to guide the learning process without explicit labels.
- What evidence would resolve it: Proposing a novel unsupervised objective function for the assessor and base learner, and validating its performance on unsupervised continual learning benchmarks.

### Open Question 3
- Question: How can assessor-guided learning be implemented in a federated learning setting to preserve data privacy while enabling collaborative continual learning across multiple agents?
- Basis in paper: [explicit] The paper mentions that "Our work is also directed to address federated continual learning problems to handle the data privacy constraint."
- Why unresolved: Federated learning introduces challenges such as communication overhead, heterogeneous data distributions across agents, and the need to aggregate updates without accessing raw data. Integrating the assessor-guided learning framework with federated learning algorithms would require addressing these challenges.
- What evidence would resolve it: Designing a federated assessor-guided learning protocol that allows agents to collaboratively train assessors and base learners without sharing raw data, and evaluating its performance on federated continual learning benchmarks.

## Limitations

- The assessor's meta-learning mechanism lacks thorough empirical validation of its sample quality discrimination ability
- The computational overhead of the bi-level optimization framework is not quantified, raising scalability concerns
- Long-term stability of the model beyond evaluated task sequences remains unknown

## Confidence

- High confidence: The overall framework design and its theoretical motivation are well-established with consistent empirical improvements
- Medium confidence: The assessor's ability to distinguish sample quality through meta-learning is plausible but requires further validation
- Low confidence: The long-term stability and computational efficiency of the approach for larger-scale problems
