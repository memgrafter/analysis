# NLP-LTU at SemEval-2023 Task 10: The Impact of Data Augmentation and Semi-Supervised Learning Techniques on Text Classification Performance on an Imbalanced Dataset

## Executive Summary
This paper presents an ensemble approach for detecting and classifying online sexism in social media posts using fine-tuned transformer models (BERTweet, RoBERTa, and DeBERTa). The system employs data augmentation through back-translation and semi-supervised learning to address class imbalance challenges. The methodology demonstrates that augmenting all classes generally yields better performance than focusing solely on underrepresented classes, and that domain-specific fine-tuning of pre-trained language models outperforms generic approaches. The ensemble achieves competitive results with an F1-score of 0.8613, placing 10th in the SemEval-2023 Task 10 competition.

## Method Summary
The approach combines an ensemble of three transformer models (BERTweet, RoBERTa, and DeBERTa) with data augmentation and semi-supervised learning techniques. Back-translation using Google Translate API serves as the primary augmentation method, applied either to all classes or only underrepresented classes. For semi-supervised learning, the system employs pseudo-labeling on unlabeled in-domain data. The models are fine-tuned on the target domain to leverage domain-specific linguistic patterns. The ensemble aggregates predictions from individual models to produce final classifications, addressing the imbalanced nature of the online sexism detection task.

## Key Results
- Achieved F1-score of 0.8613 for sub-taskA, ranking 10th in the competition
- Domain-specific fine-tuning of PLMs outperformed generic pre-trained models
- Augmenting all classes via back-translation generally led to higher classification scores than balancing only underrepresented classes

## Why This Works (Mechanism)
The ensemble approach combines multiple transformer models, each capturing different aspects of linguistic patterns in online sexism detection. Back-translation augments the dataset by creating paraphrased versions of existing text, increasing diversity while preserving semantic meaning. This helps models generalize better to varied expressions of sexism. Semi-supervised learning leverages unlabeled in-domain data to expand the training distribution without manual annotation costs. The domain-specific fine-tuning allows models to adapt to the particular linguistic characteristics and context of online sexism discourse, which differs from general language patterns.

## Architecture Onboarding
Component map: Data -> Augmentation -> Model Ensemble (BERTweet, RoBERTa, DeBERTa) -> Prediction Aggregation -> Output

Critical path: Raw text → Pre-processing → Augmentation (optional) → Model fine-tuning → Ensemble voting → Classification

Design tradeoffs: The ensemble approach balances model diversity against computational cost, while data augmentation increases training data diversity but may introduce noise. Semi-supervised learning extends training data but depends on quality of pseudo-labels.

Failure signatures: Overfitting on augmented data, poor generalization to new contexts, sensitivity to translation quality in back-translation, and suboptimal ensemble weighting.

First experiments: 1) Baseline with single model without augmentation, 2) Individual transformer performance comparison, 3) Augmentation impact analysis (all-classes vs. minority-only).
