# On the Convergence Rate of Gaussianization with Random Rotations

## Quick Facts
- arXiv ID: 2306.13520
- Source URL: https://arxiv.org/abs/2306.13520
- Reference count: 40
- Primary result: Number of Gaussianization layers grows at least linearly with input dimension D, unlike constant-layer coupling flows

## Executive Summary
This paper analyzes the convergence rate of Gaussianization normalizing flows, which transform data to a standard normal distribution through iterative random rotations and dimension-wise nonlinear transforms. The key finding is that the number of required layers grows at least linearly with input dimension, in contrast to coupling-based normalizing flows where the number of layers is constant. This is because Gaussianization cannot capture dependencies between dimensions, which dominates in high dimensions. The linear scaling is proven analytically for Gaussian input and confirmed empirically on toy and real datasets.

## Method Summary
The method involves iteratively applying a random rotation followed by a dimension-wise nonlinear transform to make each marginal distribution standard normal. Multiple blocks are stacked: f(x) = (fdim ∘ frot)^L(x), where the dimension-wise transform is implemented using rational-quadratic splines. The convergence is measured via KL divergence between the output distribution and the standard normal distribution. The analysis compares this approach to coupling-based normalizing flows that explicitly model dependencies between dimensions.

## Key Results
- Number of Gaussianization layers required grows at least linearly with input dimension D (Ω(D) scaling)
- KL divergence convergence requires L ≥ log(L/L')(D+1)/2 layers for random rotations
- Coupling-based normalizing flows require only constant O(1) layers regardless of dimension
- Linear scaling is proven analytically for Gaussian input and confirmed empirically on toy and real datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The number of Gaussianization layers required grows at least linearly with input dimension D when using random rotations.
- Mechanism: Random rotations cannot capture inter-dimensional dependencies, so each layer can only reduce marginal non-Gaussianity independently. The covariance matrix has D(D+1)/2 degrees of freedom, but each layer only has D parameters, requiring Ω(D) layers.
- Core assumption: The target distribution is Gaussian with normalized trace (Assumption 1: tr Σ = D).
- Evidence anchors:
  - [abstract]: "the number of required layers grows at least linearly with the input dimension"
  - [section 4.1]: "at least L ≥ 1/2(D + 1) Gaussianization layers are required almost surely"
  - [corpus]: Weak evidence - corpus papers discuss convergence rates but not specifically Gaussianization scaling.
- Break condition: If rotations could be learned to diagonalize Σ in one step (which is theoretically possible but practically infeasible in high dimensions).

### Mechanism 2
- Claim: The convergence rate for KL divergence scales as L ≥ log(L/L')(D+1)/2 layers for random rotations.
- Mechanism: Each layer reduces the loss by a factor dependent on dimension, with the reduction rate 1 - 2/(D+2) becoming slower as D increases.
- Core assumption: L ≪ 1 (small initial loss) and eigenvalues are distinct (Assumption 2: λi ≠ λj).
- Evidence anchors:
  - [section 4.1]: "in the case L ≪ 1, the expected loss after L iterative Gaussianization blocks with random rotations is approximately: EQ1...L∈O(D)[L(L)] ≤ (1 - 2/(D+2))L"
  - [section 4.1]: "the number of layers L required to reduce the loss by a fixed amount scales at least linearly with the dimension D"
  - [corpus]: Weak evidence - corpus papers discuss convergence rates but not specifically Gaussianization's KL divergence scaling.
- Break condition: If L is not small (L ≫ 0) or eigenvalues are not distinct.

### Mechanism 3
- Claim: Coupling-based normalizing flows require only constant O(1) layers regardless of dimension, while Gaussianization requires Ω(D) layers.
- Mechanism: Coupling layers explicitly model dependencies between dimensions by reshaping active subspaces conditional on passive ones, while Gaussianization reshapes each dimension independently.
- Core assumption: The target distribution is Gaussian with normalized trace.
- Evidence anchors:
  - [section 4.3]: "the number of coupling blocks is independent of the problem dimension: Lcpl = Θ(1)"
  - [section 4.3]: "in contrast to Gaussianization, the number of coupling blocks is independent of dimension"
  - [corpus]: Weak evidence - corpus papers discuss coupling flows but not specifically comparing their scaling to Gaussianization.
- Break condition: If coupling layers cannot model the dependencies effectively or if the parameterization becomes insufficient.

## Architecture Onboarding

- Component map:
  Input data x → Rotation layer Qx → Dimension-wise transform fdim → Output z
  Multiple blocks stacked: f(x) = (fdim ∘ frot)^L(x)
  Loss: KL divergence between output distribution and standard normal

- Critical path:
  1. Choose rotation matrix Q (randomly or learned)
  2. Apply dimension-wise transform to make each marginal standard normal
  3. Repeat L times
  4. Measure convergence via KL divergence

- Design tradeoffs:
  - Random rotations: Simple but require Ω(D) layers
  - Learned rotations: Potentially fewer layers but suffer from overfitting in high dimensions
  - Coupling layers: Constant layers but more complex per-layer computation

- Failure signatures:
  - Linear increase in required layers with dimension (expected for random rotations)
  - Slower than linear scaling (may indicate dependencies being captured)
  - Overfitting to spurious non-Gaussian directions (when learning rotations)

- First 3 experiments:
  1. Test convergence on Gaussian data with varying covariance structures to verify Ω(D) scaling
  2. Compare random vs learned rotations on synthetic data to observe overfitting effects
  3. Test on multi-scale EMNIST to observe real-world scaling behavior and identify dimensionality thresholds

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the precise scaling behavior of Gaussianization layers when dependencies between dimensions are partially present?
- Basis in paper: [explicit] Section 5.1 describes toy experiments where some dimensions are independent of others
- Why unresolved: The paper only conjectures that the number of required layers might be constant for fixed number of dependent dimensions, but doesn't prove this rigorously
- What evidence would resolve it: A mathematical proof showing the exact relationship between the number of dependent dimensions and the scaling behavior

### Open Question 2
- Question: Can better rotations than random ones be found that maintain good performance in high dimensions?
- Basis in paper: [explicit] Section 4.2 discusses limitations of learned rotations and spurious non-Gaussian projections
- Why unresolved: The paper identifies the problem but doesn't provide a solution or prove that better rotations are impossible
- What evidence would resolve it: A method that can reliably find rotations that improve convergence rate in high dimensions, or a proof that no such method exists

### Open Question 3
- Question: How does the scaling behavior change when using learned dimension-wise transforms instead of analytically determined ones?
- Basis in paper: [explicit] Section 3.2 mentions that iterative training with learned transforms is currently the state-of-the-art for high dimensions
- Why unresolved: The paper focuses on analytically determined transforms and doesn't analyze how learned transforms affect the scaling
- What evidence would resolve it: Experimental comparison of scaling behavior using learned vs. analytically determined transforms on high-dimensional data

## Limitations

- The theoretical analysis assumes Gaussian input with normalized trace, which may not hold for real-world data
- The empirical validation uses a relatively small dataset (5k training points) and only two digits from EMNIST
- The analysis assumes distinct eigenvalues and small initial loss, which may not always be satisfied in practice

## Confidence

**High confidence** in:
- The Ω(D) scaling for random rotations on Gaussian input (Theorem 1)
- The O(1) scaling for coupling-based flows (Proposition 1)
- The fundamental difference in scaling behavior between Gaussianization and coupling flows

**Medium confidence** in:
- The linear scaling holding for non-Gaussian real-world data

- The practical significance of the scaling difference for typical use cases
