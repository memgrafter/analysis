# Heterogeneous-Branch Collaborative Learning for Dialogue Generation

## Quick Facts
- arXiv ID: 2303.11621
- Source URL: https://arxiv.org/abs/2303.11621
- Reference count: 9
- Primary result: Addresses branch homogeneity in collaborative learning by using attribute-aware data partitioning and dual knowledge distillation to improve diversity and response quality

## Executive Summary
This paper tackles the branch homogeneity problem in collaborative learning for dialogue generation, where multiple model branches converge to similar representations due to identical training objectives and datasets. The authors propose heterogeneous attribute-aware collaborative learning that divides training data into subsets based on dialogue attributes (coherence, informativeness, specificity) and trains each branch on its corresponding subset. They further introduce dual group-based knowledge distillation combining positive and negative distillation to encourage diverse learning while preserving knowledge transfer. The approach achieves state-of-the-art performance over existing collaborative learning methods with significant improvements in branch diversity and response quality.

## Method Summary
The method divides dialogue data into attribute-specific subsets using scoring methods for coherence, informativeness, and specificity. A collaborative learning framework with one master branch and multiple auxiliary branches is trained using both cross-entropy loss and dual knowledge distillation. Positive distillation transfers knowledge from auxiliary branches to the master branch, while negative distillation maximizes distance between branches. An orthogonal negative distillation technique is used to strengthen attribute-specific features while preserving shared knowledge for basic sentence generation. All branches are trained simultaneously on their respective attribute subsets.
