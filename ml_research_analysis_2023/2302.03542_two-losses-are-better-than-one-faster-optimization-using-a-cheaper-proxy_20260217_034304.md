# Two Losses Are Better Than One: Faster Optimization Using a Cheaper Proxy

## Quick Facts
- arXiv ID: 2302.03542
- Source URL: https://arxiv.org/abs/2302.03542
- Reference count: 40
- Key outcome: Proximal-point updates using cheap proxy loss accelerate convergence when main gradients are expensive, matching SGD rates on smooth objectives

## Executive Summary
This paper introduces an optimization algorithm that leverages a cheaper proxy loss function to accelerate convergence when the main objective has costly gradients. The method performs approximate proximal-point updates using the proxy while correcting with few stochastic gradients from the main loss. When the proxy is similar to the main objective (in a smoothness sense), the method achieves rates matching SGD on a smoother function, thus improving sample efficiency. Theoretical guarantees are provided for both convex and strongly convex cases, with experiments on logistic regression and ResNet training demonstrating practical benefits. The approach is particularly useful when gradients of the main loss are expensive or hard to compute.

## Method Summary
The method maintains two loss functions: a main loss (expensive to compute) and a proxy loss (cheap to compute). At each iteration, it performs an approximate proximal-point update using the proxy loss's gradient, then corrects this update using a small number of stochastic gradients from the main loss. The correction step is crucial for maintaining convergence guarantees. The algorithm is designed to work in the regime where computing the proxy gradient is significantly cheaper than computing the main loss gradient, but the proxy is still a reasonable approximation of the main objective in terms of smoothness properties.

## Key Results
- Achieves convergence rates matching SGD on a smooth function when proxy is sufficiently smooth relative to main loss
- Theoretical guarantees for both convex and strongly convex cases
- Practical experiments show improved sample efficiency on logistic regression and ResNet training
- Particularly effective when main loss gradients are expensive to compute

## Why This Works (Mechanism)
The method exploits the structure of the optimization problem by using a cheap proxy to approximate the expensive main objective. The proximal-point updates with the proxy provide a good direction most of the time, while the occasional corrections with actual main loss gradients ensure convergence to the correct optimum. The key insight is that if the proxy is smooth and close to the main objective, the expensive corrections can be infrequent while still maintaining good convergence properties.

## Limitations
- Theoretical analysis relies on strong assumptions about proxy smoothness and Lipschitz continuity that may not hold in practice
- Limited empirical validation beyond logistic regression and ResNet architectures
- Computational overhead of maintaining proxy gradients may offset benefits in some settings
- Performance depends critically on quality of proxy approximation to main objective
