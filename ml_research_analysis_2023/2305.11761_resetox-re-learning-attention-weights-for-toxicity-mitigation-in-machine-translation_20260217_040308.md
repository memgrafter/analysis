# ReSeTOX: Re-learning attention weights for toxicity mitigation in machine translation

## Quick Facts
- arXiv ID: 2305.11761
- Source URL: https://arxiv.org/abs/2305.11761
- Reference count: 17
- Key outcome: 57% reduction in added toxicity while maintaining 99.5% translation quality across 164 languages

## Executive Summary
ReSeTOX introduces a novel approach to mitigating added toxicity in neural machine translation without requiring model retraining. The method dynamically adjusts decoder self-attention weights during inference using a single gradient descent step when toxicity is detected, followed by beam search rescoring. By combining toxicity mitigation with translation quality preservation in a unified loss function, ReSeTOX achieves significant toxicity reduction while maintaining high translation quality across 164 languages. The approach is particularly effective for low-resource languages and performs well across different genders.

## Method Summary
ReSeTOX operates by detecting toxic tokens in NMT outputs using external toxicity classifiers (ETOX or Detoxify), then performing a single gradient descent update on the decoder's self-attention key-value pairs to minimize a combined loss function balancing toxicity mitigation and translation faithfulness. The method integrates with beam search decoding, updating attention weights conditionally when toxicity is detected and re-scoring hypotheses with the modified weights. The optimization is controlled by a hyperparameter α that balances the two objectives, with α=0.8 found to work well across languages. The approach requires no model retraining and can be applied to any pre-trained NMT model.

## Key Results
- Achieves 57% reduction in added toxicity across 164 languages
- Maintains 99.5% translation quality preservation (LaBSE similarity)
- Particularly effective on low-resource languages with up to 72% toxicity reduction
- Works across different genders with consistent performance

## Why This Works (Mechanism)

### Mechanism 1
Dynamic adjustment of decoder self-attention weights during inference can reduce added toxicity without retraining. When toxicity is detected, a single gradient descent step updates key-value pairs to minimize a combined loss function balancing toxicity mitigation and translation faithfulness. Core assumption: beam search hypotheses contain less toxic alternatives that can be selected through re-scoring.

### Mechanism 2
Toxicity classifier guidance steers attention weight updates toward less toxic outputs. The loss function incorporates toxicity scores to penalize toxic token generation, effectively steering attention away from toxic associations. Core assumption: the toxicity classifier accurately identifies toxic content and provides meaningful optimization gradients.

### Mechanism 3
Hyperparameter α controls the trade-off between toxicity reduction and translation quality preservation. The combined loss function balances translation faithfulness against toxicity mitigation, with α determining their relative importance. Core assumption: α can be tuned to find an optimal balance across languages and domains.

## Architecture Onboarding

- Component map: Input sentence -> NMT model with self-attention -> Toxicity classifier (ETOX/Detoxify) -> Loss function -> Translated sentence with reduced toxicity

- Critical path: 1) Generate translation using beam search 2) Apply toxicity classifier 3) If toxic, compute loss and update attention weights 4) Re-score beam hypotheses 5) Select final translation

- Design tradeoffs: Inference time vs. toxicity reduction, translation quality vs. mitigation, classifier accuracy vs. model performance

- Failure signatures: Increased inference time with little toxicity reduction, significant drop in translation quality, over-reliance on toxicity classifier

- First 3 experiments: 1) Baseline comparison without ReSeTOX 2) Ablation study with different α values 3) Classifier comparison (ETOX vs. Detoxify)

## Open Questions the Paper Calls Out

- How does ReSeTOX's performance vary across different language families and what linguistic factors contribute to these variations? The paper shows performance variations across 164 languages but lacks deep linguistic analysis of underlying factors.

- Can ReSeTOX's dynamic attention weight adjustment be optimized for better trade-offs between toxicity mitigation and translation quality? The paper only explores one α value (0.8) without systematic parameter space exploration.

- What is the impact of different toxicity detection tools on ReSeTOX's effectiveness and how can this dependency be mitigated? The paper compares two tools but doesn't explore strategies for reducing dependency on specific detection tools.

- How does ReSeTOX perform in real-world deployment scenarios with streaming translation and varying latency constraints? The paper focuses on batch processing without evaluating real-time deployment scenarios.

## Limitations

- Single gradient update step may be insufficient for effective toxicity mitigation across all languages
- Dual-classifier approach creates evaluation inconsistency (word-list vs. neural classifiers)
- Conditional update mechanism could introduce bias if toxicity classifier is imperfect

## Confidence

- High Confidence: General approach of dynamic attention adjustment during inference is sound
- Medium Confidence: Single gradient descent step mechanism needs more rigorous validation
- Low Confidence: Evaluation consistency across different toxicity classifiers
