# Energy Efficient Training of SNN using Local Zeroth Order Method

## Quick Facts
- arXiv ID: 2302.00910
- Source URL: https://arxiv.org/abs/2302.00910
- Reference count: 40
- Key outcome: LOCAL ZO method reduces backward pass neurons to <1% while maintaining accuracy, enabling up to 100x speedup

## Executive Summary
This paper addresses the computational inefficiency in training spiking neural networks (SNNs) caused by the non-differentiable Heaviside function. The authors propose a local zeroth-order (LOCAL ZO) method that approximates gradients at the neuron level without explicit gradient computation, enabling efficient backpropagation. The method theoretically connects to surrogate gradient approaches through different sampling distributions. Experiments on neuromorphic datasets demonstrate comparable accuracy to standard methods while dramatically reducing computational load in the backward pass.

## Method Summary
The paper introduces a local zeroth-order optimization approach for training SNNs that approximates gradients using zeroth-order information at each neuron. Instead of computing exact gradients through the non-differentiable Heaviside function, LOCAL ZO samples perturbations around current neuron parameters and uses function evaluations to estimate gradient directions. This approach enables backpropagation-like training while avoiding the computational overhead of explicit gradient calculations. The method is theoretically connected to surrogate gradient techniques, showing how different sampling distributions can reproduce various surrogate functions. By activating fewer than 1% of neurons during backward computation, the approach achieves significant efficiency gains while maintaining competitive accuracy on standard neuromorphic benchmarks.

## Key Results
- Achieves comparable accuracy to surrogate gradient methods on neuromorphic datasets
- Reduces active neurons in backward pass to less than 1% of total neurons
- Demonstrates up to 100x speedup in backward computation (based on neuron reduction)
- Shows better generalization than state-of-the-art energy-efficient SNN training (SATO)

## Why This Works (Mechanism)
The LOCAL ZO method works by approximating the gradient direction at each neuron using function evaluations rather than explicit differentiation. By sampling perturbations around current parameter values and observing the resulting changes in loss, the method estimates gradient information sufficient for parameter updates. This bypasses the need to compute gradients through the non-differentiable activation function. The theoretical analysis shows that different sampling distributions in the zeroth-order method correspond to different surrogate gradient functions, providing a unified framework for understanding various training approaches.

## Architecture Onboarding

**Component map**: Input -> Spike Encoding -> SNN Layers -> Output -> Loss Function -> LOCAL ZO Gradient Approximation -> Parameter Update

**Critical path**: Forward pass generates spikes and loss → LOCAL ZO samples perturbations at each neuron → Function evaluations estimate gradients → Parameters updated using approximated gradients

**Design tradeoffs**: The method trades off some gradient accuracy for computational efficiency, with the sampling distribution determining the quality of approximation. Fewer perturbations reduce computation but may yield noisier gradient estimates.

**Failure signatures**: Poor convergence may occur if sampling distributions are too narrow (insufficient exploration) or too wide (excessive noise). Training instability could result from inadequate gradient approximation quality.

**First experiments**: 1) Verify gradient approximation quality by comparing to analytical gradients on simple test functions. 2) Test convergence on a single SNN layer with synthetic data before full network training. 3) Validate neuron activity reduction by instrumenting the backward pass to count active neurons during training.

## Limitations
- Speedup claims based on neuron counts rather than actual timing measurements may not reflect real hardware performance
- Limited evaluation to small neuromorphic datasets raises questions about scalability to complex vision tasks
- Single baseline comparison (SATO) restricts generalizability of efficiency claims
- Theoretical connections to surrogate methods established but practical implications not fully explored
