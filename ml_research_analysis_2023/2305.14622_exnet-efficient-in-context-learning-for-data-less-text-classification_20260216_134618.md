# EXnet: Efficient In-context Learning for Data-less Text classification

## Quick Facts
- arXiv ID: 2305.14622
- Source URL: https://arxiv.org/abs/2305.14622
- Reference count: 10
- Key outcome: EXnet outperforms GPT-Neo by up to 48% in F1-score while being 86× smaller (15M parameters for smallest variant)

## Executive Summary
EXnet is a lightweight model designed for in-context learning in text classification without requiring parameter updates. The model addresses limitations of large pre-trained language models, which are computationally expensive, have inference costs, and provide poor accuracy on domain-specific tasks. EXnet employs a single encoder, projector blocks, cross-attention, and a feed-forward network to process query and support examples, predicting binary ("yes"/"no") classification outcomes. Evaluated on 9 unseen datasets, EXnet demonstrates strong cross-domain and cross-task generalization, outperforming GPT-Neo (1.3 billion parameters) by up to 48% in F1-score, despite being 86× smaller (15M parameters for the smallest variant). Increasing the number of in-context examples improves performance, particularly for complex, subjective tasks. EXnet's architecture and efficiency make it a practical solution for real-world text classification tasks requiring few-shot learning.

## Method Summary
EXnet uses a single encoder to process both query and support examples, enabling shared representations and reducing parameter overhead. The encoder generates embeddings for each support example and the query, which are concatenated and projected to a common space, then cross-attended to jointly reason about task semantics. The model employs asymmetric projector blocks (P1 deeper than P2) to refine support representations more than query representations, improving example utilization. Trained with binary cross-entropy loss and AdamW optimizer, EXnet achieves strong performance on binary text classification tasks without parameter updates during inference.

## Key Results
- Outperforms GPT-Neo (1.3B parameters) by up to 48% in F1-score
- 86× smaller than GPT-Neo (15M parameters for smallest variant)
- Strong cross-domain and cross-task generalization on 9 unseen datasets
- Performance improves with increased in-context examples (K), especially for complex tasks

## Architecture Onboarding

- Component map:
  - Encoder E -> Projector P1 -> Cross-attention C -> Feed-forward FFN
  - Encoder E -> Projector P2 -> Cross-attention C -> Feed-forward FFN
- Critical path:
  1. Input -> Encoder E -> K support embeddings + query embedding
  2. Concat support embeddings -> P1 -> projected support
  3. Query embedding -> P2 -> projected query
  4. Cross-attention (support as K/V, query as Q) -> joint representation
  5. Feed-forward -> sigmoid -> "yes"/"no" probability
- Design tradeoffs:
  - Single encoder vs. dual encoders: Saves parameters but requires shared representation space
  - Asymmetric projectors: Deeper support processing may help example relevance but risks overfitting
  - Cross-attention vs. concatenation: Attention allows selective relevance modeling; concatenation is cheaper but less flexible
- Failure signatures:
  - If cross-attention outputs near-uniform weights -> model ignores examples
  - If FFN saturates -> loss plateaus early
  - If P1 overfits -> training loss drops but validation F1 stays flat
- First 3 experiments:
  1. Train with K=2, measure cross-entropy vs. F1; check if loss correlates with accuracy
  2. Swap P1/P2 depths; observe impact on cross-task performance
  3. Remove cross-attention, use direct concatenation; compare to full model

## Limitations
- Evaluation primarily benchmarks against a single GPT-Neo variant, limiting generalizability
- Binary classification framing may oversimplify real-world multi-class scenarios
- Evaluation focuses on short text classification tasks, leaving performance on longer documents unexplored

## Confidence

- **Medium Confidence**: The claim of superior cross-domain generalization is supported but could be strengthened with additional baselines and more diverse evaluation datasets.
