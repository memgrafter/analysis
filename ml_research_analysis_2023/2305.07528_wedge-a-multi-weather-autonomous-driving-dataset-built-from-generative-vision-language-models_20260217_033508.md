# WEDGE: A multi-weather autonomous driving dataset built from generative vision-language models

## Quick Facts
- arXiv ID: 2305.07528
- Source URL: https://arxiv.org/abs/2305.07528
- Reference count: 40
- Primary result: WEDGE improves truck detection by 4.48 AP on real-world weather benchmarks

## Executive Summary
WEDGE is a synthetic autonomous driving dataset containing 3,360 images across 16 weather conditions, generated using DALL-E 2 via structured prompting. The dataset includes 16,513 bounding box annotations supporting weather classification and 2D object detection tasks. It addresses the scarcity of diverse adverse weather data for autonomous driving perception by creating controlled weather scenarios that preserve object visibility and structural integrity. WEDGE demonstrates that synthetic weather data can improve real-world weather benchmark performance, achieving up to 4.48 AP improvement for truck detection on the DAWN dataset.

## Method Summary
The dataset was created using DALL-E 2 API calls with structured prompts combining scenes (highway, road, traffic jam), object classes (cars, trucks, bus, people), and weather conditions (snowing, raining, foggy, etc.). Each weather condition contains 210 images, manually verified and annotated with bounding boxes. The dataset was used to fine-tune Faster R-CNN detectors (MobileNet-Large and ResNet50 backbones) pre-trained on COCO, with performance evaluated on both synthetic data and real-world weather benchmarks like DAWN.

## Key Results
- WEDGE contains 3,360 images across 16 weather conditions with 16,513 bounding box annotations
- Baseline classification accuracy on synthetic data: 53.87% (MobileNet-Large)
- Baseline detection mAP on synthetic data: 45.41
- Fine-tuning on WEDGE improves truck AP by 4.48 on DAWN-All benchmark

## Why This Works (Mechanism)

### Mechanism 1
DALL-E 2 can generate realistic synthetic driving scenes across diverse weather conditions that preserve object visibility and structural integrity for perception tasks. The vision-language model conditions image generation on weather-specific prompts, producing scene variants that simulate adverse weather effects while maintaining recognizable objects and drivable contexts.

### Mechanism 2
Fine-tuning state-of-the-art object detectors on WEDGE improves real-world weather benchmark performance, particularly for well-represented object classes like trucks. Synthetic weather data provides additional adversarial examples that expose detectors to out-of-distribution conditions, improving generalization to real adverse weather through domain adaptation.

### Mechanism 3
The dataset's class and weather distribution enables robust multi-weather perception by simulating the unbalanced object frequencies and visibility challenges encountered in real driving. By generating diverse weather conditions with controlled object distributions, the dataset exposes models to realistic adverse scenarios where object detection difficulty varies by weather type.

  - Quick check question: How does prompt structure (objects, scenes, weather) influence the generated image content and weather effects?

- Concept: Sim2Real domain adaptation and transfer learning
  - Why needed here: Fine-tuning detectors on synthetic data requires understanding when and how synthetic-to-real transfer succeeds or fails, particularly for different object classes
  - Quick check question: What factors determine whether fine-tuning on synthetic weather data improves or hurts real-world detection performance?

- Concept: Weather effects on computer vision and perception
  - Why needed here: Different weather conditions affect object visibility and detection differently; understanding these effects helps interpret why certain classes benefit more from synthetic training
  - Quick check question: How do fog, rain, dust, and snow each uniquely impact object detection performance in autonomous driving?

## Architecture Onboarding

- Component map: DALL-E 2 API calls with structured prompts → image collection → manual verification → annotation → dataset structure → baseline evaluation → fine-tuning → real-world benchmark evaluation
- Critical path: 1. Generate synthetic images via DALL-E 2 API with weather-specific prompts 2. Manually verify and annotate images with bounding boxes 3. Establish baseline classification and detection performance on synthetic data 4. Fine-tune pre-trained detectors on WEDGE 5. Evaluate fine-tuned models on real-world weather benchmarks (DAWN)
- Design tradeoffs: Prompt specificity vs. generation diversity; annotation effort vs. model performance; synthetic data quality vs. real-world transfer
- Failure signatures: Poor real-world performance despite good synthetic results; inconsistent weather effects across similar prompts; unrealistic object appearances or placements
- First 3 experiments: 1. Generate small validation set with varied weather prompts and evaluate image quality manually 2. Fine-tune simple detector on synthetic data and test on held-out real weather dataset 3. Compare detection performance across different weather conditions to identify transfer patterns

## Open Questions the Paper Calls Out

### Open Question 1
How can we quantitatively measure and minimize the Sim2Real gap for synthetic weather conditions, particularly for rare events like tornadoes? The paper identifies tornadoes as producing unrealistic images and mentions this may be due to the inability to find hyper-realistic training images captured in these adverse conditions.

### Open Question 2
What architectural modifications or training strategies could prevent fine-tuning on WEDGE from harming performance on other object categories? The paper notes that fine-tuning improves truck detection but "fine-tuning hurts performance for other categories."

### Open Question 3
How can prompt engineering be optimized to generate more geographically diverse and temporally accurate imagery that avoids region-centric correlations? The paper identifies "region-centric correlations (eg. cherry blossoms associated with spring)" as anomalies in WEDGE.

## Limitations

- The paper's Sim2Real transfer claims are limited to truck detection, with no comprehensive validation across diverse object classes
- Quality and realism of synthetic weather effects across all 16 conditions remains unclear, particularly for rare weather types
- The dataset may contain geographic and temporal biases due to limitations in the underlying DALL-E 2 training data

## Confidence

- **High Confidence**: Dataset creation methodology (DALL-E 2 prompting and manual annotation) is clearly described and reproducible
- **Medium Confidence**: Baseline classification and detection performance on synthetic data (53.87% accuracy, 45.41 mAP) is measurable and verifiable
- **Low Confidence**: Claims about real-world performance improvements lack comprehensive validation across diverse object classes and weather conditions
