# On Modeling Long-Term User Engagement from Stochastic Feedback

## Quick Facts
- **arXiv ID**: 2302.06101
- **Source URL**: https://arxiv.org/abs/2302.06101
- **Reference count**: 15
- **Primary result**: RL-based method for recommender systems improves long-term user engagement without candidate item storage overhead, achieving 2.72% VV and 1.59% DUR increases in online A/B tests.

## Executive Summary
This paper addresses the challenge of improving long-term user engagement in recommender systems using reinforcement learning while avoiding the computational overhead of storing candidate item sets. The authors propose a method that models the correlation between user engagement and recommended items directly from offline logs generated by an existing behavior policy. By leveraging distributional RL techniques, the approach also accounts for randomness in user feedback and interaction termination, which are commonly overlooked in prior work. Online experiments on a short-video recommendation system demonstrate significant improvements in engagement metrics.

## Method Summary
The method learns a scoring function to rank items based on long-term user engagement without requiring candidate item storage. It uses distributional RL to model randomness in rewards and termination, estimating the value distribution of the behavior policy from offline data. The approach incorporates learned termination probabilities into the discount factor, making the value distribution aware of interaction termination likelihood. A neural network with shared embeddings for both value and termination prediction is trained using quantile regression to approximate the value distribution.

## Key Results
- Online A/B test showed 2.72% increase in average videos viewed per user (VV)
- Online A/B test showed 1.59% increase in average viewing duration (DUR)
- Significant improvements in click-through rate (CTR) and completion rate (CVR)
- Eliminates computational overhead of storing candidate item sets

## Why This Works (Mechanism)

### Mechanism 1
The proposed method avoids candidate item storage overhead by modeling the correlation between user engagement and recommended items directly from offline logs. Since the behavior policy is already highly optimized, its logs contain implicit information about which items drive long-term engagement. The model learns this correlation without needing the full candidate set. Core assumption: The behavior policy is sufficiently optimized that its logs capture meaningful engagement patterns. Break condition: If the behavior policy is not well-optimized, the logs will not contain useful engagement patterns.

### Mechanism 2
The method incorporates stochasticity in rewards and termination behavior using distributional RL and learned termination probabilities. The distributional RL framework models rewards as random variables rather than fixed values. The discount factor is modified to incorporate learned termination probabilities, making the value distribution aware of when interactions are likely to end. Core assumption: User feedback and interaction termination are inherently stochastic processes. Break condition: If user behavior is more deterministic than assumed, the complexity of distributional RL may be unnecessary.

### Mechanism 3
The modified distributional Bellman operator with learned termination probabilities is a contraction mapping. The paper proves that the new operator T_ℓ^π is a η-contraction in the Wasserstein metric, ensuring convergence of the learning algorithm. Core assumption: The mathematical properties of the modified Bellman operator hold under the stated conditions. Break condition: If the termination probability estimates are poor, the contraction property may not hold in practice.

## Architecture Onboarding

- **Component map**: Feature embedding module -> Shared backbone -> Value head -> Termination head -> Target network
- **Critical path**: 1. Embed input features 2. Process through shared layers 3. Compute value distribution via quantile regression 4. Compute termination probability 5. Apply modified Bellman update with termination-weighted discount 6. Backpropagate combined loss
- **Design tradeoffs**: Using shared embeddings vs separate ones: Shared saves parameters but may introduce interference; Number of quantiles (200 used): More quantiles capture distribution better but increase computation; Target network update frequency (every 100 steps): More frequent updates track changes better but may destabilize learning
- **Failure signatures**: Training instability: Check target network update frequency and learning rates; Poor engagement prediction: Verify quantile regression implementation and termination probability estimates; No improvement over baseline: Confirm behavior policy logs are sufficiently diverse and the model is learning meaningful correlations
- **First 3 experiments**: 1. Validate quantile regression implementation by checking if learned quantiles match empirical reward distributions on a simple synthetic dataset 2. Test termination probability prediction accuracy on held-out data from behavior policy logs 3. Compare learned value distributions against empirical returns to verify the distributional RL component is functioning correctly

## Limitations
- No baseline comparisons provided to assess relative improvement over simpler methods
- Results may not generalize beyond short-video recommendation domain
- Method's effectiveness depends heavily on behavior policy being well-optimized

## Confidence
- **Medium** for the core engagement improvement claims, primarily due to the absence of baseline comparisons in the paper
- **Low** confidence in generalizability to different domains beyond short-video recommendation
- **Medium** confidence in the theoretical properties of the modified Bellman operator due to lack of independent verification

## Next Checks
1. Implement a simpler baseline that models stochasticity without distributional RL to determine if the added complexity is necessary for the observed gains
2. Test the method on logs from a less optimized behavior policy to assess sensitivity to the core assumption about behavior policy quality
3. Verify the distributional RL implementation by comparing learned value distributions against empirical return distributions on validation data
