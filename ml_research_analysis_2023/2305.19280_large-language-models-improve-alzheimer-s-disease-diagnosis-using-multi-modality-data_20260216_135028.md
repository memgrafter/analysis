# Large language models improve Alzheimer's disease diagnosis using multi-modality data

## Quick Facts
- arXiv ID: 2305.19280
- Source URL: https://arxiv.org/abs/2305.19280
- Reference count: 25
- Primary result: Achieves state-of-the-art performance on ADNI dataset for multi-class AD diagnosis using GPT-4 embeddings and cross-attention fusion

## Executive Summary
This paper presents a novel approach for diagnosing Alzheimer's disease (AD) using multi-modal data fusion with large language models. The authors propose leveraging GPT-4 to process and embed non-image patient data, then using cross-attention mechanisms to fuse these embeddings with image features extracted from PET and MRI scans. The method achieves superior performance across binary, ternary, and quaternary classification tasks on the ADNI dataset, outperforming existing techniques while demonstrating the potential of LLMs in medical diagnosis applications.

## Method Summary
The method uses GPT-4 to convert structured patient information (clinical, genetic, cognitive test results) into 64-dimensional feature embeddings, while ConvNeXt-S extracts image features from PET and MRI scans. A cross-attention mechanism then fuses these multi-modal features by aligning image and non-image representations. The fused features are classified using an MLP with dynamic output shape that adapts to different classification tasks (binary, ternary, quaternary). The model is trained end-to-end on the ADNI dataset with standard classification metrics.

## Key Results
- Achieves state-of-the-art accuracy, specificity, and sensitivity on ADNI dataset
- Outperforms existing techniques in binary classification (AD vs. NC), ternary classification (EMCI vs. LMCI vs. NC), and quaternary classification tasks
- Demonstrates effectiveness of multi-modal fusion through ablation experiments
- Shows GPT-4 effectively captures relationships in non-image patient data for AD diagnosis

## Architecture Onboarding

- Component map: ConvNeXt-S (MRI) → Cross-attention → GPT-4 embeddings → Cross-attention → ConvNeXt-S (PET) → Cross-attention → MLP → Classification output
- Critical path: ConvNeXt-S → Cross-attention → GPT-4 embeddings → MLP → Classification output
- Design tradeoffs:
  - Using two separate image encoders vs. a shared encoder (better specialization but more parameters)
  - GPT-4 vs. smaller specialized medical language models (better general knowledge but higher computational cost)
  - Cross-attention vs. concatenation vs. other fusion methods (better alignment but potentially more complex)
- Failure signatures:
  - Overfitting to ADNI dataset (check validation performance on external datasets)
  - Poor generalization across different AD stages (monitor performance on MCI vs. AD classifications)
  - Ineffective use of non-image data (compare performance with and without non-image features)
- First 3 experiments:
  1. Train with only image data (MRI and PET) to establish baseline performance
  2. Train with only non-image data processed by GPT-4 to assess standalone contribution
  3. Train with different non-image embedding dimensions (16, 32, 64, 128) to find optimal size
