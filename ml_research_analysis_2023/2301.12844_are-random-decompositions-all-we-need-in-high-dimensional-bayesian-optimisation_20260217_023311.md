# Are Random Decompositions all we need in High Dimensional Bayesian Optimisation?

## Quick Facts
- arXiv ID: 2301.12844
- Source URL: https://arxiv.org/abs/2301.12844
- Authors: 
- Reference count: 40
- Key outcome: Random tree decompositions achieve optimal worst-case expected mismatch between true black-box function and surrogate model, leading to state-of-the-art performance in high-dimensional Bayesian optimization

## Executive Summary
This paper addresses the challenge of scaling Bayesian optimization (BO) to high-dimensional spaces by proposing random tree-based decompositions instead of data-driven approaches. The key insight is that learning decompositions from optimization data can lead to locally optimal but globally suboptimal decompositions, whereas random sampling achieves optimal worst-case bounds. The authors develop the Random Decomposition Upper Confidence Bound (RDUCB) algorithm, which samples random tree decompositions and uses additive acquisition functions for efficient optimization. Empirical results demonstrate that RDUCB outperforms previous state-of-the-art methods, particularly in high-dimensional settings.

## Method Summary
RDUCB samples random tree decompositions with equal edge selection probability and uses additive GP kernels to model the black-box function. The additive structure enables efficient optimization of the UCB acquisition function using message passing algorithms. The algorithm iteratively samples decompositions, fits GP surrogates, optimizes the acquisition function, and evaluates the black-box function at suggested points. This approach avoids overfitting to local function structure while maintaining computational tractability through the additive decomposition.

## Key Results
- RDUCB achieves best regret of 0.2 ± 0.04 on Stybtang function at 100 dimensions, compared to 0.4 ± 0.08 for the previous state-of-the-art Tree algorithm
- Integration of random decomposition into HEBO improves high-dimensional performance from Bayesmark benchmarks, with 20% relative improvement in optimization efficiency
- Theoretical guarantee shows random decomposition achieves optimal worst-case expected mismatch bound against adversarial function selection

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Random tree decompositions avoid overfitting to local function structure during BO optimization
- Mechanism: By sampling decompositions independently of collected data, the algorithm prevents learning spurious local interactions that mislead optimization paths toward suboptimal regions
- Core assumption: The true black-box function can be well-approximated by some tree-based decomposition across the entire search space
- Evidence anchors:
  - [abstract]: "data-driven learners of decompositions can be easily misled towards local decompositions that do not hold globally across the search space"
  - [section 3]: Provides empirical example where data-driven decomposition learner (Tree algorithm) gets stuck in local mode due to falsely learning complete separability
  - [corpus]: No direct evidence, but related work on Hoeffding decomposition suggests decomposition methods can capture interaction structures without overfitting
- Break condition: If the true function requires non-tree decompositions (e.g., cycles or higher-order interactions) that cannot be well-approximated by any tree structure

### Mechanism 2
- Claim: Random sampling achieves optimal worst-case expected mismatch between true function and surrogate model
- Mechanism: Theorem 4.5 proves that uniformly random tree selection minimizes expected mismatch against adversarial function selection, effectively trading off information gain and functional approximation error
- Core assumption: The class of tree-based decompositions with bounded number of edges provides sufficient representational power for the target functions
- Evidence anchors:
  - [section 4.1]: Theorem 4.5 states "for the scheme Sr that selects a decomposition from G uniformly at random, the expected sum of mismatches admits the following bound..."
  - [section 4.2]: Corollary 4.2 formalizes the cumulative regret bound incorporating expected mismatch
  - [corpus]: No direct evidence; this is a novel theoretical contribution
- Break condition: When the adversarial function can exploit the uniform randomness to maintain constant high mismatch across all possible tree structures

### Mechanism 3
- Claim: Additive UCB acquisition functions can be efficiently optimized using message passing on random tree decompositions
- Mechanism: The additive structure of the UCB acquisition function (sum over components) enables decomposition into smaller subproblems that can be solved independently and combined via message passing
- Core assumption: The tree structure enables efficient message passing algorithms without cycles that would complicate the computation
- Evidence anchors:
  - [section 2.2]: "if we utilise an acquisition function with an additive structure... we can determine novel query points to evaluate very efficiently using message passing (Rolland et al., 2018)"
  - [section 4.2]: Mentions "message passing optimisers that can better exploit additive acquisition structures"
  - [corpus]: No direct evidence; relies on established message passing techniques from graphical models
- Break condition: When tree decompositions become too large or complex for efficient message passing to remain tractable

## Architecture Onboarding

- Component map:
  Random tree sampler -> GP surrogate model -> Message passing optimizer -> Data buffer -> Main loop

- Critical path:
  1. Sample random tree decomposition
  2. Fit GP surrogate with additive kernel based on sampled tree
  3. Optimize additive UCB acquisition using message passing
  4. Evaluate black-box function at suggested point
  5. Update data buffer and repeat

- Design tradeoffs:
  - Random vs. learned decompositions: Random avoids local overfitting but may miss optimal structure
  - Tree vs. other decomposition types: Trees enable efficient message passing but may be too restrictive
  - Exploration vs. exploitation: UCB parameter βt balances these competing objectives

- Failure signatures:
  - Poor optimization performance: May indicate insufficient representational power of tree decompositions
  - High computational cost: Could suggest message passing on large trees is becoming intractable
  - Unstable GP fitting: Might indicate inappropriate kernel hyperparameters or insufficient data

- First 3 experiments:
  1. Implement random tree sampler and verify uniform edge selection probability across multiple runs
  2. Test GP fitting with additive kernels on synthetic decomposable functions with known structure
  3. Benchmark message passing optimization on small tree decompositions with known optimal acquisition values

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the theoretical limit on how much random tree decompositions can improve performance in extremely high-dimensional spaces (e.g., thousands of dimensions)?
- Basis in paper: [inferred] The paper demonstrates empirical gains of RDUCB over Tree in high-dimensional settings, but the theoretical analysis focuses on tree decompositions with a fixed number of edges. The scalability analysis in Section 5.3 only goes up to 250 dimensions for Stybtang and 180 for LassoBench DNA.
- Why unresolved: The theoretical bound in Proposition 4.4 shows that the maximum information gain for a squared exponential kernel following a tree decomposition is upper-bounded by γ_T ≤ O(d(logT)^3). However, this bound doesn't directly address the performance degradation that might occur as the dimensionality increases beyond the tested range. The paper doesn't provide a theoretical analysis of how the performance of RDUCB scales with dimensionality beyond the empirical results.
- What evidence would resolve it: Conducting experiments on problems with thousands of dimensions and analyzing the performance degradation (if any) would provide empirical evidence. Additionally, deriving a tighter theoretical bound on the performance of RDUCB that accounts for the increased dimensionality would strengthen the theoretical understanding.

### Open Question 2
- Question: How does the performance of RDUCB compare to other decomposition methods when the black-box function has a non-tree-structured decomposition?
- Basis in paper: [explicit] The paper focuses on tree-based decompositions and provides theoretical guarantees for this class. It mentions that other decomposition methods exist but doesn't directly compare RDUCB to them in the context of non-tree-structured functions.
- Why unresolved: The theoretical analysis assumes tree-based decompositions, and the empirical evaluation focuses on problems where tree decompositions are effective. The paper doesn't explore scenarios where the black-box function has a more complex decomposition structure, such as cycles or higher-order interactions.
- What evidence would resolve it: Conducting experiments on benchmark problems with known non-tree-structured decompositions and comparing the performance of RDUCB to other decomposition methods (e.g., those that can handle cycles or higher-order interactions) would provide empirical evidence. Additionally, extending the theoretical analysis to handle more general decomposition structures would strengthen the understanding of RDUCB's limitations.

### Open Question 3
- Question: Can the random decomposition strategy be adapted to handle non-numerical inputs (e.g., graphs or strings) effectively?
- Basis in paper: [explicit] The paper acknowledges that RDUCB cannot handle non-numerical inputs and states that this is a challenge not only for RDUCB but also for other decomposition-based techniques.
- Why unresolved: The paper doesn't propose a solution for handling non-numerical inputs and doesn't explore the theoretical challenges associated with defining a notion of decomposition for such input types.
- What evidence would resolve it: Developing a novel decomposition rule that can handle non-numerical inputs and evaluating its performance on benchmark problems with such inputs would provide empirical evidence. Additionally, extending the theoretical analysis to handle non-numerical inputs and deriving bounds on the performance of the adapted algorithm would strengthen the theoretical understanding.

## Limitations

- Random tree decompositions may be too restrictive for black-box functions with non-tree interaction structures (cycles or higher-order interactions)
- The algorithm cannot handle non-numerical inputs, limiting its applicability to certain problem domains
- Theoretical regret bounds depend on problem-specific constants that are not fully characterized

## Confidence

- High: The core claim that random decompositions avoid local overfitting compared to data-driven approaches is well-supported by both theory (Theorem 4.5) and empirical evidence (Figure 1, Section 3)
- Medium: The theoretical regret bounds are sound but their practical implications depend on problem-specific constants not fully characterized in the paper
- Medium: The empirical performance improvements are consistently demonstrated across multiple benchmarks, though some datasets show more modest gains than others
