# Learning from Aggregated Data: Curated Bags versus Random Bags

## Quick Facts
- arXiv ID: 2305.09557
- Source URL: https://arxiv.org/abs/2305.09557
- Reference count: 40
- Primary result: Curated bags enable lossless gradient-based learning for semilinear losses while random bags provide PAC learnability with controlled error bounds

## Executive Summary
This paper investigates machine learning with aggregated data labels as a privacy-preserving method. It compares two aggregation procedures: curated bags, where data is grouped based on common features, and random bags, where data is grouped randomly. For curated bags and semilinear loss functions (e.g., mean squared error, log loss), the paper shows that gradient-based learning can be performed without any performance loss, since the sum of gradients can be computed from aggregate labels. For random bags, a generalization risk bound is provided using Rademacher complexity, showing a trade-off between bag size and achievable error rate. Empirical results confirm that curated bags effectively preserve information during aggregation and outperform random bags. The study suggests aggregate learning is an effective method for preserving user privacy while maintaining model accuracy.

## Method Summary
The paper proposes two methods for learning from aggregated data. For curated bags, it shows that gradient-based learning remains lossless when using semilinear loss functions by leveraging the structure of generalized additive models (GAMs). For random bags, it provides generalization risk bounds using Rademacher complexity analysis. The framework includes optional differential privacy mechanisms by adding calibrated noise to aggregate labels. The empirical study uses the Criteo Ads dataset with categorical features, comparing performance across different bag sizes and aggregation strategies.

## Key Results
- Curated bags enable lossless gradient-based learning for semilinear losses (MSE, log loss, Poisson loss)
- Random bags provide PAC learnability with error bounds that trade off bag size against accuracy
- Empirical results show curated bags preserve information effectively and outperform random bags
- Differential privacy noise can be added to aggregate labels without destroying learning performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Curated bags preserve gradient information for semilinear losses.
- Mechanism: When data is grouped by feature values, the sum of gradients over each bag can be computed from aggregate labels using the semilinear loss structure.
- Core assumption: The model is a generalized additive model (GAM) where sub-models depend only on features that are constant within each curated bag.
- Evidence anchors:
  - [abstract] "For the curated bag setting and for a broad range of loss functions, we show that we can perform gradient-based learning without any degradation in performance that may result from aggregating data."
  - [section 3.3] "Proposition 1 (Lossless Aggregate Learning, Simplest Version)...the sum of the derivatives of the loss function with respect to the j0-th feature on all individual data examples in a curated bag can be obtained from the aggregate label"
- Break condition: If sub-models depend on features that vary within a curated bag, the gradient aggregation fails.

### Mechanism 2
- Claim: Random bags enable PAC learnability with controlled error bounds.
- Mechanism: The Rademacher complexity analysis provides a generalization risk bound that trades off bag size against achievable error rate.
- Core assumption: Data examples are sampled without replacement within each bag, and bags can have overlapping examples.
- Evidence anchors:
  - [abstract] "For the random bag setting, we provide a generalization risk bound based on the Rademacher complexity of the hypothesis class"
  - [section 4] "Theorem 2...upper-bound its excess risk R(ĥ) - inf h∈H R(h) by a combination of the usual and flattened Rademacher complexities"
- Break condition: If bag size approaches the full dataset size (m→N), the bound becomes unbounded and learning becomes impossible.

### Mechanism 3
- Claim: Differentially private noise can be added to aggregate labels without destroying learning performance.
- Mechanism: The GAM architecture with neural network sub-models can tolerate noise levels up to a certain privacy budget (ϵ) while maintaining accuracy.
- Core assumption: The privacy noise is calibrated to the sensitivity of the aggregate label computation.
- Evidence anchors:
  - [abstract] "in the context of classification...the proportion of each class among the instances in a bag can serve as an aggregate label, which can be then perturbed appropriately to ensure differential privacy"
  - [section 5] "We introduce noise to ensure that the aggregate label is ϵ-differentially private at various privacy budgets ϵ"
- Break condition: Excessive noise levels destroy the gradient signal needed for learning.

## Architecture Onboarding

- Component map:
  Feature preprocessing -> Bag generation -> Model architecture -> Privacy layer -> Training loop

- Critical path:
  1. Preprocess features and generate bags
  2. Compute aggregate labels from individual labels
  3. Initialize GAM with appropriate sub-model architecture
  4. Compute gradients using aggregate labels
  5. Update parameters via gradient descent
  6. Evaluate on held-out data

- Design tradeoffs:
  - Curated vs random bags: Information preservation vs simplicity
  - Neural network vs linear sub-models: Expressivity vs interpretability
  - Bag size: Privacy preservation vs learning accuracy
  - Privacy budget (ϵ): Privacy protection vs model utility

- Failure signatures:
  - Training loss plateaus early: Likely gradient information loss due to bag construction or model architecture mismatch
  - High variance in validation loss: Possible insufficient data or overly aggressive privacy noise
  - Degraded performance vs baseline: Check bag construction and gradient computation implementation

- First 3 experiments:
  1. Train GAM with neural network sub-models on curated bags without privacy noise, compare to individual label baseline
  2. Vary bag size in random bags setting, measure impact on test error and generalization bound
  3. Add differential privacy noise at different ϵ levels, measure privacy-utility tradeoff curve

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the lossless aggregate learning framework be extended to more complex loss functions beyond semilinear losses, such as those used in deep learning models with non-smooth components?
- Basis in paper: The paper explicitly limits the analysis to semilinear loss functions and states this as a key assumption in the theoretical results.
- Why unresolved: The proof relies on the specific mathematical structure of semilinear losses, which may not generalize to more complex loss functions.
- What evidence would resolve it: A formal proof showing that gradient-based learning remains lossless for a broader class of loss functions, or a counterexample demonstrating that performance degradation occurs.

### Open Question 2
- Question: How does the choice of curated bag feature sets affect the practical performance and privacy guarantees in real-world datasets with heterogeneous feature distributions?
- Basis in paper: The paper mentions that curated bags are formed by partitioning based on feature values, but does not systematically analyze how different feature selection strategies impact performance or privacy.
- Why unresolved: The theoretical results assume idealized conditions, but real datasets may have imbalanced or correlated features that affect bag formation.
- What evidence would resolve it: Empirical studies comparing different feature selection strategies for curated bags across diverse datasets, measuring both accuracy and privacy metrics.

### Open Question 3
- Question: What is the optimal trade-off between bag size and sample complexity in the random bags setting for specific hypothesis classes, and how does this depend on the underlying data distribution?
- Basis in paper: The generalization bound in Theorem 2 shows a trade-off between bag size and error rate, but does not provide specific guidance on optimal parameter choices for particular hypothesis classes or distributions.
- Why unresolved: The bound is general and applies to all hypothesis classes, but practical applications require understanding how the trade-off manifests in specific settings.
- What evidence would resolve it: Numerical studies exploring the relationship between bag size, sample complexity, and error rates for specific hypothesis classes across different data distributions, potentially leading to practical guidelines.

## Limitations

- Privacy guarantees are demonstrated but specific epsilon values and their relationship to performance are not fully quantified
- Model architecture details (layer sizes, activation functions, regularization) are not specified for reproducibility
- Theoretical assumptions of i.i.d. sampling may not hold in real-world data with correlated features

## Confidence

- **High Confidence**: The core theoretical result for curated bags with semilinear losses (Proposition 1) is well-founded and supported by clear mathematical derivation
- **Medium Confidence**: The Rademacher complexity bounds for random bags are theoretically sound but depend on unknown constants and bag size assumptions
- **Medium Confidence**: The empirical validation on Criteo Ads dataset provides evidence but uses a single dataset, limiting generalizability
