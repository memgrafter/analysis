# An evaluation of Google Translate for Sanskrit to English translation via sentiment and semantic analysis

## Quick Facts
- arXiv ID: 2303.07201
- Source URL: https://arxiv.org/abs/2303.07201
- Reference count: 40
- Primary result: Google Translate shows low semantic and sentiment similarity to expert translations of the Bhagavad Gita

## Executive Summary
This study develops and applies a comprehensive framework to evaluate Google Translate's Sanskrit-to-English translation quality using the Bhagavad Gita as a test case. The framework combines sentiment analysis using a BERT model trained on the SenWave dataset with semantic analysis using MPNet embeddings to measure cosine similarity. The research compares Google Translate output against three expert translations (Gandhi, Easwaran, and Purohit Swami) across 700 verses. Qualitative evaluation by a Sanskrit expert reveals that Google Translate struggles with poetic elements, contextual significance, and metaphorical language, making it unsuitable for translating culturally rich Sanskrit texts.

## Method Summary
The evaluation framework extracts Sanskrit Bhagavad Gita verses from the Bhaktivedanta Vedabase and generates English translations using Google Translate API. A BERT model fine-tuned on the SenWave dataset performs sentiment analysis across all translations, while MPNet embeddings calculate cosine similarity for semantic comparison. KeyBERT extracts keywords from each verse to support qualitative analysis. A Sanskrit expert conducts detailed qualitative evaluation focusing on mistranslations of poetic language, metaphors, and contextual elements. The approach combines quantitative metrics with expert qualitative assessment to provide a comprehensive evaluation of translation quality.

## Key Results
- Google Translate showed significantly lower semantic similarity scores compared to expert translations when measured using MPNet embeddings
- Sentiment analysis revealed substantial differences between Google Translate output and expert translations in capturing emotional tone
- Qualitative evaluation identified specific failures in translating poetic Sanskrit elements, metaphors, and contextual significance
- The framework successfully demonstrated measurable differences between machine and expert translations across multiple analytical dimensions

## Why This Works (Mechanism)
The framework works by leveraging complementary analytical approaches: sentiment analysis captures emotional content preservation while semantic similarity measures meaning preservation at the embedding level. BERT's contextual understanding from SenWave training enables nuanced sentiment detection, while MPNet's masked language modeling captures semantic relationships. The combination of quantitative metrics with expert qualitative analysis provides validation through multiple lenses, addressing the limitations of any single evaluation method. KeyBERT keyword extraction supports qualitative analysis by identifying critical translation differences.

## Architecture Onboarding

**Component Map**
Google Translate API -> BERT sentiment analysis -> MPNet semantic similarity -> KeyBERT keyword extraction -> Sanskrit expert qualitative evaluation

**Critical Path**
Verse extraction → Google Translate generation → Sentiment analysis → Semantic analysis → Qualitative evaluation

**Design Tradeoffs**
- Using Google Translate API provides standardized baseline but limits control over translation process
- BERT fine-tuning on SenWave balances sentiment analysis capability with domain relevance
- Single Sanskrit expert provides deep insight but lacks systematic inter-rater validation
- Focusing on Bhagavad Gita enables comprehensive analysis but limits generalizability

**Failure Signatures**
- Low semantic similarity scores may reflect style differences rather than quality issues
- Inconsistent sentiment analysis indicates BERT model needs better Sanskrit-specific fine-tuning
- Qualitative evaluation disagreements suggest unclear assessment criteria
- High variance in translation quality across different verse types indicates domain sensitivity

**3 First Experiments**

2. Conduct inter-rater reliability analysis with multiple Sanskrit experts on same verses
3. Compare BERT sentiment analysis results with human-annotated sentiment labels on sample verses

## Open Questions the Paper Calls Out

**Open Question 1**
- Question: What specific features or modifications could improve Google Translate's ability to handle poetic and metaphorical language in Sanskrit texts?
- Basis in paper: [explicit] The paper identifies that Google Translate struggles with poetic nature, contextual significance, metaphor, and imagery in Sanskrit texts like the Bhagavad Gita.
- Why unresolved: The paper highlights the problem but does not propose specific solutions or features that could address these translation challenges.
- What evidence would resolve it: Implementation and testing of proposed modifications (e.g., enhanced contextual understanding, metaphor detection algorithms, poetic structure preservation) followed by quantitative comparison of translation quality metrics.

**Open Question 2**
- Question: How does translation bias vary across different schools of Hindu philosophy when using Google Translate?
- Basis in paper: [inferred] The paper mentions that different philosophical schools (Advaita Vedanta vs. Dvaita Vedanta) interpret the Bhagavad Gita differently, and questions whether Google Translate's training data might introduce philosophical biases.
- Why unresolved: The study identifies the potential for philosophical bias but does not investigate how translation quality or interpretation varies based on philosophical orientation.
- What evidence would resolve it: Comparative analysis of Google Translate outputs against translations from different philosophical schools, measuring semantic similarity and contextual preservation across philosophical perspectives.

**Open Question 3**
- Question: Would incorporating rhythmic and phonetic features improve Google Translate's accuracy for Sanskrit verse translation?
- Basis in paper: [explicit] The paper notes that Sanskrit texts like the Bhagavad Gita were written to be sung and remembered through oral traditions, with rhythm and rhyme being key attributes that Google Translate fails to preserve.
- Why unresolved: While the paper identifies the loss of rhythm and rhyme as a limitation, it does not explore whether incorporating these features into the translation model would improve overall accuracy or contextual preservation.
- What evidence would resolve it: Training a modified Google Translate model that incorporates rhythmic and phonetic features, then comparing translation quality metrics (semantic similarity, contextual preservation) against the standard model using the same test corpus.

## Limitations
- Evaluation limited to single religious text (Bhagavad Gita), limiting generalizability to other Sanskrit domains
- Qualitative analysis relies on expert judgment without systematic documentation of evaluation criteria or inter-rater reliability measures
- Sentiment analysis using BERT on SenWave dataset may not capture unique emotional and philosophical nuances of Sanskrit poetry
- Semantic similarity measures using MPNet embeddings may be influenced by translation style differences rather than quality differences
- Study does not account for inherent ambiguity in Sanskrit where single words can have multiple valid meanings depending on context

## Confidence
- Framework validity for Sanskrit evaluation: Medium - The methodology is sound but limited to one domain
- Google Translate quality assessment: Medium - Results are specific to Bhagavad Gita and may not generalize
- Qualitative evaluation findings: Medium - Based on expert judgment without systematic validation
