# Towards Table-to-Text Generation with Pretrained Language Model: A Table Structure Understanding and Text Deliberating Approach

## Quick Facts
- arXiv ID: 2301.02071
- Source URL: https://arxiv.org/abs/2301.02071
- Reference count: 15
- Key outcome: TASD outperforms baselines with improvements of 3.12 BLEU-1, 2.01 BLEU-2, 0.24 BLEU-3, 0.56 METEOR, and 2.92 ROUGE-L on numericNLG dataset, and 2.85 BLEU-1, 1.52 BLEU-2, 0.38 BLEU-3, 0.02 BLEU-4, 0.55 METEOR, and 0.50 ROUGE-L on Totto dataset.

## Executive Summary
This paper introduces TASD, a novel table-to-text generation approach that leverages a pretrained language model with enhanced table structure understanding and text deliberation. The method serializes tables using customized templates, employs a three-layered multi-head attention network to capture table structure information, and uses a multi-pass decoder framework to refine generated text. Experiments on two public datasets demonstrate significant improvements over baseline methods in automatic and human evaluation metrics.

## Method Summary
The TASD approach consists of three main components: template-based table serialization, table-structure-aware text generation using a three-layered multi-head attention network, and text deliberation via a multi-pass decoder framework. The method first linearizes table content into text format using customized templates that don't require labeled target cells. Then, a hierarchical attention mechanism progressively encodes table information at cell, table, and cross-attention levels to create structure-aware representations. Finally, the multi-pass decoder generates an initial text description and then refines it by considering the table representation again, resulting in more polished and accurate table descriptions.

## Key Results
- TASD achieves improvements of 3.12 BLEU-1, 2.01 BLEU-2, 0.24 BLEU-3, 0.56 METEOR, and 2.92 ROUGE-L on the numericNLG dataset compared to baselines
- On the Totto dataset, TASD improves performance by 2.85 BLEU-1, 1.52 BLEU-2, 0.38 BLEU-3, 0.02 BLEU-4, 0.55 METEOR, and 0.50 ROUGE-L
- Human evaluation confirms TASD's effectiveness in generating more faithful and fluent table descriptions compared to baseline methods

## Limitations

- The template-based serialization may not capture all relevant information from complex tables, potentially limiting the model's ability to generate comprehensive descriptions
- The effectiveness of the hierarchical attention mechanism relies heavily on the assumption that table structure is the primary factor influencing generation quality, which may not hold for all table types or domains
- The multi-pass decoder framework assumes that the initial generation can be meaningfully improved through deliberation, which may not always be the case for straightforward or well-structured tables

- Human evaluation results: Medium - Encouraging results but based on relatively small sample sizes (100 examples per test set)
