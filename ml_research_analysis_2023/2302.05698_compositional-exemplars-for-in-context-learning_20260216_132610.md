# Compositional Exemplars for In-context Learning

## Quick Facts
- arXiv ID: 2302.05698
- Source URL: https://arxiv.org/abs/2302.05698
- Reference count: 37
- Key outcome: CEIL significantly improves in-context learning performance across 12 NLP datasets using diverse and relevant example selection via DPPs

## Executive Summary
This paper introduces CEIL (Compositional Exemplars for In-context Learning), a method that addresses the challenge of selecting effective in-context examples for few-shot learning. CEIL uses conditional Determinantal Point Processes (DPPs) to jointly model the diversity and relevance of example subsets, optimizing them through contrastive learning. The approach is evaluated across 12 datasets spanning 7 NLP tasks, demonstrating consistent improvements over baseline selection methods while using fewer examples than competitors.

## Method Summary
CEIL employs conditional DPPs to model the joint probability distribution over in-context example subsets, balancing diversity and relevance through a trade-off parameter λ. The method is trained using contrastive learning with both InfoNCE loss and pairwise margin loss to align example selection with language model preferences. During inference, a Maximum a Posteriori (MAP) algorithm with greedy selection retrieves the optimal example subset. The retriever is trained on constructed datasets where each instance has 50 candidate subsets of 16 examples, using a two-stage retrieval process to create challenging training scenarios.

## Key Results
- CEIL outperforms previous methods on 12 datasets across 7 NLP tasks
- Achieves higher accuracy with fewer in-context examples than baseline methods
- Demonstrates transferability of the retriever across different language models (GPT-Neo, GPT2-XL, Codex)
- Shows consistent performance improvements across classification and generation tasks

## Why This Works (Mechanism)
The effectiveness of CEIL stems from its ability to jointly optimize for both diversity and relevance in example selection. By using conditional DPPs, the method captures the complementary nature of examples while ensuring they remain task-relevant. The contrastive learning framework with dual loss functions (InfoNCE and margin loss) enables the retriever to learn preferences that align with specific language models, resulting in more effective in-context learning.

## Foundational Learning
- **Determinantal Point Processes (DPPs)**: Probabilistic models for diverse subset selection
  - Why needed: To capture the joint probability of selecting diverse yet relevant examples
  - Quick check: Verify the covariance matrix computation correctly encodes diversity

- **Contrastive Learning**: Training paradigm using InfoNCE and margin losses
  - Why needed: To align retriever preferences with language model behavior
  - Quick check: Monitor loss convergence and ensure positive/negative pairs are properly constructed

- **Conditional DPPs**: Extension of DPPs conditioned on query inputs
  - Why needed: To adapt example selection based on the specific query being answered
  - Quick check: Validate that the conditioning mechanism properly incorporates query information

## Architecture Onboarding

**Component Map**: Query -> BERT Encoder -> Conditional DPP Retriever -> Example Subset -> LLM

**Critical Path**: Query encoding → DPP probability computation → MAP inference → LLM prompt construction

**Design Tradeoffs**: The method balances diversity (capturing different aspects of the task) against relevance (ensuring examples are applicable to the query), controlled by hyperparameter λ. This tradeoff is critical for effective few-shot learning.

**Failure Signatures**: Poor performance may manifest as either redundant examples (insufficient diversity) or irrelevant examples (insufficient relevance). Training instability can occur if the contrastive loss is not properly balanced or if the DPP covariance matrix is ill-conditioned.

**Three First Experiments**:
1. Verify DPP probability computation on synthetic data with known diversity properties
2. Test retriever performance on a single dataset with ground truth labels to validate the contrastive learning setup
3. Compare CEIL's example selection against random selection on a simple classification task to establish baseline improvement

## Open Questions the Paper Calls Out
- How does CEIL performance compare when the number of in-context examples exceeds the maximum context size of language models?
- How does retriever transferability vary across different tasks and language models?
- How does CEIL perform when in-context examples are noisy or irrelevant?

## Limitations
- Missing implementation details for exact preprocessing pipelines of all 12 datasets
- Lack of ablation studies on key design choices such as the diverse-vs-relevant tradeoff hyperparameter
- Limited systematic analysis of retriever transferability across different model scales

## Confidence
- High confidence: The core methodology using conditional DPPs for example selection is theoretically sound
- Medium confidence: Reported performance improvements are substantial but depend on unreported implementation details
- Low confidence: Claims about transferability across LLMs are based on limited experimentation
