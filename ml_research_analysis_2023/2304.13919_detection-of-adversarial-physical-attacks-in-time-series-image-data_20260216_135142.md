# Detection of Adversarial Physical Attacks in Time-Series Image Data

## Quick Facts
- arXiv ID: 2304.13919
- Source URL: https://arxiv.org/abs/2304.13919
- Reference count: 40
- Key outcome: VG* achieves 99.8% detection accuracy for stop signs and 97.8% for yield signs using majority-vote mechanisms on time-series image data

## Executive Summary
This paper introduces VisionGuard* (VG*), a time-series detector that leverages majority-vote mechanisms to detect adversarial physical attacks in image sequences. VG* builds upon VisionGuard (VG), a single-image detector, by applying VG across a sliding window of historical frames and using majority-vote to classify the current frame. The method is motivated by autonomous driving applications where time-series image data is used for decision-making. Theoretical analysis provides conditions under which VG* outperforms single-image detectors as the detection window length increases. Experimental results demonstrate VG*'s effectiveness on videos of clean and physically attacked traffic signs, achieving high detection accuracy while maintaining computational efficiency suitable for safety-critical autonomous systems.

## Method Summary
VG* is a time-series detector that applies a single-image detector (VG) to each frame within a sliding window and uses majority-vote to classify the current frame as adversarial or clean. The method assumes perfect object tracking to associate frames to the same object and applies the detector to the last T frames to reason about the current frame. The detection threshold is selected via ROC curves on validation data. The approach can be extended by substituting different single-image detectors for VG.

## Key Results
- VG* achieves 99.8% detection accuracy for stop signs and 97.8% for yield signs in adversarial settings
- Outperforms baseline detectors (MD* and ED*) originally designed for digital attacks and out-of-distribution data
- Computational efficiency allows real-time execution with minimal disk space requirements

## Architecture Onboarding

- Component map: Input frames -> Object tracking -> Sliding window (T frames) -> Single-image detector (VG) -> Majority-vote -> Output classification
- Critical path:
  1. Receive current frame (xt) and past images (X0:t−1)
  2. Apply single-image detector (VG) to each image within the sliding detection window
  3. Compute majority-vote over the detector outputs
  4. Classify current frame based on majority-vote result
- Design tradeoffs:
  - Window length (T): Longer windows may improve accuracy but increase computational cost and latency
  - Single-image detector choice: Different detectors may offer varying performance against specific attack types
  - Threshold selection: Balancing true positive and false positive rates based on application requirements
- Failure signatures:
  - Decreased accuracy with longer window lengths, indicating potential independence assumption violations
  - Poor performance against specific attack types, suggesting the need for detector substitution or enhancement
  - High computational latency, indicating the need for optimization or reduced window length
- First 3 experiments:
  1. Evaluate VG* performance with varying window lengths (T) on a dataset of clean and adversarial traffic sign videos
  2. Compare VG* performance against baseline time-series detectors (MD* and ED*) on the same dataset
  3. Test VG* robustness to different types of physical attacks and object tracking errors

## Limitations

- Theoretical analysis assumes independence of detector outputs across frames, which may not hold in practice due to temporal correlation in video data
- Requires reliable object tracking to associate frames to the same object, but implementation details of this tracking are not provided
- Performance may degrade when majority-vote assumptions fail (e.g., when most frames are incorrectly classified)
