# Universal Information Extraction with Meta-Pretrained Self-Retrieval

## Quick Facts
- arXiv ID: 2306.10444
- Source URL: https://arxiv.org/abs/2306.10444
- Reference count: 40
- Primary result: Universal IE model achieving SOTA performance across 12 datasets with 0.7% improvement in fully-supervised settings and 2.0% in few-shot scenarios

## Executive Summary
This paper introduces MetaRetriever, a universal information extraction model that leverages task-specific knowledge retrieval from pretrained language models to improve performance across multiple IE tasks. The model employs a retrieve-then-extract approach, first retrieving relevant knowledge from the PLM before generating extraction results. Through meta-pretraining on a large-scale corpus constructed with CROCODILE, MetaRetriever achieves state-of-the-art performance on 12 datasets spanning named entity recognition, relation triple extraction, event extraction, and structured sentiment extraction.

## Method Summary
MetaRetriever uses a retrieve-then-extract approach where it first retrieves task-specific knowledge from pretrained language models and then generates extraction results based on this retrieved knowledge. The model is meta-pretrained using a meta-learning algorithm to enable fast adaptation to different IE tasks. The training corpus is constructed using CROCODILE, an automatic relation extraction dataset construction tool. The model demonstrates strong performance across multiple IE tasks with minimal task-specific tuning.

## Key Results
- Achieves state-of-the-art performance across 12 datasets spanning 4 IE tasks
- Outperforms previous best model UIE by 0.7% in fully-supervised settings
- Shows over 2.0% improvement in few-shot and low-resource scenarios

## Why This Works (Mechanism)
The model's effectiveness stems from its ability to retrieve task-specific knowledge from pretrained language models before performing extraction. This retrieve-then-extract approach allows the model to leverage existing knowledge encoded in PLMs while maintaining task-specific focus. The meta-pretraining algorithm enables rapid adaptation to new tasks by learning how to efficiently retrieve and utilize relevant information.
