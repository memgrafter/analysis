# Priors for symbolic regression

## Quick Facts
- arXiv ID: 2304.06333
- Source URL: https://arxiv.org/abs/2304.06333
- Reference count: 40
- The authors develop a framework for incorporating detailed prior information on both functions and their parameters into symbolic regression.

## Executive Summary
This paper introduces a framework for incorporating detailed prior information into symbolic regression, focusing on both function structure and parameter values. The authors develop a method using an n-gram language model as a structural prior, which is sensitive to the arrangement of operators relative to one another in addition to the frequency of occurrence of each operator. They also develop a formalism based on the Fractional Bayes Factor to treat numerical parameter priors in such a way that models may be fairly compared though the Bayesian evidence. The proposed methods are demonstrated on benchmarks and a real-world dataset from the field of cosmology.

## Method Summary
The authors develop a framework for symbolic regression that incorporates detailed prior information on both functions and their parameters. They use an n-gram language model trained on a corpus of scientific equations to capture dependencies between operators, and apply the Fractional Bayes Factor to handle improper parameter priors. The method combines these with Minimum Description Length (MDL) or Bayesian evidence for model selection. They test their approach on synthetic benchmarks (Nguyen-8, Korns-4, Korns-7) and real-world cosmological data (Pantheon+ supernovae), comparing their priors to standard methods using exhaustive search with esr algorithm.

## Key Results
- The n-gram language model prior improves symbolic regression by capturing dependencies between operators that reflect physical plausibility.
- The Fractional Bayes Factor (FBF) resolves the problem of improper priors in symbolic regression by conditioning on a fraction of the data.
- MDL with the language model prior balances model complexity and accuracy better than MDL alone by encoding function structure according to domain knowledge.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The n-gram language model prior improves symbolic regression by capturing dependencies between operators that reflect physical plausibility.
- Mechanism: By training on a corpus of scientific equations, the prior assigns higher probabilities to operator arrangements that commonly occur in physical laws. This reduces the search space toward more interpretable, domain-relevant expressions.
- Core assumption: The distribution of operators in real scientific equations is a good proxy for what makes an equation physically meaningful.
- Evidence anchors:
  - [abstract]: "Our prior on the structure of a function is based on a 𝑛-gram language model, which is sensitive to the arrangement of operators relative to one another..."
  - [section 2.4]: Describes using Katz back-off models to evaluate conditional probabilities of operators given their ancestors in the tree.
  - [corpus]: Found 25 related papers; average FMR 0.516, but no citations yet—weak external validation of corpus relevance.
- Break Condition: If the training corpus does not reflect the target domain, the prior may favor irrelevant or physically implausible structures.

### Mechanism 2
- Claim: The Fractional Bayes Factor (FBF) resolves the problem of improper priors in symbolic regression by conditioning on a fraction of the data.
- Mechanism: FBF uses a fraction b of the data to form a proper posterior that becomes the prior for the remaining data, ensuring that the evidence is well-defined even when the initial prior is improper.
- Core assumption: Large datasets allow the likelihood to dominate, making the choice of b less sensitive to specific data splits.
- Evidence anchors:
  - [section 2.3]: "O’Hagan suggests using 𝑏 = 𝑁 −1/2... One must choose a size of the training set..."
  - [section 2.3]: Derives approximation log Z (𝐷 |𝑓𝑖 ) ≃ (1 − 𝑏) log 𝑃 (𝐷 |𝑓𝑖, ˆ𝜽𝑖 ) + 𝑝/2 log 𝑏 for uniform priors.
  - [corpus]: No direct corpus evidence; this is theoretical.
- Break Condition: If N is small, the approximation breaks down and the evidence becomes unstable.

### Mechanism 3
- Claim: MDL with the language model prior balances model complexity and accuracy better than MDL alone by encoding function structure according to domain knowledge.
- Mechanism: Replaces the complexity penalty k log n with a term that reflects the probability of the function under the learned language model, favoring simpler, more interpretable equations.
- Core assumption: Functions that are common in scientific equations are more likely to be correct or meaningful for new problems.
- Evidence anchors:
  - [abstract]: "We also develop a formalism based on the Fractional Bayes Factor to treat numerical parameter priors..."
  - [section 2.2]: Shows how the functional prior in MDL is −log 𝑃(𝑓𝑖) = k log n + ∑ log 𝑐𝛼 + p/2 log(2π𝜈𝑝).
  - [corpus]: Weak external validation—no citations, average neighbor FMR 0.516.
- Break Condition: If the training corpus is not representative, the prior may mislead the search.

## Architecture Onboarding

- Component map: Data ingestion -> symbolic regression generation (ESR) -> model selection (Bayesian/MDL) -> prior application (language model + FBF)
- Critical path:
  1. Load or generate training equations
  2. Train n-gram language model
  3. Generate candidate functions (ESR)
  4. For each function: optimize parameters, compute likelihood, apply prior
  5. Rank functions using chosen metric (Bayesian evidence or MDL)
- Design tradeoffs:
  - Exhaustive vs heuristic search: exhaustive guarantees completeness but is expensive
  - Length of n-grams: longer n-grams capture more structure but need more data
  - Choice of b in FBF: larger b gives more robust training but less data for evidence
- Failure signatures:
  - If all functions rank equally, likely the prior is too flat or the corpus unrepresentative
  - If MDL always selects trivial functions, the complexity penalty may be too harsh
  - If Bayesian evidence is infinite, improper priors not handled correctly
- First 3 experiments:
  1. Train n-gram on Feynman Lectures corpus, generate functions for Nguyen-8, compare MDL vs MDL+LM ranking
  2. Apply FBF with b=1/√N to the Pantheon+ supernova data, check if x^x functions are suppressed
  3. Swap in a different corpus (e.g., general equations) and observe change in function rankings on benchmarks

## Limitations

- The use of a scientific equation corpus for the n-gram language model lacks robust external validation—no citations and an average neighbor FMR of 0.516 suggest limited related work and potential domain mismatch.
- The Fractional Bayes Factor relies on the assumption that N is sufficiently large for the likelihood to dominate, but no sensitivity analysis is provided for smaller datasets.
- The exhaustive search approach, while theoretically sound, may not scale well for higher complexity functions, and the exact enumeration strategy for ESR is not detailed.

## Confidence

- High: The theoretical framework for Bayesian evidence and MDL is well-established and correctly applied.
- Medium: The n-gram language model prior is innovative but its effectiveness depends heavily on the quality and relevance of the training corpus.
- Medium: The Fractional Bayes Factor method is a valid solution for improper priors, but its approximation may break down for small N.
