# A Note on Dimensionality Reduction in Deep Neural Networks using Empirical Interpolation Method

## Quick Facts
- arXiv ID: 2305.09842
- Source URL: https://arxiv.org/abs/2305.09842
- Reference count: 23
- Reduces DNN training parameters by 10x while maintaining accuracy

## Executive Summary
This paper introduces DNN-EIM, a method that applies the empirical interpolation method (EIM) to reduce dimensionality of training data for deep neural networks. The approach identifies a reduced set of interpolation points from the data, allowing for parallel training of separate neural networks - one per class for classification tasks or one per EIM point for parameterized PDEs. This parallel structure significantly reduces the number of parameters to learn while maintaining comparable accuracy to standard full-dimensional approaches. Numerical experiments on MNIST and PDEs demonstrate that DNN-EIM achieves high accuracy with fewer parameters and faster training times compared to standard DNN approaches and projection-based methods.

## Method Summary
DNN-EIM combines empirical interpolation method with deep learning by first applying EIM to identify key interpolation points from the training data, then training separate neural networks in parallel - one for each class (classification) or one for each EIM point (PDEs). For classification, each network receives data at EIM points as input and outputs class membership; for PDEs, each network takes parameter values as input and outputs solution values at its corresponding EIM point. The method leverages the low-dimensional structure of data to reduce computational complexity while maintaining accuracy through careful selection of interpolation points.

## Key Results
- Achieves 10x reduction in training parameters compared to standard DNN approaches
- Maintains accuracy comparable to full-dimensional training on MNIST and PDE examples
- Demonstrates faster training times through parallel network training
- Outperforms projection-based methods like POD in terms of accuracy and efficiency

## Why This Works (Mechanism)
DNN-EIM works by exploiting the low-dimensional structure of the data through EIM, which identifies a minimal set of interpolation points that can reconstruct the full solution space. By training separate networks for each class or EIM point, the method reduces the effective dimensionality of the learning problem. The parallel training structure allows each network to specialize on a smaller, more focused task, reducing the total number of parameters needed. This approach is particularly effective when the underlying data or solutions lie close to a low-dimensional manifold, as is often the case in classification tasks and parameterized PDEs.

## Foundational Learning
- Empirical Interpolation Method (EIM): A technique for approximating functions in high-dimensional spaces by selecting a minimal set of interpolation points. Why needed: Provides the dimensionality reduction foundation for the approach. Quick check: Verify EIM correctly identifies interpolation points that minimize approximation error.
- Proper Orthogonal Decomposition (POD): A method for extracting dominant modes from data to create a reduced basis. Why needed: Generates the projection basis that EIM operates on. Quick check: Confirm POD basis captures sufficient variance in the training data.
- Parallel Neural Network Training: Training multiple neural networks simultaneously, each on a specialized subset of the problem. Why needed: Enables the dimensionality reduction by decomposing the learning task. Quick check: Ensure all networks complete training successfully and independently.

## Architecture Onboarding
- Component Map: Training Data -> POD Basis -> EIM Points -> Parallel NNs -> Predictions
- Critical Path: EIM point selection → Parallel network training → Prediction combination
- Design Tradeoffs: More EIM points → higher accuracy but more networks; fewer points → faster training but lower accuracy
- Failure Signatures: Poor accuracy indicates insufficient EIM points; slow training suggests parallelization issues
- First Experiments: 1) Verify EIM point selection is consistent across runs, 2) Compare accuracy with varying numbers of EIM points, 3) Benchmark training time with and without parallelization

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but several areas remain unexplored based on the content:
1. Theoretical convergence rates of DNN-EIM for classification as a function of EIM points and network architecture
2. Scalability to high-dimensional PDEs beyond 2D
3. Extension to non-stationary PDEs with time-varying parameters
4. Sensitivity to noise in training data and effective denoising strategies

## Limitations
- Incomplete specification of activation function and exact EIM implementation details
- Limited validation to 1D and 2D PDEs, lacking scalability analysis for higher dimensions
- Assumes clean training data without addressing noise sensitivity
- Missing theoretical analysis of convergence rates and error bounds
