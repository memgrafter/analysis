# Input-length-shortening and text generation via attention values

## Quick Facts
- arXiv ID: 2303.07585
- Source URL: https://arxiv.org/abs/2303.07585
- Reference count: 40
- Primary result: Attention-based input reduction achieves 86.5% accuracy on SST-2 while using only 6% of original tokens

## Executive Summary
This paper investigates two applications of BERT's attention mechanism: reducing input sequence length for text classification and controlling text generation quality. The authors demonstrate that tokens selected by BERT's early layers are more effective for classification than later layers, and that approximately 6% of original tokens can achieve 86.5% accuracy on the SST-2 sentiment analysis task. They also show that using BERT's attention scores to select top tokens as input conditions for GPT-2 can generate high-quality text that is comparable to original examples according to both BERTScore metrics and human evaluation.

## Method Summary
The paper explores using BERT's attention mechanism in two distinct ways. For input reduction, they investigate which BERT layers produce the most effective tokens for classification by analyzing attention scores across different layers. They compare two filtering approaches: attention-based filtering that selects top-scoring tokens, and similarity-based filtering that retains tokens with highest average cosine similarity to others. For text generation control, they use BERT's attention scores to select top 10% or 20% of tokens from input text as conditions for GPT-2 generation, then compare the quality of generated text against original examples using BERTScore and human evaluation.

## Key Results
- Early BERT layers (layers 0-3) produce more effective tokens for classification than later layers
- Retaining approximately 6% of original tokens achieves 86.5% accuracy on SST-2 sentiment analysis
- Similarity-based filtering outperforms attention-based filtering, achieving similar accuracy with 53% sequence reduction
- BERTScore metrics for generated text: precision 0.77, recall 0.79, F1 0.78
- Human evaluation rated generated text slightly higher in fluency and cohesiveness than original text

## Why This Works (Mechanism)
The attention mechanism in transformer models inherently captures token importance through self-attention scores. Early layers tend to capture more general, task-relevant features that are broadly applicable across different inputs, while later layers develop more specialized representations. By leveraging these attention scores to identify and retain only the most informative tokens, the model can maintain performance while significantly reducing computational requirements. For text generation, using attention-selected tokens as generation conditions provides focused semantic guidance to the decoder, resulting in coherent and contextually appropriate output.

## Architecture Onboarding

### Component Map
BERT Encoder -> Attention Score Extraction -> Token Selection -> Classification Head
BERT Encoder -> Attention Score Extraction -> Token Selection -> GPT-2 Decoder

### Critical Path
The critical path for classification involves BERT's self-attention computation, attention score extraction from early layers, token selection based on scores, and final classification. For text generation, the path includes BERT's attention computation, token selection, and GPT-2 generation conditioned on selected tokens.

### Design Tradeoffs
The approach trades off complete token representation for computational efficiency. Using early layers provides better generalization but may miss task-specific features captured in later layers. The similarity-based filtering approach requires additional computation for cosine similarity calculations but provides more stable token selection across different inputs.

### Failure Signatures
- Performance degradation when input text contains domain-specific terminology not well-represented in early layers
- Generated text may lack diversity when using top-k token selection with small k values
- Similarity-based filtering may fail on texts with high lexical diversity or specialized vocabulary

## Limitations
- BERTScore evaluation relies on pre-trained model potentially introducing bias
- Human evaluation involved only three raters, limiting statistical significance
- Similarity-based filtering requires careful threshold tuning and may not generalize across domains
- Experiments limited to clean text from news and Wikipedia sources
- Computational savings assume static input reduction, not dynamic attention processing

## Confidence
High: Empirical results showing early BERT layers select more effective tokens for classification, and that ~6% token retention achieves 86.5% SST-2 accuracy
Medium: Generalizability of similarity-based filtering across different text domains and tasks
Low: Claims about generated text being "indistinguishable" based on limited human evaluation with three raters

## Next Checks
1. Test similarity-based filtering on noisy, domain-specific text (social media, medical records) to evaluate robustness

3. Implement and benchmark attention-based input reduction during actual inference to measure real-world computational savings
