# Unsupervised Video Anomaly Detection for Stereotypical Behaviours in Autism

## Quick Facts
- arXiv ID: 2302.13748
- Source URL: https://arxiv.org/abs/2302.13748
- Reference count: 0

## Executive Summary
This paper introduces DS-SBD, a novel unsupervised video anomaly detection framework designed to identify stereotypical behaviors in autism spectrum disorder (ASD). The approach leverages dual-stream architecture incorporating pose trajectory and repetition detection to capture both spatial and temporal characteristics of behaviors. By training with proxy tasks including pose reconstruction, prediction, and repetition detection, the method learns to distinguish normal from abnormal behavioral patterns without requiring labeled anomaly data.

## Method Summary
The proposed framework uses a dual-stream network architecture where one stream processes pose trajectory information while the other focuses on detecting repetitive behavioral patterns. The model is trained using three proxy tasks: reconstructing input poses, predicting future poses, and detecting repetitions in behavior sequences. This multi-task learning approach enables the network to learn meaningful representations of normal behaviors that can then be used to identify anomalies through reconstruction error and repetition pattern analysis.

## Key Results
- DS-SBD achieves 71.04% micro-AUROC and 73.39% macro-AUROC on the SSBD dataset
- The repetition detection module significantly improves performance over baseline methods
- Ablation studies confirm the importance of each component in the dual-stream architecture

## Why This Works (Mechanism)
The effectiveness of DS-SBD stems from its ability to capture both the temporal evolution of poses and the characteristic repetition patterns that often define stereotypical behaviors. By combining these complementary information streams, the model can better distinguish between normal variations in behavior and true anomalies that deviate from established patterns.

## Foundational Learning
- Pose trajectory modeling: Essential for capturing the spatial-temporal evolution of movements; quick check involves verifying smooth pose transitions
- Repetition pattern detection: Critical for identifying the cyclical nature of stereotypical behaviors; quick check involves analyzing periodicity in movement sequences
- Dual-stream architecture: Enables parallel processing of complementary behavioral features; quick check involves ensuring proper synchronization between streams

## Architecture Onboarding
Component map: Input video -> Pose estimation -> Dual-stream network (Trajectory stream + Repetition stream) -> Proxy task outputs (Reconstruction, Prediction, Repetition detection) -> Anomaly score
Critical path: Pose extraction → Trajectory stream processing → Repetition detection → Anomaly scoring
Design tradeoffs: Balances complexity of dual-stream processing against performance gains from capturing multiple behavioral aspects
Failure signatures: Poor pose estimation quality propagates through entire pipeline; insufficient training data for repetition patterns limits detection capability
First experiments: 1) Test individual stream performance, 2) Validate proxy task effectiveness, 3) Measure impact of pose estimation quality on final results

## Limitations
- Results based on single SSBD dataset may not generalize across diverse ASD populations
- Unsupervised nature makes true performance evaluation challenging without labeled anomaly data
- Repetition detection module effectiveness may vary with behavioral complexity and context
