# KINLP at SemEval-2023 Task 12: Kinyarwanda Tweet Sentiment Analysis

## Quick Facts
- arXiv ID: 2304.12569
- Source URL: https://arxiv.org/abs/2304.12569
- Reference count: 5
- Primary result: BERT-style model with morphological modeling achieved 72.50% weighted F1 score, ranking 2nd in SemEval-2023 Task 12 competition

## Executive Summary
This paper presents a BERT-style pre-trained language model for Kinyarwanda tweet sentiment analysis that achieved second place in the SemEval-2023 Task 12 competition. The model uses a two-tier transformer architecture that explicitly models Kinyarwanda morphology, including stem, affixes, POS tag, and affix set information. Pre-training employs multi-task masked morphology prediction on a large corpus, followed by fine-tuning on the sentiment analysis task using a web platform that enables quick experimentation without machine learning code.

## Method Summary
The system uses a two-tier transformer architecture where a first-tier transformer encodes morphological information (stem, affixes, POS tag, affix set) for each word, reducing vocabulary size while preserving linguistic structure. The second-tier transformer captures sentence-level context using this morphological representation. The model is pre-trained using BERT-style masked language modeling with multi-task learning that predicts all four morphological components simultaneously. Fine-tuning is performed on the tweet dataset with a learning rate of 2e-5, batch size 16, and 30 epochs. The approach compares BERT-style and GPT-style pre-training, confirming BERT-style achieves better accuracy for sentiment classification.

## Key Results
- Achieved 72.50% weighted F1 score on the SemEval-2023 Task 12 competition, ranking 2nd out of 34 teams
- BERT-style pre-training (71.9±0.8 F1) outperformed GPT-style pre-training (70.1±0.7 F1) for sentiment classification
- Fine-tuning showed large variance, likely due to small dataset size and non-standard language characteristics
- Error analysis revealed significant challenges with data quality and class ambiguity, especially between negative and neutral sentiment

## Why This Works (Mechanism)

### Mechanism 1: Morphology-Explicit Architecture
- Claim: Two-tier transformer explicitly modeling Kinyarwanda morphology improves sentiment classification over BPE-based models
- Mechanism: First tier encodes morphological information (stem, affixes, POS tag, affix set) for each word, reducing vocabulary size while preserving linguistic structure. Second tier captures sentence-level context using this representation.
- Core assumption: Morphological decomposition is more effective than byte-pair encoding for handling Kinyarwanda's complex agglutinative morphology in downstream tasks.
- Evidence anchors: Abstract mentions "Kinyarwanda morphology is modeled in a two tier transformer architecture"; section describes KinyaBERT using same approach.
- Break condition: If morphological analyzer produces incorrect segmentations or language has simpler morphology where BPE would suffice.

### Mechanism 2: Multi-Task Morphology Prediction
- Claim: Multi-task masked morphology prediction during pre-training improves downstream sentiment classification performance.
- Mechanism: Model predicts multiple morphological attributes (stem, affixes, POS tag, affix set) simultaneously during masked language modeling, creating richer intermediate representations that transfer better to classification tasks.
- Core assumption: Learning to predict morphological structure provides beneficial inductive biases for understanding sentiment-bearing linguistic features.
- Evidence anchors: Abstract states "transformer model is pre-trained on large text corpus using multi-task masked morphology prediction"; section describes multi-task learning scheme.
- Break condition: If morphological prediction tasks are too difficult relative to target task, causing negative transfer.

### Mechanism 3: BERT-Style Bidirectional Context
- Claim: BERT-style pre-training achieves better sentiment classification accuracy than GPT-style pre-training for this task.
- Mechanism: BERT's bidirectional context modeling captures better representations for classification by considering both left and right context, while GPT's autoregressive approach may miss important context for sentiment words.
- Core assumption: Sentiment-bearing words and phrases benefit from bidirectional context understanding rather than unidirectional generation modeling.
- Evidence anchors: Section confirms "BERT-style achieves better accuracy"; Table 2 shows BERT variant achieving 71.9±0.8 F1 vs GPT at 70.1±0.7 F1.
- Break condition: If task requires more generation-oriented understanding or bidirectional context introduces noise for specific linguistic patterns.

## Architecture Onboarding

- **Component map**: Input text → Morphological segmentation → First-tier encoding → Second-tier encoding → [Pre-training: masked prediction] or [Fine-tuning: classification head] → Output
- **Critical path**: Input text flows through morphological analyzer API to extract stem, affixes, POS tag, and affix set; first-tier transformer encodes morphology; second-tier transformer processes sentence context; pre-training uses multi-task masked prediction or fine-tuning uses classification head.
- **Design tradeoffs**: Morphology vs BPE (higher accuracy for complex morphology but requires morphological analyzer); BERT vs GPT (better classification performance vs better generation capabilities); Multi-task vs single-task (richer representations vs simpler optimization).
- **Failure signatures**: Poor morphology segmentation causing cascading errors; overfitting on small tweet dataset showing high variance in fine-tuning results; class imbalance issues with negative/neutral boundary confusion.
- **First 3 experiments**: 1) Run morphological analyzer on sample Kinyarwanda text to verify segmentation quality; 2) Fine-tune pre-trained model on small subset of training data to observe variance patterns; 3) Test classification on examples near class boundaries to understand confusion patterns.

## Limitations

- Data quality concerns with significant class boundary ambiguity between negative and neutral sentiment labels
- Small dataset size leading to high variance in fine-tuning results (71.9±0.8 F1 vs 70.1±0.7 F1)
- Dependency on external morphological analyzer API without evaluation of its accuracy or reliability

## Confidence

**High Confidence**:
- Two-tier architecture with morphological modeling is feasible and can be implemented
- BERT-style pre-training outperforms GPT-style pre-training for this classification task
- System achieved second place in competition with reported metrics

**Medium Confidence**:
- Morphological modeling provides significant advantages over BPE tokenization for Kinyarwanda specifically
- Multi-task masked morphology prediction during pre-training meaningfully improves sentiment classification
- Morphological decomposition approach will generalize to other highly agglutinative languages

**Low Confidence**:
- Specific performance gains attributed to architectural choices versus data quality issues
- Claimed advantages of morphological modeling over simpler tokenization methods
- Robustness of approach to variations in morphological analyzer quality
