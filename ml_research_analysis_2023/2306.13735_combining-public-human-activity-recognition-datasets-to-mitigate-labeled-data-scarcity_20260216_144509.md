# Combining Public Human Activity Recognition Datasets to Mitigate Labeled Data Scarcity

## Quick Facts
- arXiv ID: 2306.13735
- Source URL: https://arxiv.org/abs/2306.13735
- Reference count: 40
- Combines multiple public HAR datasets to pre-train models that require less labeled data for fine-tuning

## Executive Summary
This paper addresses the challenge of labeled data scarcity in human activity recognition (HAR) on mobile devices by proposing a multi-dataset pre-training approach. The authors introduce a Leave-One-Dataset-Out (LODO) evaluation framework to assess how pre-trained models generalize to unseen target domains. Through extensive experiments with state-of-the-art neural network architectures, they demonstrate that combining public HAR datasets significantly reduces the amount of labeled data needed to achieve satisfactory performance on target domains. The approach is particularly effective for transformer-based architectures like HART and MobileHART, which benefit more from pre-training compared to smaller networks like DeepConvLSTM.

## Method Summary
The authors propose combining multiple public HAR datasets to create a comprehensive pre-training corpus, followed by fine-tuning on limited labeled data from target domains. The Leave-One-Dataset-Out (LODO) evaluation framework systematically tests model generalization by pre-training on all datasets except one (held out as target), then fine-tuning and evaluating on the held-out dataset. This methodology assesses cross-dataset generalization capabilities under labeled data scarcity conditions. Experiments compare various neural architectures including DeepConvLSTM, HART, and MobileHART, with pre-training performed on combinations of public datasets before fine-tuning on limited target domain data.

## Key Results
- Combining public HAR datasets significantly reduces labeled data requirements for achieving satisfactory performance on unseen target domains
- Transformer-based architectures (HART, MobileHART) benefit more from multi-dataset pre-training than smaller networks like DeepConvLSTM
- Pre-training on multiple datasets improves recognition rates, particularly in scenarios with limited labeled data availability

## Why This Works (Mechanism)
The approach works by leveraging the complementary information present across multiple HAR datasets collected under different conditions, sensor placements, and participant populations. Pre-training on this diverse corpus allows models to learn robust feature representations that generalize across domains. When fine-tuned on limited target domain data, these pre-trained models can quickly adapt to new conditions without requiring extensive labeled data collection. The LODO framework ensures that the evaluation captures realistic scenarios where target domain data is scarce and differs from pre-training data.

## Architecture Onboarding

**Component Map:**
Raw Sensor Data -> Neural Network (DeepConvLSTM/HART/MobileHART) -> Feature Extraction -> Classification Layer -> Activity Prediction

**Critical Path:**
Data preprocessing → Multi-dataset pre-training → Fine-tuning on target domain → Evaluation

**Design Tradeoffs:**
- Larger transformer architectures provide better generalization but require more computational resources
- Smaller networks like DeepConvLSTM are more efficient but benefit less from pre-training
- Combining datasets increases pre-training data diversity but may introduce domain shift challenges

**Failure Signatures:**
- Poor performance on target domains despite successful pre-training indicates domain shift issues
- Limited improvement from pre-training suggests architectural limitations or insufficient dataset diversity
- Overfitting during fine-tuning indicates excessive model capacity relative to available labeled data

## Limitations
- Performance gains are most pronounced for transformer architectures, with smaller networks showing less benefit
- Evaluation focuses on leave-one-dataset-out scenarios which may not capture more extreme real-world domain differences
- Does not extensively address domain shift issues beyond dataset differences such as sensor placement variations

## Confidence
- High confidence in effectiveness of multi-dataset pre-training for reducing labeled data requirements
- Medium confidence in relative performance benefits across different neural architectures
- Low confidence in generalizability to scenarios with more extreme domain shifts

## Next Checks
1. Evaluate the pre-training approach on datasets with significant sensor placement differences to assess robustness to domain shift
2. Test the LODO methodology with datasets collected from different demographic populations to validate cross-population generalization
3. Compare performance against domain adaptation techniques rather than simple fine-tuning to determine if more sophisticated adaptation methods would yield better results in low-data scenarios
