# Towards Open Temporal Graph Neural Networks

## Quick Facts
- arXiv ID: 2303.15015
- Source URL: https://arxiv.org/abs/2303.15015
- Reference count: 40
- Key outcome: OTGNet achieves 73.88% average performance and 19.25% average forgetting on Reddit, outperforming baselines significantly.

## Executive Summary
This paper introduces OTGNet, the first method to handle open set temporal graphs where new classes emerge over time. The method addresses two main challenges: heterophily propagation, where connected nodes from different classes have conflicting representations, and catastrophic forgetting, where old class knowledge is lost when learning new classes. OTGNet disentangles node knowledge into class-relevant and class-agnostic components, using information bottleneck to propagate only class-agnostic knowledge between different class nodes. It also selects diverse and important triad structures from old classes for replay during new class learning.

## Method Summary
OTGNet addresses open set temporal graph learning by disentangling node representations into class-relevant and class-agnostic components. The method uses information bottleneck to extract class-agnostic representations for message passing between different class nodes, preventing heterophily propagation. For catastrophic forgetting, OTGNet selects representative triad structures from old classes using a submodular optimization that balances importance and diversity, then replays these triads during new class learning. The framework operates on temporal graphs with dynamic class emergence, using triad-based knowledge preservation and information bottleneck-based message passing to maintain performance across tasks.

## Key Results
- OTGNet achieves 73.88% average performance and 19.25% average forgetting on Reddit dataset
- Significantly outperforms TGAT+BiC (54.61%, 25.42%) and TGN+BiC (53.16%, 26.83%) baselines
- Effectively mitigates both heterophily propagation and catastrophic forgetting while maintaining computational efficiency

## Why This Works (Mechanism)

### Mechanism 1
- Claim: OTGNet disentangles node knowledge into class-relevant and class-agnostic components to prevent heterophily propagation.
- Mechanism: The model uses information bottleneck to extract class-agnostic representations (z(t)) from node embeddings. When aggregating messages from neighbors of different classes, it uses z(t) instead of the full embedding x(t), avoiding the transfer of class-conflicting information.
- Core assumption: Node knowledge can be decomposed into class-relevant and class-agnostic parts, and class-agnostic knowledge can be safely propagated across class boundaries.
- Evidence anchors:
  - [abstract]: "We assume the knowledge of a node can be disentangled into class-relevant and class-agnostic one, and thus explore a new message passing mechanism by extending the information bottleneck principle to only propagate class-agnostic knowledge between nodes of different classes"
  - [section 3.4]: "To avoid aggregating conﬂictive knowledge between nodes of different classes, one intuitive thought is to extract class-agnostic knowledge from each node, and transfer the class-agnostic knowledge between nodes of different classes"

### Mechanism 2
- Claim: OTGNet prevents catastrophic forgetting through triad structure selection and replay.
- Mechanism: The method selects representative triad structures (both closed and open) from old classes using an influence-based value function that balances importance and diversity. These triads are replayed during new class learning to preserve knowledge of old classes.
- Core assumption: Triad structures capture evolution patterns in temporal graphs and can serve as effective knowledge preservation units.
- Evidence anchors:
  - [abstract]: "Moreover, we devise a strategy to select both important and diverse triad sub-graph structures for effective class-incremental learning"
  - [section 3.3]: "we propose to select representative structures from old classes to preserve knowledge, and incorporate them into the learning process of new classes for replay"

### Mechanism 3
- Claim: The triad selection process balances importance and diversity through a submodular optimization.
- Mechanism: The method defines a value function combining influence-based importance scores with diversity measured by embedding similarity. This function is proven to be monotone and submodular, enabling greedy selection with approximation guarantees.
- Core assumption: The triad value function satisfies submodularity and monotonicity, allowing efficient greedy optimization.
- Evidence anchors:
  - [section 3.3]: "By Theorem 1, we can greedily select closed triads as in Algorithm 1. As aforementioned, the open triad set So k can be chosen by the same method. The proof of Theorem 1 can be found in Krause & Golovin (2014)."
  - [section A.3]: Formal proof of monotonicity and submodularity properties

## Foundational Learning

- Concept: Information Bottleneck Principle
  - Why needed here: OTGNet uses information bottleneck to extract class-agnostic representations by minimizing mutual information with class labels while preserving information about node features.
  - Quick check question: How does information bottleneck differ from traditional autoencoders in terms of the information it preserves and discards?

- Concept: Submodular Optimization
  - Why needed here: The triad selection problem is formulated as maximizing a submodular function, allowing efficient greedy algorithms with theoretical guarantees.
  - Quick check question: What properties must a function satisfy to be submodular, and why do these properties enable efficient optimization?

- Concept: Influence Functions
  - Why needed here: OTGNet uses influence functions to estimate the importance of triad structures without retraining the model, by measuring how much each triad contributes to classification performance.
  - Quick check question: How do influence functions estimate the effect of removing a training sample without actually retraining the model?

## Architecture Onboarding

- Component map: Knowledge Preservation Module -> Message Passing Module -> Training Loop
- Critical path: New task → Extract class-agnostic representations → Message passing → Classification loss → Triad selection → Replay triads → Next task
- Design tradeoffs:
  - Memory budget vs. representation quality: Larger M allows better old class preservation but increases memory and computation
  - Information bottleneck strength vs. discriminative power: Stronger bottleneck reduces heterophily propagation but may harm class discrimination
  - Triad selection complexity vs. approximation quality: More exhaustive search finds better triads but increases computational cost
- Failure signatures:
  - High average forgetting (AF) despite triad replay indicates ineffective knowledge preservation
  - Poor performance on new classes with good old class performance suggests excessive information bottleneck regularization
  - Slow convergence or unstable training may indicate inappropriate hyperparameter settings (ρ, β, γ)
- First 3 experiments:
  1. Compare OTGNet with and without information bottleneck on a small dataset to verify heterophily propagation mitigation
  2. Test triad selection with varying memory budgets (M) to find the sweet spot between performance and resource usage
  3. Evaluate the impact of the diversity term (γ) in triad selection by comparing with random and importance-only selection methods

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of OTGNet scale with increasing memory budget M for selected triads?
- Basis in paper: [explicit] The paper states "We note that our algorithm does not guarantee that the selected triads must be connected with the nodes in the new task" and mentions the memory budget M is set to 10 throughout experiments, but does not explore scaling behavior.
- Why unresolved: The paper only tests M=10 across all datasets and mentions time complexity concerns with larger M, but doesn't provide empirical evidence of performance trade-offs at different M values.
- What evidence would resolve it: A systematic study varying M from small to large values on multiple datasets showing both performance improvements and computational costs.

### Open Question 2
- Question: What is the theoretical lower bound on the approximation ratio of the greedy algorithm for the triad selection problem?
- Basis in paper: [explicit] The paper states "we show that F (Sc k) satisfies the condition of monotone and submodular" and references Krause & Golovin (2014) for a general theorem, but doesn't provide the specific bound for their value function.
- Why unresolved: The paper proves monotonicity and submodularity but doesn't calculate or state the actual approximation guarantee for their specific objective function.
- What evidence would resolve it: A formal proof showing the exact approximation ratio (e.g., (1-1/e)) for the specific value function F used in triad selection.

### Open Question 3
- Question: How does the choice of δ in the diversity constraint affect the quality of selected triads and model performance?
- Basis in paper: [explicit] The paper defines C(gc k,i) using a similarity radius δ and mentions it measures diversity, but doesn't systematically study its impact on model performance.
- Why unresolved: The paper sets δ=0.5 throughout experiments but doesn't explore how different δ values affect the diversity of selected triads or downstream performance.
- What evidence would resolve it: Empirical results showing model performance across different δ values, along with analysis of how δ affects the diversity distribution of selected triads.

## Limitations

- The assumption that node knowledge can be cleanly separated into class-relevant and class-agnostic components may not hold in all real-world scenarios
- The triad selection mechanism relies on influence functions which require Hessian computations that may not scale to very large graphs
- The method's performance is only validated on three datasets, limiting generalizability

## Confidence

- High confidence in the mechanism design and theoretical foundations (submodularity proof, information bottleneck formulation)
- Medium confidence in empirical performance due to limited dataset diversity
- Low confidence in scalability claims given the computational complexity of Hessian-based influence estimation

## Next Checks

1. **Scalability validation**: Test OTGNet on graphs with >100K nodes to verify Hessian computation and influence function estimation remain tractable

2. **Robustness to assumption violations**: Evaluate performance when class-relevant and class-agnostic knowledge are not well-separated by adding overlapping features to node attributes

3. **Alternative knowledge preservation**: Replace triad-based replay with simpler experience replay methods to isolate the contribution of the triad selection mechanism
