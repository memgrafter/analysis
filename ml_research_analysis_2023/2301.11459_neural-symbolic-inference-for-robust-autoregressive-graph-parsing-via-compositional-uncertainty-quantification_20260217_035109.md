# Neural-Symbolic Inference for Robust Autoregressive Graph Parsing via Compositional Uncertainty Quantification

## Quick Facts
- arXiv ID: 2301.11459
- Source URL: https://arxiv.org/abs/2301.11459
- Reference count: 35
- Achieves state-of-the-art SMATCH scores across 8 Redwoods Treebank evaluation corpora

## Executive Summary
This paper introduces a novel compositional neural-symbolic inference framework for graph semantic parsing that leverages uncertainty quantification at the subgraph level. The method combines neural autoregressive parsing with symbolic parsing, using the neural component's confidence estimates to determine when to invoke the symbolic parser for subgraph components with high uncertainty. This hybrid approach achieves superior generalization across domains and better handling of tail linguistic phenomena compared to pure neural or symbolic approaches, while maintaining state-of-the-art performance on in-domain test sets.

## Method Summary
The proposed method employs a two-stage parsing pipeline where a neural autoregressive graph parser generates subgraph components with associated confidence scores. When uncertainty exceeds a threshold for specific subgraph components, the system invokes a symbolic parser to generate those components instead. This compositional approach allows the neural parser to handle regular, predictable graph structures while the symbolic parser addresses complex or ambiguous cases where explicit rules are beneficial. The uncertainty quantification is performed at the subgraph level rather than globally, enabling more granular control over when to switch between neural and symbolic processing.

## Key Results
- Achieves 35.26% error reduction over pure neural parser on aggregated SMATCH score across 8 Redwoods Treebank corpora
- Demonstrates 35.60% error reduction compared to pure symbolic parser
- Shows significantly stronger robustness in generalization to out-of-distribution datasets and long-tail linguistic phenomena

## Why This Works (Mechanism)
The approach works by exploiting the complementary strengths of neural and symbolic methods. Neural parsers excel at capturing statistical patterns and regular structures but struggle with rare or complex linguistic phenomena. Symbolic parsers handle explicit rules well but lack flexibility for statistical patterns. By quantifying uncertainty compositionally at the subgraph level, the system can dynamically route components to the most appropriate parser, combining the neural parser's pattern recognition with the symbolic parser's rule-based precision where needed.

## Architecture Onboarding

**Component Map:**
Neural Parser -> Confidence Estimator -> Decision Module -> (Neural Parser / Symbolic Parser) -> Graph Assembler

**Critical Path:**
Input sentence → Neural parser generates subgraphs with confidence → Decision module routes high-uncertainty subgraphs to symbolic parser → Symbolic parser processes selected subgraphs → Graph assembler combines outputs → Final semantic graph

**Design Tradeoffs:**
The system trades computational overhead for improved accuracy and robustness. Maintaining both neural and symbolic parsers increases memory usage and inference time, but enables better handling of edge cases and generalization. The confidence threshold parameter requires tuning - too low wastes symbolic resources, too high misses opportunities for improvement.

**Failure Signatures:**
- False negatives: Low-confidence neural components incorrectly routed to neural parser
- False positives: High-confidence neural components that would benefit from symbolic parsing
- Subgraph decomposition errors that break semantic dependencies
- Confidence miscalibration leading to poor routing decisions

**First Experiments:**
1. Evaluate component routing accuracy by measuring improvement when symbolic parser handles subgraphs
2. Test confidence calibration across different linguistic phenomena
3. Measure computational overhead compared to pure neural or symbolic baselines

## Limitations
- Assumes reliable uncertainty estimation at subgraph level, which may not hold for all graph structures
- Symbolic parser performance depends on quality of subgraph components, with potential error propagation
- Computational overhead from maintaining dual parsing systems may limit scalability to larger graphs

- Uncertainty quantification methodology (Medium): Theoretically sound but implementation details matter
- Robustness claims (Medium): Demonstrated generalization but could benefit from more diverse evaluation
