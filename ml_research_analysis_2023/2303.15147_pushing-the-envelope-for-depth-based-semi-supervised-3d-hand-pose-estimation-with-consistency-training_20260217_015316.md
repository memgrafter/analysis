# Pushing the Envelope for Depth-Based Semi-Supervised 3D Hand Pose Estimation with Consistency Training

## Quick Facts
- arXiv ID: 2303.15147
- Source URL: https://arxiv.org/abs/2303.15147
- Reference count: 40
- Primary result: Proposed semi-supervised method significantly outperforms state-of-the-art methods, achieving performance on par with fully supervised methods using only 25% of annotations.

## Executive Summary
This paper presents a semi-supervised framework for 3D hand pose estimation from depth images that leverages unlabeled data through consistency training. The method employs a teacher-student network architecture where the teacher network is trained using both labeled and unlabeled data with a consistency loss that enforces equivariance under affine transformations. The student network is trained using pseudo-labels generated by the teacher network's EMA parameters. Experiments on three public datasets (ICVL, NYU, MSRA) demonstrate that the method significantly outperforms existing semi-supervised approaches while achieving performance comparable to fully supervised methods with only 25% of the annotations.

## Method Summary
The proposed method uses a two-network teacher-student framework for semi-supervised 3D hand pose estimation. The teacher network is trained using labeled data with supervised loss and unlabeled data with consistency loss, enforcing equivariance under affine transformations. The student network is trained using pseudo-labels generated by the teacher network's exponential moving average (EMAN) parameters. Both networks share the same architecture: an Hourglass encoder followed by two branches for heatmap and depth map estimation. The method employs dynamic thresholding and sample masking to reduce confirmation bias during training. For inference, only the student network is used, achieving state-of-the-art performance with significantly reduced annotation requirements.

## Key Results
- The proposed method outperforms state-of-the-art semi-supervised approaches by a significant margin across all three datasets (ICVL, NYU, MSRA).
- Using only 25% of the annotations, the method achieves performance comparable to state-of-the-art fully supervised methods.
- The teacher-student framework with consistency training and EMA-based pseudo-labels demonstrates effective utilization of unlabeled data for improving 3D hand pose estimation accuracy.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Consistency training enforces equivariance under affine transformations on unlabeled data, improving pose estimation accuracy.
- Mechanism: The teacher network is trained using both labeled and unlabeled samples. For unlabeled data, the method enforces that the pose estimation remains consistent across different affine transformations (rotation, scaling, translation) of the same input. This is implemented via a consistency loss that measures the difference between the pose estimation of an augmented view and the pose estimation of the original view by the teacher network.
- Core assumption: Maintaining pose estimation equivariance under affine transformations improves generalization and accuracy for 3D hand pose estimation.
- Evidence anchors:
  - [abstract] "The teacher network is trained using both the available labeled and unlabeled samples. It leverages the unlabeled samples via a loss formulation that encourages estimation equivariance under a set of affine transformations."
  - [section] "It leverages the unlabeled samples via a loss formulation that encourages estimation equivariance under a set of affine transformations."
- Break condition: If the augmentation set M does not include relevant transformations for hand pose variations, or if the equivariance assumption does not hold for complex hand poses.

### Mechanism 2
- Claim: Using a student network trained on pseudo-labels from the teacher network, refined by exponential moving average (EMAN), improves stability and accuracy.
- Mechanism: The student network is trained using pseudo-labels generated by the teacher network. To stabilize training, the pseudo-labels are generated using the exponential moving average (EMAN) of the teacher network's parameters, not the instantaneous parameters. This prevents the student from chasing a rapidly changing target.
- Core assumption: The EMA of the teacher's parameters provides a more stable and reliable source of pseudo-labels for training the student.
- Evidence anchors:
  - [abstract] "The student network is trained using the unlabeled samples with their pseudo-labels provided by the teacher network."
  - [section] "However, using pseudo-labels generated directly by the teacher network can lead to a potential problem. The teacher itself is constantly updated in the training, which could cause performance degradation and training instability in the student network. An alternative is to use the exponential moving average (EMA) of the teacher network's parameters to generate pseudo-labels [52]."
- Break condition: If the teacher network's performance degrades significantly, the EMA will also degrade, providing poor pseudo-labels.

### Mechanism 3
- Claim: Dynamic thresholding and sample masking reduce confirmation bias and improve the quality of pseudo-labels.
- Mechanism: The method uses uncertainty estimation (standard deviation of predicted heatmaps) to mask out noisy pseudo-labels during training. Dynamic thresholding adjusts the acceptance threshold for each joint based on the fraction of pseudo-labels accepted in previous epochs, ensuring a balanced use of pseudo-labels across all joints.
- Core assumption: Masking out low-confidence pseudo-labels and dynamically adjusting thresholds reduces confirmation bias and improves training stability.
- Evidence anchors:
  - [abstract] "Unlike SemiHand [43], the proposed method only uses view consistency."
  - [section] "Sample Masking. Models trained using self-generated pseudo-labels generally suffer from confirmation bias [52], where the model keeps amplifying its own errors. It has been demonstrated that masking out noisy pseudo-labels and maintaining only high-quality ones for training can considerably reduce the confirmation bias [44]."
- Break condition: If the uncertainty measure (heatmap standard deviation) is not a reliable indicator of pseudo-label quality, or if the dynamic thresholding strategy is not properly tuned.

## Architecture Onboarding

- Component map: The system consists of two identical networks: a teacher network and a student network. The teacher network is trained using both labeled and unlabeled data with a consistency loss. The student network is trained using pseudo-labels generated by the teacher network's EMAN parameters. Both networks follow the same architecture, consisting of an encoder (Hourglass network) and two branches for heatmap and depth map estimation.
- Critical path: The critical path is the training of the teacher network, as it directly influences the quality of the pseudo-labels used to train the student network. Ensuring the teacher network is trained effectively with proper consistency loss and masking strategies is crucial.
- Design tradeoffs: The method trades increased training complexity (two networks, consistency loss, dynamic thresholding) for improved performance with limited labeled data. The use of EMAN adds complexity but improves stability.
- Failure signatures: Poor performance could indicate issues with the teacher network's training (e.g., incorrect consistency loss, inadequate masking), instability in the student network's training (e.g., incorrect EMAN parameters), or an unsuitable architecture for the task.
- First 3 experiments:
  1. Train the teacher network on labeled data only to establish a baseline performance.
  2. Train the teacher network with consistency training on unlabeled data to evaluate the impact of consistency loss.
  3. Train the student network using pseudo-labels from the teacher network to assess the effectiveness of the student-teacher paradigm.
