# Semi-supervised Learning of Pushforwards For Domain Translation & Adaptation

- arXiv ID: 2304.08673

## Executive Summary
This paper presents a novel algorithm for learning pushforward maps between probability distributions, addressing key challenges in domain translation, adaptation, and generative modeling. The method reformulates optimal transport as a map-focused problem using normalizing flows to parameterize the transformation, allowing for out-of-sample application, constraint incorporation, and probabilistic modeling. The approach is evaluated on synthetic benchmarks and a real-world scientific application involving spectral calibration between Earth and Mars measurements, demonstrating superior performance compared to existing methods.

## Method Summary
The method, called parOT (parametric pushforward estimation with map constraints), parameterizes the pushforward map using compositions of normalizing flows, which are diffeomorphic transformations with tractable Jacobians. The learning objective combines multiple terms: a paired loss for known correspondences, negative log-likelihoods for the source and target distributions, an integral probability metric (IPM) to align the distributions, and identity regularization. This formulation allows the method to incorporate domain knowledge through regularization, provide probabilistic models for sampling and likelihood evaluation, and apply to out-of-sample data points. The approach can operate with varying levels of supervision, from fully paired to semi-supervised settings.

## Key Results
- Superior map accuracy compared to existing OT methods on benchmark datasets
- Effective domain adaptation demonstrated on ChemCam spectral measurements from Earth and Mars
- Provides probabilistic modeling capabilities including sampling and likelihood evaluation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The method can transform out-of-sample data points from the source domain to the target domain.
- Mechanism: The pushforward map is parameterized as a composition of normalizing flows (NFs), which are diffeomorphic maps that can be inverted and have tractable Jacobians. This allows the map to be applied to new data points.
- Core assumption: The true pushforward map is a diffeomorphism from the source to target space.
- Evidence anchors:
  - [abstract]: "the map must be available to apply on out-of-sample data points"
  - [section 3.2]: "We use compositions of NFs... to parameterize the function T"
- Break condition: If the true pushforward is not a diffeomorphism (e.g., it's not bijective or not differentiable), the NF parameterization may fail to accurately represent it.

### Mechanism 2
- Claim: The method can incorporate domain knowledge via regularization.
- Mechanism: The loss function includes a term that penalizes the difference between the pushforward of the source distribution and the target distribution, measured by an integral probability metric (IPM). This regularization term can be modified to include domain-specific constraints.
- Core assumption: The IPM can be computed efficiently for the chosen class of functions.
- Evidence anchors:
  - [abstract]: "the map must be available to apply on out-of-sample data points and should correspond to a probabilistic model over the two spaces"
  - [section 3.1]: "we can formulate well-defined constraints on F"
- Break condition: If the chosen class of functions for the IPM is too restrictive, it may not capture important domain knowledge.

### Mechanism 3
- Claim: The method provides a probabilistic model over the source and target spaces.
- Mechanism: The normalizing flows parameterize the pushforward map, which induces a probability distribution on the target space. This allows for sampling from the target distribution and evaluating likelihoods.
- Core assumption: The normalizing flows can accurately model the source and target distributions.
- Evidence anchors:
  - [abstract]: "it models the empirical distributions over the two data spaces and allows both sampling and likelihood evaluation"
  - [section 3.2]: "the parameters θNF of the NFs... should maximize the likelihood"
- Break condition: If the normalizing flows are not expressive enough to model the true distributions, the probabilistic model will be inaccurate.

## Limitations
- The assumption that the pushforward map is a diffeomorphism may not hold in all real-world scenarios, particularly when source and target distributions have different supports or topological structures.
- Sample complexity guarantees remain theoretical without empirical validation on truly high-dimensional data (>1000 dimensions).
- Claims about scalability to very high-dimensional spaces lack empirical support beyond theoretical analysis.

## Confidence
- **High confidence**: The theoretical framework connecting optimal transport to normalizing flows is sound, and the synthetic benchmark results are reproducible and clearly presented.
- **Medium confidence**: The domain adaptation results on the ChemCam dataset are promising but limited to a single real-world application, making generalization uncertain.
- **Low confidence**: Claims about scalability to very high-dimensional spaces (>1000 dimensions) lack empirical support beyond the theoretical analysis.
