# Instance-Aware Repeat Factor Sampling for Long-Tailed Object Detection

## Executive Summary
This paper introduces Instance-Aware Repeat Factor Sampling (IRFS), a method that addresses long-tail distribution in object detection by combining both image and instance counts to define resampling factors. The approach improves upon traditional Repeat Factor Sampling (RFS) by using a geometric mean of image and instance count fractions, ensuring better prioritization of rare categories during training. IRFS demonstrates significant performance gains, particularly for rare categories, while maintaining performance on common and frequent categories. The method is designed as a plug-in replacement for RFS and can be easily integrated into existing long-tailed detection frameworks.

## Method Summary
IRFS addresses long-tail imbalance by computing resampling factors using the geometric mean of image count fraction (f(i,c)) and instance count fraction (f(b,c)) for each category. This approach unifies instance and image counts in the resampling process, creating a more balanced view of category rarity. The method uses a threshold t=0.001 to determine the resampling factor rc = max(1, √t/√f(i,c)×f(b,c)). IRFS is evaluated using the LVIS v1.0 dataset with Mask R-CNN and Cascade Mask R-CNN frameworks, ResNet-50/101 backbones, and standard training hyperparameters including 12-epoch schedules with SGD optimization.

## Key Results
- Achieves +50% relative average precision improvement on rare categories compared to RFS
- Improves performance on common categories by +7% and frequent categories by +2% over RFS
- Demonstrates consistent results across different backbone architectures (ResNet-50 and ResNet-101)
- Shows effectiveness when combined with ECM loss and other long-tailed frameworks

## Architecture Onboarding

- Component map:
  Data loader -> Instance count tracking -> Category-level repeat factor calculator -> Image-level repeat factor aggregator -> Training pipeline

- Critical path:
  1. Compute image count fraction f(i,c) for each category
  2. Compute instance count fraction f(b,c) for each category  
  3. Calculate geometric mean √f(i,c)×f(b,c)
  4. Apply threshold t to determine resampling factor rc
  5. Aggregate rc across categories in each image to get ri
  6. Implement resampling during training

- Design tradeoffs:
  - Geometric mean vs harmonic/quadratic mean: Geometric mean provides multiplicative balance but may under-represent extreme cases
  - Instance count precision vs computational overhead: More precise instance tracking improves IRFS but increases preprocessing time
  - Fixed threshold t vs adaptive threshold: Fixed threshold simplifies implementation but may not generalize across datasets

- Failure signatures:
  - Numerical instability when f(i,c) or f(b,c) approaches zero
  - Over-resampling of extremely rare categories leading to overfitting
  - Under-resampling of moderately rare categories due to geometric mean dampening

- First 3 experiments:
  1. Compare IRFS with geometric mean vs IRFS with arithmetic mean on LVIS v1.0 rare category AP
  2. Test IRFS with different threshold values (t = 0.001, 0.01, 0.1) to find optimal performance
  3. Combine IRFS with ECM loss and compare against standalone RFS and standalone ECM performance
