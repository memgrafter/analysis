# Accelerating Policy Gradient by Estimating Value Function from Prior Computation in Deep Reinforcement Learning

## Quick Facts
- arXiv ID: 2302.01399
- Source URL: https://arxiv.org/abs/2302.01399
- Reference count: 6
- Key outcome: Proposed method improves sample efficiency in on-policy policy gradient methods by using prior computation to estimate value functions, reducing gradient variance.

## Executive Summary
This paper introduces a method to improve sample efficiency in on-policy policy gradient methods by leveraging prior computation to estimate value functions. The approach combines value estimates from pre-trained networks (such as DQN Q-networks) with newly learned value functions, using this combined estimate as a baseline in policy gradient updates. This technique reduces gradient variance and accelerates learning, particularly in early training stages. Experiments demonstrate effectiveness across multiple environments including LunarLander, BeamRider, Breakout, and Walker tasks.

## Method Summary
The method estimates value functions from prior computations (e.g., Q-networks from DQN) and combines them with new value function estimates for target tasks. A weighted linear combination serves as a baseline in policy gradient methods, with a weaning factor that gradually transitions from relying on prior computation to the newly learned value function. The approach is tested in four settings: same algorithm same task, different algorithm same task, same algorithm different task, and different algorithm different task, demonstrating improved sample efficiency across these scenarios.

## Key Results
- LunarLander: Method quickly solved the task, outperforming baseline
- BeamRider: Performance improved after 2.5M timesteps compared to training from scratch
- Breakout: Achieved better performance after 5M timesteps than baseline
- Walker tasks: Demonstrated effectiveness in continuous control settings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using a prior value function as a baseline reduces gradient variance in policy gradient methods, improving sample efficiency.
- Mechanism: The prior value function provides a more accurate baseline than Monte Carlo estimates, reducing the variance of gradient estimates in policy gradient updates.
- Core assumption: The prior value function is a reasonable approximation of the true value function for the target task.
- Evidence anchors: Abstract mentions theoretical property of reducing variance in gradient computation and improving sample efficiency.
- Break condition: If the prior value function is significantly different from the true value function, the baseline could introduce bias and hurt learning.

### Mechanism 2
- Claim: Linear combination of current and prior value functions provides a smooth transition that maintains unbiased gradient estimates while improving initial learning.
- Mechanism: The weaning factor w_t allows gradual transition from relying on prior computation to the newly learned value function.
- Core assumption: The weaning schedule is properly tuned to balance prior knowledge with new learning.
- Evidence anchors: Paper discusses the weaning parameter and its role in making up for initial bad estimates of the value function.
- Break condition: If the weaning schedule is too aggressive or too conservative, it could either discard useful prior knowledge too quickly or prevent the new value function from learning effectively.

### Mechanism 3
- Claim: Prior computation from different algorithms (DQN) and environments can be effectively transferred to improve policy gradient methods.
- Mechanism: The value function abstraction allows knowledge transfer across different RL algorithms and environments.
- Core assumption: The underlying MDP structure (state and action spaces) is sufficiently similar between source and target tasks.
- Evidence anchors: Abstract mentions estimating value functions from prior computations like Q-networks learned in DQN.
- Break condition: If the source and target tasks have significantly different dynamics or reward structures, the transferred value function may provide misleading information.

## Architecture Onboarding

- Component map:
  - Q-function extractor -> Value function learner -> Baseline combiner -> Policy gradient optimizer -> Environment
  - State -> Value estimator (combined) -> Policy gradient -> Action -> Environment -> Reward -> Value function update -> Policy update

- Critical path: State → Value estimator (combined) → Policy gradient → Action → Environment → Reward → Value function update → Policy update

- Design tradeoffs:
  - Fixed vs. adaptive weaning schedule: Fixed schedules are simpler but may not adapt to task complexity
  - Source task selection: More similar tasks provide better priors but may limit transfer opportunities
  - Computational overhead: Additional value function estimation vs. sample efficiency gains

- Failure signatures:
  - Slow initial learning: Prior value function may be too dissimilar from target task
  - Unstable training: Weaning schedule may be improperly tuned
  - Poor final performance: New value function may not learn effectively

- First 3 experiments:
  1. LunarLander with pre-trained Q-network from same environment - verify baseline variance reduction
  2. Walker stand to walker run transfer - test cross-task value function transfer
  3. Same algorithm, same task rerun - validate self-transfer capability

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance gain scale with the quality of the pre-trained Q-function or value function?
- Basis in paper: The paper mentions that "A better pre-training, in general, should result in a better performance gain" and discusses the importance of the quality of the pre-trained Q-function.
- Why unresolved: The paper does not provide quantitative analysis on how the performance gain scales with the quality of the pre-trained function.
- What evidence would resolve it: Experiments varying the quality of pre-trained Q-functions and measuring the corresponding performance gains in the target task.

### Open Question 2
- Question: What is the optimal weaning strategy for the weight w_t that balances between the prior computation and the new value function?
- Basis in paper: The paper discusses using a weaning factor w_t to balance between the prior value function and the new value function, but notes that it needs to be tuned based on task complexity and pre-trained Q-network quality.
- Why unresolved: The paper does not provide a systematic approach to determine the optimal weaning strategy.
- What evidence would resolve it: Comparative studies of different weaning strategies (fixed, linear decay, exponential decay, etc.) across various tasks and pre-trained function qualities.

### Open Question 3
- Question: How does the method perform in high-dimensional observation spaces beyond the tested Atari and vector-based environments?
- Basis in paper: The paper tests the method on Atari (image-based) and vector-based environments but does not explore more complex high-dimensional spaces.
- Why unresolved: The paper's experimental scope is limited to specific environment types.
- What evidence would resolve it: Application and evaluation of the method on environments with higher-dimensional observations (e.g., 3D vision-based tasks, point cloud data).

### Open Question 4
- Question: Can the method be extended to continuous action spaces where estimating the value function from a Q-function is intractable?
- Basis in paper: The paper acknowledges that "estimating the value from Q-function can be challenging for the continuous case" and focuses on discrete action spaces.
- Why unresolved: The paper does not provide solutions or experiments for continuous action spaces.
- What evidence would resolve it: Development and testing of methods to estimate value functions from Q-functions in continuous action spaces, or alternative approaches to leverage prior computation in such settings.

## Limitations
- Limited experimental scope to four environments with comparison primarily against single baseline
- No systematic exploration of different weaning schedules or sensitivity to initial weighting factor
- Transfer effectiveness across significantly different tasks not thoroughly evaluated

## Confidence
- High confidence: The core theoretical claim that using a baseline reduces variance in policy gradient methods is well-established in RL literature
- Medium confidence: The effectiveness of cross-algorithm knowledge transfer and cross-task transfer shows promise but needs broader validation
- Low confidence: The optimal weaning schedule and sensitivity to initial conditions are not well-characterized

## Next Checks
1. Ablation study on weaning schedules: Systematically test different weight decay schedules (linear, exponential, adaptive) to identify optimal transition strategies from prior to learned value functions
2. Cross-task transfer robustness: Evaluate the method on tasks with varying degrees of similarity to the source task, including tasks with different reward structures or dynamics, to establish transfer boundaries
3. Computational overhead analysis: Quantify the additional computation required for maintaining and using the prior value function against the sample efficiency gains to determine practical deployment scenarios
