# Scalable Clustering: Large Scale Unsupervised Learning of Gaussian Mixture Models with Outliers

## Quick Facts
- arXiv ID: 2302.14599
- Source URL: https://arxiv.org/abs/2302.14599
- Authors: 
- Reference count: 40
- Primary result: Proposes SCRLM algorithm for scalable clustering with outliers, achieving 100% accuracy under certain assumptions

## Executive Summary
This paper introduces SCRLM, a scalable clustering algorithm for Gaussian mixture models with outliers that extracts clusters one-by-one by finding local minima of a robust loss function. The method addresses the challenge of clustering large-scale, high-dimensional datasets with outliers while maintaining computational efficiency. SCRLM provides theoretical guarantees for accuracy under specific assumptions about cluster separation and distribution, making it particularly suitable for applications requiring both speed and precision in unsupervised learning.

## Method Summary
SCRLM operates by first identifying cluster centers as local minima of a robust loss function designed to be resistant to outliers. The algorithm then extracts clusters sequentially, starting with the most prominent ones, by assigning points based on proximity to identified centers while accounting for outlier contamination. This one-by-one extraction approach allows SCRLM to handle large datasets efficiently without requiring simultaneous computation of all clusters. The method combines robust statistics principles with greedy optimization to achieve both scalability and accuracy in unsupervised clustering tasks.

## Key Results
- Achieves 100% clustering accuracy with high probability under assumptions of spherical Gaussian clusters with well-separated centers
- Outperforms existing methods in both accuracy and computational speed, particularly for large-scale high-dimensional datasets
- Serves as an effective initialization method for k-means clustering, improving convergence and final results

## Why This Works (Mechanism)
SCRLM's effectiveness stems from its robust loss function that naturally downweights the influence of outliers during cluster center identification. By finding local minima of this loss function, the algorithm can distinguish true cluster centers from outlier-influenced points even when contamination is present. The sequential extraction approach prevents error propagation that often occurs in simultaneous clustering methods, as each cluster is identified and removed before proceeding to the next. This one-by-one strategy, combined with the robust optimization framework, allows SCRLM to maintain accuracy while scaling to large datasets where traditional methods struggle.

## Architecture Onboarding

**Component Map:**
Robust Loss Function -> Local Minimum Finding -> Sequential Cluster Extraction -> Outlier Handling -> Final Clustering Assignment

**Critical Path:**
1. Compute robust loss function over data points
2. Identify local minima as candidate cluster centers
3. Extract most prominent cluster based on center proximity
4. Remove identified cluster points and repeat
5. Handle remaining points as outliers or assign to nearest cluster

**Design Tradeoffs:**
- Sequential extraction provides scalability but may miss subtle cluster structures
- Robust loss function increases computation time but improves outlier resistance
- Local optimization ensures efficiency but may get stuck in suboptimal solutions

**Failure Signatures:**
- Poor performance when cluster separation assumption (σ < Δ/2) is violated
- Degraded accuracy with non-spherical or varying-density clusters
- Sensitivity to parameter choices in the robust loss function formulation

## Open Questions the Paper Calls Out

## Limitations
- Theoretical guarantees assume spherical Gaussian clusters with well-separated centers, limiting real-world applicability
- Strong requirement that maximum intra-cluster distance must be less than half the minimum inter-cluster distance (σ < Δ/2)
- Performance with varying numbers and distributions of outliers requires further exploration
- Claims of 100% accuracy under specific conditions need broader validation across diverse datasets
