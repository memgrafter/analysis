# Grounding and Distinguishing Conceptual Vocabulary Through Similarity Learning in Embodied Simulations

## Quick Facts

## Executive Summary
This paper presents a method for grounding contextualized word vectors from transformer-based language models to object representations using similarity learning in embodied simulations. The approach learns to compare and distinguish objects based on their geometric properties and behaviors when interacted with, then uses an affine transformation to project word vectors into this learned object representation space. The results show that grounding object representations helps subsequent grounding of verb and attribute concepts more than the reverse, and that XLM embeddings perform best at clustering with the correct object types after transformation.

## Method Summary
The method involves collecting agent interaction data from a virtual environment where objects are manipulated in stacking tasks. A similarity learning model with multi-similarity loss is trained on this behavioral data to create an object representation space that captures abstract properties like roundness and flatness. Contextualized embeddings from BERT, RoBERTa, ALBERT, and XLM are extracted from generated sentences describing objects and their behaviors. A ridge regression-based affine transformation is then computed to map language model embeddings into the object representation space. Grounding quality is evaluated by incrementally adding conceptual vocabulary and measuring clustering performance with KNN classification.

## Key Results
- Similarity learning over object behavior data successfully distinguishes between 9 object types (roundness/flatness classification) with high accuracy
- XLM embeddings achieve the highest clustering accuracy after affine transformation into object representation space
- Grounding object concepts first before abstract concepts yields better overall grounding performance than the reverse order

## Why This Works (Mechanism)

### Mechanism 1
Similarity learning over object behavior data creates a representation space that captures abstract properties (roundness/flatness) across object types. The pair-based deep learning with multi-similarity loss maximizes distances between dissimilar object samples and minimizes distances between similar ones, causing the model to learn embeddings that encode common structural properties.

### Mechanism 2
An affine transformation can map contextualized word embeddings from LLMs into the learned object representation space while preserving semantic relationships. Ridge regression learns a projection matrix that minimizes mean squared error between paired word and object embeddings, creating a "bridge" between language and object spaces.

### Mechanism 3
Grounding object concepts first facilitates grounding of related abstract concepts (verbs, attributes) more effectively than the reverse order. Object representations provide a concrete scaffold that abstract concepts can attach to, following psycholinguistic patterns of human concept learning.

## Architecture Onboarding

- **Component map**: Data collection -> Similarity learning model -> Object representation space creation -> LLM embedding extraction -> Affine transformation computation -> Concept grounding evaluation

- **Critical path**: Data collection → Similarity learning → Object representation space creation → LLM embedding extraction → Affine transformation computation → Concept grounding evaluation

- **Design tradeoffs**:
  - Using behavior data vs. images: Behavior data is less noisy and computationally cheaper but may miss visual distinctions
  - Simple affine mapping vs. complex neural network: Affine is interpretable and efficient but may not capture non-linear relationships
  - Small hint set vs. larger supervised training: Hints improve performance with minimal data but may introduce bias

- **Failure signatures**:
  - Poor object classification accuracy in similarity learning phase
  - Low KNN F1 scores in transformed concept embedding space
  - Cluster separation metrics showing no improvement as more concepts are added to mapping
  - High variance in transformation matrix across different training runs

- **First 3 experiments**:
  1. Train similarity learning model on object behavior data and evaluate classification accuracy on held-out test set
  2. Compute affine transformation using only object terms and evaluate clustering of related attribute/verb terms
  3. Add hints to transformation computation and measure improvement in grounding performance for each LLM model

## Limitations

- The evaluation is limited to 9 specific objects in a stacking task, which may not represent the full complexity of real-world grounding scenarios
- The assumption that behavior trajectories encode all relevant object properties needs more empirical validation
- The effectiveness of simple affine transformations versus more complex mappings is not thoroughly explored

## Confidence

**High Confidence**: The technical implementation of the similarity learning framework with multi-similarity loss and the ridge regression-based affine transformation are standard, well-established approaches.

**Medium Confidence**: The claim that grounding object concepts first facilitates better grounding of abstract concepts than the reverse order shows promising results but requires more rigorous testing.

**Low Confidence**: The assertion that XLM embeddings consistently outperform other models in clustering accuracy needs more extensive validation.

## Next Checks

1. **Cross-domain validation**: Test the grounding approach on a completely different embodied simulation environment (e.g., kitchen manipulation tasks with utensils and food items) to verify that the learned representations generalize beyond the original stacking task.

2. **Ablation study on transformation complexity**: Compare the simple affine transformation against more complex non-linear mappings (e.g., small neural networks) to determine if the linear assumption holds across different object categories and concept types.

3. **Behavioral analysis of failure cases**: Systematically analyze instances where transformed embeddings fail to cluster correctly, examining whether failures stem from the similarity learning phase, the transformation computation, or inherent limitations in the LLM embeddings themselves.
