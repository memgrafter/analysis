# Contextual Dynamic Prompting for Response Generation in Task-oriented Dialog Systems

## Quick Facts

## Executive Summary
This paper addresses response generation in task-oriented dialog systems by proposing contextual dynamic prompting, which learns prompts from dialog contexts to improve upon traditional prefix-tuning approaches. The method encodes dialog context (and optionally dialog states) into continuous prompt vectors that are concatenated with user utterances before being fed into a frozen T5 model. Experiments on the MultiWOZ 2.2 dataset show that contextual dynamic prompts improve combined score by 3 points and by 20 points when dialog states are incorporated compared to the baseline. Human evaluation confirms that agents using contextual dynamic prompts are preferred over vanilla prefix-tuning, demonstrating improved response quality and conversational experience.

## Method Summary
The paper proposes contextual dynamic prompting for response generation in task-oriented dialog systems. The approach involves encoding dialog context and dialog states into continuous prompt vectors using a frozen T5 encoder, which are then transformed into prefix tokens via a lightweight MLP. These prefix tokens are concatenated with user utterances and fed into a frozen T5 decoder to generate system responses. The method is evaluated on the MultiWOZ 2.2 dataset, comparing performance with vanilla prefix-tuning using metrics like BLEU, Inform, Success, and Combined score.

## Key Results
- Contextual dynamic prompts improve combined score by 3 points compared to baseline
- Dialog states incorporation improves performance by 20 points
- Human evaluation shows agents with contextual dynamic prompts are preferred over vanilla prefix-tuning

- Core assumption: Dialog context contains useful signals that can guide response generation, and these signals vary across turns.

## Architecture Onboarding

- Component map: T5 encoder -> MLP (prompt encoder) -> T5 decoder
- Critical path:
  1. Encode dialog context and dialog states using the frozen T5 encoder.
  2. Transform the context representation into prefix tokens using the MLP.
  3. Concatenate the prefix tokens with the user utterance.
  4. Generate the system response using the T5 decoder.
- Design tradeoffs:
  - Freezing the T5 encoder vs. fine-tuning: Freezing the encoder keeps the number of trainable parameters low but may limit the model's ability to adapt to the task.
  - Including dialog states vs. context only: Incorporating dialog states provides structured information but requires accurate state tracking.
  - Using a lightweight MLP vs. a more complex model: A simpler MLP keeps the model efficient but may limit its capacity to extract complex signals.
- Failure signatures:
  - Poor performance on the validation set: Indicates that the model is not effectively learning from the context or states.
  - Inconsistent responses across similar contexts: Suggests that the prefix generation is not capturing the relevant context information.
  - High BLEU score but low inform/success rates: Implies that the model is generating fluent but not task-relevant responses.
- First 3 experiments:
  1. Train and evaluate the model with context only (no dialog states) to assess the impact of contextual prompting.
  2. Train and evaluate the model with context and dialog states to assess the impact of incorporating structured information.
  3. Compare the model's performance with vanilla prefix-tuning on the validation set to validate the effectiveness of contextual dynamic prompting.
