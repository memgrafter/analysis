# Removing supervision in semantic segmentation with local-global matching and area balancing

## Quick Facts
- arXiv ID: 2303.17410
- Source URL: https://arxiv.org/abs/2303.17410
- Reference count: 40
- Primary result: 75% mIoU on PascalVOC2012 val set with image-level labels

## Executive Summary
Patch-Class to Masks (PC2M) introduces an end-to-end network for semantic segmentation that uses only image-level labels through local-global patch matching and area balancing. The method achieves state-of-the-art performance in weakly supervised semantic segmentation (75% mIoU on PascalVOC2012) and extends to unsupervised segmentation by replacing labels with self-supervised features. The core innovation lies in using optimal transport plans with area constraints to align local and global predictions, producing dense pseudo-labels that capture object shape and localization.

## Method Summary
PC2M uses a dual-branch ViT architecture with shared weights, processing full images (global branch) and cropped patches (local branch) through different augmentations. Both branches predict patch-class probability matrices, which are aligned using optimal transport plans that respect estimated class area distributions. The area distributions are updated via exponential moving average, and the model is trained using a combination of match-loss (relative entropy between transport plans) and multi-class cross-entropy loss. For unsupervised segmentation, image-level labels are replaced with pseudo-multi-level labels generated from self-supervised DINO features clustered via normalized Laplacian eigenvectors.

## Key Results
- 75% mIoU on PascalVOC2012 validation set (weakly supervised)
- 46% mIoU on MS-COCO2014 validation set (weakly supervised)
- 43.6% mIoU on PascalVOC2012 validation set (unsupervised)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Optimal transport with area balancing forces local and global branch predictions to agree on both class assignments and relative object sizes.
- Mechanism: Two marginal distributions (αℓ, αg) represent estimated class areas. OT finds coupling matrices Qℓ and Qg matching patches to classes while respecting area constraints. Match-loss contrasts transport plans between branches, encouraging agreement on dense pseudo-labels.
- Core assumption: Estimated class areas are good proxies for true areas, and enforcing agreement improves localization and shape consistency.
- Evidence anchors:
  - [abstract]: "The local-global matching is compelled by optimal transport plans fulfilling area constraints nearing a solution for exact shape prediction."
  - [section]: "The local-global matching is, in turn, compelled by optimal transport plans fulfilling area constraints nearing a solution for exact shape prediction."
- Break condition: If area estimates α are severely wrong, transport plan forces incorrect pseudo-labels; if OT regularization ϵ is too small, transport becomes unstable.

### Mechanism 2
- Claim: Dual-branch architecture with local and global views improves object part grouping by contrasting fine-grained and context-aware representations.
- Mechanism: One branch receives full images (global), the other receives cropped patches (local). Different augmentations force network to reconcile fine details with overall context, improving grouping of parts into coherent objects.
- Core assumption: Local and global views capture complementary information that, when aligned, yield better masks than single-view approaches.
- Evidence anchors:
  - [abstract]: "PC2M is formed by two branches, one developing on augmentations with image parts and the other with augmentations using most of the image..."
  - [section]: "By feeding different augmented views (one seizing most of the original image and one randomly cropping parts of it) to the two branches..."
- Break condition: If augmentations are too similar, branches collapse into redundancy; if too dissimilar, alignment loss becomes ineffective.

### Mechanism 3
- Claim: Replacing image-level labels with self-supervised DINO features and clustering yields pseudo-multi-labels for unsupervised segmentation.
- Mechanism: Self-supervised features extracted per patch, graph built using cosine affinities, normalized Laplacian eigenvectors clustered to produce pseudo-labels without human annotation.
- Core assumption: DINO features capture semantic structure that clustering can separate into meaningful object categories.
- Evidence anchors:
  - [abstract]: "Dropping the image-level labels and clustering self-supervised learned features to yield pseudo-multi-level labels, we obtain an unsupervised model..."
  - [section]: "We withdraw the image-level labels and compute the pseudo-multi-labels using self-supervised features... we use DINO [6] self-supervised features."
- Break condition: If DINO features are not discriminative enough, clustering produces incoherent pseudo-labels; if number of clusters is wrong, semantic meaning is lost.

## Foundational Learning

- Concept: Optimal Transport with entropic regularization
  - Why needed here: OT finds transport plan between patch predictions and class areas optimal under cost (negative log likelihood) while entropy regularization ensures smoothness.
  - Quick check question: What does the entropy term in OT regularization prevent, and why is it important for training stability?

- Concept: Exponential Moving Average (EMA) for area estimation
  - Why needed here: EMA smooths estimate of class areas over epochs, preventing abrupt changes that would destabilize OT plan and pseudo-label generation.
  - Quick check question: How does EMA balance between using current batch's statistics and long-term estimate?

- Concept: Vision Transformer patch embedding and classification token
  - Why needed here: ViT splits images into patches, encodes them into feature vectors, uses classification token to predict image-level labels, enabling patch-level semantic segmentation.
  - Quick check question: How does patch size in ViT affect granularity of segmentation predictions?

## Architecture Onboarding

- Component map: ViT backbone -> Dense projection layer -> Optimal Transport solver -> EMA updater -> Match-loss + MCE loss
- Critical path: ViT backbone → feature projection → OT computation → match-loss → backprop → EMA update
- Design tradeoffs:
  - OT regularization ε: too high → uniform coupling; too low → unstable convergence
  - EMA momentum γ: too high → slow adaptation; too low → noisy estimates
  - Patch size in ViT: smaller → finer masks but higher memory; larger → coarser but efficient
- Failure signatures:
  - mIoU stalls early → check OT cost matrices and regularization
  - Class imbalance in predictions → inspect α updates and EMA
  - Segmentation masks noisy → verify patch embedding quality and projection layer
- First 3 experiments:
  1. Remove OT step (set Qℓ = Pℓ, Qg = Pg) and observe mIoU drop to confirm its contribution
  2. Freeze α (no EMA update) to measure impact of area adaptation
  3. Train with only global branch to isolate effect of dual-view augmentation
