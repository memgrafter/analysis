# Bootstrapping Parallel Anchors for Relative Representations

## Quick Facts
- arXiv ID: 2303.00721
- Source URL: https://arxiv.org/abs/2303.00721
- Reference count: 33
- Primary result: Achieves cross-lingual zero-shot learning with ~10x fewer anchors (15 seeds vs 300 ground truth)

## Executive Summary
This paper introduces a method to discover parallel anchors between domains using only a small set of known seed anchors, enabling relative representation alignment without requiring full supervision. The approach optimizes an initial approximation of anchor embeddings in the target domain to align their relative representations with the source domain. By representing samples through latent similarities with respect to anchor points rather than absolute positions, the method achieves significant reduction in required anchors while maintaining competitive performance on cross-lingual zero-shot learning tasks.

## Method Summary
The method discovers parallel anchors between domains by iteratively optimizing target domain anchor embeddings to minimize the mean squared error between relative representations across domains. Starting from a small set of seed anchors, the approach uses Sinkhorn algorithm to estimate correspondence between relative representation spaces and updates the target anchors through gradient descent under unit norm constraints. This bootstrapping process enables tasks like cross-lingual zero-shot learning with approximately 10x fewer required anchors compared to using all ground truth anchors.

## Key Results
- Achieves performance close to using all ground truth anchors while relying only on 15 seeds instead of 300
- Enables zero-shot predictions in cross-lingual text classification with competitive accuracy
- Demonstrates significant reduction in required supervision for cross-domain alignment tasks

## Why This Works (Mechanism)

### Mechanism 1
The optimization process discovers parallel anchors by minimizing the MSE between relative representations across domains. The method iteratively optimizes an initial approximation of anchor embeddings in the target domain to align their relative representations with the source domain, using Sinkhorn algorithm to estimate correspondence at each step. This works because the relative representation space is smooth enough that small perturbations in anchor embeddings lead to predictable changes in relative representations.

### Mechanism 2
Using relative representations instead of absolute embeddings reduces the dimensionality and complexity of the alignment problem. By representing each sample through similarities with respect to anchor points, the method transforms the absolute reference frame to a relative coordinate system, making alignment across domains more tractable. This preserves semantic information while being more comparable across domains than absolute embeddings.

### Mechanism 3
Unit norm constraint on optimized anchors ensures stability and meaningful cosine similarity comparisons. By constraining all anchor vectors to have unit norm throughout optimization, the method maintains consistent scale across domains and ensures cosine similarity remains valid. This not only ensures the effectiveness of the optimization but also reduces the search space.

## Architecture Onboarding

- Component map: Input embeddings -> Relative representation computation -> Sinkhorn correspondence estimation -> MSE loss computation -> Anchor optimization loop -> Discovered anchors

- Critical path: 
  1. Initialize approximate target anchors with seeds + random vectors
  2. Compute relative representations for both domains
  3. Estimate correspondence with Sinkhorn
  4. Compute MSE loss between aligned representations
  5. Update target anchors with gradient descent under unit norm constraint
  6. Repeat until convergence

- Design tradeoffs:
  - Number of optimization steps vs. convergence quality
  - Number of seeds vs. accuracy of discovered anchors
  - Random initialization vs. informed initialization strategies
  - MSE loss vs. alternative alignment objectives

- Failure signatures:
  - Slow convergence or oscillation in anchor values
  - MSE plateauing at high value indicating poor alignment
  - Discovered anchors showing low similarity to true parallel anchors
  - Performance degradation when using discovered anchors in downstream tasks

- First 3 experiments:
  1. Validate that with all ground truth anchors (GT), the method achieves near-perfect alignment
  2. Test with only seeds (no optimization) to establish baseline performance degradation
  3. Run full optimization pipeline with 15 seeds and verify discovered anchors achieve performance close to GT

## Limitations
- The method's performance heavily depends on the quality and representativeness of initial seed anchors
- Assumes relative representations across domains are sufficiently smooth for reliable optimization convergence
- Does not provide comprehensive analysis of computational complexity or scalability with larger datasets

## Confidence

**High confidence**: The core optimization framework and mathematical formulation are well-specified and reproducible

**Medium confidence**: The claim of ~10x reduction in required anchors is supported by experiments but may vary with different domain pairs

**Medium confidence**: The effectiveness of relative representations for cross-domain alignment is demonstrated but not extensively validated across diverse domains
