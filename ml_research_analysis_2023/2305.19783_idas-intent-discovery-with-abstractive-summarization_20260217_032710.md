# IDAS: Intent Discovery with Abstractive Summarization

## Quick Facts
- arXiv ID: 2305.19783
- Source URL: https://arxiv.org/abs/2305.19783
- Reference count: 18
- Key outcome: IDAS outperforms state-of-the-art unsupervised methods on Banking (+7.42% ARI), StackOverflow (+3.34% ACC), and Transport datasets, and surpasses semi-supervised methods on CLINC without using labeled data

## Executive Summary
Intent discovery aims to infer latent intents from unlabeled conversational utterances, a crucial step for creating new conversational agents. Prior methods rely on unsupervised encoders to map utterances to vectors for clustering, but noisy features like syntax may affect similarity. IDAS proposes a novel approach using abstractive summarization to generate concise labels that retain core intent elements while removing non-essential information. By leveraging an LLM to generate labels for prototypical utterances and In-Context Learning for non-prototypical utterances, IDAS significantly outperforms existing unsupervised methods across multiple datasets.

## Method Summary
IDAS uses an LLM to generate abstractive summaries (labels) of utterances to retain core intent elements while removing non-essential information. The method identifies prototypical utterances through K-means clustering, generates labels for these prototypes using the LLM, then uses In-Context Learning to generate labels for non-prototypical utterances by retrieving similar labeled utterances as demonstrations. Utterances and their labels are encoded by a frozen pre-trained encoder and averaged into a single vector representation, followed by K-means clustering to recover latent intents.

## Key Results
- Outperforms state-of-the-art unsupervised methods on Banking (+7.42% ARI), StackOverflow (+3.34% ACC), and Transport datasets
- Surpasses two semi-supervised methods on CLINC benchmark without using any labeled data
- Demonstrates effectiveness of abstractive summarization for intent discovery

## Why This Works (Mechanism)

### Mechanism 1
Abstractive summarization removes noisy syntactic and lexical features that are unrelated to the underlying intent, thereby improving cluster quality. Utterances are transformed into short, descriptive labels by an LLM, preserving only the core intent elements while stripping away irrelevant details such as syntax, n-grams, or non-intent related nouns. Core assumption: The similarity between utterances in the textual space is more reflective of their true intent relationship when represented by core semantic elements rather than raw text.

### Mechanism 2
In-Context Learning (ICL) with KATE's nearest-neighbor demonstration retrieval enables effective label generation without manual annotations. For non-prototypical utterances, the model retrieves the n most similar utterances with already generated labels and uses them as demonstrations in an ICL prompt to generate a label for the target utterance. Core assumption: Utterances with similar vector representations are likely to share the same intent, making them effective demonstrations for ICL.

### Mechanism 3
Averaging utterance and label encodings into a single vector representation, followed by non-parametric smoothing, enhances the separation of different intents in the embedding space. Utterances and their generated labels are encoded separately using a frozen pre-trained encoder, then averaged. Further smoothing is applied by averaging the encodings of the n' nearest neighbors, including the utterance itself. Core assumption: The combined representation captures both the original utterance's meaning and the distilled intent, while smoothing suppresses utterance-specific noise and enhances intent-related features.

## Architecture Onboarding

- Component map: Input utterances -> K-means prototype selection -> LLM label generation -> ICL label generation -> Frozen encoder encoding -> Smoothing -> Final K-means clustering
- Critical path: 1) Initial clustering to select prototypes 2) LLM label generation for prototypes 3) ICL label generation for non-prototypes 4) Encoding and smoothing of utterance-label pairs 5) Final K-means clustering to infer intents
- Design tradeoffs: Using frozen pre-trained encoder vs. training new one (pros: avoids training, leverages general language understanding; cons: may not capture domain-specific nuances); Abstractive summarization vs. extractive methods (pros: removes noise, focuses on core intent; cons: relies on LLM quality, may introduce ambiguity); Number of ICL demonstrations (pros: more demonstrations provide better context; cons: computational cost, potential for noisy demonstrations)
- Failure signatures: Poor cluster quality (issues with label generation, encoding, or smoothing); High variance in generated labels within a cluster (issues with similarity function or LLM generalization); Inability to distinguish between intents (overly general summarization or insensitive encoder)
- First 3 experiments: 1) Ablation study on encoding strategies (only utterances, only labels, combined averaged) 2) Ablation study on number of ICL demonstrations 3) Qualitative analysis of generated labels

## Open Questions the Paper Calls Out

### Open Question 1
How does IDAS handle cases where the LLM generates overly general labels that could apply to multiple intents? The paper identifies this as a limitation but does not propose a solution or quantify its impact on clustering performance.

### Open Question 2
How robust is IDAS to variations in the order of utterances when generating labels? While the paper addresses this by shuffling utterances, it does not quantify the impact of utterance order on final clustering performance.

### Open Question 3
How does IDAS perform when the number of latent intents is unknown or incorrectly estimated? The paper assumes a known number of intents for K-means clustering but does not explore scenarios where this number is unknown or incorrectly estimated.

## Limitations
- Performance heavily depends on LLM quality for label generation with no ablation study on different LLM models
- Fixed K assumption (ground truth intent count) limits applicability to truly unsupervised scenarios
- No evaluation of robustness to noisy or out-of-distribution utterances
- Limited analysis of computational costs for ICL demonstrations

## Confidence
High confidence in core claims about architectural approach and demonstrated performance improvements. Medium confidence in mechanisms explaining why IDAS works better than alternatives. Low confidence in generalizability claims beyond evaluated datasets.
