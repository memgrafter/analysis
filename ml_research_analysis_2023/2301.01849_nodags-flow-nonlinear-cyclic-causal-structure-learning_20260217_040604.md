# NODAGS-Flow: Nonlinear Cyclic Causal Structure Learning

## Quick Facts
- arXiv ID: 2301.01849
- Source URL: https://arxiv.org/abs/2301.01849
- Reference count: 12
- Primary result: Learns nonlinear cyclic causal structures from interventional data using residual normalizing flows

## Executive Summary
NODAGS-Flow addresses the challenge of learning nonlinear cyclic causal structures from interventional data by modeling the steady state of discrete dynamical systems. The method employs residual normalizing flows to ensure invertibility and tractable Jacobian determinant computation through contractive flows. It handles both observational and interventional data with Gumbel-Softmax parameterization for sparse dependency structures. On synthetic interventional datasets, NODAGS-Flow achieves SHD values of 3.9 on nonlinear cyclic graphs compared to 4.8 for LLC, while on real-world Perturb-CITE-seq data it achieves I-NLL of 14.3 versus 19.8 for LLC.

## Method Summary
NODAGS-Flow uses residual normalizing flows to model the steady state of discrete dynamical systems, ensuring invertibility and tractable Jacobian computation through contractive residual flows. The approach employs Gumbel-Softmax parameterization to learn sparse dependency structures, enabling both observational and interventional data handling. The method is specifically designed to capture feedback loops and cyclic structures that traditional acyclic causal learning methods miss.

## Key Results
- On nonlinear cyclic graphs: SHD of 3.9 (NODAGS-Flow) vs 4.8 (LLC)
- On real-world Perturb-CITE-seq co-culture data: I-NLL of 14.3 (NODAGS-Flow) vs 19.8 (LLC)
- Enables learning of feedback loops in gene regulatory networks

## Why This Works (Mechanism)
NODAGS-Flow leverages residual normalizing flows to model the steady-state distribution of cyclic causal systems, which naturally captures feedback loops through its invertible transformations. The contractive property of residual flows ensures numerical stability and tractable Jacobian computation, critical for likelihood-based learning. Gumbel-Softmax parameterization enables differentiable sampling of discrete causal structures, allowing gradient-based optimization of the sparse dependency graph.

## Architecture Onboarding

Component Map:
Data Input -> Residual Flow Model -> Gumbel-Softmax Structure Sampling -> Loss Computation -> Gradient Update -> Causal Structure Output

Critical Path:
Observation/Intervention Data → Residual Flow Forward Pass → Structure Parameter Update → Jacobian Determinant Computation → Likelihood Evaluation → Structure Optimization

Design Tradeoffs:
- Residual flows provide invertibility but increase computational cost versus standard flows
- Gumbel-Softmax enables gradient-based optimization but introduces approximation error versus discrete sampling
- Contractive constraints ensure stability but may limit model expressiveness

Failure Signatures:
- Poor edge recovery indicates insufficient flow capacity or inappropriate Gumbel-Softmax temperature
- Unstable training suggests violation of contractive flow constraints
- Local optima trapping indicates need for better initialization or regularization

First Experiments:
1. Validate basic invertibility and Jacobian computation on synthetic acyclic data
2. Test structure recovery on known small cyclic graphs with ground truth
3. Benchmark predictive performance on simple interventional datasets
