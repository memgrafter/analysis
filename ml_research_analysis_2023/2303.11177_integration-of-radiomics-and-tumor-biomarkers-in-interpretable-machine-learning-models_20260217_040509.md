# Integration of Radiomics and Tumor Biomarkers in Interpretable Machine Learning Models

## Quick Facts
- arXiv ID: 2303.11177
- Source URL: https://arxiv.org/abs/2303.11177
- Reference count: 7
- Proposed interpretable ML model for lung nodule malignancy classification by integrating CBM-derived biomarkers with expert-derived radiomics features

## Executive Summary
This paper introduces ConRad, an interpretable machine learning framework for lung nodule malignancy classification that integrates concept bottleneck models (CBM) to predict tumor biomarkers with traditional radiomics features. The model is evaluated on the LIDC-IDRI dataset using five different classifiers, with non-linear SVMs and Lasso-regularized logistic regression achieving the best performance. The approach demonstrates that combining CBM-derived biomarkers with radiomics features can maintain accuracy while improving interpretability compared to end-to-end CNN models.

## Method Summary
The ConRad model uses concept bottleneck models to predict tumor biomarkers from lung nodule images, which are then combined with expert-derived radiomic features. These combined features are fed into five different classifiers: linear SVM, non-linear SVM, logistic regression, Lasso-regularized logistic regression, and random forest. The model is evaluated on the LIDC-IDRI dataset, comparing performance against end-to-end CNN approaches while emphasizing interpretability through feature selection and reduction.

## Key Results
- ConRad model outperforms end-to-end CNN models in interpretability while maintaining comparable accuracy
- Non-linear SVM and logistic regression with Lasso regularization achieve best performance metrics
- Lasso regularization reduces feature count while preserving accuracy, enhancing interpretability
- CBM-derived biomarkers combined with radiomic features provide effective classification framework

## Why This Works (Mechanism)
The integration of CBM-derived biomarkers with radiomic features creates a multi-layered representation that captures both abstract biological concepts and quantitative imaging patterns. This approach leverages the interpretability of CBM models to provide meaningful biological insights while maintaining the predictive power of radiomics features, resulting in a model that is both accurate and explainable.

## Architecture Onboarding

Component Map:
CBM biomarker predictor -> Radiomic feature extractor -> Feature combiner -> Classifier (SVM/LogReg/Random Forest)

Critical Path:
CBM biomarker prediction → Feature combination → Classification → Interpretability assessment

Design Tradeoffs:
- Accuracy vs interpretability: CBM provides explainability but may reduce raw predictive power
- Feature complexity: Combining CBM biomarkers with radiomics increases dimensionality but improves representation
- Model selection: Multiple classifiers evaluated to balance performance and interpretability

Failure Signatures:
- Poor CBM biomarker predictions leading to inaccurate feature combinations
- Overfitting due to high-dimensional feature space
- Loss of interpretability when using complex non-linear classifiers
