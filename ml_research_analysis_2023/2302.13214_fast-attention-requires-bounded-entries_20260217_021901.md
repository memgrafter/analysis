# Fast Attention Requires Bounded Entries

## Quick Facts
- arXiv ID: 2302.13214
- Source URL: https://arxiv.org/abs/2302.13214
- Reference count: 7
- One-line primary result: Attention computation is fast when input entries are small (B = o(√log n)) but provably hard when inputs are large (B = Θ(√log n)) under SETH

## Executive Summary
This paper investigates the computational complexity of attention matrix computation in large language models. The attention matrix A is computed as the entry-wise exponential of the scaled inner product between query and key matrices. The authors establish a sharp threshold: when input entries are bounded by B = o(√log n), there exists an n^{1+o(1)} time algorithm using polynomial approximations; when B = Θ(√log n), assuming the Strong Exponential Time Hypothesis, no truly subquadratic time algorithm exists.

The key technique uses low-degree polynomial approximations of the exponential function to construct a low-rank approximation of the attention matrix, avoiding explicit computation of the full n×n matrix. This approach adapts polynomial methods from kernel density estimation literature to the attention computation setting. Lower bounds are proven via fine-grained reductions from approximate nearest neighbor search.

## Method Summary
The method uses polynomial approximations of the exponential function to compute attention matrices implicitly without forming the full n×n matrix. When input matrices Q, K, V ∈ [-B,B]^{n×d} with d = O(log n) have bounded entries (B = o(√log n)), the algorithm computes a low-degree polynomial P that approximates exp(x) for x ∈ [0,B]. This polynomial is applied to QK⊤/d to get an approximate attention matrix, which is then factored into a low-rank form U1U⊤2. The final attention output is computed using this factorization combined with diagonal normalization. The error is controlled through careful analysis showing that polynomial approximation error propagates but remains bounded within acceptable limits.

## Key Results
- There exists an n^{1+o(1)} time algorithm to approximate attention matrices when B = o(√log n)
- Under SETH, no truly subquadratic time algorithm exists when B = Θ(√log n)
- A sharp threshold exists at B = Θ(√log n) separating tractable from intractable regimes
- The polynomial approximation technique enables implicit computation without forming the full n×n attention matrix

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Fast attention algorithms are possible when input entries are small (B = o(√log n)) by using polynomial approximations of the exponential function.
- Mechanism: The attention matrix A = exp(QK⊤/d) is approximated by a low-degree polynomial P applied to QK⊤/d. This polynomial can be factored into a low-rank form U1U⊤2, avoiding explicit computation of the full n×n matrix.
- Core assumption: The exponential function can be well-approximated by low-degree polynomials when inputs are bounded by B = o(√log n).
- Evidence anchors:
  - [abstract]: "If d = O(log n) and B = o(√log n), there is an n^{1+o(1)} time algorithm to approximate Att(Q,K,V) up to 1/poly(n) additive error."
  - [section]: "Lemma 2.1 ([AA22]). Let B > 1 and let ǫ∈ (0,0.1). There is a polynomial P : R→ R of degree g := Θ(max{log(1/ǫ)/log(log(1/ǫ)/B), B}) such that for all x∈ [0, B], we have |P(x)−exp(x)|< ǫ."
- Break condition: If B grows to Θ(√log n) or larger, the required polynomial degree becomes too high for subquadratic time algorithms.

### Mechanism 2
- Claim: Attention computation is provably hard when input entries are large (B = Θ(√log n)) under the Strong Exponential Time Hypothesis.
- Mechanism: A reduction from approximate nearest neighbor search to attention computation shows that solving attention quickly would enable solving ANN too fast, contradicting SETH.
- Core assumption: SETH holds, which states that k-SAT cannot be solved in O(2^{(1-ε)n}) time for any ε > 0.
- Evidence anchors:
  - [abstract]: "If d = O(log n) and B = Θ(√log n), assuming the Strong Exponential Time Hypothesis from fine-grained complexity theory, it is impossible to approximate Att(Q,K,V) up to 1/poly(n) additive error in truly subquadratic time n^{2−Ω(1)}."
  - [section]: "Lemma 4.3 ([Rub18]). Assuming SETH, for every q > 0, there are ǫ∈ (0,1) and C > 0 such that (1+ǫ)-Approximate Hamming Nearest Neighbor Search in dimension d = C log n requires Ω(n^{2−q}) time."
- Break condition: If SETH is false or if we relax the error guarantees beyond 1/poly(n), faster algorithms might become possible.

### Mechanism 3
- Claim: Error propagation through the attention computation pipeline is controlled by bounding errors at each stage.
- Mechanism: The polynomial approximation error in A is controlled by choosing appropriate polynomial degree. This error propagates through the diagonal normalization matrix D and the final attention computation, but remains bounded due to the structure of the problem.
- Core assumption: The error introduced at each computational step can be bounded and does not compound to exceed the desired accuracy.
- Evidence anchors:
  - [section]: "Lemma 3.5. Let A∈ R^{n×n} be any matrix whose entires are all positive and ǫ_A∈ (0,0.1) be any parameter. Let ˜A∈ R^{n×n} be any matrix such that, for all (i,j)∈ [n]×[n], we have |˜A_{i,j}−A_{i,j}|≤ ǫ_A·A_{i,j}. Define the matrices D, ˜D∈ R^{n×n} by D = diag(A1_n) and ˜D = diag(˜A1_n). Then, for all i∈ [n] we have |˜D_{i,i}−D_{i,i}|≤ ǫ_A·D_{i,i}."
  - [section]: "Lemma 3.6. Let ǫ_A, ǫ_D∈ (0,0.1) and B > 1 be parameters, and let V∈ R^{n×d} denote a matrix with∥V∥∞ ≤ B. ... Then, we have ∥˜D^{−1}˜AV−D^{−1}AV∥∞ ≤ (ǫ_A + ǫ_D)·B."
- Break condition: If the input bound B grows too large or if the required accuracy ǫ becomes too stringent, error bounds may exceed acceptable limits.

## Architecture Onboarding

- Component map: Input matrices Q, K, V -> Polynomial approximation module -> Low-rank factorization engine -> Error control system -> Output assembly

- Critical path:
  1. Compute polynomial approximation parameters (degree g based on B and desired accuracy)
  2. Apply polynomial to QK⊤/d to get approximate attention matrix
  3. Factor into low-rank form U1U⊤2
  4. Compute diagonal normalization matrix D
  5. Multiply D^{-1} with U1U⊤2V to get final result

- Design tradeoffs:
  - Accuracy vs. speed: Higher accuracy requires higher polynomial degree, increasing computation time
  - Memory vs. computation: Low-rank factorization saves memory but requires additional computation for factorization
  - Input scaling: Larger input bounds B require higher polynomial degrees, making the algorithm slower

- Failure signatures:
  - Runtime explosion when B approaches Θ(√log n)
  - Accuracy degradation when polynomial degree is insufficient for desired error bounds
  - Memory issues when attempting to explicitly form the n×n attention matrix

- First 3 experiments:
  1. Verify polynomial approximation accuracy: Test Lemma 2.1 by approximating exp(x) for various B and ε values, measuring actual vs. theoretical error
  2. Validate low-rank factorization: Implement Lemma 3.2 and verify that P(QK⊤/d) = U1U⊤2 for test matrices
  3. Benchmark error propagation: Test Lemma 3.6 by computing attention with controlled errors at each stage and measuring final error magnitude

## Limitations
- The sharp threshold at B = Θ(√log n) may not be tight, leaving open the possibility of intermediate complexity regimes
- Theoretical results assume idealized conditions that may not hold in practical implementations
- The polynomial coefficient computation may face numerical stability issues for larger values of B
- The analysis is specific to softmax attention and may not extend to alternative attention mechanisms

## Confidence
- **High Confidence**: The existence of an n^{1+o(1)} time algorithm when B = o(√log n), the lower bound showing impossibility of subquadratic algorithms when B = Θ(√log n) under SETH, the polynomial approximation technique for exponential functions with bounded inputs
- **Medium Confidence**: The sharpness of the Θ(√log n) threshold, the practical applicability of the theoretical bounds, the robustness of the results to variations in attention mechanisms
- **Low Confidence**: Specific constant factors hidden in asymptotic notation, numerical stability of polynomial coefficient computation, real-world performance compared to empirical observations
