# Multimodal Inverse Cloze Task for Knowledge-based Visual Question Answering

## Quick Facts
- arXiv ID: 2301.04366
- Source URL: https://arxiv.org/abs/2301.04366
- Reference count: 40
- Primary result: Extends ICT pre-training with multimodal context for KVQAE, improving fusion models

## Executive Summary
This paper introduces Multimodal Inverse Cloze Task (ICT) as a pre-training method for knowledge-based visual question answering about named entities (KVQAE). The approach extends traditional ICT by incorporating contextual images as pseudo-questions, enabling pre-training of complex fusion models that can effectively retrieve and comprehend knowledge from multimodal sources. The method demonstrates significant performance improvements over late fusion baselines on the ViQuAE dataset.

## Method Summary
The authors propose Multimodal ICT as a pre-training approach for KVQAE tasks. Unlike traditional ICT which uses textual contexts as pseudo-questions, Multimodal ICT incorporates visual contexts from multimodal documents to create richer pseudo-questions. This allows pre-training of fusion architectures that can better handle the interaction between visual and textual modalities. The method is evaluated using two fusion architectures - ECA (early cross-attention) and ILF (intermediate linear fusion) - showing substantial improvements in both retrieval and reading comprehension tasks.

## Key Results
- Pre-trained models with Multimodal ICT outperform late fusion baselines by 9% relative MRR in retrieval
- Reading comprehension performance improves by 15% relative F1 score
- Qualitative analysis shows models learn meaningful cross-modal interactions between question images and knowledge base text

## Why This Works (Mechanism)
Multimodal ICT works by leveraging contextual images as additional pseudo-questions during pre-training, which forces the model to learn rich cross-modal representations. This is particularly effective for KVQAE because real-world knowledge often involves both visual and textual information about entities. By exposing the model to these multimodal contexts during pre-training, it develops stronger fusion capabilities that transfer to downstream tasks.
