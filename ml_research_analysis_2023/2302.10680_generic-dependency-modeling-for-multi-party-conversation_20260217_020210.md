# Generic Dependency Modeling for Multi-Party Conversation

## Quick Facts
- arXiv ID: 2302.10680
- Source URL: https://arxiv.org/abs/2302.10680
- Reference count: 0
- Primary result: ReDE achieves 72.40 F1 score on Molweni-MRC, surpassing previous SOTA of 72.20

## Executive Summary
This paper introduces a simple yet effective framework for modeling utterance dependencies in multi-party conversations using relative dependency encoding (ReDE). The core innovation encodes the relative distance between utterances as a bias term in Transformer self-attention computations. The approach is implemented through a dependency-based bias term added to attention scores, which is then integrated into pre-trained models like RoBERTa and BART. Experiments across four benchmarks demonstrate consistent performance improvements, with ReDE achieving state-of-the-art results on Molweni-MRC while showing comparable or superior performance on emotion detection, relation extraction, and abstractive summarization tasks.

## Method Summary
The proposed framework introduces relative dependency encoding (ReDE) that models conversational dependencies by encoding the relative distance between utterances as a bias term in Transformer self-attention. Specifically, for each utterance pair, the framework calculates a dependency distance and incorporates this information as an additive bias to the attention scores during computation. This bias term is learned during training and allows the model to attend differently based on conversational structure rather than just content similarity. The approach is model-agnostic and can be integrated into existing pre-trained architectures like RoBERTa and BART through fine-tuning. The relative distance is computed based on utterance positions in the conversation, with the assumption that utterances closer together are more likely to be dependent on each other.

## Key Results
- ReDE achieves 72.40 F1 score on Molweni-MRC, surpassing previous SOTA of 72.20
- Consistent performance improvements across all four benchmark tasks
- The framework works effectively with both RoBERTa and BART base models
- Ablation studies confirm the importance of relative dependency encoding for multi-party conversations

## Why This Works (Mechanism)
The framework works by explicitly encoding conversational structure through relative utterance distances, allowing Transformers to attend to contextually relevant utterances based on their position in the conversation flow. By adding this dependency information as a bias term to attention scores, the model can differentiate between utterances that are conversationally related versus those that are merely temporally close. This addresses a key limitation of standard self-attention, which treats all pairwise relationships equally regardless of conversational context. The relative distance encoding effectively guides the attention mechanism to focus on utterances that are more likely to be conversationally dependent, improving the model's ability to capture multi-party conversation dynamics.

## Architecture Onboarding

**Component Map**
Pre-trained Model (RoBERTa/BART) -> Relative Dependency Encoder -> Attention Computation -> Output Layer

**Critical Path**
Input utterances → Position encoding → Relative distance calculation → Bias term computation → Modified attention scores → Contextual representations → Task-specific output

**Design Tradeoffs**
The framework trades increased model complexity (additional parameters for bias terms) for improved conversational understanding. The relative distance calculation assumes linear conversation flow, which may not capture all dependency patterns but keeps the approach computationally efficient and generalizable.

**Failure Signatures**
Potential failure modes include incorrect relative distance calculations for non-linear conversation structures, over-reliance on positional information at the expense of semantic content, and difficulty handling interruptions or overlapping speech turns common in multi-party conversations.

## Limitations
- Assumes linear utterance order is sufficient for capturing conversational structure, potentially missing complex dependency patterns
- Evaluation focuses on single-turn reference modeling, leaving questions about longer-term context tracking
- Dataset diversity could be expanded to include more varied conversation types and domains

## Confidence
High confidence in core technical contribution (relative dependency encoding mechanism) and reproducibility of results. Medium confidence in generalizability claims due to limited conversation type diversity in evaluation.
