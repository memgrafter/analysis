# DOMINO: Domain-aware Loss for Deep Learning Calibration

## Quick Facts
- arXiv ID: 2302.05142
- Source URL: https://arxiv.org/abs/2302.05142
- Reference count: 0
- Primary result: DOMINO improves calibration of deep learning models in medical imaging by incorporating class-wise penalties based on similarity

## Executive Summary
This paper introduces DOMINO, a domain-aware loss function designed to improve calibration of deep learning models in medical imaging. DOMINO incorporates class-wise penalties based on similarity within target domains, reducing risky errors even when predictions are incorrect. The method was tested on MEDNIST classification using cross-entropy, DOMINO-HC, and DOMINO-CM, yielding accuracies of 99.47%, 99.54%, and 99.56% respectively. Brier Score Loss results showed DOMINO-CM consistently outperformed standard cross-entropy across multiple classes (e.g., 0.00183 vs 0.00219 for Abdomen CT), indicating improved calibration.

## Method Summary
DOMINO is a domain-aware loss function that computes penalties for incorrect classifications based on class-wise similarities. It's implemented as a regularization term added to existing loss functions like cross-entropy or dice loss. The method uses a parameter β (0-1) to balance the base loss with the DOMINO regularization term. Two variants are presented: DOMINO-HC (hierarchical class method) which requires manual creation of task groups, and DOMINO-CM (confusion matrix method) which automatically computes class similarities from training data.

## Key Results
- Accuracy improvements: 99.47% (cross-entropy) → 99.54% (DOMINO-HC) → 99.56% (DOMINO-CM) on MEDNIST
- Brier Score Loss consistently improved with DOMINO-CM across all classes (e.g., 0.00183 vs 0.00219 for Abdomen CT)
- DOMINO effectively reduced risky errors by assigning lower penalties to confusion between safer class pairs
- The method is particularly valuable in high-risk applications where distinguishing between classes carries different levels of risk

## Why This Works (Mechanism)

### Mechanism 1
- Claim: DOMINO improves calibration by applying class-wise penalties based on similarity within target domains.
- Mechanism: The loss function adds a regularization term W to the base loss, where W is a matrix of penalties for confusing classes. Similar classes receive lower penalties, while dissimilar classes receive higher penalties.
- Core assumption: Class similarity information can be meaningfully captured in a matrix and used to guide the learning process.
- Evidence anchors:
  - [abstract] "The proposed loss function applies a class-wise penalty based on the similarity between classes within a given target domain."
  - [section] "The DOMINO loss function that computes penalties for incorrect classifications based on class-wise similarities."

### Mechanism 2
- Claim: DOMINO reduces risky errors by assigning lower penalties to confusion between safer class pairs.
- Mechanism: The W matrix is constructed such that penalties are asymmetric - lower for class pairs that are safer to confuse, higher for dangerous confusions.
- Core assumption: The risk of confusing different classes is not uniform and can be encoded in the penalty matrix.
- Evidence anchors:
  - [section] "In this way, DOMINO loss allows a model to make safer and more meaningful mistakes when wrong."
  - [section] "DOMINO would assign lower penalties for confusing pedestrian and bicycle rider, whereas it assigns a maximal penalty for confusing either of these classes with the stop sign."

### Mechanism 3
- Claim: DOMINO improves both accuracy and calibration metrics across tasks.
- Mechanism: By incorporating domain knowledge through the W matrix, the model learns more true information about class representation rather than fighting class similarity.
- Core assumption: Traditional deep learning algorithms fight class similarity, whereas DOMINO leverages it.
- Evidence anchors:
  - [section] "Our prior experiments [17] show that DOMINO can improve both accuracy and calibration metrics across many classification and segmentation tasks."
  - [section] "DOMINO works by learning more true information about class representation, as opposed to traditional deep learning algorithms that fight class similarity."

## Architecture Onboarding

- Component map:
  Base loss function (cross-entropy, dice loss, etc.) -> DOMINO regularization term (W matrix) -> PyTorch framework for implementation -> CUDA GPU for optimal performance

- Critical path:
  1. Define class similarity/risk relationships
  2. Construct W matrix based on chosen method (CM or HC)
  3. Integrate DOMINO into existing loss function
  4. Train model with combined loss
  5. Evaluate calibration metrics

- Design tradeoffs:
  - DOMINO-CM: No prior knowledge needed but doubles training time
  - DOMINO-HC: Requires manual creation of task groups but potentially better performance
  - GPU vs CPU: Significant speed difference for segmentation tasks

- Failure signatures:
  - Poor calibration despite DOMINO implementation
  - Increased training time without accuracy improvement
  - W matrix construction errors leading to nonsensical penalties

- First 3 experiments:
  1. Implement DOMINO-CM on MNIST classification and compare Brier Score Loss to baseline
  2. Apply DOMINO-HC to a simple medical imaging dataset with known class relationships
  3. Test DOMINO on a segmentation task using U-Net architecture with combined cross-entropy and dice loss

## Open Questions the Paper Calls Out
The paper doesn't explicitly call out open questions, but several remain unresolved based on the presented work, including how DOMINO performs across diverse medical imaging datasets, the theoretical relationship between DOMINO's weighting scheme and uncertainty quantification, and how the method scales to extremely large-scale medical imaging datasets.

## Limitations
- Effectiveness heavily depends on accurate construction of the W matrix, which may be challenging in domains with poorly defined class relationships
- Limited validation across diverse medical imaging datasets beyond MEDNIST restricts generalizability claims
- Computational overhead from DOMINO-CM (doubling training time) may be prohibitive for large-scale applications

## Confidence

**High Confidence**: DOMINO's ability to improve calibration metrics (Brier Score Loss) compared to standard cross-entropy, as demonstrated on MEDNIST.

**Medium Confidence**: The claim that DOMINO reduces risky errors through asymmetric penalties, based on limited empirical evidence and theoretical reasoning.

**Low Confidence**: Generalization of DOMINO's effectiveness to other medical imaging tasks and datasets beyond the presented MEDNIST experiments.
