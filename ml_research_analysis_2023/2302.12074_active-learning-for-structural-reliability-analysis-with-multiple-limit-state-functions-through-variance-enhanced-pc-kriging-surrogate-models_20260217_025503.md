# Active learning for structural reliability analysis with multiple limit state functions through variance-enhanced PC-Kriging surrogate models

## Quick Facts
- arXiv ID: 2302.12074
- Source URL: https://arxiv.org/abs/2302.12074
- Reference count: 12
- This paper proposes an active learning framework using variance-corrected PC-Kriging surrogates to efficiently train models for multiple limit state functions under fixed computational budgets, achieving accurate failure and repair probability estimates.

## Executive Summary
This paper addresses the challenge of training surrogate models for structural reliability analysis when multiple limit state functions must be simultaneously captured within a fixed computational budget. The proposed approach uses active learning with PC-Kriging surrogate models enhanced by a variance correction derived from leave-one-out cross-validation. Sequential sample selection employs U-function-based metrics, with the target limit state chosen either alternately or via a convergence-based criterion that prioritizes the most inaccurate function at each step. The method is validated on both an analytical multimodal problem and a practical offshore wind substructure collision case, demonstrating superior performance in balancing accuracy across all limit states while minimizing overall prediction error.

## Method Summary
The method combines PC-Kriging surrogate models with active learning for structural reliability analysis involving multiple limit states. PC-Kriging uses polynomial chaos expansion (PCE) as a trend function within a Kriging framework. A key innovation is the variance correction derived from leave-one-out cross-validation to address potential bias in the surrogate's variance predictions. Active learning employs a U-function that balances exploitation (proximity to limit states) and exploration (prediction uncertainty), with the target limit state selected either alternately or using a convergence-based metric that identifies the most inaccurate function at each step. The framework sequentially selects experimental design points to improve the surrogate model's accuracy across all limit states within a fixed computational budget.

## Key Results
- The convergence-based target selection (Xg*) consistently outperforms simple alternating schemes, balancing accuracy across all limit states while minimizing overall prediction error
- Variance-corrected U-function scores (U-LOO) improve joint accuracy across limit states compared to raw variance (U)
- The proposed framework achieves accurate failure and repair probability estimates in both analytical and practical offshore wind substructure collision test cases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Variance-corrected U-function scores enable more precise identification of informative training points near multiple limit state boundaries.
- Mechanism: The U-function evaluates candidate samples by balancing proximity to the limit state (exploitation) and prediction uncertainty (exploration). When combined with a leave-one-out cross-validation variance correction, the predicted variance becomes more reliable, improving the ranking of candidate samples.
- Core assumption: The surrogate model's internal variance estimates are systematically biased and can be corrected via LOO-CV without excessive computational cost.
- Evidence anchors:
  - [abstract] "PC-Kriging-based surrogate models are actively trained while additionally accounting for a variance correction derived from leave-one-out cross validation error information"
  - [section] "The selection of subsequent experimental design points can thus be further improved by adequately correcting the generated variance predictions, σ̂g(x), which might be potentially biased [7]."
- Break condition: If LOO-CV error estimates are unstable or too noisy relative to prediction variance, the correction may degrade rather than improve sample selection.

### Mechanism 2
- Claim: Sequential targeting of the most inaccurate limit state (via convergence-based metric) balances budget allocation across multiple failure/repair events.
- Mechanism: At each active learning step, a convergence metric δ(β̂gj) identifies which limit state function currently has the largest relative error. The U-function is then evaluated only for that function, ensuring the next sample improves the worst-performing surrogate.
- Core assumption: Relative improvement in the target limit state's β̂ index is a reliable proxy for overall system reliability accuracy.
- Evidence anchors:
  - [abstract] "The results show that a balanced computational budget administration can be effectively achieved by successively targeting the specified multiple limit state functions within a unified active learning scheme."
  - [section] "At each active learning step, t, a convergence-related metric δ(β̂gj) inspired on the reliability index is here proposed for selecting the target limit state function."
- Break condition: If multiple limit states improve at different rates, focusing solely on the worst may under-resource others that plateau quickly.

### Mechanism 3
- Claim: Using corrected variance (U-LOO) rather than raw variance improves joint accuracy across limit states under the same budget.
- Mechanism: Raw variance from the surrogate tends to underestimate uncertainty near the limit state boundary; the LOO-CV correction inflates these estimates, leading the U-function to explore more aggressively and avoid local minima.
- Core assumption: The correction factor formula (Eq. 5) reliably scales variance to match out-of-sample error behavior.
- Evidence anchors:
  - [section] "The selection of subsequent experimental design points can thus be further improved by adequately correcting the generated variance predictions, σ̂g(x), which might be potentially biased [7]."
  - [section] "strategies resulting from U-based learning scores computed from both PCK's variance (U) and corrected variance (U-LOO) are additionally compared."
- Break condition: If the correction factor becomes too large or unstable, the exploration term dominates and the method degenerates into pure space-filling.

## Architecture Onboarding

- Component map: Experimental design → PC-Kriging surrogate (PCE + Kriging kernel) → U-function score (with optional LOO variance correction) → convergence metric δ(β̂gj) → target limit state selection → next sample acquisition
- Critical path: Sample acquisition loop: (1) Generate Monte Carlo candidates, (2) Evaluate U-function (corrected if U-LOO), (3) Select argmin, (4) Run high-fidelity simulation, (5) Update surrogate, (6) Recompute δ(β̂gj), repeat
- Design tradeoffs: (a) Correction overhead vs. improved sample selection, (b) Targeting worst limit state vs. alternating schemes, (c) Fixed budget vs. adaptive stopping
- Failure signatures: (a) Persistent bias in failure probability estimates, (b) High variance across repeated experiments, (c) Oversampling in low-importance regions
- First 3 experiments:
  1. Run U-function with raw variance on the analytical test (Section 3.1) and record β̂ error progression for both limit states.
  2. Repeat with U-LOO correction; compare error reduction and stability.
  3. Implement the convergence-based target selector (Xg* j) and verify that the most inaccurate limit state is consistently chosen each step.

- What evidence would resolve it: A comparative study reporting prediction accuracy and training time for variance-corrected PC-Kriging versus other correction schemes (e.g., plug-in, resampling-based corrections) would clarify relative performance.

## Limitations

- The methodology's performance heavily depends on the reliability of the leave-one-out variance correction, which may become unstable for small sample sizes or highly correlated inputs
- Computational overhead from repeated LOO-CV variance corrections increases with sample size, potentially limiting scalability for problems requiring hundreds of iterations
- The analytical test case uses only two limit states with simple input distributions, and real-world applications may exhibit more complex interactions requiring additional validation

## Confidence

- **High confidence** in the general framework of active learning with variance-corrected PC-Kriging for multiple limit states, supported by consistent performance across both test cases
- **Medium confidence** in the specific convergence-based target selection strategy, as it shows superiority over alternatives but relies on the assumption that worst-limit-state improvement correlates with overall accuracy
- **Medium confidence** in the LOO variance correction mechanism, as the correction formula is well-established but its effectiveness may vary with problem characteristics and sample size
