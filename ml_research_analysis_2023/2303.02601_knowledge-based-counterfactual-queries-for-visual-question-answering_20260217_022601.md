# Knowledge-Based Counterfactual Queries for Visual Question Answering

## Quick Facts
- arXiv ID: 2303.02601
- Source URL: https://arxiv.org/abs/2303.02601
- Reference count: 40
- This work proposes a model-agnostic method for explaining VQA model behavior through counterfactual perturbations

## Executive Summary
This paper introduces a knowledge-based approach to generate counterfactual questions for visual question answering models. The method systematically perturbs questions through word-level substitutions guided by knowledge bases like WordNet and color databases, while keeping visual inputs constant. By analyzing how VQA models respond to these counterfactuals, the authors reveal linguistic biases and robustness limitations in model behavior. The approach is tested on the ViLT model using VQA-v2 and Visual Genome datasets, demonstrating significant accuracy drops of 15-20% across various perturbation types.

## Method Summary
The method generates counterfactual questions by applying different word replacement strategies: synonyms, hypernyms, hyponyms, siblings, color perturbations, and word deletions. These replacements are guided by structured knowledge bases (WordNet for lexical relations and Google Color for color terms). The counterfactuals maintain the same visual context but alter the linguistic modality, allowing researchers to isolate and analyze model responses to specific linguistic variations. The approach extracts both local explanations (individual unexpected responses) and global rules (summarized behavioral patterns) from the model's reactions to these perturbations.

## Key Results
- VQA model accuracy drops by 15-20% or more across all perturbation experiments
- Model shows insensitivity to certain color changes in questions
- Lexical weaknesses are revealed when models encounter rare synonyms
- Clear biases emerge toward specific word concepts in model decision-making

## Why This Works (Mechanism)
The method works by exploiting the structured knowledge in WordNet to create linguistically valid but semantically distinct variations of original questions. By keeping visual inputs constant, any accuracy changes can be attributed to the linguistic modifications, revealing whether the model relies on specific word patterns rather than true visual understanding. The counterfactual generation process systematically tests the model's robustness to lexical variations while maintaining semantic coherence through knowledge-based constraints.

## Foundational Learning

**Knowledge Bases**: Structured repositories like WordNet that encode semantic relationships between words. Why needed: Provides the systematic way to generate semantically valid perturbations. Quick check: Verify that generated counterfactuals maintain grammatical correctness and semantic plausibility.

**Counterfactual Analysis**: Method of understanding model behavior by observing responses to hypothetical scenarios. Why needed: Isolates specific factors affecting model decisions. Quick check: Ensure counterfactuals differ from originals in only the targeted aspect.

**Multimodal Models**: Systems processing both visual and textual information simultaneously. Why needed: VQA models are multimodal, requiring analysis of both modalities. Quick check: Confirm perturbations affect only the text while visual inputs remain unchanged.

## Architecture Onboarding

**Component Map**: Knowledge Base -> Counterfactual Generator -> VQA Model -> Explanation Extractor

**Critical Path**: Input Question → Knowledge Base Lookup → Word Replacement → Counterfactual Question → VQA Model → Accuracy/Response Analysis → Local/ Global Explanations

**Design Tradeoffs**: 
- Linguistic-only perturbations miss visual modality failures
- Knowledge base quality directly impacts counterfactual validity
- Single model testing limits generalizability of findings

**Failure Signatures**:
- Model accuracy drops >15% indicate vulnerability to specific perturbations
- Consistent responses to semantically different questions reveal bias
- Unexpected answers to counterfactuals indicate misunderstanding of lexical variations

**First 3 Experiments**:
1. Generate synonyms for all content words in test questions and measure accuracy degradation
2. Replace object mentions with hypernyms/hyponyms and analyze response changes
3. Apply color perturbations to questions mentioning colors and measure sensitivity

## Limitations
- Focuses only on linguistic perturbations, missing visual modality failures
- Relies heavily on quality and coverage of external knowledge bases
- Limited to single VQA model (ViLT), may not generalize to other architectures

## Confidence

**Major Claims:**
- Counterfactual generation method validity: High
- Effectiveness in reducing VQA accuracy: High
- Pattern discovery through explanations: Medium
- Model behavior insights: Medium
