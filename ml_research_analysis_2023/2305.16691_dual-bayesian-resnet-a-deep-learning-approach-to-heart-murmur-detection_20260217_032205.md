# Dual Bayesian ResNet: A Deep Learning Approach to Heart Murmur Detection

## Quick Facts
- arXiv ID: 2305.16691
- Source URL: https://arxiv.org/abs/2305.16691
- Reference count: 13
- Primary result: Weighted accuracy of 0.771 on hidden test set for heart murmur detection in pediatric heart sounds

## Executive Summary
This paper presents a deep learning approach to heart murmur detection in pediatric heart sound recordings using a Dual Bayesian ResNet architecture. The method treats the ternary classification task (present, unknown, absent) as two sequential binary classifications using Monte Carlo dropout ResNet50 networks on log mel spectrograms. The approach achieved 4th place out of 40 teams in the PhysioNet Challenge 2022 with a weighted accuracy of 0.771 on the hidden test set. When integrating with patient demographic data and signal features using XGBoost, the accuracy improved to 0.820 on a held-out training subset, though weighted accuracy decreased to 0.749.

## Method Summary
The method processes 4-second overlapping audio segments from pediatric heart sound recordings, converting them to log mel spectrograms (64 coefficients, 10-2000 Hz). Two Bayesian ResNet50 networks perform binary classification: one for "present vs unknown/absent" and another for "unknown vs present/absent." Segment-level predictions are aggregated to classify each patient's recordings. The approach can be extended by integrating outputs with demographic data and signal features using XGBoost. The method was evaluated on the PhysioNet Challenge 2022 dataset containing 1568 patients with up to 6 heart sound recordings each.

## Key Results
- Achieved weighted accuracy of 0.771 on hidden test set, placing 4th out of 40 teams
- Log mel spectrograms proved effective representation, providing majority of predictive power
- Bayesian neural networks provided strong classification performance with uncertainty estimates
- XGBoost integration improved accuracy to 0.820 on training subset but decreased weighted accuracy to 0.749

## Architecture Onboarding

- Component map:
  Input: 4-second overlapping audio segments converted to log mel spectrograms (64 coefficients, 10-2000 Hz)
  Component 1: Bayesian ResNet50 for "present vs unknown/absent" classification
  Component 2: Bayesian ResNet50 for "unknown vs present/absent" classification
  Component 3: Aggregation logic that first checks "present" classification, then "unknown" if not present
  Optional Component 4: XGBoost integration with demographic data and signal features
  Output: Patient-level classification (present, unknown, absent)

- Critical path: Spectrogram generation → Present classifier → (if absent) Unknown classifier → (if absent) Absent classification → Patient aggregation

- Design tradeoffs:
  - Two binary classifiers vs single multi-class classifier: Prioritizes present detection at cost of additional computation
  - Bayesian approach vs deterministic: Provides uncertainty estimates but increases inference time
  - Spectrogram representation vs raw audio: Enables use of vision architectures but may lose temporal fine structure

- Failure signatures:
  - High false negatives for present murmurs: Check present classifier performance and aggregation logic
  - Poor performance on unknown cases: Verify unknown classifier calibration and that unknown cases are properly represented in training data
  - Degradation when adding demographic features: Investigate feature engineering quality and potential data leakage

- First 3 experiments:
  1. Train a single ResNet50 on the ternary classification task to establish baseline performance
  2. Train the two binary classifiers independently to verify they capture complementary information
  3. Test different spectrogram parameters (frequency range, number of coefficients) to optimize feature representation
