# AI-assisted coding: Experiments with GPT-4

## Quick Facts
- arXiv ID: 2304.13187
- Source URL: https://arxiv.org/abs/2304.13187
- Reference count: 40
- Primary result: GPT-4 achieves 72% success rate on coding problems with minimal prompting

## Executive Summary
This paper presents a series of experiments exploring GPT-4's capabilities in code generation, refactoring, and testing. The authors conducted three main experiments: interactive coding problem solving, code quality improvement through refactoring, and automated test generation. GPT-4 demonstrated strong performance in solving coding problems (72% success rate) and significantly improved code quality metrics, reducing flake8 warnings by 63%. However, the model's test generation capability showed promise with 94% coverage but suffered from high failure rates of 55%. The results highlight GPT-4's potential as an AI-assisted coding tool while emphasizing the continued need for human oversight to ensure code validity and accuracy.

## Method Summary
The authors conducted three experiments to evaluate GPT-4's coding capabilities. First, they tested GPT-4's problem-solving ability using interactive coding tasks with minimal prompting, achieving a 72% success rate. Second, they assessed code refactoring capabilities by measuring improvements in code quality metrics, specifically focusing on flake8 warning reduction, which showed a 63% improvement with a Cohen's d effect size of 0.50. Third, they evaluated test generation by having GPT-4 create tests for its own code, resulting in 94% file coverage but with a concerning 55% test failure rate. The experiments used standard programming problems and code quality metrics to provide quantitative assessments of GPT-4's performance.

## Key Results
- GPT-4 successfully solves coding problems in 72% of cases with minimal prompting
- Code refactoring improves quality metrics, reducing flake8 warnings by 63% (Cohen's d=0.50)
- Test generation achieves 94% coverage but suffers from 55% failure rate

## Why This Works (Mechanism)
GPT-4's success in coding tasks stems from its transformer-based architecture trained on diverse code repositories, enabling pattern recognition and code synthesis. The model leverages its understanding of programming syntax, logic structures, and common coding patterns to generate functional solutions. For refactoring, GPT-4 applies learned best practices and code optimization techniques to improve existing code. In test generation, it uses its knowledge of testing frameworks and common edge cases to create comprehensive test suites, though quality control remains challenging.

## Limitations
- Limited information on problem complexity and variety affects generalizability of 72% success rate
- Quality improvements focus on superficial metrics without addressing functional correctness
- High test failure rate (55%) raises concerns about test reliability and validity

## Confidence
- Basic problem-solving: High (72% success rate)
- Code quality improvements: Medium (63% reduction in flake8 warnings, Cohen's d=0.50)
- Test generation: Low (55% failure rate)
