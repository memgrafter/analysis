# CRL+: A Novel Semi-Supervised Deep Active Contrastive Representation Learning-Based Text Classification Model for Insurance Data

## Quick Facts
- arXiv ID: 2302.04343
- Source URL: https://arxiv.org/abs/2302.04343
- Reference count: 40
- Achieves 95.68% accuracy, 95.25% precision, 95.68% recall, and 95.46% F-measure on obituary dataset

## Executive Summary
CRL+ is a novel semi-supervised text classification model that combines supervised contrastive representation learning (CRL) with active learning to improve performance on unstructured obituary data for cause of death prediction. The model leverages RoBERTa transformer architecture with a supervised contrastive loss function to learn discriminative representations, then employs an active learning loop to iteratively select the most informative samples for expert labeling. This approach addresses the challenge of limited labeled data in insurance applications while achieving state-of-the-art performance on the cause of death classification task.

## Method Summary
CRL+ integrates supervised contrastive learning with active learning by first pre-training a RoBERTa transformer using supervised contrastive loss on available labeled data, then applying the model to unlabeled data to select high-confidence predictions for expert labeling. The labeled dataset is iteratively expanded through the active learning loop, with the model being retrained after each iteration until performance thresholds are met or labeling budgets are exhausted.

## Key Results
- Achieves 95.68% accuracy on obituary dataset for cause of death classification
- Outperforms both standalone contrastive representation learning and active learning approaches
- Demonstrates effective handling of semi-supervised learning with limited labeled data

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Supervised contrastive learning improves representation quality by pulling together samples with same label and pushing apart samples with different labels
- Core assumption: Labels are available for at least a subset of training data
- Evidence: SupCon loss computed using positive pairs (same label) and negative pairs (different label)
- Break condition: If labeled data is too small or noisy

### Mechanism 2
- Claim: Active learning reduces labeling effort by iteratively selecting most informative samples
- Core assumption: Model can estimate uncertainty reliably and most uncertain samples are most informative
- Evidence: Model trained on labeled data, applied to unlabeled data, high-uncertainty samples selected for expert labeling
- Break condition: If uncertainty estimates are poor or labeling budget exhausted

### Mechanism 3
- Claim: Combining supervised contrastive learning with active learning leverages strengths of both methods
- Core assumption: Combination is synergistic and leads to better performance than either method individually
- Evidence: Supervised contrastive learning provides strong initialization while active learning focuses labeling effort
- Break condition: If combination introduces conflicting objectives or model becomes too complex

## Architecture Onboarding

- **Component map**: RoBERTa transformer encoder -> Supervised contrastive learning module -> Classification layer -> Active learning loop
- **Critical path**: Pre-train RoBERTa with supervised contrastive learning on labeled data -> Apply model to unlabeled data and select high-uncertainty samples -> Expert labels selected samples -> Add labeled samples to training set -> Repeat until performance threshold met or labeling budget exhausted
- **Design tradeoffs**: Number of labeled samples vs. model performance, number of active learning iterations vs. labeling budget, model complexity vs. training time
- **Failure signatures**: Poor performance (insufficient labeled data, noisy labels, model issues), slow convergence (suboptimal hyperparameters, inefficient active learning), high uncertainty (ambiguous samples requiring expert review)
- **First 3 experiments**: 1) Pre-train RoBERTa with supervised contrastive learning and evaluate on validation set, 2) Apply pre-trained model to unlabeled data and analyze uncertainty distribution, 3) Run small active learning loop with limited budget and evaluate performance improvement
