# Visual Information Matters for ASR Error Correction

## Quick Facts
- arXiv ID: 2303.10160
- Source URL: https://arxiv.org/abs/2303.10160
- Reference count: 0
- Primary result: Visual information improves ASR error correction by up to 1.2% WER, particularly for homophone confusions.

## Executive Summary
This paper tackles the problem of improving ASR output through a multimodal post-processing correction system. The key idea is to incorporate visual context alongside text and speech modalities to address errors that are difficult to correct using only text and audio, such as homophone confusions. The authors propose two simple methods to achieve this: (1) a gated fusion technique that concatenates image features with text embeddings, and (2) a prompt-based approach that uses image captions as additional context. They also introduce a new benchmark dataset, Visual-ASR-EC, carefully curated to ensure visual context is critical for correction—even humans struggle without it. Experiments show that the prompt-based method significantly outperforms strong baselines, achieving up to 1.2% improvement in WER across multiple ASR models. The results confirm that visual information is both effective and essential for certain ASR error correction scenarios.

## Method Summary
The paper proposes two methods for incorporating visual information into ASR error correction: gated fusion and prompt-based approaches. Gated fusion projects visual features to text embedding dimension, concatenates them, and applies a tanh gate to control visual information contribution. The prompt-based method prepends image captions to source sentences using a [SEP] token. Both methods are applied sequentially after a baseline transformer model, with filtering to ensure corrections align with visual context. The Visual-ASR-EC dataset is created by extracting frames from How2 and YouTube videos, generating ASR outputs, and filtering to include only examples where visual context is necessary for correction.

## Key Results
- Visual information improves ASR error correction by up to 1.2% WER across multiple ASR models
- Prompt-based method outperforms gated fusion, particularly when captions provide relevant context
- Human evaluation confirms visual context is essential even for humans on the curated test set
- Performance degrades on random test sets where visual context is not critical

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Gated fusion of visual and textual features improves ASR error correction by selectively incorporating image context.
- Mechanism: Projects visual features to text embedding dimension, concatenates with text embeddings, applies tanh gate to control visual contribution.
- Core assumption: Visual information helps correct homophone confusions and visually disambiguable errors.
- Evidence anchors: Abstract mentions gated fusion effectiveness; section describes tanh gating process; weak citation support.

### Mechanism 2
- Claim: Image captions as prompts provide contextual disambiguation for homophones and visual errors.
- Mechanism: Prepends generated captions to source sentences with [SEP] token for context.
- Core assumption: Captions capture semantically relevant visual information for disambiguation.
- Evidence anchors: Abstract highlights prompt-based method; section shows example of caption as prompt; weak citation support.

### Mechanism 3
- Claim: Sequential application allows specialized correction for different error types.
- Mechanism: Baseline model handles general errors, then visual methods address visually-dependent corrections with filtering.
- Core assumption: Different error types benefit from different correction approaches.
- Evidence anchors: Abstract describes sequential application; section explains filtering mechanism; weak citation support.

## Architecture Onboarding

- Component map: ASR output → Text encoder → (Visual encoder + gating) → Decoder → Corrected output
  For prompt-based: ASR output + Caption → Text encoder → Decoder → Corrected output

- Critical path: ASR output → Text encoder → (Visual encoder + gating) → Decoder → Corrected output
  For prompt-based: ASR output + Caption → Text encoder → Decoder → Corrected output

- Design tradeoffs:
  - Gated fusion requires image features but provides direct visual integration
  - Prompt-based leverages text data but depends on caption quality
  - Sequential application adds complexity but enables specialized correction

- Failure signatures:
  - Gated fusion: Visual features don't improve or degrade performance
  - Prompt-based: Poor caption quality or irrelevant context
  - Both: Filtering mechanism rejects too many or too few corrections

## Limitations

- Visual information approach effectiveness depends heavily on caption quality and relevance
- Sequential correction method adds computational complexity and potential error propagation
- Evaluation metrics (WER/SER) may not fully capture correction quality in context

## Confidence

- Visual information improves ASR error correction in visually disambiguable cases: High
- Gated fusion and prompt-based methods are effective: Medium
- Results generalize to diverse real-world scenarios: Low
