# History Repeats: Overcoming Catastrophic Forgetting For Event-Centric Temporal Knowledge Graph Completion

## Quick Facts
- arXiv ID: 2305.18675
- Source URL: https://arxiv.org/abs/2305.18675
- Reference count: 17
- Primary result: Achieves MRR of 0.358 on ICEWS-M, outperforming fine-tuning baseline of 0.325

## Executive Summary
This paper addresses catastrophic forgetting in temporal knowledge graph (TKG) completion by proposing a continual learning framework that combines temporal regularization with clustering-based experience replay. The method incrementally learns new events while preserving knowledge of previous events through elastic weight consolidation with decayed importance weights and selective sampling of representative historical data. Experiments on ICEWS-M, ICEWS-2M, and GDELT datasets demonstrate significant improvements over fine-tuning baselines, with the full model achieving average MRR scores of 0.358, 0.349, and 0.256 respectively.

## Method Summary
The approach builds on RE-NET as the base model and introduces two key mechanisms: temporal elastic weight consolidation (EWC) with decayed importance for older tasks, and clustering-based experience replay using HDBSCAN to select representative samples from past data. The temporal EWC applies exponentially decaying weights to older tasks' regularization terms, allowing newer tasks to adapt more parameters while protecting essential knowledge from recent tasks. The clustering-based experience replay identifies density-based clusters in the embedding space and selects data points closest to cluster exemplars, ensuring diverse and representative coverage of the data distribution. The framework operates in an incremental fashion, processing time windows sequentially while maintaining a memory buffer of historical data.

## Key Results
- Full model achieves MRR of 0.358 on ICEWS-M compared to 0.325 for fine-tuning baseline
- Clustering-based experience replay outperforms uniform sampling when memory is sufficient
- Ablation studies confirm effectiveness of both temporal EWC and clustering components
- Model shows consistent improvement across ICEWS-M, ICEWS-2M, and GDELT datasets

- Mechanism: The model computes Fisher Information Matrix for each task to identify important parameters, then applies exponentially decaying weights (α^(t-τ)) to older tasks' regularization terms, allowing newer tasks to adapt more parameters while protecting essential knowledge from recent tasks
- Core assumption: The Fisher Information Matrix accurately captures parameter importance across time-varying TKG distributions

### Mechanism 2
- Claim: Clustering-based experience replay selects representative samples that capture data structure better than random sampling
- Mechanism: HDBSCAN identifies density-based clusters in the embedding space [es:eo], then selects data points closest to cluster exemplars while prioritizing larger clusters, ensuring diverse and representative coverage of the data distribution
- Core assumption: The [es:eo] embedding representation effectively captures the underlying structure of TKG events for clustering purposes
- Evidence anchors:
  - [section 4.1.1]: "clustering is applied to the representation of events in the training set in order to uncover the underlying structure of the data"

- Break condition: When cluster structure becomes meaningless due to uniform or random data distribution

### Mechanism 3
- Claim: The combination of temporal regularization and selective experience replay creates complementary forgetting prevention mechanisms
- Mechanism: Temporal regularization provides parameter-level protection through EWC loss, while experience replay provides data-level reinforcement through selective sampling, creating two independent paths to preserve knowledge
- Core assumption: Parameter consolidation and data replay address different aspects of forgetting that cannot be solved by either mechanism alone
- Evidence anchors:
  - [abstract]: "Our incremental learning framework employs regularization and experience replay to alleviate catastrophic forgetting"
  - [section 4]: "we utilize experience replay and regularization techniques - methodologies commonly employed in image processing and reinforcement learning"
  - [section 5.4]: "clustering-based experience replay showing superior performance compared to random experience replay"
- Break condition: When one mechanism becomes redundant due to overlapping protection coverage

## Architecture Onboarding

- Component map: Base RE-NET model → Temporal EWC regularization layer → Clustering-based experience replay buffer → Incremental training pipeline
- Critical path: Model initialization → Task incremental training with EWC loss → Memory buffer update with clustering → Validation and performance tracking
- Design tradeoffs: Memory buffer size vs. forgetting mitigation (smaller buffers require more selective sampling), EWC regularization strength vs. adaptability to new tasks, cluster size vs. computational complexity
- Failure signatures: Performance degradation on older tasks despite regularization, memory buffer becoming ineffective with random sampling, Fisher Information Matrix instability across time steps
- First 3 experiments:
  1. Implement temporal EWC without clustering to establish baseline forgetting prevention
  2. Add clustering-based experience replay with fixed buffer size to test data selection effectiveness
  3. Combine both mechanisms with varying α decay rates to optimize temporal importance weighting

## Limitations
- Reliance on specific dataset characteristics and temporal patterns may limit generalization
- Computational overhead of HDBSCAN clustering and Fisher Information Matrix computation could be prohibitive for larger-scale TKGs
- Decay parameter α for temporal EWC requires careful tuning and may not generalize well across different domains

## Confidence
- **High Confidence**: The empirical results showing improved MRR scores compared to fine-tuning baselines are well-supported by the reported experimental data and ablation studies.
- **Medium Confidence**: The theoretical foundation of temporal EWC with decayed importance is reasonable but lacks direct corpus validation for TKG applications.
- **Low Confidence**: The clustering mechanism's effectiveness across diverse TKG datasets remains unproven, as the study is limited to event-centric datasets with specific characteristics.

## Next Checks

3. **Hyperparameter Sensitivity Study**: Systematically vary the temporal decay parameter α and memory buffer sizes across different datasets to identify robust ranges that generalize beyond the reported experimental conditions.
