# Variational sparse inverse Cholesky approximation for latent Gaussian processes via double Kullback-Leibler minimization

## Quick Facts
- arXiv ID: 2301.13303
- Source URL: https://arxiv.org/abs/2301.13303
- Reference count: 39
- Key outcome: DKLGP achieves superior accuracy compared to inducing-point and mean-field variational methods at similar computational complexity for latent Gaussian processes

## Executive Summary
This paper proposes a scalable variational inference method for latent Gaussian processes (LGPs) by combining sparse inverse Cholesky (SIC) approximations of both the prior and the variational posterior. The key idea is to use double Kullback-Leibler (KL) minimization: a forward KL-optimal SIC approximation of the prior and a reverse KL-optimal variational approximation of the posterior, both under SIC restrictions. A particular ordering and nearest-neighbor sparsity pattern is adopted, along with reduced ancestor sets, to enable efficient computation via stochastic gradient descent in polylogarithmic time per iteration. The proposed double-KL-optimal Gaussian-process approximation (DKLGP) is shown to be vastly more accurate than inducing-point and mean-field variational methods at similar computational complexity for both simulated and real data.

## Method Summary
The method combines two KL-optimal approximations: (1) a forward KL-optimal SIC approximation of the prior Gaussian process using r-maximin ordering and nearest-neighbor sparsity, and (2) a reverse KL-optimal variational approximation of the posterior in the family of SIC Gaussians. The variational parameters are optimized via minibatch stochastic gradient descent using reduced ancestor sets to enable efficient computation. The prior approximation is computed once per hyperparameter update using closed-form solutions, while the variational parameters are updated iteratively to maximize the evidence lower bound (ELBO).

## Key Results
- DKLGP achieves significantly lower RMSE and NLL than inducing-point and mean-field variational methods on real-world datasets (e.g., Air Quality UCI, Security Detection)
- The method scales polylogarithmically with data size due to reduced ancestor sets and efficient SIC computations
- For simulated data with n=100,000, DKLGP maintains accuracy while reducing computation time by orders of magnitude compared to exact methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Double KL minimization ensures both the prior and variational posterior approximations are optimal under sparse inverse Cholesky constraints
- Mechanism: The method minimizes forward KL divergence for the prior approximation and reverse KL divergence for the variational posterior, both restricted to the same sparse inverse Cholesky (SIC) family
- Core assumption: The optimal SIC approximation to the prior can be computed in closed form and remains valid when used as the reference distribution for variational inference
- Evidence anchors:
  - [abstract] "We combine this variational approximation of the posterior with a similar and efficient SIC-restricted Kullback-Leibler-optimal approximation of the prior"
  - [section] "we replace the prior p(f) defined in (1) by a Gaussian distribution that minimizes a second KL divergence under an SIC constraint"
  - [corpus] Weak evidence - no direct supporting papers found in neighbors
- Break condition: If the closed-form solution for the prior approximation becomes inaccurate for highly irregular input geometries or extreme correlation structures

### Mechanism 2
- Claim: Reduced ancestor sets enable polylogarithmic computational scaling while maintaining approximation accuracy
- Mechanism: By exploiting the screening effect and ignoring ancestors beyond a reduced set determined by nearest-neighbor distances, the method avoids computing full ancestor dependencies while preserving accuracy
- Core assumption: For Matérn-type kernels, the contribution of non-reduced ancestors to the posterior variance becomes negligible
- Evidence anchors:
  - [abstract] "For this setting, our variational approximation can be computed via stochastic gradient descent in polylogarithmic time per iteration"
  - [section] "Claim 2.4. For Matérn-type LGPs with exponential-family likelihoods, (V⁻¹L:,i)ⱼ≈ 0 for all j ∉ Ãi"
  - [corpus] Moderate evidence - Gaussian Processes Sampling with Sparse Grids uses similar sparse approximations
- Break condition: When input locations are highly irregular or clustered such that the screening effect breaks down

### Mechanism 3
- Claim: The maximin ordering combined with nearest-neighbor sparsity achieves near-optimal accuracy for stationary kernels
- Mechanism: This ordering maximizes minimum distances between subsequent points, while the nearest-neighbor sparsity pattern captures the essential correlations needed for accurate approximation
- Core assumption: For stationary kernels like Matérn, the number of neighbors needed for accurate approximation grows only polylogarithmically with data size
- Evidence anchors:
  - [abstract] "We then focus on a particular SIC ordering and nearest-neighbor-based sparsity pattern resulting in highly accurate prior and posterior approximations"
  - [section] "Schäfer et al. (2021a) proved that a highly accurate approximation of the prior can be obtained using Sp = S with ρ = O(log n)"
  - [corpus] Strong evidence - Multiple neighbor papers cite Vecchia approximations for stationary kernels
- Break condition: For non-stationary kernels or inputs with complex geometries where stationary assumptions fail
