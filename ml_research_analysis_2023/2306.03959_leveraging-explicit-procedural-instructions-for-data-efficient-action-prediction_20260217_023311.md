# Leveraging Explicit Procedural Instructions for Data-Efficient Action Prediction

## Executive Summary
This paper introduces KADS, a knowledge-augmented dialogue system that improves action prediction in task-oriented dialogues by leveraging explicit procedural instructions. The system combines a knowledge retriever with a language model to pull relevant agent guidelines and generate actions. KADS is trained using a novel semi-supervised scheme with dialogue-document matching and action-oriented masked language modeling. Experiments on two datasets (ABCD and SGD) show that KADS improves both b-slot and value prediction accuracy for in-distribution and out-of-distribution actions, particularly in low-data settings.

## Method Summary
KADS integrates explicit procedural instructions into a task-oriented dialogue system through a knowledge retriever and language model architecture. The system uses a semi-supervised training approach that combines dialogue-document matching with action-oriented masked language modeling. During inference, KADS retrieves relevant procedural knowledge and generates actions by conditioning on both dialogue context and retrieved instructions. The method addresses the challenge of limited training data and improves generalization to unseen actions through explicit knowledge integration.

## Key Results
- KADS achieves 85.2% b-slot accuracy on AST compared to 79.5% for baseline T5 on ABCD dataset
- On unseen actions, KADS reaches 11.6% accuracy versus 0% for the baseline
- KADS shows consistent improvements across both in-distribution and out-of-distribution action prediction

## Why This Works (Mechanism)
KADS works by explicitly incorporating procedural knowledge into the dialogue system's decision-making process. The knowledge retriever identifies relevant agent guidelines for each dialogue turn, while the language model uses this information to generate more accurate actions. The semi-supervised training scheme allows the system to learn from both labeled dialogues and unlabeled procedural documents, creating a more robust model that can generalize to new scenarios. The action-oriented masked language modeling specifically trains the system to predict action components while leveraging the retrieved procedural knowledge.

## Architecture Onboarding

**Component Map**: Dialogue Context -> Knowledge Retriever -> Retrieved Instructions -> Language Model -> Action Prediction

**Critical Path**: The retriever-language model pipeline is critical, where the retriever must find relevant instructions and the language model must effectively use them to generate actions.

**Design Tradeoffs**: The system trades computational overhead (retrieval step) for improved accuracy and generalization. The semi-supervised approach balances labeled data scarcity with the availability of procedural documents.

**Failure Signatures**: Without quality procedural instructions, the system reverts to baseline performance. Poor retrieval results in irrelevant knowledge being used for action prediction. Insufficient training data limits the effectiveness of the semi-supervised scheme.

**First Experiments**: 1) Test retrieval accuracy on procedural documents, 2) Evaluate language model performance with and without retrieved instructions, 3) Measure semi-supervised training effectiveness compared to fully supervised baseline.

## Limitations
- Heavy dependence on availability and quality of procedural instruction documents
- Experiments limited to two datasets with relatively constrained domain diversity
- Method's effectiveness fundamentally constrained by presence of structured, relevant procedural knowledge
