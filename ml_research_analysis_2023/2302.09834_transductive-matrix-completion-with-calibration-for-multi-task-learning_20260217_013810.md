# Transductive Matrix Completion with Calibration for Multi-Task Learning

## Quick Facts
- arXiv ID: 2302.09834
- Source URL: https://arxiv.org/abs/2302.09834

## Executive Summary
This paper proposes a Transductive Matrix Completion with Calibration (TMCC) algorithm for multi-task learning where both feature and target matrices are incomplete. The method simultaneously recovers both matrices under low-rank constraints while incorporating calibration information about the features. Theoretical analysis shows the method achieves a constant order improvement over existing methods due to the calibration constraint, with a sub-linear convergence rate of O(1/k²). Experiments on synthetic data demonstrate superior performance compared to baseline methods, particularly when the target matrix has a nonlinear relationship with the feature matrix.

## Method Summary
The TMCC algorithm addresses multi-task learning by recovering incomplete feature and target matrices under low-rank assumptions while incorporating calibration constraints. It uses accelerated proximal gradient descent with singular value thresholding to achieve joint recovery. The calibration constraint AX* = B acts as prior knowledge that regularizes feature matrix estimation, providing constant order improvement in recovery error. The algorithm handles multiple response matrices from different exponential family distributions and demonstrates sub-linear convergence rate O(1/k²).

## Key Results
- Statistical guarantee shows constant order improvement in recovery error due to calibration constraint
- Sub-linear convergence rate of O(1/k²) achieved through accelerated proximal gradient descent
- Synthetic experiments show TMCC outperforms existing methods, especially for nonlinear feature-target relationships
- Recovery error bounded by right-hand side of equation (3) with high probability

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Calibration information provides constant order improvement in recovery error
- Mechanism: The calibration constraint AX* = B acts as additional prior knowledge that regularizes the feature matrix estimation, reducing uncertainty beyond what standard matrix completion achieves
- Core assumption: Calibration matrix A is full rank (Assumption 5) and the calibration information is sufficiently strong

### Mechanism 2
- Claim: Joint recovery of target and feature matrices enables better target matrix completion
- Mechanism: By simultaneously estimating both X* and Z* under low-rank constraints, the algorithm exploits the relationship between features and targets rather than treating them separately
- Core assumption: There exists a meaningful relationship between feature matrix X* and target matrix Z* (low-rank structure)
- Evidence anchors:
  - [section 2]: "Our goal is to recover Z*" and "we believe that some hidden connection between X* and Z* may provide us benefits"
  - [section 4]: "when the relationship between X* and Z* is not linear, simultaneously recovering demonstrates great strength"
  - [corpus]: Moderate evidence - multiple papers on matrix completion with side information
- Break condition: When the feature-target relationship is weak or when the relationship is highly nonlinear in ways not captured by the model

### Mechanism 3
- Claim: Sub-linear convergence rate O(1/k²) achieved through accelerated proximal gradient descent
- Mechanism: The algorithm uses an accelerated proximal gradient descent step (θ = (c-1)/(c+2)) combined with singular value thresholding to achieve faster convergence
- Core assumption: The objective function is smooth enough and the step size η is appropriately chosen
- Evidence anchors:

## Architecture Onboarding

- Component map: Incomplete feature matrix X, response matrices Y^(1),...,Y^(S), indicator matrices Rx, Ry, calibration matrices A, B -> TMCC algorithm -> Completed feature matrix X̂ and target matrices Ẑ^(1),...,Ẑ^(S)

- Critical path:
  1. Initialize random matrices M^(0) = M^(1)
  2. For k = 1 to K:
     - Compute θ = (c-1)/(c+2)
     - Compute Q = (1+θ)M^(k) - θM^(k-1)
     - Compute gradient Bf_τ1(Q) with calibration term
     - Update T = Q - ηBf_τ1(Q)
     - Apply singular value thresholding: M^(k+1) = T_ητ2(T)
     - Check stopping criterion
  3. Return final M = M^(k+1)

- Design tradeoffs:
  - Joint vs. separate recovery: Joint recovery exploits feature-target relationships but increases computational complexity
  - Calibration strength: Stronger calibration improves accuracy but requires more prior knowledge
  - Rank selection: Higher rank allows more complex relationships but risks overfitting

- Failure signatures:
  - Slow convergence: May indicate poor step size choice or ill-conditioned calibration matrix
  - High recovery error: Could signal weak calibration information or violation of low-rank assumptions
  - Numerical instability: May occur when calibration matrix A is nearly singular

- First 3 experiments:
  1. Verify convergence on synthetic data with known ground truth and varying calibration strength
  2. Test sensitivity to rank selection by varying r and measuring recovery error
  3. Compare performance against baseline methods (MC0, CMC SI, TS) on both linear and nonlinear data relationships

- What evidence would resolve it: Analyzing the convergence rate of TMCC with and without the calibration constraint, and comparing the results to determine the impact of calibration on the rate.

## Limitations

- Limited empirical validation on real-world datasets beyond synthetic experiments
- Assumes calibration matrix A is full rank, which may not hold in practice
- Sensitivity to hyperparameter selection not thoroughly explored
