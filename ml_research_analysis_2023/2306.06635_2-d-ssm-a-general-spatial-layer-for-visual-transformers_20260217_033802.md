# 2-D SSM: A General Spatial Layer for Visual Transformers

## Quick Facts
- arXiv ID: 2306.06635
- Source URL: https://arxiv.org/abs/2306.06635
- Authors: 
- Reference count: 40
- This paper proposes 2D-SSM, a novel spatial layer for visual transformers based on a multidimensional State Space Model that significantly enhances performance across multiple ViT backbones and datasets.

## Executive Summary
This paper introduces 2D-SSM, a spatial layer for visual transformers that addresses the need for two-dimensional position awareness, dynamic spatial locality, and translation/permutation invariance in computer vision models. The layer is grounded in Roesser's model for multidimensional state space and uses efficient parameterization with only 8 parameters per channel that can be expanded into unbounded two-dimensional kernels. When incorporated at the beginning of each transformer block, 2D-SSM significantly improves performance across multiple ViT backbones and datasets while adding negligible parameters and inference time.

## Method Summary
The 2D-SSM layer implements a two-dimensional linear recurrent structure (Roesser's model) that inherently encodes positional information. It uses 8 parameters (A1, A2, A3, A4, B1, B2, C1, C2) per channel to construct convolution kernels through diagonalization and normalization. The layer is integrated into ViT backbones by applying it to 2D sequences of patches before each transformer block. Key innovations include efficient parameterization, accelerated computation through diagonalization, and a normalization scheme to prevent kernel explosion. The layer can be used with either complex or real parametrization and shows strong 2-D inductive bias even without positional encoding.

## Key Results
- 2D-SSM significantly improves ViT performance across CIFAR-100, Tiny-ImageNet, Celeb-A, and CIFAR-10 Grayscale datasets
- The layer achieves effective performance even without positional encoding, demonstrating strong 2-D inductive bias
- 2D-SSM provides better parameter efficiency and generalization compared to S4ND while maintaining or exceeding performance

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The 2D-SSM layer injects two-dimensional position awareness by design
- **Mechanism:** The layer uses Roesser's model with explicit construction of kernel K from parameters A, B, C, and D, inherently encoding positional information along both axes
- **Core assumption:** The recurrent formulation naturally captures positional dependencies without requiring separate positional encoding
- **Evidence anchors:** Abstract states layer has strong 2-D inductive bias and works without positional encoding; section confirms positional information is taken into account by design

### Mechanism 2
- **Claim:** The layer captures local and global spatial features with controllable receptive fields
- **Mechanism:** Uses only 8 parameters per channel but can expand into unbounded two-dimensional kernels; A1-A4 values control focus on short/long dependencies in horizontal, vertical, or diagonal directions
- **Core assumption:** Diagonalizing system matrices A1-A4 while keeping them within [0,1] allows stable yet expressive kernel computation
- **Evidence anchors:** Section explains 8 parameters can express unbounded kernels and control dependency lengths; A1-A4 values enable capturing different spatial dependencies

### Mechanism 3
- **Claim:** Better parameter efficiency and generalization compared to S4ND
- **Mechanism:** Unlike S4ND's rank-1 kernels from 1-D SSMs, 2D-SSM directly learns multi-dimensional functions with additional system matrices A2 and A3 that aggregate information from different axes
- **Core assumption:** Additional system matrices provide sufficient expressiveness to overcome S4ND's rank limitation
- **Evidence anchors:** Section contrasts S4ND's independent 1-D SSMs with 2D-SSM's direct multi-dimensional learning; Theorem 4.1 proves full-rank kernel expression vs Theorem 4.2's rank-1 limitation for S4ND

## Foundational Learning

- **Concept: State Space Models (SSM)**
  - Why needed here: 2D-SSM is built on multidimensional SSM theory for converting between state representations and spatial convolutions
  - Quick check question: What is the relationship between linear time-invariant SSMs and continuous convolution that makes them efficient for training?

- **Concept: Roesser's Model for Multidimensional State Space**
  - Why needed here: Extends classical SSM to two dimensions with separate horizontal and vertical state components crucial for 2D-SSM's positional awareness
  - Quick check question: How does Roesser's model differ from simply running two independent 1-D SSMs along each axis?

- **Concept: Diagonalization of System Matrices**
  - Why needed here: Enables efficient computation by allowing summation of at most 2Lmax elements instead of exponential growth while maintaining expressiveness through eigenvalues
  - Quick check question: Why does diagonalizing A1, A2, A3, A4 matrices make kernel computation feasible for large images?

## Architecture Onboarding

- **Component map:** Input (2D patches) -> 2D-SSM layer (2D convolution with learned kernel K) -> Transformer block (self-attention and MLP) -> Output (enhanced features with spatial bias)

- **Critical path:**
  1. Compute kernel K from SSM parameters using diagonalization and normalization
  2. Apply 2D convolution between input U and kernel K
  3. Feed result into transformer block
  4. Repeat for each transformer block in the architecture

- **Design tradeoffs:**
  - Diagonalization vs full matrices: Diagonal form enables efficient computation but may limit expressiveness
  - Real vs complex parameters: Complex parameters provide better performance but increase complexity and training instability
  - Parameter sharing across channels: Reduces parameters but may limit channel-specific adaptation

- **Failure signatures:**
  - Vanishing/exploding gradients (check if A values properly constrained to [0,1])
  - Poor performance compared to baseline (verify kernel computation and normalization)
  - Training instability with complex parameters (monitor for NaN values or divergence)
  - Unexpected bias toward diagonal patterns (check relaxation modifications)

- **First 3 experiments:**
  1. **Sanity check with ViT-Small on CIFAR-100:** Verify 2D-SSM improves baseline accuracy and persists without positional encoding
  2. **Ablation study on normalization:** Compare performance with and without "divide by two" normalization
  3. **Comparison with S4ND:** Implement S4ND as described and compare performance on same datasets

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** What is the optimal normalization scheme for the 2-D SSM layer to prevent kernel explosion while maintaining expressiveness?
- **Basis in paper:** The paper mentions a straightforward normalization mechanism (dividing by two) and notes that these modifications are "probably not optimal"
- **Why unresolved:** Current normalization is a heuristic and calls for optimal normalization as future work
- **What evidence would resolve it:** Comparative experiments testing different normalization schemes across various vision tasks and dataset sizes

### Open Question 2
- **Question:** How does the 2-D SSM layer perform on spatial vision tasks like video processing, image segmentation, and image inpainting compared to specialized architectures?
- **Basis in paper:** The paper mentions these tasks as future directions but only evaluates classification performance
- **Why unresolved:** Current experiments focus solely on image classification benchmarks
- **What evidence would resolve it:** Direct comparisons of 2-D SSM with state-of-the-art models on video classification, semantic segmentation, and image inpainting benchmarks

### Open Question 3
- **Question:** Can multi-dimensional parallel scanners be effectively applied to reduce the training time of the 2-D SSM layer for long-range dependencies?
- **Basis in paper:** The paper identifies slow training time as a limitation and suggests multi-dimensional parallel scanners as a potential solution
- **Why unresolved:** Proposed as future work without experimental validation
- **What evidence would resolve it:** Implementation and evaluation of multi-dimensional parallel scanners with 2-D SSM layer, comparing training time and memory usage across varying sequence lengths

## Limitations
- **Limitation 1:** Slow training time compared to standard ViT models due to SSM kernel computation
- **Limitation 2:** Unclear optimal normalization scheme, with current implementation using a heuristic approach
- **Limitation 3:** Theoretical expressiveness advantages over S4ND require more extensive empirical validation across diverse tasks

## Confidence

- **Claim:** Negligible parameter and inference overhead** (High confidence)
  - Well-supported by stated 8 parameters per channel, though actual overhead may vary with implementation details
- **Claim:** Expressiveness advantage over S4ND** (High confidence)
  - Theoretically proven but would benefit from more extensive empirical validation
- **Claim:** Effectiveness without positional encoding** (Medium confidence)
  - Demonstrated on CIFAR-100 but requires validation on larger-scale datasets like ImageNet
- **Claim:** Controllability of receptive fields through A1-A4 parameters** (Medium confidence)
  - Theoretically plausible but practical range of achievable patterns remains unclear
