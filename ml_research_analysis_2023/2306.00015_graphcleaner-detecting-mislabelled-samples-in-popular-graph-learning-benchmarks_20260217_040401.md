# GraphCleaner: Detecting Mislabelled Samples in Popular Graph Learning Benchmarks

## Quick Facts
- arXiv ID: 2306.00015
- Source URL: https://arxiv.org/abs/2306.00015
- Reference count: 23
- Primary result: Proposed method GRAPH CLEANER achieves 0.14 F1 and 0.16 MCC improvements over state-of-the-art mislabel detection methods

## Executive Summary
This paper addresses the underexplored problem of mislabel detection in graph data, where nodes have both feature attributes and relational connections. The authors propose GRAPH CLEANER, a post-hoc method that combines synthetic mislabel dataset generation with neighborhood-aware detection. The method estimates a mislabel transition matrix to create realistic synthetic mislabels and trains a binary classifier using neighborhood agreement features. Experiments demonstrate significant improvements over existing methods on 6 datasets, with practical impact shown by detecting and correcting mislabels in popular graph benchmarks.

## Method Summary
GRAPH CLEANER operates in two main phases: synthetic mislabel generation and neighborhood-aware detection. First, it estimates a mislabel transition matrix from the data to understand how labels are likely to be corrupted. This matrix is used to generate a synthetic mislabel dataset that mimics the real mislabeling pattern. In the detection phase, a binary classifier is trained using neighborhood agreement features - capturing how a node's label aligns with its neighbors' labels. The method also provides theoretical guarantees on false positive and negative rates through conformal prediction, ensuring reliable detection performance.

## Key Results
- GRAPH CLEANER achieves an average improvement of 0.14 in F1 score and 0.16 in MCC compared to state-of-the-art methods
- Case studies identify at least 6.91% mislabelled samples in the PubMed dataset
- Removing detected mislabels improves evaluation performance from 86.71% to 89.11%
- The method provides theoretical guarantees on false positive and negative rates using conformal prediction

## Why This Works (Mechanism)
The method leverages the unique structure of graph data where nodes are connected and labels exhibit local consistency patterns. By generating synthetic mislabels that follow realistic transition patterns estimated from the data, the method creates training examples that closely resemble actual mislabeling scenarios. The neighborhood-aware detection captures the inherent smoothness assumption in graph data - correctly labeled nodes tend to agree with their neighbors, while mislabelled nodes often stand out as inconsistencies in the local neighborhood structure.

## Foundational Learning
- Graph neural networks: Understanding how information propagates through graph structures is crucial for designing effective neighborhood features
- Conformal prediction: Provides rigorous statistical guarantees on detection reliability without requiring knowledge of true mislabel distribution
- Label transition matrices: Model the probabilistic relationships between true and observed labels, essential for generating realistic synthetic mislabels
- Neighborhood consistency: Exploits the assumption that connected nodes in graphs often share similar labels, a key property for detection
- Binary classification for anomaly detection: Treats mislabel detection as an anomaly detection problem where synthetic mislabels serve as positive examples

## Architecture Onboarding

**Component map:** Synthetic mislabel generator -> Neighborhood feature extractor -> Binary classifier -> Conformal prediction wrapper

**Critical path:** The synthetic mislabel generation creates training data → Neighborhood features are computed based on graph structure → Binary classifier learns to distinguish clean from mislabeled nodes → Conformal prediction provides statistical guarantees

**Design tradeoffs:** Balances between realistic synthetic mislabel generation (computational cost) and detection accuracy; uses neighborhood features which may miss global patterns but are computationally efficient

**Failure signatures:** Poor performance when graph structure doesn't reflect label similarity; degradation when true mislabel distribution differs significantly from synthetic generation; computational bottlenecks on very large graphs

**3 first experiments:** 1) Test on a simple synthetic graph with known mislabels to verify detection capability 2) Evaluate on a small real-world dataset to assess practical performance 3) Validate the conformal prediction guarantees on controlled experiments

## Limitations
- Primary evaluation on citation networks and molecular graphs may limit generalizability to other graph types
- Computational complexity of synthetic mislabel generation and classifier training may be prohibitive for very large graphs
- Effectiveness of conformal prediction guarantees in real-world scenarios with unknown mislabel distributions remains uncertain

## Confidence
- High: Method's effectiveness on tested datasets and ability to detect mislabels in popular benchmarks
- Medium: Theoretical guarantees provided by conformal prediction
- Low: Performance on graph types not covered in the study
