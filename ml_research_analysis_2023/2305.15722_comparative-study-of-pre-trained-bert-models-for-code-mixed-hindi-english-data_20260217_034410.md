# Comparative Study of Pre-Trained BERT Models for Code-Mixed Hindi-English Data

## Quick Facts
- arXiv ID: 2305.15722
- Source URL: https://arxiv.org/abs/2305.15722
- Authors: 
- Reference count: 28

## Executive Summary
This paper presents a comparative study of pre-trained transformer-based models for code-mixed Hindi-English NLP tasks. The authors evaluate HingBERT, HingRoBERTa, HingRoBERTa-Mixed (pre-trained on code-mixed text), mBERT, ALBERT, BERT, and RoBERTa on five datasets containing Hindi-English code-mixed tweets. Through systematic fine-tuning and hyperparameter optimization, the HingBERT-based models significantly outperform vanilla BERT and RoBERTa models, demonstrating the importance of pre-training on code-mixed data. The HingRoBERTa-Mixed model achieves state-of-the-art results by handling both Roman and Devanagari scripts.

## Method Summary
The authors use five Hindi-English code-mixed tweet datasets (Icon, Emotions, Sentiment, HateSpeech, HASOC) and apply preprocessing to clean text by removing hyperlinks, mentions, hashtags, punctuations, and emojis. They fine-tune seven pre-trained models (HingBERT, HingRoBERTa, HingRoBERTa-Mixed, mBERT, ALBERT, BERT, RoBERTa) using hyperparameter tuning with learning rates from 1e-6 to 1e-4, epochs from 1-5, and batch sizes of 32-64. Experiments are tracked using Weights & Biases, and models are evaluated using F1 score (macro), precision, recall, and accuracy.

## Key Results
- HingRoBERTa and HingRoBERTa-Mixed models outperform all other models on sentiment analysis, emotion recognition, and hate speech detection tasks
- HingBERT-based models provide significant improvements over vanilla BERT models, highlighting the importance of pre-training on code-mixed text
- HingRoBERTa-Mixed achieves state-of-the-art results by handling both Roman and Devanagari scripts in code-mixed text

## Why This Works (Mechanism)

### Mechanism 1
- Claim: HingBERT-based models outperform vanilla BERT because they are pre-trained on real code-mixed text
- Mechanism: Code-mixed text has unpredictable language transitions and informal grammar. Pre-training on code-mixed text allows the model to learn representations that capture the blending of languages, including informal spelling and transliteration patterns
- Core assumption: Pre-training data distribution must match the target task's linguistic characteristics for optimal fine-tuning
- Evidence anchors:
  - [abstract] "Our HingBERT-based models provide significant improvements thus highlighting the poor performance of vanilla BERT models on code-mixed text."
  - [section] "As they were all trained on romanized Hindi English code mix data, HingBERT, HingRoBERTa, and HingRoBERTa-Mixed outperform base BERT and RoBERTa, which were only trained in English."
- Break condition: If the code-mixed data is too small or not representative of the target domains, performance gains will diminish

### Mechanism 2
- Claim: HingRoBERTa-Mixed achieves state-of-the-art results because it is trained on both Roman and Devanagari scripts
- Mechanism: Mixed-script training allows the model to handle transliteration variability, where the same Hindi word may appear in Roman or Devanagari script depending on the user
- Core assumption: Handling script variability is crucial for robust performance on real-world code-mixed text
- Evidence anchors:
  - [section] "Specifically, HingRoBERTa performs the best on Icon, Hate speech, and HASOC datasets while HingRoBERTa-Mixed provides state-of-the-art results for the Emotions and Sentiment dataset."
- Break condition: If downstream datasets predominantly use only one script, the script mixing advantage disappears

### Mechanism 3
- Claim: Multilingual BERT performs reasonably well because it is trained on Hindi and other Devanagari script languages
- Mechanism: Multilingual BERT captures language-agnostic representations, and Hindi being in the training set provides some cross-lingual transfer, even if not explicitly trained on code-mixed text
- Core assumption: Shared linguistic features between monolingual Hindi and code-mixed Hindi-English allow some level of transfer
- Evidence anchors:
  - [section] "Multilingual BERT is not trained on code mix data but was trained on Devnagari script languages like Hindi and Marathi. Consequently, it works rather well even if it isn't as good as the Hing models."
- Break condition: If Hindi-specific linguistic features dominate, non-Hindi languages in mBERT could dilute performance

## Foundational Learning

- Concept: Code-mixing vs. code-switching
  - Why needed here: Understanding the linguistic phenomenon being modeled ensures correct preprocessing and evaluation
  - Quick check question: Does the text contain intra-sentential language alternation or just borrowing words?

- Concept: Pre-training vs. fine-tuning distinction
  - Why needed here: Models must be pre-trained on data matching the target domain before fine-tuning for best results
  - Quick check question: What language distribution is present in the pre-training corpus versus the fine-tuning corpus?

- Concept: Script variability handling
  - Why needed here: Real-world code-mixed text may use Roman or Devanagari scripts interchangeably; models must be robust to both
  - Quick check question: Does the dataset contain transliterated words, and how are they normalized?

## Architecture Onboarding

- Component map: Tokenizer → Embedding layer → Transformer blocks → Classification head
- Critical path: Load pre-trained weights → Tokenize code-mixed text → Forward pass through transformer → Apply classification head → Compute loss
- Design tradeoffs: Using HingRoBERTa-Mixed increases model size and training time but improves robustness to script variability; HingRoBERTa is lighter but may miss some transliteration cases
- Failure signatures: Poor performance on transliterated words, inconsistent predictions across scripts, overfitting on one script type
- First 3 experiments:
  1. Fine-tune HingBERT on a small validation set to confirm baseline performance before scaling
  2. Compare predictions on purely Roman vs. mixed-script examples to isolate script handling effects
  3. Ablation: Train HingRoBERTa without mixed-script data to quantify the benefit of script variability

## Limitations
- Claims about superiority rest on comparisons against relatively standard baselines but do not test against more recent code-mixed models or large language models
- Corpus analysis shows weak direct evidence for several key mechanisms, particularly regarding script handling advantages
- Paper does not provide detailed ablation studies to isolate effects of pre-training data quality versus model architecture changes

## Confidence
- **High confidence**: The overall finding that code-mixed pre-training improves performance on code-mixed tasks is well-supported by comparative results
- **Medium confidence**: The specific claim about HingRoBERTa-Mixed achieving state-of-the-art results due to mixed-script training is plausible but lacks direct experimental evidence
- **Medium confidence**: The mechanism explaining mBERT's reasonable performance through Hindi pre-training is reasonable but not quantitatively validated
