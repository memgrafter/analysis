# Multiple-level Point Embedding for Solving Human Trajectory Imputation with Prediction

## Quick Facts
- arXiv ID: 2301.04482
- Source URL: https://arxiv.org/abs/2301.04482
- Reference count: 38
- Primary result: INGRAIN achieves lower L2 losses than competitive baselines for both trajectory imputation and prediction tasks

## Executive Summary
This paper addresses the challenge of sparse human trajectory data by proposing a joint imputation and prediction framework called INGRAIN. The method tackles the interdependence between missing and observed trajectory points through a novel attention-based imputation component combined with an RNN-based prediction module. By introducing an Imputation Cycle mechanism that performs gradual imputation at multiple levels, the model achieves superior performance compared to existing approaches. Experiments on Geolife, Cuebiq-AU, and Cuebiq-US datasets demonstrate that INGRAIN effectively captures spatial-temporal dependencies while providing flexibility for task-specific optimization.

## Method Summary
INGRAIN combines non-autoregressive attention-based imputation with autoregressive RNN-based prediction to solve human trajectory imputation and prediction jointly. The framework uses multi-head self-attention in encoder-decoder layers to capture coexistence patterns between observed and missing points, followed by a Supplement Layer that extracts sequential patterns. A novel Imputation Cycle allows gradual imputation of missing points in batches rather than all at once, with prediction feedback incorporated at each cycle. The model is trained using a fused objective function that optimizes both imputation and prediction tasks simultaneously, enabling mutual performance enhancement.

## Key Results
- INGRAIN outperforms competitive baselines on both imputation and prediction tasks across Geolife, Cuebiq-AU, and Cuebiq-US datasets
- Attention-based imputation effectively captures spatial-temporal dependencies between observed and missing trajectory points
- Collaborative learning between imputation and prediction components creates mutual performance enhancement
- Gradual imputation with fewer points per cycle (n < I) yields better results than single-pass imputation
- Model demonstrates stability across varying missing rates and trajectory lengths

## Architecture Onboarding

- Component map: Linear Embedding Layer → Time Frame Encoding → Encoder/Decoder Blocks (with Self-Attention) → Supplement Layer → GRU-based Prediction Unit → Loss Functions (Limp, Lpre, Lvel)
- Critical path: Trajectory → Linear Embedding → Time Encoding → Encoder-Decoder Attention → Imputation Cycle (n points) → Supplement Layer → GRU → Prediction
- Design tradeoffs: Attention-based imputation vs sequential RNN imputation (flexibility vs computational cost), single vs multi-level imputation cycles (accuracy vs training time)
- Failure signatures: High imputation loss indicates attention mechanism isn't capturing dependencies; high prediction loss suggests supplement layer or GRU isn't learning effective sequential patterns

## Limitations
- Evaluation focuses on L2 loss metrics which may not fully capture real-world trajectory prediction quality where temporal smoothness and pattern consistency matter
- Computational complexity of multi-head attention scales quadratically with sequence length, potentially limiting applicability to very long trajectories
- Generalizability to other mobility contexts (transportation modes, urban/rural settings) remains untested
