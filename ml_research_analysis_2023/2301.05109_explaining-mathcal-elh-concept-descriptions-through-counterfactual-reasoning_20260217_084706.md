# Explaining $\mathcal{ELH}$ Concept Descriptions through Counterfactual Reasoning

## Quick Facts
- arXiv ID: 2301.05109
- Source URL: https://arxiv.org/abs/2301.05109
- Reference count: 40
- Key outcome: First approach for generating counterfactual explanations in ELH description logic using minimal feature changes and similarity to existing negative individuals

## Executive Summary
This paper introduces the first method for generating counterfactual explanations for individuals classified by ELH concepts in knowledge bases. The approach identifies counterfactual candidates by finding individuals that do not satisfy the same concept as the original individual, using minimal feature changes measured by edit distance between concise bounded descriptions. Multiple counterfactuals are ranked by their similarity to existing negative individuals in the knowledge base. User studies on family and animals ontologies show that explanations focusing on distinctive features are preferred, and that counterfactuals are as effective as concept-based explanations.

## Method Summary
The method generates counterfactual explanations by first inferring all possible concept and role assertions for an individual using a reasoner. For each subconcept of the target concept, it creates counterfactual candidates by removing axioms (atomic concept assertions or role assertions) such that the concept no longer holds. Candidates with minimal edit distance to the original individual are selected as counterfactuals. When multiple candidates exist, they are ranked by their similarity to existing negative individuals in the knowledge base, using either minimum distance to any negative individual or average distance to all negative individuals.

## Key Results
- Counterfactual explanations successfully identify minimal changes needed to prevent concept classification
- User studies show counterfactual explanations are as effective as concept-based explanations for understanding classification decisions
- Explanations focusing on distinctive features are preferred by users over other explanation types
- The approach works effectively on both family and animals ontologies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Counterfactual candidates are generated by removing axioms from the individual's CBD to make the concept no longer hold.
- Mechanism: The algorithm systematically removes either atomic concept assertions or role assertions (via subsumption) that contribute to the concept classification.
- Core assumption: The individual's classification depends on a minimal set of axioms that can be removed to invalidate the concept.
- Evidence anchors:
  - [abstract] "Counterfactual candidates are generated from concepts and the candidates with fewest feature changes are selected as counterfactuals."
  - [section] "First, a reasoner infers as many concept and role assertions as possible taking subsumptions into account... We turn the xi into a counterfactual candidate with Ki ̸|= C(x′) by removing axioms such that the subconcept Ci does not hold anymore"
  - [corpus] Weak evidence - the corpus focuses on general counterfactual generation, not the specific DL removal mechanism.
- Break condition: If the concept requires complex interactions between multiple axioms, simple removal may not produce valid counterfactuals.

### Mechanism 2
- Claim: Counterfactuals are ranked by edit distance between concise bounded descriptions.
- Mechanism: The algorithm measures similarity by counting the number of additions/removals needed to transform one individual's CBD into another's.
- Core assumption: Minimal feature changes produce the most interpretable counterfactuals.
- Evidence anchors:
  - [abstract] "Counterfactual candidates are generated from concepts and the candidates with fewest feature changes are selected as counterfactuals."
  - [section] "Let 𝛿 (𝑋 , 𝑌) := |𝑋 \ 𝑌 | + |𝑌 \ 𝑋 | be the edit distance between two arbitrary sets counting the number of additions and removals."
  - [corpus] Moderate evidence - edit distance similarity is a common counterfactual ranking approach mentioned in related work.
- Break condition: When multiple counterfactuals have identical edit distances, the ranking may not distinguish meaningfully.

### Mechanism 3
- Claim: Likeliness ranking uses existing negative individuals to score counterfactual plausibility.
- Mechanism: Counterfactuals are scored by their similarity to existing individuals that don't satisfy the concept.
- Core assumption: Counterfactuals resembling existing negative examples are more plausible in the real world.
- Evidence anchors:
  - [abstract] "When multiple counterfactuals exist, we rank them based on the likeliness of their feature combinations."
  - [section] "We define the min-likeliness... as the minimal distance: min𝑥∈𝑁𝐼 𝛿 (CR(x ′), CR(x))"
  - [corpus] Weak evidence - the corpus neighbors focus on different counterfactual ranking approaches not based on existing individuals.
- Break condition: If the knowledge base lacks diverse negative examples, the likeliness ranking may be unreliable.

## Architecture Onboarding

- Component map:
  - Input: Knowledge base K, concept C, individual x
  - Reasoner: Infers all concept and role assertions from TBox
  - Counterfactual generator: Creates candidates by removing axioms
  - Similarity scorer: Computes edit distances between CBDs
  - Likeliness ranker: Scores candidates using existing negative individuals
  - Output: Ranked list of counterfactual explanations

- Critical path:
  1. Reasoner infers all possible assertions
  2. Algorithm creates counterfactual candidates for each subconcept
  3. Edit distance filtering selects minimal-change candidates
  4. Likeliness ranking orders remaining candidates
  5. Results returned to user

- Design tradeoffs:
  - Simple edit distance vs. semantic similarity measures
  - Computational cost of considering all negative individuals vs. approximation methods
  - Using only subject-related axioms vs. including objects in similarity calculation

- Failure signatures:
  - No counterfactuals generated: Likely the concept is ⊤ or the individual has no mutable axioms
  - All counterfactuals have same score: May indicate insufficient diversity in the knowledge base
  - Counterfactuals seem implausible: May need to adjust similarity or likeliness metrics

- First 3 experiments:
  1. Run on a simple family ontology with known concept classifications to verify basic counterfactual generation
  2. Test with different TBox configurations (with/without role hierarchies) to observe impact on counterfactual candidates
  3. Compare min-likeliness vs. mean-likeliness ranking on a dataset with diverse negative examples to evaluate which produces more intuitive results

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the edit distance calculation be improved to better capture semantic similarity between individuals in knowledge bases, beyond simple feature count differences?
- Basis in paper: [explicit] The paper uses edit distance between concise bounded descriptions as the similarity measure, but notes this is a limitation and mentions the need to explore various calculation possibilities depending on ontology structure and use cases
- Why unresolved: The paper acknowledges that different ontology structures might require different similarity measures, but doesn't provide concrete alternatives or experimental validation of improved methods
- What evidence would resolve it: Comparative studies showing improved user satisfaction and explanation quality using alternative semantic similarity measures versus the current edit distance approach

### Open Question 2
- Question: How can actionability be incorporated into counterfactual explanations to ensure suggested changes are feasible in the real world?
- Basis in paper: [explicit] The paper notes that counterfactual explanations in domains like family ontologies are limited because people cannot change their gender or family relations, and mentions future work will focus on applications where actionability can be reached
- Why unresolved: The paper identifies actionability as a limitation but doesn't propose specific methods for determining which counterfactual changes are practically achievable
- What evidence would resolve it: Development and validation of a framework that filters counterfactual candidates based on real-world feasibility constraints and measures its impact on user satisfaction

### Open Question 3
- Question: How does the performance of counterfactual explanations in ELH compare to concept-based explanations when dealing with more complex description logics that include disjunctions?
- Basis in paper: [inferred] The paper plans to expand the algorithm to more complex DLs like ALC, which contains disjunctions, and mentions that learned concepts can become very long and hard to grasp even for experts
- Why unresolved: The current work is limited to ELH and doesn't explore how counterfactual explanations perform with more expressive logics that would create longer, more complex concepts
- What evidence would resolve it: User studies comparing understanding, satisfaction, and actionability of counterfactual versus concept-based explanations across different DL expressivity levels, including those with disjunctions

## Limitations
- Approach is limited to ELH, which is less expressive than full description logics
- Edit distance similarity measure may not capture semantic similarity adequately
- User studies were limited to family and animals ontologies, which may not generalize to all domains
