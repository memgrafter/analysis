# Magnitude Invariant Parametrizations Improve Hypernetwork Learning

## Quick Facts
- **arXiv ID:** 2304.07645
- **Source URL:** https://arxiv.org/abs/2304.07645
- **Reference count:** 40
- **Primary result:** MIP stabilizes hypernetwork training by normalizing inputs and using additive parameter updates, achieving consistent improvements across multiple tasks

## Executive Summary
This paper identifies a fundamental training instability in hypernetworks caused by the proportionality between input magnitude and output weights. This relationship leads to unstable optimization, slow convergence, and sometimes failed training. The authors propose a Magnitude Invariant Parametrization (MIP) that addresses this by encoding inputs to constant norm vectors and treating hypernetwork outputs as additive changes to learnable primary network parameters. This removes the proportionality dependency while preserving model expressiveness.

Experimental results across multiple tasks (Bayesian neural networks, medical image registration, and adaptive model resizing) demonstrate that MIP consistently stabilizes training, accelerates convergence, and improves final accuracy compared to default hypernetwork formulations. The method works across different optimizers, activation functions, and hypernetwork architectures without introducing additional computational overhead.

## Method Summary
The Magnitude Invariant Parametrization (MIP) addresses hypernetwork training instability by normalizing input vectors to constant norm before processing through the hypernetwork. The hypernetwork output is then treated as an additive change to learnable primary network parameters rather than directly generating weights. This approach breaks the proportionality relationship between input magnitude and output weight scaling that causes optimization difficulties. The method preserves the expressiveness of hypernetworks while stabilizing training dynamics and accelerating convergence.

## Key Results
- MIP consistently stabilizes hypernetwork training across Bayesian neural networks, medical image registration, and adaptive model resizing tasks
- Training convergence is accelerated compared to default hypernetwork formulations
- Final accuracy is improved while maintaining model expressiveness
- Method works across different optimizers, activation functions, and hypernetwork architectures without computational overhead

## Why This Works (Mechanism)
The fundamental mechanism addresses a proportionality problem where input magnitude directly scales output weights in standard hypernetworks. When input magnitudes vary, gradients can explode or vanish, causing unstable optimization. By normalizing inputs to constant norm and using additive updates, MIP decouples input magnitude from weight scaling. This creates stable gradients that depend on the hypernetwork's ability to generate meaningful parameter changes rather than being overwhelmed by magnitude effects. The additive formulation also provides a natural regularization effect by preventing extreme weight values.

### Design Tradeoffs
- **Expressiveness vs Stability:** MIP trades some direct weight control for stable optimization
- **Normalization vs Information Loss:** Constant norm encoding may lose some magnitude information
- **Additive Updates vs Direct Generation:** Additive approach provides regularization but may limit extreme weight adjustments

### Failure Signatures
- Training instability when input magnitudes vary widely
- Slow convergence with standard hypernetwork formulations
- Gradient explosion or vanishing in early training stages
