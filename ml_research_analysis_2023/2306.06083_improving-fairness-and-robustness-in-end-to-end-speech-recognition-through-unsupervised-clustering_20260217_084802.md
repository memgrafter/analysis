# Improving Fairness and Robustness in End-to-End Speech Recognition through unsupervised clustering

## Quick Facts
- **arXiv ID:** 2306.06083
- **Source URL:** https://arxiv.org/abs/2306.06083
- **Reference count:** 0
- **Primary result:** Privacy-preserving clustering approach improves WER across all demographic groups, with largest gains for non-native speakers, Southern US accents, and elderly speakers

## Executive Summary
This paper addresses fairness challenges in ASR systems where performance varies across demographic and accent groups. The authors propose a novel approach that uses unsupervised clustering of training utterances based on speaker ID model embeddings, then uses the resulting cluster IDs as additional features during RNN-T model training. At inference, utterances are assigned an "unknown" cluster ID. Experiments on voice command and Casual Conversations datasets show this method improves WER across all demographic groups while preserving privacy by avoiding direct use of speaker embeddings.

## Method Summary
The method involves extracting utterance-level embeddings using a pre-trained speaker ID model (VoxCeleb-based), applying PCA for dimensionality reduction, and clustering with K-means to create cluster IDs. These cluster IDs are then fed as one-hot vectors to the RNN-T model encoder during training, with a 0.1 probability of using an "unknown" cluster ID. The approach uses 22K hours of public Facebook videos in English (expanded to 123K hours through data augmentation) for training, and evaluates on Voice Command and Casual Conversations datasets. The RNN-T model has 80M total parameters with a 20-layer Emformer encoder, LSTM predictor, and joiner.

## Key Results
- Improves WER across all demographic groups compared to baseline RNN-T
- Largest gains observed for non-native speakers, Southern US accents, and elderly speakers
- Preserves privacy by using cluster IDs instead of direct speaker embeddings
- Achieves 4.5% relative WER reduction on Voice Command dataset

## Why This Works (Mechanism)
The approach works by providing the ASR model with implicit information about speaker characteristics through cluster assignments, without exposing sensitive speaker identity information. By clustering similar speakers together and using these clusters as features during training, the model learns to better handle variations in accent, age, and other demographic factors. The "unknown" cluster ID at inference forces the model to generalize to unseen speaker patterns.

## Architecture Onboarding

**Component Map**: Training Data → Speaker ID Model → PCA → K-means → Cluster IDs → RNN-T Encoder → Output

**Critical Path**: Speaker ID Model → K-means Clustering → RNN-T Training → Inference with "unknown" cluster ID

**Design Tradeoffs**: The method balances privacy preservation with fairness improvement by using cluster IDs instead of raw embeddings, but requires additional computational overhead for clustering and careful tuning of cluster numbers.

**Failure Signatures**: Poor clustering quality due to insufficient domain adaptation of speaker ID model, leading to ineffective fairness improvements; overfitting to training clusters causing poor generalization at inference.

## Limitations
- Privacy analysis is limited; clustering process may still retain identifiable patterns that could be reverse-engineered
- Small sample sizes for certain demographic groups make it difficult to assess statistical significance of improvements
- Method adds computational overhead and complexity to training pipeline without clear guidance on optimal cluster numbers

## Confidence

**High Confidence**: Technical implementation of feeding cluster IDs as features is straightforward and well-specified; use of publicly available datasets provides reasonable reproducibility

**Medium Confidence**: Reported WER improvements are promising but small sample sizes for certain groups make statistical significance uncertain; assumption about "unknown" cluster ID generalization needs validation

**Low Confidence**: Privacy-preserving claims lack thorough validation; clustering may inadvertently create identifiable patterns; method's robustness to adversarial inference attempts is unexplored

## Next Checks

1. Perform statistical significance testing (t-tests or bootstrap confidence intervals) on WER improvements for each demographic group
2. Conduct formal privacy audit by attempting to reconstruct speaker identities from cluster assignments or evaluating vulnerability to membership inference attacks
3. Evaluate method on additional datasets with diverse accents, languages, and recording conditions to assess broader generalization
