# Emotional Expression Detection in Spoken Language Employing Machine Learning Algorithms

## Quick Facts
- arXiv ID: 2304.11040
- Source URL: https://arxiv.org/abs/2304.11040
- Reference count: 30
- SVM achieves highest accuracy: 67.7% on test data, 77.7% on training data

## Executive Summary
This paper presents a speech emotion recognition system that identifies seven emotions from spoken language using machine learning algorithms. The approach employs Empirical Mode Decomposition (EMD) for signal decomposition and extracts 66 sub-features across 14 feature types. Four machine learning models—SVM, Neural Network, Ensemble, and KNN—are trained on combined CREMA-D and TESS datasets containing 10,242 audio samples. The SVM model achieves the highest accuracy of 67.7% on test data and 77.7% on training data, demonstrating the effectiveness of the proposed method for emotional expression detection.

## Method Summary
The method uses EMD to decompose non-linear, non-stationary speech signals into intrinsic mode functions (IMFs) that preserve temporal resolution. Following decomposition, 66 sub-features are extracted across 14 feature types including MFCC, GTCC, spectral descriptors, and harmonicity metrics. The mean and variance of these features are calculated for each audio sample. Four machine learning models (SVM, Neural Network, Ensemble, and KNN) are trained on the combined CREMA-D and TESS datasets with an 80/20 train-test split. The SVM model with RBF kernel achieves the highest accuracy, outperforming other models in both training and test scenarios.

## Key Results
- SVM achieves highest accuracy: 67.7% on test data and 77.7% on training data
- Ensemble model shows severe overfitting: 99.1% training accuracy vs 61.6% test accuracy
- Accuracy improves when reducing emotion classes from 7 to 4 emotions

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** EMD improves emotion classification by decomposing speech signals into scale-specific components
- **Mechanism:** EMD recursively extracts IMFs through sifting algorithm, producing AM/FM modulated components that isolate signal variations at different scales
- **Core assumption:** Emotional content manifests in distinct oscillatory modes separable by sifting process
- **Evidence anchors:** EMD utilization stated in abstract and section; sifting algorithm described in [15]
- **Break condition:** If emotional cues are not scale-specific or mode mixing occurs, EMD could degrade features

### Mechanism 2
- **Claim:** Multi-domain feature fusion captures complementary acoustic cues for emotion
- **Mechanism:** MFCC/GTCC capture spectral envelope, spectral descriptors quantify timbre, periodicity/harmonicity measure voice quality; combined representation is more discriminative
- **Core assumption:** Emotional states map to distinct patterns across multiple acoustic dimensions
- **Evidence anchors:** Feature extraction techniques listed in abstract; mean/variance evaluation mentioned in section
- **Break condition:** If feature redundancy outweighs complementarity, performance plateaus or degrades

### Mechanism 3
- **Claim:** SVM achieves highest accuracy due to effective handling of high-dimensional feature spaces
- **Mechanism:** SVM finds hyperplane maximizing margin between emotion classes; kernel functions map data to higher dimensions for linear separability
- **Core assumption:** Emotional classes are linearly separable (or kernel-mappable) in feature space
- **Evidence anchors:** SVM accuracy results stated in abstract; pattern recognition application mentioned in section
- **Break condition:** If decision boundary is highly non-linear and kernel choice is suboptimal, SVM accuracy may fall below other models

## Foundational Learning

- **Concept:** Empirical Mode Decomposition and sifting algorithm
  - **Why needed here:** EMD is the first processing step; understanding iterative maxima/minima envelope extraction is critical for interpreting temporal localization
  - **Quick check question:** What is the stopping criterion for the sifting process in EMD?

- **Concept:** Mel-Frequency Cepstral Coefficients and Gammatone Cepstral Coefficients
  - **Why needed here:** These form bulk of 66 sub-features; knowing their computation (windowing, filterbank, DCT) is essential for debugging feature extraction
  - **Quick check question:** How does the GT filterbank differ from the MF filterbank in terms of bandwidth modeling?

- **Concept:** Multi-class classification evaluation (accuracy, confusion matrix)
  - **Why needed here:** Results report accuracy per class and confusion matrices; understanding TP/FP/TN/FN for 7 emotions is key to interpreting performance gaps
  - **Quick check question:** If class "neutral" has high false negatives, what acoustic feature might be ambiguous?

## Architecture Onboarding

- **Component map:** Load audio -> EMD decomposition -> IMFs -> feature extraction (14 types, 66 sub-features) -> mean/variance calculation -> train/test split (80/20) -> classifier (SVM, NN, Ensemble, KNN) -> evaluate -> iterate features/classes

- **Critical path:** Load audio → EMD → feature extraction → train/test split → classifier → evaluate → iterate features/classes

- **Design tradeoffs:**
  - Feature richness vs. overfitting: 66 features on 8,194 training samples may risk overfitting (SVM training accuracy 77.7%, test 67.7%)
  - Class balance vs. accuracy: 7 emotions unevenly represented; reducing classes improves accuracy
  - Model complexity vs. generalization: Ensemble achieves 99.1% training accuracy but only 61.6% test accuracy (severe overfitting)

- **Failure signatures:**
  - Large train-test accuracy gap → overfitting (e.g., Ensemble 99.1% vs 61.6%)
  - Uniform confusion across multiple classes → feature space insufficiently discriminative
  - Low accuracy on specific emotions (e.g., pleasant surprise) → class imbalance or feature inadequacy

- **First 3 experiments:**
  1. **Feature ablation:** Remove spectral descriptors and retrain SVM; compare accuracy drop
  2. **Class reduction:** Retrain SVM on 4 emotions (anger, happy, neutral, sad); report test accuracy
  3. **Cross-validation:** Apply 5-fold CV on full feature set; measure variance in accuracy across folds
