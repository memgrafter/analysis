# On tracking varying bounds when forecasting bounded time series
## Quick Facts
- arXiv ID: 2306.13428
- Source URL: https://arxiv.org/abs/2306.13428
- Reference count: 8
- New framework for forecasting bounded time series with time-varying unobserved bounds using generalized logit-normal distributions

## Executive Summary
This paper addresses the challenge of forecasting bounded time series where the bounds themselves vary over time and are unobserved. The authors propose a novel framework that treats the upper bound as a time-varying parameter within a generalized logit-normal distribution model. Three estimation algorithms are developed: batch Normalized Gradient Descent, recursive Maximum Likelihood Estimation, and Online Normalized Gradient Descent. The approach is validated on both synthetic data and real wind power data, demonstrating significant improvements in probabilistic forecasting accuracy.

## Method Summary
The authors develop a framework for forecasting bounded time series with time-varying, unobserved bounds. They model the data using a generalized logit-normal distribution where the upper bound is treated as a time-varying parameter. An extended log-likelihood function is constructed that incorporates this varying bound. Three estimation algorithms are proposed: a batch Normalized Gradient Descent (NGD) approach that processes data in chunks, a recursive Maximum Likelihood Estimation (rMLE) method that updates estimates sequentially, and an Online Normalized Gradient Descent (ONGD) algorithm that combines online learning with gradient descent. The ONGD algorithm performs best in experiments, achieving a 32% reduction in Continuous Ranked Probability Score (CRPS) compared to probabilistic persistence on real wind power data.

## Key Results
- ONGD algorithm achieves 32% CRPS reduction versus probabilistic persistence on real wind power data
- Framework successfully tracks varying bound parameter in both synthetic and real data experiments
- Synthetic data results show ONGD closely matches ideal forecaster performance
- Calibration issues remain despite strong overall performance

## Why This Works (Mechanism)
The framework succeeds by explicitly modeling the varying upper bound as a learnable parameter within a probabilistic distribution. By treating the bound as unknown but smooth, the extended log-likelihood function can simultaneously estimate both the bound trajectory and the distribution parameters. The online learning approach with normalized gradient descent enables efficient tracking of bound changes while maintaining computational tractability. The normalization helps stabilize the gradient updates when dealing with the bounded nature of the data.
