# Augmenting Hessians with Inter-Layer Dependencies for Mixed-Precision Post-Training Quantization

## Quick Facts
- arXiv ID: 2306.04879
- Source URL: https://arxiv.org/abs/2306.04879
- Reference count: 40
- Primary result: Proposed augmented Hessian metric with inter-layer dependencies improves accuracy-latency trade-off in mixed-precision PTQ

## Executive Summary
This paper addresses the limitations of traditional Hessian-based layer sensitivity metrics for mixed-precision post-training quantization by introducing an augmented Hessian metric that incorporates inter-layer dependencies. The authors demonstrate that pure layer-wise Hessian sensitivity fails to capture the full picture of quantization impact, particularly for layers that interact strongly with others during inference. Their augmented metric combines second-order curvature information with pairwise layer quantization effects, using this to guide a bisection search algorithm for optimal bit-width assignment. The method achieves significant latency reductions (25.48% on ResNet50, 21.69% on MobileNetV2, and 33.28% on BERT) while maintaining accuracy within 99.99% of the original model.

## Method Summary
The proposed method consists of three main components: (1) computing an augmented Hessian sensitivity metric that combines layer-wise Hessian traces with pairwise inter-layer quantization effects, (2) sorting layers based on this metric, and (3) using a bisection search algorithm to determine optimal bit-width assignments for each layer. The augmented sensitivity is calculated as E_AugHessian = E_Hessian + βE_InterLayer, where the inter-layer component is estimated by directly quantizing pairs of layers and measuring accuracy degradation. The bisection search uses this ordering to efficiently find the quantization configuration that meets accuracy targets while minimizing latency. Weight quantization uses fine-grained CASE minimization, while activation quantization uses percentile-based calibration.

## Key Results
- Achieved 25.48% latency reduction on ResNet50 compared to 16-bit baseline while maintaining 99.99% accuracy
- Achieved 21.69% latency reduction on MobileNetV2 with minimal accuracy loss
- Achieved 33.28% latency reduction on BERT model, demonstrating effectiveness across CNN and Transformer architectures

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hessian-based layer sensitivity metrics alone fail to capture inter-layer dependencies that significantly impact quantization accuracy.
- Mechanism: The authors augment the layer-wise Hessian sensitivity with pairwise layer quantization interactions to better estimate true sensitivity ordering.
- Core assumption: The interaction between quantized layers has a measurable impact on overall model accuracy that cannot be captured by individual layer sensitivity alone.
- Evidence anchors:
  - [abstract] "Previous works rely on layer-wise Hessian information to determine numerical precision, but as we demonstrate, Hessian estimation is typically insufficient in determining an effective ordering of layer sensitivities."
  - [section 3.2] "Since assuming layer-wise independence does not produce an accurate ordering of the final per-layer sensitivity, we augment our sensitivity metric by estimating pairwise-layer sensitivities."

### Mechanism 2
- Claim: A guided bisection search using augmented sensitivity metrics efficiently finds optimal quantization configurations.
- Mechanism: The augmented Hessian sensitivity is used to sort layers, then a bisection search iteratively determines the sensitivity threshold for each bit-width level.
- Core assumption: The augmented sensitivity metric provides a sufficiently accurate ordering to enable efficient bisection search convergence.
- Evidence anchors:
  - [section 3.3] "We use a bisection method to determine the quantization configuration with O(b log N) model evaluations."
  - [section 4] "Our method delivers competitive model latency and model compression while exceeding the accuracy delivered by other techniques."

### Mechanism 3
- Claim: Combining second-order information (Hessian traces) with pairwise layer interactions provides superior guidance for quantization search.
- Mechanism: The final augmented Hessian metric E_AugHessian = E_Hessian + βE_InterLayer combines both individual layer curvature and inter-layer quantization effects.
- Core assumption: Both second-order information and inter-layer dependencies contribute meaningfully to quantization sensitivity and can be combined linearly.
- Evidence anchors:
  - [section 3.2] "We then normalize and scale E_InterLayer to combine it with the E_Hessian as: E_AugHessian = E_Hessian + βE_InterLayer"
  - [section 4] "The augmented Hessian sensitivity metric consistently improves upon model latency compared to the pure Hessian metric."

## Limitations

- The computational cost of estimating pairwise inter-layer dependencies requires O(N²) additional model evaluations, making the method potentially expensive for very deep networks.
- The combining coefficient β between Hessian and inter-layer components is fixed without systematic exploration of optimal values across different architectures.
- The paper lacks detailed runtime analysis comparing the augmented approach to pure Hessian methods, making practical scalability assessment difficult.

## Confidence

- **High confidence**: The core observation that layer-wise Hessian sensitivity alone is insufficient for accurate quantization ordering is well-supported by the empirical results showing progressive search outperforms Hessian-based methods.
- **Medium confidence**: The effectiveness of the augmented Hessian metric in consistently improving accuracy-latency tradeoffs across different architectures (CNNs and Transformers) is demonstrated, but the specific contribution of inter-layer dependencies versus improved search methodology is not fully isolated.
- **Low confidence**: The claim that this method delivers "state-of-the-art" results is difficult to verify given the lack of comparison with the most recent PTQ methods in the literature.

## Next Checks

1. **Runtime Overhead Analysis**: Measure and compare the total computation time of the augmented Hessian method versus pure Hessian and progressive search baselines, including all pairwise dependency evaluations, to quantify the practical cost of the improvement.

2. **Ablation on Inter-layer Component**: Implement a variant that uses only inter-layer dependencies (without Hessian traces) to quantify the relative contribution of each component to the final performance, helping to identify if the Hessian component is actually necessary.

3. **Sensitivity to β Parameter**: Systematically vary the combining coefficient β across a wide range (0 to 1) on multiple architectures to determine if the optimal value is consistent or architecture-dependent, and whether the current fixed choice is near-optimal.
