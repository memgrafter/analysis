# Efficient Robustness Assessment via Adversarial Spatial-Temporal Focus on Videos

## Quick Facts
- arXiv ID: 2301.00896
- Source URL: https://arxiv.org/abs/2301.00896
- Reference count: 40
- This paper presents a new query-based black-box adversarial attack method for video recognition models, which jointly reduces temporal and spatial redundancy in the video to achieve efficient gradient estimation.

## Executive Summary
This paper introduces AstFocus, a novel black-box adversarial attack method for video recognition models that leverages a cooperative Multi-Agent Reinforcement Learning (MARL) framework. By jointly selecting key frames and key regions, AstFocus reduces the search space for gradient estimation, significantly improving attack efficiency. The method demonstrates superior performance in terms of fooling rate, query number, and perturbation magnitude compared to state-of-the-art approaches.

## Method Summary
AstFocus employs a cooperative MARL framework with two specialized agents: a temporal agent for selecting key frames and a spatial agent for selecting key regions within frames. These agents are jointly trained using common rewards from the threat model, enabling coordinated selection that captures cross-domain dependencies. The method integrates NES gradient estimation for black-box attack and is tested on UCF-101, HMDB-51, and Kinetics-400 datasets using C3D, TSN, TSM, and SlowFast models.

## Key Results
- Achieves at least 10% reduction in query number compared to state-of-the-art methods
- Improves fooling rate by at least 10% with the smallest perturbations
- Outperforms existing methods in terms of time and perturbation magnitude

- Claim: The cooperative MARL framework reduces query cost by focusing on key frames and regions rather than full video space.
- Mechanism: Two agents—temporal and spatial—are jointly trained to select sparse but discriminative subsets of frames and patches. This reduces the gradient estimation space from full video dimensions to a much smaller set of selected elements, lowering the number of required queries.
- Core assumption: The threat model's prediction can be reliably attacked by perturbing only the selected key frames and regions, without significant loss in attack success.

## Architecture Onboarding

- Component map:
  - Input: Full video frames (M frames × H × W × 3)
  - Temporal Agent: Selects key frames (binary mask of size M)
  - Spatial Agent: Selects patches within each frame (indices per frame)
  - Policy Networks: LSTM-based networks for each agent
  - Reward Functions: Common reward (model confidence drop) + spatial-specific (edgebox) + temporal-specific (sparse + representative)
  - NES Gradient Estimator: Estimates gradients on reduced video space
  - PGD Attack Loop: Iteratively applies perturbations and updates agents
- Critical path:
  1. Extract frame-level features via lightweight CNN (e.g., MobileNet V2)
  2. Run temporal and spatial policy networks to get selections
  3. Reduce video to key frames and patches
  4. Apply NES to estimate gradients on reduced space
  5. Update adversarial video and agents based on rewards
  6. Repeat until success or max iterations
- Design tradeoffs:
  - Patch size vs. spatial coverage: Larger patches reduce dimensions but may miss fine details
  - Number of key frames vs. attack success: Fewer frames reduce queries but may lower attack effectiveness
  - Reward weights vs. agent behavior: Balancing common vs. specific rewards affects coordination
- Failure signatures:
  - Agents converge to trivial solutions (e.g., always selecting the same frames/patches)
  - High variance in reward signals leading to unstable training
  - Gradient estimation quality drops due to overly aggressive dimensionality reduction
- First 3 experiments:
  1. Baseline test: Run PGD+NES on full video, record query number and attack success rate
  2. Single-agent test: Apply only temporal or spatial agent, compare efficiency vs. baseline
  3. Joint-agent test: Run full AstFocus, measure query reduction and attack success vs. both single-agent and baseline
