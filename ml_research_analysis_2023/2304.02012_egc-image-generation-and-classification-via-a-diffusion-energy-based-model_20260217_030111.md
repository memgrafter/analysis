# EGC: Image Generation and Classification via a Diffusion Energy-Based Model

## Quick Facts
- arXiv ID: 2304.02012
- Source URL: https://arxiv.org/abs/2304.02012
- Reference count: 40
- Primary result: First model to achieve strong performance in both image classification and generation using a single neural network

## Executive Summary
This paper introduces EGC (Energy-based Generative Classifier), a unified framework that achieves strong performance in both image classification and generation using a single neural network. The key innovation is reinterpreting a standard classifier as an energy-based model that jointly models the distribution of noisy images and labels, enabling image generation in the backward pass via denoising with a score function. EGC achieves competitive generation results compared to state-of-the-art approaches on ImageNet-1k, CelebA-HQ, and LSUN Church, while obtaining superior classification accuracy (95.9%) and robustness against adversarial attacks on CIFAR-10.

## Method Summary
EGC models the joint distribution p(x,y) in its forward pass using a classifier that outputs logits, while the backward pass performs image generation by estimating unconditional and conditional scores. The model uses a UNet architecture with attention pooling, trained with a diffusion process that populates low data density regions to improve score estimation accuracy. The training objective combines Fisher divergence for unconditional score estimation with cross-entropy loss for classification guidance, balanced by a hyperparameter γ. The diffusion process gradually adds Gaussian noise through a Markov chain, and generation occurs through reverse denoising using estimated scores and classifier guidance.

## Key Results
- Achieves 95.9% classification accuracy on CIFAR-10, outperforming standard classifiers
- Competitive generation performance with state-of-the-art diffusion models on ImageNet-1k, CelebA-HQ, and LSUN Church
- Superior robustness against adversarial attacks (FGSM and PGD) compared to baseline classifiers
- First successful demonstration of excelling in both classification and generation tasks using a single set of network parameters

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The joint distribution modeling p(x,y) enables unified classification and generation by leveraging gradient information from both tasks.
- Mechanism: The forward pass estimates p(x,y) as an energy-based model where the neural network outputs logits for each class. The backward pass computes gradients that serve dual purposes: unconditional score ∇xlogp(x) for denoising and conditional guidance ∇xlogp(y|x) for class-specific generation.
- Core assumption: The neural network can effectively approximate both the energy function and its gradients, enabling stable denoising without requiring explicit MCMC sampling.
- Evidence anchors:
  - [abstract] "the forward pass in EGC is a classifier that outputs a joint distribution p(x,y), enabling an image generator in its backward pass by marginalizing out the label y"
  - [section 3.2] "the backward pass of the neural network is a generation model to predict the score and classifier guidance to gradually denoise data"
  - [corpus] Weak evidence for this specific dual-use mechanism; most related work treats classification and generation separately

### Mechanism 2
- Claim: Diffusion process populates low data density regions, improving score estimation accuracy and generation stability.
- Mechanism: The forward diffusion process gradually adds Gaussian noise to images through a Markov chain, creating a smooth transition from data distribution to noise distribution. This populates regions where data density is low, making the score function more accurate across the entire space.
- Core assumption: The score function estimated at multiple noise levels captures the underlying data structure sufficiently well to enable stable reverse denoising.
- Evidence anchors:
  - [abstract] "populating low data density regions to improve the accuracy of estimated scores, resulting in stable training and image sampling"
  - [section 3.1] "Diffusion models gradually inject noise into the source samples during the noising process"
  - [corpus] Strong evidence from diffusion literature showing improved stability, though specific joint modeling claims are less supported

### Mechanism 3
- Claim: Optimizing Fisher divergence instead of direct likelihood circumvents the intractable partition function while maintaining effective density modeling.
- Mechanism: Rather than optimizing log p(x) directly which requires computing Z(θ), the model minimizes the Fisher divergence between q(xt|x0) and pθ(xt), which depends only on the score ∇xlogpθ(x) = ∇xfθ(x).
- Core assumption: The score matching objective provides a tractable alternative to maximum likelihood that still leads to accurate density estimation.
- Evidence anchors:
  - [section 3.1] "Compared with directly optimizing the log-probability of EBM (Equation 3), Fisher divergence circumvents optimizing the normalized densities parameterized by Z(θ)"
  - [section 4.2] "We adopt the diffusion process to populate low data density regions and optimize the unconditional score using Fisher divergence"
  - [corpus] Strong theoretical support for score matching, but limited evidence for its effectiveness in this specific joint modeling context

## Architecture Onboarding

- Component map: Noisy image → UNet with attention pooling → logits → joint probability p(x,y) in forward pass; Gradients → unconditional score ∇xlogp(x) and conditional guidance ∇xlogp(y|x) → reverse denoising in backward pass
- Critical path: Forward pass (noisy image → logits → joint probability) → backward pass (gradient computation → denoising with guidance)
- Design tradeoffs: Using U-Net vs ResNet affects gradient propagation quality; more diffusion steps improve stability but increase computation; balancing reconstruction vs classification loss affects both tasks
- Failure signatures: Poor FID scores indicate generation issues; low classification accuracy indicates discriminative task problems; unstable training manifests as exploding gradients during backward pass
- First 3 experiments:
  1. Train EGC on CIFAR-10 with default hyperparameters and verify it achieves ~95% accuracy
  2. Test unconditional generation by running the backward pass with random noise and check FID
  3. Verify conditional generation by fixing class labels and checking semantic consistency in generated samples

## Limitations

- The dual-use mechanism for classification and generation is novel but lacks extensive empirical validation beyond reported results
- Limited exploration of how EGC performs across datasets with varying sizes and complexities
- Insufficient analysis of EGC's robustness against diverse attack types and model architectures

## Next Checks

1. **Gradient Stability Analysis**: Conduct ablation studies systematically varying the diffusion steps and noise schedules to quantify the impact on gradient stability during the backward pass. Measure gradient norms and check for exploding/vanishing gradients across different settings.

2. **Distribution Coverage Validation**: Compare the coverage of generated samples from EGC against standard diffusion models by measuring KL divergence between generated and real distributions across different noise levels. This would validate whether joint modeling truly populates low data density regions more effectively.

3. **Cross-Domain Generalization**: Evaluate EGC on datasets outside the standard vision benchmarks (e.g., medical imaging or satellite imagery) to test whether the unified approach generalizes beyond natural images, or whether it relies on specific characteristics of the benchmark datasets.
