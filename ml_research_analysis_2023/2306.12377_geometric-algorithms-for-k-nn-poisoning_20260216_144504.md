# Geometric Algorithms for $k$-NN Poisoning

## Quick Facts
- arXiv ID: 2306.12377
- Source URL: https://arxiv.org/abs/2306.12377
- Reference count: 21
- This paper introduces a geometric algorithm for label poisoning attacks on k-NN classifiers.

## Executive Summary
This paper presents a randomized algorithm that computes an εn-additive approximation of the optimal poisoning attack on k-NN classifiers in n·22O(d+k/ε) time for data sets in Rd. The algorithm uses multi-scale random partitions to divide the problem into smaller subproblems, solves each via brute-force enumeration, and combines results using dynamic programming. This approach provides the first provable bounds for label-flipping poisoning attacks against k-NN classifiers.

## Method Summary
The algorithm employs a multi-scale random partition scheme to cluster data points, then solves optimal poisoning subproblems for each cluster using brute-force enumeration. These cluster-level solutions are combined via dynamic programming to achieve a global solution that maximizes corruption while respecting the total poison budget. The approach relies on properties of Lipschitz functions and metric space partitions to ensure small expected corruption while maintaining provable approximation bounds.

## Key Results
- Achieves εn-additive approximation of optimal poisoning in n·22O(d+k/ε) time
- Provides provable guarantees on maximum achievable corruption under bounded perturbations
- Extends to settings with separate training and test sets
- First provable bounds for label-flipping poisoning attacks against k-NN

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The multi-scale random partition approach ensures small expected corruption while maintaining provable approximation bounds.
- Mechanism: The algorithm partitions the data into clusters using a multi-scale random partition scheme, where each cluster has bounded diameter relative to the k-th nearest neighbor distance. This enables solving smaller subproblems via brute-force enumeration and combining results via dynamic programming.
- Core assumption: The random partition guarantees that with high probability, the k nearest neighbors of any point remain in the same cluster, limiting the corruption impact.
- Evidence anchors: [abstract] The algorithm uses multi-scale random partitions to divide the problem into smaller subproblems; [section] Lemma 2 and Lemma 4 describe the multi-scale random partition construction and its properties; [corpus] Weak evidence - related work focuses on different poisoning approaches without similar geometric partitioning
- Break condition: If the Lipschitz constant of the distance function grows too quickly with dimension, the partition quality degrades and approximation guarantees fail.

### Mechanism 2
- Claim: The dynamic programming approach optimally combines local solutions from each cluster to achieve global approximation.
- Mechanism: After solving optimal poisoning subproblems for each cluster, the algorithm uses dynamic programming to combine these partial solutions, ensuring the overall solution respects the total poison budget while maximizing corruption.
- Core assumption: The corruption metric is additive across clusters when k-nearest neighbors are preserved within clusters.
- Evidence anchors: [section] The dynamic programming formula explicitly combines cluster-level solutions; [section] Lemma 6 proves the expected corruption bound using the additivity property; [corpus] No direct evidence in corpus - this appears to be the novel contribution
- Break condition: If points have k-nearest neighbors spanning multiple clusters, the additivity assumption breaks and the dynamic programming approach may overestimate achievable corruption.

### Mechanism 3
- Claim: The brute-force enumeration within clusters is computationally feasible due to the bounded cluster size guarantee.
- Mechanism: By Lemma 5, each cluster contains only O(k·hd) points, making brute-force enumeration of all possible poisonings computationally tractable for small clusters.
- Core assumption: The random partition ensures cluster sizes remain polynomial in k and the dimension d.
- Evidence anchors: [section] Lemma 5 provides the cluster size bound O(k·hd+O(1)); [section] The running time analysis in Theorem 1 relies on this bounded cluster size; [corpus] Weak evidence - related work doesn't discuss similar geometric enumeration approaches
- Break condition: If the dimension d or the ratio h grows too large, the cluster size becomes exponential and brute-force enumeration becomes infeasible.

## Architecture Onboarding

- Component map: Multi-scale random partition generator -> Cluster-level brute-force solver -> Dynamic programming combiner
- Critical path: The brute-force enumeration within clusters dominates the O(n·22O(d+k/ε)) runtime, making it the most time-consuming step.
- Design tradeoffs: The algorithm trades computational efficiency for provable approximation guarantees, with exponential dependence on d and k/ε inherent to the problem's complexity.
- Failure signatures: Algorithm may fail when clusters become too large, when k-nearest neighbors frequently cross cluster boundaries, or when the Lipschitz constant grows too quickly with dimension.

## Limitations
- Exponential dependence on dimension d and k/ε severely limits practical applicability to low-dimensional problems
- Algorithm relies heavily on specific metric space properties that may not generalize to all distance metrics
- Theoretical guarantees haven't been empirically validated on real-world datasets, particularly for higher dimensions or large k values
