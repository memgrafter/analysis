# Rethinking the Reasonability of the Test Set for Simultaneous Machine Translation

## Quick Facts
- arXiv ID: 2303.00969
- Source URL: https://arxiv.org/abs/2303.00969
- Reference count: 0
- The general full-sentence translation test set underestimates SimulMT performance, which is alleviated by manually annotated monotonic test set (SiMuST-C) and finetuning on automatically extracted monotonic training set.

## Executive Summary
Simultaneous machine translation (SimulMT) requires models to start translation before reading the full source sentence, producing monotonic translations aligned with the source stream. However, general full-sentence translation test sets often contain long-distance reordering that does not align with this monotonic nature, leading to underestimation of SimulMT performance. To address this, the authors manually annotate a monotonic test set (SiMuST-C) based on the MuST-C English-Chinese test set using a streaming annotation method. They also automatically extract a monotonic training set by selecting sentence pairs with zero anticipation (AA=0) and demonstrate that finetuning SimulMT models on this data improves performance by up to 3 BLEU points on their annotated test set.

## Method Summary
The authors address the underestimation problem in SimulMT evaluation by creating a monotonic test set through manual streaming annotation of the MuST-C English-Chinese test set. Annotators perform READ/WRITE actions at each step, ensuring the target stream is monotonically aligned with the source. They also extract a monotonic training corpus by selecting sentence pairs with zero anticipation (AA=0) using SimAlign, then finetune SimulMT models on this data. The approach is evaluated on three different SimulMT models (Wait-k, GMA, and Re-trans) using metrics including BLEU-Orig, BLEU-Mono, BLEU-Stream, AL, NE, and human acceptability scores.

## Key Results
- Manual streaming annotation of MuST-C test set creates SiMuST-C, alleviating underestimation of SimulMT performance
- Finetuning on automatically extracted monotonic training set improves SimulMT models by up to 3 BLEU points
- Evaluations on three different SimulMT models verify the effectiveness of the proposed approach

## Why This Works (Mechanism)

### Mechanism 1
- Claim: General full-sentence test sets underestimate SimulMT performance because they contain long-distance reordering that does not align with the monotonic nature of streaming translations.
- Mechanism: SimulMT models must translate before reading the full source sentence, producing monotonic translations. When evaluated on test sets with long-distance reordering (e.g., "worldwide" appearing at the end of the sentence), BLEU scores are artificially low because the model's monotonic output does not match the reference's reordered structure.
- Core assumption: Monotonic translation is a necessary constraint for SimulMT due to limited source information during streaming.

### Mechanism 2
- Claim: Manual streaming annotation creates test sets that better reflect SimulMT capabilities by capturing the monotonic nature of the translations.
- Mechanism: Annotators perform streaming annotation, choosing READ or WRITE actions at each step, ensuring the target stream is monotonically aligned with the source. This produces references that match the expected output of SimulMT models, reducing the gap between reference and model output.
- Core assumption: Human annotators can produce high-quality monotonic translations when constrained to streaming conditions.
- Evidence anchors:

### Mechanism 3
- Claim: Finetuning on automatically extracted monotonic training data improves SimulMT model performance on monotonic test sets.
- Mechanism: The monotonic corpus is created by selecting sentence pairs with zero anticipation (AA=0), meaning no target words are aligned with unseen source words. Training on this data encourages models to learn monotonic translation patterns, improving performance on streaming test sets.
- Core assumption: Models can learn to prioritize monotonicity when trained on data that enforces this constraint.

## Architecture Onboarding

- Component map: MuST-C dataset -> Streaming annotation -> SiMuST-C test set -> Automatic extraction of monotonic training pairs (AA=0) -> Finetuning SimulMT models -> Improved evaluation on SiMuST-C
- Critical path: Data annotation -> Model evaluation on SiMuST-C -> Monotonic corpus extraction -> Model finetuning -> Improved evaluation on SiMuST-C
- Design tradeoffs:
  - Manual vs. automatic annotation: Manual annotation ensures high-quality monotonic references but is time-consuming and potentially expensive.
  - Monotonic vs. non-monotonic training: Monotonic training improves streaming performance but may reduce quality on offline translation tasks.
  - Evaluation metrics: BLEU captures translation quality but may not fully reflect SimulMT-specific characteristics like latency and stability.
- Failure signatures:
  - Low human acceptability scores despite high BLEU: Indicates the test set may still contain non-monotonic elements or the model is overfitting to specific patterns.
  - No improvement after finetuning on monotonic corpus: Suggests the corpus may not be representative or the model architecture is not well-suited for monotonic translation.
  - High AL scores on SiMuST-C: May indicate the model is not effectively learning to translate with low latency, despite the monotonic nature of the test set.
- First 3 experiments:
  1. Evaluate existing SimulMT models on SiMuST-C to confirm the reduction in underestimation compared to MuST-C.
  2. Extract monotonic corpus from training data and perform finetuning on Wait-k model, measuring improvement on SiMuST-C.
  3. Compare human evaluation results with automatic metrics (BLEU, AL, NE) on SiMuST-C to validate the test set's effectiveness.

## Limitations
- The SiMuST-C test set contains only 200 sentence pairs, which may not fully represent the diversity of the original MuST-C test set.
- The streaming annotation process relies heavily on human judgment to determine READ/WRITE actions, with uncertainty about annotation consistency.
- The automatic monotonic corpus extraction method uses a strict AA=0 threshold, potentially limiting the size and diversity of the finetuning corpus.

## Confidence
- High Confidence: The core claim that general full-sentence test sets underestimate SimulMT performance due to monotonic alignment requirements.
- Medium Confidence: The effectiveness of the streaming annotation method in creating high-quality monotonic references.
- Medium Confidence: The claim that finetuning on automatically extracted monotonic training data improves SimulMT performance by up to 3 BLEU points.
