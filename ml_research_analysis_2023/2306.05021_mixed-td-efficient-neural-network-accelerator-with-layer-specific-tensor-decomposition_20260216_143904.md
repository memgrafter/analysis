# Mixed-TD: Efficient Neural Network Accelerator with Layer-Specific Tensor Decomposition

## Quick Facts
- arXiv ID: 2306.05021
- Source URL: https://arxiv.org/abs/2306.05021
- Reference count: 30
- Key outcome: Layer-specific tensor decomposition method combining SVD and CPD achieves 69.1% top-1 accuracy on ResNet-18 with 35 Mb memory footprint and 1041 FPS throughput on FPGA.

## Executive Summary
This paper presents Mixed-TD, a method for efficiently deploying convolutional neural networks on FPGAs with limited on-chip memory. The approach uses layer-specific tensor decomposition combining Singular Value Decomposition (SVD) and Canonical Polyadic Decomposition (CPD) to compress CNN weights while maintaining accuracy. An evolutionary search algorithm with a random forest throughput predictor explores the vast design space to find optimal decomposition parameters. The method achieves competitive accuracy with significantly improved throughput per DSP compared to state-of-the-art sparsity and quantization methods.

## Method Summary
Mixed-TD applies layer-specific SVD and CPD decompositions to compress CNN weights, enabling deployment on memory-limited FPGAs. The method formulates an optimization problem to maximize accuracy under resource and throughput constraints, then solves it via evolutionary search enhanced by a random forest throughput predictor. For each convolutional layer, the 4-D weight tensor can be decomposed either in SVD or CPD format, with channel grouping enabling finer-grained compression. The compressed weights are then mapped to a dataflow accelerator architecture with dedicated hardware for each layer, using configurable unrolling factors to optimize throughput.

## Key Results
- Achieves 69.1% and 71.5% top-1 accuracy on ResNet-18 and RepVGG-A0 respectively
- 35 Mb memory footprint for compressed weights
- 1041 FPS and 1162 FPS throughput on AMD Alveo U250 FPGA
- 1.73× to 10.29× improvement in FPS per DSP compared to sparsity and quantization methods
- 150× acceleration in search convergence using random forest predictor vs full optimization

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Layer-specific mixing of SVD and CPD enables higher compression with lower accuracy loss than using either method alone.
- Mechanism: SVD compresses 2nd-order tensors more efficiently, while CPD handles higher-order tensors without reshaping. By choosing the optimal decomposition per layer, the method adapts to varying redundancy across the network.
- Core assumption: Each layer's weight tensor has a different optimal decomposition format (SVD vs. CPD) based on its internal structure and redundancy.
- Evidence anchors:
  - [abstract]: "Mixed-TD method applies layer-specific Singular Value Decomposition (SVD) and Canonical Polyadic Decomposition (CPD) in a mixed manner."
  - [section]: "In the proposed Mixed-TD method, there are three types of layer-specific design choices. SVD or CPD: For each convolutional layer, its 4-d weight tensor can be decomposed either in SVD or CPD format."

### Mechanism 2
- Claim: Evolutionary search with random forest predictor accelerates design space exploration by 150x compared to full optimization.
- Mechanism: The evolutionary algorithm explores the vast design space of decomposition parameters, while the random forest predictor estimates throughput without expensive hardware synthesis, allowing rapid convergence to optimal designs.
- Core assumption: Throughput can be accurately predicted from network characteristics and decomposition choices without full hardware mapping.
- Evidence anchors:
  - [abstract]: "Our work is open-sourced: https://github.com/Yu-Zhewen/Mixed-TD"
  - [section]: "The paper proposes building a proxy that predicts the achievable throughput for a specific configuration based on network characteristics and the optimizer used. For this purpose, a random forest was selected as the proxy model."

### Mechanism 3
- Claim: Channel grouping in tensor decomposition enables finer-grained compression while maintaining computational efficiency.
- Mechanism: By splitting weight tensors along channel dimensions before decomposition, the method can apply different compression rates to different channel groups, exploiting channel-wise redundancy variations.
- Core assumption: Different channel groups within a layer have varying levels of redundancy that can be exploited independently.
- Evidence anchors:
  - [section]: "Instead of directly applying the tensor decomposition to the entire Wj, we can choose to slice and split Wj into multiple chunks where each chuck can then be decomposed individually."

## Architecture Onboarding

- Component map: Input buffer -> MAC units -> Accumulation module -> Next layer
- Critical path: Input buffer → MAC units → Accumulation module → Next layer
- Design tradeoffs:
  - SVD vs CPD: SVD has fewer computation stages but requires reshaping; CPD handles higher-order tensors directly but has more stages
  - Unrolling factors: Higher unrolling increases throughput but also resource usage
  - Channel grouping: Enables finer compression but adds complexity to data movement
- Failure signatures:
  - Low throughput: Check if unrolling factors are optimally configured or if resource constraints are limiting performance
  - High accuracy loss: Verify that decomposition ranks are sufficiently high or that the wrong decomposition method was chosen for certain layers
  - Memory overflow: Check if channel grouping or decomposition ranks are creating tensors larger than on-chip memory

  1. Implement SVD-only decomposition on ResNet-18 and measure accuracy and resource usage
  2. Add channel grouping to the SVD implementation and compare compression ratios
  3. Implement CPD-only decomposition and compare against SVD results to identify which layers benefit from each method

## Limitations

## Confidence

**High Confidence:** The core mechanism of layer-specific tensor decomposition combining SVD and CPD is mathematically sound and the FPGA dataflow architecture is well-established. The reported accuracy degradation of approximately 0.4 percentage points on ImageNet is consistent with typical compression trade-offs.

**Medium Confidence:** The claimed 1.73× to 10.29× improvement in FPS per DSP over sparsity and quantization methods is based on synthesis results, but the comparison methodology is not fully transparent. The evaluation only benchmarks against a limited set of baselines without comprehensive ablation studies.

**Low Confidence:** The generalizability of the evolutionary search approach to other network architectures (beyond ResNet-18 and RepVGG-A0) and different FPGA targets is not demonstrated. The random forest predictor's accuracy across diverse design spaces remains unverified.
