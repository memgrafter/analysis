# JOINEDTrans: Prior Guided Multi-task Transformer for Joint Optic Disc/Cup Segmentation and Fovea Detection

## Quick Facts
- **arXiv ID**: 2305.11504
- **Source URL**: https://arxiv.org/abs/2305.11504
- **Reference count**: 40
- **Primary result**: Achieves state-of-the-art performance in joint optic disc/cup segmentation and fovea detection using a vessel-guided transformer architecture with fewer parameters than competing models

## Executive Summary
JOINEDTrans introduces a multi-task transformer framework for simultaneous optic disc/cup segmentation and fovea detection in fundus images. The method leverages spatial priors from vessel segmentation through a pretrained encoder and employs a coarse-to-fine approach. The coarse stage performs joint segmentation and detection using a Swin-Transformer with vessel information, while the fine stage refines results using cropped regions. A novel star-shape loss function improves segmentation quality. The model demonstrates superior performance on three public datasets (GAMMA, REFUGE, PALM) compared to existing state-of-the-art methods.

## Method Summary
The JOINEDTrans framework addresses the challenge of joint optic disc/cup segmentation and fovea detection by incorporating vessel structure information as spatial priors. The method uses a pretrained encoder from vessel segmentation to provide anatomical context to the transformer backbone. A coarse-to-fine strategy is employed where the coarse stage performs joint segmentation and detection tasks simultaneously, followed by a fine stage that refines results on cropped regions around detected landmarks. The model introduces a star-shape loss function to improve the geometric quality of segmentations. The approach achieves high performance while maintaining parameter efficiency compared to other transformer-based methods.

## Key Results
- Achieves Dice scores of 0.9843 (optic disc) and 0.9059 (optic cup) on GAMMA dataset
- Demonstrates fovea detection with 16.57 pixels Euclidean distance on PALM dataset
- Outperforms state-of-the-art methods while requiring fewer parameters than other transformer-based approaches

## Why This Works (Mechanism)
The model's effectiveness stems from leveraging vessel structure as anatomical priors, which provides spatial context for both segmentation and detection tasks. The multi-task learning framework enables information sharing between related tasks, while the coarse-to-fine approach progressively refines predictions. The star-shape loss function specifically addresses the geometric characteristics of optic structures, improving segmentation quality beyond standard loss functions.

## Architecture Onboarding

**Component map**: Vessel Encoder -> Swin-Transformer Backbone -> Coarse Prediction -> Cropping Module -> Fine Prediction

**Critical path**: Image input → Vessel-encoder feature extraction → Swin-Transformer processing → Joint segmentation/detection → Coarse-to-fine refinement → Final outputs

**Design tradeoffs**: The coarse-to-fine approach adds computational overhead but improves accuracy; the vessel-encoder provides useful priors but may limit generalization to non-vessel-based applications

**Failure signatures**: Poor performance on images with abnormal vessel patterns, degraded accuracy with severe artifacts or low contrast, potential overfitting to vessel-specific patterns

**First experiments**: 1) Evaluate performance degradation when removing vessel encoder, 2) Test coarse stage performance in isolation to verify coarse-to-fine benefit, 3) Compare star-shape loss with standard BCE/Dice losses through ablation

## Limitations
- Performance evaluation limited to three public datasets which may not represent all clinical scenarios
- Coarse-to-fine approach introduces computational complexity that may limit real-time deployment
- Star-shape loss function contribution lacks extensive ablation studies for quantification
