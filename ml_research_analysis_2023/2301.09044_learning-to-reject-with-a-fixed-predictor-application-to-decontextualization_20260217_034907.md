# Learning to Reject with a Fixed Predictor: Application to Decontextualization

## Quick Facts
- **arXiv ID:** 2301.09044
- **Source URL:** https://arxiv.org/abs/2301.09044
- **Reference count:** 40
- **Primary result:** New surrogate loss function for rejector learning with a fixed predictor; achieves ~25% improvement in coverage when halving error rate on decontextualization task

## Executive Summary
This paper addresses the problem of learning when to reject a fixed predictor's output, focusing on natural language generation tasks where the full set of correct answers may be unknown. The key insight is that traditional rejection learning assumes access to all possible correct answers, which is impractical in many NLP settings. The authors introduce a novel surrogate loss function with an implicit threshold that enables efficient learning of a rejector given a pre-trained, fixed predictor, along with strong theoretical guarantees through H-consistency bounds.

## Method Summary
The method follows a two-step approach: first, a predictor f is trained on the main task using standard cross-entropy loss; second, a rejector r is learned using a new surrogate loss function that operates on manually-labeled binary acceptability judgments (a) for (x, f(x)) pairs. The surrogate loss ℓ₁(r, x, a) = e^(α/2)[r(x)−a] + c·e^(−βr(x)) is convex, differentiable, and includes an implicit threshold at zero, eliminating the need for separate threshold tuning. The theoretical contribution includes proving H-consistency under the condition 2βc/α = ¯I_c, showing that minimizing the surrogate loss directly minimizes the rejection loss. Experiments on decontextualization demonstrate significant improvements in precision-coverage trade-offs compared to confidence-based and cross-entropy baselines.

## Key Results
- Achieves ~25% improvement in coverage when halving the error rate on decontextualization task
- Comes within ~3% of the theoretical limit for rejection performance
- Outperforms MaxProb and cross-entropy baselines in both precision-coverage trade-offs and stability
- Demonstrates effectiveness with 2,000 manually-labeled examples through 4-fold cross-validation

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The surrogate loss has a built-in threshold at zero, so it directly optimizes for a specific precision without needing to fit an external threshold.
- **Mechanism:** The loss function ℓ₁(r, x, a) = e^(α/2)[r(x)−a] + c·e^(−βr(x)) is convex in r(x) and achieves its minimum at a value that naturally separates accept/reject decisions. By setting 2βc/α = ¯I_c, the optimal rejector r₀(x) aligns in sign with the Bayes optimal rejector r*(x), ensuring that the implicit threshold at zero coincides with the optimal decision boundary.
- **Core assumption:** The predictor f is fixed and produces binary labels a ∈ {−1, +1} indicating whether f(x) is in the set of acceptable outputs Ax,y.
- **Evidence anchors:**
  - [abstract] states that the surrogate loss includes an implicit threshold, eliminating the need for separate threshold tuning.
  - [section 4] shows that the surrogate loss upper-bounds the induced rejection loss and is convex and differentiable, with a built-in threshold at 0.
  - [corpus] evidence is weak here; related work focuses on multi-class abstention or cost-based rejection, not on fixed-predictor rejection with implicit thresholds.
- **Break condition:** If the predictor f is not fixed or the binary labeling a is unreliable, the alignment of signs between r₀(x) and r*(x) may fail, breaking the threshold property.

### Mechanism 2
- **Claim:** The surrogate loss is H-consistent, meaning excess surrogate loss bounds excess rejection loss, providing strong generalization guarantees.
- **Mechanism:** Using tools from Awasthi et al. (2022), the paper proves that minimizing the surrogate loss ℓ₁ over all measurable functions R_all yields an H-consistency bound: Rℓ₂(r) − R*ℓ₂ ≤ O(√ε) when Rℓ₁(r) − R*ℓ₁ ≤ ε. This is achieved by relating the calibration gaps ΔCℓ₁ and ΔCℓ₂ via a convex function Ψ, ensuring that reducing surrogate loss directly reduces rejection loss.
- **Core assumption:** The relation 2βc/α = ¯I_c holds, and the hypothesis set R is the family of all measurable functions R_all.
- **Evidence anchors:**
  - [abstract] mentions a strong H-consistency guarantee for the surrogate loss.
  - [section 5] provides the detailed proof, defining calibration gaps and showing that under the parameter relation, the excess rejection loss is bounded by O(√ε) in terms of excess surrogate loss.
  - [corpus] includes related work on consistency bounds for rejection learning, but not exactly matching the fixed-predictor scenario.
- **Break condition:** If the parameter relation 2βc/α = ¯I_c is violated or R is restricted (e.g., linear functions), the H-consistency bound may no longer hold.

### Mechanism 3
- **Claim:** The two-step learning method (learn f, then learn r) is necessary because the full set of correct labels is unknown, making joint optimization infeasible.
- **Mechanism:** First, a predictor f is learned using standard cross-entropy loss. Then, given f, a binary labeler a is created by manual annotation on held-out pairs (x, f(x)), indicating whether f(x) is acceptable. The rejector r is then trained on these (x, f(x), a) triples using the surrogate loss. This avoids needing all possible correct labels y for a given x.
- **Core assumption:** It is feasible to manually label a moderate-sized dataset of (x, f(x)) pairs to determine acceptability.
- **Evidence anchors:**
  - [section 1] explains that in NLP tasks like decontextualization, the full set of accurate outputs may be large and not available, motivating the two-step approach.
  - [section 3.2] describes the two-step method and the need for manual labeling of (x, f(x)) pairs.
  - [corpus] includes related work on rejection learning, but the specific two-step fixed-predictor setup is not directly evidenced.
- **Break condition:** If manual labeling is too costly or the predictor f changes, the binary labels a become invalid, breaking the two-step approach.

## Architecture Onboarding

- **Component map:**
  Predictor f -> Binary labeler a -> Rejector r

- **Critical path:**
  1. Pre-train or fix predictor f on the main task.
  2. Generate predictions f(x) for a held-out set of (x, y) pairs.
  3. Manually label each (x, f(x)) pair as acceptable (a=+1) or not (a=−1).
  4. Train rejector r using the surrogate loss ℓ₁ on the labeled (x, f(x), a) triples.
  5. Evaluate precision-coverage trade-off on validation data.

- **Design tradeoffs:**
  - Fixed vs. joint predictor/rejector: Fixed predictor simplifies the problem but requires manual labeling; joint optimization is more complex but avoids labeling.
  - Implicit vs. explicit threshold: Implicit threshold in surrogate loss simplifies training but requires careful parameter tuning (2βc/α = ¯I_c).
  - Manual labeling cost: Necessary for binary labels a, but costly; labeling 2,000 examples took significant effort.

- **Failure signatures:**
  - Poor precision-coverage trade-off: Indicates misalignment of signs between r₀(x) and r*(x), possibly due to incorrect parameter relation.
  - High variance in results: Suggests instability in manual labeling or insufficient training data.
  - Inability to reach theoretical limit: May indicate suboptimal predictor f or surrogate loss parameterization.

- **First 3 experiments:**
  1. Train predictor f on decontextualization task using cross-entropy loss; evaluate baseline precision-coverage without rejection.
  2. Manually label 100 (x, f(x)) pairs; train rejector r using surrogate loss; evaluate precision-coverage trade-off; compare to MaxProb baseline.
  3. Scale up to 2,000 labeled examples; perform 4-fold cross-validation; compare surrogate loss to cross-entropy loss and MaxProb across multiple precision levels.

## Limitations

- The method requires manual labeling of (x, f(x)) pairs to create binary acceptability judgments, which is costly and may not scale to very large datasets.
- Theoretical guarantees assume the full hypothesis class R_all, but practical implementations may use restricted function classes, potentially weakening the H-consistency bounds.
- Results are based on a single NLP task (decontextualization) with a specific model architecture (T5X), limiting generalizability to other tasks and models.

## Confidence

- **High Confidence:** The theoretical framework for H-consistency and the convex surrogate loss design. The proofs appear sound and the mathematical arguments are rigorous.
- **Medium Confidence:** The practical effectiveness of the method on decontextualization. While the reported results are strong, they are based on a single task and model.
- **Low Confidence:** The general applicability of the method to other NLP tasks and model architectures beyond T5X on decontextualization.
