# Correcting discount-factor mismatch in on-policy policy gradient methods

## Quick Facts
- **arXiv ID**: 2306.13284
- **Source URL**: https://arxiv.org/abs/2306.13284
- **Reference count**: 40
- **Primary result**: Proposes a novel averaging correction that integrates state information over trajectories to correct discount-factor mismatch bias in on-policy policy gradient methods

## Executive Summary
This paper addresses a fundamental bias in on-policy policy gradient methods where the state distribution used in gradient estimation ignores the discount factor. The authors derive an extended policy gradient theorem that includes an averaging correction term, which can be approximated through regression on a data buffer. Experimental results demonstrate that this correction consistently matches or exceeds the performance of uncorrected estimators across multiple benchmark tasks while reducing variance compared to existing solutions.

## Method Summary
The authors propose an averaging correction term that integrates state information over trajectories to correct the discount-factor mismatch bias. This correction is derived from an extended policy gradient theorem and approximated through a regression task where a neural network predicts γ^t given a state s. The method modifies existing on-policy algorithms (like PPO and BAC) to include this correction when sampling states from the undiscounted stationary distribution. Implementation involves collecting trajectories, updating the correction network via regression on a data buffer, then updating value and policy networks using the corrected gradient estimator.

## Key Results
- The averaging correction consistently matches or exceeds the performance of uncorrected estimators across OpenAI Gym and DeepMind suite benchmarks
- The correction demonstrates lower variance compared to existing γ^t correction methods
- The method effectively prevents degenerate policies in tasks with substantial discount-factor mismatch bias

- Claim: The averaging correction term provides an unbiased gradient estimate by matching the discounted state distribution
- Mechanism: The correction factor cπ(s) = E[τs+(s)]dπ,γ(s) exactly equals the ratio of discounted to undiscounted state distributions, correcting the state distribution mismatch
- Core assumption: The Markov chain is irreducible and all states are positive recurrent under all policies

- Break condition: If the Markov chain is not irreducible or positive recurrent, the averaging correction may not exist or be finite

### Mechanism 2
- Claim: The averaging correction has lower variance than the existing γt correction
- Mechanism: Instead of sampling a single γt term, the averaging correction integrates information over all time steps where a state appears, effectively averaging multiple samples
- Core assumption: The state distribution can be approximated from a finite data buffer
- Evidence anchors:
  - [abstract]: "Our correction circumvents the performance degradation associated with the γt correction with a lower variance."
  - [section]: "Notice that our correction integrates information of a state over the trajectory and turns out to be the mean of the existing correction, and hence with less variance."

- Break condition: If the buffer size is too small, the variance reduction benefit may be minimal

### Mechanism 3
- Claim: The averaging correction can be approximated through regression on a data buffer

- Core assumption: The regression task can approximate the averaging correction well enough to reduce bias
