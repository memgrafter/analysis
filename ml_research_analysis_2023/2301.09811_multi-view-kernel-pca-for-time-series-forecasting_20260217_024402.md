# Multi-view Kernel PCA for Time series Forecasting

## Quick Facts
- arXiv ID: 2301.09811
- Source URL: https://arxiv.org/abs/2301.09811
- Reference count: 40
- Primary result: RKM-MV outperforms baselines (RNN, ARMA, KRLS, LS-SVM, RRKM) on most datasets except Lorenz where LS-SVM is better

## Executive Summary
This paper introduces a kernel principal component analysis model for multi-variate time series forecasting based on the multi-view formulation of Restricted Kernel Machines. The model performs eigenvalue decomposition on summed kernel matrices of input and output views to extract shared latent structure, then uses kernel ridge regression or pre-image methods for forecasting. Experiments on standard datasets show the model outperforms closely related approaches in most cases, with the ability to handle non-linear output kernels as a key advantage.

## Method Summary
The method trains by solving an eigenvalue decomposition problem on the summation of input and output kernel matrices, extracting shared latent structure that encodes temporal dependencies. For forecasting, linear output kernels use kernel ridge regression while non-linear kernels require solving a pre-image problem to map latent predictions back to input space. The model employs recursive prediction where forecasts are fed back as inputs for multi-step ahead forecasting. Training involves constructing kernel matrices, performing eigen-decomposition to obtain latent representations, and learning mapping functions for prediction.

## Key Results
- RKM-MV outperforms baselines (RNN, ARMA, KRLS, LS-SVM, RRKM) on most standard time series datasets
- Model excels with non-linear output kernels by solving pre-image problems
- SantaFe and Energy datasets show particularly strong performance improvements
- Lorenz dataset exception where LS-SVM performs better indicates potential dataset-specific limitations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Eigenvalue decomposition of summed kernel matrices captures multi-view dynamics.
- Mechanism: The model jointly diagonalizes the input kernel matrix K(X) and output kernel matrix K(Y) via their sum, extracting shared latent structure that encodes temporal dependencies.
- Core assumption: K(X) + K(Y) is positive semi-definite and yields meaningful eigenvalues for forecasting.
- Evidence anchors:
  - [abstract] "The training problem is simply an eigenvalue decomposition of the summation of two kernel matrices corresponding to the views of the input and output data."
  - [section 3.1] "Eliminating Ux,Uy from the above equations and denoting H = [h1 ... hn] ∈ Rs×n and Λ = diag(λi) ∈ Rs×s, we get the following eigen-value problem: [K(X) + K(Y)] H⊤ = H⊤Λ"
  - [corpus] Weak: related papers focus on transformer-based or adaptive methods, not kernel eigen-decomposition for multi-view.
- Break Condition: If K(X) + K(Y) is not positive semi-definite or has ill-conditioned eigenvalues, decomposition fails.

### Mechanism 2
- Claim: Pre-image problem mapping is handled via kernel ridge regression or kernel smoother.
- Mechanism: For non-linear output kernels, forecasting requires inverting the implicit feature map; kernel ridge regression learns this mapping from latent to input space.
- Core assumption: Output feature space is approximately linearly reconstructible from latent variables.
- Evidence anchors:
  - [abstract] "When that kernel is non-linear, a pre-image problem has to be solved to forecast a point in the input space."
  - [section 3.2.1] "Alternatively, one can learn the pre-image map using kernel ridge regression [49]. Consider a specific case of Eq. (15) where the denoised point Ψ = Uy h⋆ (see Eq. (10)) i.e. argmin_x⋆ ||Uy h⋆ - ψ(y⋆)||². Then one could formulate the following problem to learn the pre-image map Γ: H ↦→ Y as follows: argmin_Γ n∑i=1 ℓ(yi,Uyhi) + λΩ(Γ)."
  - [corpus] Weak: related work does not discuss pre-image methods for multi-view forecasting.
- Break Condition: If kernel ridge regression underfits or overfits, pre-image mapping becomes inaccurate.

### Mechanism 3
- Claim: Recursive prediction leverages past forecasts as inputs for multi-step ahead forecasting.
- Mechanism: After training, the model uses predicted outputs as inputs for the next time step, enabling iterative forecasting.
- Core assumption: Forecast errors do not compound catastrophically across recursive steps.
- Evidence anchors:
  - [section 3] "we employ the recursive model such that the predictions are used as input for further predictions ˆy = f(ˆyi-1, . . . , ˆyi-p)."
  - [section 4.2] "For all methods, the entire validation set is forecasted, in recursive fashion, with the initial vector as the last point of the training set."
  - [corpus] Weak: related papers focus on non-recursive architectures like transformers or adaptive trees.
- Break Condition: If recursive error accumulation exceeds tolerance, forecast degrades rapidly.

## Architecture Onboarding

- Component map: Data preprocessing -> Kernel matrix construction -> Eigen-decomposition -> Recursive forecasting loop
- Critical path: Kernel matrix construction → eigen-decomposition → recursive forecasting loop
- Design tradeoffs:
  - Kernel choice (linear vs RBF) affects forecast quality and pre-image complexity
  - Lag length p controls temporal dependency capture vs computational cost
  - Number of components s balances expressiveness and overfitting risk
  - Pre-image method (ridge vs smoother) trades accuracy vs runtime
- Failure signatures:
  - Ill-conditioned eigenvalues → unstable training
  - Large forecast errors early in recursion → error accumulation
  - Poor pre-image reconstruction → low-fidelity predictions
- First 3 experiments:
  1. Sine wave with small lag and linear kernel: verify attractor learning in latent space
  2. SantaFe chaotic data with RBF kernel: test multi-step recursive forecasting accuracy
  3. Ablation on number of components: measure MSE vs latent dimensionality
