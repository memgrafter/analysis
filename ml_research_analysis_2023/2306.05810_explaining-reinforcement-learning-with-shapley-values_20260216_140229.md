# Explaining Reinforcement Learning with Shapley Values

## Quick Facts
- **arXiv ID:** 2306.05810
- **Source URL:** https://arxiv.org/abs/2306.05810
- **Reference count:** 18
- **Primary result:** Introduces SVERL-Performance (SVERL-P) framework that uses Shapley values to explain agent performance by explicitly deriving policies when state features are removed

## Executive Summary
This paper presents a theoretical analysis of explaining reinforcement learning using Shapley values, identifying limitations in earlier approaches. The authors develop a new framework called SVERL-Performance (SVERL-P) that properly accounts for how removing state features affects both agent policy and performance. Through experiments in Minesweeper and Taxi domains, they demonstrate that SVERL-P produces meaningful explanations that align with human intuition about feature importance.

## Method Summary
The SVERL-P framework explains agent performance by explicitly deriving the agent's policy when state features are removed and quantifying the change in performance. It calculates conditional limiting state occupancy distributions, derives modified policies that account for missing features, computes expected returns under these modified policies, and then calculates Shapley values using these performance-based characteristic value functions.

## Key Results
- SVERL-P reveals that specific features contribute substantially to performance in Minesweeper states
- In Taxi domain, SVERL-P shows that observing destination without passenger location increases suboptimal navigation behavior
- SVERL-P explanations match and supplement human intuition about feature importance

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Shapley values applied to value functions explain the value function as a static predictor but not the agent's performance
- **Mechanism:** The characteristic value function for Shapley values applied to value functions uses the expected return under the agent's original policy without considering how removing state features would change the policy and thus the expected return
- **Core assumption:** The value function predictions remain valid even when the agent cannot observe all state features
- **Evidence anchors:**
  - [abstract]: "Our analysis exposes the limitations of earlier uses of Shapley values in reinforcement learning."
  - [section]: "By never evaluating any change in policy, the full consequences of removing state features are not being considered."

### Mechanism 2
- **Claim:** Shapley values applied to policies explain feature contributions to decisions but not to performance
- **Mechanism:** The characteristic value function for Shapley values applied to policies considers only how state features affect the action selection probability, without evaluating how these decisions impact the agent's expected return
- **Core assumption:** The contribution of a state feature to the probability of selecting an action is meaningful for understanding agent performance
- **Evidence anchors:**
  - [abstract]: "Our analysis exposes the limitations of earlier uses of Shapley values in reinforcement learning."
  - [section]: "However, one would be incorrect to then conclude that the sign is important for the agent to perform well."

### Mechanism 3
- **Claim:** SVERL-P explains agent performance by explicitly deriving the agent's policy when state features are removed and quantifying the change in performance
- **Mechanism:** The characteristic value function for SVERL-P uses the expected return under a modified policy that accounts for the absence of certain state features, thus capturing the full consequences of feature removal on agent performance
- **Core assumption:** The modified policy πC can approximate how the agent would behave when certain state features are not observed
- **Evidence anchors:**
  - [abstract]: "We then develop an approach that uses Shapley values to explain agent performance."
  - [section]: "SVERL-P considers the consequences of removing features by explicitly deriving an agent's policy and quantifying the change in performance."

## Architecture Onboarding

- **Component map:** MDP states/actions -> State occupancy distributions -> Policy derivation -> Expected return calculation -> Shapley value computation
- **Critical path:** 1) Compute conditional limiting state occupancy distribution pπ(s'|sC) for all subsets of features C, 2) Derive modified policy πC that accounts for missing state features, 3) Calculate expected return under modified policy, 4) Compute Shapley values using characteristic value functions
- **Design tradeoffs:** Computational complexity vs. accuracy (exact Shapley values are expensive), feature independence vs. feature correlation (accounting for correlations increases accuracy but complexity), local vs. global explanations (local focus on specific states, global considers entire state space)
- **Failure signatures:** Shapley values that do not align with intuitive understanding of feature importance, large discrepancies between local and global explanations, unexpected negative contributions from state features
- **First 3 experiments:** 1) Implement SVERL-P on simple gridworld domain (e.g., Gridworld-B) and compare results with intuitive expectations, 2) Apply SVERL-P to complex domain (e.g., Taxi) and analyze explanations for specific states, 3) Compare SVERL-P with applying Shapley values to value functions and policies in various domains to demonstrate limitations

## Limitations
- The core assumption that modified policies πC can accurately approximate agent behavior when state features are removed remains unverified through extensive empirical validation
- The computational complexity of exactly calculating Shapley values for large state spaces presents a practical limitation not fully addressed
- The theoretical analysis focuses on local explanations without thoroughly examining how these translate to global understanding of agent performance across entire state spaces

## Confidence

- **High confidence:** The theoretical framework distinguishing between value-based, policy-based, and performance-based Shapley explanations is well-established and mathematically sound
- **Medium confidence:** The empirical demonstrations in Gridworld, Taxi, and Minesweeper domains support the theoretical claims, but the sample size of domains is limited
- **Medium confidence:** The claim that SVERL-P produces more meaningful explanations than value/policy-based approaches is supported by examples but lacks systematic quantitative comparison across diverse domains
