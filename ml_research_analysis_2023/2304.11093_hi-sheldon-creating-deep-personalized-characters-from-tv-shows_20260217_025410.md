# Hi Sheldon! Creating Deep Personalized Characters from TV Shows

## Quick Facts
- arXiv ID: 2304.11093
- Source URL: https://arxiv.org/abs/2304.11093
- Reference count: 40
- Key outcome: Introduces DPCC task and baseline method for generating multimodal responses that reflect specific character personalities using 10x more character-specific data than existing datasets

## Executive Summary
This paper introduces the Deep Personalized Character Creation (DPCC) task, which aims to generate multimodal responses (text, audio, video) from multimodal inputs that reflect a specific character's personality. The authors collect a large-scale multimodal dialogue dataset called DPCD from TV shows, containing approximately 10 times more character-specific data than existing datasets. They propose a baseline method that uses multimodal feature encoding, personalized text generation, text-to-speech synthesis, and acoustic-visual synchronization to create 5 DeepCharacters from The Big Bang Theory. Both subjective and objective evaluations demonstrate that the generated responses capture the characters' personalities and achieve high quality.

## Method Summary
The proposed baseline method for DPCC consists of several key components. First, multimodal feature encoding extracts semantic features from text, audio, and video inputs using MISA (Multimodal Sentiment Analysis) model. Second, a personalized text generation module fine-tunes DialoGPT on character-specific multimodal conversation contexts to generate text responses that reflect the character's personality. Third, a text-to-speech synthesis module converts the generated text into natural-sounding speech. Finally, an acoustic-visual synchronization module (PC-AVS) ensures that the generated speech aligns properly with the character's facial expressions and lip movements. The method is trained and evaluated on the Deep Personalized Character Dataset (DPCD), which contains approximately 10k utterances and 6 hours of audio/video per character from The Big Bang Theory.

## Key Results
- The generated responses achieve high characterization quality according to both subjective human evaluation and objective metrics
- The multimodal responses capture character personalities effectively while maintaining coherence across text, audio, and video modalities
- The DPCD dataset provides ~10x more character-specific data than existing multimodal dialogue datasets, enabling better personalization

## Why This Works (Mechanism)
The approach works by leveraging the rich multimodal information available in TV show data to capture both the semantic content and personality traits of characters. By training on character-specific dialogue contexts, the model learns to generate responses that not only answer questions appropriately but also reflect the unique speech patterns, emotional expressions, and behavioral characteristics of each character. The multimodal feature encoding ensures that all available information (text, audio, video) is considered during generation, while the acoustic-visual synchronization ensures temporal coherence between generated speech and facial expressions.

- Personalized text generation (DialoGPT fine-tuning) - why needed: To generate character-specific responses that reflect personality; quick check: Evaluate perplexity and diversity metrics on held-out character dialogue
- Text-to-speech synthesis - why needed: To convert generated text into natural-sounding speech matching character voice; quick check: Compare speech quality to original character dialogue
- Acoustic-visual synchronization (PC-AVS) - why needed: To ensure generated speech aligns with facial expressions and lip movements; quick check: Measure synchronization quality using alignment metrics

## Architecture Onboarding

Component map: TV show data → Multimodal feature encoding (MISA) → Personalized text generation (DialoGPT) → Text-to-speech synthesis → Acoustic-visual synchronization (PC-AVS) → DeepCharacter output

Critical path: The most critical path is from multimodal feature encoding through personalized text generation to the final multimodal output. The quality of character embeddings directly impacts the ability to generate personality-consistent responses, which in turn affects the overall characterization quality.

Design tradeoffs: The system trades computational complexity for quality by using multiple sophisticated models (MISA, DialoGPT, TTS, PC-AVS) in sequence. This approach requires significant computational resources but achieves better characterization than simpler single-model approaches. The dataset size tradeoff is also significant - collecting 10x more character-specific data improves quality but requires substantial data curation effort.

Failure signatures:
- Poor alignment between modalities leading to incoherent responses - diagnose by checking timestamp synchronization and manually reviewing sample outputs
- Generated responses lack character-specific personality - diagnose by comparing generated responses to original character dialogue using characterization metrics and human evaluation
- Low audio/video quality in generated outputs - diagnose by measuring speech clarity and image sharpness against baseline

First experiments:
1. Verify multimodal feature extraction by implementing MISA on CMU-MOSEI and testing character embedding quality using semantic similarity metrics
2. Replicate the text generation pipeline by fine-tuning DialoGPT on character-specific dialogue contexts and evaluating perplexity and diversity metrics
3. Implement the end-to-end pipeline with TTS and PC-AVS synchronization, then conduct user studies comparing generated responses to original character dialogue for characterization quality assessment

## Limitations
- The DPCD dataset is not publicly available, limiting reproducibility
- The acoustic-visual synchronization implementation details are not fully specified
- Character-specific fine-tuning approach may not generalize well to characters with limited dialogue data

## Confidence
- Data collection and preprocessing: Medium - requires TV show footage and careful alignment
- Multimodal feature encoding: High - MISA is well-established
- Text generation: High - DialoGPT fine-tuning is standard
- TTS and synchronization: Medium - PC-AVS implementation details are limited
