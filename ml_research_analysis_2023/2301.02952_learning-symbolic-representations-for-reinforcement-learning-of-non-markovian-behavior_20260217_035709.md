# Learning Symbolic Representations for Reinforcement Learning of Non-Markovian Behavior

## Quick Facts
- arXiv ID: 2301.02952
- Source URL: https://arxiv.org/abs/2301.02952
- Reference count: 31
- Primary result: AutRL learns non-Markovian behavior more sample-efficiently than Recurrent-PPO by discovering symbolic representations via automata learning

## Executive Summary
This paper addresses reinforcement learning in non-Markovian environments where rewards depend on the entire state-action history. The authors propose AutRL, an end-to-end algorithm that automatically discovers symbolic representations summarizing reward-relevant properties of the state-action history. By leveraging automata learning to augment states with automaton states, AutRL transforms non-Markovian problems into Markovian ones, enabling standard RL algorithms to solve them effectively. The method demonstrates superior sample efficiency and stability compared to Recurrent-PPO across four non-Markovian benchmark domains.

## Method Summary
AutRL combines automata learning with reinforcement learning to handle non-Markovian reward structures. The algorithm first learns a finite automaton that captures reward-relevant patterns in the state-action history. This automaton's states are then used to augment the original state space, creating a Markovian representation. Standard RL algorithms can then operate on this augmented state space to learn optimal policies. The automata learning component automatically discovers propositional symbols that summarize the history, eliminating the need for manual feature engineering. The approach is evaluated against Recurrent-PPO, showing faster convergence to higher-reward policies with fewer environment samples.

## Key Results
- AutRL converges to higher-reward policies than Recurrent-PPO across all tested non-Markovian domains
- Demonstrates significantly better sample efficiency, requiring fewer environment interactions to learn effective policies
- Shows improved stability across multiple runs compared to the baseline method

## Why This Works (Mechanism)
The approach works by converting non-Markovian problems into Markovian ones through automata-based state augmentation. When rewards depend on history, standard RL algorithms fail because the Markov property is violated. AutRL learns a finite automaton that tracks reward-relevant history patterns, with each automaton state representing a symbolic summary of the history. By augmenting the original state with the automaton state, the resulting representation satisfies the Markov property, enabling standard RL algorithms to operate effectively. The automata learning component automatically discovers which history features are actually relevant for rewards, avoiding unnecessary complexity.

## Architecture Onboarding

**Component Map**
State-Action History -> Automata Learning -> Automaton States -> State Augmentation -> Standard RL Algorithm -> Policy

**Critical Path**
The automata learning component is the critical path, as it must successfully discover a finite automaton that captures all reward-relevant history patterns. If the automaton fails to represent the true reward structure, the entire approach fails.

**Design Tradeoffs**
- Model complexity vs. expressiveness: More complex automata can represent more patterns but require more samples to learn
- Automaton size vs. generalization: Larger automata may overfit to specific history patterns
- Learning speed vs. accuracy: Faster automata learning may produce suboptimal representations

**Failure Signatures**
- Poor performance indicates the learned automaton doesn't capture reward-relevant history patterns
- High variance across runs suggests instability in automata learning
- Slow convergence may indicate the automaton is too complex or learning is inefficient

**First Experiments**
1. Test on a simple non-Markovian domain with known optimal automaton structure to verify correct learning
2. Compare performance with varying automaton complexity limits to understand tradeoffs
3. Evaluate sample efficiency on domains with different history dependency lengths

## Limitations
- Evaluation scope limited to four specific non-Markovian environments, leaving generalizability to complex domains uncertain
- Computational overhead from automata learning and state augmentation not thoroughly analyzed
- Theoretical convergence guarantees rely on conditions that may not hold in practice

## Confidence

**High Confidence**
- Automata-based state augmentation is technically sound for transforming non-Markovian to Markovian problems
- Empirical superiority over Recurrent-PPO in sample efficiency and stability is convincingly demonstrated

**Medium Confidence**
- Theoretical convergence guarantees are valuable but depend on specific conditions
- Generalization to broader non-Markovian settings supported by test environment diversity but not rigorously proven

**Low Confidence**
- Claims about computational efficiency and scalability lack systematic analysis of runtime and memory requirements
