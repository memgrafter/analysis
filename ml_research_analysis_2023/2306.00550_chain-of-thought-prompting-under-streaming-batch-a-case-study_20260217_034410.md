# Chain-Of-Thought Prompting Under Streaming Batch: A Case Study

## Quick Facts
- arXiv ID: 2306.00550
- Source URL: https://arxiv.org/abs/2306.00550
- Reference count: 21
- Key outcome: Incorrect and shallow rationales can effectively replace correct and deep ones in streaming batch CoT prompting without significant performance loss, potentially reducing prompt engineering costs.

## Executive Summary
This paper investigates Chain-of-Thought (CoT) prompting optimization in streaming batch settings, examining whether incorrect or shallow rationales can replace correct ones without degrading performance. The study evaluates four datasets (MultiArith, GSM8K, StrategyQA, Letter) using the text-davinci-002 model, partitioning data into 10 batches. Results show that prompts containing incorrect CoTs (Wrong-CoT) achieve similar accuracy to those with only correct CoTs (Correct-CoT), with average accuracy differences of less than 5% across all datasets. Similarly, shallow CoTs outperform deep CoTs, achieving average accuracy improvements of 2-6% on different datasets.

## Method Summary
The study implements streaming batch CoT prompting by processing data in continuous batches and updating prompts after each batch using an optimization function. Four datasets are partitioned into 10 batches each, and the text-davinci-002 model generates answers using different prompting strategies. The research compares Correct-CoT versus Wrong-CoT (with >50% incorrect rationales) and Deep-CoT versus Shallow-CoT (using a heuristic parameter ξ based on the number of line breaks). The prompting optimization function f updates the prompt by substituting rationales based on these criteria before processing the next batch.

## Key Results
- Wrong-CoT prompts achieve similar accuracy to Correct-CoT prompts, with average differences of less than 5% across all datasets
- Shallow CoTs outperform deep CoTs, achieving average accuracy improvements of 2-6% on different datasets
- The streaming batch approach maintains performance while potentially reducing prompt engineering costs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Incorrect rationales can replace correct rationales without significant performance degradation
- Core assumption: LLM has sufficient reasoning capacity to overcome potential confusion from incorrect rationales
- Evidence anchors: Average accuracy differences of less than 5% between Wrong-CoT and Correct-CoT; substitution method ensures >50% incorrect rationales
- Break condition: If reasoning capacity is significantly lower than assumed or incorrect rationale proportion exceeds critical threshold

### Mechanism 2
- Claim: Shallow rationales outperform deep rationales in streaming batch CoT prompting
- Core assumption: LLM's reasoning process is not hindered by lack of detailed step-by-step explanations
- Evidence anchors: Shallow CoTs achieve 2-6% average accuracy improvements; heuristic parameter ξ distinguishes deep from shallow CoTs
- Break condition: If task complexity exceeds LLM's ability to reason without detailed explanations

### Mechanism 3
- Claim: Streaming batch CoT prompting efficiently uses context window and reduces redundancy
- Core assumption: LLM can effectively integrate new information without being overwhelmed by changing prompt content
- Evidence anchors: Findings suggest incorrect/shallow rationales can replace correct/deep ones without significant performance loss
- Break condition: If LLM struggles to integrate new information or update frequency is too high
