# Improving Long Context Document-Level Machine Translation

## Quick Facts
- arXiv ID: 2306.05183
- Source URL: https://arxiv.org/abs/2306.05183
- Authors: 
- Reference count: 38
- One-line primary result: Window-attention achieves competitive BLEU/TER scores while significantly improving memory efficiency for long document translation

## Executive Summary
This paper addresses the challenge of scaling document-level neural machine translation beyond sentence-level context. The core problem is that standard attention mechanisms degrade in performance and scale poorly (O(L²) memory) as context size increases. The proposed solution is window-attention, a constrained attention variant that restricts attention to a small window around aligned tokens. This reduces memory usage to O(L·w) while maintaining translation quality. Evaluated on three document-level translation benchmarks, the method achieves competitive results compared to strong baselines and excels on targeted discourse tasks like pronoun and style translation.

## Method Summary
The proposed method is window-attention - a constrained attention variant that restricts attention to a small window around aligned tokens. The key insight is that when attending to large contexts, the attention mechanism becomes less focused on the current sentence, degrading performance. Window-attention addresses this by only allowing query vectors to attend to key vectors within a fixed-size window around aligned positions. Three variants of alignment during decoding are tested: 1-1 alignment, linear alignment, and sent-align (which aligns to the start of the corresponding source sentence). The method is evaluated using transformer base architecture with specific hyperparameters and compared against baseline concatenation approaches and LST-attention.

## Key Results
- Window-attention reduces memory usage from O(L²) to O(L·w) while maintaining competitive BLEU and TER scores
- Sent-align decoding strategy significantly outperforms other alignment approaches
- The method excels at targeted discourse tasks like pronoun and style translation
- GPU memory efficiency is significantly better, especially for long input sequences

## Why This Works (Mechanism)

### Mechanism 1
The attention mechanism becomes less focused on the current sentence as context size increases, degrading performance. When attending to large contexts, the model spreads attention across many tokens, diluting relevance to the current sentence. This breaks the focus optimized for sentence-level coherence.

### Mechanism 2
Restricting attention to a local window around aligned tokens reduces memory usage from O(L²) to O(L·w). Instead of computing attention over all tokens, the model only attends to tokens within a fixed-size window around the aligned token, drastically cutting attention computations.

### Mechanism 3
Sentence-aligned decoding (sent-align) improves translation quality for long documents compared to simple linear alignment. Instead of assuming uniform source-target token ratio, sent-align explicitly aligns to the start of the corresponding source sentence when a new target sentence begins, ensuring better coherence.

## Architecture Onboarding

- **Component map**: Transformer encoder → window-attention layers → decoder with sent-align cross-attention → beam search decoder
- **Critical path**: Input → subword tokenization → BPE → transformer layers with window-attention → alignment function → decoding with sent-align
- **Design tradeoffs**: Memory efficiency (O(L·w) vs O(L²)) vs potential loss of long-range context; alignment accuracy vs simplicity
- **Failure signatures**: Degraded BLEU when w is too small; GPU OOM errors when context is too long without window-attention; misalignment artifacts in generated text

## Limitations

- Restricting attention to a local window may cause the model to miss important long-range dependencies in documents where discourse coherence relies on information spread across distant sentences
- The method relies heavily on alignment quality, particularly for the sent-align strategy, and performance degrades if alignment is noisy or unavailable
- Evaluation focuses primarily on BLEU and TER scores, which may not fully capture discourse-level improvements, and the optimal window size is not thoroughly explored across different domains and languages

## Confidence

- **High Confidence**: Memory efficiency claim (O(L²) → O(L·w)) and GPU memory usage comparison are well-supported; observation that attention patterns become less focused with longer contexts is empirically demonstrated
- **Medium Confidence**: Translation quality improvements over baseline methods are supported but sometimes modest; superiority of window-attention over LST-attention is demonstrated but margin varies; effectiveness of sent-align decoding is clearly shown but may be dataset-dependent
- **Low Confidence**: Generalizability of window size selection across different domains and languages is not thoroughly explored; assumption that local context is sufficient may not hold for all document types or languages with different discourse structures

## Next Checks

1. **Window Size Sensitivity Analysis**: Systematically vary the window size (w) from 10 to 100 tokens and measure the impact on translation quality, memory usage, and GPU runtime across all three datasets. Plot BLEU/TER vs window size to identify optimal values per dataset and determine if a single window size works universally.

2. **Long-Distance Dependency Stress Test**: Create a controlled evaluation set where discourse coherence explicitly requires information from distant sentences (>500 tokens apart). Measure how window-attention with different window sizes performs on this set compared to full attention baselines, quantifying the trade-off between efficiency and capturing long-range dependencies.

3. **Alignment Quality Robustness**: Evaluate system performance when alignment quality degrades. Use different alignment methods (some deliberately noisy) and measure the impact on sent-align decoding performance. Compare against the linear alignment baseline under the same conditions to determine if the improvement is primarily due to better alignment or the window-attention mechanism itself.
