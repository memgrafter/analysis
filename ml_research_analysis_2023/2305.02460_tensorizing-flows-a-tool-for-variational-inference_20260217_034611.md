# Tensorizing flows: a tool for variational inference

## Quick Facts
- arXiv ID: 2305.02460
- Source URL: https://arxiv.org/abs/2305.02460
- Reference count: 40
- Authors: 
- Key outcome: Authors propose combining normalizing flows with tensor trains to improve variational inference for multimodal distributions, demonstrating better performance on synthetic benchmarks

## Executive Summary
The paper addresses a fundamental limitation of standard normalizing flows in variational inference: their tendency to suffer from mode collapse when approximating multimodal target distributions due to the unimodal Gaussian base distribution. The authors propose tensorizing flows, which construct a multimodal base distribution using tensor train (TT) approximation of the target density before applying a neural network flow for refinement. This approach leverages the global structure-capturing ability of tensor trains while maintaining the expressivity of neural flows, achieving improved performance on synthetic Gaussian mixture and Ginzburg-Landau models compared to standard normalizing flows.

## Method Summary
The tensorizing flow method constructs a base distribution using tensor train approximation of the square root of the target density, then refines it with an invertible residual network (iResNet) flow. The TT base is built via cross-approximation, normalized, and orthogonalized to enable efficient autoregressive sampling. The iResNet flow maps are trained to minimize the variational loss, which combines the base distribution's ability to capture global multimodal structure with the flow's capacity for local refinement. This combination addresses the mode collapse problem of standard normalizing flows while maintaining computational efficiency that scales linearly with dimension for fixed TT ranks.

## Key Results
- Tensorizing flows achieve lower variational loss than standard normalizing flows on synthetic Gaussian mixture models
- The method scales linearly with dimension for fixed tensor train ranks, making it suitable for high-dimensional problems
- Improved performance demonstrated on 20-dimensional Ginzburg-Landau model compared to baseline normalizing flows
- Autoregressive sampling from the TT base distribution is computationally efficient through orthogonalization

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Tensorizing flows address mode collapse in variational inference by replacing the unimodal Gaussian base distribution with a multimodal tensor train (TT) approximation of the target density.
- Mechanism: The TT base distribution captures global structure and multimodality of the target distribution through cross-approximation of the square root of the target density. This provides a better initialization that already approximates the target reasonably well, reducing the burden on the neural network flow to correct large deviations from the target.
- Core assumption: The TT approximation of the square root of the target density is accurate enough to capture the essential multimodal structure with low ranks.
- Evidence anchors:
  - [abstract]: "In variational inference, the unimodality of the reference Gaussian distribution used within the normalizing flow can cause difficulties in learning multimodal distributions."
  - [section 2.2]: "The unimodality of the Gaussian reference p0 results in a tendency toward 'mode collapse' during parameter optimization"
- Break Condition: If the TT ranks required to capture multimodality grow exponentially with dimension, the linear scaling advantage is lost and computational cost becomes prohibitive.

### Mechanism 2
- Claim: The combination of TT base distribution and neural network flow achieves better variational inference performance than either approach alone.
- Mechanism: The TT base distribution provides a coarse approximation that captures global structure, while the neural network flow refines this approximation to match the target distribution more precisely. This division of labor allows for more efficient learning than starting from a unimodal Gaussian or using TT alone.
- Core assumption: The neural network flow can effectively refine the TT base distribution to match the target density.
- Evidence anchors:
  - [abstract]: "We show that by combining flows with tensor networks on difficult variational inference tasks, we can improve on the results obtained by using either tool without the other."
  - [section 3.3]: "The representation power of the neural-network flow model then serves to bridge the approximation gap"
- Break Condition: If the target distribution has structure that is difficult for both TT and neural flows to capture (e.g., highly non-smooth or discontinuous), the combination may not provide significant benefits.

### Mechanism 3
- Claim: The autoregressive sampling framework enables exact sampling from the multimodal TT base distribution at linear computational cost.
- Mechanism: By representing the TT base distribution in right-left orthogonal form, marginalization operations required for autoregressive sampling can be performed efficiently through tensor contractions. This allows generation of samples with exact densities at cost scaling linearly with dimension.
- Core assumption: The right-left orthogonalization of the TT enables efficient marginalization through the "collapse the ladder" operation.
- Evidence anchors:
  - [section 3.1.3]: "orthonormality of the univariate basis functions φ1,...,φn guarantees that the integration...yields identity matrices forming the rungs of a 'ladder'"
  - [section 3.1.2]: "we demonstrate that by putting the cores of C in right-left orthogonal form, the marginalizations...can be performed for free"
- Break Condition: If the required TT ranks grow large, the O(dnr³) cost of orthogonalization and O(dn²r²) cost of sampling may become prohibitive.

## Architecture Onboarding

- Component map: TT base construction -> Autoregressive sampling -> iResNet flow refinement -> Variational loss optimization
- Critical path:
  1. Cross-approximate √p to get coefficient tensor B
  2. Normalize and orthogonalize to get TT base C
  3. Draw samples from p0 using autoregressive sampling
  4. Train iResNet flow to minimize variational loss
  5. Evaluate on validation set
- Design tradeoffs:
  - Higher TT ranks improve base distribution quality but increase computational cost
  - Deeper iResNet flows provide more expressivity but require more training data
  - Larger univariate basis size n improves approximation but increases sampling cost
- Failure signatures:
  - Mode collapse despite using TT base (indicates TT ranks too low or flow not expressive enough)
  - Poor validation loss improvement (indicates flow not learning or learning rate issues)
  - Sampling failures (indicates numerical instability in orthogonalization or basis functions)
- First 3 experiments:
  1. Implement TT base distribution with rank 1 on simple Gaussian target to verify correctness
  2. Test autoregressive sampling on low-dimensional multimodal distribution
  3. Train simple iResNet flow on unimodal target to verify flow component works independently

## Limitations
- The paper lacks comparison to other multimodal VI methods beyond standard normalizing flows
- Limited empirical validation on real-world high-dimensional problems
- Computational overhead of TT-cross approximation may not be justified for simpler targets

## Confidence
- High Confidence: The theoretical framework combining TT base distributions with neural flows is sound
- Medium Confidence: Empirical improvements on synthetic benchmarks are convincing but need real-world validation
- Low Confidence: Claims about computational efficiency scaling in high dimensions need more substantiation
