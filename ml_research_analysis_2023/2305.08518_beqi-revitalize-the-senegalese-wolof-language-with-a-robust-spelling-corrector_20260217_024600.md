# Beqi: Revitalize the Senegalese Wolof Language with a Robust Spelling Corrector

## Quick Facts
- arXiv ID: 2305.08518
- Source URL: https://arxiv.org/abs/2305.08518
- Reference count: 0
- Primary result: First deep learning-based spelling corrector for Wolof language achieves 81% accuracy

## Executive Summary
This paper presents Beqi, the first deep learning-based spelling corrector for Wolof, a low-resource African language facing significant challenges with spelling errors. The authors treat spelling correction as a machine translation task, converting noisy conventional text to official standardized text. They generate synthetic parallel data using a rule-based engine that transforms correctly written Wolof sentences into their misspelled forms, then train both LSTM and Transformer models using the OpenNMT library. The best-performing model uses character-level subword tokenization with the Transformer architecture, achieving 81% accuracy on test data.

## Method Summary
The authors address Wolof spelling errors by framing the problem as machine translation from noisy to correct text. They first create a synthetic parallel corpus by taking correctly written Wolof sentences and applying transformation rules to generate misspelled versions. These rules are based on observed error patterns in the language. The synthetic corpus is then used to train sequence-to-sequence models using OpenNMT, with experiments conducted using both LSTM and Transformer architectures. Various subword tokenization strategies are compared, including word-level, byte-pair encoding, and character-level approaches. The models are trained to translate misspelled sentences back to their correct forms.

## Key Results
- Character-level subword tokenization with Transformer architecture achieves the highest accuracy at 81%
- The spelling corrector successfully bridges the gap between conventional (misspelled) and official (standardized) Wolof writing
- The synthetic data generation approach proves effective for training in a low-resource language setting

## Why This Works (Mechanism)
The approach works because it treats spelling correction as a sequence-to-sequence translation problem, allowing the model to learn complex error patterns and their corrections. By using synthetic data generation, the researchers can create large parallel corpora even when real-world misspelled-correct pairs are scarce. The character-level subword tokenization is particularly effective because it can handle out-of-vocabulary words and capture morphological patterns common in Wolof spelling errors.

## Architecture Onboarding

**Component map**: Raw text → Synthetic data generator → Tokenizer → Transformer/LSTM encoder → Decoder → Corrected text

**Critical path**: The transformation rules in the synthetic data generator are critical because they determine the quality and diversity of training examples, directly impacting model performance

**Design tradeoffs**: The choice between LSTM and Transformer architectures involves balancing computational efficiency with modeling capacity. Character-level tokenization trades vocabulary size for increased sequence length.

**Failure signatures**: Models may fail on unseen error patterns not covered by the rule engine, or struggle with code-switched content mixing Wolof and French. Performance degradation on proper nouns and loanwords is expected.

## Open Questions the Paper Calls Out

**Open Question 1**: How effective would unsupervised approaches be compared to the rule-based engine for generating synthetic noisy data for Wolof spelling correction? The authors propose exploring unsupervised approaches to learn common errors from a noisy corpus instead of using a rule engine like the one used in this paper.

**Open Question 2**: How would incorporating real-world code-switching data into the training corpus impact the performance of the spelling correction model? The authors plan to explore NLP approaches addressing the phenomenon of code-switching, which is very characteristic of everyday Wolof that is strongly influenced by French.

**Open Question 3**: Would a bidirectional spelling correction model that can handle both conventional-to-official and official-to-conventional text be more beneficial for Wolof language revitalization? The authors mention the existence of two forms of writing in Wolof (conventional and official) and the importance of bridging the gap between them, but their current model only corrects conventional to official.

## Limitations

- Evaluation relies on synthetic data, which may not fully capture real-world error patterns and distributions
- The rule-based noisy text generator may introduce systematic biases that don't reflect natural spelling mistakes
- Limited evaluation metrics focused primarily on character-level accuracy without comprehensive error analysis
