# Interpolation Learning With Minimum Description Length

## Quick Facts
- arXiv ID: 2302.07263
- Source URL: https://arxiv.org/abs/2302.07263
- Reference count: 23
- Key outcome: MDL exhibits tempered overfitting with error strictly bounded away from 0.5 as a simple function of Bayes error, independent of other distribution properties

## Executive Summary
This paper analyzes the overfitting behavior of the minimum description length (MDL) learning rule, which minimizes description length while interpolating training data. The key finding is that MDL exhibits tempered overfitting, where the generalization error remains bounded away from 0.5 (and thus provides an edge over random guessing) as a simple function of the Bayes error, without dependence on other properties of the source distribution. The analysis provides finite sample guarantees in the agnostic setting and characterizes asymptotic behavior under random label noise.

## Method Summary
The analysis follows a two-step approach: first bounding the minimum description length of any interpolating program using pseudo-random generators with specific independence properties, then bounding the generalization error of short programs using information-theoretic arguments. The paper constructs short interpolating programs that can encode label information using minimal bits, leveraging seeded hash functions with m-way independence properties. Generalization error bounds are derived through mutual information analysis between training data and learned predictors.

## Key Results
- MDL interpolation error is bounded away from 0.5 as a function only of Bayes error
- Under random label noise, MDL error converges to exactly 2L*(1-L*), twice the Bayes error
- Construction of short interpolating programs using pseudo-random generators with m-way independence
- Agnostic finite sample guarantees for MDL overfitting behavior

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MDL exhibits tempered overfitting where error is bounded away from 0.5 as a function only of Bayes error.
- Mechanism: The MDL rule finds the shortest program that interpolates training data. The proof separates analysis into (1) bounding minimum description length of any interpolating program and (2) bounding generalization error of short programs. This decoupling allows showing error cannot exceed a threshold determined solely by Bayes error, independent of distribution details.
- Core assumption: The description length bound from Corollary 3.2 can be plugged into the generalization bounds from Lemmas 4.1 and 4.2.

### Mechanism 2
- Claim: Random label noise yields precise asymptotic error characterization of MDL interpolation.
- Mechanism: Under random label noise where Y|X = h*(X) ⊕ Ber(L*), the MDL error converges to exactly 2L*(1-L*), which is twice the Bayes error but still bounded away from 0.5. This is tighter than the agnostic case because noise independence from X allows more precise information-theoretic analysis.
- Core assumption: The noise model satisfies Y⊥X|h*(X), enabling the refined analysis in Lemma 4.2.

### Mechanism 3
- Claim: Constructing short interpolating programs requires pseudo-random generators with specific independence properties.
- Mechanism: The proof shows existence of seeded hash functions that can encode label information using only H(L(h)) bits per sample rather than m·b bits. This is achieved by showing a PRG exists that generates N bits that are m-way independent and marginally Ber(α) using seed length m·H(α) + O(log m + log log N).
- Core assumption: Such PRGs exist and can be described as "the lexicographically first such PRG."

## Architecture Onboarding

- Component map: Training data -> Interpolation program search -> Description length calculation -> Generalization bound application -> Error prediction

- Critical path: Training data → Interpolation program search → Description length calculation → Generalization bound application → Error prediction

- Design tradeoffs:
  - Runtime vs. description length: The analysis ignores runtime but focuses on program length
  - Tightness vs. generality: Agnostic bounds are looser but apply to any distribution; random label noise bounds are tighter but require specific noise assumptions
  - Constructive vs. non-constructive: The PRG existence proof is non-constructive, relying on enumeration arguments

- Failure signatures:
  - Description length bounds becoming vacuous (e.g., when b(m) grows too fast)
  - Generalization bounds failing to hold for short programs
  - Noise dependencies violating independence assumptions
  - PRG construction failing due to insufficient independence properties

## Limitations
- Analysis assumes infinite-precision bit-strings and ignores computational runtime, focusing solely on description length
- Non-constructive nature of PRG existence proof may yield impractical programs
- Tempered overfitting bounds may be loose in practice for moderate sample sizes where b(m) grows rapidly

- **Medium Confidence**: The random label noise characterization relies on specific noise independence assumptions
- **Medium Confidence**: The PRG construction for short programs exists non-constructively
