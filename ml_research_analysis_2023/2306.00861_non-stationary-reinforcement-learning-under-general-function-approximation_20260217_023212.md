# Non-stationary Reinforcement Learning under General Function Approximation

## Quick Facts
- arXiv ID: 2306.00861
- Source URL: https://arxiv.org/abs/2306.00861
- Reference count: 40
- Key outcome: First dynamic regret analysis in non-stationary MDPs with general function approximation using sliding window mechanism

## Executive Summary
This paper addresses reinforcement learning in non-stationary Markov Decision Processes (MDPs) under general function approximation. The authors propose a new complexity metric called dynamic Bellman Eluder (DBE) dimension that generalizes Bellman Eluder dimension to handle time-varying Bellman operators. They design a model-free algorithm called SW-OPEA that uses a sliding window mechanism and novel confidence set construction to achieve dynamic regret guarantees. The algorithm is shown to be provably efficient when the variation budget is not too large, outperforming existing UCB-type algorithms in small variation budget scenarios.

## Method Summary
The SW-OPEA algorithm operates by maintaining a sliding window of recent episodes and constructing confidence sets that account for both statistical uncertainty and non-stationarity. At each episode k, the algorithm executes the current policy f_k, collects data within the sliding window, and constructs a confidence set Bk using local regression constraints with variation budget terms. The next policy f_k+1 is selected as the greedy policy that maximizes the value function under Bk. The algorithm's regret is bounded by leveraging the DBE dimension to control the complexity of the function class, while the sliding window mechanism helps manage the non-stationarity through local variation budget terms.

## Key Results
- Proposes dynamic Bellman Eluder (DBE) dimension as a complexity measure for non-stationary MDPs
- Establishes upper bound on dynamic regret for SW-OPEA algorithm
- Shows SW-OPEA is provably efficient when variation budget is not significantly large
- Demonstrates superior performance compared to UCB-type algorithms in small variation budget scenarios
- Achieves first dynamic regret analysis in non-stationary MDPs with general function approximation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Dynamic Bellman Eluder (DBE) dimension generalizes Bellman Eluder dimension to handle time-varying Bellman operators in non-stationary MDPs.
- Mechanism: By constructing the function class as the union of Bellman residuals across all episodes (I - T_k h)F, the DBE dimension captures the complexity of non-stationary environments while reducing to BE dimension when transitions/rewards are static.
- Core assumption: The non-stationarity is bounded such that variations are small compared to a universal gap.
- Evidence anchors:
  - [abstract] "We propose a new complexity metric called dynamic Bellman Eluder (DBE) dimension for non-stationary MDPs, which subsumes majority of existing tractable RL problems in static MDPs as well as non-stationary MDPs."
  - [section] "For non-stationary MDPs, the Bellman operators Th varies over time, and hence we introduce our new complexity measure called dynamic Bellman Eluder dimension for non-stationary MDPs."
- Break condition: When non-stationarity exceeds the universal gap, DBE dimension becomes significantly larger than BE dimension, potentially degrading algorithm performance.

### Mechanism 2
- Claim: The sliding window mechanism in SW-OPEA reduces regret by focusing on recent transitions while maintaining optimism.
- Mechanism: By using only the latest w episodes to form the confidence set Bk, the algorithm avoids outdated information from distant past episodes while incorporating a local variation budget term to account for transition kernel differences.
- Core assumption: The local variation budget can be effectively bounded or estimated.
- Evidence anchors:
  - [abstract] "SW-OPEA...features a sliding window mechanism and a new confidence set design for non-stationary MDPs."
  - [section] "Such a design ensures the optimal state-action value function in current episode to lie within the confidence region, and hence the optimism principle remains valid."
- Break condition: When the variation budget is too large relative to window size w, the confidence sets become too conservative, leading to suboptimal exploration.

### Mechanism 3
- Claim: The probability distribution shift lemma enables bounding the effect of transition kernel changes on Bellman error estimation.
- Mechanism: The lemma bounds the difference between squared Bellman errors under different transition distributions using total variation distance and function bounds, allowing concentration inequalities to handle non-stationarity.
- Core assumption: The value functions remain bounded by H (episode length).
- Evidence anchors:
  - [section] "We introduce a novel auxiliary MDP to help bound term (II)...Then, we show in Lemma C.1 that..."
  - [section] "First, we develop the following crucial probability distribution shift lemma, which will handle the transition kernel variation in non-stationary MDPs."
- Break condition: When transition kernel changes are too large, the TV distance term dominates, breaking the concentration bounds.

## Architecture Onboarding

- Component map: Data collection -> Sliding window manager -> Confidence set constructor -> Optimistic planner -> Regret calculator
- Critical path:
  1. Execute policy π_k using f_k from Bk-1
  2. Collect trajectory data and update sliding window
  3. Construct confidence set Bk using LDh constraints
  4. Compute f_k+1 as arg max over Bk
  5. Repeat for next episode

- Design tradeoffs:
  - Window size w: Larger w provides more data but includes stale information; smaller w is more adaptive but noisier
  - Variation budget inclusion: Including ∆w_P terms ensures coverage but may over-regularize; excluding them risks optimism failure
  - Function class G choice: Larger G increases coverage but reduces concentration; smaller G improves bounds but may exclude optimal functions

- Failure signatures:
  - Rapidly increasing regret: Suggests window size too small or variation budget underestimated
  - Conservative policy selection: Indicates confidence sets too large, possibly due to excessive variation budget terms
  - Algorithm instability: May indicate violation of realizability or completeness assumptions

- First 3 experiments:
  1. Test on stationary MDP with known optimal policy to verify reduction to GOLF behavior
  2. Vary window size w on slowly changing MDP to find optimal tradeoff point
  3. Compare against UCB-type algorithms on non-stationary linear MDPs with different variation budgets to validate theoretical claims

## Limitations
- Relies heavily on bounded non-stationarity assumptions that may not hold in many practical scenarios
- Requires knowledge of the variation budget ∆, which is typically unknown in practice
- Sliding window mechanism introduces hyperparameter w that requires careful tuning
- Theoretical guarantees only established when window size is sufficiently large relative to problem parameters

## Confidence

- **High Confidence**: The theoretical framework for DBE dimension and its relationship to Bellman Eluder dimension in stationary settings. The sliding window mechanism's ability to handle non-stationarity is well-supported by the regret analysis.
- **Medium Confidence**: The probability distribution shift lemma and its application to non-stationary MDPs. While mathematically sound, the practical impact of this technical result on algorithm performance needs further validation.
- **Low Confidence**: The realizability and completeness assumptions, which are strong requirements that may not hold in many practical applications. The performance guarantees may degrade significantly when these assumptions are violated.

## Next Checks

1. **Ablation Study**: Systematically test SW-OPEA with different window sizes w and variation budget estimates ∆ to identify sensitivity and optimal hyperparameter choices in practice.

2. **Assumption Violation Testing**: Evaluate algorithm performance when completeness or realizability assumptions are violated to understand the robustness of theoretical guarantees.

3. **Scalability Assessment**: Benchmark the algorithm on larger MDPs with more complex function approximation to evaluate computational efficiency and practical scalability beyond theoretical bounds.
