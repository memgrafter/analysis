# Retrieving Comparative Arguments using Ensemble Methods and Neural Information Retrieval

## Quick Facts
- arXiv ID: 2305.01513
- Source URL: https://arxiv.org/abs/2305.01513
- Reference count: 27
- This work combines ensemble tree methods with comparative text features and neural information retrieval using BERT to retrieve comparative arguments from web corpora, achieving first place in relevance and second place in quality in the Touche 2021 competition.

## Executive Summary
This paper addresses the task of retrieving comparative arguments from the ClueWeb12 corpus to help users make informed decisions between two options. The authors propose a novel approach that combines ensemble tree methods (Random Forest, XGBoost, LightGBM) with comparative text features and neural information retrieval using BERT. Their system substantially outperforms the baseline, achieving first place in relevance (NDCG@5=0.489) and second place in quality (NDCG@5=0.684) in the Touche 2021 competition. The work demonstrates that combining statistical features, comparative structures, and neural ranking methods can effectively retrieve comparative arguments from web corpora.

## Method Summary
The authors use PyTerrier to extract statistical ranking features (BM25, Heimstra, DFIC, DPH, TF-IDF, DirichletLM, PL2) and comparative structures from documents using a sequence-labelling model. They train ensemble models (Random Forest, XGBoost, LightGBM) on combined features extracted from ClueWeb12 using the ChatNoir search engine. Additionally, they employ a BERT-based reranker fine-tuned on the Antique dataset (QA dataset with 0-2 scores) and previous year's Touche data. The final system combines statistical features, comparative structures, and neural ranking to achieve state-of-the-art performance in comparative argument retrieval.

## Key Results
- Achieved first place in relevance with NDCG@5=0.489 in Touche 2021 competition
- Achieved second place in quality with NDCG@5=0.684 in Touche 2021 competition
- Outperformed baseline systems by substantial margins in both relevance and quality metrics
- Demonstrated effectiveness of combining statistical features, comparative structures, and neural ranking

## Why This Works (Mechanism)
The approach works by leveraging multiple complementary information sources: statistical ranking features capture document-query relevance, comparative structures identify argumentative content, and neural reranking provides semantic understanding. The ensemble methods effectively combine these diverse features, while the BERT reranker captures nuanced semantic relationships that traditional features miss. This multi-faceted approach addresses the complexity of comparative argument retrieval better than single-method approaches.

## Architecture Onboarding

**Component Map**: ChatNoir -> PyTerrier feature extraction -> Ensemble models -> BERT reranker -> Final ranking

**Critical Path**: Query -> ChatNoir retrieval (100 docs) -> PyTerrier statistical features + comparative structure extraction -> Ensemble model prediction -> BERT reranking -> Final ranked list

**Design Tradeoffs**: The authors chose to combine multiple ensemble methods rather than relying on a single powerful model, accepting increased complexity for better feature utilization. They used pretraining on Antique dataset due to limited comparative argument data, trading domain specificity for model capacity. The decision to use multiple feature types (statistical, comparative, neural) increases computational cost but provides comprehensive document understanding.

**Failure Signatures**: 
- Low relevance scores indicate ChatNoir retrieval quality issues or inadequate statistical features
- Poor quality scores suggest BERT reranker not capturing semantic nuances
- Inconsistent performance across queries may indicate ensemble model overfitting to specific query types
- Feature importance imbalance suggests one feature type dominates unfairly

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do the ensemble models perform on queries with more complex comparative structures beyond simple object comparisons?
- Basis in paper: [inferred] The paper mentions using comparative structures extracted by a sequence-labelling model, but does not evaluate performance on complex comparisons with multiple aspects or nested comparisons.
- Why unresolved: The evaluation focuses on overall NDCG scores without detailed analysis of how the models handle different types of comparative queries.
- What evidence would resolve it: A detailed breakdown of performance metrics for queries with varying complexity of comparative structures, or an ablation study showing how performance changes with different types of comparisons.

### Open Question 2
- Question: What is the optimal balance between statistical features and comparative features for the ensemble models?
- Basis in paper: [inferred] The paper mentions using both statistical features from PyTerrier and comparative features, but does not perform a systematic analysis of their relative importance or optimal combination.
- Why unresolved: The feature importance analysis shows relative weights but doesn't explore the optimal configuration or interaction between different feature types.
- What evidence would resolve it: An ablation study systematically removing or varying weights of different feature types, or a sensitivity analysis showing how performance changes with different feature combinations.

### Open Question 3
- Question: How would the models perform with more task-specific training data instead of using Antique dataset?
- Basis in paper: [explicit] The paper acknowledges that "this data is not insufficient for fitting large supervised ranking models" and uses Antique dataset as a workaround, suggesting this is a limitation.
- Why unresolved: The authors explicitly state that the available comparative argument retrieval data is insufficient for training large models, and using a related but different task's dataset may not be optimal.
- What evidence would resolve it: A comparison of model performance using only the available comparative argument retrieval data versus the current approach, or an evaluation showing how performance scales with the amount of task-specific training data.

## Limitations
- The sequence-labelling model for comparative structure extraction lacks clear implementation details, creating uncertainty about the exact feature extraction process
- The BERT reranker architecture and hyperparameters from OpenNIR are not explicitly stated, potentially affecting reproducibility of the neural ranking component
- The ensemble approach combines statistical features, comparative structures, and neural reranking, but the specific weighting and interaction between these components remain unclear
