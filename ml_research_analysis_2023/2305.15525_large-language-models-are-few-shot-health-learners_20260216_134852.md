# Large Language Models are Few-Shot Health Learners

## Quick Facts
- arXiv ID: 2305.15525
- Source URL: https://arxiv.org/abs/2305.15525
- Reference count: 32
- Primary result: Prompt tuning with context-inclusive prompts improves LLM performance on health tasks by up to 75% accuracy improvement in activity recognition and 130% error reduction in cardiovascular tasks

## Executive Summary
This paper demonstrates that large language models can effectively learn to process physiological and behavioral time-series data with minimal examples through few-shot prompt tuning. Using a 24B parameter LLM, the authors evaluate nine health tasks across cardiovascular, activity recognition, metabolic, and mental health domains. The key innovation is context-inclusive prompts that ground numerical sequences in domain-specific meaning, combined with soft prompt embeddings that allow task-specific adaptation without full fine-tuning. The results show substantial performance improvements over both zero-shot and supervised baselines, suggesting LLMs can serve as effective few-shot learners for diverse health applications when properly grounded with numerical time-series data.

## Method Summary
The authors evaluate a 24B parameter LLM (PaLM) on nine health tasks requiring numerical reasoning with physiological and behavioral time-series data. They compare zero-shot performance, prompt engineering, and prompt tuning with 3-, 10-, and 25-shot examples across four health domains. The method uses context-inclusive prompts that incorporate domain-specific contextual information (e.g., "Inter-beat Intervals") alongside numerical sequences, and implements prompt tuning by adding a learnable soft prompt embedding layer to the frozen LLM. Performance is benchmarked against zero-shot and supervised baseline models using accuracy, mean absolute error, and error reduction metrics.

## Key Results
- Context-inclusive prompts with few-shot tuning achieved up to 75% accuracy improvement in activity recognition tasks
- Cardiovascular tasks showed 130% error reduction compared to zero-shot performance
- Prompt tuning with context-inclusive prompts consistently outperformed both zero-shot and numerical-only prompt approaches across all nine tasks
- The 24B parameter LLM demonstrated effective few-shot learning capability with as few as 3 training examples per task

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Context-inclusive prompts allow LLMs to leverage their internal knowledge of physiological patterns by anchoring numerical sequences in domain-specific meaning.
- Mechanism: When prompts include textual context like "Inter-beat Intervals (IBIs)" or "accelerometer data in meters per second squared," the model can retrieve relevant domain knowledge and apply it to the numerical sequence.
- Core assumption: The LLM's pretraining corpus contains sufficient medical/health knowledge to interpret domain-specific terms when provided with appropriate anchors.
- Evidence anchors:
  - [abstract]: "with only few-shot tuning, a large language model is capable of grounding various physiological and behavioral time-series data"
  - [section]: "The Context-Inclusive prompts involve incorporating relevant contextual information into the prompt... The inclusion of this additional context is based on the hypothesis that it could steer the language model towards utilizing its domain-specific knowledge"

### Mechanism 2
- Claim: Few-shot prompt tuning with a learnable soft prompt embedding allows the model to adapt its internal representations specifically for physiological time-series data without full fine-tuning.
- Mechanism: The soft prompt embedding layer learns task-specific patterns that help the frozen LLM process numerical time-series data by creating an optimal prefix for each task.
- Core assumption: A relatively small number of examples (3-25 shots) contains sufficient information to guide the model's adaptation to new data types.
- Evidence anchors:
  - [abstract]: "with only few-shot tuning, a large language model is capable of grounding various physiological and behavioral time-series data"
  - [section]: "we add a soft learnable prompt embedding... This approach enables us to move beyond manual prompt design and facilitates learning of an optimal prefix for each task"

### Mechanism 3
- Claim: The model's ability to perform arithmetic operations on physiological measurements is enhanced when numerical reasoning is explicitly grounded in health context.
- Mechanism: When the model is prompted with health-specific arithmetic problems, it can leverage both its general arithmetic capabilities and its domain knowledge about health calculations to produce accurate results.
- Core assumption: The model's pretraining included sufficient information about health-related arithmetic formulas and their application.
- Evidence anchors:
  - [abstract]: "LLMs can capture rich representations of concepts that are useful for real-world tasks"
  - [section]: "The synthetic metabolic health data includes 25 samples for training and 100 samples for testing" and "This task requires LLMs to accurately recall the MET value for each activity and the equation of how to calculate burned calories"

  - Why needed here: The paper's core contribution is demonstrating that the model can learn effectively from very few examples (3-25 shots) rather than requiring large training datasets

## Architecture Onboarding

- Component map: Numerical data → Template conversion → Prompt embedding (if few-shot tuned) → 24B parameter LLM (PaLM) → Health task output
- Critical path: Input numerical data → Template conversion → Prompt embedding (if few-shot tuned) → LLM processing → Health task output
- Design tradeoffs:
  - Using frozen LLM weights preserves general knowledge but limits adaptation capability
  - Few-shot tuning balances adaptation needs with computational efficiency
  - Context-inclusive prompts improve performance but increase input length and complexity
  - Soft prompt embeddings are parameter-efficient but may be less powerful than full fine-tuning
- Failure signatures:
  - Zero-shot performance degrades to near-random guessing on complex tasks
  - Numerical-only prompts perform worse than context-inclusive prompts across all tasks
  - Model produces outputs that are overly confident but factually incorrect (hallucinations)
  - Failure to handle sequential data patterns beyond model's attention window
- First 3 experiments:
  1. Replicate zero-shot performance on the simplest task (averaging heart rates) to establish baseline
  2. Implement 3-shot prompt tuning with context-inclusive prompts on activity recognition task
  3. Compare numerical-only vs context-inclusive prompt tuning on inter-beat interval classification task

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different large language model architectures (beyond the 24B parameter model tested) perform on health tasks requiring numerical reasoning?
- Basis in paper: [explicit] The paper explicitly states "In this paper, we only evaluated one LLM" and acknowledges "Clearly differences exist across LLM capabilities"
- Why unresolved: The study only tested a single 24B parameter transformer architecture, limiting generalizability to other model sizes and architectures
- What evidence would resolve it: Comparative experiments testing multiple LLM architectures (varying parameter counts, different model families) on the same health tasks with consistent evaluation protocols

### Open Question 2
- Question: What is the minimum amount of training data required for LLMs to achieve reliable performance on health tasks involving time-series physiological data?
- Basis in paper: [explicit] The paper explores "3-shot, 10-shot, and 25-shot scenarios" but doesn't systematically determine the optimal data efficiency
- Why unresolved: The study only tested three fixed shot counts without exploring the full spectrum of training data requirements or identifying diminishing returns
- What evidence would resolve it: Systematic experiments varying the number of training examples across a broader range (1-shot to 100+ shots) to identify the point of optimal performance

### Open Question 3
- Question: How does the performance of LLMs on health tasks change when dealing with longer time-series sequences that exceed typical input token limits?
- Basis in paper: [explicit] The paper notes that "The prompt-engineered LLM was unable to produce output for approximately 50% of the test data in the cardiovascular and activity recognition tasks" due to sequence length limitations
- Why unresolved: The study encountered token limit issues but didn't systematically investigate how sequence length affects model performance or explore solutions like windowing or summarization
- What evidence would resolve it: Experiments testing model performance on progressively longer sequences with and without techniques to handle extended sequences, measuring accuracy degradation points and identifying effective mitigation strategies

## Limitations

- The evaluation relies on a relatively small number of examples (3-25 shots) across nine tasks, raising questions about generalizability to more complex or variable health scenarios.
- The use of a 24B parameter LLM (PaLM) represents a significant computational resource that may not be accessible for widespread adoption, though the paper suggests similar results could be achieved with smaller models.
- The context-inclusive prompts require careful manual design, which may limit scalability across diverse health applications.
- The paper demonstrates performance improvements but doesn't fully explore the boundaries of these improvements - specifically, how performance degrades as task complexity increases or when faced with out-of-distribution data.

## Confidence

**High Confidence**: The core finding that few-shot prompt tuning with context-inclusive prompts improves LLM performance on health time-series tasks is well-supported by the experimental results across multiple datasets and task types.

**Medium Confidence**: The claim that soft prompt embeddings provide optimal task-specific adaptation is supported but could benefit from more extensive ablation studies comparing different embedding sizes and learning rates.

**Low Confidence**: The assertion that LLMs can serve as reliable few-shot learners for diverse health tasks may be overstated given the limited scope of tested tasks and the relatively controlled nature of the datasets.

## Next Checks

1. **Generalization Test**: Evaluate the model on held-out health tasks not seen during prompt tuning to assess true few-shot learning capability versus memorization of patterns from the nine tasks tested.

2. **Robustness Analysis**: Systematically vary input noise levels, missing data patterns, and out-of-distribution physiological measurements to quantify performance degradation and identify failure modes in real-world deployment scenarios.

3. **Scalability Assessment**: Implement and test the same approach with progressively smaller LLM architectures (7B, 3B, 1B parameters) to determine the minimum model size required to maintain performance improvements while reducing computational requirements.
