# CQE: A Comprehensive Quantity Extractor

## Quick Facts
- arXiv ID: 2305.08853
- Source URL: https://arxiv.org/abs/2305.08853
- Reference count: 27
- Primary result: Novel framework achieving 85.6-88.2% F1 for value/unit extraction and 76.1% F1 for concept detection

## Executive Summary
CQE is a comprehensive quantity extraction framework that detects values, units, changes, and associated concepts in text. It uses dependency parsing and a unit dictionary to extract quantities, then applies normalization and standardization. The system introduces concept detection as a novel capability, identifying entities or properties that quantities reference. CQE outperforms existing systems on the NewsQuant dataset across multiple domains, with high precision, recall, and F1-scores for both value/unit pairs and concept detection.

## Method Summary
CQE employs a rule-based approach using dependency parsing and a dictionary of 531 units to detect values, units, and changes in text. It implements 61 dependency parsing rules to identify grammatical relationships between quantity components. The framework includes a BERT-based unit disambiguation module trained on 18 ambiguous surface forms to resolve contextual ambiguity. Concept detection uses five priority-ordered strategies including keyword detection, dependency subtree analysis, and relative clause handling. The system normalizes and standardizes extracted quantities for consistent output.

## Key Results
- Achieves 85.6-88.2% F1-scores for value/unit pair extraction on NewsQuant dataset
- Concept detection achieves 76.1% F1-score, a novel capability in quantity extraction
- BERT-based unit disambiguation reaches 88.1% F1, significantly outperforming existing methods
- Outperforms other systems across economics, sports, technology, cars, science, and companies domains

## Limitations

- Evaluation relies on a single custom dataset (NewsQuant) with 590 sentences, limiting generalizability to other text types and domains
- The 61 dependency parsing rules and 531-unit dictionary may not capture all possible quantity expressions in natural language
- BERT-based disambiguation was trained on a custom dataset of only 18 ambiguous surface forms, potentially missing other ambiguous units

## Confidence

- **High Confidence**: The dependency parsing mechanism for value/unit extraction (85.6-88.2% F1 scores) is well-supported by the quantitative evaluation on NewsQuant
- **Medium Confidence**: The BERT-based unit disambiguation approach shows strong quantitative results (88.1% F1), but the custom training dataset and evaluation methodology are not fully detailed
- **Low Confidence**: The generalizability of the 61 dependency parsing rules and 531-unit dictionary to domains beyond news text remains uncertain without cross-domain validation
