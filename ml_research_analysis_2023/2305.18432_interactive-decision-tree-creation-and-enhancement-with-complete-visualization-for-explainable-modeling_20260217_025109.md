# Interactive Decision Tree Creation and Enhancement with Complete Visualization for Explainable Modeling

## Quick Facts
- **arXiv ID**: 2305.18432
- **Source URL**: https://arxiv.org/abs/2305.18432
- **Reference count**: 36
- **Primary result**: Novel BC-DT and SPC-DT visualization methods using General Line Coordinates enable complete decision tree visualization, allowing interactive threshold adjustment to improve model interpretability and prevent overfitting.

## Executive Summary
This paper introduces two novel visualization methods, BC-DT and SPC-DT, for decision trees that leverage General Line Coordinates (GLC) to provide complete visualization of n-D data in 2-D space. BC-DT uses bended coordinates at threshold points while SPC-DT employs shifted paired coordinates with directed graphs to visualize decision tree structures. These methods enable observation of individual cases, data flow, threshold sensitivity, and case density, addressing limitations of traditional DT visualization. The interactive nature allows domain experts to trace misclassified cases, adjust thresholds, and build more robust decision trees, effectively preventing overgeneralization and overfitting.

## Method Summary
The BC-DT and SPC-DT methods transform decision tree structures into 2-D visualizations using General Line Coordinates. BC-DT represents edges as bended coordinates that converge at threshold points, while SPC-DT uses shifted paired coordinates where adjacent attributes are visualized together in 2-D Cartesian space. Both methods enable interactive exploration where users can drag thresholds and immediately see the impact on classification. The approach supports both importing pre-trained trees and building trees interactively from data. Case studies on benchmark datasets demonstrate how these visualizations help identify and correct issues like overgeneralization and overfitting by allowing manual threshold adjustment based on domain knowledge.

## Key Results
- BC-DT and SPC-DT provide complete visualization of decision trees, showing individual cases, data flow, threshold sensitivity, and case density in n-D space
- Interactive threshold adjustment enables domain experts to prevent overgeneralization and overfitting by incorporating knowledge about borderline cases
- Case studies demonstrate improved model evaluation and enhancement capabilities compared to traditional DT visualization methods
- The methods support both importing pre-trained trees and building trees interactively from data

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: BC-DT and SPC-DT expand visualization capabilities beyond traditional DT methods by enabling observation of individual cases, data flow, threshold sensitivity, and density in n-D space.
- **Mechanism**: By representing DT edges as bended coordinates (BC-DT) or using shifted paired coordinates (SPC-DT), the methods map the entire n-D data space into 2-D visualizations that preserve the decision tree structure while showing how each case traverses it.
- **Core assumption**: The General Line Coordinates (GLC) framework allows lossless transformation of n-D points into 2-D representations without losing classification semantics.
- **Evidence anchors**: Abstract states these methods use Bended Coordinates (BC) and Shifted Paired Coordinates (SPC), and section explains these capabilities allow observation of relations between attributes, individual cases relative to DT structure, data flow in DT, sensitivity of split thresholds, and density of cases in n-D space.

### Mechanism 2
- **Claim**: SPC-DT enables simultaneous multi-attribute split exploration, improving over sequential single-attribute splits in traditional DTs.
- **Mechanism**: By pairing adjacent attributes in the decision tree and visualizing them in 2-D, SPC-DT allows the user to evaluate purity in 4 quadrants simultaneously, potentially finding better splits than sequential univariate tests.
- **Core assumption**: Purity measures (e.g., Gini index) can be meaningfully extended to 2-D attribute pairs and optimized interactively.
- **Evidence anchors**: Section discusses how SPC-DT computes purity of 4 quadrants simultaneously for each pair of attributes, contrasting with sequential DT processes where attribute selection depends on parent node choices.

### Mechanism 3
- **Claim**: Interactive threshold adjustment in BC-DT and SPC-DT reduces overfitting and improves model robustness by allowing domain experts to incorporate knowledge about borderline cases.
- **Mechanism**: The visualization shows exact case positions relative to thresholds; users can drag thresholds and instantly see impact on classification, enabling fine-tuning that balances accuracy and generalization.
- **Core assumption**: Domain experts can identify and correct overgeneralization/overfitting by inspecting individual cases near decision boundaries.
- **Evidence anchors**: Abstract mentions these features are critical for preventing overgeneralization and overfitting, while section discusses how setting proper criteria automatically is challenging and interactive adjustment via graphics is a big advantage.

## Architecture Onboarding

- **Component map**: Data parser -> GLC transformer -> Visualization renderer -> Interactive controller -> Performance evaluator
- **Critical path**: Data → GLC transformation → Visual rendering → User interaction → Model update
- **Design tradeoffs**:
  - Space vs. detail: Bended coordinates save space but may distort attribute scales; shifted pairs are more explicit but can cause occlusion
  - Interactivity vs. performance: Real-time threshold adjustment is valuable but may lag with large datasets
  - Generality vs. usability: Supporting arbitrary GLCs increases flexibility but adds UI complexity
- **Failure signatures**:
  - Occlusion: Too many overlapping lines hide individual cases
  - Distortion: Disproportionate scaling in BC-DT misleads about threshold importance
  - Instability: Minor threshold changes flip many classifications, indicating overfitting
- **First 3 experiments**:
  1. Load Wisconsin Breast Cancer dataset, import a pre-trained DT, and verify that individual cases are traceable along bended edges
  2. Switch to SPC-DT, reposition coordinate pairs to minimize line crossings, and observe improvement in case clarity
  3. Adjust a root threshold interactively and confirm that accuracy metrics update and borderline cases move visibly

## Limitations
- Scale limits: Effectiveness for high-dimensional datasets (>10 attributes) remains uncertain, with potential combinatorial explosion in SPC-DT's attribute pairing approach
- Computational overhead: Real-time interactive updates may introduce unacceptable latency for datasets with thousands of cases
- Domain expertise assumption: Heavy reliance on user ability to interpret visualizations meaningfully may not hold for casual users or in expert-limited domains

## Confidence
- **High confidence**: Visual capabilities of BC-DT and SPC-DT (showing individual cases, data flow, threshold sensitivity) are well-demonstrated through case studies; GLC transformation foundation appears sound
- **Medium confidence**: Interactive threshold adjustment reducing overfitting is supported by case studies but lacks quantitative comparison with baselines; effectiveness depends on user skill and dataset characteristics
- **Low confidence**: SPC-DT's simultaneous multi-attribute split exploration consistently outperforming sequential splits is weakly supported; presented as theoretical advantage with limited empirical validation
