# Explaining the Model and Feature Dependencies by Decomposition of the Shapley Value

## Quick Facts
- arXiv ID: 2306.10880
- Source URL: https://arxiv.org/abs/2306.10880
- Reference count: 27
- One-line primary result: A method to decompose Shapley values into interventional and dependent parts for more interpretable model explanations

## Executive Summary
This paper addresses the challenge of explaining complex machine learning models when features are dependent. The authors propose a novel approach that decomposes Shapley values into two components: an interventional part that explains the model itself and a dependent part that captures feature dependencies in the data. By computing both conditional and interventional expectations, this decomposition provides more nuanced and interpretable explanations compared to existing methods. The approach is demonstrated to be equivalent or superior to state-of-the-art methods on both synthetic and real-world datasets.

## Method Summary
The method involves computing conditional Shapley values using Kernel SHAP with conditional data distribution sampling, then decomposing these into interventional and dependent parts. The interventional part is calculated by sampling permutations and comparing intervened versus non-intervened expectations, while the dependent part is derived by subtracting the interventional part from the conditional Shapley value. This decomposition allows for separate interpretation of model effects and feature dependencies, providing enhanced explanatory power.

## Key Results
- The decomposition approach provides equivalent or superior explanations compared to state-of-the-art methods
- Dependent SHAP parts increase linearly with feature correlation, offering better interpretability than Shapley residuals
- The method allows for increased insight into model-data structure without requiring causal knowledge

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Decomposing SHAP values into interventional and dependent parts resolves the model vs. result explanation ambiguity.
- Mechanism: The conditional SHAP value can be mathematically split into two components: (1) an interventional part that explains the model by breaking feature dependencies, and (2) a dependent part that captures feature interactions and associations in the data. This decomposition allows users to see both the direct model effect and the indirect data-driven effect of each feature.
- Core assumption: Conditional SHAP values can be expressed as the sum of these two components, and both parts retain interpretability and practical utility.
- Evidence anchors:
  - [abstract] "We propose a new algorithmic approach to combine both explanations, removing the burden of choice and enhancing the explanatory power of Shapley values"
  - [section] "Thus, the conditional SHAP value can be split up into two SHAP value parts... they arguably provide both a model and a result explanation"
  - [corpus] Weak evidence - related papers discuss conditional vs. interventional SHAP but do not provide a unified decomposition approach.
- Break condition: If the decomposition does not preserve the local accuracy property or if the dependent part becomes too noisy to interpret meaningfully.

### Mechanism 2
- Claim: Interventional SHAP parts pass the dummy property, ensuring model correspondence.
- Mechanism: The interventional part of the decomposition satisfies the dummy property (14), meaning that if a feature has no direct effect on the model output, its interventional SHAP part will be zero. This guarantees that the interventional component accurately reflects the model's internal logic without being influenced by feature dependencies.
- Core assumption: The dummy property is a sufficient condition for model correspondence in explanation methods.
- Evidence anchors:
  - [section] "Proposition 2. Interventional SHAP part passes the dummy property (14), i.e. f([xi, x\i]) = f([d, x\i]) ∀x, d =⇒ ϕi,int = 0"
  - [corpus] No direct evidence - the claim relies on the mathematical proof provided in the paper.
- Break condition: If the model contains complex interactions or non-linearities that cause the dummy property to fail for the interventional part.

### Mechanism 3
- Claim: The dependent SHAP part increases linearly with feature correlation and captures feature dependencies better than Shapley residuals.
- Mechanism: The dependent part of the decomposition directly measures the contribution of feature dependencies to the SHAP value. It increases linearly with the correlation between features, providing a more intuitive and interpretable measure of dependency effects compared to Shapley residuals, which can be non-monotonic and zero at non-zero correlations.
- Core assumption: Linear relationship between dependent SHAP part and feature correlation holds across different models and data distributions.
- Evidence anchors:
  - [section] "Figure 4 shows that the dependent SHAP part increases linear with the correlation and is zero when the features are independent, as desired"
  - [corpus] Weak evidence - related papers discuss Shapley residuals but do not provide a comparison with the proposed dependent SHAP part.
- Break condition: If the relationship between dependent SHAP part and feature correlation becomes non-linear or breaks down for certain types of feature interactions.

## Architecture Onboarding

- Component map:
  - Data preprocessing: Estimate conditional data distribution (multivariate Gaussian or Gaussian copula)
  - SHAP computation: Calculate conditional SHAP values using Kernel SHAP
  - Decomposition: Separate conditional SHAP into interventional and dependent parts
  - Visualization: Generate force plots showing both components
  - Evaluation: Compare with state-of-the-art methods and validate results
- Critical path:
  1. Estimate conditional data distribution from training data
  2. Compute conditional SHAP values using Kernel SHAP
  3. Sample permutations and data points to calculate interventional SHAP parts
  4. Subtract interventional parts from conditional SHAP to get dependent parts
  5. Generate visualizations and evaluate results
- Design tradeoffs:
  - Computational cost vs. accuracy: Increasing K1 and K2 parameters improves accuracy but increases computation time
  - Choice of conditional data distribution: Multivariate Gaussian is simple but may not capture complex dependencies; Gaussian copula is more flexible but requires more tuning
  - Interpretability vs. completeness: The decomposition provides more insight but may be harder to interpret than a single SHAP value
- Failure signatures:
  - Decomposition does not preserve local accuracy property
  - Dependent SHAP parts are noisy or uninterpretable
  - Interventional SHAP parts fail to capture model effects accurately
  - Computational cost becomes prohibitive for large datasets or models
- First 3 experiments:
  1. Apply decomposition to a simple synthetic dataset with known feature dependencies and validate the linear relationship between dependent SHAP parts and feature correlation
  2. Compare the decomposition with conditional and interventional SHAP on a real-world dataset (e.g., Boston Housing) and evaluate the interpretability of the results
  3. Test the decomposition on a non-linear model (e.g., random forest) and assess its performance relative to the linear case

## Limitations
- The method's performance heavily depends on accurate estimation of conditional data distributions, which can be challenging for high-dimensional or non-Gaussian data
- The computational cost increases significantly with the number of features and data points, potentially limiting applicability to large-scale problems
- The linear relationship between dependent SHAP parts and feature correlation, while demonstrated on synthetic data, may not hold universally across different model types and data distributions
