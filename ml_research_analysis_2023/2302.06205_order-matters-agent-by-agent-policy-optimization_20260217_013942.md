# Order Matters: Agent-by-agent Policy Optimization

## Quick Facts
- **arXiv ID**: 2302.06205
- **Source URL**: https://arxiv.org/abs/2302.06205
- **Reference count**: 40
- **Primary result**: A2PO outperforms strong baselines in MARL tasks by sequentially updating agents' policies with PreOPC and semi-greedy agent selection

## Executive Summary
This paper addresses the non-stationarity problem in multi-agent reinforcement learning (MARL) by proposing an agent-by-agent policy optimization (A2PO) algorithm. Unlike simultaneous updates, A2PO updates agents sequentially, allowing each agent to perceive changes made by preceding agents. The algorithm uses preceding-agent off-policy correction (PreOPC) to approximate advantage functions and applies a semi-greedy agent selection rule to accelerate optimization. Theoretical analysis provides monotonic improvement guarantees for each agent during training. Experiments on four benchmarks demonstrate significant improvements in both performance and sample efficiency compared to existing methods.

## Method Summary
A2PO implements sequential agent updates with preceding-agent off-policy correction (PreOPC) to approximate advantage functions while using off-policy data. Each agent updates its policy using a clipped surrogate objective, with an adaptive clipping parameter that starts large and decreases over time. The semi-greedy agent selection rule combines greedy selection based on advantage magnitude with random selection to avoid early convergence. The algorithm uses centralized critics for each agent and applies a truncation mechanism to control total variation distances between policies.

## Key Results
- Achieves 100% win rates on some SMAC benchmarks compared to baseline methods
- Demonstrates 1.6x-3.6x better sample efficiency than MAPPO across tested tasks
- Consistently outperforms strong baselines (MAPPO, CoPPO, HAPPO) on StarCraftII, Multi-agent MuJoCo, Multi-agent Particle Environment, and Google Research Football benchmarks

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Sequential agent-by-agent policy updates reduce non-stationarity compared to simultaneous updates.
- **Mechanism**: Sequential updates allow each agent to observe and adapt to changes made by preceding agents before updating, effectively converting the problem into a stationary single-agent problem from the perspective of the current agent.
- **Core assumption**: The order of agent updates can be chosen such that agents with more influence on others update earlier.
- **Evidence anchors**: Abstract and section 3.3 discussing non-stationarity challenges.

### Mechanism 2
- **Claim**: Preceding-agent off-policy correction (PreOPC) enables monotonic improvement for each agent's policy.
- **Mechanism**: PreOPC corrects advantage function estimates by accounting for policy changes of preceding agents, allowing agents to perceive changes despite using off-policy data.
- **Core assumption**: The approximation error introduced by PreOPC can be controlled to maintain monotonic improvement guarantees.
- **Evidence anchors**: Section 3.3 describing PreOPC method and section 4 presenting Theorem 1 on monotonic bounds.

### Mechanism 3
- **Claim**: The semi-greedy agent selection rule accelerates optimization while maintaining performance balance.
- **Mechanism**: Combines greedy selection (largest absolute advantage) with random selection to avoid early convergence, balancing rapid improvement with exploration.
- **Core assumption**: Advantage function estimates provide meaningful guidance for agent selection.
- **Evidence anchors**: Section 4 describing the semi-greedy rule and section 5.2 showing its superior performance.

## Architecture Onboarding

- **Component map**: A2PO algorithm -> PreOPC correction -> Semi-greedy agent selection -> Adaptive clipping parameter -> Centralized critics
- **Critical path**: 1. Collect data using current joint policy, 2. For each agent in selected order: a. Compute advantage approximation using PreOPC, b. Update agent's policy using clipped surrogate objective, c. Update agent's value function, 3. Repeat until convergence
- **Design tradeoffs**: Sequential vs. simultaneous updates (reduces non-stationarity but may increase training time), single rollout vs. multiple rollouts (improves sample efficiency but requires sophisticated advantage estimation), parameter sharing vs. independence (reduces parameters but may limit expressiveness)
- **Failure signatures**: Poor performance (issues with agent selection order, PreOPC approximation error, or hyperparameter tuning), high variance in training (insufficient exploration or overly aggressive updates), slow convergence (suboptimal agent selection rule or insufficient training steps)
- **First 3 experiments**: 1. Run A2PO on simple multi-agent particle environment task to verify basic functionality, 2. Compare A2PO with baseline methods on SMAC to validate performance improvements, 3. Ablation study removing PreOPC or semi-greedy rule to assess individual contributions

## Limitations

- Limited empirical validation primarily focused on cooperative tasks, with unclear effectiveness in competitive or mixed settings
- Approximation error sensitivity of PreOPC method not extensively studied, particularly in scenarios with large policy changes or highly stochastic environments
- Hyperparameter sensitivity not thoroughly explored, particularly for adaptive clipping parameter and semi-greedy agent selection rule

## Confidence

**High confidence**: The core mechanism of sequential agent-by-agent policy updates reducing non-stationarity is well-supported by theoretical analysis and empirical results.

**Medium confidence**: The effectiveness of PreOPC in enabling monotonic improvement is supported, but sensitivity to approximation error is not extensively studied.

**Low confidence**: The semi-greedy agent selection rule's acceleration benefits are demonstrated empirically but lack strong theoretical justification, and scalability to large-scale environments is not thoroughly investigated.
