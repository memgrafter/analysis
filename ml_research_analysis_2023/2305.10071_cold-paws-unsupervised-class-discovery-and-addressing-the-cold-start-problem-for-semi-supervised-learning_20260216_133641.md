# Cold PAWS: Unsupervised class discovery and addressing the cold-start problem for semi-supervised learning

## Quick Facts
- arXiv ID: 2305.10071
- Source URL: https://arxiv.org/abs/2305.10071
- Authors: 
- Reference count: 40
- Key outcome: Outperforms random sampling in cold-start problem, achieving up to 90% class coverage and 10% accuracy improvement

## Executive Summary
This paper addresses the cold-start problem in semi-supervised learning by proposing a method to select informative subsets of images for labeling. The approach combines self-supervised learning (SimCLR), clustering (k-medoids), and manifold learning (t-SNE) to identify representative images that span class diversity. Tested on CIFAR-10, Imagenette, DeepWeeds, and EuroSAT, the method shows significant improvements over random sampling in both unsupervised class discovery and downstream model performance with supervised and semi-supervised learning.

## Method Summary
The method trains a SimCLR model to obtain feature embeddings of the dataset, then uses k-medoids clustering with t-SNE transformation to select representative images. The selected images are labeled and used to fine-tune a model with either supervised learning or semi-supervised learning (PAWS). The approach aims to improve upon random sampling by selecting images that better represent the dataset's class diversity.

## Key Results
- K-medoids (t-SNE) strategy achieved up to 90% success in sampling all classes at least once
- Improved test accuracy by 10% compared to random sampling in some cases
- Competitive performance compared to state-of-the-art semi-supervised learning methods on CIFAR-10 with 30 labels
- Particularly effective on imbalanced datasets like DeepWeeds

## Why This Works (Mechanism)

### Mechanism 1
Self-supervised contrastive learning maps semantically similar images into nearby regions of a low-dimensional feature space. SimCLR applies stochastic transformations to images and trains a neural network to minimize a contrastive loss, effectively clustering transformed views of the same image and similar images together. The core assumption is that the feature space preserves class-relevant similarities even without labels.

### Mechanism 2
K-medoids clustering in the transformed feature space selects a small set of images that span the dataset's class diversity. K-medoids chooses actual data points as cluster centers, ensuring that each cluster's representative is a real image from the dataset, which improves downstream labeling efficiency. The core assumption is that the clusters discovered by k-medoids correspond to meaningful groups that capture the variation within each class.

### Mechanism 3
Semi-supervised learning starting from the self-supervised representation improves model performance compared to training from scratch with the same small labeled set. Methods like PAWS use the full dataset to refine the decision boundaries by leveraging similarity between labeled and unlabeled samples, while the initial weights capture general visual features. The core assumption is that the initial self-supervised weights provide a better starting point than random initialization for the downstream task.

## Foundational Learning

- Concept: Contrastive loss and similarity metrics
  - Why needed here: Understanding how SimCLR's loss function shapes the feature space is critical for reasoning about why certain images get selected by clustering.
  - Quick check question: What does minimizing the contrastive loss in SimCLR encourage the network to do with transformed views of the same image?

- Concept: Clustering algorithms (k-medoids vs. k-means)
  - Why needed here: Knowing that k-medoids selects actual data points as centers explains why this method might yield more representative images for labeling.
  - Quick check question: How does k-medoids differ from k-means in terms of cluster center selection, and why might that matter for selecting real images?

- Concept: Manifold learning and dimensionality reduction
  - Why needed here: Techniques like t-SNE are used to transform the feature space before clustering; understanding their role helps explain improvements in label selection.
  - Quick check question: What is the purpose of applying t-SNE to the feature space before clustering, and how might it affect the selection of representative images?

## Architecture Onboarding

- Component map:
  SimCLR model (ResNet backbone + projection head) -> feature extraction
  t-SNE transformation (optional) -> 2D embedding for clustering
  K-medoids clustering -> selection of representative images
  Labeled subset + full dataset -> semi-supervised learning (PAWS)
  Evaluation on held-out test set -> accuracy metrics

- Critical path:
  1. Train SimCLR on full dataset.
  2. Extract feature embeddings from backbone or projection head.
  3. (Optional) Apply t-SNE to reduce dimensionality.
  4. Run k-medoids clustering to select n images.
  5. Label selected images.
  6. Fine-tune or train with PAWS using labeled and unlabeled data.
  7. Evaluate on test set.

- Design tradeoffs:
  - Using backbone features vs. projection head features: Backbone may preserve more task-relevant information, but projection head may yield cleaner clusters.
  - Applying t-SNE vs. not: t-SNE can improve cluster separation but adds stochasticity and computational cost.
  - K-medoids vs. greedy selection: K-medoids is simpler and faster but may not optimize for the mini-max objective.

- Failure signatures:
  - Poor clustering: t-SNE plots show no clear class separation or clusters don't align with true classes.
  - Random performance: Selected images perform no better than random sampling on downstream tasks.
  - Overfitting: Models trained on small labeled sets overfit, especially if clusters are too homogeneous.

- First 3 experiments:
  1. Train SimCLR on CIFAR-10 and visualize t-SNE embeddings to check for class-aligned clusters.
  2. Run k-medoids clustering with different distance metrics and compare class coverage.
  3. Train a simple classifier on the selected labeled set and compare accuracy to random selection.

## Open Questions the Paper Calls Out

### Open Question 1
How do different self-supervised learning methods compare in their effectiveness for the cold-start problem? The paper focuses on SimCLR but acknowledges other methods like bootstrapping and MoCo could be used. Direct comparison of multiple self-supervised methods using the same downstream evaluation pipeline would resolve this.

### Open Question 2
What is the theoretical relationship between the quality of the self-supervised feature space and the downstream semi-supervised performance? The paper demonstrates correlation but doesn't establish formal bounds or explain the mechanism. Mathematical analysis connecting feature space geometry to semi-supervised learning performance metrics would resolve this.

### Open Question 3
How does the cold-start selection strategy perform when classes have highly imbalanced representation in the dataset? The paper notes that DeepWeeds has imbalanced classes and observes that the k-medoids strategy improves performance compared to random sampling in this case. Systematic evaluation across multiple imbalanced datasets using metrics like balanced accuracy, F1-score, and area under the precision-recall curve would resolve this.

## Limitations

- Dependence on quality of self-supervised representations which may not generalize well to all datasets or tasks
- Sensitivity to choice of clustering parameters and number of clusters selected
- Limited comparison to other active learning or cold-start strategies, making it difficult to assess relative contribution of each component

## Confidence

- High confidence: The mechanism by which self-supervised learning creates feature spaces that cluster semantically similar images (Mechanism 1).
- Medium confidence: The claim that k-medoids clustering in the transformed feature space selects a small set of images that span the dataset's class diversity (Mechanism 2).
- Medium confidence: The assertion that semi-supervised learning starting from the self-supervised representation improves model performance compared to training from scratch with the same small labeled set (Mechanism 3).
