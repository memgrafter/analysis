# Shapley Based Residual Decomposition for Instance Analysis

## Quick Facts
- arXiv ID: 2305.18818
- Source URL: https://arxiv.org/abs/2305.18818
- Reference count: 40
- Key outcome: Introduces a method to decompose regression residuals with respect to data instances using Shapley Values, enabling model-agnostic identification of influential or anomalous instances.

## Executive Summary
This paper presents a novel approach to instance-level analysis in regression models by decomposing residuals using Shapley Values. Instead of attributing model error to features, the method quantifies how each data instance contributes to the residuals of all other instances. The resulting contribution and composition matrices provide insights into instance behavior, enabling detection of outliers and patterns. The technique is model-agnostic and can be extended to asymmetric cases for data valuation tasks.

## Method Summary
The method trains regression models on subsets of data and computes residuals for each instance. Shapley Values are then calculated for these residuals, decomposing them into instance-level contributions. This decomposition is performed symmetrically (all instances in both training and evaluation) or asymmetrically (separate training and test sets). The approach uses permutation sampling Monte Carlo or influence functions for approximation. Visualizations like CC plots display mean composition and contribution values to reveal instance behaviors and outliers.

## Key Results
- Generates contribution and composition matrices showing how instances impact residuals
- Visualizations like CC plots reveal patterns and outliers in the data
- Experiments demonstrate utility in analyzing instance behaviors and model appropriateness across various datasets and models
- Technique can be applied to data valuation tasks in the asymmetric case

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Shapley Values applied to residuals decompose instance effects on model error rather than feature contributions.
- Mechanism: Residuals ei are split into n components ϕi,j such that Σjϕi,j = ei, capturing each instance's contribution to every other instance's error.
- Core assumption: The additivity and efficiency axioms of Shapley Values hold when the value function is the residual of a model trained on a subset of instances.
- Evidence anchors:
  - [abstract] "We introduce the idea of decomposing the residuals of regression with respect to the data instances instead of features."
  - [section] "We seek to decompose the residuals ei further into n components ϕi,j such that Σj ϕi,j = ei. This property can be exactly satisfied by the Shapley Values of the residuals ei."
  - [corpus] Weak: neighbors discuss Shapley over data but not over residuals; no direct evidence of residual decomposition.
- Break condition: If residuals are non-additive across subsets or model retraining is too noisy, the Shapley attribution may not capture true instance effects.

### Mechanism 2
- Claim: CC (contribution-composition) plots visualize instance behavior in a model-agnostic way, enabling detection of outliers and patterns.
- Mechanism: Each instance is plotted by mean composition (how much it is influenced) and mean contribution (how much it influences others), forming interpretable axes.
- Core assumption: The mean values over all subsets in the Shapley computation are stable and representative of instance behavior.
- Evidence anchors:
  - [abstract] "The approach generates contribution and composition matrices showing how instances impact residuals."
  - [section] "We begin by graphically visualizing the Shapley Values of residuals by plotting the summary mean of each axis of Composition ϕi,j and Contribution values ϕc i,j on Figure 3 which we call a CC plot."
  - [corpus] Weak: neighbors mention Shapley over data but not visualization methods; no direct evidence of CC plots.
- Break condition: If instance effects are highly non-uniform across subsets, the mean-based axes may mislead; if model is highly nonlinear, residuals may not be well-behaved.

### Mechanism 3
- Claim: Asymmetric decomposition (training set ≠ test set) extends data valuation to explain instance effects on held-out error.
- Mechanism: Contribution matrices become Ntrain by Ntest, so each training instance's effect on each test instance's residual is captured, enabling data valuation tasks.
- Core assumption: The value function v(Si_π) can be computed on disjoint sets X and S without loss of interpretability.
- Evidence anchors:
  - [abstract] "The technique can also be applied to data valuation tasks in the asymmetric case."
  - [section] "When i ≠ j (asymmetric case) then we are more interested in the relationships between the instances present within the training and testing sets."
  - [corpus] Weak: neighbors discuss Data Shapley for valuation but not asymmetric residual decomposition; no direct evidence.
- Break condition: If training and test distributions diverge significantly, contributions may not generalize; if model overfits, contributions may be spurious.

## Foundational Learning

- Concept: Shapley Value axioms (efficiency, symmetry, dummy, additivity)
  - Why needed here: Ensure that decomposition of residuals is exact and interpretable, and that each instance's effect is fairly attributed.
  - Quick check question: If instance i never changes the residual when added to any subset, what should ϕi,j be for all j?

- Concept: Residual analysis in regression
  - Why needed here: The value function is defined as the residual of a model trained on a subset, so understanding residuals is essential to interpret the decomposition.
  - Quick check question: If a model perfectly fits the training subset, what is the residual for any instance in that subset?

- Concept: Permutation sampling Monte Carlo for Shapley approximation
  - Why needed here: Exact Shapley computation is exponential in number of instances; sampling is the practical way to estimate ϕi,j.
  - Quick check question: How many permutations are needed to get within ε of the true Shapley value with high probability?

## Architecture Onboarding

- Component map: Data ingestion -> train/test split -> Model training (subset-specific) -> Value function evaluation (residuals) -> Shapley approximation (Monte Carlo or KernelSHAP) -> Contribution/composition matrix assembly -> Visualization (CC plots) or downstream tasks (valuation, outlier detection)

- Critical path: For each sampled permutation: subset selection -> model retrain -> residual computation -> incremental Shapley update. This loop dominates runtime.

- Design tradeoffs:
  - Accuracy vs runtime: Exact Shapley is exponential; sampling gives approximate but tractable results.
  - Symmetric vs asymmetric: Symmetric gives square matrices and instance-instance interaction insight; asymmetric enables data valuation but loses some interpretability.
  - Model complexity: Simple models (Ridge) train fast per subset; complex models (Random Forest, NN) make sampling expensive.

- Failure signatures:
  - High variance in contribution/composition across permutations -> unstable decomposition
  - All-zero or near-zero contributions -> model fits too well or data lacks variation
  - Asymmetric decomposition yields zero matrices -> disjoint sets have no overlapping influence

- First 3 experiments:
  1. Generate a small synthetic regression dataset (n=20) and run symmetric decomposition with Ridge regression; verify Σjϕi,j ≈ ei.
  2. Apply asymmetric decomposition (train on half, test on half) and check that contribution matrix is rectangular and captures test residuals.
  3. Visualize CC plot and manually verify that known outliers appear far from the main cluster.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the appropriate value function to use for classification problems in residual decomposition?
- Basis in paper: [explicit] The authors state "In the future we plan to extend our work to the Classification case with an appropriate choice of the value function. The challenge is that there is typically little notion of distances and residuals in the context of classification meaning that some novel choice of value must be selected."
- Why unresolved: Classification problems do not have a natural notion of residuals like regression does, so a suitable value function that captures instance contributions to classification error needs to be designed and validated.
- What evidence would resolve it: Experiments showing that a proposed value function for classification produces meaningful instance decomposition results and aligns with domain knowledge.

### Open Question 2
- Question: How do the Shapley values from residual decomposition compare to influence functions in terms of approximation accuracy and computational efficiency?
- Basis in paper: [explicit] The authors discuss influence functions as a potential speedup method but note "Despite the generally poor approximations produced by these algorithms, they are still useful...further experiments are required...to quantify exactly how much they differ and what are acceptable trade-offs of accuracy versus run-time."
- Why unresolved: While influence functions can approximate Shapley values more efficiently, their accuracy relative to true Shapley values is not well-characterized, and the trade-off between accuracy and speed needs empirical validation.
- What evidence would resolve it: Systematic experiments comparing Shapley values from Monte Carlo sampling vs. influence functions across diverse datasets and models, quantifying approximation errors and runtime differences.

### Open Question 3
- Question: What are the most effective algorithmic improvements to scale residual decomposition to large datasets and complex models?
- Basis in paper: [explicit] The authors identify scalability as a key challenge: "The development of more performant algorithms must also be considered since scaling to larger datasets and more complex models is still a significant challenge." They discuss various potential approaches like KernelSHAP, G-Shapley, and influence functions.
- Why unresolved: The paper presents several candidate algorithmic improvements but does not systematically compare their effectiveness or combine them in a unified framework for residual decomposition.
- What evidence would resolve it: Benchmarking studies evaluating the accuracy and scalability of different algorithmic improvements (e.g., KernelSHAP, G-Shapley, influence functions, parallelization) for residual decomposition on large datasets and complex models.

## Limitations

- Computational scalability remains unaddressed for large datasets; Monte Carlo sampling may be prohibitively expensive.
- No empirical comparison to feature-level Shapley methods to demonstrate added value.
- Asymmetric case lacks validation; it's unclear if contributions remain meaningful when training and test sets are disjoint.

## Confidence

- High confidence in the Shapley decomposition framework for symmetric instance analysis, as it builds directly on established axioms.
- Medium confidence in CC plot interpretability, as the visual mapping is intuitive but empirical validation across diverse datasets is limited.
- Low confidence in asymmetric decomposition for data valuation, as the claim is speculative and not supported by experiments in the manuscript.
