# A Circuit Complexity Formulation of Algorithmic Information Theory

## Quick Facts
- **arXiv ID**: 2306.14087
- **Source URL**: https://arxiv.org/abs/2306.14087
- **Reference count**: 7
- **Primary result**: Proposes a new algorithmic information theory based on circuit complexity with advantages over traditional Kolmogorov complexity

## Executive Summary
This paper introduces a novel formulation of algorithmic information theory using circuit complexity instead of the traditional Kolmogorov complexity framework. The authors define a circuit prior as a Bayesian mixture over circuits and introduce index complexity, which measures the size of the smallest circuit computing a string's bits given their indices. They analyze the minimum index complexity predictor (MIP) and derive bounds on prediction errors, showing that for strings sampled from the circuit prior, the fraction of errors decreases with string length. This result parallels the coding theorem in algorithmic information theory and offers several advantages including computability and potential relevance to deep learning and physical models of computation.

## Method Summary
The authors propose a new algorithmic information theory framework based on circuit complexity. They define a circuit prior as a Bayesian mixture over circuits, where the prior is a pushforward measure of a circuit size prior. The key concept introduced is index complexity, which measures the size of the smallest circuit that can compute a string's bits given their indices. The minimum index complexity predictor (MIP) is then analyzed, which predicts the next bit based on the smallest circuit consistent with the observed bits. The paper derives bounds on the number of prediction errors made by MIP, demonstrating that for strings sampled from the circuit prior, the fraction of errors decreases with string length, analogous to the coding theorem in traditional algorithmic information theory.

## Key Results
- Circuit prior defined as Bayesian mixture over circuits with circuit size prior
- Index complexity introduced to measure smallest circuit size computing string bits given indices
- MIP bounds show decreasing prediction error fraction with string length for circuit prior-sampled strings

## Why This Works (Mechanism)
The proposed approach works by leveraging circuit complexity as a computable alternative to Kolmogorov complexity. By defining a circuit prior and analyzing the minimum index complexity predictor, the authors establish a connection between circuit complexity and prediction performance. The decreasing error bounds for strings sampled from the circuit prior demonstrate that circuits of sufficient size can capture the structure of these strings, enabling accurate predictions. This mechanism provides a foundation for a practical algorithmic information theory that can be applied to real-world problems involving prediction and compression.
