# Proto-Value Networks: Scaling Representation Learning with Auxiliary Tasks

## Quick Facts
- arXiv ID: 2304.12567
- Source URL: https://arxiv.org/abs/2304.12567
- Reference count: 40
- Key outcome: Proto-value networks learn state representations through predicting random policy value functions for binary reward functions, achieving DQN-level performance with only 4M environment interactions.

## Executive Summary
Proto-value networks (PVN) extend proto-value functions to deep reinforcement learning by learning state representations through predicting the value function of the random policy for randomly sampled binary reward functions. The method uses random network indicators to define sets of states and trains a neural network to approximate the successor measure via off-policy learning. Experiments on 46 Atari games demonstrate that the learned representations enable linear function approximation to match DQN performance with minimal environment interactions. Performance scales with network capacity, allowing larger networks to support more auxiliary tasks without degradation.

## Method Summary
PVN pre-trains an encoder network on offline datasets by predicting value functions for randomly sampled binary reward functions defined by random network indicators. The encoder is then frozen and a linear value function head is trained online using standard RL algorithms. The method leverages the successor measure framework, replacing state-equality with set-inclusion, and uses quantile regression bias tuning for stable training. The approach requires only 4M environment interactions to achieve performance comparable to DQN trained with 200M interactions.

## Key Results
- PVN achieves DQN-level performance on Atari games with only 4M environment interactions
- Performance scales linearly with network capacity, with larger networks supporting more auxiliary tasks
- PVN outperforms baselines including random initialization, behavior cloning, SPR, and random cumulants across all aggregate metrics
- Learned representations capture temporal structure, placing successive states close together in feature space

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Proto-value networks learn representations by predicting value functions of random policies for binary reward functions defined by random network indicators.
- Core assumption: Binary reward functions defined by random networks can induce meaningful structure in the representation space.
- Evidence anchors:
  - [abstract] "Proto-value networks extend proto-value functions to deep RL by learning state representations through predicting the value function of the random policy for a set of randomly sampled binary reward functions."
  - [section] "Specifically, we implement the successor measure (Blier et al., 2021; Touati & Ollivier, 2021), which extends the successor representation (Dayan, 1993) by replacing state-equality with set-inclusion."
- Break condition: If random network indicators fail to create meaningful partitions of state space, or if random policy value functions don't capture useful structure.

### Mechanism 2
- Claim: Increasing network capacity allows more auxiliary tasks to be learned simultaneously without performance degradation.
- Core assumption: Neural networks can learn multiple auxiliary tasks without interference if they have sufficient capacity.
- Evidence anchors:
  - [section] "We find that increasing the representational capacity of the network increases performance, even for a very small number of tasks... as network capacity is increased, the algorithm can use more auxiliary tasks to improve its representation."
  - [section] "For example, while the 2× network achieves maximal performance with 10 tasks, the 8× network performs best in the range of [50, 100] tasks."
- Break condition: If tasks interfere with each other due to insufficient capacity, or if additional tasks don't provide complementary information.

### Mechanism 3
- Claim: Using the random policy (rather than optimal policy) for auxiliary tasks provides more stable learning.
- Core assumption: Off-policy learning from random policy is more stable than learning optimal policies for auxiliary tasks.
- Evidence anchors:
  - [section] "Using the mean formulation has a much higher median human normalized score than the max formulation. This is likely due to instability that arises from max bias and state coverage due to the off-policy learning required for the optimal value function."
  - [section] "Learning the value function of the random policy also requires off-policy learning; however, we predict that it doesn't have such a large effect, as we previously described in Section 4.2."
- Break condition: If random policy fails to provide sufficient state coverage or if auxiliary tasks require more sophisticated policies.

## Architecture Onboarding

- Component map:
  Encoder network (Impala-CNN variant) -> Random network indicator generators -> Auxiliary task prediction heads -> Replay buffer for offline pre-training -> Linear value function head for online evaluation

- Critical path:
  1. Generate random network indicators and tune their activation rates
  2. Pre-train encoder on auxiliary tasks using offline data
  3. Freeze encoder and train linear value function on environment rewards
  4. Evaluate performance after fixed number of steps

- Design tradeoffs:
  - Network width vs number of auxiliary tasks: Larger networks support more tasks
  - Random policy vs optimal policy: Random policy provides more stable learning
  - Binary vs continuous rewards: Binary rewards are simpler to tune and align with Atari environments

- Failure signatures:
  - Poor performance on held-out games suggests representation doesn't generalize
  - Decreasing performance with more tasks indicates capacity saturation
  - Instability during training suggests learning rate or architecture issues

- First 3 experiments:
  1. Baseline: Random initialization performance to establish lower bound
  2. Scaling experiment: Vary network width and number of tasks on 5 games
  3. Ablation: Replace random network indicators with hash functions to test indicator quality

## Limitations
- Effectiveness depends heavily on quality of random network indicators, which may not transfer well to all domains beyond Atari
- Uses binary rewards, limiting applicability to environments requiring continuous reward prediction
- Computational overhead of training many auxiliary tasks may be prohibitive for resource-constrained settings

## Confidence
- High confidence: The core mechanism of using random policy value functions for representation learning (Mechanism 1) and the scaling relationship with network capacity (Mechanism 2) are well-supported by experimental evidence
- Medium confidence: The claim about random policy providing more stable learning (Mechanism 3) is supported but could benefit from more rigorous ablation studies comparing different policy choices
- Low confidence: Generalization to non-Atari domains and the robustness of random network indicators across different MDP structures remain untested
