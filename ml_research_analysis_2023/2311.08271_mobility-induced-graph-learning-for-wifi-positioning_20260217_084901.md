# Mobility-Induced Graph Learning for WiFi Positioning

## Quick Facts
- arXiv ID: 2311.08271
- Source URL: https://arxiv.org/abs/2311.08271
- Reference count: 34
- Key outcome: Achieves 1.073 m RMSE (semi-supervised) and 1.398 m RMSE (self-supervised) in WiFi positioning

## Executive Summary
This paper introduces MINGLE, a novel graph neural network approach for WiFi positioning that leverages user mobility patterns. The method constructs mobility-induced graphs (time-driven and direction-driven) from sequential WiFi measurements and movement patterns, then applies a cross-graph learning framework with graph convolutional networks to estimate user location from round-trip time measurements. The approach uniquely incorporates mobility regularization to improve accuracy without requiring ground-truth locations, demonstrating superior performance in handling noisy measurements and reducing the need for labeled data.

## Method Summary
MINGLE constructs two types of mobility-induced graphs based on user movement patterns: time-driven graphs capturing temporal relationships between measurements and direction-driven graphs encoding spatial movement directions. These graphs are processed through a cross-graph learning framework using graph convolutional networks to fuse temporal and spatial information for location estimation. The method employs a mobility regularization term that leverages the consistency of user movement patterns to improve positioning accuracy, particularly effective when ground-truth labels are scarce or noisy.

## Key Results
- Achieves 1.073 m RMSE in semi-supervised learning scenarios
- Achieves 1.398 m RMSE in self-supervised learning scenarios
- Demonstrates superior performance in handling noisy WiFi measurements compared to baseline methods

## Why This Works (Mechanism)
The method works by exploiting the inherent structure in user mobility patterns to create meaningful relationships between sequential WiFi measurements. By constructing time-driven and direction-driven graphs, MINGLE captures both temporal dependencies and spatial movement constraints that naturally exist in mobile scenarios. The cross-graph learning framework then effectively fuses these complementary information sources through graph convolutional networks, while the mobility regularization term leverages the physical consistency of movement to constrain the learning process and improve robustness to measurement noise.

## Architecture Onboarding

**Component Map**: WiFi RTT Measurements -> Graph Construction (Time-driven + Direction-driven) -> Graph Convolutional Networks -> Cross-graph Fusion -> Location Estimation -> Mobility Regularization

**Critical Path**: The most critical sequence is: WiFi measurements → graph construction → graph convolutions → cross-graph fusion → location output, with mobility regularization providing additional constraints throughout training.

**Design Tradeoffs**: The method trades computational complexity for improved accuracy by processing multiple graph representations simultaneously. The choice between time-driven and direction-driven graphs represents a balance between temporal consistency and spatial movement patterns.

**Failure Signatures**: Poor graph construction due to insufficient or irregular mobility data will lead to degraded performance. Over-regularization from the mobility term can cause underfitting, while under-regularization may fail to leverage movement patterns effectively.

**First Experiments**: 1) Validate graph construction quality with synthetic mobility patterns; 2) Test individual graph performance before cross-graph fusion; 3) Evaluate sensitivity to mobility regularization strength.
