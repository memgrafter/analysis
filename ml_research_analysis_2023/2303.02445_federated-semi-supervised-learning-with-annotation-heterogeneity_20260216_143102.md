# Federated Semi-Supervised Learning with Annotation Heterogeneity

## Quick Facts
- arXiv ID: 2303.02445
- Source URL: https://arxiv.org/abs/2303.02445
- Reference count: 40
- Key outcome: HASSLE achieves 2.5-5.3% accuracy improvements over state-of-the-art FSSL methods when only 5% of data is labeled

## Executive Summary
This paper addresses federated semi-supervised learning (FSSL) under annotation heterogeneity, where clients have varying amounts of labeled data (0%-100%). Existing FSSL methods assume uniform labeling across clients and cannot handle arbitrary annotation distributions. The authors propose HASSLE, a dual-model framework with supervised and unsupervised models trained separately on labeled and unlabeled data. A mutual learning strategy called SUMA enables knowledge transfer between the dual models through global residual alignment and model proximity alignment. Experiments on FMNIST, CIFAR-10, and CIFAR-100 show HASSLE achieves significant accuracy improvements over state-of-the-art FSSL methods when only 5% of data is labeled.

## Method Summary
HASSLE is a dual-model framework that uses separate supervised and unsupervised models to handle arbitrary annotation percentages across federated clients. The supervised model learns from labeled data while the unsupervised model learns from unlabeled data with pseudo-labels. SUMA mutual learning transfers knowledge between models through global residual alignment (using residual models to capture complementary knowledge) and model proximity alignment (L2 regularization to keep models complementary). The framework is validated on FMNIST, CIFAR-10, and CIFAR-100 with Dirichlet-distributed data splits showing 2.5-5.3% accuracy improvements over state-of-the-art methods.

## Key Results
- HASSLE achieves 2.5-5.3% accuracy improvements over state-of-the-art FSSL methods when only 5% of data is labeled
- Performance improves with more unlabeled clients, demonstrating effective knowledge transfer
- The framework handles arbitrary annotation distributions (0%-100% labeled data) across clients
- Experiments conducted on FMNIST, CIFAR-10, and CIFAR-100 datasets with 20 clients and 200 communication rounds

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Dual-model framework enables flexible handling of arbitrary annotation percentages across clients
- Mechanism: Separate supervised and unsupervised models allow each client to contribute only relevant data type (labeled or unlabeled), avoiding wasted computation or inapplicable training
- Core assumption: Models with same architecture can learn complementary representations when trained on different data types
- Evidence anchors:
  - [abstract] "it is a dual-model framework with two models trained separately on labeled and unlabeled data such that it can be simply applied to a client with an arbitrary labeling percentage"
  - [section 4.1] "Instead of a single model (e.g., a single semi-supervised model) for local training and global aggregation, we propose to use dual models with the same structure to learn from labeled and unlabeled data separately"
- Break condition: If supervised and unsupervised models learn redundant representations, the dual-model approach provides no benefit over single model approaches

### Mechanism 2
- Claim: Mutual learning via global residual alignment transfers knowledge between supervised and unsupervised models
- Mechanism: Residual models learn the difference between dual models, allowing each model to complement the other with complementary knowledge from the opposite data type
- Core assumption: The difference between supervised and unsupervised models captures useful complementary information that can be learned and transferred
- Evidence anchors:
  - [section 4.2] "we incorporate two compact models called residual models to learn the differences between the dual models"
  - [section 4.2] "r(t)U−S is called the supervised residual model, which aims to learn the knowledge from the global unsupervised model to complement the global supervised model on DL,k"
- Break condition: If residual models fail to learn meaningful differences or if the dual models become too similar, knowledge transfer becomes ineffective

### Mechanism 3
- Claim: Model proximity alignment ensures dual models remain mutually beneficial during training
- Mechanism: L2 regularization between dual models in parameter space keeps them close enough to maintain complementary relationship while still allowing specialized learning
- Core assumption: Keeping models close in parameter space while allowing different training objectives maintains a useful complementary relationship
- Evidence anchors:
  - [section 4.2] "we propose a model proximity term to align the dual models in the model parameter space during local training"
  - [section 4.2] "the update of the local supervised model with proximity alignment is formulated by: LS (DL,k, w(t)S,k|w(t)U ) = ∑(x,y)∈DL,k ℓ(f (x, w(t)S,k),y), +γ∥w(t)S,k − w(t)U ∥2"
- Break condition: If proximity constraint is too strong, models may converge to same solution; if too weak, models may diverge and lose complementary relationship

## Architecture Onboarding

- Component map:
  Server -> Global dual models (wS, wU) and residual models (rU−S, rS−U)
  Clients -> Local models and data (labeled, unlabeled, or both)
  SUMA strategy -> Pseudo-labeling, residual learning, proximity alignment

- Critical path:
  1. Server initializes global models and sends to clients
  2. Clients perform local training with SUMA (pseudo-labeling, residual learning, proximity alignment)
  3. Clients upload updated models to server
  4. Server aggregates models to update global models
  5. Repeat until convergence

- Design tradeoffs:
  - Communication cost vs model performance: More models transmitted increases communication but enables better knowledge transfer
  - Residual model size vs effectiveness: Smaller residual models reduce communication but may capture less complementary knowledge
  - Proximity strength vs model diversity: Stronger constraints keep models complementary but may limit specialized learning

- Failure signatures:
  - Supervised and unsupervised models converge to same performance (loss of complementary relationship)
  - Residual models fail to improve performance (inadequate complementary knowledge captured)
  - Performance degrades with more unlabeled clients (knowledge transfer not effective)

- First 3 experiments:
  1. Run HASSLE on synthetic dataset with known annotation distribution to verify correct handling of different client types
  2. Compare performance with and without residual models on moderate-sized dataset to validate knowledge transfer mechanism
  3. Test robustness to different proximity constraint strengths on CIFAR-10 to find optimal balance between complementarity and specialization

## Limitations
- The performance benefits are primarily demonstrated in low-label regimes (5% labeled data), with less clear evidence of sustained advantages as labeled data increases
- The dual-model approach increases communication overhead by 4x compared to single-model methods, though this trade-off is not explicitly quantified
- The residual model design (1/4 channel size) appears somewhat arbitrary without ablation studies on optimal sizing

## Confidence
- High Confidence: The core dual-model framework with SUMA mutual learning is technically sound and well-grounded in established federated and semi-supervised learning principles
- Medium Confidence: The claimed 2.5-5.3% accuracy improvements over state-of-the-art methods are reproducible given the detailed experimental setup
- Low Confidence: The optimal design choices (residual model size, proximity constraint strength) are not fully justified through systematic hyperparameter optimization or ablation studies

## Next Checks
1. Apply HASSLE to a naturally occurring federated dataset (e.g., medical imaging data from multiple hospitals) where annotation percentages vary organically rather than through synthetic Dirichlet distribution
2. Quantify the exact communication cost increase (4 models vs 1) and evaluate whether compression techniques or sparsification could maintain performance while reducing bandwidth requirements
3. Conduct systematic ablation studies varying the residual model size from 1/8 to full model size to determine the optimal trade-off between communication cost and knowledge transfer effectiveness
