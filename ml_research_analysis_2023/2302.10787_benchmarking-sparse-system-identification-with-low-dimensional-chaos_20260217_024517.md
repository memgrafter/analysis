# Benchmarking sparse system identification with low-dimensional chaos

## Quick Facts
- arXiv ID: 2302.10787
- Source URL: https://arxiv.org/abs/2302.10787
- Reference count: 0
- Primary result: Comprehensive benchmark of SINDy algorithms across 70 chaotic systems, showing weak formulation provides significant performance improvements

## Executive Summary
This paper presents a comprehensive benchmark of sparse system identification algorithms using a large database of chaotic dynamical systems. The study compares four optimization algorithms (STLSQ, SR3, Lasso, and MIOSR) for solving the SINDy problem, with and without the weak formulation. Using 70 polynomial chaotic systems from the dysts database, the research systematically evaluates algorithm performance across varying noise levels and dynamical properties. The weak formulation demonstrates significant performance improvements even on clean data. STLSQ and MIOSR show the best overall performance, with STLSQ being particularly robust and fast.

## Method Summary
The study benchmarks sparse system identification by generating 70 polynomial chaotic systems from the dysts database, creating training and testing trajectories with varying noise levels. For each system, a fourth-order polynomial feature library is constructed, and derivatives are computed (either directly or via weak formulation). Four optimization algorithms (STLSQ, Lasso, SR3, MIOSR) are compared using ensemble methods with 50% subsampling to generate 10 models per threshold value. Hyperparameter selection uses AIC-based Pareto front optimization across 300 threshold values. Performance is evaluated using coefficient error and RMSE metrics, with results aggregated across all systems and noise conditions.

## Key Results
- Weak formulation provides significant performance improvements even on clean data by avoiding derivative computation noise amplification
- STLSQ and MIOSR show the best overall performance, with STLSQ being particularly robust and fast across all noise levels
- SINDy model quality shows minimal dependence on dynamical properties like chaos level, scale separation, and equation complexity

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The weak formulation of SINDy provides significant performance improvements even on clean data by avoiding derivative computation noise amplification
- Mechanism: The weak formulation subdivides time trajectories into subdomains and minimizes integrals of the governing equations rather than pointwise errors, eliminating the need to compute derivatives from noisy data
- Core assumption: Even clean data contains unavoidable noise from finite sampling rates that gets amplified when computing numerical derivatives
- Evidence anchors:
  - [abstract] "In addition, we show very compelling evidence that the weak SINDy formulation provides significant improvements over the traditional method, even on clean data."
  - [section] "Interestingly, the typical justification for the high performance of weak formulations of sparse regression is that it allows the user to avoid amplifying noise when computing derivatives of the data. However, we find significant improvements with the weak formulation even when there is no added noise"

### Mechanism 2
- Claim: Ensemble methods with subsampling significantly improve noise robustness by averaging over multiple model instances
- Mechanism: Generating 10 models per threshold value by subsampling 50% of trajectory data without replacement and averaging results reduces variance and improves model stability
- Core assumption: The true dynamics are consistent across different subsamples of the same trajectory
- Evidence anchors:
  - [section] "For all the algorithms, we use ensembling [94]. We subsample the five training trajectories by choosing 50% of the total trajectory data without replacement in order to generate 10 models for each value of the threshold hyperparameter."
  - [section] "This is because models with many parameters can overfit using many small but nonzero terms and potentially produce very accurate testing trajectories if we only investigate regions that are nearby to the strange attractor(s)"

### Mechanism 3
- Claim: Pareto-optimal model selection using AIC balances sparsity and accuracy, preventing overfitting while maintaining predictive power
- Mechanism: The AIC criterion penalizes model complexity while rewarding goodness of fit, automatically selecting models that generalize well to new data
- Core assumption: The true underlying dynamics can be captured by a sparse set of terms from the polynomial library
- Evidence anchors:
  - [section] "We then sweep over 300 values of increasingly large hard thresholds, and determine the best threshold by the minimal, finite-sample-size-corrected, Akaike information criterion (AIC) [80] averaged over the 10 models generated by subsampling"
  - [section] "This is because models with many parameters can overfit using many small but nonzero terms and potentially produce very accurate testing trajectories if we only investigate regions that are nearby to the strange attractor(s)"

## Architecture Onboarding

- Component map: Data generation → Feature library construction → Derivative computation → Sparse optimization (STLSQ/Lasso/SR3/MIOSR) → Pareto front generation (AIC) → Ensemble averaging → Performance evaluation
- Critical path: The derivative computation step is critical since it directly impacts all subsequent optimization; weak formulation bypasses this bottleneck
- Design tradeoffs: Traditional vs weak formulation (speed vs noise robustness), greedy vs exact optimization (speed vs optimality), ensemble size vs computational cost
- Failure signatures: Large coefficient errors indicate overfitting or noise issues; unstable trajectories indicate incorrect high-order terms; poor AIC scores indicate suboptimal hyperparameter selection
- First 3 experiments:
  1. Run STLSQ on a simple 3D chaotic system (e.g., Lorenz63) with clean data to verify basic functionality
  2. Compare traditional vs weak formulation performance on a noisy dataset to observe noise robustness
  3. Generate ensemble models with different subsampling rates to understand variance reduction effects

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do SINDy models perform on datasets with even higher levels of noise than 1%?
- Basis in paper: [explicit] The authors note that at 1% noise levels, STLSQ and MIOSR still perform well, but they did not test larger noise values. They mention that weak or integral formulations are required for high-noise settings.
- Why unresolved: The study only tested up to 1% noise levels. The performance of different algorithms at higher noise levels remains unexplored.
- What evidence would resolve it: Systematic testing of SINDy algorithms on datasets with noise levels exceeding 1%, comparing traditional and weak formulations, and evaluating model stability and accuracy.

### Open Question 2
- Question: Does model performance depend on the effective dimension of the attractor rather than the state space dimension?
- Basis in paper: [inferred] The authors discuss invariant manifolds and reduced effective dimensions in Appendix C, noting that chaotic systems can have effective dimensions on attractors significantly smaller than state space dimension. They found weak correlations between dynamical properties and model performance.
- Why unresolved: The study used simple metrics like Lyapunov exponents and description length rather than effective dimension. The relationship between attractor dimension and model performance was not directly investigated.
- What evidence would resolve it: Direct computation of attractor dimensions for each system and correlation analysis with model performance, controlling for state space dimension and other properties.

### Open Question 3
- Question: How would optimizing for dynamical properties like stiffness or stability affect SINDy performance?
- Basis in paper: [explicit] The authors mention in Appendix C that many dynamical or engineering-focused metrics can be directly minimized during optimization, and optimizing stiffness and stability would be useful for finding models applicable to chaos control.
- Why unresolved: The study used standard AIC for hyperparameter selection rather than incorporating dynamical properties into the objective function. The impact of such modifications remains unknown.
- What evidence would resolve it: Implementation of SINDy variants that optimize for stiffness or stability metrics, comparison with baseline SINDy performance, and evaluation on datasets requiring long-term stability for applications like chaos control.

## Limitations
- Limited to polynomial systems from the dysts database, potentially missing performance characteristics on non-polynomial chaotic systems
- Fixed polynomial library order (4th degree) may not be optimal for all systems, and performance sensitivity to this parameter was not explored
- Algorithm-specific limitations, particularly for SR3 which shows inconsistent performance in weak formulation settings

## Confidence
- High confidence in weak formulation performance improvements due to systematic testing across 70 systems and multiple noise levels
- High confidence in STLSQ and MIOSR as best overall performers based on comprehensive benchmarking
- Medium confidence in minimal dependence on dynamical properties due to limited range of chaos measures available in database

## Next Checks
