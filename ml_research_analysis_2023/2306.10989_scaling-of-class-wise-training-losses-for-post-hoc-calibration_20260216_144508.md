# Scaling of Class-wise Training Losses for Post-hoc Calibration

## Quick Facts
- arXiv ID: 2306.10989
- Source URL: https://arxiv.org/abs/2306.10989
- Reference count: 11
- Key outcome: Class-wise loss scaling improves post-hoc calibration performance while preserving accuracy across multiple datasets and architectures

## Executive Summary
This paper addresses the challenge of model calibration in deep learning, where prediction reliability is crucial for safety-critical applications. The authors propose a novel method called class-wise loss scaling that synchronizes divergent class-wise training losses to improve calibration performance. By using multiple scaling factors based on sigmoid functions, the method compensates for overfitted and underfitted classes while preserving the total training loss, thus preventing accuracy degradation during calibration. The approach can be easily integrated with existing post-hoc calibration methods and demonstrates state-of-the-art calibration performance across CIFAR-10, CIFAR-100, and ImageNet datasets.

## Method Summary
The method computes class-wise losses from pre-trained model outputs, normalizes them using Gaussian normalization, and applies scaling factors derived from optimized sigmoid parameters (α and β) to create balanced class-wise training losses. These scaled losses are then used to train post-hoc calibration functions (such as Temperature Scaling, Ensemble Temperature Scaling, Parametric Temperature Scaling, and Class-wise Temperature Scaling) instead of using the original total loss. The SLSQP optimizer is used to find optimal scaling parameters that minimize calibration error while preserving accuracy. This approach allows the use of pre-trained models as initialization, reducing computational overhead compared to full retraining.

## Key Results
- State-of-the-art calibration performance on CIFAR-10, CIFAR-100, and ImageNet datasets
- Preservation of original model accuracy while significantly reducing Expected Calibration Error (ECE)
- Effective performance on imbalanced datasets (CIFAR-10-LT and CIFAR-100-LT) without hyperparameter tuning
- Successful integration with multiple post-hoc calibration methods (TS, ETS, PTS, CTS)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Diverging class-wise training losses are the root cause of miscalibration in deep learning models.
- Mechanism: The variance of class-wise losses across training epochs is highly correlated with expected calibration error (ECE). When some classes have much higher losses than others, the model becomes overconfident on some classes and underconfident on others.
- Core assumption: Class-wise losses reflect relative confidence calibration quality, not just overall accuracy.

- Core assumption: Total loss preservation prevents accuracy degradation during calibration.

## Architecture Onboarding

- Component map:
  Pre-trained model (classifier g) -> Post-hoc calibration function f (TS, ETS, PTS, CTS) -> Class-wise loss scaling estimator (sigmoid-based weight computation) -> Loss normalization module (Gaussian normalization) -> SLSQP optimizer (for α, β optimization)

- Critical path:
  1. Compute class-wise losses from pre-trained model outputs
  2. Normalize class-wise losses using Gaussian normalization
  3. Optimize α and β parameters using SLSQP
  4. Compute class-wise scaling weights using sigmoid function
  5. Apply scaled losses to calibration function training
  6. Evaluate calibration performance on test set

- Design tradeoffs:
  - Using pre-trained models saves computation but may limit calibration potential
  - Gaussian normalization handles outliers better than Min-Max but adds complexity
  - SLSQP optimization adds training overhead but enables automatic weight computation

- Failure signatures:
  - Unstable α, β values during optimization
  - Large discrepancy between training and validation calibration performance
  - Accuracy degradation despite improved ECE

- First 3 experiments:
  1. Run baseline calibration method (e.g., Temperature Scaling) on CIFAR10 with WideResNet32 and measure ECE
  2. Apply class-wise loss scaling to the same configuration and compare ECE and accuracy

## Limitations
- Performance degradation on extremely imbalanced datasets with high class imbalance ratios
- Limited evaluation on specialized architectures beyond standard CNNs
- Sensitivity to initialization of scaling parameters α and β during optimization

## Confidence
- High Confidence: The correlation between class-wise loss variance and calibration error is well-supported by empirical evidence, with strong experimental results demonstrating improved ECE across multiple datasets and architectures.
- Medium Confidence: The preservation of total loss through scaling factors appears effective, but the long-term stability of this approach across diverse training scenarios requires further investigation.
- Low Confidence: The generalizability to extremely imbalanced datasets and the behavior with very deep or specialized architectures (like vision transformers) remains untested.
