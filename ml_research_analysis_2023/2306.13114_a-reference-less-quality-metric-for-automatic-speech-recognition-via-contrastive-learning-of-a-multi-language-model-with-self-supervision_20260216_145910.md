# A Reference-less Quality Metric for Automatic Speech Recognition via Contrastive-Learning of a Multi-Language Model with Self-Supervision

## Quick Facts
- arXiv ID: 2306.13114
- Source URL: https://arxiv.org/abs/2306.13114
- Reference count: 0
- Proposes NoRefER, a referenceless quality metric for ASR systems using contrastive learning

## Executive Summary
This paper introduces NoRefER, a novel reference-less quality metric for automatic speech recognition systems. The metric employs contrastive learning with a multi-language model to evaluate ASR output quality without requiring ground truth transcriptions. By fine-tuning a pre-trained language model using Siamese architecture on pairwise ASR hypotheses with varying quality levels, NoRefER demonstrates strong correlation with word error rate (WER) scores across multiple languages and ASR systems.

## Method Summary
NoRefER leverages contrastive learning to fine-tune a pre-trained multi-language model on pairwise combinations of ASR outputs with known quality differences. The approach uses a Siamese architecture where the model learns to distinguish between higher and lower quality ASR hypotheses. This training enables the metric to assess ASR quality without access to reference transcriptions. The method also enables ensembling of ASR hypotheses, achieving over 7% WER reduction when used for system combination.

## Key Results
- NoRefER shows strong correlation with WER scores across multiple languages and ASR systems
- Outperforms baseline perplexity-based metrics in quality assessment
- Achieves over 7% WER reduction when used for ensembling ASR hypotheses

## Why This Works (Mechanism)
The contrastive learning approach allows NoRefER to learn quality distinctions directly from ASR output pairs, eliminating the need for reference transcriptions. By training on diverse language pairs and quality levels, the metric develops a robust understanding of quality patterns across different linguistic phenomena. The Siamese architecture enables effective comparison between hypotheses, while the multi-language model provides broad linguistic coverage for quality assessment.
