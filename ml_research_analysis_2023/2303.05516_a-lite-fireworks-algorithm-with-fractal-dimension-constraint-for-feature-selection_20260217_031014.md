# A Lite Fireworks Algorithm with Fractal Dimension Constraint for Feature Selection

## Quick Facts
- arXiv ID: 2303.05516
- Source URL: https://arxiv.org/abs/2303.05516
- Reference count: 40
- Classification accuracies of 93.91% and 78.99% achieved on UCI datasets

## Executive Summary
This paper proposes a Lite Fireworks Algorithm with Fractal Dimension constraint (LFW A+FD) for feature selection in high-dimensional visual data processing for robotics applications. The method combines a simplified fireworks algorithm with fractal dimension-based feature dimensionality reduction to address computational constraints in traditional machine learning approaches. The algorithm constructs an adaptive explosion radius using historical data and employs fractal dimension to constrain the number of selected features.

## Method Summary
The LFW A+FD method integrates a simplified fireworks algorithm with fractal dimension constraints to optimize feature selection for high-dimensional visual data in robotics applications. The approach uses an adaptive explosion radius based on historical data and fractal dimension calculations to determine the optimal number of features to retain. This combination aims to reduce noise in the original data while maintaining classification accuracy, making it suitable for resource-constrained robotics vision systems.

## Key Results
- Classification accuracies of 93.91% and 78.99% achieved on two UCI datasets
- Feature dimension reductions of 84.21% and 93.18% respectively
- Outperforms comparison methods while using significantly fewer features

## Why This Works (Mechanism)
Assumption: The method works by leveraging fractal dimension as a measure of feature complexity and relevance. The adaptive explosion radius allows the algorithm to dynamically adjust its search space based on historical performance, while the fractal dimension constraint ensures that only the most informative features are retained. This dual approach addresses both the exploration-exploitation tradeoff in optimization and the curse of dimensionality in high-dimensional data.

## Foundational Learning
- Fireworks Algorithm: Metaheuristic optimization technique inspired by fireworks explosions, used for exploring solution spaces efficiently
- Fractal Dimension: Mathematical concept measuring complexity and self-similarity in data structures, useful for quantifying feature relevance
- Feature Selection: Process of identifying and retaining most informative features while removing redundant or irrelevant ones to improve model efficiency
- Adaptive Explosion Radius: Dynamic adjustment of search space based on historical performance data to balance exploration and exploitation
