# Fairly Predicting Graft Failure in Liver Transplant for Organ Assigning

## Quick Facts
- **arXiv ID**: 2302.09400
- **Source URL**: https://arxiv.org/abs/2302.09400
- **Reference count**: 40
- **Primary result**: Proposes fair machine learning framework combining deep learning and tree models for liver transplant graft failure prediction

## Executive Summary
This paper addresses the critical issue of fairness in liver transplant graft failure prediction, which directly impacts organ allocation decisions. The authors propose a hybrid machine learning framework that combines the strengths of tree-based models for dense features with neural networks for sparse features, enhanced by knowledge distillation and a two-step debiasing strategy. The framework aims to make accurate and fair predictions across different racial and gender groups, outperforming existing methods in both prediction performance and fairness metrics.

## Method Summary
The proposed framework integrates deep learning and tree-based models to handle mixed feature types in liver transplant data. It employs knowledge distillation to transfer insights from tree models to neural networks, and implements a two-step debiasing approach to enhance fairness. The method processes sparse features through embedding layers and factorization machines, while dense features are handled via a distillation network. Fairness constraints are incorporated at both the knowledge distillation stage and during end-to-end training to ensure equitable predictions across sensitive attributes.

## Key Results
- The framework achieves superior performance in both prediction accuracy and fairness metrics compared to existing methods
- Fair predictions are maintained across different races and genders, addressing critical bias concerns in organ allocation
- The two-step debiasing approach effectively enhances fairness without significantly compromising prediction accuracy

## Architecture Onboarding

- Component map: Data preprocessing -> Sparse feature processing -> Dense feature processing -> Fairness enforcement -> Final prediction
- Critical path: Data preprocessing → Embedding layer → Factorization Machine → Deep Neural Network → Tree model training → Knowledge distillation → Fairness loss → Final prediction
- Design tradeoffs:
  - One-hot vs. integer encoding for sparse features: One-hot captures all categories but suffers from dimensionality curse; integer encoding is compact but may miss category relationships
  - Fairness loss weight balancing: Too much weight on fairness reduces accuracy; too little fails to mitigate bias
  - Tree model selection: More complex trees may capture more patterns but risk overfitting and unstable distillation
- Failure signatures:
  - High DPD/EOD with low ROC AUC: Model is fair but inaccurate
  - Low DPD/EOD with high ROC AUC: Model is accurate but unfair
  - Inconsistent results across cross-validation folds: Unstable tree model or distillation process
  - Poor performance on minority groups: Insufficient representation or model capacity for those groups

## Limitations

- Knowledge distillation assumption lacks rigorous empirical validation for transplant fairness applications
- Two-step debiasing effectiveness depends heavily on proper tuning of fairness loss weights
- Potential feedback loops from biased historical decisions in training data are not addressed
