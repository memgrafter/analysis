# CLaC at SemEval-2023 Task 2: Comparing Span-Prediction and Sequence-Labeling approaches for NER

## Executive Summary
This paper presents a comparison between Span Prediction and Sequence Labeling approaches for Named Entity Recognition (NER) using the MultiCoNER 2 dataset. The authors evaluate both methods using XLM-RoBERTa as the underlying language model, with experiments on both base and large model variants. Their results show that the Span Prediction approach slightly outperforms Sequence Labeling on test data, while using the larger XLM-RoBERTa model significantly improves performance for both approaches. The authors also discover that using special input tokens (<s> and </s>) improves performance in post-competition experiments.

## Method Summary
The paper compares two popular NER approaches: Sequence Labeling and Span Prediction. For Sequence Labeling, they use BIO (Begin-Inside-Outside) tagging scheme where each token is labeled as B (beginning of entity), I (inside entity), or O (outside entity). For Span Prediction, they use a question-answering approach where the model predicts entity spans and their corresponding types by answering questions like "What is the type of the entity at position X?" The experiments are conducted using XLM-RoBERTa as the backbone model, with both base (XLM-RoBERTa-base) and large (XLM-RoBERTa-large) variants tested to evaluate the impact of model size.

## Key Results
- The best Span Prediction system slightly outperforms the best Sequence Labeling system on test data
- Using XLM-RoBERTa-large significantly improves performance compared to XLM-RoBERTa-base
- Post-competition experiments show that using special input tokens (<s> and </s>) improves the performance of both approaches

## Architecture Onboarding
- **Component Map**: Input Text -> XLM-RoBERTa -> (Sequence Labeling or Span Prediction) -> NER Output
- **Critical Path**: Raw text is tokenized, passed through XLM-RoBERTa encoder, then either through a classification layer (for sequence labeling) or span prediction layer (for span prediction), producing final entity predictions
- **Design Tradeoffs**: Sequence labeling is simpler and faster but may struggle with entity boundaries; span prediction is more flexible but computationally heavier and requires post-processing
- **Failure Signatures**: Sequence labeling may produce invalid BIO sequences; span prediction may generate overlapping spans or miss entities at sentence boundaries
