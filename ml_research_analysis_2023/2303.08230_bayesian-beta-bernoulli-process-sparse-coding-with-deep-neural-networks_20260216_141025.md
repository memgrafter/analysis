# Bayesian Beta-Bernoulli Process Sparse Coding with Deep Neural Networks

## Quick Facts
- arXiv ID: 2303.08230
- Source URL: https://arxiv.org/abs/2303.08230
- Reference count: 7
- Introduces Beta-Bernoulli Process Sparse Coding with Deep Neural Networks (BPE-SCN), a non-parametric iterative algorithm for learning discrete latent representations

## Executive Summary
This paper introduces Beta-Bernoulli Process Sparse Coding with Deep Neural Networks (BPE-SCN), a non-parametric iterative algorithm for learning discrete latent representations in deep models. The key innovation is using a Beta-Bernoulli process prior on latent factors to encourage sparsity, along with local data scaling variables for scale-invariant discrete features. The method employs a MAP-EM greedy pursuit algorithm that decouples the encoder and decoder, reducing generalization error to just the reconstruction error.

## Method Summary
BPE-SCN uses a Beta-Bernoulli process prior on latent factors to enforce sparsity and local scaling variables for scale-invariant feature learning. The method employs MAP-EM greedy pursuit to optimize latent codes without amortization bias, decoupling encoder and decoder. The approach is evaluated on MNIST, CIFAR-10, and 20-Newsgroup datasets, showing improved reconstruction errors and sparsity compared to VAE baselines.

## Key Results
- Achieves better reconstruction errors than VAEs (8.51 MSE on CIFAR-10 vs 16.94 for VAE)
- Learns substantially sparser latent encodings (0.86 sparsity vs 0.81 for VAE)
- Beta-Bernoulli process prior leads to encodings with more true zeros compared to other sparsity-promoting priors
- Local scaling variables enable scale-invariant feature learning

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Beta-Bernoulli process prior enforces sparsity by assigning low activation probabilities to most dimensions
- Mechanism: Each latent dimension has probability πk from Beta distribution, leading to znk being 0 with high probability
- Core assumption: Beta process is valid non-parametric prior that encourages true zeros
- Evidence anchors: [abstract], [section] on Beta-Bernoulli prior encouraging sparse encodings
- Break condition: If Beta hyperparameters are mis-specified, sparsity may not emerge or may be excessive

### Mechanism 2
- Claim: Local scaling variables λn enable scale-invariant feature learning
- Mechanism: Separate scale parameter λn is introduced for each data point, drawn from Gaussian/Gamma distribution
- Core assumption: Scale variations are independent of underlying discrete latent structure
- Evidence anchors: [abstract], [section] on disentangling scale from latent representation
- Break condition: If local scale prior is misspecified or data contains scale-content correlations

### Mechanism 3
- Claim: MAP-EM greedy pursuit avoids amortization bias, improving generalization
- Mechanism: Non-parametric iterative search finds zn = arg maxz p(x,z;θ) by sequentially activating bits
- Core assumption: Non-parametric greedy search can find good MAP estimate without prohibitive cost
- Evidence anchors: [abstract], [section] on non-parametric encoder reducing generalization error
- Break condition: If search space too large or sparsity insufficient, algorithm may get stuck in poor local optima

## Architecture Onboarding

- Component map: Prior layer (Beta-Bernoulli process) -> Local scale layer (λn) -> Encoder (MAP-EM greedy pursuit) -> Decoder (Deep neural network) -> Likelihood (Gaussian/Poisson/Bernoulli)

- Critical path:
  1. Sample batch B
  2. Update q(λn) for each n in B (if applicable)
  3. Update q(πk) for each k using natural gradient
  4. For each n in B, run greedy pursuit to find zn
  5. Update global parameters θ using ADAM on lower bound
  6. Repeat until convergence

- Design tradeoffs:
  - Non-parametric encoder vs parametric: better accuracy, slower inference
  - Beta-Bernoulli prior vs Laplace/Cauchy: enforces true zeros, potentially sparser codes
  - Local scaling vs no scaling: scale invariance at cost of extra parameters and marginalization

- Failure signatures:
  - If sparsity too low: Beta-Bernoulli hyperparameters too large, greedy pursuit not effective
  - If inference too slow: sparsity not emerging, need to adjust prior or early stopping
  - If reconstructions poor: neural network capacity insufficient, likelihood model mismatch

- First 3 experiments:
  1. Verify Beta-Bernoulli prior induces sparsity on synthetic binary data with known sparse structure
  2. Test local scaling by training on MNIST with random intensity scaling and comparing latent codes
  3. Compare greedy pursuit MAP-EM encodings to VAE encodings on small dataset, measuring reconstruction error and sparsity
