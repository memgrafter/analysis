# Inspecting class hierarchies in classification-based metric learning models

## Quick Facts
- **arXiv ID**: 2301.11065
- **Source URL**: https://arxiv.org/abs/2301.11065
- **Reference count**: 40
- **Primary result**: Proposes evaluation measures for classification models considering class hierarchies, finding ProxyDR outperforms NormFace on hierarchical inference

## Executive Summary
This paper addresses the evaluation of classification models that incorporate class hierarchies by proposing performance measures that assess both standard classification accuracy and alignment between learned class representatives and predefined hierarchical structures. The authors train softmax classifiers and three metric learning models (NormFace, ProxyDR, CORR loss) with various training options on benchmark and real-world datasets. They find that ProxyDR, when trained without predefined hierarchies, achieves significantly better hierarchical inference performance than NormFace, and that CNNs with random weights surprisingly correspond to predefined hierarchies better than random chance.

## Method Summary
The authors develop a framework for evaluating classification-based metric learning models that considers class hierarchies through class representatives in embedding space. They train multiple models including softmax classifiers, NormFace, ProxyDR, and CORR loss on both benchmark and real-world datasets. The evaluation combines standard classification accuracy with new hierarchy-informed performance measures that assess how well learned class representatives align with predefined hierarchical structures. Different training options are explored, including whether to use predefined hierarchies during training.

## Key Results
- ProxyDR model trained without predefined hierarchies achieves significantly better hierarchical inference performance than NormFace
- ProxyDR enhances some hierarchy-informed performance measures under the same training options
- CNNs with random weights correspond to predefined hierarchies better than random chance

## Why This Works (Mechanism)
The paper's evaluation framework works by measuring not just classification accuracy but also how well learned embeddings respect predefined hierarchical relationships between classes. This is achieved through class representatives in embedding space that can be compared against ground truth hierarchical structures. The ProxyDR model appears to better capture hierarchical relationships even without explicit hierarchical supervision during training, suggesting it learns meaningful structure from the data itself.

## Limitations
- Evaluation framework tested only on three metric learning methods (NormFace, ProxyDR, CORR loss)
- Claims about ProxyDR outperforming NormFace lack statistical significance testing across multiple seeds
- Random CNN performance claims need stronger baselines including pretrained features
- Scalability of evaluation framework to larger, more complex hierarchies not demonstrated
- No ablation studies varying network depth/width for random CNN experiments

## Confidence
- **High**: Classification accuracy measurements are standard and reliable
- **Medium**: Hierarchy-informed performance measures show directional trends but need validation
- **Low**: Claims about random CNN weights capturing hierarchies need substantial additional evidence

## Next Checks
