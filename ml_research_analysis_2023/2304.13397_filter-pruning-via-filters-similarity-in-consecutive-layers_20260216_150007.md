# Filter Pruning via Filters Similarity in Consecutive Layers

## Quick Facts
- **arXiv ID:** 2304.13397
- **Source URL:** https://arxiv.org/abs/2304.13397
- **Reference count:** 0
- **Primary result:** Filter Similarity in Consecutive Layers (FSCL) achieves state-of-the-art performance in filter pruning on CIFAR-10 and ImageNet datasets, outperforming other methods in terms of accuracy, FLOPs, and parameter reduction.

## Executive Summary
This paper proposes Filter Similarity in Consecutive Layers (FSCL), a novel filter pruning method that leverages the relationship between filters and channels in consecutive layers. Traditional methods process each layer independently, missing opportunities to exploit cross-layer information. FSCL addresses this by calculating the similarity between filters in consecutive layers using convolution operations, which quantifies the worth of features extracted by filters. The method prunes filters with lower importance scores, leading to improved model compression while maintaining accuracy.

## Method Summary
FSCL is a filter pruning method that exploits the relationship between filters in consecutive layers. It calculates the similarity between filters using convolution operations to quantify the importance of features extracted by filters. The method prunes filters with lower importance scores, resulting in improved model compression while maintaining accuracy. FSCL outperforms other methods on CIFAR-10 and ImageNet datasets, achieving state-of-the-art performance in terms of accuracy, FLOPs, and parameter reduction.

## Key Results
- On CIFAR-10, FSCL pruned VGG-16 by 81.5% FLOPs and 89.5% parameters with only a 0.28% accuracy drop.
- On ImageNet, FSCL pruned ResNet-50 by 53.8% parameters and 55.99% FLOPs with only a 0.31% accuracy drop.
- FSCL outperforms other methods in terms of accuracy, FLOPs, and parameter reduction.

## Why This Works (Mechanism)
FSCL works by exploiting the relationship between filters in consecutive layers. It calculates the similarity between filters using convolution operations, which quantifies the importance of features extracted by filters. By pruning filters with lower importance scores, FSCL reduces the model size and computational cost while maintaining accuracy. The method leverages cross-layer information, which traditional methods often miss, leading to improved compression efficiency.
