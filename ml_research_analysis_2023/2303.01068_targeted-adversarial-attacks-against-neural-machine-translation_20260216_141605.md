# Targeted Adversarial Attacks against Neural Machine Translation

## Quick Facts
- arXiv ID: 2303.01068
- Source URL: https://arxiv.org/abs/2303.01068
- Reference count: 25
- Primary result: Proposed attack outperforms Seq2Sick method with >75% success rate in inserting target keywords while maintaining translation similarity

## Executive Summary
This paper addresses targeted adversarial attacks against Neural Machine Translation (NMT) models, focusing on inserting predefined keywords into translations while preserving semantic similarity with the original sentence. The authors propose an optimization-based approach that operates in the continuous embedding space of NMT models, using gradient projection to craft adversarial examples. The method dynamically selects attack positions and employs a linear transformation between NMT and language model embedding spaces to measure semantic similarity.

## Method Summary
The attack formulates an optimization problem combining adversarial loss (to ensure keyword insertion) and similarity loss (to preserve original meaning). It solves this iteratively using gradient projection in the NMT embedding space, projecting back to valid tokens using language model embeddings. A linear transformation maps between NMT and LM embedding spaces, enabling similarity computation. The algorithm dynamically selects the best attack position in each iteration based on logit differences between the most probable token and target keyword.

## Key Results
- Attack succeeds in inserting target keywords for >75% of test sentences
- Outperforms Seq2Sick method in both success rate and translation quality degradation
- Maintains semantic similarity with original sentences through embedding space projection

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Gradient projection in embedding space enables adversarial example crafting while preserving semantic similarity
- Mechanism: Iterative gradient descent in NMT's continuous embedding space, followed by projection to nearest valid tokens using LM embeddings
- Core assumption: LM embeddings capture semantic similarity and projection finds valid semantically-similar tokens
- Evidence anchors: [abstract] gradient projection in embedding space; [section 3] embedding representation of LM for projection; [corpus] optimization in embedding space
- Break condition: Projection consistently maps to semantically distant tokens or LM embeddings fail to capture semantic similarity

### Mechanism 2
- Claim: Dynamic position selection maximizes attack success rate
- Mechanism: Algorithm dynamically selects position minimizing logit difference between most probable token and target keyword in each iteration
- Core assumption: Position with minimum logit difference is easiest to attack and can change as adversarial example evolves
- Evidence anchors: [section 2] dynamic position selection algorithm; [section 3] best position found in every iteration; [corpus] dynamic position selection for maximum success rate
- Break condition: Optimal attack position becomes unstable or consistently leads to semantically implausible sentences

### Mechanism 3
- Claim: Linear transformation enables effective similarity measurement between embedding spaces
- Mechanism: Linear function L(.) maps NMT embedding vectors to LM embedding vectors for similarity computation
- Core assumption: Linear transformation adequately preserves semantic relationships between embedding spaces
- Evidence anchors: [section 3] linear function L for LM embedding vectors; [section 2] LM embedding representation for similarity computation; [corpus] linear transformation for similarity computation
- Break condition: Linear transformation cannot adequately capture relationship between embedding spaces, leading to inaccurate similarity measurements

## Architecture Onboarding

- Component map: Input sentence -> NMT model -> Embedding space -> Linear transformation L(.) -> LM embedding space -> Similarity computation -> Output adversarial sentence

- Critical path:
  1. Tokenize input sentence
  2. Convert to NMT embeddings
  3. Apply linear transformation to LM embeddings
  4. Compute adversarial loss and similarity term
  5. Perform gradient descent step
  6. Project to nearest valid tokens
  7. Check if target keyword is in translation
  8. Repeat until success or max iterations

- Design tradeoffs:
  - Embedding space choice: NMT embeddings vs. LM embeddings for similarity computation
  - Projection method: Using LM embeddings vs. other similarity metrics
  - Position selection: Dynamic vs. fixed attack position
  - Hyperparameter α: Balancing attack success vs. similarity preservation

- Failure signatures:
  - Low success rate despite high similarity: Attack is too conservative
  - High success rate but low similarity: Attack is too aggressive
  - Oscillating between similar sentences: Projection step is ineffective
  - Converging to semantically meaningless sentences: Linear transformation is inadequate

- First 3 experiments:
  1. Test linear transformation L by mapping NMT embeddings to LM embeddings and measuring cosine similarity preservation
  2. Evaluate projection step by taking random NMT embeddings, projecting them, and checking semantic similarity of resulting tokens
  3. Run attack with α=0 (no similarity constraint) to establish upper bound on success rate for comparison

## Limitations
- Linear transformation between embedding spaces may not adequately preserve semantic relationships
- Attack performance on language pairs beyond English-French and English-German remains untested
- Computational cost of iterative gradient projection may limit practical real-world applicability

## Confidence

**High Confidence**: Basic optimization framework combining adversarial and similarity terms is mathematically sound; iterative approach is well-defined and logically consistent.

**Medium Confidence**: Dynamic position selection improving attack success rate is supported by algorithm description but needs broader empirical validation; claim of outperforming Seq2Sick appears reasonable but comparative analysis with recent methods would strengthen this.

**Low Confidence**: Assumption that linear transformation adequately preserves semantic similarity requires rigorous validation; claim of >75% success rate maintaining similarity needs verification across broader test sets and scenarios.

## Next Checks

1. **Embedding Space Transformation Validation**: Systematically evaluate linear transformation L by measuring preservation of semantic relationships between token pairs before and after transformation, including correlation coefficients for semantically related word pairs and testing relative distance maintenance.

2. **Cross-Lingual Generalization Test**: Extend attack evaluation beyond English-French and English-German to include less common language pairs and non-English target languages to test performance across different language families and resource availability levels.

3. **Real-World Feasibility Assessment**: Evaluate computational efficiency and practical limitations by measuring execution time across different sentence lengths and assessing quality degradation through professional human evaluations rather than automated metrics, testing real-time execution capability and human detectability.
