# Hierarchical Event Grounding

## Quick Facts
- arXiv ID: 2302.04197
- Source URL: https://arxiv.org/abs/2302.04197
- Reference count: 7
- This work extends event linking to hierarchical KB events, showing improved performance with auxiliary hierarchical loss.

## Executive Summary
This paper introduces the task of hierarchical event grounding, extending traditional event linking to include parent-child relationships among events in knowledge bases. The authors propose a retrieve-and-rerank framework with a bi-encoder for efficient candidate retrieval and a cross-encoder for fine-grained ranking. They introduce a hierarchical loss that enforces structural consistency in event embeddings, and demonstrate zero-shot hierarchical relation discovery using mention overlap. Experiments on a multilingual dataset show improved performance over strong baselines, particularly for cross-lingual and zero-shot scenarios.

## Method Summary
The proposed method uses a retrieve-and-rerank paradigm for hierarchical event grounding. A bi-encoder retrieves top-k event candidates for each mention using XLM-RoBERTa embeddings, while a cross-encoder re-ranks these candidates with full mention-context pairs. The bi-encoder training incorporates an auxiliary hierarchical loss that encourages parent-child events to have higher similarity than unrelated events, using a ComplEx-based scoring function. For zero-shot hierarchical relation extraction, the system computes mention overlap between event pairs as a proxy for parent-child relations. The framework is evaluated on a multilingual Wikipedia/Wikidata dataset with event hierarchies of maximum height 3.

## Key Results
- Proposed method outperforms strong baselines in hierarchical event linking on multilingual Wikipedia/Wikinews dataset
- Bi-encoder with hierarchical loss improves recall while cross-encoder re-ranking increases strict accuracy
- Zero-shot hierarchical relation extraction via mention overlap shows promise for discovering unseen event hierarchies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Auxiliary hierarchical loss improves retrieval by enforcing structural consistency in event embeddings
- Mechanism: ComplEx-based scoring function models asymmetric, transitive parent-child relations in complex space
- Core assumption: Asymmetric portion of Hermitian inner product captures directionality of parent-child relations
- Evidence anchors: Weak - no direct performance gain reported for this mechanism in isolation
- Break condition: Noisy parent-child links may introduce bias rather than signal

### Mechanism 2
- Claim: Retrieve-and-rerank paradigm enables effective multi-label event prediction
- Mechanism: Bi-encoder retrieves candidates efficiently, cross-encoder re-ranks with full context
- Core assumption: Cross-encoder can correct bi-encoder errors using full mention-context pairs
- Evidence anchors: Weak - no ablation on reranking-only vs combined performance
- Break condition: k too small (gold events missed) or too large (inefficient reranking)

### Mechanism 3
- Claim: Zero-shot hierarchical relation extraction via mention overlap captures implicit parent-child relations
- Mechanism: Fraction of shared mentions between events serves as parent-child proxy
- Core assumption: Child event mentions are subset of parent event mentions
- Evidence anchors: Weak - only evaluated on unseen subsets, no supervised baseline comparison
- Break condition: Ambiguous mentions or shared contexts without hierarchical relation

## Architecture Onboarding

- Component map: Wikipedia/Wikinews mentions -> Wikidata event candidates -> bi-encoder (retrieve) -> cross-encoder (re-rank) -> hierarchy-aware loss

- Critical path:
  1. Collect mention-event pairs and build hierarchies
  2. Train bi-encoder with BCE + optional hierarchy loss
  3. Retrieve top-k events per mention
  4. Train cross-encoder on retrieved pairs
  5. Apply threshold to cross-encoder scores for final predictions
  6. Use best bi-encoder for zero-shot hierarchy extraction

- Design tradeoffs:
  - Retrieval speed vs accuracy: bi-encoder fast but less precise; cross-encoder accurate but slow
  - k value: higher k increases recall but adds computational cost
  - Hierarchy loss weight: balances structural consistency against mention matching accuracy

- Failure signatures:
  - Low Recall@min but high Recall@k: model retrieves gold events but needs more candidates
  - High Recall@k but low strict accuracy: model over-predicts, needs stricter thresholding
  - Poor cross-lingual performance: bi-encoder embeddings may not align across languages

- First 3 experiments:
  1. Run baseline bi-encoder and measure Recall@min on dev set to establish performance floor
  2. Add hierarchical pretraining and compare recall and strict accuracy changes
  3. Train cross-encoder on top-8 retrievals and evaluate strict accuracy vs bi-encoder Recall@min

## Open Questions the Paper Calls Out

- Question: How does performance compare to system that first performs standard event linking then propagates hierarchy relations in KB?
- Basis in paper: Explicit mention of alternate task formulation requiring gold hierarchy relations at test time
- Why unresolved: No direct comparison between proposed system and two-step approach
- What evidence would resolve it: Comparative study using same dataset and evaluation metrics

- Question: How does performance vary across different languages, especially low-resource languages?
- Basis in paper: Overall results for multilingual and crosslingual tasks but no language-specific analysis
- Why unresolved: Paper provides aggregate results but not detailed language-specific performance
- What evidence would resolve it: Comprehensive analysis across all languages with focus on low-resource languages

- Question: How does system perform on events with varying hierarchical depths, and does performance degrade for deeper hierarchies?
- Basis in paper: Dataset includes hierarchies of height 3 but no depth-specific performance analysis
- Why unresolved: No detailed analysis of performance across different hierarchy depths
- What evidence would resolve it: Performance analysis on events with varying hierarchical depths

## Limitations

- Weak empirical evidence for hierarchical loss contribution due to lack of ablation studies
- Zero-shot hierarchy extraction relies on mention overlap without validation against ground truth
- Cross-lingual evaluation limited to only three languages, making generalization claims uncertain
- Claims about spatio-temporal granularity modeling lack direct evaluation or evidence

## Confidence

**High Confidence**: Retrieve-and-rerank paradigm is well-established with clear implementation details
**Medium Confidence**: Overall framework is sound but specific contribution of hierarchical loss unclear
**Low Confidence**: Claims about spatio-temporal granularity and ComplEx-based hierarchy loss not adequately supported
