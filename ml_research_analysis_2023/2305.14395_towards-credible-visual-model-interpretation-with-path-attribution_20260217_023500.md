# Towards credible visual model interpretation with path attribution

## Quick Facts
- **arXiv ID**: 2305.14395
- **Source URL**: https://arxiv.org/abs/2305.14395
- **Reference count**: 40
- **One-line primary result**: Novel path attribution method improves insertion-deletion AUC scores by up to 58.8% over baselines on ImageNet and CIFAR-10

## Executive Summary
This paper addresses reliability issues in path attribution methods for interpreting deep visual models. The authors identify three key problems: counter-intuitive attributions due to ill-defined baselines, ambiguous path features, and the need for well-specified baselines that mimic feature absence. They propose a novel method that integrates gradients over multiple baselines while enforcing validity checks on path features through gradient-based comparisons. Extensive experiments demonstrate consistent performance gains over baselines like Integrated Gradients, Expected Gradients, and Adversarial Gradient Integration, with improvements up to 58.8% in insertion-deletion AUC scores.

## Method Summary
The proposed method combines three solutions: (1) restricting baseline selection to the same open connected set as the input to avoid counter-intuitive attributions, (2) defining a desired baseline that minimizes model output difference while maintaining minimum feature difference to mimic feature absence, and (3) enforcing validity checks on path features by comparing gradient signs and magnitudes. The method computes a desired baseline using iterative updates that minimize ||F(x) - F(x')||₂ while ensuring |x_i - x'_i| ≥ δ for all features. Attribution maps are then computed by integrating gradients over multiple baselines (computed with Gaussian blur) and checking for valid path features where gradients have consistent signs and smaller magnitudes than at the input.

## Key Results
- Insertion-deletion AUC improvements up to 58.8% over Integrated Gradients, Expected Gradients, and Adversarial Gradient Integration
- Better sensitivity-N correlation indicating improved alignment between attributions and model output changes
- Consistent performance gains across ResNet, DenseNet, and VGG models on both ImageNet and CIFAR-10 datasets
- Visualizations show more coherent and interpretable attribution maps compared to baseline methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using a baseline from the same open connected set as the input avoids counter-intuitive attribution scores.
- Mechanism: Path attribution integrates gradients from baseline to input. If baseline and input lie in different linear regions of a piecewise linear model, gradients can change abruptly, causing inconsistent attributions. Restricting the baseline to the same open connected set ensures the model uses the same weights throughout integration, preserving weak dependence and completeness simultaneously.
- Core assumption: Piecewise linear function F is defined over open connected sets U_i, and attribution method weakly depends on input only through its neighborhood set U_i.
- Evidence anchors: [abstract] "pinpoint the conditions in which the counter-intuitive results can be avoided"; [section 5] "we always get abs(A1/A2) = 4 whenever x′ ∈ U2"; [corpus] No direct corpus evidence found.
- Break condition: Finding a baseline in the same connected set may be difficult or computationally expensive for models with many linear regions.

### Mechanism 2
- Claim: A well-specified baseline that mimics feature absence improves attribution reliability.
- Mechanism: The baseline represents feature absence. By defining a baseline that satisfies ||F(x) - F(x')||₂ ≈ 0 and |x_i - x'_i| ≥ δ for all features, the method ensures the baseline uses similar model weights as the input while enforcing minimum difference to avoid singularity in attribution computation.
- Core assumption: Computational analogue of feature absence can be achieved by minimizing model output difference between input and baseline while maintaining minimum feature difference.
- Evidence anchors: [abstract] "devise a scheme to preclude conditions in which visual model interpretation can invalidate axiomatic properties"; [section 5] "Our definition conforms to original idea that baseline signifies feature absence"; [corpus] No direct corpus evidence found.
- Break condition: If model output difference cannot be minimized without violating minimum feature difference constraint, finding valid baseline becomes challenging.

### Mechanism 3
- Claim: Valid path features, verified through gradient-based checks, ensure features on the path reside between feature absence and presence.
- Mechanism: By comparing signs and magnitudes of gradients at input and along path, the method identifies valid path features. A feature is valid if its gradient has same sign as input gradient and smaller magnitude, indicating it lies between input and baseline.
- Core assumption: Gradient magnitude and sign can reliably indicate relative position of feature between baseline and input on path.
- Evidence anchors: [abstract] "ensuring valid path features through gradient-based checks"; [section 5] "we can identify the valid features on the path defined by our path function γ"; [corpus] No direct corpus evidence found.
- Break condition: If model's gradient landscape is complex or non-smooth, gradient-based check may fail to identify valid path features accurately.

## Architecture Onboarding

- **Component map**: ComputeBaseline -> Path integration with gradient checks -> Attribution map generation
- **Critical path**: Baseline computation → Path integration with gradient checks → Attribution map generation
- **Design tradeoffs**:
  - Multiple baselines vs. single baseline: Using multiple baselines can suppress noise but increases computation time
  - Number of integration steps: More steps improve accuracy but increase computation time
  - Minimum feature difference (δ): Larger δ enforces stronger feature absence but may make finding valid baseline more difficult
- **Failure signatures**:
  - Poor baseline selection: If baseline is not in same open connected set as input, attribution scores may be counter-intuitive
  - Invalid path features: If gradient-based check fails to identify valid path features, attribution map may be unreliable
  - Noisy attributions: If integration path is not smooth or model has shattered gradients, attribution map may be noisy
- **First 3 experiments**:
  1. Implement ComputeBaseline algorithm and test on simple piecewise linear function with known open connected sets
  2. Implement Path integration algorithm with single baseline and test on simple deep learning model, comparing results with Integrated Gradients
  3. Extend Path integration algorithm to use multiple baselines and test on more complex deep learning model, evaluating performance gain over Integrated Gradients using insertion/deletion metrics

## Limitations
- Theoretical claims about open connected sets primarily demonstrated through synthetic examples rather than comprehensive empirical validation
- Gradient-based validity checks may not generalize well to models with complex, non-smooth gradient landscapes
- Computational overhead of finding suitable baselines from same open connected set as inputs could be prohibitive for real-world applications

## Confidence
- **High confidence**: Empirical improvements in insertion-deletion AUC scores and sensitivity-N correlation are well-supported by experimental results across multiple models and datasets
- **Medium confidence**: Theoretical framework connecting open connected sets to attribution reliability is sound but relies on idealized assumptions about piecewise linear models that may not fully capture real neural network behavior
- **Low confidence**: Claim that proposed method fundamentally resolves counter-intuitive attribution problem requires more extensive testing on diverse model architectures and failure cases
