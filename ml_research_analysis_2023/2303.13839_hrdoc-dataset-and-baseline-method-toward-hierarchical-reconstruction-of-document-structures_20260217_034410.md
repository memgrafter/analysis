# HRDoc: Dataset and Baseline Method Toward Hierarchical Reconstruction of Document Structures

## Quick Facts
- arXiv ID: 2303.13839
- Source URL: https://arxiv.org/abs/2303.13839
- Reference count: 16
- Key outcome: HRDoc dataset with 2,500 multi-page documents and DSPS model achieving micro F1 scores of 81.43% (simple) and 69.03% (hard) for hierarchical reconstruction

## Executive Summary
This paper introduces the hierarchical reconstruction of document structures as a novel task in both NLP and CV fields, aiming to convert multi-page documents into corresponding semantic structures. To support this task, the authors created a large-scale dataset called HRDoc, consisting of 2,500 multi-page documents with nearly 2 million line-level annotated semantic units. A hierarchical document structure parsing system (DSPS) was proposed, utilizing a multi-modal bidirectional encoder and a structure-aware GRU decoder with soft-mask operation. The DSPS model achieved significant improvements over baseline methods, with micro F1 scores of 81.43% and 69.03% on HRDoc-Simple and HRDoc-Hard datasets, respectively, for the overall hierarchical reconstruction task.

## Method Summary
The DSPS model is an encoder-decoder architecture that performs hierarchical document structure reconstruction. The encoder combines text embeddings (Sentence-Bert), layout embeddings, visual embeddings (ResNet-50 with RoIAlign), and page embeddings through layer normalization and concatenation before feeding into a transformer encoder. The decoder is a structure-aware GRU that predicts parent units using a soft-mask operation that incorporates domain-specific knowledge about likely parent-child relationships. The model simultaneously performs three subtasks: semantic unit classification, parent finding, and relation classification, with a multi-task learning loss function combining these objectives.

## Key Results
- DSPS achieved micro F1 scores of 81.43% on HRDoc-Simple and 69.03% on HRDoc-Hard datasets
- Cross-page hierarchical relationships are critical, with page-level processing showing significant performance degradation
- The soft-mask operation with domain-specific knowledge improved parent unit prediction accuracy

## Architecture Onboarding

- Component map: PDF → Semantic units → Encoder embeddings → GRU decoding → Parent finding → Relation classification → Tree reconstruction
- Critical path: PDF → Semantic units → Encoder embeddings → GRU decoding → Parent finding → Relation classification → Tree reconstruction
- Design tradeoffs:
  - Page-level vs document-level processing: Document-level enables cross-page relationships but increases computational complexity
  - Fixed vs dynamic vocabulary: Fixed vocabulary (14 classes) simplifies training but may not generalize to all document types
  - Soft-mask smoothing: Additive smoothing prevents zero probabilities but may introduce bias for rare relationships
- Failure signatures:
  - Low F1 scores on specific classes (e.g., Mail, Affiliation) suggest visual modality interference
  - Performance drop in page-level setting indicates cross-page relationships are critical
  - Imbalanced parent-child predictions suggest soft-mask parameters need adjustment
- First 3 experiments:
  1. Ablation study: Remove visual embeddings and measure classification performance degradation to quantify multimodal benefit
  2. Cross-page vs page-level comparison: Run DSPS in both settings on HRDoc-Hard to confirm cross-page relationships are essential
  3. Soft-mask sensitivity: Vary the smoothing parameter (currently 5) to find optimal balance between flexibility and domain knowledge enforcement

## Limitations

- Dataset Scope Limitation: The HRDoc dataset consists of 2,500 documents primarily from biomedical and computer science domains, which may limit generalizability to other document types
- Evaluation Metric Limitations: The paper relies solely on micro F1 scores for evaluation, which may not capture important aspects of hierarchical reconstruction quality
- Computational Complexity: The DSPS model processes documents at the line level with multimodal embeddings, which could become computationally expensive for documents with thousands of semantic units
