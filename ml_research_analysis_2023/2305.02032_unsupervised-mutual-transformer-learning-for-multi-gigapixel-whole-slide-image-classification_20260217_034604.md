# Unsupervised Mutual Transformer Learning for Multi-Gigapixel Whole Slide Image Classification

## Quick Facts
- **arXiv ID**: 2305.02032
- **Source URL**: https://arxiv.org/abs/2305.02032
- **Reference count**: 40
- **Primary result**: First fully unsupervised WSI classification algorithm using mutual transformer learning

## Executive Summary
This paper introduces an unsupervised whole slide image (WSI) classification method using mutual transformer learning. The approach leverages the inherent heterogeneity difference between disease-positive and disease-negative patches, using reconstruction error patterns to generate pseudo-labels. A transformer-based pseudo-label generator and cleaner work iteratively to refine instance-level classifications, achieving state-of-the-art performance on cancer detection and subtype classification tasks without any labeled data.

## Method Summary
The method uses a two-module mutual learning framework consisting of a Transformer Pseudo-Label Generator (TPLG) and Transformer Label Cleaner (TLC). TPLG extracts features from WSI patches and projects them into a latent space using transformer encoders, then reconstructs them with inverse projectors. The reconstruction error difference between homogeneous negative patches and heterogeneous positive patches enables pseudo-label generation. TLC cleans these labels using cross-entropy loss and graph smoothing. The modules iteratively refine each other using discriminative learning where positive instances are trained against fixed Gaussian noise targets, improving the disparity in reconstruction errors.

## Key Results
- First fully unsupervised WSI classification algorithm achieving competitive performance with supervised methods
- Mutual learning framework with transformer-based pseudo-label generator and cleaner shows superior performance
- Discriminative learning mechanism improves normal vs. cancerous instance labeling through reconstruction error disparity
- State-of-the-art performance on multiple datasets including cancer subtype classification

## Why This Works (Mechanism)

### Mechanism 1
The reconstruction error is systematically higher for disease-positive instances than for disease-negative ones, enabling unsupervised discrimination. The transformer projector encodes instances into a latent space, and the inverse projector reconstructs them. Disease-negative instances are more homogeneous, so they reconstruct with low error, while heterogeneous disease-positive instances yield high reconstruction error. This error difference drives pseudo-label assignment.

### Mechanism 2
Mutual learning between the transformer pseudo-label generator and cleaner improves classification accuracy over iterations. The TPLG generates pseudo-labels based on reconstruction error. These labels are cleaned by the TLC, which produces more reliable pseudo-labels. The cleaned labels are fed back to the TPLG in the next iteration with discriminative learning, iteratively refining both modules' performance.

### Mechanism 3
Discriminative learning using Gaussian noise as the target for positive instances increases transformation error disparity, improving discrimination. In subsequent iterations, the TPLG uses the original features as the reconstruction target for negative instances but uses a fixed random Gaussian noise matrix as the target for positive instances. This forces the projector to encode positive instances differently, increasing their reconstruction error relative to negatives.

## Foundational Learning

- **Transformer architecture with self-attention mechanisms**
  - Why needed here: The transformer projector and inverse projector must handle variable-length sequences of local windows from gigapixel images while capturing long-range dependencies and hierarchical patterns in tissue structures
  - Quick check question: Can you explain how self-attention in transformers differs from convolutional receptive fields in capturing spatial relationships?

- **Multiple Instance Learning (MIL) framework**
  - Why needed here: WSIs are treated as bags of instances (patches), and the goal is to predict slide-level labels from instance-level pseudo-labels without pixel-level annotations
  - Quick check question: How does the MIL assumption about instance-label relationships differ from standard supervised learning?

- **Graph-based label smoothing for instance clustering**
  - Why needed here: Spatially adjacent instances in WSIs are highly correlated, and graph convolutions help smooth isolated noisy labels by propagating information from neighboring instances
  - Quick check question: What graph structure would you use to connect instances within a WSI, and why?

## Architecture Onboarding

- **Component map**: Feature Extraction Head -> Transformer Projector -> Transformer Inverse Projector -> Reconstruction Loss -> Pseudo-label Generation -> Label Cleaning -> Discriminative Learning -> Graph Smoothing -> Slide-level Prediction

- **Critical path**: Feature extraction → Transformer projector → Inverse projector → Reconstruction loss → Pseudo-label generation → Label cleaning → Discriminative learning → Graph smoothing → Slide-level prediction

- **Design tradeoffs**:
  - Fixed vs. varying Gaussian noise for discriminative learning: Fixed noise provides consistent error increase for positive instances but may limit model adaptability
  - Number of transformer layers: More layers capture complex patterns but increase computational cost and overfitting risk
  - Graph smoothing neighborhood size: Larger neighborhoods provide better noise suppression but may blur local boundaries

- **Failure signatures**:
  - High reconstruction loss variance across instances suggests poor feature learning or inadequate transformer capacity
  - Pseudo-labels clustering around 0.5 probability indicates label cleaner not effectively separating classes
  - Graph smoothing not improving slide-level accuracy suggests spatial correlation assumptions are invalid

- **First 3 experiments**:
  1. Train TPLG only (without TLC) on CAMELYON-16 to verify reconstruction error pattern between positive and negative instances
  2. Implement TLC module and test label cleaning performance on synthetic noisy labels
  3. Add discriminative learning with Gaussian noise and measure transformation error disparity between positive and negative instances

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of the UMTL algorithm compare to other self-supervised learning methods for WSI classification? The paper compares UMTL to weakly-supervised methods and mentions that self-supervised learning can also be used to improve UMTL's performance, but does not provide a direct comparison.

### Open Question 2
Can the UMTL algorithm be extended to handle multi-class classification tasks beyond cancer vs. normal and cancer subtype classification? The paper demonstrates effectiveness for cancer vs. normal and cancer subtype classification tasks, but does not explore its potential for other multi-class classification tasks.

### Open Question 3
How does the performance of UMTL vary with different WSI datasets, especially those with different staining techniques or imaging modalities? The paper evaluates UMTL on four WSI datasets with similar staining techniques (H&E), but does not explore its performance on datasets with different staining or imaging modalities.

## Limitations
- Core assumption that disease-negative patches are more homogeneous than disease-positive patches may not hold across all cancer types and staining protocols
- Effectiveness of fixed Gaussian noise as a discriminative learning target needs systematic validation across different datasets
- Mutual learning framework's convergence behavior is not well-characterized for different initialization strategies
