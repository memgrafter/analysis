# Unsupervised Seismic Footprint Removal With Physical Prior Augmented Deep Autoencoder

## Quick Facts
- arXiv ID: 2302.10756
- Source URL: https://arxiv.org/abs/2302.10756
- Reference count: 40
- This paper presents FR-Net, a physical prior augmented deep learning method for unsupervised seismic footprint removal.

## Executive Summary
This paper introduces FR-Net, a novel deep learning approach for removing seismic footprints without requiring clean labels. The method leverages a unidirectional total variation (UTV) model that exploits the directional nature of footprint noise, allowing the network to separate noise from useful signals in an unsupervised manner. By combining this physical prior with a deep convolutional autoencoder, FR-Net achieves superior performance compared to state-of-the-art methods on both synthetic and real field datasets, effectively removing footprints while preserving signal resolution.

## Method Summary
FR-Net is a physical prior augmented deep convolutional autoencoder that removes seismic footprints in an unsupervised manner. The method converts 3D seismic data into time slices, extracts overlapping 50×50 patches, and processes them through an encoder-decoder architecture. The key innovation is the integration of a unidirectional total variation (UTV) regularization term that exploits the directional characteristics of footprint noise. The network is trained end-to-end using backpropagation with a composite loss function combining mean squared error and UTV regularization, eliminating the need for clean-label pairs.

## Key Results
- FR-Net achieves an SNR of 36.00 dB on synthetic data, outperforming other methods (10.29, 20.69, and 20.10 dB).
- On real field data, FR-Net effectively removes footprint noise without degrading seismic image resolution.
- The method successfully separates footprint noise from useful signals in an unsupervised manner.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The UTV model exploits directional consistency of footprint stripes to isolate them without prior signal assumptions.
- Mechanism: The UTV model penalizes vertical gradients (perpendicular to stripes) while preserving horizontal gradients (along stripes). This directional bias matches the physical structure of footprint noise, allowing the autoencoder to focus on denoising useful signal.
- Core assumption: Footprint noise is strictly directional and forms regular linear patterns.
- Evidence anchors:
  - [abstract]: "The key to the FR-Net is to design a unidirectional total variation (UTV) model for footprint acquisition according to the intrinsically directional property of noise."
  - [section]: "Making use of this linear feature, a TV technique is naturally chosen for the footprint removal task because of its edge preservation property... However, as depicted in Fig. 1(a), it is highly visible that a footprint has a clear directional signature."
  - [corpus]: Weak - neighbors do not discuss UTV or directional regularization specifically.
- Break condition: If footprints are not perfectly linear or if noise direction varies spatially, the UTV regularization may over-smooth or under-remove.

### Mechanism 2
- Claim: Unsupervised learning via physical prior augmented autoencoder avoids dependence on clean-label pairs.
- Mechanism: The autoencoder learns to reconstruct seismic data; the UTV regularization is added to the loss to push the model to remove directional patterns (footprints) while preserving signal. This allows training on noisy data alone.
- Core assumption: The autoencoder can learn to represent the signal structure without explicit clean labels when guided by UTV.
- Evidence anchors:
  - [abstract]: "The complete separation of footprint noise and useful signals is achieved by optimizing the FR-Net via backpropagation."
  - [section]: "By strongly regularizing a deep convolutional autoencoder (DCAE) using the UTV model, our FR-Net transforms the DCAE from an entirely data-driven model to a prior-augmented approach."
  - [corpus]: Weak - no direct evidence in neighbors of unsupervised autoencoder training with physical priors.
- Break condition: If the autoencoder cannot capture complex signal structures, the unsupervised reconstruction will fail.

### Mechanism 3
- Claim: Gradient-based optimization jointly updates network parameters and UTV penalties to balance denoising and signal preservation.
- Mechanism: The BP algorithm is extended to compute derivatives of the UTV term; parameters are updated to minimize MSE plus UTV regularization, allowing end-to-end training.
- Core assumption: Standard gradient descent with extended derivatives is sufficient for convergence in this hybrid loss space.

## Architecture Onboarding

- Component map: Input patches -> Encoder (conv + ReLU + pooling) -> Latent space -> Decoder (conv + ReLU + upsampling) -> Output patches -> UTV regularizer -> Loss function

- Critical path:
  1. Data preprocessing: Extract overlapping patches from flattened time slices
  2. Forward pass: Encoder → latent → decoder → reconstruction
  3. Loss computation: MSE between input and reconstruction + UTV penalty
  4. Backward pass: Standard BP + custom derivatives for UTV
  5. Parameter update: Adam optimizer with learning rate tuning
  6. Postprocessing: Reassemble patches into full image

- Design tradeoffs:
  - Larger λ₁/λ₂ → more aggressive footprint removal but risk signal distortion
  - Smaller λ₁/λ₂ → less footprint removal but better signal preservation
  - Patch size → larger patches capture more context but increase computation
  - Batch size → larger batches stabilize gradients but require more memory

- Failure signatures:
  - If footprint stripes remain visible in output, λ₁/λ₂ too small
  - If edges become blurry or signals attenuated, λ₁/λ₂ too large
  - If training loss plateaus early, learning rate too low or architecture too shallow
  - If loss diverges, gradients from UTV term dominate

- First 3 experiments:
  1. Verify patch extraction and reassembly pipeline works on synthetic data with known footprints
  2. Train FR-Net with λ₁=λ₂=0 to confirm autoencoder learns to reconstruct cleanly without UTV
  3. Add UTV regularization gradually and monitor SNR improvement on synthetic test set

## Limitations
- The effectiveness of UTV regularization depends on accurate parameterization (λ₁, λ₂), which was not thoroughly explored for sensitivity.
- The method's performance relies heavily on the directional consistency of footprint noise, which may not hold in all real-world scenarios.
- The evaluation focuses primarily on SNR for synthetic data and visual inspection for real data, lacking quantitative metrics for real-world performance.

## Confidence
- **High confidence**: The core mechanism of using UTV regularization to exploit directional characteristics of footprint noise is well-supported by the evidence and physically intuitive.
- **Medium confidence**: The unsupervised training approach via physical prior augmented autoencoder is plausible but lacks extensive ablation studies to confirm its necessity and superiority.
- **Low confidence**: The specific parameter choices (λ₁, λ₂) and their impact on the balance between footprint removal and signal preservation are not well-justified or explored.
