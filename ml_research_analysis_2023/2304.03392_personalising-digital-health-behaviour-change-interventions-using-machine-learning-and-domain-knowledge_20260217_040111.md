# Personalising Digital Health Behaviour Change Interventions using Machine Learning and Domain Knowledge

## Quick Facts
- arXiv ID: 2304.03392
- Source URL: https://arxiv.org/abs/2304.03392
- Reference count: 6
- Proposes a virtual coaching system using machine learning and domain knowledge to personalize digital health behavior change interventions

## Executive Summary
This paper introduces a virtual coaching system that personalizes digital health behavior change interventions (BCI) by combining machine learning with domain knowledge. The system addresses the challenge of predicting patient behavior by first modeling motivation, ability, and trigger (MAT) values as an intermediate representation, then using these to predict actual behavior. The approach leverages counterfactual explanations to identify specific intervention modifications that could increase patient adherence. Results demonstrate that this two-step approach outperforms direct behavior prediction, particularly when using counterfactual examples with feature control for BCI personalization.

## Method Summary
The proposed system employs a two-stage machine learning approach for personalizing digital health behavior change interventions. First, the system predicts motivation, ability, and trigger (MAT) values using a prediction model trained on simulated patient data with varying levels of intervention receptivity. Second, these MAT values are used to predict whether patients will perform the targeted behavior. The system incorporates Diverse Counterfactual Explanations (DiCE) to generate specific changes to BCI properties that would increase the likelihood of patient adherence. This approach addresses the challenge of directly predicting patient behavior by creating an intermediate representation that enables more effective learning of intervention personalization.

## Key Results
- Directly predicting patient behavior is challenging, necessitating an intermediate MAT representation
- The two-step approach (predicting MAT values first, then behavior) enables more effective intervention personalization
- Diverse Counterfactual Explanations (DiCE) method can generate specific changes to BCI properties to increase patient adherence likelihood

## Why This Works (Mechanism)
The system works by recognizing that behavior change depends on three fundamental components: motivation, ability, and trigger. By first predicting these MAT values, the model creates an interpretable intermediate representation that captures the psychological mechanisms underlying behavior change. This intermediate step allows the model to learn more effectively than attempting to predict behavior directly from raw features. The use of counterfactual explanations then enables the system to identify actionable modifications to intervention parameters that would shift a patient's MAT values in favorable directions, thereby increasing the probability of desired behavior.

## Foundational Learning

**MAT Framework** - Understanding motivation, ability, and trigger as fundamental components of behavior change. Why needed: Provides psychological foundation for intervention design. Quick check: Verify interventions target all three components.

**Counterfactual Explanations** - Method for generating actionable insights about what changes would lead to different outcomes. Why needed: Enables specific, interpretable recommendations for intervention modification. Quick check: Ensure generated counterfactuals are feasible and actionable.

**Feature Control in Counterfactuals** - Technique for ensuring generated counterfactuals remain within realistic bounds. Why needed: Prevents unrealistic recommendations that could undermine intervention effectiveness. Quick check: Validate counterfactuals against domain constraints.

## Architecture Onboarding

Component Map: Patient Data -> MAT Predictor -> Behavior Predictor -> DiCE Counterfactual Generator -> Intervention Recommendations

Critical Path: The core workflow flows from patient data through MAT prediction to behavior prediction, then to counterfactual generation for intervention personalization.

Design Tradeoffs: The two-step prediction approach trades computational complexity for improved prediction accuracy and interpretability, accepting the additional modeling overhead to gain more effective personalization.

Failure Signatures: Direct behavior prediction failures may manifest as poor generalization across patient populations; MAT-based failures may indicate insufficient feature representation of psychological constructs.
