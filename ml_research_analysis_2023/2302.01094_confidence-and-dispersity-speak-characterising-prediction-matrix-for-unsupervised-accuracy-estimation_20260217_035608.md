# Confidence and Dispersity Speak: Characterising Prediction Matrix for Unsupervised Accuracy Estimation

## Quick Facts
- arXiv ID: 2302.01094
- Source URL: https://arxiv.org/abs/2302.01094
- Authors: 
- Reference count: 19
- Primary result: Nuclear norm achieves R² up to 0.997 and Spearman's ρ up to 0.998 in unsupervised accuracy estimation across distribution shifts

## Executive Summary
This work addresses the challenge of estimating model accuracy without labeled data under distribution shifts. The authors propose using the nuclear norm of the prediction matrix as a metric that captures both prediction confidence and dispersity. By analyzing prediction matrices from various models across ImageNet, CIFAR-10, and CUB-200 datasets with synthetic and real-world distribution shifts, they demonstrate that nuclear norm correlates strongly with ground-truth accuracy, outperforming existing methods like ATC and DoC. The approach remains robust under moderate label imbalance but shows limitations under severe class imbalance.

## Method Summary
The method computes the nuclear norm of the prediction matrix (nt × k) generated by running a pre-trained model on unlabeled test data. This nuclear norm is normalized by its upper bound √(min(nt,k)·nt) to create a size-invariant metric. The normalized nuclear norm is then correlated with ground-truth accuracy across different distribution shifts. The approach is compared against existing unsupervised accuracy estimation methods including AC, ANE, ATC, and DoC using correlation metrics R² and Spearman's ρ.

## Key Results
- Nuclear norm achieves R² up to 0.997 and Spearman's ρ up to 0.998 in correlation with ground-truth accuracy
- Outperforms existing methods (ATC, DoC) across 3 datasets, 14 distribution shifts, and multiple model architectures
- Remains effective under moderate label imbalance but degrades with severe class imbalance
- Shows consistent performance across synthetic (ImageNet-C, CIFAR-10-C) and real-world distribution shifts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Nuclear norm captures both prediction confidence and dispersity in the prediction matrix, enabling accurate unsupervised accuracy estimation.
- Mechanism: Nuclear norm equals the sum of singular values of the prediction matrix. Larger values indicate both diverse class predictions (high dispersity) and confident predictions (high Frobenius norm, which is upper bounded by nuclear norm).
- Core assumption: The prediction matrix from a well-performing model has both high confidence scores and balanced class distribution.
- Evidence anchors:
  - [abstract] "we use the nuclear norm that has been shown to be effective in characterizing both properties"
  - [section] "Nuclear norm||P||∗ is defined as the sum of singular values of P... A larger nuclear norm implies more classes are predicted and involved, indicating higher prediction dispersity. In addition, the nuclear-norm||P||∗ is an upperbound of the Frobenius-norm that||P||F reflects prediction confidence"
  - [corpus] Weak - corpus papers discuss nuclear norm in different contexts (blind deconvolution, LLM evaluation) but don't directly address this specific dual characterization mechanism
- Break condition: If prediction dispersity and confidence are uncorrelated with accuracy, or if the relationship between nuclear norm and these properties breaks down under specific distribution shifts.

### Mechanism 2
- Claim: Prediction dispersity (class balance in predictions) strongly correlates with model accuracy under distribution shift.
- Mechanism: When a model performs well on out-of-distribution data, its predictions are both confident and spread across classes. Poor performance leads to degenerate predictions concentrated on few classes, reducing dispersity.
- Core assumption: Distribution shift causes target features to cluster in ways that, when predicted, show clear correlation between dispersity and accuracy.
- Evidence anchors:
  - [abstract] "Our key insight is that a well-performing model should give predictions with high confidence and high dispersity"
  - [section] "we report our empirical observation in Fig. 1... prediction dispersity exhibits a very strong correlation (Spearman's rank correlationρ> 0.950) with classifier performance"
  - [corpus] Weak - corpus doesn't directly address dispersity-accuracy correlation mechanism
- Break condition: If label shift (class imbalance) is severe, dispersity becomes less informative since balanced predictions may not be expected.

### Mechanism 3
- Claim: Normalizing nuclear norm by its upper bound makes it robust to test set size variations.
- Mechanism: Since nuclear norm scales with matrix dimensions, dividing by √(min(nt,k)·nt) creates a size-invariant metric that maintains correlation with accuracy regardless of how many samples are in the test set.
- Core assumption: The upper bound relationship holds across different test set sizes and the normalized metric preserves the confidence-dispersity relationship.
- Evidence anchors:
  - [section] "Since test sets can contain any number of data points, we normalize the nuclear norm of prediction matrix by its upper bound derived from matrix size and obtain ˆ||P||∗ =||P||∗/√(min(nt,k)·nt)"
  - [section] "scaled nuclear norm is well correlated with accuracy with different dataset sizes" (Figure 6)
  - [corpus] Missing - corpus doesn't discuss normalization for size invariance
- Break condition: If the upper bound relationship becomes invalid for extreme matrix dimensions or if normalization disrupts the correlation structure.

## Architecture Onboarding

- Component map: Pre-trained model + unlabeled test dataset -> Prediction matrix generator -> Nuclear norm calculator -> Correlation engine -> Validation module
- Critical path:
  1. Generate predictions on unlabeled test set
  2. Form prediction matrix P (nt × k)
  3. Compute nuclear norm ||P||*
  4. Normalize: ||P||*/√(min(nt,k)·nt)
  5. Correlate normalized value with accuracy
- Design tradeoffs:
  - Using nuclear norm vs. simpler metrics (average confidence, entropy): Nuclear norm captures both confidence and dispersity but is computationally heavier
  - Normalization method: The chosen normalization makes it size-invariant but assumes uniform class distribution
  - Single model vs. ensemble: This method works with single models, unlike some comparison methods requiring multiple models
- Failure signatures:
  - Severe class imbalance: Nuclear norm loses effectiveness as it assumes uniform class distribution
  - Random predictions: Nuclear norm may still give moderate values even for random predictions
  - Very small test sets: Normalization may become unstable with few samples
- First 3 experiments:
  1. Implement nuclear norm calculation on a simple synthetic prediction matrix with known dispersity and confidence
  2. Compare nuclear norm correlation with accuracy against average confidence on ImageNet-C with a single model
  3. Test size invariance by running on subsets of the same test set and verifying consistent normalized values

## Limitations
- Performance degrades significantly under severe label shift (class imbalance)
- Assumes prediction matrix has meaningful structure - may fail for truly random predictions
- Computational cost of nuclear norm calculation (SVD) may be prohibitive for very large test sets

## Confidence
- Nuclear norm correlation claims: **High** - extensive experiments across 3 datasets, 14 shifts, and multiple models show consistent R² > 0.8, with peak performance at R² = 0.997
- Dispersity-confidence relationship: **Medium** - strong empirical correlation observed but theoretical justification for why this relationship holds under all distribution shifts is limited
- Size invariance through normalization: **Medium** - demonstrated empirically but the upper bound assumption needs further theoretical validation
