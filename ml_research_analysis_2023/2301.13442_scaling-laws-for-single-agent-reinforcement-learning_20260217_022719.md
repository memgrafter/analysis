# Scaling laws for single-agent reinforcement learning
## Quick Facts
- arXiv ID: 2301.13442
- Source URL: https://arxiv.org/abs/2301.13442
- Reference count: 40
- This paper introduces "intrinsic performance" to study scaling laws in RL, finding power-law relationships between compute, model size, and task performance.

## Executive Summary
This paper introduces a new metric called "intrinsic performance" to study scaling laws in single-agent reinforcement learning. Intrinsic performance measures the minimum compute required to train any model size to achieve a given return, providing a compute-optimal perspective on RL performance. The authors empirically demonstrate that both intrinsic performance and optimal model size scale as power laws with respect to model parameters and environment interactions across a range of synthetic environments. These findings validate and refine previous work on sample efficiency while providing concrete implications for forecasting computational requirements in AI development.

## Method Summary
The authors conduct a systematic empirical study across multiple synthetic RL environments with varying horizon lengths. They train models of different sizes on each environment while tracking both the return achieved and the compute budget used. By analyzing the relationship between model size, compute budget, and performance, they identify power-law scaling relationships. The study employs standard RL algorithms and evaluates performance using the introduced intrinsic performance metric, which captures the compute-optimal trade-off between model size and training data.

## Key Results
- Intrinsic performance (minimum compute to achieve target return) scales as a power law in both model size and environment interactions
- The optimal model size for a given compute budget also follows a power law relationship
- Increasing horizon length primarily affects the scaling coefficient rather than the power-law exponent

## Why This Works (Mechanism)
The paper's findings emerge from the fundamental trade-offs in RL between model capacity and data efficiency. As model size increases, it can better represent the value function or policy, reducing the number of environment interactions needed to achieve a target performance. Conversely, for a fixed compute budget, there exists an optimal model size that balances these factors. The power-law relationships arise from the smooth, continuous nature of this trade-off across many orders of magnitude in scale, suggesting that RL systems exhibit predictable behavior even as they grow substantially in size.

## Limitations
- Results are primarily validated on synthetic environments, which may not generalize to complex real-world tasks
- The intrinsic performance metric, while theoretically motivated, requires broader empirical validation
- Analysis focuses on compute-optimal model sizes without extensively exploring other resource constraints like memory or wall-clock time

## Confidence
- Claims about power-law scaling of intrinsic performance with model size and compute: High
- Claims about how scaling exponents vary with horizon length: Medium
- Claims about implications for AI development forecasting: Low
