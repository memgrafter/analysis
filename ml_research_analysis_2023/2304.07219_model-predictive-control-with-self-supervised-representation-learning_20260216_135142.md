# Model Predictive Control with Self-supervised Representation Learning

## Quick Facts
- arXiv ID: 2304.07219
- Source URL: https://arxiv.org/abs/2304.07219
- Reference count: 21
- Adds reconstruction function to TOLD model for self-supervised learning

## Executive Summary
This paper proposes an enhanced TD-MPC framework that adds a reconstruction function to the TOLD model, enabling self-supervised learning from latent state representations. The reconstruction loss complements the existing consistency loss, providing a more stable learning signal and improved sample efficiency. Experiments on DeepMind Control Suite tasks show that the modified agent achieves better or comparable performance to the original TD-MPC, with particular improvements in state-based environments and increased stability in image-based tasks.

## Method Summary
The paper enhances the TD-MPC framework by adding a reconstruction function to the TOLD model. This reconstruction function learns to map latent states back to the original observation space, creating a self-supervised learning signal. The modified agent is trained using a combined loss that includes reward, value, consistency, and reconstruction terms. The approach is tested on both state-based and image-based tasks from the DeepMind Control Suite, with evaluation after every 20k environment steps.

## Key Results
- Improved sample efficiency and stability in state-based environments
- Enhanced stability in image-based tasks, particularly for Finger Turn Hard
- Reconstruction loss provides more stable learning signal than consistency loss alone
- Performance comparable or better than baseline TD-MPC across most tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The reconstruction loss stabilizes training by providing a dense self-supervised learning signal that is not dependent on reward sparsity.
- Mechanism: By reconstructing the original observation from the latent state, the agent learns features that preserve important information for reconstruction, indirectly improving the dynamics and representation functions. This creates a more stable learning signal beyond sparse rewards.
- Core assumption: Task-relevant features that help reconstruct observations are also useful for the control task.
- Evidence anchors:
  - [abstract] "This allows our agent to have a more stable learning signal during training and also improves sample efficiency."
  - [section] "By including the term lh−1 in the single-step loss, we aim to further enhance the learning signal and thereby improving the robustness of the learning process, especially in sparse and noisy environments."
  - [corpus] Weak corpus support for reconstruction in TD-MPC specifically; related papers focus on other domains.
- Break condition: If the reconstruction task forces the latent space to encode irrelevant details, harming the abstraction quality and control performance.

### Mechanism 2
- Claim: Joint training of reconstruction with dynamics and representation functions forces these components to retain task-relevant information needed for both reconstruction and control.
- Mechanism: Error gradients from the reconstruction loss flow through the dynamics and representation functions, making them preserve features necessary for reconstructing the observation, which are also likely relevant for the control task.
- Core assumption: Features useful for reconstructing observations overlap substantially with those useful for control.
- Evidence anchors:
  - [section] "Since the reconstruction function is also jointly trained with the other components, error gradients are propagated through the other functions, resulting in shared behaviours and features."
  - [section] "Thus, both the representation and dynamics functions will be forced to retain information essential to reconstruct the original observation."
  - [corpus] No direct corpus support for this specific mechanism in TD-MPC; weak relevance from other self-supervised papers.
- Break condition: If reconstruction introduces noise or forces encoding of non-task-relevant details, it could degrade the quality of the latent representation for control.

### Mechanism 3
- Claim: Pre-training the world model using reconstruction loss enables faster initial learning by providing better initial estimates.
- Mechanism: The agent can explore the environment without rewards, learning a world model through reconstruction, then use this pre-trained model for faster adaptation during reward-based training.
- Core assumption: A pre-trained world model that accurately reconstructs observations also provides good predictions for control-relevant dynamics.
- Evidence anchors:
  - [section] "Another possible advantage of our proposed change to the TD-MPC framework is the ability to pre-train the world model in a self-supervised manner."
  - [abstract] "This allows our agent to have a more stable learning signal during training and also improves sample efficiency."
  - [corpus] No corpus evidence of pre-training in TD-MPC; this is an untested suggestion.
- Break condition: If the reconstruction-based pre-training doesn't generalize to the actual control task, it may not improve performance.

## Foundational Learning

- Concept: Temporal Difference (TD) Learning
  - Why needed here: The TOLD model uses TD learning to jointly train representation, dynamics, reward, value, and policy functions using bootstrapped targets.
  - Quick check question: How does TD learning differ from supervised learning in the context of the TOLD model's value function updates?

- Concept: Latent State Representation
  - Why needed here: The agent encodes observations into latent states to reduce complexity and focus on task-relevant information, essential for efficient planning and learning.
  - Quick check question: What is the purpose of using latent states instead of raw observations in model-based RL algorithms like TD-MPC?

- Concept: Model Predictive Control (MPC)
  - Why needed here: MPC plans short-horizon trajectories by simulating actions through the learned dynamics model, using the value function for long-term return estimates.
  - Quick check question: How does the planning horizon in MPC affect the trade-off between computational cost and planning accuracy?

## Architecture Onboarding

- Component map:
  - TOLD model with 6 components: representation (hθ), dynamics (dθ), reward (Rθ), value (Qθ), policy (πθ), and reconstruction (h⁻¹θ)
  - Target network (θ⁻) for stable Q-learning updates
  - Replay buffer for experience storage
  - MPPI-based planner for action selection

- Critical path:
  1. Encode observation → latent state (hθ)
  2. Plan actions using dynamics and value functions
  3. Execute action, store transition
  4. Sample batch, compute losses (including reconstruction)
  5. Update all model components jointly

- Design tradeoffs:
  - Reconstruction loss coefficient: Too high may force encoding irrelevant details; too low may not provide sufficient stabilization
  - Latent space dimensionality: Higher capacity improves reconstruction but increases complexity
  - Planning horizon H: Longer horizons improve foresight but reduce dynamics model accuracy

- Failure signatures:
  - Reconstruction loss dominates other losses → poor control performance
  - Latent states don't reconstruct well but control is good → possibly over-regularized
  - Training instability or collapse → learning rate or loss coefficients may need adjustment

- First 3 experiments:
  1. Run TD-MPC with reconstruction on Finger Turn Hard state-based task; compare learning curves and final performance to baseline
  2. Test different reconstruction loss coefficients (e.g., 0.1, 1.0, 2.0) on Cheetah Run to find optimal balance
  3. Evaluate sample efficiency by measuring performance after 100k vs 500k steps on image-based tasks

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the reconstruction loss coefficient affect performance across different environments and task complexities?
- Basis in paper: [explicit] The paper states that reconstruction coefficients were empirically chosen for different environments (2.0, 0.25, 0.275 for state-based tasks and 0.15, 0.275, 0.15 for image-based tasks) but does not systematically explore the sensitivity of performance to these values.
- Why unresolved: The paper does not provide a sensitivity analysis of the reconstruction coefficient across different environments or task complexities.
- What evidence would resolve it: A systematic study varying the reconstruction loss coefficient across multiple orders of magnitude for different environment types would show how sensitive the performance is to this hyperparameter.

### Open Question 2
- Question: Does pre-training the TOLD model using self-supervised reconstruction learning improve sample efficiency and final performance compared to random initialization?
- Basis in paper: [explicit] The paper mentions that pre-training with self-supervised reconstruction could provide better initial estimates and reduce training time, but states "We leave this open for future work."
- Why unresolved: The paper does not actually implement or test the pre-training approach, only suggests it as a future direction.
- What evidence would resolve it: Direct comparison of TD-MPC-SRL with and without pre-training on the same tasks would demonstrate whether pre-training provides measurable benefits in sample efficiency and final performance.

### Open Question 3
- Question: How does the proposed method scale to more complex environments like Humanoid or Dog tasks from DMControl?
- Basis in paper: [inferred] The paper notes that the modified agent struggles with high-dimensional environments and suggests that "a more diverse comparison of performance would include a variety of other complex environments."
- Why unresolved: The paper only tests on relatively simpler tasks (Finger Turn Hard, Cheetah Run, Acrobot Swingup, Reacher Easy) and does not evaluate performance on more complex, high-dimensional control tasks.
- What evidence would resolve it: Testing TD-MPC-SRL on complex environments like Humanoid-stand or Dog tasks would reveal whether the benefits of reconstruction loss generalize to more challenging scenarios.

## Limitations

- Reconstruction loss coefficient optimization was not thoroughly explored across tasks
- Image-based task results show stability improvements but not consistently superior final performance
- Pre-training hypothesis remains untested despite being identified as promising direction
- Exact architectural details for reconstruction function in image-based tasks are not fully specified

## Confidence

- High confidence in the mechanism by which reconstruction loss provides a more stable learning signal through dense self-supervised training
- Medium confidence in the claim that joint training forces retention of task-relevant information
- Medium confidence in the overall performance improvements, given mixed results between state-based and image-based tasks
- Low confidence in the untested pre-training hypothesis

## Next Checks

1. Conduct an ablation study varying the reconstruction loss coefficient (e.g., 0.1, 0.5, 1.0, 2.0) across all tasks to determine optimal values and test the sensitivity of performance to this hyperparameter.

2. Perform a pre-training experiment where the world model is first trained on reconstruction loss for a fixed number of steps without rewards, then fine-tuned with the full TD-MPC objective, measuring the impact on sample efficiency and final performance.

3. Test the algorithm on a broader set of DeepMind Control Suite tasks, particularly those with more complex dynamics or sparse rewards, to better understand the generalization capabilities and limitations of the approach.
