# AC2C: Adaptively Controlled Two-Hop Communication for Multi-Agent Reinforcement Learning

## Quick Facts
- arXiv ID: 2302.12515
- Source URL: https://arxiv.org/abs/2302.12515
- Reference count: 38
- AC2C achieves 95.33% success rate with 2.972 × 10^5 bits communication overhead in traffic junction task

## Executive Summary
This paper introduces AC2C (Adaptively Controlled Two-Hop Communication), a novel protocol for multi-agent reinforcement learning that enables effective long-range communication among agents with limited communication ranges. The method combines an attention-based communication module with a gating mechanism to selectively control two-hop communication frequency, reducing overhead while maintaining performance. Experiments demonstrate AC2C outperforms baseline methods across three cooperative multi-agent tasks, achieving higher success rates with lower communication costs.

## Method Summary
AC2C implements a two-hop communication protocol where agents exchange information with both immediate neighbors and selectively with two-hop neighbors based on a gating mechanism. The attention-based communication module learns to weigh the importance of messages from different neighbors, while the gating mechanism determines when two-hop communication is necessary. This adaptive approach reduces unnecessary communication while preserving critical information flow. The protocol is evaluated on traffic junction, cooperative navigation, and predator-prey tasks, demonstrating superior performance compared to relevant baselines.

## Key Results
- AC2C achieves 95.33% success rate in traffic junction task versus 93.81% for best baseline
- Communication overhead reduced to 2.972 × 10^5 bits versus 3.790 × 10^5 bits for baseline
- Consistent performance improvements across all three tested cooperative multi-agent environments

## Why This Works (Mechanism)
The gating mechanism in AC2C learns to identify when two-hop communication is essential for task success, preventing unnecessary information exchange while maintaining critical long-range coordination. The attention-based communication module effectively weights incoming messages from different neighbors, allowing agents to focus on the most relevant information. By combining these mechanisms, AC2C reduces communication overhead while preserving the information flow necessary for successful coordination in sparse communication environments.

## Architecture Onboarding

**Component Map:** Environment -> Agent(s) -> Communication Module -> Gating Mechanism -> Action Selection

**Critical Path:** State observation → Attention-weighted neighbor messages → Gating decision → Two-hop message transmission (when approved) → Action computation

**Design Tradeoffs:** Reduced communication frequency versus information completeness; Computational overhead of attention mechanism versus communication savings; Implementation complexity of adaptive gating versus static communication protocols

**Failure Signatures:** Communication bottlenecks in densely connected scenarios; Missed coordination opportunities when gating is too restrictive; Attention mechanism failure to identify relevant neighbors

**First Experiments:** 1) Isolate gating mechanism contribution through ablation testing; 2) Test attention module sensitivity to neighbor count variations; 3) Evaluate communication overhead under different network densities

## Limitations
- Evaluation relies on synthetic benchmark environments with specific communication constraints
- No ablation studies isolating gating mechanism versus attention module contributions
- Assumes reliable communication channels without modeling packet loss or latency
- Attention mechanism computational overhead during inference not analyzed
- Evaluation limited to cooperative tasks, limiting generalizability to mixed-motive scenarios
