# Augmenting Zero-Shot Detection Training with Image Labels

## Quick Facts
- arXiv ID: 2306.06899
- Source URL: https://arxiv.org/abs/2306.06899
- Authors: 
- Reference count: 40
- This work improves zero-shot object detection by adding ImageNet classification labels, increasing mAP on unseen classes from 14.7 to 18.0 (+3.3) on the 65/15 COCO split.

## Executive Summary
This paper addresses zero-shot object detection (ZSD) by augmenting training with image classification labels from ImageNet alongside object detection data from COCO. The authors modify YOLOX to output CLIP embeddings instead of class probabilities, aligning these to CLIP text embeddings. Their approach achieves a significant improvement in mAP on unseen classes (14.7 → 18.0, +3.3) by leveraging ImageNet data, more than doubling the gain of related work. The method shows particular effectiveness for medium and large objects, though struggles with small objects and visually similar classes.

## Method Summary
The method modifies YOLOX to output 512-dimensional CLIP embeddings instead of class probabilities. During training, it jointly optimizes on COCO detection data and filtered ImageNet classification data, using only classification loss on ImageNet images. The model aligns predicted embeddings to precomputed CLIP text embeddings using cosine similarity and cross-entropy loss. ImageNet classes are filtered to exclude those semantically related to unseen COCO classes, preserving zero-shot integrity while providing useful supervision. The approach uses text prompts to generate target embeddings and trains with a 4:1 ratio of COCO to ImageNet data.

## Key Results
- mAP on unseen classes improves from 14.7 to 18.0 (+3.3) when adding ImageNet classification data
- The ImageNet benefit is not due to longer training, as additional COCO-only training does not improve ZSD performance
- Qualitative results show the model can detect varying sizes of unseen objects, but struggles with objects visually similar to seen classes

## Why This Works (Mechanism)

### Mechanism 1
Adding ImageNet classification data improves zero-shot detection performance by increasing the diversity and coverage of the CLIP embedding space. The detector learns to output embeddings that are better aligned to CLIP text embeddings by seeing more diverse object categories during training, even without bounding box supervision. The core assumption is that the CLIP embedding space is structured such that embeddings for visually similar objects are close together, so learning more categories implicitly improves alignment for unseen classes.

### Mechanism 2
The joint training strategy with filtered ImageNet data preserves the zero-shot detection setup while providing useful supervision. By filtering out ImageNet classes that are semantically related to unseen COCO classes, the model can learn from ImageNet without "cheating" on the unseen classes, and the classification loss on ImageNet images still improves embedding alignment. The core assumption is that the semantic overlap between ImageNet and COCO classes is limited enough that filtering preserves most of ImageNet's diversity benefit.

### Mechanism 3
Using only text embeddings (not image embeddings) from CLIP is sufficient and simpler for zero-shot detection alignment. The model learns to output embeddings that are close to CLIP text embeddings for the seen classes, and this alignment transfers to unseen classes because the text embeddings for unseen classes are also in the same space. The core assumption is that CLIP text embeddings are sufficiently discriminative and generalizable across the object taxonomy to enable zero-shot detection.

## Foundational Learning

- Concept: Contrastive learning and embedding spaces (CLIP)
  - Why needed here: The core idea is to map images and text into a shared embedding space where similarity indicates semantic relatedness. Understanding how CLIP was trained and how its embeddings behave is crucial to grasping why adding more text supervision helps.
  - Quick check question: Why does maximizing cosine similarity between matched image-text pairs and minimizing it for mismatched pairs lead to semantically meaningful embeddings?

- Concept: Zero-shot learning and detection
  - Why needed here: ZSD requires the model to generalize to classes not seen during training. Understanding the difference between traditional detection and ZSD, and why direct classification is insufficient, is key.
  - Quick check question: What is the main challenge in evaluating zero-shot detection performance, and how does the 65/15 split address it?

- Concept: Multi-task learning and data augmentation
  - Why needed here: The method jointly trains on detection and classification data. Understanding how to balance losses, handle missing labels (e.g., no bounding boxes for ImageNet), and why data augmentation helps is important for implementation and debugging.
  - Quick check question: How does the model decide which bounding box to use for backpropagation when training on ImageNet images without ground truth boxes?

## Architecture Onboarding

- Component map:
  Backbone (YOLOX) -> Classification head (512-dim CLIP embeddings) -> Cosine similarity with CLIP text encoder -> Softmax with temperature -> Cross-entropy loss

- Critical path:
  1. Load and preprocess COCO and ImageNet images
  2. Forward pass through YOLOX to get bounding boxes, objectness, and classification embeddings
  3. Compute cosine similarities between predicted embeddings and precomputed CLIP text embeddings
  4. Apply softmax with temperature scaling to get class probabilities
  5. Compute cross-entropy loss against ground truth labels
  6. Backpropagate only on classification loss for ImageNet, all losses for COCO
  7. Update model weights

- Design tradeoffs:
  Using only text embeddings simplifies training but may miss fine-grained visual distinctions captured by image embeddings; filtering ImageNet classes preserves zero-shot integrity but reduces data diversity; decoupling classification from objectness/bounding box learning allows ImageNet augmentation but requires careful loss balancing.

- Failure signatures:
  mAP on unseen classes does not improve despite ImageNet addition: likely due to poor filtering or misalignment in embedding space; mAP on seen classes drops significantly: likely due to changes in classification head or missing data augmentation; training instability or slow convergence: likely due to improper loss scaling or temperature parameter issues.

- First 3 experiments:
  1. Train the modified YOLOX (with embedding head) on COCO only and verify mAP on unseen classes matches or exceeds baseline.
  2. Add ImageNet data with filtering and check if mAP on unseen classes improves; if not, inspect filtering logic and embedding alignment.
  3. Compare training with and without ImageNet to confirm the gain is not due to longer training or other confounding factors.

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of the proposed method scale with increasing amounts of image classification data (e.g., ImageNet)? The authors mention that the benefit of adding ImageNet data is due to both the increased quantity and quality of training data, but do not explore the effect of varying amounts of ImageNet data.

### Open Question 2
How does the proposed method perform when using different embedding spaces, such as ALIGN or DeViSE, instead of CLIP? The authors use CLIP as the embedding space but mention that other embedding spaces exist and could potentially be used.

### Open Question 3
How does the proposed method handle the case of visually similar objects from different classes, such as a hot dog and a dog? The authors mention that visually similar objects can be confused by the detector, but do not explore potential solutions to this issue.

## Limitations

- The method shows significant performance gap between seen and unseen classes, with poor detection of small unseen objects
- The approach requires careful filtering of ImageNet classes to preserve zero-shot integrity, which may reduce data diversity
- The paper doesn't provide head-to-head comparisons with alternative ZSD approaches using image embeddings under identical conditions

## Confidence

- **High Confidence**: The experimental results showing mAP improvement from 14.7 to 18.0 on unseen classes with ImageNet addition are well-documented and reproducible.
- **Medium Confidence**: The mechanism explaining why ImageNet helps (increased diversity and coverage of the embedding space) is plausible but not directly proven.
- **Low Confidence**: The claim that using only text embeddings (not image embeddings) is sufficient and simpler lacks direct comparative evidence.

## Next Checks

1. Conduct a systematic analysis of the CLIP embedding space to verify that ImageNet classes truly provide complementary coverage to COCO classes, and that the filtering strategy preserves meaningful diversity while preventing information leakage.

2. Test whether the ImageNet benefit scales with the number of ImageNet classes added (e.g., try adding only 100, 500, or 800 filtered classes) to determine if there's a saturation point or optimal amount of additional data.

3. Implement a head-to-head comparison with ZSD-YOLO using image embeddings under identical training conditions, hyperparameters, and evaluation protocols to definitively assess whether text-only embeddings are indeed sufficient for the claimed performance gains.
