# Face: Fast, Accurate and Context-Aware Audio Annotation and Classification

## Quick Facts
- arXiv ID: 2303.03666
- Source URL: https://arxiv.org/abs/2303.03666
- Reference count: 33
- One-line primary result: Achieves 90% annotation accuracy with only 15% initial labeling budget and 98.05% classification accuracy on UrbanSound8K dataset

## Executive Summary
This paper presents FACE, a context-aware framework for audio event annotation and classification that achieves high accuracy with minimal computational effort. The method combines sophisticated feature extraction (Tempogram, Chromagram, Mel-scaled Spectrogram, MFCCs, Spectral Contrast, Spectral flatness, Spectral bandwidth, Spectral centroid, Roll-off frequency, RMS value, Tonnetz, and zero-crossing rate) with context-aware active learning for annotation. The framework achieves an average accuracy of 90% when only 15% of data have initial annotation, while the classification algorithm reaches 98.05% accuracy on the UrbanSound8K dataset. All source codes and implementation results are publicly available.

## Method Summary
The FACE framework operates through three main stages: feature extraction, context-aware active learning for annotation, and neural network classification. Audio features are extracted using Librosa, including time-domain features (Tempogram), frequency-domain features (Chromagram, MFCCs), and harmonic features (Tonnetz). The annotation process employs active learning with outlier detection using Local Outlier Factor (LOF) and hard-to-predict sample selection to minimize labeling effort while maximizing accuracy. For classification, a CNN with locally connected convolutional blocks is trained on the annotated dataset. The method is validated on the UrbanSound8K dataset containing 8,732 audio samples across 10 urban sound classes.

## Key Results
- Achieves 90% annotation accuracy with only 15% of data initially labeled
- Classification accuracy of 98.05% on UrbanSound8K dataset
- Context-aware active learning reduces annotation effort by 85% while maintaining high accuracy

## Why This Works (Mechanism)
The FACE framework succeeds by combining multiple complementary audio features that capture different aspects of sound: temporal patterns (Tempogram), harmonic content (Tonnetz), spectral characteristics (MFCCs, Chromagram), and statistical measures (Spectral Contrast, Spectral Centroid). The context-aware active learning strategy intelligently selects which samples to annotate by identifying outliers and hard-to-predict instances, maximizing information gain per annotation effort. The CNN classifier with locally connected convolutional blocks can effectively learn spatial hierarchies in the feature space, enabling high classification accuracy even with limited training data.

## Foundational Learning

1. **Active Learning**: A semi-supervised learning approach that strategically selects which data samples to label to maximize model performance with minimal labeling effort. Needed because manual annotation is expensive and time-consuming in audio classification tasks. Quick check: Verify the active learning loop correctly identifies hard-to-predict samples and outlier samples for annotation priority.

2. **Local Outlier Factor (LOF)**: An unsupervised anomaly detection algorithm that identifies outliers based on local density deviation. Used to detect audio samples that differ significantly from others, making them high-value annotation targets. Quick check: Confirm LOF is configured with neighbors=1 and correctly identifies samples with density scores below the threshold.

3. **Mel-scaled Spectrogram**: A time-frequency representation that approximates human auditory perception by applying a Mel filterbank to the power spectrum. Provides a more perceptually relevant feature representation than linear frequency spectrograms. Quick check: Verify the Mel filterbank is correctly configured with 128 bands and the spectrogram is computed with appropriate hop length and window size.

4. **Tonnetz**: A feature representation that captures harmonic and tonal content by computing the tonal centroid features from the chromagram. Useful for distinguishing between different musical and harmonic sounds. Quick check: Ensure Tonnetz is computed correctly using the 12-bin chromagram with appropriate normalization.

## Architecture Onboarding

Component Map: Audio Files -> Feature Extraction -> Context-Aware Active Learning -> Annotation -> CNN Classifier -> Classification Results

Critical Path: The annotation pipeline is the critical path as it enables the supervised learning phase. Without accurate annotation, the classification accuracy cannot be achieved regardless of classifier sophistication.

Design Tradeoffs: The framework trades computational complexity during feature extraction for reduced annotation effort. While extracting multiple sophisticated features (Tempogram, Chromagram, MFCCs, Tonnetz) requires significant preprocessing, this investment pays off by enabling accurate active learning with minimal labeled data.

Failure Signatures: Low classification accuracy despite high annotation accuracy suggests issues with feature quality or classifier architecture. Poor annotation accuracy indicates problems with the active learning strategy or outlier detection parameters.
