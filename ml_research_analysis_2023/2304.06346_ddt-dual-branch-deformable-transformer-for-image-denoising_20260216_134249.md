# DDT: Dual-branch Deformable Transformer for Image Denoising

## Quick Facts
- **arXiv ID**: 2304.06346
- **Source URL**: https://arxiv.org/abs/2304.06346
- **Reference count**: 40
- **Key outcome**: DDT achieves state-of-the-art performance on real-world and synthetic denoising with 86 GFLOPs and 18.4M parameters, outperforming methods like SwinIR and SADNet on efficiency metrics.

## Executive Summary
This paper addresses the challenge of efficient image denoising using transformers, which are known for their ability to model long-range dependencies but suffer from quadratic computational complexity with spatial resolution. The authors propose a Dual-branch Deformable Transformer (DDT) that processes local and global interactions in parallel, using deformable attention to focus on important regions and reduce redundant calculations. The DDT achieves state-of-the-art performance on both real-world and synthetic denoising tasks with significantly fewer computational costs. Specifically, on the SIDD dataset, the DDT achieves a PSNR of 39.83 dB and SSIM of 0.960 with only 86 GFLOPs and 18.4M parameters, outperforming other methods in terms of efficiency.

## Method Summary
The DDT architecture consists of a 4-stage Unet-like encoder-decoder structure with Dual-branch Deformable Transformer Blocks (DDTBs). The model uses deformable attention to sample features adaptively, reducing computational complexity from quadratic to linear. Local and global branches process features in parallel with different patch division strategies - fixed patch size for local branch and fixed number of patches for global branch. The model is trained with L1 loss using AdamW optimizer with progressive learning from 128×128 to 256×256 resolution, and includes data augmentation techniques.

## Key Results
- Achieves 39.83 dB PSNR and 0.960 SSIM on SIDD dataset with only 86 GFLOPs and 18.4M parameters
- Outperforms SwinIR and SADNet on efficiency metrics while maintaining competitive denoising performance
- Demonstrates superior performance on synthetic Gaussian noise denoising tasks with lower computational costs than state-of-the-art methods

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Dual-branch structure enables simultaneous modeling of local and global image features with linear computational complexity.
- **Mechanism**: The DDT splits input features into local and global branches, processing them in parallel. Local branch divides features into fixed-size patches for intra-patch attention, while global branch divides into a fixed number of patches for inter-patch attention. This parallel processing reduces redundant calculations compared to sequential global-then-local approaches.
- **Core assumption**: Local and global information are equally useful for image denoising, and processing them in parallel is more efficient than sequential processing.
- **Evidence anchors**:
  - [abstract] "We propose an efficient Dual-branch Deformable Transformer (DDT) denoising network which captures both local and global interactions in parallel."
  - [section III-B] "With the dual-branch structure, we can process inputs with linear complexity, making it possible to process high-resolution images using Transformer architecture, preserving global receptive fields while capturing locality."
  - [corpus] Weak evidence - no direct corpus support for dual-branch efficiency in image denoising.
- **Break condition**: If either local or global information proves significantly more important for denoising, the parallel structure becomes suboptimal compared to a single specialized branch.

### Mechanism 2
- **Claim**: Deformable attention reduces computational cost by focusing on informative regions rather than processing all spatial locations.
- **Mechanism**: Deformable attention uses a Position Sub-network to generate offsets (∆p) and modulation scalars (∆m) that adaptively sample feature values. Instead of computing attention for all pixels, it samples features at deformable points, reducing the number of key-value pairs from H×W to H/γ × W/γ.
- **Core assumption**: Image regions contain redundant information, and most informative content is concentrated in specific areas rather than uniformly distributed.
- **Evidence anchors**:
  - [abstract] "we apply deformable attention operation in both branches, which helps the network focus on more important regions and further reduces computational complexity."
  - [section III-C] "We consider that the sampled feature x′ preserves most of the important information of x, reducing redundant contents compared with the origin feature x."
  - [appendix] Detailed derivation shows computational cost reduction from quadratic to linear complexity.
- **Break condition**: If noise patterns are uniformly distributed across the entire image or if informative regions cannot be predicted by the Position Sub-network, deformable attention may miss critical information.

### Mechanism 3
- **Claim**: Patch-based division with different rules for local and global branches optimizes the trade-off between computational efficiency and feature representation.
- **Mechanism**: Local branch uses fixed patch size (p×p) for intra-patch attention, capturing fine-grained local details. Global branch uses fixed number of patches for inter-patch attention, capturing long-range dependencies. This dual-patch strategy balances resolution and coverage.
- **Core assumption**: Fixed patch size in local branch and fixed patch count in global branch provide optimal coverage for their respective tasks.
- **Evidence anchors**:
  - [section III-B] "We divide features with a fixed patch size and a fixed number of patches in local and global branches, respectively."
  - [section IV-D] Table III shows ablation results comparing single-branch vs dual-branch performance.
  - [corpus] No direct corpus evidence for this specific patch division strategy.
- **Break condition**: If optimal patch size or count varies significantly across different image types or noise levels, the fixed parameters may become suboptimal.

## Architecture Onboarding

- **Component map**: Input → 3×3 conv → F0 → DDTB(1) → downsample → DDTB(2) → downsample → DDTB(3) → downsample → DDTB(4) → Bottleneck → Decoder DDTBs → Refinement DDTBs → 3×3 conv → residual → output

- **Critical path**: 
  1. Input → 3×3 conv → F0
  2. DDTB(1) → downsample → DDTB(2) → downsample → DDTB(3) → downsample → DDTB(4) → Bottleneck
  3. Bottleneck → Decoder DDTBs → Refinement DDTBs
  4. Refinement → 3×3 conv → residual → output

- **Design tradeoffs**:
  - Patch size p vs. local detail: Smaller patches capture more local detail but increase computational cost
  - γ (deformable attention stride) vs. global context: Larger γ captures more global context but may miss fine details
  - Channel expansion in DDA vs. parameter efficiency: More channels improve representation but increase parameters

- **Failure signatures**:
  - High PSNR but poor visual quality: May indicate over-smoothing from excessive denoising
  - Low PSNR with high computational cost: Could indicate inefficient deformable attention parameters or patch division
  - Mode collapse in training: May result from insufficient diversity in training data or overly aggressive regularization

- **First 3 experiments**:
  1. **Single-branch baseline**: Implement DDT with only local branch (double channels to match parameter count) and compare PSNR/SSIM to dual-branch version
  2. **Deformable vs. standard attention**: Replace deformable attention with standard multi-head self-attention (adjusting channels to maintain similar parameters) and measure computational cost and performance impact
  3. **Patch size ablation**: Test different patch sizes p (e.g., 4×4, 8×8, 16×16) in local branch while keeping other parameters fixed to find optimal trade-off between detail preservation and efficiency

## Limitations
- Lack of detailed ablation studies on critical hyperparameters like patch size and deformable attention stride
- Real-world denoising performance shows smaller margins over baselines compared to synthetic tasks
- Fixed patch sizes and numbers for local/global branches may not be optimal across different image types

## Confidence
- **High Confidence**: Claims about computational complexity reduction through dual-branch structure and deformable attention are well-supported by theoretical analysis and empirical FLOPs measurements.
- **Medium Confidence**: Performance claims on synthetic datasets are convincing, but real-world denoising results show smaller margins over baselines, suggesting the method may be less robust to complex noise patterns.
- **Low Confidence**: Claims about the optimality of fixed patch sizes and numbers for local/global branches lack ablation evidence, and the Position Sub-network architecture for deformable attention is underspecified.
