# Large-scale Dynamic Network Representation via Tensor Ring Decomposition

## Quick Facts
- arXiv ID: 2304.08798
- Source URL: https://arxiv.org/abs/2304.08798
- Reference count: 40
- Primary result: Achieves RMSE of 0.2775 and 0.2812 on two real LDN datasets, with 12.57-20.62% accuracy gains over existing models

## Executive Summary
This paper addresses the challenge of representation learning for large-scale dynamic networks (LDNs), which are high-dimensional and incomplete (HDI) tensors capturing temporal evolution of network structure and edge weights. The authors propose a novel Non-negative Latent Factorization of Tensors (NLFT) model based on Tensor Ring (TR) decomposition to improve upon existing CPF-based methods. The model incorporates linear bias to capture data fluctuations and employs a Single Latent Factor-dependent, Non-negative, and Multiplicative Update (SLF-NMU) principle to reduce complexity while ensuring non-negativity constraints. Experiments on two real LDN datasets demonstrate superior performance, with the proposed model achieving RMSE values of 0.2775 and 0.2812 on datasets D1 and D2 respectively, representing accuracy gains of 12.57-20.62% over existing models.

## Method Summary
The paper proposes a Non-negative Latent Factorization of Tensors (NLFT) model based on Tensor Ring (TR) decomposition for representation learning of large-scale dynamic networks (LDNs). The model decomposes the input HDI tensor into core tensors U, V, W and linear bias tensors A, B, C using TR decomposition, then optimizes these parameters using the Single Latent Factor-dependent, Non-negative, and Multiplicative Update (SLF-NMU) algorithm. The method incorporates linear bias terms to capture temporal and structural fluctuations in the network data, while the SLF-NMU principle ensures non-negativity constraints are maintained throughout the optimization process.

## Key Results
- Achieves RMSE of 0.2775 on dataset D1 and 0.2812 on dataset D2
- Demonstrates 12.57-20.62% accuracy improvements over existing models
- Successfully handles high-dimensional and incomplete tensor data with 409,028 and 298,280 nodes across 1149 and 865 time points

## Why This Works (Mechanism)

### Mechanism 1: Tensor Ring Decomposition Advantages
Tensor Ring decomposition preserves structural information better than Canonical Polyadic Factorization for high-order tensors. The cyclic multiplication structure of TR decomposition captures higher-order interactions between dimensions that CPF cannot represent effectively, maintaining low-rank properties while preserving more complex data structures.

### Mechanism 2: SLF-NMU Computational Efficiency
Single Latent Factor-dependent, Non-negative, and Multiplicative Update (SLF-NMU) reduces computational complexity while maintaining non-negativity. The multiplicative update rules based on single latent factor dependencies converge to optimal non-negative solutions without requiring expensive gradient computations, avoiding additive gradient descent issues with negative values in non-negative data.

### Mechanism 3: Linear Bias Modeling
Linear bias modeling captures data fluctuations in dynamic networks better than standard factorization. Linear bias tensors are introduced to model temporal and structural fluctuations, with each bias tensor capturing diagonal slice variations across dimensions, effectively representing the dynamic patterns in the network data.

## Architecture Onboarding

- **Component map**: Input HDI tensor → TR decomposition into U, V, W → Linear bias decomposition into A, B, C → SLF-NMU optimization → Output predicted tensor with reduced RMSE/MAE

- **Critical path**: The system decomposes the input HDI tensor into low-rank components while maintaining non-negativity and incorporating linear bias for dynamic patterns, with SLF-NMU update rules ensuring convergence to optimal solutions.

- **Design tradeoffs**: TR decomposition vs CPF (complexity vs structural preservation), multiplicative vs additive updates (convergence speed vs implementation simplicity), linear bias vs higher-order terms (computational efficiency vs modeling flexibility)

- **Failure signatures**: Poor convergence indicates incorrect learning rates or initialization, high reconstruction error suggests insufficient rank or missing bias terms, negative values in output indicate SLF-NMU implementation errors
