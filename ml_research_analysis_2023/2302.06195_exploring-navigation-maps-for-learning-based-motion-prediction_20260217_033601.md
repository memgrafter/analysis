# Exploring Navigation Maps for Learning-Based Motion Prediction

## Quick Facts
- arXiv ID: 2302.06195
- Source URL: https://arxiv.org/abs/2302.06195
- Reference count: 38
- Key outcome: Navigation maps significantly improve motion prediction over no map, and with knowledge distillation achieve results close to HD map-reliant models

## Executive Summary
This paper investigates navigation maps as a cost-effective alternative to HD maps for learning-based motion prediction in autonomous driving. While HD maps are expensive to create and maintain, navigation maps with near-global coverage are freely available from sources like OpenStreetMap. The authors integrate navigation maps into existing motion prediction models and propose a knowledge distillation method that leverages locally available HD maps during training to transfer geometric information to navigation map-based models. Their approach demonstrates significant improvements over map-free baselines and achieves performance close to HD map-reliant models on the Argoverse dataset.

## Method Summary
The authors propose integrating navigation maps into existing learning-based motion prediction models by replacing HD map lane segment queries with road segment queries from navigation maps. They implement a knowledge distillation framework where a teacher model trained with HD maps guides a student model trained with navigation maps through latent space matching. The distillation loss is computed as the mean squared error between teacher and student embeddings, scaled by the number of time steps. The total training loss combines the standard prediction loss with the distillation loss, allowing the student to benefit from the geometric precision of HD maps during training while operating with coarser navigation maps during inference.

## Key Results
- Navigation map integration improves minADE by 3.65m and minFDE by 5.89m for k=6 predictions compared to map-free baselines
- Knowledge distillation with navigation maps achieves results close to original HD map-reliant models
- The approach works across different prediction models (LaneGCN and HiVT) with consistent improvements

## Why This Works (Mechanism)

### Mechanism 1
Navigation maps provide sufficient topological and road-level geometric information to improve motion prediction over no map at all. By replacing HD map lane segment queries with road segment queries from navigation maps, the model gains coarse geometric priors about drivable regions, enabling better intent prediction. The core assumption is that road-level geometry is sufficient to distinguish between different vehicle motion patterns, even without lane-level detail.

### Mechanism 2
Knowledge distillation from HD map-aware teacher to navigation map-aware student improves performance close to HD map-reliant models. The teacher's HD map embeddings guide the student's navigation map embeddings via a distillation loss in latent space, transferring high-fidelity geometric cues. The core assumption is that latent embeddings from HD maps encode transferable information that can be approximated using coarser navigation map geometry.

### Mechanism 3
Navigation maps enable global coverage for motion prediction without requiring costly HD map creation. Free, globally available OpenStreetMap data provides road topology for training and inference, avoiding the need for manual HD map generation. The core assumption is that OSM's road-level geometry is globally consistent enough for reliable prediction across diverse regions.

## Architecture Onboarding

- **Component map**: OpenStreetMap API wrapper → Navigation map graph (nodes + edges) → LaneGCN/HiVT model → Graph encoder + attention fusion → Trajectory decoder → Teacher-student pipeline → Frozen HD map teacher → Navigation map student with distillation loss → Argoverse dataset loader → Coordinate transformation + trajectory targets

- **Critical path**: 1. Load OSM navigation map and transform to local coordinates 2. Replace HD map lane queries with road segment queries 3. Run teacher model (HD map) to obtain embeddings 4. Train student model with distillation loss to match teacher embeddings 5. Evaluate predictions against ground truth

- **Design tradeoffs**: Road-level vs lane-level geometry (simpler, more robust, but less precise); Full vs partial embedding distillation (full matching ensures strong guidance but may limit flexibility; partial matching allows navigation map-specific features); Teacher-student vs standalone (distillation improves performance but requires HD map during training)

- **Failure signatures**: Poor minADE/minFDE improvement over map-free baseline → navigation map insufficient; High MR with correct geometry → intent prediction failure; Distillation loss divergence → teacher-student embedding mismatch

- **First 3 experiments**: 1. Run LaneGCN/HiVT with navigation map only, compare to map-free baseline on Argoverse validation set 2. Enable teacher-student distillation with d=dt, evaluate improvement 3. Test teacher-student with d=1.5·dt, analyze trade-off between guidance and flexibility

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of navigation map-based motion prediction models vary across different geographic regions with varying road network complexity? The paper evaluates on Argoverse dataset from Miami and Pittsburgh but suggests investigating whether similar results are achievable in other application areas beyond motion prediction. This remains unresolved as experiments are limited to two specific urban areas.

### Open Question 2
What is the impact of incorporating additional features from navigation maps (e.g., road segment attributes) on motion prediction performance? The authors deliberately omit road segment features to demonstrate the benefit of basic navigation map geometry alone, leaving the impact of additional features unexplored. This requires experiments comparing performance with and without various road segment features across multiple prediction models.

### Open Question 3
How does the performance of navigation map-based models degrade as the time horizon for prediction increases compared to HD map-based models? The paper evaluates prediction performance at specific time horizons but doesn't analyze how performance changes with increasing prediction distance, particularly for scenarios requiring precise lane-level information. This requires comparative analysis of prediction error growth over increasing time horizons.

## Limitations
- The paper lacks rigorous testing of road-level vs. lane-level geometry sufficiency across varying map granularities
- Knowledge distillation effectiveness is demonstrated but lacks comprehensive ablation studies on distillation loss impact
- Global consistency assumption for OpenStreetMap data is asserted but not empirically verified across diverse geographic regions

## Confidence

- **High confidence**: The empirical results showing navigation maps significantly outperform map-free baselines (minADE/minFDE improvements of 3.65m/5.89m for k=6 on LaneGCN and 4.35m/7.19m on HiVT)
- **Medium confidence**: The knowledge distillation approach achieves results "close to" HD map models, though exact proximity varies by metric
- **Low confidence**: The generalizability of results beyond Argoverse dataset and the assumption of OSM consistency across all geographic regions

## Next Checks

1. Conduct ablation studies testing navigation map granularity (road-level vs. partial lane-level information) to quantify the minimum sufficient detail for prediction improvement

2. Implement cross-dataset validation by testing models trained on Argoverse with navigation maps on a different autonomous driving dataset to assess generalizability

3. Perform geographic diversity testing by evaluating model performance across OSM regions with varying quality levels (urban vs. rural, developed vs. developing countries)
