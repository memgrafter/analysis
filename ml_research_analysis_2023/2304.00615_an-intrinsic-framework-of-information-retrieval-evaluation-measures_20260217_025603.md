# An Intrinsic Framework of Information Retrieval Evaluation Measures

## Quick Facts
- arXiv ID: 2304.00615
- Source URL: https://arxiv.org/abs/2304.00615
- Reference count: 40
- Key outcome: Introduces an intrinsic framework classifying IR evaluation measures into ordinal/pseudometric, ordinal/metric, and interval/metric categories based on their ordering and distance properties

## Executive Summary
This paper proposes an intrinsic framework for characterizing information retrieval (IR) evaluation measures by exploiting their inherent ordering and distance properties. The framework classifies IR measures into three categories based on their mathematical properties: ordinal/pseudometric (default properties), ordinal/metric (distinct values for all rankings), and interval/metric (equally spaced attained values). Using this taxonomy, the paper analyzes common IR measures, finding that set-based retrieval measures like precision, recall, and F-measure exhibit strong formal properties (most are metrics and interval scales), while rank-based measures like average precision and discounted cumulative gain are generally pseudometrics and ordinal scales, sacrificing formal properties to better capture user satisfaction.

## Method Summary
The method employs the Representational Theory of Measurement (RTM) to classify IR evaluation measures based on their intrinsic properties. The framework derives an ordering structure and distance metric from each measure's attained values, then applies a taxonomy to categorize measures as ordinal/pseudometric, ordinal/metric, or interval/metric. The classification process involves determining the ordering by comparing attained values, checking injectivity (which determines metric vs. pseudometric properties), and verifying equispacedness (which determines interval scale properties).

## Key Results
- Set-based retrieval measures (precision, recall, F-measure) are generally interval scales and metrics
- Rank-based measures (average precision, DCG, NDCG) are typically ordinal scales and pseudometrics
- The framework reveals a fundamental tradeoff between formal mathematical properties and ability to capture user satisfaction

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Retrieval measures are inherently ordered because their values reflect relative system effectiveness.
- Mechanism: The framework exploits the fact that every IR measure defines a natural weak order on system outputs based on its attained values.
- Core assumption: The ordering is preserved through the measure's definition, making comparisons between systems meaningful.
- Evidence anchors:
  - [abstract] "By exploiting the information contained in a retrieval measure itself."
  - [section 3] "Every IR evaluation measure, f, establishes an implicit ordering relationship, ⪯f, which is defined by their attained values..."
  - [corpus] Weak - no direct corpus evidence linking ordering to effectiveness comparisons.
- Break condition: If two systems produce identical measure values but differ in actual relevance, the ordering loses discriminative power.

### Mechanism 2
- Claim: The intrinsic framework derives both ordering and distance metrics from the measure's own values.
- Mechanism: The absolute difference between measure values serves as a natural distance metric, enabling comparison of system outputs.
- Core assumption: The Euclidean distance on measure values reflects meaningful differences in retrieval performance.
- Evidence anchors:
  - [section 3] "Every IR evaluation measure, f, has a naturally associated distance, df..."
  - [section 4] "df(ˆ r1, ˆ r2) = |f(ˆ r1) − f(ˆ r2)|"
  - [corpus] Weak - no corpus evidence showing distance reflects actual performance gaps.
- Break condition: If the measure is non-injective, distance may be zero for distinct rankings, breaking metric properties.

### Mechanism 3
- Claim: The framework classifies measures into three intrinsic categories based on injectivity and equispacedness.
- Mechanism: Measures are categorized as ordinal/pseudometric (default), ordinal/metric (injective), or interval/metric (equispaced values).
- Core assumption: The attained values' properties (distinctness and spacing) determine the measure's formal classification.
- Evidence anchors:
  - [section 5] "Three main categories of retrieval measures according to their intrinsic properties."
  - [section 6] Examples showing set-based measures are interval/metric, rank-based are typically ordinal/pseudometric.
  - [corpus] Weak - no corpus evidence validating the practical utility of this classification.
- Break condition: If the measure's domain is explicitly specified, the intrinsic classification may not hold.

## Foundational Learning

- Concept: Representational Theory of Measurement (RTM)
  - Why needed here: Provides the theoretical foundation for classifying scales (nominal, ordinal, interval, ratio) based on preservation of order and differences.

## Architecture Onboarding

- Component map: The framework consists of three main components: (1) the ordering structure (⪯f), (2) the distance metric (df), and (3) the classification taxonomy. The ordering and distance are derived from the measure's attained values, while the taxonomy uses these to categorize the measure.

- Critical path: To classify a measure, first determine its ordering by comparing attained values, then check if it's injective (metric vs. pseudometric), and finally check if values are equispaced (interval scale vs. ordinal).

- Design tradeoffs: The framework prioritizes theoretical rigor (RTM-based classification) over practical applicability. It may classify measures as "weaker" than their actual utility suggests.

- Failure signatures: If a measure is not injective, it cannot be a metric. If values are not equispaced, it cannot be an interval scale. The framework will not detect ratio scales since it lacks multiplicative operations.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the intrinsic framework be extended to handle non-monotonic relationships between system output rankings and evaluation measures?
- Basis in paper: [inferred] The paper assumes a weak order on the empirical domain induced by the retrieval measure, but doesn't explore scenarios where this ordering might be non-monotonic.
- Why unresolved: The current framework relies on the retrieval measure inducing a total order on the domain, which may not hold for all possible evaluation scenarios or measures.
- What evidence would resolve it: Formal characterization of metric and scale properties when the retrieval measure induces a non-monotonic or partial order on the domain.

### Open Question 2
- Question: How do the intrinsic properties of evaluation measures change when considering dynamic or adaptive retrieval systems that modify their ranking based on user feedback?
- Basis in paper: [inferred] The framework assumes static rankings, but doesn't address scenarios where the system's output changes based on user interactions or feedback.
- Why unresolved: Modern retrieval systems often incorporate user feedback to adjust rankings, which could impact the intrinsic properties derived from the measure itself.
- What evidence would resolve it: Analysis of how user feedback loops affect the metric and scale properties of evaluation measures within the intrinsic framework.

### Open Question 3
- Question: Can the intrinsic framework be applied to evaluate multi-modal retrieval systems that return heterogeneous results (e.g., text, images, videos) within the same ranking?
- Basis in paper: [inferred] The framework is presented for homogeneous document rankings, but doesn't explicitly address heterogeneous or multi-modal retrieval scenarios.
- Why unresolved: Modern retrieval systems often return diverse result types, and it's unclear how the intrinsic properties would generalize to such scenarios.
- What evidence would resolve it: Extension of the intrinsic framework to handle heterogeneous result types and analysis of how this affects the metric and scale properties of evaluation measures.

## Limitations
- Focus on measures with real-valued outputs excludes categorical or structured results
- Cannot detect ratio scales due to lack of multiplicative operations
- Absence of corpus evidence linking theoretical properties to practical retrieval performance

## Confidence
- Ordering structure derivation: Medium - theoretical basis is strong but lacks empirical validation
- Distance metric properties: Medium - clear mathematical derivation but uncertain practical relevance
- Classification taxonomy: High - follows established RTM principles
- Practical utility: Low - no corpus evidence demonstrating real-world applicability
