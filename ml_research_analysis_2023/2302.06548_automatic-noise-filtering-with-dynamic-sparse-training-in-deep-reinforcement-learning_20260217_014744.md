# Automatic Noise Filtering with Dynamic Sparse Training in Deep Reinforcement Learning

## Quick Facts
- arXiv ID: 2302.06548
- Source URL: https://arxiv.org/abs/2302.06548
- Reference count: 40
- Key outcome: ANF-SAC and ANF-TD3 outperformed standard SAC and TD3 by a large margin, using up to 95% fewer weights, and maintained superior performance even with noise levels up to 99%.

## Executive Summary
This paper introduces Automatic Noise Filtering (ANF), a method that combines dynamic sparse training with deep reinforcement learning to address the challenge of training agents in extremely noisy environments where up to 99% of input features are pure noise. ANF works by dynamically pruning connections to noise features and growing connections to task-relevant features in the input layer, allowing the agent to focus on useful information while ignoring irrelevant noise. The method demonstrates superior performance compared to standard SAC and TD3 algorithms while using significantly fewer weights, and shows better transfer learning capabilities in environments where feature relevance changes over time.

## Method Summary
ANF implements dynamic sparse training on the input layer of SAC and TD3 networks, starting with 80% sparsity and dynamically adjusting connectivity every 1000 timesteps. The method drops the 5% of smallest-magnitude weights and regrows the same number randomly, allowing the network to adaptively focus on task-relevant features. This approach contrasts with dense networks that must adjust all weights and with static sparse networks that cannot adapt their topology during training. ANF maintains dense hidden layers to preserve representational capacity while filtering noise at the input stage.

## Key Results
- ANF-SAC and ANF-TD3 achieved 100% success rate on Humanoid-v3 with 90% noise features, while dense baselines failed completely
- ANF maintained superior performance with up to 95% sparsity in the input layer, using 95% fewer weights than dense networks
- In the PENE transfer learning setting, ANF adapted faster to feature permutations than dense baselines due to maintained plasticity

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Dynamic sparse training (DST) enables faster identification of task-relevant features by allowing the network to drop connections to noise features and grow connections to relevant features, rather than adjusting dense weight values.
- **Mechanism:** ANF starts with a randomly sparsified input layer and dynamically prunes weak connections (low magnitude weights) while growing new connections after every topology-change period. This allows the network to adaptively shift its connectivity focus toward features that provide useful information about the environment's task.
- **Core assumption:** Dropping and growing sparse connections is computationally easier and faster than adjusting all weights in a dense network to achieve the same performance gain.
- **Evidence anchors:** [abstract]: "The sparse input layer learns to focus its connectivity on task-relevant features, such that ANF-SAC and ANF-TD3 outperform standard SAC and TD3 by a large margin, while using up to 95% fewer weights."
- **Break condition:** If the task-relevant features are not distinguishable from noise features in terms of magnitude or distribution, pruning based on weight magnitude becomes ineffective.

### Mechanism 2
- **Claim:** Sparsifying only the input layer while keeping hidden layers dense allows ANF to efficiently filter noise at the source without losing representational capacity in deeper layers.
- **Mechanism:** By focusing dynamic sparse training on the first layer, ANF creates a sparse feature selector that passes only relevant information to the dense hidden layers, which can then learn complex task representations from this cleaned input.
- **Core assumption:** The distinction between relevant and noise features can be made effectively at the input layer level.
- **Evidence anchors:** [section 4]: "Another difference between ANF and DS-TD3/SAC [39] is that we only sparsify the input layer."
- **Break condition:** If task-relevant features require complex combinations or transformations that cannot be captured by sparse input-layer connectivity alone.

### Mechanism 3
- **Claim:** ANF maintains plasticity through dynamic topology changes, enabling effective adaptation to changing environments (PENE) where feature relevance shifts over time.
- **Mechanism:** The ability to drop and regrow connections allows ANF to quickly adjust to new feature distributions after permutations, recovering performance faster than dense networks that must retrain all weights.
- **Core assumption:** Maintaining some connections to previously noise features provides a useful starting point for adapting to new task-relevant features.
- **Evidence anchors:** [section 5]: "Agents that have to learn continually must be able to maintain plasticity. Standard methods are unable to do so... Since the connections of the input layer can drop and grow dynamically, ANF ensures that the agent has sufficient adaptability."
- **Break condition:** If environment changes are too frequent relative to the topology-change period, the network cannot stabilize on useful connections.

## Architecture Onboarding

- **Component map:** State → Sparse input layer (dynamic pruning/growing) → Dense hidden layers → Policy/Value output → Action selection
- **Critical path:** State → Sparse input layer (dynamic pruning/growing) → Dense hidden layers → Policy/Value output → Action selection
- **Design tradeoffs:**
  - Input layer sparsity vs. performance: Higher sparsity reduces parameters but may miss some task-relevant features
  - Topology-change period: Shorter periods allow faster adaptation but increase computational overhead
  - Drop fraction: Larger fractions create more dramatic topology changes but may destabilize learning
- **Failure signatures:**
  - Performance plateaus early: May indicate insufficient sparsity or inappropriate topology-change frequency
  - High variance in performance: Could suggest unstable pruning/growing dynamics
  - Slow adaptation to PENE: May indicate connections to noise features were pruned too aggressively

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of ANF scale with even higher levels of noise beyond 99%?
- Basis in paper: [explicit] The paper tests noise levels up to 99% and shows ANF still outperforms baselines, but does not test higher levels.
- Why unresolved: The experiments stop at 99% noise, leaving open the question of whether ANF can handle noise levels approaching 100%.
- What evidence would resolve it: Additional experiments with noise levels of 99.5%, 99.9%, and 99.99% to determine the upper limit of ANF's noise filtering capability.

### Open Question 2
- Question: What is the theoretical relationship between the number of task-relevant features and the maximum achievable sparsity level?
- Basis in paper: [inferred] The paper shows ANF can achieve high sparsity levels (up to 95% in Humanoid) but does not explore the relationship between task-relevant feature count and sparsity limits.
- Why unresolved: The paper demonstrates practical results but does not provide theoretical analysis of sparsity limits as a function of task-relevant feature density.
- What evidence would resolve it: Mathematical analysis and experiments varying the number of task-relevant features while measuring maximum achievable sparsity without performance degradation.

### Open Question 3
- Question: How would ANF perform in environments where noise and task-relevant features have overlapping distributions?
- Basis in paper: [explicit] Section 7 shows ANF can handle noise that imitates task-relevant features, but only tests one specific imitation scenario.
- Why unresolved: The paper tests only one type of feature distribution overlap, not exploring the full spectrum of possible feature distribution relationships.
- What evidence would resolve it: Experiments with various degrees of distribution overlap between noise and task-relevant features, measuring performance degradation as overlap increases.

## Limitations

- The effectiveness of weight magnitude-based pruning may break down when task-relevant features cannot be distinguished from noise through magnitude alone
- The paper does not provide quantitative evidence comparing the computational efficiency of dynamic sparse training versus dense weight adjustment
- Single-layer sparsity may be insufficient for environments requiring complex feature transformations that cannot be captured at the input layer

## Confidence

- High confidence: ANF-SAC/ANF-TD3 outperform dense baselines in extreme noise environments (90-99% noise)
- Medium confidence: Single-layer sparsity is sufficient for effective noise filtering across diverse MuJoCo tasks
- Low confidence: Weight magnitude-based pruning is the optimal criterion for distinguishing relevant from noise features

## Next Checks

1. Test ANF performance when task-relevant features have similar magnitude distributions to noise features, challenging the pruning criterion
2. Compare computational efficiency (wall-clock time) of ANF vs. dense SAC/TD3 during training to verify the claimed computational advantage
3. Evaluate ANF in environments with structured noise (e.g., correlated noise patterns) rather than pure Gaussian noise to assess real-world robustness
