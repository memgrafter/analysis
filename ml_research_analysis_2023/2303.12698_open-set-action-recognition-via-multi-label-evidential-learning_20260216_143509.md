# Open Set Action Recognition via Multi-Label Evidential Learning

## Executive Summary
This paper introduces MULE, the first framework for open set action recognition that handles single/multi-actor and single/multi-action settings. MULE models actor-context-object relations and uses Beta Evidential Neural Networks to estimate uncertainty for each action with Beta distributions. A multi-label evidence debiasing constraint reduces static bias, and a primal-dual average scheme updates parameters with convergence guarantees. Experiments on AVA and Charades demonstrate that MULE achieves state-of-the-art performance.

## Method Summary
MULE is a novel framework designed to tackle the challenges of open set action recognition, which involves recognizing both known and unknown actions in videos with varying numbers of actors and actions. The framework models the complex relationships between actors, context, and objects in a video. It employs Beta Evidential Neural Networks to quantify uncertainty for each action using Beta distributions, allowing for more nuanced uncertainty estimation. To address static bias in multi-label settings, MULE incorporates a multi-label evidence debiasing constraint. Additionally, a primal-dual average scheme is utilized to update the model parameters, ensuring convergence. The framework is evaluated on the AVA and Charades datasets, where it demonstrates superior performance compared to existing methods.

## Key Results
- MULE achieves an error of 11.22 and AUROC of 86.92 on the AVA dataset.
- The framework outperforms state-of-the-art methods in open set action recognition.
- MULE effectively handles single/multi-actor and single/multi-action settings.

## Why This Works (Mechanism)
The success of MULE can be attributed to its ability to model complex actor-context-object relationships and its use of Beta Evidential Neural Networks for uncertainty estimation. By leveraging Beta distributions, the framework can capture the uncertainty associated with each action more effectively. The multi-label evidence debiasing constraint helps mitigate static bias, which is crucial in multi-label settings. The primal-dual average scheme ensures stable and convergent parameter updates, contributing to the overall robustness of the model.
