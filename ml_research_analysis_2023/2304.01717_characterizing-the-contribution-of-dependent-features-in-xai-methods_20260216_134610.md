# Characterizing the contribution of dependent features in XAI methods

## Quick Facts
- arXiv ID: 2304.01717
- Source URL: https://arxiv.org/abs/2304.01717
- Reference count: 13
- Primary result: Proposed MIP method addresses collinearity in XAI by providing more reliable feature rankings through iterative predictor removal and ranking normalization

## Executive Summary
This paper addresses a critical limitation in explainable AI (XAI) methods like SHAP and LIME: their vulnerability to feature collinearity, which can produce unreliable feature rankings. The authors propose a model-agnostic proxy method that modifies standard XAI rankings to account for dependencies among predictors. The approach iteratively removes the top-ranked predictor, retrains the model, and calculates a Modified Informative Position (MIP) score based on ranking stability across iterations, ensuring that collinear features receive similar importance scores.

The method was validated using cardiac MRI data from the UK Biobank, demonstrating improved correlation with biologically plausible benchmarks compared to standard SHAP alone. The results show that the MIP method effectively addresses the issue of collinearity, providing a more robust and interpretable feature ranking in the presence of dependent predictors. The approach is computationally straightforward and can be applied to any XAI method that doesn't inherently account for collinearity.

## Method Summary
The proposed method iteratively removes the top-ranked predictor based on SHAP scores, retrains the model, and recalculates rankings to account for feature dependencies. For each iteration, the feature's position index is normalized by the current number of remaining features, and these normalized scores are summed across all iterations to produce the final MIP score. Lower MIP scores indicate more informative predictors, while higher scores indicate less informative ones. The method is model-agnostic and validated using cardiac MRI data from the UK Biobank for sex classification, showing improved correlation with biological benchmarks compared to standard SHAP rankings.

## Key Results
- The MIP method successfully addresses collinearity issues in XAI, ensuring collinear features receive similar importance scores
- Validation on UK Biobank cardiac MRI data showed improved correlation with biologically plausible benchmarks compared to standard SHAP
- The method demonstrates model-agnostic behavior across multiple classifier types (SVC, LGBM, DT, RF, LR)
- Standard deviation of MIP scores serves as a proxy for ranking robustness, with higher SD indicating greater stability

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Modified Informative Position (MIP) score accounts for feature collinearity by normalizing each feature's rank index by the number of remaining features at each iteration.
- Mechanism: At each iteration, the top-ranked feature is removed, the model is retrained, and SHAP is reapplied. The feature's position index is divided by the current number of features, creating a normalized score. Summing these normalized scores across all iterations yields the MIP score.
- Core assumption: Features that are collinear will consistently drop in rank together across iterations, leading to similar cumulative normalized scores.
- Evidence anchors:
  - [abstract]: "This approach ensures that collinear features receive similar importance scores, leading to a more robust and interpretable feature ranking."
  - [section]: "The smaller the score, the more the predictor is informative, or, equivalently, the higher the score the less informative the predictor."
- Break condition: If features are not truly collinear, they will drop in rank at different rates, causing their MIP scores to diverge significantly.

### Mechanism 2
- Claim: The MIP method is model-agnostic because it relies only on SHAP rankings, which are computed after each model retraining.
- Mechanism: The algorithm iteratively removes the top SHAP-ranked feature, retrains the model (which could be any classifier), and recomputes SHAP rankings. The MIP score is then calculated based on the consistency of feature positions across these iterations.
- Core assumption: SHAP rankings will reflect the true marginal contribution of each feature to the model output, regardless of the underlying model architecture.
- Evidence anchors:
  - [abstract]: "The proposed approach has the advantage of being model-agnostic as well as simple to calculate the impact of each predictor in the model in presence of collinearity."
  - [section]: "The proposed method is model-agnostic, which means that it can be applied to any XAI method that does not consider the collinearity among the predictors in its outcome."
- Break condition: If the underlying model is highly unstable to feature removal, the SHAP rankings may become erratic, making the MIP scores unreliable.

### Mechanism 3
- Claim: The standard deviation (SD) of MIP scores serves as a proxy for the robustness of the feature ranking, with higher SD indicating greater stability.
- Mechanism: Features that consistently move up or down in rank across iterations will have higher variance in their normalized scores, leading to a larger SD. A high SD suggests that features are being ranked in a stable, sequential order rather than being grouped together due to collinearity.
- Core assumption: A stable ranking order (low collinearity) will produce a larger variance in MIP scores because features will move independently.
- Evidence anchors:
  - [section]: "The higher SD means that the features are approaching the top list sequentially."
  - [section]: "The model that produces the lowest NMR value is the more stable one."
- Break condition: If all features have similar MIP scores (low SD), it suggests that the ranking is unstable and likely affected by collinearity.

## Architecture Onboarding

- Component map: Data preprocessing -> Model training -> SHAP ranking -> Iterative feature removal and retraining -> MIP score calculation -> SD-based stability assessment
- Critical path: 1. Train initial model on full feature set. 2. Compute SHAP rankings. 3. Iteratively remove top-ranked feature, retrain, and recompute SHAP. 4. Calculate MIP scores by summing normalized rank indices. 5. Compute SD of MIP scores to assess stability.
- Design tradeoffs: Computational cost: The iterative retraining can be expensive for large datasets or complex models. Model dependency: The method assumes SHAP rankings are meaningful after each retraining. Interpretability: The MIP scores are more interpretable than raw SHAP values in the presence of collinearity.
- Failure signatures: Low SD of MIP scores: Indicates instability in the ranking, possibly due to high collinearity or model sensitivity. Inconsistent MIP scores across different models: Suggests the method may not be robust to model choice.
- First 3 experiments: 1. Apply MIP to a synthetic dataset with known collinear features and verify that collinear features receive similar MIP scores. 2. Compare MIP rankings with standard SHAP rankings on a real-world dataset (e.g., UK Biobank) and assess stability using SD. 3. Test MIP across multiple classifiers (e.g., RF, SVM, LR) on the same dataset to confirm model-agnostic behavior.
