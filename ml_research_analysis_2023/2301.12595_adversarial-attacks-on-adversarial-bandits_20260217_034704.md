# Adversarial Attacks on Adversarial Bandits

## Quick Facts
- arXiv ID: 2301.12595
- Source URL: https://arxiv.org/abs/2301.12595
- Reference count: 40
- Key outcome: Attacker can force any no-regret bandit algorithm to select a suboptimal target arm in T-o(T) rounds while incurring only o(T) cumulative attack cost.

## Executive Summary
This paper investigates the vulnerability of adversarial multi-armed bandit algorithms to reward poisoning attacks, where an attacker manipulates the loss or reward signal to influence the victim's arm selection. The authors propose attack algorithms that force any no-regret bandit algorithm to select a suboptimal target arm in T-o(T) rounds while incurring only o(T) cumulative attack cost. The attack is optimal among all victim-agnostic attack algorithms, with a theoretical lower bound matching the upper bound achieved by the proposed attack. Experiments demonstrate the effectiveness of the attacks on both vanilla and robust versions of the Exp3 algorithm. The results highlight critical security concerns in bandit-based systems, such as online recommendation, where an attacker could potentially hijack the system to promote a desired product.

## Method Summary
The paper proposes template-based attack algorithms that exploit the partial observability of loss functions in multi-armed bandit settings. The attacker uses pre-defined loss function templates to manipulate the victim's perception of which arm is optimal, forcing selection of a target arm while minimizing attack cost. The attack algorithms work by keeping the target arm's loss unchanged or minimally perturbed while maximally penalizing non-target arms. The paper provides theoretical analysis showing the attacks are asymptotically optimal among all victim-agnostic attack algorithms, with both upper and lower bounds on cumulative attack cost.

## Key Results
- Any no-regret bandit algorithm can be forced to select a suboptimal target arm in T-o(T) rounds
- The proposed attack achieves o(T) cumulative attack cost while forcing target arm selection
- The attack is theoretically optimal among all victim-agnostic attack algorithms
- Experiments show effectiveness against both vanilla and robust versions of Exp3 algorithm

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The attacker can force any no-regret bandit algorithm to select a suboptimal target arm in T-o(T) rounds with only o(T) cumulative attack cost.
- **Mechanism:** The attacker uses template-based loss functions where the target arm's loss is kept unchanged or minimally perturbed while non-target arms are maximally penalized. This exploits the partial observability of loss functions in multi-armed bandit settings.
- **Core assumption:** The bandit algorithm satisfies the "no-regret" property with regret rate α ∈ [1/2, 1).
- **Evidence anchors:**
  - [abstract]: "attacker is able to mislead any no-regret adversarial bandit algorithm into selecting a suboptimal target arm in every but sublinear (T−o(T)) number of rounds, while incurring only sublinear (o(T)) cumulative attack cost."
  - [section 4.1]: "the target arm becomes the best-in-hindsight arm after attack. Consider running a no-regret bandit algorithm on the perturbed loss ˜L1:T, since ˜Lt(a†) = Lt(a†) ≤ 1−ρ, every time the player selects a non-target arm at ̸= a†, it will incur at least ρ regret."
  - [corpus]: Weak - the corpus contains related work on adversarial attacks but doesn't directly support this specific mechanism.
- **Break condition:** If the bandit algorithm uses a robust variant that explicitly defends against such template-based attacks, or if the regret rate α approaches 1 (making the attack less effective).

### Mechanism 2
- **Claim:** The attack cost is asymptotically optimal among all victim-agnostic attack algorithms.
- **Mechanism:** The attacker's template-based approach achieves the theoretical lower bound on cumulative attack cost that any victim-agnostic attack algorithm must incur to achieve T−o(T) target arm selections.
- **Core assumption:** The attacker knows the regret rate α but doesn't know the specific bandit algorithm used by the victim.
- **Evidence anchors:**
  - [abstract]: "We also derived a theoretical lower bound on the cumulative attack cost that any victim-agnostic attack algorithm must incur. The lower bound matches the upper bound achieved by our attack, which shows that our attack is asymptotically optimal."
  - [section 5]: "if an attack algorithm achieves T−o(T) target arm selections and is also victim-agnostic, then the cumulative attack cost is at least Ω(T^α)."
  - [corpus]: Explicit - "Stochastic Bandits Robust to Adversarial Attacks" directly relates to this mechanism.
- **Break condition:** If the attacker has knowledge of the specific bandit algorithm beyond just the regret rate, or if the victim algorithm is not truly victim-agnostic.

### Mechanism 3
- **Claim:** The attack effectiveness varies based on the "attack difficulty" determined by how close the target arm's loss is to the maximum value.
- **Mechanism:** The attacker adjusts the template loss functions based on the attack difficulty parameter ρ, where smaller ρ (target arm closer to optimal) makes the attack easier and more cost-effective.
- **Core assumption:** There exists a constant ρ ∈ (0, 1] such that Lt(a†) ∈ [0, 1−ρ] for all t ∈ [T].
- **Evidence anchors:**
  - [section 4.1]: "Assumption 4.1. (Easy Attack Scenario). There exists some constant ρ ∈ (0, 1] such that Lt(a†) ∈ [0, 1−ρ], ∀t ∈ [T]."
  - [section 4.2]: "We now show that our attack(6) recovers the results of Theorem 4.3 when it is applied in the easy attack scenario."
  - [corpus]: Weak - the corpus doesn't provide direct evidence for this mechanism, though it mentions related attack scenarios.
- **Break condition:** If the target arm's loss is always at the maximum value (Lt(a†) = 1 for all t), making it impossible to make the target arm appear optimal.

## Architecture Onboarding

- **Component map:**
  - Environmental loss functions L1:T (unknown to attacker)
  - Attacker's template loss functions ˜L1:T (attacker-controlled)
  - Victim bandit algorithm (unknown specific implementation)
  - Arm selection process (victim's decision-making)
  - Loss observation and perturbation mechanism (attacker's intervention point)

- **Critical path:**
  1. Environment generates loss Lt(at) for selected arm at
  2. Attacker observes at and Lt(at)
  3. Attacker perturbs to ˜Lt(at) based on template strategy
  4. Victim observes ˜Lt(at) instead of Lt(at)
  5. Victim updates policy based on perturbed observation
  6. Process repeats for T rounds

- **Design tradeoffs:**
  - Template-based vs adaptive attacks: Template-based attacks are simpler and provably optimal but less flexible
  - Attack cost vs success rate: Higher attack cost can force more target arm selections but reduces efficiency
  - Knowledge of regret rate vs specific algorithm: Knowing only regret rate makes attack more general but potentially less precise

- **Failure signatures:**
  - Target arm selected less than T−o(T) times despite attack implementation
  - Cumulative attack cost exceeds o(T) while still achieving target arm selection
  - Bandit algorithm shows unexpected robustness to loss perturbations
  - Regret bounds are violated under attack (indicating algorithm detection of manipulation)

- **First 3 experiments:**
  1. Implement the easy attack scenario (Section 4.1) with K=2 arms where Lt(a2)=0 and Lt(a1)=0.5, verify target arm a1 is selected in T−o(T) rounds

  3. Compare Exp3 vs ExpRb robustness by running attacks under different assumed attack budgets Φ and measuring target arm selection frequency

## Limitations
- Attack effectiveness degrades significantly when target arm's true loss is close to maximum value
- Optimality claim relies on assumption that attacker knows regret rate but not specific algorithm
- Template-based approach is less flexible than adaptive strategies that could respond to victim behavior

## Confidence
**High Confidence:** The core mechanism of template-based attacks exploiting partial observability and the theoretical optimality bounds (Theorem 4.3, 5.1) are well-supported by the mathematical analysis and proofs provided in the paper.

**Medium Confidence:** The experimental results demonstrating attack effectiveness on Exp3 and ExpRb are convincing but limited in scope. The paper would benefit from testing on a broader range of bandit algorithms and more diverse loss distributions.

**Low Confidence:** The assumption that attackers only know regret rates but not specific algorithms may be overly restrictive. In practice, many systems using bandit algorithms publish their implementation details, potentially allowing for more targeted and effective attacks.
