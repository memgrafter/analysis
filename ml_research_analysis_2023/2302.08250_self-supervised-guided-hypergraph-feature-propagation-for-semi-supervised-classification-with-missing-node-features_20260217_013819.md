# Self-supervised Guided Hypergraph Feature Propagation for Semi-supervised Classification with Missing Node Features

## Quick Facts
- arXiv ID: 2302.08250
- Source URL: https://arxiv.org/abs/2302.08250
- Reference count: 0
- Primary result: Achieves 79.41% accuracy on Cora with 99% missing features (2.67% drop from no missingness)

## Executive Summary
This paper proposes SGHFP, a hypergraph-based method for semi-supervised node classification when node features are missing. The approach constructs both feature and pseudo-label hypergraphs, fuses them into a sparse matrix, and iteratively propagates features using a diffusion equation. SGHFP significantly outperforms existing feature propagation methods, achieving strong results even with extreme feature missingness (99% missing features).

## Method Summary
SGHFP addresses semi-supervised node classification with missing features by constructing feature and pseudo-label hypergraphs to capture complex data correlations. These hypergraphs are fused into a sparse matrix, and features are iteratively propagated using a diffusion equation. After each propagation step, known features are clamped to their original values to ensure stable convergence. The method requires only 1% known features to achieve competitive accuracy on benchmark datasets.

## Key Results
- Achieves 79.41% accuracy on Cora with 99% missing features
- Outperforms FP baseline by significant margins across all tested datasets
- Maintains 75.17% accuracy on PubMed with 99% missing features
- Shows only 2.67% relative accuracy drop compared to no missing features

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SGHFP outperforms FP by integrating higher-order data correlations via fused hypergraphs.
- Mechanism: Feature hypergraph captures node similarity from raw features, pseudo-label hypergraph captures label consistency; fusing them before propagation enriches the propagation matrix with both structural and semantic information.
- Core assumption: Hyperedges that connect nodes of the same class provide stronger, more reliable propagation paths than pairwise edges.
- Evidence anchors:
  - [abstract] "the constructed feature hypergraph and pseudo-label hypergraph are fused effectively, which can better preserve the higher-order data correlations among nodes."
  - [section 2.2] "the constructed feature hypergraph Gf and pseudo-label hypergraph Gpl are further fused into an effective hypergraph before each iteration."
  - [corpus] Weak match: "Hypergraph Neural Network with State Space Models for Node Classification" mentions hyperedges connecting more than two nodes but not fusion with pseudo-labels.
- Break condition: If node features are highly noisy or classes are not well-separated, pseudo-label hypergraph may introduce incorrect propagation signals.

### Mechanism 2
- Claim: The iterative reconstruction with known-feature clamping preserves original known information while inferring missing parts.
- Mechanism: After each propagation step, the algorithm resets known features to their original values, ensuring stable convergence toward correct missing feature estimates.
- Core assumption: Known features are accurate and propagation noise does not overwhelm true values in early iterations.
- Evidence anchors:
  - [section 2.3] "After that, we clamp the known features by resetting them to their original true values."
  - [section 2.2] "Equation 2 shows that pseudo-label hypergraph is beneficial to increase the intra-class feature influence."
  - [corpus] No direct evidence for clamping strategy; only general iterative imputation methods.
- Break condition: If the propagation matrix has large eigenvalues, iterative updates may diverge before clamping corrects them.

### Mechanism 3
- Claim: The self-supervised pseudo-label hypergraph improves intra-class propagation strength without requiring additional labeled data.
- Mechanism: Reconstructed features from previous iteration are fed into a two-layer GCN to generate pseudo-labels, which then guide hypergraph construction toward preserving class boundaries.
- Core assumption: Two-layer GCN can produce reasonably accurate pseudo-labels even with partially missing features.
- Evidence anchors:
  - [abstract] "the reconstructed node features produced by the previous iteration are fed to a two-layer GNNs to construct a pseudo-label hypergraph."
  - [section 2.2] "the reconstructed node features produced by the previous iteration are fed to a two-layer GNNs to construct a pseudo-label hypergraph."
  - [corpus] No direct evidence for two-layer GCN usage; only general GNN-based feature imputation.
- Break condition: If class overlap is high, pseudo-labels may reinforce incorrect class boundaries.

## Architecture Onboarding

- Component map: Feature hypergraph generator -> Two-layer GCN -> Pseudo-label hypergraph generator -> Hypergraph fusion module -> Hypergraph feature propagation -> Clamping -> Next iteration
- Critical path: Feature hypergraph → Pseudo-label hypergraph → Fusion → Propagation → Clamping → Next iteration
- Design tradeoffs:
  - Higher-order hyperedges increase expressiveness but raise computational cost
  - More propagation iterations improve reconstruction but risk over-smoothing
  - Complex fusion strategy preserves accuracy but adds implementation complexity
- Failure signatures:
  - Accuracy plateaus or degrades over iterations → over-smoothing or noisy pseudo-labels
  - Large memory usage → hypergraph degree matrices too dense
  - Slow convergence → propagation matrix poorly conditioned
