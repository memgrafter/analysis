# Cursive Caption Text Detection in Videos

## Quick Facts
- **arXiv ID**: 2301.03164
- **Source URL**: https://arxiv.org/abs/2301.03164
- **Reference count**: 40
- **Primary result**: F-measure of 0.91 for cursive caption text detection in videos using Faster R-CNN with adapted anchor boxes

## Executive Summary
This paper presents a deep learning-based system for detecting and identifying cursive caption text in video frames, with a focus on Urdu and English scripts. The method combines text detection with script identification in an end-to-end pipeline, leveraging object detectors such as Faster R-CNN, SSD, R-FCN, and YOLO. By adapting anchor boxes and training on a dataset of 11,203 video frames from Pakistani news channels, the system achieves high accuracy in localizing and classifying cursive text lines. The approach addresses the challenge of handling multiple scripts in video content and demonstrates strong performance, particularly with Faster R-CNN and Inception v2.

## Method Summary
The system fine-tunes pre-trained deep learning object detectors (Faster R-CNN, SSD, R-FCN, YOLO) on video frames containing cursive caption text in Urdu and English scripts. The pipeline adapts anchor boxes (base size 256×256, scales 1.0, 2.0, 5.0, aspect ratios 0.125–0.50) to better match the elongated shapes of text lines. Training uses a dataset of 11,203 labeled frames (40,470 text lines) from four Pakistani news channels. Detection and script identification are combined in a three-class end-to-end model, with separate script classifiers also trained on extracted text lines. The method achieves an F-measure of 0.91 on the test set.

## Key Results
- F-measure of 0.91 achieved on 11,203 video frames for cursive caption text detection.
- Faster R-CNN with adapted anchor boxes outperforms other detectors (SSD, R-FCN, YOLO).
- Script identification integrated into end-to-end pipeline for multi-script video content.

## Why This Works (Mechanism)
The approach works by adapting anchor boxes to match the aspect ratios and scales typical of cursive text lines, improving localization accuracy. Fine-tuning deep object detectors on domain-specific data (Urdu and English cursive text) enables the model to generalize across scripts. Combining detection and script identification reduces pipeline complexity and latency, while exploiting the strengths of CNNs in handling varied text orientations and styles in video frames.

## Architecture Onboarding
- **Component map**: Video frames → Object detector (e.g., Faster R-CNN) → Text bounding boxes + script labels → Output
- **Critical path**: Frame input → Anchor-based proposal generation → Classification + regression → Script identification → Final detection
- **Design tradeoffs**: End-to-end vs. two-stage (speed vs. modularity); larger anchor boxes improve recall but may hurt precision
- **Failure signatures**: Low IoU indicates anchor mismatch; script confusion suggests insufficient training data per class
