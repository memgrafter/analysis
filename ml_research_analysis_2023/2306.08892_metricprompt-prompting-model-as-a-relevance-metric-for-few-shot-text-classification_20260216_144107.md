# MetricPrompt: Prompting Model as a Relevance Metric for Few-shot Text Classification

## Quick Facts
- arXiv ID: 2306.08892
- Source URL: https://arxiv.org/abs/2306.08892
- Reference count: 40
- Primary result: Reformulates few-shot text classification as text pair relevance estimation, outperforming manual and automatic verbalizer design methods

## Executive Summary
MetricPrompt addresses the challenge of designing effective verbalizers for few-shot text classification by reformulating the task as a text pair relevance estimation problem. The method employs a prompting model as a relevance metric that simultaneously processes training and query samples to capture cross-sample relevance information. This approach achieves state-of-the-art performance across three widely used text classification datasets in four different few-shot settings.

## Method Summary
MetricPrompt transforms few-shot text classification by treating it as a relevance estimation task between text pairs. The method uses a prompting model (BART-large) to evaluate the relevance between a training sample and a query sample simultaneously, rather than relying on traditional verbalizers. This cross-sample relevance approach allows the model to capture contextual relationships that single-sample processing might miss. The framework is trained to distinguish relevant from irrelevant sample pairs, enabling more accurate classification with limited training data.

## Key Results
- Achieves new state-of-the-art performance across three text classification datasets
- Outperforms both manual verbalizer design and other automatic verbalizer methods
- Demonstrates effectiveness across four different few-shot settings
- Shows consistent improvements in accuracy over baseline approaches

## Why This Works (Mechanism)
MetricPrompt works by leveraging cross-sample relevance information that traditional single-sample classification methods cannot capture. By reformulating the problem as a text pair relevance estimation task, the prompting model can better understand the relationship between training examples and query samples. This dual-input approach allows the model to implicitly learn semantic similarities and differences that are crucial for accurate classification, especially when training data is limited.

## Architecture Onboarding

**Component Map**: Input Query + Input Training Sample -> BART-large Relevance Model -> Relevance Score -> Classification Decision

**Critical Path**: The critical path flows from the simultaneous processing of query and training samples through the BART-large model to produce a relevance score that directly informs classification decisions. This dual-input approach is essential for capturing the cross-sample relationships that drive performance improvements.

**Design Tradeoffs**: The primary tradeoff involves computational cost versus accuracy - processing two samples simultaneously increases inference time but provides significant accuracy gains. The choice of BART-large as the base model represents a balance between model capacity and practical deployment considerations. Another tradeoff exists between prompt template complexity and generalization ability.

**Failure Signatures**: Performance degradation may occur when sample pairs have weak semantic relationships, when the relevance model overfits to specific prompt templates, or when the training samples fail to represent the full label space adequately. The method may also struggle with longer sequences where cross-sample relevance becomes harder to establish.

- Cross-sample relevance estimation may face scalability challenges with longer text sequences
