# Improving Classification Neural Networks by using Absolute activation function (MNIST/LeNet-5 example)

## Quick Facts
- arXiv ID: 2304.11758
- Source URL: https://arxiv.org/abs/2304.11758
- Reference count: 8
- Primary result: The Absolute activation function (|y|) enables 7x parameter reduction while improving MNIST accuracy from 98.86% to 99.44%

## Executive Summary
This paper proposes using the absolute value function as an activation function in neural networks for classification tasks. The core insight is that the derivative modulus of the Absolute activation function is exactly 1 almost everywhere, which prevents vanishing and exploding gradients in deep networks. Experiments on MNIST with LeNet-like architectures demonstrate that this activation function can achieve higher accuracy while requiring significantly fewer trained parameters compared to traditional activation functions like ReLU, Tanh, and SeLU.

## Method Summary
The paper proposes using |y| as the activation function in neural networks, replacing traditional functions like ReLU or Tanh. The method involves modifying the ADAM optimizer to handle the volatility introduced by the Absolute activation function's non-differentiability at zero. The training procedure includes learning rate scheduling with stepwise decreases from 1e-3 to 1e-6, with model reinitialization between steps based on validation accuracy bounds estimated through bootstrapping.

## Key Results
- Achieved 99.44% accuracy on MNIST compared to 98.86% with standard LeNet-5 (Tanh activation)
- Reduced number of trained parameters by up to 7 times
- Demonstrated effectiveness on synthetic 2D datasets with reduced network size
- Showed the Absolute activation function's superiority over ReLU, Tanh, and SeLU in accuracy and parameter efficiency

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Absolute activation function avoids vanishing and exploding gradients because its derivative modulus is exactly 1 almost everywhere.
- Mechanism: Unlike smooth activation functions whose derivatives vary in magnitude, the absolute value function has a constant magnitude of 1 for all non-zero inputs. This stabilizes gradient flow through deep networks.
- Core assumption: The discontinuity at zero does not significantly harm optimization because gradient descent algorithms can handle this discontinuity through appropriate learning rate schedules.
- Evidence anchors:
  - [abstract] "The derivative modulus of the activation function should be close to 1 to avoid vanishing/exploding gradients in deep networks. The Absolute activation function, |y|, satisfies this condition."
  - [section] "This property is possessed not only by a linear function, but also by many other real-valued functions whose derivative modulus are equal to 1 almost everywhere."

### Mechanism 2
- Claim: The Absolute activation function enables smaller network architectures with fewer parameters while maintaining or improving accuracy.
- Mechanism: By using the absolute value function, the network can represent complex decision boundaries with fewer neurons because the absolute operation creates non-linear transformations that would otherwise require multiple layers or neurons.
- Core assumption: The Kolmogorov-Arnold theorem's universal approximation properties apply to networks with absolute activation functions, allowing effective function approximation with simpler architectures.
- Evidence anchors:
  - [abstract] "Experiments on synthetic 2D datasets and the MNIST problem demonstrate that the Absolute activation function can achieve high accuracy with fewer parameters compared to ReLU, Tanh, and SeLU activations."
  - [section] "It is shown that solving the MNIST problem with the LeNet-like architectures based on Absolute activation allows to significantly reduce the number of trained parameters in the neural network with improving the prediction accuracy."

### Mechanism 3
- Claim: The Absolute activation function's non-monotonic nature provides advantages over traditional monotonic activation functions for certain classification tasks.
- Mechanism: Unlike monotonic functions like ReLU or Tanh, the absolute value function can create more complex decision boundaries by reflecting negative values, potentially capturing patterns that monotonic functions miss.
- Core assumption: The non-monotonic property does not harm the universal approximation capability of neural networks when combined with appropriate output layers.
- Evidence anchors:
  - [section] "Absolute activation function Abs differs significantly from them - it is nonmonotone, but continuous, like SWISH, MISH and APTx functions."
  - [section] "The Absolute activation function already mentioned by researchers [Karnewar(2018), Apicella et al.(2021)], but its efficiency has not been demonstrated in details."

## Limitations
- The paper's claims are based primarily on experiments with the MNIST dataset and LeNet-like architectures, limiting generalizability to other problems and network architectures.
- The modified ADAM algorithm's implementation details are underspecified, particularly regarding how accuracy bounds are estimated and used for learning rate adjustment.
- The paper lacks ablation studies to isolate the effects of the Absolute activation function from the modified training procedure.

## Confidence
- **High Confidence**: The theoretical justification that |y| has derivative modulus of 1 almost everywhere, which should prevent vanishing/exploding gradients
- **Medium Confidence**: The claim of achieving 99.44% accuracy on MNIST with 7x fewer parameters, given this is based on a single architecture and dataset
- **Low Confidence**: The assertion that Absolute activation is broadly superior to established activations like ReLU and SeLU across diverse problems
