# Translate to Disambiguate: Zero-shot Multilingual Word Sense Disambiguation with Pretrained Language Models

## Quick Facts
- arXiv ID: 2304.13803
- Source URL: https://arxiv.org/abs/2304.13803
- Reference count: 12
- Primary result: Zero-shot WSD via C-WLT outperforms fully supervised baselines on recall for many languages

## Executive Summary
This paper proposes a zero-shot approach to multilingual word sense disambiguation (WSD) using contextual word-level translation (C-WLT) with pretrained language models (PLMs). The method prompts PLMs to translate words in context, then uses the intersection of sense inventories between source and target words to identify the correct sense. The approach requires no additional training or fine-tuning, and achieves strong performance across 18 languages by leveraging the cross-lingual word sense knowledge that PLMs acquire during pretraining.

## Method Summary
The method involves prompting a PLM to perform contextual word-level translation by providing the full sentence context along with the target word to be translated. The PLM generates translations with likelihoods, which are then mapped to sense sets using multilingual sense ontologies (BabelNet). The final WSD prediction is the intersection of sense sets from the source word and its translations. The approach is evaluated zero-shot, without any fine-tuning on WSD data, and performance is measured using recall and Jaccard similarity metrics.

## Key Results
- Larger PLMs encode more cross-lingual word sense knowledge, improving C-WLT and WSD performance
- WSD via C-WLT outperforms fully supervised baselines on recall for many evaluation languages
- Ensembling diverse target languages narrows down predicted sense sets, improving Jaccard similarity

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Larger PLMs encode more cross-lingual word sense knowledge, enabling better contextual word-level translation (C-WLT) performance.
- Mechanism: As model size increases, PLMs develop richer representations of lexical semantics and context-dependent meaning, allowing them to disambiguate word senses across languages more effectively when prompted with context.
- Core assumption: Cross-lingual word sense knowledge emerges from pretraining on diverse text corpora, and this knowledge scales with model capacity.
- Evidence anchors:
  - [abstract]: "as the model size increases, PLMs encode more cross-lingual word sense knowledge and better use context to improve WLT performance"
  - [section 2.2]: "the performance of both uncontextualized and contextualized word-level translation improves as the model size increases"
  - [corpus]: Weak - no direct citation showing scaling of cross-lingual knowledge with model size, but inference supported by general findings about scaling in PLMs
- Break condition: If pretraining data lacks sufficient cross-lingual coverage, larger models may not improve cross-lingual word sense knowledge despite increased capacity.

### Mechanism 2
- Claim: Contextual information in prompts enables PLMs to produce sense-specific translations rather than ambiguous ones.
- Mechanism: By providing the full sentence context, the model can condition its translation on the intended meaning of the word, selecting the appropriate translation variant that matches the specific sense used in context.
- Core assumption: PLMs can leverage contextual information to disambiguate word senses during translation, not just in monolingual settings.
- Evidence anchors:
  - [abstract]: "Building on C-WLT, we introduce a zero-shot approach for WSD... outperforms fully supervised baselines on recall"
  - [section 2.2]: "the addition of context... improves word-level translation performance across all settings"
  - [corpus]: Moderate - supports contextual translation but doesn't directly prove sense disambiguation mechanism
- Break condition: If context is insufficient or ambiguous itself, the model may still produce incorrect sense-specific translations.

### Mechanism 3
- Claim: Ensembling translations from multiple diverse target languages narrows down the predicted sense set through intersection of sense inventories.
- Mechanism: When the same word is translated into multiple typologically diverse languages, the intersection of sense sets from these translations is more likely to contain the correct sense, as shared senses across languages are more likely to be contextually relevant.
- Core assumption: Related senses of a word will have similar translations across different languages, and intersection operations can filter out incorrect senses.
- Evidence anchors:
  - [abstract]: "ensembling diverse target languages... narrows down the predicted set of senses, as demonstrated by the improvements in Jaccard similarity"
  - [section 3.1]: "ensembling the senses from a set of target languages... more likely to be relevant to the specific context"
  - [corpus]: Weak - corpus mentions ensembling but doesn't provide strong empirical evidence for the intersection mechanism
- Break condition: If target languages are too similar or if translations don't capture distinct sense boundaries, the intersection may not effectively filter incorrect senses.

## Architecture Onboarding

- Component map:
  - PLM (autoregressive, multilingual or English) -> Prompt template -> Multilingual sense ontology (BabelNet) -> Intersection logic -> Target language ensemble

- Critical path:
  1. Input context and target word → PLM with C-WLT prompt
  2. PLM generates top translation(s) with likelihoods
  3. Retrieve sense sets for source word and top translation(s)
  4. Compute intersection of sense sets
  5. Output intersected sense set as prediction

- Design tradeoffs:
  - Model size vs. generalization: Larger models perform better but may overfit to pretraining languages
  - Target language diversity vs. coverage: More diverse languages improve filtering but may reduce coverage
  - Single vs. ensemble prediction: Ensembling improves recall but may reduce precision (Jaccard similarity)
  - English vs. multilingual models: English models generalize better despite less direct multilingual training

- Failure signatures:
  - Low recall: Translation coverage gaps, sense inventory incompleteness, or insufficient model capacity
  - Low Jaccard similarity: Over-prediction of senses, target languages too similar, or poor intersection filtering
  - Wrong language predictions: Prompt language mismatch, multilingual model confusion, or prompt format issues
  - Performance gap between MCS and LCS: Unbalanced pretraining data, Zipfian distribution of senses, or model bias toward common senses

- First 3 experiments:
  1. Test C-WLT with varying context lengths to find optimal context for disambiguation
  2. Compare single target language settings (English, Chinese, Spanish) to identify best-performing target for different source languages
  3. Evaluate the effect of prompt language (English vs. source vs. target) on translation quality and sense prediction accuracy

## Limitations

- Prompt engineering sensitivity may affect generalization across all 18 languages studied, as only templates for a subset are provided
- Sense inventory coverage issues in BabelNet for many languages necessitate back-off strategies that impact performance
- Language similarity effects on the intersection mechanism are not systematically analyzed, potentially affecting filtering effectiveness

## Confidence

- **High Confidence**: The core finding that larger PLMs perform better at cross-lingual WSD is well-supported by systematic experiments across model sizes
- **Medium Confidence**: The claim that C-WLT outperforms fully supervised baselines on recall is supported by results, but comparison methodology lacks full specification
- **Medium Confidence**: The ensembling approach showing improved Jaccard similarity is demonstrated empirically, but the mechanism explanation could benefit from deeper linguistic analysis

## Next Checks

3. Implement and evaluate alternative back-off strategies beyond MCS to quantify the performance cost of incomplete sense inventory coverage and identify optimal handling methods
