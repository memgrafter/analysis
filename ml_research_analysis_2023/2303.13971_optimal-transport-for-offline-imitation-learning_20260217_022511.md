# Optimal Transport for Offline Imitation Learning

## Quick Facts
- arXiv ID: 2303.13971
- Source URL: https://arxiv.org/abs/2303.13971
- Reference count: 9
- Key outcome: OTR with a single demonstration matches performance of offline RL with ground-truth rewards across D4RL benchmarks

## Executive Summary
Optimal Transport Reward labeling (OTR) addresses offline imitation learning by automatically assigning rewards to unlabeled trajectories using optimal transport alignment with expert demonstrations. The method computes optimal coupling between trajectories to derive similarity-based reward signals that can be used by any offline RL algorithm. OTR demonstrates state-of-the-art performance on D4RL benchmarks while maintaining computational efficiency, requiring only about 1 minute to label a 1 million transition dataset.

## Method Summary
OTR computes rewards for offline trajectories by aligning them with expert demonstrations using entropy-regularized optimal transport. The optimal coupling matrix represents a soft alignment between states in unlabeled trajectories and expert states, with rewards derived from the negative weighted sum of state similarities. This reward-annotated dataset can then be used by any offline RL algorithm, making OTR agnostic to the specific RL method chosen. The approach leverages Sinkhorn's algorithm for efficient computation of the optimal coupling matrix.

## Key Results
- OTR with a single demonstration matches performance of offline RL with ground-truth rewards across locomotion, antmaze, and adroit tasks
- OTR consistently outperforms previous offline imitation learning methods
- Computational efficiency: labels 1 million transitions in about 1 minute
- Approach is agnostic to specific offline RL algorithm used

## Why This Works (Mechanism)

### Mechanism 1
Optimal transport provides a principled way to compute similarity between unlabeled trajectories and expert demonstrations without requiring reward annotations. The coupling matrix µ∗ represents a soft alignment between states, with rewards derived from the negative weighted sum of costs between states weighted by coupling probabilities. This captures meaningful state similarity that can be interpreted as a reward signal.

### Mechanism 2
By computing rewards offline before RL training, OTR enables seamless integration with any offline RL algorithm. This separation of reward learning from policy learning avoids the need to modify the RL algorithm itself, allowing any standard offline RL method to be used with the pre-computed reward signals.

### Mechanism 3
The entropy-regularized optimal transport formulation enables efficient computation of the optimal coupling matrix. Using Sinkhorn's algorithm to solve the entropy-regularized problem makes the approach practical for large datasets by ensuring the solution is sparse and computationally tractable.

## Architecture Onboarding

- **Component map**: Data Preprocessing -> Optimal Transport Engine -> Reward Computation -> RL Integration -> Evaluation
- **Critical path**: Load expert demonstrations and unlabeled dataset → Compute optimal coupling for each unlabeled trajectory → Compute rewards from optimal coupling → Train offline RL algorithm on reward-annotated dataset → Evaluate learned policy
- **Design tradeoffs**: Computational efficiency vs. optimality (entropy-regularized OT enables faster computation but may sacrifice some optimality); Reward quality vs. computation time (more expert demonstrations improve quality but increase computation); State space choice (states vs. state-action pairs affects performance and requirements)
- **Failure signatures**: Poorly calibrated rewards lead to failed policy learning; excessive computation time makes approach impractical; RL algorithm sensitivity to distribution shift causes failure
- **First 3 experiments**: 1) Run OTR on hopper-medium-v2 with single expert demonstration to verify correct reward computation; 2) Compare OTR rewards against ground-truth rewards to assess correlation; 3) Run IQL on OTR reward-annotated data and compare against IQL with ground-truth rewards

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does OTR perform with sparse or incomplete expert demonstrations compared to dense demonstrations?
- Basis in paper: The paper states OTR is most useful when providing ground-truth rewards is difficult but providing good demonstrations is feasible
- Why unresolved: Only evaluates OTR with full expert demonstrations, not exploring performance with sparse or incomplete demonstrations
- What evidence would resolve it: Experiments showing OTR performance with varying levels of demonstration completeness and density

### Open Question 2
- Question: Can OTR be extended to work with continuous action spaces in a computationally efficient manner?
- Basis in paper: Uses state-only demonstrations and mentions PWIL sometimes performs badly without expert actions
- Why unresolved: Focuses on state-only demonstrations without exploring computational challenges of incorporating actions
- What evidence would resolve it: Implementation and benchmarking of OTR with continuous action spaces showing computational complexity and performance

### Open Question 3
- Question: What is the impact of different optimal transport cost functions on OTR performance?
- Basis in paper: Uses cosine distance as cost function but mentions alternative cost functions in related work
- Why unresolved: Only uses one cost function without exploring sensitivity to different cost function choices
- What evidence would resolve it: Systematic comparison of OTR performance using different cost functions (Euclidean, Mahalanobis) on benchmark tasks

## Limitations

- Performance depends critically on the quality and representativeness of expert demonstrations
- Computational efficiency comes at the cost of approximate solutions from entropy-regularized optimal transport
- Assumes state similarity (cosine distance) is sufficient for reward computation, potentially missing temporal or action-based information

## Confidence

- **High Confidence**: Computational efficiency claims (1 minute for 1M transitions) and agnosticism to specific offline RL algorithms are well-supported
- **Medium Confidence**: Matching ground-truth reward performance across all D4RL tasks is supported but generalization to unseen tasks remains uncertain
- **Medium Confidence**: Outperforming previous methods is based on specific comparison datasets and may not hold universally

## Next Checks
