# Quantile Extreme Gradient Boosting for Uncertainty Quantification

## Quick Facts
- arXiv ID: 2304.11732
- Source URL: https://arxiv.org/abs/2304.11732
- Reference count: 40
- One-line primary result: QXGBoost provides uncertainty quantification for XGBoost using differentiable quantile regression with Huber norm smoothing.

## Executive Summary
This paper introduces QXGBoost, a method for uncertainty quantification in XGBoost models using quantile regression with Huber norm smoothing. The authors address the challenge of estimating prediction intervals for XGBoost, which is widely used but lacks built-in uncertainty quantification. They propose using a modified quantile regression objective function that incorporates the Huber norm to ensure differentiability, enabling gradient-based optimization in XGBoost. The method is evaluated on both simulated and real-world traffic noise data, comparing it with quantile gradient boosting and quantile LightGBM. Results show that QXGBoost produces competitive or better prediction intervals, with improved coverage width-based criterion (CWC) scores. The method is praised for its simplicity and ease of implementation, making it accessible for applications requiring uncertainty analysis in XGBoost models.

## Method Summary
QXGBoost combines quantile regression with XGBoost using Huber norm smoothing to create differentiable objective functions. The method trains two separate models for lower and upper quantiles (e.g., 5% and 95%) to generate prediction intervals. The Huber norm function smooths the quantile loss to make it differentiable, enabling its use in XGBoost's gradient-based optimization. Models are trained on 75% of data and tested on 25%, with evaluation using coverage width-based criterion (CWC), prediction interval coverage probability (PICP), and normalized prediction interval average width (PINAW) metrics.

## Key Results
- QXGBoost produces competitive or better prediction intervals compared to quantile GBM and quantile LightGBM
- Improved coverage width-based criterion (CWC) scores demonstrate better balance between interval width and coverage probability
- Method successfully applied to both simulated data (y = 1.5×x×sin(x) + ε) and real-world traffic noise data (6,647 observations with 44 predictors)
- Simple modification makes uncertainty quantification accessible in XGBoost without requiring deep statistical expertise

## Why This Works (Mechanism)

### Mechanism 1
QXGBoost enables uncertainty quantification in XGBoost by replacing the non-differentiable quantile regression loss with a Huber norm-based approximation. The Huber norm function is smooth at zero and differentiable everywhere, which allows XGBoost's gradient-based optimization to work. The approximation converges to the true quantile regression loss as the Huber threshold approaches zero. Core assumption: The Huber approximation is close enough to the true quantile loss for practical use, and the smoothness does not significantly degrade model performance.

### Mechanism 2
QXGBoost generates prediction intervals by training two separate models for the lower and upper quantiles (e.g., 5% and 95%). Each model optimizes a quantile loss (smoothed by Huber) to predict a specific quantile of the conditional distribution. The difference between the upper and lower quantile predictions forms the prediction interval. Core assumption: The conditional distribution of the target is sufficiently smooth that two quantiles can approximate the full uncertainty.

### Mechanism 3
QXGBoost performance is evaluated using coverage width-based criterion (CWC), which balances interval width and coverage probability. CWC penalizes both narrow intervals with poor coverage and wide intervals with good coverage, favoring models that achieve high coverage with minimal width. Core assumption: CWC is a meaningful and stable metric for comparing uncertainty quantification methods.

## Architecture Onboarding

- Component map: Input features → Quantile XGBoost model → Prediction quantiles (lower/upper bounds) → Prediction interval
- Critical path:
  1. Data preprocessing and splitting
  2. Hyperparameter tuning for both XGBoost and Huber threshold
  3. Training two quantile models (τ=0.05 and τ=0.95)
  4. Evaluating prediction intervals using PICP, PINAW, and CWC
- Design tradeoffs:
  - Smaller Huber threshold → better approximation to true quantile loss but potentially harder optimization
  - Larger number of trees → better coverage but risk of overfitting
  - Two models for PIs → doubled training time but necessary for uncertainty quantification
- Failure signatures:
  - Poor coverage (PICP << 90%) → Huber threshold too large or insufficient model capacity
  - Very wide intervals → Huber threshold too small or excessive regularization
  - Overfitting → too many trees or too deep trees without early stopping
- First 3 experiments:
  1. Validate that the Huber-smoothed loss approximates the true quantile loss by plotting both for various thresholds.
  2. Compare PICP and PINAW for different Huber thresholds on a simple simulated dataset.
  3. Benchmark QXGBoost against quantile GBM and quantile LightGBM on the traffic noise dataset using CWC.

## Open Questions the Paper Calls Out

### Open Question 1
How does the choice of the Huber threshold (υ) parameter affect the trade-off between PICP and PINAW in QXGBoost, and what is the optimal range for this parameter across different datasets? The paper discusses that the Huber threshold parameter controls both PICP and PINAW, with small thresholds leading to large PICP and PINAW, and large thresholds producing small PICP and PINAW. This is unresolved because the paper does not provide a definitive optimal range for the Huber threshold parameter, suggesting that it needs to be tuned for each specific dataset.

## Limitations

- Performance depends critically on the Huber threshold parameter, which requires careful tuning for each dataset
- Only compared against other tree-based quantile methods, not statistical approaches like quantile regression forests or conformal prediction
- Computational overhead of training two separate models and tuning additional hyperparameter not discussed

## Confidence

- **High confidence**: The core mechanism of using Huber norm smoothing to enable differentiable quantile regression in XGBoost is theoretically sound and well-explained
- **Medium confidence**: The empirical results showing improved CWC scores are promising but based on only two datasets
- **Medium confidence**: The claim that QXGBoost is "easy to implement and use" is reasonable given the simplicity of the modification
