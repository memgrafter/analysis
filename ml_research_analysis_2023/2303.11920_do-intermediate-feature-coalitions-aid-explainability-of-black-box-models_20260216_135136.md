# Do intermediate feature coalitions aid explainability of black-box models?

## Quick Facts
- arXiv ID: 2303.11920
- Source URL: https://arxiv.org/abs/2303.11920
- Reference count: 25
- Primary result: Intermediate concepts based on levels structures improve explainability for black-box models by providing explanations at different abstraction levels

## Executive Summary
This paper introduces intermediate concepts based on levels structures to improve explainability for black-box models. The approach uses hierarchical feature coalitions to provide explanations at different abstraction levels, from individual features to grand coalitions. Experiments on Titanic and Cars datasets demonstrate that contextual importance and utility values provide meaningful explanations, while contextual influence values have limitations when dealing with dependent features. The method offers a theoretical framework linking coalition games, levels structures, and intermediate concepts for more flexible and expressive explanations.

## Method Summary
The approach builds on cooperative game theory, specifically games with levels structures, to create a hierarchical representation of feature coalitions. Domain experts define meaningful feature coalitions (intermediate concepts) based on domain knowledge. These coalitions are organized into a levels structure, a hierarchical representation where each level corresponds to feature coalitions with increasing coarseness from singletons to the grand coalition. The Contextual Importance and Utility (CIU) method is then applied to calculate importance and utility values for both individual features and coalitions, generating explanations at different abstraction levels.

## Key Results
- Contextual importance and utility values provide meaningful explanations at different levels of abstraction
- Intermediate concepts aid explainability by capturing joint importance of related features
- Contextual influence values have limitations when dealing with dependent features

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hierarchical levels structure improves explainability by aggregating features into meaningful coalitions.
- Mechanism: By defining coalitions of features (like WEALTH = {fare, class} or FAMILY = {sibsp, parch}), the model can provide explanations at different levels of abstraction rather than just individual features. This captures the joint importance of related features.
- Core assumption: The feature coalitions are meaningfully defined by domain experts and capture relevant real-world relationships.
- Evidence anchors:
  - [abstract] "The levels structure is a hierarchical representation where each level corresponds to feature coalitions, with increasing coarseness from singletons to the grand coalition."
  - [section] "CIU's origins are in Decision Theory... The intermediate concepts presented in [6] correspond to coalitions of features with a level structure."
  - [corpus] Weak - no corpus papers directly address this hierarchical feature coalition approach.
- Break condition: If feature coalitions are poorly defined or don't capture meaningful relationships, the explanations become misleading.

### Mechanism 2
- Claim: Contextual Importance and Utility (CIU) provides more nuanced explanations than individual feature attribution.
- Mechanism: CIU measures both the range of variation (importance) and how favorable current values are (utility) for both individual features and coalitions. This allows for explanations that show not just what features matter, but how their current values contribute to the outcome.
- Core assumption: The model outputs can be meaningfully mapped to utility values in the range [0,1].
- Evidence anchors:
  - [abstract] "contextual importance and utility values provide meaningful explanations"
  - [section] "Contextual Utility (CU) expresses to what extent the current values of features in {i} contribute to obtaining a high output utility"
  - [corpus] Weak - no corpus papers directly compare CIU to other explainability methods.
- Break condition: If the model outputs cannot be meaningfully mapped to utility values, or if the utility interpretation doesn't align with human understanding.

### Mechanism 3
- Claim: Levels structure provides a theoretical framework linking coalition games, levels structures, and intermediate concepts.
- Mechanism: By building on cooperative game theory (specifically games with levels structures), the approach provides a mathematical foundation for aggregating features and generating explanations. The framework allows for part-whole relationships and hierarchical explanations.
- Core assumption: The cooperative game theory framework can be meaningfully applied to feature coalitions in machine learning.
- Evidence anchors:
  - [abstract] "The proposed approach offers a well-founded link between coalition games, levels structures, and intermediate concepts"
  - [section] "A triple (N,v,B), where (N,v) ∈ GN and B is a level structure on N, represents a cooperative scenario with level structure"
  - [corpus] Weak - no corpus papers directly reference this game theory connection.
- Break condition: If the game theory assumptions (like superadditivity) don't hold for the feature coalitions, the mathematical framework breaks down.

## Architecture Onboarding

- Component map: Feature coalitions (domain expert input) -> Levels structure builder -> CIU calculator -> Explanation generator
- Critical path:
  1. Define feature coalitions based on domain knowledge
  2. Build levels structure from coalitions
  3. Calculate CIU values for instance to explain
  4. Generate explanations at different abstraction levels
- Design tradeoffs:
  - More detailed coalitions provide more nuanced explanations but increase complexity
  - Higher levels of abstraction simplify explanations but may lose important details
  - Domain expert involvement ensures meaningful coalitions but requires subject matter expertise
- Failure signatures:
  - If CIU values don't align with intuitive feature importance, the coalition definitions may be incorrect
  - If explanations at higher levels contradict those at lower levels, the levels structure may be improperly defined
  - If computational cost becomes prohibitive, the coalition definitions may be too complex
- First 3 experiments:
  1. Apply the approach to a simple dataset with clearly related features (like Titanic) to verify basic functionality
  2. Test with a dataset where features have complex interactions to evaluate the handling of non-linear relationships
  3. Compare explanations generated at different levels of abstraction to ensure consistency and meaningfulness

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can contextual influence values be effectively used with intermediate concepts when dealing with dependent features?
- Basis in paper: [explicit] The paper discusses limitations of contextual influence values when dealing with dependent features and mentions this as an ongoing topic for future research.
- Why unresolved: The paper acknowledges that contextual influence values can be misleading when features have opposite signs and suggests this as a challenge for future research.
- What evidence would resolve it: A concrete methodology for calculating contextual influence values for coalitions that accounts for feature dependencies, along with experimental validation on datasets with known feature dependencies.

### Open Question 2
- Question: How can Shapley values be adapted to work effectively with intermediate concepts and levels structures in post-hoc explainability?
- Basis in paper: [explicit] The paper mentions that Shapley values have limitations with average values and dependent features, but also notes that using coalition structures for Shapley values has been proposed in PartitionExplainer and groupShapley approaches.
- Why unresolved: While the paper acknowledges the potential of using Shapley values with coalitions, it doesn't provide a concrete solution or experimental validation of this approach with intermediate concepts.
- What evidence would resolve it: A detailed framework for applying Shapley values to intermediate concepts within levels structures, along with comparative experiments against other explainability methods.

### Open Question 3
- Question: What are the optimal criteria for defining intermediate concepts and levels structures in different domains?
- Basis in paper: [explicit] The paper mentions that there is no hard and fast rule for collating features into intermediate concepts and that the end-user can be interested in explanations produced by different coalitions for the same predictive outcome.
- Why unresolved: The paper demonstrates the use of intermediate concepts in two specific examples but doesn't provide a general methodology for determining the optimal intermediate concepts and levels structures in different domains.
- What evidence would resolve it: A set of guidelines or algorithms for automatically determining intermediate concepts based on domain characteristics, validated across multiple diverse datasets.

## Limitations
- The approach relies heavily on domain expert input to define meaningful feature coalitions, which may not always be available or reliable
- Effectiveness depends critically on the quality of coalitions and their hierarchical organization
- Results shown on only two datasets, lacking extensive validation across diverse domains and model types

## Confidence

- **High confidence**: The theoretical framework linking coalition games, levels structures, and intermediate concepts is well-established
- **Medium confidence**: The effectiveness of CIU in providing meaningful explanations is demonstrated but needs broader validation
- **Low confidence**: The limitations of contextual influence values with dependent features are identified but not thoroughly explored
