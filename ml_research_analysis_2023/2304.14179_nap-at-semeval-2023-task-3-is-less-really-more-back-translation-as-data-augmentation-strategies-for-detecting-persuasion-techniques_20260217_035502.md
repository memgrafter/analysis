# NAP at SemEval-2023 Task 3: Is Less Really More? (Back-)Translation as Data Augmentation Strategies for Detecting Persuasion Techniques

## Quick Facts
- arXiv ID: 2304.14179
- Source URL: https://arxiv.org/abs/2304.14179
- Reference count: 37
- Key outcome: Both back-translation and span injection improve multi-label persuasion technique detection, with ensemble models achieving top leaderboard performance.

## Executive Summary
This paper investigates whether (back-)translation as data augmentation improves multi-lingual persuasion technique detection in news articles. The authors augment training data with translations and back-translations across 9 languages, conduct automatic and human evaluations, and ensemble multiple model architectures. Their in-depth analyses indicate that both data augmentation strategies boost performance, but balancing human-produced and machine-generated data is crucial. The study provides empirical evidence for effective multi-lingual data augmentation in detecting persuasion techniques.

## Method Summary
The authors augment gold training data through translation and back-translation using MarianMT, then fine-tune XLM-RoBERTa-base/large, adapter modules, and SetFit models on these datasets. They ensemble predictions via threshold-tuned voting and evaluate using F1-micro and F1-macro scores. Automatic BLEU evaluation and human judgments assess translation quality and label preservation.

## Key Results
- Back-translation (+BT-sl) consistently improved F1 scores across all persuasion technique labels
- Ensemble models outperformed individual architectures on the leaderboard
- Balancing human-produced and machine-generated data proved crucial for optimal performance

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Back-translation preserves more persuasion technique signals than direct translation.
- **Mechanism:** Back-translation acts as a paraphrase that maintains semantic coherence and persuasion technique labels while introducing controlled linguistic variation.
- **Core assumption:** The translation system can preserve subtle rhetorical devices better when translating to a pivot language and back, compared to direct translation which may distort meaning.
- **Evidence anchors:**
  - [abstract] "Our in-depth analyses indicate that both data augmentation strategies boost performance; however, balancing human-produced and machine-generated data seems to be crucial."
  - [section] "Results clearly point to back-translation (+BT-sl) as the most robust augmentation strategy with consistent improvement of F1 scores across all labels."
  - [corpus] Weak: corpus provides no direct evidence about translation vs. back-translation differences; only automatic BLEU scores which are not persuasive-technique specific.
- **Break condition:** If pivot language introduces cultural or linguistic mismatches that alter persuasion technique semantics, back-translation could degrade rather than preserve signals.

### Mechanism 2
- **Claim:** Adding textual spans containing persuasion techniques improves model focus and performance.
- **Mechanism:** By explicitly including the labeled spans in training data, the model learns to associate specific textual patterns with persuasion techniques, improving recall for underrepresented labels.
- **Core assumption:** Persuasion techniques have identifiable lexical or syntactic markers that can be isolated without losing context.
- **Evidence anchors:**
  - [abstract] "Our in-depth analyses however show that less tends to be really more w.r.t balancing natural vs. augmented data..."
  - [section] "Results clearly point to back-translation (+BT-sl) as the most robust augmentation strategy with consistent improvement of F1 scores across all labels."
  - [corpus] Weak: no corpus evidence directly linking span injection to performance gains; only indirect via regression analysis.
- **Break condition:** If persuasion techniques rely heavily on broader context beyond the span, isolating spans may mislead the model.

### Mechanism 3
- **Claim:** Ensemble models combining diverse architectures and training data types yield better performance than single models.
- **Mechanism:** Different architectures (XLM-RoBERTa, adapters, SetFit) and training data (gold, back-translation, spans) capture complementary aspects of persuasion techniques, and voting aggregates these signals.
- **Core assumption:** Each model type has distinct strengths (e.g., adapters for low-frequency classes, SetFit for few-shot efficiency) that collectively improve robustness.
- **Evidence anchors:**
  - [abstract] "Our system successfully leverages (back-)translation as data augmentation strategies with multi-lingual transformer models..."
  - [section] "We then compute the F1-scores on the validation set using an ensemble. For each instance in the validation set, all models that are part of the ensemble can vote..."
  - [corpus] Weak: no explicit corpus comparison of ensemble vs. single-model performance; only leaderboard rankings.
- **Break condition:** If models are too correlated (e.g., same architecture, similar data), ensemble voting may not provide meaningful gains.

## Architecture Onboarding

- **Component map:** Gold data → (back-)translation → augmented corpora → XLM-RoBERTa/adapters/SetFit models → threshold tuning → ensemble voting → evaluation

- **Critical path:**
  1. Load gold data and relevant spans
  2. Generate (back-)translations across language pairs
  3. Train individual models on varied training sets
  4. Tune thresholds per model on validation set
  5. Combine predictions via ensemble voting
  6. Evaluate on test set

- **Design tradeoffs:**
  - More augmentation → larger training set but risk of noise or label drift
  - Adapter modules → parameter efficiency vs. potential loss of fine-tuning flexibility
  - Ensemble voting → robustness vs. increased inference complexity

- **Failure signatures:**
  - BLEU scores drop sharply for certain language pairs → possible translation quality issues
  - Human judgments show low fidelity for back-translations → semantic distortion
  - Ensemble performance worse than best single model → model correlation or voting threshold misconfiguration

- **First 3 experiments:**
  1. Train XLM-RoBERTa-base on gold data only; measure baseline F1-macro per persuasion technique.
  2. Add back-translated data (+BT-sl) and retrain; compare F1 changes per label to isolate augmentation effect.
  3. Train adapter modules on +BT-sl data; evaluate if low-frequency label recall improves versus base model.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different language pairs impact the transfer and preservation of specific persuasion techniques during (back-)translation?
- Basis in paper: [explicit] The paper states that some persuasion techniques might be language- and culture-dependent, as their transfer and preservation vary depending on the language pair in consideration. However, the study does not provide a detailed analysis of which specific language pairs are most effective for transferring or preserving each persuasion technique.
- Why unresolved: The human evaluation study was small-scale and did not systematically analyze the impact of different language pairs on the transfer and preservation of persuasion techniques. The paper only provides a general observation that some techniques are language- and culture-dependent without identifying specific patterns.
- What evidence would resolve it: A large-scale human evaluation study that systematically analyzes the transfer and preservation of each persuasion technique across different language pairs would provide evidence to resolve this question. The study should include a diverse set of language pairs and persuasion techniques to identify specific patterns and trends.

### Open Question 2
- Question: What are the underlying reasons for the observed difference in performance between injecting translations and back-translations for the task of detecting persuasion techniques?
- Basis in paper: [explicit] The paper mentions that the considerable difference in performance between injecting translations and back-translations is surprising and not on par with the human evaluation findings. The authors plan to conduct further analyses to investigate this phenomenon.
- Why unresolved: The paper does not provide an explanation for the observed difference in performance between translations and back-translations. The authors acknowledge the need for further investigation but do not propose any hypotheses or potential explanations.
- What evidence would resolve it: A detailed analysis of the generated translations and back-translations, including a comparison of their linguistic features and the preservation of persuasion techniques, would provide evidence to resolve this question. Additionally, conducting a controlled experiment that isolates the impact of translations and back-translations on the detection of persuasion techniques would help identify the underlying reasons for the observed difference in performance.

### Open Question 3
- Question: How does the choice of data augmentation strategy impact the detection of persuasion techniques for different language families?

The results varied between languages, indicating that the choice of data augmentation strategy may have different effects on language families.
- Why unresolved: The paper does not provide a detailed analysis of how the choice of data augmentation strategy impacts the detection of persuasion techniques for different language families. The authors only mention that the results varied between languages without identifying specific patterns or trends.
- What evidence would resolve it: A comprehensive study that systematically analyzes the impact of different data augmentation strategies on the detection of persuasion techniques for various language families would provide evidence to resolve this question. The study should include a diverse set of language families and data augmentation strategies to identify specific patterns and trends.

## Limitations
- Translation quality for persuasion techniques may vary across language pairs without systematic evaluation
- Human evaluation was small-scale and didn't systematically compare back-translation vs direct translation quality
- Ensemble voting mechanism lacks analysis of optimal thresholds and model correlation

## Confidence

- **High Confidence**: The general finding that data augmentation improves multi-label persuasion technique detection performance. This is supported by consistent F1 score improvements across multiple models and languages.
- **Medium Confidence**: The specific claim that back-translation is superior to direct translation for preserving persuasion signals. While supported by automatic metrics, lacks direct human evaluation evidence for persuasion-specific quality.
- **Medium Confidence**: The ensemble voting mechanism's effectiveness. While leaderboard results support this, the study doesn't isolate ensemble contributions from individual model improvements.

## Next Checks
1. **Direct Persuasion Technique Preservation Test**: Conduct a controlled human evaluation comparing back-translation vs. direct translation on a subset of persuasion technique-containing sentences, explicitly rating how well each method preserves rhetorical devices and persuasion labels.

2. **Model Correlation Analysis**: Calculate inter-model correlations on validation sets to determine whether ensemble gains come from complementary predictions or correlated errors, and adjust voting thresholds accordingly.

3. **Augmentation Ratio Sensitivity**: Systematically vary the ratio of gold to augmented data (e.g., 100% gold, 75/25, 50/50, 25/75, 100% augmented) to empirically determine the optimal balance that maximizes F1-macro while minimizing noise.
