# POTTER: Pooling Attention Transformer for Efficient Human Mesh Recovery

## Quick Facts
- arXiv ID: 2303.13357
- Source URL: https://arxiv.org/abs/2303.13357
- Reference count: 40
- This paper addresses human mesh recovery using transformer architectures with significantly reduced computational overhead.

## Executive Summary
This paper addresses the challenge of human mesh recovery (HMR) from monocular images using transformer architectures. While transformer-based methods have achieved state-of-the-art performance, they suffer from substantial memory and computational overhead. To address this, the authors propose a pure transformer architecture called POoling aTtention TransformER (POTTER) for efficient HMR. POTTER introduces a novel Pooling Attention Transformer (PAT) block that significantly reduces memory and computational costs by replacing conventional attention modules with pooling attention. Additionally, the authors design a new transformer architecture by integrating a High-Resolution (HR) stream to maintain high-resolution local and global features for more accurate human mesh recovery. The proposed POTTER outperforms the state-of-the-art method METRO with only 7% of total parameters and 14% of Multiply-Accumulate Operations (MACs) on the Human3.6M and 3DPW datasets.

## Method Summary
POTTER is a pure transformer architecture for human mesh recovery that introduces Pooling Attention Transformer (PAT) blocks. The key innovation is replacing conventional attention modules with pooling attention (PoolAttn) that reduces computational complexity from O(D²) to O(D) by applying 2D average pooling to squeeze features along spatial or embedding axes. The architecture includes a hierarchical 4-stage basic stream for low-resolution global features and a parallel High-Resolution (HR) stream that maintains high-resolution local and global features through patch splitting operations. The model outputs SMPL pose and shape parameters, joint positions, and mesh vertices using a HybrIK head. Training involves pre-training on ImageNet-1k for 300 epochs, followed by HMR training with AdamW optimizer and losses on pose parameters, shape parameters, and joint positions.

## Key Results
- POTTER achieves 59.8 MPJPE on Human3.6M and 88.8 MPJPE on 3DPW, outperforming METRO
- POTTER uses only 7% of total parameters and 14% of MACs compared to METRO
- POTTER cls achieves 84.3% top-1 accuracy on ImageNet-1k with 21.5M parameters and 2.6G MACs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: PoolAttn reduces computational complexity from O(D²) to O(D) by replacing full attention with patch-wise and embed-wise pooling.
- Mechanism: Instead of computing full attention over all patches and all embedding dimensions, PoolAttn applies 2D average pooling to squeeze features along spatial or embedding axes, then uses matrix multiplication on the reduced representations.
- Core assumption: The spatial structure of patches and embedding dimensions can be preserved and still capture sufficient correlation for accurate mesh recovery.
- Evidence anchors:
  - [abstract] "significantly reduces the memory and computational cost without sacrificing performance"
  - [section] "Compared with the conventional attention module which requires (4D² + 4D) params and (4DN² + 2D²N) MACs, our PoolAttn significantly reduce the complexity from O(D²) to O(D)"
  - [corpus] Weak signal: no direct citations to PoolAttn design in neighbor papers.
- Break condition: If spatial/embedding structure preservation is insufficient for modeling complex human articulation dependencies.

### Mechanism 2
- Claim: HR stream maintains high-resolution features by avoiding patch merging, preserving local detail needed for accurate mesh reconstruction.
- Mechanism: HR stream applies patch splitting to reverse merging, allowing low-resolution global features from basic stream to fuse with high-resolution local features at each stage.
- Core assumption: High-resolution features are critical for capturing fine-grained local details in human body parts, which are lost when patches are merged.
- Evidence anchors:
  - [abstract] "The high-resolution local and global features from the HR stream can be utilized for recovering more accurate human mesh"
  - [section] "the output of 'stage 1' Xout1 is also used by the HR streams...we do not need a patch merging layer to merge the patches, which downgrades the high-resolution representation to the low-resolution representation"
  - [corpus] Weak signal: neighbor papers do not explicitly discuss HR stream design.
- Break condition: If high-resolution local details are not critical for the HMR task, or if the computational cost of maintaining high resolution outweighs the accuracy gain.

### Mechanism 3
- Claim: Combining patch-wise and embed-wise pooling attention captures both global patch correlations and local embedding dimension correlations, improving accuracy without extra cost.
- Mechanism: Patch-wise pooling models dependencies between all patches while preserving their spatial layout; embed-wise pooling models dependencies between embedding dimensions within each patch.
- Core assumption: Both inter-patch and intra-patch correlations are important for accurate human mesh recovery, and can be modeled efficiently with pooling.
- Evidence anchors:
  - [abstract] "significantly reduces the memory and computational cost without sacrificing performance"
  - [section] "we apply the pooling attention module to model the patch-wise attention and embed-wise attention while reducing computational and memory costs"
  - [corpus] Weak signal: neighbor papers do not discuss dual pooling attention design.
- Break condition: If either type of correlation (patch-wise or embed-wise) is not useful for the HMR task.

## Architecture Onboarding

- Component map:
  Image -> Patch Embedding -> Basic Stream (low-res global features) -> HR Stream (high-res local+global features) -> HMR Head -> Mesh Output

- Critical path:
  Image → Patch Embedding → Basic Stream (low-res global features) → HR Stream (high-res local+global features) → HMR Head → Mesh Output

- Design tradeoffs:
  - PoolAttn vs full attention: Efficiency vs potential loss of some correlation modeling capability
  - HR Stream vs single stream: Accuracy vs memory/computation cost
  - Patch size vs resolution: Larger patches reduce sequence length but lose detail

- Failure signatures:
  - Poor mesh reconstruction: Check if PoolAttn is losing critical correlations; verify HR stream is properly fusing features
  - High memory usage: Check patch sizes and number of stages; verify PAT blocks are using pooling correctly
  - Low accuracy: Verify SMPL model fitting; check if PoolAttn is too aggressive in pooling

- First 3 experiments:
  1. Replace PoolAttn with full attention in PAT block and measure accuracy/memory tradeoff
  2. Remove HR stream and measure impact on accuracy and memory usage
  3. Vary patch size in initial embedding and observe impact on reconstruction quality

## Limitations

- The PoolAttn mechanism's effectiveness relies on assumptions about correlation preservation that may not hold for all body poses and occlusions
- The HR stream design, while innovative, lacks comprehensive ablation studies to prove its necessity versus simpler high-resolution feature preservation methods
- The model's performance on out-of-distribution poses and extreme occlusions remains unclear due to limited testing on synthetic perturbations

## Confidence

- Medium confidence: Accuracy improvements over METRO
- Low confidence: The necessity and optimal configuration of the HR stream design
