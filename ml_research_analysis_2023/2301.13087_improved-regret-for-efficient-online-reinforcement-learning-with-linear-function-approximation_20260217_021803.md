# Improved Regret for Efficient Online Reinforcement Learning with Linear Function Approximation

## Quick Facts
- arXiv ID: 2301.13087
- Source URL: https://arxiv.org/abs/2301.13087
- Reference count: 40
- Primary result: O(K^{6/7}) regret bound for online RL with linear function approximation and bandit feedback

## Executive Summary
This paper presents a policy optimization algorithm for online reinforcement learning with linear function approximation that achieves improved regret bounds without requiring exploratory assumptions or a simulator. The algorithm combines mirror descent policy updates with least squares policy evaluation in an auxiliary MDP to compute exploration bonuses. It achieves an expected regret of O(K^{6/7}) for the general setting with unknown dynamics and bandit feedback, improving upon the previous state-of-the-art O(K^{14/15}). With access to a simulator, the algorithm obtains an O(K^{2/3}) regret bound, matching the best known result but with a computationally efficient implementation.

## Method Summary
The algorithm uses mirror descent for policy updates combined with least squares policy evaluation in an auxiliary MDP to compute exploration bonuses. The key innovation is using optimistic least squares estimation in the bonus MDP to approximate the bonus-to-go function, which enables more efficient exploration than previous approaches. This allows the algorithm to balance exploration and exploitation while maintaining computational efficiency.

## Key Results
- Achieves O(K^{6/7}) expected regret for general setting with unknown dynamics and bandit feedback
- Improves upon previous state-of-the-art O(K^{14/15}) bound
- With simulator access, obtains O(K^{2/3}) regret bound matching best known results
- Computationally efficient implementation compared to prior approaches

## Why This Works (Mechanism)
The algorithm's effectiveness stems from its use of optimistic least squares estimation in an auxiliary MDP to approximate bonus-to-go functions. This approach enables more efficient exploration than previous methods by providing a computationally tractable way to estimate uncertainty in value functions. The mirror descent policy updates combined with this exploration mechanism allow the algorithm to adapt to changing environments while maintaining theoretical guarantees on regret.
