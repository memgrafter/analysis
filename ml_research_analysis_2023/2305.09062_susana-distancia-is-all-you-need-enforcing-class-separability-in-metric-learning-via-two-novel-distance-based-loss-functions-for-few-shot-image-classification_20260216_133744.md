# SuSana Distancia is all you need: Enforcing class separability in metric learning via two novel distance-based loss functions for few-shot image classification

## Quick Facts
- arXiv ID: 2305.09062
- Source URL: https://arxiv.org/abs/2305.09062
- Reference count: 40
- Key result: Proposed Proto-Triplet and ICNN loss functions achieve state-of-the-art accuracy on few-shot image classification tasks, with 61.32% (5-way 1-shot) and 79.93% (5-way 5-shot) accuracy using Proto-Triplet Loss.

## Executive Summary
This paper introduces two novel distance-based loss functions designed to enhance class separability in few-shot image classification. The Proto-Triplet Loss modifies traditional triplet loss by using class prototypes as anchors, positives, and negatives, making it more suitable for limited data scenarios. The ICNN Loss measures inter- and intra-class nearest neighbor distances to evaluate and improve embedding quality. Both methods aim to minimize intra-class distance while maximizing inter-class distance between samples. Extensive experiments on miniImagenet, Caltech-101, Stanford Dogs, Stanford Cars, and CUB datasets demonstrate significant accuracy improvements over existing metric-based few-shot learning approaches.

## Method Summary
The method proposes two complementary distance-based loss functions for few-shot learning. The Proto-Triplet Loss replaces individual samples with class prototypes (mean embeddings of support samples) in the triplet loss formulation, providing more stable comparisons across classes when data is scarce. The ICNN Loss evaluates embedding quality by measuring inter-class and intra-class nearest neighbor distances, encouraging the model to minimize intra-class distance and maximize inter-class distance. Both losses are designed to work with metric learning approaches, particularly Prototypical Networks, and can be combined for synergistic improvements. The framework uses either a ConvNet or ResNet-12 as the feature extractor, with training involving computing class prototypes, calculating both loss functions, and backpropagating the combined loss.

## Key Results
- Proto-Triplet Loss achieves 61.32% accuracy in 5-way 1-shot and 79.93% in 5-way 5-shot settings
- ICNN Loss achieves 60.79% accuracy in 5-way 1-shot and 80.41% in 5-way 5-shot settings
- Both loss functions significantly outperform state-of-the-art metric-based few-shot learning methods
- Results demonstrate effectiveness across multiple datasets including miniImagenet, Caltech-101, Stanford Dogs, Stanford Cars, and CUB

## Why This Works (Mechanism)

### Mechanism 1
Proto-Triplet Loss improves few-shot learning by using class prototypes as anchors, positives, and negatives instead of individual samples. This provides more stable and representative comparisons across classes when data is limited. The core assumption is that class prototypes effectively represent the underlying class distribution, and using them in triplet loss formulation improves class separation. The effectiveness depends on the accuracy of class prototypes in representing the underlying distribution.

### Mechanism 2
ICNN Loss improves few-shot learning by measuring and optimizing inter-class and intra-class nearest neighbor distances. The loss assigns each data point an Inter and Intra Class Nearest Neighbors score and optimizes the embedding network based on the quality of generated features. The core assumption is that feature embedding quality can be effectively assessed through nearest neighbor distances, and optimizing these distances leads to better generalization. The method's success depends on the robustness of nearest neighbor calculation to noise and outliers.

### Mechanism 3
The combination of Proto-Triplet Loss and ICNN Loss provides complementary benefits by enforcing class separability from different angles. Proto-Triplet Loss focuses on pulling same-class prototypes closer and pushing different-class prototypes further apart, while ICNN Loss optimizes overall inter-class and intra-class distances in the embedding space. The core assumption is that these two loss functions address different aspects of the feature embedding optimization problem, leading to synergistic improvements. Their combination is most effective when the optimization objectives are well-aligned and not conflicting.

## Architecture Onboarding

- Component map: Feature Extractor (ConvNet/ResNet-12) -> Loss Functions (Proto-Triplet, ICNN, Cross-Entropy) -> Optimizer (Adam/SGD) -> Datasets (MiniImagenet, CUB-200, Caltech-101, Stanford Dogs, Stanford Cars)

- Critical path:
  1. Pre-train the feature extractor (for ResNet-12 only)
  2. For each meta-train task:
     a. Compute class prototypes from support set
     b. Calculate Proto-Triplet Loss using query samples and prototypes
     c. Calculate ICNN Loss using support and query samples
     d. Combine losses and backpropagate
  3. Validate and test on held-out tasks

- Design tradeoffs:
  - ConvNet vs. ResNet-12: ConvNet is simpler and less prone to overfitting, while ResNet-12 is more powerful but requires pre-training
  - Number of negative prototypes in Proto-Triplet Loss: More negatives provide more comprehensive comparison but increase computational cost
  - ICNN Loss parameters (p, q, r): These control the relative importance of inter-class distance, intra-class distance, and class ratio terms

- Failure signatures:
  - Overfitting: High training accuracy but low validation/test accuracy
  - Underfitting: Low accuracy on both training and validation/test sets
  - Poor class separability: Confusion between classes in embedding space, visible through UMAP visualization

- First 3 experiments:
  1. Train a baseline model using only cross-entropy loss to establish performance benchmark
  2. Implement and train a model using only Proto-Triplet Loss to assess individual contribution
  3. Implement and train a model using only ICNN Loss to assess individual contribution
  4. (Bonus) Combine Proto-Triplet Loss and ICNN Loss to evaluate synergistic effect

## Open Questions the Paper Calls Out

### Open Question 1
How do the proposed loss functions (Proto-Triplet and ICNN) perform when applied to different metric meta-learning methods beyond Prototypical Networks? The paper mentions that the framework can be extended to test these loss functions with different metric meta-learning methods, suggesting potential improvements in feature representations for few-shot tasks. This remains unexplored as the paper primarily focuses on evaluating the loss functions with Prototypical Networks.

### Open Question 2
What is the impact of making the hyper-parameters of the ICNN algorithm learnable instead of fixed values? The paper suggests that one extension could be to make the hyper-parameters of the ICNN algorithm learnable, indicating potential for improved performance. However, the current implementation uses fixed hyper-parameters, and the effect of learning these parameters during training is not explored.

### Open Question 3
How do the proposed loss functions perform in few-shot learning tasks with datasets that have a significantly different number of classes or samples per class compared to the datasets used in the experiments? The paper evaluates the loss functions on datasets with varying characteristics, but the impact of more extreme variations in class and sample numbers is not tested. The experiments focus on datasets with moderate numbers of classes and samples, leaving performance in more extreme scenarios unexplored.

## Limitations
- The paper lacks extensive ablation studies to fully validate the individual contributions of each loss component
- Computational complexity introduced by the novel loss functions is not thoroughly analyzed
- Generalization capabilities to extremely challenging few-shot scenarios (e.g., 20-way classification) are not thoroughly explored

## Confidence
- **High Confidence**: Implementation details for ConvNet architecture and basic formulation of both loss functions are clearly specified
- **Medium Confidence**: Reported accuracy improvements are consistent across multiple datasets, but limited ablation studies exist
- **Low Confidence**: Generalization to extremely challenging few-shot scenarios and computational efficiency are not thoroughly explored
