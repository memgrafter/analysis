# Modelos Generativos basados en Mecanismos de Difusión

## Quick Facts
- arXiv ID: 2302.09378
- Source URL: https://arxiv.org/abs/2302.09378

## Executive Summary
This paper presents the theoretical foundations of diffusion-based generative models, explaining how they enable image generation by reversing a physical diffusion process where two miscible liquids of different colors progressively mix until forming a homogeneous mixture. The models work by progressively corrupting pixels with random noise and training a neural network to reverse each corruption step, allowing image generation from random noise by chaining a similar number of steps used for image deconstruction during training. Written in Spanish, the article aims to facilitate access to this scientific knowledge for the Spanish-speaking community.

## Method Summary
Diffusion-based generative models generate images by first progressively corrupting input images with random Gaussian noise over T steps, then training a neural network (typically a U-Net) to predict the noise at each step. During generation, the model starts with random noise and iteratively denoises it using the trained network for T steps to produce a final image. The training objective uses a variational lower bound (ELBO) that connects the forward and reverse diffusion processes, with the denoising network learning to predict noise rather than the clean image itself.

## Key Results
- Diffusion models can generate high-quality images by learning to reverse gradual corruption processes
- The denoising network learns to predict noise at each step rather than the full image reconstruction
- The training objective uses a variational lower bound (ELBO) connecting forward and reverse diffusion processes

- Mechanism: The model learns to denoise images step-by-step by predicting noise at each stage, then reconstructs the original image from pure noise
- Core assumption: Gradual corruption with small noise steps allows the denoising network to learn a stable inverse mapping

### Mechanism 2
- Claim: The denoising network learns to predict noise rather than the clean image itself
- Mechanism: The network predicts the noise ϵ added at each step, which simplifies the learning task since noise is typically simpler to model than the full image distribution
- Core assumption: Predicting noise ϵ is easier than predicting the full image reconstruction at each step

- Break condition: If the noise prediction task becomes too complex (e.g., with very high-dimensional noise), the network may fail to converge.
