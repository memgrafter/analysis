# Can current NLI systems handle German word order? Investigating language model performance on a new German challenge set of minimal pairs

## Quick Facts
- arXiv ID: 2306.04523
- Source URL: https://arxiv.org/abs/2306.04523
- Reference count: 26
- Primary result: German NLI models struggle significantly with word order variations, achieving 0.33%-57.68% accuracy on the WOGLI challenge set

## Executive Summary
This paper introduces WOGLI, a challenge set of 16,000 German NLI examples designed to test models' ability to handle flexible word order while maintaining subject-object distinctions. The dataset consists of minimal pairs where only word order and necessary morphological changes differ between premises and hypotheses. Experiments with German autoencoding models fine-tuned on translated NLI data show poor performance on these tasks, with accuracy ranging from 0.33% to 57.68% depending on model size. Data augmentation with WOGLI improves performance but requires substantial amounts of augmentation data. The results demonstrate that German word order remains challenging for current NLI systems even after fine-tuning.

## Method Summary
The authors created WOGLI by translating English NLI examples from SNLI and MultiNLI into German, then systematically manipulating word order while preserving lemmata and making necessary morphological changes to mark case and number. Each premise has two corresponding hypotheses: one entailed and one non-entailed, differing only in word order and morphology. The dataset was used to evaluate German BERT models fine-tuned on the translated NLI data, as well as to test data augmentation approaches. The authors also created generalization sets to test transfer to related word order phenomena beyond the specific patterns in WOGLI.

## Key Results
- German BERT models achieve 0.33%-57.68% accuracy on WOGLI depending on model size
- Data augmentation with WOGLI improves performance but requires substantial amounts of augmentation data
- Models struggle to generalize from WOGLI to related word order phenomena even with augmentation
- Current German NLI systems show significant limitations in handling word order flexibility

## Why This Works (Mechanism)
The mechanism underlying these results relates to how German NLI models process syntactic versus morphological information. German's flexible word order allows subject and object positions to vary while case marking on articles and nouns preserves grammatical roles. However, current models appear to rely heavily on word order patterns learned from training data rather than leveraging morphological cues. This creates a vulnerability when presented with WOGLI examples where word order is manipulated but grammatical roles are maintained through case marking. The models fail to properly integrate morphological information with syntactic structure, leading to systematic errors on these controlled contrasts.

## Foundational Learning
- German case marking system: Essential for understanding how German distinguishes subject/object roles morphologically rather than syntactically
- Natural Language Inference task formulation: Understanding the three-way classification (entailment, contradiction, neutral) and its challenges
- Word order flexibility in German: Recognizing that German allows more flexible word order than English due to rich morphology
- Minimal pair construction: Understanding how to create controlled contrasts that isolate specific linguistic phenomena
- Adversarial dataset design: Knowing how to create challenge sets that expose model weaknesses
- Transfer learning in NLI: Understanding how models trained on one language (English) perform on another (German)

## Architecture Onboarding
Component map: NLI dataset (SNLI/MultiNLI) -> German translation -> WOGLI construction -> Model evaluation -> Data augmentation -> Generalization testing

Critical path: The evaluation pipeline involves translating English NLI data, constructing minimal pairs with controlled word order variations, fine-tuning German models on translated data, testing on WOGLI, and evaluating generalization to related phenomena.

Design tradeoffs: The authors chose to use translated English NLI data rather than collecting German NLI data from scratch, which introduces potential bias but allows leveraging existing large-scale datasets. They opted for template-based data augmentation rather than more sophisticated approaches.

Failure signatures: Models fail catastrophically on WOGLI, with accuracy dropping to near-random levels (0.33%), indicating fundamental difficulties with word order distinctions rather than simple classification errors.

First experiments:
1. Evaluate BERT base vs. large models on WOGLI to assess size effects
2. Test data augmentation with varying amounts of WOGLI examples (10, 100, 1000)
3. Evaluate models on the generalization sets to assess transfer capability

## Open Questions the Paper Calls Out
- Can models learn to properly integrate morphological case marking with syntactic structure to handle word order variations?
- What architectural modifications might help models better handle German's flexible word order?
- How do these findings generalize to other morphologically rich languages with flexible word order?
- Would collecting German NLI data natively rather than translating from English yield different results?

## Limitations
- Dataset construction relies on translations from English NLI datasets, potentially biasing toward English patterns
- Evaluation focuses exclusively on BERT model family, leaving open questions about other architectures
- Data augmentation experiments use simple template-based approaches that may not capture full complexity of natural German text

## Confidence
- High confidence: Core finding that German NLI models struggle with word order variations is well-supported
- Medium confidence: Claim that this represents fundamental limitation rather than BERT-specific issue
- Medium confidence: Effectiveness of data augmentation requiring substantial amounts of data

## Next Checks
