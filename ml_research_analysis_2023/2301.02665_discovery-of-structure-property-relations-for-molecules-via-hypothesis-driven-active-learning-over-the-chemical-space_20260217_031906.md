# Discovery of structure-property relations for molecules via hypothesis-driven active learning over the chemical space

## Quick Facts
- arXiv ID: 2301.02665
- Source URL: https://arxiv.org/abs/2301.02665
- Reference count: 0
- Primary result: Physics-augmented active learning approach achieves accurate structure-property predictions using fewer exploration steps than traditional data-driven methods

## Executive Summary
This paper introduces a novel approach for active learning over chemical spaces using hypothesis-driven Gaussian processes (GPs). The method constructs probabilistic mean functions from automatically generated hypotheses using physics-informed featurization and compressed sensing. The hypotheses are evaluated through a reward-driven acquisition scheme, enabling efficient exploration of chemical space. The approach was demonstrated on the QM9 dataset for predicting molecular formation enthalpy, using only a small subset of molecules and a handful of easily computable features. The method successfully reconstructed the structure-property relationships for the entire dataset, achieving accurate predictions while requiring fewer exploration steps compared to traditional data-driven GP methods.

## Method Summary
The method combines physics-informed featurization via compressed sensing (using LASSO) with structured Gaussian processes to predict molecular properties. It uses symbolic regression (SISSO-like) to generate hypotheses from nonlinear combinations of a small set of features (MW, TPSA, molelogP, SP, IE), then wraps these hypotheses in probabilistic models within Gaussian processes. An epsilon-greedy reward-driven acquisition scheme selects the best hypothesis at each exploration step based on uncertainty reduction. The approach was validated on QM9 dataset for formation enthalpy prediction, using 1,000 molecules for hypothesis generation and 300 for initial seeds.

## Key Results
- Successfully reconstructed structure-property relationships for QM9 dataset using only 5 easily computable features
- Achieved accurate predictions while requiring fewer exploration steps compared to traditional data-driven GP methods
- Demonstrated effective hypothesis competition through reward-driven acquisition scheme

## Architecture Onboarding

- Component map: Feature generation -> Hypothesis formulation -> sGP training -> Reward evaluation -> Next point selection
- Critical path: Feature generation → Hypothesis formulation → sGP training → Reward evaluation → Next point selection
- Design tradeoffs:
  - Limited feature set vs. model complexity: Using only a handful of easily computable features keeps hypotheses interpretable but may miss important physics
  - Exploration vs. exploitation: Epsilon-greedy policy balances between trying new hypotheses and exploiting known good ones
  - Computational cost vs. accuracy: More sophisticated kernel functions or larger hypothesis spaces could improve performance but increase computational burden
- Failure signatures:
  - Poor convergence: If uncertainty doesn't decrease over exploration steps, hypotheses may be inadequate
  - High variance in rewards: Indicates instability in hypothesis selection or model training
  - Model collapse: If one hypothesis dominates too quickly, exploration may be insufficient

## Limitations
- Limited generalizability to more complex chemical systems where essential physics may not be captured by a small set of easily computable features
- Compressed sensing approach may miss important higher-order interactions not included in initial feature combinations
- Dependence on the quality and representativeness of the initial 1,000 molecules for hypothesis generation
