# Interactive Log Parsing via Light-weight User Feedback

## Quick Facts
- **arXiv ID:** 2301.12225
- **Source URL:** https://arxiv.org/abs/2301.12225
- **Reference count:** 40
- **Key outcome:** Proposes human-in-the-loop framework with three feedback mechanisms that achieve near-perfect template mining accuracy (GA > 0.95, MA > 0.99) across sixteen benchmark datasets

## Executive Summary
This paper addresses the limitation of traditional automatic log parsing algorithms that cannot adapt to users' varying needs in log analysis. The authors propose an interactive framework that incorporates light-weight user feedback to improve log template mining. The framework introduces three types of feedback mechanisms (Message-Completion, Merge, Separation) that enable users to directly influence the parsing results by adding templates, merging clusters, and splitting clusters respectively. The approach is designed to be generic and can be applied to any base log parsing algorithm while maintaining computational efficiency.

## Method Summary
The paper presents a human-in-the-loop framework for interactive log template mining that addresses the rigidity of traditional automatic log parsing algorithms. The framework provides three light-weight user feedback mechanisms that allow users to improve template richness (Message-Completion), merge clusters (Merge), and split clusters (Separation). These atomic algorithms are designed to be efficient and correct, with theoretical analysis proving their computational complexity and query complexity bounds. The framework is generic and can be applied to any base log parsing algorithm, making it a flexible solution for various log analysis scenarios.

## Key Results
- Achieves near-perfect template mining accuracy with GA > 0.95 and MA > 0.99 across sixteen benchmark datasets
- Successfully improves parsing accuracy across different base algorithms and parameter settings
- Maintains computational efficiency while incorporating interactive user feedback
- Demonstrates significant improvement over traditional automatic log parsing algorithms

## Why This Works (Mechanism)
The framework works by incorporating human domain knowledge into the log parsing process through three light-weight feedback mechanisms. The Message-Completion algorithm allows users to add missing templates that the automatic algorithm fails to identify, addressing the problem of template richness. The Merge algorithm enables users to combine similar log templates that were incorrectly separated by the base algorithm, while the Separation algorithm allows users to split overly-general clusters into more specific templates. These mechanisms work together to create a flexible parsing system that can adapt to users' specific needs while maintaining efficiency.

## Architecture Onboarding

**Component Map:** User Feedback -> Atomic Algorithms (Message-Completion, Merge, Separation) -> Base Parser -> Log Templates

**Critical Path:** User provides feedback → Appropriate atomic algorithm processes feedback → Base parser updates templates → Improved parsing results

**Design Tradeoffs:** The framework trades off some computational overhead for significantly improved accuracy and adaptability. The light-weight feedback mechanisms are designed to minimize user effort while maximizing impact on parsing quality.

**Failure Signatures:** Poor base algorithm selection, excessive user feedback requirements for large datasets, or feedback that conflicts with the underlying log structure can lead to suboptimal results.

**First Experiments:**
1. Apply framework to a single dataset with known issues to verify feedback mechanisms work as intended
2. Test each atomic algorithm independently to validate correctness and efficiency
3. Compare framework performance against base algorithm alone to quantify improvement

## Limitations
- Framework relies on user feedback which may become impractical for very large log datasets
- Experiments primarily focus on benchmark datasets rather than real-world deployment scenarios
- Real-world logs with high noise levels, heterogeneity, or streaming characteristics may present different challenges
