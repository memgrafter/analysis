## Executive Summary
This paper introduces FlexCHarts, a differentiable neural architecture search method with dynamic channel allocation to optimize channel dimensions in DNNs. The method addresses the limitation of fixed search spaces in existing approaches by enabling flexible adaptation of channel dimensions during the search process. FlexCHarts reformulates the architectural variables to allow smooth changes in channel ranges and introduces a dynamic channel allocation mechanism to efficiently adapt kernel dimensions. Experiments on CIFAR-10 demonstrate that FlexCHarts achieves comparable accuracy and latency to previous methods while improving search efficiency by 1.3-1.7× in GPU-hours and 1.5-1.7× in memory requirements. The approach eliminates the need for well-engineered search spaces a priori, representing a step towards fully automated DNN design.

## Method Summary
FlexCHarts reformulates the continuous relaxation of neural architecture search to enable dynamic channel allocation. The method introduces a novel architectural variable representation that allows smooth adaptation of channel dimensions during the search process. A dynamic channel allocation mechanism is implemented to efficiently adjust kernel dimensions based on the learned architectural parameters. This approach eliminates the need for pre-defined channel dimension ranges that are typically required in traditional differentiable architecture search methods. The continuous relaxation is achieved through a combination of architectural variable reformulation and an efficient optimization strategy that maintains the differentiability of the search process while allowing flexible channel dimension exploration.

## Why This Works (Mechanism)
FlexCHarts works by reformulating the continuous relaxation in differentiable architecture search to enable dynamic channel allocation. The method modifies the architectural variable representation to allow smooth changes in channel dimensions during the search process, rather than being constrained to pre-defined ranges. This reformulation maintains the differentiability required for gradient-based optimization while providing the flexibility to explore a wider range of channel configurations. The dynamic channel allocation mechanism efficiently adapts kernel dimensions based on the learned architectural parameters, enabling the search process to discover optimal channel configurations without being limited by hand-engineered search space constraints.

## Architecture Onboarding

**Component Map:** Input -> FlexCHarts Reformulation -> Dynamic Channel Allocation -> Output Architecture

**Critical Path:** The core optimization loop involves architectural variable updates, channel dimension adaptation, and weight updates in an alternating fashion.

**Design Tradeoffs:** FlexCHarts trades some additional optimization complexity for the benefit of eliminating hand-engineered search space constraints. The dynamic allocation mechanism adds computational overhead but enables exploration of a much larger design space.

**Failure Signatures:** Optimization instability may occur when channel dimensions change too rapidly, potentially causing vanishing or exploding gradients. Memory fragmentation can happen when dynamically allocating channels across different layers.
