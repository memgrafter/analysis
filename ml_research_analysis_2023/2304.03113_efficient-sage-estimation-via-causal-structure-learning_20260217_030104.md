# Efficient SAGE Estimation via Causal Structure Learning
## Quick Facts
- arXiv ID: 2304.03113
- Source URL: https://arxiv.org/abs/2304.03113
- Reference count: 21
- Key outcome: d-SAGE accelerates SAGE estimation by up to 38% by skipping redundant feature evaluations using causal structure learning

## Executive Summary
This paper introduces d-SAGE, a method that accelerates Shapley Additive Global importancE (SAGE) value estimation by exploiting conditional independencies in the data. The core insight is that if a feature is conditionally independent of the target given a subset of other features, its surplus contribution is zero, allowing the expensive computation to be skipped. To identify these independencies, d-SAGE leverages causal structure learning (CSL) to infer a graph encoding dependencies, enabling efficient d-separation queries. Experiments on synthetic and real-world data show significant speedups without distorting importance values, with negligible overhead from graph learning.

## Method Summary
d-SAGE combines causal structure learning with SAGE estimation to reduce computational cost. It first learns a causal graph from the data using algorithms like PC or GES, which encode conditional independencies among features. During SAGE estimation, it uses d-separation on this graph to determine whether a feature's contribution is conditionally independent of the target given a subset of features. If so, the feature's surplus contribution is set to zero and the expensive marginal contribution calculation is skipped. This approach preserves the accuracy of SAGE values while reducing the number of feature evaluations required.

## Key Results
- d-SAGE achieves up to 38% speedup in SAGE estimation compared to standard methods
- The computational overhead of causal structure learning is negligible relative to the savings from skipped evaluations
- d-SAGE maintains the accuracy and reliability of SAGE importance values
- Performance gains depend on the quality of the causal graph and sparsity of conditional independencies in the data

## Why This Works (Mechanism)
The method works by exploiting conditional independencies (CIs) in the data: if a feature is independent of the target given a subset of other features, its marginal contribution to the model's prediction is zero. Causal structure learning (CSL) is used to infer a graph representing these dependencies, enabling efficient d-separation queries to identify which features can have their contributions skipped. This reduces the number of expensive marginal contribution calculations required by SAGE, yielding significant computational savings.

## Foundational Learning
- **Causal Structure Learning (CSL):** Algorithms (e.g., PC, GES) infer a graph encoding conditional independencies among features. Why needed: To identify which features can have their contributions skipped. Quick check: Verify that the learned graph reflects known or expected dependencies in the data.
- **d-Separation:** A graph-based method to determine conditional independence. Why needed: To efficiently test if a feature is independent of the target given a subset. Quick check: Confirm that d-separation queries align with empirical independence tests.
- **Shapley Values/SAGE:** A method for estimating feature importance by averaging marginal contributions over all feature subsets. Why needed: The baseline method whose computational cost is being reduced. Quick check: Ensure SAGE values computed with d-SAGE match those from standard SAGE.
- **Conditional Independence:** A statistical property indicating that two variables are independent given a third. Why needed: The theoretical foundation for skipping redundant calculations. Quick check: Test that zero contributions are only assigned when true conditional independence holds.

## Architecture Onboarding
- **Component map:** Data -> CSL (PC/GES) -> Causal Graph -> d-SAGE (d-separation queries) -> SAGE values
- **Critical path:** Structure learning (once) -> For each feature subset: d-separation check -> Skip or compute marginal contribution -> Aggregate Shapley values
- **Design tradeoffs:** Accuracy vs. computational cost; graph quality vs. generalizability; upfront cost of structure learning vs. repeated savings in SAGE estimation
- **Failure signatures:** Poor structure learning leads to missed savings or incorrect importance values; dense causal graphs limit reduction in evaluations; high-dimensional data increases structure learning overhead
- **3 first experiments:** 1) Run d-SAGE on synthetic data with known causal structure to verify speedup and accuracy. 2) Apply d-SAGE to benchmark datasets and compare runtime and importance rankings to standard SAGE. 3) Test sensitivity to different CSL algorithms (PC vs GES) and their hyperparameters.

## Limitations
- Performance gains depend on the sparsity of conditional independencies and quality of the causal graph
- Limited discussion of robustness to noisy or misspecified causal graphs
- Computational overhead of structure learning may become significant for high-dimensional or streaming data
- Results concentrated on controlled datasets and specific model classes; limited real-world scalability discussion
