# Full Automation of Goal-driven LLM Dialog Threads with And-Or Reciners and Refiner Oracles

## Quick Facts
- arXiv ID: 2306.14077

## Executive Summary
This paper presents a system for fully automating deep reasoning in LLM dialog threads through recursive exploration of alternatives and expansion of details. The method adapts SLD-resolution logic programming to natural language reasoning patterns, using AND-steps for detail expansion and OR-steps for alternative generation up to a specified depth. The system employs semantic similarity to ground-truth facts or LLM-based oracle advice to validate reasoning steps and filter the search space.

The approach demonstrates applications across consequence prediction, causal explanation, recommendation systems, and focused scientific literature exploration. The system generates explainable answers with justification traces and compiles reasoning steps into Horn Clause programs for further analysis. The method claims to provide crisper, more accurate results than conventional search engines or interactive dialog agents while reducing hallucination issues.

## Method Summary
The system implements AND-OR recursion for goal-driven dialog automation, where AND-steps expand details and OR-steps explore alternatives. The recursion depth is controlled by a specified parameter. Semantic similarity measures validate reasoning steps against ground-truth facts or LLM-based oracle advice, filtering the search space to maintain logical consistency. The system generates justification traces and compiles reasoning steps into Horn Clause programs for analysis. This approach adapts SLD-resolution logic programming principles to natural language reasoning patterns.

## Key Results
- Demonstrates automated reasoning across consequence prediction, causal explanation, recommendation systems, and scientific literature exploration

## Why This Works (Mechanism)
The system works by combining logical reasoning patterns with natural language processing through AND-OR recursion. AND-steps systematically expand details within a reasoning chain, while OR-steps explore alternative paths when multiple valid approaches exist. The semantic similarity validation mechanism grounds each reasoning step against established facts or oracle advice, preventing the accumulation of errors that typically lead to hallucinations. By adapting SLD-resolution logic programming to natural language, the system maintains logical rigor while operating in the more flexible domain of human language.
