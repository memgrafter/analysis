# An entity-guided text summarization framework with relational heterogeneous graph neural network

## Quick Facts
- arXiv ID: 2302.03205
- Source URL: https://arxiv.org/abs/2302.03205
- Reference count: 40
- Primary result: Outperforms extractive and abstractive baselines on CNN/DM, competitive on NYT50

## Executive Summary
This paper proposes an entity-guided text summarization framework that leverages entities mentioned in text to connect Knowledge Graphs and Graph Neural Networks. The framework constructs sentence-entity graphs where entity-entity edges are built based on KG, initializes entity embeddings from KG, and trains them using entity-entity edges. The relational heterogeneous GNN calculates graphs with weighted multi-type edges, utilizing both edge weights and types in the propagation process. Experimental results show the method outperforms extractive baselines including HGNN-based HGNNSum and abstractive baselines like SENECA on CNN/DM, with competitive performance on NYT50.

## Method Summary
The framework connects GNNs with KGs by constructing sentence-entity graphs where entity-entity edges are built based on KG relationships, initializing entity embeddings on the KG, and training these embeddings using the entity-entity edges. The relational heterogeneous GNN for summarization is proposed to handle graphs with weighted multi-type edges by making use of both edge weights and edge types during the propagation process. This approach enables modeling of cross-sentence relations in text and knowledge beyond text for summarization purposes.

## Key Results
- Outperforms extractive baselines including HGNN-based HGNNSum on CNN/DM
- Beats abstractive baselines including entity-driven SENECA on CNN/DM
- Shows performance correlation with sentence-entity edge density on sub-datasets
- Demonstrates effectiveness of entity-entity edges and edge weighting through ablation studies

## Why This Works (Mechanism)
The framework leverages entities as bridges between text and external knowledge, enabling the model to capture semantic relationships that span across sentences and incorporate world knowledge beyond the input text. By initializing entity embeddings from the knowledge graph and maintaining entity-entity relationships during training, the model can propagate information more effectively across the heterogeneous graph structure. The use of weighted multi-type edges allows the model to distinguish between different relationship strengths and types, leading to more nuanced information flow during summarization.

## Architecture Onboarding

Component Map: Text -> Entity Linking -> Sentence-Entity Graph Construction -> Knowledge Graph Integration -> Relational Heterogeneous GNN -> Summarization Output

Critical Path: The entity linking quality directly impacts KG integration, which affects entity embeddings initialization, ultimately determining the GNN's ability to capture cross-sentence relationships for summarization.

Design Tradeoffs:
1. Dense vs. sparse sentence-entity graphs: Higher density improves performance but increases computational cost
2. Entity linking precision vs. recall: More entities provide more knowledge but may introduce noise
3. KG vs. text-only embeddings: KG initialization provides external knowledge but may be domain-mismatched

Failure Signatures:
1. Poor entity linking leads to incorrect KG integration and degraded summarization
2. Over-reliance on entity-entity edges may miss important sentence-level information
3. Imbalanced edge weighting can cause information bottleneck in certain graph regions

First Experiments:
1. Vary entity linking thresholds to measure impact on summarization quality
2. Compare KG-initialized embeddings vs. learned-only embeddings
3. Test different edge weighting schemes on summarization performance
