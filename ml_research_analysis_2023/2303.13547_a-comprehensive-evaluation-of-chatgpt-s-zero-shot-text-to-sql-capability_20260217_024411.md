# A comprehensive evaluation of ChatGPT's zero-shot Text-to-SQL capability

## Quick Facts
- arXiv ID: 2303.13547
- Source URL: https://arxiv.org/abs/2303.13547
- Reference count: 6
- Primary result: ChatGPT achieves only 14% gap to state-of-the-art models in execution accuracy on Spider dataset

## Executive Summary
This paper comprehensively evaluates ChatGPT's zero-shot Text-to-SQL performance across 12 benchmark datasets. The study leverages ChatGPT's conversational and code generation abilities without any fine-tuning, using direct prompt-based generation. Results show ChatGPT performs strongly, with a 14% gap compared to state-of-the-art models on the Spider dataset, and excels particularly in robustness settings and multi-turn scenarios.

## Method Summary
The evaluation uses ChatGPT's zero-shot capability to generate SQL queries from natural language questions and database schemas. A direct prompt structure is employed without fine-tuning. Generated SQL is executed in SQLite databases and validated against gold standards using execution accuracy, valid SQL count, and test-suite accuracy metrics across multiple benchmark datasets.

## Key Results
- ChatGPT achieves only 14% gap compared to state-of-the-art models in execution accuracy on Spider dataset
- Excels in robustness settings, outperforming SOTA models by 4.1% in ADVETA (RPL) scenario
- Demonstrates strong multi-turn and compositional generalization capabilities with smaller performance gaps in these settings
- Shows weaker cross-lingual performance when table and column names are non-English

## Why This Works (Mechanism)

### Mechanism 1
ChatGPT's conversational and code generation abilities enable strong zero-shot Text-to-SQL performance by leveraging pretraining on large-scale code and natural language data to map user questions to executable SQL queries without fine-tuning.

### Mechanism 2
ChatGPT's robustness stems from its ability to handle synonym substitutions and adversarial schema modifications due to its broad pretraining exposure to diverse linguistic variations and adversarial examples.

### Mechanism 3
ChatGPT's contextual modeling ability enhances multi-turn Text-to-SQL performance through its attention mechanisms that effectively track dialogue context to resolve references and dependencies across turns.

## Architecture Onboarding

**Component map:**
Prompt design (single-turn and multi-turn templates) -> Input processing (user question and database schema) -> SQL generation (ChatGPT's autoregressive decoding) -> Execution engine (SQLite for validation)

**Critical path:**
1. Receive user question and database schema
2. Format into prompt template
3. Generate SQL query via ChatGPT
4. Execute query in SQLite
5. Compare results to gold standard

**Design tradeoffs:**
- Zero-shot vs fine-tuning: Simplicity vs potential performance gain
- Execution accuracy vs exact match: Flexibility vs precision
- Single-turn vs multi-turn: Complexity vs real-world applicability

**Failure signatures:**
- Non-executable SQL: Syntax errors or invalid references
- Incorrect results: Semantic misunderstanding of the question
- Robustness issues: Failure on synonym substitutions or schema modifications

**First 3 experiments:**
1. Validate single-turn performance on Spider dataset
2. Test robustness on Spider-SYN and Spider-Realistic
3. Evaluate multi-turn capability on SParC and CoSQL

- Why unresolved: The paper focuses on evaluating ChatGPT's performance on 12 benchmark datasets but does not extend the analysis to larger or more diverse datasets.

## Limitations

- Limited visibility into prompt engineering details and optimization strategies
- Potential domain shift effects not thoroughly investigated for specialized schemas
- Evaluation scope constraints focusing primarily on execution accuracy

## Confidence

**High confidence**: ChatGPT achieves strong zero-shot Text-to-SQL performance with only 14% gap to SOTA models on Spider execution accuracy

**Medium confidence**: ChatGPT excels in robustness settings and outperforms SOTA models in ADVETA (RPL) scenarios, though underlying mechanisms need more exploration

**Low confidence**: ChatGPT's cross-lingual performance limitations when table and column names are non-English are based on limited evidence
