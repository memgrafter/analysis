# Random projection tree similarity metric for SpectralNet

## Quick Facts
- arXiv ID: 2302.13168
- Source URL: https://arxiv.org/abs/2302.13168
- Reference count: 40
- Primary result: Random projection tree similarity metric improves SpectralNet clustering accuracy over k-nn graphs

## Executive Summary
This paper proposes a novel similarity metric based on random projection trees (rpTrees) for the graph clustering method SpectralNet. SpectralNet uses a neural network to find an embedding that separates the data, but it was only used with k-nn graphs constructed using a distance metric. k-nn graphs restrict points to have a fixed number of neighbors regardless of the local statistics around them. The proposed rpTree similarity metric does not restrict the number of positive pairs and produces better clustering accuracy compared to k-nn graph with a distance metric. The experiments revealed that the rpTree parameters, including the leaf size and the selection of projection direction, do not affect the clustering accuracy. It is computationally efficient to keep the leaf size in order of log(n) and project the points onto a random direction instead of trying to find the direction with the maximum dispersion.

## Method Summary
The proposed method constructs a similarity graph for SpectralNet using random projection trees instead of traditional k-nearest neighbors. Each point in the dataset is projected onto a random direction, and points are grouped into leaves of the tree based on these projections. The similarity between points is then defined by their co-occurrence in the same leaves. This approach allows for variable numbers of neighbors depending on local data density, unlike fixed-k k-nn graphs. The paper demonstrates that this rpTree-based similarity metric leads to improved clustering performance in SpectralNet while being computationally efficient.

## Key Results
- Random projection tree similarity metric improves clustering accuracy compared to k-nn graphs
- rpTree parameters (leaf size and projection direction) do not significantly affect clustering accuracy
- Computationally efficient to use leaf size of order log(n) and random projection directions

## Why This Works (Mechanism)
Random projection trees capture local data density variations better than fixed-k k-nn graphs. By allowing variable numbers of neighbors based on data distribution, the rpTree similarity metric creates more meaningful connections between similar points. The use of random projections provides a computationally efficient way to approximate nearest neighbors without computing pairwise distances. The logarithmic leaf size scaling ensures that the method remains efficient as dataset size grows.

## Architecture Onboarding

Component map:
Data points -> Random projection -> Tree construction -> Leaf assignment -> Similarity graph -> SpectralNet clustering

Critical path:
The critical path is from data points through random projection to tree construction and leaf assignment, which determines the similarity graph. This graph then feeds into SpectralNet for clustering.

Design tradeoffs:
- Variable vs. fixed neighbor counts: rpTrees allow adaptive neighbor selection based on local density
- Random vs. optimized projections: Random projections are computationally cheaper but may be less optimal
- Tree depth vs. accuracy: Deeper trees provide more precise groupings but increase computation

Failure signatures:
- Poor clustering if data has very high intrinsic dimensionality where random projections fail
- Degraded performance if leaf size is too small (few neighbors) or too large (loss of locality)
- Potential issues with non-Euclidean data where random projections don't capture meaningful relationships
