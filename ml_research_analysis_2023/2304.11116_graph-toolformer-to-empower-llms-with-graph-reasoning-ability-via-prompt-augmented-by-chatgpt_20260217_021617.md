# Graph-ToolFormer: To Empower LLMs with Graph Reasoning Ability via Prompt Augmented by ChatGPT

## Quick Facts
- arXiv ID: 2304.11116
- Source URL: https://arxiv.org/abs/2304.11116
- Reference count: 40
- Primary result: Framework teaches LLMs graph reasoning via ChatGPT-augmented prompts with API calls, achieving high ROUGE/BLEU scores

## Executive Summary
Graph-ToolFormer is a framework that teaches large language models (LLMs) to perform graph reasoning tasks by incorporating external graph learning tools through API calls. The approach uses ChatGPT to generate and augment a dataset with graph reasoning API calls, which is then used to fine-tune existing pre-trained LLMs like GPT-J and LLaMA. The framework enables LLMs to handle various graph reasoning tasks across multiple domains including bibliographic networks, protein molecules, recommender systems, social networks, and knowledge graphs.

## Method Summary
The framework fine-tunes LLMs using a dataset where graph reasoning API calls are embedded within text statements. ChatGPT generates thousands of input-output pairs with appropriate API calls from hand-crafted prompts, which are then filtered and used for training. During inference, the model learns to insert appropriate API calls at key positions when generating responses about graph data. The approach supports nested and sequential API calls for complex reasoning tasks and uses a memory bank mechanism to handle variable-length graph inputs.

## Key Results
- Successfully fine-tunes LLMs to perform graph reasoning across multiple domains
- Achieves high ROUGE and BLEU scores on various graph reasoning datasets
- Demonstrates capability to handle nested and sequential API calls for complex tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Graph-ToolFormer enables LLMs to perform graph reasoning by inserting API calls into text outputs
- Core assumption: LLMs can learn to recognize when and where to insert API calls through pattern matching
- Break condition: If LLM fails to identify appropriate insertion points or selects incorrect API functions

### Mechanism 2
- Claim: ChatGPT augments a small set of hand-crafted prompts into a large training dataset
- Core assumption: ChatGPT's few-shot learning can reliably generate valid API call annotations
- Break condition: If ChatGPT generates invalid or nonsensical API calls

### Mechanism 3
- Claim: Graph-ToolFormer handles nested and sequential API calls for complex graph reasoning
- Core assumption: LLMs can learn to generate and nest API calls through training
- Break condition: If LLM fails to correctly nest or sequence API calls

## Architecture Onboarding

- Component map: ChatGPT -> Base LLM (GPT-J/LLaMA) -> Graph reasoning toolkit -> Data storage -> Fine-tuning pipeline -> Inference engine with memory bank
- Critical path: Data generation → Fine-tuning → Inference with API execution
- Design tradeoffs: Using existing LLMs vs. training from scratch (cost vs. flexibility)
- Failure signatures: Invalid API calls in generation output, LLM fails to insert API calls, API execution errors
- First 3 experiments: 1) Fine-tune on basic graph property reasoning tasks and evaluate ROUGE scores, 2) Test inference on unseen tasks and verify API call correctness, 3) Extend to complex task (e.g., paper topic reasoning) and evaluate across multiple datasets

## Limitations

- Computational requirements for fine-tuning large LLMs on graph-augmented datasets are not thoroughly explored
- Evaluation relies primarily on text generation metrics (ROUGE/BLEU) rather than actual graph reasoning performance
- Effectiveness on highly specialized graph domains like protein structures or complex knowledge graphs remains unverified

## Confidence

**High Confidence**: Framework successfully integrates API calls into LLM outputs; ChatGPT can generate valid API-augmented datasets; approach outperforms baselines on basic tasks

**Medium Confidence**: Framework generalizes to diverse real-world graph domains; nested/sequential API calls improve complex reasoning; memory bank mechanism handles variable-length inputs

**Low Confidence**: Performance on specialized graph domains (proteins, knowledge graphs); scalability to industrial-scale datasets; robustness with noisy/incomplete graph data
