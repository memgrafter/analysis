# Towards Label-Efficient Incremental Learning: A Survey

## Quick Facts
- arXiv ID: 2302.00353
- Source URL: https://arxiv.org/abs/2302.00353
- Authors: [Authors not specified]
- Reference count: 12

## Executive Summary
This paper provides the first comprehensive survey on label-efficient incremental learning, addressing the challenge of reducing label supervision requirements for continual learning systems. The authors identify three main directions for achieving label efficiency: semi-supervision through pseudo-labeling on unlabeled data, few-shot supervision by expanding pre-trained classifiers with minimal examples, and self-supervision using pretext tasks that eliminate the need for labels entirely. The survey offers a structured overview of recent techniques in each direction while highlighting their respective strengths and limitations.

## Method Summary
The paper categorizes label-efficient incremental learning approaches into three main strategies. Semi-supervised methods leverage pseudo-labels generated on unlabeled data to expand training datasets without additional manual annotation. Few-shot supervised methods reduce label requirements by adapting pre-trained classifiers with only a few examples per new class, balancing the challenges of overfitting to novel categories and preserving performance on base classes. Self-supervised methods omit labels entirely by training on unlabeled data using pretext tasks like contrastive learning or reconstruction to build discriminative feature representations.

## Key Results
- Label-efficient incremental learning can be achieved through semi-supervision, few-shot supervision, or self-supervision
- Each approach addresses different aspects of the label-efficiency challenge while managing catastrophic forgetting
- Future research directions include mixed-supervised learning, incremental dense learning, incremental active learning, and incremental object discovery

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pseudo-labeling on unlabeled data reduces the need for human annotations while maintaining incremental learning performance.
- Mechanism: The model first trains on a small labeled dataset to obtain a base classifier. It then generates pseudo-labels on the unlabeled subset and self-trains using these pseudo-labels, effectively increasing the training data without additional manual annotation.
- Core assumption: Pseudo-labels generated by the model are sufficiently accurate to serve as supervision for self-training.
- Evidence anchors:
  - [section] "Researchers train deep learners on a small subset of labeled data, and then produce pseudo labels on unlabeled data [Sohn et al., 2020]."
  - [section] "The pseudo labels are used for further self-training [Sahito et al., 2022; Zoph et al., 2020]."
  - [corpus] No direct corpus evidence for this mechanism; weak evidence.
- Break condition: If pseudo-label accuracy drops below a threshold, self-training may degrade performance or cause catastrophic forgetting.

### Mechanism 2
- Claim: Few-shot learning updates a pre-trained classifier with minimal labeled examples for new classes while preserving performance on old classes.
- Mechanism: The model starts with a pre-trained feature extractor and classifier. For each new task, only a few labeled examples per new class are used to update the classifier weights, often leveraging semantic relationships or prototype-based associations to minimize overfitting and forgetting.
- Core assumption: The pre-trained model's feature space contains sufficient discriminative information to adapt to new classes with few examples.
- Evidence anchors:
  - [section] "Few-shot-supervised learners reduce label-supervision by expanding a pre-trained classifier with only few examples (e.g. 1-shot) [Tao et al., 2020]."
  - [section] "Few-shot-supervised methods tackle two fundamental challenges simultaneously: i) Overfitting to Novel Categories... ii) Forgetfulness of Base Categories..."
  - [corpus] No direct corpus evidence for this mechanism; weak evidence.
- Break condition: If the pre-trained feature space is not discriminative enough or too specialized, few-shot adaptation may fail.

### Mechanism 3
- Claim: Self-supervised learning can replace or supplement label supervision in incremental learning by designing pretext tasks that do not require labels.
- Mechanism: The model is trained solely on unlabeled data using self-supervised objectives like contrastive learning (e.g., SimSiam, Barlow-Twins) or reconstruction (e.g., MAE). This builds rich feature representations that can be evaluated with a linear probe after training.
- Core assumption: Self-supervised objectives are sufficient to learn discriminative features that generalize across incremental tasks.
- Evidence anchors:
  - [section] "Self-supervision omits the need for label-supervision by designing pretext tasks [Chen et al., 2020]."
  - [section] "In incremental learning, self-supervision corresponds to training only the feature extractor fΘ(·) solely on unlabeled data..."
  - [corpus] No direct corpus evidence for this mechanism; weak evidence.
- Break condition: If the self-supervised task does not align well with the target task, the learned representations may not be discriminative enough.

## Architecture Onboarding

- Component map: Feature extractor (fΘ) -> Classifier head (hφ) -> Memory buffer -> Pseudo-label generator
- Critical path: Pre-train → Incremental task loop (train → evaluate → store exemplars) → Repeat
- Design tradeoffs:
  - Memory vs. performance: Larger memory buffers reduce forgetting but increase resource usage
  - Pseudo-label quality vs. self-training stability: Higher-quality pseudo-labels improve performance but may be harder to generate
  - Backbone freezing vs. fine-tuning: Freezing prevents overfitting but may limit adaptation; fine-tuning risks forgetting
- Failure signatures:
  - Accuracy drop on old tasks while learning new ones → forgetting
  - Erratic pseudo-label quality → unstable self-training
  - Overfitting to few examples → poor generalization on new classes

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does mixed-supervised learning combining semi-, few-shot-, and self-supervision compare to pure approaches in incremental learning?
- Basis in paper: [explicit] The authors suggest exploring "mixed supervision settings for incremental learning" as a future direction, noting that such combinations are common in non-incremental learning.
- Why unresolved: The paper identifies this as an unexplored area without providing empirical comparisons of mixed-supervised approaches.
- What evidence would resolve it: Empirical studies comparing performance of incremental learners using combinations of semi-, few-shot-, and self-supervision versus pure approaches across multiple benchmarks.

### Open Question 2
- Question: How can self-supervision replace label-supervision entirely for incremental learning without requiring separate linear-probing evaluation?
- Basis in paper: [explicit] The authors note that self-supervised incremental learners "require a separate labeled linear-probing stage for evaluation purposes, limiting their use cases."
- Why unresolved: Current self-supervised incremental learning methods still rely on labeled data for evaluation, contradicting the goal of label-efficiency.
- What evidence would resolve it: Development and validation of self-supervised incremental learning methods that can be evaluated without any labeled data, perhaps through self-supervised evaluation metrics.

### Open Question 3
- Question: Can incremental learners develop novel object discovery capabilities without any supervision?
- Basis in paper: [explicit] The authors identify "Incremental Object Discovery" as a novel problem, noting that existing incremental learners have "no novel object discovery capacity" and that the visual world constantly presents novel objects.
- Why unresolved: Current incremental learning assumes all objects are at least partially labeled, which is unrealistic in real-world scenarios.
- What evidence would resolve it: Development and validation of incremental learning methods that can automatically discover and learn novel objects from unlabeled data streams without prior exposure or supervision.

## Limitations
- Analysis is largely conceptual with limited empirical validation for specific mechanisms
- Evidence anchors rely heavily on citations without direct corpus evidence
- Does not address practical challenges like pseudo-label noise accumulation over long sequences
- Lacks detailed discussion of trade-offs between self-supervised pretraining quality and incremental adaptation capacity

**Low**: Assertions about few-shot learning effectiveness without specific empirical benchmarks
