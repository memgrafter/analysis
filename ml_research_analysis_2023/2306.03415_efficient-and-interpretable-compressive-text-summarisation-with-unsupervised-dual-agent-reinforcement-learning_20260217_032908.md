# Efficient and Interpretable Compressive Text Summarisation with Unsupervised Dual-Agent Reinforcement Learning

## Quick Facts
- **arXiv ID**: 2306.03415
- **Source URL**: https://arxiv.org/abs/2306.03415
- **Reference count**: 21
- **Primary result**: URLComSum achieves strong ROUGE scores, particularly on the Newsroom dataset, using unsupervised dual-agent reinforcement learning for compressive text summarization

## Executive Summary
This paper introduces URLComSum, the first unsupervised method for compressive text summarization that employs a dual-agent reinforcement learning framework. The system uses two specialized agents: an extractor that identifies salient sentences and a compressor that selects important words to form a concise summary. The approach measures semantic coverage using Wasserstein distance and fluency using SLOR, achieving competitive performance on standard summarization benchmarks without requiring labeled training data.

## Method Summary
URLComSum employs a novel dual-agent reinforcement learning architecture where two agents work sequentially to create compressed summaries. The extractor agent first identifies salient sentences from the input document, then the compressor agent selects key words from these sentences to form the final summary. The system uses Wasserstein distance to measure semantic coverage between the summary and source document, while SLOR (Sentence Length Normalized Log-Odds Ratio) evaluates fluency. Both agents are trained end-to-end using reinforcement learning without requiring human-labeled summaries, making the approach fully unsupervised.

## Key Results
- URLComSum achieves strong ROUGE-1, ROUGE-2, and ROUGE-L scores across CNN/DailyMail, Newsroom, and XSum datasets
- The method shows particularly strong performance on the Newsroom dataset compared to baseline methods
- The unsupervised approach matches or exceeds performance of supervised methods in compressive summarization tasks

## Why This Works (Mechanism)
The dual-agent reinforcement learning framework enables URLComSum to effectively balance content selection and compression in a coordinated manner. The extractor agent focuses on identifying semantically important sentences, while the compressor agent operates on the extracted content to produce a concise summary. By using Wasserstein distance as a semantic coverage reward, the system can better capture the distributional similarity between summary and source document compared to traditional n-gram based metrics. The SLOR fluency reward ensures the compressed summaries maintain natural language characteristics, preventing the output from becoming incoherent despite aggressive compression.

## Architecture Onboarding

**Component Map**: Document -> Extractor Agent -> Extracted Sentences -> Compressor Agent -> Compressed Summary -> Reward Calculation (Wasserstein + SLOR) -> Policy Update

**Critical Path**: The critical path flows from input document through the extractor agent, then to the compressor agent, and finally to reward calculation. The Wasserstein distance computation and SLOR evaluation must be efficient to maintain reasonable training times, as these occur at each policy update step.

**Design Tradeoffs**: The dual-agent design increases model complexity but allows specialized optimization for extraction and compression tasks. The unsupervised approach sacrifices some performance potential compared to supervised methods but gains in data efficiency and generalizability. Using Wasserstein distance improves semantic coverage measurement but increases computational overhead compared to simpler metrics.

**Failure Signatures**: Training instability may occur if the extractor and compressor agents develop conflicting objectives. The system may produce overly compressed summaries that lose essential information if the semantic coverage reward is not properly balanced with fluency constraints. Poor convergence could result from inadequate reward shaping or inappropriate hyperparameters for the reinforcement learning algorithm.

**First Experiments**: 1) Test extractor agent alone on sentence selection task to verify it captures salient content, 2) Evaluate compressor agent performance on extracted sentences before full system integration, 3) Conduct ablation studies removing either Wasserstein distance or SLOR rewards to measure their individual contributions

## Limitations
- The paper lacks human evaluation studies, relying solely on automatic metrics like ROUGE to assess summary quality
- The dual-agent reinforcement learning framework introduces significant complexity that may affect reproducibility and training stability
- Performance gains are most pronounced on the Newsroom dataset, suggesting potential sensitivity to dataset characteristics and limited generalizability

## Confidence
- **High confidence** in the novelty and theoretical framework of the dual-agent approach
- **Medium confidence** in the reported performance metrics and dataset-specific results
- **Low confidence** in the method's generalizability and real-world applicability without human evaluation
