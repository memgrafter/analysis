# Towards Robust Feature Learning with t-vFM Similarity for Continual Learning

## Quick Facts
- arXiv ID: 2306.02335
- Source URL: https://arxiv.org/abs/2306.02335
- Reference count: 22
- This paper proposes t-vMF similarity for continual learning, achieving 67.98%±1.29 accuracy on Seq-CIFAR-10 with buffer size 200

## Executive Summary
This paper addresses catastrophic forgetting in continual learning by improving feature learning through a novel similarity metric. The authors replace cosine similarity in supervised contrastive loss with t-vMF (student-t von Mises-Fisher) similarity to create more robust representations under data imbalance. Experiments on Seq-CIFAR-10 demonstrate that this approach outperforms several strong baselines, particularly with smaller buffer sizes, showing promise for memory-efficient continual learning systems.

## Method Summary
The method replaces cosine similarity with t-vMF similarity in the asymmetric supervised contrastive loss (LASC) framework. The t-vMF similarity, derived from the von Mises-Fisher distribution extended with a student t-distribution, penalizes large angles between features more strongly than cosine similarity. This encourages tighter clustering of same-class samples, mitigating the impact of imbalanced training data. The approach uses a buffer replay strategy with asymmetric sampling, where anchor samples are selected only from current training data while buffer samples maintain old knowledge. The model employs a ResNet-18 backbone with a 2-layer projection MLP (128-dim) and trains with temperature scaling and concentration parameters optimized for continual learning settings.

## Key Results
- Achieves 67.98%±1.29 accuracy on Seq-CIFAR-10 with buffer size 200 in class-incremental settings
- Outperforms strong baselines including BiC, LWM, and LAFTR across multiple buffer sizes
- Shows competitive performance with larger buffers (500), demonstrating effectiveness across memory constraints
- Reduces intra-class variance compared to cosine similarity, leading to more robust feature representations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Replacing cosine similarity with t-vMF similarity reduces intra-class variance, improving robustness under data imbalance
- Mechanism: The t-vMF similarity function penalizes large angles between features more strongly than cosine similarity, encouraging tighter clustering of same-class samples
- Core assumption: Intra-class variance due to data imbalance degrades continual learning performance; reducing this variance via a tighter similarity metric improves robustness
- Evidence anchors:
  - [abstract] "due to the data imbalance during the training, there are still challenges in learning better representations... we suggest using a different similarity metric instead of cosine similarity in supervised contrastive loss in order to learn more robust representations."
  - [section 2] "cosine similarity within the supervised contrastive loss, can extract features with large within-class variance, resulting in degraded model performance."
  - [corpus] Weak - no direct corpus evidence provided.
- Break condition: If data distribution is balanced or base encoder already produces low intra-class variance, t-vMF may not yield significant improvements

### Mechanism 2
- Claim: Asymmetric sampling strategy focuses on current task samples as anchors, improving adaptation while preserving old knowledge
- Mechanism: By selecting anchor samples only from current learning batch, the model prioritizes learning discriminative features for current task while buffer samples maintain old knowledge
- Core assumption: Focusing contrastive learning on current task samples enhances task-specific feature learning without losing old task representations
- Evidence anchors:
  - [section 2] "Differ from (Mai et al., 2021a), LASC selects anchor samples only from current training data rather than consider all the samples in the training stage."
  - [section 3] "Our proposed method outperforms all the baselines with buffer 200, which indicates that the t-vMF similarity shows promise."
  - [corpus] Weak - no direct corpus evidence provided.
- Break condition: If buffer size is too small or task distribution is highly non-stationary, asymmetric sampling may lead to under-representation of older tasks

### Mechanism 3
- Claim: Temperature scaling (τ) and concentration parameter (κ) jointly control trade-off between discriminative power and generalization
- Mechanism: Temperature τ scales similarity logits controlling probability distribution sharpness; κ adjusts von Mises-Fisher distribution concentration influencing feature clustering tightness
- Core assumption: Proper tuning of τ and κ is critical for optimal continual learning performance
- Evidence anchors:
  - [section 2] "Apply a t-distributed profile function ft(d; κ) = 1/(1 + 1/2 κd²) on p(˜zi; ˜zp, κ), the equation of t-vFM similarity function between two features..."
  - [section 3] "The value of κ in Equation 3 is set to 16."
  - [corpus] Weak - no direct corpus evidence provided.
- Break condition: If τ is too high or κ poorly tuned, model may overfit to current tasks or fail to learn discriminative features

- Component map: Input -> Base encoder (ResNet-18) -> Projection MLP (128-dim) -> t-vMF similarity -> Loss computation -> Parameter update
- Critical path: Input → Base encoder → Projection MLP → t-vMF similarity → Loss computation → Parameter update
- Design tradeoffs:
  - Buffer size vs. memory constraints: Larger buffers improve performance but increase memory usage
  - κ value vs. feature clustering: Higher κ values lead to tighter clustering but may reduce generalization
  - Temperature τ vs. gradient magnitude: Lower τ values amplify gradients but may cause instability
- Failure signatures:
  - High intra-class variance: Indicates poor feature learning or inadequate buffer size
  - Catastrophic forgetting: Suggests insufficient buffer samples or ineffective loss function
  - Overfitting: May occur if τ is too low or κ is too high

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does t-vMF similarity metric specifically affect intra-class variance reduction compared to other similarity metrics like cosine similarity or Euclidean distance in continual learning settings?
- Basis in paper: [explicit] Paper states cosine similarity "can extract features with large within-class variance, resulting in degraded model performance" and proposes t-vMF to "enhance the stability and reliability of feature extraction"
- Why unresolved: Paper demonstrates improved performance but doesn't provide quantitative analysis of how t-vMF specifically reduces intra-class variance compared to alternatives
- What evidence would resolve it: Experiments comparing t-vMF with other similarity metrics while measuring intra-class variance directly, along with analysis of how different κ values affect variance reduction

### Open Question 2
- Question: What is the optimal value of the concentration parameter κ for t-vMF similarity across different continual learning scenarios and buffer sizes?
- Basis in paper: [explicit] Paper mentions "The larger value κ has, that smaller compact region between two representation is" and shows results with κ=16, but also reports experiments with κ=4, 16, and 32 without clear guidance
- Why unresolved: Paper demonstrates different κ values perform differently (κ=32 best for class incremental, κ=4 best for task incremental with buffer 500) but doesn't provide principled approach for selecting κ
- What evidence would resolve it: Systematic experiments across various continual learning scenarios showing how κ should be tuned based on factors like buffer size, task complexity, and dataset characteristics

### Open Question 3
- Question: How does t-vMF similarity approach generalize to more complex continual learning scenarios beyond Seq-CIFAR-10?
- Basis in paper: [inferred] Paper only evaluates on Seq-CIFAR-10 with specific buffer sizes and incremental learning settings
- Why unresolved: Experimental scope limited to single dataset and specific incremental learning settings, leaving questions about scalability and adaptability to more challenging scenarios
- What evidence would resolve it: Extensive experiments on diverse datasets (e.g., ImageNet-100, CORe50) and various continual learning scenarios including online learning, class-incremental with more classes, and task-incremental with more tasks

## Limitations
- Limited evaluation to a single benchmark (Seq-CIFAR-10) without broader validation across datasets or task types
- Theoretical claims about why t-vMF reduces intra-class variance more effectively than alternatives lack empirical validation
- Buffer management strategy and class balance enforcement during training are not fully specified, creating potential reproducibility challenges

## Confidence
- High confidence: Core methodology of replacing cosine similarity with t-vMF in supervised contrastive loss is technically sound and implementable
- Medium confidence: Reported performance improvements (67.98%±1.29 accuracy with buffer 200) are plausible given experimental setup, though limited to one benchmark
- Low confidence: Theoretical claims about why t-vMF specifically reduces intra-class variance more effectively than alternatives lack empirical validation
