# Efficiently Upgrading Multilingual Machine Translation Models to Support More Languages

## Quick Facts
- arXiv ID: 2302.03528
- Source URL: https://arxiv.org/abs/2302.03528
- Authors: 
- Reference count: 17
- Primary result: Models exceed baseline performance with 30% less computation or match larger baselines with 50% less computation

## Executive Summary
This paper addresses the challenge of efficiently adding new languages to existing multilingual machine translation (MMT) models, which requires updating vocabulary and potentially changing model architecture. The authors propose a three-part method: careful parameter initialization, learning rate scaling to prevent catastrophic forgetting, and strategic data up-sampling. Their approach enables models to exceed baseline performance with significantly less computation or match larger models with over 50% less computation.

## Method Summary
The method involves three key techniques for upgrading MMT models: (1) initializing new parameters using <unk> embeddings to preserve semantic consistency, (2) scaling down learning rates for reused parameters while maintaining or increasing rates for new parameters to prevent catastrophic forgetting, and (3) up-sampling data from new languages and related low-resource languages to accelerate learning of new directions. The approach was tested on models ranging from 20 to 25 languages, comparing upgraded models against baselines trained from scratch.

## Key Results
- Upgraded models exceeded same-sized baseline performance with 30% less computation
- Models matched larger baseline performance with over 50% less computation
- Learning rate scaling with factor 0.5 and up-sampling by factor 5 provided optimal balance between new language learning and old language retention

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Initializing new parameters using <unk> embeddings preserves semantic consistency with existing vocabulary space.
- Mechanism: <unk> embeddings act as a neutral baseline that doesn't introduce strong priors about specific tokens, allowing new tokens to be learned without conflicting with existing embedding relationships.
- Core assumption: The <unk> embedding represents a suitable "neutral" starting point that doesn't bias learning toward any particular semantic direction.
- Evidence anchors: [abstract]: "we find that initializing the new embeddings with that of <unk> leads to the best performance"

### Mechanism 2
- Claim: Scaling down learning rate for reused parameters reduces catastrophic forgetting.
- Mechanism: Lower learning rate for old parameters keeps them closer to their original values, preserving knowledge about previously learned tasks while allowing new parameters to adapt rapidly.
- Core assumption: Parameter values that remain close to their pre-continual learning state better retain knowledge about old tasks.
- Evidence anchors: [abstract]: "scaling down the learning rate for reused parameters depending on whether they are copied from the old model or not"

### Mechanism 3
- Claim: Data up-sampling of new and related low-resource languages accelerates learning of new directions while maintaining balance.
- Mechanism: Increasing the frequency of new language pairs in training data provides stronger learning signals for these directions, while up-sampling related low-resource pairs prevents these directions from being forgotten.
- Core assumption: The model can effectively learn new directions when they appear more frequently in training data.
- Evidence anchors: [abstract]: "up-sampling data from new languages and related old low-resource languages"

## Architecture Onboarding

- Component map: SentencePiece tokenizer with 64K tokens → Shared source/target embeddings → 12-layer encoder → 12-layer decoder → Language-specific softmax layer
- Critical path: Embedding → Encoder layers → Decoder layers → Output layer
- Design tradeoffs:
  - Wider vs deeper: Width provides more per-layer capacity; depth provides hierarchical representation
  - Learning rate scaling vs EWC: Simpler to implement but may be less precise
  - Up-sampling vs balanced data: Faster new language learning vs stable overall performance
- Failure signatures:
  - New languages perform poorly despite up-sampling → Check learning rate for new parameters
  - Old languages degrade significantly → Verify learning rate scaling for old parameters
  - Training becomes unstable → Check initialization of new layers/parameters
- First 3 experiments:
  1. Test <unk> initialization vs random initialization for new embeddings
  2. Compare different learning rate scaling factors (0.5, 0.1, 0.05) for old parameters
  3. Experiment with different up-sampling ratios (5x, 10x, 15x) for new languages

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the effectiveness of learning rate scaling vary when adding new languages incrementally (one at a time) versus in bulk (multiple languages simultaneously)?
- Basis in paper: [inferred] The paper only experiments with adding new languages in bulk and mentions this as a limitation, noting that continuous addition of languages one by one was not investigated.
- Why unresolved: The paper does not explore incremental language addition scenarios, leaving open whether the learning rate scaling technique would be equally effective when languages are added gradually over multiple training phases.
- What evidence would resolve it: Experiments comparing learning rate scaling effectiveness across incremental versus bulk language addition scenarios, measuring both final performance and catastrophic forgetting across multiple addition stages.

### Open Question 2
- Question: What is the optimal up-sampling ratio for different resource levels of new languages (high, mid, low, very low resource) when growing multilingual translation models?
- Basis in paper: [explicit] The paper uses an up-sampling factor of 5 based on previous studies but notes that up-sampling too much (e.g., α = 10) worsens old direction performance while not improving new directions, suggesting the need for language-specific optimization.
- Why unresolved: The paper only experiments with one up-sampling ratio (α = 5) and notes that excessive up-sampling harms performance, but does not systematically explore optimal ratios for different resource levels or provide a principled method for determining the best ratio.
- What evidence would resolve it: A comprehensive study varying up-sampling ratios across different resource levels of new languages, identifying optimal ratios that maximize new language performance while minimizing degradation of old languages.

### Open Question 3
- Question: How does the choice of initialization method for new parameters affect long-term model performance and convergence speed when scaling models to thousands of languages?
- Basis in paper: [explicit] The paper explores different initialization methods (random, <unk>, concatenation with noise, averaged weights) and finds some methods superior, but only within the context of adding 5 new languages to 20 existing ones.
- Why unresolved: The experiments are limited to small-scale language additions, and it remains unclear whether the observed initialization benefits would scale to much larger multilingual models with thousands of languages and more significant architectural changes.
- What evidence would resolve it: Large-scale experiments scaling models to support hundreds or thousands of languages, comparing convergence speed and final performance across different initialization strategies under various architectural modifications.

## Limitations

- Data-specific limitations: The study uses a specific subset of NLLB data without mined or back-translated examples, limiting reproducibility and generalizability to other data scenarios.
- Evaluation scope: The analysis is limited to specific language groups (20 seed + 5 new languages) without exploring broader language diversity or typological differences.
- Implementation details: Several implementation specifics are underspecified, including exact learning rate scaling factors for different parameter groups and up-sampling ratios.

## Confidence

**High confidence:** The core finding that the proposed approach reduces computation by 30-50% while maintaining or improving translation quality is well-supported by experimental results across multiple model configurations.

**Medium confidence:** The three technical mechanisms (initialization, learning rate scaling, up-sampling) are logically sound and show empirical benefits, but the exact optimal values for hyperparameters like learning rate scaling factors and up-sampling ratios remain unclear.

**Low confidence:** The claim that <unk> initialization is optimal lacks theoretical justification and may not hold for all tokenizer implementations or model training scenarios.

## Next Checks

1. **Ablation study on learning rate scaling factors:** Systematically test different learning rate scaling values (0.1, 0.2, 0.5, 0.8) for old parameters while keeping new parameters at default rate to identify the optimal balance between retaining old knowledge and learning new languages.

2. **Cross-validation across language families:** Apply the methodology to language pairs from different language families (e.g., Indo-European, Afro-Asiatic, Sino-Tibetan) to test whether the approach generalizes beyond the specific language groups used in the study.

3. **Alternative initialization strategies:** Compare <unk> initialization against other strategies such as averaging existing embeddings, using language-specific neutral embeddings, or learning initialization through meta-learning to validate the specific choice of <unk> initialization.
