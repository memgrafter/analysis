# SSGD: A smartphone screen glass dataset for defect detection

## Quick Facts
- arXiv ID: 2303.06673
- Source URL: https://arxiv.org/abs/2303.06673
- Reference count: 0
- Key outcome: First publicly available dataset for smartphone screen glass defect detection, with 2504 high-resolution images and seven defect types; CNN models (especially ATSS) outperform Transformers in accuracy and speed

## Executive Summary
This paper introduces SSGD, the first publicly available dataset for defect detection on smartphone screen glass, containing 2504 high-resolution images across two production workstations. The dataset captures seven common defect types with varying sizes and distributions. Extensive benchmarking of both CNN-based and Transformer-based object detection frameworks reveals that CNN models, particularly ATSS, achieve superior performance in both accuracy and inference speed for this high-resolution industrial defect detection task.

## Method Summary
The study benchmarks multiple object detection frameworks on the SSGD dataset, using ResNet-50 for CNN models and various Vision Transformers. CNN models employ SGD optimizer with 2× schedule (24 epochs), batch size 16, and multi-scale training, while Transformers use AdamW optimizer, 2× schedule, batch size 8, and single-scale training. All models use 1500×1000 input resolution. Performance is evaluated using 5-fold cross-validation with standard COCO metrics (AP, AP50, AP75, APS, APM, APL).

## Key Results
- ATSS (anchor-free CNN) achieves the best overall performance across all evaluation metrics
- CNN models significantly outperform Transformer-based methods in both accuracy and inference speed
- Multi-scale training proves essential for handling the varying defect sizes in the dataset
- Vision Transformers show inferior performance on high-resolution defect detection despite architectural novelty

## Why This Works (Mechanism)

### Mechanism 1
- Claim: High-resolution images with adaptive training sample selection improve detection of small and diverse defect types
- Mechanism: The dataset contains 2504 high-resolution (1500×1000) images with seven defect types captured on two workstations, providing varied defect scales and distributions. ATSS uses an adaptive training sample selection strategy to better handle this heterogeneity, leading to superior performance
- Core assumption: Defect detection benefits from high-resolution inputs and adaptive sampling when defects vary in size and type
- Evidence anchors:
  - [abstract] "ATSS, outperform Transformer-based methods in accuracy and speed for this high-resolution defect detection task"
  - [section] "Due to an adaptive training sample selection strategy, ATSS obtains the best performance in all ResNet-50-based models"
- Break condition: If defect types or sizes become more uniform, simpler sampling strategies may suffice

### Mechanism 2
- Claim: Vision Transformers are slower and less accurate than CNNs on high-resolution defect detection tasks
- Mechanism: Transformers like Swin-T process high-resolution images at lower FPS and achieve lower AP than ResNet-50-based CNNs, likely due to inefficient spatial token handling at large resolutions
- Core assumption: CNNs are more efficient for dense, high-resolution defect detection than current Vision Transformers
- Evidence anchors:
  - [abstract] "CNN models, especially ATSS, outperform Transformer-based methods in accuracy and speed for this high-resolution defect detection task"
  - [section] "When compared to ResNet-50, Swin-T gets 3.2 AP gains. Nevertheless, Transformer-based models have an obvious disadvantage in the speed that is required in industrial scenarios"
- Break condition: If Vision Transformers are optimized for high-resolution inputs or industrial latency requirements change

### Mechanism 3
- Claim: Multi-scale training is crucial for robust defect detection across varying defect sizes
- Mechanism: The dataset contains small, medium, and large defects; multi-scale training (short side [800,1500], long side ≤2250) exposes the model to varied resolutions, improving generalization
- Core assumption: Defect sizes in production vary widely, so models must learn from multi-scale data
- Evidence anchors:
  - [section] "We also adopt the multi-scale training, where the short side of input images is randomly resized to [800, 1500] pixels, and the long side is at most 2250 pixels"
  - [section] "Part I: the amount of different types detection object issmall: 241, middle: 378, large: 1038"
- Break condition: If defect sizes become more predictable or constrained, single-scale training may suffice

## Limitations
- Results may be domain-specific to smartphone screen glass inspection and require validation on other defect detection tasks
- Performance gap between CNN and Transformer models may narrow as Vision Transformers are optimized for high-resolution industrial inspection
- 5-fold cross-validation may not fully capture real-world production variability

## Confidence
- **High confidence**: SSGD dataset creation and benchmark results showing CNN superiority in speed and accuracy
- **Medium confidence**: Generalizability of ATSS advantages to other defect detection scenarios
- **Medium confidence**: Comparative performance rankings between different CNN and Transformer architectures
