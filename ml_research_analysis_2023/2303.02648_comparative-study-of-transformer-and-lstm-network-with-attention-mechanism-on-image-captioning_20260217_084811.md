# Comparative study of Transformer and LSTM Network with attention mechanism on Image Captioning

## Quick Facts
- arXiv ID: 2303.02648
- Source URL: https://arxiv.org/abs/2303.02648
- Reference count: 30
- Transformer achieved 48.8% validation accuracy and 0.45 BLEU score after 10 epochs

## Executive Summary
This paper presents a comparative study of Transformer and LSTM with attention mechanism for image captioning using the MS-COCO dataset. Both models utilize a pretrained Inception-V3 CNN encoder for feature extraction. The study finds that the Transformer model outperforms the LSTM with attention block, achieving a BLEU score of 0.45 compared to 0.3 for LSTM after 10 epochs of training. The Transformer's attention mechanism addresses the vanishing gradient problem in traditional RNN and LSTM models by calculating word importance in parallel rather than sequentially.

## Method Summary
The study compares two neural network architectures for image captioning on the MS-COCO dataset. Both models use Inception-V3 as a CNN encoder to extract image features, which are then processed by either a Transformer decoder or an LSTM with attention mechanism. The models were trained for 10 epochs on AWS g4dn.xlarge GPU instances. The Transformer uses multi-head attention to process all input tokens in parallel, while the LSTM uses an attention mechanism to focus on relevant image regions. Performance was evaluated using BLEU score, with the Transformer achieving 0.45 compared to 0.3 for LSTM.

## Key Results
- Transformer model achieved 48.8% validation accuracy and 0.45 BLEU score after 10 epochs
- LSTM with attention achieved 0.3 BLEU score after 10 epochs
- Transformer addresses vanishing gradient problems through parallel attention computation
- Both models used Inception-V3 for feature extraction from MS-COCO images

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Transformer's attention mechanism directly addresses vanishing gradient problems in RNN/LSTM by calculating word importance without sequential dependencies.
- Mechanism: Self-attention computes weighted context vectors across all input tokens in parallel, eliminating sequential processing bottlenecks that cause gradient decay.
- Core assumption: Parallel attention computation preserves gradient flow better than sequential recurrence for long sequences.
- Evidence anchors:
  - [abstract]: "The Transformer model addresses the vanishing gradient problem in traditional RNN and LSTM models by using an attention mechanism to calculate the importance of each input text."
  - [section]: "The attention mechanism, which calculates the importance of each input text, is utilised to overcome this problem."
  - [corpus]: Weak signal. Nearest neighbor papers mention attention-based models but do not directly discuss gradient flow.
- Break condition: If attention weights become uniform or the model reverts to sequential processing, gradient benefits vanish.

### Mechanism 2
- Claim: Inception-V3 CNN encoder provides superior visual feature extraction that feeds both Transformer and LSTM models with discriminative spatial information.
- Mechanism: Inception-V3's parallel convolutional filters capture multi-scale visual patterns, encoding rich features into a numpy file used by both caption generators.
- Core assumption: High-quality visual embeddings are necessary for both attention-based and transformer-based caption generation.
- Evidence anchors:
  - [section]: "For both the models we have used pretrained Inception-V3 CNN encoder for feature extraction of the images."
  - [section]: "Among these different layers , Inception V3 has been one of the most popular choices mainly because of its higher efficiency , is faster and is computationally less expensive."
  - [corpus]: Weak signal. No direct comparison of Inception-V3 vs other encoders in neighbors.
- Break condition: If the encoder fails to extract discriminative features, caption quality degrades regardless of decoder architecture.

### Mechanism 3
- Claim: BLEU score metric effectively captures n-gram overlap between generated and reference captions, correlating with caption quality.
- Mechanism: BLEU calculates precision-based n-gram matches (1-4 grams) between machine-generated text and human references, providing a scalar accuracy measure.
- Core assumption: N-gram overlap is a sufficient proxy for caption relevance and fluency.
- Evidence anchors:
  - [section]: "The Bilingual Evaluation Understudy score (BLEU) is used to checked the accuracy of caption generated by both models."
  - [section]: "BLEU evaluates the similarity between the machine-generated text and the reference text through the calculation of n-gram overlap, with higher scores indicating a closer match."
  - [corpus]: Weak signal. Neighbors discuss attention and transformer architectures but do not analyze BLEU evaluation.
- Break condition: If reference captions are poor or diverse, BLEU may not reflect true caption quality.

## Architecture Onboarding

- Component map: Inception-V3 CNN → Image feature extraction → numpy feature file → Transformer/LSTM+attention decoder → Sequence generation → BLEU evaluation
- Critical path: Feature extraction → Decoder input → Attention/transformer processing → Caption generation → BLEU evaluation
- Design tradeoffs:
  - Transformer: Parallel processing, better gradient flow, higher compute cost
  - LSTM+attention: Sequential processing, simpler, potentially slower convergence
  - Inception-V3: Rich features but fixed CNN capacity vs. end-to-end learning
- Failure signatures:
  - Low BLEU scores → Poor attention alignment or feature extraction
  - Overfitting → High train accuracy, low validation accuracy
  - Vanishing gradients → LSTM fails to learn long-range dependencies
- First 3 experiments:
  1. Replace Inception-V3 with ResNet-50 encoder; compare BLEU scores.
  2. Train LSTM without attention; measure performance drop.
  3. Reduce Transformer to single-head attention; observe accuracy change.

## Limitations

- Limited training duration (only 10 epochs) may not represent full model convergence
- Architectural details of attention mechanisms are underspecified, making exact reproduction difficult
- Evaluation relies solely on BLEU score, which may not fully capture caption quality and relevance

## Confidence

- High Confidence: The fundamental claim that Transformers can outperform LSTMs in image captioning due to attention mechanisms and parallel processing capabilities
- Medium Confidence: The specific performance metrics (BLEU scores of 0.45 vs 0.3) and validation accuracy of 48.8% for Transformer, given the limited training duration
- Low Confidence: The attribution of performance differences solely to architectural differences without accounting for hyperparameter optimization or training stability
