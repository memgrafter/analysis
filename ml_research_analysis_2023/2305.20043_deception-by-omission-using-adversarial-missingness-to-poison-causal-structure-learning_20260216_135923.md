# Deception by Omission: Using Adversarial Missingness to Poison Causal Structure Learning

## Quick Facts
- **arXiv ID**: 2305.20043
- **Source URL**: https://arxiv.org/abs/2305.20043
- **Reference count**: 40
- **Key outcome**: Adversarial missingness attacks successfully manipulate causal structure learning by selectively withholding data, achieving up to 100% success in edge deletion with controlled missingness rates.

## Executive Summary
This paper introduces adversarial missingness (AM), a novel attack model that poisons causal structure learning by strategically omitting portions of true training data. Unlike traditional data poisoning that modifies data, AM exploits the modeler's assumption of missing-at-random data to bias learned causal structures. The authors propose two methods: rejection sampling with provable properties for arbitrary structural causal models (SCMs), and a neural network-based heuristic (LAMM) for Gaussian SCMs. Experiments on synthetic and real data demonstrate that AM attacks can effectively remove targeted edges while maintaining low missingness rates, outperforming random missingness attacks across multiple structure learning algorithms.

## Method Summary
The adversary constructs an adversarial SCM and missingness mechanism to manipulate the learned causal structure. Two approaches are presented: rejection sampling, which ensures the observed data distribution matches the adversarial SCM using weights based on probability ratios, and LAMM, which uses a neural network to learn an effective missingness distribution by minimizing KL divergence between the adversarial SCM and the modeler's learned structure. The modeler applies structure learning algorithms (MissDAG, MissPC, NOTEARS) to partially observed data, while the adversary optimizes missingness patterns to achieve the desired structural manipulation.

## Key Results
- LAMM achieves 100% success in removing a target edge from a 3-node Gaussian SCM with only 27% overall missingness
- On the Sachs dataset, LAMM consistently outperforms random missingness attacks with 70-95% success rates
- The attack remains effective against multiple structure learning algorithms including those specifically designed to handle missing data (MissDAG, MissPC)
- Localized rejection sampling enables targeted edge deletion while controlling the missingness rate

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Rejection sampling ensures partially observed data from the true SCM looks like it was sampled from the adversarial SCM
- Mechanism: Uses missingness mechanism that preferentially selects observation patterns where observed features are more probable under the adversarial distribution, implemented via rejection sampling with weights based on probability ratios
- Core assumption: Adversary can construct an adversarial SCM that is β-indistinguishable from the true SCM and Markovian with respect to the target DAG
- Break condition: If adversarial SCM cannot be β-indistinguishable or maximum ratio Λ* is too large, missingness rate becomes prohibitive

### Mechanism 2
- Claim: LAMM learns an adversarial missingness mechanism that directs structure learning to converge to the adversarial SCM
- Mechanism: Parameterizes missingness distribution with neural network and optimizes it to minimize KL divergence between adversarial SCM and modeler's learned structure
- Core assumption: Modeler's structure learning algorithm can be approximated as a differentiable process depending on missingness mechanism
- Break condition: If differentiable approximation is poor or neural network cannot learn effective mechanism within constraints

### Mechanism 3
- Claim: Localized rejection sampling allows deletion of specific edges while controlling missingness rate
- Mechanism: Masks only a subset of variables using probabilities depending only on the value of those variables
- Core assumption: Adversarial SCM preserves dependence of masked variables on unmasked variables
- Break condition: If conditional distributions cannot be matched or maximum ratio Λ is too large, missingness rate becomes prohibitive

## Architecture Onboarding

- **Component map**: True SCM (θp) -> Adversary (constructs θα and PR|X) -> Missingness mechanism -> Partially observed data -> Modeler (structure learning algorithm) -> Learned DAG -> (Optional) Data auditor

- **Critical path**: 
  1. Adversary constructs adversarial SCM and missingness mechanism
  2. Adversary applies missingness mechanism to true data to generate partially observed training data
  3. Modeler uses structure learning algorithm to learn causal structure from partially observed data
  4. (Optional) Data auditor verifies plausibility of learned SCM

- **Design tradeoffs**:
  - Rejection sampling vs. neural network heuristic: provable properties vs. sample efficiency
  - Localized vs. global missingness: targeted edge deletion vs. construction complexity
  - β-indistinguishability vs. attack success: more indistinguishable SCM may be less effective at manipulation

- **Failure signatures**:
  - High missingness rate causing modeler to reject training data
  - Modeler's algorithm fails to converge or converges to unintended structure
  - Data auditor detects learned SCM is implausible

- **First 3 experiments**:
  1. Implement rejection sampling on simple Gaussian SCM with known target edge to delete
  2. Implement LAMM algorithm on same SCM and compare performance to rejection sampling
  3. Test attacks against different structure learning algorithms (MissDAG, MissPC, NOTEARS)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can adversarial missingness attacks be successfully defended against by existing causal structure learning algorithms that explicitly model missing data?
- Basis in paper: [inferred] Paper shows LAMM succeeds against MissDAG and MissPC but doesn't explore defensive strategies
- Why unresolved: Experiments demonstrate attack success but not whether algorithms can be modified to resist AM attacks while handling benign missing data
- What evidence would resolve it: Experiments showing modified MissDAG/MissPC can maintain accurate learning under AM attacks while performing well on benign missing data

### Open Question 2
- Question: What is the fundamental trade-off between attack success rate and missingness rate in AM attacks, and how does this vary across different SCM parameterizations and DAG structures?
- Basis in paper: [explicit] Paper mentions exploring trade-off using Lagrange multiplier λ but provides limited characterization across settings
- Why unresolved: Experiments examine specific λ values for individual datasets rather than systematically mapping success rate vs. missingness rate curves for various SCM families and DAG structures
- What evidence would resolve it: Systematic experiments varying λ and measuring both success rate and missingness rate across multiple SCM parameterizations and DAG structures

### Open Question 3
- Question: How does choice of initialization affect robustness of AM attacks when modeler uses different causal structure learning algorithms?
- Basis in paper: [explicit] Paper uses multiple initializations for MissDAG but notes modeler's initialization scheme is unknown and could cause overfitting
- Why unresolved: Experiments only test limited initialization schemes and don't explore how sensitive LAMM is to initialization choices across different learning algorithms
- What evidence would resolve it: Experiments varying initialization schemes across multiple learning algorithms, measuring attack success sensitivity to initialization, and developing methods for adversary to select robust initializations

## Limitations
- Theoretical guarantees rely on existence of β-indistinguishable adversarial SCMs, which may not always be constructible
- LAMM heuristic lacks theoretical guarantees and depends heavily on quality of differentiable approximation
- Scalability concerns as number of variables grows, with computational complexity increasing significantly

## Confidence
- **High confidence**: Theoretical framework and proof of concept for rejection sampling
- **Medium confidence**: Effectiveness of LAMM across diverse SCM structures
- **Low confidence**: Scalability of approaches to large, complex causal graphs
