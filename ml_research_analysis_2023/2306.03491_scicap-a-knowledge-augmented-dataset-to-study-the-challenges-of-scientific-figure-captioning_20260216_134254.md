# SciCap+: A Knowledge Augmented Dataset to Study the Challenges of Scientific Figure Captioning

## Quick Facts
- arXiv ID: 2306.03491
- Source URL: https://arxiv.org/abs/2306.03491
- Reference count: 7
- Primary result: Knowledge-augmented captioning using mention-paragraphs and OCR tokens significantly improves scientific figure captioning performance

## Executive Summary
This paper addresses the challenge of scientific figure captioning by extending the SciCap dataset with mention-paragraphs (text paragraphs referencing figures) and OCR tokens (text extracted from figures), creating the SciCap+ dataset. The authors use the M4C-Captioner model, a multimodal transformer-based architecture with a pointer network, as a baseline. Results show that leveraging knowledge from multiple modalities, particularly mention-paragraphs and OCR tokens, significantly boosts automatic evaluation metrics compared to using only figure inputs. Human evaluations reveal that while model-generated captions are nearly as informative as ground-truth captions, both humans and models struggle with highly informative scientific captions, highlighting the inherent difficulty of the task.

## Method Summary
The study extends SciCap by adding mention-paragraphs and OCR tokens to create SciCap+. The M4C-Captioner model uses a multimodal transformer architecture with four transformer layers, 12 attention heads, and a pointer network. Input features are extracted using pre-trained models: ResNet-152 for figures, SciBERT for mention-paragraphs, and FastText+PHOC+Faster R-CNN for OCR tokens. The model is trained using Adam optimizer with learning rate 0.001, batch size 128, and maximum 67 decoding steps. The approach integrates visual features from figures, textual knowledge from mention-paragraphs, and scientific terminology from OCR tokens to generate informative captions.

## Key Results
- Using mention-paragraphs and OCR tokens significantly improves automatic evaluation metrics (BLEU-4, METEOR, ROUGE-L, SPICE, CIDEr) compared to figure-only input
- Model-generated captions are nearly as informative as ground-truth captions according to human evaluation
- Both humans and models struggle to write highly informative scientific figure captions, highlighting task difficulty

- Core assumption: Scientific figure captioning benefits from joint learning across modalities rather than treating each modality separately

## Architecture Onboarding

- Component map: Figure/ResNet-152 → Mention/SciBERT → OCR/FastText+PHOC+Faster R-CNN → M4C-Captioner (4 transformer layers, 12 attention heads, pointer network) → Output caption
- Critical path: Figure visual features + Mention text features + OCR text/visual features → Joint multimodal transformer encoding → Pointer network decoding → Caption generation
- Design tradeoffs: Using pre-trained models (ResNet-152, SciBERT, FastText) provides strong initial representations but requires careful fine-tuning; the pointer network adds complexity but handles scientific terminology
- Failure signatures: Low scores across all metrics indicate insufficient multimodal knowledge; poor CIDEr scores suggest missing scientific terminology; degraded performance with mention/OCR removal confirms their importance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What specific visual encoder architecture would be most effective for scientific figures, given that ResNet-152 performed poorly?
- Basis in paper: [explicit] The authors note that removing visual features from figures increased CIDEr scores, indicating ResNet-152 is not well-suited for this task
- Why unresolved: The paper only experimented with ResNet-152 and did not explore alternative visual encoders specifically designed for scientific figures
- What evidence would resolve it: Comparative experiments using different visual encoders (e.g., specialized encoders trained on scientific figures) and measuring their impact on caption quality metrics

### Open Question 2
- Question: How does the quality of OCR extraction affect the overall performance of scientific figure captioning models?
- Basis in paper: [explicit] The authors use Google Vision OCR API for OCR extraction and mention that OCR tokens significantly boost performance
- Why unresolved: The paper does not systematically evaluate how variations in OCR quality (e.g., accuracy, completeness) impact captioning performance
- What evidence would resolve it: Controlled experiments varying OCR quality (e.g., using different OCR tools or introducing noise) and measuring the corresponding changes in caption quality

### Open Question 3
- Question: What is the optimal balance between using mention-paragraphs and OCR tokens for knowledge augmentation in scientific figure captioning?
- Basis in paper: [explicit] The authors show that both mention-paragraphs and OCR tokens improve performance, but do not explore the optimal combination or weighting of these knowledge sources
- Why unresolved: The experiments use fixed combinations of knowledge sources without exploring the impact of varying their relative importance
- What evidence would resolve it: Systematic ablation studies varying the relative contribution of mention-paragraphs and OCR tokens to determine the optimal balance for maximizing caption quality

## Limitations
- Evaluation framework relies heavily on automatic metrics that may not fully capture scientific caption informativeness
- Human evaluation sample size of 100 captions per model is modest for complex scientific content
- OCR extraction pipeline details remain unspecified, potentially impacting reproducibility

## Confidence

**High Confidence**: Multimodal transformer architecture with pointer network is effective for scientific figure captioning, as evidenced by consistent improvements across all automatic metrics when combining figure, mention, and OCR inputs. The ablation study showing performance degradation when removing mention or OCR features provides strong evidence for their contributions.

**Medium Confidence**: Mention-paragraphs significantly improve caption quality by providing domain-specific context. While the paper demonstrates this through automatic metrics, the mechanism is primarily supported by a single illustrative example rather than comprehensive qualitative analysis. The claim that OCR tokens are crucial for scientific terminology is supported by automatic metric improvements but lacks systematic validation of OCR extraction quality.

**Low Confidence**: The assertion that scientific figure captioning is inherently difficult for both humans and models. While the paper shows that model-generated captions are nearly as informative as ground-truth captions, this comparison is limited by the small human evaluation sample and doesn't account for potential human annotator expertise variation or the specific scientific domain expertise required.

## Next Checks

1. **OCR Extraction Pipeline Validation**: Replicate the OCR extraction process on a held-out set of figures and measure OCR accuracy and completeness. Compare caption quality when using perfect OCR (manually corrected) versus extracted OCR to quantify the impact of OCR noise on final performance.

2. **Mention-Paragraph Relevance Analysis**: Implement a filtering mechanism to identify and remove irrelevant mention-paragraphs, then retrain the model to measure performance changes. Conduct a systematic study correlating mention relevance scores with caption quality improvements to validate the claim about mention-paragraphs providing useful context.

3. **Human Evaluation Expansion**: Scale up human evaluation to 500+ captions per model across multiple scientific domains. Include expert domain scientists as annotators and measure inter-annotator agreement, then correlate human judgments with automatic metric scores to identify which metrics best predict human-rated informativeness in scientific contexts.
