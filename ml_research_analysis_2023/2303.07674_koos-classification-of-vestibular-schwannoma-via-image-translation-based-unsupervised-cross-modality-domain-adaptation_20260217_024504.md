# Koos Classification of Vestibular Schwannoma via Image Translation-Based Unsupervised Cross-Modality Domain Adaptation

## Quick Facts
- arXiv ID: 2303.07674
- Source URL: https://arxiv.org/abs/2303.07674
- Reference count: 21
- Key outcome: Achieved rank 1 in crossMoDA 2022 challenge with MA-MAE of 0.2148 (validation) and 0.26 (test)

## Executive Summary
This study tackles the challenge of Koos classification for vestibular schwannoma using high-resolution T2 (hrT2) MRI scans, which lack annotations but are safer and more cost-effective than contrast-enhanced T1 (ceT1) scans. The proposed method employs unsupervised cross-modality domain adaptation by translating annotated ceT1 scans into hrT2 modality using CycleGAN, then training a segmentation model on the generated pseudo hrT2 scans to segment VS and adjacent brain structures. Handcrafted features extracted from these segmentations are used by a random forest classifier to predict Koos grades. The method achieved top ranking in the crossMoDA 2022 challenge, demonstrating the effectiveness of image translation-based domain adaptation for this clinical task.

## Method Summary
The method uses CycleGAN to translate annotated ceT1 scans into pseudo hrT2 modality, bridging the supervision gap between labeled and unlabeled data. A segmentation model trained on these translated images segments VS and seven adjacent brain structures in real hrT2 scans. Handcrafted features including volume, shortest distance to VS (DistVS), and contact surface with VS (SurfVS) are extracted from these segmentations. A random forest classifier then predicts Koos grades from these features. The pipeline leverages nnU-Net for automated segmentation configuration and uses 2D CycleGAN for computational efficiency, with images resized to 256×256.

## Key Results
- Achieved rank 1 in crossMoDA 2022 challenge Koos classification task
- Macro-Averaged Mean Absolute Error (MA-MAE) of 0.2148 on validation set
- MA-MAE of 0.26 on test set
- Outperformed fully-supervised approaches that require annotated hrT2 data

## Why This Works (Mechanism)

### Mechanism 1
CycleGAN-based image translation transfers supervision from ceT1 to hrT2 by learning a mapping that preserves anatomical structures while converting contrast characteristics. The bidirectional mappings between ceT1 and hrT2 domains are learned using adversarial loss and cycle consistency loss, enabling supervised learning on translated pseudo hrT2 images with ceT1 annotations. The anatomical correspondence between modalities is sufficient for cycle consistency to preserve segmentation-relevant features.

### Mechanism 2
Random forest classification using handcrafted features from brain structure segmentations captures Koos grade-relevant patterns. Segmentation of 8 brain structures provides volumetric and spatial relationship features (volume, DistVS, SurfVS) that correlate with Koos grade criteria. These handcrafted features contain sufficient discriminative information to predict Koos grades based on the anatomical criteria.

### Mechanism 3
nnU-Net's automated configuration adapts effectively to the cross-modality segmentation task without manual intervention. The automated optimization of preprocessing, network architecture, and training pipeline for specific dataset characteristics reduces domain adaptation errors. nnU-Net's configuration can handle the domain shift between translated pseudo hrT2 and real hrT2 images without requiring manual tuning.

## Architecture Onboarding

- **Component map**: ceT1 → CycleGAN translation → pseudo hrT2 + annotations → segmentation model training → real hrT2 segmentation → feature extraction → random forest classification
- **Critical path**: ceT1 → CycleGAN translation → pseudo hrT2 + annotations → segmentation model training → real hrT2 segmentation → feature extraction → random forest classification
- **Design tradeoffs**:
  - 2D vs 3D CycleGAN: 2D reduces computational cost but loses volumetric context
  - No cross-validation: Faster training but potentially less robust model
  - Handcrafted vs learned features: Interpretable but may miss complex patterns
- **Failure signatures**:
  - Poor translation quality: CycleGAN outputs look unrealistic or anatomical structures are distorted
  - Segmentation failures: nnU-Net struggles with boundary definition or confuses adjacent structures
  - Classification errors: Random forest overfitting due to limited feature diversity or underfitting due to insufficient discriminative power
- **First 3 experiments**:
  1. Qualitative inspection of CycleGAN outputs comparing translated vs real hrT2 images
  2. Segmentation performance metrics (Dice, Hausdorff) on validation set
  3. Feature importance analysis from random forest to validate feature selection

## Open Questions the Paper Calls Out

### Open Question 1
What is the optimal image size for CycleGAN translation between ceT1 and hrT2 modalities to balance computational efficiency and translation quality? The paper uses 256×256 due to computational constraints but does not explore whether this size is optimal for translation quality.

### Open Question 2
Would using more advanced domain adaptation techniques beyond CycleGAN improve Koos classification performance in unsupervised cross-modality settings? The paper only explores CycleGAN and acknowledges that performance falls short of fully-supervised approaches.

### Open Question 3
How does the choice of segmentation model architecture impact Koos classification accuracy when using features extracted from segmentation outputs? The paper uses nnU-Net's default configuration without exploring alternatives that might better handle cross-modality challenges.

### Open Question 4
Would incorporating additional handcrafted features beyond the current 8 structures and 3 feature types improve Koos classification performance? The paper suggests that improving adaptation of other brain structures related to Koos classification could enhance performance.

## Limitations
- Relies heavily on CycleGAN's ability to preserve anatomical structure during modality translation, which is validated primarily through visual inspection rather than quantitative metrics
- Assumes handcrafted features capture all relevant Koos grade criteria, but grading scale may depend on subtle contrast patterns or textural features not captured by current feature set
- nnU-Net's automated configuration effectiveness for cross-modality adaptation is assumed but not explicitly validated

## Confidence

- **High confidence**: Experimental methodology and implementation details are well-documented with clear pipeline steps and hyperparameter specifications; rank 1 achievement in crossMoDA 2022 challenge provides strong external validation
- **Medium confidence**: CycleGAN translation mechanism is theoretically sound but lacks quantitative validation of anatomical preservation specific to Koos classification features; effectiveness of specific handcrafted features for Koos grading is assumed rather than empirically validated
- **Low confidence**: Assumption that nnU-Net's automated configuration can handle domain shift between translated pseudo hrT2 and real hrT2 images is not explicitly tested or validated
