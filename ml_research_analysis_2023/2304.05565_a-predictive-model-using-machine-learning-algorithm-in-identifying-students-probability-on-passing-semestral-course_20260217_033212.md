# A Predictive Model using Machine Learning Algorithm in Identifying Students Probability on Passing Semestral Course

## Quick Facts
- arXiv ID: 2304.05565
- Source URL: https://arxiv.org/abs/2304.05565
- Reference count: 9
- Primary result: Developed predictive model achieving 0.7619 accuracy for identifying at-risk students early in semester

## Executive Summary
This study developed a machine learning predictive model to forecast student probability of passing courses during the early stages of a semester. The research employed classification and decision tree algorithms within the CRISP-DM framework to analyze academic performance data from 82 students. The model successfully identified at-risk students using six predictor variables including attendance, class performance, and exam results from prelim and midterm periods. The resulting model demonstrates strong predictive capability with accuracy of 0.7619, precision of 0.8333, recall of 0.8823, and F1 score of 0.8571.

## Method Summary
The study followed the CRISP-DM framework to develop a predictive model for student performance. Researchers collected data from an integrated academic information system, cleaning and analyzing records from 82 students. The dataset included six predictor variables (attendance, class performance, prelim and midterm exam results) and one outcome variable indicating pass/fail status. Classification and decision tree algorithms were applied to create the predictive model, which was evaluated using standard performance metrics. The methodology focused on early identification of students at risk of failing, enabling timely interventions.

## Key Results
- Predictive model achieved 0.7619 accuracy, 0.8333 precision, 0.8823 recall, and 0.8571 F1 score
- Model successfully identifies at-risk students early in the semester using six academic performance variables
- Enables educators to implement timely interventions and improve learning outcomes

## Why This Works (Mechanism)
The model works by leveraging early academic performance indicators to predict final course outcomes. By analyzing attendance patterns, class participation, and exam results from the initial weeks of the semester, the decision tree algorithms can identify patterns that correlate with eventual success or failure. The CRISP-DM framework ensures systematic data preparation and model development, while the classification algorithms effectively handle the binary nature of pass/fail outcomes.

## Limitations
- Small sample size (n=82 students) from single institution limits generalizability
- Cross-sectional data prevents establishing causal relationships
- Limited predictor variables may miss important factors affecting student performance
