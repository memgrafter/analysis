# AutoML for neuromorphic computing and application-driven co-design: asynchronous, massively parallel optimization of spiking architectures

## Quick Facts
- arXiv ID: 2302.13210
- Source URL: https://arxiv.org/abs/2302.13210
- Reference count: 14
- Primary result: The proposed AutoML-inspired approach efficiently explores neuromorphic architecture design spaces and identifies high-performance configurations for targeted applications

## Executive Summary
This paper addresses the challenge of efficiently exploring vast neuromorphic architecture design spaces through an AutoML-inspired approach. The authors integrate a parallel asynchronous model-based search (AMBS) with a spiking neural network simulation framework called spikelearn to optimize configurations across network architecture, neuron models, synaptic plasticity mechanisms, and input encoding. The approach is demonstrated on real-time on-chip learning applications using both shallow networks and complex architectures inspired by insect olfactory systems. Results show that the method can identify robust, high-performing configurations, with classification accuracy reaching up to 93% when using longer encodings.

## Method Summary
The method combines deepHyper's parallel asynchronous model-based search with spikelearn, a lightweight simulation framework based on the streamnet data structure. AMBS enables parallel evaluation of hyperparameter configurations while updating random forest surrogate models in real-time to guide the search. Spikelearn simulates spiking neural networks with leaky integrate-and-fire neurons and modulated synaptic plasticity rules. The workflow manages distributed execution using Ray or MPI, allowing efficient exploration of design spaces for online learning tasks using the MNIST dataset.

## Key Results
- AutoML-inspired approach effectively identifies optimal neuromorphic architecture configurations
- Classification accuracy reaches up to 93% with longer input encodings
- The optimization approach demonstrates viability for application-driven co-design of complex spiking architectures

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Asynchronous model-based search (AMBS) enables efficient exploration of large neuromorphic design spaces by parallelizing evaluations and updating surrogate models in real-time
- Core assumption: The surrogate model can generalize from limited sampled configurations to predict performance in unexplored regions
- Evidence anchors:
  - "Through the integration of a parallel asynchronous model-based search approach with a simulation framework to simulate spiking architectures, we are able to efficiently explore the configuration space"
  - "Since AMBS enables asynchronous search, a large number of hyperparameter configurations can be evaluated in parallel and inform the surrogate modeling"
- Break condition: Surrogate model accuracy degrades if the design space contains many local optima or discontinuities

### Mechanism 2
- Claim: Streamnet's modular architecture allows seamless integration of heterogeneous simulation components
- Core assumption: Each element's interface remains consistent when components are swapped
- Evidence anchors:
  - "The streamnet structure is ideally suited to the simulation of neural networks, since: 1) the exact computation carried out within each element is hidden from the streamnet"
  - "It allows swapping elements without breaking the simulation as long as they share the same interface"
- Break condition: Inconsistent interfaces between components or computational bottlenecks when scaling

### Mechanism 3
- Claim: The modulated synaptic plasticity rule enables effective supervised learning in spiking neural networks
- Core assumption: The modulatory signal accurately encodes class information and trace dynamics capture necessary temporal correlations
- Evidence anchors:
  - "This model can be viewed in two ways: it resembles some of the covariance rate models... It can also be viewed as an spiking counterpart of a mean square error loss function"
  - "We have considered leaky integrate and fire neurons given by the following equations... This model is analogous to Loihi's model"
- Break condition: Learning fails if the modulatory signal is noisy or trace time constants poorly matched

## Architecture Onboarding

- Component map: spikelearn (simulation framework) -> deepHyper (AMBS engine) -> Ray/MPI (workflow management) -> Random forest surrogate models (predictive guidance)

- Critical path: Parameter configuration → spikelearn simulation → accuracy evaluation → deepHyper update → new parameter sampling → repeat

- Design tradeoffs:
  - Simulation speed vs accuracy: Simplified neuron models trade biological realism for computational efficiency
  - Search space granularity vs computational cost: Finer parameter resolution increases search time exponentially
  - Model complexity vs generalization: More complex architectures may overfit to specific tasks

- Failure signatures:
  - Search gets stuck in local optima (flat accuracy landscape)
  - Surrogate model predictions diverge from actual performance
  - Simulation crashes due to numerical instability or memory limits

- First 3 experiments:
  1. Verify basic functionality: Run a simple spiking network with known parameters through spikelearn and check output spike patterns
  2. Test AMBS workflow: Optimize a trivial parameter (e.g., learning rate) on a small network and verify convergence
  3. Validate parallel execution: Run multiple spikelearn instances simultaneously and measure speedup compared to sequential execution

- Why unresolved: The paper only explores a specific case of online, on-chip learning with a shallow network and a complex network inspired by the olfactory system of the insect brain
- What evidence would resolve it: A study comparing the performance of different neuromorphic architectures with varying neuron models, synaptic plasticity mechanisms, and input encodings for a range of applications

### Open Question 2
- Question: How does the proposed optimization approach perform in optimizing more complex architectures and tasks beyond the exemplar case of online, on-chip learning?
- Basis in paper: [explicit] The paper demonstrates the approach on an exemplar case of real-time, on-chip learning application, but states that it is a necessary step to explore more complex metalearning experiments involving distributions of tasks
- Why unresolved: The paper only presents results for a specific case of online, on-chip learning with a shallow network and a complex network inspired by the olfactory system of the insect brain
- What evidence would resolve it: A study applying the proposed optimization approach to a variety of complex architectures and tasks, such as signal processing or autonomous agents

### Open Question 3
- Question: How do the identified configurations in the optimization process generalize to other tasks and datasets beyond the MNIST dataset used in the exemplar case?
- Basis in paper: [explicit] The paper mentions that the optimization experiments were carried out using only 10,000 samples and a small number of simulation steps, and that the goal is to identify configurations leading to fast learning in a specific task
- Why unresolved: The paper only presents results for the optimization of a specific task (online learning of the MNIST dataset) and does not explore the generalization of the identified configurations to other tasks and datasets
- What evidence would resolve it: A study evaluating the performance of the identified configurations on a variety of tasks and datasets beyond the MNIST dataset

## Limitations
- Limited corpus evidence supporting AMBS effectiveness in neuromorphic contexts
- Implementation details of spikelearn framework remain incompletely specified
- Focus on shallow and insect-brain-inspired architectures without exploring deeper, more complex networks

## Confidence

- AMBS integration with neuromorphic simulation: Medium - Mechanistically sound but lacks direct empirical validation in this specific context
- Streamnet's effectiveness for complex architectures: Low - Theoretically justified but no practical performance data provided
- Synaptic plasticity rule's learning capabilities: Medium - Based on established principles but novel in spiking context without extensive validation
