# Particle-based Online Bayesian Sampling

## Quick Facts
- arXiv ID: 2302.14796
- Source URL: https://arxiv.org/abs/2302.14796
- Reference count: 40
- Primary result: Proposes OPVI method achieving sublinear regret bounds for online Bayesian sampling with dynamically changing posteriors

## Executive Summary
This paper introduces Online Particle-based Variational Inference (OPVI), a method for tracking dynamically changing posterior distributions in streaming data scenarios. The key innovation is combining particle-based variational inference with online optimization techniques, specifically using a sublinearly increasing batch size to reduce gradient error variance. The method is theoretically analyzed as a Wasserstein gradient flow and shown to achieve sublinear regret bounds, outperforming naive online ParVI methods and online MCMC approaches in experiments on synthetic data, Bayesian neural networks, and image classification.

## Method Summary
OPVI is an online Bayesian sampling method that updates particles to approximate dynamically changing posterior distributions. The core algorithm uses a sublinearly increasing batch size schedule to reduce gradient error variance in stochastic approximations. At each iteration, particles are updated using a vector field derived from the kernel-smoothed Stein operator, with updates interpreted as approximating a Wasserstein gradient flow. The method theoretically achieves sublinear regret bounds by balancing gradient error and path variation of the optimal posterior sequence.

## Key Results
- OPVI achieves sublinear regret bounds by using sublinearly increasing batch size to reduce gradient error
- Outperforms naive online ParVI methods and online MCMC methods in experiments
- Achieves comparable results to full-batch methods while using significantly less data and computation time
- Successfully tracks dynamically changing posteriors in synthetic data, BNN classification, and MNIST image classification tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sublinearly increasing batch size reduces gradient error variance in online ParVI.
- Mechanism: As batch size $B_t$ grows sublinearly with iteration $t$, the expected squared gradient error $E[\|\epsilon_t\|^2]$ decreases proportionally to $1/B_t$, making cumulative error $E_T$ sublinear.
- Core assumption: Stochastic gradient error is bounded by $\epsilon_t = \sqrt{1/B_t - 1/N_T}$ and gradient variance is uniformly bounded.
- Evidence anchors:
  - [section] "Base on section 2.8 in (Lohr, 2021), we have: $E[\|\epsilon_t\|^2] = \frac{N_T - B_t}{N_T B_t} \Lambda^2$"
  - [section] "We can see when the batch size $B_t$ is growing sublinear, the gradient error bound $E_T$ is sublinear."
- Break condition: If gradient variance $\Lambda$ grows with data size, the sublinear bound may fail.

### Mechanism 2
- Claim: Dynamic regret bound ensures convergence to time-varying optimal posterior.
- Mechanism: By bounding dynamic regret as $O(\max(1, E_T, V_T))$, the particle distribution $q_t$ tracks the sequence of optimal posteriors $p_t^*$ when both $E_T$ and $V_T$ grow sublinearly.
- Core assumption: The sequence of optimal posteriors $\{p_t^*\}$ has bounded path variation $V_T$.
- Evidence anchors:
  - [section] "We give the dynamic regret bound on $P_2(W)$ in the following Theorem... RP2(W)(T) ≤ O(max(1,ET,VT))"
  - [section] "That means the OPVI methods can converge to the dynamic changing target posterior $p_t$ when T is large enough."
- Break condition: If the optimal posterior path variation $V_T$ grows superlinearly, the regret bound becomes linear and convergence fails.

### Mechanism 3
- Claim: Riemannian structure of Wasserstein space enables gradient flow analysis for ParVI.
- Mechanism: The gradient flow on $P_2(W)$ approximates the evolution of particle distribution under SVGD-like updates, allowing transfer of Euclidean regret bounds to distribution space.
- Core assumption: The kernel $K$ is chosen such that its RKHS $H$ approximates the tangent space $L^2_{q_t}$ of $P_2(W)$.
- Evidence anchors:
  - [section] "The function in $H$ is roughly a kernel smoothed function in $L^2_{q_t}$"
  - [section] "Thus, the vector field $v^{SVGD}_H$ in eq. (8) can be used to approximate the vector field $v^{SVGD}_{L^2_{q_t}}$"
- Break condition: If the kernel is too narrow or too wide, the RKHS approximation of the tangent space breaks down.

## Architecture Onboarding

- Component map:
  - OPVI -> Particle update rule -> Batch size scheduler -> Kernel choice -> Gradient error estimation

- Critical path:
  1. Initialize particles from simple distribution
  2. At each iteration $t$:
     - Sample mini-batch of size $B_t = N_T \cdot t^\rho / (N_T + t^\rho)$
     - Compute gradient estimate using kernel-smoothed Stein operator
     - Update particles: $x_t^{(i)} \leftarrow x_t^{(i)} + \alpha v_t^{OPVI-H}(x_t^{(i)})$
  3. Track regret and particle distribution distance to optimal posterior

- Design tradeoffs:
  - Batch size growth rate $\rho$: Smaller $\rho$ reduces variance but increases computation per iteration
  - Kernel bandwidth: Affects approximation quality of tangent space; too narrow causes particle collapse, too wide reduces gradient signal
  - Step size $\alpha$: Fixed vs. decaying; fixed is simpler but may require tuning for stability

- Failure signatures:
  - Linear regret growth: Indicates insufficient variance reduction or excessive path variation
  - Particle collapse: Suggests kernel bandwidth too small or gradient noise dominates
  - Poor classification accuracy: May indicate inadequate particle diversity or kernel choice mismatch

- First 3 experiments:
  1. 2D synthetic data with known posterior: Verify particle distribution tracks true posterior as batch size grows
  2. BNN on UCI dataset: Compare RMSE and log-likelihood against SVGD with fixed batch size
  3. MNIST classification: Test high-dimensional performance and analyze particle diversity over iterations

## Open Questions the Paper Calls Out

- Basis in paper: [explicit] The paper discusses a sublinear increasing batch size schedule (Bt = NT t^ρ / (NT + t^ρ)) and analyzes its impact on gradient error and regret bounds.
- Why unresolved: The paper focuses on a specific increasing batch size schedule but doesn't explore the impact of different schedules on regret bounds or practical performance.

## Limitations

- Theoretical guarantees rely on assumptions about bounded gradient variance and sublinear path variation that may not hold for highly non-stationary streaming data
- Kernel-based approximation of Wasserstein tangent space introduces additional approximation error not fully quantified
- Experimental evaluation limited to relatively small-scale problems compared to modern deep learning applications

## Confidence

- **High Confidence**: The core algorithmic framework and theoretical analysis connecting OPVI to Wasserstein gradient flows
- **Medium Confidence**: The variance reduction mechanism through sublinearly increasing batch size, as empirical validation is limited
- **Medium Confidence**: The experimental comparisons, though comprehensive for the scale tested, lack evaluation on truly large-scale streaming data scenarios
