# Towards Asking Clarification Questions for Information Seeking on Task-Oriented Dialogues

## Quick Facts
- arXiv ID: 2305.13690
- Source URL: https://arxiv.org/abs/2305.13690
- Reference count: 40
- Primary result: MAS2S significantly outperforms baselines on both clarification question generation (BLEU-0.315, ROUGE-0.296) and answer prediction (Success-0.412)

## Executive Summary
This paper introduces a task-oriented dialogue system that asks clarification questions to address user information needs and profile ambiguities. The proposed Multi-Attention Seq2Seq Network (MAS2S) integrates task knowledge, user profiles, and dialogue context using a BART-based encoder-decoder architecture with an answer confidence embedding network. The method is evaluated on the newly constructed ClariT dataset, which extends ShARC with user profiles. MAS2S demonstrates significant improvements over baselines in both clarification question generation and answer prediction, showing its effectiveness in generating necessary clarification questions and providing accurate, personalized answers in task-oriented information-seeking dialogues.

## Method Summary
The proposed MAS2S framework addresses the task-oriented information seeking problem by generating clarification questions to resolve ambiguities in user profiles and task knowledge. The system employs a BART-based encoder-decoder architecture that integrates three key components: task knowledge, user profiles, and dialogue context. A novel answer confidence embedding network calculates confidence scores for potential answers, which are then used as embeddings to guide the clarification question generation process. The system is trained end-to-end on the ClariT dataset, which extends the ShARC dataset with user profile information, enabling the model to generate personalized clarification questions that consider both the user's specific attributes and the task requirements.

## Key Results
- MAS2S achieves BLEU score of 0.315 and ROUGE score of 0.296 for clarification question generation
- The system attains a Success rate of 0.412 for answer prediction tasks
- MAS2S significantly outperforms baseline models on both clarification question generation and answer prediction metrics

## Why This Works (Mechanism)
The MAS2S framework effectively addresses the challenge of information-seeking in task-oriented dialogues by proactively identifying and resolving ambiguities through clarification questions. By integrating task knowledge, user profiles, and dialogue context into a unified encoding space, the model can identify when user queries are underspecified or when the available information is insufficient to provide a confident answer. The answer confidence embedding network plays a crucial role by quantifying the certainty of potential answers, allowing the system to determine when clarification is necessary. This approach enables more accurate and personalized responses while maintaining a natural conversational flow, as the system can ask targeted questions that address specific ambiguities rather than providing potentially incorrect information or generic responses.

### BART Architecture
- Why needed: Provides a strong pre-trained foundation for natural language understanding and generation tasks
- Quick check: Ensure the encoder properly encodes the concatenated input and the decoder generates coherent questions

### Answer Confidence Embeddings
- Why needed: Quantifies the certainty of potential answers to determine when clarification questions are necessary
- Quick check: Validate that confidence scores correlate with actual answer accuracy on a validation set

## Architecture Onboarding

### Component Map
User Query -> Task Knowledge Encoder -> User Profile Encoder -> Dialogue Context Encoder -> Answer Confidence Network -> BART Encoder -> BART Decoder -> Clarification Question

### Critical Path
1. User query is processed through all encoders
2. Answer confidence embeddings are calculated
3. All components are concatenated and fed to BART encoder
4. BART decoder generates clarification question

### Design Tradeoffs
- Pre-trained BART vs. training from scratch: Used pre-trained BART for better generalization but requires more computational resources
- Answer confidence vs. heuristic-based approaches: Confidence embeddings provide more nuanced control but add complexity to the model
- Task knowledge integration vs. pure dialogue-based approach: Task knowledge improves accuracy but requires domain-specific data preparation

### Failure Signatures
- Overly generic clarification questions indicate poor integration of user profile information
- Repeated questions suggest issues with dialogue context tracking
- Incorrect questions when task knowledge is present point to encoding problems

### Exactly 3 First Experiments
1. Test model with task knowledge removed to measure its contribution
2. Evaluate with answer confidence embeddings disabled to assess their impact
3. Compare performance on user queries with varying levels of ambiguity

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does MAS2S perform on task-oriented dialogue systems that involve multi-turn conversations with complex user profiles and task knowledge?
- Basis in paper: The paper focuses on task-oriented information seeking and extends the ShARC dataset with user profiles. It also mentions that the proposed paradigm can be extended to more complex scenarios, such as considering task relations, dialogue relations, and multi-modal information.
- Why unresolved: The paper only evaluates MAS2S on the ClariT dataset, which is an extension of the ShARC dataset with user profiles. It does not explore the performance of MAS2S on more complex task-oriented dialogue systems.
- What evidence would resolve it: Experiments on more complex task-oriented dialogue datasets that involve multi-turn conversations, complex user profiles, and task knowledge would provide evidence to answer this question.

### Open Question 2
- Question: How does MAS2S handle cases where the user's information needs and profile are highly ambiguous or conflicting?
- Basis in paper: The paper mentions that MAS2S uses an answer confidence embedding network to calculate answer confidence embeddings. However, it does not explicitly discuss how MAS2S handles cases where the user's information needs and profile are highly ambiguous or conflicting.
- Why unresolved: The paper does not provide enough information on how MAS2S handles ambiguous or conflicting user information.
- What evidence would resolve it: Experiments on task-oriented dialogue datasets that involve highly ambiguous or conflicting user information would provide evidence to answer this question.

### Open Question 3
- Question: How does the performance of MAS2S compare to human performance on task-oriented information seeking?
- Basis in paper: The paper evaluates MAS2S on the ClariT dataset and compares its performance to baselines. However, it does not compare the performance of MAS2S to human performance on task-oriented information seeking.
- Why unresolved: The paper does not provide a comparison of MAS2S's performance to human performance.
- What evidence would resolve it: A human evaluation study that compares the performance of MAS2S to human performance on task-oriented information seeking would provide evidence to answer this question.

## Limitations
- Evaluation limited to a single dataset (ClariT), raising concerns about generalizability to other task-oriented dialogue domains
- System relies on pre-defined task knowledge and user profiles, which may not capture the full complexity of open-domain information-seeking scenarios
- Evaluation metrics (BLEU, ROUGE, Success rate) may not fully capture qualitative aspects of clarification question quality and user satisfaction

## Confidence
- MAS2S significantly outperforms baselines: **High confidence** (supported by quantitative results)
- The approach effectively generates necessary clarification questions: **Medium confidence** (evaluation limited to one dataset)
- MAS2S provides accurate, personalized answers: **Medium confidence** (success rate is promising but evaluation scope is limited)
