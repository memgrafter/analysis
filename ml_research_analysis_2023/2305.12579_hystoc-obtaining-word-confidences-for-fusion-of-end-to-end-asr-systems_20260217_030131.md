# Hystoc: Obtaining word confidences for fusion of end-to-end ASR systems

## Quick Facts
- **arXiv ID:** 2305.12579
- **Source URL:** https://arxiv.org/abs/2305.12579
- **Reference count:** 0
- **Primary result:** Hystoc generates well-calibrated word-level confidences from n-best ASR outputs, improving system fusion by up to 1% absolute WER

## Executive Summary
This paper introduces Hystoc, a method for deriving word-level confidence scores from end-to-end ASR systems using confusion network alignment. Hystoc transforms n-best hypothesis lists into confusion networks where token confidences are extracted as posterior probabilities. The resulting confidences are well calibrated and significantly improve the performance of system fusion using the ROVER algorithm, achieving up to 1% absolute WER improvement on the Spanish RTVE2020 dataset. The method is simple, general-purpose, and works across different e2e architectures, though performance varies by system type.

## Method Summary
Hystoc is an iterative alignment procedure that converts n-best hypotheses from an ASR system into a confusion network. The process begins by sorting hypotheses by decreasing score, then iteratively aligns each hypothesis into the confusion network using Levenshtein alignment. For each token in the hypothesis, Hystoc either places it into an existing bin (if the token exists there) or creates a new bin (for insertions). Hypothesis scores are log-added with a temperature-scaled factor and normalized per bin to yield final word confidences. These confidences represent posterior probabilities and can be used for downstream tasks like system fusion via ROVER or direct n-best list fusion.

## Key Results
- Hystoc confidences show strong linear correlation with word accuracy across most e2e systems tested, except RNN-T
- Using Hystoc confidences in ROVER fusion improves WER by up to 1% absolute on Spanish RTVE2020 dataset
- Direct fusion of n-best outputs via Hystoc yields only minor gains when systems are very similar
- Temperature scaling allows adjustment of confidence sharpness, with higher temperatures potentially improving calibration

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hystoc converts hypothesis-level scores into well-calibrated word-level confidences via confusion network alignment.
- Mechanism: Hystoc iteratively aligns n-best hypotheses in order of decreasing score, building a confusion network where each bin contains token variants with associated probabilities. Scores from aligned hypotheses are log-added with a temperature-scaled factor, then normalized per bin to yield confidences.
- Core assumption: Hypothesis scores are monotonic with true token probabilities and can be aggregated across hypotheses to recover accurate per-token posteriors.
- Evidence anchors:
  - [abstract] "Hystoc is an iterative alignment procedure which turns hypotheses from an n-best output of the ASR system into a confusion network. Eventually, word-level confidences are obtained as posterior probabilities in the individual bins of the confusion network."
  - [section 2] "Hystoc is an iterative alignment procedure. Specifically, it aligns individual hypotheses hi into a confusion network in the order of decreasing hypothesis scores si."
  - [corpus] No direct corpus evidence of confusion network calibration; assumes alignment method is effective.
- Break condition: If hypothesis scores are poorly calibrated or if n-best lists are too short, the alignment may produce misleading confidences.

### Mechanism 2
- Claim: Hystoc confidences correlate strongly with word accuracy, making them useful for downstream fusion.
- Mechanism: After building the confusion network, each token's confidence is its posterior probability in the bin. This value directly predicts whether the token is correct, enabling effective fusion weighting.
- Core assumption: Token accuracy is linearly related to the posterior probability in the confusion network bin.
- Evidence anchors:
  - [section 3.2] "With the exception of the RNN-T model, all confidences are in a close linear relationship with the word accuracies in the corresponding cohorts."
  - [section 3.2] "We conclude that it is safe to increase the temperature if one desires more precise estimates of word accuracy."
  - [corpus] Limited direct corpus evidence; relies on experimental observation from the paper.
- Break condition: For models like RNN-T with poorly calibrated scores, the confidence-accuracy correlation breaks down.

### Mechanism 3
- Claim: Hystoc enables effective fusion of multiple e2e systems via Rover by providing calibrated confidences.
- Mechanism: Hystoc-generated confidences replace fixed values in Rover, allowing it to weight token votes more accurately across systems, improving overall WER.
- Core assumption: Rover's fusion quality is limited by the quality of input confidences; better confidences yield better fusion.
- Evidence anchors:
  - [abstract] "utilizing Hystoc in fusion of multiple e2e ASR systems increases the gains from the fusion by up to 1 % WER absolute on Spanish RTVE2020 dataset."
  - [section 3.3] "Providing the Hystoc confidences is beneficial in all cases, though the scale of the improvement varies."
  - [corpus] No corpus evidence of Rover fusion improvements; based solely on paper results.
- Break condition: If systems have very similar outputs, gains from Hystoc fusion are minor.

## Foundational Learning

- Concept: Confusion networks and their construction via alignment
  - Why needed here: Hystoc relies on building a confusion network from n-best hypotheses; understanding this structure is key to implementing or modifying Hystoc.
  - Quick check question: What is the difference between a confusion network and a lattice in ASR?

- Concept: Levenshtein alignment and its role in confusion network building
  - Why needed here: Hystoc uses Levenshtein alignment to map tokens from a hypothesis into the existing confusion network bins, potentially creating new bins for insertions.
  - Quick check question: How does Levenshtein alignment handle insertions, deletions, and substitutions in the context of confusion network construction?

- Concept: Temperature scaling in confidence calibration
  - Why needed here: Hystoc uses a temperature parameter to control the sharpness of confidence estimates; higher temperature can improve calibration.
  - Quick check question: What effect does increasing the temperature parameter have on the distribution of confidences in a confusion network?

## Architecture Onboarding

- Component map: ASR system → n-best hypotheses with scores → Hystoc alignment → confusion network → word-level confidences → Rover fusion or other downstream use
- Critical path: Hypothesis scoring → alignment into confusion network → bin normalization → confidence extraction
- Design tradeoffs: Hystoc trades off simplicity and generality (works with any e2e system) against potential calibration issues for poorly scored hypotheses; also, direct Hystoc fusion (without Rover) is less effective than using Rover with Hystoc confidences.
- Failure signatures: Poor confidence-accuracy correlation (e.g., for RNN-T systems), minor gains from Hystoc fusion when systems are very similar, dramatic WER deterioration when including certain systems like RNN-T in direct Hystoc fusion.
- First 3 experiments:
  1. Generate n-best lists from a single e2e system, run Hystoc with varying temperatures, and plot confidence vs. accuracy to verify calibration.
  2. Fuse two e2e systems using Rover with Hystoc confidences vs. fixed confidences, measure WER improvement.
  3. Attempt direct Hystoc fusion of n-best lists from multiple systems, compare WER to Rover-based fusion.

## Limitations

- Hystoc's effectiveness is fundamentally tied to the quality of hypothesis scores from underlying e2e ASR systems
- Direct fusion of n-best outputs using Hystoc yields only minor gains, particularly when systems have very similar outputs
- All experimental results are reported on a single Spanish dataset, limiting generalizability

## Confidence

**High confidence:** Hystoc can convert hypothesis-level scores into word-level confidences through confusion network alignment.

**Medium confidence:** Hystoc significantly improves Rover-based fusion of e2e ASR systems.

**Low confidence:** Hystoc is universally applicable across all e2e ASR architectures without modification.

## Next Checks

3. Compare Hystoc-based fusion against other confidence estimation methods (e.g., lattice-based confidences, minimum Bayes risk decoding) in a controlled setting to quantify Hystoc's unique contribution to fusion performance.
