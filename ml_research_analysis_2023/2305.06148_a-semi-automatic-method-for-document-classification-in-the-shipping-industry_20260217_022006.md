# A semi-automatic method for document classification in the shipping industry

## Quick Facts
- arXiv ID: 2305.06148
- Source URL: https://arxiv.org/abs/2305.06148
- Reference count: 2
- Primary result: 92% accuracy for Contract-Breach document classification using 0.6 cosine similarity threshold

## Executive Summary
This paper presents a semi-automatic document classification method for the shipping industry that combines human expertise with automated keyword frequency analysis. The approach uses manually selected keywords from training documents to build a corpus feature vector, then applies cosine similarity to classify test documents as either Contract-Breach or Others. Experiments with 250 Contract-Breach documents and 50 Criminal-Law documents from Singapore's judiciary website achieved 92% accuracy using a 0.6 similarity threshold. The method demonstrates that combining human judgment with automated processing can produce robust document classification for Intelligent Document Processing in shipping contexts.

## Method Summary
The classification method follows a semi-automatic approach where human experts select 50 keywords from 50 Contract-Breach training samples, then the top 20 most frequent keywords form the corpus feature vector. Test documents are classified based on cosine similarity between their document feature vector and the corpus vector, with a threshold of 0.6 determining the final classification. The process involves PDF text extraction, keyword frequency counting, vector creation, and similarity-based classification.

## Key Results
- Achieved 92% classification accuracy for Contract-Breach documents
- Optimal performance achieved with 0.6 cosine similarity threshold
- Top 20 keywords from 50 manually selected keywords provided sufficient discriminative power

## Architecture Onboarding

- Component map: Document preprocessing (PDF extraction) → Keyword selection (human + frequency analysis) → Corpus feature vector creation → Document feature vector extraction → Cosine similarity calculation → Classification decision
- Critical path: The most time-consuming step is likely the human keyword selection, followed by PDF text extraction. The actual classification computation is relatively fast
- Design tradeoffs: Semi-automatic keyword selection trades off automation for potentially better domain-specific accuracy. Using only 20 keywords trades off comprehensiveness for computational efficiency and reduced noise
- Failure signatures: Low accuracy could indicate poor keyword selection, overlapping document classes, insufficient training data, or inappropriate threshold selection

## Limitations

- The keyword selection process relies entirely on human judgment for the initial 50 keywords, which introduces potential bias and makes the method difficult to scale
- Only 300 total documents were used (250 Contract-Breach + 50 Criminal-Law), which is a relatively small sample size for evaluating classification performance
- The method assumes keyword frequencies are sufficient for classification, but doesn't account for semantic meaning or context

## Confidence

- High confidence: The overall methodology is clearly described and follows standard text classification approaches
- Medium confidence: The 92% accuracy claim is plausible given the described methodology, but the small dataset size and lack of statistical validation (confidence intervals, significance testing) reduces certainty
- Low confidence: The generalizability of the approach to other document types or industries beyond shipping remains unproven
