# Learning Disentangled Prompts for Compositional Image Synthesis

## Quick Facts
- arXiv ID: 2306.00763
- Source URL: https://arxiv.org/abs/2306.00763
- Reference count: 40
- Primary result: Zero-shot domain adaptive image synthesis using few target images with disentangled prompts

## Executive Summary
This paper introduces a novel approach for zero-shot domain adaptive image synthesis that enables generating images in a new style using a pretrained class-conditional generative model and only a few target domain images. The key innovation is learning disentangled prompts that separately encode semantic (class) and domain (style) information, allowing the synthesis of images from any class in the target domain's style. The method employs source class distilled visual prompt tuning and domain adaptive classifier-free guidance to achieve this capability.

## Method Summary
The method builds upon a pretrained class-conditional MaskGIT model and introduces a visual prompt generator that learns two types of learnable prompts: a class-specific prompt that reuses existing class token embeddings, and a class-agnostic prompt adapted to the target domain. During training, the class-specific prompt learns to predict class affinity matrices while the class-agnostic prompt learns domain-specific features through an information bottleneck. For synthesis, domain adaptive classifier-free guidance is applied, which drops both class and prompt tokens when generating unconditional logits to bias sampling towards the target domain. The approach enables compositional generalization by composing learned domain knowledge with arbitrary semantic classes from the pretrained model's vocabulary.

## Key Results
- Achieves high-quality zero-shot domain adaptation with as few as 1-10 target images per domain
- Improves zero-shot domain adaptation classification accuracy compared to baselines
- Demonstrates effective compositional generalization across diverse target domains including Van Gogh painting, haunted houses, and watercolor styles

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The source class distilled visual prompt design enables disentanglement of semantic (class) and domain (style) knowledge, which is critical for zero-shot domain adaptive image synthesis.
- Mechanism: By using two types of learnable prompts—a class-specific prompt (ˆtc) and a class-agnostic prompt (pϕ)—the method allows the transformer to separately encode class semantics and domain style. The class-specific prompt reuses existing class token embeddings from the pretrained model, while the class-agnostic prompt is adapted to the target domain.
- Core assumption: The class-agnostic prompt has limited capacity (low-dimensional bottleneck), forcing it to learn only domain-specific features rather than class-specific ones. The attention control mechanism ensures that the class-specific prompt is utilized effectively.
- Evidence anchors:
  - [abstract] "Specifically, we propose a novel source class distilled visual prompt that learns disentangled prompts of semantic (e.g., class) and domain (e.g., style) from a few images."
  - [section] "For ZDAIS, we want a representation where class and domain information are disentangled. Furthermore, to generalize to novel classes in Ysrc\Ytgt, it is desirable to reuse class token embeddings of the source domain."
- Break condition: If the class-agnostic prompt capacity is too large or the attention control is ineffective, the domain and class information may become entangled, preventing zero-shot generalization.

### Mechanism 2
- Claim: Domain adaptive classifier-free guidance (DA-CFG) improves both visual fidelity and domain adaptability in synthesized images.
- Mechanism: DA-CFG extends classifier-free guidance by sampling from both conditional and unconditional logits, but crucially drops the class and prompt tokens when generating unconditional logits. This encourages sampling from the target domain rather than the source domain.
- Core assumption: The unconditional logits generated without the class and prompt tokens will bias the sampling towards the target domain distribution learned by the adapted prompt.
- Evidence anchors:
  - [abstract] "Subsequently, we present a domain adaptive classifier-free guidance to synthesize images improving not only visual fidelity but also domain adaptability."
  - [section] "As confirmed in Sec. 4.1.1, we find that it is crucial to drop both class and the prompt (pϕ) tokens when generating unconditional logits as it promotes to sample from the target instead of a source domain."
- Break condition: If the unconditional logits still retain traces of the class or prompt tokens, the guidance may not effectively shift the sampling towards the target domain, reducing domain adaptation quality.

### Mechanism 3
- Claim: The proposed method enables compositional generalization by composing learned domain knowledge with arbitrary semantic classes from the pretrained model's vocabulary.
- Mechanism: After adapting the visual prompts to a target domain using a few training images, the learned domain knowledge (captured by the class-agnostic prompt) can be composed with any class token embedding from the source model's vocabulary, enabling synthesis of novel classes in the target domain's style.
- Core assumption: The pretrained model's class embeddings capture sufficient semantic information that can be meaningfully combined with the learned domain style to generate coherent images of unseen classes.
- Evidence anchors:
  - [abstract] "Learned domain prompt is then used to synthesize images of any classes in the style of target domain."
  - [section] "We study the compositional generalization of image synthesis models trained on the standard ImageNet benchmark... Our method learns to compose their style with arbitrary object categories within the vocabulary of the pretrained generative model."
- Break condition: If the semantic classes in the target domain are too different from those in the source model's vocabulary, or if the domain style is too complex to be captured by a single class-agnostic prompt, compositional generalization may fail.

## Architecture Onboarding

- Component map:
  - Pretrained class-conditional MaskGIT model (frozen) -> Source class distilled visual prompt generator (learnable) -> Domain adaptive classifier-free guidance module -> Scheduled parallel decoding for image synthesis

- Critical path:
  1. Train the visual prompt generator on a few target domain images using the MTM loss.
  2. Use the learned prompts to generate unconditional logits (dropping class and prompt tokens).
  3. Apply domain adaptive classifier-free guidance to sample from the conditional and unconditional logits.
  4. Decode the sampled token sequence to synthesize the final image.

- Design tradeoffs:
  - Prompt capacity vs. disentanglement: A lower-dimensional bottleneck for the class-agnostic prompt promotes disentanglement but may limit domain adaptation capability.
  - Attention control vs. flexibility: The attention control mechanism ensures effective use of the class-specific prompt but may restrict the model's flexibility in certain scenarios.
  - Number of target domain images vs. diversity: More training images can improve domain adaptation and diversity but may require more computational resources.

- Failure signatures:
  - Poor domain adaptation: Synthesized images retain characteristics of the source domain rather than the target domain.
  - Entangled class and domain information: The model fails to generalize to novel classes in the target domain's style.
  - Reduced diversity: The model samples from a narrow distribution, leading to repetitive or low-quality outputs.

- First 3 experiments:
  1. Train the visual prompt generator on a few target domain images and visualize the learned class affinity matrix A to verify disentanglement.
  2. Generate images using the learned prompts with and without domain adaptive classifier-free guidance to assess the impact on domain adaptation quality.
  3. Synthesize images of novel classes in the target domain's style and compare them qualitatively with ground-truth images (if available) or NST baselines to evaluate compositional generalization.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the proposed method perform when the target domain images are completely unrelated to any source classes in the ImageNet dataset?
- Basis in paper: [explicit] The paper discusses a scenario where the target domain images may not be accurately recognized by the class affinity matrix A, leading to potential failure cases.
- Why unresolved: The paper provides some qualitative examples of failure cases but does not offer a comprehensive quantitative analysis of performance degradation in such scenarios.
- What evidence would resolve it: Conducting experiments with target domain images that are completely unrelated to any source classes and measuring the quality of synthesized images and their impact on downstream tasks like classification accuracy.

### Open Question 2
- Question: How does the proposed method scale with the number of target domain images per class?
- Basis in paper: [explicit] The paper discusses experiments with varying numbers of target domain images per class (1-5 images per class) and notes an improvement in domain adaptive zero-shot synthesis with longer class-agnostic prompts when there are many training examples.
- Why unresolved: The paper does not provide a systematic study of how the performance of the proposed method changes as the number of target domain images per class increases beyond the tested range.
- What evidence would resolve it: Conducting experiments with a larger range of target domain images per class and analyzing the impact on FID scores and generation diversity.

### Open Question 3
- Question: How does the proposed method compare to other generative transfer learning methods when the target domain contains images of different object categories?
- Basis in paper: [explicit] The paper mentions that the method is designed to handle target domains with images of different object categories by assigning each image its own class.
- Why unresolved: The paper does not provide a direct comparison of the proposed method with other generative transfer learning methods in scenarios where the target domain contains images of different object categories.
- What evidence would resolve it: Conducting experiments with target domains containing images of different object categories and comparing the performance of the proposed method with other generative transfer learning methods in terms of FID scores and qualitative results.

## Limitations

- The method relies on a low-dimensional bottleneck for the class-agnostic prompt, which may limit its ability to capture complex domain styles
- The effectiveness of the attention control mechanism in preventing entanglement is assumed but not thoroughly validated
- The approach may struggle with target domains that have classes significantly different from the source model's vocabulary

## Confidence

**High Confidence:** The fundamental mechanism of using disentangled prompts for semantic and domain information is well-supported by the evidence provided. The claim that visual prompt tuning enables efficient adaptation without full model fine-tuning is also well-established in the literature.

**Medium Confidence:** The effectiveness of domain adaptive classifier-free guidance in improving both visual fidelity and domain adaptability is supported by the experimental results, but the analysis suggests this could be sensitive to implementation details. The compositional generalization claims are plausible but may have limitations in practice.

**Low Confidence:** The assumption that a single class-agnostic prompt can capture sufficient domain style information for diverse target domains is questionable. The robustness of the approach to significant domain shifts and its scalability to more complex generative models remain uncertain.

## Next Checks

1. **Disentanglement Validation:** Conduct a controlled experiment where the class-agnostic prompt capacity is systematically varied, and measure the impact on both domain adaptation quality and compositional generalization. This would directly test the relationship between prompt capacity and disentanglement effectiveness.

2. **Attention Control Analysis:** Implement an ablation study where the attention control mechanism is disabled, and compare the results with the full model. This would quantify the importance of the attention control in preventing entanglement and maintaining zero-shot generalization.

3. **Cross-Domain Generalization Test:** Evaluate the model's performance on target domains with significantly different characteristics from ImageNet, such as medical imaging or satellite imagery. This would test the robustness and generalizability of the approach beyond the studied domains.
