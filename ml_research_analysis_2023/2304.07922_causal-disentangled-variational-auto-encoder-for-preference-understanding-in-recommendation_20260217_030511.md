# Causal Disentangled Variational Auto-Encoder for Preference Understanding in Recommendation

## Quick Facts
- arXiv ID: 2304.07922
- Source URL: https://arxiv.org/abs/2304.07922
- Reference count: 26

## Executive Summary
This paper introduces the Causal Disentangled Variational Auto-Encoder (CaD-VAE), a novel approach for learning causal disentangled representations from interaction data in recommender systems. Unlike traditional disentanglement methods that enforce independence between all latent factors, CaD-VAE explicitly models causal relationships between semantically related high-level concepts using structural causal models. The approach captures both coarse-grained causal relationships (between concepts like directors and genres) and fine-grained independence (within each concept like different genres). Experiments on four real-world datasets demonstrate that CaD-VAE significantly outperforms existing state-of-the-art methods for learning disentangled representations in recommendation tasks.

## Method Summary
CaD-VAE is a variational autoencoder that learns causal disentangled representations by modeling explicit causal relationships between semantically related high-level concepts. The model uses an encoder to generate independent exogenous variables, a causal layer implementing structural causal models (SCMs) to transform them into causal representations, and a decoder to reconstruct observations. The key innovation is the use of an adjacency matrix A to encode causal relationships between four high-level concepts (Director → Film Genre → Actor, Production Year), combined with β-VAE regularization to encourage independence between fine-grained factors within each concept. Additional supervision using concept labels constrains the learned causal structure to match known relationships, improving both disentanglement quality and recommendation performance.

## Key Results
- CaD-VAE achieves NDCG@50 scores of 0.19272 on ML-100k, 0.34716 on ML-1M, 0.38991 on ML-20M, and 0.29172 on Netflix
- Outperforms state-of-the-art baselines including MacridVAE, β-MultVAE, MultiDAE, DGCF, and SEM-MacridVAE
- Demonstrates improved disentanglement quality with higher correlation metrics between latent dimensions
- Shows effectiveness of incorporating causal relationships between high-level concepts for recommendation

- Mechanism: The model uses A to define a causal graph where each element A_{ij} encodes the causal effect of factor i on factor j. The causal layer applies the transformation z = g((I - A^T)^{-1} ε) to propagate causal influences through the latent space.
- Core assumption: The high-level concepts in recommendation data have well-defined causal relationships that can be represented as a DAG.

- Claim: β-VAE regularization encourages independence between fine-grained factors within each high-level concept.
