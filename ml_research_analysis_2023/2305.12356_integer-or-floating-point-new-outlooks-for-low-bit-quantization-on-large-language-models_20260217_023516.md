# Integer or Floating Point? New Outlooks for Low-Bit Quantization on Large Language Models

## Quick Facts
- arXiv ID: 2305.12356
- Source URL: https://arxiv.org/abs/2305.12356
- Reference count: 27
- This paper proposes Mixture of Formats Quantization (MoFQ) for efficient LLM deployment, achieving state-of-the-art results in both 4-bit W-only and 8-bit WA quantization scenarios.

## Executive Summary
This paper addresses the challenge of efficient deployment of large language models (LLMs) through low-bit quantization. The authors observe that different layers in LLMs have varying tensor distributions that favor either integer (INT) or floating-point (FP) quantization formats. To leverage these complementary advantages, they propose MoFQ, which selectively determines the optimal format on a layer-wise basis. MoFQ achieves state-of-the-art results across multiple benchmarks, surpassing existing methods like GPTQ and INT/FP-only approaches while maintaining faster quantization speeds.

## Method Summary
MoFQ is built on the PPQ library and implements a layer-wise format selection mechanism that evaluates quantization error for both INT and FP formats using metrics like tensor MSE, layer output MSE, or model output MSE. The approach supports both weight-only (W-only) and weight-activation (WA) post-training quantization scenarios. For 4-bit W-only quantization, MoFQ leverages a redesigned FP4 format that reallocates NaN and Inf representations to reduce quantization errors. The method uses per-channel quantization for weight tensors and per-tensor quantization for activation tensors, ensuring that all quantized tensors within the same layer share the same data type while maintaining the same bit-width across the model.

## Key Results
- MoFQ achieves state-of-the-art results in both 4-bit W-only and 8-bit WA quantization scenarios on LLaMA models
- In 4-bit W-only quantization, MoFQ surpasses GPTQ without complex hyperparameter tuning and with an order of magnitude faster quantization speed
- In 8-bit WA quantization, MoFQ significantly outperforms INT/FP-only methods, achieving performance close to the full precision model
- The redesigned FP4 format reduces quantization errors by approximately 35% compared to IEEE-aligned formats

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Different layers in LLMs have different tensor distributions that favor either INT or FP quantization formats depending on static/dynamic nature and outlier presence.
- Mechanism: Weight tensors are static during inference and benefit from INT quantization at 8-bit due to uniform distribution, but this advantage diminishes at 4-bit when INT and FP distributions become more similar. Activation tensors are dynamic with significant outliers, making FP quantization superior due to FP's ability to represent large values with lower precision and small values with higher precision.
- Core assumption: The tensor distribution characteristics (static vs dynamic, outlier presence) directly determine which quantization format minimizes quantization error for that layer.
- Evidence anchors:
  - [section]: "For weight tensors with static distribution, INT quantization outperforms FP quantization at 8-bit but this advantage diminishes at 4-bit. For activation tensors with dynamic distribution and significant outliers, FP quantization surpasses INT quantization due to FP can represent large values with lower precision and small values with higher precision."
  - [abstract]: "the optimal quantization format varies across different layers due to the complexity and diversity of tensor distribution"

### Mechanism 2
- Claim: MoFQ achieves state-of-the-art results by selecting the optimal quantization format on a layer-wise basis, leveraging the complementary advantages of both INT and FP formats.
- Mechanism: The algorithm evaluates each layer using error metrics (tensor MSE, layer output MSE, or model output MSE) to determine whether INT or FP format minimizes quantization error for that specific layer, then applies the selected format consistently within that layer.
- Core assumption: Layer-wise format selection based on error minimization metrics can consistently identify the optimal format for each layer across different tasks and models.
- Evidence anchors:
  - [section]: "MoFQ effectively harnesses the complementary benefits of both formats, while ensuring that tensors within the same layer share the same data type and all quantized tensors have the same bit-width."
  - [abstract]: "MoFQ achieves state-of-the-art results in both weight-only (W-only) and weight-activation (WA) post-training quantization scenarios when tested on LLaMA across various tasks."

### Mechanism 3
- Claim: Reallocating NaN and Inf representations in low-bit floating-point formats enhances quantization precision by freeing up bit combinations for normalized numbers.
- Mechanism: In 4-bit FP formats, the standard IEEE 754 allocation of 4 values to NaN and Inf is modified to represent additional normalized numbers (±4 and ±6), reducing quantization errors by approximately 35% compared to IEEE-aligned formats.
- Core assumption: NaN and Inf values are not needed during model quantization, so their bit combinations can be repurposed for more useful numerical representations.
- Evidence anchors:
  - [section]: "Tensor-wise analysis shows that our redesigned FP4 format can lead to about 35% lower quantization errors compared to the IEEE-aligned FP4 format."
  - [section]: "4 of these numbers are used to represent NaN and Inf when adhering to the IEEE 754 standard. By reallocating them, we can obtain additional represented numbers, specifically ±4 and ±6."

  - Why needed here: MoFQ relies on various error metrics to select the optimal format for each layer, so understanding these metrics and their relationship to model accuracy is crucial for implementing and tuning the approach.

## Architecture Onboarding

- Component map: MoFQ consists of a format selection engine that iterates through model layers, evaluates quantization error for both INT and FP formats using specified error metrics, selects the optimal format per layer, and applies the quantization accordingly. The system interfaces with existing quantization libraries (PPQ) and supports both W-only and WA quantization scenarios.
- Critical path: For each layer to be quantized: 1) Generate quantized versions using both INT and FP formats, 2) Compute error metric for each format, 3) Select format with minimum error, 4) Apply selected format to create quantized layer, 5) Add to quantized model.
- Design tradeoffs: Layer-wise format selection provides optimal accuracy but increases quantization time compared to uniform format approaches. The choice of error metric balances quantization speed against accuracy (tensor error is fastest, model output error is most accurate but slowest).
- Failure signatures: If format selection consistently chooses one format across all layers despite varying tensor distributions, the error metrics may be poorly calibrated. If quantization speed is significantly slower than expected, the error computation step may be inefficient. If model accuracy degrades unexpectedly, the format selection may be overfitting to error metrics rather than actual performance.
- First 3 experiments:
  1. Run MoFQ on a small LLM (e.g., LLaMA-7B) using tensor MSE as the error metric to verify basic functionality and compare against INT-only and FP-only baselines on WikiText-2.
  2. Evaluate the impact of different error metrics (tensor MSE vs layer output MSE) on the same model to understand the accuracy-speed tradeoff.
  3. Test MoFQ with the NaN/Inf reallocation optimization on 4-bit quantization to verify the claimed 35% reduction in quantization errors compared to IEEE-aligned FP4.

## Open Questions the Paper Calls Out

The paper mentions that MoFQ can be extended to finer granularities (e.g., channel-wise or block-wise format selection) but leaves this as future work due to increased memory consumption and hardware complexity challenges. The authors also note that the selection of error metrics plays a crucial role in balancing quantization accuracy and speed, but do not provide comprehensive guidance on metric selection for different scenarios.

## Limitations

- The paper's claims are primarily validated on LLaMA and OPT models, raising questions about generalization to other LLM architectures
- Exact implementation details for the format selection algorithm and error metric configurations are not fully specified, making faithful reproduction challenging
- Hardware compatibility issues for mixed INT/FP format models across different inference platforms are not extensively addressed

## Confidence

- MoFQ achieves state-of-the-art results in both W-only and WA quantization scenarios: High confidence based on extensive empirical comparisons with baseline methods across multiple datasets and bit-widths
- The optimal quantization format varies across different layers due to tensor distribution complexity: High confidence supported by both theoretical analysis and experimental evidence showing consistent layer-wise format selection patterns
- Reallocating NaN and Inf representations in low-bit FP formats reduces quantization errors by ~35%: Medium confidence as this is based on tensor-wise analysis but lacks extensive experimental validation across diverse models
