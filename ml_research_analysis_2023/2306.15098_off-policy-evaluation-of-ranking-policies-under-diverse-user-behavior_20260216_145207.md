# Off-Policy Evaluation of Ranking Policies under Diverse User Behavior

## Quick Facts
- arXiv ID: 2306.15098
- Source URL: https://arxiv.org/abs/2306.15098
- Reference count: 40
- This paper proposes Adaptive IPS (AIPS), an off-policy evaluation method that adapts importance weighting based on context-aware user behavior models, achieving minimum variance among unbiased estimators and outperforming existing methods on synthetic and real-world data.

## Executive Summary
This paper addresses the challenge of off-policy evaluation (OPE) in ranking systems where user behavior is diverse and context-dependent. Traditional OPE methods assume a single user behavior model (like independent or cascade), which can lead to biased or high-variance estimates when the true behavior is more complex. The authors propose Adaptive IPS (AIPS), which uses adaptive importance weighting based on a context-aware behavior model. AIPS is shown to be unbiased under any user behavior distribution and achieves minimum variance among unbiased IPS estimators. The authors also develop a data-driven method to optimize the behavior model to minimize AIPS's mean squared error (MSE). Experiments on synthetic and real-world data demonstrate that AIPS significantly outperforms existing methods, especially when user behavior is diverse.

## Method Summary
The paper proposes Adaptive IPS (AIPS), an off-policy evaluation method for ranking policies under diverse user behavior. AIPS uses adaptive importance weighting based on a context-aware behavior model, where the importance weights are defined based on the actions that actually affect the reward for each user. The method involves collecting logged bandit data with context, actions, and rewards, then optimizing the user behavior model by minimizing the estimated MSE using a tree-based subgroup identification procedure. The optimized model is used to adaptively weight the importance of different actions when estimating the policy value, leading to reduced variance compared to traditional IPS estimators.

## Key Results
- AIPS is unbiased under any user behavior distribution and achieves minimum variance among unbiased IPS estimators.
- AIPS significantly outperforms existing methods on synthetic data with varying user behavior distributions and ranking lengths.
- On real-world data, AIPS reduces the conditional value at risk (CVaR) of squared error by over 30% compared to the next best method.

## Architecture Onboarding

- Component map: Data collection -> User behavior model optimization -> Importance weighting -> MSE estimation -> Policy value estimation
- Critical path: Data → User behavior optimization → Importance weighting → MSE estimation → Policy value estimation
- Design tradeoffs:
  - Using a larger set of candidate behavior models increases the chances of finding a good model but also increases computation time.
  - Estimating MSE accurately is crucial for effective behavior model optimization, but it may be challenging with limited data.
- Failure signatures:
  - High variance in AIPS estimates compared to other estimators may indicate that the behavior model optimization is not effective.
  - Large bias in AIPS estimates compared to the true policy value may suggest that the selected behavior model is not a good fit for the data.

## Limitations

- The performance of AIPS relies heavily on the accuracy of the user behavior model estimation or optimization, which may be challenging with limited data or a small candidate set of behavior models.
- The paper only provides empirical results on one real-world dataset, and further validation on multiple datasets across different domains is needed to establish the robustness of AIPS.
- The effectiveness of the MSE estimation procedure used in the behavior model optimization step is not extensively validated, which is critical for the overall performance of AIPS.
