# A framework for benchmarking class-out-of-distribution detection and its application to ImageNet

## Quick Facts
- arXiv ID: 2302.11893
- Source URL: https://arxiv.org/abs/2302.11893
- Reference count: 40
- Key outcome: Introduces severity-specific C-OOD benchmarks via confidence-based sampling; reveals knowledge distillation, ViTs, and CLIP as top performers.

## Executive Summary
This paper presents a framework for benchmarking class-out-of-distribution (C-OOD) detection that addresses the challenge of evaluating models across realistic and varied detection difficulties. The method constructs severity-specific benchmarks by sampling ImageNet-21k classes based on their confidence scores, allowing evaluation across multiple difficulty levels. When applied to 525 pretrained ImageNet classifiers, the framework reveals key insights: knowledge distillation consistently improves C-OOD detection, a subset of Vision Transformers (ViTs) achieves top performance, CLIP demonstrates strong zero-shot detection at low severity levels, and accuracy correlates strongly with detection performance.

## Method Summary
The framework filters ImageNet-21k to remove ID classes and similar classes, then estimates severity scores for each OOD class based on a model's confidence function. Severity-specific C-OOD benchmarks are generated using a sliding window approach that groups OOD classes with similar severity scores. The method constructs severity-specific benchmarks by sampling ImageNet-21k classes based on their confidence scores, allowing evaluation across multiple difficulty levels.

## Key Results
- Knowledge distillation consistently improves C-OOD detection performance across all severity levels.
- A subset of Vision Transformers (ViTs) outperforms all other architectures in C-OOD detection.
- CLIP achieves strong zero-shot C-OOD detection, especially at low severity levels, without requiring training on ID classes.
- Model accuracy correlates strongly with C-OOD detection performance across severity levels.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Severity-based sampling isolates detection difficulty so performance can be measured at each realistic risk tolerance level.
- Mechanism: The framework ranks OOD classes by confidence and groups them into percentiles; each percentile becomes a separate benchmark.
- Core assumption: Confidence scores reflect true detection difficulty and can be reliably estimated on a disjoint set.
- Evidence anchors:
  - [abstract] "The method constructs severity-specific benchmarks by sampling ImageNet-21k classes based on their confidence scores, allowing evaluation across multiple difficulty levels."
  - [section] "This method for reducing the number of considered groups of classes was chosen because it groups OOD classes with similar severity scores together."
  - [corpus] Weak: corpus lacks direct studies of percentile-based severity calibration.
- Break condition: If the estimation set is too small or confidence is poorly calibrated, severity scores become unreliable and benchmarks no longer reflect true difficulty.

### Mechanism 2
- Claim: Knowledge distillation consistently improves C-OOD detection across all severity levels.
- Mechanism: Distilling from a larger model improves the student's uncertainty estimates, which in turn yields better OOD confidence separation.
- Core assumption: The teacher's confidence estimates are more reliable and transfer to the student for OOD detection.
- Evidence anchors:
  - [abstract] "(1) knowledge distillation consistently improves class-out-of-distribution (C-OOD) detection performance;"
  - [section] "knowledge distillation had the most significant impact in most severity levelss> 3."
  - [corpus] Weak: no corpus citations directly linking distillation to OOD performance.
- Break condition: If the teacher is not better at uncertainty estimation, or if the student architecture cannot capture the teacher's signals, distillation may not help.

### Mechanism 3
- Claim: CLIP's multimodal training enables zero-shot C-OOD detection without needing to see ID classes.
- Mechanism: CLIP's text-image embeddings capture semantic similarity, so OOD classes that are descriptively similar to ID classes are harder to detect.
- Core assumption: Semantic distance in CLIP's joint embedding space correlates with detection difficulty.
- Evidence anchors:
  - [abstract] "(3) the language—vision CLIP model achieves good zero-shot detection performance, with its best instance outperforming 96% of all other models evaluated;"
  - [section] "CLIP could be used as a zero-shot C-OOD detection algorithm without the need to train on the ID classes."
  - [corpus] Weak: corpus does not contain studies on CLIP's OOD detection performance.
- Break condition: If CLIP's embeddings do not reflect visual similarity or if text semantics diverge from visual semantics, zero-shot detection will fail.

## Architecture Onboarding

- Component map: Data filtering → severity scoring → group sliding window → benchmark generation → evaluation (AUROC)
- Critical path: Filter ImageNet-21k → Estimate severity scores on disjoint set → Sort & group → Build severity benchmarks → Run model evaluation
- Design tradeoffs: Larger estimation sets → more accurate severity scores but higher cost; stricter filtering → fewer OOD classes but cleaner benchmarks
- Failure signatures: High variance in severity scores across classes → noisy benchmarks; poor AUROC on low-severity → weak confidence separation; CLIP degrading on high-severity → semantic mismatch
- First 3 experiments:
  1. Run the severity estimation step on a small subset to check score distribution and filter efficacy.
  2. Generate benchmarks for a single model and confidence function to validate the pipeline.
  3. Compare AUROC results across severity levels to confirm monotonic difficulty trends.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can we optimize confidence function hyperparameters (like ODIN's temperature and perturbation) specifically for different severity levels of C-OOD detection?
- Basis in paper: [explicit] The paper notes that ODIN's hyperparameters were not optimized specifically for different severity levels and suggests this might allow for better results
- Why unresolved: The paper uses a simple grid search over validation set to find hyperparameters that improve mean AUROC across all severity levels, but acknowledges this may not be optimal for individual severity levels
- What evidence would resolve it: Empirical comparison of C-OOD detection performance using severity-specific vs. global hyperparameter optimization across multiple models and severity levels

### Open Question 2
- Question: What architectural modifications could transfer the C-OOD detection advantages of successful ViT models to other architectures like CNNs?
- Basis in paper: [explicit] The paper observes that a subset of ViTs performs better C-OOD detection than any other model and calls for research into training more robust ViTs or transferring their advantages
- Why unresolved: The paper identifies the superior performance but doesn't identify the specific architectural or training features that enable this advantage
- What evidence would resolve it: Comparative analysis of successful vs. unsuccessful ViT architectures to identify distinguishing features, followed by architectural modifications to other models incorporating these features

### Open Question 3
- Question: How does the multimodal nature of CLIP contribute to its superior zero-shot C-OOD detection performance compared to unimodal approaches?
- Basis in paper: [explicit] The paper notes that CLIP's zero-shot C-OOD detection is good, especially at low severity levels, and suggests the multimodal nature is a crucial component while scaling effects of softmax hinder performance
- Why unresolved: While the paper observes CLIP's effectiveness, it doesn't fully explain the mechanism by which its language-vision integration enhances OOD detection
- What evidence would resolve it: Ablation studies comparing CLIP's performance with different combinations of its visual and language components, and analysis of how semantic similarity in text embeddings affects OOD detection

## Limitations

- The severity estimation step relies on a single model's confidence scores, which may not generalize across different architectures or data distributions.
- The filtering criteria for removing ID classes and similar classes from ImageNet-21k are not fully specified, leaving room for implementation variance that could affect benchmark quality.
- The paper lacks corpus citations linking knowledge distillation, CLIP's zero-shot detection, and severity-based sampling to prior work, making it difficult to assess novelty and contextualize results.

## Confidence

- High confidence: Knowledge distillation consistently improves C-OOD detection performance across severity levels.
- Medium confidence: CLIP achieves strong zero-shot C-OOD detection at low severity levels.
- Low confidence: Severity-based sampling reliably reflects real-world deployment difficulty.

## Next Checks

1. **Severity score stability test**: Evaluate how much severity rankings change when using different models for estimation; high variance would undermine benchmark reliability.
2. **Filtering robustness audit**: Implement multiple filtering strategies (e.g., strict vs. relaxed hypernym/hyponym removal) and measure impact on benchmark composition and model performance.
3. **Cross-model transferability**: Test whether severity scores from one model type (e.g., CNN) predict difficulty for another (e.g., ViT); poor transferability would indicate overfitting to model-specific confidence behaviors.
