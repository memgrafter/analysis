# Revisiting Event Argument Extraction: Can EAE Models Learn Better When Being Aware of Event Co-occurrences?

## Quick Facts
- **arXiv ID**: 2306.00502
- **Source URL**: https://arxiv.org/abs/2306.00502
- **Reference count**: 18
- **Primary result**: TabEAE achieves new state-of-the-art performance on 4 datasets by extracting multiple events in parallel

## Executive Summary
This paper explores whether Event Argument Extraction (EAE) models can improve by being aware of event co-occurrences, a strategy proven effective for event extraction but previously unexplored for EAE. The authors reformulate EAE as a table generation problem and extend a state-of-the-art prompt-based EAE model into a non-autoregressive framework called TabEAE. This framework extracts arguments for multiple events in parallel, forcing the model to better distinguish semantic boundaries between overlapping events. Experiments on four datasets (ACE05, RAMS, WikiEvents, MLEE) demonstrate that training TabEAE to extract all events concurrently substantially improves its ability to extract single events, achieving new state-of-the-art performance.

## Method Summary
The paper reformulates Event Argument Extraction as a table generation problem, where events are represented as rows in a table with argument slots as columns. TabEAE uses a non-autoregressive generation framework with three key components: a trigger-aware context encoder (17 RoBERTa layers) that encodes text conditioned on event triggers, a slotted table constructor that creates prompt-based table structures with argument slots, and a non-autoregressive table decoder (7 RoBERTa layers) with structure-aware attention masks that decodes all event arguments simultaneously. The model employs three training-inference schemes: Single-Single (train and infer one event at a time), Multi-Multi (train and infer all events in parallel), and Multi-Single (train with all events but infer with single events). This approach enables parallel extraction of multiple events while maintaining event-specific information through attention masking.

## Key Results
- TabEAE achieves new state-of-the-art performance on ACE05, RAMS, WikiEvents, and MLEE datasets
- Training with parallel event extraction (Multi-Multi/Multi-Single) improves ability to distinguish semantic boundaries of overlapping events
- Parallel extraction substantially improves single-event extraction performance compared to single-event training
- Structure-aware attention masks are crucial, with performance dropping by 1.9-1.5 F1 points when removed

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Training TabEAE to extract all events in parallel (Multi-Multi or Multi-Single) improves its ability to capture semantic boundaries between overlapping events.
- Mechanism: When multiple events share arguments, parallel extraction forces the model to learn fine-grained distinctions between event boundaries by attending to overlapping semantic regions simultaneously.
- Core assumption: The model can learn to differentiate overlapping events through exposure to co-occurring events during training.
- Evidence anchors:
  - [abstract]: "via training the model to extract all events in parallel, it can better distinguish the semantic boundary of each event"
  - [section 5.1]: "when trained to extract all events concurrently, the model's performance gains of extracting the arguments of overlapping events are much higher than that of extracting the arguments of non-overlapping events"
  - [corpus]: Weak evidence - only 4 datasets with limited event overlap patterns
- Break condition: If the dataset has very few overlapping events, this mechanism loses effectiveness.

### Mechanism 2
- Claim: Parallel extraction improves extraction of arguments distant from their triggers.
- Mechanism: Exposure to multiple events in parallel helps the model learn long-range dependencies between triggers and their arguments across different event types.
- Core assumption: Distant arguments are harder to extract and benefit more from contextual information provided by other events.
- Evidence anchors:
  - [section 5.2]: "when equipped with the Multi-Multi/Multi-Single schemes the model's performance gains of extracting remote arguments are higher than the performance gains of extracting nearby arguments"
  - [abstract]: "via training the model to extract all events in parallel, it can better distinguish the semantic boundary of each event"
  - [corpus]: Weak evidence - only tested on WikiEvents and MLEE with longer documents
- Break condition: If most arguments are close to their triggers, the benefit diminishes.

### Mechanism 3
- Claim: Non-autoregressive table generation with structure-aware attention masks enables better parallel event extraction.
- Mechanism: The structure-aware attention mask ensures each table component only attends to relevant regions, preventing interference between different events during parallel decoding.
- Core assumption: The attention mask design properly isolates event-specific information while allowing cross-event learning where beneficial.
- Evidence anchors:
  - [section 5.3]: "After removing the structure-aware attention mask, the Arg-C F1 scores drop by 1.9, 1.5, 1.1, 1.5 on ACE05, RAMS, WikiEvents and MLEE respectively"
  - [section 3.2.3]: "We devise a structure-aware self-attention mask, M Tab, so that each element of the table can only attend to the region related to it"
  - [corpus]: Strong evidence from ablation study showing significant performance drop without the mask
- Break condition: If the attention mask is too restrictive, it may prevent beneficial information flow between related events.

## Architecture Onboarding

- Component map:
  Trigger-aware context encoder (17 RoBERTa layers) -> Slotted table constructor (prompts + argument slots) -> Non-autoregressive table decoder (7 RoBERTa layers + structure-aware attention) -> Span selector (head + tail pointer mechanism)

- Critical path:
  Trigger → Context Encoding → Table Construction → Parallel Decoding → Span Selection

- Design tradeoffs:
  - Deep encoder (17 layers) vs shallow decoder (7 layers) for better context understanding
  - Fixed prompt templates vs learned prompt generation
  - Non-autoregressive vs autoregressive decoding for speed vs accuracy

- Failure signatures:
  - Poor performance on overlapping events → attention mask too restrictive
  - Degraded performance on single events → insufficient single-event training
  - Span selection errors → span selector not properly aligned with table decoder

- First 3 experiments:
  1. Single-Single baseline: Train and infer with one event at a time to establish baseline performance
  2. Multi-Multi: Train and infer with all events in parallel to test parallel extraction capability
  3. Multi-Single: Train with all events in parallel but infer with single events to evaluate transfer learning

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different prompt construction strategies impact TabEAE's performance across various event extraction datasets?
- Basis in paper: [explicit] The paper mentions that prompts are manually constructed for MLEE and directly taken from previous works for other datasets, and an ablation study shows performance drops when using argument roles instead of prompts.
- Why unresolved: The paper doesn't explore automated prompt construction or compare different prompt strategies across datasets systematically.
- What evidence would resolve it: Experiments comparing TabEAE performance with manually constructed prompts, automatically generated prompts, and no prompts across multiple datasets would provide insights into optimal prompt strategies.

### Open Question 2
- Question: Can TabEAE be effectively extended to handle entity coreference resolution alongside event argument extraction?
- Basis in paper: [inferred] The paper mentions in the limitations section that entity coreference is ignored, which limits the model's ability to understand underlying relations between entities crucial for EAE.
- Why unresolved: The current TabEAE framework doesn't incorporate entity coreference resolution, which could improve understanding of entity relationships in narrative documents.
- What evidence would resolve it: Developing and evaluating a TabEAE variant that integrates entity coreference resolution and measuring its impact on EAE performance would demonstrate the potential benefits of this extension.

### Open Question 3
- Question: What are the limitations of using non-autoregressive generation for complex nested event structures in EAE?
- Basis in paper: [explicit] The paper notes that TabEAE (Multi-Multi) performs better on MLEE, where nested events extensively exist, but doesn't explore the limitations of non-autoregressive generation for complex nested structures.
- Why unresolved: The paper doesn't investigate scenarios where non-autoregressive generation might struggle with deeply nested or highly interdependent event structures.
- What evidence would resolve it: Creating datasets with varying degrees of event nesting complexity and evaluating TabEAE's performance, particularly comparing it with autoregressive approaches, would reveal the strengths and limitations of non-autoregressive generation for nested events.

## Limitations
- The effectiveness of parallel event extraction is primarily validated on datasets with moderate event overlap, leaving uncertainty about performance on datasets with minimal event co-occurrence
- The study focuses on structured extraction scenarios and does not evaluate TabEAE's performance on open-domain or more complex event extraction tasks
- The benefits of parallel training are demonstrated through comparison with single-event baselines, but direct comparison with other state-of-the-art EAE models using similar parallel extraction approaches is limited

## Confidence
- **High Confidence**: The architectural design of TabEAE and its core components (trigger-aware encoding, structure-aware attention masks, non-autoregressive decoding) are well-validated through ablation studies and performance improvements
- **Medium Confidence**: The claim that parallel training improves semantic boundary distinction is supported by experimental results but could benefit from additional qualitative analysis of model attention patterns
- **Medium Confidence**: The assertion that distant argument extraction benefits more from parallel training is supported by data from longer documents but may not generalize to all document types

## Next Checks
