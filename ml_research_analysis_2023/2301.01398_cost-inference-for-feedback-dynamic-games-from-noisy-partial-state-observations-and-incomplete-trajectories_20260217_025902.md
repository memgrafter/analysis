# Cost Inference for Feedback Dynamic Games from Noisy Partial State Observations and Incomplete Trajectories

## Quick Facts
- arXiv ID: 2301.01398
- Source URL: https://arxiv.org/abs/2301.01398
- Reference count: 38
- Key outcome: Efficient cost inference algorithm for inverse feedback nonlinear games using partial state observations and incomplete trajectories

## Executive Summary
This paper addresses the challenge of inferring cost functions in nonlinear dynamic games when only noisy partial state observations and incomplete trajectories are available. The authors develop an efficient gradient approximation scheme based on linearization and quadraticization methods, enabling the use of first-order optimization to solve the inverse feedback game problem. The algorithm is evaluated on platooning scenarios and demonstrates better robustness and generalization compared to open-loop baseline methods.

## Method Summary
The method involves joint inference of initial conditions and cost parameters using coordinate gradient descent. At each iteration, the algorithm uses ILQGames to solve the forward nonlinear dynamic game approximately, generating linearized dynamics and quadraticized costs. The gradient approximation treats these linearized components as constants with respect to cost parameters, enabling efficient partial derivative computation. The loss function combines negative log-likelihood of observations with regularization terms, and the coordinate descent alternates between updating the initial condition and cost parameters until convergence.

## Key Results
- Demonstrates reliable convergence on 2-vehicle and 3-vehicle platooning scenarios
- Shows better robustness and generalization than open-loop baseline methods when expert data follows FBNE assumption
- Characterizes the non-convexity of the inverse feedback game problem with multiple isolated global minima

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The algorithm uses linearization and quadraticization of nonlinear dynamics and costs to approximate the FBNE solution, enabling efficient gradient computation.
- Mechanism: The ILQGames algorithm is employed as a submodule to solve the forward nonlinear dynamic game approximately at each iteration. This linearization and quadraticization allows the loss function to be approximated by a tractable LQ game, whose equilibrium can be computed efficiently.
- Core assumption: The local linear-quadratic approximation around the current state and control trajectory is sufficiently accurate to enable meaningful gradient updates.
- Break condition: If the dynamics or cost functions are highly nonlinear or discontinuous, the local linearization may not provide a good approximation, leading to poor gradient estimates and slow convergence.

### Mechanism 2
- Claim: The gradient approximation treats the linearized dynamics and quadraticized costs as constants with respect to the cost parameters, enabling efficient partial derivative computation.
- Mechanism: Instead of computing the total derivative of the loss with respect to cost parameters, which would involve complex dependencies through the linearized dynamics, the algorithm approximates the gradient by treating the linearized dynamics and quadraticized costs as constants and only computing partial derivatives with respect to the cost parameters.
- Core assumption: The changes in cost parameters are small enough that the linearized dynamics remain a good approximation throughout the gradient update step.
- Break condition: If the cost parameters change significantly between iterations, the linearization approximation may break down, leading to inaccurate gradient estimates and poor convergence.

### Mechanism 3
- Claim: The coordinate descent approach, alternating between updating the initial condition and the cost parameters, enables efficient joint inference of both quantities.
- Mechanism: The algorithm first updates the estimate of the initial condition using gradient descent on the loss function, then updates the cost parameters using gradient descent, and repeats this process until convergence. This allows for joint inference of the initial condition and cost parameters without requiring them to be optimized simultaneously.
- Core assumption: The loss function is sufficiently smooth and the coordinate descent updates lead to a decrease in the loss function at each iteration.
- Break condition: If the loss function has many local minima or the coordinate descent updates do not lead to a decrease in the loss function, the algorithm may get stuck in suboptimal solutions or fail to converge.

## Architecture Onboarding

- Component map: ILQGames solver -> Gradient approximation module -> Coordinate descent optimizer -> Loss function
- Critical path:
  1. Initialize cost parameters and initial condition.
  2. Use ILQGames to solve the forward game and obtain an approximate FBNE trajectory.
  3. Compute approximate gradients using the gradient approximation module.
  4. Update the initial condition using gradient descent.
  5. Re-solve the forward game with the updated initial condition.
  6. Compute gradients and update the cost parameters using gradient descent.
  7. Repeat steps 2-6 until convergence.

- Design tradeoffs:
  - Accuracy vs. efficiency: The ILQGames approximation trades off accuracy for computational efficiency, which may lead to suboptimal solutions in highly nonlinear games.
  - Robustness vs. sensitivity: The gradient approximation assumes small changes in cost parameters, which may not hold in all cases, leading to sensitivity to initialization and hyperparameters.

- Failure signatures:
  - Slow convergence or oscillation: May indicate that the ILQGames approximation is not accurate enough or that the learning rate is too high.
  - Poor generalization to unseen initial conditions: May suggest that the inferred costs are overfitting to the observed data or that the regularization terms are not properly tuned.

- First 3 experiments:
  1. Validate the gradient approximation: Compare the approximate gradients to finite difference estimates on a simple LQ game with known solutions.
  2. Test the algorithm on a nonlinear game with known costs: Generate synthetic data from a nonlinear game with known costs and evaluate the algorithm's ability to recover the true costs.
  3. Evaluate robustness to noise and partial observability: Generate noisy, partial observations of the expert trajectories and assess the algorithm's performance in recovering the true costs and generalizing to unseen initial conditions.

## Limitations
- The gradient approximation scheme may not be accurate for highly nonlinear or discontinuous dynamics and cost functions.
- The coordinate descent approach may struggle to find global optima in the presence of multiple isolated minima.
- Robustness claims require more rigorous testing across diverse game scenarios beyond the platooning examples.

## Confidence

**High Confidence**: The characterization of the inverse feedback dynamic game problem as non-convex with multiple isolated global minima is well-supported by the theoretical analysis in Section 4. The use of ILQGames as a submodule for forward problem approximation follows established methods in the literature.

**Medium Confidence**: The gradient approximation scheme's effectiveness is demonstrated empirically but lacks theoretical guarantees for convergence to global optima. The coordinate descent approach shows promise but may be sensitive to initialization and hyperparameters.

**Low Confidence**: The generalization claims to unseen initial conditions, while supported by the platooning experiments, require validation on more diverse game scenarios to establish robustness.
