# IQL-TD-MPC: Implicit Q-Learning for Hierarchical Model Predictive Control

## Quick Facts
- arXiv ID: 2306.00867
- Source URL: https://arxiv.org/abs/2306.00867
- Reference count: 14
- Hierarchical offline RL approach combining IQL with TD-MPC to solve long-horizon sparse-reward tasks, achieving >40 average scores on antmaze compared to near-zero without hierarchy.

## Executive Summary
IQL-TD-MPC introduces a hierarchical offline reinforcement learning framework that integrates Implicit Q-Learning with Temporal Difference Learning for Model Predictive Control. The approach addresses the challenge of long-horizon sparse-reward tasks by using IQL-TD-MPC as a high-level Manager that generates intent embeddings, which are then combined with state representations for any offline RL algorithm acting as a Worker. This hierarchical structure enables better exploration of the state-action space while maintaining the benefits of offline training.

## Method Summary
The method combines IQL's implicit policy regularization with TD-MPC's model-based planning in an offline setting. IQL handles out-of-distribution actions by learning conservative Q-functions, while TD-MPC uses these learned policies for planning without requiring online interaction. The hierarchical framework positions IQL-TD-MPC as the Manager component, generating intent embeddings that are concatenated to state representations. Any standard offline RL algorithm can then serve as the Worker, receiving both the original state and the high-level intent to make decisions. This architecture enables tackling complex long-horizon tasks by decomposing them into manageable sub-problems.

## Key Results
- Achieves average scores over 40 on challenging antmaze tasks compared to near-zero scores without hierarchical approach
- Significantly outperforms standard offline RL algorithms (AWAC, TD3-BC, DT, CQL) when used in hierarchical framework
- Demonstrates effectiveness of combining model-based planning with implicit policy regularization for offline RL

## Why This Works (Mechanism)
The approach works by leveraging IQL's ability to learn conservative Q-functions that avoid out-of-distribution actions in the offline setting, while TD-MPC provides model-based planning capabilities using these learned policies. The hierarchical decomposition allows the high-level Manager to plan over longer horizons using intent embeddings, while the Worker focuses on low-level execution. This separation of concerns enables better credit assignment and exploration in sparse-reward environments.

## Foundational Learning
- **Implicit Q-Learning**: Conservative Q-function learning that avoids out-of-distribution actions; needed to ensure safe offline training, quick check: verify Q-values don't increase for unseen actions
- **Temporal Difference Learning for MPC**: Model-based planning using learned dynamics; needed for long-horizon reasoning, quick check: validate planning rollouts match actual environment transitions
- **Hierarchical RL**: Decomposition of tasks into high-level goals and low-level execution; needed for managing complexity, quick check: ensure intent embeddings capture meaningful sub-goals
- **Offline RL**: Learning from fixed datasets without exploration; needed for real-world applications, quick check: confirm no policy queries leave training distribution
- **State-Action Value Functions**: Estimation of expected returns; fundamental for all RL approaches, quick check: verify Bellman backups converge
- **Model Predictive Control**: Receding horizon planning with learned models; needed for efficient long-term planning, quick check: validate planning horizon matches task requirements

## Architecture Onboarding

**Component Map:**
Dataset -> IQL (Q-function learning) -> TD-MPC (Planning) -> Manager (Intent generation) -> Worker (Low-level control)

**Critical Path:**
1. Learn conservative Q-functions using IQL from offline dataset
2. Use learned policies in TD-MPC for model-based planning
3. Generate intent embeddings from high-level plans
4. Concatenate intents with states for Worker algorithm
5. Execute low-level actions using Worker policy

**Design Tradeoffs:**
- Model accuracy vs computational efficiency in TD-MPC planning
- Intent embedding complexity vs Worker algorithm simplicity
- Conservatism in IQL vs exploration capability
- Planning horizon length vs real-time constraints

**Failure Signatures:**
- Poor performance indicates dataset coverage issues or model inaccuracies
- Instability suggests insufficient conservatism in IQL learning
- Suboptimal exploration points to inadequate intent embedding design

**First Experiments:**
1. Validate IQL-TD-MPC Manager performance on simple navigation tasks with dense rewards
2. Test intent embedding quality by visualizing high-level plan trajectories
3. Evaluate Worker performance with ground-truth intents versus learned intents

## Limitations
- Performance heavily depends on dataset quality and coverage of high-level decision space
- Computational overhead of IQL-TD-MPC integration not characterized, raising scalability concerns
- Evaluation focused primarily on antmaze domains, generalization to other hierarchical tasks uncertain

## Confidence
- **High Confidence**: Core algorithmic combination of IQL with TD-MPC is technically sound with robust empirical improvements on D4RL antmaze
- **Medium Confidence**: Consistent outperformance of non-hierarchical baselines supported, but improvement magnitude varies with dataset quality
- **Low Confidence**: Scalability to complex domains and applicability beyond navigation tasks not thoroughly validated
