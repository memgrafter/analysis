# Machine Learning Model Attribution Challenge

## Quick Facts
- arXiv ID: 2302.06716
- Source URL: https://arxiv.org/abs/2302.06716
- Reference count: 12
- Primary result: Manual observation of base model training data characteristics was most effective for attributing fine-tuned LLMs, with the top team correctly identifying seven base models.

## Executive Summary
This paper presents the findings of a competition challenging participants to identify the base models underlying anonymous, fine-tuned large language models using only textual outputs. The challenge attracted both manual and automated approaches, with manual observation of base model training data characteristics proving most successful. Participants examined model card documentation and compared outputs to identify unique signatures. The competition highlighted the difficulty of model attribution while demonstrating that human expertise in analyzing training data and output patterns remains superior to purely statistical approaches for this task.

## Method Summary
The challenge involved identifying base models from a set of anonymous, fine-tuned LLMs using only textual outputs. Participants employed two main approaches: manual observation of similarities between fine-tuned and base model outputs, leveraging training data documentation, and automated statistical methods measuring output similarity. The manual approach involved generating prompts targeting specific training data characteristics documented in model cards and comparing outputs. Automated approaches used metrics like edit distance to measure similarity between base and fine-tuned model outputs. The evaluation metric prioritized correct attribution with ties broken by fewest API calls to the fine-tuned models.

## Key Results
- Manual approaches won the competition, with participants observing output similarities and developing attribution heuristics based on base model training data documentation
- The top-scoring team correctly identified seven base models using hand-crafted prompts and reasoning about base model training data
- Automated statistical approaches measuring output similarity showed some success but were generally less effective than manual methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Manual observation of base model training data differences enables attribution.
- Mechanism: Participants examined training data characteristics (temporal range, domain, language) documented in base model cards and compared outputs to identify unique signatures.
- Core assumption: Training data characteristics persist through fine-tuning and create distinguishable output patterns.
- Evidence anchors:
  - [abstract] "The most successful approaches were manual, as participants observed similarities between model outputs and developed attribution heuristics based on public documentation of the base models"
  - [section] "The participants reasoned about the fine-tuned models by searching for differences they could trace to the training data of the base model. The training data used for most base models is documented online in the model card."
- Break condition: If fine-tuning data dominates base model characteristics or if multiple models share similar training data, this approach fails.

### Mechanism 2
- Claim: Output similarity between base and fine-tuned models indicates attribution.
- Mechanism: Participants generated text from both base and fine-tuned models using the same prompts and measured similarity in continuations.
- Core assumption: Fine-tuned models retain sufficient similarity to their base models to be distinguishable from other base models.
- Evidence anchors:
  - [abstract] "several teams also submitted automated, statistical solutions" suggesting similarity measurement was used
  - [section] "Participants also observed similarities in output between base models and fine-tuned models" and "several fine-tuned and base model pairs were observed to have the same continuation for some natural language prompts"
- Break condition: If fine-tuning significantly alters output patterns or if multiple base models produce similar outputs, similarity measures become unreliable.

### Mechanism 3
- Claim: API characteristics reveal base model information.
- Mechanism: Participants observed differences in API behavior (loading time, failure rates) that correlated with base model properties.
- Core assumption: Base model architecture affects API performance characteristics that persist through fine-tuning.
- Evidence anchors:
  - [section] "Finally, two participants used observations about the competition API, specifically that two models took much longer to load and failed to return a response more often. They attributed these fine-tuned models to the largest base models."
- Break condition: If API implementation details vary independently of base model characteristics or if fine-tuning changes computational requirements.

## Architecture Onboarding

- Component map: Participant interaction interface -> Competition API -> Fine-tuned model instances -> Base model storage
- Critical path: Participant query → API processing → model generation → output comparison → attribution decision
- Design tradeoffs: Manual approaches require domain expertise but are more accurate; automated approaches scale better but may be less precise
- Failure signatures: Incorrect attributions occur when base models share training data, when fine-tuning significantly alters output, or when API characteristics don't correlate with model properties
- First 3 experiments:
  1. Generate identical prompts from all base models and measure output diversity
  2. Fine-tune a known base model and test attribution accuracy with manual and automated methods
  3. Vary fine-tuning data characteristics and measure impact on attribution success rate

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can manual model attribution techniques scale to larger sets of base models, especially when those models share training data?
- Basis in paper: [explicit] The paper states that manual approaches won't scale to larger numbers of possible base models, especially base models that share training data.
- Why unresolved: The paper demonstrates manual techniques worked for a limited set of 13 models but doesn't test their effectiveness with larger, more overlapping model sets.
- What evidence would resolve it: A controlled experiment testing manual attribution techniques on progressively larger sets of base models, including those with overlapping training data, would demonstrate scalability limits.

### Open Question 2
- Question: Would increasing the number of API calls improve the accuracy of automated model attribution approaches?
- Basis in paper: [explicit] The paper notes that the proposed solutions used a very modest number of API calls and states "it remains to be seen if their accuracy would improve as API calls increased."
- Why unresolved: The competition constrained API calls to simulate a real-world scenario, preventing participants from testing whether more queries would yield better results.
- What evidence would resolve it: A systematic study varying the number of API calls (while keeping other variables constant) to measure the relationship between query volume and attribution accuracy.

### Open Question 3
- Question: Can specific input prompts be learned that produce more unique outputs across different models, improving attribution accuracy?
- Basis in paper: [explicit] The paper suggests that future approaches could "build on this work by learning input prompts that produce more unique outputs in a given model."
- Why unresolved: Current approaches used either manual prompt selection or random prompts, but no systematic method for learning optimal prompts has been developed or tested.
- What evidence would resolve it: Development and testing of a prompt-learning algorithm that optimizes for model-discriminative outputs, with empirical comparison to baseline approaches.

## Limitations

- The specific fine-tuned models used in the challenge are not provided, preventing direct replication of exact results
- Limited quantitative comparison between manual and automated approaches across all participants
- Insufficient discussion of failure cases and edge conditions where attribution methods might break down

## Confidence

- Manual attribution approaches: High
- Automated attribution approaches: Medium
- API-based characteristics: Low

## Next Checks

1. Conduct controlled experiments with known fine-tuned models to validate whether training data characteristics persist through fine-tuning and remain distinguishable.
2. Implement and test the automated similarity measurement approach on a diverse set of base and fine-tuned model pairs to quantify its effectiveness compared to manual methods.
3. Analyze edge cases where multiple base models share similar training data characteristics to determine attribution failure rates and identify distinguishing features.
