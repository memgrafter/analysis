# MIGPerf: A Comprehensive Benchmark for Deep Learning Training and Inference Workloads on Multi-Instance GPUs

## Quick Facts
- arXiv ID: 2301.00407
- Source URL: https://arxiv.org/abs/2301.00407
- Reference count: 35
- Key outcome: MIGPerf is an open-source tool that benchmarks deep learning training and inference workloads on Multi-Instance GPUs (MIG), revealing MIG's effectiveness for various workloads and superiority over MPS for large batch sizes.

## Executive Summary
MIGPerf is an open-source benchmark tool designed to streamline performance evaluation of deep learning training and inference workloads on Multi-Instance GPUs (MIG). The tool addresses the challenges of manual benchmarking and framework compatibility by providing a unified workflow that abstracts MIG partitioning, workload execution, and result collection. MIGPerf enables comprehensive performance analysis, including throughput, latency, GPU utilization, memory usage, and energy consumption, across different MIG partition sizes and workloads. The authors validate MIGPerf using A100 and A30 GPUs, demonstrating its effectiveness in comparing MIG with software-based GPU sharing methods like MPS.

## Method Summary
MIGPerf provides a unified benchmark workflow that abstracts MIG partitioning, workload execution, and result collection. The tool includes a controller module to manage GPU partitioning, a profiler to run training/inference workloads, and an exporter to format results for tools like Prometheus. MIGPerf is implemented atop widely used model development frameworks like HuggingFace, allowing easy extension to new models and metrics. The authors conduct experiments using MIGPerf on A100 and A30 GPUs, evaluating performance metrics such as throughput, latency, GPU utilization, memory usage, and energy consumption. The results provide insights into MIG's effectiveness for various workloads, including training and inference tasks, and compare MIG with software-based GPU sharing methods like MPS.

## Key Results
- MIGPerf enables efficient benchmarking of MIG GPUs, addressing challenges of manual benchmarking and framework compatibility.
- The tool reveals MIG's superiority over MPS in terms of tail latency and stability for large batch sizes.
- MIGPerf's modular design allows easy extension to new models, frameworks, and metrics, laying the foundation for future research on hybrid training and inference workload orchestration on MIG GPUs.

## Architecture Onboarding

- Component map:
  - MIG Controller: Handles MIG enablement, partitioning, and compute instance management.
  - MIG Profiler: Runs training/inference workloads, monitors performance via DCGM, saves results.
  - Exporter: Formats results for analysis tools (Prometheus, Jupyter).
  - Visualizer: Provides quick result analysis.
  - Client: Remote control interface for users.

- Critical path: MIG Controller → MIG Profiler → Exporter → Visualizer
- Design tradeoffs:
  - Modularity vs. integration complexity: Easy to extend but requires careful coordination.
  - Real-time monitoring vs. overhead: DCGM monitoring adds latency but provides detailed metrics.
  - Framework support vs. maintenance: Supporting multiple frameworks increases code but improves usability.

- Failure signatures:
  - MIG partitioning fails → Controller logs error, no GIs available.
  - Profiler cannot find device → Workload performer raises "device not found" error.
  - Exporter cannot connect to database → Results saved locally but not accessible to external tools.

- First 3 experiments:
  1. Run ResNet-50 training on a single MIG partition (e.g., 1g.10gb) with varying batch sizes; measure throughput and utilization.
  2. Deploy BERT inference on MIG vs MPS with small batch sizes; compare tail latency.
  3. Execute multiple concurrent ResNet-18 inference processes on MIG partitions; monitor tail latency under increasing request rates.
