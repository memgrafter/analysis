# UDApter -- Efficient Domain Adaptation Using Adapters

## Quick Facts
- arXiv ID: 2302.03194
- Source URL: https://arxiv.org/abs/2302.03194
- Reference count: 22
- Primary result: UDApter achieves competitive UDA performance by fine-tuning only a fraction of model parameters

## Executive Summary
This paper introduces UDApter, two parameter-efficient methods for unsupervised domain adaptation using adapter modules. The first method (TS-DT-) learns domain-invariant representations through domain adapters before adding task adapters for task-specific learning. The second method (JOINT-DT-) jointly optimizes both domain divergence reduction and task loss with a single adapter. Experiments on AMAZON sentiment analysis and MNLI natural language inference datasets demonstrate that UDApter outperforms strong baselines including DANN and DSN while fine-tuning only a small fraction of parameters.

## Method Summary
UDApter uses adapter modules inserted into transformer layers to enable efficient domain adaptation. The methods employ small bottleneck layers that can be trained while keeping the main model frozen. Two approaches are proposed: TS-DT- sequentially trains domain adapters to learn domain-invariant features before adding task adapters for task-specific learning, while JOINT-DT- uses a single adapter to jointly minimize both domain divergence and task loss. Both methods use MK-MMD divergence to measure and reduce domain differences.

## Key Results
- UDApter achieves competitive performance compared to strong UDA baselines while fine-tuning only a fraction of parameters
- TS-DT- and JOINT-DT- methods outperform DANN and DSN on AMAZON and MNLI datasets
- UDApter achieves within 0.85% F1 of state-of-the-art UDA methods on the natural language inference task
- Parameter efficiency is significantly improved compared to full fine-tuning approaches

- Core assumption: Reducing marginal distribution divergence leads to domain-invariant features that improve transfer.

- Claim: Joint optimization of domain divergence and task loss can learn both domain-invariant and task-specific features simultaneously.

## Architecture Onboarding

- Component map:
  Transformer backbone (frozen) -> Domain adapter layers (learnable) -> Task adapter layers (learnable) -> Classification head

- Critical path:
  1. Compute representations for source and target through domain adapters
  2. Calculate divergence loss between these representations
  3. Backpropagate only through adapter parameters
  4. For task adapters, compute task loss on source labels
  5. Backpropagate only through task adapter parameters

- Design tradeoffs:
  - Sequential (TS-DT-) vs joint (JOINT-DT-) training: Sequential offers composability but requires more parameters; joint is more parameter-efficient but less flexible.
  - Adapter reduction factor: Smaller reduction factors generally perform better but increase parameter count.
  - Divergence measure choice: MK-MMD worked best in experiments but may not generalize to all domains.

- Failure signatures:
  - If divergence loss plateaus early: Domain adapters aren't learning effective invariance
  - If task accuracy drops significantly from baseline: Task adapters aren't leveraging domain-invariant features properly
  - If both losses oscillate: Learning rate or lambda scheduling may need adjustment

- First 3 experiments:
  1. Implement domain adapters only with MK-MMD divergence on a simple dataset (e.g., AMAZON with 2 domains) to verify divergence reduction works
  2. Add task adapters sequentially (TS-DT-) and test on same dataset to verify composability and performance improvement
  3. Implement joint optimization (JOINT-DT-) and compare parameter efficiency vs. sequential approach

## Open Questions the Paper Calls Out

- How well do UDApter methods perform when using different backbone transformer models beyond BERT-base-uncased?
- Can UDApter be effectively applied to non-classification tasks like machine translation or text generation?
- How important is aligning label distributions in addition to marginal distributions for NLP domain adaptation?

## Limitations

- Only tested with BERT-base-uncased as the backbone model
- Limited to classification and NLI tasks, not generation tasks
- Does not explore label distribution alignment which may be important for NLP adaptation
