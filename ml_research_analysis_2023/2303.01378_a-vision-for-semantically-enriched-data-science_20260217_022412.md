# A Vision for Semantically Enriched Data Science

## Quick Facts
- arXiv ID: 2303.01378
- Source URL: https://arxiv.org/abs/2303.01378
- Authors: 
- Reference count: 40
- Primary result: Automated machine learning can be significantly enhanced by incorporating semantic understanding of data through knowledge graphs, formula mining, and causal dependencies.

## Executive Summary
This paper presents a vision for semantically enriched data science that addresses the limitations of current automated machine learning approaches. The authors argue that while automation has made progress in areas like feature selection and hyperparameter tuning, it has not adequately leveraged domain knowledge and data semantics. They propose a framework that integrates semantic annotation and reasoning to improve data augmentation, transformation, and model explainability by mapping data to real-world concepts and utilizing external knowledge sources.

## Method Summary
The proposed method involves semantic annotation and reasoning to enhance automated machine learning tasks. The approach uses knowledge graph-based column type annotation (CTA) and property annotation (CPA) to map tabular data to real-world concepts. It incorporates code and text mining to discover relevant formulas and expressions for feature engineering. The framework also leverages causal dependencies between attributes to impose semantic constraints and improve model trustworthiness. The system integrates these components into an automated pipeline that transforms raw data into semantically enriched features for machine learning models.

## Key Results
- Semantic understanding can improve automated feature engineering by mapping data columns to real-world concepts using knowledge graphs
- Knowledge graph-based semantic annotation enables meaningful data transformations and formula discovery
- Incorporating causal dependencies helps build trustworthy models that avoid spurious correlations and improve explainability

## Why This Works (Mechanism)

### Mechanism 1
Semantic annotation improves automated feature engineering by enabling formula discovery and meaningful data transformations. By mapping data columns to real-world concepts using knowledge graphs and mined code/text repositories, the system can automatically discover relevant formulas (e.g., BMI, CFR) and apply them as features. The core assumption is that domain-specific formulas and transformations are recoverable from existing code repositories and knowledge bases. Evidence shows semantic understanding can improve tasks like feature engineering and model trustworthiness. Break condition occurs if semantic mapping fails to accurately connect data columns to relevant knowledge graph concepts.

### Mechanism 2
Knowledge graph-based column type annotation (CTA) and property annotation (CPA) enable automated semantic understanding of tabular data. Systems use neural network-based meta-learning on embeddings of column vectors to map named entity columns to knowledge graph concepts and properties, improving automated feature engineering. The core assumption is that knowledge graphs contain sufficient coverage of relevant concepts for the target domain. Evidence includes approaches that assume knowledge graph existence for table understanding. Break condition occurs if knowledge graphs have poor recall, limiting semantic annotation effectiveness.

### Mechanism 3
Incorporating causal dependencies between attributes enables semantically coherent learning and improves model fairness and explainability. By leveraging causal information to impose semantic constraints and evaluate attribute dependencies, models can avoid spurious correlations and improve trustworthiness. The core assumption is that causal dependencies between attributes can be accurately estimated from observational data or external knowledge sources. Evidence includes studies exploring causal information for semantic constraints and interventions. Break condition occurs if causal dependencies cannot be accurately estimated or incorporated into the learning framework.

## Architecture Onboarding

- **Component map**: Data ingestion → Semantic Annotation (CTA/CPA) → Knowledge Graph Mapping → Formula Mining → Feature Engineering → Model Training
- **Critical path**: Data → Semantic Annotation → Knowledge Graph Mapping → Formula Mining → Feature Engineering → Model Training
- **Design tradeoffs**: Tradeoff between knowledge graph-based approaches (high precision but limited recall) and knowledge-agnostic approaches (better recall but potentially lower precision)
- **Failure signatures**: Poor semantic mapping leads to irrelevant feature generation; inaccurate causal dependencies lead to biased or incorrect models; mining failures lead to missing important transformations
- **First 3 experiments**:
  1. Test semantic column annotation accuracy on a benchmark dataset with known ground truth mappings
  2. Implement and evaluate formula discovery from code repositories for a specific domain
  3. Compare feature engineering performance with and without semantic constraints on a standard dataset

## Open Questions the Paper Calls Out

### Open Question 1
How can we effectively infer semantics from numeric data in tabular datasets? This remains unresolved because current approaches struggle with recall and scalability when dealing with numeric data, and there is a lack of benchmarks for evaluating numeric column-to-concept mapping. Development of robust embedding techniques for numeric data, coupled with comprehensive annotated benchmarks, would demonstrate progress.

### Open Question 2
How can we efficiently mine and integrate actionable information from large code and text repositories for feature engineering? While mining techniques exist, integrating diverse sources of information and linking them to specific data science tasks remains an open problem. Demonstration of a system that can automatically extract and apply relevant formulas from code and text to improve feature engineering across multiple domains would resolve this.

### Open Question 3
How can we develop techniques to automatically detect and mitigate bias in machine learning models using semantic understanding? Current techniques rely heavily on manual validation and external information, and there is a lack of methods to automatically infer semantic constraints and dependencies from data. Development of automated techniques that can infer causal dependencies and semantic constraints from data, and use them to adjust model training and mitigate bias, would resolve this.

## Limitations
- Limited empirical validation of the full semantic data science pipeline's effectiveness
- Scalability challenges with knowledge graph-based approaches due to poor coverage (only 3% of tables matched in estimates)
- Significant technical hurdles in accurately estimating causal relationships from observational data

## Confidence

- **High confidence**: The identification of current gaps in automated data science and the importance of semantic understanding
- **Medium confidence**: The proposed mechanisms for semantic annotation and feature engineering, as they rely on demonstrated but not yet widely validated techniques
- **Low confidence**: The scalability and practical effectiveness of the full semantic data science pipeline, particularly regarding knowledge graph coverage and causal dependency estimation
