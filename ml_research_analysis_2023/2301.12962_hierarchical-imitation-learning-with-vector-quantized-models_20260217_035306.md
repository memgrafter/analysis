# Hierarchical Imitation Learning with Vector Quantized Models

## Quick Facts
- arXiv ID: 2301.12962
- Source URL: https://arxiv.org/abs/2301.12962
- Reference count: 40
- Hierarchical imitation learning approach segments expert trajectories and outperforms state-of-the-art baselines in complex reasoning tasks

## Executive Summary
This paper introduces HIPS, a hierarchical imitation learning framework that segments expert trajectories into variable-length subtrajectories using reinforcement learning. The method identifies subgoals by associating reward magnitude with low-level action predictability, then trains a vector-quantized generative model (VQVAE) on these subgoals for high-level planning. By combining learned subgoal generation with a low-level policy and standard search algorithms, HIPS achieves state-of-the-art performance on four complex reasoning environments including Sokoban and Traveling Salesman Problem.

## Method Summary
HIPS segments expert demonstrations into variable-length subtrajectories using reinforcement learning, identifying subgoals where reward magnitude correlates with low-level action predictability. These subgoals are represented using a vector-quantized generative model (VQVAE) that enables efficient high-level planning. The hierarchical architecture consists of a high-level policy that generates subgoal sequences and a low-level policy that executes actions to achieve these subgoals. The approach integrates with standard search algorithms like PHS*, MCTS, and A* to solve complex reasoning tasks more effectively than previous methods.

## Key Results
- Achieves 97.5% success rate on Sokoban, significantly outperforming baseline PIF
- Solves 99.9% of Traveling Salesman Problem instances while finding better solutions than training data
- Discovers trajectories that improve upon the quality of expert demonstrations in the training set
- Outperforms state-of-the-art baselines across all four tested environments (Sokoban, Sliding Tile Puzzle, Box-World, and TSP)

## Why This Works (Mechanism)
The method works by decomposing complex tasks into manageable subtasks through subgoal identification. High-reward states that are also predictable from previous actions serve as natural subgoal candidates. The VQVAE model provides a compressed, discrete representation of these subgoals that enables efficient planning while preserving essential information. This hierarchical decomposition allows the system to handle long-horizon tasks by breaking them into shorter, more tractable segments, while the integration with search algorithms ensures optimal path planning between subgoals.

## Foundational Learning
- Vector Quantized Variational Autoencoders (VQVAEs): Discrete latent variable models that learn compressed representations of data
  - Why needed: To create efficient, discrete subgoal representations for planning
  - Quick check: Can the VQVAE reconstruct subgoals with minimal information loss
- Hierarchical Reinforcement Learning: Decomposing tasks into high-level goals and low-level actions
  - Why needed: To handle long-horizon tasks by breaking them into manageable segments
  - Quick check: Does the high-level policy successfully coordinate with the low-level policy
- Subgoal Identification via Reward Predictability: Using reward magnitude and action predictability to find meaningful subtask boundaries
  - Why needed: To automatically discover natural decomposition points in expert trajectories
  - Quick check: Are identified subgoals associated with meaningful task progress
- Search Algorithm Integration: Combining learned policies with traditional planning methods
  - Why needed: To ensure optimal path planning between subgoals
  - Quick check: Does the combined approach outperform pure learning or pure search

## Architecture Onboarding

Component Map: Expert Trajectories -> Subgoal Segmentation -> VQVAE Training -> High-Level Policy + Low-Level Policy -> Search Algorithm -> Task Solution

Critical Path: Expert Demonstrations → Subgoal Identification → VQVAE Representation → High-Level Planning → Low-Level Execution → Task Completion

Design Tradeoffs:
- Discrete vs continuous subgoal representations: VQVAE provides computational efficiency but may lose information
- Number of subgoals: More subgoals increase planning flexibility but require more training data
- Search algorithm choice: Different algorithms offer tradeoffs between solution quality and computation time

Failure Signatures:
- Poor subgoal identification leading to inefficient task decomposition
- VQVAE compression loss causing suboptimal high-level planning
- Mismatch between high-level subgoal selection and low-level execution capabilities
- Search algorithm getting stuck in local optima

First Experiments:
1. Validate subgoal identification by visualizing high-reward, predictable states in expert trajectories
2. Test VQVAE reconstruction quality on held-out subgoals to measure information retention
3. Evaluate high-level policy performance in isolation before integrating with low-level policy

## Limitations
- Requires substantial expert demonstrations (10,000 trajectories per environment), limiting applicability to data-scarce domains
- Vector quantization may introduce information loss affecting long-term planning in environments with subtle state differences
- Assumes high-reward states correspond to meaningful subgoals, which may not hold in environments with dense or non-monotonic rewards
- Performance comparisons limited to only one baseline (PIF), raising questions about the specific source of improvements

## Confidence
- High confidence in method effectiveness on tested environments and benchmark results
- Medium confidence in VQVAE providing better subgoal representation than alternatives
- Low confidence in generalization to domains with continuous action spaces or non-deterministic environments

## Next Checks
1. Test the method on environments with continuous state and action spaces to evaluate scalability beyond discrete domains
2. Conduct ablation studies to isolate contributions of individual components (VQVAE, hierarchical structure, subgoal identification)
3. Evaluate performance with varying amounts of expert data (100, 1,000, and 10,000 trajectories) to establish data efficiency requirements
