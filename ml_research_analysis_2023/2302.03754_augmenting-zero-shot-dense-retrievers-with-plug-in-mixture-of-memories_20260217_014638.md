# Augmenting Zero-Shot Dense Retrievers with Plug-in Mixture-of-Memories

## Quick Facts
- arXiv ID: 2302.03754
- Source URL: https://arxiv.org/abs/2302.03754
- Reference count: 28
- Key outcome: MoMA achieves strong zero-shot retrieval accuracy on 18 BEIR tasks, outperforming systems with larger models and more computation

## Executive Summary
This paper introduces Mixture-of-Memory Augmentation (MoMA), a mechanism that enhances zero-shot dense retrieval by retrieving augmentation documents from multiple external corpora. The method jointly trains an augmentation component with the retrieval model using supervision signals and hard negatives, enabling plug-in of new memory at inference time. Experiments on the BEIR benchmark demonstrate that MoMA significantly outperforms existing methods, particularly for biomedical and scientific domains, while maintaining efficiency through its FiD-based fusion architecture.

## Method Summary
MoMA retrieves augmentation documents from a mixture of external corpora (Wikipedia, MeSH) to enhance query representations for dense retrieval. The method uses a T5-based architecture where a separate augmentation retriever selects K documents from the memory mixture, which are then fused with the query using a FiD decoder. The model is jointly trained with ANCE-style hard negatives, and at inference time, the target corpus can be plugged into the memory mixture for zero-shot adaptation. The training process involves three episodes of joint training with three epochs each, using BM25 negatives for initial warm-up.

## Key Results
- MoMA outperforms T5-ANCE and other baselines on BEIR benchmark, achieving 16.0% average NDCG@10 improvement
- The method shows particularly strong performance on biomedical and scientific datasets (31.1% and 23.1% improvements respectively)
- MoMA with 3 memory sources (MARCO, Wikipedia, MeSH) achieves comparable performance to much larger models like GTR-XXL
- Plug-in memory enables effective zero-shot adaptation, with target corpus documents successfully retrieved even when only available at test time

## Why This Works (Mechanism)

### Mechanism 1
Joint training with hard negatives from the memory mixture improves augmentation component quality. The augmentation model f_a() is trained using hard negatives mined from the mixture-of-memory corpora, forcing it to distinguish between relevant and irrelevant augmentation documents. This is combined with attention scores from the FiD decoder that approximate document usefulness.

### Mechanism 2
FiD architecture enables efficient fusion of multiple augmentation documents with the query. The FiD mechanism separately encodes K augmentation documents with the T5 encoder, then uses one decoder that attends to all encoded vectors. This is more efficient than concatenating all text pieces and more expressive than encoding them independently.

### Mechanism 3
Plug-in memory enables zero-shot adaptation by providing in-domain context without parameter updates. At inference time, the target corpus is added to the memory mixture (M = M ∪ C_t \ C_s), allowing the augmentation model to retrieve in-domain documents that weren't available during training. The main model parameters remain frozen.

## Foundational Learning

- **Dense retrieval and vector similarity**: MoMA builds upon dense retrieval by adding augmentation documents to query representations. Quick check: What is the scoring function used in dense retrieval and how does it differ from sparse retrieval?

- **Attention mechanisms and cross-attention**: FiD decoder's cross-attention to encoded documents determines which augmentation documents are useful. Quick check: How does the FiD decoder's attention to multiple encoded inputs differ from standard self-attention?

- **Hard negative mining in contrastive learning**: Both the main retrieval model and augmentation component use hard negatives for training. Quick check: What is the difference between random negatives and hard negatives, and why are hard negatives more effective for training?

## Architecture Onboarding

- **Component map**: Query encoder -> Query representation; Query + memory mixture -> Augmentation retriever -> K augmentation documents; Base query + K augmentation documents -> FiD encoder -> Fused representations; Fused query representation + document representations -> Final retrieval scores

- **Critical path**: 1) Input query → Query encoder → Base query representation; 2) Query + memory mixture → Augmentation retriever → K augmentation documents; 3) Base query + K augmentation documents → FiD encoder → Fused representations; 4) Fused query representation + document representations → Final retrieval scores

- **Design tradeoffs**: Joint training complexity vs. performance gain; Memory mixture size vs. efficiency; Number of augmentation documents K vs. model capacity

- **Failure signatures**: Poor zero-shot performance; Overfitting to training data; High computational cost; Degraded main retrieval accuracy

- **First 3 experiments**: 1) Ablation study comparing MoMA with T5-ANCE on BEIR; 2) Memory analysis testing MoMA with different memory compositions; 3) Plug-in test evaluating zero-shot performance with and without target corpus

## Open Questions the Paper Calls Out

1. How to efficiently select effective grounding corpora for specific domains beyond the empirical settings tested in this paper. The paper mentions this needs customization according to query domains and user needs.

2. Can the joint learning mechanism be extended to handle more than three memory sources while maintaining computational efficiency? The paper only tests with three sources and doesn't explore scalability limits.

3. How does MoMA's performance compare to other retrieval-augmented approaches when applied to non-textual data or multimodal retrieval tasks? The paper focuses exclusively on text-based dense retrieval.

## Limitations

- The paper doesn't fully establish whether hard negatives are superior to pure attention distillation through direct comparison
- FiD architecture efficiency claims lack direct ablation studies comparing it to alternative fusion methods
- Computational overhead of joint training and potential for overfitting when memory mixtures are small are acknowledged but not thoroughly quantified

## Confidence

- **High Confidence**: MoMA improves zero-shot retrieval accuracy on BEIR benchmark compared to T5-ANCE and other baselines
- **Medium Confidence**: Joint training with hard negatives is more effective than attention distillation alone
- **Medium Confidence**: FiD architecture provides optimal balance of efficiency and capacity for fusion
- **Medium Confidence**: Plug-in memory enables effective zero-shot adaptation

## Next Checks

1. Implement a controlled experiment comparing MoMA trained with only attention distillation versus MoMA with hard negative mining to quantify the contribution of hard negatives.

2. Create alternative fusion methods including simple concatenation and independent encoding with averaging, then compare zero-shot retrieval accuracy and computational efficiency against the FiD approach.

3. Systematically vary the composition and size of the memory mixture across different domain combinations to measure how zero-shot performance changes and identify optimal memory configurations.
