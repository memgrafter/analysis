# Towards Building Voice-based Conversational Recommender Systems: Datasets, Potential Solutions, and Prospects

## Quick Facts
- arXiv ID: 2306.08219
- Source URL: https://arxiv.org/abs/2306.08219
- Reference count: 40
- Creates first voice-based conversational recommender systems (VCRSs) datasets in e-commerce and movie domains

## Executive Summary
This paper introduces the first benchmark datasets for voice-based conversational recommender systems (VCRSs) in e-commerce and movie domains. The authors propose a framework that converts user-item interactions into voice-based conversations using ChatGPT-driven prompts and VITS text-to-speech synthesis. They demonstrate that their generated conversations achieve quality scores comparable to or better than real human dialogues. The paper also explores a preliminary solution using multi-task classification to extract age and gender features from voice data, showing 6-10% performance improvements in recommendations when these features are integrated. The work lays the foundation for future research in building end-to-end voice-based recommendation systems.

## Method Summary
The authors create VCRSs datasets by first generating text-based conversations from user-item interaction records using ChatGPT-driven prompts that simulate natural dialogues. These conversations are then synthesized into speech using VITS text-to-speech models. The framework also explores extracting age and gender features from voice data using multi-task classification models, which are then integrated into the recommendation system. The approach uses existing datasets (Coat and MovieLens-1M) as foundations, augmenting them with user and item features, and employs a two-phase fusion strategy where ASR extracts features that are then integrated into the recommendation module.

## Key Results
- Generated conversations achieve quality scores comparable to or better than real human dialogues (FED metric and user studies)
- Multi-task classification extracts age and gender features from voice data with ~90% accuracy
- Integrating voice-based features improves recommendation performance by 6-10% compared to not using these features
- Successfully creates first benchmark VCRSs datasets in both e-commerce and movie domains

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Voice-based CRS can achieve higher recommendation accuracy by extracting user age and gender from speech data
- Mechanism: Speech data contains paralinguistic features (age, gender) that are harder to fake than self-reported registration data
- Core assumption: ASR models can reliably extract age and gender features from speech with accuracy comparable to manual labels
- Evidence anchors:
  - [abstract] "voice inputs can convey more information than text inputs, such as user age, gender, and accent, which enables VCRSs to deliver more accurate and transparent recommendations"
  - [section 3.1] "we empirically verify the benefits and necessity of creating such datasets... By using SOTA classification models, these features can be extracted from voice inputs with an accuracy of around 90%"
  - [corpus] weak evidence - no corpus papers specifically validate this extraction accuracy
- Break condition: If ASR model accuracy falls below ~80%, the performance gains from voice features become marginal

### Mechanism 2
- Claim: ChatGPT-driven template generation produces more natural conversations than fixed manual templates
- Mechanism: Large language models generate diverse, context-aware conversation patterns that mimic real human dialogue
- Core assumption: ChatGPT has been trained on sufficient conversational data to produce natural dialogue templates
- Evidence anchors:
  - [section 3.2.2] "we involve ChatGPT (a more advanced large language model) to generate conversation templates and enable multiple-choice questions, so as to ensure the naturalness, multiplicity, and rationality of the simulated conversations"
  - [section 3.2.2] "our proposed ChatGPT-driven templates intuitively indicate the naturalness of our generated conversations"
  - [corpus] weak evidence - no corpus papers directly compare ChatGPT vs manual templates for CRS
- Break condition: If ChatGPT templates fail to match user expectations in pilot tests, fallback to expert-curated templates

### Mechanism 3
- Claim: End-to-end voice-to-voice pipeline outperforms two-phase fusion approaches
- Mechanism: Integrating ASR, CRS, and TTS in a single pipeline allows joint optimization and better context preservation
- Core assumption: Features extracted from ASR representations can be effectively used by CRS module
- Evidence anchors:
  - [section 4.1] "if implicit latent features represented by low-dimensional embeddings are extracted from the voice data, these embeddings can be directly integrated into the CRS module"
  - [section 4.3] "A more comprehensive solution would be both end-to-end and dynamic"
  - [corpus] weak evidence - no corpus papers validate end-to-end vs two-phase performance comparison
- Break condition: If joint training causes gradient conflicts between modules, separate training with feature-level fusion may be necessary

## Architecture Onboarding

- Component map: Voice input → ASR (Wav2Vec2) → Multi-task Classifier (age/gender) → Feature Integration → Recommendation Model → LLM (ChatGPT) → TTS (VITS) → Voice output
- Critical path: ASR → Multi-task Classifier → Feature Integration → Recommendation Model
- Design tradeoffs: Two-phase fusion (separate ASR and recommendation) vs end-to-end fusion (joint optimization); model complexity vs performance
- Failure signatures: Poor ASR transcription accuracy leading to wrong feature extraction; age/gender prediction errors degrading recommendation quality; TTS naturalness issues reducing user engagement
