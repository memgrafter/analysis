# Better speech synthesis through scaling

## Quick Facts
- arXiv ID: 2305.07243
- Source URL: https://arxiv.org/abs/2305.07243
- Reference count: 20
- One-line primary result: TorToise achieves state-of-the-art speech synthesis quality through large-scale training combining autoregressive decoding and diffusion modeling

## Executive Summary
TorToise introduces a novel text-to-speech system that combines an autoregressive decoder with a denoising diffusion probabilistic model (DDPM) to produce high-quality, expressive speech. The system leverages advances from image generation to scale up speech synthesis performance. By training on a massive dataset of 49,000 hours of speech audio and using sophisticated re-ranking techniques, TorToise demonstrates significant improvements in realism and expressiveness compared to previous TTS models.

## Method Summary
The method combines three key components: an autoregressive decoder that converts text to discrete speech tokens, a DDPM that decodes these tokens into high-quality speech spectrograms, and a contrastive model (CLVP) that re-ranks outputs to select the highest quality speech. The system is trained on 49,000 hours of speech data from audiobooks and podcasts using 8 NVIDIA RTX-3090 GPUs over one year. The autoregressive decoder uses GPT-2 style architecture with speaker conditioning, while the DDPM operates on the discrete token space. CLVP provides text-speech correlation scoring for output selection.

## Key Results
- TorToise outperforms previous TTS models in realism and expressiveness metrics
- The autoregressive-DDPM combination produces high-quality speech spectrograms that vocoders can convert to natural-sounding waveforms
- Large-scale training (49,000 hours) with substantial compute resources yields significant performance improvements
- CLVP re-ranking effectively selects the highest quality speech outputs from multiple autoregressive samples

- Core assumption: Discrete tokens from the autoregressive model provide sufficient information for the DDPM to generate high-quality speech

- Claim: Re-ranking outputs using a contrastive model (CLVP) improves the quality of generated speech

- Core assumption: CLVP can accurately distinguish between high and low-quality text-speech pairs

## Architecture Onboarding

- Component map: Text input → Autoregressive decoder → Speech tokens → CLVP → Re-ranked speech tokens → DDPM → Speech spectrograms → Vocoder → Waveform output
- Critical path: Text input → Autoregressive decoder → DDPM → Vocoder → Waveform output
- Design tradeoffs:
  - Using an autoregressive decoder + DDPM allows for high-quality speech generation but introduces additional latency compared to end-to-end TTS models
  - Re-ranking outputs using CLVP improves quality but adds computational overhead
  - Training on a large dataset improves performance but requires significant compute resources
- Failure signatures:
  - If the autoregressive decoder fails to produce meaningful speech tokens, the DDPM cannot generate coherent speech
  - If the DDPM fails to decode speech tokens accurately, the vocoder will produce low-quality waveforms
  - If CLVP is not well-trained, the re-ranking process may select suboptimal outputs
