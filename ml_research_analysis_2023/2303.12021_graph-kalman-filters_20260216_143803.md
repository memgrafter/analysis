# Graph Kalman Filters

## Executive Summary
This paper presents a novel Graph Kalman Filter (GKF) framework that extends classical Kalman filtering to handle dynamical systems where inputs, states, and outputs are attributed graphs with evolving topology. The approach linearizes nonlinear state-transition and readout functions (parameterized by graph neural networks) around current state estimates, enabling optimal state estimation in graph-based systems. The framework supports both node-level and graph-level prediction tasks and learns system dynamics end-to-end with downstream prediction tasks. While theoretical derivations are provided, experimental validation is deferred to future work.

## Method Summary
The Graph Kalman Filter operates on discrete-time graph-based dynamical systems where inputs $x_t$, states $h_t$, and outputs $y_t$ are attributed graphs with node features and adjacency matrices. The framework uses graph neural networks to parameterize the state-transition function $f_\theta$ and readout function $f_\psi$, along with an input encoder $f_\varphi$. The filter linearizes these functions around current estimates using first-order Taylor expansions to compute Jacobians, then propagates covariance matrices through the linearized system. Model parameters are trained end-to-end using gradient-based optimization to minimize the sum of squared errors between predicted and actual outputs.

- Linearization approach enables optimal state estimation in nonlinear graph-based systems

## Architecture Onboarding

- **Component map:** Input graph → Input encoder (fϑ) → State transition function (fθ) → Readout function (fψ) → Kalman gain computation → Updated state estimate → Output prediction

- **Critical path:** Input graph → Input encoder → State transition function → Readout function → Kalman gain computation → Updated state estimate → Output prediction

- **Design tradeoffs:**
  - Flexibility vs. complexity: The GKF can handle varying graph topologies but requires more complex implementations compared to traditional Kalman filters.
  - End-to-end learning vs. interpretability: While the end-to-end learning approach allows for task-specific optimization, it may make the learned system dynamics less interpretable.
  - Computational cost vs. accuracy: The linearization and Jacobian computations add computational overhead but enable optimal state estimation in nonlinear systems.

- **Failure signatures:**
  - Divergence of the filter: If the linearization is inaccurate or the system is highly nonlinear, the filter may fail to converge.
  - Overfitting: If the model is too complex or the data is insufficient, the end-to-end learning may overfit to the training data.
  - Numerical instability: Computing Jacobians and propagating covariance matrices can lead to numerical issues if not handled carefully.
