# Automatic Attention Pruning: Improving and Automating Model Pruning using Attentions

## Quick Facts
- arXiv ID: 2303.08595
- Source URL: https://arxiv.org/abs/2303.08595
- Reference count: 40
- Primary result: AAP achieves 79.11% parameters reduction and 70.13% FLOPs reduction on ResNet-56 with CIFAR-10 without accuracy drop, outperforming state-of-the-art structured pruning works.

## Executive Summary
Automatic Attention Pruning (AAP) is an adaptive, attention-based, structured pruning approach that automatically generates small, accurate, and hardware-efficient models. It improves upon Lottery Ticket Hypothesis-based iterative pruning by introducing activation-based attention pruning to identify unimportant filters and adaptive pruning policies to meet various pruning objectives. AAP uses layer-wise thresholds calculated based on each layer's contribution to model size or FLOPs, allowing differentiated aggressiveness in pruning. Comprehensive evaluation shows AAP substantially outperforms state-of-the-art structured pruning methods across multiple model architectures and datasets.

## Method Summary
AAP employs activation-based attention pruning to identify unimportant filters by computing attention values from ReLu activation feature maps. The method uses layer-wise differentiated thresholds, where each layer's threshold is calculated by multiplying a global threshold by the layer's weight based on its contribution to model size or FLOPs. An adaptive pruning policy automatically adjusts the global threshold to meet user objectives, starting conservatively and increasing aggressiveness iteratively while rolling back when accuracy drops below target. The pruned model is retrained using rewinding to a previous epoch to recover from over-pruning.

## Key Results
- On ResNet-56 with CIFAR-10, AAP achieves 79.11% parameters reduction and 70.13% FLOPs reduction without accuracy drop
- On ResNet-50 with ImageNet, AAP achieves the smallest accuracy loss (lower than related works by 0.08% to 2.61%) for the same level of parameters and FLOPs reduction
- AAP consistently outperforms state-of-the-art structured pruning methods across various model architectures including ResNet, VGG, MobileNet, ShuffleNet, and LeNet

## Why This Works (Mechanism)

### Mechanism 1
Activation-based attention pruning more precisely identifies unimportant filters than weight-magnitude-based pruning. Attention values are computed from ReLu activation feature maps and reflect the importance of filters in capturing task-relevant features. Small activations indicate filters that contribute little to the final prediction, regardless of their weight values.

### Mechanism 2
Layer-wise differentiated thresholds improve pruning efficiency by accounting for each layer's contribution to model size and FLOPs. For each layer, a weight is computed based on its proportion of remaining parameters or FLOPs, and the global threshold is multiplied by this weight to obtain a layer-specific threshold.

### Mechanism 3
Adaptive pruning thresholds enable automatic convergence to a pruned model that meets user objectives without manual tuning. The pruning process starts conservatively and increases the global threshold iteratively, rolling back when accuracy drops below target and restarting more conservatively.

## Architecture Onboarding

- **Component map**:
  - Attention mapping function -> Global threshold (T) -> Layer-specific thresholds -> Filter pruning -> Model retraining -> Objective evaluation -> Threshold adjustment

- **Critical path**:
  1. Compute attention values for each filter using the attention mapping function
  2. Calculate layer-specific thresholds based on the global threshold and each layer's contribution
  3. Prune filters below the layer-specific threshold
  4. Rewind weights and learning rate if needed
  5. Retrain the pruned model for the remaining epochs
  6. Evaluate the model against the pruning objective
  7. Adjust the global threshold based on the adaptive pruning policy
  8. Repeat until the model converges or the objective is met

- **Design tradeoffs**:
  - Attention function choice: Different attention mapping functions (Mean, Max, Sum) may lead to different pruning effectiveness. AAP uses Attention Mean with p=1 for its robustness.
  - Rewinding strategy: Rewinding to an earlier epoch helps recover from over-pruning, but the choice of epoch affects stability and accuracy.
  - Layer-wise threshold adjustment: While it improves pruning efficiency, it adds complexity to the pruning process.

- **Failure signatures**:
  - Over-pruning: If the model's accuracy drops significantly below the target, it may indicate that the pruning threshold is too aggressive.
  - Under-pruning: If the model's size or FLOPs reduction is insufficient, it may indicate that the pruning threshold is too conservative.
  - Convergence issues: If the model fails to converge after multiple pruning rounds, it may indicate that the rewinding strategy or learning rate schedule needs adjustment.

- **First 3 experiments**:
  1. Ablation study on attention functions: Compare the effectiveness of Attention Mean, Attention Max, and Attention Sum on a small model (e.g., ResNet-56 on CIFAR-10) to validate the choice of Attention Mean with p=1.
  2. Comparison with weight-magnitude-based pruning: Implement and compare AAP with Iterative L1-Norm Pruning (ILP) on the same model to demonstrate the superiority of activation-based attention pruning.
  3. Layer-wise threshold adjustment impact: Prune a model with and without layer-wise threshold adjustment to quantify the improvement in pruning efficiency and accuracy.

## Limitations
- The paper does not extensively validate whether activation-based attention values remain reliable indicators of filter importance across different network depths, architectures, and training regimes.
- The layer-wise threshold calculation assumes that layers with more parameters or FLOPs contain proportionally more redundant filters, which may not hold for all architectures.
- The exact criteria for rewinding epoch selection and its impact on final accuracy are not fully specified.

## Confidence

- **High Confidence**: The core mechanism of using activation-based attention for filter importance is well-supported by the literature on activation values as feature indicators.
- **Medium Confidence**: The adaptive pruning policy's effectiveness relies on the assumption that gradual threshold increases with rollback capabilities will converge to optimal solutions.
- **Medium Confidence**: Layer-wise differentiated thresholds improve pruning efficiency, but the optimal calculation method may vary depending on specific model architectures.

## Next Checks

1. Evaluate AAP on a diverse set of architectures (including non-convolutional models) to verify that activation-based attention remains a reliable indicator across different network types.

2. Systematically vary the threshold calculation method and measure its impact on final accuracy and pruning ratios to identify potential failure modes in the layer-wise adjustment approach.

3. Quantitatively measure the correlation between attention values and actual filter importance across different network depths and training stages to validate the core assumption of the pruning mechanism.
