# Linking data separation, visual separation, and classifier performance using pseudo-labeling by contrastive learning

## Quick Facts
- arXiv ID: 2302.02663
- Source URL: https://arxiv.org/abs/2302.02663
- Reference count: 8
- One-line primary result: Contrastive learning improves data separation in latent space, leading to better visual separation in 2D projections and higher classifier performance with limited labeled data.

## Executive Summary
This work investigates the relationship between data separation (DS), visual separation (VS), and classifier performance (CP) in semi-supervised learning using pseudo-labeling. The authors propose using contrastive learning methods (SimCLR and SupCon) to create a latent space with high data separation, then projecting this space to 2D using t-SNE to achieve visual separation. Pseudo-labels generated from well-separated visual clusters are used to train a deep neural network, achieving high classification performance even with only 1% labeled samples. Experiments on five challenging image datasets of human intestinal parasites demonstrate that SupCon outperforms SimCLR in this low-supervision regime, and that good visual separation in 2D projections correlates with high classifier performance.

## Method Summary
The method uses contrastive learning (SimCLR and SupCon) with a ResNet-18 encoder to create a latent space from image datasets. This latent space is projected to 2D using t-SNE, and pseudo-labels are propagated from the small set of labeled samples to the majority unlabeled samples using OPFSemi based on the visual separation in the 2D projection. A VGG-16 classifier is then trained on the original images using both true labels and propagated pseudo-labels. The approach is evaluated on five real-world datasets of human intestinal parasites, measuring data separation via Linear SVM/OPFSup accuracy, visual separation via pseudo-label propagation accuracy, and classifier performance via VGG-16 accuracy and Cohen's κ.

## Key Results
- SupCon achieves higher data separation than SimCLR when only 1% supervised samples are available, despite SimCLR using thousands of distinct samples
- High data separation in the latent space leads to high visual separation in 2D projections
- High visual separation enables accurate pseudo-label propagation, which in turn leads to high classifier performance
- Datasets with impurity classes show lower classification performance due to mixed pseudo-labels in projections

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Contrastive learning methods improve data separation in the latent space, enabling effective pseudo-label propagation and high classifier performance
- Core assumption: Contrastive loss functions effectively capture data structure, pulling same-class samples together and different-class samples apart
- Evidence anchors: Abstract states contrastive learning produces latent space for EPL; section describes contrastive methods pulling similar samples closer and pushing dissimilar pairs apart
- Break condition: If contrastive loss fails to distinguish classes due to high intra-class variance or low inter-class variance, DS improvement would be minimal

### Mechanism 2
- Claim: Visual separation in 2D t-SNE projection correlates with data separation in high-dimensional space, enabling effective pseudo-label propagation
- Core assumption: t-SNE preserves local structure sufficiently to reflect global class separability, and OPFSemi can effectively use this structure
- Evidence anchors: Abstract shows contrastive methods with good DS lead to good VS; section describes t-SNE aiming to mimic DS in visual structure
- Break condition: If t-SNE fails to preserve separability structure due to curse of dimensionality or inappropriate settings, VS won't reflect DS

### Mechanism 3
- Claim: Pseudo-labels from high-VS projections can train DNNs to achieve high classifier performance with only 1% supervised samples
- Core assumption: Pseudo-labels are accurate enough that training on them doesn't degrade performance, and VGG-16 can learn from augmented dataset
- Evidence anchors: Abstract states pseudo-labels via good VS projections achieve high CP; section describes training VGG-16 with pseudo-labels to test correlation with VS and DS
- Break condition: If pseudo-labels contain too much noise, training on them will lead to overfitting and poor generalization

## Foundational Learning

- Concept: Contrastive Learning (SimCLR and SupCon)
  - Why needed here: Creates latent space with high data separation, foundational for VS and CP improvements
  - Quick check question: What is the key difference between SimCLR and SupCon in how they select positive and negative samples for contrastive loss?

- Concept: Dimensionality Reduction (t-SNE)
  - Why needed here: Projects high-dimensional latent space to 2D for visual assessment of class separation
  - Quick check question: How does t-SNE's focus on preserving local structure help reveal class separability in the projection?

- Concept: Semi-supervised Learning (OPFSemi)
  - Why needed here: Propagates labels from few supervised samples to majority unsupervised samples based on visual separation
  - Quick check question: What principle underlies OPFSemi's label propagation, and how does it use 2D projection structure to assign pseudo-labels?

## Architecture Onboarding

- Component map:
  Image datasets (H.larvae, H.eggs, P.cysts) -> Contrastive Learning (SimCLR/SupCon) -> ResNet-18 encoder -> Latent space -> t-SNE -> 2D projection -> OPFSemi -> Pseudo-labels -> VGG-16 classifier -> Accuracy/Cohen's κ

- Critical path:
  1. Train contrastive model (SimCLR/SupCon) on image dataset
  2. Extract latent features from encoder
  3. Project to 2D using t-SNE
  4. Propagate labels with OPFSemi
  5. Train VGG-16 on images with true + pseudo-labels
  6. Evaluate on test set

- Design tradeoffs:
  - SimCLR vs SupCon: SimCLR uses more unsupervised samples but SupCon leverages few supervised samples for potentially better DS
  - t-SNE parameters: Perplexity, learning rate, and iterations significantly affect VS in projection
  - OPFSemi vs other methods: Chosen for performance but others might be more efficient or robust to noise

- Failure signatures:
  - Low propagation accuracy: Indicates poor VS in projection, possibly due to insufficient DS or inappropriate t-SNE settings
  - Low classifier accuracy: Could indicate noisy pseudo-labels or DNN not learning effectively from augmented dataset
  - High variance across dataset splits: Suggests method sensitivity to specific samples chosen as 1% supervised set

- First 3 experiments:
  1. Train SimCLR on H.eggs dataset and evaluate DS using Linear SVM on latent space features
  2. Project SimCLR latent space to 2D using t-SNE and visualize VS; check if clusters correspond to true classes
  3. Use OPFSemi to propagate labels in 2D projection and measure propagation accuracy; compare with true labels for unsupervised samples

## Limitations
- Results are demonstrated only on five specific datasets of human intestinal parasites, limiting generalizability to other domains
- The study uses only t-SNE for dimensionality reduction, not exploring how other techniques (e.g., UMAP) might affect the relationship between VS, DS, and CP
- The specific impact of impurity (adversarial) classes on the correlation between VS, DS, and CP is not thoroughly investigated

## Confidence
- Contrastive learning improves data separation: High
- Visual separation correlates with classifier performance: High
- Results generalize to other domains: Medium
- Pseudo-label accuracy sufficient for DNN training: Medium
- t-SNE is optimal dimensionality reduction method: Low
