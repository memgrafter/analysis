# Delivering Inflated Explanations

## Quick Facts
- arXiv ID: 2306.15272
- Source URL: https://arxiv.org/abs/2306.15272
- Authors: 
- Reference count: 15
- Key outcome: Introduces inflated explanations that generalize abductive explanations by replacing exact feature values with value sets, achieving runtime efficiency (7.11s average) and significant value set expansion (100-720 values increase) across 38 datasets.

## Executive Summary
This paper introduces "inflated explanations" as a generalization of abductive explanations in Explainable AI. While standard AXp use narrow literals (xi = vi), inflated explanations use xi ∈ Ei, where Ei is the maximally large subset of a feature's domain that preserves the prediction. The authors propose efficient algorithms for computing these explanations for both categorical and ordinal features, demonstrating practical scalability and improved informativeness. The method establishes minimal hitting set duality relationships between inflated abductive and contrastive explanations.

## Method Summary
The method computes inflated explanations by first finding an abductive explanation and then expanding each feature's value set. For categorical features, the algorithm iteratively adds domain values that maintain prediction sufficiency through exhaustive checking. For ordinal features, linear or binary search with precision δ finds the maximum range of values preserving the prediction. The approach is evaluated on 38 datasets using Random Forest classifiers, with 80% training and 20% testing split.

## Key Results
- Average runtime of 7.11 seconds across 38 datasets
- 20 out of 38 datasets showed 100-720 value increases in inflated feature subsets
- Established minimal hitting set duality between inflated abductive and contrastive explanations
- Demonstrated scalability for both categorical and ordinal feature types

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Inflated explanations generalize abductive explanations by replacing exact feature values with value sets that preserve the prediction.
- Mechanism: Starting from a minimal abductive explanation (AXp), the algorithm expands each feature's value set by including adjacent values that don't change the prediction outcome.
- Core assumption: The classifier is monotonic or exhibits predictable behavior when features are varied.
- Evidence anchors:
  - [abstract] "inflated explanations which is a set of features, and for each feature of set of values (always including the value of the instance being explained), such that the decision will remain unchanged."
  - [section] "The purpose of the paper is to propose approaches for obtaining more expressive rules using the ∈ operator."
- Break condition: If the classifier is non-monotonic or exhibits complex interactions between features that aren't captured by sequential value expansion.

### Mechanism 2
- Claim: Categorical features can be inflated by iteratively adding domain values that maintain prediction sufficiency.
- Mechanism: For each feature in the AXp, the algorithm tests all remaining domain values and adds them to the set if the prediction remains unchanged.
- Core assumption: The prediction function can be efficiently evaluated for each candidate expansion.
- Evidence anchors:
  - [section] "Given an initial Ej, we traverse all the values in the domain of the feature, with the exception of the values in Ej."
  - [section] "Clearly, by inspection of the decision list, we can conclude that, for a non-Adult, any of the colors Red, Blue, Green and Black will yield prediction 1."
- Break condition: When feature domains are extremely large, making exhaustive checking computationally prohibitive.

### Mechanism 3
- Claim: Ordinal features can be inflated using linear or binary search to find the maximum range of values that preserve the prediction.
- Mechanism: Starting from the instance value, the algorithm expands upward and downward until the prediction changes, using precision δ for control.
- Core assumption: Ordinal features have meaningful order relationships that allow systematic expansion.
- Evidence anchors:
  - [section] "By iteratively increasing the largest possible value for Q, with increments of δ (see Algorithm 4), we conclude that Q can increase up to 6.6 while ensuring that the prediction does not change to A."
  - [section] "The search for increasing values is illustrated by Algorithm 4, and the search for decreasing values is illustrated by Algorithm 5."
- Break condition: When precision δ is too large to capture meaningful value ranges, or when the search space is unbounded.

## Architecture Onboarding

- Component map: Input (model, instance, δ) -> AXp computation engine -> Inflation engine (categorical/ordinal branches) -> Duality checker -> Output (inflated explanation)
- Critical path: AXp computation → Sequential feature inflation → Duality validation
- Design tradeoffs: Linear search vs binary search for ordinal features (speed vs precision), exhaustive vs heuristic value selection for categorical features
- Failure signatures: Explanation inflation fails when feature domains are too large, when classifier evaluation is expensive, or when non-monotonic behavior prevents systematic expansion
- First 3 experiments:
  1. Test inflation on a simple monotonic classifier with small categorical and ordinal features
  2. Compare inflation performance with varying precision δ values
  3. Validate duality relationships by computing both inflated AXp and CXp for the same instance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do inflated explanations perform when applied to deep neural networks compared to random forests?
- Basis in paper: [explicit] The paper only evaluates inflated explanations on random forest classifiers
- Why unresolved: The experimental results are limited to random forests, leaving performance on other model types unexplored
- What evidence would resolve it: Experimental results showing inflated explanation quality and computation time for deep neural networks on the same benchmark datasets

### Open Question 2
- Question: Can the linear search algorithms for ordinal features be replaced with more efficient methods without sacrificing explanation quality?
- Basis in paper: [explicit] The paper uses simple linear search and mentions binary search as a potential improvement
- Why unresolved: The paper only implements linear search and briefly mentions alternatives without empirical comparison
- What evidence would resolve it: Comparative experiments showing runtime and explanation quality differences between linear, binary, and exponential search methods

### Open Question 3
- Question: What is the relationship between inflated explanation size and human understanding of model decisions?
- Basis in paper: [inferred] The paper claims inflated explanations are "more informative" but provides no human studies
- Why unresolved: No user studies are conducted to validate the practical benefits of inflated explanations
- What evidence would resolve it: User studies comparing human comprehension and trust in inflated vs standard explanations across different feature types and explanation sizes

## Limitations

- Assumes monotonic or predictable classifier behavior when features are varied, which may not hold for complex models
- Computational cost of exhaustive value checking for categorical features with large domains remains a concern
- The precision parameter δ is a critical hyperparameter whose optimal value is not thoroughly investigated

## Confidence

- Medium confidence overall due to empirical nature of runtime claims and limited characterization of edge cases
- High confidence in mathematical duality results and algorithmic correctness
- Medium confidence in practical scalability claims due to limited ablation studies on parameter sensitivity
