# FIRE: An Optimization Approach for Fast Interpretable Rule Extraction

## Quick Facts
- arXiv ID: 2306.07432
- Source URL: https://arxiv.org/abs/2306.07432
- Reference count: 33
- Key outcome: FIRE extracts sparse, interpretable decision rules from tree ensembles using MCP and fused LASSO penalties, achieving up to 24% lower test error and running 40x faster than existing solvers.

## Executive Summary
FIRE introduces a novel optimization framework for extracting interpretable decision rules from tree ensembles. The method combines a non-convex MCP penalty for aggressive rule selection with a fused LASSO penalty to encourage grouping of rules with shared antecedents, improving interpretability. A specialized block coordinate descent solver leverages problem structure for up to 40x faster computation. Experimental results demonstrate superior performance compared to state-of-the-art methods like RuleFit, GLRM, and SIRUS across multiple datasets.

## Method Summary
FIRE formulates rule extraction as an optimization problem with a non-convex MCP penalty for sparsity and a fused LASSO penalty for rule fusion. The method generates a tree ensemble, constructs a rule matrix from decision rules, and solves a regularized regression problem to select a sparse subset of rules. A specialized greedy block coordinate descent (GBCD) solver exploits the problem structure through block updates and greedy selection heuristics, dramatically reducing computation time while maintaining solution quality.

## Key Results
- Outperforms RuleFit, GLRM, and SIRUS with up to 24% lower test error
- Achieves up to 40x faster computation through specialized GBCD solver
- Improves interpretability by reducing antecedents through fused LASSO penalty
- Extracts sparse rule sets while maintaining strong predictive performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The fused LASSO penalty encourages rule fusion by penalizing the absolute differences between weights of adjacent leaf nodes within each tree, leading to grouped rule selection.
- Mechanism: The fused LASSO penalty encourages grouping of rules from the same tree, which increases the number of internal nodes removed from the decision tree and reduces the number of antecedents that practitioners must examine.
- Core assumption: Rules from the same tree that are selected together share common antecedents, making them more interpretable.
- Evidence anchors:
  - [abstract]: "FIRE encourages fusing rules during selection, so that many of the selected decision rules share common antecedents."
  - [section]: "The fused LASSO is a classical tool used in the context of approximating a signal via a piecewise constant approximation using an ℓ1-based penalty—we present a novel exploration of this tool in the context of rule ensemble extraction."
  - [corpus]: Weak. No direct mention of fused LASSO in related papers.
- Break condition: If rules from different trees share common antecedents, the fused LASSO penalty may not effectively encourage fusion.

### Mechanism 2
- Claim: The non-convex MCP penalty performs better at sparse selection in the presence of correlated rules compared to the ℓ1-penalty.
- Mechanism: The MCP penalty encourages heavy shrinkage and bias in the weights, which makes it a poor choice for sparse variable selection in the presence of correlated variables. However, it performs better at sparse selection in the presence of correlated rules.
- Core assumption: Correlated rules are common in shallow tree ensembles, and the MCP penalty is effective at selecting a sparse subset of these rules.
- Evidence anchors:
  - [abstract]: "Our regularizer comprises of a non-convex sparsity-inducing penalty to aggressively select rules."
  - [section]: "Since we intend to perform sparse selection from a collection of correlated rules, we use a non-convex penalty which incurs less bias than LASSO."
  - [corpus]: Weak. No direct mention of MCP penalty in related papers.
- Break condition: If the rules are not correlated, the MCP penalty may not provide any advantage over the ℓ1-penalty.

- Mechanism: The GBCD solver updates blocks instead of coordinates and uses greedy block selection heuristics, which drastically reduces the number of iterations compared to cyclic BCD.

## Limitations
- The MCP penalty's effectiveness relative to ℓ1 in correlated rule scenarios is theoretically justified but lacks extensive empirical comparison across diverse correlation structures
- The fused LASSO penalty's interpretability benefits depend on the assumption that rules from the same tree share common antecedents, which may not hold for all tree ensemble architectures
- The GBCD solver's computational advantages are demonstrated but the specific implementation details and scalability to very large problems remain unclear
