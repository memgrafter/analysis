# MossFormer: Pushing the Performance Limit of Monaural Speech Separation using Gated Single-Head Transformer with Convolution-Augmented Joint Self-Attentions

## Quick Facts
- arXiv ID: 2302.11824
- Source URL: https://arxiv.org/abs/2302.11824
- Reference count: 0
- Primary result: Achieves state-of-the-art SI-SDRi of 22.8 dB on WSJ0-2mix and 21.2 dB on WSJ0-3mix, reaching theoretical upper bound

## Executive Summary
This work addresses the monaural speech separation task, which involves separating individual speakers from a single overlapped speech mixture. The authors propose MossFormer, a novel Transformer architecture that employs gated single-head self-attention with convolution-augmented joint local and global attention to effectively model both long-range elemental interactions and local feature patterns. The model significantly outperforms previous state-of-the-art methods on both clean and noisy/reverberated benchmarks, achieving near-theoretical upper bounds on WSJ0-3mix.

## Method Summary
The MossFormer architecture uses a time-domain masking-net framework with a convolutional encoder-decoder structure. The masking network employs a gated single-head transformer with R=22 MossFormer blocks that incorporate convolution-augmented joint local and global self-attention mechanisms. The model is trained using SI-SDR loss with Adam optimizer, employing a learning rate of 1.5e-4 and batch size of 1. Key innovations include the use of attentive gating mechanisms, convolution modules with SiLU activation and 1D depthwise convolution, and joint attention that processes speech signals in chunks to balance global and local feature modeling.

## Key Results
- Achieves 22.8 dB SI-SDRi on WSJ0-2mix (8 kHz), surpassing previous state-of-the-art by 0.9 dB
- Reaches 21.2 dB SI-SDRi on WSJ0-3mix, achieving the theoretical upper bound for this task
- Sets new state-of-the-art results on WHAM! and WHAMR! benchmarks for noisy and reverberant conditions

## Why This Works (Mechanism)
The effectiveness of MossFormer stems from its ability to simultaneously capture both long-range dependencies through global self-attention and local patterns through convolution-augmented mechanisms. The gated single-head attention reduces computational complexity while the joint attention mechanism ensures comprehensive feature modeling across different temporal scales.

## Architecture Onboarding

**Component map**: Input -> Conv Encoder -> Masking Net (MossFormer blocks) -> Conv Decoder -> Output

**Critical path**: The masking network with convolution-augmented joint attention is the critical component determining separation quality.

**Design tradeoffs**: The architecture balances computational efficiency (gated single-head attention) with modeling capacity (joint local/global attention). Chunk-based processing enables parallelization but requires careful chunk size selection.

**Failure signatures**: Poor separation quality typically indicates issues with attention mechanism implementation, incorrect chunk sizes, or insufficient model depth.
