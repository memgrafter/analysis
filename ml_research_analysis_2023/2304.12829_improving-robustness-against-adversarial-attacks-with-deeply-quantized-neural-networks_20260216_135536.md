# Improving Robustness Against Adversarial Attacks with Deeply Quantized Neural Networks

## Quick Facts
- arXiv ID: 2304.12829
- Source URL: https://arxiv.org/abs/2304.12829
- Reference count: 40
- Key outcome: STQ model achieves 8.3% and 79.5% higher accuracy than benchmarks on average for white-box and black-box attacks respectively on CIFAR-10 and GSC datasets

## Executive Summary
This paper investigates adversarial robustness of deeply quantized neural networks for resource-constrained tiny devices. It proposes a Stochastic Ternary Quantized (STQ) DNN model using QKeras framework with Jacobian Regularization (JR) integrated for robustness. The STQ model was trained on CIFAR-10, SVHN, and GSC datasets and compared against MLCommons/Tiny benchmarks. Experimental results show that the STQ model achieved 8.3% and 79.5% higher accuracy than benchmarks on average for white-box and black-box attacks respectively on CIFAR-10 and GSC datasets, and 6.5% higher accuracy for black-box attacks on SVHN dataset.

## Method Summary
The STQ model uses QKeras for quantization-aware training with stochastic ternary quantization and Jacobian Regularization. The model was trained for 1000 epochs with batch size 64, cosine annealing learning rate scheduler, Adamax optimizer, and categorical cross-entropy loss. The architecture employs heterogeneous quantization where different layers use different bit-depths based on their importance, optimizing the trade-off between model size and accuracy.

## Key Results
- STQ model achieved 8.3% and 79.5% higher accuracy than benchmarks on average for white-box and black-box attacks respectively on CIFAR-10 and GSC datasets
- STQ model achieved 6.5% higher accuracy for black-box attacks on SVHN dataset
- Model size reduced by 86.5% compared to MLCommons/Tiny benchmarks

## Why This Works (Mechanism)

### Mechanism 1
Stochastic quantization during training improves adversarial robustness by introducing noise that forces the network to learn invariant features. Instead of quantizing all weights deterministically, a subset is quantized stochastically in each iteration, with probability inversely proportional to quantization error. This acts like data augmentation in weight space, making the model more resilient to small input perturbations.

### Mechanism 2
Jacobian Regularization integrated into QKeras training improves adversarial robustness by penalizing sensitivity to input changes. JR adds a regularization term to the loss function that minimizes the Frobenius norm of the Jacobian matrix, effectively reducing the network's sensitivity to small input perturbations. QKeras implicitly incorporates per-layer JR during backpropagation.

### Mechanism 3
Ternary quantization with heterogeneous bit-depth per layer optimizes the trade-off between model size and accuracy. Different layers use different quantization levels based on their importance, reducing memory footprint while maintaining accuracy. QKeras allows independent quantization of each layer.

- **Design tradeoffs**:
  - Model size vs. accuracy: Ternary quantization reduces model size but may affect accuracy
  - Robustness vs. clean accuracy: JR improves robustness but may slightly reduce clean accuracy
  - Training time vs. performance: STQ requires more training iterations but yields better results

- **Failure signatures**:
  - Significant accuracy drop on clean data: Indicates over-aggressive quantization
  - Poor performance against adversarial attacks: Suggests JR is not properly integrated or tuned
