# Towards Realizing the Value of Labeled Target Samples: a Two-Stage Approach for Semi-Supervised Domain Adaptation

## Quick Facts
- arXiv ID: 2304.10762
- Source URL: https://arxiv.org/abs/2304.10762
- Reference count: 0
- Best performance: 54.3% mean accuracy in 1-shot, 57.8% in 3-shot settings on DomainNet

## Executive Summary
This paper addresses the problem of Semi-Supervised Domain Adaptation (SSDA) where models must adapt from a labeled source domain to a target domain using few labeled target samples and many unlabeled target samples. The key insight is that existing SSDA methods dilute the value of precious labeled target samples by merging them with abundant source data. The authors propose a two-stage approach: first training an Unsupervised Domain Adaptation (UDA) model, then adapting it using labeled and unlabeled target samples. This decoupling protects the labeled target samples from being overwhelmed by source data. Experiments on DomainNet show significant improvements over state-of-the-art methods.

## Method Summary
The proposed method tackles SSDA through a two-stage approach. In the first stage, a UDA model is trained using labeled source samples and unlabeled target samples with RandAugment data augmentation, supervised loss on source data, and domain alignment loss. In the second stage, the pretrained UDA model is adapted using both labeled and unlabeled target samples through a Consistency Learning based Mean Teacher (CLMT) model. The CLMT gradually converts unlabeled target samples into pseudo-labeled samples by generating weak and strong augmentations, using teacher model predictions as pseudo-labels to train the student model. This approach mitigates the bias problem while protecting potentially sensitive source data.

## Key Results
- Achieves 54.3% mean accuracy in 1-shot setting on DomainNet, outperforming previous best (52.8%) by 1.5%
- Achieves 57.8% mean accuracy in 3-shot setting on DomainNet, outperforming previous best (57.6%) by 0.2%
- Demonstrates consistent improvements across all 7 domain pairs tested
- Shows the two-stage approach effectively utilizes limited labeled target samples

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Two-stage approach decouples SSDA into UDA + semi-supervised learning, mitigating bias from overwhelming source data
- Mechanism: First stage learns domain adaptation using labeled source and unlabeled target samples, creating a model already adapted to target domain. Second stage fine-tunes using only target samples, allowing labeled target samples to provide direct supervision without dilution
- Core assumption: Labeled target samples contain valuable information that gets diluted when merged with source data
- Evidence anchors: [abstract] Existing SSDA approaches simply merge the few precious labeled target samples into vast labeled source samples or further align them, which dilutes the value of labeled target samples and thus still obtains a biased model; [section] We approach SSDA in a new perspective which fundamentally resolves the imbalance problem by utilizing labeled source samples and labeled target samples in two separated stages
- Break condition: If labeled target samples are not representative of target domain or domain shift is too large

### Mechanism 2
- Claim: CLMT handles imbalance between labeled and unlabeled target samples by gradually converting unlabeled samples to labeled ones
- Mechanism: For each unlabeled sample, generate weak and strong augmentations. Teacher model produces pseudo-label for weak version, which supervises training on strong version. This gradually increases pseudo-labeled sample count
- Core assumption: Teacher-generated pseudo-labels are accurate enough to provide meaningful supervision
- Evidence anchors: [abstract] We further propose a consistency learning based mean teacher model to effectively adapt the learned UDA model using labeled and unlabeled target samples; [section] We use a teacher model to produce a pseudo label for the image and use the pseudo label to train the student model in supervised way by taking the strongly-augmented image as input
- Break condition: If pseudo-labels are too noisy or inaccurate

### Mechanism 3
- Claim: Two-stage approach protects labeled source samples by not requiring them in second stage
- Mechanism: After first stage, UDA model is adapted using only target samples, eliminating need for source data access in stage two
- Core assumption: UDA model contains sufficient information to be further adapted without original source data
- Evidence anchors: [abstract] Another imbalance problem arises immediately with the proposed two-stage solution - the imbalance between labeled target samples and unlabeled target samples; [section] After obtaining the UDA model, we start to adapt it to the target domain with proposed consistency learning based mean teacher (CLMT) model, by taking labeled and unlabeled target samples as input
- Break condition: If UDA model is not robust enough or second stage requires significant source domain information

## Architecture Onboarding

- Component map:
  - UDA Stage: Labeled source samples -> RandAugment -> Supervised loss (Ls) + Domain alignment loss (Lu) -> UDA model
  - SSL Stage: Pretrained UDA model -> Labeled target samples + Unlabeled target samples -> CLMT (Teacher + Student) -> Supervised loss (Lt) + Consistency loss (Ld) -> Adapted model

- Critical path:
  1. Train UDA model using labeled source and unlabeled target samples
  2. Initialize CLMT model with the pretrained UDA model
  3. Generate pseudo labels for unlabeled target samples using the teacher network
  4. Train the student network using the pseudo labels and the labeled target samples
  5. Update the teacher network using EMA of the student network

- Design tradeoffs:
  - Two-stage approach vs. single-stage: Better utilization of labeled target samples and source data protection, but requires more computational resources
  - CLMT vs. other semi-supervised methods: Gradually reduces imbalance between labeled/unlabeled samples, but sensitive to noisy pseudo-labels
  - RandAugment vs. other augmentations: Strong augmentation for source data, but specific augmentation strategies for target samples affect pseudo-label quality

- Failure signatures:
  - Poor UDA stage performance leads to suboptimal starting point for SSL stage
  - Noisy pseudo-labels in CLMT cause student model to learn incorrect patterns
  - Overfitting to source domain or labeled target samples despite two-stage separation

- First 3 experiments:
  1. Train UDA model using labeled source and unlabeled target samples, evaluate on target domain
  2. Initialize CLMT with pretrained UDA, evaluate using only labeled target samples
  3. Fine-tune CLMT using both labeled and unlabeled target samples, evaluate final performance

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but several remain unaddressed based on the experimental setup and methodology.

## Limitations
- Limited ablation studies on whether two-stage separation is more important than advanced pseudo-labeling techniques
- Sparse implementation details for CLMT, particularly regarding pseudo-label quality assurance and filtering mechanisms
- No empirical validation of the source data protection claim (no experiments testing source data removal in stage two)

## Confidence
- Two-stage approach effectiveness: Medium - Strong empirical results, but unclear attribution of gains specifically to decoupling mechanism versus improved semi-supervised learning
- CLMT superiority: Medium - Sound consistency learning framework, but specific implementation details that make it superior are not fully specified
- Domain protection benefit: Low-Medium - Theoretical benefit exists but wasn't empirically validated

## Next Checks
1. **Ablation on stage separation**: Implement single-stage baseline with advanced pseudo-label filtering to determine performance contribution from two-stage architecture versus better utilization of labeled target samples
2. **Pseudo-label quality analysis**: Add quantitative measurements of pseudo-label accuracy over training and correlation between pseudo-label quality and final performance
3. **Source data removal test**: Train stage-one UDA model, then deliberately remove source data and run only stage two to verify practical utility of source data protection claim
