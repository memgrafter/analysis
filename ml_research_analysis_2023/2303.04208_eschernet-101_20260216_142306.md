# EscherNet 101

## Quick Facts
- arXiv ID: 2303.04208
- Source URL: https://arxiv.org/abs/2303.04208
- Reference count: 33
- Primary result: Deep CNN achieves 98.9% accuracy classifying 2D periodic patterns into 17 wallpaper symmetry groups

## Executive Summary
EscherNet 101 is a deep convolutional neural network trained to classify images of 2D periodic patterns into their 17 wallpaper symmetry groups. The network learns hierarchical symmetry representations by combining lower-level directional filters into multi-oriented, multi-scale structures that capture wallpaper group symmetries. Using systematic augmentations including translation, rotation, and scaling on synthetic patterns, the network achieves 98.9% classification accuracy while revealing how deep learning can model texture perception and symmetry recognition.

## Method Summary
The network uses a CNN architecture with 4 convolutional layers (32 7×7 and 64 3×3 filters), 2 fully connected layers (512 and 17 neurons), and softmax output. It's trained on synthetic wallpaper patterns generated algorithmically from noise patches with systematic augmentations. Training uses 48,000 images per group (816,000 total) with SGD, batch size 250, and learning rate schedule 0.01→0.005→0.001, minimizing cross-entropy loss.

## Key Results
- Achieves 98.9% overall classification accuracy on 204,000 test images
- Most confusion occurs between symmetry groups sharing similar subgroups (e.g., P3↔P6)
- Learned filters capture second-order invariants such as symmetries, with higher layers encoding increasingly complex multi-oriented features
- CAM visualization shows discrete, uniform peaks indicating translation symmetry learning

## Why This Works (Mechanism)

### Mechanism 1
- Early convolutional layers detect oriented edge-like features; later layers combine these into rotationally symmetric structures matching wallpaper group symmetries
- Core assumption: Learned filters encode invariant spatial relationships rather than memorizing pixel patterns
- Break condition: Without augmentations, image features dominate and symmetry invariants are lost

### Mechanism 2
- Translation symmetry is learned through evenly distributed peak activations in class activation maps
- Core assumption: Translation symmetry can be captured by spatial distribution of high activations rather than explicit geometric modeling
- Break condition: When scale range expands beyond training, network loses accuracy

### Mechanism 3
- Hierarchical subgroup relationships are learned through asymmetric confusion patterns
- Core assumption: Network's internal representations preserve the mathematical lattice of symmetry groups
- Break condition: Training data lacks sufficient examples of rarer subgroups

## Architecture Onboarding

- Component map: Input (128×128 grayscale) → Conv(7×7,32) → ReLU → Conv(7×7,32) → ReLU → MaxPool(2×2) → Conv(3×3,64) → ReLU → Conv(3×3,64) → ReLU → MaxPool(2×2) → FC(512) → ReLU → FC(17) → Softmax
- Critical path: Feature extraction (conv layers) → symmetry combination (pooling) → group classification (fully connected)
- Design tradeoffs: Small network for interpretability vs. larger networks for raw accuracy; fixed image size limits scale robustness
- Failure signatures: High confusion between groups with shared symmetries; drop in accuracy with expanded scale range

## Open Questions the Paper Calls Out

### Open Question 1
- How does EscherNet's performance change when trained on affine-deformed wallpaper patterns rather than purely Euclidean ones?
- Basis: Paper mentions extending work to affine deformation where EscherNet could learn provable rules
- Why unresolved: Current network only handles Euclidean symmetries without testing affine transformations
- Evidence needed: Training on affine-deformed synthetic patterns and comparing classification accuracy and confusion matrices

### Open Question 2
- What is the minimum resolution and unit lattice size required for EscherNet to maintain high classification accuracy?
- Basis: Current study uses 256×256 pixels with 8×8 unit lattices without exploring parameter sensitivity
- Why unresolved: Fixed resolution and lattice size untested across different scales
- Evidence needed: Systematic testing with varying image resolutions and unit lattice sizes measuring classification accuracy

### Open Question 3
- Do learned filters in higher layers capture complete wallpaper group structures or just local symmetry components?
- Basis: Paper observes filter evolution but doesn't determine if network learns complete structures
- Why unresolved: Evolution noted but causal relationship between filters and complete group structures unproven
- Evidence needed: Detailed analysis of activation patterns across all layers when processing different wallpaper groups

## Limitations
- Performance entirely dependent on quality of synthetic wallpaper pattern generation
- Robustness to real-world patterns and expanded scale ranges remains untested
- Claims about invariant spatial relationships inferred from augmentation success but not directly validated

## Confidence

- **High Confidence**: Overall classification accuracy (98.9%) and confusion patterns between mathematically related subgroups
- **Medium Confidence**: Claims about hierarchical symmetry learning through filter progression
- **Low Confidence**: Assertion that network learns invariant spatial relationships rather than memorizing pixel patterns

## Next Checks

1. **Ablation Study on Augmentations**: Train identical networks with systematic removal of each augmentation type to quantify individual contributions to symmetry learning

2. **Cross-Scale Robustness Test**: Evaluate trained network on patterns with scale ranges beyond training distribution (e.g., 50-300% instead of 100-200%)

3. **Real-World Transfer Test**: Test network on small dataset of real wallpaper patterns or architectural photographs to assess practical applicability
