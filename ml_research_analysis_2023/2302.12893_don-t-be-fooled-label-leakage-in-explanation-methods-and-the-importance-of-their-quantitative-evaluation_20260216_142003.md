# Don't be fooled: label leakage in explanation methods and the importance of their quantitative evaluation

## Quick Facts
- arXiv ID: 2302.12893
- Source URL: https://arxiv.org/abs/2302.12893
- Authors: 
- Reference count: 29
- Primary result: Class-dependent feature attribution methods can leak label information, making selected classes appear more likely than they actually are; distribution-aware methods avoid this issue and are theoretically optimal for certain evaluation metrics

## Executive Summary
This paper addresses a critical problem in explainable AI: label leakage in feature attribution methods. The authors demonstrate that class-dependent methods (which generate explanations for individual classes) can inadvertently leak information about the true or predicted class, leading to over-confident and potentially misleading explanations. They introduce distribution-aware methods that generate explanations based on how feature perturbations affect the entire label distribution, showing these methods avoid label leakage and are theoretically optimal for preserving distributional information. Through comprehensive experiments on three clinical datasets, they validate that distribution-aware methods produce more reliable explanations than class-dependent alternatives.

## Method Summary
The authors introduce distribution-aware feature attribution methods that generate explanations by measuring how feature perturbations affect the label's probability distribution. They prove that the optimal feature attribution method for their proposed iAUC evaluation metric is distribution-aware. To implement this, they propose two baseline methods: SHAP-KL and FastSHAP-KL, which estimate Shapley values using KL divergence as the value function. The evaluation framework uses a surrogate model trained with randomly masked inputs to avoid label leakage during assessment. They compare seven class-dependent and three distribution-aware methods across biosignals, retinal images, and clinical notes, measuring performance using area under the inclusion curve (iAUC).

## Key Results
- Class-dependent methods leak information about the selected class, making that class appear more likely than it actually is
- Distribution-aware methods (SHAP-KL and FastSHAP-KL) do not exhibit label leakage and maintain better calibrated explanations
- SHAP-KL and FastSHAP-KL achieve higher iAUC scores than class-dependent methods when using the predicted class
- The optimal feature attribution method for iAUC evaluation is theoretically distribution-aware

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Class-dependent methods can leak information about the selected class, making that class appear more likely than it actually is.
- Mechanism: Class-dependent methods generate feature attribution vectors as a function of class, which means the explanation itself contains information about the class being explained. When evaluating these methods by progressively including top features, this leaked class information can inflate performance metrics because the surrogate model can predict the class better using fewer features than with all features available.
- Core assumption: The evaluation framework uses true labels or predicted classes to select which class to explain, creating a dependency between the explanation and the class label.
- Evidence anchors:
  - [abstract] "we demonstrate that class-dependent methods can 'leak' information about the selected class, making that class appear more likely than it is"
  - [section] "we theoretically and empirically show that class-dependent methods can 'leak' information about the selected class, making that class appear more likely than it is"
  - [corpus] Weak evidence - no direct mention of label leakage in related papers

### Mechanism 2
- Claim: Distribution-aware methods avoid label leakage by focusing on the change in label distribution when features are perturbed.
- Mechanism: Distribution-aware methods generate explanations based on how feature perturbations affect the entire distribution of the label, not just a single class. This creates explanations that are calibrated according to the predicted probability distribution across all classes, preventing over-confidence in any single class prediction.
- Core assumption: The data distribution F(y|x) represents the true relationship between features and labels, and this distribution should be preserved even when features are removed or perturbed.
- Evidence anchors:
  - [abstract] "we introduce 'distribution-aware' methods, which favor explanations that keep the label's distribution close to its distribution given all features of the input"
  - [section] "a distribution-aware method generates feature attributions by measuring the effect of feature perturbation on the distribution of the label"
  - [corpus] No direct evidence in related papers about distribution-aware methods specifically

### Mechanism 3
- Claim: The optimal feature attribution method for the iAUC evaluation metric is distribution-aware.
- Mechanism: The iAUC metric measures how well a feature attribution method preserves the label distribution when progressively including features. Since this metric is fundamentally about preserving distributional information, methods that optimize this metric must be distribution-aware rather than class-dependent.
- Core assumption: The iAUC evaluation metric accurately captures the utility of feature attribution methods for preserving distributional information about the label.
- Evidence anchors:
  - [section] "we demonstrate that the optimal feature attribution method is distribution-aware"
  - [section] "we see that the optimal feature attribution vector e*(x) for an instance x is distribution-aware in that it minimizes the KL divergence between the likelihood of the label given all of the features and the likelihood of the target variable given the top n% of the features"
  - [corpus] No direct evidence in related papers about iAUC optimization

## Architecture Onboarding

- Component map: Data preprocessing -> Prediction model training -> Feature attribution method implementation -> Surrogate evaluation model training -> Inclusion curve construction -> iAUC calculation -> Method comparison

- Critical path:
  1. Train prediction model on training data
  2. Generate explanations for test data using various attribution methods
  3. Train surrogate evaluation model with random feature masking
  4. Construct inclusion curves by progressively including top features
  5. Calculate iAUC for each method
  6. Compare class-dependent vs distribution-aware methods

- Design tradeoffs:
  - Class-dependent methods: More interpretable for single-class analysis but risk label leakage and miscalibration
  - Distribution-aware methods: Better calibrated but potentially less intuitive for class-specific insights
  - Surrogate model approach: Computationally efficient but requires careful hyperparameter tuning
  - Random feature masking: Prevents co-adaptation but may introduce noise in evaluation

- Failure signatures:
  - If inclusion curves show performance exceeding full-feature performance, indicates label leakage in class-dependent methods
  - If distribution-aware methods show similar leakage patterns, suggests issues with surrogate model approximation
  - If iAUC differences are negligible across methods, suggests evaluation metric may not be sensitive enough
  - If training fails for specific methods, check hyperparameter settings and data preprocessing

- First 3 experiments:
  1. Reproduce the label leakage demonstration on a simple synthetic dataset with known ground truth
  2. Compare SHAP-KL vs SHAP-S on CIFAR-10 to validate findings from clinical datasets
  3. Test different surrogate model architectures to see if evaluation results are robust to model choice

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of distribution-aware methods compare to class-dependent methods when evaluated on tasks where the goal is to understand which features increase or decrease the probability of a specific class for all data points?
- Basis in paper: [explicit] The paper mentions in Section 7.2 that class-dependent methods are useful when trying to understand which features increase or decrease the probability of a specific class, in which case explanations are generated using a fixed class for all data points. However, it remains open what is the best evaluation for a class-specific explanation.
- Why unresolved: The paper focuses on evaluating methods based on iAUC, which measures how well the target distribution can be approximated using a subset of features. This evaluation metric may not be suitable for tasks where the goal is to understand the impact of features on a specific class for all data points.
- What evidence would resolve it: Conducting experiments to compare the performance of distribution-aware and class-dependent methods on tasks where the goal is to understand the impact of features on a specific class for all data points, using an appropriate evaluation metric for class-specific explanations.

### Open Question 2
- Question: Can the development of additional distribution-aware methods that make use of advances in discrete optimization lead to better performance in optimizing evaluation metrics such as Equation (4)?
- Basis in paper: [explicit] The paper mentions in Section 7.3 that directly maximizing evaluation metrics for feature attribution methods can be infeasible since they often involve discrete functions that are not differentiable, such as topn in Equation (4). The paper introduces two baseline distribution-aware methods, SHAP-KL and FastSHAP-KL, that yield real-valued optimization problems with a squared loss, but neither optimizes iAUC directly.
- Why unresolved: The paper does not explore the development of additional distribution-aware methods that make use of advances in discrete optimization to more directly optimize evaluation metrics such as Equation (4).
- What evidence would resolve it: Developing and evaluating new distribution-aware methods that leverage advances in discrete optimization to directly optimize evaluation metrics such as Equation (4), and comparing their performance to existing methods.

### Open Question 3
- Question: How does the cognitive burden of considering explanations generated for all classes impact the accuracy of human decision-making when using class-dependent methods?
- Basis in paper: [explicit] The paper discusses in Section 7.5 that class-dependent methods can surface features that make the selected class appear more reasonable and obfuscate features that support other classes. The paper suggests that end users should consider the feature attributions generated for every class to avoid drawing inaccurate conclusions, but this constitutes a significant cognitive burden.
- Why unresolved: The paper does not explore the effect of miscalibrated explanations on human decision-making or the impact of the cognitive burden of considering explanations for all classes.
- What evidence would resolve it: Conducting user studies to investigate the impact of the cognitive burden of considering explanations for all classes on the accuracy of human decision-making when using class-dependent methods, and exploring ways to mitigate this burden.

## Limitations

- The analysis is limited to three clinical datasets and may not generalize to all domains or data types
- The theoretical optimality results depend on specific assumptions about the surrogate model and evaluation metric
- The comparison focuses on specific class-dependent and distribution-aware methods, potentially missing other important approaches

## Confidence

- High confidence: The existence of label leakage in class-dependent methods and the basic mechanism by which it occurs
- Medium confidence: The theoretical optimality of distribution-aware methods for iAUC and the proposed SHAP-KL and FastSHAP-KL baselines
- Low confidence: The generalizability of results to non-clinical domains and alternative evaluation metrics
