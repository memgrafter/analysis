# Extending Context Window of Large Language Models via Positional Interpolation

## Executive Summary
This paper introduces Position Interpolation (PI), a method to extend the context window of pre-trained large language models by linearly downscaling position indices. The approach allows models like LLaMA to handle longer contexts (up to 32K tokens) with minimal fine-tuning (1000 steps). PI achieves better perplexity on long text tasks compared to direct fine-tuning while preserving model quality on original tasks, with only minor degradation (up to 2%). The method is theoretically stable due to a much smaller interpolation bound compared to extrapolation.

## Method Summary
Position Interpolation (PI) extends the context window of pre-trained LLMs by linearly downscaling position indices. During training, position indices are interpolated to a smaller range, allowing the model to learn representations for longer sequences. After training, the model can handle extended contexts without significant degradation in performance. The method requires minimal fine-tuning (1000 steps) and is theoretically stable due to a smaller interpolation bound compared to extrapolation.

## Key Results
- PI extends context windows to 32K tokens with minimal fine-tuning (1000 steps).
- Achieves better perplexity on long text tasks compared to direct fine-tuning.
- Preserves model quality on original tasks with only minor degradation (up to 2%).

## Why This Works (Mechanism)
Position Interpolation works by linearly downscaling position indices during training, which allows the model to learn representations for longer sequences. The theoretical stability of PI is ensured by a much smaller interpolation bound compared to extrapolation, as shown by the analysis in Theorem 1. This stability translates to better performance on long text tasks while preserving quality on original tasks.
