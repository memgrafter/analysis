# Towards a Unified Model for Generating Answers and Explanations in Visual Question Answering

## Quick Facts
- arXiv ID: 2301.10799
- Source URL: https://arxiv.org/abs/2301.10799
- Reference count: 40
- UMAE achieves new state-of-the-art explanation scores on A-OKVQA and VCR, and competitive out-of-domain performance on VQA-X.

## Executive Summary
This paper introduces UMAE, a unified model for generating both answers and explanations in visual question answering. The approach uses artificial prompt tokens to condition a multimodal encoder-decoder model on different tasks while learning shared semantic features. By fine-tuning on various VQA tasks simultaneously, UMAE achieves state-of-the-art performance on knowledge-intensive VQA datasets and demonstrates the ability to generate answers and explanations jointly, improving efficiency and flexibility compared to separate models.

## Method Summary
UMAE is a unified model for generating answers and explanations in visual question answering. The approach involves adding artificial prompt tokens to training instances to distinguish different tasks while learning shared semantic features. A multimodal encoder-decoder model (OFA-large) is fine-tuned on various VQA tasks, including answer generation, explanation generation, and joint answer-explanation generation. The model uses perplexity as a metric to map generated answers to multiple-choice options. Experiments are conducted on three knowledge-intensive VQA datasets (OK-VQA, A-OKVQA, and VCR) with a focus on achieving state-of-the-art performance in both answer accuracy and explanation quality.

## Key Results
- UMAE achieves new state-of-the-art answer accuracy on A-OKVQA
- UMAE achieves new state-of-the-art explanation scores on A-OKVQA and VCR
- UMAE demonstrates competitive out-of-domain performance on VQA-X
- UMAE can jointly generate answers and explanations together, improving efficiency

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Adding artificial prompt tokens to training data enables the model to distinguish tasks while learning shared semantic features.
- Mechanism: Artificial prompt tokens act as task-specific signals, conditioning the encoder-decoder model on the desired output type (answer, explanation, or both) without requiring separate models.
- Core assumption: The pretrained model has learned representations that can be flexibly conditioned on discrete prompts.
- Evidence anchors:
  - [abstract] "We add artificial prompt tokens to training instances and fine-tune a multimodal encoder-decoder model on various VQA tasks."
  - [section 3.1] "We augment training instances with artificial prompt tokens, enabling the model to distinguish different tasks while learning shared semantic features."
  - [corpus] Weak - No direct citations on prompt token effectiveness in multimodal VQA found.
- Break condition: If the model fails to generalize to unseen tasks or the prompts introduce significant bias in the embeddings.

### Mechanism 2
- Claim: Multitask learning with mixed datasets improves both answer and explanation quality by enforcing consistency between predictions.
- Mechanism: By training on both answer and explanation tasks simultaneously, the model learns to generate explanations that are more grounded in the predicted answer, reducing inconsistencies seen in separate models.
- Core assumption: Shared representations across tasks lead to better alignment between answers and explanations.
- Evidence anchors:
  - [abstract] "Our approach is also capable of jointly generating answers and explanations together... training explanation models independently of the QA model makes the explanations less grounded."
  - [section 5.2] "UMAE ALL achieves better results across all datasets, showing the advantage of mixing tasks and datasets in different domains."
  - [corpus] Weak - No direct citations on multitask learning improving explanation-grounding in VQA found.
- Break condition: If the multitask training causes catastrophic forgetting of task-specific skills or the model struggles to balance the different objectives.

### Mechanism 3
- Claim: Using perplexity as a metric to map generated answers to multiple-choice options improves accuracy over traditional embedding similarity methods.
- Mechanism: Perplexity measures the likelihood of each option being generated by the model given the image, objects, and question, selecting the option with the lowest perplexity as the answer.
- Core assumption: The generative model's likelihood scores correlate with answer correctness for multiple-choice questions.
- Evidence anchors:
  - [section 3.2] "To map the generated output to Multiple-Choice options, we propose to evaluate each option as a text generation task... The perplexity is then calculated with: PPL(Y) = exp{−1/t ∑i log pθ(yi|y<i)}, which reflects the probability of each option being generated by the model."
  - [section 5.1] "For models that are fine-tuned on A-OKVQA, we also see salient improvement (+9%) with the proposed perplexity as a metric to map options in Multiple-Choice instead of GloVe embeddings similarity."
  - [corpus] Weak - No direct citations on perplexity-based multiple-choice evaluation in VQA found.
- Break condition: If the model's perplexity scores do not correlate with answer correctness or if the metric is sensitive to generation noise.

## Architecture Onboarding

- Component map: Multimodal encoder-decoder transformer (e.g., OFA-large) with artificial prompt tokens added to the tokenizer. Visual encoder processes image patches and object features, text encoder processes prompt tokens and question text, decoder generates answers and explanations.
- Critical path: Image → Object detection → Visual encoder → Cross-modal attention → Text encoder → Decoder → Answer/Explanation generation
- Design tradeoffs: Using a single unified model vs. separate models for answers and explanations; multitask learning vs. single-task learning; perplexity-based evaluation vs. embedding similarity for multiple-choice questions.
- Failure signatures: Low answer accuracy due to visual encoder failure or object detection errors; poor explanation quality due to lack of grounding in the answer; inconsistent performance across different datasets or tasks.
- First 3 experiments:
  1. Fine-tune the pretrained multimodal encoder-decoder model on a single VQA dataset with artificial prompt tokens for answer generation only. Evaluate answer accuracy and compare to baseline.
  2. Add explanation generation to the fine-tuning process, using the same dataset and prompt tokens. Evaluate both answer accuracy and explanation quality, comparing to separate models for each task.
  3. Mix multiple VQA datasets with different domains during fine-tuning, using the same prompt token approach. Evaluate performance on each dataset individually and compare to single-dataset training.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How effective is the proposed perplexity-based metric for mapping generated answers to multiple-choice options compared to other metrics like GloVe embedding similarity?
- Basis in paper: [explicit] The paper proposes using perplexity as a metric for mapping generated answers to multiple-choice options and compares its performance to GloVe embedding similarity on A-OKVQA.
- Why unresolved: The comparison is limited to a single dataset and metric, and further evaluation on other datasets and metrics is needed to establish the generalizability of the proposed approach.
- What evidence would resolve it: Conducting experiments on additional VQA datasets with different answer formats and comparing the performance of perplexity-based metric with other metrics like BERTScore or human evaluation would provide more insights into the effectiveness of the proposed approach.

### Open Question 2
- Question: How does the performance of UMAE vary with different decoding strategies for generating explanations?
- Basis in paper: [explicit] The paper experiments with different decoding strategies like beam search, top-k sampling, nucleus sampling, and typical sampling for generating explanations and reports the explanation scores for each strategy.
- Why unresolved: The paper only reports the scores for a single decoding strategy (nucleus sampling) and does not provide a detailed analysis of how the choice of decoding strategy affects the quality of explanations.
- What evidence would resolve it: Conducting a comprehensive evaluation of UMAE with different decoding strategies and analyzing the trade-offs between explanation quality and diversity would provide a better understanding of the impact of decoding strategies on the model's performance.

### Open Question 3
- Question: How can the quality of explanations generated by UMAE be further improved?
- Basis in paper: [inferred] The paper reports the explanation scores achieved by UMAE and identifies potential areas for improvement through error analysis.
- Why unresolved: The paper does not propose specific methods for improving the quality of explanations, and further research is needed to address the identified issues like knowledge gaps, visual understanding, and semantic misassociation.
- What evidence would resolve it: Proposing and evaluating techniques like knowledge augmentation, improved visual grounding, and semantic alignment would provide insights into how to enhance the quality of explanations generated by UMAE.

## Limitations

- The core innovation of using artificial prompt tokens lacks strong empirical validation, as the results section focuses on overall performance rather than isolating the impact of the prompt token mechanism.
- The perplexity-based evaluation method for multiple-choice questions is introduced without thorough ablation studies to demonstrate its superiority over traditional embedding similarity approaches.
- The paper does not address potential bias introduced by the prompt tokens or investigate whether the model might be overfitting to the specific prompt patterns used during training.

## Confidence

- **High confidence**: The overall claim that UMAE achieves state-of-the-art results on A-OKVQA and VCR explanation tasks, and competitive performance on VQA-X. This is directly supported by the experimental results presented in Table 1.
- **Medium confidence**: The claim that UMAE can jointly generate answers and explanations together, making it more efficient than separate models. While the paper demonstrates this capability, the explanation quality when jointly generating is not directly compared to separate models trained specifically for explanations.
- **Low confidence**: The claim that adding artificial prompt tokens enables the model to distinguish tasks while learning shared semantic features. The paper provides minimal evidence for the specific mechanism by which prompt tokens improve multitask learning, and no ablation studies isolate their contribution.

## Next Checks

1. **Ablation study on prompt tokens**: Remove the artificial prompt tokens from the model and retrain on the same datasets to quantify their contribution to the overall performance improvements. Compare answer accuracy and explanation quality with and without prompt tokens while keeping all other factors constant.

2. **Perplexity vs embedding similarity comparison**: For the multiple-choice question answering task, conduct a direct comparison between perplexity-based evaluation and traditional embedding similarity methods (e.g., GloVe similarity) across different models and datasets. Include statistical significance testing to determine if the improvement is robust.

3. **Generalization test on unseen tasks**: Evaluate UMAE's performance on a new VQA task or dataset that was not seen during training, using the same prompt token mechanism. This would test whether the model can truly generalize its learned task-switching ability to novel question-answering scenarios without requiring additional fine-tuning.
