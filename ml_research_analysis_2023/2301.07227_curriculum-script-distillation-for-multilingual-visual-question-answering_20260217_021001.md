# Curriculum Script Distillation for Multilingual Visual Question Answering

## Quick Facts
- arXiv ID: 2301.07227
- Source URL: https://arxiv.org/abs/2301.07227
- Reference count: 20
- Key outcome: Curriculum-based script mixing improves multilingual VQA, with Roman-script languages performing ~6% better than non-Roman scripts, and code-switched languages outperforming monolingual by ~5-12%.

## Executive Summary
This paper addresses the challenge of extending Visual Question Answering (VQA) models to languages beyond English by introducing a curriculum learning strategy based on script knowledge distillation. The approach uses a three-stage fine-tuning process that leverages English-annotated data to bootstrap performance on target languages through machine-translated questions and self-training with high-confidence predictions. The experiments demonstrate significant performance differences based on script compatibility, with Roman-script languages benefiting substantially from English knowledge transfer. The method achieves strong results across multiple multilingual VQA datasets while highlighting the importance of script compatibility in cross-lingual transfer learning.

## Method Summary
The curriculum learning approach consists of three stages: (1) task-specific fine-tuning on English VQA data, (2) weak annotation of target language questions using concatenated source-target language inputs via machine translation, and (3) final fine-tuning using high-confidence predictions from stage 2. The method employs pre-trained multimodal models (cross-encoders and dual-encoders) and generates pseudo-labels for target languages through self-training. The approach is evaluated on the MuCO VQA dataset covering English, German, Spanish, French, Hindi, and Bengali, demonstrating that script compatibility significantly impacts transfer performance.

## Key Results
- Target languages sharing Roman script with English outperform non-Roman script languages by approximately 6% in VQA accuracy
- Code-switched languages with mixed Romanized scripts perform 5-12% better than their monolingual counterparts
- The three-stage curriculum effectively transfers knowledge from English to target languages through scripted translation and self-training
- Script compatibility plays a vital role in multilingual VQA performance, suggesting orthographic features influence cross-lingual transfer

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Curriculum-based script mixing improves multilingual VQA by incrementally exposing the model to target language patterns while maintaining English supervision.
- Mechanism: The model undergoes three-stage fine-tuning: (1) task-specific fine-tuning on English data, (2) weak annotation using concatenated source-target language inputs, and (3) final fine-tuning with high-confidence predictions. This staged exposure helps the model gradually adapt to target language structures while retaining strong English grounding.
- Core assumption: The model can leverage English-annotated knowledge to bootstrap target language performance through scripted translation and self-training.
- Evidence anchors:
  - [abstract] "We aim to address this problem by introducing a curriculum based on the source and target language translations to finetune the pre-trained models for the downstream task."
  - [section] "The first step is to finetune a selected pre-trained model with annotated data in one language where the task-specific annotations are available... The next step is to adapt the model to the target language, which requires annotations from the target language."
- Break condition: If the translation quality between source and target languages is too poor, the weak annotations in stage 2 may mislead the model, causing performance degradation rather than improvement.

### Mechanism 2
- Claim: Script compatibility between source and target languages significantly impacts VQA performance.
- Mechanism: Languages sharing the same script (e.g., Roman script) benefit from pre-training language model biases toward that script, leading to better performance compared to languages with different scripts.
- Core assumption: The pre-trained model's representation space is more aligned for languages using the same script, making transfer more effective.
- Evidence anchors:
  - [abstract] "Experimental results demonstrate that script plays a vital role in the performance of these models. Specifically, we show that target languages that share the same script perform better (~6%) than other languages"
  - [section] "the performance of the target languages that share the same script as that of the pre-training languages is higher compared to the languages with different scripts"
- Break condition: If the model is pre-trained on multilingual data with diverse scripts, the script compatibility advantage may diminish or disappear.

### Mechanism 3
- Claim: Code-switched languages with mixed Romanized scripts outperform their monolingual counterparts due to beneficial cross-linguistic knowledge transfer.
- Mechanism: The Romanized script in code-switched languages provides a bridge between English and the target language, allowing the model to leverage its English knowledge more effectively than in purely monolingual target languages.
- Core assumption: The partial Romanization in code-switched data reduces the script gap between English and the target language, facilitating better knowledge transfer.
- Evidence anchors:
  - [abstract] "code-switched languages with mixed Romanized scripts perform better than their monolingual counterparts (~5-12%)"
  - [section] "the performance on switched concepts in English with code-switching is better than their counterparts, (by about ~5-12%)"
- Break condition: If the code-switching patterns are too complex or the Romanization is inconsistent, the benefits may be outweighed by increased confusion in the model.

## Foundational Learning

- Concept: Self-training with weak supervision
  - Why needed here: The approach relies on generating pseudo-labels for target language data by using the English-trained model on translated questions, which requires understanding how to leverage weak annotations effectively.
  - Quick check question: How does the selection of high-confidence predictions from the weakly annotated data affect the quality of the final fine-tuned model?

- Concept: Curriculum learning in multilingual contexts
  - Why needed here: The staged fine-tuning approach is a form of curriculum learning that gradually increases task complexity by moving from source language only to mixed source-target inputs.
  - Quick check question: What is the rationale behind using concatenated source and target language questions in the intermediate stage rather than just target language questions?

- Concept: Script-based language modeling
  - Why needed here: The paper demonstrates that script compatibility affects model performance, which requires understanding how orthographic features influence language model representations.
  - Quick check question: How might pre-training a model on multilingual data with diverse scripts change the observed script compatibility effects?

## Architecture Onboarding

- Component map:
  Pre-trained multimodal model (cross-encoder or dual-encoder) -> Machine translation model -> VQA dataset with English annotations -> Target language VQA dataset -> Selection mechanism for high-confidence pseudo-labels -> Fine-tuning pipeline with staged curriculum

- Critical path:
  1. Task-specific fine-tuning on English data
  2. Translation of English questions to target language
  3. Weak annotation using concatenated source-target inputs
  4. Selection of high-confidence predictions
  5. Final fine-tuning on selected pseudo-labeled data

- Design tradeoffs:
  - Translation quality vs. computational cost: Using machine translation introduces noise but avoids expensive human annotation
  - Script compatibility vs. model generalization: Focusing on Roman-script languages may limit applicability to non-Roman scripts
  - Stage complexity vs. performance: More stages in the curriculum might improve performance but increase training time and complexity

- Failure signatures:
  - Performance plateau or degradation after stage 2 indicates issues with weak annotation quality or selection mechanism
  - Minimal difference between monolingual and code-switched performance suggests the curriculum isn't effectively leveraging script mixing
  - Poor performance on non-Roman script languages indicates strong dependency on script compatibility

- First 3 experiments:
  1. Implement and evaluate the three-stage curriculum on a single language pair (e.g., English to Spanish) using a cross-encoder model
  2. Compare performance of the curriculum approach against zero-shot transfer and direct fine-tuning baselines
  3. Test the impact of varying the number of high-confidence samples selected in stage 3 (e.g., 1k, 5k, 10k) on final performance

## Open Questions the Paper Calls Out

- How does the performance gap between Roman-script and non-Roman-script languages change with different multilingual pre-training strategies?
- What is the optimal selection strategy for high-confidence predictions in the self-training curriculum?
- How does the performance of code-switched languages vary with different degrees of script mixing?
- What is the impact of using multimodal translation (rather than unimodal translation) for generating target language questions?

## Limitations

- The observed script compatibility advantages may be influenced by translation quality and dataset characteristics rather than purely orthographic features
- The method relies on machine translation quality, which could introduce noise that propagates through the curriculum stages
- The selection of 5k high-confidence examples appears arbitrary without systematic exploration of optimal thresholds
- The approach may not generalize well to non-Roman script languages without additional architectural modifications

## Confidence

- High confidence: The general framework of curriculum-based fine-tuning for multilingual VQA is well-supported by experimental results
- Medium confidence: Specific claims about script compatibility advantages (~6% improvement) are supported but may be influenced by confounding factors
- Medium confidence: Code-switching performance gains (~5-12%) are demonstrated but the mechanism requires more detailed analysis

## Next Checks

1. Systematically evaluate how varying machine translation quality affects the weak annotation stage and subsequent curriculum performance across different language pairs
2. Design controlled experiments that isolate script effects from other factors by testing languages with identical scripts but different linguistic families
3. Perform ablation studies on the three-stage curriculum by testing intermediate configurations to quantify the contribution of each stage
