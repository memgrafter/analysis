# Less Can Be More: Unsupervised Graph Pruning for Large-scale Dynamic Graphs

## Quick Facts
- arXiv ID: 2305.10673
- Source URL: https://arxiv.org/abs/2305.10673
- Reference count: 40
- This paper tackles the problem of unsupervised graph pruning on dynamic graphs, aiming to remove redundant or noisy edges without relying on labels.

## Executive Summary
This paper introduces STEP, a self-supervised temporal pruning framework for large-scale dynamic graphs. The method addresses the challenge of removing redundant or noisy edges without labeled data by learning edge importance through temporal and structural information. STEP achieves this through a three-component architecture that learns to prune edges while maintaining downstream task performance, demonstrating significant efficiency gains on real-world datasets.

## Method Summary
STEP is a self-supervised temporal pruning framework that learns to remove potentially redundant edges from dynamic graphs without requiring labels. The framework consists of three main components: a graph embedding network that learns node and edge representations with temporal information, a graph sampling network that computes edge importance scores and samples the underlying graph structure, and a graph-less pruning network that enables efficient online pruning by processing individual edges without explicit message passing. The model is trained using a contrastive loss that maximizes mutual information between the original graph and pruned graph, combined with self-distillation and Bernoulli Moment Matching regularization.

## Key Results
- STEP can prune over 50% of edges on a million-scale industrial graph while maintaining up to 98% of the original performance
- Outperforms baselines in terms of classification accuracy and robustness on three real-world datasets
- Reduces storage and inference time while preserving essential graph structure

- Mechanism: The framework learns edge representations through a graph embedding network, then uses these to compute edge importance scores. - Core assumption: The underlying graph structure can be discovered through self-supervision by comparing representations of the full graph versus the pruned graph

- Claim: The graph-less pruning network enables efficient online pruning by processing individual edges without explicit message passing
- Mechanism: After training, the compact pruning network takes edge features and time information as input to determine whether to preserve each edge. This avoids the computational overhead of full graph message passing at inference time
- Core assumption: Edge importance can be accurately determined from local edge features and temporal information without requiring global graph structure

## Architecture Onboarding

- Component map: Graph Embedding Network -> Graph Sampling Network -> Graph-less Pruning Network
- Critical path: Graph embedding → edge importance scoring → differentiable sampling → contrastive learning → knowledge distillation to pruning network
- Design tradeoffs:
  - Complexity vs. performance: More complex embedding networks may improve pruning quality but increase training time
  - Sparsity vs. accuracy: Higher pruning ratios reduce storage/computation but may hurt downstream performance
  - Self-supervision quality: The contrastive objective must be well-designed to replace labeled data
- Failure signatures:
  - Training instability: Oscillating or exploding gradients during contrastive learning
  - Poor pruning quality: Downstream performance degrades significantly with pruning
  - Inference inefficiency: Graph-less network doesn't provide expected speedups
- First 3 experiments:
  1. Ablation study: Remove contrastive loss vs. self-distillation vs. regularization to identify most critical components
  2. Hyperparameter sensitivity: Vary pruning ratio 𝑝 and Bernoulli probability 𝑞 to find optimal settings
  3. Efficiency benchmark: Compare inference time and storage requirements against baselines on the Alipay dataset

## Limitations
- The evaluation is limited to three datasets, with the largest being an industrial dataset whose specific preprocessing steps are not fully disclosed
- The claim of maintaining 98% performance while pruning 50% of edges may not generalize across all graph types
- The Bernoulli Moment Matching regularization is novel but lacks comparison to simpler alternatives

## Confidence
- High Confidence: The overall framework design and multi-component architecture are well-specified and technically sound
- Medium Confidence: The empirical results showing pruning efficiency gains are convincing, though dataset coverage is limited
- Low Confidence: The effectiveness of Bernoulli Moment Matching regularization compared to simpler approaches is not well-established
