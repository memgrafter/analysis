# Multilevel Sentence Embeddings for Personality Prediction

## Quick Facts
- arXiv ID: 2305.05748
- Source URL: https://arxiv.org/abs/2305.05748
- Reference count: 18
- Key outcome: Two-step approach achieves 0.381 (English) and 0.342 (Japanese) mean absolute errors for personality prediction, outperforming separate BERT models

## Executive Summary
This study introduces a novel two-step approach for training sentence embedding models on hierarchically structured data, specifically for personality prediction from social media posts. The method first maps sentences to a hypersphere using AdaCos loss based on class memberships, then fine-tunes with a novel loss function based on cosine similarity of intra-level pairs to capture polarity differences. Applied to both English and Japanese personality datasets as well as the MNLI dataset, the approach demonstrates superior performance compared to multiple class-specific models while maintaining a single unified model architecture.

## Method Summary
The proposed method employs a two-stage training process for sentence embedding models. First, sentences are mapped to a hypersphere using AdaCos loss, which optimizes class membership separation. Second, the model is fine-tuned with a novel loss function that calculates cosine similarity between intra-level pairs, specifically designed to capture polarity differences within hierarchical structures. This approach is evaluated across multiple datasets including English and Japanese personality prediction tasks and the MNLI dataset, showing consistent improvements over separate class-specific models.

## Key Results
- Achieves average mean absolute errors of 0.381 (English) and 0.342 (Japanese) for personality prediction
- Outperforms five separate BERT models with errors of 0.411 and 0.456 respectively
- For MNLI dataset, achieves 0.284 average error versus 0.321 for separate models

## Why This Works (Mechanism)
The two-step approach effectively captures both class membership and polarity differences within hierarchical data structures. The initial AdaCos loss ensures proper separation of different classes in the embedding space, while the subsequent fine-tuning with intra-level polarity loss captures nuanced differences between similar classes. This hierarchical approach allows the model to learn both coarse-grained class distinctions and fine-grained polarity relationships simultaneously, leading to improved generalization across different personality prediction tasks.

**Component map**: Input text -> Text encoder (BERT) -> AdaCos loss layer -> Intra-level polarity loss -> Final embeddings

**Critical path**: Text encoding -> AdaCos training -> Intra-level polarity fine-tuning -> Prediction

**Design tradeoffs**: Single model vs. multiple class-specific models (computational efficiency vs. specialization), hypersphere mapping vs. standard embeddings (class separation vs. flexibility)

**Failure signatures**: Poor class separation in embedding space, inability to capture polarity differences between similar classes, overfitting to specific personality assessment frameworks
