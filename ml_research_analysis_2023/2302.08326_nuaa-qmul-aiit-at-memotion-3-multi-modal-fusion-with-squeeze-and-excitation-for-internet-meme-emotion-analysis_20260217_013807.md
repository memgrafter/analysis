# NUAA-QMUL-AIIT at Memotion 3: Multi-modal Fusion with Squeeze-and-Excitation for Internet Meme Emotion Analysis

## Quick Facts
- arXiv ID: 2302.08326
- Source URL: https://arxiv.org/abs/2302.08326
- Reference count: 23
- Key outcome: Achieved top rank in task A (F1: 0.3441) and second place in task C of Memotion 3 shared task

## Executive Summary
This paper introduces SEFusion, a multi-modal fusion method for internet meme emotion analysis that combines text and image features using squeeze-and-excitation principles. The approach learns modality-specific weights to capture the relative importance of text versus image content for each meme, then applies these weights to their respective features through matrix multiplication. SEFusion achieved top performance in Task A (emotion classification) and second place in Task C (scale quantification) of the Memotion 3 shared task, demonstrating its effectiveness for meme emotion analysis while highlighting challenges in offensive content detection.

## Method Summary
The system extracts text features using Twitter-RoBERTa and image features using CLIP-ViT-B-32, then applies SEFusion to combine these modalities. SEFusion works by reducing each modality feature to a scalar weight via dense layers, concatenating these weights, applying a sigmoid gating mechanism, and performing matrix multiplication with reshaped concatenated features. Classification uses dense layers with task-specific depths (2 layers for tasks A/B, 5 layers for task C) and is trained with sparse categorical cross-entropy with prior loss and Logit Adjustment for imbalanced data.

## Key Results
- Achieved top rank in Task A (emotion classification) with F1 score of 0.3441
- Ranked second in Task C (scale quantification) of Memotion 3 shared task
- Significant performance gap in Task B3 (offensive meme classification) with F1 near 0.5
- Demonstrated effectiveness of SEFusion for meme emotion analysis while highlighting limitations in offensive content detection

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SEFusion learns modality-specific weights that capture the relative importance of text vs. image for each meme
- Mechanism: The squeeze step reduces each modality feature to a scalar weight via a dense layer. The excitation step applies a gating mechanism (sigmoid of W4·ReLU(W3·z)) to produce final weights s. These weights are multiplied by reshaped concatenated features to produce the fused output
- Core assumption: The scalar weights learned in the squeeze step are sufficient to represent the relative importance of each modality for the final classification task

- Break condition: If the scalar weights cannot capture the complex dependencies between modalities, the fusion may be suboptimal

### Mechanism 2
- Claim: SEFusion allows flexible fusion of features from different modalities regardless of their dimensional differences
- Mechanism: The text and image features are concatenated, reshaped into X' (R2×640), and the weight vector s (R1×2) is multiplied with X' to produce the final fused feature
- Core assumption: Reshaping the concatenated features allows the learned weights to be applied uniformly across all features, regardless of their original modality
- Evidence anchors: [section 3.3.2]: "Considering that the dimensionality of the text and image features are different, we concatenate these features and directly reshape the concatenated features into X′... in order to apply the operation matrix multiplication on s and X′ easily."; [corpus]: No direct citations; this is the proposed method
- Break condition: If the reshaping mixes features from different modalities in a way that prevents the learned weights from being applied meaningfully, the fusion may be ineffective

### Mechanism 3
- Claim: SEFusion improves meme emotion classification by explicitly modeling modal interdependencies
- Mechanism: The excitation step (gating mechanism) captures the relationships between the modalities by learning how the weight of one modality depends on the weight of the other
- Core assumption: The gating mechanism can effectively capture the interdependencies between modalities and improve classification performance
- Evidence anchors: [abstract]: "SEFusion learns the weights of each modality and applies them to their own modality features, allowing for flexible fusion of features from different modalities."; [section 3.3.2]: "To make use of the information aggregated in the squeeze operation, we follow it with a second operation that aims to fully capture modal-wise dependencies."; [corpus]: No direct citations; this is the proposed method

## Open Questions the Paper Calls Out

- Question: Why does task B3 (offensive meme classification) perform significantly worse than other binary classification tasks in the Memotion 3 challenge?
  - Basis in paper: [explicit] The authors note that task B3's weighted-F1 score is near 0.5, close to the general baseline for binary classification, while other sub-tasks show much better performance. They suggest that "identifying the offensive memes is very hard using our existing features."
  - Why unresolved: The paper identifies this as a problem but doesn't investigate the underlying causes. It's unclear whether this is due to dataset imbalance, feature extraction limitations, or the inherent difficulty of offensive content detection in memes
  - What evidence would resolve it: A detailed error analysis showing which types of offensive memes are misclassified, comparison with alternative feature extraction methods, or ablation studies testing different model architectures for this specific task

- Question: How would the SEFusion method perform if the feature dimensions of different modalities were unified before applying the fusion operation?
  - Basis in paper: [explicit] The authors acknowledge a limitation where "the weight did not apply to the corresponding modality since we mixed the text and image features when reshaping the concatenated feature vector" and suggest "unifying the feature dimension of different modalities before performing SEFusion" as a future direction
  - Why unresolved: The authors did not implement or test this alternative approach, so there's no empirical evidence about whether this modification would improve performance
  - What evidence would resolve it: Running the same experiments with dimension-unified features and comparing the results to the current SEFusion approach

- Question: What is the optimal number of dense layers for each subtask in the meme emotion analysis pipeline?
  - Basis in paper: [explicit] The authors mention that "we use 2 dense layers" for task A and B, but "we use 5 dense layers" for task C, noting that "𝑛 is a hyper-parameter and needs to be adjusted for different sub-tasks."
  - Why unresolved: The paper does not provide systematic experimentation or justification for these specific choices. It's unclear whether these numbers are optimal or if different tasks would benefit from different configurations
  - What evidence would resolve it: Conducting a systematic hyperparameter search across all subtasks to determine the optimal number of dense layers for each, or providing theoretical justification for why different tasks require different depths

## Limitations
- The reshaping operation in SEFusion mixes text and image features, preventing learned weights from being applied specifically to their corresponding modality
- Underfitting observed across tasks with lower training than validation F1 scores suggests model capacity or training duration may be insufficient
- Task B3 (offensive meme classification) performs near random chance, indicating the features extracted are inadequate for detecting offensive content

## Confidence
- **High confidence**: The SEFusion mechanism is clearly described through equations and implementation details are reproducible for the core fusion component
- **Medium confidence**: The ranking results are verifiable against competition metrics, but the comparative analysis with baseline methods is limited to final scores without statistical significance testing
- **Low confidence**: The claim that SEFusion is "superior" to other fusion methods lacks rigorous ablation studies or direct comparisons with established techniques like attention-based fusion
