# RSRM: Reinforcement Symbolic Regression Machine

## Executive Summary
This paper presents the Reinforcement Symbolic Regression Machine (RSRM), a novel approach that combines reinforcement learning with symbolic regression to discover complex mathematical equations from limited data. The method integrates Monte Carlo Tree Search, Double Q-learning, and a modulated sub-tree discovery block to efficiently search for accurate mathematical expressions. RSRM demonstrates superior performance over baseline models on basic benchmarks and shows improved generalization capabilities on real-world datasets like free-falling balls.

## Method Summary
RSRM employs a three-module architecture: an MCTS agent explores optimal math expression trees, Double Q-learning reduces the search space, and a modulated sub-tree discovery block defines new mathematical operators. This combination allows the system to balance exploration and exploitation while discovering complex symbolic relationships from data. The method addresses key challenges in symbolic regression by using reinforcement learning techniques to guide the search process and genetic programming principles to evolve expression structures.

## Key Results
- Achieves 100% recovery rates for complex expressions on basic benchmarks
- Demonstrates superior performance on free-falling balls dataset compared to NGGP, cubic splines, and MLPs
- Shows better generalization test results than competing methods

## Why This Works (Mechanism)
The method's effectiveness stems from its three-pronged approach: MCTS provides systematic exploration of the expression space, Double Q-learning optimizes the search through value estimation and reduced state space, and the modulated sub-tree discovery block expands the operator vocabulary to capture complex relationships. This integration allows RSRM to navigate the combinatorial explosion of possible expressions while maintaining accuracy and generalization capabilities.

## Architecture Onboarding

**Component Map**: Data -> Preprocessing -> MCTS Agent -> Double Q-learning -> Modulated Sub-tree Discovery -> Expression Output

**Critical Path**: The core computational flow follows data preprocessing through MCTS exploration, value estimation via Double Q-learning, and operator discovery, with each stage feeding into the next to produce final expressions.

**Design Tradeoffs**: The integration of three distinct techniques creates complexity but enables superior performance. The choice of Double Q-learning over single Q-learning reduces overestimation bias but increases computational overhead. The modulated sub-tree discovery block adds flexibility but may introduce overfitting risks.

**Failure Signatures**: Poor performance may manifest as: inability to discover simple expressions (MCTS exploration issues), overfitting to training data (Double Q-learning value estimation problems), or failure to generalize (modulated sub-tree discovery generating overly complex operators).
