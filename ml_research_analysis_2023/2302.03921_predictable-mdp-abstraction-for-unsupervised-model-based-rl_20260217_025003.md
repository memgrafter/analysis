# Predictable MDP Abstraction for Unsupervised Model-Based RL

## Quick Facts
- **arXiv ID**: 2302.03921
- **Source URL**: https://arxiv.org/abs/2302.03921
- **Reference count**: 40
- **Primary result**: PMA learns a latent MDP by transforming the action space to only allow predictable actions, outperforming prior unsupervised model-based RL methods.

## Executive Summary
PMA (Predictable MDP Abstraction) addresses model exploitation in unsupervised model-based RL by learning a latent MDP where actions are restricted to those with predictable outcomes. The method uses an information-theoretic objective to balance predictability, state coverage, and epistemic uncertainty minimization. PMA demonstrates superior zero-shot planning and RL performance across seven MuJoCo environments compared to prior approaches, while enabling robust longer-horizon planning without model exploitation.

## Method Summary
PMA transforms the action space to only allow predictable actions, aiming to reduce model errors that cause exploitation. The approach uses an information-theoretic objective to maximize predictability and state coverage while minimizing epistemic uncertainty. This creates a latent MDP that can be used for zero-shot planning or as a foundation for subsequent RL training. The method addresses a key challenge in model-based RL where inaccurate models can be exploited by agents to achieve high rewards through unrealistic state transitions.

## Key Results
- PMA outperforms prior unsupervised model-based RL methods in zero-shot planning and RL performance across seven MuJoCo environments
- Achieves better robustness for longer-horizon planning without suffering from model exploitation
- Demonstrates that restricting actions to predictable outcomes improves planning reliability and final performance

## Why This Works (Mechanism)
PMA works by transforming the original MDP's action space to only include actions that lead to predictable state transitions. This predictability is measured through an information-theoretic objective that simultaneously maximizes state coverage while minimizing epistemic uncertainty. By removing unpredictable actions from consideration, the learned latent MDP avoids the model exploitation problem common in standard model-based RL, where agents discover and exploit inaccuracies in the learned dynamics model to achieve high rewards through unrealistic transitions.

## Foundational Learning
- **Epistemic uncertainty**: Uncertainty due to limited data that can be reduced with more observations; crucial for identifying which model predictions are reliable versus which should be avoided.
- **Information bottleneck principle**: Technique for learning compressed representations that retain task-relevant information; used here to balance predictability against state coverage.
- **Latent MDP**: A lower-dimensional Markov Decision Process that abstracts the original environment; enables more efficient planning while preserving essential dynamics.
- **Model exploitation**: Phenomenon where RL agents discover and exploit inaccuracies in learned dynamics models to achieve high rewards through unrealistic state transitions.
- **Deterministic latent dynamics**: Assumption that the latent state transitions follow deterministic rules; simplifies learning but may not capture all environment stochasticity.

## Architecture Onboarding
**Component map**: Original MDP -> Predictability filter -> Latent MDP -> Planner/RL agent
**Critical path**: State observation → Predictability evaluation → Action filtering → Latent state transition → Planning/RL update
**Design tradeoffs**: 
- Predictability vs. coverage: Stricter predictability requirements yield more reliable models but may limit achievable performance
- Latent space dimensionality: Higher dimensions capture more information but increase computational cost and overfitting risk
- Epistemic uncertainty estimation: More sophisticated methods provide better uncertainty quantification but increase computational overhead

**Failure signatures**:
- Poor performance on stochastic environments where few actions are truly predictable
- Collapse to trivial latent representations that cover minimal state space
- Over-reliance on epistemic uncertainty minimization leading to overly conservative behavior

**First experiments**:
1. Evaluate predictability filtering on a simple gridworld with known dynamics
2. Compare latent state representations learned with and without epistemic uncertainty terms
3. Test zero-shot planning performance on a deterministic pendulum environment

## Limitations
- The information-theoretic objective may struggle to distinguish predictable actions in complex environments
- The learned latent MDP may lose task-relevant structure when state abstraction is lossy
- The method assumes minimal stochasticity in the environment, which may not hold for all domains

## Confidence
- **Predictable action transformation reduces model exploitation**: High confidence based on ablation studies and comparison to baselines
- **Information-theoretic objective balances predictability and state coverage**: Medium confidence; results support the claim but could benefit from additional qualitative analysis of latent states
- **Zero-shot planning performance**: High confidence supported by quantitative results across multiple environments

## Next Checks
1. Test PMA on environments with high stochasticity to evaluate robustness of the predictable action transformation
2. Perform ablation studies isolating the impact of epistemic uncertainty minimization versus predictability maximization
3. Compare latent state representations learned by PMA to ground-truth state features in environments where available
