# Unveiling Cross Modality Bias in Visual Question Answering: A Causal View with Possible Worlds VQA

## Quick Facts
- arXiv ID: 2305.19664
- Source URL: https://arxiv.org/abs/2305.19664
- Authors: [List of authors not provided]
- Reference count: 31
- Primary result: Achieves state-of-the-art performance on VQA-CP v2, doubling accuracy on numerical questions through causal bias reduction.

## Executive Summary
This paper introduces a causal approach to reduce vision and language bias in VQA systems by modeling experience bias as an unobserved confounder and using counterfactual inference. The method employs an explain-away fusion strategy and a causal graph that separates the problem into anticausal learning and an explain-away network. The model is trained to concurrently reduce vision and language bias, significantly improving accuracy on VQA-CP v2 datasets, particularly for numerical questions.

## Method Summary
The proposed PW-VQA model uses a causal graph to separate VQA into anticausal learning (learning from answer to question and image) and an explain-away network (modeling language-vision bias through a collider structure). The model includes vision and question encoders, a multimodal encoder, and an explain-away fusion function. Training involves counterfactual inference to compute total indirect effects, with losses for VQA prediction, question prediction, and answer prediction, plus KL-divergence to stabilize the counterfactual branch.

## Key Results
- Doubles accuracy on numerical questions compared to previous methods
- Achieves state-of-the-art performance on VQA-CP v2 dataset
- Effectively reduces both vision and language bias in VQA systems

## Why This Works (Mechanism)

### Mechanism 1: Anticausal Learning
- **Claim:** Reformulates VQA by modeling answer as cause of vision and question
- **Mechanism:** Reverses usual direction to learn from A to (Q,V), removing spurious correlations
- **Core assumption:** Ground-truth answer A is available and correctly influences Q and V during training
- **Evidence anchors:** Abstract mentions modeling confounding effects; section on anticausal learning; weak corpus support
- **Break condition:** Fails if A is noisy or dataset doesn't reflect true causal relationship

### Mechanism 2: Explain-Away Network
- **Claim:** Collider structure Q→K←V removes vision-language shortcuts
- **Mechanism:** Blocks direct paths when collider is present, forcing joint multimodal reasoning
- **Core assumption:** Language and vision shortcuts mediated through shared representation K
- **Evidence anchors:** Abstract mentions explain-away relations; section defines collider structure; weak corpus support
- **Break condition:** Ineffective if K doesn't adequately fuse Q and V or collider assumption is invalid

### Mechanism 3: Unobserved Confounder Modeling
- **Claim:** Models annotator experience U as common cause of A, Q, and V
- **Mechanism:** Blocks paths through U via counterfactual inference to reduce experience bias
- **Core assumption:** Annotator experience influences Q and V selection and can be inferred
- **Evidence anchors:** Abstract mentions experience bias modeling; section on confounder structure; weak corpus support
- **Break condition:** Fails if experience bias isn't dominant or can't be inferred from data

## Architecture Onboarding

- **Component map:**
  - Vision encoder (FV) -> extracts image features v
  - Question encoder (FQ) -> extracts question features q
  - Multimodal encoder (FVQ) -> fuses v and q into k
  - Explain-away fusion function (EA) -> combines Zq, Zv, Zk with parameter α
  - Answer predictor -> outputs logits Zq,v,k, Zq, Zv
  - KL-divergence loss (Lkl) -> stabilizes counterfactual branch sharpness
  - Cross-entropy losses (LVQA, LQ, LVA) -> train each branch

- **Critical path:** v,q → FV, FQ → FVQ → Zk → EA → Zq,v,k → answer; counterfactual branch uses v*, q*, k* to compute TIE

- **Design tradeoffs:**
  - Anticausal learning requires correct A labels during training
  - EA fusion adds complexity for bias removal capability
  - Unobserved confounder modeling needs strong causal assumptions

- **Failure signatures:**
  - TIE ≈ TE indicates ineffective counterfactual branch
  - Y/N accuracy drop suggests over-suppression of useful language bias
  - Other question performance worsening indicates too aggressive explain-away

- **First 3 experiments:**
  1. Run with α=1.0, fixed c to verify TIE reduces to zero and Lkl is active
  2. Compare Y/N, Num, Other accuracy with/without counterfactual branch
  3. Train with synthetic confounder U to verify causal effect recovery

## Limitations
- Causal assumptions about unobserved confounder U lack empirical validation
- Anticausal learning direction may not hold uniformly across VQA-CP v2 data
- Explain-away collider effectiveness depends heavily on multimodal fusion quality

## Confidence

- **High confidence:** Mathematical formulation of counterfactual inference and TIE calculation
- **Medium confidence:** Performance improvements on VQA-CP v2 are real but causal attribution needs validation
- **Low confidence:** Causal graph assumptions about dataset generation process
