# Learning Multi-Object Positional Relationships via Emergent Communication

## Quick Facts
- arXiv ID: 2302.08084
- Source URL: https://arxiv.org/abs/2302.08084
- Authors: 
- Reference count: 18
- Primary result: Emergent communication can learn positional relationships between objects and transfer to multi-step MDP tasks, outperforming raw-pixel inputs and pre-trained features

## Executive Summary
This paper investigates emergent communication about positional relationships between two objects in a referential game setting. The key finding is that input variation between Speaker and Listener agents is crucial for learning abstract positional relationships rather than memorizing specific pixel patterns. The emergent language learned through this process generalizes well to a multi-step Object Placement task and outperforms both raw-pixel images and pre-trained image features. The paper also demonstrates that pre-training in the referential game with input variation is more effective than pre-training image encoders with contrastive learning methods.

## Method Summary
The paper uses a referential game setup where a Speaker agent observes a target image and generates a message to describe it, while a Listener agent receives the message and selects the target image from a set of candidates. Three datasets are used: fixed (same images for both agents), variation (randomly generated images but same for both agents), and random (randomly generated images for each agent separately). The agents are trained using REINFORCE for the Speaker and cross-entropy loss for the Listener. The learned language is then transferred to a multi-step MDP task (Object Placement) where the positional relationship describes the goal. The paper compares emergent communication against raw-pixel inputs, pre-trained image features from SimCLR, and RL-trained from scratch.

## Key Results
- Input variation between Speaker and Listener is necessary for emergent communication about abstract positional relationships
- Emergent language generalizes well to the multi-step Object Placement MDP task and outperforms raw-pixel images and pre-trained features
- Language transfer from the referential game performs better than learning language directly in the new task

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Input variation between Speaker and Listener is necessary for emergent communication about abstract positional relationships.
- **Mechanism:** When Speaker and Listener observe different pixel-level instantiations of the same abstract (object, object, relationship) combination, the environment forces agents to encode semantic relationships rather than memorize specific pixel patterns.
- **Core assumption:** The random image generator produces diverse enough pixel-level differences while preserving semantic content for the agents to detect the underlying abstraction.
- **Evidence anchors:**
  - [abstract]: "The key factor affecting the generalization ability of the emergent language is the input variation between Speaker and Listener, which is realized by a random image generator in our work."
  - [section]: "We use a random image generator to generate specific images according to the combinations, where the absolute position, size, and orientation of objects vary... agents can only succeed when they express and understand the abstract information in the images."
- **Break condition:** If the random generator produces insufficiently diverse images or if the variation is too extreme to preserve the positional relationship, agents may fail to extract the abstraction.

### Mechanism 2
- **Claim:** Emergent language from the referential game generalizes better to multi-step MDP tasks than raw-pixel inputs or pre-trained features.
- **Mechanism:** The discrete symbolic language learned in the referential game captures abstract positional relationships in a compressed, compositional form that new agents can quickly interpret and use for policy learning.
- **Core assumption:** The referential game environment encourages the emergence of compositional, generalizable language that can be transferred to new tasks.
- **Evidence anchors:**
  - [abstract]: "The learned language can generalize well in a new multi-step MDP task where the positional relationship describes the goal, and performs better than raw-pixel images as well as pre-trained image features."
  - [section]: "Our experiments show that the emergent language can generalize well in the new multi-step MDP task, and is more powerful than raw-pixel images as well as pre-trained image features."
- **Break condition:** If the new task requires different types of information not captured by positional relationships, or if the symbolic language becomes too task-specific, generalization may fail.

### Mechanism 3
- **Claim:** Pre-training in the referential game with input variation is more effective than pre-training image encoders with SimCLR for emergent communication.
- **Mechanism:** Pre-training image encoders with SimCLR makes different pixel-level instantiations of the same semantic content too similar, reducing the environmental pressure on agents to use emergent language for semantic encoding.
- **Core assumption:** The effectiveness of emergent communication depends on the agents having to solve the semantic encoding problem themselves rather than relying on pre-encoded representations.
- **Evidence anchors:**
  - [abstract]: "We also use an image encoder pre-trained by a contrastive learning method, SimCLR (Chen et al., 2020), for comparison, and show that the language learned through the referential game with the random dataset generalizes better."
  - [section]: "Using the pre-trained SimCLR model leads to worse performance compared to Figure 2b, i.e., the agents cannot generalize well on the test set, though we find that they get a high accuracy at training time."
- **Break condition:** If the pre-trained encoder preserves sufficient diversity in representations or if the referential game environment is modified to reduce input variation, this advantage may disappear.

## Architecture Onboarding

- **Component map:**
  - Random image generator → creates diverse pixel-level instantiations of (object, object, relationship) combinations
  - Speaker: CNN image encoder → LSTM sequence generator → symbol distribution
  - Listener: CNN image encoder → LSTM sequence encoder → similarity computation → image selection
  - Object Placement environment: 3×3 grid with two movable objects, goal defined by positional relationship

- **Critical path:** Speaker generates message from target image → Listener receives message and candidate images → Listener selects target image → reward signal propagates back to train both agents

- **Design tradeoffs:**
  - Message length (T=6) vs. expressiveness: Longer messages could capture more complex relationships but increase learning difficulty
  - Vocabulary size (|V|=5) vs. compositional capacity: Larger vocabularies enable more diverse messages but may reduce pressure for compositionality
  - Input variation level vs. learning stability: Too much variation may prevent learning; too little fails to force abstraction

- **Failure signatures:**
  - Low test accuracy despite high training accuracy: Likely overfitting to specific pixel patterns rather than learning abstract relationships
  - Slow convergence in Object Placement task: May indicate the emergent language isn't capturing the necessary information or new Listener struggles to interpret it
  - High TopSim but poor task performance: Could mean the language is compositional but not aligned with task requirements

- **First 3 experiments:**
  1. Train agents on fixed dataset and evaluate on random test set to confirm input variation is necessary
  2. Train agents on variation dataset and evaluate on random test set to confirm input variation is necessary
  3. Train agents on random dataset and evaluate on random test set to confirm the proposed approach works

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the input variation between Speaker and Listener impact the emergence of compositional language in referential games?
- Basis in paper: [explicit] The paper states that input variation between Speaker and Listener is crucial for learning abstract information in emergent communication.
- Why unresolved: While the paper demonstrates the importance of input variation, it does not provide a detailed analysis of how different degrees of variation impact the emergence of compositional language.
- What evidence would resolve it: A study varying the degree of input variation and measuring the resulting compositionality of the emergent language.

### Open Question 2
- Question: Can emergent communication protocols learned in referential games effectively transfer to more complex multi-step MDP tasks with different state spaces?
- Basis in paper: [explicit] The paper shows that language transfer from the referential game to a multi-step MDP task (Object Placement) outperforms learning language directly in the task.
- Why unresolved: The Object Placement task used in the paper is relatively simple. It's unclear if the emergent language would generalize to more complex tasks with larger state spaces or different types of objectives.
- What evidence would resolve it: Testing the emergent language on a variety of more complex MDP tasks with different state spaces and objectives.

### Open Question 3
- Question: How does the use of pre-trained image encoders affect the emergence and generalization of communication protocols in referential games?
- Basis in paper: [explicit] The paper shows that using pre-trained SimCLR image encoders leads to worse performance compared to learning image representations from scratch in the referential game.
- Why unresolved: While the paper demonstrates a negative effect, it doesn't explore why this occurs or whether other pre-trained encoders might have different effects.
- What evidence would resolve it: A systematic study of different pre-trained image encoders and their impact on emergent communication, including analysis of the learned representations.

## Limitations

- The paper's results are limited to simple positional relationships between two objects in a 3x3 grid, which may not generalize to more complex spatial reasoning tasks
- The effectiveness of input variation depends heavily on the quality and diversity of the random image generator, which isn't thoroughly validated
- The small vocabulary size (|V|=5) and fixed message length (T=6) may artificially constrain the emergent language's expressive power

## Confidence

**High Confidence:**
- Emergent communication with input variation achieves higher test accuracy than without variation
- Emergent language outperforms raw-pixel images and pre-trained features in the Object Placement task

**Medium Confidence:**
- Pre-training in the referential game with input variation is more effective than pre-training image encoders with SimCLR
- Language transfer from the referential game performs better than learning language directly in the task

**Low Confidence:**
- The emergent language is compositional and generalizable due to input variation forcing semantic abstraction
- The discrete symbolic language captures abstract positional relationships in a compressed, compositional form

## Next Checks

1. **Validate image generator diversity:** Analyze the distribution of pixel-level variations produced by the random image generator to confirm it creates sufficient diversity while preserving semantic relationships. This should include statistical measures of object position, size, and orientation variation across generated images.

2. **Test with expanded relationship vocabulary:** Extend the study to include more complex spatial relationships (e.g., diagonal, circular arrangements) and larger state spaces to evaluate whether the emergent communication approach scales beyond the current limited scope.

3. **Compare with alternative representation learning:** Implement and compare against other representation learning approaches (e.g., VQ-VAE, autoencoder-based methods) to determine if the advantages of emergent communication are specific to the communication framework or stem from general representation learning benefits.
