# Task-Attentive Transformer Architecture for Continual Learning of Vision-and-Language Tasks Using Knowledge Distillation

## Quick Facts
- **arXiv ID**: 2303.14423
- **Source URL**: https://arxiv.org/abs/2303.14423
- **Reference count**: 40
- **Primary result**: Task-attentive transformer with dynamic expansion and knowledge distillation achieves state-of-the-art performance on vision-and-language continual learning benchmarks.

## Executive Summary
This paper introduces a task-attentive transformer architecture for continual learning of vision-and-language tasks. The approach dynamically expands the model by adding task-specific attention layers and utilizes knowledge distillation to mitigate catastrophic forgetting. Experiments on diverse vision-and-language benchmarks demonstrate that the proposed method achieves state-of-the-art performance in terms of both accuracy and forgetting rates compared to existing continual learning techniques.

## Method Summary
The method dynamically expands a pre-trained ViLT transformer by adding task-specific attention layers and classifier heads for each new task. The base ViLT encoder remains frozen while task-attention blocks are inserted after the last self-attention layer. Knowledge distillation is applied between intermediate layers to constrain distribution shift without harming plasticity. A small memory buffer (1% of data) is used for experience replay during training. The model is trained using AdamW optimizer with cross-entropy, knowledge distillation, and diversity losses.

## Key Results
- State-of-the-art performance on vision-and-language continual learning benchmarks
- Significant reduction in forgetting rates compared to baseline methods
- Effective knowledge transfer across sequentially learned tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Dynamic task-attention layers enable specialization without forgetting.
- Mechanism: Each new task introduces a unique task token and classifier head, while the base ViLT encoder remains frozen. This isolates task-specific learning to the added layers.
- Core assumption: The base encoder captures generalizable features that can be shared across tasks, and catastrophic forgetting occurs primarily in task-specific parameters.
- Evidence anchors:
  - [abstract]: "The new additional parameters are used to specialize the network for each task."
  - [section 4.2]: "The task attention block is placed after the last self-attention block of the transformer... we define a new task token with the same dimension, τ ∈ G × 1, and initialize a new task-specific classifier."
- Break condition: If base encoder updates are needed for task-specific adaptation, freezing them may limit performance.

### Mechanism 2
- Claim: Intermediate knowledge distillation constrains distribution shift without harming plasticity.
- Mechanism: Knowledge distillation loss is computed between the last self-attention block and the task-attention block, constraining the pre-trained parameters while allowing the task-specific layers to adapt.
- Core assumption: Intermediate layers encode high-level shared knowledge that benefits all tasks, and constraining these layers prevents forgetting without blocking new learning.
- Evidence anchors:
  - [section 5.2]: "the loss term Likd is computed between the last self-attention block of the transformer and the task attention block... we are the first method that introduces intermediate knowledge distillation objective function in the multimodal CL field."
- Break condition: If intermediate layer features become too task-specific, distillation may hinder adaptation.

### Mechanism 3
- Claim: Experience replay with small memory buffer mitigates forgetting for diverse tasks.
- Mechanism: A small subset of data from previous tasks is stored and replayed during current task training, maintaining parameter distributions for old tasks.
- Core assumption: Even a small amount of replay data can effectively prevent catastrophic forgetting when combined with distillation and task-specific layers.
- Evidence anchors:
  - [section 5.3]: "we use a memory buffer during the training stage at each time-step which stores a tiny percentage, e.g., ≈ 1%, of the training dataset for all the previous tasks... When learning the current task with a specific batch number, the next batch will be randomly selected from the memory buffer."
- Break condition: If task distributions are too dissimilar, a small memory buffer may not provide sufficient diversity.

## Architecture Onboarding

- Component map: ViLT encoder -> Task-attention block -> Task-specific classifier head -> Output
- Critical path: Input → ViLT encoder → Task-attention block → Task-specific classifier → Output
- Design tradeoffs:
  - Freezing base encoder vs. allowing updates for task-specific adaptation
  - Size of memory buffer vs. computational overhead
  - Number of task-attention layers vs. model complexity
- Failure signatures:
  - High forgetting rates indicate insufficient constraint on base encoder updates or inadequate memory buffer size.
  - Low accuracy on new tasks suggests task-specific layers are not learning effectively or distillation is too restrictive.
- First 3 experiments:
  1. Test with a single new task to verify task-attention block specialization works.
  2. Test with two tasks in sequence to observe forgetting and knowledge transfer.
  3. Test with varying memory buffer sizes to find optimal tradeoff between forgetting prevention and computational overhead.
