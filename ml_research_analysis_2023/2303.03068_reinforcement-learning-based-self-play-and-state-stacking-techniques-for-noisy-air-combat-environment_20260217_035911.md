# Reinforcement Learning Based Self-play and State Stacking Techniques for Noisy Air Combat Environment

## Quick Facts
- arXiv ID: 2303.03068
- Source URL: https://arxiv.org/abs/2303.03068
- Reference count: 18

## Executive Summary
This paper presents a reinforcement learning approach for autonomous air combat that addresses the challenge of noisy observations through a novel state stacking technique and improves robustness through a self-play mechanism. The state stacking method concatenates consecutive observations to provide temporal context that helps agents filter out noise and make more informed decisions. The self-play component involves periodically updating the enemy agent with a frozen copy of the training agent, creating increasingly sophisticated adversarial scenarios that enhance the main agent's performance. Experimental results demonstrate significant improvements in winning ratios compared to baseline approaches, particularly under high noise conditions.

## Method Summary
The proposed framework combines two key techniques: state stacking and self-play. State stacking mitigates observation noise by concatenating multiple consecutive states into a single input, allowing the agent to leverage temporal information for better decision-making in noisy environments. The self-play mechanism periodically updates the enemy agent with a frozen copy of the training agent, creating progressively challenging scenarios that improve the agent's robustness and generalization. The reinforcement learning agent is trained using standard algorithms, with the modified observation space from state stacking and the dynamic enemy behavior from self-play. Experiments were conducted in simulated air combat environments with varying noise levels to evaluate the effectiveness of these techniques.

## Key Results
- State stacking technique achieved up to 238% performance increase under high noise levels compared to single-state observations
- Both state stacking and self-play significantly improved agent winning ratios compared to baseline approaches
- Self-play created progressively smarter enemy strategies that enhanced overall agent robustness

## Why This Works (Mechanism)
The state stacking technique works by providing temporal context that helps filter out random noise in individual observations. By concatenating consecutive states, the agent can distinguish between actual environmental changes and noise-induced variations, leading to more stable and accurate decision-making. The self-play mechanism creates a curriculum of increasingly difficult scenarios, where the agent must adapt to smarter opponents over time, resulting in better generalization and robustness to various combat situations.
