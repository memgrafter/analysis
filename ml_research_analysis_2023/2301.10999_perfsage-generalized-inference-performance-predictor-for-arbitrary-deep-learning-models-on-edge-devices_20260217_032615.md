# PerfSAGE: Generalized Inference Performance Predictor for Arbitrary Deep Learning Models on Edge Devices

## Quick Facts
- arXiv ID: 2301.10999
- Source URL: https://arxiv.org/abs/2301.10999
- Reference count: 18
- PerfSAGE achieves MAPE <5% across all targets and model search spaces

## Executive Summary
This paper introduces PerfSAGE, a novel graph neural network (GNN) approach for predicting inference performance metrics (latency, energy, memory) of arbitrary deep neural network (DNN) models on edge hardware platforms. PerfSAGE uses a GNN-based feature extractor that directly processes arbitrary DNN graphs without requiring prior knowledge of model construction rules or search spaces. The authors introduce the EdgeDLPerf dataset containing 134,912 DNN models from four distinct search spaces annotated with performance metrics from three edge hardware platforms. Experimental results demonstrate state-of-the-art prediction accuracy with MAPE <5% across all targets and model search spaces, outperforming previous GNN-based predictors and addressing limitations of non-GNN approaches for accelerator prediction.

## Method Summary
PerfSAGE employs a graph neural network architecture that directly processes arbitrary DNN graph structures. The model uses a novel GNN-based feature extractor to encode DNN architectures, handling categorical node and edge features through learned embeddings. The training process optimizes a hybrid loss function combining mean absolute percentage error across latency, energy, and memory targets. The approach is trained on the EdgeDLPerf dataset, which provides comprehensive coverage of diverse model search spaces and three edge hardware platforms (CPU, NPU, TPU). The GNN architecture enables generalization across arbitrary model structures without requiring knowledge of specific search spaces or construction rules.

## Key Results
- Achieves MAPE <5% across all targets (latency, energy, memory) and model search spaces
- Outperforms previous state-of-the-art GNN-based performance predictors
- Successfully predicts performance on accelerators, addressing limitations of non-GNN approaches
- Demonstrates generalization across four distinct search spaces with 134,912 total models

## Why This Works (Mechanism)
PerfSAGE works by leveraging graph neural networks to directly process the structural relationships in DNN architectures. Unlike traditional predictors that rely on predefined feature sets or search space knowledge, the GNN-based feature extractor learns to capture relevant architectural patterns through message passing over the graph structure. This allows the model to handle arbitrary graph topologies and extract meaningful performance-related features from the connectivity patterns, layer types, and parameter configurations. The hybrid loss function ensures balanced optimization across all three performance targets.

## Architecture Onboarding

**Component Map:**
Raw DNN Graph → GNN Feature Extractor → Learned Embeddings → Performance Predictors → MAPE Loss → Optimized Weights

**Critical Path:**
GNN Feature Extractor → Performance Predictors (Latency, Energy, Memory) → Hybrid Loss Function → Model Updates

**Design Tradeoffs:**
- GNN-based approach vs. traditional feature engineering: sacrifices some interpretability for generalization capability
- Direct graph processing vs. predefined feature extraction: requires more complex model but handles arbitrary architectures
- Three-target prediction vs. separate models: reduces overhead but requires careful loss balancing

**Failure Signatures:**
- High MAPE on specific search spaces indicates insufficient coverage or model capacity
- Poor accelerator predictions suggest architectural features not captured by GNN layers
- Training instability may indicate suboptimal hybrid loss function weighting

## Open Questions the Paper Calls Out
### Open Question 1
- Question: Can PerfSAGE be effectively trained using self-supervised learning to reduce the need for large benchmark datasets?
- Basis in paper: Authors suggest future work could involve applying self-supervised training to reduce the number of models requiring benchmarking
- Why unresolved: Self-supervised learning techniques for performance prediction have not been explored in the context of DNN inference on edge devices
- What evidence would resolve it: Demonstrating PerfSAGE's performance using self-supervised training on a smaller dataset compared to the current supervised approach

### Open Question 2
- Question: How does PerfSAGE's prediction accuracy change with different batch sizes during edge inference?
- Basis in paper: Authors note they only predict for batch size one inference and suggest investigating how to incorporate batch size as additional information
- Why unresolved: The current model is not designed to handle varying batch sizes, which are common in real-world edge deployments
- What evidence would resolve it: Evaluating PerfSAGE's accuracy across a range of batch sizes and comparing it to ground truth measurements

### Open Question 3
- Question: Can uncertainty quantification be integrated into PerfSAGE to provide confidence scores for predictions?
- Basis in paper: Authors propose exploring Bayesian Deep Learning methods to associate an uncertainty score with each prediction to avoid pitfalls of erroneous predictions
- Why unresolved: The current model provides point estimates without any measure of confidence, which could be problematic for critical applications
- What evidence would resolve it: Implementing uncertainty quantification in PerfSAGE and validating its effectiveness in distinguishing between accurate and inaccurate predictions

## Limitations
- Heavy dependency on the EdgeDLPerf dataset, limiting generalizability to other model architectures or hardware platforms
- Incomplete implementation details for critical components (GNN layers, categorical encoding, hybrid loss function)
- Lack of comprehensive hardware benchmarking methodology descriptions and potential platform-specific variations

## Confidence
- **High Confidence**: The overall concept of using GNNs for arbitrary DNN performance prediction and reported state-of-the-art accuracy on the EdgeDLPerf dataset
- **Medium Confidence**: Ability to generalize to unseen DNN models and hardware platforms beyond those in the EdgeDLPerf dataset
- **Low Confidence**: Exact reproducibility of results due to incomplete implementation details and hardware-specific benchmarking information
