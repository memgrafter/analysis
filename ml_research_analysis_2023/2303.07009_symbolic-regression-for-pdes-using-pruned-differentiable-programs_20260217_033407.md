# Symbolic Regression for PDEs using Pruned Differentiable Programs

## Quick Facts
- arXiv ID: 2303.07009
- Source URL: https://arxiv.org/abs/2303.07009
- Reference count: 40
- Primary result: End-to-end framework for interpretable PDE solutions using pruned differentiable programs

## Executive Summary
This paper presents a novel approach to symbolic regression for partial differential equations by combining Physics-Informed Neural Networks (PINNs) with Differentiable Program Architectures (DPAs). The method generates datasets from trained PINNs and performs symbolic regression using a grammar-based DPA, followed by depth-first pruning using weight magnitudes as a heuristic. The framework achieves significant parameter reduction (95.3% on average) while maintaining or improving accuracy compared to PINNs, and demonstrates superior performance over state-of-the-art symbolic regression solvers on complex PDEs including Navier-Stokes and industrial applications.

## Method Summary
The framework operates through a two-stage process: first, a PINN is trained to solve a given PDE and generate solution data; second, symbolic regression is performed on this dataset using a DPA defined by a context-free grammar. The DPA represents mathematical expressions as differentiable programs that can be optimized using gradient-based methods. A depth-first pruning strategy then removes parameters with low magnitudes, reducing model complexity while preserving accuracy. The approach leverages the differentiable nature of the program architecture to enable efficient gradient-based optimization, bridging the gap between black-box neural networks and interpretable mathematical expressions.

## Key Results
- Pruning reduces DPA parameters by 95.3% on average while maintaining PINN-level accuracy
- DPA accuracy improves by 7.81% on average after pruning
- Outperforms state-of-the-art symbolic regression solvers on Navier-Stokes and industrial Air-Preheater problems
- Generates concise analytical expressions without performance loss versus PINNs

## Why This Works (Mechanism)
The method succeeds by leveraging the strengths of both PINNs and differentiable program architectures. PINNs provide accurate solutions to complex PDEs, generating high-quality training data for symbolic regression. The DPA's differentiable nature allows gradient-based optimization through a grammar-defined search space, making symbolic regression computationally tractable. Weight-magnitude-based pruning effectively identifies and removes redundant parameters while preserving the essential mathematical structure, resulting in more interpretable expressions without sacrificing accuracy.

## Architecture Onboarding

### Component Map
PINN -> Dataset Generation -> DPA (Grammar-based) -> Weight-based Pruning -> Interpretable Expression

### Critical Path
The critical path involves PINN training, dataset generation, DPA optimization, and pruning. Each stage depends on the previous one's output, with pruning being the final refinement step that directly produces the interpretable result.

### Design Tradeoffs
The framework trades off direct equation-based symbolic regression for a two-stage approach using PINN-generated data. This enables handling more complex PDEs but introduces dependency on PINN quality and may limit exploration of the full solution space. The weight-based pruning heuristic is computationally efficient but may not always identify the most interpretable expressions.

### Failure Signatures
- Poor PINN training leading to low-quality datasets
- Grammar mismatch causing inability to represent target solutions
- Over-aggressive pruning removing essential mathematical components
- Gradient vanishing in deep DPA structures
