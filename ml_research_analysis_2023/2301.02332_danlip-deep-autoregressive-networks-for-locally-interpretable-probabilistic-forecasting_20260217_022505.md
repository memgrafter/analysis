# DANLIP: Deep Autoregressive Networks for Locally Interpretable Probabilistic Forecasting

## Quick Facts
- arXiv ID: 2301.02332
- Source URL: https://arxiv.org/abs/2301.02332
- Reference count: 26
- Key outcome: Model achieves comparable performance to DeepAR while providing interpretable predictions through linear combination of input features

## Executive Summary
DANLIP is a deep learning model for probabilistic time series forecasting that balances high performance with interpretability. The model uses a restricted architecture that outputs predictions as a linear combination of input features, enabling both local and global interpretability. Experiments on three real-world datasets demonstrate that DANLIP achieves performance comparable to state-of-the-art methods while allowing meaningful interpretation of predictions through feature contribution analysis.

## Method Summary
DANLIP is a deep autoregressive model that predicts parameters of a Gaussian distribution for time series forecasting. The model incorporates both continuous and categorical features through embedding layers and RNN-based encoder-decoder architecture with attention mechanisms. Key innovation is the restriction of output to a linear combination of input features weighted by learned functions, enabling interpretable predictions. The model is trained using log-likelihood maximization and provides both point forecasts (mean) and uncertainty estimates (standard deviation).

## Key Results
- Achieved comparable performance to DeepAR on Electricity, Rossmann, and Walmart datasets
- Provided meaningful interpretation of predictions by identifying which features positively or negatively impact forecast mean and variance
- Demonstrated ability to analyze feature contributions both for individual samples and across entire datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The model achieves interpretability by restricting its output to a linear combination of input features weighted by functions of the input.
- Mechanism: The DANLIP architecture ensures that predictions can be expressed as a weighted sum of input features, where the weights are themselves functions of the input. This is similar to how linear regression works but with learned functions replacing fixed coefficients. By doing this, the model allows for both local and global interpretability because each feature's contribution to the prediction can be calculated.
- Core assumption: The neural network layers can learn appropriate functions to weight the input features while maintaining the linear combination structure.
- Evidence anchors:
  - [abstract] "The model uses a restricted architecture that outputs predictions as a linear combination of input features, enabling local interpretability."
  - [section 2.2] "Following the self-explaining neural network model proposed by Melis and Jaakkola [15], which is analogous to the RETAIN architecture of Choi et al. [3], we ensure the interpretability of our forecasting method by restricting the form of the output of the neural network as y = ∑f∈F γΘ(x)f xf."
- Break condition: If the learned functions γΘ(x) become too complex or the neural network layers fail to learn them effectively, the interpretability benefit may be lost.

### Mechanism 2
- Claim: The model provides both point and probabilistic forecasts by predicting the parameters of a Gaussian distribution.
- Mechanism: DANLIP is designed to predict both the mean (µ) and standard deviation (σ) of a Gaussian distribution. These parameters define the entire probability distribution for each time step, allowing the model to provide both a point forecast (the mean) and a measure of uncertainty (the standard deviation). The model achieves this by using separate dense layers to predict µ and σ from the concatenated context vector and decoder input.
- Core assumption: The underlying data generating process can be well approximated by a Gaussian distribution.
- Evidence anchors:
  - [section 3.1] "Firstly, let M be number of continuous features, and N be number of categorical features... We restrict the stochastic processes to be Gaussian, as it is a probability distribution which directly use the mean and standard deviation as its input."
  - [section 3.1] "Using the sequence of vectors (cj)j∈{t−h,...,t−1}, we can finally perform mean and standard deviation prediction in the decoding layer by using the following formula: µj = W⊤µ,j · [c|dj] and σj = Softplus(W⊤σ,j · [c|dj])"
- Break condition: If the true data distribution is significantly non-Gaussian, the model's probabilistic forecasts may be inaccurate.

### Mechanism 3
- Claim: The model can handle both continuous and categorical features through embedding and attention mechanisms.
- Mechanism: DANLIP incorporates continuous features directly into the model while using embedding layers to convert categorical features into dense vectors. These embedded features are then processed by RNN layers with attention mechanisms to create context vectors that capture relevant information from the input sequence. This allows the model to effectively use both types of features for forecasting.
- Core assumption: The embedding size chosen for categorical features is sufficient to capture their relevant information.
- Evidence anchors:
  - [section 3.1] "For each time step j∈{t−h,t−1}, eCat f = Embedding(xCat jf) ∀f∈FCat... We let FCat be set of categorical feature indices of the vector shown in Equation (14). Analogously, we define FCont for continuous features."
  - [section 3.1] "Then we can subsequently define the encoding layer as follows: gt−h,...,gt−1 = RNNα(vt−h,...,v t−1)... qj = w⊤α gj + bα ∀j∈{t−h,...,t−1}... αt−h,...,αt−1 = Softmax(qt−h,...,q t−1)"
- Break condition: If the embedding size is too small, important information from categorical features may be lost. If it's too large, the model may overfit.

## Foundational Learning

- Concept: Autoregressive forecasting
  - Why needed here: The model generates future predictions by using previous predictions as inputs, which is essential for multi-step forecasting.
  - Quick check question: How does the model handle the lack of true future values during the prediction phase?

  - Why needed here: Attention allows the model to focus on relevant parts of the input sequence when making predictions, improving both performance and interpretability.

  - Why needed here: Categorical variables need to be converted into a format that can be processed by neural networks, and embeddings provide a way to do this while preserving semantic information.

## Architecture Onboarding

- Component map: Input → Preprocessing → Encoder (with attention) → Decoder (with attention) → Dense layers → Output
- Critical path: Input → Preprocessing → Encoder (with attention) → Decoder (with attention) → Dense layers → Output
- Design tradeoffs:
  - Model complexity vs interpretability: Restricting the output to a linear combination of features enables interpretability but may limit model expressiveness
  - Embedding size for categorical features: Larger embeddings can capture more information but increase model complexity and risk of overfitting
  - Number of RNN layers: More layers can improve performance but increase training time and risk of overfitting
- Failure signatures:
  - Poor forecasting performance: May indicate issues with model architecture, hyperparameters, or data preprocessing
  - Inconsistent feature contributions: Could suggest problems with the attention mechanism or embedding layers
  - Overfitting: High performance on training data but poor performance on validation/test data
- First 3 experiments:
  1. Train the model on a simple dataset (e.g., electricity consumption) with only continuous features to verify basic functionality
  2. Add categorical features (e.g., hour of day, day of week) and verify that the model can handle them through embeddings
  3. Evaluate the model's interpretability by analyzing feature contributions on a dataset with known feature importance (e.g., Rossmann)
