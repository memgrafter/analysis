# Transformed Distribution Matching for Missing Value Imputation

## Quick Facts
- arXiv ID: 2302.10363
- Source URL: https://arxiv.org/abs/2302.10363
- Reference count: 40
- This paper proposes Transformed Distribution Matching (TDM) for missing value imputation using deep invertible functions and optimal transport

## Executive Summary
This paper introduces Transformed Distribution Matching (TDM), a novel approach for missing value imputation that leverages the distributional consistency of data batches. The method transforms data through deep invertible functions and uses optimal transport to match distributions in latent space. TDM aims to simultaneously learn these transformations and impute missing values through a simple, well-motivated algorithm. The authors demonstrate that their method achieves state-of-the-art performance across extensive experiments while requiring fewer hyperparameters than competing approaches.

## Method Summary
TDM operates on the principle that any two batches of data with missing values originate from the same underlying distribution. The method transforms observed values into a latent space using deep invertible functions, then matches the distributions of observed and missing portions using optimal transport. This transformation and matching process occurs simultaneously, allowing the model to learn appropriate imputations that respect the original data distribution. The approach is designed to be robust to various missingness patterns and requires minimal hyperparameter tuning.

## Key Results
- Achieves state-of-the-art performance across extensive experiments on multiple datasets
- Generates high-quality imputations regardless of how missing values are generated
- Demonstrates robustness across different missingness patterns
- Requires fewer hyperparameters to fine-tune compared to competing methods

## Why This Works (Mechanism)
The method works by exploiting the fundamental assumption that data batches with missing values share the same underlying distribution. By transforming data through invertible functions into a latent space where distribution matching becomes tractable, TDM can effectively learn the relationship between observed and missing values. The optimal transport framework provides a principled way to align distributions in this transformed space, ensuring that imputed values are consistent with the observed data distribution.

## Foundational Learning
**Deep Invertible Functions**
- *Why needed*: To transform data into a space where distribution matching is tractable while preserving information for exact reconstruction
- *Quick check*: Verify that the Jacobian determinant can be computed efficiently for the chosen invertible architecture

**Optimal Transport**
- *Why needed*: To provide a principled framework for distribution matching in the latent space
- *Quick check*: Confirm that the transport cost matrix can be computed efficiently for the dataset size

**Distributional Consistency**
- *Why needed*: The core assumption that enables matching between observed and missing data
- *Quick check*: Verify that empirical distributions of observed values are similar across batches

## Architecture Onboarding

**Component Map**
Data -> Invertible Transformation -> Latent Space -> Optimal Transport Matching -> Imputed Values

**Critical Path**
The critical path flows from observed data through the invertible transformation to the latent space, where optimal transport aligns distributions, producing final imputations.

**Design Tradeoffs**
The method trades computational complexity for theoretical soundness, using optimal transport which is more computationally expensive than simpler matching methods but provides stronger distributional guarantees.

**Failure Signatures**
- Poor imputations when the distributional consistency assumption is violated
- Computational bottlenecks with high-dimensional data or large batch sizes
- Suboptimal performance when the invertible transformation cannot adequately capture the data structure
