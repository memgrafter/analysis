# Approximating DTW with a convolutional neural network on EEG data

## Quick Facts
- arXiv ID: 2301.12873
- Source URL: https://arxiv.org/abs/2301.12873
- Reference count: 25
- Key outcome: CNN-based DTW approximation achieves higher computational efficiency than FastDTW/SoftDTW while maintaining comparable accuracy in EEG sleep staging tasks.

## Executive Summary
This paper introduces a convolutional neural network approach to approximate Dynamic Time Warping (DTW) for time series analysis, specifically targeting EEG data. The authors propose two architectures: a siamese encoder-decoder model and a direct regression model, both trained to mimic DTW similarity by minimizing reconstruction loss and approximating DTW values using Euclidean distance in embedded space. The method demonstrates significant computational efficiency gains compared to traditional DTW approximations while maintaining accuracy in time series classification tasks like sleep staging. The approach also shows promising generalization across different EEG datasets.

## Method Summary
The paper presents two CNN-based architectures to approximate DTW similarity for EEG time series. The siamese encoder-decoder model uses shared convolutional encoders to map time series into a common embedding space, where DTW similarity is approximated via Euclidean distance. An additional decoder reconstructs the original time series to preserve temporal information. The direct regression model bypasses the embedding space entirely, learning to predict DTW values directly. Both architectures are trained using a combination of reconstruction loss and DTW approximation loss, with a hyperparameter λ balancing these objectives. The models are evaluated on sleep staging tasks using the SleepEDF and SHHS datasets.

## Key Results
- The CNN-based approach achieves significantly higher computational efficiency than FastDTW and SoftDTW for DTW approximation.
- The method maintains comparable accuracy to traditional DTW in sleep staging classification tasks on EEG data.
- The approach generalizes well across different EEG datasets, demonstrating potential for broader applications.

## Why This Works (Mechanism)
The proposed CNN architectures work by learning to map time series into a space where Euclidean distance approximates DTW similarity. The siamese encoder-decoder model achieves this through shared convolutional encoders that compress time series into embeddings, with the Euclidean distance between embeddings serving as the DTW approximation. The decoder ensures the embeddings retain sufficient temporal information by reconstructing the original time series. The direct regression model bypasses the embedding step, learning to predict DTW values directly from the input time series. Both approaches leverage the representational power of CNNs to capture temporal patterns efficiently.

## Architecture Onboarding

**Component Map:**
Raw EEG Signal -> Convolutional Encoder -> Embedding Space -> (Euclidean Distance for DTW Approximation) OR (Direct Regression Output)

**Critical Path:**
For siamese model: Input → Shared Encoder → Embedding → Euclidean Distance → DTW Approximation
For direct model: Input → CNN Layers → Output Layer → DTW Value Prediction

**Design Tradeoffs:**
- Siamese encoder-decoder provides interpretability through embeddings but adds reconstruction complexity
- Direct regression is simpler but loses the geometric interpretation of similarity in embedding space
- Reconstruction loss ensures temporal information preservation but increases computational overhead

**Failure Signatures:**
- Poor reconstruction indicates loss of temporal information
- Large gaps between predicted and true DTW values suggest inadequate learning of temporal alignment
- Overfitting to training data manifests as poor generalization to new subjects or datasets
