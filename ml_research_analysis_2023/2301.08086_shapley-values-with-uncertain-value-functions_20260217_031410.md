# Shapley Values with Uncertain Value Functions

## Quick Facts
- arXiv ID: 2301.08086
- Source URL: https://arxiv.org/abs/2301.08086
- Reference count: 38
- Primary result: Uncertain Shapley values can be represented as regular Shapley values with shifted deterministic value functions, preserving all theoretical properties.

## Executive Summary
This paper introduces Shapley values with uncertain value functions (VFs) in explainable machine learning, where the value function is treated as a random variable quantifying feature impact on model predictions. The authors prove that uncertain Shapley values correspond to regular Shapley values with shifted deterministic VFs, where the shift is determined by the mean bias of marginal contributions. They demonstrate that this equivalence preserves all properties of regular Shapley values while introducing higher computational costs to achieve desired confidence levels. The work provides a theoretical foundation for handling uncertainty in feature importance estimation.

## Method Summary
The authors define uncertain value functions as random variables and show that uncertain Shapley values can be represented as regular Shapley values with shifted deterministic VFs. They use a synthetic dataset (10,000 points, 12 features) generated with scikit-learn's make_regression method, adding Bernoulli and Gaussian noise to the value function. A linear regression model is trained, and Shapley values are calculated with and without noise using the R² score as the value function. The theoretical framework is validated through moment calculations using binomial expansion, demonstrating how higher moments of uncertain Shapley values can be computed without full probability distribution knowledge.

## Key Results
- Uncertain Shapley values preserve all properties of regular Shapley values through equivalence with shifted deterministic VFs
- The computational cost scales linearly with the desired confidence level (n times more evaluations for n samples per coalition)
- Binomial expansion allows calculation of higher moments without full probability distribution knowledge
- Different noise types (Bernoulli vs Gaussian) produce distinct effects on Shapley value uncertainty

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Uncertain Shapley values can be represented as regular Shapley values with a shifted deterministic value function
- Mechanism: Additive noise in the value function can be absorbed into a constant shift applied to the deterministic part, transforming uncertain SVs into regular SVs without changing theoretical properties
- Core assumption: Noise is additive and independent of coalition structure
- Evidence anchors:
  - [abstract] "We show that random effects can in fact be absorbed into a Shapley value with a noiseless but shifted value function"
  - [section 3.3] Theorem 1 formally proves this equivalence and shows that uncertain SVs preserve all properties of regular SVs
- Break condition: If noise is not additive or depends on coalition structure in a complex way, the equivalence may break down

### Mechanism 2
- Claim: Higher moments of uncertain Shapley values can be calculated using binomial expansion without knowing the full probability distribution
- Mechanism: The uncertain SV is expressed as a sum of random variables, and the nth moment can be decomposed using the binomial theorem into moments of deterministic and noise components
- Core assumption: Noise components are independent across different coalitions
- Evidence anchors:
  - [section 3.4] "Both equalities are direct implications of the binomial theorem"
- Break condition: If noise components are correlated across coalitions, the binomial decomposition would not hold

### Mechanism 3
- Claim: Computational cost of evaluating uncertain Shapley values scales linearly with desired confidence level
- Mechanism: Each coalition evaluation must be repeated n times to achieve a confidence interval of width proportional to 1/√n, requiring n times more evaluations than regular Shapley values
- Core assumption: Independent and identically distributed samples can be drawn for each coalition evaluation
- Evidence anchors:
  - [section 4.1] "For uncertain SVs, we can repeat each evaluation n∈N times, which in total requires n2^N VF evaluations"
- Break condition: If samples are not independent or noise has heavy tails, more samples may be needed for the same confidence

## Limitations

- Theoretical results rely heavily on the assumption that noise in the value function is additive and independent across coalition evaluations, which may not hold in real-world scenarios
- Computational complexity scales as O(n·2^N) where n is the number of samples per coalition, becoming prohibitive for datasets with many features
- Focus on synthetic data with simple noise structures (Bernoulli and Gaussian) limits generalizability to more complex real-world value functions

## Confidence

**High confidence**: The equivalence between uncertain and regular Shapley values with shifted VFs is mathematically rigorous and well-supported by Theorem 1. The preservation of Shapley value properties under uncertainty is clearly demonstrated.

**Medium confidence**: The computational scaling claim appears reasonable but lacks empirical validation. The assumption of independent noise samples may not hold in practice, potentially requiring more than n samples for a given confidence level.

**Low confidence**: The moment calculation approach assumes independence of noise across coalitions without thorough validation. The binomial expansion approach may break down with correlated noise or non-i.i.d. distributions.
