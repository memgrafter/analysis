# The Inadequacy of Shapley Values for Explainability

## Quick Facts
- arXiv ID: 2302.08160
- Source URL: https://arxiv.org/abs/2302.08160
- Authors: 
- Reference count: 40
- Key outcome: Shapley values can yield provably misleading information about feature importance by assigning high importance to irrelevant features while underestimating relevant ones, contradicting explainability goals.

## Executive Summary
This paper presents a formal argument that Shapley values, commonly used for feature attribution in explainable AI, can yield provably misleading information about feature importance. The core issue is that Shapley values can assign high importance to irrelevant features while underestimating the importance of relevant features, contradicting the fundamental goals of explainability. The authors demonstrate this through rigorous mathematical analysis and extensive empirical experiments on Boolean functions and real-world datasets. They show that for a significant fraction of cases, Shapley values fail to distinguish between relevant and irrelevant features, leading to potentially misleading explanations.

## Method Summary
The authors use systematic enumeration of Boolean functions and instances to identify cases where Shapley values violate feature relevancy. They implement polynomial-time algorithms for computing exact Shapley values and deciding feature relevancy based on abductive explanations (AXp). The study covers all Boolean functions of 3-4 variables (65,536 functions, over 1 million instances) and tests 6 public datasets converted to Boolean features and classes. They compare exact Shapley values against SHAP implementations and propose an alternative measure based on abductive explanations.

## Key Results
- Shapley values can assign non-zero importance to features proven irrelevant, violating explainability principles
- Shapley values can rank irrelevant features higher than relevant ones, contradicting explainability goals
- Shapley values can assign zero importance to features that are relevant for predictions
- Alternative measure based on abductive explanations respects feature relevancy but may be computationally intensive

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Shapley values can assign non-zero importance to features proven irrelevant, violating explainability goals.
- **Mechanism:** The Shapley value formula (3) sums contributions from all subsets S, including those where feature i is irrelevant (WAXp false). Even when a feature is provably irrelevant (not in any AXp), φ(S) can still vary across different S, creating non-zero Shapley values.
- **Core assumption:** The definition of φ in (2) uses averaging over feature space subsets, which doesn't respect feature relevancy - it only considers prediction changes, not whether features are essential for explanations.

### Mechanism 2
- **Claim:** Shapley values can rank irrelevant features higher than relevant ones, contradicting explainability principles.
- **Mechanism:** When computing Shapley values, the contribution from different subsets S can create situations where an irrelevant feature i1 accumulates larger absolute values than a relevant feature i2, even though i2 is provably needed for at least one explanation.
- **Core assumption:** The ranking of features by absolute Shapley values doesn't align with feature relevancy determined by AXp enumeration, because Shapley values consider all subsets while AXp only considers minimal sufficient feature sets.

### Mechanism 3
- **Claim:** Shapley values can assign zero importance to features that are relevant for predictions.
- **Mechanism:** For certain classifier functions and instances, the mathematical formula for Shapley values (3) can sum to zero for a feature i that is included in at least one AXp, meaning the feature is provably necessary for some explanations but gets no importance score.
- **Core assumption:** The Shapley value computation doesn't guarantee non-zero values for relevant features because it's based on marginal contributions across all subsets, not on whether the feature appears in any minimal explanation.

## Foundational Learning

- **Concept: Feature relevancy vs. feature importance**
  - Why needed here: The paper distinguishes between features that are provably relevant (appear in at least one AXp) versus features assigned importance by Shapley values. Understanding this distinction is critical to grasp why Shapley values fail.
  - Quick check question: Can a feature be irrelevant (not in any AXp) but still have a non-zero Shapley value? (Yes - that's the core problem)

- **Concept: Boolean function representation and truth tables**
  - Why needed here: The paper uses truth table enumeration to systematically explore all Boolean functions and their instances to find counterexamples. Understanding this systematic approach is key to understanding the rigor of the results.
  - Quick check question: How many possible Boolean functions are there for m variables? (2^(2^m) - this explains why the paper only goes up to 4 variables)

- **Concept: Computational complexity classes (P vs NP)**
  - Why needed here: The paper argues that finding a polynomial-time algorithm for computing "correct" Shapley values that respect feature relevancy would imply P=NP, since deciding feature relevancy is NP-complete for d-DNNFs.
  - Quick check question: What complexity class contains the problem of deciding whether a feature is relevant for a d-DNNF classifier? (NP-complete)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can Shapley values be modified to accurately reflect feature relevancy while maintaining computational efficiency?
- Basis in paper: [explicit] The authors argue that variants of Shapley values respecting feature relevancy are unlikely to be computed in polynomial time for d-DNNFs unless P=NP, but do not explore all possible modifications.
- Why unresolved: The paper presents a negative result about the complexity of modifying Shapley values but does not explore the full space of potential modifications or hybrid approaches.
- What evidence would resolve it: A proof demonstrating that all possible variants of Shapley values respecting feature relevancy are computationally intractable, or a concrete example of a modified Shapley value measure that both respects relevancy and can be computed efficiently for a significant class of models.

### Open Question 2
- Question: How does the performance of Shapley values in explainability compare to other feature attribution methods that do not rely on game theory?
- Basis in paper: [inferred] The paper focuses on the inadequacy of Shapley values but does not provide a comprehensive comparison with other feature attribution methods like LIME or counterfactual explanations.
- Why unresolved: The authors primarily compare Shapley values to exact Shapley values and SHAP, but do not systematically evaluate their performance against other established explainability methods.
- What evidence would resolve it: A large-scale empirical study comparing Shapley values to other feature attribution methods across diverse datasets and model types, measuring their ability to correctly identify relevant features and rank feature importance.

### Open Question 3
- Question: Are there specific types of classifiers or data distributions for which Shapley values perform better at capturing feature relevancy?
- Basis in paper: [inferred] The paper demonstrates issues with Shapley values across various Boolean functions and d-DNNF classifiers, but does not systematically explore if certain model classes or data distributions mitigate these issues.
- Why unresolved: The experiments focus on Boolean functions and d-DNNF classifiers derived from specific datasets, but do not exhaustively explore the performance of Shapley values across different types of classifiers or data distributions.
- What evidence would resolve it: A comprehensive study evaluating Shapley values across a wide range of classifier types (e.g., neural networks, decision trees, linear models) and data distributions (e.g., Gaussian, imbalanced, high-dimensional), identifying conditions under which Shapley values perform well or poorly in capturing feature relevancy.

## Limitations
- Computational: Exhaustive enumeration only covers up to 4 variables due to exponential growth in function space
- Theoretical: Results rely on worst-case analysis rather than probabilistic guarantees over typical distributions
- Practical: Alternative measure based on abductive explanations may face computational challenges for complex classifiers

## Confidence

**High confidence**: The mathematical proofs for Issues I1, I2, and I3 are rigorously established through systematic enumeration and polynomial-time decision procedures. The claim that Shapley values can violate feature relevancy is formally proven.

**Medium confidence**: The empirical results on d-DNNF datasets (Table 2) demonstrate that SHAP implementations can reproduce the theoretical issues in practice, though the connection between theoretical Boolean functions and real-world data distributions requires careful interpretation.

**Low confidence**: The proposed alternative measure based on abductive explanations, while theoretically sound, may face practical implementation challenges due to potentially high computational costs for complex classifiers.
