# Stochastic Surprisal: An inferential measurement of Free Energy in Neural Networks

## Quick Facts
- arXiv ID: 2302.05776
- Source URL: https://arxiv.org/abs/2302.05776
- Authors: 
- Reference count: 12
- Primary result: Introduces stochastic surprisal as gradients of hypothetical actions with respect to network parameters, improving IQA correlation metrics and robust recognition accuracy without retraining.

## Executive Summary
This paper proposes stochastic surprisal as a novel method to introduce action during inference in neural networks. By computing gradients of hypothetical actions (such as changing class predictions or reducing reconstruction error) with respect to network parameters, the method quantifies the effect of these actions and provides a way for networks to respond to input-level noise. The approach is evaluated on two applications: image quality assessment and robust object recognition, demonstrating improvements in correlation metrics and classification accuracy without requiring retraining of the base network.

## Method Summary
Stochastic surprisal is computed during inference by backpropagating the gradient of a hypothetical action loss (e.g., MSE between current and target output) with respect to network parameters. This captures the parameter changes required to achieve the hypothetical action, representing the network's sensitivity to that action. The method aggregates gradients across all possible actions to form a feature vector encoding the input's impact on the network. It applies to both generative networks (measuring reconstruction error gradients) and discriminative networks (measuring class prediction gradients), and can be plugged into existing methods without retraining.

## Key Results
- Improved IQA performance: PLCC increased from 0.872 to 0.908 when plugged into an existing IQA method
- Enhanced robust recognition: Classification accuracy on corrupted CIFAR-10 images improved by up to 8% across ResNet architectures
- Demonstrated plug-in capability: Works as an enhancement to existing networks without requiring retraining
- Framework versatility: Applies to both generative (reconstruction error) and discriminative (class prediction) networks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Stochastic surprisal introduces active inference by computing gradients of hypothetical actions with respect to parameters, enabling response to noise without retraining
- Mechanism: During inference, gradients of action loss (e.g., MSE between current and target output) are backpropagated to parameters, representing required parameter changes to achieve hypothetical action
- Core assumption: All possible actions are equally likely, justifying use of their gradients as stochastic measurement of surprisal
- Evidence anchors: Abstract states gradients are computed for actions like changing class prediction or reducing reconstruction error; section defines stochastic surprisal as measuring parameter changes for any given action
- Break condition: Large parameter spaces make gradient computation computationally infeasible, or action set is not representative of network's decision space

### Mechanism 2
- Claim: Stochastic surprisal improves robustness by characterizing noise and distortion in inputs, distinguishing signal from noise
- Mechanism: Gradient of distortion-specific loss w.r.t. parameters captures network's sensitivity to perturbations; in IQA, enables comparison between reference and distorted images in gradient space
- Core assumption: Gradient of distortion-specific loss w.r.t. parameters captures essential characteristics of that distortion
- Evidence anchors: Abstract reports 8% accuracy improvement on corrupted CIFAR-10; section defines stochastic surprisal as measuring parameter changes for any given action
- Break condition: Loss function for action does not correlate with perceptual or task-relevant differences, so gradients won't capture useful noise characteristics

### Mechanism 3
- Claim: Stochastic surprisal provides unified framework for generative and discriminative networks by framing action as output space change
- Mechanism: For generative networks, action is minimizing reconstruction error with gradients w.r.t. decoder parameters; for discriminative networks, action is changing predicted class with gradients w.r.t. final layer weights for each class
- Core assumption: Change in output space can be meaningfully mapped to changes in parameter space via gradients
- Evidence anchors: Abstract states gradients are computed for actions like changing class prediction or reducing reconstruction error; section uses fidelity-based MSE loss for both network types
- Break condition: Mapping between output space changes and parameter space changes is not smooth or differentiable, so gradient computation fails

## Architecture Onboarding

- Component map: Perception network (pre-trained) → Action loss function → Gradient computation → Stochastic surprisal features → Downstream task (IQA or classification)
- Critical path: Input → Perception network → Action loss → Gradient computation → Feature extraction → Task-specific processing → Output
- Design tradeoffs: Computational cost of gradient computation vs. performance gain; choice of action loss function (MSE, cross-entropy, etc.); whether to use all possible actions or a subset
- Failure signatures: Low correlation between stochastic surprisal features and task performance; gradients exploding or vanishing; poor generalization to unseen distortions
- First 3 experiments:
  1. Implement stochastic surprisal on a simple autoencoder for MNIST denoising and compare performance to baseline
  2. Apply stochastic surprisal to a pre-trained ResNet on CIFAR-10C and measure robustness improvement
  3. Use stochastic surprisal as a plug-in on an existing IQA method (e.g., UNIQUE) and evaluate on MULTI-LIVE

## Open Questions the Paper Calls Out

- Question: How can the computational complexity of computing stochastic surprisal be reduced for networks with a large number of classes?
  - Basis in paper: Authors mention stochastic surprisal feature scales linearly with number of classes, making it prohibitive for large datasets, and suggest selecting only a subset of most likely actions as potential solution
  - Why unresolved: Paper does not explore or validate any specific method to address this scalability issue
  - What evidence would resolve it: Empirical results comparing different strategies (e.g., selecting top-k actions, clustering actions) to reduce computational cost while maintaining performance on large-scale datasets

## Limitations

- Computational scalability: Gradient computation for all possible actions becomes prohibitive for networks with large action spaces or parameter counts
- Theoretical justification gap: The assumption that all actions are equally likely for computing surprisal lacks rigorous proof
- Limited generalizability validation: While claims of universal applicability exist, the method has only been validated on specific network architectures and tasks

## Confidence

- High confidence: Performance improvements on CIFAR-10C (8% accuracy gain) and IQA metrics (PLCC improvement from 0.872 to 0.908) are well-documented and reproducible
- Medium confidence: Theoretical framework connecting FEP to stochastic surprisal is plausible but lacks rigorous proof of claimed equivalence between parameter gradients and active inference
- Low confidence: Claim that stochastic surprisal generalizes to any supervised network without architectural constraints requires broader validation across diverse network architectures

## Next Checks

1. **Ablation study on action set size**: Systematically vary the number of actions used in stochastic surprisal computation (e.g., top-k classes only) to determine the minimal effective set and test the "all actions equally likely" assumption
2. **Cross-dataset generalization**: Apply the method to ImageNet-level classification and complex IQA datasets (e.g., KonIQ-10k) to verify scalability and robustness to dataset complexity
3. **Comparison with gradient-based explainability methods**: Benchmark stochastic surprisal against established gradient-based feature importance methods (e.g., saliency maps, Integrated Gradients) to isolate whether improvements come from the active inference framework or simply from using gradients as features
