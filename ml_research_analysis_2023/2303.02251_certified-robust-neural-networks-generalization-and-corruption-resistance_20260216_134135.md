# Certified Robust Neural Networks: Generalization and Corruption Resistance

## Quick Facts
- arXiv ID: 2303.02251
- Source URL: https://arxiv.org/abs/2303.02251
- Reference count: 40
- Primary result: HR training achieves certified robustness against evasion, poisoning, and generalization error using distributionally robust optimization

## Executive Summary
This paper introduces a novel holistic robust (HR) training method that provides certified robustness against multiple types of data corruption and statistical error. The HR loss is constructed as an upper bound on test loss with high probability, combining adversarial reweighting, poisoning protection via optimal transport, and KL-based generalization control. Experiments demonstrate that HR training significantly outperforms state-of-the-art methods on MNIST and CIFAR-10, particularly when multiple sources of corruption are present simultaneously.

## Method Summary
HR training is a distributionally robust optimization approach that constructs an ambiguity set containing both the adversarial test distribution and clean data generating distribution. The method solves a convex optimization problem over weights to reweight adversarial examples, using Danskin's theorem for efficient gradient computation. The HR loss combines three components: an optimal transport metric for poisoning protection, KL divergence for generalization guarantees, and adversarial reweighting. The training procedure generates adversarial examples using PGD, solves the weight optimization at each minibatch, and updates model parameters with gradient descent.

## Key Results
- HR loss provides certified upper bound on test loss with high probability
- Achieves state-of-the-art adversarial test error on CIFAR-10
- Significantly outperforms standard adversarial training when multiple corruption types are present
- Adds only ~5% computational overhead compared to standard adversarial training

## Why This Works (Mechanism)

### Mechanism 1
The HR loss bounds test loss with high probability by combining adversarial reweighting, poisoning protection, and KL-based generalization control. HR constructs an ambiguity set containing both adversarial test distribution and clean data generating distribution, then minimizes worst-case expected loss over this set. The bound holds when data is IID, less than α fraction is poisoned, and evasion attacks are bounded.

### Mechanism 2
KL divergence component protects against statistical error by creating a confidence region around empirical distribution. The KL ball contains true data generating distribution with high probability, providing generalization guarantees without dependence on parameter space dimension. This requires compact support and bounded loss functions.

### Mechanism 3
Optimal transport component protects against poisoning by measuring distributional distance under bounded perturbations. L¹ distance captures effect of label flipping or other poisoning attacks by measuring how far empirical distribution can be pushed under bounded corruption. Works when poisoning affects small fraction α of samples.

## Architecture Onboarding

- **Component map**: PGD adversarial generation -> weight optimization -> gradient computation -> parameter update
- **Critical path**: At each minibatch: generate adversarial examples → solve weight optimization → compute gradient → update parameters. Bottleneck is typically adversarial example generation step.
- **Design tradeoffs**: HR training trades increased per-iteration computation (solving weight optimization) for better generalization and robustness. Weight optimization adds ~5% overhead vs standard AT.
- **Failure signatures**: (1) Training loss increases while test loss decreases (overfitting to reweighting), (2) HR loss becomes loose upper bound on test loss, (3) Sensitivity to hyperparameter choices (α, r, ϵ)
- **First 3 experiments**:
  1. Replicate MNIST experiments with varying r values to observe statistical error robustness
  2. Implement poisoning experiment with label flipping on CIFAR-10 to test α parameter effectiveness
  3. Compare HR training vs standard AT on pre-activation ResNet18 with ℓ∞ attacks to verify robust overfitting mitigation

## Open Questions the Paper Calls Out

- **Open Question 1**: How does HR loss behave when both evasion and poisoning corruption are present simultaneously with varying levels of statistical error?
- **Open Question 2**: Can HR training algorithm be extended to handle other types of corruption beyond evasion and poisoning, such as data drift or concept drift?
- **Open Question 3**: How does performance of HR training compare to other state-of-the-art methods when dealing with highly imbalanced datasets or rare classes?

## Limitations

- KL-based generalization component requires strong assumptions about data compactness and bounded losses
- Confidence set construction may be overly conservative for high-dimensional data
- Computational overhead of solving weight optimization problem at each iteration could become prohibitive for very large models

## Confidence

- **High Confidence**: HR loss as upper bound on test loss under stated assumptions
- **Medium Confidence**: Outperformance on CIFAR-10 relative to state-of-the-art methods
- **Medium Confidence**: HR training mitigates robust overfitting
