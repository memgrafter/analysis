# Solution for the EPO CodeFest on Green Plastics: Hierarchical multi-label classification of patents relating to green plastics using deep learning

## Quick Facts
- arXiv ID: 2302.13784
- Source URL: https://arxiv.org/abs/2302.13784
- Reference count: 27
- Primary result: Two BERT-based models achieve hierarchical F1 scores of 0.2584 (SBNN) and 0.3197 (SBHNN) for green plastics patent classification

## Executive Summary
This paper addresses the challenge of classifying patents related to green plastics using a hierarchical multi-label classification approach. The authors develop a novel classification scheme for green plastics technologies and create an automatic labeling system using keyword matching to generate training data. Two deep learning models are introduced - SBNN (SciBERT with conventional neural network) and SBHNN (SciBERT with hierarchical neural network) - both using patent titles and abstracts as input. The SBHNN model outperforms SBNN, particularly for lower levels of the classification hierarchy, demonstrating the value of exploiting hierarchical structure in the classification task.

## Method Summary
The approach uses SciBERT as a feature extractor to convert patent titles and abstracts into 768-dimensional vectors, which are then classified using either a conventional or hierarchical neural network. Labels are automatically assigned through keyword matching using regular expressions derived from manually defined keywords for each class. The models are trained with binary cross-entropy loss incorporating class importance weights and positive sample weights. The classification scheme consists of 9 classes organized hierarchically, where each patent can belong to multiple classes simultaneously.

## Key Results
- SBHNN achieves hierarchical F1 score of 0.3197, outperforming SBNN's 0.2584 on the full classification hierarchy
- Both models perform better on higher-level classes, with performance degrading for lower hierarchy levels
- The models demonstrate the feasibility of using deep learning for patent classification in emerging technology domains without existing classification schemes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hierarchical labels improve model learning by providing more positive training samples at each level
- Mechanism: By assigning all ancestor classes to a patent, the model receives additional supervision signals beyond the leaf class, helping it learn the hierarchical structure
- Core assumption: The model can leverage hierarchical relationships to improve classification accuracy
- Evidence anchors: [section]: "In order to provide more informative labels to the model for training, we propose to use hierarchical labels, meaning that for a patent belonging to a certain class, we also assign all the ancestor classes of said class"

### Mechanism 2
- Claim: BERT-based feature extraction captures high-level semantic information from patent text
- Mechanism: The SciBERT model transforms patent titles and abstracts into dense 768-dimensional feature vectors that encode semantic meaning, which are then used by the neural network classifier
- Core assumption: Patent text contains sufficient semantic information in titles and abstracts to distinguish between green plastics classes
- Evidence anchors: [abstract]: "Both models use a BERT model as a feature extractor and on top of it, a neural network as a classifier"

### Mechanism 3
- Claim: Weak supervision through keyword matching enables training on emerging technology without existing labels
- Mechanism: Regular expression matching of domain-specific keywords automatically assigns labels to patents, creating a labeled dataset for supervised learning
- Core assumption: The manually defined keywords accurately capture the semantic boundaries of each class
- Evidence anchors: [abstract]: "To achieve this, we come up with a strategy to automatically assign labels to patents in order to create a labeled training dataset that can be used to learn a classification model in a supervised learning setting"

## Architecture Onboarding

- Component map: Patent text → SciBERT → Feature vector → Neural network → Class probabilities
- Critical path: Patent title and abstract (concatenated) → SciBERT feature extraction (768-dimensional vector) → Neural network classifier → Probability scores for each class
- Design tradeoffs:
  - Using only title and abstract vs. full description (simplicity vs. information content)
  - SciBERT vs. other feature extractors (domain-specific vs. general)
  - Hierarchical neural network vs. conventional neural network (structure exploitation vs. simplicity)
  - Keyword-based labeling vs. manual annotation (scalability vs. accuracy)
- Failure signatures:
  - Poor performance on lower hierarchy levels suggests insufficient training data or model capacity
  - Class imbalance causing bias toward frequent classes
  - Weak keyword definitions leading to noisy labels
  - Overfitting on small classes due to limited samples

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would incorporating the full patent description, rather than just title and abstract, affect classification performance for deeper hierarchy levels?
- Basis in paper: [inferred] The paper notes that description content could help with classifying deeper levels and mentions approaches for handling long documents with transformers
- Why unresolved: The authors only used title and abstract due to description length challenges, leaving the performance impact of full descriptions unknown
- What evidence would resolve it: Comparative experiments showing classification metrics with and without full description content for deep hierarchy levels

### Open Question 2
- Question: Would periodic retraining with newly manually labeled patents significantly improve model performance over time?
- Basis in paper: [explicit] The authors suggest periodically updating the model with newly labeled data and giving higher importance to manually labeled patents
- Why unresolved: The paper doesn't test this approach or quantify the performance improvement from such updates
- What evidence would resolve it: Longitudinal study showing classification metrics improvements as more manually labeled patents are incorporated over multiple retraining cycles

### Open Question 3
- Question: How does the performance of language-agnostic BERT models compare to SciBERT for multi-language patent classification?
- Basis in paper: [explicit] The authors suggest exploring language-agnostic BERT models for processing all three languages (English, French, German)
- Why unresolved: The paper only uses monolingual SciBERT and doesn't compare it to language-agnostic alternatives
- What evidence would resolve it: Direct performance comparison between SciBERT and language-agnostic BERT models on a multi-language patent classification task

## Limitations
- Performance degrades significantly for lower hierarchy levels due to class imbalance and limited training data
- Keyword-based automatic labeling may introduce noise in training data, affecting model accuracy
- Only patent titles and abstracts are used as input, potentially missing important information contained in full descriptions

## Confidence
- **High confidence**: The methodology for hierarchical multi-label classification using BERT-based feature extraction is technically sound and well-implemented
- **Medium confidence**: The keyword-based automatic labeling approach is practical but likely introduces some noise that affects model performance
- **Medium confidence**: The architectural improvements of SBHNN over SBNN are demonstrated, though the performance gap (0.3197 vs 0.2584 F1 score) suggests room for improvement
