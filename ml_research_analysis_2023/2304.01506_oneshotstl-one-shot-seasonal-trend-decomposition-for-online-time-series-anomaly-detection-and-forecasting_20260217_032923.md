# OneShotSTL: One-Shot Seasonal-Trend Decomposition For Online Time Series Anomaly Detection And Forecasting

## Quick Facts
- arXiv ID: 2304.01506
- Source URL: https://arxiv.org/abs/2304.01506
- Authors: 
- Reference count: 40
- Primary result: O(1) update complexity per data point, achieving 10-1000x speedup over batch methods

## Executive Summary
OneShotSTL presents a novel online algorithm for time series seasonal-trend decomposition that enables real-time anomaly detection and forecasting on streaming data. The method achieves constant-time O(1) complexity per data point through innovative combination of iterative reweighted least squares and online symmetric Doolittle factorization. Extensive experiments demonstrate the algorithm's effectiveness, achieving competitive accuracy scores while providing dramatic speed improvements over traditional batch processing methods. The approach is particularly valuable for applications requiring real-time analysis of continuously arriving time series data.

## Method Summary
OneShotSTL introduces an incremental decomposition framework that processes time series data points as they arrive, rather than waiting for complete datasets. The algorithm leverages iterative reweighted least squares to handle outliers and noise while maintaining computational efficiency. The core innovation lies in the online symmetric Doolittle factorization, which enables efficient matrix updates without recomputing the entire decomposition. This combination allows the method to maintain accuracy comparable to offline approaches while achieving constant-time updates. The algorithm is specifically designed for seasonal time series with constant period lengths, making it particularly suitable for applications like sensor monitoring, financial analysis, and IoT systems.

## Key Results
- Achieves 0.713 VUS-ROC score for anomaly detection with 160-second runtime
- Delivers 0.337 MAE for forecasting with sub-second processing time per data point
- Provides 10-1000x speedup compared to state-of-the-art batch methods

## Why This Works (Mechanism)
The algorithm's efficiency stems from its ability to update decompositions incrementally rather than recomputing from scratch. By maintaining and updating matrix factorizations online, OneShotSTL avoids the computational overhead of batch processing while preserving the accuracy of traditional seasonal-trend decomposition methods. The iterative reweighted least squares component provides robustness to outliers and noise, ensuring reliable decomposition even in challenging real-world scenarios. The symmetric Doolittle factorization enables efficient rank-one updates to the decomposition matrices as new data arrives.

## Architecture Onboarding
**Component Map:** Data Stream -> Seasonal Extraction -> Trend Estimation -> Residual Analysis -> Anomaly/Forecast Output
**Critical Path:** Real-time data ingestion → Incremental decomposition update → Component extraction → Output generation
**Design Tradeoffs:** Speed vs. accuracy (constant O(1) updates may sacrifice some precision), memory usage vs. historical context (limited window size for online processing)
**Failure Signatures:** Degraded performance on time series with varying seasonal periods, potential accuracy loss with high-frequency noise, sensitivity to initial conditions
**First 3 Experiments:** 1) Benchmark decomposition accuracy on synthetic time series with known components, 2) Stress test with varying noise levels and outlier frequencies, 3) Scalability test with increasing time series lengths (10K → 1M points)
