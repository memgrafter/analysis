# Do Large Language Models Know What They Don't Know?

## Quick Facts
- arXiv ID: 2305.18153
- Source URL: https://arxiv.org/abs/2305.18153
- Reference count: 28
- Key outcome: LLMs possess intrinsic self-knowledge capacity, but even best model (GPT-4) achieves only 75.47% self-knowledge versus human baseline of 84.93%.

## Executive Summary
This paper investigates whether large language models can recognize their own knowledge limitations, a capability referred to as "self-knowledge." The authors introduce the SelfAware dataset containing 1,032 unanswerable questions across five categories and develop an automated methodology using text similarity to detect uncertainty in model responses. Experiments on 20 LLMs show that in-context learning and instruction tuning significantly improve self-knowledge, though even the best-performing model, GPT-4, achieves only 75.47% self-knowledge compared to human performance of 84.93%. The results demonstrate that while LLMs possess some inherent self-knowledge capacity, there remains considerable room for improvement in their ability to recognize unanswerable questions.

## Method Summary
The authors created the SelfAware dataset with 1,032 unanswerable questions paired with 2,337 answerable questions from existing datasets. They developed an automated evaluation methodology using SimCSE-based text similarity to compare model responses to reference sentences expressing uncertainty. A threshold of 0.75 similarity was applied to classify responses as uncertain. The methodology was tested across 20 LLMs including GPT-3, InstructGPT, and LLaMA models using three input forms: Direct, Instruction, and In-Context Learning. Self-knowledge was quantified using F1 score to balance precision and recall in detecting unanswerable questions.

## Key Results
- In-context learning and instruction tuning significantly improve self-knowledge across all model families tested
- GPT-4 achieves highest self-knowledge at 75.47% F1 score, compared to human baseline of 84.93%
- Model parameter size correlates positively with self-knowledge performance
- Instruction-tuned models like Vicuna-13B outperform larger non-instruction-tuned models like LLaMA-65B

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LLMs possess intrinsic capacity for self-knowledge that can be enhanced through in-context learning and instruction tuning
- Mechanism: Model's internal representations encode signals about knowledge boundaries detectable through text similarity to uncertainty expressions
- Core assumption: Model outputs contain semantic indicators of uncertainty correlating with actual knowledge limitations
- Evidence anchors: Abstract states "intrinsic capacity for self-knowledge," section 4.4 shows parameter size elevation associated with F1 score improvement
- Break condition: If outputs don't contain consistent uncertainty markers or text similarity fails to detect them reliably

### Mechanism 2
- Claim: Instruction tuning and in-context learning improve self-knowledge by providing explicit examples of handling uncertainty
- Mechanism: Models learn to generate uncertainty markers more reliably when trained or prompted with instructions to recognize unanswerable questions
- Core assumption: Models can learn from explicit uncertainty recognition examples and generalize this behavior
- Evidence anchors: Section 4.4 shows Vicuna-13B outperforms LLaMA-65B, corroborating instruction tuning efficacy; section 4.4 states instructions and examples boost self-knowledge
- Break condition: If models fail to generalize from provided examples to novel unanswerable questions

### Mechanism 3
- Claim: SelfAware dataset's balanced structure creates effective evaluation framework
- Mechanism: Diverse unanswerable questions across five categories test model's ability to recognize different knowledge gaps
- Core assumption: Performance on balanced dataset reflects general self-knowledge capability
- Evidence anchors: Section 2 explains capping answerable questions for feasibility; section 2.1 describes five distinctive categories
- Break condition: If models perform well on dataset but poorly on real-world unanswerable questions

## Foundational Learning

- Concept: Text similarity metrics and semantic embeddings
  - Why needed here: Evaluation relies on computing similarity between model outputs and reference sentences expressing uncertainty
  - Quick check question: Can you explain how SimCSE works to create sentence embeddings for comparison?

- Concept: F1 score calculation and application to imbalanced datasets
  - Why needed here: Evaluation metric balances precision and recall for detecting unanswerable questions (minority class)
  - Quick check question: How would you calculate precision, recall, and F1 score given true positives, false positives, and false negatives?

- Concept: Chain-of-thought and in-context learning principles
  - Why needed here: These techniques enhance model's self-knowledge through explicit examples and reasoning steps
  - Quick check question: What's the difference between in-context learning and fine-tuning, and when would you use each?

## Architecture Onboarding

- Component map: Dataset preparation pipeline -> Reference sentence generation and filtering -> Text similarity computation module -> Evaluation framework -> Model testing harness
- Critical path: 1) Prepare unanswerable and answerable question sets 2) Generate reference uncertainty sentences 3) Compute similarity scores between model outputs and references 4) Apply threshold to classify uncertainty 5) Calculate F1 score for self-knowledge evaluation
- Design tradeoffs:
  - Reference sentence selection: Manual filtering ensures quality but limits scalability
  - Threshold selection: 0.75 balances precision and recall but may not generalize to all models
  - Dataset balance: 2:1 ratio of answerable to unanswerable questions enables testing but may bias evaluation
- Failure signatures:
  - Low F1 scores across all models suggest reference sentence quality issues
  - High precision but low recall indicates overly strict similarity threshold
  - High recall but low precision suggests insufficient specificity in uncertainty markers
- First 3 experiments:
  1. Test similarity threshold sensitivity by varying from 0.65 to 0.95 and measuring F1 score changes
  2. Compare reference sentence generation from different model families (GPT-3 vs. LLaMA) for cross-model generalization
  3. Evaluate impact of different input forms (Direct vs. Instruction vs. ICL) on subset of models to validate findings at scale

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal threshold for detecting uncertainty in model responses?
- Basis in paper: [explicit] Paper explores different thresholds (0.95, 0.90, 0.85, 0.80, 0.75, 0.70, 0.65) and finds 0.75 produces highest F1 score, but doesn't explore thresholds below 0.65
- Why unresolved: Only tested thresholds down to 0.65, leaving uncertainty about whether lower thresholds might yield better results or if 0.75 is truly optimal
- What evidence would resolve it: Additional experiments testing thresholds below 0.65 (e.g., 0.60, 0.55, 0.50) to determine if performance continues to improve or if 0.75 is indeed optimal point

### Open Question 2
- Question: How do other input forms like Reflexion and Tree of Thoughts compare to three tested input forms?
- Basis in paper: [explicit] Paper mentions these as future directions but only tests Direct, Instruction, and In-Context Learning forms
- Why unresolved: Paper acknowledges these alternative methods but doesn't empirically compare their effectiveness at improving self-knowledge
- What evidence would resolve it: Direct experimental comparison of these newer prompting methods against three tested forms using same evaluation methodology

### Open Question 3
- Question: How does model self-knowledge vary across different types of unanswerable questions?
- Basis in paper: [inferred] Paper categorizes unanswerable questions into five types but doesn't analyze performance variation across these categories
- Why unresolved: While dataset includes diverse question types, paper doesn't report how self-knowledge performance differs for each category
- What evidence would resolve it: Detailed breakdown of F1 scores for each question category to identify which types of unanswerable questions models struggle with most

## Limitations
- Automated text similarity methodology relies heavily on quality of 16 manually curated reference sentences, which may not capture full range of uncertainty expressions
- 0.75 similarity threshold chosen empirically may not generalize optimally across all model families or question types
- Dataset construction methodology hasn't been validated against real-world unanswerable questions users might actually encounter

## Confidence
- High Confidence: In-context learning and instruction tuning improve self-knowledge performance (well-supported by multiple experiments across different model families)
- Medium Confidence: Model parameter size correlates with self-knowledge (supporting evidence but could be confounded by other factors like training data diversity)
- Low Confidence: Automated evaluation methodology's ability to accurately capture true self-knowledge versus learned response patterns needs further validation

## Next Checks
1. Conduct manual annotation study where human evaluators label subset of model responses as uncertain or not, then compare against automated similarity-based classification to measure true accuracy
2. Test methodology on real user queries from actual applications to validate whether performance on constructed dataset translates to practical scenarios
3. Experiment with dynamically generating reference uncertainty sentences using same models being evaluated, rather than relying on fixed set of 16 references, to test cross-model generalization
