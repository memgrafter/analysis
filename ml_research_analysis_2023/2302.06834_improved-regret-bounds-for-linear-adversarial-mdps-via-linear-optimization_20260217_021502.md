# Improved Regret Bounds for Linear Adversarial MDPs via Linear Optimization

## Quick Facts
- arXiv ID: 2302.06834
- Source URL: https://arxiv.org/abs/2302.06834
- Reference count: 40
- Primary result: Achieves $\tilde{O}(K^{4/5})$ regret for linear adversarial MDPs without a simulator

## Executive Summary
This paper addresses the problem of learning in linear adversarial Markov Decision Processes with unknown transitions. The authors develop a novel algorithm called GLAP that reduces the linear MDP problem to linear optimization by constructing a finite policy class and using feature visitation estimators. By carefully balancing exploration and exploitation, the algorithm achieves improved regret bounds of $\tilde{O}(K^{4/5})$ without requiring access to a transition simulator, which represents a significant improvement over previous work. The key insight is transforming the problem into a linear bandit framework where standard techniques can be applied.

## Method Summary
The paper proposes a three-component approach to tackle linear adversarial MDPs. First, it constructs a finite policy class using linear softmax policies with parameter discretization. Second, it implements a feature visitation estimation oracle that collects trajectories through reward-free exploration to estimate transition dynamics. Third, it runs the GLAP algorithm that maintains a probability distribution over policies and updates them using an EXP3-type rule based on optimistic value estimates. The algorithm operates on the constructed policy class and uses G-optimal design to compute exploration probabilities, achieving improved regret bounds through this reduction to linear optimization.

## Key Results
- Achieves $\tilde{O}(K^{4/5})$ regret bound for linear adversarial MDPs without a simulator
- Provides $\tilde{O}(\sqrt{d^2H^5K})$ regret when a simulator is available
- First algorithm to achieve sublinear regret in the linear adversarial MDP setting without simulator access
- Reduction framework from linear MDPs to linear optimization could be of independent interest

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Reducing linear MDPs to linear optimization enables improved regret bounds by operating over a finite policy class with estimated feature visitations
- Mechanism: The algorithm constructs a finite policy class Π and maintains a probability distribution over policies. By using linear optimization techniques (G-optimal design and EXP3-style updates), it balances exploration and exploitation while estimating feature visitations through a reward-free oracle
- Core assumption: The MDP satisfies an exploratory assumption ensuring learnability, and the policy construction provides sufficient approximation of the optimal policy
- Evidence anchors: [abstract] "reduces linear MDP into linear optimization by subtly setting the feature maps of the bandit arms of linear optimization"; [section 4] "operate on a set of policies and optimize the probability distribution of which policy to execute"
- Break condition: If the exploratory assumption fails (λ*min = 0) or the policy class cannot approximate the optimal policy within the required error bound

### Mechanism 2
- Claim: The feature visitation estimation oracle provides accurate enough estimates of policy features to enable regret minimization without a simulator
- Mechanism: The oracle collects trajectories through a reward-free exploration strategy, using least squares estimation to approximate the transition operator. It returns feature visitation estimates with bounded error (ε/√d) that can be used in the main algorithm
- Core assumption: The collected trajectories provide sufficient coverage of the feature space to estimate transition dynamics accurately
- Evidence anchors: [section 4.2] "investigate the least square method to estimate the transition operator"; [lemma 2] "returns a feature visitation estimation that satisfies ||ˆφπ,h - φπ,h||2 ≤ ε/√d"
- Break condition: If the feature space is too high-dimensional relative to the number of collected trajectories, leading to poor estimation

### Mechanism 3
- Claim: The policy construction provides a finite policy class that approximates the optimal policy within a constant error bound
- Mechanism: Using a covering argument over a softmax policy parameterization, the algorithm constructs a finite policy set whose best member approximates the optimal policy's value within O(1) regret
- Core assumption: The Lipschitz property of the value function with respect to policy parameters enables effective approximation through discretization
- Evidence anchors: [section 4.1] "the difference between values of induced policies can be upper bounded by the difference between the parameters w"; [lemma 1] "the regret compared with the optimal policy in Π is close to the global regret"
- Break condition: If the feature dimension d or horizon H is too large, making the policy covering too coarse to achieve good approximation

## Limitations
- Policy class size grows rapidly with feature dimension d and horizon H, potentially making the approach computationally infeasible for large problems
- Performance critically depends on the exploratory assumption being satisfied, which may not hold in all practical scenarios
- The feature estimation oracle requires collecting a large number of trajectories (proportional to d^2H^2) before the main algorithm can begin

- **High confidence**: The regret bound analysis and the reduction framework from linear MDPs to linear optimization
- **Medium confidence**: The feature estimation oracle's accuracy and its dependence on the exploratory assumption
- **Medium confidence**: The policy construction's approximation guarantees and computational feasibility for large d and H
