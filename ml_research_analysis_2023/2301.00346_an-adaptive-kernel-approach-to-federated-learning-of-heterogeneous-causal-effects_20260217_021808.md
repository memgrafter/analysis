# An Adaptive Kernel Approach to Federated Learning of Heterogeneous Causal Effects

## Quick Facts
- arXiv ID: 2301.00346
- Source URL: https://arxiv.org/abs/2301.00346
- Reference count: 40
- Primary result: Achieves lower errors in estimating conditional average treatment effect (CATE) and average treatment effect (ATE) compared to baselines when sources have different distributions

## Executive Summary
This paper addresses federated causal inference where data sources have dissimilar distributions, proposing an adaptive kernel approach using Random Fourier Features to disentangle loss functions into source-specific components. The method enables learning causal effects without sharing raw data, minimizing privacy risks while automatically learning similarities among sources through transfer coefficients. Key results show superior performance on both synthetic and real-world datasets (IHDP), achieving lower errors in estimating conditional average treatment effect (CATE) and average treatment effect (ATE) when sources have different distributions.

## Method Summary
The proposed method uses Random Fourier Features to approximate kernel functions, enabling decomposition of the global objective into local components per data source. Each source computes gradients locally and sends them to a central server without sharing raw data. The approach learns adaptive transfer coefficients that capture similarity between sources through modified kernel functions, allowing the model to automatically adjust for source similarity. Variational inference with latent confounders enables identification of causal effects in decentralized settings by approximating posterior distributions needed for causal effect identification.

## Key Results
- Outperforms baselines (BART, TARNet, CFRNet, CEVAE, etc.) on both synthetic and IHDP datasets
- Achieves lower PEHE and ATE errors when sources have different distributions
- Provides minimax lower bounds to assess parameter estimation quality
- Successfully estimates similarities among sources through learned transfer coefficients without prior information

## Why This Works (Mechanism)

### Mechanism 1
Random Fourier Features enable decentralized training by decomposing the loss function into source-specific components. By approximating kernel functions with finite random Fourier features, the global objective can be rewritten as a sum of local objective functions, each associated with a data source. This decomposition allows each source to compute gradients locally and send them to a central server without sharing raw data. The method requires translation-invariant kernel functions and sufficient random features for quality approximation.

### Mechanism 2
Adaptive transfer coefficients (λs,v) learn the similarity between data sources without prior knowledge. The kernel function is modified to include adaptive coefficients λs,v ∈ [0,1] that weight the contribution of each source to the estimation of functions for other sources. These coefficients are learned from data, allowing the model to automatically adjust for source similarity. The optimization landscape complexity and data source dissimilarity can affect the effectiveness of this mechanism.

### Mechanism 3
Variational inference with latent confounders enables identification of causal effects in decentralized settings. The model uses variational inference to approximate the posterior distribution of latent confounders Z, allowing estimation of the conditional distributions needed for causal effect identification. The ELBO is decomposed across sources using the same Random Fourier Features approach. This mechanism relies on the latent confounder Z having a relationship to observed variables X that makes it identifiable through variational inference.

## Architecture Onboarding

- **Component map**: Data Sources -> Local Computation -> Gradient Aggregation -> Model Update -> Broadcast -> Effect Estimation
- **Critical path**: Data → Local Computation → Gradient Aggregation → Model Update → Broadcast → Effect Estimation
- **Design tradeoffs**: Communication efficiency vs. model accuracy; Privacy vs. performance; Model complexity vs. interpretability
- **Failure signatures**: Poor convergence (insufficient communication or inappropriate learning rates); High variance in estimates (inadequate random features or poor variational approximation); Bias in causal effect estimates (violated assumptions about latent confounders or source similarity)
- **First 3 experiments**: 1) Test Random Fourier Features approximation quality on small synthetic dataset; 2) Validate adaptive transfer mechanism on two sources with known similarity; 3) Verify causal effect estimation on synthetic dataset with known ground truth

## Limitations

- Theoretical guarantees depend on adaptive factors λs,v whose practical behavior is not fully characterized
- Implementation complexity with multiple hyperparameters and sparse federated optimization details
- Scalability concerns with O(m²) complexity for computing similarity coefficients between all source pairs
