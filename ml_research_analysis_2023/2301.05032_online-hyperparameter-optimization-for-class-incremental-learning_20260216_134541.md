# Online Hyperparameter Optimization for Class-Incremental Learning

## Quick Facts
- arXiv ID: 2301.05032
- Source URL: https://arxiv.org/abs/2301.05032
- Reference count: 40
- This paper addresses the challenge of class-incremental learning (CIL), where a model needs to learn new classes phase-by-phase while retaining knowledge of previously learned classes. The core idea is to use an online hyperparameter optimization method to adaptively balance the stability-plasticity tradeoff in CIL. The authors formulate the CIL task as an online Markov Decision Process (MDP) and propose a novel algorithm to solve it, which uses local estimated rewards and the Exp3 bandit algorithm to handle the lack of future data and bandit feedback. The method consistently improves top-performing CIL methods in both training-from-half (TFH) and training-from-scratch (TFS) settings, e.g., boosting the average accuracy of TFH and TFS by 2.2 percentage points on ImageNet-Full compared to the state-of-the-art.

## Executive Summary
This paper tackles the class-incremental learning (CIL) problem by formulating it as an online Markov Decision Process (MDP) and using an Exp3 bandit algorithm to optimize hyperparameters dynamically. The approach addresses the challenge of balancing stability (retaining old knowledge) and plasticity (learning new knowledge) by adaptively adjusting knowledge distillation loss weights, learning rates, and classifier types across training phases. By using local estimated rewards instead of true validation data, the method overcomes the limitation of not having access to future data in the online setting. The experimental results demonstrate consistent improvements over state-of-the-art CIL methods across three benchmark datasets.

## Method Summary
The authors formulate CIL as an online MDP where each phase represents a stage, and the policy network selects hyperparameters (KD loss weights, learning rates, classifier types) as actions. Since validation data isn't available during training, the method creates local validation sets from training data to estimate rewards. The Exp3 bandit algorithm handles the bandit feedback constraint by updating action probabilities based on observed rewards. The policy generates probability distributions over discretized hyperparameter actions, which are sampled and applied during CIL training. This framework allows for fine-grained control over the stability-plasticity tradeoff without requiring future data or full feedback.

## Key Results
- Consistently improves top-performing CIL methods in both TFH and TFS settings
- Boosts average accuracy by 2.2 percentage points on ImageNet-Full compared to state-of-the-art
- Demonstrates effectiveness across three benchmark datasets: CIFAR-100, ImageNet-Subset, and ImageNet-Full
- Shows significant improvements even with coarse discretization of the hyperparameter space

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The online MDP formulation enables adaptive hyperparameter optimization by treating each phase as a stage and allowing the policy to learn from estimated rewards.
- Mechanism: By reformulating CIL as an online MDP, the method can adjust hyperparameters dynamically across phases based on local estimated rewards, rather than using fixed hyperparameters. This captures the time-varying nature of the training data.
- Core assumption: The fast mixing assumption holds - hyperparameters chosen early don't significantly impact classes seen in later phases.

## Architecture Onboarding

- Component map:
  Policy network -> Exp3 bandit module -> Local dataset builder -> CIL training module

- Critical path:
  1. Policy generates action probabilities
  2. Action sampled and applied to CIL training
  3. Local validation set created and reward computed
  4. Exp3 updates action probabilities
  5. Repeat for multiple iterations per phase

- Design tradeoffs:
  - Discretization vs continuous search space for hyperparameters
  - Number of policy update iterations vs training time
  - Size of local validation sets vs estimation accuracy

- Failure signatures:
  - Poor performance on later phases suggests insufficient stability
  - Rapid changes in hyperparameter values suggest instability in policy learning
  - Low variance in action selection suggests policy isn't exploring enough

- First 3 experiments:
  1. Test with fixed hyperparameters (no policy) to establish baseline
  2. Test with only KD loss weights optimization to isolate its impact
  3. Test with full hyperparameter optimization on CIFAR-100 with N=5 phases

## Limitations

- The fast mixing assumption (early hyperparameters don't significantly impact later phases) remains theoretically unproven and could fail in scenarios with strong phase dependencies
- Local validation set approach relies on the assumption that training data provides representative performance estimates, which may not hold for highly imbalanced or domain-shifted datasets
- Significant computational overhead due to multiple policy iterations required per training phase

3. **Ablation on hyperparameter selection**: Systematically vary which hyperparameters are included in the optimization (e.g., test with only KD weights, or add memory allocation parameters) to identify the true drivers of performance improvements
