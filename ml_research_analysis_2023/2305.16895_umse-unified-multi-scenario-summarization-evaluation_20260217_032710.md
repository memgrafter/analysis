# UMSE: Unified Multi-scenario Summarization Evaluation

## Quick Facts
- arXiv ID: 2305.16895
- Source URL: https://arxiv.org/abs/2305.16895
- Reference count: 17
- Key outcome: UMSE achieves comparable performance to specialized evaluation models across three summarization scenarios while being the first unified model for reference-based, reference-free, and combined evaluation.

## Executive Summary
This paper proposes UMSE, a unified multi-scenario summarization evaluation model that addresses the limitation of existing methods which are optimized separately for reference-based and reference-free scenarios. The authors introduce a perturbed prefix-tuning method that shares cross-scenario knowledge while preserving scenario-specific capabilities, and employ a self-supervised training paradigm that eliminates the need for human annotations. Experiments on the SummEval benchmark demonstrate that UMSE performs comparably to several strong baseline methods specifically designed for each scenario, establishing the first unified approach for three typical evaluation scenarios.

## Method Summary
UMSE uses a RoBERTa-large backbone with continuous prefix tokens that are perturbed through different orderings for different scenarios. The model is trained using a self-supervised paradigm that constructs two types of training data: summary matching oriented data and document matching oriented data. Negative samples are automatically generated using BM25 retrieval and sentence replacement strategies. The perturbed prefix-tuning enables knowledge transfer across scenarios while maintaining scenario-specific capabilities. The model employs a binary classification framework where it distinguishes between positive and negative sample pairs, with an optional fusion module for the combined scenario.

## Key Results
- UMSE achieves comparable performance to specialized baseline methods across all three evaluation scenarios on the SummEval benchmark
- The perturbed prefix-tuning method effectively transfers knowledge between scenarios while preserving scenario-specific capabilities
- UMSE demonstrates significant improvement over existing baselines in the Sum-Doc scenario while maintaining competitive performance in Sum-Ref and Sum-Doc-Ref scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The perturbed prefix-tuning method enables knowledge transfer across scenarios while preserving scenario-specific capabilities.
- Mechanism: The method uses the same continuous prefix tokens but arranges them in different orders for different scenarios. This allows the model to leverage shared matching knowledge while maintaining unique prompt characteristics for each scenario.
- Core assumption: Shared semantic understanding between scenarios can be effectively captured through reordered continuous prefix tokens without losing scenario-specific nuances.
- Evidence anchors:
  - [abstract] "we propose a perturbed prefix tuning method to share cross-scenario knowledge between scenarios"
  - [section 3.3] "We perturb PSD as {p1, p3, ..., pLp, p2, ..., pLp-1}, and use this perturbed prefix as the prefix for Sum-Doc-Ref PSDR"
  - [corpus] Weak evidence - corpus shows related work on multi-scenario models but no direct comparison to perturbed prefix-tuning specifically
- Break condition: If prefix length is too short to capture meaningful semantic patterns, or if scenarios have fundamentally incompatible knowledge structures that cannot be reconciled through reordering.

### Mechanism 2
- Claim: Self-supervised training without human annotations enables effective model training while maintaining generalization ability.
- Mechanism: The paper constructs two types of self-supervised datasets - summary matching oriented data and document matching oriented data - using BM25 retrieval and sentence replacement strategies to create positive and negative pairs automatically.
- Core assumption: The automatically constructed negative samples are sufficiently challenging to force the model to learn meaningful distinctions without human supervision.
- Evidence anchors:
  - [abstract] "use a self-supervised training paradigm to optimize the model without extra human labeling"
  - [section 3.2] "we propose to use the leading three sentences of the corresponding document D as the candidate summary X LD3" and "we first use the BM25 retrieval model to retrieve the most similar document D′ to D"
  - [corpus] Weak evidence - corpus shows related work on self-supervised methods but no direct comparison to this specific construction approach
- Break condition: If the negative sampling strategy fails to create meaningful distinctions, or if the automatic data construction introduces systematic biases that the model exploits rather than learning genuine semantic understanding.

### Mechanism 3
- Claim: The unified model architecture achieves comparable performance to specialized models across multiple scenarios.
- Mechanism: By using a single transformer model with different prefixes for different scenarios, the approach reduces model complexity while maintaining or improving performance through knowledge sharing.
- Core assumption: A single model can effectively handle the different input formats and evaluation criteria of multiple scenarios without sacrificing performance.
- Evidence anchors:
  - [abstract] "Experimental results across three typical scenarios on the benchmark dataset SummEval indicate that our UMSE can achieve comparable performance with several existing strong methods which are specifically designed for each scenario"
  - [section 4.5] "UMSE (w/ SD) performs comparably to the UMSE (w/ SR) in the Sum-Ref scenario and achieves significant improvement over the existing baselines"
  - [corpus] Weak evidence - corpus shows related multi-scenario approaches but no direct performance comparisons to specialized models
- Break condition: If scenario-specific requirements are too divergent for a single architecture to handle effectively, or if the unified approach introduces interference between scenarios that degrades overall performance.

## Architecture Onboarding

- Component map: Input → Prefix encoding → Transformer processing → Pooling → MLP → Output score
- Critical path: Input → Prefix encoding → Transformer processing → Pooling → MLP → Output score
- Design tradeoffs: 
  - Unified vs. separate models: Memory efficiency vs. scenario-specific optimization
  - Prefix length: More context vs. increased computational cost
  - Negative sampling difficulty: Harder negatives improve learning but may increase training instability
- Failure signatures:
  - Performance degradation across all scenarios: Likely prefix perturbation not effective or transformer backbone insufficient
  - Performance gap between scenarios: Imbalanced data construction or insufficient scenario-specific capacity
  - Training instability: Negative sampling too difficult or learning rate issues
- First 3 experiments:
  1. Ablation study: Remove perturbed prefix-tuning and use standard prefix-tuning to measure knowledge transfer effectiveness
  2. Negative sampling analysis: Vary the difficulty of negative samples to find optimal balance between learning efficiency and stability
  3. Prefix length sensitivity: Test different prefix lengths to identify optimal trade-off between performance and computational cost
