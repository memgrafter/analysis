# Spatiotemporal Transformer for Stock Movement Prediction

## Quick Facts
- arXiv ID: 2305.03835
- Source URL: https://arxiv.org/abs/2305.03835
- Authors: 
- Reference count: 7

## Executive Summary
This paper introduces a Spatiotemporal Transformer-LSTM model (STST) for stock movement prediction that combines spatiotemporal embeddings with an LSTM classifier. The model addresses the challenge of capturing both long-range temporal dependencies and spatial correlations among stock data features. Tested on two benchmark datasets, STST demonstrates superior performance compared to existing methods and shows promising results in simulated trading scenarios.

## Method Summary
The STST model processes stock data by first creating spatiotemporal embeddings through a combination of positional encoding (Time2Vec) applied to temporal features and concatenation with non-temporal features. These embeddings are then processed through a transformer encoder with power normalization, followed by an LSTM-MLP classifier for binary prediction of stock price movements. The model was trained on ACL18 and KDD17 datasets using grid search for hyperparameter tuning and evaluated using accuracy and Matthew's Correlation Coefficient.

## Key Results
- Achieved 63.707% accuracy on ACL18 dataset and 56.879% on KDD17 dataset
- Outperformed several state-of-the-art methods including CNN-LSTM, HAN, and traditional transformers
- Simulated trading results showed at least 10.41% higher profits than S&P 500 index

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The spatiotemporal embedding allows the model to capture both temporal and spatial dependencies simultaneously, improving stock movement prediction accuracy.
- Mechanism: By splitting input features into temporal and non-temporal components, applying positional encoding only to temporal features, and concatenating them before passing through a dense layer, the model can learn relationships across both time steps and feature dimensions.
- Core assumption: Financial time series data contains both temporal patterns (price movements over time) and spatial patterns (relationships between different features within the same time step).

  - [section]: "This can be overcome by the addition of larger receptive fields, but this can quickly become very computationally expensive. Transformers overcome many of these challenges..."
  - [corpus]: Weak corpus support for spatiotemporal specifically; most related papers focus on temporal or sentiment analysis without explicit spatial feature correlation.
- Break condition: If spatial correlations within timesteps are not predictive of stock movements, or if the computational cost of spatiotemporal processing outweighs the benefits.

### Mechanism 2
- Claim: The transformer-encoder with self-attention captures long-range dependencies in stock data that traditional sequential models struggle with.
- Mechanism: Multi-headed self-attention allows the model to weigh the importance of different time steps relative to each other, identifying which historical data points are most relevant for predicting future movements.
- Core assumption: Stock price movements are influenced by patterns that span across multiple time steps, and these relationships can be learned through attention mechanisms.
- Evidence anchors:
  - [section]: "Using this notion, we propose the Spatiotemporal Transformer for Stocks (STST), a transformer-LSTM model that is focused on correlating spatiotemporal patterns for the task of stock movement prediction."
  - [section]: "Since price movement prediction is a binary classification problem, the output for each classification model is a single value."
  - [corpus]: Weak corpus support for stock movement prediction specifically; related papers focus more on sentiment analysis and multimodal approaches.
- Break condition: If the attention mechanism fails to identify meaningful long-range dependencies, or if the relationships are too complex to be captured by self-attention alone.

### Mechanism 3
- Claim: The combination of transformer-encoder outputs with an LSTM-MLP classifier provides better performance than either component alone.
- Mechanism: The transformer-encoder contextualizes the input features, creating rich embeddings that capture complex relationships. The LSTM-MLP then processes these contextualized embeddings sequentially to make final predictions.
- Core assumption: The sequential processing of contextualized features by LSTM can capture temporal patterns that the transformer alone cannot effectively model.
- Evidence anchors:
  - [section]: "Since price movement prediction is a binary classification problem, the output for each classification model is a single value. It is passed through the sigmoid activation function to obtain the output prediction."
  - [section]: "Finally, we tested the variant with spatiotemporal embeddings and an MLP classifier (STST-MLP). This model achieved accuracies of 62.509% and 54.319% for each dataset, an increase of up to 10.4% over the baseline model."
  - [corpus]: Weak corpus support for this specific combination; most related work uses either pure transformers or pure LSTMs.
- Break condition: If the LSTM-MLP classifier fails to improve upon the transformer's predictions, or if the additional complexity does not justify the performance gain.

## Architecture Onboarding

- Component map:
  Input Layer (Raw stock data) -> Spatiotemporal Embedding Layer -> Transformer Encoder -> LSTM-MLP Classifier -> Output Layer (Binary classification)

- Critical path:
  1. Input features are split into temporal and non-temporal components
  2. Temporal features receive positional encoding via Time2Vec
  3. Features are concatenated and passed through dense layer
  4. Transformer encoder processes the embeddings
  5. LSTM-MLP classifier makes final prediction

- Design tradeoffs:
  - Transformer vs. LSTM for encoding: Transformers capture long-range dependencies more efficiently but require more computational resources
  - Spatiotemporal vs. temporal-only embeddings: Spatiotemporal approach captures more complex relationships but increases model complexity
  - LSTM vs. MLP classifier: LSTM can capture sequential patterns in contextualized embeddings but adds computational overhead

- Failure signatures:
  - Poor performance on datasets with longer time spans may indicate difficulty in generalizing across different market conditions
  - Overfitting on smaller datasets suggests the model is too complex for the available data
  - Failure to outperform simple baselines may indicate that the spatiotemporal embedding is not capturing useful information

- First 3 experiments:
  1. Train the model with only temporal embeddings and an MLP classifier to establish a baseline performance
  2. Add the LSTM classifier while keeping temporal embeddings to assess the impact of sequential processing
  3. Implement the full spatiotemporal embedding approach and compare performance gains against the previous experiments

## Limitations
- Limited dataset scope: Only tested on two datasets (ACL18 and KDD17) with specific stock pools and time periods, raising questions about generalizability
- Unclear implementation details: Exact implementation of spatiotemporal embedding layer is underspecified
- Incomplete baseline comparison: Doesn't specify which baselines are current state-of-the-art methods or report computational efficiency comparisons

## Confidence
- High confidence in the technical implementation of the transformer-LSTM architecture and the general approach to stock movement prediction using spatiotemporal embeddings.
- Medium confidence in the performance claims, given the limited dataset scope and lack of comparison to the most current state-of-the-art methods.
- Low confidence in the claimed real-world applicability based solely on simulated trading results, which often don't translate to live market conditions due to factors like transaction costs, slippage, and market impact.
