# Multi-modal reward for visual relationships-based image captioning

## Quick Facts
- arXiv ID: 2303.10766
- Source URL: https://arxiv.org/abs/2303.10766
- Reference count: 40
- This paper proposes a deep neural model for image captioning based on fusing visual relationships with spatial features extracted from images.

## Executive Summary
This paper introduces a novel image captioning approach that combines visual relationships extracted from scene graphs with spatial features using an Attention-on-Attention (AoA) encoder-decoder architecture. The method employs a multi-modal reward function that combines language-based CIDEr rewards with vision similarity rewards in a common embedding space, optimized through deep reinforcement learning. Experimental results on MSCOCO demonstrate that incorporating visual relationships and the proposed multi-modal reward improves captioning performance compared to standard baselines.

## Method Summary
The proposed method extracts visual relationships as triplets from scene graphs and fuses them with spatial features from ResNet-101 in an AoA-based encoder. The AoA blocks refine both feature types through parallel attention mechanisms before feeding them to an LSTM decoder. Training proceeds in two phases: first with cross-entropy loss, then with self-critical sequence training (SCST) using a multi-modal reward combining CIDEr language reward and vision similarity reward. The vision reward measures caption-image similarity in a shared embedding space.

## Key Results
- The proposed method outperforms standard SCST and Up-Down baselines on MSCOCO with gains of 1-2 points on CIDEr
- Visual relationship features improve caption semantic richness when combined with spatial features
- The multi-modal reward (α=0.7) balances language and vision components effectively

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The multi-modal reward improves caption relevance by combining CIDEr language reward with vision similarity reward.
- Mechanism: The reward function uses a linear combination of language and vision similarity, where the vision component measures similarity between the generated caption and image in a shared embedding space.
- Core assumption: Vision reward computed from image-caption embedding network accurately reflects visual relevance of captions.
- Evidence anchors: [abstract] "A multi-modal reward function is then introduced for deep reinforcement learning of the proposed network using a combination of language and vision similarities in a common embedding space."
- Break condition: If vision reward does not correlate with human judgment of caption relevance, the optimization will favor captions that score well on embedding similarity but lack semantic coherence.

### Mechanism 2
- Claim: Visual relationship triplets extracted from scene graphs provide high-level semantic features that complement spatial features.
- Mechanism: Scene graph generator extracts object relationships as triplets (subject, relation, object), which are embedded and aggregated to form visual relationship features.
- Core assumption: Extracted triplets capture meaningful relationships that improve caption quality.
- Evidence anchors: [abstract] "To take advantage of visual relationships in caption generation, this paper proposes a deep neural network architecture for image captioning based on fusing the visual relationships information extracted from an image's scene graph with the spatial feature maps of the image."
- Break condition: If scene graph extraction fails to capture salient relationships or produces noisy triplets, the semantic enrichment will degrade caption quality.

### Mechanism 3
- Claim: Attention on Attention (AoA) blocks address attention mechanism limitations by adding a second attention step to refine candidate vectors.
- Mechanism: AoA blocks compute information vectors and attention gates from the attention result and query, then combine them via element-wise multiplication to produce refined outputs.
- Core assumption: The second attention step effectively filters irrelevant or noisy information from candidate vectors.
- Evidence anchors: [section] "To tackle the latter issue, attention on attention (AoA) has been proposed, which extends the conventional attention mechanism by adding another attention step."
- Break condition: If the additional attention step adds computational overhead without meaningful improvement, or if it over-smooths the feature representations.

  - Why needed here: Attention allows the decoder to focus on relevant parts of image features when generating each token, crucial for handling complex scenes

## Architecture Onboarding

- Component map: Spatial features -> AoA encoder -> LSTM decoder -> Caption generation
- Critical path: Feature extraction → AoA encoder refinement → Decoder with attention → Caption generation → Multi-modal reward optimization
- Design tradeoffs: Using lightweight spatial features instead of bottom-up features reduces computational cost but may lose fine-grained object details
- Failure signatures: Poor captions may indicate issues with triplet extraction, AoA refinement, or reward function balance

## Limitations

- Scene graph extraction process lacks transparency regarding confidence thresholds and error rates in triplet generation
- Multi-modal reward function combines vision and language components without validating whether vision reward correlates with caption quality
- Performance improvements over baselines are modest (1-2 points on CIDEr) and may not be statistically significant

## Confidence

**High Confidence:** The general architecture combining visual relationships with spatial features through AoA mechanisms is sound and follows established deep learning principles.

**Medium Confidence:** The specific implementation details of the AoA blocks and their effectiveness in fusing relationship features are plausible but not fully validated.

**Low Confidence:** The quality and relevance of extracted visual relationship triplets, the effectiveness of the vision similarity reward in improving caption quality, and the statistical significance of performance improvements all require further validation.

## Next Checks

1. **Ablation Study on Relationship Quality:** Conduct controlled experiments filtering scene graph triplets by confidence scores (e.g., keep only triplets with confidence > 0.8 vs > 0.5 vs all triplets). Measure the correlation between triplet quality and caption performance to establish whether the relationship features genuinely improve captions or introduce noise.

2. **Vision Reward Validation:** Implement a human evaluation study where captions optimized with different α values (0.3, 0.5, 0.7, 0.9) are judged on visual relevance and linguistic quality. Compare these judgments against the vision similarity scores to verify that higher vision reward correlates with better caption quality according to human raters.

3. **Statistical Significance Testing:** Perform paired t-tests or bootstrap confidence intervals on the CIDEr scores comparing the proposed method against strong baselines (Up-Down, SCST) across multiple random seeds. Report effect sizes and determine whether the observed improvements are statistically significant or within the range of experimental noise.
