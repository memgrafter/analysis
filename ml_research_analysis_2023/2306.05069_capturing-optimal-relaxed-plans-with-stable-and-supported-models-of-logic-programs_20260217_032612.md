# Capturing (Optimal) Relaxed Plans with Stable and Supported Models of Logic Programs

## Quick Facts
- arXiv ID: 2306.05069
- Source URL: https://arxiv.org/abs/2306.05069
- Reference count: 8
- Primary result: Supported model encodings outperform stable model encoding and IP approach on STRIPS benchmarks

## Executive Summary
This paper establishes a novel connection between delete-free (relaxed) planning and logic programming by presenting three encodings of relaxed planning problems as logic programs. The encodings utilize both stable models and supported models, with the latter incorporating acyclicity constraints through vertex elimination. The approach enables efficient computation of optimal relaxed plans using answer set solvers, with experimental results showing significant performance improvements over existing methods, particularly for the supported model encodings which solve more problems faster than state-of-the-art integer programming approaches.

## Method Summary
The authors present three distinct encodings of relaxed planning problems as logic programs. The first encoding uses stable models, while the second and third employ supported models with acyclicity constraints enforced via vertex elimination. These encodings transform the delete-free planning problem into logic programming frameworks that can be solved using answer set solvers. The vertex elimination technique in the supported model encodings allows for more natural handling of acyclicity constraints, which is crucial for computing optimal relaxed plans. The experimental evaluation compares these encodings against a state-of-the-art integer programming approach across 2212 STRIPS planning problems.

## Key Results
- Supported model encodings significantly outperform the stable model encoding
- Diagnostic supported model encoding solves more problems faster than IP approach
- Experimental results demonstrate advantages across all time limits tested

## Why This Works (Mechanism)
The supported model encodings work more effectively because they handle acyclicity constraints more naturally through vertex elimination. This allows the logic programming solvers to more efficiently explore the solution space of relaxed plans. The stable model encoding, while theoretically sound, suffers from computational inefficiencies when dealing with the acyclicity requirements inherent in relaxed planning. The vertex elimination technique in supported models provides a more direct path to finding optimal solutions by eliminating cyclic dependencies early in the solving process.

## Foundational Learning
- Relaxed planning: Planning without delete lists, allowing actions to be applied repeatedly; needed to understand the problem domain being encoded
- Stable models: A semantics for logic programs that provides a foundation for answer set programming; quick check: can represent recursive definitions
- Supported models: An alternative semantics for logic programs that ensures every true atom has a supporting rule; needed for better handling of acyclicity constraints
- Vertex elimination: A technique for enforcing acyclicity by systematically removing vertices; quick check: transforms cyclic graphs into acyclic ones
- Answer set solvers: Computational systems for finding stable or supported models of logic programs; needed to execute the encodings
- STRIPS planning: A classical planning representation using preconditions and effects; quick check: forms the benchmark suite used

## Architecture Onboarding
Component map: STRIPS problem -> Logic Program Encoding -> Answer Set Solver -> Relaxed Plan
Critical path: Problem specification → Encoding transformation → Solver execution → Plan extraction
Design tradeoffs: Stable models provide theoretical elegance but computational inefficiency; supported models sacrifice some theoretical simplicity for practical performance gains
Failure signatures: Cyclic dependencies causing non-termination in stable models; unsupported atoms in logic programs; timeout in solver execution
First experiments:
1. Verify basic encoding correctness on small, hand-crafted STRIPS problems
2. Compare runtime performance between stable and supported model encodings on medium-sized problems
3. Test vertex elimination implementation on problems with known cyclic structures
