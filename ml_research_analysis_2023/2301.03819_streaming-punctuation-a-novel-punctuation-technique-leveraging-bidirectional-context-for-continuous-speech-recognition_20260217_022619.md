# Streaming Punctuation: A Novel Punctuation Technique Leveraging Bidirectional Context for Continuous Speech Recognition

## Quick Facts
- arXiv ID: 2301.03819
- Source URL: https://arxiv.org/abs/2301.03819
- Reference count: 35
- Key outcome: 13.9% segmentation F0.5-score improvement and 0.66 BLEU score improvement across seven target languages for downstream Machine Translation

## Executive Summary
This paper addresses the challenge of poor punctuation and segmentation in continuous speech recognition, particularly for voice typing and meeting transcriptions where irregular pausing patterns or slow speakers cause over-segmentation. The authors propose a streaming punctuation approach that uses dynamic decoding windows and a Transformer-based punctuation model to punctuate and re-punctuate ASR outputs. This bidirectional context approach effectively tackles over-segmentation issues while improving downstream machine translation performance.

## Method Summary
The proposed streaming punctuation technique employs dynamic decoding windows that expand and contract based on punctuation likelihood scores, allowing the model to leverage bidirectional context while maintaining streaming capabilities. A Transformer-based punctuation model processes the ASR outputs, with the system designed to re-punctuate text as new information becomes available. This approach specifically targets the over-segmentation problem that occurs when speakers pause irregularly or speak slowly, resulting in fragmented sentences that lack proper punctuation and structure.

## Key Results
- Segmentation F0.5-score improved by 13.9% compared to baseline streaming approaches
- Average BLEU score improvement of 0.66 across seven target languages for downstream Machine Translation
- Effective handling of over-segmentation issues in continuous speech recognition scenarios

## Why This Works (Mechanism)
The bidirectional context modeling through dynamic decoding windows allows the punctuation model to consider both preceding and following text segments when making punctuation decisions. This overcomes the fundamental limitation of traditional streaming approaches that only have access to past context. The Transformer architecture's self-attention mechanism efficiently captures long-range dependencies, enabling accurate punctuation placement even when segments are initially mis-punctuated. The dynamic window adjustment based on punctuation likelihood scores ensures the model balances latency constraints with accuracy requirements.

## Limitations
- Evaluation limited to four English datasets and seven target languages for MT downstream task
- Computational overhead from dynamic window approach may impact resource-constrained streaming scenarios
- No latency measurements provided for real-time streaming applications
