# Learning Representative Trajectories of Dynamical Systems via Domain-Adaptive Imitation

## Quick Facts
- arXiv ID: 2304.10260
- Source URL: https://arxiv.org/abs/2304.10260
- Reference count: 14
- Introduces DATI, a deep RL agent for domain-adaptive trajectory imitation

## Executive Summary
This paper introduces DATI, a deep reinforcement learning agent for domain-adaptive trajectory imitation, inspired by predators learning to map their dynamics to prey positions. DATI treats trajectory imitation as a style transfer problem between domains, using a cycle-consistent GAN framework. The agent learns to generate representative trajectories from partial knowledge of a dynamical system's evolution rule, without requiring explicit reward functions. Experiments on synthetic trajectory families (FixedStart, UShaped, Circles, Ribbons) show DATI outperforms baseline methods (DDPG-TI, BC) in dynamic time warping distance, with the same per-task hyperparameters. DATI also generalizes to real-world maritime traffic data, discovering abnormal motion patterns with 78% F1-score. The method's robustness to trajectory geometry and ability to handle spatially-unconstrained data make it promising for applications like anomaly detection in traffic and pathfinding for ocean voyages.

## Method Summary
DATI frames trajectory imitation as a domain-adaptive style transfer problem, treating agent and expert trajectories as separate domains. The method employs a cycle-consistent GAN architecture where a generator learns to map between these domains, and a discriminator evaluates trajectory quality. The agent learns without explicit reward functions by leveraging the cycle consistency constraint - trajectories mapped from agent to expert and back should match the original agent trajectory. This approach enables learning representative trajectories from partial knowledge of dynamical systems. The framework consists of a trajectory generator that produces agent trajectories, a style transfer network that maps between agent and expert domains, and discriminators that evaluate trajectory quality in each domain.

## Key Results
- DATI outperforms DDPG-TI and BC baselines in dynamic time warping distance across synthetic trajectory families
- Achieves 78% F1-score in detecting abnormal motion patterns in real-world maritime traffic data
- Maintains consistent hyperparameters across different trajectory geometries and dynamical systems
- Demonstrates robustness to spatially-unconstrained trajectory data without requiring explicit reward functions

## Why This Works (Mechanism)
DATI works by treating trajectory imitation as a domain adaptation problem where the agent learns to map its own dynamics to the expert's trajectory distribution. The cycle-consistent GAN framework enables this by establishing a bidirectional mapping between agent and expert domains, with the cycle consistency constraint ensuring that transformations preserve trajectory characteristics. This approach bypasses the need for explicit reward engineering by using the expert trajectory distribution as implicit guidance. The generator learns to produce trajectories that, when passed through the style transfer network to the expert domain and back, reconstruct the original agent trajectory, while also producing trajectories that the expert domain discriminator accepts as valid. This dual constraint enables the agent to discover representative trajectories that capture the underlying dynamics of the system without requiring complete knowledge of the evolution rules.

## Architecture Onboarding
**Component Map**: Trajectory Generator -> Style Transfer Network -> Discriminator (Expert Domain) -> Cycle Consistency Loss -> Discriminator (Agent Domain) -> Adversarial Loss

**Critical Path**: The core learning loop involves the trajectory generator producing agent trajectories, the style transfer network mapping these to the expert domain, the expert discriminator evaluating these mapped trajectories, and the cycle consistency constraint ensuring that trajectories mapped back to the agent domain reconstruct the originals. This creates a self-supervised learning signal that drives the agent to discover representative trajectories without explicit rewards.

**Design Tradeoffs**: The cycle-consistent GAN framework trades computational complexity for the benefit of reward-free learning. While traditional RL methods require carefully designed reward functions, DATI learns implicitly from trajectory distributions. However, this comes at the cost of training stability and potential mode collapse in the GAN components. The architecture prioritizes generalization across different trajectory geometries over fine-grained control of individual trajectory characteristics.

**Failure Signatures**: Common failure modes include mode collapse in the GAN components, where the generator produces limited trajectory variations; poor cycle consistency, where mapped trajectories fail to reconstruct properly; and discriminator overfitting, where the discriminators become too specialized to training data and fail to generalize. These manifest as high DTW distances, poor F1-scores on anomaly detection, and unstable training curves with large loss oscillations.

## Limitations
- Effectiveness on highly complex or high-dimensional trajectory spaces remains uncertain
- Computational complexity of GAN-based architecture may limit real-time applications
- F1-score of 78% on maritime data may not generalize to other domains with different noise patterns

## Confidence

Medium: Comparative performance against baselines is convincing but may not generalize to all dynamical systems.
Medium: Maritime traffic application demonstrates practical utility but dataset-specific nature warrants caution.
