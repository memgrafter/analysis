# Can Transformers Learn to Solve Problems Recursively?

## Quick Facts
- **arXiv ID**: 2305.14699
- **Source URL**: https://arxiv.org/abs/2305.14699
- **Reference count**: 40
- **Primary result**: Transformers can learn to approximate structurally recursive functions to some degree, but the learned algorithms fall short and fail on specific classes of inputs.

## Executive Summary
This paper investigates whether transformer models can learn to solve recursive problems by emulating structurally recursive functions from input-output examples. The authors train small transformer models on two tasks: a binary successor function with one recursive subcase and a tree traversal with two recursive subcases. Through empirical analysis and mechanistic interpretability techniques including perturbation analysis and attention visualization, they reconstruct the "shortcut" algorithms that models learn to approximate these recursive functions. The findings reveal that while transformers can approximate recursive functions to some degree, the learned algorithms have systematic failure patterns on specific input classes.

## Method Summary
The authors train transformer models on two recursive tasks: a binary successor function and a tree traversal problem. They employ mechanistic interpretability techniques including perturbation analysis to identify which input tokens most affect model outputs, attention visualization to understand information flow, and algorithm reconstruction to map learned behaviors to explicit computational procedures. The study combines empirical testing across multiple input patterns with conceptual analysis to understand the limitations of transformer-based recursive computation.

## Key Results
- Transformers can learn to approximate structurally recursive functions to some degree
- Reconstructed algorithms explain 91% of failure cases for one function
- Learned algorithms fail systematically on specific classes of inputs despite appearing correct on many examples

## Why This Works (Mechanism)
Transformers can approximate recursive computation through learned attention patterns and token processing strategies that mimic recursive behavior without explicitly implementing recursion. The models develop shortcut algorithms that work for many inputs but fail on edge cases where true recursion would succeed. These learned algorithms use attention mechanisms to route information and make decisions based on local patterns rather than global recursive structure.

## Limitations
- Small scale experiments limit generalizability to larger, more complex recursive tasks
- Focus on toy problems leaves uncertainty about real-world application
- Interpretability techniques may not capture full complexity of learned algorithms
- Findings tied to specific models and tasks may not reflect broader transformer capabilities

## Confidence
- **High confidence**: Transformers can approximate structurally recursive functions to some degree
- **Medium confidence**: The reconstructed algorithms explain the majority of failure cases (91% accuracy for one function)
- **Low confidence**: The limitations observed in toy problems directly translate to real-world recursive tasks
