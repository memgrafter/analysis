# CISum: Learning Cross-modality Interaction to Enhance Multimodal Semantic Coverage for Multimodal Summarization

## Quick Facts
- arXiv ID: 2302.09934
- Source URL: https://arxiv.org/abs/2302.09934
- Reference count: 32
- This paper proposes a multi-task cross-modality learning framework (CISum) to improve multimodal semantic coverage by learning the cross-modality interaction in multimodal articles. It translates images into visual descriptions based on text correlation, fuses them with text to generate summaries, and selects the most relevant image. An automatic multimodal semantics coverage metric is designed for evaluation. Experiments show CISum outperforms baselines in multimodal semantics coverage while maintaining strong performance on traditional ROUGE and BLEU metrics. Specifically, CISum achieves 43.21 R-1, 30.39 R-2, 40.51 R-L, 39.02 B-1, 32.20 B-2, 26.54 B-3, 22.55 B-4, and 73.76 IP scores.

## Executive Summary
This paper addresses the challenge of multimodal semantic coverage in summarization by proposing a multi-task learning framework that learns cross-modality interactions. The key innovation is translating images into text-based visual descriptions that are semantically aligned with the textual content, then fusing these representations to generate summaries that capture both textual and visual information. The model employs a noisy filter cross-modality attention module to reduce irrelevant information during fusion and optimizes three tasks simultaneously: visual-aware summary generation, relevant image selection, and visual description generation. Experiments on Chinese multimodal summarization datasets show that CISum significantly outperforms baselines in multimodal semantic coverage while maintaining competitive performance on traditional text-only evaluation metrics.

## Method Summary
CISum is a multi-task cross-modality learning framework that improves multimodal semantic coverage by learning interactions between text and image modalities. The method first translates images into visual descriptions aligned with text content, then fuses these representations using a noisy filter cross-modality attention module. The framework consists of separate text and visual transformer blocks that process BERT text embeddings and Faster R-CNN image features respectively, followed by cross-modality transformer blocks for interaction learning. A noisy filter mechanism reduces irrelevant information during fusion. The model optimizes three tasks simultaneously using dynamic weight averaging: visual-aware summary generation, relevant image selection, and visual description generation. The framework is trained on a Chinese multimodal summarization dataset with 52,656 training samples.

## Key Results
- Achieved 43.21 R-1, 30.39 R-2, 40.51 R-L, 39.02 B-1, 32.20 B-2, 26.54 B-3, 22.55 B-4 ROUGE and BLEU scores
- Obtained 73.76 IP score for image selection accuracy
- Significantly outperformed baselines on multimodal semantic coverage metrics (MSC-P, MSC-R, MSC-F1)
- Demonstrated strong performance on both traditional text-only metrics and novel multimodal coverage metrics

- Core assumption: Visual content contains semantically complementary information to text, and transforming images into text-based descriptions reduces the semantic gap between modalities.

- Claim: The noisy filter cross-modality attention module reduces irrelevant information and improves cross-modality fusion quality.

- Core assumption: Not all visual information is relevant to the text content, and filtering out irrelevant visual features improves semantic alignment.
- Evidence anchors:
  - [section]: "Usually, there exists redundancy information in different modalities, and the unrelated information may also affect the fusion of the contents... Therefore, a noisy filter module is proposed to capture the crucial cross-modality correlation information during feature fusion."

## Architecture Onboarding

- Component map: Input → BERT text embedding + Faster R-CNN image features → Text and Visual Transformer Blocks → Cross-modality Transformer Blocks → Noisy Filter Module → Multi-task Triple Decoder (Text, Image, Description) → Visual Description Locator → Output
- Critical path: Text and image embeddings → Cross-modality fusion with noisy filtering → Multi-task decoding → Visual description insertion
- Design tradeoffs: 
  - Multi-task learning improves overall performance but increases complexity and training time
  - Noisy filtering improves semantic alignment but adds parameters and potential for over-filtering
  - Visual description generation adds multimodal coverage but requires additional supervision or self-supervised training
- Failure signatures:
  - Low multimodal semantic coverage scores despite good text-only metrics: indicates poor cross-modality fusion
  - Poor image selection accuracy: suggests cross-modality interaction not learned effectively
  - Degraded text summarization performance: suggests tasks are competing rather than complementing
- First 3 experiments:
  1. Test the noisy filter module in isolation by comparing cross-modality attention with and without filtering on a held-out validation set
  2. Validate the multi-task learning framework by training with different combinations of tasks (text-only, text+image, all three) and measuring performance changes
  3. Evaluate the visual description generation quality by measuring ROUGE/BLEU scores between generated and reference descriptions on a subset of the data

## Limitations

- The noisy filter cross-modality attention module is a novel mechanism without direct validation through ablation studies, making its actual contribution to performance uncertain
- Visual description generation quality is crucial but not empirically validated, as poor descriptions could introduce noise rather than improve coverage
- MSC metrics for multimodal semantic coverage are introduced but not validated against human judgments of multimodal coverage quality
- The model focuses only on text and image modalities, leaving open questions about performance on other media types like audio or video

## Confidence

- High: The overall framework architecture (multi-task learning with three complementary tasks) is sound and well-explained
- Medium: The use of visual descriptions to improve multimodal semantic coverage is reasonable but effectiveness depends on description quality
- Low: The novel noisy filter mechanism's actual contribution to performance improvement is not empirically validated through ablation studies

## Next Checks

2. **Human evaluation of visual descriptions**: Conduct a human study where annotators assess whether generated visual descriptions accurately capture image content, establishing the quality of this crucial input to the summary generation process

3. **Single-task vs multi-task comparison**: Train the model with only the visual-aware summary generation task and compare to the full multi-task model to quantify the actual contribution of the additional tasks to multimodal coverage improvement
