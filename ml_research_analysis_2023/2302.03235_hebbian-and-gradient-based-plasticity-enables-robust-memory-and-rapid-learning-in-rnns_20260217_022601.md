# Hebbian and Gradient-based Plasticity Enables Robust Memory and Rapid Learning in RNNs

## Quick Facts
- **arXiv ID**: 2302.03235
- **Source URL**: https://arxiv.org/abs/2302.03235
- **Reference count**: 40
- **Primary result**: Gradient-based plasticity outperforms Hebbian plasticity on few-shot regression tasks requiring inference of underlying mappings

## Executive Summary
This paper introduces a general framework for incorporating two types of plasticity rules—Hebbian and gradient-based—into recurrent neural networks. The Hebbian rule strengthens connections between co-active neurons through outer product updates, while the gradient-based rule uses self-generated internal losses to evolve parameters toward self-determined targets. Both rules are meta-trained to enable rapid learning and robust memory retention across diverse tasks including copying sequences, associative learning, one-shot image classification, and few-shot regression.

## Method Summary
The authors propose RNN architectures with plastic weights that can evolve during task execution based on two distinct plasticity rules. Hebbian plasticity updates weights using the outer product of pre- and post-synaptic activities, reinforcing recent activations. Gradient-based plasticity generates internal losses from model outputs and applies gradient descent to evolve parameters toward these self-generated targets. Both approaches include neuromodulation through an adaptive learning rate η(t) that scales plasticity globally. The models are meta-trained using AdamW optimizer with gradient clipping, and tested across memory and few-shot learning tasks.

## Key Results
- Hebbian plasticity excels at sequential and associative memory tasks, improving performance on copying tasks and cue-reward associations
- Gradient-based plasticity outperforms Hebbian plasticity on few-shot regression tasks that require inferring underlying mappings
- Neuromodulation (adaptive η(t)) is crucial for flexible and robust memory systems, preventing catastrophic forgetting
- The gradient-based approach achieves competitive performance on one-shot image classification compared to ProtoNet and COSOC

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hebbian plasticity improves sequential and associative memory by strengthening connections between co-active neurons.
- Mechanism: The outer product of pre-synaptic activity pl(t) and post-synaptic activity ql(t) directly updates plastic weights, reinforcing recent activations and creating memory traces.
- Core assumption: Memory formation requires strengthening of recently active synaptic connections without explicit error signals.
- Evidence anchors:
  - [abstract]: "Hebbian plasticity is well-suited for several memory and associative learning tasks"
  - [section]: "The outer product of pre-synaptic activity pl(t) and post-synaptic activity ql(t)" (equation 1)
  - [corpus]: Weak evidence - related papers discuss Hebbian memory but don't directly validate the specific implementation
- Break condition: Memory capacity saturates or degrades when synaptic updates become too large without decay mechanisms.

### Mechanism 2
- Claim: Gradient-based plasticity enables rapid learning on few-shot regression tasks by optimizing toward self-generated targets.
- Mechanism: The model generates an internal loss from its own predictions and uses gradient descent to evolve parameters toward this target, allowing coordinated updates across layers.
- Core assumption: Complex learning problems require error propagation to prior layers for coordinated weight updates.
- Evidence anchors:
  - [abstract]: "gradient-based plasticity outperforms Hebbian plasticity on few-shot regression tasks"
  - [section]: "At each time step t, we first calculate the internal loss on the model output ot" (equation 3)
  - [corpus]: Moderate evidence - papers on gradient-based plasticity discuss similar approaches but focus on different architectures
- Break condition: Internal loss becomes degenerate or uninformative, preventing meaningful gradient updates.

### Mechanism 3
- Claim: Neuromodulation (adaptive η(t)) provides flexible and robust memory systems by controlling plasticity rate based on ongoing experience.
- Mechanism: A self-generated signal scales plasticity globally, allowing rapid learning during active input periods and preserving memory during delays.
- Core assumption: Biological memory systems require adaptive plasticity control rather than fixed learning rates.
- Evidence anchors:
  - [abstract]: "neuromodulation, which controls the global plasticity rate, is crucial for flexible and robust plasticity-based memory systems"
  - [section]: "η(t) is the internal learning rate that controls the global plasticity" (equation 2)
  - [corpus]: Strong evidence - multiple papers explicitly model neuromodulation in biological and artificial systems
- Break condition: η(t) becomes too high during delay periods, causing catastrophic forgetting of stored information.

- Critical path: Input → RNN activation → Plasticity update → Weight evolution → Output prediction
- Design tradeoffs:
  - Plastic vs static weights: memory capacity vs computational stability
  - Hebbian vs gradient-based: computational efficiency vs learning flexibility
  - Fixed vs adaptive η(t): simplicity vs robustness
- Failure signatures:
  - Gradient explosion in plastic weights (check δt norm scaling)
  - Vanishing learning (η(t) decaying to zero too quickly)
  - Memory degradation (plastic weights not retaining information)

## Limitations

- Several key implementation details remain underspecified, including the exact form of the self-generated internal loss in gradient-based plasticity
- The paper lacks comprehensive ablation studies showing performance with and without neuromodulation
- Comparison to standard RNN baselines could be more rigorous, particularly for memory tasks

## Confidence

- **High Confidence**: The general framework of incorporating plasticity rules into RNNs, the effectiveness of Hebbian plasticity for associative memory tasks, and the role of neuromodulation in providing robust memory systems
- **Medium Confidence**: The specific implementation details of gradient-based plasticity, the relative performance comparisons across all task types, and the generalization claims to unseen tasks
- **Low Confidence**: The exact computational efficiency claims, particularly regarding the comparison to Transformer-based models, and the scalability of these approaches to more complex sequential decision-making tasks
