# A neural network based model for multi-dimensional nonlinear Hawkes processes

## Quick Facts
- arXiv ID: 2303.03073
- Source URL: https://arxiv.org/abs/2303.03073
- Reference count: 19
- Primary result: Proposes NNNH method using neural networks to estimate nonlinear Hawkes processes, outperforming state-of-the-art methods on benchmark datasets

## Executive Summary
This paper introduces the Neural Network for Non-Linear Hawkes (NNNH) method, which uses feed-forward neural networks to model both the kernels and base intensity functions of nonlinear Hawkes processes. The method enables joint parameter estimation by maximizing the log-likelihood function using stochastic gradient descent. By allowing kernel outputs to take negative values, the NNNH method can capture both excitatory and inhibitory patterns in event sequences. The approach is validated on simulated data and real-world datasets including cryptocurrency trading and neuron spike train data.

## Method Summary
The NNNH method models nonlinear Hawkes processes by representing individual kernels and base intensity functions as separate feed-forward neural networks. D² kernel networks (φdj) model excitation/inhibition effects between dimensions, while D base intensity networks (µd) model time-varying or constant background intensities. Parameters are jointly estimated by maximizing the log-likelihood using Adam-based stochastic gradient descent. An efficient computation method exploits the piecewise linearity of intensity functions between zero-crossing points to calculate integrals without numerical approximation. The method handles both excitatory and inhibitory patterns by allowing kernel outputs to be negative, and can approximate non-smooth kernels through ReLU activation functions.

## Key Results
- NNNH method outperforms state-of-the-art methods in negative log-likelihood on benchmark datasets
- Successfully captures both excitatory and inhibitory patterns in real-world cryptocurrency trading data
- Accurately estimates non-smooth kernels (rectangular functions) that traditional parametric methods cannot handle
- Demonstrates flexibility and accuracy across univariate and multivariate Hawkes processes

## Architecture Onboarding

- Component map: Event timestamps -> Kernel networks (D² feed-forward networks) -> Base intensity networks (D feed-forward networks) -> Estimated conditional intensities -> Optimizer (Adam)

- Critical path:
  1. Preprocess data: Scale timestamps and split into train/validation/test sets
  2. Initialize networks: Set up D² kernel networks and D base intensity networks with random parameters
  3. Forward pass: Compute ˆλ*d(t) for sampled events using current network parameters
  4. Compute loss: Calculate negative log-likelihood on current batch
  5. Backward pass: Compute gradients of loss w.r.t. all network parameters
  6. Update parameters: Apply Adam update rules to adjust network parameters
  7. Early stopping: Monitor validation loss and stop when it stops improving

- Design tradeoffs:
  - Neural network architecture: More neurons increase approximation capacity but also increase computational cost and risk of overfitting
  - Learning rates: Different learning rates for hidden and output layers can accelerate convergence but require careful tuning
  - Batch size: Larger batches provide more stable gradients but require more memory and may converge to sharper minima

- Failure signatures:
  - Training loss decreases but validation loss increases: Overfitting, reduce network complexity or apply regularization
  - Both training and validation loss plateau at high values: Poor initialization, learning rates too low, or insufficient network capacity
  - Numerical instability in gradient computations: Check for exploding/vanishing gradients, consider gradient clipping
