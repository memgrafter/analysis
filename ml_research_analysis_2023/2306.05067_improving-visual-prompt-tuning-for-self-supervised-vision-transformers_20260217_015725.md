# Improving Visual Prompt Tuning for Self-supervised Vision Transformers

## Quick Facts
- arXiv ID: 2306.05067
- Source URL: https://arxiv.org/abs/2306.05067
- Reference count: 34
- Primary result: Gated Prompt Tuning outperforms VPT on fine-grained classification, visual task adaptation, and semantic segmentation for MAE and MoCo v3 self-supervised ViTs

## Executive Summary
Visual Prompt Tuning (VPT) often underperforms when applied to self-supervised Vision Transformers (ViTs) because prompt tokens interact with all ViT blocks, causing them to focus on irrelevant information for the task. The authors propose Gated Prompt Tuning, which learns a gate for each ViT block to control how much that block influences the prompt tokens. This allows prompts to selectively focus on blocks that are most relevant for the task. The method also introduces Adaptive Attention Shaping, which adjusts attention scores within ViT blocks using learnable temperatures to further improve prompt effectiveness.

## Method Summary
The proposed method learns two sets of parameters: gate values γ₁...γₗ₋₁ for each ViT block (except the first) and temperature values τ₁...τₗ for each block. For each block l, the gated prompt representation is computed as a convex combination of the previous prompt representation and the current block's output, weighted by the gate value. Temperature scaling is then applied to reshape self-attention scores within each block. Only the prompt tokens, gates, and temperatures are trained while the ViT backbone remains frozen.

## Key Results
- Gated Prompt Tuning improves over VPT-shallow and VPT-deep on five FGVC datasets
- State-of-the-art results on VTAB-1K for both MAE and MoCo v3 pretrained ViTs
- Achieves 48.0 mIoU on ADE20K semantic segmentation, outperforming VPT baselines

## Why This Works (Mechanism)

### Mechanism 1
Prompts in self-supervised ViTs are influenced by all blocks, but each block encodes different information hierarchies depending on pretraining and task relevance. If prompts interact with irrelevant blocks, they get "disturbed" by task-irrelevant information.

### Mechanism 2
Learnable gates can selectively control which blocks influence prompt tokens. Each gate value determines the convex combination of previous prompt representation and current block's output, allowing prompts to focus on blocks requiring task-specific steering.

### Mechanism 3
Adaptive Attention Shaping with learnable temperatures improves prompt effectiveness by adjusting attention sharpness. Temperature scaling reshapes self-attention scores, making them sharper or smoother to aid prompts in encoding beneficial task instructions.

## Architecture Onboarding

- Component map: ViT backbone (frozen) with L transformer blocks -> Learnable prompt tokens (100 for shallow, 10 per block for deep) -> Learnable gate values γ₁...γₗ₋₁ for each block -> Learnable temperature values τ₁...τₗ for each block -> Task-specific classification head

- Critical path:
  1. Initialize prompt tokens, gates, and temperatures
  2. For each block l: compute gate gₗ, pass input through block, compute gated prompt representation
  3. Apply temperature scaling to attention scores
  4. Use final prompt representation for classification
  5. Backpropagate only through prompt tokens, gates, and temperatures

- Design tradeoffs:
  - Gate values are constrained to [0,1] via sigmoid, limiting extreme gating
  - Temperature scaling affects all attention heads equally in a block
  - Adding gates and temperatures increases parameters but improves efficiency vs. more prompt tokens

- Failure signatures:
  - Gates all converging to 0 or 1 indicates poor selective learning
  - Temperature values becoming extreme (very large or small) suggests instability
  - Performance worse than VPT-shallow suggests gating is harming rather than helping

- First 3 experiments:
  1. Train with only gated prompt tuning (no temperature scaling) on CUB dataset to verify gating improves over VPT-shallow
  2. Train with only temperature scaling (no gating) on CUB to verify attention shaping helps
  3. Combine both mechanisms and test on ADE20K segmentation to verify gains transfer to dense prediction tasks

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal strategy for selecting the number and distribution of learnable gates across ViT blocks to maximize task performance?
- Basis in paper: [inferred] The authors show that gating can significantly improve performance but do not explore the impact of different gate configurations or numbers.
- Why unresolved: The paper uses a fixed number of gates (one per block) without exploring alternatives or justifying this choice theoretically.
- What evidence would resolve it: Systematic ablation studies varying the number and distribution of gates, or theoretical analysis of how gate placement affects information flow through the network.

### Open Question 2
- Question: How does the performance of Gated Prompt Tuning scale with larger, more complex ViT architectures and datasets?
- Basis in paper: [inferred] The authors only test on ViT-B/16 and relatively standard datasets, without exploring scalability to larger models or more challenging tasks.
- Why unresolved: The paper's experimental scope is limited to specific model sizes and benchmark datasets.
- What evidence would resolve it: Testing on larger ViT variants (e.g., ViT-L/16, ViT-H) and more challenging datasets or real-world applications.

### Open Question 3
- Question: What is the relationship between the learned gate values and specific task-relevant features or concepts in the data?
- Basis in paper: [explicit] The authors observe that different tasks activate different blocks but do not analyze what features these blocks correspond to.
- Why unresolved: The paper focuses on performance metrics rather than interpretability or feature analysis.
- What evidence would resolve it: Feature visualization techniques showing what each gated block learns to attend to for different tasks, or correlation analysis between gate values and interpretable data features.

## Limitations

- The gating mechanism's effectiveness depends heavily on the pretraining method, with unclear generalizability across different self-supervised learning approaches
- The Adaptive Attention Shaping applies the same temperature scaling across all attention heads within a block, which may not be optimal
- The paper doesn't explore how sensitive the gating values are to initialization or whether they transfer between tasks

## Confidence

- **High Confidence**: The observation that VPT underperforms on self-supervised ViTs compared to supervised models - well-supported by empirical results
- **Medium Confidence**: The core hypothesis that selective block interaction improves prompt effectiveness - supported by results but could also be explained by increased model capacity
- **Low Confidence**: The specific mechanism of Adaptive Attention Shaping improving prompt effectiveness - novel approach lacking direct empirical validation

## Next Checks

1. **Ablation on parameter count**: Compare Gated Prompt Tuning against a variant with the same number of additional parameters but without gating or temperature scaling to isolate whether improvements come from selective mechanisms or increased capacity.

2. **Cross-task gate transfer**: Train gates on one task (e.g., CUB classification), freeze them, and evaluate on a different task (e.g., Cars classification) to determine if the gating mechanism learns task-specific or more general patterns.

3. **Visualization of gate evolution**: Track gate values throughout training to verify they actually learn selective patterns rather than simply saturating to fixed values, and correlate these patterns with task performance improvements.
