## Executive Summary
This paper addresses the challenge of high variance in training targets for denoising score-matching (DSM) in diffusion models. The authors propose the Stable Target Field (STF) objective, which incorporates a reference batch to calculate weighted conditional scores as more stable training targets. By trading bias for reduced variance, STF asymptotically approaches unbiasedness as reference batch size increases. The method is theoretically grounded with proofs of asymptotic unbiasedness and trace-of-covariance reduction, while empirically demonstrating improved image quality, stability, and training speed across various diffusion models and datasets.

## Method Summary
The Stable Target Field (STF) objective addresses high variance in denoising score-matching by introducing a reference batch mechanism. Instead of using individual noisy samples as training targets, STF calculates weighted conditional scores using both the current batch and a reference batch. This approach creates more stable training targets by averaging over multiple samples, reducing the variance in the score estimation process. The method is particularly effective when combined with existing techniques like EDM, and can be applied to various diffusion model architectures without requiring architectural changes.

## Key Results
- Achieves state-of-the-art FID of 1.90 on CIFAR-10 unconditional generation with 35 network evaluations when combined with EDM
- Reduces variance in training targets through reference batch mechanism while maintaining asymptotic unbiasedness
- Improves training stability and speed across multiple diffusion model architectures and datasets

## Why This Works (Mechanism)
The Stable Target Field objective works by leveraging multiple reference samples to compute more stable conditional scores. Traditional DSM uses individual noisy samples as training targets, which can lead to high variance in the estimated scores. STF mitigates this by incorporating a reference batch, where the weighted average of conditional scores across multiple samples provides a more stable target. This approach trades some bias (which diminishes with larger reference batch sizes) for significant variance reduction. The theoretical framework ensures that as the reference batch size grows, the bias approaches zero while the variance reduction becomes more pronounced, leading to more stable and efficient training.

## Architecture Onboarding

**Component Map**: Input Batch -> Reference Batch Integration -> Weighted Conditional Score Calculation -> STF Loss Computation

**Critical Path**: The core training loop where STF loss is computed and backpropagated through the network. The reference batch integration is the key differentiator from standard DSM.

**Design Tradeoffs**: STF trades increased computational overhead (due to reference batch processing) for reduced variance in training targets. Larger reference batch sizes reduce bias but increase memory and computation requirements.

**Failure Signatures**: If reference batch size is too small, variance reduction benefits are minimal. If too large, computational overhead may outweigh benefits. Poor weight initialization can lead to unstable early training despite STF's variance reduction.
