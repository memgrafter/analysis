# An evaluation framework for dimensionality reduction through sectional curvature

## Quick Facts
- arXiv ID: 2303.09909
- Source URL: https://arxiv.org/abs/2303.09909
- Reference count: 21
- One-line primary result: Introduces the first non-trivial curvature-based evaluation metric for dimensionality reduction that captures global geometric structure preservation.

## Executive Summary
This work presents a novel evaluation framework for dimensionality reduction algorithms based on Riemannian geometry. The framework uses sectional curvature to quantify how well algorithms preserve the original data manifold's geometric properties after dimensionality reduction. By creating synthetic datasets with controllable curvature properties and evaluating six state-of-the-art algorithms (PCA, SVD, MDS, ISOMAP, t-SNE, UMAP), the authors demonstrate that their metric provides a more robust and geometrically meaningful evaluation than existing continuity-based measures like NPR.

## Method Summary
The framework generates synthetic datasets by immersing a 2D grid into R⁷ using parameterized curvature functions, creating controllable test cases. Dimensionality reduction algorithms are then applied to reduce to R². The evaluation metric computes the L²-norm difference between sectional curvatures of the original and reduced data, with lower values indicating better geometric preservation. The framework includes open-source Python packages for both the problem instance generator and the evaluation metric.

## Key Results
- UMAP and t-SNE perform best at preserving curvature compared to linear methods like PCA
- The metric provides more robust evaluation than NPR by capturing global geometric structure rather than just local neighborhood relationships
- The problem instance generator successfully creates synthetic datasets with controllable curvature properties for systematic evaluation

### Mechanism 1
- Claim: The metric captures true geometric structure preservation by comparing sectional curvatures before and after dimensionality reduction.
- Mechanism: The evaluation framework measures how well the pullback metric's sectional curvature is preserved, with lower curvature differences indicating better preservation of the original manifold's geometric properties.
- Core assumption: Preserving sectional curvature ensures the global topology of the data is maintained after dimensionality reduction.

- Claim: The problem instance generator creates controllable test cases by immersing R² into R⁷ using parameterized curvature functions.
- Mechanism: By controlling the curvature parameters θ and η, the generator produces synthetic datasets with varying geometric complexity, allowing systematic evaluation of algorithms across different manifold shapes.
- Core assumption: Immersing a simple grid structure into higher dimensions with controlled curvature creates representative test cases for evaluating dimensionality reduction algorithms.
- Evidence anchors:
  - [abstract] "To test this metric, the authors created a parameterized problem instance generator that produces synthetic datasets with controllable curvature properties."
  - [section 2.1] "The makegen generator returns a smooth function that is an immersion Φ: R^n → R^m with m > n whose image is an immersed sub-manifold M_Φ ⊆ R^m."

- Claim: The metric provides objective comparison beyond local neighborhood preservation by capturing global geometric structure.
- Mechanism: Unlike NPR which only measures local continuity, the sectional curvature metric evaluates how well the overall shape and bending of the manifold is preserved across the entire dataset.
- Core assumption: Global geometric preservation is more important than local neighborhood preservation for evaluating dimensionality reduction quality.

## Architecture Onboarding

- Component map:
  - Problem instance generator (makegen) → creates synthetic datasets with controllable curvature
  - Dimensionality reduction algorithms (PCA, SVD, MDS, ISOMAP, t-SNE, UMAP) → process the high-dimensional data
  - Curvature metric computation → evaluates the geometric preservation quality
  - Comparison and ranking system → aggregates results across different instances

- Critical path:
  1. Generate synthetic dataset with makegen using specified curvature parameters
  2. Apply dimensionality reduction algorithm to reduce R^m to R^n
  3. Compute sectional curvature differences between original and reduced data
  4. Aggregate results across multiple instances and parameter combinations

- Design tradeoffs:
  - Computational complexity: The curvature metric requires computing derivatives up to third order, making it more expensive than NPR
  - Dimensionality limitation: The framework is currently designed for reducing from R^7 to R^2, limiting applicability to other dimensional configurations
  - Interpolation stability: The accuracy depends heavily on the quality of the interpolation method used to estimate the unknown reduction function

- Failure signatures:
  - High curvature scores across all algorithms may indicate issues with the generator producing degenerate manifolds
  - Inconsistent rankings across different curvature types suggest the metric may be sensitive to specific geometric properties
  - Numerical instability in curvature computation points to problems with the interpolation or differentiation procedures

- First 3 experiments:
  1. Test the metric on simple cases: use flat curvature (θ=0) and verify all algorithms get similar low scores
  2. Evaluate a single algorithm (e.g., PCA) across different curvature types to verify it performs worse on curved manifolds
  3. Compare metric scores with NPR scores on the same dataset to validate the metric captures different properties

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the proposed sectional curvature metric compare to other emerging dimensionality reduction evaluation methods like geometric variance or topological persistence measures?
- Basis in paper: [inferred] The paper explicitly compares against NPR but does not evaluate against other geometric or topological evaluation metrics that have emerged since NPR.
- Why unresolved: The authors only benchmark against NPR, leaving open whether sectional curvature provides advantages over other geometric/topological evaluation frameworks.
- What evidence would resolve it: Direct comparison studies using geometric variance, persistent homology-based metrics, and other topological measures on the same synthetic datasets used in this paper.

### Open Question 2
- Question: What is the optimal interpolation method for estimating the pullback metric f*g when only finite point samples are available from dimensionality reduction algorithms?
- Basis in paper: [explicit] The authors mention using order 3 spline interpolation but note "stability of the interpolation is satisfactory" without exploring alternatives or determining optimality.
- Why unresolved: The paper uses a specific interpolation approach but doesn't systematically evaluate whether spline interpolation is optimal or if other methods (Gaussian processes, neural networks, etc.) would perform better.
- What evidence would resolve it: Systematic comparison of different interpolation methods on synthetic datasets with known ground truth curvature properties, measuring accuracy of curvature estimation.

### Open Question 3
- Question: How does the dimensionality reduction metric scale with increasing ambient dimension m in the embedding Φ: R^n → R^m?
- Basis in paper: [inferred] The experiments use m=7, but the theoretical framework allows arbitrary m>n. The authors don't investigate how performance or computational requirements change with higher m.
- Why unresolved: The paper doesn't explore the trade-offs between embedding dimension and metric reliability/computational cost, which is practically important for real-world applications.
- What evidence would resolve it: Experiments varying m (e.g., m=10, 20, 50) while keeping n fixed, measuring both metric accuracy and computational complexity to identify scaling relationships.

### Open Question 4
- Question: Can the sectional curvature metric be adapted to evaluate dimensionality reduction algorithms that output non-injective mappings or handle overlapping manifolds?
- Basis in paper: [inferred] The current framework assumes the pullback metric f*g0 is well-defined and invertible, but doesn't address cases where dimensionality reduction algorithms collapse distinct regions of the manifold.
- Why unresolved: The metric as formulated doesn't explicitly handle or penalize self-intersections or manifold overlaps that can occur in real dimensionality reduction, which could be important failure modes.
- What evidence would resolve it: Extension of the metric to incorporate measures of injectivity or overlap detection, validated on datasets where algorithms are known to produce self-intersections.

## Limitations
- The computational complexity of curvature calculations limits scalability to large datasets
- Current implementation is constrained to specific dimensional configurations (R⁷ to R²)
- Performance on real-world datasets with noise remains untested

## Confidence
- **High Confidence**: The core mechanism that sectional curvature captures global geometric properties is well-established in differential geometry
- **Medium Confidence**: Comparative performance results on synthetic data may not fully translate to real-world scenarios
- **Low Confidence**: Framework's ability to generalize beyond R⁷ to R² and sensitivity to interpolation methods are not well-established
