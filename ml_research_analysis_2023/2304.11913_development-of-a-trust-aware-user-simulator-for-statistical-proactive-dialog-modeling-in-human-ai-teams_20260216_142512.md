# Development of a Trust-Aware User Simulator for Statistical Proactive Dialog Modeling in Human-AI Teams

## Executive Summary
This paper presents a trust-aware user simulator designed to enhance the training of proactive dialog policies in human-AI team interactions. The simulator models user behavior by incorporating socio-demographic features and personality traits from corpus data. Two simulation methods were compared: complexity-based and task-step-based approaches. The task-step-based method demonstrated superior performance in capturing sequential dependencies in user interactions, as evidenced by lower Kullback-Leibler distances and mean square errors. The simulator integrates trust prediction to adapt dialog strategies, improving the realism of simulated user behavior. This research provides a valuable tool for exploring proactive strategies in human-AI collaboration, with potential applications in various domains requiring effective human-AI team coordination.

## Method Summary
The trust-aware user simulator leverages a corpus-based approach to model user behavior in human-AI team interactions. The simulator incorporates socio-demographic features and personality traits to capture user characteristics. Two simulation methods were developed and compared: a complexity-based method and a task-step-based method. The task-step-based method models user behavior based on sequential task steps, allowing for better representation of dependency relationships in dialog sequences. Trust prediction is integrated into the simulator to adapt dialog strategies based on predicted trust levels. The simulator's performance was evaluated using metrics such as Kullback-Leibler distance and mean square error to compare the effectiveness of the two simulation approaches in capturing user interaction patterns.

## Key Results
- Task-step-based simulation method outperformed complexity-based method in modeling sequential dependencies
- Lower Kullback-Leibler distances and mean square errors achieved with task-step-based approach
- Integration of trust prediction enhanced realism of simulated user behavior

## Why This Works (Mechanism)
The trust-aware user simulator works by leveraging corpus-based modeling of user behavior, incorporating socio-demographic and personality features to create realistic user profiles. The task-step-based simulation method captures sequential dependencies in user interactions more effectively than the complexity-based approach, allowing for more accurate representation of dialog flow. Trust prediction is integrated to adapt dialog strategies based on predicted trust levels, enhancing the realism of user behavior and improving the training of proactive dialog policies in human-AI teams.

## Architecture Onboarding

1. Corpus data preprocessing -> Feature extraction -> User profile generation
2. Trust prediction module -> Dialog strategy adaptation
3. Simulation method selection (complexity-based or task-step-based) -> User behavior modeling

Critical path: Corpus data -> Feature extraction -> User profile generation -> Simulation method -> User behavior modeling -> Trust prediction -> Dialog strategy adaptation

Design tradeoffs:
- Complexity-based vs. task-step-based simulation methods
- Balance between simulation accuracy and computational efficiency
- Integration of trust prediction vs. simpler user models

Failure signatures:

- Computational inefficiency in complex user profile generation
