# Complementary Learning Subnetworks for Parameter-Efficient Class-Incremental Learning

## Quick Facts
- arXiv ID: 2306.11967
- Source URL: https://arxiv.org/abs/2306.11967
- Authors: 
- Reference count: 40
- Key outcome: CLSNet achieves competitive results against state-of-the-art methods in class-incremental learning, especially in accuracy gain, memory cost, training efficiency, and task-order robustness

## Executive Summary
This paper addresses catastrophic forgetting in class-incremental learning (CIL) through a novel approach called CLSNet. The method leverages the synergy between two complementary learning subnetworks: a plastic CNN feature extractor and an analytical feed-forward classifier. By holistically controlling model parameters and ensuring decision boundaries fit new classes while retaining recognition of previously learned classes, CLSNet effectively mitigates forgetting. The approach is parameter-efficient, requiring only one matrix per task or one vector per class for knowledge retention.

## Method Summary
CLSNet jointly optimizes a plastic CNN feature extractor and an analytical SLFN classifier. The CNN uses a pre-trained backbone with frozen early layers and trainable last layer for representation augmentation. The SLFN classifier uses closed-form solutions with declarative parameters for each task. For each CIL session, the method augments representations by diversifying features through random mappings, then optimizes using ADMM to get optimal representations. The classifier is updated incrementally using an analytical solution that balances new task performance with knowledge retention of previous tasks, with a trade-off parameter λt managing forgetting of previously learned tasks.

## Key Results
- Achieves competitive accuracy against state-of-the-art methods on CIFAR-100 and ImageNet-Subset
- Demonstrates superior memory efficiency with minimal additional parameters per task
- Shows robustness to task ordering across multiple random task sequences
- Maintains high performance on both old and new tasks, indicating effective mitigation of catastrophic forgetting

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Joint optimization of plastic CNN feature extractor and analytical SLFN classifier prevents catastrophic forgetting by controlling decision boundary deformation.
- Mechanism: The plastic CNN feature extractor provides task-dependent knowledge without interference, while the analytical SLFN classifier incrementally integrates task-specific knowledge through closed-form solutions, preventing overwriting of previously learned parameters.
- Core assumption: Decision boundary distortion is the primary cause of catastrophic forgetting in CIL.
- Evidence anchors:
  - [abstract] "ensuring that the decision boundary learned fits new classes while retaining recognition of previously learned classes"
  - [section] "holistically controlling the parameters of a well-trained model, ensuring that the decision boundary learned fits new classes while retaining recognition of previously learned classes"
  - [corpus] Weak evidence - no direct corpus citations about decision boundary control mechanisms
- Break condition: If the decision boundary cannot be properly controlled due to severe class overlap or non-stationary data distributions.

### Mechanism 2
- Claim: Diverse representation augmentation restores optimal representations for task sequences.
- Mechanism: The method divides the last layer of the pre-trained CNN into n groups of random mapping features, then iteratively adjusts network parameters using ADMM to recover optimal representations for each task.
- Core assumption: Fixed representations from pre-trained models lack transferability across task sequences.
- Evidence anchors:
  - [section] "The discriminative information learned for old tasks may not be sufficiently discriminative between the incoming tasks... we design a new diverse representation augmentation strategy"
  - [section] "we first diversify knowledge by collecting multiple drifted representations; Then, we incrementally adjust the network parameters for representation augmentation"
  - [corpus] No direct evidence in corpus about representation augmentation techniques
- Break condition: If the ADMM optimization fails to converge or the random mapping features cannot capture sufficient diversity.

### Mechanism 3
- Claim: Declarative parameter plasticity enables selective forgetting of trivial tasks.
- Mechanism: The method implements memory fading through trade-off coefficients, where the most previously learned tasks are the first to be removed when network capacity is limited, allowing better learning of incoming tasks.
- Core assumption: Limited network capacity requires selective removal of inessential information.
- Evidence anchors:
  - [section] "Given a non-growing backbone, it is empirically investigated that CLSNet can innately manage the long/short-term memory of each seen task, e.g., graceful forgetting previously learned trivial tasks makes it suffice to train on incoming tasks better with limited network capacity"
  - [section] "we implement memory fading with a potential priority queue where the most previously learned tasks are the first to be removed"
  - [corpus] No corpus evidence about graceful forgetting mechanisms
- Break condition: If the priority queue implementation incorrectly identifies important tasks as trivial.
