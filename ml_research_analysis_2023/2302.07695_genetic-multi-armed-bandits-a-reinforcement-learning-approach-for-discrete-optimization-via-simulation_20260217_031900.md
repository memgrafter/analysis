# Genetic multi-armed bandits: a reinforcement learning approach for discrete optimization via simulation

## Quick Facts
- arXiv ID: 2302.07695
- Source URL: https://arxiv.org/abs/2302.07695
- Reference count: 7
- Combines MAB and GA for discrete stochastic optimization with logarithmic memory complexity

## Executive Summary
This paper introduces GMAB, a novel algorithm that integrates multi-armed bandit and genetic algorithm concepts to solve discrete stochastic optimization problems through simulation. The algorithm maintains full memory of all observations while using genetic operators for exploration and exploitation, achieving superior performance compared to existing methods. A tree-based memory implementation ensures efficient O(log n) complexity, and the method theoretically converges to global optima with probability 1 as simulation effort increases.

## Method Summary
GMAB combines multi-armed bandit and genetic algorithm approaches to address discrete stochastic optimization via simulation. The algorithm maintains full memory of all simulation observations and employs genetic operators for both exploration and exploitation. A tree-based memory structure provides O(log n) complexity, enabling efficient search while storing complete historical data. The method demonstrates convergence to global optima with probability 1 as simulation effort approaches infinity.

## Key Results
- Achieves superior performance compared to benchmark algorithms with fewer simulations needed
- Tree-based memory implementation maintains O(log n) complexity with respect to memory size
- Theoretical guarantee of convergence to global optima with probability 1 as simulation effort approaches infinity
- Maintains extremely low runtime due to efficient memory implementation

## Why This Works (Mechanism)
The algorithm succeeds by combining the exploration-exploitation balance of multi-armed bandits with the population-based search and genetic operators from genetic algorithms. Full memory retention allows the algorithm to leverage all historical observations for decision-making, while genetic operators enable both exploration of new solutions and exploitation of promising regions. The tree-based memory structure provides efficient access to stored observations, maintaining computational feasibility despite full memory retention.

## Foundational Learning

**Multi-armed bandit theory**: Framework for sequential decision-making under uncertainty; needed for balancing exploration vs exploitation in optimization; quick check: verify regret bounds hold for discrete problems.

**Genetic algorithms**: Population-based search using crossover and mutation operators; needed for maintaining solution diversity and escaping local optima; quick check: ensure genetic operators preserve solution feasibility.

**Tree-based data structures**: Hierarchical organization enabling efficient search and retrieval; needed for maintaining O(log n) memory complexity; quick check: verify balance properties under dynamic updates.

## Architecture Onboarding

**Component map**: Simulation engine -> Memory storage -> Genetic operators -> Selection mechanism -> Next action decision

**Critical path**: Simulation observation → Tree-based memory insertion → Genetic operator application → Selection of next arm → New simulation

**Design tradeoffs**: Full memory vs computational overhead (solved via tree structure); exploration vs exploitation balance (managed by genetic operators); solution quality vs runtime (optimized through O(log n) memory).

**Failure signatures**: Poor convergence indicates ineffective genetic operators or imbalanced exploration/exploitation; excessive memory growth suggests tree structure degradation; suboptimal solutions may indicate insufficient population diversity.

**First experiments**: 1) Verify tree insertion/removal maintains O(log n) complexity across varying dataset sizes. 2) Test genetic operator effectiveness on benchmark discrete functions. 3) Validate convergence behavior on problems with known global optima.

- Superior performance claims based on limited benchmark comparisons (3-4 algorithms) and relatively small-scale test instances
