# Automatic Readability Assessment for Closely Related Languages

## Quick Facts
- **arXiv ID**: 2305.13478
- **Source URL**: https://arxiv.org/abs/2305.13478
- **Reference count**: 22
- **Key outcome**: Cross-lingual readability assessment using n-gram overlap features outperforms mBERT embeddings for closely related Philippine languages

## Executive Summary
This paper addresses automatic readability assessment (ARA) for low-resource languages by leveraging linguistic similarity between closely related languages. The authors propose CrossNGO, a novel feature based on character n-gram overlap, and evaluate it alongside traditional features and mBERT embeddings across three Philippine languages (Tagalog, Bikol, Cebuano). Their experiments show that combining traditional features with CrossNGO significantly outperforms mBERT alone, and that including data from a closely related language improves model accuracy. The best models achieve state-of-the-art results for Tagalog (57.7%) and Cebuano (79.7%) and set a baseline for Bikol (79.3%).

## Method Summary
The authors collected readability corpora for three Philippine languages (Tagalog, Bikol, Cebuano) with 3 difficulty levels each, plus an English control dataset. They extracted traditional linguistic features, mBERT embeddings, and CrossNGO (character n-gram overlap between related languages). Random Forest classifiers were trained with 5-fold stratified cross-validation across singular, pairwise, and full cross-lingual setups. Performance was measured by classification accuracy.

## Key Results
- Traditional features extended with CrossNGO significantly outperform mBERT embeddings alone for low-resource languages
- Cross-lingual training with closely related languages improves model confidence and reduces misclassification
- Best models achieve state-of-the-art results for Tagalog (57.7%) and Cebuano (79.7%), and baseline for Bikol (79.3%)

## Why This Works (Mechanism)

### Mechanism 1
Using traditional features extended with CrossNGO significantly improves ARA models for low-resource languages compared to using mBERT embeddings alone. CrossNGO leverages character n-gram overlap between closely related languages to capture linguistic similarity at a granular level, while traditional features provide surface-level text complexity indicators. Together, they encode both surface and deep linguistic characteristics without relying on large language models.

### Mechanism 2
Including data from a closely related language in the training set improves model confidence and reduces misclassification between adjacent readability levels. Training on a multilingual dataset increases the effective sample size and provides more varied linguistic patterns, which helps the model generalize better and distinguish subtle differences between levels.

### Mechanism 3
For low-resource languages, conventional fine-tuning of mBERT underperforms compared to traditional feature-based models. mBERT fine-tuning relies on large-scale pre-training data and may not adapt well to small, domain-specific readability datasets without sufficient fine-tuning data or specialized pre-training.

## Architecture Onboarding

- **Component map**: Data ingestion -> Feature extraction (traditional + CrossNGO + mBERT) -> Random Forest training -> Stratified k-fold evaluation
- **Critical path**: 1) Collect and preprocess readability datasets 2) Extract traditional and CrossNGO features 3) Optionally extract mBERT embeddings 4) Train Random Forest with various feature combinations 5) Evaluate and compare across cross-lingual setups
- **Design tradeoffs**: Using Random Forest vs. deep learning: simpler, interpretable, but may miss complex patterns; CrossNGO vs. mBERT: more targeted for related languages, less resource-intensive; Data from related languages: increases sample size but assumes shared complexity patterns
- **Failure signatures**: Low accuracy on all setups: features not discriminative or model not learning; High variance between folds: small dataset, need more regularization or data; CrossNGO adds no value: languages not closely related enough
- **First 3 experiments**: 1) Train Random Forest with only traditional features on each language (l1→l1) to establish baseline 2) Add CrossNGO to traditional features and compare performance 3) Train with traditional + CrossNGO on [l1+l2]→l3 setup to test cross-lingual benefit

## Open Questions the Paper Calls Out

- **Open Question 1**: How would the performance of cross-lingual readability assessment models change if they were tested on non-fiction texts (e.g., news articles, academic papers) rather than fictional short stories? The study's focus on fictional short stories means there is no empirical evidence about model performance on different text genres, which could have different linguistic features and complexity patterns.

- **Open Question 2**: What is the impact of using more sophisticated traditional feature sets (e.g., lexical density, discourse-based features) on cross-lingual readability assessment performance for closely related languages? The authors acknowledge they were limited to basic handcrafted features due to lack of NLP tools for POS tagging, named entity recognition, etc. in the target languages.

- **Open Question 3**: How would the proposed CrossNGO feature perform when applied to speech data or conversational transcripts rather than written texts? The authors note that most linguistic literature on mutual intelligibility in Philippine languages discusses speech communication, but they specifically focus on written texts.

## Limitations

- CrossNGO effectiveness depends heavily on the degree of mutual intelligibility between languages, which was not quantitatively measured
- Small dataset sizes (especially for Bikol with only 150 samples) may not be representative and could lead to overfitting
- Use of default Random Forest parameters without optimization raises questions about whether reported performance is optimal

## Confidence

- **High confidence**: Traditional features + CrossNGO outperform mBERT alone for these specific languages
- **Medium confidence**: CrossNGO is generally useful for ARA in low-resource, closely related languages
- **Low confidence**: CrossNGO would work for any pair of closely related languages

## Next Checks

1. Test CrossNGO on a different language family (e.g., Romance or Slavic languages) to assess generalization beyond Philippine languages
2. Conduct a quantitative measurement of mutual intelligibility between the languages studied to establish a threshold for when CrossNGO is expected to be effective
3. Perform ablation studies to determine the minimum number of shared n-grams needed for CrossNGO to provide meaningful signal, and test sensitivity to noise in the n-gram list
