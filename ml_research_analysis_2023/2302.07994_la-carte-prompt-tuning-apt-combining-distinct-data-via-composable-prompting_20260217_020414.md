# À-la-carte Prompt Tuning (APT): Combining Distinct Data Via Composable Prompting

## Quick Facts

## Executive Summary
This paper introduces À-la-carte Prompt Tuning (APT), a novel approach that enables composing machine learning models at inference time from pre-trained prompts corresponding to distinct datasets. The method addresses key challenges in continual learning, including forgetting and model customization, by allowing users to select subsets of data sources dynamically during inference. APT leverages vision transformers with a modified attention mechanism to prevent interference between prompts while maintaining efficient inference. Experimental results demonstrate that APT achieves state-of-the-art performance on continual learning benchmarks, with accuracy within 5% of models trained on the full union of data sources.

## Method Summary
APT introduces a composable prompting framework where each dataset is associated with a distinct prompt token. The key innovation is a modified attention mechanism that allows multiple prompts to be combined at inference time without interference. During training, prompts are learned for each dataset independently, while the backbone remains frozen or partially trainable. At inference, users can select any subset of prompts to combine, enabling flexible model composition. The method employs a gating mechanism in the attention layer to control information flow between prompts, preventing catastrophic forgetting while maintaining task-specific knowledge. Experiments use vision transformers (VIT-B/16) with ImageNet21k and ALBEF pretraining as backbone architectures.

## Key Results
- Achieves state-of-the-art performance on Split CIFAR-100 and CORe50 continual learning benchmarks
- Maintains accuracy within 5% of models trained on the full union of data sources
- Demonstrates comparable training and inference costs to traditional single-dataset training
- Shows performance degradation with increasing number of data sources, but remains effective up to 20 sources

## Why This Works (Mechanism)
APT works by introducing a composable prompting architecture that decouples task-specific knowledge from shared representations. The modified attention mechanism acts as a selective filter, allowing only relevant information from each prompt to influence the output while preventing interference between different data sources. This design enables the model to maintain distinct knowledge representations for each dataset while allowing flexible composition at inference time. The gating mechanism ensures that prompts can be combined without catastrophic forgetting, as each prompt maintains its own learned parameters that remain stable during composition.

## Architecture Onboarding

Component Map: Input Image -> Backbone (ViT) -> Prompt Tokens -> Modified Attention Layer -> Output Classification

Critical Path: Image features extracted by backbone are combined with selected prompt tokens through the modified attention mechanism, which gates information flow to produce the final classification output.

Design Tradeoffs: The method trades some accuracy (within 5% of union-trained models) for flexibility and reduced computational cost during training. The modified attention adds complexity but enables composability without interference.

Failure Signatures: Performance degradation occurs with increasing number of prompts/data sources, suggesting scalability limitations. Potential interference between prompts when too many are combined simultaneously.

Three First Experiments:
1. Test APT performance on a single dataset to establish baseline accuracy without composability
2. Evaluate interference effects by combining prompts from semantically similar datasets
3. Measure inference time and memory overhead when combining multiple prompts

## Limitations
- Limited evaluation scope primarily focused on CIFAR-100 and CORe50 datasets
- Unclear generalizability to more complex vision tasks like object detection or segmentation
- Scalability concerns with increasing number of data sources beyond 20
- Modified attention mechanism not extensively analyzed for interpretability or unintended consequences
