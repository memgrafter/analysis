# Professional Certification Benchmark Dataset: The First 500 Jobs For Large Language Models

## Quick Facts
- arXiv ID: 2305.05377
- Source URL: https://arxiv.org/abs/2305.05377
- Reference count: 40
- Large language models tested on 1149 professional certification exams, with GPT-3 passing 39% and Turbo-GPT3.5 achieving 100% on OSCP exam

## Executive Summary
This study introduces a comprehensive benchmark dataset of 1149 professional certification exams, evaluating large language models on vocational readiness across diverse domains including cloud computing, cybersecurity, healthcare, finance, and sensory fields. The research compares zero-shot performance of GPT-3 and Turbo-GPT3.5 on multiple-choice questions, finding that Turbo-GPT3.5 significantly outperforms GPT-3 with median 60% better results. The benchmark reveals strong model performance in computer-related fields, healthcare, and non-technical domains, with particular excellence on the Offensive Security Certified Professional (OSCP) exam.

## Method Summary
The study benchmarks large language models using 1149 professional certification exams containing 6137 multiple-choice questions across diverse vocational domains. GPT-3 and Turbo-GPT3.5 are tested in a zero-shot manner without fine-tuning or exam preparation. Models receive a standardized prompt prefix format and temperature is set to 0 for deterministic output. The evaluation measures percentage of correct answers and compares against certification passing thresholds of 70% or higher.

## Key Results
- GPT-3 achieves 39% pass rate across 1149 professional certification exams without fine-tuning
- Turbo-GPT3.5 achieves 100% on Offensive Security Certified Professional (OSCP) exam and 70% on FINRA Series 6 financial exam
- Turbo-GPT3.5 shows median 60% better performance than previous models across benchmark domains

## Architecture Onboarding

### Component Map
GPT-3/Turbo-GPT3.5 API -> Prompt Processor -> Answer Formatter -> Performance Evaluator

### Critical Path
1. Exam question retrieval from dataset
2. Prompt formatting with model-specific prefix
3. API submission with temperature=0
4. Answer extraction and format validation
5. Correctness scoring against answer key

### Design Tradeoffs
- Zero-shot approach sacrifices potential performance gains from fine-tuning for baseline assessment
- Multiple-choice format enables automated scoring but may not capture practical skills
- Broad domain coverage trades depth for breadth in vocational competency assessment

### Failure Signatures
- Model outputs that don't follow "Answer: [insert]" format indicate prompt compliance issues
- Performance variance across API calls suggests temperature or model version inconsistencies
- Incomplete exam coverage suggests dataset retrieval or processing errors

### First Experiments
1. Verify prompt format compliance by testing model on sample questions and checking output structure
2. Confirm passing threshold calculation by manually scoring sample exam responses
3. Test API rate limiting by submitting small batches of questions and monitoring response times

## Limitations
- Exact API parameters and model versions used are not specified, affecting reproducibility
- No performance breakdown by individual domain or question type is provided
- Zero-shot methodology may underestimate capabilities that could be improved with minimal fine-tuning

## Confidence
- **High confidence**: Open-sourced benchmark dataset contains 1149 professional certification exams with 6137 multiple-choice questions
- **Medium confidence**: Reported performance metrics for GPT-3 and Turbo-GPT3.5 based on zero-shot testing methodology
- **Low confidence**: Claims about broad competency across all listed domains lack granular performance data
