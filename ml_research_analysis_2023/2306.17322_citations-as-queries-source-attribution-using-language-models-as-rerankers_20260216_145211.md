# Citations as Queries: Source Attribution Using Language Models as Rerankers

## Quick Facts
- arXiv ID: 2306.17322
- Source URL: https://arxiv.org/abs/2306.17322
- Reference count: 12
- Key result: Semi-supervised BART reranking achieves 0.94 Recall@10 on source attribution

## Executive Summary
This paper studies source attribution, the task of finding which documents were used to create another text. The authors fine-tune language models to rerank candidate sources retrieved by BM25, experimenting with two datasets - Wikipedia citations and medieval Arabic texts. They explore different degrees of supervision from fully supervised to semi-supervised, finding that semi-supervised methods can achieve near-full supervision performance while avoiding costly span-level annotation. The results demonstrate the value of fine-tuning for source attribution and the potential of semi-supervised methods.

## Method Summary
The paper operationalizes source attribution as a two-stage retrieval-reranking problem. BM25 retrieves candidate sources from a document collection, then fine-tuned language models rerank these candidates. The authors experiment with different supervision levels: fully supervised (requiring annotated source spans), semi-supervised (using BM25 top results as proxy sources), and unsupervised. Models include embedding similarity using BERT, BART generator, and RAG. The approach is tested on Wikipedia citations and medieval Arabic text reuse datasets.

## Key Results
- Semi-supervised BART reranking achieves 0.94 Recall@10 on Wikipedia dataset
- Fully supervised methods reach 0.97 Recall@10, showing semi-supervised approach is nearly as effective
- Untuned BERT embedding similarity serves as weak baseline at 0.49 Recall@10
- RAG models underperform expectations when partially-frozen due to hardware constraints

## Why This Works (Mechanism)

### Mechanism 1
Semi-supervised BART reranking achieves strong performance because it learns to copy relevant source text to target spans without requiring full span-level annotation. The model is trained to predict masked target spans conditioned on source documents, using the top-ranked BM25 source as a proxy for the true source.

### Mechanism 2
Generative models like BART learn complex source-target relationships beyond simple copying by transforming source text appropriately for the target context. The model learns to generate masked portions of target documents conditioned on complete source documents, capturing paraphrasing and summarization patterns.

### Mechanism 3
Embedding similarity using BERT provides a strong baseline because topically similar documents are likely to be used as sources. The model computes cosine similarity between BERT embeddings of target and candidate source documents, assuming sources used to write a text will be topically similar.

## Architecture Onboarding

- Component map: Document → BM25 retrieval → Reranking model → Ranked sources → Evaluation
- Critical path: Query document → BM25 retrieval → Fine-tuned reranker → Top-ranked sources
- Design tradeoffs:
  - Fully supervised vs. semi-supervised: Full supervision provides better performance but requires costly span-level annotations; semi-supervised reduces annotation burden with minimal performance loss
  - Model complexity vs. performance: Simple embedding similarity is fast but weak; generative models are powerful but computationally expensive
  - Domain specificity vs. generalization: Wikipedia's structured citations allow simpler approaches; Maqrizi's complex reuse requires more sophisticated models
- Failure signatures:
  - Poor baseline BM25 recall (<0.6) suggests the retrieval stage needs improvement before reranking
  - Similar performance between untuned BERT and RAG indicates the reranking model isn't learning meaningful patterns
  - Large gap between semi-supervised and fully supervised performance suggests the baseline retrieval isn't providing useful supervision signals
- First 3 experiments:
  1. Run baseline BM25 retrieval on Wikipedia dataset and verify Recall@10 ≈ 0.64 as reported
  2. Implement semi-supervised BART reranking using BM25 top result as proxy source and compare performance to baseline
  3. Test embedding similarity baseline using pretrained BERT on Maqrizi dataset to verify the performance degradation reported

## Open Questions the Paper Calls Out

### Open Question 1
How do semi-supervised methods for source attribution perform on larger, more diverse datasets compared to fully supervised methods? The paper shows promising results on Wikipedia and Maqrizi datasets but notes further work on larger datasets is needed to validate generalizability.

### Open Question 2
Can unsupervised methods like RAG, with better hardware and full generator fine-tuning, achieve competitive performance in source attribution tasks? The paper's partially-frozen RAG model performed poorly, suggesting full fine-tuning with better hardware could improve performance.

### Open Question 3
How does the performance of fine-tuned BERT models for embedding source and target documents compare to other reranking methods in source attribution tasks? The paper suggests this as a potential approach but did not directly evaluate it as a reranking method.

## Limitations

- Evaluation limited to two specific datasets (Wikipedia and medieval Arabic texts) may not generalize to other domains
- Performance gap between semi-supervised (0.94) and fully supervised (0.97) methods suggests some cases still require full annotation
- RAG models underperformed expectations, but the paper provides limited analysis of why this occurred

## Confidence

- Semi-supervised BART achieving near-full-supervision performance: Medium confidence
- Embedding similarity methods as weak baselines: High confidence  
- RAG models underperforming expectations: Medium confidence
