# ROSARL: Reward-Only Safe Reinforcement Learning

## Quick Facts
- arXiv ID: 2306.00035
- Source URL: https://arxiv.org/abs/2306.00035
- Reference count: 23
- Key outcome: Safe RL algorithm that guarantees optimal policies minimize probability of reaching unsafe states through a theoretically derived reward penalty

## Executive Summary
This paper introduces ROSARL, a novel safe reinforcement learning approach that addresses the challenge of avoiding unsafe states while maintaining task performance. The method establishes a theoretical upper bound (Minmax penalty) on rewards for unsafe states that guarantees optimal policies minimize the probability of reaching those states. Unlike traditional safe RL methods that require safety constraints or demonstrations, ROSARL operates solely through reward modification based on the controllability and diameter of the MDP environment.

## Method Summary
The method works by estimating a Minmax penalty online during learning using value function estimates from any off-the-shelf RL algorithm. This penalty is calculated as the minimum of the observed reward range and the difference between value function estimates. When the agent encounters an unsafe state, the reward is replaced with this penalty, effectively disincentivizing unsafe behavior. The approach is theoretically grounded in MDP theory and can be integrated with any value-based RL method. Experiments demonstrate effectiveness in both tabular gridworld environments and high-dimensional continuous control tasks.

## Key Results
- The Minmax penalty is derived as a theoretical upper bound on rewards for unsafe states based on MDP controllability and diameter
- Online estimation of the penalty using value function estimates is effective during learning
- Experiments show reduced failure rates in Safety Gym PointGoal1-Hard and Lava Gridworld environments compared to baselines
- The method maintains task performance while significantly improving safety outcomes

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The Minmax penalty is the upper bound of rewards at unsafe states that guarantees safe optimal policies.
- **Mechanism:** By assigning a penalty of ¯RMIN to unsafe states, the optimal policy minimizes the probability of reaching those states. This is derived from the controllability and diameter of the MDP.
- **Core assumption:** The MDP is controllable (C > 0) and the set of unsafe states is non-empty.
- **Evidence anchors:**
  - [abstract] "we are interested in finding the upper bound of rewards at unsafe states whose optimal policies minimises the probability of reaching those unsafe states"
  - [section 3] "Theorem 1 (Safety Bounds) Consider a controllable MDP... If ¯R(s, a, s′) < ¯RMIN for all s′ ∈ G !, then π∗ is safe for all R"
  - [corpus] Weak correlation; no direct mention of Minmax penalty or controllability-diameter relationship.
- **Break condition:** If the MDP is not controllable (C = 0), the Minmax penalty cannot be defined and the theorem does not apply.

### Mechanism 2
- **Claim:** The Minmax penalty can be estimated online using value function estimates.
- **Mechanism:** The algorithm updates RMIN and RMAX based on observed rewards, and VMIN and VMAX based on value function estimates. The Minmax penalty is then calculated as min(RMIN, VMIN - VMAX).
- **Core assumption:** The value function estimates converge to the true values during learning.
- **Evidence anchors:**
  - [abstract] "can be estimated online using value function estimates during learning"
  - [section 4] "we propose an approach that makes use of the value function being learned by any off-the-shelf model-free RL algorithm"
  - [corpus] No direct mention of online estimation or value function usage.
- **Break condition:** If the value function estimates do not converge or are highly inaccurate, the Minmax penalty estimate will be unreliable.

### Mechanism 3
- **Claim:** Using the Minmax penalty results in safer policies than existing baselines in high-dimensional continuous control tasks.
- **Mechanism:** The penalty disincentivizes unsafe behavior by assigning the maximum possible penalty for entering unsafe states, leading the agent to learn safer policies.
- **Core assumption:** The environment has a clear distinction between safe and unsafe states, and the penalty is large enough to deter unsafe behavior.
- **Evidence anchors:**
  - [abstract] "Experiments show that using the Minmax penalty in both tabular and high-dimensional continuous control tasks results in safer policies than existing baselines"
  - [section 5.3] "TRPO-Minmax uses the estimated Minmax penalty to dramatically reduce the failure rate"
  - [corpus] No direct comparison with baselines or mention of failure rates.
- **Break condition:** If the environment is highly stochastic and the penalty is not large enough, the agent may still frequently enter unsafe states.

## Architecture Onboarding

- **Component map:**
  MDP environment with safe and unsafe states -> Value function approximator -> Minmax penalty estimator -> RL algorithm -> Safety mechanism
- **Critical path:**
  1. Agent interacts with environment and receives reward
  2. Value function is updated based on the experience
  3. Minmax penalty estimator updates RMIN, RMAX, VMIN, VMAX
  4. Minmax penalty is calculated as min(RMIN, VMIN - VMAX)
  5. If the next state is unsafe, the reward is replaced with the Minmax penalty
  6. RL algorithm updates the policy and value function using the modified reward
- **Design tradeoffs:**
  - Larger Minmax penalty leads to safer policies but may slow down learning
  - Smaller Minmax penalty allows faster learning but may result in unsafe behavior
  - The choice of RL algorithm affects the efficiency and stability of learning
- **Failure signatures:**
  - High failure rate despite using the Minmax penalty (penalty may be too small or environment too stochastic)
  - Slow learning progress (penalty may be too large, discouraging exploration)
  - Value function estimates not converging (may lead to unreliable Minmax penalty estimates)
- **First 3 experiments:**
  1. Implement the Minmax penalty estimator and integrate it with a simple RL algorithm (e.g., Q-learning) in a tabular gridworld environment with a single unsafe state.
  2. Vary the size of the Minmax penalty and observe its effect on the failure rate and learning efficiency.
  3. Test the algorithm in a more complex environment with multiple unsafe states and compare its performance to a baseline RL algorithm without the Minmax penalty.

## Limitations

- The approach assumes known unsafe absorbing states, which may not hold in real-world environments with uncertain safety constraints
- The theoretical guarantees rely on controllability assumptions that may be violated in complex or stochastic environments
- The diameter-based penalty calculation may be overly conservative in large state spaces, potentially slowing down learning

## Confidence

- Theoretical safety guarantees (High): The derivation of the Minmax penalty bound is mathematically rigorous and well-established
- Online estimation effectiveness (Medium): While the mechanism is sound, the practical performance depends heavily on value function convergence quality
- Baseline comparisons (Medium): Results show improvement over baselines, but the experimental setup may favor the proposed method
