## Executive Summary
This paper introduces Bayesian Kernelized Tensor Factorization (BKTF) as a novel surrogate model for Bayesian optimization. Unlike standard Gaussian processes with simple kernels, BKTF leverages a low-rank tensor CP decomposition with GP priors on latent basis functions to capture complex, nonstationary, nonseparable, and multimodal objective functions. The method enables efficient MCMC inference and provides full uncertainty quantification, achieving superior performance on benchmark optimization functions and machine learning hyperparameter tuning tasks, particularly with limited initial data and budget.

## Method Summary
BKTF uses a low-rank CP tensor decomposition where each tensor element is modeled as a product of latent basis functions with GP priors. The multilinear kernel allows nonstationary and nonseparable structure through location-specific basis functions. MCMC inference (Gibbs sampling for basis functions, slice sampling for hyperparameters) approximates the posterior distribution, enabling computation of mean and variance tensors for acquisition function evaluation. The method is integrated into Bayesian optimization via an Upper Confidence Bound (UCB) acquisition function.

## Key Results
- BKTF achieves faster convergence and superior performance compared to standard GP-based surrogates on benchmark optimization functions
- The method shows better performance in machine learning hyperparameter tuning, particularly when initial data and budget are limited
- BKTF successfully captures nonstationary, nonseparable, and multimodal objective functions that challenge standard GP surrogates

## Architecture Onboarding

- Component map:
  Input (Cartesian product space) -> CP Tensor Decomposition (with GP priors) -> MCMC Inference (Gibbs + Slice sampling) -> Posterior Tensor Distribution -> Mean/Variance Tensors -> Bayesian UCB Acquisition -> Next Query Point

- Critical path:
  1. Define Cartesian product space and initialize with observed data
  2. Perform MCMC inference to approximate posterior of tensor decomposition
  3. Compute mean and variance tensors from MCMC samples
  4. Define Bayesian UCB acquisition function
  5. Find next query point by maximizing acquisition function
  6. Evaluate function at new point and repeat

- Design tradeoffs:
  - Tensor rank (R): Higher rank allows more complex function approximation but increases computational cost
  - Interpolation points (md): More points provide finer resolution but increase tensor size exponentially
  - MCMC sample size: More samples provide better posterior approximation but increase computational cost
  - Kernel choice: Different kernels capture different function structures (e.g., Matérn vs SE)

- Failure signatures:
  - Poor function approximation: BKTF fails to capture key features of the objective function
  - Slow convergence: MCMC inference takes too long or fails to converge
  - Suboptimal acquisition: Uncertainty quantification is poor, leading to ineffective exploration-exploitation tradeoff
  - Computational issues: Tensor reconstruction becomes prohibitive for high-dimensional problems

- First 3 experiments:
  1. Implement BKTF surrogate for a simple 2D benchmark function (e.g., Branin) and compare with GP surrogate
  2. Vary the tensor rank and interpolation points to understand their impact on performance
  3. Test BKTF on a higher-dimensional function (e.g., Griewank with D=3) to evaluate scalability

## Limitations
- BKTF's computational and storage costs become prohibitive when tensor dimensionality increases, limiting scalability to high-dimensional problems
- The method requires manual selection of CP rank R, which demands prior knowledge about the problem structure
- Current implementation requires full tensor reconstruction for acquisition function computation, which is computationally expensive
