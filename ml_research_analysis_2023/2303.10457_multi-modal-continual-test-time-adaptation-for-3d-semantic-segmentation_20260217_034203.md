# Multi-Modal Continual Test-Time Adaptation for 3D Semantic Segmentation

## Quick Facts
- arXiv ID: 2303.10457
- Source URL: https://arxiv.org/abs/2303.10457
- Reference count: 40
- Key outcome: CoMAC achieves state-of-the-art performance, outperforming previous methods by 6.9% on the more challenging benchmark

## Executive Summary
This paper addresses the challenge of adapting multi-modal networks to dynamic target domains without source data access for 3D semantic segmentation. The authors propose CoMAC, which employs an adaptive dual-stage mechanism to generate reliable cross-modal predictions by attending to the more reliable modality based on class-wise feature-centroid distance. The method introduces class-wise momentum queues to update centroids for adaptation while preventing catastrophic forgetting through stochastic restoration of pseudo-source features.

## Method Summary
CoMAC implements a continual test-time adaptation framework for multi-modal 3D semantic segmentation. The method uses pre-trained 2D (UNet with ResNet-34) and 3D (SCN based on UNet) networks, applying intra-modal prediction aggregation (iMPA) with centroid-based weighting and inter-modal pseudo-label fusion (xMPF) for cross-modal reliability estimation. Class-wise momentum queues (CMQs) store confident target features and enable stochastic restoration of pseudo-source features to balance adaptation and knowledge preservation. The framework operates in a one-pass protocol with immediate inference for each sample, using mean Intersection-over-Union (mIoU) as the evaluation metric.

## Key Results
- CoMAC outperforms previous methods by 6.9% on the more challenging benchmark
- Achieves superior performance across two new benchmarks introduced in the paper
- Demonstrates effective handling of catastrophic forgetting through CMQs and stochastic restoration

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The adaptive dual-stage mechanism in iMPA and xMPF effectively suppresses noisy predictions by attending to the more reliable modality during continual domain shifts.
- Mechanism: Uses centroid-based reliability estimation to weigh predictions from different modalities, giving more weight to predictions whose features are closer to the class-wise centroids in the latent space.
- Core assumption: Features close to centroids indicate higher reliability and less domain shift influence.
- Evidence anchors: [abstract], [section], [corpus] Weak - no direct evidence found for centroid-based reliability estimation specifically.
- Break condition: If the domain shift is so severe that both modalities become equally unreliable, or if centroids fail to adapt quickly enough to the target domain changes.

### Mechanism 2
- Claim: Class-wise momentum queues (CMQs) enable active adaptation to the target domain while preventing catastrophic forgetting.
- Mechanism: CMQs maintain momentum queues of confident target features for each class, which are used to update class-wise centroids. Pseudo-source features are stochastically restored to revisit source knowledge.
- Core assumption: Maintaining a balance between target domain adaptation and source knowledge preservation prevents catastrophic forgetting.
- Evidence anchors: [abstract], [section], [corpus] Weak - no direct evidence found for CMQs specifically.
- Break condition: If the stochastic restoration probability is too low (causing forgetting) or too high (preventing adaptation), or if confident feature selection becomes unreliable.

### Mechanism 3
- Claim: The cross-modal pseudo-label fusion effectively combines information from both modalities to generate more reliable pseudo-labels than single-modal approaches.
- Mechanism: xMPF fuses intra-modal predictions from both modalities based on their reliability scores, giving more weight to the reliable modality when they disagree.
- Core assumption: Combining information from both modalities when one is reliable can produce better pseudo-labels than relying on either modality alone.
- Evidence anchors: [abstract], [section], [corpus] Weak - no direct evidence found for cross-modal pseudo-label fusion specifically.
- Break condition: If both modalities become equally unreliable during domain shifts, or if the weighting mechanism fails to correctly identify the reliable modality.

## Architecture Onboarding

- Component map: Raw input → feature extraction → iMPA → xMPF → pseudo-labels → student network update → teacher network EMA update

- Critical path: Raw input → feature extraction → iMPA → xMPF → pseudo-labels → student network update → teacher network EMA update

- Design tradeoffs:
  - Number of augmentations vs. computational cost (more augmentations improve stability but increase computation)
  - CMQ size vs. memory usage (larger queues provide better adaptation but consume more memory)
  - Restoration probability vs. adaptation speed (higher probability prevents forgetting but slows adaptation)

- Failure signatures:
  - Both modalities showing low confidence simultaneously (indicates severe domain shift)
  - Centroids not updating (indicates CMQ not capturing confident target features)
  - Pseudo-labels not improving over time (indicates adaptation failure)

- First 3 experiments:
  1. Verify that features from the same class cluster around centroids in the source domain
  2. Test that CMQs correctly update centroids when target features are enqueued
  3. Confirm that xMPF gives more weight to the modality with features closer to centroids

## Limitations

- Stochastic restoration mechanism requires careful tuning of the restoration probability to balance between preventing catastrophic forgetting and allowing sufficient adaptation
