# Deep Predictive Coding with Bi-directional Propagation for Classification and Reconstruction

## Quick Facts
- arXiv ID: 2305.18472
- Source URL: https://arxiv.org/abs/2305.18472
- Authors: 
- Reference count: 33
- Key outcome: DBPC achieves classification accuracy comparable to other approaches while using significantly fewer parameters through bi-directional propagation and local learning rules

## Executive Summary
This paper introduces Deep Bi-directional Predictive Coding (DBPC), a learning algorithm that enables neural networks to perform classification and reconstruction tasks simultaneously using the same weights. DBPC extends predictive coding approaches by allowing both feedforward and feedback propagation of information, where each layer predicts the activities of neurons in both the previous and next layers. The method relies on locally available information for learning, supporting parallel updates across all layers in the network.

The performance of DBPC is evaluated using both fully connected networks (DBPC-FCN) and convolutional neural networks (DBPC-CNN) on the MNIST and FashionMNIST datasets. The results show that DBPC achieves classification accuracy comparable to other approaches while using significantly fewer parameters. For example, DBPC-FCN achieves 97.67% accuracy on MNIST with 1.225M parameters, compared to FIPC 3 which achieves 98.84% with 2.450M parameters. On the more challenging FashionMNIST dataset, DBPC-CNN achieves 91.61% accuracy using 1.004M parameters, outperforming PC-1 which achieves 89.00% with 0.532M parameters.

## Method Summary
DBPC implements a bi-directional propagation mechanism where each layer simultaneously predicts the activities of neurons in both the previous layer (using feedback propagation) and the next layer (using feedforward propagation). The errors in these predictions are used to update both the layer representations and the weights in parallel, relying only on locally available information. This allows all layers to be updated simultaneously without waiting for information from distant layers. The same set of weights is used for both feedforward and feedback propagation, enabling the network to perform both classification and reconstruction tasks without separate parameter sets. The algorithm is tested on MNIST and FashionMNIST datasets using both fully connected and convolutional architectures.

## Key Results
- DBPC-FCN achieves 97.67% accuracy on MNIST with 1.225M parameters, compared to FIPC 3 which achieves 98.84% with 2.450M parameters
- DBPC-CNN achieves 91.61% accuracy on FashionMNIST using 1.004M parameters, outperforming PC-1 which achieves 89.00% with 0.532M parameters
- Reconstruction performance measured by PSNR and SSIM shows DBPC-CNN achieves higher quality reconstructions compared to DBPC-FCN

- Claim: The network can perform both classification and reconstruction using the same weights through bi-directional propagation
- Mechanism: Each layer simultaneously predicts the activities of neurons in both the previous layer (using feedback propagation) and the next layer (using feedforward propagation). The errors in these predictions are used to update both the layer representations and the weights in parallel.
- Core assumption: The same set of weights can be used for both feedforward and feedback propagation without interfering with each other's performance.
- Evidence anchors: The abstract states that each layer learns to predict activities in previous and next layers allowing simultaneous classification and reconstruction tasks.

### Mechanism 2: Local learning rules enable parallel updates
- Claim: The learning algorithm relies only on locally available information, enabling in-parallel learning across all layers
- Mechanism: Each layer uses information from its immediate neighbors (previous and next layers) to compute errors and update its representations and weights. This local computation allows all layers to be updated simultaneously without waiting for information from distant layers.
- Core assumption: Local information is sufficient for each layer to learn effective representations for both classification and reconstruction tasks.
- Evidence anchors: The abstract mentions that DBPC relies on locally available information for learning, thus enabling in-parallel learning across all layers.

### Mechanism 3: Parameter efficiency through weight sharing
- Claim: The network achieves competitive performance with fewer parameters compared to other approaches
- Mechanism: By using the same weights for both classification and reconstruction tasks, the network eliminates the need for separate sets of parameters for each task. This weight sharing allows the network to achieve similar performance with a smaller overall parameter count.
- Core assumption: The shared weights can effectively capture the features needed for both classification and reconstruction without significant loss in performance.
- Evidence anchors: The abstract states that DBPC's classification and reconstruction performance is similar to other approaches but uses a significantly smaller network.

## Architecture Onboarding

- Component map: Input layer -> Hidden layers (bi-directional propagation) -> Output layer
- Critical path:
  1. Input data is fed into the network
  2. Feedforward propagation generates predictions about the next layer
  3. Feedback propagation generates predictions about the previous layer
  4. Errors in both predictions are computed locally
  5. Representations and weights are updated in parallel across all layers
  6. Output layer produces the classification result
  7. Feedback propagation from any layer can be used for reconstruction

- Design tradeoffs:
  - Using the same weights for both tasks reduces parameter count but may limit the network's ability to specialize for each task
  - Local learning enables parallel updates but may not capture global patterns as effectively as non-local methods
  - Bi-directional propagation adds complexity but allows for simultaneous classification and reconstruction

- Failure signatures:
  - Poor classification accuracy: The network may be too focused on reconstruction or vice versa
  - Poor reconstruction quality: The network may be too focused on classification or the feedback propagation may not be learning effectively
  - Slow convergence: The local learning rules may not be effective for the given dataset or network architecture

## Limitations
- Performance evaluation is limited to relatively simple datasets (MNIST and FashionMNIST), leaving questions about scalability to more complex visual recognition tasks
- Specific hyperparameter values (learning rates, λf, λb, βc, βr) are not explicitly provided, which could significantly impact the results
- Comparison is limited to a small set of baseline methods, not including state-of-the-art predictive coding approaches or traditional backpropagation-based networks
