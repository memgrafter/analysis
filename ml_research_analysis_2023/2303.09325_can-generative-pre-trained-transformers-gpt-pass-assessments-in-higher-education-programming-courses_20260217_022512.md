# Can Generative Pre-trained Transformers (GPT) Pass Assessments in Higher Education Programming Courses?

## Quick Facts
- arXiv ID: 2303.09325
- Source URL: https://arxiv.org/abs/2303.09325
- Reference count: 40
- Primary result: GPT-3.5 achieved 64.3% accuracy on MCQs and 66.4% on coding tasks, falling short of 70% passing thresholds.

## Executive Summary
This study evaluates GPT-3.5's ability to pass assessments in three Python programming courses, testing 599 exercises including MCQs and coding tasks. The model achieved 64.3% accuracy on MCQs and 66.4% on coding tasks, both below the 70% passing threshold. While capable of improving solutions using auto-grader feedback, GPT-3.5 struggles with multi-step reasoning, nuanced formatting, and complex problem decomposition. Results indicate GPT-3.5 can significantly assist learners but cannot yet serve as a complete end-to-end solution for programming education.

## Method Summary
The study manually collected 599 exercises from three Python programming courses (PE1, PE2, PPP) including MCQs and coding tasks. Text-davinci-003 was used with temperature=0.0 for MCQs and temperature=0.7 for coding tasks. Answers were submitted to an auto-grader, with coding solutions iteratively improved based on feedback. Performance was measured against reference solutions and course passing thresholds of 70%.

## Key Results
- GPT-3.5 achieved 64.3% accuracy on MCQs, below the 70% passing threshold
- Coding task performance reached 66.4% after feedback iteration, still below passing threshold
- Performance on MCQs with code snippets (56.7%) was significantly lower than plain MCQs (76.3%)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: GPT-3.5 performs better on plain MCQs than on MCQs containing code snippets
- Mechanism: The model processes natural language more fluently when not required to parse and reason about embedded code, reducing cognitive load in the transformer architecture
- Core assumption: Code snippets introduce additional complexity that exceeds GPT-3.5's current reasoning capacity
- Evidence anchors: Performance difference between code-containing MCQs (56.7%) and plain MCQs (76.3%)

### Mechanism 2
- Claim: GPT-3.5 can effectively use auto-grader feedback to improve coding task solutions
- Mechanism: The model iteratively refines its output by incorporating structured feedback, leveraging its generative capabilities to adjust code based on specified criteria
- Core assumption: Feedback is sufficiently specific and actionable for the model to parse and implement corrections
- Evidence anchors: Score improvement from 53.6% to 66.4% after feedback iteration on coding tasks

### Mechanism 3
- Claim: GPT-3.5 struggles with tasks requiring complex chains of reasoning
- Mechanism: The transformer architecture, while powerful for pattern matching, has limitations in executing multi-step logical deductions, especially when interleaving code and language
- Core assumption: Complex reasoning requires deeper contextual understanding than current GPT-3.5 can provide
- Evidence anchors: Struggles with nuanced output formatting, bug-fixing, refactoring, and real-world artifacts

## Architecture Onboarding

- Component map: Data collection -> Model configuration -> Evaluation pipeline -> Analysis
- Critical path: 1) Collect and format assessment exercises 2) Configure GPT-3.5 prompts 3) Submit to auto-grader and capture scores/feedback 4) Iterate on coding tasks based on feedback 5) Analyze results and identify patterns
- Design tradeoffs: Using text-davinci-003 instead of Codex for consistency across tasks, limiting prompt length to avoid truncation, setting temperature to 0.7 for coding tasks to encourage variation
- Failure signatures: Poor performance on MCQs with code snippets (below 60% accuracy), inability to pass any course module with >70% threshold, failure to improve coding solutions when feedback requires multi-step reasoning
- First 3 experiments: 1) Test GPT-3.5 on plain MCQs (no code) to establish baseline performance 2) Test GPT-3.5 on MCQs with code snippets to identify performance drop 3) Test GPT-3.5 on coding tasks without feedback to measure raw generation ability

## Limitations
- Evaluation based on single model version (text-davinci-003) rather than exploring full spectrum of available GPT variants
- Dataset represents only three courses from a single institution, limiting generalizability
- Auto-grader's feedback mechanism and evaluation criteria not fully specified

## Confidence

**High Confidence**: GPT-3.5 struggles with tasks requiring multi-step reasoning, well-supported by consistent underperformance on complex coding tasks and MCQs with code snippets.

**Medium Confidence**: GPT-3.5 can effectively use auto-grader feedback to improve coding solutions, supported by observed score improvements but extent across different feedback types remains unclear.

**Low Confidence**: GPT-3.5 cannot serve as complete end-to-end solution for programming education, based on single model version and limited dataset warranting further investigation.

## Next Checks
