# Transformer-based approaches to Sentiment Detection

## Quick Facts
- arXiv ID: 2303.07292
- Source URL: https://arxiv.org/abs/2303.07292
- Reference count: 2
- Four transformer models (BERT, RoBERTa, DistilBERT, XLNet) achieve 80.5%-82.6% accuracy on disaster sentiment detection task

## Executive Summary
This study evaluates transformer-based models for disaster-related sentiment detection in text. Using a dataset of 10,876 comments labeled as disaster or non-disaster, four models are fine-tuned and compared: BERT, RoBERTa, DistilBERT, and XLNet. RoBERTa achieves the highest test accuracy of 82.6%, while DistilBERT shows strong training performance at 98.5%. The research demonstrates that transformer architectures are effective for this task, with RoBERTa being particularly recommended for quality predictions. The study also highlights the importance of pre-processing techniques, vocabulary characteristics, and balanced labeling in influencing model performance.

## Method Summary
The study fine-tunes four transformer models (BERT, RoBERTa, DistilBERT, XLNet) on a binary disaster classification task using 10,876 labeled comments from Appen's dataset. The models are trained with Adam optimizer (6e-5 learning rate, 0.01 weight decay), batch size 64, 10 epochs, and 25% validation split. Text preprocessing removes URLs, HTML tags, symbols, punctuation, and emoticons. Each model is evaluated on test accuracy, with RoBERTa achieving 82.6% and DistilBERT showing 98.5% training accuracy but lower test performance at 80.5%.

## Key Results
- RoBERTa achieves highest test accuracy of 82.6% for disaster detection
- DistilBERT achieves 98.5% training accuracy but only 80.5% test accuracy
- BERT achieves 81.7% test accuracy
- XLNet achieves 80.9% test accuracy

- Mechanism: Pre-trained models already encode general language patterns; fine-tuning adapts these patterns to the specific vocabulary and context of disaster-related text.
- Core assumption: The pre-trained models have learned transferable linguistic features relevant to the target domain.
- Evidence anchors:
