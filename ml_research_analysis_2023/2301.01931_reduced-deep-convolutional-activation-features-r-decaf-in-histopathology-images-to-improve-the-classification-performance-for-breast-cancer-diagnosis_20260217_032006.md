# Reduced Deep Convolutional Activation Features (R-DeCAF) in Histopathology Images to Improve the Classification Performance for Breast Cancer Diagnosis

## Quick Facts
- arXiv ID: 2301.01931
- Source URL: https://arxiv.org/abs/2301.01931
- Reference count: 0
- Primary result: Proposed R-DeCAF framework achieves up to 4.3% improvement in classification accuracy compared to using all deep features, with best accuracy of 91.13% for 400× magnification data using AlexNet features reduced to 23 dimensions via PCA.

## Executive Summary
This study introduces Reduced Deep Convolutional Activation Features (R-DeCAF) to improve breast cancer classification in histopathology images. The method extracts deep features from pre-trained CNNs (AlexNet, VGG-16, VGG-19) and applies linear dimension reduction algorithms like PCA to capture informative features while reducing feature vector size. The framework demonstrates that using reduced features (FVS<120) not only improves classification performance but also reduces computational time, addressing the limitation that all deep features are not necessarily beneficial for classification tasks.

## Method Summary
The R-DeCAF framework extracts deep features from the first fully connected layer (FC6) of pre-trained CNNs using transfer learning with frozen weights. Linear dimensionality reduction techniques, particularly PCA, are applied to reduce the high-dimensional feature vectors (4096 dimensions) to smaller sizes (less than 120 dimensions) while maintaining cumulative explained variance between 15-35%. An SVM classifier with RBF kernel is then trained on the reduced features and evaluated using 10-fold cross-validation on the BreakHis dataset containing 7,909 histopathology images at various magnifications (40×, 100×, 200×, 400×).

## Key Results
- R-DeCAF achieves up to 4.3% improvement in classification accuracy compared to using all deep features
- Best accuracy of 91.13% obtained for 400× magnification using AlexNet features reduced to 23 dimensions via PCA (CEV=0.15)
- Using reduced features (FVS<120) significantly decreases computational time while improving or maintaining classification performance
- The optimal CNN architecture for feature extraction varies with magnification level, with AlexNet performing best at 400× magnification

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Linear dimensionality reduction methods like PCA can improve classification accuracy while reducing feature vector size for deep features in histopathology images.
- Mechanism: PCA transforms high-dimensional deep features into a lower-dimensional space while preserving maximum variance, capturing data essence and reducing noise/redundancy.
- Core assumption: First few principal components contain most informative features for classification, and some deep features are redundant or misleading.
- Evidence anchors:
  - [abstract] "linear approaches such as principal component analysis (PCA) represent a better combination among deep features and lead to a higher accuracy in the classification task using small number of features"
  - [section 4] "keeping all DeCAF features extracted from pre-trained AlexNet, VGG-16, and VGG-19 is not effective in the classification task"
- Break condition: If dataset contains features with very different variances or highly nonlinear classification boundaries, PCA may not capture most informative features.

### Mechanism 2
- Claim: Transfer learning with pre-trained CNNs can effectively extract deep features for breast cancer classification in histopathology images.
- Mechanism: Pre-trained CNNs like AlexNet, VGG-16, and VGG-19, trained on large natural image datasets, can be used as feature extractors for histopathology images, leveraging learned feature representations.
- Core assumption: Features learned by CNNs on natural images can be transferred to histopathology images as they share common visual patterns.
- Evidence anchors:
  - [abstract] "pre-trained CNNs such as AlexNet, VGG-16 and VGG-19 are utilized in transfer learning mode as feature extractors"
  - [section 3.2] "The advantage of transfer learning technique is to avoid a time-consuming procedure for training a CNN from scratch"
- Break condition: If histopathology images are significantly different from natural images, transferred features may not be relevant, leading to poor classification performance.

### Mechanism 3
- Claim: Magnification level of histopathology images affects classification accuracy due to differences in image complexity and information content.
- Mechanism: Higher magnification images (e.g., 400×) provide more detailed information, more effectively captured by simpler CNN architectures like AlexNet, while lower magnification images may benefit from deeper architectures like VGG-16 and VGG-19.
- Core assumption: Optimal CNN architecture for feature extraction depends on magnification level and complexity of histopathological images.
- Evidence anchors:
  - [section 4] "The magnification factor effect on the classification accuracy depending on complexity level of BC histopathological images"
- Break condition: If dataset contains images with similar complexity across different magnification levels, relationship between magnification and optimal architecture may not hold.

- What evidence would resolve it: Comparative analysis of R-DeCAF performance using different CEV ranges on multiple histopathological image datasets to identify the optimal balance between accuracy and FVS.

## Limitations

- The study relies on a single dataset (BreakHis) with specific image characteristics, which may not generalize to other histopathology datasets.
- The optimal CEV range (15-35%) and feature vector size (<120) are dataset-specific findings that may vary across different medical imaging tasks.
- Comparison with state-of-the-art methods is limited, as the paper only reports performance metrics without providing a comprehensive benchmark against recent deep learning approaches.

## Confidence

- High confidence: The mechanism of PCA improving classification accuracy by reducing noise and redundancy in deep features is well-established and supported by the experimental results.
- Medium confidence: The effectiveness of transfer learning with pre-trained CNNs for histopathology feature extraction is demonstrated, but the specific architecture choice (AlexNet vs VGG-16/19) for different magnification levels needs further validation on diverse datasets.
- Low confidence: The claim that reduced features (<120 dimensions) consistently outperform using all deep features across different medical imaging tasks requires additional experimental validation beyond breast cancer histopathology.
