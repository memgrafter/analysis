# Self-Interpretable Time Series Prediction with Counterfactual Explanations

## Quick Facts
- arXiv ID: 2306.06024
- Source URL: https://arxiv.org/abs/2306.06024

## Executive Summary
This paper presents CounTS, a novel self-interpretable time series prediction model that generates counterfactual explanations for time series data. The model uses variational Bayesian deep learning to infer latent variables representing confounders, then applies counterfactual inference while keeping these confounders fixed. CounTS outperforms state-of-the-art baselines in generating counterfactual explanations (measured by counterfactual change ratio) while maintaining comparable prediction accuracy on synthetic and real-world datasets.

## Method Summary
CounTS is a variational Bayesian deep learning model that learns causal relationships in time series data by inferring latent variables representing confounders. The model consists of an encoder network that maps time series to latent representations, a predictor network that maps latent variables to outputs, and inference networks that approximate posterior distributions. It uses an evidence lower bound (ELBO) objective with an additional supervision term to learn both generative and inference models. Counterfactual explanations are generated through an iterative gradient-based optimization process that intervenes on the input while keeping inferred confounders unchanged.

## Key Results
- CounTS outperforms state-of-the-art baselines in generating counterfactual explanations (measured by counterfactual change ratio)
- The model maintains comparable prediction accuracy to baseline models while providing explanations
- On real-world sleep study data, CounTS successfully identified and fixed exogenous variables to generate actionable counterfactual explanations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: CounTS can identify causal effects between time series input and output in the presence of confounding variables
- Mechanism: The model uses variational Bayesian deep learning to infer latent variables that represent confounders, then applies counterfactual inference (abduction-action-prediction) while keeping these confounders fixed
- Core assumption: The causal graph structure correctly captures the true data-generating process where exogenous variables affect both the input time series and the output
- Evidence anchors:
  - [abstract]: "CounTS uses a variational Bayesian deep learning approach to model causal relationships in time series data, inferring latent variables that represent confounders"
  - [section 4.2.2]: "Theorem 4.1 (Identifiability). Given the posterior distribution of exogenous variable p(ul, ug|x, y), the effect of action p(y = ycf |do(x = x′), ul, ug) can be identified using Ep(z|x′,ul,ug)[p ycf |z, ul, ug]"
  - [corpus]: Weak evidence - related papers focus on graph neural networks and time series explanations but none specifically address causal inference with confounders in time series
- Break condition: If the assumed causal graph structure is incorrect or if the posterior inference of confounders is poor, the identifiability guarantee fails

### Mechanism 2
- Claim: CounTS generates actionable and feasible counterfactual explanations
- Mechanism: By inferring and fixing the posterior distribution of confounding variables (ul, ug), the model searches for counterfactual inputs that change the prediction while keeping immutable variables unchanged
- Core assumption: The confounder variables captured by ul and ug correspond to immutable factors that should not be changed in counterfactual explanations
- Evidence anchors:
  - [abstract]: "CounTS outperforms state-of-the-art baselines in generating counterfactual explanations (measured by counterfactual change ratio) while maintaining comparable prediction accuracy"
  - [section 5.2]: "CounTS successfully identifies and fixes the exogenous variables u and m to generate actionable and feasible counterfactual explanations"
  - [section 5.4]: "CounTS managed to keep the first 30-second segment signal mostly unchanged, maintaining its periodicity and 7 breathing cycles"
- Break condition: If the inferred confounders are not actually immutable or if the counterfactual search algorithm fails to find minimal changes, the explanations become infeasible

### Mechanism 3
- Claim: The evidence lower bound (ELBO) objective enables effective learning of both generative and inference models
- Mechanism: The ELBO combines prediction accuracy, regularization of inferred latent variables, and entropy maximization to learn a model that can both predict and generate counterfactuals
- Core assumption: The factorized form of the generative model and inference model are appropriate for the data
- Evidence anchors:
  - [section 4.1]: "Our CounTS uses the evidence lower bound (ELBO) LELBO of the log likelihood log p(y|x) as an objective to learn the generative and inference models"
  - [section 4.1]: "We include an additional term (N is the training set size) Ly = XN i=1 log q(yi|xi) to supervise q(y|x) using label y during training"
  - [corpus]: Weak evidence - related surveys on self-interpretable neural networks mention ELBO but don't specifically address time series counterfactuals
- Break condition: If the ELBO components are not properly balanced (via λ hyperparameter) or if the factorized model is misspecified, learning fails

## Architecture Onboarding

- Component map:
  - Time series x -> Encoder network -> (z, ul, ug) -> Predictor network -> Output y
  - Inference networks: qϕ(y|x), qϕ(ul, ug|x, y), qϕ(z|x, y) for approximating posteriors
  - Counterfactual search: iterative gradient-based optimization to find xcf

- Critical path: x → Encoder → (z, ul, ug) → Predictor → y for prediction; x, ypred → Inference → (z, ul, ug) → Counterfactual search → xcf for explanations

- Design tradeoffs: The model trades off prediction accuracy for explanation quality by explicitly modeling confounders; simpler models might predict better but cannot generate feasible counterfactuals

- Failure signatures: Poor counterfactual change ratio indicates failure to identify correct confounders; high prediction error indicates poor latent representation learning; slow counterfactual search indicates optimization difficulties

## Limitations

- The paper relies heavily on the assumed causal graph structure, but provides limited validation that this structure matches real-world data-generating processes
- The identifiability theorem assumes perfect posterior inference of confounders, yet the variational approximation quality is not thoroughly evaluated
- The method's scalability to high-dimensional multivariate time series remains unclear, as experiments focus on relatively simple datasets

## Confidence

- **High Confidence**: The variational Bayesian framework and counterfactual inference algorithm are technically sound and well-grounded in established causal inference theory
- **Medium Confidence**: The experimental results showing improved counterfactual change ratio, though the comparison to baselines could be more comprehensive
- **Low Confidence**: The claim that inferred confounders correspond to truly immutable factors in real-world applications, as this requires domain expertise validation
