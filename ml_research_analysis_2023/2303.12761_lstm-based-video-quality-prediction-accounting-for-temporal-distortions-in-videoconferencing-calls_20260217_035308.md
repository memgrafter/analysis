# LSTM-based Video Quality Prediction Accounting for Temporal Distortions in Videoconferencing Calls

## Quick Facts
- arXiv ID: 2303.12761
- Source URL: https://arxiv.org/abs/2303.12761
- Reference count: 0
- Primary result: LSTM model with QR-code-based alignment achieves PCC of 0.99 on validation set, outperforming VMAF baseline (PCC 0.94).

## Executive Summary
This paper introduces a novel LSTM-based approach for predicting video quality in videoconferencing calls, addressing the challenge of temporal distortions such as frame freezes and skips that are not captured by traditional metrics like VMAF. The key innovation is the use of QR codes embedded in source videos to enable precise alignment between reference and degraded videos, allowing extraction of temporal features. By combining these features with VMAF core features and training an LSTM network, the model achieves a Pearson Correlation Coefficient (PCC) of 0.99 on a new dataset of 1,628 six-second video clips from live Microsoft Teams calls. The model also provides per-frame quality predictions, offering valuable insights into the causes of quality degradation.

## Method Summary
The method involves using QR codes as markers in source videos to align reference and degraded videos, enabling extraction of temporal features such as frame skips and freezes. These features, along with VMAF core features (VIF, ADM, Motion), are fed into a 6-layer LSTM network with 256 hidden units per layer to predict video quality. The model outputs per-frame MOS and overall video MOS (via average pooling). The dataset comprises 1,628 six-second clips from live Teams calls under 83 network conditions, annotated with crowdsourced MOS ratings.

## Key Results
- Proposed LSTM model achieves PCC of 0.99 on validation set, significantly outperforming VMAF baseline (PCC 0.94).
- Per-frame quality predictions provide detailed insight into causes of quality degradation, such as identifying frame freezes.
- Dataset and model are open-sourced for future research.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Temporal distortions in videoconferencing degrade perceived quality but are not captured by frame-based metrics like VMAF.
- Mechanism: QR codes enable precise alignment between reference and degraded videos, revealing temporal distortions (repeated or missing frame indices) that are fed into LSTM to model their impact on quality.
- Core assumption: Alignment vector accurately reflects temporal distortions and correlates with subjective quality ratings.
- Evidence anchors: QR codes used for alignment and temporal feature extraction; alignment vector captures frame skips and freezes.
- Break condition: QR code detection failure under poor network conditions leads to alignment errors and poor model predictions.

### Mechanism 2
- Claim: LSTM architecture is well-suited to model sequential temporal dependencies in video quality.
- Mechanism: LSTM processes VMAF core features and temporal features as sequences, learning to weigh the impact of each frame's quality and temporal anomalies on overall quality.
- Core assumption: Temporal masking effects and memory of past frames influence perceived quality; LSTM can capture these better than static pooling.
- Evidence anchors: LSTM achieves PCC of 0.99; well-suited for modeling sequences and time dependencies.
- Break condition: Irregular temporal distortions or long sequences may challenge LSTM generalization or cause overfitting.

### Mechanism 3
- Claim: Per-frame quality prediction provides insight into specific causes of quality degradation.
- Mechanism: LSTM outputs per-frame quality scores, allowing analysis of temporal patterns in degradation. Aggregated scores match subjective MOS ratings.
- Core assumption: Frame-level scores correlate with user perception and can be meaningfully aggregated to match MOS.
- Evidence anchors: Per-frame predictions offer detailed insight; model reaches MOS close to ground truth by considering freezes.
- Break condition: Noisy per-frame predictions lead to unreliable overall MOS.

## Architecture Onboarding

- Component map:
  - Degraded video frames, QR code-derived reference frame indices -> VMAF core features (VIF, ADM, Motion) + temporal features (frame skips, freezes) -> 6-layer LSTM (256 hidden units) -> Per-frame MOS and overall video MOS (via average pooling)

- Critical path:
  1. Align degraded and reference videos using QR codes.
  2. Extract VMAF core and temporal features for each frame.
  3. Feed features as sequences into LSTM.
  4. Produce per-frame and overall quality predictions.

- Design tradeoffs:
  - QR codes add overhead but enable robust alignment; simpler heuristics may fail under poor conditions.
  - LSTM depth/width vs. overfitting: 6 layers, 256 units chosen for best validation performance but smaller models also work.
  - Per-frame vs. video-level prediction: per-frame gives interpretability but requires careful pooling.

- Failure signatures:
  - QR code detection failure -> alignment errors -> poor temporal feature extraction.
  - Overfitting to training network conditions -> poor generalization to new scenarios.
  - Noisy per-frame predictions -> unreliable overall MOS.

- First 3 experiments:
  1. Validate QR code detection and alignment accuracy on a subset of degraded videos.
  2. Train LSTM with only VMAF core features (no temporal) and compare PCC to baseline VMAF.
  3. Add temporal features (skip, freeze) incrementally and measure impact on PCC and RMSE.

## Open Questions the Paper Calls Out
- Would replacing VMAF core features with end-to-end deep learning approaches further improve the model's accuracy beyond the current PCC of 0.99?
- How does the model perform on videoconferencing calls with different types of temporal distortions not well-represented in the current dataset, such as extreme packet loss or network jitter?
- Can the model's per-frame quality predictions be used to develop real-time video quality improvement algorithms for videoconferencing systems?

## Limitations
- The approach depends heavily on QR code detection and alignment robustness under poor network conditions.
- The dataset is specific to Microsoft Teams and 83 controlled network conditions, limiting generalization to other platforms or real-world network variability.
- Lack of a separate test set and ablation studies on temporal feature importance introduces uncertainty about true model robustness and feature contribution.

## Confidence
- High confidence: The mechanism by which QR codes enable precise alignment for temporal feature extraction is clearly described and supported by the methodology section.
- Medium confidence: The claim that LSTM architecture effectively models sequential temporal dependencies is plausible given prior literature, but direct experimental comparison to alternative architectures is not provided.
- Medium confidence: Per-frame quality predictions offer interpretability, but the practical utility and correlation with user perception for individual frames are not extensively validated.

## Next Checks
1. Validate QR code detection accuracy and alignment quality across the full range of network conditions, especially under severe packet loss or compression.
2. Evaluate model performance on a held-out test set or new dataset from a different videoconferencing platform to assess robustness and generalization.
3. Conduct an ablation study to quantify the contribution of temporal features versus VMAF core features to overall model performance, and compare LSTM with alternative architectures.
