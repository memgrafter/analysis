# GrowSP: Unsupervised Semantic Segmentation of 3D Point Clouds

## Quick Facts
- arXiv ID: 2305.16404
- Source URL: https://arxiv.org/abs/2305.16404
- Reference count: 40
- First unsupervised method for 3D semantic segmentation, achieving 44.5% mIoU on S3DIS Area-5

## Executive Summary
This paper introduces GrowSP, the first unsupervised semantic segmentation method for 3D point clouds. The method employs a progressive superpoint growth strategy that enables the model to discover semantic elements without human labels. GrowSP demonstrates significant performance improvements over existing unsupervised baselines and approaches the accuracy of fully-supervised methods like PointNet++.

## Method Summary
GrowSP consists of three main components: a feature extractor that processes raw point cloud data, a superpoint constructor that groups points into progressively growing regions, and a semantic primitive clustering module that assigns semantic labels. The progressive growth mechanism allows the model to iteratively refine its understanding of semantic structures without supervision, using a combination of geometric and feature-based clustering approaches.

## Key Results
- Achieves 44.5% mIoU on S3DIS Area-5, compared to 6.4% for IIC and 17.9% for PICIE
- Demonstrates strong generalization to unseen datasets
- Approaches fully-supervised methods like PointNet++ (50.1% mIoU on S3DIS Area-5)
- Sets new state-of-the-art for unsupervised 3D semantic segmentation

## Why This Works (Mechanism)
The progressive superpoint growth mechanism enables the model to gradually discover semantic structures without supervision. By starting with small, fine-grained superpoints and progressively merging them based on feature similarity and geometric relationships, the method can capture both local details and global semantic patterns. The unsupervised clustering leverages inherent geometric and structural patterns in point clouds to form meaningful semantic groups.

## Architecture Onboarding
Component map: Raw point cloud -> Feature Extractor -> Superpoint Constructor -> Clustering Module -> Semantic Labels
Critical path: Feature extraction provides representations that guide superpoint construction, which creates regions that the clustering module then assigns semantic labels to. Each component depends on the previous one's output.
Design tradeoffs: Balance between local detail preservation (small superpoints) and global semantic coherence (larger regions). Too small regions miss global context, too large lose local details.
Failure signatures: Poor feature extraction leads to meaningless superpoints; overly aggressive merging creates semantically inconsistent regions; clustering instability results in label noise.
First experiments: 1) Visualize intermediate superpoints at different growth stages, 2) Test feature extractor on simple geometric shapes, 3) Run clustering on pre-computed features to isolate component performance.
