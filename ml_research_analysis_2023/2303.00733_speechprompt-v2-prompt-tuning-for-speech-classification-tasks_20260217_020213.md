# SpeechPrompt v2: Prompt Tuning for Speech Classification Tasks

## Quick Facts
- arXiv ID: 2303.00733
- Source URL: https://arxiv.org/abs/2303.00733
- Reference count: 0
- Key outcome: SpeechPrompt v2 achieves state-of-the-art or competitive performance in speech classification tasks using fewer than 0.15M trainable parameters.

## Executive Summary
SpeechPrompt v2 proposes prompt tuning for spoken language models to perform diverse speech classification tasks. It learns task-specific prompt vectors and a learnable verbalizer to map model outputs to task labels, requiring fewer than 0.15M trainable parameters. Experiments on 10 tasks across 14 datasets show SpeechPrompt v2 achieves state-of-the-art or competitive performance in tasks like speech commands recognition, intent classification, language identification, and emotion recognition, while demonstrating limitations in non-speech and highly variable tasks. A learnable verbalizer is introduced to improve mapping quality over frequency-based methods. The framework provides parameter-efficient, unified speech processing capability.

## Method Summary
SpeechPrompt v2 is a prompt tuning framework for spoken language models that performs diverse speech classification tasks. It concatenates task-specific prompt vectors at the input and through attention layers of pre-trained speech models like GSLM and pGSLM. A learnable verbalizer maps the model's output distribution over discrete units to task labels. The framework keeps pre-trained models frozen while only updating prompt vectors and the verbalizer, requiring fewer than 0.15M trainable parameters. Training uses cross-entropy loss, and the approach demonstrates parameter-efficient performance across multiple speech classification tasks.

## Key Results
- Achieves state-of-the-art performance on 10 speech classification tasks across 14 datasets
- Uses fewer than 0.15M trainable parameters compared to millions in full fine-tuning
- Introduces a learnable verbalizer that outperforms frequency-based mapping methods
- Demonstrates limitations on non-speech and highly variable tasks like emotion recognition

## Why This Works (Mechanism)

### Mechanism 1
Prompt vectors act as task-specific instructions that condition frozen speech models to generate appropriate outputs for classification tasks. By concatenating trainable prompt vectors at the input and through attention layers of pre-trained speech models, the model's output distribution is steered toward task-relevant vocabulary units without modifying the model parameters. Core assumption: The pre-trained speech model's latent space contains sufficient task-relevant information that can be selectively accessed through prompt conditioning.

### Mechanism 2
The learnable verbalizer maps discrete speech model outputs to meaningful task labels through learned transformations rather than heuristic frequency-based mappings. A linear transformation layer learns to map the output probability distribution over discrete units to the target task's label space, capturing non-linear relationships between units and labels. Core assumption: There exists a learnable transformation that can effectively bridge the gap between speech model output vocabulary and task-specific labels.

### Mechanism 3
Deep prompt tuning enhances instruction-following ability by injecting prompts into multiple layers of the transformer architecture. Trainable prompts are concatenated with key and value projections in attention layers across multiple transformer layers, creating multiple points of task-specific conditioning throughout the model's computation. Core assumption: Multiple injection points provide richer task-specific context than input-only prompting.

## Architecture Onboarding

- Component map: Speech audio -> SSL model -> Discrete units -> Prompt conditioning -> Model output -> Verbalizer -> Labels
- Critical path: Speech → Discrete units → Prompt conditioning → Model output → Verbalizer → Labels
- Design tradeoffs:
  - Parameter efficiency vs. task performance: Very few trainable parameters (<0.15M) may limit complex task adaptation
  - Frozen model constraint: Cannot learn new representations but enables multi-task serving
  - Linear verbalizer: Simple and parameter-efficient but may not capture complex label relationships
- Failure signatures:
  - Performance degradation on non-speech or highly variable tasks suggests insufficient prompt guidance
  - Instability across runs indicates prompt tuning sensitivity to initialization
  - Poor performance on low-resource languages may indicate insufficient pre-training coverage
