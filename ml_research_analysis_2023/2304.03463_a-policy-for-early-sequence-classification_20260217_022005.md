# A Policy for Early Sequence Classification

## Quick Facts
- arXiv ID: 2304.03463
- Source URL: https://arxiv.org/abs/2304.03463

## Executive Summary
This paper introduces Classifier-Induced Stopping (CIS), a novel method for early sequence classification that learns both the classifier and stopping policy in a supervised manner without exploration. CIS uses the classifier's own predictions at each time step to determine when to stop, learning the optimal stopping time from these induced decisions. The method outperforms existing approaches like PPO and LARM across three diverse datasets (IMDB reviews, ECG waveforms, and stock options), achieving an average Pareto frontier AUC increase of 11.8%.

## Method Summary
CIS addresses early sequence classification by learning both the classifier and stopping policy using supervised learning rather than exploration-based methods. The approach uses an LSTM base network with two feed-forward heads: one for classification and one for policy (wait or stop). The reward function combines classification accuracy and timeliness, with a time penalty parameter μ controlling the accuracy-timeliness tradeoff. During training, CIS computes rewards based on its own classification predictions at each time step, learning when to stop without exploration. The model is trained with Adam optimizer using dataset-specific hyperparameters.

## Key Results
- CIS achieves an average Pareto frontier AUC increase of 11.8% over state-of-the-art methods
- Outperforms PPO and LARM benchmarks across IMDB reviews, ECG waveforms, and stock options datasets
- Demonstrates superior accuracy-timeliness tradeoffs across the entire Pareto frontier spectrum
- Shows consistent performance improvements across diverse sequence types and classification tasks

- Mechanism: CIS learns both policy and classifier in a supervised manner by using the classifier's own predictions to determine when to stop. At each time step, it computes rewards based on classification accuracy and time, using this to learn the optimal stopping time.
- Core assumption: The classifier's predictions at each time step are reliable enough to determine the optimal stopping time.

- Mechanism: CIS learns the stopping policy in a supervised manner by using the classifier's own predictions as labels for the optimal stopping time. It computes rewards at each time step based on classification accuracy and time.
- Core assumption: The reward function accurately captures the trade-off between accuracy and timeliness.
- Evidence anchors: [abstract] "While previous methods depend on exploration during training to learn when to stop and classify, ours is a more direct, supervised approach." ## Limitations
- Performance depends heavily on reward function design and time penalty parameter configuration
- Assumes classifier predictions at each time step are reliable indicators of optimal stopping time
- Limited testing on noisy data or scenarios with ambiguous stopping criteria
- Doesn't provide theoretical justification for why supervised learning approach is superior to exploration-based methods

## Confidence
- **High Confidence**: Empirical results showing CIS outperforming PPO and LARM on three tested datasets with 11.8% average Pareto frontier AUC improvement
- **Medium Confidence**: Claim that supervised learning approach is fundamentally superior to exploration-based methods for early sequence classification
- **Low Confidence**: Assertion that CIS "directly learns the optimal stopping time" without exploration
