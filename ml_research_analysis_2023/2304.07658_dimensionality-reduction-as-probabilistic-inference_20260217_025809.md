# Dimensionality Reduction as Probabilistic Inference

## Quick Facts
- arXiv ID: 2304.07658
- Source URL: https://arxiv.org/abs/2304.07658
- Authors: 
- Reference count: 40
- Primary result: Probabilistic framework (ProbDR) that unifies classical DR algorithms (PCA, t-SNE, UMAP, etc.) as instances of variational inference

## Executive Summary
This paper introduces a unified probabilistic framework (ProbDR) that casts classical dimensionality reduction algorithms as variational inference problems. By modeling low-dimensional latent variables as generators of covariance, precision, or graph Laplacian matrices, the framework provides a principled way to understand, compose, and extend DR methods. The approach enables reasoning about uncertainties, handling unseen data, and leveraging probabilistic programming languages for implementation.

## Method Summary
The method formulates DR as variational inference where low-dimensional latents X are used to construct a moment matrix M (covariance, precision, or graph Laplacian) that serves as a generative model for high-dimensional data Y. Inference is performed by optimizing an evidence lower bound (ELBO) that balances data fit and regularization. The framework demonstrates that many classical DR algorithms performing eigendecomposition are equivalent to two-step maximum a posteriori (MAP) processes under a Wishart distribution, which is mathematically equivalent to ProbDR inference.

## Key Results
- Classical DR algorithms (PCA, t-SNE, UMAP, Isomap, LLE) can be unified under a single probabilistic inference framework
- Eigendecomposition-based algorithms perform a two-step MAP process equivalent to ProbDR inference
- Probabilistic programming languages can implement DR algorithms, enabling reasoning about uncertainties and unseen data
- The framework facilitates model composition and extensions, particularly when domain knowledge is present

## Why This Works (Mechanism)

### Mechanism 1
Classical DR algorithms can be unified under ProbDR by modeling low-dimensional latents as generators of moment matrices (covariance, precision, or graph Laplacian) that serve as generative models. The framework casts DR as variational inference with an ELBO objective balancing data fit and regularization through KL divergence.

### Mechanism 2
Algorithms relying on eigendecomposition perform a two-step MAP process: (1) estimate a positive semi-definite matrix from data, and (2) find embedding via eigenvectors. This is equivalent to MAP inference under a Wishart distribution, which matches the KL divergence minimization in ProbDR.

### Mechanism 3
The probabilistic generative model enables reasoning about uncertainties and unseen data through Bayesian inference. By placing a probabilistic model on data Y conditioned on latents X via moment matrix M, one can compute predictive distributions and quantify uncertainty in embeddings.

## Architecture Onboarding

- **Component map**: Latent variables X -> Moment matrix M (covariance/precision/Laplacian) -> Generative model p(Y|M) -> Variational distribution q(M|Y) -> ELBO objective
- **Critical path**: 1) Construct moment matrix M from data, 2) Define variational distribution q(M|Y), 3) Define generative model p(Y|M), 4) Optimize ELBO w.r.t. X and parameters
- **Design tradeoffs**: Choice of moment matrix affects generative model and computational complexity; improper uniform prior simplifies inference but may not always be appropriate; graph Laplacian vs. covariance affects interpretation
- **Failure signatures**: ELBO optimization fails to converge or gets stuck; estimated M is not positive definite; poor predictive performance on unseen data
- **First 3 experiments**: 1) Reproduce PCA embeddings using ProbDR with Gaussian generative model and covariance moment matrix, 2) Implement UMAP embeddings using ProbDR with Bernoulli variational distribution and graph Laplacian, 3) Predict unseen data using ProbDR-UMAP generative model and compare to VAE

## Limitations
- Unification relies on specific interpretations of classical algorithms as MAP inference, which may not extend to all variants
- Improper uniform prior on latents may lead to improper posteriors in some cases
- Mathematical equivalence between two-step MAP and ProbDR depends on specific assumptions about Wishart distribution and matrix definiteness

## Confidence

- **High confidence**: Core variational inference framework and ELBO optimization are well-established
- **Medium confidence**: Mathematical equivalence between two-step MAP and ProbDR is rigorously proven but practical implications need investigation
- **Medium confidence**: Probabilistic generative model enables uncertainty reasoning, but quality depends on model specification
