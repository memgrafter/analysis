# The Berkelmans-Pries Feature Importance Method: A Generic Measure of Informativeness of Features

## Quick Facts
- arXiv ID: 2301.04740
- Source URL: https://arxiv.org/abs/2301.04740
- Reference count: 40
- The Berkelmans-Pries Feature Importance method is introduced as a global approach to determine the importance of features in predicting a target variable, combining Shapley values and the Berkelmans-Pries dependency function.

## Executive Summary
This paper introduces the Berkelmans-Pries Feature Importance (BP-FI) method, a novel approach to determining feature importance in machine learning models. The method combines Shapley values from cooperative game theory with the Berkelmans-Pries dependency function to provide a global measure of feature informativeness. BP-FI is designed to have desirable mathematical properties including efficiency, symmetry, and a bounded range of [0,1]. The authors demonstrate that BP-FI accurately predicts correct feature importance values in cases where ground truth can be derived exactly, and show through extensive experimentation that existing methods lack these useful properties.

## Method Summary
The BP-FI method calculates feature importance by treating features as players in a cooperative game where the characteristic function is defined by the Berkelmans-Pries dependency function. For a dataset with features X and target Y, the BP dependency function measures how much knowing a subset of features changes the distribution of Y. Shapley values are then computed using this characteristic function to fairly distribute the total dependency among individual features. The method is exact for discrete features but can handle continuous features through discretization, though this may affect accuracy.

## Key Results
- BP-FI demonstrates efficiency, symmetry, and null-independence properties that are missing from many existing methods
- The method accurately predicts correct feature importance values for several cases where ground truth can be derived exactly
- Experimental results on 468 feature importance methods show that existing methods do not have the same useful properties as BP-FI

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Shapley values ensure efficiency, symmetry, and null-independence, which provide fairness and stability in feature attribution.
- Mechanism: Shapley values assign credit to each feature based on marginal contributions across all possible coalitions, ensuring each feature's importance reflects its actual contribution.
- Core assumption: The dataset features form a cooperative game where coalition values can be defined by the BP dependency function.
- Evidence anchors:
  - [abstract]: "It is shown to have many desirable properties, including efficiency, symmetry, and a range of [0,1]."
  - [section]: "Shapley values are efficient, meaning that all the value is distributed among the players...Shapley values are symmetric, meaning that if v(S ∪ { i}) = v(S ∪ { j}) for every S ⊆ Ωfeat \ { i, j }, it follows that FI (i) = FI(j)."
- Break condition: If the dependency function is not subadditive or superadditive, Shapley value guarantees may not hold for individual features.

### Mechanism 2
- Claim: The BP dependency function provides a normalized measure of how much knowing a feature changes the distribution of the target variable.
- Mechanism: The function computes the expected absolute difference between the distribution of Y and the conditional distribution given a feature set, then normalizes by the maximum possible change.
- Core assumption: All variables are discrete or can be discretized without significant information loss.
- Evidence anchors:
  - [section]: "It is given by...where (in the discrete case) it holds that...The numerator is the expected absolute difference between the distribution of Y and the distribution of Y given X."
  - [section]: "The BP dependency function is non-increasing under functions of X [5], which means that for any measurable function f it holds that Dep (Y |f (X)) ≤ Dep (Y |X)."
- Break condition: If continuous variables are poorly binned, the dependency function may lose critical information and distort feature importance.

### Mechanism 3
- Claim: Combining Shapley values with the BP dependency function ensures that feature importance is bounded, interpretable, and consistent with intuitive properties.
- Mechanism: The characteristic function v(S) = Dep(Y|S) ensures that each feature's importance is tied to actual information gain, while Shapley values distribute this importance fairly across features.
- Core assumption: The dependency function behaves monotonically and is bounded in [0,1], allowing Shapley values to inherit these bounds.
- Evidence anchors:
  - [abstract]: "accurately predicts the correct FI values for several cases where the ground truth can be derived exactly."
  - [section]: "Property 3 (Range). For any R V X, it holds that FI (X) ∈ [0, 1]."
- Break condition: If the dependency function fails to capture the true information content due to poor discretization or sample size, the resulting Shapley values may be misleading.

## Architecture Onboarding

- Component map: Data preprocessing -> BP dependency function evaluation -> Shapley value computation -> Result validation
- Critical path:
  1. Preprocess dataset (bin continuous features, handle missing values)
  2. Compute BP dependency values for all feature subsets
  3. Calculate Shapley values using these dependency values
  4. Validate results against known properties
- Design tradeoffs:
  - Exact Shapley computation is exponential in number of features, but approximations can be used
  - Discretization of continuous features affects dependency function accuracy
  - Runtime vs. precision tradeoff in dependency function computation
- Failure signatures:
  - NaN or infinite values in dependency function indicate constant target variable or poor discretization
  - Inconsistent total importance across datasets suggests numerical instability
  - Non-zero importance for null-independent features indicates implementation error
- First 3 experiments:
  1. Verify BP-FI on the XOR dataset: FI(X1) = FI(X2) = 0.5
  2. Test cloning property: Adding a duplicate feature should not increase the original feature's importance
  3. Check range property: All feature importance values should be in [0,1]

## Limitations
- Computational complexity limits the method to moderate numbers of features (typically <20) without approximation techniques
- The method requires discrete features or careful binning of continuous features, which may lose information
- Experimental validation relies on synthetic datasets rather than real-world data
- The study only tested 468 out of potentially thousands of existing feature importance methods

## Confidence
- **High confidence**: The theoretical properties of Shapley values (efficiency, symmetry, null-independence) are well-established
- **Medium confidence**: The BP dependency function correctly captures feature-target relationships in discrete cases
- **Medium confidence**: Experimental results showing the method's performance on synthetic datasets
