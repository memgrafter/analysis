# A Novel Plagiarism Detection Approach Combining BERT-based Word Embedding, Attention-based LSTMs and an Improved Differential Evolution Algorithm

## Quick Facts
- arXiv ID: 2305.02374
- Source URL: https://arxiv.org/abs/2305.02374
- Reference count: 40
- Proposes a plagiarism detection model integrating BERT embeddings, attention-based LSTMs, and improved DE algorithm for weight initialization

## Executive Summary
This study presents a novel plagiarism detection approach that addresses key challenges in the field by combining advanced neural network architectures with evolutionary optimization. The model leverages BERT-based word embeddings to capture semantic similarities between source and suspicious texts, while attention-based LSTMs extract relevant features from these embeddings. To optimize the model's performance, an improved differential evolution algorithm is employed for weight initialization, specifically addressing the class imbalance problem through the use of focal loss.

## Method Summary
The proposed BPD-IDE model consists of two parallel bidirectional LSTM networks that process source and suspicious sentences separately, with attention mechanisms to focus on important features. These networks are initialized using an enhanced differential evolution algorithm that incorporates clustering-based mutation and a novel updating strategy. BERT embeddings serve as the input representation, capturing semantic similarities between text pairs. The model predicts similarity scores through a feed-forward network and addresses class imbalance using focal loss during training.

## Key Results
- Achieves improvements of up to 43% in F-measure compared to conventional methods
- Demonstrates 44% improvement in G-means metrics
- Shows superior performance across three benchmark datasets (MSRP, SNLI, SemEval2014)
- Outperforms both conventional and population-based plagiarism detection methods

## Why This Works (Mechanism)
The integration of BERT embeddings provides rich semantic representations that capture contextual similarities beyond surface-level text matching. The attention-based LSTMs effectively focus on relevant features while filtering noise, and the improved DE algorithm optimizes weight initialization to avoid poor local minima. The focal loss function specifically addresses the class imbalance problem common in plagiarism detection datasets, where genuine matches are typically far less frequent than non-matches.

## Limitations
- Evaluation on only three benchmark datasets may not fully capture generalizability across diverse plagiarism scenarios
- Significant performance improvements lack detailed statistical significance testing
- Clustering-based mutation strategy contribution to performance gains not quantified through ablation studies
- Limited analysis of how different class imbalance ratios affect model performance

## Confidence
- High: BERT-based word embeddings effectively capture semantic similarities
- Medium: Attention-based LSTMs contribute meaningfully to feature extraction
- Medium: The improved DE algorithm provides superior weight initialization compared to random initialization
- Low: Performance improvements are statistically significant across all metrics
