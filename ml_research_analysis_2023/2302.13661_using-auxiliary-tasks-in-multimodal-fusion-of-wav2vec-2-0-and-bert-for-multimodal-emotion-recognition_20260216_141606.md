# Using Auxiliary Tasks In Multimodal Fusion Of Wav2vec 2.0 And BERT For Multimodal Emotion Recognition

## Quick Facts
- arXiv ID: 2302.13661
- Source URL: https://arxiv.org/abs/2302.13661
- Reference count: 0
- Primary result: 78.42% Weighted Accuracy and 79.71% Unweighted Accuracy on IEMOCAP

## Executive Summary
This paper presents a novel approach to multimodal emotion recognition that addresses key challenges of data scarcity and effective multimodal fusion. The authors propose an end-to-end framework using wav2vec 2.0 for audio and BERT for text modalities, combined with a K-layer multi-head attention mechanism for fusion. To enhance feature learning and modality alignment, two auxiliary tasks are introduced: modality recombination prediction and emotion alignment learning. The proposed method achieves state-of-the-art performance on the IEMOCAP dataset with 78.42% Weighted Accuracy and 79.71% Unweighted Accuracy, demonstrating the effectiveness of the auxiliary task design.

## Method Summary
The proposed approach employs wav2vec 2.0 and BERT as upstream networks to extract audio and text features respectively. These features are then fused using a K-layer multi-head attention mechanism in the downstream fusion stage. To address insufficient fusion between modalities and capture emotion-related features, two auxiliary tasks are designed. The first auxiliary task involves randomly recombining text and audio modalities and predicting the combination through the fusion vector. The second auxiliary task replaces one modality with data of the same emotion category to learn emotion alignment. The entire framework is trained end-to-end, with the auxiliary tasks helping to learn better-aligned and discriminative features for emotion recognition.

## Key Results
- Achieved 78.42% Weighted Accuracy (WA) on IEMOCAP dataset
- Achieved 79.71% Unweighted Accuracy (UA) on IEMOCAP dataset
- Outperforms baseline models by approximately 3% in both metrics
- Ablation studies demonstrate effectiveness of each proposed module

## Why This Works (Mechanism)
The method works by leveraging pre-trained language and speech models (BERT and wav2vec 2.0) to extract rich modality-specific features, then using multi-head attention to fuse these features effectively. The auxiliary tasks serve as regularizers that force the model to learn more discriminative and aligned representations. The modality recombination task ensures the model learns to identify when modalities are mismatched, while the emotion alignment task ensures consistent emotional representations across modalities. This multi-task learning approach prevents the model from overfitting to the primary emotion recognition task and encourages learning of more robust cross-modal representations.

## Architecture Onboarding

**Component Map:** Audio -> wav2vec 2.0 -> Audio Features -> Multi-head Attention -> Fusion Vector -> Emotion Classifier
                                   Text -> BERT -> Text Features -> Multi-head Attention -> Fusion Vector -> Emotion Classifier

**Critical Path:** Audio and text inputs → modality-specific feature extraction → multi-head attention fusion → auxiliary task heads → emotion classification

**Design Tradeoffs:** The use of pre-trained models reduces training data requirements but limits architectural flexibility. The K-layer attention mechanism provides depth for complex fusion but increases computational cost. Auxiliary tasks improve feature learning but add training complexity.

**Failure Signatures:** Poor cross-modal attention patterns, imbalanced attention weights between modalities, degraded performance on either modality alone, or failure to converge on auxiliary tasks may indicate architectural issues.

## Limitations
- Experimental validation is constrained to a single dataset (IEMOCAP), limiting generalizability
- Performance gains of approximately 3% over baselines may not represent real-world deployment scenarios
- The auxiliary task designs lack detailed analysis of different sampling strategies and their effects
- The K-layer multi-head attention fusion mechanism's parameter sensitivity is not thoroughly explored
