# Let GPT be a Math Tutor: Teaching Math Word Problem Solvers with Customized Exercise Generation

## Quick Facts
- arXiv ID: 2305.14386
- Source URL: https://arxiv.org/abs/2305.14386
- Reference count: 24
- Primary result: CEMAL achieves 94.7% accuracy on MAWPS, 93.3% on ASDiv-a, and 85.4% on SVAMP using significantly fewer parameters than comparable methods

## Executive Summary
This paper introduces CEMAL, a novel approach for distilling math word problem solving capabilities from large language models (LLMs) into smaller, more efficient student models. The key innovation lies in iteratively assessing the student model's learning status and generating customized exercises to improve its performance. By leveraging GPT-3.5's capabilities for both evaluation and exercise generation, CEMAL creates a personalized learning experience that adapts to the student model's weaknesses. The method demonstrates substantial improvements over traditional fine-tuning approaches while using significantly fewer parameters.

## Method Summary
CEMAL employs an iterative training process where a student model learns from customized exercises generated by GPT-3.5 based on the student's current performance. The process involves three main phases: initial assessment to identify knowledge gaps, customized exercise generation targeting specific weaknesses, and continuous evaluation to track progress. GPT-3.5 acts as both the evaluator and exercise generator, creating problems that challenge the student model's weak areas. This adaptive approach allows for more efficient learning compared to static training datasets, as the student model receives targeted practice where needed most.

## Key Results
- Achieves 94.7% accuracy on MAWPS dataset, significantly outperforming fine-tuned baselines
- Reaches 93.3% accuracy on ASDiv-a with substantially fewer parameters than comparable models
- Demonstrates 85.4% accuracy on SVAMP while surpassing LLM chain-of-thought methods in efficiency

## Why This Works (Mechanism)
The effectiveness of CEMAL stems from its adaptive learning approach that mimics human tutoring methods. By continuously assessing the student model's performance and generating targeted exercises, the system creates a feedback loop that addresses specific weaknesses. The use of GPT-3.5 for both evaluation and exercise generation ensures high-quality, contextually appropriate problems that challenge the student model at the right level. This personalized approach allows for more efficient learning compared to static training datasets, as the student model receives practice precisely where needed.

## Foundational Learning
- **Math Word Problem Solving**: Understanding how to translate natural language into mathematical expressions is crucial for developing effective solvers
  - *Why needed*: Core competency for the student model to develop
  - *Quick check*: Verify model can correctly parse and solve simple word problems before scaling complexity

- **Iterative Assessment**: Continuous evaluation of model performance to identify learning gaps
  - *Why needed*: Enables personalized exercise generation targeting specific weaknesses
  - *Quick check*: Ensure assessment accuracy correlates with actual performance improvements

- **Exercise Customization**: Generating problems tailored to address identified weaknesses
  - *Why needed*: Maximizes learning efficiency by focusing on areas needing improvement
  - *Quick check*: Validate generated exercises effectively challenge target concepts

## Architecture Onboarding

**Component Map**: GPT-3.5 (Evaluator) -> Exercise Generator -> Student Model -> Performance Evaluator -> GPT-3.5

**Critical Path**: The feedback loop between the student model's performance evaluation and the subsequent exercise generation represents the most critical component. This path must maintain high accuracy in both assessment and generation to ensure effective learning.

**Design Tradeoffs**: The system trades computational efficiency for personalized learning effectiveness. While generating customized exercises requires additional LLM calls, the improved learning outcomes may justify the resource investment, particularly for smaller student models.

**Failure Signatures**: 
- Poor exercise generation leading to ineffective training
- Inaccurate performance assessment causing misguided customization
- Student model overfitting to generated exercises rather than general problem-solving

**First 3 Experiments**:
1. Test basic exercise generation quality by comparing GPT-3.5 outputs against human-annotated problems
2. Validate assessment accuracy by correlating model predictions with ground truth performance metrics
3. Evaluate customization effectiveness by measuring learning gains from targeted versus random exercise sets

## Limitations
- Heavy reliance on GPT-3.5 quality for both evaluation and exercise generation may limit generalizability to other domains
- The iterative assessment mechanism's effectiveness could vary significantly with different student model architectures
- Comparison with chain-of-thought prompting assumes equivalent computational resources, which may not reflect real-world constraints

## Confidence
**High Confidence Claims:**
- CEMAL outperforms fine-tuned baseline models on standard benchmarks
- The method achieves competitive accuracy with substantially fewer parameters
- The iterative exercise generation approach shows promise for student model training

**Medium Confidence Claims:**
- CEMAL surpasses LLMs with chain-of-thought prompting (requires verification of equivalent resource assumptions)
- The customization mechanism consistently improves learning outcomes across all tested datasets
