# BanglaBook: A Large-scale Bangla Dataset for Sentiment Analysis from Book Reviews

## Quick Facts
- **arXiv ID:** 2305.06595
- **Source URL:** https://arxiv.org/abs/2305.06595
- **Reference count:** 28
- **Primary result:** Introduces BanglaBook dataset with 158,065 samples across three sentiment classes

## Executive Summary
This paper presents BanglaBook, a comprehensive dataset for Bangla sentiment analysis derived from book reviews. The dataset contains 158,065 samples categorized into positive, negative, and neutral sentiments, collected from two online bookstores with non-Bangla reviews translated into Bangla. The collection addresses a significant gap in Bangla natural language processing resources, particularly for sentiment classification tasks.

The research establishes baseline performance using various machine learning approaches, demonstrating that pre-trained models like Bangla-BERT significantly outperform traditional machine learning methods and LSTM architectures. The dataset and accompanying code are made publicly available, enabling further research in low-resource language sentiment analysis and providing a foundation for developing more sophisticated models for Bangla text classification.

## Method Summary
The BanglaBook dataset was constructed through systematic collection of book reviews from two online Bangladeshi bookstores. The dataset includes both original Bangla reviews and translated non-Bangla reviews, with translation quality verified through human annotation. Reviews were manually labeled into three sentiment categories: positive, negative, and neutral. The dataset exhibits a strong positive sentiment bias with 141,587 positive samples (89.5%), 9,674 negative samples (6.1%), and 6,804 neutral samples (4.3%).

Baseline models were established using Support Vector Machines with handcrafted features, LSTM networks, and pre-trained transformer models including Bangla-BERT variants. The models were evaluated using standard classification metrics, and an error analysis was conducted to identify systematic classification failures, particularly in distinguishing neutral and negative sentiments.

## Key Results
- BanglaBook contains 158,065 labeled Bangla book reviews across three sentiment classes
- Pre-trained models (Bangla-BERT) significantly outperform traditional ML and LSTM approaches
- Dataset shows severe class imbalance (89.5% positive, 6.1% negative, 4.3% neutral)
- Error analysis reveals systematic difficulties in classifying neutral and negative sentiments due to positive word dominance

## Why This Works (Mechanism)
The effectiveness of BanglaBook stems from addressing the critical data scarcity in Bangla NLP. By collecting from real book review sources, the dataset captures authentic linguistic patterns and sentiment expressions specific to the Bangla language context. The inclusion of both original Bangla reviews and translated content expands the dataset's coverage while maintaining cultural relevance. Pre-trained transformer models like Bangla-BERT demonstrate superior performance because they leverage large-scale pretraining on Bangla text, enabling them to capture nuanced language patterns that traditional ML approaches and LSTM networks cannot effectively model.

## Foundational Learning
The dataset construction reveals that sentiment expression patterns in Bangla book reviews follow distinct linguistic patterns that may differ from other domains or languages. The strong positive bias in the dataset reflects cultural tendencies in book reviewing behavior, where readers are more likely to leave positive reviews. The systematic errors in distinguishing neutral and negative sentiments suggest that Bangla sentiment expression may rely heavily on specific lexical markers and contextual cues that current models struggle to differentiate. These findings provide foundational insights into how sentiment manifests in Bangla text and inform future model development for low-resource language processing.

## Architecture Onboarding
For researchers looking to work with BanglaBook, the recommended approach is to start with pre-trained Bangla-BERT variants as they provide the strongest baseline performance. The dataset's class imbalance requires careful handling during model training, particularly through techniques like class weighting or oversampling for minority classes. Since the dataset comes from book reviews, models trained on BanglaBook may need fine-tuning or adaptation when applied to other Bangla text domains such as social media or news comments. The publicly available code provides a practical starting point for implementing baseline models and conducting further experiments.

## Open Questions the Paper Calls Out
The paper identifies several important questions for future research: How can models be improved to better handle the neutral and negative sentiment classes given their underrepresentation? What specific linguistic features in Bangla distinguish these sentiment categories? Can the dataset be expanded to include more diverse text sources beyond book reviews to improve generalizability? How can the translation quality verification process be further strengthened? These questions highlight the ongoing challenges in developing robust sentiment analysis systems for low-resource languages.

## Limitations
- Severe class imbalance (89.5% positive sentiment) may bias model performance and generalizability
- Translation process quality verification methodology lacks detailed validation procedures
- Error analysis remains qualitative without systematic investigation of classification failures
- Dataset limited to book review domain, potentially limiting applicability to other Bangla text types
- Manual labeling process may introduce subjective bias in sentiment categorization
