# MAKE: Vision-Language Pre-training based Product Retrieval in Taobao Search

## Quick Facts
- arXiv ID: 2301.12646
- Source URL: https://arxiv.org/abs/2301.12646
- Reference count: 22
- Key outcome: MAKE achieves 0.9014 Prel score, 0.9295 Pcate score, and 0.6088 Recall@K on Taobao product retrieval

## Executive Summary
MAKE introduces a vision-language pre-training approach for text-to-multimodal retrieval in Taobao Search. The method addresses the challenge of varying importance between text and image across different products and semantic imbalance between user queries and product titles. MAKE employs a three-tower structure with separate encoders for queries, titles, and images, enhanced by a Modal Adaptation module for cross-modal fusion and a Keyword Enhancement mechanism for improving query representations.

## Method Summary
MAKE uses a three-tower architecture with separate encoders for queries, titles, and images. The Modal Adaptation module dynamically adjusts the importance of text and image features based on product characteristics, while the Keyword Enhancement mechanism improves query representations by jointly optimizing similar queries. The pre-training approach is specifically designed for the Taobao search domain where product images and titles have varying levels of relevance to user queries.

## Key Results
- Achieves 0.9014 Prel score, 0.9295 Pcate score, and 0.6088 Recall@K
- Improves GMV by 0.79% and transactions by 0.37% in online A/B tests
- Successfully deployed in Taobao Search, enhancing retrieval system efficiency

## Why This Works (Mechanism)
MAKE works by addressing two key challenges in product retrieval: the varying importance of text and image across products, and semantic imbalance between queries and titles. The three-tower architecture allows separate processing of each modality, while the Modal Adaptation module dynamically fuses cross-modal information based on product characteristics. The Keyword Enhancement mechanism improves query representations by leveraging semantic similarities between related queries, enabling more accurate matching with product titles.

## Foundational Learning

**Vision-Language Pre-training**: Pre-training models on large-scale image-text pairs to learn cross-modal representations. *Why needed*: Enables the model to understand relationships between visual and textual information. *Quick check*: Verify pre-training dataset size and diversity.

**Modal Adaptation**: Dynamic adjustment of feature importance based on product characteristics. *Why needed*: Different products require different emphasis on text vs. image features. *Quick check*: Confirm adaptation mechanism learns meaningful patterns.

**Keyword Enhancement**: Joint optimization of similar queries to improve representations. *Why needed*: User queries often lack product-specific keywords present in titles. *Quick check*: Measure improvement in query-title semantic alignment.

## Architecture Onboarding

Component map: User Query -> Query Encoder -> Modal Adaptation -> Retrieval
                           -> Keyword Enhancement
Product -> Title Encoder -> Modal Adaptation -> Retrieval
        -> Image Encoder -> Modal Adaptation -> Retrieval

Critical path: Query encoding → Keyword Enhancement → Modal Adaptation → Retrieval matching

Design tradeoffs: Three-tower architecture provides flexibility but increases computational complexity versus two-tower alternatives. Modal Adaptation adds dynamic fusion capability but requires additional parameters.

Failure signatures: Poor retrieval performance when product images are low-quality or irrelevant to titles. Reduced effectiveness when user queries contain highly ambiguous terms.
