# Multimodal Procedural Planning via Dual Text-Image Prompting

## Quick Facts
- arXiv ID: 2305.01795
- Source URL: https://arxiv.org/abs/2305.01795
- Reference count: 36
- Key outcome: Introduces Text-Image Prompting (TIP) for generating paired text-image procedural plans, outperforming baselines on WIKIPLAN and RECIPEPLAN datasets in human evaluations and automatic metrics (WMD, S-BERT, ROUGE-L, METEOR, FID, CLIP, etc.)

## Executive Summary
This paper introduces the Multimodal Procedural Planning (MPP) task, where a model generates paired text and image steps toward completing a high-level goal. The key challenge lies in ensuring informativeness, temporal coherence, and accuracy across both modalities. To address this, the authors propose Text-Image Prompting (TIP), a dual-modality prompting framework that uses LLMs and diffusion models connected via Text-to-Image and Image-to-Text bridges. TIP generates visual-grounded text plans and textual-grounded image plans, achieving state-of-the-art performance on newly collected procedural datasets.

## Method Summary
The proposed TIP framework operates by leveraging both LLMs and diffusion-based models through dual bridges. The Text-to-Image Bridge (T2I-B) generates images conditioned on text prompts, while the Image-to-Text Bridge (I2T-B) produces text descriptions from images. The framework iteratively refines both modalities by using each to inform the other, ensuring multimodal coherence. The approach is evaluated on two newly collected datasets (WIKIPLAN and RECIPEPLAN) and compared against unimodal and multimodal baselines using both human evaluation and automatic metrics.

## Key Results
- TIP outperforms baselines on WIKIPLAN and RECIPEPLAN datasets in human evaluations for informativeness, temporal coherence, and plan accuracy
- Automatic metrics show improved performance in WMD, S-BERT, ROUGE-L, METEOR, FID, and CLIP scores compared to competing methods
- Ablation studies confirm the importance of both the Text-to-Image and Image-to-Text bridges in the dual-prompting framework

## Why This Works (Mechanism)
The dual-modality prompting approach works by creating a feedback loop between text and image generation. The LLM generates text plans that condition the diffusion model to create relevant images, while the images are then used to refine the text descriptions. This iterative process ensures that both modalities remain aligned and coherent throughout the procedural planning process. The dual bridges (T2I-B and I2T-B) act as information exchangers that maintain consistency between the generated text and images.

## Architecture Onboarding

**Component Map**: LLM -> T2I-B -> Diffusion Model -> I2T-B -> LLM -> Output
The critical path involves text generation, image generation, image description, and iterative refinement.

**Critical Path**: LLM generates initial text plan → T2I-B creates prompts for diffusion model → Diffusion model generates images → I2T-B produces image descriptions → LLM refines text plan based on visual input

**Design Tradeoffs**: The framework balances computational cost (running both LLM and diffusion models) against multimodal quality. Using iterative refinement improves coherence but increases inference time.

**Failure Signatures**: Common failure modes include text-image misalignment, irrelevant image generation, and loss of temporal coherence across steps. These manifest as low CLIP scores and poor human evaluation ratings.

## Limitations

- Evaluation relies heavily on human judgment and automatic metrics that may not fully capture multimodal coherence quality
- Limited comparison to a small set of competing methods without comprehensive ablation of individual framework components
- Newly collected datasets lack detailed validation of annotation quality and potential biases
- Focus on structured domains (cooking, crafting) leaves open questions about generalization to more complex or open-ended procedural tasks

## Confidence

**Medium** - The approach is novel and methodologically sound, but empirical evidence for superiority is not definitive
**Medium** - Dataset creation process is described but lacks independent validation or analysis of potential biases
**High** - Automatic metrics are well-established
**Medium** - Human evaluation criteria and rater training are not fully specified
