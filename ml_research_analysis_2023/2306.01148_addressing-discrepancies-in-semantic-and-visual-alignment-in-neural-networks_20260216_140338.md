# Addressing Discrepancies in Semantic and Visual Alignment in Neural Networks

## Executive Summary
This paper addresses the challenge of aligning semantic relationships with visual representations in image classification models, particularly when semantic similarity does not correspond to visual similarity. The authors propose a data augmentation method using diffusion-based semantic mixing to generate hybrid images representing semantic blends of classes. These hybrids are added to the training set with 50/50 labeling between the two source classes. The method is evaluated on a modified CIFAR-100 dataset where semantic superclasses are constructed to be visually dissimilar. Results show that the augmented models achieve higher super class accuracy on mistakes over adversarially perturbed data compared to standard models, with the best performance from the high augmentation, high mix strength variant. Additionally, the augmented models make fewer mistakes between visually similar classes that are not semantically related. These findings demonstrate the potential of synthetic data to incorporate prior semantic knowledge into training and improve alignment between semantic and visual representations.

## Method Summary
The method uses diffusion-based semantic mixing (MagicMix) to generate hybrid images that visually blend two semantically related classes. These hybrids are added to the training set with 50/50 labeling between the source classes. The approach is evaluated on a modified CIFAR-100 dataset with five semantic superclasses constructed to be visually dissimilar. Models are trained with varying levels of augmentation and mix strength, then evaluated on adversarial examples to measure semantic alignment through super class accuracy on mistakes.

## Key Results
- Diffusion-based semantic mixing with 50/50 labeling improves semantic alignment in image classification models
- Models trained with augmented data achieve higher super class accuracy on adversarial mistakes compared to standard models
- The high augmentation, high mix strength variant performs best, making fewer mistakes between visually similar classes that are not semantically related

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Diffusion-based semantic mixing generates synthetic training examples that preserve semantic relationships while visually blending source classes.
- Mechanism: The MagicMix pipeline creates hybrid images by interpolating between a base image and a target class description using a pre-trained text-conditioned diffusion model. The mixing strength parameter controls the visual blend, producing images that carry features from both classes.
- Core assumption: Diffusion models can generate visually coherent hybrids that maintain class-relevant features when guided by semantic class names.
- Evidence anchors:
  - [abstract] "We leverage recent work in diffusion-based semantic mixing to generate semantic hybrids of two classes"
  - [section] "We pre-generate our hybrid images using the MagicMix pipeline from (Liew et al., 2022) using image-text mixing"
  - [corpus] No direct evidence about MagicMix's effectiveness in maintaining visual coherence during blending
- Break condition: If the diffusion model fails to produce visually coherent hybrids, the synthetic data would not help alignment and might introduce noise.

### Mechanism 2
- Claim: Adding hybrid images with 50/50 labeling encourages the model to represent semantically related classes more similarly.
- Mechanism: During training, hybrid images are labeled with equal probability for each source class. This creates a soft label distribution that bridges the representation space between classes, reducing the decision boundary distance for semantically similar pairs.
- Core assumption: Models can learn from ambiguous training examples and adjust internal representations to reflect the semantic relationships encoded in the mixed labels.
- Evidence anchors:
  - [abstract] "These hybrids are added to the training set as augmented data"
  - [section] "Augmented instances are labelled 50% as the base class and 50% as the target class"
  - [corpus] No evidence that this soft labeling approach specifically improves semantic alignment in prior work
- Break condition: If the model overfits to the hard label components or if the hybrid images are too ambiguous, the soft labeling might not effectively bridge class representations.

### Mechanism 3
- Claim: Adversarial evaluation reveals improved semantic alignment because semantically similar classes become easier to confuse under perturbation.
- Mechanism: The hypothesis is that when semantic alignment improves, small adversarial perturbations can more easily switch predictions between semantically related classes than between unrelated classes. Higher super class accuracy on adversarial mistakes indicates better alignment.
- Core assumption: Adversarial vulnerability correlates with internal representation similarity between classes.
- Evidence anchors:
  - [abstract] "We evaluate whether the method increases semantic alignment by evaluating model performance on adversarially perturbed data"
  - [section] "we look at the metric over adversarial instances of increasing severity, with the idea being that, if the model has a similar representation of visually similar classes, it will be easy to find an adversarial perturbation"
  - [corpus] No direct evidence that adversarial vulnerability is a reliable proxy for semantic alignment
- Break condition: If adversarial perturbations exploit different features than those used for semantic grouping, this metric might not accurately reflect semantic alignment.

## Limitations

- The effectiveness of diffusion-based semantic mixing (MagicMix) in generating visually coherent hybrid images that maintain class-relevant features is not directly validated
- The use of adversarial vulnerability as a proxy for semantic alignment lacks empirical validation and may measure different phenomena
- The method's performance on more complex and challenging datasets, as well as its ability to incorporate domain-specific knowledge, remains untested

## Confidence

- **High confidence**: The experimental setup (modified CIFAR-100 with constructed superclasses, adversarial evaluation protocol) is clearly specified and reproducible
- **Medium confidence**: The hypothesis that synthetic hybrids with soft labeling can improve semantic alignment is plausible but depends on MagicMix's effectiveness and the model's ability to learn from ambiguous examples
- **Low confidence**: The assumption that adversarial vulnerability directly indicates semantic alignment is not empirically validated and could be measuring different phenomena
