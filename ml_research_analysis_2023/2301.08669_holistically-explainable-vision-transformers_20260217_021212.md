# Holistically Explainable Vision Transformers

## Quick Facts
- arXiv ID: 2301.08669
- Source URL: https://arxiv.org/abs/2301.08669

## Executive Summary
This paper presents B-cos ViTs, a novel Vision Transformer architecture designed to be inherently explainable. The key innovation is reformulating each component of the ViT (tokenisation, attention, MLPs, classifier) as a dynamic linear function, enabling the entire model to be summarized by a single linear transform for each input. This approach allows for direct visualization of the model's decision-making process, providing model-inherent explanations that outperform various post-hoc explanation methods on localization and pixel perturbation metrics while maintaining competitive ImageNet classification performance.

## Method Summary
The authors reformulate standard ViT components to create B-cos ViTs that can be summarized by single linear transforms for each input. This is achieved by making the tokenisation, attention, MLPs, and classifier components all linear functions. The resulting architecture maintains competitive performance on ImageNet classification while enabling highly interpretable explanations through direct visualization of the linear transforms. The approach differs from traditional ViTs by replacing non-linear components with linear approximations, allowing the model's decision-making process to be directly visualized and understood.

## Key Results
- B-cos ViTs achieve competitive ImageNet classification performance
- Explanations outperform post-hoc methods on localization and pixel perturbation metrics
- Model-inherent explanations provide direct visualization of decision-making process

## Why This Works (Mechanism)
The approach works by transforming each component of the Vision Transformer into a dynamic linear function. This linearization allows the entire model to be represented as a single linear transform for each specific input, which can then be directly visualized. The linear formulation preserves the essential information flow while making the decision-making process transparent and interpretable.

## Architecture Onboarding

Component Map:
Input Image -> Linear Tokenisation -> Linear Attention -> Linear MLPs -> Linear Classifier -> Output

Critical Path:
The critical path consists of the sequential application of linear components. Each stage transforms the input representation while maintaining linear properties, culminating in the final classification decision.

Design Tradeoffs:
The primary tradeoff is between model capacity and interpretability. Linear components sacrifice some representational power but gain complete transparency. This design choice enables direct visualization of the decision-making process at the cost of potential accuracy reduction compared to non-linear alternatives.

Failure Signatures:
- Poor performance on tasks requiring complex non-linear interactions
- Over-simplification of feature representations leading to reduced accuracy
- Potential inability to capture hierarchical features effectively
