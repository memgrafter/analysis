# Eye-SpatialNet: Spatial Information Extraction from Ophthalmology Notes

## Quick Facts
- arXiv ID: 2305.11948
- Source URL: https://arxiv.org/abs/2305.11948
- Reference count: 31
- Primary result: First comprehensive representation and extraction of detailed spatial information from ophthalmology notes using Eye-SpatialNet schema

## Executive Summary
Eye-SpatialNet presents a novel frame semantics-based representation schema for extracting spatial and contextual information from ophthalmology clinical notes. The system extends existing radiology schemas to address ophthalmology-specific needs, incorporating entities like drugs, procedures, and detailed spatial descriptors. Using a two-turn question answering approach with BERT, the model extracts spatial triggers, anatomical locations, findings, and descriptors from clinical text. The framework demonstrates strong performance in identifying spatial relationships within ophthalmology notes, with particular success in detecting spatial triggers and ground frame elements.

## Method Summary
The Eye-SpatialNet system employs a two-turn question answering approach using BERTLARGE-MIMIC model. First, spatial triggers are identified using a Queryfind method with descriptions. Then, frame elements are extracted sequentially by generating queries from the initial spatial triggers and using Queryfind + desc to find relevant text spans. The model is fine-tuned sequentially from radiology to ophthalmology domain, with training on 450 notes and evaluation on 100 test notes. Queries are generated using templates with entity descriptions, and performance is evaluated using exact match span comparison with precision, recall, and F1 metrics.

## Key Results
- Achieved F1 score of 89.31 for spatial trigger detection
- Extracted 1,715 spatial triggers, 7,308 findings, 2,424 anatomies, and 9,914 descriptors from 600 annotated notes
- Obtained F1 scores of 74.86 for Figure frame elements and 88.47 for Ground frame elements
- First work to comprehensively represent and extract detailed spatial information from ophthalmology notes

## Why This Works (Mechanism)
The two-turn QA approach works effectively because it breaks down the complex spatial extraction task into manageable steps: first identifying spatial triggers that indicate the presence of spatial relationships, then using those triggers to generate targeted queries for extracting specific frame elements. This sequential approach allows the model to focus on relevant context and improves precision in identifying spatial relationships within the dense clinical text.

## Foundational Learning
- Frame semantics and semantic role labeling: Essential for understanding how spatial relationships are represented linguistically in clinical text, enabling structured extraction of medical findings
- Question answering for information extraction: Critical for adapting NLP techniques to clinical domains where explicit queries must be formulated to extract specific medical concepts
- Domain adaptation in NLP: Necessary for transferring knowledge from radiology to ophthalmology, addressing the challenge of specialized medical vocabularies and concepts

## Architecture Onboarding

**Component Map**: BERT model -> Spatial trigger detection -> Query generation -> Frame element extraction -> Evaluation

**Critical Path**: Spatial trigger identification → Query formulation → Frame element extraction → Performance evaluation

**Design Tradeoffs**: The two-turn QA approach sacrifices some potential recall for higher precision by focusing first on spatial triggers, but requires careful query template design and may miss implicit spatial relationships not triggered by explicit markers.

**Failure Signatures**: Lower performance on Drug and Device entities (F1 36.52 and 48.92) indicates the model struggles with less frequent entities and may require more training examples or specialized handling for these categories.

**First 3 Experiments**: 1) Test spatial trigger detection on external ophthalmology notes from different institution 2) Evaluate performance on radiology notes with ophthalmology findings embedded 3) Compare exact match evaluation with more lenient span matching to assess practical utility

## Limitations
- Limited generalizability due to single-institution dataset from Robert Cizik Eye Clinic
- Performance disparity between frame elements suggests model struggles with more complex extraction tasks
- Evaluation using exact span matching may be overly strict for variable clinical text phrasing

## Confidence
- High confidence in the schema design and annotation process: The Eye-SpatialNet schema is well-defined with clear entity types and frame elements, and the annotation methodology is thoroughly documented.
- Medium confidence in the BERT-based extraction approach: While the two-turn QA method shows promising results, the specific query templates and fine-tuning procedures are not fully specified, making exact replication challenging.
- Low confidence in the clinical applicability without further validation: The model performance on less frequent entities (Drug, Device) and frame elements (Diagnosis, Reason) is notably lower, and the evaluation does not assess clinical utility or impact on patient care.

## Next Checks
1. External validation: Test the trained model on ophthalmology notes from a different institution or clinical setting to assess generalizability and identify potential domain adaptation needs.
2. Error analysis and model refinement: Conduct detailed error analysis on false positives/negatives, particularly for lower-performing frame elements, and investigate whether alternative query formulations or model architectures could improve performance.
3. Clinical utility assessment: Partner with clinicians to evaluate whether the extracted spatial information actually improves clinical workflows, disease monitoring accuracy, or screening effectiveness in real-world settings.
