# Grokking modular arithmetic

## Quick Facts
- **arXiv ID**: 2301.02679
- **Source URL**: https://arxiv.org/abs/2301.02679
- **Reference count**: 25
- **Key outcome**: Two-layer neural networks can learn modular arithmetic tasks and exhibit grokking behavior with analytically solvable weights

## Executive Summary
This paper presents a theoretical and empirical analysis of how two-layer neural networks can learn modular arithmetic tasks through a phenomenon called "grokking" - where generalization occurs suddenly after extensive training. The authors derive analytical expressions for the network weights that solve modular addition tasks, showing that these solutions are found by standard optimization algorithms like gradient descent and AdamW. The network uses a mean-field parametrization and mean squared error loss without requiring explicit regularization. The key insight is that the network learns to represent modular functions using trigonometric functions with frequencies determined by the base of modular addition, where phases are chosen to create constructive interference at the correct output values.

## Method Summary
The paper focuses on two-layer neural networks with mean-field parametrization to solve modular arithmetic tasks. The architecture uses ReLU activation functions and mean squared error loss. The authors provide analytical solutions for the network weights that enable perfect generalization on modular addition tasks, demonstrating that these analytical solutions match what gradient descent discovers during training. The approach involves mapping input pairs to feature spaces using trigonometric functions whose frequencies depend on the modular base, then combining these features to produce the correct modular output. The analysis shows that the network learns to create interference patterns that constructively reinforce the correct output values while canceling incorrect ones.

## Key Results
- Two-layer networks with mean-field parametrization can analytically solve modular arithmetic tasks
- No explicit regularization is required for grokking to occur in these architectures
- The network learns feature maps that are complete sets of trigonometric functions with frequencies determined by the modular base
- The critical amount of data needed for generalization can be computed analytically
- The phenomenon extends to other modular functions beyond addition, including n² + m² and (n + m)²

## Why This Works (Mechanism)
The network succeeds by learning to represent modular arithmetic as interference patterns between trigonometric functions. The key mechanism is that the network discovers feature maps that correspond to complete sets of trigonometric functions with frequencies determined by the modular base. These functions are phase-shifted to ensure constructive interference at positions where the modular sum equals the target value. The mean-field parametrization allows the analytical solution to capture this interference pattern precisely, enabling perfect generalization even when training data is limited. The ReLU activation function plays a crucial role in creating the non-linear feature mappings necessary for this representation.

## Foundational Learning
- **Modular arithmetic**: The mathematical operation of wrapping around after reaching a base value (e.g., 3 + 2 mod 4 = 1). This is the target function the network must learn to generalize beyond training data.
- **Mean-field parametrization**: A weight initialization scheme where weights are drawn from a distribution rather than being fixed, allowing for analytical tractability. This enables deriving closed-form solutions for the network weights.
- **Grokking**: The phenomenon where neural networks show sudden generalization after prolonged training, transitioning from memorization to true understanding. This is the key behavior being studied and explained.
- **Feature map learning**: The process by which networks discover useful representations of input data. Here, the network learns trigonometric feature maps that encode modular relationships.
- **Constructive interference**: The wave phenomenon where aligned phases amplify each other. The network uses this principle to reinforce correct output values while canceling incorrect ones.

## Architecture Onboarding

### Component map
Input pairs (n, m) -> Two-layer network with ReLU activation -> Feature maps (trigonometric functions) -> Linear combination -> Modular output

### Critical path
Input -> First layer (feature map discovery) -> Second layer (interference pattern creation) -> Output. The first layer discovers the trigonometric feature maps, while the second layer learns the correct linear combination to create constructive interference at target values.

### Design tradeoffs
The mean-field parametrization enables analytical solutions but may limit expressiveness compared to fixed initialization schemes. The two-layer architecture is minimal for capturing the interference pattern but may not scale to more complex modular relationships. The MSE loss function works well for this task but other losses might affect grokking behavior.

### Failure signatures
Poor generalization occurs when the network fails to discover the correct feature maps, resulting in incorrect interference patterns. This manifests as continued overfitting to training data without the sudden generalization jump. Insufficient training data or inappropriate initialization can prevent the network from finding the analytical solution.

## Open Questions the Paper Calls Out
The paper doesn't explicitly call out open questions, but the work raises several natural directions: whether the analytical framework extends to deeper networks, how grokking behavior varies across different initialization schemes and hyperparameters, and whether similar interference-based mechanisms apply to non-modular arithmetic tasks.

## Limitations
- Analytical solutions are limited to two-layer networks with mean-field parametrization, potentially limiting generalization to deeper architectures
- The framework doesn't fully explain why certain bases (like base 2) show more pronounced grokking than others
- The results may be sensitive to initialization schemes and hyperparameter choices that aren't thoroughly explored
- The physical interpretation of the learned interference patterns could benefit from further theoretical development
