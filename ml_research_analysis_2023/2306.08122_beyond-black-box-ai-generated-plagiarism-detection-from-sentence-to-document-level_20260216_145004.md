# Beyond Black Box AI-Generated Plagiarism Detection: From Sentence to Document Level

## Quick Facts
- arXiv ID: 2306.08122
- Source URL: https://arxiv.org/abs/2306.08122
- Reference count: 12
- This paper introduces a plagiarism detection method that compares student answers to AI-generated responses using multiple paraphrased prompts and cosine similarity metrics, achieving up to 94% accuracy on a mixed-domain dataset while providing sentence- and document-level explanations.

## Executive Summary
This paper presents a novel approach to AI-generated plagiarism detection that moves beyond black-box methods by comparing student submissions against multiple AI-generated responses created from paraphrased prompts. The system achieves high accuracy while providing interpretable results at both sentence and document levels. By avoiding black-box detection mechanisms, the method offers transparency in its decision-making process and adapts to different large language models without requiring retraining when models are upgraded.

## Method Summary
The plagiarism detection method works by generating multiple reference responses using different paraphrased versions of the original prompt across various LLMs. Student submissions are then compared against these AI-generated references using cosine similarity metrics at both sentence and document levels. The approach creates a transparent comparison framework where the similarity scores between student work and AI-generated content can be examined and explained, rather than relying on opaque classification models. The system's design allows it to function across different LLM architectures without requiring model-specific retraining.

## Key Results
- Achieves up to 94% accuracy on a mixed-domain dataset
- Provides interpretable results at both sentence and document levels
- Successfully adapts to different LLMs without requiring retraining when models are upgraded

## Why This Works (Mechanism)
The method's effectiveness stems from its comparative approach that leverages multiple AI-generated references rather than relying on a single detection model. By using paraphrased prompts to generate diverse reference responses, the system captures a broader representation of how AI might respond to similar queries. The cosine similarity metric provides a quantifiable measure of textual overlap that can be explained and interpreted. The multi-level analysis (sentence and document) allows for granular detection while maintaining an overall assessment, making the detection process more transparent and interpretable than traditional black-box methods.

## Foundational Learning
- Cosine similarity metric - needed to quantify textual overlap between student and AI-generated responses; quick check: verify that higher scores indicate greater similarity
- Sentence-level vs document-level analysis - needed to provide both granular and holistic detection; quick check: ensure sentence scores aggregate correctly to document scores
- Prompt paraphrasing techniques - needed to generate diverse AI reference responses; quick check: confirm paraphrased prompts maintain semantic equivalence while varying surface form
- LLM adaptation mechanisms - needed to ensure method works across different model architectures; quick check: test with at least two different LLM families

## Architecture Onboarding

**Component Map:** Student submission -> Preprocessing -> Sentence tokenizer -> Cosine similarity calculator -> Aggregation module -> Sentence-level scores -> Document-level scores -> Explanation generator

**Critical Path:** Input document -> Paraphrase generator -> Multiple LLM invocations -> Reference response collection -> Cosine similarity computation -> Result aggregation

**Design Tradeoffs:** Uses cosine similarity for transparency vs. more complex semantic embeddings; multiple prompt paraphrasing vs. single prompt efficiency; sentence-level granularity vs. computational overhead

**Failure Signatures:** False positives from common phrase overlap, false negatives from sophisticated paraphrasing, performance degradation with highly domain-specific content, sensitivity to reference LLM quality

**First Experiments:** 1) Run system with known AI-generated and human-written samples to verify basic functionality, 2) Test with paraphrased versions of the same content to assess sensitivity, 3) Compare results across different LLM reference models

## Limitations
- May face practical limitations when dealing with highly specific or domain-constrained prompts
- Reliance on cosine similarity may not capture semantic nuances that more sophisticated embeddings could detect
- Effectiveness against advanced paraphrasing and paraphrasing-aware AI detectors remains uncertain

## Confidence
- 94% accuracy claim: High confidence in reported results but requires independent verification
- Adaptability to model upgrades: Medium confidence - plausible but needs real-world testing across multiple model generations
- Avoidance of black-box behavior: High confidence - well-supported by transparent comparison methodology
- Performance against advanced paraphrasing: Low confidence - represents a potential vulnerability not fully addressed
