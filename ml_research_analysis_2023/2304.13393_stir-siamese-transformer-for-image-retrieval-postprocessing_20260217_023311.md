# STIR: Siamese Transformer for Image Retrieval Postprocessing

## Quick Facts
- arXiv ID: 2304.13393
- Source URL: https://arxiv.org/abs/2304.13393
- Reference count: 10
- Key outcome: STIR achieves 94.9% CMC@1 on DeepFashion In-shop, surpassing previous state-of-the-art of 92.7%.

## Executive Summary
STIR introduces a Siamese Transformer architecture for postprocessing image retrieval results. Unlike previous re-ranking methods, STIR performs pixel-level attention-based comparisons between query and candidate images without relying on global or local feature extraction. The method achieves state-of-the-art results on Stanford Online Products and DeepFashion In-shop datasets by re-ranking top results from a strong baseline model. STIR demonstrates that direct pixel-level comparisons using attention mechanisms can effectively improve already high-performing retrieval systems.

## Method Summary
STIR is a Siamese Transformer that re-ranks top results from a base retrieval model by performing pairwise comparisons between query and gallery images. The model concatenates query and candidate images, processes them through a Vision Transformer backbone, and outputs a binary probability indicating whether the pair is a negative match. Training uses hard negative mining with batch sizes of P=30 labels and K=4 images per label. The asymmetric nature of the Siamese architecture allows for directional context, which can be symmetrized by averaging results from both orderings.

## Key Results
- Achieves 94.9% CMC@1 on DeepFashion In-shop dataset
- Improves upon ViT-Triplet baseline and outperforms previous re-ranking methods
- CMC@1 metric saturates quickly as number of re-ranked results increases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: STIR improves retrieval by directly comparing pixel-level features of query-gallery pairs using attention.
- Mechanism: The Siamese Transformer processes concatenated query and gallery images through a ViT backbone, enabling attention to focus on region-level correspondences across both images simultaneously.
- Core assumption: Pixel-level comparisons provide complementary information to global embeddings, especially when top results are already close.
- Evidence anchors:
  - [abstract] "STIR does not rely on global/local feature extraction and directly compares a query image and a retrieved candidate on pixel level with the usage of attention mechanism."
  - [section 3.2] "We suggest to use a reranking model that performs pairwise comparisons of the query image and top retrieved results."
  - [corpus] Weak - no corpus neighbors directly discuss pixel-level attention for reranking.
- Break condition: If the feature extractor fails to produce discriminative embeddings, pixel-level comparisons will have little discriminative power.

### Mechanism 2
- Claim: STIR's asymmetry can be leveraged for better reranking by considering both (query, gallery) and (gallery, query) orderings.
- Mechanism: The model produces different outputs depending on which image is placed first, capturing directional context that can be averaged for symmetric results.
- Core assumption: Image similarity is not perfectly symmetric in feature space, and averaging directional outputs improves robustness.
- Evidence anchors:
  - [section 3.2] "Another important property of STIR is that it is asymmetric... we have not found significant differences between these two options, but the results improve a little further if we symmetrize STIR by averaging their results."
  - [section 4.3] "STIR-Symmetric (ViT-Triplet), n = 5" shows improved CMC@1 over non-symmetric version.
  - [corpus] Missing - no corpus discussion of asymmetric Siamese models.
- Break condition: If both orderings produce nearly identical outputs, symmetrization adds computational cost without benefit.

### Mechanism 3
- Claim: Limiting reranking to top-k results allows use of heavier models without sacrificing efficiency.
- Mechanism: Since ViT-Triplet already produces high-quality top results (CMC@5 = 97.6% on In-Shop), STIR only needs to process a small number of pairs, making the computationally expensive ViT-based reranking feasible.
- Core assumption: The top-k results from the base model contain most or all correct answers, so reranking a small set suffices.
- Evidence anchors:
  - [section 3.2] "with a good feature extractor CMC@k saturates for relatively small values of k, such as k = 5, so we do not need to rerank a lot and can afford to use a relatively heavyweight model."
  - [section 4.3] Table 3 shows CMC@1 saturates quickly as n increases, supporting limited reranking.
  - [corpus] Weak - no corpus neighbors discuss saturation of CMC@k or limited reranking.
- Break condition: If the base model's top-k results frequently miss correct answers, limited reranking will fail to recover them.

## Architecture Onboarding

- Component map:
  - Base model: ViT-Triplet (ViT-S/16 + triplet loss)
  - Reranking model: STIR (ViT-S/16 + concatenated image pair input + MLP head)
  - Training data pipeline: SOP and In-Shop datasets with hard pair mining
  - Evaluation: CMC@k, mAP@k metrics

- Critical path:
  1. Train ViT-Triplet on dataset with hard triplet mining
  2. Extract top-k results from base model
  3. Form image pairs (query + each top result)
  4. Train/fine-tune STIR on these pairs with binary cross-entropy
  5. Rerank by STIR scores and evaluate

- Design tradeoffs:
  - Reranking only top-k limits computational cost but may miss deeper corrections
  - Asymmetric STIR allows directional context but requires symmetrization for best results
  - Using full images in STIR preserves detail but increases latency vs. using intermediate features

- Failure signatures:
  - STIR fails to improve CMC@1 despite high base performance → likely base model already optimal or reranking model underfit
  - STIR training diverges → check pair mining strategy and learning rate
  - STIR adds latency without accuracy gain → verify that top-k contains incorrect answers worth correcting

- First 3 experiments:
  1. Train ViT-Triplet on SOP with default hyperparameters; verify CMC@1 > 85%
  2. Implement STIR with n=3; train on top-3 pairs from ViT-Triplet; measure CMC@1 improvement
  3. Compare asymmetric vs symmetric STIR; confirm symmetrization improves results

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can gallery-to-gallery interactions be incorporated into the STIR model to improve re-ranking performance?
- Basis in paper: [explicit] The paper states that "we only consider direct query-to-gallery interactions, while gallery-to-gallery interactions are left indirect."
- Why unresolved: The paper does not explore methods for incorporating gallery-to-gallery interactions into the STIR architecture, which could potentially improve re-ranking accuracy by considering relationships between gallery images.
- What evidence would resolve it: Experimental results comparing STIR with and without gallery-to-gallery interaction mechanisms, showing improvements in re-ranking metrics like CMC@k and mAP@k.

### Open Question 2
- Question: What is the optimal number of top results to re-rank for balancing computational efficiency and retrieval performance?
- Basis in paper: [explicit] The paper notes that "CMC@1 (Recall@1) metric saturates quickly as we increase n" in the ablation study, but does not provide a definitive recommendation for the optimal n.
- Why unresolved: While the paper shows that CMC@1 saturates, it does not fully explore the trade-off between computational cost and performance gains across different dataset sizes and types.
- What evidence would resolve it: A comprehensive study varying the number of re-ranked results (n) across multiple datasets, showing the point of diminishing returns for both accuracy and computational cost.

### Open Question 3
- Question: How would replacing the ViT backbone with more efficient architectures like Swin Transformer affect STIR's performance and speed?
- Basis in paper: [explicit] The paper suggests that "replacing it with an architecture such as the Swin Transformer... may significantly speed up postprocessing" due to its linear complexity with respect to image size.
- Why unresolved: The paper only proposes this as a future direction without empirical validation of the performance and speed trade-offs.
- What evidence would resolve it: Experimental results comparing STIR with ViT versus Swin Transformer backbones, showing both accuracy metrics and computational efficiency improvements.

## Limitations
- Limited evaluation to only two datasets (SOP and In-shop), leaving generalizability uncertain
- Does not explore gallery-to-gallery interactions that could further improve re-ranking
- Heavy computational cost of ViT-based reranking may limit practical deployment

## Confidence

- **High confidence**: STIR architecture, training procedure, and baseline results on SOP and In-shop datasets
- **Medium confidence**: Claims about pixel-level attention benefits and efficiency of limited reranking
- **Low confidence**: Claims about STIR's superiority in general retrieval scenarios beyond the tested datasets
