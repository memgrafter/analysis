# Demonstration-free Autonomous Reinforcement Learning via Implicit and Bidirectional Curriculum

## Quick Facts
- arXiv ID: 2305.09943
- Source URL: https://arxiv.org/abs/2305.09943
- Reference count: 23
- Primary result: IBC achieves state-of-the-art performance in non-episodic, reset-free RL without demonstrations

## Executive Summary
This paper introduces IBC (Implicit and Bidirectional Curriculum), a demonstration-free autonomous reinforcement learning algorithm designed for non-episodic, reset-free environments. The method combines an auxiliary agent that conditionally assists the main agent and fades away as learning progresses, with a bidirectional goal curriculum generated via optimal transport. IBC enables autonomous learning from scratch in sparse reward environments by generating intermediate goals for both forward and backward episodes without requiring expert demonstrations. The approach is evaluated on six benchmark tasks and outperforms previous methods in sample efficiency and final success rate, even compared to methods that leverage demonstrations.

## Method Summary
IBC operates by combining a conditionally activated auxiliary agent with a bidirectional goal curriculum based on optimal transport. The auxiliary agent is only activated when the forward agent fails at the given curriculum goal, gradually fading out as the forward agent improves. The bidirectional curriculum generates intermediate goals for both forward and backward episodes by sampling states from past trajectories in the replay buffer and assigning them to target distributions using bipartite matching based on Wasserstein distance. This creates a sequence of increasingly difficult goals without requiring expert demonstrations. The method uses SAC with goal relabeling and operates in non-episodic, reset-free environments by leveraging the bidirectional curriculum to generate initial states and goals.

## Key Results
- IBC outperforms previous methods on six benchmark tasks in terms of sample efficiency and final success rate
- The method achieves state-of-the-art performance even compared to methods that leverage demonstrations
- Ablation studies confirm the effectiveness of both the implicit curriculum (auxiliary agent) and the explicit bidirectional curriculum

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Conditional activation of the auxiliary agent reduces interference from unnecessary backward episodes as the forward agent improves.
- **Mechanism**: The auxiliary agent is only activated when the forward agent fails to achieve the curriculum goal, gradually fading out as the forward agent becomes more capable. This allows more training transitions to be devoted to the forward agent, improving sample efficiency.
- **Core assumption**: The forward agent's learning progress can be reliably measured by its success rate on curriculum goals.
- **Evidence anchors**:
  - [abstract] "auxiliary agent that is conditionally activated upon learning progress and fades away as learning progresses"
  - [section 4.1] "we conditionally activate the auxiliary agent when the forward agent has failed at the given goal state such that the auxiliary agent gradually disappears as the forward agent improves"
- **Break condition**: If the success rate metric is noisy or plateaus early, the auxiliary agent may remain active longer than optimal, reducing sample efficiency.

### Mechanism 2
- **Claim**: Bidirectional goal curriculum generation via optimal transport enables non-episodic RL without demonstrations by generating intermediate goals for both forward and backward agents.
- **Mechanism**: Curriculum goals are sampled from past trajectories in the replay buffer and assigned to target distributions (ρtar(s) for forward, ρ0,tar(s) for auxiliary) using bipartite matching based on Wasserstein distance. This creates a sequence of increasingly difficult goals without requiring expert demonstrations.
- **Core assumption**: Past trajectories in the replay buffer contain states that are informative for constructing a curriculum toward the target distribution.
- **Evidence anchors**:
  - [abstract] "bidirectional goal curriculum based on optimal transport to generate intermediate goals for both forward and backward episodes"
  - [section 4.2] "We propose a bidirectional goal curriculum based on the surrogate problem... for both forward and auxiliary agents without relying on demonstrations"
- **Break condition**: If the replay buffer lacks diversity or the optimal transport matching fails to find meaningful intermediate states, the curriculum may stall or provide poor guidance.

### Mechanism 3
- **Claim**: Using a subset of the optimal state distribution (ρtar(s)) as the target for the forward agent approximates the theoretically ideal initial state distribution, improving training efficiency.
- **Mechanism**: By setting ρtar(s) to be a subset of ρ*(s) from the optimal policy, the forward agent learns to practice from states that are closer to where it will be evaluated, reducing the need for full resets.
- **Core assumption**: A state distribution close to ρ*(s) enables more efficient RL training, as supported by prior theory (Kakade & Langford, 2002).
- **Evidence anchors**:
  - [section 4.1] "Interestingly, a previous work (Kakade & Langford, 2002) provides theoretical grounds that ρ0(s) close to ρ*(s) enables efficient training in RL"
- **Break condition**: If ρtar(s) is poorly chosen or too small, the forward agent may not receive adequate diversity in initial states, harming exploration and robustness.

## Architecture Onboarding

- **Component map**: Replay buffer -> Curriculum buffer -> Bidirectional goal curriculum module -> Forward agent and Auxiliary agent -> Environment

- **Critical path**:
  1. Sample initial state from ρ0(s)
  2. Select agent (forward or auxiliary) based on success/failure
  3. Generate curriculum goal from bidirectional module
  4. Execute policy, store transition
  5. Periodically update curriculum goals via optimal transport
  6. Update policies using SAC with goal relabeling

- **Design tradeoffs**:
  - Conditional activation vs. always-on auxiliary agent: balances sample efficiency with stability
  - Bidirectional vs. unidirectional curriculum: provides richer guidance but increases complexity
  - Optimal transport vs. simpler distance metrics: more principled but computationally heavier

- **Failure signatures**:
  - Auxiliary agent never deactivates: success rate metric unreliable or task too hard
  - Curriculum goals converge to poor regions: suboptimal target distributions or buffer sampling issues
  - Forward agent fails to improve: insufficient diversity in initial states or poor curriculum guidance

- **First 3 experiments**:
  1. Run IBC with fixed auxiliary agent (no conditional activation) to measure sample efficiency loss
  2. Remove bidirectional curriculum, use only forward agent with random goals to test curriculum necessity
  3. Replace optimal transport with random goal selection to validate the importance of principled curriculum generation

## Open Questions the Paper Calls Out
- How does the performance of IBC change when applied to environments with irreversible actions or non-ergodic dynamics?
- What is the optimal balance between the implicit curriculum (auxiliary agent fading) and explicit bidirectional curriculum in terms of learning efficiency?
- How sensitive is IBC to the choice of goal space transformation functions φf and φa?

## Limitations
- Computational overhead of optimal transport-based curriculum generation, which scales quadratically with buffer size
- Assumption that past trajectories contain useful states for curriculum construction
- Requirement for careful tuning of the auxiliary agent's activation threshold

## Confidence
- Medium: The bidirectional curriculum mechanism is well-justified, but empirical validation relies on synthetic benchmarks with available ground-truth success rates
