# HIINT: Historical, Intra- and Inter- personal Dynamics Modeling with Cross-person Memory Transformer

## Quick Facts
- arXiv ID: 2305.12369
- Source URL: https://arxiv.org/abs/2305.12369
- Reference count: 40
- Primary result: CPM-T outperforms baselines by up to 7.3%, 9.3%, and 2.0% F1-scores on joint engagement, rapport, and human beliefs prediction tasks respectively.

## Executive Summary
This paper introduces CPM-T, a Cross-person Memory Transformer framework that models affect dynamics in interactive conversations by explicitly capturing intrapersonal and interpersonal influences. The model uses cross-person attention to model contingent behaviors between individuals, memory slot attention to retain historical context, and integrates LLM reasoning to guide interpretation of verbal cues. Experiments on three public datasets show significant improvements over baseline models for predicting joint engagement, rapport, and human beliefs in multi-party interactions.

## Method Summary
CPM-T processes multimodal inputs (audio, video, text) through individual separation using video inpainting and speaker diarization. Cross-modal transformers fuse features, followed by cross-person attention to model interpersonal influences and memory slot attention to capture historical context. LLM-generated reasoning sentences provide verbal context guidance for interpreting nonverbal cues. The framework maintains memory modules to store conversation contexts and employs cross-modal attention to align information across modalities. The model is trained with AdamW optimizer using dataset-specific hyperparameters and evaluated on three classification tasks across three public datasets.

## Key Results
- Outperforms baseline models by up to 7.3% average F1-score on joint engagement prediction
- Achieves 9.3% improvement in average F1-score for rapport prediction tasks
- Shows 2.0% better performance on human beliefs prediction compared to state-of-the-art methods

## Why This Works (Mechanism)

### Mechanism 1
Cross-person attention models contingent behaviors between pairs of people, where a target person's behavior is influenced by another person's behavior. This is achieved through attention weights between multimodal representations of different individuals, capturing interpersonal influence patterns in conversations.

### Mechanism 2
LLM-generated reasoning sentences provide verbal context that guides interpretation of nonverbal cues. The verbal context initializes memory banks and helps align nonverbal behaviors with their corresponding verbal meaning through cross-modal attention mechanisms.

### Mechanism 3
Dynamic memory network with memory slot attention captures long-range dependencies and retains important historical context. Memory read and write operations with slot attention allow the model to encode and retrieve past information, preventing interference between slots while maintaining contextual information across conversation windows.

## Architecture Onboarding

- **Component map**: Video/Audio → Individual Separation → Cross-modal Fusion → Cross-person Attention → Memory Processing → Prediction
- **Critical path**: Input features → Individual separation → Cross-modal fusion → Cross-person attention → Memory processing → Prediction output
- **Design tradeoffs**: Memory slots vs. standard attention (better retention but higher complexity), LLM integration vs. direct modeling (improved performance but external dependency), individual separation vs. joint modeling (clearer interpersonal dynamics but requires preprocessing)
- **Failure signatures**: Poor performance on low-engagement classes indicates insufficient modeling of subtle dynamics; degradation on longer conversations suggests memory limitations; inconsistent results across datasets may indicate overfitting
- **First 3 experiments**: 1) Compare CPM-T with/without LLM guidance on DAMI-P2C, 2) Test memory slot configurations on MPIIGroupInteraction, 3) Evaluate individual modality contributions on BOSS dataset

## Open Questions the Paper Calls Out

- **Open Question 1**: How can CPM-T be adapted to handle more complex multi-party interactions beyond dyadic conversations? The paper suggests future research should focus on models that take into account more complex social dynamics, but doesn't provide specific extension mechanisms.

- **Open Question 2**: How can memory modules be improved to better capture long-range dependencies and contextual information? While the paper uses memory slot attention, it acknowledges that further research is needed to enhance scalability and interpretability of memory networks.

- **Open Question 3**: How can the model be extended to handle more diverse and nuanced affective states beyond predefined categories? The authors suggest this as future work but don't provide specific approaches for handling more granular affective states.

## Limitations

- The framework's performance gains may be overestimated due to limited analysis of failure cases and challenging subsets like low-engagement scenarios.
- Memory slot attention mechanism has quadratic complexity that may limit scalability for very long conversations.
- Dependency on LLM quality for verbal context guidance introduces uncertainty about the model's robustness to varying LLM performance levels.

## Confidence

- **High Confidence**: Overall architecture design and baseline comparisons are well-documented with supported performance claims.
- **Medium Confidence**: LLM reasoning mechanism is plausible but not fully validated through controlled experiments; cross-person attention effectiveness depends on contingent behavior assumptions.
- **Low Confidence**: Claims about capturing "complex dependencies" lack empirical validation through attention pattern interpretability analyses.
