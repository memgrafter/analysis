# CAT: A Contextualized Conceptualization and Instantiation Framework for Commonsense Reasoning

## Quick Facts
- **arXiv ID:** 2305.04808
- **Source URL:** https://arxiv.org/abs/2305.04808
- **Reference count:** 40
- **Key outcome:** Semi-supervised CAT framework achieves state-of-the-art performance on conceptualization tasks and improves commonsense reasoning modeling

## Executive Summary
This paper introduces CAT, a semi-supervised learning framework that conceptualizes commonsense knowledge bases to acquire abstract knowledge for improving commonsense reasoning. The method integrates event conceptualization and instantiation via bootstrapping to scale contextualized knowledge acquisition. Experiments demonstrate CAT achieves state-of-the-art performance on two conceptualization tasks and significantly improves commonsense inference modeling, with GPT2 models trained on CAT-derived knowledge outperforming baselines by up to 11.8% on generative conceptualization and 2.2% on commonsense reasoning tasks.

## Method Summary
CAT is a semi-supervised learning framework that addresses the lack of annotations in commonsense knowledge bases by using teacher-student models with pseudo-label refinement. The framework consists of two main components: event conceptualization (determining if a head event can be abstracted into a valid concept) and triple conceptualization (validating abstract triples within their context). CAT employs bootstrapping with alternative conceptualizations and instantiations retrieved via natural language prompts, creating a feedback loop that mutually reinforces both tasks. The method uses KG-BERT-based teacher models to generate initial pseudo-labels, which are then refined by student models trained with bootstrapping.

## Key Results
- CAT achieves state-of-the-art performance on two conceptualization tasks, improving over baselines by 2.1-3.4% on test set AUC
- GPT2 models trained on CAT-derived knowledge outperform baselines by up to 11.8% on generative conceptualization tasks
- The framework significantly improves commonsense inference modeling, demonstrating 2.2% improvement on commonsense reasoning benchmarks
- Ablation studies show that removing the CAT cycle component reduces performance (e.g., 88.1→87.4 AUC for event conceptualization with DeBERTa-v3-large)

## Why This Works (Mechanism)

### Mechanism 1: Bootstrapping alternative conceptualizations
Bootstrapping alternative conceptualizations and instantiations improves discriminative conceptualization accuracy by retrieving and ranking alternatives for each head event, then aggregating them via natural language prompts to create an ensemble signal that reinforces correct conceptualizations and flags implausible ones.

### Mechanism 2: CAT cycle mutual reinforcement
The CAT cycle (event conceptualization → triple conceptualization → event conceptualization) mutually reinforces both tasks by using instantiations to help verify triple plausibility within context, then feeding results back to refine event conceptualization, creating a feedback loop.

### Mechanism 3: Pseudo-label refinement
Pseudo-label refinement using student models improves data quality and generalization by having student models re-score and refine initial pseudo-labels generated by teacher models, discarding low-confidence examples and re-training.

## Foundational Learning

- **Concept: Event conceptualization (discriminative)**
  - Why needed here: Core task is determining if a head event can be abstracted into a valid concept; discriminative models are needed to verify correctness
  - Quick check question: Given event "PersonX watches football game", is conceptualizing to "relaxing event" valid? Answer: Yes, if it aligns with relation/tail; No, if it omits critical context

- **Concept: Triple conceptualization**
  - Why needed here: After head event conceptualization, the abstract triple must be validated within its context (relation, tail) to ensure it yields plausible commonsense knowledge
  - Quick check question: Is the triple ("relaxing event", xIntent, "have fun") plausible? Answer: Yes, because relaxing events generally intend to have fun

- **Concept: Bootstrapping in NLP**
  - Why needed here: Leverages alternative conceptualizations/instantiations to strengthen learning signals without requiring massive labeled data
  - Quick check question: What is the role of retrieved alternatives in bootstrapping? Answer: They provide additional context and ensemble-like signals to improve discrimination

## Architecture Onboarding

- **Component map:** Teacher models (event & triple conceptualization) → pseudo-label assignment → Alternative retrieval & ranking → Bootstrapping via prompts → Student models (event & triple conceptualization) → Refinement & final training

- **Critical path:**
  1. Train teacher models on labeled data
  2. Assign pseudo-labels to unlabeled data using teacher models
  3. Retrieve alternative conceptualizations/instantiations
  4. Bootstrap via prompt aggregation and train student models
  5. Refine pseudo-labels with student models
  6. Retrain final student models on refined data

- **Design tradeoffs:**
  - More retrievals → richer signals but higher computational cost and potential noise
  - Higher thresholds for pseudo-labels → higher quality but less data
  - Using GPT2 for generative conceptualization → better abstraction but weaker discriminative performance

- **Failure signatures:**
  - AUC plateaus or drops after increasing retrievals
  - Pseudo-labels skewed toward easy examples (threshold too high)
  - Student models diverge from teacher models (possible overfitting)

- **First 3 experiments:**
  1. Teacher model ablation: Train CAT with and without teacher models; compare pseudo-label quality
  2. Retrieval size tuning: Vary number of alternative conceptualizations/instantiations; plot performance vs. retrieval count
  3. Threshold sensitivity: Sweep T+ and T−; measure final test AUC and pseudo-label distribution

## Open Questions the Paper Calls Out

### Open Question 1
How can dynamic thresholding be implemented to automatically select optimal thresholds for pseudo-label assignment in CAT, rather than relying on manually set thresholds? The paper mentions this as a limitation and suggests dynamic thresholding or meta pseudo labels could be implemented.

### Open Question 2
How would CAT perform on conceptualization tasks using other commonsense knowledge bases beyond ATOMIC, such as ATOMIC2020, GLUCOSE, or ASER? The paper only tested CAT on AbstractATOMIC and suggests verifying the framework on other CSKBs as future work.

### Open Question 3
How does CAT's performance compare to large language models like GPT-3.5 or ChatGPT on conceptualization tasks? The paper only provides limited case studies with ChatGPT due to limited access to these models.

### Open Question 4
What is the impact of CAT's abstract commonsense knowledge on other commonsense reasoning tasks beyond COMET, such as CommonsenseQA, SocialIQA, or Winograd Schema Challenge? The paper only evaluates CAT's impact on one task (COMET).

## Limitations
- Syntactic parsing rules for instance identification within head events are not specified, which is critical for accurate conceptualization
- Specific prompt templates used for bootstrapping are not detailed, leaving ambiguity about how alternative concepts are aggregated
- Retrieval mechanisms for alternative conceptualizations and instantiations lack specification regarding similarity metrics and candidate generation strategies

## Confidence

**High Confidence:** The core methodology of combining event conceptualization with triple conceptualization through bootstrapping is well-supported by experimental results, with ablation studies validating the framework's design.

**Medium Confidence:** The claim that pseudo-label refinement via student models improves data quality is supported by performance gains, but implementation details significantly affect the mechanism.

**Low Confidence:** The assertion that CAT-derived knowledge "significantly improves commonsense inference modeling" relies on specific baseline comparisons without detailed error analysis showing why CAT knowledge is superior.

## Next Checks
1. **Implementation fidelity test:** Reconstruct the syntactic parsing rules for instance identification using the AbstractATOMIC dataset and evaluate their precision on a held-out sample of events.

2. **Prompt template ablation:** Systematically vary the prompt templates used for bootstrapping and measure their impact on conceptualization accuracy to identify which prompt formulations are most critical.

3. **Generalization boundary test:** Evaluate CAT-trained models on out-of-distribution events from ATOMIC that were not seen during training to assess whether the bootstrapping approach truly generalizes beyond the training distribution.
