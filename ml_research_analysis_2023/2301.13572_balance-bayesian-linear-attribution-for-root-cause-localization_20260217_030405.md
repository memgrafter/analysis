# BALANCE: Bayesian Linear Attribution for Root Cause Localization

## Quick Facts
- arXiv ID: 2301.13572
- Source URL: https://arxiv.org/abs/2301.13572
- Reference count: 40
- Key outcome: BALANCE achieves up to 6% higher accuracy than state-of-the-art methods for root cause analysis in distributed systems.

## Executive Summary
BALANCE addresses the challenge of root cause analysis in distributed data systems by formulating it as a feature attribution problem. The method combines a Bayesian multicollinear feature selection (BMFS) model with attribution analysis to identify the most likely causes of KPI anomalies. By handling correlated candidate causes and promoting sparsity, BALANCE provides interpretable results that can be used for system recovery decisions.

## Method Summary
BALANCE is a three-module framework for root cause analysis that uses Bayesian feature selection to predict target KPIs from candidate root causes in a forward manner, then applies attribution analysis in a backward manner to compute importance scores. The core innovation is the BMFS model with a correlated horse-shoe prior that handles multicollinearity while promoting sparsity. The framework is evaluated on synthetic data and three real-world tasks: bad SQL localization, container fault localization, and fault type diagnosis for Exathlon, achieving up to 6% higher accuracy than state-of-the-art methods.

## Key Results
- Achieves up to 6% higher accuracy than state-of-the-art RCA methods on synthetic and real-world datasets
- Successfully deployed in production for real-time diagnosis of distributed systems
- Demonstrates superior performance in handling multicollinearity and sparsity in candidate root causes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BALANCE achieves superior performance by modeling KPI-candidate relationships as linear regression with Bayesian feature selection
- Mechanism: Uses correlated horse-shoe prior to encourage sparsity and handle correlations among candidates, then applies attribution analysis for importance scoring
- Core assumption: Linear relationships exist between KPIs and candidate causes, and correlated horse-shoe prior accurately identifies relevant causes
- Evidence: Abstract states BMFS promotes sparsity while handling correlation; Section 4.1.1 details the correlated horse-shoe prior
- Break condition: If relationships are non-linear or prior fails to identify relevant causes, performance degrades

### Mechanism 2
- Claim: Bayesian framework handles high-dimensional RCA problems by automatically learning parameters
- Mechanism: Automatic parameter learning through variational inference eliminates manual tuning and adapts to data characteristics
- Core assumption: Bayesian framework can effectively learn parameters and handle missing values without intervention
- Evidence: Abstract mentions processing missing data through inference; Section 4.1.2 details variational inference algorithm
- Break condition: Insufficient data or excessive missing values prevent accurate parameter learning

### Mechanism 3
- Claim: Attribution analysis provides interpretable results for decision-making
- Mechanism: Computes importance scores based on regression coefficients and KPI changes during anomalies for ranking causes
- Core assumption: Attribution scores accurately reflect importance in explaining KPI anomalies
- Evidence: Abstract introduces attribution analysis; Section 4.2 details the method and its advantages
- Break condition: If attribution analysis fails to accurately compute scores or they're not interpretable

## Architecture Onboarding

- Component map: Data Collection -> Target ADCandidates AD -> BALANCE (BMFS, Attribution, Merging) -> Recovery Decision Maker
- Critical path: 1) Collect and aggregate data into time series database, 2) Conduct real-time anomaly detection on target KPI, 3) Trigger anomaly detection on candidates, 4) Load abnormal KPI and candidates, 5) Train forward BMFS model, 6) Compute candidate attributions, 7) Merge and rank root causes from multiple targets, 8) Send to recovery decision maker
- Design tradeoffs: Accuracy vs. efficiency (linear model), Interpretability vs. performance (attribution analysis), Flexibility vs. complexity (handles different data types)
- Failure signatures: Poor synthetic data performance with high multicollinearity/noise, failure to identify true root causes in real applications, long running times for large-scale problems
- First 3 experiments: 1) Evaluate on synthetic data with varying multicollinearity, noise, and sparsity, 2) Compare with state-of-the-art RCA methods on real-world applications, 3) Analyze impact of hyperparameters on performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does BALANCE handle different temporal granularities between KPIs and candidate causes?
- Basis in paper: [explicit] Paper mentions bad SQL localization uses fixed-interval tenant KPIs vs. batch-sampled SQL metrics with uneven gaps
- Why unresolved: Only heuristic alignment approach mentioned without rigorous methodology or alternative evaluation
- What evidence would resolve it: Systematic evaluation comparing temporal alignment strategies and their impact on RCA accuracy

### Open Question 2
- Question: What's the theoretical relationship between multicollinearity handling in BMFS and variational inference convergence?
- Basis in paper: [explicit] Correlated horse-shoe prior combines horse-shoe and g-prior, but theoretical properties unexplored
- Why unresolved: Empirical effectiveness shown without theoretical analysis of posterior landscape or convergence properties
- What evidence would resolve it: Theoretical analysis of how correlated horse-shoe prior affects posterior concentration and natural gradient convergence

### Open Question 3
- Question: How does BALANCE perform when linear model assumption is violated?
- Basis in paper: [inferred] Assumes linear relationships, but this may not hold in complex distributed systems
- Why unresolved: Only evaluated on cases where linear models work well, not tested on non-linear relationships
- What evidence would resolve it: Empirical study comparing BALANCE with non-linear RCA methods on datasets with known non-linear relationships

## Limitations
- Model assumptions may not hold in complex systems with nonlinear interactions
- Scalability constraints with extremely high dimensionality or exponential growth in candidate causes
- Attribution interpretation conflates correlation with causation in systems with feedback loops

## Confidence
- **High Confidence**: Bayesian framework's multicollinearity and sparsity handling through correlated horse-shoe prior
- **Medium Confidence**: Attribution analysis provides interpretable results but requires real-world causal validation
- **Low Confidence**: Claims about superiority in all three real-world applications need independent verification
