# Sharper Model-free Reinforcement Learning for Average-reward Markov Decision Processes

## Quick Facts
- arXiv ID: 2306.16394
- Source URL: https://arxiv.org/abs/2306.16394
- Reference count: 40
- Key result: Achieves $\tilde{O}(S^5 A^2 \mathrm{sp}(h^*)\sqrt{T})$ regret for online setting and $\tilde{O}(SA\mathrm{sp}^2(h^*)/\epsilon^2 + S^2A\mathrm{sp}(h^*)/\epsilon)$ sample complexity for simulator setting

## Executive Summary
This paper develops model-free reinforcement learning algorithms for infinite-horizon average-reward Markov Decision Processes (MDPs). The key innovation is approximating the average-reward problem using a discounted MDP framework combined with variance reduction through reference-advantage decomposition. The authors propose two main techniques: improved discounted approximation via value-difference estimation and efficient construction of confidence regions for the optimal bias function with space complexity $O(SA)$. The algorithms achieve optimal regret bounds for the online setting and near-optimal sample complexity for the simulator setting.

## Method Summary
The paper presents model-free reinforcement learning algorithms that transform the average-reward MDP problem into a discounted MDP approximation. The approach uses a reference-advantage decomposition to reduce variance during policy evaluation. The algorithm maintains estimates of the optimal bias function and constructs confidence regions efficiently using $O(SA)$ space. For the online setting, it employs a regret minimization framework, while for the simulator setting, it uses a PAC-learning approach to find $\epsilon$-optimal policies. The key technical contributions are the improved approximation of the average-reward value function using value-difference estimation and an efficient method for constructing confidence regions that scales linearly with the state-action space.

## Key Results
- Achieves $\tilde{O}(S^5 A^2 \mathrm{sp}(h^*)\sqrt{T})$ regret bound for online average-reward RL
- Achieves $\tilde{O}(SA\mathrm{sp}^2(h^*)/\epsilon^2 + S^2A\mathrm{sp}(h^*)/\epsilon)$ sample complexity for finding $\epsilon$-optimal policies in simulator setting
- Introduces two new techniques: better discounted approximation via value-difference estimation and efficient confidence region construction with $O(SA)$ space complexity

## Why This Works (Mechanism)
The mechanism works by transforming the average-reward MDP problem into a sequence of discounted MDP subproblems, where the discount factor is carefully chosen to balance approximation error and variance. The reference-advantage decomposition reduces variance in policy evaluation by comparing against a reference policy. The value-difference estimation technique provides a more accurate approximation of the average-reward value function from the discounted MDP solution. The efficient confidence region construction maintains statistical guarantees while using only $O(SA)$ space, making it practical for tabular MDPs.

## Foundational Learning

**Average-reward MDPs**: The framework for sequential decision making where the goal is to maximize the long-term average reward per step. Needed because standard discounted MDPs don't capture the true objective in many real-world applications where the process continues indefinitely. Quick check: Verify that the Bellman equation for average-reward MDPs involves relative values rather than absolute values.

**Reference-advantage decomposition**: A variance reduction technique that decomposes the value function into a reference value plus an advantage term. Needed to reduce the variance in policy evaluation, which is crucial for stable learning in average-reward settings. Quick check: Confirm that the reference policy is chosen to minimize the variance of the advantage term.

**Bias function and its span**: The bias function represents the difference between the total expected reward and the average reward over time. Its span (maximum minus minimum value) appears in the theoretical bounds and affects algorithm performance. Needed because the span determines the approximation error when converting average-reward problems to discounted MDPs. Quick check: Verify that the span of the optimal bias function is finite and bounded by the maximum reward range.

## Architecture Onboarding

**Component map**: Observation -> State-action value estimation -> Policy update -> Confidence region construction -> Next action selection

**Critical path**: The algorithm maintains estimates of state-action values, updates the policy based on these estimates, constructs confidence regions around the optimal bias function, and uses these regions to guide exploration and exploitation decisions.

**Design tradeoffs**: The $O(SA)$ space complexity for confidence region construction is a significant improvement over naive approaches, but the algorithm still requires maintaining full state-action value estimates. The dependence on $\mathrm{sp}(h^*)$ in the bounds is unavoidable but limits practical interpretability.

**Failure signatures**: Poor performance when the span of the optimal bias function is large relative to the reward scale, computational infeasibility for very large state-action spaces despite the $O(SA)$ space requirement, and sensitivity to estimation errors in the bias function span.

**First experiments**: 1) Test on a simple grid world MDP with known optimal policy to verify regret bounds, 2) Evaluate sample complexity on a random MDP with varying $\epsilon$ values, 3) Compare performance against standard Q-learning variants on benchmark MDPs.

## Limitations
- Theoretical bounds depend on $\mathrm{sp}(h^*)$, which is typically unknown in practice
- Results are presented for tabular MDPs without addressing function approximation
- No empirical validation provided to demonstrate practical significance
- Space complexity of $O(SA)$ may still be prohibitive for very large problems

## Confidence

High confidence: The theoretical framework and algorithm design are sound and follow established reinforcement learning methodology. The regret bounds for the online setting and sample complexity bounds for the simulator setting are well-defined and follow standard analysis techniques.

Medium confidence: The novelty of the two proposed techniques (better discounted approximation via value-difference estimation and efficient confidence region construction) appears significant, though the practical impact relative to existing variance reduction methods requires empirical validation.

Low confidence: The practical utility of the proposed algorithms in real-world scenarios, given the dependence on unknown quantities like $\mathrm{sp}(h^*)$ and the computational demands of maintaining $O(SA)$ space complexity for large problems.
