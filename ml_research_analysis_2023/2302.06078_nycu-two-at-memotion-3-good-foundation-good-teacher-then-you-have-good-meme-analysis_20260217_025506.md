# NYCU-TWO at Memotion 3: Good Foundation, Good Teacher, then you have Good Meme Analysis

## Quick Facts
- arXiv ID: 2302.06078
- Source URL: https://arxiv.org/abs/2302.06078
- Reference count: 27
- Primary result: 2nd place on Task A (sentiment) and Task B (emotion), 4th on Task C (intensity)

## Executive Summary
This paper presents a multi-modal framework for meme sentiment and emotion analysis in the Memotion 3 competition. The system uses CLIP for aligned image-text feature extraction and employs two novel architectures: Cooperative Teaching Model (CTM) for sentiment classification and Cascaded Emotion Classifier (CEC) for emotion and intensity prediction. The approach achieved strong results, placing 2nd on sentiment and emotion tasks while leveraging knowledge distillation and hierarchical classification to improve performance on this challenging Hinglish meme dataset.

## Method Summary
The framework extracts multi-modal features using CLIP's pre-trained image and text encoders, then processes these features through either CTM for sentiment classification or CEC for emotion classification and intensity prediction. CTM uses knowledge distillation between two teacher models (good and bad) to train student models, while CEC cascades intensity predictions from Task C into emotion classification for Task B. The system combines these predictions for final task outputs.

## Key Results
- Achieved 2nd place on Task A (sentiment classification) with F1-score of 0.342
- Achieved 2nd place on Task B (emotion classification) with F1-score of 0.784
- Achieved 4th place on Task C (emotion intensity) with F1-score of 0.535
- Ablation studies confirm effectiveness of proposed CTM and CEC models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Cooperative Teaching Model (CTM) improves Task A performance by exploiting the hierarchical nature of sentiment labels.
- Mechanism: CTM treats neutral sentiment as an implicit mixture of positive and negative sentiment, using knowledge distillation from a "good teacher" (positive-focused) and a "bad teacher" (negative-focused) to train student models. Students learn by approximating teacher outputs with added Gaussian noise to simulate uncertainty.
- Core assumption: Neutral sentiment contains implicit positive or negative components, and students can learn better sentiment classification by observing teacher outputs on this composite signal.
- Evidence anchors:
  - [abstract] "CTM is based on the idea of knowledge distillation, and can better predict the sentiment of a given meme in Task A"
  - [section 4.2] "we introduce the concept of knowledge distillation to design the framework that has two teacher models to teach their student models how to classify sentiment respectively"
- Break condition: If neutral sentiment does not contain implicit positive/negative sentiment, or if teacher models fail to capture the hierarchical structure, CTM performance will degrade.

### Mechanism 2
- Claim: Cascaded Emotion Classifier (CEC) improves Task B performance by leveraging Task C's intensity predictions.
- Mechanism: CEC first predicts emotion intensity (Task C), then concatenates these predictions with multi-modal embeddings to inform Task B emotion classification. This creates a hierarchical prediction cascade where intensity information guides the emotion type classification.
- Core assumption: Emotion intensity and emotion type are hierarchically related, and using intensity predictions as input features for emotion classification will improve accuracy.
- Evidence anchors:
  - [abstract] "CEC can leverage the emotion intensity suggestion from the prediction of Task C to classify the emotion more precisely in Task B"
  - [section 4.3] "we propose a framework combining the two classification tasks by leveraging the prediction of Task C as a suggestion for Task B"
- Break condition: If emotion intensity and emotion type are not hierarchically related, or if intensity predictions are unreliable, CEC performance will not improve.

### Mechanism 3
- Claim: CLIP-based multi-modal feature extraction improves meme sentiment analysis by aligning image and text embeddings in a shared semantic space.
- Mechanism: CLIP pre-trains image and text encoders using contrastive loss to pull together aligned image-text pairs in embedding space. This alignment allows downstream models to extract rich, semantically coherent multi-modal features for meme analysis.
- Core assumption: Meme images and captions contain aligned semantic information that can be captured by contrastive learning, and this alignment will benefit downstream sentiment and emotion classification.
- Evidence anchors:
  - [abstract] "we use CLIP[1] to extract aligned image-text features"
  - [section 4.1] "CLIP is composed of an image encoder and a text encoder, both jointly pre-trained to project the image and the caption onto the same embedding space in a contrastive manner"
- Break condition: If meme captions are not semantically aligned with images (e.g., captions contain ironic or implicit meanings), or if pre-training data does not match the target domain, CLIP features may not improve performance.

## Foundational Learning

- Concept: Knowledge Distillation
  - Why needed here: CTM uses knowledge distillation to transfer hierarchical sentiment understanding from teacher models to student models, improving Task A performance.
  - Quick check question: In CTM, what is the role of the "good teacher" and "bad teacher" models, and how do they differ from the student models?

- Concept: Multi-modal Feature Alignment
  - Why needed here: CLIP's contrastive pre-training aligns image and text features in a shared embedding space, enabling downstream models to extract semantically coherent multi-modal representations for meme analysis.
  - Quick check question: How does CLIP's contrastive loss encourage alignment between image and text embeddings, and why is this important for meme sentiment analysis?

- Concept: Hierarchical Classification
  - Why needed here: CEC exploits the hierarchical relationship between emotion intensity (Task C) and emotion type (Task B), using intensity predictions as input features for emotion classification to improve accuracy.
  - Quick check question: In CEC, how are emotion intensity predictions from Task C used to inform emotion type classification in Task B, and why is this approach expected to improve performance?

## Architecture Onboarding

- Component map: Meme Encoder (CLIP + Swin Transformer) -> CTM/CEC -> Task-specific output
- Critical path: Meme Encoder extracts features, which are then processed by either CTM (Task A) or CEC (Tasks B&C) to generate predictions
- Design tradeoffs:
  - Using both CLIP and Swin Transformer for feature extraction provides complementary perspectives but increases computational cost
  - CTM's hierarchical sentiment modeling (neutral as implicit positive/negative) improves Task A performance but requires careful teacher-student coordination
  - CEC's cascaded architecture leverages Task C predictions for Task B but may propagate errors from Task C to Task B
- Failure signatures:
  - Poor Task A performance: Check if teacher-student coordination in CTM is working, or if neutral sentiment is not well-modeled as implicit positive/negative
  - Poor Tasks B&C performance: Check if emotion intensity predictions in Task C are reliable, or if the cascaded architecture is not capturing the hierarchical relationship
  - Overall poor performance: Check if CLIP features are well-aligned with meme semantics, or if pre-training data matches the target domain
- First 3 experiments:
  1. Train CTM with only the student model (no teacher) to verify the importance of knowledge distillation for Task A
  2. Train CEC without the cascaded architecture (separate models for Tasks B and C) to verify the benefit of leveraging Task C predictions for Task B
  3. Train models using only Swin Transformer features (no CLIP) to verify the importance of CLIP's aligned multi-modal features for meme analysis

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of the Meme Encoder pipeline change when incorporating Swin Transformer features in a multi-task learning setup?
- Basis in paper: [inferred] The paper mentions using both Swin Transformer and CLIP models but only conducts ablation studies on CTM and CEC, not the Meme Encoder.
- Why unresolved: The paper only uses Swin Transformer as a feature extractor and fine-tunes it on the Memotion task dataset, but does not explore its effectiveness in a multi-task learning setup.
- What evidence would resolve it: Conducting ablation studies on the Meme Encoder pipeline with Swin Transformer features in a multi-task learning setup.

### Open Question 2
- Question: How does the performance of the CTM model change when using a different pre-training dataset for the CLIP model?
- Basis in paper: [explicit] The paper mentions that the text in the Memotion 3.0 dataset is in Hinglish, which affected the performance of the foundation model pre-trained on English data.
- Why unresolved: The paper only uses the Memotion 1.0 dataset for verification, but does not explore the use of other Hinglish meme datasets for pre-training.
- What evidence would resolve it: Conducting experiments with different pre-training datasets for the CLIP model and comparing the performance of the CTM model.

### Open Question 3
- Question: How does the performance of the CEC model change when using a different emotion classification architecture?
- Basis in paper: [inferred] The paper proposes the CEC model, which leverages the emotion intensity prediction from Task C to improve the emotion classification in Task B, but does not explore the use of other emotion classification architectures.
- Why unresolved: The paper only uses the CEC model and does not compare it with other emotion classification architectures.
- What evidence would resolve it: Conducting experiments with different emotion classification architectures and comparing the performance of the CEC model.

## Limitations

- Dataset domain mismatch: CLIP pre-trained on web data may not capture meme-specific semantics or code-mixed Hinglish language
- Knowledge distillation assumptions: Hierarchical sentiment structure may not generalize across different meme datasets or languages
- Cascaded architecture dependencies: Task C prediction errors could propagate to Task B through the CEC architecture

## Confidence

- High Confidence: CLIP feature extraction methodology, basic CTM and CEC architectures, overall 2nd/4th place competition results
- Medium Confidence: The effectiveness of knowledge distillation in CTM, the hierarchical sentiment assumption, the impact of domain mismatch
- Low Confidence: The robustness of CEC across different dataset distributions, the generalizability of CTM to non-Hinglish memes

## Next Checks

1. Cross-Domain Validation: Evaluate CTM and CEC performance on English-only meme datasets to quantify the impact of Hinglish code-mixing on model performance. This would test whether the hierarchical sentiment assumption and cascaded architecture generalize beyond the current dataset.

2. Teacher Model Ablation: Systematically compare CTM performance with different teacher configurations: (a) both teachers present, (b) only good teacher, (c) only bad teacher, (d) no teachers (direct student training). This would isolate the contribution of knowledge distillation versus hierarchical sentiment modeling.

3. Feature Alignment Analysis: Conduct controlled experiments measuring CLIP embedding similarity between meme images and captions versus generic image-text pairs. This would quantify how well CLIP's pre-training aligns with the specific characteristics of meme data, validating or challenging the paper's assumption about feature quality.
