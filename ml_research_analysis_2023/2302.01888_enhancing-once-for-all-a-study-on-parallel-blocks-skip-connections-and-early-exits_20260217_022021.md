# Enhancing Once-For-All: A Study on Parallel Blocks, Skip Connections and Early Exits

## Quick Facts
- arXiv ID: 2302.01888
- Source URL: https://arxiv.org/abs/2302.01888
- Reference count: 20
- Primary result: OFAv2 achieves up to 12.07% higher accuracy than OFA on Tiny ImageNet while maintaining eco-friendly benefits

## Executive Summary
This paper presents OFAv2, an enhanced version of the Once-For-All algorithm for neural architecture search. The authors introduce three architectural improvements to the OFAMobileNetV3 backbone: early exits, dense skip connections, and parallel blocks. To support these changes, they extend the Progressive Shrinking training algorithm with two new elastic steps and propose an Ensembled Knowledge Distillation technique for training multi-output networks. Experiments on Tiny ImageNet demonstrate significant accuracy improvements while maintaining the algorithm's flexibility and environmental advantages.

## Method Summary
The authors enhance OFAMobileNetV3 with three key architectural modifications: early exits to enable early predictions for smaller images, dense skip connections to improve gradient flow, and parallel blocks that execute additional convolutional paths alongside standard blocks. They extend the Progressive Shrinking training algorithm with Elastic Level and Elastic Height steps to accommodate these changes. The training employs Ensembled Knowledge Distillation using multiple teacher exits, with a dynamic teacher selection strategy based on predicted accuracy. The approach is evaluated on Tiny ImageNet using SGD with momentum 0.9, weight decay 3e-5, and cosine annealing learning rate schedule.

## Key Results
- OFAv2 achieves up to 12.07% higher accuracy compared to original OFA on Tiny ImageNet
- The enhanced architecture maintains flexibility for various subnet configurations
- Early exits and parallel blocks contribute significantly to performance gains
- Dense skip connections improve gradient flow during training

## Why This Works (Mechanism)
The architectural modifications address fundamental limitations in the original OFA design. Early exits enable efficient inference for smaller input sizes by providing intermediate predictions. Dense skip connections mitigate vanishing gradient problems in deep networks, allowing better feature propagation. Parallel blocks increase representational capacity without significantly increasing latency. The Extended Progressive Shrinking algorithm accommodates these changes through elastic training steps that handle the increased architectural complexity.

## Architecture Onboarding

**Component Map:** Input -> Early Exits -> Main Backbone (Parallel Blocks + Dense Skip Connections) -> Output

**Critical Path:** Input images flow through early exits for small sizes, then through parallel blocks with dense skip connections, and finally to the output layer.

**Design Tradeoffs:** Early exits improve efficiency for small inputs but may hurt large input performance. Parallel blocks increase capacity but add computational overhead. Dense skip connections improve gradient flow but may increase memory usage.

**Failure Signatures:** Poor early exit performance indicates optimization difficulties with multi-output training. Parallel block failures suggest suboptimal block design or insufficient training.
