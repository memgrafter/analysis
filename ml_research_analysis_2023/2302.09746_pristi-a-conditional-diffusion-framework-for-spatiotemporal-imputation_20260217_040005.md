# PriSTI: A Conditional Diffusion Framework for Spatiotemporal Imputation

## Quick Facts
- arXiv ID: 2302.09746
- Source URL: https://arxiv.org/abs/2302.09746
- Reference count: 40
- Primary result: PriSTI outperforms existing imputation methods on AQI-36, METR-LA, and PEMS-BAY datasets with lower MAE, MSE, and CRPS across various missing patterns

## Executive Summary
PriSTI addresses the critical challenge of spatiotemporal data imputation where sensor failures or transmission losses create incomplete datasets. The framework leverages conditional diffusion models to impute missing values while avoiding the error accumulation typical of autoregressive methods. By constructing conditional information that captures both spatiotemporal dependencies and geographic relationships, PriSTI demonstrates superior performance across real-world air quality, traffic, and mobility datasets with various missing patterns and rates.

## Method Summary
PriSTI employs a conditional diffusion framework that iteratively denoises corrupted spatiotemporal data by conditioning on available observations and spatial relationships. The method constructs spatiotemporal attention mechanisms that incorporate geographic proximity alongside temporal dependencies, allowing the model to leverage the inherent structure of sensor networks. During training, the model learns to reverse a gradual noising process, enabling it to reconstruct missing values from partially observed spatiotemporal sequences without the error propagation issues common in autoregressive approaches.

## Key Results
- Achieves lowest MAE, MSE, and CRPS across three real-world datasets (AQI-36, METR-LA, PEMS-BAY)
- Outperforms existing imputation methods across various missing patterns including sensor failures and high missing rates
- Maintains effectiveness with missing rates up to 60% while preserving spatiotemporal coherence

## Why This Works (Mechanism)
The conditional diffusion framework succeeds because it operates in a non-autoregressive manner, generating complete spatiotemporal sequences in parallel rather than sequentially. This eliminates the cascading error problem where mistakes in early predictions compound through subsequent steps. The spatiotemporal attention mechanism explicitly models both temporal dynamics and geographic relationships between sensors, capturing the physical constraints that govern real-world phenomena. By learning to reverse a gradual noising process, the model develops robust representations of the underlying data distribution that generalize well to unseen missing patterns.

## Architecture Onboarding

Component Map: Sensor Data -> Spatiotemporal Attention -> Conditional Diffusion Denoiser -> Imputed Values

Critical Path: The denoiser network processes the noised input conditioned on observed values and spatial relationships through multiple diffusion timesteps, with spatiotemporal attention providing contextual information at each step.

Design Tradeoffs: Non-autoregressive imputation provides parallelization and avoids error accumulation but requires more complex modeling of global dependencies compared to sequential approaches.

Failure Signatures: Poor performance on extreme missing rates (>80%) or when sensor failures create disconnected spatial regions with no available neighbors.
