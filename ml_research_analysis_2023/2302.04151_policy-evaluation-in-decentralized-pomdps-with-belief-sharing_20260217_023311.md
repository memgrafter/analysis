# Policy Evaluation in Decentralized POMDPs with Belief Sharing

## Quick Facts
- arXiv ID: 2302.04151
- Source URL: https://arxiv.org/abs/2302.04151
- Reference count: 40
- Primary result: Decentralized belief sharing achieves bounded disagreement with global posterior in multi-agent POMDPs

## Executive Summary
This paper addresses the challenge of policy evaluation in multi-agent systems with partial observability by proposing a fully decentralized belief sharing strategy. The approach enables agents to approximate global belief states through localized interactions and belief exchanges over communication networks. By combining diffusion strategies with temporal-difference learning and function approximation, the method maintains bounded disagreement between local and global belief distributions while allowing agents to cluster around network centroids.

## Method Summary
The proposed method extends diffusion HMM strategies to POMDP settings through a decentralized belief forming mechanism. Agents maintain local belief states and value function parameter estimates, which are updated through individual observations and localized interactions with neighboring agents. The temporal-difference learning component enables function approximation for value estimation, while the diffusion strategy ensures information propagation across the network. Agents exchange both beliefs and value function parameters, allowing for collaborative policy evaluation without centralized coordination.

## Key Results
- Agents maintain bounded disagreement with the global posterior distribution under the proposed belief sharing strategy
- Decentralized approach achieves squared Bellman error comparable to centralized methods in multi-sensor target tracking simulations
- Agents successfully cluster around the network centroid, demonstrating effective information aggregation

## Why This Works (Mechanism)
The method works by creating a distributed belief formation system where local updates are continuously refined through neighbor interactions. The bounded disagreement property emerges from the combination of individual belief updates based on local observations and the averaging effects of the diffusion strategy. Temporal-difference learning provides the function approximation framework that enables scalable value estimation, while the belief sharing mechanism ensures that local information propagates effectively across the network topology.

## Foundational Learning
- **Diffusion strategies**: Distributed optimization methods that enable agents to aggregate information through local averaging; needed for scalable belief propagation across networks
- **Temporal-difference learning**: Model-free reinforcement learning method that updates value estimates based on temporal differences; required for function approximation in policy evaluation
- **Hidden Markov Models (HMMs)**: Probabilistic models for sequential data with hidden states; foundational for extending belief propagation to POMDP settings
- **POMDP belief states**: Probability distributions over environment states given observations; essential for representing partial observability in multi-agent systems
- **Network consensus**: Convergence of distributed agents to common values; critical for ensuring agreement among local beliefs

## Architecture Onboarding

### Component Map
Sensors/Agents -> Local Belief Update -> Diffusion Averaging -> Value Function Update -> Policy Evaluation

### Critical Path
Observation collection → Belief update → Neighborhood exchange → Belief averaging → Value estimation → Policy evaluation

### Design Tradeoffs
- Decentralization vs. computational overhead from belief exchanges
- Communication frequency vs. belief accuracy and convergence speed
- Function approximation complexity vs. value estimation precision
- Network topology constraints vs. information propagation efficiency

### Failure Signatures
- Divergence of local beliefs from global posterior
- Oscillations in belief estimates due to communication delays
- Slow convergence in sparse network topologies
- Overestimation errors in value function approximation

### First 3 Experiments
1. Single-agent belief update with known observation model to verify basic belief propagation
2. Two-agent network with synthetic observations to test belief exchange mechanism
3. Small-scale multi-agent system with ground truth to validate bounded disagreement property
