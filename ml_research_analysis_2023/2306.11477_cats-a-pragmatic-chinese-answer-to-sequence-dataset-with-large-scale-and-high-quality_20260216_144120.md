# CATS: A Pragmatic Chinese Answer-to-Sequence Dataset with Large Scale and High Quality

## Quick Facts
- arXiv ID: 2306.11477
- Source URL: https://arxiv.org/abs/2306.11477

## Executive Summary
This paper introduces CATS, a large-scale Chinese dataset for answer-to-sequence generation in practical TableQA systems. The dataset addresses the limitations of existing small-scale and English-biased datasets by providing 43,369 SQL-table pairs with high-quality annotations. To better model the heterogeneous input data, the authors propose a Unified Graph Transformation approach that converts SQL and table inputs into a joint graph structure, along with a Node Segment Embedding to preserve structural information. Experiments show that their method outperforms baseline models in terms of BLEU, ROUGE-L, and COVERAGE metrics, as well as human evaluation scores for fluency, faithfulness, and coverage.

## Method Summary
The authors propose a Unified Graph Transformation (UGT) approach to address the challenge of answer-to-sequence generation from SQL queries and tables. UGT converts the SQL query and table into a unified graph representation by first transforming them into two undirected graphs (SQL graph and table graph), then connecting nodes that indicate the same column across these graphs and adding self-loop connections. The unified graph is then tokenized and transformed into a token graph, with Node Segment Embedding (NSE) preserving the original graph structure. The model uses a transformer-based architecture with a Graph Attention Network (GAT) layer to model the graph topology and generate natural language descriptions.

## Key Results
- The proposed method achieves BLEU scores of 56.34 and 55.95 on the development and test sets, respectively.
- The model outperforms baseline models in terms of ROUGE-L and COVERAGE metrics.
- Human evaluation shows higher scores for fluency, faithfulness, and coverage compared to baseline models.

## Architecture Onboarding

- Component map: Input Layer (SQL query and execution result) -> Unified Graph Transformation (UGT) -> Token Graph Transformation -> Node Segment Embedding (NSE) -> Local Node Encoder (L-NE) -> Global Node Encoder -> Transformer Decoder -> Output Layer (Generated text)

- Critical path: 1. Input SQL and table, 2. UGT converts inputs into unified graph, 3. Token graph transformation and NSE, 4. L-NE and Global Node Encoder process the graph, 5. Transformer Decoder generates output text

- Design tradeoffs:
  - Using a unified graph representation vs. separate encodings for SQL and table: The unified graph allows for better semantic alignment but may introduce complexity in modeling.
  - Preserving graph structure with NSE vs. simpler token graph transformation: NSE maintains structural information but adds complexity to the model.

- Failure signatures:
  - Poor BLEU and ROUGE-L scores: Indicates issues with fluency or relevance of generated text
  - Low COVERAGE scores: Suggests the model is not capturing all information from the input table
  - High repetition in generated text: May indicate overfitting or issues with the decoding process

- First 3 experiments:
  1. Compare the performance of the full model with and without NSE to assess its impact on preserving graph structure.
  2. Evaluate the model's performance on tables of varying sizes and complexities to understand its scalability.
  3. Analyze the generated text for faithfulness and fluency to identify potential areas for improvement in the decoding process.

## Limitations

- Dataset Generalization: The CATS dataset, while large and high-quality, is specific to Chinese language and may not generalize well to other languages or domains.
- Graph Representation Limitations: The Unified Graph Transformation (UGT) approach relies on effectively capturing and aligning the structural relationships in SQL and tables, which may be challenging for complex or heterogeneous data.
- Evaluation Metrics: While the paper uses BLEU, ROUGE-L, and COVERAGE for automatic evaluation, these metrics may not fully capture the nuances of answer-to-sequence generation.

- Low Confidence: The generalizability of the model to other languages or domains beyond Chinese is uncertain, as the CATS dataset is specific to the Chinese language.
