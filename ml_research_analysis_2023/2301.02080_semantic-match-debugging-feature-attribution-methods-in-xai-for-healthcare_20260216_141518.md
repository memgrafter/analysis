# Semantic match: Debugging feature attribution methods in XAI for healthcare

## Quick Facts
- arXiv ID: 2301.02080
- Source URL: https://arxiv.org/abs/2301.02080
- Reference count: 6
- Key outcome: Feature attribution methods can be unreliable for unstructured data due to lack of semantic match between explanations and human understanding.

## Executive Summary
This paper critiques the use of feature attribution methods for post-hoc local explainability in healthcare AI, arguing that such methods can be unreliable due to a lack of semantic match between the explanations and human understanding. The authors propose distinguishing between low-level features with clear semantics (like lab values in EHRs) and high-level features lacking intrinsic meaning (like pixels in images). For low-level features with predefined semantics, feature attribution can still be meaningful and useful, enabling clinicians to assess model outputs. The paper provides a procedure to test for semantic match and highlights the need for explanations that align with human categories and reasoning.

## Method Summary
The authors propose a framework to evaluate whether feature attribution methods in XAI for healthcare provide reliable explanations by testing for semantic match between explanations and human understanding. The method involves implementing feature attribution on structured medical data with clearly defined feature semantics, generating explanations, and evaluating whether the attributions correspond to human-understandable concepts. This is compared against explanations from unstructured image data where feature semantics are ambiguous. The approach focuses on distinguishing between low-level features with predefined semantics and high-level features lacking intrinsic meaning.

## Key Results
- Feature attribution methods can be meaningful for low-level features when those features have predefined semantics
- High-level features in unstructured data lack reliable semantic match, making feature attribution potentially misleading
- The semantic match diagram provides a framework to test whether explanations are reliable

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Feature attribution methods can be meaningful for low-level features when those features have predefined semantics.
- Mechanism: The semantic match between feature attributions and human-understandable concepts enables clinicians to assess whether model outputs align with domain knowledge.
- Core assumption: Low-level features in structured data (like EHRs) have intrinsic meaning independent of other features.
- Evidence anchors:
  - [abstract] "For low-level features with predefined semantics, feature attribution can still be meaningful and useful, enabling clinicians to assess model outputs."
  - [section] "The distinction between low-and high-level features helps untangle the cases in which semantic match works out-of-the-box from those in which it fails."
  - [corpus] Weak evidence - related papers focus on feature attribution methods generally but do not specifically address the semantic match concept for low-level features.
- Break condition: If the structured data features lose their predefined semantics or become context-dependent.

### Mechanism 2
- Claim: High-level features in unstructured data lack reliable semantic match, making feature attribution potentially misleading.
- Mechanism: Pixels or other raw data elements don't have intrinsic meaning; only patterns of these elements can be interpreted, and these patterns may not align with human concepts.
- Core assumption: Humans cannot reliably interpret sub-symbolic representations without a clear translation mechanism.
- Evidence anchors:
  - [section] "Images are a prime example of what is sometimes called 'unstructured data', namely data that does not come equipped with additional structure and is akin to raw sensory data."
  - [section] "A single feature has no intrinsic meaning: a certain color value of a pixel means nothing by itself."
  - [corpus] No direct evidence in corpus - papers discuss feature attribution but not specifically the semantic mismatch issue for high-level features.
- Break condition: If the model's internal representation somehow aligns with human visual intuition by chance.

### Mechanism 3
- Claim: The semantic match diagram provides a framework to test whether explanations are reliable.
- Mechanism: By formalizing the relationship between machine representations, explanations, and human concepts, we can systematically identify when explanations fail.
- Core assumption: Explanations can be evaluated through their ability to commute between sub-symbolic representations and human-understandable concepts.
- Evidence anchors:
  - [abstract] "They propose distinguishing between low-level features, which have clear semantics... and high-level features, which lack intrinsic meaning."
  - [section] "We call such a commuting diagram a semantic match."
  - [corpus] Weak evidence - corpus papers discuss feature attribution methods but don't mention the semantic match diagram specifically.
- Break condition: If the semantic match diagram itself becomes too complex or doesn't capture the nuances of human concept formation.

  2. Train predictive model on EHR data
  3. Apply feature attribution method
  4. Test for semantic match with domain experts

  - Structured data requires careful feature engineering to ensure semantic clarity
  - Feature attribution methods may be computationally expensive

  - Clinicians unable to explain why certain features are important
  - Performance metrics good but user trust low

## Limitations
- The paper's core argument relies heavily on the theoretical distinction between low-level and high-level features without providing extensive empirical validation
- The distinction between structured and unstructured data is presented as clear-cut, but real-world medical data often contains mixed structures that blur this boundary
- The assertion that feature attribution is universally reliable for structured data with predefined semantics requires more empirical validation across diverse medical domains

## Confidence
- High confidence: The observation that pixel-level explanations in images may not align with human concepts is well-supported by the nature of sub-symbolic representations
- Medium confidence: The framework for testing semantic match is conceptually sound but lacks detailed implementation guidelines
- Low confidence: The assertion that feature attribution is universally reliable for structured data with predefined semantics requires more empirical validation across diverse medical domains
