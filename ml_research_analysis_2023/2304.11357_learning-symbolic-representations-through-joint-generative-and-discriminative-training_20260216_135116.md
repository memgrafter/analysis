## Executive Summary
This paper introduces GEDI, a Bayesian framework that integrates self-supervised learning objectives with generative models to improve symbolic representation learning. GEDI unifies generative and discriminative approaches through a shared architecture and joint training, enabling better clustering performance and leveraging logical constraints for small data regimes. The key innovation is a novel data augmentation strategy (DAM) that exploits learned data manifold structure, improving both generative and discriminative learning. Experiments on SVHN, CIFAR-10, and CIFAR-100 show GEDI significantly outperforms baselines in clustering tasks, while a neural-symbolic MNIST addition task demonstrates successful learning of symbolic representations with weak supervision.

## Method Summary
GEDI is a Bayesian framework that combines an energy-based generative model with a discriminative clustering objective through joint training. The model uses a shared encoder architecture where the same network maps inputs to both generative and discriminative latent spaces. A novel Data Augmentation based on Manifold structure (DAM) strategy generates augmentations by sampling from the learned data manifold using the pre-trained energy-based model. The framework incorporates logical constraints as an additional loss term, enabling neuro-symbolic reasoning in small data regimes. Training proceeds in two stages: first pre-training the energy-based model using Stochastic Gradient Langevin Dynamics, then jointly training all components with combined loss functions.

## Key Results
- GEDI achieves +15 NMI improvement on SVHN clustering compared to baselines like JEM, Barlow Twins, and SwAV
- Successfully learns symbolic representations in neural-symbolic MNIST addition task with weak supervision
- Prevents representational collapse observed in other neuro-symbolic methods through discriminative component
- Demonstrates effectiveness of DAM strategy in exploiting learned data manifold structure

## Architecture Onboarding

- Component map: Input -> Encoder -> Projection Head -> Output Layer -> Cluster Assignments; Energy-based Model provides generative likelihood and DAM augmentations

- Critical path:
  1. Forward pass through encoder and projection head
  2. Compute discriminative loss using cluster assignments
  3. Compute generative loss using EBM
  4. Compute DAM augmentations and update losses
  5. Backward pass and parameter update

- Design tradeoffs:
  - Single vs. separate encoders for generative and discriminative components
  - Number of DAM steps (T) vs. computational cost
  - Strength of logical constraint loss vs. risk of conflicting with data-driven learning

- Failure signatures:
  - Poor clustering performance despite high generative likelihood (indicates misalignment between generative and discriminative objectives)
  - Representational collapse in neuro-symbolic task (indicates weak discriminative signal)
  - Slow or unstable training (indicates poor EBM approximation of data density)

## Limitations

- DAM mechanism's effectiveness heavily depends on the quality of the pre-trained energy-based model, but limited empirical evidence shows the EBM accurately captures data manifold structure
- The paper demonstrates success in preventing representational collapse but lacks systematic ablation studies showing exactly how much each component contributes to this effect
- Claims about leveraging logical constraints for small data regimes are demonstrated on MNIST addition task but lack extensive validation across different constraint types and data scarcity levels

## Confidence

- High Confidence: The clustering performance improvements on SVHN (+15 NMI) are well-supported by experimental results and comparisons with strong baselines
- Medium Confidence: The claim about leveraging logical constraints for small data regimes, while demonstrated on the MNIST addition task, lacks extensive validation across different constraint types and data scarcity levels
- Medium Confidence: The mechanism preventing representational collapse is supported by results but could benefit from more detailed analysis of the loss landscape and gradient flows

## Next Checks

1. Conduct ablation studies varying the strength of the discriminative component to quantify its contribution to preventing representational collapse versus the logical constraint loss

2. Test DAM's effectiveness when the pre-trained EBM is intentionally perturbed or trained with reduced capacity to assess sensitivity to EBM quality

3. Evaluate GEDI on additional small data regime tasks beyond MNIST addition, particularly with more complex logical constraints, to verify the generalizability of the logical constraint mechanism
