# EEL: Efficiently Encoding Lattices for Reranking

## Quick Facts
- arXiv ID: 2306.00947
- Source URL: https://arxiv.org/abs/2306.00947
- Reference count: 20
- One-line primary result: EEL encodes lattices in a single Transformer pass, enabling fast reranking with minimal degradation compared to exhaustive search

## Executive Summary
EEL (Efficient Encoding of Lattices) addresses the computational inefficiency of reranking large candidate sets in conditional text generation. The method encodes lattices of generation outputs in a single Transformer pass, enabling fast reranking with token-factored rerankers (TFRs). EEL achieves near-optimal performance compared to exhaustive search while providing substantial speedups across three generation tasks: machine translation, summarization, and table-to-text. The approach combines causal masking, modified positional encodings, and dynamic programming to efficiently extract high-scoring hypotheses from lattices.

## Method Summary
EEL encodes lattices using a single Transformer pass with causal masking to preserve context within each hypothesis path. The method uses modified positional encodings to maintain token positions within their respective hypothesis paths. Token-factored rerankers (TFRs) score tokens independently, allowing dynamic programming to efficiently extract the highest-scoring hypothesis without enumerating all paths. The approach handles lattice recombination through single-context masking, randomly selecting one parent per node to minimize ambiguity while maintaining coverage of high-probability paths.

## Key Results
- EEL achieves minimal degradation compared to exhaustive search while providing 10-100x speedups
- Strong performance on downstream metrics (COMET, PARENT, unique noun count) across three generation tasks
- EEL outperforms naive reranking approaches in both quality and efficiency metrics
- Single-context masking provides the best tradeoff between speed and coverage

## Why This Works (Mechanism)

### Mechanism 1
Causal TFR models with linearized lattice encoding can approximate the same token-level scores as individual hypothesis scoring. The EEL pipeline uses a causal mask and modified positional encodings to ensure each token attends only to its proper context within the lattice, replicating the computation path of scoring a hypothesis in isolation. The core assumption is that token-level scores are additive and can be computed independently if context is preserved. Break condition: If recombination creates ambiguous positional contexts, the approximation degrades.

### Mechanism 2
Dynamic programming over lattice scores efficiently finds the highest-scoring hypothesis without enumerating all paths. Algorithm 1 applies Viterbi-style dynamic programming, extending best paths to each node based on predecessor scores, leveraging the additive structure of TFR scores. The core assumption is that the score decomposition in TFRs allows optimal substructure for dynamic programming. Break condition: If the reranker score is not additive over tokens, the DP extraction fails.

### Mechanism 3
Single-context masking minimizes degradation by reducing ambiguity in token context while maintaining coverage. By randomly selecting one parent per node, the mask creates a subgraph that preserves valid causal chains without conflicting contexts. The core assumption is that random single-context sampling covers most high-probability paths while avoiding context mismatches. Break condition: If important high-scoring paths are consistently missed by random sampling, performance degrades.

## Foundational Learning

- Concept: Causal masking in Transformers
  - Why needed here: Ensures tokens only attend to prior tokens in the same hypothesis path, preserving the autoregressive nature required for TFRs
  - Quick check question: What happens if bidirectional attention is used with a TFR?

- Concept: Dynamic programming for path optimization
  - Why needed here: Enables finding the best-scoring hypothesis in a lattice without enumerating exponentially many paths
  - Quick check question: How does the additive score structure enable DP?

- Concept: Positional encoding in sequence models
  - Why needed here: Ensures tokens have consistent positions within their hypothesis paths for correct attention patterns
  - Quick check question: Why can't we use absolute positions for all lattice nodes?

## Architecture Onboarding

- Component map: Transformer encoder → Causal mask generator → Positional encoder → Dynamic programming extractor
- Critical path: Lattice input → Mask application → Single Transformer pass → DP extraction → Best hypothesis
- Design tradeoffs: Single mask vs. few-mask (speed vs. coverage), canonical vs. alternative positional encodings (consistency vs. flexibility)
- Failure signatures: Degradation in reranker scores, incorrect best hypothesis selection, slow encoding times
- First 3 experiments:
  1. Validate TFR score decomposition on simple beam search lattices
  2. Test causal masking on lattices with no recombination
  3. Compare single vs. full context masking on lattices with recombination

## Open Questions the Paper Calls Out

### Open Question 1
Can the EEL approach be extended to work with non-causal token-factored rerankers? The paper mentions that causal TFRs enable lossless encoding for lattices without reentrancies, but there can be degradation in graphs with reentrancies when using bidirectional TFRs (bTFRs). Experiments comparing EEL with bTFRs on lattices with reentrancies would provide evidence for or against the extension of EEL to work with these models.

### Open Question 2
How does the choice of position id scheme affect the performance of EEL? The paper mentions they use a canonical position id strategy but also mentions alternatives like longest/shortest path or random depth-first traversal. Experiments comparing EEL with different position id schemes on various tasks and lattices would provide evidence for the impact of position id scheme choice.

### Open Question 3
Can EEL be applied to other tasks beyond text generation, such as machine translation or summarization? While the paper demonstrates effectiveness on these tasks, it does not explore potential for other tasks. Experiments applying EEL to question answering, sentiment analysis, or named entity recognition would provide evidence for broader applicability.

## Limitations

- EEL performance on lattice decoding is notably worse than beam search, suggesting limited generalizability across decoding strategies
- Single-context masking introduces approximation errors that could miss important hypotheses in certain lattice structures
- TFR model training procedure is underspecified regarding exact methodology for obtaining labels and training duration
- Evaluation focuses primarily on English-centric tasks with limited validation on truly low-resource or non-English scenarios

## Confidence

**High confidence**: The core mechanism of encoding lattices in a single Transformer pass is well-supported by empirical results. Speed improvements over naive reranking approaches are clearly demonstrated with quantitative metrics.

**Medium confidence**: Effectiveness of token-factored reranking for downstream metric optimization is supported by correlation metrics but relies on TFR training data quality. Approximation claims for single-context masking are plausible given results but lack rigorous theoretical bounds.

**Low confidence**: The claim that EEL "almost matches" exhaustive search performance is based on limited comparisons. The paper does not adequately address how performance scales with increasingly complex lattice structures or how often important hypotheses are missed by single-context approximation.

## Next Checks

1. **Mask coverage analysis**: Implement a mechanism to track which high-scoring hypotheses are missed by single-context masking versus full-context encoding to quantify approximation error.

2. **Cross-decoding validation**: Test EEL on lattice outputs from multiple decoding algorithms (not just beam search) to establish generalizability, including diverse beam search and top-k sampling lattices.

3. **TFR robustness evaluation**: Systematically vary the amount and quality of training data for TFR models to determine minimum requirements for effective reranking, including ablation studies removing various TFR components.
