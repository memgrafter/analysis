# Self-Supervised Learning based Depth Estimation from Monocular Images

## Quick Facts
- arXiv ID: 2304.06966
- Source URL: https://arxiv.org/abs/2304.06966
- Reference count: 0
- The paper extends Monodepth2 with Mask R-CNN refinement, ESPCN upsampling, and learnable camera intrinsics, achieving up to 28.34% RMSE reduction on KITTI.

## Executive Summary
This paper presents improvements to the Monodepth2 self-supervised monocular depth estimation framework. The authors integrate Mask R-CNN for semantic segmentation to refine disparity maps, add a learnable camera intrinsics network to estimate camera parameters during training, and replace bilinear upsampling with ESPCN for better feature propagation. Weather augmentations are also applied to improve generalization. Experiments on the KITTI dataset demonstrate significant improvements in depth estimation accuracy, with the best-performing variant combining all three architectural modifications and achieving improved accuracy while maintaining reasonable training times.

## Method Summary
The method extends Monodepth2 by adding three key architectural changes: (1) Mask R-CNN integration to refine disparity maps using semantic segmentation masks, (2) ESPCN sub-pixel convolution for upsampling instead of bilinear interpolation, and (3) a learnable camera intrinsics network that predicts focal lengths and principal point offsets from encoder features. The model is trained self-supervised using stereo image pairs from the KITTI dataset, with reprojection loss computed after applying the semantic masks to the disparity map. Weather augmentations (RandomSnow, RandomSunflare, RandomFog, RandomRain) are used during training to improve generalization to real-world scenarios.

## Key Results
- The best model combining Mask R-CNN, ESPCN, and learnable camera intrinsics reduces RMSE by 28.34% compared to baseline Monodepth2
- ESPCN upsampling provides sharper depth edges compared to bilinear interpolation
- Learnable camera intrinsics improve pose and depth consistency by adapting to unknown camera parameters
- Weather augmentations help generalize the model to real-world scenarios beyond the KITTI dataset

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Mask R-CNN segmentation masks refine the disparity map by preserving object boundaries and semantic coherence.
- Mechanism: The disparity map from the depth decoder is multiplied element-wise with semantic masks from Mask R-CNN. Objects like vehicles and people are masked out and assigned coherent depth values, reducing depth bleeding across object boundaries.
- Core assumption: Mask R-CNN's instance segmentation is accurate enough that object boundaries in the disparity map can be reliably aligned with them.
- Evidence anchors:
  - [abstract]: "integrate Mask R-CNN for semantic segmentation to refine disparity maps"
  - [section]: "We have chalked out a few architectural changes which might give us further improvement on the current model. To avoid semantic distortions that we see in the current model, we aim to adjust the disparity map using Mask R-CNN segmentation."
  - [corpus]: Weak - No corpus paper directly tests Mask R-CNN for depth map refinement; evidence is only from the source paper.
- Break condition: If Mask R-CNN confidence drops below 0.7 or segmentation masks are misaligned with depth edges, the refinement can introduce artifacts.

### Mechanism 2
- Claim: ESPCN upsampling preserves high-frequency details and reduces interpolation blur compared to bilinear upsampling.
- Mechanism: ESPCN performs sub-pixel convolution that rearranges channel-wise features into spatial resolution, multiplying height and width by r (here 2) while dividing channels by r². This avoids interpolation smoothing.
- Core assumption: The encoder features contain enough high-frequency information that rearranging them into higher resolution yields sharper depth edges.
- Evidence anchors:
  - [abstract]: "replace bilinear upsampling with ESPCN for better feature propagation"
  - [section]: "Lastly, we have replaced the bilinear upsampling with ESPCN to improve the propagation of intuitive features during upsampling."
  - [corpus]: Weak - No corpus paper directly evaluates ESPCN for depth upsampling; evidence is only from the source paper.
- Break condition: If the sub-pixel convolution introduces checkerboard artifacts or if the feature maps are too low-resolution to benefit from ESPCN, performance can degrade.

### Mechanism 3
- Claim: Learnable camera intrinsics allow the model to adapt to unknown or imperfect camera parameters during training, improving pose and depth consistency.
- Mechanism: A small camera network predicts focal lengths (fx, fy) and principal point offsets (cx, cy) from encoder features, forming K matrix. This K is used in pose estimation and reprojection, rather than fixed values.
- Core assumption: The shared encoder features contain enough scene geometry cues to predict reasonable camera parameters that improve reprojection consistency.
- Evidence anchors:
  - [abstract]: "add a learnable camera intrinsics network to estimate camera parameters during training"
  - [section]: "We also have integrated a learnable camera intrinsic network from WildNet... The PoseNet Encoder's feature outputs are delivered to the camera network... The normalized focal lengths fx, fy and main offsets cx, cy... will then be estimated."
  - [corpus]: Weak - No corpus paper directly tests learnable intrinsics in self-supervised depth; evidence is only from the source paper.
- Break condition: If the camera network predicts implausible K values (e.g., extreme focal lengths), reprojection loss can explode and training can diverge.

## Architecture Onboarding

- Component map: Input frames -> Shared ResNet-50 encoder -> Depth decoder (+ESPCN) -> Disparity map -> Mask R-CNN refinement -> Loss computation
- Critical path: Input -> Encoder -> Depth Decoder (+ESPCN) -> Disparity -> Apply Mask -> Loss -> Backprop
- Design tradeoffs:
  - ESPCN vs bilinear: better sharpness but more parameters and potential checkerboard artifacts
  - Learnable K vs fixed: better generalization to unknown cameras but risk of unstable predictions
  - Mask R-CNN integration: improves semantic coherence but adds inference overhead and depends on mask quality
- Failure signatures:
  - Sharp checkerboard patterns -> ESPCN over-activation
  - Large depth errors near object boundaries -> Mask R-CNN misalignment
  - Training instability or NaN losses -> Learnable K diverging
- First 3 experiments:
  1. Replace bilinear upsampling with ESPCN in depth decoder and measure RMS improvement.
  2. Add learnable camera intrinsics network and compare with fixed K baseline.
  3. Integrate Mask R-CNN refinement and evaluate impact on semantic boundary accuracy.

## Limitations
- Mask R-CNN integration lacks specification of exact class IDs and confidence thresholds, making reproduction difficult
- All three proposed mechanisms (Mask R-CNN, ESPCN, learnable K) lack independent validation from external studies
- No ablation studies to quantify individual contributions of each modification to the reported performance gains

## Confidence
- **Low confidence**: Mask R-CNN refinement mechanism - relies solely on source paper implementation with no external validation
- **Medium confidence**: ESPCN upsampling - theoretically sound but no comparative evaluation against alternatives like transposed convolutions
- **Medium confidence**: Learnable camera intrinsics - plausible mechanism but no analysis of stability or sensitivity to initialization
