# Robustness, Evaluation and Adaptation of Machine Learning Models in the Wild

## Quick Facts
- arXiv ID: 2303.02781
- Source URL: https://arxiv.org/abs/2303.02781
- Reference count: 3
- One-line primary result: Proposes algorithms for training robust models, proactive evaluation via accuracy surfaces, and lightweight adaptation using unlabeled data, achieving consistent improvements across diverse tasks.

## Executive Summary
This thesis addresses the challenge of improving ML model reliability when deployed in the wild, where test data distributions often differ from training data. It proposes three complementary strategies: training models to be more robust to domain shifts, evaluating models proactively across interpretable attribute spaces, and adapting models using only unlabeled data. The work introduces several algorithms including CSD and CGD for domain robustness, AAA for accuracy surface estimation, and lightweight adaptation techniques for NLP services.

## Method Summary
The thesis develops three main approaches to address ML model failures in the wild. For training robustness, it introduces CSD (common-specific decomposition) which separates domain-generalizing features from domain-specific ones, and CGD (common gradient descent) which models inter-domain interactions. For evaluation, it proposes AAA (accuracy surfaces over attribute spaces) using Gaussian processes to model accuracy as a function over interpretable attributes. For adaptation, it develops lightweight techniques including RegSense regularization and SrcSel source selection for corpus sketch-based adaptation of NLP models.

## Key Results
- CSD and CGD algorithms achieve significant improvements in worst-case accuracy and robustness to subpopulation shifts across multiple datasets
- AAA system enables proactive evaluation of model vulnerabilities through accuracy surface estimation, outperforming baseline methods on demographic variations
- Lightweight adaptation techniques using corpus sketches achieve substantial perplexity improvements on downstream NLP tasks with minimal computational overhead

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Models fail silently when test data shifts from training distribution
- Mechanism: Domain shift breaks the assumption that training and test examples are identically distributed, causing model to exploit spurious correlations that don't generalize
- Core assumption: Training data contains domain-specific features with incidental correlations to labels that vary across domains
- Evidence anchors:
  - [abstract]: "Current ML systems can fail silently on test examples with distribution shifts"
  - [section 1.1]: "Standard training and testing algorithms assume that train and test examples are sampled from the same underlying distribution"
  - [corpus]: Weak - only mentions related work on domain shifts without specific evidence for silent failures
- Break condition: If training data perfectly represents all possible test distributions or if domain-agnostic features are the only label-correlated features

### Mechanism 2
- Claim: Common-specific decomposition separates generalizing features from domain-specific ones
- Mechanism: Decomposes classifier parameters into common component (generalizes across domains) and low-rank domain-specific component (varies across domains), then discards the specific component
- Core assumption: There exist domain-generalizing features whose correlation with labels is consistent across domains
- Evidence anchors:
  - [section 2.3]: "train domain-specific classifiers w̃d that can be represented as w̃d = wc + Wsγd"
  - [section 2.3.2]: "in the setting of equation RNT, where ec ⊥ Es, we saw that the correct domain generalizing classifier is wc = ec"
  - [corpus]: Moderate - related work on decomposition-based approaches but limited specific evidence for low-rank assumption
- Break condition: If no clear separation exists between domain-generalizing and domain-specific features, or if decomposition is not identifiable

### Mechanism 3
- Claim: Accuracy surfaces over attribute spaces enable proactive evaluation of model vulnerabilities
- Mechanism: Models accuracy as a function over interpretable attributes, allowing users to query performance on any attribute combination without acquiring test data
- Core assumption: Input instances can be characterized by a small set of interpretable attributes that capture variability of user expectations
- Evidence anchors:
  - [section 4.1]: "we propose that a model provider... publish the accuracy of the classification model... as a surface defined on a space of input instance attributes"
  - [section 4.1]: "Indoor-outdoor, day-night, urban-rural may be attributes of input images for visual object recognition tasks"
  - [corpus]: Moderate - related work on subpopulation performance but limited specific evidence for attribute-based surfaces
- Break condition: If attributes are not interpretable, not available, or if attribute combinations grow combinatorially making surface estimation infeasible

## Architecture Onboarding

- Component map:
  Training for domain robustness: CSD algorithm (common-specific decomposition) -> CGD algorithm (common gradient descent)
  Evaluation of deployed models: AAA system (accuracy surface estimation) -> BetaGP-SLP model
  Unlabeled domain adaptation: RegSense regularization -> SrcSel source selection -> KYC adaptation system

- Critical path:
  1. Identify domain shifts causing model failures
  2. Apply appropriate training algorithm (CSD/CGD) to improve robustness
  3. Evaluate model vulnerabilities using accuracy surfaces
  4. Adapt model to target domain if performance is poor

- Design tradeoffs:
  - CSD vs CGD: CSD explicitly decomposes parameters but requires low-rank assumption; CGD models inter-domain interactions but may be computationally heavier
  - BetaGP-SLP vs simpler estimators: BetaGP-SLP handles heteroscedasticity but is more complex; simpler estimators may underfit uncertainty
  - RegSense vs SrcSel: RegSense only uses target corpus; SrcSel also uses source corpus but requires additional computation

- Failure signatures:
  - CSD: Poor decomposition if rank is mis-specified or if common/specific features are not separable
  - CGD: May overfit to noisy domains if choice adjustment is not properly tuned
  - AAA: Poor estimates if attribute space is too large or if attributes are not well-calibrated
  - RegSense: May not adapt if target corpus is too small or if semantic drift is too large
  - KYC: May fail if client sketches are not representative or if adaptation is too simple

- First 3 experiments:
  1. Test CSD on rotated MNIST to verify decomposition separates rotation angle from digit identity
  2. Test AAA on MF-CelebA to verify accuracy surface captures demographic variations
  3. Test SrcSel on StackExchange topics to verify source selection improves perplexity over target corpus

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the impact of extreme domain imbalance on the performance of CGD?
- Basis in paper: [explicit] The paper states that CGD's performance degrades with increasing ratio of majority to minority domain sizes, with the worst domain error rate of 0.45% being far better than the 0.49% of groupDRO at a 1000:1 ratio.
- Why unresolved: The paper only evaluates CGD on a limited set of domain imbalance ratios. It's unclear how CGD would perform on even more extreme imbalances or with different data distributions.
- What evidence would resolve it: Extensive experiments on datasets with varying levels of domain imbalance, including ratios beyond 1000:1, would help understand CGD's robustness to extreme domain shifts.

### Open Question 2
- Question: How does CGD compare to other methods for subpopulation shift robustness, such as IRM or PGI?
- Basis in paper: [inferred] The paper mentions CGD's focus on inter-domain interactions and its ability to avoid learning spurious features. However, it doesn't directly compare CGD to other methods like IRM or PGI, which also aim to address subpopulation shift.
- Why unresolved: The paper focuses primarily on comparing CGD to groupDRO and other methods for domain generalization. A direct comparison with other subpopulation shift methods would provide a more comprehensive evaluation of CGD's effectiveness.
- What evidence would resolve it: Experiments comparing CGD to IRM, PGI, and other methods on standard subpopulation shift benchmarks would help determine its relative performance.

### Open Question 3
- Question: How does CGD's performance scale with the number of domains and the dimensionality of the input space?
- Basis in paper: [inferred] The paper discusses the computational complexity of CGD and mentions that it scales linearly with the number of domains. However, it doesn't explicitly evaluate the impact of increasing the number of domains or the dimensionality of the input space on CGD's performance.
- Why unresolved: The scalability of CGD to high-dimensional data and a large number of domains is crucial for its practical applicability. The paper doesn't provide insights into how CGD's performance might be affected by these factors.
- What evidence would resolve it: Experiments on datasets with varying numbers of domains and increasing input dimensionality would help understand CGD's scalability and identify potential limitations.

## Limitations
- The low-rank assumption in CSD may not hold for all real-world domain shifts, potentially limiting its applicability
- The accuracy surface estimation approach depends heavily on having well-calibrated attribute classifiers, which may not be available in practice
- The evaluation focuses primarily on classification tasks, leaving open questions about applicability to other ML domains like regression or structured prediction

## Confidence
- High confidence: The existence of silent failures due to domain shifts (well-established in ML literature)
- Medium confidence: The effectiveness of common-specific decomposition for domain robustness (supported by experiments but depends on low-rank assumption)
- Medium confidence: The utility of accuracy surfaces for proactive evaluation (demonstrated but limited to attribute-rich domains)
- Medium confidence: The effectiveness of corpus sketch-based adaptation (validated on NLP tasks but may not generalize)
