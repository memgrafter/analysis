# Injecting the BM25 Score as Text Improves BERT-Based Re-rankers

## Quick Facts
- arXiv ID: 2301.09728
- Source URL: https://arxiv.org/abs/2301.09728
- Reference count: 40
- Injecting BM25 scores as text tokens improves BERT-based cross-encoder re-rankers across multiple metrics and datasets.

## Executive Summary
This paper introduces a simple yet effective method to improve BERT-based cross-encoder re-rankers by injecting normalized BM25 scores as text tokens in the input. The approach addresses the challenge of interpolating BM25 and BERT scores, where cross-encoders often underperform BM25 on exact matching tasks. By normalizing BM25 scores using global Min-Max and converting them to integers, the method provides a discriminative signal that helps cross-encoders better capture lexical relevance while retaining semantic understanding. Experiments on MSMARCO Passage and TREC DL collections demonstrate consistent improvements across four different cross-encoder architectures.

## Method Summary
The method involves injecting normalized BM25 scores as text tokens between the query and document in cross-encoder inputs. BM25 scores are globally normalized using Min-Max normalization and converted to integers by multiplying by 100. This normalized score is then injected as a text token in the input sequence. The approach is evaluated with four cross-encoder architectures (BERT-base, BERT-large, DistilBERT, MiniLM) on MSMARCO Passage and TREC DL collections, showing improvements in nDCG@10, MAP, and MRR@10 metrics.

## Key Results
- All four cross-encoders (BERT-base, BERT-large, DistilBERT, MiniLM) show consistent improvements on nDCG@10, MAP, and MRR@10 metrics
- The method outperforms both plain cross-encoders and linear interpolation ensembles
- Analysis shows better exact matching performance than BM25 alone, with 40% overlap between relevant passages ranked by BM25 and BERT with BM25 injection
- Improvements are consistent across different query types and robust to model architecture choices

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Injecting BM25 scores helps cross-encoders capture exact matching relevance signals
- Mechanism: The injected score acts as a strong prior for lexical overlap, compensating for BERT's tendency to underweight exact term matches
- Core assumption: BERT can effectively process numerical values when represented as text
- Evidence anchors: Paper's abstract and experimental results showing improved exact matching
- Break condition: If the score is not normalized appropriately or the model cannot interpret the numeric string

### Mechanism 2
- Claim: Global Min-Max normalization provides a more interpretable signal for the cross-encoder
- Mechanism: Global normalization ensures high-scoring documents receive scores close to 1, making relative importance more apparent
- Core assumption: Cross-encoders can distinguish between different normalized integer values
- Evidence anchors: Experimental results showing global normalization outperforms local normalization
- Break condition: If global statistics don't accurately represent score distribution

### Mechanism 3
- Claim: Injected BM25 score helps cross-encoders mimic BM25's exact matching while retaining semantic capabilities
- Mechanism: The score provides lexical matching signals that the model combines with its own semantic understanding
- Core assumption: Cross-encoders can effectively fuse lexical and semantic signals
- Evidence anchors: Overlap analysis showing increased common relevant passages between BM25 and injected methods
- Break condition: If the model over-relies on the score or cannot combine signals effectively

## Architecture Onboarding

- Component map: First-stage retriever (BM25) -> Second-stage re-ranker (Cross-encoder) -> Input modification (BM25 score injection) -> Output (reranked documents)

- Critical path:
  1. Retrieve top-k documents using BM25
  2. Normalize BM25 scores using global Min-Max and convert to integers
  3. Inject normalized BM25 score as text token into cross-encoder input
  4. Fine-tune cross-encoder on query-document pairs
  5. Rerank documents using fine-tuned cross-encoder

- Design tradeoffs:
  - Simplicity vs. potential for more complex feature engineering
  - Global normalization vs. local normalization (consistency vs. adaptability)
  - Integer representation vs. float representation (BERT numeracy vs. precision)

- Failure signatures:
  - No improvement or degradation in ranking effectiveness
  - Over-reliance on BM25 score leading to loss of semantic understanding
  - Inability to handle out-of-vocabulary BM25 scores

- First 3 experiments:
  1. Compare effectiveness of different BM25 score representations on small data subset
  2. Evaluate impact of local vs. global normalization on ranking effectiveness
  3. Test method with different cross-encoder architectures to assess robustness

## Open Questions the Paper Calls Out

- Question: How do cross-encoders perform when BM25 scores are injected for long documents requiring truncation?
  - Basis in paper: Authors note truncation issues and suggest BM25 score might provide information about lexical relevance of whole document
  - Why unresolved: Experiments were on passage collections where truncation was less of an issue
  - What evidence would resolve it: Experiments on document collections requiring truncation comparing with/without BM25 injection

- Question: Does injecting BM25 scores improve dense retrievers that use semantic embeddings?
  - Basis in paper: Authors acknowledge combining BM25 and dense retrievers shows improvements but state this is outside scope
  - Why unresolved: Paper focuses exclusively on lexical retrievers and cross-encoders
  - What evidence would resolve it: Experiments applying BM25 injection to dense retrievers like DPR or ANCE

- Question: What's the impact of injecting BM25 scores when using multiple lexical rankers or adding traditional Learning-to-Rank features?
  - Basis in paper: Authors suggest injecting scores from several lexical rankers and adding more traditional features could be interesting directions
  - Why unresolved: Paper only demonstrates method with BM25 as single lexical ranker
  - What evidence would resolve it: Experiments comparing cross-encoders with BM25 injection alone vs. multiple lexical ranker scores

## Limitations

- The method's effectiveness may be sensitive to specific implementation choices like normalization parameters and integer conversion
- Theoretical grounding for why BERT processes numeric strings as text tokens lacks rigorous validation
- The approach builds on relatively isolated prior work with limited community validation

## Confidence

- **High confidence**: Empirical claim that injecting normalized BM25 scores improves cross-encoder effectiveness across multiple metrics and datasets
- **Medium confidence**: Claim about improved exact matching performance compared to both BM25 and plain cross-encoders
- **Low confidence**: Generalizability claim that this approach works across different query types, BM25 variants, and normalization schemes
