# ConKI: Contrastive Knowledge Injection for Multimodal Sentiment Analysis

## Quick Facts
- **arXiv ID**: 2306.15796
- **Source URL**: https://arxiv.org/abs/2306.15796
- **Reference count**: 18
- **Key outcome**: ConKI outperforms prior state-of-the-art methods on MAE, correlation, classification accuracy, and F1 metrics for multimodal sentiment analysis

## Executive Summary
ConKI addresses multimodal sentiment analysis by injecting domain-specific knowledge alongside general knowledge from pretrained models. It decomposes each modality's representation into pan-knowledge (from BERT or transformers) and knowledge-specific (via adapters) parts. A hierarchical contrastive learning procedure operates between knowledge types within each modality, across modalities within samples, and across samples to improve learning. Experiments on CMU-MOSI, CMU-MOSEI, and SIMS show ConKI achieves state-of-the-art performance on multiple evaluation metrics, demonstrating the effectiveness of combining knowledge injection with contrastive learning for MSA.

## Method Summary
ConKI uses knowledge injection via adapters and hierarchical contrastive learning to improve multimodal sentiment analysis. The method extracts low-level features from text, audio, and video modalities, encodes them with BERT and transformer encoders, and trains modality-specific adapters on external datasets. These adapters are then fine-tuned on target datasets with both the main MSA task loss (mean squared error) and a hierarchical contrastive loss that operates at three levels: knowledge-level, modality-level, and sample-level contrasts. This approach allows the model to leverage both general knowledge from pretrained models and domain-specific knowledge from adapters while maintaining contrastive learning objectives across multiple dimensions.

## Key Results
- Achieves state-of-the-art performance on MAE, correlation, classification accuracy, and F1 metrics across CMU-MOSI, CMU-MOSEI, and SIMS datasets
- Demonstrates effectiveness of combining knowledge injection with contrastive learning for multimodal sentiment analysis
- Shows improved performance compared to previous methods that use either knowledge injection or contrastive learning alone

## Why This Works (Mechanism)
The mechanism works by decomposing modality representations into general knowledge from pretrained models and domain-specific knowledge from adapters, then using hierarchical contrastive learning to reinforce the relationships between these knowledge types. The three-level contrastive learning (within modality, across modalities, and across samples) creates a rich learning signal that helps the model better understand the complex relationships in multimodal sentiment data.

**Critical Path**: Feature extraction → Adapter knowledge injection → Hierarchical contrastive learning → Sentiment prediction
**Design Tradeoffs**: Knowledge injection vs. full fine-tuning (adapter approach is more parameter-efficient), single vs. multi-level contrastive learning (hierarchical provides richer learning signals)
**Failure Signatures**: Poor adapter pretraining on external dataset leads to degraded performance, suboptimal contrastive loss parameters cause unstable training

## Limitations
- Adapter architecture details beyond basic sandwich structure are not fully specified, potentially affecting reproducibility
- Negative pair construction details for hierarchical contrastive learning are not explicitly described
- Performance may be sensitive to proper tuning of contrastive learning parameters (temperature τ and balance weight λ)

## Confidence
- **High confidence**: The general methodology of using adapters for knowledge injection and the three-level contrastive learning framework are clearly described and represent valid approaches
- **Medium confidence**: The specific architectural details (adapter structure, contrastive loss parameters) are sufficient for implementation but may affect performance outcomes
- **Medium confidence**: The experimental results demonstrate state-of-the-art performance, but the exact reproduction of these results depends on unspecified implementation details
