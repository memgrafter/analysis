# Angle based dynamic learning rate for gradient descent

## Quick Facts
- arXiv ID: 2304.10457
- Source URL: https://arxiv.org/abs/2304.10457
- Reference count: 40
- Primary result: Angle-based method for adaptive learning rates achieves higher accuracy than Adam, RMSprop, and AdaBelief on CIFAR-10/100 and mini-ImageNet

## Executive Summary
This paper proposes a novel angle-based method for dynamically adjusting learning rates in gradient descent optimization. The approach computes gradients at two points - the current location and a point orthogonal to the current gradient direction - then uses the angle between these gradients to determine an adaptive step size via cotangent. The method is simple to implement, requires no second-order information, and satisfies the Armijo condition for sufficient decrease. Experiments on CIFAR-10, CIFAR-100, and mini-ImageNet datasets show that the proposed method achieves higher accuracy than state-of-the-art optimizers like Adam, RMSprop, and AdaBelief on architectures including ResNet, DenseNet, and EfficientNet.

## Method Summary
The method computes an adaptive learning rate by measuring the angle between the current gradient and a gradient computed at a point displaced perpendicularly from the current location. At each iteration, it calculates the negative gradient g1 at the current point X, generates a random perpendicular unit vector p1, perturbs X to a new point X2 by stepping h units in the perpendicular direction, then computes gradient g2 at X2. The angle θ between g1 and g2 is calculated, and the step size is set as d = h·cot(θ) + ε (to prevent division by zero). An exponentially weighted average of past step sizes is maintained, and if the current step is below this average, it is doubled to prevent stalling. The final update moves in the direction of the normalized g1 by the computed step size.

## Key Results
- The proposed method achieves higher classification accuracy than Adam, RMSprop, and AdaBelief on CIFAR-10, CIFAR-100, and mini-ImageNet datasets
- The method satisfies the Armijo condition for sufficient decrease, ensuring monotonic progress on convex loss surfaces
- Convergence is proven under assumptions of convex loss with Lipschitz-continuous gradients

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The adaptive learning rate adjusts step size based on the angle between the current gradient and a probe gradient computed in the perpendicular direction.
- Mechanism: The algorithm samples a point displaced perpendicularly from the current location, computes a new gradient there, measures the angle between this gradient and the original one, and uses the cotangent of that angle to set the step size. This dynamically adapts to the local curvature without requiring expensive second-order information.
- Core assumption: The angle between two nearby gradients is a meaningful proxy for local curvature that can guide step size selection.
- Evidence anchors:
  - [abstract] "we use the angle between the current gradient and the new gradient: this new gradient is computed from the direction orthogonal to the current gradient"
  - [section II] "At X2 we calculate another negative gradient g2... We now simply use these information to calculate the height of the triangle as shown in the Figure 2 by calculating the step size d = h · cot (θ)"
- Break condition: If the orthogonal step h is too large, gradients may lie in different localities and the angle no longer reflects local geometry; if h is too small, the angle becomes unstable or near zero.

### Mechanism 2
- Claim: The method satisfies Armijo's sufficient decrease condition, ensuring monotonic progress.
- Mechanism: By bounding the perpendicular step h and relating it to the gradient norm and Lipschitz constant, the proof shows that the objective function decreases at each iteration, fulfilling Armijo's condition.
- Core assumption: The loss surface is convex and has Lipschitz-continuous gradients, which allows analytical bounds on step size.
- Evidence anchors:
  - [section IV] "Under the assumptions of theorem 1, the update rule in Algorithm 1 satisfies the first Wolfe's sufficient decrease condition condition (5) with c1 = 1/2L"
  - [section IV, Theorem 1 proof] shows the derivation of sufficient decrease using the Lipschitz bound.
- Break condition: For non-convex surfaces, the convexity assumption fails, and the proof of monotonic decrease no longer holds.

### Mechanism 3
- Claim: The decaying expectation of step sizes prevents overly aggressive steps when the current estimate is much smaller than recent history.
- Mechanism: The algorithm maintains an exponentially weighted average of past step sizes and, if the current step is below this average, doubles it. This smooths the learning rate trajectory and avoids stalling in flat regions.
- Core assumption: Past step sizes provide a reasonable baseline for the expected magnitude of useful steps.
- Evidence anchors:
  - [section II, Algorithm 1 steps 8-11] "davg ← β · davg + (1 − β) · d ... if d < davg then d ← 2 · d"
- Break condition: If the landscape changes abruptly, the decaying average may lag and cause overcorrection when doubling steps.

## Architecture Onboarding

- Component map: Compute g1 at X -> Generate perpendicular vector p1 -> Perturb to X2 = X - h·p1 -> Compute g2 at X2 -> Calculate angle θ between g1 and g2 -> Compute step d = h·cot(θ) -> Update davg and possibly double d -> Update X = X + (d/||g1||)·g1

- Critical path:
  1. Compute g1 = -∇f(X)
  2. Generate random perpendicular unit vector p1
  3. Perturb X to X2 = X - h · p1
  4. Compute g2 = -∇f(X2)
  5. Calculate angle θ between g1 and g2
  6. Compute step d = h · cot(θ)
  7. Update davg and possibly double d if too small
  8. Update X = X + (d / ||g1||) · g1

- Design tradeoffs:
  - Small h → stable angle but poor exploration; large h → better exploration but risk of measuring unrelated gradients
  - Fixed h vs. adaptive h: fixed is simpler but may be suboptimal across different loss landscapes
  - Adding ε to cot(θ) prevents numerical instability but introduces a small bias

- Failure signatures:
  - NaNs or infinities in d due to θ ≈ 0 (can happen if h is too small or gradients are nearly parallel)
  - Diverging training if h is too large and gradients become uncorrelated
  - No improvement in accuracy compared to baselines on non-convex tasks

- First 3 experiments:
  1. Run on a simple convex quadratic to verify monotonic decrease and Armijo condition satisfaction.
  2. Compare convergence speed on CIFAR-10 with ResNet18 against Adam and SGD with momentum.
  3. Test sensitivity to h by sweeping h over several orders of magnitude on a toy surface (e.g., f(x,y) = -sin(x² + y²)/(x² + y²)).

## Limitations
- The convergence proof assumes convex loss functions, but deep learning loss surfaces are highly non-convex, making theoretical guarantees uncertain
- The method requires computing an additional gradient at each step, doubling gradient computations and potentially increasing training time
- Optimal values for the perpendicular step size h and decay rate β may vary significantly across tasks and architectures

## Confidence
- High confidence: Empirical results showing improved accuracy on CIFAR-10, CIFAR-100, and mini-ImageNet with ResNet, DenseNet, and EfficientNet architectures are well-documented and reproducible
- Medium confidence: Theoretical convergence proof under convexity assumptions is mathematically sound, but applicability to deep learning scenarios is uncertain
- Low confidence: Claims about effectiveness across diverse architectures and datasets beyond reported experiments would require additional validation
