# A Unified Evaluation Framework for Novelty Detection and Accommodation in NLP with an Instantiation in Authorship Attribution

## Quick Facts
- arXiv ID: 2305.05079
- Source URL: https://arxiv.org/abs/2305.05079
- Reference count: 40
- Key outcome: Introduces NoveltyTask framework for evaluating novelty detection and accommodation in NLP, instantiated in authorship attribution with BERT-base model

## Executive Summary
This paper presents NoveltyTask, a two-stage evaluation framework for assessing NLP systems' ability to handle novel instances. The framework consists of novelty detection (identifying whether instances belong to known classes or are novel) followed by novelty accommodation (classifying across all classes including novel ones using feedback). The authors instantiate this framework in authorship attribution using a dataset of 250,000 Amazon reviews across 200 authors. Experiments show that baseline methods achieve low performance in both stages, highlighting the challenge of the task. The MaxProb method performs best in novelty detection, while retraining methods outperform others in novelty accommodation.

## Method Summary
The method involves training a BERT-base model with a linear classification layer on 100 known classes (500 instances each), then evaluating novelty detection on 20,000 instances (100 per class) and accommodation on 100,000 instances (500 per class). Various novelty detection methods (MaxProb, Euclidean distance, Mahalanobis distance, etc.) are compared, and accommodation is performed through different approaches: retraining with original and feedback data, fine-tuning only on feedback, and fine-tuning with sampled original data plus feedback. The framework evaluates performance using F1 scores for known and novel classes in detection, and overall F1 across ranges of reported novelties in accommodation.

## Key Results
- Baseline methods achieve low performance in both novelty detection and accommodation stages
- MaxProb method performs best in novelty detection using maximum softmax probability as confidence estimator
- Retraining methods outperform fine-tuning approaches in novelty accommodation
- Feedback dataset quality significantly impacts accommodation performance
- Catastrophic forgetting occurs when fine-tuning only on feedback dataset

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Two-stage pipelined formulation correlates detection accuracy with accommodation performance
- Mechanism: Correct novelty detection provides more ground truth labels in feedback dataset DF, enabling better learning of novel classes during accommodation
- Core assumption: Feedback dataset DF contains enough examples per novel class for meaningful learning
- Evidence anchors: Abstract mentions correlation between detection accuracy and accommodation performance; section discusses trivial system flagging all as novel to maximize feedback
- Break condition: If DF contains fewer than 5-10 examples per novel class, accommodation performance plateaus

### Mechanism 2
- Claim: MaxProb effectiveness stems from using model confidence to identify out-of-distribution samples
- Mechanism: Novel instances typically have lower maximum softmax probabilities as they don't fit known class distributions
- Core assumption: Model's softmax outputs meaningfully reflect confidence and distinguish known from novel instances
- Evidence anchors: Abstract identifies MaxProb as best detection method; section describes using maximum softmax probability as confidence estimator
- Break condition: If softmax distributions are poorly calibrated or novel instances randomly align with known classes

### Mechanism 3
- Claim: Catastrophic forgetting mitigated by sampling from original training data alongside feedback
- Mechanism: Sampling from original DT dataset alongside DF maintains exposure to known classes while learning novel ones
- Core assumption: Sampled DT dataset provides sufficient diversity to prevent forgetting known classes
- Evidence anchors: Section describes strategy of further fine-tuning using both sampled DT and DF; mentions improvement over retraining method
- Break condition: If downsampling is too aggressive, forgetting still occurs; if too lenient, novel class learning suffers

## Foundational Learning

- Concept: Multi-class classification with (K+1) classes where extra class represents "novel"
  - Why needed here: Detection stage requires distinguishing between K known classes and one "novel" class
  - Quick check question: In a (K+1) class classification problem, if an instance is predicted as the (K+1)th class, what does that indicate about the instance?

- Concept: Catastrophic forgetting in neural network fine-tuning
  - Why needed here: Understanding why fine-tuning only on DF causes performance degradation on known classes
  - Quick check question: What happens to a neural network's performance on previously learned tasks when it is fine-tuned only on new, different data?

- Concept: Evaluation metrics for imbalanced datasets (micro vs macro F1, AUC)
  - Why needed here: Novelty detection and accommodation stages have imbalanced class distributions
  - Quick check question: When would you prefer micro F1 over macro F1 for evaluating a multi-class classification model?

## Architecture Onboarding

- Component map: BERT-base model -> Linear classification layer -> Novelty detection module -> Feedback incorporation module -> Evaluation module
- Critical path: Training → Novelty Detection → Feedback Generation → Accommodation → Final Evaluation
- Design tradeoffs: Detection vs accommodation performance (better detection provides more feedback but may sacrifice known class accuracy); feedback quality vs quantity (more feedback helps accommodation but may contain noise if detection is imperfect); model capacity (retraining from scratch uses more resources but may generalize better than fine-tuning)
- Failure signatures: Low F1Novel in detection stage (model cannot distinguish novel from known instances); high F1Known but low overall F1 in accommodation (catastrophic forgetting occurring); plateau in accommodation performance (feedback dataset too small or uninformative)
- First 3 experiments: 1) Run baseline detection with MaxProb on Eval Det and plot P-R curves for known vs novel classes; 2) Implement feedback incorporation via retraining and compare to fine-tuning only on DF; 3) Test the sampled DT + DF method and measure catastrophic forgetting on known classes

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the number of training examples per known label in the initial dataset affect novelty detection and accommodation performance?
- Basis in paper: Authors study different configuration settings by varying parameters like number of known classes and instances per class in evaluation, but do not explicitly analyze effect of varying training examples per known label
- Why unresolved: Paper focuses on label-balanced setting without investigating how initial training dataset size impacts handling novelties
- What evidence would resolve it: Experiments comparing performance across different numbers of training examples per known label (e.g., 100, 500, 1000) while keeping other parameters constant

### Open Question 2
- Question: How do more advanced novelty detection methods (e.g., contrastive learning, meta-learning) compare to baseline methods explored?
- Basis in paper: Authors acknowledge exploring only limited set of methods and mention several advanced methods from recent literature that could be explored
- Why unresolved: Paper's primary goal is introducing NoveltyTask framework, not extensively comparing different detection methods
- What evidence would resolve it: Experiments comparing performance of advanced methods (contrastive learning, meta-learning) against baseline methods using same evaluation protocol

### Open Question 3
- Question: How does performance change in label-imbalanced settings?
- Basis in paper: Authors mention only investigating label-balanced setting and that exploring label-imbalanced setting is interesting research direction
- Why unresolved: Paper focuses on label-balanced setting without investigating performance changes when instances per class are imbalanced
- What evidence would resolve it: Experiments comparing performance in label-imbalanced settings while keeping other parameters constant

## Limitations
- Effectiveness of MaxProb method may be dataset-dependent and not generalize across different domains
- Optimal sampling strategy for preventing catastrophic forgetting is underspecified in the sampled DT+DF method
- Framework scalability to tasks with thousands of classes or different data modalities beyond text remains untested

## Confidence

**High Confidence**: Two-stage pipelined formulation and overall task definition are well-justified by literature on open-world learning; observation that retraining methods outperform fine-tuning has strong empirical support

**Medium Confidence**: Claim that higher detection accuracy leads to better accommodation assumes feedback dataset contains enough informative examples per novel class; relationship may break down if DF is too small or imbalanced; specific sampling strategy significantly impacts results but is underspecified

**Low Confidence**: Superiority of specific novelty detection methods (like MaxProb) across all scenarios may be dataset-dependent; framework's scalability to tasks with thousands of classes or different data modalities remains untested

## Next Checks

1. **Feedback Dataset Quality Analysis**: Systematically vary the number of instances per novel class in DF and measure corresponding accommodation performance to determine minimum viable feedback size for meaningful learning

2. **Calibration Testing**: Evaluate whether MaxProb confidence scores are well-calibrated by computing expected calibration error (ECE) on detection stage to verify assumption that low MaxProb indicates novelty

3. **Sampling Strategy Ablation**: Compare different sampling strategies for DT (random sampling, stratified sampling, importance sampling) when incorporating feedback to identify optimal approach for preventing catastrophic forgetting
