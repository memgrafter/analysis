# K-SHAP: Policy Clustering Algorithm for Anonymous Multi-Agent State-Action Pairs

## Quick Facts
- arXiv ID: 2302.11996
- Source URL: https://arxiv.org/abs/2302.11996
- Reference count: 22
- Primary result: Outperforms existing methods by 2x in ARI, NMI, and purity metrics on both synthetic and real market data

## Executive Summary
K-SHAP is a novel policy clustering algorithm designed to identify distinct behavioral strategies among anonymous agents in multi-agent systems. The method uses imitation learning to train a world-policy that mimics all agent behaviors, then applies SHAP values to explain how state features influence actions. By clustering these SHAP values with K-Means, K-SHAP successfully groups observations according to agent policies without requiring identity labels. The algorithm demonstrates superior performance compared to existing clustering methods on both synthetic market data and real-world financial datasets, making it particularly valuable for analyzing confidential market data where participant identities are unknown.

## Method Summary
K-SHAP frames policy clustering as an imitation learning problem where a world-policy learns to map states to actions for all agents. The algorithm first trains a Random Forest model on anonymous state-action pairs to learn collective agent behaviors. It then computes SHAP values for each observation, which measure each feature's contribution to the predicted action in the action space units. Finally, K-Means clustering is applied to these SHAP values to group observations with similar behavioral responses. The method requires knowing the number of clusters k from ground truth in synthetic experiments, though it can use the Elbow method when k is unknown.

## Key Results
- Outperforms K-Means, ClusterGAN, DCN, and EM K-Clustering by 2x factors in ARI, NMI, and purity metrics
- Successfully identifies trader strategies from anonymous NASDAQ market data using Silhouette index and Utility metrics
- Demonstrates consistent performance across both synthetic market data (with ground truth) and real financial datasets

## Why This Works (Mechanism)

### Mechanism 1
- SHAP values convert state features into a common metric space regardless of original units, enabling effective clustering
- SHAP values measure each feature's contribution to the model output in the same units as the output (action space), normalizing features with different magnitudes and units
- Core assumption: The world-policy accurately learns to map states to actions for all agent behaviors
- Evidence anchors: [abstract] mentions using SHAP to generate feature attribution explanations; [section] explains features have same units as model output in SHAP space
- Break condition: If the world-policy fails to accurately model agent behaviors, SHAP values will not meaningfully represent behavioral differences

### Mechanism 2
- Clustering in SHAP space groups observations based on how agents respond to environmental states rather than raw state-action patterns
- SHAP values capture the mapping from environmental states to actions, so similar behavioral responses produce similar SHAP vectors
- Core assumption: Agents with the same policy will respond similarly to identical environmental states
- Evidence anchors: [abstract] states algorithm identifies distinct behavioral strategies by clustering SHAP values; [section] describes SHAP values describing agent responses to input features
- Break condition: If agents use identical state-action mappings but different internal reasoning, or if state-action pairs are identical across different strategies

### Mechanism 3
- The world-policy learns collective agent behaviors by modeling the mapping from states to actions for all agents
- Behavioral cloning on anonymous state-action pairs forces the model to learn all possible state-action mappings present in the data
- Core assumption: The anonymous state-action pairs contain sufficient information to distinguish between different policies
- Evidence anchors: [abstract] describes learning a world-policy that mimics all agent behaviors upon different environmental states; [section] characterizes world-policy as emulating collective agent behaviors
- Break condition: If multiple agents produce identical state-action pairs or if behavioral differences are too subtle to distinguish in the state space

## Foundational Learning

- Concept: Imitation Learning (IL) - learning to map states to actions by mimicking demonstrations
  - Why needed here: K-SHAP uses IL to learn a world-policy that can replicate all agent behaviors from anonymous observations
  - Quick check question: What is the difference between behavioral cloning and inverse reinforcement learning?

- Concept: Shapley values - measuring individual feature contributions to a model prediction
  - Why needed here: SHAP values explain how each state feature contributes to an agent's action, revealing behavioral patterns
  - Quick check question: How does the Shapley value calculation ensure fair attribution among features?

- Concept: Clustering algorithms - grouping similar data points based on distance metrics
  - Why needed here: K-Means clusters the SHAP values to group observations with similar behavioral responses
  - Quick check question: What distance metric does K-Means use by default, and why is it appropriate here?

## Architecture Onboarding

- Component map: World-policy → SHAP explainer → K-Means clustering → Policy labels
- Critical path: Data → World-policy training → SHAP value computation → Clustering → Policy identification
- Design tradeoffs: Random Forest (explainable, slower) vs. Neural Network (faster, less interpretable) for world-policy
- Failure signatures: Poor clustering performance when SHAP values show no clear structure; Random Forest may overfit on high-dimensional state spaces
- First 3 experiments:
  1. Train world-policy on synthetic data with known ground truth, visualize SHAP values with UMAP
  2. Compare clustering performance using SHAP values vs. raw state-action pairs
  3. Test different world-policy models (Random Forest, XGBoost, NN) on the same dataset

## Open Questions the Paper Calls Out

- Question: How does K-SHAP handle situations where agent actions are primarily driven by sequential dependencies rather than state features?
  - Basis in paper: The paper mentions that K-SHAP "has not enough information to classify an action driven only by a sequence of previous actions, unless the state retains traces of the agent actions."
  - Why unresolved: The paper identifies this as a limitation but doesn't propose solutions or evaluate performance in such scenarios.
  - What evidence would resolve it: Experiments comparing K-SHAP performance on datasets with sequential dependencies versus state-only dependencies, and proposed modifications to handle sequential information.

- Question: What is the impact of using different world-policy models (Random Forest, XGBoost, Neural Network) on K-SHAP's clustering performance?
  - Basis in paper: The paper evaluates three different world-policy models in Appendix C.3 and shows varying performance.
  - Why unresolved: While the paper shows different performance metrics, it doesn't provide a detailed analysis of why certain models work better or how to choose the optimal model for different scenarios.
  - What evidence would resolve it: A comprehensive study of world-policy model selection criteria, including model architecture analysis and guidelines for different data types.

- Question: How does K-SHAP perform when the number of clusters k is unknown and must be determined through the Elbow method?
  - Basis in paper: The paper discusses using the Elbow method for unknown k in Appendix C.1 but notes that "the performance is slightly inferior."
  - Why unresolved: The paper shows performance degradation but doesn't quantify the trade-off or provide strategies to improve clustering accuracy when k is unknown.
  - What evidence would resolve it: Detailed comparison of clustering performance with known versus unknown k across multiple datasets, and proposed methods to improve accuracy when k is unknown.

## Limitations
- Method assumes SHAP values in action space can distinguish policies, but may fail when multiple agents produce identical state-action pairs
- Performance heavily depends on world-policy accuracy with no clear diagnostics for insufficient learning
- Requires knowing number of clusters k from ground truth in synthetic experiments, limiting real-world applicability

## Confidence

- High confidence: SHAP values normalize feature contributions to a common metric space, enabling effective clustering
- Medium confidence: World-policy approach successfully learns collective agent behaviors from anonymous state-action pairs
- Low confidence: Method generalizes robustly to real-world scenarios where ground truth policy labels are unavailable
