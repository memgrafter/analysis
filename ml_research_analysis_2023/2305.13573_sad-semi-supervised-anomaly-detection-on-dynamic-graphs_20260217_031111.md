# SAD: Semi-Supervised Anomaly Detection on Dynamic Graphs

## Quick Facts
- arXiv ID: 2305.13573
- Source URL: https://arxiv.org/abs/2305.13573
- Reference count: 19
- Key outcome: SAD achieves 1.95% average AUC improvement over baselines on four datasets

## Executive Summary
This paper introduces SAD, a semi-supervised framework for anomaly detection on dynamic graphs that addresses the critical challenge of limited labeled data. The framework leverages a time-equipped memory bank to capture temporal distributions of normal and unlabeled samples, combined with pseudo-label contrastive learning to maximize the utility of unlabeled data. By integrating temporal graph encoding with deviation-based anomaly detection, SAD demonstrates state-of-the-art performance across four real-world datasets while requiring minimal labeled examples.

## Method Summary
SAD combines temporal graph encoding, deviation-based anomaly detection, and contrastive learning in a unified framework. The method uses a TGAT-based temporal graph encoder to capture evolving graph structures, an anomaly detector to compute deviation scores from normal patterns, and a time-equipped memory bank that maintains statistical distributions of normal and unlabeled samples. A pseudo-label contrastive learning module leverages these memory banks to generate high-quality contrastive pairs, enabling effective learning from unlabeled data. The framework jointly optimizes anomaly detection objectives with contrastive learning, allowing it to achieve superior performance even with minimal labeled training data.

## Key Results
- Achieves 1.95% average AUC improvement over best baseline across four datasets
- Demonstrates effectiveness with only 5% labeled data
- Outperforms strong baselines including GNN-based and contrastive methods
- Shows consistent improvements across Wikipedia, Reddit, MOOC, and Alipay datasets

## Why This Works (Mechanism)
SAD addresses the fundamental limitation of existing dynamic graph anomaly detection methods that underutilize unlabeled data. By introducing a time-equipped memory bank, the framework captures temporal evolution of normal patterns, enabling better anomaly detection in evolving graphs. The pseudo-label contrastive learning module transforms unlabeled data into valuable training signals, effectively bridging the gap between supervised and unsupervised learning. This combination allows SAD to learn robust representations that distinguish anomalies from normal evolving patterns, particularly in scenarios with limited labeled examples.

2. **Contrastive Learning with Pseudo-labels**
   - Why needed: Leverage large amounts of unlabeled data to improve representation learning when labeled data is scarce
   - Quick check: Ensure that pseudo-labels generated from memory banks have high precision by measuring agreement with ground truth on a validation set

3. **Deviation-based Anomaly Detection**
   - Why needed: Detect anomalies by measuring statistical deviation from learned normal patterns rather than explicit classification
   - Quick check: Validate that anomaly scores follow expected distributions for normal vs. anomalous samples using statistical tests

## Architecture Onboarding

**Component Map**: Temporal Graph Encoder -> Anomaly Detector -> Time-Equipped Memory Bank -> Pseudo-label Contrastive Learning -> Anomaly Detector

**Critical Path**: Input graphs → Temporal encoding → Memory bank updates → Contrastive pair generation → Joint optimization → Anomaly scoring

**Design Tradeoffs**: The framework balances memory overhead (storing distributions) against learning effectiveness, and computational cost of contrastive learning against performance gains from unlabeled data utilization.

**Failure Signatures**: Poor performance may indicate insufficient memory bank decay rate, suboptimal sampling strategy, or improper temperature parameter in contrastive loss leading to collapsed representations.

**First Experiments**:
1. Verify TGAT embeddings capture temporal patterns by visualizing node trajectories over time
2. Test memory bank effectiveness by measuring anomaly score distribution changes as memory decays
3. Evaluate pseudo-label quality by measuring agreement between generated labels and ground truth
