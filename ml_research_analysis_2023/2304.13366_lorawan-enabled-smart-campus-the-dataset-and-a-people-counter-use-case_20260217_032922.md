# LoRaWAN-enabled Smart Campus: The Dataset and a People Counter Use Case

## Quick Facts
- arXiv ID: 2304.13366
- Source URL: https://arxiv.org/abs/2304.13366
- Reference count: 36
- Primary result: 95% accuracy in predicting room occupancy using LSTM on LoRaWAN sensor data

## Executive Summary
This paper presents a comprehensive Smart Campus dataset collected via LoRaWAN infrastructure at the University of Oulu, comprising hundreds of IoT sensors measuring environmental parameters across campus buildings. The dataset addresses the critical challenge of missing sensor transmissions through a k-nearest neighbor (KNN) imputation approach. The authors demonstrate a practical application using deep learning (LSTM) to predict room occupancy based on sensor readings, achieving 95% accuracy. The openly available dataset enables further research in indoor monitoring and occupancy estimation applications.

## Method Summary
The authors deployed hundreds of LoRaWAN sensors across the University of Oulu campus to collect environmental data including CO2 levels, temperature, and humidity. To handle missing transmissions from sensor outages or network collisions, they implemented a KNN-based imputation method to fill gaps in the time series data. For the people counting use case, they developed an LSTM deep learning model that processes sequences of sensor readings to predict the number of occupants in a room. The dataset and models are made openly available for further research and application development.

## Key Results
- KNN imputation successfully handles missing transmissions in LoRaWAN sensor networks
- LSTM model achieves 95% accuracy in predicting room occupancy
- Dataset includes hundreds of sensors measuring CO2, temperature, and humidity across campus
- Open dataset enables exploration of additional features and applications

## Why This Works (Mechanism)
The success of this approach stems from leveraging the temporal patterns in environmental sensor data. CO2 levels and temperature variations correlate strongly with occupancy patterns, providing predictive features for the LSTM model. The KNN imputation works effectively because nearby sensors and similar time periods exhibit correlated behavior, allowing reasonable estimates for missing values. LoRaWAN's low-power, long-range characteristics make it suitable for dense campus deployments while maintaining battery life.

## Architecture Onboarding
**Component Map**: Sensors -> LoRaWAN Gateway -> Cloud Storage -> KNN Imputation -> LSTM Model -> Occupancy Prediction
**Critical Path**: Sensor data collection → Missing data handling → Feature engineering → Model inference → Occupancy output
**Design Tradeoffs**: LoRaWAN chosen for range/battery life over high data rates; KNN selected for simplicity over complex imputation methods; LSTM prioritized for temporal pattern capture over simpler models
**Failure Signatures**: Network congestion causing packet loss; Sensor drift affecting CO2 readings; Model overfitting to specific room configurations
**First Experiments**: 1) Test KNN imputation sensitivity to k parameter choice, 2) Validate LSTM performance across different room sizes, 3) Assess model robustness to sensor placement variations

## Limitations
- Validation limited to single room type and occupancy scenario
- KNN imputation lacks comparison with alternative missing data methods
- 95% accuracy may not generalize across different spatial layouts
