# Iterative Partial Fulfillment of Counterfactual Explanations: Benefits and Risks

## Quick Facts
- arXiv ID: 2303.11111
- Source URL: https://arxiv.org/abs/2303.11111
- Reference count: 40
- Primary result: IPF can have both positive and negative effects on cost, with sensitivity to dataset properties and algorithm choice

## Executive Summary
This paper introduces and formalizes iterative partial fulfillment (IPF), a realistic scenario where users of counterfactual explanations may not fully fulfill the recommendations before seeking updated explanations. The paper investigates how IPF affects the total improvement cost compared to complete fulfillment. It proves that optimal cost counterfactual explanation algorithms are IPF-stable, preserving cost, while gradient ascent and randomized search methods can lead to cost increases due to oscillation or conflicting guidance. Experiments on two datasets with three counterfactual explanation algorithms and four selection strategies show that IPF can have both positive and negative effects on cost, with sensitivity to dataset properties and algorithm choice.

## Method Summary
The paper uses two datasets (Adult Income and German Credit) and a random forest classifier. Counterfactual explanations are generated using the DiCE-ML package with different search methods (random, genetic, prototype-guided). The IPF process is simulated with varying effort levels, tracking total improvement cost, success rate, and number of steps. Demographic parity ratios for relative total cost and number of steps are calculated to analyze fairness implications.

## Key Results
- Optimal cost counterfactual algorithms are IPF-stable, preserving total cost
- Gradient ascent and randomized search algorithms can increase total cost under IPF due to oscillation
- IPF effects are sensitive to dataset properties and algorithm choice

## Why This Works (Mechanism)

### Mechanism 1
Optimal cost counterfactual algorithms find the closest instance with the target prediction. Under IPF, the subject moves toward this optimal point in a straight line. Since the optimal point is closest, any intermediate point on the path remains closer to the optimal point than to any other candidate, preserving the path. This assumes L1-like cost functions and convex feature spaces.

### Mechanism 2
Gradient ascent and randomized search algorithms find local minima that may not be the globally closest point. Under IPF, partial fulfillment may move the subject away from the current local minimum toward a new one, effectively "resetting" progress. This can lead to oscillation between states or paths that require more total change, assuming multiple local minima exist.

### Mechanism 3
Look-up based counterfactual algorithms select the closest instance from a finite set of candidates. Since the set is finite, the closest candidate to any intermediate state remains the same as the closest to the original state, preserving the path. This assumes the candidate set includes a good counterfactual.

## Architecture Onboarding

- **Component map**: Input space X with D features -> Model prediction function m: X → [0,1] -> Counterfactual explanation algorithm A: X → X -> Cost metric c(x,x') -> Partial fulfillment function φ(x,x',u) -> IPF process

- **Critical path**: Generate counterfactual explanation → Simulate partial fulfillment → Update state and generate new explanation → Repeat until positive prediction → Calculate total improvement cost

- **Design tradeoffs**: Algorithm choice affects IPF stability and cost; effort level affects granularity and oscillation potential; maximum iterations affects success rate and total cost

- **Failure signatures**: Oscillation between states; increasing total cost with decreasing effort; inconsistent explanations across iterations

## Open Questions the Paper Calls Out

### Open Question 1
How do different datasets and model types affect the IPF cost increase observed in gradient ascent and randomized search CF algorithms? Unresolved because the paper only tests two datasets with random forest classifiers.

### Open Question 2
Can IPF stability be achieved through regularization techniques in gradient-based CF algorithms? Unresolved because the paper identifies the problem but doesn't explore solutions beyond caching CF explanations.

### Open Question 3
How does the number of CF explanations provided affect IPF welfare outcomes? Unresolved because while the paper shows multiple CF options can increase costs, it doesn't explore optimal numbers or how trade-offs vary.

## Limitations

- Theoretical proofs rely on specific assumptions about cost functions and feature spaces
- Empirical validation uses only random forest classifiers, may not generalize to other architectures
- Does not explore impact of IPF on model interpretability or user trust
