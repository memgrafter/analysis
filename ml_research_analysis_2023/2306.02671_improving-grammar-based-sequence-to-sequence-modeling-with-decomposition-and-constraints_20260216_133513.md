# Improving Grammar-based Sequence-to-Sequence Modeling with Decomposition and Constraints

## Quick Facts
- arXiv ID: 2306.02671
- Source URL: https://arxiv.org/abs/2306.02671
- Reference count: 20
- Primary result: Low-rank variants of Neural QCFG with new constraints outperform vanilla Neural QCFG in most settings

## Executive Summary
This paper addresses the computational inefficiency of Neural QCFG, a grammar-based sequence-to-sequence model, by introducing two low-rank variants and new constraint mechanisms. The authors propose an efficient model (E model) that decomposes binary rules into three parts for faster inference, and an expressive model (P model) that maintains structural constraints while still achieving efficiency gains. Additionally, two new constraints are introduced: a soft tree hierarchy constraint based on node distances and a coverage constraint limiting alignments per source node. Experiments on SCAN, StylePTB, and En-Fr MT datasets demonstrate that these innovations improve performance while reducing computational complexity.

## Method Summary
The method introduces two low-rank variants of Neural QCFG to address its computational inefficiency. The efficient model (E model) decomposes binary rules A[αi] → B[αj]C[αk] into three separate rules: A[αi] → R, R → B[αj], and R → C[αk], reducing time complexity from O(|N|(|N|+|P|)²S³T³) to O(GET³). The expressive model (P model) maintains relationships between source tree nodes using an interface rule R, αi → αj, αk, allowing it to impose all constraints used by vanilla Neural QCFG plus additional ones. Two new constraints are introduced: a soft tree hierarchy constraint that rewards rules with smaller distances between tree nodes, and a coverage constraint that limits the number of alignments per source tree node. The models are trained using maximum likelihood estimation with regularization.

## Key Results
- E model reduces time complexity by decomposing binary rules while maintaining reasonable performance
- P model preserves structural constraints and outperforms vanilla Neural QCFG on most tasks
- Soft tree hierarchy and coverage constraints improve model performance on compositional generalization tasks
- Proposed models and constraints outperform vanilla Neural QCFG in most settings across SCAN, StylePTB, and En-Fr MT datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Decomposing binary rules into three parts reduces time complexity from O(|N|(|N|+|P|)²S³T³) to O(GET³) or better.
- Mechanism: The E model breaks a binary rule A[αi] → B[αj]C[αk] into three separate rules: A[αi] → R, R → B[αj], and R → C[αk]. This decomposition reduces the number of rules from O(|N|(|N|+|P|)²S³) to O((3|N|+2|P|)|R|S), significantly lowering the computational burden.
- Core assumption: The decomposition does not lose critical information needed for inference, and the new symbol set R can adequately represent the relationships between the original symbols.
