# Blind Image Quality Assessment via Vision-Language Correspondence: A Multitask Learning Perspective

## Quick Facts
- **arXiv ID**: 2303.14968
- **Source URL**: https://arxiv.org/abs/2303.14968
- **Reference count**: 40
- **Key outcome**: Joint training of BIQA with scene classification and distortion type identification using CLIP embeddings, outperforming state-of-the-art models

## Executive Summary
This paper presents a novel multitask learning approach to blind image quality assessment (BIQA) that leverages vision-language correspondence. The method jointly trains a BIQA model with auxiliary tasks of scene classification and distortion type identification, using a pre-trained CLIP model to compute joint probabilities over task label combinations described in natural language. This allows the model to benefit from additional training signals and improve generalization. Experiments demonstrate the method outperforms state-of-the-art BIQA models on multiple benchmark datasets in terms of prediction accuracy and robustness, while also better realigning quality annotations from different datasets into a common perceptual scale.

## Method Summary
The proposed method employs a multitask learning framework that jointly optimizes three tasks: blind image quality assessment, scene classification, and distortion type identification. A ViT-B/32 visual encoder and GPT-2 language encoder from CLIP are used to obtain visual and textual embeddings. Joint probabilities are computed using cosine similarities between these embeddings, with marginalization applied for each task. Dynamic loss weighting automatically balances task importance based on relative descending rates during training. The model is trained on 6 IQA datasets with additional labels for scene categories and distortion types, using AdamW optimizer with cosine annealing learning rate schedule.

## Key Results
- Outperforms state-of-the-art BIQA models on multiple benchmark datasets (LIVE, CSIQ, KADID-10k, BID, CLIVE, KonIQ-10k)
- Achieves higher SRCC and PLCC values compared to existing methods
- Better realigns quality annotations from different datasets into a common perceptual scale
- Demonstrates improved robustness to diverse image distortions

## Architecture Onboarding

- Component map: Visual encoder (ViT-B/32) → image embedding matrix → cosine similarity with textual templates → joint probability → marginalization → quality score → fidelity loss → backprop

- Critical path: Image → visual encoder → cosine similarity with textual templates → joint probability → marginalization → quality score → fidelity loss → backprop

- Design tradeoffs:
  - Using CLIP pre-trained models vs. training from scratch: Faster convergence and better semantic understanding vs. more parameters to fine-tune
  - Dynamic vs. static task weighting: Better adaptation to training dynamics vs. simpler implementation
  - Joint vs. separate textual templates: More efficient computation vs. potentially less expressive for each task

- Failure signatures:
  - Poor quality prediction: Check if visual encoder is learning distortion-sensitive features; verify joint probability computation
  - Unstable training: Monitor loss descending rates; check temperature parameters
  - Weak auxiliary task performance: Verify marginalization is correct; check if task weightings are appropriate

- First 3 experiments:
  1. Verify joint probability computation: Feed known image and check if joint probability correctly identifies quality, scene, and distortion labels
  2. Test dynamic weighting: Run training for few epochs and plot how task weights evolve over time
  3. Ablation on auxiliary tasks: Train with only BIQA vs. all three tasks and compare quality prediction performance on validation set

## Limitations

- Reliance on CLIP embeddings may be insufficient for subtle or complex quality-related concepts
- Dynamic loss weighting depends on stable loss descending rates which may not hold across different training regimes
- Effectiveness of auxiliary tasks assumes they provide complementary information, but potential redundancy could undermine this assumption

## Confidence

**High confidence**: Fundamental approach of using multitask learning with vision-language correspondence is sound and well-supported by existing literature

**Medium confidence**: Dynamic loss weighting mechanism lacks extensive validation across different scenarios; effectiveness of combining auxiliary tasks is plausible but not definitively proven

**Low confidence**: Assumption that CLIP embeddings contain sufficient quality-related information may not hold universally for specialized quality assessment scenarios
