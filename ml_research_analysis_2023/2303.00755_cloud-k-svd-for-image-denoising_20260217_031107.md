# Cloud K-SVD for Image Denoising

## Quick Facts

## Executive Summary
Cloud K-SVD introduces a distributed dictionary learning algorithm for image denoising that leverages Kubernetes and Docker containers to train dictionaries across multiple nodes without exchanging raw data. The method uses consensus averaging to synchronize dictionary atoms across nodes, enabling privacy-preserving denoising while maintaining accuracy comparable to centralized approaches. Experiments demonstrate successful recovery of benchmark grayscale images corrupted by Additive White Gaussian Noise (AWGN), achieving SSIM scores of 0.88, 0.91, and 0.95 for increasing noise levels.

## Method Summary
Cloud K-SVD implements a distributed version of the K-SVD algorithm where multiple worker nodes collaboratively learn a mutual dictionary from local image patches without sharing raw data. The algorithm uses Simultaneous Orthogonal Matching Pursuit (SOMP) for sparse coding and consensus averaging for dictionary updates. Implemented in Kubernetes using Docker containers, the system consists of preprocessor and postprocessor pods for data management, with worker pods handling local dictionary learning and consensus iterations. The mutual dictionary learned across nodes enables image recovery at any node in the network, achieving privacy-preserving denoising performance comparable to state-of-the-art methods like Pruned Non-Local Means.

## Key Results
- Achieved SSIM scores of 0.88, 0.91, and 0.95 for AWGN noise levels σ² = 0.01, 0.005, and 0.001 respectively
- Demonstrated successful recovery of benchmark grayscale images including Castle, Lenna, China, Flower, Chelsea, Camera, Astronaut, and Face
- Showed comparable performance to state-of-the-art methods while preserving privacy through distributed computation without raw data exchange

## Architecture Onboarding

- Component map: Preprocessor pod -> Worker pods (P) -> Postprocessor pod
- Critical path: Image → Patch extraction → Worker pod processing (sparse coding + consensus) → Patch aggregation → Denoised image
- Design tradeoffs:
  - Communication vs. Privacy: More frequent consensus iterations improve accuracy but increase communication overhead and potential privacy leakage
  - Patch size vs. Performance: Larger patches capture more context but increase computational complexity and memory requirements
  - Sparsity level (K) vs. Denoising: Higher K preserves more detail but may retain more noise
- Failure signatures:
  - Poor denoising quality: Indicates dictionary consensus failure or inadequate iterations
  - High communication latency: Suggests network bottlenecks or inefficient consensus implementation
  - Memory exhaustion: Occurs when patch size or number of atoms exceeds node capacity
- First 3 experiments:
  1. Test Cloud K-SVD on a single node with synthetic data to verify dictionary learning and denoising accuracy
  2. Deploy Cloud K-SVD on 4 nodes with clean image patches to validate consensus mechanism and mutual dictionary formation
  3. Evaluate Cloud K-SVD on noisy image patches with varying noise levels to assess denoising performance and parameter sensitivity
