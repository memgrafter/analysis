# Model Analysis & Evaluation for Ambiguous Question Answering

## Quick Facts
- arXiv ID: 2305.12483
- Source URL: https://arxiv.org/abs/2305.12483
- Reference count: 17
- Primary result: Retrieval-augmented models show improved ASQA performance with larger models and semantic retrieval, but automated metrics don't fully capture answer quality

## Executive Summary
This paper presents a comprehensive analysis of ambiguous question answering (ASQA) models that generate long-form answers covering multiple interpretations of queries. The authors evaluate retrieval-augmented systems using T5 and BART models across various training configurations and metrics. They find that model scaling improves performance, semantic matching in retrieval has positive impact, and while automated metrics align with human judgment, they don't fully capture answer quality. The study reveals that models are well-grounded in retrieved evidence but face limitations in comprehensiveness and potential knowledge base biases.

## Method Summary
The study uses a retrieval-augmented system combining generative models (T5 and BART) with retrieval methods (BM25 and DPR) to address ASQA. The approach involves intermediate fine-tuning on larger LFQA datasets (ELI5, MS MARCO NLGEN) followed by task-specific training on ASQA data. Models are trained with specific parameters (20 epochs, AdamW optimizer, learning rates of 10^-5 for T5 and 5*10^-6 for BART) and evaluated using both automated metrics (ROUGE-L, STR-EM, DISAMBIG-F1, DR) and human evaluation (COMP, FLUE, OVER). The evaluation framework includes open-book experiments with retrieved passages and closed-book comparisons.

## Key Results
- Larger models (BART-large) consistently outperform smaller models (BART-base) across automated metrics and human evaluation
- Semantic matching in retrieval improves answer quality compared to random passage retrieval
- Automated metrics show reasonable alignment with human judgment but fail to fully capture answer comprehensiveness
- Intermediate fine-tuning on larger LFQA collections yields only marginal improvements in ASQA performance

## Why This Works (Mechanism)
The retrieval-augmented approach works by first retrieving relevant passages from a knowledge base (Wikipedia) using semantic matching, then generating comprehensive answers that cover multiple interpretations. The system leverages both explicit evidence from retrieved passages and the model's knowledge to construct answers. Larger models benefit from increased capacity to handle multiple interpretations and generate more coherent long-form responses. The intermediate fine-tuning on related tasks provides some transfer learning benefits, though limited by task differences.

## Architecture Onboarding

Component Map: Question -> Retrieval (BM25/DPR) -> Passages -> Generative Model (T5/BART) -> Answer

Critical Path: The critical path involves retrieving relevant passages using semantic matching, then generating answers that synthesize multiple interpretations from the retrieved evidence.

Design Tradeoffs: The main tradeoff involves balancing retrieval quality against computational cost, with semantic retrieval providing better passages but at higher computational expense. Model size tradeoffs exist between performance gains and resource requirements.

Failure Signatures: Failure occurs when retrieval misses relevant passages (incomplete answers), models hallucinate information not in evidence (hallucination), or generated answers fail to cover all interpretations (incompleteness).
