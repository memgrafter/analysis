# Diagnosing and Rectifying Vision Models using Language

## Quick Facts
- arXiv ID: 2302.04269
- Source URL: https://arxiv.org/abs/2302.04269
- Authors: 
- Reference count: 40
- One-line primary result: Language can be used to probe vision models through cross-modal transferability in shared embedding spaces, enabling diagnosis and rectification without visual data.

## Executive Summary
This paper introduces DrML, a method that leverages language to diagnose and rectify vision models by exploiting the shared embedding space learned through multi-modal contrastive learning. The key insight is that embeddings from one modality (text) can serve as proxies for another modality (images) due to geometric properties of the modality gap. This cross-modal transferability enables DrML to discover error slices, identify influential attributes, and rectify model misbehaviors without requiring any visual data. The method is validated across three datasets representing common failure modes, demonstrating its effectiveness in improving model performance on identified error slices through language-based fine-tuning.

## Method Summary
DrML uses text embeddings as proxies for image embeddings in shared multi-modal embedding spaces learned through contrastive learning (primarily CLIP). The method generates language prompts to discover error slices and influential attributes, then fine-tunes vision models using text embeddings to rectify identified misbehaviors. The core approach relies on the theoretical property that classifiers trained on one modality transfer to another due to the modality gap being orthogonal to embedding spans. DrML consists of three main components: cross-modal transferability verification, error slice discovery through generated text prompts, and model rectification via fine-tuning on text embeddings from error slices.

## Key Results
- Classifiers trained on one modality (text or image) can be equivalently applied to embeddings from another modality, enabling cross-modal diagnosis
- DrML successfully discovers high-error data slices and influential attributes without requiring any visual data
- Language-based fine-tuning improves model performance on error slices identified through text-based analysis
- Strong correlation between text and image slice performance validates the cross-modal transferability assumption

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Text embeddings can serve as proxies for image embeddings in multi-modal contrastive spaces
- Mechanism: Classifiers trained on one modality transfer to another due to geometric properties of the modality gap
- Core assumption: The modality gap is orthogonal to the span of embeddings and approximates a constant vector
- Evidence anchors:
  - [abstract] "classifiers trained on embeddings from one modality can be equivalently applied to embeddings from another modality"
  - [section] "modality gap is orthogonal to the span of image embeddings and text embeddings, and image embeddings and text embeddings have zero mean in the subspace orthogonal to the modality gap"
  - [corpus] Weak - only 5 papers found, average FMR 0.511 suggests moderate relevance but limited coverage
- Break condition: If the modality gap loses orthogonality or becomes non-constant, transferability fails

### Mechanism 2
- Claim: Error slices can be discovered using language without visual data
- Mechanism: Generated text prompts correlate with image slice performance due to cross-modal transferability
- Core assumption: Language prompts generated from attribute combinations maintain semantic alignment with image concepts
- Evidence anchors:
  - [abstract] "DrML can discover high-error data slices, identify influential attributes and further rectify undesirable model behaviors, without requiring any visual data"
  - [section] "Strong correlation between the performances on text and image slices allows us to confidently run image slice discovery algorithm using text inputs"
  - [corpus] Weak - no direct evidence of attribute-to-slice correlation mechanisms
- Break condition: If text embeddings lose semantic alignment with image concepts, correlation breaks

### Mechanism 3
- Claim: Model behaviors can be rectified using language inputs without collecting visual data
- Mechanism: Fine-tuning on text embeddings generated from error slices transfers to improve image-based performance
- Core assumption: Text-to-image transferability extends to rectification as well as diagnosis
- Evidence anchors:
  - [abstract] "DrML can further use language to rectify failure modes of the classifier"
  - [section] "We continue training the model using the same hyperparameters as if the model is trained on corresponding images"
  - [corpus] Weak - only mentions related work on debiasing but no direct evidence for language-based rectification
- Break condition: If fine-tuning dynamics differ significantly between modalities, rectification fails

## Architecture Onboarding

- Component map: CLIP (ViT-B/32) encoders → 512-dim shared space → classifier (linear/MLP) → predictions
- Critical path: Text prompt generation → text embedding extraction → classifier inference → error/slice identification
- Design tradeoffs: Language-based diagnosis trades potential precision for massive scalability and annotation-free operation
- Failure signatures: Poor correlation between text and image performance indicates modality gap violation or semantic misalignment

  1. Verify cross-modal transferability on a simple binary classification task using CLIP embeddings
  2. Test correlation strength between generated text prompts and actual image slice performance
  3. Validate rectification effectiveness by comparing pre/post fine-tuning performance on error slices

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the modality gap phenomenon observed in CLIP extend to other multi-modal contrastive learning models beyond those tested in the paper?
- Basis in paper: Explicit - The paper states "we verify these conditions and then show empirically that closing the modality gap can improve transferability" across various models like CLIP, VideoCLIP, ConVIRT, and CLASP.
- Why unresolved: The paper only tests a limited set of models. It's unclear if the modality gap and its impact on cross-modal transferability is a universal phenomenon across all multi-modal contrastive learning approaches.
- What evidence would resolve it: Testing the modality gap geometry and cross-modal transferability on a wider range of multi-modal contrastive learning models, including those using different architectures, pre-training objectives, and datasets.

### Open Question 2
- Question: How does the choice of prompt engineering techniques affect the performance of DrML in discovering error slices and identifying influential attributes?
- Basis in paper: Explicit - The paper mentions using prompt engineering to generate better text inputs and prompt ensemble to generate more diverse inputs.
- Why unresolved: The paper doesn't explore the impact of different prompt engineering strategies on DrML's effectiveness. It's unclear which techniques are most effective for different tasks and datasets.
- What evidence would resolve it: Conducting experiments comparing the performance of DrML using different prompt engineering techniques, such as varying the level of detail in prompts, using different prompt templates, and incorporating domain-specific knowledge.

### Open Question 3
- Question: Can DrML be extended to diagnose and rectify model failures beyond the three common types explored in the paper (spurious correlation, underrepresented data, and unseen data)?
- Basis in paper: Inferred - The paper demonstrates DrML's effectiveness on three specific failure modes, but doesn't explore its applicability to other types of failures.
- Why unresolved: The paper focuses on a limited set of failure modes. It's unclear if DrML can be generalized to diagnose and rectify other types of model failures, such as those caused by adversarial attacks, distribution shifts, or model bias.
- What evidence would resolve it: Applying DrML to diagnose and rectify model failures in different domains and datasets, including those with different types of data, labels, and failure modes.

## Limitations

- Cross-modal transferability assumptions rely heavily on CLIP's specific architecture and may not generalize to all multi-modal models
- Method's effectiveness depends on generating semantically meaningful text prompts that accurately represent image concepts
- Shapley value approach assumes independence between attributes, which may not hold in real-world scenarios

## Confidence

**High confidence**: The cross-modal transferability mechanism (Mechanism 1) is well-supported by both theoretical proof and empirical evidence across multiple datasets. The geometric conditions are clearly defined and validated.

**Medium confidence**: Error slice discovery using language (Mechanism 2) shows strong correlations but relies on the quality of generated prompts and assumes the discovered slices are meaningful rather than artifacts of the generation process.

**Low confidence**: The rectification claims (Mechanism 3) are supported by improvement metrics but lack ablation studies to isolate the effect of language-based fine-tuning from other factors like continued training dynamics.

## Next Checks

1. Evaluate DrML on a different multi-modal model (e.g., ALIGN or Flamingo) to verify transferability assumptions aren't CLIP-specific.

2. Systematically vary prompt generation parameters to quantify their impact on error slice discovery accuracy and identify failure modes.

3. Test the attribution method's robustness by introducing correlated attributes and measuring how this affects Shapley value calculations and subsequent rectification.
