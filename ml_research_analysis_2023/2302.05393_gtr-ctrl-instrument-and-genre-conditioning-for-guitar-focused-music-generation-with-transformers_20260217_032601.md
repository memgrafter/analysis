# GTR-CTRL: Instrument and Genre Conditioning for Guitar-Focused Music Generation with Transformers

## Quick Facts
- arXiv ID: 2302.05393
- Source URL: https://arxiv.org/abs/2302.05393
- Reference count: 35
- GTR-CTRL achieves PIP scores above 70% across all instrument combinations using control tokens

## Executive Summary
GTR-CTRL introduces a set of conditioning techniques for guitar-focused symbolic music generation using Transformers. The system leverages the DadaGP dataset of over 26,000 guitar tablature songs and employs special control tokens to condition on instrumentation and musical genre. The approach enables fine-grained control over generated music, allowing users to specify which instruments should be present and what genre the music should follow. The model architecture builds upon Transformer-XL and demonstrates improved control compared to unconditioned models.

## Method Summary
The GTR-CTRL system uses a Transformer-XL architecture trained on the DadaGP dataset of guitar tablature. The key innovation is the introduction of special control tokens that allow conditioning on both instrumentation and genre. For instrument conditioning (inst-CTRL), the model uses prompt-based tokens representing different instrument combinations, achieving PIP scores above 70% for all combinations. For genre conditioning (genre-CTRL), genre-specific control tokens enable the model to generate music in Metal, Punk, Rock, Classical, and Folk styles. The training process involves tokenizing tablature into a sequence format compatible with Transformers, with the control tokens integrated into the input sequence to guide generation.

## Key Results
- Inst-CTRL achieves PIP scores above 70% for all instrument combinations, with full-prompt configuration reaching 87.54% on average
- Genre-CTRL full-prompt achieves classification scores of 0.668, 0.813, 0.640, 0.675, and 0.177 for Metal, Punk, Classical, Rock, and Folk respectively
- GTR-CTRL outperforms unconditional models for Punk, Classical, and Folk genres while showing competitive performance for Metal and Rock

## Why This Works (Mechanism)
The conditioning mechanism works by embedding control tokens directly into the input sequence, allowing the Transformer's attention mechanism to learn associations between these tokens and their corresponding musical characteristics. The prompt-based approach provides explicit guidance during both training and generation, creating a direct pathway for the model to condition output on specific instrumentation and genre attributes. This token-level conditioning is particularly effective for symbolic music generation because it operates at the same granular level as the musical data itself.
