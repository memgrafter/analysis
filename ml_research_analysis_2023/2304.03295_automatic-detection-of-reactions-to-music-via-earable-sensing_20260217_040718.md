# Automatic Detection of Music Reactions via Earable Sensing

## Quick Facts
- arXiv ID: 2304.03295
- Source URL: https://arxiv.org/abs/2304.03295
- Reference count: 40
- Primary result: Macro F1 scores of 0.89 for vocal reactions and 0.81 for motion reactions using earable sensing

## Executive Summary
GrooveMeter is a system that automatically detects users' reactions to music by analyzing data from smart earbuds. It uses inertial measurement units (IMU) and microphones to identify vocal reactions (singing, humming, whistling) and motion reactions (head movement). The system employs a multi-step pipeline with early-stage filtering, YAMNet-based sound event classification, music information-leveraged correction, and post-processing with smoothing. Evaluation on a dataset of 926 minutes from 30 participants demonstrates high accuracy in detecting music reactions while being robust against background noise and motion artifacts.

## Method Summary
The GrooveMeter system processes audio and motion data from smart earbuds through a sophisticated pipeline. It begins with early-stage filtering to reduce computational load, followed by sound event classification using the YAMNet model. The system then applies music information-leveraged correction to improve accuracy and concludes with post-processing that includes smoothing to reduce false positives. The approach is designed to be energy-efficient by filtering out irrelevant data early in the processing chain.

## Key Results
- Achieved macro F1 score of 0.89 for vocal reactions detection
- Achieved macro F1 score of 0.81 for motion reactions detection
- Demonstrated robustness against background noise and motion artifacts
- Showed significant energy savings through early-stage filtering

## Why This Works (Mechanism)
The system leverages the rich multimodal data available from smart earbuds, combining audio signals with motion data to create a more comprehensive picture of user reactions. By using YAMNet for sound classification and incorporating music information for correction, the system can distinguish between intentional vocal reactions and background noise. The early filtering stage reduces computational load, while post-processing with smoothing helps eliminate false positives, creating a robust and efficient detection system.

Component Map: Microphone/Audio Data -> Early Filtering -> YAMNet Classification -> Music Information Correction -> Post-processing Smoothing -> Output

Critical Path: The core detection pipeline (audio input to final output) must operate in real-time with minimal latency to be practical for user applications.

Design Tradeoffs: The system prioritizes accuracy and robustness over computational efficiency in the core classification stage, but compensates with early filtering to reduce overall energy consumption.

Failure Signatures: Poor performance may occur with unfamiliar music genres, extreme background noise levels, or when multiple users are singing simultaneously in the same environment.
