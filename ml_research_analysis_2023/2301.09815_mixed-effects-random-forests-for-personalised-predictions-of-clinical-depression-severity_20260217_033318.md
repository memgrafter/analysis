# Mixed Effects Random Forests for Personalised Predictions of Clinical Depression Severity

## Quick Facts
- arXiv ID: 2301.09815
- Source URL: https://arxiv.org/abs/2301.09815
- Reference count: 28
- Primary result: Mixed effects random forests significantly improve depression severity prediction accuracy compared to baselines when labeled patient data is available.

## Executive Summary
This work introduces mixed effects random forests for personalized prediction of depression severity using multimodal physiological and digital activity data. The model combines standard random forests with patient-specific random intercepts, enabling personalized predictions that outperform both standard random forests and simple baseline methods. Results show significant accuracy improvements (0.199-0.276 MAE reduction) for individual patients when training data includes labeled examples from those patients, though generalization to new patients remains challenging.

## Method Summary
The method employs a mixed effects random forest that combines fixed effects (from a standard random forest) with random intercepts for each patient. The model is trained using an expectation maximization (EM) procedure to optimize parameters for both shared and patient-specific effects. The dataset contains 2,820 features from physiological sensors, smartphone usage, and weather data, with 149 observations from 31 patients over 8 weeks. Models are evaluated across three scenarios: Random Split (70:30 train/test), Time Split (first 3 observations train, rest test), and User Split (leave-one-patient-out).

## Key Results
- Mixed effects random forests outperform standard random forests and personal average baselines in Random and Time Split scenarios (p<0.05)
- Average MAE improvement of 0.199-0.276 compared to personal average baseline
- No significant improvement in User Split scenario (generalization to new patients)
- Random forest fixed effects contribute additional lift beyond random intercepts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The mixed effects random forest improves accuracy by learning both shared (fixed) effects and individual-specific (random) effects for each patient.
- Mechanism: The model combines a standard random forest for fixed effects with cluster-specific random intercepts. This allows predictions to be adjusted based on each patient's average observed scores, rather than centering predictions around a global average.
- Core assumption: Patients have heterogeneous baseline depression levels that can be captured by random intercepts.
- Evidence anchors:
  - [abstract]: "We suggest that this improved performance results from the ability of the mixed effects random forest to personalise model parameters to individuals in the dataset."
  - [section]: "It is probable that this additional lift is due to the random forest fixed effect terms, f(Xi), that – when estimated using the EM procedure – learn relations between the multimodal input features and the HDRS 17 scores (net of patient specific random effect values) that can be shared across patients."
  - [corpus]: Found related work on using random effects machine learning algorithms to identify vulnerability to depression, suggesting this approach is recognized in the field.
- Break condition: The improvement only applies when labeled patient data is available in the training set; it does not generalize to new patients without prior data.

### Mechanism 2
- Claim: The random forest component maintains performance even when the number of features far exceeds the number of observations.
- Mechanism: Random forests are ensemble methods that average predictions from multiple decision trees, reducing overfitting and handling high-dimensional feature spaces effectively.
- Core assumption: The dataset contains many more features than observations (p ≫ n), which can cause standard regression methods to fail.
- Evidence anchors:
  - [section]: "Given the random forest's ability to maintain performance when there are many more features than observations (i.e., in the p ≫ n context)."
  - [section]: "The dataset contains 2,820 input features and its rows are filtered to only include data captured on days with clinical scores, resulting in 149 observations in total."
  - [corpus]: Weak evidence; no direct corpus support for random forests handling p ≫ n, though related work exists on random forests for binary geospatial data.
- Break condition: If the feature space is not high-dimensional relative to observations, the advantage of using random forests diminishes.

### Mechanism 3
- Claim: The EM training procedure enables effective parameter estimation for both fixed and random effects.
- Mechanism: The EM algorithm iteratively updates parameters by alternating between expectation (E-step) and maximization (M-step) until convergence, optimizing a generalized log likelihood objective.
- Core assumption: A closed-form solution for parameter estimation does not exist, requiring iterative optimization.
- Evidence anchors:
  - [section]: "The model parameters are fit using an expectation maximisation (EM) procedure with convergence monitored by a generalised log likelihood objective function."
  - [supplementary]: Detailed EM algorithm description with E-step and M-step equations.
  - [corpus]: Weak evidence; no direct corpus support for the EM procedure in this context, though mixed effects random forest theory exists.
- Break condition: If the EM procedure fails to converge or gets stuck in local optima, the model parameters may not be well-estimated.

## Limitations

- The improvement from mixed effects random forests only applies when training data includes labeled patient data (Random/Time splits); generalization to new patients (User split) remains unsolved.
- The specific feature engineering details for each modality are not fully specified, which may affect reproducibility.
- The hyperparameter tuning ranges for the baseline random forest are not reported, making it difficult to assess optimal configuration.

## Confidence

- **High confidence**: The mechanism by which mixed effects random forests improve accuracy through personalization (Mechanism 1) is well-supported by experimental results showing consistent MAE reductions in Random/Time split scenarios.
- **Medium confidence**: The claim about random forests handling high-dimensional data (Mechanism 2) is plausible but relies on theoretical arguments rather than extensive empirical validation in this specific context.
- **Low confidence**: The effectiveness of the EM training procedure (Mechanism 3) is assumed but not empirically validated; no convergence diagnostics or comparison to alternative optimization methods are provided.
