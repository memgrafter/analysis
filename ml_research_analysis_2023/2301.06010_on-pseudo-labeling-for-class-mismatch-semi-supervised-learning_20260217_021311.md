# On Pseudo-Labeling for Class-Mismatch Semi-Supervised Learning

## Quick Facts
- arXiv ID: 2301.06010
- Source URL: https://arxiv.org/abs/2301.06010
- Reference count: 37
- Key outcome: Υ-Model with RPL and SEC improves PL performance in class-mismatched SSL, achieving up to ~3% accuracy gains on CIFAR10 and ~7% on ImageNet100.

## Executive Summary
This paper analyzes Pseudo-Labeling (PL) in class-mismatched semi-supervised learning, where unlabeled Out-Of-Distribution (OOD) data from unseen classes can severely degrade PL performance. The core issue identified is imbalanced pseudo-labels on OOD data, which worsens as training proceeds. The authors propose a two-branched Υ-Model: (1) Re-balanced Pseudo-Labeling (RPL) truncates high-confidence pseudo-labels to balance classes and filter OOD data, and (2) Semantic Exploration Clustering (SEC) uses balanced clustering on low-confidence OOD data to assign meaningful extra-class labels. Experiments on CIFAR10, SVHN, CIFAR100, Tiny ImageNet, and ImageNet100 show Υ-Model consistently outperforms supervised baseline and state-of-the-art methods across all class mismatch ratios (0–100%), with relative improvements up to ~3% accuracy on CIFAR10 and ~7% on ImageNet100. The approach stabilizes PL performance and leverages OOD data effectively without requiring OOD class knowledge.

## Method Summary
The paper addresses class-mismatched semi-supervised learning by proposing the Υ-Model, which combines Re-balanced Pseudo-Labeling (RPL) and Semantic Exploration Clustering (SEC). RPL truncates high-confidence pseudo-labels to balance classes and filter OOD data, while SEC applies balanced clustering to low-confidence OOD data to assign extra-class labels. The method is evaluated on multiple datasets with varying class mismatch ratios, showing consistent improvements over baseline PL and other state-of-the-art methods.

## Key Results
- Υ-Model achieves up to ~3% accuracy improvement on CIFAR10 and ~7% on ImageNet100 compared to baseline PL.
- RPL and SEC together stabilize PL performance across all class mismatch ratios (0–100%).
- The method outperforms supervised baselines and other state-of-the-art approaches in class-mismatched settings.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Pseudo-labeling creates imbalanced pseudo-labels on OOD data, which damages performance.
- **Mechanism:** When the model predicts on OOD data, the confidence scores are spread across ID classes due to lack of direct supervision, leading to imbalance. This imbalance amplifies over iterations as incorrect pseudo-labels reinforce each other.
- **Core assumption:** OOD data do not follow the same distribution as ID data, so their predictions on ID classes are inherently unstable.
- **Evidence anchors:**
  - [abstract] "the major problem of PL is imbalanced pseudo-labels on OOD data, which worsens as training proceeds."
  - [section 3.1] "pseudo-labels on OOD data tend to be imbalanced while on ID data, they remain balanced."
  - [corpus] FMR scores ~0.53 show moderate semantic overlap but not sufficient for balanced pseudo-labels.
- **Break condition:** If OOD data distribution closely mimics ID distribution, imbalance reduces or disappears.

### Mechanism 2
- **Claim:** Filtering or reweighting OOD data by labeling them as extra classes improves classification on ID data.
- **Mechanism:** By assigning OOD data to extra classes, the model learns to distinguish between ID and OOD, reducing confusion. Clustering OOD data into semantic groups further enhances this separation.
- **Core assumption:** The semantic structure within OOD data contains useful information that can be leveraged for better ID classification.
- **Evidence anchors:**
  - [abstract] "OOD data can help classify In-Distribution (ID) data given their OOD ground truth labels."
  - [section 3.2] "labeling OOD data as a class different from ID data... performance can be further improved when pseudo-labels partition unlabeled OOD data into their semantic clusters."
  - [corpus] Related works on open-set SSL confirm benefits of treating OOD separately.
- **Break condition:** If OOD data are too few or too diverse, clustering may not capture meaningful semantics.

### Mechanism 3
- **Claim:** RPL (Re-balanced Pseudo-Labeling) and SEC (Semantic Exploration Clustering) together stabilize performance across all class-mismatch ratios.
- **Mechanism:** RPL truncates pseudo-labels to balance classes and filter out OOD data. SEC mines semantics of low-confidence OOD data via clustering, assigning them to extra classes.
- **Core assumption:** High-confidence data likely contain ID samples, while low-confidence data are mostly OOD and benefit from clustering.
- **Evidence anchors:**
  - [abstract] "RPL re-balances pseudo-labels of high-confidence data, which simultaneously filters out OOD data and addresses the imbalance problem."
  - [section 4.1] "selecting only top-N confident samples for each ID class... will keep ID data and omit many OOD data."
  - [section 4.2] "clustering method in Asano et al. (2020); Caron et al. (2020) to create pseudo-labels for these OOD data."
- **Break condition:** If confidence thresholds are poorly set, RPL may discard too many ID samples or keep too many OOD samples.

## Architecture Onboarding

- **Component map:**
  - Backbone (Wide-ResNet-28-2)
  - Confidence scoring module (ID confidence)
  - RPL module (high-confidence branch)
  - SEC module (low-confidence branch)
  - Sinkhorn-Knopp OT solver for balanced clustering
- **Critical path:**
  1. Train initial model on labeled ID data.
  2. Generate pseudo-labels for unlabeled data.
  3. Split data into high/low confidence sets.
  4. Apply RPL to high-confidence set.
  5. Apply SEC to low-confidence set.
  6. Combine pseudo-labeled sets and retrain.
- **Design tradeoffs:**
  - RPL vs. reweighting: RPL is simpler and avoids instability from zero pseudo-labels in some classes.
  - K (extra classes): Larger K may capture more semantics but increases clustering complexity.
  - Confidence thresholds: Must balance filtering OOD vs. retaining ID data.
- **Failure signatures:**
  - Performance degrades if RPL threshold too high (loses ID data) or too low (keeps OOD data).
  - SEC fails if OOD data too few or too imbalanced for meaningful clustering.
  - Model overfits if clustering iterations too many or K too large.
- **First 3 experiments:**
  1. Run baseline PL vs. RPL-only on CIFAR10(6/4) at 100% mismatch; verify RPL improves over PL.
  2. Run SEC-only vs. SEC+RPL on CIFAR10(6/4) at 100% mismatch; confirm SEC+RPL outperforms SEC-only.
  3. Sweep K from 1 to 10 on CIFAR10(6/4) at 100% mismatch; identify optimal K balancing accuracy and runtime.

## Open Questions the Paper Calls Out
- **Open Question 1:** How do different forms of semi-supervised learning methods like consistency-based methods suffer from the same class-mismatch problems as Pseudo-Labeling? The paper mentions in the conclusion that they will explore whether other forms of semi-supervised learning methods like consistency-based methods suffer from the same problems, suggesting this is currently unknown.
- **Open Question 2:** What is the optimal number of extra classes (K) for the SEC component across different datasets and class mismatch ratios? The paper shows that performance improves with K and reaches best performance when K is roughly the actual number of OOD classes, but notes that the model is not sensitive to K selection. However, they don't provide a systematic analysis of optimal K values.
- **Open Question 3:** How would the Υ-Model perform on real-world datasets where OOD data are naturally imbalanced across classes, rather than artificially balanced as in the experiments? While the paper demonstrates effectiveness on one imbalanced dataset, they haven't tested on diverse real-world datasets with varying degrees of class imbalance in the OOD data.

## Limitations
- The paper's claims hinge on the assumption that OOD data inherently produce imbalanced pseudo-labels, but this is not empirically proven across diverse datasets.
- The effectiveness of RPL and SEC depends heavily on confidence thresholds and clustering parameters, which are not fully specified.
- The method's scalability to larger, more complex datasets (e.g., ImageNet-1K) remains unclear.

## Confidence
- **High confidence**: RPL and SEC improve PL performance in class-mismatched settings, as evidenced by consistent accuracy gains across experiments.
- **Medium confidence**: The mechanism of imbalanced pseudo-labels on OOD data is plausible but not rigorously validated. The assumption that OOD data lack semantic overlap with ID data may not hold in all cases.
- **Low confidence**: The clustering-based approach for OOD data (SEC) may not generalize to datasets with highly diverse or noisy OOD samples, as clustering quality is dataset-dependent.

## Next Checks
1. Validate pseudo-label imbalance: Analyze pseudo-label distributions on ID vs. OOD data across multiple datasets to confirm the imbalance claim.
2. Test scalability: Evaluate Υ-Model on larger datasets (e.g., ImageNet-1K) to assess its scalability and robustness to more complex class distributions.
3. Stress test clustering: Experiment with varying OOD data diversity and quantity to determine SEC's failure points and sensitivity to clustering parameters.
