# Achieving a Better Stability-Plasticity Trade-off via Auxiliary Networks in Continual Learning

## Quick Facts
- arXiv ID: 2303.09483
- Source URL: https://arxiv.org/abs/2303.09483
- Authors: 
- Reference count: 34
- One-line primary result: ANCL achieves 1-3% improvements over strong continual learning baselines by balancing stability and plasticity through auxiliary network regularization.

## Executive Summary
This paper introduces Auxiliary Network Continual Learning (ANCL), a method that addresses catastrophic forgetting in neural networks by introducing an auxiliary network trained solely on current tasks. The approach provides additional plasticity while the main network maintains stability, achieving a better balance between learning new tasks and retaining old knowledge. The method is evaluated on CIFAR-100 and Tiny ImageNet datasets, showing consistent improvements of 1-3% over strong baselines in both task and class incremental learning scenarios. Through extensive analyses including weight distance, centered kernel alignment, and mean accuracy landscape, the authors demonstrate that ANCL achieves better stability-plasticity trade-off by interpolating between old and auxiliary network parameters, with the balance controlled by regularization hyperparameters.

## Method Summary
ANCL creates a dual-network system where an auxiliary network is trained only on current task data while the main network is regularized by both the old network and the auxiliary network. The main network's loss function combines task-specific loss with regularization terms that interpolate between stability (maintaining old knowledge via old network) and plasticity (incorporating new learning via auxiliary network). The method is evaluated on CIFAR-100 and Tiny ImageNet datasets using ResNet32 architectures, with performance measured by averaged accuracy for task incremental learning and averaged incremental accuracy for class incremental learning. The approach requires hyperparameter tuning of λ (old network regularization strength) and λa (auxiliary network regularization strength) through grid search.

## Key Results
- ANCL achieves 1-3% consistent improvements over strong continual learning baselines on both CIFAR-100 and Tiny ImageNet datasets
- Weight distance analysis shows ANCL solutions lie between old network parameters and auxiliary network parameters, confirming interpolation behavior
- Centered kernel alignment analysis reveals that λa controls the interpolation between continual learning weights and auxiliary weights, with optimal trade-off achieved at specific ratios
- ANCL demonstrates better stability-plasticity balance compared to standard regularization methods across both task and class incremental learning scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The auxiliary network trained solely on current tasks provides additional plasticity while the main network maintains stability through regularization
- Mechanism: ANCL creates a dual-network system where the auxiliary network is optimized only on current task data (allowing it to freely adapt and learn new patterns) while the main network is regularized by both the old network and the auxiliary network. This regularization interpolates between stability (maintaining old knowledge via old network) and plasticity (incorporating new learning via auxiliary network), with the balance controlled by hyperparameters λ and λa.
- Core assumption: The regularization terms Ω(θ; θ1:t-1, λ) and Ω(θ; θt, λa) can effectively balance stability and plasticity when properly weighted
- Evidence anchors:
  - [abstract] "ANCL outperforms existing CL baselines on both CIFAR-100 and Tiny ImageNet... Through extensive analyses on ANCL solutions, we identify some essential principles beneath the stability-plasticity trade-off."
  - [section 3.1] "ANCL applies the auxiliary network trained on the current task to the continually learned previous network to achieve a balance between stability and plasticity."
- Break condition: If the regularization hyperparameters are poorly tuned, the model may become too biased toward either stability (underfitting new tasks) or plasticity (catastrophic forgetting of old tasks)

### Mechanism 2
- Claim: ANCL achieves better weight interpolation between old and auxiliary networks compared to standard continual learning methods
- Mechanism: Through the Weight Distance analysis, ANCL solutions show that the main network parameters lie between the old network parameters and the auxiliary network parameters. As λa increases, the main network moves closer to the auxiliary network (more plasticity), while decreasing λa keeps it closer to the old network (more stability). This creates a continuum of solutions that can be tuned for optimal trade-off.
- Core assumption: The optimal continual learning solution lies at an interpolation point between old and auxiliary network parameters
- Evidence anchors:
  - [section 5.1] "WD analysis is shown in the top row of Fig. 2... For A-EWC and A-MAS, W Daux decreases and W Dold increases as λa becomes larger. This result implies a direct interpolation between the old and auxiliary networks."
  - [section 5.3] "In A-EWC and A-MAS, it is clearly observed that λa adjusts the interpolation between the CL weights θCL and the auxiliary weights θaux2."
- Break condition: If the interpolation assumption is incorrect (i.e., optimal solution lies outside the convex hull of old and auxiliary parameters), this mechanism would fail

### Mechanism 3
- Claim: ANCL provides more flexible knowledge transfer than standard regularization methods by utilizing both regularization and distillation approaches
- Mechanism: ANCL can be applied to various CL methods (EWC, MAS, LwF, LFL, etc.) and enhances their performance by adding the auxiliary network regularization term. For regularization-based methods (EWC, MAS), the auxiliary network provides an additional regularization source, while for distillation-based methods (LwF, LFL), it provides an additional knowledge source for distillation. This flexibility allows ANCL to adapt to different types of CL methods.
- Core assumption: The auxiliary network can serve as a valid regularization or knowledge source for both regularization and distillation-based CL methods
- Evidence anchors:
  - [section 3.1] "ANCL applies the auxiliary network trained on the current task to the continually learned previous network to achieve a balance between stability and plasticity."
  - [section 5.2] "For A-LwF and A-LFL, W Daux becomes relatively smaller than W Dold with increasing λa but W Dold and W Daux are both growing. Unlike EWC and MAS which directly regularize the weights itself, LwF and LFL have more flexibility to remember the previous knowledge by utilizing loss terms based on activations or logits."
- Break condition: If the auxiliary network's representation quality is poor or incompatible with the main network's architecture, the regularization/distillation terms may not provide meaningful gradients

## Architecture Onboarding

- Component map: Main network -> Old network (frozen) -> Auxiliary network (trained on current task, then frozen) -> Main network (regularized by both old and auxiliary networks)

- Critical path:
  1. Initialize main network with random weights
  2. For task 1: Train main network, freeze as old network
  3. For task t>1: Initialize auxiliary network from old network, train auxiliary on task t, freeze auxiliary
  4. Train main network using combined loss with regularization from both old and auxiliary networks
  5. Freeze main network as new old network for next task

- Design tradeoffs:
  - Computational overhead: ANCL requires training an additional auxiliary network for each task
  - Hyperparameter complexity: Requires tuning both λ (old network regularization strength) and λa (auxiliary network regularization strength)
  - Memory usage: Stores parameters for both old and auxiliary networks
  - Flexibility vs. stability: Higher λa increases plasticity but may reduce stability

- Failure signatures:
  - If λa is too small: Performance approaches standard CL methods, missing the benefits of auxiliary network
  - If λa is too large: May cause instability or convergence issues due to conflicting gradients from old and auxiliary networks
  - If task identity is not properly handled: May cause confusion between task-specific heads in multi-head settings
  - If memory buffer is insufficient: Class incremental learning may suffer from bias toward recent tasks

- First 3 experiments:
  1. Baseline comparison: Implement ANCL with EWC on CIFAR-100/10 and compare against standard EWC with varying λ values
  2. Hyperparameter sensitivity: For a fixed method (e.g., ANCL-EWC), sweep λa while keeping λ fixed to find optimal trade-off
  3. Weight interpolation analysis: Visualize weight distances between main network, old network, and auxiliary network at different training stages to confirm interpolation behavior

## Open Questions the Paper Calls Out

- Question: What is the optimal balance between the regularization strength λ (for stability) and λa (for plasticity) in ANCL across different tasks and datasets?
- Basis in paper: [explicit] The authors note that ANCL achieves better stability-plasticity trade-off when the balance is controlled by the ratio between λ and λa, and that the best trade-off is achieved at a specific ratio where CKA multi and mean accuracy are highest.
- Why unresolved: The paper conducts extensive grid searches for λ and λa, but does not provide a universal rule or method to determine the optimal ratio without extensive hyperparameter tuning.
- What evidence would resolve it: A theoretical framework or empirical study that can predict the optimal λ/λa ratio based on task characteristics, dataset properties, or early training signals.

## Limitations

- Parameter sensitivity: ANCL performance heavily depends on hyperparameter tuning of λ and λa, with no principled guidance provided for selecting optimal values across different tasks or datasets.
- Computational overhead: ANCL doubles the training time and memory requirements by introducing an auxiliary network for each task, which is not explicitly discussed in the paper.
- Limited generalization analysis: While results are shown on CIFAR-100 and Tiny ImageNet, the paper lacks extensive testing across diverse domains, architectures, and task distributions.

## Confidence

- High Confidence: The core mechanism of using an auxiliary network to provide plasticity while regularizing the main network is sound and well-supported by the weight distance and CKMA analyses.
- Medium Confidence: The 1-3% improvement claims are supported by experimental results, but the practical significance and generalizability remain uncertain.
- Low Confidence: The interpolation hypothesis (that optimal solutions lie between old and auxiliary network parameters) is supported by empirical observations but lacks theoretical justification.
