# Integrating Edge-AI in Structural Health Monitoring domain

## Quick Facts
- arXiv ID: 2304.03718
- Source URL: https://arxiv.org/abs/2304.03718
- Reference count: 16
- Primary result: 92.4% accuracy for crack detection with 20ms inference time on edge device

## Executive Summary
This study presents an edge-AI framework for real-time structural health monitoring, specifically targeting crack detection in bridges. The framework utilizes the Kneron KL520 edge-AI chip to perform AI inference directly on devices, eliminating cloud dependencies and enabling immediate decision-making. An optimized CNN model was developed and trained on a crack dataset, achieving 92.4% accuracy on a test set of 355 images. The inference time was dramatically reduced from 3 seconds to 20 milliseconds per image through quantization and model optimization techniques.

## Method Summary
The method involves developing a CNN-based model optimized for the Kneron KL520 edge-AI chip. The model was trained on a crack dataset with 40,000 images (20,000 positive, 20,000 negative), achieving 99.54% training and 99.52% validation accuracy. The trained model was then quantized to 8-bit format and converted to NEF (Neural Network Exchange Format) for deployment on the KL520 chip. The framework includes image preprocessing, CNN inference, and post-processing components to classify cracks in real-time.

## Key Results
- 92.4% accuracy achieved on 355-image test set for crack detection
- Inference time reduced from 3 seconds to 20 milliseconds per image
- Real-time processing enabled through edge-AI deployment on Kneron KL520 chip

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Quantization and model optimization significantly reduce inference latency for edge-AI SHM.
- Mechanism: Converting floating-point neural network weights to 8-bit integers reduces memory usage and computational complexity, enabling faster inference on resource-constrained edge devices like the Kneron KL520.
- Core assumption: The quantized model maintains sufficient accuracy for real-time crack detection despite reduced precision.
- Evidence anchors:
  - [section] "The general model was transformed into an 8-bit model... The average inference time per image on the device was 20 milliseconds"
  - [abstract] "The inference time was reduced from 3 seconds to 20 milliseconds per image through quantization and model optimization techniques"

### Mechanism 2
- Claim: Edge-AI platforms provide real-time processing capabilities without cloud dependency.
- Mechanism: By performing AI inference directly on the edge device, the framework eliminates network latency and enables immediate decision-making at the monitoring site.
- Core assumption: The edge device has sufficient computational resources to process images in real-time while maintaining battery life and thermal constraints.
- Evidence anchors:
  - [abstract] "reducing latency and enabling real-time decision-making"
  - [section] "Edge-AI allows a process for artificial intelligence inference and computation on-device rather than on cloud servers or network connections"

### Mechanism 3
- Claim: Transfer learning enables efficient model adaptation for edge deployment.
- Mechanism: Using pre-trained models and fine-tuning them on the specific crack detection dataset reduces training time and computational requirements compared to training from scratch.
- Core assumption: The pre-trained model features are transferable to crack detection tasks and sufficient for the target domain.
- Evidence anchors:
  - [section] "Although the device supports popular CNN models like VGG16, VGG19, MobileNet, etc., but it has support for a limited set of operators"
  - [abstract] "An edge-AI-compatible deep learning model is developed"

### Open Question 2
- Question: What are the limitations of using quantization for model optimization on the Kneron KL520 chip, and how do they affect model accuracy and inference time?
- Basis in paper: [explicit] The paper mentions using quantization to optimize the model for the Kneron KL520 chip, reducing inference time significantly, but does not discuss the trade-offs in terms of accuracy loss or potential limitations.
- Why unresolved: While quantization is highlighted as a key optimization technique, the study does not explore its impact on model accuracy or the extent of accuracy loss, if any, resulting from quantization.
- What evidence would resolve it: Detailed analysis comparing model performance before and after quantization, including accuracy metrics and potential accuracy loss, to assess the trade-offs of using quantization.

### Open Question 3
- Question: How scalable is the proposed edge-AI framework for larger-scale structural health monitoring applications beyond crack detection?
- Basis in paper: [inferred] The paper proposes an edge-AI framework for crack detection in bridges, but does not explore its applicability or scalability to other SHM tasks or larger-scale deployments.
- Why unresolved: The framework's effectiveness is demonstrated for a specific task, but its potential for broader applications in SHM or scalability for larger infrastructure networks is not addressed.
