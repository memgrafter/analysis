# Nonparametric Iterative Machine Teaching

## Quick Facts
- arXiv ID: 2306.03007
- Source URL: https://arxiv.org/abs/2306.03007
- Reference count: 40
- Key outcome: The paper proposes a framework for teaching nonparametric target models to iterative learners in an online fashion.

## Executive Summary
This paper introduces Nonparametric Iterative Machine Teaching (NIMT), extending traditional parametric iterative teaching to function spaces through Reproducing Kernel Hilbert Spaces (RKHS). The framework enables teachers to guide iterative learners toward nonparametric target models by operating directly in function space rather than parameter space. Two algorithms are proposed: Random Functional Teaching (RFT) and Greedy Functional Teaching (GFT), with the latter showing significantly faster convergence through intelligent example selection based on functional gradient magnitudes.

## Method Summary
The method formulates NIMT as functional optimization in RKHS, where both target and learner models are functions in the same space. The teacher selects teaching examples that guide the learner through functional gradient descent updates. RFT samples examples randomly, while GFT selects examples that maximize the gradient magnitude toward the target function. The iterative teaching dimension (ITD) is analyzed theoretically, with GFT achieving tighter bounds than RFT under mild assumptions. The framework generalizes parametric iterative machine teaching by replacing parameter updates with function updates in the RKHS.

## Key Results
- GFT achieves lower iterative teaching dimension than RFT, with bounds of O(ψ(2L(f0)/η̃ϵ)) versus O(2L(f0)/η̃ϵ) respectively
- Theoretical analysis shows feasibility of extending parametric IMT to nonparametric settings under proper assumptions
- Experiments on synthetic and real datasets demonstrate effectiveness of both algorithms, with GFT showing faster convergence in most cases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Nonparametric iterative machine teaching extends parametric iterative teaching by operating in function space rather than parameter space, enabling teaching of parameter-free target models.
- Mechanism: By formulating the teaching problem as functional optimization in Reproducing Kernel Hilbert Space (RKHS), the teacher can guide learners to converge to nonparametric target functions through functional gradient descent. This shifts from updating parameters to updating entire functions at each iteration.
- Core assumption: Both the target model and learner model belong to the same RKHS, ensuring the target is realizable within the learner's hypothesis space.
- Evidence anchors:
  - [abstract] "Unlike parametric IMT that merely operates in the parameter space, we cast NIMT as a functional optimization problem in the function space."
  - [section] "Shifting our focus to functions, we formulate NIMT as an instance of functional optimization problem"

### Mechanism 2
- Claim: The greedy functional teaching algorithm achieves faster convergence than random sampling by selecting examples that maximize the gradient magnitude toward the target function.
- Mechanism: The functional gradient of the loss with respect to the model can be decomposed into a scalar magnitude and a unit kernel direction. GFT selects examples where the scalar component (representing the difference between current and target model evaluations) is maximized, effectively taking the steepest descent step in function space.
- Core assumption: The partial derivative of the loss with respect to the model output has positive correlation with the distance between current and target models, making the selection criterion computationally tractable.
- Evidence anchors:
  - [abstract] "Further, the greedy teaching algorithm has a significantly lower ITD, which reaches a tighter upper bound of ITD in NIMT."
  - [section] "Combining Proposition 5 and results in Theorem 6, maximizing gradient norm written in Eq. 6 derives our greedy functional teaching algorithm"

### Mechanism 3
- Claim: The iterative teaching dimension (ITD) for greedy functional teaching is bounded by O(ψ(2L(f0)/η̃ϵ)), which is lower than the ITD for random functional teaching bounded by O(2L(f0)/η̃ϵ).
- Mechanism: The greedy algorithm accumulates a "superiority factor" ψ(t) through its selection strategy, where each iteration's improvement is scaled by the ratio of the random selection improvement to the greedy selection improvement. This cumulative factor grows slower than linear iteration count, yielding tighter bounds.
- Core assumption: The greedy ratio γj = SL(fj;xj)/SL(fj;xj*) remains bounded between 0 and 1, ensuring the superiority factor accumulates meaningfully.
- Evidence anchors:
  - [abstract] "We obtain the iterative teaching dimension (ITD) of the random teaching algorithm under proper assumptions, which serves as a uniform upper bound of ITD in NIMT. Further, the greedy teaching algorithm has a significantly lower ITD, which reaches a tighter upper bound of ITD in NIMT."
  - [section] "Therefore, we conclude that ITD of RFT is O(2L(f0)/ (η̃ϵ)) < ∞, which suggests feasibility of our extension from the parametric IMT to nonparametric IMT."

## Architecture Onboarding

- Component map: Teacher (selects examples using RFT or GFT algorithms) → Learner (updates model using functional gradient descent) → Model space (RKHS where both operate) → Evaluation (measures distance to target using L2 norm in RKHS)
- Critical path: Example selection → Example feeding → Model update → Convergence check → Repeat until convergence
- Design tradeoffs: RFT offers simplicity and lower computational cost but slower convergence; GFT provides faster convergence but requires computing gradient magnitudes for example selection
- Failure signatures: Slow convergence indicates poor kernel choice or inappropriate learning rate; divergence suggests the target function is outside the RKHS or the loss function is ill-conditioned
- First 3 experiments:
  1. Test RFT on a simple 1D regression problem where the target is a Gaussian mixture to verify basic functionality
  2. Compare RFT vs GFT on the same problem to demonstrate the convergence speed difference
  3. Test both algorithms on a 2D classification problem with a nonlinear decision boundary to verify generalization to higher dimensions

## Limitations

- Theoretical bounds rely heavily on assumptions about RKHS properties and may not hold when target functions lie outside the chosen RKHS.
- Computational complexity of GFT scales with the number of candidate examples, potentially becoming prohibitive in high-dimensional or large-scale settings.
- Empirical validation focuses primarily on synthetic datasets and two real-world datasets, with limited exploration of diverse kernel choices and their impact on algorithm performance.

## Confidence

**High Confidence**: The core mechanism of extending parametric iterative teaching to nonparametric settings through functional optimization in RKHS is well-grounded mathematically. The basic RFT algorithm implementation and its convergence properties are clearly established.

**Medium Confidence**: The theoretical bounds on ITD for both RFT and GFT algorithms under stated assumptions. The empirical superiority of GFT over RFT is demonstrated, but the magnitude of improvement may vary significantly with problem characteristics.

**Low Confidence**: The general applicability of the framework to complex, high-dimensional real-world problems and the sensitivity of results to kernel choice and hyperparameters. The scalability analysis for large-scale problems is limited.

## Next Checks

1. **Kernel Sensitivity Analysis**: Systematically test different kernel functions (linear, polynomial, RBF with varying bandwidths) on benchmark datasets to quantify how kernel choice affects convergence speed and teaching dimension, particularly comparing cases where the target function may lie near or far from the RKHS.

2. **Scalability Evaluation**: Implement the algorithms on larger-scale datasets (e.g., CIFAR-10 or larger UCI datasets) to measure computational complexity and memory requirements, comparing wall-clock time and resource usage between RFT and GFT as dataset size increases.

3. **Out-of-RKHS Target Testing**: Design experiments where the target function deliberately lies outside the chosen RKHS (e.g., using discontinuous or highly non-smooth functions) to empirically measure how much approximation error accumulates and whether the algorithms still provide useful learning guidance despite theoretical limitations.
