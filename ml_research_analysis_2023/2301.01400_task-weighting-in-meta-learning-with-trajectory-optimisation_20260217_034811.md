# Task Weighting in Meta-learning with Trajectory Optimisation

## Quick Facts
- arXiv ID: 2301.01400
- Source URL: https://arxiv.org/abs/2301.01400
- Reference count: 0
- Key outcome: Trajectory Optimisation based Task Weighting (TOW) algorithm for meta-learning that outperforms common weighting methods by up to 6% on few-shot learning benchmarks

## Executive Summary
This paper introduces Trajectory Optimisation based Task Weighting (TOW), a novel principled and fully-automated task-weighting algorithm for meta-learning. The key innovation is formulating the task-weighting problem as a trajectory optimisation problem, where meta-parameters are treated as states and task weights as actions. The algorithm uses iterative Linear Quadratic Regulator (iLQR) to solve for optimal task weights within a mini-batch. TOW is theoretically grounded with convergence guarantees to an ε₀-stationary point under certain conditions, and empirically demonstrates superior performance on few-shot learning benchmarks compared to hand-engineered weighting methods.

## Method Summary
TOW reformulates task-weighting in meta-learning as a trajectory optimisation problem. In this formulation, the meta-parameter θ is treated as the state variable, while task weights w are the control actions. The algorithm uses iLQR to iteratively optimize these weights by minimizing a loss function that balances performance across all tasks in a mini-batch. The optimization proceeds by linearizing the dynamics around the current trajectory and solving a sequence of quadratic approximations. This approach allows for automated, principled weight assignment that adapts to the specific characteristics of each task and batch composition, moving beyond simple uniform weighting or heuristic-based approaches.

## Key Results
- TOW achieves up to 6% higher accuracy than baseline weighting methods on few-shot learning benchmarks
- Outperforms uniform weighting, exploration (focusing on difficult tasks), and exploitation (focusing on easy tasks) strategies
- Demonstrates scalability to larger networks like ResNet-12 and maintains performance on out-of-distribution tasks

## Why This Works (Mechanism)
TOW works by treating task-weighting as a control problem where the goal is to find optimal "actions" (task weights) that guide the "state" (meta-parameters) along a trajectory that minimizes overall loss. By using iLQR, the algorithm can account for the coupling between tasks and adapt weights based on the current learning dynamics. This principled approach allows TOW to balance exploration and exploitation automatically, focusing on tasks that provide the most information for meta-learning while maintaining stability across the batch.

## Foundational Learning
- **Meta-learning fundamentals**: Understanding how models learn to learn across tasks is crucial for appreciating why task weighting matters in meta-learning optimization
- **Trajectory optimisation**: The core mathematical framework that enables viewing task weighting as a control problem with states and actions
- **iLQR algorithm**: The specific optimization technique used to solve the trajectory optimisation problem efficiently in the meta-learning context
- **Stationary point convergence**: The theoretical guarantee that ensures TOW's optimization process will find a locally optimal solution under certain conditions
- **Few-shot learning benchmarks**: The empirical evaluation framework (Omniglot, miniImageNet) that provides standardized comparisons for meta-learning algorithms

## Architecture Onboarding
- **Component map**: Meta-parameters (θ) ← iLQR optimization ← Task weights (w) ← Task losses
- **Critical path**: iLQR iteratively updates task weights → weights are applied to compute weighted meta-gradient → meta-parameters are updated
- **Design tradeoffs**: Computational overhead of iLQR vs. performance gains from optimal weighting; flexibility to adapt to batch composition vs. stability of fixed weighting schemes
- **Failure signatures**: Poor convergence if loss landscape is highly non-smooth; suboptimal weights if batch size is too small to capture task diversity
- **First experiments**: 1) Compare TOW's weighting distribution against uniform weighting on a simple meta-learning task 2) Test convergence behavior with varying batch sizes 3) Measure computational overhead compared to baseline methods

## Limitations
- Convergence proof relies on assumptions about Lipschitz continuity of the Hessian and smoothness of the loss landscape that may not hold in practical scenarios
- Computational overhead of iLQR-based optimization could be prohibitive for very large-scale applications despite demonstrated scalability to ResNet-12
- Empirical evaluation is limited to specific few-shot learning benchmarks, leaving questions about generalization to other meta-learning domains
