# A Stutter Seldom Comes Alone -- Cross-Corpus Stuttering Detection as a Multi-label Problem

## Quick Facts
- arXiv ID: 2305.19255
- Source URL: https://arxiv.org/abs/2305.19255
- Reference count: 0
- Multi-label stuttering detection using wav2vec 2.0 achieves competitive results across English and German datasets

## Executive Summary
This paper presents a multi-label stuttering detection system that treats stuttering detection as a multi-label problem, recognizing that multiple dysfluency types often co-occur. The system uses wav2vec 2.0 with an attention-based classification head and multi-task learning, evaluated on three datasets containing English and German stuttered speech. The approach demonstrates competitive performance across cross-corpus and multi-language settings, though performance on samples with multiple labels remains below overall detection results.

## Method Summary
The proposed approach uses wav2vec 2.0 as a feature extractor, followed by an attention-based classification head for multi-label stuttering detection. The system employs multi-task learning to simultaneously detect different types of dysfluencies. The architecture treats stuttering detection as a multi-label problem, allowing the model to predict multiple dysfluency types for each speech sample. The model is trained on multiple datasets containing both English and German stuttered speech, including fluency-shaped speech recordings.

## Key Results
- Multi-label systems trained on cross-corpus and multi-language data achieve competitive results
- Performance on samples with multiple labels stays below overall detection results
- Error analysis highlights the difficulty of detecting co-occurring dysfluencies

## Why This Works (Mechanism)
The system leverages self-supervised pre-trained representations from wav2vec 2.0, which captures rich acoustic features useful for detecting subtle patterns in stuttered speech. The attention-based classification head allows the model to focus on relevant temporal regions in the speech signal, while multi-task learning helps the model learn shared representations across different dysfluency types. The multi-label formulation is particularly important because stuttering events rarely occur in isolation, and modeling them jointly helps capture the complex relationships between different dysfluency types.

## Architecture Onboarding

Component Map:
wav2vec 2.0 feature extractor -> Attention-based classification head -> Multi-label output layer

Critical Path:
1. Speech signal input
2. wav2vec 2.0 feature extraction
3. Attention-based temporal pooling
4. Multi-label classification
5. Loss computation and backpropagation

Design Tradeoffs:
- Multi-label vs binary classification: Multi-label better captures co-occurring dysfluencies but increases model complexity
- Attention-based vs simple pooling: Attention allows dynamic focus but adds computational overhead
- Multi-task vs single-task: Multi-task leverages shared representations but may suffer from negative transfer

Failure Signatures:
- Poor performance on multi-label samples indicates difficulty in modeling co-occurring dysfluencies
- Domain shift between training and test corpora suggests need for domain adaptation
- Class imbalance issues may lead to biased predictions toward more frequent dysfluency types

3 First Experiments:
1. Ablation study comparing single-task vs multi-task learning performance
2. Analysis of attention weight patterns on correctly vs incorrectly classified samples
3. Evaluation of domain adaptation techniques when training on multiple corpora

## Limitations
- Performance on multi-label samples remains below overall detection results
- Limited analysis of why certain dysfluency combinations are particularly challenging

## Confidence

High confidence: The overall architecture using wav2vec 2.0 with multi-task learning is technically sound and well-implemented. The experimental setup and evaluation metrics are appropriate for the task.

Medium confidence: Claims about competitive cross-corpus performance are supported by the results, but the relatively small number of datasets and speakers limits generalizability. The observation that multi-label performance lags behind single-label performance is valid but needs more detailed analysis.

Low confidence: The paper's implications for clinical applications and real-world deployment are not well-supported by the current results, particularly given the limited dataset sizes and lack of user studies.

## Next Checks

1. Conduct ablation studies to quantify the contribution of multi-task learning versus single-task training for each dysfluency type, particularly focusing on the hardest-to-detect combinations.

2. Test the model on additional stuttering datasets with different recording conditions, speaker demographics, and languages to better understand cross-corpus generalization limits.

3. Implement and evaluate specific techniques for handling multi-label data during training, such as focal loss or class-balanced sampling, to determine if these improve detection of co-occurring dysfluencies.
