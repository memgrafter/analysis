# Exploring Attention Map Reuse for Efficient Transformer Neural Networks

## Quick Facts
- arXiv ID: 2301.12444
- Source URL: https://arxiv.org/abs/2301.12444
- Reference count: 37
- Primary result: Attention map reuse reduces Transformer inference latency by 38-52% on GPU and 33-61% on CPU for speech recognition while preserving WER for moderate reuse configurations.

## Executive Summary
This paper introduces attention map reuse as a structured approach to compress Transformer models for speech recognition. The method shares one attention map across multiple consecutive self-attention layers, reducing the number of attention computations by a factor of M. This approach is highly structured and hardware-friendly compared to other self-attention compression methods like sparsification or clustering. The authors demonstrate that self-attention is the main bottleneck in Conformer inference, especially for long sequences, and show that attention map reuse can significantly reduce inference latency while maintaining recognition accuracy for moderate reuse configurations.

## Method Summary
The method reuses the attention map computed in layer ℓ for the next M-1 consecutive layers, reducing the effective number of self-attention computations from L to L/M. This is implemented by removing query and key parameters after the first layer in each group while doubling the value dimension to compensate for reduced parameters. The approach is tested on the LibriSpeech speech recognition dataset using a Conformer-M model with various attention map reuse configurations (2×8, 4×4, 8×2) and compared against a baseline model without reuse.

## Key Results
- Attention map reuse achieves 38-52% speedup on GPU and 33-61% on CPU for 10-40 second utterances
- WER is almost preserved for moderate reuse configurations (2×8, 4×4)
- Performance degrades when too many layers share the same attention map (e.g., 8×2 configuration)
- The method is most effective for long sequences where self-attention computation dominates inference time

## Why This Works (Mechanism)

### Mechanism 1: Attention Map Computation Reduction
- Claim: Attention map reuse reduces the number of attention computations by sharing one attention map across multiple consecutive self-attention layers.
- Mechanism: The attention map computed in the ℓ-th layer is reused for the next M-1 layers, reducing the effective number of SA computations from L to L/M.
- Core assumption: The attention maps between neighboring SA layers are sufficiently similar that reusing one does not significantly degrade performance.
- Evidence anchors: Abstract statement about reducing SA computation from L to L/M; observation that SA behavior is similar between neighboring layers.

### Mechanism 2: Long Sequence Effectiveness
- Claim: Attention map reuse is particularly effective for long sequences because SA computation dominates inference time quadratically with sequence length.
- Mechanism: As sequence length T increases, SA computation grows quadratically (O(T²)) while other components grow linearly, making SA the bottleneck for long sequences.
- Core assumption: The target task processes long sequences where quadratic complexity becomes prohibitive.
- Evidence anchors: SA takes 45% of total inference time for 10-second input but 67% for 30-second input; quadratic vs linear growth comparison.

### Mechanism 3: Hardware-Friendly Structure
- Claim: The structured nature of attention map reuse makes it highly hardware-friendly compared to other SA compression techniques.
- Mechanism: Unlike sparsification or clustering methods requiring unstructured computation patterns, attention map reuse removes entire attention computation blocks in a predictable, structured manner.
- Core assumption: Modern hardware platforms benefit from structured computation patterns rather than irregular, data-dependent patterns.
- Evidence anchors: Abstract statement about being "highly structured and easy to implement on modern hardware platforms"; comparison to unstructured computation savings.

## Architecture Onboarding

- **Component map**: Input audio frames → Conformer layer stack (MHSA, Conv, FF) → Attention map reuse → Transcribed text output

- **Critical path**: The attention map computation in MHSA is the critical path for long sequences; attention map reuse shortens this by reusing computed attention maps across multiple layers.

- **Design tradeoffs**: 
  - Performance vs. speed: More aggressive reuse (higher M) provides greater speedup but risks performance degradation
  - Parameter efficiency: Doubling value dimension to compensate for reduced parameters
  - Task sensitivity: Works best for tasks not sensitive to small attention variations

- **Failure signatures**: 
  - Performance degradation when M is too large (e.g., 8×2 configuration shows WER increase)
  - Limited benefit for short sequences where SA is not the bottleneck
  - Issues if attention maps between layers vary significantly

## Open Questions the Paper Calls Out

- **Cross-task validation**: How does attention map reuse perform on transformer models with longer sequence lengths (2048+ frames) common in some speech recognition tasks? The paper evaluates up to 1024 frames but notes that many speech tasks involve longer utterances.

- **Streaming compatibility**: What is the impact of attention map reuse on streaming speech recognition where only past and current frames are available? The paper focuses on non-streaming scenarios and doesn't address unidirectional attention patterns required in streaming applications.

- **Technique combination**: How does attention map reuse interact with other efficient transformer techniques like sparse attention or low-rank factorization? While the paper mentions these are "orthogonal and can be used together," it doesn't provide empirical results combining them.

## Limitations

- Results are primarily validated on a single speech recognition task (LibriSpeech) using one model architecture (Conformer), limiting generalizability to other Transformer-based tasks.
- The effectiveness depends heavily on the assumption that consecutive SA layers perform similar roles, which may not hold for tasks requiring more diverse attention patterns.
- The paper doesn't thoroughly explore the impact of sequence length variability or the interaction between attention map reuse and other efficiency techniques.

## Confidence

- **High Confidence**: The observation that SA computation dominates inference time for long sequences (45% for 10-second input, 67% for 30-second input) is well-supported by the time breakdown analysis.
- **Medium Confidence**: The claim that attention map reuse preserves WER for moderate configurations (2×8, 4×4) while providing significant speedups is reasonably supported, though limited to one dataset and model architecture.
- **Low Confidence**: The assertion that attention map reuse is "highly structured and easy to implement on modern hardware platforms" lacks specific hardware implementation details or benchmarks.
