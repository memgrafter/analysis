# Multilingual Multi-Figurative Language Detection

## Quick Facts
- arXiv ID: 2306.00121
- Source URL: https://arxiv.org/abs/2306.00121
- Reference count: 21
- Introduces benchmark for multilingual multi-figurative language detection across seven languages and three figures of speech

## Executive Summary
This paper presents a novel benchmark for multilingual multi-figurative language detection, focusing on hyperbole, idioms, and metaphors across seven languages. The authors develop a unified framework using template-based prompt learning with mT5, eliminating the need for task- or language-specific modules. Their approach demonstrates strong performance across most tasks, with prompt-based mT5 achieving the highest accuracy scores. The study evaluates both cross-lingual and cross-figurative generalization capabilities, revealing insights about transfer learning effectiveness across different figurative language types.

## Method Summary
The authors introduce a unified framework for multilingual multi-figurative language detection that leverages template-based prompt learning with mT5. The approach eliminates the need for separate modules for different tasks or languages by using a single model architecture with carefully designed prompts. The framework is evaluated through both cross-lingual and cross-figurative settings, with multitask training implemented to improve overall performance. The evaluation compares prompt mT5 against mBERT and vanilla mT5 baselines across multiple languages and figurative language types.

## Key Results
- Prompt mT5 with multitask training achieves highest accuracy: 82.00% (hyperbole EN), 86.00% (idiom EN), 83.43% (metaphor EN)
- Zero-shot English models show strong performance: 81.00% (hyperbole EN), 79.50% (idiom EN), 83.43% (metaphor EN)
- Cross-lingual transfer improves performance for all figures except idioms, where cultural specificity limits transfer

## Why This Works (Mechanism)
The unified framework succeeds by leveraging the pre-trained knowledge of mT5 through carefully designed prompt templates that can handle multiple figurative language types without requiring separate task-specific modules. The multitask training approach allows the model to learn shared representations across different figurative language types, improving generalization. The template-based prompt learning enables flexible adaptation to different languages while maintaining a consistent approach, reducing the need for language-specific engineering.

## Foundational Learning
- **mT5 model architecture**: Understanding the transformer-based multilingual architecture is crucial for implementing prompt-based approaches
- **Cross-lingual transfer learning**: Essential for evaluating how knowledge transfers between languages and for designing effective multilingual models
- **Figurative language classification**: Core domain knowledge needed to understand the specific challenges of detecting hyperbole, idioms, and metaphors
- **Template-based prompt engineering**: Critical technique for adapting pre-trained models to specific tasks without fine-tuning
- **Multitask learning**: Important for understanding how joint training across multiple figurative language types improves overall performance
- **Cross-dataset evaluation**: Necessary for assessing model generalization beyond the specific benchmark used

Design tradeoffs:
- Unified approach vs. specialized models for each language/figurative type
- Prompt-based learning vs. full fine-tuning (reduced training cost vs. potential performance)
- Seven languages coverage vs. depth of representation for each language

Failure signatures:
- Poor cross-lingual transfer for idioms indicates cultural specificity limitations
- Performance degradation when moving from English to other languages
- Difficulty distinguishing between different figurative language types

## Limitations
- Evaluation limited to three specific figurative language types (hyperbole, idiom, metaphor)
- Cross-dataset generalization not tested, limiting claims about real-world applicability
- Cultural and linguistic specificity, particularly for idioms, may limit framework applicability to low-resource languages
