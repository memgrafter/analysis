# Importance Sparsification for Sinkhorn Algorithm

## Quick Facts
- arXiv ID: 2306.06581
- Source URL: https://arxiv.org/abs/2306.06581
- Reference count: 26
- Primary result: Reduces OT and UOT computational cost from O(n²) to O(n) per iteration while maintaining consistency

## Executive Summary
This paper introduces Spar-Sink, a novel importance sparsification method for efficiently approximating entropy-regularized and unbalanced optimal transport solutions. The key innovation is constructing a sparse kernel matrix by sampling elements based on natural upper bounds of optimal transport plans, achieving significant computational speedups while maintaining theoretical guarantees. The method demonstrates consistent performance across extensive experiments and extends to Wasserstein barycenter estimation.

## Method Summary
Spar-Sink constructs a sparse approximation of the kernel matrix K by sampling elements using importance sampling probabilities derived from natural upper bounds of transport plans (ai and bj). The algorithm employs Poisson sampling to select s << n² elements, reducing computational complexity from O(n²) to O(n) per iteration. Theoretical analysis establishes consistency under mild regularity conditions, requiring the kernel matrix to satisfy certain spectral properties and the subsampling size to scale appropriately with problem dimension.

## Key Results
- Reduces computational cost from O(n²) to O(n) per iteration for both OT and UOT problems
- Maintains the same iteration complexity as classical Sinkhorn up to a constant factor
- Achieves hundreds of times speedup in practice while preserving prediction accuracy
- Successfully extends to Wasserstein barycenter approximation with improved efficiency

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Importance sparsification reduces OT and UOT computational cost from O(n²) to O(n) per iteration.
- Mechanism: The algorithm constructs a sparse kernel matrix by sampling elements based on upper bounds of optimal transport plans using Poisson sampling.
- Core assumption: The kernel matrix K is positive definite with bounded condition number.
- Evidence anchors: [abstract], [section 3.2]
- Break Condition: If K's condition number becomes too large, sparse approximation may lose accuracy.

### Mechanism 2
- Claim: The proposed estimators are consistent under mild regularity conditions.
- Mechanism: Sampling probabilities maintain unbiased estimate of kernel matrix with subsampling size scaling appropriately.
- Core assumption: Kernel matrix satisfies spectral norm conditions and sampling probabilities are bounded below.
- Evidence anchors: [section 4]
- Break Condition: If α is too small, s must be very large negating computational benefits.

### Mechanism 3
- Claim: The algorithm maintains the same iteration complexity as classical Sinkhorn up to a constant factor.
- Mechanism: Sparse approximation introduces only constant factor overhead in convergence iterations.
- Core assumption: Error from sparsification is bounded and doesn't significantly affect convergence.
- Evidence anchors: [section 4], [section 5.2]
- Break Condition: If sampling probability construction fails to capture informative elements, iteration count increases.

## Limitations
- Theoretical guarantees depend on regularity conditions that may not hold in high-dimensional settings
- Relationship between subsample size s and dimension d is not fully characterized
- Wasserstein barycenter extension lacks rigorous theoretical justification

## Confidence

- **High Confidence**: O(n) per iteration computational complexity improvement and basic importance sampling framework
- **Medium Confidence**: Consistency proofs under mild regularity conditions
- **Low Confidence**: Wasserstein barycenter extension results due to limited validation
