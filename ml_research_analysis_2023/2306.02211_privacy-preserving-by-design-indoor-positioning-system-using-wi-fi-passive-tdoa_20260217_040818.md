# Privacy-Preserving by Design: Indoor Positioning System Using Wi-Fi Passive TDOA

## Quick Facts
- arXiv ID: 2306.02211
- Source URL: https://arxiv.org/abs/2306.02211
- Reference count: 40
- PassiFi achieves sub-meter median accuracy of 0.82m while preserving privacy

## Executive Summary
PassiFi introduces a novel passive Wi-Fi TDoA indoor localization system that addresses privacy concerns inherent in active localization approaches. The system operates by listening to Fine Timing Measurement (FTM) exchanges between access points without requiring user devices to transmit, thereby preserving user privacy. PassiFi employs a fingerprinting approach with deep neural networks to learn the complex relationship between Time Difference of Arrival measurements and location, achieving sub-meter accuracy while maintaining privacy guarantees.

## Method Summary
PassiFi uses a passive listening approach to capture FTM exchanges between Wi-Fi access points. The system constructs a fingerprinting database by collecting TDoA measurements at various reference points throughout the environment. A deep neural network is then trained to learn the complex relationship between these TDoA measurements and corresponding locations. During operation, the system passively listens to ongoing FTM exchanges and uses the trained model to estimate user positions without any active transmission from client devices, ensuring privacy preservation while maintaining high localization accuracy.

## Key Results
- Achieves sub-meter median accuracy of 0.82m in real-world testbed evaluation
- Outperforms traditional multilateration by 128% while maintaining privacy
- Matches state-of-the-art active RTT systems in accuracy without requiring user device transmission

## Why This Works (Mechanism)
PassiFi's privacy preservation stems from its passive operation design. By listening to FTM exchanges between access points rather than requiring the user device to transmit, the system eliminates the need for client-side participation in the localization process. This passive approach inherently protects user privacy since no location-related data is transmitted from the user device. The system's accuracy is achieved through deep learning that captures complex multipath effects and environmental characteristics that would be difficult to model with traditional geometric approaches.

## Foundational Learning
- Wi-Fi Fine Timing Measurement (FTM): Enables precise time synchronization between devices for ranging measurements; needed for accurate TDoA calculations
- Time Difference of Arrival (TDoA): Technique for determining location based on time differences of signal arrivals at multiple receivers; provides geometric positioning capability
- Fingerprinting database construction: Process of collecting reference measurements at known locations; enables machine learning approaches to localization
- Deep neural networks for localization: Machine learning models that learn complex relationships between signal measurements and positions; handles multipath and environmental complexities
- Passive localization techniques: Methods that operate without requiring active transmission from target devices; preserves privacy and reduces power consumption

## Architecture Onboarding
Component map: APs <-> FTM exchanges -> PassiFi listener -> TDoA measurements -> Deep neural network -> Location estimate

Critical path: FTM exchange capture → TDoA calculation → Neural network inference → Position output

Design tradeoffs: Accuracy vs. privacy (passive listening preserves privacy but may have lower SNR than active approaches), Database maintenance overhead vs. localization accuracy (environmental changes require database updates)

Failure signatures: Reduced accuracy in dynamic environments with moving obstacles, performance degradation when access point density is insufficient, localization errors in areas with severe multipath distortion

First experiments:
1. Validate TDoA measurement accuracy in controlled environment with known transmitter positions
2. Test neural network training convergence and localization accuracy on synthetic dataset
3. Evaluate system performance with varying numbers of access points and anchor placements

## Limitations
- Single testbed evaluation limits generalizability across diverse environments with different multipath characteristics
- Fingerprinting database requires maintenance overhead when environment changes
- Limited adversarial testing beyond theoretical analysis of two specific attack types

## Confidence
- High confidence: The core concept of passive Wi-Fi TDoA for privacy preservation is technically sound and well-established in prior work
- Medium confidence: The sub-meter accuracy claims and 128% improvement over multilateration are supported by the presented results but need broader validation
- Medium confidence: The privacy benefits of passive operation are clearly demonstrated, though real-world deployment considerations remain underexplored

## Next Checks
1. Conduct multi-environment evaluation across at least 3-5 diverse indoor spaces to assess generalizability of accuracy claims
2. Perform extensive adversarial testing with varied attack scenarios beyond the two mentioned to validate security robustness
3. Evaluate system performance under dynamic conditions including moving obstacles, changing occupancy, and environmental modifications to assess fingerprinting database maintenance requirements
