# Transfer Learning for Real-time Deployment of a Screening Tool for Depression Detection Using Actigraphy

## Quick Facts
- arXiv ID: 2303.07847
- Source URL: https://arxiv.org/abs/2303.07847
- Reference count: 0
- Primary result: Transfer learning approach achieves 0.96 mean accuracy for depression detection using actigraphy data

## Executive Summary
This paper presents a transfer learning approach for real-time depression screening using actigraphy data from wearable devices. The method addresses the challenge of limited primary healthcare data by training an initial model on a larger secondary dataset and then adapting it for use with primary Fitbit step count data. The approach combines feature engineering from hourly activity data with scaling normalization to handle different data units across devices. A demonstration UI enables real-time screening with uploaded Fitbit data, showing promise for scalable digital health applications.

## Method Summary
The method involves training a Random Forest model on a secondary "Depresjon" dataset containing minute-wise activity levels from 55 participants, then applying transfer learning to adapt it for primary Fitbit data. Hourly activity data is aggregated from minute-level records, missing values are imputed, and RobustScaler is applied for normalization. Statistical features are computed from four 6-hour time-of-day bins, creating the final feature set. Modified leave-one-out cross-validation is performed on the primary dataset, and a Gradio UI demonstrates real-time deployment capability.

## Key Results
- Modified leave-one-out cross-validation on primary dataset achieved mean accuracy of 0.96
- RobustScaler outperformed MinMaxScaler for normalizing activity data across different devices
- Feature engineering from hourly activity data and time-of-day binning proved effective for depression detection
