# Continual Learning for Out-of-Distribution Pedestrian Detection

## Quick Facts
- arXiv ID: 2306.15117
- Source URL: https://arxiv.org/abs/2306.15117
- Reference count: 0
- This paper proposes a continual learning approach based on modified Elastic Weight Consolidation (EWC) for out-of-distribution pedestrian detection, achieving 9% and 18% miss rate improvements on CrowdHuman and CityPersons datasets respectively.

## Executive Summary
This paper addresses the out-of-distribution generalization problem in pedestrian detection, where models trained on one dataset experience significant performance degradation when tested on data from a different distribution. The authors propose a continual learning approach based on a modified Elastic Weight Consolidation (EWC) loss integrated with Faster R-CNN. Their method penalizes changes to model weights based on their importance to the initial task, allowing the network to learn new distributions while maintaining performance on previous ones. The approach is evaluated on two popular pedestrian detection datasets (CityPersons and CrowdHuman) in cross-dataset scenarios, demonstrating significant improvements over standard fine-tuning.

## Method Summary
The proposed method modifies Elastic Weight Consolidation for object detection by calculating parameter importance using the derivative of the loss with respect to each parameter, rather than the model output. This allows balanced treatment of classification and regression losses in Faster R-CNN. During fine-tuning on a new dataset, the modified EWC loss adds a penalty term for changing important weights, preventing catastrophic forgetting. Gradient clipping (Gmax=20) is applied to prevent exploding gradients. The method calculates Fisher Information for each weight based on the initial dataset, then uses this to weight the regularization term during fine-tuning on a new dataset.

## Key Results
- 9% miss rate percent reduction improvement on CrowdHuman dataset
- 18% miss rate percent reduction improvement on CityPersons dataset
- Significant improvement over standard fine-tuning across varying occlusion levels (Reasonable, Bare, Partial, Heavy)
- Effective mitigation of catastrophic forgetting in cross-dataset scenarios

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: The modified EWC loss prevents catastrophic forgetting by penalizing weight changes based on their importance to the initial dataset.
- **Mechanism**: The algorithm calculates Fisher Information for each weight based on the initial dataset, then adds a penalty term to the loss function when fine-tuning on a new dataset. Weights important for the first dataset are penalized more heavily when they change.
- **Core assumption**: The Fisher Information Matrix accurately captures parameter importance for the initial task distribution.
- **Evidence anchors**:
  - [abstract] "Our method adopts and modifies Elastic Weight Consolidation to a backbone object detection network, in order to penalize the changes in the model weights based on their importance towards the initially learned task."
  - [section] "This method minimizes the change in the model's output with respect to the initial dataset after fine-tuning on a new dataset."
  - [corpus] Weak evidence - the corpus contains related continual learning papers but none specifically address the EWC modification for object detection regression tasks.
- **Break condition**: If the initial dataset's distribution is not representative or if the importance weights become outdated due to significant domain shifts.

### Mechanism 2
- **Claim**: The modified EWC formulation works for both classification and regression components simultaneously.
- **Mechanism**: Instead of using the model output for importance calculation (as in standard EWC), this work uses the derivative of the loss with respect to each parameter, allowing balanced treatment of classification and regression losses regardless of their absolute value ranges.
- **Core assumption**: The derivative of the combined loss with respect to parameters provides a balanced importance measure across different loss components.
- **Evidence anchors**:
  - [section] "In our formulation, the importance of a parameter is now based on the derivative of the loss with respect to that parameter, rather than the derivative of the model's output which effectively balances the two loss quantities."
  - [corpus] Moderate evidence - the corpus includes papers on continual learning but none specifically address multi-task EWC formulations for object detection.
- **Break condition**: If the loss components have fundamentally incompatible optimization dynamics that cannot be balanced through this approach.

### Mechanism 3
- **Claim**: Gradient clipping prevents exploding gradients when using EWC regularization.
- **Mechanism**: During training, all gradients are clipped to a maximum value (Gmax = 20), preventing numerical instability that can occur with the EWC penalty term.
- **Core assumption**: Gradient clipping does not significantly impact the optimization trajectory while preventing numerical issues.
- **Evidence anchors**:
  - [section] "Previous studies point to a potential disadvantage of using EWC for training, in that it may result in exploding gradients. In order to overcome this issue with minimum modification to the loss and maintain its advantages, all gradients are clipped to Gmax in the training process."
  - [corpus] Weak evidence - the corpus contains papers on continual learning but none specifically discuss gradient clipping in the context of EWC for object detection.
- **Break condition**: If the optimal learning trajectory requires gradients larger than the clipping threshold.

## Architecture Onboarding

- **Component map**: Feature extractor (ResNet-50 backbone) -> Region Proposal Network (RPN) -> ROI pooling layer -> Classification head (binary pedestrian/non-pedestrian) -> Bounding box regression head (coordinate offsets) -> EWC regularization module integrated into the loss calculation

- **Critical path**: Training → Dataset switch → Fine-tuning with EWC → Evaluation on both datasets

- **Design tradeoffs**:
  - EWC coefficient λ vs. adaptation speed to new distribution
  - Gradient clipping threshold vs. optimization stability
  - Choice of backbone architecture vs. computational efficiency
  - Single dataset vs. replay buffer for continual learning

- **Failure signatures**:
  - Increasing miss rate on original dataset during fine-tuning (catastrophic forgetting)
  - Training instability or NaN values (gradient explosion)
  - No improvement on new dataset (λ too high)
  - Degraded performance on both datasets (poor λ choice)

- **First 3 experiments**:
  1. Train baseline Faster R-CNN on CityPersons, fine-tune without regularization on CrowdHuman, measure forgetting on CityPersons
  2. Repeat with proposed EWC method, compare forgetting magnitude
  3. Vary λ parameter systematically to find optimal trade-off between learning new distribution and preserving old performance
