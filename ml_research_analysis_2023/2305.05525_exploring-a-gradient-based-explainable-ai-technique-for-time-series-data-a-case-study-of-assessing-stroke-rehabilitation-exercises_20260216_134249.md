# Exploring a Gradient-based Explainable AI Technique for Time-Series Data: A Case Study of Assessing Stroke Rehabilitation Exercises

## Quick Facts
- **arXiv ID:** 2305.05525
- **Source URL:** https://arxiv.org/abs/2305.05525
- **Reference count:** 7
- **Primary result:** Gradient-based saliency maps achieved 0.96 recall and 0.91 F2-score for detecting compensatory motions in stroke rehabilitation exercise videos

## Executive Summary
This paper proposes a gradient-based explainable AI technique using saliency maps to identify salient frames in post-stroke rehabilitation exercise videos. The approach trains a feed-forward neural network with weak exercise-level labels, then uses gradient information to detect frame-level compensatory motions. By normalizing gradient scores and applying a threshold, the method highlights frames where therapists should focus their attention, potentially reducing the need for time-consuming frame-level annotations during model training.

## Method Summary
The method preprocesses video data to extract body key points and distance features, then trains a feed-forward neural network (300→150 hidden units, ReLU) to classify exercise trials as normal or compensatory. Gradients of the loss function with respect to input frames are computed, normalized to [0,1], and thresholded (0.36) to identify salient frames. The approach was evaluated on 15 post-stroke patients performing upper-limb exercises, using frame-level annotations for performance measurement.

## Key Results
- Achieved 0.96 recall and 0.91 F2-score for detecting frame-level compensatory motions
- Demonstrated potential for highlighting important frames that therapists should prioritize reviewing
- Showed promise for reducing frame-level labeling efforts in model training through weakly supervised learning

## Architecture Onboarding

- Component map: Input video data -> Feed-forward neural network -> Gradient-based saliency maps -> Thresholded frame-level classification
- Critical path:
  1. Preprocess video data to extract body key points and distance features
  2. Train feed-forward neural network on exercise-level labels
  3. Compute gradients of loss function with respect to input data for each frame
  4. Normalize gradient scores and apply threshold to identify compensatory frames
  5. Evaluate performance using frame-level annotations

- Design tradeoffs:
  - Using a feed-forward neural network vs. more complex architectures like LSTMs or CNNs
  - Weakly supervised learning vs. full frame-level supervision
  - Threshold-based classification vs. probabilistic or multi-class approaches

- Failure signatures:
  - Low recall or F2-score indicating poor detection of compensatory frames
  - High false positive rate suggesting the threshold is too low
  - Overfitting to training data resulting in poor generalization to new exercises

- First 3 experiments:
  1. Train the model on a subset of the data and visualize saliency maps to ensure they highlight relevant frames
  2. Test different threshold values on a validation set to find the optimal balance between recall and precision
  3. Evaluate the model's performance on data from patients not seen during training to assess generalization

## Limitations
- Limited dataset scale with only 15 post-stroke patients and restricted exercise variations
- Heavy dependence on threshold selection, which may not generalize across different patient populations
- Assumption that exercise-level labels contain sufficient information for accurate frame-level detection
