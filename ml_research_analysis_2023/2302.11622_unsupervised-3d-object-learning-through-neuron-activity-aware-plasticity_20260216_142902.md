# Unsupervised 3D Object Learning through Neuron Activity aware Plasticity

## Quick Facts
- arXiv ID: 2302.11622
- Source URL: https://arxiv.org/abs/2302.11622
- Reference count: 39
- Key outcome: NeAW Hebbian learning outperforms other Hebbian variants and supervised models with limited data on ModelNet10/40

## Executive Summary
This paper introduces Neuron Activity Aware (NeAW) Hebbian learning, an unsupervised approach for 3D object classification that dynamically switches between Hebbian and anti-Hebbian learning based on neuron activity. The method addresses the problem of biased neuron activation in traditional Hebbian learning, where only a few neurons activate regardless of input. By balancing neuron activity through this dynamic switching mechanism, the model achieves better representation learning and higher classification accuracy, particularly when training data is limited.

## Method Summary
The method transforms 3D point clouds into high-dimensional feature representations using a multi-layer perceptron encoder trained with NeAW Hebbian learning. The learning rule monitors neuron activity and switches between Hebbian (strengthening active synapses) and anti-Hebbian (weakening active synapses) updates to balance activation across neurons. Winner-Take-All layers ensure sparse activation patterns, and the encoder is trained unsupervised before adding classifier layers for supervised fine-tuning. The approach is evaluated on ModelNet10 and ModelNet40 datasets with 1024 points per object.

## Key Results
- NeAW Hebbian learning achieves 89.5% accuracy on ModelNet10 (fully supervised) and 88.4% with only 10% labeled data
- On ModelNet40, the method achieves 80.8% accuracy (fully supervised) and 78.4% with 10% labeled data
- Outperforms traditional Hebbian, anti-Hebbian, and other biologically plausible learning rules
- Demonstrates superior performance compared to fully supervised models when training data is limited

- Claim: Balanced neuron activity increases variance of neuron activations, leading to better representation learning.

- Core assumption: Higher variance in neuron activity distribution indicates better representation learning with more distinguishable features.

- Claim: Object-dependent neuron activation increases class-to-class dissimilarity in latent space.

  Input (1024 3D points) -> Encoder (3-layer MLP with NeAW Hebbian learning and WTA) -> Classifier (FC layers with LayerNorm and Softmax) -> Output (class probabilities)

- Critical path:
  1. Point cloud sampling and preprocessing
  2. Encoder training with NeAW Hebbian learning (unsupervised)
  3. Classifier training with labeled data (supervised)

- Design tradeoffs:
  - Using unsupervised learning reduces dependency on labeled data but may sacrifice some accuracy
  - WTA layers improve representation learning but make the model non-differentiable
  - Balancing neuron activity improves feature extraction but adds complexity to the learning rule

- Failure signatures:
  - Skewed neuron activity distribution (few neurons dominate activation)
  - Poor class separation in t-SNE visualizations
  - Low variance in neuron activity across different inputs

## Limitations

- The geometric condition for boundary shifting may not hold for all real-world point cloud data, limiting theoretical guarantees
- WTA layers make the model non-differentiable, potentially hindering practical deployment and fine-tuning
- The analysis focuses on variance improvement without establishing direct causal links to classification performance

## Confidence

- Claims about NeAW Hebbian learning's effectiveness: Medium confidence (experimental results show improvements but lack ablation studies)
- Theoretical analysis applicability to real-world scenarios: Low confidence (relies on idealized geometric assumptions)
- Comparison to supervised models with limited data: High confidence (most directly tested claim with clear experimental evidence)
