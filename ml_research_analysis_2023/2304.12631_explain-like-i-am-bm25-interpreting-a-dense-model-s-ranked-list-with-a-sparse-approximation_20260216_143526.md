# Explain like I am BM25: Interpreting a Dense Model's Ranked-List with a Sparse Approximation

## Quick Facts
- arXiv ID: 2304.12631
- Source URL: https://arxiv.org/abs/2304.12631
- Reference count: 37
- Key outcome: BFS-based state-space exploration generates equivalent queries that achieve up to 0.5194 RBO and 96% nDCG of neural retrieval models

## Executive Summary
This paper proposes a method to interpret neural retrieval models by generating "equivalent queries" that approximate the model's output using sparse retrieval models. The authors formulate this as an optimal subset selection problem and solve it using a BFS-based state-space exploration. Their experiments on the MS-MARCO dataset show that the generated equivalent queries achieve high fidelity scores and can produce nDCG values up to 96% of the target neural models. The BFS approach significantly outperforms greedy baselines and RM3-based query expansion.

## Method Summary
The method generates equivalent queries by performing BFS-based state-space exploration over query term additions and removals. Starting from an empty query, the algorithm explores possible term combinations using RM3 weights as heuristics, evaluating each state using rank-based overlap (RBO) against the target neural model's output. The search continues up to a depth of 10 term operations or until the best equivalent query is found, with experiments showing superior performance compared to greedy search and RM3 baselines.

## Key Results
- BFS approach achieves RBO scores up to 0.5194, significantly outperforming greedy baselines
- Generated equivalent queries retain up to 96% of the nDCG performance of target neural models
- BFS demonstrates superior ability to explore promising directions and backtrack when needed compared to greedy search

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BFS-based state-space exploration finds equivalent queries that approximate NRM output better than greedy search
- Mechanism: The BFS explores multiple branches simultaneously and can backtrack to promising unexplored paths, whereas greedy search commits to a single path
- Core assumption: The optimal equivalent query exists within the explored state space and can be found through systematic term addition/removal
- Evidence anchors:
  - [abstract]: "The BFS approach significantly outperforms greedy baselines"
  - [section]: "An advantage of the best-first exploration is that it is able to continue exploring along a promising direction at greater depths, or is able to back-track to expand yet unexplored states at lower depths"
- Break condition: If the state space is too large or the optimal solution requires more than 10 term additions/removals, BFS may not find the global optimum

### Mechanism 2
- Claim: Equivalent queries provide interpretable explanations by revealing semantic concepts used by NRMs
- Mechanism: Sparse retrieval models use explicit term matching, so when an equivalent query produces similar results to an NRM, the terms in that query represent the semantic concepts the NRM implicitly considers
- Core assumption: The terms selected for the equivalent query capture the semantic meaning that the NRM encodes in dense representations
- Evidence anchors:
  - [abstract]: "the generated equivalent queries achieve high fidelity scores... and can produce nDCG values up to 96% of the target neural models"
  - [section]: "The interesting point is that 'appenzeler' and 'vacherin' are two different varieties of Swiss cheese; the two equivalent queries produced by our method unravel the different concepts and terms used by these two models"
- Break condition: If the NRM uses complex non-linear transformations that don't map cleanly to term combinations, equivalent queries may not provide meaningful explanations

### Mechanism 3
- Claim: RM3 weights provide effective heuristics for term selection during state-space exploration
- Mechanism: RM3 weights represent the relevance of terms in pseudo-relevant documents, making them good candidates for inclusion in equivalent queries
- Core assumption: Terms with high RM3 weights are semantically related to the query and improve retrieval effectiveness
- Evidence anchors:
  - [section]: "the normalized probability of the RM3 weights... the higher the RM3 weight of a term... the higher is the likelihood of exploring along the branch"
  - [section]: "A large volume of work on pseudo-relevance feedback (PRF) in IR has shown that most terms that are semantically related to the information need mostly occur within the top-𝑘 set of documents retrieved"
- Break condition: If RM3 weights don't correlate well with semantic relevance for the specific domain or if the top-k documents don't contain relevant terms

## Foundational Learning

- Concept: Discrete state-space optimization
  - Why needed here: The equivalent query problem is formulated as an optimal subset selection problem which is NP-complete
  - Quick check question: Why can't we simply try all possible combinations of query terms to find the optimal equivalent query?

- Concept: Best-First Search (BFS) algorithm
  - Why needed here: BFS can explore multiple paths simultaneously and backtrack when needed, unlike greedy search
  - Quick check question: What's the key difference between BFS and greedy search in terms of path exploration?

- Concept: Rank-based overlap metrics (RBO)
  - Why needed here: RBO measures similarity between ranked lists while accounting for rank positions, which is crucial for evaluating retrieval effectiveness
  - Quick check question: How does RBO differ from simple set-based metrics like Jaccard when comparing ranked retrieval results?

## Architecture Onboarding

- Component map:
  Neural Retrieval Models (NRMs) as black-box targets -> Sparse retrieval model (BM25) as approximator -> State-space exploration engine (BFS) -> Term selection heuristics (RM3 weights) -> Evaluation metrics (RBO, nDCG, MAP)

- Critical path:
  1. Input query and NRM
  2. Generate top-k document list using NRM
  3. Extract vocabulary from top-k documents
  4. Initialize BFS with empty query
  5. Explore state space using term addition/removal actions
  6. Evaluate states using RBO against NRM output
  7. Return best equivalent query found

- Design tradeoffs:
  - Exploration depth vs. latency (10-depth limit chosen)
  - Branch factor (30 chosen for exploration breadth)
  - Local approximation (k=10 for top results) vs. global explanation
  - Model-aware (NRM-specific) vs. model-agnostic explanations

- Failure signatures:
  - Low fidelity scores despite extensive exploration
  - Equivalent queries that are very long or contain irrelevant terms
  - Poor retrieval performance when equivalent queries are executed on BM25
  - High latency due to excessive state exploration

- First 3 experiments:
  1. Run BFS on a simple query with known ground truth to verify basic functionality
  2. Compare BFS vs greedy performance on queries with different semantic complexity
  3. Test sensitivity to exploration parameters (depth, branch factor) on a validation set

## Limitations
- Method requires access to target NRM's ranked lists, making it a post-hoc explanation rather than real-time interpretability
- Effectiveness depends heavily on RM3 weights which may not generalize across domains
- The 10-term depth limit and 30-term branching factor are arbitrary choices without sensitivity analysis

## Confidence
- High confidence: BFS-based equivalent query generation shows strong experimental results with clear algorithmic description
- Medium confidence: The method's generalizability to other domains and languages is unknown
- Low confidence: The computational complexity and practical limitations for large-scale applications are not explored
