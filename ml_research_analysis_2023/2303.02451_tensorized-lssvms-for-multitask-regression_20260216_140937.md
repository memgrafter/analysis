# Tensorized LSSVMs for Multitask Regression

## Quick Facts
- arXiv ID: 2303.02451
- Source URL: https://arxiv.org/abs/2303.02451
- Reference count: 26
- Primary result: Novel tensorized LSSVM method (tLSSVM-MTL) outperforms existing matrix- and tensor-based MTL methods in prediction accuracy and computational efficiency.

## Executive Summary
This paper introduces tensorized LSSVM (tLSSVM-MTL), a multitask learning method for regression that leverages high-order tensors and CP decomposition. The approach models tasks referenced by multiple indices using a weight tensor factorized into shared and task-specific latent factors. An alternating optimization algorithm solves the nonconvex problem by alternating between linear systems in the dual. Experiments on synthetic and real-world datasets demonstrate superior performance compared to existing methods.

## Method Summary
The tLSSVM-MTL method constructs a high-order tensor for all weights, with each mode relating to a task index. This tensor is factorized using CP decomposition into a shared factor L and task-specific factors Un for each mode. The resulting nonconvex optimization problem is solved via an alternating algorithm where each subproblem reduces to solving a linear system in the dual. This approach enables flexible multilinear modeling while maintaining computational efficiency. The method can also be extended to nonlinear settings using kernel functions.

## Key Results
- tLSSVM-MTL outperforms existing matrix-based and tensor-based MTL methods in terms of prediction accuracy
- The method demonstrates better computational efficiency compared to alternative approaches
- Experimental validation on both synthetic and real-world datasets confirms the effectiveness of the tensorized approach

## Why This Works (Mechanism)

### Mechanism 1
CP decomposition allows shared and task-specific latent factors to be modeled simultaneously in a tensorized multitask regression framework. The weight tensor is factorized as a sum of rank-one components, where the shared factor L captures common information across all tasks, and the task-specific factors Un encode variations along each index. This structure enables exploitation of task correlations while preserving task individuality. Core assumption: Low CP rank (K) is sufficient to capture the essential task relationships without overfitting.

### Mechanism 2
Alternating minimization with dual linear systems efficiently optimizes the nonconvex tensorized LSSVM problem. By fixing all but one factor (L or Un), each subproblem becomes convex and is solved via a linear system in the dual, enabling tractable updates despite the overall nonconvexity. Core assumption: Block coordinate descent converges to a good local minimum for this problem structure.

### Mechanism 3
Tensor representation with multiple indices captures richer task relationships than single-index methods. Tasks referenced by multiple indices (e.g., food rating and customer group) are naturally embedded in a high-order tensor, preserving structural task-relations that single-index representations cannot. Core assumption: Real-world tasks often have multiple relevant indexing dimensions, justifying the tensor formulation.

## Architecture Onboarding

- Component map: Weight tensor W (dh × T1 × ... × TN) -> Shared factor L (dh × K) and Task-specific factors Un (Tn × K) for each mode n -> Kernel function k(·,·) (optional) -> Alternating optimization loop

- Critical path:
  1. Construct weight tensor from multitask data
  2. Initialize factors L and Un
  3. Alternate between updating L (solve linear system for all tasks) and each Un (solve linear system for tasks in that mode)
  4. Check convergence (relative change in factors < 1e-3)
  5. Make predictions using primal or kernelized expression

- Design tradeoffs:
  - CP rank K vs. model capacity and overfitting
  - Explicit feature mapping vs. kernel trick (memory vs. flexibility)
  - Number of modes N vs. data availability and interpretability

- Failure signatures:
  - Slow or stalled convergence in alternating updates
  - Overfitting indicated by poor test performance despite good training fit
  - Numerical instability in solving large linear systems (ill-conditioned Q matrices)

- First 3 experiments:
  1. Synthetic data with known CP structure: Verify recovery of shared and task-specific factors at different SNRs.
  2. Real multitask regression (e.g., restaurant ratings): Compare prediction accuracy (RMSE, Q2, correlation) against matrix-based MTL methods.
  3. Ablation study: Remove CP factorization (use full tensor) or shared factor to quantify their contribution.

## Limitations
- The alternating optimization approach may converge to local minima depending on initialization
- CP rank selection remains heuristic, potentially affecting model capacity and generalization
- Scalability to very high-dimensional tasks and large numbers of modes requires further investigation

## Confidence
- High: The core mechanism of CP decomposition enabling shared and task-specific factor modeling is well-supported by the mathematical formulation and experimental results.
- Medium: The computational efficiency claims rely on alternating linear systems, but convergence guarantees and comparison with other optimization methods need more rigorous analysis.
- Medium: The superiority over matrix-based MTL methods is demonstrated empirically, but the advantage in cases with weak task correlations remains unclear.
