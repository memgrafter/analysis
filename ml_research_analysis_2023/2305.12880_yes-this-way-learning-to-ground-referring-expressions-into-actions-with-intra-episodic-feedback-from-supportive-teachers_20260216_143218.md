# Yes, this Way! Learning to Ground Referring Expressions into Actions with Intra-episodic Feedback from Supportive Teachers

## Quick Facts
- arXiv ID: 2305.12880
- Source URL: https://arxiv.org/abs/2305.12880
- Reference count: 27
- Key outcome: Intra-episodic feedback improves follower success rate from 61.94% to 91.39% on complex test tasks with 12-18 pieces

## Executive Summary
This paper investigates using intra-episodic feedback from a teacher to improve a follower's ability to ground referring expressions into actions in a collaborative task. The authors frame this as a reinforcement learning problem in a controlled Pentomino environment, where a teacher provides initial referring expressions and monitors the follower's actions to deliver corrective feedback. Their results demonstrate that intra-episodic feedback enables better generalization to more complex scenes compared to only providing the initial statement.

## Method Summary
The authors train a follower agent using Proximal Policy Optimization (PPO) in a Minigrid-like environment with Pentomino pieces. The teacher generates unambiguous referring expressions using the Incremental Algorithm and provides feedback based on the follower's actions when the gripper moves beyond a distance threshold or hovers over pieces. The follower's policy network conditions visual features on language inputs (initial expression and feedback) using FiLM modulation, learning to associate action sequences with success through sparse rewards and teacher feedback.

## Key Results
- Follower with intra-episodic feedback achieves 91.39% success rate on test tasks with 12-18 pieces
- Follower without feedback achieves only 61.94% success rate on same complex tasks
- Property order in initial expressions affects learning success, with positional attributes performing best
- Agent successfully grounds both initial referring expressions and feedback into actions despite sparse rewards

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Intra-episodic feedback allows the follower to learn faster and generalize better to complex scenes
- Mechanism: Teacher provides corrective feedback during episodes based on follower's actions, helping associate actions with success/failure
- Core assumption: Follower can ground feedback language meaning into policy through interaction alone
- Evidence anchors: Results show feedback improves performance on larger maps, more pieces, and new target pieces

### Mechanism 2
- Claim: Teacher's property order in initial referring expressions affects follower learning success
- Mechanism: Incremental Algorithm generates expressions based on preference order over object properties; follower learns to prioritize properties based on order
- Core assumption: Follower can extract and prioritize information from expression based on property order
- Evidence anchors: Results show orders prioritizing positional attributes perform better; follower picks up positional clues early

### Mechanism 3
- Claim: Follower learns to ground initial expression and feedback into actions without direct reward ties
- Mechanism: Policy network takes visual observations, gripper position, initial expression, and feedback as input; learns action associations through sparse rewards and feedback
- Core assumption: Follower can ground language into actions through sparse reward signal and feedback
- Evidence anchors: Policy architecture explicitly conditions on language inputs; learns action distributions from combined inputs

## Foundational Learning

- Concept: Reinforcement Learning (RL) with sparse rewards
  - Why needed here: Follower needs to learn policy mapping observations to actions with reward only at episode end
  - Quick check question: How does follower learn from sparse rewards?

- Concept: Incremental Algorithm (IA) for referring expression generation
  - Why needed here: Teacher needs to generate unambiguous expressions that uniquely identify target piece
  - Quick check question: How does IA generate unambiguous referring expressions?

- Concept: Feature-wise Linear Modulation (FiLM) for language-conditioned visual features
  - Why needed here: Follower's policy network needs to condition visual features on language input
  - Quick check question: How does FiLM condition visual features on language?

## Architecture Onboarding

- Component map: Teacher -> Environment -> Follower -> Encoder -> Policy Network
- Critical path: 1) Teacher generates initial referring expression 2) Follower takes actions based on observations and language 3) Teacher provides feedback based on follower's actions 4) Follower learns from sparse rewards and feedback 5) Follower generalizes to complex scenes
- Design tradeoffs: Heuristic teacher vs. learned teacher policy; IA vs. learned language generation; FiLM vs. other language-conditioning methods
- Failure signatures: Follower fails to ground language into actions; fails to learn from sparse rewards; fails to generalize; teacher fails to generate unambiguous expressions
- First 3 experiments: 1) Train with different IA preference orders and measure success rate 2) Train with/without intra-episodic feedback and measure success/generalization 3) Train on complex scenes and measure success/generalization

## Limitations
- Teacher feedback mechanism relies on hand-crafted rules with fixed thresholds rather than learned optimization
- Property ordering in Incremental Algorithm is fixed during training without exploration of adaptive ordering
- Generalization claims based on synthetic scene complexity increases that may not reflect real-world challenges

## Confidence
**High Confidence**: Intra-episodic feedback improves success rates compared to initial statement alone (91.39% vs 61.94% on complex test tasks)

**Medium Confidence**: Property order in initial expressions affects learning success, dependent on specific heuristic algorithm

**Medium Confidence**: Agent grounds feedback language into actions, but mechanism relies on fixed teacher rules rather than demonstrating true language understanding

## Next Checks
