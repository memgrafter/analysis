# Learnt Deep Hyperparameter selection in Adversarial Training for compressed video enhancement with perceptual critic

## Quick Facts
- arXiv ID: 2302.14516
- Source URL: https://arxiv.org/abs/2302.14516
- Reference count: 0
- Key outcome: Up to 10% (FID) and 15% (KID) performance increase using selected EfficientNetB3 layers in critic

## Executive Summary
This paper introduces a novel method for selecting perceptually relevant layers from a pre-trained image classification network to enhance compressed video quality using adversarial training. The approach uses representational dissimilarity matrices (RDMs) to identify which layers of EfficientNetB3 best capture perceptual differences between compressed and clean video patches. These selected layers are then used as hyperparameters in a Wasserstein-GAN critic, resulting in improved perceptual quality metrics compared to standard critic architectures.

## Method Summary
The method involves selecting layers from EfficientNetB3 based on their ability to distinguish compressed from clean patches using RDMs. Layers 0 and 3 are identified as most perceptually relevant. These layers are then used in a PatchGAN-style critic for a W-GAN trained to enhance compressed video. The generator uses a UNet architecture with motion vector concatenation and is trained with a weighted loss combining adversarial and MSE terms, where the weight Λ balances perceptual quality against pixel-level accuracy.

## Key Results
- 10% improvement in FID scores compared to critic networks without optimized feature selection
- 15% improvement in KID scores with the proposed layer selection method
- Demonstrated reduction in computational complexity by using only 2 layers instead of full network features
- Effective mitigation of hallucination artifacts through weighted MSE regularization

## Why This Works (Mechanism)

### Mechanism 1
Selecting layers based on representational dissimilarity matrices (RDMs) improves the critic's ability to distinguish compressed vs. clean patches. RDMs measure how well each layer's activations can predict dissimilarity between compressed and clean patches. Layers with high RDM correlation weights are chosen because their features encode perceptual information invariant to compression artifacts. Core assumption: Perceptual differences between compressed and clean patches are preserved in certain intermediate layers of a classification network. Break Condition: If compression artifacts do not manifest as perceptually relevant features in EfficientNetB3's internal representations, the RDM method would select irrelevant layers.

### Mechanism 2
Using only perceptually relevant features reduces critic complexity while maintaining performance. By filtering EfficientNetB3's outputs to only layers 0 and 3, the critic processes fewer features but focuses on those most correlated with human perceptual judgments. This reduces computational load and prevents the critic from being distracted by non-perceptual features. Core assumption: Not all features from a classification network are equally useful for perceptual quality assessment. Break Condition: If compression artifacts affect features across all layers uniformly, selecting only 2 layers might discard useful information and hurt performance.

### Mechanism 3
The weighted MSE term (Λ) in the generator loss balances perceptual quality with reconstruction accuracy. The generator is trained with both adversarial loss (from the critic) and a weighted MSE term. Lower Λ emphasizes perceptual fidelity (more detail), while higher Λ emphasizes pixel-level accuracy (better color matching). Core assumption: Pure adversarial training without MSE regularization leads to hallucination artifacts. Break Condition: If the critic is already strong enough to enforce realistic outputs, the MSE term might be unnecessary and could reduce perceptual quality.

## Architecture Onboarding

- Component map: Generator UNet -> Motion vector concatenation -> I-frame feature integration -> Restoration parameter guidance; Critic PatchGAN -> EfficientNetB3 layers 0,3; Feature selector RDM-based method

- Critical path: 1) Extract EfficientNetB3 features from reference and compressed patches 2) Compute RDMs and select top layers (0 and 3) 3) Train generator with MSE loss only 4) Train critic using selected features 5) Adversarial training with weighted loss (Λ balancing MSE and perceptual terms)

- Design tradeoffs:
  - Layer selection vs. using all features: Fewer features reduce computation but risk losing information
  - Λ weight tuning: Higher values improve pixel accuracy but reduce perceptual detail
  - Motion vector usage: Improves temporal coherence but adds complexity

- Failure signatures:
  - Streaking artifacts: Indicates critic (Ct) without EfficientNetB3 features is insufficient
  - Over-smoothing: Suggests MSE weight (Λ) is too high
  - Color mismatch: Indicates Λ is too low, prioritizing detail over color accuracy

- First 3 experiments:
  1. Compare critic variants (Copt, C5,6, Ct) on a small validation set to verify layer selection improves performance
  2. Sweep Λ values (0.1, 10, 1000) to find optimal balance between detail and color accuracy
  3. Test RDM selection on a different classification network (e.g., VGG) to validate the approach's generalizability

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of the proposed method scale with larger datasets and more diverse video content? The paper uses a dataset with 2649 degraded/reference pairs and 99 reference patches for feature selection. It is unclear how the method would perform in real-world scenarios with a wider variety of videos.

### Open Question 2
What is the impact of using different pre-trained classification networks (other than EfficientNetB3) for feature selection and critic network input? The paper does not investigate the performance of the method when using different pre-trained classification networks.

### Open Question 3
How does the proposed method perform in terms of subjective perceptual quality compared to traditional metrics like PSNR and SSIM? The paper reports performance in terms of FID and KID but does not conduct a subjective study to validate the perceptual quality of the generated patches.

## Limitations

- Performance scaling with larger, more diverse datasets remains untested
- Computational efficiency benefits are demonstrated but not quantified in terms of actual inference time savings
- Layer selection mechanism effectiveness depends on compression artifacts manifesting as perceptually relevant features in the chosen classification network

## Confidence

- Layer selection mechanism: Medium
- Computational efficiency claims: Low
- Generalization across datasets: Low
