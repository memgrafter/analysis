# Robust-DefReg: A Robust Deformable Point Cloud Registration Method based on Graph Convolutional Neural Networks

## Quick Facts

- Reference count: 33

## Executive Summary
Robust-DefReg is a novel non-rigid point cloud registration method that combines Graph Convolutional Neural Networks (GCNN), T-Net, and Loopy Belief Propagation (LBP) to address challenges like deformation, noise, outliers, and data incompleteness. The method employs a coarse-to-fine pipeline that first aligns point clouds using learned global features, then refines correspondences through iterative displacement updates. Experimental results demonstrate superior registration accuracy compared to existing methods, particularly in scenarios involving large deformations, while maintaining computational efficiency suitable for practical applications.

## Method Summary
Robust-DefReg is an end-to-end point cloud registration pipeline that processes input point clouds through multiple stages. First, T-Net applies spatial transformations to normalize input coordinates. Then, EdgeConv layers extract 64-dimensional feature descriptors from k-NN graphs. These features enable k-NN correspondence finding between source and target point clouds, with displacement costs computed as Euclidean distances between feature vectors. Finally, Loopy Belief Propagation with 3 iterations refines the displacement candidates by incorporating spatial relationships between neighboring points. The method is trained end-to-end using Adam optimizer with learning rate 1e-4 and L1 loss, processing one point cloud pair per batch with instance normalization.

## Key Results
- Achieves better registration accuracy than state-of-the-art methods, particularly for large deformations
- Demonstrates robustness to noise, outliers, and data incompleteness while maintaining computational efficiency
- Provides a unified framework that combines coarse and fine alignment strategies within a single pipeline
