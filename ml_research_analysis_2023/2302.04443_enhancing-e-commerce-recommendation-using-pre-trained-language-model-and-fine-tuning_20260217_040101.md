# Enhancing E-Commerce Recommendation using Pre-Trained Language Model and Fine-Tuning

## Quick Facts
- arXiv ID: 2302.04443
- Source URL: https://arxiv.org/abs/2302.04443
- Reference count: 9
- This paper investigates incorporating pre-trained language models (PLMs) into traditional recommender systems for e-commerce.

## Executive Summary
This paper explores enhancing e-commerce recommendation systems by incorporating pre-trained language models, specifically RoBERTa, with traditional collaborative filtering methods. The authors combine RoBERTa with matrix factorization and XGBoost algorithms, investigating different fine-tuning strategies including domain adaptive pretraining (DAPT) and task adaptive pretraining (TAPT). Experiments show that RoBERTa consistently improves predictive capability across both recommender algorithms, with the best performance achieved through a combination of MLM and TSDAE pretraining. The study demonstrates that XGBoost benefits more significantly from PLM embeddings than matrix factorization.

## Method Summary
The method combines RoBERTa sentence embeddings with traditional recommender systems (matrix factorization and XGBoost) to enhance e-commerce recommendations. The approach involves preprocessing e-commerce datasets, fine-tuning RoBERTa using various strategies (MLM, TSDAE, DAPT, TAPT), generating sentence embeddings from product descriptions, and integrating these embeddings with baseline models. The authors evaluate performance using accuracy, precision, recall, F1 score, and MAP metrics, comparing enhanced models against vanilla implementations.

## Key Results
- RoBERTa embeddings consistently improve model performance regardless of the underlying recommender algorithm
- XGBoost recommender benefits more from PLM introduction than matrix factorization recommender
- MLM followed by TSDAE pretraining achieves the best performance increase
- Domain and task adaptive pretraining together outperforms individual pretraining approaches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: PLMs like RoBERTa improve recommendation performance by capturing rich textual semantics from item descriptions that traditional models ignore.
- Mechanism: RoBERTa generates high-dimensional sentence embeddings encoding nuanced product features, which are combined with user-item interaction features in XGBoost, enriching the feature space beyond pure collaborative signals.
- Core assumption: Textual descriptions contain complementary information to interaction data that boosts predictive accuracy.
- Evidence anchors: [abstract] Traditional recommendation algorithms failed to incorporate rich textual information; [section V-A] Vocabulary overlap analysis shows ~50% overlap between retail and Amazon descriptions; [corpus] Weak—only FMR and neighbor titles provided.

### Mechanism 2
- Claim: Domain-Adaptive Pretraining (DAPT) and Task-Adaptive Pretraining (TAPT) further improve RoBERTa embeddings for e-commerce recommendation.
- Mechanism: DAPT (using Amazon corpus) tunes RoBERTa to e-commerce vocabulary; TAPT (using retail descriptions) adapts it to the specific task. Combined, they produce embeddings more aligned with both domain and task semantics.
- Core assumption: RoBERTa pretrained on general web text lacks e-commerce-specific phrase knowledge; domain adaptation fills this gap.
- Evidence anchors: [section V-B] Effect of using both adaptation techniques together; [section VI] MLM followed by TSDAE achieves better performance; [corpus] Weak—no explicit vocabulary similarity statistics.

### Mechanism 3
- Claim: XGBoost benefits more from PLM embeddings than matrix factorization because it can leverage high-dimensional, heterogeneous features without suffering from the same sparsity constraints.
- Mechanism: XGBoost natively handles sparse inputs and feature interactions, so it can directly ingest both interaction-based features and dense embeddings. Matrix factorization struggles because it projects into a low-rank latent space that may lose embedding detail.
- Core assumption: MF's low-rank factorization compresses information too aggressively when combined with high-dimensional embeddings.
- Evidence anchors: [abstract] RoBERTa consistently increases model performance; [section IV] MF cannot directly incorporate embeddings while XGBoost can; [corpus] Weak—corpus neighbors mention "Encoding embeddings."

## Architecture Onboarding

- Component map: Data preprocessing -> RoBERTa (base) -> Optional DAPT/TAPT (MLM/TSDAE) -> Sentence embeddings -> Feature engineering (XGBoost or MF) -> Recommendation model -> Evaluation
- Critical path: Text descriptions -> RoBERTa fine-tuning -> Embeddings -> XGBoost features -> Predictions
- Design tradeoffs:
  - RoBERTa embeddings increase model complexity and GPU memory; simpler models (like TF-IDF) are lighter but less expressive
  - DAPT/TAPT order (TAPT→MLM vs MLM→TAPT) can change performance; must tune per dataset
  - MF cannot directly use embeddings without lossy combination; XGBoost can, but risks overfitting
- Failure signatures:
  - Low precision/recall on rare items -> embeddings not capturing niche semantics
  - XGBoost overfitting -> too many features relative to samples; consider feature selection or regularization
  - MF performance drop -> embeddings added but latent factor space cannot represent them; try concatenation instead of weighted sum
- First 3 experiments:
  1. Run vanilla XGBoost on user-item interaction features only; record baseline metrics
  2. Add RoBERTa embeddings (no fine-tuning) to XGBoost features; compare performance
  3. Apply TAPT on retail descriptions, generate embeddings, add to XGBoost; evaluate improvement

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the effectiveness of incorporating PLMs into traditional recommender systems vary across different e-commerce domains and datasets?
- Basis in paper: [explicit] The paper mentions that vocabulary similarity between Amazon and retail datasets is comparably low, which might compromise domain-specific pretraining effectiveness. It also states that larger, more structurally similar datasets could investigate the full potential of this pretraining method.
- Why unresolved: The paper only explores one e-commerce dataset, so results may not be generalizable to other domains with different characteristics.
- What evidence would resolve it: Conducting experiments on multiple e-commerce datasets from different domains and comparing results would provide evidence on generalizability.

### Open Question 2
- Question: How does the performance of PLM-enhanced recommender systems compare to deep learning-based recommender systems?
- Basis in paper: [inferred] The paper mentions that more state-of-the-art deep learning-based recommendation algorithms could be used as the recommendation model, and exploring benefits of PLMs on deep learning-based recommender systems will be an interesting future direction.
- Why unresolved: The paper focuses on traditional recommenders (MF and XGBoost) and does not compare PLM-enhanced systems to deep learning approaches.
- What evidence would resolve it: Conducting experiments comparing PLM-enhanced recommender systems to deep learning-based systems on the same e-commerce datasets would provide evidence on their relative effectiveness.

### Open Question 3
- Question: How does the order of pretraining phases (domain-adaptive pretraining and task-adaptive pretraining) affect the performance of PLM-enhanced recommender systems?
- Basis in paper: [explicit] The paper investigates the effect of using both DAPT and TAPT together and observes the effect of manipulating the order of different pretraining phases, showing that combining domain- and task-adaptive pretraining achieves better performance.
- Why unresolved: The paper only explores two different orders (T→M and M→T) and their combination (D→T), not investigating other possible orders or combinations.
- What evidence would resolve it: Conducting experiments on different orders and combinations of pretraining phases and comparing their performance on e-commerce datasets would provide evidence on the optimal pretraining strategy.

## Limitations
- Exact hyperparameters for RoBERTa fine-tuning (learning rate, batch size, epochs) are not specified, making direct reproduction difficult
- Method for combining sentence embeddings with matrix factorization is vaguely described as "weighted sum" without detailing the weighting mechanism
- Vocabulary overlap analysis shows only ~50% overlap between retail and Amazon descriptions, suggesting domain adaptation may be critical but effectiveness is not quantified

## Confidence

- High confidence: RoBERTa embeddings improve XGBoost performance over baseline collaborative filtering. Experimental results show consistent improvements across multiple datasets and the mechanism is well-supported.
- Medium confidence: Domain-adaptive pretraining (DAPT + TAPT) provides measurable benefits. While the paper shows MLM→TSDAE ordering performs best, the general claim that adaptation helps is reasonable but needs more rigorous ablation.
- Low confidence: Matrix factorization benefits from RoBERTa embeddings. The paper claims improvements but MF's inability to naturally incorporate high-dimensional embeddings suggests any gains may be limited or require specific implementation details not fully disclosed.
