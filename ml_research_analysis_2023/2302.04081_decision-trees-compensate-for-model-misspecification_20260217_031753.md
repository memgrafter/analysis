# Decision trees compensate for model misspecification

## Quick Facts
- arXiv ID: 2302.04081
- Source URL: https://arxiv.org/abs/2302.04081
- Authors:
- Reference count: 6
- Key outcome: Interpretable multiresponse GLMs and mixture GLMs match GBM performance while reducing model complexity

## Executive Summary
This paper challenges the common belief that deep trees in gradient boosting machines (GBMs) primarily model interactions. Instead, the authors propose that tree depth compensates for various forms of model misspecification, including insufficient training, incorrect linkages, composite responses, heterogeneous populations, and missing features. Through five synthetic scenarios, they demonstrate how deeper trees can implicitly address these issues without requiring explicit modeling. The paper introduces two interpretable alternatives—multiresponse GLMs and mixture GLMs—that achieve comparable performance to deep GBMs while maintaining interpretability and reducing model complexity.

## Method Summary
The authors generate five synthetic datasets demonstrating different forms of model misspecification, then train XGBoost models with varying depths (1-3) and compare their performance to interpretable alternatives. The multiresponse GLM approach uses S=3 submodels to explicitly model composite responses, while the mixture GLM approach uses S=2 components to handle population heterogeneity. Both methods employ gradient descent optimization to fit the parameters. Performance is evaluated using RMSE and MAE metrics across different tree depths and model types.

## Key Results
- Multiresponse GLMs with three submodels achieve RMSE of 2.74 on synthetic data, comparable to depth-3 GBMs (RMSE 2.77)
- Interpretable models use significantly fewer parameters (27 vs 256 for equivalent linear models)
- Depth-3 GBMs outperform simpler models in scenarios with heterogeneous populations, but multiresponse approaches come close
- The interpretable alternatives provide full model transparency while maintaining competitive performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Trees compensate for insufficient training by using depth to model the same patterns with fewer splits per tree.
- Mechanism: When gradient boosting is undertrained (low learning rate, few trees), individual trees must capture more complexity to compensate. Higher tree depth allows each tree to model more intricate patterns, reducing the overall number of trees needed for good performance.
- Core assumption: The dataset contains patterns that can be modeled with additive effects, but the model is undertrained relative to the true complexity.
- Evidence anchors:
  - [abstract] "They confirm 5 alternative hypotheses about the role of tree depth in performance in the absence of true interactions"
  - [section] "When other hyperparameters result in undertraining, increasing the tree-depth will make the model less underfit, even if there are no interactions to model"
  - [corpus] No direct corpus evidence found for this specific mechanism
- Break condition: When the model is sufficiently trained (high learning rate, many trees), additional depth provides no benefit and may increase overfitting risk.

### Mechanism 2
- Claim: Trees compensate for incorrect linkages by using depth to implicitly transform the response structure.
- Mechanism: When the assumed link function doesn't match the true data generating process (e.g., using additive instead of multiplicative effects), deeper trees can approximate the correct transformation through sequential partitioning, effectively learning the appropriate link function implicitly.
- Core assumption: The true relationship between features and response involves multiplicative or non-linear effects that don't match the assumed additive link.
- Evidence anchors:
  - [abstract] "Part of the success of tree models is due to their robustness to various forms of mis-specification"
  - [section] "An additive (unity-linked) model would need tree-depth > 1 to fully model price. Start with $100, add $100 for blueness, add $200 for largeness, and add a further $200 for the interaction of blueness and largeness. But our effects are not additive"
  - [corpus] No direct corpus evidence found for this specific mechanism
- Break condition: When the correct link function is known and applied, simpler models with appropriate links should match or exceed deep tree performance.

### Mechanism 3
- Claim: Trees compensate for composite responses by using depth to implicitly separate sub-processes.
- Mechanism: When the observed response is a sum of multiple independent Poisson processes, deep trees can learn to partition the feature space such that each partition primarily contains one sub-process, effectively separating the mixed response without explicit modeling.
- Core assumption: The response variable is actually a composite of multiple independent generating processes that sum to the observed value.
- Evidence anchors:
  - [abstract] "We present two methods for robust generalized linear models (GLMs) addressing the composite and mixed response scenarios"
  - [section] "Consider a composite multiplicative process... Use the result as the λ for a Poisson generator, and take the output as response A. Repeat the process with the same coin results with different permutations of the doubling and halving indicators to get response B and C"
  - [corpus] No direct corpus evidence found for this specific mechanism
- Break condition: When the number of sub-processes is known and can be explicitly modeled using multi-response GLMs, the simpler approach should match or exceed tree performance.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the improved performance of deeper trees primarily come from better handling of mis-specification rather than true interaction modeling?
- Basis in paper: [explicit] The authors explicitly state that "interactions cannot fully account for the depth of trees found in practice" and propose five alternative hypotheses about the role of tree depth in performance in the absence of true interactions.
- Why unresolved: While the authors demonstrate through synthetic scenarios that trees can compensate for various forms of mis-specification, they don't definitively prove that this is the primary reason for deep trees' success in real-world datasets. The relationship between mis-specification robustness and performance gains could vary by dataset characteristics.
- What evidence would resolve it: A comprehensive empirical study comparing tree performance on datasets with controlled levels of mis-specification (missing features, heterogeneous populations, etc.) versus datasets with true interactions would help determine which factor drives performance gains.

### Open Question 2
- Question: How do the proposed interpretable alternatives (multiresponse GLMs and mixture GLMs) perform on high-dimensional real-world datasets with hundreds of features?
- Basis in paper: [inferred] The authors note that "the typical dataset used in an industry modelling task has hundreds of explanatory columns conveying millions of bits of information" and suggest that multiresp models and mixture GLMs are unlikely to be useful in such cases due to interpretability constraints.
- Why unresolved: The experiments presented focus on synthetic datasets with binary features and limited dimensionality. The scalability and effectiveness of these methods on real-world high-dimensional data remains untested.
- What evidence would resolve it: Testing multiresponse GLMs and mixture GLMs on benchmark high-dimensional datasets (like those used in Kaggle competitions) would reveal whether these methods can maintain competitive performance while providing interpretability benefits.

### Open Question 3
- Question: Is there a systematic way to determine when a dataset contains mis-specification that could be addressed by interpretable alternatives versus when true interactions are present?
- Basis in paper: [explicit] The authors propose five scenarios where tree depth compensates for mis-specification, but don't provide a framework for diagnosing which scenario applies to a given dataset.
- Why unresolved: The paper demonstrates that mis-specification can be a significant factor, but practitioners need practical guidance on identifying when their dataset exhibits these characteristics and when simpler interpretable models might suffice.
- What evidence would resolve it: Developing diagnostic tools or statistical tests that can detect the presence of composite responses, heterogeneous populations, missing features, or incorrect linkages in real datasets would enable practitioners to make informed decisions about model complexity.

## Limitations

- Reliance on synthetic data rather than real-world datasets may not capture practical application complexity
- Exact implementation details for synthetic data generators and optimization procedures are not fully specified
- Limited testing of multiresponse GLM approach with only S=3 submodels, suggesting potential need for higher values in some cases

## Confidence

- High confidence: The hypothesis that trees compensate for insufficient training through depth is well-supported by experimental results showing consistent performance improvements with increased depth when learning rates are low
- Medium confidence: The mechanism of depth compensating for incorrect linkages is supported by synthetic examples, but generalizability to real-world scenarios requires further validation
- Medium confidence: The multiresponse GLM approach shows promise for composite responses, but limited testing with only S=3 submodels suggests there may be cases where higher values of S are needed
