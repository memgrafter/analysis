# InterFormer: Interactive Local and Global Features Fusion for Automatic Speech Recognition

## Quick Facts
- arXiv ID: 2305.16342
- Source URL: https://arxiv.org/abs/2305.16342
- Authors: 
- Reference count: 0
- Key outcome: InterFormer achieves 0.2% CER improvement on Aishell-1 and 0.4-1.5% WER improvement on Librispeech over baseline Transformer and Conformer models

## Executive Summary
This paper proposes InterFormer, a parallel architecture combining convolution and transformer branches with bidirectional feature interaction modules (BFIM) and selective fusion modules (SFM) for automatic speech recognition. The method aims to improve local and global feature fusion compared to existing serial architectures. Experimental results show InterFormer achieves superior performance over baseline Transformer and Conformer models, with a 0.2% improvement in character error rate on Aishell-1, and 0.4-1.5% improvement in word error rate on Librispeech.

## Method Summary
InterFormer uses a parallel architecture with convolution and transformer branches connected by bidirectional feature interaction modules (BFIM) and selective fusion modules (SFM). The convolution branch captures local features using depthwise convolutions and dynamic ReLU activation, while the transformer branch captures global features using multi-head self-attention with relative positional encoding. BFIM enables information exchange between branches in both directions (local-to-global and global-to-local), while SFM dynamically weights and combines features from both branches using attention mechanisms and channel attention. The model is trained using ESPNet with Adam optimizer, warm-up, label smoothing, and dropout.

## Key Results
- 0.2% improvement in character error rate on Aishell-1 dataset
- 0.4-1.5% improvement in word error rate on Librispeech dataset
- Superior performance compared to baseline Transformer and Conformer models

## Why This Works (Mechanism)

### Mechanism 1
Parallel convolution and transformer branches with bidirectional interaction capture complementary local and global features more effectively than serial architectures. The InterFormer uses two parallel branches—convolution for local features and transformer for global features—connected by Bidirectional Feature Interaction Modules (BFIM) that allow information to flow both from convolution to transformer (L2G) and transformer to convolution (G2L). This creates a dynamic exchange where local features can enhance global context and global context can refine local details.

### Mechanism 2
Dynamic ReLU activation in the convolution branch, informed by global features, enables adaptive interaction between local and global representations. The dynamic ReLU activation function uses global features (G) from the transformer branch to modulate the activation parameters, creating a context-aware transformation that adapts based on global information rather than using static activation functions.

### Mechanism 3
Selective Fusion Module (SFM) dynamically weights and combines local and global features based on their relative importance at different time steps and layers. SFM uses a softmax-based attention mechanism to learn selective factors that determine how much of the local versus global features to retain, followed by channel attention through Squeeze-and-Excitation to further refine the fusion.

## Architecture Onboarding

- **Component map**: Input → 2D-CNN subsampling → Positional embedding → N InterFormer blocks → Output
- **Critical path**: Data flows through parallel branches simultaneously, with BFIM modules enabling information exchange between branches, and SFM modules fusing the processed features before passing to the next block
- **Design tradeoffs**: Parallel design increases computational cost compared to serial Conformer, but enables better feature interaction; dynamic components (ReLU, attention) add complexity but improve adaptation
- **Failure signatures**: If one branch consistently dominates (SFM attention weights become unbalanced), if training becomes unstable (dynamic components causing gradient issues), or if performance plateaus despite increased complexity
- **First 3 experiments**:
  1. Remove BFIM modules and compare to baseline to verify interaction contribution
  2. Replace SFM with simple addition/concatenation to validate fusion effectiveness
  3. Replace dynamic ReLU with standard ReLU to test activation function impact
