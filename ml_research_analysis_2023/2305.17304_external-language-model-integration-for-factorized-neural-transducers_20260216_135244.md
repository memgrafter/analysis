# External Language Model Integration for Factorized Neural Transducers

## Quick Facts
- arXiv ID: 2305.17304
- Source URL: https://arxiv.org/abs/2305.17304
- Reference count: 0
- Primary result: Average gains of 18% WERR with lexical adaptation across various scenarios and up to 60% WERR in one entity-rich scenario

## Executive Summary
This paper proposes methods for adapting factorized neural transducers (FNT) to target domains using external language models. The key insight is that FNT's predictor naturally behaves like a language model, making linear interpolation with external LMs more effective than shallow fusion. The authors demonstrate significant improvements through lexical adaptation with n-gram and neural LMs, and extend the approach to handle class-based LMs for structured entity-rich scenarios.

## Method Summary
The paper proposes linear/log-linear interpolation of predictor outputs with external n-gram and neural language models during beam search decoding. This exploits FNT's factorized predictor structure, which separately models blank and non-blank probabilities with the non-blank branch acting as an internal language model. For class-based scenarios, the method integrates class-based n-gram LMs using prefix trees and specialized transitions to handle entity structures. The approach includes optimization techniques like conditional interpolation that queries n-gram LMs only for high-probability words to balance accuracy and speed.

## Key Results
- Average gains of 18% WERR with lexical adaptation across various scenarios
- Up to 60% WERR in one entity-rich scenario using class-based n-gram and neural LMs
- Linear interpolation significantly outperforms shallow fusion for FNT adaptation
- Conditional linear interpolation with n-gram LMs achieves ~20% slowdown with rank 200

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Linear interpolation with external LMs is more effective than shallow fusion because FNT forces the predictor to behave like a language model, making interpolation in probability space more natural and effective.
- Core assumption: The predictor's behavior as an internal LM is sufficiently similar to external LMs to make linear interpolation meaningful.
- Evidence anchors:
  - [abstract] "demonstrate that both neural and n-gram external LMs add significantly more value when linearly interpolated with predictor output compared to shallow fusion"
  - [section 2] "Since the predictor in FNT behaves like an LM [20], it can be adapted to the target domain by interpolating with an external LM"

### Mechanism 2
- Claim: Class-based LM integration extends FNT's interpolation capability to structured entity-rich scenarios by defining specialized transitions that preserve class structure during beam search.
- Core assumption: The beam search can effectively manage the increased state space complexity introduced by class-based transitions.
- Evidence anchors:
  - [section 2.2] "For n-gram models, LM states s are short sequences (histories) of previous tokens... With CLM trained on sentences tagged in terms of classes, its states s now include not just previous token historyh (with tokens being words or classes), but also current position (node) p in the prefix tree of the active class c"
  - [section 2.2] "Fig. 2 shows an example of such transitions"

### Mechanism 3
- Claim: Conditional linear interpolation with n-gram LMs achieves speed-accuracy tradeoff by selectively biasing only high-probability words from the external model.
- Core assumption: High-probability words from the external LM are the most important for adaptation, and lower-probability words don't significantly impact accuracy.
- Evidence anchors:
  - [section 2.1] "we employ several optimization techniques to speed up interactions with n-grams LMs. In addition to extensive caching, we do not consult external n-gram LMs for all words in a given context but just for the ones with reasonably high probabilities (e.g. up to a certain rank r in a sorted list)"
  - [section 2.1] "With this approximation and r = 200, we observe only ≈ 20% slow-down during inference due to interpolation with medium-sized n-grams models"

## Architecture Onboarding

- Component map: Audio input -> Encoder (18 transformer layers) -> Predictor (factored into blank and non-blank branches) -> External LM integration (neural or n-gram) -> Beam search decoder with augmented states -> Output sequence
- Critical path: Audio input → Encoder features → Predictor probabilities → External LM interpolation → Beam search → Output sequence
- Design tradeoffs: Linear interpolation vs. shallow fusion (accuracy vs. simplicity), n-gram vs. neural LM (speed vs. performance), full vs. conditional interpolation (accuracy vs. computational cost)
- Failure signatures: Degradation in structured scenarios with class-based LM suggests prefix tree management issues; poor performance with n-gram LMs suggests insufficient adaptation data; slow decoding indicates need for optimization of external LM queries
