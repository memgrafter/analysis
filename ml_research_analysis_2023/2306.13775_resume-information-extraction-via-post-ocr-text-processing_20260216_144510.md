# Resume Information Extraction via Post-OCR Text Processing

## Quick Facts
- arXiv ID: 2306.13775
- Source URL: https://arxiv.org/abs/2306.13775
- Reference count: 0
- Multi-stage approach combines OCR, object detection, and transformer-based text classification for automated resume parsing

## Executive Summary
This paper presents a multi-stage approach for extracting structured information from resume images by combining OCR technology with object detection and transformer-based text classification. The system preprocesses resume images using YOLOv8 to identify text blocks, applies EasyOCR for text extraction, and then classifies the extracted text using transformer models including BERT, DistilBERT, RoBERTa, and XLNet. The method achieves strong performance on a dataset of 286 labeled resumes across five categories, with DistilBERT achieving an F1-weighted score of 0.9748 while maintaining computational efficiency through fewer parameters.

## Method Summary
The approach processes resume images through three main stages: (1) YOLOv8 object detection identifies and segments text blocks within the resume image, (2) EasyOCR performs optical character recognition on each detected text block to extract textual content, and (3) transformer-based models (BERT, DistilBERT, RoBERTa, XLNet) classify the extracted text into predefined categories. This pipeline enables automated parsing of resume information while maintaining flexibility to handle various resume layouts and formats.

## Key Results
- DistilBERT achieves highest performance with F1-weighted score of 0.9748 among tested transformer models
- YOLOv8 object detection achieves mean average precision (mAP) of 0.8456 at IoU 0.5
- System successfully processes 286 labeled resumes across five predefined categories
- DistilBERT demonstrates superior efficiency with fewer parameters compared to BERT while maintaining high accuracy

## Why This Works (Mechanism)
The system works by leveraging the complementary strengths of different AI models for each stage of resume processing. YOLOv8 effectively identifies text regions within complex resume layouts, reducing the search space for OCR processing. EasyOCR then accurately extracts text from these localized regions, avoiding interference from background elements or decorative content. The transformer models, particularly DistilBERT, excel at understanding context and semantic relationships in the extracted text, enabling accurate classification into predefined categories despite variations in wording or formatting.

## Architecture Onboarding

Component Map:
Resume Image -> YOLOv8 Text Detection -> EasyOCR Text Extraction -> Transformer Classification -> Structured Output

Critical Path:
YOLOv8 detection -> EasyOCR extraction -> DistilBERT classification

Design Tradeoffs:
- YOLOv8 vs. other detection models: Balance between detection accuracy and computational efficiency
- EasyOCR vs. other OCR engines: Tradeoff between recognition accuracy and processing speed
- DistilBERT vs. full BERT: Performance versus parameter efficiency and inference speed

Failure Signatures:
- Poor YOLOv8 detection leads to missing or incorrect text regions for OCR
- EasyOCR errors propagate to classification stage, causing category misassignments
- Transformer models struggle with ambiguous or context-dependent text segments

## Limitations
- Evaluation conducted on relatively small dataset of 286 labeled resumes, limiting generalizability
- Performance metrics may not reflect real-world diversity in resume layouts, languages, and quality
- Pipeline may struggle with low-quality images, unusual fonts, or non-standard resume formats
- System assumes clean and well-structured text output from OCR, which may not always be realistic

## Confidence
- **High confidence**: The multi-stage methodology combining YOLOv8, EasyOCR, and transformer classification is technically sound and represents a valid approach to resume information extraction
- **Medium confidence**: Reported performance metrics are likely accurate for the specific dataset but may not generalize to diverse real-world resumes
- **Medium confidence**: DistilBERT's superior performance is supported by experimental results, but the significance across different resume types requires further validation
