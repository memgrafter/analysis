# Hawkes Process Based on Controlled Differential Equations

## Quick Facts
- arXiv ID: 2305.07031
- Source URL: https://arxiv.org/abs/2305.07031
- Reference count: 23
- Key outcome: HP-CDE model outperforms existing methods on 4 real-world datasets for event prediction and log-likelihood computation

## Executive Summary
This paper introduces a Hawkes process model based on controlled differential equations (HP-CDE) to address limitations of existing neural network-based Hawkes process models in handling irregular time-series data and computing exact log-likelihoods. The key innovation is leveraging neural controlled differential equations (neural CDEs) to model continuous occurrence dynamics and calculate exact log-likelihoods using ODE solvers. The model demonstrates superior performance on four real-world datasets, achieving higher accuracy and lower RMSE in event prediction tasks while providing better log-likelihood values. Ablation and sensitivity analyses confirm the effectiveness of the proposed method in handling irregular time-series data and computing exact log-likelihoods.

## Method Summary
The paper presents a Hawkes process model based on controlled differential equations (HP-CDE) that leverages neural controlled differential equations (neural CDEs) to model continuous occurrence dynamics and calculate exact log-likelihoods using ODE solvers. The model consists of an embedding layer, interpolation algorithm, neural CDE layer, ODE solver, and three prediction layers for event type, time, and log-likelihood. The method is trained on four real-world datasets (MIMIC, MemeTracker, Retweet, StackOverFlow) using maximum likelihood estimation and evaluated on event type prediction accuracy, event time prediction RMSE, and log-likelihood.

## Key Results
- HP-CDE outperforms existing methods by non-trivial margins on 4 real-world datasets
- Achieves higher accuracy and lower RMSE in event prediction tasks
- Provides better log-likelihood values compared to baseline methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Continuous modeling of intensity via neural CDE enables exact log-likelihood computation.
- Mechanism: The model represents the intensity function as a continuous-time function derived from the hidden state of a neural CDE. This continuous formulation allows the non-event log-likelihood integral to be computed exactly using an ODE solver.
- Core assumption: The hidden state trajectory from the neural CDE is differentiable and integrable over the event sequence time interval.
- Evidence anchors: [abstract] "Since HP-CDE continuously reads data, i) irregular time-series datasets can be properly treated preserving their uneven temporal spaces, and ii) the log-likelihood can be exactly computed."

### Mechanism 2
- Claim: Neural CDE's continuous-time processing is robust to irregular time intervals between events.
- Mechanism: Unlike RNN-based models that discretize time or use heuristic decay functions, neural CDE processes the time derivative of the interpolated path, naturally handling varying inter-arrival times without additional preprocessing.
- Core assumption: The interpolated path Z(t) from discrete events preserves the temporal structure needed for accurate dynamics modeling.
- Evidence anchors: [abstract] "Since HP-CDE continuously reads data, i) irregular time-series datasets can be properly treated preserving their uneven temporal spaces..."

### Mechanism 3
- Claim: Joint modeling of event type, time, and likelihood improves overall prediction accuracy.
- Mechanism: The model uses three separate prediction layers (event type, time, and log-likelihood) that share the continuous hidden representation from the neural CDE, allowing information to flow across tasks and improve learning of occurrence dynamics.
- Core assumption: The continuous hidden representation contains sufficient information to predict all three quantities accurately.
- Evidence anchors: [abstract] "Moreover, as both Hawkes processes and neural CDEs are first developed to model complicated human behavioral dynamics, neural CDE-based Hawkes processes are successful in modeling such occurrence dynamics."

## Architecture Onboarding

- Component map: Event sequence → Embedding → Interpolation → Neural CDE → Hidden state h(t) → ODE solver (non-event LL) + Prediction layers (event type, time, event LL)

- Critical path: Event sequence → Embedding → Interpolation → Neural CDE → Hidden state h(t) → ODE solver (non-event LL) + Prediction layers (event type, time, event LL)

- Design tradeoffs:
  - Continuous vs. discrete modeling: Continuous enables exact likelihood but requires ODE solvers
  - Interpolation method: Affects the quality of the continuous path Z(t)
  - Prediction task balance: Three tasks may compete for representation capacity

- Failure signatures:
  - Poor likelihood values: Likely ODE solver or continuous intensity formulation issues
  - Inaccurate event predictions: May indicate embedding or neural CDE parameterization problems
  - High memory usage: ODE solver complexity increases with number of event types
