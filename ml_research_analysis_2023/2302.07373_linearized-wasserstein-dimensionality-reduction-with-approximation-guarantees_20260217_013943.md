# Linearized Wasserstein dimensionality reduction with approximation guarantees

## Quick Facts
- arXiv ID: 2302.07373
- Source URL: https://arxiv.org/abs/2302.07373
- Reference count: 40
- One-line primary result: Introduces LOT Wassmap algorithm with approximation guarantees for low-dimensional embedding of probability measures in Wasserstein space

## Executive Summary
This paper addresses the computational challenge of analyzing datasets naturally interpreted as probability measures by introducing LOT Wassmap, an algorithm for uncovering low-dimensional structures in the Wasserstein space. The method leverages linearized optimal transport (LOT) and Sinkhorn approximations to avoid computing full pairwise Wasserstein distance matrices, achieving computational efficiency while providing theoretical guarantees on embedding quality. The algorithm is particularly useful when explicit descriptions of probability measures are unavailable and finite samples must be used instead.

## Method Summary
LOT Wassmap computes low-dimensional embeddings of probability measures by first calculating transport maps from a reference measure to each target measure using either linear programming or Sinkhorn iterations. These transport maps are centered and stacked into a matrix, and the truncated singular value decomposition of this matrix produces the final embedding. The method provides theoretical guarantees on embedding quality under both the linearized optimal transport approximation and finite sample scenarios, with computational complexity reduced from O(N²) to O(N) by avoiding pairwise distance computations.

## Key Results
- LOT Wassmap achieves correct embeddings that improve with increased sample size while significantly reducing computational costs compared to methods requiring pairwise distance computations
- Theoretical guarantees show embedding quality degrades gracefully with sample size, with total error decomposing into LOT approximation error, finite sample error, and discretization error
- The algorithm's computational efficiency comes from computing only N transport maps instead of N² pairwise Wasserstein distances

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using LOT distances instead of full Wasserstein distances reduces computational cost from O(N²) to O(N)
- Mechanism: LOT approximates Wasserstein distance by linearizing transport maps around a reference measure, so only N transport maps are needed instead of N² pairwise computations
- Core assumption: The transport maps from reference to each measure can be composed to approximate pairwise distances
- Evidence anchors:
  - [abstract] "Our algorithm leverages approximation schemes such as Sinkhorn distances and linearized optimal transport to speed-up computations, and in particular, avoids computing a pairwise distance matrix."
  - [section 1.3] "This results in only O(N) optimal transport computations."
- Break condition: If the linearized approximation error exceeds the subspace structure tolerance, embedding quality degrades significantly.

### Mechanism 2
- Claim: Truncated SVD of centered transport maps produces equivalent embedding to MDS on pairwise LOT distances
- Mechanism: The centered transport map matrix T has T⊤T = -½JΛJ where Λ contains empirical LOT distances, making the truncated SVD equivalent to MDS embedding
- Core assumption: The centering and column-stacking operations preserve the geometric structure needed for MDS
- Evidence anchors:
  - [section 3.2] "Lemma A.1 shows that T⊤T where T is as in Algorithm 2 is actually the MDS matrix -½JΛJ"
  - [section 3.3] "Corollary 3.4. Invoke the notations and assumptions of Theorem 3.3. Choose a reference measure σ ∈ W2(Rn) and compute all transport maps Tµᵢσ. Let T be the transport map matrix created by centering and column-stacking the transport maps Tµᵢσ as in Algorithm 2."
- Break condition: If the rank of centered transport matrix is less than embedding dimension, truncated SVD cannot capture the subspace.

### Mechanism 3
- Claim: Approximation error bounds ensure embedding quality degrades gracefully with sample size
- Mechanism: The total error |W₂(µ,ν)² - ŴLOT²| decomposes into three parts: LOT approximation error, finite sample error, and discretization error, each bounded by explicit terms
- Core assumption: Each component error can be bound independently and their sum provides a valid total error bound
- Evidence anchors:
  - [section 4] "The main approximation argument consists of the following triangle inequality: |W₂(µ₁,µ₂)² - ŴLOT²(μ̂₁,μ̂₂;γ)²| ≤ |W₂(µ₁,µ₂)² - W_LOT²(µ₁,µ₂)²| + |W_LOT²(µ₁,µ₂)² - W_LOT²(μ̂₁,μ̂₂;γ)²| + |W_LOT²(μ̂₁,μ̂₂;γ)² - ŴLOT²(μ̂₁,μ̂₂;γ)²|"
  - [section 4.1 Theorem 4.2] "With probability at least 1 - δ, |W₂(µ₁,µ₂)² - ŴLOT²(μ̂₁,μ̂₂;γLP)²| ≤ (M + 2R)(Cε^(p/(6p+16n)) + 2Op(rₙ(k)log(1+k)tn,α) + R√(2log(2/δ))/m)"
- Break condition: If sample size is too small relative to dimensionality, finite sample error dominates and embedding becomes unreliable.

## Architecture Onboarding

- Component map: Input measures -> Reference measure σ -> Transport solver (LP/Sinkhorn) -> Barycentric projection -> Centering and column-stacking -> Truncated SVD -> Output embedding
- Critical path:
  1. Sample m points from each measure and reference
  2. For each measure, compute transport map from reference using chosen solver
  3. Center and stack transport maps into matrix T
  4. Compute truncated SVD of T
  5. Return first d right singular vectors scaled by singular values
- Design tradeoffs:
  - Linear program vs Sinkhorn: LP gives exact solutions but slower; Sinkhorn faster but needs regularization parameter tuning
  - Reference measure choice: Different σ can affect approximation quality and computational efficiency
  - Sample size m: Larger m improves approximation but increases computation time quadratically
- Failure signatures:
  - Poor embedding quality: likely due to insufficient sample size or inappropriate reference measure
  - Slow computation: may indicate using LP instead of Sinkhorn or excessively large m
  - Rank-deficient matrix: could mean too few samples relative to embedding dimension
- First 3 experiments:
  1. Simple 1D translation manifold: Generate N Gaussians with means on circle, embed with both LP and Sinkhorn variants, verify circular structure
  2. Grid translation manifold: Create 2D grid of translated Gaussians, test embedding recovery with varying sample sizes
  3. Scaling manifold: Generate Gaussians with different anisotropic scalings, test whether embedding captures scaling parameters correctly

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do the approximation guarantees for LOT Wassmap scale with the dimensionality of the Wasserstein space (n)?
- Basis in paper: [explicit] The paper discusses computational costs and approximation errors in relation to the dimension n, particularly in the context of entropic regularization and linearized optimal transport.
- Why unresolved: The paper provides bounds for specific cases (compactly supported and non-compactly supported target measures) but does not explicitly discuss how these bounds scale with increasing dimensionality n.
- What evidence would resolve it: Experiments or theoretical analysis showing the dependence of approximation error and computational cost on the dimension n, ideally with both synthetic and real-world datasets.

### Open Question 2
- Question: Can the LOT Wassmap algorithm be extended to handle datasets where the measures are not generated by pushforward transformations of a fixed template measure?
- Basis in paper: [inferred] The paper assumes a generative model where data measures are of the form µi = hi ♯µ for some fixed template measure µ and a space of functions H. This is a significant assumption that may not hold in all practical scenarios.
- Why unresolved: The theoretical guarantees and the algorithm itself are built around this assumption, and there is no discussion of how the method might be adapted for more general datasets.
- What evidence would resolve it: Development of a modified version of LOT Wassmap that does not rely on the generative model assumption, along with experiments demonstrating its effectiveness on datasets that do not fit this model.

### Open Question 3
- Question: What is the impact of the choice of reference measure σ on the quality of the LOT Wassmap embedding?
- Basis in paper: [explicit] The paper mentions that the choice of reference measure σ is important for the linearized optimal transport framework, and it is used in the computation of transport maps and the empirical linearized Wasserstein-2 distance.
- Why unresolved: While the paper discusses the role of the reference measure, it does not provide a systematic study of how different choices of σ affect the embedding quality or computational efficiency.
- What evidence would resolve it: A comprehensive study comparing the performance of LOT Wassmap using different reference measures, including both synthetic and real-world datasets, to identify the characteristics of a good reference measure.

### Open Question 4
- Question: How does the LOT Wassmap algorithm perform when the data measures have significant overlap or are highly concentrated?
- Basis in paper: [inferred] The paper discusses the case of compactly supported and non-compactly supported target measures, but does not specifically address the scenario of highly concentrated or overlapping measures.
- Why unresolved: The behavior of optimal transport distances and linearized approximations can be sensitive to the geometry of the measures, and the paper does not provide insights into how LOT Wassmap handles these challenging cases.
- What evidence would resolve it: Experiments or theoretical analysis focusing on datasets with highly concentrated or overlapping measures, to assess the robustness and limitations of LOT Wassmap in these scenarios.

## Limitations

- The approximation quality heavily depends on the choice of reference measure, for which the paper provides no systematic guidance
- Theoretical bounds involve unspecified constants that could significantly impact practical performance
- The method assumes measures can be generated by pushforward transformations of a fixed template, limiting applicability to more general datasets

## Confidence

**High confidence**: The computational complexity claims (O(N) vs O(N²)) are well-established from the linearized optimal transport literature. The equivalence between truncated SVD of centered transport maps and MDS on LOT distances is mathematically rigorous and supported by Lemma A.1.

**Medium confidence**: The approximation error bounds in Section 4 are theoretically sound but may be conservative in practice. The decomposition into three error terms is valid, but the actual constants and their dependencies on problem parameters could be tighter.

**Low confidence**: The practical guidance for choosing between linear programming and Sinkhorn variants is limited. The paper suggests computational trade-offs but doesn't provide clear criteria for when one method outperforms the other in terms of embedding quality.
