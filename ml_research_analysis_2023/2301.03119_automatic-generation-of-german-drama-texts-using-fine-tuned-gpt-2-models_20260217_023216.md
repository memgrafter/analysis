# Automatic Generation of German Drama Texts Using Fine Tuned GPT-2 Models

## Quick Facts
- arXiv ID: 2301.03119
- Source URL: https://arxiv.org/abs/2301.03119
- Reference count: 7
- Primary result: Hierarchical approach using fine-tuned GPT-2 models for German drama generation shows competitive automatic metrics but poor manual quality due to dataset variability and weak outline generation

## Executive Summary
This paper proposes a hierarchical approach to German drama generation using fine-tuned GPT-2 models, consisting of an outline model (producing scene outlines from keywords) and a generation model (producing scenes from outlines and context). The system uses GerDraCor and DTA datasets and compares two versions trained with keywords extracted via tf-idf and TextRank. Automatic evaluation shows competitive perplexity and topic drift scores, but manual analysis reveals poor text quality, likely due to dataset variability and weak outline generation. Despite improvements in global consistency, the model suffers from repetition, non-uniform formatting, and instability, limiting its ability to produce coherent drama texts.

## Method Summary
The approach uses a two-stage fine-tuning process on German GPT-2: first training an outline model to generate scene summaries from extracted keywords (using tf-idf and TextRank), then training a generation model to produce full scenes from these outlines plus context. The system processes GerDraCor and DTA datasets through XML parsing, historical spelling normalization, and keyword extraction. Training uses 3 epochs with batch sizes of 4-8, AdamW optimizer, top-p sampling (p=0.9), and repetition penalty 2.0. Evaluation combines automatic metrics (perplexity, n-gram overlap, topic drift) with manual qualitative analysis on 100 test scenes.

## Key Results
- Automatic metrics show competitive perplexity and topic drift scores compared to baseline models
- Manual qualitative analysis reveals poor text quality with issues in coherence, formatting, and repetition
- Hierarchical approach improves global consistency but suffers from compounding errors in outline generation
- Dataset variability (verse vs prose, inconsistent formatting) significantly impacts generation quality

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The hierarchical approach improves global consistency by separating outline generation from scene generation.
- Mechanism: The outline model first produces a condensed representation of the scene, which the generation model uses as a guide. This two-stage process allows the model to maintain coherence over longer text spans.
- Core assumption: The generated outline accurately captures the key elements of the scene, and the generation model can effectively use this outline to produce coherent text.
- Evidence anchors:
  - [abstract] "The system uses GerDraCor and DTA datasets and compares two versions trained with keywords extracted via tf-idf and TextRank. Automatic evaluation shows competitive perplexity and topic drift scores..."
  - [section 4.3.1] "TextRank is a graph-based ranking model which takes into account the co-occurrence of words in a window of N words, adding edges between those nodes and then applying a ranking algorithm until convergence."
  - [corpus] Weak evidence - the corpus shows related work but does not directly confirm this mechanism.
- Break condition: If the outline generation produces poor quality outlines, the generation model will fail to maintain coherence regardless of its own capabilities.

### Mechanism 2
- Claim: Fine-tuning GPT-2 on domain-specific data (German drama) improves generation quality compared to generic pre-trained models.
- Mechanism: By training on German drama corpora (GerDraCor and DTA), the model learns the specific linguistic patterns, formatting conventions, and narrative structures of German drama texts.
- Core assumption: The domain-specific data contains sufficient examples of German drama structure and style for the model to learn meaningful patterns.
- Evidence anchors:
  - [abstract] "Our models perform well according to automatic quantitative evaluation, but, conversely, manual qualitative analysis reveals a poor quality of generated texts."
  - [section 4.1] "The model was trained on a 16GB and 2,350,234,427 tokens data set consisting of data from the Wikipedia dump, EU Bookshop corpus, Open Subtitles, CommonCrawl, ParaCrawl and News Crawl."
  - [corpus] Weak evidence - related work shows similar approaches but doesn't directly validate this mechanism.
- Break condition: If the training data is too limited, noisy, or unrepresentative of the target domain, fine-tuning will not produce meaningful improvements.

### Mechanism 3
- Claim: Using keyword extraction (tf-idf and TextRank) for outline generation provides more focused and relevant outlines than using full text.
- Mechanism: Keywords extracted from the text represent the most important elements, allowing the outline model to focus on generating summaries that capture the essence of scenes rather than getting distracted by less important details.
- Core assumption: The extracted keywords accurately represent the semantic content of the scene and are sufficient for generating meaningful outlines.
- Evidence anchors:
  - [section 4.3.1] "Keyword Extraction Algorithms RAKE first generates a set of candidate keywords for the document subsequently creating a co-occurrence matrix from those."

- Break condition: If the keyword extraction algorithms produce irrelevant or redundant keywords, the generated outlines will be poor quality regardless of the outline generation model's capabilities.

## Architecture Onboarding

- Component map:
  Data preprocessing -> Keyword extraction -> Outline generation -> Scene generation -> Evaluation

- Critical path: Preprocessing → Keyword extraction → Outline generation → Scene generation → Evaluation
- Design tradeoffs:
  - Hierarchical approach adds complexity but improves global consistency
  - Using keywords instead of full text reduces input complexity but may lose important context
  - Fine-tuning on domain data improves relevance but requires sufficient quality training data
- Failure signatures:
  - Poor keyword extraction → irrelevant or redundant outlines → incoherent scenes
  - Insufficient training data → overfitting or poor generalization
  - Incorrect preprocessing → malformed input to models
- First 3 experiments:
  1. Test keyword extraction quality by manually comparing extracted keywords to human-identified key elements
  2. Validate outline generation by comparing generated outlines to human-written summaries of the same scenes
  3. Test generation model with ground truth outlines (bypassing outline generation) to isolate generation quality from outline quality

## Limitations

- Dataset quality issues: GerDraCor and DTA corpora have significant variability in formatting and content, with inconsistent stage direction conventions and mixture of verse and prose
- Evaluation methodology gaps: Discrepancy between competitive automatic metrics and poor manual evaluation suggests current metrics may not capture drama-specific quality requirements
- Missing implementation details: Critical details like exact data splits, post-processing rules, and iterative generation parameters are not fully specified

## Confidence

- Medium confidence: Hierarchical approach improves global consistency - While automatic metrics support this, poor manual evaluation results suggest benefits may be outweighed by compounding errors
- Medium confidence: Fine-tuning GPT-2 on domain-specific data improves generation quality - Automatic metrics show competitive performance, but manual analysis reveals fundamental quality issues
- Low confidence: Keyword extraction methods meaningfully impact outline quality - Paper doesn't provide comparative analysis of tf-idf vs TextRank outputs or their impact on final generation quality

## Next Checks

1. Cross-dataset validation: Test fine-tuned models on out-of-domain German text (news articles or novels) to determine whether poor manual evaluation results stem from dataset quality issues or fundamental limitations in the approach

2. Ablation study on outline quality: Generate scenes using ground truth human-written outlines instead of model-generated outlines to determine whether poor manual evaluation results are primarily due to weak outline generation or the scene generation model itself

3. Controlled formatting experiment: Test generation model on a curated subset of GerDraCor containing only plays with consistent formatting (all prose, standardized stage directions) to determine whether dataset variability is the primary cause of poor manual evaluation results
