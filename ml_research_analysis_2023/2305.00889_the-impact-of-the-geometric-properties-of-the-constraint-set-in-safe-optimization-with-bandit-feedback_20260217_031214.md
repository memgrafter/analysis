# The Impact of the Geometric Properties of the Constraint Set in Safe Optimization with Bandit Feedback

## Quick Facts
- arXiv ID: 2305.00889
- Source URL: https://arxiv.org/abs/2305.00889
- Reference count: 40
- One-line primary result: Introduces sharpness as a geometric property of constraint sets that characterizes the difficulty of safe learning in bandit settings, establishing sublinear regret bounds for polytope-sharp sets.

## Executive Summary
This paper addresses safe optimization with bandit feedback, where an agent must learn to maximize a reward function while respecting safety constraints without knowing the true environment parameters. The authors propose a two-phase algorithm that first performs pure exploration to gather information about the unknown parameters, then switches to exploration-exploitation using conservative inner approximations of the feasible action set. The key innovation is the introduction of "sharpness" as a geometric property that characterizes how difficult it is to learn safely within a constraint set. They show that when constraint sets are "polytope-sharp" (including all convex sets), the algorithm achieves sublinear regret bounds.

## Method Summary
The method involves a two-phase bandit algorithm: first, a pure exploration phase where actions are sampled from an initial feasible set to gather information about the unknown parameter; second, an exploration-exploitation phase where the algorithm maintains confidence sets for parameter estimates and uses conservative inner approximations of the feasible action set to ensure safety. The algorithm solves an optimistic optimization problem within the conservative approximation to balance exploration and exploitation. The choice of exploration duration T' depends on the maximum shrinkage of the response set Y, which is characterized by the sharpness property.

## Key Results
- Introduced the concept of sharpness as a geometric property of constraint sets that impacts learning difficulty
- Established sublinear regret bounds (O(T^(2/3))) when the constraint set is polytope-sharp
- Demonstrated through numerical experiments that sharper constraint sets lead to higher regret
- Showed that all convex sets are polytope-sharp, providing a broad class of sets with sublinear regret guarantees

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sharpness of the safety set controls the tightness of the conservative inner approximation of the feasible action set, which directly impacts the suboptimality gap in regret.
- Mechanism: The algorithm maintains a confidence set Ct for the unknown parameter Θ* and uses it to define a conservative inner approximation Gt of the feasible action set X. The sharpness of the response set Y = Θ*A ∩ E bounds how far the optimal action x* can be from Gt, limiting the suboptimality gap f(Θ*x*) - f(Θ*xt).
- Core assumption: The safety set E and action set A have geometric properties captured by sharpness, and the algorithm can estimate or bound this sharpness to choose an appropriate pure exploration duration T'.
- Evidence anchors:
  - [abstract] "we introduce the notion of the sharpness of a particular constraint set, which characterizes the difficulty of performing learning within the constraint set in an uncertain setting"
  - [section 4.1] "choosing actions from this inner approximation maintains safety because it ensures that some region around the expected response lies within the safety constraint"
  - [corpus] Weak - no direct evidence in corpus neighbors about sharpness concept
- Break condition: If the safety set has very sharp corners (high sharpness), the conservative approximation becomes loose, increasing the suboptimality gap and potentially breaking the sublinear regret guarantee.

### Mechanism 2
- Claim: Polytope-sharp sets (including all convex sets) allow for linear sharpness bounds, enabling sublinear regret bounds.
- Mechanism: By identifying the class of polytope-sharp sets, the algorithm can guarantee that sharpness is bounded linearly by shrinkage. This linearity allows the regret bound to scale sublinearly with time, specifically as T^(2/3).
- Core assumption: The response set Y is polytope-sharp, which is true for convex Y or can be established via polytopic subsets for non-convex Y.
- Evidence anchors:
  - [section 4.1] "we define the class of sets for which we can use polytopic subsets to bound the sharpness" and "all compact convex sets are polytope-sharp"
  - [section 4.2] "If Y is polytope-sharp, then the regret of Algorithm 1 satisfies RT = O(T^(2/3))"
  - [corpus] Weak - no direct evidence in corpus neighbors about polytope-sharp sets
- Break condition: If Y is not polytope-sharp and has nonlinear sharpness growth, the regret bound may become linear in T, violating the sublinear guarantee.

### Mechanism 3
- Claim: The algorithm's two-phase approach (pure exploration followed by exploration-exploitation) balances information gathering and reward maximization.
- Mechanism: The pure exploration phase ensures sufficient information about the unknown parameter Θ* by sampling from the initial feasible set G0. The exploration-exploitation phase then uses this information to choose optimistic actions within the conservative approximation Gt-1, balancing safety and reward.
- Core assumption: The pure exploration phase is long enough (T' ≥ max(t_δ, t_h)) to ensure both parameter estimation accuracy and safety constraint satisfaction.
- Evidence anchors:
  - [section 3] "The algorithm is given in Algorithm 1... first performing pure exploration for an appropriate duration T', and then performing exploration-exploitation"
  - [section 4.2] "choosing T' = max(T^(2/3), t_δ, t_h) ensures that RT = O(T^(2/3))"
  - [corpus] Weak - no direct evidence in corpus neighbors about two-phase bandit algorithms
- Break condition: If T' is chosen too small, parameter estimation may be poor, leading to overly conservative Gt and poor rewards. If T' is too large, exploration time reduces exploitation time, increasing regret.

## Architecture Onboarding

- Component map: Pure exploration module -> Parameter estimation module -> Safe action selection module -> Regret tracking module
- Critical path:
  1. Initialize G0 from Assumptions 1 and 4
  2. Pure exploration phase: Sample xt from G0, observe yt, update estimates
  3. Exploration-exploitation phase: Compute Ct-1 and Gt-1, solve optimistic optimization problem, observe yt, update estimates
  4. Repeat until T rounds completed
  5. Output regret bound
- Design tradeoffs:
  - T' vs. regret: Larger T' improves parameter estimation but reduces exploitation time
  - Sharpness vs. conservatism: Sharper sets require more conservative approximations, potentially increasing regret
  - Confidence width vs. safety: Wider confidence sets ensure safety but may be overly conservative
- Failure signatures:
  - Linear regret growth: Indicates poor parameter estimation or overly sharp safety set
  - Safety constraint violations: Suggests confidence sets are too narrow or Gt computation is incorrect
  - Suboptimal exploration: May indicate poor choice of T' or issues with pure exploration sampling
- First 3 experiments:
  1. Verify sublinear regret on a simple convex safety set (e.g., Euclidean ball) with known sharpness
  2. Test algorithm on a polytope-sharp non-convex set to confirm robustness
  3. Stress test with very sharp safety sets to observe breakdown of sublinear regret guarantee

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the sharpness concept be generalized to other norms beyond the infinity norm, and how would this impact the regret bounds?
- Basis in paper: [explicit] The paper introduces sharpness using the infinity norm (Sharp∞Y) and establishes regret bounds based on this norm. However, it does not explore the implications of using other norms.
- Why unresolved: The paper focuses on the infinity norm for simplicity and tractability, but it is unclear how the results would extend to other norms, such as the 2-norm or 1-norm, which might be more suitable for different applications.
- What evidence would resolve it: Conducting experiments with different norms and comparing the regret bounds would provide insights into the generality and applicability of the sharpness concept.

### Open Question 2
- Question: How does the choice of the exploration-exploitation trade-off parameter T' affect the overall regret, and is there an optimal way to determine this parameter for different problem instances?
- Basis in paper: [explicit] The paper mentions that T' needs to be chosen appropriately based on the maximum shrinkage of Y, but it does not provide a detailed analysis of how T' impacts the regret or a method for determining the optimal T'.
- Why unresolved: The choice of T' is crucial for balancing exploration and exploitation, but the paper does not explore the sensitivity of the regret to this parameter or provide a systematic approach for its selection.
- What evidence would resolve it: Conducting experiments with varying T' values and analyzing the resulting regret would help understand the impact of this parameter and potentially lead to a more principled approach for its selection.

### Open Question 3
- Question: Can the proposed algorithm be extended to handle non-linear constraints or non-convex safety sets, and what would be the implications for the regret bounds?
- Basis in paper: [inferred] The paper assumes linear constraints and convex safety sets, but many real-world applications involve non-linear or non-convex constraints. The sharpness concept might need to be adapted for such cases.
- Why unresolved: The current algorithm and analysis are tailored to linear constraints and convex sets, and it is unclear how they would perform or what modifications would be necessary for non-linear or non-convex constraints.
- What evidence would resolve it: Developing and testing extensions of the algorithm for non-linear or non-convex constraints, and analyzing the resulting regret bounds, would provide insights into the feasibility and limitations of such extensions.

## Limitations
- The algorithm's performance degrades significantly when the safety set has high sharpness, potentially leading to linear regret
- The theoretical analysis assumes known bounds on the parameters (L, S, ν), which may not be available in practice
- The paper focuses on linear constraints and convex safety sets, limiting applicability to problems with non-linear or non-convex constraints
