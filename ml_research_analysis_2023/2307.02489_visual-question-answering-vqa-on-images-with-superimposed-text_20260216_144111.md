# Visual Question Answering (VQA) on Images with Superimposed Text

## Quick Facts
- arXiv ID: 2307.02489
- Source URL: https://arxiv.org/abs/2307.02489
- Reference count: 22
- Primary result: Adding superimposed text to medical images has negligible to modest impact on VQA performance

## Executive Summary
This paper investigates how superimposed text annotations affect visual question answering performance on medical images. Using a BERT-based transformer model with DenseNet-121 feature extraction, the study systematically tests VQA performance across four experimental conditions varying whether text is added to training and/or test images. The experiments use the 2019 ImageCLEF medical image dataset, which contains low-resolution images with noise. BLEU scores serve as the primary evaluation metric across 1-gram to 4-gram conditions.

The key finding is that superimposed text has minimal impact on VQA performance, with only modest decreases observed when training on images with text but testing on clean images. This suggests that AI-based image analysis can tolerate superimposed annotations without serious degradation in performance, making it feasible to add text annotations to medical images for documentation purposes while maintaining analytical capabilities.

## Method Summary
The study employs a BERT-based transformer model for VQA, using DenseNet-121 for feature extraction from medical images. Four experimental conditions are tested: clean training and clean test images, clean training with text on test images, text on both training and test images, and text on training with clean test images. The ImageCLEF 2019 medical image dataset provides the image corpus, with BLEU scores (1-gram, 2-gram, 3-gram, and 1-4-gram) serving as the evaluation metric. The baseline BLEU scores are 0.56 for 1-grams, 0.28 for 2-grams, 0.16 for 3-grams, and 0.21 for 1-4-grams.

## Key Results
- Adding text to test images only did not impact VQA performance
- Adding text to both training and test images resulted in small decreases in BLEU scores for 2-gram and 3-gram conditions
- Training on text-annotated images and testing on clean images led to small decreases in BLEU scores for 2-gram and 3-gram conditions
- Overall, superimposed text had negligible to modest impacts on VQA performance

## Why This Works (Mechanism)
The BERT-based transformer architecture, combined with DenseNet-121 feature extraction, appears robust to the addition of superimposed text annotations. The model likely learns to focus on the underlying image features rather than being distracted by text overlays, particularly when trained on both clean and text-annotated images. This suggests the attention mechanisms in BERT can effectively filter or incorporate textual information as needed while maintaining focus on the visual content for question answering.

## Architecture Onboarding

Component Map:
DenseNet-121 -> BERT Transformer -> Output Layer

Critical Path:
Input images → DenseNet-121 feature extraction → BERT attention layers → Answer generation

Design Tradeoffs:
- DenseNet-121 provides efficient feature extraction but may miss fine-grained details
- BERT transformer handles both visual and textual inputs but requires significant computational resources
- BLEU score evaluation is standardized but may not capture all aspects of answer quality

Failure Signatures:
- Significant BLEU score drops when text is added to test images only
- Inconsistent performance across different n-gram conditions
- Model overfitting to training conditions with or without text

Three First Experiments:
1. Test model performance on images with varying text densities and positions
2. Compare performance across different medical imaging modalities (CT, MRI, ultrasound)
3. Evaluate model's ability to distinguish relevant versus irrelevant text information

None

## Limitations
- Experiments used only one medical image dataset (ImageCLEF 2019), limiting generalizability
- Text annotations were manually generated rather than representative of real clinical annotations
- Study did not examine varying text positions, font sizes, or densities that occur in actual practice
- Evaluation relied solely on BLEU scores, which may not capture all aspects of VQA quality
- Did not investigate whether model can distinguish between relevant and irrelevant text information

## Confidence
- Text addition has negligible impact on VQA performance: Medium
- VQA models can handle superimposed text without performance degradation: Medium
- Text annotations can be safely added to medical images for AI analysis: Low

## Next Checks
1. Test the same methodology across multiple medical imaging modalities (CT, MRI, ultrasound) and diverse clinical annotation styles to assess generalizability
2. Conduct experiments with varying text characteristics (size, font, position, density) and measure performance thresholds where degradation occurs
3. Implement ablation studies comparing VQA performance on text-only regions versus image-only regions to determine whether the model actually uses or ignores superimposed text information
