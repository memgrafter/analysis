# Exploring Resiliency to Natural Image Corruptions in Deep Learning using Design Diversity

## Quick Facts
- arXiv ID: 2303.09283
- Source URL: https://arxiv.org/abs/2303.09283
- Reference count: 40
- Key outcome: Architecture diversity produces more diversity in all explored metrics and creates more resilient ensembles for image natural corruptions

## Executive Summary
This paper investigates how diversity in deep learning models impacts accuracy and resilience to natural image corruptions. The authors compare ensembles created from diverse architectures trained independently or via neural architecture search (NAS) and evaluate prediction-based and attribution-based diversity metrics. They find that model architecture is more important for resilience than model size or accuracy, and that attribution-based diversity is less negatively correlated with ensemble accuracy than prediction-based diversity. The balanced loss function of individual and ensemble accuracy creates more resilient ensembles for image natural corruptions.

## Method Summary
The authors create ensembles using either independently trained diverse architectures or architectures found through neural architecture search. They evaluate both prediction-based and attribution-based diversity metrics to understand how diversity impacts ensemble resilience to natural image corruptions. The study uses the ImageNet-C benchmark to test resilience against common corruptions. A balanced loss function is employed that considers both individual model accuracy and ensemble accuracy to create more resilient ensembles.

## Key Results
- Model architecture diversity is more important for resilience than model size or accuracy
- Attribution-based diversity shows less negative correlation with ensemble accuracy compared to prediction-based diversity
- Architecture diversity produces more diversity across all explored metrics: predictions, attributions, and activations
- Balanced loss functions create more resilient ensembles for image natural corruptions

## Why This Works (Mechanism)
The mechanism underlying improved resilience stems from architectural diversity creating complementary strengths across different corruption types. When models with different architectural inductive biases encounter corrupted inputs, their varied feature extraction approaches result in diverse failure modes. This diversity prevents correlated errors across ensemble members, maintaining higher collective accuracy. The attribution-based diversity captures more nuanced differences in how models process corrupted features, leading to better ensemble complementarity than simple prediction agreement.

**Critical Path:**

**Design Tradeoffs:**
The main tradeoff is between individual model accuracy and ensemble diversity. Highly accurate models may have similar failure modes, reducing ensemble resilience. Conversely, diverse but less accurate models can complement each other better against corruptions.

**Failure Signatures:**
Ensembles with low diversity show correlated failures across corruption types, leading to significant accuracy drops. Prediction-based diversity alone may miss deeper architectural differences that attribution-based metrics capture.

**3 First Experiments:**
1. Compare ensemble performance using only prediction-based diversity vs. only attribution-based diversity on ImageNet-C
2. Test ensembles with varying architectural diversity levels (low, medium, high) across corruption types
