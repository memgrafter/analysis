# BEL: A Bag Embedding Loss for Transformer enhances Multiple Instance Whole Slide Image Classification

## Quick Facts
- arXiv ID: 2303.01377
- Source URL: https://arxiv.org/abs/2303.01377
- Reference count: 0
- This work proposes a Bag Embedding Loss (BEL) to enhance transformer-based multiple instance learning (MIL) for whole slide image classification.

## Executive Summary
This paper introduces BEL (Bag Embedding Loss) to improve transformer-based MIL models for whole slide image classification. By enforcing discriminative bag-level representations through cosine similarity minimization between same-class embeddings and maximization between different classes, BEL addresses weak supervision challenges in histopathology. The approach significantly outperforms baseline MIL methods on BRACS and CAMELYON17 datasets, with notable improvements in accuracy, F1 score, and AUROC, particularly for underrepresented disease classes.

## Method Summary
BEL is a novel loss function added to the standard classification loss in transformer-based MIL models like TransMIL. It operates by maintaining running class centroids and computing cosine similarity-based contrastive loss between bag embeddings and their respective class centroids, with a margin parameter to enforce separation. The method processes WSIs by segmenting tissue, extracting 512×512 patches at 40× magnification, passing them through a pretrained DenseNet-121 for feature extraction, and feeding these into a TransMIL encoder with Neyström approximation for scalable self-attention. The bag embedding from the class token is then supervised using BEL alongside cross-entropy loss during training.

## Key Results
- BEL significantly improves TransMIL performance on BRACS and CAMELYON17 datasets
- Notable accuracy gains: BRACS (86.82%→88.46%), CAMELYON17 (87.92%→90.42%)
- F1 score improvements: BRACS (81.88%→84.56%), CAMELYON17 (89.73%→91.42%)
- BEL particularly benefits underrepresented disease classes as shown by improved precision-recall curves

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BEL improves bag-level representation learning by enforcing discriminative embeddings between classes
- Mechanism: The Bag Embedding Loss (BEL) minimizes cosine similarity between bag embeddings of the same class while maximizing the distance (with margin m) between embeddings of different classes. This creates class-specific clusters in the embedding space.
- Core assumption: Bag embeddings contain sufficient information to distinguish between classes when properly supervised
- Evidence anchors:
  - [abstract]: "BEL forces the model to learn a discriminative bag level representation by minimizing the distance between bag embeddings of the same class and maximizing the distance between different classes"
  - [section]: Equation (4) shows the explicit form of BEL using cosine similarity with margin-based separation
  - [corpus]: Weak - corpus papers focus on instance-level MIL improvements rather than bag embedding supervision
- Break condition: If bag embeddings are too noisy or contain insufficient discriminative information, BEL cannot create meaningful class separation

### Mechanism 2
- Claim: BEL addresses weak supervision challenges in WSI classification
- Mechanism: By adding a class-aware supervision signal beyond the standard cross-entropy loss, BEL compensates for the lack of instance-level labels in MIL problems where only bag-level annotations exist
- Core assumption: The transformer can generate meaningful bag embeddings that capture class-relevant information
- Evidence anchors:
  - [abstract]: "when applied to high magnification datasets, problems emerge due to the large number of instances and the weak supervisory learning signal"
  - [section]: "we propose a novel Bag Embedding Loss (BEL) which is added to the classiﬁcation loss during training, thereby forcing TransMIL to learn discriminative bag level representations"
  - [corpus]: No direct evidence in corpus papers - they focus on instance-level attention mechanisms rather than bag embedding supervision
- Break condition: If the transformer architecture cannot generate meaningful bag embeddings (e.g., due to architectural limitations or insufficient training data)

### Mechanism 3
- Claim: BEL improves performance on underrepresented classes by explicitly enforcing class separation
- Mechanism: The margin-based separation in BEL creates stronger decision boundaries for minority classes, improving their classification accuracy beyond what standard cross-entropy provides
- Core assumption: Class imbalance exists and underrepresented classes benefit from explicit separation in embedding space
- Evidence anchors:
  - [section]: "Figure 2 shows the area under the precision-recall curve for both datasets and all classes. We found that the improvements mainly resides in disease classes which are not strongly represented"
  - [corpus]: Weak - corpus papers don't specifically address class imbalance in MIL contexts
- Break condition: If class imbalance is minimal or if the margin parameter m is not properly tuned for the specific dataset characteristics

## Foundational Learning

- Concept: Multiple Instance Learning (MIL)
  - Why needed here: The entire framework operates under MIL assumptions where only bag-level labels are available, not instance-level labels
  - Quick check question: In MIL, if a bag is labeled positive, what can we infer about its instances? (Answer: At least one instance is positive)

- Concept: Self-attention and transformer architectures
  - Why needed here: TransMIL uses transformer encoders to model dependencies between instances, which is crucial for generating meaningful bag embeddings
  - Quick check question: What is the computational complexity of standard self-attention that makes it challenging for large WSIs? (Answer: O(n²) where n is the number of instances)

- Concept: Cosine similarity and embedding spaces
  - Why needed here: BEL explicitly uses cosine similarity to measure distances between bag embeddings, making understanding of embedding spaces critical
  - Quick check question: What is the range of cosine similarity values and what do they represent? (Answer: [-1, 1], where 1 means identical direction, -1 means opposite direction)

## Architecture Onboarding

- Component map:
  WSI → patches → features → TransMIL → bag embedding → BEL + CE loss → gradients → update

- Critical path: WSI → patches → features → TransMIL → bag embedding → BEL + CE loss → gradients → update

- Design tradeoffs:
  - Neyström approximation enables processing large bags but introduces approximation error
  - BEL adds computational overhead but improves class separation
  - DenseNet-1024 feature extraction is fixed (pretrained) but may not be optimal for specific datasets

- Failure signatures:
  - Training instability: Check learning rate and weight decay parameters
  - Poor convergence: Verify margin m and update ratio λ values
  - Class imbalance issues: Examine BEL's impact on minority class performance
  - Memory issues: Large WSIs may exceed GPU memory despite Neyström approximation

- First 3 experiments:
  1. Baseline: Train TransMIL with only cross-entropy loss on BRACS dataset
  2. Ablation: Train with cross-entropy + BEL with varying margin m values (0.1, 0.25, 0.5)
  3. Comparison: Evaluate BEL vs. instance-level attention mechanisms on class-wise performance metrics

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of BEL scale with different margin values (m) and update ratios (λ) across various histopathology datasets?
- Basis in paper: [explicit] The paper mentions that a margin m in [0.1, 0.25] performs best and used m = 0.25, with λ = 0.996 for update ratio.
- Why unresolved: The paper only tests a narrow range of parameters and does not explore the sensitivity of BEL's performance to these hyperparameters.
- What evidence would resolve it: A comprehensive ablation study varying m and λ across multiple datasets would reveal the optimal ranges and their impact on classification performance.

### Open Question 2
- Question: Does BEL improve the explainability of transformer models in histopathology by producing more interpretable attention maps?
- Basis in paper: [explicit] The paper states they analyze the impact of BEL on the attention distribution of TransMIL but does not provide detailed results or visualizations.
- Why unresolved: While the authors mention analyzing attention maps, they do not present quantitative or qualitative evidence of improved interpretability.
- What evidence would resolve it: Comparative visualizations of attention maps before and after BEL training, along with expert pathologist validation, would demonstrate whether BEL enhances interpretability.

### Open Question 3
- Question: How does BEL compare to other contrastive learning approaches for improving bag-level representations in MIL?
- Basis in paper: [inferred] BEL uses a similarity-based loss to minimize distances between same-class embeddings and maximize distances between different classes, similar to contrastive learning principles.
- Why unresolved: The paper does not benchmark BEL against other contrastive learning methods or data augmentation strategies for MIL.
- What evidence would resolve it: Head-to-head comparisons with established contrastive learning frameworks on the same datasets would establish BEL's relative effectiveness.

## Limitations

- Limited ablation studies to isolate BEL's specific contribution to performance gains
- Results confined to two specific histopathology datasets without broader domain testing
- Architectural dependencies not explored - effectiveness may be tied to TransMIL specifically

## Confidence

- **High Confidence**: BEL improves TransMIL performance on the tested histopathology datasets (BRACS and CAMELYON17)
- **Medium Confidence**: BEL specifically helps underrepresented classes through margin-based separation (supported by precision-recall analysis but limited ablation)
- **Low Confidence**: BEL's benefits generalize beyond transformer-based MIL to other architectures or problem domains

## Next Checks

1. **Ablation Study**: Train TransMIL with cross-entropy alone, with BEL alone (removing cross-entropy), and with both losses to isolate BEL's specific contribution to performance gains.

2. **Cross-Domain Testing**: Apply BEL to non-histopathology MIL problems (e.g., satellite imagery, medical time series) to verify generalization beyond the current domain.

3. **Alternative Architectures**: Implement BEL with non-transformer MIL architectures (e.g., DeepMIL, Attention-based MIL) to test architectural dependencies and determine if BEL's benefits are architecture-specific.
