# Inferring Preferences from Demonstrations in Multi-objective Reinforcement Learning: A Dynamic Weight-based Approach

## Quick Facts
- arXiv ID: 2304.14115
- Source URL: https://arxiv.org/abs/2304.14115
- Reference count: 9
- Primary result: Dynamic Weight-based Preference Inference (DWPI) algorithm achieves 100% accuracy on optimal demonstrations and outperforms baselines by 76.73-90.8% in time efficiency

## Executive Summary
This paper introduces the Dynamic Weight-based Preference Inference (DWPI) algorithm for inferring user preferences from observed behavior trajectories in multi-objective reinforcement learning settings. The algorithm trains a neural network model using demonstrations from a dynamic weight MORL agent, enabling autonomous preference inference without ongoing user input. The method is evaluated across three benchmark environments and demonstrates significant improvements in both inference accuracy and computational efficiency compared to baseline approaches.

## Method Summary
The DWPI algorithm works by first training a dynamic weights MORL agent (either DWTQ for low-dimensional or DWDQN for high-dimensional preference spaces) that can generate optimal reward trajectories for any given preference vector. This agent is then used to create a paired dataset of reward trajectories and their corresponding preference vectors. An inference model is trained on this dataset using supervised learning with mean squared error loss, where 75% of trajectories include added noise to ensure robustness to sub-optimal demonstrations. During inference, the trained model maps new reward trajectories to their inferred preference vectors through a single forward pass.

## Key Results
- Achieved 100% accuracy in inferring preferences from optimal demonstrations in the Deep Sea Treasure environment
- Outperformed baseline PM and MWAL algorithms by 76.73-90.8% in time efficiency across all three environments
- Maintained robust performance when inferring preferences from sub-optimal demonstrations with added noise
- Demonstrated superior accuracy and distributional distance metrics compared to baseline approaches

## Why This Works (Mechanism)

### Mechanism 1
The algorithm achieves 100% accuracy on optimal demonstrations by learning a deterministic mapping from reward trajectories to preference vectors. A dynamic weight MORL agent generates optimal reward trajectories paired with their generating preference vectors, which are used to train a neural network that learns the inverse mapping. The core assumption is that the reward trajectory uniquely determines the preference vector when the agent is optimal. Break condition occurs if multiple preference vectors could generate similar optimal trajectories.

### Mechanism 2
Sub-optimal demonstration robustness is achieved by adding noise to reward trajectories during training. The training dataset includes 75% sub-optimal trajectories created by adding unnecessary time steps, allowing the inference model to learn to map imperfect trajectories to preferences close to the optimal ones. The core assumption is that sub-optimal trajectories from the same preference vector cluster near the optimal trajectory in feature space. Break condition occurs if sub-optimal trajectories diverge significantly from optimal ones.

### Mechanism 3
Computational efficiency is achieved by avoiding online RL training during inference. The inference model is trained offline once using the generated dataset, and during inference only a forward pass through the neural network is needed. The core assumption is that the inference problem can be cast as a supervised learning problem where the neural network learns the inverse mapping. Break condition occurs if the inference problem is too complex for a fixed neural network to capture the mapping accurately.

## Architecture Onboarding

- Component map: Dynamic Weight MORL Agent -> Environment -> Reward Trajectories -> Preference Inference Model -> Preference Vector
- Critical path: Train DWMORL agent -> Generate demonstration dataset -> Train inference model -> Deploy inference model for new trajectories
- Design tradeoffs: Accuracy vs. computational efficiency (offline training allows fast inference but requires dataset generation), model complexity vs. generalization (deeper networks may capture complex mappings but risk overfitting)
- Failure signatures: Poor inference accuracy on unseen trajectories (overfitting), high variance in predictions (insufficient training data), inability to handle new environment types (model not generalizable)
- First 3 experiments:
  1. Train DWMORL agent on DST environment and verify it generates expected optimal trajectories for known preferences
  2. Train inference model on generated dataset and evaluate accuracy on optimal demonstrations
  3. Test inference model robustness by evaluating on sub-optimal demonstrations with added noise

## Limitations
- The DWPI algorithm's effectiveness is fundamentally constrained by the assumption that reward trajectories uniquely map to preference vectors
- The paper does not fully characterize the distribution of sub-optimal trajectories or provide detailed analysis of failure modes
- The approach requires training a dynamic weight MORL agent for each new environment, which may not scale efficiently

## Confidence

- **High confidence**: Time efficiency improvements (90.8% vs baselines) are well-supported by the architecture design of offline training
- **Medium confidence**: 100% accuracy on optimal demonstrations in DST, though this may be an artifact of the simplified 2D preference space
- **Medium confidence**: Sub-optimal demonstration robustness, as the noise generation mechanism is not fully specified

## Next Checks
