# SSS at SemEval-2023 Task 10: Explainable Detection of Online Sexism using Majority Voted Fine-Tuned Transformers

## Quick Facts
- arXiv ID: 2304.03518
- Source URL: https://arxiv.org/abs/2304.03518
- Reference count: 5
- Primary result: Ensemble of DeBERTaV3 variants with focal loss achieves macro F1 scores of 0.8392, 0.6092, and 0.4319 on three sexism detection subtasks.

## Executive Summary
This work addresses the task of detecting and explaining online sexism on social media using a hierarchical classification approach across three subtasks. The authors experiment with BERT-based models (RoBERTa and DeBERTaV3), applying focal loss and class weights to handle dataset imbalance. They find that a majority voting ensemble of the top three models—DeBERTaV3 with focal loss, DeBERTaV3 with a learning rate of 4e-5, and the baseline DeBERTaV3—outperforms individual baselines. For the multi-class tasks, 5-fold cross-validation further improves results. The final ensemble achieves macro F1 scores of 0.8392, 0.6092, and 0.4319 on the respective subtasks.

## Method Summary
The authors employ a hierarchical classification strategy for online sexism detection, using transformer-based models (RoBERTa and DeBERTaV3) fine-tuned on the provided dataset. To address class imbalance, they apply focal loss and class weights during training. The ensemble approach combines the top three performing models using majority voting. For multi-class tasks, 5-fold cross-validation is used to enhance robustness. The evaluation focuses on macro F1 scores to ensure balanced performance across all classes.

## Key Results
- Ensemble of DeBERTaV3 variants achieves macro F1 scores of 0.8392, 0.6092, and 0.4319 on the three subtasks.
- Majority voting ensemble outperforms individual baselines.
- 5-fold cross-validation improves performance on multi-class tasks.

## Why This Works (Mechanism)
The ensemble method leverages the strengths of multiple DeBERTaV3 variants, each optimized with different hyperparameters (focal loss, learning rate). This diversity helps mitigate individual model weaknesses and improves robustness. Focal loss addresses class imbalance by focusing on hard-to-classify examples, while cross-validation ensures stable performance across folds.

## Foundational Learning
- **Focal Loss**: Needed to handle class imbalance by reducing the contribution of easy examples. Quick check: Verify focal loss parameters (gamma, alpha) are tuned for the dataset.
- **Class Weights**: Required to balance the loss function across classes. Quick check: Ensure weights are inversely proportional to class frequencies.
- **Majority Voting Ensemble**: Combines predictions from multiple models to improve robustness. Quick check: Validate that ensemble predictions align with individual model strengths.
- **5-Fold Cross-Validation**: Ensures model stability and reduces overfitting. Quick check: Confirm folds are stratified to maintain class balance.
