# simpleKT: A Simple But Tough-to-Beat Baseline for Knowledge Tracing

## Quick Facts
- arXiv ID: 2302.06881
- Source URL: https://arxiv.org/abs/2302.06881
- Authors: 
- Reference count: 10
- Key outcome: simpleKT achieves top 3 performance across 7 datasets, beating 12 deep learning baselines with 57 wins, 3 ties, and 16 losses

## Executive Summary
This paper proposes simpleKT, a simple but effective knowledge tracing method that explicitly models question-specific variations while using plain dot-product attention. Inspired by the Rasch model from psychometrics, simpleKT decomposes question embeddings into KC embeddings plus question-specific difficulty vectors, then applies standard attention over KC-response interactions. The method achieves competitive performance against 12 deep learning baselines across 7 public datasets, demonstrating that sophisticated neural architectures are not always necessary for accurate knowledge tracing.

## Method Summary
SimpleKT addresses knowledge tracing by transforming question-response data into KC-response data through expansion, then applying Rasch model-inspired question difficulty vectors. The model embeds KCs and responses separately, combines them with question-specific variation vectors, and uses standard dot-product attention to aggregate historical information. A two-layer MLP produces final predictions. The approach avoids complex forgetting mechanisms and sophisticated attention variants, instead relying on the additive decomposition of question embeddings and plain attention to capture temporal dependencies in student learning interactions.

## Key Results
- Achieves top 3 performance in terms of AUC scores across 7 public datasets
- Beats 12 deep learning-based KT baselines with 57 wins, 3 ties, and 16 losses
- Demonstrates competitive performance while maintaining computational simplicity
- Shows robust performance across datasets with varying characteristics (interactions from 164K to 2.8M, KCs from 110 to 1,223)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SimpleKT achieves competitive performance by explicitly modeling question-specific variations while using plain dot-product attention
- Mechanism: Each question embedding is decomposed into the average of its KCs' embeddings plus a question-specific variation vector. This captures latent difficulty differences among questions sharing the same KCs. The dot-product attention then aggregates historical KC-response pairs without additional complexity.
- Core assumption: The additive decomposition of question embeddings adequately represents individual question difficulty while keeping KC representations general.
- Evidence anchors:
  - [abstract] "Inspired by the Rasch model in psychometrics, we explicitly model question-specific variations to capture the individual differences among questions covering the same set of knowledge components"
  - [section] "Due to the fact that questions covering the same set of KCs may have various difficulty levels, students perform significantly different. Therefore, it is unrealistic to treat every KC in the expanded KC-response sequence identical. Inspired by the very classic and simple Rasch model in psychometrics that explicitly uses a scalar to characterize the latent factor of question difficulty, we choose to use a question-specific difficulty vector to capture the individual differences among questions on the same KC."

### Mechanism 2
- Claim: Expanding question-response data into KC-response data allows the model to operate on a denser representation space while preserving question difficulty signals
- Mechanism: Each question-level interaction is split into multiple KC-level interactions, one per KC the question covers. The question-specific variation vector is then applied to each KC's representation in that interaction.
- Core assumption: KC-level interactions retain sufficient signal about question difficulty to make the expansion useful for prediction.
- Evidence anchors:
  - [section] "Therefore, to effectively learn and fairly evaluate the DLKT models from such highly sparse question-response data, following the previous work of (Ghosh et al., 2020) and (Liu et al., 2022), we artificially transform the original question-response data into KC-response data by expanding each question-level interaction into multiple KC-level interactions when the question is associated with a set of KCs"

### Mechanism 3
- Claim: Plain dot-product attention is sufficient to capture temporal dependencies in student learning without additional gating or monotonic mechanisms
- Mechanism: The model uses standard scaled dot-product attention over the sequence of KC representations and interaction embeddings, followed by a two-layer MLP to produce the final prediction.
- Core assumption: The raw interaction embeddings contain enough temporal and contextual information for accurate prediction; no complex forgetting or recency modeling is necessary.
- Evidence anchors:
  - [abstract] "Furthermore, instead of using sophisticated representations to capture student forgetting behaviors, we use the ordinary dot-product attention function to extract the time-aware information embedded in the student learning interactions"
  - [section] "Different from many existing DLKT approaches that use sophisticated neural components to model student learning and/or forgetting behaviors, we choose to use the ordinary dot-product attention function to explore and extract knowledge states from students' past learning history."

## Architecture Onboarding

- Component map: Input KC-response sequences -> KC embedding via Wc -> Question embedding via Wq -> Question difficulty vector mq -> Interaction representation (zck ⊕ mq ⊙ vck) -> Dot-product attention over history -> Two-layer MLP -> Output prediction

- Critical path: 1) Expand question-response to KC-response, 2) Embed KCs and responses, 3) Apply question difficulty vectors, 4) Run dot-product attention over history, 5) Refine with MLP and sigmoid

- Design tradeoffs:
  - Simplicity vs. expressiveness: Uses plain attention instead of gated or monotonic attention
  - KC expansion vs. sparsity: Trades off larger sequence length for denser KC-level signal
  - Additive difficulty vs. learned interactions: Avoids complex question-KC interaction modeling

- Failure signatures:
  - Overfitting on small datasets: Simple model may memorize instead of generalize
  - Poor performance when questions have many KCs: Expansion may blow up sequence length
  - Degraded accuracy on datasets without KC info: Question difficulty modeling loses signal

  2. Test dot-product attention vs. monotonic attention on BD2006
  3. Measure impact of KC-response expansion on POJ dataset
