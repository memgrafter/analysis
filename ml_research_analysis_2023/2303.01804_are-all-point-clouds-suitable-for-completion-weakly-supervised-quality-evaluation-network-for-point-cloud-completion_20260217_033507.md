# Are All Point Clouds Suitable for Completion? Weakly Supervised Quality Evaluation Network for Point Cloud Completion

## Quick Facts
- arXiv ID: 2303.01804
- Source URL: https://arxiv.org/abs/2303.01804
- Reference count: 40
- Primary result: A weakly supervised quality evaluation network that filters low-quality point clouds improves 3D object detection and completion results, achieving up to 25% MMD reduction on KITTI

## Executive Summary
This paper addresses the problem of noisy or low-quality point clouds in real-world 3D object detection and completion tasks, which can degrade downstream performance when using models trained on clean CAD datasets. The authors propose a weakly supervised quality evaluation network that scores input point clouds to filter out unsuitable data before applying completion models. Their method constructs a synthetic training dataset by augmenting ShapeNet point clouds and using a real-world detector to simulate noisy real-world conditions. A quality evaluation standard is defined by comparing completion results from good and poor inputs against ground truth. The evaluation network is trained using this standard without requiring manual labeling.

## Method Summary
The proposed approach constructs a synthetic training dataset by augmenting ShapeNet point clouds and using a real-world detector to simulate noisy real-world conditions. The quality evaluation standard compares completion results from good and poor inputs against ground truth. The evaluation network is trained using this standard without requiring manual labeling. Experiments on KITTI show the method effectively filters low-quality point clouds and improves detection and completion results, with up to 25% MMD reduction in some sequences. The approach is lightweight, fast, and can be easily integrated into existing pipelines to enhance robustness in practical applications.

## Key Results
- Achieves up to 25% MMD reduction on KITTI sequences
- Effectively filters low-quality point clouds before completion
- Lightweight and fast inference suitable for real-time applications
- Improves both detection and completion results when integrated into existing pipelines

## Why This Works (Mechanism)
The method works by learning to distinguish between high-quality and low-quality point clouds through a weakly supervised approach. By comparing completion results from augmented (poor quality) and original (good quality) point clouds against ground truth, the network learns quality assessment without explicit labels. This allows filtering of unsuitable inputs before completion, preventing degradation of downstream tasks.

## Architecture Onboarding

**Component Map**: Point Cloud Input -> Quality Evaluation Network -> Score Threshold -> Filter/Complete

**Critical Path**: The network takes a point cloud as input, outputs a quality score, and applies a threshold to decide whether to proceed with completion. This path determines which inputs receive full processing.

**Design Tradeoffs**: The weakly supervised approach trades potential accuracy for reduced annotation costs and faster training. The synthetic dataset augmentation balances realism with control over noise characteristics.

**Failure Signatures**: Low-quality point clouds that pass the filter may produce noisy completion results. Conversely, high-quality point clouds incorrectly flagged as poor may be unnecessarily discarded, reducing detection performance.

## Limitations
