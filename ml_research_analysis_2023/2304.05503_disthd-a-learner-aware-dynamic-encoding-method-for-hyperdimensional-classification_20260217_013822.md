# DistHD: A Learner-Aware Dynamic Encoding Method for Hyperdimensional Classification

## Quick Facts
- arXiv ID: 2304.05503
- Source URL: https://arxiv.org/abs/2304.05503
- Reference count: 28
- Achieves 8.0× lower dimensionality with 2.12% higher accuracy than state-of-the-art HDC methods

## Executive Summary
DistHD introduces a dynamic encoding method for hyperdimensional computing that identifies and regenerates dimensions misleading classification, enabling accurate learning with 8.0× lower dimensionality than state-of-the-art approaches. It uses a top-2 classification strategy and dimension regeneration to adapt the encoding during training, achieving on average 2.12% higher classification accuracy. DistHD is 5.97× faster in training and 8.09× faster in inference compared to leading methods, and demonstrates 12.90× higher robustness to hardware errors than deep neural networks. This approach addresses the inefficiency of static encoding in HDC, making it well-suited for resource-constrained edge devices.

## Method Summary
DistHD is a dynamic encoding framework for hyperdimensional computing that improves classification accuracy while reducing dimensionality. The method begins by encoding input features into high-dimensional hypervectors, then employs top-2 classification to identify the two most similar classes for each sample. It calculates distance matrices to identify dimensions that are closest to wrong labels and farthest from correct ones, then regenerates these misleading dimensions with new random base vectors. This adaptive learning process continues iteratively until convergence, allowing DistHD to achieve high accuracy with significantly lower dimensionality (0.5k vs 4k) compared to static encoding approaches.

## Key Results
- Achieves 8.0× lower dimensionality while maintaining or improving classification accuracy
- Delivers 5.97× faster training and 8.09× faster inference compared to state-of-the-art methods
- Demonstrates 12.90× higher robustness to hardware errors than deep neural networks
- Achieves on average 2.12% higher classification accuracy across five benchmark datasets

- Mechanism: The algorithm computes top-2 labels for each training sample, calculates distance matrices to identify dimensions closest to wrong labels and farthest from correct ones, and regenerates these dimensions with new random base vectors to improve discrimination.
- Core assumption: Misleading dimensions identified through distance matrices from top-2 classification can be regenerated to improve overall classification accuracy.
