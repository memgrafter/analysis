# Putting People in Their Place: Affordance-Aware Human Insertion into Scenes

## Quick Facts
- arXiv ID: 2304.14406
- Source URL: https://arxiv.org/abs/2304.14406
- Reference count: 40
- Primary result: Diffusion-based approach for inserting people into scenes while respecting scene affordances, trained on 2.4M video clips

## Executive Summary
This paper introduces a diffusion-based approach for inserting people into scenes in a way that respects scene affordances. The method learns to re-pose humans in video clips by using a large-scale diffusion model trained on 2.4M video clips. The model can infer realistic poses given scene context, re-pose reference people, and harmonize the composition. It can also hallucinate realistic people and scenes when prompted without conditioning. The approach demonstrates state-of-the-art performance on human-scene interaction synthesis while supporting interactive editing and multiple prompting strategies.

## Method Summary
The method trains a latent diffusion model on video clips to learn re-posing humans while respecting scene context. The model takes a masked scene image and reference person image as input, encoding them separately. Scene image features are concatenated with the noisy image and mask for UNet input, while reference person CLIP features are passed through cross-attention. The model uses classifier-free guidance during sampling to trade off quality for diversity. Training uses a simplified diffusion objective with masked scenes and reference people as conditions.

## Key Results
- Achieves FID of 10.078 and PCKh of 17.602 on the conditional generation task
- Demonstrates improved realism and naturalness compared to prior work
- Shows state-of-the-art performance on human-scene interaction synthesis
- Supports interactive editing and multiple prompting strategies

## Why This Works (Mechanism)

### Mechanism 1
Video data provides richer training signal for learning human-scene affordances than static images alone. By sourcing two random frames from the same video, the model learns the mapping between different poses of the same person in the same scene, capturing the dynamic affordances of the environment. This assumes the same person can be observed in multiple poses within a single video, providing diverse examples of possible interactions with the scene.

### Mechanism 2
Classifier-free guidance (CFG) enables trading off sample quality for diversity in generated outputs. By dropping the conditioning signals during training with a certain probability, the model learns a true unconditional distribution. At inference, CFG amplifies the difference between conditional and unconditional predictions to control diversity. This assumes dropping conditioning during training allows the model to learn a meaningful unconditional distribution that can be leveraged for guidance.

### Mechanism 3
The diffusion model architecture with cross-attention to CLIP features allows effective conditioning on both scene context and reference person appearance. The model encodes the masked scene image and reference person separately. Scene image features are concatenated with the noisy image and mask for UNet input. Reference person CLIP features are passed through cross-attention to guide the generation. This assumes CLIP features capture relevant semantic information about the reference person's appearance that can be effectively used for conditioning.

## Architecture Onboarding

- **Component map**: VAE autoencoder -> UNet-based denoising backbone with cross-attention -> CLIP image encoder -> DDIM sampler
- **Critical path**: Masked scene image + Reference person → CLIP encoding → UNet denoising → Output image
- **Design tradeoffs**: Using CLIP features vs VAE features for reference person conditioning; concatenating scene features vs using cross-attention; training on video data vs static images with augmentations
- **Failure signatures**: Poor face and limb structures due to VAE encoding limitations; lighting inconsistencies between reference person and scene; inability to handle extreme input poses
- **First 3 experiments**:
  1. Ablation study: Compare using CLIP features vs VAE features for reference person conditioning
  2. Ablation study: Compare concatenating scene features vs using cross-attention for scene conditioning
  3. Ablation study: Compare training on video data vs static images with augmentations for learning affordances

## Open Questions the Paper Calls Out

### Open Question 1
How would performance scale with even larger datasets and longer training durations? The authors mention their model is trained on 2.4M video clips and note that "by virtue of scale, our work generalizes better to diverse scenes and poses and could be scaled further [60]." This remains unresolved as the paper only trains on 2.4M video clips and does not explore scaling beyond this point.

### Open Question 2
Would pixel-based diffusion models outperform latent diffusion models for this task? The authors note that "bad faces and limbs" are common failure modes due to the first-stage VAE being unable to encode face and limb structures well, suggesting this might be alleviated by training pixel-based diffusion models. This remains unresolved as the paper only uses latent diffusion models and does not compare against pixel-based alternatives.

### Open Question 3
How sensitive is the model to the specific masking strategy used during training? The authors use a combination of bounding boxes, segmentation masks, and random scribbles, and note this "allows us to insert people at different levels of granularity." This remains unresolved as the paper does not explore how performance changes when using only one type of mask or different mask distributions.

## Limitations

- Claims about video data providing unique advantages over static images are largely theoretical without direct validation
- Classifier-free guidance effects are underspecified with no analysis of parameter sensitivity
- Conditioning architecture details are sparse with no comparison to alternative approaches

## Confidence

- **High confidence**: The core diffusion model architecture and training procedure are well-specified and reproducible
- **Medium confidence**: The qualitative improvements in realism and naturalness are supported by FID and PCKh metrics
- **Low confidence**: Claims about video data providing unique advantages over static images, and the specific effects of classifier-free guidance parameters

## Next Checks

1. **Ablation study on conditioning architecture**: Compare the proposed CLIP feature + cross-attention approach against alternatives like VAE features with concatenation to validate architectural benefits.

2. **Video vs static image training analysis**: Train identical models on video data versus augmented static images to empirically measure the claimed advantage of video for learning human-scene affordances.

3. **Classifier-free guidance parameter sweep**: Systematically vary the conditioning drop rate and guidance scale to identify optimal values and understand how CFG affects the quality-diversity tradeoff.
