# Reliable Prediction Intervals with Directly Optimized Inductive Conformal Regression for Deep Learning

## Executive Summary
This paper introduces Directly Optimized Inductive Conformal Regression (DOICR), a method that directly optimizes the width of prediction intervals (PIs) for regression problems in deep learning, while ensuring validity. Unlike previous methods that struggle to balance PI width and coverage, DOICR embeds the inductive conformal predictor within the training process and minimizes PI width through gradient descent. The method is compared against three state-of-the-art approaches (QD-soft, ICP, SCPO) on six public datasets, including tabular and image data. Results show that DOICR consistently outperforms existing methods in reducing PI width (MPIW) while maintaining validity (PICP close to the confidence level).

## Method Summary
DOICR embeds the inductive conformal predictor within the training process by defining a loss function based on the average width of prediction intervals. The method uses a normalized nonconformity measure (NCM) based on neural network predictions and uncertainty estimates. During training, the model splits the training data into a proper training set (D1) and an embedded calibration set (D2). The loss function is defined as the average width of the PIs over D1, where the width is determined by the (1−ε)th quantile of the NCMs computed on D2. This makes the loss continuous in the model parameters, allowing gradient descent to optimize it. To prevent overfitting to specific data splits, the training set is shuffled each epoch with new D1 and D2 selections.

## Key Results
- DOICR consistently outperforms existing methods in reducing Mean Prediction Interval Width (MPIW)
- Prediction Interval Coverage Probability (PICP) remains close to the confidence level across all tested confidence levels
- DOICR achieves better predictive efficiency than QD-soft, ICP, and SCPO on both tabular and image datasets
- The method is general and can be easily combined with various deep learning architectures, including CNNs

## Why This Works (Mechanism)

### Mechanism 1
- DOICR directly optimizes PI width by embedding ICP in the training loss, enabling gradient descent to minimize interval width while maintaining validity
- Core assumption: The normalized NCM and quantile computation are continuous functions of model parameters, ensuring differentiable loss
- Break condition: If NCM or quantile calculation isn't continuous in parameters, gradient descent fails

### Mechanism 2
- DOICR maintains validity by shuffling training data each epoch and re-splitting into D1/D2, preventing overfitting to specific partitions
- Core assumption: Exchangeability assumption of ICP holds across different random splits of training data
- Break condition: If data isn't exchangeable or optimizer exploits persistent structure across splits, validity may be compromised

### Mechanism 3
- DOICR integrates easily with deep learning architectures because it only requires defining a loss function, leveraging automatic differentiation
- Core assumption: Deep learning framework's automatic differentiation can handle all operations in DOICR loss function
- Break condition: If automatic differentiation cannot handle quantile computation or other operations, method fails

## Architecture Onboarding

- **Component map:** Input data → Model (neural network) → Loss function (DOICR) → Optimizer (gradient descent) → Output (optimized parameters)
- **Critical path:** Data preparation → Model definition → Loss function definition → Training (gradient descent with shuffling) → Evaluation (test ICP)
- **Design tradeoffs:** Single network for prediction/uncertainty reduces computational cost but limits flexibility; data shuffling prevents overfitting but may increase training time; confidence level choice affects validity/efficiency tradeoff
- **Failure signatures:** Non-differentiable loss function; overfitting to specific data splits (PICP drops below target); automatic differentiation failures
- **First 3 experiments:** 1) Implement DOICR with MLP on Boston Housing and compare with standard ICP; 2) Experiment with different confidence levels and observe PICP/MPIW tradeoff; 3) Implement DOICR with CNN on RSNA bone age and compare with standard ICP

## Open Questions the Paper Calls Out

- **How can the data efficiency problem in DOICR be addressed?** The paper identifies that DOICR wastes data by requiring calibration sets, reducing training examples. This remains unresolved, with evidence needed from studies comparing different data allocation strategies that improve MPIW without sacrificing PICP.

- **How can DOICR be modified to ensure conditional validity across subpopulations?** While the paper notes that validity may not be evenly spread across subpopulations, it doesn't provide concrete solutions for handling conditional validity. Evidence needed from experimental results showing DOICR implementations maintaining both high efficiency and balanced PICP across subgroups.

- **Can DOICR be effectively extended to other complex architectures beyond CNNs?** The paper only demonstrates DOICR with MLPs and CNNs, explicitly identifying extension to RNNs or Transformers as an area needing further research without providing preliminary results.

## Limitations

- DOICR suffers from data efficiency problems, requiring calibration sets that reduce available training data
- Validity may not be evenly spread across different subpopulations, potentially lacking conditional validity
- The paper only demonstrates DOICR with MLPs and CNNs, with extension to other architectures remaining unexplored

## Confidence

- **High confidence**: Core mechanism of embedding ICP within training loss for direct optimization
- **Medium confidence**: Validity preservation through data shuffling (theoretically sound but not empirically validated)
- **Medium confidence**: Ease of integration with deep learning frameworks (assumes automatic differentiation compatibility)
