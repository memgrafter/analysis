# Query-Utterance Attention with Joint modeling for Query-Focused Meeting Summarization

## Quick Facts
- arXiv ID: 2303.04487
- Source URL: https://arxiv.org/abs/2303.04487
- Reference count: 0
- Primary result: Achieves SOTA ROUGE-1/2/L scores of 37.99/13.66/33.36 on QMSum dataset

## Executive Summary
This paper addresses the challenge of generating query-focused summaries for long meeting transcripts by proposing a query-aware framework that jointly models relevance at both token and utterance levels. The proposed Query-Utterance Attention mechanism combines token-level relevance captured implicitly through attention mechanisms with utterance-level relevance explicitly calculated using a dense retrieval module (SBERT). Experiments on the QMSum dataset demonstrate significant improvements over previous state-of-the-art methods, with ROUGE-1, ROUGE-2, and ROUGE-L scores of 37.99, 13.66, and 33.36 respectively. Ablation studies confirm the effectiveness of this joint modeling approach in improving query relevance and factual consistency.

## Method Summary
The framework introduces Query-Utterance Attention, which integrates two complementary forms of relevance modeling: token-level relevance captured implicitly by attention mechanisms and utterance-level relevance computed explicitly using a dense retrieval module based on SBERT. The joint attention module incorporates both types of relevance into the generation process, allowing the model to better focus on content most relevant to the query while maintaining coherence across longer meeting transcripts. This dual-level approach addresses the limitations of existing methods that typically focus on only one level of relevance modeling.

## Key Results
- Achieves state-of-the-art ROUGE-1 score of 37.99 on QMSum dataset
- Improves ROUGE-2 score to 13.66, outperforming previous methods
- Reaches ROUGE-L score of 33.36, demonstrating strong overall summary quality

## Why This Works (Mechanism)
The effectiveness stems from the dual-level relevance modeling that captures both fine-grained token-level attention and higher-level utterance relevance. Token-level attention allows the model to focus on specific words and phrases most relevant to the query within each utterance, while the SBERT-based dense retrieval module identifies which entire utterances are most pertinent to the query context. By jointly modeling these two perspectives, the framework can better navigate the trade-off between local relevance and global coherence in meeting summarization.

## Architecture Onboarding

**Component Map:** Input Transcript -> Token Attention + SBERT Utterance Relevance -> Joint Attention Module -> Summary Generation

**Critical Path:** The joint attention module represents the critical component where token-level and utterance-level relevance scores are combined before being fed into the decoder for summary generation.

**Design Tradeoffs:** Balances computational efficiency (token attention) with semantic accuracy (utterance retrieval), but introduces complexity in combining different relevance signals.

**Failure Signatures:** If token attention dominates, summaries may miss broader context; if utterance-level relevance dominates, local relevance may be lost.

**First 3 Experiments:** 1) Ablation study removing SBERT component, 2) Baseline comparison with token-only attention, 3) Analysis of attention weight distributions across query types.

## Limitations
