# TTIDA: Controllable Generative Data Augmentation via Text-to-Text and Text-to-Image Models

## Quick Facts
- arXiv ID: 2304.08821
- Source URL: https://arxiv.org/abs/2304.08821
- Reference count: 25
- Primary result: Novel data augmentation approach combining T2T and T2I models that improves performance across image classification, cross-domain classification, and image captioning tasks

## Executive Summary
TTIDA introduces a novel data augmentation approach that leverages large-scale pre-trained text-to-text (T2T) and text-to-image (T2I) models to generate high-quality, labeled synthetic images. The method first uses a T2T model (GPT-2) to generate detailed object descriptions from simple category labels, then conditions a T2I model (GLIDE) on these descriptions to produce photo-realistic images. This approach enables flexible and controllable data augmentation that consistently outperforms traditional and GAN-based methods across diverse tasks including in-domain classification, cross-domain classification, and image captioning.

## Method Summary
TTIDA fine-tunes GPT-2 on image captions to generate detailed descriptions for each category label, then uses GLIDE to generate synthetic images based on these descriptions (or directly from labels as a baseline). The synthetic images are combined with the original dataset and used to train downstream models. The method is evaluated on CIFAR-100 for in-domain classification, Office-31/Office-Home for cross-domain classification, and MS COCO for image captioning, showing consistent improvements over traditional augmentation baselines.

## Key Results
- Outperforms traditional and GAN-based data augmentation methods on CIFAR-100, Office-31, Office-Home, and MS COCO
- Particularly effective in low-resource settings (few-shot, long-tail, adversarial scenarios)
- Improves robustness to adversarial examples, with 2.80% better accuracy on adversarial CIFAR-100
- Benefits cross-domain tasks by generating diverse, domain-agnostic synthetic images

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using a T2T model to generate detailed descriptions as prompts for a T2I model increases the diversity and controllability of generated images.
- Mechanism: The T2T model (GPT-2) takes simple label text (e.g., "bike") and produces richer, caption-like descriptions (e.g., "a white bike near the wall"). This richer prompt allows the T2I model (GLIDE) to generate more varied and contextually detailed images, which are more effective for augmentation.
- Core assumption: Detailed descriptions lead to more diverse and high-quality synthetic images than simple labels.
- Evidence anchors:
  - [abstract] "By conditioning the T2I model on detailed descriptions produced by T2T models, we are able to generate photo-realistic labeled images in a flexible and controllable manner."
  - [section] "To automatically obtain a finer prompt for the T2I model, we can first input the label text to a text-to-text (T2T) generative model... to produce a longer object description."
  - [corpus] Weak/no direct evidence; needs empirical validation.
- Break condition: If the T2T model fails to produce relevant or diverse descriptions, or if the T2I model cannot leverage the richer prompts effectively.

### Mechanism 2
- Claim: Combining large-scale pre-trained T2T and T2I models enables effective data augmentation across diverse tasks and settings.
- Mechanism: Pre-trained T2T and T2I models, trained on large-scale web data, can generate high-quality synthetic images for various downstream tasks (e.g., image classification, captioning) without requiring extensive task-specific training.
- Core assumption: Pre-trained models generalize well to new domains and tasks when used for data augmentation.
- Evidence anchors:
  - [abstract] "Experiments on in-domain classification, cross-domain classification, and image captioning tasks show consistent improvements over other data augmentation baselines."
  - [section] "We propose TTIDA... to leverage the generative capabilities of large-scale pretrained text-to-image (T2I) and text-to-text (T2T) models for the purpose of data augmentation."
  - [corpus] Weak/no direct evidence; needs empirical validation.
- Break condition: If the pre-trained models' knowledge is too domain-specific or if the generated data distribution diverges too far from the target domain.

### Mechanism 3
- Claim: TTIDA is particularly effective in low-resource and adversarial settings.
- Mechanism: In scenarios with limited data (few-shot, long-tail, adversarial), synthetic images generated by TTIDA provide additional training samples, improving model robustness and performance.
- Core assumption: Synthetic data can effectively compensate for data scarcity and help models generalize to unusual or adversarial examples.
- Evidence anchors:
  - [abstract] "Analytical studies in varied settings, including few-shot, long-tail, and adversarial, further reinforce the effectiveness of TTIDA in enhancing performance and increasing robustness."
  - [section] "Table 5: Classiﬁcation accuracy on CIFAR-100 with adversarial training images... The model trained with augmented data performs 2.80% better, demonstrating that it boosts model robustness to unusual images."
  - [corpus] Weak/no direct evidence; needs empirical validation.
- Break condition: If synthetic data introduces noise or biases that degrade model performance, or if the model overfits to synthetic samples.

## Architecture Onboarding

- Component map: Original dataset -> GPT-2 (T2T) -> GLIDE (T2I) -> Augmented dataset -> Downstream model

- Critical path:
  1. Fine-tune T2T model on image captions
  2. Generate descriptions for each label using T2T model
  3. Generate synthetic images using T2I model (with/without descriptions)
  4. Combine original and synthetic images
  5. Train downstream model on augmented dataset

- Design tradeoffs:
  - Using descriptions vs. labels as prompts for T2I model (diversity vs. similarity to original data)
  - Fine-tuning T2I model on target dataset (better alignment vs. increased training cost)
  - Number of synthetic images to generate (augmentation effectiveness vs. computational cost)

- Failure signatures:
  - T2T model generates irrelevant or repetitive descriptions
  - T2I model fails to generate realistic images or produces mode collapse
  - Augmented data distribution diverges too far from original data
  - Model overfits to synthetic data

- First 3 experiments:
  1. Ablation: Compare using descriptions vs. labels as prompts for T2I model on a simple image classification task.
  2. Scalability: Test TTIDA on datasets with varying sizes and domains to assess its robustness and generalization.
  3. Robustness: Evaluate TTIDA's effectiveness in adversarial and long-tail settings by adding unusual or imbalanced samples to the training data.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does TTIDA's performance compare when using different T2T models (e.g., T5 vs. GPT-2) for generating object descriptions?
- Basis in paper: [inferred] The paper uses GPT-2 as the T2T model but does not explore alternative T2T models like T5.
- Why unresolved: The paper does not provide a direct comparison of different T2T models for generating object descriptions, which could impact the diversity and quality of generated images.
- What evidence would resolve it: Experimental results comparing TTIDA's performance using different T2T models (e.g., GPT-2 vs. T5) for generating object descriptions would provide insights into the impact of T2T model choice on TTIDA's effectiveness.

### Open Question 2
- Question: What is the impact of fine-tuning the T2I model (GLIDE) on the target dataset (e.g., CIFAR-100) versus using the pre-trained model?
- Basis in paper: [explicit] The paper mentions that fine-tuning the T2I model on the CIFAR-100 training set brings further gains in performance (Table 7).
- Why unresolved: The paper does not provide a detailed analysis of the trade-offs and benefits of fine-tuning the T2I model versus using the pre-trained model, such as computational cost, data requirements, and potential overfitting.
- What evidence would resolve it: A comprehensive study comparing the performance, computational cost, and data requirements of fine-tuning the T2I model versus using the pre-trained model on various datasets would provide insights into the optimal approach.

## Limitations
- Limited empirical validation of core mechanisms, particularly the claim that detailed T2T-generated descriptions lead to better augmentation quality
- Potential domain gaps between pretrained models' training data and target domains not thoroughly analyzed
- Adversarial robustness claims lack complete experimental methodology specification

## Confidence
- High confidence: Basic TTIDA framework is well-specified and improvements over traditional methods are likely reproducible
- Medium confidence: Effectiveness claims in low-resource settings have supporting evidence but lack comprehensive ablation studies
- Low confidence: Mechanism-level claims about why detailed descriptions improve augmentation are primarily theoretical with weak direct empirical support

## Next Checks
1. Ablation study on prompt quality: Systematically compare synthetic images and downstream performance when using (a) simple labels, (b) T2T-generated descriptions, and (c) human-written detailed captions as prompts for the T2I model.

2. Domain gap analysis: Conduct controlled experiments where synthetic images are generated for domains with varying similarity to the T2T and T2I models' pretraining data. Measure performance degradation as domain distance increases.

3. Fine-tuning sensitivity analysis: Systematically vary the fine-tuning procedure for both GPT-2 (T2T) and GLIDE (T2I), including hyperparameters, training data size, and epochs. Quantify the impact of fine-tuning quality on final task performance.
