# Multi-pooling 3D Convolutional Neural Network for fMRI Classification of Visual Brain States

## Quick Facts
- arXiv ID: 2303.14391
- Source URL: https://arxiv.org/abs/2303.14391
- Reference count: 8
- Primary result: MP3DCNN achieved 14.918%, 3.368%, and 2.646% accuracy improvements over baseline for categorical, face sub-categorical, and object sub-categorical classifications respectively using unaveraged fMRI volumes

## Executive Summary
This paper introduces a multi-pooling 3D convolutional neural network (MP3DCNN) architecture for decoding visual brain states from fMRI data. The model leverages branch connections from early convolutional layers combined with pooling operations to extract multi-level features, addressing the challenge of local feature redundancy in fMRI classification. When tested on fMRI data from subjects viewing static images of faces and objects, the MP3DCNN demonstrated significant improvements in classification accuracy compared to previous approaches, with gains ranging from 2.6% to 14.9% across different classification tasks and averaging conditions.

## Method Summary
The MP3DCNN architecture consists of a three-layer 3D convolutional neural network with branch connections from the first and second convolutional layers. Each branch incorporates pooling and linear layers to extract features at different levels of abstraction. The model processes fMRI volumes as input, using 3D convolutions to capture spatial-temporal patterns in brain activity. The architecture is designed to reduce local feature redundancy through multiple pooling layers while passing global information to the classifier through branch connections. The model was trained and evaluated on fMRI data from subjects viewing static images of faces and objects, with experiments conducted using both unaveraged and 9-fold averaged fMRI volumes.

## Key Results
- Achieved 14.918% accuracy improvement for categorical classification using unaveraged fMRI volumes
- Obtained 3.368% and 2.646% improvements for face sub-categorical and object sub-categorical classifications respectively with unaveraged volumes
- When using 9-fold averaged fMRI volumes, showed improvements of 4.088%, 1.684%, and 13.649% for categorical, face sub-categorical, and object sub-categorical classifications

## Why This Works (Mechanism)
The MP3DCNN architecture works by addressing two key challenges in fMRI classification: local feature redundancy and the need for multi-level feature integration. The multiple pooling layers in the branches reduce redundancy by aggregating local activations into more abstract representations. The branch connections from early convolutional layers allow the model to capture both fine-grained and global features simultaneously. This multi-level feature integration enhances the model's ability to distinguish between different visual categories and subcategories by providing the classifier with complementary information at different scales of abstraction.

## Architecture Onboarding
Component map: Input fMRI volumes -> 3D CNN (3 layers) -> Branch connections (layers 1 & 2) -> Pooling + Linear layers -> Concatenation -> Classifier
Critical path: The branch connections from early layers to the classifier represent the critical innovation, enabling multi-level feature integration
Design tradeoffs: Three-layer depth balances model capacity with computational efficiency; branch connections add complexity but enable richer feature representation
Failure signatures: Overfitting indicated by large gap between training and validation accuracy; poor generalization shown by degraded performance on new datasets
First experiments: 1) Ablation study removing branch connections to quantify their contribution, 2) Varying pooling strategies to optimize redundancy reduction, 3) Testing different averaging window sizes to find optimal preprocessing

## Limitations
- Limited generalizability to other fMRI datasets and experimental paradigms beyond static image viewing
- Optimal network depth not systematically explored beyond the chosen three-layer architecture
- Potential overfitting concerns not adequately addressed through regularization or validation strategies

## Confidence
- High confidence in reported accuracy improvements (14.918%, 3.368%, 2.646% for categorical classification)
- Medium confidence that multi-pooling and branch connections are primary drivers of improvements
- Medium confidence in interpretation of reduced feature redundancy and enhanced robustness
