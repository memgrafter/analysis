# PolicyClusterGCN: Identifying Efficient Clusters for Training Graph Convolutional Networks

## Quick Facts
- **arXiv ID**: 2306.14357
- **Source URL**: https://arxiv.org/abs/2306.14357
- **Reference count**: 12
- **Primary result**: RL-based framework learns edge importance weights to improve GCN clustering, outperforming heuristic methods on node classification tasks

## Executive Summary
PolicyClusterGCN introduces a reinforcement learning framework to learn edge importance weights for graph clustering in GCN training. The approach replaces heuristic clustering methods with a policy network that predicts discrete edge weights, which are then used by a clustering algorithm to form efficient clusters for minibatch GCN training. The policy is trained via actor-critic RL using classification accuracy as rewards. Experiments on six real-world datasets show improved node classification performance compared to existing state-of-the-art models.

## Method Summary
The method trains a two-layer policy network to predict discrete edge weights for all graph edges. These weights are used by the Graclus clustering algorithm to partition the graph into clusters, which are then used for GCN minibatch training. The policy network is updated using actor-critic reinforcement learning, where rewards are computed from the classification accuracy achieved during GCN training on the generated clusters. The MDP formulation allows systematic exploration of cluster configurations through epsilon-greedy edge weight updates.

## Key Results
- PolicyClusterGCN outperforms existing state-of-the-art models on node classification tasks across six real-world datasets
- The learned policy identifies clusters with high label uncertainty, suggesting better exploration of classification boundaries
- The RL framework shows improved performance compared to heuristic clustering methods like Metis and Graclus

  - [section 3.1] "To accelerate the exploration phase through actions, we utilize exponential edge weights" and "We train the policy network using a standard policy gradient algorithm"

## Architecture Onboarding

- Component map:
  Policy network (2-layer neural network) → predicts edge weights for all edges → Clustering algorithm (Graclus) → partitions graph based on edge weights → ClusterGCN/HOGCN → trains GCN on clusters, provides reward signal → Actor-critic RL algorithm → updates policy network parameters

- Critical path: State → Policy Network → Edge Weights → Clustering → GCN Training → Reward → Policy Update

- Design tradeoffs:
  - Discrete vs continuous edge weights (discrete chosen due to clustering algorithm constraints)
  - Two-layer policy network vs GCN-based policy (two-layer chosen for memory efficiency on large graphs)
  - Epsilon-greedy exploration vs pure exploitation (exploration needed to find good cluster configurations)

- Failure signatures:
  - Policy network predictions don't change significantly across steps (exploration/exploitation balance issue)
  - GCN validation accuracy doesn't improve over training (reward signal too weak or policy not learning meaningful edge weights)
  - Clusters have high label entropy variance (policy not learning to create clusters with balanced label distributions)

- First 3 experiments:
  1. Verify policy network can predict different edge weights given different graph states (input: graph with known structure, output: varied edge weights)
  2. Test clustering algorithm sensitivity to edge weights (input: same graph with different edge weights, output: different cluster assignments)
  3. Validate reward signal computation (input: clusters with known label distributions, output: reward scores that reflect classification difficulty)

## Limitations

- The RL framework introduces significant complexity without fully justifying its superiority over simpler alternatives
- The choice of discrete edge weights over continuous values appears arbitrary and not empirically validated
- The memory efficiency argument for a two-layer policy network over GCN-based approaches is not experimentally supported

## Confidence

- **High Confidence**: The general approach of using RL to optimize graph clustering parameters is sound and well-motivated by the limitations of heuristic methods
- **Medium Confidence**: The experimental results showing performance improvements over baseline clustering methods, though the absolute gains are modest
- **Low Confidence**: The specific design choices (discrete weights, two-layer policy network) and their claimed advantages are not rigorously justified
