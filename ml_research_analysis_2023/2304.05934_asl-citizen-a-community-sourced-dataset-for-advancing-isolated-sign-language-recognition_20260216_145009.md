# ASL Citizen: A Community-Sourced Dataset for Advancing Isolated Sign Language Recognition

## Quick Facts
- **arXiv ID:** 2304.05934
- **Source URL:** https://arxiv.org/abs/2304.05934
- **Reference count:** 15
- **Primary result:** 62% accuracy and 91% recall-at-10 on unseen user test set for ISLR dictionary retrieval

## Executive Summary
This paper introduces ASL Citizen, a large-scale crowdsourced dataset for isolated sign language recognition (ISLR) containing 83,912 videos of 2,731 distinct American Sign Language (ASL) signs recorded by 52 Deaf and hard-of-hearing signers. The dataset is specifically designed for sign language dictionary retrieval tasks where users demonstrate signs to retrieve matching dictionary entries. The authors propose and evaluate both appearance-based (I3D) and pose-based (ST-GCN) models, achieving state-of-the-art results with 62% accuracy and 91% recall-at-10 on a test set of unseen users. The dataset and code are publicly available to advance ISLR research.

## Method Summary
The authors collect the ASL Citizen dataset through community sourcing, recording 83,912 videos across 2,731 ASL signs from 52 Deaf/hard-of-hearing signers in real-world environments. For model training, they employ two approaches: an I3D appearance-based model processing standardized 64-frame video clips, and an ST-GCN pose-based model using MediaPipe holistic keypoint extraction. Both models are trained for 75 epochs using Adam optimizer with learning rate 1e-3, with the I3D model using ReduceLRonPlateau scheduler and cross-entropy loss, while ST-GCN uses Cosine Annealing scheduler. The dataset is split into 35 training users, 6 validation users, and 11 test users with completely unseen test users to ensure realistic evaluation conditions.

## Key Results
- 62% accuracy on dictionary retrieval test set of unseen users
- 91% recall-at-10 on the same unseen user test set
- State-of-the-art performance compared to previous ISLR methods
- Successful demonstration of both appearance-based and pose-based approaches

## Why This Works (Mechanism)
The success stems from the high-quality, diverse dataset collected from 52 Deaf/hard-of-hearing signers in natural environments, capturing authentic sign variations. The split into unseen test users ensures the models generalize to new signers rather than memorizing individual signing styles. The combination of appearance-based and pose-based approaches leverages complementary information - I3D captures visual appearance and motion patterns while ST-GCN focuses on skeletal dynamics and hand configurations.

## Architecture Onboarding

**Component Map:** Video input -> Frame standardization (64 frames) -> I3D or ST-GCN model -> Cross-entropy loss -> Evaluation metrics

**Critical Path:** Data collection → Preprocessing (frame standardization, keypoint extraction) → Model training (75 epochs) → Unseen user evaluation

**Design Tradeoffs:** Appearance-based I3D captures rich visual information but requires more computational resources and may overfit to visual styles; pose-based ST-GCN is more robust to appearance variations but depends on reliable keypoint extraction. The unseen user split prioritizes generalization over maximum performance.

**Failure Signatures:** Poor performance on unseen users indicates overfitting to training signers' styles; high validation loss suggests insufficient model capacity or poor data quality; low keypoint detection rates compromise ST-GCN effectiveness.

## Limitations
- The paper doesn't specify exact preprocessing details for videos longer than 64 frames, creating uncertainty in reproduction
- Pose-based approach depends on MediaPipe holistic which can fail on certain camera angles or lighting conditions
- No quantification of keypoint extraction failure rates or their impact on dataset quality
- Random seed usage for data splits and model initialization is unspecified
