# Extracting Digital Biomarkers for Unobtrusive Stress State Screening from Multimodal Wearable Data

## Quick Facts
- arXiv ID: 2303.04484
- Source URL: https://arxiv.org/abs/2303.04484
- Reference count: 31
- Primary result: Achieves 85% accuracy in classifying 5 stress levels using multimodal wearable data

## Executive Summary
This study explores digital biomarkers for stress state classification using multimodal wearable and mobile phone data from the Tesserae dataset. The authors employ Random Forest machine learning to identify important stress-related features and classify 5 stress levels. Key findings include: phone activity and sleep modalities are the most important features for stress classification, including personality-related parameters (anxiety, negative affect, etc.) improves classification accuracy from 71% to 85%, and applying SMOTE to address class imbalance further enhances performance, particularly for lower-stress classes. The study achieves an 85% overall accuracy in classifying 5 stress levels, which is comparable to or better than related studies using fewer classes. The results highlight the potential of using digital biomarkers from wearable devices for unobtrusive stress monitoring in daily life scenarios.

## Method Summary
The authors use the Tesserae dataset containing multimodal wearable and mobile phone data from 35 participants over 213 days. They employ Random Forest machine learning to identify important stress-related features and classify 5 stress levels. The study investigates the impact of including personality-related parameters and applying SMOTE for class imbalance. Feature importance is determined using Random Forest's built-in methods, and classification performance is evaluated using standard metrics (precision, recall, F1-score, accuracy).

## Key Results
- Phone activity and sleep modalities are the most important features for stress classification
- Including personality-related parameters (anxiety, negative affect, etc.) improves classification accuracy from 71% to 85%
- Applying SMOTE to address class imbalance further enhances performance, particularly for lower-stress classes

### Mechanism 1
- Claim: Personality-related features (anxiety, negative affect, etc.) improve stress classification accuracy by providing psychological context that complements physiological signals.
- Mechanism: The model captures psychological dimensions of stress that may not be directly observable from wearable sensor data alone. These personality traits act as higher-level indicators that modulate how physiological responses manifest as stress.
- Core assumption: Personality traits have consistent and measurable relationships with stress levels across individuals in daily life contexts.
- Evidence anchors:
  - [abstract]: "Including personality-related parameters (anxiety, negative affect, etc.) improves classification accuracy from 71% to 85%"
  - [section]: "The two overwhelming important biomarkers are anxiety and negative affection over stress. This result is coherent with the literature [22,23]"
  - [corpus]: Weak - related papers focus on linguistic biomarkers and mental health screening, but don't directly address personality-stress relationships in wearable data
- Break condition: If personality traits are highly variable or context-dependent, making them unreliable predictors across different populations or time periods.

### Mechanism 2
- Claim: SMOTE application improves classification of lower-stress classes by addressing class imbalance through synthetic data generation.
- Mechanism: SMOTE creates synthetic examples for minority classes by interpolating between existing samples, allowing the classifier to better learn decision boundaries for underrepresented stress levels.
- Core assumption: The distribution of synthetic samples created by SMOTE is representative of the true underlying distribution of minority stress classes.
- Evidence anchors:
  - [abstract]: "Applying SMOTE to address class imbalance further enhances performance, particularly for lower-stress classes"
  - [section]: "We obtained the best classification result, 85% overall class accuracy, by adjusting class imbalance and adding extra features related to personality characteristics"
  - [corpus]: Weak - corpus papers don't specifically address SMOTE application in stress detection, though class imbalance is a common ML challenge
- Break condition: If the synthetic data generated by SMOTE doesn't accurately represent the true distribution of stress states, leading to overfitting on unrealistic patterns.

### Mechanism 3
- Claim: Multimodal fusion (combining phone activity, sleep, heart rate, and location data) captures complementary aspects of stress manifestation across different behavioral and physiological dimensions.
- Mechanism: Different stress indicators manifest across multiple modalities - sleep disruption, changes in phone usage patterns, physiological arousal (heart rate), and environmental context (location). Combining these provides a more complete picture than any single modality alone.
- Core assumption: Stress manifests consistently across multiple measurable dimensions in daily life, and these dimensions are sufficiently independent to provide complementary information.
- Evidence anchors:
  - [abstract]: "Phone activity and sleep modalities are the most important features for stress classification"
  - [section]: "In all cases, phone activity and sleep modalities-related markers are the most relevant to stress"
  - [corpus]: Weak - related papers focus on single modalities or don't explicitly address multimodal fusion for stress detection
- Break condition: If stress manifestations are highly individual-specific or if certain modalities are redundant, multimodal fusion may not provide additional value.

- Design tradeoffs:
  - Using Random Forest vs. deep learning: RF provides better interpretability through feature importance but may miss complex nonlinear patterns
  - SMOTE vs. other imbalance techniques: SMOTE is simple but may create unrealistic synthetic samples
  - Including personality features vs. pure physiological data: Improves accuracy but requires survey data collection

- Failure signatures:
  - Low precision on higher stress classes despite SMOTE: Indicates synthetic samples may not represent true patterns
  - Feature importance concentrated in one modality: Suggests missing complementary information
  - Poor generalization across different populations: Indicates dataset may be too specific to the studied population

- First 3 experiments:

  2. Apply SMOTE and retrain RF to measure improvement in minority class performance
  3. Add personality features and compare performance to the baseline to quantify their contribution
