# EDeR: A Dataset for Exploring Dependency Relations Between Events

## Quick Facts
- arXiv ID: 2304.01612
- Source URL: https://arxiv.org/abs/2304.01612
- Reference count: 23
- Key outcome: Human-annotated dataset for event dependency relations achieves 82.61% accuracy on binary classification

## Executive Summary
This paper introduces EDeR, a human-annotated dataset that identifies when one event is a required or optional argument of another event. The dataset integrates with OntoNotes annotations and provides refined event representations that improve semantic role labeling and co-reference resolution performance. Baseline models fine-tuned on EDeR achieve up to 82.61% accuracy in binary argument/non-argument classification, though three-way classification proves more challenging with only 70.79% accuracy.

## Method Summary
The method involves creating a human-annotated dataset of event dependency relations using a multi-stage quality control process with screening tests, qualification stages, and expert supervision. The dataset is built from OntoNotes, extracting candidate event pairs where one event predicate appears within another event's span. Baseline models range from heuristic rules to fine-tuned transformer models (BERT, RoBERTa, DistilBERT, XLNet, GPT-2), with marked-predicate sentence input. The event dependency relations are then integrated into downstream tasks like semantic role labeling and co-reference resolution to demonstrate performance improvements.

## Key Results
- Best binary classification model achieves 82.61% accuracy
- Three-way classification (required, optional, non-argument) reaches 70.79% accuracy
- Event dependency relations improve semantic role labeling and co-reference resolution performance
- Performance varies significantly based on sentence length and event distance

## Limitations
- Dataset covers only predicate-argument relationships, excluding other event-event relations like causation or temporal sequences
- Annotation relies on human judgment for required/optional distinction, potentially introducing subjectivity
- Performance improvements demonstrated primarily on OntoNotes, limiting generalizability to other domains

## Confidence

- **High Confidence**: The dataset construction methodology and quality control procedures are well-documented and follow established annotation practices. The baseline model performance results are reproducible given access to the dataset and standard pre-trained models.

- **Medium Confidence**: The claim that event dependency relations improve downstream task performance is supported by experimental results but requires further validation across diverse datasets and task types. The three-way classification difficulty is observed but the specific challenges are not fully characterized.

- **Low Confidence**: The generalizability of the annotation scheme to languages other than English and the scalability of the manual annotation approach for larger datasets remain uncertain without additional experiments.
