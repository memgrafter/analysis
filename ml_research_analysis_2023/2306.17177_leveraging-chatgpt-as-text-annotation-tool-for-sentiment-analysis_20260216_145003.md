# Leveraging ChatGPT As Text Annotation Tool For Sentiment Analysis

## Quick Facts
- arXiv ID: 2306.17177
- Source URL: https://arxiv.org/abs/2306.17177
- Reference count: 11
- Primary result: ChatGPT achieved 67% accuracy on tweets (20% improvement over best lexicon-based algorithm) and 94% on Amazon reviews (25% improvement)

## Executive Summary
This paper explores using ChatGPT as a text annotation tool for sentiment analysis, comparing it to traditional lexicon-based methods on two distinct datasets. The study demonstrates that ChatGPT significantly outperforms existing tools like VADER and TextBlob, achieving 20-25% accuracy improvements on both sports tweets and Amazon product reviews. The research highlights ChatGPT's superior ability to handle complex language features like sarcasm and emojis that typically challenge conventional sentiment analysis approaches.

## Method Summary
The study used the ChatGPT API (gpt-3.5-turbo) with a consistent prompt to classify sentiment in two datasets: 6,201 soccer-related tweets and 2,000 Amazon product reviews. Performance was compared against VADER and TextBlob using standard evaluation metrics (accuracy, precision, recall, F1-score). The soccer tweets dataset included 1,214 samples with emojis, while the Amazon dataset contained an equal split of positive and negative reviews. Both lexical-based tools and ChatGPT were evaluated using the same three sentiment categories (positive, neutral, negative).

## Key Results
- ChatGPT achieved 67% accuracy on soccer tweets, representing a 20% improvement over the best lexicon-based method
- On Amazon reviews, ChatGPT reached 94% accuracy, a 25% improvement over traditional approaches
- ChatGPT demonstrated superior handling of sarcasm and emojis compared to VADER and TextBlob
- The model returned neutral classifications or requested additional information for 58 Amazon review samples

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ChatGPT's large language model architecture enables better understanding of context, sarcasm, and emojis compared to lexicon-based methods
- Mechanism: The model's pre-training on diverse text data allows it to capture nuanced language patterns that traditional sentiment lexicons miss
- Core assumption: The model's internal representations contain sufficient contextual information to disambiguate sentiment in complex cases
- Evidence anchors: "ChatGPT achieves a remarkable increase in accuracy of 20% for the tweets dataset and approximately 25% for the Amazon reviews dataset"; "Both lexical-based tools could not identify the sarcasm and output the sentiment as positive, whereas ChatGPT understands the sarcasm and explains why it is negative"
- Break condition: If prompt phrasing changes the sentiment output significantly

### Mechanism 2
- Claim: Zero-shot learning capability allows ChatGPT to perform sentiment annotation without task-specific fine-tuning
- Mechanism: The model's general language understanding enables it to infer sentiment polarity from textual cues without requiring domain-specific training data
- Core assumption: The model's pre-training captures sufficient sentiment-related knowledge across domains
- Evidence anchors: "These large language models can perform a variety of tasks without much training"; "It is evaluated on two distinct sentiment analysis datasets with varying purposes"
- Break condition: When domain-specific jargon or highly specialized language is used that wasn't present in the training data

### Mechanism 3
- Claim: ChatGPT's conversational nature enables interactive clarification for ambiguous sentiment cases
- Mechanism: The model can request additional context when uncertain, potentially improving annotation accuracy over static algorithms
- Core assumption: The model's ability to recognize its own uncertainty and request clarification translates to better sentiment classification
- Evidence anchors: "ChatGPT could not classify 58 tweets as it termed them neutral or it needed more information"; "It can answer questions on various topics and tasks"
- Break condition: If clarification requests significantly slow down the annotation process beyond acceptable limits

## Architecture Onboarding

- Component map: Data input → ChatGPT API call with prompt → Response parsing → Sentiment label extraction → Evaluation metrics calculation
- Critical path: API call reliability and response parsing accuracy are the most critical components
- Design tradeoffs: Speed vs accuracy (ChatGPT is slower but more accurate than lexicon methods), cost vs performance (API costs vs manual annotation), consistency vs flexibility (model variability vs fixed rules)
- Failure signatures: Inconsistent sentiment labels for identical inputs, API rate limiting, parsing errors for unexpected response formats
- First 3 experiments:
  1. Test the same prompt across multiple ChatGPT API calls to measure output consistency
  2. Compare performance on texts with and without emojis to quantify emoji handling improvement
  3. Measure response time and cost per annotation to establish operational feasibility

## Open Questions the Paper Calls Out
The authors identify three key open questions: (1) How does ChatGPT's performance vary across different languages and cultural contexts when used for sentiment analysis text annotation? (2) What are the specific computational resources and costs required to implement ChatGPT as a text annotation tool at scale compared to traditional methods? (3) How does ChatGPT's sentiment annotation performance compare when dealing with domain-specific terminology and jargon across different industries?

## Limitations
- The exact ChatGPT prompt used for sentiment annotation is not specified, limiting reproducibility
- The study lacks analysis of computational cost and latency implications at scale
- Performance with domain-specific terminology and jargon beyond sports and e-commerce is not evaluated
