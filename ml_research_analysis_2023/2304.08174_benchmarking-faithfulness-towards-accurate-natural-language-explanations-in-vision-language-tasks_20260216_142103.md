# Benchmarking Faithfulness: Towards Accurate Natural Language Explanations in Vision-Language Tasks

## Quick Facts
- arXiv ID: 2304.08174
- Source URL: https://arxiv.org/abs/2304.08174
- Reference count: 0
- Primary result: Ablating redundant inputs to explanation modules increases faithfulness on e-SNLI-VE but not consistently across all datasets

## Executive Summary
This thesis develops three faithfulness metrics for natural language explanations (NLEs) in vision-language tasks: Attribution-Similarity, NLE-Sufficiency, and NLE-Comprehensiveness. The study evaluates how well NLEs represent the reasoning process of models by comparing input feature relevance distributions for task answers and explanations. Using the e-ViL benchmark and ablation models of e-UG, the research demonstrates that removing redundant inputs (question and answer text) to the explanation module increases faithfulness on the e-SNLI-VE dataset as measured by Attribution-Similarity, though results differ across datasets.

## Method Summary
The study implements an ablation analysis on the e-UG model architecture, systematically removing redundant inputs (question and answer text) from the GPT-2 explanation module. Using Integrated Gradients for feature attribution, the research calculates three faithfulness metrics comparing input relevance distributions between task answers and explanations. The evaluation framework measures task accuracy, explanation quality (using METEOR and BERTScore), and faithfulness across baseline and ablation model variants on VQA-X and e-SNLI-VE datasets.

## Key Results
- Removing redundant inputs to explanation modules increases Attribution-Similarity on e-SNLI-VE linguistic modality
- NLE-Sufficiency and NLE-Comprehensiveness metrics are not correlated with Attribution-Similarity
- Results vary significantly across datasets, with no consistent faithfulness improvement on VQA-X or e-SNLI-VE visual modality

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The proposed faithfulness metrics capture different aspects of explanation quality because they are grounded in distinct theoretical rationales.
- Mechanism: Attribution-Similarity measures the alignment between input relevance distributions for task answers and explanations. NLE-Sufficiency and NLE-Comprehensiveness assess whether explanation-relevant features are sufficient and comprehensive for task prediction.
- Core assumption: Different theoretical foundations for faithfulness (alignment vs sufficiency vs comprehensiveness) yield complementary insights.
- Evidence anchors:
  - [abstract] "our analysis demonstrates that NLE-Sufficiency and -Comprehensiveness are not necessarily correlated to Attribution-Similarity"
  - [section 4.1.2] "we argue that across a large number of complex inputs and operations, a consistent similarity of ra ~ re is a plausible basis for assuming an explanation-module me to faithfully represent ma"
  - [corpus] Weak - no direct citations to similar multi-metric approaches
- Break condition: If all metrics converge on the same rankings, the theoretical distinction may be unnecessary.

### Mechanism 2
- Claim: Ablating redundant inputs forces explanation modules to rely on task-relevant features, increasing faithfulness.
- Mechanism: By removing the question and answer text from the explanation module's input, the module must learn to extract relevant information from task-module features, leading to more faithful explanations.
- Core assumption: Redundant inputs provide shortcuts for generating explanations without engaging with task-relevant reasoning.
- Evidence anchors:
  - [abstract] "the removal of redundant inputs to the explanation-generation module of e-UG successively increases the model's faithfulness on the linguistic modality"
  - [section 4.4] "we hypothesize that removing redundant inputs increases the faithfulness of the explanations"
  - [corpus] Moderate - related work on "removing redundant features" exists but not in VL-NLE context
- Break condition: If ablation models show no faithfulness improvement or explanation quality degradation.

### Mechanism 3
- Claim: The combination of task accuracy and explanation quality metrics provides a more complete evaluation than either alone.
- Mechanism: Task accuracy ensures the model solves the problem correctly, while explanation metrics (including faithfulness) assess the quality of reasoning communicated.
- Core assumption: High task accuracy with poor explanations or vice versa indicates different failure modes that need separate assessment.
- Evidence anchors:
  - [abstract] "the study shows that removing redundant inputs... increases faithfulness on the e-SNLI-VE dataset as measured by Attribution-Similarity"
  - [section 5.4] "the automatic explanation metrics are only correlated with human judgment"
  - [corpus] Strong - e-ViL benchmark explicitly combines task and explanation scores
- Break condition: If task accuracy perfectly predicts explanation quality, the separate metrics may be redundant.

## Architecture Onboarding

- Component map:
  Task module (UNITER transformer) → processes image and text to predict answer
  Explanation module (GPT-2) → generates natural language explanation
  Attribution module (Integrated Gradients) → computes feature relevance
  Evaluation pipeline → calculates task accuracy, explanation quality, and faithfulness metrics

- Critical path:
  Task module output → Explanation module input → Explanation generation → Attribution computation → Faithfulness evaluation

- Design tradeoffs:
  - Modularity vs. integration: Separate modules allow flexibility but may reduce faithfulness
  - Computational cost: Integrated Gradients requires multiple forward passes per example
  - Dataset size vs. generalization: Small datasets may not capture diverse reasoning patterns

- Failure signatures:
  - Low attribution similarity despite high explanation quality → explanations may be plausible but not faithful
  - High sufficiency but low comprehensiveness → explanations use important features but miss contextual information
  - Ablation models fail to generate explanations → task-module features insufficient for explanation generation

- First 3 experiments:
  1. Implement Attribution-Similarity metric on a simple vision-language model
  2. Compare attribution distributions between task answer and explanation for a single example
  3. Create ablation models by removing question input and measure impact on faithfulness metrics

## Limitations
- Results vary significantly across datasets, with no consistent faithfulness improvement on VQA-X or e-SNLI-VE visual modality
- The lack of correlation between different faithfulness metrics suggests either complementary measurement or fundamental measurement issues
- The study is primarily constrained by the e-ViL benchmark's scope and specific ablation models tested

## Confidence
- Medium: The ablation study showing increased faithfulness on e-SNLI-VE with redundant input removal, given dataset-specific effects
- Medium: The theoretical distinction between faithfulness metrics, pending convergence analysis
- Low: Generalization of findings across diverse vision-language tasks beyond the tested datasets

## Next Checks
1. Cross-dataset validation: Replicate the ablation study on additional vision-language datasets (e.g., VCR, GQA) to assess generalizability of the redundant input removal effect

2. Metric convergence analysis: Systematically measure correlation between faithfulness metrics across different model architectures and input types to determine if they capture distinct or overlapping aspects of explanation quality

3. Human evaluation validation: Conduct targeted human studies comparing explanations from baseline and ablation models on critical examples where automatic metrics show the largest discrepancies to validate whether faithfulness improvements translate to human perception of explanation quality
