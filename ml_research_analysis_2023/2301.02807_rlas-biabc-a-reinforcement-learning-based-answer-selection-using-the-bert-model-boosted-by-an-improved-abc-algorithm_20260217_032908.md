# RLAS-BIABC: A Reinforcement Learning-Based Answer Selection Using the BERT Model Boosted by an Improved ABC Algorithm

## Quick Facts
- arXiv ID: 2301.02807
- Source URL: https://arxiv.org/abs/2301.02807
- Reference count: 40
- Primary result: Outperforms state-of-the-art methods on LegalQA, TrecQA, and WikiQA datasets

## Executive Summary
This paper introduces RLAS-BIABC, a novel answer selection method that combines reinforcement learning with BERT embeddings and an improved artificial bee colony (ABC) algorithm. The approach treats answer selection as a sequential decision-making problem where an agent classifies QA pairs and receives rewards based on minority class importance. The improved ABC algorithm pretrains policy weights to address class imbalance, while RL fine-tunes the model for optimal performance. Experimental results demonstrate significant improvements over existing methods, particularly on the LegalQA dataset where RLAS-BIABC achieves more than 40% error reduction compared to IKAAS.

## Method Summary
RLAS-BIABC treats answer selection as a reinforcement learning problem where QA pairs are sequentially processed by an agent that makes classification decisions. The method uses BERT embeddings to represent question-answer pairs, then employs an improved ABC algorithm to pretrain policy weights, addressing the inherent class imbalance in answer selection tasks. The pretraining phase initializes the policy network weights using ABC optimization, which is then refined through RL fine-tuning. The reward function is designed to emphasize the importance of correctly identifying minority class instances (relevant answers). This hybrid approach leverages the global search capability of ABC for initialization and the adaptive learning of RL for refinement, resulting in a robust answer selection system.

## Key Results
- RLAS-BIABC achieves significant improvements in MAP and MRR metrics across all three benchmark datasets
- On LegalQA dataset, RLAS-BIABC reduces error by more than 40% compared to IKAAS in MAP
- The method shows 24% improvement in MRR over IKAAS on LegalQA dataset
- Performance gains are consistent across TrecQA and WikiQA datasets, though less pronounced

## Why This Works (Mechanism)
The mechanism works because the ABC pretraining provides a globally optimized initialization that escapes poor local minima common in RL training. The improved ABC algorithm specifically addresses class imbalance during initialization, giving the RL fine-tuning phase a better starting point. The reward function's emphasis on minority class importance ensures the policy learns to prioritize relevant answer detection, which is crucial for practical QA systems where false negatives are particularly costly.
