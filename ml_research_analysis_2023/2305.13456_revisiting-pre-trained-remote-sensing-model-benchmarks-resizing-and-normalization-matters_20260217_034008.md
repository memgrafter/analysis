# Revisiting pre-trained remote sensing model benchmarks: resizing and normalization matters

## Quick Facts
- **arXiv ID:** 2305.13456
- **Source URL:** https://arxiv.org/abs/2305.13456
- **Reference count:** 40
- **Primary result:** Proper image preprocessing (resizing and normalization) significantly improves performance of pre-trained models on remote sensing datasets.

## Executive Summary
This paper demonstrates that standard image preprocessing steps - specifically resizing to the model's training dimensions (224x224) and appropriate normalization - have a substantial impact on transfer learning performance in remote sensing applications. The authors show that ImageNet-pretrained models, when used with correct preprocessing, can compete with state-of-the-art methods. Their experiments across seven satellite and aerial imagery datasets reveal that many previous studies have overlooked these fundamental preprocessing requirements, leading to suboptimal performance and misleading benchmarks.

## Method Summary
The authors systematically evaluate the impact of image preprocessing on transfer learning performance across seven remote sensing datasets. They test different resizing strategies (224x224 vs. 384x384) and normalization methods (channel-wise standardization vs. reflectance conversion). The study compares ResNet-50 models pretrained on ImageNet with various self-supervised learning methods and introduces two new baseline methods: MOSAIKS (using polynomial features) and image statistics. Experiments are conducted using consistent evaluation protocols across all datasets to ensure fair comparisons.

## Key Results
- Proper preprocessing yields a 32.28% increase in overall accuracy on the So2Sat dataset
- EuroSAT accuracy improves by 11.16% when using correct preprocessing
- ImageNet-pretrained models with proper preprocessing achieve competitive results compared to state-of-the-art methods
- MOSAIKS and image statistics baselines outperform several self-supervised learning approaches on multispectral datasets

## Architecture Onboarding

### Component Map
Input images -> Preprocessing (resize + normalize) -> Pretrained model -> Classification head -> Output predictions

### Critical Path
The critical path is the preprocessing stage, where incorrect resizing or normalization directly impacts all downstream performance.

### Design Tradeoffs
- Resizing to 224x224 maintains consistency with ImageNet pretraining but may lose some spatial detail
- Channel-wise standardization is faster but reflectance conversion may better preserve spectral information
- Using larger input sizes (384x384) can capture more detail but increases computational cost

### Failure Signatures
- Performance drops when input dimensions don't match pretraining dimensions
- Poor results when using inappropriate normalization for the data type
- Inconsistent benchmarking due to unreported or incorrect preprocessing steps

## Limitations
- Findings primarily apply to classification tasks on medium-resolution satellite and aerial imagery
- Analysis focuses on ResNet-based architectures, may not generalize to other backbones
- Does not address semantic segmentation or object detection tasks
