# DetGPT: Detect What You Need via Reasoning

## Quick Facts
- arXiv ID: 2305.14167
- Source URL: https://arxiv.org/abs/2305.14167
- Reference count: 12
- Key outcome: Introduces a reasoning-based object detection system using natural language queries to locate objects in images

## Executive Summary
DetGPT is a novel object detection system that enables users to locate objects in images using natural language instructions. Unlike conventional object detection methods, DetGPT leverages large language models and open-vocabulary detectors to perform reasoning within the context of user instructions and the visual scene. The system automatically locates objects of interest based on expressed desires, even if the object is not explicitly mentioned, enabling more sophisticated and intuitive interactions between humans and machines.

## Method Summary
DetGPT employs a two-stage approach for reasoning-based object detection. First, a multi-modal model interprets the image and instruction to generate relevant object names. Then, an open-vocabulary detector localizes these objects in the image. The system is trained using a curated dataset of 5000 images with ~30000 query-answer pairs, aligned with the COCO dataset for fine-tuning. The multi-modal model (e.g., BLIP-2 + Vicuna) is fine-tuned for instruction following, and then integrated with an open-vocabulary detector (e.g., Grounding-DINO) to perform the final object detection.

## Key Results
- DetGPT enables natural language queries for object localization, allowing users to interact using natural language instructions
- The system can automatically locate objects of interest based on expressed desires, even if the object is not explicitly mentioned
- DetGPT demonstrates potential for more sophisticated and intuitive interactions between humans and machines, applicable across various fields including robotics, automation, and autonomous driving

## Why This Works (Mechanism)
DetGPT's effectiveness stems from its ability to combine the reasoning capabilities of large language models with the visual understanding of open-vocabulary object detectors. By leveraging the multi-modal model to interpret user instructions in the context of the visual scene, DetGPT can generate relevant object names that may not be explicitly mentioned. The open-vocabulary detector then localizes these objects, enabling accurate object detection based on natural language queries.
