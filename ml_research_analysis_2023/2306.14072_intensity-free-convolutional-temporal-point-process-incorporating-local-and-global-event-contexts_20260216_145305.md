# Intensity-free Convolutional Temporal Point Process: Incorporating Local and Global Event Contexts

## Quick Facts
- arXiv ID: 2306.14072
- Source URL: https://arxiv.org/abs/2306.14072
- Reference count: 40
- Key outcome: CTPP model incorporating local and global contexts outperforms state-of-the-art TPP models on three real-world datasets

## Executive Summary
This paper introduces CTPP, a convolutional neural network-based temporal point process model that captures both local temporal dependencies and global event history. The model uses continuous convolution kernels to encode local context within a specified horizon, while a recurrent neural network processes the global event sequence. This dual-context approach enables comprehensive modeling of event patterns in sequential data. The method is evaluated on three real-world datasets, demonstrating superior performance compared to existing state-of-the-art temporal point process models in terms of negative log-likelihood and prediction accuracy.

## Method Summary
CTPP combines convolutional neural networks with recurrent neural networks to model temporal point processes. The model processes events through two parallel pathways: a local context pathway using continuous convolution kernels to capture dependencies within a fixed temporal horizon, and a global context pathway using RNNs to encode the entire event history. These representations are then combined to predict the next event time and type. The convolutional component allows the model to focus on recent, relevant events while the RNN maintains long-term dependencies, creating a comprehensive representation of the event sequence.

## Key Results
- CTPP outperforms state-of-the-art TPP models on three real-world datasets
- The model achieves better negative log-likelihood scores compared to baseline methods
- CTPP demonstrates superior event prediction accuracy across all evaluated datasets

## Why This Works (Mechanism)
The model's effectiveness stems from its ability to simultaneously capture both local and global temporal dependencies in event sequences. Local context is encoded through continuous convolution kernels that can flexibly adapt to different temporal scales within a specified horizon, allowing the model to focus on immediately relevant events. The RNN-based global context pathway maintains information about the entire event history, ensuring that long-term patterns are not lost. By combining these two complementary representations, CTPP can model complex event dynamics that neither purely local nor purely global approaches can capture effectively.

## Architecture Onboarding
Component Map: Event sequence -> Convolutional local context pathway -> RNN global context pathway -> Combined representation -> Event prediction
Critical Path: Input events are processed through both local (convolution) and global (RNN) pathways, then combined for final prediction
Design Tradeoffs: Fixed local context horizon provides computational efficiency but may miss longer-range local dependencies; RNNs offer strong global context but can struggle with very long sequences
Failure Signatures: Poor performance on datasets with highly variable temporal scales; potential overfitting when local context horizon is too short relative to event frequency
First Experiments:
1. Train CTPP with only the local context pathway to isolate its contribution
2. Train with only the global context pathway to establish baseline performance
3. Vary the local context horizon parameter across different datasets to study sensitivity

## Limitations
- Evaluation focuses primarily on likelihood-based metrics and accuracy, potentially missing practical deployment considerations
- Fixed local context horizon parameter lacks sensitivity analysis across datasets with varying temporal scales
- Limited ablation studies to isolate the specific contribution of convolutional components versus other architectural choices

## Confidence
High: The methodological contribution of combining local convolutions with RNN-based global context is novel and technically sound
Medium: Empirical superiority claims are based on limited baseline comparisons without statistical significance testing or broader state-of-the-art inclusion
Low: Generalizability of local context benefits is uncertain due to fixed horizon assumption and limited dataset diversity
