# CombLM: Adapting Black-Box Language Models through Small Fine-Tuned Models

## Quick Facts
- arXiv ID: 2305.16876
- Source URL: https://arxiv.org/abs/2305.16876
- Authors: 
- Reference count: 11
- Primary result: CombLM achieves up to 9% improvement in perplexity for domain adaptation and 6% in BLEURT for machine translation compared to baselines.

## Executive Summary
This paper proposes CombLM, a method for adapting large black-box language models to new domains or tasks without access to their weights. The approach involves fine-tuning a small white-box LM on target domain data and combining its probability distributions with those of the large black-box LM through a learned combination function. The combination function is a small neural network trained on a small validation set, allowing the model to dynamically weight the specialized domain expert and general knowledge source for each token prediction.

## Method Summary
CombLM works by first fine-tuning a small LM (OPT-1.3B) on domain-specific data to create a domain expert. A small combination network is then trained on a validation set to merge the probability distributions from both the small fine-tuned LM and the large black-box LM (OPT-30B). The combination function can take various forms, from simple averaging to sophisticated neural networks that incorporate entropy information. This approach requires only forward passes through both LMs and a small validation set to train the combination function, making it computationally efficient compared to fine-tuning the large black-box model directly.

## Key Results
- CombLM improves perplexity by up to 9% compared to the large black-box LM alone on domain adaptation tasks
- For machine translation, CombLM achieves up to 6% improvement in BLEURT scores over the large LM baseline
- The combination function can be effectively trained with as few as 100 sequences
- Different combination architectures (entropy-scalar, full-vector) show varying performance depending on validation set size

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The combination function learns to dynamically weight the small domain expert and large black-box LM based on which model is more confident for each token.
- Mechanism: The combination network takes probability distributions from both models as input and outputs a new probability distribution, giving more weight to the more confident model for each token.
- Core assumption: Output distribution entropies are informative signals about which model should be trusted for each token prediction.
- Evidence anchors:
  - [abstract]: "The combination function is a small neural network trained on a small validation dataset."
  - [section 2]: "The entropy combinations are motivated by the fact that we expect output distribution entropies to be informative to the combination function."
- Break condition: If both models have similar confidence levels across all tokens, the dynamic weighting may not provide significant benefit.

### Mechanism 2
- Claim: The small fine-tuned domain expert provides specialized knowledge while the large black-box LM provides general knowledge, and their combination achieves better performance than either alone.
- Mechanism: The small LM becomes an expert in the target domain while the large LM retains broad general knowledge, allowing the combination function to leverage both knowledge sources.
- Core assumption: Domain-specific and general knowledge are complementary and can be effectively combined at the probability level.
- Evidence anchors:
  - [abstract]: "Our approach fine-tunes a small white-box LM and combines it with the large black-box LM at the probability level."
- Break condition: If the domain expert overfits to the small domain-specific dataset, the combination may not improve performance.

### Mechanism 3
- Claim: The combination function can be learned with minimal data and compute requirements compared to fine-tuning the large black-box LM.
- Mechanism: Instead of fine-tuning the 30B parameter OPT model, only a small combination network needs to be trained on a small validation set.
- Core assumption: A small neural network can effectively learn to combine probability distributions without requiring extensive training data or compute resources.
- Evidence anchors:
  - [abstract]: "Our approach fine-tunes a small white-box LM and combines it with the large black-box LM at the probability level through a small network, learned on a small validation set."
- Break condition: If the combination function requires more capacity or data than expected, the computational advantage over fine-tuning may diminish.

## Architecture Onboarding

- Component map: Large black-box LM (OPT-30B) -> Small fine-tuned LM (OPT-1.3B) -> Combination function -> Validation set -> Domain-specific dataset

- Critical path:
  1. Fine-tune small LM on domain-specific data
  2. Collect validation set (1000 sequences)
  3. Generate probability distributions from both LMs
  4. Train combination function on validation set
  5. Use combined model for inference

- Design tradeoffs:
  - Capacity vs. data efficiency: Higher capacity combination functions perform better with more data but may overfit with less
  - In-domain vs. general performance: Fitting on domain data improves in-domain performance but may degrade general performance
  - Compute cost: Fine-tuning large LM vs. training small combination function

- Failure signatures:
  - No improvement over large LM: Combination function may be too simple or validation set too small
  - Degradation in performance: Overfitting of combination function or poor domain expert fine-tuning
  - High perplexity on general text: Combination function too focused on domain-specific patterns

- First 3 experiments:
  1. Implement mean combination as baseline to verify that learned combinations can outperform simple averaging
  2. Test entropy-scalar combination on a small dataset to validate the entropy-based weighting hypothesis
  3. Compare performance when fitting combination function on domain data vs. mixed domain-general data to study the general performance tradeoff

## Limitations
- Validation Data Size Impact: The relationship between validation set size and performance is not fully characterized
- Combination Function Expressiveness: The optimal architecture for different scenarios remains unclear
- Generalization Across Domains: Results focus on four specific domains, limiting broader applicability claims

## Confidence

**High Confidence**: The core claim that CombLM can improve performance over both the large black-box LM and the small fine-tuned model is well-supported by experimental results across multiple domains and tasks.

**Medium Confidence**: The claim about CombLM's computational efficiency relative to fine-tuning large LMs is reasonable but not empirically demonstrated with runtime comparisons.

**Low Confidence**: The claim that CombLM preserves general language modeling capabilities while improving domain-specific performance lacks comprehensive evidence.

## Next Checks

1. **Scalability Analysis**: Systematically test how CombLM performance scales with validation set size (100, 500, 1000, 5000 sequences) across different domains to establish minimum effective training set size.

2. **Architecture Sensitivity Study**: Conduct a more comprehensive exploration of combination function architectures, including deeper networks and attention-based mechanisms, to determine whether current architectures are near-optimal.

3. **Cross-Domain Transferability**: Evaluate whether combination functions trained on one domain can effectively transfer to similar but distinct domains to assess generality of learned combination patterns.
