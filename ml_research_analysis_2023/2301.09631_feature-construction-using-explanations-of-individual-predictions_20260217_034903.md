# Feature construction using explanations of individual predictions

## Quick Facts
- arXiv ID: 2301.09631
- Source URL: https://arxiv.org/abs/2301.09631
- Reference count: 14
- Proposed method uses perturbation-based explanation techniques to identify co-occurring attributes for feature construction

## Executive Summary
This paper introduces Explainable Feature Construction (EFC), a method that leverages perturbation-based explanation techniques like SHAP and IME to identify groups of co-occurring attributes. These identified attribute groups are then used to reduce the search space for feature construction, making the process more efficient. The method is evaluated across 10 synthetic datasets, 30 real-world UCI datasets, and one real-world financial dataset. Results demonstrate that EFC significantly improves classification accuracy for various classifiers including Decision Trees, Naive Bayes, SVM-RBF, and kNN, while also reducing computational time compared to exhaustive search methods.

## Method Summary
EFC employs perturbation-based explanation methods to generate local explanations for individual predictions. These explanations identify which attributes co-occur and contribute to specific outcomes. The method then uses these co-occurrence patterns to form attribute groups that serve as candidate features for construction. By focusing the search on these pre-identified groups rather than all possible attribute combinations, EFC substantially reduces the computational complexity of the feature construction process while maintaining or improving classification performance.

## Key Results
- EFC significantly improves classification accuracy across multiple classifier types (DT, NB, SVM-RBF, kNN) compared to baseline methods
- Computational time is reduced compared to exhaustive search approaches due to targeted search space
- Constructed features demonstrate interpretability and show similarity to human-created features in the financial domain

## Why This Works (Mechanism)
EFC works by leveraging the insights from local explanation methods to identify meaningful attribute relationships. Perturbation-based explanations reveal which attributes tend to co-occur in predictions for specific outcomes, effectively capturing domain-relevant patterns. By using these patterns to guide feature construction, the method focuses computational resources on attribute combinations that are more likely to be meaningful and predictive, rather than exploring all possible combinations indiscriminately.

## Foundational Learning
- **Perturbation-based explanation methods (SHAP, IME)**: These methods generate local explanations by systematically perturbing input features and observing prediction changes. Understanding their mechanics is crucial for grasping how EFC identifies attribute co-occurrences.
- **Feature construction search space complexity**: The combinatorial explosion of possible feature combinations necessitates search space reduction techniques. EFC addresses this fundamental challenge.
- **Classification accuracy metrics**: Understanding standard evaluation metrics is essential for interpreting the reported performance improvements across different classifier types.
- **Interpretability in feature engineering**: The ability to create interpretable features that align with domain knowledge is increasingly important for practical applications.

## Architecture Onboarding

**Component Map**
- Input data → Perturbation-based explanation method (SHAP/IME) → Attribute co-occurrence identification → Feature construction search space reduction → Classification model training → Performance evaluation

**Critical Path**
The critical path flows from perturbation-based explanations through attribute co-occurrence identification to feature construction. The quality of explanations directly impacts the effectiveness of search space reduction and ultimately the classification performance.

**Design Tradeoffs**
- Explanation method selection (SHAP vs IME) affects both computational cost and explanation quality
- The granularity of attribute grouping balances between computational efficiency and potential loss of nuanced relationships
- Search space reduction may miss some potentially valuable feature combinations not captured by explanation patterns

**Failure Signatures**
- Poor explanation quality leading to irrelevant attribute grouping
- Over-aggressive search space reduction missing important feature combinations
- Explanation methods producing biased results that propagate to constructed features

- Single-domain application (financial dataset) provides limited evidence for generalizability across diverse domains
- Does not explicitly address potential biases in explanation methods that could affect feature construction
