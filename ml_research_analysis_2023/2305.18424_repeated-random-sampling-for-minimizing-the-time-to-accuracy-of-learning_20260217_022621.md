# Repeated Random Sampling for Minimizing the Time-to-Accuracy of Learning

## Quick Facts
- arXiv ID: 2305.18424
- Source URL: https://arxiv.org/abs/2305.18424
- Reference count: 40
- Primary result: RS2 achieves 66% accuracy on ImageNet with 10% data (11 points higher than next-best) while training 9× faster

## Executive Summary
This paper introduces Repeated Sampling of Random Subsets (RS2), a simple yet powerful approach to accelerate deep learning training by uniformly resampling random data subsets each epoch. Unlike static pruning methods that select important data once, RS2 randomly samples from the full dataset every epoch, minimizing "time-to-accuracy" by combining runtime efficiency with competitive accuracy. The method demonstrates state-of-the-art performance across multiple benchmarks, particularly excelling in high-compression regimes where it outperforms 30+ data pruning and distillation methods.

## Method Summary
RS2 repeatedly samples random subsets of the dataset uniformly at each training epoch, rather than selecting a static subset based on data importance scores. This approach eliminates the computational overhead of periodic importance score recomputation while maintaining convergence properties theoretically equivalent to full-dataset training in terms of mini-batch iterations. The method is evaluated across supervised image classification (CIFAR10, ImageNet, ImageNet30) and self-supervised pretraining (GPT2), showing consistent improvements in both accuracy and training speed, particularly in high-compression scenarios.

## Key Results
- On ImageNet with 10% data usage, RS2 achieves 66% accuracy (11 points higher than next-best method)
- RS2 trains 9× faster than full-dataset training while maintaining competitive accuracy
- The method shows strong robustness to noisy labels and extends effectively to self-supervised pretraining
- RS2 outperforms 30+ state-of-the-art data pruning and distillation methods across multiple benchmarks

## Why This Works (Mechanism)
RS2 leverages the statistical properties of random sampling to maintain effective gradient estimation while dramatically reducing computational cost. By resampling uniformly each epoch, the method ensures all data points contribute to learning over time, avoiding the bias introduced by static subset selection. The random sampling provides sufficient gradient variance to escape local minima while the repeated exposure to different data subsets maintains model generalization.

## Architecture Onboarding

Component Map:
Dataset -> Random Sampler -> Model -> Loss -> Optimizer -> Model Updates

Critical Path:
Random sampling occurs before each epoch, feeding mini-batches to the model through standard training loops. The sampler maintains no state between epochs, ensuring true random selection each time.

Design Tradeoffs:
RS2 trades the potential accuracy gains from intelligent data selection for massive computational savings and theoretical guarantees. While static pruning methods may achieve higher accuracy with the same data volume, RS2's uniform sampling provides better runtime efficiency and avoids the overhead of computing importance scores.

Failure Signatures:
Poor performance may occur when dataset contains highly imbalanced classes or when random sampling fails to cover important data patterns. The method may also underperform on tasks requiring specific data ordering or curriculum learning.

## Limitations
- Scalability to extremely large-scale datasets beyond ImageNet30 remains unverified
- Theoretical convergence guarantees rely on standard deep learning optimization assumptions that may not hold in practice
- Robustness to noisy labels demonstrated only on synthetic CIFAR variants, not real-world noisy label scenarios
