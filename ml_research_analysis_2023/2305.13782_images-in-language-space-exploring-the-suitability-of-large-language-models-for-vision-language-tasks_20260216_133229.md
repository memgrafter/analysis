# Images in Language Space: Exploring the Suitability of Large Language Models for Vision & Language Tasks

## Quick Facts
- arXiv ID: 2305.13782
- Source URL: https://arxiv.org/abs/2305.13782
- Reference count: 21
- LLMs can perform vision-language tasks through image-to-text conversion with adaptive in-context learning

## Executive Summary
This paper investigates whether large language models can handle vision-language tasks by converting images into textual descriptions and prompting LLMs with these descriptions alongside text. The authors evaluate several open-source and open-access LLMs against GPT-3 on five multimodal datasets using image captioning and visual tags as representation methods. Experiments show that adaptive in-context sample selection generally outperforms random selection, and that using image captions from BLIP yields the best average performance. The results demonstrate that LLMs can generalize to vision-language tasks with limited in-context samples, achieving competitive performance compared to fine-tuned vision-language models on tasks like MAMI, HF, and NLVR2.

## Method Summary
The approach converts images to textual descriptions using image captioning models (BLIP, OFA, ViT-GPT2) and visual tags (object detection, scene classification, facial expressions). These text representations are then used in prompts alongside task descriptions and in-context examples to guide LLMs in completing vision-language tasks. The method employs in-context learning with adaptive sample selection based on similarity metrics, comparing performance across multiple LLMs including GPT-3, T0pp, Flan-T5, and others on five benchmark datasets. Evaluation uses standard metrics like Macro-F1 and Accuracy to compare LLM performance against both each other and fine-tuned vision-language models.

## Key Results
- Adaptive in-context sample selection outperforms random selection across all datasets
- BLIP-generated captions achieve the highest average performance among image representation methods
- GPT-3 achieves best overall performance across three datasets, while T0pp and Flan-T5 perform best among open-source models
- LLMs achieve competitive performance compared to fine-tuned VLMs on MAMI (F1: 64.4 vs 83.4), HF (Acc: 57.4 vs 66.1), and NLVR2 (Acc: 31.7 vs 79.5)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Language models can perform vision-language tasks when visual content is encoded as text.
- Mechanism: Images are converted to textual descriptions via image captioning and classification models, making visual information accessible to LLMs through natural language processing pathways.
- Core assumption: The textual representation captures sufficient semantic information from the image for the LLM to reason about it.
- Evidence anchors:
  - [abstract] "make visual information accessible to the language model using separate verbalisation models"
  - [section 2] "Zhou et al. (2022b,a) modelled the context words in prompts for applying pre-trained vision-language tasks for downstream vision tasks"
  - [corpus] Weak: Only indirect analogies about compositionality in VLMs found, no direct evidence about LLM reasoning on text-encoded images.
- Break condition: If the image-to-text representation loses critical visual details needed for task completion, LLM performance will degrade significantly.

### Mechanism 2
- Claim: In-context learning with carefully selected samples improves LLM performance on multimodal tasks.
- Mechanism: Adaptive sample selection based on similarity metrics (cosine similarity of SentenceTransformer embeddings) provides more relevant examples than random sampling, guiding the LLM's reasoning.
- Core assumption: Similarity in embedding space correlates with task-relevant similarity for the vision-language task.
- Evidence anchors:
  - [abstract] "adaptive in-context sample selection generally outperforms random selection"
  - [section 4.4] "We use the Sentence Transformers (Reimers and Gurevych, 2019) to calculate the similarities among samples"
  - [corpus] Missing: No direct corpus evidence about similarity-based sample selection effectiveness.
- Break condition: If the embedding model doesn't capture task-relevant features, adaptive selection may perform worse than random.

### Mechanism 3
- Claim: Different image representation methods (captioning vs visual tags) have varying effectiveness across tasks.
- Mechanism: Image captioning provides richer contextual descriptions while visual tags provide structured object/scene information; task requirements determine which is more effective.
- Core assumption: The information needs of vision-language tasks vary systematically, making some representation methods more suitable than others.
- Evidence anchors:
  - [section 5.2] "using captions generated by BLIP model yields the higher performance on average" but "Visual Tags resulted in the highest performance on three datasets"
  - [section 4.3] "two different methods to extract textual representation of images: image captioning and the combination of multiple image classification model outputs"
  - [corpus] Weak: Only indirect evidence about compositionality in VLMs, no direct evidence about captioning vs tags effectiveness.
- Break condition: If the task requires specific visual details that one representation method captures better than another, performance will vary accordingly.

## Architecture Onboarding

- Component map:
  Image preprocessing → Captioning/Classification models → Text representation → Prompt construction → LLM API → Output parsing
  Datasets (MAMI, HF, MVSA, OK-VQA, NLVR2) → Ground truth comparison → Evaluation metrics

- Critical path:
  Image → Text representation → Prompt → LLM → Answer
  Any failure in this pipeline (poor image representation, prompt formatting issues, LLM API failures) will prevent task completion.

- Design tradeoffs:
  - Richness vs token limits: More detailed image descriptions improve performance but consume prompt tokens
  - Sample selection: Adaptive selection requires additional computation but improves results; random is faster but less effective
  - Representation method: Captioning provides context but may be verbose; visual tags are structured but may miss nuances

- Failure signatures:
  - Poor image representations → LLM generates irrelevant or incorrect answers
  - Incorrect prompt formatting → LLM ignores image context or misunderstands task
  - Insufficient token budget → Truncated prompts or missing in-context examples
  - Model choice mismatch → Some LLMs perform better on certain tasks than others

- First 3 experiments:
  1. Zero-shot baseline: Test LLM performance without any in-context examples to establish baseline reasoning capability
  2. Random vs adaptive selection: Compare performance with same number of samples using both methods to validate selection importance
  3. Captioning method comparison: Test BLIP, ViT-GPT2, and OFA on a single dataset to determine which representation works best for that task

## Limitations

- Performance gaps remain significant on complex reasoning tasks like NLVR2 (31.7% vs 79.5% accuracy compared to fine-tuned VLMs)
- Token budget limitations restrict the richness of image descriptions that can be provided to LLMs
- Results depend heavily on quality of image-to-text conversion, with potential loss of critical visual details

## Confidence

- **High Confidence**: LLMs can perform vision-language tasks when visual content is converted to text, and adaptive in-context sample selection improves performance over random selection.
- **Medium Confidence**: Different image representation methods (captioning vs visual tags) have varying effectiveness across tasks, with BLIP captions performing best on average.
- **Medium Confidence**: Among tested LLMs, GPT-3 achieves best overall performance while T0pp and Flan-T5 lead among open-source models, though comparisons are affected by API access differences and token constraints.

## Next Checks

1. **Task-specific image representation analysis**: Systematically test which types of visual information (objects, relationships, spatial arrangements) are most critical for each task by ablating specific elements from captions and measuring performance impact.

2. **Prompt structure ablation study**: Evaluate the contribution of each prompt component (task description, in-context examples, evaluation format) by removing or modifying them to identify optimal prompt architecture for different task types.

3. **Token budget scaling experiment**: Measure how LLM performance scales with increasing token budgets for image descriptions and in-context examples to quantify the practical limitations of the approach.
