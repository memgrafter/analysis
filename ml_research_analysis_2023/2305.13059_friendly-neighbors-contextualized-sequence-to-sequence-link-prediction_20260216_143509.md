# Friendly Neighbors: Contextualized Sequence-to-Sequence Link Prediction

## Quick Facts
- arXiv ID: 2305.13059
- Source URL: https://arxiv.org/abs/2305.13059
- Reference count: 9
- Primary result: KGT5-context achieves SOTA on Wikidata5M and WikiKG90Mv2 using 60M parameters (vs. 674M ensemble methods)

## Executive Summary
This paper introduces KGT5-context, a sequence-to-sequence approach for link prediction in knowledge graphs that incorporates contextual information from a query entity's one-hop neighborhood. By verbalizing the direct neighborhood and appending it to the input sequence, the model achieves state-of-the-art performance on major benchmarks while using a significantly smaller model (60M parameters versus 674M for ensemble approaches). The method demonstrates that contextual information can substantially improve performance without requiring massive model sizes.

## Method Summary
KGT5-context extends the KGT5 model by verbalizing the one-hop neighborhood of the query entity and appending this contextual information to the input sequence. The approach transforms the link prediction task into a sequence-to-sequence generation problem where the model predicts missing relations or entities given both the query and its immediate neighborhood context. This simple modification allows the model to leverage local graph structure without requiring complex architectural changes or massive parameter counts.

## Key Results
- Achieves state-of-the-art performance on Wikidata5M with a 2 percentage point improvement
- Reaches competitive performance on WikiKG90Mv2 despite being orders of magnitude smaller than leading models
- Uses only 60M parameters compared to 674M for ensemble approaches, demonstrating superior parameter efficiency
- Maintains strong performance across both benchmark datasets while using the same simple contextualization approach

## Why This Works (Mechanism)
The mechanism works by providing the model with direct access to the query entity's immediate neighborhood context, allowing it to reason about local graph structure during the prediction task. By verbalizing one-hop neighbors, the model gains information about entity types, relationships, and patterns that would otherwise require the model to infer from distant connections. This explicit contextualization reduces the burden on the model to learn neighborhood patterns from scratch, enabling better generalization with fewer parameters.

## Architecture Onboarding

**Component Map**: Input Query -> Neighborhood Verbalization -> Sequence Concatenation -> KGT5 Encoder-Decoder -> Prediction Output

**Critical Path**: The verbalized neighborhood is concatenated to the query entity representation, which then flows through the encoder to capture context, followed by decoder attention mechanisms that use this context for prediction.

**Design Tradeoffs**: The approach trades increased input sequence length (and computational cost per prediction) for reduced model size and potentially better generalization. Alternative designs could include learned neighborhood embeddings or graph neural network-based context aggregation.

**Failure Signatures**: Performance degradation may occur when one-hop neighborhoods are insufficient for prediction (requiring multi-hop reasoning), or when verbalized neighborhoods become too large and introduce noise. The model may also struggle with highly dense neighborhoods where context becomes overwhelming.

## Limitations
- Limited experimental validation to only two benchmarks (Wikidata5M and WikiKG90Mv2), constraining generalizability
- Comparison to ensemble methods with 10x more parameters may overstate practical significance despite impressive efficiency gains
- Lack of ablation studies makes it difficult to isolate the contribution of neighborhood verbalization from other factors

## Confidence
- **High Confidence**: Technical implementation of verbalizing one-hop neighborhoods and appending to input sequences is straightforward and verifiable
- **Medium Confidence**: Reported performance improvements are reproducible but may not generalize beyond tested benchmarks
- **Low Confidence**: Claims about being "state-of-the-art" relative to ensemble methods with 10x more parameters may overstate practical significance
