# Spherical Transformer for LiDAR-based 3D Recognition

## Quick Facts
- arXiv ID: 2303.12766
- Source URL: https://arxiv.org/abs/2303.12766
- Reference count: 40
- Ranks 1st on both nuScenes and SemanticKITTI semantic segmentation benchmarks with 81.9% and 74.8% mIoU respectively, and 3rd on the nuScenes object detection benchmark with 72.8% NDS and 68.5% mAP

## Executive Summary
This paper addresses the critical challenges of information disconnection and limited receptive field in LiDAR-based 3D recognition, particularly for sparse distant points. The authors propose SphereFormer, a novel Transformer module that uses radial window self-attention to partition 3D space into non-overlapping narrow and long windows. This approach overcomes disconnection issues and dramatically enlarges the receptive field. The method achieves state-of-the-art results, ranking 1st on both nuScenes and SemanticKITTI semantic segmentation benchmarks and 3rd on the nuScenes object detection benchmark.

## Method Summary
SphereFormer is a plugin module that inserts at the end of each encoder stage in existing sparse convolutional backbones. It consists of three key innovations: radial window self-attention that partitions space into non-overlapping narrow and long windows using spherical coordinates, exponential splitting for fine-grained position encoding that grows intervals with distance, and dynamic feature selection through head splitting between radial and cubic attention. The module is designed specifically for LiDAR point clouds, which have varying sparsity patterns where close points are dense and distant points are sparse. SphereFormer is inserted into SparseConvNet for segmentation and CenterPoint for detection, trained with AdamW optimizer and poly scheduler.

## Key Results
- Achieves 81.9% mIoU on nuScenes semantic segmentation, ranking 1st on the benchmark
- Achieves 74.8% mIoU on SemanticKITTI semantic segmentation, ranking 1st on the benchmark
- Achieves 72.8% NDS and 68.5% mAP on nuScenes object detection, ranking 3rd on the benchmark

## Why This Works (Mechanism)

### Mechanism 1
Radial window self-attention overcomes information disconnection in sparse distant LiDAR points by directly aggregating long-range information. The method partitions 3D space using spherical coordinates (r, θ, ϕ) into non-overlapping narrow and long radial windows, allowing sparse distant points to access information from dense close points within a single attention operation.

### Mechanism 2
Exponential splitting provides fine-grained position encoding for radial windows with large radius ranges. Instead of uniform splitting that creates large intervals for distant points, exponential splitting uses intervals that grow exponentially with distance, ensuring fine-grained relative position encoding for nearby token pairs while maintaining computational efficiency for distant pairs.

### Mechanism 3
Dynamic feature selection allows different points to adaptively choose between local and global information based on their sparsity context. The model splits attention heads between radial window self-attention (for long-range global context) and cubic window self-attention (for local neighbors), with points in dense regions primarily using local information while sparse distant points rely more on global context.

  - Why needed here: The method fundamentally relies on representing LiDAR point clouds in spherical coordinates (r, θ, ϕ) with the sensor as origin to create meaningful radial partitions
  - Quick check question: Why is using spherical coordinates more appropriate than Cartesian coordinates for LiDAR point clouds in this context?

- Concept: Window-based self-attention mechanisms in Transformers
  - Why needed here: The core innovation builds upon window self-attention but modifies the window shape and partitioning strategy specifically for LiDAR data
  - Quick check question: How does window self-attention differ from global self-attention, and what are the trade-offs?

- Concept: Position encoding strategies for attention mechanisms
  - Why needed here: The exponential splitting method is a novel position encoding approach designed specifically for the radial window geometry
  - Quick check question: What are the main challenges in designing position encodings for attention mechanisms with non-uniform spatial distributions?

## Architecture Onboarding

- Component map: Radial window partitioning → Exponential position encoding → Multi-head attention with dynamic head splitting → Feature fusion
- Critical path: Radial window partitioning → Exponential position encoding → Multi-head attention with dynamic head splitting → Feature fusion
- Design tradeoffs: Larger radial windows capture more context but increase computational cost; exponential splitting balances precision and efficiency; head splitting allows adaptive information selection but adds complexity to the attention mechanism
- Failure signatures: Poor performance on sparse distant points suggests issues with radial partitioning or exponential splitting; degradation in dense regions may indicate problems with dynamic feature selection; overall performance drops could stem from window size or head splitting ratio misconfiguration
- First 3 experiments:
  1. Compare baseline sparse convolution with SphereFormer using cubic vs. radial windows on nuScenes validation set, measuring mIoU at different distance ranges
  2. Test uniform vs. exponential splitting with fixed radial window shape to isolate the impact of position encoding granularity
  3. Evaluate dynamic feature selection by comparing models with different head splitting ratios (e.g., 50/50, 70/30, 30/70) on close vs. distant point performance

## Limitations
- Generalizability to different LiDAR sensors with varying scanning patterns and sparsity distributions remains uncertain
- Computational efficiency at scale is unclear, particularly for large scenes with long-range radial windows
- The optimal head splitting ratio and sensitivity to window size parameters require further systematic analysis

## Confidence
- High Confidence: The SphereFormer architecture works as described and achieves the reported benchmark results on nuScenes and SemanticKITTI
- Medium Confidence: The mechanism explanations for why radial windows outperform cubic windows are reasonable but could benefit from additional empirical validation
- Low Confidence: The claim that exponential splitting is the optimal position encoding strategy for radial windows lacks comparison to other potential encoding methods

## Next Checks

- Next Check 3: Conduct a systematic ablation study varying the head splitting ratio between radial and cubic attention across different distance ranges
