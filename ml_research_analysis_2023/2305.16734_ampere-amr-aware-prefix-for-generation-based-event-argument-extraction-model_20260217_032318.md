# AMPERE: AMR-Aware Prefix for Generation-Based Event Argument Extraction Model

## Quick Facts
- arXiv ID: 2305.16734
- Source URL: https://arxiv.org/abs/2305.16734
- Reference count: 30
- 4-10% absolute F1-score improvements over prior methods, especially in low-resource settings

## Executive Summary
This paper addresses the challenge of incorporating structured semantic information into generation-based event argument extraction (EAE) models. The authors propose AMPERE, which encodes abstract meaning representation (AMR) graphs into AMR-aware prefixes for every layer of the generation model. This allows the model to leverage AMR information to improve event argument extraction. AMPERE also includes an adjusted copy mechanism to handle potential noise from the AMR graph. Experiments on ACE2005 and ERE datasets show that AMPERE achieves 4-10% absolute F1-score improvements over prior methods, especially in low-resource settings with reduced training data. The method demonstrates consistent performance across different training sizes and datasets.

## Method Summary
AMPERE encodes AMR graphs into prefixes for every layer of a generation-based EAE model (DEGREE). It uses an AMR encoder (AMRBART or RoBERTa) to generate prefixes from linearized AMR graphs, which are then injected into each layer's attention mechanism. An adjusted copy mechanism with a regularization term encourages copying from the input to mitigate noise introduced by AMR normalization. The model is trained and evaluated on ACE2005 and ERE datasets with varying data proportions.

## Key Results
- AMPERE achieves 4-10% absolute F1-score improvements over prior methods
- Most significant gains observed in low-resource settings (5-20% training data)
- Consistent performance improvements across different training sizes and datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: AMR-aware prefixes enable structured semantic information to guide generation-based EAE models by directly influencing the attention mechanism.
- Mechanism: The linearized AMR graph is encoded into dense vectors, then distributed as learnable prefixes across every layer of the Transformer. These prefixes act as additional key-value matrices in attention blocks, biasing the model's weighting toward AMR-derived semantic relationships.
- Core assumption: The semantic structure captured in AMR graphs aligns closely enough with event argument roles to be useful for guiding generation.
- Evidence anchors:
  - [abstract]: "We propose AMPERE, which generates AMR-aware prefixes for every layer of the generation model."
  - [section]: "These additional key and value matrices will be concatenated with the original key and value matrices in the attention block."
  - [corpus]: Weak - only 25 related papers found, average FMR 0.525, suggesting limited prior work on AMR integration in generation-based models.
- Break condition: If AMR structure is too noisy or misaligned with event roles, prefixes could mislead rather than guide generation.

### Mechanism 2
- Claim: The adjusted copy mechanism stabilizes generation by reducing hallucinations and enforcing token fidelity to input.
- Mechanism: A regularization term is added to the loss to encourage the model to copy tokens from the input passage, mitigating the noise introduced by AMR graph normalization.
- Core assumption: AMR parsers introduce inconsistencies (e.g., "washington" → "Washington") that harm generation quality if not controlled.
- Evidence anchors:
  - [abstract]: "We also introduce an adjusted copy mechanism to AMPERE to help overcome potential noises brought by the AMR graph."
  - [section]: "We apply a copy mechanism... and add an additional regularization loss term to encourage copying from the input passage."
  - [corpus]: Weak - few citations on copy mechanism adaptations for AMR integration in EAE.
- Break condition: If copying is over-penalized, the model loses its generative flexibility and underfits.

### Mechanism 3
- Claim: Using AMRBART as AMR encoder leverages pre-trained AMR-to-text knowledge, improving encoding quality with fewer parameters than full RoBERTa.
- Mechanism: AMRBART is pre-trained on AMR 3.0 data and enlarged vocabulary, allowing it to better interpret AMR structures and transfer knowledge from AMR-to-text tasks.
- Core assumption: Pre-training on AMR-to-text tasks provides useful inductive biases for AMR encoding in the context of EAE.
- Evidence anchors:
  - [section]: "We consider using the encoder part of the current state-of-the-art AMR-to-text model — AMRBART... Employing the model as our AMR encoder enables AMPERE to leverage knowledge from other tasks."
  - [section]: "The AMR encoder component of AMPERE (RoBERTa) has approximately 1.7 times more parameters than that of AMPERE (AMRBART)."
  - [corpus]: Weak - limited work comparing AMRBART vs RoBERTa for AMR encoding in EAE.
- Break condition: If AMR-to-text task differs too much from EAE, AMRBART's advantages may not transfer.

## Foundational Learning

- Concept: AMR graph linearization
  - Why needed here: AMR graphs are structured; they must be linearized into sequences for standard encoder processing.
  - Quick check question: How does depth-first-search linearization preserve AMR graph semantics in a flat sequence?

- Concept: Prefix tuning in Transformers
  - Why needed here: Prefix vectors are injected into each layer's attention mechanism to guide generation without changing the base model architecture.
  - Quick check question: What is the difference between fixed prefixes (Li & Liang 2021) and the dynamic prefixes used in AMPERE?

- Concept: Copy mechanism regularization
  - Why needed here: AMR normalization can introduce mismatched tokens; the adjusted copy mechanism mitigates hallucination risk.
  - Quick check question: How does the loss term λΣw_i^gen bias the model toward copying rather than generation?

## Architecture Onboarding

- Component map:
  - AMR Parser (SPRING) → AMR Encoder (AMRBART or RoBERTa) → Prefix Generator → Base EAE Model (DEGREE) → Adjusted Copy Mechanism → Loss
- Critical path: AMR → Encoding → Prefix Injection → Generation → Copy control
- Design tradeoffs:
  - AMRBART vs RoBERTa: AMRBART uses pre-trained AMR-to-text knowledge but fewer parameters; RoBERTa is more general but requires more parameters.
  - Layer-wise vs single-layer prefixes: Layer-wise offers finer control but increases complexity.
  - Copy strength: Higher λ enforces copying but may reduce generative flexibility.
- Failure signatures:
  - Prefixes not improving: Check if AMR graph linearization is semantically faithful.
  - Over-reliance on copying: Loss term λ too high or input mismatch.
  - Degradation in high-resource settings: AMR noise outweighing benefits.
- First 3 experiments:
  1. Compare AMR-aware prefixes vs AMR concatenation vs no AMR in 5% ACE05-E.
  2. Test adjusted copy mechanism vs no copy vs pure copy under 20% ACE05-E.
  3. Compare AMRBART vs RoBERTa as AMR encoder on 5% ACE05-E.

## Open Questions the Paper Calls Out

The paper doesn't explicitly call out open questions but identifies several limitations in the discussion section.

## Limitations

- Weak prior work context: Only 25 related papers found with minimal citations, suggesting limited comparative baselines for evaluating novelty
- Architecture complexity: Multiple interacting components (AMR parsing, prefix injection, copy mechanism) make debugging and optimization challenging
- Parameter efficiency claims: Claims about AMRBART's efficiency are somewhat superficial without comprehensive ablation studies across resource settings

## Confidence

- Novelty claims: Low confidence due to insufficient contextualization within existing literature
- Method applicability: Medium confidence given architectural complexity and lack of comprehensive failure mode analysis
- Parameter efficiency: Medium confidence pending more rigorous ablation studies

## Next Checks

1. Cross-domain robustness test: Evaluate AMPERE on domain-shifted datasets (e.g., biomedical or scientific texts) to assess generalization beyond newswire text

2. AMR parser sensitivity analysis: Systematically vary AMR parsing quality to quantify impact of AMR graph quality on final EAE performance

3. Prefix injection ablation: Conduct layer-wise ablation study removing prefixes from different Transformer layers to identify which layers benefit most from AMR information
