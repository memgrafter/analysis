# NTKCPL: Active Learning on Top of Self-Supervised Model by Estimating True Coverage

## Quick Facts
- arXiv ID: 2306.04099
- Source URL: https://arxiv.org/abs/2306.04099
- Reference count: 40
- Primary result: NTKCPL achieves higher accuracy than existing active learning strategies when training on top of self-supervised models, especially in low-budget scenarios

## Executive Summary
This paper proposes NTKCPL, a novel active learning strategy designed specifically for training models initialized with self-supervised learning. The method addresses the challenge that when combining active learning with self-supervised models, the phase transition point occurs earlier, making it difficult to determine optimal strategies for unseen datasets. NTKCPL estimates the empirical risk on the entire active learning pool using pseudo-labels and model predictions with Neural Tangent Kernel (NTK) approximation, analyzing factors affecting approximation error and designing a pseudo-label clustering generation method to reduce this error.

## Method Summary
NTKCPL is an active learning algorithm that works on top of frozen self-supervised feature extractors. The method uses NTK to approximate the behavior of a 2-layer MLP classifier, generating pseudo-labels through constrained K-means clustering with a cluster-splitting approach. For each candidate sample, it estimates empirical risk using NTK predictions with CPL, selecting samples with minimum estimated risk. The algorithm is designed to work efficiently in low-budget scenarios where only a small fraction of data needs to be labeled, leveraging the strong initialization provided by self-supervised pre-training.

## Key Results
- NTKCPL outperforms baseline methods (Random, Entropy, Coreset, BADGE, TypiClust, LookAhead) in most cases across five datasets
- The method has a wider effective budget range, working effectively with annotation quantities one order of magnitude larger than traditional low-budget active learning experiments
- Achieves similar results to training with 20-40% labeled data on randomly initialized networks using only 0.4-6% labeled data when using self-supervised initialization

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The phase transition point occurs earlier when combining active learning with self-supervised models
- Mechanism: Self-supervised pre-training provides stronger feature representations that reduce the number of labeled samples needed to achieve good performance, shifting the phase transition point forward
- Core assumption: Self-supervised learning provides a strong initialization that reduces the reliance on labeled data for active learning
- Evidence anchors: [abstract] "the phase transition point occurs earlier. It becomes challenging to determine which strategy should be used for previously unseen datasets"; [section] "When training based on a self-supervised model, often only 0.4-6% of the total data needs to be labeled to achieve similar results to training with 20-40% labeled data on a randomly initialized network"

### Mechanism 2
- Claim: NTKCPL estimates true coverage more accurately than distance-based methods
- Mechanism: Uses Neural Tangent Kernel to approximate model predictions and pseudo-labels to estimate true coverage without requiring true labels
- Core assumption: NTK can approximate the classifier behavior when the encoder is frozen and pseudo-labels provide reasonable cluster assignments
- Evidence anchors: [section] "We propose a look ahead strategy, NTKCPL, to approximate the empirical risk on the whole active learning pool directly"; [section] "Our method approximates the true coverage well for most cases" (fig. 4)

### Mechanism 3
- Claim: The CPL generation method reduces approximation error by balancing purity and over-clustering
- Mechanism: Uses constrained K-means and cluster splitting to generate pseudo-labels that maintain cluster purity while avoiding over-clustering
- Core assumption: The model's predictions can identify confusing samples within clusters, and splitting low-purity clusters improves the approximation
- Evidence anchors: [section] "To improve the over-clustering, we manually set the maximum number of clusters and design a clustering-splitting approach"; [section] "Our method outperforms both low- and high-budget active learning strategies within a range of annotation quantities one order of magnitude larger than traditional low-budget active learning experiments"

## Architecture Onboarding

- Component map: Self-supervised feature extractor (frozen) -> 2-layer MLP classifier (trainable) -> NTK approximation module -> CPL generation module (constrained K-means + splitting) -> Active learning selection loop

- Critical path: 
  1. Compute NTK kernel matrix
  2. Generate CPL on active learning features
  3. For each candidate sample, estimate empirical risk using NTK prediction with CPL
  4. Select sample with minimum estimated risk
  5. Query true label and retrain classifier

- Design tradeoffs:
  - Freezing encoder vs fine-tuning: Freezing is more efficient but may limit performance in high-budget scenarios
  - Cluster number selection: Too few clusters cause over-clustering error, too many cause impurity
  - NTK vs direct model training: NTK is faster but less accurate when features are strong

- Failure signatures:
  - Poor performance on datasets with mixed self-supervised features (like SVHN)
  - Performance drops when maximum cluster number is poorly chosen
  - Ineffectiveness when pseudo-labels have low purity

- First 3 experiments:
  1. Run NTKCPL on CIFAR-10 with 20 labels and compare to random baseline
  2. Test CPL generation with different maximum cluster numbers on CIFAR-10
  3. Compare coverage estimation accuracy on CIFAR-100 with true labels vs CPL

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would NTKCPL perform when combining active learning with fine-tuning the entire self-supervised model instead of just the classifier?
- Basis in paper: [explicit] The paper mentions this as a limitation, stating "Our approach is limited to the fixed training approach, i.e., training the classifier on top of a frozen self-supervised training encoder" and suggests exploring how to accurately approximate the fine-tuning model initialized with self-supervised weights using NTK.
- Why unresolved: The current implementation only trains a classifier on top of a frozen encoder, which restricts its use to low-budget scenarios. The effectiveness of NTKCPL in high-budget scenarios where fine-tuning the entire model is preferred remains untested.
- What evidence would resolve it: Experiments comparing NTKCPL's performance when fine-tuning the entire model versus training only the classifier across various annotation budgets and datasets.

### Open Question 2
- Question: What is the impact of different self-supervised learning algorithms on the effectiveness of NTKCPL?
- Basis in paper: [inferred] The paper uses different self-supervised models (SimSiam for CIFAR datasets, BYOL for ImageNet-100 and Oxford-IIIT Pet) but doesn't systematically compare their impact on NTKCPL's performance. The effectiveness of NTKCPL for other self-supervised methods like MoCo, SwAV, or DINO is not explored.
- Why unresolved: While the paper shows NTKCPL works with multiple self-supervised models, it doesn't isolate the effect of the self-supervised algorithm choice on active learning performance.
- What evidence would resolve it: Comparative experiments using NTKCPL with various self-supervised learning algorithms (SimSiam, BYOL, MoCo, SwAV, DINO) on the same datasets to measure relative performance differences.

### Open Question 3
- Question: How does NTKCPL's performance scale with extremely large datasets where the candidate set cannot be efficiently subsampled?
- Basis in paper: [explicit] The paper mentions "For computational simplicity... we use 10,000 samples" as the candidate set and compares computation time with LookAhead, but doesn't explore scenarios where even this subsampling becomes computationally prohibitive.
- Why unresolved: The current implementation relies on subsampling the unlabeled set for computational efficiency, but the paper doesn't address how NTKCPL would perform when the dataset is so large that even candidate set selection becomes a bottleneck.
- What evidence would resolve it: Experiments demonstrating NTKCPL's effectiveness on extremely large-scale datasets (e.g., JFT-300M, LAION-5B) with strategies for efficient candidate set selection or approximations that reduce computational complexity.

## Limitations
- The method is limited to training classifiers on top of frozen self-supervised encoders, making it ineffective for high-budget scenarios where fine-tuning the entire model is preferred
- Performance advantage is strongest in low-budget scenarios but diminishes as budget increases, suggesting limitations in high-resource settings
- The effectiveness depends heavily on the quality of self-supervised features and optimal cluster number selection, which may not generalize well to all datasets

## Confidence

- **High Confidence:** The overall experimental methodology and baseline comparisons are sound
- **Medium Confidence:** The phase transition point shift claim has theoretical support but limited empirical breadth
- **Low Confidence:** The NTK approximation's effectiveness across diverse self-supervised feature qualities is not thoroughly validated
