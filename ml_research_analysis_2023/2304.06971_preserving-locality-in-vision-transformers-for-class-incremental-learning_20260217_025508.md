# Preserving Locality in Vision Transformers for Class Incremental Learning

## Quick Facts
- arXiv ID: 2304.06971
- Source URL: https://arxiv.org/abs/2304.06971
- Reference count: 37
- Primary result: LPA layer achieves 2% accuracy gains in B10-10 scenarios on CIFAR100

## Executive Summary
This paper identifies "Locality Degradation" in Vision Transformers during Class Incremental Learning, where attention layers progressively lose focus on local features. The authors propose a Locality-Preserved Attention (LPA) layer that incorporates local information directly into attention computation and initializes attention weights with small values to encourage locality focus early in training. Experiments on CIFAR100 and ImageNet100 demonstrate consistent accuracy improvements across multiple CIL scenarios, with LPA-backed models showing better preservation of locality and improved transferability.

## Method Summary
The method introduces a Locality-Preserved Attention (LPA) layer that modifies standard ViT attention by incorporating relative positional encoding with quadratic terms to emphasize local spatial relationships. The LPA layer uses λ parameters initialized with small values to control the influence of global attention gradients, allowing locality-focused features to dominate early learning. This design aims to preserve task-agnostic local features that transfer better to new tasks, addressing catastrophic forgetting in CIL scenarios. The approach is evaluated on CIFAR100 and ImageNet100 with replay buffers of 2000 samples.

## Key Results
- LPA achieves 2% accuracy improvements in B10-10 scenarios on CIFAR100
- The approach consistently outperforms baseline across all tested CIL scenarios (B10-10, B20-5, B5-20)
- Nonlocality measures show slower growth in LPA models, indicating better locality preservation
- Eigenvalue analysis reveals more transferable directions in LPA-learned representations

## Why This Works (Mechanism)

### Mechanism 1
LPA prevents attention layers from losing concentration on local features by incorporating relative positional information with quadratic encoding, emphasizing local spatial relationships. Small λ initialization controls gradients to encourage early focus on locality. This works because local features contain more transferable, task-agnostic information crucial for incremental learning.

### Mechanism 2
Small λ initialization suppresses global attention influence initially, giving more weight to locality-enhanced attention. This encourages learning task-agnostic local features first, which are more transferable across incremental tasks than early-learned global features.

### Mechanism 3
Preserving locality in attention layers maintains task-agnostic representation that transfers better to new tasks. LPA ensures low-level local information is preserved throughout training, preventing over-specialization to current task features and maintaining knowledge of previous tasks.

## Architecture Onboarding

- **Component map**: Image patches → Patch embeddings → LPA layer → Class token processing → MLP layers → Classification output

- **Critical path**: Image patches → Patch embeddings → LPA layer processing (with locality emphasis) → Class token aggregation → Classification prediction

- **Design tradeoffs**: Local vs global attention balance (controlled by λ), computational overhead of positional encoding, risk of underfitting if locality is overemphasized

- **Failure signatures**: High forgetting metrics despite LPA implementation, performance degradation on early tasks, training instability with extreme λ values

- **First 3 experiments**: 1) Test different λ initialization values (0.01, 0.02, 0.05) on CIFAR100 B10-10, 2) Compare nonlocality measures between baseline and LPA across all layers, 3) Evaluate eigenvalue distributions of representation covariance matrices for transferability assessment

## Limitations

- Locality Degradation phenomenon lacks independent verification in prior literature
- Experimental validation limited to CIFAR100 and ImageNet100 datasets
- Paper focuses on accuracy improvements without detailed analysis of internal representation changes
- Computational overhead and efficiency trade-offs not quantified

## Confidence

**High Confidence**: Experimental results showing consistent accuracy improvements across CIL scenarios on CIFAR100
**Medium Confidence**: Claim that preserving locality helps prevent catastrophic forgetting in CIL
**Low Confidence**: Claim that LPA achieves "stable training" in CIL scenarios
