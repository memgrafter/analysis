# Solving differential equations using physics informed deep learning: a hand-on tutorial with benchmark tests

## Quick Facts
- arXiv ID: 2302.12260
- Source URL: https://arxiv.org/abs/2302.12260
- Reference count: 0
- Primary result: PINNs solve ODEs with 20-40 collocation points vs. hundreds required by traditional methods for weakly nonlinear problems

## Executive Summary
This tutorial demonstrates how physics-informed neural networks (PINNs) can solve ordinary differential equations by embedding physical laws directly into the loss function. The method shows particular promise for weakly nonlinear problems, requiring significantly fewer collocation points than traditional numerical methods while enabling instantaneous prediction after training. The study provides practical insights into hyperparameter selection and demonstrates both forward and inverse problem solving capabilities, though challenges remain for strongly nonlinear systems like the Van der Pol oscillator with high damping parameters.

## Method Summary
PINNs solve differential equations by training neural networks to minimize a combined loss function that includes both data fidelity and physics constraints. The network approximates the solution function, and automatic differentiation computes derivatives needed for the differential equation residual. Training minimizes the difference between the neural network's predictions and the physical laws at collocation points distributed across the domain. For inverse problems, the loss function also includes terms that match observed data when initial conditions are unknown.

## Key Results
- PINNs require 20-40 collocation points versus hundreds needed by traditional methods for weakly nonlinear ODEs
- Solution prediction is instantaneous after training, unlike iterative numerical integration
- Van der Pol oscillator with high damping (μ=100) requires training data distributed across entire domain, reducing PINN advantages
- PINNs excel at mesh-free solutions and inverse problems with unknown initial conditions
- Hyperparameter tuning remains challenging with no automated procedures currently available

## Why This Works (Mechanism)
PINNs work by embedding differential equations as soft constraints in the neural network training process. The network learns to satisfy both the governing equations and boundary/initial conditions simultaneously. This approach transforms the problem of solving differential equations into a machine learning optimization task where the network weights are adjusted to minimize the residual of the differential equation across collocation points. The physics constraints act as regularization, guiding the network toward physically meaningful solutions even with limited training data.

## Foundational Learning

1. **Automatic differentiation** - Used to compute derivatives of neural network outputs with respect to inputs, essential for evaluating differential equation residuals during training. Without this, computing high-order derivatives for PDEs would be computationally prohibitive.

2. **Collocation methods** - PINNs evaluate residuals at discrete points rather than integrating over continuous domains. This transforms continuous problems into finite-dimensional optimization problems that neural networks can handle.

3. **Loss function engineering** - The combined loss includes terms for initial/boundary conditions, differential equation residuals, and data fitting (for inverse problems). Proper weighting between these terms is crucial for stable training.

4. **Neural network architecture selection** - Fully connected networks with appropriate activation functions (typically tanh or sine) are used. Network depth and width affect the function approximation capability and training stability.

5. **Hyperparameter sensitivity** - Learning rates, network architecture, and collocation point distribution significantly impact convergence and solution accuracy. PINNs are particularly sensitive to these choices compared to standard ML tasks.

## Architecture Onboarding

**Component map:** Neural network -> Automatic differentiation -> Loss computation -> Optimization -> Solution function

**Critical path:** Network architecture selection → Collocation point placement → Loss function formulation → Training optimization → Solution evaluation

**Design tradeoffs:** 
- Network depth vs. training stability: Deeper networks can capture more complex solutions but are harder to train
- Collocation point density vs. computational cost: More points improve accuracy but increase training time
- Loss function weighting vs. constraint satisfaction: Proper balance needed between physics terms and data terms
- Activation function choice vs. derivative smoothness: Different activations affect the quality of computed derivatives

**Failure signatures:**
- Oscillatory or unstable solutions indicate insufficient collocation points or poor loss function weighting
- Slow convergence or divergence suggests learning rate issues or network architecture mismatch
- Solutions that don't satisfy boundary conditions point to inadequate constraint enforcement in the loss
