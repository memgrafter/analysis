# Knowledge-based Multimodal Music Similarity

## Quick Facts
- **arXiv ID**: 2306.12249
- **Source URL**: https://arxiv.org/abs/2306.12249
- **Reference count**: 40
- **Primary result**: Introduces a knowledge-based multimodal music similarity system combining symbolic and audio content for explainable similarity measures

## Executive Summary
This research addresses limitations in existing music similarity approaches by developing a knowledge-based multimodal system that combines symbolic (melodic and harmonic) and audio content. The system creates a knowledge graph encoding musical relationships and uses symbolic features to inform deep learning models analyzing audio signals. Key contributions include the ChoCo chord corpus with 30M triples, the Harmonic Memory knowledge graph, and pitchclass2vec embeddings. The approach demonstrates improved performance in music structure analysis while providing transparent similarity assessments that can identify local patterns and influences between songs.

## Method Summary
The methodology involves creating a multimodal dataset encoded as an RDF/OWL knowledge graph, developing similarity measures from symbolic data using TPS encoding and DTW, and training deep learning models informed by symbolic content. The system extracts symbolic representations (melodic/harmonic patterns), creates semantic relationships in the knowledge graph, and uses transformers for unsupervised matching between symbolic annotations and audio features. The final similarity computation combines symbolic similarity measures with score-informed audio similarity, enabling both global and local pattern analysis.

## Key Results
- Created ChoCo chord corpus containing 30M triples encoding harmonic relationships
- Developed Harmonic Memory knowledge graph integrating multimodal musical data
- Demonstrated improved performance in music structure analysis and cover song detection
- Enabled transparent similarity assessments identifying local patterns and influences between songs

- Core assumption: Symbolic representations capture musically meaningful structures that are relevant to human perception of similarity

## Architecture Onboarding

- Component map: Data Ingestion -> Knowledge Graph Layer -> Feature Extraction -> Alignment Module -> Similarity Computation -> Knowledge Graph Output
- Critical path: Symbolic feature extraction → Knowledge graph construction → Audio-symbolic alignment → Similarity computation → Evaluation
- Design tradeoffs:
  - Symbolic vs. Audio emphasis: More symbolic focus provides explainability but may miss audio-specific patterns
  - Knowledge graph complexity vs. query efficiency: Richer relationships improve accuracy but increase computational overhead
  - Transformer architecture choice: Balance between model capacity and training data requirements
- Failure signatures:
  - Poor alignment scores between symbolic and audio features
  - Knowledge graph query timeouts or memory issues
  - Similarity measures that don't correlate with human judgments
  - Overfitting when training on limited multimodal data
- First 3 experiments:
  1. Verify symbolic similarity measures: Test LHARP and DTW-based harmonic similarity on known pattern datasets and compare results to ground truth
  2. Validate knowledge graph construction: Query the ChoCo KG for basic harmonic relationships and verify alignment quality with MusicBrainz metadata
  3. Test transformer alignment: Train a simple transformer on aligned symbolic-audio pairs and measure unsupervised mapping quality before fine-tuning

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What specific methods can be developed to create high-quality multimodal datasets that effectively link symbolic annotations (both melodic and harmonic) with audio data?
- Basis in paper: [explicit] RQ1 - "What is an effective method to create high-quality datasets that incorporate multimodal data that links symbolic annotations (both melodic and harmonic) and audio?"
- Why unresolved: The paper outlines the need for such datasets but does not provide detailed methodologies for creating them, particularly focusing on the integration of different data types into a cohesive knowledge graph.
- What evidence would resolve it: A detailed workflow or framework for dataset creation that demonstrates successful integration of symbolic and audio data, validated through experiments showing improved music similarity analysis.

### Open Question 2
- Question: How can similarity measures be objectively quantified and measured from a knowledge graph of musical data?
- Basis in paper: [explicit] RQ2 - "How can similarity measures be derived from this knowledge graph in order for it to be objectively measured and quantified?"
- Why unresolved: While the paper discusses the importance of deriving similarity measures, it does not specify how these measures can be standardized or validated across different musical contexts.
- What evidence would resolve it: A set of standardized similarity metrics with empirical validation showing consistent and reliable results across diverse musical datasets.

### Open Question 3
- Question: What are the benefits and limitations of using score-informed audio analysis for identifying similarities and patterns in audio data?
- Basis in paper: [explicit] RQ3 - "How can score-informed audio analysis be used to identify similarities and patterns in audio data, and what are the benefits of this approach for the study of music similarity?"
- Why unresolved: The paper suggests potential benefits but lacks a comprehensive analysis of the limitations and practical challenges of implementing score-informed audio analysis in real-world scenarios.
- What evidence would resolve it: Comparative studies demonstrating the effectiveness of score-informed audio analysis against traditional methods, highlighting both advantages and potential drawbacks in various musical genres.

## Limitations

- Current absence of comprehensive evaluation on diverse music genres beyond testing datasets
- Potential scalability challenges with larger knowledge graphs affecting query performance
- Assumption that symbolic representations universally capture perceptually relevant musical features

## Confidence

- High confidence in knowledge graph-based multimodal data integration
- Medium confidence in transformer-based audio-symbolic alignment without supervision
- Low confidence in generalizability across all music genres and cultural contexts

## Next Checks

1. **Cross-genre performance validation**: Test the similarity system on music genres not represented in the training data (e.g., classical, electronic, world music) to assess generalizability.

3. **Knowledge graph scalability test**: Evaluate query performance and memory usage as the knowledge graph expands beyond the current 30M triples to assess practical deployment constraints.
