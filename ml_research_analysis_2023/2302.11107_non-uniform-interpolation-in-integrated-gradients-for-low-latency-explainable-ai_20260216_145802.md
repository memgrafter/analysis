# Non-Uniform Interpolation in Integrated Gradients for Low-Latency Explainable-AI

## Quick Facts
- arXiv ID: 2302.11107
- Source URL: https://arxiv.org/abs/2302.11107
- Reference count: 24
- Achieves 2.6-3.6× speedup on GPU systems for Integrated Gradients with minimal accuracy loss

## Executive Summary
This paper introduces a non-uniform interpolation scheme for Integrated Gradients (IG) that significantly reduces computational overhead while maintaining attribution quality. The key insight is that IG paths contain regions of varying information density, which can be exploited by allocating more interpolation steps where classification probability changes are greater. By dividing the baseline-to-input path into intervals and performing uniform IG within each, the method achieves substantial speedup (2.6-3.6×) on GPU systems with only 0.2-3.2% additional latency overhead compared to standard uniform IG.

## Method Summary
The proposed method improves IG efficiency by analyzing classification probability changes along the interpolation path and using these changes to determine optimal step allocation. The path from baseline to input is divided into intervals, with the number of steps per interval proportional to the square root of the probability change. Within each interval, standard uniform IG is applied. This approach concentrates computational effort where information gain is highest, reducing total steps needed for comparable attribution quality. The method is evaluated on ImageNet using InceptionV3, demonstrating significant speed improvements while maintaining convergence accuracy.

## Key Results
- Achieves 2.6-3.6× speedup on GPU systems compared to uniform IG
- Maintains similar convergence accuracy with only 0.2-3.2% latency overhead
- Demonstrates effectiveness on ImageNet with InceptionV3 architecture
- Provides practical improvements for real-time explainable AI applications

## Why This Works (Mechanism)
The method works by recognizing that not all regions along the IG path contribute equally to feature attribution. Areas with larger classification probability changes contain more information about feature importance and therefore warrant finer-grained sampling. By allocating steps non-uniformly based on this information density, the method captures essential gradient information with fewer total steps, reducing computational cost while preserving attribution quality.

## Limitations
- Relies on classification probability changes as proxy for information content, which may not hold for all architectures
- Requires careful tuning of interval boundaries and step allocation parameters
- Effectiveness depends on correlation between probability changes and feature importance gradients
