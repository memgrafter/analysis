# Unsupervised Open-domain Keyphrase Generation

## Quick Facts
- arXiv ID: 2306.10755
- Source URL: https://arxiv.org/abs/2306.10755
- Reference count: 40
- State-of-the-art unsupervised results on 8 benchmark datasets with only 16% gap to supervised methods

## Executive Summary
This paper introduces unsupervised open-domain keyphrase generation, addressing the challenge of building effective keyphrase generation models without labeled training data that can perform across multiple domains. The authors propose a two-module approach combining phrase generation with informativeness guidance, achieving state-of-the-art results compared to existing unsupervised methods while significantly narrowing the performance gap with supervised approaches.

## Method Summary
The authors propose a seq2seq model with two distinct modules: a phraseness module that generates candidate phrases using a retrieval-augmented seq2seq approach, and an informativeness module that guides generation toward phrases representing core text concepts through sentence embeddings. The phraseness module retrieves relevant phrases from a pre-built phrase repository and incorporates them into the generation process, while the informativeness module uses semantic similarity between generated phrases and input text embeddings to ensure relevance and coverage of key concepts.

## Key Results
- Achieves state-of-the-art performance on 8 benchmark datasets for unsupervised keyphrase generation
- Reduces the performance gap between supervised and unsupervised methods to approximately 16%
- Demonstrates consistent performance across different domains, outperforming baselines on out-of-domain datasets
- Shows robust performance without requiring labeled training data

## Why This Works (Mechanism)
The method works by combining two complementary signals: surface-level phrase patterns through retrieval augmentation and semantic relevance through embedding-based informativeness scoring. The retrieval component provides high-quality phrase candidates learned from existing text corpora, while the embedding-based module ensures generated phrases capture the semantic essence of the input text rather than just surface patterns.

## Architecture Onboarding
**Component Map**: Input Text -> Phraseness Module (Retrieval-Augmented Seq2seq) -> Candidate Phrases -> Informativeness Module (Embedding Similarity) -> Final Keyphrases

**Critical Path**: The retrieval process in the phraseness module is critical, as it provides the phrase candidates that form the basis for generation. Poor retrieval quality directly impacts final output quality.

**Design Tradeoffs**: The approach trades computational complexity (due to retrieval operations) for improved phrase quality and domain adaptability. The embedding-based informativeness scoring adds computational overhead but provides semantic guidance.

**Failure Signatures**: Poor retrieval performance leads to irrelevant or low-quality candidate phrases. Weak sentence embeddings result in semantically disconnected keyphrases. Both modules failing simultaneously produces completely off-topic outputs.

## Limitations
- May struggle with highly specialized domains where keyphrase patterns differ significantly from general text
- Performance heavily dependent on quality and coverage of the underlying phrase repository
- Scalability to very long documents or extremely large input texts not thoroughly evaluated
- Sentence embeddings may miss nuanced semantic relationships crucial for keyphrase generation
