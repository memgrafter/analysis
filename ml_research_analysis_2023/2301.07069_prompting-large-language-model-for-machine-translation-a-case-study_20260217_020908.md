# Prompting Large Language Model for Machine Translation: A Case Study

## Quick Facts
- arXiv ID: 2301.07069
- Source URL: https://arxiv.org/abs/2301.07069
- Reference count: 40
- This paper studies how to use large language models (LLMs) for machine translation (MT) by prompting, finding that prompt template and demonstration selection both have substantial impact on translation quality.

## Executive Summary
This paper investigates the effectiveness of prompting large language models for machine translation tasks. Through systematic experiments with GLM-130B, the authors demonstrate that prompt template language, demonstration example selection, and the construction of pseudo-parallel examples from monolingual data all significantly impact translation quality. The study reveals that while certain features of prompt examples correlate with performance, these correlations are not strong enough to guarantee optimal translation. The research also explores cross-lingual and cross-domain transfer learning for prompting, showing that knowledge transfer from other language pairs and domains can improve translation quality.

## Method Summary
The study employs GLM-130B (130B parameters, INT4 quantized) to investigate prompting for machine translation across multiple language pairs and domains. The methodology includes systematic ablation studies of six different prompt templates, evaluation of seven demonstration selection strategies based on features like semantic similarity and LMScore, and exploration of pseudo-parallel example construction via zero-shot prompting. The research examines cross-lingual transfer (using examples from other language pairs) and cross-domain transfer (using examples from different domains like news, medical, and legal). Experiments are conducted on multiple datasets including FLORES, WMT21, Multi-Domain, and PDC, with evaluation using both BLEU and COMET metrics.

## Key Results
- English template language performs best across most translation directions, even when translating between non-English languages
- Pseudo-parallel examples constructed via back-translation outperform forward-translation and direct monolingual examples
- Feature-based demonstration selection (LMScore, semantic similarity, length) improves over random selection but correlations remain weak
- Cross-lingual and cross-domain transfer learning can improve prompting performance when examples are properly selected
- GLM-130B shows preference for English template language despite being pretrained on equal amounts of Chinese and English tokens

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Template language affects prompting performance
- Mechanism: GLM-130B shows preference for English template language, even when pretraining includes Chinese
- Core assumption: The model's cross-lingual understanding is asymmetric and favors English
- Evidence anchors:
  - [abstract] "Using monolingual examples for prompting hurts translation. By contrast, constructing pseudo parallel examples via back-/forward-translation is a good option."
  - [section] "The preference of GLM-130B to English template also shows that the level of language understanding and cross-lingual ability in GLM-130B varies across languages, even though it's pretrained on the same amount of monolingual Chinese and English tokens."
  - [corpus] Weak - no corpus papers specifically address template language asymmetry
- Break condition: When using a non-English template language for non-English translation directions, performance drops significantly

### Mechanism 2
- Claim: Demonstration quality and relevance are weakly correlated with prompting performance
- Mechanism: Several features (LMScore, semantic similarity, length) show significant but weak Spearman correlation with prompting success
- Core assumption: Feature-based selection can improve prompting but cannot guarantee optimal results
- Evidence anchors:
  - [abstract] "several features of prompt examples, such as semantic similarity, show significant Spearman correlation with their prompting performance; yet, none of the correlations are strong enough"
  - [section] "Several features correlate with prompting performance significantly yet weakly"
  - [corpus] Weak - corpus papers don't extensively discuss correlation strength between prompt features and performance
- Break condition: When feature-based selection fails to outperform random selection consistently across different language pairs

### Mechanism 3
- Claim: Monolingual data can be leveraged through pseudo-parallel construction
- Mechanism: Using GLM-130B to translate monolingual examples into pseudo-parallel pairs improves prompting compared to direct monolingual use
- Core assumption: Back-translation produces more robust pseudo-parallel examples than forward-translation
- Evidence anchors:
  - [abstract] "using pseudo parallel prompt examples constructed from monolingual data via zero-shot prompting could improve translation"
  - [section] "Inspired by data augmentation in MT, we next resort to constructing pseudo parallel data... back-translation (i.e. translating target monolingual examples) performs better and behaves more robustly than forward-translation"
  - [corpus] Weak - corpus papers don't extensively discuss pseudo-parallel construction for prompting
- Break condition: When the zero-shot translation quality is too low to produce useful pseudo-parallel examples

## Architecture Onboarding

- Component map:
  GLM-130B model (130B parameters, INT4 quantized) -> Prompt template generator (6 templates) -> Demonstration example selector (7 features) -> Pseudo-parallel constructor (back/forward translation) -> Evaluation metrics (BLEU, COMET)

- Critical path: Template selection → Demonstration selection → Prompt construction → GLM-130B inference → Evaluation

- Design tradeoffs:
  - Memory vs performance: More prompt examples improve quality but require more GPU memory
  - Feature complexity vs effectiveness: Complex features like semantic similarity don't outperform simple length-based selection
  - Translation direction vs template language: English templates work best overall but Chinese templates help when translating into Chinese

- Failure signatures:
  - Empty or off-target outputs (particularly when translating into Chinese)
  - Code-switched output mixing languages inappropriately
  - Prompt trap where model copies template phrases instead of translating them

- First 3 experiments:
  1. Test all 6 templates with zero-shot prompting on Wiki Ablation set to identify best template
  2. Evaluate feature-based demonstration selection (LMScore, semantic similarity, length) vs random selection on Full sets
  3. Compare back-translation vs forward-translation for constructing pseudo-parallel examples from monolingual data

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the optimal prompt template for translation vary across different language families (e.g., Indo-European vs. Sino-Tibetan)?
- Basis in paper: [inferred] The paper found that language-specific templates (German vs. Chinese) yielded mixed results, with English templates generally performing best. However, the study only examined three languages from two families.
- Why unresolved: The paper's scope was limited to English, German, and Chinese. Testing templates across a broader range of language families could reveal more generalizable patterns.
- What evidence would resolve it: Systematic experiments with prompt templates on translation tasks involving diverse language families, comparing performance across template languages.

### Open Question 2
- Question: How do the correlations between prompt example features and translation performance change with larger language models (e.g., PaLM, GPT-4)?
- Basis in paper: [explicit] The paper identified several features (semantic similarity, sequence length, LM score) that correlated with performance for GLM-130B, but noted these correlations were not strong enough to guarantee optimal translation.
- Why unresolved: The study only used GLM-130B. Larger models might exhibit stronger or different correlations due to their enhanced cross-lingual capabilities.
- What evidence would resolve it: Repeating the feature correlation analysis with prompting experiments on larger LLMs and comparing the strength and significance of correlations.

### Open Question 3
- Question: What is the optimal strategy for combining feature-based and input-relevant prompt example selection?
- Basis in paper: [explicit] The paper found that feature-based selection (e.g., semantic similarity) improved performance over random selection but was not consistently optimal. Input-relevant examples based on n-gram overlap were mentioned as a competing strategy.
- Why unresolved: The paper did not explore hybrid strategies that combine feature-based ranking with input similarity matching. The relative importance of each factor remains unclear.
- What evidence would resolve it: Controlled experiments testing hybrid selection strategies (e.g., re-ranking feature-selected examples by input similarity) and comparing their performance against pure feature-based or input-based approaches.

## Limitations

- The study only examines three languages (English, German, Chinese) and four domains, limiting generalizability to other language pairs and domains
- The correlation analysis between prompt features and performance, while statistically significant, shows weak correlations that may not be practically useful for selection
- The paper does not explore hybrid selection strategies combining multiple features or input similarity matching

## Confidence

- High Confidence: English template language performs best across most translation directions
- Medium Confidence: Pseudo-parallel examples via back-translation outperform forward-translation; cross-lingual transfer can improve performance
- Low Confidence: Specific ranking of feature importance; claims about correlation strength

## Next Checks

1. **Feature correlation robustness test**: Replicate the feature-performance correlation analysis across all language pairs using bootstrapped confidence intervals to determine whether the weak correlations are statistically distinguishable from random.

2. **Template language generalization**: Test the English template preference hypothesis with additional non-English languages (e.g., French, Japanese) to determine whether the asymmetry is specific to Chinese-English or a general phenomenon.

3. **Pseudo-parallel quality assessment**: Conduct human evaluation of the pseudo-parallel examples generated via back-translation versus forward-translation to determine whether the observed BLEU improvements reflect better example quality or artifacts of the evaluation metric.
