# From Temporal to Contemporaneous Iterative Causal Discovery in the Presence of Latent Confounders

## Executive Summary
This paper introduces TS-ICD, a novel algorithm for causal discovery from time-series data with latent confounders. TS-ICD builds on the RAI learning paradigm and ICD algorithm, leveraging the stationarity and homology properties of SVAR processes to reduce the number of conditional independence tests. By identifying autonomous subgraphs and refining temporal relations before contemporaneous ones, TS-ICD achieves superior performance compared to state-of-the-art algorithms. On synthetic data, TS-ICD requires fewer CI tests and demonstrates higher causal accuracy, particularly in mitigating the curse of dimensionality. Real-world application to river discharge data reveals more plausible causal graphs, identifying expected relations while omitting implausible ones.

## Method Summary
TS-ICD is an iterative causal discovery algorithm that refines a fully connected dynamic PAG by testing conditional independence between nodes. It prioritizes refining temporal relations with larger lags before those with smaller lags, exploiting the stationarity and homology properties of SVAR processes to reduce conditioning set sizes. The algorithm identifies autonomous subgraphs by separating exogenous and endogenous nodes, focusing CI tests within these subgraphs. Unlike FCI-based approaches requiring multiple passes, TS-ICD uses a single iterative loop with ordered CI tests, achieving efficiency gains while maintaining completeness under the SVAR assumption.

## Key Results
- TS-ICD requires fewer CI tests than state-of-the-art algorithms while maintaining higher causal accuracy
- The algorithm demonstrates superior performance in mitigating the curse of dimensionality for large graphs
- Real-world application to river discharge data produces more plausible causal graphs compared to competing methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Learning long-range temporal relations before short-range ones reduces conditioning set sizes in subsequent CI tests
- Mechanism: The algorithm prioritizes refining edges connecting nodes with larger temporal distances first. This exploits the stationarity and homology properties of SVAR processes, where longer-range temporal relations are identified before shorter-range ones. By refining these longer-range relations first, the algorithm can reduce the number of nodes that need to be considered in conditioning sets for subsequent, shorter-range temporal relations.
- Core assumption: The data-generating process follows a stationary SVAR model with finite order τ
- Evidence anchors:
  - [abstract]: "TS-ICD achieves superior performance compared to state-of-the-art algorithms. On synthetic data, TS-ICD requires fewer CI tests and demonstrates higher causal accuracy, particularly in mitigating the curse of dimensionality."
  - [section]: "Thus, from the RAI learning paradigm, initially refining edges between τ apart nodes may reduce the number of CI tests required for refining edges between nodes that are less than τ apart"
- Break condition: If the stationarity assumption is violated, or if the temporal ordering of causal effects is not preserved across lags

### Mechanism 2
- Claim: Autonomy identification enables efficient learning by reducing the search space for conditioning sets
- Mechanism: The algorithm identifies autonomous subgraphs by splitting nodes into exogenous and endogenous sets. This allows the algorithm to focus on learning contemporaneous relations within autonomous subgraphs while treating exogenous nodes as a conditioning set. This reduces the number of possible conditioning sets needed for each CI test, as the algorithm only needs to consider nodes within the autonomous subgraph plus the exogenous set.
- Core assumption: The causal structure can be decomposed into autonomous subgraphs that are conditionally independent given the exogenous nodes
- Evidence anchors:
  - [abstract]: "By identifying autonomous subgraphs and refining temporal relations before contemporaneous ones, TS-ICD achieves superior performance compared to state-of-the-art algorithms"
  - [section]: "In a dynamic PAG, a sub-graph containing contemporaneous relations among endogenous nodes is an autonomous sub-graph given exogenous nodes"
- Break condition: If the causal structure cannot be decomposed into autonomous subgraphs, or if the exogenous nodes are not sufficient to render the subgraphs conditionally independent

### Mechanism 3
- Claim: Single iterative learning loop with ordered CI tests is more efficient than multiple passes
- Mechanism: Unlike FCI-based algorithms that require multiple iterative passes to handle latent confounders, TS-ICD uses a single iterative loop with a specific ordering of CI tests. This ordering (temporal relations by lag length, then contemporaneous relations) ensures that all necessary CI tests are performed in a single pass, reducing computational overhead while maintaining completeness.
- Core assumption: The ordered CI testing strategy captures all necessary independence relations to identify the correct equivalence class
- Evidence anchors:
  - [abstract]: "TS-ICD builds on the RAI learning paradigm and ICD algorithm, leveraging the stationarity and homology properties of SVAR processes to reduce the number of conditional independence tests"
  - [section]: "TS-ICD uses autonomy identification to reduce the (τ + 1)n term in the binomial coefficient that measures the number of possible conditioning sets"
- Break condition: If the ordering of CI tests fails to capture certain independence relations that would be discovered in separate passes

## Architecture Onboarding

- Component map:
  - Main algorithm loop (TS-ICD) that iterates over conditioning set sizes
  - Temporal relation refinement module (RefineHomology for temporal edges)
  - Contemporaneous relation refinement module (RefineHomology for contemporaneous edges)
  - PDSepRange function for generating ICD-Sep compliant conditioning sets
  - Independence oracle for performing CI tests
  - Edge orientation rules for finalizing the PAG structure

- Critical path:
  1. Initialize fully connected dynamic PAG
  2. For each conditioning set size r from 0 to |O|-2:
     - Sort temporal edges by lag length (descending)
     - Refine temporal edges using PDSepRange and independence oracle
     - Refine contemporaneous edges using PDSepRange and independence oracle
     - Orient remaining edges using deterministic rules

- Design tradeoffs:
  - Single iterative loop vs. multiple passes (efficiency vs. potential completeness)
  - Fixed ordering of temporal relations vs. adaptive ordering (determinism vs. potential optimality)
  - Explicit autonomy identification vs. implicit handling (clarity vs. potential overhead)

- Failure signatures:
  - Poor performance on non-stationary data
  - Inefficiency when causal structure lacks clear autonomy
  - Sensitivity to the choice of independence test
  - Potential incompleteness if ordering misses certain CI relations

- First 3 experiments:
  1. Compare TS-ICD with a naive ICD application to synthetic SVAR data with known ground truth
  2. Test sensitivity to stationarity assumption by introducing time-varying coefficients
  3. Evaluate performance on data with varying levels of autonomy to test the robustness of the autonomy identification approach

## Limitations
- The algorithm assumes stationary SVAR processes, limiting applicability to non-stationary time-series data common in many domains
- Performance heavily depends on correct independence test implementation and threshold selection
- The single iterative loop design, while efficient, may sacrifice completeness compared to multi-pass approaches in certain scenarios

## Confidence
- **Confidence: Medium** on performance gains against state-of-the-art algorithms, as empirical validation is limited to specific synthetic scenarios and one real-world dataset. The paper claims superior performance but lacks comprehensive benchmarking across diverse data distributions.
- **Confidence: Low** on the generalizability of the autonomy identification mechanism beyond the assumed SVAR structure. The algorithm's effectiveness depends heavily on the stationarity and homology properties, which may not hold in real-world applications with complex dynamics.

## Next Checks
1. Test TS-ICD on non-stationary synthetic data with time-varying coefficients to evaluate robustness beyond the stationarity assumption
2. Benchmark against additional state-of-the-art algorithms (including those using interventional data) on multiple real-world time-series datasets with known causal structures
3. Conduct sensitivity analysis on the autonomy identification component by varying the exogenous node proportion and observing impact on causal accuracy and efficiency metrics
