# Weakly-Supervised Scientific Document Classification via Retrieval-Augmented Multi-Stage Training

## Quick Facts
- arXiv ID: 2306.07193
- Source URL: https://arxiv.org/abs/2306.07193
- Reference count: 40
- Primary result: WANDER outperforms weakly-supervised methods by 11.9% average Macro-F1 on scientific datasets

## Executive Summary
This paper tackles the challenge of weakly-supervised scientific document classification, where only label names are available as supervision without any labeled examples. The key innovation is WANDER, a multi-stage training framework that uses dense retrieval to perform semantic matching between label names and documents in the embedding space. The method addresses the fundamental problem that scientific label names often contain domain-specific concepts that do not appear in the document corpus, making traditional hard matching ineffective.

The approach significantly outperforms existing weakly-supervised methods by an average of 11.9% in Macro-F1 across three scientific datasets (MeSH, arXiv-Math, arXiv-CS). The multi-stage architecture combines dense retrieval pretraining, iterative label expansion using both local TF-IDF and global semantic similarity, and self-training refinement to achieve state-of-the-art results in this challenging setting.

## Method Summary
WANDER is a multi-stage training framework designed for weakly-supervised scientific document classification. The method consists of three main stages: (1) pretraining a dense retrieval model using contrastive learning on the corpus with SciBERT backbone, (2) retrieving documents relevant to each label name using the DR model, (3) expanding label names iteratively using both local TF-IDF-based keyword extraction and global semantic similarity from a pretrained language model, and (4) applying self-training to refine the classifier using high-confidence pseudo labels. The approach addresses the semantic gap between label names and documents by retrieving relevant documents and expanding label names with semantically similar terms, enabling effective classification without labeled data.

## Key Results
- WANDER achieves 11.9% average improvement in Macro-F1 over existing weakly-supervised methods
- Significant performance gains across all three datasets: MeSH (biomedical), arXiv-Math, and arXiv-CS
- Self-training refinement stage provides additional 2-3% improvement in classification accuracy
- Dense retrieval outperforms hard matching baselines, particularly for label names containing domain-specific concepts

## Why This Works (Mechanism)
The method works by addressing the fundamental challenge of semantic mismatch between label names and document content. Dense retrieval enables semantic matching in the embedding space, retrieving documents that are conceptually related to label names even when exact terms don't appear in the corpus. The iterative label expansion process enriches label names with relevant keywords extracted from retrieved documents using both local TF-IDF statistics and global semantic similarity, bridging the vocabulary gap. Self-training then refines the classifier by leveraging high-confidence predictions on unlabeled data, creating a feedback loop that improves classification boundaries over time.

## Architecture Onboarding

**Component Map**
Dense Retrieval Model -> Label Document Retrieval -> Label Name Expansion (TF-IDF + Global Similarity) -> Classifier Training -> Self-Training Refinement -> Final Classifier

**Critical Path**
Pretraining DR (Stage 0) -> Stage-I Retrieval -> Stage-II Iterative Expansion -> Stage-III Self-Training -> Evaluation

**Design Tradeoffs**
- DR vs hard matching: DR handles semantic gaps but requires pretraining; hard matching is simpler but fails on out-of-vocabulary concepts
- Local vs global expansion: TF-IDF captures document-specific importance while global similarity provides broader semantic context
- Self-training threshold: Higher confidence thresholds reduce noise but limit refinement; lower thresholds increase coverage but introduce more errors

**Failure Signatures**
- Poor retrieval quality indicates insufficient DR pretraining or semantic mismatch between label names and documents
- Label expansion introduces noise when keywords are semantically related but not topically relevant
- Self-training amplifies errors if confidence threshold is too low or initial classifier is weak
