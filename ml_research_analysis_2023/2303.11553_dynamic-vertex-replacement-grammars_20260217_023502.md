# Dynamic Vertex Replacement Grammars

## Quick Facts
- **arXiv ID**: 2303.11553
- **Source URL**: https://arxiv.org/abs/2303.11553
- **Reference count**: 40
- **Primary result**: Introduces DyVeRG framework for interpretable modeling of temporal graph dynamics using evolving graph grammars

## Executive Summary
This paper introduces dynamic vertex replacement grammars (DyVeRG), a new framework for modeling time-varying relational data using graph grammars. Unlike traditional graph grammars that operate on static structures, DyVeRG learns rule transitions that capture temporal changes in dynamic graphs. The method extracts grammars from graph snapshots, then tracks how rules evolve between time steps using hierarchical clusterings. This enables interpretable analysis of graph dynamics and forecasting. DyVeRG was evaluated on four real-world dynamic graph datasets against five baseline models, outperforming baselines on EU Emails and Facebook datasets for distinguishing genuine temporal dynamics from imposters.

## Method Summary
DyVeRG extends static vertex replacement grammars to the temporal domain by tracking how hierarchical clusterings evolve across time. The framework extracts a grammar from each graph snapshot using hierarchical clustering (Leiden), then updates the grammar by mapping nodes between consecutive filtrations. This creates rule transitions that capture structural changes like edge additions/deletions and node dynamics. The dyvergence score quantifies how much a grammar must be modified to accommodate temporal changes, enabling forecasting and imposter detection. By tracking how specific production rules evolve, the framework reveals interpretable patterns in network dynamics that are not available from black-box temporal graph models.

## Key Results
- Outperformed baselines on EU Emails and Facebook datasets for distinguishing genuine temporal dynamics from imposters
- Performed competitively on graph generation tasks using portrait divergence and maximum mean discrepancy metrics
- Qualitative case study demonstrated how rule transitions provide insights into network dynamics, such as revealing patterns in email communication

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Dynamic vertex replacement grammars extend static VRGs by tracking how hierarchical clusterings evolve across time, enabling interpretable modeling of temporal graph changes.
- Mechanism: The framework extracts a grammar from each graph snapshot using hierarchical clustering (Leiden), then updates the grammar by mapping nodes between consecutive filtrations. This creates rule transitions that capture structural changes like edge additions/deletions and node dynamics.
- Core assumption: Hierarchical clusterings from consecutive time steps have stable mappings that can be tracked to identify temporal changes.
- Evidence anchors:
  - [abstract] "Dynamic vertex-replacement grammars (DyVeRG), which generalize vertex replacement grammars in the time domain by providing a formal framework for updating a learned graph grammar in accordance with modifications to its underlying data."
  - [section] "The DyV eRG model finds stable mappings between filtrations of the nodes in the dynamic graph across time."

### Mechanism 2
- Claim: The dyvergence score quantifies how much a grammar must be modified to accommodate temporal changes, enabling forecasting and imposter detection.
- Mechanism: After updating a grammar from time t to t+1, the framework computes the graph edit distance between rules and their updated versions. Aggregating these edit distances provides a scalar measure of temporal deviation that can distinguish genuine dynamics from synthetic imposters.
- Core assumption: The aggregate edit distance between consecutive grammars correlates with meaningful temporal changes in the underlying data.
- Evidence anchors:
  - [section] "We can use this mapping to quantify the difference between the two grammars in terms of the number of changes introduced by the temporal update process."
  - [section] "we compute ∆ = − ln 1/(1 + ∑ GED(...))" showing the explicit formula for measuring deviation.

### Mechanism 3
- Claim: The interpretable rule transitions provide insights into network dynamics that are not available from black-box temporal graph models.
- Mechanism: By tracking how specific production rules evolve (e.g., a rule representing a user's email behavior changing structure), the framework reveals patterns like triadic closure, node addition/removal, and community dynamics in human-interpretable terms.
- Core assumption: The extracted rules capture meaningful substructures whose evolution reflects actual network processes.
- Evidence anchors:
  - [section] "we illustrate some specific examples of frequent rule transitions—analogous to subgraph-to-subgraph transitions—learned by the model."
  - [section] "In either case, because there was no rule at time t that ¨P1 and ¨P2 are updated versions of, we can be certain they were additions that participated in a larger connected component that was introduced wholly at time t + 1."

## Architecture Onboarding

- Component map: Graph snapshot → Hierarchical clustering → Rule extraction → Grammar construction → Temporal update → Dyvergence calculation → Graph generation
- Critical path: The temporal update mechanism is the core innovation; it must reliably map and update rules between consecutive time steps
- Design tradeoffs: The framework balances interpretability (small rule sizes via µ parameter) against capturing complex temporal dynamics
- Failure signatures: Poor performance on datasets with highly volatile temporal changes, memory issues with large graphs, failure to distinguish imposters when temporal patterns are subtle

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the rule isomorphism criteria be relaxed to enable more general temporal trend discovery while maintaining interpretability?
- Basis in paper: [explicit] The paper mentions that "if a more relaxed view of rule isomorphism is adopted, and the definition of rule transition is broadened, then our model could describe even more general temporal trends"
- Why unresolved: The paper uses strict isomorphism for rule transitions in its current implementation, limiting the generality of discovered trends
- What evidence would resolve it: Empirical studies comparing different levels of relaxation in rule isomorphism and their impact on discovered temporal trends and interpretability

### Open Question 2
- Question: How does the performance of DyVeRG vary with different hierarchical clustering algorithms for generating the initial filtration?
- Basis in paper: [explicit] The paper mentions that "we choose to use Leiden for our analyses as opposed to the myriad alternatives" but doesn't systematically compare different clustering methods
- Why unresolved: The choice of clustering algorithm could significantly impact the extracted grammars and their temporal evolution
- What evidence would resolve it: Comparative studies using different clustering algorithms (Louvain, spectral clustering, etc.) on the same datasets

### Open Question 3
- Question: What is the impact of the maximum RHS size parameter (μ) on the quality and interpretability of extracted grammars?
- Basis in paper: [explicit] The paper mentions using "subfiltrations covering at most μ nodes (terminal or nonterminal) total, where μ ∈ N+ is set a priori to limit the maximum size of any rule's RHS"
- Why unresolved: The paper doesn't explore how different values of μ affect the resulting grammars and their ability to model temporal dynamics
- What evidence would resolve it: Sensitivity analysis showing grammar quality metrics across different μ values on benchmark datasets

## Limitations

- Framework's effectiveness depends critically on the stability of hierarchical clusterings across time steps, which may break down for highly volatile temporal graphs
- The paper does not thoroughly address computational complexity for large-scale graphs, particularly the graph edit distance calculations that scale poorly
- Interpretability claims assume that rule transitions correspond to meaningful network processes, but this relationship is not empirically validated across diverse temporal patterns

## Confidence

- **High confidence**: The core mechanism of tracking rule evolution through hierarchical clusterings is well-defined and theoretically sound
- **Medium confidence**: The dyvergence metric effectively distinguishes genuine temporal dynamics from imposters, though performance may vary with dataset characteristics
- **Low confidence**: The interpretability claims regarding rule transitions providing actionable insights, as this requires domain-specific validation
