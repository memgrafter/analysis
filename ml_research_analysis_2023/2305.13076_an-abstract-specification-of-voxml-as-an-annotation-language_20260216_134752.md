# An Abstract Specification of VoxML as an Annotation Language

## Quick Facts
- arXiv ID: 2305.13076
- Source URL: https://arxiv.org/abs/2305.13076
- Authors: 
- Reference count: 9
- The paper proposes an abstract syntax for VoxML as an annotation language, enabling it to encode visual object affordances, habitats, and agent-relative embodiment for annotating human-object interactions.

## Executive Summary
VoxML is a modeling language for simulating actions in the visual world that can also be used as a markup language for annotating linguistic expressions involving human-object interactions. This paper formally specifies VoxML as an annotation language by defining an abstract syntax (ASynvoxml) that is interoperable with ISO semantic annotation standards. The annotation scheme translates annotation structures into semantic forms interpretable against a VoxML minimal model using a lexicon of object voxemes, enabling more complete situated interpretations than traditional lexical semantic forms.

## Method Summary
The paper defines an abstract syntax for the VoxML-based annotation scheme as a set-theoretic tuple with base categories (event/action, entity/object, relation) and assignments from attributes to values. Annotation structures are generated based on this abstract syntax, consisting of anchoring and content structures. These annotation structures are translated to semantic forms in typed first-order logic, which are then interpreted with respect to the VoxML minimal model by referring to the voxicon (set of voxemes). The enriched object representations include geometrical type, habitat, affordance structures, and agent-relative embodiment.

## Key Results
- VoxML can be formally specified as an abstract syntax interoperable with ISO semantic annotation standards
- Enriched object representations (geometry, habitat, affordances, embodiment) enable more complete situated interpretations than traditional semantic forms
- The annotation scheme can translate and interpret actions like "Mary picked up the glass from the table" using the VoxML minimal model and voxicon

## Architecture Onboarding

- Component map: Abstract syntax specification (ASynvoxml tuple) -> Annotation structures (anchoring and content) -> Translation to semantic forms (typed first-order logic) -> VoxML minimal model interpretation (using voxicon) -> ISO standard interoperability references

- Critical path: 1. Define abstract syntax with base and relational categories; 2. Generate annotation structures from linguistic data; 3. Translate annotation structures to semantic forms; 4. Interpret semantic forms against VoxML minimal model using voxicon; 5. Ensure interoperability with ISO standards

- Design tradeoffs: Generality vs. specificity in abstract syntax definition; complexity of enriched object representations vs. interpretation efficiency; level of detail in semantic forms vs. tractability of interpretation

- Failure signatures: Inability to represent certain linguistic constructions in annotation structures; loss of critical information during translation to semantic forms; incompatibility with ISO standards; inefficient or incorrect interpretation against minimal model

- First 3 experiments: 1. Annotate "Mary picked up the glass" and verify translation to semantic forms and interpretation against minimal model; 2. Test ISO-TimeML interoperability by referencing temporal links in a narrative; 3. Evaluate interpretation of sentences with pronoun anaphora like "Mary picked up the glass and put it on the table"

## Limitations

- Weak evidence supporting claims of ISO standard interoperability, relying primarily on structural compatibility rather than demonstrated integration
- Limited empirical validation of enriched object representations' effectiveness compared to traditional semantic forms
- Unclear methodology for determining object habitats in different contexts

## Confidence

- **High confidence**: Formal specification of abstract syntax (ASynvoxml) and general framework for translating annotation structures to semantic forms
- **Medium confidence**: Claim that enriched object representations enable more complete interpretations, with theoretical justification but limited empirical validation
- **Low confidence**: Interoperability with ISO standards and practical effectiveness of habitat-based interpretation due to weak supporting evidence
