# Reversible Vision Transformers

## Quick Facts
- arXiv ID: 2302.04869
- Source URL: https://arxiv.org/abs/2302.04869
- Reference count: 40
- Reversible vision transformers achieve up to 15.5x memory savings while maintaining competitive accuracy

## Executive Summary
This paper introduces reversible vision transformers that decouple GPU memory requirements from model depth by reconfiguring residual connections in Vision Transformer (ViT) and Multiscale Vision Transformer (MViT) architectures. The key innovation allows inputs to be recomputed from outputs during the backward pass, eliminating the need to store intermediate activations. Experiments across image classification, object detection, and video classification tasks demonstrate significant memory savings of up to 15.5x compared to non-reversible counterparts while maintaining competitive accuracy. The reversible transformers also achieve up to 2.3x higher throughput for deeper models, making them particularly promising for hardware resource-limited training regimes.

## Method Summary
The authors adapt Vision Transformer and Multiscale Vision Transformer architectures to reversible variants by implementing a reversible transformation structure that allows inputs to be recomputed from outputs in the backward pass. This eliminates the need to store intermediate activations, trading computation for memory. A critical innovation is removing internal residual connections around MLP and attention blocks to address training convergence issues in deeper models. The reversible design inherently provides stronger regularization, which requires adapted training recipes including lighter augmentations and higher weight decay. The method is evaluated on ImageNet-1K for image classification, Kinetics-400/600 for video classification, and MS-COCO for object detection.

## Key Results
- Reversible vision transformers achieve up to 15.5x memory savings compared to non-reversible counterparts
- Memory savings enable up to 2.3x higher throughput for deeper models
- Competitive accuracy maintained across image classification, object detection, and video classification tasks
- Particularly beneficial for video recognition tasks often constrained by memory limitations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Reversible vision transformers reduce memory footprint by avoiding activation caching during training.
- Mechanism: The reversible transformation structure allows inputs to be recomputed from outputs in the backward pass, eliminating the need to store intermediate activations. This trades computation for memory.
- Core assumption: The forward pass can be analytically inverted using the reversible transformation structure.
- Evidence anchors:
  - [abstract] "Reversible Vision Transformers achieve a reduced memory footprint of up to 15.5x at roughly identical model complexity, parameters and accuracy"
  - [section] "As noted in §3.1.1, an input transformed with the reversible transformation T allows recalculating the input from the output of the transformation. Hence, a network composed of such reversible transformations does not need to store intermediate activations since they can be recomputed easily in the backward pass from the output."
- Break condition: If the reversible transformation cannot be inverted analytically, or if the functions F and G in the transformation are not equidimensional.

### Mechanism 2
- Claim: Removing internal residual connections improves training convergence for deeper reversible vision transformer models.
- Mechanism: The reversible transformation already provides residual connections between the two streams. Adding internal residuals around MLP and attention blocks creates conflicting gradient flow patterns that destabilize training in deeper models.
- Core assumption: Internal skip connections create gradient conflicts in the reversible architecture's two-stream structure.
- Evidence anchors:
  - [section] "Interestingly, we observe a key relationship between the residual connections and signal propagation in Reversible Vision Transformer... we choose to omit them entirely for reversible vision transformer blocks."
  - [section] "Figure 3a... we observe that while the na¨ıve version with internal skip connections trains stably for shallow models, for deeper models the accuracy drops significantly."
- Break condition: If the internal residuals are somehow made compatible with the reversible transformation's gradient flow.

### Mechanism 3
- Claim: Reversible vision transformers have stronger inherent regularization than non-reversible counterparts.
- Mechanism: The reversible structure and the need to recompute activations during training introduces additional constraints and noise that regularize the model, reducing overfitting.
- Core assumption: The additional computation required for reversibility acts as a form of regularization.
- Evidence anchors:
  - [section] "We observe that a straightforward adaptation of vision transformers to reversible architectures fails to scale for deeper models because of training convergence instabilities due to internal sub-block residual connections."
  - [section] "Across different models and datasets, we find that at the same FLOP and parameter specifications, the reversible models tend to have stronger inherent regularization than their non-reversible counterparts."
- Break condition: If the regularization effect is somehow negated by other training choices or if the reversible architecture is modified to remove this regularization.

- Critical path: Input → Reversible blocks (ViT or MViT) → Fusion → Classifier head
- Design tradeoffs:
  - Memory vs. Computation: Reversible architectures trade computation for memory by recomputing activations instead of storing them.
  - Depth vs. Convergence: Deeper reversible models may require careful configuration of residual connections to avoid training instabilities.
  - Regularization vs. Performance: Reversible models have stronger inherent regularization, which may require adjustments to training recipes.
- Failure signatures:
  - Training divergence or instability for deeper models with internal residual connections.
  - Performance degradation if the reversible transformation is not implemented correctly.
  - Memory usage not scaling down as expected if the reversible structure is not fully utilized.

## Limitations
- Training convergence issues for deeper models require careful configuration of residual connections
- Stronger inherent regularization may require adapted training recipes and could impact performance
- Computational overhead of recomputation during backward pass not fully characterized

## Confidence
- **High Confidence**: Claims about memory savings (up to 15.5x) and throughput improvements (up to 2.3x) - these are directly measurable and empirically validated.
- **Medium Confidence**: Claims about training convergence improvements through residual removal - supported by ablation studies but could benefit from deeper theoretical analysis.
- **Medium Confidence**: Claims about inherent regularization - observed empirically but the mechanism isn't fully explained.

## Next Checks
1. **Ablation of Recomputation Cost**: Measure wall-clock training time for reversible vs non-reversible models to quantify the trade-off between memory savings and computational overhead across different hardware configurations.

3. **Memory-Bounded Training Analysis**: Conduct experiments on extremely memory-constrained setups (e.g., single GPU with limited VRAM) to verify the practical utility of reversible transformers in real-world deployment scenarios.
