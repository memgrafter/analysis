# A dynamic Bayesian optimized active recommender system for curiosity-driven Human-in-the-loop automated experiments

## Quick Facts
- arXiv ID: 2304.02484
- Source URL: https://arxiv.org/abs/2304.02484
- Reference count: 0
- Primary result: Human-in-the-loop BOARS system with deep kernel learning improves identification of symmetric piezoresponse amplitude hysteresis loops in ferroelectric thin films

## Executive Summary
This paper introduces a human-in-the-loop automated experiment workflow called Bayesian Optimized Active Recommender System (BOARS) that enables dynamic adjustment of optimization targets during materials characterization. The system combines a human-operated recommender interface for real-time spectrum voting with a Bayesian optimization engine to guide parameter space exploration. Tested on piezoresponse force spectroscopy data from PbTiO3 thin films, the method successfully identifies regions with symmetric hysteresis loops affected by subsurface defects. The use of deep kernel learning significantly improves performance compared to traditional kernel functions by better handling the high-dimensional input space.

## Method Summary
The BOARS framework integrates a human recommender system (ARS) with Bayesian optimization (BO) for automated materials experimentation. Users visualize spectra in real-time and vote on their quality (bad=0, good=1, very good=2), which constructs a dynamic target that evolves with each new vote. This target guides a Gaussian process-based surrogate model, which uses deep kernel learning to handle high-dimensional image patches from the microscopy data. The acquisition function suggests optimal measurement locations for the next spectrum, balancing exploration of new regions with exploitation of known good areas. The method was validated on both pre-acquired and real-time atomic force microscopy data.

## Key Results
- BOARS successfully identified regions with symmetric piezoresponse amplitude hysteresis loops in PbTiO3 thin films
- Deep kernel learning outperformed traditional periodic kernels in capturing complex relationships between image features and spectral objectives
- The system effectively found regions more affected by subsurface defects than local domain structure
- Real-time implementation on atomic force microscope demonstrated practical feasibility

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The human-in-the-loop recommender system allows dynamic adjustment of optimization targets based on visual inspection of spectra.
- Mechanism: Users vote on spectra in real time, constructing a target that evolves as more data is collected. The system updates the target using a weighted combination of previous votes and new spectra, guided by user preference parameters.
- Core assumption: Human judgment can effectively identify structurally similar spectra that represent desired material properties, even without pre-defined objective functions.
- Evidence anchors:
  - [abstract]: "The approach was tested on piezoresponse force spectroscopy data... The results show that the method can efficiently find regions of symmetric piezoresponse amplitude hysteresis loops..."
  - [section]: "Given a spectrum, the user (human) visualizes the spectra and provide subjective vote on its quality... With the next subsequent upvoting of other spectra, the target is accordingly updated as per eq. 1."
  - [corpus]: Weak—no direct citations found; mechanism is described but not independently validated in neighboring work.
- Break condition: If user votes become inconsistent or uncorrelated with actual material behavior, the dynamic target construction fails.

### Mechanism 2
- Claim: Deep kernel learning (DKL) improves the ability to balance prior image-based information with posterior spectral similarity in high-dimensional parameter spaces.
- Mechanism: DKL embeds high-dimensional image patches into a low-dimensional latent space via a neural network, then applies a Gaussian process kernel to learn the relationship between image features and spectral objectives. This allows the model to ignore spurious correlations with surface domains.
- Core assumption: Local image patches contain useful prior information, but the relationship to spectral targets is complex and non-linear, requiring learned feature extraction.
- Evidence anchors:
  - [section]: "We utilized a DKL implementation... where the high-dimensional input image patch is first embedded into low dimensional kernel space... and then a standard GP kernel operates..."
  - [section]: "The estimated uncertainty map... within the white region has relatively lower variance... unlike the BOARS with traditional kernel, the dKL also adjusts the knowledge through posterior exploration..."
  - [corpus]: Weak—no direct citations found; assumption is supported by method description but not independently verified.
- Break condition: If the neural network fails to learn meaningful embeddings, the DKL model reverts to poor performance.

### Mechanism 3
- Claim: Bayesian optimization with acquisition functions enables efficient exploration-exploitation trade-off in adaptive experiment design.
- Mechanism: After each spectrum measurement, a surrogate Gaussian process model updates posterior means and variances. The acquisition function selects the next measurement location to maximize expected improvement, balancing known good regions with unexplored areas.
- Core assumption: The surrogate model accurately approximates the expensive objective function, and acquisition functions can guide sampling toward regions of interest.
- Evidence anchors:
  - [section]: "The second part of the architecture is the BO engine, which guides the path to locate the regions of interest with maximum structural similarity to the human-upvoted spectra, through sequential updating with a computationally cheap surrogate model..."
  - [section]: "The acquisition function suggests the next best location to capture spectra."
  - [corpus]: Weak—mechanism is standard in BO literature but not specifically validated here.
- Break condition: If the objective function is noisy or discontinuous, the BO trajectory may converge to suboptimal regions.

## Limitations

- The approach relies heavily on subjective human judgment, introducing variability that is difficult to quantify
- Evidence base is limited to a single material system (PbTiO3 thin films), making generalizability uncertain
- Deep kernel learning implementation details are sparse, with insufficient quantitative comparison between kernel types
