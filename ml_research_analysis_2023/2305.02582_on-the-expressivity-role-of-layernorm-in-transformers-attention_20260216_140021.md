# On the Expressivity Role of LayerNorm in Transformers' Attention

## Quick Facts
- arXiv ID: 2305.02582
- Source URL: https://arxiv.org/abs/2305.02582
- Reference count: 18
- Key outcome: LayerNorm in Transformers serves two crucial roles: projection of keys onto a hyperplane orthogonal to [1,1,...,1] and scaling all keys to the same norm, both of which enhance attention expressivity

## Executive Summary
This paper reveals that LayerNorm, typically viewed as a mere normalization technique in Transformers, plays a crucial role in enabling the attention mechanism's expressivity. The authors demonstrate that LayerNorm can be decomposed into two key components: projection and scaling. The projection ensures all keys lie on a hyperplane orthogonal to the [1,1,...,1] vector, allowing the attention mechanism to learn queries aligned with this vector and attend equally to all keys when needed. The scaling component ensures all keys have the same norm, preventing the problem of "unselectable" keys where some keys lie within the convex hull of others and cannot be selected by the attention mechanism.

## Method Summary
The paper uses synthetic tasks (majority voting on sequences of 50 tokens from 20 classes) and standard language modeling on Wikipedia to study LayerNorm's impact. Experiments are conducted on small Transformer models with 8-dimensional hidden states. The authors implement modified versions of LayerNorm that remove either the projection or scaling components to isolate their effects. They measure convergence speed, query alignment with [1,1,...,1] vectors, and the fraction of "unselectable" keys across different configurations.

## Key Results
- Transformers learn to align queries with the [1,1,...,1] vector when LayerNorm projects keys onto the orthogonal hyperplane, enabling faster convergence on majority tasks
- LayerNorm's scaling component prevents unselectable keys by ensuring all keys have the same norm, with experiments showing at least 32% unselectable keys without this scaling
- The geometric properties of LayerNorm are most evident in small models (d=8) and may be less critical for larger models with higher dimensional embeddings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LayerNorm's projection component enables equal attention to all keys by aligning queries with the [1,1,...,1] vector
- Mechanism: LayerNorm projects all key vectors onto a hyperplane orthogonal to the [1,1,...,1] vector. This allows the attention mechanism to learn queries aligned with this vector, resulting in equal attention scores for all keys
- Core assumption: The attention mechanism can learn to align queries with the [1,1,...,1] vector when keys are projected onto the orthogonal hyperplane
- Evidence anchors:
  - [abstract]: "projection allows the attention mechanism to create an attention query that attends to all keys equally, offloading the need to learn this operation by the attention"
  - [section 3.1]: "Since all projected keys are orthogonal to the hyperplane's normal ⃗1 vector, this fact can be exploited in the training process by learning weights such that the queries will be parallel to ⃗1"
  - [corpus]: Weak - no direct corpus evidence supporting this specific mechanism

### Mechanism 2
- Claim: LayerNorm's scaling component prevents "unselectable" keys by ensuring all keys have the same norm
- Mechanism: LayerNorm scales all projected key vectors to have the same norm of √d. This prevents any key from lying within the convex hull of other keys, making all keys selectable by the attention mechanism
- Core assumption: Keys with different norms can create situations where some keys lie within the convex hull of others and cannot be selected
- Evidence anchors:
  - [abstract]: "scaling allows each key to potentially receive the highest attention, and prevents keys from being 'un-select-able'"
  - [section 3.2]: "Applying LayerNorm to the keys ensures that all keys are scaled to the same size, and thus none of them lies inside the convex hull of S"
  - [section 4.2]: "Without scaling, there are at least 32% 'unselectable' keys that cannot receive maximal attention score in each layer"

### Mechanism 3
- Claim: LayerNorm enables faster convergence on majority tasks by providing geometric structure
- Mechanism: By projecting keys onto the hyperplane orthogonal to [1,1,...,1], LayerNorm creates a geometric structure that allows the attention mechanism to exploit this structure by aligning queries with [1,1,...,1], enabling faster computation of majority
- Core assumption: The attention mechanism can learn to exploit the geometric structure created by LayerNorm projection
- Evidence anchors:
  - [abstract]: "projection allows the attention mechanism to create an attention query that attends to all keys equally, offloading the need to learn this operation by the attention"
  - [section 4.1]: "We show that in the 'majority' task, a Transformer learns to align the queries to be orthogonal to the keys, allowing a much faster convergence"

## Architecture Onboarding

- Component map:
  - Input vectors → LayerNorm (projection + scaling) → Attention mechanism
  - Projection: Orthogonalizes keys to [1,1,...,1]
  - Scaling: Normalizes all keys to norm √d
  - Attention: Computes scores based on dot-product of queries and keys

- Critical path:
  - LayerNorm projection → Attention query alignment → Equal attention scores
  - LayerNorm scaling → Prevention of unselectable keys → All keys selectable

- Design tradeoffs:
  - Using LayerNorm before attention provides geometric structure but adds computational overhead
  - Alternative: Learnable projection matrix could provide similar benefits but requires more parameters
  - LayerNorm after attention (Post-LN) may not provide the same geometric benefits for the attention mechanism

- Failure signatures:
  - If attention queries are not aligning with [1,1,...,1] despite LayerNorm projection, check for issues in the attention mechanism or training process
  - If unselectable keys persist despite LayerNorm scaling, verify that the scaling is correctly implemented and that key norms are being properly normalized

- First 3 experiments:
  1. Train a Transformer with and without LayerNorm on a majority task to observe convergence speed differences
  2. Analyze the geometric structure of keys with and without LayerNorm projection to verify the orthogonalization to [1,1,...,1]
  3. Measure the fraction of unselectable keys in a language model with and without LayerNorm scaling to confirm the prevention of this issue

## Open Questions the Paper Calls Out
1. How does the LayerNorm projection property affect the learning dynamics of attention mechanisms in larger Transformer models with higher dimensional embeddings?
2. What would be the impact of modifying LayerNorm to project keys onto hyperplanes orthogonal to multiple normal vectors instead of just [1,1,...,1]?
3. How does the LayerNorm scaling property interact with different attention mechanisms beyond dot-product attention, such as additive attention or scaled dot-product variants?

## Limitations
- Empirical validation is limited to small-scale synthetic tasks and single-layer Transformer architecture
- Claims about practical impact on convergence speed in real-world language modeling tasks are primarily based on synthetic majority tasks
- Analysis assumes dot-product attention without considering alternative attention mechanisms that might behave differently under LayerNorm

## Confidence
- High confidence: The geometric interpretation of LayerNorm's scaling component preventing unselectable keys through norm normalization is well-supported by both theory and empirical evidence
- Medium confidence: The projection mechanism's role in enabling equal attention through hyperplane orthogonality is theoretically sound but relies on assumptions about the attention mechanism's ability to learn specific query alignments
- Low confidence: Claims about the practical impact on convergence speed in real-world language modeling tasks, as the evidence is primarily based on synthetic majority tasks

## Next Checks
1. Test the projection mechanism on a deeper Transformer architecture (4+ layers) with natural language data to verify if queries consistently align with [1,1,...,1] vectors
2. Implement an alternative attention mechanism (e.g., additive attention) to determine if LayerNorm's geometric benefits are specific to dot-product attention
3. Conduct an ablation study measuring the impact of removing LayerNorm at different depths in a pre-trained language model to assess practical importance beyond the initial layers
