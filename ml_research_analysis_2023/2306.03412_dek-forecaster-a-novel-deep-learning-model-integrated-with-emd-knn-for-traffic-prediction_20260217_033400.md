# DEK-Forecaster: A Novel Deep Learning Model Integrated with EMD-KNN for Traffic Prediction

## Quick Facts
- arXiv ID: 2306.03412
- Source URL: https://arxiv.org/abs/2306.03412
- Reference count: 40
- Best variant achieves 96.48% accuracy with MAPE of 3.22% and RMSE of 0.54 Gbps

## Executive Summary
This paper addresses Internet traffic volume forecasting for ISPs, a critical task for network planning and investment decisions. The proposed DEK-Forecaster model combines deep sequence learning with Empirical Mode Decomposition (EMD) for noise reduction, empirical rule-based outlier detection, and K-Nearest Neighbor (KNN) imputation for outlier mitigation. The method processes ISP traffic data through multiple stages to improve prediction accuracy over traditional deep learning baselines.

## Method Summary
The DEK-Forecaster approach integrates EMD for denoising traffic data by subtracting the average of all Intrinsic Mode Functions (IMFs), uses three-standard-deviation rules for outlier detection, and applies optimized KNN imputation to replace detected outliers. Time-lagged features are selected via ARIMA and AIC criteria. The model architecture combines LSTM Seq2Seq with attention mechanisms, processed through the EMD-KNN pipeline. Experiments demonstrate improved performance over standard deep learning baselines using real ISP traffic data.

## Key Results
- LSTM Seq2Seq ATN EMD KNN variant achieves 96.48% accuracy
- MAPE of 3.22% and RMSE of 0.54 Gbps on ISP traffic data
- Significant improvements over traditional deep learning baselines

## Why This Works (Mechanism)
The integration of EMD for noise reduction helps isolate meaningful traffic patterns from random fluctuations. The three-standard-deviation outlier detection identifies anomalous traffic spikes that could otherwise distort predictions. KNN imputation provides robust handling of these outliers by leveraging similar historical patterns. Together, these preprocessing steps create cleaner input data for the deep learning model, improving prediction accuracy.

## Foundational Learning

**Empirical Mode Decomposition (EMD)**: Signal processing technique that decomposes non-linear, non-stationary signals into intrinsic mode functions
- Why needed: Traditional Fourier-based methods assume linearity and stationarity, which traffic data violates
- Quick check: Can verify decomposition quality by reconstructing original signal from IMFs

**Intrinsic Mode Functions (IMFs)**: Oscillatory components extracted by EMD, each representing different time scales of variation
- Why needed: Traffic data contains multi-scale patterns (daily, weekly, seasonal) that need separate analysis
- Quick check: Number and characteristics of IMFs should reflect expected traffic patterns

**K-Nearest Neighbors Imputation**: Method for replacing missing or outlier values using similar historical observations
- Why needed: Simple statistical methods may not capture complex traffic dependencies
- Quick check: Imputed values should fall within reasonable range based on neighboring observations

## Architecture Onboarding

**Component Map**: Raw Traffic Data -> EMD Decomposition -> IMF Subtraction (Denoising) -> Outlier Detection -> KNN Imputation -> ARIMA Feature Selection -> LSTM Seq2Seq ATN -> Forecast

**Critical Path**: The EMD denoising and KNN imputation preprocessing stages are critical, as they directly affect input quality to the LSTM model. The attention mechanism in the LSTM is also crucial for capturing long-term dependencies.

**Design Tradeoffs**: The model trades computational complexity (EMD and KNN steps) for improved accuracy. The three-standard-deviation threshold for outlier detection is simple but may not adapt well to varying traffic regimes.

**Failure Signatures**: Poor EMD decomposition could lead to over-smoothing or under-smoothing of traffic patterns. Suboptimal KNN parameters might result in inappropriate outlier replacement values. Incorrect feature selection could miss important temporal dependencies.

**First Experiments**: 1) Test EMD decomposition quality on synthetic signals with known components, 2) Validate outlier detection accuracy on labeled anomalous traffic data, 3) Benchmark KNN imputation against other methods on artificially corrupted datasets.

## Limitations
- No comparison with recent advanced deep learning architectures (Transformers, Informer, Autoformer)
- Single ISP dataset without public availability prevents independent validation
- Three-standard-deviation outlier detection may not generalize across different traffic regimes

## Confidence

High: The methodology appears sound and improvements over basic deep learning models are statistically significant within tested conditions.

Medium: Lack of comparison with state-of-the-art models and single proprietary dataset limit external validity and reproducibility.

Low: The empirical nature of parameter choices and absence of sensitivity analysis reduce confidence in generalizability.
