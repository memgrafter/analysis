# RNAS-CL: Robust Neural Architecture Search by Cross-Layer Knowledge Distillation

## Quick Facts
- arXiv ID: 2301.08092
- Source URL: https://arxiv.org/abs/2301.08092
- Reference count: 40
- Key outcome: First NAS method that jointly optimizes accuracy, latency, and adversarial robustness without robust training using cross-layer knowledge distillation

## Executive Summary
This paper introduces RNAS-CL, a novel neural architecture search method that achieves robust architectures without requiring robust training. The key innovation is using intermediate attention maps from a robust teacher model to guide each student layer during architecture search, automatically finding optimal cross-layer teacher-student mappings via Gumbel-Softmax. This approach enables learning where to pay attention for improved robustness while simultaneously optimizing model efficiency through channel number search. Experiments demonstrate significant improvements in both clean and adversarial accuracy compared to existing efficient and robust methods, while maintaining smaller model sizes.

## Method Summary
RNAS-CL employs a two-phase approach: search and training. During the search phase, Gumbel-Softmax is used to optimize architectural weights, including teacher-student layer mappings and channel numbers, over 100 epochs (CIFAR-10) or 100 epochs (ImageNet-100). The method uses cross-entropy loss, KL divergence, and attention loss, with Gumbel-Softmax temperature initialized at 5.0 and decayed by e⁻⁰·⁰⁴⁵ per epoch. After search, the optimal architecture is trained from scratch for 200 epochs (ImageNet-100) or 100 epochs (CIFAR-10) using the same loss functions. The cross-layer knowledge distillation approach leverages attention maps (sum of squared activations across channels) from a robust teacher model to guide each student layer, enabling robustness without robust training.

## Key Results
- Outperforms existing efficient and robust methods by up to 14.5% in clean accuracy
- Achieves up to 28% higher PGD adversarial accuracy compared to baselines
- Maintains smaller model sizes while achieving superior performance across CIFAR-10 and ImageNet-100

## Why This Works (Mechanism)
The cross-layer knowledge distillation mechanism works by transferring intermediate representations (attention maps) from a robust teacher to each student layer, rather than just final outputs. This allows the student to learn robust features at multiple levels of abstraction. The Gumbel-Softmax optimization automatically discovers the most effective teacher-student layer pairings, ensuring that each student layer receives the most relevant robust guidance. This approach is more effective than traditional knowledge distillation because it captures the teacher's robustness patterns throughout the network depth, not just at the output level.

## Architecture Onboarding

**Component Map**: Input -> Search Space -> Gumbel-Softmax Optimization -> Attention Map Extraction -> Cross-Layer Distillation -> Output

**Critical Path**: Search phase (Gumbel-Softmax optimization) → Attention map computation → Teacher-student layer mapping → Channel number optimization → Training phase (final architecture training)

**Design Tradeoffs**: The method trades increased search complexity (cross-layer mappings) for improved robustness without robust training. Channel number search adds computational overhead but enables efficiency optimization. The robust teacher requirement adds initial training cost but enables subsequent robustness without adversarial training.

**Failure Signatures**: Poor robustness results indicate suboptimal teacher-student layer mappings. High computational cost suggests inefficient search space configuration. Low clean accuracy may indicate over-optimization for robustness at the expense of natural performance.
