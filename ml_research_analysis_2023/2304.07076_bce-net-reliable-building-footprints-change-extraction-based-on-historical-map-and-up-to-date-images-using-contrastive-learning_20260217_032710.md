# BCE-Net: Reliable Building Footprints Change Extraction based on Historical Map and Up-to-Date Images using Contrastive Learning

## Quick Facts
- arXiv ID: 2304.07076
- Source URL: https://arxiv.org/abs/2304.07076
- Reference count: 14
- Key outcome: Proposed BCE-Net achieves F1 scores of 93.99% on public dataset and 70.74% on SI-BU dataset

## Executive Summary
This paper introduces BCE-Net, a novel building footprint change extraction method that addresses the challenge of pseudo-changes in historical map and up-to-date image analysis. The method combines deformable convolutional networks to handle geometric inconsistencies between historical footprints and current building representations, with instance-level contrastive learning to improve building feature discrimination. The approach is evaluated on both a public dataset and a newly constructed practical dataset, demonstrating state-of-the-art performance.

## Method Summary
BCE-Net is a multi-task segmentation framework that takes historical building footprints and up-to-date high-resolution images as inputs. The model uses a pre-trained ResNet34 encoder followed by a deformable convolution-based feature transform module to handle geometric inconsistencies. Three parallel segmentation heads identify newly constructed, removed, and existing buildings, while an instance-level contrastive loss improves feature distinguishability. The model is trained using binary cross-entropy and Dice loss with data augmentation.

## Key Results
- Achieves F1 score of 93.99% on public dataset, outperforming state-of-the-art methods
- Achieves F1 score of 70.74% on newly constructed SI-BU dataset
- Demonstrates effectiveness in handling pseudo-changes due to seasonal variations and building façade inclination

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Deformable convolutional network directly learns offsets to handle geometric inconsistencies
- Mechanism: Replaces standard convolutions with deformable layers that adaptively adjust feature sampling locations to align building rooftops with historical footprints
- Core assumption: Geometric transformation between footprints and images can be learned through offset parameters
- Evidence anchors: Abstract mentions deformable convolutional network for geometric inconsistencies; section describes DCN-based feature transform module
- Break condition: If geometric transformation is too complex for learned offsets to capture

### Mechanism 2
- Claim: Instance-level contrastive learning increases distinguishability between building and non-building features
- Mechanism: Computes cosine similarity between feature patches within building bounding boxes across three segmentation branches to pull same-building features closer and push different features apart
- Core assumption: Buildings have global consistency in features across representations that can be exploited through contrastive learning
- Evidence anchors: Abstract mentions instance-level contrastive learning for building semantics; section describes similarity-based contrastive loss
- Break condition: If background pseudo-changes share similar global features with buildings

### Mechanism 3
- Claim: Multi-task segmentation framework constrains feature learning to exploit building semantics
- Mechanism: Trains three parallel segmentation heads (newly constructed, removed, existing buildings) with shared encoder features to learn comprehensive building representations
- Core assumption: Features useful for identifying existing buildings are also valuable for distinguishing changed buildings from background
- Evidence anchors: Abstract mentions multi-branch building extraction method; section describes auxiliary segmentation head for existing buildings
- Break condition: If features for existing buildings differ significantly from those needed for change detection

## Foundational Learning

- Concept: Deformable convolution operations and their ability to learn spatial offsets
  - Why needed here: To handle geometric inconsistencies between historical building footprints and current building representations caused by off-nadir angles and building heights
  - Quick check question: How does a deformable convolution differ from a standard convolution in terms of feature sampling locations?

- Concept: Contrastive learning and instance-level feature discrimination
  - Why needed here: To improve model's ability to distinguish buildings from background pseudo-changes caused by seasonal variations and building façade inclination
  - Quick check question: What is the difference between pixel-level and instance-level contrastive learning in terms of feature comparison scope?

- Concept: Multi-task learning and shared feature representation
  - Why needed here: To exploit building semantics across different change states and improve overall model generalization
  - Quick check question: How does training multiple related tasks simultaneously benefit feature learning compared to training each task independently?

## Architecture Onboarding

- Component map: Encoder -> Feature Transform -> Feature Splitting -> Segmentation Heads -> Loss Computation
- Critical path: The deformable convolution module is critical for handling geometric inconsistencies, while the contrastive loss is critical for reducing pseudo-changes
- Design tradeoffs: Increased complexity (three segmentation heads, deformable convolutions, contrastive loss) for improved robustness to geometric inconsistencies and pseudo-changes
- Failure signatures: Poor performance on buildings with significant off-nadir angles, failure to distinguish buildings from background pseudo-changes, inability to handle large scale variations
- First 3 experiments:
  1. Train baseline model without deformable convolutions and contrastive loss
  2. Add deformable convolutions only to evaluate geometric inconsistency handling
  3. Add contrastive loss only to evaluate pseudo-change reduction

## Limitations

- Limited corpus support for deformable convolution effectiveness in building change detection
- Instance-level contrastive learning approach lacks direct validation in this specific domain
- SI-BU dataset construction process and annotation quality not fully described
- Performance on very high off-nadir imagery or dense urban areas not evaluated

## Confidence

- High confidence: Multi-task segmentation framework and overall architectural approach are well-established in computer vision literature
- Medium confidence: Deformable convolution for geometric alignment shows promise but lacks extensive validation in this specific domain
- Low confidence: Instance-level contrastive learning mechanism's effectiveness for reducing pseudo-changes requires more rigorous evaluation
