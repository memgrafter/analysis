# Graph Embedding Augmented Skill Rating System
## Quick Facts
- arXiv ID: 2304.08257
- Source URL: https://arxiv.org/abs/2304.08257
- Reference count: 34
- This paper presents a framework for learning player embeddings in competitive games and events using skill gap graphs.

## Executive Summary
This paper introduces a novel approach to player skill rating that combines graph embedding techniques with traditional Elo rating systems. The framework models players and their win-loss relationships as an undirected weighted graph, learning low-dimensional embeddings that capture relative skill levels. The proposed GElo system extends classic Elo by incorporating player embeddings to adjust rating scores based on player activeness and skill similarities, demonstrating improved reliability over traditional methods through experiments on public datasets.

## Method Summary
The framework constructs skill gap graphs from player match histories and learns embeddings using random walk-based graph embedding methods. These embeddings preserve topological relationships while providing convenient low-dimensional representations for subsequent tasks. GElo extends the classic Elo system by first constructing the skill gap graph, learning player embeddings, and then adjusting Elo's calculated rating scores based on player activeness metrics and cosine similarities between embeddings. The system operates offline and in parallel without requiring modifications to existing rating infrastructure.

## Key Results
- Player embeddings learned from skill gap graphs effectively capture relative skill levels among players
- GElo demonstrates more reliable evaluation of player skill levels compared to vanilla Elo
- The approach is non-intrusive to existing rating systems and can be executed offline

## Why This Works (Mechanism)
The approach works by transforming competitive relationships into graph structures where nodes represent players and edges encode win-loss outcomes. Random walk-based embeddings capture the topological relationships in this graph, preserving skill hierarchies in a low-dimensional space. By incorporating these embeddings into Elo's calculations through activeness and similarity adjustments, the system benefits from both the historical reliability of Elo and the nuanced skill representations learned from the graph structure.

## Foundational Learning
1. **Graph Embeddings**: Low-dimensional vector representations of graph nodes that preserve topological relationships
   - Why needed: To transform complex competitive relationships into analyzable vector representations
   - Quick check: Can reconstruct graph structure from embeddings using similarity metrics

2. **Random Walk-based Embedding**: Methods that generate node embeddings by simulating random walks on graphs
   - Why needed: To capture multi-hop relationships and local graph structures
   - Quick check: Embedding distances correlate with graph proximity

3. **Cosine Similarity**: Metric for measuring similarity between vector representations
   - Why needed: To quantify skill similarity between players based on their embeddings
   - Quick check: High cosine similarity indicates similar skill levels in validation data

Component Map: Match History -> Skill Gap Graph -> Random Walk Embeddings -> Cosine Similarity Calculations -> GElo Adjustment

Failure Signatures: Poor embedding quality manifests as inconsistent rating adjustments; graph sparsity leads to unreliable similarity calculations

## Limitations
- Assumes player skill relationships can be adequately represented through undirected weighted graphs based solely on win-loss outcomes
- Random walk-based embedding may introduce biases based on specific random walk parameters chosen
- Reliance on cosine similarities assumes embedding space adequately represents skill relationships across all game types

## Confidence
- High Confidence: Core methodology of constructing skill gap graphs and combining embeddings with Elo ratings is technically sound
- Medium Confidence: Experimental results showing improved reliability over vanilla Elo are promising but limited by tested datasets
- Low Confidence: General applicability claims to various competitive scenarios require further validation across diverse game genres

## Next Checks
