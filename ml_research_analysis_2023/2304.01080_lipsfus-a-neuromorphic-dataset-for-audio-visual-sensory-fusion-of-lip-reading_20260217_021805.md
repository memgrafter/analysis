# LIPSFUS: A neuromorphic dataset for audio-visual sensory fusion of lip reading

## Quick Facts
- **arXiv ID**: 2304.01080
- **Source URL**: https://arxiv.org/abs/2304.01080
- **Reference count**: 30
- **Key outcome**: A neuromorphic audio-visual dataset for lip reading with 89.6% audio and 72.7% visual classification accuracy using CNNs

## Executive Summary
This paper introduces LIPSFUS, a neuromorphic audio-visual dataset designed for sensory fusion applications using both artificial and spiking neural networks. The dataset was collected using synchronized Address-Event-Representation sensors—a neuromorphic Dynamic Vision Sensor (DVS) and a neuromorphic Auditory Sensor (NAS)—to capture visual lip movements and auditory speech data from 22 participants. The dataset includes words like digits, robotic commands, and short phrases recorded in both quiet and noisy environments, with additional conversion of the BBC LRW dataset into spiking format for expanded training possibilities.

## Method Summary
The dataset was collected using synchronized DVS and NAS sensors to capture visual and auditory speech data respectively. The AER-merger platform tagged each spike with a 1-bit identifier to distinguish between visual and audio events while maintaining temporal synchronization. Data preprocessing involved converting spiking information into histogram-based images suitable for CNN processing, along with temporal window shifting for data augmentation. Validation was performed using CNN architectures implemented in Keras+TensorFlow, achieving classification accuracies of up to 89.6% for audio and 72.7% for visual recognition of spoken digits.

## Key Results
- CNN validation achieved 89.6% audio classification accuracy for spoken digits
- Visual classification accuracy reached 72.7% for spoken digits
- Dataset includes synchronized neuromorphic recordings from 22 participants in quiet and noisy environments

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The dataset's high temporal synchronization between neuromorphic audio and visual streams enables effective sensory fusion learning.
- Mechanism: Synchronized spiking data from NAS and DVS sensors captures precise temporal relationships between lip movements and speech sounds, critical for audiovisual speech recognition.
- Core assumption: Temporal alignment between audio and visual events is maintained at the spike level during recording.
- Evidence anchors: [abstract] mentions "precise temporal synchronization using a set of Address-Event-Representation sensors"; [section] II.A describes AER-merger adding 1-bit to distinguish visual from audio spikes while maintaining temporal distribution.

### Mechanism 2
- Claim: The neuromorphic sensor format preserves temporal sparsity patterns useful for SNN learning.
- Mechanism: Spiking events from DVS and NAS sensors encode information in temporal patterns rather than frame-based intensity, reducing redundancy and emphasizing temporal features.
- Core assumption: Temporal spike patterns contain discriminative information for lip reading tasks.
- Evidence anchors: [section] II.A explains DVS has 128x128 pixels encoding changes as spikes, NAS has 64-channel frequency decomposition with spike outputs; [abstract] states "collected with precise temporal synchronization using a set of Address-Event-Representation sensors."

### Mechanism 3
- Claim: Data augmentation through temporal window shifting preserves lip movement dynamics while expanding training samples.
- Mechanism: Shifting temporal windows that capture speech activity creates variations that help networks generalize to different speaking speeds and durations.
- Core assumption: Lip movement patterns are consistent across different temporal shifts within reasonable bounds.
- Evidence anchors: [section] II.C.1 describes data augmentation by shifting temporal windows around spoken word activity for both audio and visual data; [abstract] mentions validation with CNN achieving "72.7% visual classification accuracy for spoken digits."

## Architecture Onboarding

- Component map: AER-sensor → AER-merger (1-bit tagging) → AER-monitor (timestamping) → jAER (storage) → CNN/SNN classifier
- Critical path: Sensor recording → temporal synchronization → spike-to-histogram conversion → classification network
- Design tradeoffs: Higher temporal resolution vs. data volume, spike-based vs. frame-based processing, synchronized vs. asynchronous recording
- Failure signatures: Misaligned timestamps, incorrect spike polarity interpretation, improper temporal window selection for augmentation
- First 3 experiments:
  1. Load AEDAT files and verify temporal synchronization by plotting audio and visual spike timestamps together

## Limitations
- Dataset validation relies only on CNNs, not the spiking neural networks it was designed for
- Small scale with only 22 participants compared to conventional audio-visual datasets
- Weak external corpus support for key mechanisms, particularly temporal synchronization in neuromorphic lip reading

## Confidence

- High confidence: Technical implementation of synchronized AER sensor recording and data collection methodology
- Medium confidence: CNN validation results showing 89.6% audio and 72.7% visual classification accuracy
- Low confidence: Claims about the dataset's utility for SNN architectures, as no SNN validation is provided
