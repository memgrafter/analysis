# BeAts: Bengali Speech Acts Recognition using Multimodal Attention Fusion

## Quick Facts
- arXiv ID: 2306.02680
- Source URL: https://arxiv.org/abs/2306.02680
- Reference count: 0
- Primary result: BeAts achieves 100% Precision and Recall on Bengali speech act recognition using multimodal attention fusion of audio and text.

## Executive Summary
This paper introduces BeAts, a multimodal attention fusion approach for Bengali speech act recognition. The method combines wav2vec2.0 for audio feature extraction and MarianMT for Bengali-to-English translation, using multimodal attention fusion to predict speech acts in a small Bengali speech corpus. BeAts significantly outperforms unimodal baselines using only speech data and simpler bimodal fusion methods. The approach demonstrates the effectiveness of combining audio and text modalities for low-resource language speech act classification.

## Method Summary
BeAts employs a multimodal fusion framework where wav2vec2.0 processes audio recordings and MarianMT translates Bengali text to English. The method uses either Optimal Transport Kernel (OTK) or multimodal transformer-based attention fusion to combine features from both modalities. The system is trained with a joint loss function incorporating audio, text, and fusion components. The approach handles the small dataset size through augmentation strategies that avoid spectral changes for audio and carefully preserve semantic meaning for translated text.

## Key Results
- Achieved 100% Precision and Recall across all three speech act classes (requests, questions, orders)
- Significantly outperformed unimodal baselines using only speech data
- Demonstrated superior performance compared to simpler bimodal fusion approaches

## Why This Works (Mechanism)
The multimodal attention fusion approach works by leveraging complementary information from both audio and text modalities. Audio features capture prosodic and acoustic cues that distinguish speech acts, while text translation preserves semantic content that may be ambiguous in audio alone. The fusion mechanism learns to weight and combine these complementary signals effectively, allowing the model to make more robust predictions than either modality alone.

## Foundational Learning
1. **Multimodal attention fusion**: Combining features from different modalities using attention mechanisms to leverage complementary information.
   - Why needed: Single modalities may miss important cues present in other modalities
   - Quick check: Verify that attention weights properly emphasize relevant features from each modality

2. **Optimal Transport Kernel in fusion**: Using optimal transport principles to align and combine features from different modalities.
   - Why needed: Provides a principled way to measure similarity between distributions from different modalities
   - Quick check: Confirm that OT distance between modalities decreases as model learns

3. **Low-resource language adaptation**: Applying multilingual models (wav2vec2.0, MarianMT) to languages with limited training data.
   - Why needed: Many languages lack large annotated datasets for supervised learning
   - Quick check: Test model performance with varying amounts of training data

## Architecture Onboarding

**Component Map**: Bengali Speech → wav2vec2.0 → Audio Features; Bengali Text → MarianMT → English Text → Text Features; Audio Features + Text Features → Multimodal Attention Fusion → Speech Act Classification

**Critical Path**: Data augmentation → wav2vec2.0 fine-tuning → MarianMT fine-tuning → Multimodal fusion → Classification

**Design Tradeoffs**: The approach trades computational complexity (multiple models and fusion layers) for improved accuracy by leveraging complementary information across modalities. This is particularly valuable for low-resource languages where data is scarce.

**Failure Signatures**: 
- Poor performance on one class may indicate modality imbalance or insufficient representation in that class
- Performance degradation with increased augmentation may suggest augmentation techniques are introducing noise
- Suboptimal fusion weights could indicate misalignment between modalities

## Limitations

- Relies on a very small dataset (85 utterances), raising questions about generalization and statistical significance
- Does not specify critical training hyperparameters (learning rate, batch size, optimizer settings, epochs)
- Specific augmentation techniques for audio and English text are not detailed
- Lacks ablation studies showing individual contributions of each component

## Confidence

- High confidence in general methodology approach (multimodal fusion using wav2vec2.0 and MarianMT is technically sound)
- Medium confidence in reported performance improvements given small dataset size and lack of detailed methodology
- Low confidence in reproducibility without additional implementation details and hyperparameter specifications
