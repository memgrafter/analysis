# Algebra Error Classification with Large Language Models

## Quick Facts
- arXiv ID: 2305.06163
- Source URL: https://arxiv.org/abs/2305.06163
- Reference count: 32
- Key outcome: BERT-based LLM error classification outperforms rule-based and tree-embedding methods on open-ended algebra responses

## Executive Summary
This paper introduces a novel approach to algebra error classification using large language models (LLMs) to identify student errors in open-ended math questions. The method addresses limitations of existing rule-based and tree-embedding approaches by handling responses regardless of syntactic validity and incorporating additional contextual information. The authors fine-tune pre-trained LLMs like BERT and GPT-2 for error classification, achieving state-of-the-art results with BERT outperforming existing methods. They also demonstrate that including student action context significantly improves classification accuracy. Qualitative analysis reveals that misclassifications often stem from ambiguous error labels rather than model performance. The proposed method offers a flexible, scalable solution for automated feedback in intelligent tutoring systems.

## Method Summary
The method fine-tunes pre-trained LLMs (BERT, GPT-2, MathBERT, XLM-RoBERTa) for algebra error classification using the CogTutor dataset containing student step-by-step responses to algebra questions. The models are trained for 30 epochs using cross-entropy loss with 4-fold cross-validation. Input consists of tokenized step history text with optional student action context. The classification head maps LLM outputs to 19 error classes. Domain adaptation using mathematical domain data is also explored.

## Key Results
- BERT achieves state-of-the-art performance, slightly improving upon leading baseline methods
- Incorporating student action context significantly improves classification accuracy across all models
- Misclassifications primarily stem from ambiguous error labels rather than model limitations

### Mechanism 1
- Claim: LLM-based error classification outperforms rule-based and tree-embedding methods on open-ended algebra responses.
- Mechanism: LLMs process raw text strings without requiring syntactic validity, enabling classification of invalid or incomplete mathematical expressions that rule-based and tree-embedding methods cannot handle.
- Core assumption: The input representation captures sufficient semantic information for the model to identify error types, even when expressions are malformed.
- Evidence anchors:
  - [abstract] "This method addresses limitations of existing rule-based and tree-embedding approaches by handling responses regardless of syntactic validity"

- Break condition: If the input representation loses critical mathematical semantics, or if the error types require deep symbolic reasoning beyond LLM capabilities.

### Mechanism 2
- Claim: Adding student action context significantly improves error classification accuracy.
- Mechanism: Incorporating ITS-recorded student interactions (e.g., selected operations) provides additional intent information that disambiguates between similar error types.
- Core assumption: The action information is reliably recorded and correlates with the student's actual reasoning process.
- Evidence anchors:
  - [abstract] "incorporating additional contextual information"
  - [section 3.4] "introducing action information improves the performance of all MLM models significantly"
  - [corpus] Weak - corpus papers discuss automated feedback but don't specifically address action context integration
- Break condition: If action logs are noisy, incomplete, or don't reflect student intent accurately.

### Mechanism 3
- Claim: Error classification performance is limited by ambiguity in error label definitions rather than model capability.
- Mechanism: Many misclassifications occur between semantically similar error types where human experts would also struggle to distinguish based on limited information.
- Core assumption: The true error class depends on unobservable student intent, making perfect classification impossible regardless of model performance.
- Evidence anchors:
  - [abstract] "qualitative analysis reveals that misclassifications often stem from ambiguous error labels rather than model performance"
  - [section 3.4] "REVERSED SIDES error is equivalent to a WRONG OPERATION error" depending on student's thought process
  - [corpus] Weak - corpus doesn't discuss error label ambiguity
- Break condition: If error labels are made more specific and mutually exclusive, or if additional context makes intent more observable.
