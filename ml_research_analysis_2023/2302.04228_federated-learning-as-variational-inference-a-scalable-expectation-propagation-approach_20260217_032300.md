# Federated Learning as Variational Inference: A Scalable Expectation Propagation Approach

## Quick Facts
- arXiv ID: 2302.04228
- Source URL: https://arxiv.org/abs/2302.04228
- Reference count: 40
- Primary result: FedEP achieves faster convergence and better accuracy than FedAvg and FedPA on CIFAR-100, StackOverFlow, and EMNIST-62 benchmarks

## Executive Summary
This paper introduces Federated Learning with Expectation Propagation (FedEP), a novel framework that reformulates federated learning as a distributed inference problem. By using variational inference to approximate the global posterior through iterative message-passing between clients and server, FedEP improves upon federated posterior averaging (FedPA) by incorporating the current global approximation during client inference. The authors address scalability challenges in modern federated settings through various algorithmic considerations including approximate inference techniques, adaptive optimization with damping, and stateless variants for memory-constrained environments.

## Method Summary
FedEP reformulates federated learning as a distributed inference problem where clients and server collaboratively approximate the global posterior using variational inference. The method employs a mean-field Gaussian variational family and iteratively refines local approximations through probabilistic message-passing. Key innovations include the incorporation of the current global approximation during client inference, approximate inference techniques (MCMC, Laplace approximation, natural gradient variational inference), and adaptive optimization with damping. The framework supports both stateful and stateless variants to handle different memory constraints, with the stateful version maintaining client-specific variational parameters across rounds and the stateless version reconstructing parameters on-demand.

## Key Results
- FedEP reaches 50% accuracy on CIFAR-100 in 461-1240 rounds versus 811+ rounds for FedPA
- Improved convergence speed and accuracy over strong baselines (FedAvg and FedPA)
- Better calibration in uncertainty quantification, particularly with scaled identity covariance approximation
- Effective performance across diverse benchmarks (CIFAR-100, StackOverFlow, EMNIST-62)

## Why This Works (Mechanism)
FedEP works by reformulating federated learning as a distributed inference problem, allowing clients and server to collaboratively approximate the global posterior through variational inference. The key mechanism is the iterative refinement of local approximations through message-passing, where clients incorporate the current global approximation during their local inference. This creates a more informed local posterior that better reflects the global data distribution. The damped updates and adaptive optimization stabilize the message-passing process, while the choice of approximate inference techniques (MCMC, Laplace, NGVI) provides flexibility in balancing computational cost and accuracy. The mean-field Gaussian variational family enables tractable computations while maintaining expressiveness.

## Architecture Onboarding
Component Map: Server -> Clients -> Server (iterative message-passing)
Critical Path: Server broadcasts global approximation → Clients perform local inference → Clients send messages to server → Server aggregates and updates global approximation → Repeat
Design Tradeoffs: Stateful clients maintain better performance but require more memory; Stateless clients reduce memory usage but may sacrifice some accuracy. Damping improves stability but may slow convergence. Approximate inference methods trade off computational cost versus accuracy.
Failure Signatures: Poor convergence in early rounds indicates damping issues or unstable cavity distribution calculations. Memory issues suggest switching to stateless variant. Divergence suggests learning rates are too high or damping is insufficient.
First Experiments: 1) Run FedEP on CIFAR-100 with scaled identity covariance to verify faster convergence than FedAvg, 2) Implement and test MCMC client inference procedure independently, 3) Compare stateful vs stateless variants on StackOverFlow to validate memory-accuracy tradeoff.

## Limitations
- Exact implementation details of MCMC-based client inference procedure remain unclear
- Limited hyperparameter exploration may affect generalizability across different federated learning scenarios
- Comparison with FedPA uses a specific version (NGVI) that may not represent the full capabilities of the baseline method
- The method's performance under extreme data heterogeneity or highly non-IID data distributions is not thoroughly explored
