# Parallel Sentence-Level Explanation Generation for Real-World Low-Resource Scenarios

## Quick Facts
- arXiv ID: 2302.10707
- Source URL: https://arxiv.org/abs/2302.10707
- Reference count: 0
- Key outcome: Non-autoregressive Transformer (C-NAT) achieves 10-15× faster inference while maintaining comparable performance to autoregressive models for parallel explanation generation in low-resource settings

## Executive Summary
This paper introduces C-NAT, a non-autoregressive Transformer model that generates sentence-level explanations in parallel with classification tasks. The method addresses the slow inference of autoregressive models by predicting all tokens simultaneously, achieving 10-15× speedup. The model handles low-resource scenarios through weakly-supervised learning using labeling functions and unsupervised learning via back-translation. Experiments on NLI and Spouse Prediction tasks demonstrate that C-NAT maintains comparable accuracy and explanation quality while dramatically reducing inference latency.

## Method Summary
The method proposes a non-autoregressive Transformer (C-NAT) architecture that enables parallel generation of sentence-level explanations alongside classification predictions. The model uses a fertility predictor to determine output length and a non-causal self-attention mask for full context access during parallel token prediction. For low-resource scenarios, the approach employs weakly-supervised learning by extracting labeling functions and templates from limited human annotations to generate pseudo data, and unsupervised learning using back-translation combined with pre-trained language model refinement. The model is evaluated on NLI and Spouse Prediction tasks, measuring both classification accuracy and explanation quality metrics.

## Key Results
- C-NAT achieves 10-15× faster inference compared to autoregressive models while maintaining comparable performance
- The model successfully handles low-resource scenarios using weakly-supervised and unsupervised learning approaches
- Experimental results show competitive performance on NLI (e-SNLI, SNLI) and Spouse Prediction tasks with limited or no annotated explanations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Non-autoregressive generation enables parallel token prediction, reducing inference latency by 10-15x compared to autoregressive models.
- Mechanism: By removing sequential dependency between tokens, the decoder predicts all tokens simultaneously using fertility predictor for output length and non-causal self-attention mask for full context access.
- Core assumption: Parallel token generation doesn't significantly degrade explanation quality compared to sequential generation.
- Evidence anchors: Abstract mentions parallel explanation generation; section describes adopting NAT architecture for parallel token generation.
- Break condition: Fertility predictor errors cause output length mismatches and malformed outputs.

### Mechanism 2
- Claim: Weakly-supervised learning using labeling functions and templates can generate pseudo data for training with limited human annotations.
- Mechanism: Extract labeling functions and templates from small human-annotated samples, apply to unlabeled data for pseudo labels/explanations using data programming.
- Core assumption: Extracted labeling functions and templates are sufficiently accurate and diverse for useful pseudo data.
- Evidence anchors: Abstract describes extracting labeling functions and templates; section details using them to produce pseudo labels.
- Break condition: Poor labeling function accuracy or coverage degrades pseudo data quality.

### Mechanism 3
- Claim: Unsupervised learning using back-translation and language model refinement can generate pseudo explanations without human annotations.
- Mechanism: Use pre-trained NMT model to back-translate input sequences as pseudo explanations, refine with pre-trained language model discriminator during training.
- Core assumption: Back-translated sequences serve as reasonable proxy explanations capturing semantic content needed for training.
- Evidence anchors: Abstract mentions utilizing back-translation mechanism; section describes generating pseudo explanations and refining with pre-trained LM.
- Break condition: Back-translation produces semantically distant explanations, leading to incorrect input-explanation mappings.

## Limitations

- Weakly-supervised learning effectiveness depends heavily on quality of extracted labeling functions, but paper lacks detailed analysis of labeling function accuracy and coverage
- Unsupervised learning via back-translation may produce semantically distant explanations, but paper doesn't thoroughly evaluate semantic drift across different datasets and domains
- Paper doesn't provide detailed ablation studies showing exactly where quality is lost compared to autoregressive baseline

## Confidence

- Parallel generation speedup claims: High confidence - supported by concrete timing measurements across multiple datasets
- Weakly-supervised learning effectiveness: Medium confidence - results show promise but lack detailed analysis of labeling function quality
- Unsupervised learning via back-translation: Medium confidence - mechanism is plausible but potential semantic drift not thoroughly evaluated
