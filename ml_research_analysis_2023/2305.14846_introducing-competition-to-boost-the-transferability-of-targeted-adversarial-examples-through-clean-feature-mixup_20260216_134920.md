# Introducing Competition to Boost the Transferability of Targeted Adversarial Examples through Clean Feature Mixup

## Quick Facts
- arXiv ID: 2305.14846
- Source URL: https://arxiv.org/abs/2305.14846
- Authors: 
- Reference count: 40
- Primary result: Introduces Clean Feature Mixup (CFM) method that improves targeted adversarial attack transferability by introducing competition through feature-space mixing

## Executive Summary
This paper addresses the challenge of improving the transferability of targeted adversarial examples in deep learning models. The authors propose introducing competition into the optimization process by incorporating two types of competitor noises: adversarial perturbations towards different target classes and friendly perturbations towards the correct class. To efficiently simulate these competitors, they introduce the Clean Feature Mixup (CFM) method, which randomly mixes stored clean features with input features in feature space. The proposed method is evaluated on ImageNet-Compatible and CIFAR-10 datasets, demonstrating significant improvements in targeted attack success rates compared to existing baselines.

## Method Summary
The Clean Feature Mixup (CFM) method attaches CFM modules to convolution and fully-connected layers of a pre-trained source model. These modules store clean features by passing clean images through the model, then during adversarial optimization, randomly mix these stored clean features with input features via linear interpolation. The mixing occurs stochastically at random layers with probability p and uses random channel-wise mixing ratios. This creates competition during optimization by forcing the adversarial example to overcome interference from both clean features (guiding predictions toward true class) and other images' features (simulating targeted attacks on different classes). The method is compatible with various attack techniques and evaluated on both ImageNet-Compatible and CIFAR-10 datasets.

## Key Results
- CFM significantly improves targeted attack success rates compared to existing baselines on both ImageNet-Compatible and CIFAR-10 datasets
- The method demonstrates compatibility with various attack techniques including iterative FGSM with momentum and translation invariance
- Computational efficiency is maintained despite the additional feature mixing operations, making it practical for real-world applications

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Competition from multiple perturbation types forces adversarial examples to leverage more diverse features, improving transferability
- Mechanism: By introducing competitor noises (adversarial perturbations toward different target classes and friendly perturbations toward the correct class), the optimization process prevents the adversarial example from overfitting to a narrow set of features identified early in the source model. This forces exploration of alternative feature combinations that are more likely to be present across different models.
- Core assumption: Decision boundaries vary significantly between models, so adversarial examples optimized on a single source model will fail if they rely on features that are not robust across models.
- Evidence anchors:
  - [abstract]: "With these competitors, even if an adversarial example deceives a network to extract specific features leading to the target class, this disturbance can be suppressed by other competitors."
  - [section]: "Consequently, adversarial perturbations should take various attack strategies, leveraging a wider range of features to overcome interference, which enhances their transferability to different models."

### Mechanism 2
- Claim: Clean Feature Mixup efficiently simulates the competitor noises in feature space without requiring additional backward passes
- Mechanism: CFM modules randomly mix stored clean features with input features at each inference. When an image's own clean features are mixed in, this suppresses the feature disturbance caused by the current targeted adversarial perturbations and guides the model's prediction back toward the true class. When clean features of another image are mixed in, this introduces the effect of targeted attacks on a different target class, forcing the adversarial example to succeed despite competing targeted attacks.
- Core assumption: Mixing features in the feature space can effectively simulate the presence of competing perturbations without the computational cost of actually optimizing multiple perturbations simultaneously.
- Evidence anchors:
  - [section]: "we efficiently mimic the behaviors of the two types of perturbations in feature space by mixing stored clean features of the images within a batch."
  - [section]: "it mixes the layers' outputs (i.e., features) with the stored clean features via linear interpolation."

### Mechanism 3
- Claim: Stochastic application of feature mixup at random layers prevents overfitting to specific feature patterns
- Mechanism: Each CFM module stochastically applies the clean feature mixup with a probability p, and the mixing ratio is randomly sampled for each channel. This causes the influence of competitors to occur at random layers of the network and vary arbitrarily across channels, enabling more diverse interference patterns.
- Core assumption: Randomization in the application of competition prevents the adversarial example from adapting to a specific interference pattern, forcing it to develop more robust attack strategies.
- Evidence anchors:
  - [section]: "To address this issue, each CFM module stochastically applies the clean feature mixup with a probability p."
  - [section]: "the mixing ratio is randomly sampled for each channel. This allows the effects of competitor noises to vary arbitrarily across channels, enabling more diverse interference."

## Architecture Onboarding

- Component map:
  - Source model (pre-trained network) -> CFM modules (attached to conv and fc layers) -> Attack optimization loop (iterative FGSM with various enhancements) -> Storage for clean features (batch-wise)

- Critical path:
  1. Convert pre-trained source model by attaching CFM modules to selected conv and all fc layers
  2. Store clean features by passing clean images through the CFM-attached model
  3. For each optimization iteration:
     - Apply input transforms (RDI, etc.)
     - Compute gradients through CFM-attached model (with random feature mixing)
     - Update adversarial example using momentum and translation invariance
     - Clip to maintain ℓ∞ constraint

- Design tradeoffs:
  - Mixing probability p vs. attack success rate: Higher p increases competition but may make optimization harder
  - Channel-wise mixing ratio range vs. interference diversity: Wider range enables more diverse interference but may destabilize optimization
  - Layer selection for CFM attachment vs. computational cost: Attaching to more layers increases effectiveness but also computational overhead
  - Batch size vs. diversity of clean features: Larger batches provide more diverse clean features for mixing but increase memory requirements

- Failure signatures:
  - If adversarial examples show low success rates but high visual similarity to clean images: CFM mixing may be too aggressive
  - If adversarial examples show high success rates on source model but low transferability: CFM may not be forcing enough feature diversity
  - If optimization fails to converge: Stochastic mixing parameters (p, αmax) may be set too high
  - If computational cost is prohibitive: Too many layers may have CFM modules attached or batch size may be too large

- First 3 experiments:
  1. Implement basic CFM-RDI on a simple dataset (CIFAR-10) with a single source model (RN-18) and compare against RDI baseline on transferability to RN-50
  2. Vary mixing probability p (0.05, 0.1, 0.25) and observe impact on attack success rate and optimization stability
  3. Implement ablation study by disabling each CFM component (clean feature storage, stochastic mixing, channel-wise mixing ratio) and measure degradation in performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the precise relationship between the diversity of features leveraged by adversarial examples and their transferability across different architectures?
- Basis in paper: [explicit] The paper hypothesizes that using diverse feature combinations improves transferability but doesn't empirically quantify this relationship.
- Why unresolved: The paper demonstrates improved transferability with CFM but doesn't isolate the effect of feature diversity from other factors like gradient stability.
- What evidence would resolve it: Experiments varying the degree of feature diversity while holding other factors constant, measuring correlation between feature diversity metrics and transferability success rates.

### Open Question 2
- Question: How does CFM's performance scale with increasingly complex and diverse target model architectures, particularly those using non-standard feature representations?
- Basis in paper: [inferred] The paper tests against standard architectures but doesn't explore extreme architectural variations or non-convolutional models.
- Why unresolved: Current experiments focus on conventional CNN and Transformer architectures; edge cases might reveal limitations.
- What evidence would resolve it: Testing CFM against unconventional architectures like graph neural networks, capsule networks, or models with novel attention mechanisms.

### Open Question 3
- Question: What is the theoretical limit of transferability improvement achievable through feature-space perturbations versus image-space perturbations?
- Basis in paper: [explicit] The paper introduces feature-space mixing but doesn't compare theoretical bounds with image-space approaches.
- Why unresolved: The paper shows practical improvements but doesn't establish whether feature-space methods approach fundamental limits of transferability.
- What evidence would resolve it: Theoretical analysis comparing information-theoretic bounds of feature-space versus image-space adversarial perturbations, combined with empirical measurements at scale.

## Limitations
- The CFM method relies on storing clean features which may not scale well to very large datasets or models with extremely high-dimensional feature spaces
- The stochastic nature of feature mixing could lead to inconsistent optimization behavior across different runs
- While effective on standard computer vision benchmarks, the approach's generalizability to other domains (e.g., NLP, audio) remains unexplored
