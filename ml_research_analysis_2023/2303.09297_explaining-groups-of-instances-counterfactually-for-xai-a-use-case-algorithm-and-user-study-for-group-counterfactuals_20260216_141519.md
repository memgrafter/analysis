# Explaining Groups of Instances Counterfactually for XAI: A Use Case, Algorithm and User Study for Group-Counterfactuals

## Quick Facts
- arXiv ID: 2303.09297
- Source URL: https://arxiv.org/abs/2303.09297
- Authors: 
- Reference count: 40
- Key outcome: Group counterfactual explanations improved user prediction accuracy from 81.6% to 83.2% in a user study (N=207), with higher confidence, satisfaction, and trust compared to single counterfactuals.

## Executive Summary
This paper addresses a novel use case in XAI where multiple similar instances need to be explained collectively using a common counterfactual explanation. The authors propose a new algorithm, Group-CF, that identifies key features from individual counterfactuals, samples valid feature values from contrasting class instances, and selects the best group counterfactual based on coverage maximization. They evaluate this approach in a user study comparing it to single counterfactuals, finding that group counterfactuals with hints led to modest but significant improvements in user prediction accuracy, confidence, explanation satisfaction, and trust.

## Method Summary
The method involves training a Gradient Boosting Classifier on the Adult (Census) dataset for a binary income prediction task. The Group-CF algorithm first generates individual counterfactuals for a pool of related instances using DiCE, identifies key features by majority voting, samples feature values from instances in the contrasting class, generates candidate group counterfactuals by substitution, and selects the best explanation based on coverage maximization. A user study with 207 participants compared three conditions: CF-Single (individual counterfactuals), CF-Group (group counterfactuals), and CF-Group-Hint (group counterfactuals with highlighted feature changes).

## Key Results
- Group counterfactuals with hints improved user prediction accuracy from 81.6% to 83.2% compared to single counterfactuals
- Participants reported higher confidence, explanation satisfaction, and trust in group counterfactual explanations
- Presenting grouped explanations in sequence without interruption improved understanding and accuracy
- The Group-CF algorithm successfully generated coherent explanations covering multiple similar instances

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Group counterfactual explanations improve understanding by reducing cognitive load through coherent, repeated feature differences.
- Mechanism: When users encounter multiple similar instances, presenting a single counterfactual explanation that applies to all instances reduces the number of distinct explanations they must process and remember. This coherence allows users to form a unified mental model of the decision boundary.
- Core assumption: Users benefit from pattern recognition and coherence in explanations when dealing with multiple similar instances.
- Evidence anchors:
  - [abstract] "These group counterfactuals meet a human preference for coherent, broad explanations covering multiple events/instances."
  - [section 1.1] "Presenting users with these related counterfactuals for several predictive-instances rather than different counterfactuals for each instance may also have psychological advantages, as it should reduce memory load and facilitate pattern-finding"
  - [corpus] Weak evidence - no direct citations on group counterfactuals specifically, though related work on "cohesive explanations" exists
- Break condition: If instances are not sufficiently similar or the group counterfactual doesn't accurately capture the common pattern, users may become confused or misled.

### Mechanism 2
- Claim: The Group-CF algorithm improves explanation quality by sampling from valid data points in the contrasting class.
- Mechanism: Instead of generating synthetic counterfactuals that may be invalid, the algorithm samples actual data points from the contrasting class that share key features with the original instances. This ensures the counterfactual feature values are realistic and actionable.
- Core assumption: Valid data points from the contrasting class provide more realistic and actionable counterfactuals than purely synthetic ones.
- Evidence anchors:
  - [section 2.2] "These sampled instances are known to be valid data points, and therefore are more likely to yield feature-value transformations that result in valid counterfactuals"
  - [section 2] The algorithm explicitly samples feature values from instances in the contrasting class rather than generating synthetic values
  - [corpus] Weak evidence - while the sampling approach is novel, there's limited corpus evidence on validity of counterfactuals from contrasting class sampling
- Break condition: If the contrasting class lacks sufficiently similar instances, the sampling may produce unrealistic or unhelpful counterfactuals.

### Mechanism 3
- Claim: The ordering of grouped explanations affects user comprehension and accuracy.
- Mechanism: When group counterfactual explanations are presented in sequence without interruption, users can better recognize patterns and build mental models. When explanations are interspersed with unrelated items, this learning effect is diminished.
- Core assumption: Continuous exposure to related explanations enhances pattern recognition more than interrupted or scattered exposure.
- Evidence anchors:
  - [section 4.1] "Spearman's correlations were computed between these gap-scores for item-sets in the training phase and the accuracy observed in that phase. This analysis showed that there were negative correlations between gap-scores and accuracy in all three conditions"
  - [section 4.1] "This finding suggests that XAI systems should present instances that are counterfactually-grouped in an unbroken sequence, to allow end-users to benefit from this ordering effect"
  - [corpus] Weak evidence - no direct corpus citations on explanation ordering, though general principles about learning sequences exist
- Break condition: If users have sufficient prior knowledge or the patterns are obvious enough, ordering effects may be minimal.

## Architecture Onboarding

- Component map: The system consists of three main components: (1) the black-box classifier that makes predictions, (2) the Group-CF algorithm that generates group counterfactual explanations, and (3) the user interface that presents instances and explanations to users. The classifier and Group-CF algorithm are decoupled, allowing different models or explanation methods to be swapped in.
- Critical path: The critical path is: input instances → find nearest neighbors → generate individual counterfactuals → identify key features → sample contrasting class instances → generate candidate group counterfactuals → select best explanation → present to user. The most computationally intensive step is typically generating individual counterfactuals for each instance in the pool.
- Design tradeoffs: The algorithm trades computational efficiency for explanation quality. Finding nearest neighbors and generating individual counterfactuals for each instance is more expensive than generating a single explanation, but produces more coherent results. The sampling approach from the contrasting class trades some exploration of the counterfactual space for validity and actionability.
- Failure signatures: The algorithm may fail when: (1) nearest neighbors are not sufficiently similar, making group counterfactuals less coherent, (2) the contrasting class lacks relevant samples, producing unrealistic counterfactuals, or (3) the black-box model is too complex or non-differentiable for reliable counterfactual generation. User studies may fail if participants don't engage with the task or if ceiling effects prevent detecting differences.
- First 3 experiments:
  1. Verify the nearest neighbor selection by visualizing the pool of instances and checking similarity metrics.
  2. Test the individual counterfactual generation on a small subset of instances to ensure feature differences are meaningful and actionable.
  3. Validate the sampling from the contrasting class by checking that sampled feature values produce realistic and valid counterfactuals before running the full Group-CF algorithm.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal sequence length for presenting group counterfactual explanations to maximize user understanding and accuracy?
- Basis in paper: [explicit] The paper found that accuracy was negatively correlated with gap-scores between items in the same set, suggesting that presenting grouped counterfactuals in unbroken sequences improved understanding.
- Why unresolved: The paper only tested one sequence length (presenting all 5 items together) and did not systematically vary the sequence length to find an optimal value.
- What evidence would resolve it: User studies comparing different sequence lengths (e.g., presenting 2, 3, 4, or 5 items together) while measuring accuracy, confidence, and satisfaction scores.

### Open Question 2
- Question: How do group counterfactual explanations perform compared to other explanation types (e.g., feature importance, example-based explanations) in multi-instance scenarios?
- Basis in paper: [inferred] The paper only compared group counterfactuals to single counterfactuals, leaving open the question of how they compare to other established explanation methods in group scenarios.
- Why unresolved: The user study only evaluated group counterfactuals against single counterfactuals, not against alternative explanation strategies.
- What evidence would resolve it: User studies comparing group counterfactuals against other explanation types (e.g., feature importance scores, prototypical examples, or rule-based explanations) in multi-instance scenarios.

### Open Question 3
- Question: How do group counterfactual explanations affect user understanding and trust in real-world applications beyond the Adult dataset?
- Basis in paper: [explicit] The paper used the Adult dataset as a proxy for domains where group counterfactuals might be useful, but acknowledged that stronger effects might be found in domains with less expertise or more complex feature interactions.
- Why unresolved: The user study used a proxy dataset rather than testing in actual domain-specific applications like the dairy farming use case that motivated the work.
- What evidence would resolve it: Field studies or user studies in actual applications (e.g., medical diagnosis, industrial maintenance) where users must interpret predictions for multiple similar instances.

## Limitations
- Ceiling effects in user study accuracy limited observable improvements from explanations
- Potential order effects from presenting grouped instances in sequence may have artificially inflated accuracy
- Specific context of multi-instance prediction scenarios may not generalize to all XAI applications
- The Group-CF algorithm's sampling approach lacks extensive validation beyond the user study
