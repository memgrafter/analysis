# Tracing and Manipulating Intermediate Values in Neural Math Problem Solvers

## Quick Facts
- arXiv ID: 2301.06758
- Source URL: https://arxiv.org/abs/2301.06758
- Reference count: 5
- Key outcome: This paper presents a method for analyzing how Transformer models process complex inputs requiring multiple inference steps, focusing on intermediate values in arithmetic problems.

## Executive Summary
This paper introduces a method for analyzing how Transformer models process intermediate values in arithmetic problems by tracing correlations between intermediate values and model activations using PCA, then performing causal interventions by manipulating model weights. The authors demonstrate that certain directions in activation space are highly correlated with intermediate values, and manipulating weights along these directions causes predictable changes in model predictions. This establishes a causal relationship rather than mere correlation, providing insights into model interpretability. The method achieves strong correlations (up to 0.986) between predicted and actual activation changes when manipulating intermediate values.

## Method Summary
The method involves training a 6-layer Transformer on synthetic arithmetic equations, then applying PCA to layer activations to identify principal components that correlate with intermediate values. The authors measure correlations between these components and intermediate values, then manipulate weights along the most-correlated directions to test for causal relationships. They validate their findings by comparing predicted activation changes (based on intermediate values) with actual changes under different inputs, demonstrating that the identified directions are causally related to model predictions rather than merely correlated.

## Key Results
- PCA identifies principal component directions in activation space that are highly correlated with intermediate values in arithmetic equations
- Manipulating weights along these directions causes predictable changes in model predictions, establishing causal relationships
- Strong correlations (up to 0.986) between predicted and actual activation changes when manipulating intermediate values
- The method demonstrates that intermediate values are encoded in specific directions within the activation space of the Transformer model

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Principal component directions in activation space can be highly correlated with intermediate values in arithmetic equations.
- Mechanism: PCA reduces the dimensionality of layer activations and identifies principal components that capture the most variance. When intermediate values are encoded in these components, their magnitudes correlate strongly with the intermediate values.
- Core assumption: Intermediate values in arithmetic equations are encoded in specific directions within the activation space of the Transformer model.
- Evidence anchors:
  - [abstract] "First, we search which directions of internal representations are highly correlated with intermediate values in equations by PCA (tracing) to find where the information about intermediate values is encoded."
  - [section] "To trace where information about intermediate values is encoded, we measure the correlation between intermediate values and the activations of the model using principal component analysis (PCA)."
  - [corpus] Weak evidence - corpus neighbors discuss math word problem solvers but don't specifically address PCA-based correlation analysis.
- Break condition: If intermediate values are distributed across multiple components or encoded in non-linear combinations, the correlation would be weak or non-existent.

### Mechanism 2
- Claim: Manipulating weights along correlated principal component directions causes predictable changes in model predictions.
- Mechanism: By increasing or decreasing the projection of layer representations onto principal components, the model's output can be systematically altered. This manipulation allows testing whether the correlation represents causation rather than mere association.
- Core assumption: The directions identified through correlation are causally related to model predictions, not just correlated by chance.
- Evidence anchors:
  - [abstract] "Second, we observe how the model prediction changed when we manipulate the weights along its direction (manipulation) to conduct a causal intervention."
  - [section] "To test if the directions we found actually influence model predictions, we perform causal interventions by manipulating activations."
  - [corpus] Weak evidence - corpus neighbors focus on math problem solving but don't address causal manipulation of model representations.
- Break condition: If the manipulation causes unpredictable or random changes in predictions, the correlation is not causal.

### Mechanism 3
- Claim: The method achieves strong correlations (up to 0.986) between predicted and actual activation changes when manipulating intermediate values.
- Mechanism: By fitting a function from intermediate values to manipulation factors, the method can predict how activations should change. Comparing these predictions to actual changes under different inputs validates the causal relationship.
- Core assumption: The relationship between intermediate values and activation changes is stable and predictable across different inputs.
- Evidence anchors:
  - [abstract] "Their results show that certain directions in activation space are highly correlated with intermediate values, and manipulating weights along these directions causes predictable changes in model predictions."
  - [section] "Predicted and the actual weights of the most-correlated direction agree well (corr. 0.986, R2 score 0.687)."
  - [corpus] Weak evidence - corpus neighbors don't discuss correlation strengths between predicted and actual activation changes.
- Break condition: If the correlation between predicted and actual changes drops significantly for different input types, the method's generalizability is limited.

## Architecture Onboarding

- Component map: Input equations with intermediate values -> 6-layer Transformer with tokenization into digits -> PCA on layer activations to identify principal components -> Correlation measurement between components and intermediate values -> Weight manipulation along correlated directions -> Prediction change observation

- Critical path:
  1. Train Transformer model on arithmetic equations
  2. Apply PCA to layer activations for each equation
  3. Measure correlation between principal component weights and intermediate values
  4. Manipulate activations along most-correlated directions
  5. Observe and measure changes in model predictions
  6. Fit function from intermediate values to manipulation factors
  7. Validate predictions by comparing to actual activation changes

- Design tradeoffs:
  - Using simple arithmetic problems limits generalizability but provides clear intermediate values for analysis
  - PCA dimensionality reduction (top 10 components) balances computational efficiency with capturing relevant variance
  - Linear manipulation of activations assumes linearity in the relationship between directions and predictions

- Failure signatures:
  - Low correlation between principal component weights and intermediate values suggests intermediate values are not encoded in those directions
  - Unpredictable changes in predictions when manipulating activations indicate correlation without causation
  - Poor agreement between predicted and actual activation changes suggests the relationship is not stable across inputs

- First 3 experiments:
  1. Train the 6-layer Transformer on 200k synthetic equations and verify high R2 score (0.9988) on test set
  2. Apply PCA to layer activations and identify principal components with highest correlation to intermediate values
  3. Manipulate activations along most-correlated directions and measure changes in model predictions to establish causation

## Limitations
- The methodology relies heavily on linear correlation analysis through PCA, which may not capture non-linear relationships between intermediate values and activations.
- The use of synthetic arithmetic problems with only addition and subtraction operations limits generalizability to more complex mathematical reasoning tasks.
- The paper doesn't address potential confounds such as the model's internal representation of numbers beyond the intermediate values of interest.

## Confidence
- High confidence: The correlation analysis between principal components and intermediate values is methodologically sound and well-supported by evidence.
- Medium confidence: The causal interpretation of weight manipulation effects requires further validation across diverse problem types.
- Low confidence: The generalizability of findings to non-synthetic, real-world mathematical problems remains untested.
