# Experience-Based Evolutionary Algorithms for Expensive Optimization

## Quick Facts
- arXiv ID: 2304.04166
- Source URL: https://arxiv.org/abs/2304.04166
- Authors: Multiple authors
- Reference count: 40
- One-line primary result: Proposes an experience-based surrogate-assisted evolutionary algorithm framework using meta-learning to enhance optimization efficiency for expensive optimization problems

## Executive Summary
This paper introduces an experience-based surrogate-assisted evolutionary algorithm (SAEA) framework designed to tackle expensive optimization problems more efficiently. The key innovation lies in leveraging experiences from related optimization tasks through meta-learning to enhance the performance of surrogate models. By learning task-independent parameters across related problems, the framework can initialize and adapt task-specific surrogate models using minimal information from the target problem (as few as 1D solutions in high-dimensional spaces). The approach demonstrates competitive or superior performance compared to state-of-the-art SAEAs while significantly reducing evaluation budgets on both multi-objective and constrained optimization problems.

## Method Summary
The proposed framework employs a meta deep kernel learning (MDKL) method to extract knowledge from related optimization tasks. This meta-learning component learns task-independent parameters that can be transferred to initialize and adapt task-specific surrogate models for the target problem. The approach uses these learned parameters to create competitive regression-based surrogates with minimal data from the new task, requiring only 1D solutions regardless of the decision space dimensionality. This meta-learning framework is integrated within a surrogate-assisted evolutionary algorithm, where the enhanced surrogate guides the search process more effectively than traditional approaches that must build surrogates from scratch for each new problem.

## Key Results
- The experience-based approach significantly reduces evaluation budgets needed on target problems while maintaining competitive optimization quality
- The framework achieves comparable or better results than state-of-the-art SAEAs on expensive multi-objective and constrained optimization problems
- Meta-learning from related tasks enables effective surrogate initialization using minimal data (1D solutions) from the target problem

## Why This Works (Mechanism)
The framework works by transferring knowledge across related optimization tasks through meta-learning. The MDKL component learns universal patterns and parameters that generalize across similar problems, which can then be adapted to specific target problems with minimal additional data. This cross-task knowledge transfer allows the surrogate model to start with a strong prior, reducing the need for extensive evaluations on the new problem. The meta-learned parameters provide a better initialization point for the surrogate, leading to faster convergence and improved optimization quality compared to building surrogates from scratch.

## Architecture Onboarding

Component map: MDKL -> Surrogate Model -> Evolutionary Algorithm -> Evaluation -> Fitness Assessment

Critical path: MDKL learning from related tasks → Surrogate model initialization → Evolutionary search → Solution evaluation → Fitness assessment → Next generation

Design tradeoffs:
- Balance between meta-learning complexity and computational overhead
- Tradeoff between the number of related tasks used for meta-learning and generalization capability
- Choice between model complexity for accurate surrogates versus speed of evaluation
- Selection of which task characteristics define "related" tasks for meta-learning

Failure signatures:
- Poor performance on target problems indicates insufficient or irrelevant related tasks for meta-learning
- High computational overhead suggests the MDKL component is too complex for the problem dimensionality
- Convergence to suboptimal solutions may indicate inadequate surrogate accuracy or inappropriate evolutionary parameters
- Instability in results across runs suggests sensitivity to initialization or insufficient diversity maintenance

Three first experiments:
1. Test the framework on a simple benchmark problem with known related tasks to verify the meta-learning component functions as expected
2. Compare performance using different numbers of related tasks to identify the optimal amount of meta-knowledge for transfer
3. Evaluate the impact of using 1D versus higher-dimensional initialization data on optimization quality and convergence speed

## Limitations
- Generalizability across diverse optimization landscapes remains uncertain, particularly for problems with significantly different characteristics from training tasks
- Reliance on related tasks for meta-learning may limit applicability when such tasks are unavailable or poorly correlated with the target problem
- Computational overhead of the meta-deep kernel learning component, especially for high-dimensional problems, is not thoroughly addressed
- Statistical significance of performance improvements across different problem instances could be more rigorously established

## Confidence
- High: The core concept of leveraging experiences from related tasks is sound and well-implemented
- Medium: The effectiveness of the MDKL approach for task-independent parameter learning
- Medium: The competitive performance claims compared to state-of-the-art SAEAs

## Next Checks
1. Test the framework's performance on a broader range of optimization problems, including those with different characteristics from the training set
2. Conduct ablation studies to quantify the contribution of the meta-learning component versus the base SAEA
3. Analyze the computational overhead and scalability of the MDKL approach for high-dimensional problems (d > 10)
