# Poor Man's Quality Estimation: Predicting Reference-Based MT Metrics Without the Reference

## Quick Facts
- arXiv ID: 2301.09008
- Source URL: https://arxiv.org/abs/2301.09008
- Reference count: 40
- Primary result: BiLSTM model achieves ρ=60.4% BLEU correlation and ρ=51.3% for other metrics in predicting reference-based MT metrics without references

## Executive Summary
This paper introduces metric estimation (ME), a novel task that predicts automated reference-based MT metrics without access to the reference translation. The authors propose a BiLSTM-based model that takes source and hypothesis texts as input, along with decoder confidence and hypothesis variance features extracted from the MT system. Experiments show the model can reliably predict BLEU scores with 60.4% correlation at the sentence level, and that pre-training on TER improves quality estimation performance compared to training from scratch. The approach generalizes across different MT systems with only a 2-3% performance drop.

## Method Summary
The authors propose a BiLSTM-based regression model for metric estimation that takes source and hypothesis texts as input, along with decoder confidence and hypothesis variance features extracted from the MT system. The model is trained to predict automated metric scores (BLEU, TER, etc.) using MSE loss on large parallel corpora. For quality estimation, the model can be pre-trained on metric estimation and then fine-tuned on human-annotated data, or used directly as a glassbox metric estimator. The approach leverages the correlation between automated metrics and human judgements, learning rich representations from large parallel data before transferring to the quality estimation task.

## Key Results
- The BiLSTM model achieves ρ=60.4% correlation for BLEU and ρ=51.3% for other metrics at sentence level
- Pre-training on TER improves quality estimation performance (ρ=23%) compared to training from scratch (ρ=20%)
- The model generalizes across different MT systems with only a 2-3% performance drop
- Using ME for pre-training QE does not outperform COMET-QE, the current state-of-the-art

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Metric estimation (ME) can predict automated MT metrics without access to reference by learning the correlation between source-hypothesis features and metric scores.
- Mechanism: The BiLSTM model extracts contextual representations from source and hypothesis texts, combines them with decoder confidence and hypothesis variance features, and learns to regress to metric scores through training on large parallel corpora.
- Core assumption: Automated metrics (BLEU, TER, etc.) correlate with human judgements, so learning to predict them provides useful signal for quality estimation.
- Evidence anchors:
  - [abstract] shows ρ=60.4% for BLEU and ρ=51.3% for other metrics at sentence level
  - [section] states "Because automated metrics correlate with human judgement, we can start by estimating fMETRIC and only later fine-tune to fHUMAN"
- Break condition: If automated metrics stop correlating with human judgements, or if the hypothesis space features become uninformative for metric prediction.

### Mechanism 2
- Claim: Pre-training on metric estimation improves quality estimation performance compared to training from scratch.
- Mechanism: The model first learns rich representations for predicting automated metrics from large parallel data, then fine-tunes these representations on smaller human-annotated quality estimation data.
- Core assumption: The learned representations from metric estimation transfer beneficially to the quality estimation task.
- Evidence anchors:
  - [abstract] shows "pre-training on TER is better (ρ=23%) than training from scratch (ρ=20%)"
  - [section] demonstrates "fine-tuning definitely improved the performance over zero-shot"
- Break condition: If the domain or MT system used for pre-training differs significantly from the target domain/system, transfer may fail.

### Mechanism 3
- Claim: Metric estimation models generalize across different MT systems with minimal performance degradation.
- Mechanism: The model learns to predict metrics based on source-hypothesis relationships and decoder features that are relatively consistent across MT systems, rather than overfitting to specific system errors.
- Core assumption: The features used (source/target lengths, decoder confidence, hypothesis variance) capture metric-relevant patterns that are system-agnostic.
- Evidence anchors:
  - [section] shows "for most systems, the drop was ~2-3%, which means that the metric estimator generalizes well across MT systems"
  - [corpus] evidence is weak as it only mentions related papers without specific generalization results
- Break condition: When transferring to MT systems with fundamentally different architectures or decoding strategies (e.g., prompted T5 LM vs. standard NMT).

## Foundational Learning

- Concept: Pearson correlation coefficient
  - Why needed here: Used to evaluate model performance by measuring linear correlation between predicted and target metric scores
  - Quick check question: If predicted scores are perfectly linearly related to target scores but with different scale, what would the Pearson correlation be?

- Concept: Byte-Pair Encoding (BPE)
  - Why needed here: Used to tokenize input texts for the BiLSTM model, handling rare words and morphological variations
  - Quick check question: What happens to the vocabulary size when applying BPE with 8192 merge operations to a corpus with many rare words?

- Concept: Mean Squared Error (MSE) loss
  - Why needed here: The regression loss function used to train the metric estimation model by minimizing squared differences between predictions and target metric scores
  - Quick check question: Why might MSE be preferred over Mean Absolute Error for this regression task?

## Architecture Onboarding

- Component map: Input BPE tokenizer → BiLSTM encoder → Feature concatenation (text + MT features) → Feed-forward regression head → Single numeric output
- Critical path: Text preprocessing → BiLSTM encoding → Feature fusion → Regression prediction
- Design tradeoffs: BiLSTM chosen for simplicity and effectiveness vs. more complex architectures like Transformers; glassbox vs. blackbox access to MT features
- Failure signatures: Poor correlation with metrics (ρ < 30%), overfitting to training MT system, sensitivity to input length
- First 3 experiments:
  1. Train ME model on WMT14 En→De data to predict BLEU scores, evaluate on held-out set
  2. Test generalization by applying trained model to WMT16 Conv outputs, measure performance drop
  3. Pre-train on TER scores, fine-tune on WMT21 QE data, compare to training from scratch on QE data

## Limitations
- The approach relies on having access to blackbox features from the MT system (decoder confidence, hypothesis variance), which may not be available for all MT systems
- Performance gains from pre-training on TER (ρ=23% vs 20%) are modest and still below state-of-the-art COMET-QE
- Generalization results across MT systems show only modest performance drops (2-3%), but these were tested on relatively similar systems

## Confidence
- Core mechanism of learning metric prediction from source-hypothesis pairs: High confidence
- Pre-training on TER improves QE performance: Medium confidence (modest absolute gains, still below state-of-the-art)
- Generalization across MT systems: Medium confidence (tested on similar systems, not fundamentally different architectures)

## Next Checks
1. Test the metric estimation model on MT systems with different architectures (e.g., prompted T5 vs standard NMT) to verify generalization claims hold for more divergent systems.
2. Conduct human evaluation studies to verify whether metric estimation predictions correlate with human quality judgements, not just automated metrics.
3. Evaluate the model on low-resource language pairs to determine if the approach scales beyond high-resource settings like English-German.
