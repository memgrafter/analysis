# Psychologically-Inspired Causal Prompts
## Quick Facts
- arXiv ID: 2305.01764
- Source URL: https://arxiv.org/abs/2305.01764
- Reference count: 37
- Primary result: Psychologically-inspired causal prompts reveal varying model uncertainty and annotation agreement in sentiment classification tasks

## Executive Summary
This paper introduces a novel framework for sentiment classification prompts that reflect different psychological causal structures. The authors propose three prompt types: C1 where sentiment causes review (explicit opinion), C2 where review causes sentiment (inference), and C3 where annotators use theory of mind to infer sentiment. Using GPT3-Instruct on Yelp and Amazon review datasets, they demonstrate that while performance remains comparable across prompts, the entropy of predictions varies significantly, with non-C1 prompts showing higher uncertainty. The analysis reveals that reviews containing explicit opinions yield higher agreement across prompt types, while ambiguous reviews lead to diverse predictions, suggesting that sentiment classification datasets contain nuanced text where underlying psychological processes significantly affect model behavior.

## Method Summary
The authors designed three psychologically-inspired prompt structures for sentiment classification. C1 prompts frame the task as sentiment causing review (explicit opinion scenarios), C2 prompts reverse this causality with review causing sentiment (inference scenarios), and C3 prompts incorporate theory of mind reasoning where annotators must infer sentiment. These prompts were systematically applied to GPT3-Instruct models using Yelp and Amazon review datasets. The experiments measured prediction performance, entropy (uncertainty), and inter-prompt agreement across different review types. Additional analysis examined how review content characteristics (explicit vs. implicit opinions) influenced these metrics across the different psychological prompt frameworks.

## Key Results
- Entropy measurements show higher uncertainty for non-C1 prompts compared to C1 prompts
- Explicit opinion reviews demonstrate higher inter-prompt agreement across all prompt types
- Performance metrics remain comparable across all three prompt types despite differences in prediction certainty

## Why This Works (Mechanism)
The effectiveness of psychologically-inspired prompts stems from aligning the task framing with different cognitive processes that humans use when interpreting sentiment. By explicitly modeling the causal relationship between sentiment and language (or vice versa), the prompts create different cognitive load and inference requirements for the model. C1 prompts leverage direct causation, requiring minimal inference, while C2 and C3 prompts force the model to engage in more complex reasoning about implicit sentiment or theory of mind processes. This variation in cognitive framing reveals that sentiment classification is not a monolithic task but contains multiple underlying psychological processes that affect model behavior and uncertainty levels.
