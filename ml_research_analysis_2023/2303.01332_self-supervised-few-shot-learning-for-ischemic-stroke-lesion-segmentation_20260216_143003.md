# Self-Supervised Few-Shot Learning for Ischemic Stroke Lesion Segmentation

## Quick Facts
- arXiv ID: 2303.01332
- Source URL: https://arxiv.org/abs/2303.01332
- Reference count: 0
- Primary result: Achieved average Dice score of 0.58 for ischemic lesion segmentation using only one annotated sample

## Executive Summary
This paper presents a self-supervised few-shot learning approach for ischemic stroke lesion (ISL) segmentation using parametric maps from CT perfusion (CTP) scans. The method generates supervoxels from five parametric maps (CBF, CBV, TTP, TMax, MIP) rather than raw CTP data, creating pseudolabels for training an anomaly detection network. The approach demonstrates significant improvements over baseline methods while requiring minimal annotated data, making it particularly valuable for clinical applications where labeled data is scarce.

## Method Summary
The approach extracts supervoxels from a set of stacked parametric maps using a modified 3D Felzenszwalb algorithm, generating pseudolabels for self-supervised training. These supervoxels are then used to train an anomaly detection network (ADNet) through an episodic few-shot learning framework. The model learns to segment ischemic lesions by recognizing deviations from normal brain tissue patterns, requiring only one annotated sample per patient for inference.

## Key Results
- Achieved average Dice score of 0.58 for ischemic lesion segmentation
- Outperformed baseline methods in few-shot learning scenario
- Demonstrated effectiveness of parametric maps over raw CTP data for supervoxel generation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Generating supervoxels from parametric maps (PMs) instead of raw CTP data improves the quality of self-supervised pseudolabels for ischemic stroke lesion segmentation.
- Mechanism: PMs (CBF, CBV, TTP, TMax, MIP) encode physiologically meaningful tissue characteristics that align better with lesion boundaries than raw voxel intensities, leading to supervoxels that more accurately represent lesion regions.
- Core assumption: Ischemic lesion boundaries are more consistently captured in the parametric space than in the raw perfusion space.
- Evidence anchors:
  - [abstract] "supervoxels extracted from a set of stacked PMs"
  - [section] "we argue that while supervoxels generated from raw 4D CTP studies cannot correctly describe the boundaries inside the brain tissue, supervoxels extracted from the PMs can capture informative sub-regions"
- Break condition: If PMs do not reliably differentiate ischemic from healthy tissue, or if lesion boundaries are better captured in raw perfusion dynamics, the advantage would disappear.

### Mechanism 2
- Claim: Self-supervised few-shot segmentation via anomaly detection (ADNet) enables training with minimal labeled data while maintaining segmentation performance.
- Mechanism: The model learns to recognize deviations from normal brain tissue by contrasting support and query volumes, using automatically generated supervoxel-based pseudolabels as proxies for lesion regions.
- Core assumption: Ischemic lesions constitute anomalies in the context of normal brain tissue appearance in CTP scans.
- Evidence anchors:
  - [section] "we propose a prototypical FSS framework for ISL segmentation and demonstrate the benefit of leveraging PMs for self-supervision"
  - [section] "we illustrate the benefits of our proposed training mechanism, leading to considerable improvements in performance in the few-shot setting"
- Break condition: If ischemic lesions are not sufficiently distinct from background tissue to be modeled as anomalies, or if supervoxel quality degrades performance.

### Mechanism 3
- Claim: The modified 3D Felzenszwalb algorithm operating on vector-valued voxels (M=5 modalities) produces supervoxels that balance region homogeneity and boundary adherence for lesion segmentation.
- Mechanism: By extending the Euclidean distance calculation to 5D vectors (CBV, CBF, TTP, TMax, MIP), the algorithm captures multi-parametric tissue similarity, producing supervoxels that better respect lesion boundaries.
- Core assumption: Multi-parametric similarity is a better criterion for supervoxel formation than single-channel similarity for this task.
- Evidence anchors:
  - [section] "we leverage the 3D version of Felzenszwalb's algorithm to produce supervoxels from the 3D image volume" and "extend the Euclidean distance calculation within the algorithm to support that each voxel in the image is represented by a vector"
  - [section] "Experiments were performed to tune ρ to improve the segmentation accuracy of the ischemic areas"
- Break condition: If the extended distance metric does not correlate with actual lesion boundaries, or if ρ tuning is too sensitive to dataset variations.

## Architecture Onboarding

- Component map:
  Input: 4D CTP scan (W×H×Z×M=30 time points) -> Pre-processing: HU conversion, co-registration, brain extraction, gamma correction -> PM generation: Automated computation of CBF, CBV, TTP, TMax, MIP -> Supervoxel generation: Modified 3D Felzenszwalb on 5D PM stack -> ADNet model: ResNet-101 encoder, MAP pooling, cosine similarity, learned threshold -> Training: Episodic self-supervised learning with supervoxel pseudolabels -> Inference: Single annotated slice as support for whole-volume segmentation

- Critical path: CTP → PM generation → supervoxel extraction → support/query pair creation → ADNet training → inference with single slice support

- Design tradeoffs:
  - Supervoxel granularity (ρ parameter) vs. computational efficiency and boundary adherence
  - Single modality vs. multi-parametric input for supervoxel generation
  - Anomaly detection framework vs. direct segmentation approaches for few-shot learning

- Failure signatures:
  - Poor Dice scores with high standard deviation across patients
  - Systematic under/over-segmentation in specific vascular territories
  - Sensitivity to ρ parameter selection indicating unstable supervoxel quality
  - Performance degradation when training on mixed patient populations

- First 3 experiments:
  1. Ablation study: Train with supervoxels from raw CTP vs. PMs to verify mechanism 1
  2. Parameter sweep: Vary ρ from 250 to 3000 to identify optimal supervoxel size
  3. Dataset split analysis: Compare performance on LVO-only vs. mixed population training to validate mechanism 2

## Limitations
- Performance evaluated on relatively small dataset (40 CTP scans across two groups)
- Generalizability to diverse clinical settings and scanner types remains uncertain
- Core assumption that parametric maps capture lesion boundaries more effectively than raw CTP data may not hold uniformly across all ischemic presentations

## Confidence
- High confidence: The self-supervised few-shot learning framework is technically sound and addresses a genuine clinical need for minimal annotation requirements
- Medium confidence: The specific mechanism of using parametric maps for supervoxel generation shows theoretical advantages but needs more empirical validation across diverse datasets
- Medium confidence: The anomaly detection formulation for few-shot segmentation is appropriate for this application but may have limitations with subtle or heterogeneous lesions
