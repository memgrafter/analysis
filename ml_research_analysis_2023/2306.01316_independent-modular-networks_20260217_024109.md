# Independent Modular Networks

## Quick Facts
- arXiv ID: 2306.01316
- Source URL: https://arxiv.org/abs/2306.01316
- Reference count: 6
- Primary result: Introduces Independent Modular Networks that automatically decompose data into identity and compositional factors, achieving near-perfect shape decomposition on 3dshapes dataset with ID classifier loss.

## Executive Summary
This paper proposes Independent Modular Networks, a modular architecture that explicitly accounts for the compositional nature of data generation processes. The approach splits modules into predetermined roles: identity modules that learn static transformations without observing input, and compositional modules that encode variable concepts while observing input. The architecture is trained to reconstruct images by combining identity and compositional features, with module combinations selected based on a scoring function that balances reconstruction quality, feature independence, and KL divergence.

## Method Summary
The method trains a modular network with fixed identity modules (learnable static transformations) and compositional modules (input-observing encoders using Lie Group VAE structure). For each input image, the network computes all possible identity+compositional module combinations, scores them using reconstruction MSE, independence regularization, and KL divergence, then selects the winning combination for parameter updates. Regularization terms promote independence between and within modules to prevent module collapse. An optional ID classifier loss improves decomposition accuracy by encouraging identity modules to specialize for specific shapes.

## Key Results
- Achieves near-perfect decomposition of ground truth shapes into separate identity modules when using ID classifier loss
- Demonstrates automatic learning of ground truth generative factor decomposition on 3dshapes dataset
- Identity modules capture object shapes while compositional modules modify other attributes (color, orientation, scale)
- Independence regularization improves resiliency to module collapse while enhancing decomposition accuracy

## Why This Works (Mechanism)

### Mechanism 1: Independence-based module collapse prevention
- Claim: Regularization enforcing independence between features extracted by different modules prevents module collapse
- Mechanism: Penalizes correlations between latent variables across modules (both within and between modules), forcing each module to learn distinct concepts not captured by others
- Core assumption: Penalizing feature correlations will naturally lead modules to specialize in different aspects without requiring explicit routing supervision
- Evidence anchors: Abstract mentions regularization improves resiliency to module collapse; section III-C1 quantifies independence between features; corpus lacks specific evidence
- Break condition: If independence regularization is too weak, modules may still learn correlated features; if too strong, modules may fail to capture necessary shared information

### Mechanism 2: Identity-compositional role separation
- Claim: Splitting modules into identity and compositional roles enables automatic decomposition of generative factors
- Mechanism: Identity modules learn static transformations without observing input, while compositional modules encode variable concepts while observing input, allowing natural decomposition of identity factors from compositional ones
- Core assumption: Certain generative factors are truly static while others are variable, and this hierarchical relationship can be learned automatically
- Evidence anchors: Abstract describes the unique structure splitting modules into predetermined roles; section III-B details identity modules using learnable parameters while compositional modules process input; corpus lacks evidence of this specific split
- Break condition: If dataset lacks clear hierarchical structure or generative factors don't naturally separate into static and variable categories

### Mechanism 3: Multi-criteria scoring function
- Claim: Scoring function with multiple criteria ensures optimal module combination selection for reconstruction
- Mechanism: Balances reconstruction quality (MSE loss), feature independence (independence penalty), and KL divergence (distribution matching) to select optimal combination
- Core assumption: Optimal reconstruction requires balancing fidelity with feature diversity and distributional alignment
- Evidence anchors: Section III-C1 uses three criteria (MSE, independence, KL divergence) to score reconstruction and features; section III-C2 combines these in loss function; corpus lacks direct evidence about multi-criteria scoring
- Break condition: Poor calibration of weighting between criteria may prioritize reconstruction over meaningful decomposition or vice versa

## Architecture Onboarding

- **Component map**: Input image → Compositional modules (m1...mn) → Transformation matrices Tc → All combinations Tc x TI → Candidate representations T → Decoder network → Reconstructions for each combination → Scoring function → Select winning combination → Loss calculation → Update weights of winning modules only

- **Critical path**: Input → Compositional feature extraction → Identity feature combination → Reconstruction → Scoring → Loss calculation → Parameter update

- **Design tradeoffs**: Fixed number of modules vs. learned module selection; Independence regularization strength vs. reconstruction quality; Identity vs. compositional module roles vs. fully flexible architecture; Single decoder vs. module-specific decoders

- **Failure signatures**: All inputs routed through same module combination (module collapse); Poor reconstruction quality despite high independence scores; Identity modules learning variable rather than static features; Computational explosion from evaluating all combinations

- **First 3 experiments**: 1) Train with only independence regularization (no ID classifier) and visualize identity reconstructions to verify shape decomposition; 2) Add ID classifier and compare decomposition accuracy across shapes; 3) Vary number of compositional vs. identity modules and measure impact on decomposition quality and reconstruction fidelity

## Limitations
- Independence-based module collapse prevention may be insufficient for datasets lacking clear compositional structure
- Fixed identity/compositional module split assumes ground truth factors naturally separate into static and variable categories, limiting generalization
- Hyperparameter sensitivity, particularly weighting between reconstruction, independence, and KL divergence criteria, could significantly impact results

## Confidence
- **Medium Confidence**: Architectural design and decomposition mechanism (identity/compositional split) is well-specified and supported by experimental results on 3dshapes
- **Medium Confidence**: Independence regularization approach for preventing module collapse is theoretically sound but lacks direct empirical validation beyond single dataset experiment
- **Low Confidence**: Generalization to more complex, real-world datasets with less clear compositional structure remains untested

## Next Checks
1. Test the model on a more complex dataset with overlapping or hierarchical generative factors (e.g., CelebA or dSprites) to evaluate robustness of independence-based module collapse prevention
2. Systematically vary the regularization weights and independence strength to identify optimal balance between decomposition accuracy and reconstruction quality
3. Compare against explicit routing supervision approaches to quantify whether indirect independence regularization truly outperforms direct module collapse prevention methods
