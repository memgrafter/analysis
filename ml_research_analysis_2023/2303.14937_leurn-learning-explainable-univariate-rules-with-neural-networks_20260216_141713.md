# LEURN: Learning Explainable Univariate Rules with Neural Networks

## Quick Facts
- arXiv ID: 2303.14937
- Source URL: https://arxiv.org/abs/2303.14937
- Authors: 
- Reference count: 40
- Primary result: Neural network architecture learning univariate decision rules for human explainability with comparable performance to state-of-the-art methods across 30 tabular datasets

## Executive Summary
LEURN introduces a novel neural network architecture that learns univariate decision rules to achieve human explainability in machine learning models. Unlike traditional neural networks that extract multivariate rules with exponentially growing branches, LEURN makes univariate decisions through learnable thresholds and a quantized tanh activation function. This design results in exact univariate decision trees where each rule's contribution to subsequent rule selection and final decisions is clearly formulated as a weighted linear combination. The architecture enables various capabilities including feature selection, feature importance extraction, semantic similarity measurement, generative usage, and confidence score provision.

## Method Summary
LEURN employs a neural network architecture that learns univariate decision rules through learnable thresholds and a quantized tanh activation function. The architecture makes univariate decisions instead of multivariate ones, avoiding the exponential growth of branches seen in traditional neural networks. Each rule's contribution to the next rule selection and final decision is explicitly formulated as a weighted linear combination, resulting in exact univariate decision trees. The model includes a smoothness parameter that allows controllable behavior between decision tree-like and vanilla neural network-like operations.

## Key Results
- Achieves comparable performance to state-of-the-art methods across 30 tabular datasets for both classification and regression problems
- Provides exact univariate decision trees with clearly formulated rule contributions
- Enables feature selection, feature importance extraction, semantic similarity measurement, generative usage, and confidence score provision
- Includes a smoothness parameter for controllable behavior between decision tree-like and neural network-like operations

## Why This Works (Mechanism)
LEURN's effectiveness stems from its unique approach to decision making through univariate rules rather than multivariate ones. By using learnable thresholds and a quantized tanh activation function, the architecture creates a structure where each decision point is independent and clearly interpretable. The weighted linear combination formulation of rule contributions ensures that the path from input to output is transparent and traceable. The smoothness parameter adds flexibility by allowing the model to adjust its behavior between strict decision tree-like operations and more fluid neural network-like operations, providing a balance between interpretability and performance.

## Foundational Learning
- **Quantized tanh activation**: Needed for creating discrete decision boundaries while maintaining differentiability; quick check: verify output distribution is binary-like
- **Learnable thresholds**: Essential for adapting decision boundaries to data distribution; quick check: confirm thresholds converge during training
- **Weighted linear combinations**: Required for transparent rule contribution calculation; quick check: validate weights sum to 1 for each rule path
- **Smoothness parameter**: Needed for balancing interpretability and performance; quick check: test effect on accuracy vs. tree depth
- **Univariate vs multivariate decisions**: Critical for maintaining interpretability; quick check: verify each decision depends on only one feature
- **Exact decision tree formulation**: Ensures transparent rule extraction; quick check: confirm tree structure matches learned rules

## Architecture Onboarding
- **Component map**: Input -> Feature normalization -> Learnable threshold layers -> Quantized tanh activation -> Weighted linear combination -> Output
- **Critical path**: Input features → Threshold comparison → Activation function → Rule selection → Final decision
- **Design tradeoffs**: Interpretability vs. performance (smoothness parameter), discrete vs. continuous operations (quantized activation), rule simplicity vs. model capacity
- **Failure signatures**: Poor performance on highly correlated features, difficulty with complex nonlinear relationships, potential overfitting with low smoothness
- **First experiments**: 1) Test on simple linearly separable dataset, 2) Compare performance with varying smoothness parameters, 3) Evaluate feature importance consistency across multiple runs
