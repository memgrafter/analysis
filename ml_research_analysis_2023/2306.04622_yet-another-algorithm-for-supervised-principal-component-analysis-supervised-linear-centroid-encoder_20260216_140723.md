# Yet Another Algorithm for Supervised Principal Component Analysis: Supervised Linear Centroid-Encoder

## Quick Facts
- arXiv ID: 2306.04622
- Source URL: https://arxiv.org/abs/2306.04622
- Reference count: 12
- SLCE achieves 98.94% classification accuracy on PANCAN dataset vs 94.23% for LDA

## Executive Summary
This paper proposes Supervised Linear Centroid-Encoder (SLCE), a linear dimensionality reduction technique that incorporates class label information through class centroids. Unlike standard PCA which minimizes sample reconstruction loss, SLCE minimizes the reconstruction loss between samples and their corresponding class centroids. The method provides a closed-form solution using eigendecomposition of a symmetric matrix and demonstrates superior performance compared to other supervised dimensionality reduction techniques on several benchmark datasets.

## Method Summary
SLCE maps samples to their class centroids using a linear transformation that minimizes centroid-reconstruction loss in the ambient space. The algorithm calculates class centroids, constructs a symmetric matrix (X̃CT + X̃T - XXT), and finds optimal projection directions through eigendecomposition. The resulting projection preserves class structure by minimizing distances between projected samples and their class centroids, providing a supervised alternative to PCA that maintains linear computational efficiency.

## Key Results
- SLCE achieves 98.94% classification accuracy on PANCAN dataset (5 classes) in 3D space, outperforming LDA's 94.23%
- On USPS handwritten digits dataset, SLCE achieves 94.9% accuracy in 8D space
- SLCE shows consistent performance advantages over PCA, LDA, HSIC PCA, and Bair's SPCA across multiple benchmark datasets

## Why This Works (Mechanism)

### Mechanism 1: Centroid Mapping
- Claim: SLCE maps each sample to its class centroid in reduced dimensional space
- Mechanism: Linear transformation minimizes reconstruction loss between projected samples and class centroids
- Core assumption: Class centroids are meaningful representatives of each class
- Evidence anchors: Abstract states SLCE maps samples to class centroids; section describes goal of approximating class centroids
- Break condition: If centroids are poorly separated or unrepresentative, reconstruction loss minimization becomes meaningless

### Mechanism 2: Eigendecomposition Solution
- Claim: Closed-form solution uses eigendecomposition of symmetric matrix for optimal projection
- Mechanism: Eigenvectors of (X̃CT + X̃T - XXT) with largest eigenvalues provide projection directions
- Core assumption: Eigendecomposition problem is well-posed with meaningful matrix structure
- Evidence anchors: Section derives closed-form solution using eigendecomposition; provides mathematical formulation
- Break condition: If matrix is ill-conditioned or lacks positive eigenvalues, solution may be unstable or non-existent

### Mechanism 3: Supervised Advantage
- Claim: SLCE is supervised PCA that incorporates label information through centroids
- Mechanism: Unlike PCA's sample reconstruction, SLCE minimizes class centroid reconstruction loss
- Core assumption: Label information through centroids improves classification over unsupervised PCA
- Evidence anchors: Abstract contrasts SLCE with PCA reconstruction; section compares equation formulations
- Break condition: If centroids don't capture discriminative information, supervision may not improve performance

- Critical path: Centroid calculation -> Matrix construction -> Eigendecomposition -> Classification accuracy
- Design tradeoffs: Closed-form solution provides efficiency but requires positive eigenvalues; centroid approach may struggle with overlapping classes
- Failure signatures: Poor classification performance, numerical instability in eigendecomposition, negative or zero eigenvalues

## Limitations

- Assumption sensitivity: Effectiveness depends heavily on class centroids being meaningful and well-separated representatives
- Linear assumption: Method assumes linear relationships between samples and class centroids, limiting applicability to complex nonlinear structures
- Eigenvalue condition: Closed-form solution requires sufficient positive eigenvalues, which may not hold for all datasets

## Confidence

- Mechanism 1 (centroid mapping): Medium confidence - centroid-based approach is intuitive but lacks direct experimental validation
- Mechanism 2 (closed-form solution): Medium confidence - mathematical derivation appears sound but lacks empirical evidence about numerical stability
- Mechanism 3 (supervised advantage): Low confidence - claims superior performance but provides limited ablation studies or theoretical justification
