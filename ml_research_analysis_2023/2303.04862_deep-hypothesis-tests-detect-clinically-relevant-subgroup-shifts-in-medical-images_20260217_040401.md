# Deep Hypothesis Tests Detect Clinically Relevant Subgroup Shifts in Medical Images

## Quick Facts
- arXiv ID: 2303.04862
- Source URL: https://arxiv.org/abs/2303.04862
- Reference count: 32
- This paper proposes a framework for detecting clinically relevant subgroup shifts in medical images using statistical hypothesis testing

## Executive Summary
This paper introduces a framework for detecting subgroup shifts in medical images using statistical hypothesis testing. The approach combines neural network-based feature extraction with classifier-based hypothesis tests to identify when test data differs from training data in clinically relevant ways. The method shows superior performance compared to deep kernel tests and multiple univariate Kolmogorov-Smirnov tests across various medical imaging datasets including histopathology and retinal fundus images. The framework is positioned as a tool for post-market surveillance of deployed medical AI algorithms to monitor for performance degradation due to population shifts.

## Method Summary
The framework operates in two main steps: first, neural network-based feature extractors are trained on the available training data to learn meaningful representations of the images. Second, a hypothesis test is performed on the test data using these extracted features to determine if the test data distribution differs from the training distribution. The authors focus on classifier-based tests (C2ST) as their primary approach, though they also compare against deep kernel tests and multiple univariate KS tests. The method is designed to be sensitive to clinically relevant subgroups rather than all possible distribution shifts.

## Key Results
- Classifier-based tests reliably detect subgroup shifts in histopathology and retinal fundus imaging datasets
- The proposed framework outperforms deep kernel tests and multiple univariate KS tests in detecting subgroup shifts
- The method shows promise for post-market surveillance of deployed medical AI systems

## Why This Works (Mechanism)
The framework works by leveraging the representational power of neural networks to capture clinically meaningful features from medical images, then using statistical hypothesis testing to detect when these features differ between training and test distributions. The classifier-based approach (C2ST) is particularly effective because it learns to distinguish between distributions rather than just measuring distributional distance. This allows it to be sensitive to shifts that affect the model's decision boundaries while being robust to irrelevant variations. The two-step process of feature extraction followed by hypothesis testing allows for efficient computation while maintaining sensitivity to clinically relevant changes.

## Architecture Onboarding

Component Map:
Training Data -> Feature Extractor -> Hypothesis Test -> Shift Detection

Critical Path:
The most critical path is the feature extraction step, as poor feature quality will propagate through to unreliable hypothesis test results. The hypothesis test itself is the second most critical component, as it determines whether shifts are detected. The choice of neural network architecture and training procedure for the feature extractor directly impacts the sensitivity and specificity of the overall system.

Design Tradeoffs:
- Feature extractor complexity vs computational efficiency: More complex networks may capture more subtle shifts but require more resources
- Hypothesis test sensitivity vs false positive rate: More sensitive tests may detect clinically irrelevant shifts
- Domain-specific vs general features: Domain-specific features may be more clinically relevant but less generalizable

Failure Signatures:
- High false positive rates when test data contains expected variation
- Missing clinically relevant shifts due to poor feature representation
- Computational bottlenecks during real-time monitoring

3 First Experiments:
1. Test detection sensitivity on known subgroup shifts with varying effect sizes
2. Evaluate false positive rate on data from the same distribution
3. Benchmark computational requirements for real-time monitoring scenarios
