# Learning Stochastic Dynamical System via Flow Map Operator

## Quick Facts

## Executive Summary
This paper introduces the stochastic Flow Map Learning (sFML) method, a novel framework for learning unknown stochastic dynamical systems from measurement data. The method extends deterministic flow map learning to handle stochastic systems by decomposing the stochastic flow map into deterministic and stochastic sub-maps. The deterministic component is modeled using a residual network (ResNet), while the stochastic component is captured using Wasserstein generative adversarial networks (WGANs-GP). This approach enables accurate simulation of system dynamics and analysis of long-term behavior through weak approximation in terms of distribution.

## Method Summary
The sFML method learns stochastic dynamical systems by decomposing the stochastic flow map into two components: a deterministic sub-map modeled by a ResNet and a stochastic sub-map modeled by a generative model (WGANs-GP). The method trains on measurement data to capture both the deterministic evolution and the stochastic fluctuations of the system. This decomposition allows for accurate representation of both the mean dynamics and the uncertainty propagation, providing a comprehensive model of the stochastic system's behavior.

## Key Results
- Successfully extends flow map learning to stochastic systems with non-Gaussian noise
- Demonstrates accurate approximation of both deterministic and stochastic components
- Validated on linear and nonlinear SDEs, including two-dimensional systems
- Provides weak approximation of unknown stochastic systems in terms of distribution

## Why This Works (Mechanism)
The sFML method works by decomposing the complex stochastic flow map into manageable deterministic and stochastic components. This decomposition allows for specialized modeling approaches: the deterministic part captures the underlying physical laws using a ResNet, while the stochastic part captures noise and uncertainty using a generative model. By training both components on the same data, the method learns the complete system dynamics, enabling accurate long-term predictions and uncertainty quantification.

## Architecture Onboarding

Component map: Data -> ResNet (deterministic) + WGANs-GP (stochastic) -> sFML model

Critical path: Training data → Deterministic sub-map learning → Stochastic sub-map learning → Integrated sFML model → System simulation

Design tradeoffs:
- ResNet depth vs. computational cost
- GAN architecture complexity vs. training stability
- Model accuracy vs. interpretability

Failure signatures:
- Poor generalization to unseen data
- Mode collapse in GAN training
- Inaccurate representation of system uncertainty

First experiments:
1. Test on a simple linear SDE with known analytical solution
2. Apply to a nonlinear SDE with Gaussian noise
3. Evaluate on a system with non-Gaussian noise to assess stochastic component modeling

## Limitations
- Assumes Markovian dynamics, limiting applicability to non-Markovian systems
- Computational cost of training GANs for high-dimensional systems
- Performance with strong nonlinear dependencies or complex correlation structures not thoroughly validated
- Limited validation on real-world experimental data

## Confidence
- High: Method's ability to approximate both deterministic and stochastic components of the flow map operator
- High: Decomposition approach's robust handling of non-Gaussian noise and multi-dimensional systems
- Medium: Applicability to real-world physical systems, as most examples focus on synthetic data

## Next Checks
1. Test the method on high-dimensional stochastic systems (dimension > 10) to assess scalability and computational efficiency.
2. Evaluate performance on real-world experimental data with measurement noise to validate practical applicability.
