# ACL-Fig: A Dataset for Scientific Figure Classification
## Quick Facts
- arXiv ID: 2301.12293
- Source URL: https://arxiv.org/abs/2301.12293
- Reference count: 20
- Primary result: 83% accuracy on 19-category scientific figure classification using ViT

## Executive Summary
This paper introduces ACL-Fig, a large-scale dataset containing 112,052 figures extracted from approximately 56,000 papers in the ACL Anthology. The dataset includes 19 categories of figures and tables, with a manually labeled subset of 1,671 figures (ACL-Fig-Pilot). The authors developed an automated pipeline combining figure extraction tools (PDFFigures2 and DeepFigures), k-means clustering, and metadata-based annotation to create this resource. A Vision Transformer model achieved the best performance, reaching 83% accuracy in classifying figures into the 19 categories. The dataset is publicly available under a CC BY-NC license and aims to support various downstream tasks in scientific document understanding.

## Method Summary
The authors developed a multi-stage pipeline to construct the ACL-Fig dataset. First, figures were extracted from ACL Anthology papers using PDFFigures2 and DeepFigures tools. The extracted figures were then clustered using k-means clustering on ResNet-152 embeddings to group similar figures. Automatic annotation was performed using paper metadata and figure captions to assign labels from 19 categories. For validation, a subset of 1,671 figures was manually labeled to create the ACL-Fig-Pilot dataset. The classification model was implemented using a Vision Transformer (ViT) architecture, trained and evaluated on both the automatically labeled and manually labeled subsets.

## Key Results
- 112,052 figures extracted from ~56K ACL Anthology papers
- ViT model achieved 83% accuracy on 19-category classification
- ACL-Fig-Pilot provides 1,671 manually labeled figures for validation
- Dataset available under CC BY-NC license for research use

## Why This Works (Mechanism)
The dataset construction pipeline leverages metadata and captions for automatic annotation, which provides scalable labeling for large-scale datasets. The combination of multiple figure extraction tools (PDFFigures2 and DeepFigures) helps capture a comprehensive set of figures from the source papers. The use of ResNet-152 embeddings for clustering groups visually similar figures, potentially improving annotation consistency. The Vision Transformer architecture is well-suited for this task as it can capture both local and global visual patterns in scientific figures, leading to the observed 83% classification accuracy.

## Foundational Learning
The paper builds upon established techniques in computer vision and document analysis. The use of ResNet-152 for feature extraction draws from deep learning advancements in image representation learning. The k-means clustering approach is a standard unsupervised learning method for grouping similar instances. The Vision Transformer architecture represents state-of-the-art developments in transformer-based image classification. The metadata-based annotation approach leverages the structured nature of academic publications, where figure captions and paper metadata typically provide semantic context.

## Architecture Onboarding
The dataset construction pipeline consists of three main components: figure extraction, clustering, and annotation. Figure extraction uses PDFFigures2 and DeepFigures to process PDF documents and extract figure regions. Clustering employs k-means on ResNet-152 embeddings to group similar figures based on visual features. Annotation uses paper metadata and figure captions to assign semantic labels from 19 categories. For classification, the Vision Transformer architecture processes the figure images through self-attention mechanisms to learn discriminative features for the 19-category classification task.

## Open Questions the Paper Calls Out
- How well does the dataset generalize to figures from non-ACL venues or other scientific domains?
- What is the impact of annotation noise on downstream task performance?
- Can the dataset support more complex tasks beyond classification, such as figure-caption alignment or question answering?
- How does the performance vary across different figure categories, particularly for underrepresented classes?
- What is the optimal balance between automatic and manual annotation for dataset construction?

## Limitations
- Automatic annotation pipeline may introduce noise due to metadata-based labeling that doesn't always clearly indicate figure types
- Clustering approach using k-means on ResNet-152 embeddings could group dissimilar figures with coincidentally similar visual features
- Evaluation limited to classification accuracy without examining class imbalance effects or utility for complex downstream tasks
- Dataset coverage limited to ACL Anthology papers, potentially missing figures from other venues
- The 1,671 manually labeled figures in ACL-Fig-Pilot may not be representative of the full dataset distribution

## Confidence
- Dataset construction methodology: Medium - The pipeline is well-described but relies on automated processes that may introduce errors
- Classification performance claims: High - Results are reproducible with provided code and models
- Dataset coverage and representativeness: Medium - Limited to ACL Anthology papers, potentially missing figures from other venues
