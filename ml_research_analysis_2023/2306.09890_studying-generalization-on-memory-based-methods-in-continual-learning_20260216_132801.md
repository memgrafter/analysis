# Studying Generalization on Memory-Based Methods in Continual Learning

## Quick Facts
- arXiv ID: 2306.09890
- Source URL: https://arxiv.org/abs/2306.09890
- Authors: 
- Reference count: 40
- Key outcome: Memory-based methods improve in-distribution performance but impair out-of-distribution generalization by learning spurious correlations.

## Executive Summary
This study investigates the generalization properties of memory-based methods in continual learning, particularly their out-of-distribution (OOD) generalization capabilities. The authors demonstrate that while memory-based methods improve in-distribution (IID) performance, they impair OOD generalization by learning spurious correlations. Using the Synbol benchmark, the research shows that the issue primarily lies in the linear classifier, which fails to correctly utilize the information encoded in the model's representations. The experiments reveal that increasing memory size enhances IID performance but does not improve OOD generalization. The study concludes that memory-based methods focus on known distributions, limiting their ability to generalize to unseen combinations of concepts.

## Method Summary
The study uses the Synbols benchmark to create a controlled continual learning scenario with varying numbers of tasks (1, 2, 4, 5, and 10 tasks). Experience Replay with reservoir sampling memory buffers is implemented, with memory sizes ranging from 50 to 1000 samples. A 6-layer CNN is trained using Adam optimizer (learning rate 4e-4) and cross-entropy loss for each scenario. The experiments compare performance on IID test sets (union of all training distributions) versus OOD test sets (unseen font/character combinations) to measure generalization capabilities.

## Key Results
- Memory-based methods improve IID performance but fail to generalize to OOD test sets
- Increasing memory size enhances IID performance without improving OOD generalization
- The linear classifier is identified as the primary bottleneck for OOD generalization
- The model learns spurious correlations between character and font rather than compositional features

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Memory-based methods improve in-distribution performance but impair out-of-distribution generalization by learning spurious correlations.
- Mechanism: Replay-based methods store subsets of previous data distributions to prevent catastrophic forgetting. While this allows the model to maintain performance on seen data, the limited buffer size leads to overfitting to the stored distribution, causing the model to rely on shortcuts rather than learning generalizable compositional features.
- Core assumption: The replay memory accurately represents the full training distribution; otherwise, the model will overfit to the subset and fail to generalize.
- Evidence anchors:
  - [abstract] "Although these methods produce good results, few studies have tested their out-of-distribution generalization properties, as well as whether these methods overfit the replay memory."
  - [section] "By only storing a subset of previous distributions, the model only reinforces concepts and ideas that are present in the buffer... if the buffer represents only a small percentage of the training distribution, it will start learning spurious correlations and will lose its generalization capabilities."
- Break condition: If the memory buffer becomes too large relative to the training set, the model may approach IID performance, but OOD generalization may still be impaired due to the model's reliance on spurious correlations learned during training.

### Mechanism 2
- Claim: The lack of out-of-distribution generalization primarily occurs in the linear classifier, which fails to correctly utilize the information encoded in the model's representations.
- Mechanism: The model's representation layers learn useful features for both IID and OOD data, but the linear classifier is unable to compose these features correctly to solve the task, instead relying on spurious correlations between character and font.
- Core assumption: The representation layers encode sufficient information to solve the task, but the classifier is the bottleneck for OOD generalization.
- Evidence anchors:
  - [section] "We use a linear probe, keeping the model fixed and training it to detect these features. We show that the learned representations have the necessary information to solve the main task, since training the probe with IID and OOD data it obtains good performance in both IID and OOD test sets."
  - [section] "However, when training only with IID data, there is still a big gap between the IID and OOD test set... suggests replay is producing its effect by reducing overfitting in the IID set on the classification layer, in contrast to the representation layers of the model."
- Break condition: If the classifier is replaced with a more expressive model (e.g., a non-linear classifier), the OOD generalization performance may improve.

### Mechanism 3
- Claim: The model does not learn to represent the combination of character and font as a compositional feature, but rather treats each combination as an independent class.
- Mechanism: When the task is flattened to treat each character-font combination as an independent class, the model can achieve near-perfect performance on the OOD test set when trained on both IID and OOD data. However, when trained only on IID data, the model fails to generalize to unseen combinations, suggesting it has not learned to compose the character and font features.
- Core assumption: The model can learn to represent each character and font independently, but fails to learn the compositional relationship between them.
- Evidence anchors:
  - [section] "When training only with the original training set, the accuracy in the OOD test set is zero. However, when training with both sets, IID and OOD, the accuracy of the OOD test set is almost 100%."
- Break condition: If the model is trained with a curriculum that explicitly encourages compositional learning (e.g., by gradually increasing the complexity of the combinations), the OOD generalization performance may improve.

## Architecture Onboarding

- Component map: Input -> 6-layer CNN (feature extraction) -> Linear classifier (task prediction) -> Replay memory buffer (stores previous distributions)
- Critical path: The critical path for OOD generalization is from the input through the CNN layers to the linear classifier. The replay memory influences the CNN's learned representations, which in turn affect the classifier's performance.
- Design tradeoffs: Using a larger replay memory improves IID performance but may not improve OOD generalization. The size of the replay memory is a key hyperparameter that needs to be tuned.
- Failure signatures: If the model shows good IID performance but poor OOD performance, it may be relying on spurious correlations learned from the replay memory. If the linear probe shows good performance on both IID and OOD data, but the full model does not, the issue likely lies with the classifier.
- First 3 experiments:
  1. Vary the size of the replay memory and observe its effect on IID and OOD performance.
  2. Train a linear probe on the learned representations and compare its IID and OOD performance to the full model.
  3. Flatten the task by treating each character-font combination as an independent class and observe the model's performance on IID and OOD data.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What specific modifications to the linear classifier architecture or training procedure could improve out-of-distribution generalization in memory-based continual learning methods?
- Basis in paper: [explicit] The paper concludes that the lack of OOD generalization primarily occurs in the linear classifier, which fails to correctly utilize the information encoded in the model's representations.
- Why unresolved: The paper identifies the problem but does not propose or test specific solutions for improving the classifier's OOD generalization capabilities.
- What evidence would resolve it: Experiments comparing different classifier architectures (e.g., non-linear classifiers, attention mechanisms) or training strategies (e.g., data augmentation, regularization techniques) on the same Synbol benchmark task.

### Open Question 2
- Question: How do different memory replay strategies (e.g., reservoir sampling vs. other sampling methods) affect the trade-off between in-distribution and out-of-distribution generalization?
- Basis in paper: [explicit] The paper uses reservoir sampling for experience replay and observes that increasing memory size improves IID performance but not OOD generalization.
- Why unresolved: The paper only tests one memory sampling method and does not explore how alternative replay strategies might impact the generalization gap.
- What evidence would resolve it: Comparative experiments using different memory sampling techniques (e.g., uniform sampling, prioritized sampling) on the same benchmark to measure their effects on both IID and OOD performance.

### Open Question 3
- Question: What is the minimum memory size required to achieve optimal in-distribution performance, and how does this threshold relate to the number of tasks in a continual learning scenario?
- Basis in paper: [explicit] The paper shows that longer training sequences (more tasks) require larger memories to match static training performance, but does not determine an optimal memory size.
- Why unresolved: The paper varies memory size but does not analyze the relationship between memory requirements and task complexity.
- What evidence would resolve it: Systematic experiments varying both the number of tasks and memory sizes to identify the point of diminishing returns for IID performance improvement.

## Limitations
- The study uses a synthetic benchmark (Synbols) which may not capture the complexity of real-world distribution shifts
- Only experience replay is tested, limiting generalizability to other memory-based approaches
- The linear classifier is identified as the bottleneck but specific solutions are not explored

## Confidence
- High confidence: Memory-based methods impair OOD generalization; larger memory buffers improve IID but not OOD performance
- Medium confidence: The linear classifier is the primary bottleneck for OOD generalization; the model fails to learn compositional representations
- Low confidence: The specific mechanisms of how spurious correlations impair generalization; generalizability to real-world datasets
