# Iterative self-transfer learning: A general methodology for response time-history prediction based on small dataset

## Quick Facts
- arXiv ID: 2306.08700
- Source URL: https://arxiv.org/abs/2306.08700
- Reference count: 19
- Key outcome: Improves model performance by near an order of magnitude on small datasets using iterative self-transfer learning with pseudo-labels and DAN-TR network

## Executive Summary
This paper proposes an iterative self-transfer learning method for response time-history prediction using small datasets. The approach combines pseudo-labeling with a novel deep adaptation network with three branches for regression (DAN-TR) to iteratively improve model performance without requiring external labeled samples or complex analysis. The method reduces validation and testing mean square error by 70-84% compared to models trained directly on small datasets, making it particularly valuable for structural analysis applications where data collection is expensive or time-consuming.

## Method Summary
The method integrates pseudo-label strategy and DAN-TR to iteratively improve model performance on small labeled datasets. The process begins with initial training on a small labeled dataset, followed by pseudo-label generation on unlabeled data. The DAN-TR network then extracts generalizable features between pseudo-labeled source and labeled target domains using multi-kernel maximum mean discrepancy loss. This cycle repeats until performance plateaus. The approach requires no external labeled samples, pre-trained models, additional artificial labeling, or complex physical/mathematical analysis, making it efficient for practical applications.

## Key Results
- Improves model performance by near an order of magnitude on small datasets
- Reduces validation and testing mean square error by 70-84% compared to direct training
- Effective on datasets as small as 5-20 samples without external data requirements

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Iterative self-transfer learning reduces model error by reusing pseudo-labeled samples to augment training data without requiring external labeled datasets.
- Mechanism: The method iteratively trains a model, generates pseudo-labels on unlabeled data, and uses these pseudo-labeled samples as a surrogate source domain. This expands the training set size and introduces data diversity, mitigating overfitting on small labeled datasets.
- Core assumption: Pseudo-labels are sufficiently accurate to avoid catastrophic drift and provide meaningful signal for feature generalization.
- Evidence anchors:
  - [abstract] "The proposed method can improve the model performance by near an order of magnitude on small datasets without the need of external labeled samples, well behaved pre-trained models, additional artificial labeling, and complex physical/mathematical analysis."
  - [section 2.1.2] "The PL strategy is a highly adaptable semi-supervised data augmentation strategy that works with a wide range of input and output data."
- Break condition: If pseudo-label accuracy falls below a threshold, error accumulation causes model drift and performance degradation.

### Mechanism 2
- Claim: The DAN-TR network extracts generalizable features between pseudo-labeled source domain and labeled target domain, improving transferability.
- Mechanism: DAN-TR uses multi-kernel maximum mean discrepancy (MK-MMD) loss between source and target domain branches to align feature distributions, enabling knowledge transfer even when marginal distributions are identical but conditional distributions differ.
- Core assumption: Shared network layers capture transferable low-level features while domain adaptation branch learns domain-invariant mappings.
- Evidence anchors:
  - [section 2.2.2] "A domain adaptation branch... shares the parameters with the source domain branch... The MK-MMD loss... between the tailored nets of the adaptation branch... and target domain branch is calculated."
  - [section 2.1.1] "The MMD method uses the kernel-mapping algorithm to map the features of both the source and target domains into the high-dimensional reproducing kernel Hilbert space and computes the distances between the embedding results."
- Break condition: When source and target domains are too dissimilar, MK-MMD cannot bridge the gap, limiting transfer effectiveness.

### Mechanism 3
- Claim: Iterative alternation between pseudo-label generation and DAN-TR-based transfer learning expands the effective eigenspace and prevents early saturation of PL strategy.
- Mechanism: After one or two PL iterations, DAN-TR training is applied, which generalizes features and increases the sample space dimensionality, allowing subsequent PL iterations to yield further improvement rather than decaying performance.
- Core assumption: Feature generalization through DAN-TR enlarges the representational capacity, making the sample space appear "sparse" and enabling further meaningful pseudo-labeling.
