# Confidence-Based Feature Imputation for Graphs with Partially Known Features

## Quick Facts
- arXiv ID: 2305.16618
- Source URL: https://arxiv.org/abs/2305.16618
- Reference count: 40
- Method achieves state-of-the-art performance on node classification and link prediction with up to 99.5% missing features

## Executive Summary
This paper introduces a novel confidence-aware feature imputation framework for graph-structured data with extremely high rates of missing features. The key innovation is assigning channel-wise confidence scores based on shortest path distances to nearest known features, which guides a two-stage imputation process. The method demonstrates state-of-the-art performance on semi-supervised node classification and link prediction tasks, significantly outperforming existing approaches when up to 99.5% of features are missing.

## Method Summary
The proposed approach operates in two stages: first, it performs channel-wise inter-node diffusion to propagate known features across the graph topology; second, it refines imputed features through node-wise inter-channel propagation. The confidence scores, derived from shortest path distances to the nearest known feature in each channel, are used to weight the imputation process, giving more weight to features with higher certainty. This confidence-aware framework effectively handles the extreme feature missingness scenario (up to 99.5%) that challenges traditional imputation methods.

## Key Results
- Achieves state-of-the-art performance on node classification and link prediction tasks
- Significantly outperforms existing methods when 99.5% of features are missing
- Demonstrates robust performance across multiple benchmark datasets including Cora, Citeseer, and PubMed

## Why This Works (Mechanism)
The method leverages confidence scores based on shortest path distances to guide the imputation process, ensuring that feature propagation respects both graph topology and feature certainty. By separating the imputation into channel-wise diffusion and node-wise refinement stages, the approach can effectively capture both local and global feature patterns. The confidence-weighted propagation prevents over-reliance on distant or uncertain feature estimates, leading to more accurate imputations even in extremely sparse settings.

## Architecture Onboarding

**Component Map:**
Input graph + partial features -> Confidence score computation (shortest path distances) -> Channel-wise inter-node diffusion -> Node-wise inter-channel propagation -> Imputed complete features

**Critical Path:**
Shortest path distance computation → Confidence score generation → Channel-wise diffusion → Node-wise refinement → Final feature matrix

**Design Tradeoffs:**
- Confidence scores based on shortest path distances provide computational efficiency but may not capture complex feature relationships
- Two-stage process allows for both global propagation and local refinement but increases computational complexity
- Channel-wise approach handles heterogeneous feature types but may miss cross-channel correlations

**Failure Signatures:**
- Poor performance on heterophilic graphs where shortest path distances don't reflect feature similarity
- Degradation when no known features exist in certain channels
- Scalability issues with very large graphs due to shortest path computations

## Open Questions the Paper Calls Out
The paper acknowledges that performance on heterophilic or dynamic graphs remains unexplored, as does scalability to very large graphs with millions of nodes. The confidence scores are static and don't account for potential changes in feature correlations during imputation, and the method requires known features to be present in each channel, which may not always be feasible in practice.

## Limitations
- Assumes feature values are continuous and that shortest path distances meaningfully capture feature similarity
- Performance on heterophilic or dynamic graphs remains unexplored
- Does not explicitly address scalability to very large graphs with millions of nodes
