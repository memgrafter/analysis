# PolyVoice: Language Models for Speech to Speech Translation

## Quick Facts
- arXiv ID: 2306.02982
- Source URL: https://arxiv.org/abs/2306.02982
- Reference count: 13
- Primary result: A two-language-model framework for speech-to-speech translation that preserves voice characteristics and handles unwritten languages using unsupervised discretized speech units

## Executive Summary
This paper presents PolyVoice, a novel framework for speech-to-speech translation that uses language models to translate and synthesize speech. The system consists of two components: U-XLM for translating speech units between languages and U-SLM for synthesizing speech while preserving the original speaker's voice characteristics. The framework uses unsupervised discretized speech units, enabling it to handle unwritten languages without requiring text transcripts. The authors demonstrate their approach on Chinese→English and English→Spanish translation pairs, showing strong performance in both translation quality and audio naturalness.

## Method Summary
PolyVoice uses a two-stage language modeling approach where speech is first converted to semantic units using HuBERT, then translated using a decoder-only Transformer (U-XLM), and finally synthesized using another language model (U-SLM) with SoundStream codec to preserve speaker characteristics. The system is trained with multi-task learning on ASR, MT, and S2S data. The U-XLM model uses a 48-layer decoder-only Transformer to predict target language units from source language units, while U-SLM processes these semantic units to generate codec units that embed the source speaker's voice characteristics.

## Key Results
- Achieves BLEU scores of 22.6 for Chinese→English and 15.5 for English→Spanish translation tasks
- Maintains speaker similarity with ASV scores of 0.831 for Chinese→English and 0.806 for English→Spanish
- Demonstrates naturalness scores of 3.72 for Chinese→English and 3.64 for English→Spanish using NISQA
- Successfully handles unwritten languages by training English→Spanish without Spanish text transcripts

## Architecture Onboarding

- Component map: Source speech → HuBERT → U-XLM → U-SLM → SoundStream → Target speech
- Critical path: Source speech → semantic unit extraction → translation → duration modeling → codec generation → target speech synthesis
- Design tradeoffs:
  - Unsupervised units enable unwritten language handling but may introduce semantic errors
  - Decoder-only architecture simplifies modeling but may need more data
  - Voice cloning improves experience but adds synthesis complexity
- Failure signatures:
  - Low BLEU scores indicate translation quality issues
  - Low ASV scores indicate voice cloning problems
  - High WER scores indicate pronunciation accuracy issues
- First 3 experiments:
  1. Evaluate U-XLM translation quality on small dataset with ground-truth units
  2. Test U-SLM voice cloning with known source speaker
  3. Measure duration model impact on synthesized speech naturalness

## Limitations
- Limited evaluation to only two language pairs without truly unwritten language testing
- Claims about superiority over existing approaches lack direct comparisons
- Uncertainty about whether unsupervised units preserve sufficient semantic information for high-quality translation

## Confidence

- Experimental methodology and evaluation metrics are appropriate

**Medium Confidence Claims**:
