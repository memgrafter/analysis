# On the Feasibility and Robustness of Pointwise Evaluation of Query Performance Prediction

## Quick Facts
- arXiv ID: 2304.00310
- Source URL: https://arxiv.org/abs/2304.00310
- Reference count: 13
- Primary result: APAE achieves high correlation with listwise metrics while demonstrating greater robustness to evaluation configuration changes

## Executive Summary
Query performance prediction (QPP) systems are typically evaluated using listwise approaches that measure rank correlation across query sets, but these methods have limitations for per-query analysis and sensitivity to evaluation configurations. This paper introduces Aggregated Pointwise Absolute Errors (APAE), a framework that evaluates QPP systems on individual queries by measuring deviations between predicted and true effectiveness values, then aggregating results. Experiments on TREC Robust dataset with multiple QPP methods, IR models, and metrics demonstrate that APAE maintains high correlation with standard listwise metrics while showing significantly greater robustness to changes in evaluation setup.

## Method Summary
The APAE framework normalizes QPP scores to [0,1] using a sufficiently large constant ℵ, then computes absolute errors between predicted and true effectiveness values for each query independently. These pointwise errors are aggregated across multiple IR metrics using min, max, or average functions, and finally averaged over the complete query set to produce the APAE score. This approach allows per-query analysis while maintaining correlation with traditional listwise evaluation methods.

## Key Results
- APAE achieves Kendall's tau correlation of 0.8-0.9 with standard listwise metrics
- Rank correlations across different IR metrics and models reach 1.0 for APAE versus 0.5-0.9 for listwise approaches
- APAE demonstrates reduced variance in QPP evaluation across different configurations
- The framework supports per-query performance analysis aligned with practical use cases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pointwise evaluation allows per-query performance analysis, which is more aligned with practical use cases than listwise rank correlation.
- Mechanism: By measuring deviations between predicted and true effectiveness scores for each query independently, then aggregating results, the framework provides query-level granularity.
- Core assumption: Individual query effectiveness is independent of other queries' effectiveness.
- Evidence anchors:
  - [abstract] "Such a listwise approach has a number of disadvantages, notably that it does not support the common requirement of assessing QPP for individual queries."
  - [section] "In contrast, a pointwise approach measures the effectiveness on individual queries, and then, if required, aggregates the results over a complete set."
- Break condition: If query performances are inherently dependent (e.g., in session-based search), the independence assumption fails.

### Mechanism 2
- Claim: Aggregated Pointwise Absolute Errors (APAE) reduces variance in QPP evaluation across different configurations.
- Mechanism: By normalizing QPP scores to [0,1] and using absolute error aggregation, APAE smooths out configuration-induced fluctuations.
- Core assumption: The normalization constant ℵ is sufficiently large to ensure positive denominators and stable comparisons.
- Evidence anchors:
  - [section] "To reduce the effect of such variations, we now propose a simple yet effective solution."
  - [section] "Our experiments demonstrate that this new approach leads to smaller variances in QPP evaluations across a range of different target metrics and retrieval models."
- Break condition: If ℵ is too small or too large, normalization may distort error measurements.

### Mechanism 3
- Claim: APAE maintains high correlation with standard listwise metrics (~0.8-0.9), validating its effectiveness as a substitute.
- Mechanism: By aggregating over multiple IR metrics (AP, nDCG, P@10, Recall), APAE captures performance trends similar to rank correlation methods.
- Core assumption: Different IR metrics reflect similar performance rankings when aggregated appropriately.
- Evidence anchors:
  - [section] "Each reported value here corresponds to the rank correlation (Kendall’sτ) between the relative ranks of the QPP systems ordered by their effectiveness as computed via one of the standard metrics... and APAE"
  - [section] "The high correlation values between the standard listwise and the proposed pointwise metrics show that APAE can be used as a substitute for the standard listwise evaluation."
- Break condition: If IR metrics diverge significantly in their rankings, aggregation may obscure rather than clarify performance differences.

## Foundational Learning

- Concept: Normalization of unbounded QPP scores to [0,1]
  - Why needed here: Enables use of distance-based error metrics for comparison
  - Quick check question: What normalization constant ℵ ensures the denominator in |μ(Q) - φ(Q)/ℵ| is always positive?

- Concept: Rank correlation measures (Kendall’s τ, Spearman’s ρ, Pearson’s r)
  - Why needed here: Understanding baseline listwise evaluation methods to validate APAE
  - Quick check question: How does Kendall’s τ differ from Spearman’s ρ in handling tied ranks?

- Concept: Aggregation functions (min, max, avg) for multi-metric evaluation
  - Why needed here: Determines how APAE combines effectiveness across different IR metrics
  - Quick check question: Which aggregation function (min, max, avg) would be most robust to outlier metrics?

## Architecture Onboarding

- Component map:
  - Input: Query set 𝒬, QPP estimates φ(·), IR model M, IR metrics ℳ
  - Processing: Normalization, error calculation per query, aggregation across metrics
  - Output: APAE score for each QPP method

- Critical path:
  1. Retrieve top-k documents for each query using IR model
  2. Compute true IR metric values μ(·) for each query
  3. Normalize QPP estimates to [0,1]
  4. Calculate absolute errors between true and predicted values
  5. Aggregate errors across metrics using chosen function
  6. Compute final APAE score as average over query set

- Design tradeoffs:
  - Choice of normalization constant ℵ vs. robustness to score scale
  - Selection of aggregation function vs. sensitivity to metric outliers
  - Number of IR metrics included vs. computational overhead

- Failure signatures:
  - Low correlation with listwise metrics suggests normalization issues
  - High variance across IR models indicates poor aggregation choice
  - Non-monotonic QPP method rankings suggest metric misalignment

- First 3 experiments:
  1. Validate normalization: Compare APAE scores using different ℵ values
  2. Test aggregation: Compute APAE with min, max, avg functions and compare stability
  3. Cross-metric consistency: Measure correlation between APAE and individual metric-based evaluations

## Limitations
- The independence assumption for query effectiveness may not hold in session-based or task-oriented searches
- The choice of normalization constant ℵ lacks sensitivity analysis to determine optimal values
- Experiments are limited to 7 QPP methods and 3 IR models, which may not generalize to all retrieval scenarios

## Confidence

**High Confidence**: The correlation between APAE and standard listwise metrics (~0.8-0.9) is well-supported by experimental results and represents a robust finding.

**Medium Confidence**: The claim about reduced variance across configurations is supported but would benefit from broader experimental validation across more diverse datasets.

**Medium Confidence**: The practical advantage of per-query analysis is theoretically sound but lacks user studies demonstrating real-world impact on QPP system development.

## Next Checks

1. **Cross-dataset validation**: Test APAE framework on multiple TREC tracks and non-TREC datasets to verify robustness claims hold beyond the Robust dataset.

2. **Sensitivity analysis**: Systematically vary the normalization constant ℵ across orders of magnitude to establish bounds for stable performance.

3. **Correlation dependency test**: Design experiments to measure performance when queries have correlated effectiveness scores, testing the independence assumption.
