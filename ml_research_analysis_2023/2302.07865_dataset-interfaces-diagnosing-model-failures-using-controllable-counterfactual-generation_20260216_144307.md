# Dataset Interfaces: Diagnosing Model Failures Using Controllable Counterfactual Generation

## Quick Facts
- **arXiv ID**: 2302.07865
- **Source URL**: https://arxiv.org/abs/2302.07865
- **Reference count**: 15
- **Primary result**: Introduces dataset interfaces for controllable counterfactual generation in computer vision, enabling fine-grained control over distribution shifts while maintaining dataset fidelity.

## Executive Summary
This paper presents dataset interfaces, a novel framework for generating counterfactual examples by encoding dataset classes as tokens in text-to-image diffusion models. The approach enables precise control over distribution shifts (such as background, lighting, and object co-occurrence) while preserving the semantic content of the original dataset. By using textual inversion to learn class-specific tokens, the method generates images that better match the target dataset distribution compared to simple class name prompting. The framework was applied to create ImageNet*, which was then used to systematically evaluate model robustness across 23 distribution shifts, revealing insights about how different types of shifts impact model performance.

## Method Summary
The dataset interfaces framework encodes each class from a target dataset as a unique token in the text space of a pre-trained text-to-image diffusion model. This encoding is achieved through textual inversion, where a small set of images per class is used to learn a token that, when combined with a base prompt, generates images matching the dataset distribution. The method allows for fine-grained control over distribution shifts by manipulating the base prompt while keeping the class token fixed. This enables systematic generation of counterfactual examples that preserve the target object while varying specific attributes. The approach was applied to ImageNet, creating ImageNet*, and used to evaluate model robustness across multiple distribution shifts.

## Key Results
- ImageNet* images show higher CLIP similarity to captions compared to Bing-scraped images
- ImageNet* images pass automatic quality filters more frequently than web-scraped counterparts
- User study confirms ImageNet* images more consistently exhibit desired shifts and objects
- Different distribution shifts have varying impacts on model performance and scaling behaviors

## Why This Works (Mechanism)
The framework works by leveraging the generative capabilities of text-to-image diffusion models while constraining the output to match a specific dataset distribution. By encoding classes as tokens through textual inversion, the method creates a compact representation that captures the essential characteristics of each class as present in the target dataset. This token-based approach allows for decoupling the class identity from the contextual attributes, enabling precise control over which aspects of the image are varied. The combination of class tokens with carefully crafted base prompts enables generation of counterfactual examples that maintain the target object while systematically varying specific attributes like background, lighting, or object co-occurrence.

## Foundational Learning
- **Textual Inversion**: Technique for learning new tokens in text-to-image diffusion models; needed to encode dataset-specific class characteristics; quick check: verify token generates class-relevant images
- **Distribution Shift**: Systematic differences between training and test data; needed to understand model robustness limitations; quick check: compare model performance across different shifts
- **CLIP Similarity**: Metric measuring semantic alignment between images and text; needed to validate generated image quality; quick check: ensure CLIP score exceeds baseline threshold
- **Counterfactual Generation**: Creating modified examples to test model behavior; needed for systematic robustness evaluation; quick check: verify generated examples preserve core object identity

## Architecture Onboarding

Component Map:
Text-to-image diffusion model -> Textual inversion module -> Class token encoder -> Prompt composition -> Image generator -> Quality filters -> Model evaluator

Critical Path:
Class token encoding (via textual inversion) → Prompt composition → Image generation → Quality validation → Model evaluation

Design Tradeoffs:
- Fine-grained control vs. computational cost of textual inversion
- Token expressiveness vs. potential for mode collapse
- Automated filtering vs. potential loss of rare but valid examples
- Systematic shifts vs. preservation of natural image statistics

Failure Signatures:
- Mode collapse: generated images lack diversity within classes
- Semantic drift: generated images lose connection to target class
- Artifact generation: unrealistic or implausible image features
- Distribution mismatch: generated images don't match target dataset statistics

First Experiments:
1. Generate 100 images per class using class tokens and evaluate CLIP similarity
2. Apply 5 different distribution shifts to a subset and measure performance degradation
3. Conduct user study with 10 participants rating 50 randomly selected generated images

## Limitations
- Evaluation primarily focused on image classification, limiting generalizability to other vision tasks
- Reliance on text-to-image diffusion models may inherit biases from underlying models
- User study sample size may not be representative of broader populations
- Automatic filters may not capture all aspects of dataset quality for edge cases
