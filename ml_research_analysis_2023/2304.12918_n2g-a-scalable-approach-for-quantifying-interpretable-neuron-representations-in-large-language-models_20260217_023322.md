# N2G: A Scalable Approach for Quantifying Interpretable Neuron Representations in Large Language Models

## Quick Facts
- arXiv ID: 2304.12918
- Source URL: https://arxiv.org/abs/2304.12918
- Reference count: 11
- Primary result: N2G successfully converts neurons into interpretable graphs for early layers but struggles with complex later-layer neurons

## Executive Summary
Neuron to Graph (N2G) addresses the challenge of interpreting neurons in large language models by automatically converting them into interpretable graph structures. The approach uses pruning to remove irrelevant context, saliency methods to identify important tokens, and augmentation to generate diverse samples. The resulting graphs visualize activation contexts and can predict token activations for validation. Experiments show N2G effectively captures neuron behavior for early layers but faces challenges with the more complex semantic behaviors of later-layer neurons.

## Method Summary
N2G transforms a target neuron into an interpretable graph through a pipeline of four main steps: pruning irrelevant context to isolate key tokens, calculating token importance using saliency methods, augmenting dataset examples with diverse samples using BERT substitutions, and building a trie structure where nodes represent tokens with activating nodes colored by normalized activation. The method processes text by checking if prior token sequences match paths through the trie, and visualizes the resulting structure as a layered graph. The approach was validated on a six-layer decoder-only Transformer model with SoLU activation trained on the Pile dataset.

## Key Results
- N2G successfully captures neuron behavior for early layers with good precision and recall metrics
- The graph visualization clearly shows activation contexts and helps identify polysemantic neurons as disconnected subgraphs
- Performance degrades for later-layer neurons due to increasingly abstract and complex semantic behaviors
- The augmentation approach using BERT substitutions effectively generates diverse samples that improve graph coverage

## Why This Works (Mechanism)

### Mechanism 1
- Claim: N2G successfully captures neuron behavior by pruning irrelevant context and focusing on key tokens.
- Mechanism: The pruning process removes all sentences after the key token and iteratively removes tokens before it until the neuron's activation on the key token remains sufficiently high. This ensures the model only considers relevant context.
- Core assumption: Removing irrelevant context will not significantly impact the neuron's activation on the key token, and the key token itself is the most important factor in the neuron's activation.

- Break condition: This mechanism would break if the neuron's activation on the key token significantly decreases when removing irrelevant context, or if the key token is not the most important factor in the neuron's activation.

### Mechanism 2
- Claim: N2G effectively captures neuron behavior by augmenting dataset examples with diverse samples.
- Mechanism: The augmentation process masks important tokens and uses BERT to predict substitutes, creating new prompts with varied inputs. This allows the model to explore the neuron's behavior in a wider range of contexts.
- Core assumption: Substituting important tokens with high-probability alternatives will generate meaningful variations that still capture the neuron's behavior.
- Evidence anchors:
  - [abstract] - Mentions augmenting dataset examples with more diverse samples to better capture the extent of neuron behavior.
  - [section] - Describes the augmentation process in detail, explaining how it masks important tokens and uses BERT for substitutions.

- Break condition: This mechanism would break if the substitutions generated by BERT do not meaningfully capture the neuron's behavior or if the neuron's behavior is highly sensitive to specific token sequences that are disrupted by the substitutions.

### Mechanism 3
- Claim: N2G provides interpretable graphs that accurately represent neuron behavior by visualizing activation contexts.
- Mechanism: The graph-building process creates a trie structure where each node represents a token, with activating nodes colored according to their normalized activation. This visualization allows researchers to understand the contexts in which the neuron activates.
- Core assumption: Visualizing the activation contexts in a graph structure will make the neuron's behavior more interpretable and easier to understand.

## Architecture Onboarding

- Component map: Input (target neuron, dataset examples) -> Pruning module -> Saliency module -> Augmentation module -> Graph builder -> Visualization module -> Output (interpretable graph, predicted token activations)

- Critical path: Pruning → Saliency → Augmentation → Graph building → Visualization

- Design tradeoffs:
  - Pruning aggressively vs. preserving potentially relevant context
  - Using high-probability BERT substitutions vs. potentially missing important variations
  - Normalizing activations for visualization vs. preserving absolute activation values

- Failure signatures:
  - Graph does not accurately capture neuron behavior (low precision/recall)
  - Visualization is cluttered or difficult to interpret
  - Augmentation generates irrelevant or nonsensical variations

- First 3 experiments:
  1. Test pruning on a simple neuron with a clear key token to verify context removal.
  2. Evaluate augmentation by checking if BERT substitutions generate meaningful variations.
  3. Visualize graph for a neuron with known behavior to assess interpretability.

## Limitations

- Graph construction scalability: The method was only validated on a six-layer transformer, and effectiveness for deeper models remains uncertain.
- Generalization across architectures: Performance on other activation functions or model architectures is not established.
- BERT augmentation reliability: BERT's predictions may not adequately represent the target model's behavior patterns.

## Confidence

- High Confidence: The core mechanism of pruning irrelevant context and building trie structures for visualization is technically sound and reproducible.
- Medium Confidence: The claim that N2G captures neuron behavior well for early layers is supported by experimental results, but evaluation methodology may not fully capture semantic meaning.
- Low Confidence: The assertion that N2G struggles with later-layer neurons is based on limited evidence without detailed analysis of why this occurs.
