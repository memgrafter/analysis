# Zero-shot domain adaptation of anomalous samples for semi-supervised anomaly detection

## Quick Facts
- arXiv ID: 2304.02221
- Source URL: https://arxiv.org/abs/2304.02221
- Reference count: 0
- Primary result: Proposed method achieves 92.9% AUC for seen anomalous data and 88.5% AUC for unseen anomalous data on rotated MNIST dataset

## Executive Summary
This paper addresses the challenge of adapting semi-supervised anomaly detection (SSAD) models to target domains when anomalous data for the target domain is unavailable. The authors propose a method that combines domain-adversarial training with importance-weighted loss functions to enable zero-shot domain adaptation. The approach leverages a variational autoencoder-based SSAD model, introducing a domain-adversarial network to obtain domain-invariant latent variables while conditioning the decoder on domain labels. The method is evaluated on rotated MNIST datasets, demonstrating superior performance in detecting seen anomalous data in the target domain compared to unsupervised methods.

## Method Summary
The proposed method introduces a domain-adversarial network to a variational autoencoder-based SSAD model to obtain domain-invariant latent variables. The encoder is trained to minimize domain classification loss while the domain classifier is trained to maximize it, creating an adversarial setup that pushes the encoder to produce latent variables lacking domain-specific information. To compensate for missing target domain anomalous data, an importance sampling-based weighted loss function approximates the ideal loss function by reweighting source domain anomalous samples based on their similarity to the target domain. The decoder is conditioned on the domain label to enable accurate reconstruction despite the loss of domain-specific information in the latent variables.

## Key Results
- Achieves 92.9% average AUC for detecting seen anomalous data in target domain
- Maintains 88.5% average AUC for detecting unseen anomalous data in target domain
- Outperforms unsupervised anomaly detection methods on seen anomalous data detection in target domain

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Domain-adversarial network forces latent representations to become indistinguishable across domains
- Mechanism: Adversarial training between encoder and domain classifier pushes encoder to produce domain-invariant latent variables
- Core assumption: Domain classifier can reliably estimate domain labels from latent variables alone
- Evidence anchors:
  - [abstract] "First, we introduce a domain-adversarial network to a variational auto-encoder-based SSAD model to obtain domain-invariant latent variables."
  - [section 4.2] "Through adversarial training of (7), we aim to match the distributions between z of the source data and that of the target data, i.e., we aim to obtain a domain-invariant latent variable."
- Break condition: If domain classifier fails to accurately predict domain labels from latent variables, adaptation performance degrades

### Mechanism 2
- Claim: Importance sampling-based weighted loss compensates for missing target domain anomalous data
- Mechanism: Weights source domain anomalous samples based on similarity to target domain using domain classifier outputs
- Core assumption: Domain classifier can accurately estimate p(d|x) and p(c|x, d=T) = p(c|x, d=S)
- Evidence anchors:
  - [section 4.3] "Here, we assumed p(d|x, c=A) = p(d|x, c=N) = p(d|x)."
  - [section 4.4] "Here, we assumed the covariate shift condition p(c|x, d=T) = p(c|x, d=S) = p(c|x)."
- Break condition: If covariate shift assumption is violated or domain classifier is poorly calibrated, importance weights will be inaccurate

### Mechanism 3
- Claim: Conditioning decoder on domain label enables accurate reconstruction despite domain-invariant latents
- Mechanism: Decoder receives both latent variable and domain label as inputs to compensate for lost domain-specific information
- Core assumption: Decoder can effectively utilize domain label information
- Evidence anchors:
  - [abstract] "Since the decoder cannot reconstruct the original data solely from domain-invariant latent variables, we conditioned the decoder on the domain label."
  - [section 4.2] "To overcome this problem, we input the domain label to the decoder in addition to the latent variable."
- Break condition: If decoder cannot effectively integrate domain label information, reconstruction quality suffers

## Architecture Onboarding

- Component map:
  Encoder -> Domain Classifier <-> Domain Adversarial Training <-> Encoder
  Encoder -> Decoder (with domain label)
  Domain Classifier -> Importance Weighting Module

- Critical path:
  1. Encode input data to obtain latent variable
  2. Classify domain from latent variable
  3. Decode latent variable (and domain label) to reconstruct input
  4. Compute weighted loss for training

- Design tradeoffs:
  - Domain invariance vs. reconstruction fidelity: Domain-adversarial training aims for domain-invariant latents but can harm reconstruction quality; conditioning decoder on domain label mitigates this
  - Importance weighting accuracy vs. model complexity: Relies on domain classifier accuracy which may be challenging early in training

- Failure signatures:
  - Poor domain classification accuracy: Domain classifier may struggle to accurately predict domain labels from latent space
  - Instability in importance weights: Importance weights may become unstable during training, particularly if domain classifier is not well-calibrated

- First 3 experiments:
  1. Train baseline VAE on source domain data and evaluate reconstruction quality on both source and target domain data
  2. Train domain-adversarial network with baseline VAE and evaluate domain classification accuracy on latent variables
  3. Train full proposed model and compare anomaly detection performance on seen and unseen anomalous data in target domain against baseline methods

## Limitations

- Method performance relies heavily on accuracy of domain classifier and validity of covariate shift assumption
- Importance weighting approach assumes p(c|x, d=T) = p(c|x, d=S) which may not hold in all scenarios
- Paper only evaluates on MNIST and rotated MNIST datasets, limiting generalizability to more complex real-world scenarios

## Confidence

- High Confidence: Core methodology of using domain-adversarial network to obtain domain-invariant latent variables and conditioning decoder on domain label is well-established and theoretically sound
- Medium Confidence: Importance sampling-based weighted loss function and its ability to compensate for missing target domain anomalous data relies on several assumptions
- Low Confidence: Paper does not thoroughly explore robustness to different types of domain shifts or impact of varying importance of domain adversarial loss
