# Affinity Clustering Framework for Data Debiasing Using Pairwise Distribution Discrepancy

## Quick Facts
- arXiv ID: 2306.01699
- Source URL: https://arxiv.org/abs/2306.01699
- Reference count: 26
- Primary result: Proposed MASC method effectively reduces group imbalance and improves fairness metrics in US Census datasets

## Executive Summary
This paper introduces MASC (Minority Augmentation via Spectral Clustering), a novel approach for mitigating representation bias in datasets caused by group imbalance. MASC utilizes affinity clustering to balance the representation of non-protected and protected groups by identifying contextually similar datasets and augmenting the target dataset with instances from the same protected attribute groups. The method constructs an affinity matrix based on pairwise distribution discrepancies using the Maximum Mean Discrepancy (MMD) metric, followed by spectral clustering to determine optimal clusters. Experiments on US Census datasets demonstrate MASC's effectiveness in reducing group imbalance and improving fairness metrics while maintaining comparable performance to existing data augmentation methods.

## Method Summary
MASC operates through a two-step process: affinity matrix construction and spectral clustering. First, it calculates pairwise distribution discrepancies between datasets using the Maximum Mean Discrepancy (MMD) metric to construct an affinity matrix. This matrix captures the similarity between datasets based on their distributional properties. Next, spectral clustering is applied to the affinity matrix to automatically determine the optimal number of clusters. The target dataset is then augmented by incorporating instances from similar datasets within the same protected attribute groups. This approach avoids the limitations of synthetic data augmentation techniques like SMOTE and RUS while achieving comparable debiasing performance.

## Key Results
- MASC effectively reduces group imbalance in US Census datasets
- Improves fairness metrics including Disparate Impact, Statistical Parity, and Equalized Odds
- Achieves comparable performance to existing data augmentation methods in both debiasing and predictive performance

## Why This Works (Mechanism)
MASC works by leveraging affinity clustering to identify datasets with similar distributional properties to the target dataset. By using MMD to measure pairwise distribution discrepancies, it captures nuanced similarities that may not be apparent through simple feature matching. Spectral clustering then groups these similar datasets, allowing for targeted augmentation from sources that maintain contextual similarity. This approach ensures that augmented data preserves the underlying data distribution while balancing representation across protected groups, leading to improved fairness without sacrificing predictive performance.

  - Why needed: Ensures balanced representation across different demographic groups
  - Quick check: Confirm augmentation maintains statistical properties of protected groups

## Architecture Onboarding

Component Map: Data Sources -> Affinity Matrix Construction -> Spectral Clustering -> Dataset Augmentation

Critical Path: The core workflow involves constructing the affinity matrix using MMD, applying spectral clustering to identify similar datasets, and augmenting the target dataset with instances from matched protected attribute groups.

Design Tradeoffs: MASC prioritizes maintaining contextual similarity through affinity-based clustering over synthetic data generation, which can introduce artifacts. This approach may be more computationally intensive but produces more realistic augmented data.

Failure Signatures: Potential failures include poor clustering due to inadequate affinity matrix construction, over-augmentation leading to data drift, or failure to identify truly similar datasets resulting in ineffective debiasing.
