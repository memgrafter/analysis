# Transferable Energy Storage Bidder

## Quick Facts
- arXiv ID: 2301.01233
- Source URL: https://arxiv.org/abs/2301.01233
- Reference count: 40
- One-line primary result: Transferable ConvLSTM model achieves 70%-90% of perfect foresight profits across multiple market designs and durations

## Executive Summary
This paper introduces a transferable energy storage arbitrage model that combines model-based optimization with a ConvLSTM network to predict opportunity value functions for price response and wholesale market bidding. The method uses dynamic programming to generate optimal value functions for training, enabling accurate bidding strategies under various market designs (HA-1, HA-10, PR-1, PR-10) and storage durations. Tested on NYISO and Queensland price data, the approach achieves 70%-90% profit ratios compared to perfect foresight. Transfer learning allows quick adaptation to new markets with minimal data, outperforming models trained from scratch in data-scarce scenarios.

## Method Summary
The approach innovates and provides several advantages as follows: Our approach has reliable performance as it uses model-based dynamic programming to address physical constraints in both training and control stages. Our approach is flexible as it can handle many market designs and storage durations. Our approach is computationally efficient as the bidding model is a small neural network and can be trained using non-proprietary software and regular computing hardware. Our approach can transfer to new markets quickly and effectively with as little as three days of local training data.

## Key Results
- Achieves 70%-90% of perfect foresight profits across multiple market designs
- Transfer learning requires only 3 days of local data to outperform training from scratch
- Model is computationally efficient and runs on regular computing hardware

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Dynamic programming pre-computes optimal value functions, which are then learned by a ConvLSTM network to predict opportunity values.
- Mechanism: The DP step recursively calculates the opportunity value function Qt using historical prices, then the ConvLSTM learns to predict these optimal values from past price data. This decouples the complex optimization from the prediction task.
- Core assumption: The optimal value functions generated by DP contain the essential information about storage value under varying market conditions and can be learned by a ConvLSTM.
- Evidence anchors:
  - [abstract] "Our approach has reliable performance as it uses model-based dynamic programming to address physical constraints in both training and control stages"
  - [section] "Our approach includes three steps: first, we use the deterministic price arbitrage dynamic programming approach from the previous section to generate the optimal storage opportunity value function segments using historical price data. We then train a learning model to predict the optimal storage opportunity value segments from past price data."
  - [corpus] Weak - the corpus focuses on other ML approaches to storage bidding, not specifically on DP-ConvLSTM combinations.
- Break condition: If the DP-generated value functions don't capture the true optimal arbitrage opportunities or if the ConvLSTM cannot learn the relationship between price patterns and value functions.

### Mechanism 2
- Claim: Transfer learning allows quick adaptation to new markets with minimal local data by leveraging patterns learned from a different market.
- Mechanism: A ConvLSTM trained on NYISO data is used as a starting point for Queensland markets. Only the output layer is fine-tuned with limited local data, assuming the underlying price patterns and storage value relationships are similar across markets.
- Core assumption: Price patterns and storage value relationships have statistical robustness and generality across different geographic markets, allowing knowledge transfer.
- Evidence anchors:
  - [abstract] "We also test a transfer learning approach by pre-training the bidding model using New York data and applying it to arbitrage in Queensland, Australia. The result shows transfer learning achieves exceptional arbitrage profitability with as little as three days of local training data"
  - [section] "The takeaway is that transfer learning beats out training the model from scratch when data scarcity is an issue."
  - [corpus] Missing - corpus papers don't discuss transfer learning approaches for storage arbitrage.
- Break condition: If the price patterns and market structures between source and target markets are too different, the transferred knowledge becomes irrelevant.

### Mechanism 3
- Claim: The ConvLSTM architecture captures temporal patterns in electricity prices, including daily and seasonal cycles, through its convolutional and LSTM layers.
- Mechanism: The ConvLSTM uses 2D convolutional layers to capture spatial-temporal patterns in price matrices, while LSTM layers handle temporal dependencies. This allows learning of cyclic price patterns and their relationship to storage value.
- Core assumption: Electricity prices exhibit persistent temporal patterns (daily/seasonal cycles) that can be learned by ConvLSTM and used to predict future opportunity values.
- Evidence anchors:
  - [section] "Thus we chose to use a convolutional long short-term memory (ConvLSTM) neural net, which can learn patterns in time series data."
  - [section] "This allows the network to capture not only the information on past prices for the current value function but also the relationship between past value functions in a 5-hour lookback."
  - [corpus] Weak - corpus papers focus on other ML architectures (MLP, RL) without discussing ConvLSTM's specific advantages for capturing temporal patterns.
- Break condition: If price patterns become too stochastic or non-cyclical, the ConvLSTM's learned patterns become less predictive.

  - Data Engineering Pipeline: Constructs input matrices ΛDAP, ΛRTP, and target Q from price data
  - ConvLSTM Network: Learns to predict opportunity values from past price patterns
  - Transfer Learning Adapter: Fine-tunes pre-trained model for new markets
  - Arbitrage Simulator: Uses predicted values to generate bids and simulate market clearing

- Critical path: DP Value Generation → Data Preparation → ConvLSTM Training → Transfer Learning (if applicable) → Bid Generation → Market Clearing Simulation

- Design tradeoffs:
  - DP-ConvLSTM vs pure RL: DP provides optimal ground truth but requires pre-computation; RL learns directly but may converge to suboptimal policies
  - ConvLSTM vs MLP: ConvLSTM captures temporal patterns better but is more complex; MLP is simpler but may miss cyclical patterns
  - Transfer learning vs training from scratch: Transfer learning requires less data but assumes similarity between markets; training from scratch is more flexible but data-hungry

- Failure signatures:
  - Low profit ratio despite high validation accuracy: Model may be overfitting to historical patterns that don't generalize
  - Sudden drops in performance: Price patterns may have changed significantly from training period
  - Transfer learning performs worse than random initialization: Source and target markets may be too different

  3. Vary storage duration (2hr, 4hr, 12hr) and evaluate profit ratio sensitivity; analyze why longer durations show lower ratios
