# Aria Digital Twin: A New Benchmark Dataset for Egocentric 3D Machine Perception

## Quick Facts
- arXiv ID: 2306.06362
- Source URL: https://arxiv.org/abs/2306.06362
- Reference count: 40
- Key outcome: Introduces a comprehensive egocentric 3D machine perception benchmark dataset with 200 sequences captured using Aria glasses in two digitized indoor spaces, providing precise 6DoF poses, ground truth data, and evaluating state-of-the-art methods.

## Executive Summary
The Aria Digital Twin (ADT) dataset addresses the need for high-quality, comprehensive egocentric 3D machine perception benchmarks. It features 200 sequences captured with Aria glasses in two fully digitized indoor spaces, providing precise 6DoF poses of devices, objects, and humans along with ground truth data including eye gaze, 3D human poses, 2D/3D object segmentations, depth maps, and photo-realistic synthetic renderings. Evaluations of state-of-the-art methods on ADT reveal challenges in 2D object detection, image segmentation, and 3D object detection tasks, highlighting the dataset's utility for advancing AR research and setting a new standard for evaluation in egocentric machine perception.

## Method Summary
The ADT dataset was created by capturing 200 sequences of real-world activities in two indoor spaces using Aria glasses equipped with RGB, monochrome, and IMU sensors. The indoor spaces and objects were digitized using high-precision FARO Focus S-150 and ATOS 5 Bluelight 3D scanners to create photo-realistic digital twins. Ground truth data was generated through motion capture systems and precise sensor calibration. The dataset was then evaluated using established metrics like AP-box and AP-Mask for object detection and segmentation tasks, and compared multiple state-of-the-art models to demonstrate its utility.

## Key Results
- ADT provides accurate 3D reconstruction and precise sensor calibration for reliable ground truth generation
- Comprehensive sensor suite of Aria glasses enables rich data for diverse machine perception tasks
- Established evaluation methodology using AP-box and AP-Mask metrics reveals challenges in 2D object detection and segmentation

- What evidence would resolve it: Develop and evaluate AR applications that leverage the eye gaze information from ADT to enhance object interaction and user experience, and compare their performance to applications without eye gaze integration.
