# DeepSI: Interactive Deep Learning for Semantic Interaction

## Quick Facts
- arXiv ID: 2305.18357
- Source URL: https://arxiv.org/abs/2305.18357
- Reference count: 40
- Key outcome: DeepSI-finetune framework achieves over 90% accuracy and faster convergence than baseline by integrating BERT fine-tuning with semantic interactions for visual analytics.

## Executive Summary
This paper introduces DeepSI-finetune, a framework that integrates deep learning fine-tuning into semantic interaction (SI) pipelines for visual analytics. Unlike prior approaches that use pretrained models as fixed feature extractors, DeepSI-finetune iteratively tunes BERT representations using user interactions, enabling task-specific adaptations. A qualitative case study on COVID-19 research articles showed DeepSI-finetune accurately clustered documents into four risk-factor groups with only 12 interactions, whereas the baseline DeepSI-vanilla failed to form clear clusters even after more interactions. A simulation-based quantitative experiment across three text corpora (SST, Vispubdata, 20 Newsgroups) confirmed DeepSI-finetune achieved over 90% accuracy and faster convergence than DeepSI-vanilla, which plateaued below 80% accuracy. These results demonstrate DeepSI-finetune's ability to capture complex user mental models more accurately and efficiently by embedding deep learning within the interactive sensemaking loop.

## Method Summary
DeepSI-finetune is a visual analytics framework that integrates semantic interaction with deep learning fine-tuning. The system uses BERT to generate document representations, which are projected to 2D visualizations using MDS. Users interact by dragging documents in the scatterplot to express similarity preferences. These interactions are mapped back to high-dimensional space using MDS⁻¹ and used as constraints to fine-tune BERT parameters through backpropagation. The framework is compared against DeepSI-vanilla, which uses BERT as a frozen feature extractor with weighted MDS. Experiments use three text corpora (SST, Vispubdata, 20 Newsgroups) and evaluate clustering quality using kNN accuracy over 200 interaction iterations.

## Key Results
- DeepSI-finetune achieved over 90% accuracy across all three text corpora, while DeepSI-vanilla plateaued below 80% accuracy
- Qualitative case study on COVID-19 research articles showed DeepSI-finetune formed clear 4-cluster structure with only 12 interactions, while baseline failed to converge
- DeepSI-finetune demonstrated faster convergence and better accuracy than baseline across all tested datasets

- Mechanism: Semantic interactions provide feedback that drives gradient updates to BERT parameters via backpropagation, enabling task-specific adaptation.
- Core assumption: User's intended similarity structure can be encoded as spatial arrangements in the visualization and translated into loss signals for fine-tuning.

- Claim: The feedback loop between user interactions and DL updates enables efficient learning of user- and task-specific representations.
- Mechanism: Each interaction loop passes low-dimensional distance constraints from the visualization back to the high-dimensional space via MDS⁻¹, which are then used to update BERT weights.
- Core assumption: Low-dimensional pairwise distances derived from user interactions can be meaningfully mapped to high-dimensional space to guide representation updates.
- Evidence anchors:
  - [abstract] "This feedback loop between human interaction and deep learning enables efficient learning of user- and task-specific representations."

- Break condition: If MDS⁻¹ mapping fails to preserve interaction intent, the feedback loop will propagate noise into BERT weights.

- Claim: Fine-tuning introduces minimal task-specific parameters, reducing the data required for effective adaptation.
- Mechanism: Fine-tuning appends a small output layer to pretrained BERT and updates only a subset of parameters via backpropagation, rather than training from scratch.
- Core assumption: Pretrained BERT weights capture general linguistic features that can be adapted with minimal task-specific training.

  - Why needed here: Fine-tuning updates pretrained model parameters using task-specific data, while feature extraction uses fixed embeddings.

## Architecture Onboarding

- Component map: User Interface -> Interaction Handler -> MDS -> MDS⁻¹ -> BERT -> Evaluation
- Critical path: User interaction → MDS⁻¹ → BERT update → MDS → Visualization
- Design tradeoffs:
  - Fine-tuning vs. feature extraction: More accurate but requires more computation per interaction
  - MDS vs. other DR methods: Simpler but potentially less expressive for complex similarity structures
  - Real-time vs. batch updates: Real-time provides immediate feedback but may be unstable
- Failure signatures:
  - Slow convergence or plateauing accuracy indicates poor interaction-DR mapping
  - Erratic projection changes suggest instability in fine-tuning updates
  - No improvement over baseline suggests interactions aren't effectively guiding fine-tuning
- First 3 experiments:
  1. Verify baseline DeepSI-vanilla performance on a simple two-cluster text dataset
  2. Test DeepSI-finetune with minimal interactions (3 per class) on the same dataset
  3. Compare learning curves of both methods across multiple interaction iterations

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of DeepSI-finetune scale with increasing dataset sizes beyond the tested ranges?
- Basis in paper: [inferred] The paper tested scalability on a desktop computer with up to thousands of data points, noting that MDS projection calculation consumed the majority of time while DL updates were negligible. This suggests potential scalability concerns for much larger datasets.
- Why unresolved: The paper does not provide experimental results for very large datasets (e.g., millions of documents), leaving uncertainty about computational limits and whether fine-tuning remains effective at scale.
- What evidence would resolve it: Systematic experiments testing DeepSI-finetune on progressively larger datasets, measuring both computational runtime and accuracy degradation, would clarify scalability boundaries.

### Open Question 2
- Question: What is the impact of different deep learning model architectures (beyond BERT) on semantic interaction quality and efficiency?
- Basis in paper: [explicit] The paper explicitly states that DeepSI-finetune is general enough to apply other pretrained DL models like RoBERTa, XLNet, GPT-3, CNN, RNN, and ELMo, but only tested BERT.
- Why unresolved: The paper only used BERT as the representative DL model, so it's unclear how alternative architectures might perform differently in terms of accuracy, convergence speed, or interaction requirements.
- What evidence would resolve it: Comparative experiments using various DL architectures (CNN, RNN, other transformers) within the DeepSI-finetune framework would reveal performance differences and guide optimal architecture selection.

### Open Question 3
- Question: How can the internal state of the fine-tuned DL model be made interpretable to analysts during the sensemaking process?
- Basis in paper: [explicit] The paper explicitly identifies this as a limitation, noting that current prototypes provide no visual hints about DL model status beyond the projection scatterplot, and suggests adding visual designs to expose fine-tuning effects.
- Why unresolved: While the paper acknowledges the importance of interpretability, it does not propose or test specific visualization techniques for exposing DL model internals to users.
- What evidence would resolve it: Development and user testing of visualization techniques that expose DL model parameters, attention patterns, or feature importance during interactive fine-tuning would demonstrate whether such interpretability improves analyst understanding and decision-making.

## Limitations
- The framework assumes users can effectively communicate similarity through spatial interactions, which may not hold for all users or domains
- Performance depends on MDS as the DR method; more complex similarity structures may require advanced DR techniques
- Limited evaluation on only text data; extension to other modalities (images, multi-modal) remains untested

## Confidence
- DeepSI-finetune improves accuracy over baseline: High confidence (confirmed across multiple datasets and quantitative experiments)
- DeepSI-finetune achieves faster convergence: Medium confidence (supported by COVID-19 case study but limited quantitative analysis)
- Fine-tuning enables task-specific adaptation: Medium confidence (mechanism theoretically sound but limited empirical validation)
