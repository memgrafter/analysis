# Equitable Multi-task Learning

## Quick Facts
- arXiv ID: 2306.09373
- Source URL: https://arxiv.org/abs/2306.09373
- Reference count: 5
- Primary result: EMTL method regularizes relative contribution of tasks (task-specific loss divided by gradient norm) to achieve equitable learning across multiple tasks, improving generalization performance and robustness.

## Executive Summary
This paper introduces EMTL (Equitable Multi-task Learning), a novel method to address the inequitable learning problem in multi-task learning (MTL). EMTL regularizes the relative contribution of different tasks in updating shared parameters by adding variance regularization on the metric of task-specific loss divided by its gradient norm. The authors theoretically prove that this variance regularization can improve MTL generalization performance. Extensive experiments on public benchmark datasets from Computer Vision and Recommendation domains, as well as industrial datasets, demonstrate EMTL's superiority and robustness compared to state-of-the-art methods.

## Method Summary
EMTL addresses the inequitable learning problem in MTL by regularizing the relative contribution of tasks. It first uses a Gradient Balancing Method (GBM) like MGDA to minimize gradient conflicts among tasks. Then, it adds variance regularization on the weighted relative contribution (αtLt/||gt||) to encourage equitable learning. EMTL integrates with MTL backbones like MMOE and PLE for recommendation tasks, and MTAN for scene understanding. The method balances both gradient and loss simultaneously, making it robust against large loss scale or gradient norm magnitude differences.

## Key Results
- EMTL stably outperforms state-of-the-art methods on public benchmark datasets (AliExpress, NYUv2) and industrial datasets.
- EMTL achieves more equitable learning across tasks compared to baselines, as evidenced by the reduced variance of relative contributions.
- EMTL is robust against large loss scale or gradient norm magnitude differences, maintaining stable performance across different scenarios.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Regularizing the variance of relative contribution (Lt/||gt||) improves generalization performance of MTL models.
- Mechanism: EMTL adds a variance regularization term to the MTL objective function, encouraging the relative contribution of each task to be more similar and preventing some tasks from being learned well while others are overlooked.
- Core assumption: The relative contribution (Lt/||gt||) is a meaningful metric for measuring the influence of each task on the shared parameters.
- Evidence anchors:
  - [abstract] "regularizing relative contribution of different tasks (i.e., value of task-specific loss divided by its raw gradient norm) in updating shared parameters"
  - [section] "We propose the thought to achieve equitable MTL and further improve MTL by regularizing relative contribution of tasks in updating shared parameters."
- Break condition: If the tasks have very different gradient norms or loss scales, the relative contribution metric may not accurately reflect the true influence of each task.

### Mechanism 2
- Claim: EMTL integrates GBM and variance regularization to efficiently solve the gradient conflict problem in MTL.
- Mechanism: EMTL first uses a GBM method (like MGDA) to get weights for each task that minimize gradient conflicts, then adds variance regularization on the weighted relative contribution (αtLt/||gt||).
- Core assumption: The GBM method can effectively reduce gradient conflicts among tasks.
- Evidence anchors:
  - [abstract] "We efficiently add variance regularization to make different tasks' relative contribution closer."
  - [section] "Firstly, simply sum all task losses commonly leading to some tasks suffer from performance degeneration, due to the gradient conflict. We can adopt existed GBM, like MGDA, to alleviate this problem."
- Break condition: If the GBM method fails to find a good set of weights that minimize gradient conflicts, the EMTL method may not improve the MTL performance.

### Mechanism 3
- Claim: EMTL is robust against large loss scale or gradient norm magnitude differences by balancing gradient and loss at the same time.
- Mechanism: EMTL uses the relative contribution metric (Lt/||gt||) which considers both the loss and gradient norm of each task. By regularizing the variance of this metric, EMTL can balance the influence of tasks with different loss scales or gradient norms.
- Core assumption: Balancing both loss and gradient norm is necessary for robust MTL.
- Evidence anchors:
  - [abstract] "Our method can balance gradient and loss simultaneously and is robust against to loss scale or gradient norm magnitude changes."
  - [section] "EMTL is robust against unbalanced loss or gradient norm, by balancing gradient and loss at same time."
- Break condition: If the tasks have very different loss scales or gradient norms, the balancing may not be sufficient to achieve good MTL performance.

- Component map:
  - Input layer: Task-specific input features
  - Shared layer: Common feature extractor for all tasks
  - Task-specific layers: Separate output layers for each task
  - Loss functions: Task-specific loss functions
  - EMTL module: Adds variance regularization on relative contribution

- Critical path:
  1. Compute task-specific losses and gradients
  2. Use GBM method to get weights for each task
  3. Compute relative contribution metric (αtLt/||gt||)
  4. Add variance regularization on relative contribution
  5. Update shared parameters using the regularized loss

- Design tradeoffs:
  - EMTL adds computational overhead due to the GBM method and variance regularization
  - EMTL requires tuning of the regularization strength hyperparameter
  - EMTL may not work well if the tasks have very different loss scales or gradient norms

- Failure signatures:
  - Some tasks consistently perform much worse than others
  - The MTL model converges to a suboptimal solution
  - The variance of relative contribution does not decrease during training

- First 3 experiments:
  1. Run EMTL on a simple MTL benchmark (e.g., NYUV2) and compare to baselines
  2. Test EMTL with different regularization strengths and analyze the effect on task performance

## Limitations
- Limited empirical evidence for the effectiveness of variance regularization on relative contribution in improving MTL generalization.
- The paper does not thoroughly discuss the impact of task-specific loss scales and gradient norms on EMTL's performance.
- EMTL's robustness against loss scale and gradient norm magnitude differences is claimed but not fully explored.

## Confidence
- High confidence in the problem formulation and the motivation for EMTL. The inequitable learning issue in MTL is well-established, and the proposed solution addresses a critical gap.
- Medium confidence in the theoretical analysis and the practical benefits of variance regularization on relative contribution. While the proof is provided, more empirical evidence is needed to fully validate the claims.
- Medium confidence in the robustness of EMTL against loss scale and gradient norm magnitude differences. The paper claims this property, but the underlying mechanisms and limitations are not fully explored.
