# Leveraging Task Dependency and Contrastive Learning for Case Outcome Classification on European Court of Human Rights Cases

## Quick Facts
- arXiv ID: 2302.00768
- Source URL: https://arxiv.org/abs/2302.00768
- Reference count: 19
- Key outcome: Multi-task model with hierarchical contrastive learning achieves consistent improvements over single-task and joint models without contrastive loss, particularly in macro-F1 and hard-macro-F1 scores for sparse classes.

## Executive Summary
This paper addresses legal judgment prediction (LJP) for European Court of Human Rights cases, specifically predicting which convention articles were violated based on case fact descriptions. The authors propose a multi-task approach that first predicts which articles were allegedly violated and then uses this information to predict which articles were actually found to be violated, capturing the dependency between these tasks at both feature and outcome levels. They also introduce a hierarchical contrastive loss to create distinctive article clusters in the latent space and further cluster cases within each article based on their outcomes. Experiments show that their model, given a static pre-trained encoder, achieves consistent improvements over single-task and joint models without contrastive loss, particularly in macro-F1 and hard-macro-F1 scores for sparse classes.

## Method Summary
The proposed method uses a hierarchical attention network with frozen LegalBERT embeddings to process case fact descriptions. The model creates article-specific representations through attention mechanisms, predicts allegation labels (Task B), then uses these predictions to enhance violation prediction (Task A) through feature concatenation. A hierarchical contrastive loss is applied at two levels: first to maximize distance between different article representations, then within each article to separate cases based on outcomes. The model is trained end-to-end with a combined loss function incorporating cross-entropy and contrastive losses.

## Key Results
- The proposed model achieves 5-6% improvements in macro-F1 and hard-macro-F1 metrics compared to single-task baselines
- Hierarchical contrastive learning creates distinctive article clusters in the latent space
- The task dependency approach shows particular utility for sparse classes (hard-macro-F1 improvements >5%)
- Using gold labels for allegation prediction improves violation prediction accuracy compared to using predicted labels

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Modeling task dependency between allegation and violation prediction improves performance by enabling feature and label information transfer.
- Mechanism: The model captures dependency at both feature and outcome levels by concatenating allegation-specific representations with violation features and predicted allegation labels.
- Core assumption: Information from the allegation prediction task contains relevant features that can improve violation prediction performance.
- Evidence anchors:
  - [abstract]: "We assess the dependency between these two tasks at the feature and outcome level."
  - [section 2]: "To capture both the inter-article correlations for allegation, violation prediction and the inter-task dependency... We utilize the task B allegation information to enhance task A violation prediction to capture the task dependency."
  - [corpus]: Weak - The corpus provides related papers but no direct evidence about task dependency mechanisms.
- Break condition: If the dependency between tasks is weak or if the feature representations from allegation prediction contain irrelevant information for violation prediction.

### Mechanism 2
- Claim: Hierarchical contrastive learning creates distinctive article clusters and outcome-based sub-clusters that improve representation quality.
- Mechanism: The model applies contrastive loss at two levels - first to maximize distance between different article representations, then within each article to separate cases based on outcomes.
- Core assumption: Forcing article representations to be distinct helps the model learn article-specific salient information more effectively.
- Evidence anchors:
  - [abstract]: "We leverage a hierarchical contrastive loss to pull together article specific representations of cases at the higher level, leading to distinctive article clusters."
  - [section 2.1]: "On the higher level, this is intended to form distinctive clusters of article-specific case representations... In the lower level, inside the latent space for each article, we further perform contrastive learning among cases based on their task outcome."
  - [corpus]: Weak - No direct corpus evidence about hierarchical contrastive learning for legal judgment prediction.
- Break condition: If the batch size is too small to provide meaningful negative samples, or if the temperature parameters are poorly tuned.

### Mechanism 3
- Claim: Article-specific attention mechanisms help extract relevant information for each article, improving performance on sparse classes.
- Mechanism: The model applies separate attention mechanisms for each article to emphasize sentences relevant to that specific article.
- Core assumption: Different articles require different information from case facts, and a single representation cannot capture all article-specific nuances.
- Evidence anchors:
  - [section 2]: "We disentangle the input case facts into multiple article-view-representations... Through this article-specific attention mechanism, sentences relevant to a specific article are emphasized."
  - [section 3.2]: "Our method performs better than the multi task architecture... It scores higher... with larger improvements (>5%) in task A macro-F1 and hard macro-F1 metrics. This suggests that our model is of particular utility for sparser classes."
  - [corpus]: Weak - No corpus evidence about article-specific attention mechanisms.
- Break condition: If the attention mechanisms fail to identify truly relevant sentences, or if the computational cost outweighs the performance benefits.

## Architecture Onboarding

- Component map:
  LegalBERT -> Sentence attention -> GRU -> Article-specific attention -> Task B attention -> Task B prediction -> Feature concatenation -> Task A attention -> Task A prediction

- Critical path: LegalBERT → Sentence attention → GRU → Article attention → Task B attention → Task B prediction → Feature concatenation → Task A attention → Task A prediction

- Design tradeoffs:
  - Freezing LegalBERT weights vs. fine-tuning: Chosen to evaluate dependency mechanisms in isolation but limits potential performance gains
  - Two-level contrastive learning vs. single level: Provides more granular clustering but increases complexity
  - Separate article representations vs. single shared representation: Better for sparse classes but increases parameter count

- Failure signatures:
  - Poor performance on Task B but good on Task A: Suggests feature transfer isn't working
  - Good performance on both tasks but worse than single-task baselines: Indicates task interference rather than beneficial transfer
  - Training instability or slow convergence: May indicate poorly tuned temperature parameters in contrastive loss

- First 3 experiments:
  1. Ablation study: Remove article-specific attention to test if single representation works as well
  2. Hyperparameter sweep: Test different temperature values for contrastive loss (τa, τc)
  3. Frozen encoder baseline: Compare with fine-tuned LegalBERT to measure impact of freezing weights

### Open Question 3

- What evidence would resolve it: Detailed analysis of cases where the allegation prediction was incorrect and how this affected the violation prediction accuracy
