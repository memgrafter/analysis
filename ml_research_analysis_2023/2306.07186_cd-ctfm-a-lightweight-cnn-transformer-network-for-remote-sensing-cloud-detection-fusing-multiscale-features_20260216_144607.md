# CD-CTFM: A Lightweight CNN-Transformer Network for Remote Sensing Cloud Detection Fusing Multiscale Features

## Quick Facts
- arXiv ID: 2306.07186
- Source URL: https://arxiv.org/abs/2306.07186
- Reference count: 18
- Achieves mIoU scores of 84.13% and 84.77% on 38-Cloud and MODIS datasets respectively, with only 2.77M parameters and 0.40-0.42 GFLOPS

## Executive Summary
CD-CTFM is a lightweight CNN-Transformer network designed for efficient remote sensing cloud detection. The model addresses the computational challenges of existing cloud detection methods by combining an encoder-decoder architecture with a lightweight CNN-Transformer backbone. It incorporates a feature pyramid module for multiscale feature fusion and a channel-spatial attention mechanism to enhance feature extraction. The approach achieves competitive accuracy while significantly reducing parameters and computational requirements.

## Method Summary
The CD-CTFM model employs an encoder-decoder architecture with a lightweight CNN-Transformer backbone that extracts both local and global features. A lightweight feature pyramid module fuses multiscale features, while a channel-spatial attention module enhances feature extraction. The model was evaluated on the 38-Cloud and MODIS datasets, demonstrating comparable accuracy to state-of-the-art methods while using only 2.77M parameters and 0.40-0.42 GFLOPS.

## Key Results
- Achieves mIoU scores of 84.13% on 38-Cloud and 84.77% on MODIS datasets
- Uses only 2.77M parameters, significantly fewer than existing methods
- Maintains computational efficiency at 0.40-0.42 GFLOPS
- Outperforms or matches existing methods in both accuracy and efficiency

## Why This Works (Mechanism)
CD-CTFM's effectiveness stems from its hybrid architecture that combines the strengths of CNNs for local feature extraction with Transformers for global context understanding. The lightweight feature pyramid module enables effective multiscale feature fusion, while the channel-spatial attention mechanism enhances important features. This design allows the model to achieve high accuracy while maintaining computational efficiency through parameter reduction.
