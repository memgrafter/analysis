# Paint it Black: Generating paintings from text descriptions

## Quick Facts
- arXiv ID: 2302.08808
- Source URL: https://arxiv.org/abs/2302.08808
- Reference count: 26
- The paper explores generating paintings from text descriptions using two approaches: (1) generating photorealistic images with SSA-GAN trained on COCO and applying neural style transfer to make them look like paintings, and (2) fine-tuning SSA-GAN on a custom dataset of captioned paintings created from WikiArt using an image captioning model. The models are evaluated using FID scores, SOA scores, and a human survey. FID scores indicate the style transfer approach produces lower quality paintings than fine-tuning, but fine-tuning suffers from caption accuracy issues, particularly with objects not typically found in paintings. The human survey found that fine-tuned images were perceived as more realistic than style-transferred ones, but style transfer achieved higher caption accuracy. Overall, the results show a trade-off between painting quality and caption accuracy, with neither approach fully satisfying both objectives.

## Executive Summary
This paper investigates two methods for generating paintings from text descriptions: style transfer applied to photorealistic images and fine-tuning a GAN on captioned paintings. The style transfer approach uses SSA-GAN trained on COCO to generate photorealistic images, which are then stylized using neural style transfer with paintings from WikiArt. The fine-tuning approach generates captions for WikiArt paintings using a pre-trained NIC model, then fine-tunes SSA-GAN on this captioned dataset. The models are evaluated using FID scores for image quality, SOA scores for caption accuracy, and a human survey. Results show that while fine-tuning produces more painting-like images, it struggles with caption accuracy for objects not typically found in paintings. Style transfer maintains better caption accuracy but produces lower quality paintings.

## Method Summary
The paper proposes two approaches to generate paintings from text descriptions. The first approach generates photorealistic images using SSA-GAN trained on COCO, then applies fast neural style transfer using selected paintings from WikiArt to create painting-like outputs. The second approach fine-tunes SSA-GAN on a custom dataset of captioned paintings created by generating captions for WikiArt images using a pre-trained NIC model. Both approaches are evaluated using FID scores for image quality, SOA scores for caption accuracy, and a human survey to assess overall quality and caption alignment.

## Key Results
- Fine-tuning SSA-GAN on captioned paintings produces more painting-like images than style transfer, as indicated by higher FID scores
- Style transfer approach achieves better caption accuracy (higher SOA scores) than fine-tuning
- Human survey shows fine-tuned images are perceived as more realistic, but the difference is not dramatic
- Caption accuracy is particularly problematic for fine-tuning when objects are not typically found in paintings
- There is a clear trade-off between painting quality and caption accuracy, with neither approach fully satisfying both objectives

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Fine-tuning SSA-GAN on captioned paintings enables the model to generate painting-style images that align with text descriptions.
- Mechanism: Pre-training on COCO gives the model a strong understanding of real-world objects and their textual associations. Fine-tuning on paintings with captions transfers this knowledge into the painting domain while maintaining the semantic mapping between text and visual content.
- Core assumption: The captioned paintings dataset provides sufficient visual-textual alignment examples for the model to learn the mapping.
- Evidence anchors:
  - [section] "We use the SSA-GAN again. Now that it is already trained on COCO, we can fine-tune it with the captioned painting data in order for the model to generate paintings directly instead of photorealistic images."
  - [section] "The advantage of this is that the model already knows the 80 object classes that it learnt when training with the COCO dataset and by fine-tuning we hope that might be able to transfer this knowledge to the final paintings."
- Break condition: If the captioned paintings dataset contains inaccurate captions or lacks diversity in painting styles, the fine-tuning process will fail to produce coherent painting-text alignments.

### Mechanism 2
- Claim: Style transfer applied to photorealistic images generates painting-like outputs that preserve text-prompt content.
- Mechanism: Generate a photorealistic image from text using a pre-trained T2I model, then apply fast neural style transfer using a painting style image. The histogram intersection algorithm selects the most color-compatible style painting to minimize semantic distortion.
- Core assumption: The style transfer process does not significantly alter the content of the generated image beyond aesthetic changes.
- Evidence anchors:
  - [section] "In a separate step, we apply neural style transfer [3] to this image to make it look like a painting."
  - [section] "We selected 30 paintings of varying styles from the WikiArt [15] dataset... and trained a stylization model for each of them."
- Break condition: If the style transfer introduces artifacts or the selected style painting has incompatible colors, the generated output may lose text-prompt alignment or appear unrealistic.

### Mechanism 3
- Claim: Caption accuracy evaluation using SOA scores reveals the trade-off between painting quality and caption fidelity.
- Mechanism: SOA scores use an object detector to verify whether generated images contain the objects specified in the text prompt. This metric isolates caption accuracy from overall image quality, allowing comparison between approaches.
- Core assumption: The object detector used for SOA evaluation can recognize objects in generated paintings, even if they are stylized.
- Evidence anchors:
  - [section] "SOA is a novel evaluation metric for T2I synthesis models that tries to tackle this issue by using an object detector to evaluate if a generated image contains the objects that it is supposed to contain according to the caption."
  - [section] "Table 1 shows the results of the SOA scores we have achieved. It indicates the percentage of images that actually contain the main object mentioned in the caption."
- Break condition: If the object detector is not trained on paintings, it may fail to recognize objects in stylized outputs, leading to artificially low SOA scores.

## Architecture Onboarding

- Component map:
  - SSA-GAN (backbone T2I model)
  - Pre-trained text encoder (bidirectional LSTM)
  - Style transfer models (30 trained on WikiArt paintings)
  - Histogram intersection algorithm (style selection)
  - NIC model (for generating captions on WikiArt)
  - Object detector (for SOA evaluation)

- Critical path:
  1. Generate photorealistic image from text (SSA-GAN)
  2. Select appropriate style painting (histogram intersection)
  3. Apply fast style transfer
  4. Evaluate using FID, SOA, and human survey

- Design tradeoffs:
  - Fine-tuning vs. style transfer: Fine-tuning produces more painting-like images but loses modern object recognition; style transfer preserves content but may introduce artifacts.
  - Caption quality: Automatic captioning introduces errors that propagate through fine-tuning, affecting caption accuracy.
  - Computational cost: Fast style transfer is efficient but may sacrifice quality compared to the original approach.

- Failure signatures:
  - Low SOA scores indicate caption-content misalignment
  - High FID scores with low human realism ratings indicate poor image quality
  - Artifacts in style-transferred images indicate style painting incompatibility

- First 3 experiments:
  1. Generate images using SSA-GAN pre-trained on COCO to establish baseline
  2. Apply style transfer to COCO-generated images using different WikiArt styles
  3. Fine-tune SSA-GAN on captioned WikiArt dataset for varying numbers of epochs (10, 20, 30) to find optimal balance between quality and caption accuracy

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal balance between painting quality and caption accuracy when fine-tuning SSA-GAN on captioned paintings, and how does this trade-off vary with the duration of fine-tuning?
- Basis in paper: [explicit] The paper discusses the trade-off between painting quality and caption accuracy, noting that fine-tuning produces convincing nature scenes and learns the style of baroque portraits but struggles with objects not typically found in paintings.
- Why unresolved: The paper mentions the trade-off but does not provide a clear optimal point or how it varies with fine-tuning duration.
- What evidence would resolve it: Systematic experiments varying fine-tuning duration and measuring both painting quality (using FID scores) and caption accuracy (using SOA scores) to identify the optimal balance point.

### Open Question 2
- Question: How does the quality of automatically generated captions for paintings impact the performance of the fine-tuning approach in generating paintings from text descriptions?
- Basis in paper: [explicit] The paper highlights that the NIC model used for captioning paintings had low accuracy, with examples of misclassifications like a skull being identified as a teddy bear.
- Why unresolved: The paper acknowledges the issue with caption accuracy but does not explore how improving caption quality would affect the fine-tuning approach's performance.
- What evidence would resolve it: Experiments using manually cleaned or more accurate captions for the WikiArt dataset and comparing the performance of the fine-tuned model with the original approach.

### Open Question 3
- Question: Would using the original style transfer model instead of the fast style transfer model improve the quality of paintings generated by the style transfer approach?
- Basis in paper: [explicit] The paper suggests that the fast style transfer model introduces artefacts and lowers the resemblance to real artworks, and mentions that the original style transfer could yield better results.
- Why unresolved: The paper did not use the original style transfer model due to time constraints and did not compare the results.
- What evidence would resolve it: Implementing the original style transfer model and comparing the FID and SOA scores of the generated paintings with those produced by the fast style transfer model.

## Limitations

- The trade-off between painting quality and caption accuracy is the primary limitation, with neither approach fully satisfying both objectives
- Caption accuracy is particularly problematic for fine-tuning when objects are not typically found in paintings
- The study relies on automatic captioning for the WikiArt dataset, which may introduce errors that propagate through the fine-tuning process

## Confidence

- **High confidence**: The comparative analysis between fine-tuning and style transfer approaches, as evidenced by the consistent patterns in FID scores, SOA scores, and human survey results. The trade-off between painting quality and caption accuracy is clearly demonstrated.
- **Medium confidence**: The effectiveness of the fine-tuning approach, as caption accuracy varies significantly depending on the objects mentioned in the text prompts. The study acknowledges that the captioning model may not accurately capture all relevant information.
- **Low confidence**: The generalizability of the results, as the study is limited to a specific set of text prompts and painting styles. The human survey sample size and demographic may not be representative of broader preferences.
