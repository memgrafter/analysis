# Low Complexity Approaches for End-to-End Latency Prediction

## Quick Facts
- arXiv ID: 2302.00004
- Source URL: https://arxiv.org/abs/2302.00004
- Reference count: 17
- Primary result: 1.77% MAPE with 0.306s inference time using sampling optimization method

## Executive Summary
This paper addresses the challenge of end-to-end latency prediction in SDN networks by proposing low complexity machine learning approaches. The authors develop a comprehensive methodology that leverages queue theory principles to extract meaningful features from network data, then applies various regression techniques to predict latency with minimal computational overhead. Their approach achieves competitive accuracy while significantly reducing training and inference times compared to state-of-the-art graph neural network solutions, making it particularly suitable for real-time network monitoring and optimization scenarios.

## Method Summary
The methodology begins with feature engineering based on queue theory, extracting four key features (π0, L, Se, and ρe) from the ITU GNN Challenge 2021 dataset. These features capture essential network characteristics including topology, link properties, traffic patterns, and routing information. The authors then evaluate multiple regression approaches including linear regression, gradient boosting regression trees (GBRT), random forest, and specialized curve-fitting methods. The curve-fitting techniques include exponential of polynomial, generative polynomials, and implicit function formulations. A critical component is the sampling optimization method with N=12 points and α parameter tuning, which achieves the best trade-off between accuracy and computational efficiency.

## Key Results
- Achieves 1.77% MAPE (Mean Absolute Percentage Error) on end-to-end latency prediction
- Inference time of 0.306 seconds, significantly faster than GNN-based approaches
- Uses only 24 parameters in the optimal sampling optimization method
- Maintains competitive accuracy with substantially lower computational complexity

## Why This Works (Mechanism)
The approach works by combining domain knowledge from queue theory with machine learning regression techniques. The queue theory-based features capture the fundamental relationships between network load, topology, and latency. By using regression methods instead of complex graph neural networks, the computational overhead is dramatically reduced while maintaining predictive accuracy. The sampling optimization method effectively balances the trade-off between model complexity and prediction accuracy through careful parameter tuning.
