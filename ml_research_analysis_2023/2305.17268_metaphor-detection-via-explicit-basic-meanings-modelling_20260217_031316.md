# Metaphor Detection via Explicit Basic Meanings Modelling

## Quick Facts
- arXiv ID: 2305.17268
- Source URL: https://arxiv.org/abs/2305.17268
- Reference count: 4
- Key outcome: BasicBERT model outperforms state-of-the-art baselines by 1.0% F1 score on metaphor detection benchmarks

## Executive Summary
This paper presents BasicBERT, a metaphor detection method that explicitly models basic meanings of target words by contrasting contextual meanings with representations learned from literal annotations in training data. The model combines three components: BasicMIP (contrast between contextual and basic meaning), AMIP (contrast between contextual and decontextualized embeddings), and SPV (incongruity between target and sentence context). Experiments on VUA18 and VUA20 benchmarks show significant improvements over existing methods, with the model reaching theoretical upper bound performance on targets with basic annotations.

## Method Summary
The BasicBERT model uses RoBERTa as a backbone encoder to contextualize target words within sentences. For each target, it constructs basic meaning representations by averaging literal instance embeddings from the training set, then contrasts these with contextual embeddings using cosine distance (BasicMIP). When literal annotations are unavailable, it falls back to decontextualized RoBERTa embeddings (AMIP approach). An additional SPV component measures incongruity between target meaning and sentence context using the CLS token embedding. The three components' outputs are concatenated and passed through a prediction layer to classify metaphors.

## Key Results
- BasicBERT achieves 1.0% higher F1 score than state-of-the-art baselines on metaphor detection benchmarks
- On VUA18, the model reaches theoretical upper bound for targets with basic annotations
- BasicMIP gains 1.4% F1 improvement over AMIP specifically for targets with literal annotations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Basic meaning representations are more contrastive with contextual meanings for metaphor detection than aggregated meaning representations.
- Mechanism: The model constructs basic meaning embeddings by averaging representations of literal instances from training data, then contrasts these with contextual embeddings using cosine distance.
- Core assumption: Basic meanings are well-represented by literal annotations in the training data.
- Evidence anchors:
  - [abstract]: "Our performance even reaches the theoretical upper bound on the VUA18 benchmark for targets with basic annotations"
  - [section 4]: "We find BasicBERT gains significant improvement on targets with literal annotations from VUA20 via basic meaning modelling by 1.4% in F1 score"
  - [corpus]: Weak - no direct corpus evidence for contrast quality between basic and aggregated meanings
- Break condition: If literal annotations are sparse or unrepresentative of true basic meanings, the basic meaning representations become unreliable.

### Mechanism 2
- Claim: The combination of BasicMIP and AMIP components improves performance on targets without literal annotations.
- Mechanism: When a target has no literal annotations, the model falls back to using decontextualized RoBERTa embeddings (AMIP approach) as the basic meaning representation.
- Core assumption: Decontextualized embeddings can serve as a reasonable approximation of basic meaning when literal annotations are unavailable.
- Evidence anchors:
  - [section 2.1]: "For target words which have no literal annotations in the training set, we return the decontextualised target representation as the basic meaning vector in the BasicMIP module"
  - [section 4]: "there are 13% of samples in the VUA18 test set for which we cannot find a corresponding basic meaning annotation from training set"
  - [corpus]: No corpus evidence provided for effectiveness of this fallback mechanism
- Break condition: If decontextualized embeddings poorly represent basic meanings, performance on targets without literal annotations will degrade.

### Mechanism 3
- Claim: SPV theory contributes additional useful features for metaphor detection.
- Mechanism: SPV measures incongruity between contextual target meaning and sentence-level context using the CLS token embedding.
- Core assumption: Incongruity between target and context is a reliable indicator of metaphoricity.
- Evidence anchors:
  - [section 2.2]: "The SPV theory is also employed which measures the incongruity between the contextual meaning of the target and its context"
  - [section 4]: Table 3 shows that SPV features have higher contrast between metaphor and literal cases than AMIP features
  - [corpus]: No corpus evidence provided for effectiveness of SPV features specifically
- Break condition: If contextual target meanings and sentence embeddings are not sufficiently discriminative, SPV features may not improve detection.

## Architecture Onboarding

- Component map: Input sentence with target word -> RoBERTa contextualization -> BasicMIP/AMIP/SPV feature extraction -> Concatenation -> Prediction layer -> Output

- Critical path: Input → RoBERTa contextualization → BasicMIP/AMIP/SPV feature extraction → Concatenation → Prediction layer → Output

- Design tradeoffs: The model trades off complexity (three parallel components) for improved performance on targets with literal annotations versus a simpler unified approach.

- Failure signatures: If basic meaning annotations are sparse, the BasicMIP component will frequently fall back to AMIP, reducing the model's advantage. If SPV features don't capture meaningful incongruity, they may add noise.

- First 3 experiments:
  1. Test model performance on targets with and without literal annotations separately to quantify BasicMIP's contribution.
  2. Compare contrast scores (cosine distances) between BasicMIP and AMIP features for metaphor vs. literal cases.
  3. Perform ablation study removing each component (BasicMIP, AMIP, SPV) to measure individual contributions to overall performance.

## Limitations

- The model's performance heavily depends on the availability of literal annotations in training data, with only 13% of test samples lacking such annotations.
- The effectiveness of the fallback mechanism using decontextualized embeddings for targets without literal annotations is asserted but not empirically validated.
- The paper lacks comprehensive ablation studies to isolate the individual contributions of each component to overall performance.

## Confidence

- High confidence: The model architecture is clearly described, and the use of RoBERTa as a backbone encoder is standard practice. The performance improvement over baselines on the VUA18 dataset is well-documented with specific F1 scores.
- Medium confidence: The theoretical justification for why basic meaning representations are more contrastive than aggregated representations is sound, but lacks direct empirical validation. The claim that the model reaches "theoretical upper bound" for annotated targets is plausible given the methodology but difficult to verify independently.
- Low confidence: The effectiveness of the fallback mechanism using decontextualized embeddings for targets without literal annotations is asserted but not empirically validated. The contribution of SPV features to overall performance is stated but not demonstrated through ablation studies.

## Next Checks

1. **Ablation study with statistical significance testing**: Remove each component (BasicMIP, AMIP, SPV) from the model and measure the impact on F1 score with confidence intervals. This would quantify the actual contribution of each component rather than relying on contrast measurements alone.

2. **Performance analysis on targets without literal annotations**: Conduct a detailed breakdown of model performance on targets lacking literal annotations in the training set, comparing against a baseline that uses only decontextualized embeddings. This would validate whether the fallback mechanism provides meaningful improvement.

3. **Cross-dataset generalization test**: Evaluate the model on an independent metaphor detection dataset (such as TroFi or MOH) without retraining to assess whether the basic meaning representations learned from VUA annotations generalize to other domains and annotation schemes.
