# TQ-Net: Mixed Contrastive Representation Learning For Heterogeneous Test Questions
## Quick Facts
- arXiv ID: 2303.08039
- Source URL: https://arxiv.org/abs/2303.08039
- Reference count: 8
- Primary result: +2.02% P@5 and +7.20% F1 score improvements over baselines for heterogeneous test question representation

## Executive Summary
This paper addresses the challenge of representing heterogeneous, multi-modal test questions containing both text and images for educational applications. The authors propose TQ-Net, a model that fuses text and image content using a coordinated representation fusion strategy and instance-level contrastive learning. To improve text-only representations, they introduce a two-stage unsupervised pre-training method called MCL (Mixture Unsupervised Contrastive Learning), which combines masked language model pre-training with contrastive learning. The proposed supervised contrastive learning (SCL) framework further enhances representation learning for relevance prediction tasks. Experiments on large-scale datasets demonstrate significant improvements in downstream tasks: similar questions (+2.02% precision) and knowledge point prediction (+7.20% F1 score) compared to previous methods.

## Method Summary
TQ-Net employs a two-stage unsupervised contrastive learning approach followed by supervised fine-tuning. The first stage uses Masked Language Model (MLM) pre-training on text data, while the second stage applies contrastive learning with both sequential (SEQ) and universal (UNI) augmentation strategies. The model architecture combines a ResNet-50 image encoder with a BERT text encoder, fused through a multi-head attention mechanism. Supervised contrastive learning (SCL) is then applied using human-labeled similar question pairs for relevance prediction. The approach handles both text-only and image-containing questions through coordinated representation learning.

## Key Results
- Similar question classification: +2.02% precision at top-5 (P@5) compared to previous methods
- Knowledge point prediction: +7.20% F1 score improvement over baseline approaches
- Ablation studies confirm effectiveness of two-stage pre-training and multi-head attention fusion

## Why This Works (Mechanism)
The paper addresses heterogeneous test question representation by learning unified embeddings that capture both text and image semantics through coordinated contrastive learning. The two-stage pre-training strategy first establishes strong text representations through MLM, then refines them through contrastive learning that explicitly encourages semantic similarity between related questions while separating unrelated ones. The multi-head attention fusion module allows the model to learn optimal combination strategies for different types of question pairs, enabling effective handling of both text-only and image-containing questions within the same framework.

## Foundational Learning
- **Contrastive Learning**: Needed to learn semantic similarity between related questions; quick check: verify loss convergence and embedding separation in representation space
- **Multi-head Attention**: Required for effective fusion of text and image representations; quick check: inspect attention weight distributions across heads
- **Masked Language Model**: Establishes initial text representation capability; quick check: measure masked token prediction accuracy during pre-training
- **Momentum Contrast**: Maintains stable negative sample queue for contrastive learning; quick check: monitor queue update consistency across training steps
- **Supervised Contrastive Learning**: Refines representations using human-labeled similarity pairs; quick check: verify gradient flow through similarity labels

## Architecture Onboarding
- **Component Map**: Input (Text/Image) -> Text Encoder (BERT) + Image Encoder (ResNet-50) -> Multi-head Attention Fusion -> Contrastive Loss -> Unified Representation
- **Critical Path**: Text/image encoding → fusion → contrastive loss computation → representation update
- **Design Tradeoffs**: Two-stage pre-training adds complexity but improves text representation quality; multi-head attention provides flexibility but increases computational cost
- **Failure Signatures**: Poor convergence in contrastive loss suggests temperature or queue size issues; suboptimal fusion performance indicates attention weight initialization problems
- **First Experiments**: 1) Validate individual encoder performance on unimodal tasks, 2) Test fusion module with synthetic paired data, 3) Verify contrastive loss behavior with known similar/dissimilar pairs
