# CerviFormer: A Pap-smear based cervical cancer classification method using cross attention and latent transformer

## Quick Facts
- arXiv ID: 2303.10222
- Source URL: https://arxiv.org/abs/2303.10222
- Reference count: 40
- Primary result: Achieves 93.70% accuracy on three-class classification (Sipakmed) and 94.57% on two-class classification (Herlev)

## Executive Summary
This study presents CerviFormer, a novel cross-attention-based Transformer model for classifying cervical cancer in Pap smear images. The model addresses the challenge of high-dimensional image input by using an asymmetric attention mechanism that projects data into a lower-dimensional latent space, avoiding the quadratic complexity typical of standard Transformers. It employs iterative cross-attention and self-attention operations to efficiently extract and refine features. Evaluated on the Sipakmed and Herlev datasets, CerviFormer achieved 93.70% accuracy on three-class classification (Sipakmed) and 94.57% on two-class classification (Herlev).

## Method Summary
CerviFormer uses a cross-attention mechanism to project high-dimensional Pap smear image data into a lower-dimensional latent space (256 dimensions), enabling efficient processing with Transformer architectures. The model employs an asymmetric attention mechanism where queries come from a small latent array while keys and values come from the input, reducing computational complexity from O(M²) to O(MN). It uses iterative cross-attention and self-attention operations to extract and refine features, with multiple cycles of alternating cross-attention (input to latent) and self-attention (within latent Transformer) to progressively improve feature representation.

## Key Results
- Achieves 93.70% accuracy on three-class classification (normal, abnormal, benign) using Sipakmed dataset
- Achieves 94.57% accuracy on two-class classification (normal, abnormal) using Herlev dataset
- Outperforms several state-of-the-art approaches for cervical cancer classification from Pap smear images

- Mechanism: The model projects the high-dimensional input data array into a lower-dimensional latent bottleneck using asymmetric attention, where the query comes from a small latent array and keys/values come from the input. This enables iterative cross-attention and self-attention operations to extract and refine features efficiently.
- Core assumption: The latent bottleneck (N=256) contains sufficient information to represent the input data effectively for classification.

### Mechanism 2
- Claim: Iterative cross-attention and self-attention operations progressively refine features in the latent space, improving classification accuracy.
- Mechanism: The model alternately applies cross-attention to extract information from the input into the latent space, then applies self-attention within the latent Transformer to refine this representation. This process repeats iteratively to progressively improve the feature representation.
- Core assumption: Multiple iterations of attention operations improve feature extraction more than a single pass.
- Evidence anchors:
  - [abstract] "It employs iterative cross-attention and self-attention operations to efficiently extract and refine features."
  - [section] "The model alternately uses the cross-attention module and latent Transformer block... ### Mechanism 3
- Claim: The asymmetric attention mechanism allows building deeper networks without quadratic scaling, enabling effective classification of complex cervical cancer patterns.
- Mechanism: By decoupling the network depth from input size through the latent bottleneck, the model can use deep Transformer architectures that would be computationally prohibitive on raw image data, capturing complex patterns in cervical cell morphology.
- Core assumption: Deep Transformer architectures are more effective at capturing complex visual patterns than shallow networks or traditional CNNs for this specific task.
- Evidence anchors:
  - [abstract] "The proposed method brings forth a comprehensive classification model to detect cervical cancer in Pap smear images."
  - [section] "The complexity of Transformers structured directly on the input data has complexity O(LM²), whereas a Transformer built in latent space has complexity O(LN²)... This enables us to develop very deep networks on large amounts of data."

## Architecture Onboarding

- Component map:
  Input image -> preprocessing -> flatten into patches -> cross-attention with latent array -> self-attention in latent Transformer -> repeat for multiple iterations -> final latent representation -> classification

- Critical path:
  1. Input image → preprocessing
  2. Flatten into patches → cross-attention with latent array
  3. Self-attention in latent Transformer
  4. Repeat steps 2-3 for multiple iterations
  5. Final latent representation → classification

- Design tradeoffs:
  - Latent bottleneck size (N=256) balances computational efficiency with information retention
  - Number of iterations trades off between computational cost and feature refinement quality
  - Patch size affects spatial resolution preservation vs. computational load

- Failure signatures:
  - Overfitting: High training accuracy but low test accuracy (check confusion matrices)
  - Underfitting: Low accuracy on both training and test sets
  - Information bottleneck: Performance plateaus despite increasing iterations, suggesting latent dimension is too small

- First 3 experiments:
  1. Test with varying latent bottleneck dimensions (e.g., 128, 256, 512) to find optimal balance
  2. Compare performance with different numbers of iterative cycles (e.g., 1, 3, 5)
  3. Validate on held-out test sets from both Sipakmed and Herlev datasets to confirm generalization

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the CerviFormer model perform on cervical cancer classification using ThinPrep images instead of Pap smear images?
- Basis in paper: [explicit] The authors mention that "Future studies will also test the method on ThinPrep images" as a direction for future work.
- Why unresolved: The study only evaluated the model on Pap smear images from the Sipakmed and Herlev datasets, not on ThinPrep images.
- What evidence would resolve it: Testing the CerviFormer model on a ThinPrep image dataset and comparing its performance metrics (accuracy, precision, recall, F1-score) to those achieved on Pap smear images.

### Open Question 2
- Question: How would incorporating confounding factors such as menstrual cycle and age affect the accuracy of the automated cervical cancer classification system?
- Basis in paper: [explicit] The authors state that "this method is inefficient in tackling confounding factors such as menstrual cycle and age which can also affect the output of the system."
- Why unresolved: The current study did not account for these confounding factors in the model development or evaluation.
- What evidence would resolve it: Developing and testing an enhanced version of the CerviFormer model that includes menstrual cycle and age as additional features, then comparing its performance to the original model.

### Open Question 3
- Question: What is the optimal number of iterations for the cross-attention and latent Transformer modules to achieve the best balance between computational efficiency and classification accuracy?
- Basis in paper: [inferred] The authors mention that "The model could be constructed with numerous cross-attention layers to lessen this effect" and discuss weight sharing between consecutive modules, suggesting that the number of iterations is a tunable parameter.
- Why unresolved: The study used a fixed number of iterations without exploring how varying this parameter affects model performance.
- What evidence would resolve it: Conducting an ablation study that tests different numbers of cross-attention and latent Transformer iterations, measuring the trade-off between computational cost and classification metrics.

## Limitations
- Evaluation is limited to two relatively small medical imaging datasets, which may not fully represent real-world clinical diversity
- Lacks ablation studies to isolate the contribution of the cross-attention mechanism versus other architectural choices
- No external validation on independent clinical datasets to assess generalization beyond the studied datasets

## Confidence
**High Confidence**: The computational efficiency claims regarding O(MN) complexity versus O(M²) for standard Transformers are mathematically sound and well-supported by the theoretical framework presented.

**Medium Confidence**: The classification performance metrics (93.70% accuracy on Sipakmed, 94.57% on Herlev) are credible given the controlled experimental conditions, but the lack of comparison to state-of-the-art methods from recent years limits confidence in the claimed superiority.

**Low Confidence**: The claims about iterative cross-attention and self-attention progressively improving feature representation lack empirical validation through ablation studies showing the specific contribution of each iteration.
