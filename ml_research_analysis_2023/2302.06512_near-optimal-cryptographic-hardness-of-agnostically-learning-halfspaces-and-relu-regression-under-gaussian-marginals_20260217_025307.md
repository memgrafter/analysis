# Near-Optimal Cryptographic Hardness of Agnostically Learning Halfspaces and ReLU Regression under Gaussian Marginals

## Quick Facts
- arXiv ID: 2302.06512
- Source URL: https://arxiv.org/abs/2302.06512
- Reference count: 40
- Proves near-optimal computational hardness for agnostically learning halfspaces and ReLU regression under Gaussian marginals, assuming sub-exponential LWE hardness

## Executive Summary
This paper establishes near-optimal computational hardness results for two fundamental learning problems: agnostically learning halfspaces and ReLU regression, both under Gaussian marginals. The authors prove that achieving error OPT+ε requires time at least n^Ω(1/(ε√logn)α) for halfspaces and n^Ω(1/(εlog²n)α) for ReLU regression, where α<2 for halfspaces and α<1/2 for ReLU regression. These lower bounds nearly match the best known algorithms, which run in time n^poly(1/ε), demonstrating that current algorithms are essentially optimal under the LWE assumption.

## Method Summary
The authors employ a reduction from the Learning with Errors (LWE) problem to establish computational hardness for both learning problems. This reduction leverages techniques from prior work on continuous LWE and distribution-independent learning, connecting cryptographic hardness assumptions to statistical learning problems. The approach involves constructing instances of the learning problems that encode LWE instances, such that solving the learning problem efficiently would yield an efficient algorithm for LWE.

## Key Results
- For halfspaces, any algorithm achieving error OPT+ε requires time at least n^Ω(1/(ε√logn)α) for any constant α<2 and sufficiently small ε
- For ReLU regression, the time lower bound is n^Ω(1/(εlog²n)α) for any constant α<1/2 and sufficiently small ε
- These bounds nearly match the best known algorithms, which run in time n^poly(1/ε)

## Why This Works (Mechanism)
The mechanism underlying these hardness results relies on a carefully constructed reduction from the Learning with Errors (LWE) problem to the learning tasks. The reduction exploits the computational hardness of distinguishing noisy linear equations from random samples in LWE to create learning instances that are equally hard to solve. For halfspaces, the reduction leverages the geometric properties of separating hyperplanes under Gaussian marginals, while for ReLU regression, it exploits the non-linear activation function's behavior with Gaussian inputs. The parameter bounds (α<2 for halfspaces, α<1/2 for ReLU) emerge from the specific structural constraints in each reduction, ensuring that any algorithm solving these learning problems would also solve LWE instances, thereby violating its assumed hardness.
