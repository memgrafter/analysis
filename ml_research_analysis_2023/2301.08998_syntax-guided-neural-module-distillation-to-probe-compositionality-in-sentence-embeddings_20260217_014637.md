# Syntax-guided Neural Module Distillation to Probe Compositionality in Sentence Embeddings

## Quick Facts
- arXiv ID: 2301.08998
- Source URL: https://arxiv.org/abs/2301.08998
- Reference count: 8
- Primary result: GTR-T5-xl shows highest distillability to syntax-guided neural module networks among tested sentence embedding models.

## Executive Summary
This paper introduces Syntax-guided Neural Module Nets (SynNaMoN) as a novel probing technique to assess compositionality in sentence embedding models. The approach constructs a neural module network based on a sentence's syntax parse and trains it to approximate the sentence's embedding from a transformer model. The distillability of a transformer to SynNaMoN captures how well syntax explains the model's compositional ability. Experiments with 5 sentence embedding models and 3 SynNaMoN architectures reveal that GTR-T5-xl is most compositional, model size doesn't considerably affect distillability, and much syntax-guided composition is linear.

## Method Summary
The method constructs a neural module network for each sentence based on its syntax parse, with one module per unique syntax rule. Each module receives concatenated embeddings of its constituents as input and produces a composed embedding. The entire SynNaMoN is trained end-to-end to approximate the sentence's embedding from a transformer model, minimizing MSE loss. Three architectures are tested: Linear (single linear layer), Nonlin (linear layer + nonlinearity), and Double (two linear layers with nonlinearity). The approach is evaluated on 5 sentence embedding models using Penn Treebank data, with distillability measured by normalized MSE between original and SynNaMoN-approximated embeddings.

## Key Results
- GTR-T5-xl demonstrates highest distillability to SynNaMoN among tested models
- Model size doesn't considerably affect distillability to SynNaMoN
- Syntax-guided composition is primarily linear, with minimal improvement from adding nonlinearities

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SynNaMoN captures compositional structure by mapping syntactic rules to learnable modules that transform concatenated child embeddings into parent embeddings.
- Core assumption: Syntax rules provide sufficient inductive bias to capture the compositional structure of sentence embeddings from transformer models.
- Evidence anchors: Abstract describes constructing neural module nets based on syntax parses to approximate transformer embeddings; section explains modules receive concatenated constituent embeddings as input.

### Mechanism 2
- Claim: Distillability of a transformer to SynNaMoN indicates how well syntax explains the transformer's compositional ability.
- Core assumption: If a transformer's compositional behavior can be well-approximated by syntax-guided composition, this indicates the transformer uses syntax as a primary mechanism for composition.
- Evidence anchors: Abstract states distillability captures whether syntax is a strong causal model of compositional ability; section explains distillability tells us about internal syntax representations.

### Mechanism 3
- Claim: Comparing different module architectures reveals the geometry of semantic composition under syntax.
- Core assumption: The difference in distillability between module architectures reveals whether syntax-guided composition is linear or requires nonlinearities.
- Evidence anchors: Abstract addresses geometry of semantic composition by specifying modules' internal architecture and linearity; section explores architectures to see if syntax is enough for linear approximation.

## Architecture Onboarding

- Component map: Syntax parser (PTB format) → Module construction (one module per syntax rule) → Module architecture (Linear/Nonlin/Double) → Training to approximate transformer embeddings → Evaluation via MSE loss

- Critical path: 1) Parse sentences to get syntax trees 2) Identify unique syntax rules across training data 3) Construct module instances for each syntax rule 4) Initialize module parameters 5) Train modules to minimize MSE between SynNaMoN output and transformer embeddings 6) Evaluate distillability on held-out data

- Design tradeoffs: Module concatenation vs. summation (concatenation allows arbitrary functions but increases parameters); syntax formalism choice (different grammars capture different aspects); module architecture complexity (linear more interpretable but may miss nonlinear composition)

- Failure signatures: High MSE across all architectures (transformer's compositional structure not well-captured by syntax); large gap between Linear and Double performance (syntax-guided composition requires nonlinear operations); poor generalization of individual modules (modules may overfit to training data)

- First 3 experiments: 1) Implement simple SynNaMoN with Linear modules and test on small subset of sentences from known transformer model 2) Compare distillability across different sentence embedding models using same SynNaMoN architecture 3) Test effect of module architecture (Linear vs. Nonlin vs. Double) on distillability for single transformer model

## Open Questions the Paper Calls Out

- Question: Does model size affect the distillability of sentence embeddings to SynNaMoN architectures?
  - Basis in paper: Explicit observation that distillability doesn't considerably vary by model size
  - Why unresolved: Paper observes no considerable variation but lacks controlled experiments to definitively determine relationship
  - What evidence would resolve it: Controlled experiments varying model sizes while keeping other factors constant

- Question: How much of sentence embedding models' compositional ability is explained by syntax versus other factors?
  - Basis in paper: Explicit statement that distillability captures whether syntax is a strong causal model of compositional ability
  - Why unresolved: Paper introduces SynNaMoN as way to measure syntax's explanatory power but doesn't quantify what percentage is explained by syntax
  - What evidence would resolve it: Comparing SynNaMoN's explanatory power to other potential causal models

- Question: How does the choice of linguistic formalism affect SynNaMoN's ability to distill sentence embeddings?
  - Basis in paper: Explicit acknowledgment that choice of linguistic formalism can significantly influence probing results
  - Why unresolved: Paper acknowledges this possibility but doesn't empirically test how different formalisms affect distillability
  - What evidence would resolve it: Replicating experiments with different formalisms (dependency grammar, different constituency grammars)

## Limitations
- Assumes syntax provides sufficient inductive bias to capture compositional structure, which may not hold for models relying heavily on non-syntactic information
- Uses Penn Treebank-style constituency grammar which may not capture all syntactic phenomena
- Distillation process may be sensitive to hyperparameter choices that aren't fully explored

## Confidence
- **High Confidence**: Core methodology of using SynNaMoN to probe compositionality is well-defined and reproducible; finding that GTR-T5-xl shows highest distillability is robust across architectures
- **Medium Confidence**: Claims about linear nature of syntax-guided composition are supported but could be influenced by specific module architectures tested; assertion that model size doesn't affect distillability needs broader validation
- **Low Confidence**: Conclusions about specific semantic intuitions captured by individual modules are anecdotal and would require systematic semantic validation

## Next Checks
1. Test SynNaMoN on dependency grammar parses to assess whether results generalize across syntactic formalisms
2. Conduct ablation studies with random vs. syntax-guided module assignments to quantify importance of syntactic structure
3. Validate semantic claims by correlating module behavior with controlled semantic phenomena (e.g., negation, quantification, metaphor)
