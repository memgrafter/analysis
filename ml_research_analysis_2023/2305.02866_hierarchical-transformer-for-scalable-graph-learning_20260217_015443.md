# Hierarchical Transformer for Scalable Graph Learning

## Quick Facts
- arXiv ID: 2305.02866
- Source URL: https://arxiv.org/abs/2305.02866
- Reference count: 10
- One-line primary result: HSGT achieves state-of-the-art performance on large-scale graph benchmarks like ogbn-products (2.4M nodes) with computational costs similar to GraphSAGE

## Executive Summary
HSGT introduces a hierarchical graph transformer architecture that uses multi-level graph hierarchies to improve scalability and performance for large graph learning tasks. The model constructs graph hierarchies via coarsening techniques and employs horizontal and vertical transformer blocks to efficiently exchange and transform information at different scales. By using historical embeddings and hierarchical sampling, HSGT enables scalable training while maintaining high performance. Experiments demonstrate state-of-the-art results on large-scale benchmarks like ogbn-products while achieving computational efficiency comparable to simpler sampling-based methods.

## Method Summary
HSGT builds graph hierarchies using coarsening algorithms like METIS, creating multiple levels where each level represents a compressed version of the graph. The model processes information through horizontal transformer blocks at each level that use biased attention with structural encodings based on shortest path distances. Vertical blocks aggregate information between hierarchy levels, while readout blocks fuse multi-level representations for final output. Training uses hierarchical sampling with neighborhood expansion and historical embeddings to store previously computed high-level representations, enabling efficient inter-batch communication without recomputation.

## Key Results
- Achieves 82.51% accuracy on ogbn-products (2.4M nodes), outperforming sampling-based transformer baselines
- Maintains computational efficiency similar to GraphSAGE while delivering state-of-the-art performance
- Shows consistent improvements across multiple large-scale benchmarks including ogbn-arxiv, ogbn-proteins, and Reddit

- Claim: Graph hierarchies enable efficient expansion of receptive field without quadratic scaling
- Mechanism: By constructing multi-level graph hierarchies using coarsening techniques, HSGT stores high-level context information in virtual nodes at higher levels. Attention interactions between nodes at different levels allow low-level nodes to access high-level contextual information efficiently, avoiding the need to compute all pairwise interactions in the full graph.
- Core assumption: High-level nodes can effectively represent and communicate essential substructures from lower levels through appropriate aggregation mechanisms

### Mechanism 2
- Claim: Historical embeddings enable scalable training by breaking inter-batch dependencies while preserving high-level context flow
- Mechanism: Historical embeddings store previously computed node representations from higher hierarchical levels. During training, instead of recomputing embeddings for all neighborhood nodes at higher levels, the model uses these stored historical embeddings as approximations, significantly reducing computational overhead while maintaining information flow between batches.
- Core assumption: Historical embeddings from previous batches provide sufficiently accurate approximations for current batch computations
- Evidence anchors:

## Architecture Onboarding

- Component map: Input transformation layer -> Horizontal block (level 0) -> Vertical block -> Horizontal block (level 1) -> ... -> Readout block -> Output
- Critical path: Input → Horizontal block (level 0) → Vertical block → Horizontal block (level 1) → ... → Readout block → Output
- Design tradeoffs:
  - Hierarchical depth vs. computational cost: More hierarchical levels enable larger receptive fields but increase complexity
  - SPD length D vs. information capture: Longer SPDs capture more structural information but increase computational cost
  - Historical embedding staleness vs. accuracy: Older embeddings reduce computational cost but may be less accurate
  - Parameter sharing vs. model capacity: Shared parameters reduce complexity but may limit expressiveness

- Failure signatures:
  - Performance degradation with increasing graph size: May indicate insufficient hierarchical depth or ineffective historical embeddings
  - High memory usage despite hierarchical sampling: May indicate inefficient implementation of historical embeddings or excessive neighborhood sampling
  - Poor performance on small graphs: May indicate over-reliance on hierarchical structure when global attention is more appropriate

- First 3 experiments:
  1. Verify hierarchy construction: Test that METIS produces the expected number of nodes at each level with the specified coarsening ratios, and that the hierarchical mappings φ correctly represent the coarsening relationships
  2. Test horizontal block functionality: Verify that biased attention with SPD encodings produces reasonable attention weights, and that the receptive field construction (D-hop neighbors + random sampling) behaves as expected
  3. Validate historical embedding mechanism: Test that historical embeddings are correctly stored and retrieved, and that the approximation error remains within acceptable bounds across training iterations

## Limitations
- The effectiveness of historical embeddings relies on theoretical bounds that are not empirically validated
- Parameter sharing across hierarchical levels may limit the model's capacity to capture scale-specific features in certain graph structures
- The SPD bias mechanism's effectiveness depends on the assumption that shortest path distances adequately capture structural importance

## Confidence

- **High confidence**: The core architectural design of hierarchical transformers with horizontal and vertical blocks is well-specified and the experimental results on benchmark datasets are reproducible.
- **Medium confidence**: The claims about computational efficiency gains from historical embeddings and parameter sharing are supported by theoretical arguments but lack comprehensive ablation studies.
- **Low confidence**: The generalizability of the approach to graphs with very different structural properties (e.g., scale-free networks, graphs with strong community structure) is not demonstrated.

## Next Checks

1. Conduct ablation studies to quantify the contribution of each hierarchical level to overall performance and identify the point of diminishing returns for adding more levels.
2. Implement a diagnostic to measure the approximation error introduced by historical embeddings over training time and validate whether the theoretical bounds hold in practice.
3. Test the model on graphs with known community structure or scale-free properties to evaluate whether the SPD bias mechanism remains effective when graph structure differs significantly from the coarsening hierarchy.
