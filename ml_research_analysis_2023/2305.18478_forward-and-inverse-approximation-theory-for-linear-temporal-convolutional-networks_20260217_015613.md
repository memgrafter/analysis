# Forward and Inverse Approximation Theory for Linear Temporal Convolutional Networks

## Quick Facts
- arXiv ID: 2305.18478
- Source URL: https://arxiv.org/abs/2305.18478
- Reference count: 39
- Key outcome: Provides Jackson-type and Bernstein-type approximation theorems for temporal convolutional networks, characterizing which sequential relationships can be efficiently captured

## Executive Summary
This paper establishes theoretical foundations for understanding the approximation capabilities of temporal convolutional architectures in sequence modeling. The authors prove a Jackson-type result giving forward approximation rates and a novel Bernstein-type result providing an inverse approximation theorem. These results together characterize the types of sequential relationships that can be efficiently captured by temporal convolutional networks, with the rate estimate improving upon previous work through a refined complexity measure that decouples spectrum and tail parameters.

## Method Summary
The paper analyzes linear temporal convolutional networks with dilated convolutions, using tensor decomposition (HOSVD) to characterize the approximation properties of sequence-to-sequence models. The method defines complexity measures based on spectrum decay and tail decay of the target function, then proves both forward and inverse approximation theorems. The forward result provides a Jackson-type rate bound, while the inverse result establishes that only targets with small complexity measures can be well approximated, creating a converse to the forward theorem.

## Key Results
- Jackson-type approximation theorem providing improved rate bounds by decoupling complexity parameters M and K
- Bernstein-type inverse approximation theorem showing necessity of small complexity measures
- Refined complexity measure C(g,f) that captures both spectral regularity and memory decay independently
- Characterization of which sequential relationships can be efficiently captured by temporal convolutional architectures

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The forward approximation theorem provides a Jackson-type rate bound that improves upon prior results by decoupling the complexity parameters M and K.
- Mechanism: The tensor structure of dilated convolutions allows the error to be split into two independent terms: one controlled by M (spectrum decay) and one controlled by K (tail decay). This independence ensures that increasing either parameter strictly reduces the overall error.
- Core assumption: The target function's representation can be decomposed via HOSVD, and the approximation error is bounded by the tail sum of singular values.
- Evidence anchors:
  - [abstract]: "The rate estimate improves upon a previous result via the introduction of a refined complexity measure."
  - [section 3.1]: "This is considered an improvement over the previous Jackson-type result presented in [7], where the first term has the form C(H)g(KM^{1/K} - K)."
  - [corpus]: Weak - no direct citations to improved rate bounds in corpus.

### Mechanism 2
- Claim: The inverse approximation theorem (Bernstein-type) is a converse to the forward result, showing that only targets with small complexity measures can be well approximated.
- Mechanism: By assuming that for all M, K there exists a model with error below a threshold, the proof shows that this forces the target's spectrum and tail to decay at rates matching the threshold. This establishes the necessity of small complexity measures.
- Core assumption: The input distribution is Gaussian, allowing expectation of squared errors to separate into sums over spectrum and tail components.
- Evidence anchors:
  - [abstract]: "The inverse approximation theorem is new... states that a target can be effectively approximated only if its complexity measure is small, which presents a converse of the forward approximation theorem."
  - [section 3.1]: "It suggests that a target can be well approximated by the model only if it has small complexity measure, which in turn implies that the target exhibits good spectrum regularity and rapid decay of memory."
  - [corpus]: Weak - no corpus papers directly cite inverse approximation theorems for CNNs.

### Mechanism 3
- Claim: The refined complexity measure C(g,f) captures both spectral regularity and memory decay, enabling tighter bounds.
- Mechanism: The measure combines the HOSVD-based spectrum decay C(g)_1 and the tail decay C(f)_2, each with its own decay function. This allows independent control over approximation quality in different frequency/time regimes.
- Core assumption: The target function belongs to the space C(g,f), meaning both spectrum and tail satisfy the respective decay conditions.
- Evidence anchors:
  - [section 2]: "We restrict ourselves to considering targets that satisfy the above two complexity measures... C(g,f) = {H ∈ C : C(g)_1(H) + C(f)_2(H) < ∞}."
  - [section 3.1]: "This complexity measure takes into account the decay of the spectrum of the target."
  - [corpus]: Weak - no corpus papers discuss refined complexity measures for CNNs.

## Architecture Onboarding

- Component map: Input sequence x(t) ∈ c(Z, Rd) -> Dilated CNN with K layers, M channels -> Output sequence y(t) ∈ c(Z, R)
- Critical path:
  1. Define target function and its representation ρ(H)
  2. Tensorize the target using HOSVD
  3. Construct CNN approximation with matching bases
  4. Bound error using complexity measures
  5. Prove forward and inverse approximation theorems

- Design tradeoffs:
  - More channels M → better spectrum approximation but more parameters
  - More layers K → better tail approximation but longer filters
  - Filter length l → affects receptive field and parameter efficiency
  - Choice of decay functions g,f → impacts tightness of complexity bounds

- Failure signatures:
  - Large approximation error despite increasing M,K → target not in C(g,f)
  - Error not decreasing monotonically with M or K → tensor structure not exploited properly
  - HOSVD decomposition unstable → target has poor spectral properties

- First 3 experiments:
  1. Approximate a target with known HOSVD decomposition (e.g., low-rank tensor) and verify error decreases with M
  2. Approximate a target with fast-decaying tail and verify error decreases with K
  3. Approximate a target with both good spectrum and tail properties and verify both error terms decrease as M,K increase

## Limitations

- The inverse approximation theorem critically relies on Gaussian input distributions, which may not hold in practical applications
- The analysis assumes target functions have good tensor structure via HOSVD, limiting applicability to sequences with clean spectral properties
- The specific element-wise activation function is not specified, creating ambiguity in the exact architecture being analyzed

## Confidence

- **High Confidence**: The forward Jackson-type approximation theorem - The proof structure is well-established and the rate improvement is clearly demonstrated through the decoupling of M and K parameters
- **Medium Confidence**: The refined complexity measure C(g,f) - While the theoretical framework is sound, the practical utility depends heavily on the target function's adherence to the assumed tensor structure
- **Low Confidence**: The inverse approximation theorem - The Gaussian input assumption and the reliance on specific spectral decomposition properties make this result more fragile and less likely to generalize to practical scenarios
