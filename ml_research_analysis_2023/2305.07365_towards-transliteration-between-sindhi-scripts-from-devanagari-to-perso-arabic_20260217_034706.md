# Towards Transliteration between Sindhi Scripts from Devanagari to Perso-Arabic

## Quick Facts
- **arXiv ID:** 2305.07365
- **Source URL:** https://arxiv.org/abs/2305.07365
- **Reference count:** 16
- **Primary result:** Hybrid rule-based and probabilistic model achieves 99.66% accuracy in Devanagari to Perso-Arabic Sindhi transliteration

## Executive Summary
This paper presents a hybrid approach for machine transliteration between Sindhi scripts, specifically from Devanagari to Perso-Arabic. The system combines a rule-based method with a probabilistic model to handle ambiguous character mappings. The rule-based component processes the majority of the text, while the probabilistic model, using Hidden Markov Models and bigram/trigram probabilities, resolves ambiguities. The system was evaluated on 1500 sentences, achieving an overall accuracy of 99.66%, with the rule-based module achieving 81.17% accuracy and the probabilistic module achieving 98.18% accuracy on ambiguous cases.

## Method Summary
The transliteration system employs a two-tier approach to convert Sindhi text from Devanagari script to Perso-Arabic script. The first tier is a rule-based module that handles direct character mappings between the two scripts using predefined dictionaries. This module processes the majority of the text but struggles with ambiguous characters that can map to multiple Perso-Arabic equivalents. The second tier is a probabilistic module that uses Hidden Markov Models (HMM) with bigram and trigram probabilities to resolve these ambiguities. The HMM model was trained on parallel corpora to learn the probability distributions of character sequences in Perso-Arabic Sindhi. When the rule-based module encounters an ambiguous character, it passes the context to the probabilistic module, which uses the learned probabilities to select the most likely Perso-Arabic character. This hybrid approach allows for efficient processing of straightforward mappings while maintaining accuracy on challenging ambiguous cases.

## Key Results
- Overall system accuracy of 99.66% on 1500 test sentences
- Rule-based module accuracy of 81.17%
- Probabilistic module accuracy of 98.18% on ambiguous cases

## Why This Works (Mechanism)
The hybrid approach works by leveraging the strengths of both rule-based and probabilistic methods. The rule-based component efficiently handles the majority of straightforward character mappings, which constitute the bulk of the transliteration task. This reduces the computational load on the probabilistic module, allowing it to focus on the more challenging ambiguous cases. The probabilistic model, trained on real parallel corpora, captures the statistical patterns and contextual dependencies in Perso-Arabic Sindhi text. By using bigram and trigram probabilities, it can make informed decisions about the most likely transliteration for ambiguous characters based on their surrounding context. This combination allows the system to achieve high accuracy while maintaining efficiency in processing.

## Foundational Learning
- **Hidden Markov Models (HMMs):** Used to model the probabilistic relationships between Devanagari and Perso-Arabic characters. Needed for handling ambiguous character mappings based on context. Quick check: Verify that the HMM correctly models state transitions and emission probabilities.
- **Bigram and Trigram Probabilities:** Capture the likelihood of character sequences in Perso-Arabic Sindhi. Needed to provide context for disambiguating character mappings. Quick check: Ensure that the probability distributions are well-calibrated and cover a wide range of character combinations.
- **Rule-based Transliteration:** Direct character mapping using predefined dictionaries. Needed for efficiently handling straightforward, unambiguous character conversions. Quick check: Validate that the rule-based dictionary covers all necessary character mappings without errors.

## Architecture Onboarding

**Component Map:** Input Devanagari text -> Rule-based module -> Ambiguous cases -> Probabilistic module (HMM) -> Output Perso-Arabic text

**Critical Path:** Input text -> Character-by-character processing -> Rule-based lookup -> Ambiguity detection -> Probabilistic resolution -> Output generation

**Design Tradeoffs:** The system trades off between efficiency and accuracy by using a rule-based approach for most cases and a more computationally intensive probabilistic model only for ambiguous cases. This design choice optimizes for speed while maintaining high accuracy on challenging mappings.

**Failure Signatures:** The system may fail on out-of-vocabulary words, rare dialectal variations, or when the probabilistic model encounters unseen character sequences. It may also struggle with proper nouns or loanwords that don't follow typical transliteration patterns.
