# LMR: Lane Distance-Based Metric for Trajectory Prediction

## Quick Facts
- arXiv ID: 2304.05869
- Source URL: https://arxiv.org/abs/2304.05869
- Reference count: 23
- Key outcome: Proposes Lane Miss Rate (LMR), a lane distance-based metric that implicitly weights Euclidean error relative to lanes and captures traffic agent intents.

## Executive Summary
The paper introduces Lane Miss Rate (LMR), a novel metric for evaluating trajectory prediction models that incorporates lane distance information. Unlike traditional Euclidean distance metrics (ADE, FDE, Miss Rate), LMR specifically considers whether predictions are on the correct lane, effectively weighting errors based on lane structure. The metric shows promise in capturing the semantic meaning of predictions relative to lane structure and has been implemented for Argoverse 2 with public source code availability.

## Method Summary
LMR is designed to evaluate trajectory predictions by considering both the Euclidean distance and the lane structure. The metric evaluates whether predictions fall on the correct lane, with hits for correct lane predictions and misses for wrong lane predictions. This approach implicitly weights Euclidean error relative to lane positions, providing a more semantically meaningful evaluation compared to traditional distance-based metrics. The implementation is specifically designed for Argoverse 2 dataset and maintains consistency with existing metrics while adding lane-based semantic information.

## Key Results
- LMR preserves the order of existing Euclidean distance-based metrics (ADE, FDE, Miss Rate)
- Correctly identifies wrong-lane predictions as misses and right-lane predictions as hits
- Implicitly weights Euclidean error relative to lane structure
- Source code implementation available for Argoverse 2

## Why This Works (Mechanism)
The metric works by incorporating lane structure information into trajectory evaluation. By considering whether predictions fall on correct lanes, it captures the semantic meaning of predictions beyond pure distance metrics. This approach aligns evaluation with human understanding of correct driving behavior - being on the correct lane is more important than minor distance variations. The metric effectively combines geometric accuracy with semantic correctness, providing a more comprehensive evaluation of trajectory prediction models.

## Architecture Onboarding

**Component Map:**
LMR -> Lane Structure Data -> Evaluation Results

**Critical Path:**
1. Load trajectory predictions and ground truth
2. Access lane structure information
3. Determine if predictions fall on correct lanes
4. Calculate LMR score

**Design Tradeoffs:**
- Balances geometric accuracy with semantic correctness
- Requires accurate lane structure data
- May be less effective in unstructured environments

**Failure Signatures:**
- Incorrect lane definitions leading to wrong evaluation
- Ambiguous lane boundaries causing inconsistent results
- Poor performance in non-lane-based environments
