# HULAT at SemEval-2023 Task 10: Data augmentation for pre-trained transformers applied to the detection of sexism in social media

## Quick Facts
- arXiv ID: 2302.12840
- Source URL: https://arxiv.org/abs/2302.12840
- Reference count: 6
- Best results: RoBERTa with data augmentation achieved macro F1-scores of 0.5877 (task B) and 0.4458 (task C)

## Executive Summary
This paper explores the application of transformer models with data augmentation for detecting sexism in social media posts, as part of SemEval-2023 Task 10. The authors fine-tune four transformer models (BERT, DistilBERT, RoBERTa, XLNet) using training data augmented with synthetic examples generated through EDA and NLPAug techniques. Their approach achieves the best results using RoBERTa with data augmentation for tasks B and C, showing that data augmentation improves fine-grained classification performance but not binary detection. The work highlights the potential of transformer-based approaches for complex social media content analysis while demonstrating the nuanced effects of data augmentation across different classification tasks.

## Method Summary
The method involves fine-tuning pre-trained transformer models on the SemEval-2023 Task 10 dataset, which consists of 20,000 English social media posts annotated for sexism detection across three tasks. For tasks B and C, the authors apply data augmentation using EDA (synonym replacement, random insertion, swapping, deletion) and NLPAug (contextualized synonym replacement) to address class imbalance and improve model generalization. The augmentation process generates synthetic training examples by applying these operations to existing posts while preserving semantic meaning. The approach uses a standard fine-tuning pipeline where augmented data is combined with original training data, followed by evaluation using macro F1-score across all three tasks.

## Key Results
- RoBERTa with data augmentation achieved macro F1-scores of 0.5877 for task B and 0.4458 for task C
- Data augmentation improved results for tasks B and C but not for task A (binary detection)
- RoBERTa outperformed other transformers (BERT, DistilBERT, XLNet) across all tasks
- Data augmentation increased recall but decreased precision, particularly in fine-grained classifications

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Data augmentation improves performance on fine-grained sexism classification but not binary detection
- Mechanism: Synthetic data from EDA and NLPAug operations increases class diversity, helping transformers learn nuanced patterns in the 11-vector classification
- Core assumption: Synthetic examples preserve semantic meaning while introducing linguistic variation that matches real-world distribution
- Evidence anchors: Abstract states data augmentation does not improve results for task A but has positive effect on task C; Section reports 10-point improvement for RoBERTa with augmentation on task C; Table 4 shows these results
- Break condition: If synthetic examples introduce artifacts that shift semantic boundaries, performance gains reverse, especially for minority classes like "3.4 condescending explanations"

### Mechanism 2
- Claim: RoBERTa outperforms other transformers due to dynamic masking and larger vocab size
- Mechanism: RoBERTa's byte-level BPE tokenizer (50k vs BERT's 30k) and dynamic MLM training capture richer context patterns for sexist content detection
- Core assumption: Increased vocabulary granularity and context masking provide better representations of subtle sexist cues
- Evidence anchors: Section reports RoBERTa defeats all previous approaches with improvements of 1-3 points in macro F1-score; Table 2 shows RoBERTa achieving 0.572 vs XLNet's 0.553 with augmentation; Abstract identifies RoBERTa with augmentation as best approach
- Break condition: If task data distribution changes such that larger vocab provides no advantage, or if fine-tuning budget is constrained and simpler models become more efficient

### Mechanism 3
- Claim: Task-specific fine-tuning with synthetic data improves recall at cost of precision
- Mechanism: Fine-tuning on combined real and synthetic data biases model toward detecting more instances of rare classes, increasing recall but introducing false positives
- Core assumption: Class imbalance in fine-grained tasks (especially vectors 3.4 with only 14 instances) makes synthetic oversampling effective despite precision trade-offs
- Evidence anchors: Section reports data augmentation increases recall with significant decrease in precision; Table 3 shows vector 1.2 precision 0.632 vs recall 0.684; Abstract notes positive effect of augmentation on task C results
- Break condition: If precision becomes critical threshold (e.g., deployment in sensitive contexts), the recall gains may not justify precision loss

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Why did data augmentation techniques fail to improve results for task A (binary sexism detection) despite showing some improvements for tasks B and C?
- Basis in paper: [explicit] The authors state that data augmentation does not improve results for task C and that their approach ranked in the middle for all three subtasks.
- Why unresolved: The paper does not provide a clear explanation for this discrepancy, only noting that data augmentation does not always improve NLP task results.
- What evidence would resolve it: Detailed analysis comparing the characteristics of binary vs. multi-class classification tasks, or experiments isolating the effects of data augmentation on different task types.

### Open Question 2
- Question: How do the performance differences between RoBERTa and other transformer models vary across the different sexism categories and vectors?
- Basis in paper: [inferred] The authors note that RoBERTa slightly outperforms other models in task A, but provide detailed results for task B showing varying F1-scores across categories.
- Why unresolved: The paper only provides comprehensive performance breakdowns for task B, with limited comparison of model differences across categories and vectors.
- What evidence would resolve it: Detailed per-category and per-vector performance comparisons between all transformer models tested.

### Open Question 3
- Question: What specific characteristics of the sexism detection task make it particularly challenging compared to other text classification tasks?
- Basis in paper: [explicit] The authors note that their systems "still have much room for improvement, especially in the two fine-grained classifications" and that about half of systems achieved F1-scores below 0.42 for task C.
- Why unresolved: The paper identifies the challenge but does not analyze the underlying factors contributing to the difficulty.
- What evidence would resolve it: Comparative analysis with other text classification tasks, or analysis of specific features of sexist language that complicate classification.

## Limitations

- Data augmentation implementation lacks detailed specifications regarding the number of augmented samples and operation intensity
- Class imbalance in fine-grained tasks (particularly vectors 3.4 with only 14 instances) is addressed but specific handling strategies are not detailed
- Comparison between transformer models is limited to macro F1 scores without deeper analysis of per-class performance patterns or failure modes
- Computational efficiency of different approaches is not discussed, which is relevant for deployment considerations

## Confidence

**High Confidence**: The core finding that RoBERTa outperforms other transformers on this dataset is well-supported by consistent improvements across multiple evaluation metrics. The observation that data augmentation helps fine-grained classification but not binary detection is also well-established through direct comparison.

**Medium Confidence**: The claim that data augmentation increases recall while decreasing precision is supported by reported metrics, but the tradeoff analysis could be more rigorous. The mechanism explanation for why augmentation helps fine-grained tasks but not binary detection is plausible but not definitively proven.

**Low Confidence**: The specific reasons why RoBERTa's dynamic masking and larger vocabulary provide advantages for sexism detection are hypothesized but not empirically validated through ablation studies or controlled experiments.

## Next Checks

1. **Augmentation Parameter Sensitivity**: Conduct a systematic study varying the number of augmented samples per instance (5x, 10x, 20x) and the intensity of EDA operations to determine the optimal augmentation strategy that maximizes macro F1 while minimizing precision loss.

2. **Per-Class Performance Analysis**: Perform detailed error analysis on the 11-vector classification task, examining which specific vectors show the largest performance gaps between augmented and non-augmented models, and correlate these with augmentation coverage to validate whether synthetic examples effectively address class imbalance.

3. **Cross-Validation of Augmentation Impact**: Implement k-fold cross-validation on the training data to assess whether the observed improvements from data augmentation are consistent across different data splits, and test whether the augmentation benefits transfer to unseen semantic patterns not represented in the training data.
