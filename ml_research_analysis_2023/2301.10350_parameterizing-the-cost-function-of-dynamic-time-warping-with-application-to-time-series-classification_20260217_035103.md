# Parameterizing the cost function of Dynamic Time Warping with application to time series classification

## Quick Facts
- arXiv ID: 2301.10350
- Source URL: https://arxiv.org/abs/2301.10350
- Reference count: 13
- Key outcome: Parameterized DTW (DTW+ and ADTW+) with cost function λγ(a,b) = |a-b|^γ achieves 47% highest accuracy on 109 UCR datasets vs 39% for standard ADTW2

## Executive Summary
This paper introduces a parameterized cost function for Dynamic Time Warping that tunes the exponent γ to adapt similarity measurement to specific time series classification tasks. Standard DTW uses γ=1 (absolute difference), but the authors show that allowing γ to vary between 0.5 and 2 significantly improves classification accuracy. The method learns the optimal γ value during training by searching over a discrete set of candidate values, with the constraint that different classes can have different optimal γ values.

The approach is evaluated on 109 UCR time series datasets, where DTW+ and ADTW+ significantly outperform standard DTW variants. The parameterized cost function is also integrated into Proximity Forest, establishing a new state-of-the-art benchmark for similarity-based time series classification. The key insight is that different tasks benefit from different ways of measuring amplitude differences - lower γ emphasizes small amplitude effects while higher γ emphasizes large amplitude effects.

## Method Summary
The paper proposes replacing the standard absolute difference cost function in DTW with a parameterized version λγ(a,b) = |a-b|^γ, where γ is learned at training time. For each class, the algorithm searches over a discrete set of γ values (0.5, 1, 1.5, 2 in most experiments) to find the value that minimizes leave-one-out error on the training set. During testing, the γ value associated with the predicted class is used for distance calculation. The approach extends to derivative-based ADTW by applying the same parameterization to the derivative calculations. When integrated into Proximity Forest, each of the 11 distance measures can be independently parameterized with its own γ value.

## Key Results
- DTW+ and ADTW+ achieve 47% highest accuracy on 109 UCR datasets (vs 39% for standard ADTW2)
- ADTW+ with γ=2 achieves highest accuracy on 47 datasets (38%)
- Parameterized cost functions significantly improve Proximity Forest performance
- γ values interact differently with noise levels for DTW vs ADTW
- Different γ values (0.5, 1, 2) perform best on different datasets

## Why This Works (Mechanism)
The parameterized cost function allows the similarity measure to adapt to the specific characteristics of each classification task. Different time series domains have different amplitude scales and noise patterns, and a fixed cost function cannot optimally capture similarity across all domains. By tuning γ, the method can emphasize small amplitude differences (γ < 1) or large amplitude differences (γ > 1) depending on what the task requires. This flexibility enables better alignment between the similarity measure and the underlying classification problem structure.

## Architecture Onboarding

Component map: Time Series -> DTW+ with γ -> Distance Matrix -> Nearest Neighbor Classifier -> Class Label

Critical path: During training, for each candidate γ value, compute leave-one-out error by calculating pairwise DTW distances with that γ, then select γ that minimizes error. During testing, use the γ value associated with the predicted class.

Design tradeoffs: The main tradeoff is between flexibility and computational cost. More γ values provide better adaptation but increase training time. The authors chose a limited set (0.5, 1, 1.5, 2) to balance these factors.

Failure signatures: Poor performance may indicate that the optimal γ value is outside the search range, or that the task requires a more complex similarity measure than what DTW+ can provide.

First experiments: 1) Run DTW+ on a simple dataset with known optimal γ to verify the search process works, 2) Compare DTW+ vs standard DTW on datasets where small vs large amplitude differences should matter, 3) Test ADTW+ vs DT+ on datasets with temporal shifts.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal range of γ values for different time series classification tasks, and does this vary based on dataset characteristics like noise levels or series length?
- Basis in paper: [explicit] The paper shows that different γ values (0.5, 1, 2) perform best on different datasets and that γ interacts with noise levels in different ways for DTW and ADTW.
- Why unresolved: The paper only tested a limited set of γ values (1/2, 1/1.5, 1, 1.5, 2) and a larger set (1/5 to 5). It doesn't explore the full parameter space or systematically characterize which dataset properties correlate with optimal γ values.
- What evidence would resolve it: Systematic experiments testing a dense grid of γ values across diverse datasets with varying noise levels, series lengths, and other characteristics to identify patterns and optimal ranges.

### Open Question 2
- Question: How do parameterized cost functions affect the performance of other DTW variants and elastic distance measures beyond DTW and ADTW?
- Basis in paper: [inferred] The paper notes that the findings could extend to "all applications relying on nearest neighbor search" and mentions that Proximity Forest uses 11 different distances. The authors suggest that other distances in PF could also benefit from cost function tuning.
- Why unresolved: The paper only experiments with DTW, ADTW, and their use in Proximity Forest. It doesn't investigate whether parameterized cost functions would improve other elastic measures like LCSS, ERP, MSM, or TWE.
- What evidence would resolve it: Experiments applying parameterized cost functions to other elastic distance measures in both NN classification and ensemble methods like PF, comparing performance against standard implementations.

### Open Question 3
- Question: What are the computational trade-offs of using parameterized cost functions in real-time or streaming time series applications?
- Basis in paper: [explicit] The paper discusses runtime implications, showing that DTW+ and ADTW+ are 25-38 times slower than their non-parameterized counterparts, and suggests using only efficient exponents (0.5, 1, 2) to reduce computational burden.
- Why unresolved: While the paper provides some runtime analysis, it doesn't explore optimization strategies for real-time applications, investigate whether the benefits justify the costs in streaming scenarios, or test whether approximate methods could maintain accuracy while improving speed.
- What evidence would resolve it: Benchmarking parameterized cost functions in streaming scenarios with various optimization strategies (pre-computation, approximation, hardware acceleration) to quantify the accuracy-speed trade-off and identify practical deployment thresholds.

## Limitations
- The γ search range (0.5-2) appears somewhat arbitrary without clear theoretical justification
- Computational overhead of searching over γ values during training is significant (25-38x slower than standard DTW)
- The method doesn't provide clear guidance for selecting γ values for new, unseen problems

## Confidence

High confidence in empirical results showing improved accuracy over standard DTW variants (109 datasets, clear statistical significance)

Medium confidence in claim that method is "not computationally expensive" - paper provides some runtime analysis but lacks comprehensive benchmarking against all DTW variants

Medium confidence in theoretical motivation for parameterized cost function - while intuitively appealing, connection between γ and task-specific amplitude effects could be more rigorously established
