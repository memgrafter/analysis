# Zero- and Few-Shot Event Detection via Prompt-Based Meta Learning

## Quick Facts
- arXiv ID: 2305.17373
- Source URL: https://arxiv.org/abs/2305.17373
- Authors: 
- Reference count: 28
- This paper addresses the challenge of detecting unseen or rare event types in event detection tasks, where limited data is available for training.

## Executive Summary
This paper proposes MetaEvent, a meta learning-based framework for zero- and few-shot event detection. The approach addresses the challenge of detecting unseen or rare event types by sampling training tasks from existing event types and performing meta training to search for optimal parameters that quickly adapt to unseen tasks. MetaEvent uses a cloze-based prompt and a trigger-aware soft verbalizer to efficiently project output to unseen event types, and designs a contrastive meta objective based on maximum mean discrepancy (MMD) to learn class-separating features. The framework demonstrates state-of-the-art performance on benchmark datasets FewEvent and MAVEN, achieving considerable improvements in both zero-shot and few-shot scenarios.

## Method Summary
MetaEvent employs a meta-learning framework that optimizes initial parameters to perform well after few updates on new tasks. The model uses a cloze-based prompt with a trigger-aware soft verbalizer that combines MLM predictions with attentive trigger features extracted from transformer attention weights. A contrastive meta objective based on MMD is used to maximize inter-class distances in feature space. The framework undergoes inner-loop updates on sampled training tasks and outer-loop optimization based on evaluation performance, enabling quick adaptation to unseen event types with minimal examples.

## Key Results
- Achieves state-of-the-art performance in both zero-shot and few-shot event detection scenarios
- Demonstrates considerable improvements over baseline methods on FewEvent and MAVEN datasets
- Successfully performs zero-shot event detection by mapping features to event types without prior knowledge

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MetaEvent's trigger-aware soft verbalizer combines MLM predictions and attentive trigger features to improve event type identification.
- Mechanism: The model uses attention weights from the transformer to compute soft trigger features (weighted sum of token features) and concatenates these with MLM predictions before classification.
- Core assumption: Attention weights in the transformer layer provide meaningful importance scores for trigger identification.
- Evidence anchors:
  - [abstract] "We design a trigger-aware soft verbalizer to identify event types in our prompt-based event detection model"
  - [section 4.1] "we design an attentive reweighting strategy to select informative trigger features from the input context"
- Break condition: If attention weights do not correlate with trigger importance, the soft trigger features become noisy and degrade performance.

### Mechanism 2
- Claim: The contrastive meta objective based on MMD encourages class-separating features that generalize to unseen event types.
- Mechanism: MMD computes pairwise distances between event feature distributions and maximizes inter-class distances in the loss function.
- Core assumption: Increasing distance between different event type distributions improves zero-shot classification accuracy.
- Evidence anchors:
  - [abstract] "we design a contrastive meta objective based on maximum mean discrepancy (MMD) to learn class-separating features"
  - [section 4.3] "To enlarge the inter-class event discrepancy for improved zero- and few-shot performance, we additionally propose a contrastive loss Lcon. based on the maximum mean discrepancy (MMD)"
- Break condition: If the MMD kernel fails to capture meaningful differences between event distributions, the contrastive loss may not improve separation.

### Mechanism 3
- Claim: Meta learning enables quick adaptation to unseen tasks by optimizing initial parameters that perform well after few updates.
- Mechanism: The model undergoes inner-loop updates on sampled training tasks and outer-loop optimization based on evaluation performance.
- Core assumption: Parameters that perform well across multiple sampled tasks will also perform well on truly unseen tasks.
- Evidence anchors:
  - [abstract] "we sample training tasks from existing event types and perform meta training to search for optimal parameters that quickly adapt to unseen tasks"
  - [section 4.2] "MetaEvent consists of an inner-loop optimization stage... and an outer-loop optimization stage that minimizes the overall loss w.r.t. θ"
- Break condition: If the distribution of sampled training tasks differs significantly from unseen task distribution, meta learning may not generalize.

## Foundational Learning

- Concept: Meta learning (learning to learn)
  - Why needed here: Event detection requires adapting to new event types with minimal examples, which meta learning frameworks are specifically designed to handle
  - Quick check question: What is the difference between standard supervised learning and meta learning in terms of optimization objectives?

- Concept: Maximum Mean Discrepancy (MMD)
  - Why needed here: MMD provides a way to measure and maximize distance between event type distributions without requiring labeled examples for unseen types
  - Quick check question: How does MMD differ from simple Euclidean distance when measuring distribution differences?

- Concept: Prompt-based learning
  - Why needed here: Leverages the pretraining objective of language models to adapt to event detection without extensive fine-tuning
  - Quick check question: What is the advantage of using cloze-based prompts over traditional classification heads for event detection?

## Limitations
- Computational overhead of meta-learning framework makes it less practical for real-time applications
- Heavy reliance on attention weights for trigger identification may not consistently capture trigger importance
- Hungarian algorithm for zero-shot mapping is mentioned but not fully detailed
- MMD contrastive loss assumptions may not hold for all event type distributions with semantic overlap

## Confidence
**High Confidence**: The effectiveness of meta-learning for few-shot event detection is well-established, and the paper's improvements over baseline methods are statistically significant.

**Medium Confidence**: The trigger-aware soft verbalizer mechanism is theoretically sound, but the actual contribution of attentive trigger features versus standard MLM predictions is not fully isolated in the experiments.

**Low Confidence**: The claim that MMD contrastive loss is essential for zero-shot performance lacks strong empirical support and doesn't adequately demonstrate superiority over alternative distance metrics.

## Next Checks
1. **Ablation study on MMD contrastive loss**: Remove the MMD component and compare zero-shot performance with the base meta-learning model to quantify the actual contribution of the contrastive loss.

2. **Trigger feature importance analysis**: Perform a controlled experiment where trigger features are randomly initialized or replaced with non-attentive features to determine if the attentive component provides meaningful improvement.

3. **Cross-dataset generalization test**: Evaluate MetaEvent on a third dataset not mentioned in the paper (such as ACE 2005 or EventStoryLine) to verify that the meta-learning framework generalizes beyond the two benchmark datasets.
