# Explanation through Reward Model Reconciliation using POMDP Tree Search

## Quick Facts
- arXiv ID: 2305.00931
- Source URL: https://arxiv.org/abs/2305.00931
- Reference count: 18
- Primary result: A method to estimate user reward weightings from action discrepancies in POMDP planning using constrained optimization and Cross-Entropy optimization.

## Executive Summary
This paper addresses the challenge of explaining differences between user and algorithm reward models in POMDP planning. The authors propose a method that leverages action discrepancies - situations where a user would choose differently than the algorithm - to estimate the user's reward weighting. By formulating this as a constrained optimization problem that minimizes the distance between algorithm and user weights while ensuring the user's action is at least as good as the algorithm's, they can generate concise explanations of model differences. The approach uses a relaxed optimization with Cross-Entropy method and DESPOT for value estimation, enabling real-time explanation generation without requiring multiple user trajectories.

## Method Summary
The method formulates reward model reconciliation as a constrained optimization problem that minimizes the L1 distance between algorithm and estimated user reward weightings while ensuring the user's proposed action has higher estimated value than the algorithm's choice. This non-convex problem is solved by relaxing the constraint into the objective function and applying Cross-Entropy optimization, with Q-value estimates obtained from the DESPOT online POMDP solver. The approach enables one-shot estimation of user reward preferences from a single action discrepancy, making it suitable for real-time explanation generation in POMDP planning scenarios.

## Key Results
- The method can estimate that a user values penalties at one location at 70% of what the algorithm does, enabling concise explanations of model differences
- The one-shot approach allows real-time explanation generation without requiring multiple user trajectories
- The constrained optimization formulation can recover a user's reward weighting from a single action discrepancy when the user's action is optimal under their true reward function

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The constrained optimization formulation can recover a user's reward weighting from a single action discrepancy
- Mechanism: By minimizing the L1 distance between the algorithm's reward weights and an estimated user weight while ensuring the user's chosen action has higher estimated value than the algorithm's, the method finds a weight vector on the boundary of the constraint that explains the discrepancy
- Core assumption: The user's action reveals meaningful information about their reward preference, and the action-value estimates are accurate enough to identify this preference
- Evidence anchors: [abstract]: "Action discrepancies, differences in decisions made by an algorithm and user, are leveraged to estimate a user's objectives as expressed in weightings of a reward function." [section IV-A]: "The objective of the optimization problem is to find a reward weighting, ˆφh, for which the human action, ah, is at least as good as the action chosen by the algorithm, aa while remaining as close as possible to original reward weighting φa."
- Break condition: If the user's action is suboptimal under their true reward function, the estimated weights will not accurately reflect their preferences

### Mechanism 2
- Claim: The relaxed optimization with Cross-Entropy method can efficiently solve the non-convex constrained problem
- Mechanism: The constraint violation is penalized to form an unconstrained objective, which Cross-Entropy optimization can handle without gradient information. DESPOT provides the required Q-value estimates in real-time
- Core assumption: The relaxed objective maintains the constraint boundary closely enough for practical estimation
- Evidence anchors: [section IV-B]: "This relaxed optimization problem is solved using the Cross-Entropy method... with the outputs restricted such that each element of φ is greater than 0." [section IV-C]: "An online POMDP solver, DESPOT, is used to obtain Q-value estimates."
- Break condition: If the relaxation parameter is poorly tuned, the solution may violate the original constraint or be too conservative

### Mechanism 3
- Claim: The one-shot approach enables real-time explanation generation without requiring multiple user trajectories
- Mechanism: By formulating the problem to use only the current belief and a single user-proposed action, explanations can be generated immediately when discrepancies occur, rather than waiting for a sequence of actions
- Core assumption: A single action contains sufficient information to characterize the user's reward preference difference from the algorithm
- Evidence anchors: [section IV-A]: "We develop an explanation based on feedback from a single timestep in what we refer to as a one-shot approach." [section III]: "Determining the minimal number of explanations to present to the user such that their model is updated while minimizing the exchange of information is a key challenge."
- Break condition: If the user's true reward function differs significantly from the algorithm's, a single action may be insufficient to capture the difference accurately

## Architecture Onboarding

- Component map: POMDP Model -> DESPOT Solver -> Cross-Entropy Optimizer -> Explanation Generator
- Critical path: User action → Belief update → Q-value estimation (DESPOT) → Weight estimation (Cross-Entropy) → Explanation generation
- Design tradeoffs:
  - Single action vs. trajectory: Faster but less accurate estimation
  - L1 vs. L2 regularization: L1 promotes sparsity but may be less stable
  - Constraint relaxation: Enables gradient-free optimization but requires careful parameter tuning
- Failure signatures:
  - Estimated weights are identical to algorithm weights: User and algorithm are already aligned
  - Optimization fails to converge: Q-value estimates may be noisy or relaxation parameter poorly tuned
  - Estimated weights produce unrealistic values: User's true reward function may be outside the model space
- First 3 experiments:
  1. Verify that the method can recover known weight differences in a simple POMDP with synthetic user actions
  2. Test sensitivity to the relaxation parameter and Cross-Entropy configuration on the HVAC repair problem
  3. Evaluate explanation quality through user studies comparing different explanation formats for the same weight differences

## Open Questions the Paper Calls Out

- Question: How does the accuracy of estimated user reward weightings (φh) improve with multiple rounds of explanation and feedback compared to the one-shot approach?
  - Basis in paper: [explicit] The paper states "Increasing the accuracy of φh, potentially through multiple rounds of explanation and feedback, is an area of future work."
  - Why unresolved: The paper only presents a proof-of-concept using a one-shot approach and acknowledges that the estimation problem is underspecified, with many possible reward weightings resulting in the same action for a given belief
  - What evidence would resolve it: Experimental results comparing the accuracy of φh estimates from single vs. multiple rounds of explanation and feedback, using metrics such as mean squared error between estimated and true reward weightings

- Question: How do different presentation methods for explaining the estimated user reward weighting differences (e.g., numerical values, visual representations, natural language) affect user understanding and trust in the algorithm's decisions?
  - Basis in paper: [inferred] The paper mentions "There are a number of potential means of presenting this information to the user" and provides one example using natural language, but does not evaluate different presentation methods
  - Why unresolved: The paper does not conduct user studies to evaluate the effectiveness of different explanation presentation methods on user understanding and trust
  - What evidence would resolve it: User study results comparing different explanation presentation methods, measuring user understanding (e.g., post-explanation questionnaires) and trust (e.g., trust scales, decision acceptance rates)

- Question: How does the proposed reward model reconciliation method scale to more complex POMDP problems with larger state and action spaces, and how does it compare to other IRL methods in terms of accuracy and computational efficiency?
  - Basis in paper: [explicit] The paper states "Our continuing work focuses on means of evaluating and improving the work presented here" and mentions that "in principle these IRL methods could be applied to our problem, we do not yet compare against them."
  - Why unresolved: The paper only provides a proof-of-concept on a relatively simple POMDP problem and does not compare the proposed method to other IRL approaches or evaluate its performance on more complex problems
  - What evidence would resolve it: Experimental results on more complex POMDP problems, comparing the proposed method to other IRL approaches in terms of estimation accuracy (e.g., mean squared error) and computational efficiency (e.g., runtime, number of iterations)

## Limitations

- The method assumes the user's action is optimal or near-optimal under their true reward function; suboptimal user choices lead to inaccurate weight estimates
- The one-shot approach using a single action may be insufficient to capture complex differences in reward preferences, especially in high-dimensional reward spaces
- The constraint relaxation and Cross-Entropy optimization require careful hyperparameter tuning to ensure both constraint satisfaction and efficient convergence

## Confidence

- **High confidence** in the core optimization formulation and its ability to find weightings that explain observed action discrepancies
- **Medium confidence** in the Cross-Entropy method's ability to reliably solve the relaxed optimization problem across different POMDP scenarios
- **Low confidence** in the method's robustness when users provide multiple or inconsistent actions over time
