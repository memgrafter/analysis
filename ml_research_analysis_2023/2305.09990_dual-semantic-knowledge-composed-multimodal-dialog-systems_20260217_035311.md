# Dual Semantic Knowledge Composed Multimodal Dialog Systems

## Quick Facts
- arXiv ID: 2305.09990
- Source URL: https://arxiv.org/abs/2305.09990
- Reference count: 40
- Primary result: 4.57% relative improvement on BLEU-1 and 5.34% on Nist metrics over state-of-the-art methods

## Executive Summary
This paper addresses limitations in multimodal task-oriented dialog systems by proposing MDS-S2, which incorporates dual semantic knowledge (attribute and relation knowledge) from knowledge bases using n-hop graph walk. The system composes multimodal context with dual semantic knowledge at different levels and applies representation-level semantic regularization using learned latent query variables. Experimental results demonstrate significant improvements over existing methods, highlighting the effectiveness of dual knowledge composition and semantic regularization for response generation.

## Method Summary
MDS-S2 introduces a novel approach to multimodal dialog systems by simultaneously acquiring attribute and relation knowledge from knowledge bases through n-hop graph walk. The method composes multimodal context with dual semantic knowledge at multiple levels and employs representation-level semantic regularization using learned latent query variables. This dual knowledge composition approach aims to address the limitations of current systems that ignore relation knowledge and lack proper representation-level regularization.

## Key Results
- Achieved 4.57% relative improvement on BLEU-1 metric compared to state-of-the-art methods
- Obtained 5.34% relative improvement on Nist metric over existing approaches
- Demonstrated effectiveness of dual semantic knowledge composition and representation-level regularization

## Why This Works (Mechanism)
The proposed method works by integrating relation knowledge that reveals correlations between entities, which is typically ignored by existing systems. By conducting n-hop graph walk on knowledge bases, MDS-S2 captures both attribute and relation knowledge simultaneously. The representation-level semantic regularization using learned latent query variables helps maintain consistency between the learned representations and the semantic structure of the knowledge base, leading to more coherent and contextually appropriate responses.
