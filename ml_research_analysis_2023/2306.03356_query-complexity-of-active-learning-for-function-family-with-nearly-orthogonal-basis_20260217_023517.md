# Query Complexity of Active Learning for Function Family With Nearly Orthogonal Basis

## Quick Facts
- arXiv ID: 2306.03356
- Source URL: https://arxiv.org/abs/2306.03356
- Reference count: 23
- This paper studies the theoretical properties of active learning on function families with nearly orthogonal basis, relaxing the strict orthogonality assumption.

## Executive Summary
This paper extends active learning theory from strictly orthogonal basis to ρ-nearly orthonormal basis functions, where ρ is a small constant. The authors develop a novel algorithm that achieves O(d/ϵ) query complexity for recovering functions from such families, where d is the dimension and ϵ is the desired accuracy. Notably, this complexity is independent of the orthogonality parameter ρ, the data distribution, and the specific function family structure. The work also extends to active deep learning, providing the first query complexity analysis for neural networks with general activation functions.

## Method Summary
The authors propose an active learning algorithm that leverages the structure of nearly orthogonal basis functions to achieve efficient query complexity. The algorithm iteratively selects samples to label based on the current model's uncertainty, with theoretical guarantees that the number of required labels scales as O(d/ϵ) regardless of the orthogonality parameter ρ. The method relies on careful analysis of the geometry of nearly orthogonal function spaces and uses this structure to bound the sample complexity. For deep learning extension, the authors adapt the algorithm to work with neural network function families, showing that similar theoretical guarantees can be achieved when using general activation functions.

## Key Results
- Achieves O(d/ϵ) query complexity for nearly orthonormal basis function families
- Query complexity independent of orthogonality parameter ρ
- First query complexity analysis for active deep learning with general activation functions
- Theoretical bounds hold without assumptions on data distribution

## Why This Works (Mechanism)
The algorithm exploits the geometric properties of nearly orthogonal function spaces to bound the sample complexity. When basis functions are nearly orthogonal (with small ρ), the space retains enough structure to enable efficient learning despite the relaxation from strict orthogonality. The algorithm's sampling strategy is designed to navigate this near-orthogonal geometry efficiently, selecting points that maximally reduce uncertainty across the function family. For deep learning, the extension leverages the fact that neural networks with general activation functions can approximate nearly orthogonal function families, allowing the same theoretical framework to apply.

## Foundational Learning
- **Nearly orthogonal basis functions**: Basis functions where inner products are bounded by a small constant ρ. Why needed: Enables more realistic function families than strict orthogonality. Quick check: Verify that basis functions satisfy ⟨φᵢ, φⱼ⟩ ≤ ρ for all i ≠ j.

- **Active learning query complexity**: The number of label queries needed to achieve a desired accuracy. Why needed: Central metric for evaluating active learning efficiency. Quick check: Confirm that O(d/ϵ) bound is independent of ρ.

- **Function family geometry**: The geometric structure induced by nearly orthogonal basis. Why needed: Underlies the theoretical analysis of sample complexity. Quick check: Validate that the algorithm's sampling strategy respects this geometry.

- **Neural network approximation theory**: How neural networks can represent function families. Why needed: Critical for extending results to deep learning. Quick check: Verify that activation functions allow sufficient approximation of nearly orthogonal bases.

## Architecture Onboarding
- **Component map**: Input space → Feature mapping → Nearly orthogonal basis expansion → Active sampling strategy → Label acquisition → Model update → Prediction
- **Critical path**: The algorithm's performance depends critically on the basis functions being sufficiently nearly orthogonal (small ρ) and the sampling strategy effectively targeting high-uncertainty regions.
- **Design tradeoffs**: The relaxation from strict orthogonality enables broader applicability but requires more sophisticated analysis to maintain theoretical guarantees. The algorithm trades computational complexity for distribution-independence.
- **Failure signatures**: If ρ is too large, the theoretical guarantees break down. Poor performance on highly correlated data distributions would indicate limitations of the distribution-independence claims.
- **First experiments**: 1) Test on synthetic data with known nearly orthogonal bases varying ρ; 2) Compare query complexity against passive learning baselines; 3) Validate deep learning extension on simple neural networks with different activation functions.
