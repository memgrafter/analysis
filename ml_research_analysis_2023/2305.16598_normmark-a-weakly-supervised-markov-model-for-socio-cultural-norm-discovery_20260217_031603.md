# NormMark: A Weakly Supervised Markov Model for Socio-cultural Norm Discovery

## Quick Facts
- arXiv ID: 2305.16598
- Source URL: https://arxiv.org/abs/2305.16598
- Reference count: 8
- Outperforms GPT-3 by 4 F1 points on LDC2022E20 dataset

## Executive Summary
NormMark introduces a generative Markov model that discovers socio-cultural norms in dialogues through weakly supervised learning. The model uniquely combines discrete and continuous latent variables to capture inter-dependencies between conversation turns, learning both label and content-related properties from previous turns. Trained via variational techniques on weakly annotated data, NormMark achieves state-of-the-art performance on the LDC2022E20 dataset, demonstrating particular strength when working with limited labeled data.

## Method Summary
NormMark employs a generative Markov model architecture that leverages both discrete and continuous latent variables to model socio-cultural norm discovery in dialogues. The model uses variational training techniques on weakly annotated data, capturing inter-dependencies between conversation turns to learn label- and content-related properties from previous turns. This approach enables effective learning from partially labeled datasets while maintaining strong performance on the LDC2022E20 benchmark.

## Key Results
- Achieves 4-point F1 improvement over GPT-3 on LDC2022E20 dataset
- Demonstrates strong performance on limited labeled data scenarios
- Establishes new state-of-the-art results for socio-cultural norm discovery

## Why This Works (Mechanism)
NormMark's effectiveness stems from its ability to model complex inter-dependencies between conversation turns using a combination of discrete and continuous latent variables. The variational training approach allows the model to learn effectively from weakly annotated data by capturing both label-specific and content-specific patterns across dialogue contexts. The Markov model structure naturally handles the sequential nature of conversations while the dual latent variable system provides rich representation capacity for nuanced socio-cultural patterns.

## Architecture Onboarding
Component map: Data -> Preprocessing -> Variational Encoder -> Discrete/Continuous Latents -> Markov Transition -> Output Classifier

Critical path: Input dialogue sequence flows through variational encoder to produce discrete and continuous latent variables, which then inform Markov transitions that capture inter-turn dependencies, ultimately feeding into the classification output.

Design tradeoffs: The dual latent variable system (discrete + continuous) provides rich representation capacity but increases model complexity and training time compared to single-variable approaches. The variational training enables weak supervision but introduces approximation uncertainties.

Failure signatures: Performance degradation on longer conversations suggests context window limitations; poor results on out-of-domain data indicate potential overfitting to training distribution.
