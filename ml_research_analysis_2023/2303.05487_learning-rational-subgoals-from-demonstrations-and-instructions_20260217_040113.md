# Learning Rational Subgoals from Demonstrations and Instructions

## Quick Facts
- arXiv ID: 2303.05487
- Source URL: https://arxiv.org/abs/2303.05487
- Reference count: 30
- The paper presents a framework for learning rational subgoals from demonstrations and instructions to support efficient long-term planning.

## Executive Summary
This paper introduces Rational Subgoals (RSGs), a framework for learning subgoal representations from unsegmented demonstration trajectories paired with abstract task descriptions. The core idea is to learn binary classifiers for subgoals that can detect when a subgoal has been achieved in a given state, and to discover dependencies between subgoals that guide hierarchical planning. The framework is evaluated on crafting and 2D continuous domains, showing significant improvements in planning efficiency and compositional generalization compared to baselines.

## Method Summary
The RSG framework learns subgoal classifiers from unsegmented demonstrations by maximizing a rationality score that measures how well the observed actions align with near-optimal actions for achieving the subgoals. It also discovers dependencies between subgoals by analyzing their temporal order in training trajectories. During planning, these learned subgoals and dependencies are used to guide off-the-shelf planners like A* and RRT, enabling efficient long-term planning for complex tasks. The framework assumes a deterministic environment and requires task descriptions in a formal language that can be represented as finite state machines.

## Key Results
- The RSG method achieves nearly perfect success rates on seen tasks and strong compositional generalization to novel tasks.
- RSGs significantly improve planning efficiency, reducing the number of expanded nodes compared to baselines.
- The learned subgoal dependencies enable efficient planning for complex tasks with a single final goal.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Learning binary classifiers for subgoals from unsegmented demonstrations enables efficient hierarchical planning.
- Mechanism: The model learns a goal conditionGo for each subgoal action term by maximizing the rationality score of demonstration trajectories. This rationality score aligns the observed actions with near-optimal actions for achieving the subgoal, as measured by the cost-to-go in the FSM-augmented planning model.
- Core assumption: Demonstration trajectories are "rational" — meaning the actions taken are close to optimal actions for the underlying subgoals.
- Evidence anchors:
  - [abstract]: "RSGs can be learned from weakly-annotated data, in the form of unsegmented demonstration trajectories, paired with abstract task descriptions..."
  - [section]: "Our training objective takes the following form: θ∗ = arg max θ 1|D| ∑ (¯s,¯a,t)∈D score(¯s, ¯a,t ;θ)" and "The rationality score measures the likelihood that the action a ∈ A t in state (s,v ) would have been chosen by a nearly-optimal agent..."
- Break condition: If demonstrations are highly suboptimal or noisy, the learned goal classifiers will not accurately represent the true subgoals, degrading planning performance.

### Mechanism 2
- Claim: Discovered dependencies between subgoals guide hierarchical search and improve planning efficiency.
- Mechanism: After learning subgoal classifiers, the model computes a dependency matrix by counting how often one subgoal precedes another in training trajectories. This matrix informs the planner about likely prerequisite subgoals, enabling it to suggest step-by-step instructions for planning toward a single final goal.
- Core assumption: The order in which subgoals appear in demonstrations reflects useful temporal dependencies for planning.
- Evidence anchors:
  - [section]: "Let bcount(o1,o 2) be the number of ¯s ∈ D such thato2 is achieved beforeo1 in ¯s. We construct a dependency matrixd by normalizing the bcount..."
  - [abstract]: "Our framework also discovers dependencies between RSGs, e.g., the task collect-wood is a helpful subgoal for the task craft-boat."
- Break condition: If the temporal order in demonstrations does not reflect true planning dependencies (e.g., due to task-specific shortcuts), the dependency matrix may mislead the planner.

### Mechanism 3
- Claim: Using FSM-augmented A* search with learned subgoal classifiers enables efficient planning for complex tasks.
- Mechanism: The planner constructs an FSM from the task description and composes it with the environment model. It then runs A* search in this augmented state space, using the learnedGo classifiers to evaluate subgoal transitions and guide the search toward satisfying the task.
- Core assumption: The environment is deterministic and fully observable, allowing exact planning with A*.
- Evidence anchors:
  - [abstract]: "Given a goal description, the learned subgoals and the derived dependencies facilitate off-the-shelf planning algorithms, such as A* and RRT..."
  - [section]: "We make plans using slightly modified versions of A* search, with a learned domain-dependent heuristic for previously seen tasks and a uniform heuristic for unseen tasks."
- Break condition: In stochastic or partially observable environments, the exact planning assumption breaks down, and the method would need significant modification.

## Foundational Learning

- Concept: Binary classification of states for subgoal detection
  - Why needed here: Subgoals must be detectable from environmental states to guide planning; binary classifiers provide a simple, efficient way to determine if a subgoal is satisfied.
  - Quick check question: What type of neural network architecture would you use to representGo if states are images versus continuous coordinates?

- Concept: Dynamic programming for sequence segmentation
  - Why needed here: Unsegmented demonstrations require inferring which state-action pairs correspond to which subgoals; dynamic programming efficiently finds the optimal segmentation that maximizes the rationality score.
  - Quick check question: How does the dynamic programming algorithm balance the rationality of primitive actions against the validity of FSM transitions?

- Concept: Finite State Machine (FSM) composition with environment models
  - Why needed here: Tasks with sequential or branching structures need a formal representation; FSMs provide this and can be composed with the environment to create an augmented planning problem.
  - Quick check question: What happens to the state space when you compose an FSM with the environment model?

## Architecture Onboarding

- Component map:
  - Goal classifiers (Go) -> FSM builder -> A* planner -> Dependency discoverer -> Dynamic programming segmenter -> LSTM encoders

- Critical path:
  1. Train goal classifiers using rationality score maximization
  2. Discover dependencies via bcount computation
  3. For a new task, build FSM and run FSM-augmented A* search
  4. Use Go classifiers to evaluate subgoal transitions during search

- Design tradeoffs:
  - Deterministic vs stochastic transitions: Current method assumes deterministic; stochastic would require MDP solvers and increase planning time
  - Separate vs shared parameterization of Go and Io: Separate gives more flexibility but doubles the number of networks
  - Uniform vs learned heuristics in A*: Learned is faster for seen tasks but requires training; uniform is slower but always available

- Failure signatures:
  - Low planning success rate: Likely due to poor goal classifiers or incorrect dependencies
  - Slow planning: Could indicate inefficient FSM construction or suboptimal heuristic
  - Unstable training: May result from poor rationality assumptions or noisy demonstrations

- First 3 experiments:
  1. Train RSGs on Crafting World with compositional tasks and evaluate planning success rate on seen tasks
  2. Test compositional generalization by evaluating on novel task compositions
  3. Evaluate planning efficiency with vs without discovered dependencies on complex tasks requiring multiple subgoals

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the RSG framework perform in domains with substantial stochasticity?
- Basis in paper: [inferred] The authors note that their assumption of a deterministic environment has allowed them to focus on the novel RSG formulation of subgoal models, and mention that for domains with substantial stochasticity, algorithmic changes may be required such as replacing maximum entropy IRL with maximum causal entropy.
- Why unresolved: The paper does not provide any experiments or analysis of the RSG framework's performance in stochastic domains, leaving open the question of how well it would generalize to such environments.
- What evidence would resolve it: Experiments applying the RSG framework to domains with varying levels of stochasticity, comparing performance to other methods, and analyzing the impact of different algorithmic modifications (e.g., maximum causal entropy vs. maximum entropy IRL).

### Open Question 2
- Question: Can RSGs be combined with unsupervised subgoal discovery methods to improve data efficiency?
- Basis in paper: [explicit] The authors mention that RSGs require trajectories with labeled task descriptions, and note that a meaningful future direction is to consider jointly learning subgoals and subgoal structures of tasks from both labeled and unlabeled trajectories.
- Why unresolved: The paper does not explore combining RSGs with unsupervised subgoal discovery methods or provide any analysis of the potential benefits or challenges of such an approach.
- What evidence would resolve it: Experiments applying RSGs to domains with a mix of labeled and unlabeled trajectories, comparing performance to RSGs trained only on labeled data, and analyzing the impact on data efficiency and generalization.

### Open Question 3
- Question: How does the choice of task description language (T L) impact the performance and generalization of RSGs?
- Basis in paper: [explicit] The authors note that their framework requires the starting and terminal nodes to be unique, and introduce virtual super starting and terminal nodes to unify multiple starting/terminal nodes. They also mention that the language T L used for describing tasks covers LTLf, a finite fragment of LTL.
- Why unresolved: The paper does not explore the impact of different task description languages on the performance and generalization of RSGs, leaving open the question of how sensitive the framework is to the choice of language.
- What evidence would resolve it: Experiments applying RSGs to domains with task descriptions in different languages (e.g., LTL, PDDL), comparing performance and generalization, and analyzing the impact of language complexity and expressiveness on the learned subgoals and planning efficiency.

## Limitations
- The framework assumes demonstrations are "rational" - i.e., actions are close to optimal for the underlying subgoals. This assumption may not hold in noisy or suboptimal demonstrations, potentially degrading goal classifier accuracy.
- The dependency discovery mechanism relies on temporal order in demonstrations, which may not always reflect true planning dependencies, especially in tasks with multiple valid solution paths.
- The method is designed for deterministic, fully observable environments, limiting its applicability to stochastic or partially observable domains without significant modification.

## Confidence

**High confidence**: The core mechanism of learning binary classifiers for subgoal detection and using them to guide planning algorithms is well-supported by experimental results showing improved planning efficiency and success rates. The compositional generalization results are particularly compelling.

**Medium confidence**: The dependency discovery mechanism and its contribution to planning efficiency are supported by experiments, but the assumptions about temporal order reflecting true dependencies warrant further investigation. The rationality assumption for demonstrations is reasonable but may not always hold in practice.

**Low confidence**: The scalability of the approach to more complex, real-world tasks remains unclear. The exact impact of the rationality assumption violations and the sensitivity to demonstration quality are not fully characterized.
