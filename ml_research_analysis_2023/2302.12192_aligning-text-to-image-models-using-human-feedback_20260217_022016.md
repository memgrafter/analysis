# Aligning Text-to-Image Models using Human Feedback

## Quick Facts
- arXiv ID: 2302.12192
- Source URL: https://arxiv.org/abs/2302.12192
- Reference count: 7
- Primary result: Fine-tuning text-to-image models using human feedback improves image-text alignment by up to 47% in human ratings

## Executive Summary
This paper presents a method to fine-tune text-to-image models using human feedback to improve alignment between generated images and text prompts. The approach involves collecting human ratings on model outputs, training a reward function to predict human preferences, and fine-tuning the model via reward-weighted likelihood maximization. Experiments on Stable Diffusion v1.5 show significant improvements in generating objects with specified colors, counts, and backgrounds, with up to 47% improvement in human-rated image-text alignment. The learned reward function outperforms CLIP score in predicting human preferences, and rejection sampling based on the reward function also improves alignment without model updates. However, the fine-tuned model shows some degradation in image fidelity, highlighting the alignment-fidelity tradeoff.

## Method Summary
The method consists of a three-stage process: (1) collecting human feedback by generating 27K images from 2700 text prompts using Stable Diffusion v1.5 and having humans rate image-text alignment on a binary scale, (2) training a reward function using the human-labeled dataset with an auxiliary prompt classification task to improve generalization, and (3) fine-tuning the Stable Diffusion model using reward-weighted likelihood maximization with pre-training loss regularization. The reward function is trained to predict human preferences using MSE loss, while the auxiliary task uses cross-entropy loss to classify prompt attributes (color, count, background). The fine-tuned model is evaluated using human ratings and automated metrics like CLIP score and FID score.

## Key Results
- Fine-tuned model improves image-text alignment by up to 47% in human ratings compared to baseline Stable Diffusion
- Learned reward function outperforms CLIP score in predicting human preferences
- Rejection sampling using reward function improves alignment without requiring model updates
- Fine-tuned model shows degradation in image fidelity, highlighting alignment-fidelity tradeoff

## Why This Works (Mechanism)
The method works by leveraging human feedback to directly optimize the text-to-image model for alignment with text prompts. By training a reward function to predict human preferences, the model can be fine-tuned to generate images that better match the specified attributes in the text. The use of an auxiliary prompt classification task helps the reward function generalize to unseen prompts by learning to extract relevant features. Reward-weighted likelihood maximization then updates the model parameters to increase the probability of generating aligned images. This approach allows the model to learn the fine-grained preferences of human raters and adapt its generation process accordingly.

## Architecture Onboarding

### Component Map
Stable Diffusion -> Image Generation -> Human Feedback Collection -> Reward Function Training -> Fine-tuning (Reward-weighted Likelihood Maximization) -> Fine-tuned Model

### Critical Path
1. Generate images using Stable Diffusion
2. Collect human feedback on image-text alignment
3. Train reward function using human-labeled dataset
4. Fine-tune Stable Diffusion using reward-weighted likelihood maximization
5. Evaluate fine-tuned model using human ratings and automated metrics

### Design Tradeoffs
- **Binary vs. ranking feedback**: Binary feedback is simpler to collect but may not capture nuanced preferences. Ranking feedback is more informative but harder to scale.
- **Reward-weighted likelihood vs. RLHF**: Reward-weighted likelihood is simpler to implement but may not explore the space as effectively as RLHF with online sample generation and KL regularization.
- **Pre-training loss regularization**: Including pre-training loss helps maintain image fidelity but may limit the extent of alignment improvements.

### Failure Signatures
- Overfitting to human dataset: Significant degradation in image fidelity, poor generalization to unseen prompts
- Reward function not generalizing: Low reward prediction accuracy on held-out prompts, minimal alignment improvements
- Imbalance in alignment-fidelity tradeoff: Large improvements in alignment but substantial decrease in image quality

## Open Questions the Paper Calls Out
### Open Question 1
How does the quality of human feedback (e.g., binary vs. ranking) affect the performance of the fine-tuned text-to-image model?
The paper uses binary human feedback for simplicity, but mentions that more informative feedback like ranking could be useful for complex text prompts. This remains unexplored as the study only used binary feedback.

### Open Question 2
What is the optimal balance between the alignment-fidelity tradeoff in fine-tuning text-to-image models using human feedback?
The paper observes that fine-tuning improves image-text alignment but degrades image fidelity, and suggests that careful investigations on design choices are important in balancing this tradeoff. The study provides initial observations but does not explore the full spectrum of design choices.

### Open Question 3
How does the diversity of the human dataset affect the generalization ability of the fine-tuned text-to-image model?
The paper notes that the diversity of the human dataset is limited and suggests that extension to more subjective text categories and informative human feedback would be important for future research. The study used a limited set of text categories and binary feedback.

### Open Question 4
How does the use of reinforcement learning with human feedback (RLHF) compare to reward-weighted likelihood maximization in fine-tuning text-to-image models?
The paper mentions that RLHF fine-tuning may lead to better models due to online sample generation and KL-regularization but defers the extension to RLHF for future work. The study only used reward-weighted likelihood maximization.

## Limitations
- Limited diversity in human dataset: The study focuses on relatively simple text prompts (colors, counts, backgrounds) and may not generalize to more complex real-world scenarios.
- Binary feedback may not capture nuanced preferences: Using binary human feedback is simpler but may not fully capture the fine-grained preferences of human raters.
- Potential overfitting to human dataset: The fine-tuned model shows some degradation in image fidelity, suggesting that it may be overfitting to the human feedback dataset.

## Confidence
- Human feedback collection method: Medium - The binary feedback approach is straightforward but may not capture nuanced preferences
- Reward function training: Medium - The auxiliary task helps with generalization but effectiveness is limited to the same dataset distribution
- Fine-tuning methodology: Medium - Reward-weighted likelihood maximization is simpler but may not explore the space as effectively as RLHF
- Evaluation metrics: Medium - Human ratings are subjective and may vary, while automated metrics like CLIP score have limitations
