# Check Your Facts and Try Again: Improving Large Language Models with External Knowledge and Automated Feedback

## Quick Facts
- **arXiv ID**: 2302.12813
- **Source URL**: https://arxiv.org/abs/2302.12813
- **Reference count**: 8
- **Key outcome**: LLM-Augmenter significantly reduces ChatGPT hallucinations while maintaining fluency, improving performance by up to 32% on usefulness metrics.

## Executive Summary
This paper introduces LLM-Augmenter, a system that improves large language models like ChatGPT by grounding responses in external knowledge and using automated feedback to iteratively revise outputs. The system addresses a critical limitation of LLMs - their tendency to hallucinate facts - by retrieving relevant information from task-specific databases and providing iterative feedback to guide response refinement. Experiments on customer service dialogs and question answering tasks demonstrate that LLM-Augmenter substantially improves factual accuracy (absolute +10% in Knowledge F1) while maintaining response fluency and informativeness.

## Method Summary
LLM-Augmenter is a modular system that enhances LLMs through four plug-and-play components: Working Memory (tracks dialog state), Policy (selects actions), Action Executor (performs actions including knowledge retrieval and prompt generation), and Utility (evaluates responses and generates feedback). The system retrieves relevant evidence from external knowledge sources, consolidates this information into evidence chains, and provides it to the LLM as part of the prompt. A utility function evaluates the generated response for factual accuracy, and if needed, generates feedback that guides the LLM to revise its response iteratively until meeting quality thresholds.

## Key Results
- Reduces ChatGPT hallucinations by up to 32% on usefulness metrics
- Improves factual accuracy by absolute +10% in Knowledge F1 scores
- Maintains response fluency and informativeness across multiple evaluation metrics
- Shows significant performance gains over both closed-book ChatGPT and rule-based baselines

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The iterative revision process using feedback significantly improves the factual accuracy of LLM responses.
- Mechanism: LLM-Augmenter first generates a candidate response using external knowledge, then uses a utility function to evaluate the response. If the response fails to meet the utility threshold (e.g., low Knowledge F1), a feedback message is generated to guide the LLM to revise its response. This process repeats until a satisfactory response is produced.
- Core assumption: The utility function can reliably detect factual inaccuracies in LLM responses, and the feedback mechanism can effectively guide the LLM to generate more accurate responses.

### Mechanism 2
- Claim: Providing task-specific external knowledge to the LLM significantly improves its ability to generate grounded and factual responses.
- Mechanism: LLM-Augmenter retrieves relevant evidence from external knowledge sources (e.g., task-specific databases, Wikipedia) and consolidates this evidence into evidence chains. This consolidated evidence is then provided to the LLM as part of the prompt, allowing it to generate responses grounded in factual information.
- Core assumption: The external knowledge sources contain relevant and accurate information for the task at hand, and the evidence consolidation process effectively filters out irrelevant information.

### Mechanism 3
- Claim: The combination of external knowledge and automated feedback leads to synergistic improvements in LLM response quality.
- Mechanism: LLM-Augmenter uses external knowledge to provide the LLM with relevant factual information, and then uses automated feedback to guide the LLM in generating responses that are both grounded in this knowledge and aligned with the desired utility function (e.g., factuality, informativeness).
- Core assumption: The external knowledge and the automated feedback are complementary, with the knowledge providing the factual basis for the response and the feedback guiding the LLM to generate a response that effectively utilizes this knowledge.

## Architecture Onboarding

- **Component map**: Working Memory -> Policy -> Action Executor (Knowledge Consolidator, Prompt Engine) -> LLM -> Utility -> Feedback
- **Critical path**: User query received → Knowledge Consolidator retrieves and consolidates external knowledge → Prompt Engine generates LLM prompt → LLM generates candidate response → Utility evaluates response and generates feedback if needed → If feedback generated, prompt revised and repeat from Prompt Engine step → Final response sent to user
- **Design tradeoffs**: Accuracy vs latency (external knowledge and feedback improve accuracy but increase response time); comprehensiveness of knowledge vs computational efficiency (retrieving more knowledge improves accuracy but increases cost)
- **Failure signatures**: Responses not grounded in external knowledge; responses misaligned with utility function; failure to retrieve relevant knowledge; evidence consolidation filtering failures; feedback mechanism ineffectiveness; system latency issues
- **First 3 experiments**:
  1. Evaluate impact of external knowledge on factual accuracy by comparing LLM performance with and without knowledge access on benchmark datasets
  2. Evaluate impact of automated feedback on factual accuracy by comparing LLM performance with and without feedback on benchmark datasets
  3. Evaluate combined impact of external knowledge and automated feedback by comparing LLM performance with both components versus only one component on benchmark datasets

## Limitations
- Performance heavily depends on the quality, relevance, and completeness of external knowledge sources
- Effectiveness of automated feedback relies on well-designed utility functions and the LLM's ability to incorporate feedback
- May increase system latency due to knowledge retrieval and iterative feedback processes
- Computational cost increases with the size and complexity of external knowledge sources

## Confidence
- **High Confidence**: The core concept of using external knowledge and iterative feedback to improve LLM response quality is well-supported by related literature on retrieval-augmented generation and reinforcement learning.
- **Medium Confidence**: The specific implementation details of the LLM-Augmenter system, such as the exact knowledge consolidation algorithm and the utility function design, may impact its effectiveness.
- **Low Confidence**: The paper does not provide sufficient details on the experimental setup, evaluation metrics, or ablation studies to fully assess the relative contributions of the external knowledge and feedback components.
