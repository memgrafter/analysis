# Evaluating the Utility of GAN Generated Synthetic Tabular Data for Class Balancing and Low Resource Settings

## Quick Facts
- **arXiv ID**: 2306.13929
- **Source URL**: https://arxiv.org/abs/2306.13929
- **Reference count**: 0
- **Primary result**: GAN-generated synthetic data improves recall in class imbalance and low-resource classification tasks.

## Executive Summary
This study investigates the effectiveness of GAN-generated synthetic data for addressing class imbalance and low-resource scenarios in classification tasks. Using an insurance claims dataset, the research compares GAN-based balancing (CTGAN and CopulaGAN) against traditional methods (SMOTE, ADASYN) and evaluates model performance in both class balancing and low-resource settings. The experiments employ GLM for class balancing and Random Forest for low-resource scenarios, with recall as the primary evaluation metric.

## Method Summary
The methodology involves training GAN models (CTGAN and CopulaGAN) on the original minority class data, generating synthetic samples, and using these to balance or enrich the training sets. For class balancing experiments, GLM with Recursive Feature Elimination is trained on balanced data. For low-resource experiments, Random Forest with PCA dimensionality reduction is trained on data enriched with synthetic samples from subsets (10%, 20%, 40%) of the original data. Performance is evaluated using recall, G-mean, and AUC metrics on stratified test sets.

## Key Results
- Models trained on GAN-balanced data achieved the highest recall values compared to other balancing techniques.
- GAN-enriched data consistently produced superior recall and G-mean values in low-resource settings across all data versions (10%, 20%, 40%).
- CopulaGAN was selected over CTGAN due to faster training and slightly better detection scores.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: GAN-generated synthetic data improves recall in class imbalance scenarios by learning minority class distributions.
- **Mechanism**: GAN models capture minority class statistical properties and generate synthetic samples that enrich the training set, allowing classifiers to learn patterns from underrepresented classes more effectively.
- **Core assumption**: The synthetic data generation preserves the statistical and structural properties of the minority class.
- **Evidence anchors**: Models trained on data enriched with GAN-synthesized data exhibited better recall values than original data; models trained on balanced data using GAN have resulted in the highest recall at a threshold of 0.7.
- **Break condition**: If GAN training fails to converge or generates synthetic data that does not match minority class distributions, recall improvements will not materialize.

### Mechanism 2
- **Claim**: Using synthetic data in low-resource settings compensates for limited training data without degrading model performance.
- **Mechanism**: By generating synthetic samples from small subsets of the original data, the model effectively trains on a larger, enriched dataset that preserves feature relationships and class balance.
- **Core assumption**: The GAN models can generalize minority class characteristics from limited data points to produce useful synthetic samples.
- **Evidence anchors**: Models trained on data enriched with GAN-synthesized data exhibited better recall values than original data; models trained on data enriched with GAN synthetic data in low-resource settings have consistently produced superior recall values.
- **Break condition**: If synthetic data introduces noise or distributional drift that misleads the classifier, performance gains will reverse.

### Mechanism 3
- **Claim**: Balancing techniques improve classification by adjusting class priors and feature distributions.
- **Mechanism**: Each balancing method augments minority class samples differently—SMOTE via interpolation, ADASYN via weighted sampling, GAN via learned generation—allowing models to better fit minority class decision boundaries.
- **Core assumption**: The choice of balancing technique aligns with dataset characteristics.
- **Evidence anchors**: The GLM model trained on GAN-balanced data achieved the highest recall value; models trained on data enriched with GAN synthetic data consistently yield superior recall and G-mean values compared to other data versions.
- **Break condition**: If the synthetic samples do not adequately represent minority class variance, balancing may overfit or misalign model decision boundaries.

- **Component map**: Data preprocessing → Stratified sampling → GAN training → Synthetic data generation → Data balancing/enrichment → Model training (GLM/RF) → Evaluation (recall, G-mean, AUC)

## Limitations
- Results may not generalize beyond the specific insurance dataset and chosen algorithms.
- The study did not test alternative classification algorithms or extensive hyperparameter configurations.
- No validation on real-world deployment scenarios or cross-domain applicability.

## Confidence
- **High Confidence**: GAN-synthesized data improves recall in class imbalance scenarios.
- **Medium Confidence**: GANs are superior to SMOTE/ADASYN for this specific dataset and algorithms.
- **Low Confidence**: Generalizability of results to other datasets, algorithms, or real-world deployment.
