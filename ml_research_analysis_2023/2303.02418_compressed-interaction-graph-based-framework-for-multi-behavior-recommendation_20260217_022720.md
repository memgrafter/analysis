# Compressed Interaction Graph based Framework for Multi-behavior Recommendation

## Quick Facts
- arXiv ID: 2303.02418
- Source URL: https://arxiv.org/abs/2303.02418
- Reference count: 40
- Key outcome: Proposes CIGF framework combining CIGCN for high-order relation modeling and MESI for multi-task learning, achieving up to 27.67% improvement in NDCG on three real-world datasets

## Executive Summary
This paper introduces a Compressed Interaction Graph based Framework (CIGF) for multi-behavior recommendation that addresses two key challenges: modeling instance-level high-order relations and alleviating gradient conflicts in multi-task learning. The framework consists of a Compressed Interaction Graph Convolution Network (CIGCN) that explicitly captures high-order interactions between instances, and a Multi-Expert with Separate Input (MESI) network that handles multiple recommendation tasks with dedicated inputs. Experimental results demonstrate consistent improvements over state-of-the-art methods across three real-world datasets, with significant gains in recommendation quality metrics.

## Method Summary
The CIGF framework combines two complementary components to tackle multi-behavior recommendation. The CIGCN module uses compressed interaction operations to efficiently model high-order relations between instances without the computational burden of traditional high-order graph convolutions. The MESI network employs separate input branches for each recommendation task while sharing underlying representations, effectively mitigating gradient conflicts that typically arise in multi-task learning scenarios. This design allows the model to capture complex behavioral patterns while maintaining stable training dynamics across multiple objectives.

## Key Results
- CIGF achieves up to 27.67% improvement in NDCG compared to state-of-the-art baselines
- Ablation studies confirm both CIGCN and MESI components contribute significantly to performance gains
- The framework demonstrates superior ability to capture high-order relations and reduce negative transfer in multi-task scenarios

## Why This Works (Mechanism)
The framework succeeds by explicitly modeling instance-level high-order relations through compressed interaction operations, which efficiently capture complex behavioral patterns without prohibitive computational costs. The separate input design in MESI prevents gradient conflicts between tasks by isolating task-specific information while maintaining shared representations for common patterns. This dual approach addresses both the relational complexity and optimization stability challenges inherent in multi-behavior recommendation systems.

## Architecture Onboarding

Component Map:
Input Features -> MESI Separate Inputs -> Shared Representations -> CIGCN High-Order Modeling -> Task-Specific Outputs

Critical Path:
User features → MESI task-specific encoders → shared embedding space → CIGCN compressed interactions → final prediction layers for each behavior type

Design Tradeoffs:
The framework trades computational complexity for modeling accuracy by using compressed interactions instead of full high-order convolutions. The separate input design sacrifices some information sharing between tasks to achieve better gradient stability. These choices prioritize recommendation quality over model simplicity and inference speed.

Failure Signatures:
- Performance degradation on sparse datasets suggests overfitting in CIGCN
- Imbalanced task performance indicates insufficient information sharing in MESI
- Slow convergence may signal inadequate gradient conflict mitigation
- Memory issues during training point to compressed interaction parameter explosion

## Limitations
- Potential overfitting of CIGCN on limited or sparse datasets due to complex architecture
- Information loss between tasks resulting from separate input design in MESI
- Limited generalizability due to evaluation on specific datasets and metrics only
- Unclear computational efficiency for real-world deployment scenarios
- Lack of detailed hyperparameter tuning guidance affecting reproducibility
