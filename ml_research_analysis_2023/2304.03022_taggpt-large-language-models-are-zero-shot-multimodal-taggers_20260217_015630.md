# TagGPT: Large Language Models are Zero-shot Multimodal Taggers

## Quick Facts
- arXiv ID: 2304.03022
- Source URL: https://arxiv.org/abs/2304.03022
- Reference count: 24
- One-line primary result: TagGPT achieves over 75% precision and recall in zero-shot multimodal tagging using LLMs.

## Executive Summary
This paper introduces TagGPT, a system that leverages large language models to automatically generate and assign high-quality tags to multimodal content without task-specific training. The approach converts multimodal data into textual clues (OCR, ASR, titles) and uses prompt engineering to guide LLMs in generating candidate tags. A post-processing module filters and merges tags based on frequency and semantic similarity to create a high-quality tag set. TagGPT offers two zero-shot tagging methods: a generative approach with late semantic matching and a selective approach with early matching in prompts. Experiments on real-world datasets show TagGPT outperforms human annotations and existing tagging systems in both tag quality and coverage.

## Method Summary
TagGPT operates by first extracting textual clues from multimodal content using OCR, ASR, and other methods. These clues are fed into an LLM (specifically GPT-3.5) through carefully designed instruction prompts to generate candidate tags. The system then filters out overly frequent tags (likely popularity-biased) and overly rare tags (likely noise), and merges semantically similar tags using vector embeddings to reduce redundancy. For tagging new data, TagGPT provides two methods: a generative approach that matches LLM-generated tags with the tag set using cosine similarity, and a selective approach that uses in-context learning by including both the input clues and candidate tags in the prompt. The approach is evaluated on Kuaishou and Food.com datasets, demonstrating high precision and recall in tag generation.

## Key Results
- Achieved precision and recall scores over 75% on Kuaishou and Food.com datasets
- Outperformed human annotations and existing tagging systems in tag quality and coverage
- Demonstrated strong generalization ability across different multimodal domains

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LLM reasoning + prompt engineering can generate high-quality tags from multimodal textual clues in a zero-shot manner.
- Mechanism: The system converts multimodal content into unified textual clues (OCR, ASR, titles), feeds them into an LLM via carefully designed instruction prompts, and generates candidate tags based on the LLM's understanding and reasoning ability.
- Core assumption: The LLM has sufficient world knowledge and reasoning capability to infer meaningful tags from textual descriptions of multimodal content.
- Evidence anchors:
  - [abstract]: "Our core insight is that, through elaborate prompt engineering, LLMs are able to extract and reason about proper tags given textual clues of multimodal data, e.g., OCR, ASR, title, etc."
  - [section 2.1.2]: "we have created multiple instruction templates for acquiring tags and filled in the corresponding positions with textual clues that correspond to the single multimodal data provided from upstream. The input text is then fed into the LLM, and the corresponding tag result can be obtained."
- Break condition: If the LLM lacks sufficient domain knowledge or the textual clues are too sparse/incomplete, tag quality will degrade significantly.
