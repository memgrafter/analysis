# MM-DAG: Multi-task DAG Learning for Multi-modal Data -- with Application for Traffic Congestion Analysis

## Quick Facts
- arXiv ID: 2306.02831
- Source URL: https://arxiv.org/abs/2306.02831
- Reference count: 40
- Key outcome: MM-DAG framework achieves up to +16.1% F1 score improvement in structure learning by introducing multi-modal-to-multi-modal regression and a novel Causality Difference measure for multi-task DAG learning with heterogeneous node types.

## Executive Summary
This paper introduces MM-DAG, a multi-task learning framework for learning causal structures from multi-modal data across multiple related tasks. The key innovation is handling overlapping and distinct variables across tasks while maintaining consistent causal relationships through a novel multi-modal regression approach and a differentiable Causality Difference measure. Applied to traffic congestion analysis, MM-DAG reveals consistent causal patterns across intersections and outperforms existing methods in structure learning accuracy.

## Method Summary
MM-DAG addresses multi-task DAG learning with multi-modal data (scalars, vectors, and functional nodes) through a unified framework. The method uses Functional Principal Component Analysis (FPCA) to decompose functional nodes, then applies a multi-modal-to-multi-modal regression to model linear causal relationships across all node types. A novel Causality Difference (CD) measure quantifies structural differences between DAGs with overlapping nodes, with a differentiable approximation (DCD) enabling gradient-based optimization. The framework jointly learns consistent DAG structures across multiple tasks while handling the heterogeneity of node types and the complexity of overlapping variable sets.

## Key Results
- Achieves up to +16.1% F1 score improvement over baseline methods in synthetic structure learning experiments
- Reduces false positive rates by 8.7% compared to state-of-the-art DAG learning methods
- Successfully identifies consistent causal patterns across traffic intersections in SUMO simulation, with 5 intersections showing high structural similarity in learned causal relationships
- Demonstrates robustness to increasing numbers of tasks, with performance improving as task count increases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The multi-modal-to-multi-modal regression enables consistent modeling of causal dependencies across scalar, vector, and functional node types.
- Mechanism: By decomposing functional nodes into orthonormal basis functions and mapping all node types to a unified coefficient space, the model preserves linear causal relationships while handling infinite-dimensional functional data.
- Core assumption: Linear transformations can approximate causal dependencies between heterogeneous node types.
- Evidence anchors:
  - [abstract]: "innovatively propose a multi-modal regression for linear causal relationship description of different variables"
  - [section 3.1]: Detailed equations (3)-(8) showing the four cases of regression between different node type combinations
  - [corpus]: Weak - related papers focus on DAG learning but don't address multi-modal node types
- Break condition: If the underlying causal relationships are strongly nonlinear, the linear approximation will fail to capture the true dependencies.

### Mechanism 2
- Claim: The Causality Difference (CD) measure effectively quantifies structural differences between DAGs with overlapping but distinct node sets.
- Mechanism: By constructing a transitive causal matrix that captures all possible causal orders and their uncertainties, CD can compare DAGs even when they have different but overlapping node sets.
- Core assumption: The transitive closure of causal relationships can be represented as a probabilistic matrix that captures both deterministic and uncertain causal orders.
- Evidence anchors:
  - [abstract]: "develop a novel Causality Difference (𝐶𝐷 ) measure and its differentiable approximator"
  - [section 3.3]: Definitions 1-2 and Theorem 1 showing topological interpretation of CD
  - [corpus]: Missing - no related papers directly address causal structure difference measures for DAGs with distinct nodes
- Break condition: If the causal relationships between overlapping nodes are highly complex or non-transitive, the transitive closure assumption may break down.

### Mechanism 3
- Claim: The differentiable Causal Difference (DCD) approximation enables efficient gradient-based optimization of the multi-task DAG structure.
- Mechanism: By using a sigmoid-based approximation of the transitive causal matrix, DCD provides smooth gradients that can be incorporated into the overall loss function.
- Core assumption: The sigmoid approximation converges to the true transitive causal matrix as the scaling parameter increases.
- Evidence anchors:
  - [abstract]: "develop a novel Causality Difference (𝐶𝐷 ) measure and its differentiable approximator"
  - [section 3.3]: Theorem 2 proving consistency of the differentiable approximation
  - [corpus]: Missing - no related papers discuss differentiable approximations of causal structure differences
- Break condition: If the scaling parameter is not sufficiently large, the approximation may introduce bias that affects the learned structure.

## Architecture Onboarding

- Component map: Input data → FPCA decomposition → Coefficient extraction → Multi-modal regression → Transitive causal matrix → DCD calculation → Structure optimization

- Critical path: Data preprocessing → Coefficient extraction → Multi-modal regression → Transitive causal matrix computation → DCD calculation → Structure optimization

- Design tradeoffs:
  - Linear vs. nonlinear modeling: The current implementation uses linear assumptions for simplicity, but this could be extended to nonlinear models
  - Differentiability vs. accuracy: The sigmoid approximation enables gradient-based optimization but may introduce approximation error
  - Task similarity weighting: The similarity parameter affects how much information is shared between tasks

- Failure signatures:
  - Poor F1 scores despite high sample sizes: May indicate the linear assumption is violated
  - High false positive rates: Could suggest the L1 penalty is too weak or the task similarity is mis-specified
  - Inconsistent structures across tasks: May indicate the CD penalty is not strong enough

- First 3 experiments:

  3. Validate the differentiability of the DCD approximation by checking gradient consistency using finite differences

## Limitations

- The framework assumes linear causal relationships, which may not capture nonlinear dependencies in complex systems
- The differentiable approximation of CD measure may introduce approximation error that affects learned structures
- Performance depends on the quality of FPCA decomposition and appropriate selection of the number of Fourier bases
