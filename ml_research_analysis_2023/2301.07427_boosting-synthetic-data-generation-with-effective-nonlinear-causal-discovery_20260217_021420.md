# Boosting Synthetic Data Generation with Effective Nonlinear Causal Discovery

## Quick Facts
- arXiv ID: 2301.07427
- Source URL: https://arxiv.org/abs/2301.07427
- Reference count: 40
- Primary result: Proposed method improves causal discovery runtime while maintaining accuracy and outperforms state-of-the-art generative models in synthetic data quality

## Executive Summary
This paper addresses the challenge of synthetic data generation when variable dependencies are unknown. The authors propose a two-stage approach that first discovers nonlinear causal relationships using a boosted version of nonlinear causal discovery (NCD) integrated with Apriori pattern mining, then generates synthetic data that respects these discovered causal structures. The method, called GENCDA, significantly improves causal discovery efficiency while maintaining high accuracy and produces superior synthetic data compared to random generation and state-of-the-art generative models.

## Method Summary
The proposed method combines Apriori pattern mining with nonlinear causal discovery (NCDA) to efficiently identify causal relationships among variables. Apriori identifies frequent itemsets that indicate correlated variables, which are then used to restrict the search space for NCD. The discovered causal structure is represented as a directed acyclic graph (DAG), which is then used by GENCDA to generate synthetic data. GENCDA fits distributions to independent variables and trains regressors for dependent variables based on their parent nodes in the DAG. The approach uses an ensemble of regressors (Gaussian Process, SVM, k-Nearest Neighbors, and Decision Tree) and various distributions for independent variables.

## Key Results
- NCDA significantly reduces causal discovery runtime compared to NCD while maintaining high accuracy (precision, recall, F1-measure)
- GENCDA outperforms random generation and state-of-the-art generative models (TVAE, CT-GAN) in synthetic data quality
- Evaluation metrics show GENCDA achieves lower SSE, RMSE, and LOF scores compared to baselines
- The method requires fewer instances than GANs or VAEs and works effectively in high-dimensional settings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Apriori pattern mining reduces the search space for nonlinear causal discovery.
- Mechanism: Apriori identifies frequent itemsets that indicate correlated variables, which are then used as a filter to limit the variables considered by NCD.
- Core assumption: Variables appearing together in frequent itemsets are likely to have causal relationships.
- Evidence anchors:
  - [abstract] "We boost them by restricting the causal discovery among the features appearing in the frequent patterns efficiently retrieved by a pattern mining algorithm."
  - [section] "Our idea can be summarized as follows. First, we apply Apriori to the dataset under study for extracting the frequent patterns. Then, we test the causal relationships considering only the combination of variables appearing together in any of the itemset extracted with Apriori."
- Break condition: If Apriori fails to identify frequent itemsets containing causally related variables, the filtering will be ineffective.

### Mechanism 2
- Claim: NCDA discovers nonlinear causal relationships more efficiently than NCD alone.
- Mechanism: NCDA combines Apriori's frequent pattern mining with NCD's nonlinear causal discovery, reducing the number of variable combinations to test.
- Core assumption: The computational complexity of NCD is reduced when the search space is limited to variables appearing in frequent itemsets.
- Evidence anchors:
  - [abstract] "State-of-the-art methods for nonlinear causal discovery are typically inefficient. We boost them by restricting the causal discovery among the features appearing in the frequent patterns efficiently retrieved by a pattern mining algorithm."
  - [section] "Our contribution is twofold. First, we design an efficient method for nonlinear causal discovery based on pattern mining named NCDA (Nonlinear Causal Discovery with Apriori)."
- Break condition: If the variables in frequent itemsets do not include the causally related variables, NCDA will miss the causal relationships.

### Mechanism 3
- Claim: GENCDA generates synthetic data that respects the discovered causal structure.
- Mechanism: GENCDA uses the causal DAG discovered by NCDA to generate synthetic data, ensuring that dependent variables are generated based on their parent variables.
- Core assumption: The causal relationships discovered by NCDA are accurate and can be used to generate synthetic data.
- Evidence anchors:
  - [abstract] "Second, we implement GENCDA, a GEnerative method based on NCDA."
  - [section] "GENCDA exploits the causal relationships discovered by NCDA to generate a synthetic dataset respecting such causal structure."
- Break condition: If the causal relationships discovered by NCDA are incorrect, the synthetic data generated by GENCDA will not respect the true causal structure.

## Architecture Onboarding

- Component map:
  - NCDA: Nonlinear Causal Discovery with Apriori
    - Apriori: Pattern mining for frequent itemsets
    - NCD: Nonlinear causal discovery algorithm
  - GENCDA: Generative method based on NCDA
    - Regressors: Gaussian Process Regressor, Support Vector Machine, k-Nearest Neighbors, Decision Tree Regressor
    - Distributions: Uniform, Exponential, Gamma, Beta, etc.

- Critical path:
  1. Apply Apriori to identify frequent itemsets
  2. Use NCDA to discover causal relationships among variables in frequent itemsets
  3. Use GENCDA to generate synthetic data respecting the discovered causal structure

- Design tradeoffs:
  - Using Apriori for filtering reduces the search space for NCD but may miss some causal relationships if they are not captured in frequent itemsets.
  - Using multiple regressors in GENCDA increases the robustness of synthetic data generation but also increases computational complexity.

- Failure signatures:
  - If NCDA fails to identify causal relationships, the synthetic data generated by GENCDA will not respect the true causal structure.
  - If the regressors in GENCDA are not well-calibrated, the synthetic data may not accurately represent the real data distribution.

- First 3 experiments:
  1. Test NCDA on a synthetic dataset with known causal relationships to evaluate its accuracy in discovering causal relationships.
  2. Compare the runtime of NCDA with NCD on datasets of increasing size to demonstrate the efficiency gain from using Apriori filtering.
  3. Generate synthetic data using GENCDA and evaluate its similarity to the real data using measures such as SSE, RMSE, and LOF.

## Limitations

- The effectiveness of Apriori pattern mining depends heavily on the minimum support threshold and may miss causal relationships not captured in frequent itemsets
- The method assumes causal relationships can be accurately discovered from the data, which may not hold for all real-world datasets
- The ensemble of regressors in GENCDA increases computational complexity and may not be optimal for all data distributions

## Confidence

- High confidence in runtime improvements over NCD due to the clear computational complexity reduction from pattern mining
- Medium confidence in causal discovery accuracy as the method relies on multiple assumptions about the relationship between frequent patterns and causal structures
- Medium confidence in synthetic data generation quality as it depends on the accuracy of the discovered causal relationships
