# Learning Choice Functions with Gaussian Processes

## Quick Facts

## Executive Summary
This paper introduces ChoiceGP, a Gaussian Process-based method for learning choice functions from choice data through Pareto rationalization. The approach models multiple latent utility functions and assumes objects are chosen based on Pareto dominance among these utilities. The method learns both the number and values of these latent utilities using variational inference and a forward selection procedure with PSIS-LOO cross-validation. Simulation experiments demonstrate superior performance compared to existing methods.

## Method Summary
The proposed method models choice functions using multiple latent utility functions represented as independent Gaussian Processes. For each choice set, the model defines the chosen subset as the Pareto-optimal objects under the latent utility vector. The likelihood function captures the probability that observed choice sets are consistent with Pareto dominance, with probabilistic relaxation to account for noise and discernibility limits. Variational inference approximates the intractable posterior, and latent dimension selection is performed through forward selection with PSIS-LOO cross-validation.

## Key Results
- ChoiceGP outperforms state-of-the-art methods (ChoiceNN and PLPR) on synthetic and real-world datasets
- The model is robust to noise and can learn the number of latent utilities from data
- On synthetic datasets (DTLZ and ZDT), ChoiceGP achieves an average accuracy of 0.843 compared to 0.707 for ChoiceNN and 0.778 for PLPR
- The method successfully handles both explicit choice data and implicit choice data from optimization problems

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The model assumes multiple latent utility functions, and objects are chosen based on Pareto dominance among these utilities.
- Mechanism: For each choice set A, the model defines C(A) as the set of Pareto-optimal objects under the latent utility vector u(x) = [u1(x), ..., ud(x)]⊤. Objects in C(A) are undominated in the strong Pareto sense: for each rejected object v ∈ R(A), there exists at least one object in C(A) that is not worse than v on all utilities.
- Core assumption: Incomparability arises either from objects having contradictory characteristics (incomparability) or from incompleteness (lack of knowledge), both modeled as multiple latent utilities.

- Break condition: If the true choice process is based on a single utility function or if the Pareto assumption doesn't hold for the application domain.

### Mechanism 2
- Claim: Gaussian Processes model the latent utility functions, and the likelihood captures the probability that choice data is consistent with Pareto dominance.
- Mechanism: Each latent utility ui(x) is modeled as an independent GP prior. The likelihood function computes the probability that observed choice sets are Pareto-undominated under these utilities, relaxing the hard Pareto conditions with probabilistic terms involving the CDF of the standard Normal distribution.
- Core assumption: The inconsistencies in choices are due to either a limit of discernibility (objects with similar utilities are hard to distinguish) or noise in utility observation.
- Evidence anchors:

  - [section]: "To account for errors in Alice's choices, we extend the likelihood in (2) to choice functions."

- Break condition: If the choice data is too noisy or the GP kernel assumptions are violated, the model may not capture the true utility structure.

### Mechanism 3
- Claim: Variational inference with a forward selection procedure for the latent dimension allows scalable learning and model selection.
- Mechanism: The intractable posterior is approximated using variational inference, which is well-defined despite the label-switching symmetry problem. The latent dimension d is selected by incrementally increasing d and choosing the model that maximizes PSIS-LOO cross-validation.
- Core assumption: The variational approximation can adequately capture the posterior, and PSIS-LOO is a reliable model selection criterion for this nonparametric model.

## Architecture Onboarding

- Component map:
  - Input: Choice data {(C(Ak), Ak)}m k=1
  - Latent utilities: u(x) = [u1(x), ..., ud(x)]⊤ modeled as independent GPs
  - Likelihood: Probabilistic relaxation of Pareto dominance conditions
  - Inference: Variational approximation of posterior p(u(X)|Dm)
  - Output: Predicted choice probabilities P(C(A*), A*|Dm)
  - Model selection: Forward selection with PSIS-LOO

- Critical path: Input → Latent utility GPs → Likelihood computation → Variational inference → Posterior approximation → Prediction

- Design tradeoffs:
  - Parametric vs. nonparametric: ChoiceGP uses nonparametric GPs, allowing flexible utility functions but requiring more computation
  - Single vs. multiple utilities: Multiple utilities capture incomparability but increase model complexity
  - Exact vs. approximate inference: Variational inference is scalable but introduces approximation error

- Failure signatures:
  - Poor predictive performance: May indicate incorrect latent dimension or poor variational approximation
  - High computational cost: May indicate need for sparse GP approximations or dimensionality reduction
  - Unreliable model selection: May indicate PSIS-LOO is not appropriate for this model structure
