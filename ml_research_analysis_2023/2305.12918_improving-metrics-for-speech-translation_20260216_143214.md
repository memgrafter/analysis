# Improving Metrics for Speech Translation

## Quick Facts
- arXiv ID: 2305.12918
- Source URL: https://arxiv.org/abs/2305.12918
- Reference count: 22
- Key outcome: Paraboth method improves correlation with human judgments by generating multiple paraphrased references and hypotheses

## Executive Summary
This paper addresses the limitation of traditional evaluation metrics in speech translation that rely on single references, which can produce misleading results. The authors introduce Paraboth, an augmentation method that generates multiple paraphrased versions of both the reference and hypothesis using neural machine translation-based paraphrasing. This approach significantly improves the correlation between automated metrics and human quality perception in speech translation tasks, particularly for Swiss German to Standard German translation.

## Method Summary
The Paraboth method enhances traditional translation metrics by generating multiple paraphrased versions of both the reference and hypothesis using a neural machine translation-based paraphrasing algorithm. For each original reference-hypothesis pair, the system creates k paraphrased versions of both texts, then calculates the metric score for all k² combinations before averaging the results. The authors also introduce two new evaluation datasets specifically designed for Swiss German speech-to-text systems, allowing for more accurate assessment of speech translation metrics. The method is tested with various metrics including WER, CER, and BLEU, demonstrating improved correlation with human judgments.

## Key Results
- Paraboth improves Kendall's Tau-like correlation for WER from 0.3472 to 0.5115 on GER-HSR-1K dataset
- Kendall's Tau-like correlation for CER improves from 0.2632 to 0.4811 using Paraboth
- BLEU correlation increases from 0.3167 to 0.4892 with Paraboth augmentation
- Best performance achieved with six paraphrases for both reference and hypothesis

## Why This Works (Mechanism)
Traditional metrics like WER, CER, and BLEU suffer when only single references are available because they penalize valid alternative expressions that convey the same meaning. By generating multiple paraphrased versions of both the reference and hypothesis, Paraboth captures a broader range of acceptable linguistic variations. This approach better aligns with how human evaluators assess translation quality, which considers semantic equivalence rather than exact string matching. The k² combinations ensure that the metric captures all possible alignments between paraphrased versions, reducing the impact of any single reference's linguistic constraints.

## Architecture Onboarding

Component Map: Input Text -> Paraphrasing Engine -> k Paraphrased Versions -> Metric Calculator -> Average Score

Critical Path: Reference/Hypothesis → Paraphrasing (k iterations) → k² Metric Calculations → Average → Final Score

Design Tradeoffs: More paraphrases improve correlation but increase computation time; fewer paraphrases reduce accuracy but improve efficiency.

Failure Signatures: Poor paraphrasing quality leads to metric degradation; insufficient paraphrase diversity fails to capture necessary linguistic variations.

## Limitations
- Evaluation limited to Swiss German datasets, raising generalizability concerns
- Modest absolute improvement in correlation metrics (approximately 0.15-0.16 gain)
- Computational costs and latency implications of multiple paraphrase generation not addressed
- No investigation of potential bias introduced by paraphrasing model training data

## Confidence

High Confidence: Core Paraboth methodology and implementation details are clearly described and reproducible.

Medium Confidence: Reported improvements are based on specific datasets and may not generalize to other speech translation tasks.

Low Confidence: Claims about broader impact on speech translation evaluation practices lack supporting evidence.
