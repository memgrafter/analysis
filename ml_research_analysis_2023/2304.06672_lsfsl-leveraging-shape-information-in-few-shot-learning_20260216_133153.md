# LSFSL: Leveraging Shape Information in Few-shot Learning

## Quick Facts
- arXiv ID: 2304.06672
- Source URL: https://arxiv.org/abs/2304.06672
- Reference count: 40
- Key outcome: LSFSL improves few-shot learning performance by 1-2% across multiple benchmarks while enhancing robustness to adversarial attacks and shortcut learning.

## Executive Summary
LSFSL addresses the challenge of few-shot learning by incorporating shape awareness into deep neural networks through a dual network architecture. The method distills shape information from edge-detected images into standard RGB input networks using bidirectional feature and decision alignment objectives. By forcing the model to focus on global shape features rather than local textures or shortcuts, LSFSL demonstrates improved performance and robustness across multiple benchmark datasets including miniImageNet, tieredImageNet, CIFAR-FS, and FC100.

## Method Summary
LSFSL employs a dual network architecture consisting of an RGB Input Network (RIN) and a Shape Input Network (SIN). The RIN receives standard RGB images while the SIN receives Sobel edge-detected images. Both networks are trained simultaneously with cross-entropy losses, plus two alignment objectives: feature alignment (LFA) using MSE between backbone features and decision alignment (LDA) using KL divergence between softmax outputs. During meta-testing, only the RIN features are used with a logistic regression classifier. The approach can be implemented through sequential knowledge distillation or online self-distillation variants.

## Key Results
- LSFSL achieves 1-2% improvement in 5-way classification accuracy across miniImageNet, tieredImageNet, CIFAR-FS, and FC100 benchmarks
- Models trained with LSFSL show enhanced robustness to adversarial attacks and texture transfer
- LSFSL reduces vulnerability to shortcut learning, texture bias, and statistical irregularities

## Why This Works (Mechanism)

### Mechanism 1
Dual network alignment with shape-distilled supervision improves feature robustness. By simultaneously training RIN and SIN networks with bidirectional feature and decision alignment, the RIN network is regularized to focus on global shape semantics rather than local textures or shortcuts. Core assumption: Shape information from Sobel edge detection captures generalizable object features that can be distilled into RGB-based networks.

### Mechanism 2
Incorporating shape priors reduces vulnerability to shortcut learning. The shape-aware training explicitly counters the neural network's tendency to learn spurious correlations, texture bias, and statistical irregularities by forcing attention to global structural features. Core assumption: Shape-based features provide more stable, generalizable representations than local texture features across different viewing conditions.

### Mechanism 3
Shape awareness improves robustness to adversarial attacks. By training on shape-enhanced representations, the network develops features that are less sensitive to small perturbations designed to fool texture-based recognition systems. Core assumption: Adversarial examples often exploit texture-based features, so shape-based features provide more robust representations.

## Architecture Onboarding

- **Component map**: RGB image -> Sobel edge detector -> SIN; RGB image -> RIN; RIN and SIN features aligned via LFA and LDA; Final classifier uses RIN features

- **Critical path**: 1. Preprocess RGB image with Sobel edge detector to create shape-enhanced input; 2. Forward pass through both RIN and SIN networks; 3. Compute cross-entropy losses for both networks; 4. Compute bidirectional feature alignment loss using MSE; 5. Compute bidirectional decision alignment loss using KL divergence; 6. Backpropagate combined loss to update both networks; 7. During meta-testing, use only RIN features with logistic regression classifier

- **Design tradeoffs**: Computational overhead (dual network training vs. single network baseline); Feature richness (balance between shape emphasis and texture preservation); Alignment strength (hyperparameters controlling influence of feature vs. decision alignment); Edge detection quality (Sobel operator effectiveness across different object types)

- **Failure signatures**: Over-regularization (model performance drops significantly if alignment objectives are too strong); Shape inadequacy (poor performance on datasets where shape is not the primary discriminative feature); Computational bottleneck (training time increases significantly due to dual network architecture); Edge detection failure (performance degradation when Sobel operator fails to capture meaningful shape information)

- **First 3 experiments**: 1. Ablation study removing feature alignment (LFA) to measure its contribution to performance; 2. Test on stylized-miniImageNet with varying texture transfer strengths to evaluate texture bias reduction; 3. Evaluate adversarial robustness using Square attack at multiple perturbation strengths to verify robustness claims

## Limitations

- The approach relies heavily on Sobel edge detection quality, which may not capture meaningful shape information for all object categories
- Dual network architecture introduces significant computational overhead without clear justification for why bidirectional distillation is superior to unidirectional approaches
- Claims about robustness to adversarial attacks and shortcut learning are primarily demonstrated on limited attack types and synthetic shortcut scenarios

## Confidence

- **High confidence**: Performance improvements on standard few-shot learning benchmarks (1-2% accuracy gains are measurable and reproducible)
- **Medium confidence**: Robustness claims against adversarial attacks and shortcut learning, as these require extensive validation across diverse attack types and real-world scenarios
- **Medium confidence**: Shape distillation mechanism effectiveness, as the specific contribution of bidirectional alignment versus unidirectional approaches is not fully isolated
