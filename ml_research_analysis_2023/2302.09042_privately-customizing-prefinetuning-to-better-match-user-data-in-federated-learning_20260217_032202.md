# Privately Customizing Prefinetuning to Better Match User Data in Federated Learning

## Quick Facts
- arXiv ID: 2302.09042
- Source URL: https://arxiv.org/abs/2302.09042
- Reference count: 5
- Primary result: FreD accurately identifies best prefinetuning datasets for FL tasks under strong privacy constraints (ε=0.6, δ=2×10⁻⁶)

## Executive Summary
This paper introduces FreD (Federated Private Fréchet Distance), a privacy-preserving method to evaluate and customize prefinetuning datasets for federated learning (FL) tasks. FreD measures the distance between a central prefinetuning dataset and private federated client data using differentially private mean and covariance estimators applied to large language model embeddings. The approach allows selection of the most representative prefinetuning dataset for an FL task, with formal (ε,δ)-differential privacy guarantees. Empirically, FreD accurately identifies the best prefinetuning dataset even under strong privacy constraints and distinguishes datasets differing by as little as 1%.

## Method Summary
FreD computes Fréchet distance between distributions of embeddings from prefinetuning and federated datasets using DP means and covariances. The algorithm applies an embedding model (e.g., ALBERT) to both datasets, calculates mean and covariance statistics with ℓ2 sensitivity clipping, adds calibrated Gaussian noise for DP guarantees, and computes closed-form Fréchet distance between resulting Gaussian distributions. The method is evaluated by training DistilGPT-2 models with various prefinetuning datasets, FL-finetuning on Reddit data, and measuring perplexity on Reddit-test.

## Key Results
- FreD accurately identifies better prefinetuning datasets even under strong privacy constraints (ε=0.6, δ=2×10⁻⁶)
- FreD distinguishes datasets differing by as little as 1% in embedding space
- Smaller FreD values correlate strongly with better downstream FL performance (lower perplexity)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: FreD measures Fréchet distance between embedding distributions from prefinetuning and federated datasets
- Mechanism: Computes DP means and covariances of embeddings, then uses closed-form Fréchet distance between Gaussian distributions
- Core assumption: Embeddings can be modeled as Gaussian distributions whose statistics capture dataset similarity
- Evidence anchors: [abstract] FreD "privately computes and compares a Fréchet distance between embeddings generated by a large language model"; [section] calculation of means m1, m2 and covariances C1, C2 from embeddings
- Break condition: If embeddings are not approximately Gaussian, closed-form distance becomes inaccurate

### Mechanism 2
- Claim: Private computation preserves distance information while protecting individual records
- Mechanism: Uses Gaussian mechanism with ℓ2 sensitivity clipping to add calibrated noise to mean and covariance estimates
- Core assumption: Sensitivity can be bounded through clipping, enabling DP guarantees
- Evidence anchors: [abstract] "distributed, differentially-private mean and covariance estimators"; [section] "Gaussian mechanism with noise on the scale of τ1 maintains (ε,δ)-DP"
- Break condition: If clipping removes too much information, distance measurement loses accuracy

### Mechanism 3
- Claim: Smaller FreD values correlate with better downstream FL performance
- Mechanism: Prefinetuning datasets closer to federated data produce better initialization, reducing perplexity
- Core assumption: Dataset similarity in embedding space translates to model performance similarity
- Evidence anchors: [abstract] "smaller FreD values correlate with better downstream FL performance"; [section] "non-private FreD and private (ε = 0.6,δ = 2×10⁻⁶) FreD corresponds strongly with Y"
- Break condition: If relationship between embedding space distance and model performance breaks, FreD loses predictive value

## Foundational Learning

- Concept: Differential Privacy and Gaussian Mechanism
  - Why needed here: Protects individual records while computing statistics across distributed datasets
  - Quick check question: What is the relationship between ℓ2 sensitivity, noise scale, and privacy parameters (ε,δ) in the Gaussian mechanism?

- Concept: Fréchet Distance and Gaussian Distributions
  - Why needed here: Core metric compares datasets using distance measure between embedding distributions
  - Quick check question: How does the closed-form Fréchet distance formula change when comparing two Gaussian distributions versus arbitrary distributions?

- Concept: Federated Learning and Model Prefinetuning
  - Why needed here: Algorithm selects better prefinetuning datasets for federated learning scenarios
  - Quick check question: Why is prefinetuning commonly used in federated learning, and how does it affect the number of communication rounds needed?

## Architecture Onboarding

- Component map: Central server -> Clients -> DP mechanisms -> Secure aggregation -> Distance computation
- Critical path: 1) Server sends embedder to clients; 2) Clients compute embeddings and apply clipping; 3) Clients add DP noise; 4) Server aggregates via secure aggregation; 5) Server computes final FreD
- Design tradeoffs: Privacy vs accuracy (stronger privacy requires more noise, reducing resolution); embedding quality vs computational cost; clipping threshold selection
- Failure signatures: High FreD values for similar datasets (excessive clipping/noise); no correlation with downstream performance (embedding space issues); privacy budget exhaustion
- First 3 experiments: 1) Compare FreD between identical vs completely different datasets; 2) Measure FreD correlation with perplexity using synthetic datasets; 3) Test privacy guarantees with membership inference attacks

## Limitations
- Core assumption that embeddings follow Gaussian distributions lacks rigorous theoretical justification
- Privacy guarantees depend on ℓ2 sensitivity bounds through clipping, which may remove important information
- Empirical validation limited to single downstream task and embedding model, raising generalizability questions

## Confidence
- High confidence: DP mechanism implementation and privacy guarantee calculations are mathematically sound
- Medium confidence: Gaussian assumption for embeddings is reasonable but lacks theoretical backing
- Low confidence: Generalization across different tasks, embedding models, and dataset characteristics remains unproven

## Next Checks

3. Evaluate FreD's ability to detect similarity in controlled synthetic datasets with known distributional properties to validate Gaussian assumption
