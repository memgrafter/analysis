# Data-Driven Approach for Formality-Sensitive Machine Translation: Language-Specific Handling and Synthetic Data Generation

## Quick Facts
- arXiv ID: 2306.14514
- Source URL: https://arxiv.org/abs/2306.14514
- Reference count: 6
- Key outcome: Data-driven approach achieves high accuracy and near-perfect formality control for EN-KO and EN-VI pairs, but shows gaps in zero-shot settings (EN-PT, EN-RU)

## Executive Summary
This work presents a data-driven approach for Formality-Sensitive Machine Translation (FSMT) across four target languages. The method combines language-specific data handling with synthetic data generation using large-scale language models and empirical prompt engineering. For EN-KO and EN-VI pairs, the approach employs pre-trained models fine-tuned on high-quality, language-specific datasets, including morpheme-aware tokenization for Korean and specialized models for Vietnamese. Synthetic examples are generated using ChatGPT with GPT-4, guided by prompt-based methods and filtered via a formality classifier. The method achieves high translation accuracy and near-perfect formality control in supervised settings (EN-KO, EN-VI), though data augmentation sometimes underperforms. In zero-shot settings (EN-PT, EN-RU), synthetic data helps fine-tune pre-trained models, though EN-PT informal translation shows lower performance, indicating room for improvement in language-specific techniques and data bias handling.

## Method Summary
The approach combines language-specific data handling with synthetic data generation for FSMT. For EN-KO and EN-VI pairs, pre-trained models are fine-tuned on high-quality, language-specific datasets. Korean benefits from morpheme-aware tokenization, while Vietnamese uses specialized models. Synthetic data is generated using ChatGPT with GPT-4, guided by prompt-based methods and filtered via a formality classifier. The method operates in both supervised (EN-KO, EN-VI) and zero-shot (EN-PT, EN-RU) settings. Data augmentation is applied selectively, as it sometimes underperforms. The approach achieves near-perfect formality control in supervised settings but shows performance gaps in zero-shot scenarios, particularly for EN-PT informal translation.

## Key Results
- Achieves high translation accuracy and near-perfect formality control in supervised settings (EN-KO, EN-VI)
- Data augmentation sometimes underperforms, requiring selective application
- Zero-shot performance for EN-PT informal translation is notably lower than formal translations
- Synthetic data generation using ChatGPT with GPT-4 shows promise but lacks comprehensive evaluation

## Why This Works (Mechanism)
The method leverages language-specific handling to address unique linguistic features of target languages (morpheme-aware tokenization for Korean, specialized models for Vietnamese) while synthetic data generation provides additional training examples for formality control. The combination of fine-tuning pre-trained models with high-quality datasets and augmenting with carefully filtered synthetic examples enables both accuracy and formality preservation. The formality classifier serves as quality control for synthetic examples, ensuring the generated data maintains appropriate formality levels.

## Limitations
- EN-PT informal translation shows significant underperformance compared to formal translation
- Synthetic data generation relies heavily on ChatGPT with GPT-4 without comprehensive quality characterization
- Language-specific techniques (Korean tokenization, Vietnamese models) require further validation across diverse text domains
