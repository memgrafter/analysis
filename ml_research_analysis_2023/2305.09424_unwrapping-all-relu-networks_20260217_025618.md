# Unwrapping All ReLU Networks

## Quick Facts
- arXiv ID: 2305.09424
- Source URL: https://arxiv.org/abs/2305.09424
- Reference count: 7
- This paper extends piecewise-linear decomposition to GCNs, tensor networks, and multiplicative interactions, enabling exact SHAP computation.

## Executive Summary
This paper presents a comprehensive framework for decomposing ReLU-based neural networks into interpretable models. The authors prove that any ReLU network can be exactly represented as a collection of linear models, each defined within convex activation regions. They extend this decomposition to Graph Convolutional Networks and tensor convolutional networks, showing how these architectures can be unwrapped into Multivariate Decision Trees and first-order logical theories. The framework enables exact and efficient computation of SHAP values without the need for local surrogate models, providing both interpretability and fast explainability.

## Method Summary
The method centers on decomposing ReLU networks into local linear models within activation regions. For each region, the authors derive explicit weight matrices and bias vectors that capture the network's behavior. They extend this to GCNs using Kronecker products to incorporate graph structure, and to tensor networks through vectorized operations. The decomposition enables construction of multivariate regression trees and exact SHAP value computation by leveraging the linear structure within each region.

## Key Results
- ReLU networks can be exactly represented as Multivariate Decision Trees and first-order logical theories
- GCNs and tensor networks can be decomposed using the same piecewise-linear framework
- Exact SHAP values can be computed efficiently using the local linear models
- The decomposition provides symbolic interpretation of network decision-making

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ReLU networks can be decomposed into a collection of linear models, each defined in a convex region of the input space.
- Mechanism: The decomposition relies on the fact that ReLU activations partition the input space into convex regions (activation regions), and within each region, the network behaves as a linear function. The local linear model for each region is computed by tracking the activation pattern through the network layers, using diagonal matrices to encode the ReLU state and matrix multiplications to propagate the weights.
- Core assumption: ReLU activations create a piecewise-linear structure with convex activation regions that can be exactly characterized by half-space conditions.
- Evidence anchors:
  - [abstract] The paper provides proofs that neural networks can be understood as interpretable models such as Multivariate Decision trees and logical theories.
  - [section] Theorem 1 states that for a given feedforward neural network N, the local linear model ηP(x) for the activation region RP(z) is given by wP(z)^T x + bP(z), where the weight and bias parameters are derived from the activation pattern.
  - [corpus] Weak evidence - only 5 related papers, no citations.

### Mechanism 2
- Claim: Graph Convolutional Networks (GCNs) and tensor convolutional networks can be decomposed using the same piecewise-linear framework as standard ReLU networks.
- Mechanism: The decomposition extends to GCNs by treating the graph convolution as a linear operation on the vectorized input, using the vec trick to handle the matrix multiplications. The local linear model incorporates the graph structure through Kronecker products with the adjacency matrix.
- Core assumption: The graph convolution can be represented as a linear transformation that preserves the piecewise-linear structure of the network.
- Evidence anchors:
  - [section] Theorem 2 provides the local linear model for a GCN, showing how the weight parameters incorporate the graph convolution operator A through Kronecker products.
  - [section] Theorem 3 extends the decomposition to tensor neural networks, using tensor contractions and the vec trick.
  - [corpus] Weak evidence - no direct evidence in corpus, but the extension is mathematically consistent with the base theory.

### Mechanism 3
- Claim: The decomposition enables exact and efficient computation of SHAP values for ReLU networks.
- Mechanism: Since each activation region has an explicit linear model, the SHAP values can be computed by summing the contributions of each feature according to the linear coefficients, without needing to fit local surrogates as in KernelSHAP.
- Core assumption: The linear model within each activation region accurately represents the network's behavior, and the SHAP value computation for linear models is well-defined.
- Evidence anchors:
  - [abstract] The paper shows how this model leads to computing cheap and exact SHAP values.
  - [section] Lemma 2 states that the Shapley value for feature i is given by φf(i)j = w̃P(z)i,j (xi - x̄i), where w̃P(z) are the coefficients of the local linear model.
  - [corpus] Weak evidence - no direct evidence in corpus, but the connection between linear models and SHAP values is standard.

## Architecture Onboarding

- Component map:
  Input -> Linear transformations + ReLU activations -> Track activation pattern -> Compute local linear model -> Produce output/SHAP values

- Critical path:
  1. Define the input space and initial conditions
  2. Apply linear transformations and ReLU activations through the hidden layers
  3. Track the activation pattern to determine the current activation region
  4. Compute the local linear model for the current activation region
  5. Use the local linear model to make predictions or compute SHAP values

- Design tradeoffs:
  - Depth vs. width: Deeper networks may have more complex activation regions but also more computational overhead
  - Graph structure: The choice of graph convolution operator affects the decomposition and interpretability
  - Tensor order: Higher-order tensor contractions increase expressiveness but also complexity

- Failure signatures:
  - Non-convex activation regions: Indicates a problem with the network architecture or the decomposition
  - Inaccurate SHAP values: Suggests that the local linear model does not accurately capture the network's behavior within the region
  - Computational inefficiency: May indicate that the decomposition is not being used effectively

- First 3 experiments:
  1. Verify the decomposition on a simple ReLU network with known activation regions
  2. Test the extension to GCNs on a small graph with a known structure
  3. Compute SHAP values for a ReLU network and compare with KernelSHAP to validate the efficiency claim
