# Doubly Robust Instance-Reweighted Adversarial Training

## Quick Facts
- arXiv ID: 2308.00311
- Source URL: https://arxiv.org/abs/2308.00311
- Reference count: 40
- Key outcome: Improves both average and worst-case adversarial robustness by 3.5% on CIFAR10 through principled instance reweighting via DRO formulation

## Executive Summary
This paper introduces a doubly robust instance reweighted adversarial training framework that leverages distributionally robust optimization (DRO) to obtain instance weights in a principled way, rather than using heuristics. The method addresses the non-uniform robustness issue in adversarial training by boosting performance on the most vulnerable examples while maintaining average robust performance. The framework is reformulated as a compositional bilevel optimization problem and solved using a novel algorithm with theoretical convergence guarantees.

## Method Summary
The proposed framework combines DRO with bilevel optimization to jointly optimize model parameters and instance weights. The inner loop uses projected gradient descent to find worst-case adversarial noise for each data point, while the outer loop optimizes both model parameters and instance weights using a KL-divergence regularized DRO formulation. The problem is reformulated as a compositional bilevel optimization problem, solved via the CID algorithm with implicit differentiation. The method uses a cyclic learning rate schedule and decays the KL-regularization parameter over training epochs.

## Key Results
- Achieves +3.5% improvement in overall robust accuracy against PGD attacks on CIFAR10
- Most gains come from improving robustness on vulnerable data points (RA-Tail-30 metric)
- Outperforms state-of-the-art baselines in both average robust performance and worst-case robustness
- Demonstrates consistent improvements across CIFAR10, SVHN, STL10, and GTSRB datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Doubly robust formulation addresses non-uniform robustness by weighting vulnerable examples higher.
- Mechanism: KL-divergence regularized outer objective allows instance weights to be optimized via distributionally robust optimization (DRO) instead of heuristics, leading to focus on worst-case performance.
- Core assumption: Instance weights computed via KL-divergence regularization yield unique solution and improve robustness on vulnerable classes.
- Evidence anchors: [abstract] "boosts the robustness on the most vulnerable examples"; [section 3.1] addresses non-uniform issues by carefully optimizing instance weights.

### Mechanism 2
- Claim: Reformulation into compositional bilevel optimization allows principled optimization with theoretical convergence guarantee.
- Mechanism: Inner loop finds worst-case adversarial noise; outer loop optimizes model parameters and instance weights jointly, reformulated as compositional bilevel problem with log-barrier penalty for differentiability.
- Core assumption: Implicit function theorem applies, making minimizer of inner problem differentiable w.r.t. model parameters.
- Evidence anchors: [section 3.2] max problem admits unique solution; [section 3.3] considers compositional bilevel optimization problem.

### Mechanism 3
- Claim: Instance reweighting via principled DRO approach outperforms heuristic-based methods in both average and worst-case robustness.
- Mechanism: Weights determined by optimizing KL-divergence regularized loss function, which balances uniform and worst-case distributions, improving robustness on vulnerable data points.
- Core assumption: Heuristic-based instance reweighting methods are suboptimal compared to principled DRO approach.
- Evidence anchors: [abstract] outperforms related state-of-the-art baseline methods; [section 1.1] existing methods mostly adopt heuristic techniques.

## Architecture Onboarding

- Component map: Data points -> Projected gradient descent (inner loop) -> Instance weights (DRO formulation) -> Model parameters and weights update (compositional bilevel optimization)

- Critical path:
  1. Sample batch of data points
  2. For each data point, perform K steps of projected gradient descent to estimate worst-case adversarial noise
  3. Compute instance weights using KL-divergence regularized loss function
  4. Update model parameters using compositional implicit differentiation
  5. Track running average of composed function values for convergence

- Design tradeoffs:
  - Batch size vs. computational efficiency
  - Number of inner loop steps K vs. approximation accuracy
  - KL-divergence regularization parameter r vs. balance between uniform and worst-case weights
  - Stepsize choices for θ and u updates vs. convergence stability

- Failure signatures:
  - Weights collapsing toward uniform (r too large)
  - Instability in optimization (stepsizes too large or inner loop approximation poor)
  - Degradation in robustness on easy examples (over-emphasis on vulnerable points)
  - Failure to improve tail robustness (DRO formulation not effective)

- First 3 experiments:
  1. Run DONE-GD on CIFAR10 with standard hyperparameters to verify improvement over AT baseline
  2. Compare weight distributions across classes to confirm focus on vulnerable examples
  3. Test sensitivity to KL-divergence regularization parameter r by varying its value and measuring impact on robustness metrics

## Open Questions the Paper Calls Out

The paper does not explicitly call out open questions, but raises several important considerations:
1. Potential application to other domains like domain adaptation, data augmentation, and imbalanced classification
2. Need for better understanding of hyperparameter sensitivity, particularly the KL-divergence regularization parameter
3. Questions about robustness to label noise and out-of-distribution data in real-world scenarios

## Limitations

- Theoretical convergence guarantees depend on assumptions about unique inner loop solutions and twice-differentiable loss functions
- Empirical validation limited to four standard vision datasets without extensive ablation studies
- Performance sensitivity to hyperparameter choices (particularly KL-regularization schedule) not fully explored
- Limited comparison against multiple heuristic-based baselines to validate principled superiority claims

## Confidence

- **Medium** for claims about improved average robustness - supported by CIFAR10 results but limited to one main dataset
- **Medium** for worst-case robustness improvements - RA-Tail-30 gains are demonstrated but the 30% threshold is arbitrary
- **Low** for claims about principled superiority over heuristics - no direct comparison to multiple heuristic baselines is shown

## Next Checks

1. Perform ablation studies on KL-divergence regularization parameter r to verify that DRO formulation is indeed responsible for improvements rather than hyperparameter tuning
2. Test robustness on a broader range of datasets including ImageNet to assess generalizability beyond small-scale vision tasks
3. Compare against multiple heuristic-based instance reweighting baselines (not just standard AT) to validate claims of principled superiority
