# Shapley Chains: Extending Shapley Values to Classifier Chains

## Quick Facts
- arXiv ID: 2303.17243
- Source URL: https://arxiv.org/abs/2303.17243
- Reference count: 13
- Key outcome: Novel post-hoc model-agnostic explainability method for multi-output classification using classifier chains that provides more complete feature attribution than independent classifiers

## Executive Summary
Shapley Chains addresses the limitation of incomplete feature attribution in multi-output classification tasks by taking into account label interdependencies and distributing their importance among features with respect to a given chaining order. The method extends Shapley values to classifier chains by separating direct and indirect feature influences, providing a more complete distribution of feature importance scores. Evaluated on both synthetic and real-world datasets, Shapley Chains reveals indirect feature contributions missed by existing approaches and emphasizes the real learning factors in multi-output applications.

## Method Summary
Shapley Chains computes feature importance scores for multi-output classification tasks using classifier chains by separating direct and indirect contributions. For each output, it calculates direct Shapley values using the SHAP framework, then recursively computes indirect contributions by weighting the direct contributions of preceding outputs. The method aggregates these scores to provide complete feature attribution, taking into account the dependencies between outputs. The approach is model-agnostic and works with any base classifier, though logistic regression is used in the experiments.

## Key Results
- Shapley Chains provides more complete feature attribution than SHAP applied to independent classifiers
- The method successfully reveals indirect feature contributions that existing approaches miss
- Different chaining orders affect attribution magnitudes but preserve relative feature rankings

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Shapley Chains correctly attributes indirect feature contributions by propagating feature Shapley values through the classifier chain
- Mechanism: For each output beyond the first, Shapley Chains computes indirect contributions by weighting the direct contributions of preceding outputs and combining them with direct feature contributions
- Core assumption: The classifier chain structure preserves meaningful feature-output dependencies
- Evidence anchors: Abstract and section descriptions of indirect contribution computation
- Break condition: If the classifier chain does not capture true dependencies, indirect contributions become misleading

### Mechanism 2
- Claim: The chaining order affects the magnitude of feature importance scores but preserves their relative ranking
- Mechanism: Different chaining orders change which outputs are available as features for subsequent predictions, altering the feature attribution path
- Core assumption: The underlying feature-output relationships remain stable across different chain orders
- Evidence anchors: Section showing chain order effects on synthetic dataset
- Break condition: If certain features are only relevant when specific outputs are predicted first, relative rankings could change

### Mechanism 3
- Claim: Shapley Chains reveals hidden feature contributions that SHAP on independent classifiers misses
- Mechanism: By including output features in the feature set for subsequent predictions, Shapley Chains captures the indirect paths through which features influence later outputs
- Core assumption: Outputs provide meaningful feature information that affects subsequent predictions
- Evidence anchors: Abstract and section describing limitations of independent classifiers
- Break condition: If outputs do not contain meaningful information for subsequent predictions, indirect contributions become noise

## Architecture Onboarding

- Component map:
  - Base classifier chain model (any model type) -> Direct contribution calculator (uses SHAP framework) -> Indirect contribution calculator (recursive weighting function) -> Contribution aggregator (combines direct and indirect scores) -> Visualization module (stacked feature contribution plots)

- Critical path:
  1. Train classifier chain on multi-output data
  2. Compute direct Shapley values for each output
  3. Recursively compute indirect contributions using the weighting function
  4. Aggregate and normalize contributions
  5. Generate visualizations for interpretation

- Design tradeoffs:
  - Chain order sensitivity vs. interpretability: Different orders yield different attribution magnitudes
  - Computational cost vs. completeness: Computing all indirect paths increases complexity
  - Model-agnostic flexibility vs. integration depth: Works with any base classifier but may miss model-specific optimizations

- Failure signatures:
  - Zero or near-zero indirect contributions across all features (chain may not capture dependencies)
  - Extremely uneven contribution distributions (potential overfitting or chain order issues)
  - Contradictory rankings between different chain orders (feature-output relationships may be unstable)

- First 3 experiments:
  1. Compare Shapley Chains vs. SHAP on independent classifiers using a simple synthetic dataset with known dependencies
  2. Test sensitivity to chain order by running multiple orders on the same dataset and comparing attribution patterns
  3. Validate on a real-world multi-output dataset by checking if indirect contributions align with domain knowledge about feature relationships

## Open Questions the Paper Calls Out

- Extending the method to multi-output regression tasks
- Handling multi-output tasks with mixed output types (classification and regression)
- Improving computational efficiency for large-scale applications

## Limitations

- The method's effectiveness depends on the quality of the classifier chain structure and whether it captures true feature-output dependencies
- Computational complexity increases significantly with chain length due to recursive indirect contribution calculations
- The decomposition into direct and indirect contributions may not always reflect meaningful feature effects in real-world applications

## Confidence

- High Confidence: The mathematical framework for computing direct and indirect Shapley contributions is well-defined and internally consistent
- Medium Confidence: The claim that Shapley Chains provides more complete attribution than independent classifiers is supported by synthetic experiments but needs broader validation
- Low Confidence: The assertion that indirect contributions represent meaningful feature effects in real-world applications lacks sufficient empirical support
