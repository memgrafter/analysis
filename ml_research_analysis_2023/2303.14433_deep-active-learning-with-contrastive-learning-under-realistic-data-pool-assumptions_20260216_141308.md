# Deep Active Learning with Contrastive Learning Under Realistic Data Pool Assumptions

## Quick Facts
- arXiv ID: 2303.14433
- Source URL: https://arxiv.org/abs/2303.14433
- Reference count: 2
- Key outcome: Achieves comparable accuracy to existing methods while requiring significantly lower annotation costs, especially in early stages

## Executive Summary
This paper addresses a critical gap in active learning by proposing benchmarks and methods that reflect realistic data pool conditions. Traditional active learning assumes data pools contain only in-distribution samples, but real-world scenarios often include out-of-distribution and ambiguous samples that waste annotation efforts. The authors introduce MixMNIST and MixCIFAR60 benchmarks that incorporate these realistic conditions, and propose a contrastive learning-based active learning method that leverages both labeled and unlabeled data to select informative samples while avoiding annotation waste.

## Method Summary
The method trains a representation model using contrastive learning on both labeled and unlabeled data pools simultaneously. Self-supervised contrastive learning is applied to unlabeled samples, while supervised contrastive learning is used for labeled samples. The method then clusters features in the learned space using k-means and selects samples based on their distance from cluster centroids, prioritizing samples closer to the centroid than any labeled non-iD samples. This approach aims to select informative in-distribution samples while avoiding annotation of out-of-distribution and ambiguous samples.

## Key Results
- The proposed method consumes only 406 samples to improve MixMNIST accuracy by 1%, compared to 68-348 samples for other methods
- Achieves comparable accuracy to existing methods with significantly lower annotation costs
- Particularly effective in early stages of active learning where annotation budgets are limited

## Why This Works (Mechanism)

### Mechanism 1
Contrastive learning clusters informative iD samples closer to the cluster centroid than non-iD samples. Self-supervised contrastive loss pulls together feature representations of unlabeled samples with similar semantics, while supervised contrastive loss pushes apart samples with different labels, creating feature space clusters where iD samples cluster tightly and non-iD samples are repelled.

### Mechanism 2
Selecting samples near but inside the circle defined by the centroid-closest non-iD sample prioritizes informative iD samples. The acquisition strategy uses distance from the cluster centroid to identify samples, selecting those closer to the centroid than any labeled non-iD sample as likely informative iD samples.

### Mechanism 3
Training the representation model with both labeled and unlabeled data pools via contrastive learning improves early-stage active learning performance. Self-supervised contrastive learning on unlabeled data helps the model learn semantic relationships before receiving many labeled samples, while supervised contrastive learning on labeled data refines these representations.

## Foundational Learning

- Concept: Contrastive learning and its loss functions
  - Why needed here: The method relies on contrastive learning to create feature space clusters that separate iD from non-iD samples
  - Quick check question: What is the difference between self-supervised and supervised contrastive learning?

- Concept: Active learning acquisition strategies
  - Why needed here: The method uses a novel acquisition strategy based on cluster distances rather than uncertainty or entropy
  - Quick check question: How does the proposed distance-based acquisition strategy differ from traditional uncertainty sampling?

- Concept: Out-of-distribution (OoD) detection
  - Why needed here: The method must distinguish between iD and OoD samples in the unlabeled data pool
  - Quick check question: What characteristics of OoD samples make them challenging for traditional active learning methods?

## Architecture Onboarding

- Component map: Representation model -> Feature extractor -> Clustering module -> Acquisition function -> Classification model
- Critical path: 1) Train representation model via contrastive learning, 2) Extract features and create clusters, 3) Apply acquisition function to select samples, 4) Annotate selected samples, 5) Update labeled data pool and repeat
- Design tradeoffs: Using contrastive learning vs. supervised learning only, distance-based acquisition vs. uncertainty-based, single auxiliary class for non-iD vs. separate classes
- Failure signatures: Poor separation between iD and non-iD samples in feature space, acquisition function selecting mostly non-iD samples, degraded classification performance despite lower annotation costs
- First 3 experiments: 1) Train representation model on MixMNIST with contrastive learning and visualize feature space clusters, 2) Implement and test distance-based acquisition strategy on MixMNIST, 3) Compare annotation costs and accuracy with random and uncertainty-based acquisition strategies on MixMNIST

## Open Questions the Paper Calls Out

### Open Question 1
How can the acquisition strategy be made more robust to variations in the quality of the learned feature representations? The authors mention that the distance threshold assumption for acquisition may not hold in more challenging benchmarks like MixCIFAR60, leading to acquisition of uninformative samples.

### Open Question 2
What are the optimal hyperparameters for contrastive learning in the proposed active learning framework? The authors mention that they did not search for optimal hyperparameters for contrastive learning, despite its sensitivity to these parameters.

### Open Question 3
How does the proposed method perform on real-world data with more diverse distributions than the proposed benchmarks? The authors propose new benchmarks that include samples from three categories, but real-world data may have more complex distributions.

## Limitations
- The specific construction methods for ambiguous samples may not fully capture real-world data pool distributions
- Effectiveness critically depends on the quality of feature representations learned through contrastive learning
- Method shows promising results on proposed benchmarks but confidence is Medium in its generalization to more complex, real-world datasets

## Confidence
- High Confidence: The paper's core premise that realistic active learning should account for non-iD samples in unlabeled pools
- Medium Confidence: The effectiveness of the distance-based acquisition strategy in practice
- Low Confidence: The specific implementation details of NV AE for generating ambiguous samples and the exact threshold calculations for the acquisition function
