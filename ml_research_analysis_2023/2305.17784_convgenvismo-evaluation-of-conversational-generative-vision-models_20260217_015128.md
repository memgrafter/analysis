# ConvGenVisMo: Evaluation of Conversational Generative Vision Models

## Quick Facts
- arXiv ID: 2305.17784
- Source URL: https://arxiv.org/abs/2305.17784
- Reference count: 7
- Introduces the first benchmark for evaluating conversational generative vision models

## Executive Summary
ConvGenVisMo introduces a framework for evaluating conversational generative vision models (CGVMs) that generate images through dialogue. The framework provides a benchmark dataset of 180 image-conversation pairs across 6 categories, where one user describes an image to another through multi-turn conversations. The evaluation approach combines traditional image quality metrics with novel element presence scores to assess how well CGVMs incorporate discussed elements into generated images. Results demonstrate that CLIP scores and element presence metrics are most informative for evaluating CGVM outputs, revealing both strengths and limitations in current approaches.

## Method Summary
The framework uses ChatGPT to summarize multi-turn conversations into generation prompts, then employs DreamStudio to generate images from these summaries. Generated images are evaluated against ground truth using automated metrics including BRISQUE, PSNR, SSIM, UQI for image quality, plus CLIP scores for semantic similarity and element presence scores (EPRe, EPPr, EPF1) for object inclusion. Object detection preprocessing using DETR-100 identifies elements for element presence calculations. The evaluation tracks performance across conversation hops to assess progressive image refinement.

## Key Results
- CLIP scores and element presence metrics are most informative for assessing CGVM outputs
- CLIP scores increase across conversation hops, indicating improved semantic alignment
- Element presence scores reveal trade-offs between recall and precision in object inclusion
- EPRe scores improve with more conversation hops while EPPr scores decrease

## Why This Works (Mechanism)

### Mechanism 1
- Element presence scores (EPPr, EPRe, EPF1) provide granular evaluation of object generation
- These scores measure presence, precision, and recall of specific objects mentioned in conversation
- Assumes objects discussed are primary evaluation targets for CGVM performance
- Evidence: Element presence metrics explicitly measure overlapping elements between generated and ground-truth images

### Mechanism 2
- CLIP scores capture semantic alignment between generated and ground truth images
- CLIP score measures cosine similarity between image embeddings for semantic meaning
- Assumes semantic similarity better indicates CGVM performance than pixel-level similarity
- Evidence: CLIP score formula uses cos(CLIP(Y), CLIP(Ŷ)) for image comparison

### Mechanism 3
- Multi-hop evaluation reveals progressive improvement in image generation quality
- Evaluates images at each conversation hop to track incorporation of new information
- Assumes CGVM performance should improve monotonically with each conversation hop
- Evidence: EPRe scores improve as number of hops increases in CGVM

## Architecture Onboarding

- **Component map**: Data collection → Conversation summarization → Image generation → Evaluation → Analysis
- **Critical path**: Conversation → Summarization → Image Generation → Evaluation → Analysis
- **Design tradeoffs**: Automated vs. human evaluation (speed vs. nuance), object detection vs. manual annotation (scalability vs. accuracy), single vs. multi-hop evaluation (detail vs. cost)
- **Failure signatures**: Low CLIP scores despite high element presence scores (semantic misalignment), decreasing EPPr with increasing EPRe (adding irrelevant objects), inconsistent performance across categories (category-specific weaknesses)
- **First 3 experiments**: 1) Evaluate simple CGVM on benchmark dataset using all metrics, 2) Compare automated metrics against human evaluations for subset, 3) Test impact of different summarization strategies on image quality

## Open Questions the Paper Calls Out

### Open Question 1
- How do different conversation summarization strategies affect CGVM performance?
- Basis: ChatGPT tends to add hallucinated details not present in original conversation
- Unresolved: Alternative summarization approaches and their impact on final image generation quality
- Resolution: Comparative evaluation of CGVM performance using different summarization methods

### Open Question 2
- What is the optimal balance between conversation length and image quality in CGVM systems?
- Basis: EPRe improves with more hops while EPPr decreases; CLIP scores increase with conversation length
- Unresolved: Optimal stopping point where additional conversation turns stop providing meaningful improvements
- Resolution: Systematic analysis of performance metrics across varying conversation lengths

### Open Question 3
- How can CGVMs be designed to better retain context from earlier conversation turns?
- Basis: CGVMs often "forget" important details from previous conversation turns
- Unresolved: Architectural solutions to improve context retention
- Resolution: Comparative evaluation of CGVM variants with different memory mechanisms

## Limitations
- Small dataset (180 pairs across 6 categories) may limit generalizability to diverse real-world scenarios
- Automated metrics correlation with human perceptual quality requires further validation
- Framework depends on specific model choices (ChatGPT, DreamStudio) and may not generalize across models

## Confidence
- High: Framework's overall architecture and multi-hop evaluation methodology
- Medium: CLIP scores as semantic alignment metrics and element presence metric effectiveness
- Low: Framework's ability to generalize to complex conversational scenarios and fully capture human perception
