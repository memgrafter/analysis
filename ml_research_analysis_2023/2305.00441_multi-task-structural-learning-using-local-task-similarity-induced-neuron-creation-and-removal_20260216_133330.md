# Multi-Task Structural Learning using Local Task Similarity induced Neuron Creation and Removal

## Quick Facts
- arXiv ID: 2305.00441
- Source URL: https://arxiv.org/abs/2305.00441
- Reference count: 26
- Multi-Task Structural Learning (MTSL) achieves competitive generalization on Cityscapes and NYUv2 datasets while maintaining inference efficiency close to one-network architectures

## Executive Summary
Multi-Task Structural Learning (MTSL) introduces a novel approach to multi-task learning by simultaneously optimizing network architecture and parameters through alternating task-learning and structural-learning phases. The method begins with individual task networks and progressively fuses locally similar task layers into group layers, transferring knowledge before removal. This brain-inspired approach achieves competitive generalization performance while maintaining inference efficiency close to single-task architectures. MTSL demonstrates improvements in multi-task performance metrics (∆SDMTL and ∆MTL) on both Cityscapes and NYUv2 datasets, outperforming state-of-the-art methods.

## Method Summary
MTSL operates through an alternating optimization framework that begins with separate single-task networks and progressively fuses them based on local task similarity. The method uses Centered Kernel Alignment (CKA) to measure representational similarity between task nodes, creating group nodes when similarity exceeds a threshold and transferring knowledge via attention-based amalgamation before removing redundant task nodes. The training process alternates between task-learning phases (where individual tasks are optimized with CKA regularization) and structural-learning phases (where architecture is simplified through neuron creation and removal). This process continues until convergence, followed by a fine-tuning phase.

## Key Results
- Achieves 2.72% and 4.72% gains in ∆SDMTL on Cityscapes and NYUv2 datasets respectively
- Maintains inference efficiency close to one-network architectures while improving multi-task performance
- Demonstrates improved robustness to natural corruptions and adversarial attacks compared to baseline methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Local task similarity drives effective neuron creation and removal by identifying redundant task-specific layers
- Mechanism: CKA similarity measures local task representation alignment, triggering neuron creation of group nodes and subsequent removal of task nodes
- Core assumption: High CKA similarity implies task nodes learn similar representations and can be fused without loss of task-specific information
- Evidence anchors: [abstract] "Local task similarity is used to guide task learning through the alignment of task representations, and also to make decisions on grouping tasks." [section] "We use CKA to gauge the similarity between task node features that represent the local activity of task neurons."

### Mechanism 2
- Claim: Progressive structural learning alternates between task specialization and network simplification to improve generalization
- Mechanism: Algorithm alternates between task-learning phase (training individual task networks) and structural-learning phase (grouping similar task nodes and removing redundancies)
- Core assumption: Task specialization followed by similarity-based grouping allows network to learn both task-specific and shared representations
- Evidence anchors: [abstract] "MTSL begins with an identical single-task network for each task and alternates between a task-learning phase and a structural-learning phase." [section] "MTSL considers entire layers as computation units and performs neuron creation and neuron removal on them."

### Mechanism 3
- Claim: Knowledge transfer via attention-based amalgamation preserves task-specific information during neuron removal
- Mechanism: When task nodes are grouped, attention networks selectively distill learned features into new group nodes before removal
- Core assumption: Attention mechanisms can effectively combine multiple task representations into single group node without significant information loss
- Evidence anchors: [abstract] "Locally similar task layers first transfer their knowledge to a newly created group layer before being removed." [section] "MTSL distills the information learned by multiple task nodes into the group node using an attention-based feature amalgamation method."

  - Why needed here: Alternating task learning and structural learning allows networks to specialize before simplifying

## Architecture Onboarding

- Component map: Input layer → Task nodes (one per task) → Group nodes (formed via CKA similarity) → Task branches → Task heads → Attention networks for knowledge amalgamation between task and group nodes → CKA-based regularization during task learning phase

- Critical path:
  1. Initialize separate task networks
  2. Task learning phase with CKA regularization
  3. Structural learning phase: measure similarity, create group nodes, transfer knowledge via attention, remove task nodes
  4. Repeat steps 2-3 until convergence
  5. Fine-tuning phase

- Design tradeoffs:
  - Dense initial architecture provides rich information flow but increases computational cost
  - Progressive removal reduces parameters but requires careful similarity measurement
  - CKA regularization improves grouping quality but adds computational overhead

- Failure signatures:
  - Poor generalization despite architecture simplification (likely due to aggressive neuron removal)
  - Task performance degradation after grouping (likely due to insufficient knowledge transfer)
  - Slow convergence or instability (likely due to improper phase scheduling)

- First 3 experiments:
  1. Train MTSL on a simple multi-task dataset (e.g., multi-digit classification) to verify basic architecture creation/removal works
  2. Vary CKA similarity threshold to observe impact on architecture complexity and task performance
  3. Compare MTSL performance with and without attention-based knowledge transfer to validate its importance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can MTSL's transition between learning phases be automated rather than using fixed epoch schedules?
- Basis in paper: [explicit] "A fixed epoch schedule is used to transition between different learning phases of MTSL. Instead, it can be explored to automatically determine the periods in training in which structural learning is required."
- Why unresolved: The paper acknowledges this limitation but does not provide a solution for automatically determining when to switch between task learning, structural learning, and fine-tuning phases.
- What evidence would resolve it: Experimental results showing MTSL with adaptive phase transitions that outperform the fixed-schedule version, along with a clear mechanism for determining when to switch phases based on learning dynamics.

### Open Question 2
- Question: Should local similarity in MTSL emerge from inter-neuron activity rather than being explicitly enforced?
- Basis in paper: [explicit] "Further, local similarity should likely be an emergent result of inter-neuron activity contrary to being explicitly enforced as in MTSL."
- Why unresolved: The paper uses CKA regularization to explicitly enforce similarity between task representations, but questions whether this is biologically plausible or optimal.
- What evidence would resolve it: Results comparing MTSL with emergent similarity (perhaps through attention mechanisms or unsupervised representation learning) against the current explicit enforcement approach.

### Open Question 3
- Question: Why does MTSL show reduced robustness to noise corruption compared to One-Net?
- Basis in paper: [explicit] "However, in noise corruption, MTSL shows reduced robustness, and the cause for this behavior is currently unclear. Task interference could likely play a role, but further investigation can be done in future work."
- Why unresolved: The paper observes this phenomenon but does not provide an explanation for why noise corruption specifically causes MTSL to underperform.
- What evidence would resolve it: Detailed analysis of how noise affects the shared representations in MTSL versus One-Net, potentially revealing whether task interference or other architectural factors are responsible.

## Limitations
- CKA similarity threshold of 0.8 for neuron grouping is determined empirically but lacks systematic sensitivity analysis
- Attention-based knowledge amalgamation mechanism may not preserve all task-specific information during feature fusion
- Alternating optimization schedule assumes task specialization occurs within fixed epoch budgets, but optimal timing may vary by task complexity

## Confidence

**High confidence**: The core mechanism of alternating task learning and structural learning phases is well-supported by experimental results showing consistent improvements across both Cityscapes and NYUv2 datasets.

**Medium confidence**: The CKA-based similarity measurement effectively identifies redundant task nodes, though the specific threshold value and its sensitivity require further validation.

**Low confidence**: The attention-based knowledge transfer mechanism's ability to preserve task-specific information during neuron removal lacks detailed ablation studies to quantify information loss.

## Next Checks

1. **Threshold Sensitivity Analysis**: Systematically vary the CKA similarity threshold (0.7, 0.75, 0.8, 0.85, 0.9) to quantify its impact on architecture complexity, task performance, and computational efficiency.

2. **Attention Mechanism Ablation**: Compare MTSL with and without attention-based knowledge transfer during neuron removal to measure the exact contribution of this component to overall performance.

3. **Phase Duration Optimization**: Experiment with different task-learning phase durations (10, 20, 30, 40 epochs) to determine optimal scheduling for various task combinations and dataset sizes.
