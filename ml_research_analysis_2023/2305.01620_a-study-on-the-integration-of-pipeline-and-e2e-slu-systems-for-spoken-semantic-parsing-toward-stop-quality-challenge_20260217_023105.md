# A Study on the Integration of Pipeline and E2E SLU systems for Spoken Semantic Parsing toward STOP Quality Challenge

## Quick Facts
- arXiv ID: 2305.01620
- Source URL: https://arxiv.org/abs/2305.01620
- Reference count: 0
- Achieved 1st place in STOP Challenge with 80.8% exact match accuracy

## Executive Summary
This paper presents a spoken semantic parsing system developed for the STOP (Spoken Language Understanding Grand Challenge) Challenge, which aims to convert spoken utterances into semantic parse sequences for task execution by voice assistants. The approach combines both end-to-end (E2E) and pipeline systems, leveraging strong automatic speech recognition (ASR) models like Whisper and pretrained language models like BART to boost performance. The team experimented with various architectures including 2-pass SLU and compositional E2E models, as well as pipeline approaches integrating ASR with NLU. System combination techniques such as ROVER were applied to combine hypotheses from multiple models.

## Method Summary
The proposed system integrates end-to-end and pipeline approaches for spoken semantic parsing. It uses Whisper as the primary ASR model, combined with WavLM or Hubert self-supervised learning representations as frontend. For semantic parsing, BART large and T5 large pretrained language models are fine-tuned using HuggingFace Seq2Seq Trainer. The system employs a 2-pass SLU approach where the second pass combines both acoustic and semantic information. System combination is performed using ROVER to merge outputs from multiple ASR and SLU models, achieving an exact match accuracy of 80.8% on the STOP dataset.

## Key Results
- Achieved 1st place in STOP Challenge with 80.8% exact match accuracy
- ROVER system combination significantly boosted performance beyond individual models
- Whisper ASR transcripts provided substantial improvements when used in compositional and 2-pass E2E SLU models
- Both pipeline and end-to-end approaches were effective, with system combination yielding the best results

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Combining multiple ASR and SLU models using ROVER significantly improves exact match accuracy beyond individual model performance.
- Mechanism: ROVER performs hypothesis-level combination by selecting the best output tokens across multiple models, reducing individual model errors through voting.
- Core assumption: Different models make complementary errors that can be resolved through voting when their outputs are combined.
- Evidence anchors:
  - [abstract] "We also investigate the output level combination of various models to get an exact match accuracy of 80.8, which won the 1st place at the challenge."
  - [section] "We use the ROVER combination on the hypothesis produced by our 4 best ASR models... Using this ASR transcript, we are able to significantly boost the performance of our pipeline systems. We further use ROVER to combine the 4 best SLU models... to achieve EM 80.8."
- Break condition: If models make correlated errors or if ROVER cannot resolve conflicts between different parse structures.

### Mechanism 2
- Claim: Incorporating pretrained language models like BART and T5 significantly improves semantic parsing performance by providing strong contextual understanding.
- Mechanism: Pretrained LMs are fine-tuned on semantic parsing tasks, leveraging their learned representations of language structure and meaning.
- Core assumption: Pretrained LMs have learned transferable linguistic knowledge that can be adapted to semantic parsing tasks.
- Evidence anchors:
  - [abstract] "Strong automatic speech recognition (ASR) models like Whisper and pretrained Language models (LM) like BART are utilized inside our SLU framework to boost performance."
  - [section] "For pretrained LMs, we use BART large and T5 large, which are trained with HuggingFace Seq2Seq Trainer."
- Break condition: If the domain-specific terminology in STOP challenge data differs significantly from pretraining data, limiting transfer effectiveness.

### Mechanism 3
- Claim: 2-pass SLU architecture that combines acoustic and semantic information from pretrained LM transcripts improves performance over single-pass approaches.
- Mechanism: First pass generates ASR transcript, second pass uses both acoustic features and semantic information from the transcript to generate better semantic parse.
- Core assumption: Combining acoustic and semantic information provides complementary signals that improve parsing accuracy.
- Evidence anchors:
  - [section] "Similar to prior work [1], we improve the semantic modeling of our E2E SLU models by adopting a 2-pass SLU approach [2], where the second pass combines both acoustic and semantic information generated by pretrained LM from ASR hypotheses."
  - [section] "We further experiment with using Whisper transcripts in our 2 pass and compositional E2E SLU model directly during inference and observe significant performance gains."
- Break condition: If semantic information from transcript is noisy or inconsistent with acoustic features, leading to conflicting signals.

## Architecture Onboarding

- Component map: Raw audio -> ASR (Whisper + WavLM/Hubert) -> Semantic parsing (BART/T5) -> System combination (ROVER) -> Semantic parse sequences
- Critical path: Audio → ASR model → Semantic parsing model → System combination → Final output
- Design tradeoffs:
  - End-to-end vs pipeline: E2E offers unified training but pipeline allows using specialized models
  - Model complexity vs performance: Larger models like Whisper achieve better accuracy but require more resources
  - Training time vs accuracy: 2-pass approaches improve accuracy but add inference latency
- Failure signatures:
  - Low exact match accuracy: Likely issues with either ASR or semantic parsing component
  - High word error rate: ASR model performance issues
  - Inconsistent outputs: System combination not working effectively
- First 3 experiments:
  1. Baseline evaluation using STOP benchmark models (Wav2Vec2, Hubert) to establish performance floor
  2. Single model evaluation with WavLM frontend and BART large to test individual component effectiveness
  3. System combination experiment with 2-3 best models using ROVER to validate hypothesis voting approach
