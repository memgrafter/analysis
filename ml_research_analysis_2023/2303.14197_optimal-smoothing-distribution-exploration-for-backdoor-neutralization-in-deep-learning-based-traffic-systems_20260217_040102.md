# Optimal Smoothing Distribution Exploration for Backdoor Neutralization in Deep Learning-based Traffic Systems

## Quick Facts
- arXiv ID: 2303.14197
- Source URL: https://arxiv.org/abs/2303.14197
- Reference count: 21
- Key outcome: Proposed method learns optimal noise distribution for randomized smoothing to neutralize backdoor attacks in DRL-based traffic controllers while maintaining system performance

## Executive Summary
This paper addresses backdoor attacks in deep reinforcement learning (DRL)-based autonomous vehicle traffic controllers by proposing a method to learn optimal noise distributions for randomized smoothing. The approach involves learning an unnormalized density function of noise parameters that connects to a stability-to-trigger-sensitivity ratio metric. By sampling from this function, the method generates optimal noise parameters that neutralize backdoor triggers while preserving system performance. Experiments on a simulated single-lane circular traffic system demonstrate effectiveness against backdoor attacks.

## Method Summary
The method learns an unnormalized density function via neural network mapping noise parameters to a stability-to-trigger-sensitivity ratio. This ratio combines average velocity and standard deviation of velocities (r1) with the relative change in desired action (r2). The optimal noise parameters are obtained by sampling from the learned unnormalized density function using a rejection sampling scheme. The approach is applied to DRL-based AV traffic controllers, where the controller is first trained on a poisoned dataset with backdoor triggers, then the optimal smoothing parameters are learned to neutralize these triggers while maintaining system performance.

## Key Results
- Smoothed controller neutralizes all trigger samples while maintaining high average velocity
- Outperforms uniform sampling and isotropic Gaussian noise baselines
- Method naturally extends to other noise types (Bernoulli, uniform) and additional parameters like mean values

## Why This Works (Mechanism)

### Mechanism 1
Learning an unnormalized density function of noise parameters allows optimal noise sampling for backdoor neutralization. The method learns a value function connecting noise parameters to a stability-to-trigger-sensitivity ratio. Sampling from this function yields optimal noise parameters that neutralize trigger samples while preserving system performance. Core assumption: stability-to-trigger-sensitivity ratio is a valid proxy for measuring trade-off between accuracy and robustness.

### Mechanism 2
Randomized smoothing with optimal noise parameters can neutralize backdoor triggers in DRL-based traffic controllers. Adding well-designed noise to inputs increases model robustness against backdoor attacks. Optimal noise parameters are learned to ensure trigger samples are smoothed and cannot cause malicious behavior. Core assumption: backdoor triggers are susceptible to noise perturbation and randomized smoothing can effectively neutralize them.

### Mechanism 3
The sampling strategy from unnormalized density function ensures generation of optimal noise parameters. A rejection sampling scheme generates samples from the unnormalized density function. The optimal noise parameter is accepted as the sample with highest probability from the unnormalized density function. Core assumption: rejection sampling can effectively generate samples from the unnormalized density function.

## Limitations
- The method's effectiveness is demonstrated only on a single-lane circular track with 21 vehicles, limiting generalizability to more complex traffic scenarios
- The approach relies on a specific backdoor attack model (insurance attack) and may not be effective against all types of backdoor attacks
- Computational overhead of the proposed method in real-time applications and scalability with traffic system complexity is not addressed

- High confidence in the fundamental concept of using randomized smoothing for backdoor neutralization
