# Augmented Transformers with Adaptive n-grams Embedding for Multilingual Scene Text Recognition

## Quick Facts
- arXiv ID: 2302.14261
- Source URL: https://arxiv.org/abs/2302.14261
- Reference count: 38
- State-of-the-art performance on multilingual scene text recognition benchmarks

## Executive Summary
This paper introduces TANGER, an augmented transformer architecture for multilingual scene text recognition that combines primary and supplementary transformers with adaptive n-grams embeddings. The model addresses the challenge of recognizing text in scenes containing multiple languages by using a dual-transformer approach that captures both single patch features and correlated neighboring patches. Cross-language rectification through a specialized loss function further improves recognition accuracy by considering both language identification and contextual coherence. Experimental results demonstrate state-of-the-art performance on four benchmark datasets and a newly collected multilingual dataset.

## Method Summary
TANGER consists of a primary transformer that processes single image patches and a supplementary pyramid transformer that employs adaptive n-grams embeddings to capture correlations between neighboring patches. The adaptive n-grams embedding method determines the optimal number of neighboring patches (n) for each patch based on visual word histograms. Cross-language rectification is achieved through a combined loss function that considers both language classification and word coherence scoring. The primary and supplementary transformers share parameters to reduce computational complexity while maintaining performance. The model is trained end-to-end using Adam optimizer with a batch size of 192 for 300 epochs.

## Key Results
- Achieves state-of-the-art performance on four benchmark multilingual scene text datasets
- Outperforms single transformer approaches by effectively capturing correlations between neighboring visual patches
- Demonstrates superior handling of complex multilingual scene texts compared to existing methods

## Why This Works (Mechanism)

### Mechanism 1: Adaptive n-grams embedding
- Claim: Adaptive n-grams embedding improves multilingual scene text recognition by capturing correlations between neighboring visual patches.
- Mechanism: Instead of treating each image patch as an isolated feature, TANGER uses an adaptive n-grams approach that determines the optimal number of neighboring patches for each patch based on visual word histograms. This allows flexible feature extraction tailored to local text structures.
- Core assumption: The optimal n for capturing text features varies across different patches due to variations in font size, orientation, and language script complexity.
- Evidence anchors: [abstract], [section], [corpus] Weak
- Break condition: If the correlation between neighboring patches is not linguistically meaningful, adaptive n-grams could introduce noise rather than improve recognition.

### Mechanism 2: Cross-language rectification loss
- Claim: Cross-language rectification loss improves multilingual recognition by addressing both language identification and contextual coherence.
- Mechanism: The loss function combines language classification loss (SoftCE) and word coherence scoring loss. This dual approach ensures that predicted characters not only belong to the correct language but also form coherent words within that language's context.
- Core assumption: Language identification errors and contextual incoherence are significant sources of error in multilingual scene text recognition that can be mitigated through explicit loss terms.
- Evidence anchors: [abstract], [section], [corpus] Weak
- Break condition: If the language identification module is inaccurate or if the coherence scoring doesn't align with actual language patterns, this mechanism could reinforce incorrect predictions.

### Mechanism 3: Parameter sharing
- Claim: Parameter sharing between primary and supplementary transformers reduces computational complexity while maintaining performance.
- Mechanism: Both transformers use the same encoder parameters, allowing the model to learn shared representations while the supplementary transformer focuses on n-grams features and the primary on single patches.
- Core assumption: The visual features extracted from single patches and n-grams embeddings share sufficient similarity to benefit from parameter sharing without significant performance degradation.
- Evidence anchors: [abstract], [section], [corpus] Weak
- Break condition: If the feature spaces for single patches and n-grams embeddings are too dissimilar, parameter sharing could limit the model's ability to learn specialized representations for each input type.

## Architecture Onboarding

- Component map: RGB image -> Patch division -> Linear projection -> Primary Transformer (single patch embeddings + position embeddings) -> Supplementary Transformer (adaptive n-grams embeddings + spatial pyramid pooling) -> Cross-language Rectification (language classification + coherence scoring) -> Character sequence prediction

- Critical path: Image -> Patch division -> Primary & Supplementary Transformers -> Cross-language Rectification -> Character prediction

- Design tradeoffs:
  - Adaptive n-grams vs. fixed n-grams: Adaptive approach offers flexibility but adds computational overhead for determining optimal n per patch.
  - Parameter sharing vs. separate parameters: Sharing reduces parameters and computation but may limit specialized feature learning.
  - Single vs. multi-model architecture: TANGER uses a single model for efficiency, whereas some approaches use separate models for different languages.

- Failure signatures:
  - Poor performance on multilingual texts: Could indicate issues with adaptive n-grams embedding or cross-language rectification.
  - High computational cost: Might suggest the adaptive n-grams determination is too expensive or parameter sharing is ineffective.
  - Degradation on monolingual texts: Could mean the multilingual-specific components are interfering with monolingual performance.

- First 3 experiments:
  1. Compare single patch embedding (ViTSTR baseline) vs. TANGER on a multilingual dataset to isolate the benefit of adaptive n-grams.
  2. Test TANGER with fixed n-grams (n=2,3,4,5) vs. adaptive n-grams to quantify the adaptive approach's contribution.
  3. Evaluate TANGER with and without cross-language rectification loss on multilingual datasets to measure its impact.

- Basis in paper: [explicit] The paper discusses adaptive n-grams embedding but does not explore its optimal configuration across diverse multilingual scene text scenarios.
- Why unresolved: The paper only tests fixed n values (2, 3, 4, 5) and compares them to adaptive n-grams embedding without exploring the full range of possible configurations.
- What evidence would resolve it: Systematic experiments varying n-grams embedding configurations across diverse multilingual datasets with different script sizes, orientations, and languages.

- What evidence would resolve it: Comparative experiments between TANGER-based end-to-end approaches and state-of-the-art detection-recognition pipelines on multilingual scene text datasets.

## Limitations
- The adaptive n-grams embedding approach lacks extensive validation across diverse multilingual datasets
- Cross-language rectification may not generalize well to languages with significantly different script structures
- Parameter sharing between transformers could limit specialized feature learning for different input types

## Confidence

**High Confidence**: The general transformer architecture and its application to scene text recognition is well-established in the literature. The paper's implementation of a dual-transformer system with shared parameters follows logical design principles and the experimental results demonstrate clear improvements over baseline methods.

**Medium Confidence**: The adaptive n-grams embedding mechanism shows theoretical soundness and empirical benefits, but the optimal n determination method and its sensitivity to different text characteristics warrant further investigation. The cross-language rectification loss appears effective but may be overfitting to the specific datasets used.

**Low Confidence**: The generalizability of TANGER to extremely diverse multilingual scenarios (scripts beyond Latin and Chinese, right-to-left languages, etc.) remains uncertain. The computational complexity claims regarding parameter sharing would benefit from more rigorous analysis across different hardware configurations.

## Next Checks

1. **Cross-dataset robustness validation**: Test TANGER on additional multilingual datasets with significantly different characteristics (e.g., ArT dataset for curved text, or datasets containing Arabic/Hebrew scripts) to evaluate generalization beyond the current evaluation set. Measure both character-level accuracy and word-level edit distance across scripts with different orthographic properties.

2. **Ablation study on n-grams flexibility**: Conduct controlled experiments comparing adaptive n-grams (varying n per patch) against fixed n-grams approaches with different n values (n=2,3,4,5) on the same multilingual datasets. This would quantify the specific contribution of the adaptive mechanism versus simply using n-grams with an optimal fixed value.

3. **Parameter sharing impact analysis**: Implement a version of TANGER where primary and supplementary transformers have separate parameters, then compare model capacity, computational complexity, and recognition performance. Measure FLOPs, parameter count, and training/inference time alongside accuracy metrics to provide a comprehensive efficiency analysis.
