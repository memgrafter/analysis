# Data Augmentation for Robust Character Detection in Fantasy Novels

## Quick Facts
- arXiv ID: 2302.04555
- Source URL: https://arxiv.org/abs/2302.04555
- Reference count: 20
- Key outcome: Data augmentation using mention replacement improves recall for detecting fantasy names in Named Entity Recognition, at the cost of some precision.

## Executive Summary
This paper explores the use of data augmentation to improve Named Entity Recognition (NER) performance for detecting character names in fantasy novels. The authors demonstrate that standard NER models, trained on general datasets, struggle with the unique naming conventions found in fantasy literature. By applying mention replacement augmentation, the model's recall for fantasy character names improves significantly, though this comes at the expense of some precision due to ambiguous entities. The study shows that providing additional local context can mitigate precision loss by helping the model disambiguate entity types.

## Method Summary
The authors apply mention replacement augmentation to inject fantasy-specific character names into the training dataset, addressing the underrepresentation of such names in standard NER training data. They fine-tune a BERT-based NER model on this augmented dataset and evaluate performance across different augmentation rates and context window sizes. The experiments compare baseline performance without augmentation to models trained with varying levels of mention replacement, measuring the impact on precision, recall, and F1 score. The study also tests the effect of expanding the context window to resolve ambiguities that arise from the augmented training data.

## Key Results
- Mention replacement augmentation significantly improves recall for fantasy character names compared to baseline models.
- Precision decreases with higher augmentation rates due to ambiguous entities that the model misclassifies.
- Expanding the context window mitigates precision loss by providing additional information to disambiguate entity types.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Mention replacement introduces fantasy-specific name patterns into training data, enabling the model to learn their entity class distributions.
- Mechanism: The model is exposed to more diverse entity forms (e.g., "Rand al'Thor", "Dagoth Ur") that resemble names in the target domain, adjusting its tokenization and classification layers to better recognize such patterns.
- Core assumption: Fantasy names are underrepresented in general NER training data, so augmentation can fill this gap.
- Evidence anchors:
  - [abstract] "We showcase the application of a specific data augmentation technique, mention replacement [7], to inject new character names in the training dataset."
  - [section 3.1] "We propose to randomly replace training entities with ones from a list of fantasy names to increase the training dataset coverage of this type of names."
  - [corpus] Weak: no direct citation metrics provided; inferred from domain mismatch.
- Break condition: If the replacement names are too far from the target distribution, the model may learn incorrect patterns and degrade overall performance.

### Mechanism 2
- Claim: Additional context resolves ambiguity by providing surrounding cues that disambiguate entity types.
- Mechanism: When the model sees more sentences before and after a token span, it gains information that can distinguish between similar-looking entities (e.g., person vs. location).
- Core assumption: Ambiguous entity classes can be resolved when enough local context is provided to the model.
- Evidence anchors:
  - [abstract] "We show that this decrease in precision can be mitigated by giving the model more local context, which resolves some of the ambiguities."
  - [section 4.2] "We define a context size of n as giving the model the n sentences that precede the considered sentence, as well as the n sentences that follow it."
  - [corpus] No explicit evidence; based on experimental results.
- Break condition: If the ambiguous entity requires knowledge beyond the provided context window, adding more local context will not resolve the ambiguity.

### Mechanism 3
- Claim: Precision loss from augmentation is not caused by class imbalance but by increased name variety encouraging PER predictions for ambiguous tokens.
- Mechanism: As the model sees more diverse name forms during training, it becomes biased toward predicting PER for tokens that look like names, even when context suggests otherwise.
- Core assumption: The decrease in precision is due to the model's increased tendency to predict PER for ambiguous entities, not class imbalance.
- Evidence anchors:
  - [section 4.1] "We test two different methods to inject names in the training dataset that should not suffer from the class imbalance problem... As none of these two methods are able to fix the precision issue, we conclude that class imbalance is not a plausible cause of precision decreasing."
  - [section 4.2] "We manually find that for 62% (58/93) of these false positives, the model attributes a PER label to some tokens even though the context alone is not sufficient to know the correct label."
  - [corpus] No direct evidence; inferred from analysis.
- Break condition: If the ambiguous entities are inherently unresolvable with local context, precision loss will persist regardless of augmentation rate.

- Critical path: Input → Preprocessing → Model → Augmentation → Training → Evaluation
- Design tradeoffs:
  - Augmentation rate vs. precision: Higher augmentation increases recall but decreases precision.
  - Context size vs. computational cost: Larger context improves disambiguation but increases inference time.
  - Replacement vs. upsampling: Replacement can reduce overall performance; upsampling maintains class distribution but doesn't fix precision issues.
- Failure signatures:
  - Persistent precision loss despite context expansion indicates that ambiguous entities require non-local or external knowledge.
  - Performance degradation with high augmentation rates suggests that the synthetic names are too far from the target distribution.
  - Low recall even with augmentation implies that the replacement names are not sufficiently representative of the target domain.

## Limitations
- The exact contribution of each mechanism to precision loss remains unclear, with the analysis relying on negative results rather than direct positive evidence.
- Manual annotation of false positives provides qualitative insight but lacks systematic validation across multiple datasets or annotators.
- The fixed list of replacement names may not fully capture the diversity of fantasy naming conventions across different subgenres or authors.

## Confidence
- **High Confidence**: The core finding that mention replacement improves recall for underrepresented entity types is supported by direct experimental evidence and aligns with established data augmentation principles.
- **Medium Confidence**: The claim that precision loss is not caused by class imbalance but by increased name variety is plausible but relies on negative results from two alternative methods rather than direct positive evidence.
- **Low Confidence**: The assertion that the model becomes biased toward PER predictions for ambiguous tokens due to exposure to diverse name forms is speculative and lacks rigorous statistical validation.

## Next Checks
1. **Cross-dataset validation**: Test the augmentation approach on multiple fantasy corpora with different naming conventions and compare performance to ensure the method generalizes beyond the initial dataset.

2. **Systematic ambiguity analysis**: Conduct a larger-scale annotation study with multiple annotators to classify false positives by ambiguity type and measure inter-annotator agreement, providing more robust evidence for the ambiguity hypothesis.

3. **Alternative augmentation strategies**: Compare mention replacement against other augmentation techniques such as synonym replacement, entity back-translation, or generative approaches to determine if the precision loss is specific to the chosen method or a general challenge of NER augmentation.
