# Global Prompt Cell: A Portable Control Module for Effective Prompt Tuning

## Executive Summary
This paper introduces Global Prompt Cell (GPC), a portable control module for prompt tuning that selectively preserves prompt information across all encoder layers. The proposed GPC consists of two units: a remembering unit and a forgetting unit, which are applied between every pair of adjacent encoders to integrate information from previous layers. The GPC module enables prompt embeddings to serve as a control module that aids pre-trained models in making better decisions, resulting in significant performance improvements on SuperGLUE datasets.

## Method Summary
GPC is designed to address the limitations of traditional prompt tuning methods by maintaining prompt information throughout the network rather than just at the input layer. The module consists of a remembering unit that processes prompt embeddings before they enter each encoder layer, and a forgetting unit that processes them after exiting each layer. These units work together to selectively preserve and update prompt information, creating a control mechanism that guides the model's decision-making process. The method is trained by freezing the original parameters of pre-trained models and only updating the GPC parameters, making it parameter-efficient while significantly improving performance on downstream tasks.

## Key Results
- 5.8% improvement on SuperGLUE datasets compared to vanilla prompt tuning
- GPC outperforms baselines including P-tuning v2, CoOp, and VPT
- Effective across multiple tasks including BoolQ, CB, COPA, RTE, WiC, and WSC

## Why This Works (Mechanism)

### Mechanism 1
- Claim: GPC selectively preserves prompt information across all encoder layers by maintaining a global memory of previous prompt states.
- Mechanism: The Global Prompt Cell uses remembering and forgetting units to selectively integrate information from previous layers with current prompt embeddings. The remembering unit captures information before the transformer layer, while the forgetting unit processes information after the transformer layer.
- Core assumption: Prompt embeddings have different characteristics than token embeddings and require specialized processing to maintain their effectiveness across multiple layers.
- Evidence anchors:
  - [abstract] "selectively preserves prompt information across all encoder layers"
  - [section 3.1] "GPC takes the input and output of the tth encoder, Pt and P*t, to generate the prompt input of the (t+1)th encoder"
- Break condition: If the remembering and forgetting units fail to properly balance historical and current information, the GPC may not effectively preserve prompt information.

### Mechanism 2
- Claim: GPC acts as a control module that aids pre-trained models in making better decisions by maintaining prompt information throughout the network.
- Mechanism: By applying the same GPC module between every pair of adjacent encoders, prompt embeddings serve as a control module that guides the model to achieve better downstream task performance.
- Core assumption: The original approach of concatenating prompt embeddings with token embeddings in the first layer leads to information loss and slow convergence.
- Evidence anchors:
  - [abstract] "prompt embeddings are no longer simply a vector concatenated with token embeddings, but also a control module that aids PTMs in making better decisions"
  - [section 1] "We believe that these drawbacks are due to the traditional approach of inserting prompt embeddings into the input layer"
- Break condition: If the GPC becomes too influential and overpowers the token embeddings, it may lead to suboptimal model performance.

### Mechanism 3
- Claim: GPC reduces the impact of vanishing gradients by maintaining a connection to earlier prompt states.
- Mechanism: The GPC structure is analogous to RNNs, where the cell state S_t maintains information from previous time steps. Similarly, GPC maintains prompt information from previous encoder layers.
- Core assumption: The vanishing gradient problem affects prompt embeddings more severely than token embeddings due to their random initialization and lack of semantic information.
- Evidence anchors:
  - [section 3.3] "GPC output Pt to the RNNs hidden states St, P*t to the RNNs output Ot-1"
  - [section 1] "Long-distance backpropagation can cause the gradient to vanish (Schmidhuber, 2014), leading to slow convergence"
- Break condition: If the GPC mechanism fails to properly maintain gradient flow, the model may still suffer from vanishing gradients despite the GPC implementation.

- Critical path: Input → Remembering unit → Encoder layer → Forgetting unit → GPC combination → Next layer's remembering unit
- Design tradeoffs:
  - Parameter efficiency vs. performance: GPC adds minimal parameters but significantly improves performance
