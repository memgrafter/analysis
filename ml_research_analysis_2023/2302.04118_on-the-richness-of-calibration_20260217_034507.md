# On the Richness of Calibration

## Executive Summary
This paper presents a comprehensive framework for analyzing calibration-based evaluation of probabilistic predictions. The authors systematically decompose the process into grouping (how predictions are partitioned) and agglomeration (how group errors are combined) components, making explicit the choices involved in designing calibration scores. They introduce the vicinity principle as a guideline for grouping, propose characterization of suitable agglomeration functions, and connect calibration evaluation to fairness notions through fairness deviation measures.

## Method Summary
The authors develop a mathematical framework that separates calibration evaluation into two fundamental components: grouping and agglomeration. The grouping component addresses how predictions are partitioned into meaningful subsets using either input features or prediction values, guided by the vicinity principle which requires groups to be large enough for reliable error estimation. The agglomeration component focuses on how to combine individual group calibration errors into an overall score, characterized as interpolating between average and maximum of absolute errors. The framework also establishes connections between calibration evaluation and fairness assessment through fairness deviation measures.

## Key Results
- Input-feature-based grouping consistently outperforms prediction-based grouping for calibration assessment
- Agglomeration functions suitable for calibration evaluation are characterized as interpolating between average and maximum of absolute errors
- Theoretical consistency of localized group-based estimators is established
- Connection between risk measures and fairness deviation measures is demonstrated

## Why This Works (Mechanism)
The framework works by making explicit the implicit choices in calibration evaluation design. By separating grouping from agglomeration, it allows for systematic analysis of each component's impact on evaluation quality. The vicinity principle ensures statistical reliability while the mathematical characterization of agglomeration functions provides theoretical grounding for score design.

## Architecture Onboarding

**Component Map:**
Grouping (Input Features or Predictions) -> Vicinity Principle Application -> Error Calculation -> Agglomeration (Average/Max Interpolation) -> Calibration Score

**Critical Path:**
1. Data grouping based on chosen principle
2. Group error calculation
3. Error combination via agglomeration function
4. Overall calibration score computation

**Design Tradeoffs:**
- Input-feature vs prediction-based grouping: interpretability vs calibration relevance
- Vicinity principle stringency: statistical reliability vs granularity
- Agglomeration function choice: sensitivity to outliers vs overall error representation

**Failure Signatures:**
- Small group sizes leading to unreliable error estimates
- Poor grouping choices causing misleading calibration scores
- Inappropriate agglomeration functions masking or exaggerating specific errors

**First Experiments:**
1. Compare calibration scores using input-feature vs prediction-based grouping on a simple binary classification dataset
2. Test sensitivity of agglomeration functions to varying group error distributions
3. Evaluate fairness deviation measures under different grouping structures
