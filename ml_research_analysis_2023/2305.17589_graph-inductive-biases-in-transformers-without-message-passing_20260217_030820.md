# Graph Inductive Biases in Transformers without Message Passing

## Quick Facts
- arXiv ID: 2305.17589
- Source URL: https://arxiv.org/abs/2305.17589
- Reference count: 26
- Key outcome: GRIT achieves state-of-the-art performance on various graph datasets, outperforming other Graph Transformers and GNNs

## Executive Summary
GRIT introduces a Graph Transformer architecture that incorporates graph inductive biases without relying on message passing. The key innovation is three-fold: learned relative positional encodings initialized with random walk probabilities, a flexible attention mechanism that updates both node and node-pair representations, and injection of degree information using batch normalization. The authors theoretically prove that GRIT can express shortest path distances and various graph propagation matrices, while empirically demonstrating superior performance across multiple graph datasets including ZINC, MNIST, CIFAR10, and molecular property prediction tasks.

## Method Summary
GRIT combines Transformers with graph-specific inductive biases through three design choices. First, it uses learned relative positional encodings initialized with random walk with restart probabilities (RRWP) to capture graph structure. Second, it employs a flexible attention mechanism that updates both node representations and node-pair representations, allowing the model to condition attention on the relationship between nodes. Third, it injects degree information into node representations using degree scalers combined with batch normalization (replacing layer normalization) to preserve the structural information. The architecture is trained end-to-end on graph datasets for both regression and classification tasks.

## Key Results
- GRIT achieves state-of-the-art performance on ZINC molecular regression task with 0.049 MAE
- Outperforms other Graph Transformers (GraphGPS, SAN, Graphormer) and GNNs on PATTERN and CLUSTER datasets
- Shows strong performance on molecular property prediction tasks (Peptides-func, Peptides-struct, PCQM4Mv2)
- Demonstrates theoretical expressive power to approximate shortest path distances and general graph propagation matrices

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Learned relative positional encodings initialized with random walk probabilities can approximate shortest path distances and general graph propagation matrices.
- Mechanism: The RRWP initialization provides a structural encoding that captures multi-hop connectivity patterns. An MLP can then transform these random walk probabilities into distances or propagation matrices by learning the appropriate mapping.
- Core assumption: The random walk probabilities contain sufficient information to reconstruct shortest paths and arbitrary linear combinations of powers of the adjacency matrix.
- Evidence anchors:
  - [abstract] "learned relative positional encodings initialized with random walk probabilities...can express shortest path distances and various graph propagation matrices"
  - [section] "Proposition 3.1. For any n ∈ N...RRWP: P = [I, M, . . . , MK−1]...can approximate shortest path distances...and general classes of graph propagation matrices"
  - [corpus] No direct evidence found in corpus; relies on theoretical proof
- Break condition: If the MLP cannot learn the mapping from RRWP to the target propagation matrices, or if the random walk probabilities are too sparse to capture the necessary structural information.

### Mechanism 2
- Claim: Updating both node and node-pair representations allows the model to learn meaningful attention scores that capture graph structure.
- Mechanism: By maintaining representations for both individual nodes and node pairs, the attention mechanism can condition on the relationship between nodes, not just their individual features. This enables learning of complex structural patterns.
- Core assumption: The node-pair representations contain sufficient information about the graph structure to guide attention, and the attention mechanism can effectively use this information.
- Evidence anchors:
  - [abstract] "a flexible attention mechanism that updates node and node-pair representations"
  - [section] "In each transformer layer, we update node representations xi, ∀i ∈ V and node-pair representations ei,j, ∀i, j ∈ V "
  - [corpus] No direct evidence found in corpus; relies on architectural design
- Break condition: If the node-pair representations become too large to scale, or if the attention mechanism fails to effectively use the pair representations.

### Mechanism 3
- Claim: Injecting degree information with batch normalization (instead of layer normalization) maintains important structural information that would otherwise be lost.
- Mechanism: Degree scalers multiply node representations by degree-based factors, but layer normalization would cancel this effect. Batch normalization preserves these degree-based modifications.
- Core assumption: Degree information is crucial for distinguishing nodes with different connectivity patterns, and batch normalization does not interfere with degree-based scaling.
- Evidence anchors:
  - [abstract] "injection of degree information in each layer"
  - [section] "We inject degree information into the node representations...batch normalization replacing the standard layer normalization"
  - [section] "Proposition 3.3. Sum-aggregated node representations, degree-scaled node representations, and mean-aggregated node representations all have the same value after application of a LayerNorm"
  - [corpus] No direct evidence found in corpus; relies on theoretical proof
- Break condition: If batch normalization introduces instability or if the degree scalers become redundant with other parts of the model.

## Foundational Learning

- Concept: Graph structure encoding
  - Why needed here: Transformers need to understand graph topology without message passing, requiring effective structural encodings
  - Quick check question: What information does a 2-hop random walk probability encode about node relationships that a 1-hop walk doesn't?

- Concept: Attention mechanisms in graph settings
  - Why needed here: The model relies on learned attention to capture graph structure instead of explicit message passing
  - Quick check question: How does conditioning attention on node-pair representations differ from standard self-attention?

- Concept: Normalization in deep networks
  - Why needed here: The choice between batch and layer normalization affects whether degree information is preserved
  - Quick check question: Why does layer normalization cancel out degree-based scaling while batch normalization doesn't?

## Architecture Onboarding

- Component map: Input features → RRWP initialization → Node and pair representation initialization → GRIT transformer blocks (attention + FFN + degree scaling + batch norm) → Graph prediction head
- Critical path: The transformer blocks are the core where all design choices interact - attention uses updated node-pair representations, degree scaling injects structural information, and batch norm preserves it
- Design tradeoffs: Using batch norm instead of layer norm preserves degree information but may introduce batch size dependencies; maintaining pair representations increases memory usage from O(n) to O(n²)
- Failure signatures: Poor performance on small datasets suggests insufficient inductive bias; unstable training suggests batch norm issues; degraded performance when removing degree scalers indicates their importance
- First 3 experiments:
  1. Test GRIT on a small graph dataset with varying K values for RRWP to find optimal hop count
  2. Compare GRIT with and without degree scalers on a dataset with diverse node degrees
  3. Test GRIT's ability to learn specific graph propagation patterns on synthetic data

## Limitations
- Scalability concerns due to O(n²) memory complexity from maintaining node-pair representations
- Potential training instability from using batch normalization, especially with small batch sizes
- Reliance on MLP learnability to transform RRWP into arbitrary propagation matrices may not hold in practice

## Confidence

- High confidence: GRIT's ability to outperform other Graph Transformers on tested datasets
- Medium confidence: Theoretical claims about expressing shortest paths and propagation matrices (dependent on MLP learnability)
- Medium confidence: Degree information preservation through batch normalization (theoretically sound but may have practical limitations)

## Next Checks

1. **Scalability test**: Evaluate GRIT on larger graph datasets (e.g., OGB-LSC) to measure the practical impact of O(n²) memory complexity and identify breaking points.

2. **Ablation study on normalization**: Systematically compare batch normalization vs. layer normalization vs. alternative normalization schemes across different batch sizes to quantify the degree information preservation effect.

3. **Expressive power validation**: Create synthetic graph datasets where specific propagation patterns are known, then test whether GRIT can actually learn these patterns when initialized with RRWP, providing empirical validation of the theoretical claims.
