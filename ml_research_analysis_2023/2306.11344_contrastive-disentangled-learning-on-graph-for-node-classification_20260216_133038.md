# Contrastive Disentangled Learning on Graph for Node Classification

## Quick Facts
- arXiv ID: 2306.11344
- Source URL: https://arxiv.org/abs/2306.11344
- Authors: 
- Reference count: 27
- The paper proposes CDLG, a contrastive disentangled learning framework that outperforms unsupervised baselines and matches supervised methods on node classification tasks.

## Executive Summary
This paper introduces CDLG, a contrastive disentangled learning framework for node classification on graph-structured data. The framework addresses two key challenges: entangled embeddings in graph data and heavy reliance on labeled data. CDLG incorporates a disentangled graph encoder with channel-specific routing and two self-supervision signals (node specificity and channel independence) to learn disentangled node embeddings without requiring extensive labeled data. Experiments on three citation networks demonstrate that CDLG achieves superior performance compared to various baseline models.

## Method Summary
CDLG uses a disentangled graph encoder that learns separate embeddings for each latent factor through a routing mechanism that probabilistically assigns neighbor nodes to different channels. Each channel maintains separate parameters and uses softmax-weighted aggregation over neighbors. The framework employs two self-supervision signals: node specificity ensures embeddings from two augmented views of the same node are similar, while channel independence ensures different channels capture distinct semantic information by contrasting embeddings across channels. The model is trained using contrastive learning with binary cross-entropy loss combining positive samples (same node across views) and negative samples from both self-supervision signals.

## Key Results
- CDLG consistently outperforms unsupervised baselines on Citeseer and Pubmed datasets
- Achieves higher accuracy than DisenGCN on Pubmed while matching its performance on Citeseer
- Demonstrates effectiveness of disentangled representations through visualization analysis

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The disentangled graph encoder learns separate embeddings for each latent factor via a routing mechanism that probabilistically assigns neighbor nodes to different channels.
- Mechanism: Each channel maintains separate parameters (Wk, bk) to transform node features, then uses softmax-weighted aggregation over neighbors based on similarity between neighbor embeddings and the current channel's representation.
- Core assumption: Different latent factors in graph data can be separated into distinct channels through learned routing probabilities that reflect neighborhood semantic coherence.
- Evidence anchors: [section] "The initial embedding vector for k-th channel can be obtained by the following equations: cu,k = σ (W ⊤ k xu + bk)" and "neighborhood routing mechanism [10] is adopted to aggregate the neighborhood information of nodes for each channel"

### Mechanism 2
- Claim: Node specificity self-supervision ensures that embeddings from two augmented views of the same node are similar while embeddings from different nodes remain distinct.
- Mechanism: Creates positive pairs by matching node embeddings from view 1 and view 2, then trains a discriminator to maximize similarity for same-node pairs and minimize similarity for different-node pairs using noise-contrastive estimation.
- Core assumption: The contrastive loss between two views can effectively capture and preserve node identity while learning meaningful representations without labels.
- Evidence anchors: [section] "We devise the first signal to enforce that for the same node, the learned embeddings of two views are consistent with each other. For different nodes, the learned embeddings are able to capture discriminative information and be distinguished from each other"

### Mechanism 3
- Claim: Channel independence self-supervision ensures that different channels capture distinct and non-overlapping semantic information by contrasting embeddings across channels.
- Mechanism: Creates negative pairs by taking embeddings from the same node but different channels, training the discriminator to maximize dissimilarity between channel embeddings from the same view.
- Core assumption: Semantic factors in graph data are naturally independent and can be separated into orthogonal channels through contrastive training.
- Evidence anchors: [section] "The signal is designed to restrict the independence between various channels because distinct channels are supposed to capture exclusive and non-overlapping information"

## Architecture Onboarding

- Component map: Input features → Disentangled Graph Encoder (K channels with routing) → Two augmented views → Contrastive Learning Framework (Node Specificity + Channel Independence) → Concatenated embeddings → Linear classifier for node classification
- Critical path: Graph → Disentangled encoder → Contrastive loss optimization → Classifier training
- Design tradeoffs: More channels (K) provide finer-grained disentanglement but increase computational cost and risk of overfitting; augmentation strength affects quality of positive/negative pairs
- Failure signatures: If channels converge to identical representations, disentanglement has failed; if contrastive loss plateaus early, augmentation or negative sampling may be inadequate
- First 3 experiments:
  1. Train with K=1 (no disentanglement) to establish baseline performance
  2. Train with K=2-4 channels without contrastive loss to test disentanglement capability alone
  3. Train full model with different augmentation ratios to find optimal negative sample quality
