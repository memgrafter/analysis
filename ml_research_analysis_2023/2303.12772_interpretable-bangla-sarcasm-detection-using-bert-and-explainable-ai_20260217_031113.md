# Interpretable Bangla Sarcasm Detection using BERT and Explainable AI

## Quick Facts
- arXiv ID: 2303.12772
- Source URL: https://arxiv.org/abs/2303.12772
- Reference count: 15
- Primary result: BERT-based model achieves 99.60% accuracy on Bangla sarcasm detection vs 89.93% for traditional ML algorithms

## Executive Summary
This paper introduces a BERT-based approach for detecting sarcasm in Bangla text, achieving state-of-the-art performance with 99.60% accuracy. The authors develop the BanglaSarc dataset from Facebook and YouTube comments, containing 5,112 samples with 1,951 sarcastic and 3,159 non-sarcastic instances. The system employs Local Interpretable Model-Agnostic Explanations (LIME) to provide interpretability, addressing both the technical challenge of sarcasm detection and the need for explainable AI in low-resource languages.

## Method Summary
The approach uses BERT with stratified K-fold cross-validation on the BanglaSarc dataset, comparing performance against traditional machine learning models including Random Forest, SVM, and Naive Bayes. Data preprocessing involves removing emojis, stopwords, and punctuation from Bangla text. The model is evaluated using accuracy, precision, recall, and F1-score metrics, with LIME providing explanations for individual predictions by identifying the most influential words in sarcasm detection decisions.

## Key Results
- BERT achieves 99.60% accuracy on Bangla sarcasm detection, significantly outperforming traditional ML algorithms at 89.93%
- Stratified K-fold cross-validation provides more reliable performance estimates for the moderately imbalanced dataset
- LIME successfully identifies key words and phrases that contribute to sarcasm detection decisions
- The BanglaSarc dataset provides a valuable resource for Bangla NLP research

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BERT's bidirectional transformer architecture captures deep semantic nuances in Bangla text
- Core assumption: Pre-trained BERT can effectively transfer language understanding to Bangla without extensive fine-tuning
- Evidence: BERT achieves 99.60% accuracy vs 89.93% for traditional ML
- Break condition: Performance degrades with domain-specific slang not in pre-training data

### Mechanism 2
- Claim: Stratified K-fold prevents overfitting by maintaining class distribution across folds
- Core assumption: Dataset diversity supports effective stratified sampling despite class imbalance
- Evidence: Model employs stratified K-fold with various performance metrics
- Break condition: Temporal or topical patterns unevenly distributed across folds

### Mechanism 3
- Claim: LIME provides interpretable explanations by identifying influential words in predictions
- Core assumption: BERT's black-box predictions can be approximated by interpretable local models
- Evidence: LIME employed for explainability in the study
- Break condition: Multi-word expressions where individual word importance is misleading
