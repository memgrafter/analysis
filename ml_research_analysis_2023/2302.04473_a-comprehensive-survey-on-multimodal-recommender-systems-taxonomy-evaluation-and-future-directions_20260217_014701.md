# A Comprehensive Survey on Multimodal Recommender Systems: Taxonomy, Evaluation, and Future Directions

## Quick Facts
- arXiv ID: 2302.04473
- Source URL: https://arxiv.org/abs/2302.04473
- Reference count: 40
- This survey provides a comprehensive overview of multimodal recommender systems, classifying models based on their methods and presenting a clear pipeline with commonly used techniques.

## Executive Summary
This survey systematically examines multimodal recommender systems that combine user interaction data with auxiliary multimodal content like images, text, and audio to improve recommendation performance and address cold-start issues. The paper introduces a comprehensive taxonomy classifying models by their methodology (matrix factorization, neural networks, GNNs) and analyzes the performance of various approaches across four public datasets. The study identifies key challenges in modality fusion, data splitting standardization, and evaluation metrics, while providing a framework that enables new researchers to understand principles and implement state-of-the-art models easily.

## Method Summary
The survey presents a taxonomy-based framework for multimodal recommendation systems, categorizing approaches into MF-based, MLP-based, and GNN-based methods. It analyzes the performance of state-of-the-art models using four Amazon datasets (Baby, Sports, Electronics, FoodRec) with pre-extracted visual features from CNN models and textual features from pre-trained embeddings. The framework includes feature extraction (CNNs for images, transformers for text), modality fusion strategies (early, intermediate, late), model classification, optimization using losses like BPR and contrastive objectives, and evaluation using top-k metrics. The MMRec framework provides a common implementation platform for running and comparing baseline models with consistent data splitting strategies.

## Key Results
- Multimodal features improve recommendation accuracy by capturing complementary information beyond user-item interactions
- Graph Neural Networks effectively propagate multimodal information across user-item relationships
- Self-supervised learning uncovers latent relationships between modalities without requiring explicit labels
- Data splitting strategy significantly impacts model performance, with temporal splits providing more realistic evaluation
- Early fusion, intermediate fusion, and late fusion methods each have distinct advantages and trade-offs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multimodal features improve recommendation accuracy by capturing complementary information beyond user-item interactions.
- Mechanism: By extracting visual, textual, and audio embeddings from items and fusing them with interaction data, the system gains richer representations of both users and items, enabling better prediction of preferences.
- Core assumption: Multimodal features contain non-redundant information that is not captured by interaction data alone.
- Evidence anchors:
  - [abstract] "Those models could capture the hidden relations between different modalities and possibly recover the complementary information which can not be captured by a uni-modal approach and implicit interactions."
  - [section] "The multimodal recommendation leverages the auxiliary multimodal information which could supplement the historical user-item interactions to improve the recommendation performance."
  - [corpus] Weak corpus support: no directly related papers cited on multimodal complementarity.
- Break condition: If multimodal features are highly correlated with existing interaction data, the complementary information assumption fails.

### Mechanism 2
- Claim: Graph Neural Networks effectively propagate multimodal information across user-item relationships.
- Mechanism: GNNs construct modality-specific graphs and perform message passing to aggregate neighborhood information, allowing learned embeddings to reflect both interaction patterns and multimodal content.
- Core assumption: User-item interactions can be represented as a graph where multimodal features can be propagated through edges.
- Evidence anchors:
  - [section] "Graph Neural Networks have been demonstrated powerful to learn the representations for graph data in different areas... It could be easily extended to the recommendation system by considering the user-item relations as a graph relation."
  - [section] "Most data in recommendation could be represented by the graph structure... The main idea of GNN is to aggregate the information from neighbor nodes and update the node representation during the propagation process."
  - [corpus] Moderate corpus support: related papers discuss graph-based multimodal approaches.
- Break condition: If the graph structure does not reflect true relationships or multimodal features are noisy, GNN performance degrades.

### Mechanism 3
- Claim: Self-supervised learning uncovers latent relationships between modalities without requiring explicit labels.
- Mechanism: By creating augmented views of items through techniques like feature masking or dropout, contrastive loss functions can maximize agreement between views, learning representations that capture underlying modality relationships.
- Core assumption: Modality views created through augmentation contain shared information that can be aligned through contrastive learning.
- Evidence anchors:
  - [section] "The self-supervised learning techniques could also help to explore the underlying relations... This paper treats ID as a special modality... and utilizes the self-supervised learning tasks feature drop(FD), feature masking (FM) and feature fine and coarse spaces (FAC) to produce different views of items then uses contrastive learning to learn the underlying training signals."
  - [corpus] Strong corpus support: several papers specifically discuss self-supervised multimodal learning.
- Break condition: If augmentation destroys modality-specific information or contrastive loss is poorly tuned, learned representations may not generalize.

## Architecture Onboarding

- Component map: Raw multimodal data -> Feature extraction (CNN for images, transformers for text) -> Modality fusion -> GNN-based representation learning -> Prediction via BPR loss
- Critical path: Raw multimodal data → Feature extraction (CNN for images, transformers for text) → Modality fusion → GNN-based representation learning → Prediction via BPR loss
- Design tradeoffs: Early fusion vs. intermediate fusion (simplicity vs. preserving modality-specific information), GNN complexity vs. scalability, multimodal feature dimensionality vs. computational cost
- Failure signatures: Poor performance on cold-start items, overfitting to specific modalities, instability across different data split strategies

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can we develop a modality fusion method that maintains modality-specific information while capturing complementary information across modalities?
- Basis in paper: [explicit] The paper explicitly discusses this challenge in Section 8.1, stating "Find out the efficient modality fusion method that can capture complementary information that a single modality can not contain."
- Why unresolved: Current fusion methods like simple concatenation or weighted sum may lose modality-specific properties and fail to capture complementary information effectively.
- What evidence would resolve it: Empirical demonstration that a new fusion method consistently outperforms both single-modality and current multimodal approaches across multiple datasets and domains.

### Open Question 2
- Question: What is the most effective data splitting strategy for multimodal recommendation systems that balances realism with evaluation robustness?
- Basis in paper: [explicit] Section 8.2 discusses standardization of data splitting strategies and notes that "the models will get different performance numbers by using different data splitting strategies even with the same dataset and evaluation metrics."
- Why unresolved: The paper identifies this as a key challenge but doesn't provide definitive guidance on which splitting strategy works best for different scenarios.
- What evidence would resolve it: Systematic evaluation across multiple datasets showing consistent performance patterns under different splitting strategies and guidelines for when to use each approach.

### Open Question 3
- Question: How can we evaluate multimodal recommender systems beyond traditional accuracy metrics to include user experience and fairness considerations?
- Basis in paper: [explicit] Section 8.3 mentions that "the effectiveness should not just consider accuracy but also the user experience and fairness."
- Why unresolved: The paper acknowledges this gap but doesn't propose specific evaluation frameworks that incorporate these dimensions.
- What evidence would resolve it: Development and validation of comprehensive evaluation frameworks that incorporate user satisfaction, fairness metrics, and diversity measures alongside traditional accuracy metrics.

## Limitations
- Evaluation consistency: Data splitting strategies (random vs. temporal) significantly impact model performance, yet many studies use different splitting methods without standardization
- Feature preprocessing variability: Different studies extract and preprocess multimodal features differently, creating implementation inconsistencies
- Cold-start evaluation gap: Most evaluation focuses on warm-start scenarios, with limited systematic assessment of how multimodal features help cold-start users and items

## Confidence
- High confidence: The taxonomy and framework structure (MF, MLP, GNN classification, feature fusion pipeline) is well-supported by multiple implementations and the MMRec framework
- Medium confidence: Claims about multimodal complementarity improving performance are supported by experimental results but depend heavily on feature quality and fusion method
- Medium confidence: GNN effectiveness for multimodal propagation is demonstrated but may not generalize to all recommendation scenarios or graph structures
