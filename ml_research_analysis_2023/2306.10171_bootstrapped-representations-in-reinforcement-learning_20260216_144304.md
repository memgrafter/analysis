# Bootstrapped Representations in Reinforcement Learning

## Quick Facts
- arXiv ID: 2306.10171
- Source URL: https://arxiv.org/abs/2306.10171
- Reference count: 40
- Key outcome: Shows TD learning converges to top-d invariant subspace of transition matrix, differing from Monte Carlo representations

## Executive Summary
This paper provides a theoretical analysis of how temporal-difference (TD) learning shapes representations in reinforcement learning compared to Monte Carlo (MC) and residual gradient methods. The authors demonstrate that TD methods converge to the top-d invariant subspace of the transition matrix, which is fundamentally different from the subspaces learned by MC methods. This difference depends critically on the choice of auxiliary tasks and learning algorithm, with implications for policy evaluation performance. The paper also shows that random cumulants can effectively approximate optimal representations under certain conditions, and validates these theoretical findings empirically on classic RL domains.

## Method Summary
The authors analyze representation learning in bootstrapped RL by studying how different learning algorithms (TD, MC, residual) converge to different subspaces of the state space. They formulate this as a matrix factorization problem where the transition matrix is decomposed into learned features and a cumulant matrix. Through theoretical analysis, they show that TD learning converges to the top-d invariant subspace of the transition matrix, while MC learning converges to a different subspace related to the cumulant matrix. They derive conditions for optimal representation quality and show that random cumulants can be effective when the transition matrix has certain properties. The analysis is validated through experiments on classic control domains comparing different cumulant designs.

## Key Results
- TD learning converges to the top-d invariant subspace of the transition matrix, while MC learning converges to a different subspace
- The representation subspaces for TD and MC are equivalent only when the transition matrix is symmetric
- Environment structure-aware cumulants improve pre-training performance on classic RL domains
- Random cumulants can effectively approximate optimal representations when the transition matrix has high rank or when cumulants are drawn from orthogonal distributions

## Why This Works (Mechanism)
Bootstrapped RL methods learn representations by minimizing prediction errors over time. The key mechanism is that TD learning uses bootstrapped targets that incorporate the learned transition dynamics, causing the representation to align with the invariant subspace structure of the transition matrix. In contrast, MC methods use complete returns that don't bootstrap, leading to different representation learning dynamics. The cumulant matrix acts as a projection that determines which aspects of the state space are emphasized during learning. When the cumulant matrix is well-designed, it can guide the representation to capture the most relevant state features for the prediction task.

## Foundational Learning
- **Temporal-difference learning**: On-policy prediction method that updates value estimates based on temporal differences between consecutive predictions. Needed to understand the core algorithm being analyzed.
- **Invariant subspaces**: Mathematical subspaces that remain unchanged under linear transformations. Quick check: Verify that learned representations project states into subspaces that respect transition dynamics.
- **Matrix factorization**: Decomposition of matrices into products of simpler matrices. Quick check: Confirm that the transition matrix can be factorized into feature matrix and cumulant matrix.
- **Policy evaluation**: Task of estimating value functions for a given policy. Quick check: Ensure the learned representations enable accurate value prediction for the target policy.
- **Cumulant design**: Process of selecting appropriate reward signals for auxiliary tasks. Quick check: Validate that cumulants encode relevant information about state transitions.
- **Representation convergence**: Property that learning algorithms converge to stable feature representations. Quick check: Monitor feature changes over training to confirm convergence.

### Critical Path
1. Environment provides transition dynamics (transition matrix)
2. Learning algorithm selects cumulant matrix
3. Representation is learned through iterative updates
4. Representation quality is evaluated via policy evaluation error

### Design Tradeoffs
- Tabular vs neural network parameterization: Tabular allows exact analysis but limits scalability
- Random vs learned cumulants: Random cumulants are easier to implement but may be suboptimal
- TD vs MC learning: TD is more sample-efficient but learns different representations than MC
- Linear vs nonlinear function approximation: Linear allows theoretical guarantees but may limit expressiveness

### Failure Signatures
- Poor policy evaluation performance indicates suboptimal representation learning
- Slow convergence suggests the cumulant matrix is poorly aligned with transition dynamics
- Instability in learned features indicates learning rate or initialization issues
- Representations that don't respect transition dynamics suggest algorithmic errors

## Open Questions the Paper Calls Out
### Open Question 1
- Question: How do representation dynamics differ when using neural network parameterizations versus tabular updates in bootstrapped methods?
- Basis in paper: [inferred] The paper assumes tabular updates for theoretical analysis but acknowledges this as a key limitation in the conclusion.
- Why unresolved: The theoretical analysis relies on exact matrix representations, while neural networks introduce additional approximation errors and generalization effects.
- What evidence would resolve it: Empirical comparison showing how representation learning dynamics change with neural network parameterization versus tabular updates.

### Open Question 2
- Question: Under what conditions do random cumulants perform well for TD learning versus Monte Carlo learning?
- Basis in paper: [explicit] The paper shows random cumulants work differently for TD and MC objectives, with MC requiring isotropy and orthogonality while TD focuses more on column norm.
- Why unresolved: The theoretical error bounds are asymptotic and don't fully characterize when random cumulants will be effective in practice.
- What evidence would resolve it: Empirical study showing the relationship between environment structure, cumulant properties, and representation quality for both TD and MC learning.

### Open Question 3
- Question: How can we design optimal cumulant matrices that adapt to environment dynamics without requiring prior knowledge?
- Basis in paper: [explicit] The paper identifies that optimal cumulants must encode environment dynamics but notes that designing them requires prior knowledge.
- Why unresolved: The paper provides conditions for optimal cumulants but doesn't show how to learn them without knowing the transition matrix.
- What evidence would resolve it: Algorithm that learns effective cumulant matrices through interaction, validated on multiple domains.

### Open Question 4
- Question: How does the choice of learning rule (TD, MC, residual) interact with environment properties to affect representation quality?
- Basis in paper: [explicit] The paper demonstrates that different learning rules converge to different representations, with TD and MC being equivalent only for symmetric transition matrices.
- Why unresolved: The theoretical analysis focuses on specific cases (e.g., symmetric matrices) but doesn't fully characterize when each learning rule is optimal.
- What evidence would resolve it: Empirical study showing how representation quality varies across different environment structures for each learning rule.

## Limitations
- Theoretical results assume linear function approximation and tabular settings, limiting direct translation to deep RL
- Analysis focuses on policy evaluation rather than control tasks, restricting applicability to full RL problems
- Connection between theoretical invariant subspace properties and practical performance gains needs more empirical validation
