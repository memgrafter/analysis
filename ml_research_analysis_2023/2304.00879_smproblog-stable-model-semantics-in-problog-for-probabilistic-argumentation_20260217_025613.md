# smProbLog: Stable Model Semantics in ProbLog for Probabilistic Argumentation

## Quick Facts
- arXiv ID: 2304.00879
- Source URL: https://arxiv.org/abs/2304.00879
- Reference count: 15
- Introduces smProbLog, a system that integrates stable model semantics with ProbLog for probabilistic argumentation

## Executive Summary
This paper presents smProbLog, a novel system that extends ProbLog2 with stable model semantics to handle probabilistic argumentation frameworks. The authors develop a new interpretation of argumentation problems as probabilistic logic programming programs, enabling joint probability distribution modeling of beliefs in arguments. By implementing this semantics in smProbLog, the system can effectively learn agent beliefs from observed accepted arguments in argumentation scenarios.

## Method Summary
The authors propose interpreting probabilistic argumentation frameworks as PLP programs, allowing them to model the joint probability distribution of beliefs in arguments. They develop a new PLP semantics that handles non-deterministic choices induced by the logical structure of argument graphs. This approach is implemented as an extension to the ProbLog2 framework, creating smProbLog which combines PLP tools with argumentative reasoning capabilities.

## Key Results
- Successfully learns agent beliefs from observations of accepted arguments in argumentation problems
- Demonstrates effective handling of non-deterministic choices in argument graph structures
- Shows practical utility of combining PLP tools with argumentative reasoning through evaluation on argumentation datasets

## Why This Works (Mechanism)
The approach works by mapping argumentation frameworks to probabilistic logic programs, where argument acceptance can be modeled with probabilities. The stable model semantics provides a way to handle the non-deterministic choices that arise from the logical dependencies in argument graphs, while ProbLog2's inference engine can compute the resulting probability distributions.

Design Tradeoffs:

- Expressiveness vs. tractability: More detailed argument representations may lead to harder inference problems

Failure Signatures:
- Incorrect belief distributions when argument graph has complex cyclic dependencies
- Performance degradation with large argumentation frameworks
- Incorrect stable model identification in presence of conflicting arguments
