# Predicting multiple sclerosis disease severity with multimodal deep neural networks

## Quick Facts
- arXiv ID: 2304.04062
- Source URL: https://arxiv.org/abs/2304.04062
- Reference count: 39
- Up to 25% increase in AUROC compared to single-modal models

## Executive Summary
This paper presents a multimodal deep learning framework for predicting Multiple Sclerosis disease severity using structured EHR data, neuroimaging (MRI), and clinical notes. The approach employs separate encoder networks for each data modality that transform inputs into unified embeddings, which are then fused using attention mechanisms for classification. The model achieves significant performance improvements over single-modal baselines, demonstrating the complementary value of combining different data types for MS severity prediction.

## Method Summary
The method uses a multimodal deep neural network with separate encoder-decoder architectures for each data type: ResNet encoders for MRI sequences, graph attention networks for clinical notes, and attention-based CNNs for structured EHR tables. The encoder processes each modality separately, then a decoder with self-attention fuses the embeddings to predict EDSS milestones (EDSS > 4.0, EDSS > 6.0, EDSS > 7.0). The model handles irregular longitudinal data through self-attention mechanisms and uses triplet margin loss for metric learning on embeddings. Training employs 5-fold cross-validation with longitudinal data from current and historical visits.

## Key Results
- Up to 25% increase in AUROC compared to single-modal models
- Significant improvements in AUPRC, sensitivity, specificity, F1 score, and accuracy
- Clinical notes encoder can be removed without substantial performance loss, indicating redundancy with other modalities

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multimodal fusion using learned embeddings outperforms single-modal baselines because each modality captures complementary aspects of disease severity.
- Mechanism: Encoder networks transform heterogeneous data (MRI, EHR, clinical notes) into unified embeddings, which a decoder with attention learns to integrate for classification.
- Core assumption: Different data modalities encode complementary, non-redundant information about MS severity.
- Evidence anchors:
  - [abstract] "The proposed pipeline demonstrates up to 25% increase in terms of the area under the Area Under the Receiver Operating Characteristic curve (AUROC) compared to models using single-modal data."
  - [section] "The results show significant prediction accuracy improvements compared to using single-modality data or simpler models."
  - [corpus] Weak; corpus lacks direct MS multimodal comparison studies.
- Break condition: If attention weights collapse to uniform or modality embeddings are highly correlated, the fusion advantage disappears.

### Mechanism 2
- Claim: Self-attention over irregular longitudinal data captures disease progression dynamics better than imputation-based methods.
- Mechanism: 1D convolutions with attention weights aggregate features across time without requiring fixed-length alignment or imputation.
- Core assumption: Disease-relevant information is distributed non-uniformly across time and can be weighted adaptively.
- Evidence anchors:
  - [section] "We introduce a self-attention module into the encoder network to handle the irregularity sampling issue, by promoting the neural network to automatically pay distinctive attention (by assigning different attention weights) to different time points of patient history."
  - [section] "Traditional imputation-based methods usually define a shared regular-spaced time axis for all patients and tries to impute the missing values..."
  - [corpus] Weak; no direct comparison to imputation methods in corpus.
- Break condition: If all attention weights converge to zero or near-zero values, the model loses temporal reasoning capability.

### Mechanism 3
- Claim: Metric learning with triplet loss creates well-separated embedding spaces for positive and negative MS severity classes, improving classification.
- Mechanism: ResNet and graph neural networks trained with triplet margin loss learn embeddings where positive and negative samples are maximally distant.
- Core assumption: MS severity classes are separable in a learned embedding space, and triplet loss is effective for this.
- Evidence anchors:
  - [section] "The triplet margin loss operates directly on embedding distances by promoting the matching point (positive) to the reference point (anchor) and the non-matching point (negative) away from the anchor."
  - [section] "By using a triplet margin loss, the network learns well-separated embedding vectors for positive and negative patients for downstream decoding networks to perform classification."
  - [corpus] Weak; no direct metric learning comparison in corpus.
- Break condition: If triplet loss fails to converge or embedding distances do not improve validation performance.

## Architecture Onboarding

- Component map: MRI encoder (ResNet per sequence) -> EHR encoder (channel per table + attention) -> Clinical notes encoder (graph attention) -> Fusion decoder (Bi-GRU + attention) -> Output classifier
- Critical path: MRI/Notes/EHR -> Embeddings -> Fusion attention -> Classification
- Design tradeoffs: Separate ResNet per MRI sequence vs. shared vs. unified encoder; attention vs. concatenation for fusion; triplet loss vs. classification loss for embeddings
- Failure signatures: Performance collapse to baseline when clinical notes removed; attention weights becoming uniform; overfitting on small dataset
- First 3 experiments:
  1. Train single-modal models (MRI only, EHR only, notes only) to establish baselines
  2. Train multimodal model without attention (simple concatenation) to test attention contribution
  3. Ablate clinical notes to quantify their contribution to performance

## Limitations
- The clinical notes encoder architecture details are underspecified, making exact reproduction challenging
- Lacks direct comparisons to imputation-based methods for handling irregular longitudinal data
- Triplet loss implementation could benefit from more extensive ablation studies to isolate its contribution

## Confidence
- High confidence: Multimodal architecture design and general feasibility for MS severity prediction
- Medium confidence: 25% AUROC improvement claims, pending independent validation and comparison to strong single-modal baselines
- Low confidence: Specific contributions of individual mechanisms (attention, triplet loss, GNN) due to limited ablation studies
