# Symbolic Metamodels for Interpreting Black-boxes Using Primitive Functions

## Quick Facts
- arXiv ID: 2302.04791

## Executive Summary
This paper introduces Symbolic Metamodels using Primitive Functions (SMPF), a novel method for interpreting black-box machine learning models by finding interpretable approximations. The approach leverages Kolmogorov superposition theorem to express multivariate functions as compositions of univariate parameterized functions, represented as trees. Genetic programming searches for optimal tree configurations while gradient descent optimizes function parameters. Experiments demonstrate SMPF's superior performance compared to existing methods in terms of accuracy and interpretability.

## Method Summary
SMPF approximates multivariate functions using Kolmogorov superposition theorem, representing them as trees with parameterized univariate functions as edges. The method employs genetic programming to explore different tree structures and gradient descent to optimize function parameters. This memetic algorithm combines structural exploration with parametric optimization, producing closed-form expressions that are both interpretable and accurate. The approach uses primitive functions like polynomials and exponentials rather than complex Meijer G-functions, making it more practical for higher-dimensional problems.

## Key Results
- SMPF achieves lower computational complexity compared to Meijer G-function methods
- Outperforms existing symbolic metamodeling methods on synthetic functions and real datasets
- Produces interpretable closed-form expressions while maintaining modeling accuracy
- Provides instance-wise feature importance estimates for better model understanding

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Kolmogorov superposition theorem enables representation of multivariate functions as compositions of univariate parameterized functions.
- Mechanism: By approximating KST with trees where edges represent parameterized functions, the method can construct interpretable metamodels that approximate black-box behavior.
- Core assumption: The approximation of KST using trees with L < 2d+1 middle nodes is sufficiently accurate for practical metamodeling tasks.
- Evidence anchors:
  - [abstract] "Our approach utilizes Kolmogorov superposition theorem, which expresses multivariate functions as a composition of univariate functions"
  - [section] "In our method, we approximate KST using trees with L < 2d + 1 middle nodes"
- Break condition: If the tree approximation deviates significantly from true KST representation, the metamodel accuracy will suffer.

### Mechanism 2
- Claim: Genetic programming combined with gradient descent creates a memetic algorithm that efficiently searches for optimal tree configurations and function parameters.
- Mechanism: GP explores different tree structures while GD optimizes function parameters within each tree, allowing both structural and parametric optimization.
- Core assumption: The combination of GP for structure and GD for parameters creates a more effective search than using either method alone.
- Evidence anchors:
  - [abstract] "Inspired by symbolic regression, we use a modified form of genetic programming to search over different tree configurations. Gradient descent (GD) is used to optimize the parameters of a given configuration"
  - [section] "This composition can be represented in the form of a tree. Inspired by symbolic regression, we use a modified form of genetic programming to search over different tree configurations. Gradient descent (GD) is used to optimize the parameters of a given configuration."
- Break condition: If the search space is too large or the fitness landscape is too rugged, the algorithm may get stuck in local optima.

### Mechanism 3
- Claim: Using primitive parameterized functions instead of Meijer G-functions produces interpretable closed-form expressions while maintaining modeling power.
- Mechanism: Simple functions like polynomials, exponentials, and trigonometric functions can be trained via GD to approximate complex behaviors, while remaining interpretable.
- Core assumption: The class of primitive functions chosen is rich enough to approximate the target black-box functions.
- Evidence anchors:
  - [abstract] "We represent the KST expression using trees where edges represent simple parameterized functions (e.g., exponential function)"
  - [section] "Importantly, SR has an advantage over SP and SM that the final result expression is guaranteed to be explainable, as it will be a combination of functions that we chose to include as the building blocks"
- Break condition: If the primitive functions cannot adequately represent the target function's behavior, the metamodel will have poor accuracy.

## Architecture Onboarding

- Component map:
  - Tree structure with three layers (input, middle, root)
  - Edge functions (parameterized univariate functions)
  - Genetic programming engine (population management, crossover, mutation)
  - Gradient descent optimizer (parameter updates)
  - Fitness evaluation (MSE + regularization)

- Critical path:
  1. Initialize random trees with parameterized edge functions
  2. Evaluate fitness using MSE on sampled points
  3. Select fittest trees for reproduction
  4. Apply crossover and mutation to create new generation
  5. Update parameters using gradient descent
  6. Repeat until convergence or max iterations

- Design tradeoffs:
  - Tree complexity vs. computational cost (more middle nodes = more parameters)
  - Sparsity vs. modeling power (connection probability p0)
  - Primitive function richness vs. interpretability
  - Population size vs. exploration diversity

- Failure signatures:
  - Fitness plateaus early (may need more iterations or different hyperparameters)
  - Trees become too complex (increase regularization λ)
  - Poor generalization (check for overfitting with simpler models)
  - Gradient updates diverge (reduce learning rate)

- First 3 experiments:
  1. Approximate simple synthetic functions (e^x, sin(xy), etc.) and compare with SR, SP, SM
  2. Instance-wise feature importance on synthetic datasets (XOR, nonlinear additive, switch)
  3. Real black-box approximation using UCI datasets (Yacht, Energy) and compare with SP

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What are the theoretical guarantees for the convergence and performance of the SMPF method?
- Basis in paper: [explicit] The authors acknowledge that "theoretical analysis is particularly challenging because of the use of GP" and state that "Even though we showed the performance of our model through extensive numerical experiments, our method lacks theoretical guarantees."
- Why unresolved: The use of genetic programming in the SMPF method makes it difficult to provide theoretical guarantees, unlike traditional optimization methods.
- What evidence would resolve it: A rigorous mathematical analysis of the SMPF method's convergence properties and performance bounds would be needed to establish theoretical guarantees.

### Open Question 2
- Question: How does the choice of primitive functions affect the performance and interpretability of the SMPF method?
- Basis in paper: [explicit] The authors mention that "The primitive functions, in principle, can be chosen by the domain expert for the particular task in hand" and provide an example of different sets of primitive functions. They also suggest future work on "Other primitive functions can be used in our setup, e.g., Meijer G-functions."
- Why unresolved: The authors only experimented with a limited set of primitive functions and did not provide a comprehensive analysis of how different choices affect the method's performance and interpretability.
- What evidence would resolve it: Systematic experiments comparing the performance and interpretability of SMPF using various sets of primitive functions would be needed to understand the impact of this choice.

### Open Question 3
- Question: Can the SMPF method be extended to handle high-dimensional data like images?
- Basis in paper: [explicit] The authors state that "our method (similar to other symbolic methods) is not appropriate for high dimensional data like images" and mention it as a limitation of the method.
- Why unresolved: The authors do not provide any suggestions or approaches for extending the method to handle high-dimensional data.
- What evidence would resolve it: Successful application of SMPF or a modified version to image data or other high-dimensional datasets would demonstrate the method's potential for handling such data.

## Limitations

- Theoretical guarantees are lacking due to the use of genetic programming
- Method is not appropriate for high-dimensional data like images
- Performance depends on choice of primitive functions, which requires domain expertise

## Confidence

- **High Confidence:** The theoretical foundation using Kolmogorov superposition theorem and the general approach of combining genetic programming with gradient descent for metamodel discovery.

- **Low Confidence:** The generalizability of the method to other types of black-box models and real-world datasets beyond the UCI repository examples.
