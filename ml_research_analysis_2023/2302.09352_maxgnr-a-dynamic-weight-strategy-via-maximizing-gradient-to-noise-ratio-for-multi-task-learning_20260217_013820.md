# MaxGNR: A Dynamic Weight Strategy via Maximizing Gradient-to-Noise Ratio for Multi-Task Learning

## Quick Facts
- arXiv ID: 2302.09352
- Source URL: https://arxiv.org/abs/2302.09352
- Reference count: 32
- This paper addresses the insufficient training problem in multi-task learning by proposing the MaxGNR algorithm that dynamically adjusts task weights to maximize Gradient-to-Noise Ratio

## Executive Summary
This paper addresses the insufficient training problem in multi-task learning, where some tasks fail to achieve optimal performance compared to single-task learning. The authors identify Inter-Task Gradient Noise (ITGN) as a key factor contributing to this problem. They propose the MaxGNR algorithm, which dynamically adjusts task weights to maximize the Gradient-to-Noise Ratio (GNR) for each task. By maximizing GNR, the algorithm aims to mitigate ITGN interference and improve task performance.

## Method Summary
The MaxGNR algorithm uses momentum-based gradient noise estimation and steepest descent optimization to maximize the Gradient-to-Noise Ratio for each task. The method involves computing optimal task weights at each iteration by maximizing the ratio of gradient norm to noise norm, using momentum gradients to estimate expected gradients and noise. The algorithm is evaluated on NYUv2 and Cityscapes datasets with segmentation, depth, and surface normal tasks.

## Key Results
- MaxGNR outperforms baseline methods under identical experimental conditions
- The algorithm demonstrates effectiveness in addressing the insufficient training problem in multi-task learning
- Evaluation metrics include mIoU, Pixel Accuracy, Absolute/Relative Error, and Mean/Median Angle Distance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: ITGN interference causes performance degradation in MTL tasks
- Mechanism: When multiple tasks are learned jointly, the gradient noise from one task propagates to other tasks, creating additional noise sources beyond the intrinsic task noise. This is particularly problematic for tasks with small gradients, as their optimization becomes dominated by noise rather than signal.
- Core assumption: Gradient noise follows Gaussian distribution (Assumption 1) and tasks have varying gradient magnitudes
- Evidence anchors:
  - [abstract] "Inter-Task Gradient Noise (ITGN) is an additional source of gradient noise for each task, which can also affect the optimization process"
  - [section] "From Eq. 3, we can infer that {Ck} and |S| control the magnitude of {ngk(θ)}, although multiple tasks share |S|, {Ck} are task-specific and determined by the intrinsic characteristics of tasks"
  - Weak corpus evidence for this specific mechanism

### Mechanism 2
- Claim: Maximizing GNR mitigates ITGN interference by balancing gradient signal against noise
- Mechanism: The algorithm dynamically adjusts task weights to maximize the ratio of gradient norm to noise norm for each task. This ensures that tasks with small gradients aren't overwhelmed by noise from other tasks, while tasks with large gradients don't dominate the learning process.
- Core assumption: GNR is a valid metric for measuring optimization quality and can be estimated using momentum gradients
- Evidence anchors:
  - [abstract] "We define the Gradient-to-Noise Ratio (GNR) to measure the relative magnitude of gradient noise and design the MaxGNR algorithm to alleviate the ITGN interference of each task by maximizing the GNR of each task"
  - [section] "Therefore, selecting weights {ωk} to maximize GNRk M is a feasible method to alleviate ITGN interference for task k"
  - Weak corpus evidence for this specific mechanism

### Mechanism 3
- Claim: Dynamic weight adjustment outperforms static weighting strategies
- Mechanism: The algorithm computes optimal weights at each iteration using steepest descent on the GNR objective, allowing the model to adapt to changing gradient and noise characteristics throughout training. This contrasts with static methods that assign fixed weights.
- Core assumption: The optimization landscape changes sufficiently during training to warrant dynamic adjustment
- Evidence anchors:
  - [section] "Because of the non-linearity of Eq. 17, a general analytical solution cannot be found. We use the steepest descent method [3] to obtain the optimal {ωk} at each iteration"
  - [section] "The dynamic weight strategy can assign appropriate weights to each task at different training stages"
  - Weak corpus evidence for this specific mechanism

## Architecture Onboarding

- Component map: Multi-task neural network (shared encoder + task-specific decoders) -> GNR computation module (gradient norm and noise estimation) -> Weight optimization module (steepest descent on GNR objective)
- Critical path: Forward pass → loss computation for each task → gradient computation → momentum-based GNR estimation → weight optimization → parameter update with adjusted weights
- Design tradeoffs: Dynamic weight adjustment provides better task balance but adds computational overhead compared to static weighting methods. The choice of momentum coefficient γ affects the accuracy of GNR estimation.
- Failure signatures: If GNR estimation is inaccurate, tasks may receive inappropriate weights leading to poor performance. If the steepest descent optimization fails to converge, weight updates may become unstable.
- First 3 experiments:
  1. Implement basic multi-task learning with equal weights on NYUv2 to establish baseline performance
  2. Add GNR computation module to analyze gradient and noise distribution across tasks
  3. Implement dynamic weight adjustment using steepest descent on GNR objective and compare performance against static weighting methods

## Next Checks

1. **Gradient noise characterization**: Perform controlled experiments to measure actual gradient noise distributions across tasks and verify whether they follow the assumed Gaussian distribution. Compare noise magnitude relative to gradient signal for different batch sizes and network architectures.

2. **Ablation study on GNR components**: Systematically disable the momentum estimation component and use instantaneous gradients instead to determine how much estimation error affects the final performance. This isolates whether the GNR approximation is critical to success.

3. **Static vs dynamic weight comparison**: Implement a time-averaged version of the MaxGNR weights (effectively creating a static weighting scheme) and compare against both pure static methods and fully dynamic MaxGNR to quantify the actual benefit of dynamic adjustment versus its computational cost.
