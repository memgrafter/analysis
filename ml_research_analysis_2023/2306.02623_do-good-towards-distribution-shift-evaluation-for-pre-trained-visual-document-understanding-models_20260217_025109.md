# Do-GOOD: Towards Distribution Shift Evaluation for Pre-Trained Visual Document Understanding Models

## Executive Summary
This paper introduces Do-GOOD, a comprehensive benchmark for evaluating the robustness of pre-trained visual document understanding models to distribution shifts in document images. The benchmark defines three categories of distribution shifts - image, text, and layout - and provides 9 datasets across 3 VDU tasks. The authors evaluate 5 state-of-the-art VDU models and 2 OOD generalization algorithms, revealing significant performance gaps between in-distribution and out-of-distribution settings. LayoutLMv3 generally performs best, but even it shows substantial drops in performance on OOD data. The benchmark provides a fine-grained framework for assessing the robustness of VDU models to various distribution shifts.

## Method Summary
The Do-GOOD benchmark evaluates VDU model robustness by defining three categories of distribution shifts (image, text, and layout) and generating OOD datasets through automatic strategies like background replacement, text attacks, and layout manipulations. The evaluation framework fine-tunes 5 state-of-the-art VDU models (BROS, LiLT, LayoutLM, LayoutLMv2, LayoutLMv3) on in-distribution datasets and measures performance on both ID and OOD data using appropriate metrics for each task. The benchmark covers 9 datasets across 3 VDU tasks: document information extraction, classification, and visual question answering.

## Key Results
- Significant performance gaps between in-distribution and out-of-distribution settings across all evaluated models
- LayoutLMv3 generally performs best but still shows substantial drops on OOD data
- Common OOD algorithms (Deep Coral, Mixup) do not consistently outperform empirical risk minimization
- Incremental training with Do-GOOD can improve OOD performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Do-GOOD benchmark improves model robustness evaluation by defining fine-grained distribution shifts in image, text, and layout dimensions.
- Mechanism: The benchmark decomposes document images into three modalities (image, text, layout) and generates OOD test sets by perturbing each dimension separately, enabling precise attribution of model failures.
- Core assumption: Distribution shifts can be meaningfully isolated by targeting one modality at a time without unintended side effects on the others.
- Evidence anchors:
  - [abstract] "The Do-GOOD benchmark defines the underlying mechanisms that result in different distribution shifts and contains 9 OOD datasets covering 3 VDU related tasks"
  - [section] "we provide a fine-grained analysis of distribution shifts on document images by dividing them into attributes related to image, text, and layout"
  - [corpus] No direct evidence found in corpus; assumption is inferred from methodology description
- Break condition: If perturbations in one modality inadvertently alter other modalities (e.g., layout changes affect text recognition), the isolation assumption fails and confounds the analysis.

### Mechanism 2
- Claim: Text-specific distribution shifts (BERT-Attack, Word Swap) simulate realistic OCR errors and improve robustness assessment.
- Mechanism: By applying semantic-preserving text attacks, the benchmark creates OOD data that mimics real-world scenarios where OCR introduces errors or malicious text modifications occur.
- Core assumption: The text attack methods generate realistic, challenging perturbations that reflect actual document image corruption patterns.
- Evidence anchors:
  - [abstract] "we employ common text attacks, such as BERT-Attack [27] and Word Swap [34, 35], to simulate a more realistic scenario where input document images may contain problematic text caused by OCR errors"
  - [section] "BERT-Attack, based on pre-trained masked language models exemplified by BERT, is used to produce OOD samples... Word Swap... we apply 5 ways to generate OOD samples"
  - [corpus] No direct evidence found in corpus; assumption is inferred from methodology description
- Break condition: If the text attacks generate unrealistic or overly adversarial examples that don't reflect real OCR error patterns, the assessment loses ecological validity.

### Mechanism 3
- Claim: Layout-specific distribution shifts (merge, move operations) reveal model sensitivity to spatial arrangement changes.
- Mechanism: The benchmark manipulates bounding box layouts by merging smaller boxes or moving entities to different positions, testing whether models rely too heavily on layout patterns rather than semantic content.
- Core assumption: Layout manipulations preserve semantic content while sufficiently changing spatial relationships to test layout dependency.
- Evidence anchors:
  - [abstract] "Another option is to move a particular box to a different location on the document image"
  - [section] "The Move manipulation is designed to investigate the impact of changing layout information from a fine-grained level to a coarse-grained level while maintaining image and text information"
  - [corpus] No direct evidence found in corpus; assumption is inferred from methodology description
- Break condition: If layout manipulations accidentally change text content or visual appearance beyond intended spatial changes, the isolation of layout effects is compromised.

## Architecture Onboarding

- Component map: Distribution shift generators -> OOD dataset creation pipeline -> VDU model evaluation framework -> Performance analysis tools
- Critical path: Generate OOD data → Fine-tune VDU models on ID data → Evaluate on ID and OOD sets → Analyze performance gaps by modality
- Design tradeoffs: Fine-grained analysis enables precise failure attribution but increases complexity; automatic generation enables scalability but may miss edge cases that manual curation would catch
- Failure signatures: Significant performance drops on single-modality shifts indicate over-reliance on that modality; inconsistent OOD algorithm performance suggests the need for task-specific robustness strategies
- First 3 experiments:
  1. Generate one example each of image, text, and layout OOD data from a simple document and visually inspect whether the perturbations achieve the intended effect
  2. Run a pre-trained VDU model (e.g., LayoutLMv3) on ID data and each OOD variant to verify that performance drops occur as expected
  3. Test whether common OOD algorithms (Deep Coral, Mixup) improve robustness on one task (e.g., FUNSD) compared to ERM baseline

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do the three distribution shifts (image, text, and layout) interact with each other to affect the performance of VDU models?
- Basis in paper: [explicit] The paper defines three categories of distribution shifts and evaluates their individual effects on VDU model performance. However, it does not explicitly study the interactions between these shifts.
- Why unresolved: The paper focuses on evaluating the individual effects of each distribution shift category. Understanding the interactions between these shifts would require additional experiments that combine multiple shifts simultaneously.
- What evidence would resolve it: Experiments that systematically combine different types of distribution shifts (e.g., image + text, text + layout, image + layout, all three together) and measure their combined effect on VDU model performance.

### Open Question 2
- Question: Are there inherent limitations in current VDU model architectures that prevent them from handling distribution shifts, or can these limitations be overcome through improved training strategies?
- Basis in paper: [inferred] The paper demonstrates significant performance gaps between in-distribution and out-of-distribution settings, suggesting current models are brittle to distribution shifts. However, it does not definitively determine whether this is due to architectural limitations or training deficiencies.
- Why unresolved: The experiments compare different pre-trained models and OOD algorithms but do not systematically isolate whether architectural changes or training modifications would be more effective at improving robustness.
- What evidence would resolve it: Controlled experiments comparing (1) architectural modifications to existing VDU models, (2) novel training strategies including data augmentation and regularization techniques, and (3) hybrid approaches combining both architectural and training improvements.

### Open Question 3
- Question: How does the effectiveness of OOD generalization algorithms vary across different types of distribution shifts and VDU tasks?
- Basis in paper: [explicit] The paper evaluates two OOD algorithms (Deep Coral and Mixup) across different distribution shifts and tasks, finding inconsistent performance improvements.
- Why unresolved: The paper provides initial evidence that OOD algorithms do not consistently outperform empirical risk minimization, but does not deeply analyze why certain algorithms work better for specific shifts or tasks.
- What evidence would resolve it: Detailed ablation studies that vary (1) the type of distribution shift, (2) the specific OOD algorithm parameters, and (3) the VDU task characteristics to identify which algorithm-task-shift combinations yield the best performance improvements.

## Limitations

- The automatic generation strategies may not fully capture real-world distribution shifts that occur in production document processing systems
- Text attack methods assume OCR errors follow similar patterns, which may not hold for specialized document domains
- Layout manipulation operations could inadvertently alter visual context that models rely on, making it difficult to isolate pure layout effects

## Confidence

- High confidence: The framework's systematic approach to decomposing distribution shifts and the observed performance gaps between ID and OOD settings
- Medium confidence: The effectiveness of automatic generation strategies in simulating realistic distribution shifts, as this depends on the similarity between synthetic and real-world shifts
- Medium confidence: The generalizability of findings across all VDU applications, given the focus on 3 specific tasks and 9 datasets

## Next Checks

1. **Ecological validity test**: Compare the automatic OOD generation strategies against manually curated challenging document samples from real-world production systems to assess whether the synthetic shifts reflect actual failure modes.

2. **Cross-domain generalization**: Evaluate Do-GOOD across additional VDU tasks and document types (e.g., invoices, receipts, scientific papers) not included in the original benchmark to test robustness generalization.

3. **Human evaluation study**: Conduct human studies where annotators assess the semantic equivalence and naturalness of OOD samples generated through text attacks and layout manipulations to validate the quality of distribution shift implementation.
