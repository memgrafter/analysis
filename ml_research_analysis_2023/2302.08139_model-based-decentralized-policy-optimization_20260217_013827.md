# Model-Based Decentralized Policy Optimization

## Quick Facts
- arXiv ID: 2302.08139
- Source URL: https://arxiv.org/abs/2302.08139
- Authors: Not specified
- Reference count: 40
- Key outcome: MDPO outperforms independent PPO and other baselines across various cooperative multi-agent tasks, demonstrating superior performance in both stationary and non-stationary environments.

## Executive Summary
This paper introduces model-based decentralized policy optimization (MDPO) to stabilize policy learning in decentralized multi-agent reinforcement learning. The approach addresses the non-stationarity challenge in decentralized MARL by introducing a latent variable function to construct stationary transition and reward models from an individual agent's perspective. A latent variable prediction method is also proposed to reduce prediction errors. Theoretical analysis shows that MDPO provides more stable policy optimization compared to model-free approaches. Empirically, MDPO demonstrates superior performance across various cooperative multi-agent tasks, including stochastic games, MPE, multi-agent MuJoCo, and Google Research Football.

## Method Summary
MDPO introduces a latent variable function to help construct transition and reward models from an individual agent's perspective, mitigating non-stationarity caused by other agents' simultaneous policy updates. The method learns a latent variable model (transition function Pθ, reward function Rφ, and latent variable function ψω) from collected experiences, then uses a latent variable prediction function fζ to predict future latent variable distributions from historical ones. The policy is updated using experiences generated by the learned model, which provides more stable observation visitation frequency compared to experiences from the non-stationary environment. The approach combines model-based learning with independent policy optimization, theoretically guaranteeing monotonic improvement in the stationary latent variable model.

## Key Results
- MDPO outperforms independent PPO and other baselines across stochastic games, MPE, multi-agent MuJoCo, and Google Research Football environments
- MDPO demonstrates superior performance in both stationary and non-stationary environments
- Theoretical analysis shows MDPO provides more stable policy optimization compared to model-free approaches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Introducing a latent variable function helps stabilize policy learning in decentralized MARL by distinguishing transitions caused by unobservable information.
- Mechanism: The latent variable function ψ(z|o) captures the probability of latent variable z given observation o, allowing construction of stationary transition P(o'|o,a,z) and reward R(o,a,z) functions from an individual agent's perspective.
- Core assumption: The latent variable effectively encodes unobservable information (e.g., other agents' policies) causing non-stationarity.
- Evidence anchors: [abstract]: "incorporates a latent variable function to help construct the transition and reward function from an individual perspective"; [section 3.1]: "we introduce a latent variable to help distinguish different transitions resulting from varying unobservable information"
- Break condition: If the latent variable cannot effectively encode relevant unobservable information, transition and reward functions will still appear non-stationary.

### Mechanism 2
- Claim: Learning a latent variable prediction function reduces the error in the varying latent variable function, contributing to monotonic policy improvement.
- Mechanism: The latent variable prediction function f_ζ(z|z_1,...,z_{l-1}) predicts the latent variable distribution for the current policy rollout using distributions from previous l-1 rollouts, reducing divergence between true and learned latent variable functions.
- Core assumption: The latent variable function varies in a predictable way across policy rollouts.
- Evidence anchors: [abstract]: "a latent variable prediction method is proposed to reduce the error of the latent variable function"; [section 3.4]: "we introduce a latent variable prediction function, which predicts the latent variable distribution given observation o in incoming policy rollout"
- Break condition: If the latent variable function changes in a highly unpredictable manner, prediction function will not effectively reduce error.

### Mechanism 3
- Claim: Independent policy optimization on experiences generated by the latent variable model results in more stationary observation visitation frequency compared to experiences collected in the non-stationary environment.
- Mechanism: The latent variable model, by construction, has stationary transition and reward functions, so independent policy optimization on model-generated experiences yields more stable observation visitation frequency.
- Core assumption: The latent variable model can be accurately learned to represent true environment dynamics.
- Evidence anchors: [section 3.2]: "we theoretically show that independently performing policy optimization on the latent variable model can make the learning process more stable"; [section 4.1]: "The latent variable model generates experiences with more stationary observation visitation frequency than IPPO"
- Break condition: If the learned latent variable model is inaccurate, generated experiences will not reflect true environment dynamics.

## Architecture Onboarding

- Component map: Pθ(o'|o,a,z) -> Rφ(o,a,z) -> ψω(z|o) -> fζ(z|z_1,...,z_{l-1}) -> π

- Critical path:
  1. Collect experiences from policy rollout in the environment
  2. Update transition function Pθ, reward function Rφ, and latent variable function ψω using collected experiences
  3. Update latent variable prediction function fζ using learned latent variable functions from previous policy rollouts
  4. Generate experiences using learned model and updated prediction function
  5. Update policy π using generated experiences
  6. Repeat from step 1

- Design tradeoffs:
  - Deterministic vs. stochastic latent variable: Choice depends on environment properties and experimental performance
  - Ensemble vs. single transition/reward function: Ensemble can improve stability and accuracy
  - Number of policy rollouts l for latent variable prediction: Larger l may improve prediction accuracy but increases computational cost

- Failure signatures:
  - Poor policy performance: Indicates inaccurate learned model or ineffective latent variable prediction
  - High variance in policy updates: Suggests instability in learning process, possibly due to inaccurate model or prediction
  - Slow convergence: May indicate overly conservative model learning or prediction, leading to insufficient exploration

- First 3 experiments:
  1. Implement latent variable model without prediction on a simple stochastic game and compare with IPPO
  2. Add latent variable prediction function and evaluate its impact on model accuracy and policy performance
  3. Test full MDPO algorithm on multi-agent particle environment task and analyze contribution of each component

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but several areas for future research are implied:
- Scalability of MDPO to environments with large numbers of agents
- Extension of latent variable prediction to handle non-stationary environments with irregular or unpredictable patterns

## Limitations
- The theoretical analysis relies on assumptions about accurately learning and predicting the latent variable function, which may not hold in highly complex environments
- Empirical evaluation is limited to specific domains and may not generalize to all cooperative multi-agent tasks
- Computational cost of the proposed method, especially with multiple policy rollouts for latent variable prediction, is not thoroughly discussed

## Confidence
- High: The motivation for addressing non-stationarity in decentralized MARL and the general approach of using a latent variable model to construct stationary transition and reward functions from an individual agent's perspective
- Medium: The effectiveness of the latent variable prediction function in reducing the error of the varying latent variable function and its contribution to monotonic policy improvement
- Low: The robustness of MDPO to highly complex environments and the scalability of the method to tasks with large state and action spaces
