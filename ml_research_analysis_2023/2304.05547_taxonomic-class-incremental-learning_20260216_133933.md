# Taxonomic Class Incremental Learning

## Quick Facts
- arXiv ID: 2304.05547
- Source URL: https://arxiv.org/abs/2304.05547
- Reference count: 40
- Standard CIL methods achieve 58.08% accuracy on CIFAR-100; TCIL achieves 56.74%

## Executive Summary
This paper proposes Taxonomic Class Incremental Learning (TCIL) to address limitations of standard Class Incremental Learning (CIL), where tasks are organized randomly rather than hierarchically. TCIL introduces a semantic curriculum where tasks follow a taxonomic tree structure, enabling coarse-to-fine learning aligned with human learning patterns. The authors unify CIL and taxonomic classification through parameter inheritance schemes, proposing a deep learning architecture that incrementally transfers knowledge from ancestor to descendant classes. Experiments on CIFAR-100 and ImageNet-100 demonstrate that TCIL outperforms existing state-of-the-art CIL methods by 2-3% in final accuracy.

## Method Summary
TCIL organizes learning tasks according to a taxonomic tree, progressing from coarse to fine-grained concepts. The method uses network expansion where new feature extractors are added for each task, combined with hierarchical parameter inheritance. When a parent node is replaced by its children, the parent's classifier parameters are copied to each child and refined independently with added perturbations. A hierarchical feature selection vector determines which features are used for classification based on taxonomic relationships. The model is trained using multiple loss functions including Node-CE for new classes, standard CE for all classes, and auxiliary loss for feature learning.

## Key Results
- TCIL achieves 2% higher final accuracy than SOTA CIL methods on CIFAR-100
- TCIL achieves 3% higher final accuracy than SOTA CIL methods on ImageNet-100
- Semantic curricula improve learning by structuring tasks from coarse to fine concepts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hierarchical parameter inheritance allows coarse-to-fine class separation while preserving parent knowledge
- Mechanism: Parent classifier parameters are copied to children nodes and refined independently with perturbations
- Core assumption: Parent parameters capture meaningful shared features across children
- Evidence anchors: Parameter copying and perturbation described in section 4; "incremental transfer of knowledge from ancestor to descendant"
- Break condition: Poor parent parameters propagate errors to children

### Mechanism 2
- Claim: Semantic curricula improve feature learning by structuring tasks from coarse to fine concepts
- Mechanism: Learning broad categories before fine-grained subcategories develops hierarchical feature extractors
- Core assumption: Semantic curriculum aligns with natural feature space structure
- Evidence anchors: "differences between human and CIL learning settings"; taxonomic tree traversal from root to leaves
- Break condition: Poorly constructed taxonomies may hinder learning

### Mechanism 3
- Claim: Network expansion with hierarchical feature selection prevents interference between tasks
- Mechanism: New feature extractors added per task with selective feature usage based on taxonomic relationships
- Core assumption: Taxonomic hierarchy guides relevant feature selection
- Evidence anchors: "hierarchical feature selection vector"; control vector gt based on hierarchical relationships
- Break condition: Overly restrictive feature selection prevents useful cross-task sharing

## Architecture Onboarding

- Component map:
  - Feature extractors (one per task with hierarchical selection) -> Classifier matrix (hierarchical with inheritance) -> Inheritance mechanism (copies and perturbs) -> Refinement mechanism (trains new parameters) -> Loss functions (Node-CE, CE, auxiliary)

- Critical path:
  1. Initialize with coarse-level task (root node's children)
  2. For each subsequent task: copy parent parameters, add perturbations, train refinement
  3. Use hierarchical feature selection to determine which features to use for each node

- Design tradeoffs:
  - Model complexity vs. performance: More feature extractors improve performance but increase computational cost
  - Granularity of hierarchy: Deeper trees provide more structure but require more data for training
  - Feature selection strategy: Full feature usage vs. hierarchical selection vs. orthogonal expansion

- Failure signatures:
  - Poor performance on fine-grained tasks: May indicate insufficient parent parameters or inadequate refinement
  - Degraded performance on coarse tasks over time: May indicate feature interference or poor hierarchical selection
  - Slow convergence: May indicate overly restrictive feature selection or insufficient training data

- First 3 experiments:
  1. Compare TCIL with random curriculum vs. semantic curriculum on CIFAR-100 to verify curriculum benefits
  2. Compare hierarchical classifier vs. flat classifier with semantic curriculum to isolate classifier architecture benefits
  3. Test different feature selection strategies (full, hierarchical, orthogonal) to optimize feature usage

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does the performance gain of TCIL over CIL methods hold for deeper and more imbalanced taxonomic trees?
- Basis in paper: Explicit mention that TCIL performance degrades with tree depth and requires larger datasets
- Why unresolved: Current experiments limited to 2-4 layer trees; deeper trees need more data for coarse-level nodes
- What evidence would resolve it: Experiments on deeper taxonomic trees with varying class distributions

### Open Question 2
- Question: How robust is TCIL to non-breadth-first traversal strategies for introducing tasks?
- Basis in paper: Tested depth-first and random traversal on balanced trees; suggests testing on imbalanced trees
- Why unresolved: Real-world taxonomic trees are often imbalanced
- What evidence would resolve it: Experiments on naturally imbalanced taxonomic trees with various traversal strategies

### Open Question 3
- Question: What is the optimal feature selection strategy for TCIL in terms of both accuracy and computational efficiency?
- Basis in paper: Compared three strategies with small performance differences
- Why unresolved: Small differences suggest choice depends on dataset characteristics or computational constraints
- What evidence would resolve it: Systematic evaluation across multiple datasets measuring both accuracy and computational costs

## Limitations

- Architectural comparison concerns: TCIL's network expansion adds complexity not present in baseline CIL methods
- Modest curriculum benefits: Semantic vs. random curriculum shows only modest improvement (56.74% vs 55.62%)
- Manually constructed taxonomies: ImageNet-100 uses manually constructed 3-layer taxonomy rather than natural hierarchies

## Confidence

- High confidence: Hierarchical parameter inheritance mechanism and implementation details
- Medium confidence: Benefits of semantic curricula over random task ordering
- Medium confidence: Overall performance improvements relative to baselines given architectural differences
