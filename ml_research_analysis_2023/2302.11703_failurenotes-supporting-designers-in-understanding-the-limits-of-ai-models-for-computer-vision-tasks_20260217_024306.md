# fAIlureNotes: Supporting Designers in Understanding the Limits of AI Models for Computer Vision Tasks

## Quick Facts
- arXiv ID: 2302.11703
- Source URL: https://arxiv.org/abs/2302.11703
- Reference count: 40
- Introduces fAIlureNotes, a tool helping UX designers understand AI model limitations through interactive exploration and failure classification

## Executive Summary
fAIlureNotes is a novel tool designed to help UX designers understand the limitations of pre-trained AI models, particularly for computer vision tasks. The tool enables designers to import user scenarios and images, annotate expected model behavior, and compare it with actual outputs. A unique failure engine automatically classifies mismatches into different AI failure modes, providing actionable insights into model limitations. Through iterative exploration using image generation and data augmentation, designers can derive design considerations for handling AI failures. Evaluation with UX practitioners demonstrated that fAIlureNotes outperforms interactive model cards in assessing context-specific model performance.

## Method Summary
The research team developed fAIlureNotes as an interactive tool that allows UX designers to explore pre-trained AI models' behavior by importing user scenarios and images. Designers can annotate expected model outputs and compare them with actual results. The tool features an automated failure engine that classifies mismatches into different AI failure modes, providing insights into model limitations. The system supports iterative exploration through image generation and data augmentation capabilities. The tool was evaluated through a comparative study with 9 UX practitioners who used fAIlureNotes versus interactive model cards to assess model performance in specific contexts.

## Key Results
- UX practitioners using fAIlureNotes demonstrated better understanding of model limitations compared to interactive model cards
- The automated failure classification system effectively identified and categorized different types of AI failures
- Designers were able to derive actionable design considerations for handling AI failures in user scenarios

## Why This Works (Mechanism)
The tool works by bridging the gap between technical AI model documentation and practical design needs. By allowing designers to work with actual user scenarios and images, fAIlureNotes makes abstract model limitations concrete and actionable. The automated failure classification system helps designers identify patterns in model behavior that might not be apparent through manual exploration alone.

## Architecture Onboarding

Component Map: User Interface -> Scenario Import -> Image Processing -> Model Integration -> Failure Engine -> Results Display

Critical Path: User imports scenario → Annotates expected behavior → System processes images → Model generates outputs → Failure engine classifies mismatches → Results displayed for design insights

Design Tradeoffs:
- Balance between automated analysis and manual exploration
- Tradeoff between comprehensive failure classification and system complexity
- Decision to prioritize computer vision while maintaining potential for other model types

Failure Signatures:
- Input-Output Mismatch: When actual model output differs from expected
- Context Misinterpretation: When model fails to understand scenario context
- Edge Case Failure: When model performs poorly on uncommon inputs
