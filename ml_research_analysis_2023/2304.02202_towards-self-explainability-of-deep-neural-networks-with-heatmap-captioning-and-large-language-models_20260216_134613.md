# Towards Self-Explainability of Deep Neural Networks with Heatmap Captioning and Large-Language Models

## Quick Facts
- arXiv ID: 2304.02202
- Source URL: https://arxiv.org/abs/2304.02202
- Reference count: 23
- One-line primary result: Template-based heatmap captioning combined with large language models shows promise for automatic XAI report generation, though further improvements are needed for fully automatic operation.

## Executive Summary
This paper proposes a framework for automatic, interactive, and scalable explainable AI (XAI) report generation using a large language model (LLM) like ChatGPT. The framework combines a template-based heatmap captioning approach to extract contextual information from heatmaps and source images, with an LLM reasoning module to generate explanations. The approach extracts four key attributes (object identity, position/size, salient regions, and dominant colors) to create captions that inform the LLM about what the neural network is focusing on. While results demonstrate the promise of this approach, the paper highlights the importance of accurate template-based captioning and notes that further improvements are required to achieve fully automatic XAI report generation.

## Method Summary
The framework operates through two main modules: a context module that generates captions from heatmaps using a template-based approach, and a reasoning module that uses an LLM (ChatGPT) to create XAI reports. The context module extracts four attributes from heatmaps and source images: object identity via zero-shot classification using CLIP, global position and size of objects, salient regions within heatmaps, and dominant colors. These attributes are combined into predefined templates to generate captions. The reasoning module then combines these contextual captions with user prompts and specialized knowledge to generate explanations through ChatGPT's language understanding capabilities. The framework can operate automatically or interactively through user feedback.

## Key Results
- Template-based heatmap captioning can extract interpretable contextual attributes without requiring supervised training on image-text pairs
- Large language models can generate meaningful XAI reports when provided with structured heatmap captions and specialized knowledge
- The framework enables automatic, interactive, and scalable XAI by combining context modeling and reasoning modules
- Generated reports were not concise and required well-designed prompts for optimal results

- Claim: The template-based heatmap captioning approach extracts interpretable contextual attributes from heatmaps and source images without requiring supervised training on image-text pairs.
- Mechanism: The approach combines four attributes (object identity via zero-shot classification, global position and size, salient regions, and dominant colors) into predefined templates to generate captions that capture the spatial and semantic content of heatmap activations.
- Core assumption: Heatmaps reliably localize objects and salient regions that correspond to neural network decision-making, and these regions can be meaningfully described using the four extracted attributes.
- Evidence anchors:
  - [abstract] "We proposed a template-based image captioning approach for context modelling to create text-based contextual information from the heatmap and input data."

- Break condition: If heatmaps fail to accurately localize objects or if the extracted attributes do not capture meaningful information about the neural network's decision process.

- Mechanism: The reasoning module combines the contextual information from heatmap captions with user prompts and specialized knowledge to generate explanations through ChatGPT's language understanding capabilities.

### Mechanism 3
- Claim: The framework enables automatic, interactive, and scalable XAI by combining context modeling and reasoning modules.
- Mechanism: The context module automatically generates captions from heatmaps, which are then processed by the reasoning module (LLM) to create explanations, while user feedback enables interactive refinement.

## Architecture Onboarding

- Component map: Image → Heatmap → Caption Generation → LLM Reasoning → XAI Report
- Critical path: The most critical dependency is accurate heatmap generation, as it directly affects the quality of captions and subsequent explanations
- Design tradeoffs:
  - Template-based vs. deep learning captioning: Template-based requires no training data but may lack diversity; deep learning could be more expressive but needs labeled data
  - Zero-shot classification vs. fine-tuned models: Zero-shot is more flexible but potentially less accurate than fine-tuned approaches
  - Generic LLM vs. specialized model: Using ChatGPT provides accessibility but may lack domain-specific optimization
- Failure signatures:
  - Inaccurate captions: Often indicate heatmap localization problems or classification errors
  - Generic/unhelpful reports: May indicate LLM prompt engineering issues or insufficient contextual information
  - Inconsistent explanations: Could suggest problems with the attribute extraction or template formulation
- First 3 experiments:
  1. Test the template-based captioning system with simple, single-object images to verify basic functionality and identify attribute extraction issues
  2. Evaluate the LLM reasoning module with well-formed captions and simple prompts to establish baseline report quality
  3. Test the full pipeline with known neural network architectures and tasks to assess the correlation between heatmap quality and explanation accuracy

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the quality of template-based heatmap captioning compare to deep learning-based image captioning approaches for generating contextual information?
- Basis in paper: [explicit] The paper mentions that "future research could explore the use of deep learning-based image captioning approaches to address these limitations" of the template-based method.
- Why unresolved: The paper only evaluates the proposed template-based approach qualitatively and does not compare it to deep learning-based methods.
- What evidence would resolve it: A quantitative comparison of template-based and deep learning-based heatmap captioning approaches on a dataset of heatmap-image pairs, measuring metrics like caption quality, diversity, and information completeness.

### Open Question 2
- Question: How can large language models be optimized specifically for XAI report generation to produce more concise and informative outputs?
- Basis in paper: [explicit] The paper notes that "reports generated by ChatGPT were not concise and required well-designed prompts" and suggests "designing a large-language model specifically for XAI report generation" as future work.
- Why unresolved: The paper uses ChatGPT out-of-the-box without fine-tuning or prompt engineering specifically for XAI tasks, leaving the potential for optimization unexplored.
- What evidence would resolve it: Experiments comparing XAI report quality from fine-tuned large language models versus ChatGPT, using metrics like conciseness, relevance, and user satisfaction with the generated explanations.

### Open Question 3
- Question: How do different heatmap generation techniques impact the quality and informativeness of the generated captions and subsequent XAI reports?
- Basis in paper: [inferred] The paper uses SESS [18] with GradCAM [14] for heatmap generation but acknowledges that "heatmap-based object localization and zero-shot classification" can introduce errors, suggesting that the choice of heatmap technique may affect downstream performance.
- Why unresolved: The paper only evaluates one heatmap generation method (SESS with GradCAM) and does not investigate how alternative techniques might improve captioning accuracy or report quality.
- What evidence would resolve it: A comparative study of multiple heatmap generation methods (e.g., GradCAM, RISE, Score-CAM) applied to the same images, measuring the impact on caption accuracy, heatmap localization quality, and the resulting XAI report informativeness.

## Limitations
- The template-based approach may lack the diversity and expressiveness of deep learning-based captioning methods
- The framework's effectiveness is heavily dependent on the quality of heatmaps and the capabilities of the LLM used
- Generated reports were not concise and required well-designed prompts, limiting practical usability

## Confidence
- High confidence: The template-based captioning approach using four attributes is well-specified and methodologically sound
- Medium confidence: The integration of heatmap captions with LLM reasoning shows promise but lacks extensive validation
- Low confidence: Claims about scalability and interactive refinement are not empirically demonstrated
