# Adopting the Multi-answer Questioning Task with an Auxiliary Metric for Extreme Multi-label Text Classification Utilizing the Label Hierarchy

## Quick Facts
- arXiv ID: 2303.01064
- Source URL: https://arxiv.org/abs/2303.01064
- Reference count: 5
- Key outcome: Multi-answer questioning task enables single-classifier extreme multi-label classification on EURLEX dataset with proposed classification metric

## Executive Summary
This paper addresses extreme multi-label text classification by adopting a multi-answer questioning task framework. The method converts the multi-label classification problem into an extractive question answering task where document titles are treated as context and concatenated category labels as answer candidates. A single BERT-based classifier with frozen lower layers is fine-tuned to identify which category tokens correspond to the correct labels. The approach leverages the EUROVOC label hierarchy to partition labels into manageable sub-groups. Additionally, the paper proposes an auxiliary classification evaluation metric that focuses on correct category identification rather than exact boundary detection, potentially providing more meaningful assessment for multi-label classification tasks.

## Method Summary
The method transforms extreme multi-label classification into a multi-answer questioning task by encoding labels as sequences and using token-level classification. The approach takes document titles as input and generates a two-sentence format: the first sentence contains the document title, and the second contains concatenated subdomain labels from the EUROVOC hierarchy. A BERT-based classifier with frozen initial layers is fine-tuned to predict which tokens in the label sequence correspond to correct categories. The proposed classification metric modifies standard seqeval evaluation by inserting category boundaries into predicted token sequences before evaluation, focusing on whether information is extracted from the correct category rather than exact chunk boundaries.

## Key Results
- The multi-answer questioning task successfully performs extreme multi-label classification on the EURLEX dataset using a single classifier
- The proposed classification metric improves evaluation performance by focusing on correct category identification
- Domain-adapted BERT models (Legal-BERT, Zlucia) did not show apparent advantages over standard BERT in this experiment

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The multi-answer questioning task enables single-classifier extreme multi-label classification without losing label relationships.
- Mechanism: By converting the multi-label classification problem into an extractive question answering task, the method treats the document as context and dynamically generated category labels as answer candidates. Token-level classification identifies which category tokens belong to correct labels, allowing variable-length label groups to be handled by a single model.
- Core assumption: The label hierarchy can partition labels into manageable sub-groups while preserving semantic content when embedded as text sequences.
- Evidence anchors:
  - [abstract] "This paper adopts the multi-answer questioning task for extreme multi-label classification. This method can build only one classifier to train multi-label classification of label sets of different lengths."
  - [section 3.2] "The multi-label text classification can turn into an extractive multi-answer questioning problem and can be handled with a token classification task."
- Break condition: If the label hierarchy is not meaningful or label semantic content is lost during tokenization, the method would fail.

### Mechanism 2
- Claim: An auxiliary classification evaluation metric improves assessment by focusing on correct category identification rather than exact boundary detection.
- Mechanism: The proposed metric modifies seqeval evaluation by inserting category boundaries into the predicted token sequence before applying seqeval, thus evaluating whether the model extracts information from the correct category rather than requiring exact chunk boundaries.
- Core assumption: Multi-label classification performance is better measured by correct category selection than by exact token span detection.
- Evidence anchors:
  - [section 3.3] "the research proposes the other evaluation method on knowledge extraction by adding the category boundaries to the predicted category tokens before applying the seqeval."
  - [section 5] "The evaluation of extractive multi-label text classification is more likely to evaluate whether to extract information (e.g. tokens) from the right category instead of extracting the exact category chunk."
- Break condition: If exact boundary detection becomes important for downstream applications, this metric would misrepresent performance.

### Mechanism 3
- Claim: Freezing lower layers of BERT and fine-tuning only the higher layers enables effective task adaptation while preserving pre-trained knowledge.
- Mechanism: By freezing the first 11 layers of BERT (including embedding) and fine-tuning the classifier and remaining layers, the model retains general linguistic features while adapting to the specific task distribution of multi-label classification.
- Core assumption: Lower BERT layers capture more general linguistic features while higher layers are more task-specific and benefit from fine-tuning.
- Evidence anchors:
  - [section 3.2] "the concept classification model freezes the first 11 layers and the EMBEDDING layers in BERT, with other layers inside the concept classification model unfrozen, and carries on fine-tuning on the built dataset."
- Break condition: If the task requires significant modification of lower-level features, freezing these layers would limit performance.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the proposed multi-answer questioning task perform on datasets with significantly longer document lengths than EURLEX titles?
- Basis in paper: [explicit] The paper mentions that the longest document in EURLEX is above 20,000 tokens, but the experiment utilizes the title as the text for multi-label classification due to BERT's input length limitations.
- Why unresolved: The paper only tested on title-level text, not full document text, so performance on longer inputs is unknown.
- What evidence would resolve it: Experimental results comparing the proposed method on both titles and full document text for the same dataset.

### Open Question 2
- Question: What is the impact of negative samples on the performance of the multi-answer questioning task?
- Basis in paper: [explicit] The paper mentions that the multi-answer questioning task was first trained with negative samples, but the model performed poorly in validation, leading to the decision to filter out empty-answer samples.
- Why unresolved: The paper did not explore different strategies for incorporating negative samples or analyze their impact on model performance.
- What evidence would resolve it: Ablation studies comparing model performance with and without negative samples, and with different negative sampling strategies.

### Open Question 3
- Question: How do different punctuation symbols for separating categories in the category list affect the performance of the proposed classification metric?
- Basis in paper: [inferred] The paper mentions that categories are separated by commas in the category list and discusses the potential benefits of inserting punctuation marks into the input sequence.
- Why unresolved: The paper only used commas as separators and did not experiment with other symbols or discuss their potential impact.
- What evidence would resolve it: Comparative experiments using different punctuation symbols as category separators and evaluating their impact on the proposed classification metric's performance.

## Limitations
- The method's effectiveness depends heavily on the quality and structure of the label hierarchy
- The evaluation metric lacks validation against established multi-label classification metrics
- The frozen layer approach may limit the model's ability to adapt lower-level linguistic features

## Confidence

**High confidence**: The basic feasibility of converting multi-label classification to a multi-answer questioning task is well-supported by the experimental results on EURLEX, with clear methodology described and measurable outcomes.

**Medium confidence**: The claim that the proposed classification metric provides meaningful improvement over seqeval evaluation has moderate support, but lacks comparison with established multi-label metrics. The evidence shows it works on this dataset but doesn't prove superiority in general.

**Low confidence**: The conclusion that domain-adapted BERT models "could not show apparent advantages" is weakly supported. The paper reports slightly worse performance for Legal-BERT and Zlucia models, but this may reflect insufficient fine-tuning or inappropriate evaluation rather than a fundamental limitation of domain adaptation.

## Next Checks

1. **Cross-domain validation**: Test the multi-answer questioning approach on a non-legal extreme multi-label dataset (e.g., Wikipedia with its category hierarchy) to verify whether the method generalizes beyond the EURLEX domain or if its success depends on specific characteristics of legal text and EUROVOC labels.

2. **Metric comparison study**: Implement standard multi-label classification metrics (F1@k, hamming loss, coverage) alongside the proposed classification metric and seqeval to determine whether the new metric provides meaningful advantages or simply measures different aspects of performance.

3. **Fine-tuning strategy ablation**: Compare the frozen-layer approach against full fine-tuning and adapter-based methods on the same dataset to determine whether the observed performance differences stem from the question-answering conversion or from suboptimal fine-tuning strategies for the BERT variants.
