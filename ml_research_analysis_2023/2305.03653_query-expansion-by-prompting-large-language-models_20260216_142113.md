# Query Expansion by Prompting Large Language Models

## Quick Facts
- arXiv ID: 2305.03653
- Source URL: https://arxiv.org/abs/2305.03653
- Authors: 
- Reference count: 36
- Key outcome: CoT prompts with PRF documents achieve 89.86% Recall@1K on MS-MARCO, outperforming classical methods

## Executive Summary
This paper proposes using large language models (LLMs) for query expansion to improve search recall without relying on pseudo-relevant documents. The study experiments with various prompts including zero-shot, few-shot, and Chain-of-Thought (CoT), both with and without pseudo-relevant feedback (PRF) documents. CoT prompts are found to be particularly effective, generating detailed step-by-step explanations with many useful keywords. The approach outperforms classical query expansion methods on MS-MARCO and BEIR datasets, with CoT prompts combined with PRF documents showing the most robust performance across different model sizes.

## Method Summary
The method uses LLM prompting for query expansion, where input queries are processed through different prompt templates (Q2D, Q2E, CoT) with optional PRF document context. The expanded queries are then used with BM25 retrieval systems. The paper experiments with multiple model sizes from small to 11B+ parameters, systematically varying prompt types and PRF inclusion. The CoT prompt specifically instructs the LLM to provide step-by-step reasoning before generating expansion terms, which produces verbose outputs containing relevant keywords.

## Key Results
- CoT-based expansions achieve 89.86% Recall@1K on MS-MARCO with Flan-T5-XXL (11B parameters)
- Performance scales with model size: CoT prompts on 3B-parameter models match classical baselines
- PRF documents stabilize performance for smaller models while maintaining effectiveness for larger models
- LLM expansions improve both recall and top-heavy metrics (MRR@10, NDCG@10) unlike traditional PRF methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Chain-of-Thought (CoT) prompts generate verbose explanations that include many relevant keywords for query expansion
- Mechanism: CoT prompts explicitly instruct the LLM to "break queries down step-by-step" and provide rationale before answering. This verbose reasoning process naturally surfaces diverse semantic relationships and related terms that might not appear in a direct answer
- Core assumption: The step-by-step reasoning process in CoT prompts exposes latent knowledge connections that are useful for expanding search queries
- Evidence anchors:
  - [abstract] "CoT prompts instruct the model to break queries down step-by-step and can provide a large number of terms related to the original query"
  - [section 5.1] "We hypothesize that this verbosity may lead to many potential keywords that are useful for query expansion"
  - [corpus] Weak evidence - related papers focus on CoT for reasoning rather than query expansion specifically
- Break condition: If the LLM's reasoning process doesn't naturally include relevant terminology, or if the step-by-step breakdown focuses on irrelevant aspects of the query

### Mechanism 2
- Claim: Including Pseudo-Relevance Feedback (PRF) documents stabilizes performance across different model sizes
- Mechanism: PRF documents provide grounding context that helps smaller models avoid hallucinations and focus on relevant terminology, while larger models can still leverage their creative abilities
- Core assumption: PRF documents contain relevant passages that can guide the LLM's output, preventing it from generating irrelevant expansions
- Evidence anchors:
  - [abstract] "Including PRF documents further improves results" and "PRF context helps stabilize performance"
  - [section 5.3] "adding PRF documents to the CoT prompt seems to help stabilize the performance for smaller model sizes but does inhibit its performance at larger capacities"
  - [corpus] Weak evidence - related papers don't specifically address PRF integration with query expansion
- Break condition: If PRF documents are irrelevant or noisy, they could mislead the LLM and degrade expansion quality

### Mechanism 3
- Claim: LLM-based query expansion improves recall without sacrificing top-heavy ranking metrics like MRR@10 and NDCG@10
- Mechanism: Unlike traditional PRF methods that trade recall for precision, LLM-generated expansions can produce both relevant and diverse terms that improve both recall and precision by capturing semantic relationships
- Core assumption: LLMs can generate expansions that maintain relevance while increasing vocabulary coverage
- Evidence anchors:
  - [abstract] "Query2Doc does not only improve recall, but also improves the top-heavy ranking metrics such as MRR@10 and NDCG@10"
  - [section 5.1] "Interestingly, Query2Doc does not only improve recall, but also improves the top-heavy ranking metrics such as MRR@10 and NDCG@10, providing a good improvement across metrics"
  - [corpus] Weak evidence - related papers focus on different aspects of query expansion
- Break condition: If the LLM generates overly generic expansions or if the expanded query becomes too long and dilutes relevance signals

## Architecture Onboarding

- Component map: Query input → Prompt generation (Q2D, Q2E, CoT, with/without PRF) → LLM processing → Expansion terms output → BM25 retrieval system → Evaluation metrics
- Critical path: 1. Query expansion generation (prompt → LLM → expansion terms) 2. Retrieval with expanded query (concatenated query terms → BM25) 3. Evaluation (Recall@1K, MRR@10, NDCG@10)
- Design tradeoffs:
  - Model size vs. performance: Larger models generally perform better but increase computational cost
  - Verbosity vs. relevance: CoT prompts generate more terms but may include irrelevant ones
  - PRF inclusion vs. creativity: PRF documents stabilize performance but may limit the LLM's creative expansion abilities
- Failure signatures:
  - Poor Recall@1K despite large model size: May indicate prompt template issues or insufficient training data for the LLM
  - High Recall@1K but low MRR@10: Expansions may be too generic or not focused on the most relevant terms
  - Performance degradation with PRF: PRF documents may be irrelevant or the LLM may overfit to them
- First 3 experiments:
  1. Compare Q2D vs. CoT prompts on a small model (Flan-T5-Small) to understand prompt effectiveness independent of model size
  2. Test CoT prompt with and without PRF documents on medium model (Flan-T5-Large) to measure PRF impact
  3. Scale up to largest model (Flan-UL2) with CoT/PRF to establish upper performance bounds and compare against classical methods

## Limitations

- The paper does not provide the exact prompt templates used in experiments, making direct reproduction difficult
- Evaluation focuses primarily on recall metrics with limited analysis of precision degradation that might occur with longer expanded queries
- The study does not investigate whether LLM-generated expansions introduce bias toward certain types of queries or domains

## Confidence

**High Confidence**: The finding that larger model sizes (11B+ parameters) consistently outperform smaller models for query expansion is well-supported by the experimental results across multiple datasets and metrics.

**Medium Confidence**: The claim that CoT prompts with PRF documents are "most robust and effective" has strong empirical support but depends on the specific implementation details that are not fully disclosed. The performance improvements over classical methods are clear, but the relative advantage of CoT versus other prompt types could vary with different experimental conditions.

**Low Confidence**: The assertion that CoT prompts "naturally surface diverse semantic relationships" is more of a hypothesis about mechanism rather than an empirically verified claim. The paper provides limited evidence about why CoT specifically works better than other approaches.

## Next Checks

1. **Prompt Template Validation**: Implement the exact CoT prompt structure described and systematically vary the verbosity level to determine if the performance gains are directly attributable to the step-by-step reasoning format or simply to generating more terms overall.

2. **Precision Analysis**: Conduct a detailed analysis of precision metrics (MRR@10, NDCG@10) alongside recall to quantify the precision-recall tradeoff and identify whether the LLM expansions maintain relevance quality as recall improves.

3. **Cross-Dataset Generalization**: Test the CoT prompt approach on datasets not mentioned in the paper, particularly those with different query characteristics (e.g., short queries, entity-heavy queries) to validate whether the method generalizes beyond the MS-MARCO and BEIR datasets used in the study.
