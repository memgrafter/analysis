# Prompt-Guided Zero-Shot Anomaly Action Recognition using Pretrained Deep Skeleton Features

## Quick Facts
- arXiv ID: 2303.15167
- Source URL: https://arxiv.org/abs/2303.15167
- Authors: 
- Reference count: 40
- Primary result: Zero-shot anomaly action recognition using pretrained skeleton features with text prompt guidance

## Executive Summary
This paper presents a novel approach for unsupervised anomaly action recognition in videos using skeleton-based features. The method addresses key limitations in conventional approaches by introducing a pretraining framework that eliminates the need for target-domain DNN training, incorporating user-provided text prompts to reduce false positives for unobserved normal actions, and using a permutation-invariant architecture to improve robustness against skeleton detection errors.

## Method Summary
The method consists of pretraining a skeleton feature extractor on a large-scale action recognition dataset using contrastive learning between skeleton features and text embeddings. During target domain training, DNN weights are frozen while modeling the distribution of normal samples using Mahalanobis distance. The anomaly score combines the Out-of-Distribution (OoD) score with a similarity score between user prompt embeddings and skeleton features. The architecture uses a PointNet-inspired design with sparse feature propagation between joints to handle permutation invariance and skeleton detection errors.

## Key Results
- Achieves comparable or superior performance to state-of-the-art approaches without requiring target domain-dependent DNN training
- Demonstrates effectiveness in addressing three key limitations: domain-dependent training, skeleton error robustness, and unobserved normal samples
- Shows improved performance on RWF-2000 and Kinetics-250 datasets compared to conventional methods

## Why This Works (Mechanism)

### Mechanism 1
Pretraining a skeleton feature extractor on a large-scale action recognition dataset eliminates the need for target-domain DNN training during anomaly detection. The pretraining phase learns general skeleton representations that are frozen during the target-domain training phase, allowing the model to model normal sample distributions using only these frozen features.

### Mechanism 2
Incorporating user-provided text prompts into the anomaly score reduces false positives for unobserved normal actions. The model computes a similarity score between skeleton features and text embeddings of abnormal actions, combining this with the OoD score to shift the decision boundary.

### Mechanism 3
A permutation-invariant architecture with sparse feature propagation between joints improves robustness to skeleton detection errors. The architecture processes skeleton sequences as unordered point clouds, using max-pooling to aggregate features across joints.

  - Quick check question: How does the Mahalanobis distance account for correlations between different feature dimensions when computing anomaly scores?

  - Why needed here: The pretraining phase uses contrastive learning to align skeleton features with text embeddings of action classes, enabling zero-shot recognition of unseen actions
  - Quick check question: What is the role of the temperature parameter τ in the contrastive loss formulation?

- **Permutation invariance in neural networks**
  - Why needed here: The skeleton feature extractor must handle unordered joint sequences, requiring permutation-invariant operations like max-pooling
  - Quick check question: Why is max-pooling a suitable operation for achieving permutation invariance in the skeleton feature extractor?

## Architecture Onboarding

- **Component map**: Input video -> Pose estimation -> Skeleton feature extraction -> OoD score calculation -> Prompt-guided action score calculation -> Anomaly score combination -> Classification
- **Critical path**: Input video → Pose estimation → Skeleton feature extraction → OoD score calculation → Prompt-guided action score calculation → Anomaly score combination → Classification
- **Design tradeoffs**: Using frozen pretrained features eliminates domain-specific training but may limit adaptation to specific domains; permutation-invariant architecture handles skeleton errors but may lose some spatial relationship information; text prompt integration enables zero-shot learning but requires high-quality prompts
- **Failure signatures**: High false positive rate (OoD score threshold too low or text prompts not specific enough); high false negative rate (OoD score threshold too high or skeleton feature extractor not capturing relevant motion patterns); inconsistent performance across domains (Pretraining dataset not representative of target domains)
- **First 3 experiments**: 1) Test OoD score alone on a dataset with known normal samples to verify Gaussian modeling; 2) Test prompt-guided action score alone with text prompts to verify zero-shot capability; 3) Combine both scores and test on datasets with unobserved normal actions to verify prompt-guided boundary shifting

## Open Questions the Paper Calls Out

- **Open Question 1**: How does the proposed method's performance scale when applied to larger, more diverse datasets with more complex actions?

  - Why unresolved: The current experiments were conducted on relatively small datasets (RWF-2000 and Kinetics-250)
  - What evidence would resolve it: Conducting experiments on larger datasets such as Kinetics-400 or Something-Something V2

- **Open Question 2**: How does the quality of user-provided text prompts impact the method's performance, and can the method be improved to handle poorly specified or ambiguous prompts?
  - Basis in paper: [explicit] The paper discusses the importance of text prompt quality and mentions the potential for using learnable prompts instead of hand-crafted ones to improve performance
  - Why unresolved: The current experiments use carefully crafted text prompts
  - What evidence would resolve it: Testing the method with a range of prompt qualities, from well-defined to ambiguous

- **Open Question 3**: How does the proposed method handle the detection of abnormal actions in multi-person scenarios, where interactions between individuals may be complex?
  - Basis in paper: [inferred] The paper focuses on single-person skeleton-based action recognition and does not explicitly address multi-person scenarios
  - Why unresolved: The current experiments are conducted on datasets that primarily involve single-person actions
  - What evidence would resolve it: Conducting experiments on datasets that include multi-person interactions, such as NTU RGB+D or SBU Kinect Interaction

## Limitations

- Limited experimental validation across diverse domains to support zero-shot generalization claims
- Qualitative demonstration of skeleton error robustness without quantitative error analysis
- Assumption of high-quality, domain-relevant text prompts without exploring prompt sensitivity

## Confidence

- **High Confidence**: Core architectural design and basic anomaly detection framework
- **Medium Confidence**: Zero-shot learning capability through text prompt integration
- **Low Confidence**: Claims of state-of-the-art performance without target-domain training
