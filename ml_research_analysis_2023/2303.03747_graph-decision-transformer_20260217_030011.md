# Graph Decision Transformer

## Quick Facts
- arXiv ID: 2303.03747
- Source URL: https://arxiv.org/abs/2303.03747
- Reference count: 40
- Primary result: Graph Decision Transformer outperforms state-of-the-art offline RL methods on image-based Atari and OpenAI Gym tasks

## Executive Summary
Graph Decision Transformer (GDT) introduces a novel offline reinforcement learning approach that transforms input sequences into causal graphs to capture dependencies between fundamentally different concepts and facilitate temporal and causal relationship learning. The approach leverages graph transformers to process these graph structures while maintaining an optional sequence transformer for handling fine-grained spatial information in visual tasks. GDT demonstrates state-of-the-art performance on image-based Atari and OpenAI Gym environments.

## Method Summary
GDT converts input sequences into causal graph structures to capture dependencies between different concepts and time steps. A graph transformer processes these graph inputs with relation-enhanced mechanisms, while an optional sequence transformer handles spatial information for visual tasks. This dual approach allows the model to effectively learn temporal and causal relationships in the input data, making it particularly well-suited for reinforcement learning tasks where understanding sequential dependencies is crucial.

## Key Results
- Outperforms state-of-the-art offline RL methods on image-based Atari environments
- Achieves superior performance on OpenAI Gym tasks compared to existing approaches
- Effectively captures temporal and causal relationships through graph-based representation

## Why This Works (Mechanism)
The graph transformation approach enables GDT to explicitly model relationships between different time steps and concepts in the input sequence. By converting sequences into causal graphs, the model can leverage graph neural network architectures to learn complex dependencies that traditional sequence models might miss. The relation-enhanced mechanisms in the graph transformer further strengthen the model's ability to understand interactions between different elements, while the optional sequence transformer preserves spatial information when needed.
