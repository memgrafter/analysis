# Trusting Your Evidence: Hallucinate Less with Context-aware Decoding

## Quick Facts
- arXiv ID: 2305.14739
- Source URL: https://arxiv.org/abs/2305.14739
- Reference count: 12
- Primary result: Context-aware decoding improves faithfulness metrics by up to 14.3% on LLaMA for summarization tasks

## Executive Summary
Context-aware decoding (CAD) addresses language model hallucination by amplifying the difference between output probabilities when models are used with and without context. The method achieves this through a contrastive output distribution that factors out prior knowledge from the model's original output distribution using pointwise mutual information. CAD is particularly effective at overriding model prior knowledge when it contradicts provided context, leading to substantial improvements in factuality metrics across multiple models including OPT, GPT, LLaMA, and FLAN-T5.

## Method Summary
CAD modifies the language model's output distribution during decoding by sampling from an adjusted probability distribution that emphasizes context-consistent outputs while downweighting prior knowledge. The method computes a contrastive adjustment using the difference between context-aware and context-free logits, weighted by hyperparameter α. This creates a new output distribution that effectively "factors out" the model's prior knowledge when contextual information is available, encouraging the model to attend more to the provided context during generation.

## Key Results
- CAD achieves 14.3% gain in factuality metrics (FactKB) for LLaMA-30B on CNN-DM summarization
- Improves Exact Match scores on knowledge conflict tasks: 5.6% for LLaMA-30B on MemoTrap
- Performance gains increase with model size in knowledge conflict tasks
- Outperforms baseline decoding methods across multiple models and datasets

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Contrastive output distribution amplifies the difference between probabilities when a model is used with and without context, encouraging the model to attend more to the context during generation.
- Mechanism: The method creates a new output distribution by sampling from a pointwise mutual information (PMI) adjustment that factors out the prior knowledge from the model's original output distribution. This effectively downweights the influence of prior knowledge when contextual information is available.
- Core assumption: The model's prior knowledge (learned during pretraining) can conflict with context knowledge, and this conflict leads to hallucination. By amplifying differences between context-aware and context-free predictions, we can shift the balance toward using context.
- Evidence anchors:

  - [section] "we factor out the prior knowledge from the model's original output distribution contrastively" and "This provides a new form of contrastive decoding (Li et al., 2022), which effectively downweights the prior knowledge when more relevant contextual information is provided."

### Mechanism 2
- Claim: The adjustment formula using PMI and α parameter effectively reweights token probabilities to favor context-consistent outputs.
- Mechanism: The method computes softmax[(1 + α)logitθ(yt ∣ c, x, y<t) − α logitθ(yt ∣ x, y<t)], where the first term represents context-aware probability and the second term represents prior knowledge. By adjusting α, we control how strongly to demote prior knowledge.
- Core assumption: The difference between context-aware and context-free logits contains signal about which outputs are more contextually appropriate versus prior-knowledge-driven.
- Evidence anchors:
  - [section] "By rearranging the terms, we obtain the final form: yt ~ softmax[(1 + α)logitθ(yt ∣ c, x, y<t) − α logitθ(yt ∣ x, y<t)]"
  - [section] "Larger α means more weight on our adjustment (α = 0 reduces to regular decoding)"
  - [corpus] Weak evidence - no citations to this specific formulation, suggesting this may be novel

### Mechanism 3
- Claim: Context-aware decoding is particularly effective when the context knowledge contradicts the model's prior knowledge, leading to substantial improvements in knowledge conflict tasks.
- Mechanism: In scenarios where the context provides information that contradicts what the model has learned during pretraining, CAD's contrastive approach helps the model override its prior knowledge and generate outputs consistent with the context.
- Core assumption: Language models have strong prior knowledge that can persist even when contradictory context is provided, and this conflict is a major source of hallucination.
- Evidence anchors:

  - [section] "CAD is especially beneficial for knowledge conflicting tasks, where the context contains information contradictory to the model's prior knowledge."

## Architecture Onboarding

- Component map: Pretrained language model θ → Context-aware decoding module → Sampling strategy → Output tokens
- Critical path: Input context → Language model logits (with context) → Language model logits (without context) → PMI adjustment with α parameter → Adjusted logits → Sampling strategy → Output tokens
- Design tradeoffs: Higher α values give more weight to context but risk ignoring useful prior knowledge; lower α values maintain more of the original model behavior but may not sufficiently address hallucination. The method adds computational overhead during decoding since it requires computing logits twice (with and without context).
- Failure signatures: Performance degradation on tasks where prior knowledge is correct and context is misleading; minimal improvement on tasks without knowledge conflicts; increased computational cost during inference.
- First 3 experiments:
  1. Run the base model with regular decoding on a knowledge conflict dataset (like MemoTrap) to establish baseline hallucination rate.
  2. Apply CAD with α = 0.5 on the same dataset and measure improvement in factuality metrics.
  3. Vary α values (0.1, 0.5, 1.0, 2.0) on a subset of data to find the optimal balance between context adherence and maintaining useful prior knowledge.

## Limitations

- The method's effectiveness depends heavily on the assumption that provided context is reliable and contradicts prior knowledge
- Optimal α values vary significantly between task types, requiring careful hyperparameter tuning
- The approach adds computational overhead during inference by requiring double computation of logits
- Limited external validation of the specific PMI-based contrastive formulation

## Confidence

- **High Confidence:** The general approach of using contrastive decoding to reduce hallucination is well-established, and the experimental results show consistent improvements across multiple models and datasets.
- **Medium Confidence:** The specific PMI-based adjustment formula and the claim that it effectively factors out prior knowledge are supported by the paper's analysis but lack external validation.
- **Low Confidence:** The mechanism's effectiveness in knowledge conflict scenarios relies heavily on the assumption that context contradictions are the primary source of hallucination, which may not hold for all models or domains.
