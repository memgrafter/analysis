# PyRCA: A Library for Metric-based Root Cause Analysis

## Quick Facts
- arXiv ID: 2306.11417
- Source URL: https://arxiv.org/abs/2306.11417
- Reference count: 5
- Primary result: Open-source Python library providing unified framework for automated root cause analysis in AIOps with interactive GUI

## Executive Summary
PyRCA is an open-source Python library designed to automate root cause analysis in AIOps environments. It provides a comprehensive framework for identifying the underlying causes of system incidents by analyzing complex metric dependencies. The library offers both a unified programmatic interface and an interactive GUI dashboard, making it accessible to both developers and domain experts. PyRCA integrates multiple causal discovery methods and root cause scoring algorithms, supporting a wide range of AIOps applications.

## Method Summary
PyRCA implements a holistic approach to root cause analysis by combining causal graph construction with root cause scoring. The library provides multiple algorithms for both tasks, allowing users to select appropriate methods based on their specific needs. For causal graph construction, it supports various causal discovery methods including constraint-based, score-based, and hybrid approaches. For root cause scoring, it implements algorithms inspired by Bayesian analysis, graph analysis, and causal analysis. The library is designed as a unified framework where users can plug in different algorithms and customize their RCA pipeline through a consistent interface.

## Key Results
- Benchmark experiments on simulated data show hypothesis-testing algorithm achieves best RCA performance
- Two-phase models significantly outperform one-phase models when using a true causal graph
- Interactive GUI dashboard enables easy integration of expert knowledge and visualization of results

## Why This Works (Mechanism)
PyRCA works by systematically uncovering causal dependencies between metrics in AIOps environments and using these relationships to identify root causes of incidents. The library's effectiveness stems from its ability to construct causal graphs that represent metric dependencies and then apply scoring algorithms that leverage these graphs to rank potential root causes. The unified framework approach allows for combining multiple causal discovery and scoring methods, enabling users to select the most appropriate algorithms for their specific scenarios.

## Architecture Onboarding
- **Component Map**: User Interface -> GUI Dashboard/Unified API -> Causal Graph Construction -> Root Cause Scoring -> Results Visualization
- **Critical Path**: Data input -> Causal graph construction -> Root cause scoring -> Result presentation
- **Design Tradeoffs**: Flexibility vs. complexity (supporting multiple algorithms while maintaining usability), simulation-based vs. real-world evaluation, GUI accessibility vs. programmatic control
- **Failure Signatures**: Poor causal graph construction leading to incorrect root cause identification, algorithm selection mismatch with data characteristics, GUI integration issues preventing expert knowledge incorporation
