# MetaVL: Transferring In-Context Learning Ability From Language Models to Vision-Language Models

## Quick Facts
- arXiv ID: 2306.01311
- Source URL: https://arxiv.org/abs/2306.01311
- Reference count: 5
- Key outcome: Transfers in-context learning from language models to vision-language models, achieving competitive performance with 20x fewer parameters

## Executive Summary
This paper introduces MetaVL, a novel approach for transferring in-context learning ability from language models to vision-language models. The method leverages meta-training of a language model on NLP tasks, then attaches a visual encoder to create a vision-language model. By freezing the language backbone and training visual components, MetaVL achieves strong few-shot performance on VQA, OK-VQA, and GQA tasks while using significantly fewer parameters than baseline models.

## Method Summary
MetaVL works by first meta-training a language model on diverse NLP tasks using an in-context learning setup (MetaICL). The meta-trained GPT2-Medium backbone is then frozen and transferred to VL tasks by attaching a visual encoder (CLIP-RN50x16) and visual prefix module. The visual prefix maps extracted visual features into the language embedding space, enabling the frozen language model to process multimodal inputs. Training proceeds with a Prefix Language Modeling objective on image-text pairs from COCO, preserving the language model's in-context learning capability while adapting to visual inputs.

## Key Results
- MetaVL outperforms baseline models on VQA, OK-VQA, and GQA tasks while using approximately 20 times fewer parameters
- Achieves competitive in-context learning performance with only 0-3 training examples per sample
- Demonstrates effective transfer of in-context learning from language to vision-language domains

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MetaVL transfers in-context learning ability from language to vision-language domains by leveraging a meta-trained language model as a frozen encoder-decoder backbone
- Mechanism: The meta-trained language model is first trained on diverse NLP tasks in an in-context learning setup (MetaICL), then transferred to VL tasks by attaching a visual encoder and visual prefix module. The frozen language model preserves its in-context learning capability while the visual components are trained to map visual features into the language embedding space
- Core assumption: In-context learning ability learned in the language domain can be effectively transferred to the vision-language domain without significant degradation
- Evidence anchors:
  - [abstract]: "we first meta-trains a language model to perform in-context learning on NLP tasks (as in MetaICL); then we transfer this model to perform VL tasks by attaching a visual encoder"
  - [section 3]: "The meta-trained language encoder-decoder is used as the LM backbone and is frozen during the VL training process so the meta-trained language model preserves its few-shot capabilities"
  - [corpus]: Found 25 related papers but average citations=0.0, indicating this is a novel approach with limited direct comparison in literature
- Break condition: If the visual features cannot be effectively mapped to the language embedding space, or if the meta-trained language model's in-context learning ability does not generalize to VL tasks

### Mechanism 2
- Claim: MetaVL achieves strong few-shot performance with a much smaller model size compared to baseline models
- Mechanism: By leveraging the meta-trained language model's in-context learning ability and effectively mapping visual features to language embeddings, MetaVL can perform well on VL tasks without requiring the extremely large model sizes typical of current VL models
- Core assumption: The in-context learning ability transferred from the language domain is sufficient to compensate for the reduced model size in VL tasks
- Evidence anchors:
  - [abstract]: "MetaVL could outperform the baseline model while having ~20 times fewer parameters"
  - [section 4.3]: "MetaVL surpasses the baseline model's performance, even when MetaVL is designed to be 20 times smaller in size"
  - [corpus]: Limited direct evidence, but related work (Frozen, MAGMA) suggests larger models generally perform better, making MetaVL's performance with fewer parameters notable
- Break condition: If the reduced model size significantly impacts the ability to learn complex VL relationships, or if the in-context learning ability cannot compensate for the parameter reduction

### Mechanism 3
- Claim: The visual prefix module effectively maps visual features to language embedding space while preserving the meta-trained language model's capabilities
- Mechanism: The visual prefix module projects the visual features extracted by the visual encoder into the same embedding space as the language tokens, allowing the frozen meta-trained language model to process both modalities coherently
- Core assumption: The visual prefix module can learn an effective mapping from visual to language embeddings without disrupting the language model's pre-learned in-context learning ability
- Evidence anchors:
  - [section 3]: "The visual encoder is defined as a function Ve(x) that takes an image of x and outputs visual features... The visual encoder is followed by the visual prefix module that is defined as Vp(x) ∈ Dv × Dl which maps the visual features to language embedding space"

- Break condition: If the visual prefix module fails to learn an effective mapping, or if training it disrupts the frozen language model's parameters

## Architecture Onboarding

- Component map: Visual encoder (CLIP-RN50x16) → Visual prefix (MLP layer) → Frozen language encoder-decoder → Language decoder
- Critical path: Visual encoder → Visual prefix → Frozen language encoder-decoder → Language decoder
- Design tradeoffs:
  - Freezing the language model preserves in-context learning ability but limits fine-tuning
  - Using a smaller language model (375M vs 7B) reduces computational cost but may limit capacity
  - The visual prefix module adds complexity but enables effective visual-language alignment
- Failure signatures:
  - Poor in-context learning performance indicates issues with meta-training or transfer
  - Visual-language misalignment suggests problems with the visual prefix module
  - Overfitting to training data may indicate insufficient regularization or too much fine-tuning
- First 3 experiments:
  1. Evaluate MetaVL's zero-shot performance on VQA to assess baseline capability without in-context examples
  2. Test MetaVL with varying numbers of shots (0-3) on VQA to measure in-context learning effectiveness
  3. Compare MetaVL's performance with and without the visual prefix module to validate its importance

## Open Questions the Paper Calls Out

1. How does the in-context learning performance of MetaVL scale with the size of the language model backbone?
   - Basis in paper: [explicit] The paper states "Due to computational limitations, we experiment with only a moderate-sized LM. It is unclear the performance of our method after scaling up"
   - Why unresolved: The paper only tested MetaVL with a GPT2-Medium sized language model due to computational constraints. It's unknown how much larger language models would improve the in-context learning performance
   - What evidence would resolve it: Testing MetaVL with increasingly larger language models (e.g., GPT-J 6B, GPT-3) and measuring the change in in-context learning performance on VQA, OK-VQA, and GQA tasks

2. Can MetaVL's in-context learning ability generalize to other vision-language tasks beyond VQA?
   - Basis in paper: [explicit] The paper notes "We considered only the VQA task, which is limited in scope. It is unclear whether our method generalizes to other VL tasks"
   - Why unresolved: The paper only evaluated MetaVL on VQA, OK-VQA, and GQA datasets. It's unclear if the meta-trained language model backbone can effectively transfer in-context learning to other VL tasks like image captioning or visual reasoning
   - What evidence would resolve it: Testing MetaVL on a diverse set of vision-language tasks (e.g., image captioning, visual reasoning, visual entailment) and measuring its in-context learning performance compared to baselines

3. What is the optimal ratio of visual features to text tokens in the prefix language modeling objective?
   - Basis in paper: [inferred] The paper describes the visual prefix module mapping visual features to language embedding space, but doesn't explore the impact of different ratios of visual to text tokens on performance
   - Why unresolved: The paper uses a fixed visual prefix module without exploring how the ratio of visual to text tokens affects the in-context learning performance. Different tasks may benefit from different ratios
   - What evidence would resolve it: Conducting ablation studies with MetaVL using different ratios of visual to text tokens in the prefix language modeling objective and measuring the impact on in-context learning performance across VQA, OK-VQA, and GQA tasks

## Limitations

- Limited evaluation to VQA, OK-VQA, and GQA tasks raises questions about generalizability to other vision-language tasks
- Computational constraints prevented testing with larger language model backbones, leaving scalability questions unanswered
- Reliance on pre-trained CLIP visual encoder and specific visual prefix architecture may limit generalizability to other visual backbones

## Confidence

- **High confidence**: The experimental results showing MetaVL's competitive performance on VQA, OK-VQA, and GQA tasks with significantly fewer parameters are well-supported by the presented data
- **Medium confidence**: The claim that in-context learning ability is effectively transferred from language to vision-language domains is supported by ablation studies and comparisons, but alternative explanations (such as improved pretraining or architectural innovations) cannot be fully ruled out
- **Low confidence**: The assertion that MetaVL achieves "strong few-shot performance" is relative and context-dependent. Without comprehensive comparisons to other few-shot VL methods or detailed analysis of failure cases, this claim remains tentative
