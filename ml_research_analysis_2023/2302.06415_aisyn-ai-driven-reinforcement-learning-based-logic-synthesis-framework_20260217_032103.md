# AISYN: AI-driven Reinforcement Learning-Based Logic Synthesis Framework

## Quick Facts
- arXiv ID: 2302.06415
- Source URL: https://arxiv.org/abs/2302.06415
- Reference count: 38
- Primary result: RL-guided AIG rewriting achieves up to 69.3% reduction in total cell area compared to classical methods

## Executive Summary
AISYN introduces a novel approach to logic synthesis that leverages reinforcement learning algorithms to guide the optimization process and escape local minima that plague classical synthesis algorithms. The framework formulates logic synthesis as a Markov Decision Process where an RL agent learns to make better decisions about AIG rewriting by interacting with the circuit representation. By combining local and global reward structures and using approximate state representations, AISYN achieves significant improvements in key quality of results metrics including area, node count, and edge count across benchmark circuits.

## Method Summary
AISYN modifies classical AIG rewriting algorithms by incorporating RL guidance to select better cuts during the rewriting process. The method formulates logic synthesis as an MDP where nodes represent approximate states and cuts represent actions. Two RL algorithms are employed: Q-learning with table-based Q-value updates and A3C with neural network function approximation. The framework uses both local rewards (immediate node count changes) and global rewards (post-mapping circuit metrics) to train the RL agent, with careful normalization to ensure global rewards have larger magnitudes. Node embeddings can be generated using GCN or node2vec for the A3C implementation.

## Key Results
- Q-learning-based rewriting (Q-drw) achieved up to 69.3% reduction in total cell area compared to classical rewriting
- A3C-based rewriting (A3C-drw) achieved up to 64.9% reduction in total cell area
- When applied to an industrial benchmark circuit, AISYN achieved 1% reduction in total power consumption post-route
- Both RL-based approaches significantly outperformed the classical AIG rewriting baseline across all tested metrics

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Reinforcement learning algorithms can guide logic synthesis optimization functions to escape local minima.
- Mechanism: By formulating logic synthesis as an MDP, the RL agent learns to make exploration-based decisions during AIG-rewriting, avoiding greedy traps that lead to suboptimal solutions.
- Core assumption: The reward function effectively captures long-term improvements in quality of results (QoR).
- Evidence anchors:
  - [abstract] "We believe that Artificial Intelligence (AI) and more specifically Reinforcement Learning (RL) algorithms can help in solving this problem. This is because AI and RL can help minimizing QoR further by exiting from local minima."
  - [section IV] "In this paper, we will show that how adding RL smartness to classical logic synthesis optimization functions can result in significant improvements in QoR."
  - [corpus] Weak evidence - related papers focus on different RL approaches but don't directly validate the local minima escape claim for AISYN specifically.

### Mechanism 2
- Claim: Using approximate state representations (nodes as states) makes the RL problem tractable while preserving solution quality.
- Mechanism: Instead of representing all possible AIG configurations as states, each node serves as an approximate state, allowing the agent to learn cut-selection policies without exploding the state space.
- Core assumption: The approximate state representation maintains sufficient information for the agent to learn effective cut-selection strategies.
- Evidence anchors:
  - [section IV-B] "In our Q-learning-based rewriting algorithm, we resort to using an approximate representation for the state of the system. In our Q-learning-based rewriting algorithm...nodes are used to represent approximate states."
  - [section IV-B] "Using the said approximate model the Q-agent will always end up at node vj when it takes an action being at node vi, therefore, its state will always go from i to j."
  - [corpus] Moderate evidence - related papers mention graph neural networks and node embeddings but don't directly validate the specific approximation strategy used in AISYN.

### Mechanism 3
- Claim: Combining local and global rewards accelerates learning and improves convergence.
- Mechanism: Local rewards provide immediate feedback for cut selections while global rewards (based on final post-synthesis metrics) guide long-term optimization, with global rewards having significantly larger magnitudes.
- Core assumption: The magnitude difference between local and global rewards helps the agent prioritize long-term optimization over short-term gains.
- Evidence anchors:
  - [section IV-B] "Our experiments show that if magnitudes of global rewards are much larger than the local ones, it will help the Q-agent to learn better and converge faster."
  - [section IV-B] "For this purpose, we always choose values for the normalization factors such that they satisfy the following: K′1 >> K1 and K′2 >> K2."
  - [corpus] Weak evidence - while the reward structure is described, there's no direct comparison showing how different reward magnitudes affect learning speed or quality.

## Architecture Onboarding

- Component map: Input Circuit -> AIG Conversion -> RL Engine -> Rewriting Module -> Technology Mapper -> Output Circuit
- Critical path:
  1. Convert input circuit to AIG format
  2. Generate node embeddings (A3C only)
  3. RL agent traverses AIG nodes in topological order
  4. At each node, agent selects cut based on learned policy
  5. Perform AIG rewriting with selected cut
  6. After full traversal, perform technology mapping
  7. Calculate global reward based on post-mapping metrics
  8. Update RL agent parameters (weights for neural networks, Q-values for table-based)

- Design tradeoffs:
  - Table-based Q-learning vs neural network-based A3C: Tables are simpler but don't scale well; neural networks generalize better but require more tuning
  - Node approximation vs full state representation: Approximation makes the problem tractable but may lose information
  - Local vs global reward scaling: Must balance immediate feedback with long-term optimization goals

- Failure signatures:
  - No improvement over baseline: Check reward function design and normalization factors
  - Poor convergence: Verify learning rate, exploration parameters, and reward scaling
  - Degraded QoR: Examine cut selection patterns and ensure RL agent is learning meaningful policies

- First 3 experiments:
  1. Run baseline comparison: Implement classical AIG-rewriting (drw) + map and measure total cell area, node count, and edge count
  2. Test Q-learning implementation: Run Q-drw + map on small benchmark circuits (c432, c880) and compare to baseline, monitoring learning curves
  3. Evaluate A3C implementation: Run A3C-drw + map on same benchmarks, comparing performance and training stability to Q-drw results

## Limitations

- The evaluation uses a limited set of benchmark circuits from the ISCAS-85 suite and one industrial design, lacking statistical significance testing and broader generalization studies
- The approximate state representation using nodes instead of full AIG configurations may lose critical information, but empirical evidence about the information loss is not provided
- Exact hyperparameters for reward normalization factors and A3C neural network architecture are not fully specified, making faithful reproduction challenging

## Confidence

**High confidence** in the mechanism showing RL can escape local minima - the theoretical foundation is sound and the approach of using exploration-based policies is well-established in reinforcement learning literature. The problem formulation as an MDP is standard practice.

**Medium confidence** in the specific reward structure and normalization factors - while the general concept of combining local and global rewards is reasonable, the exact scaling factors are presented as ranges rather than precise values, and there's limited experimental validation showing how different scalings affect learning.

**Medium confidence** in the node approximation approach - the paper provides a clear description of the approximation strategy, but doesn't provide comparative results showing how this approximation performs against alternative state representations or against the theoretical baseline of using full AIG states.

## Next Checks

1. **Statistical validation**: Perform t-tests or ANOVA on QoR metrics across multiple runs to establish statistical significance of the reported improvements, particularly for the industrial benchmark where only one data point is provided.

2. **Generalization testing**: Apply AISYN to a broader set of benchmark circuits including larger industrial designs and different circuit families (arithmetic circuits, control logic, memory blocks) to assess how well the learned policies transfer across circuit types.

3. **Ablation study on state representation**: Compare the node-based approximation against alternative state representations such as graph embeddings or full AIG states on a subset of benchmarks to quantify the information loss and identify if more sophisticated representations could yield additional improvements.
