# IKD+: Reliable Low Complexity Deep Models For Retinopathy Classification

## Quick Facts
- arXiv ID: 2303.02310

## Executive Summary
This paper proposes IKD+ (Iterative Knowledge Distillation+), a method for compressing deep learning models for retinopathy classification while maintaining accuracy and improving reliability. IKD+ uses iterative knowledge distillation with calibration-sensitive loss functions to transfer knowledge from a large teacher model (ensemble of EfficientNets) to progressively simpler student models. Evaluated on a multi-disease retinopathy dataset, IKD+ achieves significant compression ratios while producing more reliable models than standard IKD approaches.

## Method Summary
IKD+ compresses deep neural networks for retinopathy classification through iterative knowledge distillation with calibration-aware loss functions. The method starts with an ensemble of EfficientNets as the teacher model and progressively creates simpler student models through a refinement operator that reduces architectural complexity. The key innovation is incorporating Expected Calibration Error (ECE) into the knowledge distillation loss using temperature-scaling or Platt-scaling, which explicitly optimizes for model reliability alongside accuracy. The training procedure uses Adam optimizer with batch size 16 and learning rate 1e-4, with data augmentation to address class imbalance in the retinal fundus dataset.

## Key Results
- Achieves up to 500× compression compared to state-of-the-art ensemble models
- Maintains ~90% accuracy even at high compression levels
- Produces models with lower Expected Calibration Error than standard IKD methods
- Temperature-scaling performs better than Platt-scaling for model calibration

## Why This Works (Mechanism)

### Mechanism 1
- Claim: IKD+ improves reliability by incorporating Expected Calibration Error (ECE) into the knowledge distillation loss function
- Mechanism: The loss function is modified to include either temperature-scaling or Platt-scaling terms that explicitly penalize poorly calibrated predictions. This encourages the student model to produce probability distributions that better match the teacher's calibrated outputs
- Core assumption: Including calibration-aware loss terms during distillation will result in a student model with better-calibrated probability estimates than standard IKD
- Evidence anchors:
  - [abstract] "We investigate the functioning of IKD+ using two widely used techniques for estimating model calibration (Platt-scaling and temperature-scaling)"

  - [corpus] Weak evidence - corpus papers focus on diabetic retinopathy detection but don't specifically discuss IKD+ or calibration-aware distillation methods
- Break condition: If the calibration terms in the loss function dominate the accuracy optimization, leading to poor classification performance despite good calibration

### Mechanism 2
- Claim: Iterative knowledge distillation progressively compresses the model while maintaining accuracy
- Mechanism: The IKD+ procedure iteratively applies a refinement operator that reduces model complexity (fewer features and filters) while transferring knowledge from the previous student model to the next simpler one, using the calibration-aware loss function
- Core assumption: Each successive student model can effectively learn from the previous student's knowledge, even as model complexity decreases
- Evidence anchors:
  - [section] "We consider a model M as a pair of (σ, π), where σ denotes the model's structure... Knowledge distillation can be considered a function KD that finds πj s.t."
  - [section] "We assume a refinement operator ρ that is applied to a structure of the deep network, which results in a new and typically simpler structure"
  - [corpus] No direct evidence - corpus papers don't discuss iterative knowledge distillation or progressive model compression
- Break condition: If accuracy degradation becomes unacceptable at some compression level, indicating the knowledge transfer chain is breaking down

### Mechanism 3
- Claim: Temperature-scaling performs better than Platt-scaling for model calibration in this retinopathy classification task
- Mechanism: Temperature-scaling adjusts the logits by a learned temperature parameter, which smooths the probability distribution and improves calibration, while Platt-scaling fits a logistic regression model to the logits
- Core assumption: The smooth probability adjustment provided by temperature-scaling is more effective for this multi-class retinopathy classification problem than the logistic regression approach of Platt-scaling
- Evidence anchors:
  - [section] "Among the two calibration-sensitive Losses considered, the Temperature scaling performs better than Platt scaling"
  - [section] "The results from our experiments are reported in Tables 1 and 2. Among the two calibration-sensitive Losses considered, the Temperature scaling performs better than Platt scaling"
  - [corpus] No evidence - corpus papers don't compare temperature-scaling vs Platt-scaling for retinopathy classification
- Break condition: If different dataset characteristics or model architectures make Platt-scaling more effective, the superiority of temperature-scaling would not generalize

## Architecture Onboarding

- Component map:
  Teacher model (EfficientNet-B6 ensemble) -> Calibration-sensitive loss (temperature-scaling/Platt-scaling) -> Student model refinement (50% feature/filter reduction) -> Adam optimizer (lr=1e-4, batch size=16)

- Critical path:
  1. Load pre-trained teacher model
  2. Initialize first student model with simplified architecture
  3. Train student using calibration-sensitive loss against teacher
  4. Apply refinement operator to create next student model
  5. Repeat training and refinement for desired number of iterations

- Design tradeoffs:
  - Compression vs accuracy: Higher compression leads to lower accuracy
  - Calibration strength vs accuracy: Stronger calibration focus may reduce accuracy
  - Teacher complexity vs student capacity: Complex teachers may be harder for simple students to learn from

- Failure signatures:
  - Accuracy drops sharply after few iterations (knowledge transfer failing)
  - ECE increases during training (calibration loss not effective)
  - Training instability with very small student models
  - Overfitting to calibration metrics at expense of classification performance

- First 3 experiments:
  1. Compare IKD+ with temperature-scaling against standard IKD on the first iteration only to isolate the calibration effect
  2. Test different refinement rates (25%, 50%, 75%) to find optimal compression per iteration
  3. Evaluate IKD+ with EfficientNet-B5 as teacher to verify results aren't specific to B6 architecture
