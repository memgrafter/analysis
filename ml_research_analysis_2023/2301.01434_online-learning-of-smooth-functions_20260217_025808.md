# Online Learning of Smooth Functions

## Quick Facts
- arXiv ID: 2301.01434
- Source URL: https://arxiv.org/abs/2301.01434
- Authors: 
- Reference count: 14
- One-line primary result: Proves sharp bounds on online learning of smooth functions with bounded derivative norms

## Executive Summary
This paper establishes fundamental bounds on online learning of smooth real-valued functions where the target function belongs to classes with bounded derivative norms. The authors analyze classes F_q of absolutely continuous functions with bounded q-norm of derivative, and their multi-variable extensions F_{q,d}. They prove new bounds showing opt_{1+ε}(F_∞) = Θ(ε^{-1/2}) and resolve several open questions about the optimal prediction error in online learning scenarios.

## Method Summary
The paper uses theoretical analysis to establish bounds on online learning of smooth functions. The main approach involves proving upper and lower bounds on opt_p(F), which measures the best worst-case bound on the sum of p-th powers of prediction errors. Key algorithms include LININT, which constructs piecewise linear approximations of the target function through revealed points. The analysis leverages smoothness constraints, Holder's inequality, and careful tracking of accumulated prediction error across trials.

## Key Results
- opt_{1+ε}(F_∞) = Θ(ε^{-1/2}) and opt_{1+ε}(F_q) = Θ(ε^{-1/2}) for q≥2
- opt_2(F_{1+ε}) = Θ(ε^{-1}) for ε∈(0,1)
- opt_p(F_q)=1 for q∈(1,2) and p≥2+1/(q-1)
- opt_p(F_{∞,d}) is infinite when p<d and finite when p>d

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The algorithm achieves sharp bounds by exploiting the smoothness constraint through adaptive sampling and piecewise linear interpolation.
- Mechanism: LININT constructs piecewise linear approximations of the target function by linearly interpolating between observed points. The smoothness constraint (bounded derivative norms) ensures that errors remain bounded between sampled points.
- Core assumption: The target function is absolutely continuous with bounded q-norm of derivative, ensuring that piecewise linear interpolation provides a good approximation.
- Evidence anchors:
  - [abstract]: "For any class of real-valued functions F and p>0, let opt_p(F) be the best upper bound on the sum of pth powers of absolute prediction errors"
  - [section]: "By Jensen's inequality, F∞ ⊆ F q ⊆ F r for all q ≥ r ≥ 1"
- Break condition: If the function class F_q does not satisfy the smoothness constraints, or if the algorithm encounters discontinuous functions, the bounds no longer hold.

### Mechanism 2
- Claim: The adversary strategy for proving lower bounds exploits the smoothness constraint by forcing large prediction errors in regions of high curvature.
- Mechanism: The adversary chooses inputs strategically to maximize prediction errors, often by placing points where the function has high slope. For single-variable functions, this involves recursive construction of piecewise linear functions with bounded derivative norms but large prediction errors.
- Core assumption: The adversary can choose inputs after seeing previous predictions, allowing them to exploit the smoothness constraint.
- Evidence anchors:
  - [section]: "Consider the following family of adversary strategies, depending on a parameter b ∈ (0, 1)"
  - [section]: "To see that this strategy is well-defined, note that all the xi are distinct, so it suffices to show that there exists a function f ∈ Fq which is consistent with all (xi, f(xi))"
- Break condition: If the adversary is restricted to choosing all inputs in advance (non-adaptive), or if the smoothness constraint is violated, the lower bounds no longer apply.

### Mechanism 3
- Claim: Multi-variable generalization maintains bounds through decomposition into single-variable subproblems.
- Mechanism: The class Fq,d is defined such that any function obtained by fixing all but one parameter belongs to Fq. This allows decomposition of the multi-variable problem into single-variable subproblems, enabling the application of single-variable bounds.
- Core assumption: The multi-variable function class Fq,d preserves the smoothness properties of the single-variable class Fq when variables are fixed.
- Evidence anchors:
  - [abstract]: "For q ≥ 1 and d ∈ Z+, let Fq,d be the class of functions f : [0,1]^d → R such that any function g : [0,1] → R formed by fixing all but one parameter of f is in Fq"
  - [section]: "This allows us to decompose the multi-variable problem into single-variable subproblems"
- Break condition: If the multi-variable function class does not preserve the single-variable smoothness properties, or if the decomposition fails, the bounds no longer hold.

## Architecture Onboarding

- Component map:
  - Algorithm (LININT) -> Piecewise linear interpolation -> Error tracking -> Prediction output
  - Adversary -> Input selection -> Function generation -> Feedback to algorithm

- Critical path:
  1. Initialize algorithm with zero prediction
  2. Receive input and make prediction using piecewise linear interpolation
  3. Receive feedback and update piecewise linear approximation
  4. Track accumulated prediction error
  5. Repeat steps 2-4 for each trial

- Design tradeoffs:
  - Accuracy vs. computational complexity: More complex interpolation schemes may provide better accuracy but increase computational cost
  - Adaptivity vs. robustness: More adaptive algorithms may perform better in practice but are harder to analyze theoretically
  - Single-variable vs. multi-variable: Multi-variable generalization enables broader application but increases complexity

- Failure signatures:
  - Violation of smoothness constraints: Algorithm may fail if target function is not absolutely continuous
  - Non-adaptive adversary: Lower bounds may not apply if adversary cannot choose inputs adaptively
  - Numerical instability: Piecewise linear interpolation may suffer from numerical issues for certain functions

- First 3 experiments:

  2. Construct adversary strategy and verify lower bounds for single-variable case
  3. Extend algorithm to multi-variable case and test on synthetic functions satisfying Fq,d constraints

## Open Questions the Paper Calls Out

### Open Question 1
- Question: For q ∈ (1, 2) and p ∈ (1, 2) ∪ (2, 2 + 1/(q-1)), what is the exact value of opt_p(F_q)?
- Basis in paper: [explicit] The paper states that "the value of opt_p(F_q) is now bounded up to a constant factor for all p, q ≥ 1 except when q ∈ (1, 2) and p ∈ (1, 2) ∪ (2, 2 + 1/(q-1))".
- Why unresolved: The paper provides bounds but not exact values for this region of (p, q) values.
- What evidence would resolve it: A new algorithm or adversary strategy that establishes the exact value of opt_p(F_q) for this range of parameters.

### Open Question 2
- Question: Is opt_d(F_{∞,d}) finite for d > 1?
- Basis in paper: [explicit] The paper states "we showed that opt_p(F_{∞,d}) is infinite when 0 < p < d and finite when p > d, but it remains to determine whether opt_d(F_{∞,d}) is finite for d > 1".
- Why unresolved: The paper proves finiteness for p > d and infiniteness for p < d, but doesn't address the boundary case p = d.
- What evidence would resolve it: A proof showing either a finite bound for opt_d(F_{∞,d}) or an infinite lower bound for this case.

### Open Question 3
- Question: For all p > 1 and q > 1, is opt_p(F_q) finite?
- Basis in paper: [explicit] The paper states "Before this paper, it was only known that opt_2(F_q) is finite for p > 1 and q ≥ 2... With our new results, we now know that opt_p(F_q) is also finite when p ≥ 2 and q > 1. We make the following conjecture about this problem."
- Why unresolved: While the paper proves finiteness for p ≥ 2 and q > 1, the case p ∈ (1, 2) with q ∈ (1, ∞) remains open.
- What evidence would resolve it: Either a proof showing opt_p(F_q) is finite for all p > 1, q > 1, or a counterexample showing it is infinite for some p ∈ (1, 2) and q ∈ (1, ∞).

## Limitations

- The bounds are theoretical and may not translate directly to practical improvements in real-world online learning scenarios
- The analysis relies heavily on specific assumptions about smoothness constraints that may not hold for many real-world functions
- The paper focuses on worst-case bounds, which may be overly pessimistic compared to average-case performance
