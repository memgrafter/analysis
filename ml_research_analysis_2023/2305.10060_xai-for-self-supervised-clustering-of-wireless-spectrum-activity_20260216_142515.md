# XAI for Self-supervised Clustering of Wireless Spectrum Activity

## Quick Facts
- arXiv ID: 2305.10060
- Source URL: https://arxiv.org/abs/2305.10060
- Reference count: 16
- The paper proposes a methodology for explaining self-supervised deep learning clustering architectures used for wireless spectrum activity classification.

## Executive Summary
This paper introduces an explainability framework for self-supervised deep learning (SSDL) clustering architectures applied to wireless spectrum activity classification. The approach combines Guided Backpropagation for interpreting CNN-based feature learning with Shallow Trees for explaining K-means clustering outcomes, supplemented by spectrum-specific visualizations. The method successfully reveals the relationship between input spectrogram content, extracted features, and cluster assignments, enabling interpretable reasoning for SSDL models in wireless communications applications.

## Method Summary
The methodology employs a DeepCluster architecture with ResNet18 CNN for feature extraction from 128×128 pixel spectrograms of wireless spectrum measurements. PCA reduces the 512-dimensional CNN features to 20 dimensions while preserving 85% of explained variance. K-means clustering with 24 clusters groups similar transmissions, with iterative training using 15-epoch clustering cycles. Explainability is achieved through Guided Backpropagation for CNN interpretation, Shallow Tree building for clustering explanation, and spectrum-specific visualizations including average spectrograms and histograms.

## Key Results
- The CNN successfully focuses on relevant transmission bursts rather than noise, as revealed by Guided Backpropagation visualizations
- Shallow Trees provide interpretable mappings between PCA-transformed features and cluster assignments
- The framework enables identification of transmission patterns and their origins in the frequency band
- t-SNE embeddings show clear separation between clusters, validating the clustering approach

## Why This Works (Mechanism)

### Mechanism 1
Guided Backpropagation reveals which parts of the spectrogram the CNN uses to make classifications by calculating and altering backpropagation gradients so that only non-negative gradients are back-propagated. Positive gradients indicate features that contribute to the final prediction. This works because positive gradients correspond to features the CNN uses for classification decisions.

### Mechanism 2
PCA dimensionality reduction preserves the most relevant information for clustering while reducing complexity by transforming the original feature space into a new coordinate system ordered by explained variance ratio. Keeping the top N dimensions captures most of the variance in the data, which contains the relevant information for clustering. This works because dimensions with highest explained variance ratio contain the most relevant information for distinguishing between transmission patterns.

### Mechanism 3
Shallow decision trees provide interpretable explanations for clustering results by mapping feature importance to specific clusters. A decision tree is built using the PCA-transformed features and K-means clustering labels, with optimized depth to maintain explainability. This works because decision trees can accurately approximate the clustering decisions while providing interpretable feature importance information.

## Architecture Onboarding

- Component map: Data preprocessing -> Spectrogram generation -> CNN feature extraction -> PCA dimensionality reduction -> K-means clustering -> Explanation generation

- Critical path: Data acquisition and preprocessing → CNN feature extraction → PCA dimensionality reduction → K-means clustering → Explanation generation using XAI techniques

- Design tradeoffs: Window size (128) balances capturing complete transmissions vs. computational cost; Number of PCA dimensions (20) balances information preservation vs. explainability; Clustering cycle length (15 epochs) balances CNN adaptation vs. training efficiency

- Failure signatures: Poor clustering results despite good CNN features; Guided Backpropagation highlights irrelevant spectrogram regions; Shallow tree has high misclassification rate; t-SNE embeddings show poor separation between clusters

- First 3 experiments: 1) Verify PCA with 20 dimensions preserves clustering structure by comparing t-SNE embeddings before and after PCA; 2) Test Guided Backpropagation on sample spectrograms to confirm it highlights transmission bursts; 3) Build shallow tree with different maximum depths to find optimal balance between accuracy and explainability

## Open Questions the Paper Calls Out

### Open Question 1
How does the number of PCA dimensions (beyond the initial 20) affect the quality of clustering and explainability in SSDL architectures for wireless spectrum data? The paper uses 20 PCA dimensions based on explained variance ratio threshold (85%) and verifies this choice through t-SNE embeddings, but optimal dimensionality for different scenarios remains unexplored.

### Open Question 2
How do different clustering algorithms (e.g., DBSCAN, hierarchical clustering) compare to K-means in terms of performance and explainability when applied to PCA-transformed features in SSDL architectures for wireless spectrum data? The paper focuses on K-means and PCA without comparing to alternative clustering algorithms.

### Open Question 3
How do different CNN architectures (e.g., ResNet, VGG, Inception) affect the quality of feature extraction and subsequent clustering and explainability in SSDL architectures for wireless spectrum data? The paper uses ResNet18 but does not investigate how different CNN architectures might perform in this application.

## Limitations

- Shallow tree explanation may oversimplify complex clustering boundaries when depth optimization constraints prevent accurate representation
- Guided Backpropagation assumes positive gradients fully capture CNN decision-making, potentially missing nuanced feature interactions
- The methodology focuses on specific CNN architecture (ResNet18) and clustering algorithm (K-means) without exploring alternatives

## Confidence

- **High Confidence**: CNN successfully focuses on transmission bursts rather than noise, evidenced by Guided Backpropagation visualizations and cluster separation in t-SNE embeddings
- **Medium Confidence**: Shallow tree provides interpretable explanations for clustering, though accuracy may be compromised by depth optimization constraints
- **Medium Confidence**: PCA dimensionality reduction effectively preserves clustering-relevant information while improving explainability
