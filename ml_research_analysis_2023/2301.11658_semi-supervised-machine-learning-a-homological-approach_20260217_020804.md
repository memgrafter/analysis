# Semi-Supervised Machine Learning: a Homological Approach

## Quick Facts
- arXiv ID: 2301.11658
- Source URL: https://arxiv.org/abs/2301.11658
- Reference count: 6
- Primary result: Homological semi-supervised learning outperforms classical methods in 8/10 models tested, improving accuracy by up to 16% over baseline models trained only on labeled data

## Executive Summary
This paper introduces a novel semi-supervised machine learning method that leverages persistent homology from topological data analysis to classify unlabeled data points. The approach constructs Vietoris-Rips filtrations and computes persistence diagrams for labeled and unlabeled data, then uses bottleneck or Wasserstein distances to determine class membership based on minimal topological variation. The method addresses the challenge of annotating large amounts of unlabeled data by exploiting the assumption that data classes lie on distinct manifolds with unique topological signatures.

## Method Summary
The method works by comparing topological changes when adding unlabeled points to labeled classes using Vietoris-Rips filtrations and persistence diagrams. For each unlabeled point, the algorithm constructs filtrations for both labeled classes and each class with the point added, then computes the bottleneck or Wasserstein distance between persistence diagrams. The point is assigned to the class with minimal distance, unless both distances exceed a threshold, in which case it's labeled as "none." The approach is evaluated on 5 UCI datasets using SVM and Random Forest classifiers, showing consistent improvement over baseline models trained only on labeled data.

## Key Results
- Method outperforms classical semi-supervised techniques (Label Propagation, Label Spreading, Self Training) in 8 out of 10 models tested
- Accuracy improvements of up to 16% over baseline models trained only on labeled data
- Performance depends on threshold selection, with multiple threshold values tested (0.2, 0.4, 0.6, 0.8, 0.899)
- Both SVM and Random Forest classifiers show improved performance with homological annotation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The topological structure of data classes is preserved when unlabeled points are added, allowing class membership to be determined by minimal persistence diagram distance changes
- Mechanism: The method assumes each class lies on a manifold, and when an unlabeled point is added to the correct class, the resulting persistence diagram changes less than when added to the wrong class
- Core assumption: Class manifolds have distinct topological signatures that can be detected through Vietoris-Rips filtrations and persistence diagrams
- Evidence anchors: [abstract] - "we have used a homological approach that consists of studying the persistence diagrams associated with data from binary classification tasks using the bottleneck and Wasserstein distances"; [section] - "our hypothesis is that if a point belongs to X1, analogously for X2, then when adding the point to the manifold on which X1 lies, the topological variation will be minimal"
- Break condition: If class manifolds overlap significantly or have similar topological features, distance measurements will not distinguish between classes reliably

### Mechanism 2
- Claim: The bottleneck and Wasserstein distances between persistence diagrams effectively quantify topological similarity changes when adding unlabeled points
- Mechanism: These distances measure how much the topological features (connected components, loops, voids) change when an unlabeled point is added to either class's Vietoris-Rips filtration
- Core assumption: The chosen distance metrics are sensitive enough to detect meaningful topological differences between the two scenarios
- Evidence anchors: [section] - "we proceed as follows: (1) Construct the Vietoris-Rips filtrations VX1, VX2, VX1∪{x} and VX2∪{x}; (2) Construct the persistence diagrams P(VX1), P(VX2), P(VX1∪{x}) and P(VX2∪{x}); (3) Compute the distances d(P(VX1), P(VX1∪{x})) and d(P(VX2), P(VX2∪{x}))"; [abstract] - "The core approach computes bottleneck or Wasserstein distances between persistence diagrams to determine class membership"
- Break condition: If the distances are not discriminative enough due to noise or high-dimensional data, the method may assign incorrect class labels

### Mechanism 3
- Claim: The threshold-based classification rule effectively filters out points that don't clearly belong to either class
- Mechanism: Points where both topological distances exceed a threshold are classified as "none," preventing ambiguous assignments
- Core assumption: There exists a meaningful threshold that separates clearly classifiable points from ambiguous ones
- Evidence anchors: [section] - "If both d1 and d2 are greater than the threshold t, return none; otherwise, return the set associated with the minimum of the distances d1 and d2"; [abstract] - "The output produced by our algorithm is whether the point x belongs to X1, X2 or none of them"
- Break condition: If the threshold is set too high, many points will be classified as "none"; if too low, ambiguous points may be incorrectly assigned

## Architecture Onboarding

- Component map: Data preprocessing -> Vietoris-Rips filtration construction -> Persistence diagram computation -> Distance calculation -> Threshold comparison -> Classification
- Critical path: The bottleneck/Wasserstein distance computation between persistence diagrams is the computational bottleneck; persistence diagram calculation is the next most critical
- Design tradeoffs: Bottleneck distance is faster but less sensitive than Wasserstein distance; higher threshold values reduce false positives but increase false negatives
- Failure signatures: Consistently high distances for all points (threshold too high); incorrect classifications on datasets with overlapping manifolds; poor performance on non-manifold structured data
- First 3 experiments:
  1. Test on a synthetic dataset with clearly separated classes and known topological structures to verify the basic mechanism works
  2. Compare bottleneck vs Wasserstein distance performance on a simple binary classification task to determine which metric works better
  3. Perform threshold sensitivity analysis by varying threshold values and measuring classification accuracy to find optimal threshold settings

## Open Questions the Paper Calls Out

The paper does not explicitly call out open questions in the traditional sense, but several areas remain unexplored based on the limitations and experimental scope:

### Open Question 1
- Question: How does the performance of the homological semi-supervised learning method scale with increasing dataset size and dimensionality?
- Basis in paper: [inferred] The paper tests on 5 UCI datasets but does not explore scalability to larger datasets or high-dimensional data
- Why unresolved: The experiments only use structured datasets of moderate size, leaving scalability to larger datasets untested
- What evidence would resolve it: Systematic experiments comparing performance on datasets of increasing size (10^3, 10^4, 10^5+ samples) and dimensionality (100-10,000+ features) while measuring computational time and accuracy

### Open Question 2
- Question: How robust is the method to noise and outliers in the unlabeled data?
- Basis in paper: [inferred] The paper does not test performance on noisy datasets or explore sensitivity to outliers
- Why unresolved: The evaluation uses clean UCI datasets without adding noise or studying outlier effects
- What evidence would resolve it: Experiments with controlled noise injection at different levels (10%, 25%, 50%) and outlier percentages, comparing performance degradation against baseline methods

### Open Question 3
- Question: What is the optimal choice of filtration parameter (e.g., maximum distance threshold) for different types of data distributions?
- Basis in paper: [explicit] The authors test multiple threshold values (0.0, 0.2, 0.4, 0.6, 0.8, 0.899) but do not provide theoretical guidance on choosing thresholds
- Why unresolved: The paper presents empirical results with various thresholds but does not explain how to select the best threshold for new datasets
- What evidence would resolve it: Analysis of how different data distributions (spherical, elongated, multi-modal) correlate with optimal threshold values, potentially through visualization or statistical measures of data structure

## Limitations
- Threshold selection methodology is unclear, with five different threshold values tested but no explanation of how optimal thresholds were determined
- Computational complexity of Vietoris-Rips filtrations for high-dimensional data is not addressed, potentially limiting scalability
- Experimental validation is limited to only 5 UCI datasets, which may not generalize well to other domains

## Confidence
- **High Confidence**: The core mathematical framework using persistence diagrams and distance metrics is well-established in topological data analysis
- **Medium Confidence**: The experimental results showing 8/10 models outperforming baselines, though limited dataset diversity reduces generalizability
- **Low Confidence**: The threshold selection process and computational scalability claims lack sufficient detail for independent verification
