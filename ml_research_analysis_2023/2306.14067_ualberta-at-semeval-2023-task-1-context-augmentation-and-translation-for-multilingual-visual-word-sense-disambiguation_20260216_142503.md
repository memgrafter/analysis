# UAlberta at SemEval-2023 Task 1: Context Augmentation and Translation for Multilingual Visual Word Sense Disambiguation

## Quick Facts
- arXiv ID: 2306.14067
- Source URL: https://arxiv.org/abs/2306.14067
- Reference count: 16
- Key outcome: The TR+DEF system (combining translation and context augmentation) achieves 57.5% accuracy on the test set, with context augmentation being crucial for performance.

## Executive Summary
This paper presents the University of Alberta team's approach to the SemEval-2023 Visual Word Sense Disambiguation (V-WSD) task, which involves selecting the correct image that depicts the intended meaning of a focus word in a given context. The proposed method combines glosses from BabelNet with text and image encoders to rank candidate images based on their semantic similarity to a given context. The authors experiment with augmenting short contexts using a language model, translating non-English instances, and using language-specific models. Their best-performing system, TR+DEF, combines context augmentation with translation and achieves 57.5% accuracy on the test set, demonstrating that context augmentation is crucial for improving performance.

## Method Summary
The method combines text and image similarity measures using embeddings from CLIP (image-text) and BERT (text-only) models, with optional context augmentation via InstructGPT and translation using DeepL/ChatGPT. The algorithm computes pairwise similarities between candidate images and context/glosses, then selects the image-gloss pair that maximizes a weighted combination of these similarities. The authors experiment with different configurations, including translation-based approaches versus language-specific models, and context augmentation using generated definitions from InstructGPT.

## Key Results
- The TR+DEF system (translation + context augmentation) achieves 57.5% accuracy on the test set
- Context augmentation yields substantial improvements in accuracy across all language conditions
- Translation-based approaches outperform language-specific models for non-English instances
- There is a significant performance gap between English and non-English instances

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Combining text and image similarity measures in a weighted average improves V-WSD accuracy.
- Mechanism: The algorithm computes pairwise similarities between candidate images and context/glosses, then selects the image-gloss pair that maximizes a weighted combination of these similarities.
- Core assumption: Images encode richer representations than text, and the combination of image-context, image-gloss, and context-gloss similarities captures semantic relationships effectively.
- Evidence anchors: [abstract] "We present a novel algorithm that leverages glosses retrieved from BabelNet, in combination with text and image encoders."

### Mechanism 2
- Claim: Context augmentation with generated definitions significantly improves V-WSD performance.
- Mechanism: InstructGPT generates detailed descriptions for short contexts, which are then concatenated to the original context before processing.
- Core assumption: Short contexts lack sufficient semantic information, and generated definitions provide additional context that improves disambiguation.
- Evidence anchors: [abstract] "As the contexts given in the task datasets are extremely short, we also experiment with augmenting these contexts with descriptions generated by a language model. This yields substantial improvements in accuracy."

### Mechanism 3
- Claim: Translating non-English instances to English and using English models yields better results than using language-specific models directly.
- Mechanism: Non-English contexts are translated to English, then processed with English CLIP and BERT models, which have more training data and better performance.
- Core assumption: English models are superior due to more training data, and the translation process introduces less noise than using less capable non-English models.
- Evidence anchors: [abstract] "Furthermore, we compare language-specific encoders against the application of English encoders to translated texts."

## Architecture Onboarding

- Component map: Context/gloss retrieval -> Encoding (text/image) -> Similarity computation -> Weighted combination -> Image selection
- Critical path: Context/gloss retrieval → Encoding (text/image) → Similarity computation → Weighted combination → Image selection
- Design tradeoffs:
  - Translation vs. language-specific models: Translation introduces noise but leverages superior English models
  - Context augmentation: Improves accuracy but adds computational cost and potential for irrelevant generation
  - Number of glosses: More glosses provide better sense coverage but increase computation
- Failure signatures:
  - Low accuracy on non-English instances: Indicates translation issues or inadequate language-specific models
  - Inconsistent performance across languages: Suggests bias in English models or insufficient non-English resources
  - No improvement with context augmentation: May indicate generated definitions are irrelevant or original contexts are already sufficient
- First 3 experiments:
  1. Compare TR (translation-based) vs. LANG SPEC (language-specific) on English test set to verify performance parity
  2. Test TR with and without context augmentation on development set to measure impact
  3. Vary weight hyperparameters (wic, wig, wcg) to find optimal combination for development set

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What specific aspects of image generation (e.g., number of images, guidance scale, diffusion steps) yield optimal performance for the V-WSD task?
- Basis in paper: [explicit] The authors experimented with different numbers of generated images and observed performance improvements up to 10 images.
- Why unresolved: The paper only tested a limited range of image generation parameters and did not perform exhaustive hyperparameter tuning.
- What evidence would resolve it: Systematic experimentation with a wider range of image generation parameters and their impact on V-WSD performance.

### Open Question 2
- Question: How does the performance of the proposed algorithm vary with different text encoders and similarity functions for simL?
- Basis in paper: [explicit] The authors used BERT as the text encoder for simL, but did not experiment with alternative encoders or similarity functions.
- Why unresolved: The paper only tested one text encoder and similarity function, leaving the impact of other choices unexplored.
- What evidence would resolve it: Comparative analysis of the algorithm's performance using different text encoders and similarity functions for simL.

### Open Question 3
- Question: Can the proposed algorithm be effectively applied to other multimodal tasks beyond V-WSD, such as image captioning or visual question answering?
- Basis in paper: [inferred] The algorithm combines text and image encoders in a shared semantic space, which is a common approach in multimodal tasks.
- Why unresolved: The paper focuses solely on the V-WSD task and does not explore the algorithm's applicability to other multimodal tasks.
- What evidence would resolve it: Empirical evaluation of the algorithm's performance on other multimodal tasks, such as image captioning or visual question answering.

## Limitations
- Cannot fully validate the translation pipeline's impact without access to original non-English contexts
- Paper doesn't provide detailed hyperparameter settings for the context augmentation process
- Analysis assumes CLIP and BERT embeddings are sufficient for capturing semantic relationships without exploring alternatives

## Confidence
- **High confidence**: The effectiveness of context augmentation for improving V-WSD accuracy is well-supported by the experimental results showing consistent improvements across all language conditions.
- **Medium confidence**: The superiority of translation-based approaches over language-specific models is supported by the results, but the analysis doesn't fully account for potential confounding factors.
- **Medium confidence**: The weighted combination of similarity measures is theoretically sound, but the optimal weight configuration may be task-specific.

## Next Checks
1. Implement a human evaluation of translation quality for a subset of non-English instances to quantify the noise introduced by the translation pipeline and assess whether this noise correlates with performance degradation.

2. Systematically vary the weight hyperparameters (wic, wig, wcg) across a wider range of values to identify whether the reported configuration is truly optimal or if alternative weight combinations yield better performance.

3. Generate multiple augmented contexts for each instance using different random seeds and measure the variance in model performance to assess the robustness and reliability of the context augmentation approach.
