# Data-Driven Inverse Reinforcement Learning for Expert-Learner Zero-Sum Games

## Quick Facts
- arXiv ID: 2301.01997
- Source URL: https://arxiv.org/abs/2301.01997
- Reference count: 40
- Expert learner zero-sum game IRL algorithm achieves better imitation performance with smaller error index than comparison methods

## Executive Summary
This paper introduces a data-driven inverse reinforcement learning framework for expert-learner zero-sum games where a learner agent observes expert behavior and reconstructs the expert's cost function intent to mimic optimal responses. The key innovation is incorporating non-cooperative disturbances into the learning process, leading to a zero-sum game formulation that enables robust learning under adversarial conditions. The framework uses modified policy iteration with single-loop learning that updates value functions, control policies, and cost function weights simultaneously without requiring system dynamics knowledge.

## Method Summary
The method formulates IRL as an expert-learner interaction where the learner observes expert states, controls, and disturbances to reconstruct the expert's cost function. It uses a modified policy iteration approach that extends standard RL to handle unknown cost functions and disturbances through a zero-sum game formulation. The algorithm operates in a single loop, iteratively updating value functions, control policies, and cost function weights using integral-based data-driven updates that don't require system dynamics knowledge. Convergence is guaranteed when the learned policy matches the expert policy within a specified threshold.

## Key Results
- Learner state successfully mimics expert trajectories under learned control policy
- Proposed algorithm achieves significantly smaller imitation error index compared to baseline methods
- Convergence is guaranteed when learned policy matches expert policy within threshold of 0.01

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The algorithm reconstructs the expert's cost function without requiring system dynamics by using observed state and control data.
- Mechanism: The method replaces analytical updates with integral-based data-driven updates using observed trajectories. This allows the learner to iteratively adjust the cost function weights based on actual system behavior rather than theoretical models.
- Core assumption: The observed expert trajectories are optimal with respect to some unknown cost function that the learner can approximate through iterative updates.
- Evidence anchors:
  - [abstract] "An off-policy IRL algorithm is developed that does not require knowledge of the expert and learner agent dynamics"
  - [section] "Using only the behavior data of the expert and learner itself (7), a learner agent learns the unknown cost function objective and the optimal control policy to mimic the expert's behavior."
- Break condition: If the expert demonstrations are not optimal or contain significant noise, the algorithm may converge to an incorrect cost function.

### Mechanism 2
- Claim: The algorithm handles non-cooperative disturbances by formulating the problem as a zero-sum game between the learner and disturbance.
- Mechanism: The algorithm computes both optimal control policies and worst-case disturbance responses simultaneously, allowing the learner to reject disturbances while mimicking expert behavior.
- Core assumption: The disturbance has a worst-case bound and can be represented as an affine function of the state.
- Evidence anchors:
  - [abstract] "we add non-cooperative disturbances that seek to disrupt the learning and stability of the learner agent"
  - [section] "The learner (7) will be stabilized and perform the same way as the target (1) does if KT in (3a) is applied to the learner (7) with bounded dT = d."
- Break condition: If disturbances exceed the assumed worst-case bounds or have non-affine structure, the algorithm's performance degrades.

### Mechanism 3
- Claim: Single-loop learning converges to a cost function that produces the same optimal policy as the expert.
- Mechanism: The algorithm iteratively updates the cost function weights (Q), value function/policy (P), and control/disturbance gains (K, L) in a single loop until convergence.
- Core assumption: The initial Q0 satisfies 0 < Q0 ≤ ˆQ where ˆQ is a solution to Theorem 1, and the system matrices satisfy controllability conditions.
- Evidence anchors:
  - [abstract] "The framework has two parts: a value function and control action update based on an extension of PI, and a cost function update based on standard inverse optimal control"
  - [section] "Theorem 2. i). With an initial Q 0 such that 0 < Q0 ≤ ˆQ and L0 = 0 where ˆQ > 0 is a solution to Theorem 1 associated with the R > 0 and γ > 0, Algorithm 1 converges."
- Break condition: If the initial Q0 is not properly bounded or the system is not controllable, convergence may fail.

## Limitations

- The approach requires expert demonstrations to be optimal with respect to some unknown cost function, which may not hold in practical scenarios with noisy or sub-optimal expert behavior
- The disturbance rejection mechanism assumes worst-case bounds and affine disturbance structure, limiting its applicability to more complex disturbance patterns
- The convergence proofs rely on controllability conditions and proper initialization of cost function weights, which may not be satisfied in all practical applications
