# Delta Denoising Score

## Quick Facts
- arXiv ID: 2304.07090
- Source URL: https://arxiv.org/abs/2304.07090

## Executive Summary
Delta Denoising Score (DDS) is a new scoring function for text-based image editing that addresses the blurriness and loss of detail issues in existing Score Distillation Sampling (SDS) methods. DDS works by subtracting a reference SDS gradient (computed from a matched image-text pair) from the main SDS gradient, effectively removing noisy directions. This allows for minimal modifications of input images while maintaining fidelity to target prompts. The method shows strong experimental results and can be applied both as a prompt-to-prompt editing technique and for training zero-shot image translation models.

## Method Summary
DDS modifies the Score Distillation Sampling framework by introducing a reference branch that computes the SDS score of a matched image-text pair. The core idea is to subtract this reference score from the target SDS score, yielding a cleaner gradient direction for image editing. The method uses classifier-free guidance with a warmup scheduler to prevent mode collapse during training, and includes identity regularization to preserve input fidelity. DDS can be applied to optimize latent images directly or used as a loss function for training image translation models.

## Key Results
- DDS outperforms existing SDS-based methods in terms of stability and output quality
- The method successfully reduces blurriness and preserves details during text-based image editing
- DDS can be used for both prompt-to-prompt editing without masks and for training zero-shot image translation models

## Why This Works (Mechanism)

### Mechanism 1
DDS removes noisy gradient directions from SDS by subtracting a reference score computed on a matched image-text pair. The reference gradient captures the "erroneous" component of SDS, which is then subtracted to yield a cleaner editing direction. This works under the assumption that the SDS gradient for a matched image-text pair should be zero or minimal.

### Mechanism 2
For similar images, the noisy component of SDS gradients is correlated. The noise direction for a source image is assumed to be similar for a target image with similar structure. By using the reference branch, DDS estimates this shared noise and applies it to clean the target's gradient.

### Mechanism 3
CFG warmup prevents mode collapse during training by gradually increasing the guidance scale. During training, CFG is initialized at a low value and gradually increased using a cosine scheduler. This allows the network to learn large edits progressively without collapsing to a fixed output.

## Architecture Onboarding

- **Component map**: Source image → DDS loss computation → Edited image (with CFG warmup and identity regularization)

- **Critical path**:
  1. Initialize latent image with source image
  2. Compute SDS gradients for target and reference pairs
  3. Subtract reference gradient from target gradient to get DDS gradient
  4. Update image using DDS gradient
  5. Apply identity regularization to preserve input fidelity

- **Design tradeoffs**:
  - CFG scale vs. fidelity: High CFG improves text fidelity but reduces input fidelity
  - Number of optimization steps: More steps allow larger edits but increase computation time
  - Reference prompt choice: Accurate reference prompts improve noise estimation but require additional effort

- **Failure signatures**:
  - Blurry outputs: Indicates insufficient noise removal or low CFG scale
  - Mode collapse: Suggests CFG warmup is not properly implemented
  - Artifacts: May result from improper optimizer choice (e.g., Adam vs. SGD)

- **First 3 experiments**:
  1. Test DDS on a simple image-text pair (e.g., flamingo to stork) with varying CFG scales to observe fidelity tradeoffs
  2. Compare DDS with regularized SDS optimization to validate noise removal effectiveness
  3. Implement CFG warmup and test for mode collapse prevention in multi-task image translation

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions but leaves several areas unexplored, including the theoretical relationship between DDS and SDS convergence, the impact of reference prompt quality, and potential extensions to multi-modal editing tasks.

## Limitations
- DDS performance depends heavily on the quality of reference prompt matching
- The correlation assumption between noise directions may break down for semantically distant image transformations
- The method requires careful tuning of CFG warmup scheduling parameters

## Confidence
- **High confidence**: DDS effectively reduces noise in SDS gradients when reference prompts are well-matched to input images
- **Medium confidence**: The correlation assumption between noise directions in similar images holds for structurally similar content but may break down for semantically distant transformations
- **Medium confidence**: CFG warmup prevents mode collapse, though optimal scheduling parameters may vary by task

## Next Checks
1. Systematically vary the quality of reference prompt matching and measure degradation in DDS performance to establish robustness bounds
