# Ensemble Modeling for Time Series Forecasting: an Adaptive Robust Optimization Approach

## Quick Facts
- arXiv ID: 2304.04308
- Source URL: https://arxiv.org/abs/2304.04308
- Reference count: 24
- Primary result: Adaptive robust ensemble method achieves 16-26% RMSE reduction and 14-28% CVaR improvement over baseline ensemble techniques

## Executive Summary
This paper introduces an adaptive robust optimization approach for ensemble time series forecasting that dynamically adjusts model weights to handle model drift. The method uses affine decision rules within a robust optimization framework to construct a linear regression ensemble where weights adapt over time based on recent forecast errors. The approach is formulated as a min-max optimization problem and transformed into a tractable form using equivalence theorems. The method is validated on synthetic data and three real-world applications (air pollution management, energy consumption forecasting, and tropical cyclone intensity forecasting), demonstrating significant performance improvements over baseline ensemble methods and the best ensemble member in hindsight.

## Method Summary
The paper presents an adaptive Ridge formulation that minimizes worst-case forecast error over an uncertainty set while applying regularization. The method uses affine decision rules to construct adaptive weights βt = β₀ + V₀ · Zt, where weights depend on historical forecast errors Zt. The optimization problem is solved as a min-max formulation that finds optimal base weights and uncertainty set parameters. The approach leverages equivalence theorems to transform the robust optimization problem into a tractable form, allowing efficient computation of adaptive ensemble weights that respond to model drift over time.

## Key Results
- Adaptive ensemble outperforms best ensemble member in hindsight by 16-26% in RMSE
- Adaptive ensemble improves over competitive ensemble techniques by 14-28% in CVaR
- Method is particularly effective when sufficient training data is available and when ensemble members may experience performance drift

## Why This Works (Mechanism)
The method works by explicitly modeling uncertainty in ensemble member performance through robust optimization. By constructing an uncertainty set around forecast errors and optimizing for worst-case performance, the approach naturally downweights poorly performing models and adapts to changing conditions. The affine decision rules allow weights to depend on historical errors, enabling the ensemble to respond to model drift without requiring complex retraining. The regularization parameter λ controls the trade-off between fitting recent data and maintaining stable weights, while the window size τ determines how much historical data influences weight adaptation.
