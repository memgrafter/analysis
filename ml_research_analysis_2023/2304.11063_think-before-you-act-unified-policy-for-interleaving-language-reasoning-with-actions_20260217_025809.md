# Think Before You Act: Unified Policy for Interleaving Language Reasoning with Actions

## Quick Facts
- **arXiv ID**: 2304.11063
- **Source URL**: https://arxiv.org/abs/2304.11063
- **Reference count**: 5
- **Key outcome**: Unified transformer policy with word outputs improves BossLevel success rate by ~10% by interleaving language reasoning and actions

## Executive Summary
This paper introduces a unified transformer policy that interleaves language reasoning with environment actions for reinforcement learning. The authors augment a causal transformer with word outputs, allowing it to generate both textual subgoal descriptions and environment actions in a single sequence. Using BabyAI training data with aligned captions describing subgoals at each step, the model demonstrates improved performance on complex tasks requiring long-term planning, particularly showing a 10% improvement on the BossLevel task compared to caption-free baselines.

## Method Summary
The method uses a GPT-2 transformer architecture (4 layers, 2 heads, 256 or 512 hidden size) trained autoregressively to predict both actions and captions from BabyAI trajectories. Expert trajectories are collected using BabyAI's expert bot, with captions generated from underlying subgoals. The model is trained with AdamW (lr=1e-4) on sub-sequences of length K, using cross-entropy loss. At test time, the model generates tokens auto-regressively, executing actions when generated and feeding back captions to continue reasoning. The approach unifies action and language reasoning into a single sequence prediction task.

## Key Results
- On BossLevel-1M, the captioning model outperforms caption-free baseline by +10% success rate
- The model shows significant improvement on tasks requiring long-term sequential planning
- Performance improvements are consistent across three random seeds with reported mean and standard error

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The model benefits from interleaving textual subgoal reasoning with environment actions, enabling it to break down complex tasks into manageable chunks
- Mechanism: By augmenting the transformer policy with word outputs, the model can decide when to generate reasoning tokens (describing subgoals) and when to generate action tokens, mimicking human problem-solving strategies
- Core assumption: The captions describing subgoals are temporally aligned with the agent's progress in the environment and provide useful intermediate objectives
- Evidence anchors: [abstract], [section 4.1], related work on language-based reasoning
- Break condition: If captions are not well-aligned or do not provide meaningful subgoals

### Mechanism 2
- Claim: The model learns to predict both actions and captions in a unified way, allowing it to leverage language annotations for effective learning and better generalization
- Mechanism: The auto-regressive transformer is trained on a dataset of unified action-caption sequences, minimizing the token prediction error across the trajectory using the entropy loss
- Core assumption: The model can effectively learn from both actions and captions, and the captions provide additional context for predicting the right actions
- Evidence anchors: [abstract], [section 4.2], prior work on decision transformers
- Break condition: If the model struggles to effectively learn from both actions and captions

### Mechanism 3
- Claim: The model's performance improves on tasks that require long-term sequential planning, as language reasoning helps to break down complex tasks into smaller, more manageable subgoals
- Mechanism: By generating reasoning tokens describing subgoals, the model can plan ahead and execute actions in a more structured manner, rather than relying solely on immediate observations
- Core assumption: Long-term planning tasks benefit from the ability to reason about subgoals, and the model can effectively use the generated reasoning tokens to guide its actions
- Evidence anchors: [section 5.3], related work on hierarchical decision-making
- Break condition: If tasks do not require long-term planning or model struggles to use reasoning tokens effectively

## Architecture Onboarding

- Component map: Instruction (natural language) -> GPT-2 model architecture -> Convolutional network for observation encoding -> 4-layer transformer (2 attention heads, dropout 0.1, hidden size 256 or 512) -> Probability distribution over action and caption tokens

- Critical path:
  1. Tokenize and embed the instruction using the GPT-2 tokenizer and embedding layer
  2. Encode the observations using the convolutional network and flatten with a linear layer
  3. Embed the action and caption tokens using the common embedding layer
  4. Pass the embedded inputs through the transformer layers
  5. Predict the next action or caption token using a linear layer and softmax
  6. At test time, generate tokens auto-regressively, switching between reasoning and acting based on the generated token

- Design tradeoffs:
  - Using a unified policy that can generate both actions and captions simplifies the architecture but may limit the model's capacity to specialize in either task
  - The choice of transformer architecture (number of layers, attention heads, hidden size) affects the model's capacity and computational efficiency
  - The granularity of the action and caption sequences may impact the model's ability to learn from the captions and generalize to new tasks

- Failure signatures:
  - If the model struggles to generate meaningful reasoning tokens, it may fail to break down complex tasks into manageable subgoals
  - If the model's action predictions are inconsistent with the generated reasoning tokens, it may indicate a misalignment between the reasoning and acting components
  - If the model's performance does not improve on tasks requiring long-term planning, it may suggest that the reasoning tokens are not effectively guiding the agent's behavior

- First 3 experiments:
  1. Evaluate the model's performance on a simple task (e.g., PutNextLocal) with varying amounts of training data to assess the impact of data size on the model's learning
  2. Compare the model's performance with and without captions on a moderately complex task (e.g., Synth) to quantify the benefit of language reasoning
  3. Analyze the model's generated reasoning tokens on a complex task (e.g., BossLevel) to assess the quality and relevance of the subgoals in guiding the agent's behavior

## Limitations
- Training data dependency: Success heavily depends on quality and alignment of generated captions with agent's subgoals
- Evaluation scope: Results limited to BabyAI environment, may not translate to other complex tasks or real-world scenarios
- Mechanism understanding: Exact mechanisms by which captions guide behavior remain unclear

## Confidence
**High Confidence Claims**:
- The unified transformer architecture with word outputs can interleave textual subgoal reasoning with environment actions
- The captioning model outperforms a caption-free baseline on BossLevel by approximately 10% in success rate
- The model successfully learns from both actions and captions using cross-entropy loss

**Medium Confidence Claims**:
- Language reasoning specifically benefits tasks requiring long-term sequential planning
- The model's reasoning tokens represent meaningful subgoals that guide behavior
- The approach generalizes across different task complexities within BabyAI

**Low Confidence Claims**:
- The exact mechanisms by which reasoning tokens influence action selection
- Performance extrapolation to non-grid-world environments
- Impact of caption quality variations on final performance

## Next Checks
1. **Ablation on Caption Quality**: Generate multiple versions of the training data with varying caption quality (perfect alignment, noisy alignment, random captions) and evaluate how this affects performance on BossLevel to quantify the importance of caption quality.

2. **Cross-Environment Transfer**: Test the pretrained captioning model (trained on BabyAI) on a different grid-world environment or a modified version of BabyAI with different layouts to assess generalization beyond the training distribution.

3. **Reasoning Token Analysis**: Implement a method to track whether generated reasoning tokens actually influence subsequent action sequences (e.g., by masking reasoning tokens during evaluation or comparing action sequences with/without reasoning tokens) to validate that the model uses reasoning for planning rather than just context.
