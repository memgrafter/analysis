# Detection of DDoS Attacks in Software Defined Networking Using Machine Learning Models

## Executive Summary
This paper investigates the application of machine learning algorithms for detecting distributed denial-of-service (DDoS) attacks in software-defined networking (SDN) environments. The study evaluates four algorithms—Random Forest, Decision Tree, Support Vector Machine, and XGBoost—using the CICDDoS2019 dataset with timestamps and WebDDoS records removed to simulate realistic deployment conditions. Performance metrics including accuracy, precision, recall, and F1-score are used to compare model effectiveness. The results demonstrate that machine learning-based detection outperforms traditional approaches, with Random Forest showing the highest accuracy of 68.9%, though computational demands remain a challenge for non-parametric algorithms.

## Method Summary
The research evaluates four machine learning algorithms (Random Forest, Decision Tree, SVM, and XGBoost) for DDoS attack detection in SDN environments using the CICDDoS2019 dataset. The dataset is preprocessed by removing timestamp features and WebDDoS records due to insufficient data. The data is split into 80% training and 20% testing sets. Each algorithm is implemented using Python's scikit-learn library, trained on the training set, and evaluated on the test set using accuracy, precision, recall, and F1-score metrics. The study focuses on comparing these algorithms' performance to identify the most effective approach for DDoS detection in SDN.

## Key Results
- Random Forest achieved the highest accuracy of 68.9% among tested models
- ML-based detection methods demonstrated superior performance compared to traditional approaches
- Computational demands of non-parametric algorithms remain a significant challenge
