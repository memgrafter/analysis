# A Brief Survey on the Approximation Theory for Sequence Modelling

## Quick Facts
- arXiv ID: 2302.13752
- Source URL: https://arxiv.org/abs/2302.13752
- Reference count: 40
- Key outcome: This paper provides a survey of approximation theory results for sequence modeling in machine learning, focusing on classifying existing results for various model architectures through the lens of classical approximation paradigms.

## Executive Summary
This survey paper provides a comprehensive overview of approximation theory results for sequence modeling, classifying existing results for various model architectures through classical approximation paradigms. The authors highlight how sequence approximation differs from classical paradigms due to infinite-dimensional input and output spaces from completely ordered index sets. The paper covers density-type (universal approximation), Jackson-type (approximation rate estimates), and Bernstein-type (inverse approximation) results for recurrent neural networks, convolution-based architectures, encoder-decoder architectures, and attention-based architectures. A key insight is that each model architecture is efficient in approximating targets that resemble its temporal structure.

## Method Summary
The paper surveys approximation theory results for sequence modeling by analyzing functional sequences and hidden dynamic functionals as the natural target space. The methodology involves mathematical analysis using norms, convergence proofs, and error bounds to establish density-type, Jackson-type, and Bernstein-type results for different architectures. The survey synthesizes results from classical approximation theory (Stone-Weierstrass theorem, Jackson theorems) and applies them to modern sequence modeling contexts, examining how each architecture's temporal structure enables efficient approximation of specific target patterns.

## Key Results
- RNNs are effective for sequence modeling when targets have exponentially decaying memory patterns, with approximation rates scaling based on memory decay speed
- Temporal CNNs excel at approximating sparse memory patterns in sequences, with efficiency related to tensorisation rank and singular value decay rates
- Encoder-decoder architectures are efficient for low-rank temporal relationships between input and output sequences, with context vector size scaling with effective rank
- Current theoretical understanding of transformer approximation capabilities remains limited, with only preliminary results available

## Why This Works (Mechanism)

### Mechanism 1
- Claim: RNNs are effective for sequence modeling when targets have exponentially decaying memory patterns
- Mechanism: RNNs with exponentially decaying memory (via linear dynamics with Hurwitz matrices) can approximate targets whose memory decays at least as fast as e^{-βt}
- Core assumption: Target functional sequences exhibit exponential memory decay and are sufficiently smooth (α-times differentiable)
- Evidence anchors:
  - [section] "The key insight here is as follows. If we assume, in addition to the usual smoothness requirements, that the memory of targets decay like an exponential (Eq. (19)), then we can efficiently approximate them using linear RNNs."
  - [corpus] "Inverse Approximation Theory for Nonlinear Recurrent Neural Networks" suggests complementary Bernstein-type results exist for this setting
- Break condition: Target functional sequences have slower-than-exponential memory decay or insufficient smoothness, leading to curse of memory where required model complexity grows exponentially with desired approximation accuracy

### Mechanism 2
- Claim: Temporal CNNs excel at approximating sparse memory patterns in sequences
- Mechanism: Temporal CNNs with K layers and M channels can approximate targets whose Riesz representation has low tensorisation rank, scaling with KM^{1/K}
- Core assumption: Target functional sequences have sparse or low-rank temporal structures amenable to tensor product-sum approximations
- Evidence anchors:
  - [section] "The key insight here is as follows. If we assume, in addition to the usual smoothness requirements, that the memory of targets decay like an exponential (Eq. (19)), then we can efficiently approximate them using linear RNNs."
  - [section] "It can be shown [46] that if H has a sparse Riesz representation (memory), then it has small C1(H). This supports the empirical observation that temporal CNNs excel in applications such as text-to-speech [7], where such sparsity patterns are expected."
- Break condition: Target functional sequences have dense or high-rank temporal structures that require exponentially many parameters for CNN approximation

### Mechanism 3
- Claim: Encoder-decoder architectures are effective for low-rank temporal relationships between input and output sequences
- Mechanism: RNN encoder-decoder with context vector of size N can approximate targets with low effective rank in their temporal product structure, scaling with the N-th singular value
- Core assumption: Target functional sequences exhibit low coupling between input and output sequences that can be captured by a finite-dimensional context vector
- Evidence anchors:
  - [section] "The Jackson-type estimate in Eq. (45) says that a target with low effective rank can be approximated efficiently with REncDec (with small context vector)."
  - [section] "This is very different from both the CNN and the RNN architectures, and the Jackson-type estimate makes this difference precise."
- Break condition: Target functional sequences have high effective rank requiring large context vectors for accurate approximation, defeating the efficiency advantage

## Architecture Onboarding

- Component map: RNNs (with variants like LSTM/GRU) -> Temporal CNNs -> Encoder-decoder architectures -> Attention-based transformers

- Critical path: For a new engineer, the progression should be: 1) Understand classical approximation theory basics, 2) Learn functional sequence formalism, 3) Study RNN approximation results and memory decay concepts, 4) Explore CNN and encoder-decoder architectures with their rank-based characterizations, 5) Examine transformer approximations and current limitations.

- Design tradeoffs: RNNs excel at exponentially decaying memory but suffer curse of memory for long-term dependencies; CNNs handle sparse memory well but struggle with dense patterns; encoder-decoders are efficient for low-rank temporal relationships but require careful context vector sizing; transformers offer flexibility but current theoretical understanding is limited.

- Failure signatures: Poor performance with RNNs often indicates insufficient memory decay in targets or excessive smoothness requirements; CNN failures suggest dense memory patterns or high-rank structures; encoder-decoder issues point to high effective rank requiring larger context vectors; transformer underperformance may indicate mismatch between assumed and actual target structure.

- First 3 experiments:
  1. Implement a simple RNN to approximate a target with known exponential memory decay (e.g., exponentially weighted moving average) and measure approximation error vs. width
  2. Build a temporal CNN to approximate a target with sparse memory (e.g., delayed impulse response) and compare performance against RNN on the same task
  3. Create an encoder-decoder model to approximate a low-rank temporal relationship (e.g., smoothed version of input sequence) and analyze how context vector size affects approximation quality

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What are the precise conditions on target functional sequences for universal approximation by Transformer architectures, and how do these compare to RNNs and CNNs?
- Basis in paper: [explicit] "Currently known approximation results only focus on linear RNN encoder-decoder. However, the density result can be extended to non-linear cases by following the same approaches outlined in Section 3, due to the similarity with RNNs. The rate estimate is less straightforward to extend to non-linear activations. Nevertheless, one may expect that the uncovered relationship between the size the context vector and a low-rank type of approximation should hold generally for encoder-decoder architectures."
- Why unresolved: While density results exist for Transformers, they rely on specific constructions that don't reveal the underlying principles. Jackson-type and Bernstein-type results are completely absent, making it impossible to characterize the approximation spaces and memory structures that Transformers are adapted to model.
- What evidence would resolve it: Jackson-type error estimates for Transformers showing how approximation error scales with model complexity (depth, width, attention heads) and target complexity (smoothness, memory decay, rank). Bernstein-type results showing necessary conditions on targets for efficient Transformer approximation.

### Open Question 2
- Question: How does the curse of memory phenomenon manifest differently across RNNs, CNNs, and encoder-decoder architectures, and what are the precise mathematical conditions that trigger it?
- Basis in paper: [explicit] "The density type results, including the linear RNN case, do not require the targets to have an exponentially decaying memory in the sense of Eq. (19). However, the rate estimate in Eq. (20) does have this requirement. The natural question is therefore, what if one has a slower memory decay rate? For example, we may replace Eq. (19) by H (r) t (ei)∼ e−βt −→ H (r) t (ei)∼ t−(r+ω) (ω > 0). Then, a truncation argument in Li et al. [43] shows that to obtain an approximation error of ϵ, a size of the RNN may need to grow exponentially, as m∼ ϵ−1/ω."
- Why unresolved: Current results only partially characterize the curse of memory for linear RNNs. The behavior for non-linear RNNs, CNNs, and encoder-decoders remains unknown, particularly for memory patterns that decay slower than exponential but faster than polynomial.
- What evidence would resolve it: Lower bounds on approximation error for each architecture type when approximating targets with different memory decay rates (exponential, polynomial, sub-polynomial). Comparative analysis showing which architectures are most robust to different memory decay patterns.

### Open Question 3
- Question: What are the exact relationships between the approximation spaces CRNN, CCNN, and CEncDec, and how do they relate to classical function spaces like Sobolev spaces?
- Basis in paper: [explicit] "One pressing need is to reduce the amount of trial and error during model selection. The understanding of the suitability of different model architectures for different problem types is essential in guiding implementations in practice. Therefore, an important task is to formalize a model selection workflow for sequence modelling. This certainly requires more than approximation theory, but the current understanding already suggests that we should quantify the memory patterns observed in datasets to select the model archetype."
- Why unresolved: While the paper suggests that each architecture is adapted to targets with similar structural properties (exponential decay for RNNs, low tensor rank for CNNs, low temporal product rank for encoder-decoders), the precise mathematical characterization of these approximation spaces and their relationships remains unknown.
- What evidence would resolve it: Proofs that the proposed norms (like |H|∗ in Eq. (58)) indeed define valid norms, characterization of whether these spaces are Banach or Hilbert spaces, interpolation theorems between these spaces, and comparisons with classical smoothness spaces showing when one space is strictly contained in another.

## Limitations

- The paper's claims are primarily theoretical, relying on mathematical proofs and bounds rather than empirical validation, which may not directly translate to practical finite-sample scenarios
- Many results depend on specific technical conditions (e.g., "uniformly asymptotically incrementally stable" dynamics, specific memory decay rates) that may be difficult to verify in practice
- The theoretical analysis often considers simplified or idealized versions of neural architectures, potentially missing practical considerations like optimization dynamics, finite precision, or architectural variants

## Confidence

- High confidence: The classification of approximation results into density-type, Jackson-type, and Bernstein-type paradigms is well-established in approximation theory literature and the connections drawn are mathematically sound
- Medium confidence: The characterization of different architectures' efficiency for specific target structures is theoretically justified but may not fully capture practical performance variations
- Low confidence: The claims about transformer approximation capabilities are acknowledged as preliminary, with only initial results available and no comprehensive theoretical characterization yet established
