# SEAL: Simultaneous Label Hierarchy Exploration And Learning

## Quick Facts
- arXiv ID: 2304.13374
- Source URL: https://arxiv.org/abs/2304.13374
- Reference count: 40
- Primary result: Simultaneously learns data-driven label hierarchies and improves semi-supervised classification performance through tree-based Wasserstein regularization

## Executive Summary
This paper introduces SEAL, a novel framework that addresses the limitation of fixed predefined label hierarchies in semi-supervised learning by simultaneously discovering data-driven label structures and improving classification performance. SEAL bridges the gap between assumed hierarchical label structures and actual data distributions by augmenting observed labels with latent labels and optimizing a tree-based Wasserstein regularization term. The method demonstrates consistent improvements over state-of-the-art semi-supervised learning approaches on standard benchmark datasets while revealing meaningful label relationships that align with human intuition.

## Method Summary
SEAL operates by optimizing a unified objective that combines standard semi-supervised learning with a tree-based Wasserstein regularization term. The framework works by augmenting observed labels with latent labels and optimizing both the neural network parameters and the label hierarchy structure simultaneously. It uses a tree-structured label hierarchy (A1) that can be initialized as a trivial binary tree or derived from prior knowledge, and employs a relaxation of the Tree-Wasserstein distance to measure hierarchical relationships. The method jointly learns the optimal label hierarchy and improves classification performance through this integrated optimization process.

## Key Results
- SEAL consistently enhances state-of-the-art semi-supervised learning methods on CIFAR-10, CIFAR-100, and STL-10 datasets
- The method achieves new state-of-the-art performance on these standard benchmarks
- SEAL discovers meaningful label structures that reveal semantic relationships between classes

## Why This Works (Mechanism)
SEAL works by leveraging the natural hierarchical structure often present in real-world labels, which is typically ignored by standard classification approaches. By simultaneously learning the label hierarchy and optimizing the classification objective, SEAL creates a more structured representation space that improves generalization. The tree-based Wasserstein regularization encourages the model to respect the hierarchical relationships between labels, while the latent label augmentation provides additional supervisory signals that improve learning from limited labeled data.

## Foundational Learning

**Tree-Wasserstein Distance**
- Why needed: Provides a principled way to measure distances between hierarchical label structures
- Quick check: Can be computed efficiently for binary trees and provides meaningful semantic distances

**Semi-Supervised Learning**
- Why needed: Most real-world scenarios have limited labeled data but abundant unlabeled data
- Quick check: SSL methods typically outperform fully supervised approaches when labeled data is scarce

**Label Hierarchy Learning**
- Why needed: Real-world labels often have implicit hierarchical relationships that can improve learning
- Quick check: Hierarchical structures can reveal semantic relationships between classes

## Architecture Onboarding

**Component Map**
Neural Network -> Tree-Wasserstein Regularization -> Latent Label Augmentation -> Hierarchical Label Structure

**Critical Path**
The optimization loop that jointly updates the neural network parameters and the label hierarchy structure through backpropagation, using the tree-based Wasserstein distance as the regularization term.

**Design Tradeoffs**
SEAL trades computational complexity for improved performance and learned label structures. The method requires more computation than standard semi-supervised learning but provides both better accuracy and interpretable hierarchies.

**Failure Signatures**
The method may struggle with datasets where hierarchical relationships are not naturally present or where the tree structure assumption is violated. Computational complexity may become prohibitive for very large label spaces.

**First Experiments**

2. Ablation study removing the tree-based regularization to measure its contribution
3. Qualitative analysis of learned hierarchies on CIFAR-100 to verify semantic coherence

### Open Question 3

## Limitations
- Computational complexity may become prohibitive for very large-scale datasets or extremely deep label hierarchies
- Performance on domains with inherently flat label structures or where hierarchical relationships are not naturally present remains unexplored
- Limited quantitative validation of the semantic coherence of learned hierarchies in practical applications

## Confidence
- SEAL consistently enhances state-of-the-art methods: High

- Computational scalability to very large datasets: Low
