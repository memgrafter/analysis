# Structured Latent Variable Models for Articulated Object Interaction

## Quick Facts
- arXiv ID: 2305.16567
- Source URL: https://arxiv.org/abs/2305.16567
- Reference count: 12
- Primary result: Neural statistician outperforms context-free baselines in parameter inference and reward prediction for door-opening tasks

## Executive Summary
This work introduces a semi-supervised approach for learning low-dimensional representations of doors in images using the neural statistician, a structured latent variable model. The model is pretrained on unlabelled door image datasets to learn hierarchical representations separating object-level parameters from instance-level configurations. After pretraining, the model is fine-tuned for two downstream tasks: parameter inference (predicting door properties) and reward prediction for door-opening policies. Results show the neural statistician outperforms context-free baselines (VAE and CNN) in parameter inference accuracy and achieves lower regret in door-opening tasks, particularly when input images show doors in different configurations.

## Method Summary
The method uses a semi-supervised learning approach where a neural statistician model is first pretrained on a large dataset of unlabelled door images, with each door having multiple associated images at different configurations. The model learns a hierarchical latent representation with context-level variables capturing shared object properties (handedness, size) and instance-level variables capturing configuration-specific details (opening angle). After pretraining, the encoder component is fine-tuned on small labeled datasets for specific tasks: parameter inference (predicting door properties from single images) and reward prediction (estimating success probability for door-opening actions). The approach leverages synthetic door image data generated using PyBullet simulation.

## Key Results
- Neural statistician encoder outperforms VAE and CNN baselines in parameter inference tasks, especially for predicting door handedness, size, angle, location, and configuration
- In reward prediction tasks, neural statistician achieves lower regret when selecting door-opening actions compared to context-free baselines
- Model performs better when input images show doors in different configurations rather than similar ones
- Pretraining on unlabelled data enables effective parameter inference with small labeled datasets (400 doors)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Neural Statistician's hierarchical latent structure enables better generalization to unseen door configurations by learning shared object-level parameters across multiple images.
- Mechanism: By enforcing separation between context-level variables (shared across all images of the same door) and instance-level variables (unique to each image's configuration), the model can infer object properties from multiple views and apply them to new configurations.
- Core assumption: Multiple images of the same door contain redundant information about object-level parameters that can be pooled to improve representation quality.
- Evidence anchors:
  - [abstract] "The neural statistician enforces separation between shared context-level variables (common across all images associated with the same door) and instance-level variables (unique to each individual image)."
  - [section] "We can take advantage of the hierarchical structure of the doors dataset to enforce separation between object-level and configuration-level variables."
- Break condition: If the dataset doesn't provide multiple images per object, or if object-level parameters vary significantly across images of the "same" object.

### Mechanism 2
- Claim: Pretraining on unlabelled door images before finetuning enables better parameter inference with fewer labeled examples.
- Mechanism: The model learns a rich, generalizable representation of door structure during pretraining, which transfers to supervised tasks during finetuning, reducing sample complexity.
- Core assumption: Door structure has universal properties (size, handedness, etc.) that can be learned from unlabelled data and applied across different door instances.
- Evidence anchors:
  - [abstract] "Current machine learning based approaches in the doors domain are based primarily on labelled datasets. However, the large quantity of available door data suggests the feasibility of a semisupervised approach based on pretraining."
  - [section] "Pretrained latent variable models additionally have the potential to aid in neural network based policy learning tasks by reducing the number of interactions required."
- Break condition: If the pretraining dataset is too small or too different from the finetuning task, the transfer learning benefit diminishes.

### Mechanism 3
- Claim: The Neural Statistician's conditional sampling capability allows generation of realistic door images with controlled variations in configuration while preserving object identity.
- Mechanism: By fixing context-level parameters and sampling instance-level variables, the model can generate multiple views of the same door in different configurations, which is useful for data augmentation and policy planning.
- Core assumption: The learned latent space has meaningful structure where context variables capture object identity and instance variables capture configuration.
- Evidence anchors:
  - [abstract] "It was found that a pretrained neural statistician encoder outperformed analogous context-free baselines when predicting door handedness, size, angle location, and configuration from door images."
  - [section] "By holding context parameters constant, we can simulate taking multiple snapshots of a single door."
- Break condition: If the latent space doesn't properly disentangle object-level and configuration-level parameters, conditional sampling will produce unrealistic or inconsistent results.

## Architecture Onboarding

- Component map:
  Shared encoder network (convolutional layers) → produces embeddings for all images in a collection
  Statistic network → predicts context variables from collection embeddings
  Inference network → predicts instance variables conditioned on context and individual image
  Latent decoder network → samples instance variables from context
  Observation decoder network → reconstructs images from context and instance variables
  Finetuning layers → map latent representations to task-specific outputs (parameters or rewards)

- Critical path: For reconstruction: Image → Shared encoder → Context and instance variables → Observation decoder → Reconstructed image

- Design tradeoffs:
  - Latent dimension choice: Small dimensions (c=8, z=1) for interpretability vs. larger dimensions for reconstruction quality
  - Number of pretraining samples: More samples improve generalization but increase computational cost
  - Context vs. instance separation: Too much separation may lose useful correlations; too little separation loses interpretability

- Failure signatures:
  - Poor reconstruction quality → indicates inadequate model capacity or training
  - Inability to generate realistic samples → suggests latent space doesn't capture data distribution well
  - Poor parameter inference → indicates lack of proper separation between object-level and configuration-level parameters
  - High regret in policy selection → suggests reward prediction is inaccurate or doesn't generalize

- First 3 experiments:
  1. Train NS and VAE on small dataset (400 doors), evaluate reconstruction quality and sampling diversity
  2. Finetune both models on parameter inference task, compare accuracy for different door parameters
  3. Evaluate policy selection performance on closed-door vs. open-door tasks, measure regret reduction

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the Neural Statistician model perform when pretrained in simulation and then fine-tuned on real-world door data?
- Basis in paper: [explicit] The paper suggests investigating the performance of the Neural Statistician model in more generalized datasets, including realistic door datasets and datasets where the viewpoint varies slightly. It also mentions investigating how well the NS generalizes to distributional shifts between pretraining and fine-tuning, such as pretraining in simulation and fine-tuning on realistic doors from the application domain.
- Why unresolved: The paper only demonstrates the model's performance on a simulated dataset and does not test its generalization to real-world data or scenarios with varying viewpoints.
- What evidence would resolve it: Experiments comparing the model's performance when pretrained in simulation versus real-world data, and when tested on data with varying viewpoints, would provide evidence for its generalization capabilities.

### Open Question 2

However, it also suggests investigating the model's performance with fewer pretraining samples to determine the minimum required for optimal performance.
- Why unresolved: The paper does not explore the lower bounds of pretraining data requirements or the trade-off between pretraining data size and model performance.
- What evidence would resolve it: Conducting experiments with varying amounts of pretraining data and evaluating the model's performance on downstream tasks would help determine the minimum required pretraining data for optimal performance.

## Limitations
- Results are based entirely on synthetic PyBullet-generated door data rather than real-world images
- Limited validation on articulated objects beyond simple doors with single hinges
- Architecture details for key components (statistic, inference, and latent decoder networks) not fully specified
- Missing ablation studies on the importance of hierarchical structure vs. pretraining alone

## Confidence
- **High**: Pretraining improves parameter inference accuracy compared to context-free baselines
- **Medium**: Hierarchical latent structure enables better generalization across door configurations
- **Low**: Performance claims transfer directly to real-world robotic manipulation scenarios
