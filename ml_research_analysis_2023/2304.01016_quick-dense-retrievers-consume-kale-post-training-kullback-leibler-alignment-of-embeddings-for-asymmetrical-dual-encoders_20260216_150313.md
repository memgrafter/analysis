# Quick Dense Retrievers Consume KALE: Post Training Kullback Leibler Alignment of Embeddings for Asymmetrical dual encoders

## Quick Facts
- arXiv ID: 2304.01016
- Source URL: https://arxiv.org/abs/2304.01016
- Reference count: 40
- Key outcome: KALE enables 3-6x faster inference with only 1% accuracy loss through asymmetric query/document encoder sizing

## Executive Summary
This paper addresses the computational inefficiency of dense retrieval systems by exploring structural compression and model size asymmetry between query and document encoders. The authors introduce Kullback-Leibler Alignment of Embeddings (KALE), a post-training compression method that aligns query encoder embeddings without retraining or index regeneration. Through extensive experiments on five benchmarks, they demonstrate that document encoder size dominates retrieval performance while query encoders can be significantly compressed, yielding substantial inference speedups with minimal accuracy degradation.

## Method Summary
The method involves training asymmetric bi-encoder models with varying query/document encoder sizes, then applying KALE post-training compression to pruned query encoders. KALE fine-tunes the compressed query encoder to minimize KL divergence with the original embeddings while keeping the document encoder frozen. This allows effective compression without full retraining or index regeneration. The approach leverages the observation that document encoders drive retrieval accuracy while query encoders can be smaller due to their simpler, more uniform inputs.

## Key Results
- Document encoder size dominates retrieval performance across all five benchmarks tested
- Asymmetric query/document encoder sizes yield 3-6x inference speedups with minimal accuracy loss
- KALE enables effective post-training compression, allowing 3-6x faster inference with only 1% accuracy loss
- Best models achieve up to 4.5x faster inference with only 1% accuracy loss compared to uncompressed baselines

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Query encoder size has minimal impact on retrieval accuracy compared to document encoder size
- Mechanism: The document encoder dominates the latent space quality, making it the primary driver of retrieval accuracy. Query encoders handle simpler, more uniform inputs, so smaller sizes suffice
- Core assumption: Query representations require less capacity than document representations due to input complexity differences
- Evidence anchors:
  - [abstract]: "document encoder size dominates retrieval performance"
  - [section 3.1]: "We find that the document encoder drives retrieval accuracy... performance out of domain is dependent on the document encoder"
  - [corpus]: Weak - no direct corpus evidence for this mechanism
- Break condition: When query complexity approaches document complexity (e.g., very long or multi-aspect queries)

### Mechanism 2
- Claim: Post-training KALE compression preserves query embedding alignment with minimal accuracy loss
- Mechanism: KALE fine-tunes pruned query encoders to minimize KL divergence with the original embeddings while keeping document encoder frozen, maintaining effective similarity computations
- Core assumption: KL divergence minimization effectively preserves the relative geometry of query embeddings
- Evidence anchors:
  - [abstract]: "KALE extends traditional Knowledge Distillation after bi-encoder training, allowing for effective query encoder compression without full retraining or index generation"
  - [section 4.2]: "KALE is applied after model training and leverages large batch sizes to make compression computationally inexpensive"
  - [corpus]: Weak - no direct corpus evidence for this mechanism
- Break condition: When pruning ratio exceeds structural capacity of query representations

### Mechanism 3
- Claim: Asymmetric encoder sizing enables significant inference speedup with minimal accuracy degradation
- Mechanism: By compressing only the query encoder (which runs on every inference) while keeping document encoder large, overall system efficiency improves dramatically without sacrificing accuracy
- Core assumption: Document encoder infrequency (batch index generation) vs query encoder frequency (per-query) justifies asymmetric optimization
- Evidence anchors:
  - [abstract]: "asymmetric query/document encoder sizes can yield significant inference speedups"
  - [section 3]: "The query encoder runs every time a user issues a query... The document encoder is usually only used once during a large-scale batch generation"
  - [corpus]: Weak - no direct corpus evidence for this mechanism
- Break condition: When document index regeneration frequency increases or query complexity grows substantially

## Architecture Onboarding

- Component map:
  Query encoder -> ANN index -> Document encoder -> KALE alignment

- Critical path:
  1. Train bi-encoder with original sizes
  2. Generate document index with frozen document encoder
  3. Prune query encoder structurally
  4. Apply KALE alignment to compressed query encoder
  5. Deploy asymmetric model for inference

- Design tradeoffs:
  - Compression vs accuracy: More compression yields faster inference but potential accuracy loss
  - Training cost vs deployment efficiency: KALE adds post-training cost but enables efficient deployment
  - Hardware utilization: CPU vs GPU inference performance varies with encoder size

- Failure signatures:
  - High accuracy drop after pruning: Likely pruned beyond representational capacity
  - KALE convergence issues: May need adjusted learning rate or batch size
  - GPU memory issues during KALE: Reduce batch size or use gradient accumulation

- First 3 experiments:
  1. Train baseline bi-encoder with symmetric BERT-base encoders on NQ dataset
  2. Apply KALE to 3-layer pruned query encoder while keeping 12-layer document encoder
  3. Measure inference speedup and accuracy loss compared to baseline on NQ dev set

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the effectiveness of KALE vary with different document encoder sizes when query encoders are compressed?
- Basis in paper: Inferred from the observation that document encoder size dominates retrieval performance, but the paper doesn't systematically study KALE's effectiveness across different document encoder configurations.
- Why unresolved: The experiments primarily use 12-layer document encoders, leaving open whether KALE's effectiveness scales differently with smaller document encoders.
- What evidence would resolve it: Systematic experiments varying document encoder sizes (3, 6, 9 layers) while applying KALE to compressed query encoders across multiple datasets.

### Open Question 2
- Question: What is the theoretical limit of KALE's effectiveness for heavily pruned models, and why does performance plateau or degrade beyond certain compression levels?
- Basis in paper: Inferred from the observation that 2-3 layer models show the largest gains from KALE, suggesting potential limits to its effectiveness.
- Why unresolved: The paper demonstrates practical effectiveness but doesn't explain the underlying mechanism or identify when KALE becomes ineffective.
- What evidence would resolve it: Theoretical analysis of KL divergence matching limits, combined with empirical studies on even more heavily pruned models (1-2 layers) and comparison with alternative compression methods.

### Open Question 3
- Question: How do different pre-training strategies for compressed query encoders affect their post-training alignment capability with KALE?
- Basis in paper: Explicit mention that models like DistilBERT (pre-trained with knowledge distillation) perform better than post-training compressed models, suggesting pre-training impacts alignment potential.
- Why unresolved: The paper only explores post-training compression and doesn't investigate whether certain pre-training approaches make models more amenable to KALE.
- What evidence would resolve it: Comparative experiments using query encoders pre-trained with various compression-aware training methods, then applying KALE to measure relative effectiveness.

## Limitations

- The evidence for why document encoders dominate retrieval performance is primarily correlational rather than mechanistic
- KALE alignment mechanism relies on assumptions about KL divergence effectiveness that lack direct validation
- Post-training compression approach may have scalability limitations for extremely large document collections
