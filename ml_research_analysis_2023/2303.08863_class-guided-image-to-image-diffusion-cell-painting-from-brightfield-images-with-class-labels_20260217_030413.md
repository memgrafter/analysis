# Class-Guided Image-to-Image Diffusion: Cell Painting from Brightfield Images with Class Labels

## Quick Facts
- **arXiv ID**: 2303.08863
- **Source URL**: https://arxiv.org/abs/2303.08863
- **Reference count**: 40
- **Key outcome**: Class-guided image-to-image diffusion improves biological feature quality in predicted microscopy images, outperforming unguided models in downstream tasks like target prediction and clustering.

## Executive Summary
This paper addresses the challenge of predicting high-quality Cell Painting fluorescence microscopy images from paired brightfield images using a class-guided image-to-image diffusion model. The authors combine the Palette diffusion framework with classifier guidance and AdaGN layers to incorporate metadata labels (perturbation and target information) during training. The class-guided approach demonstrates improved feature extraction and downstream task performance compared to unguided models, with perturbation labels showing particularly strong results in phenotypic feature correlations and target matching.

## Method Summary
The method combines Palette's image-to-image diffusion with classifier guidance using metadata labels. During training, class labels are incorporated via AdaGN layers, embedding label information into normalization layers. During inference, gradients from a pre-trained classifier guide the denoising steps toward class-consistent outputs. The model is trained on paired brightfield and Cell Painting images from the JUMP-Target-2 dataset, with separate models trained with and without labels. Evaluation includes both image-level metrics (SSIM, MSE/MAE) and feature-level metrics (CellProfiler feature correlation, target matching) using transfer learning with a DINO vision transformer backbone.

## Key Results
- Class-guided diffusion improves meaningful content in reconstructed images compared to unguided models
- Using perturbation labels yields strong results in phenotypic feature correlations, SSIM, and target matching
- The approach outperforms unguided models in mechanism of action prediction and clustering tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Class-guided image-to-image diffusion improves feature quality in predicted microscopy images by steering the denoising process with relevant metadata.
- Mechanism: The model combines Palette's image-to-image framework with classifier guidance. During training, class labels are incorporated via AdaGN layers, embedding label information into normalization. During inference, gradients from a pre-trained classifier guide the denoising steps toward class-consistent outputs, effectively biasing the generation toward biologically meaningful structures.
- Core assumption: The discrete metadata labels are biologically informative and correlate with morphological differences in the target images.
- Evidence anchors: [abstract], [section 3], [corpus]
- Break condition: If class labels are noisy, uninformative, or not correlated with biological differences, the model may overfit to background noise or irrelevant patterns, reducing image fidelity.

### Mechanism 2
- Claim: The model's ability to generate high-quality images depends on the relevance and specificity of the class labels used during training.
- Mechanism: Labels guide the network to learn features that differentiate between biological phenotypes. Perturbation labels (which are freely available and biologically meaningful) lead to better downstream performance compared to more abstract labels like target, which may be too broad or noisy.
- Core assumption: Perturbation labels capture meaningful biological variation and are sufficiently specific to guide learning without introducing noise.
- Evidence anchors: [abstract], [section 5], [corpus]
- Break condition: If labels are too coarse, ambiguous, or not linked to the image content, the guidance signal becomes noisy, and the model may degrade image quality.

### Mechanism 3
- Claim: Transfer learning with pretrained models like DINO can extract robust phenotypic representations from both real and synthetic microscopy images, improving downstream prediction tasks.
- Mechanism: The DINO backbone (ViT-S/8) extracts feature embeddings from predicted images. These embeddings capture high-level biological features that correlate with target mechanisms of action, enabling better prediction performance than raw pixel metrics alone.
- Core assumption: The pretrained vision transformer has learned general visual features that transfer well to microscopy data and capture relevant biological patterns.
- Evidence anchors: [section 4.5], [section 5], [corpus]
- Break condition: If the pretrained model's features do not align with the biological patterns in the microscopy data, transfer learning may fail to improve downstream performance.

## Architecture Onboarding

- **Component map**: Brightfield images -> U-Net-based DDPM with AdaGN layers -> Cell Painting images -> DINO feature extraction -> Downstream task evaluation

- **Critical path**:
  1. Preprocess brightfield images (illumination correction, normalization)
  2. Train DDPM with or without class labels
  3. Sample predicted Cell Painting images using trained model
  4. Extract features using CellProfiler or DINO
  5. Evaluate on downstream tasks (target matching, clustering, etc.)

- **Design tradeoffs**:
  - Using class labels can improve feature quality but may introduce background noise if labels are not informative.
  - Classifier guidance improves target matching but adds computational cost and may slightly reduce image fidelity.
  - Transfer learning with DINO improves downstream performance but requires additional computation for feature extraction.

- **Failure signatures**:
  - Background noise in predicted images when labels are not biologically meaningful.
  - Overfitting to label-specific patterns, reducing general image quality.
  - Poor downstream performance if transfer learning features do not align with biological patterns.

- **First 3 experiments**:
  1. Train a baseline unlabelled model and evaluate on image-level and feature-level metrics.
  2. Train a model with perturbation labels and compare performance to the unlabelled model.
  3. Train a model with target labels and analyze the trade-off between target matching and image quality.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Does incorporating class labels through adaptive group normalization (AdaGN) and classifier guidance improve the quality of generated images and extracted biological features across different datasets and tasks?
- Basis in paper: [explicit] The paper states that incorporating labels can improve the quality of extracted biological features and outperform the unguided model in downstream tasks.
- Why unresolved: The paper only evaluates this on a single dataset (JUMP-CP) and a limited set of downstream tasks. It's unclear if the findings generalize to other datasets or tasks.
- What evidence would resolve it: Testing the class-guided approach on multiple diverse datasets and tasks to see if the improvements hold. Ablation studies isolating the effects of AdaGN vs classifier guidance.

### Open Question 2
- Question: How does the choice of class labels (e.g. perturbation vs target) impact the performance of class-guided image-to-image diffusion models?
- Basis in paper: [explicit] The paper finds that using the perturbation label improves performance more than using the target label. It suggests that more ambitious labels may prevent learning a faithful reconstruction.
- Why unresolved: The paper only compares two types of labels on one dataset. It's unclear what other types of labels could be used and how they would perform.
- What evidence would resolve it: Systematically testing different types of labels (e.g. compound, batch, biological process) on multiple datasets to determine which labels are most effective and why.

### Open Question 3
- Question: Can class-guided image-to-image diffusion be used to generate realistic images that can fool human observers?
- Basis in paper: [inferred] The paper focuses on quantitative metrics like feature correlation and target matching. It does not report any perceptual studies or qualitative evaluations.
- Why unresolved: The paper does not assess whether the generated images look realistic to humans, which is important for practical applications.
- What evidence would resolve it: Conducting perceptual studies where human observers are asked to distinguish real vs generated images. If humans cannot reliably tell the difference, the generated images are perceptually realistic.

## Limitations
- Limited evaluation to a single dataset (JUMP-Target-2) with two specific label types
- Relatively small active subset (118 perturbations) used for final evaluation
- No ablation studies on different label encoding schemes or their individual contributions

## Confidence
- **Medium-High**: The core claim that class guidance improves feature quality is well-supported by consistent quantitative improvements across multiple metrics
- **Medium**: Claims about transfer learning effectiveness show promise but may be sensitive to specific model architectures and pretraining schemes
- **Medium**: Generalizability beyond the specific dataset and label types remains uncertain

## Next Checks
1. Test the class-guided model on a completely independent dataset with different biological perturbations to assess generalizability beyond the JUMP-Target-2 plates.
2. Conduct ablation studies comparing different label encoding methods (one-hot, embedding layers, etc.) and their impact on image quality versus downstream task performance.
3. Evaluate the model's performance when using noisy or partially incorrect labels to determine robustness to label quality issues.
