# A Unified Generative Retriever for Knowledge-Intensive Language Tasks via Prompt Learning

## Quick Facts
- arXiv ID: 2304.14856
- Source URL: https://arxiv.org/abs/2304.14856
- Reference count: 40
- Key outcome: UGR achieves state-of-the-art retrieval performance across multiple knowledge-intensive language tasks through prompt-based unification

## Executive Summary
This paper introduces the Unified Generative Retriever (UGR), a novel approach that unifies various retrieval tasks (document, passage, sentence, and entity retrieval) through prompt learning. UGR represents relevant contexts using n-gram-based identifiers and employs task-specific prompts to capture task specifications while sharing common knowledge across tasks. The model is trained on a heterogeneous set of retrieval corpora in a supervised, multi-task fashion. Experimental results on the KILT benchmark demonstrate significant improvements in R-precision compared to previous state-of-the-art models, with strong performance on in-domain, out-of-domain, and unseen tasks. UGR also achieves competitive results under zero-shot and few-shot settings and contributes to new state-of-the-art downstream results when paired with existing reader models.

## Method Summary
UGR employs a prompt learning strategy to unify different retrieval tasks by representing relevant contexts with n-gram-based identifiers. The approach investigates three methods to design prompt tokens for each task: linear, anchor, and hybrid. By training on a heterogeneous set of retrieval corpora with well-designed prompts in a supervised and multi-task fashion, UGR captures task specifications while sharing common knowledge across tasks. The n-gram-based identifier system allows the model to represent various types of relevant contexts (documents, passages, sentences, entities) in a unified manner, enabling the same architecture to perform multiple retrieval tasks effectively.

## Key Results
- UGR achieves significant improvements in R-precision compared to previous state-of-the-art models
- Demonstrates strong adaptability to unseen tasks with competitive results under zero-shot and few-shot settings
- Contributes to new state-of-the-art downstream results when paired with existing reader models

## Why This Works (Mechanism)
The effectiveness of UGR stems from its ability to unify different retrieval tasks through a common representation (n-gram-based identifiers) while maintaining task-specific capabilities through prompt learning. The prompt learning strategy allows the model to adapt to different task specifications without requiring separate architectures for each retrieval type. By training on heterogeneous corpora in a multi-task fashion, UGR learns to share common knowledge across tasks while preserving task-specific distinctions through carefully designed prompts.

## Architecture Onboarding

**Component Map:**
Input Prompt -> UGR Model (with n-gram identifier layer) -> Unified Retrieval Output

**Critical Path:**
Task-specific prompt generation → N-gram identifier mapping → Unified retrieval computation → R-precision evaluation

**Design Tradeoffs:**
- Unified architecture vs. task-specific models (simplicity vs. potential specialization)
- N-gram identifier granularity (specificity vs. generalization)
- Prompt learning complexity (linear vs. anchor vs. hybrid approaches)

**Failure Signatures:**
- Poor performance on specific task types may indicate insufficient prompt design
- Degradation on unseen tasks suggests overfitting to training tasks
- Low R-precision could indicate ineffective n-gram identifier mapping

## Limitations
- Evaluation primarily focuses on R-precision, which may not fully capture retrieval quality across diverse downstream applications
- Performance on truly unseen tasks beyond the KILT benchmark remains uncertain
- Computational efficiency and memory requirements compared to task-specific retrievers are not discussed
- The analysis of why certain prompt types work better for specific tasks is limited

## Confidence
- R-precision improvements: High confidence
- Zero-shot and few-shot performance claims: Medium confidence (limited to KILT benchmark)
- Scalability to very large or dynamic corpora: Medium confidence (not empirically tested)
- Prompt type effectiveness analysis: Medium confidence (limited investigation)
