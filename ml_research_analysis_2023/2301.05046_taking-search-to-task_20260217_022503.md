# Taking Search to Task

## Quick Facts
- arXiv ID: 2301.05046
- Source URL: https://arxiv.org/abs/2301.05046
- Reference count: 40
- Key outcome: Presents a comprehensive framework for task-based information retrieval using hierarchical tree structures and both explicit and implicit task representations to support complex search tasks across multiple applications.

## Executive Summary
This paper provides a comprehensive review and synthesis of the role of tasks in information retrieval (IR), examining how tasks have been understood, modeled, and applied in search systems over decades of research. The authors present a new framing device for tasks using a tree-like structure that captures task hierarchy and various moves within it, offering both explicit and implicit representations. They discuss applications across contextual search, multi-device search, conversational agents, and proactive recommendation systems. The paper also addresses evaluation methodologies and metrics for task-based systems, considering both process and outcome measures.

## Method Summary
The paper proposes a framework for task-based information retrieval that models user tasks as hierarchical trees with both explicit (interpretable hierarchies) and implicit (vector embeddings) representations. The method involves extracting observable user actions (queries, clicks, dwell time) and contextual signals to build task representations, then using these representations to support various IR applications including contextual search, multi-device search, and proactive recommendations. The framework includes evaluation approaches combining process metrics (task completion time, effort) and outcome metrics (satisfaction, success), with applications ranging from conversational agents to task-aware recommendation systems.

## Key Results
- Task representations using hierarchical tree structures can effectively model complex search tasks across multiple levels of abstraction
- Both explicit task hierarchies and implicit vector embeddings have complementary advantages for different search applications
- Multi-device search experiences can be unified through task representations that persist across sessions and devices
- Task-based evaluation requires both process metrics (effort, time) and outcome metrics (satisfaction, success) for comprehensive assessment

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Task-aware search systems can better support complex, multi-step information seeking by representing tasks as hierarchical trees with observable and unobservable actions.
- Mechanism: The paper proposes a tree-like structure where tasks decompose into sub-tasks and actions, allowing the system to model task progression across multiple levels and predict next steps based on current context.
- Core assumption: Search sessions contain sufficient observable signals (queries, clicks, dwell time) that can be mapped to hierarchical task structures, even when some task components are unobservable.
- Evidence anchors:
  - [abstract] "We present a new framing device for tasks using a tree-like structure and various moves on that structure that allow different interpretations and applications."
  - [section 3.1] "We can say that a task (also called a 'macrotask') is composed of sub-tasks, sub-sub-tasks, and so on."
  - [corpus] Weak evidence - no direct corpus support for tree-based task representations in search systems.

### Mechanism 2
- Claim: Task representations can be both explicit (interpretable hierarchies) and implicit (vector embeddings) to support different search applications.
- Mechanism: The paper suggests combining explicit task trees with implicit vector representations derived from user behavior patterns, allowing both interpretability and scalability across different contexts.
- Core assumption: Both explicit and implicit representations capture complementary aspects of task information that can be integrated for improved search support.
- Evidence anchors:
  - [abstract] "We have experimented with both of these representations over the years... recognizing their advantages and disadvantages. However, we have started to converge on ideas that offer the best of both worlds."
  - [section 3.3] "There are different ways we can extract, represent, and apply task information to address the challenges discussed in Section 3.3."
  - [corpus] Weak evidence - no direct corpus support for hybrid explicit/implicit task representations.

### Mechanism 3
- Claim: Multi-device search experiences can be unified through task representations that persist across sessions and devices.
- Mechanism: By abstracting tasks beyond individual actions to higher-level task representations, search systems can maintain continuity across different devices and time periods.
- Core assumption: Users perform coherent tasks across multiple devices, and these can be tracked through consistent task representations rather than device-specific interactions.
- Evidence anchors:
  - [section 5.2] "Cross-device searching, where people initiate a task at one time and/or on one device and resume it later, perhaps on a different device, is related to cross-session and may be simply because of necessity, but also the device capabilities."
  - [section 5.2] "This involves moving up in our task tree, from actions to micro-tasks, sub-tasks, and so on, stopping at the point where the device space can be most fully represented without being so broad that the task representation is meaningless."
  - [corpus] Weak evidence - no direct corpus support for multi-device task persistence.

## Architecture Onboarding

- Component map:
  - Task representation layer: Handles both explicit tree structures and implicit vector embeddings
  - Behavior tracking layer: Captures observable user actions (queries, clicks, dwell time)
  - Context inference layer: Derives task states from behavior patterns and contextual signals
  - Multi-device synchronization: Maintains task continuity across sessions and devices
  - Evaluation framework: Provides both process and outcome metrics for task performance

- Critical path:
  1. User initiates search session with query
  2. System captures observable actions and contextual signals
  3. Task representation layer updates current task state
  4. Context inference layer predicts next task/sub-task
  5. System provides task-aware recommendations or completions
  6. Evaluation framework tracks task progress and outcomes

- Design tradeoffs:
  - Explicit vs. implicit representations: Interpretability vs. scalability
  - Granularity levels: Fine-grained actions vs. high-level task abstraction
  - Privacy vs. functionality: More data collection improves task understanding but raises privacy concerns
  - Real-time vs. batch processing: Immediate task support vs. more accurate long-term modeling

- Failure signatures:
  - High variance in task state predictions despite consistent user behavior
  - Task representations that don't align with user's perceived task progress
  - Poor performance when switching between devices or resuming tasks
  - Evaluation metrics showing good process metrics but poor outcome metrics

- First 3 experiments:
  1. Build a simple explicit task tree representation using query clustering and test on a single-session dataset to verify basic task hierarchy extraction
  2. Implement implicit task vector embeddings using session-based neural networks and compare prediction accuracy against explicit representations
  3. Create a multi-device task continuity test where users switch between devices and measure task completion success rates with and without unified task representations

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can we develop a unified task representation that works across different IR applications and contexts?
- Basis in paper: [explicit] The paper discusses the need for a "far-reaching representation capable of modeling work at multiple levels of abstraction" and mentions both explicit (hierarchical) and implicit (vector-based) representations.
- Why unresolved: The paper acknowledges that current approaches have limitations and proposes a task tree structure but doesn't provide a definitive solution for a universal representation.
- What evidence would resolve it: A working system that can seamlessly apply task representations across diverse IR applications (contextual search, conversational agents, proactive recommendations) while maintaining interpretability and scalability.

### Open Question 2
- Question: What are the most effective ways to capture unobservable task-related events and actions?
- Basis in paper: [explicit] The paper notes that "some actions are also unobserved, or unobservable, from software" and discusses the challenge of moving up the task hierarchy when observations are incomplete.
- Why unresolved: The paper identifies this as a challenge but doesn't provide concrete solutions for capturing these hidden task elements.
- What evidence would resolve it: Methods or tools that can successfully triangulate data from multiple sources (search logs, device usage, external applications) to infer task context with high accuracy.

### Open Question 3
- Question: How can task-based IR systems balance proactive recommendations with user agency and avoid undue influence?
- Basis in paper: [explicit] The paper dedicates a section to ethical considerations, warning about systems "unduly influence user behaviors and nudge them in ways that perpetuate bias and a false sense of trust."
- Why unresolved: While the paper identifies the risks, it doesn't provide concrete guidelines or mechanisms for maintaining this balance.
- What evidence would resolve it: A framework or set of principles that allows task-based systems to provide helpful proactive assistance while preserving user autonomy and preventing manipulation.

## Limitations

- The paper acknowledges that explicit task tree representations may become too complex to infer from observable signals alone, limiting their practical applicability
- Implicit vector embeddings may lose interpretability needed for user trust and system transparency
- The proposed multi-device task continuity approach faces challenges from device-specific constraints that could prevent unified task support

## Confidence

- High confidence: Historical synthesis of task-based IR research and well-established evaluation frameworks
- Medium confidence: Novel tree-based framing device and dual representation approach due to limited external validation
- Medium confidence: Ethical considerations around user influence and privacy require more empirical study
