# SF2Former: Amyotrophic Lateral Sclerosis Identification From Multi-center MRI Data Using Spatial and Frequency Fusion Transformer

## Quick Facts
- arXiv ID: 2302.10859
- Source URL: https://arxiv.org/abs/2302.10859
- Authors: 
- Reference count: 13
- Key outcome: Achieved 0.816 accuracy, 0.843 sensitivity, 0.812 specificity, and 0.815 F1-score on CALSNIC1 dataset for ALS vs healthy control classification

## Executive Summary
This study introduces SF2Former, a transformer-based framework that fuses spatial and frequency domain features for classifying Amyotrophic Lateral Sclerosis (ALS) patients from healthy controls using multi-center MRI data. The approach processes 15 consecutive coronal slices from 3D MRI volumes using parallel Vision Transformer (ViT) and Global Filter Network (GFNet) branches, followed by feature fusion and majority voting. Evaluated on multi-modal neuroimaging data from the Canadian ALS Neuroimaging Consortium (CALSNIC) datasets, SF2Former demonstrates superior performance compared to several popular deep learning methods while showing robustness to multi-center data variability.

## Method Summary
SF2Former processes 3D MRI volumes by extracting 15 consecutive coronal slices from the central region, then applying parallel transformer architectures: a ViT for spatial domain features and a GFNet for frequency domain features. Both networks use ImageNet pre-trained weights and are fine-tuned on the MRI data. The extracted features are fused through a linear layer, and individual slice predictions are aggregated using majority voting to produce the final classification. The model is trained using SGD optimizer (lr=0.001, momentum=0.9) with cross-entropy loss and evaluated via 5-fold stratified cross-validation on T1-weighted, R2*, and FLAIR MRI modalities from CALSNIC datasets.

## Key Results
- Achieved 0.816 accuracy, 0.843 sensitivity, 0.812 specificity, and 0.815 F1-score on CALSNIC1 dataset
- R2* modality showed best performance among the three MRI modalities tested
- Demonstrated superior performance compared to several popular deep learning-based techniques
- Showed robustness to multi-center data with different scanner types

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Fusing spatial and frequency domain features improves ALS classification by capturing complementary structural and signal characteristics.
- Mechanism: MRI data is inherently acquired in the frequency domain and transformed to spatial domain for visualization. By using both ViT (spatial) and GFNet (frequency), the model can extract complementary discriminative features that individually might miss subtle ALS-related changes.
- Core assumption: ALS pathology manifests as subtle structural changes that are better captured by analyzing both spatial patterns and frequency domain characteristics.
- Evidence anchors:
  - [abstract] "To further improve the network's performance, spatial and frequency domain information are combined because MRI scans are captured in the frequency domain before being converted to the spatial domain."
  - [section] "However, directly involving a deep model in the frequency domain is computationally expensive, especially when the image resolution is high. The GFNet Rao et al. (2021) uses a similar downsampling design of the ViT and replaces the self-attention layer with the Fast Fourier Transform (FFT) on the embedded patch tokens."
- Break condition: If ALS pathology doesn't manifest differently in frequency vs spatial domains, or if the computational cost of frequency domain processing outweighs the benefits.

### Mechanism 2
- Claim: Using coronal slices instead of full 3D volumes improves classification while reducing computational complexity.
- Mechanism: The model processes 15 consecutive coronal slices from the central region of 3D MRI volumes, leveraging the observation that this region better captures the corticospinal tract (CST), a key region of interest in ALS.
- Core assumption: The CST and surrounding regions, which are more prominent in coronal slices, contain the most discriminative information for ALS classification.
- Evidence anchors:
  - [section] "Manual observation from experts suggests that this range of coronal slices better captures the CST, which is a prominent region of interest in ALS."
  - [section] "We use an eight-core CPU platform that leverages parallel processing and takes around 5 minutes per scan on average to perform the preprocessing."
- Break condition: If ALS pathology affects brain regions that are not well-represented in coronal slices, or if slice selection becomes too dependent on expert manual observation.

### Mechanism 3
- Claim: Majority voting across slices reduces false positives and improves overall classification accuracy.
- Mechanism: Since not all slices will contain disease-affected tissues, the model aggregates predictions from individual slices using majority voting to produce the final classification for each subject.
- Core assumption: Disease-affected tissues are not uniformly distributed across all slices, so individual slice predictions will be inconsistent.
- Evidence anchors:
  - [section] "The science behind applying majority voting in our methodology is that it is unlikely to present all the disease-affected tissues or areas in all the chosen slices."
  - [section] "In other words, it is not feasible to automatically capture the 2D planes that will always contain distinct clinical characteristics for any subjects without manual effort from a specialist."
- Break condition: If ALS pathology is uniformly distributed across all slices, making majority voting unnecessary, or if the number of slices used for voting is too small to be statistically meaningful.

- Critical path: Input coronal slices → ViT processing → GFNet processing → Feature fusion → Classification → Majority voting → Final output

- Failure signatures: Poor performance on individual slices, high variance in slice-level predictions, or failure to generalize to new centers would indicate problems with the approach.

## Limitations
- Slice selection relies on manual expert observation, introducing potential subjectivity and limiting generalizability
- Using 2D slices instead of full 3D volumes may miss volumetric information relevant for ALS diagnosis
- Specific impact of different scanner parameters and acquisition protocols on performance is not thoroughly characterized

## Confidence
- High confidence: The superiority of the SF2Former framework over baseline methods (accuracy 0.816, F1-score 0.815) is well-supported by the experimental results on two independent datasets.
- Medium confidence: The claim that fusing spatial and frequency domain features provides complementary information is reasonable but could benefit from ablation studies isolating the contribution of each modality.
- Medium confidence: The assertion that majority voting improves classification by reducing false positives is plausible given the methodology, though the exact impact of this approach on individual patient predictions is not fully explored.

## Next Checks
1. **Ablation study**: Evaluate model performance using only the ViT branch (spatial only) and only the GFNet branch (frequency only) to quantify the contribution of each modality to the overall performance.

2. **Slice range optimization**: Systematically vary the number and position of coronal slices used (e.g., 5, 10, 15, 20 slices across different anatomical regions) to determine the optimal configuration for ALS classification.

3. **Cross-scanner validation**: Test the model on data from additional MRI scanners and centers not included in the CALSNIC datasets to assess true generalizability and identify potential scanner-specific biases.
