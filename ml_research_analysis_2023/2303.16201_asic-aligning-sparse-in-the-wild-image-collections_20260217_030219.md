# ASIC: Aligning Sparse in-the-wild Image Collections

## Quick Facts
- arXiv ID: 2303.16201
- Source URL: https://arxiv.org/abs/2303.16201
- Authors: 
- Reference count: 40
- Key outcome: Proposes a method for jointly aligning sparse collections of in-the-wild images without manual annotations, achieving state-of-the-art results on keypoint consistency and image warping benchmarks

## Executive Summary
This paper introduces ASIC (Aligning Sparse in-the-wild Image Collections), a self-supervised method for establishing dense correspondences across a sparse collection of in-the-wild images of the same object category. The method leverages pre-trained DINO ViT features to obtain initial sparse keypoint matches, then refines these through a joint canonical space mapping learned by an alignment network. The approach demonstrates superior performance on several benchmarks compared to existing self-supervised methods, introducing a new metric (k-CyPCK) to evaluate consistency across image sequences.

## Method Summary
ASIC takes a sparse collection of in-the-wild images (10-30 images) of the same object category and jointly learns dense correspondences without manual annotations. The method uses pre-trained DINO ViT features to extract initial sparse keypoint matches through mutual nearest neighbors. An alignment network then maps all images to a shared canonical space, optimized using a multi-term loss function that includes keypoint consistency, equivariance, reconstruction, and part alignment regularization. The approach produces dense, consistent correspondences across the entire collection, evaluated using PCK and the newly introduced k-CyPCK metric.

## Key Results
- Outperforms existing self-supervised methods on CUB-200 and SPair-71k benchmarks in keypoint consistency
- Achieves higher PCK scores indicating better correspondence accuracy
- Introduces k-CyPCK metric showing improved consistency of keypoint propagation across image sequences
- Demonstrates effectiveness on collections as small as 10-30 images without manual annotations

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Pseudo-correspondences from DINO SSL features serve as accurate initial keypoint matches for training the alignment network
- Mechanism: The alignment network refines noisy sparse pseudo-correspondences by enforcing contrastive consistency across all image pairs, pulling matching keypoints together in canonical space and pushing non-matches apart
- Core assumption: DINO SSL features contain sufficient semantic information to identify corresponding keypoints across images
- Evidence anchors:
  - [abstract] "We use pairwise nearest neighbors obtained from deep features of a pre-trained vision transformer (ViT) model as noisy and sparse keypoint matches"
  - [section] "Prior work has shown that deep features extracted from large pre-trained networks contain useful local semantic information [9, 13, 30]"
- Break condition: If DINO features fail to capture semantic correspondence (e.g., for highly occluded objects or domain shift), the pseudo-correspondences become too noisy to refine effectively

### Mechanism 2
- Claim: Joint canonical space mapping enables dense and consistent correspondences across the entire image collection
- Mechanism: The alignment network maps all images to a shared canonical grid, ensuring that semantically similar pixels from different images are aligned to the same location in the canonical space
- Core assumption: A shared canonical grid can represent diverse object instances within a category despite variations in pose, shape, and texture
- Evidence anchors:
  - [abstract] "We use pairwise nearest neighbors obtained from deep features of a pre-trained vision transformer (ViT) model as noisy and sparse keypoint matches and make them dense and accurate matches by optimizing a neural network that jointly maps the image collection into a learned canonical grid"
  - [section] "We want to train an alignment network Φalign that takes a single image as input at a time and outputs C = Φalign(I), the canonical space coordinate map, of the image"
- Break condition: If the canonical grid cannot accommodate large deformations or viewpoint changes, the mapping becomes inconsistent and correspondences degrade

### Mechanism 3
- Claim: Self-supervised regularization terms (equivariance, reconstruction, part alignment) improve the quality and density of learned correspondences
- Mechanism: Geometric equivariance ensures the mapping is consistent under synthetic transformations, reconstruction loss improves perceptual similarity, and part alignment encourages semantically similar regions to map to nearby locations in canonical space
- Core assumption: These auxiliary losses provide useful inductive biases that guide the network toward meaningful dense correspondences without requiring labeled data
- Evidence anchors:
  - [section] "We introduce additional regularization via equivariance and reconstruction terms to get dense correspondences across collection"
  - [section] "In order to make them accurate, we enforce pair-wise consistency across the image collection with an alignment network and a self-supervised keypoint consistency loss"
- Break condition: If the regularization terms are too strong or poorly weighted, they may over-constrain the solution and prevent the network from learning the true dense correspondences

## Architecture Onboarding

- Component map: Input images -> DINO feature extraction -> Mutual nearest neighbors computation -> U-Net alignment network (Φalign) -> Shared canonical grid (G) -> Differentiable warp operation -> Loss computation

- Critical path:
  1. Extract DINO features from all images
  2. Compute mutual nearest neighbors for all image pairs
  3. Initialize canonical grid G randomly
  4. Train Φalign using the multi-term loss function
  5. Evaluate dense correspondences using PCK and k-CyPCK metrics

- Design tradeoffs:
  - Small dataset size (10-30 images) vs. need for dense correspondences
  - Trade-off between alignment accuracy and computational efficiency
  - Balancing different loss terms to avoid over-regularization

- Failure signatures:
  - Poor PCK scores indicate failure to establish accurate correspondences
  - Inconsistent canonical space mappings across the collection
  - Degenerate solutions where the alignment network collapses to a trivial mapping

- First 3 experiments:
  1. Test the alignment network on a simple dataset with minimal pose variation to verify basic functionality
  2. Evaluate the impact of different loss weightings on correspondence quality
  3. Compare performance with and without the geometric equivariance regularization

## Limitations
- The method relies heavily on the quality of DINO SSL features, which may not generalize well to highly occluded objects or significant domain shifts
- The small dataset size (10-30 images) raises questions about scalability to larger collections
- The learned canonical space representation may struggle with extreme pose variations
