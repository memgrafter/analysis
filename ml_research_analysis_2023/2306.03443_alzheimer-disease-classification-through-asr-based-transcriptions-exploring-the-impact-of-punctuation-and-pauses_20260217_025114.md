# Alzheimer Disease Classification through ASR-based Transcriptions: Exploring the Impact of Punctuation and Pauses
## Quick Facts
- arXiv ID: 2306.03443
- Source URL: https://arxiv.org/abs/2306.03443
- Reference count: 0
- ASR-based transcription with pause encoding achieves 0.833 accuracy for AD classification

## Executive Summary
This study investigates Alzheimer's disease classification using automatic speech recognition (ASR) transcriptions, comparing manual and ASR-based approaches. The research evaluates traditional machine learning (SVM, KNN) using LIWC features against deep learning (biLSTM) using FastText embeddings, while examining the impact of pause encoding and punctuation on classification performance. Results demonstrate that manual transcriptions yield slightly better accuracy (0.854) than ASR-based transcriptions (0.833), but the difference is minimal. Deep learning approaches generally outperform traditional ML methods, and pause encoding significantly improves classification accuracy for both transcription types. The findings suggest that high-quality ASR transcriptions, combined with pause encoding, can achieve comparable AD classification results to manual transcriptions, offering a promising scalable solution for automatic AD screening.

## Method Summary
The study employed the Whisper-large ASR model to generate transcriptions from speech data, achieving a word error rate (WER) of 30.18%. These ASR transcriptions included automatic punctuation. The research compared traditional machine learning classifiers (SVM and KNN) using Linguistic Inquiry and Word Count (LIWC) features with deep learning approaches (biLSTM) using FastText embeddings. The investigation focused on the impact of two key factors: pause encoding and punctuation. The study used manual transcriptions as a baseline for comparison and evaluated performance across different combinations of transcription type, pause encoding, and punctuation handling.

## Key Results
- Manual transcriptions achieved slightly higher accuracy (0.854) than ASR-based transcriptions (0.833)
- Deep learning approaches (biLSTM) generally outperformed traditional ML methods (SVM, KNN)
- Pause encoding significantly improved classification accuracy for both manual and ASR-based transcriptions
- Punctuation had minimal impact on classification performance

## Why This Works (Mechanism)
The study demonstrates that speech patterns associated with Alzheimer's disease can be effectively captured through ASR transcriptions, even with moderate transcription errors. The biLSTM architecture's ability to learn sequential dependencies in text embeddings allows it to extract meaningful features from speech transcripts that distinguish AD patients from healthy controls. Pause encoding provides critical temporal information about speech patterns that traditional word-based features may miss, capturing the characteristic speech disruptions and hesitations associated with cognitive decline.

## Foundational Learning
- **Automatic Speech Recognition (Whisper-large)**: Converts spoken language to text with automatic punctuation. Needed to scale AD screening beyond manual transcription capabilities. Quick check: WER=30.18% indicates reasonable transcription quality for feature extraction.
- **Linguistic Inquiry and Word Count (LIWC)**: Provides psychologically meaningful word categories for text analysis. Needed to capture language patterns associated with cognitive decline. Quick check: Used as baseline features for traditional ML models.
- **FastText Embeddings**: Generates dense vector representations of words that capture semantic relationships. Needed to provide rich input features for deep learning models. Quick check: Input to biLSTM for sequential pattern learning.
- **Pause Encoding**: Represents timing information between speech segments. Needed to capture temporal speech patterns characteristic of AD. Quick check: Improves accuracy from baseline to 0.854 (manual) and 0.833 (ASR).
- **biLSTM Networks**: Processes sequential data bidirectionally to capture context from both directions. Needed to learn complex temporal patterns in speech transcripts. Quick check: Generally outperforms traditional ML across conditions.

## Architecture Onboarding
**Component Map**: Speech Audio -> ASR (Whisper-large) -> Text Transcriptions -> Feature Extraction (LIWC/FastText) -> Pause Encoding -> Classification Model (SVM/KNN/biLSTM) -> AD Prediction

**Critical Path**: ASR Transcription -> Pause Encoding -> Classification Model (biLSTM) -> AD Classification

**Design Tradeoffs**: Traditional ML (SVM/KNN) offers faster training and interpretability but captures less complex patterns than biLSTM. biLSTM requires more computational resources but better captures sequential dependencies in speech patterns.

**Failure Signatures**: 
- High WER (>30%) reduces classification accuracy significantly
- Missing pause encoding eliminates temporal information crucial for AD detection
- Overfitting in biLSTM when training data is limited
- Punctuation errors have minimal impact, suggesting robust feature extraction

## Limitations
- The modest difference (0.021 accuracy) between manual and ASR-based transcriptions may not translate to clinical significance
- The study used a relatively small sample size, limiting generalizability
- Whisper-large model's WER=30.18% suggests substantial transcription errors that could impact real-world applicability

## Confidence
- High confidence: Pause encoding significantly improves classification accuracy across both transcription types
- Medium confidence: Deep learning approaches generally outperform traditional ML methods
- Medium confidence: Punctuation has minimal impact on classification performance
