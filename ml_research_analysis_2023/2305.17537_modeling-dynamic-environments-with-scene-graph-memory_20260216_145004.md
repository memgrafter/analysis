# Modeling Dynamic Environments with Scene Graph Memory

## Quick Facts
- arXiv ID: 2305.17537
- Source URL: https://arxiv.org/abs/2305.17537
- Reference count: 36
- This paper introduces a novel approach to temporal link prediction in partially observable dynamic graphs for embodied AI agents to efficiently search for objects in dynamic environments.

## Executive Summary
This paper addresses the challenge of enabling embodied AI agents to efficiently search for objects in dynamic household environments where full observability is not possible. The authors propose a Scene Graph Memory (SGM) representation that aggregates partial observations over time, combined with a Node Edge Predictor (NEP) neural network architecture that predicts object locations. The NEP uses a novel combination of graph neural networks and transformer encoders to process the SGM and make predictions about where objects are likely to be found. The approach is evaluated on a new Dynamic House Simulator benchmark that creates diverse dynamic environments with realistic object movement patterns.

## Method Summary
The proposed method consists of two main components: the Scene Graph Memory (SGM) and the Node Edge Predictor (NEP). The SGM accumulates observations over time into a single graph structure, preserving temporal features like time since last observation and observation count for each node and edge. The NEP then processes this aggregated graph using a combination of graph neural networks for feature propagation and a transformer encoder for joint evaluation of query edges. The model is trained on 10,000 SGMs generated from 100 diverse household environments in the Dynamic House Simulator, which simulates realistic object movements and partial observability conditions.

## Key Results
- The NEP model significantly outperforms baselines including Random, Frequentist, Priors, Myopic, HMS, and Bayesian methods in terms of accuracy for Predict Object Location task.
- The model demonstrates superior adaptability and efficiency in finding objects in dynamic scenes compared to existing approaches.
- Experiments show the NEP's effectiveness in handling partial observability and dynamic node additions/removals in the scene graph.

## Why This Works (Mechanism)

### Mechanism 1
The Scene Graph Memory (SGM) enables the agent to accumulate and leverage partial observations over time, compensating for the inability to observe the full environment at any single timestep. The SGM aggregates all observed nodes and edges into a single graph structure, preserving temporal features for each node and edge. This allows the Node Edge Predictor (NEP) to learn environment-specific dynamics from incomplete data. The core assumption is that temporal features in the SGM are sufficient for the model to infer object movement patterns and edge changes without full observability.

### Mechanism 2
The Node Edge Predictor (NEP) architecture, combining GNNs with a transformer encoder, effectively propagates and fuses information across the SGM to predict query edge likelihoods. The NEP first embeds nodes and edges using MLPs, then fuses node embeddings for each query edge, and finally applies a transformer encoder to jointly evaluate all query edges using self-attention. The core assumption is that the combination of GNN-based feature propagation and transformer-based edge comparison is superior to models that reason about edges independently.

### Mechanism 3
The Dynamic House Simulator provides a realistic benchmark for evaluating link prediction in partially observable dynamic graphs by simulating diverse object movement patterns and partial observability. The simulator generates environments with unique initial scene graphs and object dynamics, allowing agents to collect observations and build SGMs over time. The core assumption is that the simulator's object movement dynamics and partial observability realistically reflect the challenges faced by embodied AI agents in household environments.

## Architecture Onboarding

- Component map: Dynamic House Simulator -> Agent collects observations -> SGM is built -> NEP processes SGM -> Predictions are made -> Agent uses predictions to guide actions
- Critical path: The agent interacts with the Dynamic House Simulator, collecting partial observations that are aggregated into the SGM. The NEP then processes this SGM to make predictions about object locations, which the agent uses to guide its search actions.
- Design tradeoffs:
  - Using SGM vs. recurrent models: SGM collapses the observation sequence into a single graph, simplifying the model but potentially losing some temporal information.
  - NEP architecture: Combining GNNs and transformers provides powerful feature propagation and edge comparison, but may be computationally expensive.
  - Partial observability: Introducing partial observability makes the problem more realistic but also more challenging.
- Failure signatures:
  - If the model fails to adapt to new environments: Check if the SGM is capturing sufficient temporal features and if the NEP is effectively learning from them.
  - If the model is slow to adapt: Check if the transformer encoder is effectively comparing query edges and if the GNN layers are properly propagating information.
  - If the model performs poorly on dynamic nodes: Check if the SGM is accurately tracking node additions and removals and if the NEP is handling these changes.
- First 3 experiments:
  1. Evaluate the NEP's performance on a static environment with full observability to establish a baseline.
  2. Introduce partial observability and dynamic nodes to test the model's adaptability.
  3. Vary the object movement patterns and observation noise to assess the model's robustness.

## Limitations

- The Dynamic House Simulator, while innovative, may not fully capture the complexity of real-world household environments with its simplified object movement patterns and partial observability settings.
- The effectiveness of the NEP architecture, particularly the combination of GNNs and transformers, is not thoroughly validated through ablation studies to isolate component contributions.
- The evaluation focuses on specific tasks and metrics, leaving unknown how the model performs on other relevant tasks or in terms of computational efficiency for practical deployment.

## Confidence

- High confidence: The problem formulation of temporal link prediction in partially observable dynamic graphs is novel and well-motivated.
- Medium confidence: The Scene Graph Memory (SGM) representation and Node Edge Predictor (NEP) architecture are effective in the proposed benchmark.
- Low confidence: The model's performance and generalization to real-world environments and more complex dynamics.
