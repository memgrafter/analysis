# Mutilmodal Feature Extraction and Attention-based Fusion for Emotion Estimation in Videos

## Quick Facts
- arXiv ID: 2303.10421
- Source URL: https://arxiv.org/abs/2303.10421
- Reference count: 32
- F1 score of 0.361 on Aff-Wild2 validation set using attention-based multimodal fusion

## Executive Summary
This work addresses emotion estimation from videos by fusing facial, audio, and pose features using an attention-based framework. The authors propose aligning temporal features across modalities with current-frame facial features to improve expression recognition. Their method processes temporal sequences from each modality through RNNs and cross-attends them with the current face feature before concatenation and classification. Evaluated on the Aff-Wild2 dataset for the ABAW 2023 challenge, the approach achieves an F1 score of 0.361 on the validation set, outperforming simple concatenation-only fusion methods.

## Method Summary
The framework extracts face features using a fine-tuned FAN network, audio features via DeepSpectrum, and pose features using OpenPose. Temporal sequences from each modality are processed through RNNs and cross-attended with the current face feature, then concatenated and classified. The attention mechanism aligns temporal features across modalities with current-frame facial features to capture cross-modal dependencies. The method was evaluated on the Aff-Wild2 dataset for the ABAW 2023 challenge.

## Key Results
- Achieved F1 score of 0.361 on Aff-Wild2 validation set
- Outperformed concatenation-only fusion methods
- Demonstrated effectiveness of attention-based multimodal fusion for emotion estimation

## Why This Works (Mechanism)
The attention-based fusion framework works by aligning temporal features across modalities with current-frame facial features. This cross-modal attention mechanism captures dependencies between different input types (face, audio, pose) while maintaining temporal context through RNN processing. By focusing on relevant temporal information from each modality relative to the current facial expression, the model can better recognize complex emotional states that manifest across multiple channels.

## Foundational Learning
- **Multimodal fusion**: Combining information from multiple input sources (visual, audio, pose) to improve prediction accuracy - needed because emotions are expressed through multiple channels simultaneously
- **Temporal sequence processing**: Using RNNs to capture temporal dependencies in sequential data - required to understand how expressions evolve over time
- **Cross-modal attention**: Mechanism to align features from different modalities based on relevance - essential for identifying which aspects of one modality are most informative given another
- **Feature extraction networks**: Specialized networks (FAN, DeepSpectrum, OpenPose) to extract meaningful representations from raw data - necessary to convert raw inputs into usable features
- **Validation set evaluation**: Testing model performance on held-out data - critical for assessing generalization ability
- **F1 score metric**: Harmonic mean of precision and recall - appropriate for imbalanced emotion classification tasks

## Architecture Onboarding

Component map: Raw video -> Face feature extraction -> Temporal RNN -> Attention mechanism <- Temporal RNN <- Audio feature extraction <- Raw video
                                                                                                    |
                                                                                                    -> Temporal RNN -> Pose feature extraction -> Raw video

Critical path: Feature extraction (Face/Audio/Pose) -> RNN processing -> Cross-modal attention -> Concatenation -> Classification

Design tradeoffs: The framework trades computational complexity (multiple feature extractors + RNNs + attention) for improved emotion recognition accuracy. The attention mechanism adds parameter overhead but enables better cross-modal alignment.

Failure signatures: Poor performance on individual modalities may indicate issues with feature extraction quality. Low attention weights across modalities might suggest feature misalignment or insufficient training data for certain emotion classes.
