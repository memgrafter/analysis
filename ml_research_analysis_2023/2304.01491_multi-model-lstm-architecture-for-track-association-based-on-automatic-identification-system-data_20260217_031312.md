# Multi model LSTM architecture for Track Association based on Automatic Identification System Data

## Quick Facts
- arXiv ID: 2304.01491
- Source URL: https://arxiv.org/abs/2304.01491
- Reference count: 11
- Multi-model LSTM framework achieves high precision, recall, accuracy, and F1 scores for vessel track association using AIS data

## Executive Summary
This paper presents a multi-model LSTM framework for track association of marine vessels using Automatic Identification System (AIS) data. The approach trains separate LSTM models for each vessel to predict locations based on historical spatio-temporal data, then uses Haversine distance as a similarity metric to associate unclassified observations to their true tracks. The model achieves high precision, recall, accuracy, and F1 scores for most vessels, with vessel three showing 100% precision and vessel four achieving 0.990 recall. However, performance was lower for vessels with overlapping data points.

## Method Summary
The method involves training separate LSTM models for each vessel using historical AIS data including timestamps, latitude, longitude, speed, and course. Data is preprocessed through interpolation, resampling at 5-second intervals, and min-max scaling. Each LSTM model uses 3 layers with 32 neurons each and RELU activation. For track association, the trained models predict vessel locations for test AIS messages, and the Haversine formula calculates geodesic distances between predicted and actual locations. The observation with the smallest distance is associated with that vessel's track.

## Key Results
- Vessel three achieved 100% precision in track association
- Vessel four achieved 0.990 recall in track association
- Vessels with overlapping data points showed lower performance scores

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The multi-model LSTM framework can predict vessel location from historical spatio-temporal AIS data.
- Mechanism: Each vessel has a dedicated LSTM model trained on its own historical sequence of longitude, latitude, speed, and direction. The LSTM's memory cells capture temporal dependencies across irregular time intervals by using sliding windows of fixed length.
- Core assumption: Vessel movement patterns are sufficiently regular and predictable based on recent historical data alone.
- Evidence anchors:
  - [abstract] "LSTM is a recurrent neural network architecture that is capable of processing multivariate temporal data collected over time in a sequential manner, enabling it to predict current vessel locations from historical observations."
  - [section] "Our approach involved training each vessel using a separate model in a multi-model fashion."
- Break condition: If vessel movement is highly erratic or influenced by unpredictable external factors (e.g., emergency maneuvers, port restrictions), the LSTM's learned temporal patterns will fail to generalize.

### Mechanism 2
- Claim: Haversine distance between predicted and actual locations serves as an effective similarity metric for track association.
- Mechanism: For each test AIS message, the predicted position from the vessel's LSTM model is compared to all unclassified observations using the Haversine formula. The observation with the smallest geodesic distance is associated with that vessel's track.
- Core assumption: The closest geodesic prediction corresponds to the true vessel track, assuming no other vessel is nearby with similar movement.
- Evidence anchors:
  - [section] "One highly precise geodesic approach for computing the distance between two points on a sphere using their respective latitude and longitude is the haversine formula... By calculating the Haversine distance... the deviation between the predicted location and actual location of the current node can be determined."
- Break condition: If multiple vessels are in close proximity or have overlapping trajectories, the nearest geodesic prediction may incorrectly associate an observation to the wrong track.

### Mechanism 3
- Claim: Multi-model training improves precision and recall by tailoring predictions to each vessel's specific movement patterns.
- Mechanism: Instead of a single model for all vessels, separate LSTM models capture vessel-specific behaviors (e.g., speed profiles, turning patterns), reducing interference between dissimilar trajectories.
- Core assumption: Vessel-specific models generalize better than a pooled model because each vessel's movement history is sufficiently distinct and consistent.
- Evidence anchors:
  - [abstract] "We propose a Long Short-Term Memory (LSTM) based multi-model framework for track association."
  - [section] "To train the LSTM... we divided the available AIS messages into training and testing sets."
- Break condition: If training data per vessel is too sparse, individual models may overfit or fail to capture generalizable patterns, reducing performance.

## Foundational Learning

- Concept: Time series interpolation and resampling
  - Why needed here: AIS data arrives at irregular intervals; models require evenly spaced inputs for sequence learning.
  - Quick check question: What interpolation method would you use to fill gaps if the sampling interval is 5 seconds but messages arrive every 3-12 seconds?

- Concept: Recurrent neural network memory mechanisms
  - Why needed here: LSTMs maintain hidden states across time steps, allowing them to remember long-term dependencies in vessel movement.
  - Quick check question: How does an LSTM's forget gate help prevent the vanishing gradient problem during training?

- Concept: Geodesic distance calculations on a sphere
  - Why needed here: Vessel positions are given in latitude/longitude; straight-line Euclidean distance is inaccurate over Earth's curvature.
  - Quick check question: Write the Haversine formula for distance between two (lat, lon) pairs on a sphere of radius r.

## Architecture Onboarding

- Component map: Data preprocessing -> Interpolation & resampling -> Min-max scaling -> Vessel-specific LSTM models -> Haversine distance computation -> Association decision logic
- Critical path: AIS input -> Preprocess -> Predict location -> Compute Haversine distances -> Assign track
- Design tradeoffs:
  - Multi-model vs. pooled model: Better vessel-specific accuracy vs. higher computational cost and data requirements.
  - Window size choice: Larger windows capture more context but may dilute recent pattern relevance.
  - Interpolation strategy: Linear vs. spline affects smoothness and realism of synthetic timestamps.
- Failure signatures:
  - High false positives when vessels overlap spatially and temporally.
  - Degraded precision when training data per vessel is too limited.
  - Model drift if vessel behavior changes significantly after training period.
- First 3 experiments:
  1. Train a single pooled LSTM on all vessels; compare precision/recall to multi-model.
  2. Vary window size (e.g., 5, 10, 15 timesteps) and measure impact on prediction error.
  3. Introduce synthetic noise in AIS speed/direction fields and test robustness of association accuracy.

## Limitations
- Performance degradation when vessel tracks overlap significantly
- Multi-model approach doesn't scale efficiently for large fleets
- Assumes vessel movement is predictable from historical data alone without external factors

## Confidence

**High Confidence**: The core mechanism of using LSTM for sequence prediction and Haversine distance for similarity measurement is well-established and theoretically sound.

**Medium Confidence**: The multi-model approach shows promising results on the tested dataset, but generalization to diverse maritime environments requires further validation.

**Low Confidence**: Claims about the framework's robustness to irregular AIS sampling and real-world noise levels are not fully substantiated in the paper.
