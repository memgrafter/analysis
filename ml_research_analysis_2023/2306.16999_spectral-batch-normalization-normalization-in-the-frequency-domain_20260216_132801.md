# Spectral Batch Normalization: Normalization in the Frequency Domain

## Quick Facts
- arXiv ID: 2306.16999
- Source URL: https://arxiv.org/abs/2306.16999
- Authors: 
- Reference count: 40
- Key outcome: Introduces spectral batch normalization (SBN) that improves generalization by normalizing feature maps in the frequency domain; improves ResNet50 ImageNet accuracy from 76.80% to 77.51%.

## Executive Summary
This paper introduces spectral batch normalization (SBN), a novel method to improve the generalization of deep neural networks by normalizing feature maps in the frequency domain. The key idea is to compute the 2D discrete Fourier transform of feature maps, normalize the frequency components, and then transform them back to the spatial domain. This approach addresses the issue of exploding feature maps, which can occur in residual networks without batch normalization and negatively impact learning. SBN prevents large feature map norms during training, leading to more uniformly distributed frequency components and discouraging the network from relying on single frequency components.

## Method Summary
SBN is implemented as a normalization layer that transforms feature maps to the frequency domain using 2D discrete Fourier transform, applies channel-wise mean/variance normalization to the frequency coefficients, scales and shifts the normalized frequencies, then transforms back to the spatial domain using inverse 2D DFT. The method is integrated into existing architectures by inserting SBN layers after batch normalization layers in deeper modules. Implementation requires handling complex numbers during frequency-domain operations and careful placement to balance regularization strength with performance.

## Key Results
- ResNet50 on CIFAR-100 improved by 2.31% with SBN
- ResNet50 on ImageNet improved from 76.80% to 77.51% with SBN
- VGG19 on CIFAR-100 improved by 0.66% with SBN
- SBN prevents exploding feature maps and leads to more uniform frequency distributions

- Core assumption: Uniform frequency distribution improves generalization by preventing the network from overfitting to specific spatial patterns.
