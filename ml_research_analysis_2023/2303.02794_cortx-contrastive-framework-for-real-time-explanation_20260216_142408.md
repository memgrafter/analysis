# CoRTX: Contrastive Framework for Real-time Explanation

## Quick Facts
- arXiv ID: 2303.02794
- Source URL: https://arxiv.org/abs/2303.02794
- Reference count: 39
- Primary result: Introduces CoRTX, a contrastive framework for real-time explanation of ML models using contrastive learning to reduce need for large explanation labels

## Executive Summary
CoRTX is a novel contrastive learning framework designed to provide real-time explanations for machine learning models. The framework addresses the challenge of requiring large amounts of labeled explanation data by learning latent explanations through a contrastive learning approach. It employs a synthetic strategy to select positive and negative instances for learning explanations, which theoretically benefits the contrastive learning process. Experimental results on three real-world datasets demonstrate CoRTX's efficiency and effectiveness in providing explanations for both tabular and image data.

## Method Summary
CoRTX operates by learning latent explanations through a contrastive learning framework. The key innovation is the use of a synthetic strategy to generate positive and negative instances for training. This approach reduces the dependency on large amounts of labeled explanation data. The framework employs a contrastive loss function with a temperature parameter τ to guide the learning process. Theoretical analysis supports the benefits of this synthetic strategy in the contrastive learning context. The model is trained to distinguish between positive (similar) and negative (dissimilar) pairs in the latent explanation space.

## Key Results
- CoRTX effectively provides explanations for both tabular and image data across three real-world datasets
- The contrastive learning approach reduces the need for large amounts of explanation labels
- Synthetic strategy for selecting positive and negative instances benefits the contrastive learning process

## Why This Works (Mechanism)
The framework works by leveraging contrastive learning to learn latent representations of explanations. By contrasting positive and negative pairs in the latent space, the model learns to capture meaningful explanations without requiring extensive labeled data. The synthetic strategy for generating these pairs ensures a diverse and informative training set, which enhances the learning process and leads to more robust explanations.

## Architecture Onboarding
**Component Map:** Input Data -> Feature Extractor -> Contrastive Loss with τ -> Latent Explanation Space -> Explanation Output

**Critical Path:** The critical path involves the feature extraction, contrastive loss computation with temperature parameter τ, and the generation of the latent explanation space. The quality of the synthetic strategy for instance selection is crucial for effective learning.

**Design Tradeoffs:** The framework balances between the complexity of the contrastive learning approach and the simplicity of the synthetic strategy. A key tradeoff is the choice of temperature parameter τ, which affects the sharpness of the learned representations.

**Failure Signatures:** Potential failures include poor selection of positive/negative instances, inappropriate choice of τ leading to collapsed representations, and overfitting to synthetic data patterns.
