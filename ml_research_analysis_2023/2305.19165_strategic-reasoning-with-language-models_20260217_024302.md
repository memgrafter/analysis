# Strategic Reasoning with Language Models

## Quick Facts
- arXiv ID: 2305.19165
- Source URL: https://arxiv.org/abs/2305.19165
- Reference count: 40
- Key outcome: LLMs achieve near-perfect generalization to novel game structures using systematic chain-of-thought demonstrations for search, value assignment, and belief tracking.

## Executive Summary
This paper proposes using large language models for strategic reasoning by providing systematically generated chain-of-thought prompts that demonstrate search, value assignment, and belief tracking. The approach enables LLMs to generalize almost perfectly to new game structures, objectives, and hidden information in matrix games, and leads to human-like negotiation strategies in realistic settings without additional training. Key results include achieving near-perfect accuracy on novel matrix games and creating a human-like negotiation agent with higher reward and human-rated scores compared to baselines.

## Method Summary
The paper evaluates LLMs on strategic reasoning tasks using systematically generated chain-of-thought prompts with demonstrations of search, value assignment, and belief tracking. The prompt compiler decomposes games into these three reasoning components and generates few-shot examples. The method is tested on 2x2 matrix games (Prisoner's Dilemma, Chicken, etc.), 2-stage games, and a Deal or No Deal negotiation game dataset using models like code-davinci-002 and text-davinci-003. Performance is measured by accuracy in predicting best responses and comparison with baselines.

## Key Results
- Achieved near-perfect generalization to novel matrix games with systematically generated chain-of-thought prompts
- Created a human-like negotiation agent with higher reward (7.6 vs 6.7) and better human-rated scores than baselines
- Factored reasoning via search() and calculate() tools enables perfect generalization to new games without context overflow

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LLMs can generalize strategic reasoning across new game structures when prompted with systematically generated chain-of-thought demonstrations that include search, value assignment, and belief tracking.
- Mechanism: The prompt compiler decomposes a game into three reasoning components—search (exhaustive exploration of states/actions), value assignment (natural language evaluation of state-action pairs), and belief tracking (inference over hidden information). These demonstrations act as few-shot examples that guide the LLM to replicate the reasoning structure in novel contexts.
- Core assumption: The LLM has sufficient world knowledge in its pretraining to understand the natural language descriptions of strategic concepts and can apply them to unseen payoffs or game structures when given the right scaffolding.
- Evidence anchors:
  - [abstract] "Our approach uses systematically generated demonstrations of reasoning about states, values, and beliefs to prompt the model."
  - [section 3.1] "Our prompt compiler takes an example game and automatically generates an example of strategic reasoning. The compiler decomposes this example into components for search, value assignment, and belief tracking."
- Break condition: If the game complexity exceeds the LLM's context window or if the reasoning traces become too long for the model to maintain coherence, generalization will fail.

### Mechanism 2
- Claim: Factored reasoning via search and calculate tools enables LLMs to handle games with large action spaces or multiple players without losing reliability.
- Mechanism: When exhaustive search is impractical, the model dispatches sub-tasks to new contexts using "search()" and "calculate()" tools. This modular decomposition prevents context overflow and maintains reasoning fidelity in larger games.
- Core assumption: The LLM can correctly interpret and execute tool calls within the prompt, and the tool outputs can be integrated back into the reasoning flow without loss of coherence.
- Evidence anchors:
  - [section 4.1.2] "When we use factored search and reasoning, this is not a limitation and the model generalizes to the new games perfectly."
- Break condition: If the tool invocation syntax is misinterpreted or if the LLM fails to correctly integrate sub-results, the reasoning will break down.

### Mechanism 3
- Claim: Belief tracking over hidden states or opponent values allows LLMs to perform well in partially observable strategic settings without explicit training on those scenarios.
- Mechanism: The model searches over possible hidden states, assigns probabilities based on observed actions/rewards, and updates beliefs iteratively. This mirrors human-like inference under uncertainty.
- Core assumption: The LLM can maintain and update probabilistic beliefs through natural language reasoning steps, and these beliefs influence subsequent action selection appropriately.
- Evidence anchors:
  - [section 4.3.1] "We estimate beliefs about the hidden information such as values of players or non-observable states by searching through the possible space of hidden information."
  - [section 4.3.2] "Our method outperforms baselines on multiple metrics...achieving a higher average reward (7.6) compared to the 'no belief' model (6.7)."
- Break condition: If the belief update logic is flawed or if the model fails to incorporate new evidence correctly, performance will degrade.

## Architecture Onboarding

- Component map:
  - Prompt compiler -> LLM inference engine -> Tool interface -> Evaluation harness
  - Game rules -> Structured demonstration -> Action choice -> Reward feedback

- Critical path:
  1. Game rules → Prompt compiler → Structured demonstration
  2. Demonstration + game → LLM → Action choice
  3. Action choice → Game engine → Reward feedback (if any)

- Design tradeoffs:
  - Context length vs. reasoning depth: Longer traces improve reasoning but risk exceeding context limits.
  - Tool granularity vs. overhead: Finer decomposition helps but adds complexity.
  - Demonstration simplicity vs. expressiveness: Simpler demos generalize better but may miss nuances.

- Failure signatures:
  - Incoherent reasoning traces (model loses track of logic).
  - Repeated incorrect action selection despite demonstrations.
  - Context overflow errors or truncated reasoning.

- First 3 experiments:
  1. Run a 2x2 matrix game with the strategic prompt vs. a direct answer prompt; compare accuracy.
  2. Test a 4x4 matrix game with factored reasoning vs. without; measure performance drop.
  3. Evaluate belief tracking in a partially observable game by hiding state information and measuring inference accuracy.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of strategic reasoning with LLMs scale with the complexity of the game (e.g., larger action spaces, more players)?
- Basis in paper: [inferred] The paper mentions that as the size of the games increases, the language model is unable to keep up with the complexity of the problem, primarily due to its limited context size. The paper proposes factoring reasoning via search and calculate tools to address this limitation.
- Why unresolved: The paper only provides results for games with up to 6 actions and 5 players. It does not explore how the performance scales with even larger games or how the factored reasoning approach performs in those cases.
- What evidence would resolve it: Experimental results showing the performance of the LLM on games with larger action spaces and more players, both with and without the factored reasoning approach.

### Open Question 2
- Question: How well do the LLMs generalize to games with completely new rules and mechanics, beyond just variations in payoffs and objectives?
- Basis in paper: [inferred] The paper focuses on evaluating the LLMs on variations of matrix games and negotiation games, but does not explicitly test generalization to games with entirely new rules or mechanics.
- Why unresolved: The paper does not provide evidence for how well the LLMs can adapt to games with completely different structures or dynamics.
- What evidence would resolve it: Experimental results showing the performance of the LLMs on games with novel rules and mechanics, beyond just variations of existing game types.

### Open Question 3
- Question: How does the performance of strategic reasoning with LLMs compare to traditional game-theoretic approaches, such as finding Nash equilibria?
- Basis in paper: [explicit] The paper does not focus on finding equilibria in this work, but mentions that the search and best-response strategies proposed could potentially be extended to level-k reasoning, which converges on equilibrium.
- Why unresolved: The paper does not provide a direct comparison between the LLM-based approach and traditional game-theoretic methods for finding equilibria.
- What evidence would resolve it: Experimental results comparing the performance of the LLM-based approach to traditional methods for finding equilibria in various game types.

## Limitations
- The approach relies heavily on synthetic game generation rather than testing in real-world strategic environments, which may limit ecological validity.
- Performance scaling with game complexity is uncertain, particularly for games with large action spaces or many players.
- Limited evaluation of belief tracking robustness in partially observable settings with no analysis of belief update accuracy.

## Confidence

- **High confidence**: Systematic chain-of-thought demonstrations improve strategic reasoning accuracy compared to direct answer prompts, supported by consistent performance gains across multiple game types.
- **Medium confidence**: Factored reasoning via tools scales to larger games without performance degradation, though edge cases where tool invocation might fail are unexplored.
- **Low confidence**: Belief tracking mechanism's robustness in partially observable settings, given limited evaluation and no analysis of belief update accuracy.

## Next Checks

1. Test the prompting strategy on continuous-action games (e.g., bidding games with real-valued offers) to assess whether natural language reasoning can handle non-discrete strategy spaces.
2. Evaluate performance degradation when prompt demonstrations are systematically degraded (shorter traces, fewer examples, or missing belief tracking components) to identify the minimum viable demonstration set.
3. Conduct a human-subject study where participants play the same games as the LLM to compare strategic reasoning quality and identify whether the model's choices align with human strategic intuitions beyond simple reward maximization.
