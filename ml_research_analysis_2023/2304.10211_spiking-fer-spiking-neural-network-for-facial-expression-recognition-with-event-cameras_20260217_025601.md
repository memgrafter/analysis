# Spiking-Fer: Spiking Neural Network for Facial Expression Recognition With Event Cameras

## Quick Facts
- arXiv ID: 2304.10211
- Source URL: https://arxiv.org/abs/2304.10211
- Reference count: 40
- First use of event cameras for facial expression recognition, achieving comparable accuracy to ANN while consuming up to 65.39× less energy.

## Executive Summary
This paper introduces Spiking-FER, the first application of Spiking Neural Networks (SNNs) to facial expression recognition (FER) using event cameras. The authors convert standard FER video datasets into event streams and propose a novel SNN architecture that encodes these streams into spiking features using a deep convolutional encoder, which are then accumulated and classified. Experiments demonstrate that Spiking-FER achieves accuracy comparable to traditional ANNs while consuming significantly less energy—up to 65.39× more efficient—making it highly suitable for low-power edge devices. The study also evaluates event-based data augmentation techniques, showing improvements in both SNN and ANN performance.

## Method Summary
The Spiking-FER architecture converts video FER datasets (ADFES, CASIA, CK+, MMI) into event streams using a V2E converter. These events are preprocessed into binary spike tensors and fed into a SEW-ResNet-18-based SNN encoder, which processes them through Integrate-and-Fire spiking neurons to extract temporal and spatial features. The spiking features are accumulated over time using an output accumulator module with a fully connected layer, and finally classified using a linear classifier. The model is trained using Surrogate Gradient Learning with cross-entropy loss, SGD optimizer, and cosine annealing for 500 epochs. Event-based data augmentation techniques like EventDrop and Mirror are applied to improve generalization.

## Key Results
- Spiking-Fer achieves comparable accuracy to ANN on benchmark FER datasets while consuming 65.39× less energy.
- Event-based data augmentation techniques (EventDrop, Mirror) significantly improve both SNN and ANN performance.
- The proposed approach is the first to use event cameras for FER, establishing a new benchmark for energy-efficient, edge-deployable FER systems.

## Architecture Onboarding

- Component map:
  Input (event streams) -> SEW-ResNet-18-based SNN encoder -> Spiking features extraction -> Output accumulator module -> Linear classifier -> Final emotion prediction

- Critical path:
  1. Convert video FER datasets to event streams using V2E converter
  2. Preprocess event streams into spike tensors (binary event frames)
  3. Feed spike tensors into Spiking-FER encoder
  4. Extract spiking features at each time-step
  5. Accumulate features over time using output accumulator
  6. Classify accumulated features using linear classifier
  7. Train model using Surrogate Gradient Learning and cross-entropy loss
  8. Evaluate performance on held-out test sets using cross-validation

- Design tradeoffs:
  - Encoder architecture: Deeper encoders may capture more complex features but increase computational cost and risk overfitting on limited FER data.
  - Accumulation time: Longer accumulation may capture more temporal information but increase latency and risk of feature degradation.
  - Data augmentation: More aggressive augmentation may improve generalization but risk introducing artifacts that harm performance.
  - Training parameters: Higher learning rates may speed up convergence but risk instability, while lower rates may lead to suboptimal solutions.

- Failure signatures:
  - Low accuracy: Encoder fails to capture relevant features, accumulation loses critical information, or classifier cannot distinguish between emotion classes.
  - High energy consumption: Inefficient encoder architecture, suboptimal accumulation process, or inadequate data augmentation leading to poor generalization.
  - Long inference times: Inefficient accumulation process, suboptimal encoder architecture, or insufficient parallelization during inference.
  - Unstable training: Inappropriate learning rate, suboptimal surrogate gradient function, or inadequate regularization leading to overfitting or underfitting.

- First 3 experiments:
  1. Convert a small subset of a video FER dataset to event streams and visualize the resulting spike tensors to ensure correct preprocessing.
  2. Train Spiking-FER on the converted dataset with default parameters and evaluate accuracy to establish a baseline performance.
  3. Experiment with different accumulation times (e.g., 2, 4, 6, 8 time-steps) and compare accuracy and inference times to find the optimal tradeoff.

## Limitations

- Energy efficiency comparisons are estimated via FLOP-based methods rather than measured on actual neuromorphic hardware, introducing potential inaccuracies in real-world power consumption claims.
- The event conversion process from video datasets using V2E converter may introduce artifacts or information loss that affects FER performance, though this is not extensively validated.
- Limited evaluation to four datasets (ADFES, CASIA, CK+, MMI) with relatively small sample sizes may constrain generalizability of results to broader FER applications.

## Confidence

- **High confidence** in the core claim that Spiking-FER achieves comparable accuracy to ANN while demonstrating superior energy efficiency through event-driven processing.
- **Medium confidence** in the specific energy efficiency gains (65.39×) due to reliance on estimated rather than measured power consumption metrics.
- **Medium confidence** in the effectiveness of proposed data augmentation techniques, as results show improvement but lack comparison to established augmentation methods.
