# Contrastive Multi-view Framework for Customer Lifetime Value Prediction

## Quick Facts
- **arXiv ID:** 2306.14400
- **Source URL:** https://arxiv.org/abs/2306.14400
- **Reference count:** 40
- **Primary result:** CMLTV achieves 32.26% increase in total payment amount in online A/B testing on Huawei's mobile game center

## Executive Summary
The paper presents CMLTV, a novel approach to predicting customer lifetime value (LTV) that addresses challenges of sparse and noisy consumption data. The method combines multi-view regression with hybrid contrastive learning to capture complementary knowledge and exploit sample relatedness. The model demonstrates strong performance improvements over baselines across multiple metrics and achieves significant results in real-world deployment, showing a 32.26% increase in total payment amount through online A/B testing on Huawei's mobile game center.

## Method Summary
CMLTV integrates a multi-view regression framework with hybrid contrastive learning to predict customer lifetime value. The approach leverages multiple heterogeneous regressors to capture complementary knowledge and improve robustness, while contrastive learning exploits sample relatedness to mitigate data sparsity issues. The model combines predictions from both classification and regression tasks, creating a comprehensive framework for LTV prediction that performs well even with limited and noisy consumption data.

## Key Results
- Achieves state-of-the-art performance across multiple metrics (RMSE, MAE, Pearson/Spearman correlation, R2 score, AUC)
- Demonstrates 32.26% increase in total payment amount in online A/B testing on Huawei's mobile game center
- Shows superior performance on a large-scale game LTV dataset compared to baseline methods

## Why This Works (Mechanism)
The effectiveness of CMLTV stems from its ability to leverage multiple heterogeneous regressors that capture different aspects of customer behavior, combined with contrastive learning that identifies and exploits relationships between samples. This dual approach addresses both data sparsity and noise issues by learning complementary representations from different perspectives while also leveraging the inherent structure in the data through contrastive objectives. The integration of classification and regression predictions provides a more robust and comprehensive prediction framework.

## Architecture Onboarding

**Component Map:** Input data -> Heterogeneous regressors -> Contrastive learning module -> Prediction fusion -> Output

**Critical Path:** Data preprocessing -> Multi-view regression -> Contrastive learning -> Prediction integration -> LTV estimation

**Design Tradeoffs:** The framework trades increased computational complexity for improved prediction accuracy and robustness. The use of multiple heterogeneous regressors and contrastive learning requires more resources but provides better handling of sparse data compared to simpler single-model approaches.

**Failure Signatures:** Poor performance may indicate insufficient sample relatedness in the data, failure of contrastive learning to capture meaningful patterns, or lack of complementary information among heterogeneous regressors. Degradation could also occur if classification and regression predictions are not properly integrated.

## Limitations
- Evaluation focused primarily on a single large-scale game LTV dataset, limiting generalizability to other industries
- Lack of ablation studies makes it difficult to isolate contributions of individual components (hybrid contrastive learning vs. multi-view regression)
- Online A/B test results presented without statistical significance testing or error margins, raising reproducibility concerns

## Confidence

**High confidence:** The core architectural approach (multi-view regression + contrastive learning) is technically sound and the offline metric improvements are well-documented

**Medium confidence:** The superiority over baselines is demonstrated but not conclusively isolated to specific components

**Low confidence:** The claimed 32.26% online improvement without supporting statistical analysis
