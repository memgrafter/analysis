# Balancing Efficiency vs. Effectiveness and Providing Missing Label Robustness in Multi-Label Stream Classification

## Quick Facts
- arXiv ID: 2310.00665
- Source URL: https://arxiv.org/abs/2310.00665
- Reference count: 40
- ML-BELS outperforms 11 state-of-the-art baselines in effectiveness metrics (accuracy, F1-score, micro-F1) and runtime on 18 datasets

## Executive Summary
This paper introduces ML-BELS, a novel neural network approach for multi-label data stream classification that addresses three key challenges simultaneously: balancing efficiency and effectiveness, handling concept drift, and robustness to missing labels. The model uses a binary relevance approach with a Broad Ensemble Learning System (BELS) as its base classifier, combined with a weighting mechanism to incorporate label dependencies. ML-BELS employs selective concept drift adaptation through per-class ensemble instances and handles missing labels using simple imputation. Experimental results demonstrate superior performance compared to 11 baselines across effectiveness metrics and runtime efficiency.

## Method Summary
ML-BELS is a multi-label stream classification model that uses BELS as a base classifier in a binary relevance framework. The approach includes a weighting mechanism based on single-label classifier predictions to incorporate label dependencies, selective concept drift adaptation at the class level through per-class ensemble instances, and missing label imputation. The model is designed to be computationally efficient by using BELS's lightweight architecture that requires only least squares solutions rather than deep neural networks.

## Key Results
- ML-BELS achieves superior effectiveness metrics (accuracy, F1-score, micro-F1) compared to 11 state-of-the-art baselines on 18 datasets
- The model demonstrates significant runtime efficiency improvements, particularly on high-dimensional data
- ML-BELS maintains competitive performance even with only 10% labeled data in missing label settings
- The selective concept drift adaptation mechanism effectively handles sudden, gradual, and recurring drifts

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using BELS as the base classifier in binary relevance reduces computational cost while maintaining accuracy
- Mechanism: BELS uses least squares solution and a compact architecture (feature mapping + enhancement layer) instead of deep neural networks. Only the output layer is replicated per class label in binary relevance, avoiding expensive feature extraction for each ensemble member
- Core assumption: The feature representation learned by BELS is sufficient for all binary classification tasks in the ensemble
- Evidence anchors:
  - [abstract] "We choose BELS as the base classifier [11]. In BELS, the ensemble is built using the output layer nodes of BELS as its components, where only a least square solution is needed to predict the labels."
  - [section 4.1] "For this purpose, we choose BELS as the base classifier [11]. In BELS, the ensemble is built using the output layer nodes of BELS as its components, where only a least square solution is needed to predict the labels."

### Mechanism 2
- Claim: Weighting mechanism based on single-label BELS predictions incorporates label dependencies in binary relevance
- Mechanism: A single-label BELS classifier generates prediction scores that are normalized and used as weights for binary relevance outputs. This encodes feature-feature and label-label dependencies
- Core assumption: Prediction scores from the single-label classifier are correlated with true label dependencies
- Evidence anchors:
  - [abstract] "Instead of a chain of stacked classifiers, our model employs independent weighted ensembles, with the weights generated by the predictions of a BELS classifier."
  - [section 4.2] "To solve this issue, we generate a set of weights for each component of binary relevance. The weights are the predictions of a single-label classifier."

### Mechanism 3
- Claim: Selective concept drift adaptation through per-class ensemble allows faster recovery than global approaches
- Mechanism: Each class label maintains its own ensemble of output layer instances. Instances are removed/replaced based on example-based accuracy thresholds. A pool allows retrieval of previously good performers
- Core assumption: Concept drift affects different class labels at different times and severities
- Evidence anchors:
  - [abstract] "Our model uses a selective concept drift adaptation mechanism that makes it suitable for a non-stationary environment."
  - [section 4.3] "In our approach, we react to drifts inside each binary relevance component. With this approach, our model is capable of handling class-level drifts and only the component responsible for that class label is updated for the drift."

## Architecture Onboarding

- Component map: Feature mapping layer → Enhancement layer → Binary relevance ensembles (one per class) → Single-label BELS for weighting → Selective concept drift adaptation (per-class) → Missing label handling (imputation)
- Critical path: Input → BELS feature extraction (once per chunk) → All binary relevance components → Weighting decision (based on label cardinality) → Final prediction
- Design tradeoffs: Computational efficiency (BELS lightweight architecture) vs. modeling capacity (no deep feature extraction per ensemble member)
- Failure signatures: Accuracy drops on datasets with very high label cardinality despite weighting; runtime increases linearly with number of class labels

## Limitations

- The paper's effectiveness claims rely heavily on comparisons with 11 baseline methods, but specific baseline implementations and hyperparameter settings are not fully detailed
- The weighting mechanism's reliance on label cardinality threshold (τ=1.5) may not generalize well to datasets with extreme cardinality distributions
- The selective concept drift adaptation approach assumes class-level drift independence, which may not hold for datasets with global drift patterns
