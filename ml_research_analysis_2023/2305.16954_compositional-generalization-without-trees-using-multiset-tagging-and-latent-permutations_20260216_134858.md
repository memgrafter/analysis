# Compositional Generalization without Trees using Multiset Tagging and Latent Permutations

## Quick Facts
- arXiv ID: 2305.16954
- Source URL: https://arxiv.org/abs/2305.16954
- Reference count: 29
- Primary result: For the first time, a model without trees achieves high accuracy on deeper recursion generalization on COGS

## Executive Summary
This paper tackles the problem of compositional generalization in semantic parsing, where sequence-to-sequence models struggle to handle novel compositions of linguistic phenomena. The authors propose a two-step approach: first predicting multisets of output tokens for each input token, then arranging these tokens into a sequence using a flexible permutation model. Unlike prior work that restricts permutations through formalisms like synchronous context-free grammars, this method uses an entropy-regularized linear program that can predict any permutation. The approach demonstrates strong performance on realistic semantic parsing tasks and achieves state-of-the-art results on COGS for non-tree-based models.

## Method Summary
The method consists of two stages: (1) Multiset tagging, where each input token is tagged with a multiset of output tokens, and (2) Permutation, where these tokens are arranged into a sequence using a GPU-friendly algorithm based on Bregman's method. The permutation prediction is formulated as an entropy-regularized linear program that is solved using KL projections. The approach uses pretrained RoBERTa embeddings and does not rely on tree structures or other a priori restrictions on permutations.

## Key Results
- Outperforms pretrained seq2seq models and prior work on realistic semantic parsing tasks requiring generalization to longer examples
- Achieves state-of-the-art results for non-tree-based models on COGS structural generalization tasks
- First model without trees to achieve high accuracy on generalization to deeper recursion on COGS

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The two-step process (multiset tagging + permutation) allows the model to separate lexical matching from structural arrangement, improving compositional generalization.
- Mechanism: First predicts which output tokens belong to each input token as multisets, decoupling token identity from order. Then arranges these tokens into the correct sequence using a flexible permutation model.
- Core assumption: The systematic correspondence between input and output tokens is largely invariant to context and recursion depth.
- Evidence anchors:
  - [abstract] "We phrase semantic parsing as a two-step process: we first tag each input token with a multiset of output tokens. Then we arrange the tokens into an output sequence..."
  - [section] "In order for a model to generalize compositionally in semantic parsing, it has to identify reusable ‘fragments’ and be able to systematically combine them in novel ways."
- Break condition: If correspondence between input and output tokens is highly context-dependent, the multiset tagging step would fail.

### Mechanism 2
- Claim: The entropy-regularized linear program allows handling any permutation without restrictions from formalisms like synchronous context-free grammars.
- Mechanism: Permutation is parameterized as a matrix V and scored using features for start/end tokens and "jumps" between tokens. Entropy regularization smooths the solution, making it differentiable.
- Core assumption: Any permutation can be represented as a sequence of jumps that can be effectively scored using a neural network with geometric attention.
- Evidence anchors:
  - [abstract] "We formulate predicting a permutation as solving a regularized linear program and we backpropagate through the solver. In contrast to prior work, our approach does not place a priori restrictions on possible permutations..."
  - [section] "We overcome two key technical challenges in this work: Firstly, we do not have supervision for the correspondence between input tokens and output tokens. Therefore, we induce the correspondence during training."
- Break condition: If entropy regularization is too strong, the solution becomes too smooth and fails to approximate a true permutation.

### Mechanism 3
- Claim: Pretrained RoBERTa embeddings provide strong contextual representations that capture linguistic structure, aiding both steps.
- Mechanism: Input is passed through pretrained RoBERTa encoder, and output hidden states are combined with static word embeddings for multiset tagging and permutation scoring.
- Core assumption: Pretrained RoBERTa has learned useful linguistic representations that transfer to semantic parsing.
- Evidence anchors:
  - [section] "We first pass the input x through a pretrained RoBERTa encoder (Liu et al., 2019), where ENCODER (x) is the output of the final layer. We then add RoBERTa's static word embeddings..."
  - [section] "Our approach outperforms pretrained seq2seq models and prior work on realistic semantic parsing tasks..."
- Break condition: If RoBERTa doesn't capture relevant linguistic structures, the model would fail to generalize compositionally.

## Architecture Onboarding

- Component map: Input -> RoBERTa encoding -> Multiset tagging -> Token arrangement -> Permutation prediction -> Output
- Critical path: Input is encoded by RoBERTa, then each token's multiset of output tokens is predicted, followed by permutation prediction using entropy-regularized linear programming, producing the final output sequence.
- Design tradeoffs:
  - Using pretrained RoBERTa vs. training from scratch: Pretrained models provide better representations but require more resources.
  - Two-step process vs. end-to-end sequence generation: Two-step improves compositional generalization but adds complexity.
  - Entropy regularization strength: Balancing smoothness for differentiability vs. approximating true permutations.
- Failure signatures:
  - If multiset tagging is inaccurate, permutation model receives incorrect input, leading to wrong output sequences.
  - If entropy regularization is too strong, permutation model may output too smooth distributions that don't correspond to valid permutations.
  - If Bregman's method fails to converge, permutation model will not produce valid output.
- First 3 experiments:
  1. Train the multiset tagging model on a small dataset and evaluate the predicted multisets against the gold standard.
  2. Implement the permutation model with a simple scoring function and test it on a small set of known permutations.
  3. Integrate the multiset tagging and permutation models and evaluate the end-to-end performance on a simple semantic parsing task.

## Limitations

- Performance bottleneck on ATIS dataset where the first stage (multiset tagging) fails to predict correct multisets, creating a significant accuracy gap.
- Computational complexity of the entropy-regularized linear program approach may not scale well to larger problems.
- Reliance on pretrained RoBERTa embeddings means the model inherits limitations of that architecture for compositional generalization tasks.

## Confidence

**High Confidence Claims:**
- The two-step approach (multiset tagging + permutation) is novel and effectively separates lexical matching from structural arrangement
- The entropy-regularized linear program formulation allows for flexible permutation prediction without a priori restrictions
- The model outperforms pretrained seq2seq models and prior work on realistic semantic parsing tasks requiring generalization to longer examples
- The model outperforms non-tree-based models on COGS structural generalization tasks

**Medium Confidence Claims:**
- The model achieves the first instance of high accuracy on deeper recursion generalization without using trees on COGS
- The permutation model's GPU-friendly implementation based on Bregman's method is computationally efficient
- The two-step process is the key factor enabling compositional generalization, rather than other architectural choices

**Low Confidence Claims:**
- The specific choice of entropy regularization strength and its effect on permutation quality
- The extent to which RoBERTa's pretrained representations are responsible for the observed improvements
- The scalability of this approach to significantly larger semantic parsing tasks
