# The Optimal Input-Independent Baseline for Binary Classification: The Dutch Draw

## Quick Facts
- arXiv ID: 2301.03318
- Source URL: https://arxiv.org/abs/2301.03318
- Reference count: 2
- This paper proves that the Dutch Draw classifier is the best input-independent baseline for binary classification evaluation under positional-invariant measures.

## Executive Summary
This paper addresses the challenge of establishing reliable baselines for evaluating binary classification models by examining input-independent classifiers that do not use feature values. The authors introduce the Dutch Draw classifier, which randomly selects a subset of samples to label as positive, and prove that it is permutation-optimal among all input-independent classifiers for any positional-invariant performance measure when test sets are randomly shuffled. This makes Dutch Draw the best general, simple, and informative baseline for binary classification evaluation under these conditions.

## Method Summary
The Dutch Draw classifier is an input-independent method that randomly selects a subset of M·θ samples (where θ is a parameter) to label as positive, regardless of their feature values. The method is proven to be permutation-optimal for all positional-invariant measures when test sets are randomly shuffled. The optimal parameter θ can be derived for most commonly used performance measures without requiring knowledge of the number of positive labels P in the test set, though accuracy requires knowing whether P ≥ M/2.

## Key Results
- The Dutch Draw classifier is proven to be permutation-optimal among all input-independent classifiers for any positional-invariant measure.
- Dutch Draw is input-independent by design, as it only depends on the parameter θ and the number of samples M.
- The optimal Dutch Draw parameter θ can be derived for most performance measures without knowing the number of positive labels P.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The Dutch Draw classifier is permutation-optimal among all input-independent classifiers for any positional-invariant measure.
- Mechanism: By selecting uniformly at random a subset of samples to label as positive, the Dutch Draw classifier maximizes the expected performance under random permutations of the test set, as proven by showing that any other input-independent classifier can be decomposed into groups with the same expected performance as Dutch Draw for some parameter θ.
- Core assumption: The test set is randomly shuffled, and the performance measure is positional-invariant (order-independent).
- Evidence anchors:
  - [abstract] "We prove that the recently proposed Dutch Draw baseline is the best input-independent classifier (independent of feature values) for all positional-invariant measures (independent of sequence order) assuming that the samples are randomly shuffled."
  - [section 5] "Thus, we can conclude that the optimal Dutch Draw classifier attains the minimum/maximum expected performance and is therefore permutation-optimal for all input-independent classifiers with a positional-invariant measure."
- Break condition: If the performance measure is not positional-invariant, or if the test set is not randomly shuffled, the permutation-optimality claim may not hold.

### Mechanism 2
- Claim: The Dutch Draw classifier is input-independent by definition.
- Mechanism: The classifier selects uniformly at random a subset of samples to label as positive, regardless of their feature values, making it independent of feature values.
- Core assumption: The classifier's prediction is only dependent on the parameter θ and the number of samples M, not on the feature values of the samples.
- Evidence anchors:
  - [section 4.2] "Next, we discuss why all Dutch Draw classifiers are input-independent (see Section 3.1). Note that a Dutch Draw classifier σθ is independent of feature values, as it is only dependent on θ and M, see Equation (9)."
- Break condition: If the classifier's prediction becomes dependent on feature values, it would no longer be input-independent.

### Mechanism 3
- Claim: The optimal Dutch Draw classifier can be derived for most commonly used performance measures without additional knowledge about the number of positive labels P.
- Mechanism: The Dutch Draw classifier's optimal parameter θ can be determined by minimizing or maximizing the expected performance over all possible values of θ, which can be done without knowing the actual number of positive labels in the test set.
- Core assumption: The performance measure is well-defined for all possible predictions, and the optimal parameter θ can be found by optimizing the expected performance.
- Evidence anchors:
  - [section 6] "Nonetheless, it was shown in (Van de Bijl et al., 2022) that the Dutch Draw baseline can only be calculated for the measure accuracy when it is known if P ≥ M/2 holds."
- Break condition: If the performance measure is not well-defined for all possible predictions, or if the optimal parameter θ cannot be found by optimizing the expected performance, this claim may not hold.

## Limitations
- The permutation-optimality result relies on the assumption that test sets are randomly shuffled, which may not hold in practical evaluation scenarios.
- The paper notes that calculating the optimal Dutch Draw parameter for accuracy requires knowing whether P ≥ M/2, which may not always be available in practice.
- The Dutch Draw classifier may not be the best baseline for specific domains or performance measures that don't meet the positional-invariance requirement.

## Confidence
- High confidence: The input-independence of Dutch Draw classifiers and their definition as random subset selectors
- Medium confidence: The permutation-optimality proof for positional-invariant measures on randomly shuffled data
- Medium confidence: The claim that Dutch Draw is the best simple baseline for binary classification evaluation

3. Implement Dutch Draw in practice for accuracy evaluation when P is unknown to determine how often the P ≥ M/2 condition can be reasonably assumed or estimated.
