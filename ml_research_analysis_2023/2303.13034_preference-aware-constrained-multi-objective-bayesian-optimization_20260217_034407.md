# Preference-Aware Constrained Multi-Objective Bayesian Optimization

## Quick Facts
- arXiv ID: 2303.13034
- Source URL: https://arxiv.org/abs/2303.13034
- Reference count: 40
- Primary result: Novel PAC-MOO approach efficiently solves constrained multi-objective optimization with preferences over black-box functions

## Executive Summary
This paper introduces PAC-MOO, a preference-aware constrained multi-objective Bayesian optimization approach that addresses the challenge of optimizing expensive black-box functions with multiple objectives and constraints while incorporating practitioner preferences. The method uses Gaussian Process surrogate models for both objectives and constraints, combined with an information-theoretic acquisition function that maximizes knowledge gain about the constrained Pareto front. Experimental results on two analog circuit design problems demonstrate superior performance compared to existing methods, particularly in scenarios with large infeasible regions.

## Method Summary
PAC-MOO builds independent Gaussian Process models for each objective and constraint function, then uses a modified Max-value Entropy Search acquisition function to select the next candidate point for evaluation. The acquisition function maximizes the mutual information between the next input and the optimal constrained Pareto front, while incorporating preference weights through a convex combination. When no feasible points are found in initial training data, a probability-based acquisition function is used to efficiently search for feasible regions before transitioning to the main optimization loop.

## Key Results
- PAC-MOO outperforms prior constrained multi-objective Bayesian optimization methods on two real-world analog circuit design problems
- The approach effectively handles cases where 90%+ of the input space is infeasible
- Preference incorporation allows practitioners to bias optimization toward preferred objective values without sacrificing overall Pareto front quality
- The method maintains computational efficiency through selective Monte Carlo sampling for Pareto front approximation

- Core assumption: GP surrogate models with squared exponential kernels accurately capture the behavior of expensive black-box functions across the input space.

## Architecture Onboarding

- Component map: Design space X -> K GP models for objectives, L GP models for constraints -> Information-theoretic acquisition function -> Expensive function evaluation -> Updated GP models

- Critical path: Initialize GP models with N0 random or expert-provided feasible points -> For each iteration: Compute acquisition function, select next point, evaluate expensive function, update GPs -> Return Pareto set from final training data

- Design tradeoffs:
  - Preference incorporation vs. general Pareto front quality: Higher preference weights improve preferred objective but may reduce overall hypervolume
  - Monte Carlo sampling vs. computational cost: More samples improve Pareto front approximation but increase computation time
  - Feasibility search vs. objective optimization: Early iterations focus on finding feasible regions before optimizing objectives

- Failure signatures:
  - Algorithm gets stuck in infeasible regions: Check if probability-based acquisition function is being used correctly
  - Poor convergence to true Pareto front: Verify GP model accuracy and acquisition function implementation
  - Computational slowdown: Monitor Monte Carlo sampling efficiency and consider reducing sample count

- First 3 experiments:
  1. Implement basic PAC-MOO without preferences on a simple 2D constrained MOO problem with known Pareto front
  2. Add preference specification and verify that preferred objective values improve while monitoring hypervolume
  3. Test on a problem with very low feasible fraction to validate the feasibility search mechanism works correctly

## Limitations
- The effectiveness of GP surrogate models in high-dimensional design spaces with many constraints remains unproven
- The computational cost of Monte Carlo sampling for Pareto front approximation scales poorly with problem dimensionality
- The preference incorporation mechanism relies on linear weighting, which may not capture complex preference structures
