# Finding an $ε$-close Variation of Parameters in Bayesian Networks

## Quick Facts
- arXiv ID: 2305.10051
- Source URL: https://arxiv.org/abs/2305.10051
- Reference count: 10
- Primary result: Novel approach for parameter tuning in Bayesian networks that finds minimal changes to probability entries to make quantitative constraints valid

## Executive Summary
This work introduces a novel approach for parameter tuning in Bayesian networks that goes beyond existing techniques. The method leverages region verification techniques from parametric Markov chains to find minimal changes to probability entries in conditional probability tables that make a given quantitative constraint valid. The algorithm handles multiple parameters across multiple conditional probability tables and allows for parameter dependencies. Experimental results show that the approach is feasible for large Bayesian network benchmarks with up to 8 parameters.

## Method Summary
The approach translates the Bayesian network parameter tuning problem into a parametric Markov chain (pMC) reachability verification problem. The pBN is converted to a pMC where the sensitivity function becomes a reachability probability in the pMC. Region verification techniques from pMCs are then used to find parameter regions that satisfy the constraint. The algorithm uses region expansion to find ϵ-close solutions by iteratively exploring parameter space around the original instantiation, and employs parameter lifting to remove parameter dependencies by creating unique parameters for each occurrence, enabling efficient verification through MDP reduction.

## Key Results
- Algorithm can handle multiple parameters across multiple CPTs and parameter dependencies
- Experimental results show feasibility for large BN benchmarks with up to 8 parameters
- Method outperforms existing tools in certain cases and applies to subclasses of parametric Bayesian networks that have received scant attention

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The approach works by translating the Bayesian network parameter tuning problem into a parametric Markov chain (pMC) reachability verification problem.
- Mechanism: The pBN is converted to a pMC where the sensitivity function becomes a reachability probability in the pMC. Region verification techniques from pMCs are then used to find parameter regions that satisfy the constraint.
- Core assumption: The pBN can be faithfully represented as a pMC without losing the probabilistic dependencies needed for constraint verification.

  - [section 4.2] "To enable the use of PLA to parameter tuning of pBNs, we map pBNs onto pMCs as proposed in [Salmani and Katoen, 2021a; Salmani and Katoen, 2021b]; see the next example."

### Mechanism 2
- Claim: Region expansion allows finding ϵ-close solutions by iteratively exploring parameter space around the original instantiation.
- Mechanism: Starting from the original parameter values, the algorithm expands regions by a factor γ until it finds a region that satisfies the constraint. This ensures the solution stays within the ϵ-bound.
- Core assumption: The solution space is continuous and the constraint satisfaction region is connected or can be approached through expansion.
- Evidence anchors:
  - [abstract] "Our experiments show that ϵ-close tuning of large BN benchmarks with up to eight parameters is feasible."
  - [section 5.1] "Region Rϵ is determined by factor ϵ, see line 16. The methods makeRegion-EC and makeRegion-CD detail this for each of our distance measures."

### Mechanism 3
- Claim: Parameter lifting removes parameter dependencies by creating unique parameters for each occurrence, enabling efficient verification through MDP reduction.
- Mechanism: Each parameter occurrence is made unique, then the region is over-approximated by substituting parameter bounds with their extremal values to create an MDP. This MDP can be efficiently analyzed for constraint satisfaction.
- Core assumption: The over-approximation created by parameter lifting does not eliminate the satisfying region.
- Evidence anchors:
  - [section 4.1] "The parameter lifting algorithm (PLA) [Quatmann et al. , 2016 ] is an abstraction technique that reduces region verification to a probabilistic model checking problem for which efﬁcient algorithms exist [Katoen, 2016]."
  - [section 4.1] "PLA handles the issue by a relaxation step that introduces intermediate parameters; see e.g., Fig. 3b, where parameter t in the outgoing edges of state C=no,A =pos is replaced by t′."

## Architecture Onboarding

- Component map:
  - pBN to pMC translator -> Parameter lifting module -> Region verification engine -> Region expansion controller -> Minimal distance extractor

- Critical path:
  1. Convert pBN to pMC representation
  2. Generate reachability constraint from BN constraint
  3. Initialize region around original parameters
  4. Apply parameter lifting and verify region
  5. If inconclusive, partition and recurse; if rejecting, expand region
  6. Extract minimal distance instantiation from accepting regions

- Design tradeoffs:
  - Multiple parameters vs. efficiency: Supporting more parameters exponentially increases complexity
  - EC vs. CD distance: EC is simpler to compute but CD better captures probability distribution changes
  - Coverage factor η: Higher coverage gives more confidence but increases computation time

- Failure signatures:
  - Memory exhaustion: Occurs when region partitioning creates too many subregions
  - Timeout: Happens when constraint requires exploring large parameter space
  - False negatives: May occur if relaxation in parameter lifting removes valid solutions

- First 3 experiments:
  1. Test with a simple BN with one parameter and verify the EC-distance implementation
  2. Run with multiple parameters but small networks to test scalability
  3. Compare results using EC-distance vs CD-distance on the same problem instance

## Limitations
- Scalability limited to networks with up to 8 parameters due to exponential complexity of region partitioning
- Parameter lifting introduces over-approximation that may eliminate valid solutions
- CD-distance computation is NP-complete for general cases, limiting practical applicability

## Confidence

**High confidence** in the core mechanism: The translation of pBNs to pMCs and the use of region verification techniques is well-established in the literature, with clear algorithmic descriptions and theoretical foundations.

**Medium confidence** in scalability claims: While the paper demonstrates feasibility on benchmarks with up to 8 parameters, the exponential complexity of region partitioning raises concerns about performance on larger networks.

**Medium confidence** in handling parameter dependencies: The parameter lifting approach is sound in theory, but the practical impact of over-approximation on solution quality is not thoroughly evaluated.
