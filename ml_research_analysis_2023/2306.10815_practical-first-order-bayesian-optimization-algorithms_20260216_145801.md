# Practical First-Order Bayesian Optimization Algorithms

## Quick Facts
- arXiv ID: 2306.10815
- Source URL: https://arxiv.org/abs/2306.10815
- Reference count: 40
- This paper proposes practical FOBO algorithms (gEI and gPI) that outperform state-of-the-art methods on various test functions.

## Executive Summary
This paper addresses the computational challenge in first-order Bayesian optimization (FOBO) by proposing a class of algorithms that efficiently utilize gradient information to identify potential query points with zero gradients. The core method involves constructing a multi-level acquisition function where the lower level optimizes to find points with zero gradient values, and the upper level ranks these points based on their function values using Gaussian process models. The proposed algorithms, named gEI and gPI, outperform state-of-the-art FOBO algorithms on several test functions, including synthetic test functions, hyper-parameter optimization tasks, and reinforcement learning tasks. The gPI algorithm, in particular, shows superior performance in most cases, demonstrating the effectiveness of incorporating function values into the acquisition function.

## Method Summary
The proposed method constructs a multi-level acquisition function for FOBO. The lower level optimizes a gradient-based acquisition function (gEI or gPI) with multiple restarts to find candidate points where gradients are close to zero. The upper level ranks these candidates using a function value-based utility function. Each partial derivative is modeled as an independent Gaussian process, reducing computational complexity from O((n(d+1))³) to O((d+1)n³). The algorithm iteratively selects query points that balance exploration and exploitation while efficiently using gradient information.

## Key Results
- gEI and gPI algorithms outperform existing FOBO methods on synthetic test functions, hyperparameter optimization, and RL tasks
- gPI consistently shows superior performance compared to gEI across all tested scenarios
- The multi-level acquisition function approach effectively balances gradient-based optimization with function value ranking

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Multi-level acquisition function efficiently finds points with zero gradient while ranking them by function value.
- Mechanism: The lower level acquisition function (gEI or gPI) optimizes to find candidate points where the gradient is close to zero. The upper level acquisition function ranks these candidates using the function value GP model to select the most promising maxima.
- Core assumption: The lower level optimization reliably finds points with near-zero gradients, and the upper level ranking effectively identifies true maxima from minima and saddle points.
- Evidence anchors:
  - [abstract]: "We construct a multi-level acquisition function where in the first step, we optimize a lower level acquisition function with multiple restarts to identify potential query points with zero gradient value."
  - [section 3.2]: "We propose to restart the optimization of gEI (x) with k different seed points. By doing so, we construct a rich set of k candidate points, where at most k of them could now be the global minima of gEI (x)."
  - [corpus]: Weak - corpus does not directly address this specific multi-level mechanism.
- Break condition: If the lower level optimization fails to find points with sufficiently small gradients, or if the upper level ranking misidentifies maxima, the algorithm's effectiveness diminishes.

### Mechanism 2
- Claim: Modeling each partial derivative as an independent GP reduces computational complexity while maintaining optimization effectiveness.
- Mechanism: Instead of modeling the function and all partial derivatives as a joint GP (O((n(d+1))³)), each partial derivative is modeled independently (O((d+1)n³)), enabling parallel updates and reducing computational burden.
- Core assumption: The independence assumption for partial derivative GPs is reasonable for the optimization task.
- Evidence anchors:
  - [section 2]: "They overcome this computational limitation by modelling each partial derivative as an independent GP. This results in d + 1 independent GPs (one for the function value and d for each partial derivative), i.e., f (·) ∼ GP (µ(·), K(·, ·)) ∂f (·)/∂x(i) ∼ GP (µi(·), Ki(·, ·)), i ∈ {1, ..., d}."
  - [section 2]: "With this, the computational burden reduces from O((d + 1)n³) to O((d + 1)n³)."
  - [corpus]: Weak - corpus does not directly address computational complexity comparisons.
- Break condition: If the independence assumption is violated (e.g., highly correlated partial derivatives), the optimization effectiveness may degrade.

### Mechanism 3
- Claim: Incorporating gradient information directly into the acquisition function improves search efficiency compared to gradient-free methods.
- Mechanism: The gEI and gPI acquisition functions explicitly incorporate gradient information through the utility functions that penalize large gradient magnitudes, guiding the search toward stationary points that are more likely to be optima.
- Core assumption: The gradient information is accurate and provides valuable directional information for optimization.
- Evidence anchors:
  - [abstract]: "We propose a class of practical FOBO algorithms that efficiently utilizes the information from the gradient GP to identify potential query points with zero gradients."
  - [section 3.2]: "In order to determine points where all partial derivatives are zero, we define our lower acquisition function as a sum of the utility functions of all the partial derivatives."
  - [corpus]: Weak - corpus does not directly address the effectiveness of gradient incorporation.
- Break condition: If the gradient information is noisy or unreliable, the algorithm may converge to suboptimal points or fail to explore effectively.

## Architecture Onboarding

- Component map: GP models for objective function and partial derivatives -> Lower level acquisition function (gEI or gPI) -> Multiple restarts optimization -> Upper level acquisition function -> Next query point selection
- Critical path: Fit GP models → Optimize lower level acquisition function with restarts → Rank candidates using upper level acquisition → Select next query point
- Design tradeoffs:
  - Independent GP models for partial derivatives vs. joint GP model: reduced computational complexity but potential loss of correlation information
  - Number of restarts for lower level optimization: more restarts increase the chance of finding global minima but increase computational cost
  - Exploration-exploitation tradeoff in upper level acquisition: higher exploration encourages finding better optima but may slow convergence
- Failure signatures:
  - Slow convergence: may indicate poor GP fitting or suboptimal acquisition function parameters
  - Oscillation around suboptimal points: may suggest inadequate exploration or noisy gradient information
  - Numerical instability in GP updates: may indicate ill-conditioned kernel matrices or inappropriate hyperparameters
- First 3 experiments:
  1. Verify GP fitting and posterior updates on synthetic functions with known gradients
  2. Test lower level acquisition function optimization on functions with multiple stationary points
  3. Evaluate the full algorithm on a simple benchmark function (e.g., Branin) and compare to ZOBO and FOBO baselines
