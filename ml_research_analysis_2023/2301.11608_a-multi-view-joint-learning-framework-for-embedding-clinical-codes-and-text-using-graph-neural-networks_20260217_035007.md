# A Multi-View Joint Learning Framework for Embedding Clinical Codes and Text Using Graph Neural Networks

## Quick Facts
- arXiv ID: 2301.11608
- Source URL: https://arxiv.org/abs/2301.11608
- Reference count: 7

## Executive Summary
This paper presents a multi-view learning framework that jointly learns from ICD codes and clinical text using a Graph Neural Network (GNN) for codes and Bi-LSTM for text, with Deep Canonical Correlation Analysis (DCCA) to align their representations. The approach combines the structured, high-performance ICD codes with readily available but noisy clinical text, enabling accurate predictions even when one view is missing. The framework also addresses the challenge of unseen ICD codes during inference by using a novel labeling training scheme that teaches the model to differentiate between seen and unseen codes. Experiments on a local dataset and MIMIC-III show that the method outperforms BERT models fine-tuned to clinical data, and achieves competitive results with a tiny fraction of the computational cost.

## Method Summary
The method proposes a multi-view learning framework using Graph Neural Network (GNN) for ICD codes, Bi-LSTM for clinical text, and Deep Canonical Correlation Analysis (DCCA) to align their representations. The framework includes a novel labeling training scheme to handle unseen ICD codes during inference. The method is trained on two datasets - a proprietary dataset with 38,551 admissions and MIMIC-III with 58,976 unique ICU admissions. The model is evaluated on six outcome prediction tasks using AUROC and AP metrics.

## Key Results
- The method outperforms BERT models fine-tuned to clinical data on both local and MIMIC-III datasets
- Achieves competitive results with a tiny fraction of the computational cost compared to BERT
- Particularly effective for stabilizing inferences on unseen codes, addressing a significant problem in detailed coding systems

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The DCCA enforces aligned representations between ICD codes and clinical text, enabling the weaker learner (Bi-LSTM on text) to learn from the stronger learner (RGCN on codes).
- Mechanism: By maximizing the correlation between the two views during training, the text embeddings are regularized to match the more structured and informative code embeddings, reducing noise in the text representation.
- Core assumption: The two views contain overlapping information about the patient encounter, so aligning their representations captures shared semantics.
- Evidence anchors:
  - [abstract] "We apply Deep Canonical Correlation Analysis (DCCA) to enforce the two views to learn a similar representation of each patient."
  - [section] "DCCA solves the following optimization problem, max_{gC,gA,U,V} 1/Ntr(U^T M_C^T M_C A V)..."
- Break condition: If the two views are largely independent or contradictory, alignment may force one view to distort its true representation, hurting performance.

### Mechanism 2
- Claim: Jump connections in the RGCN allow information flow between distant nodes, enabling embedding of correlations not present in the tree hierarchy.
- Mechanism: By adding edges from leaf nodes to all their ancestors with distinct edge types, the maximum distance between any two nodes is reduced to two hops, preventing over-smoothing and allowing distant but correlated codes to influence each other.
- Core assumption: Distant nodes in the ontology can still be semantically related (e.g., anemia and renal failure), and these relations are useful for prediction.
- Evidence anchors:
  - [section] "Jump connections make the distance between two leaf nodes two, and this ensures that the GNN is able to embed any correlation between two nodes."
  - [section] "We use different edge types for connections between different levels in the tree graph..."
- Break condition: If the hierarchy is too flat or if the added edges create spurious correlations, the model may overfit or become unstable.

### Mechanism 3
- Claim: The labeling training scheme teaches the model to differentiate between seen and unseen codes, improving generalization to rare or novel codes.
- Mechanism: By augmenting node embeddings with a binary label indicating whether the code was seen during DCCA training, the RGCN learns to treat unseen nodes differently, avoiding overconfident predictions on unfamiliar codes.
- Core assumption: The distribution of embeddings for seen and unseen nodes is sufficiently different that a simple label can guide the model's behavior.
- Evidence anchors:
  - [section] "We augment the initial node embeddings with 1-0 labels... Note that we still use h_0^u as the trainable node embedding, while the input to the RGCN is augmented to h_0^{+u}."
  - [section] "The different labels allow the RGCN to tell whether a node is unseen during the DCCA process."
- Break condition: If the labeling is noisy or if seen and unseen nodes are too similar in embedding space, the model may fail to learn a meaningful distinction.

## Foundational Learning

- Concept: Graph Neural Networks (GNN) and Relational GNNs (RGCN)
  - Why needed here: To embed hierarchical and relational structure of ICD codes into vector representations that capture semantic similarities and ontology relationships.
  - Quick check question: What happens to node embeddings if you remove jump connections in the RGCN?
- Concept: Deep Canonical Correlation Analysis (DCCA)
  - Why needed here: To align the embeddings from two different views (codes and text) so they share a common latent space, enabling cross-view regularization and independent inference.
  - Quick check question: Why is max pooling used instead of sum pooling in DCCA for this application?
- Concept: Bidirectional LSTM with two-stage processing
  - Why needed here: To handle long clinical texts without suffering from vanishing gradients, by first summarizing blocks of text and then processing the block embeddings sequentially.
  - Quick check question: How does block size affect the ability of the model to capture long-range dependencies?

## Architecture Onboarding

- Component map: Input -> RGCN -> DCCA -> MLP heads, Input -> Two-stage Bi-LSTM -> DCCA -> MLP heads
- Critical path:
  1. Construct ICD ontology graph with jump connections
  2. Train RGCN and Bi-LSTM jointly with DCCA
  3. Extract projection matrices from DCCA
  4. Attach task-specific MLP and fine-tune end-to-end
- Design tradeoffs:
  - Using DCCA enables independent inference but requires careful batch sizing to approximate full-batch correlation
  - Jump connections improve connectivity but increase graph density and computational cost
  - Labeling scheme improves unseen code handling but reduces DCCA training data
- Failure signatures:
  - Poor correlation between views → DCCA fails to align embeddings
  - Over-smoothing in RGCN → embeddings become indistinguishable
  - Vanishing gradients in Bi-LSTM → text embeddings are too coarse
- First 3 experiments:
  1. Train RGCN alone on ICD codes and evaluate on code prediction task
  2. Train Bi-LSTM alone on clinical text and evaluate on text-only task
  3. Combine RGCN and Bi-LSTM with DCCA and evaluate joint performance and independent inference capability

## Limitations

- The evaluation is constrained to a relatively small set of six outcome prediction tasks, which may not fully capture the method's generalization capabilities across the broader landscape of clinical coding and prediction problems.
- The proprietary dataset's exact characteristics are not fully disclosed, limiting reproducibility and external validation.
- While the paper demonstrates competitive performance against BERT models, direct comparisons with other state-of-the-art clinical text models are limited.
