# Supervised Feature Selection with Neuron Evolution in Sparse Neural Networks

## Quick Facts
- arXiv ID: 2303.07200
- Source URL: https://arxiv.org/abs/2303.07200
- Reference count: 24
- Key outcome: NeuroFS achieves highest ranking-based score among state-of-the-art supervised feature selection methods

## Executive Summary
NeuroFS introduces a novel supervised feature selection method that leverages sparse neural networks with dynamic neuron evolution. The approach gradually prunes uninformative input neurons while using gradient information to strategically regrow potentially informative inactive neurons. Through extensive experiments on 11 real-world datasets spanning low and high-dimensional data, NeuroFS demonstrates superior performance compared to established methods like LassoNet, STG, and QuickSelection, particularly excelling in high-dimensional settings while maintaining computational efficiency.

## Method Summary
NeuroFS implements supervised feature selection through sparse neural networks trained from scratch with dynamic neuron evolution. The method initializes a sparse MLP with Erdős-Rényi connectivity and iteratively prunes neurons with lowest strength (L1 norm of incoming weights) while regrowing inactive neurons connected to zero-weights with largest gradient magnitudes. After training, the top-K neurons by strength are selected as features and evaluated using SVM classification. The approach uses specific hyperparameters including sparsity level ε=30, update fractions ζin=0.2 and ζh=0.3, and neuron removal duration α=0.65.

## Key Results
- Achieves highest ranking-based score among considered state-of-the-art supervised feature selection models
- Outperforms competitors like LassoNet, STG, and QuickSelection on classification accuracy
- Particularly effective on high-dimensional datasets while maintaining computational efficiency through sparse networks

## Why This Works (Mechanism)

### Mechanism 1
Dynamic neuron pruning and regrowth in the input layer reduces the search space for feature selection. At each training epoch, NeuroFS removes low-strength neurons and adds inactive neurons connected to high-gradient weights, progressively narrowing the active feature set. Core assumption: neuron strength correlates with feature importance, and gradient magnitude indicates which inactive features could improve representation. Evidence: method description shows gradual pruning of uninformative features and gradient-based selection of regrowth candidates.

### Mechanism 2
Gradient-based regrowth accelerates convergence by prioritizing connections likely to improve data representation. Inactive neurons connected to zero-weights with largest gradient magnitudes are reactivated, guiding topology evolution toward informative features. Core assumption: large gradient magnitudes on zero-connections signal high potential for reducing loss if those connections were activated. Evidence: experiments demonstrate NeuroFS achieves highest ranking-based score among state-of-the-art methods.

### Mechanism 3
Sparse neural network training from scratch avoids over-parameterization while maintaining performance. NeuroFS uses sparse MLP layers initialized with Erdős-Rényi connectivity, updated via magnitude-based pruning and gradient-based growth, keeping parameter count low. Core assumption: sparse architectures can match or exceed dense network performance on feature selection tasks while reducing computational cost. Evidence: method outperforms competitors while maintaining computational efficiency through sparse networks.

## Architecture Onboarding

- Component map:
  Input layer (sparse neurons with dynamic pruning/regrowth) -> Hidden layers (sparse MLPs with magnitude-based pruning and gradient-based regrowth) -> Output layer (softmax classifier)

- Critical path:
  1. Initialize sparse MLP with Erdős-Rényi connectivity
  2. For each epoch: train via forward/backward pass, update input layer (prune low-strength, regrow high-gradient inactive), update hidden layers (prune low-magnitude, regrow high-gradient)
  3. After training, select top-K neurons by strength as features

- Design tradeoffs:
  - Sparsity level ε: Higher → fewer parameters, faster training but risk underfitting
  - Update fractions ζin, ζh: Balance between exploration and stability
  - Neuron removal duration α: Controls how aggressively search space is reduced

- Failure signatures:
  - Input layer stagnates (no neuron changes) → α too small or ζin too low
  - Performance collapses on high-dimensional data → ε too high, insufficient capacity
  - Hidden layers diverge → ζh too large, pruning too aggressive

- First 3 experiments:
  1. Train NeuroFS on COIL-20 with K=25; verify input neuron count decreases over epochs
  2. Replace gradient regrowth with random; compare accuracy and convergence speed
  3. Vary ε from 0.2 to 0.8; measure parameter count, FLOPs, and classification accuracy

## Limitations
- Lacks detailed implementation specifics for sparse matrix operations and exact pruning/regrowth criteria
- Experimental results averaged over 5 seeds without specifying starting point, affecting reproducibility
- Evaluation limited to 11 datasets, potentially limiting generalizability to all types of high-dimensional data

## Confidence

- **High Confidence:** Neuron strength (L1 norm of incoming weights) as feature importance metric is well-supported by theoretical framework and experimental results. Sparse neural networks can maintain or improve classification accuracy while reducing computational costs.

- **Medium Confidence:** Gradient-based regrowth effectiveness in guiding topology evolution is supported by results, but correlation between gradient magnitude and feature importance needs more rigorous testing. Computational efficiency gains demonstrated but not quantified in absolute terms.

- **Low Confidence:** Generalizability to datasets with different characteristics (very large-scale or highly imbalanced data) is not thoroughly explored. Paper lacks discussion of potential failure modes or limitations.
