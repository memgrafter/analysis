# Recurrent Neural Networks and Long Short-Term Memory Networks: Tutorial and Survey

## Quick Facts
- arXiv ID: 2304.11461
- Source URL: https://arxiv.org/abs/2304.11461
- Reference count: 18
- This paper provides a comprehensive tutorial on RNNs and LSTMs, covering their dynamical system formulation, BPTT training, gradient problems, and various architectural solutions.

## Executive Summary
This paper serves as both an educational tutorial and survey of Recurrent Neural Networks and Long Short-Term Memory networks. It covers the fundamental dynamical system formulation of RNNs, explains backpropagation through time for training, and addresses the critical problems of gradient vanishing and explosion when learning long-term dependencies. The tutorial extends to LSTM architectures with detailed explanations of gate operations and cell functionality, as well as modern variants and bidirectional processing approaches.

## Method Summary
The paper presents a systematic exposition of RNNs through their dynamical system formulation, followed by detailed coverage of BPTT for training. It analyzes the gradient vanishing/explosion problems inherent in standard RNNs and presents architectural solutions including close-to-identity weight matrices, long delays, leaky units, and echo state networks. The tutorial then delves into LSTM architecture with comprehensive coverage of input, forget, and output gates, as well as cell states. Modern variants and bidirectional architectures are also covered, providing a complete educational resource.

## Key Results
- RNNs formulated as dynamical systems with BPTT for training
- Analysis of gradient vanishing/explosion problems in long-term dependencies
- Comprehensive coverage of LSTM gates (input, forget, output) and cell functionality
- Survey of LSTM variants and bidirectional RNN/LSTM architectures including ELMo

## Why This Works (Mechanism)
RNNs work by maintaining hidden states that capture sequential information through recurrent connections. The dynamical system formulation treats RNNs as iterative maps where current states depend on previous states and current inputs. LSTM networks specifically address the vanishing gradient problem through gated mechanisms that regulate information flow, allowing selective retention and forgetting of information across long sequences.

## Architecture Onboarding
**Component Map:** Input → Hidden State (RNN/LSTM Cell) → Output, with LSTM adding Input Gate, Forget Gate, Output Gate, and Cell State
**Critical Path:** Input sequence → Hidden state updates → Output predictions, with gate operations controlling information flow in LSTM
**Design Tradeoffs:** Standard RNNs favor simplicity but suffer from gradient problems; LSTMs add parameters for better long-term memory at computational cost
**Failure Signatures:** Gradient vanishing (no learning of long-term dependencies), gradient explosion (unstable training), poor gating decisions in LSTM
**First Experiments:** 1) Train simple RNN on sequence copying task to observe gradient problems, 2) Implement basic LSTM and verify improved performance on same task, 3) Test bidirectional LSTM on language modeling task
