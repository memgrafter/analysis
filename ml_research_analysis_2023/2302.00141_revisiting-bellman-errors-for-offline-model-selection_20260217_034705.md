# Revisiting Bellman Errors for Offline Model Selection

## Quick Facts
- arXiv ID: 2302.00141
- Source URL: https://arxiv.org/abs/2302.00141
- Reference count: 40
- Key outcome: Supervised Bellman Validation (SBV) achieves strong and robust performance on diverse offline datasets, outperforming competing baselines for offline model selection in reinforcement learning.

## Executive Summary
This paper revisits the use of Bellman errors for offline model selection (OMS) in reinforcement learning. Previous approaches struggled with estimation bias and poor performance in complex environments. The authors propose a new algorithm, Supervised Bellman Validation (SBV), that more accurately estimates the mean squared Bellman error (MSBE) than prior methods. SBV achieves impressive OMS performance on diverse datasets ranging from simulated clinical trials to Atari games, outperforming competing baselines. The paper also investigates when Bellman errors are effective for OMS through theoretical and empirical analyses, providing guidance on how to improve their performance.

## Method Summary
The paper introduces Supervised Bellman Validation (SBV), a new algorithm for offline model selection that more accurately estimates the mean squared Bellman error (MSBE). SBV partitions the offline dataset into training and validation sets. It trains candidate Q-functions on the training set using offline RL algorithms, and separately estimates each Bellman backup function using a regression algorithm tuned to minimize Bellman backup MSE. The validation set is used to evaluate the MSBE for each candidate Q-function. SBV then selects the Q-function with the lowest estimated MSBE as the best policy. This approach reduces estimation bias compared to empirical Bellman errors by using a separate regression algorithm to estimate the Bellman backup function, rather than using the Q-function itself.

## Key Results
- SBV achieves strong and robust performance on diverse offline datasets, including simulated clinical trials and Atari games.
- SBV outperforms competing baselines such as EMSBE, WIS, and FQE in terms of top-3 policy values and top-5 policy returns.
- Theoretical and empirical analyses provide insights into when Bellman errors are effective for OMS, guiding future research on improving their performance.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SBV reduces estimation bias compared to empirical Bellman errors by using a regression algorithm to estimate the Bellman backup function.
- Mechanism: SBV splits the offline dataset into training and validation sets. It then uses the training set to estimate Q* via offline RL, and separately estimates each Bellman backup function B*Qm using a regression algorithm that minimizes the Bellman backup MSE. The validation set is used to evaluate the mean squared Bellman error (MSBE) as an estimate of the true Bellman error.
- Core assumption: The regression algorithm can accurately estimate the Bellman backup function B*Qm from the training data.
- Evidence anchors:
  - [abstract]: "We develop a new estimator of the MSBE that is more accurate than prior methods."
  - [section 4]: "Similar to the supervised learning case, SBV creates a training set DT and a validation set DV by randomly partitioning trajectories from D, and trains M Q-functions Q = {Q1, ..., QM } on DT."
- Break condition: If the regression algorithm cannot accurately estimate the Bellman backup function due to insufficient data or model misspecification, SBV's estimates of the MSBE will be biased.

### Mechanism 2
- Claim: SBV's approach of using a separate regression algorithm to estimate Bellman backups, rather than using the Q-function itself, reduces target variance and improves estimation accuracy.
- Mechanism: By using a regression algorithm trained on the same data but with a different objective (minimizing Bellman backup MSE), SBV can produce a more stable estimate of the Bellman backup that is less sensitive to the noise in the Q-function estimates.
- Core assumption: The regression algorithm can learn a smoother, more stable approximation of the Bellman backup than the Q-function itself.
- Evidence anchors:
  - [abstract]: "Our estimator obtains impressive OMS performance on diverse offline datasets ranging from simulated clinical trials (Klasnja et al., 2015) to Atari games (Bellemare et al., 2013; Agarwal, Schuurmans and Norouzi, 2020)."
  - [section 4]: "Denote the fitted models from our regression algorithms as ˆB*Q1, ..., ˆB*QM. The MSBE for each candidate Qm can then be estimated as EDV [(Qm(s, a) − (ˆB*Qm)(s, a))2]."
- Break condition: If the regression algorithm overfits to the training data or cannot generalize well to the validation set, SBV's estimates of the MSBE will be inaccurate.

### Mechanism 3
- Claim: SBV's use of cross-validation to tune the regression algorithm ensures that the Bellman backup estimates are accurate and generalizable.
- Mechanism: By using the validation set to evaluate the performance of different regression algorithms and hyperparameters, SBV can select the model that best generalizes to unseen data, leading to more accurate estimates of the MSBE.
- Core assumption: The validation set is representative of the true data distribution and can be used to reliably evaluate the performance of the regression algorithm.
- Evidence anchors:
  - [abstract]: "SBV achieves strong and robust performance on diverse offline datasets ranging from simulated clinical trials (Klasnja et al., 2015) to Atari games (Bellemare et al., 2013; Agarwal, Schuurmans and Norouzi, 2020)."
  - [section 4]: "When implementing SBV, each Bellman backup function was estimated using a different regression algorithm tuned to minimize MSE on the validation set, in-line with Algorithm A.1."
- Break condition: If the validation set is not representative of the true data distribution or is too small to provide reliable estimates of the regression algorithm's performance, SBV's estimates of the MSBE will be inaccurate.

## Architecture Onboarding

- Component map:
  - Offline dataset D = {(s, a, r, s')}
  - Training set DT (80% of trajectories)
  - Validation set DV (20% of trajectories)
  - Q-functions Q1, ..., QM (estimated using offline RL algorithms on DT)
  - Regression algorithms R1, ..., RN (used to estimate Bellman backup functions)
  - Bellman networks (neural networks used to estimate Bellman backup functions in complex control problems)

- Critical path:
  1. Split offline dataset D into training set DT and validation set DV
  2. Estimate Q-functions Q1, ..., QM using offline RL algorithms on DT
  3. For each Qm, estimate Bellman backup function B*Qm using regression algorithm Rm tuned on DT
  4. Estimate MSBE for each Qm using DV
  5. Select Qm* with lowest estimated MSBE as the best policy

- Design tradeoffs:
  - Using a separate regression algorithm to estimate Bellman backups vs. using the Q-function itself
  - Using cross-validation to tune the regression algorithm vs. using a fixed set of hyperparameters
  - Using a simple regression algorithm vs. a complex neural network for Bellman backup estimation

- Failure signatures:
  - High variance in MSBE estimates across different runs
  - MSBE estimates not correlated with true policy performance
  - Regression algorithm overfitting to training data

- First 3 experiments:
  1. Evaluate SBV on a simple toy environment with known optimal policy and compare to baseline methods
  2. Evaluate SBV on a more complex environment (e.g., Bicycle MDP) and compare to baseline methods
  3. Evaluate SBV on a high-dimensional Atari environment and compare to baseline methods

## Open Questions the Paper Calls Out

## Limitations
- Theoretical analysis relies on assumptions about the behavior policy and coverage conditions that may not hold in practice.
- Empirical validation is currently limited to specific environments and candidate policy sets, raising questions about generalizability.
- The regression-based approach for estimating Bellman backups may struggle with high-dimensional or complex state-action spaces.
