# TsSHAP: Robust model agnostic feature-based explainability for time series forecasting

## Quick Facts
- arXiv ID: 2303.12316
- Source URL: https://arxiv.org/abs/2303.12316
- Reference count: 38
- Primary result: Model-agnostic SHAP-based explanations for time series forecasting with faithfulness scores of 0.42-0.89

## Executive Summary
TsSHAP addresses the critical need for explainability in time series forecasting by providing a model-agnostic method that generates local, semi-local, and global explanations using SHAP values from a surrogate model. The approach extracts interpretable features from time series data (such as lags, seasonality, and trends) and trains a surrogate model to map these features to forecasts produced by black-box forecasting models. This enables users to understand which features drive predictions without requiring access to the internal workings of complex forecasting algorithms. The method was validated across five real-world datasets and six forecasting models, demonstrating robust explanation quality while maintaining computational efficiency.

## Method Summary
TsSHAP employs a surrogate model approach to generate SHAP-based explanations for time series forecasting. First, historical backtested forecasts are generated using an expanding window strategy. Interpretable features are extracted from the time series data, including lags, seasonality indicators, and trend components. A surrogate XGBoost model is then trained to map these features to the original forecaster's predictions. TreeSHAP is applied to this surrogate model to compute feature importance scores, which are aggregated differently depending on whether local (single point), semi-local (time interval), or global (entire series) explanations are desired. The method is fully model-agnostic, requiring no access to the internals of the forecasting model being explained.

## Key Results
- Surrogate models achieved low prediction errors with MAPE up to 0.21 across all tested forecasters
- Explanation faithfulness scores ranged from 0.42-0.89, with moving average forecaster achieving the highest faithfulness
- Sensitivity scores remained low (median 0.8-12.64), indicating stable explanations under small input perturbations
- Complexity metrics (entropy of feature importance) ranged from 0.07-2.67, with naive forecaster showing the lowest complexity

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Surrogate model mapping interpretable features to forecasts enables model-agnostic explanations.
- Mechanism: TsSHAP trains a surrogate model to learn the relationship between user-defined interpretable features and the black-box forecaster's outputs. This surrogate model can then be explained using TreeSHAP to obtain feature importance scores.
- Core assumption: A tree-based surrogate model can accurately approximate the black-box forecaster's behavior.
- Evidence anchors:
  - [abstract]: "TsSHAP provides robust, model agnostic feature-based explainability for univariate time series forecasting using SHAP values from a surrogate model."
  - [section 4.1]: "TsSHAP is model agnostic. Since we do not have access to the actual internals of the forecaster model, we first learn a surrogate model g."
  - [corpus]: Weak - no direct evidence in corpus about surrogate model approach.
- Break condition: If the surrogate model fails to accurately approximate the black-box forecaster's outputs, the explanations derived from the surrogate will not faithfully represent the forecaster's decision process.

### Mechanism 2
- Claim: Local, semi-local, and global explanations capture different scopes of feature importance.
- Mechanism: TsSHAP formalizes three explanation scopes - local (single forecast point), semi-local (time interval of forecasts), and global (entire time series) - each aggregating SHAP values differently to provide relevant insights.
- Core assumption: Different explanation scopes are meaningful and useful for time series forecasting contexts.
- Evidence anchors:
  - [abstract]: "Moreover, we formalize the notion of local, semi-local, and global explanations in the context of time series forecasting."
  - [section 5.1]: "We introduce the notion of scope of explanation in the context of time series forecasting."
  - [corpus]: Weak - no direct evidence in corpus about explanation scopes.
- Break condition: If the aggregation methods for each scope are not appropriate, the explanations may not provide meaningful insights for their intended use cases.

### Mechanism 3
- Claim: Block bootstrap perturbation provides robust evaluation of explanation quality.
- Mechanism: TsSHAP uses block bootstrap to create multiple perturbed versions of the time series while preserving trend-cycle, allowing evaluation of explanation faithfulness and sensitivity across different data realizations.
- Core assumption: Block bootstrap preserves the essential characteristics of the time series needed for meaningful explanation evaluation.
- Evidence anchors:
  - [section 6.3]: "To generate bootstrapped samples... we employ the block bootstrap algorithm."
  - [section 6.4.1]: "Faithfulness... Let N(X) represents a neighbourhood around X, obtained through perturbation (§ 6.3)."
  - [corpus]: Weak - no direct evidence in corpus about block bootstrap for explanation evaluation.
- Break condition: If the block bootstrap does not preserve important time series characteristics, the perturbed samples may not provide a valid basis for evaluating explanation robustness.

## Architecture Onboarding

- Component map:
  Black-box forecaster -> Surrogate model (XGBoost) -> Interpretable feature extraction -> TreeSHAP explainer -> Explanation visualization

- Critical path:
  1. Generate backtested historical forecasts using expanding window strategy
  2. Extract interpretable features from the time series
  3. Train surrogate model to map features to forecaster outputs
  4. Apply TreeSHAP to surrogate model to obtain explanations
  5. Evaluate explanations using faithfulness, sensitivity, and complexity metrics

- Design tradeoffs:
  - Accuracy of surrogate model vs. complexity of interpretable features
  - Granularity of explanations (local vs. semi-local vs. global) vs. computational cost
  - Choice of explainer algorithm (TreeSHAP) vs. alternative approaches

- Failure signatures:
  - Low faithfulness scores indicate explanations do not accurately represent forecaster behavior
  - High sensitivity scores suggest explanations are unstable to small input changes
  - Complex explanations (high entropy) may be difficult to interpret

- First 3 experiments:
  1. Train surrogate model on a simple forecaster (e.g., Naive) and verify it achieves high accuracy
  2. Generate local explanations for a specific forecast and check if they align with the forecaster's expected behavior
  3. Evaluate explanation quality (faithfulness, sensitivity, complexity) for different explanation scopes on a real dataset

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does TsSHAP's performance scale with increasing forecast horizon length beyond 10%?
- Basis in paper: [inferred] The paper mentions using a forecast horizon of 10% of the data but doesn't explore longer horizons.
- Why unresolved: The experiments only tested horizons up to 10%, leaving open questions about performance degradation or adaptation needs for longer-term forecasts.
- What evidence would resolve it: Testing TsSHAP with forecast horizons of 20%, 30%, and 50% of the data, comparing surrogate model accuracy and explanation quality across these horizons.

### Open Question 2
- Question: Can TsSHAP be effectively extended to multivariate time series forecasting while maintaining explanation quality?
- Basis in paper: [explicit] The authors state "TsSHAP can be extended to explain the prediction interval" and "extend the above algorithm to multivariate time series forecasting models" as future work.
- Why unresolved: The current implementation is limited to univariate time series, and the paper doesn't provide evidence or methodology for handling multiple interrelated time series.
- What evidence would resolve it: Implementing and validating TsSHAP on multivariate datasets, measuring explanation faithfulness and complexity when handling cross-series feature interactions.

### Open Question 3
- Question: What is the computational overhead of generating TsSHAP explanations compared to the forecast computation time itself?
- Basis in paper: [inferred] While the paper discusses explanation quality metrics, it doesn't report timing data for explanation generation.
- Why unresolved: The method relies on training surrogate models and computing SHAP values, but the relative computational cost is unknown.
- What evidence would resolve it: Benchmarking TsSHAP explanation generation time versus forecast computation time across different model complexities and dataset sizes.

## Limitations

- Limited to univariate time series forecasting without exogenous variables, restricting applicability to many real-world scenarios
- Performance on complex forecasting models (Prophet, XGBoost) is less reliable than on simpler models, with lower faithfulness scores
- Computational overhead of training surrogate models and computing SHAP values may be prohibitive for real-time explanation needs

## Confidence

- High confidence: The methodology for generating local, semi-local, and global explanations using SHAP values from a surrogate model
- Medium confidence: The faithfulness and sensitivity evaluation results across different forecasters and explanation scopes
- Low confidence: The claim that TsSHAP provides "robust" explanations across all tested forecasters, particularly for complex models like Prophet and XGBoost
