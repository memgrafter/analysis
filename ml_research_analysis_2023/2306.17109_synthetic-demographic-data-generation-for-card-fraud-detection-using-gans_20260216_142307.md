# Synthetic Demographic Data Generation for Card Fraud Detection Using GANs

## Quick Facts
- arXiv ID: 2306.17109
- Source URL: https://arxiv.org/abs/2306.17109
- Reference count: 10
- Generates high-quality synthetic demographic data using GANs for card fraud detection

## Executive Summary
This study introduces DGGAN, a deep learning model that generates high-quality synthetic demographic data for card fraud detection using Generative Adversarial Networks (GANs). The model addresses class imbalance issues common in categorical demographic data by training and generating samples simultaneously. Evaluation using SDMetrics shows improved performance for categorical columns, with shape and pair trend scores increasing to 0.78 and 0.88, respectively. Overall, the model achieves average shape and pair trend scores of 0.88 and 0.92 across all features, demonstrating its effectiveness in generating balanced, realistic synthetic demographic data.

## Method Summary
DGGAN uses a fully-connected GAN architecture with simultaneous generation during training. The model employs geometric progression scheduling to control sample generation percentage, starting at 0.2% and increasing by a ratio of 1.15884 over 50 epochs. Continuous features are normalized using max-absolute, min-max, or standardization methods, while categorical features use one-hot encoding. The generator and discriminator both use leaky ReLU activations with slopes of 0.8 and 0.1 respectively. Evaluation uses SDMetrics to measure KSComplement, TVComplement, CorrelationSimilarity, and ContingencySimilarity across continuous and categorical features.

## Key Results
- Shape score for categorical columns improved to 0.78 from baseline
- Pair trend score for categorical columns reached 0.88
- Average shape score across all features: 0.88, pair trend score: 0.92
- Geometric progression generation method significantly improved class imbalance issues

## Why This Works (Mechanism)

### Mechanism 1
Simultaneous sample generation during GAN training mitigates class imbalance in categorical demographic data. By generating synthetic samples at each training epoch using geometric progression, the generator is exposed to underrepresented categories early in training, preventing mode collapse toward dominant categories.

### Mechanism 2
Geometric progression in generation percentage balances category representation without over-generating unrealistic samples. The generation percentage increases gradually over epochs, allowing the generator to produce fewer random samples early and more refined samples later, aligning synthetic distribution with real data distribution.

### Mechanism 3
Fully connected network architecture captures all possible correlations between demographic columns without locality bias. Unlike convolutional or recurrent architectures, fully connected layers treat each feature independently of spatial or sequential structure, making them suitable for tabular demographic data.

## Architecture Onboarding

- Component map: Random noise -> Generator (fully connected) -> Synthetic samples; Real data -> Discriminator (fully connected) -> Real/fake prediction; Both samples -> Training loop with geometric progression scheduling
- Critical path: 1) Data preprocessing (normalization and one-hot encoding) 2) GAN model initialization 3) Training loop with simultaneous generation 4) Evaluation using SDMetrics 5) Visualization of results
- Design tradeoffs: Fully connected vs. specialized architectures (simpler but may miss complex dependencies); Simultaneous generation vs. post-training generation (better balance but requires careful scheduling); Geometric progression ratio (controls trade-off between early diversity and final realism)
- Failure signatures: Mode collapse (generator produces only dominant categories); Over-smoothing (synthetic data lacks diversity and realism); Correlation degradation (synthetic data fails to preserve feature relationships)
- First 3 experiments: 1) Baseline GAN without simultaneous generation to establish mode collapse baseline 2) GAN with fixed generation percentage to test geometric progression necessity 3) GAN with different geometric progression ratios to find optimal balance

## Open Questions the Paper Calls Out

### Open Question 1
How does DGGAN's performance on highly imbalanced categorical data compare to other synthetic data generation methods like microsimulation? The paper suggests deep learning models like GANs may perform better than established methods but does not directly compare DGGAN to alternatives.

### Open Question 2
What is the impact of incorporating synthetic demographic data into transaction data on fraud detection accuracy? The paper suggests this could improve detection performance but does not provide empirical evidence through integration experiments.

### Open Question 3
How does the choice of normalization function affect DGGAN's performance on continuous features? The paper mentions using three normalization functions but does not analyze their individual impacts on model quality.

### Open Question 4
What is the optimal geometric progression parameter for different datasets, and how does it affect data balance? The paper provides one specific ratio without exploring its generalizability or sensitivity to dataset characteristics.

### Open Question 5
How does DGGAN handle generation for categorical columns with very large numbers of categories? The paper identifies potential performance issues with large categories but does not explore solutions or conduct targeted experiments.

## Limitations

- Geometric progression implementation details remain unspecified, making faithful reproduction challenging
- No baseline comparisons with established synthetic data generation methods like CTGAN or TVAE
- Fully connected architecture may miss latent sequential or hierarchical patterns in demographic data

## Confidence

**High Confidence:** Simultaneous generation during training effectively mitigates class imbalance (supported by quantitative SDMetrics improvements).

**Medium Confidence:** Geometric progression provides optimal balance between early diversity and final realism (mechanistic reasoning is sound but lacks comparative analysis).

**Low Confidence:** Fully connected networks sufficiently capture all correlations in demographic tabular data (architectural justification exists but lacks empirical validation).
