# Finding the Needle in a Haystack: Unsupervised Rationale Extraction from Long Text Classifiers

## Quick Facts
- **arXiv ID**: 2303.07991
- **Source URL**: https://arxiv.org/abs/2303.07991
- **Reference count**: 16
- **Primary result**: Standard attention-based approaches perform poorly when combined with long text transformers like Longformer; compositional soft attention architecture significantly outperforms Longformer-based methods on sentiment classification datasets while being 30-60% faster to train.

## Executive Summary
This paper addresses the challenge of unsupervised rationale extraction from long text classifiers, where the goal is to identify token-level justifications for document-level predictions without using token-level annotations during training. The authors find that standard attention-based methods, particularly when combined with Longformer's sparse self-attention mechanism, struggle to identify meaningful token-level rationales in long documents. They propose a compositional soft attention architecture that applies RoBERTa sentence-wise and composes token representations across sentences using Ranked Soft Attention. This approach significantly outperforms Longformer-based methods on sentiment classification tasks while also being computationally more efficient.

## Method Summary
The authors investigate three attention-based architectures for unsupervised rationale extraction: Weighted Soft Attention, Ranked Soft Attention, and Compositional Soft Attention. Weighted Soft Attention applies a single RoBERTa model to the full document with attention-based token scoring, while Ranked Soft Attention extends this by supervising only the top and bottom k% of tokens per epoch. The key innovation is Compositional Soft Attention, which processes each sentence individually with RoBERTa and then composes the resulting token embeddings using Ranked Soft Attention. This compositional approach allows standard RoBERTa to learn meaningful intra-sentence token dependencies before combining them at the document level. The models are evaluated on three datasets (FCE, BEA 2019, and IMDB) using F1, F0.5, and MAP metrics for token-level rationale extraction, along with document-level classification F1 scores.

## Key Results
- Longformer's sparse self-attention performs at or below random baseline for token-level rationale extraction on longer sentiment datasets
- Compositional Soft Attention achieves 6-8% higher F1 and F0.5 scores compared to Longformer-based methods on sentiment datasets
- Compositional Soft Attention is 30-60% faster to train than Longformer-based approaches
- Weighted Soft Attention fails on long documents as most token scores converge to 1, providing insufficient discrimination between rationales and non-rationales

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sparse self-attention in Longformer struggles to identify token-level rationales for document classification
- Mechanism: Longformer's global attention mechanism focuses on document-level dependencies rather than token-level relevance, causing most tokens to receive similar attention scores that don't distinguish rationales from non-rationales
- Core assumption: Global attention patterns learned by Longformer prioritize document coherence over token-level justification
- Evidence anchors:
  - [abstract] "we find that the sparse self-attention present in Longformer struggles to locate tokens that can serve as a plausible rationale for document labels"
  - [section] "For longer sentiment detection datasets, the quality of the rationale extracted from the self-attention layers is not better than the random baseline"
- Break condition: If token-level attention scores from Longformer consistently outperform random baselines on rationale extraction tasks

### Mechanism 2
- Claim: Weighted Soft Attention fails on long documents due to insufficient token-level supervision per epoch
- Mechanism: Only minimum and maximum token scores receive supervision signals each epoch, leaving most tokens unsupervised and causing scores to converge to initial values
- Core assumption: The loss function structure inherently limits the number of tokens receiving direct supervision during training
- Evidence anchors:
  - [section] "Only minimum and maximum token scores are optimized. While working well for individual sentences, such an approach does not scale well to longer documents"
  - [section] "empirically, we find that most of the token scores obtained using Weighted Soft Attention are close to 1 for long documents"
- Break condition: If supervision signal distribution changes to provide meaningful gradients to more tokens per epoch

### Mechanism 3
- Claim: Compositional Soft Attention enables effective token-level rationale extraction by applying RoBERTa sentence-wise
- Mechanism: Processing each sentence individually with standard RoBERTa allows the model to learn meaningful intra-sentence token dependencies, which are then composed across sentences using Ranked Soft Attention
- Core assumption: RoBERTa's self-attention mechanism is better suited for identifying rationales at the sentence level than Longformer's global attention
- Evidence anchors:
  - [abstract] "We introduce a Compositional Soft Attention architecture, which applies a vanilla RoBERTa model sentence-wise and composes the obtained token contextual embeddings using Ranked Soft Attention"
  - [section] "the compositional nature of this architecture allowed the RoBERTa model to learn to provide meaningful token-level scores for each sentence individually"
- Break condition: If sentence-level processing fails to capture document-level context needed for accurate classification

## Architecture Onboarding

- Component map:
  Input: Long text documents split into sentences -> Sentence encoder: Individual RoBERTa models applied to each sentence -> Token embeddings: Contextual representations from sentence encoders -> Composition layer: Ranked Soft Attention that combines sentence-level token embeddings -> Output: Document classification and token-level attention scores

- Critical path:
  1. Document splitting into sentences
  2. Individual sentence encoding with RoBERTa
  3. Token embedding composition using Ranked Soft Attention
  4. Document-level prediction and token-level rationale extraction

- Design tradeoffs:
  - Sentence-wise processing vs full-document processing
  - Standard RoBERTa efficiency vs Longformer's global context
  - Computational cost of multiple small transformers vs single large transformer
  - Token-level supervision granularity (k% vs top/bottom tokens)

- Failure signatures:
  - All token scores clustering near 1 or 0
  - Low MAP scores despite reasonable document classification
  - Significant performance drop on longer documents vs shorter ones
  - Training instability with Ranked Soft Attention hyperparameters

- First 3 experiments:
  1. Compare token attention score distributions between Longformer and Compositional Soft Attention on sample documents
  2. Measure supervision signal distribution per token across training epochs for both architectures
  3. Evaluate MAP scores while varying the k% parameter in Ranked Soft Attention to find optimal token supervision rate

## Open Questions the Paper Calls Out
- **Question**: How do compositional soft attention architectures scale to truly long documents beyond the memory limits of current GPUs?
  - Basis in paper: [explicit] The authors identify this as a key limitation, noting that their approach "still doesn't not permit application to texts of arbitrary length, as the memory of the GPU is the main limitation."
  - Why unresolved: The paper acknowledges this as an open problem but does not propose specific technical solutions to overcome GPU memory constraints for arbitrarily long sequences.
  - What evidence would resolve it: Empirical results showing successful application of the compositional approach to documents with 10K+ tokens, demonstrating memory-efficient implementation techniques or distributed computing strategies.

- **Question**: What alternative evaluation metrics could better capture the quality of token-level rationales in long documents beyond F1/F0.5/MAP?
  - Basis in paper: [explicit] The authors state "current approaches of evaluating rationale extraction as a sequence labeling problem do not scale well to longer documents" and call for "alternative methods of evaluating plausibility of token-level rationale extractors for long texts."
  - Why unresolved: The paper identifies the need for new evaluation paradigms but does not propose specific alternative metrics or frameworks suitable for long document analysis.
  - What evidence would resolve it: Development and validation of novel evaluation frameworks specifically designed for long-document rationale extraction, with demonstrated advantages over traditional token-level metrics.

- **Question**: How do different sparse attention patterns in long-sequence transformers affect the quality of token-level rationale extraction compared to dense attention?
  - Basis in paper: [explicit] The authors observe that "standard soft attention methods to perform significantly worse when combined with the Longformer language model" and note that "sparse self-attention present in Longformer struggles to locate tokens that can serve as a plausible rationale."
  - Why unresolved: While the paper identifies performance issues with Longformer's sparse attention, it does not systematically compare different sparse attention patterns or analyze the relationship between attention sparsity and rationale quality.
  - What evidence would resolve it: Controlled experiments comparing token-level rationale extraction performance across multiple long-sequence transformers with different sparse attention patterns (Big Bird, Longformer variants, ETC, etc.) under identical experimental conditions.

## Limitations
- The Compositional Soft Attention architecture's performance advantages may not generalize beyond sentiment classification to tasks requiring strong document-level context
- Implementation details for k% token supervision are ambiguous, particularly regarding whether supervision is applied sentence-wise or across entire documents
- The correlation between MAP scores and human interpretability of rationales is not empirically established

## Confidence
- **High confidence**: Computational efficiency claim (30-60% faster training) is well-supported by architecture comparison and training time measurements
- **Medium confidence**: Longformer's sparse self-attention struggles with token-level rationale extraction is supported by empirical results but mechanism explanation is speculative
- **Low confidence**: Weighted Soft Attention "does not scale well to longer documents" is based on observed score distributions rather than systematic investigation of underlying causes

## Next Checks
1. **Cross-task generalization test**: Evaluate Compositional Soft Attention on non-sentiment document classification tasks (e.g., scientific paper classification, news categorization) to verify whether sentence-wise processing maintains performance advantages when document-level context is more important than sentence-level sentiment.

2. **Attention pattern visualization**: Generate and analyze attention heatmaps comparing Longformer global attention patterns with RoBERTa sentence-level attention to empirically verify whether the claimed mechanism (global attention prioritizing document coherence) explains the performance differences in rationale extraction.

3. **Hyperparameter sensitivity analysis**: Systematically vary the k% parameter in Ranked Soft Attention across different ranges (1%, 5%, 10%, 20%) and document lengths to determine whether the claimed supervision limitation is inherent to the architecture or can be mitigated through appropriate hyperparameter tuning.
