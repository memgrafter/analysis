# Discrete Diffusion Probabilistic Models for Symbolic Music Generation

## Quick Facts
- arXiv ID: 2305.09489
- Source URL: https://arxiv.org/abs/2305.09489
- Reference count: 11
- Primary result: SCHmUBERT achieves higher consistency and variance scores than a state-of-the-art continuous diffusion model with 5× fewer parameters (76M vs 425M)

## Executive Summary
This paper introduces SCHmUBERT, a Discrete Denoising Diffusion Probabilistic Model (D3PM) for direct generation of polyphonic symbolic music. The model uses an absorbing state diffusion process to enable flexible note-level inpainting and is trained on the Lakh MIDI dataset using a hierarchical transformer architecture. SCHmUBERT outperforms a continuous diffusion model on unconditional generation and inpainting tasks while requiring significantly fewer parameters.

## Method Summary
SCHmUBERT employs an absorbing state D3PM architecture with a hierarchical transformer. The model uses a 1D CNN with kernel size 4 and stride 4 to compress musical sequences, reducing sequence length by 4× while increasing embedding dimension. A GPT-like transformer stack (24 layers, 512 dim, 8 heads) processes the compressed sequences, followed by transpose convolutions for decompression. The absorbing state diffusion process enables note-level inpainting by masking tokens with probability t/T and transitioning them to an absorbing state that can only be reversed in the reverse process.

## Key Results
- Outperforms Mittal et al.'s continuous diffusion model (425M parameters) with 76M parameters
- Achieves higher consistency and variance scores on framewise self-similarity metrics
- Demonstrates flexible note-level inpainting capability
- Shows post-hoc classifier guidance for controllable generation without retraining

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Absorbing state diffusion enables flexible note-level inpainting by masking arbitrary tokens and reconstructing them jointly
- Mechanism: Forward diffusion masks tokens with probability t/T, transitioning them to an absorbing state that can only be reversed in the reverse process. The reverse process predicts the full x0 from xt, allowing reconstruction of masked tokens without sequential dependency
- Core assumption: The absorbing state can represent any masked note or motif without loss of musical context
- Evidence anchors: Abstract states the absorbing state allows "flexible inpainting at the note level"; section explains the absorbing state "can only transition into the Absorbing state, but not leave it"

### Mechanism 2
- Claim: Hierarchical transformer with lower-level CNN summarization improves training efficiency without sacrificing model capacity
- Mechanism: Adjacent embeddings are convolved into compressed representations (lower hierarchy), reducing sequence length by 4× while increasing embedding dimension. The upper hierarchy processes these compressed sequences with GPT-like transformers, then transposed convolutions decompress back to original length
- Core assumption: The lower hierarchy preserves enough musical structure for accurate reconstruction
- Evidence anchors: Section describes "A 1D CNN with kernel size 4 and stride 4 then computes first summarization... effectively reducing the sequence length to a quarter, while increasing the embedding dimension"

### Mechanism 3
- Claim: Post-hoc classifier guidance allows controllable generation without retraining the diffusion model
- Mechanism: A separately trained classifier provides gradients to guide sampling toward desired attributes (e.g., note density). The ASD3PM's x0 parametrization allows using an off-the-shelf classifier trained only on unmasked data
- Core assumption: The classifier's gradients meaningfully steer the reverse diffusion process toward the target attribute distribution
- Evidence anchors: Section states "the x0 parametrization of our ASD3PMs allows using an off-the-shelf differentiable classifier... to guide the sampling process without the need for any retraining"

  - Why needed here: The paper applies D3PMs directly to symbolic music, requiring understanding of how discrete diffusion differs from continuous
  - Quick check question: What is the key difference between uniform and absorbing state D3PMs in terms of forward transition matrices?

- Concept: Absorbing state mechanism
  - Why needed here: This mechanism enables the note-level inpainting capability central to the paper's contributions
  - Quick check question: How does the absorbing state transition matrix differ from standard categorical distributions?

- Concept: Hierarchical sequence modeling
  - Why needed here: The architecture uses a two-level hierarchy (CNN summarization + transformer) that needs to be understood for implementation
  - Quick check question: What is the effect of the 4× reduction in sequence length on the transformer's computational complexity?

## Architecture Onboarding

- Component map: Input embeddings → 1D CNN (kernel=4, stride=4) → GPT-like transformer stack (24 layers, 512 dim, 8 heads) → 1D Transpose CNN → output head. For trio mode: three parallel lower hierarchies sum before upper hierarchy
- Critical path: Embedding → CNN compression → transformer processing → decompression → probability prediction. This path must maintain musical coherence
- Design tradeoffs: Lower hierarchy reduces computation but may lose fine-grained detail; absorbing state enables inpainting but requires careful transition matrix design
- Failure signatures: If inpainting produces musically incoherent results, check absorbing state transitions; if training is unstable, check CNN compression ratios; if samples lack diversity, check classifier guidance implementation
- First 3 experiments:
  1. Implement absorbing state forward diffusion with simple uniform masking to verify basic functionality
  2. Add CNN lower hierarchy and compare training speed/parameter count against flat transformer baseline
  3. Implement classifier guidance with a simple attribute (e.g., pitch range) and verify controllability

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do current statistical metrics for symbolic music generation fail to capture musical quality, and what alternative evaluation methods could better assess fidelity and diversity?
- Basis in paper: The authors discuss the limitations of statistical metrics and present an algorithm that creates spurious musical samples indistinguishable by current metrics
- Why unresolved: The paper demonstrates the limitations of current metrics but does not propose a comprehensive alternative evaluation framework
- What evidence would resolve it: Development and validation of new evaluation metrics that better capture musical quality, potentially combining statistical measures with perceptual studies or other qualitative assessments

### Open Question 2
- Question: Can the fine-grained control and interactivity offered by SCHmUBERT be effectively leveraged in practical music creation tools, and how would this impact the creative process?
- Basis in paper: The authors discuss SCHmUBERT's potential for interaction and control during the sampling process, which is not available in comparable generative models
- Why unresolved: While the paper presents the potential for interaction, it does not explore or validate how this could be implemented in real-world music creation tools or its impact on creativity
- What evidence would resolve it: User studies or case studies demonstrating the practical application of SCHmUBERT's fine-grained control in music creation, along with qualitative assessments of its impact on the creative process

### Open Question 3
- Question: How effective is post-hoc classifier guidance in controlling the output of diffusion models like SCHmUBERT, and what are the limitations of this approach?
- Basis in paper: The authors present a proof of concept for using a separately trained classifier to guide SCHmUBERT towards predefined note densities
- Why unresolved: The paper only provides a basic proof of concept without exploring the full potential or limitations of classifier guidance in controlling diffusion model outputs
- What evidence would resolve it: Extensive experiments testing classifier guidance with various types of classifiers and musical attributes, along with analyses of the trade-offs between control and sample quality

## Limitations

- Framewise self-similarity metrics may not correlate with perceptual musical quality and can be gamed by non-musical but statistically similar samples
- Hierarchical architecture's effectiveness relies on CNN summarization preserving musical structure without significant loss, which is not empirically validated
- Absorbing state mechanism lacks detailed ablation studies showing its necessity versus simpler masking approaches

## Confidence

- **High Confidence**: Model architecture and training procedure are well-specified and reproducible; parameter count comparison is verifiable
- **Medium Confidence**: Note-level inpainting capability works as claimed, but musical quality of generated samples needs independent verification
- **Low Confidence**: Classifier guidance results are promising but limited to a simple proof-of-concept with note density

## Next Checks

1. **Musical Quality Validation**: Conduct a listening test with professional musicians to evaluate whether framewise self-similarity metrics correlate with perceptual musical quality, addressing the paper's own caution about metric reliability

2. **Ablation Study on Hierarchical Architecture**: Compare the hierarchical transformer against a flat transformer baseline with matched parameter counts to isolate the contribution of the CNN summarization layer to performance gains

3. **Extended Classifier Guidance Evaluation**: Test the classifier guidance mechanism with multiple musical attributes (e.g., rhythm complexity, harmonic progression) and evaluate both guidance strength and sample quality degradation to establish practical utility beyond the note density proof-of-concept
