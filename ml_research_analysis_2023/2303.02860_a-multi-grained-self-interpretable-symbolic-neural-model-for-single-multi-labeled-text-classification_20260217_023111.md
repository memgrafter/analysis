# A Multi-Grained Self-Interpretable Symbolic-Neural Model For Single/Multi-Labeled Text Classification

## Quick Facts
- arXiv ID: 2303.02860
- Source URL: https://arxiv.org/abs/2303.02860
- Reference count: 40
- Primary result: Achieves good prediction accuracy while providing interpretable span-level labels without requiring span-level gold labels

## Executive Summary
This paper proposes a multi-grained self-interpretable symbolic-neural model for text classification that can handle both single-label and multi-label tasks in a unified framework. The model combines a structured language model backbone with a neural network to predict class labels of text spans from constituency trees without requiring span-level gold labels. Through self-supervised learning using raw texts and sentence-level labels, the model achieves strong classification performance while maintaining interpretability by explicitly predicting span labels that align with human rationales.

## Method Summary
The proposed model leverages a structured language model (such as Fast-R2D2) to parse input text into constituency trees, then uses an MLP layer to estimate label distributions from node representations. A top-down encoder optionally fuses information from inside and outside of spans. The model employs dynamic programming to maximize the probability that a tree's yield contains correct labels, handling both single-label and multi-label classification through a unified label extraction framework. Training occurs in a self-supervised manner without requiring span-level gold labels, making the approach general and applicable to various constituent-level self-interpretable classification tasks.

## Key Results
- The model achieves good prediction accuracy in downstream text classification tasks
- Predicted span labels are consistent with human rationales to a certain degree
- The approach successfully handles both single-label and multi-label classification tasks in a unified way
- Experiments demonstrate the model's ability to predict span-level labels without access to span-level gold labels

## Why This Works (Mechanism)

### Mechanism 1
The model predicts span-level labels without requiring span-level gold labels by learning constituency trees in a self-supervised manner through the structured language model. The symbolic-neural model uses dynamic programming to estimate the probability that a tree's yield contains the correct labels, maximizing the probability of label consistency. This relies on the assumption that constituents in text correspond to at most one label and that label states are independent of each other.

### Mechanism 2
The model achieves good prediction accuracy while being inherently interpretable by leveraging the structured language model backbone to provide intermediate representations for each constituency node. These representations serve as symbolic interfaces that allow explicit prediction of span labels. The model's accuracy depends on the structured language model's ability to learn reasonable syntax structures in an unsupervised manner and provide useful intermediate representations for each constituency node.

### Mechanism 3
The model handles both single-label and multi-label text classification tasks in a unified way through a yield function that traverses a label tree in a top-down manner and extracts labels. This unified framework relies on the yield function correctly extracting labels from the label tree and the training objective maximizing the probability of label consistency across different label scenarios.

## Architecture Onboarding

- **Component map**: Structured language model (Fast-R2D2) -> MLP layer -> Top-down encoder -> Dynamic programming algorithm
- **Critical path**: 1) Parse input text into constituency tree using structured language model, 2) Compute node representations for each span, 3) Use MLP to estimate label probabilities, 4) Apply yield function to extract labels, 5) Use dynamic programming to maximize label consistency probability
- **Design tradeoffs**: Using structured language model backbone allows for explicit span labeling but may be slower than pure neural models; top-down encoder improves performance but adds complexity; mutual-exclusiveness constraint improves interpretability but may limit expressiveness
- **Failure signatures**: Poor parsing accuracy from structured language model backbone, incorrect span label predictions despite high parsing accuracy, inability to handle complex multi-label cases with nested or overlapping labels
- **First 3 experiments**: 1) Train on simple single-label dataset (SST-2) and evaluate accuracy and interpretability, 2) Train on multi-label dataset (ATIS) and compare to baselines, 3) Analyze predictions on dataset with known interpretability issues (CoLA) to identify failure modes

## Limitations

- The model relies on the assumption that constituents correspond to at most one label and that label states are independent, which may not hold in many real-world scenarios
- The effectiveness of the structured language model backbone in providing useful intermediate representations for span labels depends heavily on the quality of unsupervised syntax learning
- The lack of direct evidence from related work addressing the specific mechanisms proposed raises questions about novelty and robustness

## Confidence

- Mechanism 1 (Predicting span labels without gold labels): **Medium** - The theoretical framework is sound, but the assumption of label independence may not hold in practice
- Mechanism 2 (Achieving accuracy and interpretability): **High** - The combination of structured language models and symbolic interfaces is a well-established approach in interpretable NLP
- Mechanism 3 (Unified single/multi-label handling): **Medium** - The yield function approach is novel, but its effectiveness in complex multi-label scenarios is unclear
