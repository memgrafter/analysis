# Prompt Tuning based Adapter for Vision-Language Model Adaption

## Quick Facts
- arXiv ID: 2303.15234
- Source URL: https://arxiv.org/abs/2303.15234
- Authors: 
- Reference count: 40
- Key outcome: Proposed Prompt-Adapter method achieves state-of-the-art performance on 11 few-shot image classification datasets, especially in extreme few-shot settings (1-8 shots).

## Executive Summary
This paper introduces Prompt-Adapter, a parameter-efficient method for few-shot image classification using vision-language models like CLIP. The approach combines pre-trained text prompt tuning with a cache-based adapter network that stores training image features and labels. By leveraging both CLIP's pre-trained knowledge and the few-shot training data through learned prompts and cached features, the method achieves superior performance compared to existing approaches. Multi-task pre-trained prompt initialization further improves adaptation performance.

## Method Summary
The Prompt-Adapter method combines CLIP's pre-trained image and text encoders with learnable prompt vectors and a cache model. The cache model stores image features and one-hot label vectors, computing cosine similarity between test images and cached features to generate logits. These cache logits are combined with CLIP-derived logits using learned prompts to produce final classification outputs. The method employs separate optimization of prompts and cache features to prevent interference, and introduces multi-task pre-trained prompt initialization by training prompts across 11 diverse datasets before single-task adaptation.

## Key Results
- Prompt-Adapter achieves state-of-the-art performance on 11 few-shot image classification datasets
- Multi-task pre-trained prompt initialization improves single-task performance across all tested settings
- Separate optimization of prompts and cache features outperforms joint optimization
- Particularly effective in extreme few-shot scenarios (1-8 shots per class)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Combining learnable prompts with a cache model enables efficient few-shot adaptation without full fine-tuning.
- Mechanism: The method stores cached features of training images and labels in a key-value database, and combines these cached logits with CLIP-derived logits using learned prompts to classify test images.
- Core assumption: CLIP's pre-trained text encoder can be effectively guided by learned prompts to align with the few-shot training data, while the cache model provides direct access to relevant training features.
- Evidence anchors:
  - [abstract] "The key idea is to combine pre-trained text prompt tuning with a parameter-efficient adapter network. The adapter stores cached features of training images and their labels..."
  - [section 3.2] "Our Prompt-Adapter adopts a similar network structure as Tip-Adapter but replaces the original manual prompt...with learnable vectors"
  - [corpus] Weak evidence - no direct comparison of this exact combination in corpus
- Break condition: If the learned prompts fail to align with the training data distribution, the combined logits will be dominated by either the cache model (overfitting) or CLIP (underfitting), reducing accuracy.

### Mechanism 2
- Claim: Multi-task pre-trained prompt initialization significantly improves single-task performance.
- Mechanism: Prompts are first trained across 11 diverse datasets to learn a joint representation, then used as initialization for single-task adaptation, capturing cross-domain knowledge.
- Core assumption: Knowledge learned from multiple diverse tasks can generalize and improve adaptation to new tasks through better initialization.
- Evidence anchors:
  - [abstract] "Based on our findings, we introduce a new model...that combines pre-trained prompt tunning with an efficient adaptation network"
  - [section 4.2] "pre-trained prompt initialization achieves 80.64% accuracy, and outperform the other methods on all three settings"
  - [corpus] Weak evidence - limited corpus support for multi-task prompt initialization in VL models
- Break condition: If the source tasks are too dissimilar from the target task, the initialization may introduce noise rather than useful prior knowledge.

### Mechanism 3
- Claim: Separate training of prompts and cache features outperforms joint optimization.
- Mechanism: The prompt is first optimized using CLIP logits, then frozen while cache features are optimized, preventing interference between the two learning processes.
- Core assumption: Joint optimization creates a balancing effect that degrades prompt learning quality, while separate optimization allows each component to specialize.
- Evidence anchors:
  - [section 3.2] "We employ two different strategies: the separately optimized strategy and the joint optimization strategy"
  - [section 4.2] "separate training achieved 81.96% accuracy on average, better than joint training"
  - [corpus] Weak evidence - no corpus examples of this specific comparison in VL adaptation
- Break condition: If the training data is extremely limited, the separation might prevent the model from finding optimal parameter interactions between prompts and cache.

## Architecture Onboarding

- Component map: CLIP image encoder → CLIP text encoder → Learned prompt vectors → Cache model (image features + one-hot labels) → Final logits (linear combination of cache logits and CLIP logits)
- Critical path: Input image → Image encoder → Cosine similarity with text embeddings → Cache logits computation → Final logit combination → Classification output
- Design tradeoffs: The method trades some accuracy (compared to full fine-tuning) for efficiency and reduced overfitting on small datasets
- Failure signatures: Poor performance on datasets with high intra-class variance, overfitting when cache model dominates, underfitting when prompts fail to align with data
- First 3 experiments:
  1. Implement the training-free variant (Prompt-Adapter) and test on a single dataset (e.g., Flowers102) with 1-shot setting
  2. Add multi-task prompt initialization and compare performance against random initialization
  3. Implement the learnable variant (Prompt-Adapter-F) and test joint vs separate optimization strategies on the same dataset

## Limitations
- The paper lacks detailed implementation specifics for the cache model architecture, particularly how cached image features and labels are stored and retrieved
- The multi-task pre-training procedure for prompt initialization is described but not detailed enough for direct replication
- The experimental setup assumes access to specific dataset splits and evaluation protocols that are not fully specified

## Confidence

- Separate optimization outperforming joint optimization: Medium confidence
- Multi-task prompt initialization improving performance: Medium confidence
