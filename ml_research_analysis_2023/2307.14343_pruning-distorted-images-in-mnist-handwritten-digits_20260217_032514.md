# Pruning Distorted Images in MNIST Handwritten Digits

## Quick Facts
- arXiv ID: 2307.14343
- Source URL: https://arxiv.org/abs/2307.14343
- Authors: 
- Reference count: 0
- One-line primary result: A two-stage deep learning approach achieves over 99.5% accuracy on MNIST by detecting and removing distorted images from the training set

## Executive Summary
This paper proposes a two-stage deep learning approach to improve handwritten digit recognition accuracy by identifying and removing distorted images from the MNIST dataset. The method first trains a neural network to detect potentially distorted digits in the training set, which are then manually validated and removed. The model is then retrained on this cleaned dataset, resulting in improved accuracy and confidence levels. The approach specifically addresses issues of overfitting and underfitting caused by ambiguous training examples.

The proposed methodology achieves an accuracy rate of over 99.5% on the testing dataset without requiring data augmentation techniques. By reducing the impact of ambiguous images that are challenging even for human observers, the approach demonstrates the potential for enhancing digit classification accuracy. The key innovation lies in recognizing that removing problematic training examples can be more effective than traditional methods like data augmentation for improving model performance.

## Method Summary
The approach employs a neural network with three convolutional layers (32 and 64 filters) followed by batch normalization and dropout layers to prevent overfitting. In the first stage, this network is trained on the full MNIST training set (60,000 images) to identify potentially distorted digits by analyzing confidence levels during prediction. A threshold of 0.99 confidence is used to flag suspicious images, which are then manually validated and removed from the training set. In the second stage, the model is retrained on the cleaned dataset (approximately 59,511 images after removing 489 distorted examples) and evaluated on the standard 10,000-image test set. The entire process uses 5-fold cross-validation to ensure robustness.

## Key Results
- Achieves over 99.5% accuracy on MNIST test dataset after removing distorted images
- Successfully addresses overfitting and underfitting issues through dataset cleaning
- Improves model confidence levels in predictions by reducing ambiguous training examples
