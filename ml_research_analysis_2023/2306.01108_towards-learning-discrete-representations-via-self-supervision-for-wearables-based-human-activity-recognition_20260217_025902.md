# Towards Learning Discrete Representations via Self-Supervision for Wearables-Based Human Activity Recognition

## Executive Summary
This work revisits discrete representations for wearables-based human activity recognition, proposing a novel method that combines self-supervised learning with vector quantization to learn effective symbolic representations from continuous sensor data. Unlike traditional discretization approaches that suffer from substantial precision loss, this method learns a mapping between short sensor data spans and a codebook of vectors, achieving performance on par with or exceeding continuous representations. The approach leverages Enhanced CPC for self-supervised pre-training and demonstrates effectiveness across six diverse datasets spanning different sensor locations and activity types.

## Method Summary
The method uses Enhanced CPC as a self-supervised base to learn latent representations from unlabeled sensor data, which are then discretized through vector quantization into discrete symbols. A convolutional encoder maps sensor windows to latent vectors, which are quantized using a learned codebook, and an aggregator summarizes temporal context for future timestep prediction. These discrete representations are then used for activity recognition through a recurrent neural network classifier. The framework also enables application of NLP-based pre-training techniques like RoBERTa to further enhance representation quality.

## Key Results
- Discrete representations achieve F1-scores comparable to or exceeding continuous representations across six benchmark datasets
- Enhanced CPC-based discrete representations outperform traditional discretization methods like SAX
- NLP-based pre-training with RoBERTa further improves classification performance when applied to discrete representations
- The approach demonstrates effectiveness across different sensor locations (wrist, waist, leg) and activity types (locomotion, daily living, gym exercises)

## Why This Works (Mechanism)

### Mechanism 1
Learning discrete representations via self-supervised vector quantization can achieve comparable or better performance than continuous representations for locomotion-style and daily living activities. Vector quantization maps short spans of continuous sensor data to a codebook of discrete vectors, reducing resolution but enabling efficient symbolic sequence processing and improved noise robustness. The discrete codebook can effectively capture essential discriminative features of human movements, especially for activities with distinct patterns.

### Mechanism 2
Self-supervised learning, specifically Enhanced CPC, provides an effective base for learning discrete representations without requiring labeled data. Enhanced CPC uses a contrastive future timestep prediction task to learn useful representations from unlabeled data, which are then quantized into discrete symbols. The future timestep prediction task captures slowly varying signal of sensor data while ignoring local noise, leading to robust representations.

### Mechanism 3
NLP-based pre-training techniques like RoBERTa can further improve the performance of discrete representations by learning better embeddings for the symbolic sequences. Pre-trained RoBERTa models can be fine-tuned on the discrete representations to learn more effective embeddings, which can then be used for activity recognition. The discrete representations can be treated as symbolic sequences similar to text, allowing the use of powerful NLP pre-training techniques.

## Architecture Onboarding

- Component map: Convolutional encoder -> Vector quantization module -> Aggregator (causal convolutional network) -> Classifier (RNN + MLP)

- Critical path:
  1. Pre-training: Learn the mapping between sensor data and codebook vectors using Enhanced CPC and vector quantization
  2. Fine-tuning: Use the learned discrete representations as input for activity recognition with an RNN classifier

- Design tradeoffs:
  - Alphabet size vs. representation fidelity: Larger alphabet sizes allow for more detailed representations but may increase computational complexity
  - Encoder output frequency vs. temporal resolution: Higher output frequencies provide more detailed representations but may increase training time and memory requirements
  - Receptive field size vs. representation granularity: Smaller receptive fields capture finer details but may miss longer-term dependencies

- Failure signatures:
  - Poor performance on fine-grained activities: May indicate that the codebook is too coarse or the self-supervised pretext task is not capturing relevant features
  - Long-tailed distribution of discrete representations: May suggest that the codebook is too large or that certain symbols are rarely used, leading to inefficient representation

- First 3 experiments:
  1. Compare the performance of discrete representations with different alphabet sizes on a benchmark dataset to understand the tradeoff between representation fidelity and computational complexity
  2. Vary the encoder output frequency and receptive field size to study their impact on representation granularity and activity recognition performance
  3. Apply NLP-based pre-training techniques (e.g., RoBERTa) to the discrete representations and evaluate their impact on activity recognition performance compared to randomly initialized embeddings

## Open Questions the Paper Calls Out

### Open Question 1
How does the learned discrete representation perform on fine-grained gesture recognition tasks compared to locomotion and daily living activities? While the paper provides evidence of poor performance on fine-grained activities, it does not explore potential modifications to the discretization method that could improve its effectiveness for such tasks.

### Open Question 2
What is the impact of using different self-supervised learning methods (e.g., Autoencoders, Multi-task self-supervision, SimCLR) as the base for discrete representation learning? The analysis is limited, and the paper does not explore the potential of combining different self-supervised methods with the discretization framework or the impact of varying the encoder architecture for these methods.

### Open Question 3
How does the learned discrete representation perform on other sensor modalities beyond accelerometers, such as gyroscopes or magnetometers? The paper focuses on accelerometer data, but the discretization framework could potentially be applied to other sensor modalities. The effectiveness of the learned representations may vary depending on the sensor type and the activities being recognized.

## Limitations

- The fixed alphabet size (100 codewords per group) and encoder architecture may not be optimal for all activity types and sensor configurations
- Claims about the superiority of discrete representations for applications beyond recognition (activity discovery, summarization, fingerprinting) remain speculative without empirical validation
- The method shows reduced effectiveness for fine-grained gesture recognition tasks compared to locomotion and daily living activities

## Confidence

- **High confidence**: The technical implementation of vector quantization and Enhanced CPC framework is sound and reproducible
- **Medium confidence**: Claims about discrete representations enabling NLP-based pre-training techniques are supported by experimental results
- **Low confidence**: Claims about the superiority of discrete representations for applications beyond recognition remain speculative
