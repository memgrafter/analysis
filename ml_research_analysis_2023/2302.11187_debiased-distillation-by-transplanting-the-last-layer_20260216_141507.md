# Debiased Distillation by Transplanting the Last Layer

## Quick Facts
- **arXiv ID:** 2302.11187
- **Source URL:** https://arxiv.org/abs/2302.11187
- **Reference count:** 8
- **Primary result:** DeTT achieves up to 16.1% improvement in worst-group accuracy over baselines on Waterbirds dataset

## Executive Summary
This paper addresses the challenge of transferring debiased knowledge from a teacher model to a student model when training data contains spurious correlations. The authors propose DeTT (Debiasing by Teacher Transplanting), which transplants the teacher's last layer directly to the student and distills feature maps with sample upweighting. Experiments on four benchmark datasets show DeTT consistently outperforms baselines in worst-group accuracy, with gains up to 16.1% on Waterbirds. The method requires only limited bias annotations and can leverage out-of-domain data for distillation without bias supervision.

## Method Summary
DeTT addresses knowledge distillation in the presence of spurious correlations by combining two key innovations: (1) directly transplanting the teacher's last layer to preserve debiasing information, and (2) distilling feature maps with sample upweighting for bias-conflicting samples. The method trains a debiased teacher model (using group DRO or JTT), then transfers its knowledge to a smaller student model. During distillation, samples where the spurious attribute misleads prediction are identified and upweighted in the feature matching loss, forcing the student to learn robust representations that focus on the true label signal rather than shortcuts.

## Key Results
- DeTT consistently outperforms baselines in worst-group accuracy across all four benchmark datasets
- Upweighting bias-conflicting samples is essential, providing up to 16.1% gain on Waterbirds
- DeTT can leverage out-of-domain unlabeled data for distillation without bias supervision
- The student's worst subgroup typically matches the teacher's worst subgroup when using last-layer transplantation

## Why This Works (Mechanism)

### Mechanism 1
Transplanting the last layer preserves the teacher's debiasing information while the feature map is fine-tuned for the student's data distribution. The last fully connected layer is assumed to encode the core debiasing capability, so directly transplanting it locks in the teacher's bias-mitigating decision boundaries. The feature extractor is then distilled with upweighted bias-conflicting samples, allowing the student to learn domain-appropriate feature representations without losing the debiasing property.

### Mechanism 2
Upweighting bias-conflicting samples during feature map distillation compensates for the skewed data distribution in the training set. A biased model identifies samples where the spurious attribute misleads prediction. These samples are then upweighted during distillation, forcing the student's feature extractor to focus on the true label signal rather than shortcuts.

### Mechanism 3
Using a debiased teacher ensures that the student learns the correct label-signal even when the training data is biased. The teacher, trained with debiasing algorithms like group DRO, has learned to focus on the core label signal. By distilling from this teacher, the student inherits this signal even if the training data contains spurious correlations.

## Architecture Onboarding

- **Component map:** Teacher model -> Projector layer (optional) -> Student model, with Identification model for sample selection
- **Critical path:** 1) Train debiased teacher on full dataset 2) Train identification model with ERM 3) For each batch: extract features, identify bias-conflicting samples, apply upweighting, compute MSE loss, compute classification loss with transplanted last layer, update student
- **Design tradeoffs:** Projector layer adds parameters but enables dimension matching; upweighting hyperparameter requires tuning but significantly impacts debiasing; external unlabeled data avoids upweighting but may reduce performance
- **Failure signatures:** Student's worst-group accuracy worse than ERM baseline (upweighting misconfigured); student's average accuracy drops significantly (projector/last layer harming feature learning); student's performance matches teacher but worst-group is poor (debiasing signal not transferring)
- **First 3 experiments:** 1) Compare DeTT with and without upweighting on Waterbirds to confirm 16.1% gain 2) Test DeTT with different λ_up values (5, 20, 50) to find optimal upweighting 3) Replace teacher with one trained via JTT to test robustness to teacher training method

## Limitations
- The method relies on the assumption that the last layer contains most debiasing information, which is not empirically validated across architectures
- Upweighting effectiveness depends heavily on hyperparameter tuning (λ_up) with limited sensitivity analysis provided
- Performance on real-world datasets with complex bias patterns remains unclear, as experiments use benchmark datasets with known spurious correlations

## Confidence
- **High confidence:** Empirical methodology is sound with proper ablation studies and baseline comparisons
- **Medium confidence:** Theoretical justification for last-layer transplantation is plausible but not rigorously proven
- **Medium confidence:** Generalization to out-of-domain data is promising but tested only on one dataset pair
