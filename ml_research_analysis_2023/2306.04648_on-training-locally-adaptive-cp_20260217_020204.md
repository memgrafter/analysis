# On training locally adaptive CP

## Quick Facts
- arXiv ID: 2306.04648
- Source URL: https://arxiv.org/abs/2306.04648
- Reference count: 6
- Primary result: Trainable attribute-dependent transformations of conformity scores produce marginally valid, locally adaptive prediction intervals

## Executive Summary
This paper addresses the challenge of making Conformal Prediction (CP) intervals locally adaptive to object attributes while maintaining marginal validity. The core innovation is a parametric transformation of conformity scores that depends on object attributes, enabling CP intervals to have different sizes for different objects. The method guarantees marginal validity when the transformation is monotonic in the conformity score, and can be optimized using standard gradient methods. Experiments demonstrate efficiency gains over traditional CP methods on both synthetic and real-world datasets.

## Method Summary
The method redefines conformity scores through a parametric attribute-dependent transformation φ_X(A) that is monotonic in A for all X. Under this monotonicity condition, the resulting prediction intervals maintain marginal validity while achieving local adaptivity. The transformation parameters are trained by minimizing an averaged efficiency objective over all confidence levels, making the otherwise non-differentiable quantile operation smooth and tractable. The approach generalizes existing methods like ERC while providing more flexibility in the choice of transformation class.

## Key Results
- Locally adaptive CP intervals outperform non-adaptive CP intervals in terms of size while maintaining empirical validity
- The choice of model class for φ_X does not appear to be crucial, with minor performance differences across different classes
- The method works on both synthetic and real-world data, demonstrating feasibility and efficiency
- Training φ_X to maximize interval efficiency is feasible with standard gradient methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The proposed method maintains marginal validity while achieving local adaptivity through a monotonic transformation of conformity scores.
- Mechanism: By defining a parametric family of attribute-dependent transformations ϕ_X(A) that are monotonic in A for all X, the ranking of conformity scores is preserved while allowing interval sizes to vary with object attributes. This preserves the exchangeability argument used in standard CP proofs while enabling locally adaptive intervals.
- Core assumption: Assumption 1 requires ϕ_X to be strictly increasing in A and have the same codomain for all X.
- Evidence anchors:
  - [abstract]: "Under certain conditions and if ϕ_X is monotonic in A for any X, the transformations produce prediction intervals that are guaranteed to be marginally valid and have X-dependent sizes."
  - [section]: "Requiring ϕ′_X > 0 guarantees that B = ϕ_X(A) is a well-defined conformity score and the existence of the inverse map, ϕ^−1_X : B_X → R+"
- Break condition: If the monotonicity condition fails (ϕ′_X ≤ 0 for some X or A), the inverse transformation may not exist or the ranking of scores may change, breaking both validity and interpretability.

### Mechanism 2
- Claim: The method enables gradient-based optimization of the transformation parameters without approximations.
- Mechanism: By averaging the confidence-specific cost function ℓ_α over all confidence levels α ∈ [0, 1], the non-differentiable empirical quantile operation becomes smooth and tractable, allowing standard gradient methods to optimize the transformation parameters θ.
- Core assumption: The model class Φ_θ must be smooth in θ for all X and A.
- Evidence anchors:
  - [section]: "The confidence-specific cost function contains non-differentiable terms but becomes smooth and tractable when it is averaged over all possible confidence levels"
  - [section]: "The smoothness of (23) allows using any gradient-based optimization method"
- Break condition: If the transformation class is not smooth in θ, or if the averaging does not sufficiently smooth the objective, gradient optimization may fail or produce poor results.

### Mechanism 3
- Claim: The approach generalizes existing methods like ERC while providing more flexibility.
- Mechanism: ERC is a special case of the proposed transformation ϕ_X(A) = A/(g(X)^2 + γ), where g models conditional residuals. The proposed method extends this by allowing more general parametric classes and optimizing them directly for efficiency.
- Core assumption: The transformation class must satisfy Assumption 1.
- Evidence anchors:
  - [section]: "Our transformation of the conformity score is more general and is not pre-trained by fitting the residuals"
  - [section]: "The scheme generalizes the Error Re-weighted Conformal approach (ERC) of Papadopoulos et al. (2008, 2011)"
- Break condition: If the transformation class is too restrictive or poorly chosen, it may not capture the true error structure, limiting efficiency gains.

## Architecture Onboarding

- Component map:
  - Point prediction model (fixed, pre-trained) -> Transformation class Φ_θ -> Optimization module (gradient-based) -> Validation module (empirical validity and efficiency checks)

- Critical path:
  1. Pre-train point prediction model
  2. Initialize transformation parameters θ
  3. Compute transformed conformity scores on calibration data
  4. Optimize θ using gradient descent on averaged efficiency objective
  5. Validate intervals on held-out test data

- Design tradeoffs:
  - Model complexity vs. overfitting risk in transformation class
  - Smoothness of transformation class vs. expressiveness
  - Computational cost of implicit differentiation vs. closed-form alternatives
  - Choice of base conformity measure (a = (f(X) - Y)^2 vs alternatives)

- Failure signatures:
  - Non-monotonic transformations leading to invalid intervals
  - Overfitting to calibration data (poor generalization)
  - Unstable training (gradient explosion or vanishing)
  - Violation of Assumption 1 (different codomains for different X)

- First 3 experiments:
  1. Verify validity: Test that empirical coverage matches nominal confidence level across different X values
  2. Compare efficiency: Measure average interval size against baseline CP method
  3. Sensitivity analysis: Test robustness to different transformation classes and hyperparameter choices

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Is training the underlying point-prediction model or the conformity score transformation more effective for improving CP efficiency?
- Basis in paper: [explicit] The authors mention that Einbinder et al. (2022) trains the point-prediction model while their approach trains the conformity score transformation, and suggest investigating whether these approaches are equivalent theoretically and practically.
- Why unresolved: No empirical comparison is provided between these two approaches to determine which is more effective.
- What evidence would resolve it: Direct experimental comparison of Einbinder et al.'s approach (training the underlying model) versus the proposed approach (training the conformity transformation) on identical datasets and metrics.

### Open Question 2
- Question: How does combining the proposed transformation-based approach with existing re-weighting methods affect CP performance?
- Basis in paper: [explicit] The authors state their approach is "not incompatible" with methods that approximate object-conditional validity through re-weighting, and suggest merging could help localize intervals on specific tasks.
- Why unresolved: No experiments are presented that combine the transformation approach with re-weighting methods.
- What evidence would resolve it: Experiments demonstrating CP performance when combining transformation-based adaptation with re-weighting methods like those in Lei and Wasserman (2014) or Barber et al. (2022).

### Open Question 3
- Question: How sensitive is the proposed method to the choice of model class for the transformation function φ_X?
- Basis in paper: [explicit] The authors test four different model classes (ERC, linear, exp, sigma) and note "the choice of the model class does not look to be crucial, with minor and data set-dependent performance differences," but do not conduct a systematic sensitivity analysis.
- Why unresolved: The authors only test four specific model classes and do not explore the full space of possible model classes or their impact on performance.
- What evidence would resolve it: Systematic experiments testing a wider range of model classes (e.g., different network architectures, kernel methods, spline-based approaches) and analyzing how sensitive performance is to these choices.

## Limitations
- The method requires the transformation φ_X to be monotonic in A for all X, which may be restrictive for complex error distributions
- Assumption 1 imposes that all φ_X have the same codomain, which may not hold for certain model classes without careful parameterization
- The approach only guarantees marginal validity, not object-conditional validity, which may be insufficient for applications requiring strict conditional guarantees

## Confidence

- **High Confidence**: The theoretical framework is sound and the monotonicity condition is correctly identified as the key requirement for maintaining validity while achieving adaptivity.
- **Medium Confidence**: Empirical results demonstrate efficiency gains on both synthetic and real-world datasets, but the relative performance across different transformation classes is not systematically explored.
- **Low Confidence**: The sensitivity of the method to violations of Assumption 1 and the behavior under extreme distributional shifts remain untested.

## Next Checks

2. **Conditional Validity Analysis**: Evaluate the degree of conditional validity achieved by the method through stratified coverage analysis across different attribute values.
3. **Scaling Behavior**: Assess computational scaling and memory requirements as the transformation class complexity increases, particularly for implicit differentiation cases.
