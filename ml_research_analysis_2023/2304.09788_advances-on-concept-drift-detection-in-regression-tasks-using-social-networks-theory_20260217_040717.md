# Advances on Concept Drift Detection in Regression Tasks using Social Networks Theory

## Quick Facts
- **arXiv ID**: 2304.09788
- **Source URL**: https://arxiv.org/abs/2304.09788
- **Reference count**: 15
- **Primary result**: SFNR+ADWIN achieves statistically similar or better accuracy compared to state-of-the-art methods while improving accuracy in concept drift scenarios without requiring user-defined parameters for drift detection.

## Executive Summary
This paper extends the Scale-free Network Regressor (SFNR) by replacing its period-based drift detection with the ADWIN algorithm. The resulting SFNR+ADWIN maintains a dynamic ensemble of regression experts modeled as a scale-free network, where experts are added or removed based on detected concept drifts. Experiments on synthetic and real-world data streams show that SFNR+ADWIN achieves statistically similar or better accuracy compared to state-of-the-art methods like FIMT-DD, AMRules, and AddExp, while also offering competitive processing times. Notably, it improves accuracy in concept drift scenarios without requiring user-defined parameters for drift detection.

## Method Summary
The SFNR+ADWIN algorithm combines a dynamic ensemble of regression experts with social networks theory and adaptive drift detection. It maintains a scale-free network of experts where node importance is inversely proportional to local RMSE. When ADWIN detects concept drift, the worst expert is removed and a new one is added through preferential attachment based on error. Expert predictions are weighted by centrality metrics (Eigenvector centrality) rather than accuracy alone, and the final prediction is computed as a weighted mean. The algorithm operates on data streams using a prequential procedure with sliding window evaluation.

## Key Results
- SFNR+ADWIN achieves statistically similar or better accuracy compared to state-of-the-art methods (FIMT-DD, AMRules, AddExp) on benchmark datasets
- The algorithm improves accuracy in concept drift scenarios without requiring user-defined parameters for drift detection
- SFNR+ADWIN offers competitive processing times while maintaining accuracy

## Why This Works (Mechanism)

### Mechanism 1
Dynamic ensemble size via scale-free network model improves concept drift handling. The algorithm maintains a scale-free network of regression experts where node importance is inversely proportional to local RMSE. Hubs (high centrality) dominate predictions, and preferential attachment based on error ensures accurate experts gain more influence. Core assumption: Experts added at different times will have non-convergent concepts, preserving diversity.

### Mechanism 2
ADWIN-based drift detection eliminates need for user-defined drift detection parameters. ADWIN monitors prediction error windows and detects statistically significant changes in error distribution, triggering network evolution (expert addition/removal) without manual period size or threshold tuning. Core assumption: ADWIN's statistical test reliably distinguishes true concept drift from noise.

### Mechanism 3
Centrality-weighted voting improves prediction accuracy during drift. Expert predictions are weighted by their centrality metrics (Eigenvector centrality) rather than accuracy alone, ensuring that well-connected experts (regardless of current error) contribute proportionally to the final prediction. Core assumption: Centrality metrics correlate with long-term predictive quality better than short-term accuracy.

## Architecture Onboarding

- **Component map**: Data stream source → Prediction phase → ADWIN drift detector → Network evolution module → Expert pool → Centrality calculator → Weighted prediction aggregator
- **Critical path**: Instance arrives → Get prediction via weighted mean → Update ADWIN → If drift detected → Remove worst expert → Rewire → Add new expert → Recalculate centrality
- **Design tradeoffs**: Fixed max network size prevents memory explosion but may limit accuracy during complex drifts; Eigenvector centrality provides nuanced weighting but requires O(n²) computation; ADWIN confidence parameter trades false positives against detection latency
- **Failure signatures**: Network becomes disconnected → Rewiring process triggered; All experts have similar RMSE → Network loses diversity; ADWIN triggers too frequently → Network evolution overhead dominates
- **First 3 experiments**: 1) Synthetic rotating hyperplane with single abrupt drift; 2) Real wine quality dataset with gradual concept evolution; 3) Stock market data with seasonal patterns and abrupt market shifts

## Open Questions the Paper Calls Out

### Open Question 1
How do different centrality metrics (Degree, Betweenness, Closeness, Eigenvector, PageRank) affect the ensemble's performance in various types of concept drift scenarios? The paper only briefly mentions that Eigenvector centrality performed best on average but doesn't explore how different metrics perform under specific drift patterns (abrupt, gradual, incremental).

### Open Question 2
What is the optimal network size for SFNR+ADWIN in different data stream scenarios, and how does it impact accuracy and processing time? The paper mentions a user-given maximum network size parameter to prevent indefinite growth, but doesn't explore how different sizes affect performance.

### Open Question 3
How does SFNR+ADWIN perform compared to state-of-the-art methods in multi-label stream classification tasks? The paper mentions future work on multi-label stream classification but doesn't provide any results for this task.

## Limitations
- The paper's claims about scale-free network topology providing inherent drift resistance rely heavily on theoretical assertions without empirical validation of network structure properties
- The ADWIN parameter (delta) is mentioned as user-defined, yet the paper claims parameter-free operation, creating internal inconsistency
- Centrality weighting mechanism assumes Eigenvector centrality correlates with predictive quality, but this relationship is not empirically tested

## Confidence
- **High confidence**: Claims about improved accuracy on specific benchmark datasets compared to FIMT-DD and AMRules
- **Medium confidence**: Claims about parameter-free drift detection, as ADWIN still requires delta tuning
- **Low confidence**: Claims about scale-free network topology providing systematic advantages, lacking structural analysis

## Next Checks
