# Branch & Learn with Post-hoc Correction for Predict+Optimize with Unknown Parameters in Constraints

## Quick Facts
- arXiv ID: 2303.06698
- Source URL: https://arxiv.org/abs/2303.06698
- Reference count: 21
- Key outcome: Proposes Branch & Learn with Post-hoc Correction (B&L-C) for Predict+Optimize with unknown parameters in both objective and constraints, achieving significant improvement in solution quality on maximum flow problems with unknown edge capacities.

## Executive Summary
This paper extends the Branch & Learn framework to handle Predict+Optimize problems where parameters are unknown in both the objective function and constraints. The key innovation is using post-hoc regret as a loss function that measures solution quality by considering the cost of correcting infeasible solutions. The framework recursively decomposes optimization problems and performs exact gradient-free training through coordinate descent. Experiments on maximum flow problems demonstrate significant improvements over baseline methods when comparing solution quality.

## Method Summary
The paper proposes Branch & Learn with Post-hoc Correction (B&L-C) to extend the Branch & Learn framework for handling unknown parameters in constraints. The method uses post-hoc regret as the loss function, which measures the quality of predicted parameters by considering the cost of correcting infeasible solutions. The framework recursively decomposes optimization problems into piecewise linear functions over a free coefficient, then uses coordinate descent to find optimal parameters without computing gradients. Different combinations of correction functions (mapping infeasible solutions to feasible ones) and penalty functions (adding cost for correction) yield different post-hoc regret function forms, affecting trainability and solution quality.

## Key Results
- Significant improvement in solution quality compared to state-of-the-art approximation methods on maximum flow problems with unknown edge capacities
- Framework successfully handles recursively solvable problems with unknown parameters in both objectives and constraints
- Different combinations of correction and penalty functions produce varying post-hoc regret function forms, providing insights for defining appropriate loss functions in different scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Post-hoc regret enables exact gradient-free training by recursively decomposing optimization subproblems and correcting infeasible solutions.
- Mechanism: The framework uses a recursive algorithm template to convert a parameterized optimization problem into a piecewise linear function over the free coefficient γ. For each interval, the estimated solution is computed, then corrected with true parameters, and the post-hoc regret is evaluated. The coordinate descent loop then finds the optimal γ without computing gradients.
- Core assumption: The optimization problem is solvable by a recursive algorithm satisfying the template's restrictions, and the solution structure remains piecewise linear in the free coefficient.
- Evidence anchors: [abstract] "We first show how to compute Post-hoc Regret exactly for any optimization problem solvable by a recursive algorithm satisfying simple conditions." [section 3] "B&L presents a standard template for recursive algorithms and shows how to cleanly adapt a recursive algorithm to Convert."

### Mechanism 2
- Claim: Different correction and penalty functions yield different post-hoc regret function forms, affecting trainability and solution quality.
- Mechanism: Correction functions map infeasible estimated solutions to feasible ones under true parameters. Penalty functions add cost for correction. Depending on the combination, the post-hoc regret function may be piecewise constant, piecewise rational linear, or piecewise nonlinear. Grid search is used for nonlinear cases.
- Core assumption: The choice of correction and penalty functions is problem and application specific, and the resulting regret function can be minimized within computational limits.
- Evidence anchors: [section 3] "Using Correction Function B... the corrected solution remains the same in each interval... Therefore, the post-hoc regret function L(γ) returned from Evaluate is a piecewise constant function..." [section 4] "Using Correction Function A... the post-hoc regret function L(γ) returned from Evaluate is a piecewise rational linear function."

### Mechanism 3
- Claim: The framework generalizes Predict+Optimize to problems with unknown parameters in both objectives and constraints, enabling exact solutions for broader problem classes.
- Mechanism: By extending the Branch & Learn framework with post-hoc correction, the method handles recursively solvable problems with unknown constraints. The correction step ensures feasibility, and the post-hoc regret measures solution quality considering both objective and constraint uncertainty.
- Core assumption: The optimization problem can be represented with unknown parameters in both objectives and constraints, and a correction function exists.
- Evidence anchors: [abstract] "we propose the first exact approach for Predict+Optimize with unknown parameters in both the objective and constraints." [section 1] "Hu et al. propose a more general loss function called post-hoc regret, in which an infeasible estimated solution is first corrected into a feasible one..."

## Architecture Onboarding

- Component map: Construct -> Convert -> Correct -> Evaluate -> Coordinate descent update
- Critical path: The framework constructs a parameterized optimization problem, converts it to a piecewise function, corrects infeasible solutions, evaluates post-hoc regret, and updates coefficients through coordinate descent.
- Design tradeoffs: Exact vs. approximate methods (exact methods compute post-hoc regret exactly but may be computationally expensive, while approximate methods are faster but may be less accurate); Correction and penalty functions (different combinations yield different regret function forms, affecting trainability and solution quality)
- Failure signatures: High computational cost (if the post-hoc regret function is highly nonlinear or has many intervals, grid search becomes prohibitive); Poor solution quality (if the correction function is not suitable for the problem, the post-hoc regret may not accurately measure solution quality); Infeasible solutions (if the correction function cannot always produce feasible solutions, the framework may fail)
- First 3 experiments: 1) Implement the framework on a simple recursively solvable problem (e.g., 0-1 knapsack) to validate the basic components; 2) Compare the framework's performance with a baseline method (e.g., regression) on a problem with unknown constraints; 3) Experiment with different correction and penalty function combinations on the same problem to understand their effects on solution quality

## Open Questions the Paper Calls Out

  - Why unresolved: The paper only demonstrates the framework on recursively and iteratively solvable problems, leaving open whether it can be generalized to other classes of optimization problems.
  - What evidence would resolve it: Successful application of post-hoc regret to at least one non-recursively solvable optimization problem class.

- Question: What are the most effective automatic approaches for selecting correction functions and penalty functions based on specific applications?
  - Basis in paper: [explicit] The paper identifies exploring automatic ways to select correction and penalty functions as a future challenge.
  - Why unresolved: The paper empirically studies different combinations but does not propose or evaluate automated selection methods.
  - What evidence would resolve it: A systematic method that automatically selects appropriate correction and penalty functions for a given application domain with demonstrated effectiveness.

- Question: How does the choice of correction function affect the scalability and runtime of Branch & Learn with Post-hoc Correction?

## Limitations
- The framework relies heavily on the assumption that optimization problems are solvable by recursive algorithms satisfying the Branch & Learn template, severely restricting the class of problems that can be directly addressed.
- Computational complexity of exact gradient-free training through coordinate descent may become prohibitive for problems with many parameters or complex solution structures.
- Experiments focus on specific combinatorial problems where the template restriction is satisfied, but generalization to broader problem classes remains unclear.

## Confidence

**High confidence**: The theoretical framework for post-hoc regret calculation and the basic mechanism of recursive decomposition are well-established in prior work (Hu et al.). The mathematical derivations for different correction-penalty combinations appear sound and are supported by clear examples.

**Medium confidence**: The experimental results demonstrate significant improvements over baseline methods, but the comparison is limited to three specific problem domains. The claim that "significant improvement in solution quality" generalizes beyond these cases is not fully substantiated.

**Low confidence**: The scalability claims for handling problems with many parameters are not empirically validated. The computational complexity analysis for the coordinate descent approach is incomplete, particularly regarding the grid search component for nonlinear regret functions.
