# Imitating careful experts to avoid catastrophic events

## Quick Facts
- arXiv ID: 2302.01193
- Source URL: https://arxiv.org/abs/2302.01193
- Reference count: 15
- Primary result: IRL incorporating carefulness signals correctly infers catastrophic outcome severity in gridworld task

## Executive Summary
This paper addresses the challenge of safe reinforcement learning in human-robot interactions by incorporating carefulness signals into inverse reinforcement learning (IRL). The key insight is that humans naturally display different behavior when catastrophic outcomes are possible, becoming more careful through slower movements and higher action confidence. By including these carefulness signals in the IRL framework, the method can distinguish between catastrophic outcomes (like injuring humans) and merely undesirable ones. The approach is validated on a gridworld task where an agent must navigate around a cliff, showing that the carefulness-aware IRL agent correctly infers the severity of falling off the cliff while baseline methods significantly underestimate this risk.

## Method Summary
The method extends IRL by incorporating carefulness levels into the action space and using linear programming to optimize for rewards that explain both state transitions and carefulness choices. The approach uses constrained optimization to maximize the margin between the optimal action and the next best action while regularizing the reward function. Human demonstrations are collected through an interactive game where carefulness is explicitly controlled via a bar that fills as the movement key is held down. The method is compared against a baseline MaxEnt IRL approach without carefulness signals.

## Key Results
- IRL agent incorporating carefulness correctly infers cliff severity in gridworld task
- Baseline IRL method without carefulness significantly underestimates cliff severity
- Human demonstrations with carefulness signals (10 rollouts) perform comparably to 10,000 optimal computer-generated rollouts
- Careful behavior in demonstrations allows disambiguation between catastrophic and undesirable outcomes

## Architecture Onboarding

- **Component map**:
  - Gridworld Environment -> Human Interface -> IRL Agent -> Reward Function

- **Critical path**:
  1. Human plays game → carefulness signals recorded
  2. Demonstrations processed into state-action-carefulness tuples
  3. IRL agent solves constrained optimization problem
  4. Reward function evaluated on test scenarios

- **Design tradeoffs**:
  - Careful vs. efficient: Higher carefulness reduces movement cost but increases safety
  - Sample efficiency vs. accuracy: Human demonstrations are fewer but include risk signals
  - Reward sparsity vs. expressiveness: L1 regularization encourages sparse rewards but may miss nuanced penalties

- **Failure signatures**:
  - Reward function underestimates cliff severity → agent falls off cliff frequently
  - Reward function overestimates cliff severity → agent avoids valid paths near cliff
  - Inconsistent carefulness → IRL agent cannot disambiguate risk levels

- **First 3 experiments**:
  1. Run simple gridworld with computer expert following optimal policy, collect 100 rollouts, train IRL agent with carefulness signals, compare learned reward to true reward
  2. Have human play gridworld for 10 rollouts, train IRL agent, compare learned reward to true reward and computer baseline
  3. Remove carefulness signals, retrain IRL agent, compare performance degradation to carefulness-enabled version

## Limitations
- The approach relies heavily on the assumption that human carefulness signals accurately reflect perceived risk, which may not generalize across diverse populations
- The linear programming formulation assumes reward decomposition that may not hold in more complex environments
- Limited empirical validation to a simple gridworld task, with no results in robotic simulators or real-world scenarios

## Confidence

- **High confidence**: The mechanism by which carefulness signals create behavioral differences when catastrophic outcomes are possible is well-supported by the experimental results showing the IRL agent correctly infers cliff severity.
- **Medium confidence**: The claim that fewer samples are needed with carefulness signals is supported by the 10 human vs 10,000 optimal rollouts comparison, but lacks broader validation across different task complexities.
- **Low confidence**: The assumption that human carefulness signals are universally reliable indicators of perceived risk, given the limited sample size and lack of diverse demonstrator data.
