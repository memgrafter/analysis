# BUFFET: Benchmarking Large Language Models for Few-shot Cross-lingual Transfer
## Quick Facts
- arXiv ID: 2305.14857
- Source URL: https://arxiv.org/abs/2305.14857
- Reference count: 27
- Key outcome: Introduces BUFFET benchmark evaluating few-shot cross-lingual transfer across 15 tasks in 54 languages, revealing that fine-tuning often outperforms in-context learning for under-represented languages.

## Executive Summary
BUFFET introduces a comprehensive benchmark for evaluating few-shot cross-lingual transfer across 15 diverse NLP tasks in 54 typologically diverse languages. The benchmark provides fixed few-shot examples and instructions to enable fair comparison across models and transfer methods. Extensive evaluations reveal that in-context learning on large language models like ChatGPT often underperforms fine-tuned models, especially for under-represented languages, highlighting the need for improved pretraining and evaluation methods for cross-lingual transfer.

## Method Summary
BUFFET unifies 15 NLP tasks across 54 languages into a text-to-text format with fixed few-shot training and validation examples per task and language. The evaluation compares fine-tuning approaches using mT5-base and in-context learning using BLOOM, BLOOMZ, mT0, and ChatGPT. Models are evaluated in zero-shot, English-only, and target-language fine-tuning settings using macro-averaged scores per task, with classification tasks evaluated using accuracy, span-based tasks using F1, and generation tasks using BLEU or ROUGE.

## Key Results
- Fine-tuning on English task data plus few-shot target language examples often outperforms in-context learning, especially for under-represented languages
- Instruction-tuned models often underperform in few-shot settings due to optimization for zero-shot instruction-based learning
- Larger models show improved few-shot in-context cross-lingual transfer performance, though fine-tuning methods still generally outperform

## Why This Works (Mechanism)
### Mechanism 1: Fine-tuning vs In-context Learning
Fine-tuning updates model parameters to adapt representations to target language distribution, while in-context learning only provides context window without parameter updates. This makes fine-tuning more effective when target language data is sufficient for adaptation.

### Mechanism 2: Instruction-tuning Impact
Instruction-tuned models are optimized for zero-shot instruction-based learning without demonstrations, making them less effective at learning from few-shot examples in context. This creates a bias towards zero-shot settings.

### Mechanism 3: Model Scaling Benefits
Larger models have more parameters and capacity to learn from in-context examples, leading to better performance on few-shot tasks. The increase in model size directly correlates with improved ability to learn from in-context examples.

## Architecture Onboarding
- **Component map**: BUFFET benchmark -> language models (mT5, BLOOM, BLOOMZ, mT0, ChatGPT) -> transfer methods (fine-tuning, in-context learning)
- **Critical path**: Create BUFFET benchmark -> evaluate models using different transfer methods -> analyze results
- **Design tradeoffs**: Balance between comprehensive benchmark and manageable evaluation; consider tradeoffs between different transfer methods and model sizes
- **Failure signatures**: Poor performance on under-represented languages; large performance gaps between different k-shot demonstrations; instruction-tuned models performing worse in few-shot vs zero-shot settings
- **First 3 experiments**:
  1. Evaluate performance of fine-tuned models vs in-context learning models on BUFFET benchmark
  2. Investigate impact of instruction-tuning on zero-shot and few-shot transfer performance
  3. Analyze performance of different model sizes on few-shot in-context learning tasks

## Open Questions the Paper Calls Out
- How do translation artifacts and unnatural topic distributions in translated datasets affect few-shot cross-lingual transfer performance?
- What are optimal strategies for selecting few-shot demonstrations to maximize in-context learning performance across different languages and tasks?
- How can we develop more effective multilingual instruction-tuning approaches that better utilize both instructions and demonstrations?
- What are the most effective methods for generating high-quality training data for under-represented languages using large language models?

## Limitations
- Task granularity may mask significant performance variations at language-family level
- Instruction quality and cross-lingual alignment may artificially depress model performance
- Standardized k-shot examples may not account for varying context window capacities across models

## Confidence
- **High confidence**: Fine-tuning on English data plus few-shot target language examples generally outperforms in-context learning
- **Medium confidence**: Instruction-tuning hinders few-shot in-context learning performance
- **Medium confidence**: Model scaling improves few-shot cross-lingual transfer performance
