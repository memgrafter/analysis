# Meta Temporal Point Processes

## Quick Facts
- arXiv ID: 2301.12023
- Source URL: https://arxiv.org/abs/2301.12023
- Reference count: 27
- Key outcome: Attentive TPP achieves state-of-the-art performance on temporal point process modeling, particularly excelling at capturing periodic patterns and demonstrating robustness to noise and distribution drift.

## Executive Summary
This paper introduces a meta-learning approach to temporal point processes by framing them as neural processes, where each event sequence is treated as a separate task. The proposed Attentive TPP model incorporates a cross-attention mechanism to capture periodic patterns by matching local histories of previous events. Experiments on four benchmark datasets and three datasets with strong periodic patterns demonstrate significant improvements in capturing periodic patterns, robustness to noise (up to 50% drop ratio), and resilience to distribution drift compared to existing methods.

## Method Summary
The method treats temporal point processes as meta-learning tasks where each event sequence is a distinct task, using neural processes as the underlying framework. The Attentive TPP model processes local history windows through a transformer-based encoder, applies cross-attention to match current local history to similar previous patterns, generates a global latent feature via variational inference, and decodes using mixture of log-normal distributions to predict the next event time. The model is trained using a meta-learning framework with specific hyperparameters including feature dimensions of 96-64, latent variable dimension of 64, and local history window size of 20.

## Key Results
- Attentive TPP achieves state-of-the-art RMSE performance on datasets with strong periodic patterns (Sinusoidal, Uber, NYC Taxi)
- Model demonstrates robustness to noise, maintaining performance with up to 50% event drop ratio
- Significant improvements in capturing periodic patterns compared to baseline methods, particularly through the cross-attention mechanism
- Resilience to distribution drift, maintaining performance when trained on early data and tested on subsequent months

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Meta-learning formulation improves generalization to unseen event sequence patterns by treating each sequence as a distinct task
- Mechanism: The model learns a global latent feature that captures task-specific characteristics while maintaining shared patterns across sequences through permutation invariance and KL regularization
- Core assumption: Event sequences from the same stochastic process share enough global characteristics to be captured by a single latent feature
- Evidence anchors:
  - [abstract] "treat each sequence as a different task, via a novel framing of TPPs as neural processes"
  - [section 3.2] "the global latent feature z cannot be very different at different event time: adding some addition context feature ri will not change G as well as z much"
  - [corpus] Weak evidence - no direct citations about meta-learning TPPs, but strong evidence about neural processes in general
- Break condition: If sequences from the same process have vastly different characteristics that cannot be captured by permutation invariance, the global latent feature may not effectively represent task-specific patterns

### Mechanism 2
- Claim: Cross-attention module captures periodic patterns by matching similar local history subsequences
- Mechanism: The model explicitly attends to previous event times with similar patterns to the current local history, allowing it to recognize repeating subsequences
- Core assumption: Repeating event subsequences in temporal point processes have similar features that can be matched through attention
- Evidence anchors:
  - [abstract] "The cross-attention mechanism is particularly effective in modeling repeating event subsequences"
  - [section 3.3] "The cross-attention module provides an inductive bias to a model that the repeating event subsequences should have similar features"
  - [corpus] Weak evidence - no direct citations about cross-attention in TPPs, but strong evidence about attention mechanisms in sequence modeling
- Break condition: If the periodic patterns are too complex or if the local history window is not appropriately sized, the attention mechanism may fail to capture the patterns

### Mechanism 3
- Claim: Latent variable path improves robustness to noise and captures stochasticity of TPPs
- Mechanism: The model learns a probability distribution over latent variables instead of deterministic features, allowing it to model the inherent randomness in temporal point processes
- Core assumption: The stochastic nature of TPPs can be effectively captured by sampling from a learned latent distribution
- Evidence anchors:
  - [abstract] "We employ Neural Processes (NPs), a family of the model-based meta learning with stochasticity, to explain TPPs"
  - [section 3.2] "As it is intractable to compute the log-likelihood for a latent variable model, amortized variational inference (VI) can be used to approximate inference"
  - [corpus] Moderate evidence - some citations about latent variable models in TPPs, but limited evidence about noise robustness
- Break condition: If the variational approximation is poor or if the number of samples is insufficient, the model may not effectively capture the stochasticity

## Architecture Onboarding

- Component map: Event sequence → Encoder → (Cross-attention) → Latent path → Decoder → Next event prediction
- Critical path: Event sequence → Encoder → (Cross-attention) → Latent path → Decoder → Next event prediction
- Design tradeoffs:
  - Local history window size vs. computational cost
  - Number of latent samples vs. approximation accuracy
  - Cross-attention vs. underfitting problem
  - Permutation invariance vs. task-specific feature learning
- Failure signatures:
  - Poor RMSE on periodic datasets suggests cross-attention not capturing patterns
  - High variance in NLL across different sequences suggests latent variable model not converging
  - Degraded performance on distribution drift suggests meta-learning not capturing robust features
- First 3 experiments:
  1. Train on one periodic dataset (Sinusoidal) and test ability to capture periodic patterns
  2. Introduce noise by randomly dropping events and measure imputation performance
  3. Train on Jan-Feb data and test on subsequent months to evaluate distribution drift robustness

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the Attentive TPP's performance compare to traditional methods in real-world deployment scenarios with significant noise and distribution drift?
- Basis in paper: [explicit] The paper demonstrates the Attentive TPP's robustness to noise (up to 50% drop ratio) and resilience to distribution drift in experiments.
- Why unresolved: While the paper shows performance on synthetic noise and a specific distribution drift case (NYC Taxi dataset), it doesn't explore real-world deployment scenarios with more complex noise patterns and distribution shifts.
- What evidence would resolve it: Testing the Attentive TPP on real-world datasets with known noise patterns and distribution drift, such as sensor data with intermittent failures or financial transaction data during market crises.

### Open Question 2
- Question: What is the theoretical relationship between approximation methods (Monte-Carlo vs. Variational Inference) and variants of Meta TPP, and how does it affect performance?
- Basis in paper: [explicit] The paper mentions that Monte-Carlo approximation generally outperforms Variational Inference for the proposed Meta TPP, but it's not the case for the Attentive TPP.
- Why unresolved: The paper conjectures that Monte-Carlo approximation better shares a role with the cross-attention path when compared to the Variational Inference approximation, but a theoretical explanation is lacking.
- What evidence would resolve it: A formal analysis of the relationship between approximation methods and the model's components, potentially through mathematical proofs or extensive empirical studies.

### Open Question 3
- Question: How does the Attentive TPP's performance scale with the size of the event sequences and the number of event types?
- Basis in paper: [inferred] The paper demonstrates the Attentive TPP's performance on datasets with varying sequence lengths and event types, but doesn't explicitly analyze the scaling behavior.
- Why unresolved: While the paper shows that the Attentive TPP outperforms baselines on several datasets, it doesn't provide a systematic analysis of how performance changes with increasing sequence lengths and event types.
- What evidence would resolve it: Conducting experiments on datasets with a wide range of sequence lengths and event types, and analyzing the Attentive TPP's performance and computational efficiency as these factors increase.

## Limitations

- The performance on synthetic periodic datasets (Sinusoidal) may not fully translate to real-world complexity with irregular patterns
- The meta-learning contribution is not isolated through ablation studies, making it difficult to assess its specific impact
- Limited evaluation of the model's behavior on datasets with highly complex, non-periodic temporal patterns
