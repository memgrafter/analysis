# Towards Evaluating Explanations of Vision Transformers for Medical Imaging

## Quick Facts
- arXiv ID: 2304.06133
- Source URL: https://arxiv.org/abs/2304.06133
- Reference count: 40
- Primary result: TransLRP gradient-based method outperforms LIME and attention visualization for ViT interpretability in chest X-ray classification

## Executive Summary
This paper addresses the critical need for interpretable AI in medical imaging by evaluating explanation methods for Vision Transformers (ViTs) applied to chest X-ray classification. The authors develop a comprehensive evaluation framework assessing faithfulness, sensitivity, and complexity of three interpretation approaches: model-agnostic LIME, attention-based visualization, and gradient-based TransLRP. Their systematic comparison reveals that TransLRP provides more accurate and consistent explanations than alternatives, though explanation quality varies significantly across disease classes, with COVID-19 cases showing notably poorer performance. This work establishes methodological standards for evaluating ViT explanations in medical contexts and highlights practical limitations in current interpretability approaches.

## Method Summary
The authors propose a framework for assessing ViT explanations using three key metrics: faithfulness correlation (measuring alignment between explanation importance scores and model behavior changes), average sensitivity (evaluating robustness to input perturbations), and effective complexity (quantifying explanation conciseness). They apply this framework to compare three interpretation methods on a ViT trained to classify 395 chest X-ray images into COVID-19, non-COVID pneumonia, and healthy categories. The evaluation systematically measures how well each method explains the model's decision-making process across different disease classes, providing quantitative comparisons of interpretability performance.

## Key Results
- TransLRP achieves faithfulness correlations of 0.27-0.44, outperforming LIME (0.17-0.35) and attention visualization (0.11-0.31)
- TransLRP demonstrates lower average sensitivity (0.29-0.40) compared to alternatives, indicating more robust explanations
- Explanation quality varies substantially by disease class, with COVID-19 achieving only 0.27 faithfulness correlation versus 0.44 for healthy cases

## Why This Works (Mechanism)
The study's framework works by systematically quantifying how well explanation methods capture the actual decision-making process of ViTs. TransLRP's superior performance stems from its ability to propagate relevance scores backward through the transformer architecture, capturing hierarchical feature interactions that simpler methods miss. The evaluation metrics directly measure whether highlighted image regions genuinely influence predictions and whether explanations remain stable under small input changes, providing objective criteria for comparison.

## Foundational Learning

**Faithfulness Correlation**: Measures alignment between explanation importance scores and actual model behavior changes when inputs are modified. Why needed: Ensures explanations accurately reflect what influences model decisions. Quick check: Correlate feature importance scores with prediction changes when those features are perturbed.

**Average Sensitivity**: Quantifies explanation stability when input images undergo small perturbations. Why needed: Prevents explanations from being overly sensitive to minor, irrelevant changes. Quick check: Measure explanation variation when adding Gaussian noise to inputs.

**Effective Complexity**: Evaluates explanation conciseness by measuring the number of features required to represent the explanation. Why needed: Balances explanation accuracy with interpretability for clinical use. Quick check: Count non-zero importance scores in the explanation map.

## Architecture Onboarding

**Component Map**: Input Image -> ViT Backbone -> Classification Head -> Prediction -> Explanation Method (TransLRP/LIME/Attention) -> Evaluation Metrics (Faithfulness, Sensitivity, Complexity)

**Critical Path**: The forward pass through ViT produces class predictions, which are then explained using one of three methods. The critical evaluation path involves: input perturbation → explanation generation → metric calculation → comparison across methods and disease classes.

**Design Tradeoffs**: Accuracy vs interpretability (complex models are harder to explain), computational cost vs explanation quality (gradient methods are faster but may miss context), and class-specific performance variations requiring tailored evaluation approaches.

**Failure Signatures**: Poor faithfulness correlation indicates explanations don't align with actual decision processes; high sensitivity suggests instability to input changes; excessive complexity implies explanations are too detailed for practical use.

**First Experiments**:
1. Measure faithfulness correlation for each method across all three disease classes
2. Compare average sensitivity when adding Gaussian noise to test images
3. Calculate effective complexity for each explanation method and visualize explanation maps

## Limitations
- Modest effect sizes with faithfulness correlations only reaching 0.27-0.44
- Class-specific performance variations, particularly poor COVID-19 explanation quality
- Limited to three interpretation methods without broader baseline comparisons
- Small dataset size (395 images) constraining generalizability
