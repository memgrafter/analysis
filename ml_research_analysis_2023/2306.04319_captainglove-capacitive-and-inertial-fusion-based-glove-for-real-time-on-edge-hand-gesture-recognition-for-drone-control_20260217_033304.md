# CaptAinGlove: Capacitive and Inertial Fusion-Based Glove for Real-Time on Edge Hand Gesture Recognition for Drone Control

## Quick Facts
- arXiv ID: 2306.04319
- Source URL: https://arxiv.org/abs/2306.04319
- Authors: 
- Reference count: 28
- One-line primary result: CaptAinGlove achieves 80% offline and 67% real-time embedded F1-score for hand gesture recognition in drone control using hierarchical multimodal fusion of capacitive and inertial sensing.

## Executive Summary
CaptAinGlove is a textile-based glove system for real-time hand gesture recognition in drone control. It uses capacitive textile electrodes on the fingers and an IMU sensor on the wrist, combined with lightweight neural networks and a hierarchical multimodal fusion approach. The system achieves an F1-score of 80% offline and 67% in real-time embedded deployment (one user). It operates at 1.15W power consumption with a 2MB memory footprint, offering a privacy-conscious, flexible, and low-power alternative to camera-based gesture control solutions.

## Method Summary
The CaptAinGlove system employs four textile capacitive channels (wrist, thumb, index, little finger) and an IMU sensor on the wrist. Sensor data is processed using sliding windows (2s size, 0.5s step) and normalized. A hierarchical fusion approach first uses an inertial model (2,882 parameters) to detect movement, triggering a capacitive model (49,890 parameters) only when non-null activity is detected. The system runs on a Portenta H7 microcontroller with TensorFlow Lite for MCU, achieving real-time inference at 20Hz.

## Key Results
- Offline accuracy: 80% F1-score on one-user dataset
- Real-time embedded accuracy: 67% F1-score
- Power consumption: 1.15W with 2MB memory footprint
- Model sizes: Inertial model (2,882 parameters), Capacitive model (49,890 parameters)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hierarchical multimodal fusion improves accuracy while reducing power consumption by avoiding unnecessary full-model inference.
- Mechanism: The inertial model first detects whether the user is performing any gesture. If the inertial model classifies the activity as null, the capacitive model is not activated, saving power. Only when a non-null activity is detected does the capacitive model run to recognize the specific gesture.
- Core assumption: Movement detection via inertial sensing can reliably distinguish between null activities and gestures, thus serving as a valid trigger for the capacitive model.
- Evidence anchors:
  - [abstract] "We employ lightweight convolutional neural networks as the backbone models and a hierarchical multimodal fusion to reduce power consumption and improve accuracy."
  - [section] "A pre-normalization ((𝑥 − 𝑥𝑚𝑖𝑛 )/( 𝑥𝑚𝑎𝑥 − 𝑥𝑚𝑖𝑛 )) per window is applied to the inertial and capacitive signals. The window size is 2s, and the window's step is 0.5s. The first neural network model (NN) is the inertial model with three channels as input (linear acceleration). This model is used to distinguish the null class from gesture detection."
  - [corpus] Weak evidence: The corpus mentions similar fusion strategies but does not specifically reference the hierarchical trigger approach used in CaptAinGlove.
- Break condition: If the inertial model frequently misclassifies null activities as gestures, unnecessary capacitive model inference will occur, increasing power consumption without accuracy gain.

### Mechanism 2
- Claim: Lightweight neural networks with small parameter counts enable real-time inference on resource-constrained edge devices.
- Mechanism: The inertial model has 2,882 parameters and the capacitive model has 49,890 parameters. These small models fit within the 2MB memory footprint of the Portenta H7 and allow for fast inference on the dual-core STM32H747 processor.
- Core assumption: The gesture recognition task can be effectively solved with small, specialized models rather than large, general-purpose networks.
- Evidence anchors:
  - [abstract] "We employ lightweight convolutional neural networks as the backbone models and a hierarchical multimodal fusion to reduce power consumption and improve accuracy."
  - [section] "The number of parameters of the inertial model is 2882; thus, it is a lightweight design... The number of parameters of the capacitive model is 49890; thus, it is a lightweight design and less susceptible to overfitting compared to a small network such as MobileNetV2 with 3.5 Million parameters."
  - [corpus] Weak evidence: The corpus mentions lightweight models in related contexts but does not provide specific parameter counts or comparisons to CaptAinGlove.
- Break condition: If the task complexity increases (e.g., more gesture classes or more subtle distinctions), the small models may become insufficient, leading to poor accuracy.

### Mechanism 3
- Claim: Textile capacitive electrodes provide a flexible, low-power, and privacy-preserving sensing modality for gesture recognition.
- Mechanism: Conductive textile patches act as capacitive sensors that detect finger movements without requiring cameras or other invasive sensors. The capacitive sensing operates at low power and does not capture visual information, preserving privacy.
- Core assumption: Capacitive sensing can reliably capture the finger movements needed to distinguish between different gestures in the drone control dictionary.
- Evidence anchors:
  - [abstract] "CaptAinGlove incorporates textile capacitive electrodes as sensing channels on the fingers and an IMU sensor on the wrist. Textile capacitive sensing has demonstrated its effectiveness as a low-power consumption, cost-effective, and scalable technology for movement tracking in gesture and activity recognition."
  - [section] "Four capacitive channels are distributed on the glove; channel one on the wrist, channel two on the thumb, channel three on the index finger, and channel four on the little finger."
  - [corpus] Weak evidence: The corpus mentions textile capacitive sensing in related works but does not provide specific details about the implementation in CaptAinGlove.
- Break condition: If environmental conditions (e.g., humidity, interference from other objects) significantly affect capacitive readings, the reliability of gesture recognition may degrade.

## Foundational Learning

- Concept: Real-time on-the-edge inference
  - Why needed here: The system must process sensor data and recognize gestures locally on the glove hardware without relying on cloud connectivity, ensuring low latency and privacy.
  - Quick check question: What are the key constraints when deploying neural networks on microcontrollers compared to desktop systems?

- Concept: Multimodal sensor fusion
  - Why needed here: Combining inertial and capacitive data provides complementary information about hand movements, improving recognition accuracy compared to using either modality alone.
  - Quick check question: How does hierarchical fusion differ from parallel fusion in multimodal systems, and when is each approach advantageous?

- Concept: Sliding window processing
  - Why needed here: Gesture recognition requires analyzing temporal patterns in sensor data, which is achieved by processing fixed-size windows with overlap (step size) to capture movement dynamics.
  - Quick check question: How do window size and step size affect the trade-off between temporal resolution and computational load in gesture recognition systems?

## Architecture Onboarding

- Component map: Sensors (4 capacitive channels + IMU) -> Sliding window processing -> Inertial model inference -> (if non-null) Capacitive model inference -> Gesture output -> UART to PC
- Critical path: Sensor data acquisition → sliding window processing → inertial model inference → (if non-null) capacitive model inference → gesture output
- Design tradeoffs:
  - Memory vs. accuracy: Small models fit on device but may limit recognition capability
  - Power vs. responsiveness: Hierarchical fusion saves power but adds latency
  - Coverage vs. flexibility: Partial finger coverage maintains mobility but may reduce recognition accuracy for some gestures
- Failure signatures:
  - High null activity misclassification → unnecessary capacitive model runs → increased power consumption
  - Capacitive channel interference → gesture confusion, especially for finger-based distinctions
  - IMU drift or calibration issues → movement detection failures
- First 3 experiments:
  1. Measure power consumption with different operating modes (only movement detection, with inertial model, with both models) to verify the hierarchical power savings claim.
  2. Test recognition accuracy with different window sizes and step sizes to find the optimal balance between temporal resolution and computational load.
  3. Evaluate gesture recognition performance when wearing the glove during actual drone control tasks to assess real-world usability and identify any practical limitations.

## Limitations
- Accuracy gap: Offline (80%) significantly exceeds real-time embedded performance (67%)
- Single-user testing: Results may not generalize across different users
- Environmental sensitivity: No testing under varying humidity, temperature, or interference conditions

## Confidence
- Power consumption claims: Medium - Single-user measurement, no environmental variation testing
- Hierarchical fusion effectiveness: Medium - Accuracy degradation in embedded deployment suggests implementation issues
- Textile capacitive sensing generalizability: Low - Only one user tested, no environmental robustness validation

## Next Checks
1. Conduct cross-user validation with at least 10 different users to assess the system's generalization capability and identify user-specific variations in gesture recognition performance.
2. Perform environmental stress testing by measuring gesture recognition accuracy and power consumption under varying humidity levels (20-80%), temperatures (10-30°C), and electromagnetic interference conditions.
3. Implement A/B testing comparing the hierarchical fusion approach against parallel fusion (both models running simultaneously) to quantify the actual power savings and determine if accuracy degradation is justified by power efficiency gains.
