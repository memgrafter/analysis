# Capturing Topic Framing via Masked Language Modeling

## Quick Facts
- **arXiv ID:** 2302.03183
- **Source URL:** https://arxiv.org/abs/2302.03183
- **Reference count:** 19
- **Primary result:** Framework achieves mean Kendall rank correlation of 0.44 with human evaluation for detecting differential media framing

## Executive Summary
This paper presents a scalable framework for measuring differential framing of issues by different media outlets using masked language modeling. The approach fine-tunes language models on outlet-specific corpora and uses them to predict word choices for masked positions in topic-relevant prompts. The framework identifies framing differences through the varying word predictions made by models trained on different outlets when given identical prompts. The method is evaluated on articles from 10 US news outlets covering five politically polarized topics, demonstrating high reliability with both human evaluation and ground truth datasets.

## Method Summary
The framework works by fine-tuning pre-trained language models (RoBERTa-base, BERT-base-cased, BERT-base-uncased) on outlet-specific article corpora using the masked language modeling objective. Prompts are generated using either manual patterns (declarative, interrogative, association) or automatic methods (bigram outer). The fine-tuned models predict words for masked positions in these prompts, with predictions normalized using either general-normalization or domain-normalization methods. Framing differences are captured by computing cosine distances between normalized probability distributions across outlets, creating outlet-topic representations that can be compared using rank correlation metrics.

## Key Results
- Achieves mean Kendall rank correlation of 0.44 with human evaluation and 0.50 with ground truth datasets
- Best performance with declarative-single manual prompt pattern (τ = 0.46) and general-normalization method
- Significantly outperforms baseline methods including LDA, TF-IDF, and standard language models
- Demonstrates high scalability by handling large corpora from multiple outlets

## Why This Works (Mechanism)

### Mechanism 1
Fine-tuning LMs on outlet-specific corpora captures differential framing patterns through learned word associations. When LMs are fine-tuned on articles from specific outlets, they learn statistical associations between words and contexts that reflect each outlet's framing style. The fine-tuned model for outlet A will predict different words than outlet B when given the same prompt, revealing framing differences.

### Mechanism 2
Normalization of LM predictions using domain-specific probability distributions enhances framing detection. Raw probability outputs from fine-tuned LMs include baseline word frequency biases. By normalizing these probabilities using either general-language or domain-specific distributions, the framework amplifies true framing differences while suppressing common word usage patterns.

### Mechanism 3
Masked language modeling with carefully designed prompts effectively captures framing preferences. By masking specific words in context-specific prompts and having fine-tuned LMs predict the most likely completions, the framework extracts semantic preferences that reflect each outlet's framing. Different prompt patterns (declarative, interrogative, association) access different aspects of framing.

  - Why needed here: Different prompt structures access different aspects of framing, affecting the quality of extracted signals
  - Quick check question: What's the difference between declarative, interrogative, and association prompt patterns in terms of the framing information they capture?

- **Concept:** Probability Normalization in Language Models
  - Why needed here: Normalization corrects for baseline frequency biases that obscure genuine framing differences
  - Quick check question: How do general-normalization and domain-normalization differ in their approach to correcting probability biases?

## Architecture Onboarding

- **Component map:** Data collection → Fine-tuning → Prompt generation → Prediction → Normalization → Comparison → Evaluation
- **Critical path:** Data collection → Fine-tuning → Prompt generation → Prediction → Normalization → Comparison → Evaluation
- **Design tradeoffs:**
  - Manual vs. automatic prompt generation: Manual offers slightly better performance but less scalability; automatic is more scalable but potentially noisier
  - Normalization methods: General normalization uses non-fine-tuned LM; domain normalization uses all-training-set fine-tuned LM
  - Choice of pre-trained LM: RoBERTa-base, BERT-base-cased, BERT-base-uncased show similar performance
- **Failure signatures:** Low Kendall's τ values across all topics suggest fundamental issues with the framework; high variance between manual prompt methods suggests instability
- **First 3 experiments:**
  1. Run the framework with no normalization on a single topic to establish baseline performance
  2. Test all three normalization methods (none, general, domain) on the same topic to identify optimal approach
  3. Compare manual prompt patterns (declarative, interrogative, association) against automatic bigram outer method for effectiveness

## Open Questions the Paper Calls Out

- **Can the framework effectively capture differential framing in languages other than English?** The authors acknowledge all experiments were conducted in English due to lack of appropriate ground truth data in other languages, and they don't know whether the framework generalizes to other languages.

- **How can the framework be adapted to capture discourse-level differential framing, in addition to word-based framing?** The authors mention their framework measures word-based differential framing but cannot currently capture discourse-level framing.

- **How can the interpretability of the automatically generated prompts be improved?** The authors note that automatically generated prompts are sometimes not relevant to the issue or topic being investigated, and more work is needed to understand the cause behind certain token predictions.

## Limitations

- Performance varies significantly across topics, with Drug Policy achieving only τ = 0.25 compared to Affordable Care Act at τ = 0.70
- Reliance on specific prompt patterns that may not scale well to new domains
- Framework assumes word choice differences directly reflect framing differences, which may not always hold true
- Normalization methods lack clear theoretical grounding for when to use general vs. domain normalization

## Confidence

**High Confidence** (Level 1-3 uncertainty):
- The overall framework architecture is sound and technically feasible
- Fine-tuning LMs on outlet-specific corpora captures outlet-specific language patterns
- Normalization improves performance over no normalization
- The framework achieves statistically significant correlation with ground truth data

**Medium Confidence** (Level 4-7 uncertainty):
- The declarative-single prompt pattern is optimal across all contexts
- Domain normalization consistently outperforms general normalization
- The method generalizes well to topics beyond the five studied
- The 10-point difference between manual and automatic prompts represents a fundamental limitation

**Low Confidence** (Level 8-11 uncertainty):
- The framework captures all relevant aspects of framing, not just word choice differences
- The method would perform equally well on highly technical or specialized topics
- The framework would maintain performance with different pre-trained LMs or different outlet selections

## Next Checks

1. **Prompt Pattern Robustness Test:** Systematically test the framework with hybrid prompt patterns that combine elements of manual and automatic approaches. Use automatic bigram extraction with declarative sentence structure to measure if this bridges the scalability-performance gap.

2. **Cross-Topic Generalization Study:** Apply the framework to a new set of five topics from the same outlets, particularly including highly technical topics like cybersecurity or emerging topics like AI ethics. Compare performance patterns to determine if effectiveness correlates with topic characteristics.

3. **Multi-Modal Framing Detection:** Extend the framework to incorporate structural features beyond word choice, such as article positioning, headline sentiment, or quotation patterns. Test whether adding these features improves performance on topics where word-based framing detection underperforms (like Drug Policy at τ = 0.25).
