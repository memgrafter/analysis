# Prak: An automatic phonetic alignment tool for Czech

## Quick Facts
- arXiv ID: 2304.08431
- Source URL: https://arxiv.org/abs/2304.08431
- Reference count: 0
- Prak is a free open-source tool for automatic phonetic alignment of Czech speech

## Executive Summary
Prak is a free open-source tool for automatic phonetic alignment of Czech speech. It generates phone sequences from text and aligns them with audio recordings using a simple architecture with a ReLU neural network trained on CommonVoice data, combined with a rule-based pronunciation generator and Viterbi alignment. Compared to existing tools like Prague Labeller, Prak achieves significantly better alignment accuracy, with 2.24% of phones mismatched or misplaced by more than 0.1s versus 10.89% for the previous tool. The tool is designed to be simple, approachable for students, and usable on multiple platforms with both GUI and command line interfaces.

## Method Summary
Prak uses a neural network acoustic model with 56k weights trained on MFCC features extracted from Czech CommonVoice audio data. The system combines this with a rule-based pronunciation generator that uses Finite State Transducers to handle Czech assimilation rules, and a Viterbi alignment decoder to find optimal phone boundaries. Training involves an iterative process alternating between time re-alignment and gradient descent optimization. The tool produces phone-aligned TextGrid files for Praat analysis and IPA transcriptions for command line use.

## Key Results
- Achieved 2.24% phone mismatch/placement error rate on manually aligned test set
- Outperformed previous Prague Labeller by factor of 5 (10.89% error rate)
- Successfully handles Czech phonetic assimilation rules through rule-based pronunciation generator

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Simple ReLU neural network with 56k weights is sufficient for accurate phonetic alignment in Czech
- Core assumption: Czech speech acoustic characteristics can be captured by small neural network on limited CommonVoice data
- Evidence anchors: Training on 14 hours CommonVoice data, explicit design choice for simplicity
- Break condition: If Czech speech is too complex for this architecture or training data is insufficient

### Mechanism 2
- Claim: Rule-based pronunciation generator with FST blocks accurately captures Czech assimilation logic
- Core assumption: Czech phonetic assimilation rules can be encoded as finite state transducers
- Evidence anchors: FST approach explicitly mentioned for handling voicing assimilation and consonant groups
- Break condition: If assimilation rules are too complex for FST encoding or new variants emerge

### Mechanism 3
- Claim: Iterative training approach converges to good alignments from naive initial guess
- Core assumption: Poor initial alignment can be corrected through alternating re-estimation and gradient descent
- Evidence anchors: Starts with 30ms phone assumption and converges to accurate alignments
- Break condition: If initial alignment is too far from reality or training gets stuck in local minima

## Open Questions the Paper Calls Out

- Question: How would alignment accuracy change with augmented CommonVoice data including Institute of Phonetics recordings?

- Why unresolved: Tool designed to avoid additional dependencies
- What evidence would resolve it: Train with both datasets and measure accuracy improvement

- Question: Would transformer-based architecture improve accuracy while maintaining efficiency?
- Basis in paper: Mentioned as potential future direction with concern about time boundary "smearing"

- What evidence would resolve it: Implement transformer model and compare against current system

## Limitations

- Evaluation based on single manually aligned test set from Charles University
- Neural network architecture details not fully specified, making exact reproduction difficult
- Performance on spontaneous speech or non-Czech languages untested
- Rule-based pronunciation generator may not handle all phonetic variations
- Limited training data (14 hours) may miss some Czech phonetic contexts

## Confidence

- **High confidence**: Core alignment methodology (NN acoustic model + Viterbi + rule-based pronunciation) is sound
- **Medium confidence**: Specific accuracy numbers reliable for tested conditions but may not generalize
- **Low confidence**: Claims about non-Czech languages or spontaneous speech performance
