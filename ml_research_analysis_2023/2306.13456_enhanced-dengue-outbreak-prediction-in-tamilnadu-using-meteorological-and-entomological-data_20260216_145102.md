# Enhanced Dengue Outbreak Prediction in Tamilnadu using Meteorological and Entomological data

## Quick Facts
- arXiv ID: 2306.13456
- Source URL: https://arxiv.org/abs/2306.13456
- Reference count: 23
- Primary result: Bidirectional Stacked LSTM model predicts dengue outbreaks in Tamil Nadu with MSE of 52.62

## Executive Summary
This study develops a predictive model for dengue outbreaks in Tamil Nadu, India, by integrating climate data (temperature, rainfall, relative humidity) with mosquito larval indices from 2014-2020. The research demonstrates that incorporating entomological data significantly improves prediction accuracy compared to climate-only models. The Bidirectional Stacked LSTM architecture outperforms standard LSTM variants, achieving the lowest mean squared error in outbreak prediction.

## Method Summary
The researchers employed a Bidirectional Stacked LSTM model that takes climate parameters and dengue incidence from the prior two months to predict current month incidence. Mosquito larval index data was preprocessed using a weighted average scheme, with missing values imputed via co-training regression. The model was evaluated across different time lags and climate parameter combinations, with optimal performance achieved using a 3-month time lag and all three climate parameters combined.

## Key Results
- Variant II (including larval index) outperformed Variant I (climate only) in prediction accuracy
- Optimal performance achieved with 3-month time lag and all three climate parameters
- Bidirectional Stacked LSTM showed lowest error among various LSTM architectures tested
- Model achieved mean squared error of 52.62 on test data

## Why This Works (Mechanism)
The integration of entomological data with climate parameters provides a more comprehensive representation of dengue transmission dynamics. Mosquito larval indices capture the vector population status, which directly influences disease transmission potential. The bidirectional architecture allows the model to learn from both past and future context within the sequence, capturing complex temporal dependencies in outbreak patterns.
