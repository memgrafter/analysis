# The Weighted Möbius Score: A Unified Framework for Feature Attribution

## Quick Facts
- arXiv ID: 2305.09204
- Source URL: https://arxiv.org/abs/2305.09204
- Authors: [Not specified in source]

## Executive Summary
This paper introduces the Weighted Möbius Score, a unified framework for feature attribution that positions existing methods within a common vector space. The framework shows that diverse attribution methods like Shapley value and Shapley interaction index are special cases of the same mathematical structure, differing only in their weight functions. By leveraging linear algebraic tools and providing interpretations in cooperative game theory and causal mediation, the framework offers a principled approach to understanding and comparing feature attribution methods across different domains.

## Method Summary
The Weighted Möbius Score framework represents attribution methods as vectors in a space where each dimension corresponds to a subset of features. The method involves computing feature isolation scores for all subsets, applying the Möbius transform to convert these to Möbius scores, and then combining them using a weight function. This unified approach allows existing methods to be expressed as special cases with different weight functions, enabling linear algebraic analysis and interpretations across game theory and causal inference. The framework was empirically tested on sentiment analysis using BERT-large and chain-of-thought prompting with ChatGPT API.

## Key Results
- Many existing attribution methods (Shapley value, Shapley interaction index, etc.) are special cases of the Weighted Möbius Score framework with different weight functions
- The framework enables linear algebraic analysis of attribution methods, providing new insights into their relationships
- Empirical validation demonstrates the framework's ability to identify feature interactions like "not bad" in sentiment analysis and evaluate attribution methods in prompt engineering

## Why This Works (Mechanism)

### Mechanism 1
The Weighted Möbius Score provides a unified framework that shows many existing attribution methods are special cases of the same mathematical structure. The framework represents attribution methods as vectors in a vector space where each dimension corresponds to a subset of features. Different weight functions applied to the Möbius transform of feature isolation scores generate existing methods like Shapley value, Shapley interaction index, and others.

### Mechanism 2
The framework enables linear algebraic analysis of attribution methods, providing new insights into their relationships and properties. By situating attribution methods in a vector space with point-wise addition and scalar multiplication, standard linear algebra tools like the Zeta and Möbius transforms can be applied to analyze and compare different methods.

### Mechanism 3
The framework provides interpretations in cooperative game theory and causal mediation analysis, offering multiple perspectives on feature attribution. Feature attribution problems can be mapped to cooperative games where feature subsets are coalitions and their contributions are payoffs, or to causal mediation models where features are mediators of treatment effects.

## Architecture Onboarding

- Component map:
  Feature isolation score -> Möbius transform -> Weight function -> Attribution method -> Vector space representation

- Critical path:
  1. Compute feature isolation scores for all subsets of features
  2. Apply Möbius transform to obtain Möbius scores
  3. Apply weight function to combine Möbius scores
  4. Return final attribution scores

- Design tradeoffs:
  - Computational complexity: Exponential in number of features due to subset enumeration
  - Interpretability vs. expressiveness: More complex weight functions capture more nuanced interactions but are harder to interpret
  - Faithfulness constraint: Ensures attributions only assign importance to relevant features

- Failure signatures:
  - Attribution scores don't sum to model prediction difference (violates efficiency property)
  - Non-zero attributions for irrelevant feature subsets (violates faithfulness)
  - Unexpected sign patterns in interaction scores (may indicate model pathologies)

- First 3 experiments:
  1. Verify the vector space structure by implementing addition and scalar multiplication of simple attribution methods
  2. Test the Möbius transform implementation on a known polynomial model to check against theoretical values
  3. Implement and compare Shapley value and Shapley interaction index using the unified framework to verify they are special cases

## Limitations
- Computational scalability is limited by exponential complexity in the number of features, making it impractical for high-dimensional data
- The framework requires models with real-valued outputs, limiting direct application to classification models with discrete labels
- Empirical validation is limited to specific domains without comprehensive testing across diverse model architectures
