# MultiWave: Multiresolution Deep Architectures through Wavelet Decomposition for Multivariate Time Series Prediction

## Quick Facts
- **arXiv ID:** 2306.10164
- **Source URL:** https://arxiv.org/abs/2306.10164
- **Reference count:** 37
- **Key outcome:** MultiWave improves deep learning models for multivariate time series prediction by incorporating frequency-based components, achieving up to 5% AUC improvement in healthcare applications

## Executive Summary
MultiWave is a novel framework that enhances deep learning models for multivariate time series prediction by incorporating multiresolution components that operate at different signal frequencies. The approach uses wavelet decomposition to break down signals into subsignals of varying frequencies, which are then grouped into frequency bands and processed by different model components. A gating mechanism with ℓ1 regularization combines these components to create sparse models that focus on the most informative frequency bands. The framework demonstrates consistent improvements across various architectures including LSTM, Transformer, and CNN models, with particular success in healthcare applications such as stress detection, COVID-19 mortality prediction, and activity recognition.

## Method Summary
MultiWave is a model-agnostic framework that improves multivariate time series prediction by decomposing signals into frequency components using multilevel discrete wavelet decomposition. The framework processes each frequency band with separate model components, applies learnable masks with ReLU activation to identify informative components, and uses ℓ1 regularization to enforce sparsity. The outputs are fused through concatenation and a fully connected layer. The approach is designed to handle multirate time series data and can be applied to any base time series model architecture. The framework was evaluated on three datasets: WESAD (wearable stress and affect detection), COVID-19 patient blood samples for mortality prediction, and MHEALTH (human activity recognition), using MSE, AUC, and classification accuracy as metrics.

## Key Results
- MultiWave accurately identifies informative frequency bands and improves performance of various deep learning models (LSTM, Transformer, CNN) across multiple applications
- Achieved up to 5% AUC improvement for in-hospital COVID-19 mortality prediction from patient blood samples
- Successfully handles multirate time series data without requiring alignment or resampling
- Creates sparse models that use only specific signals at specific frequencies, improving interpretability

## Why This Works (Mechanism)

### Mechanism 1
- Wavelet decomposition allows explicit separation and processing of signal components at different frequency bands
- Core assumption: Signals contain meaningful information distributed across multiple frequency bands
- Evidence: Abstract and methodology sections confirm frequency-based processing improves model performance
- Break condition: If wavelet decomposition fails to produce meaningful frequency separation

### Mechanism 2
- Gating mechanism with ℓ1 regularization creates sparse models focusing on informative frequency bands
- Core assumption: Not all frequency bands are equally informative, and sparsity improves generalization
- Evidence: Abstract mentions gating produces sparse models; methodology describes ℓ1 regularization on mask weights
- Break condition: If regularization weight is too high or low, affecting sparsity balance

### Mechanism 3
- Model-agnostic design allows improvements across diverse deep learning architectures
- Core assumption: Different architectures benefit from frequency-based decomposition and gating
- Evidence: Abstract demonstrates improvements across LSTM, Transformer, and CNN models
- Break condition: If certain architectures are incompatible with frequency decomposition approach

## Architecture Onboarding

- **Component map:**
  - Wavelet Decomposition Layer -> Frequency Grouping Module -> Base Model Components -> Mask Layer -> Fusion Layer
  - Input signals -> Multilevel DWT (D1, D2, ..., DL, AL) -> Frequency band grouping -> Model components (Φj) -> ReLU masks -> Concatenation -> Fully connected layer

- **Critical path:**
  1. Wavelet decomposition of input signals
  2. Grouping of subsignals by frequency
  3. Application of masks to frequency components
  4. Processing by base model components
  5. Concatenation and fusion of component outputs
  6. Application of ℓ1 regularization during training

- **Design tradeoffs:**
  - Wavelet choice (Haar vs. Daubechies vs. Biorthogonal): Affects frequency separation quality and computational cost
  - Number of decomposition levels: Balances frequency resolution against model complexity
  - ℓ1 regularization weight: Trade-off between sparsity and model expressiveness
  - Component architecture choice: Different base models may perform better for different frequency bands

- **Failure signatures:**
  - No improvement over baseline: Check if frequency decomposition is meaningful or if masks are zeroing out all components
  - Degraded performance: Verify wavelet parameters and check if oversampling is introducing artifacts
  - Inconsistent results across runs: Examine mask initialization and regularization weight stability
  - Specific frequency bands consistently masked out: Investigate if those bands contain noise or if model is too aggressive in sparsity

- **First 3 experiments:**
  1. Synthetic data with known frequency components: Generate square waves at different frequencies, test if MultiWave can identify and use correct components
  2. Uniformly sampled real data: Apply MultiWave to dataset with consistent sampling rates to verify frequency-based improvements
  3. Multirate real data: Test MultiWave on data with varying sampling rates to confirm handling of different frequencies without alignment

## Limitations

- Experimental validation based on relatively small number of datasets (three real-world applications plus synthetic data)
- Specific implementation details of base model components and exact preprocessing steps are not fully specified
- Relative contribution of frequency decomposition versus gating mechanism is not clearly separated
- Computational overhead and training efficiency impact are not thoroughly discussed

## Confidence

- **High:** The general mechanism of wavelet decomposition for frequency separation is well-established and supported by related work
- **Medium:** Improvement claims are supported by experimental results but limited to specific datasets and architectures
- **Low:** Exact implementation details and hyperparameter settings are not fully specified, affecting reproducibility
