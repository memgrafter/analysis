# Weakly-Supervised HOI Detection from Interaction Labels Only and Language/Vision-Language Priors

## Quick Facts
- arXiv ID: 2303.05546
- Source URL: https://arxiv.org/abs/2303.05546

## Executive Summary
This paper presents a novel approach for weakly-supervised human-object interaction (HOI) detection that requires only image-level interaction labels, without bounding box annotations or interaction-object pairs. The method leverages vision-language and language models to improve detection quality. Specifically, it uses a vision-language model (CLIP) to prune non-interacting human-object proposals based on grounding maps, a large language model (RoBERTa) to suppress implausible interactions, and an auxiliary weakly-supervised preposition prediction task to enhance spatial reasoning. Extensive experiments show that these contributions significantly improve HOI detection performance on standard benchmarks compared to weakly-supervised baselines.

## Method Summary
The proposed method formulates HOI detection as a multiple instance learning problem where each image is a bag of human-object pairs, and at least one pair must have the correct interaction label. The approach consists of three main components: (1) proposal pruning using CLIP grounding maps to filter out non-interacting pairs, (2) implausible interaction suppression using a RoBERTa-based language model lookup table, and (3) an auxiliary preposition prediction task to improve spatial reasoning. The model is trained using binary focal loss for HOI detection and binary cross-entropy loss for preposition prediction, with an overall objective combining both tasks.

## Key Results
- Achieves state-of-the-art weakly-supervised HOI detection performance on V-COCO and HICO-DET benchmarks
- Demonstrates significant improvements over weakly-supervised baselines by leveraging vision-language and language priors
- Shows that image-level interaction labels extracted from captions are sufficient for training effective HOI detectors

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Using CLIP grounding maps to prune non-interacting proposals significantly improves HOI detection performance.
- Mechanism: CLIP generates grounding maps that highlight visual regions corresponding to text descriptions. By averaging grounding scores within proposal bounding boxes, proposals with low interaction scores can be filtered out, reducing the search space for interacting pairs.
- Core assumption: CLIP's grounding capability is accurate enough to distinguish interacting from non-interacting regions.
- Evidence anchors:
  - [abstract]: "We first propose an approach to prune non-interacting human and object proposals to increase the quality of positive pairs within the bag, exploiting the grounding capability of the vision-language model."
  - [section 3.3]: Describes the process of generating grounding maps from image-text pairs and calculating interaction scores for proposals.
  - [corpus]: Weak evidence - only 5 related papers found, average FMR=0.489, average citations=0.1.
- Break condition: If CLIP's grounding maps are not discriminative enough to identify interacting regions, or if the object detector produces very noisy proposals.

### Mechanism 2
- Claim: Using a large language model to suppress implausible interactions improves HOI detection performance.
- Mechanism: An LLM is queried to obtain a probability distribution over possible interaction classes given an object category. Interactions with low probabilities are suppressed by adjusting confidence scores.
- Core assumption: The LLM has learned natural co-occurrences between interactions and objects during training.
- Evidence anchors:
  - [abstract]: "Second, we use a large language model to query which interactions are possible between a human and a given object category, in order to force the model not to put emphasis on unlikely interactions."
  - [section 3.4]: Describes the process of querying the LLM and creating a binary lookup table for plausible interactions.
  - [corpus]: Weak evidence - only 5 related papers found, average FMR=0.489, average citations=0.1.
- Break condition: If the LLM's knowledge about natural co-occurrences is not accurate or if the queried probabilities are not discriminative enough.

### Mechanism 3
- Claim: Adding a weakly-supervised preposition prediction task improves spatial reasoning and HOI detection performance.
- Mechanism: An auxiliary preposition prediction task is added to the model, forcing it to learn spatial relationships between human-object pairs. The task is weakly supervised using prepositions extracted from captions.
- Core assumption: Learning spatial relationships improves the model's ability to identify interacting pairs.
- Evidence anchors:
  - [abstract]: "Lastly, we use an auxiliary weakly-supervised preposition prediction task to make our model explicitly reason about space."
  - [section 3.5]: Describes the formulation of the preposition prediction task and the learning objective.
  - [corpus]: Weak evidence - only 5 related papers found, average FMR=0.489, average citations=0.1.
- Break condition: If the extracted prepositions from captions are not accurate or if the model does not effectively learn spatial relationships from the task.

## Limitations
- The method's reliance on large language models (RoBERTa-101 for interaction plausibility and CLIP for grounding) introduces uncertainty about the method's robustness to different domains or datasets.
- The grounding capability of CLIP is assumed to be accurate enough for pruning proposals, but this may not generalize well to scenarios with complex backgrounds or unusual object poses.
- The preposition prediction task relies on captions from COCO and Visual Genome, which may not capture the full diversity of spatial relationships needed for HOI detection.

## Confidence
- **High Confidence**: The overall experimental methodology and evaluation protocol are sound, with clear metrics (Agent AP, Role AP, Full mAP) and standard datasets (V-COCO, HICO-DET).
- **Medium Confidence**: The effectiveness of the CLIP grounding and LLM plausibility suppression mechanisms, while theoretically justified, may be sensitive to implementation details not fully specified in the paper.
- **Medium Confidence**: The contribution of the preposition prediction task is supported by experimental results but the specific implementation details (preposition set, parser configuration) are unclear.
