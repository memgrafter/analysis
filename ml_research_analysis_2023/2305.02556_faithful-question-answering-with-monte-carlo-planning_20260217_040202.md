# Faithful Question Answering with Monte-Carlo Planning

## Quick Facts
- arXiv ID: 2305.02556
- Source URL: https://arxiv.org/abs/2305.02556
- Reference count: 32
- Primary result: FAME achieves 67.1% answer accuracy on EntailmentBankQA, outperforming Entailer's 53.1%

## Executive Summary
FAME introduces a Monte-Carlo planning approach to Faithful Question Answering that generates valid reasoning steps to support answer selection. The method uses a modular reasoning environment with a fixed fact corpus to prevent hallucination, combined with a controller that selects actions through look-ahead search. Experiments show FAME achieves higher answer accuracy than previous methods while maintaining faithfulness, demonstrating that planning-based reasoning can outperform large language models with smaller architectures.

## Method Summary
FAME formulates question answering as a sequential decision-making problem where a controller generates reasoning steps through discrete actions. The system uses Monte-Carlo planning to evaluate future states and select actions that lead to high-quality reasoning trees. A modular environment separates retrieval, entailment generation, and verification components, with a fixed fact corpus preventing hallucination. The controller is trained via behavior cloning on gold entailment trees, followed by iterative verifier-guided fine-tuning that accepts valid non-gold trajectories. State scores combine step validity and hypothesis faithfulness to guide both planning and training.

## Key Results
- FAME achieves 67.1% answer accuracy on EntailmentBankQA, outperforming Entailer's 53.1%
- Manual evaluation shows FAME generates valid and faithful reasoning steps compared to large language models
- The method finds valid reasoning trees in 91% of cases (61% gold-equivalent, 30% valid alternatives)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Monte-Carlo planning enables foresighted action selection by evaluating future states
- Mechanism: The algorithm assigns action values Q(s,a) based on iterative simulations that propagate state scores backward through trajectories, allowing the controller to choose actions that lead to high-quality reasoning trees rather than just locally optimal steps
- Core assumption: The state verifier V(s) provides accurate estimates of tree validity and hypothesis faithfulness
- Evidence anchors:
  - [abstract] "we introduce a Monte-Carlo planning algorithm to do a look-ahead search and select actions that will eventually lead to high-quality steps"
  - [section 4.3.2] "Each simulation consists of three stages: Selection, Expansion, Back-propagation" with explicit state score propagation
  - [corpus] Weak - only one related paper mentions MCTS, suggesting this application to language reasoning is novel
- Break condition: If the state verifier becomes inaccurate or the planning budget is exhausted before reaching meaningful states

### Mechanism 2
- Claim: Modular reasoning environment with separate retriever, entailment module, and fact corpus prevents hallucination
- Mechanism: The controller can only generate conclusions by combining existing facts from the corpus or previously generated intermediate conclusions, rather than generating unsupported facts
- Core assumption: The fact corpus contains all necessary information for correct reasoning
- Evidence anchors:
  - [abstract] "Our method is based on a deterministic corpus to prevent hallucination"
  - [section 4.1] "X is the set of sentences that can be selected as premises... Sentences in X are either facts retrieved from the corpus or conclusions generated by previous steps"
  - [corpus] Weak - no direct comparison with hallucination-prone methods in related work
- Break condition: If the fact corpus lacks critical information needed for reasoning

### Mechanism 3
- Claim: Verifier-guided iterative training finds correct trajectories even when they differ from gold trees
- Mechanism: The state verifier scores generated trajectories, and only high-quality trajectories are added to training data, allowing the controller to learn from valid but non-gold reasoning paths
- Core assumption: Multiple valid reasoning trees can exist for the same hypothesis
- Evidence anchors:
  - [section 4.4] "If the state score of the final state is greater than a threshold, we add the trajectory to the training data... we could find some potentially correct trajectories, which may not be the same as the annotated ones but can still produce valid and faithful entailment trees"
  - [section 6.2] "61% of them obtain the same trees as the gold ones, 30% obtain different but still valid trees"
  - [corpus] Moderate - one related paper mentions reinforcement learning with answer-faithful traces
- Break condition: If the verifier threshold is set too high or too low, preventing proper training signal

## Architecture Onboarding

- Component map: Controller (T5-large) → Action Space (Retrieve/Entail/End) → Reasoning Environment (Retriever + Entailment Module + Fact Corpus) → State Verifier (Vs + Vh) → Monte-Carlo Planner
- Critical path: Question → Hypothesis Generation → Controller State Prediction → MCP Action Selection → Environment Execution → Verifier Scoring → Answer Selection
- Design tradeoffs: Fixed fact corpus vs. dynamic retrieval provides stability but may lack coverage; modular design allows component updates but increases complexity
- Failure signatures: Low hypothesis faithfulness despite valid steps indicates corpus limitations; high state scores but wrong answers suggest verifier calibration issues
- First 3 experiments:
  1. Test controller with oracle actions to establish upper bound on performance
  2. Evaluate state verifier accuracy on held-out entailment steps
  3. Compare MCP vs. greedy planning on a small validation set

## Open Questions the Paper Calls Out
1. Can FAME be extended to handle a wider variety of reasoning modules, such as numerical calculations or commonsense reasoning?
2. How would FAME perform if it could retrieve facts from an up-to-date external knowledge source, like a modern search engine, instead of a fixed corpus?

## Limitations
- Performance heavily depends on the quality and coverage of the fixed fact corpus
- State verifier accuracy is critical for both planning and training effectiveness
- The method may not generalize well to questions requiring external knowledge beyond the corpus

## Confidence
- **High confidence**: The core Monte-Carlo planning algorithm implementation and its integration with the modular reasoning environment
- **Medium confidence**: The effectiveness of verifier-guided iterative training in finding valid non-gold trajectories
- **Medium confidence**: The claim that FAME achieves better faithfulness with smaller models compared to large language models
