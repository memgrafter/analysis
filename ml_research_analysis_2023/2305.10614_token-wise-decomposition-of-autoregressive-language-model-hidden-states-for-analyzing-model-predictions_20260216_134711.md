# Token-wise Decomposition of Autoregressive Language Model Hidden States for Analyzing Model Predictions

## Quick Facts
- arXiv ID: 2305.10614
- Source URL: https://arxiv.org/abs/2305.10614
- Reference count: 13
- Primary result: Introduces exact token-wise decomposition of Transformer hidden states enabling efficient analysis of token importance in language model predictions

## Executive Summary
This work presents a novel method for analyzing autoregressive language model predictions by decomposing hidden states into token-specific contributions and a cumulative bias term. The decomposition is exact for virtually all contemporary Transformer architectures when using differentiable activation functions, enabling efficient computation of token importance measures without perturbing model computations. Using change in next-word probability as an importance metric, the authors demonstrate that Transformer-based language models rely primarily on collocational associations for predictions, followed by syntactic dependencies and coreference relationships.

## Method Summary
The method involves a linear decomposition of Transformer decoder hidden states at each timestep into the sum of final output representations of each input token and a cumulative bias term. This decomposition is exact when activation functions are differentiable almost everywhere. The approach defines a probability distribution that ablates the contribution of specific input tokens, allowing analysis of their influence on model probabilities over upcoming words with only one forward pass. The importance measure ∆LP is defined as the change in next-word log probability when ablating a token's contribution. The authors apply stepwise regression analysis to characterize which context words make the biggest contribution to language model predictions, examining factors like pointwise mutual information, syntactic dependencies, and coreference relationships.

## Key Results
- Stepwise regression shows language models rely primarily on collocational associations (PMI) for next-word predictions, followed by syntactic dependencies and coreference relationships
- ∆LP importance measure correlates weakly with attention weights and gradient norms (r < 0.3), demonstrating it captures distinct information
- Analyses using ∆LP successfully predict syntactic dependencies and coreferent mention spans, with collocational associations and token repetitions respectively explaining most predictions

- Claim: The decomposition is exact when the activation function is differentiable almost everywhere.
- Mechanism: By reformulating the activation function as a linear approximation (tangent lines), the feedforward network becomes locally linear, allowing token-wise vectors to be preserved through each layer.
- Core assumption: The activation function is differentiable except on a set of Lebesgue measure zero (e.g., ReLU at x=0).

## Limitations

- Exact decomposition relies on differentiable activation functions, limiting architectural choices
- Conclusions based on specific corpora (CoNLL-2012, WSJ) may not generalize to other domains
- PMI as proxy for collocational association has known limitations (inflated for rare pairs, doesn't capture semantic relatedness)
