# An Extensible Multimodal Multi-task Object Dataset with Materials

## Quick Facts
- arXiv ID: 2305.14352
- Source URL: https://arxiv.org/abs/2305.14352
- Reference count: 19
- EMMa provides 2.8M Amazon product listings with images, text, price, mass, ratings, and 182 material types

## Executive Summary
EMMa (Extensible Multimodal Multi-task dataset with Materials) addresses the challenge of creating large-scale datasets that combine multiple object attributes including visual, textual, and material properties. The dataset contains 2.8 million Amazon product listings with comprehensive annotations including images, text descriptions, price, mass, customer ratings, and material classifications. A novel Smart Labeling framework enables rapid addition of new binary object properties with minimal manual labeling effort, achieving high accuracy (F1 > 90%) for properties like sharpness, transparency, and deformability. The dataset's extensible design and rich material taxonomy make it valuable for diverse computer vision and machine learning applications.

## Method Summary
The Smart Labeling framework enables rapid addition of new binary object properties by leveraging few-shot learning with minimal human annotation. Users provide 10-20 positive and negative examples for the target property, which are used to fine-tune a multimodal model. The framework then automatically labels the remaining dataset, achieving high accuracy with F1 scores exceeding 90% for properties such as sharpness, transparency, and deformability. This approach significantly reduces the manual labeling burden while maintaining label quality, making it practical to extend the dataset with custom properties tailored to specific research needs.

## Key Results
- EMMa contains 2.8 million Amazon product listings with multimodal data (images, text, price, mass, ratings)
- Material taxonomy includes 182 fine-grained material types for detailed material classification
- Smart Labeling framework achieves F1 scores >90% for binary properties (sharpness, transparency, deformability) with only 10-20 examples per property

## Why This Works (Mechanism)
The Smart Labeling framework succeeds by leveraging multimodal learning and transfer learning from pre-trained models. The approach exploits the rich contextual information available in multimodal data (images and text descriptions) to infer object properties that may not be explicitly stated. By fine-tuning on a small set of carefully curated examples, the model learns to recognize patterns and correlations between visual/textual features and the target property. The framework's effectiveness stems from the inherent richness of multimodal data, where complementary information from different modalities helps disambiguate property labels and improves generalization to unseen examples.

## Architecture Onboarding

**Component Map:**
Smart Labeling Framework -> Multimodal Model (Image+Text) -> Property Classifier -> Dataset Extension

**Critical Path:**
User-provided examples → Model fine-tuning → Automated labeling → Quality validation → Dataset extension

**Design Tradeoffs:**
- Annotation efficiency vs. label accuracy (few examples vs. comprehensive coverage)
- Model complexity vs. fine-tuning speed (larger models may require more compute)
- Property specificity vs. generalization (highly specific properties may overfit)
- Manual validation effort vs. automated labeling scale

**Failure Signatures:**
- Low F1 scores indicating poor property discrimination
- High false positive rates suggesting ambiguous property definitions
- Class imbalance causing biased predictions toward majority class
- Inconsistent labeling across similar product categories

**First Experiments:**
1. Validate Smart Labeling framework on three diverse properties beyond sharpness, transparency, and deformability
2. Test few-shot learning performance with varying numbers of training examples (5, 10, 20, 50)
3. Evaluate material taxonomy coverage by analyzing distribution across product categories
