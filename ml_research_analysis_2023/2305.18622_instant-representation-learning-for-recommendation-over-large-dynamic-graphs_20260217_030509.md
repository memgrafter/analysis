# Instant Representation Learning for Recommendation over Large Dynamic Graphs

## Quick Facts
- arXiv ID: 2305.18622
- Source URL: https://arxiv.org/abs/2305.18622
- Reference count: 40
- This paper introduces SUPA, a sample-update-propagate architecture for instant representation learning on large dynamic multiplex heterogeneous graphs, achieving state-of-the-art performance on six real-world datasets.

## Executive Summary
This paper addresses the challenge of instant representation learning for large dynamic multiplex heterogeneous graphs in recommender systems, where existing methods struggle with rapid graph evolution and neighborhood disturbance. The proposed SUPA model introduces a sample-update-propagate architecture to alleviate these issues, utilizing node-type specific updaters, edge-type specific interactors, and time-aware propagation to capture multiplex heterogeneity and streaming dynamics. The model is trained incrementally using the InsLearn workflow, enabling single-pass training on large dynamic graphs. Extensive experiments on six real-world datasets demonstrate SUPA's superiority over sixteen state-of-the-art baseline methods, achieving significant improvements in link prediction tasks with H@50 and MRR metrics. The results highlight SUPA's robustness to neighborhood disturbance and its effectiveness in handling dynamic graph evolution for real-world recommender systems.

## Method Summary
SUPA addresses instant representation learning for dynamic multiplex heterogeneous graphs through a novel sample-update-propagate architecture. Instead of traditional neighbor aggregation, SUPA samples an influenced subgraph for each new edge, updates the two interactive nodes using node-type specific updaters and edge-type specific interactors, then propagates interaction information through the sampled subgraph with time-aware attenuation. The model is trained incrementally using the InsLearn workflow, which processes edges in batches based on timestamps and updates parameters in a single pass. This approach effectively handles neighborhood disturbance and captures multiplex heterogeneity while maintaining computational efficiency for large-scale graphs.

## Key Results
- SUPA achieves significant improvements in link prediction tasks with H@50 and MRR metrics across six real-world datasets
- The model demonstrates superior performance compared to sixteen state-of-the-art baseline methods
- SUPA successfully handles large dynamic graphs with up to 1.5 million edges and processes 11,657 edges per second on a single GPU

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SUPA's sample-update-propagate architecture alleviates neighborhood disturbance better than neighbor-aggregation methods.
- Mechanism: Instead of aggregating neighbor embeddings, SUPA samples an influenced subgraph for each new edge, updates the two interactive nodes, and propagates interaction information through the sampled subgraph with time-aware attenuation.
- Core assumption: The local context of an interaction can be captured by a sampled subgraph rather than all neighbors, reducing sensitivity to rapid neighbor changes.
- Evidence anchors:
  - [abstract] "Compared to neighbor-aggregation architecture, SUPA develops a sample-update-propagate architecture to alleviate neighborhood disturbance."
  - [section III-C] "The Relation-specific Update Module updates the representations of the two interactive nodes... The Time-aware Propagation Module propagates the interaction information on Gs,e to update the representations of the influenced nodes."
  - [corpus] Weak corpus support: no direct neighbor papers focus on neighborhood disturbance in dynamic graphs.
- Break condition: If the influenced subgraph fails to capture necessary high-order relationships, the method loses effectiveness.

### Mechanism 2
- Claim: Node-type and edge-type specific parameters allow SUPA to model multiplex heterogeneity.
- Mechanism: Different node types have separate updaters with distinct forgetting rates; edge-type specific interactors and context embeddings capture interaction heterogeneity.
- Core assumption: Different node types (e.g., users vs items) evolve at different rates and have different semantic roles, requiring specialized processing.
- Evidence anchors:
  - [section III-C1] "we set different (αo)s for different node types because the memory drift for nodes of different kinds might distinguish from each other."
  - [section III-C2] "We utilize the relation-specific context embedding to model the inspiration that different kinds of interaction introduce diverse information of node features."
  - [corpus] Moderate support: related papers like GATNE and MB-GMN also model heterogeneous edges but without temporal dynamics.
- Break condition: If node type distinctions are not meaningful in the dataset, the added complexity offers no benefit.

### Mechanism 3
- Claim: Time-aware propagation with attenuation and termination prevents outdated information from corrupting embeddings.
- Mechanism: Interaction information decays based on time intervals using function g(∆E(t′)) and is terminated if intervals exceed threshold τ.
- Core assumption: Older interactions provide diminishing value and may introduce noise if propagated too far.
- Evidence anchors:
  - [section III-D] "The interaction information undergoes a slow attenuation related to the interactive time interval when walking through each edge during the propagation flow... we use a filter function D(·) to detect out-of-date edges and terminate such propagation flow."
  - [section I] "the Neighborhood Disturbance existing in dynamic graphs deteriorates the performance of neighbor-aggregation based graph models."
  - [corpus] Weak support: no direct papers in corpus discuss time-aware propagation termination.
- Break condition: If τ is set too low, the model loses long-term signal; if too high, noise from outdated edges accumulates.

## Architecture Onboarding

- Component map:
  Influenced Graph Sampling Module → Relation-specific Update Module → Time-aware Propagation Module → Loss Computation → Parameter Update

- Critical path: New edge arrives → Influenced graph sampled → Interactive nodes updated → Interaction propagated → Loss computed → Parameters updated

- Design tradeoffs:
  - Sampling k paths per node trades completeness for efficiency
  - Time-based attenuation balances recency vs. historical signal
  - Single-pass training trades full optimization for scalability

- Failure signatures:
  - Poor link prediction despite high training accuracy → overfitting from insufficient regularization
  - Degradation over time → τ set too high or propagation too far
  - Slow training → k or l too large for available compute

- First 3 experiments:
  1. Run link prediction with k=1, l=2, τ=large to verify basic functionality
  2. Test neighborhood disturbance by limiting neighbor retention and measuring robustness
  3. Validate incremental learning by training on streaming batches and measuring performance drift

## Limitations

- Limited ablation studies on the individual components of the sample-update-propagate architecture make it difficult to quantify the relative contribution of each mechanism to overall performance improvements.
- The effectiveness of SUPA's neighborhood disturbance mitigation strategy lacks direct comparison against alternative approaches specifically designed for this problem in dynamic graphs.
- The choice of hyperparameters (k, l, τ) appears critical but is not thoroughly explored across different dataset characteristics and scales.

## Confidence

- **High Confidence**: The experimental methodology using six diverse real-world datasets with proper link prediction evaluation and comparison against sixteen state-of-the-art baselines is rigorous and well-documented.
- **Medium Confidence**: The theoretical framework for time-aware propagation with attenuation and termination is sound, though the specific implementation details of the filter function D(x) and threshold τ selection could benefit from more extensive validation.
- **Low Confidence**: The claim that node-type specific updaters with different forgetting rates significantly improve performance lacks sufficient empirical justification through comparative analysis.
