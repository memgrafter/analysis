# CSI-Based Efficient Self-Quarantine Monitoring System Using Branchy Convolution Neural Network

## Quick Facts
- arXiv ID: 2306.01756
- Source URL: https://arxiv.org/abs/2306.01756
- Reference count: 29
- Primary result: Device-free self-quarantine monitoring system using Wi-Fi CSI and BranchyGhostNet achieves 98.19% accuracy for 5 human activities with 54.04% latency reduction

## Executive Summary
This paper presents a privacy-preserving self-quarantine monitoring system that leverages Wi-Fi Channel State Information (CSI) to detect human activities and room occupancy without requiring wearable devices. The system employs a novel BranchyGhostNet architecture featuring an early exit prediction branch, which significantly reduces inference latency for room occupancy detection while maintaining high accuracy. The implementation uses Raspberry Pi 4B hardware connected to cloud IoT platforms for remote monitoring and alerting, addressing both privacy concerns and practical deployment needs.

## Method Summary
The proposed system captures Wi-Fi CSI data using Raspberry Pi 4B devices and processes it through the BranchyGhostNet neural network architecture. This network incorporates an early exit branch specifically designed for room occupancy detection tasks, allowing faster predictions for simpler decisions while maintaining the full network path for complex activity classification. The model is trained to recognize five distinct human activities and detect room occupancy, with all processing occurring locally on the device before transmitting relevant alerts through cloud IoT platforms for remote monitoring.

## Key Results
- Achieved 98.19% average accuracy for classifying five human activities
- Reduced inference latency by 54.04% for room occupancy detection using early exit branch
- Successfully implemented on Raspberry Pi 4B with cloud IoT platform integration

## Why This Works (Mechanism)
The system exploits the fact that human movement affects Wi-Fi signal propagation patterns, which can be captured through CSI measurements. By analyzing these subtle changes in the wireless channel, the system can detect presence and movement without requiring cameras or wearable sensors. The BranchyGhostNet architecture enhances efficiency by allowing simpler decisions (like occupancy detection) to exit early without processing the entire network, while more complex activity classifications still benefit from the full network depth.

## Foundational Learning
- **Wi-Fi CSI measurements**: Captures detailed channel characteristics that change with human presence; needed because raw signal strength lacks sufficient resolution for activity recognition
- **Early exit neural networks**: Allows different computational paths based on task complexity; needed to balance accuracy and efficiency for different monitoring requirements
- **Device-free activity recognition**: Enables monitoring without wearables; needed for privacy preservation and user compliance
- **Raspberry Pi 4B processing**: Provides sufficient computational power for real-time inference; needed for edge computing deployment
- **Cloud IoT integration**: Enables remote monitoring and alerting; needed for practical quarantine management

## Architecture Onboarding
Component map: CSI sensors -> Raspberry Pi 4B -> BranchyGhostNet -> Early exit branch / Full network -> Occupancy/Activity classification -> Cloud IoT platform -> Remote monitoring interface

Critical path: Wi-Fi CSI capture → Preprocessing → BranchyGhostNet inference → Decision routing (early exit vs full path) → Classification output → Cloud transmission → Alert generation

Design tradeoffs: Accuracy vs latency through early exit mechanism; computational load vs privacy preservation; edge processing vs cloud dependency

Failure signatures: Wi-Fi interference affecting CSI quality; false negatives in occupancy detection during low activity periods; cloud connectivity issues preventing alert transmission
