# Deep-BIAS: Detecting Structural Bias using Explainable AI

## Quick Facts
- arXiv ID: 2304.01869
- Source URL: https://arxiv.org/abs/2304.01869
- Reference count: 21
- Key outcome: Deep-BIAS outperforms BIAS toolbox with up to 0.95 macro F1 score for 600-sample distributions.

## Executive Summary
This paper introduces Deep-BIAS, a deep learning extension of the BIAS toolbox for detecting structural bias (SB) in heuristic optimization algorithms. Unlike the original BIAS toolbox, which uses 39 statistical tests and a Random Forest model, Deep-BIAS employs a convolutional neural network to directly classify SB from raw performance distributions. The method is trained on 189 parameterized scenarios of SB, covering four main types: center bias, bound bias, gaps/clusters, and discretization. Experiments show Deep-BIAS outperforms the original BIAS toolbox in classification accuracy, with macro F1 scores up to 0.95 for sample sizes of 600. Deep-BIAS also provides insights into the strength and type of SB using explainable AI (XAI) techniques.

## Method Summary
Deep-BIAS uses a one-dimensional convolutional neural network (1D CNN) to detect structural bias directly from ordered performance distributions. The model is trained via AutoKeras on a synthetic dataset of 160,000 distributions generated from 189 parameterized SB scenarios. Four CNN models are trained for different sample sizes (30, 50, 100, and 600), each using two convolutional blocks with max pooling, followed by a dense layer and SoftMax classification head. Predictions are averaged across dimensions and thresholded to determine bias presence. SHAP values are used to highlight regions of interest in the distribution for interpretability.

## Key Results
- Deep-BIAS achieves macro F1 scores up to 0.95 for sample sizes of 600, outperforming the original BIAS toolbox.
- The method detects various types of SB in 336 state-of-the-art optimization algorithms, particularly center bias and discretization behavior.
- SHAP explanations reveal which regions of the distribution drive bias predictions, enhancing interpretability.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Deep-BIAS outperforms BIAS by using raw distribution data instead of p-values from 39 statistical tests.
- Mechanism: A 1D CNN directly maps ordered sample points to structural bias class probabilities, capturing local and global distribution features in one inference step.
- Core assumption: SB manifests as predictable distributional patterns that are learnable from large synthetic datasets.
- Evidence anchors:
  - [abstract]: "Deep-BIAS employs a convolutional neural network to directly classify SB from raw performance distributions."
  - [section]: "Instead of using 39 statistical tests and their p-values, we propose using a single convolutional deep learning model to predict the presence and type of SB in the raw final-point distributions."
- Break condition: If real-world distributions contain bias patterns not represented in the synthetic training set, the model will misclassify or miss subtle SB types.

### Mechanism 2
- Claim: SHAP values provide interpretable insight into which regions of the distribution drive the bias classification.
- Mechanism: SHAP assigns each sample point a contribution score toward the predicted class, enabling visual highlighting of bias locations in the distribution.
- Core assumption: The trained CNN's internal feature representations are stable enough that local Shapley attributions reliably reflect causal contributions.
- Evidence anchors:
  - [section]: "Using the Shapley values for each point in the distribution, it is possible to highlight regions of interest for a particular prediction."
  - [corpus]: No direct empirical comparison of SHAP vs other XAI methods is provided; assumption is theoretical.
- Break condition: If the model is overconfident on noisy regions, SHAP attributions may highlight irrelevant fluctuations.

### Mechanism 3
- Claim: AutoKeras optimization finds a lightweight CNN that generalizes well across SB scenarios without overfitting.
- Mechanism: Hyperparameter search over filter sizes, pooling, and dense layers is constrained to architectures that fit the 1D ordered input and maintain low validation loss.
- Core assumption: The synthetic SB dataset is large enough (160k distributions) to support robust architecture search.
- Evidence anchors:
  - [section]: "Each network is trained for 50 epochs and uses a small randomly selected validation set (from the original training data) to compare different models with each other."
  - [corpus]: No ablation study comparing AutoKeras vs manual architecture search; assumption is efficiency claim.
- Break condition: If validation set is too small or unrepresentative, AutoKeras may overfit to noise and yield poor generalization.

## Foundational Learning

  - Why needed here: The ordered performance distribution is a 1D signal; CNNs extract local patterns that indicate bias location.

  - Why needed here: Understanding why 39 tests + RF was used in BIAS helps appreciate the design decision to replace them with a single CNN.

  - Why needed here: SHAP enables visualizing which parts of a distribution contribute to bias detection, bridging black-box predictions and human understanding.

## Architecture Onboarding

- Component map: Data generator → Ordered 1D distribution (N samples) → AutoKeras trainer → CNN with 2 conv+pool blocks + dense + SoftMax → Predictor → Per-dimension class probabilities → Average → Threshold → SHAP explainer → Per-point contributions → Visual heatmap
- Critical path:
  1. Generate synthetic SB distributions for training
  2. Train optimized CNN via AutoKeras
  3. Predict on real algorithm data
  4. Average per-dimension predictions
  5. Apply threshold for bias decision
  6. Generate SHAP attributions for interpretability
- Design tradeoffs:
  - Using ordered distributions discards temporal information but simplifies input shape.
  - Averaging per-dimension predictions assumes independence; may miss joint-bias patterns.
  - SHAP explanations are computationally heavy for large N.
- Failure signatures:
  - High false negatives when SB patterns differ from training set.
  - Misclassification of subtle SB as uniform due to threshold choice.
  - SHAP attributions pointing to noise if model overfits.
- First 3 experiments:
  1. Generate 1000 uniform and 1000 SB distributions (N=30), train a small CNN, and verify classification accuracy >90%.
  2. Apply trained model to a synthetic DE run with known saturation bias, check SHAP heatmap for boundary peaks.
  3. Compare false positive/negative rates between CNN and 39-test RF baseline on the 189-parameterized test set.

## Limitations
- The synthetic SB dataset covers 189 parameterized scenarios, but exact parameter ranges are not fully detailed, limiting reproducibility.
- SHAP attributions assume stable CNN feature representations but lack comparison with alternative XAI methods.
- The method assumes independence across dimensions when averaging predictions, which may miss joint-bias patterns.

## Confidence
- **High Confidence**: CNN architecture design and training pipeline (well-specified in code repository).
- **Medium Confidence**: Generalization to unseen SB types (limited by synthetic dataset coverage).
- **Low Confidence**: SHAP-based interpretability claims (no ablation study vs other XAI methods).
