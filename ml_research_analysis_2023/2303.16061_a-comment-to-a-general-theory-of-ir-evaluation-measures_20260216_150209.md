# A comment to "A General Theory of IR Evaluation Measures"

## Quick Facts
- arXiv ID: 2303.16061
- Source URL: https://arxiv.org/abs/2303.16061
- Reference count: 16
- Key outcome: The scale type of IR evaluation measures depends on the ordering relationship defined on the empirical relational system, invalidating claims that certain measures are interval scales independently of adopted ordering

## Executive Summary
This comment addresses critical limitations in a paper claiming certain IR evaluation measures are interval scales regardless of adopted ordering. The core issue is that scale type classification must account for the specific ordering relationship on the empirical relational system (ERS). The original paper's generic procedure only considers one specific ordering, making its derived interval scale claims valid only for that particular case. This means that statements about measures like Precision, Recall, and F-measure being interval scales are not generally valid across different orderings. The consequence is that incorrect scale type classification can lead to inappropriate statistical analyses and misleading conclusions about retrieval system performance.

## Method Summary
The comment demonstrates that scale type depends on ERS ordering by showing the original generic procedure only considers one specific ordering relationship. It argues that any claims about interval scale properties must explicitly specify the ERS being used, as different orderings will yield different scale classifications. The theoretical framework emphasizes that the same measure can have different scale types under different orderings of the empirical relational system.

## Key Results
- Scale type of IR evaluation measures depends on the ordering relationship defined on the empirical relational system
- The original paper's generic procedure only considers one specific ordering, limiting the validity of its interval scale claims
- Incorrect scale type classification leads to inappropriate statistical analyses and potentially misleading conclusions about retrieval performance

## Why This Works (Mechanism)
The mechanism operates through the fundamental principle that measurement theory requires scale type to be defined relative to the empirical relational system's ordering. When the ordering changes, the permissible transformations and statistical operations also change, affecting the scale classification. This dependency means that any generic claim about scale type must be qualified by the specific ERS ordering being used.

## Foundational Learning

**Empirical Relational System (ERS)**: The formal structure containing objects and their empirical relations. Needed to establish the measurement context. Quick check: Verify that all relevant objects and their relationships are captured in the system definition.

**Ordering Relationship**: The specific way elements in the ERS are compared or ranked. Critical because different orderings yield different scale types. Quick check: Confirm the ordering is well-defined and consistent across all elements.

**Scale Type Classification**: The process of determining permissible transformations and statistical operations. Essential for valid statistical inference. Quick check: Verify that statistical operations align with the identified scale type.

## Architecture Onboarding

**Component Map**: ERS Definition -> Ordering Specification -> Scale Type Determination -> Statistical Analysis

**Critical Path**: ERS definition and ordering specification must be established before scale type determination can be performed, which then enables appropriate statistical analysis

**Design Tradeoffs**: Generality vs specificity - broader claims about scale types require more comprehensive consideration of multiple orderings, but specific claims are more defensible

**Failure Signatures**: Incorrect scale type classification manifests as inappropriate statistical tests, invalid comparisons, or misleading performance claims
