# The Power of Learned Locally Linear Models for Nonlinear Policy Optimization

## Quick Facts
- arXiv ID: 2305.09619
- Source URL: https://arxiv.org/abs/2305.09619

## Executive Summary
This paper presents a model-based reinforcement learning approach that iteratively learns locally linear models of nonlinear system dynamics and performs iLQR-like policy updates. The key innovation is maintaining a policy with an open-loop input sequence and a sequence of stabilizing feedback gains, alternating between learning local linear models of the closed-loop linearized dynamics and performing gradient updates. The approach overcomes exponential dependence on problem horizon by synthesizing locally stabilizing gains. Theoretically, the algorithm computes an ϵ-stationary policy where the open-loop input sequence is an ϵ-first order stationary point for the iLQR approximation of the planning objective.

## Method Summary
The proposed method is an iterative algorithm that alternates between two phases: (1) learning local linear models of the closed-loop linearized dynamics using trajectories corrupted with measurement noise from an oracle, and (2) performing iLQR-like policy updates using gradient descent on the open-loop input sequence. The policy consists of both an open-loop input sequence and a sequence of stabilizing feedback gains that ensure closed-loop stability. The algorithm estimates the gradient of the cost function using the learned linear models and updates the policy parameters accordingly. The gain synthesis subroutine ensures that the closed-loop system remains stable throughout the learning process.

## Key Results
- Achieves sample complexity polynomial in relevant problem parameters
- Overcomes exponential dependence on problem horizon through locally stabilizing gains
- Computes an ϵ-stationary policy where the open-loop input sequence is an ϵ-first order stationary point for the iLQR approximation
- Demonstrates improved performance compared to natural deep learning baselines on quadrotor and inverted pendulum benchmarks

## Why This Works (Mechanism)
The algorithm's effectiveness stems from its ability to leverage local linear approximations of the nonlinear dynamics while maintaining closed-loop stability through carefully synthesized feedback gains. By alternating between model learning and policy optimization, it efficiently navigates the trade-off between exploration and exploitation. The use of iLQR-like updates on the learned linear models allows for efficient gradient-based optimization while the gain synthesis ensures that the resulting policies are stabilizing, preventing the exponential growth in error that would otherwise occur over long horizons.

## Architecture Onboarding

### Component Map
Oracle -> Trajectory Generator -> Linear Model Learner -> Gradient Estimator -> Policy Updater -> Gain Synthesizer -> Closed-Loop System

### Critical Path
The critical path for the algorithm is: Trajectory Generator -> Linear Model Learner -> Gradient Estimator -> Policy Updater -> Gain Synthesizer -> Closed-Loop System. This path represents the flow of information and computation in each iteration of the algorithm, where trajectories are generated using the current policy, linear models are learned from these trajectories, gradients are estimated using the learned models, the policy is updated based on these gradients, and stabilizing gains are synthesized to ensure closed-loop stability.

### Design Tradeoffs
- Local linear models vs. global nonlinear models: Local models offer computational efficiency and ease of optimization but may suffer from approximation errors far from the linearization point.
- Open-loop vs. closed-loop control: Open-loop control allows for efficient gradient-based optimization but may be sensitive to model errors, while closed-loop control provides robustness but complicates the optimization landscape.
- Exploration strategy: Random exploration may provide good coverage of the state space but can be inefficient, while directed exploration can focus on relevant regions but may miss important dynamics.

### Failure Signatures
- Instability during training: If the Lyapunov stability modulus μ_π,⋆ exceeds 1 or the gain magnitude L_π becomes too large, the closed-loop system may become unstable.
- Poor performance of iLQR baselines: If the learned dynamics have high train/test error or the exploration strategy does not provide sufficient data coverage, the iLQR baselines may underperform.
- Slow convergence: If the gradient estimates are noisy or the learning rate is too small, the algorithm may converge slowly or get stuck in suboptimal regions.

## Limitations
- Theoretical analysis assumes access to an oracle that provides trajectories corrupted with measurement noise, which may not be directly applicable to real-world scenarios.
- Performance of the algorithm may be sensitive to hyperparameters such as the sample size, gradient step size, noise variance, and controllability window.
- The algorithm's convergence guarantees rely on the stability of the learned linear models and the accuracy of the gradient estimates, which may be affected by factors like exploration strategy and noise levels.
