# Infor-Coef: Information Bottleneck-based Dynamic Token Downsampling for Compact and Efficient language model

## Quick Facts
- arXiv ID: 2305.12458
- Source URL: https://arxiv.org/abs/2305.12458
- Reference count: 17
- Key result: Achieves 18x FLOPs speedup with <8% accuracy degradation on GLUE benchmark

## Executive Summary
Infor-Coef introduces a novel approach for accelerating language models by combining dynamic token downsampling with static pruning, optimized through the information bottleneck principle. This method selectively allocates computation across different samples and hidden states, creating a compact and efficient subnetwork. The approach demonstrates significant performance improvements over existing static pruning, dynamic pruning, and distillation baselines, achieving an 18x speedup with minimal accuracy loss on the GLUE benchmark.

## Method Summary
Infor-Coef integrates dynamic token downsampling with static pruning in a unified framework optimized using the information bottleneck principle. The method employs a training strategy that jointly optimizes token retention and model pruning decisions. By leveraging the information bottleneck, the approach learns to retain only the most informative tokens while pruning less critical model parameters, resulting in a more efficient subnetwork. The training process is guided by a specialized loss function that balances information preservation with computational efficiency.

## Key Results
- Achieves 18x FLOPs speedup compared to BERT baseline
- Maintains less than 8% accuracy degradation on GLUE benchmark
- Outperforms various static pruning, dynamic pruning, and distillation baselines

## Why This Works (Mechanism)
The information bottleneck principle enables selective allocation of computation by identifying and retaining only the most informative tokens while pruning less critical model parameters. This approach allows the model to maintain task-relevant information while significantly reducing computational complexity. The dynamic nature of token downsampling ensures that computation is allocated efficiently based on the specific requirements of each input sample.

## Foundational Learning

**Information Bottleneck Principle**: A framework for learning compressed representations that preserve relevant information. Why needed: Enables selective retention of task-relevant information while discarding noise. Quick check: Verify that the bottleneck objective is properly formulated to balance compression and relevance.

**Dynamic Token Downsampling**: Real-time selection of tokens to process based on their importance. Why needed: Allows adaptive computation allocation based on input characteristics. Quick check: Ensure the downsampling mechanism can operate efficiently during inference.

**Static Pruning**: Pre-computed removal of model parameters deemed less important. Why needed: Reduces model size and computation for known patterns. Quick check: Validate that pruning doesn't remove critical model capacity.

**Component Map**: Input -> Token Importance Scoring -> Dynamic Downsampling -> Static Pruning -> Efficient Subnetwork
