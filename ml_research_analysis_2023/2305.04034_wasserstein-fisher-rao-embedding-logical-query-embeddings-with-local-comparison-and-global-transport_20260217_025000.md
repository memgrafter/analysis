# Wasserstein-Fisher-Rao Embedding: Logical Query Embeddings with Local Comparison and Global Transport

## Executive Summary
This paper proposes Wasserstein-Fisher-Rao Embedding (WFRE), a novel method for answering complex logical queries on knowledge graphs. The approach embeds sets as bounded measures in R and uses a scoring function based on the Wasserstein-Fisher-Rao (WFR) metric to balance local comparison and global transport. WFRE introduces an efficient convolution-based algorithm for linear time computation and employs a block-diagonal kernel to enforce the desired trade-off. The method demonstrates superior performance across multiple benchmark datasets and evaluation sets containing combinatorially complex queries.

## Method Summary
WFRE embeds sets as bounded measures in R and computes similarity scores using the Wasserstein-Fisher-Rao metric. The approach employs a convolution-based algorithm that achieves linear time complexity for computing the WFR distance. A block-diagonal kernel is introduced to control the trade-off between local comparison and global transport. The method processes logical queries by decomposing them into basic operations (AND, OR, NOT) and applying the WFR-based scoring function at each step. The convolution algorithm enables efficient computation of the optimal transport plan required for the WFR metric.

## Key Results
- WFRE outperforms existing query embedding methods on standard benchmark datasets
- Superior performance on evaluation sets with combinatorially complex logical queries
- Effective handling of hierarchical knowledge graph structures
- Ablation study demonstrates that the local-global trade-off is crucial for performance improvement

## Why This Works (Mechanism)
WFRE works by representing query answers as probability measures and computing their similarity using the WFR metric, which naturally captures both local feature matching and global structural alignment. The convolution-based algorithm enables efficient computation of the optimal transport plan required for the WFR distance. The block-diagonal kernel enforces a controlled trade-off between local and global comparison, preventing either aspect from dominating. This balanced approach allows WFRE to handle the combinatorial complexity of logical queries while maintaining computational efficiency.

Needed to provide a principled way to compare query embeddings that balances local and global information. - **Measure embedding**: Technique for representing sets as probability measures. Essential for enabling the use of Wasserstein-based metrics. Quick check: Ensure the embedding preserves relevant statistical properties of the original sets.

## Architecture Onboarding

**Component Map**: Entity Embeddings -> Measure Embedding -> WFR Metric Computation -> Convolution Algorithm -> Scoring Function

**Critical Path**: The critical path involves converting entity embeddings to measure representations, computing the WFR distance via the convolution algorithm, and applying the block-diagonal kernel to obtain final scores. The convolution algorithm is the computational bottleneck and requires careful optimization.

**Design Tradeoffs**: The primary tradeoff is between computational efficiency and expressiveness. The convolution-based algorithm achieves linear time complexity but may limit the expressiveness of the WFR metric. The block-diagonal kernel design trades off flexibility for controlled local-global comparison. Using pre-trained entity embeddings avoids costly joint learning but may limit adaptation to query-specific patterns.

**Failure Signatures**: Performance degradation may occur when: (1) the block-diagonal kernel is poorly tuned, leading to overemphasis on either local or global comparison; (2) the convolution algorithm introduces numerical instability for large queries; (3) entity embeddings are of insufficient quality or incompatible with the measure embedding scheme.
