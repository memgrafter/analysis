# XAI in Computational Linguistics: Understanding Political Leanings in the Slovenian Parliament

## Quick Facts
- arXiv ID: 2305.04631
- Source URL: https://arxiv.org/abs/2305.04631
- Reference count: 7
- Primary result: SVM achieved 91% accuracy, SloBERTa achieved 87% accuracy in classifying parliamentary speeches as left- or right-leaning

## Executive Summary
This study applies XAI techniques to understand political leanings in the Slovenian Parliament during the 2014-2020 migrant crisis debates. Researchers developed both classical machine learning (SVM) and transformer language models (BERT, SloBERTa) to classify parliamentary speeches as left- or right-leaning. Using feature importance analysis and Shapley values, the study identified key differentiating terms: left-leaning speakers used concepts like "refugee," "unity," and "debate," while right-leaning speakers emphasized "illegal migrant," "Slovenia," and party names. This demonstrates how XAI can bridge computational and political linguistics by revealing the linguistic patterns that distinguish political ideologies in parliamentary discourse.

## Method Summary
The study used the ParlaMint SI dataset of Slovenian parliamentary transcriptions, filtering for migration-related speeches and balancing left/right classes. Two approaches were employed: (1) Linear SVM with TF-IDF features using unigrams, bigrams, and trigrams, and (2) fine-tuning multilingual BERT and SloBERTa with 512-token truncation. Feature importance analysis was applied to the SVM model, while SHAP values were used to explain transformer model decisions. The analysis identified key partisan linguistic markers through these explainability techniques.

## Key Results
- SVM model achieved 91% accuracy in classifying left vs. right-leaning speeches
- SloBERTa achieved 87% accuracy, outperforming BERT
- Feature importance analysis revealed left-leaning speakers used terms like "refugee," "unity," and "debate"
- Right-leaning speakers emphasized "illegal migrant," "Slovenia," and party names
- SHAP values provided similar interpretations for transformer models

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SVM feature importance reveals partisan linguistic markers because hyperplane weights directly encode term contributions to class separation
- Mechanism: Linear SVM creates a decision boundary where each feature's weight magnitude indicates its contribution to distinguishing left- vs right-leaning speeches
- Core assumption: The linear separability assumption holds for parliamentary discourse features
- Evidence anchors: Abstract mentions feature importance analysis identifying key differentiating terms; section explains hyperplane weights represent orthogonal coordinates to the decision boundary

### Mechanism 2
- Claim: SHAP values provide interpretable explanations for transformer models by quantifying each token's marginal contribution to prediction
- Mechanism: SHAP uses cooperative game theory to calculate how much each token's presence changes the model's output probability
- Core assumption: The model's behavior can be decomposed into additive contributions from individual tokens
- Evidence anchors: Section explains SHAP derives values through sampling approximations; similar results to SVM feature importance

### Mechanism 3
- Claim: Domain-specific language models outperform multilingual models for parliamentary discourse classification
- Mechanism: Monolingual models trained on Slovenian parliamentary data learn language-specific patterns and political terminology
- Core assumption: Political discourse contains language-specific patterns that cannot be adequately captured by multilingual models
- Evidence anchors: Section notes SloBERTa is monolingual and trained purely on Slovenian data; SloBERTa outperformed BERT with 87% accuracy

## Foundational Learning

- Concept: Feature importance in linear models
  - Why needed here: Understanding how SVM weights translate to feature importance is essential for interpreting which words/phrases drive classification decisions
  - Quick check question: If a word has a weight of -2.5 in an SVM model, does this mean it strongly predicts the "left" class, the "right" class, or neither?

- Concept: Shapley value theory
  - Why needed here: SHAP values provide the theoretical foundation for interpreting complex transformer model decisions
  - Quick check question: If a token has a Shapley value of +3.2 in a classification model, does this contribute positively to the "left" or "right" class prediction?

- Concept: Political discourse analysis
  - Why needed here: Understanding how political ideologies manifest in language helps validate whether model-identified features actually correspond to meaningful partisan distinctions
  - Quick check question: Why might the term "refugee" be associated with left-leaning discourse while "illegal migrant" is associated with right-leaning discourse in European parliamentary contexts?

## Architecture Onboarding

- Component map: ParlaMint dataset → preprocessing → TF-IDF → Linear SVM; ParlaMint dataset → tokenization → BERT/SloBERTa fine-tuning; SHAP analysis for transformer models
- Critical path: Data preprocessing → Model training → Explainability analysis → Interpretation
- Design tradeoffs: SVM provides interpretable linear coefficients but may miss nonlinear patterns; transformers capture complex patterns but require approximation methods like SHAP for interpretation
- Failure signatures: Low accuracy despite high feature importance values (model overfitting), SHAP values showing counterintuitive patterns (feature interaction issues)
- First 3 experiments:
  1. Run SVM with unigrams only and compare accuracy to bigram/trigram combinations to establish baseline complexity
  2. Apply SHAP to the best-performing SloBERTa model on a small validation set to verify interpretation consistency
  3. Compare feature importance from SVM with SHAP values from transformer models to identify convergent vs divergent patterns

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do the SHAP values for specific words correlate with their actual political connotations in Slovenian political discourse?
- Basis in paper: The paper identifies key differentiating terms through Shapley values but notes this is where "our analysis stops" and suggests further qualitative work is needed
- Why unresolved: The study identifies words like "illegal migrant," "refugee," and party names as important but doesn't analyze their contextual usage or connotative meaning in political discourse
- What evidence would resolve it: A detailed qualitative analysis of how these words are used in context, examining whether they function as neutral descriptors, loaded terms, or stylistic elements in political rhetoric

### Open Question 2
- Question: Would incorporating more nuanced political classifications beyond left/right improve model accuracy and explanatory power?
- Basis in paper: The study uses a binary left/right classification based on party affiliations, but acknowledges this is a simplification of complex political positions
- Why unresolved: The binary classification may miss important ideological distinctions within the left-right spectrum that could affect how migration issues are discussed
- What evidence would resolve it: Testing the model with multi-dimensional political classifications and comparing performance metrics and feature importance results

### Open Question 3
- Question: How does the truncation of speeches to 512 tokens affect the models' ability to capture the full argumentative structure of parliamentary speeches?
- Basis in paper: The paper notes that "more than 60% of the speeches in our dataset contain more than 512 tokens" and that this truncation could explain why language models underperform compared to classical methods
- Why unresolved: The study acknowledges truncation as a limitation but doesn't explore how much information is lost or how it affects the models' understanding of complex political arguments
- What evidence would resolve it: Comparative analysis of model performance using different sequence lengths, examining how truncation affects predictions for longer, more complex speeches versus shorter ones

## Limitations
- Limited generalizability across political contexts - findings are specific to Slovenian parliamentary discourse during the 2014-2020 migrant crisis period
- Potential confounding factors in feature importance - patterns may reflect strategic positioning during the migration crisis rather than stable ideological markers
- Approximation limitations in transformer explainability - SHAP method provides approximations rather than exact attributions

## Confidence

**High confidence**: Classification performance claims (91% SVM accuracy, 87% SloBERTa accuracy) are well-supported by methodology and cross-validation approach.

**Medium confidence**: Identification of specific partisan linguistic markers is plausible but context-dependent, requiring domain expertise validation beyond computational analysis.

**Low confidence**: Generalizability of findings to other political contexts and stability of identified markers over time, as the study doesn't provide sufficient evidence for cross-national validity.

## Next Checks
- Check 1: Conduct temporal validation by training separate models on speeches from different years (2014, 2016, 2018, 2020) to assess whether linguistic markers remain stable over time
- Check 2: Apply trained models to parliamentary speeches on different topics to test whether the same linguistic patterns distinguish left- and right-leaning positions across policy domains
- Check 3: Compare Slovenian parliamentary discourse patterns with similar analyses of other European parliaments during the same period to assess cross-national validity
