# tmn at SemEval-2023 Task 9: Multilingual Tweet Intimacy Detection using XLM-T, Google Translate, and Ensemble Learning

## Quick Facts
- arXiv ID: 2304.04054
- Source URL: https://arxiv.org/abs/2304.04054
- Reference count: 10
- Ranked 4th on leaderboard with Pearson's r of 0.599, improving up to 0.088 Pearson's r over average submissions

## Executive Summary
This paper describes a system developed for SemEval-2023 Task 9: Multilingual Tweet Intimacy Analysis. The system uses an ensemble of XLM-T models, a multilingual RoBERTa model adapted to the Twitter domain, and leverages Google Translate to improve performance on unseen languages. By combining models trained on original data (for seen languages) and joint original+translated data (for unseen languages), the system achieved strong results, ranking 4th overall with significant improvements over baseline submissions.

## Method Summary
The system uses XLM-T, a multilingual RoBERTa model pre-trained on 200M tweets, fine-tuned on the SemEval-2023 Task 9 dataset. Tweets were translated to English using Google Translate and concatenated with original text to create joint input representations. Two-part ensemble learning was applied: XLM-T models fine-tuned on original data for seen languages, and models fine-tuned on joint original+translated data for unseen languages. The ensemble strategy improved zero-shot performance on Hindi, Arabic, Dutch, and Korean.

## Key Results
- Achieved Pearson's r of 0.599 on the test set, ranking 4th on the leaderboard
- Improved performance up to 0.088 Pearson's r over average submissions across 45 systems
- Demonstrated effectiveness of translation-based data augmentation for zero-shot learning on unseen languages

- Evidence anchors: Abstract identifies XLM-T as Twitter-adapted; section shows best results with XLM-T on original dataset

- Core assumption: Different data representations capture different aspects of intimacy

- Break condition: If models in ensemble are too similar or one representation dominates

## Architecture Onboarding

- Component map: Input tweets -> Google Translate preprocessing -> XLM-T model fine-tuning -> Two-part ensemble -> Output intimacy scores

- Critical path:
  1. Preprocess input tweets through Google Translate
  2. Fine-tune XLM-T on original data for seen languages
  3. Fine-tune XLM-T on joint original+translated data for unseen languages
  4. Ensemble predictions from both models
  5. Output final intimacy score

- Design tradeoffs:
  - Translation improves zero-shot performance but may introduce noise
  - Ensemble improves robustness but increases computational cost
  - Domain adaptation improves Twitter-specific performance but may limit generalization

- Failure signatures:
  - Poor unseen language performance: Check translation quality and translation service
  - Inconsistent predictions across languages: Investigate training data biases
  - Overfitting to seen languages: Increase regularization or use more diverse data

- First 3 experiments:
  1. Compare XLM-T fine-tuned on original vs. translated data for seen languages
  2. Test different translation services (Google Translate vs. DeepL) for quality impact
  3. Experiment with different ensemble strategies (weighted averaging, stacking)
