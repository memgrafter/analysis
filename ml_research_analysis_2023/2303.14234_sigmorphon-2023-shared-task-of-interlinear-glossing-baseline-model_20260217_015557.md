# SIGMORPHON 2023 Shared Task of Interlinear Glossing: Baseline Model

## Quick Facts
- arXiv ID: 2303.14234
- Source URL: https://arxiv.org/abs/2303.14234
- Reference count: 4
- Primary result: Morphological segmentation (open track) outperforms word-level input (closed track) by up to 16.4% in morpheme accuracy

## Executive Summary
This paper presents a transformer-based baseline system for the SIGMORPHON 2023 Shared Task on Interlinear Glossing, treating gloss generation as a token classification task using a RoBERTa architecture. The system processes segmented morphemes (open track) or whole words (closed track) along with their translations to predict morphological glosses. Results show significant performance differences between tracks, with open track models achieving up to 16.4% better morpheme accuracy. The study identifies key challenges including unseen word handling, phonetic information integration, and the need for architecture adaptation in low-resource settings.

## Method Summary
The baseline system uses a RoBERTa transformer architecture for token classification, where each morpheme or word is classified into a gloss label based on contextual information from both transcription and translation. The model employs separate tokenizers for transcription and translation, concatenates them with a separator token, and uses a classification head for gloss prediction. Training uses AdamW optimizer with learning rate 2e-5, 80 epochs, batch size 16, and weight decay 0.01 on a V100 GPU. The system processes data in both open track (with morphological segmentation) and closed track (without segmentation) configurations across six low-resource languages.

## Key Results
- Open track models outperform closed track models by up to 16.4% in morpheme accuracy
- Word-level accuracy tends to be higher than morpheme accuracy in the closed track, indicating better handling of simple words over complex multi-morphemic ones
- The model successfully handles homophonous morphemes through contextual disambiguation using translation information

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Treating gloss generation as a token classification task allows the model to leverage contextual information from both transcription and translation to disambiguate homophonous morphemes.
- Mechanism: The RoBERTa architecture encodes the concatenated transcription and translation using separate vocabularies, creating a joint representation where morphological context and semantic context interact. This enables disambiguation based on surrounding words.
- Core assumption: Morphological ambiguity can be resolved through contextual patterns in the surrounding text and translation.
- Evidence anchors: [abstract] "In our system, we utilize a transformer architecture and treat gloss generation as a sequence labelling task." [section] "A transformer-based architecture is an effective choice for this task, as labelling morphemes often involves disambiguating homophonous morphemes based on context." [corpus] Weak - no direct evidence of homophone disambiguation success rates
- Break condition: If morphological ambiguity cannot be resolved through contextual patterns alone, such as with rare or unseen morpheme combinations.

### Mechanism 2
- Claim: Morphological segmentation (open track) provides explicit morpheme boundaries that improve model performance by reducing out-of-vocabulary issues.
- Mechanism: By providing segmented morphemes as input tokens, the model can learn individual morpheme-to-gloss mappings more effectively than when inferring segmentation from word forms.
- Core assumption: Explicit morpheme boundaries reduce the vocabulary space and improve generalization to unseen words.
- Evidence anchors: [section] "As expected, the models trained with segmentation (open track) outperformed the models without, by up to a 16.4% improvement in morpheme accuracy." [section] "In the closed track, word-level accuracy tended to be higher than morpheme accuracy. This indicates that the models could learn words with few morphemes more accurately than words with a greater number of constituent morphemes, which were more likely to be out-of-vocabulary." [corpus] No direct evidence of vocabulary size reduction
- Break condition: If the segmentation process introduces noise or if languages have many morphemes per word that the model cannot handle effectively.

### Mechanism 3
- Claim: Concatenating transcription and translation with a separator token allows the model to use translation context to inform gloss predictions.
- Mechanism: The translation provides semantic context that helps disambiguate morphological functions, especially for functional morphemes that don't carry lexical meaning.
- Core assumption: Semantic context from translation is useful for disambiguating morphological functions.
- Evidence anchors: [section] "The input transcription and translation are encoded using two separate vocabularies and concatenated into a single string with a separator token." [section] "For example, the English plural morpheme can take the form -s or -es depending on the stem. A model which incorporates phonetic similarity could learn more efficiently..." [corpus] Weak - no direct evidence of translation context effectiveness
- Break condition: If translation context is too noisy or if the semantic mapping between source and target languages is too distant for effective disambiguation.

## Architecture Onboarding

- Component map: Transcription tokenizer -> Translation tokenizer -> Concatenation layer -> RoBERTa encoder -> Classification head
- Critical path:
  1. Preprocess data: segment words into morphemes (open track) or keep whole words (closed track)
  2. Tokenize transcription and translation separately
  3. Concatenate with separator token
  4. Feed through RoBERTa encoder
  5. Apply classification head to predict glosses
  6. Evaluate using accuracy, F1, BLEU metrics
- Design tradeoffs:
  - Token classification vs sequence-to-sequence: classification is simpler but less flexible for handling word boundaries
  - Separate vocabularies for transcription vs translation: allows different tokenization strategies but increases complexity
  - Fixed architecture vs language-specific tuning: simpler deployment but may miss language-specific optimizations
- Failure signatures:
  - Low morpheme accuracy but high word accuracy: model handles simple words well but struggles with multi-morphemic complexity
  - Poor performance on unseen words: vocabulary coverage issues, need subword tokenization
  - Translation context not helping: semantic distance between source and target too large, or translation too noisy
- First 3 experiments:
  1. Compare closed track (word-level) vs open track (morpheme-level) performance on a single language to verify the 16.4% improvement claim
  2. Test with and without translation context by removing the translation input to see if semantic information improves performance
  3. Evaluate on a held-out test set with unseen words to measure vocabulary coverage and generalization capabilities

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does incorporating phonetic information improve morpheme gloss prediction accuracy compared to purely orthographic approaches?
- Basis in paper: [explicit] The paper suggests that models operating on orthographic transcription could benefit from phonetic similarity between morphemes to make better predictions on unseen or ambiguous morphemes.
- Why unresolved: The current baseline system does not incorporate phonetic information, leaving the potential performance gains unexplored.
- What evidence would resolve it: Empirical comparison of models with and without phonetic features on the same dataset, measuring improvements in accuracy for unseen morphemes and ambiguous cases.

### Open Question 2
- Question: What is the optimal model architecture and parameter size for extremely low-resource languages like Gitksan with only 31 sentences?
- Basis in paper: [explicit] The paper notes that using the same model architecture for every language despite vast differences in training data, and suggests that reducing architecture size in low-resource settings might show better results.
- Why unresolved: The current baseline uses a standard RoBERTa architecture without parameter reduction or architecture adaptation for low-resource languages.
- What evidence would resolve it: Systematic experimentation comparing different model sizes and architectures on languages with varying data quantities, identifying the optimal configuration for extremely low-resource cases.

### Open Question 3
- Question: Can unsupervised morphological segmentation methods effectively replace explicit segmentation in the closed track to match open track performance?
- Basis in paper: [explicit] The paper identifies that word-level models have no way to make predictions for unseen words even if constituent morphemes are known, and mentions that unsupervised morphological segmentation research has had some success.
- Why unresolved: Current models in the closed track cannot handle unseen words without morphological segmentation, creating a significant performance gap with the open track.
- What evidence would resolve it: Head-to-head comparison of models using different unsupervised segmentation approaches versus the current closed track approach, measuring whether they can achieve comparable accuracy to open track models.

## Limitations

- Limited ablation studies: The paper demonstrates segmentation benefits but lacks detailed studies on which specific components drive the 16.4% improvement
- Weak evidence for key mechanisms: Claims about translation context helping disambiguation and RoBERTa resolving homophone ambiguity lack direct empirical support
- Architecture specification gaps: Missing critical details about RoBERTa variant and preprocessing steps that could impact reproducibility

## Confidence

- High confidence: Open track models outperform closed track models by 16.4% in morpheme accuracy with clear methodology and substantial difference
- Medium confidence: Word-level accuracy tends to be higher than morpheme accuracy in closed track, suggesting better handling of simpler words (interpretation could benefit from additional analysis)
- Low confidence: Translation context significantly aids in disambiguating morphological functions (proposed but not empirically validated)
