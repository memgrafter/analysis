# Learning from AI: An Interactive Learning Method Using a DNN Model Incorporating Expert Knowledge as a Teacher

## Quick Facts
- arXiv ID: 2306.02257
- Source URL: https://arxiv.org/abs/2306.02257
- Reference count: 12
- Primary result: Interactive editing of attention maps with expert-knowledge AI improves learner classification accuracy (77.78% vs 55.69% baseline)

## Executive Summary
This study proposes an interactive learning method where learners use an AI model incorporating expert knowledge as a teacher to acquire the grounds for expert decisions. The approach uses an attention branch network (ABN) fine-tuned by experts, allowing learners to interactively edit attention maps to match correct recognition results. Through this process, learners develop understanding of diagnostic criteria embedded in the expert-annotated regions.

The method was evaluated using fundus images for diabetic retinopathy classification, demonstrating that learners using the proposed approach with expert-knowledge AI models achieved significantly higher post-learning accuracy (77.78%) compared to traditional learning methods. The study also showed that learners could focus on disease regions closest to expert annotations, as measured by higher class IoU scores for attention maps.

## Method Summary
The method involves fine-tuning an ABN with expert-modified attention maps, then creating an interactive application where learners can edit these attention maps and observe changes in classification results. Experts first modify attention maps for misclassified samples, which are then used to fine-tune the ABN through a custom loss function combining classification error with attention map similarity. Learners interact with the system by editing attention maps to emphasize diagnostically relevant regions, receiving immediate feedback through changes in classification scores. The approach was evaluated using fundus images from the Messidor and IDRiD datasets.

## Key Results
- Post-learning classification accuracy of 77.78% for learners using the proposed method with expert-knowledge AI model
- Significant improvement over learning without the app (55.69%) or using non-expert AI models (57.50%)
- Highest class IoU scores (0.1314) for attention maps, indicating learners focused on disease regions closest to expert annotations
- The proposed method demonstrated effectiveness for teaching multiple learners simultaneously

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Learners improve classification accuracy by iteratively editing attention maps to align with expert-annotated regions.
- Mechanism: The learner edits the attention map of an ABN fine-tuned with expert knowledge, then observes changes in classification scores, learning which regions are diagnostically relevant.
- Core assumption: Attention maps provide interpretable cues about expert decision grounds, and learners can discover these grounds through interaction.
- Evidence anchors:
  - [abstract] "the learner learns by editing the attention maps and changing the inference results"
  - [section] "By repeatedly editing the attention maps and making inferences so that the correct recognition results are output, the learner can acquire the grounds for the expert's judgments embedded in the ABN"
- Break condition: If edited attention maps diverge too far from expert-annotated regions, the ABN's classification score will not improve, providing no learning signal.

### Mechanism 2
- Claim: Expert knowledge embedded in the ABN improves both classification accuracy and visual explanatory power.
- Mechanism: Experts manually modify attention maps for misclassified samples; these modified maps are then used to fine-tune the ABN, weighting feature maps toward diagnostically relevant regions.
- Core assumption: Expert-modified attention maps encode valid diagnostic criteria that can be transferred to the model via fine-tuning.
- Evidence anchors:
  - [abstract] "a method that incorporates expert human knowledge in the model via an attention map in a manner that improves explanatory power and recognition accuracy"
  - [section] "Lm(xi) is the error when outputting the same attention map Me(xi) as the corrected attention map M(xi)"
- Break condition: If expert knowledge is incorrect or inconsistent, the fine-tuned model may perform worse than the original ABN.

### Mechanism 3
- Claim: Interactive learning with the app produces higher post-learning classification accuracy than passive learning or learning with non-expert AI models.
- Mechanism: The app enables learners to actively explore the relationship between attention map edits and classification outcomes, receiving immediate feedback.
- Core assumption: Active exploration and immediate feedback accelerate learning of diagnostic criteria compared to passive instruction.
- Evidence anchors:
  - [section] "Compared with the other learning methods, the proposed method using the AI model with expert knowledge results in higher post-learning scores"
  - [section] "the proposed method is effective for teaching multiple learners"
- Break condition: If the app interface is confusing or the feedback is delayed/ambiguous, the learning benefit may not materialize.

## Architecture Onboarding

- Component map: ABN feature extractor → Attention branch (1×1 conv) → Perception branch (classification) + Attention map visualization. Learner app: input image + display attention map + editing interface + inference trigger.
- Critical path: Load image → Generate ABN attention map → Learner edits → Apply edited map to attention mechanism (Eq. 3) → Run inference → Display score → Iterate.
- Design tradeoffs: Using binary edited maps simplifies interaction but loses gradient information; fine-tuning only attention and perception branches preserves feature extractor stability but may limit adaptation.
- Failure signatures: Learner edits have no effect on classification scores; ABN consistently misclassifies despite expert fine-tuning; IoU scores plateau below expert level.
- First 3 experiments:
  1. Run ABN on a test fundus image, inspect default attention map and classification score.
  2. Edit attention map to emphasize known disease region, rerun inference, compare score change.
  3. Fine-tune ABN with expert-modified maps on a small misclassified subset, evaluate classification accuracy improvement.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How would the proposed method perform when applied to tasks requiring higher levels of expertise, such as visual inspection tasks beyond medical image classification?
- Basis in paper: [explicit] The authors mention that future work includes applying the "learn from AI" method to tasks requiring higher levels of expertise (such as visual inspection) beyond the medical image classification demonstrated in this study.
- Why unresolved: The current study only evaluated the method on diabetic retinopathy classification using fundus images. There is no empirical evidence of how well this approach generalizes to more complex inspection tasks.
- What evidence would resolve it: Experimental results showing the method's effectiveness on various visual inspection tasks (e.g., manufacturing defect detection, quality control in different industries) compared to traditional training methods.

### Open Question 2
- Question: What is the optimal balance between learner autonomy in editing attention maps and guidance from the AI model to maximize learning efficiency?
- Basis in paper: [inferred] The study shows that learners can interactively edit attention maps and learn from AI feedback, but it doesn't explore how much guidance versus autonomy is most effective for different types of learners or tasks.
- Why unresolved: The current study uses a fixed approach where learners edit attention maps freely, but doesn't investigate whether different levels of AI intervention or guidance would improve learning outcomes.
- What evidence would resolve it: Comparative experiments testing different levels of AI intervention (e.g., AI suggesting regions to focus on, AI restricting certain edits, AI providing hints) and measuring their impact on learning efficiency and accuracy.

### Open Question 3
- Question: How does the proposed method scale when applied to domains with larger and more complex datasets, or when dealing with multi-class classification problems?
- Basis in paper: [explicit] The authors note that future work should include larger-scale experiments, but the current study only used a relatively small dataset (124 normal and 81 diseased fundus images).
- Why unresolved: The study's evaluation was limited to a binary classification task with a modest dataset size. There's no evidence of how well the method would perform with more classes or larger, more complex datasets.
- What evidence would resolve it: Experiments demonstrating the method's effectiveness on multi-class classification problems and larger datasets, including analysis of computational requirements and learning curve patterns.

### Open Question 4
- Question: What is the long-term retention rate of knowledge acquired through the proposed method compared to traditional learning methods?
- Basis in paper: [inferred] While the study shows improved post-learning accuracy, it doesn't investigate whether learners retain this knowledge over extended periods or if the knowledge degrades faster than traditionally acquired expertise.
- Why unresolved: The experimental design only measured immediate post-learning performance without follow-up assessments to determine knowledge retention over time.
- What evidence would resolve it: Longitudinal studies tracking learners' performance over weeks or months after using the proposed method versus traditional learning, measuring both retention and the ability to apply knowledge to novel situations.

## Limitations

- The exact procedure for expert modification of attention maps is not specified, which is critical for the method's effectiveness
- The study used a relatively small dataset (30 normal and 40 disease images for evaluation), limiting statistical power and generalizability
- The specific implementation details of the educational application's user interface and interaction logic are not provided

## Confidence

- **High confidence:** The ABN architecture with attention mechanisms can generate interpretable maps for diabetic retinopathy classification
- **Medium confidence:** Interactive editing of attention maps can improve learner understanding of diagnostic grounds
- **Medium confidence:** Expert knowledge incorporated through attention map modification can enhance model performance
- **Low confidence:** The specific interaction design and expert modification procedures are optimal for learning

## Next Checks

1. **Expert knowledge validation:** Conduct a controlled experiment comparing ABN performance using expert-modified attention maps versus randomly modified maps or no modification, to confirm that expert knowledge specifically drives the performance improvement.

2. **Interaction design A/B test:** Implement and test multiple interaction paradigms (e.g., different attention map editing tools, feedback frequencies, or visualization methods) to identify which design features most strongly correlate with learning outcomes.

3. **Cross-dataset generalizability test:** Evaluate the method on additional fundus image datasets (e.g., EyePACS, Kaggle Diabetic Retinopathy) with different imaging protocols to assess robustness and generalizability of both the model and the learning approach.
