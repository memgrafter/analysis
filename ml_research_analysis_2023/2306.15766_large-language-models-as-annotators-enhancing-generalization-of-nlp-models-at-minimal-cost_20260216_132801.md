# Large Language Models as Annotators: Enhancing Generalization of NLP Models at Minimal Cost

## Quick Facts
- arXiv ID: 2306.15766
- Source URL: https://arxiv.org/abs/2306.15766
- Authors: 
- Reference count: 12
- Key outcome: LLM-based annotations with Conditional Informativeness sampling improve NLP model generalization in low-data regimes.

## Executive Summary
This paper investigates using large language models (LLMs) to annotate unlabeled data and improve generalization of NLP models in low-data regimes. The authors propose a sampling strategy called Conditional Informativeness, which selects inputs for LLM annotation based on the deviation between predictions of the base model and the finetuned NLP model. Experiments on semantic similarity and semantic search tasks show that this approach significantly outperforms random and uncertainty-based sampling strategies, leading to substantial improvements in accuracy for both training and target domains.

## Method Summary
The approach uses an active learning framework where a base model is first finetuned on labeled data to create an NLP model. For unlabeled inputs, Conditional Informativeness scores are computed by measuring the deviation between the base model and finetuned model predictions. Inputs with the highest deviation scores are selected for LLM annotation, then the NLP model is retrained on the augmented dataset combining original labeled data with LLM annotations. This strategy targets inputs where the finetuned model is likely making errors, making LLM corrections most valuable.

## Key Results
- Conditional Informativeness sampling significantly improves accuracy on both training and target domains for semantic similarity and semantic search tasks
- The approach outperforms random sampling and uncertainty-based sampling strategies
- LLM annotations provide diverse, high-quality labels that fill gaps in training data and improve out-of-domain performance

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LLM annotations are most informative when targeting inputs where the finetuned model's predictions deviate significantly from the base model
- Mechanism: Conditional Informativeness metric captures this deviation, identifying inputs likely to be incorrectly predicted by the finetuned model
- Core assumption: LLM annotations are more accurate than the finetuned model on high-deviation inputs
- Evidence anchors:
  - [abstract] "we propose a sampling strategy based on the difference in prediction scores between the base model and the finetuned NLP model"
  - [section] "inputs which have the max deviation between the two scores are the ones likely to be incorrectly predicted by the finetuned model"

### Mechanism 2
- Claim: Random and uncertainty-based sampling are less effective than Conditional Informativeness for LLM annotations
- Mechanism: Random sampling wastes budget on inputs the model already handles well; uncertainty sampling targets uncertain inputs but these may not be most informative for LLM correction
- Core assumption: Most informative inputs for LLM annotation are those where finetuned model deviates from base model, not where it's uncertain
- Evidence anchors:
  - [section] "Experiments with classification (semantic similarity) and ranking (semantic search) tasks show that our sampling strategy leads to significant gains in accuracy"

### Mechanism 3
- Claim: LLM annotations improve generalization to both training and target domains by providing diverse, high-quality labels
- Mechanism: LLM annotations fill gaps in training data by providing labels for inputs that the finetuned model struggles with
- Core assumption: LLM annotations are diverse enough to cover patterns needed for both training and target domain generalization
- Evidence anchors:
  - [abstract] "Experiments with classification (semantic similarity) and ranking (semantic search) tasks show that our sampling strategy leads to significant gains in accuracy for both the training and target domains"

  1. Finetune base model on labeled data to get NLP model
  2. Compute Conditional Informativeness for unlabeled inputs
  3. Sample inputs with highest Conditional Informativeness
  4. Annotate sampled inputs using LLM
  5. Retrain NLP model on original labeled data + LLM annotations

## Limitations
- The generalizability of Conditional Informativeness to other NLP tasks beyond semantic similarity and search remains untested
- The computational cost of repeatedly computing LLM predictions during sampling may offset benefits in some scenarios
- No thorough analysis of how annotation costs scale with task complexity or dataset size

## Confidence

**High Confidence:** The experimental methodology is sound with appropriate baseline comparisons and clear statistical significance demonstrations.

**Medium Confidence:** The sampling strategy shows consistent improvements across different datasets and tasks, but the magnitude of improvements varies and theoretical grounding could be stronger.

**Low Confidence:** Scalability analysis and cost-benefit evaluation are limited, with insufficient exploration of robustness to LLM variations and prompt engineering choices.
