# Neural network with optimal neuron activation functions based on additive Gaussian process regression

## Quick Facts
- arXiv ID: 2301.05567
- Source URL: https://arxiv.org/abs/2301.05567
- Reference count: 0
- One-line primary result: A neural network approach using GPR-derived activation functions achieves PES fitting accuracy of <1 cm⁻¹ with 1000 training points and 100 terms.

## Executive Summary
This paper presents a novel neural network approach that constructs optimal neuron activation functions using additive Gaussian process regression (GPR). Unlike conventional neural networks that use fixed activation functions across all neurons, this method generates individual activation functions for each neuron based on component functions from HDMR-GPR. The approach eliminates the need for non-linear optimization of neural network parameters while maintaining high expressive power. The authors demonstrate the method's effectiveness by fitting the potential energy surface of the water molecule, achieving accuracy comparable to full-dimensional GPR models with significantly fewer terms.

## Method Summary
The method constructs neural networks where activation functions are derived from additive Gaussian process regression component functions. First-order HDMR models are used in redundant coordinates (averages of coordinate pairs), which creates a single-hidden layer neural network architecture with universal approximation properties. The component functions serve as individual activation functions for each neuron, avoiding non-linear parameter fitting. Model complexity is reduced through variance-based pruning of component functions. The approach combines the robustness of linear regression with the expressive power of neural networks.

## Key Results
- Achieved test set error <1 cm⁻¹ for H2O PES fitting with 1000 training points and ~100 terms
- Outperformed conventional neural networks in high accuracy regimes where conventional NNs suffer from overfitting
- Demonstrated effective model compression through variance-based pruning, reaching accuracy plateaus with reduced terms
- Showed that first-order HDMR in redundant coordinates provides universal approximation capability

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Using HDMR-GPR to construct neuron activation functions eliminates the need for non-linear parameter optimization in neural networks.
- **Mechanism**: The activation functions are derived as component functions from an additive Gaussian process regression model. These component functions are linear combinations of smooth kernel functions and thus require only linear operations to compute, avoiding the need for non-linear optimization of weights and biases.
- **Core assumption**: The component functions from HDMR-GPR can serve as valid neuron activation functions for universal approximation.
- **Evidence anchors**:
  - [abstract] "An approach is also introduced that avoids non-linear fitting of neural network parameters."
  - [section] "One reason why the same simple-form activation functions are typically used for all neurons is the possibility to simplify this optimization with backpropagation."
  - [corpus] Weak evidence - related papers discuss non-linear activation functions but don't specifically address HDMR-GPR based activation functions.
- **Break condition**: If the component functions from HDMR-GPR are not smooth or universal approximators, the approach would fail to provide valid activation functions.

### Mechanism 2
- **Claim**: Using redundant coordinates in the first-order HDMR model allows the single-hidden layer neural network to achieve universal approximation.
- **Mechanism**: By defining redundant coordinates as averages of pairs of original coordinates, the model effectively samples higher-order coupling terms while maintaining a first-order additive structure. This allows the model to capture complex relationships between variables without explicitly increasing the order of the HDMR.
- **Core assumption**: The redundant coordinates preserve the essential information needed for accurate function approximation.
- **Evidence anchors**:
  - [section] "A first order additive model in redundant coordinates, however, even if those coordinates linearly depend on the original coordinates, is a universal approximator as it has the form of a single-hidden layer NN."
  - [section] "The redundant variables y are defined by defining new vectors that are averages of all pairs of coordinates and adding them to the coordinate set."
  - [corpus] Weak evidence - related papers discuss redundant coordinates but don't specifically address their use in HDMR-based neural networks.
- **Break condition**: If the redundant coordinates introduce too much noise or lose critical information, the approximation quality would degrade.

### Mechanism 3
- **Claim**: Pruning component functions based on their variance effectively reduces model complexity without sacrificing accuracy.
- **Mechanism**: By discarding component functions with the lowest magnitudes (as measured by their variance), the model can achieve the same accuracy with fewer terms. This is possible because many component functions contribute little to the overall approximation.
- **Core assumption**: The variance of a component function is a good indicator of its importance to the overall model.
- **Evidence anchors**:
  - [section] "With 91 terms a second plateau is reached at about 0.35 and 0.77 cm-1 for train and test points, respectively. There is no advantage of going beyond 91 terms."
  - [section] "We therefore study the possibility of discarding some of them based on their variance."
  - [corpus] Weak evidence - related papers discuss pruning in neural networks but don't specifically address variance-based pruning in HDMR-GPR models.
- **Break condition**: If important component functions have low variance due to the specific distribution of training data, pruning based on variance could remove crucial terms.

## Architecture Onboarding

- **Component map**: Input coordinates -> Redundant coordinate generator -> HDMR-GPR component function calculator -> Neuron activation functions -> Output layer (linear combination)

- **Critical path**:
  1. Define redundant coordinates based on original coordinates
  2. Set up additive GPR with appropriate kernel function
  3. Compute component functions for each redundant coordinate
  4. Use component functions as activation functions in neural network
  5. Linearly combine neuron outputs to get final prediction

- **Design tradeoffs**:
  - Number of redundant coordinates vs. model complexity: More redundant coordinates increase expressive power but also increase computational cost
  - Kernel choice in GPR: Different kernels (e.g., squared exponential vs. Matern) affect the smoothness and flexibility of activation functions
  - Variance threshold for pruning: Higher thresholds lead to simpler models but risk losing important information

- **Failure signatures**:
  - Poor test set performance despite good training performance: Indicates overfitting, possibly due to too many redundant coordinates or insufficient regularization in GPR
  - Unstable results across different runs: Suggests sensitivity to initialization or data sampling, which could be mitigated by using more training data or ensemble methods
  - Component functions with unrealistic shapes: May indicate issues with the GPR setup, such as inappropriate kernel choice or hyperparameter values

- **First 3 experiments**:
  1. Reproduce the H2O potential energy surface fitting results using the provided dataset and compare with conventional neural networks
  2. Vary the number of redundant coordinates and observe the effect on model accuracy and complexity
  3. Test different kernel functions in the GPR component and evaluate their impact on the quality of activation functions and overall model performance

## Limitations
- Reliance on smooth activation functions may limit applicability to problems requiring discontinuous or highly non-smooth mappings
- Computational complexity scales poorly with input dimensionality due to combinatorial explosion of redundant coordinates
- Variance-based pruning effectiveness may not generalize well to datasets with different statistical properties
