# A Parameter-free Adaptive Resonance Theory-based Topological Clustering Algorithm Capable of Continual Learning

## Quick Facts
- **arXiv ID:** 2305.01507
- **Source URL:** https://arxiv.org/abs/2305.01507
- **Reference count:** 40

## Executive Summary
This paper introduces CAE (Correntropy-Induced Metric-based Adaptive Resonance Theory), a novel parameter-free clustering algorithm that addresses the plasticity-stability dilemma in continual learning. The algorithm automatically estimates similarity and edge deletion thresholds using a DPP-based criterion incorporating Correntropy-Induced Metric (CIM) and age-based estimation methods. Experimental results demonstrate that CAE achieves superior clustering performance compared to existing algorithms while eliminating the need for parameter tuning.

## Method Summary
CAE builds upon Adaptive Resonance Theory (ART) by introducing automatic threshold estimation mechanisms. The core innovation lies in using DPP (Determinantal Point Process) to estimate both the similarity threshold and edge deletion threshold. The algorithm employs Correntropy-Induced Metric (CIM) to measure distances between data points, which provides robustness to outliers and noise. The age-based estimation method helps maintain stability during the learning process while allowing for plasticity when new patterns emerge. This combination enables the algorithm to perform continual learning without requiring pre-specified parameters.

## Key Results
- Superior clustering performance with NMI scores ranging from 0.907 to 0.998 across tested datasets
- High Adjusted Rand Index (ARI) scores between 0.868 and 0.999
- Outperforms state-of-the-art clustering algorithms without requiring parameter tuning
- Demonstrates effective continual learning capabilities on both synthetic and real-world datasets

## Why This Works (Mechanism)
The algorithm's success stems from its ability to dynamically adapt to data distributions through automatic threshold estimation. By using CIM, it can handle non-Gaussian noise and outliers effectively, while the DPP-based estimation ensures optimal threshold selection for each specific dataset. The age-based mechanism maintains stability by preventing premature cluster formation while allowing new patterns to be incorporated when significant.

## Architecture Onboarding

**Component Map:**
Data Input -> CIM Distance Calculation -> DPP-based Threshold Estimation -> Age-based Cluster Management -> Cluster Output

**Critical Path:**
The critical path involves computing CIM distances between new data points and existing clusters, followed by DPP-based threshold estimation to determine cluster assignment or creation. The age-based management system then updates cluster parameters accordingly.

**Design Tradeoffs:**
The algorithm trades computational complexity for parameter-free operation. While DPP-based estimation is computationally intensive, it eliminates the need for manual parameter tuning, making the system more robust across different datasets.

**Failure Signatures:**
The algorithm may struggle with extremely high-dimensional data due to CIM distance calculations, and performance could degrade with highly imbalanced datasets where age-based mechanisms might favor older clusters.
