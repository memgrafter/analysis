# InfoPrompt: Information-Theoretic Soft Prompt Tuning for Natural Language Understanding
## Quick Facts
- arXiv ID: 2306.04933
- Source URL: https://arxiv.org/abs/2306.04933
- Reference count: 25
- Primary result: Information-theoretic framework for soft prompt tuning using mutual information maximization

## Executive Summary
InfoPrompt introduces an information-theoretic approach to soft prompt tuning that addresses two key limitations: sensitivity to initialization and insufficient capture of task-relevant information. The framework formulates prompt tuning as maximizing mutual information between prompts and other model parameters or encoded representations. By developing novel mutual information-based loss functions, InfoPrompt aims to discover proper prompt initialization while encouraging the pretrained language model to be more aware of task-relevant information captured in the learned prompt.

## Method Summary
InfoPrompt formulates soft prompt tuning as a mutual information maximization problem, developing two novel loss functions: a head loss for proper prompt initialization and a representation loss to enhance task-relevant information capture. The framework leverages gradient descent algorithms with theoretical guarantees for optimizing these mutual information objectives. This information-theoretic approach aims to overcome traditional prompt tuning limitations without requiring prior knowledge.

## Key Results
- Significantly accelerates convergence compared to traditional prompt tuning methods
- Outperforms traditional prompt tuning without requiring prior knowledge
- Shows effectiveness across 6 tasks and 3 datasets through extensive experiments

## Why This Works (Mechanism)
The framework works by maximizing mutual information between prompt tokens and both the model parameters and encoded representations. This information-theoretic approach ensures that learned prompts contain task-relevant information while being properly initialized. The dual-loss structure (head loss and representation loss) creates a feedback loop that improves both prompt quality and model awareness of task-specific patterns.
