# Fantastic Rewards and How to Tame Them: A Case Study on Reward Learning for Task-oriented Dialogue Systems

## Quick Facts
- **arXiv ID**: 2302.10342
- **Source URL**: https://arxiv.org/abs/2302.10342
- **Reference count**: 40
- **Primary result**: Introduced RewardNet and RewardMLE objectives for learning reward functions from preference-based orderings, achieving competitive results on MultiWOZ 2.0 with improvements in task completion and response quality.

## Executive Summary
This paper addresses the challenge of learning effective reward functions for training end-to-end task-oriented dialogue systems. The authors propose two generalized learning-to-rank inspired objectives (RewardNet and RewardMLE) that learn dense rewards from preference-based orderings among dialogue trajectories, moving beyond traditional sparse rewards. These learned rewards are then used to guide policy gradient training with a Gumbel-softmax trick for variance reduction. Experiments on MultiWOZ 2.0 demonstrate that this approach achieves competitive performance, outperforming existing methods on both task completion and response quality metrics.

## Method Summary
The method involves learning a reward function using either RewardNet (listwise cross-entropy loss) or RewardMLE (Plackett-Luce model) objectives, which are inspired by learning-to-rank literature and take multiple dialogue trajectories per update to capture richer preference information. This learned reward function is then used to guide the training of an end-to-end dialogue agent via policy gradient methods, specifically REINFORCE with the Gumbel-softmax trick for variance reduction. The response generation model is based on MinTL with BART-large, trained jointly with a supervised DST loss and the policy gradient loss weighted by a hyperparameter α.

## Key Results
- The proposed methods achieve competitive results on MultiWOZ 2.0, outperforming existing approaches on both task completion and response quality metrics.
- RewardNet and RewardMLE provide richer learning signals than pairwise preference learning by considering multiple trajectories per update.
- Gumbel-softmax trick enables stable training of end-to-end dialogue agents with large action spaces by reducing variance in policy gradient estimates.

## Why This Works (Mechanism)

### Mechanism 1
Learning a dense reward function that explains pairwise preference orderings among dialogue trajectories improves RL training stability and final performance compared to sparse rewards. The reward network is trained using a learning-to-rank objective (RewardNet or RewardMLE) on multiple dialogue trajectories per update, providing richer, more informative reward signals per step than a binary success/failure reward. The learned reward function guides both reward estimation and response generation, stabilizing policy gradient updates. Core assumption: Preference orderings among sampled trajectories are meaningful and consistent with the evaluation metric, and the reward network can approximate these preferences well enough to improve downstream RL training.

### Mechanism 2
Using Gumbel-softmax trick to estimate policy gradients reduces variance compared to standard REINFORCE, enabling stable training of end-to-end dialogue agents with large action spaces. Gumbel-softmax provides a low-variance, differentiable approximation to sampling from the categorical action distribution, enabling more stable policy gradient updates, especially when the action space (vocabulary) is large. Core assumption: The variance reduction from Gumbel-softmax is significant enough to overcome the high variance inherent in REINFORCE for large action spaces.

### Mechanism 3
Using multiple trajectories per update in the reward learning objective (RewardNet/MLE) is more effective than pairwise preference learning, as it considers more information and is more robust to scoring inaccuracies. RewardNet uses a listwise cross-entropy loss, and RewardMLE uses a Plackett-Luce model, both considering the relative rankings of multiple trajectories simultaneously. This provides a richer learning signal than pairwise comparisons. Core assumption: The additional information from multiple trajectories per update leads to a better approximation of the true preference orderings and a more accurate reward function.

## Architecture Onboarding

- **Component map**: Belief state, system response, goal -> Reward Network (BART-base + MLP) -> Reward score [0,1] -> Policy Gradient Method (REINFORCE + Gumbel-softmax) -> Response Generation Model (MinTL/BART-large)

- **Critical path**: Reward network is trained first using the learning-to-rank objectives on sampled trajectories. The learned reward function is then used to guide the training of the response generation model via policy gradients and weighted regularization.

- **Design tradeoffs**: Using a transformer encoder for the reward network provides strong representation learning but increases model size and training time compared to simpler architectures. Using the full system response as the action space enables rich, natural language generation but makes the RL problem more challenging than using abstract dialogue acts. RewardNet and RewardMLE provide richer learning signals than pairwise preference learning but may be more computationally expensive.

- **Failure signatures**: If the learned reward does not correlate with the evaluation metric or is too noisy, the response generation model will not improve. If the policy gradient updates are too unstable (high variance), the model may diverge or fail to learn. The performance may be sensitive to the number of trajectories used in reward learning, the probabilistic transform function, and the coefficient α in the generation loss.

  2. Check the variance of policy gradient estimates with and without Gumbel-softmax on a small validation set.
  3. Ablate the number of trajectories used in reward learning (e.g., 2, 3, 5) and measure the impact on final performance.

## Limitations
- The evaluation focuses on a single dataset (MultiWOZ 2.0) with a specific metric suite, limiting generalizability.
- The paper reports results averaged over 5 random seeds but does not provide variance estimates or detailed sensitivity analysis to hyperparameters.
- The learned reward function is evaluated only indirectly through its impact on downstream policy training, not through direct correlation with human preferences.
- The choice of automatic evaluation metrics as proxy for human preference may not fully capture response quality dimensions like naturalness or appropriateness.
