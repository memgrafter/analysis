# Masakhane-Afrisenti at SemEval-2023 Task 12: Sentiment Analysis using Afro-centric Language Models and Adapters for Low-resource African Languages

## Quick Facts
- arXiv ID: 2304.06459
- Source URL: https://arxiv.org/abs/2304.06459
- Reference count: 4
- This work explored pre-trained Afro-centric language models and adapters for sentiment analysis across 12 African languages.

## Executive Summary
This paper presents the Masakhane-Afrisenti system for the SemEval-2023 Task 12 on sentiment analysis for 12 African languages. The team explored three main approaches: classical machine learning classifiers, pre-trained Afro-centric and multilingual language models, and adapters for zero-shot transfer. The experiments showed that Afro-centric language models generally outperformed multilingual models for low-resource African languages in monolingual settings, while adapters demonstrated effectiveness for zero-shot classification in related languages. Ensemble methods combining multiple models improved performance for certain languages like Nigerian Pidgin.

## Method Summary
The system utilized three main approaches: classical ML classifiers (SVM, Logistic Regression, XGBoost), pre-trained language models (Afro-centric models like Afro-XLMR and AfriBERTa, multilingual models like LaBSE and mBERT, and language-specific models for Arabic dialects), and adapters for zero-shot transfer. For monolingual tasks, various models were fine-tuned on task-specific data. For zero-shot tasks, monolingual texts in target languages were used to train adapters, which were then fine-tuned on related language data. Ensemble methods combining multiple models were also employed. Models were trained for 10 epochs and the best epoch was selected based on validation F1 score.

## Key Results
- Afro-centric language models (Afro-XLMR, AfriBERTa) outperformed multilingual models for most low-resource African languages in monolingual sentiment classification
- Adapters demonstrated effectiveness for zero-shot sentiment classification in related languages with limited resources
- Ensemble methods combining multiple models improved performance for certain languages like Nigerian Pidgin
- Language-specific models (Bernice, UBARabic) performed better than Afro-centric models for certain Arabic dialects

- Component map:
  - Pre-trained language models (Afro-centric, language-specific, multilingual)
  - Adapters for efficient fine-tuning
  - Ensemble methods for combining model predictions
  - Data preprocessing (cleaning, balancing)
  - Evaluation metrics (weighted F1 score)

- Critical path:
  1. Preprocess data (cleaning, balancing)
  2. Fine-tune pre-trained models on task-specific data
  3. Train adapters for zero-shot tasks
  4. Combine model predictions using ensemble methods
  5. Evaluate performance using weighted F1 score

- Design tradeoffs:
  - Using Afro-centric models vs. multilingual models: Afro-centric models may perform better for low-resource African languages but have limited availability and may not cover all languages.
  - Using adapters vs. full fine-tuning: Adapters are more parameter-efficient but may not capture all task-specific features compared to full fine-tuning.
  - Using ensemble methods: Can improve performance but may increase complexity and computational cost.

- Failure signatures:
  - Poor performance on low-resource languages: May indicate that the pre-trained models do not capture the necessary linguistic features or that the fine-tuning process is not effective.
  - Overfitting on limited data: May indicate that the models are too complex or that the data is not representative of the target language.
  - Inconsistent predictions across models: May indicate that the models are not well-calibrated or that the ensemble method is not effectively combining their predictions.

- First 3 experiments:
  1. Fine-tune Afro-XLMR on a low-resource African language sentiment dataset and evaluate performance.
  2. Train adapters for zero-shot sentiment classification in a related language and compare performance to full fine-tuning.
  3. Combine predictions from multiple fine-tuned models using a voting-based ensemble and evaluate the impact on performance.

## Limitations

- Evaluation methodology relied solely on weighted F1-score, which may not capture all aspects of sentiment classification performance, particularly class imbalance effects.
- Test sets were relatively small for several languages (e.g., Xitsonga, Yoruba, Twi), limiting the statistical significance of findings.
- The linguistic similarity between language pairs used for zero-shot transfer was not quantitatively measured or validated.

## Confidence

- High Confidence: The observation that Afro-centric models generally outperform multilingual models for low-resource African languages in monolingual settings is well-supported by experimental results across multiple languages.
- Medium Confidence: The effectiveness of adapters for zero-shot sentiment classification in related languages is demonstrated, though the specific choice of related languages for adapter training was somewhat heuristic.
- Medium Confidence: The ensemble approach showing improved performance for Nigerian Pidgin is based on limited experimental evidence and would benefit from more systematic evaluation.

## Next Checks

1. Conduct a more rigorous linguistic similarity analysis between language pairs used for zero-shot transfer to establish quantitative justification for adapter selection choices.

2. Perform statistical significance testing across multiple runs with different random seeds to validate that observed performance differences are not due to chance, particularly for languages with small test sets.

3. Expand evaluation to include additional metrics beyond weighted F1-score (such as precision-recall curves and per-class F1 scores) to better understand model behavior across different sentiment categories and potential class imbalance effects.
