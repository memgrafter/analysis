# Analysis of Interpolating Regression Models and the Double Descent Phenomenon

## Quick Facts
- arXiv ID: 2304.08113
- Source URL: https://arxiv.org/abs/2304.08113
- Reference count: 10
- Primary result: Explains double descent phenomenon in interpolating regression models through smallest singular value analysis

## Executive Summary
This paper analyzes interpolating regression models and explains the double descent phenomenon, where test error first decreases then increases to a peak at the interpolation threshold (number of parameters equals number of training samples) before decreasing again as model complexity increases. The analysis focuses on minimum norm solutions to least-squares problems and ridge regression, demonstrating that the smallest singular value of the regression matrix controls the peak location and double descent shape of test error. Through theoretical analysis and numerical examples using complex exponential basis functions, the paper shows how model structure and ordering affect the double descent behavior.

## Method Summary
The method involves analyzing minimum norm solutions to least-squares problems and ridge regression for interpolating models. The approach uses singular value decomposition (SVD) of the regression matrix to study how the smallest singular value changes as model order varies from underparameterized to overparameterized regimes. Numerical examples employ complex exponential basis functions with two different orderings (linear and optimal) to demonstrate theoretical predictions about double descent behavior. The analysis decomposes prediction error into bias and variance components, showing how the variance scales inversely with the square of the smallest singular value.

## Key Results
- The smallest singular value of the regression matrix controls the peak location and double descent shape of test error
- For n < N (underparameterized), increasing model order decreases the smallest singular value, increasing variance
- For n ≥ N (overparameterized), increasing model order increases the smallest singular value, decreasing variance
- Model structures with larger minimum singular values achieve better performance
- Overparameterization can be beneficial when true parameters are close to the row space of the regression matrix

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The smallest singular value of the regression matrix controls the location and shape of the double descent peak.
- Mechanism: As model order increases from underparameterized to overparameterized, the smallest singular value first decreases then increases, creating a minimum at n=N (interpolation threshold). Since variance scales as 1/σ²ᵣ, this creates a peak in test error at n=N.
- Core assumption: The variance contribution dominates the total error at the peak.
- Evidence anchors: Abstract statement about smallest singular value controlling peak location; section 3.4 analysis of singular value behavior with model order changes.

### Mechanism 2
- Claim: Overparameterization can be beneficial when the true parameters are close to the row space of the regression matrix.
- Mechanism: When n>N, the smallest singular value σᵣ doesn't decrease further (or may increase). If the true parameter vector θ₀ is close to the row space of Φ, the bias contribution becomes small, and the reduced variance from larger σᵣ leads to better generalization.
- Core assumption: The true parameter vector lies close to the row space of the regression matrix.
- Evidence anchors: Section 3.5 discussion of overparameterized models; section 3.4 showing singular value increase for n≥N.

### Mechanism 3
- Claim: The ordering of basis functions affects the double descent behavior through the singular value distribution.
- Mechanism: Different orderings of the same basis functions lead to different singular value distributions. An "optimal ordering" can achieve equal singular values (variance-optimal), while a "linear ordering" can lead to a near-singular matrix at n=N, amplifying the double descent effect.
- Core assumption: The ordering of basis functions affects the singular value distribution of the regression matrix.
- Evidence anchors: Section 4 defining frequency sets for linear and optimal orderings; section 3.1 discussion of variance-optimal basis selection.

## Architecture Onboarding

- Component map: Regression matrix Φ -> SVD decomposition -> Minimum norm solution θ = Φ⁺y -> Bias-variance decomposition -> Test error analysis
- Critical path: 1) Construct the regression matrix Φ from basis functions and training data, 2) Compute SVD of Φ, 3) Analyze smallest singular value behavior as model order changes, 4) Derive bias-variance decomposition of prediction error, 5) Use results to explain double descent phenomenon
- Design tradeoffs: Minimum norm solution ensures interpolation but can lead to high variance when smallest singular value is small; regularization reduces variance but introduces bias; basis function ordering affects singular value distribution and double descent behavior
- Failure signatures: If smallest singular value doesn't follow predicted monotonic behavior; if bias contribution dominates over variance at peak; if true parameters are orthogonal to row space of Φ
- First 3 experiments:
  1. Generate synthetic dataset with known underlying function and fit interpolating models of varying complexity; plot test error vs model order to observe double descent shape
  2. Compute smallest singular value of regression matrix for each model order; plot alongside test error to verify minimum at interpolation threshold
  3. Try different orderings of same basis functions; observe how double descent behavior changes; verify optimal ordering leads to more equal singular values and less pronounced double descent

## Open Questions the Paper Calls Out

- How does the minimum singular value behavior change when using non-linear parametrizations or kernel-based methods?
- What is the exact relationship between peak height in double descent and distribution of singular values in regression matrix?
- How does double descent phenomenon extend to time-series data with temporal correlations?
- Can we develop model structure selection criteria that optimize for smallest singular value to avoid double descent peaks?

## Limitations
- Analysis relies heavily on properties of minimum singular value, which may not generalize to all model architectures
- Theoretical framework assumes specific data distributions and basis function structures that may not capture real-world scenarios
- Beneficial effects of overparameterization depend critically on true parameter vector being close to row space of regression matrix
- Numerical experiments limited to specific complex exponential basis functions and relatively small-scale problems

## Confidence
- High confidence: General relationship between smallest singular value and variance at interpolation threshold
- Medium confidence: Specific conditions under which overparameterization provides benefits (proximity to row space)
- Low confidence: Generality of findings to non-linear models and real-world datasets beyond synthetic examples

## Next Checks
1. Cross-validation with alternative basis functions: Test double descent behavior using different basis function families (polynomial, Fourier, wavelet) to assess robustness beyond complex exponentials

2. Row space proximity validation: Design experiments to explicitly measure angle between true parameters and row space of Φ across different model orders to verify theoretical conditions for beneficial overparameterization

3. Noise sensitivity analysis: Systematically vary noise levels in data generating process to determine how noise-to-signal ratio affects double descent peak height and transition from under- to overparameterized regimes
