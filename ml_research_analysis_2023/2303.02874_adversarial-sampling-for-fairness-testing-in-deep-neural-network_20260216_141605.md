# Adversarial Sampling for Fairness Testing in Deep Neural Network

## Quick Facts
- arXiv ID: 2303.02874
- Source URL: https://arxiv.org/abs/2303.02874
- Reference count: 40
- One-line primary result: Achieved 93.3% accuracy and consistent fairness across all ten CIFAR-10 classes using adversarial sampling and a filter layer.

## Executive Summary
This research introduces a novel method for testing fairness in deep neural network classifiers using adversarial sampling. The approach trains the model only on clean CIFAR-10 images and then tests fairness by generating adversarial samples for each class. A key innovation is the use of a standalone filter layer to remove adversarial noise before classification, allowing the model to predict the original class without retraining. The method successfully demonstrated consistent accuracy and fairness across all ten CIFAR-10 categories.

## Method Summary
The study trained a CNN on CIFAR-10 original images without exposure to adversarial examples. Adversarial samples were generated per class using standard attack methods. A filter layer was implemented to denoise these samples before classification. The model's misclassification rates across all classes were analyzed to assess fairness, with the goal of achieving both high accuracy (93.3%) and consistency across classes.

## Key Results
- Achieved 93.3% accuracy on CIFAR-10 using only clean training data
- Demonstrated consistent fairness across all ten image classes
- Successfully predicted original categories from adversarial samples using a filter layer

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Adversarial sampling exposes group-level fairness disparities in DNN classifiers.
- Mechanism: Generates adversarial examples per class and measures misclassification rates to detect disproportionate errors.
- Core assumption: Fairness is measurable via consistency of misclassification rates across all classes.
- Evidence anchors:
  - [abstract] "When we feed the adversarial samplings to our model, it was able to predict the original category/class of the image the adversarial sample belongs to."
  - [section] "there is unfairness as some of classes have high rate of positive misclassification than the others."
- Break condition: If model architecture inherently biases certain classes, uniform adversarial attacks may not reveal this.

### Mechanism 2
- Claim: A dedicated filter layer can remove adversarial perturbations while preserving class identity.
- Mechanism: The filter applies noise removal before the DNN processes the image.
- Core assumption: Perturbations can be separated from original features without destroying discriminative information.
- Evidence anchors:
  - [abstract] "We also introduced and used the separation of concern concept... we were able to have accuracy of 93.3%."
  - [section] "remove as much perturbation and denoise as possible while creating a new folder dogsa-clean to store all the new images."
- Break condition: If perturbations are designed to be imperceptible to humans but highly disruptive, the filter may fail without losing key features.

### Mechanism 3
- Claim: Training only on clean data and testing on adversarial data allows fairness testing without bias from adversarial training.
- Mechanism: DNN trained on original CIFAR-10 images only; adversarial examples used solely for testing fairness.
- Core assumption: Performance on adversarial examples reflects fairness rather than robustness.
- Evidence anchors:
  - [abstract] "We trained our neural network model on the original image, and without training our model on the perturbed or attacked image."
  - [section] "Rather than the existing method of training the model on the adversarial sample and label them as invalid."
- Break condition: If decision boundaries are highly nonlinear, adversarial examples may exploit regions not represented in clean training data.

## Architecture Onboarding

- Component map:
  Data loader -> CIFAR-10 original images
  CNN model -> Trained on clean data only
  Adversarial generator -> Produces perturbed versions per attack method
  Filter layer -> Removes noise from adversarial samples
  Evaluation module -> Computes misclassification rates per class

- Critical path:
  1. Train CNN on clean CIFAR-10 data.
  2. Generate adversarial samples per class using FGSM, PGD, C&W, etc.
  3. Pass adversarial samples through filter layer.
  4. Classify filtered images with CNN.
  5. Compare misclassification rates across classes.

- Design tradeoffs:
  - Using only clean data for training avoids adversarial bias but may underestimate robustness.
  - The filter layer must balance noise removal with feature preservation.
  - Testing fairness via misclassification rates is simple but may miss subtle bias patterns.

- Failure signatures:
  - High variance in misclassification rates across classes indicates fairness issues.
  - Drop in accuracy after filtering suggests the filter is too aggressive.
  - Consistent misclassification of a specific class may indicate dataset imbalance or model bias.

- First 3 experiments:
  1. Train the CNN on CIFAR-10 and verify baseline accuracy (~93.3%).
  2. Generate adversarial samples for each class and measure misclassification rates.
  3. Apply the filter layer and re-evaluate accuracy and fairness consistency.

## Limitations
- The filter layer's exact implementation is not fully specified, making it difficult to reproduce the noise removal mechanism.
- No quantitative analysis of fairness metrics (e.g., demographic parity, equal opportunity) is provided; misclassification rates alone may not capture all fairness dimensions.
- The adversarial attack strength and diversity across classes are not clearly described, which could affect fairness detection reliability.

## Confidence
- **High confidence**: The core idea that adversarial sampling can expose group-level fairness disparities in DNN classifiers.
- **Medium confidence**: The claim that a standalone filter layer can remove adversarial perturbations while preserving class identity.
- **Low confidence**: The assertion that training only on clean data and testing on adversarial data provides a complete fairness assessment.
