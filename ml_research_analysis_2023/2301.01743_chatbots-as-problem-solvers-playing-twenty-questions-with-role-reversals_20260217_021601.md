# Chatbots as Problem Solvers: Playing Twenty Questions with Role Reversals
## Quick Facts
- arXiv ID: 2301.01743
- Source URL: https://arxiv.org/abs/2301.01743
- Reference count: 39
- Primary result: ChatGPT achieved 94% correct guess rate with 12 average questions in multi-role twenty questions experiments

## Executive Summary
This study demonstrates ChatGPT's capability to play twenty questions across multiple roles including object guessing, question answering, and bilingual exchanges. The research systematically explores 16 experimental setups testing ChatGPT's reasoning abilities in standard gameplay, role reversals, emotional state deduction, and abstract concept handling. The model consistently achieved high performance with a 94% correct guess rate while maintaining efficient gameplay requiring only 12 questions on average.

## Method Summary
The researchers designed 16 experimental setups to test ChatGPT's twenty questions capabilities across different roles and conditions. Experiments included standard gameplay where ChatGPT guessed objects, reversed roles where it answered questions, bilingual exchanges, and emotional state deduction using crowd-sourced emotion datasets. The study systematically varied object complexity from concrete items to abstract concepts and recipes, measuring performance through correct guess rates and average question counts.

## Key Results
- ChatGPT achieved 94% correct guess rate across all experimental setups
- Average of 12 questions required per game
- Successfully handled abstract concepts, recipe variations, and emotional contexts
- Demonstrated adaptability in role reversals and bilingual gameplay

## Why This Works (Mechanism)
ChatGPT's transformer architecture enables multi-step reasoning through attention mechanisms that track question-answer relationships across conversational turns. The model's training on diverse web data provides broad knowledge coverage for object recognition and contextual understanding. The self-attention mechanism allows maintaining conversation state while dynamically adjusting questioning strategies based on accumulated information.

## Limitations
- Results based on single language model without comparative analysis
- Emotional state experiments rely on crowd-sourced datasets with uncharacterized quality
- Limited control over object complexity and question difficulty variations
- Performance metrics assume standard game rules without systematic complexity variation

- **Low**: Proposed diagnostic and educational applications without real-world validation
