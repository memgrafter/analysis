# Learning Optimal Fair Scoring Systems for Multi-Class Classification

## Quick Facts
- arXiv ID: 2304.05023
- Source URL: https://arxiv.org/abs/2304.05023
- Authors: Multiple authors
- Reference count: 34
- Primary result: Proposes FAIRScoringSystems framework for fair and interpretable multi-class classification using mixed-integer linear programming

## Executive Summary
This paper introduces FAIRScoringSystems, a framework that extends the SLIM scoring system methodology to multi-class classification while incorporating fairness constraints. The approach uses mixed-integer linear programming to generate interpretable models that balance accuracy, sparsity, and fairness. By formulating the problem as an optimization task with fairness constraints, the method produces scoring systems that can control statistical parity violations while maintaining competitive classification performance.

## Method Summary
FAIRScoringSystems builds upon the SLIM framework by extending it to handle multi-class problems through a one-vs-rest approach. The method formulates the classification task as a mixed-integer linear program that simultaneously optimizes for accuracy and fairness while controlling model sparsity. Fairness is enforced through statistical parity constraints that limit the difference in positive classification rates across protected groups. The optimization finds scoring systems where features are assigned integer weights and thresholds, resulting in interpretable decision rules that can be expressed as simple score-based classifications.

## Key Results
- Successfully reduces statistical parity violations compared to standard SVM classifiers
- Achieves competitive classification performance while maintaining controlled sparsity
- Demonstrates effective accuracy-fairness trade-offs through tunable fairness tolerance parameters
- Shows improved fairness metrics on both synthetic and real-world datasets

## Why This Works (Mechanism)
The method works by explicitly encoding fairness constraints into the optimization objective, forcing the model to consider both accuracy and fairness during training rather than as a post-processing step. The mixed-integer linear programming formulation allows precise control over model complexity through sparsity constraints while ensuring that the resulting scoring systems satisfy fairness requirements across all classes. The one-vs-rest approach for multi-class problems enables the extension of binary fairness constraints to the multi-class setting.

## Foundational Learning
- Mixed-Integer Linear Programming (MILP): Required for formulating the optimization problem with both continuous and discrete decision variables. Quick check: Verify solver capabilities for large-scale MILP problems.
- Statistical Parity: Fundamental fairness metric measuring equal positive classification rates across groups. Quick check: Compute statistical parity difference on validation sets.
- Scoring Systems: Interpretable models using weighted feature sums and thresholds. Quick check: Ensure final model can be expressed as simple scoring rules.

## Architecture Onboarding
**Component Map:** Data Preprocessing -> MILP Formulation -> Optimization Solver -> Scoring System Generation -> Fairness Evaluation

**Critical Path:** The optimization solver represents the critical path, as solution quality and runtime directly impact model development. The MILP formulation must be carefully constructed to balance constraint tightness with solver tractability.

**Design Tradeoffs:** Accuracy vs. fairness vs. sparsity represents the primary design tension. Tighter fairness constraints typically require more features (less sparsity) or result in lower accuracy. The regularization parameter controls this balance.

**Failure Signatures:** Poor scalability with dataset size, inability to find feasible solutions when fairness constraints are too tight, and suboptimal solutions when the MILP relaxation is too loose.

**First Experiments:**
1. Run baseline SVM classifier on synthetic dataset to establish performance reference
2. Solve MILP with only accuracy objective (no fairness constraints) to verify optimization works
3. Incrementally tighten fairness constraints while monitoring solver status and solution quality
