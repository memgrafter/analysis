# Efficient Shapley Values Estimation by Amortization for Text Classification

## Quick Facts
- arXiv ID: 2305.19998
- Source URL: https://arxiv.org/abs/2305.19998
- Reference count: 25
- Key outcome: Proposed amortized model estimates Shapley Values accurately with up to 60× speedup and deterministic stability

## Executive Summary
This paper addresses the computational efficiency and stability challenges in estimating Shapley Values for interpreting neural text classification models. The authors propose an amortized model that directly predicts explanation scores for input features without requiring additional model evaluations. By training on precomputed Shapley Values, the model learns to generalize attribution patterns across instances. Experimental results on Yelp-Polarity and MNLI datasets demonstrate that the amortized model achieves high correlation with reference scores while providing significant computational speedup and stable deterministic inference.

## Method Summary
The paper proposes an amortized model for efficient Shapley Value estimation in text classification. The approach involves precomputing Shapley Values on training data using SVS-25, then training a BERT-based amortized model to directly predict these values from input text. The model uses a linear layer on top of BERT embeddings to output attribution scores. During inference, the trained model provides deterministic predictions without additional model evaluations, achieving significant speedup compared to traditional sampling-based methods while maintaining stability across runs.

## Key Results
- Achieved Spearman correlation >0.60 on Yelp-Polarity dataset
- Up to 60× speedup compared to traditional Shapley Value estimation methods
- Deterministic inference produces stable explanations across different random seeds
- Local adaptation using amortized model predictions as initialization improves sample efficiency of SVS

## Open Questions the Paper Calls Out

The paper identifies several open questions regarding the generalizability and limitations of the amortized approach. These include exploring different model architectures and training losses to improve approximation quality, investigating the method's performance on diverse text classification tasks beyond sentiment analysis and textual entailment, examining the impact of different reference explanation methods on training, evaluating robustness to out-of-distribution examples and adversarial attacks, and understanding computational requirements when scaling to larger models or longer sequences.

## Limitations

- The method's effectiveness may degrade on datasets with limited shared attribution patterns across instances
- Current evaluation is limited to two text classification datasets, leaving generalization uncertainty
- Trade-off between computational efficiency and approximation accuracy requires more thorough investigation
- Potential overfitting to training data could affect generalization to new instances
