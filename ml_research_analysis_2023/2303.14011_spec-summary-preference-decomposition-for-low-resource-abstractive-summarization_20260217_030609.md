# SPEC: Summary Preference Decomposition for Low-Resource Abstractive Summarization

## Quick Facts
- arXiv ID: 2303.14011
- Source URL: https://arxiv.org/abs/2303.14011
- Reference count: 40
- Primary result: State-of-the-art ROUGE-1/2/L scores on six diverse summarization corpora in low-resource settings

## Executive Summary
SPEC introduces a novel approach for abstractive summarization in low-resource settings by decomposing content and preference during learning through parameter modulation. The method addresses the limitation of previous approaches that learn without separating content from preference, which can constrain generated summaries by training set biases. SPEC uses preference-aware adapters to enable control over preferences during inference and introduces a preference-match decoding method to automatically estimate suitable preferences from few examples. Experimental results demonstrate significant improvements over existing methods on six diverse corpora.

## Method Summary
SPEC combines meta-learning with parameter-efficient adapters to decompose content and preference during training. The method uses preference-aware adapters that modulate parameters based on preference features, allowing separate learning of content and preference. Intra-preference learning uses self-supervised datasets from the target corpus, while inter-preference learning leverages related annotated corpora through meta-learning. A novel preference-match decoding method employs K-Means clustering to estimate representative preferences and generate summary candidates for user selection.

## Key Results
- Achieves state-of-the-art performance on six diverse corpora (Amazon Product Reviews, Reddit-TIFU, Movie Reviews, SAMSum, SciTLDR, XSum)
- Shows significant improvements in ROUGE-1/2/L scores compared to previous methods
- Demonstrates effectiveness in both 10-example and 100-example low-resource settings
- Improves performance by 30.11%/33.95%/27.51% and 26.74%/31.14%/24.48% under 10- and 100-example settings respectively

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Decomposing content and preference during learning allows the model to learn shared knowledge without being constrained by text properties in source corpora.
- Mechanism: Using preference-aware adapters that modulate parameters based on preference features, enabling separate learning of content and preference.
- Core assumption: Preferences contain sufficient information about the required target, and the model can learn to create specific features with the modulated parameters according to the given preference.
- Evidence anchors: Abstract states that previous methods learn without decomposing content and preference, constraining generated summaries by preference bias in training sets. Section describes parameter modulation where adapter parameters are transformed according to preference features.

### Mechanism 2
- Claim: Utilizing both intra- and inter-preference learning allows the model to leverage knowledge from both in-domain and out-domain examples.
- Mechanism: Intra-preference learning uses self-supervised datasets from target corpus as pseudo summaries for in-domain knowledge; inter-preference learning uses meta-learning with related annotated corpora for out-domain knowledge.
- Core assumption: Self-supervised datasets and related annotated corpora provide useful knowledge that can improve the model's performance on the target corpus.
- Evidence anchors: Abstract mentions improving MTL-ABS by addressing unannotated documents from target domain not being explored. Section describes inserting adapters φself and φmeta trained with Dself and Dmeta alternately.

### Mechanism 3
- Claim: The preference-match decoding can automatically generate suitable summary candidates for user selection based on representative preferences estimated from few examples.
- Mechanism: Uses K-Means clustering to find representative preferences from available preferences of target corpus, then generates summary candidates using these representatives.
- Core assumption: The target corpus contains a few representative preferences, and summaries generated given these representatives could be suitable under the data distribution.
- Evidence anchors: Abstract states the method proposes novel decoding to automatically estimate suitable preferences and generate corresponding summary candidates. Section hypothesizes corpus can contain few representative preferences suitable under data distribution.

## Architecture Onboarding
- **Component map**: Input document → BART base model → Adapters (φself, φmeta) → Preference-aware adapters → Generated summary
- **Critical path**: Input document flows through BART base model, adapters, and preference-aware adapters to generate the summary
- **Design tradeoffs**: Main tradeoff between model capacity and available training data; parameter-efficient adapters limit capacity but enable learning without full retraining
- **Failure signatures**: Model not learning to decompose content and preference effectively; preference-match decoding not accurately estimating representative preferences; poor generalization to target corpus
- **First 3 experiments**:
  1. Evaluate performance on small subset of target corpus with different numbers of representative preferences
  2. Compare performance with and without preference decomposition on synthetic dataset with known content and preference biases
  3. Evaluate performance on larger subset of target corpus with different numbers of available preferences and representative preferences

## Limitations
- Evaluation framework limited to only 10 and 100 example settings, providing limited insight into intermediate data scales
- Potential biases introduced by preference metrics (ROUGE, extractive diversity/coverage, novel word ratio, compression ratio) may influence model toward specific summary styles
- Limited empirical evidence showing that model actually learns distinct preference dimensions versus memorizing patterns

## Confidence
- **Medium** for core claim of achieving state-of-the-art performance - ROUGE scores show improvements but evaluation framework has limitations
- **Medium** for mechanism claims - limited empirical evidence that preference decomposition actually learns distinct dimensions
- **Low** for preference-match decoding claims - assumption about K-Means clustering identifying meaningful preferences is stated without empirical verification

## Next Checks
1. **Preference Dimensionality Analysis**: Conduct systematic study varying number of representative preferences (k=1 to 16) with qualitative analysis of whether generated summaries for different preferences differ meaningfully beyond surface-level variations.

2. **Robustness to Preference Noise**: Design experiments where preference labels are partially corrupted or incomplete, then measure how SPEC's performance degrades compared to baseline methods.

3. **Cross-Corpus Generalization**: Test SPEC on corpus where preference distribution significantly differs from meta-training corpora to measure whether intra-preference learning provides sufficient adaptation capability.
