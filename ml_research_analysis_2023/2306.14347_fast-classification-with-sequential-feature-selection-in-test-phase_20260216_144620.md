# Fast Classification with Sequential Feature Selection in Test Phase

## Quick Facts
- arXiv ID: 2306.14347
- Source URL: https://arxiv.org/abs/2306.14347
- Reference count: 14
- Proposes fast sequential feature selection method for classification with zero training time

## Executive Summary
This paper introduces a statistical approach for active feature acquisition in classification tasks that operates exclusively during the test phase. The method uses Fisher scores to rank features and sequentially selects the most informative subset while minimizing acquisition costs. It demonstrates competitive accuracy compared to reinforcement learning methods while achieving significantly faster inference speeds, making it particularly suitable for scenarios with small datasets or frequent model updates.

## Method Summary
The approach performs sequential feature selection during testing by first ranking features using Fisher scores, then filtering the training dataset based on observed feature values. The algorithm iteratively acquires features until reaching acceptable accuracy or budget constraints. A key innovation is that it requires zero training time since feature ranking and selection occur entirely at inference time. The method was evaluated on synthetic CUBE and real Forest datasets, showing substantial speed improvements over existing reinforcement learning approaches while maintaining competitive classification accuracy.

## Key Results
- Achieves 0.0056-0.04 seconds testing time per sample
- Requires zero training time for feature selection
- Competitive accuracy compared to reinforcement learning methods
- Significant speed improvements over RL approaches

## Why This Works (Mechanism)
The method leverages Fisher scores to identify features with high discriminative power between classes. By filtering the training data based on already observed feature values, it creates a more focused search space for subsequent feature selection. The sequential nature allows the algorithm to adaptively choose features based on current prediction confidence and remaining budget, avoiding unnecessary feature acquisitions.

## Architecture Onboarding

**Component Map**: Training Data -> Fisher Score Computation -> Feature Ranking -> Test Sample -> Sequential Feature Selection -> Classification Decision

**Critical Path**: The most time-critical components are Fisher score computation and sequential feature selection during testing. These directly impact the 0.0056-0.04 seconds per sample timing claim.

**Design Tradeoffs**: Zero training time is achieved by computing feature rankings at test time, trading off some computational overhead during inference for flexibility. This design choice makes the method suitable for frequent model updates but may increase per-sample latency.

**Failure Signatures**: Performance degradation occurs when Fisher scores poorly discriminate between classes, when budget constraints are too restrictive, or when feature dependencies are ignored in the ranking process.

## Limitations
- Evaluation limited to only two datasets (CUBE and Forest), restricting generalizability
- Comparison framework excludes traditional feature selection methods and other active learning approaches
- Training time claims ambiguous since Fisher score computation requires processing training data
- Timing metrics lack hardware specifications and experimental conditions
