# Simultaneous prediction of hand gestures, handedness, and hand keypoints using thermal images

## Quick Facts
- arXiv ID: 2303.01547
- Source URL: https://arxiv.org/abs/2303.01547
- Reference count: 31
- Multi-task deep learning architecture achieves over 98% accuracy for gesture classification, handedness detection, and fingertip localization, and over 91% accuracy for wrist points localization using thermal images.

## Executive Summary
This paper introduces a novel multi-task deep learning architecture for simultaneous hand gesture classification, handedness detection, and hand keypoints localization using thermal images. The proposed method leverages a shared encoder-decoder structure followed by three specialized branches to address these tasks. The approach was validated on a custom dataset of 24 users performing 10 gestures, achieving high accuracy across all tasks. Additionally, the method was tested on external datasets, outperforming existing state-of-the-art techniques in terms of accuracy and computational efficiency.

## Method Summary
The method uses a multi-task deep learning architecture with shared encoder-decoder layers followed by three specialized branches for gesture classification, handedness detection, and hand keypoints localization. The network takes 100×100 thermal images as input and outputs gesture labels, handedness probabilities, and 2D keypoint coordinates. Training uses a joint loss function combining categorical cross-entropy for gesture classification, binary cross-entropy for handedness detection, and mean squared error for keypoint localization. The model was trained using stochastic gradient descent with empirically determined loss weights (α=0.77, β=0.15, γ=0.08).

## Key Results
- Achieved over 98% accuracy for gesture classification, handedness detection, and fingertip localization
- Achieved more than 91% accuracy for wrist points localization
- Outperformed existing state-of-the-art techniques on external datasets in both accuracy and computational efficiency
- Demonstrated robustness to lighting variations and skin color differences compared to RGB-based approaches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The shared encoder-decoder architecture allows simultaneous learning of correlated tasks, improving overall model performance.
- Mechanism: The encoder learns shared feature representations across gesture classification, handedness detection, and keypoint localization tasks. The decoder branches then specialize these features for each specific task.
- Core assumption: The three tasks share enough visual features that joint learning provides a regularization effect.
- Evidence anchors: The abstract states "Our method uses a novel deep multi-task learning architecture that includes shared encoder-decoder layers followed by three branches dedicated for each mentioned task."

### Mechanism 2
- Claim: The adaptive filtering technique for fingertip localization improves accuracy by leveraging predictions from other branches.
- Mechanism: Instead of using a fixed threshold for fingertip detection, the method uses predicted gesture and handedness information to determine which channels should contain valid fingertips, then applies geometric constraints based on hand anatomy to reorder misclassified fingers.
- Core assumption: The predicted gesture and handedness information is sufficiently accurate to guide the fingertip localization refinement.
- Evidence anchors: The abstract mentions "Instead of a threshold-based finger point localization, we introduce an adaptive filtering technique that utilizes the insight learned in the other branches of the network."

### Mechanism 3
- Claim: Using thermal images reduces sensitivity to lighting variations and skin color differences compared to RGB approaches.
- Mechanism: Thermal cameras capture heat signatures rather than visible light, making the system robust to illumination changes and skin tone variations that typically affect RGB-based hand detection methods.
- Core assumption: The thermal signatures of hands are sufficiently distinctive from backgrounds across different environmental conditions.
- Evidence anchors: The abstract states "While RGB-data-based methods can suffer from problems such as lighting condition variations and skin color variations that can negatively impact the accuracy of the hand detection method, the thermal-data-based approaches are less affected by those variations."

## Architecture Onboarding

- Component map: Input (100×100 thermal image) -> Shared encoder (4 conv layers, 4 max-pooling) -> Shared decoder (2 up-convolution with skip connections) -> Branch 1 (Gesture: 2 conv → global avg pooling → 2 dense) -> Branch 2 (Handedness: 2 conv → global avg pooling → 1 dense) -> Branch 3 (Keypoints: 4 conv → up-convolution → 2 conv → 50×50×6 output)
- Critical path: Input → Shared encoder → Shared decoder → All three branches simultaneously
- Design tradeoffs:
  - Joint learning improves generalization but adds complexity
  - Fixed input size (100×100) simplifies processing but may lose fine details
  - Multi-task approach uses fewer parameters than three separate models
- Failure signatures:
  - Poor performance on one task while others succeed suggests task interference
  - Inconsistent predictions across branches may indicate shared representation issues
  - High training accuracy but low test accuracy suggests overfitting
- First 3 experiments:
  1. Train with only the shared encoder-decoder (no branches) to verify basic feature extraction works
  2. Train each branch independently to establish baseline performance
  3. Train all branches together with equal loss weights, then adjust weights based on performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the performance of the multi-task network compare to single-task networks when using combined RGB and thermal data inputs?
- Basis in paper: The paper mentions exploring combining different modalities of data in a single DL network pipeline for better performance as a future research direction.
- Why unresolved: The paper only evaluates the proposed method using thermal images and does not investigate the potential benefits of combining thermal and RGB data.
- What evidence would resolve it: Conducting experiments that train and evaluate both single-task and multi-task networks using combined RGB and thermal data, and comparing their performance to the current thermal-only approach.

### Open Question 2
- Question: Can the proposed adaptive filtering technique for fingertip localization be further improved to handle more complex hand gestures or varying hand sizes?
- Basis in paper: The paper introduces an adaptive filtering technique that utilizes insights from other branches of the network for refining hand keypoints localization results.
- Why unresolved: The paper does not explore the limitations of the current adaptive filtering technique or investigate potential improvements for handling more complex scenarios.
- What evidence would resolve it: Testing the adaptive filtering technique on a more diverse dataset with complex gestures and varying hand sizes, and analyzing its performance to identify areas for improvement.

### Open Question 3
- Question: What is the impact of using different loss function weightings (α, β, γ) on the overall performance of the multi-task network?
- Basis in paper: The paper mentions that the parameters α, β, and γ in the loss function were empirically estimated using a grid search method.
- Why unresolved: The paper does not provide a detailed analysis of how different weightings affect the performance of the network or explore the sensitivity of the model to these parameters.
- What evidence would resolve it: Conducting a systematic study that varies the loss function weightings and evaluates their impact on the performance of the multi-task network across different tasks.

### Open Question 4
- Question: How does the proposed method perform in real-world scenarios with varying environmental conditions, such as different lighting or temperature ranges?
- Basis in paper: The paper mentions that the dataset was collected in indoor conditions with a specific temperature range, and future research directions include exploring the method's performance in different conditions.
- Why unresolved: The paper does not evaluate the method's robustness to varying environmental conditions or investigate its performance outside the controlled indoor setting.
- What evidence would resolve it: Testing the proposed method in real-world scenarios with varying lighting conditions and temperature ranges, and comparing its performance to the current indoor results.

## Limitations

- The custom dataset contains only 24 users, which may limit generalizability despite validation on external datasets
- Hand segmentation algorithm details are not fully specified, potentially affecting reproducibility
- Performance on extremely low contrast thermal images is not evaluated

## Confidence

**High Confidence:**
- Multi-task learning architecture effectively handles all three tasks simultaneously
- Thermal imaging provides robustness to lighting and skin color variations
- The proposed method outperforms existing state-of-the-art techniques on external datasets
- Over 98% accuracy for gesture classification, handedness detection, and fingertip localization is achievable

**Medium Confidence:**
- The adaptive filtering technique significantly improves fingertip localization accuracy
- The specific loss function weight configuration (α=0.77, β=0.15, γ=0.08) is optimal
- The 100×100 input resolution provides sufficient detail for all tasks

**Low Confidence:**
- Performance would remain consistent with significantly larger datasets
- The method would maintain accuracy with different thermal camera specifications
- Real-time performance would be acceptable across all tested hardware configurations
