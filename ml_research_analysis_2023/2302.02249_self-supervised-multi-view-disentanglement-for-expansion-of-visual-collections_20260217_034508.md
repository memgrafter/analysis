# Self-supervised Multi-view Disentanglement for Expansion of Visual Collections

## Quick Facts
- arXiv ID: 2302.02249
- Source URL: https://arxiv.org/abs/2302.02249
- Authors: 
- Reference count: 40
- Key outcome: Improved retrieval performance on artistic image collections via self-supervised disentanglement of object, style, and color views

## Executive Summary
This paper introduces a self-supervised method to learn disentangled multi-view representations for images. The approach factors input features into view-specific and view-aligned components, using a reconstruction loss and inter-view orthogonality regularization to encourage disentanglement. These disentangled representations enable inferring the intent of a collection of images as a distribution over views, which is used to rank candidate images for expansion via a weighted similarity metric. The method is evaluated on a dataset of artistic images, showing improved retrieval performance compared to single-view and multi-view baselines. It also enables a novel querying mechanism by composing multiple collections.

## Method Summary
The method extracts pre-trained ResNet-152 (object), ALADIN (style), and LAB histogram (color) features as input views. A three-pathway neural model (view-specific F_p, view-aligned F_a, reconstruction F_r) disentangles these into view-specific representations via a composite loss: alignment (L_align) between input and view-aligned, orthogonalization (L_ortho) between view-specific representations, information transfer (L_transfer) from view-aligned to view-specific, and reconstruction (L_recon) of input from both. For collection expansion, intent weights are computed from collection-level view-specific representations reflecting homogeneity, then candidate images are ranked via weighted similarity using these weights. The model is trained with Adam (lr=0.0001, batch=64) over a hyperparameter sweep.

## Key Results
- Improved retrieval MAP and MRR on BAM artistic image dataset vs single-view and multi-view baselines
- Effective disentanglement demonstrated via reduced inter-view correlations and HSIC metrics
- Novel collection composition querying mechanism enables complex intent capture

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Disentangled view-specific representations enable more accurate intent inference for image collections.
- Mechanism: The model factors input features into view-specific (zp) and view-aligned (za) components. By minimizing inter-view overlap through orthogonalization loss, each view-specific representation captures unique aspects of the image. This allows computing collection-level intent weights that reflect the true homogeneity of images along each view.
- Core assumption: The correlations between views in raw feature spaces obscure the true intent of a collection. By disentangling these correlations, we can more accurately measure intent.
- Evidence anchors:
  - [abstract] "Our method factors input features into view-specific and view-aligned components, using a reconstruction loss and inter-view orthogonality regularization to encourage disentanglement."
  - [section] "We factorize the input into two components - the view-aligned representations contain what is common across the views, and the view-specific representations contain information unique to each view."
  - [corpus] Weak - the corpus neighbors don't directly address disentanglement or intent inference for image collections.
- Break condition: If the orthogonalization loss is too strong, view-specific representations lose too much information and become degenerate (peaked at -1 and 1 similarity values).

### Mechanism 2
- Claim: Weighted similarity using intent weights improves retrieval effectiveness by prioritizing relevant views.
- Mechanism: The intent weights (αm) computed from collection-level view-specific representations determine how much each view contributes to the final similarity score for ranking candidate images. Views with higher intent weights are given more importance.
- Core assumption: The intent weights accurately reflect which views are most relevant for a given collection, and prioritizing these views improves retrieval quality.
- Evidence anchors:
  - [abstract] "These disentangled representations enable inferring the intent of a collection of images as a distribution over views, which is used to rank candidate images for expansion via a weighted similarity metric."
  - [section] "We model this by characterizing the intent as being proportional to the degree of homogeneity of images in the collection along that view."
  - [corpus] Weak - the corpus neighbors focus on different retrieval tasks and don't directly validate weighted similarity using intent weights.
- Break condition: If the intent weights are poorly estimated (e.g., due to insufficient collection purity), the weighted similarity may prioritize irrelevant views and hurt retrieval performance.

### Mechanism 3
- Claim: Composing collections as queries enables novel querying mechanism for image search.
- Mechanism: By combining view representations from multiple collections, a new hypothetical collection representation is created. This composite representation captures selective characteristics from each input collection, enabling retrieval of images matching this complex intent.
- Core assumption: The disentangled view representations from different collections can be meaningfully combined to represent a new, composite intent.
- Evidence anchors:
  - [abstract] "Finally, we present a new querying mechanism for image search enabled by composing multiple collections and perform retrieval under this setting using the techniques presented in this paper."
  - [section] "By picking desired view representations from each collection in the query, we can create a composite representation for a new (hypothetical) collection which can be used as a query for expansion."
  - [corpus] Weak - the corpus neighbors don't discuss composing collections as queries.
- Break condition: If the views are not properly disentangled, combining them may not produce meaningful composite representations.

## Architecture Onboarding

- Component map: Input views (ResNet, ALADIN, LAB) -> Model (F_p, F_a, F_r) -> Disentangled view-specific representations -> Collection-level representation and intent weights -> Weighted similarity ranking

- Critical path:
  1. Extract input view representations for images
  2. Pass through model to obtain disentangled view-specific representations
  3. Compute collection-level representation and intent weights
  4. Use weighted similarity to rank candidate images

- Design tradeoffs:
  - Strength of orthogonalization (λ2): Higher values lead to better disentanglement but risk information loss
  - Choice of input views: The selected views (object, style, color) may not capture all relevant aspects of images
  - Intent inference method: Assumes intent is proportional to collection homogeneity, which may not always hold

- Failure signatures:
  - Degenerate view-specific representations (peaked at -1 and 1 similarity values) indicate too much orthogonalization
  - Poor retrieval performance suggests inaccurate intent weights or suboptimal view selection
  - High reconstruction loss indicates the disentangled representations have lost too much information

- First 3 experiments:
  1. Train the model with varying λ2 values and analyze the effect on inter-view correlation and HSIC metrics
  2. Evaluate intent inference on pure vs impure collections to validate the method
  3. Compare retrieval performance using input representations, input-output combination, and output-output combination
