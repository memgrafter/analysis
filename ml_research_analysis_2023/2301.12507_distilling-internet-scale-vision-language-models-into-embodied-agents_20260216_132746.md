# Distilling Internet-Scale Vision-Language Models into Embodied Agents

## Quick Facts
- **arXiv ID:** 2301.12507
- **Source URL:** https://arxiv.org/abs/2301.12507
- **Reference count:** 26
- **Primary result:** Uses VLM to generate supervision for language-conditioned embodied agents, enabling teaching of novel object names, attributes, and user preferences without extensive human supervision

## Executive Summary
This paper introduces a method for teaching embodied agents to ground language into their observation and action spaces by leveraging pretrained vision-language models (VLMs). The approach uses VLMs to retroactively generate language descriptions of agent trajectories, which are then used as supervision signals for training. This combines model distillation with hindsight experience replay (HER), allowing agents to learn from sparse success signals by converting them into dense language supervision. The method demonstrates that internet-scale VLMs can be repurposed to teach task-relevant language groundings to embodied agents through simple prompting techniques.

## Method Summary
The method trains an initial task-agnostic agent via behavioral cloning on human-human interaction data, then generates trajectories in a 3D environment. A pretrained Flamingo VLM (80B parameters) retroactively labels final observations in these trajectories using various prompts (zeroshot or fewshot). The agent is then retrained via behavioral cloning on the VLM-labeled trajectories, truncated to the last 5 seconds. This process teaches the agent to perform specific tasks like lifting named objects, recognizing attributes, or understanding category membership, all without requiring extensive human-annotated training data.

## Key Results
- VLM supervision improves embodied agent language grounding through retroactive trajectory relabeling
- Simple prompt variations control which task-relevant features the VLM focuses on during relabeling
- Few-shot prompting enables VLM adaptation to domain-specific visual contexts and ad-hoc category structures

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** VLM supervision improves embodied agent language grounding through retroactive trajectory relabeling
- **Mechanism:** The VLM observes final agent states and generates task-relevant language descriptions, which are then used as training targets via behavioral cloning. This converts sparse success signals into dense language supervision.
- **Core assumption:** VLM-generated descriptions accurately capture the task-relevant aspects of agent behavior.
- **Evidence anchors:** Weak - corpus contains related work but no direct validation of this mechanism
- **Break condition:** If VLM captions consistently miss task-relevant features or hallucinate incorrect information, the supervision signal becomes noisy and degrades performance.

### Mechanism 2
- **Claim:** Prompt engineering controls which task-relevant features the VLM focuses on during relabeling.
- **Mechanism:** Simple prompt variations (e.g., "What is this object?" vs "What color is this object?") direct the VLM to generate different types of descriptions from the same trajectory, teaching different skills to the agent.
- **Core assumption:** VLM responses are sufficiently sensitive to prompt variations to produce meaningfully different task descriptions.
- **Evidence anchors:** Moderate - corpus contains related work on promptable VLM representations but no direct evidence for this specific mechanism
- **Break condition:** If VLM responses are too rigid or ignore prompt variations, this control mechanism fails and the agent cannot learn task-specific groundings.

### Mechanism 3
- **Claim:** Few-shot prompting enables VLM adaptation to domain-specific visual contexts and ad-hoc category structures.
- **Mechanism:** Providing in-context examples helps the VLM recognize and label objects in the 3D rendered environment, including novel category definitions like user preferences.
- **Core assumption:** VLM can generalize from few examples to correctly label unseen instances in the specific visual domain.
- **Evidence anchors:** Moderate - corpus contains related work on few-shot VLM adaptation but no direct evidence for this mechanism
- **Break condition:** If VLM cannot generalize from few examples or the examples are unrepresentative, few-shot prompting fails to improve domain adaptation.

## Foundational Learning

- **Concept:** Hindsight Experience Replay (HER) and its language-conditioned extension
  - **Why needed here:** The method builds directly on HER by using VLM-generated language as relabeling function instead of environment-provided goals
  - **Quick check question:** How does HER typically handle sparse rewards, and how does this paper modify that approach?

- **Concept:** Behavioral cloning as training method for imitation learning
  - **Why needed here:** The relabeled trajectories are used to train agents via behavioral cloning, not RL
  - **Quick check question:** What are the key differences between behavioral cloning and RL approaches in this context?

- **Concept:** Prompt engineering and few-shot learning in VLMs
  - **Why needed here:** The method relies on simple and few-shot prompts to control VLM behavior and enable domain adaptation
  - **Quick check question:** How do prompt variations affect VLM output, and what determines the number of examples needed for few-shot adaptation?

## Architecture Onboarding

- **Component map:** Agent -> Trajectory Generator -> VLM -> Behavioral Cloning Trainer -> Retrained Agent
- **Critical path:** 1. Agent generates trajectories using initial policy 2. VLM relabels final observations with language descriptions 3. Behavioral cloning trains new policy on VLM labels 4. Evaluate policy performance on target tasks
- **Design tradeoffs:** VLM size vs inference speed (80B parameters provides better language grounding but increases latency); Prompt specificity vs generalization (more specific prompts may improve precision but reduce flexibility); Few-shot examples vs label quality (more examples improve domain adaptation but increase prompt complexity)
- **Failure signatures:** Low precision relabeling causes worse performance than low accuracy relabeling; VLM failing to recognize objects in 3D rendered environment (common in early experiments); Behavioral cloning overfitting to VLM noise rather than learning robust groundings
- **First 3 experiments:** 1. Object naming task - teach agent to lift specific objects by name 2. Attribute recognition task - teach agent to recognize object colors/shapes 3. Category membership task - teach agent to distinguish food vs toys

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** Can the VLM-based relabeling approach be extended to learn temporally-extended tasks beyond simple one-step instructions?
- **Basis in paper:** The paper mentions that future work could extend the method beyond traditional HER to use a VLM to annotate observation pairs or full videos, facilitating teaching temporally-extended tasks.
- **Why unresolved:** The current method focuses on relabeling the final observation only, which is suitable for simple tasks but may not capture the complexity of longer sequences of actions.
- **What evidence would resolve it:** Experiments demonstrating the approach's effectiveness in teaching agents to perform multi-step tasks or those requiring temporal reasoning.

### Open Question 2
- **Question:** How does the quality of the initial "original" agent affect the final performance of the VLM-retrained agent?
- **Basis in paper:** The paper trains an "original" agent via behavioral cloning on human-human data, but it's unclear how the quality of this initial agent influences the downstream task performance after VLM relabeling.
- **Why unresolved:** The paper doesn't explore the relationship between the original agent's capabilities and the effectiveness of the VLM-based training.
- **What evidence would resolve it:** Comparative experiments training agents with varying levels of initial competence and measuring the impact on final performance.

### Open Question 3
- **Question:** Can the VLM-based relabeling method be applied to other domains beyond the 3D rendered environment used in the paper?
- **Basis in paper:** The paper uses a 3D rendered environment and suggests that future work could experiment with different environments, but doesn't test this.
- **Why unresolved:** The effectiveness of the method in real-world scenarios or other simulated environments is unknown.
- **What evidence would resolve it:** Successful application of the approach to different domains, such as robotics or real-world image datasets.

## Limitations
- VLM relabeling quality control is not extensively validated, with limited exploration of systematic label quality issues
- Generalization beyond controlled environments is untested, with all experiments using a 3D rendered environment
- Computational efficiency is not analyzed, as using an 80B parameter VLM creates substantial overhead

## Confidence
- **High Confidence:** The core mechanism of using VLM-generated language supervision for behavioral cloning shows consistent experimental support
- **Medium Confidence:** Claims about prompt engineering control and few-shot adaptation are supported but lack rigorous ablation studies
- **Low Confidence:** Claims about teaching "ad-hoc user preferences" are demonstrated only in very limited context with simple binary categories

## Next Checks
1. **VLM Label Quality Analysis:** Conduct systematic evaluation of VLM-generated labels across different prompt types and visual domains, measuring inter-rater reliability between VLM outputs and human annotations
2. **Domain Transfer Experiments:** Test the method on environments with varying visual complexity, including photorealistic simulations and real-world captured imagery
3. **Computational Efficiency Study:** Benchmark the method's performance using progressively smaller VLMs (e.g., 3B, 7B parameters) and compare to the 80B baseline to analyze the tradeoff between VLM size, inference speed, and downstream agent performance
