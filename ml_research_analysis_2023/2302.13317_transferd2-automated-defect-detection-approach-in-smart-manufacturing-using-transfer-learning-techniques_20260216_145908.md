# TransferD2: Automated Defect Detection Approach in Smart Manufacturing using Transfer Learning Techniques

## Quick Facts
- arXiv ID: 2302.13317
- Source URL: https://arxiv.org/abs/2302.13317
- Reference count: 24
- Key outcome: Transfer learning approach achieves 95.72% accuracy on source data and 91.00% on unseen target objects for defect detection

## Executive Summary
TransferD2 presents a transfer learning approach for automated defect detection in smart manufacturing, addressing the challenge of detecting defects on new objects with limited labeled source data. The method uses pre-trained deep learning models (Xception, ResNet101V2, InceptionResNetV2) combined with a data enhancement technique that generates a large balanced dataset from a small source dataset through image tiling and oversampling. The approach successfully extends defect detection capabilities from source objects to unseen target objects, demonstrating that transfer learning can be effective even with limited training data.

## Method Summary
The method involves preprocessing source images by cropping backgrounds and splitting them into 10x10 grids, then mapping defect annotations to individual tiles and labeling them as defective or non-defective. A data enhancement technique balances the dataset by oversampling defective tiles, creating 22,700 labeled images from the original 227. Three pre-trained models are integrated into a classifier with global average pooling, dropout, and sigmoid output layers. The classifier is trained on the enhanced dataset for 50 epochs, then applied to target objects using a sliding window approach with thresholding to detect defects and draw pseudo-bounding boxes.

## Key Results
- ResNet101V2 achieves highest accuracy of 95.72% on source data
- Xception performs best on target data with 91.00% accuracy
- Model choice is not dependent on network depth for defect detection tasks
- Transfer learning successfully extends defect detection to unseen objects with limited source data

## Limitations
- Dataset composition and defect types remain unspecified, limiting generalizability assessment
- Tile-based approach assumes defects are spatially localized, which may not hold for larger defects
- Fixed 10x10 tiling grid and 0.7 threshold value were not systematically optimized
- Absence of ablation studies on augmentation techniques leaves optimization questions open

## Confidence

- Transfer learning effectiveness on unseen objects: High
- Data enhancement through tiling and oversampling: Medium
- Model depth independence for defect detection: Low
