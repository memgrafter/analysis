# Dual Formulation for Chance Constrained Stochastic Shortest Path with Application to Autonomous Vehicle Behavior Planning

## Quick Facts
- arXiv ID: 2302.13115
- Source URL: https://arxiv.org/abs/2302.13115
- Reference count: 22
- The paper presents an exact integer linear programming formulation for chance-constrained stochastic shortest path planning that achieves deterministic policies while significantly reducing computational complexity.

## Executive Summary
This paper addresses the challenge of chance-constrained stochastic shortest path planning for autonomous vehicles, focusing on optimizing expected performance while bounding collision risk. The authors develop an exact integer linear programming formulation for chance-constrained stochastic shortest path (CC-SSP) that provides deterministic policies, along with a randomized rounding algorithm for stochastic policies. The work generalizes CC-SSP to handle multi-step constraints and demonstrates significant computational efficiency improvements over tree-based history expansion methods. Experimental results show the approach achieves close-to-optimal solutions with the randomized rounding algorithm performing at least 94% of optimal in practice.

## Method Summary
The paper introduces a novel dual formulation for chance-constrained stochastic shortest path planning. The core approach uses an exact integer linear programming (ILP) formulation that converts the chance-constrained problem into a deterministic optimization framework. This is complemented by a randomized rounding algorithm that generates stochastic policies while maintaining risk bounds. The method handles both single-step and multi-step chance constraints, generalizing the problem formulation. The computational complexity is significantly reduced compared to traditional tree-based expansion methods, enabling efficient planning over longer horizons. The approach is validated on grid-based and highway driving scenarios, demonstrating near-optimal performance while maintaining collision risk below specified thresholds.

## Key Results
- Integer linear programming formulation achieves exact deterministic solutions for chance-constrained stochastic shortest path problems
- Randomized rounding algorithm achieves at least 94% of optimal performance in practice
- Computational complexity significantly reduced compared to tree-based history expansion methods
- Approach successfully handles both single-step and multi-step chance constraints

## Why This Works (Mechanism)
The dual formulation works by converting the probabilistic constraints into deterministic linear constraints through a clever mathematical transformation. By reformulating the chance-constrained problem using dual variables, the authors can leverage efficient integer linear programming solvers to find exact solutions. The randomized rounding algorithm provides a practical way to generate stochastic policies while maintaining theoretical guarantees on risk bounds. This combination of exact methods for deterministic policies and approximation algorithms for stochastic policies provides a comprehensive solution framework that balances computational efficiency with solution quality.

## Foundational Learning
- Chance-constrained optimization: Optimization problems with probabilistic constraints that limit risk; needed to ensure safe autonomous vehicle behavior planning under uncertainty
- Integer linear programming: Mathematical optimization technique for finding exact solutions to discrete decision problems; needed for deterministic policy computation
- Randomized rounding algorithms: Techniques for converting fractional solutions to integral ones while preserving approximation guarantees; needed for efficient stochastic policy generation
- Dual formulation: Mathematical approach that converts primal problems into equivalent dual problems; needed to transform probabilistic constraints into tractable deterministic form
- Multi-step chance constraints: Extensions that consider risk accumulation over multiple time steps; needed for more realistic safety guarantees in sequential decision making
- Stochastic shortest path: Path planning problem with probabilistic state transitions; needed to model uncertainty in autonomous driving environments

## Architecture Onboarding

Critical Path: Problem formulation → Integer Linear Programming → Risk constraint verification → Policy selection → Vehicle execution

Design Tradeoffs: The approach trades some theoretical optimality guarantees for computational tractability, choosing to use integer linear programming for exact solutions in manageable problem sizes while employing randomized rounding for larger instances. The formulation balances between deterministic and stochastic policies based on problem requirements and computational constraints.

Failure Signatures: Performance degradation when probability distributions are misspecified or when the discretized state space inadequately represents the continuous driving environment. The randomized rounding algorithm may produce suboptimal policies when the fractional LP solution is far from the integer optimum. Computational bottlenecks can occur when problem size exceeds solver capabilities despite efficiency improvements over tree-based methods.
