# Self-Distillation with Meta Learning for Knowledge Graph Completion

## Quick Facts
- arXiv ID: 2305.12209
- Source URL: https://arxiv.org/abs/2305.12209
- Reference count: 8
- Primary result: Proposed MetaSD achieves competitive performance with 10x smaller models on FB15k-237 and WN18RR datasets

## Executive Summary
This paper introduces MetaSD, a self-distillation framework with meta learning for knowledge graph completion (KGC) that addresses two key challenges: compressing large graph embeddings for efficient deployment and improving performance on long-tail samples. The method employs dynamic pruning to obtain a smaller pruned model from a large source model, with the pruning mask updated adaptively per epoch. Additionally, a one-step meta self-distillation method distills comprehensive knowledge from the source model to the pruned model using meta learning. Experimental results demonstrate that MetaSD achieves MRR scores of 0.391 and 0.491 on FB15k-237 and WN18RR datasets respectively while being 10x smaller than baseline models, with significant improvements on long-tail samples.

## Method Summary
The MetaSD framework consists of a source model (teacher) and a pruned model (student) that co-evolve during training. The source model is initialized with ComplEx and serves as the teacher. At each epoch, dynamic magnitude-based pruning creates a smaller pruned model from the source model. The framework uses one-step meta self-distillation where the source model is updated based on the performance of a virtual copy of the pruned model on a quiz set, while the pruned model is updated using knowledge distillation from the source model. Both models are updated iteratively throughout training rather than keeping the teacher fixed, allowing them to adapt to each other dynamically.

## Key Results
- MetaSD achieves MRR scores of 0.391 and 0.491 on FB15k-237 and WN18RR datasets respectively
- The pruned model is 10x smaller than baseline models while maintaining competitive performance
- Significant improvements on long-tail samples validate effectiveness in handling data imbalance
- The framework shows promise for compressing knowledge graph embeddings without substantial performance loss

### Mechanism 1
- Claim: Dynamic pruning allows the pruned model to be more sensitive to difficult-to-memorize (long-tail) samples compared to the source model
- Core assumption: The pruned model, due to its smaller size and adaptive structure, will inherently be more sensitive to the long-tail distribution of samples

### Mechanism 2
- Claim: One-step meta self-distillation improves the source model's knowledge transfer ability by using the pruned model's performance as feedback
- Core assumption: The performance of the pruned model on a quiz set is a good indicator of how well the source model is transferring knowledge

- Break condition: If the quiz set is not representative of training distribution, meta-update may not improve or could degrade transfer ability

### Mechanism 3
- Claim: Mutual update of source and pruned models allows them to co-evolve, avoiding the need to pre-train a large model and potentially improving final pruned model's performance
- Core assumption: The iterative, mutual update process allows the two models to adapt to each other in a way that improves the final pruned model's performance

- Break condition: If learning rates or balance hyperparameters are not well-tuned, mutual update process could lead to instability or divergence

## Architecture Onboarding

- Component map: Source Model (T) -> Dynamic Pruning Module -> Pruned Model (S) -> Meta-Learning Module -> Source Model (T) -> Knowledge Distillation Module -> Pruned Model (S)

- Critical path:
  1. Initialize source model T (ComplEx)
  2. For each epoch:
     a. Prune T to obtain S (dynamic pruning)
     b. For each batch:
        i. Create virtual copy S' of S
        ii. Update S' using knowledge distillation from T (Virtual-Train)
        iii. Update T using S' performance on quiz set (Meta-Train)
        iv. Update S using knowledge distillation from updated T (Actual-Train)
        v. Update T using combination of cross-entropy and knowledge distillation from S (Actual-Train)

- Design tradeoffs:
  - Model Size vs. Performance: Pruned model is 10x smaller but achieves competitive performance
  - Static vs. Dynamic Pruning: Dynamic pruning allows adaptation to difficult samples but adds computational overhead
  - Fixed vs. Co-evolving Teacher: Co-evolving teacher with student can improve performance but adds complexity

- Failure signatures:
  - Pruned model performance plateaus or degrades: Could indicate pruning rate is too high or meta-learning is not effective
  - Training instability or divergence: Could indicate learning rates or balance hyperparameters are not well-tuned
  - Long-tail performance does not improve: Could indicate dynamic pruning is not effectively focusing on long-tail samples

- First 3 experiments:
  1. Run with only knowledge distillation (no meta-learning, no dynamic pruning) to establish baseline performance
  2. Add dynamic pruning to see its effect on long-tail sample performance
  3. Add meta-learning to see its effect on overall and long-tail sample performance

## Limitations
- The meta-learning framework relies on computationally expensive second-order gradient computations that may limit scalability to larger knowledge graphs
- Dynamic pruning lacks theoretical guarantees about preserving model capacity for critical relations
- The paper demonstrates effectiveness primarily on two benchmark datasets, leaving open questions about generalization to industrial-scale KGs
- The mutual update mechanism introduces additional hyperparameters that require careful tuning, which is not fully explored in ablation studies
