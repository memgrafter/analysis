# Inductive Linear Probing for Few-shot Node Classification

## Quick Facts
- arXiv ID: 2306.08192
- Source URL: https://arxiv.org/abs/2306.08192
- Authors: 
- Reference count: 20
- Key outcome: Most meta-learning methods perform poorly in inductive few-shot node classification; I-GNN achieves superior performance by pre-training GNN embeddings and using a linear classifier

## Executive Summary
This paper identifies a critical gap in meta-learning research: most existing methods fail in the inductive few-shot node classification setting. The authors propose I-GNN, a simple baseline that pre-trains a GNN encoder on base classes and uses a linear classifier on support nodes. Through comprehensive experiments on five real-world datasets, I-GNN demonstrates superior performance compared to state-of-the-art meta-learning approaches in the inductive setting, while also showing competitive results in transductive settings for certain datasets. The work calls for renewed research focus on inductive few-shot learning in graph domains.

## Method Summary
I-GNN employs a two-phase training approach. First, it pre-trains a GNN encoder on base classes using supervised learning with LCE loss and weight decay. The encoder is then frozen and used to generate embeddings for all nodes in target tasks. For each task, a new linear classifier is trained only on the support set to predict labels for the query set. This approach leverages the transferability of pre-trained GNN embeddings while avoiding the challenges that meta-learning methods face in inductive settings where graph connectivity between training and test nodes is severed.

## Key Results
- I-GNN significantly outperforms all tested meta-learning methods (MAML, ProtoNet, Meta-GNN, GPN, AMM-GNN, G-Meta) in the inductive setting
- On Cora, Citeseer, and Corafull datasets, I-GNN achieves higher accuracy in inductive settings compared to transductive settings
- MAML and ProtoNet maintain consistent performance between transductive and inductive settings because they do not use message-passing GNNs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: I-GNN outperforms meta-learning methods in inductive few-shot node classification by leveraging pre-trained GNN embeddings and a linear classifier trained on support nodes.
- Mechanism: I-GNN uses a two-phase training approach. First, it pre-trains a GNN encoder on base classes using supervised learning with LCE loss and weight decay. Then, the GNN encoder is frozen and used to generate embeddings for all nodes in the target task. A new linear classifier is trained only on the support set to predict labels for the query set.
- Core assumption: The pre-trained GNN embeddings are transferable and contain sufficient information to distinguish novel classes, even with limited labeled support data.
- Evidence anchors:
  - [abstract]: "we propose a simple yet competitive baseline approach specifically tailored for inductive few-shot node classification tasks"
  - [section]: "In the second phase, the parameter of the GNN encoder is frozen, and the classifier is discarded. When fine-tuning on a target few-shot node classification task, the pretrained GNN encoder is used to directly transfer embeddings of all nodes from the task, and a new linear classifier (fψ) is involved and tuned with few-shot labeled nodes from the support set (Si) to predict labels of nodes in the query set (Qi)."
- Break condition: The transferability of GNN embeddings breaks down if the base and novel classes are too dissimilar or if the GNN architecture is too shallow to capture class-discriminative features.

### Mechanism 2
- Claim: Meta-learning methods suffer in inductive settings because they require a large number of samples to learn effective adaptation strategies.
- Mechanism: Meta-learning algorithms like MAML and ProtoNet are designed to learn how to adapt quickly to new tasks by optimizing over many meta-tasks. However, in the inductive setting, the message-passing mechanism of GNNs is disrupted because edges between training and test nodes are removed. This makes it harder for GNNs to learn generalizable knowledge, and the meta-learning models cannot compensate due to limited data.
- Core assumption: The meta-learning framework assumes access to rich, diverse meta-tasks during training, which is not fully available in the inductive setting due to the lack of graph connectivity.
- Evidence anchors:
  - [abstract]: "We empirically show that most current meta-learning frameworks cannot perform well in this setting."
  - [section]: "This decline is attributed to the challenges of generalizing knowledge from limited labeled examples to unseen data... the need for generalization contribute to lower performance in the inductive setting."
- Break condition: If the inductive setting is relaxed to allow some shared structure between training and test tasks, or if the meta-learning algorithm is modified to handle sparse supervision, the performance gap may narrow.

### Mechanism 3
- Claim: MAML and ProtoNet maintain consistent performance between transductive and inductive settings because they do not use message-passing GNNs.
- Mechanism: MAML and ProtoNet operate on a per-node basis and do not leverage the graph structure through message passing. As a result, they are not affected by the removal of edges between dataset splits in the inductive setting. Their performance remains the same because the underlying learning mechanism is independent of the graph topology.
- Core assumption: The performance of MAML and ProtoNet is invariant to the graph structure because they do not use GNNs for message passing.
- Evidence anchors:
  - [section]: "The scores for both MAML and ProtoNet remain the same on all datasets because they do not utilize message-passing GNN in their approach."
- Break condition: If MAML or ProtoNet are modified to incorporate graph structure (e.g., via GNNs), their performance may start to degrade in the inductive setting.

## Architecture Onboarding

- Component map:
  GNN Encoder (gθ) -> Linear Classifier (fϕ) -> Task-specific Linear Classifier (fψ) -> Support Set (Si) -> Query Set (Qi)

- Critical path:
  1. Pre-train GNN encoder on base classes with LCE loss and weight decay
  2. Freeze GNN encoder
  3. For each target task:
     a. Generate embeddings for all nodes using frozen GNN encoder
     b. Train new linear classifier on support set
     c. Evaluate on query set

- Design tradeoffs:
  - Simplicity vs. adaptability: I-GNN is simple but may not adapt as well as meta-learning methods in some settings
  - Pre-training data: Requires sufficient base class data to learn transferable embeddings
  - Computational cost: Pre-training GNN encoder is expensive but only done once

- Failure signatures:
  - Poor performance if base and novel classes are too dissimilar
  - Overfitting if the support set is too small relative to the number of classes
  - Underfitting if the GNN encoder is too shallow to capture class-discriminative features

- First 3 experiments:
  1. Replicate the inductive vs. transductive comparison on Cora dataset with 2-way 1-shot and 2-way 5-shot settings
  2. Vary the number of base classes and novel classes to test the limits of transferability
  3. Compare I-GNN with and without pre-training on base classes to quantify the impact of pre-training

## Limitations

- The exact GNN architecture for the encoder is not specified, which could affect reproducibility and comparison to other methods
- Performance may be highly sensitive to learning rates, weight decay values, and pre-training duration, but these hyperparameters are not provided
- Results are based on five specific datasets; performance on other graph types or larger-scale graphs remains unknown

## Confidence

- High confidence: The core claim that I-GNN outperforms existing meta-learning methods in the inductive setting is well-supported by the experimental results
- Medium confidence: The mechanism explanation for why meta-learning methods struggle in inductive settings is reasonable but lacks theoretical depth
- Low confidence: The claim that I-GNN can outperform meta-learning methods in transductive settings for certain datasets is based on limited experimental evidence
