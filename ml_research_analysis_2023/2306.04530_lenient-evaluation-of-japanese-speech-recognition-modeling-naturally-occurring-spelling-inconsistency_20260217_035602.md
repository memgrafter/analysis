# Lenient Evaluation of Japanese Speech Recognition: Modeling Naturally Occurring Spelling Inconsistency

## Quick Facts
- arXiv ID: 2306.04530
- Source URL: https://arxiv.org/abs/2306.04530
- Reference count: 12
- Japanese ASR evaluation improved by accounting for spelling variation

## Executive Summary
Japanese ASR evaluation faces challenges due to multiple valid spellings for the same words using hiragana, katakana, and kanji. This paper addresses this by creating a lattice of plausible spelling variants for each reference utterance, using text normalization, kanji restoration NMT, and lexical equivalence classes. Manual evaluation showed 95.4% of generated variants were acceptable, with 16% rated better than the original. ASR experiments across three domains demonstrated 2.4%-3.1% absolute CER reduction, corresponding to over 25% relative error reduction on voice search.

## Method Summary
The approach constructs reference lattices of spelling variants using a text normalization system to convert kanji to hiragana/katakana, an NMT model for context-aware kanji restoration from kana, and lexical resources providing spelling equivalence classes. These components generate all plausible variants for each word, which are then combined into a lattice. ASR hypotheses are compared against this lattice using a modified Levenshtein distance calculation that finds the shortest path through the lattice, effectively allowing the system to match against any valid spelling variant.

## Key Results
- Manual evaluation rated 95.4% of spelling variants as plausible, with 16% preferred over original
- CER reduced by 2.4%-3.1% absolute across three domains (Farfield, VoiceSearch, YouTube)
- Over 25% relative error reduction achieved on voice search domain
- NMT model achieved 3.8% token error rate on kanji restoration task

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The lattice-based evaluation reduces false errors caused by orthographic variation in Japanese.
- Mechanism: By creating a reference lattice of plausible spelling variants for each word, the system allows matching against multiple valid spellings instead of penalizing the system for choosing a valid alternate form.
- Core assumption: The lexical resources and NMT model can generate all plausible spelling variants that are semantically equivalent.
- Evidence anchors:
  - [abstract] "We create a lattice of plausible respellings of the reference transcription, using a combination of lexical resources, a Japanese text-processing system, and a neural machine translation model for reconstructing kanji from hiragana or katakana."
  - [section] "In a manual evaluation, raters rated 95.4% of the proposed spelling variants as plausible."
  - [corpus] Weak - related papers focus on ASR evaluation metrics but don't directly validate spelling variant generation
- Break condition: If the NMT model or lexical resources fail to capture valid variants, or if context-dependent variants are incorrectly included.

### Mechanism 2
- Claim: The NMT-based kanji restoration model provides context-aware conversion from kana to kanji.
- Mechanism: The model is trained on web text with kana-to-kanji conversions tagged, allowing it to predict the most appropriate kanji spelling based on surrounding context.
- Core assumption: The NMT model can accurately disambiguate between semantically distinct kanji spellings that share the same kana reading.
- Evidence anchors:
  - [abstract] "We create a lattice of plausible respellings...using...a neural machine translation model for reconstructing kanji from hiragana or katakana."
  - [section] "The token error rate for kanji restoration on a held out corpus is approximately 3.8%."
  - [corpus] Weak - no direct validation of NMT model's semantic disambiguation ability in corpus
- Break condition: If the NMT model makes semantic errors, incorrectly converting kana to the wrong kanji variant.

### Mechanism 3
- Claim: The spelling equivalence classes from lexical resources ensure only semantically interchangeable variants are included.
- Mechanism: The system uses curated lexical resources that list spelling equivalence classes, ensuring that only variants that can be safely substituted without considering context are included in the lattice.
- Core assumption: The lexical resources accurately capture all semantically interchangeable spelling variants and exclude variants with different meanings.
- Evidence anchors:
  - [abstract] "Finally, 旨い has another possible kanji spelling, 美味い, which we have already seen in Section 2. To allow for these variants we use lexical resources licensed from the CJK Institute...which lists spelling equivalence classes for several tens of thousands of Japanese words."
  - [section] "These equivalence classes are 'safe' in the sense that one can substitute any spelling in the class for any other without considering the context of the word."
  - [corpus] Weak - related papers don't discuss lexical resource validation for semantic equivalence
- Break condition: If the lexical resources are incomplete or incorrectly mark variants as interchangeable when they have different meanings.

## Architecture Onboarding

- Component map:
  - Reference transcription → Text normalization (kanji→hiragana) → Word segmentation
  - NMT prediction (hiragana→kanji) + Lexical equivalence lookup
  - Lattice construction with all variants
  - ASR hypothesis vs. lattice comparison using Levenshtein distance

- Critical path:
  1. Reference transcription → Text normalization (kanji→hiragana) → Word segmentation
  2. For each word: NMT prediction (hiragana→kanji) + Lexical equivalence lookup
  3. Lattice construction with all variants
  4. ASR hypothesis vs. lattice comparison using Levenshtein distance

- Design tradeoffs:
  - Using a proprietary text normalization system vs. open-source alternatives (Mecab mentioned as potential replacement)
  - Tradeoff between lattice size (more variants = better coverage but slower evaluation) and practical evaluation speed
  - Choosing NMT vs. rule-based approaches for kanji restoration (NMT provides context-awareness but requires training data)

- Failure signatures:
  - High CER reduction but poor manual evaluation scores (lattice includes too many incorrect variants)
  - Low CER reduction but high manual evaluation scores (lattice too conservative, missing valid variants)
  - NMT model errors showing systematic semantic mistakes (e.g., consistently choosing wrong kanji for ambiguous kana)

- First 3 experiments:
  1. Implement text normalization and basic lattice construction without NMT or lexicon - measure baseline CER reduction from just kana conversion
  2. Add NMT-based kanji restoration to the lattice - measure additional CER reduction and analyze NMT error types
  3. Integrate lexical equivalence classes - measure final CER reduction and conduct manual evaluation on generated variants

## Limitations
- Proprietary lexical resources and text normalization system limit reproducibility
- Manual evaluation sample size (100 utterances) may not capture all edge cases
- NMT model's semantic disambiguation capabilities lack deeper validation
- Potential downstream impact on ASR system development not addressed

## Confidence
- **High Confidence**: The core mechanism of using lattices to reduce false errors from orthographic variation is well-established and the 2.4-3.1% absolute CER reduction is clearly demonstrated across three domains.
- **Medium Confidence**: The effectiveness of the NMT-based kanji restoration model and lexical equivalence classes is supported by error rate metrics and manual evaluation, but lacks deeper validation of semantic accuracy.
- **Low Confidence**: The reproducibility of results given proprietary components is uncertain. Without access to the exact lexical resources and text normalization system, achieving comparable performance is speculative.

## Next Checks
1. **Semantic Accuracy Validation**: Manually audit 200 randomly selected lattice variants from the NMT model to verify that semantic disambiguation is correct, particularly for homophonic kanji pairs. Compare error rates between NMT predictions and baseline kana-to-kanji conversion rules.

2. **Reproducibility Benchmark**: Implement the complete pipeline using only open-source components (Mecab for text normalization, publicly available lexicons) and evaluate on a held-out test set from the same domains. Measure performance degradation compared to the proprietary implementation.

3. **Lattice Sensitivity Analysis**: Systematically vary the size and composition of spelling equivalence classes in the lattice to determine the optimal tradeoff between CER reduction and evaluation accuracy. Test whether overly permissive lattices begin to mask genuine ASR errors by comparing with human-annotated gold standards.
