# GDOD: Effective Gradient Descent using Orthogonal Decomposition for Multi-Task Learning

## Quick Facts
- arXiv ID: 2301.13465
- Source URL: https://arxiv.org/abs/2301.13465
- Reference count: 40
- Primary result: GDOD significantly improves multi-task learning performance by decomposing gradients to separate task-shared and conflicting components, achieving notable gains in AUC and Logloss metrics

## Executive Summary
GDOD addresses the fundamental challenge of conflicting gradients in multi-task learning by introducing an orthogonal decomposition technique. The method separates each task's gradient into shared and conflicting components using an orthogonal basis derived from all task gradients. By updating parameters only using the task-shared components, GDOD effectively avoids interference between tasks while maintaining convergence guarantees under both convex and non-convex assumptions. Extensive experiments demonstrate significant performance improvements over existing MTL approaches across multiple datasets.

## Method Summary
The GDOD method works by first computing gradients for all tasks in a multi-task learning setting. It then constructs an orthogonal basis from the span of all task gradients and decomposes each task's gradient into components that lie within this basis (task-shared) and those that don't (task-conflicting). Only the task-shared components are used for parameter updates during optimization. This approach ensures that parameter updates benefit from commonalities across tasks while avoiding detrimental interference from conflicting gradient directions. The method includes theoretical convergence proofs and is designed to be compatible with various deep learning architectures.

## Key Results
- GDOD achieves significant improvements in AUC and Logloss metrics compared to state-of-the-art MTL optimization methods
- The method demonstrates consistent performance gains across three public datasets and one large-scale industrial dataset
- Theoretical convergence guarantees are established under both convex and non-convex optimization scenarios

## Why This Works (Mechanism)
GDOD works by addressing the core problem of gradient conflicts in multi-task learning through orthogonal decomposition. When multiple tasks are learned simultaneously, their gradients often point in different directions, creating conflicts that hinder learning. GDOD resolves this by projecting each task's gradient onto an orthogonal basis formed by all task gradients, effectively identifying which components contribute to shared learning objectives versus conflicting ones. By selectively updating parameters using only the shared components, the method maintains beneficial knowledge transfer between related tasks while preventing destructive interference from unrelated tasks.

## Architecture Onboarding
- **Component map**: Task gradients → Orthogonal basis construction → Gradient decomposition → Parameter update (using shared components only)
- **Critical path**: Gradient computation → Orthogonal basis generation → Decomposition step → Selective parameter update
- **Design tradeoffs**: Orthogonal decomposition adds computational overhead but improves task compatibility; selective updates reduce interference but may slow convergence for highly conflicting tasks
- **Failure signatures**: Performance degradation when tasks have minimal shared structure; increased computational cost due to decomposition step
- **First experiments**: 1) Test on synthetic MTL problems with known task relationships, 2) Compare gradient directions before and after decomposition, 3) Measure computational overhead versus performance gains

## Limitations

- Experimental validation limited to classification tasks with relatively small datasets (except proprietary industrial dataset)
- Computational overhead of orthogonal decomposition not thoroughly analyzed for resource-constrained applications
