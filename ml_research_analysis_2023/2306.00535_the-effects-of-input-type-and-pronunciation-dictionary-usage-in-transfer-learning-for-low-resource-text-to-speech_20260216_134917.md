# The Effects of Input Type and Pronunciation Dictionary Usage in Transfer Learning for Low-Resource Text-to-Speech

## Quick Facts
- arXiv ID: 2306.00535
- Source URL: https://arxiv.org/abs/2306.00535
- Reference count: 0
- Primary result: Articulatory features outperformed phone labels in both intelligibility and naturalness for cross-lingual TTS transfer learning in low-resource languages

## Executive Summary
This paper investigates the effectiveness of articulatory features versus phone labels as input representations for cross-lingual transfer learning in text-to-speech systems for low-resource languages (LRLs). The authors use West Frisian as a case study and explore two approaches to handle the absence of pronunciation dictionaries: a massively multilingual grapheme-to-phoneme (G2P) model and a universal phone recognizer. The results demonstrate that articulatory features provide superior performance in both intelligibility (measured by character error rate) and naturalness (measured by MOS prediction) compared to phone labels. The proposed dictionary creation approaches show promise for languages without native pronunciation resources.

## Method Summary
The study uses FastSpeech 2 as the TTS architecture, pre-trained on LJSpeech (English) and fine-tuned on 15 minutes of West Frisian audiobook data. The authors compare three dictionary creation approaches: ground-truth pronunciation, massively multilingual G2P model (trained on 269 languages), and universal phone recognizer. Both phone labels and articulatory features are tested as input representations. Performance is evaluated using character error rate from an ASR system and mean opinion score from a MOS prediction model.

## Key Results
- Articulatory features outperformed phone labels in both intelligibility and naturalness metrics
- The multilingual G2P model achieved 33% ± 6% mean phone error rate when used as baseline
- The universal phone recognizer reached 64.2% phone error rate for Tusom in the original work

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Articulatory features as input enable more efficient cross-lingual transfer learning than phone labels
- Mechanism: Articulatory features capture shared pronunciation characteristics across languages (place, manner, voicing) allowing the model to generalize better from source to target language with limited data
- Core assumption: The phonological similarity between languages is better captured by articulatory features than discrete phone labels
- Evidence anchors: [abstract] "using articulatory features outperformed using phone labels in both intelligibility and naturalness"; [section] "This likely comes from the better learning efficiency hypothesized in Section 1.1"
- Break condition: If the target language's phonological inventory is radically different from the source language, articulatory features may not capture sufficient information

### Mechanism 2
- Claim: Multilingual G2P models can create usable pronunciation dictionaries for low-resource languages without native pronunciation resources
- Mechanism: By training on 269 languages and using language tokens, the G2P model learns generalizable phoneme-to-grapheme patterns that transfer to unseen languages through nearest-neighbor language selection
- Core assumption: Languages share sufficient phonological patterns that a massively multilingual model can predict reasonable pronunciations even for unseen languages
- Evidence anchors: [abstract] "using a massively multilingual model to convert grapheme-to-phone (G2P) in both training and synthesizing"; [section] "Using the dictionary as baseline, this model had a mean phone error rate of 33% ± 6% (SE)"
- Break condition: If the target language's phoneme inventory and G2P rules are too different from all training languages, performance degrades significantly

### Mechanism 3
- Claim: Universal phone recognition can create makeshift pronunciation dictionaries when G2P approaches fail
- Mechanism: By recognizing phones directly from audio and matching to PHOIBLE's database of 2,186 languages, this approach is theoretically more language-independent than G2P
- Core assumption: Phone recognition accuracy is sufficient when combined with articulatory features to enable effective TTS training
- Evidence anchors: [abstract] "using a universal phone recognizer to create a makeshift dictionary"; [section] "They reached a PER of 64.2% for the test language Tusom"
- Break condition: If phone recognition accuracy is too low, the resulting makeshift dictionary will be insufficient for quality TTS

- Component map: Text → G2P/Phone Recognition → TTS Model → Spectrogram → Vocoder → Audio
- Critical path: Text → G2P/Phone Recognition → TTS Model → Spectrogram → Vocoder → Audio
- Design tradeoffs:
  - Using articulatory features increases model complexity but improves cross-lingual generalization
  - G2P approach requires no pronunciation dictionary but has higher error rates than ground truth
  - Phone recognition approach is more language-independent but requires fine-tuning with ground truth data
- Failure signatures:
  - High CER indicates poor intelligibility (likely from G2P/phone recognition errors)
  - Low MOS indicates poor naturalness (could be from architecture limitations or feature representation issues)
  - Significant gap between CER and MOS suggests different failure modes for intelligibility vs naturalness

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How well does the multilingual G2P model perform on truly unseen low-resource languages that are not included in its training data?
- Basis in paper: [explicit] The paper acknowledges that Frisian was included in the G2P model's training data (though with limited data), and thus the results cannot be reliably generalized to truly unseen languages
- Why unresolved: The experiments were conducted on Frisian, which was part of the training data, making it difficult to assess the model's true zero-shot capability
- What evidence would resolve it: Testing the G2P model on LRLs that are completely absent from the training data and comparing its performance to the results obtained with Frisian

### Open Question 2
- Question: Is it possible to bypass the intermediate step of phonetic transcriptions and convert audio directly to articulatory features for creating a makeshift dictionary?
- Basis in paper: [explicit] The authors mention this as future work, suggesting that current methods require intermediate phonetic transcriptions which may introduce inaccuracies
- Why unresolved: This represents a methodological limitation that hasn't been explored yet, and the paper only proposes it as a direction for future research
- What evidence would resolve it: Developing and testing a system that directly maps audio to articulatory features and using this to build pronunciation dictionaries, then comparing the results to current approaches

### Open Question 3
- Question: How would the performance of articulatory features as input change when using an autoregressive TTS architecture instead of the non-autoregressive FastSpeech 2 used in this study?
- Basis in paper: [explicit] The authors note that their results with articulatory features were obtained using a non-AR architecture, and reference previous work [6] that used Tacotron 2 (an AR architecture) without finding significant improvements
- Why unresolved: The comparison between input types was only tested with one architecture type, leaving open the question of whether the advantage of articulatory features is architecture-dependent
- What evidence would resolve it: Replicating the experiments using an autoregressive architecture like Tacotron 2 while keeping all other variables constant, and comparing the results to those obtained with FastSpeech 2

## Limitations
- Evaluation is based on a single low-resource language (West Frisian), limiting generalizability to other LRLs with different phonological inventories
- The G2P model was trained on West Frisian data, which may overestimate its performance on truly unseen languages
- Phone recognition approach requires significant fine-tuning with ground-truth data, which may not be available for many LRLs

## Confidence

**High confidence:** Articulatory features outperform phone labels in the specific experimental setup tested
**Medium confidence:** Multilingual G2P models can create usable pronunciation dictionaries for unseen languages
**Medium confidence:** Universal phone recognition can serve as a fallback when G2P approaches fail

## Next Checks

1. **Generalization Testing**: Validate the approach across 3-5 additional low-resource languages with diverse phonological characteristics, comparing performance drop-off between languages

2. **True Zero-Resource Evaluation**: Test the G2P model on languages completely excluded from its training data, measuring the degradation in CER and MOS compared to seen languages

3. **Human Evaluation Correlation**: Conduct a small-scale human MOS study on 2-3 conditions to verify the correlation between predicted MOS and human perception, particularly for the G2P and phone recognition approaches
