# Mask-then-Fill: A Flexible and Effective Data Augmentation Framework for Event Extraction

## Quick Facts
- arXiv ID: 2301.02427
- Source URL: https://arxiv.org/abs/2301.02427
- Reference count: 23
- Improves event extraction performance on ACE2005, particularly in low-resource settings

## Executive Summary
This paper introduces Mask-then-Fill, a novel data augmentation framework for event extraction that masks out non-event-related text spans and fills them with contextually coherent replacements generated by a fine-tuned infilling model. The approach addresses the challenge of generating diverse training data while preserving the original event structure, achieving a good balance between data diversity and distributional similarity. Experiments demonstrate significant improvements for both EEQA and Text2Event event extraction models, particularly when training data is limited.

## Method Summary
The Mask-then-Fill framework operates by first identifying adjunct fragments (non-overlapping spans that don't contain event triggers or arguments) in sentences, then randomly masking one such fragment and using a fine-tuned T5 model to generate a contextually appropriate replacement span. The T5 model is trained on in-filling tasks using a corpus of plain sentences where spans have been masked. This augmented data is then used to train event extraction models, with the key insight being that variable-length replacements provide more flexible text manipulation than fixed-length methods while maintaining the original event structure.

## Key Results
- Achieves significant performance improvements on ACE2005 for both EEQA and Text2Event models
- Particularly effective in low-resource settings with limited training data
- Augmented data achieves better balance between diversity and distributional similarity compared to existing methods
- Outperforms baseline augmentation approaches including Synonym Replacement, BERT-based methods, and Span-BackTranslation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Replacing adjunct fragments with variable-length spans increases data diversity while preserving event structure
- Mechanism: The Mask-then-Fill process masks out non-event-related text spans and fills them with contextually coherent spans generated by a fine-tuned infilling model, allowing for both syntactic and semantic variation
- Core assumption: Adjunct fragments do not contain event triggers or arguments, so replacing them will not alter the original event structure
- Evidence anchors:
  - [abstract] "it first randomly masks out an adjunct sentence fragment and then infills a variable-length text span with a fine-tuned infilling model."
  - [section 2] "we first define an adjunct fragment as a set of non-overlapping spans of x that do not contain the event triggers and arguments."

### Mechanism 2
- Claim: Using a sequence-to-sequence model fine-tuned on in-filling tasks produces more fluent and contextually appropriate replacements than simple word substitution
- Mechanism: The T5 model is trained to predict missing spans given surrounding context, allowing it to generate replacements that fit both syntactic and semantic constraints of the sentence
- Core assumption: A model trained on general in-filling tasks can generalize to the specific domain of event extraction
- Evidence anchors:
  - [section 2] "We formulate our blank in-filling process as the task of predicting the missing span of text which is consistent with the preceding and subsequent text."

### Mechanism 3
- Claim: The approach achieves better balance between diversity and distributional similarity compared to existing methods
- Mechanism: By measuring both Affinity (distributional similarity) and Diversity metrics, the authors show that their method generates data that is both varied and close to the original distribution
- Core assumption: Maintaining distributional similarity prevents overfitting while diversity provides useful variation for training
- Evidence anchors:
  - [abstract] "Our further analysis shows that it achieves a good balance between diversity and distributional similarity."

## Architecture Onboarding

- Component map: Input preprocessing -> Fragment classification -> Masking module -> Infilling model -> Output generation -> Evaluation
- Critical path: 1. Input sentence analysis and fragment classification, 2. Random selection and masking of adjunct fragment, 3. Infilling model generation of replacement span, 4. Integration of generated span into original sentence, 5. Evaluation of augmented data quality
- Design tradeoffs: Variable-length vs fixed-length replacement (flexibility vs complexity), Single vs multiple fragment modification (simplicity vs diversity), Fine-tuning vs zero-shot (performance vs training requirements)
- Failure signatures: Generated text introduces new events or modifies existing ones, Masked fragments are not properly identified, affecting event structure, Infilling model produces grammatically incorrect text
- First 3 experiments: 1. Test masking and infilling on simple sentences with clear event-argument structure, 2. Evaluate generated samples using Affinity and Diversity metrics, 3. Integrate augmented data into a basic event extraction model and measure performance impact

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions in a dedicated section, but several limitations and potential future directions are mentioned in the Limitations section.

## Limitations
- Only modifies one adjunct fragment at a time, leaving potential benefits of multi-fragment modification unexplored
- Relies on T5 model without investigating whether alternative infilling models might yield better results
- Evaluated only on ACE2005 English dataset, limiting understanding of cross-lingual and cross-domain generalizability

## Confidence
- High confidence: The Mask-then-Fill framework improves performance for both EEQA and Text2Event models on ACE2005 dataset
- Medium confidence: The approach achieves better balance between diversity and distributional similarity compared to existing methods
- Medium confidence: Variable-length span replacement provides more flexibility than fixed-length methods

## Next Checks
1. **Fragment Classification Validation**: Implement a test to verify that masked fragments never contain event triggers or arguments by running the fragment identification algorithm on sentences with known event structures and checking for violations.

2. **Generated Text Quality Assessment**: Conduct a human evaluation study to assess whether the infilling model generates contextually appropriate text that maintains grammatical correctness and doesn't introduce spurious events.

3. **Cross-Dataset Generalization Test**: Apply the Mask-then-Fill framework to a different event extraction dataset (e.g., TAC-KBP) to evaluate whether the performance improvements and diversity/distribution balance generalize beyond ACE2005.
