# PubGraph: A Large-Scale Scientific Knowledge Graph

## Quick Facts
- arXiv ID: 2302.02231
- Source URL: https://arxiv.org/abs/2302.02231
- Reference count: 32
- Primary result: Novel inductive KG methods achieving high performance on citation link prediction without explicit features

## Executive Summary
PubGraph is a large-scale temporal knowledge graph containing over 432 million nodes and 15.49 billion edges, mapped to the Wikidata ontology. It unifies data from OpenAlex and Semantic Scholar to study scientific progress, with three benchmark datasets created for knowledge graph completion tasks. The work introduces novel inductive learning methods that operate on unseen nodes without explicit features, achieving high performance on citation link prediction tasks. All resources are publicly available under CC-BY-SA license with quarterly updates.

## Method Summary
The paper develops PubGraph by extracting and transforming OpenAlex data using KGTK, then creating three benchmark datasets (PG-1M, PG-10M, PG-Full) through snowball sampling. Experiments span static transductive, temporal transductive, and inductive settings using models like ComplEx, RotatE, DE-TransE, DE-DistMult, GraphSAGE, and RGCN. The novel inductive methods modify message-passing to work without node features by leveraging network structure, and hybrid approaches combine static embeddings with inductive training. Evaluation uses various negative sampling strategies including community-based sampling as an efficient proxy for full ranking.

## Key Results
- Novel inductive learning methods achieve high performance on citation link prediction tasks operating on unseen nodes without explicit features
- Hybrid models (GraphSAGE-H, RGCN-H) outperform end-to-end variants by leveraging static transductive embeddings
- Community-based negative sampling provides efficient proxy for full ranking while maintaining evaluation difficulty

## Why This Works (Mechanism)

### Mechanism 1
High MRR in inductive settings despite featureless nodes indicates that multi-hop neighborhood aggregation captures sufficient structural signal for citation prediction. GraphSAGE-E and RGCN-E use modified message-passing that aggregates only neighbor representations, distributing node embeddings across the graph and implicitly encoding citation structure without explicit features. The core assumption is that structural patterns in citation networks (e.g., common co-authors, venues, and institutions) are strong predictors of future citations.

### Mechanism 2
Hybrid models (GraphSAGE-H, RGCN-H) outperform end-to-end variants because static transductive embeddings provide strong initialization for inductive training. Pretraining with ComplEx provides high-quality static embeddings which are then frozen and used as features in message-passing models, combining speed and reasoning power. The core assumption is that static embeddings capture enough information about nodes that inductive models can leverage them effectively without further fine-tuning.

### Mechanism 3
Community-based negative sampling provides efficient proxy for full ranking while maintaining evaluation difficulty. Sampling negatives from the same community as the target node increases difficulty by selecting structurally similar but non-linked nodes, providing better signal for model quality. The core assumption is that nodes within the same community are more likely to be potential citation candidates, making them harder negatives than random samples.

## Foundational Learning

- Concept: Transductive vs. Inductive learning
  - Why needed here: PubGraph experiments evaluate both settings, requiring understanding of when models can use all training nodes (transductive) vs. only seen nodes (inductive).
  - Quick check question: In the inductive setting, can the model see embeddings for nodes in the test set during training?

- Concept: Knowledge Graph Embeddings (KGE)
  - Why needed here: PubGraph uses various KGE models (ComplEx, RotatE, TransE) that learn vector representations of entities and relations.
  - Quick check question: What is the key difference between ComplEx and RotatE in how they model relations?

- Concept: Message Passing in Graph Neural Networks
  - Why needed here: Inductive models (GraphSAGE, RGCN) use message passing to aggregate information from node neighborhoods.
  - Quick check question: How does the modified message passing in GraphSAGE-E differ from standard GraphSAGE?

## Architecture Onboarding

- Component map:
  OpenAlex -> Wikidata mapping -> PubGraph KG -> PG-1M/PG-10M/PG-Full datasets -> Training framework (DGL-KE for static/transductive, PyTorch for inductive) -> Evaluation (negative sampling strategies)

- Critical path:
  1. Extract and transform OpenAlex data using KGTK
  2. Sample KGs (PG-1M, PG-10M, PG-Full) with snowball sampling
  3. Train static/transductive models (ComplEx, RotatE, DE-TransE, DE-DistMult)
  4. Train inductive models (GraphSAGE-E/H, RGCN-E/H)
  5. Evaluate with various negative sampling strategies

- Design tradeoffs:
  - Static vs. temporal models: Static models perform better but cannot generalize to unseen timestamps
  - End-to-end vs. hybrid inductive: Hybrid models faster but rely on quality of static embeddings
  - Community vs. random negative sampling: Community sampling more efficient but requires community detection

- Failure signatures:
  - Low MRR across all models: Likely data quality issues or incorrect temporal splits
  - Hybrid models underperforming: Static embeddings may be poor quality or not capturing relevant information
  - Community sampling giving inflated scores: Communities may be too large or not well-defined

- First 3 experiments:
  1. Run ComplEx on PG-1M with default hyperparameters to establish baseline
  2. Implement GraphSAGE-E on PG-1M to verify featureless inductive approach
  3. Compare random vs. community negative sampling on a small subset to validate proxy effectiveness

## Open Questions the Paper Calls Out

### Open Question 1
How do temporal dynamics affect knowledge graph completion performance when predicting future citations? The authors note that temporal transductive models "fall far behind the static models" due to their inability to generalize to unseen timestamps, but don't fully explain why this occurs. Systematic experiments varying temporal granularity, time gaps between training and testing periods, and analysis of temporal pattern recognition in KG models would resolve this.

### Open Question 2
What is the optimal negative sampling strategy for large-scale KG evaluation that balances computational efficiency with accurate performance measurement? The authors propose community-based negative sampling as an efficient proxy but note it only works when ground truth is known. Extensive comparison of different negative sampling strategies against full evaluation metrics across multiple KG sizes and tasks, including deployment scenarios, would resolve this.

### Open Question 3
How do different types of auxiliary information (e.g., author collaborations, venue prestige, institutional reputation) contribute to citation link prediction accuracy? The ablation study shows adding authors improves performance by 38% MRR, but the relative contributions of other node types and relationships are not fully explored. Controlled experiments varying which relationship types are included, measuring individual and combined effects on prediction accuracy across different KG scales, would resolve this.

## Limitations
- Community-based negative sampling strategy's effectiveness depends heavily on community detection quality, which was not fully specified in terms of parameters or validation
- Performance gap between hybrid and end-to-end inductive models may narrow if static embeddings are updated more frequently or if temporal dynamics are better captured
- Resource requirements for reproducing results are substantial, with DE-TransE requiring 120GB GPU memory for PG-10M

## Confidence

- High confidence: Static transductive models (ComplEx, RotatE) performance claims, as these are well-established methods with clear baselines
- Medium confidence: Hybrid inductive models outperforming end-to-end variants, as this depends on static embedding quality which wasn't fully characterized
- Medium confidence: Community-based sampling efficiency claims, as computational savings are demonstrated but effectiveness for model selection is assumed
