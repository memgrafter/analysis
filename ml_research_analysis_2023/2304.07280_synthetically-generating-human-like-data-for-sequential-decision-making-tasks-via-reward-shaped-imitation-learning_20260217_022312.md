# Synthetically Generating Human-like Data for Sequential Decision Making Tasks via Reward-Shaped Imitation Learning

## Quick Facts
- arXiv ID: 2304.07280
- Source URL: https://arxiv.org/abs/2304.07280
- Reference count: 38
- Primary result: Presents a technique to synthetically generate human-like decision making data for sequential tasks by integrating reward shaping from reinforcement learning with imitation learning

## Executive Summary
This paper introduces a novel approach for generating synthetic human-like decision-making data for sequential tasks. The method combines reward shaping from reinforcement learning with imitation learning, starting from a small set of human-generated data. The approach trains an expert agent and then generates synthetic trajectories that closely mimic human decision patterns. Experiments in maze navigation games demonstrate that the synthetic data achieves high similarity to human data as measured by METEOR scores, with imitation learning further improving trajectory quality beyond the expert agent alone.

## Method Summary
The core methodology integrates reward shaping from reinforcement learning with imitation learning to train an expert agent, which is then used to generate synthetic trajectories. The process begins with a small set of human-generated data that informs the reward shaping component. The expert agent learns from this shaped reward function and human demonstrations, then generates synthetic trajectories that capture human-like decision patterns. The imitation learning component further refines these trajectories by learning directly from human demonstrations, improving the quality and naturalness of the generated sequences.

## Key Results
- Synthetic trajectories achieve high similarity to human data as measured by METEOR scores in maze navigation tasks
- Imitation learning improves trajectory quality beyond what the expert agent alone can generate
- The method successfully demonstrates the potential for creating larger quantities of human decision-making data from small initial datasets

## Why This Works (Mechanism)
The method works by leveraging the strengths of both reinforcement learning and imitation learning. Reward shaping provides a structured learning signal that guides the agent toward desirable behaviors, while imitation learning ensures the agent's actions remain consistent with human patterns. This dual approach allows the system to generate data that is both behaviorally sound (through reward shaping) and human-like (through imitation). The initial human data serves as both a behavioral template and a source of reward signals, creating a feedback loop that produces increasingly natural synthetic trajectories.

## Foundational Learning
- **Reinforcement Learning**: Why needed - provides the framework for learning optimal behaviors through interaction with an environment; Quick check - agent improves performance over time through trial and error
- **Imitation Learning**: Why needed - enables learning directly from human demonstrations to capture human-like decision patterns; Quick check - agent can replicate demonstrated behaviors
- **Reward Shaping**: Why needed - transforms sparse or delayed rewards into more immediate and informative signals; Quick check - agent learns more efficiently with shaped rewards
- **METEOR Score**: Why needed - provides a metric for evaluating the similarity between generated and human trajectories; Quick check - higher scores indicate better human-likeness
- **Sequential Decision Making**: Why needed - the problem domain involves making a series of interdependent decisions; Quick check - current decision affects future state and options
- **Trajectory Generation**: Why needed - produces complete sequences of actions from start to goal; Quick check - generated paths are complete, coherent, and goal-directed

## Architecture Onboarding
- **Component Map**: Human Data -> Reward Shaping -> Expert Agent Training -> Imitation Learning -> Synthetic Trajectory Generation
- **Critical Path**: Human demonstrations → Reward function design → Expert agent training → Imitation learning refinement → Synthetic data generation
- **Design Tradeoffs**: Balancing between exploration (from RL) and exploitation (from imitation learning); choosing appropriate reward shaping functions that capture human preferences without over-constraining the agent
- **Failure Signatures**: Synthetic trajectories that deviate significantly from human patterns; poor convergence during training; reward shaping that creates unintended behaviors
- **First 3 Experiments**: 1) Compare METEOR scores between expert agent and imitation learning outputs, 2) Test synthetic data quality with varying amounts of initial human data, 3) Evaluate task performance when training on synthetic vs. human data

None

## Limitations
- Evaluation focuses on maze navigation tasks, a relatively narrow domain compared to potential applications
- Does not address generalization to complex, real-world sequential decision-making scenarios
- Reliance on human-generated data for initial training raises scalability concerns when such data is scarce or expensive

## Confidence
- High confidence: The core methodology combining reward shaping with imitation learning is technically sound and the experimental framework is well-structured
- Medium confidence: The claim that synthetic data can effectively substitute for human data is supported within the maze navigation domain but requires validation in more diverse applications
- Medium confidence: The assertion about laying foundation for applications in warfighter training and human assistants is plausible but not directly demonstrated in the current work

## Next Checks
1. Test the method across multiple sequential decision-making domains beyond maze navigation to assess generalizability
2. Conduct ablation studies to quantify the contribution of each component (reward shaping vs. imitation learning) to the final performance
3. Implement a user study comparing task performance when trained on synthetic versus human data to validate practical applicability
