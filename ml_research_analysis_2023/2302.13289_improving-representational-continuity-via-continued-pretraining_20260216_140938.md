# Improving Representational Continuity via Continued Pretraining

## Quick Facts
- arXiv ID: 2302.13289
- Source URL: https://arxiv.org/abs/2302.13289
- Reference count: 24
- Key outcome: LP-FT method consistently outperforms naive SGD under all adaptation methods and achieves state-of-the-art results on sequential CIFAR-10, CIFAR-100, TinyImageNet, and NLP continual learning benchmarks.

## Executive Summary
This paper addresses a critical issue in continual learning evaluation: existing kNN-based protocols overestimate model performance. Through systematic investigation, the authors demonstrate that when evaluated with proper adaptation methods, strong continual learning baselines can underperform naive training. They propose LP-FT (Linear Probe Fine-Tuning), a simple yet effective method that first trains a linear head on new tasks before fine-tuning the entire model. LP-FT consistently outperforms baselines across multiple benchmarks and provides more realistic performance estimates.

## Method Summary
The LP-FT method consists of a two-stage training process for continual learning. When presented with a new task, the method first trains a linear classifier head on frozen feature representations to find the optimal mapping for the new task. Only after this linear adaptation is complete does it fine-tune the entire model (both feature extractor and head) jointly. This approach is evaluated using three probe types: kNN classifier, linear probe, and LP-FT probe (fine-tuning the entire model). The method is designed to preserve representational continuity while adapting to new tasks with limited data.

## Key Results
- LP-FT consistently outperforms naive SGD across all evaluation protocols (kNN, linear probe, LPFT probe)
- Under proper evaluation with adaptation methods, strong continual learning baselines (SI, DER, UCL) can underperform naive SGD
- LP-FT achieves state-of-the-art results on sequential CIFAR-10, CIFAR-100, TinyImageNet, and NLP continual learning benchmarks
- Performance gains are most pronounced on larger datasets, with LP-FT showing 8.69% improvement over baselines on CIFAR-100 under kNN evaluation

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: LP-FT preserves learned representations better than naive SGD because it first finds an optimal linear head for the new task before fine-tuning the entire model.
- **Mechanism**: The initial linear head training finds the best linear combination of existing features for the new task without altering the feature extractor. Only after this stable mapping is established does the fine-tuning step update the full model, reducing distortion of previously learned representations.
- **Core assumption**: The feature extractor learned from prior tasks contains useful representations that can be linearly adapted to new tasks before deeper adaptation is needed.
- **Evidence anchors**: LP-FT first trains the head φ, and then jointly optimizes the entire model (φ,θ). Under the exact kNN evaluation protocol used in [14], LP-FT matches or outperforms continual learning methods.

### Mechanism 2
- **Claim**: LP-FT improves evaluation accuracy because it finds better probe classifiers when using the LPFT probe evaluation method.
- **Mechanism**: The LPFT probe trains a linear head and then fine-tunes the entire model on few-shot data, which is more expressive than simple linear probes or KNN classifiers. This allows it to better utilize the available data to find task-specific decision boundaries.
- **Core assumption**: The few-shot data contains enough information to guide meaningful fine-tuning that improves classification accuracy.
- **Evidence anchors**: We investigate three different options for probe: 1. Train a kNN classifier on frozen representations, 2. Train a linear probe on the model representations, 3. Fine-tune the entire model via LP-FT. Under the exact kNN evaluation protocol used in [14], LP-FT matches or outperforms continual learning methods.

### Mechanism 3
- **Claim**: LP-FT's effectiveness scales with dataset size because it can leverage more data to improve representations while maintaining stability.
- **Mechanism**: Larger datasets provide more signal for the initial linear head training to find good task mappings, and more data for the subsequent fine-tuning to incorporate task information without overfitting. This explains why the gap between LP-FT and SGD increases on larger datasets like TinyImageNet.
- **Core assumption**: The scaling behavior observed (better on C100 than C10, best on Tiny) generalizes across different dataset types and sizes.
- **Evidence anchors**: LPFT's numbers are generally more competitive for larger datasets... the gap between LPFT and SGD increases from 3.94% (KNN probe), 1.01% (linear probe) to 8.69% and 2.7% respectively on C100 compared to C10. On Tiny, we see LPFT to be the dominant method, achieving 7.28% and 1.67% on top of the second best methods under KNN (DER) and linear probe (SI) evaluations respectively.

## Architecture Onboarding

- **Component map**: Feature extractor (θ) -> Linear head (φ) -> Output. For NLP tasks, this extends to task-specific parameters in each encoder layer (e.g., task masks in B-CL).
- **Critical path**: For each new task: 1) Train task-specific head on frozen feature extractor, 2) Fine-tune entire model starting from the trained head, 3) Use LPFT probe for evaluation. The order is critical - head training must complete before fine-tuning begins.
- **Design tradeoffs**: LP-FT adds one additional training phase (head training) compared to naive SGD, increasing training time but potentially improving performance and reducing forgetting. It also requires storing intermediate checkpoints. The trade-off is between training efficiency and model quality.
- **Failure signatures**: If LP-FT performs worse than SGD, this could indicate: 1) The feature extractor has poor representations for the new task, 2) The few-shot data is too limited or unrepresentative, or 3) The learning rate schedule is inappropriate for the fine-tuning phase.
- **First 3 experiments**:
  1. Implement LP-FT on sequential CIFAR-10 with 5 tasks, comparing to naive SGD using the standard kNN evaluation protocol.
  2. Test LP-FT with different few-shot evaluation protocols (linear probe, LPFT probe) on the same CIFAR-10 setup to validate the evaluation protocol findings.
  3. Apply LP-FT to a small NLP continual learning benchmark (e.g., 2-3 tasks) using a pre-trained BERT model to verify cross-domain effectiveness.

## Limitations

- The method's effectiveness is most pronounced on larger datasets, suggesting limited benefits for smaller-scale problems
- The paper focuses primarily on vision and text classification tasks, leaving performance on other task types unexplored
- The two-stage training process increases computational overhead compared to simpler methods

## Confidence

**High Confidence**: The experimental methodology for comparing adaptation methods is sound, and the finding that kNN evaluation overestimates performance is well-supported. The LP-FT method's consistent improvement across benchmarks is statistically robust.

**Medium Confidence**: The claim that LP-FT fundamentally improves representational continuity is supported by empirical results but lacks theoretical justification. The mechanism by which LP-FT preserves representations better than alternatives could be more thoroughly analyzed.

**Low Confidence**: The paper's assertion that most continual learning research overstates performance improvements due to evaluation protocol issues, while compelling, would require systematic re-evaluation of a broader range of methods to be definitive.

## Next Checks

3. Test LP-FT on non-standard continual learning scenarios including domain-incremental learning and class-incremental learning with imbalanced data to assess robustness beyond the evaluated settings.
