# In or Out? Fixing ImageNet Out-of-Distribution Detection Evaluation

## Quick Facts
- arXiv ID: 2306.00826
- Source URL: https://arxiv.org/abs/2306.00826
- Reference count: 40
- One-line primary result: Current OOD datasets contain significant ID contamination, and feature-based methods outperform baselines when evaluated on clean data.

## Executive Summary
This paper addresses the critical issue of evaluating out-of-distribution (OOD) detection performance for ImageNet-1K, revealing that commonly used test OOD datasets contain significant contamination from ImageNet-1K classes. The authors introduce NINCO, a novel OOD dataset with 5,879 manually verified ID-free images across 64 classes, along with synthetic "OOD unit-tests" to expose detector weaknesses. Evaluations across 11 OOD detection methods and 26 model variants show that many methods perform better than previously thought when evaluated on clean data, with feature-based methods consistently outperforming baselines. The study provides a more accurate benchmark for OOD detection development.

## Method Summary
The authors systematically evaluated 11 OOD detection methods across 26 model variants, including Vision Transformers, ConvNext, EfficientNets, and CLIP models with various pretraining schemes. They created NINCO, a manually curated OOD dataset with 5,879 ID-free images across 64 classes, and generated synthetic "OOD unit-tests" to probe detector robustness. The evaluation used standard metrics (FPR@TPR95, AUROC, AUPR) and compared performance on contaminated existing datasets versus the cleaned NINCO dataset. The study also analyzed how pretraining on datasets like ImageNet-21K affects OOD detection performance when combined with different detection methods.

## Key Results
- Over 50% of commonly used OOD test datasets contain ImageNet-1K class contamination, distorting evaluation results
- Feature-based methods (Mahalanobis, Relative Mahalanobis, ViM) consistently outperform non-feature-based baselines
- Many detector-model combinations fail on simple synthetic unit-tests despite good performance on natural OOD data
- IN-21K pretraining improves detection when combined with appropriate methods, but training scheme matters more than pretraining itself

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Many OOD detection methods fail on synthetic "unit-tests" because they rely on feature embeddings that break down for simple, non-photorealistic inputs like black, white, or uniform noise.
- Mechanism: Feature-based OOD detectors compute distances or logits in a learned feature space. If the model's feature extractor is tuned for natural images, its embeddings for synthetic inputs become unreliable, causing these detectors to fail.
- Core assumption: Pretrained feature extractors encode only natural image statistics and lack robustness to synthetic patterns.
- Evidence anchors:
  - [abstract]: "many OOD detectors struggle to detect these supposedly easy unit-tests, in particular methods that work well on natural test data"
  - [section 4.2]: "Especially for methods relying on feature representations (like ViM and Maha) the OOD unit-tests reveal difficulties."
- Break condition: If a feature extractor is trained to be invariant to synthetic patterns or if synthetic data is added to pretraining, these failures may be reduced.

### Mechanism 2
- Claim: ID contamination in test OOD datasets systematically underestimates OOD detector performance by counting correct rejections of ID samples as false positives.
- Mechanism: If test OOD data contains samples from ID classes, better models (which recognize ID content confidently) are "punished" more than weaker models, distorting evaluation metrics like FPR.
- Core assumption: Current OOD detection evaluations assume all test OOD samples are truly OOD, with no ID contamination.
- Evidence anchors:
  - [abstract]: "more than 50% of the dataset contains objects belonging to one of the ID classes...These erroneous samples heavily distort the evaluation of OOD detectors."
  - [section 2.2]: "A better model can correctly recognize ID objects with high confidence...leading to a false 'false positive' in the evaluation."
- Break condition: If the assumption that OOD datasets are ID-free is violated, the mechanism fails.

### Mechanism 3
- Claim: Pretraining on large datasets like IN-21K improves OOD detection performance, but the type of pretraining matters more than pretraining itself.
- Mechanism: Pretraining provides better feature embeddings for OOD detection, especially when combined with feature-based methods. However, the specific architecture and training procedure (e.g., CLIP vs. traditional IN-21K pretraining) affects how useful these features are for OOD tasks.
- Core assumption: Larger pretraining datasets yield more generalizable features that improve OOD detection.
- Evidence anchors:
  - [abstract]: "IN-21K pretraining improves detection when combined with appropriate methods"
  - [section 4.1]: "surprisingly, it turns out to be difficult for many OOD detectors to improve consistently over the baseline... pretraining helps in two ways"
- Break condition: If the pretraining data is not sufficiently diverse or if the downstream task requires different features, benefits may be limited.

## Architecture Onboarding

- Component map:
  Dataset curation: NINCO (ID-free OOD classes), synthetic unit-tests
  Model zoo: ViT, ConvNext, BiT, EfficientNet variants with various pretraining schemes
  OOD detection methods: MSP, MaxLogit, Energy, KL-Matching, Mahalanobis, Relative Mahalanobis, ViM, KNN, Cosine, MCM/RCos
  Evaluation pipeline: FPR@TPR95, AUROC, AUPR metrics, class-wise breakdowns

- Critical path:
  1. Curate ID-free OOD dataset (NINCO)
  2. Generate synthetic unit-tests
  3. Train or load pretrained models
  4. Apply OOD detection methods
  5. Evaluate using FPR@TPR95 and other metrics
  6. Analyze failures and compare methods/models

- Design tradeoffs:
  - Manual dataset curation ensures ID-free data but is labor-intensive.
  - Synthetic unit-tests expose weaknesses but don't reflect real-world complexity.
  - Pretrained models generally perform better, but some training schemes are more beneficial than others.

- Failure signatures:
  - High FPR on NINCO classes or synthetic unit-tests indicates detector/model weakness.
  - Large discrepancy between FPR on cleaned vs. contaminated datasets suggests ID contamination.
  - Certain detectors failing on black/white/monochrome inputs signals lack of synthetic robustness.

- First 3 experiments:
  1. Evaluate a baseline model (e.g., ViT-B-384-21k) with MSP on NINCO and compare FPR@TPR95 to cleaned subsets of existing datasets.
  2. Test a feature-based method (e.g., Mahalanobis) on the same model and datasets; observe improvements or failures on unit-tests.
  3. Compare OOD detection performance on NINCO classes with and without overlap with IN-21K to assess pretraining impact.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the effectiveness of OOD detection methods vary when applied to classes in NINCO that overlap with ImageNet-21K versus those that don't?
- Basis in paper: [explicit] The authors evaluated the performance of different OOD detection methods on classes with and without overlap with ImageNet-21K, noting that most methods perform better on classes with overlap.
- Why unresolved: While the paper provides some insights, it does not deeply analyze the reasons behind the performance differences or how these might impact the generalizability of OOD detection methods.
- What evidence would resolve it: A detailed analysis comparing the performance of OOD detection methods across different types of class overlaps, including a study on the impact of class semantics and feature space similarity.

### Open Question 2
- Question: What are the specific weaknesses of feature-based OOD detection methods when applied to synthetic "OOD unit-tests"?
- Basis in paper: [explicit] The paper highlights that many feature-based methods struggle with certain synthetic OOD unit-tests, particularly those involving simple images like black, white, and grey.
- Why unresolved: The paper identifies the problem but does not explore the underlying causes or potential solutions for these weaknesses.
- What evidence would resolve it: A systematic study identifying the specific features or patterns in the unit-tests that cause these methods to fail, and experiments testing modifications to these methods to improve their robustness.

### Open Question 3
- Question: How does the choice of pretraining dataset (e.g., ImageNet-21K vs. JFT-300M) impact the effectiveness of OOD detection methods?
- Basis in paper: [explicit] The paper discusses the impact of different pretraining strategies on OOD detection performance, noting that IN-21K pretraining generally improves results, but the effect of other datasets like JFT-300M is less clear.
- Why unresolved: The paper does not provide a comprehensive comparison of different pretraining datasets or explore the mechanisms behind their effects on OOD detection.
- What evidence would resolve it: A large-scale study comparing OOD detection performance across multiple pretraining datasets, along with an analysis of how different pretraining strategies affect the feature space and model robustness.

### Open Question 4
- Question: Can the NINCO dataset be extended to cover a broader range of OOD classes without introducing ID contamination?
- Basis in paper: [explicit] The paper introduces NINCO as a solution to the ID contamination problem but acknowledges the challenge of sourcing truly OOD classes from ImageNet-1K.
- Why unresolved: The paper does not explore methods for expanding NINCO or discuss the potential for future datasets that could address the limitations of current OOD detection benchmarks.
- What evidence would resolve it: A framework for systematically identifying and validating new OOD classes, possibly leveraging advances in automated data curation or crowd-sourced verification to ensure ID-free samples.

## Limitations

- The study's conclusions depend on the assumption that NINCO's manual curation is exhaustive and free of ID contamination, with no statistical validation of this verification process
- Synthetic unit-tests represent idealized failure modes that may not reflect real-world OOD scenarios and their practical relevance is unclear
- The focus on ImageNet-1K as the ID distribution limits generalizability to other classification tasks and domains

## Confidence

**Major claim clusters confidence:**
- **High**: ID contamination in existing OOD datasets significantly distorts evaluation metrics; NINCO provides cleaner evaluation data
- **Medium**: Feature-based methods consistently outperform baselines across model variants; pretraining improves detection when combined with appropriate methods
- **Low**: Synthetic unit-tests reliably predict real-world OOD detection performance; failures on unit-tests indicate fundamental limitations of feature-based methods

## Next Checks

1. Conduct statistical validation of NINCO's manual curation process, including inter-rater reliability tests and random sampling audits to confirm ID-free status
2. Test the same OOD detection methods on non-ImageNet classification tasks (e.g., CIFAR-10/100) to assess generalizability of findings
3. Compare performance on synthetic unit-tests versus real-world OOD distributions to quantify the practical relevance of unit-test failures
