# Inverse Reinforcement Learning With Constraint Recovery

## Quick Facts
- arXiv ID: 2305.08130
- Source URL: https://arxiv.org/abs/2305.08130
- Authors: 
- Reference count: 24
- One-line primary result: Algorithm successfully recovers reward and constraint functions from expert demonstrations in a grid-world environment

## Executive Summary
This paper addresses the problem of inverse reinforcement learning with constraint recovery (IRL-CR) in constrained Markov decision processes (CMDPs). The method proposes a novel approach to recover both the reward and constraint functions from expert demonstrations using the principle of maximum entropy. By formulating a constrained non-convex optimization problem and solving it through alternating convex subproblems with exponentiated gradient descent, the algorithm demonstrates successful recovery of both functions in a grid-world environment.

## Method Summary
The algorithm takes trajectory demonstrations of optimal policy for a CMDP, along with known initial state distribution, state transition probabilities, and discount factor. It formulates a constrained non-convex optimization problem using maximum entropy principle, where the goal is to recover reward and constraint function parameters that make the maximum entropy distribution over trajectories match the empirical feature expectations from demonstrations. The method reduces the problem to alternating convex subproblems solved via exponentiated gradient descent with Bregman projection to ensure parameter constraints. The algorithm iteratively computes optimal policy for current parameters, updates state visitation frequencies, calculates policy feature expectations, and updates parameters until convergence.

## Key Results
- Successfully recovers both reward and constraint functions from expert demonstrations
- Matching empirical and policy feature expectations ensures recovered functions produce same trajectory distribution as expert
- Algorithm works with reasonable sample sizes (100 samples with T = 2000)
- Qualitative matching of expert's optimal policy demonstrated in grid-world environment

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Algorithm successfully recovers both reward and constraint functions by matching empirical and policy feature expectations using maximum entropy IRL
- Core assumption: Expert demonstrations are generated by optimal policy under true CMDP with known meaningful state feature vectors
- Break condition: Suboptimal demonstrations or exploration noise prevent accurate feature expectation matching

### Mechanism 2
- Claim: Alternating optimization with exponentiated gradient descent efficiently solves non-convex problem by reducing to convex subproblems
- Core assumption: CMDP has finite horizon T and known transition dynamics
- Break condition: Short horizons relative to task complexity lead to poor local optima

### Mechanism 3
- Claim: Linear function approximation of reward and constraint functions makes problem tractable while maintaining expressiveness
- Core assumption: True functions can be well-approximated by linear combinations of provided state features
- Break condition: Nonlinear relationships between true functions and state features lead to insufficient recovery

## Architecture Onboarding

- Component map:
  - Feature extractor: Computes state feature vectors Φr(s) and Φc(s)
  - Policy optimizer: Finds optimal policy for given reward/constraint parameters
  - State visitation calculator: Computes dt(s) using recursive equations
  - Feature expectation calculator: Computes empirical and policy feature expectations
  - Parameter updater: Applies exponentiated gradient descent with projection
  - Convergence checker: Monitors parameter changes for stopping condition

- Critical path:
  1. Initialize parameters wr, wc
  2. Compute empirical feature expectations from demonstrations
  3. Alternate between: Policy optimization, state visitation frequency computation, policy feature expectation calculation, parameter update via gradient descent, parameter projection
  4. Check convergence and return parameters

- Design tradeoffs:
  - Linear vs nonlinear function approximation: Linear is tractable but may lack expressiveness
  - Horizon length T: Longer horizons improve policy representation but increase computational cost
  - Sample size: More demonstrations improve estimation but increase data requirements

- Failure signatures:
  - Slow convergence: May indicate poor initialization or need for larger T
  - Oscillating parameters: Could suggest learning rate is too high or projection is causing issues
  - Recovered policy doesn't match expert: May indicate insufficient expressiveness of linear approximation

- First 3 experiments:
  1. Run with known parameters (synthetic data) to verify recovery accuracy
  2. Vary horizon length T to observe impact on convergence quality
  3. Test with different feature vector choices to assess sensitivity to representation choice

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does performance of IRL-CR algorithm scale with number of constraints in CMDP?
- Basis in paper: Extension to more than one constraint is stated as straightforward but not experimentally validated
- Why unresolved: Authors only consider single constraint in experiments
- What evidence would resolve it: Experiments comparing performance across CMDPs with varying numbers of constraints

### Open Question 2
- Question: What is impact of trajectory length T on accuracy of constraint recovery?
- Basis in paper: Authors observe increasing T increases accuracy but don't provide quantitative analysis
- Why unresolved: Relationship between trajectory length and accuracy not precisely characterized
- What evidence would resolve it: Systematic experiments measuring constraint recovery error as function of T

### Open Question 3
- Question: How does IRL-CR algorithm perform when feature representation is unknown or learned from data?
- Basis in paper: Authors mention representation learning needs to be employed for real-world settings
- Why unresolved: Current algorithm assumes known feature representations which is often unrealistic
- What evidence would resolve it: Experiments comparing performance using ground-truth vs learned feature representations

## Limitations

- Algorithm validated only on single grid-world domain with linear function approximations
- Assumes expert demonstrations are generated by optimal policy under true CMDP
- Convergence properties of alternating optimization not formally analyzed
- No guarantees about finding global optima versus poor local optima
