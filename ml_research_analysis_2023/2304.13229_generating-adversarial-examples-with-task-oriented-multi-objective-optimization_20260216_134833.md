# Generating Adversarial Examples with Task Oriented Multi-Objective Optimization

## Quick Facts
- arXiv ID: 2304.13229

## Executive Summary
This paper addresses the challenge of generating adversarial examples that satisfy multiple objectives/goals, which naturally leads to a multi-objective optimization (MOO) setting. However, a naive application of MOO tends to focus too much on dominating tasks and ignores underperforming ones. To address this issue, the authors propose a Task Oriented MOO (TA-MOO) framework that maintains the performance of goal-achieved tasks while spending more effort on improving goal-unachieved tasks. The key idea is to incorporate a geometry-based regularization term that represents the distance between the original simplex and a reduced simplex involving the weight vectors for the currently unsuccessful tasks only.

## Method Summary
The paper proposes a Task Oriented Multi-Objective Optimization (TA-MOO) framework for generating adversarial examples that satisfy multiple objectives. The method uses a geometry-based regularization term that represents the distance between the original simplex and a reduced simplex involving the weight vectors for the currently unsuccessful tasks only. The framework updates task weights using gradient descent with softmax parameterization and incorporates the regularization term to focus optimization on goal-unachieved tasks while maintaining performance on goal-achieved tasks. The approach is evaluated on various adversarial example generation schemes, including attacking multiple models, learning universal perturbation, and attacking over many data transformations.

## Key Results
- TA-MOO outperforms the baselines by a wide margin on three adversarial generation tasks
- The proposed approach demonstrates effectiveness in attacking ensemble models, learning universal perturbations, and attacking over data transformations
- Experimental results show improved performance on goal-unachieved tasks while maintaining success on goal-achieved tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Standard MOO tends to focus optimization on tasks with strongest gradients, neglecting underperforming tasks.
- Mechanism: In MOO, tasks are weighted based on gradient strengths. Tasks with larger gradients dominate the optimization, while tasks with weaker gradients receive less attention, leading to imbalanced performance across objectives.
- Core assumption: Tasks with weak gradients correspond to objectives that are already close to being achieved.
- Evidence anchors:

  - [section]: "The optimizing process focuses too much on one dominating task and can be trapped easily by it"

- Break condition: If gradient strengths are similar across tasks, the dominating effect diminishes.

### Mechanism 2
- Claim: TA-MOO uses a geometry-based regularization to focus optimization on goal-unachieved tasks while maintaining performance on goal-achieved tasks.
- Mechanism: TA-MOO introduces a regularization term that minimizes the distance between the current weight vector and a reduced simplex containing only weights for goal-unachieved tasks. This encourages weights for successful tasks to be small while keeping the sum of weights for unsuccessful tasks close to 1.
- Core assumption: We can explicitly determine whether each task has achieved its goal (e.g., whether an adversarial example successfully attacks a model).
- Evidence anchors:
  - [abstract]: "incorporate a geometry-based regularization term that represents the distance between the original simplex and a reduced simplex involving the weight vectors for the currently unsuccessful tasks only"
  - [section]: "To favor the unsuccessful tasks while maintaining the success of the successful ones, we propose a geometry-based regularization term"

- Break condition: If task goal achievement cannot be explicitly determined, this mechanism fails.

### Mechanism 3
- Claim: TA-MOO's regularization helps overcome the gradient domination problem by providing a supervised signal.
- Mechanism: While standard MOO relies solely on gradient strengths to assign weights, TA-MOO uses task achievement status as an additional signal. This allows it to focus on improving tasks that haven't achieved their goals, even if their gradients are weak.
- Core assumption: Task achievement status is a better indicator of which tasks need more optimization effort than gradient strength alone.
- Evidence anchors:

- Break condition: If task achievement status is unreliable or cannot be determined, this mechanism fails.

## Architecture Onboarding

- Component map:
  Adversarial example generator -> Task weight optimizer -> Goal achievement detector -> Geometry-based regularization

- Critical path:
  1. Compute gradients for all tasks
  2. Update task weights using geometry-based regularization
  3. Compute combined gradient using weighted sum
  4. Update adversarial example
  5. Project to valid space

- Design tradeoffs:
  - Computational cost vs. performance: TA-MOO requires additional computation for weight updates and regularization
  - Task goal determination: Requires explicit definition of what constitutes task achievement
  - Gradient domination sensitivity: Performance depends on gradient strength differences across tasks

- Failure signatures:
  - Gradient domination: One task dominates optimization, leading to poor performance on other tasks
  - Incorrect goal detection: Misclassifying task achievement status leads to wrong weight assignments
  - Numerical instability: Issues with gradient computation or projection operations

- First 3 experiments:
  1. Test on simple ensemble of 2-3 models with clear goal achievement criteria
  2. Compare against uniform weighting baseline on same ensemble
  3. Test sensitivity to regularization parameter λ on a simple case
