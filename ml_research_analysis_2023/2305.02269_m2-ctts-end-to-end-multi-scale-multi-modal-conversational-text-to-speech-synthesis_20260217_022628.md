# M2-CTTS: End-to-End Multi-scale Multi-modal Conversational Text-to-Speech Synthesis

## Quick Facts
- arXiv ID: 2305.02269
- Source URL: https://arxiv.org/abs/2305.02269
- Reference count: 0
- This paper proposes M2-CTTS, an end-to-end multi-scale multi-modal conversational text-to-speech system that comprehensively utilizes historical conversation and enhances prosodic expression.

## Executive Summary
This paper introduces M2-CTTS, an end-to-end multi-scale multi-modal conversational text-to-speech system designed to enhance prosodic expression by comprehensively utilizing historical conversation context. The system employs both textual and acoustic context modules with coarse-grained and fine-grained modeling to capture utterance-level prosody trends and local emphasis. Experimental results on the DailyTalk dataset demonstrate improved naturalness and prosody performance compared to baseline systems, particularly when combining fine-grained context information with acoustic features.

## Method Summary
M2-CTTS is built on a FastSpeech2 backbone with additional Textual Context Module (TCM) and Acoustic Context Module (ACM), each containing utterance-level and phoneme-level submodules. The system uses multi-head cross-modal attention to identify important local context features, and incorporates Style-Adaptive Layer Normalization (SALN) in the decoder for conditional prosody generation. The model is trained on the DailyTalk dataset with 400K steps using batch size 16 on GeForceRTX 3090.

## Key Results
- CMOS tests show M2-CTTS achieves 0.07 and 0.15 improvements over baseline for naturalness and expressiveness
- The model mixed with fine-grained context information and acoustic features demonstrates better prosody performance
- Five-scale MOS tests confirm quality and naturalness improvements over baseline systems

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Coarse-grained modeling captures utterance-level prosody trends while fine-grained modeling captures local emphasis and keyword prosody.
- Mechanism: The system uses separate modules (TUM, WUM for coarse-grained; TPM, WPM for fine-grained) to extract both global utterance prosody and local phoneme-level prosody features. The coarse modules aggregate entire utterances, while the fine modules use multi-head cross-modal attention to identify important local elements.
- Core assumption: Utterance-level prosody and phoneme-level prosody provide complementary information that can be combined to produce more natural conversational speech.
- Evidence anchors: [abstract] "we design a textual context module and an acoustic context module with both coarse-grained and fine-grained modeling" [section 2.1] "Although global information like emotions or intentions allows the model to understand the conversation, detailed information like keywords or emphasis that include strong or implicit meanings should also be highlighted."

### Mechanism 2
- Claim: Multi-modal context modeling (text + acoustic) provides richer conversational context than single-modal approaches.
- Mechanism: The system extracts both textual features (using BERT) and acoustic features (using Wav2vec 2.0) from historical conversations, then combines them through separate encoders and attention mechanisms.
- Core assumption: Acoustic prosody contains complementary information to textual semantics that improves conversational TTS naturalness.
- Evidence anchors: [abstract] "it is insufficient to only consider the textual features, and acoustic features also contain various prosody information" [section 2.2] "in addition to semantic and syntactic features, paralinguistic information like acoustic prosodic cues also play an important role in context understanding"

### Mechanism 3
- Claim: Style-Adaptive Layer Normalization (SALN) with conditional decoding enhances expressiveness by infusing prosody information into the decoder.
- Mechanism: SALN dynamically adjusts normalization parameters based on prosody embeddings, allowing the decoder to generate speech with appropriate style variations.
- Core assumption: Directly conditioning the decoder on prosody embeddings through adaptive normalization improves the naturalness and expressiveness of generated speech.
- Evidence anchors: [abstract] "we use Style-Adaptive Layer Normalization (SALN) [5] to infuse prosody information" [section 2.3] "we adopt Style-Adaptive Layer Normalization (SALN) [5] in decoder as Conditional Decoder to increase the expressiveness and better utilize the history context"

## Architecture Onboarding

- Component map: Input text → Encoder → Context modules (TCM + ACM) → Conditional Decoder → Output mel spectrogram
- Critical path: Input text → Encoder → Context modules (TCM + ACM) → Conditional Decoder → Output mel spectrogram
- Design tradeoffs:
  - Complexity vs. performance: Adding fine-grained modules increases model complexity but provides better prosody
  - Modality fusion: How to effectively combine textual and acoustic information without losing important features
  - Attention mechanism choice: Multi-head vs. single-head for local feature identification
- Failure signatures:
  - Poor prosody matching: Context modules not effectively capturing conversational cues
  - Training instability: SALN conditioning causing normalization issues
  - Slow convergence: Complex architecture making training difficult
- First 3 experiments:
  1. Baseline comparison: FastSpeech2 without context modules to establish performance floor
  2. Single-modality test: Implement only textual context module to verify modality importance
  3. Coarse vs. fine-grained ablation: Compare systems with only coarse-grained modules vs. both coarse and fine-grained to measure contribution of fine-grained modeling

## Limitations
- Limited speaker diversity with only Mandarin conversations between one female and one male speaker
- CMOS tests conducted with only 20 subjects and lack of objective prosody metrics
- Incomplete ablation study design makes it difficult to isolate the contribution of fine-grained modeling

## Confidence
- High Confidence: The architectural framework and implementation approach are technically sound and follow established practices in conversational TTS
- Medium Confidence: The effectiveness of the coarse-grained vs. fine-grained modeling distinction is plausible but not conclusively demonstrated
- Low Confidence: The claim that M2-CTTS significantly outperforms baseline systems in naturalness and expressiveness is weakly supported by subjective CMOS tests
