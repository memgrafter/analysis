# SERT: A Transfomer Based Model for Spatio-Temporal Sensor Data with Missing Values for Environmental Monitoring

## Quick Facts
- arXiv ID: 2306.03042
- Source URL: https://arxiv.org/abs/2306.03042
- Reference count: 4
- Primary result: SERT achieves competitive or superior performance compared to state-of-the-art methods, with lower RMSE in 7-hour ahead forecasting

## Executive Summary
This paper proposes SERT and SST-ANN, transformer-based models for multivariate spatio-temporal forecasting with missing values. The models use triplet encoding (time, variable, value) and attention mechanisms to handle missing data without imputation. Experiments on simulated and real environmental monitoring data show that SERT achieves competitive or superior performance compared to state-of-the-art methods, with lower RMSE in 7-hour ahead forecasting. SST-ANN provides interpretability via contribution scores for variable importance analysis. Both models handle missing values naturally, and SST-ANN offers faster computation and insights into feature contributions.

## Method Summary
The paper introduces SERT (Spatio-Temporal Encoder Representations) and SST-ANN (Spatio-Temporal Artificial Neural Network) for multivariate time series forecasting with missing values. Both models use triplet encoding where each observation is represented as (time, variable name, value) embeddings summed together. SERT uses transformer encoder layers while SST-ANN uses direct linear layers. A masked MSE loss function handles missing values by computing loss only on observed values. SST-ANN additionally provides interpretability through contribution scores that quantify variable importance.

## Key Results
- SERT achieves competitive or superior performance compared to state-of-the-art methods
- SERT shows lower RMSE in 7-hour ahead forecasting on both simulated and real environmental monitoring data
- SST-ANN provides interpretability via contribution scores for variable importance analysis
- Both models handle missing values naturally without imputation
- SST-ANN offers faster computation while providing insights into feature contributions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Triplet encoding (time, variable, value) allows the model to represent multivariate time series naturally without alignment.
- Mechanism: Each observation is embedded as a sum of embeddings for its time, variable name, and value, enabling direct input to transformers without prior alignment or imputation.
- Core assumption: The embedding space can capture the semantic relationships between time, variable identity, and value magnitude.
- Evidence anchors:
  - [abstract]: "The models use triplet encoding (time, variable, value) and attention mechanisms to handle missing data without imputation."
  - [section]: "An individual data point 𝑖 is represented as a triplet (𝑡𝑖, 𝑓𝑖, 𝑣𝑖) where 𝑡𝑖 is time, 𝑓𝑖 is the variable name and 𝑣𝑖 is the measured value..."
  - [corpus]: Weak evidence; no direct citations to prior work validating triplet embedding for spatio-temporal data.
- Break condition: If the embedding dimensions are too small to capture variable-specific patterns, the model may fail to distinguish between different variables.

### Mechanism 2
- Claim: Masked loss function enables training without imputation by ignoring missing target values.
- Mechanism: The loss is computed only over observed values using a binary mask, so the model learns from available data and does not propagate errors from missing values.
- Core assumption: The training data contains enough observed values to learn meaningful patterns.
- Evidence anchors:
  - [section]: "We use a masked Mean Squared Error (MSE) loss function to train our models. Masking in the loss function is used to handle missing values in the output data."
  - [abstract]: "Both models handle missing values naturally, and SST-ANN offers faster computation and insights into feature contributions."
  - [corpus]: Weak evidence; no prior work cited showing effectiveness of masked loss in transformer-based forecasting.
- Break condition: If the missingness is too high, the masked loss may result in insufficient gradient signals for training.

### Mechanism 3
- Claim: SST-ANN provides interpretability via contribution scores by using embeddings directly in the output layer.
- Mechanism: The model computes contributions of each observation by multiplying embeddings with output layer weights, then aggregates to variable importance.
- Core assumption: The contribution scores are proportional to the actual influence of input variables on predictions.
- Evidence anchors:
  - [section]: "We can compute the importance of each variable by normalizing the absolute value of the average contribution values for the variables."
  - [abstract]: "SST-ANN provides interpretability via contribution scores for variable importance analysis."
  - [corpus]: Weak evidence; the only related work (Tipirneni & Reddy 2022) is not cited for this specific mechanism.
- Break condition: If the model is overparameterized, contributions may be spurious and not reflect true importance.

## Foundational Learning

- Concept: Embedding techniques for categorical and continuous variables.
  - Why needed here: The triplet encoding requires mapping time, variable names, and values into a common vector space.
  - Quick check question: What is the difference between a lookup embedding for variable names and a continuous value embedding for time?

- Concept: Attention mechanisms in transformers.
  - Why needed here: The encoder captures long-range dependencies across variables and time without recurrence.
  - Quick check question: How does multi-head self-attention help the model learn both local and global patterns in the data?

- Concept: Handling missing data in supervised learning.
  - Why needed here: The model must learn from incomplete data without imputation, using masking in both input and loss.
  - Quick check question: What is the difference between a masked input and a masked loss, and why are both used here?

## Architecture Onboarding

- Component map: Triplet encoding (time, variable, value) → embeddings → Transformer encoder layers (SERT) or direct linear layer (SST-ANN) → Linear layer → Predictions → Contribution scores (SST-ANN only)
- Critical path:
  For SERT: Triplet encoding → Transformer encoder → Linear layer → Predictions
  For SST-ANN: Triplet encoding → Linear layer → Predictions → Contribution scores
- Design tradeoffs:
  - SERT: More accurate but slower due to transformer layers; less interpretable.
  - SST-ANN: Faster, interpretable via contributions, but less accurate.
- Failure signatures:
  - Low RMSE but high variance: Possible overfitting due to transformer complexity.
  - Poor performance with high sparsity: Masked loss insufficient when too many values missing.
  - Inconsistent contribution scores: Overparameterization causing spurious importance.
- First 3 experiments:
  1. Train SST-ANN on fully observed synthetic data and verify contribution scores align with known variable importance.
  2. Train SERT with varying transformer depths and compare RMSE on a held-out set.
  3. Increase missingness level in synthetic data and plot RMSE vs. sparsity for both models.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does incorporating spatial distance information between monitoring locations affect model performance and interpretability?
- Basis in paper: Explicit - The paper states this is a limitation and mentions that future research should focus on incorporating distance information between locations.
- Why unresolved: The authors did not test models that account for spatial distance between locations, and the two location encoding methods used do not consider this factor.
- What evidence would resolve it: Experimental results comparing model performance (RMSE, computational efficiency) between models with and without spatial distance encoding, and analysis of how distance information affects contribution scores and variable importance.

### Open Question 2
- Question: What is the optimal balance between model complexity and interpretability for environmental monitoring applications?
- Basis in paper: Explicit - The paper presents both SERT (complex, accurate) and SST-ANN (simpler, interpretable) models and discusses the trade-off between accuracy and interpretability.
- Why unresolved: The paper demonstrates both approaches but doesn't provide a framework for determining when to prioritize accuracy versus interpretability, or how to quantify this trade-off for different environmental monitoring scenarios.
- What evidence would resolve it: A systematic study evaluating model selection criteria across various environmental monitoring scenarios, including case studies showing when interpretability outweighs accuracy gains, and vice versa.

### Open Question 3
- Question: How do different missing data patterns (e.g., random vs. systematic sensor failures) affect model performance?
- Basis in paper: Inferred - While the paper evaluates performance under different sparsity levels, it doesn't examine how the spatial or temporal patterns of missing data affect model performance.
- Why unresolved: The paper only considers random removal of observations at different sparsity levels, not specific missing data patterns that might occur in real environmental monitoring scenarios.
- What evidence would resolve it: Experiments comparing model performance under various missing data patterns (random, clustered, seasonal, sensor-specific), and analysis of how different patterns affect the attention mechanisms and contribution scores in the proposed models.

## Limitations

- The experimental validation relies heavily on simulated data with controlled missingness patterns, which may not fully capture real-world complexity.
- The paper lacks ablation studies to isolate the contribution of the triplet encoding scheme versus the transformer architecture itself.
- The contribution score interpretability mechanism for SST-ANN is not rigorously validated against ground-truth variable importance.

## Confidence

- **High confidence**: The core mechanism of using triplet encoding with masked loss for handling missing values is well-specified and theoretically sound.
- **Medium confidence**: The comparative performance claims against baseline models are supported by experimental results, though the choice of baselines and evaluation conditions could be more comprehensive.
- **Low confidence**: The interpretability claims for SST-ANN's contribution scores lack rigorous validation and may be sensitive to model architecture choices.

## Next Checks

1. Conduct ablation studies comparing triplet encoding with alternative missing value handling approaches (e.g., mean imputation + standard transformer) on the same datasets.
2. Validate SST-ANN's contribution scores by creating synthetic scenarios with known variable importance and testing whether the model correctly identifies them.
3. Test model robustness by evaluating performance across different missingness mechanisms (MCAR, MAR, MNAR) rather than just varying sparsity levels.
