# Two-step counterfactual generation for OOD examples

## Quick Facts
- arXiv ID: 2302.05196
- Source URL: https://arxiv.org/abs/2302.05196
- Reference count: 40
- Key outcome: Two-step counterfactual generation achieves lower L1 distances and better realism than baselines for explaining OOD classifications

## Executive Summary
This paper addresses the problem of explaining why machine learning models classify data as out-of-distribution (OOD) by introducing OOD counterfactuals - perturbed data points that move between different OOD categories through a two-step process. The method separates latent features into non-discriminative and discriminative partitions, then perturbs each partition separately to make them more similar to in-distribution (ID) data. Experiments on synthetic and benchmark datasets show that this approach generates counterfactuals that are more realistic and have lower L1 distances compared to baseline methods, while maintaining data similarity to the ID distribution.

## Method Summary
The method decomposes learned latent features into two types - non-discriminative and discriminative partitions - then applies a two-step perturbation process. In the first step, non-discriminative features are perturbed to minimize negative log-likelihood (NLL) under a Gaussian Mixture Model (GMM) fitted to ID data. In the second step, discriminative features are similarly perturbed. This approach allows counterfactuals to move across OOD categories (far-OOD → near-OOD → ID) while maintaining realism through GMM-based likelihood maximization. The method uses PCA for initial feature extraction and QDA for partitioning features based on conditional entropy.

## Key Results
- OOD counterfactuals achieved lower negative log-likelihood and AUROC values compared to baseline methods
- The two-step approach consistently produced lower L1 distances to original data points
- Counterfactuals successfully moved across different OOD categories (far-OOD, near-OOD, ID) through the perturbation process

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Separating latent features into non-discriminative and discriminative partitions enables targeted counterfactual generation
- Mechanism: The method decomposes latent features into two partitions, then perturbs each partition separately to make them more similar to ID data distributions. This two-step process allows counterfactuals to move across different OOD categories (far-OOD → near-OOD → ID).
- Core assumption: Latent features can be meaningfully partitioned into class-irrelevant (non-discriminative) and class-relevant (discriminative) components that capture different aspects of OOD detection.
- Evidence anchors:
  - [abstract] "Their approach involves decomposing the learned latent features into the two proposed types of latent features and then summing the Mahalanobis Distance estimated from each type of latent feature."
  - [section] "By having two distinct steps we can: Generate counterfactuals across the different OOD categories. Examine how the (latent and/or input) features of a data point change as it moves from far-OOD to near-OOD and finally to ID."

### Mechanism 2
- Claim: Using Gaussian Mixture Models (GMM) on partitioned latent features improves counterfactual realism
- Mechanism: The method models non-discriminative and discriminative partitions separately with GMMs fitted to ID data, then optimizes counterfactuals to maximize likelihood under these distributions. This ensures counterfactuals remain in high-density regions of ID data space.
- Core assumption: ID data in each latent partition follows a Gaussian distribution, and maximizing likelihood under these distributions produces realistic counterfactuals.
- Evidence anchors:
  - [abstract] "Counterfactuals are perturbed to minimize the NLL under the GMM defined by non-discriminative partition in the first step of the process and then perturbed to minimize the NLL under the GMM defined by the discriminative partition in the second step."
  - [section] "we decided that a counterfactual with a low negative log-likelihood (NLL) under a gaussian mixture model (GMM) obtained from the ID data would mean that the counterfactual is similar to the ID data points."

### Mechanism 3
- Claim: Two-step optimization with separate partitions reduces L1 distance while improving realism
- Mechanism: By optimizing non-discriminative and discriminative partitions in separate steps, the method achieves lower L1 distances to original data while generating more realistic counterfactuals (lower AUROC values) compared to baselines that optimize all features simultaneously.
- Core assumption: Separating optimization steps for different feature partitions leads to more controlled and interpretable changes than simultaneous optimization.

## Limitations
- The approach relies on the assumption that latent features can be meaningfully partitioned into discriminative and non-discriminative components using conditional entropy, which may not generalize well across different datasets
- The method assumes Gaussian distributions for ID data in latent space, which may not hold for all datasets
- Computational complexity of the two-step optimization process could limit scalability to larger datasets or higher-dimensional feature spaces
