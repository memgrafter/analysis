# SparCA: Sparse Compressed Agglomeration for Feature Extraction and Dimensionality Reduction

## Quick Facts
- arXiv ID: 2302.10776
- Source URL: https://arxiv.org/abs/2302.10776
- Reference count: 0
- Primary result: Hierarchical dimensionality reduction combining agglomerative clustering, PCA compression, and orthogonal matching pursuit to produce interpretable sparse features with performance comparable to PCA

## Executive Summary
SparCA is a hierarchical dimensionality reduction method that addresses the challenge of creating interpretable features while maintaining strong performance in downstream supervised learning tasks. The method groups features into clusters using agglomerative clustering, compresses each cluster via PCA, and then reconstructs sparse representations using orthogonal matching pursuit to recover 95% of component variance. Tested across three domains (MNIST images, IMDb reviews, and single-cell gene expression), SparCA achieved classification performance comparable to or exceeding PCA while producing highly interpretable features that are sparse combinations of original features from single clusters.

## Method Summary
SparCA combines agglomerative clustering with Ward's minimum variance criterion to group features into clusters, then applies PCA to compress each cluster separately. The method then uses orthogonal matching pursuit (OMP) to find sparse representations of the principal components using only the original features from each cluster. The number of clusters is determined using a characteristic cluster-feature curve that identifies a plateau region where additional clusters don't increase the number of features. A variance threshold of 0.95 is used for OMP to determine which features to include in the sparse representation. The method produces interpretable features that are sparse combinations of original features, with each resulting feature representing a specific, localized aspect of the data.

## Key Results
- MNIST: 0.93 accuracy with 182 features vs PCA's 115 features at 0.93 accuracy
- IMDb: 0.85 accuracy with 340 features vs PCA's 184 features at 0.84 accuracy
- Gene expression: 0.98 accuracy with 508 features vs PCA's 12 features at 0.94 accuracy

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SparCA achieves interpretable features by grouping features into clusters that minimize within-cluster variance, then compressing each cluster via PCA and reconstructing sparse representations.
- Mechanism: Agglomerative clustering with Ward's method first groups highly correlated features into clusters. PCA is then applied to each cluster separately, extracting components that capture the dominant variance within that cluster. Finally, OMP is used to find the minimal set of original features needed to reconstruct each component with high fidelity (95% variance threshold).
- Core assumption: Features within each cluster are sufficiently correlated that PCA can compress them effectively while maintaining interpretability, and the 95% variance threshold is adequate for downstream task performance.
- Evidence anchors:
  - [abstract] "SparCA groups features into clusters, compresses each cluster via PCA, and then reconstructs sparse representations using only the minimum features required to recover 95% of component variance."
  - [section] "The first step in the procedure is performed using agglomerative clustering with Ward's minimum variance criterion... Once the features have been grouped into a particular number of clusters, the next step in the procedure is performed using PCA to create a compressed representation of the features in each group."
  - [corpus] Weak evidence - no direct mention of Ward's method or similar hierarchical clustering approaches in related papers.
- Break condition: If feature clusters contain weakly correlated features, PCA compression will be ineffective and the resulting components will not be interpretable. Similarly, if the variance threshold is set too low, important information will be lost.

### Mechanism 2
- Claim: SparCA produces highly interpretable features by ensuring each resulting feature is a sparse combination of only the original features from a single cluster, rather than the entire feature space.
- Mechanism: After clustering and PCA compression, OMP is used to find sparse approximations of each principal component using only the original features from that cluster. This creates a final feature set where each feature represents a specific, localized aspect of the data.
- Core assumption: The feature space can be meaningfully partitioned into clusters where features within each cluster share common characteristics or functions.
- Evidence anchors:
  - [abstract] "SparCA... produces an interpretable reduced feature set that is sparse in the input feature space"
  - [section] "SparCA differs from many other DR methods in that while the number of feature clusters is a chosen parameter, the number of compressed features that arise from those clusters is not and instead arises from the covariance structure of the data"
  - [corpus] No direct evidence - related papers discuss sparse autoencoders but not hierarchical clustering-based approaches.
- Break condition: If the feature space cannot be meaningfully clustered (e.g., all features are independent), the method will fail to produce interpretable results.

### Mechanism 3
- Claim: SparCA's performance matches or exceeds PCA without requiring extensive hyperparameter tuning by using intuitive, data-driven parameter selection.
- Mechanism: The number of clusters is chosen using the characteristic cluster-feature curve, which shows a plateau region where additional clusters don't increase the number of features. The variance threshold for OMP can be set to a default value (0.95) without tuning.
- Core assumption: The cluster-feature curve has a consistent shape across different datasets, allowing for heuristic-based cluster number selection.
- Evidence anchors:
  - [section] "The number of clusters chosen should be the minimum number required to reach the constant plateau regime of the c-f curve"
  - [section] "the variance threshold for the OMP procedure... can generally be set to a value between 0.9 and 0.99 and not tuned further"
  - [corpus] Weak evidence - no direct mention of cluster-feature curves in related papers, though general dimensionality reduction literature supports heuristic-based parameter selection.
- Break condition: If the cluster-feature curve doesn't exhibit the expected plateau shape for a particular dataset, the heuristic may fail and lead to suboptimal performance.

## Architecture Onboarding

- Component map: Standard scaling -> Agglomerative clustering -> PCA per cluster -> OMP sparse reconstruction -> Feature stacking -> Transformation
- Critical path:
  1. Feature scaling
  2. Agglomerative clustering to form N clusters
  3. For each cluster: PCA compression followed by OMP sparse reconstruction
  4. Stack all sparse components into final transformation matrix
  5. Apply transformation to input data

- Design tradeoffs:
  - Number of clusters vs. interpretability: More clusters generally increase interpretability but may reduce compression efficiency
  - Variance threshold vs. sparsity: Higher thresholds produce denser features but preserve more information
  - Clustering method: Ward's method is used for its minimum variance property, but other methods could be explored

- Failure signatures:
  - Poor performance despite high dimensionality: May indicate that features don't cluster well or that the variance threshold is too high
  - All features being selected by OMP: Suggests the variance threshold is too low or clusters are too heterogeneous
  - Runtime issues: Agglomerative clustering has O(n²) complexity with n being the number of features, which can be problematic for extremely high-dimensional data

- First 3 experiments:
  1. Run SparCA on a simple synthetic dataset with known cluster structure and verify that features are correctly grouped and compressed
  2. Compare SparCA and PCA performance on MNIST using default parameters to establish baseline performance parity
  3. Test the effect of varying the number of clusters on both the number of resulting features and classification performance on a benchmark dataset
