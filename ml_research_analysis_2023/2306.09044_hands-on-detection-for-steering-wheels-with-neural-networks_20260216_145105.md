# Hands-on detection for steering wheels with neural networks

## Quick Facts
- arXiv ID: 2306.09044
- Source URL: https://arxiv.org/abs/2306.09044
- Reference count: 10
- Primary result: TDNN achieves 99.63% accuracy with 150 μs response time for hands-on/hands-off detection

## Executive Summary
This paper presents a machine learning-based hands-on detection (HOD) system for steering wheels using capacitive sensors. The system addresses limitations of traditional torque-based HOD methods by directly sensing driver contact through capacitive changes. A Time Delay Neural Network (TDNN) with 50 hidden neurons was selected for its optimal balance of accuracy, speed, and memory efficiency, achieving 99.63% accuracy with a 150 μs response time on an STM32F769 microcontroller.

The approach eliminates the need for external calibration by using gradient data instead of absolute capacitance values, making the system more robust across different drivers. The study demonstrates reliable detection when gripping the wheel with one or two hands, though reduced accuracy occurs when touching with two fingers, especially at certain wheel positions. The research validates that neural networks can significantly improve HOD reliability while meeting the critical 200ms response time target required for autonomous vehicle safety.

## Method Summary
The method involves training and comparing multiple machine learning models (TDNN, LSTM, Random Forest) on recorded capacitance data from a sensor mat wrapped around a steering wheel. Data was collected at 2 ms intervals for different touch scenarios (two-finger, four-finger, two-hand) and preprocessed into 100-value windows representing 200 ms duration. The TDNN with 50 hidden neurons was selected for its balance of accuracy (99.63%), speed (150 μs), and memory efficiency (84 kB), then ported to an STM32F769 microcontroller for evaluation.

## Key Results
- TDNN with 50 hidden neurons achieves 99.63% accuracy for hands-on/hands-off detection
- System response time is 150 μs for TDNN inference, meeting the 200ms target
- Gradient-based normalization eliminates need for external calibration across drivers
- Reliable detection when gripping wheel with one or two hands, reduced accuracy with two-finger touches

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Gradient-based normalization enables calibration-free HOD by removing dependence on absolute capacitance values.
- Mechanism: Converting raw capacitance measurements to gradients (dC/dt) normalizes input across drivers by focusing on change magnitude rather than absolute baseline. This eliminates need to estimate min/max capacitance values during deployment.
- Core assumption: Maximum capacitive rate of change is sufficiently consistent across drivers to serve as normalization reference.
- Evidence anchors: "To eliminate this issue, the absolute capacitance values were converted into gradient values, focussing on change in capacity over time instead. This makes it easier to normalize the values, since only the maximum capacitive rate of change need to be known." and "The approach eliminates the need for external calibration by using gradient data instead of absolute capacitance values."

### Mechanism 2
- Claim: TDNN architecture provides optimal balance of accuracy and speed for real-time HOD classification.
- Mechanism: TDNN processes 100 consecutive gradient samples (200ms window) through 50 hidden neurons, achieving 99.63% accuracy with 150μs inference time. Fixed-length sliding window ensures consistent temporal context.
- Core assumption: 200ms temporal window captures sufficient hand-to-wheel contact dynamics for reliable classification.
- Evidence anchors: "Therefore a window with a fixed length of 100 values is placed over every sample. The values in the window form the input for the machine learning models." and "the TDNN with 50 hidden neurons was selected and ported to the micro controller."

### Mechanism 3
- Claim: Machine learning eliminates false positives from torque-based HOD systems.
- Mechanism: Neural network learns capacitive patterns specific to driver contact rather than inferring from steering force. This prevents false hands-off detection during low-force steering situations.
- Core assumption: Capacitive signatures are distinct enough from background noise to enable reliable classification.
- Evidence anchors: "This paper aims to answer the question: Can neural networks increase reliability of HOD within a response time of 200ms?" and "A better HOD variant, also used in this paper, uses a capacitance sensor. This allows to detect the driver's contact with the steering wheel, without relying on any exerted force to the steering wheel."

## Architecture Onboarding

- Component map: Capacitance sensors → ADC → Gradient calculator → TDNN (50 neurons) → Classification → Microcontroller GPIO
- Critical path: Sensor measurement → Gradient computation → Neural network inference → Decision output (total: ~150μs for TDNN)
- Design tradeoffs: TDNN chosen over LSTM for speed (150μs vs 600μs) despite slightly lower accuracy when using gradient data. Memory vs accuracy tradeoff favors TDNN's 84kB footprint.
- Failure signatures: 
  - False negatives at spoke connection points (6 o'clock, 3 o'clock, 9 o'clock positions)
  - Two-finger touch detection failures, especially on inside wheel surface
  - Environmental capacitance interference causing spurious detections
- First 3 experiments:
  1. Measure raw capacitance values with known touches at each wheel position to establish baseline sensitivity patterns
  2. Implement gradient calculation and verify that two-finger touches produce distinguishable rate-of-change signatures
  3. Train minimal TDNN (1-5 neurons) on position-specific data to validate that accuracy degrades predictably at spoke connections

## Limitations

- Validation relies entirely on controlled laboratory conditions without real driving field testing
- Gradient normalization assumption lacks empirical validation across diverse driver populations
- Two-finger touch detection limitations are inherent to capacitive sensing at certain wheel positions

## Confidence

- **High confidence**: TDNN's superior speed-accuracy tradeoff compared to LSTM/Random Forest models (direct measurements reported)
- **Medium confidence**: Gradient normalization eliminates calibration requirements (based on internal test data only)
- **Medium confidence**: Two-finger touch detection limitations are inherent to capacitive sensing (supported by position-specific testing)
- **Low confidence**: System reliability under real-world driving conditions (no field testing data)

## Next Checks

1. **Cross-driver validation**: Test the gradient normalization approach with 20+ drivers of varying body compositions to verify consistent maximum capacitive rate-of-change across populations.

2. **Environmental stress testing**: Evaluate system performance under controlled temperature (0-40°C), humidity (10-90% RH), and electromagnetic interference to identify failure thresholds.

3. **Long-term drift assessment**: Monitor classification accuracy over 100+ hours of continuous operation to quantify sensor aging effects and model degradation.
