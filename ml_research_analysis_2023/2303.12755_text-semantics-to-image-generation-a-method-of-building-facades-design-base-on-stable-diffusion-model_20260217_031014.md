# Text Semantics to Image Generation: A method of building facades design base on Stable Diffusion model

## Quick Facts
- arXiv ID: 2303.12755
- Source URL: https://arxiv.org/abs/2303.12755
- Reference count: 0
- Key outcome: LoRA fine-tuning with ControlNet enables controllable building facade generation with architectural style semantics

## Executive Summary
This study presents a method for generating building facades using Stable Diffusion with LoRA fine-tuning and ControlNet for enhanced controllability. The approach significantly reduces computational requirements while maintaining high-quality results, and ControlNet allows precise control over generated content through various conditions. Experiments demonstrate that the fine-tuned model effectively captures architectural style semantics, with optimal ControlNet weight values (0.6-0.8) balancing structural consistency with detail preservation.

## Method Summary
The method involves fine-tuning Stable Diffusion v1-4 with LoRA on the CMP Facades dataset (200 images, 512×512 pixels) using parameters (Epoch=1, Batch Size=20000, Learning Rate=0.00001), then applying ControlNet with various conditions (Canny Edge, Depth Map, etc.) at weights 0.6-0.8. The process includes preprocessing the dataset, training the LoRA adapter, loading ControlNet, generating images with different prompts and weights, and evaluating results for style consistency and detail preservation.

## Key Results
- LoRA fine-tuning significantly reduces computational requirements while maintaining high-quality architectural style semantics
- ControlNet enables precise control over generated content through conditions like Canny Edge and Depth Map
- Optimal ControlNet weight values (0.6-0.8) balance structural consistency with detail preservation

## Why This Works (Mechanism)

### Mechanism 1
LoRA fine-tuning significantly reduces computational requirements while maintaining high-quality architectural style semantics. LoRA injects trainable low-rank matrices into each Transformer block instead of updating full model weights, reducing parameter count and memory usage during training. Core assumption: The low-rank decomposition captures sufficient information to adapt the model to architectural facade generation tasks.

### Mechanism 2
ControlNet enables precise control over generated content through various conditions like Canny Edge and Depth Map. ControlNet adds conditioning layers that guide the diffusion process based on structural information, allowing the model to maintain consistency with reference objects. Core assumption: Structural information from control conditions (edges, depth maps) is sufficient to guide the diffusion process toward desired architectural features.

### Mechanism 3
Optimal ControlNet weight values (0.6-0.8) balance structural consistency with detail preservation. ControlNet weights determine the strength of influence from control conditions, with intermediate values preserving both structure and architectural details. Core assumption: There exists an optimal range of weights that provides sufficient control without sacrificing too much detail or diversity.

## Open Questions the Paper Calls Out

### Open Question 1
How does the performance of LoRA fine-tuning on CMP Facades dataset compare to other fine-tuning methods like DreamBooth when using the same computational resources? Basis: The paper states LoRA is quicker and less computationally intensive while maintaining the same level of quality as full-model fine-tuning, and contrasts it with techniques like Textual Inversion or Dreambooth. Unresolved because the paper doesn't provide direct quantitative comparisons between LoRA and other fine-tuning methods on the same dataset or with identical hardware constraints.

### Open Question 2
What is the relationship between ControlNet weight values and the preservation of specific architectural style features across different architectural styles? Basis: The paper notes that as ControlNet weight increases, architectural style gradually unifies and building facade elements become more condensed, with the optimal range being 0.6-0.8, but doesn't provide systematic analysis of how this affects different styles. Unresolved because the paper only demonstrates the effect on Chinese, Italian, French, Rococo, and modern styles but doesn't analyze which specific architectural features are most affected by weight changes.

### Open Question 3
How would increasing the training dataset size beyond 200 images affect the quality and diversity of generated building facades? Basis: The paper acknowledges that the dataset is insufficient and mentions that training with additional data would require more digital memory space. Unresolved because the paper only experiments with 200 images and doesn't explore the performance scaling with larger datasets.

### Open Question 4
Which ControlNet condition (Canny Edge, Segment Map, Depth Map, or MLSD) is most effective for preserving the structural integrity of complex architectural facades? Basis: The paper shows that different ControlNet conditions produce different results and that Canny Edge produces more results than Segment Map and MLSD, but doesn't systematically compare their effectiveness for complex facades. Unresolved because the paper provides qualitative comparisons but lacks quantitative evaluation of structural preservation across conditions.

## Limitations

- **Dataset Size and Generalization**: The study uses only 200 training images from the CMP Facades dataset, raising questions about the model's ability to generalize across diverse architectural styles and building types beyond the training set.

- **ControlNet Weight Optimization**: The reported optimal weight range of 0.6-0.8 is based on qualitative assessment rather than quantitative metrics, without systematic ablation studies or objective quality measures.

- **Architectural Style Semantics Capture**: The paper claims LoRA fine-tuning effectively captures architectural style semantics but provides limited quantitative evidence and lacks comparative analysis against other fine-tuning methods.

## Confidence

- **High Confidence**: LoRA fine-tuning reduces computational requirements while maintaining quality
- **Medium Confidence**: ControlNet enables precise control through conditions like Canny Edge and Depth Map
- **Low Confidence**: Optimal ControlNet weight range of 0.6-0.8 universally balances structure and detail
