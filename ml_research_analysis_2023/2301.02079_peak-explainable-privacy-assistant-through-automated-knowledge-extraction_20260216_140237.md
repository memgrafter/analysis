# PEAK: Explainable Privacy Assistant through Automated Knowledge Extraction

## Quick Facts
- arXiv ID: 2301.02079
- Source URL: https://arxiv.org/abs/2301.02079
- Reference count: 30
- Key outcome: A privacy assistant that generates visual and textual explanations for why images are classified as private or public, achieving 88.5% accuracy and high user satisfaction

## Executive Summary
This paper presents PEAK, an explainable privacy assistant that classifies images as private or public and provides intuitive explanations for these decisions. The system uses automated keyword extraction from images, topic modeling via NMF, and Shapley value analysis to generate visual explanations showing which topics and keywords influenced the classification. A user study with 45 participants found the explanations to be sufficiently detailed, satisfying, and understandable, demonstrating the effectiveness of this approach for making privacy decisions transparent to end users.

## Method Summary
The methodology extracts 20 descriptive keywords per image using Clarifai API, then applies NMF to discover 20 latent topics from these keywords. A Random Forest classifier is trained on TF-IDF vectors of these topics to predict privacy (private/public). TreeExplainer computes Shapley values to identify each topic's contribution to predictions. Explanations are categorized as Dominant (one clear topic), Collaborative (multiple contributing topics), Conflicting (opposing topic influences), or Vague (no clear dominant topics), and displayed as visual circles with keywords and short text descriptions.

## Key Results
- Classifier achieved 88.5% accuracy on test set
- User study: Participants rated explanations as sufficiently detailed (M=3.88/5), satisfying (M=3.62/5), and understandable (M=3.8/5)
- NMF topics showed good coherence with intra-topic similarity >0.18 and inter-topic similarity <0.5

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Topic modeling via NMF captures latent semantic structure in image keywords, enabling interpretable privacy decisions.
- Mechanism: NMF factorizes the image-keyword matrix into non-negative components, revealing dominant topics. Each image is then represented as a weighted combination of these topics, which the classifier uses to predict privacy.
- Core assumption: The descriptive keywords generated by Clarifai accurately reflect the semantic content of images, and these keywords group into coherent topics.
- Evidence anchors:
  - [abstract] "The core method involves using topic modeling to discover latent topics from descriptive keywords associated with images."
  - [section 3.1] "NMF is an approximation to factorize a non-negative matrix of a non-negative image-keyword matrix X, into non-negative matrices W and H... NMF is suitable for interpretability (components are non-negative) and works better and faster for short texts (a set of keywords) as compared to alternatives such as Latent Dirichlet allocation (LDA)."
  - [corpus] Weak: The corpus contains no papers explicitly validating NMF for privacy explanations, but does mention NMF in related ML contexts.
- Break condition: If keywords are too sparse or semantically noisy, topic coherence degrades, breaking the explanation quality.

### Mechanism 2
- Claim: Shapley values identify the most influential topics for a specific privacy prediction, enabling targeted explanations.
- Mechanism: TreeExplainer computes Shapley values for each topic, measuring its marginal contribution to the Random Forest prediction. Dominant topics (high positive Shapley) are highlighted in explanations.
- Core assumption: Shapley values meaningfully reflect real feature influence in tree-based models for privacy classification.
- Evidence anchors:
  - [section 4] "The TreeExplainer [16] model provides the contributions of each feature in terms of Shapley values... One way to create explanations would be to display all these values to the user. However, as the number of features increases, it would be cumbersome and confusing to show them all to the end user."
  - [section 4] "Regarding topic reduction, we divide images into four categories: Dominant, Conflicting, Collaborative, and Vague, in terms of the contribution of topics to the decision."
  - [corpus] Weak: No direct corpus evidence for Shapley in privacy explanations, but Shapley is standard in XAI literature.
- Break condition: If the classifier is not tree-based or Shapley assumptions fail, the explanation categories become invalid.

### Mechanism 3
- Claim: Visual topic-keyword circles with short text improve user understanding and satisfaction of privacy decisions.
- Mechanism: Each topic is visualized as a labeled circle with keyword tags; the text describes the image's association with these topics. This dual modality aligns with user preferences for non-technical, glanceable explanations.
- Core assumption: Users find visual representations with brief text more comprehensible than feature lists or heatmaps.
- Evidence anchors:
  - [section 2.1] "The explanations that we are interested in generating are meant for end users. Hence, even if our explanations are influenced by the features that are used for classification, our aim is not to educate the user about how the underlying classifier works. Hence, the explanation should not be too technical."
  - [section 5] "Our user study has three phases... we ask participants to rank the following questions: (1) This explanation that the algorithm produces has SUFFICIENT DETAIL. (2) This explanation produced by the algorithm is SATISFYING. (3) From this explanation, I UNDERSTAND why an image has been identified as private or public."
  - [section 5.3] "Our results indicate that participants were very confident that explanations were sufficiently detailed (𝑀 = 3.88, 𝑆𝐷 = 1.12), found the explanations satisfactory (𝑀 = 3.62, 𝑆𝐷 = 1.28), and understood why the images were labeled as private or public (𝑀 = 3.8, 𝑆𝐷 = 1.33)."
  - [corpus] Weak: No corpus evidence for this exact visual design; related papers focus on different explanation modalities.
- Break condition: If users prefer more detailed or different explanation formats, satisfaction drops.

## Foundational Learning

- Concept: Non-negative Matrix Factorization (NMF)
  - Why needed here: NMF discovers interpretable latent topics from keyword data without negative weights, enabling meaningful topic-keyword associations.
  - Quick check question: Why is NMF preferred over LDA for short keyword sets in this context?

- Concept: Shapley Values in Explainable AI
  - Why needed here: Shapley values quantify each topic's marginal contribution to a prediction, enabling identification of dominant or conflicting topics for explanations.
  - Quick check question: How does TreeExplainer compute Shapley values efficiently for Random Forest models?

  - Why needed here: Intra-topic and inter-topic similarity ensure discovered topics are semantically meaningful and distinguishable, improving explanation quality.

## Architecture Onboarding

- Component map:
  Clarifai API → Keyword Extraction → NMF Model → Topic Discovery → Random Forest Classifier → Privacy Prediction → TreeExplainer → Shapley Value Computation → Explanation Generator → Visual + Text Output → User Interface

- Critical path:
  1. Extract keywords from image → 2. Apply NMF → 3. Train Random Forest on topic vectors → 4. Compute Shapley values → 5. Generate explanation based on topic categories → 6. Display to user.

- Design tradeoffs:
  - NMF vs LDA: NMF is faster and more interpretable for short keyword sets but may miss long-range dependencies.
  - Shapley vs saliency: Shapley values are model-agnostic and fair but computationally heavier than saliency maps.
  - Visual vs textual: Visuals are more accessible but may oversimplify complex topic interactions.

- Failure signatures:
  - Low intra-topic similarity (<0.15) → Topics are incoherent, explanations lose meaning.
  - Dominant topic Shapley <0.5 → No clear explanation category, fallback to Vague.
  - High inter-topic similarity (>0.5) → Topics overlap, reducing distinctiveness.

- First 3 experiments:
  1. Validate NMF topic coherence on a held-out keyword set; check intra-topic similarity >0.18.
  2. Train Random Forest on NMF topics; confirm accuracy >85% on test set.
  3. Generate explanations for 10 random images; ensure all fall into one of four categories without errors.

## Limitations

- The methodology relies heavily on the quality of automatically generated keywords from Clarifai, which is not validated within the paper
- Specific thresholds for categorizing explanations (e.g., dominant topic threshold of 0.7) are not clearly defined, creating uncertainty in reproduction
- The user study sample size of 45 participants may not capture diverse user preferences across different demographics or cultural contexts
