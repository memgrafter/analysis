# Shattering the Agent-Environment Interface for Fine-Tuning Inclusive Language Models

## Quick Facts
- **arXiv ID**: 2305.11455
- **Source URL**: https://arxiv.org/abs/2305.11455
- **Reference count**: 40
- **Key outcome**: Introduces Inclusive Learning from Human Feedback (ILHF) that jointly optimizes language model policy and reward function, producing inclusive models that maintain response diversity while aligning with human preferences

## Executive Summary
This paper addresses the challenge of fine-tuning language models to align with human preferences while maintaining response diversity. Traditional RLHF approaches tend to produce agglomerative models that collapse to a single "best" response, losing the rich diversity of human communication. The authors propose a novel framework called Inclusive Learning from Human Feedback (ILHF) that reframes the language model itself as simultaneously embodying the policy, reward function, and environment simulator. This unified perspective enables direct fine-tuning based on human feedback without requiring separate reward model training.

The key innovation is optimizing for KL divergence between human preference distributions and the model's response distributions, which naturally preserves diversity. The approach is validated through synthetic experiments demonstrating that ILHF produces inclusive models that converge to desired response distributions, outperforming traditional RLHF methods. Additionally, the authors show how ensemble sampling can be incorporated to improve learning efficiency through uncertainty-based exploration.

## Method Summary
ILHF reframes fine-tuning as an optimization problem where the pretrained language model simultaneously serves as policy, reward function, and environment simulator. Instead of training a separate reward model, ILHF directly optimizes the language model parameters to minimize KL divergence between human preference distributions and the model's induced response preference distributions. The log probability of responses serves as the reward signal. For exploration, Ensemble-ILHF maintains an ensemble of models and samples from them to represent epistemic uncertainty about the optimal response distribution.

## Key Results
- ILHF produces inclusive models that maintain the population response distribution rather than collapsing to a single preferred response
- Ensemble-ILHF with posterior sampling improves learning efficiency over standard ILHF
- ILHF outperforms traditional RLHF approaches that tend to produce agglomerative models in synthetic experiments

## Architecture Onboarding

- **Component map**: Pretrained language model → Prompt generator → Human labeler → ILHF loss computation → Optimizer → Updated model parameters → (Optional) Ensemble sampler

- **Critical path**: Prompt → Model generates responses → Human provides preferences → Compute ILHF loss → Update model parameters → Repeat

- **Design tradeoffs**:
  - Direct optimization vs. separate reward model: ILHF eliminates the need for a separate reward model but requires the language model to be sufficiently expressive
  - Exploration strategies: Ensemble-ILHF adds computational overhead but may improve learning efficiency
  - Model complexity: Larger models may better capture the dual role of policy and reward function but increase computational cost

  - Model collapses to single response regardless of prompt (agglomerative behavior)

## Limitations
- Empirical validation is limited to synthetic environments and controlled experiments, lacking human evaluation on real-world tasks
- The fundamental assumption that pretrained language model parameters can adequately serve dual roles as both policy and reward function remains untested on complex, real-world tasks
- Scaling to practical applications introduces numerous potential failure modes not addressed in the paper
