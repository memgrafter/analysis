# Discovering Multiple Algorithm Configurations

## Quick Facts
- arXiv ID: 2303.07434
- Source URL: https://arxiv.org/abs/2303.07434
- Reference count: 40
- Primary result: Automatic discovery of multiple algorithm configurations for different dataset modes outperforms single-configuration optimization in robotics applications

## Executive Summary
This paper extends the traditional algorithm configuration problem by automatically discovering multiple configurations that correspond to different modes in the dataset. Rather than finding a single optimal configuration for all data, the method partitions the dataset during optimization and finds a different configuration for each partition. Three approaches are proposed: post hoc partitioning after optimization, staged partitioning with exploration followed by exploitation, and an online method using multi-armed bandits. Experiments on synthetic functions and four robotics domains demonstrate clear benefits of multi-mode configurations over single-mode baselines.

## Method Summary
The method treats algorithm configuration as a black-box optimization problem using CMA-ES, where the algorithm is evaluated across the entire dataset. The key innovation is partitioning the dataset into modes that respond similarly to different configurations, then optimizing each partition independently. Three partitioning strategies are proposed: post hoc (partition after initial optimization), staged (explore then exploit), and online (dynamic assignment using multi-armed bandits). The partitioning is formulated as a 0-1 Integer Linear Programming problem to minimize total configuration costs across partitions.

## Key Results
- Staged partitioning method consistently outperforms both post hoc and online methods across most dimensions and function evaluations
- Post hoc method shows clear improvement over single-mode configuration baseline in all tested robotics domains
- Online bandit method performs only slightly better than baseline, despite theoretical appeal
- Multi-mode configurations discovered automatically lead to better overall performance than single configuration optimized for entire dataset

## Why This Works (Mechanism)

### Mechanism 1
Partitioning the dataset into multiple modes during optimization leads to better overall performance than optimizing a single configuration for the entire dataset. The algorithm configurations are evaluated across the dataset, and response patterns are used to partition data into groups that respond similarly to different configurations. Each partition is then optimized independently. This works because datasets contain distinct modes that respond differently to algorithm configurations, which can be discovered automatically during optimization.

### Mechanism 2
Staged partitioning (exploration followed by exploitation) outperforms both post hoc and online methods for discovering multiple algorithm configurations. Half of function evaluations are spent exploring configuration space to find adequate minima, then data is partitioned and each partition is optimized independently. This approach balances exploration (finding good partitions) and exploitation (optimizing within partitions), which is necessary for optimal performance.

### Mechanism 3
The online method using multi-armed bandits can dynamically assign data points to partitions during optimization, but performs poorly compared to other methods. A multi-armed bandit is set up for each datum, with each arm representing a different partition. The algorithm samples partition assignments and evaluates configurations accordingly. While theoretically appealing for online assignment of data points to partitions, this method typically only slightly outperforms the single mode baseline due to insufficient exploration or instability in the optimization process.

## Foundational Learning

- **Black box optimization**: Why needed here: The algorithm configuration problem is treated as a black box optimization problem where the objective function (performance of the algorithm on the dataset) is expensive to evaluate and does not provide gradients. Quick check question: What are the advantages of using black box optimization methods like CMA-ES for algorithm configuration compared to gradient-based methods?

- **Integer Linear Programming**: Why needed here: The partitioning of the dataset into modes is formulated as an optimization problem where the goal is to minimize the total cost of configurations across all partitions. Quick check question: How does the 0-1 Integer Linear Programming formulation ensure that each datum is assigned to exactly one partition?

- **Multi-armed bandits**: Why needed here: The online method uses Thompson Sampling with a Gaussian distribution to dynamically assign data points to partitions during optimization. Quick check question: Why is Thompson Sampling a suitable choice for the online method, and what are its limitations compared to other bandit algorithms?

## Architecture Onboarding

- **Component map**: Black box optimizer (CMA-ES) -> Dataset of configurations and performance -> Partitioning algorithm (post hoc/staged/online) -> Evaluation function
- **Critical path**: 1) Initialize black box optimizer with initial configuration 2) Evaluate algorithm performance across dataset 3) Partition dataset based on response patterns 4) Optimize configurations for each partition independently
- **Design tradeoffs**: Exploration vs. exploitation in staged method; computational cost of partitioning vs. performance gain; number of partitions (K) vs. overfitting risk
- **Failure signatures**: Poor performance of online method due to insufficient exploration; overfitting to dataset when using too many partitions; computational bottleneck in evaluating algorithm performance
- **First 3 experiments**: 1) Synthetic function with known modes to characterize partitioning methods 2) Stereoscopic depth estimation to evaluate real-world performance 3) Motion planning to test method in different robotics domain

## Open Questions the Paper Calls Out

### Open Question 1
Does the post hoc method always outperform the staged method across all robotics domains and dataset sizes, or are there specific conditions where the staged method is superior? The paper shows staged method performs best in synthetic experiments with 50 function evaluations, but doesn't provide comprehensive analysis across different dataset sizes, problem dimensions, and application domains to identify specific conditions favoring one method over the other.

### Open Question 2
What are the typical algorithm modes that exist in robotics applications, and how can modal configurations be used for long-term deployed autonomous systems? The paper concludes more study is needed to understand what typical algorithm modes exist and how such modal configurations might be used long-term in deployed autonomous systems, providing experimental evidence but not generalizing to identify common mode types or practical deployment strategies.

### Open Question 3
How does the online method's performance compare to more sophisticated multi-armed bandit algorithms in the algorithm configuration setting? The paper only evaluates the online method using basic Thompson Sampling and suggests more sophisticated bandit algorithms could perform better, but doesn't compare against advanced bandit algorithms that might better handle the exploration-exploitation trade-off.

## Limitations
- Performance gap between methods is significant in some domains but less clear in others, particularly for the online bandit approach
- Computational overhead of evaluating multiple configurations across entire dataset for each optimization step is not thoroughly characterized
- Reliance on synthetic benchmarks and four specific robotics applications limits generalizability of results

## Confidence
- High confidence: The core mechanism of partitioning datasets to find multiple configurations is sound and well-supported by synthetic experiments
- Medium confidence: The staged method's superiority over post hoc partitioning is demonstrated but may depend on specific dataset characteristics and could be less effective on more homogeneous datasets
- Low confidence: The online method's poor performance suggests fundamental limitations in applying bandit approaches to this problem, but reasons are not thoroughly analyzed
