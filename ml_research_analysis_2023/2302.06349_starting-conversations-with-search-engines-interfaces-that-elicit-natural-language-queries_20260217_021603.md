# Starting Conversations with Search Engines -- Interfaces that Elicit Natural Language Queries

## Quick Facts
- arXiv ID: 2302.06349
- Source URL: https://arxiv.org/abs/2302.06349
- Reference count: 19
- Primary result: Chatbot-inspired interfaces increase product attribute mentions by 84% and natural language formulations by 139% compared to standard search bars

## Executive Summary
This study investigates how search interface design influences users to reveal more information about their product needs. Through a user study (N=139) comparing four interface designs, the research demonstrates that chatbot-inspired interfaces significantly outperform traditional search bars in eliciting detailed product attribute information. The chatbot interface increased mentioned product attributes by 84% and promoted natural language formulations by 139% compared to standard search bars. When users interacted with the chatbot interface, they provided 43% complete sentences versus only 18-12% in search bar conditions.

## Method Summary
The study used a between-subjects online user study with 139 participants recruited from Prolific and evenly distributed across four interface conditions. Participants searched for a laptop based on a provided scenario using one of four interface designs: small search bar, big search bar, speech bubble with direct question, or chatbot interface. Queries were analyzed using manual annotation and NLTK for parts of speech analysis. Statistical significance was tested using Kruskal-Wallis tests with Mann-Whitney U post-hoc analysis.

## Key Results
- Chatbot interface increased mentioned product attributes by 84% compared to standard search bars
- Natural language formulations increased by 139% in chatbot conditions versus standard search bars
- Complete sentence usage was 43% in chatbot condition versus 18-12% in search bar conditions

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Chatbot-inspired interfaces significantly increase the number of product attributes users mention in their initial search query.
- Mechanism: The conversational design elements create a social presence that encourages users to treat the search interface as a dialogue partner rather than a passive input field, prompting them to provide more detailed information.
- Core assumption: Users perceive conversational interfaces as more interactive and responsive, leading to increased information disclosure.
- Evidence anchors:
  - [abstract]: "a chatbot-inspired search interface can increase the number of mentioned product attributes by 84%"
  - [section]: "The chatbot interface elicits longer queries with a significantly higher number of key facts"
  - [corpus]: Weak evidence - corpus contains related papers on conversational search but none specifically address attribute elicitation through interface design
- Break Condition: The effect disappears if the chatbot interface provides no meaningful follow-up responses or if users perceive the conversation as artificial/fake.

### Mechanism 2
- Claim: Natural language formulations increase by 139% when using chatbot interfaces compared to standard search bars.
- Mechanism: The conversational interface design implicitly signals to users that natural language is acceptable and expected, reducing the cognitive burden of translating needs into keyword form.
- Core assumption: Users adapt their query formulation based on perceived interface capabilities and expectations set by design elements.
- Evidence anchors:
  - [abstract]: "promote natural language formulations by 139% in comparison to a standard search bar interface"
  - [section]: "the queries of the chatbot interfaces are formulated in a more natural way than the queries in the search bar conditions"
  - [corpus]: Weak evidence - related papers discuss conversational search but don't quantify natural language formulation increases
- Break Condition: If the system cannot actually process natural language queries effectively, users will revert to keyword searches despite interface design.

### Mechanism 3
- Claim: Complete sentence usage increases significantly (43% vs 18-12%) when using chatbot interfaces.
- Mechanism: The conversational design primes users to engage in dialogue rather than keyword search, making complete sentence formulation feel more natural and appropriate.
- Core assumption: Users' language patterns are influenced by the communication style the interface implicitly suggests.
- Evidence anchors:
  - [abstract]: "promoted natural language formulations by 139% in comparison to a standard search bar interface"
  - [section]: "43% of queries are grammatically complete sentences" in chatbot condition vs "only 18%, 12%, and 11% of the participants used complete sentences" in search bar conditions
  - [corpus]: No direct evidence found in corpus - this appears to be a novel finding
- Break Condition: The effect diminishes if users are experienced with keyword search and strongly prefer that approach regardless of interface design.

## Architecture Onboarding

- Component map:
  - Interface rendering engine (supports multiple interface variants)
  - Query processing pipeline (handles both keyword and natural language inputs)
  - Follow-up question generator (for chatbot conditions)
  - Analytics collector (captures query metadata and user behavior)
  - Result display component (dummy results for study purposes)

- Critical path:
  1. User loads interface variant
  2. User submits query
  3. System captures query metadata (length, key facts, POS tags)
  4. For chatbot condition: generate and display follow-up question
  5. User continues to results page
  6. Collect post-interaction survey data

- Design tradeoffs:
  - Natural language processing capability vs. simplicity of keyword search
  - Rich interface design vs. loading speed and accessibility
  - Detailed query capture vs. user privacy concerns
  - Follow-up question relevance vs. generic prompts

- Failure signatures:
  - Users abandoning natural language formulations after initial attempts
  - High bounce rates when chatbot follow-up questions are poorly matched
  - Increased query abandonment when interface feels too complex
  - Users providing minimal information despite conversational design

- First 3 experiments:
  1. A/B test comparing chatbot interface with and without follow-up questions
  2. Multivariate test varying placeholder text length and conversational tone
  3. Sequential test measuring how query formulation changes across multiple search attempts

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different conversational interface designs (beyond search bars and chatbots) affect the amount and quality of information users reveal about their product needs?
- Basis in paper: [explicit] The study compares four interfaces, including a chatbot and search bars, but does not explore other conversational designs like voice assistants or mixed-mode interfaces.
- Why unresolved: The study focuses on specific interface types, leaving the impact of other conversational designs untested.
- What evidence would resolve it: Comparative user studies testing various conversational interface designs (e.g., voice assistants, mixed-mode interfaces) in product search scenarios.

### Open Question 2
- Question: What are the long-term effects of using conversational interfaces on user behavior and search query formulation habits?
- Basis in paper: [inferred] The study is a one-time user study, not tracking changes in user behavior over time.
- Why unresolved: The study does not investigate whether users adapt their query formulation habits after prolonged use of conversational interfaces.
- What evidence would resolve it: Longitudinal studies tracking user behavior and query formulation habits over extended periods of using conversational interfaces.

### Open Question 3
- Question: How do conversational interfaces impact search performance and user satisfaction in domains beyond product search?
- Basis in paper: [explicit] The study focuses on product search, but the authors suggest investigating other domains to generalize findings.
- Why unresolved: The study is limited to product search, and the impact of conversational interfaces on other domains remains unexplored.
- What evidence would resolve it: Comparative user studies testing conversational interfaces in various domains (e.g., informational, navigational) and measuring search performance and user satisfaction.

## Limitations
- The study relies on a controlled laboratory setting with a single product category (laptops) and hypothetical scenarios, limiting ecological validity
- Manual annotation of query attributes introduces potential subjectivity despite inter-rater reliability measures
- The analysis doesn't directly measure whether increased query detail translates to better search outcomes

## Confidence
- High Confidence: The 84% increase in product attributes and 139% increase in natural language formulations are well-supported by the experimental data with appropriate statistical testing and clear effect sizes.
- Medium Confidence: The practical significance of these improvements for real search systems depends on whether increased query detail translates to better search outcomes, which wasn't directly measured.
- Low Confidence: The generalizability across different product categories, user demographics, and real-world search scenarios requires further validation.

## Next Checks
1. Cross-domain validation: Replicate the study with different product categories (travel, recipes, electronics) to test generalizability of the conversational interface effect.
2. Longitudinal study: Track users over multiple search sessions to measure if the conversational interface effect persists or diminishes with repeated use.
3. Search outcome correlation: Measure whether increased query detail from conversational interfaces actually improves search result relevance and user satisfaction in realistic search tasks.
