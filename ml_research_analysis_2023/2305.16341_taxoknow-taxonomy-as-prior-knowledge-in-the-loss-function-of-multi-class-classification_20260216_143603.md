# TaxoKnow: Taxonomy as Prior Knowledge in the Loss Function of Multi-class Classification

## Quick Facts
- arXiv ID: 2305.16341
- Source URL: https://arxiv.org/abs/2305.16341
- Reference count: 10
- Primary result: Taxonomy integration improves minority class performance in imbalanced multi-class classification

## Executive Summary
This paper addresses imbalanced multi-class classification by integrating hierarchical taxonomies into neural network loss functions. Two approaches are proposed: a symbolic-based method representing taxonomy as logical constraints in the semantic loss function, and a GCN-based method encoding taxonomy as graph structure with regularization. Both methods incorporate taxonomy knowledge as explicit regularizers in the loss function. Experiments on two industrial datasets and two public benchmarks demonstrate significant performance improvements, particularly for minority classes in severely imbalanced scenarios.

## Method Summary
The paper introduces two complementary methods for integrating hierarchical taxonomies into multi-class classification. The symbolic-based approach translates taxonomic relationships into propositional logic constraints using Sentential Decision Diagrams (SDDs) to create a differentiable semantic loss. The GCN-based approach represents the taxonomy as a graph where nodes are categories and edges represent parent-child relationships, using Graph Convolutional Networks to learn embeddings that regularize the classifier's output distribution. Both methods condition the classification task on higher-level taxonomic concepts to improve minority class performance.

## Key Results
- Significant accuracy improvements across all tested datasets when incorporating taxonomy knowledge
- GCN-based method shows better Macro Average F1-score performance, particularly for long-tailed problems
- Largest performance gains observed when labeled data is limited, benefiting semi-supervised settings
- Taxonomy integration consistently improves minority class performance in both supervised and semi-supervised scenarios

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Symbolic logical constraints enforce taxonomic coherence in neural network outputs
- Mechanism: The hierarchical taxonomy is translated into propositional logic sentences, which are then converted into differentiable semantic loss functions via SDDs. This loss regularizes the network to satisfy taxonomic constraints during training
- Core assumption: The taxonomy is complete and consistent
- Break condition: Taxonomy contains contradictory relationships or missing parent-child links

### Mechanism 2
- Claim: Graph Convolutional Networks encode taxonomic structure as node embeddings that regularize classification outputs
- Mechanism: The hierarchical taxonomy is represented as a graph where nodes are taxonomic categories and edges represent parent-child relationships. GCNs learn embeddings for all nodes, including unlabeled ones, which are then used as a regularization target for the classifier's output distribution
- Core assumption: The taxonomic graph is sufficiently connected to allow meaningful message passing between related categories
- Break condition: The taxonomic graph is too sparse or disconnected for GCNs to propagate meaningful information between nodes

### Mechanism 3
- Claim: Hierarchical taxonomy provides abstraction that improves minority class performance in imbalanced datasets
- Mechanism: By conditioning classifier outputs on higher-level taxonomic concepts, the model can leverage statistical patterns from parent categories to better predict underrepresented leaf nodes, effectively transferring knowledge up the taxonomy hierarchy
- Core assumption: Higher-level taxonomic categories have more balanced distributions than leaf categories
- Break condition: The taxonomy hierarchy is too shallow or the imbalance is so severe that even parent categories are themselves highly imbalanced

## Foundational Learning

- Concept: Propositional logic and model counting
  - Why needed here: The semantic loss function relies on propositional logic sentences that must be converted to differentiable objectives using model counting techniques
  - Quick check question: Can you explain how a sentence like "one and exactly one of X3, X4, X5 must be true" translates to a logical constraint and how this becomes a loss term?

- Concept: Graph neural networks and message passing
  - Why needed here: The GCN-based approach requires understanding how node features are updated through aggregation of neighbor information in the taxonomic graph
  - Quick check question: How would you construct the adjacency matrix for a taxonomy tree, and what would the GCN propagation look like for a three-level hierarchy?

- Concept: Imbalanced classification metrics
  - Why needed here: The paper emphasizes Macro Average F1-score, which is crucial for evaluating performance on minority classes in imbalanced datasets
  - Quick check question: Why might Macro Average F1-score be more informative than accuracy for evaluating taxonomic classification performance?

## Architecture Onboarding

- Component map: BERT encoder -> taxonomy regularization module (symbolic or GCN) -> classification head
- Critical path: Input text -> BERT pooling -> regularized loss computation -> parameter updates
- Design tradeoffs: Symbolic approach offers precise logical constraints but may struggle with incomplete taxonomies; GCN approach handles incomplete taxonomies but requires more memory and may be less precise
- Failure signatures: Poor minority class performance despite regularization (taxonomy constraints too weak), training instability (over-regularization), or no improvement over baseline (taxonomy not informative)
- First 3 experiments:
  1. Implement symbolic-based method on a simple taxonomy with complete relationships and verify constraint satisfaction during training
  2. Test GCN-based method on a small taxonomy graph, comparing node embeddings with known taxonomic relationships
  3. Run ablation study removing taxonomic constraints to quantify performance impact on minority classes

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the effectiveness of taxonomy integration vary across different levels of class imbalance severity?
- Basis in paper: The experiments demonstrate improvement but don't systematically test across varying imbalance ratios
- Why unresolved: The experiments show improvement but don't compare effectiveness at different imbalance thresholds
- What evidence would resolve it: Systematic experiments varying class imbalance ratios across datasets, showing performance curves as imbalance increases or decreases

### Open Question 2
- Question: How do the symbolic-based and GCN-based approaches compare in handling extremely deep versus shallow taxonomy hierarchies?
- Basis in paper: The paper notes GCN performs better on Macro Average F1-score for long-tailed problems, and both methods were tested on taxonomies with three levels
- Why unresolved: The experiments used taxonomies with similar depth, so comparison across varying taxonomy depths remains untested
- What evidence would resolve it: Experiments using taxonomies with varying depths (shallow vs. deep hierarchies) comparing both approaches' performance across these structures

### Open Question 3
- Question: What is the relationship between taxonomy granularity and classification performance in different domains?
- Basis in paper: The paper uses taxonomies with three levels across different datasets but doesn't systematically explore how varying the number of taxonomy levels affects performance
- Why unresolved: While the paper demonstrates taxonomy benefits, it doesn't test how performance changes when using more or fewer taxonomy levels
- What evidence would resolve it: Experiments systematically varying taxonomy granularity (number of levels) across multiple domains, measuring performance changes as taxonomy becomes more or less detailed

## Limitations

- Symbolic-based method relies heavily on complete and consistent taxonomies, with no evaluation of robustness to taxonomic errors
- GCN-based approach requires substantial computational resources and may not scale to very large taxonomic structures
- The experiments only tested taxonomies with three levels, limiting generalizability to deeper or differently structured hierarchies

## Confidence

- **High Confidence**: Performance improvements on both industrial and public datasets
- **Medium Confidence**: Mechanism explanations for how hierarchical abstraction improves minority class performance
- **Low Confidence**: Generalizability to taxonomies with more than three levels or different structural properties

## Next Checks

1. **Taxonomy Robustness Test**: Systematically introduce taxonomic errors (contradictions, missing links, incorrect parent assignments) into the evaluation datasets and measure performance degradation for both methods to quantify robustness requirements.

2. **Cross-Domain Taxonomy Transfer**: Apply the best-performing method to a completely different domain (e.g., medical diagnosis codes or biological taxonomy) to validate whether the approach generalizes beyond product categorization and customer service domains.

3. **Ablation of Taxonomy Levels**: Conduct controlled experiments removing different levels of the taxonomy hierarchy to quantify the marginal benefit of each abstraction level, particularly for the minority class performance gains claimed in the paper.
