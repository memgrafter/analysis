# One-class systems seamlessly fit in the forward-forward algorithm

## Quick Facts
- arXiv ID: 2306.15188
- Source URL: https://arxiv.org/abs/2306.15188
- Reference count: 3
- One-line primary result: Forward-forward training with one-class objective functions achieves comparable performance to backpropagation for anomaly detection, with the best models showing slightly better results.

## Executive Summary
This paper investigates the integration of deep one-class objective functions with the forward-forward algorithm for neural network training. The forward-forward algorithm updates weights after each layer's forward pass, reducing memory requirements and enabling online training. The authors evaluate five one-class loss functions (Goodness, GoodnessAdjusted, HB-SVDD, SVDD, and LS-SVDD) on the banknote authentication dataset using both forward-forward and normal backpropagation training methods. Results show that forward-forward training achieves comparable performance to backpropagation, with the best models trained using forward-forward slightly outperforming backpropagation in terms of accuracy, F1 score, and AUC.

## Method Summary
The study evaluates five one-class objective functions in the context of the forward-forward algorithm for training neural networks on anomaly detection tasks. The banknote authentication dataset (1372 samples, 4 features) is used as the benchmark. The authors implement neural networks with four different architectures (4,10,10), (4,25,25), (4,50,50), and (4,100,100) layers. Each architecture is trained using both forward-forward and backpropagation methods with all five loss functions. Training is repeated 50 times with different random seeds to ensure robust results. Performance is measured using accuracy, F1 score, and AUC metrics, with early stopping based on validation loss.

## Key Results
- Forward-forward training achieves average accuracy of 56.63% versus 57.60% for backpropagation, showing comparable overall performance
- Best models trained with forward-forward achieve higher performance (accuracy 94.18%, F1 0.9375, AUC 0.9461) compared to best backpropagation models (accuracy 93.45%, F1 0.9274, AUC 0.9354)
- The Goodness function performs well on average across both training methods, making it a reliable choice for one-class classification

## Why This Works (Mechanism)

### Mechanism 1
One-class objective functions naturally handle variable layer sizes, making them suitable for forward-forward training where each layer is updated independently. In forward-forward training, each layer receives its own loss calculation without relying on backpropagated gradients from subsequent layers. One-class loss functions like SVDD, HB-SVDD, and Goodness operate directly on the layer's activations, which can vary in dimension depending on the network architecture. This eliminates the need for specialized goodness functions that were proposed in the original forward-forward algorithm.

### Mechanism 2
Forward-forward training achieves comparable performance to backpropagation for one-class classification tasks. The paper shows that forward-forward training with various one-class loss functions achieves average accuracy of 56.63% versus 57.60% for backpropagation. While backpropagation has slightly better average performance, forward-forward achieves higher performance for the best models (accuracy 94.18% vs 93.45%). This suggests that layer-wise optimization can capture the essential patterns for one-class classification without full backpropagation.

### Mechanism 3
The Goodness function performs well across both training methods for one-class classification. The Goodness function and its adjusted variant show strong average performance across both forward-forward and backpropagation training methods. This suggests that this particular loss function is robust to the different optimization dynamics of the two training approaches, making it a reliable choice for one-class classification regardless of training method.

- Critical path: Data preprocessing → Model initialization → Forward pass through each layer → Loss calculation using one-class objective → Weight update (immediately for forward-forward, after full forward pass for backpropagation) → Evaluation on validation set → Early stopping if needed → Final evaluation on test set

- Design tradeoffs: Forward-forward offers reduced memory requirements and potential for online training but may sacrifice some optimization quality compared to backpropagation. The choice of loss function involves tradeoffs between different one-class classification approaches (SVDD-based vs. goodness-based). The network architecture (layer sizes) also impacts performance.

If forward-forward significantly underperforms backpropagation, it may indicate that the layer-wise updates are insufficient for the given task complexity. If certain loss functions fail consistently, it may indicate incompatibility with the forward-forward approach.

## Open Questions the Paper Calls Out

### Open Question 1
How do different one-class objective functions perform across various neural network architectures beyond the 4-layer networks tested in this study? The authors mention that "Future work should be conducted to expand this study to deeper models" suggesting this has not been fully explored. The paper only evaluated 4 specific network architectures (4,10,10; 4,25,25; 4,50,50; 4,100,100) and didn't explore deeper or wider architectures.

### Open Question 2
Does pretraining network weights using autoencoders significantly improve the stability and performance of forward-forward trained one-class models? The authors state "Future work can introduce autoencoders into the training pipeline to regulate the model results across different random seeds." The authors acknowledge this as a potential direction but did not implement or evaluate autoencoder pretraining in their experiments.

### Open Question 3
What is the optimal strategy for determining positive and negative data assignments in forward-forward training for one-class problems? The authors note that "The assignment of these positive and negative data is subject to creativity" and mention using incorrect class assignments for negative data, but don't explore alternative strategies. The paper uses a basic strategy (correct vs incorrect class assignments) without exploring other creative assignments that might improve performance.

## Limitations

- Evaluation is limited to a single dataset (banknote authentication), restricting generalizability to other domains
- Forward-forward algorithm's performance variability across different network architectures and problem complexities remains unexplored
- Comparison focuses on average performance metrics without extensive statistical significance testing between methods

## Confidence

- High Confidence: The mechanism showing one-class loss functions naturally fit forward-forward training due to their ability to operate on individual layer activations without requiring global backpropagation.
- Medium Confidence: The claim that forward-forward achieves comparable performance to backpropagation, as results show mixed outcomes (better average performance for backpropagation but better peak performance for forward-forward).
- Medium Confidence: The Goodness function's robust performance across training methods, though this conclusion is based on limited empirical evidence from a single dataset.

## Next Checks
