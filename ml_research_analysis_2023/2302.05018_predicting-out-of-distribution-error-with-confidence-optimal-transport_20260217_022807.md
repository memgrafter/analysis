# Predicting Out-of-Distribution Error with Confidence Optimal Transport

## Quick Facts
- arXiv ID: 2302.05018
- Source URL: https://arxiv.org/abs/2302.05018
- Reference count: 5
- Primary result: COT estimates OOD error using optimal transport between calibrated softmax outputs and source labels, achieving R² > 0.987 and MAE 1.8-3.4 on CIFAR/TinyImageNet corruption benchmarks

## Executive Summary
This paper introduces Confidence Optimal Transport (COT), a novel method for estimating out-of-distribution (OOD) error without requiring target domain labels. COT leverages the Earth Mover's Distance (EMD) between calibrated softmax outputs of target data and one-hot labels of source data to predict classification error. The method demonstrates superior performance compared to existing OOD error estimation techniques across multiple benchmark datasets and architectures.

## Method Summary
COT operates by computing the Earth Mover's Distance between softmax probability distributions from target data and one-hot encoded source labels. The core insight is that when a model encounters OOD data, its softmax outputs become less confident and more uniform, increasing the transport cost between these outputs and the confident one-hot source labels. By calibrating the model's softmax outputs on source data first, COT establishes a robust baseline for measuring distributional shifts that correlate with classification error.

## Key Results
- Achieved R² correlation coefficients exceeding 0.987 for error prediction across multiple benchmarks
- Maintained mean absolute error around 1.8-3.4 percentage points depending on dataset and architecture
- Consistently outperformed existing OOD error estimation methods including Mahalanobis distance and energy-based approaches

## Why This Works (Mechanism)
The method exploits the relationship between model confidence and prediction accuracy. When a well-calibrated model processes OOD data, its softmax outputs spread probability mass across multiple classes rather than concentrating on the correct class. This spreading increases the Earth Mover's Distance to the one-hot source labels, which directly correlates with increased classification error. The optimal transport framework provides a principled way to measure this distributional shift that captures both the magnitude and direction of probability mass movement.

## Foundational Learning
- **Optimal Transport Theory**: Measures the minimum "work" required to transform one probability distribution into another - needed to quantify distributional shifts between softmax outputs and labels
- **Model Calibration**: Ensures softmax probabilities reflect true confidence levels - required for establishing baseline transport distances that correlate with accuracy
- **Earth Mover's Distance**: A specific optimal transport metric that satisfies metric properties and has efficient computation - chosen for its interpretability and computational tractability
- **Softmax Calibration Techniques**: Methods like temperature scaling or Platt scaling - necessary preprocessing step to ensure model confidences are reliable
- **Distributional Shift Detection**: Framework for identifying when input distributions differ from training data - COT provides a specific instantiation using transport distances
- **Quick check**: Verify that EMD computation between calibrated softmax and one-hot labels correlates with actual error on validation data before applying to OOD

## Architecture Onboarding

**Component Map**: Input Data -> Model Forward Pass -> Softmax Calibration -> EMD Computation -> Error Prediction

**Critical Path**: Target data → Model → Calibrated softmax → EMD with source labels → Error estimate

**Design Tradeoffs**: 
- Uses EMD rather than simpler metrics (KL divergence, Wasserstein distance) for better correlation with error but higher computational cost
- Requires full softmax calibration step, adding preprocessing overhead but improving accuracy
- Depends on having access to source labels for computing reference distances

**Failure Signatures**:
- Poor correlation between EMD and error when model is poorly calibrated
- Degraded performance on extreme domain shifts where softmax distributions bear little resemblance to source class distributions
- Computational bottlenecks when computing EMD for large batch sizes or many classes

**3 First Experiments**:
1. Validate calibration step by checking if model accuracy equals average softmax confidence on source validation set
2. Compute EMD between source softmax outputs and one-hot labels to establish baseline transport distances
3. Test correlation between EMD and error on a small OOD validation set before full benchmark evaluation

## Limitations
- Relies heavily on model calibration quality, which may not hold across all architectures and training regimes
- Theoretical justification for transport-distance-to-error relationship remains implicit rather than rigorously proven
- Evaluation focused primarily on CIFAR and TinyImageNet corruption benchmarks, limiting generalizability to more diverse OOD scenarios

## Confidence

**Claims about COT outperforming existing methods on benchmark datasets**: High - supported by extensive quantitative results with clear metrics

**Claims about COT's general applicability to any OOD setting**: Medium - based on limited experimental scope to corruption benchmarks

**Claims about the theoretical soundness of the transport-distance-to-error relationship**: Low - empirical correlation observed but formal proof lacking
