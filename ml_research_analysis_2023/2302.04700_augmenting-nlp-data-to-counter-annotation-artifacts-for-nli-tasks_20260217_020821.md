# Augmenting NLP data to counter Annotation Artifacts for NLI Tasks

## Quick Facts
- arXiv ID: 2302.04700
- Source URL: https://arxiv.org/abs/2302.04700
- Reference count: 1
- Primary result: Data augmentation reduces word overlap bias in NLI models

## Executive Summary
This paper addresses the problem of annotation artifacts in Natural Language Inference (NLI) datasets, where models exploit dataset-specific biases instead of truly understanding the task. The authors focus on word overlap bias (WOB), where models rely on word overlap between premise and hypothesis to classify entailment. They propose a data augmentation technique that appends neutral sentences to training examples, forcing the model to learn more robust features rather than exploiting superficial patterns.

The augmented model achieves comparable overall performance on the test set but shows a 0.7% improvement on tough entailment examples, demonstrating reduced dependence on WOB and improved generalization. The approach provides a practical method for mitigating annotation artifacts without requiring changes to model architecture or extensive retraining.

## Method Summary
The authors quantify annotation artifacts by splitting entailment examples into "easy" (high overlap) and "tough" (low overlap) sets based on word overlap between premise and hypothesis. They measure model performance on each set to establish baseline bias levels. The proposed augmentation technique appends neutral sentences to training examples, creating scenarios where simple word overlap heuristics would fail. This forces models to learn deeper semantic relationships rather than relying on surface-level patterns. The augmented training data is used to retrain models, with performance evaluated on both easy and tough subsets to measure reduction in bias exploitation.

## Key Results
- Augmented model achieves 0.7% improvement on tough entailment examples
- Overall test performance remains comparable to baseline models
- Reduction in word overlap bias demonstrates improved generalization
- Data augmentation effectively counters annotation artifacts without architectural changes

## Why This Works (Mechanism)
The augmentation approach works by creating training examples where word overlap between premise and hypothesis no longer reliably indicates entailment. By appending neutral sentences, the method breaks the correlation between lexical overlap and semantic relationship, forcing models to develop more sophisticated reasoning capabilities. This disrupts the shortcut learning that occurs when models exploit dataset artifacts, leading to better generalization on examples that don't follow the same biased patterns.

## Limitations
- Focuses exclusively on word overlap bias while NLI datasets contain multiple artifact types
- Performance improvement of 0.7% may not justify computational overhead in all scenarios
- Binary split of examples into easy/tough sets may oversimplify artifact susceptibility
