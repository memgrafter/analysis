# Distilling from Similar Tasks for Transfer Learning on a Budget

## Quick Facts
- arXiv ID: 2304.12314
- Source URL: https://arxiv.org/abs/2304.12314
- Reference count: 40
- Key outcome: Proposed DISTILL NEAREST and DISTILL WEIGHTED methods improve transfer learning under data and compute constraints by selecting and weighting source models via task similarity metrics.

## Executive Summary
This paper addresses the challenge of efficient transfer learning when labeled data is limited and computational resources are constrained. The authors propose using task similarity metrics to select and weight pre-trained source models for knowledge distillation, avoiding the need to fine-tune large foundation models. Their methods, DISTILL NEAREST (selecting a single best source model) and DISTILL WEIGHTED (combining multiple source models weighted by relevance), outperform transfer learning from ImageNet initializations and semi-supervised techniques like FixMatch, achieving an average improvement of 5.6% across 8 diverse target tasks. The results demonstrate that carefully selecting and weighting source models for distillation can yield efficient yet accurate recognition systems under data and compute constraints.

## Method Summary
The method involves selecting and weighting source models for knowledge distillation based on task similarity metrics without requiring access to source data. DISTILL NEAREST selects the single most similar source model using metrics like PARC, while DISTILL WEIGHTED combines multiple source models weighted by their normalized similarity scores. The target model is trained with a combination of supervised loss on labeled data and distillation loss from pseudo-labels generated by the weighted source models. This approach leverages semi-supervised learning by using pseudo-labels from source models to provide structured supervision on unlabeled target data, enabling efficient transfer learning without costly fine-tuning of large foundation models.

## Key Results
- DISTILL NEAREST and DISTILL WEIGHTED outperform ImageNet initialization and semi-supervised methods like FixMatch by 5.6% average across 8 target tasks.
- Task similarity metrics (PARC, CKA, RSA) effectively rank source models for distillation without source data access.
- DISTILL WEIGHTED consistently outperforms DISTILL NEAREST when multiple relevant source models are available.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Task similarity metrics (like PARC) can effectively rank source models for distillation without requiring source data access.
- Mechanism: PARC measures correlation between feature-space distance matrices of target examples (labeled and unlabeled) and their label structures. Higher correlation indicates the source model's features preserve task-relevant groupings in the target space, making its pseudo-labels useful for training.
- Core assumption: Task similarity correlates with downstream distillation performance even when source and target label spaces differ.
- Evidence anchors:
  - [abstract] "task similarity metrics correlate well with predictive performance"
  - [section 4.1] "PARC [9] fits the bill" and is used to quantify similarity
  - [corpus] Weak: No direct neighbor paper discusses PARC; most focus on general task similarity or multi-source transfer without this specific metric.
- Break condition: If source models are too dissimilar in domain or if feature representations are not aligned with target task semantics, PARC scores will not correlate with distillation accuracy.

### Mechanism 2
- Claim: Weighted multi-source distillation outperforms single-source when no one source fully captures target task structure.
- Mechanism: Source models are weighted by normalized task similarity scores raised to power p, allowing emphasis on more relevant sources. This combination of complementary source knowledge yields better target representations than any single source.
- Core assumption: Combining diverse but partially relevant source models improves target task learning more than using only the single best source.
- Evidence anchors:
  - [abstract] "distill multiple source models trained on different domains weighted by their relevance"
  - [section 4.2] Describes DISTILL_WEIGHTED and normalization scheme
  - [corpus] Weak: Neighbors discuss multi-source transfer but not weighted distillation from diverse tasks without source data.
- Break condition: If all source models are equally poor matches, weighting does not help; if one source is overwhelmingly better, weighting adds unnecessary complexity.

### Mechanism 3
- Claim: Semi-supervised pseudo-label distillation bypasses costly fine-tuning while leveraging large model knowledge.
- Mechanism: Pseudo-labels from source models provide structured supervision on unlabeled target data; training target model with these labels plus few ground-truth labels yields accurate model without large compute.
- Core assumption: Pseudo-labels from similar tasks preserve useful semantic groupings even across different label spaces.
- Evidence anchors:
  - [abstract] "pseudo-labels of the source models" and methods outperform fine-tuning
  - [section 4.1] Ldistill_s uses source model outputs as pseudo-labels for unlabeled target data
  - [corpus] Moderate: Some neighbors discuss knowledge distillation but not specifically pseudo-label use across task domains.
- Break condition: If source pseudo-labels are noisy or misaligned with true target structure, training will converge poorly.

## Architecture Onboarding

- Component map:
  - Source models (AlexNet, GoogLeNet, ResNet variants) on various source tasks -> Similarity metric (PARC) computed on small labeled probe set -> Target model (MobileNetV3) initialized from ImageNet weights -> Per-source classifier mapping target features to source label space -> Training loop with SGD and λ-weighted supervised + distillation loss

- Critical path:
  1. Compute PARC similarity scores between each source model and target task.
  2. Select nearest source (DISTILL_NEAREST) or compute weights (DISTILL_WEIGHTED).
  3. Initialize target model with ImageNet weights.
  4. Train with labeled data + pseudo-labels from selected/weighted sources.

- Design tradeoffs:
  - Single vs multi-source: Single is simpler but may miss complementary knowledge; multi-source adds complexity but can improve accuracy when no single source is sufficient.
  - Feature vs pseudo-label similarity: Features give better correlation but pseudo-labels are task-specific; current design uses features for selection/weighting.
  - Equal vs weighted combination: Equal weighting simpler but suboptimal; weighted improves accuracy at cost of hyperparameter tuning (p).

- Failure signatures:
  - Low correlation between PARC scores and test accuracy suggests poor task alignment or metric mismatch.
  - If distillation loss dominates, target model may overfit to noisy pseudo-labels.
  - If λ too high, model may ignore valuable unlabeled supervision.

- First 3 experiments:
  1. Run single-source distillation using highest PARC-scored source model on a small target dataset; verify improvement over ImageNet fine-tuning.
  2. Compare DISTILL_EQUAL vs DISTILL_WEIGHTED with p=1 on a target with multiple relevant sources; measure accuracy gain.
  3. Test effect of reducing labeled data to 5%; verify DISTILL methods still outperform baselines under extreme label scarcity.

## Open Questions the Paper Calls Out

- Question: What is the optimal way to select and weight source models for cross-domain distillation when multiple diverse source tasks are available?
  - Basis in paper: [explicit] The paper discusses using task similarity metrics like PARC to select and weight source models, but questions remain about the best approach for multi-source distillation.
  - Why unresolved: While the paper shows that task similarity metrics correlate with performance, it doesn't definitively establish the optimal selection and weighting strategy, especially for cases with heterogeneous data.
  - What evidence would resolve it: Systematic experiments comparing different source model selection and weighting strategies across a wide range of target tasks and source model combinations would provide insights into optimal approaches.

- Question: How can semi-supervised learning techniques be effectively integrated with cross-domain distillation from multiple source models?
  - Basis in paper: [inferred] The paper mentions that additional semi-supervised losses like FixMatch could be added but leaves exploration for future work, suggesting potential benefits of combining SSL with multi-source distillation.
  - Why unresolved: The paper focuses on the selection and weighting of source models for distillation, but doesn't explore how to best combine this with established semi-supervised learning techniques to maximize performance.
  - What evidence would resolve it: Experiments comparing different combinations of semi-supervised learning methods (e.g., consistency regularization, pseudo-labeling) with multi-source distillation across various target tasks would reveal the most effective integration strategies.

- Question: How does the effectiveness of cross-domain distillation vary with the amount and quality of labeled data available for the target task?
  - Basis in paper: [explicit] The paper conducts experiments with reduced labeled data (5% instead of 20%) and shows that distillation methods still outperform ImageNet initialization, but the relationship between data availability and distillation effectiveness is not fully explored.
  - Why unresolved: While the paper demonstrates that distillation is effective even with limited labeled data, it doesn't provide a comprehensive analysis of how the performance gap between distillation and other methods changes as the amount and quality of labeled data varies.
  - What evidence would resolve it: Experiments systematically varying the amount and quality of labeled data for target tasks, while comparing distillation methods to other approaches, would reveal the conditions under which distillation is most beneficial.

## Limitations

- Data and Compute Efficiency Claims: The experimental validation is limited to a specific set of source models and target tasks, and the computational savings from avoiding fine-tuning are not quantified explicitly.
- Task Similarity Metric Validity: The PARC metric's effectiveness may depend on the specific feature representations and task structures used, and the correlation with distillation performance is not perfect.
- Semi-supervised Pseudo-label Quality: The method relies on potentially noisy pseudo-labels from source models, especially when source and target label spaces differ significantly, and the paper does not thoroughly analyze their impact on final accuracy.

## Confidence

- High: The core claim that task similarity metrics can effectively rank source models for distillation without source data access.
- Medium: The claim that weighted multi-source distillation outperforms single-source when no one source fully captures target task structure.
- Low: The assertion that semi-supervised pseudo-label distillation bypasses costly fine-tuning while maintaining accuracy.
