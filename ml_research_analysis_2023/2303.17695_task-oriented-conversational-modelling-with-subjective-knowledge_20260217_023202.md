# Task Oriented Conversational Modelling With Subjective Knowledge

## Quick Facts
- arXiv ID: 2303.17695
- Source URL: https://arxiv.org/abs/2303.17695
- Reference count: 3
- One-line primary result: Proposed two-step knowledge selection pipeline improves efficiency and accuracy in task-oriented dialogue systems

## Executive Summary
This paper addresses the challenge of knowledge selection in task-oriented dialogue systems by incorporating subjective knowledge from customer reviews and FAQs. The authors propose a two-step pipeline consisting of entity retrieval and knowledge matching, with two entity retrieval methods: a fuzzy logic approach achieving perfect accuracy but high computational cost, and a Named Entity Recognition (NER) method that is 7X faster while maintaining reasonable accuracy. Additionally, they explore keyword extraction from conversation history, finding that using only the last utterance improves exact match accuracy by 4% compared to using all utterances.

## Method Summary
The proposed method uses a two-step knowledge selection pipeline: entity retrieval followed by knowledge matching. For entity retrieval, the authors introduce fuzzy logic-based matching (100% accuracy, computationally expensive) and NER-based extraction (72% accuracy, 7X faster). The NER model is fine-tuned using BERT with IOB tagging (B-ent, I-ent, O) to identify entities from conversation history. For knowledge matching, keyword extraction is performed, with experiments showing that using only the last utterance yields a 4% improvement in exact match accuracy. The complete pipeline is evaluated on the DSTC-11 dataset using knowledge selection exact match accuracy and response generation metrics (BLEU, ROUGE1).

## Key Results
- Fuzzy logic entity retrieval achieves 100% accuracy but with high computational cost
- NER-based entity retrieval is 7X faster while maintaining 72% accuracy
- Using only the last utterance for keyword extraction improves exact match accuracy by 4%
- Proposed methods significantly enhance efficiency and accuracy of knowledge selection

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Entity retrieval using fuzzy logic achieves perfect accuracy but high computational cost.
- Mechanism: Fuzzy logic compares n-grams derived from conversation history against all entity names, selecting the entity with highest similarity score above threshold (0.95).
- Core assumption: Entity names appear as exact or near-exact substrings in conversation history.
- Evidence anchors:
  - [abstract] "First, we propose entity retrieval using fuzzy logic which retrieves the correct entity with 100% accuracy on validation data."
  - [section 3.1] "We perform the fuzzy matching between these n-grams with all the entities present in the knowledge database and select the one with the highest similarity score as the final entity name."
  - [corpus] Weak: Corpus does not directly support fuzzy logic mechanism.
- Break condition: Entity names do not appear in conversation history or require linguistic understanding beyond substring matching.

### Mechanism 2
- Claim: Named Entity Recognition (NER) achieves 7X speedup while maintaining reasonable accuracy (72%).
- Mechanism: Fine-tuned BERT-based NER model classifies tokens into B-ent, I-ent, O tags to directly extract entity names from conversation history.
- Core assumption: Entity names are consistently mentioned and can be identified through token classification.
- Evidence anchors:
  - [abstract] "Our proposed Named Entity Recognition (NER) based entity retrieval method results in 7X faster search compared to the baseline model."
  - [section 3.2] "We use the POS tagging to prepare the training dataset where each token is labeled as one of the followings, B-ent (Beginning entity), I-ent (Inside entity) and O (outside entity)."
  - [table 1] "Fine-tuned NER 72 220 (~7X speedup)"
- Break condition: Entity names are not consistently mentioned or require context beyond token-level classification.

### Mechanism 3
- Claim: Keyword extraction from last utterance improves exact match accuracy by 4% compared to using all utterances.
- Mechanism: Restricting knowledge selection to keywords from the most recent utterance reduces noise and focuses on immediate user intent.
- Core assumption: Relevant keywords for knowledge selection are predominantly contained in the last utterance.
- Evidence anchors:
  - [abstract] "Additionally, we also explore a potential keyword extraction method which can improve the accuracy of knowledge selection. Preliminary results show a 4% improvement in exact match score on knowledge selection task."
  - [section 5] "Table 3 shows that using only the last utterance leads to an improvement of ~4% in exact match accuracy as compared to when we use all the utterances."
  - [corpus] Weak: Corpus does not provide evidence for keyword extraction effectiveness.
- Break condition: Relevant context spans multiple utterances or keywords are distributed across conversation history.

## Architecture Onboarding

- Component map: Conversation history and user utterance -> Entity Retrieval (Fuzzy logic or NER) -> Reduced search space -> Knowledge Matching (Keyword extraction + similarity scoring) -> Top knowledge candidates -> Response generation

- Critical path: Conversation history → Entity Retrieval → Reduced search space → Knowledge Matching → Selected knowledge → Response generation

- Design tradeoffs:
  - Fuzzy logic vs. NER: Perfect accuracy (100%) vs. 7X speedup (72% accuracy)
  - Keyword extraction: Using last utterance only (+4% accuracy) vs. all utterances (baseline)
  - Computational efficiency vs. accuracy in entity retrieval

- Failure signatures:
  - Entity retrieval failure: Incorrect entity leads to irrelevant knowledge candidates
  - Keyword extraction failure: Missing relevant keywords reduces knowledge selection accuracy
  - NER misclassification: Wrong entity tags propagate through the pipeline

## Open Questions the Paper Calls Out

- Basis in paper: [explicit] The paper notes that the NER-based entity retrieval method is 7x faster but still needs improvement in accuracy compared to the fuzzy logic method which achieves 100% accuracy.
- Why unresolved: The paper identifies this as a limitation and suggests future work to improve NER accuracy for this specific task.
- What evidence would resolve it: Experiments comparing improved NER models (e.g., using different architectures or fine-tuning strategies) against the current model, showing higher accuracy while maintaining the speed advantage.

### Open Question 2
- Question: How can the generalizability of the knowledge selection model be improved to handle domains beyond 'hotel' and 'restaurant' as seen in the DSTC-11 dataset?
- Basis in paper: [explicit] The paper acknowledges that the model might be biased due to training data being limited to 'hotel' and 'restaurant' domains, and suggests extending the work to improve generalizability.
- Why unresolved: The current model has not been tested or validated on other domains like 'flight' or 'taxi'.
- What evidence would resolve it: Training and testing the model on additional domains and demonstrating consistent performance across different domain types.

### Open Question 3
- Question: What is the optimal number of utterances from the conversation history needed to improve knowledge selection accuracy without sacrificing computational efficiency?
- Basis in paper: [explicit] The paper presents an ablation study showing that using only the last utterance improves exact match accuracy by 4% compared to using all utterances, suggesting a potential trade-off between accuracy and efficiency.
- Why unresolved: The study does not explore the impact of using different numbers of utterances beyond the extremes of one versus all.
- What evidence would resolve it: Experimental results comparing knowledge selection accuracy using varying numbers of utterances, identifying the point where additional utterances no longer significantly improve accuracy.

- The knowledge selection improvements are measured in isolation without fully demonstrating end-to-end conversational quality gains
