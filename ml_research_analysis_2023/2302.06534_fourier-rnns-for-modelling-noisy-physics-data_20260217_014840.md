# Fourier-RNNs for Modelling Noisy Physics Data

## Quick Facts
- arXiv ID: 2302.06534
- Source URL: https://arxiv.org/abs/2302.06534
- Authors: [List of authors]
- Reference count: 20
- Primary result: Fourier-RNNs significantly outperform both FNO and standard RNNs on noisy, non-Markovian physics data while maintaining comparable performance to FNO on Markovian PDE data

## Executive Summary
This paper introduces Fourier-RNNs, a novel sequential model that integrates Fourier Neural Operators into RNN architecture. By replacing standard linear transformations with Fourier layers, the model learns mappings in both input and Fourier spaces, enabling robust modeling of noisy physics data. The key innovation lies in updating the hidden state within the Fourier space, which allows the model to capture long-range dependencies and noise patterns that are not well-represented in finite-dimensional Euclidean spaces. The Fourier-RNN demonstrates superior performance on Navier-Stokes and wave equation problems with varying noise levels, achieving orders of magnitude lower mean squared errors compared to baseline models.

## Method Summary
Fourier-RNNs extend the Fourier Neural Operator framework by incorporating recurrent neural network architecture. The model replaces standard linear transformations in RNN cells with Fourier layers, enabling learning in both input and Fourier spaces. The hidden state is explicitly represented and updated within the Fourier space, allowing the model to model both Markovian and non-Markovian dynamics effectively. The architecture combines the operator learning capabilities of FNO with the temporal modeling capabilities of RNNs, making it particularly suitable for physics data where modal behaviors are observed across space and time.

## Key Results
- Fourier-RNNs achieve mean squared errors orders of magnitude lower than baseline models on noisy Navier-Stokes and wave equation problems
- The model performs comparably to FNO on Markovian PDE data while significantly outperforming both FNO and standard RNNs on non-Markovian, noisy physics data
- Fourier-RNNs demonstrate enhanced ability to model modal physics behavior while maintaining robustness to noise through their explicit hidden state representation

## Why This Works (Mechanism)

### Mechanism 1
- Claim: F-RNN outperforms standard RNNs in noisy physics data because it learns mappings in both input and Fourier spaces, enabling robust modal behavior modeling
- Mechanism: By integrating Fourier layers into the RNN architecture, F-RNN learns both spatial and temporal patterns simultaneously. The hidden state is updated within the Fourier space, allowing the model to capture long-range dependencies and noise patterns that are not well-represented in finite-dimensional Euclidean spaces
- Core assumption: The noise in physics data has a structured component that can be captured by Fourier analysis
- Evidence anchors:
  - [abstract] "The Fourier-RNN allows for learning the mappings from the input to the output as well as to the hidden state within the Fourier space associated with the temporal data."
  - [section] "Since we have extended the Fourier Neural Operator learning to the hidden state, it is important that we give adequate attention to the initialization of the hidden state."
- Break condition: If the noise in the data is purely random with no underlying structure, Fourier analysis may not provide additional benefits over standard RNN approaches

### Mechanism 2
- Claim: F-RNN maintains comparable performance to FNO on Markovian PDE data while excelling in non-Markovian, noisy scenarios
- Mechanism: F-RNN combines the operator learning capabilities of FNO with the explicit hidden state representation of RNNs. This allows it to model both Markovian and non-Markovian dynamics effectively, adapting to the specific characteristics of the data
- Core assumption: Non-Markovian physics data contains temporal dependencies that extend beyond the immediate previous state
- Evidence anchors:
  - [abstract] "While the Fourier-RNN performs identical to the FNO when handling PDE data, it outperforms the FNO and the conventional RNN when deployed in modelling noisy, non-Markovian data."
  - [section] "The F-RNN allows for learning within the Fourier space along with the input space, making it ideal for modelling physics relevant data where modal behaviors is seen across space and time."
- Break condition: If the physics data is purely Markovian with no long-term dependencies, the explicit hidden state representation may not provide significant advantages

### Mechanism 3
- Claim: The explicit hidden state representation in F-RNN enables better noise handling compared to FNO
- Mechanism: F-RNN's hidden state can retain information from multiple previous time steps, allowing it to distinguish between noise and actual signal variations. This is particularly useful in high-noise regimes where FNO, being Markovian, may misinterpret noise as signal features
- Core assumption: Noise in physics data has temporal patterns that can be learned and distinguished from actual signal patterns
- Evidence anchors:
  - [section] "The explicit hidden state, capable of looking longer into the past allows for the F-RNN to understand the impact the noise has across the data and is able to adjust for it within the solution."
  - [section] "The FNO, being Markovian and only dependent on the previous state, estimates the noise to be a feature of the solution and is unable to account for it."
- Break condition: If the noise is truly random and uncorrelated across time steps, the hidden state representation may not provide significant noise handling benefits

## Architecture Onboarding

- Component map:
  Input layer -> Fourier layers -> RNN cells -> Output layer

- Critical path:
  1. Input data is transformed into Fourier space
  2. Fourier layers learn mappings for both input-output and hidden state updates
  3. Hidden state is explicitly represented and updated across time steps
  4. Output is generated by inverse Fourier transform and additional linear transformations

- Design tradeoffs:
  - Complexity vs. Performance: F-RNN is more complex than standard RNNs but offers superior performance on noisy physics data
  - Computational Cost: The additional Fourier transforms increase computational requirements but provide significant benefits in data modeling
  - Interpretability: The Fourier space representation may be less interpretable than standard Euclidean space approaches

- Failure signatures:
  - Performance degradation in low-noise scenarios where standard RNNs might suffice
  - Increased computational requirements compared to standard RNNs
  - Potential overfitting if the Fourier layers learn noise patterns instead of signal patterns

- First 3 experiments:
  1. Implement a basic F-RNN with one Fourier layer and compare its performance on a simple time-series dataset with a standard RNN
  2. Gradually increase the number of Fourier layers and observe the impact on model performance and computational requirements
  3. Test the F-RNN on a noisy physics dataset (e.g., Navier-Stokes equation) and compare its performance with FNO and standard RNN approaches
