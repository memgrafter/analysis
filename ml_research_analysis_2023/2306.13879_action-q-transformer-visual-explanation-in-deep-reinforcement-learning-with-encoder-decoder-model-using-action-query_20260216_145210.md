# Action Q-Transformer: Visual Explanation in Deep Reinforcement Learning with Encoder-Decoder Model using Action Query

## Quick Facts
- arXiv ID: 2306.13879
- Source URL: https://arxiv.org/abs/2306.13879
- Reference count: 10
- Primary result: AQT achieves higher performance than Rainbow baseline on some Atari 2600 games using transformer-based interpretability

## Executive Summary
Action Q-Transformer (AQT) introduces a transformer encoder-decoder structure to Q-learning based deep reinforcement learning methods, enhancing interpretability by calculating state values via the encoder and advantages via the decoder. The method uses action queries to obtain distinct attention maps for each action, enabling detailed analysis of the agent's decision-making process. Experiments on 17 Atari 2600 games demonstrate that AQT achieves higher performance than the baseline Rainbow model in some games, particularly simpler ones. Visualization of attention maps in games like Breakout and Seaquest reveals that the model correctly focuses on important objects and regions relevant to scoring and actions.

## Method Summary
AQT extends Rainbow with a transformer encoder-decoder that processes CNN-extracted features from Atari frames. The encoder calculates state values by attending to relationships between spatial patches, while the decoder computes advantages using action queries generated from one-hot action vectors. The method introduces Target Trained Q-network (TTQ) to address transformer scaling issues by using pre-trained baseline Q-values as targets. The model is trained using distributional RL with noisy networks, prioritized experience replay, and multi-step returns on 17 Atari 2600 games with 4-frame stacked 84x84 grayscale observations.

## Key Results
- AQT outperforms Rainbow baseline on simpler Atari games (e.g., Breakout, Seaquest)
- Attention visualizations show model focuses on relevant game objects (ball, bricks, submarine)
- TTQ variant improves performance on games where basic AQT struggles
- Method demonstrates potential for interpretable RL through action-specific attention maps

## Architecture Onboarding

- Component map:
  Feature extractor -> Transformer encoder-decoder -> Value branch and Advantage branch -> Q-value calculation
  Query branch (action queries) -> Decoder
  TTQ (target values) -> Training

- Critical path:
  1. Input image is processed by the feature extractor to generate feature maps.
  2. Feature maps are passed to the transformer encoder-decoder, along with action queries from the query branch.
  3. The encoder calculates state values, while the decoder calculates advantages.
  4. State values and advantages are combined to obtain action values.
  5. The agent selects the action with the highest action value.
  6. TTQ provides a target value for training the AQT model, helping it converge faster and achieve better performance.

- Design tradeoffs:
  - Using a transformer encoder-decoder structure increases the model's complexity but allows for better capture of long-term dependencies and improved interpretability.
  - Introducing action queries as input to the decoder enables the calculation of action-specific attention maps but adds complexity to the model.
  - Implementing TTQ helps address the transformer scaling law but requires the availability of a learned baseline model.

- Failure signatures:
  - If the model fails to converge or achieves poor performance, it could indicate issues with the transformer architecture, action queries, or TTQ implementation.
  - If the attention maps do not accurately represent the agent's decision-making process, it could suggest problems with the transformer structure or the action queries.

- First 3 experiments:
  1. Verify that the feature extractor correctly processes the input image and generates meaningful feature maps.
  2. Test the transformer encoder-decoder's ability to calculate state values and advantages using the feature maps and action queries.
  3. Evaluate the effectiveness of the TTQ in improving the model's performance and addressing the transformer scaling law.

## Limitations
- Performance improvements are most notable on simpler Atari games, with limited gains on complex environments
- Visualization examples lack systematic analysis across all 17 games evaluated
- TTQ mechanism's effectiveness shown only through game scores without ablation studies
- No comparison against other transformer-based RL methods or computational complexity analysis

## Confidence
- **High confidence**: The transformer encoder-decoder structure correctly calculates state values and advantages as described in the methodology
- **Medium confidence**: The performance improvements on simpler Atari games are statistically significant and reproducible
- **Low confidence**: The interpretability claims based on attention visualization without quantitative evaluation of alignment between attention maps and true decision factors
