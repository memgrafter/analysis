# Human-machine cooperation for semantic feature listing

## Quick Facts
- arXiv ID: 2304.05012
- Source URL: https://arxiv.org/abs/2304.05012
- Reference count: 13
- The paper proposes a method combining human-curated semantic features with LLM-generated data to efficiently produce high-quality semantic feature norms.

## Executive Summary
This paper addresses the challenge of generating semantic feature norms—lists of features that concepts possess—which traditionally require extensive human labor. The authors propose a novel method that combines a learned model of human lexical semantics from limited data with LLM-generated data to efficiently produce these norms. The approach involves computing a low-dimensional matrix decomposition based on human-generated features and using an LLM to generate "guesses" about which concepts possess which features. These guesses are then used to infer the location of new concepts within the low-dimensional similarity space computed from human-generated features. The method shows significant improvements in alignment between machine and human feature vectors compared to using raw LLM features alone.

## Method Summary
The method combines human-curated semantic feature data with LLM-generated features through matrix completion. It computes an SVD of the human concept-by-feature matrix, retaining top singular values and vectors. An LLM (FLAN-T5 XXL) generates feature vectors for new concepts, which are then mapped via logistic regression to coordinates in the low-dimensional SVD space. The predicted coordinates are re-composed to the original feature space to infer features for new concepts. The approach was evaluated using datasets of animal and tool concepts, showing improved alignment with human features compared to raw LLM outputs.

## Key Results
- Matrix completion approach significantly improves alignment between machine and human feature vectors
- Statistically significant improvements achieved while holding out up to 70% of original data
- Higher-quality semantic feature vectors produced compared to LLMs alone
- Method demonstrates efficiency gains by requiring less human data while maintaining quality

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Matrix decomposition of human feature data captures the underlying covariance structure of semantic features across concepts.
- Mechanism: SVD extracts low-rank principal components representing primary axes of feature variation, encoding relationships between co-occurring features.
- Core assumption: Semantic feature matrix is low-rank, allowing small number of components to represent variance.
- Evidence anchors: [abstract] "concept-by-feature matrices collected in norming experiments are typically high in dimension but low in rank"; [section] "statistically significant improvements while holding out up to 70%".

### Mechanism 2
- Claim: LLM-generated feature vectors provide coarse information that can be refined through low-dimensional space.
- Mechanism: LLM generates initial binary vectors with directional information; logistic regression maps these to SVD space coordinates.
- Core assumption: Noisy LLM predictions contain enough signal for approximate concept positioning.
- Evidence anchors: [abstract] "guesses may not be fully accurate, but can be used to infer where a new concept might reside"; [section] "metric computed separately for animal and tool datasets".

### Mechanism 3
- Claim: Combination of human structure and machine efficiency yields higher quality norms.
- Mechanism: Human data provides ground truth structure via SVD; LLM provides scalable generation; matrix completion corrects and refines LLM errors.
- Core assumption: Human-curated structures contain valuable semantic relationship information.
- Evidence anchors: [abstract] "method yields higher-quality vectors than those produced by LLMs alone"; [section] "statistically significant improvements while holding out up to 70%".

## Foundational Learning

- Concept: Singular Value Decomposition (SVD)
  - Why needed here: Extracts low-rank structure from human feature matrix for dimensionality reduction and matrix completion.
  - Quick check question: What does each component of the SVD (U, Σ, V^T) represent in semantic feature matrices?

- Concept: Signal Detection Theory and d' metric
  - Why needed here: Measures alignment between human and machine feature vectors by treating comparison as binary classification.
  - Quick check question: How does d' differ from simple accuracy metrics with imbalanced classes?

- Concept: Logistic Regression as mapping function
  - Why needed here: Learns mapping from LLM-generated features to coordinates in low-dimensional SVD space.
  - Quick check question: Why is logistic regression appropriate for mapping binary features to continuous SVD coordinates?

## Architecture Onboarding

- Component map: Human feature matrix → SVD decomposition → LLM feature generation → Logistic regression mapping → Matrix reconstruction

- Critical path: 1. Collect human feature norms → 2. Compute SVD → 3. Generate LLM features → 4. Fit logistic regression → 5. Predict coordinates → 6. Reconstruct feature vector

- Design tradeoffs:
  - Matrix rank vs. reconstruction accuracy: Higher rank captures more variance but requires more data
  - LLM size vs. computational cost: Larger models generate better features but are more expensive
  - Number of human examples vs. method efficiency: More examples improve accuracy but reduce efficiency gains

- Failure signatures:
  - Low d' values indicate poor alignment between machine and human features
  - SVD reconstruction error indicates insufficient rank or poor human data quality
  - Logistic regression coefficients with high variance indicate unstable mappings

- First 3 experiments:
  1. Test SVD rank sensitivity by varying rank from 5-20 and measuring reconstruction error
  2. Compare different LLM models (FLAN-T5 variants) on feature generation quality
  3. Evaluate holdout percentages (10%, 30%, 50%, 70%) to determine minimum data requirements

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the optimal rank of the SVD decomposition for maximizing alignment across different domains and dataset sizes?
- Basis in paper: [inferred] Uses rank-10 decomposition but notes "minor variations in performance" as rank changed, with stability "around 10".
- Why unresolved: Only explores rank-10 without systematic investigation across domains or data withholding conditions.
- What evidence would resolve it: Systematic evaluation varying SVD rank from 1-50 while measuring d' for both animal and tool domains under different data withholding conditions.

### Open Question 2
- Question: How does performance compare to other machine-human alignment techniques like RLHF or supervised fine-tuning?
- Basis in paper: [inferred] Only compares to raw LLM features, not other alignment approaches.
- Why unresolved: Establishes improvement over raw LLM features but doesn't benchmark against established alignment techniques.
- What evidence would resolve it: Direct comparisons between matrix completion, RLHF, and supervised fine-tuning on same semantic feature norm datasets.

### Open Question 3
- Question: How does quality vary across different LLM architectures and sizes?
- Basis in paper: [explicit] Uses FLAN-T5 XXL (11B parameters) but doesn't explore other models.
- Why unresolved: Only tests one LLM architecture, leaving questions about smaller or differently-architected models.
- What evidence would resolve it: Testing methodology with various LLM architectures and comparing d' scores.

### Open Question 4
- Question: How well does this approach generalize to semantic domains beyond animals and tools?
- Basis in paper: [inferred] Only tests animal and tool domains, representing subset of possible semantic domains.
- Why unresolved: Doesn't test whether method works equally well for abstract concepts, emotions, or other categories.
- What evidence would resolve it: Applying method to diverse domains (emotions, actions, abstract concepts, events) and measuring alignment.

### Open Question 5
- Question: What is the computational cost-benefit tradeoff compared to collecting more human annotations?
- Basis in paper: [inferred] Claims "potentially huge savings in human effort" but doesn't quantify matrix completion computational costs.
- Why unresolved: Shows improved alignment but doesn't compare computational resources required versus additional human annotation.
- What evidence would resolve it: Cost analysis comparing time/resources for matrix completion versus collecting additional human annotations for various dataset sizes.

## Limitations

- Assumes semantic feature matrices are inherently low-rank, which may not generalize to all semantic domains
- Relies on high-quality human feature norms as training data; systematic biases in human annotations would be encoded and potentially amplified
- Binary feature predictions oversimplify the graded nature of human semantic knowledge
- Evaluation focuses primarily on d' values without capturing other aspects like feature completeness or generation of novel features

## Confidence

- **High Confidence (5/5):** Core claim that combining human-curated structure with LLM-generated data improves semantic feature prediction over raw LLM outputs
- **Medium Confidence (3/5):** Claim that the approach is efficient and scalable; lacks concrete measurements of computational efficiency for large-scale deployment
- **Low Confidence (2/5):** Generalizability claim to broader semantic domains; evaluation limited to two specific domains without evidence for diverse concept categories

## Next Checks

1. **Domain Generalization Test:** Apply the method to at least three additional semantic domains (emotions, physical objects, social roles) and measure whether the low-rank assumption holds and whether d' improvements persist.

2. **Ablation Study on Human Data Requirements:** Systematically vary the amount of human feature data used (5%, 10%, 20%, 50%) and measure resulting d' values to quantify minimum human input needed.

3. **Cross-Lingual Validation:** Train the SVD model on English semantic features but test prediction quality on concepts in other languages where LLMs may have different strengths.
