# TextDefense: Adversarial Text Detection based on Word Importance Entropy

## Quick Facts
- arXiv ID: 2302.05892
- Source URL: https://arxiv.org/abs/2302.05892
- Reference count: 40
- Primary result: TextDefense achieves high AUC scores across multiple datasets, model architectures, and attack methods, outperforming state-of-the-art detection methods.

## Executive Summary
This paper presents TextDefense, a universal adversarial detection method for natural language processing models that leverages the target model's own predictions to identify adversarial examples. The method computes word importance scores for each input text and uses entropy to quantify the distribution scale, identifying adversarial texts by a threshold determined from clean and local adversarial samples. Experiments demonstrate TextDefense's effectiveness across multiple datasets, model architectures, and attack methods, achieving high detection rates while being attack-agnostic.

## Method Summary
TextDefense calculates word importance scores using a deletion-based Word Importance Rank (WIR) algorithm, where each word's importance is measured by the change in model prediction when that word is removed. The method then computes the entropy of absolute importance scores to quantify the distribution scale, with higher entropy indicating more redundant information and likely adversarial text. A threshold is determined using clean and local adversarial examples, and this threshold is applied to classify new inputs as adversarial or clean. The approach is designed to be attack-agnostic, requiring only the target model's predictions without access to attack algorithms or adversarial example generation.

## Key Results
- TextDefense achieves AUC scores typically above 0.9 across multiple datasets and attack methods
- Performance correlates strongly with target model generalizability, with higher validation accuracy yielding better detection
- Outperforms three state-of-the-art detection methods in both clean and adaptive attack scenarios

## Limitations

- Performance strongly depends on target model generalizability, potentially failing on models with lower validation accuracy
- Threshold determination requires generating local adversarial examples, which may be computationally expensive for large-scale applications
- Effectiveness against sophisticated adaptive attacks targeting the entropy-based detection mechanism remains partially unexplored
