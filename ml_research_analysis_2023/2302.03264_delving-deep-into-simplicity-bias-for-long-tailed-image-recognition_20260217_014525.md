# Delving Deep into Simplicity Bias for Long-Tailed Image Recognition

## Quick Facts
- arXiv ID: 2302.03264
- Source URL: https://arxiv.org/abs/2302.03264
- Authors: 
- Reference count: 40

## Executive Summary
This paper investigates Simplicity Bias (SB) in long-tailed image recognition, finding that tail classes suffer more severely from SB, harming their generalization performance. The authors propose Triple-Level Self-Supervised Learning (3LSSL) to mitigate SB by learning more comprehensive features through holistic-, partial-, and augmented-level self-supervised learning. Experiments on five long-tailed benchmark datasets show that 3LSSL consistently outperforms state-of-the-art methods, with particularly strong performance on tail classes.

## Method Summary
The proposed 3LSSL method combines supervised learning with three levels of self-supervised learning to address simplicity bias in long-tailed data. The holistic-level SSL learns comprehensive patterns in the entire image, the partial-level SSL forces the model to learn from masked regions using class activation maps, and the augmented-level SSL enhances tail class representations through an augmented queue mechanism. The method leverages the complementary strengths of supervised and self-supervised learning to improve feature learning, particularly for underrepresented tail classes.

## Key Results
- 3LSSL achieves 59.1% and 59.9% accuracy on ImageNet-LT with ResNet-50 and ResNeXt-50, outperforming previous best results by 1.1% and 2.9%
- On Places-LT, 3LSSL achieves 51.4% accuracy with ResNet-50, a 3.1% improvement over previous best
- Qualitative visualizations demonstrate that 3LSSL effectively learns comprehensive patterns, especially for tail classes

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Simplicity Bias (SB) is more severe for tail classes in long-tailed recognition
- Mechanism: Neural networks preferentially learn simpler predictive patterns (e.g., MNIST digits) over complex patterns (e.g., CIFAR objects), and this bias is amplified when training data is scarce for certain classes
- Core assumption: The MNIST-CIFAR-LT toy dataset accurately models how SB manifests in real long-tailed scenarios
- Evidence anchors:
  - [abstract] "tail classes suffer more severely from SB, which harms the generalization performance of such underrepresented classes"
  - [section 3.1.2] "when the imbalance ratio is 100, even if the CIFAR parts of 'tail' are easier to classify...its classification accuracy only achieves 32.16% under the influence of more serious SB"
  - [corpus] No direct corpus evidence found
- Break condition: If SB were equally distributed across all classes regardless of sample count

### Mechanism 2
- Claim: Self-supervised learning (SSL) mitigates SB by learning more comprehensive features
- Mechanism: SSL's augmentation-invariant representation learning encourages models to capture complex patterns that supervised learning might ignore, particularly benefiting tail classes with limited data
- Core assumption: SSL and supervised learning are complementary rather than redundant
- Evidence anchors:
  - [abstract] "SSL can mitigate SB and perform in complementary to the supervised counterpart by enriching the features extracted from tail samples"
  - [section 3.2] "Combining SSL, the classification accuracy obtains an obvious improvement on the tail data (about 3% improvements)"
  - [section 4.1] "holistic-level SSL to enhance the learning of comprehensive patterns in the holistic level"
- Break condition: If SSL were to learn only simple patterns similar to supervised learning

### Mechanism 3
- Claim: Triple-level SSL specifically addresses long-tailed data distribution challenges
- Mechanism: 3LSSL uses holistic-level (learn comprehensive patterns), partial-level (force learning from masked regions), and augmented-level (enhance tail class representations) SSL to overcome SB's impact on tail data
- Core assumption: The three levels of SSL work synergistically rather than redundantly
- Evidence anchors:
  - [abstract] "propose a novel SSL method tailored to imbalanced data. It leverages SSL by triple diverse levels, i.e., holistic-, partial-, and augmented-level"
  - [section 4] Detailed description of each level's mechanism
  - [section 5.3.1] "comparing #4 vs. #1...both the holistic- and partial-level SSL, it brings 4.5% accuracy boost"
- Break condition: If any single level of SSL were sufficient to achieve similar results

## Architecture Onboarding

- Component map: Encoder → Projector → Class Balancer → Three SSL levels (Holistic, Partial, Augmented) → Classifier
- Critical path: Input → Encoder → Three SSL streams → Aggregated loss → Backpropagation through encoder
- Design tradeoffs: Complexity of triple-level SSL vs. performance gains; computational overhead vs. accuracy improvements
- Failure signatures: No improvement on tail classes; performance degradation on head classes; training instability
- First 3 experiments:
  1. Implement baseline SSL (holistic only) on MNIST-CIFAR-LT to verify SB mitigation
  2. Add partial-level SSL with CAM-based masking to test complex pattern learning
  3. Implement augmented queue mechanism to verify tail class enhancement
