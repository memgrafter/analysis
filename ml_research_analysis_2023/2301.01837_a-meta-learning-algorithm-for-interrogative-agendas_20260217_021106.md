# A Meta-Learning Algorithm for Interrogative Agendas

## Quick Facts
- arXiv ID: 2301.01837
- Source URL: https://arxiv.org/abs/2301.01837
- Reference count: 40
- Key outcome: Meta-learning algorithm learns weighted combinations of FCA-based classifiers to improve accuracy and sample complexity while providing interpretability through feature importance weights.

## Executive Summary
This paper introduces a meta-learning framework for constructing "good" interrogative agendas in formal concept analysis (FCA) that improves the accuracy and sample complexity of categorization tasks. The method assigns real-valued importance weights to different feature subsets by learning a weight function over concept lattices induced by these subsets. During training, gradient descent optimizes these weights to minimize classification loss, and the resulting weighted combination of multiple FCA-based classifiers provides both improved performance and interpretability. The framework allows for negative weights to encode counteracting categorizations and includes a recursive agenda selection strategy to reduce computational complexity. Theoretical analysis shows the framework can model deliberation between agendas from different algorithms, enabling their comparison and combination.

## Method Summary
The meta-learning algorithm operates by constructing concept lattices from feature subsets, then learning a weight function w: R → R that assigns importance to each lattice. For classification, the membership of an object in a class is computed as a weighted sum of base classifier outputs across lattices. Gradient descent is used to optimize these weights to minimize classification loss on training data. The method handles both crisp and non-crisp agendas, with negative weights allowing for the encoding of "opposite" categorizations. A recursive agenda selection strategy starts with low-cardinality feature subsets, learns weights, drops unimportant ones, and iteratively expands to supersets of retained subsets to manage computational complexity.

## Key Results
- Meta-learning improves accuracy and sample complexity of FCA-based classification and outlier detection algorithms
- The framework provides interpretability by assigning importance weights to different feature subsets
- Recursive agenda selection reduces computational complexity while retaining expressiveness
- The method allows encoding of counteracting categorizations through negative weights

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Learning feature set importance improves classifier accuracy and sample complexity.
- Mechanism: The meta-learning algorithm assigns weights to concept lattices induced by different feature subsets. During training, gradient descent optimizes these weights to minimize classification loss. Objects are then classified using a weighted sum over lattice-specific predictions, effectively combining multiple categorizations into a single decision.
- Core assumption: Feature subsets contribute differently to classification accuracy, and the correct weighting of these subsets can be learned from training data.
- Evidence anchors: [abstract], [section] on weighted membership computation
- Break condition: If the chosen basis lattices do not cover the relevant feature space, or if the classification algorithm is insensitive to the agenda, the learned weights cannot improve accuracy.

### Mechanism 2
- Claim: Negative weights allow encoding of "opposite" or counteracting categorizations.
- Mechanism: The framework permits real-valued weights, so negative weights for a lattice indicate that its classification decisions should be inverted. This allows the meta-learner to compensate for systematic mismatches between lattice output and the target task.
- Core assumption: The downstream classification or outlier detection algorithm can be meaningfully interpreted as a soft prediction over [0,1], so negation is well-defined.
- Evidence anchors: [section] on negative weights for opposite categorizations, [abstract]
- Break condition: If the downstream algorithm does not output interpretable probabilities (e.g., hard 0/1 decisions only), negative weights cannot be meaningfully applied.

### Mechanism 3
- Claim: Recursive agenda selection reduces computational complexity while retaining expressiveness.
- Mechanism: Instead of considering all 2^|X| possible feature subsets, the algorithm starts with low-cardinality subsets, learns weights, drops unimportant ones, and iteratively expands to supersets of retained subsets.
- Core assumption: Important feature combinations are likely to contain features already identified as important in simpler subsets (monotonicity assumption).
- Evidence anchors: [section] on recursive agenda selection
- Break condition: If the monotonicity assumption fails (e.g., a feature is irrelevant alone but critical in a specific combination), the recursive pruning will miss the correct agenda.

## Architecture Onboarding

- Component map: Input data (objects × features) -> Basis lattice construction -> Weight initialization -> Gradient descent optimization -> Weighted combination of base classifier outputs -> Classification/outlier detection output

- Critical path: 1. Generate basis concept lattices from feature subsets 2. Initialize random weights 3. For each training epoch: compute weighted sum of base algorithm outputs, calculate loss, backpropagate to update weights 4. Fix weights and use weighted sum to classify new objects

- Design tradeoffs:
  - Basis lattice selection: smaller sets → lower computation but possible loss of accuracy; larger sets → higher expressiveness but exponential growth
  - Weight real vs. constrained: real weights allow negation but may be harder to interpret; non-negative simplifies interpretation but may limit expressiveness
  - Loss function choice: differentiable losses (cross-entropy) enable gradient descent; discrete losses require reinforcement learning or policy gradients

- Failure signatures:
  - Training loss plateaus early: likely insufficient basis lattices or learning rate too low
  - Validation accuracy worse than single-lattice baseline: likely overfitting to training agenda or poor gradient signal from base algorithm
  - Extremely large weights for some lattices: likely imbalance in base algorithm outputs or missing normalization

- First 3 experiments:
  1. Implement a toy dataset (e.g., synthetic apples example) and a simple FCA-based classifier; run the meta-learner with basis = all single-feature lattices; verify that learned weights match known importance
  2. Test recursive agenda selection: start with single-feature lattices, prune low-weight ones, expand to two-feature combinations; measure impact on accuracy and runtime
  3. Compare negative vs. non-negative weight constraints: train both variants on the same dataset; measure accuracy and interpretability differences
