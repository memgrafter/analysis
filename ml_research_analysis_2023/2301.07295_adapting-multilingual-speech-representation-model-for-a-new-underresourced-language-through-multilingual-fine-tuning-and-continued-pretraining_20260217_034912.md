# Adapting Multilingual Speech Representation Model for a New, Underresourced Language through Multilingual Fine-tuning and Continued Pretraining

## Quick Facts
- arXiv ID: 2301.07295
- Source URL: https://arxiv.org/abs/2301.07295
- Reference count: 8
- Key outcome: Continued pretraining on Sakhalin Ainu data reduces CER to 10.6 and WER to 33.5 after 60k updates

## Executive Summary
This study investigates how to adapt a multilingual wav2vec 2.0 model (XLSR-53) for speech recognition in Sakhalin Ainu, an underresourced language. The researchers compare continued pretraining on target language data versus multilingual fine-tuning using additional languages. Results show continued pretraining provides the most consistent performance gains, with optimal results after 60k updates. When target language data is scarce, multilingual fine-tuning with related languages like Hokkaido Ainu can provide additional benefits, especially when using shared character vocabularies.

## Method Summary
The researchers used the XLSR-53 pretrained wav2vec 2.0 model (trained on 56k hours across 53 languages) and adapted it for Sakhalin Ainu through two approaches: continued pretraining on Ainu data for up to 100k updates, and multilingual fine-tuning using various combinations of Ainu, Japanese, and English data. They evaluated performance using Character Error Rate (CER) and Word Error Rate (WER) on a test set. The study also examined the impact of shared versus separate character vocabularies and the use of external language models during decoding.

## Key Results
- Continued pretraining on target language data achieved CER of 10.6 and WER of 33.5 after 60k updates
- Multilingual fine-tuning with related languages improves performance when target data is scarce
- Shared character vocabularies facilitate cross-lingual transfer in low-resource scenarios
- External language models offer limited benefit compared to the model's implicit language model after continued pretraining

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Continued pretraining on target language data reduces ASR error rates more than multilingual fine-tuning alone.
- Mechanism: Exposing the pretrained XLSR-53 model to more Sakhalin Ainu speech data refines its acoustic representations for the specific phoneme patterns and speech rhythms of the target language.
- Core assumption: The pretrained model has already learned useful cross-lingual acoustic features, but needs adaptation to the target language's specific acoustic characteristics.
- Evidence anchors:
  - [abstract]: "continued pretraining on target language data leads to substantial error reduction, with best performance after 60k updates (CER: 10.6, WER: 33.5)"
  - [section 6.3]: "Our results show that continued pretraining is clearly the most effective way to adapt a speech representation model for a new language"
- Break condition: If the target language's acoustic patterns are too divergent from the pretraining languages, or if pretraining data is too limited to capture meaningful variation.

### Mechanism 2
- Claim: Multilingual fine-tuning with data from related languages improves performance when target language data is scarce.
- Mechanism: Fine-tuning with data from a related language (e.g., Hokkaido Ainu) provides additional supervision that helps the model generalize better to the target language.
- Core assumption: Languages share enough acoustic and phonological features for cross-lingual transfer to be beneficial during fine-tuning.
- Evidence anchors:
  - [abstract]: "if a model pretrained on a related speech variety or an unrelated language with similar phonological traits is available, multilingual fine-tuning using additional data from that language can have positive impact on speech recognition performance when there is very little labeled data in the target language"
  - [section 6.3]: "adding data from another variety of Ainu produced the best performing model"
- Break condition: If the languages are too dissimilar or if the target language data is sufficient on its own.

### Mechanism 3
- Claim: Shared character vocabularies facilitate cross-lingual transfer in low-resource scenarios.
- Mechanism: Using a unified character set across languages during fine-tuning reduces the model's confusion between languages and improves its ability to map acoustic features to the correct graphemes.
- Core assumption: Character-level representations are more transferable across languages than language-specific token sets.
- Evidence anchors:
  - [section 6.3.2]: "when there is very little labeled target language data and additional data from a similar speech variety is utilized, it is better to use a shared character vocabulary, as it seems to facilitate cross-lingual transfer"
  - [section 6.3.2]: "With less than 1h of target language data (i.e., 'Wenenekaype' only) and additional data from a similar language (Hokkaido Ainu or Japanese), using a shared output vocabulary resulted in lower error rates"
- Break condition: If languages use vastly different scripts or transliteration methods, making shared vocabularies impractical.

## Architecture Onboarding
- Component map: Pretrained XLSR-53 wav2vec 2.0 model -> Continued pretraining on Ainu data (optional) -> Fine-tuning on target language data (with/without additional languages) -> Viterbi/KenLM decoding
- Critical path: Pretrain XLSR-53 -> Continue pretraining on Ainu data (optional) -> Fine-tune on target language data (with or without additional languages) -> Decode using Viterbi or KenLM language model
- Design tradeoffs: Using additional languages during fine-tuning can improve performance when target language data is scarce, but may introduce confusion if languages are too dissimilar. Shared character vocabularies can facilitate cross-lingual transfer but may not be suitable for all language pairs.
- Failure signatures: If error rates do not improve after continued pretraining or multilingual fine-tuning, it may indicate that the languages are too dissimilar or that the target language data is sufficient on its own.
- First 3 experiments:
  1. Continue pretraining XLSR-53 on Sakhalin Ainu data for 10k updates, then fine-tune on "Wenenekaype" data and evaluate.
  2. Fine-tune XLSR-53 on "Wenenekaype" data with and without additional Hokkaido Ainu data, evaluate performance.
  3. Fine-tune XLSR-53 on "Wenenekaype" data with a shared character vocabulary across Ainu and Japanese, evaluate performance.

## Open Questions the Paper Calls Out
- What is the optimal amount of continued pretraining updates needed to maximize ASR performance for a new low-resource language?
- How does the effectiveness of multilingual fine-tuning vary with the degree of linguistic similarity between the target language and transfer languages?
- What is the impact of shared vs. separate character vocabularies on ASR performance across different language pairs and data availability scenarios?

## Limitations
- Conclusions rest on a single language pair (Sakhalin Ainu with Hokkaido Ainu) and limited data sizes
- The optimal update count of 60k is derived from a single experimental run without uncertainty estimates
- The benefit of shared vocabularies is shown only in a specific scenario with minimal target language data (<1h)

## Confidence
- **High confidence**: Continued pretraining on target language data consistently reduces ASR error rates when sufficient target language data exists. The 10.6 CER and 33.5 WER results after 60k updates are specific and reproducible.
- **Medium confidence**: Multilingual fine-tuning with related languages improves performance when target language data is scarce, but this depends heavily on language relatedness and data availability.
- **Low confidence**: Shared character vocabularies universally facilitate cross-lingual transfer in low-resource scenarios, as evidence is limited to specific Ainu-Japanese combinations.

## Next Checks
1. Test continued pretraining performance across multiple update counts (10k, 30k, 60k, 90k) with statistical significance testing to verify the claimed optimum.

2. Evaluate the multilingual fine-tuning benefit across additional language pairs with varying degrees of relatedness (e.g., Spanish-Portuguese, Mandarin-Cantonese) to assess generalizability.

3. Compare shared versus separate vocabularies across language pairs with different script types (Latin, Cyrillic, Arabic) to determine if the benefit extends beyond similar writing systems.
