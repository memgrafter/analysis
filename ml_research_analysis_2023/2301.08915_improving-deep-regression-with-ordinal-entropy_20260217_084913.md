# Improving Deep Regression with Ordinal Entropy

## Quick Facts
- arXiv ID: 2301.08915
- Source URL: https://arxiv.org/abs/2301.08915
- Reference count: 27
- Key outcome: Proposed ordinal entropy regularizer significantly improves regression performance across depth estimation, crowd counting, and age estimation tasks

## Executive Summary
This paper addresses the performance gap between classification and regression for continuous target estimation by investigating why cross-entropy outperforms MSE loss in feature learning. The authors demonstrate theoretically that MSE loss fails to maximize feature representation entropy, while cross-entropy naturally encourages higher entropy feature spaces. To bridge this gap, they propose an ordinal entropy regularizer that preserves ordinal relationships between labels while increasing feature diversity. The regularizer consists of weighted diversity and tightness terms that spread feature centers based on label distances while keeping features close to their centers. Extensive experiments on synthetic and real-world regression tasks show significant performance improvements, achieving state-of-the-art results on depth estimation benchmarks.

## Method Summary
The method combines standard regression with MSE loss and an ordinal entropy regularizer. The regularizer has two components: a diversity term that spreads feature centers based on label distances, and a tightness term that pulls features toward their centers. Both terms are weighted by distances in the label space to preserve ordinal relationships. The final loss is a weighted sum of the task loss and regularizer terms. Key implementation details include feature normalization before distance computation, sampling subsets for entropy estimation, and empirically setting trade-off parameters λd and λt for each task.

## Key Results
- Achieves state-of-the-art performance on depth estimation benchmarks (NYU-Depth-v2)
- Improves crowd counting accuracy on ShanghaiTech dataset (MAE: 64.1→62.6 on SHA, 7.7→7.5 on SHB)
- Enhances age estimation accuracy across all splits of AgeDB-DIR dataset
- Demonstrates significant improvements in synthetic operator learning tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Regression with MSE loss fails to maximize marginal entropy of feature representations compared to classification with cross-entropy loss.
- Mechanism: MSE loss minimizes H(Z|Y) without increasing H(Z), leading to lower feature diversity. Cross-entropy loss both minimizes H(Z|Y) and maximizes H(Z) through tightness and diversity terms.
- Core assumption: Features learned by regression collapse toward class centers, reducing spread in feature space.
- Evidence anchors:
  - [abstract]: "regression with a mean squared error loss in its ability to learn high-entropy feature representations"
  - [section 3.3]: "minimizing Lmse is a proxy for minimizing H(Z|Y), without increasing H(Z)"
  - [corpus]: Weak - no direct mentions of entropy maximization in MSE vs cross-entropy comparison
- Break condition: If feature normalization is removed, the entropy gap disappears as shown in ablation studies.

### Mechanism 2
- Claim: The ordinal entropy regularizer spreads feature centers while keeping features close to their centers, preserving ordinal relationships.
- Mechanism: Weighted diversity term encourages distance between feature centers based on label distances, while tightness term pulls features toward their centers.
- Core assumption: Label distances can be used as weights to maintain ordinal relationships in feature space.
- Evidence anchors:
  - [section 4]: "weight the feature norms in L'd with wij, where wij are the distances in the label space Y"
  - [section 5.4]: "Table 1 shows that using the unweighted diversity term...is worse than the weighted version"
  - [corpus]: Weak - no direct mentions of weighted diversity for ordinal preservation
- Break condition: If weight function wij is set to uniform (ignoring label distances), ordinal relationships break.

### Mechanism 3
- Claim: Even with limited samples, the ordinal entropy regularizer effectively improves regression performance.
- Mechanism: Entropy estimation from M samples remains effective even when M is small (as low as 2), with performance improving as M increases up to a point.
- Core assumption: Pairwise distances in limited samples can approximate true feature space entropy.
- Evidence anchors:
  - [section 5.4]: "Results corroborate the conclusion derived from the linear task" for nonlinear operator learning
  - [section 5.4]: "when M = 2, the performance is slightly better than the baseline model"
  - [corpus]: Weak - no direct mentions of sample size effects on entropy regularization
- Break condition: If M becomes too large, performance degrades due to insufficient room to maneuver feature distances.

## Architecture Onboarding

- Component map:
  - Feature encoder (ϕ) -> Regression head (fθ) -> Predictions
  - Regularizer components: Diversity term (Ld) + Tightness term (Lt)
  - Task loss (Lm) + Regularizer terms (λd·Ld + λt·Lt)

- Critical path:
  1. Forward pass: Input → Feature encoder → Regression head → Predictions
  2. Compute task loss (Lm) and ordinal entropy terms (Ld, Lt)
  3. Backward pass: Gradients flow through both task and regularizer losses
  4. Parameter update: Apply weighted combination of all losses

- Design tradeoffs:
  - Sample size (M) vs. computational efficiency: Larger M improves entropy estimation but increases quadratic complexity
  - λd, λt values: Too high overpowers task loss; too low underutilizes regularizer benefits
  - Feature normalization: Essential for entropy estimation but adds preprocessing step

- Failure signatures:
  - Performance degrades when λd, λt are set too high (regularizer dominates task loss)
  - No improvement observed when feature normalization is removed
  - Ordinal relationships break when using uniform weights instead of label-distance-based weights

- First 3 experiments:
  1. Baseline regression with MSE loss only (verify lower entropy than classification)
  2. Regression with diversity term only (Ld) to test entropy increase without ordinal preservation
  3. Full ordinal entropy (Ld + Lt) to verify combined benefits of entropy and ordinal preservation

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How does the proposed ordinal entropy regularizer perform on regression tasks with very large label spaces (e.g., millions of classes)?
- Basis in paper: [inferred] The paper mentions that for depth estimation, they use M=3536 samples for entropy estimation, but doesn't explore extremely large label spaces.
- Why unresolved: The paper focuses on regression tasks with moderate label spaces (depth, crowd count, age) but doesn't investigate scalability to very large label spaces.
- What evidence would resolve it: Experiments on regression tasks with millions of classes, showing how performance scales with increasing label space size.

### Open Question 2
- Question: Can the ordinal entropy regularizer be extended to handle regression tasks with non-ordinal continuous labels?
- Basis in paper: [inferred] The paper assumes ordinal relationships exist between labels and uses L2 distances in the label space, but doesn't discuss non-ordinal cases.
- Why unresolved: The current formulation relies on ordinal relationships to define the weighting function wij, making it unclear how it would work for non-ordinal labels.
- What evidence would resolve it: Experiments on regression tasks with non-ordinal continuous labels, demonstrating how the regularizer can be adapted or showing its limitations.

### Open Question 3
- Question: How sensitive is the ordinal entropy regularizer to the choice of trade-off parameters λd and λt across different regression tasks?
- Basis in paper: [explicit] The paper mentions that λd and λt are set empirically and shows sensitivity analysis for λd on operator learning, but doesn't explore cross-task sensitivity.
- Why unresolved: While the paper provides some analysis, it doesn't investigate how sensitive the performance is to these parameters when applied to different types of regression tasks.
- What evidence would resolve it: Systematic experiments varying λd and λt across multiple regression tasks, showing how performance changes with different parameter settings.

## Limitations
- The theoretical analysis relies on assumptions about feature distributions that are not fully validated empirically
- Performance improvements depend heavily on proper feature normalization, which adds preprocessing complexity
- The method requires careful tuning of λd and λt parameters for each specific task

## Confidence
- High confidence: The experimental results showing performance improvements with the ordinal entropy regularizer across all tested tasks
- Medium confidence: The theoretical analysis connecting MSE loss to reduced feature entropy compared to cross-entropy
- Low confidence: The claim that entropy maximization alone explains the performance gap between regression and classification

## Next Checks
1. Direct entropy measurement validation: Measure and compare feature entropy for regression with/without the regularizer on the same datasets to directly verify the entropy claims.
2. Controlled synthetic experiments: Create synthetic datasets where the ordinal relationships are explicitly known and test whether the regularizer preserves these relationships while improving regression performance.
3. Ablation of entropy estimation: Replace the meanNN entropy estimator with alternative entropy estimation methods to verify that results are robust to the choice of entropy approximation.
