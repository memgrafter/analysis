# Evaluating robustness of support vector machines with the Lagrangian dual approach

## Quick Facts
- arXiv ID: 2306.02639
- Source URL: https://arxiv.org/abs/2306.02639
- Reference count: 40
- Primary result: Proposed SDVer method improves provable robustness verification for SVMs with nonlinear kernels compared to state-of-the-art SAVer method

## Executive Summary
This paper addresses the challenge of evaluating adversarial robustness in support vector machines (SVMs) with nonlinear kernels, which are widely used in safety-critical applications but pose security threats due to verification difficulties. The authors propose SVM dual verifier (SDVer), a novel method based on Lagrangian duality that transforms the verification problem into a convex optimization problem solvable via subgradient methods. Experimental results demonstrate that SDVer achieves better provable robustness percentages than SAVer, particularly for nonlinear kernels like polynomial, sigmoid, and RBF, while maintaining similar performance for linear kernels.

## Method Summary
The SDVer method formalizes adversarial robustness evaluation of SVMs as an optimization problem and solves it using Lagrangian duality to obtain a lower bound. The approach reformulates SVMs with various kernel types as feedforward neural networks, enabling unified verification across different kernels. The Lagrangian dual problem is solved using a subgradient method enhanced with the Adam optimizer, which provides faster convergence and better stability compared to basic subgradient methods. The method computes a lower bound on the verification objective, allowing classification of samples as provably robust or vulnerable to adversarial perturbations.

## Key Results
- SDVer achieves higher provable robustness percentages than SAVer for SVMs with nonlinear kernels (polynomial, sigmoid, RBF) on MNIST and Fashion-MNIST datasets
- For dissimilar class pairs (e.g., 0 vs 1, ankle-boot vs bag), SDVer achieves 73.7% provable robustness for RBF kernel compared to SAVer's 51.7%
- For similar class pairs (e.g., 4 vs 9, shirt vs coat), SDVer achieves 68.1% provable robustness for RBF kernel compared to SAVer's 50.3%
- SDVer maintains comparable performance to SAVer for linear kernels, achieving similar provable robustness percentages

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Lagrangian duality transforms a nonlinear SVM verification problem into a convex optimization problem that can be solved efficiently using subgradient methods.
- Mechanism: The adversarial robustness verification of SVMs is formalized as an optimization problem (8). This problem is generally NP-hard for nonlinear kernels. By introducing Lagrangian multipliers, the original problem is converted into a Lagrangian dual problem (9), which is convex and can be solved using subgradient methods to obtain a lower bound on the original problem's optimal value.
- Core assumption: The Lagrangian dual problem provides a tight enough lower bound on the original verification problem to make robust decisions about adversarial examples.
- Evidence anchors:
  - [abstract] "We first formalize the adversarial robustness evaluation of SVMs as an optimization problem. Then a lower bound of the original problem is obtained by solving the Lagrangian dual problem of the original problem."
  - [section] "By using the subgradient method to solve the Lagrangian dual problem, a lower bound of the original optimization problem is obtained."
- Break condition: If the gap between the dual bound and the true optimal value is too large, the verification results become unreliable, potentially misclassifying vulnerable samples as robust.

### Mechanism 2
- Claim: Feedforward neural network representation enables unified verification across different kernel types.
- Mechanism: The SVM optimization problem is reformulated as a feedforward neural network representation (8) regardless of kernel type. This allows the same verification framework to handle linear, polynomial, sigmoid, and RBF kernels by simply adjusting the activation functions in each layer.
- Core assumption: All SVM kernel functions can be accurately represented as feedforward neural networks with appropriate activation functions.
- Evidence anchors:
  - [section] "We formulate the optimization problem (3) as a feedforward neural network representation" and "To obtain a more general feedforward neural network representation of (3), we set zL = f(x′)"
  - [section] "When the kernel function is sigmoid, the corresponding optimization problem is a type of sigmoid programming problem. The work [52] has proved that the solution to the sigmoid programming problem is NP-hard."
- Break condition: If certain kernels cannot be accurately represented as feedforward networks, or if the representation introduces approximation errors that significantly affect verification accuracy.

### Mechanism 3
- Claim: Subgradient method with Adam optimizer efficiently approximates the dual problem's optimal value.
- Mechanism: The dual problem is solved iteratively using a subgradient method enhanced with the Adam optimizer (Algorithm 1). This combination provides faster convergence and better stability compared to basic subgradient methods, allowing the algorithm to find tight bounds within practical time limits.
- Core assumption: The subgradient method with Adam converges to a sufficiently accurate approximation of the dual problem's optimal value for practical verification purposes.
- Evidence anchors:
  - [section] "We combine the original subgradient method with the Adam algorithm [55] to achieve convergence effectiveness."
  - [section] "The details of the algorithm are provided as Algorithm 1."
- Break condition: If the subgradient method fails to converge within the maximum iteration limit (K=10350000) or if the convergence is too slow for practical applications.

- Critical path: Input (x, y, δ) → SVM neural network representation → Lagrangian dual formulation → Subgradient method with Adam optimization → Lower bound and robustness decision
- Design tradeoffs:
  - Accuracy vs. computational efficiency: Tighter bounds require more iterations but increase computation time

  - Algorithm fails to converge within iteration limit
  - Verification results show high false positive/negative rates on benchmark datasets
  - Performance degrades significantly on certain kernel types or datasets

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can the time complexity of SDVer be reduced to match or outperform SAVer's linear time complexity?
- Basis in paper: [explicit] The paper states "Our method has no advantage in terms of time consumption. How reduce the time complexity of our proposed method is a challenging direction."
- Why unresolved: The paper acknowledges the sublinear time complexity of SDVer compared to SAVer's linear complexity but does not provide a solution or methodology to improve it.
- What evidence would resolve it: Development and demonstration of an optimized version of SDVer with improved time complexity, along with experimental validation showing comparable or better performance than SAVer in terms of computational efficiency.

### Open Question 2
- Question: Can the robustness verification method for binary-class SVMs be extended to multi-class SVMs effectively?
- Basis in paper: [explicit] The paper concludes with "Our proposed method is suitable for evaluating the adversarial robustness of binary-class SVMs. The multi-class SVMs are also widely used in safety-critical fields. In the future, we also will extend our robustness verification method for binary-class SVMs to multi-class SVMs."
- Why unresolved: The paper focuses on binary-class SVMs and explicitly mentions the need for future work to extend the method to multi-class SVMs, indicating this has not yet been addressed.
- What evidence would resolve it: Implementation and validation of SDVer for multi-class SVMs, with experimental results demonstrating its effectiveness and comparability to existing methods for multi-class robustness verification.

### Open Question 3
- Question: How does the performance of SDVer compare to other robustness verification methods for SVMs beyond SAVer, especially in terms of computational efficiency and accuracy?
- Basis in paper: [inferred] The paper compares SDVer only to SAVer, leaving open the question of how it performs relative to other potential methods for SVM robustness verification.
- Why unresolved: The paper's experimental evaluation is limited to a comparison with SAVer, and does not explore the broader landscape of robustness verification methods for SVMs.
- What evidence would resolve it: Comprehensive benchmarking of SDVer against a variety of robustness verification methods for SVMs, including SAVer and others, evaluating both computational efficiency and accuracy of robustness assessments.

## Limitations
- Experimental evaluation limited to binary classification on MNIST and Fashion-MNIST datasets with specific class pairs
- Computational complexity and scalability for large datasets and high-dimensional feature spaces not thoroughly discussed
- Comparison with SAVer focuses primarily on provable robustness percentages without examining false positive/negative rates or computational efficiency trade-offs

## Confidence
- High confidence: The fundamental mechanism of Lagrangian duality providing a convex relaxation for verification problems is theoretically sound and well-established in optimization literature.
- Medium confidence: The empirical results showing improved provable robustness for nonlinear kernels are convincing but limited by the narrow experimental scope and lack of statistical significance analysis.
- Medium confidence: The neural network representation of SVM kernels as a unified verification framework is conceptually valid, though the practical impact on verification accuracy requires more extensive validation.
