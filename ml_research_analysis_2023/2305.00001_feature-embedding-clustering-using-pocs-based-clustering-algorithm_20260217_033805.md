# Feature Embedding Clustering using POCS-based Clustering Algorithm

## Executive Summary
This paper introduces a POCS-based clustering algorithm for feature embedding clustering problems and compares it with K-Means and Fuzzy C-Means algorithms. The algorithm represents each data point as a convex set and uses parallel projection operations from cluster prototypes to corresponding data members to minimize the objective function. Experiments on synthetic embedding datasets from the 5 Celebrity Faces and MNIST datasets demonstrate competitive performance compared to classical clustering schemes.

## Method Summary
The POCS-based clustering algorithm treats each data point as a convex set and applies parallel projection operations from cluster prototypes to corresponding data members to minimize the objective function. Prototype initialization uses the K-Means++ method. The algorithm iteratively assigns data points to clusters and updates prototypes by computing weighted simultaneous projections onto convex sets representing individual data points. The objective function is defined as minimizing the sum of weighted squared distances between data points and their projected positions.

## Key Results
- On Face embedding set, POCS-based clustering achieves similar clustering error to K-Means++ but converges 2-3 times faster
- On MNIST embedding set, POCS-based clustering has slightly higher clustering error than K-Means but converges significantly faster
- Overall, POCS-based clustering shows competitive performance compared to classical clustering schemes
