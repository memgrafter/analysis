# Provably Efficient Adversarial Imitation Learning with Unknown Transitions

## Quick Facts
- arXiv ID: 2306.06563
- Source URL: https://arxiv.org/abs/2306.06563
- Reference count: 40
- Primary result: Achieves minimax optimal expert sample complexity of Õ(H^{3/2}|S|/\epsilon) and interaction complexity of Õ(H^{3}|S|^{2}|A|/\epsilon^{2})

## Executive Summary
This paper addresses adversarial imitation learning (AIL) in the challenging setting where both the expert policy and environment transitions are unknown. The authors propose a novel model-based framework that connects AIL with reward-free exploration (RFE), enabling efficient learning of transition models before performing imitation. The resulting algorithm, MB-TAIL, achieves optimal sample complexity while significantly improving interaction complexity compared to prior work. The approach is further extended to function approximation settings using state abstractions, removing dependence on state space size.

## Method Summary
The method follows a two-phase approach: first using RF-Express to learn a transition model through reward-free exploration, then performing imitation learning using this learned model. The key innovation is a transition-aware estimator that splits expert trajectories, using half for behavior cloning on visited states and half for online interactions on unvisited states. This separates policy estimation uncertainty from state-action visitation uncertainty. The algorithm employs gradient-based optimization to solve a saddle point problem for state-action distribution matching, leveraging the learned transition model for efficient policy evaluation.

## Key Results
- Achieves minimax optimal expert sample complexity of Õ(H^{3/2}|S|/\epsilon)
- Improves interaction complexity by O(H) compared to best-known algorithm OAL
- Extends to function approximation setting with complexity independent of state space size |S|
- Demonstrates effectiveness on Reset Cliff MDP with state size 20, action size 5, horizon 20

## Why This Works (Mechanism)

### Mechanism 1
- Claim: MB-TAIL achieves optimal expert sample complexity by splitting expert trajectories into two parts
- Mechanism: Uses first half for behavior cloning on visited states, then collects online interactions for unvisited states, separating policy estimation from visitation uncertainty
- Core assumption: Expert policy is deterministic, enabling perfect BC on visited states
- Break condition: Stochastic expert policies would degrade BC accuracy on visited states

### Mechanism 2
- Claim: MB-TAIL improves interaction complexity through model-based RFE instead of model-free exploration
- Mechanism: Learns transition model via RF-Express first, then uses model-based planning for efficient imitation
- Core assumption: Transition model can be learned accurately enough for good policy evaluation
- Break condition: Poor transition model learning in large/complex state spaces

### Mechanism 3
- Claim: Function approximation extension removes dependence on state space size
- Mechanism: Uses state abstractions satisfying bisimulation conditions to operate on abstract MDPs
- Core assumption: State abstractions exist with consistent rewards/transitions within abstract states
- Break condition: No suitable abstractions satisfying bisimulation conditions

## Foundational Learning

- **Reward-free exploration (RFE)**: Needed because AIL lacks environment rewards; RF-Express enables transition model learning without rewards. Quick check: How does RF-Express guarantee uniform policy evaluation across all possible reward functions?

- **State abstractions and bisimulation**: Needed to reduce complexity dependence on state space size; groups states with similar transition/reward properties. Quick check: What conditions must abstractions satisfy to preserve optimal policies?

- **Online gradient descent for saddle point optimization**: Needed to solve the minimax optimization problem for distribution matching. Quick check: How does ℓ1-norm's dual representation convert distribution matching to saddle point form?

## Architecture Onboarding

- **Component map**: Expert data → BC policy estimation → Online interaction → Transition model learning → Abstract state-action distribution estimation → Saddle point optimization → Final policy
- **Critical path**: Transition model learning is critical - downstream policy evaluation/optimization fails without accurate model
- **Design tradeoffs**: Model-based (efficient but requires accurate model learning) vs model-free (robust but less efficient)
- **Failure signatures**: Poor imitation indicates either inadequate expert samples (high estimator variance) or insufficient interactions (poor transition model)
- **First 3 experiments**:
  1. Test BC performance on visited states with varying expert sample sizes
  2. Verify RF-Express learns accurate transition models on simple MDPs with known transitions
  3. Test full algorithm on small tabular MDPs where ground truth can be computed

## Open Questions the Paper Calls Out

- Question: Can MB-TAIL achieve better performance under specific environment or expert policy assumptions?
- Basis: Paper mentions potential for better guarantees on structured instances but doesn't explore this
- Why unresolved: No empirical/theoretical exploration of performance under specific assumptions
- What would resolve: Results showing MB-TAIL achieves better performance under specific assumptions

### Open Question 2
- Question: How does MB-TAIL compare to state-of-the-art algorithms in complex/high-dimensional environments?
- Basis: Only tested on simple Reset Cliff MDP
- Why unresolved: No experiments in more complex environments
- What would resolve: Empirical comparison in complex/high-dimensional environments

### Open Question 3
- Question: How does MB-TAIL's performance scale with state and action space sizes?
- Basis: Theoretical results for tabular and function approximation settings, but no scaling analysis
- Why unresolved: No detailed analysis of scaling behavior
- What would resolve: Theoretical/empirical results on scaling with state/action space sizes

## Limitations

- **Transition model accuracy dependence**: Performance heavily depends on accurate transition model learning, which may fail in complex environments
- **Deterministic expert assumption**: Strong assumption that limits applicability to real-world scenarios with stochastic expert policies
- **Restrictive state abstraction requirements**: Bisimulation condition is very strong and may be difficult to satisfy in practice

## Confidence

- **Theoretical claims**: High confidence - rigorous mathematical proofs provided
- **Interaction complexity improvement**: Medium confidence - theoretical derivation sound but practical significance depends on RF-Express efficiency
- **Function approximation extension**: Low confidence - bisimulation requirement very strong, lacks empirical validation

3. **State abstraction discovery**: Develop methods for automatically discovering abstractions satisfying bisimulation condition and test empirical complexity reduction
