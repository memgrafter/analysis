# What Do Self-Supervised Vision Transformers Learn?

## Quick Facts
- arXiv ID: 2305.00729
- Source URL: https://arxiv.org/abs/2305.00729
- Reference count: 34
- Self-supervised vision transformers trained via contrastive learning (CL) and masked image modeling (MIM) exhibit fundamentally different learning behaviors.

## Executive Summary
Self-supervised vision transformers trained via contrastive learning (CL) and masked image modeling (MIM) exhibit fundamentally different learning behaviors. CL captures global, shape-oriented features and excels at linear probing, but suffers from attention homogeneity that limits dense prediction and fine-tuning performance. MIM captures local, texture-oriented features, preserves token diversity, and excels in fine-tuning and dense tasks, but lags in linear probing. A simple linear combination of CL and MIM objectives leverages both strengths, outperforming either method alone across multiple datasets.

## Method Summary
The paper compares contrastive learning (CL) and masked image modeling (MIM) for self-supervised vision transformer training. CL uses global projections with contrastive loss to maximize similarity between positive views, while MIM reconstructs masked patches from context. The study analyzes attention behavior, representation transformation, and downstream task performance across ImageNet-1K, iNaturalist-2018, and ADE20K datasets. Experiments include linear probing, fine-tuning, and dense prediction evaluation, along with attention analysis via attention distance and normalized mutual information, representation analysis using SVD and Fourier analysis, and t-SNE visualization.

## Key Results
- CL captures global, shape-oriented features and linearly separates images well, but suffers from attention homogeneity limiting dense prediction
- MIM captures local, texture-oriented features, preserves token diversity, and excels in fine-tuning and dense tasks, but lags in linear probing
- A simple linear combination of CL and MIM objectives outperforms either method alone on ImageNet, iNaturalist-18, and ADE20K

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Contrastive learning (CL) achieves better linear probing accuracy because it captures global, shape-oriented features that help distinguish whole objects.
- Mechanism: CL uses image-level global projections to maximize similarity between positive views and dissimilarity between negative views. This forces the model to extract invariant global structures like object shapes, which are highly correlated with image identity and thus separable by a linear classifier.
- Core assumption: Shape information is more discriminative for image-level classification than texture or fine-grained token features.
- Evidence anchors:
  - [abstract] "CL captures global, shape-oriented features and linearly separates images well"
  - [section] "CL recognizes objects and distinguish images. On the other hand, however, it also suggests that CL struggles to preserve local information"
  - [corpus] Weak: no direct neighbor discusses shape vs texture in CL; this is the novel claim here.
- Break condition: If downstream tasks require fine-grained localization or texture discrimination, CL's shape bias becomes a liability.

### Mechanism 2
- Claim: Masked image modeling (MIM) excels at fine-tuning and dense prediction because it preserves token diversity and captures local, texture-oriented features.
- Mechanism: MIM reconstructs masked patches from their context, forcing the model to learn rich token-level representations that encode fine spatial details like textures. The diversity of token features improves dense prediction performance where local information matters.
- Core assumption: Token-level reconstruction naturally encourages preservation of local spatial detail.
- Evidence anchors:
  - [abstract] "MIM captures local, texture-oriented features, preserves token diversity, and excels in fine-tuning and dense tasks"
  - [section] "MIM applies a different transformation to individual tokens...MIM alters the distance between tokens of a single image"
  - [corpus] Weak: neighbor papers discuss MIM performance but not the texture-preserving mechanism in detail.
- Break condition: If the downstream task is purely image-level classification with large models, MIM's token-level focus offers diminishing returns.

### Mechanism 3
- Claim: CL suffers from attention homogeneity collapse, reducing representational diversity and limiting scalability and dense prediction.
- Mechanism: CL's global attention patterns cause all query tokens and heads to focus on similar global structures (e.g., object boundaries), making their attention maps nearly identical. This homogenizes token representations, reducing the model's capacity to learn diverse features.
- Core assumption: Diverse attention patterns are necessary for rich token representations and effective dense prediction.
- Evidence anchors:
  - [abstract] "CL...suffers from attention homogeneity across tokens, limiting dense prediction and fine-tuning performance"
  - [section] "Self-attentions of CL surprisingly indicate almost identical object shapes for the two query tokens...this phenomenon occurs because the self-attention maps of CL are homogeneous"
  - [corpus] Moderate: neighbor paper on attention visualization supports the concept of homogeneous attention but not specifically in CL.
- Break condition: If the model is shallow or the task is simple image classification, attention homogeneity may not severely impair performance.

## Architecture Onboarding

- Component map:
  Input: Image patches → patch embeddings + positional embeddings → Stacked Transformer blocks (multi-head self-attention + MLP) → CL branch: Global projector + contrastive loss (e.g., MoCo) / MIM branch: Masking strategy + decoder head for reconstruction → Output: Representations for downstream tasks

- Critical path:
  1. Pre-training (CL or MIM) → learn representations
  2. Linear probing: freeze backbone, train linear classifier on [CLS] token
  3. Fine-tuning: update entire model on downstream task
  4. Dense prediction: use token features for segmentation/detection

- Design tradeoffs:
  - CL: better for linear probing, worse for dense tasks due to attention homogeneity; shape-biased.
  - MIM: better for fine-tuning and dense tasks, worse for linear probing; texture-biased; preserves token diversity.
  - Hybrid: balances both strengths but adds complexity and training instability risk.

- Failure signatures:
  - CL: poor dense prediction accuracy, homogeneous attention maps across tokens, low token-level representational diversity.
  - MIM: poor linear probing accuracy, may overfit to textures, requires careful masking strategy.
  - Hybrid: instability if λ is poorly tuned; may not converge if objectives conflict.

- First 3 experiments:
  1. Compare linear probing accuracy of CL vs MIM pre-trained ViTs on ImageNet to confirm shape vs texture bias.
  2. Visualize attention maps for CL and MIM models to confirm attention homogeneity vs diversity.
  3. Apply Fourier analysis to pre-trained representations to verify low-frequency vs high-frequency utilization.

## Limitations

- The analysis relies heavily on indirect evidence linking architectural mechanisms to observed performance differences, with the causal chain not fully established.
- The interpretation that CL's shape bias inherently limits dense prediction performance could be confounded by other factors like optimization dynamics.
- The claim that frequency domain analysis definitively proves the shape vs texture bias claims is not conclusively demonstrated.

## Confidence

**High Confidence:**
- CL exhibits better linear probing accuracy than MIM
- MIM exhibits better fine-tuning and dense prediction performance than CL
- Attention homogeneity is observed in CL models
- Early/middle layers are more important for MIM; later layers are more important for CL

**Medium Confidence:**
- CL captures global, shape-oriented features while MIM captures local, texture-oriented features
- The mechanism of attention homogeneity causing poor dense prediction performance
- The complementary nature of CL and MIM objectives when combined

**Low Confidence:**
- The specific claim that shape information is inherently more discriminative for linear probing than texture information
- The assertion that frequency domain analysis definitively proves the shape vs texture bias claims
- The assumption that attention diversity is the primary factor enabling dense prediction success

## Next Checks

1. **Ablation study on attention diversity**: Train a CL variant with explicit regularization to increase attention diversity (e.g., attention entropy maximization) and measure the impact on dense prediction performance while controlling for other variables.

2. **Frequency analysis on downstream tasks**: Apply Fourier decomposition to feature maps during fine-tuning and dense prediction tasks to verify whether CL and MIM models actually use different frequency components during inference, not just during pre-training.

3. **Shape vs texture classification probe**: Train separate linear probes on synthetic datasets containing only shape information (silhouettes) versus only texture information to empirically verify which type of feature is more linearly separable and task-relevant.
