# Nondeterministic Stacks in Neural Networks

## Quick Facts
- arXiv ID: 2304.12955
- Source URL: https://arxiv.org/abs/2304.12955
- Reference count: 0
- One-line primary result: A method for incorporating nondeterministic stacks into neural networks that significantly improves handling of syntactic ambiguity

## Executive Summary
This dissertation introduces a method for incorporating nondeterministic stacks into neural networks, addressing the limitation of existing stack-augmented models in handling syntactic ambiguity. The core idea is to develop a differentiable data structure that efficiently simulates a nondeterministic pushdown automaton, representing an exponential number of computations with a dynamic programming algorithm. This allows the neural network to explore multiple syntactic interpretations in parallel, mirroring human language processing. The proposed Nondeterministic Stack Recurrent Neural Network (NS-RNN) and its variant, the Renormalizing NS-RNN (RNS-RNN), demonstrate significant improvements in learning context-free languages, particularly those with ambiguity.

## Method Summary
The dissertation develops a differentiable weighted pushdown automaton (WPDA) that uses Lang's algorithm to efficiently represent all possible runs of a nondeterministic pushdown automaton. The model consists of an LSTM controller that generates stack actions (push, pop, no-op), which are then processed by the differentiable WPDA. The WPDA maintains a dynamic programming representation of all possible stack configurations and their weights, allowing for efficient computation of the marginal distribution over stack tops. The NS-RNN and RNS-RNN variants differ in how they read from the stack, with the RNS-RNN including information about the WPDA's state in its stack reading. The model is trained using backpropagation and gradient descent on language modeling tasks.

## Key Results
- NS-RNN and RNS-RNN outperform prior stack-augmented models on context-free language learning tasks
- RNS-RNN achieves better perplexity on the Penn Treebank natural language modeling benchmark
- RNS-RNN demonstrates surprising ability to learn non-context-free languages, including cross-serial dependencies

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The differentiable WPDA represents an exponential number of nondeterministic runs using a dynamic programming algorithm.
- Mechanism: Lang's algorithm constructs a stack WFA that encodes all possible runs of the WPDA as paths in a weighted graph. The algorithm uses a recurrence relation that sums over all runs, enabling efficient computation of the marginal distribution over stack tops.
- Core assumption: The recurrence relations in Lang's algorithm correctly compute the weight of all runs that end at a given timestep and stack configuration.
- Evidence anchors:
  - [abstract]: "representing an exponential number of computations with a dynamic programming algorithm"
  - [section]: "Lang's algorithm exploits structural similarities in PDA runs"
- Break condition: If the recurrence relations are incorrect, the algorithm would fail to represent all possible runs, and the model would lose its ability to handle nondeterminism.

### Mechanism 2
- Claim: Unnormalized weights allow the model to "amplify" the gradient flow to all possible runs, improving learning efficiency.
- Mechanism: Using unnormalized weights instead of probabilities means that the weight of a run is the product of individual action weights, which can be much larger than the product of probabilities. This allows the model to learn faster because the gradient flow to a transition is proportional to its posterior probability, which is always nonzero.
- Core assumption: The unnormalized weights do not cause numerical instability or gradient explosion.
- Evidence anchors:
  - [abstract]: "a differentiable data structure that efficiently simulates a nondeterministic pushdown automaton"
  - [section]: "The probability of a run in the NS-RNN's differentiable WPDA is the product of individual action probabilities, which are always strictly less than one."
- Break condition: If the unnormalized weights cause numerical instability or gradient explosion, the model would fail to train effectively.

### Mechanism 3
- Claim: The RNS-RNN's stack reading includes information about the WPDA's state, allowing the controller to make more informed decisions.
- Mechanism: The stack reading now includes a joint distribution over top stack symbols and PDA states, providing the controller with information about the current state of the underlying WPDA. This allows the controller to interpolate the two distributions based on the weight of being in each state, but it cannot do this without input from the differentiable WPDA.
- Core assumption: The joint distribution over states and stack symbols is informative enough for the controller to make good decisions.
- Evidence anchors:
  - [abstract]: "The proposed Nondeterministic Stack Recurrent Neural Network (NS-RNN) and its variant, the Renormalizing NS-RNN (RNS-RNN), demonstrate significant improvements in learning context-free languages"
  - [section]: "In the RNS-RNN, the controller can read the distribution over the PDA's current top stack symbol, but it cannot observe its current state."
- Break condition: If the joint distribution is not informative enough, the controller would not be able to make good decisions, and the model would not improve performance.
