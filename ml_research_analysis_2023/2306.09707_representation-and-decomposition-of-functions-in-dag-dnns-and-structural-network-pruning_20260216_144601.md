# Representation and decomposition of functions in DAG-DNNs and structural network pruning

## Quick Facts
- arXiv ID: 2306.09707
- Source URL: https://arxiv.org/abs/2306.09707
- Reference count: 18
- Primary result: Introduces DAG-DNN representation for systematic structural pruning with theoretical guarantees on training performance

## Executive Summary
This paper presents a novel theoretical framework for representing deep neural networks (DNNs) as directed acyclic graphs (DAGs) where each arc corresponds to a function. The key innovation is a "lifting" structure that represents network functions using lower-triangular matrices, enabling systematic structural pruning. The authors demonstrate that this representation can capture all functions defined on various sub-architectures of a DNN and provide theoretical justification for the lottery ticket hypothesis. The framework claims to enable finding sub-networks with initialization that achieve training performance comparable to the original network using fewer iterations.

## Method Summary
The authors introduce DAG-DNNs as a new representation where network architecture is expressed as a direct-acyclic graph with functions associated with arcs. Functions are represented using sequences of lower-triangular matrices, with each matrix corresponding to a node level in the DAG-DNN. This decomposition allows for systematic structural pruning by identifying and removing redundant components while maintaining the ability to train the remaining sub-network effectively. The framework claims to be universal, applicable to any DNN architecture.

## Key Results
- Proves that all functions defined on various sub-architectures of a DNN can be derived from the DAG-DNN representation
- Demonstrates that sub-networks obtained through this pruning approach can achieve training performance on par with the original network using the same or fewer iterations
- Provides theoretical justification for the lottery ticket hypothesis through the proposed DAG-DNN representation
- Claims the decomposition is universal and applicable to any DNN architecture

## Why This Works (Mechanism)
The DAG-DNN representation works by decomposing complex network functions into simpler components represented as lower-triangular matrices. This "lifting" structure allows for systematic identification of redundant or non-essential components that can be pruned without significantly affecting the overall function approximation capability. The triangular matrix representation ensures that the decomposition preserves the essential information flow through the network while enabling targeted removal of less critical connections.

## Architecture Onboarding

Component map:
Input -> DAG-DNN Representation -> Lower-triangular Matrix Decomposition -> Systematic Pruning -> Trained Sub-network

Critical path:
The critical path involves converting the original DNN to DAG-DNN representation, performing the lower-triangular matrix decomposition, identifying components for pruning, and training the resulting sub-network.

Design tradeoffs:
The main tradeoff is between the theoretical elegance of the DAG-DNN representation and its practical implementation complexity. While the framework offers systematic pruning, it may introduce computational overhead during the representation and decomposition phases.

Failure signatures:
Potential failures could include:
- Inability to find meaningful sub-networks if the decomposition is too aggressive
- Performance degradation if essential components are mistakenly pruned
- Computational inefficiency if the representation and decomposition steps are too complex

## Limitations
- Theoretical claims about training performance lack empirical validation on standard benchmarks
- The practical applicability of the lower-triangular matrix representation across different DNN architectures is unclear
- Computational overhead of the DAG-DNN representation during training is not discussed
