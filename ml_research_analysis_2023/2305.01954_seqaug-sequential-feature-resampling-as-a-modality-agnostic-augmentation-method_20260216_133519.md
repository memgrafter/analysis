# SeqAug: Sequential Feature Resampling as a modality agnostic augmentation method

## Quick Facts
- arXiv ID: 2305.01954
- Source URL: https://arxiv.org/abs/2305.01954
- Reference count: 0
- Primary result: Novel modality-agnostic sequence feature augmentation technique that resamples feature values from underlying distribution, achieving state-of-the-art results on CMU-MOSEI with 20% less training data

## Executive Summary
SeqAug is a novel data augmentation method that resamples feature values from the underlying distribution by permuting feature dimensions along the temporal axis within sequences. Unlike traditional data augmentation techniques that require modality-specific knowledge, SeqAug is truly modality-agnostic and can be applied to any sequential feature representation. The method demonstrates significant improvements on multimodal sentiment analysis tasks, particularly when applied to transformer-based architectures, and requires substantially less training data to achieve state-of-the-art performance.

## Method Summary
SeqAug operates by randomly selecting feature dimensions and permuting them along the temporal axis within each sequence, effectively resampling from the original feature distribution while preserving semantic meaning. The method uses different probability distributions for different architectures: beta distribution for transformers and folded-normal distribution for recurrent networks like LSTMs. Augmentation is applied independently to each modality before multimodal fusion, making it suitable for both single-modality and multi-modal setups. The approach is computationally efficient and simple to implement, requiring only the feature sequences as input.

## Key Results
- Matches or outperforms state-of-the-art models on CMU-MOSEI dataset
- Requires 20% less training data to achieve competitive performance
- Works effectively across multiple modalities (text, audio, visual) and architectures (transformers and recurrent networks)
- Improves performance for both single-modality and multi-modal setups

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Resampling along the temporal axis preserves semantic meaning while increasing feature diversity
- Mechanism: Permuting feature values within the same sequence generates new feature configurations that maintain the underlying semantic structure, as the original relationships between features and labels are preserved through the resampling process
- Core assumption: The original sequence contains sufficient statistical information about the feature distribution such that resampling within the sequence approximates sampling from the true underlying distribution
- Evidence anchors: [abstract] "resampling is performed by randomly selecting feature dimensions and permuting them along the temporal axis"; [section] "This way we achieve sequential augmentations which 1) can be modeled as resampling from the original distribution and 2) do not affect the underlying semantics since resampling occurs within the sequence itself"
- Break condition: If temporal structure carries critical information that cannot be preserved through permutation, or if the feature sequence is too short to provide meaningful permutations

### Mechanism 2
- Claim: Modality-agnostic resampling works because different modalities share similar sequential feature structure
- Mechanism: SeqAug applies the same resampling logic across different modalities because all extracted feature sequences have a temporal dimension that can be independently manipulated without losing modality-specific information
- Core assumption: The temporal structure in feature sequences is sufficiently generic across modalities that a single resampling approach can improve performance regardless of modality type
- Evidence anchors: [abstract] "Experiments on CMU-MOSEI verify that SeqAug is modality agnostic; it can be successfully applied to a single modality or multiple modalities"; [section] "Unlike other DA methods our approach is modality agnostic and is thus suitable for all streams of features, as well as multi-modal setups"
- Break condition: When modalities have fundamentally different temporal characteristics that cannot be captured by simple permutation, or when modality-specific augmentation would be significantly more effective

### Mechanism 3
- Claim: Beta and folded-normal distributions provide appropriate probability models for feature address selection across different architectures
- Mechanism: The choice of distribution reflects different sensitivities of architectures to feature perturbation magnitude, with transformers tolerating more aggressive changes than recurrent networks
- Core assumption: The sensitivity of different neural architectures to feature perturbations can be characterized by their architectural properties, particularly the autoregressive nature of LSTMs versus the parallel processing in transformers
- Evidence anchors: [section] "We attribute this difference to the autoregressive nature of the LSTM"; [section] "MulT can handle a more aggressive augmentation scheme due to the beta distribution sampling, which has a mean equal to 0.5. On the other hand, MMRnn requires a smoother (folded-normal) augmentation to work properly"
- Break condition: When the relationship between architectural properties and perturbation tolerance does not generalize to other architectures, or when the chosen distributions do not adequately capture the optimal sampling behavior

## Architecture Onboarding

- Component map: Input feature sequence → Feature address sampling (beta/folded-normal distribution) → Time resampling (permutation) → Augmented feature sequence → Model training/inference
- Critical path: Feature extraction → SeqAug transformation → Model training → Evaluation → Hyperparameter tuning (distribution parameters)
- Design tradeoffs: Modality-agnostic approach sacrifices potential gains from modality-specific augmentation for simplicity and broad applicability; aggressive augmentation improves diversity but risks semantic drift
- Failure signatures: Performance degradation when augmentation rate is too high, failure to converge when distribution parameters are poorly chosen, inconsistent improvements across modalities suggesting modality-specific requirements
- First 3 experiments:

## Limitations

- The modality-agnostic claim remains weakly supported, as the evaluation only demonstrates effectiveness across three pre-defined modalities without testing on diverse feature types
- The distribution choice mechanism (beta vs folded-normal) is justified post-hoc based on empirical results rather than theoretical analysis, creating uncertainty about generalization to other architectures
- The 20% data reduction claim is impressive but requires scrutiny regarding which specific samples were excluded and whether this generalizes beyond the CMU-MOSEI dataset

## Confidence

- **High Confidence**: The core technical implementation of feature permutation within sequences is well-specified and reproducible. The empirical improvements on CMU-MOSEI are clearly demonstrated and verifiable.
- **Medium Confidence**: The mechanism explanations for why resampling preserves semantics and why different distributions work better for different architectures. These rely on reasonable assumptions but lack direct empirical validation.
- **Low Confidence**: The broad claims about modality-agnostic effectiveness and the 20% data reduction generalization across diverse domains and datasets.

## Next Checks

1. **Distribution Generalization Test**: Apply SeqAug with both beta and folded-normal distributions to a third architecture type (e.g., CNN or GNN) to verify whether the architectural sensitivity pattern holds beyond LSTMs and transformers.

2. **Modality Diversity Validation**: Test SeqAug on non-traditional modalities like sensor data, financial time series, or graph-structured sequences to assess true modality-agnostic capabilities beyond the three studied modalities.

3. **Data Reduction Robustness**: Systematically vary the training set size (5%, 10%, 20%, 30%, 40% reductions) across multiple datasets to determine the minimum data requirement and whether the 20% reduction is a consistent or dataset-specific phenomenon.
