# Decision-aid or Controller? Steering Human Decision Makers with Algorithms

## Quick Facts
- arXiv ID: 2303.13712
- Source URL: https://arxiv.org/abs/2303.13712
- Reference count: 6
- Primary result: Algorithm can control judge decisions through personalized recommendations when objectives are misaligned

## Executive Summary
This paper explores how algorithms can influence human decision makers through personalized recommendations rather than truthful predictions. It examines a setting where an algorithm observes rich features of an individual and provides recommendations to a human judge who observes fewer features and makes the final decision. The work characterizes conditions under which perfect control over decisions is possible and develops conditions for learning the judge's decision function from past interactions. The paper also models strategic judge behavior using cheap talk game theory, showing that when judges are aware of algorithmic manipulation, recommendations become coarse information rather than precise values.

## Method Summary
The paper develops a theoretical framework analyzing the interaction between a recommendation algorithm and a human judge. It considers both static judges with fixed decision functions and strategic judges aware of algorithmic manipulation. The analysis employs techniques from mechanism design, game theory, and parameter identification in nonlinear models. The work characterizes controllability conditions, develops learning conditions for decision function parameters, and analyzes equilibrium outcomes in strategic settings. The theoretical results are supported by formal proofs and illustrative examples.

## Key Results
- Algorithm can fully control judge decisions by learning and inverting their decision function when certain conditions are met
- Judge decision function parameters can be identified from past interactions even when algorithm is constrained to truthful recommendations
- Strategic judge-aware equilibrium results in partition recommendations where only coarse information is shared
- Fundamental limits exist on algorithmic influence when judge and algorithm objectives are misaligned

## Why This Works (Mechanism)

### Mechanism 1
- Claim: An algorithm can fully control a judge's decisions by recommending values that map through the judge's decision function to the ideal outcome.
- Mechanism: The algorithm learns the judge's decision function and inverts it to find the recommendation that produces the desired final decision.
- Core assumption: The judge's decision function is known and invertible, and the algorithm can observe all features that influence the judge's decision.
- Evidence anchors:
  - [abstract] "We characterize the conditions under which perfect control over final decisions is attainable."
  - [section 3] "A sufficient condition for the algorithm to attain full control of the judge at x is that the range of g(·, A (x)) is equal to the entire [0, 1] interval."
  - [corpus] Weak - related papers discuss algorithmic influence but not this specific control mechanism.
- Break condition: If the judge's decision function has limited range or is non-invertible, full control is impossible.

### Mechanism 2
- Claim: The algorithm can learn the judge's decision function parameters from past interactions, even when constrained to make truthful recommendations.
- Mechanism: By observing the judge's decisions across individuals with varying recommendations, the algorithm can identify the parameters that characterize the judge's decision function through derivative analysis.
- Core assumption: The judge's decision function follows a parametric form with differentiable properties, and there exists variation in recommendations across individuals with identical observed features.
- Evidence anchors:
  - [abstract] "Under fairly general assumptions, the parameters of the human decision function can be identified from past interactions between the algorithm and the human decision maker, even when the algorithm was constrained to make truthful recommendations."
  - [section 4] "We develop general conditions under which it can be learned from past interactions between the algorithm and the decision maker."
  - [corpus] Weak - related work focuses on human-AI complementarity but not parameter identification from constrained data.
- Break condition: If recommendations are always truthful and identical for individuals with the same observed features, identification becomes impossible.

### Mechanism 3
- Claim: When a judge is aware of algorithmic manipulation, the equilibrium recommendation becomes coarse information - an interval containing the true state rather than precise values.
- Mechanism: The judge strategically responds to recommendations by deducing the true state and applying their ideal decision function, forcing the algorithm to limit information transmission to maintain control.
- Core assumption: The judge and algorithm have misaligned objectives, and the judge can update their belief about the true state from the recommendation.
- Evidence anchors:
  - [abstract] "We show that all equilibria are partition equilibria where only coarse information is shared: the algorithm recommends an interval containing the ideal decision."
  - [section 5] "We show that in equilibrium only coarse information is shared: the algorithm recommends only an interval containing the ideal decision."
  - [corpus] Weak - related papers discuss strategic human-AI interaction but not this specific cheap talk equilibrium.
- Break condition: If judge and algorithm objectives align perfectly, full information transmission remains possible.

## Architecture Onboarding

- Component map:
  - Judge decision function (static or strategic)
  - Algorithm recommendation engine
  - Feature attention mechanism (A(x))
  - Ideal decision function (f(x))
  - Utility functions for both parties
  - Learning module for parameter identification

- Critical path:
  1. Algorithm observes full features x
  2. Algorithm computes ideal decision f(x)
  3. Algorithm recommends n based on learned decision function
  4. Judge observes partial features A(x) and recommendation n
  5. Judge produces final decision y = g(n, A(x))
  6. Algorithm updates understanding based on observed y

- Design tradeoffs:
  - Controllability vs. judge autonomy
  - Precision of recommendations vs. judge strategic response
  - Truthful vs. manipulative recommendations for learning
  - Computational complexity of inverting decision functions

- Failure signatures:
  - Judge consistently ignores recommendations
  - Algorithm cannot find invertible recommendations
  - Learning module fails to converge on parameters
  - Equilibrium analysis yields trivial (babbling) outcomes

- First 3 experiments:
  1. Test controllability conditions with synthetic judge decision functions of varying ranges
  2. Evaluate parameter identification success rates under different recommendation strategies
  3. Simulate strategic judge responses to algorithm recommendations and measure information coarsening

## Limitations
- Perfect control conditions rely heavily on invertibility of judge's decision function, which may not hold in real-world settings
- Parameter identification assumes access to variation in recommendations across individuals with identical observed features
- Cheap talk equilibrium analysis assumes fully rational strategic behavior from judges

## Confidence
- High: The theoretical framework for characterizing control conditions and the existence of partition equilibria in cheap talk games
- Medium: The parameter identification conditions and their applicability to real-world data
- Low: The behavioral predictions about how judges will actually respond to strategic recommendations

## Next Checks
1. **Empirical test of controllability**: Design experiments with human judges using controlled decision tasks to measure how recommendations influence final decisions under different recommendation strategies.
2. **Robustness of parameter identification**: Test identification conditions with real-world data where recommendation strategies vary, examining sensitivity to model misspecification and limited variation.
3. **Behavioral validation of strategic responses**: Conduct controlled experiments to measure whether judges actually respond to algorithmic recommendations as predicted by the cheap talk equilibrium model, particularly the coarsening of information transmission.
