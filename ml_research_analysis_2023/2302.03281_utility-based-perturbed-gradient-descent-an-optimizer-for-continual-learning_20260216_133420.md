# Utility-based Perturbed Gradient Descent: An Optimizer for Continual Learning

## Quick Facts
- arXiv ID: 2302.03281
- Source URL: https://arxiv.org/abs/2302.03281
- Reference count: 40
- Primary result: UPGD addresses catastrophic forgetting and decaying plasticity in continual learning by protecting useful weights and features while perturbing less useful ones based on estimated utility

## Executive Summary
This paper introduces UPGD, an online learning optimizer designed specifically for continual learning scenarios. UPGD addresses two critical challenges: catastrophic forgetting (losing previously learned information) and decaying plasticity (reduced ability to learn new tasks). The method estimates the utility of weights and features, then protects useful ones while applying larger perturbations to less useful ones, maintaining both stability and adaptability in non-stationary environments.

## Method Summary
UPGD is an online learning optimizer that combines utility-based weight protection with strategic noise injection. The algorithm estimates utility for each weight/feature using second-order Taylor approximation, scales these utilities to [0,1] range, and then applies gradient updates weighted by utility (small for useful weights, large for less useful ones). Simultaneously, a utility-informed search component applies noise perturbations to less useful weights, preventing saturation and maintaining plasticity. The method works with both weight-wise and feature-wise variants, using masks to manage feature utilities.

## Key Results
- UPGD effectively reduces catastrophic forgetting across multiple continual learning benchmarks
- The method maintains network plasticity by preventing feature saturation through utility-based noise injection
- UPGD enables modern representation learning methods to work effectively in continual learning settings while maintaining computational scalability

## Why This Works (Mechanism)

### Mechanism 1
UPGD protects useful weights and features from being overwritten during continual learning. The utility estimates determine which weights are important for current task performance, applying smaller gradient updates to preserve these useful features while allowing larger updates to less useful ones.

### Mechanism 2
UPGD mitigates decaying plasticity by injecting noise into less useful weights. This continual perturbation prevents weights from saturating and maintains the network's ability to adapt to new tasks by replacing saturated features with more adaptable ones.

### Mechanism 3
UPGD maintains computational scalability through linear complexity utility estimation. By using second-order Taylor approximation and avoiding storage of past samples, the method remains practical for lifelong learning scenarios.

## Limitations
- Utility estimation relies on second-order Taylor approximation, whose accuracy for complex tasks is unclear
- Implementation details for "anti-correlated noise" and specific scaling functions are not fully specified
- No ablation studies on the impact of different noise types or utility scaling functions
