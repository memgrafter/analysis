# CUDA: Curriculum of Data Augmentation for Long-Tailed Recognition

## Quick Facts
- **arXiv ID:** 2302.05499
- **Source URL:** https://arxiv.org/abs/2302.05499
- **Reference count:** 40
- **Key outcome:** CUDA achieves 42.7% accuracy on CIFAR-100-LT with imbalance ratio 100, outperforming baseline CE method (38.7%).

## Executive Summary
CUDA introduces a curriculum-based data augmentation method specifically designed for long-tailed recognition tasks. The approach assigns different augmentation strengths to different classes based on their difficulty level, measured by the level-of-learning (LoL) score. By adaptively adjusting augmentation strength during training, CUDA makes minority classes easier to learn while preventing over-augmentation of majority classes. Experiments demonstrate consistent improvements across CIFAR-100-LT, ImageNet-LT, and iNaturalist 2018 datasets when integrated with various long-tailed recognition methods.

## Method Summary
CUDA is a curriculum-based data augmentation method for long-tailed recognition that adjusts augmentation strength per class based on the level-of-learning (LoL) score. The LoL score is computed by evaluating model performance on augmented samples and determines whether to increase or decrease augmentation strength for each class. The method uses 22 different augmentation operations with varying magnitudes and integrates seamlessly with existing long-tailed recognition algorithms. CUDA's core innovation is its adaptive strength adjustment mechanism that follows curriculum learning principles, making minority classes progressively easier to learn while maintaining information in majority classes.

## Key Results
- Achieves 42.7% accuracy on CIFAR-100-LT with imbalance ratio 100, compared to 38.7% for baseline CE method
- Consistently improves performance across various LTR methods including CE, CE-DRW, LDAM-DRW, BS, RIDE, and BCL
- Shows significant gains on ImageNet-LT and iNaturalist 2018 datasets, demonstrating broad applicability
- Outperforms other auto-augmentation methods like RandAugment and AutoAugment on long-tailed recognition tasks

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Class-wise augmentation strength directly modulates classifier weight norms, reducing majority class dominance and improving minority performance.
- **Mechanism:** Strong augmentation for majority classes decreases feature alignment, leading to smaller classifier weight norms for those classes, thereby balancing the classifier and improving minority class performance.
- **Core assumption:** The norm of the classifier weights correlates inversely with augmentation strength due to reduced feature alignment.
- **Evidence anchors:**
  - [abstract] "we further find that strongly augmented classes get diversified feature representation, preventing the growth of the norm of a linear classifier for corresponding classes."
  - [section] "When we conduct augmentation only for partial classes (0-49 classes), the feature alignment for augmented classes of the training dataset is degraded compared to the non-augmented classes."
- **Break condition:** If feature alignment does not decrease with strong augmentation, the mechanism fails to reduce classifier weight norms.

### Mechanism 2
- **Claim:** Curriculum learning via LoL score enables the model to learn progressively harder samples, improving generalization.
- **Mechanism:** LoL score determines augmentation strength per class, starting with weaker augmentation and increasing it as the model learns, aligning with curriculum learning principles.
- **Core assumption:** Models learn better when presented with easier samples first, then progressively harder ones.
- **Evidence anchors:**
  - [abstract] "CUDA increases and decreases the augmentation strength of the class that was successfully and wrongly predicted by the trained model."
  - [section] "CUDA enables modeling by first presenting easier examples earlier during training to improve generalization."
- **Break condition:** If the model does not improve with a curriculum approach, or if LoL score does not correlate with learning difficulty.

### Mechanism 3
- **Claim:** CUDA improves feature extraction ability by diversifying representations for minority classes while maintaining majority class information.
- **Mechanism:** By applying stronger augmentation to minority classes, CUDA forces the model to learn more robust and diverse features, improving feature alignment for minority classes.
- **Core assumption:** Augmentation increases feature diversity, which improves the model's ability to extract meaningful features for underrepresented classes.
- **Evidence anchors:**
  - [abstract] "strongly augmented classes get diversified feature representation"
  - [section] "CUDA obtains feature alignment gains for almost all classes."
- **Break condition:** If augmentation does not lead to feature diversity or if feature alignment does not improve for minority classes.

## Architecture Onboarding

- **Component map:** LoL score computation module → Strength-based augmentation module → Integration with LTR algorithms

- **Critical path:**
  1. Compute LoL score for each class based on model performance on augmented samples
  2. Adjust augmentation strength for each class based on LoL score
  3. Generate augmented samples using the adjusted strength
  4. Train the LTR algorithm with the augmented dataset

- **Design tradeoffs:**
  - Tradeoff between augmentation strength and feature alignment: Stronger augmentation may lead to better feature diversity but can also degrade feature alignment if not managed properly
  - Computational cost of LoL score computation: Computing LoL score requires additional forward passes through the model, increasing training time

- **Failure signatures:**
  - LoL score does not increase for any class: Indicates that the model is not learning, or the LoL score computation is not working correctly
  - Performance degradation for minority classes: Suggests that the augmentation strength for minority classes is too high, leading to feature alignment issues

- **First 3 experiments:**
  1. Implement CUDA on a simple LTR algorithm (e.g., CE) and evaluate its impact on CIFAR-100-LT with an imbalance ratio of 100
  2. Analyze the effect of different LoL score thresholds (γ) on model performance and LoL score dynamics
  3. Compare CUDA with other augmentation methods (e.g., AutoAugment, RandAugment) on ImageNet-LT to assess its effectiveness
