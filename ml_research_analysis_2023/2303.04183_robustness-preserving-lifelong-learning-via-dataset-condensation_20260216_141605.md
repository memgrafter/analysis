# Robustness-preserving Lifelong Learning via Dataset Condensation

## Quick Facts
- arXiv ID: 2303.04183
- Source URL: https://arxiv.org/abs/2303.04183
- Reference count: 0
- The paper proposes DERPLL, a method that uses bilevel optimization to select informative coresets for memory replay in class-incremental learning while preserving adversarial robustness, significantly outperforming baselines in both standard and robust accuracy.

## Executive Summary
This paper addresses the challenge of maintaining adversarial robustness in class-incremental learning (CIL), where a model must continually adapt to new tasks while retaining performance on previous tasks without forgetting robustness against adversarial attacks. The authors propose DERPLL, which combines bilevel optimization for coreset selection with adversarial training and knowledge distillation-like regularization to preserve both accuracy and robustness. Experiments on CIFAR-10 with ResNet-18 show DERPLL significantly outperforms baselines in both standard accuracy and robust accuracy across multiple tasks, with improvements of up to 6% in robust accuracy.

## Method Summary
DERPLL uses bilevel optimization to select informative coresets for memory replay in CIL, combined with adversarial training and LwF-style regularization. The method selects a subset of training data (coreset) via outer loop optimization while training the model on that coreset in the inner loop. It combines adversarial training with projected gradient descent (PGD) and adds an LwF loss term that penalizes prediction disagreement between old and new models on both clean and adversarial examples from the coreset. The approach is evaluated on CIFAR-10 split into 5 tasks with 2 classes each, using ResNet-18.

## Key Results
- DERPLL outperforms random and influence-score-based coreset selection methods in both standard accuracy (SA) and robust accuracy (RA) across multiple tasks
- Robust accuracy improvements of up to 6% over baselines
- DERPLL is especially effective with small memory budgets, making it data-efficient while sustaining adversarial robustness
- Maintains performance gains across all tasks seen so far after each task update

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Coreset selection via bilevel optimization enables efficient data retention that supports both accuracy and robustness.
- Mechanism: The bilevel optimization problem selects a subset of training data (coreset) by optimizing model performance on the full dataset while constraining the coreset size. The outer loop selects the coreset, and the inner loop trains the model on that coreset.
- Core assumption: A small, carefully selected subset of data can represent the full dataset well enough to maintain model performance on previous tasks.
- Evidence anchors:
  - [abstract] "We propose a new memory-replay LL strategy that leverages modern bi-level optimization techniques to determine the 'coreset' of the current data"
  - [section] "The coreset selection problem can be formulated as the following bi-level optimization (BLO) problem"
  - [corpus] No direct corpus evidence for this specific mechanism
- Break condition: If the coreset becomes too small or poorly selected, model performance on previous tasks degrades significantly.

### Mechanism 2
- Claim: Regularization via knowledge distillation (LwF) preserves model knowledge across tasks while maintaining robustness.
- Mechanism: The LwF loss term penalizes prediction disagreement between the old model and the new model on both clean and adversarial examples from the coreset, encouraging the new model to retain previous knowledge.
- Core assumption: Minimizing prediction disagreement between models helps preserve learned representations and prevents catastrophic forgetting.
- Evidence anchors:
  - [abstract] "combines adversarial training with a knowledge distillation-like regularization (LwF) to preserve both accuracy and robustness"
  - [section] "we introduce an LwF loss term to retain accuracy/robustness on the past tasks, which is implemented by minimizing the prediction disagreement between the old model θ(t−1) and the new model θ(t)"
  - [corpus] No direct corpus evidence for this specific mechanism
- Break condition: If the regularization weight is too high, the model cannot adapt to new tasks; if too low, forgetting occurs.

### Mechanism 3
- Claim: Adversarial training with projected gradient descent (PGD) creates robust models that resist adversarial attacks.
- Mechanism: The model is trained by minimizing the worst-case loss over small perturbations (within ℓ∞-norm ball), forcing it to learn robust features that are invariant to adversarial examples.
- Core assumption: Training on worst-case perturbations improves model robustness to adversarial attacks.
- Evidence anchors:
  - [abstract] "machine learning (ML) models can be vulnerable in the sense that tiny, adversarial input perturbations can deceive the models"
  - [section] "adversarial training (AT) attempts to learn θ by solving [18] min θ ℓϵ AT(θ;D) := E(x,y)∈D { max ∥δ∥∞≤ϵ ℓ(θ; x + δ,y ) }"
  - [corpus] No direct corpus evidence for this specific mechanism
- Break condition: If attack strength (ϵ) is too large, training becomes unstable; if too small, insufficient robustness is achieved.

## Architecture Onboarding

- Component map:
  - Data pipeline: CIFAR-10 dataset split into 5 tasks with 2 classes each
  - Model: ResNet-18 neural network
  - Coreset selector: Bilevel optimization module for selecting informative data points
  - Training loop: Combines adversarial training on new data with LwF regularization on coreset
  - Evaluation: Tests both standard accuracy and robust accuracy on clean and adversarial examples

- Critical path: Data → Coreset selection → Model training (AT + LwF) → Evaluation

- Design tradeoffs:
  - Memory budget vs. performance: Smaller coresets save memory but may reduce performance
  - Regularization strength vs. adaptation: Higher LwF weights preserve old knowledge but may hinder learning new tasks
  - Attack strength (ϵ) vs. training stability: Larger ε provides better robustness but may make training unstable

- Failure signatures:
  - Accuracy on old tasks drops significantly when training on new tasks (forgetting)
  - Robust accuracy remains low even after adversarial training (insufficient robustness)
  - Training becomes unstable or diverges (attack strength too high or regularization improperly balanced)

- First 3 experiments:
  1. Baseline comparison: Implement random coreset selection and compare performance against the proposed bilevel optimization approach
  2. Ablation study: Train with and without LwF regularization to measure its impact on robustness preservation
  3. Memory scaling: Test performance with different coreset sizes (e.g., 50, 100, 250 images per class) to find optimal memory budget

## Limitations
- Effectiveness depends heavily on implementation details of bilevel optimization (gradient unrolling steps, learning rates, projection methods) not fully specified
- Robustness improvements may be sensitive to specific attack strength (ε = 8/255) and training schedule

## Confidence

- High: The core claim that combining adversarial training with LwF regularization helps preserve robustness in CIL settings is well-supported by the experimental results.
- Medium: The specific superiority of bilevel optimization for coreset selection over random or influence-score methods is demonstrated, but depends on implementation details.
- Low: The paper's claims about the mechanism by which bilevel optimization selects optimal coresets (outer loop optimizing model performance, inner loop training on coreset) are plausible but not fully validated.
