# Strategy Synthesis in Markov Decision Processes Under Limited Sampling Access

## Quick Facts
- arXiv ID: 2303.12718
- Source URL: https://arxiv.org/abs/2303.12718
- Reference count: 40
- Key outcome: Reinforcement learning algorithm using interval MDPs with LCB exploration and action scoping achieves faster strategy synthesis under limited sampling, especially in large action spaces, though optimal strategies may not be achievable in the limit

## Executive Summary
This paper addresses strategy synthesis for Markov Decision Processes (MDPs) under limited sampling access. The authors propose a reinforcement learning algorithm that uses interval MDPs as internal models, incorporating lower confidence bound (LCB) exploration and action scoping to improve sample efficiency. The algorithm is evaluated on examples from both AI and formal methods communities, demonstrating that it can synthesize good strategies faster than classical RL methods, particularly when dealing with large action spaces or high probability deviations.

## Method Summary
The paper presents a reinforcement learning algorithm for strategy synthesis in gray-box MDPs where the topology is known but transition probabilities are unknown. The method uses interval MDPs as internal models, constructing confidence intervals for transition probabilities using Hoeffding bounds from sampled data. The algorithm employs LCB exploration to reinforce learned strategies and action scoping to reduce the effective action space by removing low-quality actions. Value iteration is performed on the interval MDP to compute bounds on the value function, from which sampling and execution strategies are derived. The approach provides PAC guarantees on the environment approximation while improving sample efficiency through exploration and scoping mechanisms.

## Key Results
- LCB sampling yields strategies with higher confidence in value bounds compared to UCB when sampling is limited
- Action scoping reduces the learning action space to promising actions, improving learning speed under sample constraints
- The proposed methods, especially with high scoping parameters, can synthesize good strategies faster than classical RL methods, particularly in large action spaces or with high probability deviations

## Architecture Onboarding

- Component map:
  MDP Environment (gray-box) -> Sampling Strategy Module -> IMDP Model Builder -> Value Iteration Engine -> Strategy Extractor
  (Known topology, unknown probabilities) (Implements UCB/LCB with exploration parameters) (Constructs and refines interval MDP from samples) (Computes bounds on value functions for the IMDP) (Derives sampling and execution strategies from value bounds)

- Critical path:
  1. Sample environment using current strategy
  2. Update IMDP transition intervals using Hoeffding bounds
  3. Run value iteration on IMDP to get value bounds
  4. Update strategy based on bounds and scoping rules
  5. Repeat until sample budget exhausted

- Design tradeoffs:
  - Exploration vs Exploitation: LCB vs UCB sampling
  - Sample Efficiency vs Optimality: Scoping removes actions but may eliminate optimal ones
  - Computation vs Precision: More value iteration steps improve bounds but increase runtime
  - Model Complexity vs Tractability: IMDP provides uncertainty handling but requires interval arithmetic

- Failure signatures:
  - LCB sampling: Strategy gets stuck in local optima, poor state coverage
  - Scoping: Sudden drop in performance, reduced action space too aggressively
  - IMDP: Value bounds remain too wide, insufficient samples to tighten intervals
  - Value iteration: Convergence issues, bounds don't improve over episodes

- First 3 experiments:
  1. Run with UCB sampling only on small MDP to verify baseline performance
  2. Add LCB sampling to compare strategy quality and state coverage
  3. Introduce scoping with varying parameters to measure impact on learning speed and optimality

## Limitations

- The algorithm provides PAC guarantees but not asymptotic optimality, limiting applicability to scenarios requiring optimal solutions
- Action scoping effectiveness depends heavily on the choice of scoping parameter h, with no principled method provided for setting this parameter
- Claims about the algorithm's performance on large-scale MDPs or complex state spaces not covered in the evaluation have low confidence

## Confidence

- **High confidence**: The theoretical framework using interval MDPs and Hoeffding bounds for PAC guarantees; the general methodology of combining LCB exploration with action scoping
- **Medium confidence**: The specific empirical advantages claimed for LCB over UCB in limited sampling regimes; the practical impact of different scoping parameters on learning speed
- **Low confidence**: Claims about the algorithm's performance on large-scale MDPs or complex state spaces not covered in the evaluation
