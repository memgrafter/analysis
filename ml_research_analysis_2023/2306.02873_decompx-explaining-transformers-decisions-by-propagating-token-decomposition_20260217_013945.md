# DecompX: Explaining Transformers Decisions by Propagating Token Decomposition

## Quick Facts
- **arXiv ID**: 2306.02873
- **Source URL**: https://arxiv.org/abs/2306.02873
- **Reference count**: 30
- **Key outcome**: DecompX outperforms existing gradient-based and vector-based methods by a significant margin in terms of faithfulness metrics (AOPC, accuracy, prediction performance) on multiple text classification datasets.

## Executive Summary
DecompX introduces a novel vector-based explanation method for Transformer models that propagates decomposed token representations through all encoder layers without mixing them. Unlike existing approaches that aggregate local attributions, DecompX builds global decompositions by tracking how each input token's representation transforms through self-attention, feed-forward networks, and the classification head. The method provides per-predicted label explanations, showing how individual tokens contribute toward or against specific label predictions. Experiments demonstrate consistent improvements over baseline methods across multiple text classification tasks.

## Method Summary
DecompX decomposes token representations into elemental vectors attributable to each input token and propagates these vectors through the model's layers. The decomposition process handles self-attention by decomposing attention weights, approximates activation functions in feed-forward networks, and incorporates the classification head for per-label explanations. The method includes all encoder components (self-attention, FFN, residual connections, layer normalization) and propagates decomposition vectors along the same path as original representations. Evaluation uses AOPC (average output probability change), accuracy on masked inputs, and prediction performance to measure faithfulness.

## Key Results
- DecompX consistently outperforms baseline methods (ALTI, GlobEnc, Integrated Gradients, Gradient×Input) across SST-2, MNLI, QNLI, and HateXplain datasets
- The method achieves higher AOPC scores, indicating better preservation of model behavior when masking important tokens
- DecompX maintains prediction accuracy better than baselines when using extracted rationales for masked input reconstruction
- Including FFN components and the classification head significantly improves faithfulness compared to methods that exclude these components

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Propagating decomposed token representations through each layer without mixing them prevents information loss during multi-layer aggregation
- Mechanism: By decomposing each token's representation into elemental vectors attributable to each input token and propagating these vectors through the model's layers, the decomposition maintains the connection between each token's contribution and its influence on later representations
- Core assumption: The decomposed vectors accurately capture each token's contribution at each layer, and the decomposition process preserves this information throughout the model
- Evidence anchors:
  - [abstract]: "DecompX is based on the construction of decomposed token representations and their successive propagation throughout the model without mixing them in between layers."
  - [section]: "Instead of employing rollout to aggregate local attributions, DecompX propagates the locally decomposed vectors throughout the layers to build a global decomposition. Since decomposition vectors propagate along the same path as the original representations, they accurately represent the inner workings of the entire model."

### Mechanism 2
- Claim: Incorporating all encoder components, including nonlinear feed-forward networks and the classification head, provides a more complete and faithful explanation of the model's decisions
- Mechanism: By including the FFN layers through an approximate decomposition of the activation function and propagating through the classification head, DecompX captures the full transformation of token representations from input to output
- Core assumption: The approximate decomposition of the activation function (fact) is sufficient to capture its effect on the token representations
- Evidence anchors:
  - [abstract]: "Additionally, our proposal provides multiple advantages over existing solutions for its inclusion of all encoder components (especially nonlinear feed-forward networks) and the classification head."
  - [section]: "To examine its individual effect we implemented GlobEnc + FFN where we incorporated the FFN component in each layer. Table 1 shows that this change improves GlobEnc in terms of faithfulness, bringing it closer to gradient-based methods."
  - [corpus]: Weak evidence - corpus contains related work on Transformers but not specifically on this comprehensive component inclusion

### Mechanism 3
- Claim: The decomposition method allows for per-predicted label explanations, indicating the extent to which each individual token has contributed towards or against a specific label prediction
- Mechanism: By propagating the decomposed vectors through the classification head, DecompX can compute the attribution of each input token to each output class, providing a more nuanced understanding of the model's decision-making process
- Core assumption: The classification head's output can be accurately decomposed into contributions from each input token
- Evidence anchors:
  - [abstract]: "Unlike existing techniques that provide absolute importance, this per-label explanation indicates the extent to which each individual token has contributed towards or against a specific label prediction."
  - [section]: "To explain a predicted output, yc⇐k would be the attribution of the kth token to the total prediction score."

## Architecture Onboarding

- Component map: Input embeddings → Multi-head self-attention → Residual connection + LayerNorm → Feed-forward network → Residual connection + LayerNorm → ... (repeated for each encoder layer) → Classification head

- Critical path: The path from input tokens through all encoder layers to the classification head, with decomposition vectors being propagated and transformed at each step

- Design tradeoffs:
  - Approximation of activation functions vs. exact decomposition: The choice to approximate activation functions allows for decomposition but introduces some error
  - Inclusion of biases vs. simplification: Including biases provides a more complete explanation but adds complexity to the decomposition process
  - Propagation of decomposition vectors vs. aggregation methods: Propagation preserves more information but is more complex than aggregation methods like rollout

- Failure signatures:
  - Inaccurate explanations: If the decomposition process fails at any point, the final explanations will be incorrect
  - Performance degradation: If the decomposition introduces significant overhead, it may impact the model's performance
  - Instability: If the decomposition is not stable across different inputs or model configurations, it may lead to unreliable explanations

- First 3 experiments:
  1. Implement the decomposition for a single self-attention layer and verify that the decomposed vectors accurately capture the attention weights and value combinations
  2. Extend the decomposition to include the FFN layer and test the approximation of the activation function on a simple dataset
  3. Implement the full decomposition through multiple encoder layers and evaluate the faithfulness of the explanations using perturbation-based metrics like AOPC

## Limitations
- The method relies on approximation of activation functions in FFN layers, which may introduce errors that are not fully quantified
- Computational overhead of propagating decomposed vectors through all layers could be substantial, potentially limiting scalability
- Evaluation focuses primarily on faithfulness metrics without extensive analysis of efficiency or robustness to adversarial inputs

## Confidence
- **High confidence** in the core decomposition mechanism and its implementation through self-attention and residual connections
- **Medium confidence** in the FFN decomposition and activation function approximation due to lack of thorough validation across different activation functions
- **Medium confidence** in the per-label explanation capability as the mechanism is clear but ablation studies on classification head contribution are limited

## Next Checks
1. **Decomposition accuracy verification**: Implement a layer-by-layer decomposition accuracy check that compares the sum of decomposed vectors to the original token representation at each layer, quantifying information loss through the network. This should include measuring reconstruction error after each component (attention, FFN, LayerNorm) to identify where the decomposition breaks down.

2. **Activation function approximation validation**: Systematically test the FFN decomposition across different activation functions (ReLU, GELU, SiLU) and measure how the choice of approximation method affects AOPC scores and explanation quality. Compare against ground truth decomposition where possible using smaller networks.

3. **Computational overhead characterization**: Measure the runtime overhead of DecompX compared to baseline methods across different sequence lengths and model sizes, and evaluate whether the faithfulness gains justify the computational cost in practical applications. Include memory usage analysis to assess scalability constraints.
