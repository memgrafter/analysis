# DocParser: End-to-end OCR-free Information Extraction from Visually Rich Documents
## Quick Facts
- arXiv ID: 2304.12484
- Source URL: https://arxiv.org/abs/2304.12484
- Reference count: 40
- Achieves state-of-the-art F1 scores: 87.3% on SROIE, 84.5% on CORD, 96.2% on private dataset

## Executive Summary
DocParser presents an end-to-end OCR-free information extraction model for visually rich documents that eliminates dependency on external OCR systems. The method combines convolutional neural networks for local character pattern extraction with Swin Transformer blocks to capture long-range dependencies between characters and document components. Through pre-training using knowledge transfer from OCR models and masked document reading on synthetic data, followed by fine-tuning on extraction tasks, DocParser achieves superior performance across multiple benchmarks while operating 1.5-2x faster than previous methods.

## Method Summary
DocParser introduces a hybrid encoder architecture that combines convolutional neural networks for local feature extraction with Swin Transformer blocks for capturing long-range dependencies in visually rich documents. The model operates directly on document images without requiring pre-processing by OCR systems, using a Transformer-based decoder to autoregressively generate field tokens. Pre-training involves knowledge transfer from existing OCR models and masked document reading tasks on synthetic data, followed by fine-tuning on specific extraction tasks. This end-to-end approach achieves state-of-the-art performance while maintaining computational efficiency advantages over traditional OCR-based pipelines.

## Key Results
- Achieves field-level F1 scores of 87.3% on SROIE, 84.5% on CORD, and 96.2% on private information statement dataset
- Operates 1.5-2x faster than previous information extraction methods
- Eliminates dependence on external OCR systems while maintaining high accuracy across diverse document types

## Why This Works (Mechanism)
The hybrid CNN-Swin architecture effectively captures both local character patterns and global document structure through multi-scale feature extraction. The end-to-end training eliminates error propagation from separate OCR and extraction stages, while knowledge transfer from pre-trained OCR models provides strong initialization for character recognition capabilities. The autoregressive decoder enables structured field generation that respects document layout constraints.

- Autoregressive Decoding: Sequential field generation maintaining layout consistency; quick check: validate token generation order follows document structure
- Knowledge Transfer: Pre-training initialization from OCR models; quick check: measure transfer learning impact on convergence speed
- Masked Document Reading: Self-supervised pre-training objective; quick check: evaluate masking strategy coverage across document types

## Architecture Onboarding
- Component Map: Document Image -> CNN Local Features -> Swin Global Features -> Transformer Decoder -> Field Tokens
- Critical Path: Image encoding through hybrid CNN-Swin encoder to autoregressive field generation
- Design Tradeoffs: Eliminates OCR dependency but requires larger model capacity for direct pixel-to-text mapping
- Failure Signatures: Poor performance on documents with unusual layouts or non-Latin scripts; degraded accuracy with high visual noise
- First Experiments: 1) Test on single-field extraction before full multi-field; 2) Evaluate pre-training impact with/without OCR knowledge transfer; 3) Compare performance with varying document text densities
