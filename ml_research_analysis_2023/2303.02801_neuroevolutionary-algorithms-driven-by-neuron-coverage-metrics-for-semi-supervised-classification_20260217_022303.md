# Neuroevolutionary algorithms driven by neuron coverage metrics for semi-supervised classification

## Quick Facts
- arXiv ID: 2303.02801
- Source URL: https://arxiv.org/abs/2303.02801
- Reference count: 36
- Key outcome: Neuroevolutionary approach uses neuron coverage metrics to improve semi-supervised classification when labeled data is scarce

## Executive Summary
This paper presents a neuroevolutionary approach that integrates neuron coverage metrics into the fitness function for semi-supervised classification. The method uses both labeled and unlabeled data during the evolutionary search process, where the fitness function combines balanced accuracy on labeled data with neuron coverage metrics computed on unlabeled data. The approach aims to make neuroevolution less sensitive to limited labeled data by leveraging structural coverage information from unlabeled instances.

## Method Summary
The method employs a neuroevolutionary algorithm where candidate neural network architectures are evolved based on a fitness function that combines two components: balanced accuracy on labeled training data and neuron coverage metrics on unlabeled data. The neuron coverage metrics (specifically NC and TKNC) measure how well different components of the neural network are activated by the training instances. During evolution, these metrics guide the search toward architectures that achieve better structural coverage while maintaining classification accuracy, with the hypothesis that better coverage leads to more robust generalization.

## Key Results
- The neuroevolutionary approach with neuron coverage metrics outperforms standard evolutionary approaches in semi-supervised settings
- NC and TKNC metrics show particularly strong performance compared to other coverage metrics
- The method demonstrates reduced sensitivity to label scarcity compared to baseline approaches
- Combined metrics (balanced accuracy + neuron coverage) lead to better generalization than either component alone

## Why This Works (Mechanism)
The approach works by using neuron coverage metrics as a proxy for structural exploration during the evolutionary search. When labeled data is scarce, the coverage metrics computed on abundant unlabeled data help guide the evolution toward architectures that activate diverse neuron patterns. This structural diversity serves as a regularizer, encouraging the discovery of network architectures that generalize better to unseen data by ensuring different network components are meaningfully engaged during training.

## Architecture Onboarding

Component map:
Population of neural architectures -> Fitness evaluation (labeled + unlabeled data) -> Selection and mutation -> New population

Critical path:
Initial population creation -> Fitness evaluation (balanced accuracy + neuron coverage) -> Selection based on fitness -> Mutation/crossover operations -> Population update -> Convergence check

Design tradeoffs:
The paper balances exploration (through coverage metrics) with exploitation (through classification accuracy). The main tension is between the computational cost of evaluating coverage metrics on unlabeled data versus the potential generalization benefits. The choice of specific coverage metrics (NC, TKNC) over others represents a deliberate tradeoff based on empirical performance.

Failure signatures:
Poor coverage metrics with high accuracy might indicate overfitting to labeled data. Conversely, high coverage with low accuracy suggests the architecture fails to learn discriminative features. Convergence to suboptimal architectures could indicate the coverage metrics are not well-calibrated to the classification task.

First experiments:
1. Run the algorithm with only balanced accuracy (no coverage metrics) to establish baseline performance
2. Test individual coverage metrics (NC alone, TKNC alone) to assess their individual contributions
3. Vary the weighting between accuracy and coverage metrics in the fitness function to find optimal balance
