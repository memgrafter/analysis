# Goat: Fine-tuned LLaMA Outperforms GPT-4 on Arithmetic Tasks

## Quick Facts
- arXiv ID: 2305.14201
- Source URL: https://arxiv.org/abs/2305.14201
- Reference count: 40
- Goat-7B fine-tuned LLaMA outperforms GPT-4 on BIG-bench arithmetic tasks

## Executive Summary
This paper introduces Goat, a fine-tuned LLaMA model that significantly outperforms GPT-4 on arithmetic tasks, achieving state-of-the-art performance on BIG-bench arithmetic sub-tasks. Goat-7B matches or surpasses PaLM-540B accuracy on addition and subtraction through supervised fine-tuning alone, achieving near-perfect accuracy on large-number operations. For multi-digit multiplication and division, the authors propose a novel decomposition method that breaks down unlearnable tasks into learnable sub-tasks using basic arithmetic principles. The approach outperforms GPT-4's long multiplication and division methods, with Goat-7B achieving 97.1% exact match accuracy on 16-digit addition, compared to GPT-4's 9.4%. The model can be trained using LoRA on a 24GB GPU and is released publicly with the dataset and generation script.

## Method Summary
The authors fine-tune LLaMA models on a curated arithmetic dataset using supervised learning, achieving strong performance on basic operations. For complex operations like multi-digit multiplication and division, they introduce a decomposition approach that breaks down problems into simpler sub-tasks. The method involves generating step-by-step solutions using basic arithmetic operations, which the model can learn effectively. LoRA is employed for efficient fine-tuning, allowing the models to be trained on consumer-grade GPUs with 24GB of memory. The complete dataset, generation scripts, and fine-tuned models are released publicly for reproducibility.

## Key Results
- Goat-7B achieves 97.1% exact match accuracy on 16-digit addition, compared to GPT-4's 9.4%
- Matches or surpasses PaLM-540B accuracy on addition and subtraction tasks
- Near-perfect accuracy on large-number addition and subtraction operations
- Novel decomposition method outperforms GPT-4's long multiplication and division approaches

## Why This Works (Mechanism)
The paper's success stems from combining task-specific fine-tuning with intelligent problem decomposition. By breaking down complex arithmetic operations into simpler, learnable components, the model can handle tasks that would otherwise be unlearnable for a single-step approach. The supervised fine-tuning on a carefully curated dataset ensures the model learns correct arithmetic patterns, while the decomposition method leverages the model's existing capabilities on basic operations to solve more complex problems systematically.

## Architecture Onboarding

**Component Map:**
LLaMA base model -> Supervised fine-tuning on arithmetic data -> Decomposition method for complex operations -> LoRA adaptation

**Critical Path:**
The most critical sequence is: fine-tuning on curated arithmetic data → applying decomposition method → evaluating exact match performance. Each step builds on the previous, with decomposition being the key innovation that enables handling of complex operations.

**Design Tradeoffs:**
The approach trades model size for task-specific performance, using a 7B parameter model rather than larger alternatives. This enables efficient training and deployment while achieving superior results on the target task. The decomposition method adds computational overhead during inference but enables solving problems that would be unlearnable otherwise.

**Failure Signatures:**
The model may fail on arithmetic operations outside its training distribution, particularly with very large numbers beyond 16 digits or with non-standard problem formats. Performance could degrade if the decomposition breaks down for certain problem types or if step-by-step reasoning becomes too complex.

## Limitations
- Evaluation focuses exclusively on BIG-bench arithmetic sub-tasks, limiting generalizability
- Performance comparisons with GPT-4 are based on reported results rather than direct head-to-head evaluations
- Decomposition method's scalability to extremely large numbers or more complex mathematical domains remains untested

## Confidence
- Goat-7B outperforming GPT-4 on BIG-bench arithmetic tasks: High
- Supervised fine-tuning alone achieving near-perfect accuracy on large-number addition/subtraction: High
- Decomposition method's effectiveness for multi-digit multiplication/division: Medium (based on single benchmark)
- LoRA training feasibility on 24GB GPU: High
