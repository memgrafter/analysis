# ECGAN: Self-supervised generative adversarial network for electrocardiography

## Quick Facts
- arXiv ID: 2301.09496
- Source URL: https://arxiv.org/abs/2301.09496
- Reference count: 28
- ECGAN is a generative adversarial network for ECG synthesis that uses a self-supervised pre-training phase to improve the quality and diversity of generated samples.

## Executive Summary
ECGAN introduces a self-supervised generative adversarial network specifically designed for electrocardiography synthesis. The model employs an encoder-decoder architecture with shared weights that first learns ECG dynamics through self-supervised pre-training, followed by adversarial training to produce synthetic ECGs matching real data distributions. The approach demonstrates superior performance across multiple quantitative metrics including Frechet Inception Distance, Inception Score, Maximum Mean Discrepancy, and Wasserstein distance, while maintaining high diversity and morphological plausibility in generated samples.

## Method Summary
ECGAN uses an encoder-decoder architecture with shared weights for self-supervised pre-training to learn ECG dynamics, followed by adversarial training. The self-supervised phase allows the model to capture temporal patterns and morphological features of ECG signals before the GAN training phase. This two-stage approach aims to address common challenges in ECG synthesis such as maintaining physiological plausibility while achieving high sample quality and diversity. The model is evaluated on standard generative modeling metrics and applied to data augmentation tasks for improving ECG arrhythmia classifier performance.

## Key Results
- ECGAN outperforms existing generative models for ECG and audio synthesis across FID, IS, MMD, and Wasserstein distance metrics
- Generated ECG samples demonstrate high diversity and morphological plausibility
- Data augmentation with ECGAN-synthetic samples improves arrhythmia classifier performance

## Why This Works (Mechanism)
The self-supervised pre-training phase allows the encoder-decoder architecture to learn meaningful representations of ECG dynamics without requiring labeled data. This pre-training establishes a robust feature space that captures the temporal and morphological characteristics of ECG signals, which the subsequent adversarial training can then refine to produce high-quality synthetic samples. The shared weights between encoder and decoder create a compressed representation that preserves essential ECG features while enabling efficient generation.

## Architecture Onboarding

**Component Map:** Input ECG -> Encoder -> Shared Weights -> Decoder -> Generator -> Discriminator -> Output Synthetic ECG

**Critical Path:** Self-supervised pre-training (encoder-decoder) -> Adversarial training (generator-discriminator) -> Synthetic ECG generation

**Design Tradeoffs:** The self-supervised pre-training adds computational overhead but improves sample quality and diversity compared to direct GAN training. Shared weights reduce parameter count but may limit architectural flexibility.

**Failure Signatures:** Mode collapse manifests as repetitive ECG patterns; poor self-supervised pre-training leads to unrealistic morphology; discriminator overpowering generator results in low sample diversity.

**First Experiments:** 1) Verify self-supervised pre-training captures ECG temporal dependencies using reconstruction loss, 2) Test adversarial training stability with gradient penalty, 3) Evaluate synthetic ECG quality using both automated metrics and expert review.
