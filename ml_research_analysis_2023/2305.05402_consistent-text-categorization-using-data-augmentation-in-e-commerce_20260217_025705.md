# Consistent Text Categorization using Data Augmentation in e-Commerce

## Quick Facts
- arXiv ID: 2305.05402
- Source URL: https://arxiv.org/abs/2305.05402
- Reference count: 24
- Primary result: Improves text classification consistency by 4-10% while maintaining accuracy

## Executive Summary
This work addresses the problem of inconsistent text classification in e-commerce, where minor product title variations (like color or size changes) can lead to different category predictions. The authors propose a semi-supervised learning framework that uses data augmentation to make the model more robust to these minor changes. They present two methods: consistent self-training (CST) and consistent generative augmentation (CGA), both of which leverage unlabeled clustered data to improve consistency while maintaining accuracy.

## Method Summary
The authors propose a semi-supervised learning approach to improve text classification consistency in e-commerce. They use data augmentation with two methods: consistent self-training (CST) and consistent generative augmentation (CGA). CST uses unlabeled clustered data to create pseudo-labels and augments the training data, while CGA trains a generative model (T5) to create new samples based on the original data. Both methods aim to make the model more robust to minor text changes that should not affect category predictions.

## Key Results
- Both CST and CGA improve consistency by 4-10% compared to baseline
- Using real-world samples (CST) is more effective than generated ones (CGA)
- Preserving the original data distribution is important for maintaining accuracy
- More examples of item versioning lead to greater consistency improvements

## Why This Works (Mechanism)

### Mechanism 1
Data augmentation with item versioning exposes the model to label-preserving perturbations, making it robust to minor text changes. By adding perturbed versions of training items, the model learns to ignore spurious features (e.g., color, size) and focus on core product characteristics. Core assumption: The unlabeled clustered data accurately represents real-world item versioning. Break condition: If the perturbation function is not label-preserving, augmented data would introduce noise.

### Mechanism 2
Self-training with pseudo-labels leverages unlabeled clustered data to expand the training set while maintaining consistency. Clusters of item versions are assigned a single pseudo-label using the base model, then all versions are added with that label, encouraging the classifier to treat them identically. Core assumption: The base model's predictions are reliable enough for pseudo-labeling. Break condition: If clusters contain heterogeneous items or the base model is poorly calibrated, pseudo-labels will be wrong.

### Mechanism 3
Generative augmentation learns the perturbation function V and creates synthetic, label-preserving examples to improve consistency. A T5 model is trained on pairs of item versions to generate new perturbed titles; filtering ensures quality and label preservation. Core assumption: The generative model can accurately learn V and produce realistic, label-consistent perturbations. Break condition: If the generative model fails to capture V accurately, generated samples will be unrealistic.

## Architecture Onboarding

- **Component map**: FastText hierarchical classifier → self-training or generative augmentation → consistency evaluation
- **Critical path**: Train base model → generate/collect augmented data → retrain with augmented set → evaluate consistency and accuracy
- **Design tradeoffs**: Real data (CST) vs. generated data (CGA): real is higher quality but less scalable; generated is more flexible but may be noisy. Filtering threshold T: higher T improves consistency but reduces data volume.
- **Failure signatures**: Accuracy drops significantly → distribution shift or poor pseudo-labels. Consistency doesn't improve → augmentation doesn't capture true versioning. High variance → unstable pseudo-labeling or generative model.
- **First 3 experiments**: 1) Train baseline FastText model and measure accuracy/consistency. 2) Apply CST with sub-sampled unlabeled data and compare results. 3) Apply CGA with T5 generation and BLEU filtering, then compare.

## Open Questions the Paper Calls Out

### Open Question 1
How does the proposed framework perform on datasets from different domains, such as healthcare or legal documents? The authors note their study was conducted on only one specific dataset and might not generalize to other problems. Testing on various domains would establish generalizability.

### Open Question 2
What is the impact of changing the model's objective function to account for consistency on the proposed solutions? The authors mention other approaches, such as changing the model's objective function to take consistency into account, might benefit the solution. Experimenting with different objective functions would compare results to the current approach.

### Open Question 3
How can the inconsistencies in the model's output be further reduced, given that the proposed solutions still show visible inconsistencies? The authors acknowledge that while their solution shows significant improvement over the baseline, inconsistencies are still visible. Developing and testing additional techniques would further reduce inconsistencies.

## Limitations

- The assumption that clustered item sets represent true label-preserving perturbations may not hold in practice
- Evaluation metrics may not fully capture real-world performance impacts
- Comparison between real and generated augmentation data is limited to one setting

## Confidence

**High Confidence:**
- The problem of inconsistent text classification due to minor product variations is well-documented
- The experimental methodology for measuring consistency using perturbed test sets is sound

**Medium Confidence:**
- Both CST and CGA improve consistency by 4-10% is supported by experimental results but shows high variance
- Real data augmentation outperforms generated data is based on limited comparisons

**Low Confidence:**
- Preserving the original distribution is important for accuracy lacks strong empirical support
- CGA with filtering can match CST performance is based on a single parameter setting

## Next Checks

1. **Cluster Quality Analysis**: Conduct detailed analysis of unlabeled clustered data to quantify truly label-preserving item sets versus heterogeneous clusters, validating core assumptions.

2. **Robustness to Base Model Quality**: Repeat experiments with base models of varying quality to determine sensitivity to base model reliability for pseudo-labeling.

3. **Ablation on Distribution Preservation**: Systematically vary augmented data distribution (oversample classes, different perturbation frequencies) to test the claim about preserving original distribution.
