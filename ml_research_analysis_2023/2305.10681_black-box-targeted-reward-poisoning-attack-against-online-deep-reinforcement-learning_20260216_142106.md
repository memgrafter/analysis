# Black-Box Targeted Reward Poisoning Attack Against Online Deep Reinforcement Learning

## Quick Facts
- arXiv ID: 2305.10681
- Source URL: https://arxiv.org/abs/2305.10681
- Authors: 
- Reference count: 12
- Primary result: First black-box targeted reward poisoning attack against online deep reinforcement learning algorithms

## Executive Summary
This paper introduces the first black-box targeted reward poisoning attack against online deep reinforcement learning (DRL) algorithms. The attack is designed to be applicable to general environments with unknown dynamics and unknown learning algorithms, requiring limited attack budgets and computational resources. By leveraging a general framework and identifying conditions for efficient attacks under a general assumption of learning algorithms, the authors demonstrate that their attack is optimal within their framework. Experimental results show that with limited budgets, the attack effectively leads learning agents to various target policies across diverse popular DRL environments and state-of-the-art learners.

## Method Summary
The authors propose a black-box targeted reward poisoning attack that operates by modifying the reward function in an MDP environment. The attacker observes state-action-reward tuples during training and applies a perturbation based on the distance between the agent's current action and a target action. For continuous action spaces, the penalty is a linear function of the distance to the target action, ensuring that perturbations are proportional to how far the agent is from the target. This creates a coherent message that rewards actions closer to the target while penalizing those farther away. The attack is designed to work without knowledge of algorithm internals or environment dynamics, relying only on the assumption that efficient DRL algorithms will eventually identify optimal actions in static environments.

## Key Results
- Attack successfully guides agents to target policies across multiple DRL algorithms (TD3, double dueling DQN) and environments (MountainCar, HalfCheetah)
- With limited budgets, attack achieves significant reduction in average distance between agent actions and target actions
- Attack maintains effectiveness across different target policy types (random, medium, expert)
- Linear penalty function ensures efficient use of attack budget while maintaining attack effectiveness

### Mechanism 1
- Claim: Adversarial MDP attack works by making agent train in a malicious environment where target actions become optimal
- Mechanism: Replaces true reward function R with adversarial reward ˆR in a way that preserves state and action spaces but alters reward structure. The agent learns to maximize reward in this corrupted environment, which is designed so target policy π† is optimal under ˆR.
- Core assumption: Efficient learning algorithms will identify and exploit optimal actions in static environments, and these optimal actions in the adversarial environment correspond to the attacker's target actions.

- Break condition: If the adversarial environment is too difficult for the learning algorithm to find optimal actions, or if the algorithm doesn't converge to optimal actions within training time.

- Claim: Linear reward penalty function ensures efficient attacks with minimal budgets
- Mechanism: For continuous action spaces, penalty is ∆·||at−π†(st)||2/L, creating smooth gradient toward target actions. This makes perturbations proportional to distance from target, ensuring small total corruption when agent is near target.

- Claim: Black-box setting is viable because attacker exploits general properties of RL algorithms rather than algorithm-specific details
- Mechanism: Attacker observes state-action-reward tuples during training and applies fixed perturbation rule without needing to understand algorithm internals. The perturbation rule is designed to work across different algorithms based on universal exploration-exploitation tradeoff properties.
- Core assumption: All efficient DRL algorithms must balance exploration-exploitation and will eventually identify optimal actions in static environments.

## Architecture Onboarding

- Component map: Learning agent -> Environment -> Attacker -> Agent receives perturbed reward
- Critical path: Agent takes action -> Environment transitions -> Attacker observes (s,a,s',r) -> Attacker computes and applies perturbation ∆ -> Agent receives (s,a,s',r+∆) -> Agent updates policy -> Repeat
- Design tradeoffs: The attack trades off between perturbation magnitude (affecting stealth) and attack effectiveness. Larger perturbations are more effective but more detectable. The linear penalty function balances this by being larger when agent is far from target and smaller when close.
- Failure signatures: Attack fails if agent's average action-target distance doesn't decrease over time, if total perturbation budget is exhausted too quickly, or if agent's policy diverges significantly from expected behavior under the adversarial MDP.
- First 3 experiments:
  1. Run attack with fixed ∆ value on simple environment (MountainCar) with known algorithm to verify basic functionality
  2. Test attack effectiveness across different target policy types (random, medium, expert) to validate generality
  3. Measure attack performance with constrained budgets to verify efficiency claims under realistic limitations

- Focuses on reward function perturbations while leaving state and action spaces unchanged
- Limited empirical validation across diverse algorithm architectures and environment types
