# Dis-AE: Multi-domain & Multi-task Generalisation on Real-World Clinical Data

## Quick Facts
- arXiv ID: 2306.09177
- Source URL: https://arxiv.org/abs/2306.09177
- Reference count: 40
- Primary result: Dis-AE improves model generalization on multiple domains simultaneously while preserving clinically relevant information in FBC data

## Executive Summary
This paper introduces Dis-AE (Disentangled Autoencoder), a novel deep learning model for domain generalization on clinical data. The model addresses the challenge of domain shift in healthcare applications, where machine learning models trained on data from one domain often perform poorly when applied to data from another domain. Dis-AE learns domain-agnostic data representations through adversarial training that makes domain labels difficult to predict while maintaining task-relevant information through an autoencoder framework.

## Method Summary
Dis-AE is a deep learning architecture that combines an autoencoder with adversarial training to learn domain-agnostic representations. The model consists of an encoder-decoder pair with multiple task classifier heads and multiple domain classifier heads attached to the latent space. During training, gradient reversal layers are applied before each domain head, forcing the encoder to produce representations that are useful for tasks but not for identifying domains. The model is trained with a combined loss function that includes reconstruction error, task classification accuracy, and adversarial domain classification terms.

## Key Results
- Achieved 98% task classification accuracy on synthetic datasets
- Significantly reduced domain shift in latent space representations
- Demonstrated successful generalization from INTERVAL blood donor data to COMPARE patient data

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Dis-AE learns domain-agnostic data representations that generalize across multiple domains by making domain labels difficult to predict via adversarial training.
- **Mechanism:** The model uses gradient reversal layers to simultaneously train task classifiers to maximize accuracy and domain classifiers to minimize accuracy, forcing the encoder to produce representations that are useful for tasks but not for identifying domains.
- **Core assumption:** The gradient reversal layer implementation effectively implements the adversarial game without requiring alternating optimization steps.
- **Evidence anchors:**
  - [abstract] "Dis-AE learns domain-agnostic data representations by using adversarial training to make the domain label difficult to predict."
  - [section] "We aim to find a saddle point of E such that... {ˆθd} = arg min {θd} Ldomain"
- **Break condition:** If the gradient reversal layer fails to properly implement the adversarial objective, the model will learn representations that encode domain information.

### Mechanism 2
- **Claim:** The autoencoder component ensures learned representations preserve clinically relevant information while removing domain-specific information.
- **Mechanism:** The reconstruction loss forces the encoder-decoder pair to learn representations that can reconstruct the input, ensuring semantic information is retained, while adversarial training removes domain-specific information from the latent space.
- **Core assumption:** The reconstruction objective and domain-adversarial objective can be balanced through the hyperparameters α, β, and λ.
- **Evidence anchors:**
  - [section] "we incorporate a decoder network mirroring the feature extractor, to ensure the model learns to extract meaningful representations from the data"
  - [section] "The model utilises adversarial training to produce data representations from which the domain can no longer be determined"
- **Break condition:** If the reconstruction objective dominates, domain information may persist in the latent space; if adversarial training dominates, the representation may lose task-relevant information.

### Mechanism 3
- **Claim:** Dis-AE can handle multiple interacting domains by treating each as a separate classifier head in the latent space.
- **Mechanism:** Multiple domain heads are attached to the latent space, each trained to predict a different domain label. The adversarial training makes all domain predictions difficult, forcing the representation to be agnostic to all domains simultaneously.
- **Core assumption:** Each domain head can effectively learn to predict its corresponding domain when not being adversarially trained.
- **Evidence anchors:**
  - [abstract] "The model utilises adversarial training to produce data representations from which the domain can no longer be determined"
  - [section] "we consider a more realistic separation when describing a dataset's domain shift... and introduce the option to add multiple domain classifier heads to the latent space"
- **Break condition:** If domains are highly correlated, removing information about one domain may inadvertently remove information about another, degrading performance.

## Architecture Onboarding

- **Component map:** Input data -> Encoder -> Latent space -> [Decoder, Task heads, Gradient reversal layers -> Domain heads]
- **Critical path:**
  1. Input data passes through encoder to latent space
  2. Latent representation goes to decoder for reconstruction
  3. Same latent representation goes to task heads for classification
  4. Same latent representation goes through gradient reversal layers to domain heads
  5. Loss combines reconstruction, task accuracy, and adversarial domain classification
- **Design tradeoffs:**
  - Balancing reconstruction quality vs. domain invariance through hyperparameters
  - Number of latent dimensions vs. ability to capture task-relevant information
  - Number of task/domain heads vs. model complexity and training stability
- **Failure signatures:**
  - High reconstruction error indicates the encoder-decoder pair isn't learning meaningful representations
  - Task accuracy drops significantly when using Dis-AE vs. vanilla AE suggests domain information is being removed along with task-relevant features
  - Domain accuracy remains high indicates adversarial training isn't effectively removing domain information
- **First 3 experiments:**
  1. Train Dis-AE on synthetic dataset A (single task, single domain) and compare task accuracy and domain variation to vanilla AE
  2. Train Dis-AE on synthetic dataset C (multiple tasks, multiple domains) and evaluate per-task performance
  3. Train Dis-AE on INTERVAL dataset and test generalization to COMPARE dataset, measuring both accuracy and model variation

## Limitations

- Reliance on synthetic datasets for initial validation may not fully capture real-world clinical data complexity
- Evaluation limited to one source-target domain pair (INTERLECT to COMPARE) for clinical data
- Performance on datasets with non-linear domain shifts or complex domain interactions remains unclear

## Confidence

- **High Confidence:** The Dis-AE architecture is technically sound and builds on established autoencoder and adversarial training principles. The synthetic dataset experiments demonstrate the model's ability to learn domain-agnostic representations when the domain shift mechanism is known and controlled.
- **Medium Confidence:** The clinical dataset results show improved generalization, but the evaluation is limited to one source-target pair. The claim that Dis-AE preserves clinically relevant information while removing domain information is supported but not definitively proven.
- **Low Confidence:** The assertion that Dis-AE can handle "multiple interacting domains" is based on synthetic experiments with controlled affine transformations. Real-world clinical domains often involve more complex, non-linear interactions that may not be adequately addressed by the current approach.

## Next Checks

1. Evaluate Dis-AE on additional clinical dataset pairs with different domain characteristics (e.g., different hospitals, different time periods, or different measurement protocols) to assess generalization across diverse domain shifts.

2. Perform ablation studies varying the hyperparameters (α, β, λ) systematically to determine their impact on reconstruction quality, domain invariance, and task performance, establishing more robust training guidelines.

3. Test Dis-AE on clinical datasets with known non-linear domain shifts or more complex domain interactions (e.g., combining hospital, time, and protocol as separate domains) to validate the model's scalability beyond affine transformations.
