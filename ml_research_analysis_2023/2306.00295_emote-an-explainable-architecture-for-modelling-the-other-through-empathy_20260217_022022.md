# EMOTE: An Explainable architecture for Modelling the Other Through Empathy

## Quick Facts
- **arXiv ID**: 2306.00295
- **Source URL**: https://arxiv.org/abs/2306.00295
- **Reference count**: 25
- **Primary result**: EMOTE architecture models other agents through empathy in MARL, producing stable action-value function estimates and human-interpretable empathetic states

## Executive Summary
This paper introduces EMOTE, an explainable architecture for modeling other agents through empathy in multi-agent reinforcement learning. The key innovation is an "Imagination Network" that transforms observed states of another agent into "empathetic states" that, when evaluated by the learning agent's own Q-function, produce behaviors mimicking the other agent. This approach generates stable and robust models of the other agent's action-value function while also producing human-interpretable empathetic states. The architecture is particularly valuable for algorithms using composite value or reward functions. Experiments demonstrate EMOTE achieves better performance in multi-agent games, robustly estimates the other agent's model across different environment configurations, and generates interpretable empathetic states reflecting the other agent's behavior.

## Method Summary
EMOTE uses a two-part architecture: an Imagination Network that transforms the observed state of an independent agent into an empathetic state, and a copy of the learning agent's action-value function that evaluates these empathetic states. The system is trained using a loss function combining categorical cross-entropy between predicted and actual actions, and L1 distance between observed and empathetic states. This architecture enables the learning agent to model the independent agent's action-value function while generating interpretable states that reveal which features the independent agent finds relevant. The method leverages the learning agent's own Q-function to naturally scale inferred rewards, eliminating the need for ad-hoc normalization.

## Key Results
- EMOTE produces stable and robust models of the other agent's action-value function while generating human-interpretable empathetic states
- The architecture naturally scales inferred rewards to match the learning agent's reward scale, enabling stable composite value functions
- Experiments demonstrate superior performance in multi-agent games and interpretable empathetic states that reflect the other agent's behavior

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: EMOTE produces stable models of the independent agent's action-value function by leveraging the learning agent's own Q-function
- **Mechanism**: The Imagination Network transforms the observed state into an empathetic state that, when passed through the learning agent's Q-function, produces action values analogous to the independent agent's true values. This works because analogous features between agents map to similar reward ranges
- **Core assumption**: Learning and independent agents share analogous features and sufficient degree of analogy exists between them
- **Evidence anchors**: Abstract states stable and robust models are produced; paper section confirms analogous features map to similar reward ranges
- **Break condition**: The analogy assumption breaks down (degree of analogy is too low), or the imagination network fails to find appropriate analogous features

### Mechanism 2
- **Claim**: EMOTE ensures inferred rewards have similar scale to the learning agent's rewards, crucial for stable composite value/reward functions
- **Mechanism**: By using the learning agent's own Q-function to evaluate empathetic states, the resulting action values naturally lie in a similar scale to the learning agent's, eliminating the need for ad-hoc normalization
- **Core assumption**: The learning agent's Q-function produces action values in a reasonable range that can serve as a reference scale
- **Evidence anchors**: Abstract confirms action-values and inferred rewards lie in similar scales; paper section describes natural narrowing of candidate reward function space
- **Break condition**: If the learning agent's reward scale is poorly chosen or if the degree of analogy is too low, the inferred rewards may not be appropriately scaled

### Mechanism 3
- **Claim**: The two-part loss function (action prediction + state reconstruction) enables EMOTE to produce interpretable empathetic states that capture analogous features
- **Mechanism**: The cross-entropy loss ensures the empathetic state produces the same action as the independent agent, while the reconstruction loss ensures minimal changes to the original state. This forces the network to identify which features need to be transformed to evoke empathy
- **Core assumption**: The imagination network can learn to transform states in a way that preserves common features while altering analogous ones
- **Evidence anchors**: Abstract states empathetic states are human interpretable and verifiable; paper section describes goal of producing empathetic states through minimal changes
- **Break condition**: If the imagination network overfits to reconstructing the original state without capturing analogous features, or if the loss weighting is poorly chosen

## Architecture Onboarding

- **Component map**: Environment -> Independent agent takes action -> Imagination Network transforms observed state to empathetic state -> Copy of Qlearn evaluates empathetic states -> Loss function updates Mimagine -> Qlearn updated via DQN updates -> IRL module infers reward function

- **Critical path**: 
  1. Independent agent takes action and environment returns (s_i, a_i, s'_i)
  2. Mimagine transforms s_i to empathetic state s_e
  3. Copy of Qlearn evaluates s_e to get Q-values
  4. Loss function updates Mimagine parameters
  5. Qlearn is updated using DQN updates
  6. IRL module infers reward function from estimated Q-values

- **Design tradeoffs**:
  - Complexity vs interpretability: Adding Mimagine increases model complexity but enables interpretable states
  - Accuracy vs stability: The two-part loss balances action prediction accuracy with stable state reconstruction
  - Generalization vs specialization: The architecture works for various environments but may need environment-specific tuning

- **Failure signatures**:
  - Poor action prediction: Loss1 dominates, indicating Mimagine fails to produce empathetic states that match independent agent actions
  - Poor state reconstruction: Loss2 dominates, indicating Mimagine makes excessive changes to states
  - Unstable training: Loss values oscillate wildly, suggesting learning rate or architecture needs adjustment

- **First 3 experiments**:
  1. Train EMOTE on the Assistive 1 environment and verify door-opening behavior emerges
  2. Compare win rates and harm rates in Adversarial 1 vs Selfish baseline
  3. Visualize empathetic states to verify analogous features (pellet colors) are being transformed correctly

## Open Questions the Paper Calls Out

### Open Question 1
- **Question**: How does the performance of EMOTE scale with increasing numbers of independent agents?
- **Basis in paper**: The paper mentions that "a new Imagination Network would be required for each" independent agent, which could hinder scalability
- **Why unresolved**: The experiments only involved a single learning agent and one independent agent, so the scalability with multiple independent agents is untested
- **What evidence would resolve it**: Experiments with EMOTE involving multiple independent agents, comparing performance and scalability to other methods

### Open Question 2
- **Question**: How does the performance of EMOTE compare to state-of-the-art multi-agent reinforcement learning methods in more complex and diverse environments?
- **Basis in paper**: The paper states "Our method does not aim to outperform current state-of-the-art, rather to produce robust and stable inferences about the independent agent’s action-value and reward function"
- **Why unresolved**: The experiments were limited to simple gridworld environments, and the paper does not claim to outperform state-of-the-art methods
- **What evidence would resolve it**: Experiments comparing EMOTE to state-of-the-art methods in more complex and diverse multi-agent environments

### Open Question 3
- **Question**: How does the choice of hyperparameter δ affect the trade-off between interpretability and accuracy of the empathetic state?
- **Basis in paper**: The paper discusses the role of δ in balancing the two loss terms and mentions that "high δ values were beneficial" in practice
- **Why unresolved**: The paper does not provide a systematic study of the effect of different δ values on the trade-off between interpretability and accuracy
- **What evidence would resolve it**: A comprehensive analysis of the effect of varying δ on the interpretability of the empathetic state and the accuracy of the inferred action-value and reward functions

## Limitations
- The architecture relies heavily on the analogy assumption between learning and independent agents, with no quantification of required similarity
- Assumes access to independent agent's trajectories during training, which may not be realistic in all multi-agent scenarios
- Lacks ablation studies to isolate the contribution of each architectural component

## Confidence
- **High Confidence**: The empirical results showing EMOTE outperforms baselines in the four game environments, and the qualitative analysis demonstrating interpretable empathetic states
- **Medium Confidence**: The theoretical mechanism explaining why EMOTE produces stable models through analogous feature mapping, as this relies on the analogy assumption which isn't empirically validated
- **Low Confidence**: The claim that EMOTE naturally solves the reward normalization problem, as the paper doesn't provide quantitative evidence comparing inferred reward scales across different agent types

## Next Checks
1. **Analogy Sensitivity Analysis**: Systematically vary the similarity between learning and independent agents (e.g., different reward functions, state representations) and measure EMOTE's performance degradation to quantify the required degree of analogy

2. **Ablation Studies**: Remove the state reconstruction loss or the action prediction loss separately to determine which component is more critical for performance and interpretability

3. **Reward Scale Validation**: Quantitatively compare the scale of inferred rewards from EMOTE versus ground truth rewards across multiple agent types to validate the claim about natural normalization
