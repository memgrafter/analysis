# Leveraging Domain Knowledge for Inclusive and Bias-aware Humanitarian Response Entry Classification

## Quick Facts
- arXiv ID: 2305.16756
- Source URL: https://arxiv.org/abs/2305.16756
- Reference count: 6
- Primary result: Domain-specific LLM with bias mitigation outperforms generic models in humanitarian response classification

## Executive Summary
This paper introduces HumBERT, a specialized large language model designed for humanitarian response entry classification. The work addresses critical challenges in adapting LLMs for data-sparse humanitarian domains while systematically measuring and mitigating societal biases. The authors propose a novel combinatorial architecture that combines shared and task-specific Transformer layers, along with a counterfactual data augmentation approach to reduce gender and country biases. Experimental results demonstrate significant performance improvements over strong baseline models in both zero-shot and fully supervised settings, while achieving substantial bias reduction without sacrificing accuracy.

## Method Summary
The authors developed HumBERT by fine-tuning a BERT base model on humanitarian response data using a combinatorial architecture with shared and task-specific Transformer layers. They implemented a systematic bias measurement framework using Sentence-BERT embeddings and introduced a counterfactual data augmentation method to mitigate gender and country biases. The approach involves generating counterfactual examples by swapping protected attributes (gender and country) in the training data, creating a more balanced representation. The model was evaluated on the IASC dataset using both zero-shot and fully supervised settings, with comprehensive bias analysis using established metrics like WEAT and log-odds ratios.

## Key Results
- HumBERT outperforms strong baseline models in both zero-shot and fully supervised settings
- Bias mitigation method reduces gender bias from 20.52 to 1.03 in the zero-shot setting
- Country bias reduced from 7.26 to 2.06 in the zero-shot setting
- Performance maintained or improved while significantly reducing biases

## Why This Works (Mechanism)
The effectiveness stems from the domain-specific fine-tuning that captures humanitarian response terminology and context patterns, combined with the combinatorial architecture that allows shared knowledge across tasks while maintaining task-specific capabilities. The counterfactual augmentation creates balanced training distributions by explicitly addressing underrepresented combinations of gender and country attributes, preventing the model from learning spurious correlations. The systematic bias measurement using Sentence-BERT embeddings provides quantitative feedback for iterative improvement of the bias mitigation strategy.

## Foundational Learning
- **Domain-specific fine-tuning**: Why needed - Generic LLMs lack domain-specific terminology and context patterns; Quick check - Evaluate on held-out domain data before and after fine-tuning
- **Combinatorial architecture**: Why needed - Balance between shared knowledge and task-specific capabilities; Quick check - Compare performance with only shared vs only task-specific layers
- **Counterfactual augmentation**: Why needed - Address data imbalance and prevent spurious correlations; Quick check - Verify counterfactual examples maintain semantic meaning
- **Bias measurement with Sentence-BERT**: Why needed - Quantitative assessment of societal biases in embeddings; Quick check - Confirm bias metrics align with qualitative inspection

## Architecture Onboarding
- **Component map**: Input data -> Shared Transformer layers -> Task-specific Transformer layers -> Classification head -> Output predictions
- **Critical path**: Data preprocessing → Counterfactual augmentation → Shared+task-specific fine-tuning → Bias measurement → Classification
- **Design tradeoffs**: Computational cost of counterfactual generation vs bias reduction benefits; complexity of combinatorial architecture vs performance gains
- **Failure signatures**: High bias scores despite augmentation indicate insufficient counterfactual diversity; performance degradation suggests over-regularization from bias mitigation
- **First experiments**: 1) Baseline performance on IASC dataset without augmentation, 2) Ablation study removing task-specific layers, 3) Counterfactual generation quality assessment

## Limitations
- Evaluation dataset limited to 4,911 entries from IASC, constraining generalizability
- Bias evaluation framework focuses only on gender and country dimensions, missing other protected characteristics
- Counterfactual augmentation assumes binary gender categories, not capturing full gender diversity
- Performance gains, while significant, may not translate to substantial practical improvements in operational contexts

## Confidence
- High confidence: Technical implementation of HumBERT architecture and experimental methodology
- Medium confidence: Generalizability of results to broader humanitarian contexts beyond IASC dataset
- Low confidence: Long-term stability and maintenance requirements of bias mitigation in production environments

## Next Checks
1. Cross-dataset validation: Evaluate HumBERT on independently collected humanitarian datasets from different organizations and regions to assess generalizability beyond the IASC corpus
2. Real-world deployment monitoring: Implement a longitudinal study tracking model performance and bias emergence in actual humanitarian response scenarios over 6-12 months
3. Extended bias dimension analysis: Expand the bias evaluation framework to include additional protected characteristics (age, disability, ethnicity) and intersectional bias patterns using more granular counterfactual generation techniques
