# Image-based Indian Sign Language Recognition: A Practical Review using Deep Neural Networks

## Quick Facts
- arXiv ID: 2304.14710
- Source URL: https://arxiv.org/abs/2304.14710
- Reference count: 9
- Key outcome: Developed an ISL recognition system achieving 99% accuracy using AlexNet, with a dataset of 36 ISL characters (0-9, A-Z) containing 1,200 images per character

## Executive Summary
This paper addresses the communication gap between hearing and deaf communities in India by developing a real-time Indian Sign Language (ISL) recognition system. The authors collected a comprehensive dataset of 36 ISL characters with 1,200 images per character, capturing various hand orientations for both left and right hands. Through extensive experimentation with multiple deep learning architectures including CNN, AlexNet, InceptionV3, ResNet-50, VGG-16, and CNN-GAN hybrid models, they achieved 99% recognition accuracy. AlexNet emerged as the best-performing model with 98.91% training accuracy and 99.6% validation accuracy, demonstrating its effectiveness for ISL recognition tasks.

## Method Summary
The authors collected the ISL-Character dataset containing 36 ISL characters (0-9, A-Z) with 1,200 images per character, capturing various hand orientations for both left and right hands. The preprocessing pipeline included resizing, grayscale conversion, Gaussian blurring to remove noise, median filtering to eliminate salt and pepper noise, and hand segmentation using thresholding and edge detection. Multiple deep learning architectures were trained on this preprocessed dataset, including traditional CNN, AlexNet, InceptionV3, ResNet-50, VGG-16, and a CNN-GAN hybrid. The models were compared based on training and validation accuracy to identify the best-performing architecture for ISL recognition.

## Key Results
- AlexNet achieved the highest performance with 98.91% training accuracy and 99.6% validation accuracy
- The system demonstrated 99% overall recognition accuracy for the best model
- Multiple hand orientations and both left/right hand images in the dataset contributed to robust performance
- Preprocessing techniques including Gaussian blurring and median filtering effectively reduced noise while preserving gesture features

## Architecture Onboarding

- Component map:
  Image capture -> Resize -> Grayscale -> Gaussian Blur -> Median Filter -> Thresholding -> Edge Detection -> CNN layers -> Classification -> Text output

- Critical path:
  Image capture → Preprocessing pipeline → Feature extraction → Classification → Text output
  The preprocessing stage is critical as errors here propagate through the entire pipeline.

- Design tradeoffs:
  - Dataset size vs. computation time: Larger datasets improve accuracy but increase training time
  - Model complexity vs. real-time performance: Deeper models like ResNet-50 achieve higher accuracy but require more computation
  - Preprocessing intensity vs. robustness: Aggressive preprocessing improves noise handling but may remove subtle gesture features

- Failure signatures:
  - Low accuracy despite high training accuracy: Overfitting - reduce model complexity or augment dataset
  - Inconsistent predictions: Preprocessing errors - check image quality and segmentation parameters
  - Slow inference: Model too complex for deployment environment - consider lighter architectures
