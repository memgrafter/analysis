# Explaining Large Language Model-Based Neural Semantic Parsers (Student Abstract)

## Quick Facts
- arXiv ID: 2301.13820
- Source URL: https://arxiv.org/abs/2301.13820
- Reference count: 1
- Primary result: LERG S and Kernel SHAP achieve the highest faithfulness in explaining LLM-based semantic parsers for text-to-SQL task

## Executive Summary
This paper investigates how to explain large language model-based neural semantic parsers, specifically focusing on the text-to-SQL task using UnifiedSKG. The authors compare multiple local explanation methods (LIME, Shapley value, Kernel SHAP, LERG, and attention-based) by evaluating their faithfulness through necessity and sufficiency metrics. Their key finding is that Shapley value-based methods, particularly LERG S and Kernel SHAP, achieve the highest faithfulness, while attention-based explanations perform better than LIME and LERG L. The study also includes qualitative analysis showing that explanations are generally plausible across different prediction types and difficulty levels.

## Method Summary
The study compares five local explanation methods on UnifiedSKG, a T5 encoder-decoder architecture for text-to-SQL parsing. The methods include LIME (perturbation-based), Shapley value and Kernel SHAP (approximation-based), LERG L/S (sampling-based), and attention-based explanations using cross-attention weights. Faithfulness is evaluated using Necessity (measuring perplexity change when top-K% features are removed) and Sufficiency (measuring perplexity when keeping only top-K% features) metrics. The UnifiedSKG model (T5 base prefix spider with cell value version) is trained on the Spider dataset, and explanations are generated for predictions across different difficulty levels and correctness categories.

## Key Results
- LERG S and Kernel SHAP achieve the highest faithfulness scores, with Shapley value-based methods outperforming others overall
- Attention-based explanations are more faithful than LIME and LERG L
- Explanations are generally plausible across correct/incorrect predictions, different difficulty levels, and compositional generalization scenarios
- Computational costs of perturbation-based methods remain a significant challenge for practical deployment

## Why This Works (Mechanism)

### Mechanism 1
- Claim: LERG S and Kernel SHAP achieve the highest faithfulness by effectively capturing feature importance through perturbation-based or model-based approximation methods
- Mechanism: Both methods approximate Shapley values, measuring average marginal contribution of each feature to prediction score
- Core assumption: Prediction score is decomposable into individual feature contributions
- Evidence anchors: Abstract states these methods have best performance per both sufficiency and necessity metrics
- Break condition: Fails if predictions are highly non-linear or involve strong feature interactions

### Mechanism 2
- Claim: Attention-based explanations are more faithful than LIME and LERG L because they directly utilize model's internal attention weights
- Mechanism: Averages last layer of multi-headed cross-attention weights to calculate feature attribution
- Core assumption: Attention weights correlate with feature importance
- Evidence anchors: Abstract states attention-based explanations are more faithful than LIME and LERG L
- Break condition: Fails if attention weights poorly align with true feature importance

### Mechanism 3
- Claim: Plausibility across prediction types indicates explanations capture genuine model behavior
- Mechanism: Manual examination of 20 examples across four hardness levels and correct/incorrect predictions
- Core assumption: Human intuition about feature importance aligns with model's decision-making
- Evidence anchors: Abstract states explanations are generally plausible across different categories
- Break condition: Fails if human intuition differs significantly from model's learned representations

## Foundational Learning

- Concept: Shapley value theory and marginal contribution calculation
  - Why needed here: Understanding how feature importance is quantified through marginal contributions is crucial for interpreting LERG S and Kernel SHAP results
  - Quick check question: Can you explain why Shapley values sum to the total prediction score across all features?

- Concept: Perturbation-based vs. model-based explanation methods
  - Why needed here: Different explanation methods have different computational costs and faithfulness properties that affect their practical utility
  - Quick check question: What are the trade-offs between perturbation-based methods that require multiple model inferences versus attention-based methods that use existing model internals?

- Concept: Semantic parsing task structure and text-to-SQL formulation
  - Why needed here: Understanding how natural language questions map to SQL queries helps interpret why certain features are important in explanations
  - Quick check question: How does the UnifiedSKG model use database schema information during SQL generation, and why would this affect feature importance attribution?

## Architecture Onboarding

- Component map: Input question and schema → T5 encoder → cross-attention layers → decoder state → SQL token generation → output SQL query
- Critical path: Natural language questions and database schema processed by encoder, connected through cross-attention layers to decoder generating SQL tokens
- Design tradeoffs: Tension between explanation quality (perturbation-based methods) and computational cost (attention-based methods)
- Failure signatures: Poor explanation faithfulness when removing top-K% features (high necessity score drop) or keeping only top-K% features (low sufficiency score)
- First 3 experiments:
  1. Run LERG S and Kernel SHAP on small example set to verify superior faithfulness scores
  2. Compare attention-based explanations against ground truth feature importance through manual examination
  3. Test explanation plausibility across different SQL complexity levels (easy, medium, hard, extra hard)

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can local explanation methods be made computationally efficient without sacrificing faithfulness?
- Basis in paper: Computational costs are identified as a key challenge
- Why unresolved: Current perturbation-based methods are computationally expensive while faster methods are less faithful
- What evidence would resolve it: A new method achieving similar faithfulness to Shapley value-based methods while maintaining attention-based efficiency

### Open Question 2
- Question: How do features interact with each other in LLM-based semantic parsers?
- Basis in paper: Feature interaction is identified as a key challenge
- Why unresolved: Current methods focus on individual feature importance without capturing interactions
- What evidence would resolve it: An explanation method revealing feature interactions and demonstrating improved understanding

### Open Question 3
- Question: How can explanations be presented in a way that is concise and user-friendly while maintaining interpretability?
- Basis in paper: Explanation for user understanding is identified as a challenge
- Why unresolved: No established method for distilling complex explanation information into user-friendly formats
- What evidence would resolve it: User studies comparing different explanation presentation formats

### Open Question 4
- Question: How can local explanation results be used to improve compositional generalization capability?
- Basis in paper: Explanation for debugging is identified as a challenge, specifically mentioning compositional generalization
- Why unresolved: While explanations are plausible for compositional generalization, no demonstration of using them to improve performance
- What evidence would resolve it: Systematic study showing how insights from local explanations can improve compositional generalization

## Limitations
- Evaluation relies entirely on faithfulness metrics rather than human-grounded measures of explanation utility
- Computational cost of perturbation-based methods may be prohibitive for real-world deployment
- Plausibility assessment relies on manual evaluation of only 20 examples, which may not be representative

## Confidence
**High confidence**: The faithfulness comparison between explanation methods is well-supported by quantitative metrics and reproducible methodology
**Medium confidence**: The qualitative plausibility assessment is reasonable but limited by small sample size and subjective evaluation criteria
**Low confidence**: The generalizability of findings to other LLM-based semantic parsing tasks beyond text-to-SQL remains unproven

## Next Checks
1. **Scalability validation**: Test whether LERG S and Kernel SHAP maintain faithfulness advantages when scaled to larger models while measuring actual computational costs
2. **Cross-task generalization**: Apply same explanation methods and evaluation framework to non-text-to-SQL semantic parsing tasks to determine if Shapley value-based methods consistently outperform alternatives
3. **User-centered evaluation**: Conduct human study where practitioners attempt to debug model errors using different explanation methods, measuring success rates and time to resolution
