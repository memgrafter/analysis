# HIT-SCIR at MMNLU-22: Consistency Regularization for Multilingual Spoken Language Understanding

## Quick Facts
- arXiv ID: 2301.02010
- Source URL: https://arxiv.org/abs/2301.02010
- Reference count: 15
- Achieved first place in MMNLU-22 competition with 49.65% exact match accuracy

## Executive Summary
This paper introduces a consistency regularization approach for multilingual spoken language understanding (SLU) that leverages hybrid data augmentation techniques. The method enforces consistency between model predictions on original examples and their semantically equivalent augmentations, including machine translation and subword sampling. Experiments on the MASSIVE dataset demonstrate significant improvements in both intent detection and slot filling tasks, achieving first place in the MMNLU-22 competition under the full-dataset setting.

## Method Summary
The approach combines consistency regularization with hybrid data augmentation to improve multilingual SLU performance. The method applies machine translation and subword sampling to create semantically equivalent augmentations of training examples, then enforces consistency between model predictions on original and augmented inputs. This regularization can be applied to both encoder-only and Text-to-Text models, making it flexible for different model architectures. The framework shows consistent improvements in zero-shot and full-dataset settings on the MASSIVE benchmark.

## Key Results
- Achieved first place in MMNLU-22 competition with 49.65% exact match accuracy
- Consistent improvements in both intent detection and slot filling tasks
- Ablation studies confirm importance of both subword sampling and consistency regularization components

## Why This Works (Mechanism)
The method works by leveraging semantic consistency across multiple augmented versions of the same utterance. Machine translation creates cross-lingual variations while preserving meaning, and subword sampling introduces controlled perturbations that improve model robustness. By enforcing consistency between predictions on these augmented inputs and the original, the model learns more robust representations that generalize better across languages and domains. This dual-augmentation approach addresses both linguistic diversity and model sensitivity to input variations.

## Architecture Onboarding

Component map: Input -> Augmentation Pipeline -> Model Backbone -> Consistency Loss -> Output

Critical path: Original utterance → Model → Prediction → Consistency Loss ← Augmented utterance → Model

Design tradeoffs: The method trades additional computation during training (for augmentation and consistency loss) for improved generalization and robustness. The choice between encoder-only and Text-to-Text models affects implementation complexity and training efficiency.

Failure signatures: Performance degradation may occur when augmentations significantly alter semantic content, when consistency regularization is too strong causing oversmoothing, or when model capacity is insufficient to maintain consistency across diverse augmentations.

First experiments: 1) Validate individual augmentation techniques on baseline model, 2) Test consistency regularization strength sensitivity, 3) Compare encoder-only vs Text-to-Text model performance
