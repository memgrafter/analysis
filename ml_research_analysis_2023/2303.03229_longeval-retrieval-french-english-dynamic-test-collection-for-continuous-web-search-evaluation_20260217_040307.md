# LongEval-Retrieval: French-English Dynamic Test Collection for Continuous Web Search Evaluation
## Quick Facts
- arXiv ID: 2303.03229
- Source URL: https://arxiv.org/abs/2303.03229
- Reference count: 29
- Presents a Web document retrieval benchmark for continuous evaluation of information retrieval systems

## Executive Summary
LongEval-Retrieval is a dynamic test collection designed for continuous evaluation of information retrieval systems. The benchmark comprises successive sub-collections representing the state of an information system at different time steps, enabling temporal analysis of system performance. Built from Qwant search engine data, it includes queries, documents, and click-based relevance assessments initially created in French and then translated to English, providing a cross-language evaluation framework.

The collection aims to study temporal persistence in IR systems and will serve as the test collection for the Longitudinal Evaluation of Model Performance Track (LongEval) at CLEF 2023. The evaluation uses nDCG and Relative nDCG Drop measures to assess system performance over time, addressing the need for continuous evaluation methodologies in the rapidly evolving landscape of Web search.

## Method Summary
The LongEval-Retrieval benchmark is constructed from Qwant search engine data, creating a dynamic test collection with successive sub-collections representing different time points. The data includes queries, Web documents, and soft relevance assessments derived from click models. The collection is initially built in French and then translated to English, creating a "mirror" collection for cross-language retrieval evaluation. The creation process involves collecting search logs, extracting queries and clicked documents, and applying click models to generate relevance assessments. Baseline runs are provided along with analysis of temporal performance patterns across the collection's time span.

## Key Results
- Dynamic test collection enables continuous evaluation of IR systems across temporal snapshots
- Cross-language collection provides French and English "mirror" datasets for comparative analysis
- Temporal analysis reveals patterns in system performance persistence over time
- Collection serves as test bed for CLEF 2023 LongEval track using nDCG and Relative nDCG Drop measures

## Why This Works (Mechanism)
The benchmark's effectiveness stems from its dynamic nature, capturing the evolution of search systems over time through successive sub-collections. By using click data from a privacy-preserving search engine (Qwant), it provides realistic relevance assessments while maintaining user privacy. The cross-language design enables comparative analysis between French and English search behaviors and system performance. The temporal dimension allows researchers to study how IR systems maintain performance consistency over extended periods, addressing a critical gap in traditional static evaluation methodologies.

## Foundational Learning
1. **Dynamic test collections** - Why needed: Traditional static collections cannot capture temporal evolution of search systems. Quick check: Can the collection be expanded with new time slices without invalidating existing data.
2. **Click model-based relevance assessment** - Why needed: Provides scalable relevance judgments without manual annotation. Quick check: Does click distribution correlate with manual relevance assessments on sampled queries.
3. **Cross-language IR evaluation** - Why needed: Enables comparative analysis across linguistic and cultural contexts. Quick check: Are query-document relationships preserved after translation between French and English collections.

## Architecture Onboarding
**Component Map:** Query Collection -> Document Collection -> Click Data -> Click Model -> Relevance Judgments -> Temporal Sub-collections -> Baseline Runs -> Performance Analysis
**Critical Path:** Query collection and click data acquisition → click model application → relevance judgment generation → temporal organization → baseline run execution → performance analysis
**Design Tradeoffs:** Click-based judgments offer scalability but may introduce position bias; cross-language design enables broader applicability but raises translation fidelity concerns
**Failure Signatures:** Poor temporal persistence may indicate unstable ranking algorithms; significant cross-language performance gaps may reveal translation artifacts; click model biases may manifest as systematic relevance assessment errors
**First Experiments:** 1) Run baseline systems on initial time slice to establish performance baseline, 2) Compare system performance across consecutive time slices to measure temporal drift, 3) Evaluate cross-language consistency by running identical systems on French and English collections

## Limitations
- Click-based relevance assessments may introduce position bias and user behavior artifacts
- Single-engine dependency (Qwant) limits generalizability to other search systems
- 12-month analysis period may be insufficient for robust temporal persistence conclusions
- Cross-language comparability affected by potential translation artifacts and cultural differences

## Confidence
- Representativeness of click-based judgments: Medium
- Temporal persistence analysis: Medium (limited to 12-month period)
- Cross-language comparability: Low (potential translation and cultural artifacts)

## Next Checks
1. Conduct manual relevance assessment study on sample queries to validate click-based judgments and identify systematic biases
2. Perform inter-engine comparison by testing baseline runs across multiple search engines to assess collection generalizability
3. Extend temporal analysis beyond initial 12-month period to verify long-term patterns in system performance persistence
