# Long-form analogies generated by chatGPT lack human-like psycholinguistic properties

## Quick Facts
- arXiv ID: 2306.04537
- Source URL: https://arxiv.org/abs/2306.04537
- Reference count: 15
- The study demonstrates that ChatGPT-generated analogies differ significantly from human-generated ones in psycholinguistic properties, achieving 89% classification accuracy using 78 Coh-metrix features.

## Executive Summary
This study investigates whether long-form analogies generated by ChatGPT exhibit human-like psycholinguistic properties compared to those created by human subjects. Using 78 features from Coh-metrix that analyze text cohesion, language, and readability, the researchers performed supervised classification to distinguish between ChatGPT and human-generated analogies. The results show significant differences in descriptive linguistic properties (word choice, sentence length) and underlying psycholinguistic properties (narrativity, cohesion, syntax). The study achieved high classification accuracy and identified 11 key features that contribute most to distinguishing between human and machine-generated text, demonstrating that psycholinguistic features can effectively identify subtle differences between human and computationally generated text.

## Method Summary
The study used 78 linguistic features extracted from Coh-metrix to analyze analogies about biochemical processes (glycolysis, enzyme kinetics). The dataset included 366 ChatGPT-generated sentences and 735 human-generated sentences. Features were standardized to zero mean and unit variance, with low-variance features removed. A linear ridge classifier was trained using 10-fold stratified cross-validation. Hierarchical clustering with Ward linkage was applied to Spearman correlations of features to identify uncorrelated groups. Classification performance was evaluated using balanced accuracy, weighted precision, and weighted recall. The authors also tested classification without length-based features to control for potential bias.

## Key Results
- ChatGPT analogies show significantly different psycholinguistic properties compared to human analogies in word choice, sentence length, narrativity, and cohesion
- Classification model achieved 89% balanced accuracy using 78 Coh-metrix features to distinguish between human and ChatGPT analogies
- 11 key features were identified through hierarchical clustering that maintain high classification performance while providing interpretability

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Psychometric feature engineering outperforms generic embedding clustering for LLM vs. human text classification.
- **Mechanism:** The study replaces opaque vector similarity with 78 engineered psycholinguistic features from Coh-Metrix. These capture fine-grained properties like syntactic simplicity, cohesion, and narrativity. Hierarchical clustering on the Spearman correlation matrix isolates uncorrelated feature groups, which are then fed to a ridge classifier. This explicit feature selection yields 89% balanced accuracy versus typical embedding-only methods that are harder to interpret.
- **Core assumption:** Psychometric features remain stable across repeated generations from the same model; the features truly capture language competence rather than superficial style.
- **Evidence anchors:**
  - [abstract] "We perform a supervised classification analysis using 78 features extracted from Coh-metrix that analyze text cohesion, language, and readability... Results illustrate high performance for classifying student-generated and chatGPT-generated analogies."
  - [section] "We employed a machine learning classifier to distinguish between ChatGPT text and human-generated text... we employ psychologically motivated 'engineered' features to describe text..."
- **Break condition:** If new LLM versions or prompts change the feature distributions enough that the selected psycholinguistic markers no longer differentiate human from machine output, classification performance would drop below acceptable thresholds.

### Mechanism 2
- **Claim:** Excluding sentence length and word count still preserves high classification accuracy.
- **Mechanism:** The authors explicitly test models without length-related features (total word count, sentence length, SD of sentence length). They find comparable balanced accuracy (~88%) and high precision/recall, indicating that psycholinguistic signals (e.g., noun phrase density, narrativity) are sufficient discriminators independent of surface length cues.
- **Core assumption:** Length-based cues are not the sole source of separability; other linguistic dimensions are equally diagnostic.
- **Evidence anchors:**
  - [section] "Fitting a classification algorithm on these two samples would allow the algorithm to capitalize on analogy length... Thus, we perform our analysis on individual sentences to control for this."
  - [section] "Classification accuracy does not depend on word count or sentence length."
- **Break condition:** If future data sets have human and LLM outputs with nearly identical length distributions, the classifier would lose this compensatory signal and accuracy would decline.

### Mechanism 3
- **Claim:** Hierarchical clustering with Ward linkage effectively reduces multicollinearity among psycholinguistic features.
- **Mechanism:** Coh-Metrix features are highly correlated. By computing a Spearman correlation matrix, converting to a distance matrix, and applying hierarchical clustering with the Ward criterion, the authors form flat clusters (max distance 1.25) that group redundant features. Selecting representatives from the top half of the dendrogram yields compact, non-redundant feature sets (e.g., 11 features) while maintaining high classification performance.
- **Core assumption:** The top half of the dendrogram captures the most discriminative feature groupings; the Ward criterion produces clusters that minimize within-cluster variance.
- **Evidence anchors:**
  - [section] "Because many of the features available in Coh-Metrix are highly correlated, we use a hierarchical clustering method... We use the Ward criterion, which minimizes the sum of squared errors between the clusters..."
  - [section] "We identified 11 features using this procedure... Performance on this model is reduced compared to the full model... but this model still illustrates reasonably high levels of classification performance."
- **Break condition:** If feature correlations shift dramatically (e.g., with a new LLM), the dendrogram structure would change, invalidating the chosen cutoff and requiring recomputation of clusters.

## Foundational Learning

- **Psycholinguistic feature engineering**
  - Why needed here: The study hinges on Coh-Metrix features (cohesion, readability, narrativity) as discriminative signals; understanding their construction is critical to replicating or extending the method.
  - Quick check question: What are the six text easability z-score dimensions Coh-Metrix provides, and how do they differ from simple readability formulas?

- **Supervised vs. unsupervised classification in text analytics**
  - Why needed here: The authors use ridge regression with stratified cross-validation; knowing when and why to choose this over clustering methods is key for similar classification tasks.
  - Quick check question: Why might stratified 10-fold cross-validation be preferable to a simple random split in this analogy classification scenario?

- **Hierarchical clustering with Ward linkage**
  - Why needed here: The feature selection relies on Ward's method to group correlated features; understanding this linkage criterion is essential to reproduce the clustering step.
  - Quick check question: How does Ward linkage differ from average or complete linkage, and why is it suitable for minimizing within-cluster variance in psycholinguistic feature sets?

## Architecture Onboarding

- **Component map:** Data ingestion -> Coh-Metrix feature extraction -> Feature filtering (variance threshold) -> Standardization (z-score) -> Length-based feature removal (optional) -> Spearman correlation -> Hierarchical clustering (Ward) -> Flat cluster selection -> Ridge classifier training -> Stratified 10-fold CV -> Evaluation metrics
- **Critical path:** Feature extraction -> Clustering -> Classifier training. Any delay here bottlenecks downstream performance evaluation.
- **Design tradeoffs:** Using engineered psycholinguistic features increases interpretability but may miss subtle embeddings-based patterns; excluding length-based features reduces bias but could discard useful discriminative cues.
- **Failure signatures:** Sudden drop in balanced accuracy, high variance across CV folds, or correlation matrix with near-zero off-diagonals indicating loss of redundancy for clustering.
- **First 3 experiments:**
  1. Re-run feature extraction and clustering on a small sample to verify that the dendrogram structure matches expectations (features in top half correspond to narrativity, cohesion, etc.).
  2. Train a baseline ridge classifier on all 78 features without clustering to establish upper-bound performance.
  3. Systematically remove different length-related features (e.g., only word count, only sentence length) to quantify their individual impact on accuracy.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Do the psycholinguistic differences between ChatGPT and human-generated analogies persist across different domains beyond biochemistry?
- Basis in paper: [explicit] The authors note that "we have not yet conducted domain-specific content analyses that may prove diagnostic" and that "given the broad domain content resources available to chatGPT, we may find that human writers draw on less content."
- Why unresolved: The study only examined analogies about biochemical concepts, and the authors acknowledge that domain-specific content analyses have not been conducted.
- What evidence would resolve it: Comparative analysis of analogies generated by ChatGPT and humans across multiple domains (e.g., physics, literature, history) using the same psycholinguistic metrics.

### Open Question 2
- Question: What psychological processes cause humans to select different function words and exhibit more variance in word choice compared to ChatGPT?
- Basis in paper: [explicit] The authors state "we have not yet identified the psychological processes that result in the documented differences" regarding word choice and variance.
- Why unresolved: The study identifies differences in word choice but does not investigate the underlying cognitive or linguistic mechanisms.
- What evidence would resolve it: Cognitive psychology experiments examining the decision-making processes behind word selection in humans versus AI, potentially using think-aloud protocols or reaction time studies.

### Open Question 3
- Question: How would specific stylistic instructions (e.g., age, educational level of author) affect the psycholinguistic properties of ChatGPT-generated analogies?
- Basis in paper: [explicit] The authors note they "did not give chatGPT any specific stylistic instructions" such as "the age or educational level of the purported author."
- Why unresolved: The study used generic prompts without stylistic constraints, leaving open the question of how ChatGPT's output might change with explicit stylistic guidelines.
- What evidence would resolve it: Comparative analysis of ChatGPT-generated analogies using prompts with different stylistic instructions (e.g., "explain this to a 10-year-old," "as a college professor would") versus generic prompts.

## Limitations

- The study relies on analogies from a single domain (biochemistry), limiting generalizability to other writing tasks or subjects
- ChatGPT was prompted with simplified instructions compared to human subjects, potentially introducing confounding factors
- Classification performance depends on the stability of Coh-metrix features across different LLM versions and prompts

## Confidence

- **High confidence:** The classification framework using psycholinguistic features is methodologically sound, with appropriate cross-validation and feature selection procedures clearly documented.
- **Medium confidence:** The interpretation that ChatGPT analogies lack human-like psycholinguistic properties is supported by the data, but could be influenced by prompt differences and domain specificity.
- **Medium confidence:** The identification of 11 key features is based on a reasonable clustering approach, but the stability of these features across different datasets remains untested.
