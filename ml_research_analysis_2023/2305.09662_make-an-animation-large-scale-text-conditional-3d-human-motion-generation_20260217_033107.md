# Make-An-Animation: Large-Scale Text-conditional 3D Human Motion Generation

## Quick Facts
- arXiv ID: 2305.09662
- Source URL: https://arxiv.org/abs/2305.09662
- Reference count: 40
- Primary result: State-of-the-art text-to-motion generation with superior human evaluation scores on realism and text alignment

## Executive Summary
Make-An-Animation is a text-conditioned human motion generation model that achieves state-of-the-art performance by leveraging large-scale pretraining on pseudo-poses extracted from image-text datasets. The model uses a two-stage training approach: first pretraining on 35M (text, static pose) pairs to learn diverse human poses and text-pose alignment, then fine-tuning on motion capture data with temporal convolution layers added for motion generation. Human evaluation shows superior performance in both motion realism and alignment with input text compared to prior works.

## Method Summary
The method employs a two-stage training process using a U-Net diffusion architecture. First, the model is trained on a large-scale dataset of 35M (text, static pseudo-pose) pairs extracted from image-text datasets using keypoint detection and SMPL regression. The U-Net processes static poses conditioned on text embeddings from a T5-XXL encoder. In the second stage, the model is fine-tuned on motion capture data (AMASS and GTA-Human) by adding 1D temporal convolution and attention layers to handle the temporal dimension. Classifier-free guidance is used during training, with null text conditioning applied 10% of the time.

## Key Results
- Superior human evaluation scores for motion realism and text alignment compared to prior text-to-motion generation methods
- Effective generalization to diverse, in-the-wild prompts through large-scale pseudo-pose pretraining
- Achieves coherent motion generation using U-Net architecture with temporal convolutions

- Core assumption: Pseudo-poses extracted from images via keypoint detection and SMPL regression are sufficiently accurate and diverse to train a generative model

## Architecture Onboarding

- Component map: Text encoder (T5-XXL) → Text embeddings → Static pose diffusion U-Net (TPP pretraining) → Temporal convolution and attention layers → SMPL body parameterization output

- Critical path: Text → Embeddings → Static pose U-Net → Temporal layers → Motion output

- Design tradeoffs:
  - Pretraining on large-scale pseudo-pose data vs. limited motion capture data
  - U-Net parallel processing vs. autoregressive approaches
  - Fixed frame length vs. variable length motion generation

- Failure signatures:
  - Poor text alignment: Check text embedding quality and cross-attention
  - Unrealistic poses: Check pseudo-pose quality in pretraining data
  - Incoherent motion: Check temporal convolution/receptive field settings

- First 3 experiments:
  1. Generate static poses from text to verify text-to-pose alignment before adding temporal layers
  2. Generate short motion clips (3-5 frames) to test temporal coherence
  3. Compare generations with and without classifier-free guidance to find optimal guidance scale

## Limitations

- Pseudo-pose quality uncertainty: The paper relies on Detectron2 and PyMAF-X for pseudo-pose extraction without quantitative evaluation of accuracy or diversity, which could introduce harmful biases
- Human evaluation methodology gaps: Lacks detailed methodology including sample size, evaluator demographics, and inter-rater reliability measures
- Limited ablation studies: Combines multiple innovations without isolating which components contribute most to performance gains
