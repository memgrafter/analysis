# Representation Sparsification with Hybrid Thresholding for Fast SPLADE-based Document Retrieval

## Quick Facts
- **arXiv ID:** 2306.11293
- **Source URL:** https://arxiv.org/abs/2306.11293
- **Reference count:** 40
- **Primary result:** Achieves up to 3.6x faster retrieval with minimal MRR@10 degradation (0.28%–0.6%) using learnable hybrid hard and soft thresholding

## Executive Summary
This paper introduces a learnable hybrid hard and soft thresholding scheme to increase the sparsity of learned sparse document representations in SPLADE-based retrieval. The approach applies soft thresholding to query tokens and a sigmoid-based approximate hard thresholding to document tokens during training, while using hard thresholding during indexing to minimize approximation errors. The method jointly learns thresholds to balance relevance and retrieval speed. Experimental results on MS MARCO and BEIR datasets show that the proposed hybrid thresholding achieves up to 3.6x faster retrieval with minimal MRR@10 degradation (0.28%–0.6%), outperforming static pruning baselines.

## Method Summary
The method extends SPLADE by adding a hybrid thresholding layer that applies different thresholding strategies to queries and documents during training. For queries, soft thresholding zeros out low-weight tokens using a soft threshold parameter. For documents, sigmoid-based approximate hard thresholding uses a learnable slope parameter K to smoothly approximate hard thresholding during training. During indexing, hard thresholding is applied directly to document tokens using the learned threshold. The model is trained with an extended loss function that includes document and query token regularization terms and a threshold penalty term, guiding the model to learn thresholds that balance relevance and sparsity.

## Key Results
- Achieves up to 3.6x faster retrieval on MS MARCO and BEIR datasets
- Maintains minimal MRR@10 degradation of 0.28%–0.6% compared to non-thresholded SPLADE
- Outperforms static pruning baselines while reducing index size and non-zero token weights

## Architecture Onboarding

- **Component map:** SPLADE model -> Hybrid thresholding layer -> Index generation module -> Retrieval engine
- **Critical path:** Train SPLADE model with hybrid thresholding layer and extended loss function -> Generate inverted index using learned document threshold -> Perform top-k retrieval using the inverted index and query threshold
- **Design tradeoffs:**
  - Threshold aggressiveness vs. retrieval effectiveness: More aggressive thresholds lead to faster retrieval but may hurt relevance.
  - Sigmoid slope parameter 𝐾 vs. training stability: Larger 𝐾 values minimize approximation error but may cause unstable training.
  - Joint training of document and query thresholds vs. separate training: Joint training allows for better balance between relevance and sparsity but may be more complex to implement.
- **Failure signatures:**
  - Large MRR degradation: The learned thresholds are too aggressive, pruning too many relevant tokens.
  - Training instability or divergence: The sigmoid slope parameter 𝐾 is too large, causing large gradient updates.
  - Slow retrieval speed: The learned thresholds are not aggressive enough, leaving too many non-zero token weights in the index.
- **First 3 experiments:**
  1. Train SPLADE model with hybrid thresholding and evaluate MRR@10 on a small validation set to check for training stability and initial effectiveness.
  2. Generate inverted index using learned document threshold and measure retrieval speed and MRR@10 on a held-out test set to evaluate the impact of thresholding on both speed and effectiveness.
  3. Vary the sigmoid slope parameter 𝐾 and the threshold penalty weight in the loss function to find the best balance between retrieval speed and effectiveness.

## Limitations

- The paper does not directly measure the index approximation error gap between sigmoid-based approximate hard thresholding during training and hard thresholding during indexing.
- The specific impact of each regularization component in the extended loss function is not isolated through ablation studies.
- The paper does not explore the performance of hybrid thresholding on substantially larger vocabulary sizes or in multi-stage ranking systems.

## Confidence

- **High confidence:** The experimental results showing improved retrieval speed with minimal MRR@10 degradation are well-supported by the MS MARCO and BEIR dataset results presented in the paper.
- **Medium confidence:** The mechanism of using sigmoid-based approximate hard thresholding to minimize index approximation error is theoretically sound but lacks direct experimental validation of the approximation gap itself.
- **Medium confidence:** The joint training approach with threshold regularization effectively balances relevance and sparsity, as evidenced by the improved performance over static pruning baselines, though the specific impact of each regularization component is not isolated.
