# DMDD: A Large-Scale Dataset for Dataset Mentions Detection

## Quick Facts
- arXiv ID: 2305.11779
- Source URL: https://arxiv.org/abs/2305.11779
- Reference count: 9
- Key outcome: Introduced DMDD corpus with 31,219 articles containing 449,000+ weakly annotated dataset mentions and 450 manually annotated articles for evaluation, establishing baseline F1 scores of 0.75 (sentence-level) and 0.73 (section-level) for dataset mention detection

## Executive Summary
This paper introduces DMDD (Dataset Mentions Detection Dataset), the largest publicly available corpus for dataset mention detection in scientific literature. The corpus contains 31,219 articles with over 449,000 weakly annotated dataset mentions created through distant supervision by matching Papers with Code dataset mentions with in-text spans, plus 450 manually annotated articles for evaluation. The authors establish baseline performance using BERT/SciBERT and LongFormer models, achieving F1 scores of 0.75 on sentence-level inputs and 0.73 on section-level inputs. They also demonstrate that fine-tuning a model pre-trained on DMDD with as few as 100 human-annotated examples can match the performance of a model trained solely on human annotations, significantly reducing annotation costs.

## Method Summary
The authors created DMDD using distant supervision by matching dataset mentions from Papers with Code with in-text spans in scientific articles, then entity-linked these mentions to dataset definition websites. The corpus contains 31,219 scientific articles with 449,000+ weakly annotated dataset mentions. For baseline evaluation, they fine-tuned BERT, SciBERT, and LongFormer models on the preprocessed corpus with 80% positive and 20% negative sequences. They evaluated performance on sentence-level, section-level, and 512-token-level inputs using exact match F1 score, precision, and recall metrics.

## Key Results
- Established baseline F1 scores of 0.75 for sentence-level and 0.73 for section-level inputs using BERT/SciBERT and LongFormer models
- Demonstrated that pre-training on DMDD and fine-tuning with just 100 human-annotated examples achieves comparable performance to models trained solely on human annotations
- Created the largest publicly available corpus for dataset mention detection with 31,219 articles and 449,000+ weakly annotated mentions

## Why This Works (Mechanism)
The distant supervision approach leverages existing dataset knowledge from Papers with Code to automatically generate large-scale weak annotations, enabling the creation of a corpus much larger than manually annotated alternatives. The entity linking to dataset definition websites provides additional context that improves model generalization. The use of transformer-based models like BERT and LongFormer allows capturing complex contextual relationships in scientific text, while the combination of weak and strong supervision reduces annotation costs without sacrificing performance.

## Foundational Learning

**Distant supervision**: Using existing knowledge bases to automatically generate weak labels for training data
- Why needed: Manual annotation of dataset mentions is extremely time-consuming and expensive
- Quick check: Verify that generated weak labels have reasonable precision (>80%) on a sampled validation set

**Entity linking**: Connecting mentions in text to canonical representations in knowledge bases
- Why needed: Helps models understand which specific datasets are referenced when names are ambiguous
- Quick check: Measure recall@K for entity linking predictions on a held-out test set

**BIO tagging format**: Converting span annotations to Begin-Inside-Outside format for sequence labeling
- Why needed: Standard format for NER-style tasks that transformer models can process
- Quick check: Ensure BIO conversion preserves all annotation boundaries without overlap

## Architecture Onboarding

**Component map**: Raw text articles -> spaCy preprocessing -> BIO conversion -> BERT/SciBERT/LongFormer model -> F1/precision/recall evaluation

**Critical path**: Data preprocessing (spaCy + BIO conversion) -> Model fine-tuning (BERT variants) -> Evaluation (exact match metrics)

**Design tradeoffs**: Distant supervision enables large corpus creation but introduces noise; weak-strong supervision combination reduces costs but requires careful hyperparameter tuning; transformer models capture context well but struggle with long sequences and entity disambiguation

**Failure signatures**: Low precision/high recall indicates overly permissive entity extraction; poor performance on unseen entities suggests insufficient generalization; degraded results on long sequences indicate context window limitations

## Limitations
- Distant supervision from Papers with Code may introduce noise since mentions are only weakly annotated and entity linking targets may not always match intended datasets in full-text context
- Evaluation focuses primarily on exact match F1 scores, which may not capture complexity of real-world dataset mention detection where partial matches or coreference resolution are important
- Annotation cost reduction claims are based on limited human annotation budgets (only 100 examples), which may not represent more challenging real-world scenarios

## Confidence
- **High**: Dataset size and construction methodology are directly verifiable from the corpus
- **Medium**: Baseline model performance metrics, as implementation details are partially specified
- **Medium**: Annotation cost reduction claims, as evaluation uses limited human annotation budgets
