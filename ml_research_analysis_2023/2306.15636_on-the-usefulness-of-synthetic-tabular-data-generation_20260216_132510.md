# On the Usefulness of Synthetic Tabular Data Generation

## Quick Facts
- arXiv ID: 2306.15636
- Source URL: https://arxiv.org/abs/2306.15636

## Executive Summary
This paper investigates the usefulness of synthetic tabular data generation for machine learning tasks across four use cases: data sharing, data summarization, data augmentation, and class balancing. The study evaluates the statistical quality of synthetic samples for downstream learning tasks and compares the predictive performance of models trained on synthetic data to those trained on real data. Experiments show that while real data consistently outperforms synthetic data, the performance gap decreases as generative models are trained on more data points. The research also examines whether synthetic data can efficiently compress statistical information from training data, potentially allowing for smaller sample sizes in downstream tasks without quality loss.

## Method Summary
The study benchmarks synthetic tabular data generation using CTGAN, TVAE, NFs, and GReaT models on classification datasets (adult, churn, sick, heloc) and regression dataset (california). For each use case, generative models are trained on 80% of the data, synthetic samples are generated matching the original training set size, and downstream ML performance is evaluated using AutoGluon/XGBoost classifiers and linear regression/MLP models. The 20% held-out test set is used for evaluation, comparing performance metrics (F1-score, ROC-AUC for classification; RMSE for regression) between models trained on real versus synthetic data.

## Key Results
- Real data consistently outperforms synthetic data across all generative models and use cases
- The performance gap between real and synthetic data narrows as more data points are used to train generative models
- Conditional generative models can effectively balance class distributions by generating synthetic samples for minority classes
- Synthetic data shows potential for efficient compression of statistical information, allowing smaller sample sizes for downstream tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Synthetic data improves ML training only when the generative model is trained on a sufficiently large fraction of the original data distribution.
- Mechanism: As more real data points are used to train the generative model, the synthetic samples better approximate the true data distribution, reducing the gap between synthetic and real data in downstream tasks.
- Core assumption: The generative model can capture the true underlying data distribution with enough training data.
- Evidence anchors:
  - [abstract]: "training on real data outperforms training on synthetic data for all tested generative models. However, the gap between synthetic and real data is closing as more data points are used to train the generative model."
  - [section]: "As a general remark, training on the available original data outperforms training on the synthetic samples for all tested generative models. Regarding the latter, we observed that the relative ordering of the downstream efficacy of the compared DGMs does not seem to change much across the varying dataset size regimes, while the gap between synthetic and real data is closing as we use more datapoints to train the generative model."

### Mechanism 2
- Claim: Conditional generative models can improve class balancing by generating synthetic samples for minority classes.
- Mechanism: By training the generative model to learn p(x|y), where y is the target variable, synthetic samples can be generated conditionally for the minority class, effectively balancing the dataset.
- Core assumption: The conditional distribution p(x|y) can be accurately learned by the generative model.
- Evidence anchors:
  - [abstract]: "For classification tasks, we can sample synthetic data conditionally from the minority categories of a given dataset to reduce or eliminate class imbalance prior to downstream training."
  - [section]: "We also sample minority datapoints from GReaT starting the autoregressive generation via setting the feature y to the value of the minority class. Hence, we can restore the balance among the categories of each dataset."

### Mechanism 3
- Claim: Synthetic data can be used for data summarization by efficiently compressing statistical information from the training data population.
- Mechanism: By training a generative model on the full real dataset and sampling a smaller number of synthetic data points, the statistical information can be represented more efficiently than with random subsets of real data.
- Core assumption: The generative model can learn to represent the statistical information of the full dataset in a smaller number of samples.
- Evidence anchors:
  - [abstract]: "The study also examines the potential of synthetic data to compress statistical information from the training data population efficiently, allowing for a smaller sample size for downstream tasks without statistical quality loss."
  - [section]: "Here we investigate if sampling from generative models trained on the full original data distribution inherently enables more efficient compression of the statistical information of the original data for the downstream task, compared to extracting random subsets of real datapoints."

- Critical path: 1. Train generative models on real data 2. Sample synthetic data from trained generative models 3. Train downstream learners on synthetic data 4. Evaluate performance of downstream learners on real test data

- Design tradeoffs:
  - Tradeoff between the quality of synthetic data and the amount of real data used for training the generative model
  - Tradeoff between the complexity of the generative model and its ability to capture the true data distribution
  - Tradeoff between the size of the synthetic dataset and the efficiency of data summarization

- Failure signatures:
  - Poor performance of downstream learners on synthetic data compared to real data
  - Inability of generative models to capture the true data distribution
  - Overfitting of generative models to the training data
  - Failure to balance classes effectively using synthetic data

- First 3 experiments:
  1. Train generative models on small subsets of real data and evaluate the performance of downstream learners on synthetic data
  2. Train generative models on the full real dataset and evaluate the efficiency of data summarization using synthetic data
  3. Use conditional generative models to balance classes and evaluate the performance of downstream learners on the balanced dataset

## Limitations
- The study relies heavily on synthetic data quality metrics without direct validation of whether synthetic samples preserve domain-specific knowledge or business logic embedded in real data
- Results show that synthetic data consistently underperforms real data for downstream tasks, but the paper doesn't fully explore why certain generative models fail to capture critical feature relationships
- The class balancing experiments lack quantitative analysis of the minority class distribution before and after synthetic sampling

## Confidence
- High confidence: The core finding that real data outperforms synthetic data for all tested generative models is well-supported by experimental results across multiple datasets
- Medium confidence: The claim about closing performance gaps with more training data for generative models, as this relationship shows variability across different dataset sizes and models
- Medium confidence: The data summarization efficiency claims, as the compression benefits are demonstrated but not extensively validated against alternative summarization methods
