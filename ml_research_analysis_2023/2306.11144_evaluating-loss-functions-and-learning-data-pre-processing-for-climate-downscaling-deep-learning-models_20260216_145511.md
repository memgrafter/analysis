# Evaluating Loss Functions and Learning Data Pre-Processing for Climate Downscaling Deep Learning Models

## Quick Facts
- arXiv ID: 2306.11144
- Source URL: https://arxiv.org/abs/2306.11144
- Reference count: 25
- Primary result: L2 loss significantly outperforms L1 for imbalanced precipitation data; learned gamma preprocessing improves both precipitation and temperature downscaling

## Executive Summary
This paper investigates the impact of loss functions and data preprocessing strategies on deep learning models for climate downscaling. The authors evaluate L1 and L2 loss functions across temperature and precipitation data, finding that L2 loss performs significantly better for imbalanced precipitation data due to its heavier penalty on large errors. They also propose and evaluate both fixed and learnable gamma correction preprocessing, showing that learning the gamma value automatically adapts to different data types and further improves model accuracy.

## Method Summary
The study uses a UNet architecture with 3 encoder and decoder groups for climate data downscaling. The model is trained on daily precipitation and temperature data from 1981-2010 over the western US, using ERA-interim reanalysis (81 km) as coarse input and PRISM observations (4 km) as ground truth. Key methodological components include testing L1 vs L2 loss functions, applying gamma correction preprocessing (fixed γ=2.2 or learned), and evaluating performance using average absolute difference and mean square error metrics. The model is trained for 800 epochs on 8 V100 GPUs.

## Key Results
- L1 and L2 losses perform similarly for temperature downscaling but L2 significantly outperforms L1 for imbalanced precipitation data
- Fixed gamma correction with γ=2.2 improves precipitation downscaling but harms temperature downscaling
- Learning the gamma value automatically adapts to different data types and outperforms both fixed preprocessing and no preprocessing

## Why This Works (Mechanism)

### Mechanism 1
- L2 loss outperforms L1 for imbalanced precipitation data because it penalizes large errors more heavily through squaring, which is critical when the distribution has extreme values near zero and very large values.
- Core assumption: Precipitation data has a highly skewed, imbalanced distribution with extreme values that should not be under-predicted.
- Evidence anchors: [abstract] "for some imbalanced data like precipitation data, L2 loss performs significantly better than L1 loss"; [section] "The model with L1 loss often underestimate the precipitation values for heavy precipitation regions"
- Break condition: If the data distribution becomes more balanced or extreme values are less important, L2 loss's advantage may diminish.

### Mechanism 2
- Predefined gamma correction (γ = 2.2) improves precipitation downscaling by compressing the high dynamic range of precipitation data, making it easier for the model to learn spatial patterns without being overwhelmed by extreme values.
- Core assumption: Precipitation data has a high dynamic range with many small values and some very large values that benefit from compression.
- Evidence anchors: [abstract] "gamma correction with fixed γ = 2.2 improves the precipitation downscaling model"; [section] "γ > 1 corresponds compressive preprocessing. This indicates that applying compressive preprocessing aids in improving the convergence of the precipitation downscaling model"
- Break condition: If γ is set too high, it may over-compress the data, losing important information about extreme events.

### Mechanism 3
- Learning gamma value automatically adapts preprocessing to different data types, improving both precipitation and temperature downscaling by learning γ > 1 for compression (precipitation) and γ < 1 for expansion (temperature).
- Core assumption: Different climate variables have different dynamic ranges and saturation characteristics that benefit from different preprocessing strategies.
- Evidence anchors: [abstract] "we propose an approach to automatically learn the non-linear pre-processing function, which further enhances model accuracy"; [section] "Table 2 shows that the L*+Learn always perform better than both L* and L*+NL2.2"
- Break condition: If the learning process gets stuck in local minima or if the gamma value becomes unstable during training, the benefits may not materialize.

## Foundational Learning

- Concept: Loss function selection and its impact on model training
  - Why needed here: Different loss functions (L1 vs L2) have different sensitivities to outliers and error magnitudes, which is crucial when dealing with imbalanced climate data like precipitation.
  - Quick check question: Why might L2 loss be preferred over L1 loss for precipitation data with extreme values?

- Concept: Data preprocessing and normalization techniques
  - Why needed here: Climate data has arbitrary value ranges and highly uneven distributions, unlike image data. Proper preprocessing (like gamma correction) can transform the data into a more learnable form.
  - Quick check question: How does gamma correction with γ > 1 help with high dynamic range data like precipitation?

- Concept: Learnable parameters in preprocessing
  - Why needed here: Fixed preprocessing may not be optimal for all data types. Making preprocessing parameters learnable allows the model to adapt to the specific characteristics of each climate variable.
  - Quick check question: What advantage does learning the gamma value provide compared to using a fixed gamma correction?

## Architecture Onboarding

- Component map: Input climate data → Gamma correction (fixed γ or learnable) → UNet encoder → Bottleneck → UNet decoder → Output prediction
- Critical path: Input → Gamma correction → UNet encoder (3 groups) → Bottleneck → UNet decoder (3 groups) → Output → Loss computation → Backpropagation → Update model and gamma (if learnable)
- Design tradeoffs: Fixed gamma is simpler but may not adapt to all data types; learnable gamma adds complexity but adapts to data characteristics; L2 loss is better for imbalanced data but more sensitive to outliers; L1 loss is more robust but may under-predict extremes
- Failure signatures: Poor performance on extreme values (L1 loss insufficient); over-compressed outputs (fixed gamma too high); unstable training (learnable gamma not converging); loss of spatial patterns (architecture issues)
- First 3 experiments: 1) Compare L1 vs L2 loss on precipitation data to verify L2's advantage for imbalanced data; 2) Apply fixed gamma correction (γ = 2.2) to precipitation data and compare with no preprocessing; 3) Implement learnable gamma and train on both precipitation and temperature data to verify adaptive preprocessing benefits

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different loss functions (L1 vs L2) perform on other climate variables beyond temperature and precipitation, such as wind speed or humidity?
- Basis in paper: [explicit] The paper only evaluates L1 and L2 losses on temperature and precipitation data.
- Why unresolved: The paper's scope is limited to temperature and precipitation, leaving the performance of these loss functions on other climate variables unexplored.
- What evidence would resolve it: Experiments applying L1 and L2 losses to downscaling models for wind speed, humidity, and other climate variables, with quantitative comparisons to the temperature and precipitation results.

### Open Question 2
- Question: What is the optimal range for the learnable gamma parameter across different climate variables and datasets?
- Basis in paper: [inferred] The paper proposes learning gamma automatically but only tests on temperature and precipitation data.
- Why unresolved: The paper demonstrates that learned gamma improves results but doesn't establish optimal ranges or patterns across different climate variables.
- What evidence would resolve it: Systematic experiments varying gamma ranges for multiple climate variables, analyzing optimal values and their relationships to data characteristics like dynamic range and distribution.

### Open Question 3
- Question: How does the performance of learned nonlinear preprocessing compare to other nonlinear transformation methods like logarithmic or exponential scaling?
- Basis in paper: [inferred] The paper only compares learned gamma correction to fixed gamma correction, not to other nonlinear preprocessing methods.
- Why unresolved: The paper's comparison is limited to gamma correction variants, leaving open whether gamma is the optimal nonlinear transformation for climate downscaling.
- What evidence would resolve it: Experiments comparing learned gamma correction to logarithmic, exponential, and other nonlinear preprocessing methods on the same datasets, with quantitative performance metrics.

### Open Question 4
- Question: Does the effectiveness of L1 vs L2 loss and preprocessing methods vary with spatial resolution or geographic region?
- Basis in paper: [explicit] The paper tests on western US data at 4km resolution but doesn't explore resolution or regional variations.
- Why unresolved: The study uses a single geographic region and resolution, so the generalizability of findings to other regions or resolutions is unknown.
- What evidence would resolve it: Experiments applying the same methods to different geographic regions (e.g., tropics, polar) and multiple resolutions, analyzing whether loss function and preprocessing effectiveness varies with these factors.

## Limitations
- Limited comparison of only two loss functions (L1 and L2) and one preprocessing type (gamma correction)
- Assumption that ERA-interim/PRISM dataset characteristics generalize to other climate datasets
- Learnable gamma introduces additional hyperparameters without thorough characterization of optimal values and convergence properties
- UNet architecture described at high level without specific implementation details

## Confidence
- **High confidence:** L1 and L2 losses perform differently for temperature vs precipitation data (supported by clear quantitative results in Table 2)
- **Medium confidence:** Fixed gamma correction with γ=2.2 improves precipitation downscaling (supported by ablation results but not extensively validated)
- **Low confidence:** Learnable gamma automatically adapts to different data types and outperforms fixed preprocessing (proposed mechanism but limited empirical validation shown)
