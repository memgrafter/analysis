# Benchmark dataset and instance generator for Real-World Three-Dimensional Bin Packing Problems

## Quick Facts
- **arXiv ID**: 2304.14712
- **Source URL**: https://arxiv.org/abs/2304.14712
- **Reference count**: 4
- **Primary result**: Introduces a benchmark dataset with 12 real-world 3D bin packing instances (38-53 items each) incorporating practical constraints and a Python generator for creating new instances

## Executive Summary
This paper introduces a comprehensive benchmark dataset for three-dimensional bin packing problems that reflects real-world industrial constraints. The dataset consists of 12 instances with varying complexity, containing 38-53 items each, and incorporates multiple practical constraints including item dimensions, weight restrictions, package affinities/incompatibilities, relative positioning preferences, and load balancing requirements. A Python script called Q4RealBPP-DataGen was developed to automatically generate these instances and can create new ones with user-defined parameters. The benchmark was designed to evaluate quantum solvers while being applicable to general optimization purposes.

## Method Summary
The authors developed Q4RealBPP-DataGen, a Python 3.9 script that generates 3D bin packing instances by drawing item dimensions and weights from distributions derived from a seed dataset of real-world logistics packages. The script creates instances with user-defined parameters including number of bins, bin dimensions, weight capacity, and various constraints. Each instance is saved as a text file with a specific format specifying bin dimensions, maximum bins, weights, constraints, and item details. The paper provides results obtained using D-Wave's Leap Constrained Quadratic Model Hybrid Solver for each instance, along with graphical and textual solution representations. The dataset and generator are publicly available through a Mendeley repository.

## Key Results
- Dataset contains 12 benchmark instances with 38-53 items each, varying in complexity
- Incorporates multiple real-world constraints: item dimensions, weight restrictions, package affinities/incompatibilities, relative positioning preferences, and load balancing requirements
- Q4RealBPP-DataGen Python script enables automatic generation of new instances with user-defined parameters
- Benchmark designed for quantum solver evaluation while remaining applicable to general optimization purposes
- Results obtained using D-Wave's Leap CQM Hybrid Solver provided for each instance with graphical and textual solution representations

- Critical path: Generate instance → Solve with quantum solver → Analyze results
- Design tradeoffs:
  - Instance size vs. quantum solver capabilities: Smaller instances are easier for quantum solvers but may not reflect real-world complexity
  - Constraint richness vs. solver applicability: More constraints increase realism but may limit the solvers that can handle the problem
  - Automation vs. manual customization: Automated generation ensures consistency but may not capture all domain-specific nuances
- Failure signatures:
  - Inconsistent instance formats or missing constraints
  - Solver failures or timeouts due to instance complexity
  - Generated instances not reflecting real-world package distributions
