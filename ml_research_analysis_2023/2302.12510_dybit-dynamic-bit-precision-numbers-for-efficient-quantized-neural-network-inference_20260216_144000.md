# DyBit: Dynamic Bit-Precision Numbers for Efficient Quantized Neural Network Inference
## Quick Facts
- arXiv ID: 2302.12510
- Source URL: https://arxiv.org/abs/2302.12510
- Reference count: 15
- Key result: 1.997% higher accuracy than state-of-the-art at 4-bit quantization, up to 8.1× speedup

## Executive Summary
This paper introduces DyBit, an adaptive data representation format for efficient deep neural network quantization. DyBit employs variable-length exponent bits that dynamically adjust precision based on tensor distribution characteristics, offering improved representation accuracy compared to traditional fixed-point formats. The authors develop a hardware-aware quantization framework that searches for optimal layer-wise bitwidths using two strategies: speedup-constrained and RMSE-constrained. This approach enables effective low-bitwidth quantization while maintaining accuracy.

## Method Summary
DyBit uses a novel floating-point-like format with variable-length exponent bits to represent tensor values more accurately across different distributions. The framework automatically determines optimal quantization bitwidths for each layer through hardware-aware search algorithms. Two search strategies are employed: one that maximizes speedup within accuracy constraints, and another that minimizes RMSE while meeting speedup targets. The mixed-precision accelerator design leverages these variable bitwidths to achieve significant computational savings without substantial accuracy loss.

## Key Results
- Achieves 1.997% higher accuracy than state-of-the-art methods at 4-bit quantization
- Delivers up to 8.1× speedup compared to original models on ImageNet classification
- Demonstrates effectiveness across ResNet and MobileNetV2 architectures

## Why This Works (Mechanism)
DyBit's variable-length exponent bits adapt to the distribution of each tensor, allocating more precision where needed and less where it's not critical. This dynamic adjustment allows the representation to maintain accuracy even at low bitwidths by preserving important value ranges. The hardware-aware quantization framework optimizes bitwidth allocation layer-by-layer, recognizing that different layers have different sensitivity to quantization error. The mixed-precision accelerator efficiently executes these heterogeneous bitwidth operations, achieving computational savings while the adaptive representation maintains model accuracy.

**Critical Path**: Tensor distribution analysis → DyBit format encoding → Layer-wise bitwidth search → Hardware resource mapping → Quantization application
