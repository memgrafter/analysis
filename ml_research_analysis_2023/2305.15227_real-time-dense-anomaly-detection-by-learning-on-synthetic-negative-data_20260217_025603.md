# Real time dense anomaly detection by learning on synthetic negative data

## Quick Facts
- arXiv ID: 2305.15227
- Source URL: https://arxiv.org/abs/2305.15227
- Reference count: 18
- Key outcome: Hybrid anomaly detection method achieves best average precision using synthetic negatives but shows performance drop on real negatives, suggesting model capacity limitations

## Executive Summary
This work addresses dense anomaly detection in semantic segmentation by extending the DenseHybrid framework with a generative flow component that samples synthetic negative data at the distribution boundary. The approach enables learning without real negative samples, potentially avoiding biases from data pasting techniques. The NF-Hybrid-LdLx variant achieves state-of-the-art performance on synthetic negatives but exhibits reduced performance when real negatives are used, raising questions about model capacity for hybrid learning approaches.

## Method Summary
The method extends DenseHybrid by incorporating a jointly trained generative flow that samples synthetic negatives at the border of the inlier distribution. This allows the model to learn without relying on real negative data, addressing potential biases introduced by pasting negative data. The approach combines discriminative and generative learning through an energy-based density mechanism, enabling real-time dense anomaly detection while maintaining computational efficiency.

## Key Results
- NF-Hybrid-LdLx achieves best average precision among methods using synthetic negatives
- NFlowJS is outperformed by the proposed extension
- Performance drop observed when hybrid approach is applied to real negative data
- Energy-based density contribution validated during both training and evaluation

## Why This Works (Mechanism)
The method works by combining discriminative learning (traditional segmentation) with generative learning (flow-based synthetic negative sampling). The generative flow samples from regions near the inlier distribution boundary, creating challenging negative examples that improve anomaly detection boundaries. The energy-based density provides an additional anomaly score that captures distributional uncertainty, complementing the discriminative segmentation confidence.

## Limitations
- SwiftNet-RN18 architecture may lack sufficient capacity for effective hybrid learning
- Synthetic negative data generation may introduce biases or fail to represent true anomaly distribution
- Evaluation focused primarily on semantic segmentation tasks, limiting generalizability
- Performance degradation observed when using real negative data suggests fundamental limitations

## Confidence
- High confidence: NF-Hybrid-LdLx outperforms NFlowJS on synthetic negatives
- Medium confidence: Energy-based density contribution is experimentally validated
- Low confidence: SwiftNet-RN18 capacity limitations are the primary cause of performance drop
