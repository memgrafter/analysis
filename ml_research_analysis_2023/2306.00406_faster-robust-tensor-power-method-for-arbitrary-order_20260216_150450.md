# Faster Robust Tensor Power Method for Arbitrary Order

## Quick Facts
- arXiv ID: 2306.00406
- Source URL: https://arxiv.org/abs/2306.00406
- Reference count: 22
- One-line primary result: Robust tensor power method generalized to arbitrary order p≥3 with O(np⁻¹) per-iteration time via sketching

## Executive Summary
This paper presents a robust tensor power method (TPM) for arbitrary order tensors that overcomes limitations of existing approaches restricted to lower-order tensors or requiring strong assumptions. The authors apply a sketching method to achieve running time of O(np⁻¹) for p-th order tensors of dimension n, providing detailed analysis for any order p. The method generalizes the robust tensor power method from third-order to general order tensors, requiring milder assumptions and supporting wider tensor choices.

## Method Summary
The method combines a sketching-based tensor power iteration with a deflation procedure to recover all components of an orthogonally decomposable tensor. A randomized Hadamard-based sketching data structure maintains low-dimensional sketches of tensor slices, enabling fast inner product evaluation without materializing the full tensor. The algorithm iterates power updates with geometric angle contraction under bounded noise, then deflates the recovered component and repeats for all k components. The approach requires O(np) space and achieves O(np⁻¹) time per iteration through the sketching technique.

## Key Results
- Generalizes robust tensor power method from order-3 to arbitrary order p≥3
- Achieves O(np⁻¹) per-iteration time using sketching, down from O(np)
- Provides convergence guarantees under bounded noise with angle contraction tan θ(v₁, ut+1) ≤ 0.8·tan θ(v₁, ut) + O(ε/λ₁)

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The method generalizes robust tensor power iteration from order-3 to arbitrary order p≥3 by controlling angle convergence between estimated and true eigenvectors under bounded noise.
- **Mechanism:** At each iteration, the algorithm computes ut+1 = A(I, ut, ..., ut)/∥A(I, ut, ..., ut)∥₂. For orthogonal tensors A* = Σλᵢvᵢ⊗ᵖ, the update contracts the angle θ(v₁, ut) geometrically: tan θ(v₁, ut+1) ≤ 0.8·tan θ(v₁, ut) + O(ε/λ₁) under bounded noise ∥E(I, ut, ..., ut)∥₂ ≤ O(ε) and |E(v, ut, ..., ut)| ≤ O(ε/√n).
- **Core assumption:** Noise tensor E is small relative to leading eigenvalue λ₁ (specifically ε ≤ c·λ₁/(c₀p²kn^(p-2)/2)) and the tensor is orthogonally decomposable.
- **Evidence anchors:**
  - [abstract] "generalized the robust tensor power method for third-order tensors to general order tensors"
  - [section] "tan θ(v1, u t+1)≤ 0.8 tan θ(v1, u t) + 18ǫ/ (c0λ 1)" from Theorem 4.7
  - [corpus] Weak signal - no corpus neighbors discuss angle convergence under noise
- **Break condition:** If noise exceeds the bound, the contraction factor degrades and convergence fails; also fails if tensor components are not linearly independent.

### Mechanism 2
- **Claim:** Sketching reduces per-iteration complexity from O(nᵖ) to O(nᵖ⁻¹) while preserving approximation guarantees.
- **Mechanism:** A randomized Hadamard-based sketching data structure maintains low-dimensional sketches of the tensor slices. Querying with u returns an (1±ε) approximation to ⟨Aᵢ, u⊗(p-1)⟩ in O(ε⁻²nᵖ⁻¹ + n²k) time. This enables fast inner product evaluation without materializing the full tensor.
- **Core assumption:** The sketching matrix provides Johnson-Lindenstrauss-style guarantees for the tensor's subspace.
- **Evidence anchors:**
  - [abstract] "We apply sketching method, and we are able to achieve the running time of Õ(np−1)"
  - [section] Lemma D.2 describes the data structure with time Õ(ε⁻²np⁻¹ + n²k)
  - [corpus] Weak signal - no corpus neighbors describe sketching for tensor inner products
- **Break condition:** If sketch dimension is insufficient for JL guarantee, approximation error exceeds tolerance; also fails if tensor slices have high rank.

### Mechanism 3
- **Claim:** Deflation removes the top component after each eigenvector recovery, enabling extraction of all k components in O(k log k) iterations.
- **Mechanism:** After estimating (λ₁, v₁), the algorithm forms the residual tensor A - λ₁v₁⊗ᵖ and repeats the power method. The Lemma 4.6 guarantees random Gaussian initialization finds components with separation condition |vⱼ·u| ≤ (1/4)|v₁·u|.
- **Core assumption:** Eigenvalues are distinct enough to satisfy the separation condition with high probability.
- **Evidence anchors:**
  - [abstract] "outputs the estimated eigenvector/eigenvalue pair, together with the deflated tensor"
  - [section] Lemma 4.6 states "there exists a vector u satisfying maxⱼ∈[k]\{t} |vⱼᵀu| ≤ (1/4)|vᵀᵗu|"
  - [corpus] Weak signal - no corpus neighbors discuss deflation with Gaussian initialization
- **Break condition:** If eigenvalues are too close or noise corrupts separation, deflation fails and components cannot be recovered.

## Architecture Onboarding

- **Component map:**
  - Data structure: Randomized Hadamard sketch storage
  - Main loop: T iterations of sketching-based tensor-vector multiplication
  - Deflation: Subtract estimated rank-1 component
  - Output: λ, v estimates with error bounds

- **Critical path:**
  1. Init: Build sketches of tensor slices (Õ(ε⁻²np))
  2. Iterate: For t=1..T: u ← ds.Query(u); u ← u/∥u∥₂ (Õ(ε⁻²nᵖ⁻¹) per step)
  3. Deflate: Update tensor residual
  4. Repeat L times for all components

- **Design tradeoffs:**
  - Higher sketch dimension → better approximation but more space/time
  - More iterations T → better convergence but slower
  - Larger L → more components recovered but more memory for residuals

- **Failure signatures:**
  - Divergence: tan θ grows instead of shrinks → noise too large
  - Stalling: Small angle changes → insufficient iterations
  - Inaccurate components: Large residual norm after deflation → separation condition violated

- **First 3 experiments:**
  1. Synthetic orthogonal tensor with known decomposition; verify convergence rates for p=3,4,5
  2. Add controlled noise; measure error vs theoretical bounds
  3. Scale n and k; benchmark sketching vs full tensor computation

## Limitations
- The orthogonal decomposability assumption restricts applicability to tensors with linearly independent components
- Sketching introduces approximation error that compounds over iterations and may degrade with tensor order
- The method requires multiple power iterations and deflations, leading to potential error accumulation across components

## Confidence
**High Confidence:** The theoretical framework for the robust tensor power method under bounded noise conditions is well-established, building on prior work for third-order tensors. The angle contraction bounds (tan θ(v₁, ut+1) ≤ 0.8·tan θ(v₁, ut) + O(ε/λ₁)) are mathematically rigorous under the stated assumptions.

**Medium Confidence:** The sketching complexity reduction claims rely on Johnson-Lindenstrauss-style guarantees, which are well-understood theoretically but may face practical challenges with very high-order tensors or extreme dimensions.

**Low Confidence:** The deflation procedure's effectiveness in practice, particularly when components are closely spaced or noise levels are high, requires empirical validation beyond the theoretical separation conditions.
