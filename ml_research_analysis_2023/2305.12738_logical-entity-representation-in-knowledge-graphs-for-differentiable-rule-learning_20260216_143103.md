# Logical Entity Representation in Knowledge-Graphs for Differentiable Rule Learning

## Executive Summary
This paper introduces Logical Entity Representation (LERP), a method that encodes contextual information from neighboring subgraphs into probabilistic logical rule learning for knowledge graph completion. By representing entities as vectors of interpretable logical functions over their local subgraphs, LERP enables more expressive rule learning while maintaining differentiability for gradient-based optimization. Empirical results show LERP outperforms traditional rule learning methods and achieves competitive performance with state-of-the-art black-box approaches, while providing interpretable representations that allow discovery of complex logical rules.

## Method Summary
LERP encodes entities as vectors of probabilistic logical functions constructed from their local subgraphs, using tree-like structures with chaining, negation, and merging operations. The method jointly learns logical rules and LERP parameters through differentiable optimization using Adam with cross-entropy loss. The model operates on knowledge graphs represented as sets of triples (s, r, o) where s and o are entities and r is a relation. Training runs for 4-10 epochs depending on the dataset, with specific hyperparameters for rule generation and LERP depth/width.

## Key Results
- LERP outperforms existing rule learning methods on knowledge graph completion benchmarks
- Achieves competitive or superior performance compared to state-of-the-art black-box methods
- Provides interpretable entity representations that enable discovery of complex logical rules
