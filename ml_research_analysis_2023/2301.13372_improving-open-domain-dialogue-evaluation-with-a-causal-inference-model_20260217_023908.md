# Improving Open-Domain Dialogue Evaluation with a Causal Inference Model

## Quick Facts
- **arXiv ID:** 2301.13372
- **Source URL:** https://arxiv.org/abs/2301.13372
- **Reference count:** 40
- **Primary result:** CF-LSTM achieves Pearson correlations of 0.34-0.68 for user ratings and 0.35 for expert ratings on Alexa Prize SocialBot dataset, outperforming baselines.

## Executive Summary
This paper addresses the challenge of evaluating open-domain conversational dialogue systems by proposing a novel causal inference model, the Counterfactual LSTM (CF-LSTM). The method uses interpretable turn-level features extracted from user utterances (such as sentiment, contradiction, and disinterest) and response-level metrics (such as relevance and specificity), which are then projected to the dialogue level. Experiments on the Alexa Prize SocialBot dataset show that CF-LSTM achieves the best performance, with Pearson correlations of 0.34 (individual), 0.46 (daily average), and 0.68 (7-day rolling average) for user ratings, and 0.35 for expert ratings, outperforming end-to-end transformers and other baseline models.

## Method Summary
The CF-LSTM model leverages causal inference by using different regressors for different dialogue behavior hypotheses. It partitions dialogues into treatment groups based on the presence or absence of negative user behaviors (e.g., insults, disinterest, contradiction). The model then trains separate regressors for each group, modeling the causal effect of these behaviors on ratings. The Wasserstein distance loss term ensures the distributions of feature representations for the two treatment groups remain distinguishable. The model processes sequences of turn-level features using LSTM layers, preserving temporal dependencies that affect user ratings.

## Key Results
- CF-LSTM achieves Pearson correlations of 0.34 (individual), 0.46 (daily average), and 0.68 (7-day rolling average) for user ratings on Alexa Prize dataset
- CF-LSTM achieves Pearson correlation of 0.35 for expert ratings
- CF-LSTM outperforms end-to-end transformers and other baseline models in both regression and classification tasks for detecting low-quality dialogues

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The CF-LSTM leverages causal inference by using different regressors for different dialogue behavior hypotheses, improving prediction accuracy over standard regression models.
- **Mechanism:** The model partitions dialogues into treatment groups based on the presence or absence of negative user behaviors (e.g., insults, disinterest, contradiction). It then trains separate regressors for each group, modeling the causal effect of these behaviors on ratings. The Wasserstein distance loss term ensures the distributions of feature representations for the two treatment groups remain distinguishable.
- **Core assumption:** All relevant confounding variables are captured in the extracted turn-level features, satisfying conditional ignorability (T ⊥ ⊥ (Y(a) | X, ∀a ∈ {0,1})).
- **Evidence anchors:**
  - [abstract] "The proposed CF-LSTM is a sequential model over turn-level features which predicts ratings using multiple regressors depending on hypotheses derived from the turn-level features."
  - [section] "The proposed CF-LSTM model consists of the LSTM layers and 2 individual MLP regressors, each used to train on a specific hypothesis or treatment."

- **Break condition:** If important confounding variables are not captured in the features (e.g., speaker personality, conversation topic drift), the causal assumptions fail and predictions degrade.

### Mechanism 2
- **Claim:** Turn-level features extracted from multiple pre-trained models provide rich, interpretable signals that correlate with dialogue quality and user satisfaction.
- **Mechanism:** The system applies ODES classifiers to detect user dialogue behaviors (critique, disinterest, etc.), sentiment classifiers for valence/satisfaction/activation, FED for response quality metrics, and other models for relevance and specificity. These features are aggregated to the dialogue level and fed into prediction models.
- **Core assumption:** The pre-trained models (ODES, FED, DialoGPT, DialogRPT) accurately capture the relevant aspects of dialogue quality for the Alexa SocialBot domain.
- **Evidence anchors:**

### Mechanism 3
- **Claim:** The LSTM component of CF-LSTM handles variable-length dialogues by processing the sequence of turn-level features, preserving temporal dependencies that affect user ratings.
- **Mechanism:** The LSTM takes the sequence of turn-level feature vectors as input, learning to map this temporal representation to the overall dialogue rating. This allows the model to capture patterns across turns, such as early negative signals or sustained engagement.
- **Core assumption:** The temporal order and dependencies in the turn-level features are informative for predicting the final dialogue rating.
- **Evidence anchors:**
  - [abstract] "The proposed CF-LSTM is a sequential model over turn-level features..."
  - [section] "The input of the LSTM layers are the dialogue-level feature vectors, which are sequences of turn-level features. Since the LSTM can take varied-length inputs, this property also holds for CF-LSTM and can take varied-length dialogue-level feature vectors."

- **Break condition:** If the temporal dependencies are weak or if the turn-level features are not informative, the LSTM component will not improve predictions over simpler aggregation methods.

## Architecture Onboarding

- **Component map:** Raw dialogue text → Turn-level feature extraction (ODES, sentiment, FED, DialoGPT, DialogRPT) → Feature aggregation → CF-LSTM (LSTM layers + treatment-specific MLP regressors + Wasserstein loss)
- **Critical path:** Feature extraction → Feature aggregation → CF-LSTM training with treatment assignment and Wasserstein loss
- **Design tradeoffs:** Using pre-trained models for feature extraction vs. end-to-end learning; treating dialogue as a sequence vs. aggregating to a single vector; using Wasserstein distance vs. simpler loss functions
- **Failure signatures:** Low Pearson correlation on held-out data; high Wasserstein distance indicating feature distributions are not well-separated by treatment; high variance in predictions across similar dialogues

## Limitations
- The core causal inference approach relies heavily on the assumption that all confounding variables are captured in the extracted turn-level features, which is not directly validated
- The Wasserstein distance loss is mentioned as important for maintaining distinguishable feature distributions across treatment groups, but the paper does not report Wasserstein distance values or analyze their impact on performance
- The effectiveness of the pre-trained models (ODES, FED, etc.) in the Alexa SocialBot domain is assumed rather than empirically validated, and the feature extraction pipeline could introduce domain-specific biases

## Confidence

**Major Uncertainties and Limitations:**
The core causal inference approach relies heavily on the assumption that all confounding variables are captured in the extracted turn-level features. The paper does not provide direct validation that conditional ignorability is satisfied, which is critical for causal interpretation. Additionally, the Wasserstein distance loss is mentioned as important for maintaining distinguishable feature distributions across treatment groups, but the paper does not report Wasserstein distance values or analyze their impact on performance. The effectiveness of the pre-trained models (ODES, FED, etc.) in the Alexa SocialBot domain is assumed rather than empirically validated, and the feature extraction pipeline could introduce domain-specific biases.

**Confidence Labels:**
- **High confidence:** The experimental results showing CF-LSTM outperforming baseline models (E2E Transformer, Dialogue-level MLP/LSTM) on the Alexa Prize dataset. The Pearson correlation improvements (0.34→0.68 for 7-day rolling average user ratings) are clearly demonstrated.
- **Medium confidence:** The causal inference framing and treatment assignment methodology. While the approach is theoretically sound, the paper lacks direct validation of key assumptions like conditional ignorability and does not analyze Wasserstein distance values.
- **Low confidence:** The robustness of the feature extraction pipeline across different dialogue domains. The paper assumes the pre-trained models generalize well to Alexa SocialBot conversations without providing cross-domain validation.

## Next Checks
1. **Assumption validation:** Conduct sensitivity analysis to test the robustness of causal estimates to unmeasured confounding. Specifically, analyze how predictions change when systematically varying the feature set to identify which features drive the causal effects.
2. **Wasserstein distance analysis:** Report and analyze Wasserstein distance values during training to verify that feature distributions are adequately separated by treatment groups, and assess the impact of Wasserstein loss weight on prediction performance.
3. **Cross-domain evaluation:** Test the CF-LSTM model on dialogue datasets from different domains (e.g., customer service, task-oriented dialogue) to evaluate the generalizability of the pre-trained feature extractors and the causal inference approach.
