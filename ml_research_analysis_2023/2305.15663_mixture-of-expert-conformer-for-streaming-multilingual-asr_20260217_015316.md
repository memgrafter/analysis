# Mixture-of-Expert Conformer for Streaming Multilingual ASR

## Quick Facts
- arXiv ID: 2305.15663
- Source URL: https://arxiv.org/abs/2305.15663
- Reference count: 0
- Key outcome: 11.9% relative WER improvement over baseline multilingual Conformer using MoE layers

## Executive Summary
This paper presents a mixture-of-experts (MoE) approach for streaming multilingual automatic speech recognition (ASR) using Conformer architecture. The authors propose replacing the feed-forward network in Conformer layers with MoE layers, which activate only a subset of parameters during training and inference. The MoE layer uses a softmax gate to select the top two experts among many for forward propagation, enabling efficient inference as the number of experts increases.

The proposed model was evaluated on 12 languages and achieved an average 11.9% relative improvement in word error rate (WER) compared to a baseline multilingual Conformer model. Compared to an adapter model using ground truth language information, the MoE model achieved similar WER and activated a similar number of parameters but without requiring any language information. Additionally, the authors demonstrated a 3% relative WER improvement by applying multilingual shallow fusion with a neural language model.

## Method Summary
The paper proposes replacing the feed-forward network (FFN) in Conformer layers with mixture-of-experts (MoE) layers. The MoE layer consists of a softmax gate that selects the top two experts among many during forward propagation. The model was trained on a 12-language dataset with 139.4M utterances using RNN-T loss with an auxiliary load-balancing loss. Features were 512D stacked log-Mel with SpecAugment, and the model used a shared wordpiece model for tokenization.

## Key Results
- Achieved 11.9% relative WER improvement compared to baseline multilingual Conformer
- MoE model matched adapter model performance without requiring language information
- 3% relative WER improvement using multilingual shallow fusion with neural language model
- Top-2 expert routing enabled efficient inference while scaling model capacity

## Why This Works (Mechanism)

### Mechanism 1
The MoE layer activates only 2 experts per frame while using many experts in total, enabling model capacity scaling without proportional computation cost increase. The softmax gating selects top-2 experts based on routing scores, and during inference only these 2 experts' outputs are computed and combined. This works because top-2 expert selection maintains performance while significantly reducing computation, though it may fail if routing becomes too noisy or load balancing fails.

### Mechanism 2
The MoE architecture achieves similar WER to adapter models without requiring language information. The gating network learns language-agnostic routing that adapts to input patterns rather than relying on explicit language labels. This works because the routing network can learn effective specialization without explicit language supervision, though it may underperform language-specific approaches if language boundaries are too sharp or training data lacks diversity.

### Mechanism 3
Replacing the end FFN in Conformer layers with MoE layers provides the best performance improvement. The end FFN position allows MoE to process the most refined representations from self-attention and convolution layers. This works because MoE layers benefit most from processing representations after both attention and convolution operations, though it may not improve over dense layers if the end FFN receives noisy or unstable representations.
