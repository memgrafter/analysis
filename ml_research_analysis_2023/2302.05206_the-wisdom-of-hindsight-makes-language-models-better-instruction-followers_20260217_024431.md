# The Wisdom of Hindsight Makes Language Models Better Instruction Followers

## Quick Facts
- arXiv ID: 2302.05206
- Source URL: https://arxiv.org/abs/2302.05206
- Reference count: 21
- Primary result: HIR achieves 11.2% and 32.6% performance gains over PPO and Final-Answer RL respectively on average across 12 BigBench tasks

## Executive Summary
This paper introduces Hindsight Instruction Relabeling (HIR), a novel approach for improving language model instruction following without additional training pipelines or parameters. HIR treats instruction following as a goal-conditioned reinforcement learning problem and uses hindsight relabeling to learn from both successful and failed instruction-output pairs. The method alternates between online sampling and offline relabeling phases, significantly outperforming baseline methods including PPO and Final-Answer RL on 12 challenging BigBench reasoning tasks.

## Method Summary
HIR is a two-stage algorithm that alternates between online sampling and offline relabeling phases. During online sampling, the model generates instruction-output pairs using temperature-based sampling. In the offline relabeling phase, instructions are modified to match the generated outputs using a scripted feedback function. The model is then trained using standard supervised learning with additional contrastive instruction labeling and entropy regularization. This approach enables learning from both successful and failed attempts without requiring reward models or additional parameters.

## Key Results
- HIR achieves 11.2% performance gain over PPO on average across 12 BigBench tasks
- HIR achieves 32.6% performance gain over Final-Answer RL on average across tasks
- HIR outperforms supervised finetuning on 7 out of 12 BigBench tasks

## Why This Works (Mechanism)

### Mechanism 1
HIR improves alignment by relabeling instructions based on model-generated outputs, effectively turning failures into learning opportunities. In online sampling, HIR generates instruction-output pairs using a language model. In offline relabeling, it modifies the instruction to match the generated output using a scripted feedback function. This allows the model to learn from both successful and failed attempts by treating the output as a new "goal" for the instruction.

### Mechanism 2
Contrastive instruction labeling improves alignment by suppressing incorrect instruction-output mappings. Alongside standard supervised loss, HIR applies a contrastive loss that pushes down the probability of incorrect instruction-output pairs. This ensures the model doesn't learn to map the same output to multiple instructions.

### Mechanism 3
Sub-output relabeling provides dense feedback by relabeling intermediate time steps in generated sequences. Instead of only relabeling the final output, HIR samples intermediate tokens in the generated sequence and relabels the instruction based on the partial output. This provides more frequent feedback signals during training.

## Foundational Learning

- **Goal-conditioned reinforcement learning**: Needed because HIR frames instruction following as reaching a "goal" (the instruction) through a sequence of actions (generated tokens). Quick check: What are the three core components of a goal-conditioned MDP that apply to instruction following?
- **Supervised sequence learning with contrastive loss**: Needed because the model needs to learn token-by-token generation while distinguishing correct from incorrect instruction mappings. Quick check: How does the contrastive loss term in HIR differ from standard cross-entropy loss?
- **Temperature-based sampling for exploration**: Needed because during online sampling, higher temperature encourages diverse outputs to create a richer dataset for relabeling. Quick check: What happens to the diversity of generated outputs when temperature is set to 0 versus 1?

## Architecture Onboarding

- **Component map**: Online sampling (high temperature generation) -> Offline relabeling (scripted feedback) -> Supervised training (seq2seq + contrastive + entropy) -> Evaluation
- **Critical path**: Online sampling → Offline relabeling → Supervised training → Evaluation
- **Design tradeoffs**: HIR avoids reward model training but requires scripted feedback functions; relabeling enables learning from failures but may introduce label noise; contrastive loss improves precision but adds complexity to training
- **Failure signatures**: Performance plateaus early (insufficient exploration), contrastive loss dominates (α coefficient too high), model generates repetitive outputs (β coefficient too low)
- **First 3 experiments**: 1) Run HIR on a single BigBench task with tracking shuffled objects to verify basic functionality; 2) Compare HIR with and without contrastive loss on logical deduction tasks; 3) Test HIR with different entropy regularization coefficients on object counting tasks

## Open Questions the Paper Calls Out

## Limitations
- Relies heavily on scripted feedback functions that may not generalize to all domains
- Limited evaluation to 12 BigBench reasoning tasks, leaving uncertainty about real-world applicability
- Does not provide detailed analysis of how relabeling quality affects final performance

## Confidence
- **High confidence**: HIR significantly outperforms PPO and Final-Answer RL on BigBench reasoning tasks
- **Medium confidence**: HIR is comparable to or surpasses supervised finetuning on average across tasks
- **Medium confidence**: The two-stage alternating optimization framework is effective for instruction following
- **Low confidence**: HIR generalizes well beyond the 12 evaluated BigBench tasks

## Next Checks
1. Evaluate HIR on a broader set of instruction following tasks including non-reasoning domains (summarization, translation, creative writing) to assess real-world applicability
2. Systematically vary the quality of scripted feedback functions to measure how HIR performance degrades and identify failure thresholds
3. Compare HIR performance when using automated feedback (LLM judges) versus scripted feedback to determine critical dependencies on handcrafted relabeling functions
