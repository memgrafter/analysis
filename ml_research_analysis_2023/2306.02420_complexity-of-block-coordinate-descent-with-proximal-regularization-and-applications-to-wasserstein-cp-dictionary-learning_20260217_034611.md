# Complexity of Block Coordinate Descent with Proximal Regularization and Applications to Wasserstein CP-dictionary Learning

## Quick Facts
- arXiv ID: 2306.02420
- Source URL: https://arxiv.org/abs/2306.02420
- Reference count: 40
- Key outcome: Establishes O(ε⁻¹(log ε⁻¹)²) complexity for BCD-PR and applies to Wasserstein dictionary learning

## Executive Summary
This paper establishes the first known worst-case complexity bounds for block coordinate descent with proximal regularization (BCD-PR) for nonconvex optimization problems. The authors prove that BCD-PR converges to an ε-stationary point within O(ε⁻¹(log ε⁻¹)²) iterations under standard smoothness assumptions, even when executed inexactly. They apply this theoretical framework to Wasserstein dictionary learning, where they propose an efficient algorithm using dual formulations and entropic regularization. The algorithm solves subproblems involving Wasserstein distances without requiring repeated optimal transport computations.

## Method Summary
The paper develops BCD-PR for nonconvex optimization with block-wise constraints, where each iteration updates one block coordinate by minimizing a proximal-regularized subproblem. For Wasserstein dictionary learning, they reformulate the problem using entropic regularization and dual formulations, enabling efficient updates via gradient descent in the dual space rather than repeated optimal transport computations. The approach handles d-dimensional joint probability distributions represented as tensors, learning elementary distributions that approximate given joint distributions.

## Key Results
- Proves O(ε⁻¹(log ε⁻¹)²) iteration complexity for BCD-PR to reach ε-stationary points
- Extends complexity bound to inexact updates with summable optimality gaps
- Demonstrates efficient Wasserstein dictionary learning without repeated OT computations
- Shows applications to Wasserstein barycenter problems and image datasets like MNIST

## Why This Works (Mechanism)

### Mechanism 1
- Claim: BCD-PR achieves ε-approximate stationarity in O(ε⁻¹(log ε⁻¹)²) iterations for nonconvex smooth objectives under block-wise constraints.
- Mechanism: Each block coordinate update minimizes a proximal-regularized subproblem, ensuring sufficient descent while controlling deviation from previous iterate. The proximal term λn||θ - θ(n-1)||² bounds per-block step size, preventing oscillations and ensuring monotonic progress in function value.
- Core assumption: Objective is L-smooth in each block coordinate and constraint sets are convex with compact sublevel sets (Assumptions 3.1-3.2).
- Evidence anchors: [abstract] "We show that for general nonconvex smooth objectives with block-wise constraints, the classical BCD-PR algorithm converges to an ε-stationary point within O(ε⁻¹) iterations." [section] "Theorem 3.4... converges to an ε-stationary point within O(ε⁻¹(log ε⁻¹)²) iterations."
- Break condition: If smoothness constant L(i) is not uniformly bounded across blocks, per-iteration descent guarantee fails. If proximal regularization τn < L(i), subproblem may not be strongly convex, breaking growth property.

### Mechanism 2
- Claim: Worst-case iteration complexity remains O(ε⁻¹(log ε⁻¹)²) even when subproblems are solved inexactly with summable optimality gaps.
- Mechanism: Inexactness is controlled via summable optimality gaps ∆n. Total error from inexactness accumulates linearly in convergence bound, but summability condition (Assumption 3.3) ensures it doesn't dominate ε⁻¹(log ε⁻¹)² term.
- Core assumption: P∞n=1 ∆n < ∞, i.e., optimality gaps decay fast enough to be summable.
- Evidence anchors: [abstract] "Under a mild condition, this result still holds even if the algorithm is executed inexactly in each step." [section] "Proposition A.1... total error from inexactness accumulates linearly in convergence bound."
- Break condition: If ∆n decays slower than 1/n², sum diverges and complexity bound no longer holds. If sum of ∆n is unbounded, accumulated error could prevent reaching ε-stationarity.

### Mechanism 3
- Claim: Entropic regularization + dual formulation approach avoids repeated optimal transport computations in Wasserstein dictionary learning.
- Mechanism: Instead of solving N separate optimal transport problems per iteration, algorithm reformulates subproblems in dual space using entropic regularization. Dual variables are updated via gradient descent, which only requires matrix multiplications and element-wise operations, avoiding expensive Sinkhorn scaling.
- Core assumption: Dual problem of entropic regularized Wasserstein distance is smooth and has Lipschitz gradient (γ-Lipschitz for parameter γ).
- Evidence anchors: [abstract] "Our algorithm is a version of BCD-PR that operates in the dual space, where the primal problem is regularized both entropically and proximally." [section] "Algorithm 2 and 3... only requires solving a single and simple subproblem (instead of N) for each block coordinate descent step."
- Break condition: If entropic parameter γ is too small, dual problem becomes ill-conditioned and gradient descent steps become unstable. If cost matrix M is not strictly positive, entropic regularization may not sufficiently smooth objective.

## Foundational Learning

- Concept: L-smoothness in block coordinates
  - Why needed here: Ensures each block-wise gradient update is stable and function behaves nicely along coordinate directions, essential for proving descent and convergence.
  - Quick check question: If f is L-smooth in block coordinate i, what inequality bounds |f(θ') - f(θ) - ⟨∇if(θ), θ'i - θi⟩| in terms of L and ∥θ' - θ∥?

- Concept: Proximal regularization and strong convexity
  - Why needed here: Proximal term τn||θ - θ(n-1)||² makes each subproblem (τn - L(i))-strongly convex, ensuring unique solution and quadratic growth, key to proving both convergence and complexity bounds.
  - Quick check question: What is the effect on strong convexity parameter of subproblem if τn = L(i)?

- Concept: Entropic regularization of Wasserstein distance
  - Why needed here: Makes optimal transport problem differentiable and smooth, enabling gradient-based optimization and dual reformulation without repeated OT solves.
  - Quick check question: How does entropic parameter γ affect smoothness of dual objective?

## Architecture Onboarding

- Component map: θn = (Dn, Λn) -> Update Λn via Algorithm 2 -> Update Dn via Algorithm 3 -> Check convergence
- Critical path: 1. Initialize θ0 = (D0, Λ0) 2. For each iteration n: a. Solve Λn via Algorithm 2 (dual gradient steps) b. Solve Dn via Algorithm 3 (dual gradient steps) c. Update θn = (Dn, Λn) 3. Check convergence via stationarity condition
- Design tradeoffs:
  - Proximal regularization vs. step size: Larger τn gives better conditioning but smaller steps; smaller τn risks non-convergence
  - Entropic regularization vs. fidelity: Larger γ gives smoother dual but biased approximation to true Wasserstein distance
  - Inexactness vs. complexity: Allowing summable gaps reduces per-iteration cost but requires careful gap control
- Failure signatures:
  - Divergence: τn too small relative to L(i), or ∆n not summable
  - Slow convergence: τn too large, causing tiny steps; or γ too small, causing ill-conditioning in dual
  - Numerical instability: γ too small or cost matrix has zeros, leading to NaNs in dual updates
- First 3 experiments:
  1. Run BCD-PR on simple 2-block quadratic with known stationary point, verify O(ε⁻¹) convergence and monotonicity
  2. Test Algorithm 2 on synthetic Wasserstein barycenter with known solution, check dual updates converge without repeated OT
  3. Combine both: run full WCPDL on small tensor with synthetic data, verify per-iteration cost scales as claimed and convergence matches theory

## Open Questions the Paper Calls Out

- Question: What is the precise relationship between entropy regularization parameter γ and approximation quality of learned dictionary atoms in Wasserstein CP-dictionary learning?
  - Basis in paper: [inferred] Paper mentions γ affects learned distributions but doesn't provide theoretical guarantees on approximation quality as function of γ
  - Why unresolved: Paper only demonstrates empirically that γ affects learned distributions (Figures 1-2) but doesn't establish theoretical bounds on how γ relates to approximation error
  - What evidence would resolve it: Theoretical analysis showing bounds on reconstruction error as function of γ, or experimental results systematically varying γ across different datasets and measuring trade-off between approximation quality and computational efficiency

- Question: How does choice of proximal regularization coefficient τ affect convergence rate in practice, and is there optimal strategy for selecting τ?
  - Basis in paper: [explicit] Figure 6 shows different convergence rates for different τ values but doesn't provide guidance on optimal selection
  - Why unresolved: Paper only shows τ affects convergence speed but doesn't provide theoretical guidance on how to choose τ optimally or whether there's systematic way to adapt τ during training
  - What evidence would resolve it: Theoretical analysis of optimal τ selection, or empirical results showing convergence rates across different datasets and problem sizes with various τ selection strategies

- Question: Can O(ε⁻¹(log ε⁻¹)²) iteration complexity bound be improved for specific problem classes or under additional assumptions?
  - Basis in paper: [explicit] Paper establishes this bound as worst-case result but notes it matches optimal result "up to a (log ε⁻¹)² factor" for gradient descent methods
  - Why unresolved: Paper presents this as general worst-case bound without exploring whether it can be tightened for structured problems or with additional assumptions
  - What evidence would resolve it: Either proof that bound is tight for general problems, or improved bound under specific assumptions (e.g., for problems with additional structure like sparsity or low-rank constraints)

## Limitations
- Strong assumptions required: L-smoothness in each block coordinate, compact sublevel sets for constraint sets, and summable optimality gaps for inexact updates may not hold in all practical scenarios
- Sensitivity to regularization parameters: Both proximal regularization coefficient τ and entropic regularization parameter γ require careful tuning for good performance
- Potential computational overhead: While avoiding repeated OT computations, the dual formulation still requires solving gradient descent subproblems that may be expensive for large-scale problems

## Confidence

- **High**: The complexity bound of O(ε⁻¹(log ε⁻¹)²) iterations for BCD-PR under standard smoothness and compactness assumptions. The dual formulation approach for avoiding repeated OT computations in Wasserstein problems.
- **Medium**: The extension of the complexity bound to inexact updates with summable gaps. The practical performance of the Wasserstein dictionary learning algorithm on real image datasets.
- **Low**: The sensitivity of the entropic regularization parameter γ on the convergence rate and approximation quality. The behavior of the algorithm when the cost matrix M contains zeros.
