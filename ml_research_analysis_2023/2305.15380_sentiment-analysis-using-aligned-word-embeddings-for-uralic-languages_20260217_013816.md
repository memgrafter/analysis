# Sentiment Analysis Using Aligned Word Embeddings for Uralic Languages

## Quick Facts
- arXiv ID: 2305.15380
- Source URL: https://arxiv.org/abs/2305.15380
- Reference count: 9
- Primary result: Novel method for sentiment analysis on endangered Uralic languages using aligned word embeddings and neural networks trained on English data, achieving 56-69% accuracy.

## Executive Summary
This paper presents a novel approach for conducting sentiment analysis on endangered Uralic languages (Erzya, Moksha, Udmurt, and Komi-Zyrian) by leveraging aligned word embeddings and neural networks trained on English data. The method translates and aligns word embeddings from English and Finnish into the endangered languages using dictionary-based methods, then trains a sentiment classifier on English data. The approach demonstrates that state-of-the-art neural models can be effectively applied to endangered languages with minimal resources, primarily a bilingual dictionary. The authors release the sentiment corpus and trained models, contributing valuable resources for future research on these underrepresented languages.

## Method Summary
The method creates word embeddings for endangered Uralic languages by cloning Finnish embeddings and substituting Finnish lemmas with their translations in the target languages using bilingual dictionaries. These embeddings are then aligned with English embeddings using dictionary-based supervised alignment (MUSE method). A Deep Averaging Network (DAN) is trained on English sentiment data and applied to the aligned embeddings for classification. The approach requires minimal resources - primarily a bilingual dictionary and a small sentiment corpus - making it suitable for low-resource languages.

## Key Results
- Sentiment classifier achieves accuracy scores ranging from 56% to 69% across four endangered Uralic languages
- Method successfully transfers sentiment analysis capabilities from English to endangered languages with minimal resources
- The approach demonstrates viability of state-of-the-art neural models for endangered languages with only dictionary requirements

## Why This Works (Mechanism)

### Mechanism 1
Translating word embeddings from a majority language to endangered languages using bilingual dictionaries enables cross-lingual transfer of semantic relationships. The method creates embeddings for endangered languages by replacing Finnish lemmas with their translations, then aligns these with English embeddings using dictionary-based supervised alignment. This allows a sentiment classifier trained on English embeddings to classify sentiment in endangered languages. Core assumption: semantic relationships captured in majority language embeddings are preserved through translation and alignment. Break condition: sparse or inaccurate translation dictionaries cause poor alignment and classifier performance.

### Mechanism 2
Fine-tuning word embeddings on domain-specific text improves coverage and semantic quality for target languages. The method expands vocabulary by including new words from domain text (two books) and adjusts embedding weights based on word co-occurrences using a sliding window approach. Core assumption: domain-specific text contains sentiment-relevant words and contexts that improve embeddings' ability to represent sentiment-bearing words. Break condition: if domain text is too small or unrepresentative, fine-tuning may not improve performance or could cause overfitting.

### Mechanism 3
Using a Deep Averaging Network (DAN) with sentence embeddings derived from word embeddings provides a simple yet effective architecture for sentiment classification. The method creates sentence embeddings by averaging word embeddings, then feeds these through two fully-connected feed-forward layers. Core assumption: averaging word embeddings captures sufficient sentence-level semantics for sentiment classification. Break condition: if sentence semantics require more complex composition than simple averaging (e.g., negation, sarcasm), the DAN may fail to capture sentiment correctly.

## Architecture Onboarding

- **Component map**: Aligned books -> Lemmatization -> Bilingual dictionaries -> Word embeddings (Finnish, English) -> Endangered language embeddings -> MUSE alignment -> Sentence embeddings (averaging) -> DAN (2 FC layers) -> Sentiment classifier (3-layer FC network) -> Evaluation

- **Critical path**: Create embeddings → Align embeddings → Create sentence embeddings → Train classifier → Evaluate on endangered language data

- **Design tradeoffs**: Using averaged word embeddings (simple but may lose word order and compositionality) vs. more complex sentence encoders; dictionary-based alignment (requires dictionaries but supervised) vs. unsupervised alignment (no dictionaries but may be less accurate); fine-tuning on small domain corpus (improves coverage but risks overfitting)

- **Failure signatures**: Low alignment accuracy indicates poor dictionary coverage or quality; sentiment classifier performs similarly on all languages suggests embeddings aren't capturing language-specific sentiment cues; large performance gap between languages with more/fewer dictionary entries indicates dependency on dictionary quality

- **First 3 experiments**: 1) Evaluate alignment accuracy on held-out dictionary data to verify alignment quality; 2) Test sentiment classifier on English dev set to ensure it's learning sentiment distinctions; 3) Evaluate on a subset of endangered language data with known sentiment to check if the approach transfers correctly

## Open Questions the Paper Calls Out

The paper explicitly calls out that their research shows state-of-the-art neural models can be used with endangered languages with the only requirement being a dictionary between the endangered language and a majority language. This highlights the open question of whether this minimal resource requirement can be further reduced or whether the approach can be extended to languages without any available dictionaries.

## Limitations

- The method's effectiveness is fundamentally limited by the quality and coverage of available bilingual dictionaries, which directly impacts both embedding alignment accuracy and downstream sentiment classification performance.
- The use of averaged word embeddings for sentence representation may miss important linguistic phenomena like negation and word order, potentially limiting performance on more complex sentiment expressions.
- The method assumes semantic relationships transfer well through translation, which may not hold for all language pairs or domains.

## Confidence

- **High confidence** in the overall methodology and reported experimental results
- **Medium confidence** in the generalizability to other endangered language pairs
- **Low confidence** in the method's ability to handle complex linguistic phenomena like negation or sarcasm

3. **Linguistic Phenomenon Robustness**: Test the classifier's sensitivity to negation, sarcasm, and other sentiment-modifying constructions by creating controlled test sets with these phenomena and measuring performance degradation compared to simple sentiment expressions.
