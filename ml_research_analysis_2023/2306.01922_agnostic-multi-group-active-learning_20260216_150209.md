# Agnostic Multi-Group Active Learning

## Quick Facts
- arXiv ID: 2306.01922
- Source URL: https://arxiv.org/abs/2306.01922
- Reference count: 40
- Primary result: Novel algorithm combining disagreement-based active learning with absolute error estimation for multi-group settings, achieving improved label complexity over passive learning

## Executive Summary
This paper addresses the problem of multi-group active learning, where the goal is to learn a classifier that performs well across multiple distributions while minimizing label queries. The authors propose a new algorithm that leverages disagreement-based active learning while also estimating absolute error on the complement of the disagreement region. This approach allows for learning in the more challenging agnostic setting where no single hypothesis may achieve zero error across all groups.

The main theoretical contribution shows that the proposed algorithm achieves label complexity that improves upon passive multi-group learning when disagreement-based methods succeed and the number of groups is not too large. The authors provide results for both the realizable case (where each group has a perfect classifier) and the agnostic case (where approximation is necessary). The algorithm maintains and updates a disagreement region across all groups and uses this to guide active label queries.

## Method Summary
The proposed algorithm combines disagreement-based active learning with absolute error estimation on the complement of the disagreement region. It maintains a version space of hypotheses that are consistent with the labeled examples across all groups, and actively queries labels for points where there is disagreement between hypotheses in this space. For the agnostic case, the algorithm uses approximation algorithms to handle the additional complexity of multiple groups. The key innovation is the integration of disagreement-based querying with absolute error estimation, allowing the algorithm to handle the more challenging multi-group agnostic setting while still achieving improved label complexity compared to passive learning.

## Why This Works (Mechanism)
The algorithm works by maintaining a disagreement region across all groups and actively querying labels in this region. The key insight is that disagreement-based methods are effective when the disagreement coefficient is small, and by combining this with absolute error estimation on the complement region, the algorithm can handle the agnostic setting where no perfect classifier exists. The use of approximation algorithms for the agnostic case allows the method to scale to multiple groups while still achieving improved label complexity over passive learning.

## Architecture Onboarding

**Component map:**
ERM oracle -> Version space maintenance -> Disagreement region computation -> Active label querying -> Hypothesis selection

**Critical path:**
1. Initialize version space with all hypotheses
2. Compute disagreement region across all groups
3. Actively query labels for points in disagreement region
4. Update version space based on new labels
5. Repeat until error threshold is met

**Design tradeoffs:**
- Computational cost of maintaining version space across multiple groups
- Accuracy of approximation algorithms in the agnostic case
- Balance between disagreement-based querying and absolute error estimation

**Failure signatures:**
- Large disagreement coefficient θG leading to many label queries
- Computational intractability of maintaining version space for large G
- Poor performance of approximation algorithms in the agnostic case

## Limitations
- Theoretical guarantees rely heavily on worst-case disagreement coefficient θG which may be loose in practice
- Algorithm assumes access to ERM oracle and requires maintaining/updating disagreement region across all groups, potentially computationally expensive
- Logarithmic factors in query complexity bound may dominate for practical values of G and d

## Confidence

**High confidence:** Correctness of algorithm and theoretical analysis of realizable case (Theorem 1)

**Medium confidence:** Agnostic case results due to use of approximation algorithms and complexity of handling multiple groups

**Low confidence:** Practical performance without empirical validation, as theory suggests potential computational challenges
