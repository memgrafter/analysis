# Self-Attention Amortized Distributional Projection Optimization for Sliced Wasserstein Point-Cloud Reconstruction

## Quick Facts
- arXiv ID: 2301.04791
- Source URL: https://arxiv.org/abs/2301.04791
- Reference count: 40
- Key outcome: Self-attention amortized distributional projection optimization using v-DSW distance improves point-cloud reconstruction, transfer learning, and generation tasks.

## Executive Summary
This paper addresses the limitations of max sliced Wasserstein (Max-SW) distance in amortized projection optimization for point-cloud reconstruction. Max-SW suffers from sub-optimal solutions and loss of metricity, while existing amortized models lack permutation invariance and symmetry. The authors propose a self-attention amortized distributional projection optimization framework that replaces Max-SW with distributional sliced Wasserstein distance using a von Mises-Fisher (vMF) projecting distribution, ensuring metricity preservation. Additionally, they design self-attention-based amortized models that are symmetric and permutation invariant, utilizing efficient attention mechanisms for linear complexity. The proposed framework demonstrates superior performance in point-cloud reconstruction, transfer learning, and point-cloud generation tasks on benchmark datasets like ModelNet40 and ShapeNet.

## Method Summary
The proposed method uses self-attention amortized models to predict location parameters for a von Mises-Fisher (vMF) distribution. The v-DSW distance is computed by sampling projection directions from the vMF distribution and averaging the Wasserstein distances between projected point-clouds. The framework employs efficient self-attention architectures to reduce computational complexity from O(m²) to O(m), where m is the number of supports. The method is trained end-to-end using an autoencoder architecture with the v-DSW loss.

## Key Results
- The proposed framework outperforms existing methods in point-cloud reconstruction quality (CD, SW, EMD metrics)
- Improved classification accuracy and generation metrics (JSD, MMD, COV, 1-NNA) on ModelNet40 and ShapeNet datasets
- Efficient attention mechanisms reduce computational complexity while maintaining reconstruction quality
- v-DSW preserves metricity even with sub-optimal amortization, addressing the limitations of Max-SW

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Replacing Max-SW with v-DSW preserves metricity even with sub-optimal amortization.
- Mechanism: The von Mises-Fisher (vMF) distribution is smooth and concentrates mass around a mean direction, so the resulting projected Wasserstein is a true metric for any non-degenerate vMF distribution. This avoids the pseudo-metricity issue of Max-SW, which only guarantees metricity at the global optimum.
- Core assumption: The vMF distribution's smoothness ensures the expected Wasserstein distance remains a metric even when the amortized model predicts a suboptimal location parameter.
- Evidence anchors:
  - [abstract]: "Since v-DSW is a metric with any non-degenerate vMF distribution, its amortized version can guarantee the metricity..."
  - [section]: "Due to the smoothness of vMF, the metricity can be preserved even without a zero amortization gap."
  - [corpus]: Weak evidence; related papers discuss sliced Wasserstein distances but do not address metricity preservation via distributional projections.
- Break condition: If the vMF concentration parameter κ becomes degenerate (e.g., κ → ∞), the distribution collapses to a point mass, and metricity is lost unless the location exactly matches the global optimum.

### Mechanism 2
- Claim: Self-attention amortized models achieve permutation invariance and symmetry, reducing the amortization gap.
- Mechanism: The self-attention operator treats all input points equally, making it invariant to permutations of the point-cloud supports. Symmetry is ensured because the same attention weights are used regardless of input order. This matches the geometric invariances required by the sliced Wasserstein framework.
- Core assumption: The self-attention mechanism's inherent properties (permutation invariance, symmetry) align with the invariances of the optimal slicing distribution.
- Evidence anchors:
  - [abstract]: "we design amortized models based on self-attention architecture... utilize efficient attention mechanisms for linear complexity."
  - [section]: "Proposition 2. Self-attention amortized models are symmetric and permutation invariant."
  - [corpus]: Weak evidence; no direct citations to attention-based amortized models in the sliced Wasserstein context.
- Break condition: If the self-attention implementation uses positional encodings or other asymmetric components, the invariance properties may be broken.

### Mechanism 3
- Claim: Efficient self-attention variants (efficient attention, linear attention) reduce computational complexity from O(m²) to O(m), making the method scalable.
- Mechanism: Efficient attention replaces the full softmax computation with a row-wise softmax and column-wise product, while linear attention uses low-rank projections to approximate the attention matrix. Both reduce the quadratic complexity to linear in the number of supports.
- Core assumption: The approximation errors introduced by these efficient variants do not significantly degrade the quality of the amortized model's predictions.
- Evidence anchors:
  - [abstract]: "... we adopt efficient self-attention architectures to make the computation linear in the number of supports."
  - [section]: "Given X ∈ Rm×d, the efficient self-attention is defined as... The linear self-attention is defined as..."
  - [corpus]: Weak evidence; no direct citations to these specific efficient attention variants in the amortized optimization context.
- Break condition: If the approximation error from the efficient variants becomes too large (e.g., due to very small projected dimensions), the amortized model's predictions may become unreliable.

## Architecture Onboarding

- Component map:
  - Input point-clouds X and Y -> Concatenated matrices X' and Y' -> Amortized model (self-attention) -> Location parameter ϵ for vMF distribution -> v-DSW computation -> Loss

- Critical path:
  1. Encode point-clouds into latent representations
  2. Apply amortized model to predict vMF location parameter
  3. Sample projection directions from vMF distribution
  4. Compute projected Wasserstein distances
  5. Aggregate and backpropagate loss

- Design tradeoffs:
  - Using v-DSW instead of Max-SW trades off some discriminative power for guaranteed metricity
  - Efficient attention variants reduce computational cost but may introduce approximation errors
  - Choosing the concentration parameter κ involves a tradeoff between smoothness and concentration of the slicing distribution

- Failure signatures:
  - High reconstruction error despite low v-DSW loss may indicate issues with the autoencoder architecture or training
  - Instability in the amortized model's predictions may suggest problems with the attention mechanism or the vMF sampling procedure
  - Degenerate vMF distributions (e.g., κ → ∞) may lead to loss of metricity

- First 3 experiments:
  1. Train the autoencoder with Max-SW and compare reconstruction quality to v-DSW to verify the metricity issue
  2. Replace standard self-attention with efficient attention in the amortized model and measure the impact on computational cost and reconstruction quality
  3. Vary the concentration parameter κ and observe its effect on the tradeoff between smoothness and discriminative power of the v-DSW
