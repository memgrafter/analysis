# Improving Adaptive Conformal Prediction Using Self-Supervised Learning

## Quick Facts
- arXiv ID: 2302.12238
- Source URL: https://arxiv.org/abs/2302.12238
- Reference count: 32
- Improves conformal prediction intervals by leveraging self-supervised learning to make them more adaptive to prediction difficulty

## Executive Summary
This paper introduces Self-Supervised Conformal Prediction (SSCP), a framework that enhances the efficiency of conformal prediction intervals by incorporating self-supervised learning signals. SSCP trains an auxiliary model with a self-supervised pretext task alongside the predictive model, using the self-supervised error as an additional feature to estimate nonconformity scores. The authors demonstrate that SSCP improves prediction intervals, particularly for challenging samples and sparse regions, by reducing interval width while maintaining valid coverage guarantees.

## Method Summary
SSCP extends conformal residual fitting by augmenting the residual model with self-supervised errors. The method trains both a predictive model and a self-supervised model (e.g., VIME or autoencoder) on labeled data, then uses the self-supervised model's errors as features for the residual model. The residual model, trained on a separate dataset, estimates the conformal normalization function that adapts interval widths based on prediction difficulty. The framework can leverage both labeled and unlabeled data to improve the self-supervised model's performance.

## Key Results
- SSCP improves prediction interval efficiency by reducing width on challenging samples and in sparse regions
- The method reduces interval deficit (when true values fall outside intervals) and excess (extra width beyond needed)
- Improvements are demonstrated across multiple UCI regression datasets including concrete, community, star, bike, blog, and Facebook

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Self-supervised loss acts as a proxy for prediction difficulty, improving residual estimation.
- Mechanism: SSCP uses the error from a self-supervised task (Lss) as an additional feature to the conformal normalization model. When Lss correlates with the predictive model's errors, the normalization model can better estimate the residuals, resulting in more adaptive intervals.
- Core assumption: The self-supervised error Lss has a relationship with the predictive model's errors for individual samples.
- Evidence anchors:
  - [abstract] "We train an auxiliary model with a self-supervised pretext task on top of an existing predictive model and use the self-supervised error as an additional feature to estimate nonconformity scores."
  - [section 4.2] "If this error has a relationship with the error of the main model, then it can provide a useful input feature to the residual model."
  - [corpus] Weak evidence: only general conformal prediction neighbors, no direct discussion of self-supervised error relationships.
- Break condition: If the self-supervised task's error is uncorrelated with the predictive model's errors, the additional feature provides no useful signal.

### Mechanism 2
- Claim: Unlabeled data improves conformal prediction intervals by enabling better self-supervised learning.
- Mechanism: By training the self-supervised model on both labeled and unlabeled data, SSCP learns richer representations that improve the self-supervised error signal, which in turn improves residual estimation and interval adaptation.
- Core assumption: The self-supervised task can learn meaningful representations from unlabeled data that transfer to improving predictive error estimation.
- Evidence anchors:
  - [abstract] "We empirically demonstrate the value of unlabeled data to improve the quality of conformal prediction intervals beyond a standard application of self-supervision representation learning."
  - [section 5.2.2] "We evaluate the effect for varying proportions p of labeled examples. Dunlabeled augments the dataset used to train the self-supervised model."
  - [corpus] Weak evidence: no direct discussion of unlabeled data improving conformal prediction intervals.
- Break condition: If the self-supervised task cannot learn useful representations from unlabeled data, or if the learned representations do not correlate with prediction difficulty, the unlabeled data provides no benefit.

### Mechanism 3
- Claim: SSCP improves intervals most for samples in sparse regions where standard CRF is inefficient.
- Mechanism: In sparse regions, the conformal normalization model (σ) struggles to accurately estimate residuals, leading CRF to use overly conservative intervals. SSCP's self-supervised signal helps σ better estimate residuals in these challenging regions, resulting in narrower intervals.
- Core assumption: Sparse regions are where the predictive model makes larger errors, and the self-supervised error captures this difficulty.
- Evidence anchors:
  - [section 5.3] "In the denser regions, CRF has narrower intervals, similar to SSCP. Whilst, in the sparser regions, CRF often has much wider prediction intervals compared to SSCP."
  - [section 5.1] "Since the residuals are a function of L, this self-supervised error provides a useful feature."
  - [corpus] Weak evidence: only general conformal prediction neighbors, no direct discussion of sparse region improvements.
- Break condition: If the self-supervised error does not capture the difficulty in sparse regions, or if the predictive model's errors are not larger in sparse regions, SSCP provides no benefit in these areas.

## Architecture Onboarding

- Component map:
  - Predictive Model (f) -> Self-Supervised Model (fss) -> Conformal Normalization Model (σ) -> Calibration Set (Dcal) -> Critical Nonconformity Score (ε) -> Test Set (Dtest) -> Adaptive Intervals [l(x), r(x)]

- Critical path: Dtrain → Predictive Model (f) + Self-Supervised Model (fss) → Dres + Self-Supervised Errors → Conformal Normalization Model (σ) → Dcal → Critical Nonconformity Score (ε) → Test Set (Dtest) → Adaptive Intervals [l(x), r(x)]

- Design tradeoffs:
  - Self-Supervised Task Selection: The choice of pretext task impacts the correlation between self-supervised errors and predictive errors. Tasks like VIME may perform better than simple autoencoders.
  - Data Splits: Using separate Dres avoids overfitting σ to training residuals but requires more data. Practitioners might consider double-dipping on Dtrain for better performance.
  - Encoder Sharing: Sharing the encoder between predictive and self-supervised models enforces a relationship between the tasks but may limit the flexibility of each model.

- Failure signatures:
  - No improvement over CRF: Indicates the self-supervised task's errors are uncorrelated with predictive errors.
  - Worse performance than CRF: Suggests the self-supervised task introduces noise or the pretext task is poorly chosen.
  - Overfitting to training data: Observed if Dres is not used, leading to σ learning training residuals instead of generalizable patterns.

- First 3 experiments:
  1. Implement SSCP with a simple autoencoder as the self-supervised task on a small tabular dataset (e.g., concrete) and compare width, deficit, and excess to CRF.
  2. Evaluate the correlation between self-supervised errors and predictive model errors across different samples to identify if the signal is strongest for challenging or sparse regions.
  3. Test SSCP with different proportions of labeled vs. unlabeled data to quantify the benefit of unlabeled data and identify the optimal ratio for a given dataset.

## Open Questions the Paper Calls Out

- Open Question 1: What is the optimal self-supervised task for improving conformal prediction intervals across different domains?
  - Basis in paper: [inferred] The paper mentions that the choice and nature of the SSL task is impactful and discusses evaluating alternative modes of self-supervision.
  - Why unresolved: The paper only evaluates VIME and autoencoder as examples, suggesting more research is needed to identify optimal tasks.
  - What evidence would resolve it: Systematic evaluation of various SSL tasks (e.g., contrastive learning, masked language modeling) across multiple domains to determine which consistently improves conformal prediction intervals.

- Open Question 2: How can we design SSL tasks specifically tailored for conformal prediction to maximize the correspondence between SSL loss and predictive model errors?
  - Basis in paper: [explicit] The paper discusses that a stronger relationship between the self-supervised loss and the predictive model errors should result in a better residual model and more efficient prediction intervals.
  - Why unresolved: The paper only uses existing SSL tasks (VIME, autoencoder) and doesn't explore designing tasks specifically for this purpose.
  - What evidence would resolve it: Development and evaluation of novel SSL tasks designed to explicitly maximize the correlation between SSL loss and predictive errors, with empirical validation showing improved conformal interval efficiency.

- Open Question 3: Can SSCP be effectively applied to non-tabular data modalities such as images and text?
  - Basis in paper: [explicit] The paper mentions that future work could explore applying self-supervision to other data modalities where SSL tasks differ from the tabular setting.
  - Why unresolved: The paper only evaluates SSCP on tabular data and doesn't investigate its performance on other modalities.
  - What evidence would resolve it: Empirical studies applying SSCP to image and text datasets using appropriate SSL tasks for each modality, demonstrating improvements in conformal interval efficiency.

## Limitations

- Weak empirical evidence for the core mechanism - the relationship between self-supervised errors and predictive model errors is not quantitatively analyzed
- Limited evaluation to only two self-supervised task types (VIME and autoencoder) without systematic comparison
- No investigation of SSCP's performance on non-tabular data modalities where SSL tasks differ significantly

## Confidence

- Confidence in the claimed improvements is Medium
  - Experimental results show consistent gains in efficiency metrics (width, deficit, excess) over CRF
  - However, lack of ablations testing different self-supervised tasks, correlation analysis between errors, and comparison to other adaptive conformal methods limits confidence in the generality of the findings
