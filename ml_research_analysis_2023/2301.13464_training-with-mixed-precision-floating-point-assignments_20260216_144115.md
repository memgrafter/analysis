# Training with Mixed-Precision Floating-Point Assignments

## Quick Facts
- arXiv ID: 2301.13464
- Source URL: https://arxiv.org/abs/2301.13464
- Reference count: 34
- This paper addresses the problem of optimizing memory-accuracy tradeoffs in low-precision floating-point training of deep neural networks

## Executive Summary
This paper tackles the challenge of mixed-precision training in deep neural networks, where the goal is to reduce memory usage while maintaining training accuracy. The authors prove that finding the optimal memory-accuracy tradeoff is NP-hard due to the exponential number of possible precision assignments and the complexity of accuracy prediction. They propose a practical heuristic algorithm that assigns low precision to tensors based on their size, starting with the largest tensors first. The method also includes an overflow handling technique that promotes tensors to high precision during training when excessive overflow is detected, preventing training divergence while using minimal additional memory.

## Method Summary
The authors introduce a heuristic algorithm for mixed-precision training that takes a desired upper bound on memory usage as input. The algorithm initializes all tensors to high precision and then demotes them to low precision in decreasing order of size until the memory constraint is met. During training, an overflow detection mechanism monitors forward tensors and promotes those with excessive overflow ratios back to high precision. This approach prioritizes memory savings by targeting larger tensors first while maintaining training stability through dynamic precision promotion. The method is designed to be compatible with existing frameworks and can be applied to various model architectures.

## Key Results
- The proposed method typically provides >2x memory reduction while maintaining training accuracy on image classification tasks
- The algorithm gives further memory reductions by trading off accuracy when desired
- The overflow handling technique prevents training divergence while using less than 3% of maximum model aggregate memory

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Tensor size ordering for precision demotion enables memory-accuracy tradeoff exploration
- **Mechanism**: The algorithm assigns low precision to tensors in decreasing order of size, optimizing memory savings while controlling accuracy loss
- **Core assumption**: Larger tensors contribute more to memory footprint and their demotion provides better memory savings for acceptable accuracy loss
- **Evidence anchors**:
  - [abstract] "our algorithm takes as input a single parameter giving a desired upper bound on the model aggregate. Starting with the largest tensor in the model, tensors are assigned low precision in size order"
  - [section] "we construct a precision assignment π as follows: initialize π to the all-high-precision assignment and update π by demoting the precision of all tensors in a group to low precision, one group at a time, until the low-precision ratio of π becomes greater than r"
  - [corpus] Weak - related papers focus on quantization search but not size-based tensor ordering
- **Break condition**: If tensor size is not correlated with memory impact, or if precision demotion order significantly affects accuracy unpredictably

### Mechanism 2
- **Claim**: Overflow promotion prevents training divergence while using minimal additional memory
- **Mechanism**: During training, tensors with excessive overflow ratios are promoted from low to high precision, maintaining training stability
- **Core assumption**: Overflow events in specific tensors signal impending training divergence that can be prevented by precision promotion
- **Evidence anchors**:
  - [abstract] "We present a novel technique that can handle an excessive number of overflows arising in training while using a small amount of additional memory"
  - [section] "After each gradient computation we update the current precision assignment π by promoting to high precision (i.e., C(t, hi)) any forward tensor whose overflow ratio is greater than a given threshold Θ"
  - [section] "The overﬂow handling technique is not speciﬁc to our algorithm and can be applied to other precision assignment methods"
- **Break condition**: If overflow detection is too expensive, or if promoted tensors cause cascading memory increases

### Mechanism 3
- **Claim**: NP-hardness of memory-accuracy tradeoff problem justifies heuristic approach
- **Mechanism**: The exponential number of precision assignments and complex accuracy prediction make exact optimization infeasible
- **Core assumption**: The space of possible precision assignments is too large for exhaustive search, and accuracy prediction lacks analytical solutions
- **Evidence anchors**:
  - [abstract] "We prove that the memory-accuracy tradeoff problem is theoretically difficult (namely NP-hard) partly due to the exponential number of possible mixed precision assignments"
  - [section] "We prove that the memory-accuracy tradeoff problem from §3.2 is NP-hard by showing that there is a polynomial-time reduction from the knapsack problem to this problem"
  - [corpus] Weak - no direct corpus evidence on NP-hardness of precision assignment problems
- **Break condition**: If new analytical methods emerge for accuracy prediction, or if hardware constraints limit the search space

## Limitations

- The size-based tensor ordering heuristic lacks comprehensive ablation studies comparing alternative ordering strategies
- The computational overhead of overflow detection and its impact on training time remains unquantified
