# Improved Benthic Classification using Resolution Scaling and SymmNet Unsupervised Domain Adaptation

## Quick Facts
- **arXiv ID**: 2303.10960
- **Source URL**: https://arxiv.org/abs/2303.10960
- **Reference count**: 30
- **Primary result**: Combines resolution scaling, SymmNet UDA, and bilinear pooling to improve benthic morphospecies classification across domain shifts, achieving up to 28% accuracy gains.

## Executive Summary
This paper addresses the challenge of classifying benthic morphospecies from images acquired by different Autonomous Underwater Vehicle (AUV) surveys, which suffer from domain shifts due to changes in camera systems, imaging altitude, illumination, and water column properties. The authors propose a framework that combines Unsupervised Domain Adaptation (UDA) using SymmNet, resolution scaling to normalize spatial resolution differences, and an efficient bilinear pooling layer for more discriminative features. They test their approach on two datasets with images from different AUV surveys and show significant improvements in classification accuracy, with increases of up to 28% compared to using a classifier trained without scaling or domain adaptation.

## Method Summary
The framework preprocesses benthic images by scaling lower resolution images to match higher resolution images (224x224 pixels) to normalize spatial resolution differences between AUV surveys. It uses a ResNet50 backbone with an efficient bilinear pooling layer (Two-Level Kronecker Product Factorization) to generate discriminative features. The SymmNet classifier aligns features between domains using adversarial training with domain and class-level confusion losses. The model is trained using labeled source data and unlabeled target data, minimizing cross-entropy, domain discrimination, class-level confusion, and entropy minimization losses.

## Key Results
- Classification accuracy improved by up to 28% when combining scaling, SymmNet UDA, and bilinear pooling compared to baseline without adaptation.
- SymmNet UDA improved classification accuracy by 5-25% on target domain datasets compared to no adaptation.
- Resolution scaling alone improved accuracy by up to 11% by normalizing spatial resolution differences between surveys.

## Why This Works (Mechanism)

### Mechanism 1
- Claim: SymmNet's class-level adversarial training improves feature alignment between source and target domains, leading to better classification performance.
- Mechanism: SymmNet uses a symmetric design with separate source and target classifiers (Cs and Ct) that are trained together. The network minimizes domain discrimination loss (Est_dom) which encourages the classifiers to distinguish between source and target samples. Simultaneously, class-level confusion loss (Fst_class) aligns features at the class level, making the target classifier more discriminative.
- Core assumption: The source and target domains share the same label space and the feature distributions can be aligned without losing class-specific information.
- Evidence anchors:
  - [abstract] "SymmNet uses an adversarial loss applied at the class level producing alignment of the source and target distribution at both the domain and class level."

  - [corpus] Weak evidence - no direct mention of SymmNet in corpus papers, but related work on domain adaptation exists.
- Break condition: If the source and target domains have significantly different label spaces or the domain shift is too large for alignment to preserve class-specific information.

### Mechanism 2
- Claim: Scaling images to match spatial resolution reduces domain shift caused by differences in camera systems and imaging altitude between AUV surveys.
- Mechanism: By cropping and resizing images from the lower resolution survey to match the higher resolution survey, the framework normalizes the spatial scale of objects in the images. This reduces the variation in object size and appearance between domains.
- Core assumption: The spatial resolution difference between surveys is the primary source of domain shift, and normalizing this difference will improve classifier performance.
- Evidence anchors:
  - [abstract] "We explore the impact to classification performance when an efficient bilinear pooling layer that requires a small number of parameters with fast inference time is applied."
  - [section] "Spatial resolution may differ between AUV surveys due to changes to the camera (e.g. imager size and/or resolution, lens field of view, etc) and altitude used during the mission."
  - [corpus] Weak evidence - no direct mention of spatial resolution scaling in corpus papers, but related work on image normalization exists.
- Break condition: If other factors like illumination or water column properties contribute more to domain shift than spatial resolution, scaling alone may not be sufficient.

### Mechanism 3
- Claim: The efficient bilinear pooling layer with Two-Level Kronecker Product Factorization (TKPF) provides more discriminative features for fine-grained benthic classification.
- Mechanism: The bilinear pooling layer calculates a low-rank approximation of the outer product of the input feature map using smaller matrices A and B. This captures pairwise feature interactions more efficiently than standard pooling, potentially improving classification of visually similar benthic species.
- Core assumption: Pairwise feature interactions are important for distinguishing between fine-grained benthic classes, and the low-rank approximation can capture these interactions effectively.
- Evidence anchors:
  - [abstract] "We explore the impact to classification performance when an efficient bilinear pooling layer that requires a small number of parameters with fast inference time is applied."
  - [section] "Bilinear pooling has been shown to provide more discriminative features from a deep learning Convolutional Neural Network (CNN) model [18], [19]."
  - [corpus] Weak evidence - no direct mention of bilinear pooling in corpus papers, but related work on feature extraction exists.
- Break condition: If the bilinear pooling layer does not learn more discriminative features than standard pooling, or if the computational overhead outweighs the benefits.

## Architecture Onboarding

- Component map: Image scaling -> ResNet50 backbone -> Bilinear pooling layer -> SymmNet classifier -> Cross-entropy loss -> Domain discrimination loss -> Class-level confusion loss -> Domain-level confusion loss -> Entropy minimization loss

- Critical path:
  1. Scale images to match spatial resolution.
  2. Extract features using ResNet50 backbone.
  3. Apply bilinear pooling to generate discriminative features.
  4. Train SymmNet classifier using labeled source data and unlabeled target data.
  5. Minimize domain discrimination, class-level confusion, and entropy minimization losses.

- Design tradeoffs:
  - Bilinear pooling vs. standard pooling: Bilinear pooling provides more discriminative features but increases computational complexity.
  - SymmNet vs. other UDA methods: SymmNet aligns features at both domain and class levels, but may be more sensitive to hyperparameter tuning.

- Failure signatures:
  - Poor classification performance on target domain: Indicates insufficient domain adaptation or feature alignment.
  - High computational cost: Suggests the bilinear pooling layer or SymmNet may be too complex for the given hardware.

- First 3 experiments:
  1. Train a classifier on labeled source data without any domain adaptation or scaling to establish a baseline.
  2. Apply scaling to normalize spatial resolution and train a classifier to evaluate the impact of resolution normalization.
  3. Combine scaling and SymmNet UDA to assess the combined effect on classification performance.
