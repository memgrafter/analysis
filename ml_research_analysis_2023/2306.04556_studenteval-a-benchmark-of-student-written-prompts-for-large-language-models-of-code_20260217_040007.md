# StudentEval: A Benchmark of Student-Written Prompts for Large Language Models of Code
## Quick Facts
- arXiv ID: 2306.04556
- Source URL: https://arxiv.org/abs/2306.04556
- Reference count: 30
- Key outcome: A benchmark using student-written prompts that better discriminates between Code LLM models than existing expert-written benchmarks

## Executive Summary
StudentEval introduces a novel benchmark for evaluating Code Large Language Models using prompts written by beginning programmers rather than experts. The benchmark contains 1,749 prompts for 48 problems created by students who had completed only one semester of Python programming. Unlike existing benchmarks that use carefully crafted expert prompts, StudentEval captures the natural variability and imperfections in how students actually express programming problems. The authors evaluated five state-of-the-art Code LLMs on this benchmark and found that it provides better discrimination between model capabilities while revealing important reliability issues when using these models as teaching tools.

## Method Summary
The authors collected prompts from students enrolled in an introductory Python programming course at a single university. Students were asked to write problem descriptions in natural language that could be given to someone to implement as Python code. Each of the 48 problems received multiple student-written prompts, creating a dataset of 1,749 total prompts. The evaluation methodology involved submitting these prompts to five different Code LLMs and analyzing the generated programs for correctness. The study focused on basic programming concepts like string manipulation, list operations, and simple algorithms. The authors measured both the pass@k metric (number of problems solved within k attempts) and examined the semantic diversity of programs generated from successful prompts.

## Key Results
- StudentEval better discriminates between Code LLM models than existing expert-written benchmarks like HumanEval
- Larger models show significantly better performance on student-written prompts compared to smaller models
- Successful prompts can generate multiple semantically distinct programs, revealing reliability issues for educational use

## Why This Works (Mechanism)
StudentEval works because it captures the authentic way beginners express programming problems, which differs substantially from how experts formulate prompts. Beginning programmers often use imprecise language, omit important constraints, or express problems in ways that require significant interpretation. This creates a more challenging and realistic evaluation scenario that better reveals the strengths and weaknesses of Code LLMs in real-world educational contexts.

## Architecture Onboarding
**Component Map:** Student -> Prompt Collection -> Benchmark Construction -> LLM Evaluation -> Performance Analysis -> Reliability Assessment
**Critical Path:** Prompt collection and benchmark construction form the foundation, followed by systematic evaluation of multiple LLMs, then analysis of both performance metrics and program semantics.
**Design Tradeoffs:** The benchmark prioritizes authenticity and variability over consistency, accepting that student prompts may contain errors or ambiguities to better reflect real-world usage scenarios.
**Failure Signatures:** Models may fail when prompts lack precision, contain ambiguous requirements, or use beginner-level language patterns that differ from typical training data.
**First Experiments:** 1) Evaluate a single LLM on 10-20 student prompts to establish baseline performance patterns, 2) Compare expert-written vs student-written prompts for the same problems to quantify difficulty differences, 3) Analyze semantic diversity in outputs from successful prompts to identify reliability patterns.

## Open Questions the Paper Calls Out
The paper acknowledges that the student population is limited to one class at one university, raising questions about generalizability across different educational contexts. It also notes that the benchmark focuses only on introductory-level Python problems, leaving open how Code LLMs would perform on student prompts for more advanced programming concepts or different programming languages.

## Limitations
- Limited to Python programming language only
- Student population comes from single university class, limiting generalizability
- Focuses on introductory-level problems, not applicable to advanced programming contexts
- Evaluation conducted on only five Code LLM models

## Confidence
- High confidence: The finding that existing benchmarks use expert-written prompts while StudentEval uses student-written prompts is well-supported. The observation that larger models perform better on student-written prompts is strongly evidenced.
- Medium confidence: The claim that StudentEval better discriminates between models than HumanEval is supported but could benefit from more extensive comparative analysis. The assertion about reliability issues is reasonable but requires further investigation.
- Low confidence: Generalizability to other programming languages and educational contexts is not established due to limited scope.

## Next Checks
1. Replicate the evaluation on additional Code LLMs not included in the original study to verify the discrimination power of StudentEval.
2. Conduct a cross-institutional study using StudentEval with prompts from students at different universities and varying educational backgrounds.
3. Extend the benchmark to include prompts from students learning other programming languages to test generalizability beyond Python.
