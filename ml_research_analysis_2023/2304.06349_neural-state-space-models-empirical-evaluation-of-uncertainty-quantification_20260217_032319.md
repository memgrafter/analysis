# Neural State-Space Models: Empirical Evaluation of Uncertainty Quantification

## Quick Facts
- arXiv ID: 2304.06349
- Source URL: https://arxiv.org/abs/2304.06349
- Reference count: 6
- One-line primary result: Bayesian probabilistic framework with Laplace approximation effectively detects out-of-distribution regimes in neural state-space models

## Executive Summary
This paper addresses uncertainty quantification in neural state-space models for nonlinear dynamical systems. The authors propose a Bayesian probabilistic framework using Laplace approximation to derive posterior distributions for neural network parameters and output predictions. They introduce a "surprise index" metric to detect out-of-distribution regimes where model predictions may be unreliable. The methodology is tested on a modified Wiener-Hammerstein system identification benchmark, demonstrating the ability to flag potential prediction failures in unseen operating conditions through increasing surprise index values and widening credible intervals.

## Method Summary
The authors frame neural state-space model learning in a Bayesian probabilistic setting, using Laplace approximation to obtain tractable Gaussian posterior distributions for network parameters. They linearize the neural network around the MAP estimate to compute predictive posterior covariances, enabling construction of credible intervals. A surprise index is defined to aggregate normalized uncertainty measures across time steps, providing a scalar metric to assess prediction reliability and detect out-of-distribution inputs. The approach is implemented on a modified Wiener-Hammerstein benchmark using a single hidden layer neural network trained with Adam and L-BFGS optimization.

## Key Results
- FIT index performance: 98.1% (multisine 1), 97.7% (multisine 2), 93.9% (multisine 3), 87.8% (multisine 4)
- Uncertainty interval coverage: 99.2%, 98.6%, 96.1%, 80.6% for the four test signals
- Surprise index values: 0.33%, 0.43%, 2.10%, 4.03% for the four test signals, increasing with extrapolation difficulty
- Credible intervals successfully widen in out-of-distribution regimes, signaling reduced prediction reliability

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Laplace approximation provides tractable uncertainty estimates for neural state-space model parameters
- Mechanism: Laplace approximation centers a Gaussian distribution around the MAP estimate, using the inverse Hessian of the negative log-likelihood as the covariance matrix
- Core assumption: The posterior distribution is unimodal and well-approximated by a Gaussian near the MAP point
- Evidence anchors:
  - [abstract] "We frame the learning problem in a Bayesian probabilistic setting and obtain posterior distributions for the neural network's weights and outputs through approximate inference techniques"
  - [section] "The parameter posterior p(θ|D) is approximated using the Laplace's method...centered around the maximum a posteriori (MAP) point estimate θMAP"
  - [corpus] No direct corpus evidence for Laplace approximation performance in state-space models
- Break condition: The posterior is multi-modal or has heavy tails that cannot be captured by a Gaussian approximation

### Mechanism 2
- Claim: Surprise index detects out-of-distribution inputs by comparing prediction uncertainty to prediction magnitude
- Mechanism: The surprise index aggregates normalized diagonal entries of J*PθMAPJ*⊤ across time steps, where J* is the Jacobian of predictions w.r.t. parameters
- Core assumption: In-distribution data produces low surprise index values while out-of-distribution data produces high values due to increased epistemic uncertainty
- Evidence anchors:
  - [abstract] "we construct credible intervals on the outputs and define a surprise index which can effectively diagnose usage of the model in a potentially dangerous out-of-distribution regime"
  - [section] "For a full sequence u∗ of length N, we introduce in this paper an aggregate surprise index s(u∗) defined by: s(u∗) = 100× ∑N−1 k=0 √((J*PθMAPJ*⊤)kk)/∑N−1 k=0|ˆy*k(θMAP)| (%)"
  - [corpus] No direct corpus evidence for surprise index effectiveness
- Break condition: The relationship between input characteristics and prediction uncertainty breaks down, or the metric fails to distinguish between high uncertainty from noise vs. out-of-distribution inputs

### Mechanism 3
- Claim: Linearization-based approximation enables tractable computation of predictive posterior covariance
- Mechanism: The neural network output is linearized around θMAP to obtain y* ~ N(ˆy*(θMAP), J*PθMAPJ*⊤ + 1/βI), where the first term captures epistemic uncertainty and the second captures aleatoric uncertainty
- Core assumption: The neural network predictions are approximately linear in the parameter space near θMAP
- Evidence anchors:
  - [section] "Our approximation of the posterior predictive distribution is based on a linearization of the neural network model with respect to its parameters about the MAP estimate"
  - [section] "Even when the approximate p(θ|D) has a simple structure, exact solution of the integral above is intractable and further approximations/simplifications are required"
  - [corpus] No direct corpus evidence for linearization effectiveness in state-space models
- Break condition: The neural network predictions are highly nonlinear in the parameter space, making the linearization approximation poor

## Architecture Onboarding

- Component map: Data preprocessing -> MAP estimation via stochastic gradient descent -> Gradient computation via recursive sensitivity equations -> Laplace approximation for posterior covariance -> Linearization for predictive posterior -> Surprise index computation
- Critical path: MAP estimation -> Gradient computation -> Laplace approximation -> Linearization
- Design tradeoffs: Laplace approximation vs. sampling methods (accuracy vs. computational cost), linearization vs. full predictive integration (tractability vs. accuracy)
- Failure signatures: Surprise index fails to detect OOD regimes, credible intervals poorly calibrated (coverage far from nominal), computational cost becomes prohibitive for large models
- First 3 experiments:
  1. Verify MAP estimation converges and produces reasonable parameter values on a simple dataset
  2. Test gradient computation via recursive sensitivity equations vs. naive approach on small dataset
  3. Validate Laplace approximation by comparing to MCMC on a simple model with known posterior

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How do different approximate inference techniques (e.g., Hamiltonian Monte Carlo, variational inference) compare to the Laplace approximation in terms of uncertainty quantification accuracy for neural state-space models?
- Basis in paper: [explicit] The authors mention that "other inference approximation techniques may be adopted to obtain a richer and more accurate characterization of the uncertainty" and suggest that "Hamiltonian Monte Carlo may be considered to overcome the limiting assumptions (e.g. uni-modality) of the currently used Laplace approximation."
- Why unresolved: The paper only uses the Laplace approximation, and a direct comparison with other techniques is not performed.
- What evidence would resolve it: Empirical studies comparing Laplace approximation with alternative inference methods on the same system identification benchmarks, measuring uncertainty calibration and computational efficiency.

### Open Question 2
- Question: How effective are uncertainty quantification methods at detecting out-of-distribution inputs across different dynamical system classes beyond the Wiener-Hammerstein benchmark?
- Basis in paper: [explicit] The authors state that "tools like the surprise index may be used to choose informative input signals to be used for model training/reﬁnement" and suggest devising "speciﬁc benchmarks and performance metrics should be devised and shared with the system identiﬁcation community."
- Why unresolved: The paper only tests on a single modified Wiener-Hammerstein system, limiting generalizability.
- What evidence would resolve it: Testing uncertainty quantification methods on diverse dynamical system benchmarks (e.g., chemical processes, mechanical systems) and evaluating their performance in detecting out-of-distribution regimes.

### Open Question 3
- Question: How can the surprise index be integrated into active learning frameworks for system identification to improve model reliability?
- Basis in paper: [explicit] The authors suggest that "tools like the surprise index may be used to choose informative input signals to be used for model training/reﬁnement" and mention "experiment design and active learning in the context of system identiﬁcation with neural state-space models."
- Why unresolved: The paper only introduces the surprise index as a diagnostic tool but does not explore its use in active learning.
- What evidence would resolve it: Developing and testing active learning algorithms that use the surprise index to guide data collection and model refinement, demonstrating improved model performance on out-of-distribution inputs.

## Limitations
- Laplace approximation assumes Gaussian posteriors which may not capture multi-modal or heavy-tailed distributions common in deep learning
- Linearization introduces additional approximation error, particularly for highly nonlinear models
- Uncertainty quantification effectiveness depends on the specific relationship between input characteristics and prediction uncertainty

## Confidence

**High**: The Bayesian framework and Laplace approximation methodology are well-established and correctly implemented
**Medium**: The surprise index metric effectively detects OOD regimes in the tested benchmark, but generalizability to other domains requires validation
**Low**: The uncertainty quantification is perfectly calibrated across all operating conditions
