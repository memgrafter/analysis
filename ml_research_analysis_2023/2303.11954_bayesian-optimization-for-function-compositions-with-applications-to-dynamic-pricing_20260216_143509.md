# Bayesian Optimization for Function Compositions with Applications to Dynamic Pricing

## Quick Facts
- arXiv ID: 2303.11954
- Source URL: https://arxiv.org/abs/2303.11954
- Reference count: 36
- This paper proposes computationally efficient Bayesian optimization algorithms for composite functions using independent Gaussian process models for each constituent function.

## Executive Summary
This paper addresses Bayesian optimization of composite functions where the form of composition is known but constituent functions are expensive to evaluate. The authors propose Expected Improvement (EI) and Upper Confidence Bound (UCB) based algorithms that model each constituent function independently using Gaussian processes. This approach is more computationally efficient than existing methods for composite function optimization. The algorithms are evaluated on standard test functions and applied to dynamic pricing problems in revenue management, demonstrating significant improvements in both regret and runtime compared to vanilla Bayesian optimization and state-of-the-art composite function algorithms.

## Method Summary
The proposed method models each constituent function in a composite function independently using Gaussian processes, rather than modeling the entire composite function as a single multi-output GP. For the cUCB acquisition function, the algorithm uses the posterior mean plus scaled variance of each constituent GP as a surrogate for the constituent function value. For cEI, Monte Carlo sampling is used to estimate the expected improvement by sampling from the M-variate normal distribution of constituent function uncertainties. The independent GP modeling approach allows parallelization of posterior updates and eliminates expensive matrix inversion operations required in multi-output GP covariance matrix computations.

## Key Results
- The proposed cUCB algorithm is 3-4 times faster than existing methods while achieving better optimization results
- cEI and cUCB significantly outperform vanilla Bayesian optimization and state-of-the-art composite function algorithms in terms of both regret and runtime
- On standard test functions (Langermann, Dixon-Price, Ackley), the proposed algorithms show improved regret performance compared to baselines
- The algorithms successfully handle dynamic pricing scenarios with different demand model assumptions (independent, correlated, identical price models)

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Modeling each constituent function independently with Gaussian processes reduces computational complexity compared to modeling the entire composite function as a single multi-output GP.
- Mechanism: Independent GPs allow parallelization of posterior updates and eliminate the need for matrix inversion operations required in multi-output GP covariance matrix computations.
- Core assumption: The constituent functions in the composition are sufficiently independent that modeling them separately captures the essential structure without significant information loss.
- Evidence anchors:
  - [abstract] "By assuming an independent Gaussian process (GP) model for each of the constituent black-box function"
  - [section] "To alleviate these problems, in this work, we model the constituent functions using independent GPs. This modelling approach allows us to train GPs for each output independently and hence the posterior GP update can be parallelized."
  - [corpus] Weak evidence - no direct citations discussing computational benefits of independent GP models for composite functions.
- Break condition: The constituent functions have strong correlations that are not captured by independent modeling, leading to poor optimization performance.

### Mechanism 2
- Claim: The cUCB acquisition function balances exploration and exploitation by using the posterior mean plus scaled variance as a surrogate for constituent function values.
- Mechanism: The UCB-style approach uses the mean term for exploitation (guidance toward known good regions) and the variance term for exploration (encouraging sampling in uncertain regions), with the scaling factor β controlling this trade-off.
- Core assumption: The posterior GP variance provides a meaningful measure of uncertainty that can guide exploration effectively.
- Evidence anchors:
  - [abstract] "We propose a UCB based acquisition function that uses the current mean plus scaled variance of the posterior GP at a point as a surrogate for the constituent function at that point."
  - [section] "As shown by Srinivas et al. [28], while the mean term in the surrogate guides exploitation, it is the variance of the posterior GP at a point that allows for suitable exploration."
  - [corpus] Weak evidence - no direct citations discussing UCB for composite function optimization specifically.
- Break condition: The scaling factor β is not properly tuned, leading to either insufficient exploration or excessive exploitation.

### Mechanism 3
- Claim: The cEI acquisition function uses Monte Carlo sampling to estimate the expected improvement for composite functions while leveraging independent GP models.
- Mechanism: For each candidate point, the algorithm samples from the M-variate normal distribution of the constituent function uncertainties, evaluates the composite function composition, and averages the improvement over multiple samples.
- Core assumption: Monte Carlo sampling can provide a good approximation of the expected improvement even with independent GP models.
- Evidence anchors:
  - [abstract] "We propose Expected Improvement (EI) and Upper Confidence Bound (UCB) based BO algorithms"
  - [section] "En(x) = En[h({µ(n)i(x) +σ(n)i(x)Zi})−g∗n]+" and "Since each function fi is being considered an independent variable with mean µ(n)i(·) and variance σ(n)i(·), the calculation of En(x) does not have a closed form and thus, the expectation needs to be evaluated empirically with sampling."
  - [corpus] Weak evidence - no direct citations discussing EI for composite function optimization with independent GPs.
- Break condition: The number of Monte Carlo samples is insufficient to provide accurate estimates of expected improvement.

## Architecture Onboarding

- Component map: GP models → Acquisition function computation → Point selection → Function evaluation → Data augmentation → Repeat
- Critical path: GP model fitting → Acquisition function computation → Next point selection → Function evaluation → Data augmentation → Repeat
- Design tradeoffs: Independent GPs provide computational efficiency and parallelization opportunities but may miss correlations between constituent functions that a multi-output GP would capture.
- Failure signatures: Poor convergence to global optimum, slow improvement in regret, runtime significantly higher than expected, acquisition function becoming degenerate.

- Why unresolved: The paper explicitly models constituent functions as independent GPs, making it unclear how the algorithms would perform with correlated observations.

## Limitations

- The independent GP modeling assumption may not capture important correlations between constituent functions in real-world applications, potentially limiting performance in cases where such correlations are strong
- Computational efficiency gains are primarily demonstrated through runtime comparisons, but the scalability to very high-dimensional problems (many constituent functions) has not been fully explored
- The Monte Carlo sampling approach for cEI requires careful tuning of the number of samples to balance accuracy and computational cost

## Confidence

- High confidence in the computational efficiency claims: The mechanism of using independent GPs to avoid expensive matrix inversions is well-established in the GP literature
- Medium confidence in regret performance claims: While empirical results show improvements, the comparison with state-of-the-art methods is limited to specific test functions and pricing scenarios
- Low confidence in generalizability to arbitrary composition functions: The evaluation focuses on specific test functions and a limited set of pricing applications
