# Valid P-Value for Deep Learning-Driven Salient Region

## Quick Facts
- arXiv ID: 2301.02437
- Source URL: https://arxiv.org/abs/2301.02437
- Reference count: 21
- Key outcome: Introduces conditional selective inference framework for computing valid p-values for salient regions in deep learning models, achieving higher true positive rates while controlling false positive rates compared to baseline methods.

## Executive Summary
This paper addresses the critical challenge of selection bias in interpreting deep learning model predictions by introducing a framework for computing valid p-values for salient regions. The method treats salient regions as selected hypotheses and employs conditional selective inference to correct for selection bias, enabling exact (non-asymptotic) inference. A novel Keras-based implementation allows efficient computation of selective p-values for a wide class of CNNs without additional implementation costs. The approach successfully controls false positive rates while achieving higher true positive rates compared to naive and Bonferroni correction methods across both synthetic and real-world datasets.

## Method Summary
The method computes selective p-values by conditioning on the selection event that identifies salient regions in deep learning models. It represents saliency map functions as piecewise linear functions of the input and uses auto-conditioning to tractably compute truncation regions for conditional inference. The approach leverages the modularity of deep learning frameworks like Keras to automatically derive selection events for various CNN architectures. For each salient region identified by the model, the method calculates the conditional distribution of test statistics given that the region was selected, producing exact p-values that account for selection bias. The framework is validated on synthetic data with known ground truth and applied to brain tumor detection in real-world medical imaging datasets.

## Key Results
- Successfully controls false positive rates while achieving higher true positive rates compared to naive and Bonferroni correction methods
- Keras-based implementation enables efficient computation across a wide class of CNN architectures without additional implementation costs
- Valid p-values provide reliable statistical significance measures for salient regions, improving interpretability and trustworthiness of deep learning models in applications like brain tumor detection

## Architecture Onboarding

- Component map:
  Input (query and reference images) -> DNN model with saliency map method -> Piecewise linear representation of saliency map -> Auto-conditioning computation of intervals -> Conditional inference for selective p-values -> Output selective p-values

- Critical path:
  1. Compute saliency map for query image using pre-trained DNN
  2. Identify salient region based on threshold
  3. Represent saliency map function as piecewise linear function
  4. Compute intervals for each piecewise linear component using auto-conditioning
  5. Identify truncation region for conditional inference
  6. Compute selective p-value based on truncated distribution

- Design tradeoffs:
  - Tradeoff between accuracy of piecewise linear representation and computational efficiency
  - Tradeoff between strict control of false positive rate and statistical power (true positive rate)
  - Tradeoff between generality of the method (applicable to wide class of CNNs) and specificity of implementation (may not work for all architectures)

- Failure signatures:
  - High false positive rates despite using selective inference (indicates issues with conditional inference or truncation region identification)
  - Low true positive rates compared to baseline methods (indicates overly conservative selective inference or inaccurate piecewise linear representation)
  - Failure to compute selective p-values for certain CNN architectures (indicates limitations of auto-conditioning or piecewise linear representation)
