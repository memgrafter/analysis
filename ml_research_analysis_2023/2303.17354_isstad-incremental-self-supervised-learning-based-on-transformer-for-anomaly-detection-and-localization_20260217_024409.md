# ISSTAD: Incremental Self-Supervised Learning Based on Transformer for Anomaly Detection and Localization

## Quick Facts
- arXiv ID: 2303.17354
- Source URL: https://arxiv.org/abs/2303.17354
- Reference count: 40
- One-line primary result: Achieves 97.6% AUC on MVTec AD, outperforming CNN-based methods

## Executive Summary
This paper addresses anomaly detection and localization in industrial defect images using a Transformer-based approach with a novel two-stage incremental learning strategy. The method first trains a Masked Autoencoder (MAE) exclusively on normal images, then applies pixel-level data augmentation to generate corrupted normal images for self-supervised fine-tuning. The model combines reconstruction error and pixel classification probability through fusion to effectively detect and localize anomalies, achieving state-of-the-art performance on the MVTec AD dataset.

## Method Summary
The proposed ISSTAD method employs a two-stage incremental learning strategy using a Transformer backbone (ViT encoder with MHA decoder). In Stage 1, an MAE is pre-trained on normal images to learn normal image distributions. In Stage 2, pixel-level data augmentation generates corrupted normal images with corresponding pixel labels, enabling the model to learn anomaly detection at the pixel level while keeping encoder parameters frozen. The final anomaly scoring combines reconstruction error and classification probability matrices through Hadamard product.

## Key Results
- Achieves 97.6% AUC on MVTec AD dataset, outperforming CNN-based state-of-the-art methods
- Demonstrates superior performance in both anomaly detection and localization tasks
- Shows effectiveness of two-stage incremental learning strategy with Transformer architecture

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Two-stage incremental learning enables effective anomaly detection by first learning normal image distributions and then fine-tuning pixel-level anomaly detection
- Mechanism: Stage 1 trains MAE exclusively on normal images, learning distributional characteristics and developing strong feature extraction. Stage 2 uses pixel-level data augmentation to generate corrupted images and labels, enabling repair learning and pixel classification
- Core assumption: The model can effectively learn normal distributions in Stage 1 and transfer this knowledge to improve pixel-level detection in Stage 2
- Evidence anchors: Abstract states the two-stage approach; section describes transformer backbone with ViT encoder and MHA decoder

### Mechanism 2
- Claim: Fusion of reconstruction error and pixel classification probability effectively captures both global and local anomaly information
- Mechanism: During inference, model generates pixel reconstruction error matrix and pixel anomaly probability matrix, combined via Hadamard product to create anomaly scoring matrix
- Core assumption: Combination provides complementary information for anomaly detection
- Evidence anchors: Abstract mentions combining matrices for anomaly scoring; section defines anomaly scoring as Hadamard product of error and probability matrices

### Mechanism 3
- Claim: Pixel-level data augmentation method generates realistic anomalies for training, improving local anomaly detection ability
- Mechanism: Method applies random corruptions (Gaussian noise, color alterations, flipping) to normal images, simultaneously generating pixel labels indicating corrupted regions
- Core assumption: Randomly generated corruptions are representative of real anomalies and provide sufficient variation
- Evidence anchors: Section describes pixel-level augmentation with specific operations applied to image blocks

## Architecture Onboarding

- Component map: Encoder (ViT) -> Decoder (MHA blocks) -> Reconstruction head (MLP) and Classification head (MLP) -> Fusion of reconstruction error and classification probability
- Critical path: Encoder → Decoder → Reconstruction head and Classification head → Fusion of reconstruction error and classification probability
- Design tradeoffs:
  - Using transformers instead of CNNs: Improved context understanding but increased computational complexity
  - Two-stage incremental learning: Better anomaly detection performance but requires more training time
  - Pixel-level data augmentation: More realistic anomalies but increased training data requirements
- Failure signatures:
  - Poor anomaly detection performance: Insufficient pre-training or inadequate pixel-level data augmentation
  - High false positive rate: Overly sensitive anomaly classification or insufficient normal image diversity in training data
  - Slow inference time: Complex transformer architecture or inefficient fusion of reconstruction error and classification probability

## Limitations
- Pixel-level data augmentation relies on randomly generated corruptions that may not fully capture real-world anomaly complexity and diversity
- Two-stage incremental learning requires substantial computational resources and training time, potentially limiting practical deployment
- Performance on datasets beyond MVTec AD remains untested, raising questions about generalizability

## Confidence
- High confidence: The two-stage incremental learning strategy and its effectiveness on MVTec AD dataset
- Medium confidence: The fusion mechanism combining reconstruction error and pixel classification probability
- Low confidence: The representativeness of pixel-level data augmentation for capturing all types of real-world anomalies
