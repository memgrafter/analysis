# HaVQA: A Dataset for Visual Question Answering and Multimodal Research in Hausa Language

## Quick Facts
- arXiv ID: 2305.17690
- Source URL: https://arxiv.org/abs/2305.17690
- Reference count: 40
- Key outcome: First multimodal VQA dataset for Hausa with 6,022 English-Hausa QA pairs, achieving 30.85 WuPalmer score for VQA and 35.5 BLEU for text translation

## Executive Summary
HaVQA introduces the first multimodal dataset for visual question-answering in the Hausa language, containing 6,022 manually translated English question-answer pairs associated with 1,555 images from Visual Genome. The dataset creates 12,044 English-Hausa parallel sentences suitable for VQA, translation, and multimodal research. Baseline experiments demonstrate that transformer-based architectures with Hausa BERT achieve reasonable performance despite the limited training data, with the DeiT-based VQA model reaching a WuPalmer score of 30.85. The text-only translation model outperforms the multimodal approach, suggesting Hausa sentences in the dataset are already unambiguous.

## Method Summary
The HaVQA dataset was created by manually translating English question-answer pairs from the Visual Genome dataset into Hausa, ensuring semantic alignment with corresponding images. The dataset was split into train/dev/test sets in an 80:10:10 ratio. Baseline experiments included VQA using multimodal Transformer-based architecture with DeiT/ViT visual encoders and Hausa BERT text encoder, text-only and multimodal machine translation using Transformer models, and visual question elicitation using LSTM decoder. Models were evaluated using WuPalmer score for VQA and BLEU points for translation tasks.

## Key Results
- VQA model with DeiT-based architecture and Hausa BERT achieved 30.85 WuPalmer score
- Text-only translation model achieved 35.5 BLEU points for English-to-Hausa translation
- Multimodal translation model achieved 26.3 BLEU points, underperforming text-only approach
- Best VQA performance on one-word answer questions, with performance declining for multi-word answers

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Manual translation ensures semantic alignment between Hausa QA pairs and images
- Mechanism: Human translators preserve semantic meaning during translation, creating reliable aligned data for VQA tasks
- Core assumption: Manual translation captures semantic nuances better than automatic translation for low-resource languages
- Evidence anchors: Abstract states manual translation "guarantees their semantic match with the corresponding visual information"

### Mechanism 2
- Claim: Pre-trained multilingual models enable effective VQA despite limited Hausa data
- Mechanism: Transfer learning from multilingual BERT provides linguistic knowledge that supports Hausa-specific tasks
- Core assumption: Multilingual models contain sufficient Hausa language coverage from pre-training
- Evidence anchors: Section 6.1 shows DeiT with Hausa BERT achieving 30.85 WuPalmer score

### Mechanism 3
- Claim: Text-only translation outperforms multimodal because Hausa sentences are unambiguous
- Mechanism: Visual context adds noise rather than improvement when source text doesn't require disambiguation
- Core assumption: Translation ambiguity directly correlates with need for multimodal context
- Evidence anchors: Section 6.2 shows text-only achieving 35.5 BLEU vs 26.3 BLEU for multimodal

  - Why needed here: Ensures translated questions accurately correspond to visual content for valid VQA tasks

- Concept: Transfer learning with pre-trained multilingual models
  - Why needed here: Enables effective VQA performance despite limited Hausa-specific training data
  - Quick check question: What evidence would indicate that Hausa BERT is successfully transferring knowledge from its multilingual pre-training?

- Concept: Evaluation metrics for multimodal tasks
  - Why needed here: Different metrics (WuPalmer for VQA, BLEU for translation) properly assess model performance across task types
  - Quick check question: Why might WuPalmer be more appropriate than BLEU for evaluating VQA answers?

## Architecture Onboarding

- Component map: Image encoder (DeiT/ViT) → Text encoder (Hausa BERT) → Fusion module → Classifier → Answer prediction
- Critical path: Question encoding → Image feature extraction → Feature fusion → Classification
- Design tradeoffs: Pre-trained models enable faster development but may limit adaptation to Hausa-specific patterns
- Failure signatures: Low WuPalmer scores indicate poor semantic alignment; BLEU score gaps suggest translation quality issues
- First 3 experiments:
  1. Train VQA model with only DeiT visual encoder and English BERT, then replace with Hausa BERT to measure transfer impact
  2. Compare text-only vs multimodal translation performance on ambiguous vs unambiguous Hausa sentences
  3. Test VQA performance on one-word answer questions vs multi-word answers to identify task limitations

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What specific visual question types or patterns yield the highest accuracy in the Hausa VQA model, and why?
- Basis in paper: The paper notes that the model performed best on one-word answer questions, but doesn't provide a detailed breakdown of question types
- Why unresolved: The paper only mentions that one-word answers worked best, but doesn't analyze which specific question types were most successful or why
- What evidence would resolve it: A detailed analysis categorizing model performance by question type (e.g., what/where/when/how much/who/why) and identifying which types achieved highest accuracy

### Open Question 2
- Question: How would the VQA model's performance change if it used direct image features instead of object tags?
- Basis in paper: The paper states "For the baseline multimodal experiments, we did not use the image directly but resorted to extracting textual tags and including them in the text-only translation input"
- Why unresolved: The authors acknowledge this limitation but don't provide experimental results comparing direct image feature usage versus their tag-based approach
- What evidence would resolve it: Performance comparison of the VQA model using direct image features versus the current object tag approach

## Limitations

- Dataset size (6,022 QA pairs) is relatively small for training robust multimodal models
- Manual translation introduces human bias and may not capture all linguistic nuances of Hausa
- Reliance on Visual Genome images may limit visual diversity and cultural relevance to Hausa-speaking communities

## Confidence

- VQA performance claims: High confidence
- Text vs multimodal translation comparison: Medium confidence
- Dataset quality and utility: Medium confidence
