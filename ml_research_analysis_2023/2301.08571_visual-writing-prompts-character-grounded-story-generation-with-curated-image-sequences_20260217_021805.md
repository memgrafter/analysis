# Visual Writing Prompts: Character-Grounded Story Generation with Curated Image Sequences

## Quick Facts
- arXiv ID: 2301.08571
- Source URL: https://arxiv.org/abs/2301.08571
- Reference count: 24
- Key outcome: Curated movie-shot sequences with recurring characters yield more narratively structured stories than previous datasets; CharGrid model outperforms TAPM on automatic and human metrics

## Executive Summary
This paper introduces Visual Writing Prompts (VWP), a new dataset for image-based story generation using curated movie shot sequences and stories written by crowdsourced workers. The key innovation is filtering image sequences to ensure coherent plots and recurring characters, which yields more narratively structured stories than previous datasets. The authors also propose a character-grid transformer model that leverages character continuity across images to generate more coherent, visually grounded, and diverse stories. Evaluations show the model outperforms the state-of-the-art TAPM model on automatic and human metrics.

## Method Summary
The VWP dataset curates movie shot sequences (5-10 images each) from MovieNet, filtered to remove fantasy, sci-fi, horror, and animation genres. Images are filtered for blur, lack of objects, similarity, and adult content. Stories are collected via crowdsourcing on AMT, providing workers with cropped character images and names to improve visual grounding. The CharGrid model uses a character-grid transformer representation that models character-instance similarity across images, fusing global image features, object features, and character features through a transformer decoder.

## Key Results
- VWP dataset contains 12K stories with 4K image sequences, providing higher narrative coherence than Flickr-based datasets
- CharGrid model outperforms TAPM on automatic metrics (BLEU, METEOR, ROUGE-L, CIDEr) and human evaluations for coherence, visual groundedness, and diversity
- Visual grounding is improved by providing character crops and names, reducing hallucination of ungrounded references

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Curating movie-shot sequences with recurring characters yields more coherent visual prompts than random Flickr albums
- Mechanism: Movie synopses already encode narrative structure; aligning image sequences with synopsis paragraphs ensures each set of images forms a self-contained plot around consistent characters
- Core assumption: Shot extraction from movies preserves the event-character coherence present in the synopsis
- Evidence anchors: [abstract] "The image sequences are aligned with a total of 12K stories which were collected via crowdsourcing given the image sequences and a set of grounded characters"; [section] "To achieve high coherence and diversity, we choose to select images from movie scenes that have a plot consisting of a series of events around several main characters"
- Break condition: If shot extraction fails to align with synopsis events, coherence breaks down

### Mechanism 2
- Claim: Providing explicit character crops and names during story-writing grounds narratives in visual input, improving visual groundedness
- Mechanism: Character crops remove ambiguity about which person in an image is being referenced; named characters constrain the writer's choice of entities, reducing hallucinated or ungrounded references
- Core assumption: Human writers reliably use provided character identities when generating stories
- Evidence anchors: [abstract] "To obtain coherent and visually grounded stories, we provide cropped images of characters explicitly with image sequences for storytellers"; [section] "To help storytellers to write stories that are visually grounded on characters or objects around them, we discard blurry images and images without any COCO 'objects'"
- Break condition: If character crops are unclear or names are missing, grounding degrades

### Mechanism 3
- Claim: The character-grid transformer representation captures coherence by modeling character-instance similarity across images
- Mechanism: A matrix of image-by-character-instance similarities encodes how prominently a character appears in each image; this structure informs the transformer about narrative flow and character continuity
- Core assumption: Similarity scores between character features and image features correlate with narrative importance
- Evidence anchors: [abstract] "We also propose a character-based story generation model driven by coherence as a strong baseline"; [section] "Inspired by this, we measure the narrative importance of a character in an image by the similarity between global image features and the character's features"
- Break condition: If character features are poorly aligned with visual instances, coherence modeling fails

## Foundational Learning

- Concept: Visual coherence metrics (e.g., Entity Grid coherence, Jaccard similarity of events)
  - Why needed here: To evaluate whether the curated image sequences and generated stories maintain consistent entities and semantically related events
  - Quick check question: What is the difference between local coherence (entity continuity) and global coherence (event relatedness)?

- Concept: Character grounding in multimodal data
  - Why needed here: Ensuring stories reference the same characters across images prevents narrative drift and hallucination
  - Quick check question: How do bounding-box crops and character names reduce ambiguity in visual grounding?

- Concept: Transformer-based multimodal fusion
  - Why needed here: The CharGrid model fuses text, global image features, object features, and character features; understanding how these modalities interact is essential
  - Quick check question: What is the role of the character-grid matrix in the transformer input pipeline?

## Architecture Onboarding

- Component map: Vision backbone (Swin Transformer) -> global image features, object features, character crops -> Object detector (Cascade Mask R-CNN) -> object features -> Character encoder -> projects character crop features -> Global encoder -> projects global image features -> Character-grid flattener -> produces coherence matrix -> GPT-2 tokenizer -> input token sequence -> Transformer decoder -> sequence generation

- Critical path: Vision backbone → feature extraction → encoder projection → character-grid assembly → transformer → GPT-2 output distribution

- Design tradeoffs:
  - Using fixed pre-trained vision backbones vs. fine-tuning for dataset specificity
  - Adding object features increases grounding but adds noise from irrelevant objects
  - Character-grid adds coherence signal but increases model complexity

- Failure signatures:
  - Low BLEU/ROUGE scores → model not copying reference language
  - High visual groundedness but low coherence → characters referenced but events unrelated
  - Low diversity scores → repetitive event sequences

- First 3 experiments:
  1. Ablation: remove character-grid matrix, keep only character features; compare coherence scores
  2. Swap character features for object features; compare visual groundedness
  3. Vary Nucleus sampling p (0.1, 0.3, 0.5); observe trade-off between diversity and coherence

## Open Questions the Paper Calls Out

### Open Question 1
- Question: How can narrative structures (like Establish, Initial, Initial Peak, and Release) be automatically annotated in visual storytelling datasets?
- Basis in paper: Explicit - The authors mention that narrative structures emerge in their collected stories and suggest future work should investigate annotating roles of events to measure narrativity
- Why unresolved: While the authors observe narrative structures in their data, they do not provide a method for automatically annotating these structures or measuring narrativity
- What evidence would resolve it: A proposed annotation scheme and evaluation framework for narrative structures in visual stories, along with empirical results showing how these annotations correlate with human judgments of narrativity

### Open Question 2
- Question: How do individual differences in human writing proficiency impact the quality of generated visual stories?
- Basis in paper: Explicit - The authors note that a major assumption in storytelling is that all humans are equally proficient, but individual differences must impact story quality
- Why unresolved: The paper acknowledges this issue but does not investigate how varying writing abilities among human annotators affect the resulting dataset quality or how this should influence model design
- What evidence would resolve it: An empirical study comparing stories from annotators with different writing proficiencies, along with model performance analysis showing how training data quality varies with annotator skill level

### Open Question 3
- Question: How can character features be effectively extracted and used in visual storytelling when characters undergo significant appearance changes or are partially occluded?
- Basis in paper: Inferred - The paper uses character features based on bounding boxes and similarity measures, but acknowledges that visual attributes can change across images
- Why unresolved: The paper doesn't address challenges in tracking characters across significant appearance variations or handling partial occlusions, which are common in real-world scenarios
- What evidence would resolve it: An evaluation showing model performance degradation when characters change appearance significantly, along with proposed solutions for robust character feature extraction under such conditions

### Open Question 4
- Question: What is the optimal trade-off between providing detailed character information and maintaining story diversity in visual storytelling datasets?
- Basis in paper: Explicit - The authors provide cropped character images to improve groundedness, but note this could potentially constrain creativity
- Why unresolved: The paper doesn't empirically investigate whether detailed character annotations limit story diversity or how to balance grounding information with creative freedom
- What evidence would resolve it: Comparative analysis showing how different levels of character detail in writing prompts affect both story coherence and diversity metrics, along with guidelines for optimal prompt design

## Limitations
- Narrative coherence improvements are inferred rather than directly measured through quantitative metrics
- Character grounding effectiveness is assumed from final story statistics rather than analyzed through worker behavior patterns
- Character-grid transformer's coherence modeling depends on unverified assumption that feature similarity correlates with narrative importance
- Dataset filtering thresholds and exact human annotation protocols are underspecified, creating reproducibility challenges

## Confidence

**High Confidence**: The dataset curation methodology (movie selection, scene extraction, image filtering) is clearly described and produces a novel resource with explicit character grounding. The experimental setup and baseline comparisons are reproducible.

**Medium Confidence**: The proposed character-grid transformer architecture is well-specified, and automatic evaluation metrics show improvements over baselines. However, the coherence modeling mechanism lacks direct validation.

**Low Confidence**: Claims about narrative coherence improvements from movie-shot curation and character grounding through crops/names rely on inferred rather than measured evidence. The correlation between feature similarity and narrative salience is assumed without empirical verification.
