# Confidence Ranking for CTR Prediction

## Quick Facts
- arXiv ID: 2307.01206
- Source URL: https://arxiv.org/abs/2307.01206
- Reference count: 16
- Proposes Confidence Ranking (CR) framework for CTR prediction with improved AUC

## Executive Summary
This paper introduces Confidence Ranking (CR), a loss framework that optimizes model logits by comparing predictions from baseline and retrained models. The method addresses distribution drift in periodic model retraining for click-through rate prediction in ad systems. CR combines point-wise and relational ranking losses with cross-entropy, showing consistent AUC improvements over strong baselines including knowledge distillation methods. The approach has been deployed in JD.com's ad system serving main traffic.

## Method Summary
The Confidence Ranking framework works by leveraging knowledge from a baseline model during retraining to maintain prediction consistency while adapting to distribution shifts. It introduces a dual-loss structure that includes point-wise ranking loss to preserve individual prediction confidence and relational ranking loss to maintain relative prediction ordering. These losses are optimized alongside traditional cross-entropy during model retraining. The framework assumes access to the baseline model's logits and aims to minimize the divergence between old and new model predictions while improving overall accuracy.

## Key Results
- Consistent AUC improvements over strong baselines on public and industrial datasets
- Deployed in JD.com's ad system serving main traffic
- Shows effectiveness of knowledge distillation-like approach without requiring teacher model architecture

## Why This Works (Mechanism)
The Confidence Ranking framework works by preserving useful information from the baseline model while allowing adaptation to new data distributions. By comparing logits between models, it creates a knowledge transfer mechanism that helps maintain prediction consistency across model iterations. The dual ranking losses ensure both individual prediction confidence and relative ordering are preserved, which is particularly important for CTR prediction where relative ranking often matters more than absolute values.

Component Map

Critical Path
1. Baseline model generates predictions
2. CR framework computes ranking losses
3. Combined loss optimization during retraining
4. Deployed retrained model maintains prediction consistency

Design Tradeoffs
- Computational overhead during retraining vs prediction stability
- Complexity of dual ranking losses vs improvement in AUC
- Dependency on baseline model availability vs independence in deployment

Failure Signatures
- Significant prediction drift despite CR optimization
- Inconsistent performance across different data distributions
- Computational bottlenecks during retraining phase
