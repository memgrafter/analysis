# Synthcity: facilitating innovative use cases of synthetic data in different data modalities

## Quick Facts
- arXiv ID: 2301.07573
- Source URL: https://arxiv.org/abs/2301.07573
- Reference count: 11
- Key outcome: Synthcity is an open-source Python library that enables practical use of synthetic data for ML fairness, privacy, and augmentation across diverse tabular data modalities

## Executive Summary
Synthcity is an open-source Python library designed to address the growing need for synthetic data generation across multiple data modalities. The library provides a unified platform supporting static data, regular/irregular time series, censored survival data, and composite datasets. With over 20 generative models including CTGAN, TVAE, PATEGAN, and domain-specific architectures, Synthcity aims to standardize synthetic data workflows through DataLoader, Plugin, and Benchmark classes while offering comprehensive evaluation metrics for fidelity, utility, and privacy assessment.

## Method Summary
Synthcity implements a modular architecture that integrates multiple generative models with standardized data loading and evaluation frameworks. The library supports various network architectures (CNN, LSTM, Transformer) and provides domain-specific models for different data types. Evaluation metrics include fidelity measures (JS distance, Wasserstein distance), utility assessment (linear/MLP/XGBoost models), and privacy metrics (k-anonymity, re-identification attacks). The platform is designed to enable use-case specific generation for fairness balancing, causal fairness, differential privacy, membership inference attacks, and cross-domain augmentation through a unified interface.

## Key Results
- Supports over 20 generative models across multiple data modalities including static, time series, and censored data
- Implements comprehensive evaluation metrics covering fidelity, utility, and privacy dimensions
- Provides standardized workflow through DataLoader, Plugin, and Benchmark classes
- Claims broadest data modality support among synthetic data libraries with use-case specific generation capabilities

## Why This Works (Mechanism)
Synthcity's effectiveness stems from its modular architecture that decouples data loading, model selection, and evaluation processes. By providing a unified interface across diverse generative models and data types, it reduces the complexity of implementing synthetic data workflows. The comprehensive evaluation framework enables systematic assessment of generated data quality across multiple dimensions, while the standardized classes facilitate reproducible research and practical deployment across different use cases.

## Architecture Onboarding

**Component Map**: DataLoader -> Plugin -> Generative Model -> Benchmark -> Evaluation Metrics

**Critical Path**: DataLoader → Plugin → Generative Model Training → Benchmark → Evaluation Metrics → Results

**Design Tradeoffs**: Modular design enables flexibility but increases complexity; comprehensive metric support ensures thorough evaluation but requires more computational resources; broad modality support increases utility but may sacrifice depth in specialized use cases.

**Failure Signatures**: Model training instability (GAN mode collapse), poor data fidelity (high JS distance), privacy leakage (successful re-identification attacks), computational bottlenecks (memory constraints with large datasets), and inconsistent results across different data modalities.
