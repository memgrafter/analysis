# Meta-Learning Siamese Network for Few-Shot Text Classification

## Quick Facts
- arXiv ID: 2302.03507
- Source URL: https://arxiv.org/abs/2302.03507
- Reference count: 40
- Key outcome: Meta-SN achieves 69.1% accuracy in 1-shot and 85.2% in 5-shot text classification, outperforming state-of-the-art methods

## Executive Summary
This paper introduces Meta-SN, a meta-learning Siamese network for few-shot text classification that leverages external class knowledge to generate prototype vectors. Instead of relying on sampled support sets, Meta-SN uses class names and descriptive texts to create more stable prototype embeddings, which are then refined via a Siamese network. The model learns sample importance based on distance to queries and samples hard-to-classify tasks during meta-training. Evaluated on six datasets, Meta-SN demonstrates superior performance in both 1-shot and 5-shot settings while showing robustness to limited descriptive information.

## Method Summary
Meta-SN addresses few-shot text classification by generating prototype vectors from external class knowledge (e.g., class names and Wikipedia descriptions) rather than sampled support sets. These initial embeddings are refined through a Siamese network that learns a metric space where inter-class distances are maximized and intra-class distances are minimized. The model incorporates a novel sampling strategy that prioritizes hard-to-classify samples and tasks during meta-training. A weight generator assigns importance to support samples based on their average distance to query instances. The entire framework is trained end-to-end using contrastive loss for the Siamese network and cross-entropy loss for classification.

## Key Results
- Achieves 69.1% accuracy in 5-way 1-shot classification across six benchmark datasets
- Achieves 85.2% accuracy in 5-way 5-shot classification
- Outperforms state-of-the-art methods including MAML, Prototypical Networks, and Relation Networks
- Ablation studies confirm effectiveness of external knowledge, hard-task sampling, and sample importance weighting
- Demonstrates robustness to limited descriptive information and stable performance across hyperparameters

## Why This Works (Mechanism)

### Mechanism 1: External Knowledge for Stable Prototypes
Meta-SN uses external descriptive texts to generate initial prototype vectors, eliminating randomness from sampled support sets. The mechanism encodes class descriptions into low-dimensional embeddings that serve as stable starting points for prototype refinement. This approach assumes that descriptive texts contain sufficient semantic information to represent class semantics more reliably than limited support samples.

### Mechanism 2: Distance-Based Sample Importance
The model learns sample importance by weighting support instances based on their average distance to query sets. Closer samples receive higher weights during prototype refinement, as they are assumed to be more informative for classification. This mechanism enhances the quality of refined prototypes by emphasizing support samples most relevant to the current task.

### Mechanism 3: Hard-Task Sampling Strategy
Meta-SN constructs meta-tasks by sampling classes and instances with higher probabilities when prototypes are close and samples are far from their class prototypes. This exposes the model to more challenging classification scenarios during training, leading to better generalization on unseen, difficult tasks. The greedy algorithm ensures diverse exposure to hard cases while maintaining task validity.

## Architecture Onboarding

- **Component map**: Word Representation Layer → Task Sampler → Sample Pair Constructor + Weight Generator → Siamese Network → Classifier
- **Critical path**: Word Representation → Task Sampler → Sample Pair + Weight → Siamese Network → Classification Loss → Model Update
- **Design tradeoffs**: Using external knowledge vs. sampled support sets (more stable prototypes but dependent on text quality); hard-task sampling vs. random sampling (better generalization but risk of bias); weight learning vs. equal weights (better use of informative samples but added complexity)
- **Failure signatures**: Poor classification if external texts are unrelated to true class semantics; degraded performance if task sampler selects too many ambiguous samples; overfitting if Siamese network overfits to training distribution
- **First 3 experiments**: 1) Verify prototype initialization from external texts produces embeddings that roughly align with class semantics; 2) Test contrastive loss in Siamese network on sample pairs to confirm it reduces intra-class distance and increases inter-class distance; 3) Evaluate classification accuracy on held-out validation set with varying meta-tasks per epoch to find optimal training schedule

## Open Questions the Paper Calls Out
The paper does not explicitly call out open questions, but the following areas remain unexplored: scalability to datasets with many classes (e.g., 50-100+ classes), adaptation to zero-shot learning scenarios, and robustness to varying quality of external descriptive texts.

## Limitations
- Reliance on external descriptive texts may limit applicability when such texts are unavailable or of poor quality
- The greedy sampling algorithm for hard-task selection lacks full algorithmic detail, making exact behavior difficult to verify
- No direct comparison to baseline methods using sampled support sets for prototype initialization limits interpretation of external knowledge's contribution

## Confidence

- **High Confidence**: The overall framework combining Siamese networks with prototype-based classification is technically sound and well-grounded in prior meta-learning literature
- **Medium Confidence**: Empirical results showing improved performance are convincing, but absence of direct comparison to sampled support set baselines limits interpretability
- **Low Confidence**: The exact impact of hard-task sampling strategy and model robustness to degraded external text quality are not fully explored
