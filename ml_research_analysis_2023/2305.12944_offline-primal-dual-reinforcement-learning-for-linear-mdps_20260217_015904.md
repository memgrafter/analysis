# Offline Primal-Dual Reinforcement Learning for Linear MDPs

## Quick Facts
- arXiv ID: 2305.12944
- Source URL: https://arxiv.org/abs/2305.12944
- Reference count: 40
- Key outcome: Proposes a primal-dual algorithm for offline RL in linear MDPs that finds an ε-optimal policy with O(ε^-4) samples, improving on previous O(ε^-5) while being computationally efficient.

## Executive Summary
This paper introduces a new primal-dual algorithm for offline reinforcement learning in linear MDPs that achieves improved sample complexity. The key innovation is a reparametrization of the Lagrangian that enables low-variance gradient estimates using only samples from the behavior policy, avoiding the need to know the behavior policy explicitly. The algorithm works under a partial coverage assumption measured by a feature coverage ratio, and extends to both discounted and average-reward settings.

## Method Summary
The method solves a linear programming formulation of RL using primal-dual optimization with a novel reparametrization trick. The algorithm has a double-loop structure: an outer loop performs stochastic gradient ascent on the dual variable β, while an inner loop runs K steps of stochastic gradient descent on the primal variable θ to approximate the value function. The reparametrization β = Λ^(-c)λ allows construction of unbiased gradient estimators using only samples from the behavior policy. The policy is updated using a softmax over accumulated parameter estimates.

## Key Results
- Achieves O(ε^-4) sample complexity for finding ε-optimal policies in linear MDPs, improving on previous O(ε^-5)
- Works under partial coverage assumptions rather than requiring uniform coverage
- Extends to both discounted and average-reward settings
- Provides the first theoretical result for average-reward offline RL

## Why This Works (Mechanism)

### Mechanism 1
- Claim: The reparametrization β = Λ^(-c)λ enables low-variance gradient estimation without explicit knowledge of the behavior policy.
- Mechanism: By expressing the gradient with respect to λ in terms of the data covariance Λ, the reparametrization allows construction of an unbiased estimator using only samples from the behavior policy. This avoids needing to know Λ explicitly when c=1, or only needing Λ when c=1/2.
- Core assumption: The feature covariance matrix Λ is invertible and the behavior policy's occupancy measure has full support over the feature space.
- Evidence anchors:
  - [abstract]: "Our key contribution is a new reparametrization that allows us to derive low-variance gradient estimators that can be used in a stochastic optimization scheme using only samples from the behavior policy."
  - [section]: "Our key contribution is a new reparametrization that allows us to derive low-variance gradient estimators that can be used in a stochastic optimization scheme using only samples from the behavior policy."
- Break condition: If the behavior policy doesn't cover the feature space sufficiently (Λ not full rank or ill-conditioned), the gradient estimates become unstable or biased.

### Mechanism 2
- Claim: The double-loop structure with inner loop K ensures accurate value function approximation while maintaining computational efficiency.
- Mechanism: The inner loop performs K steps of stochastic gradient descent on θ to ensure ⟨ϕ(x,a), θ⟩ approximates the true action-value function. This creates a policy π_t that's sufficiently good for the outer loop's gradient ascent on β.
- Core assumption: The linear MDP assumption holds, so Q-functions are realizable as linear combinations of features.
- Evidence anchors:
  - [abstract]: "Our method finds an ε-optimal policy with O(ε^-4) samples, improving on the previous O(ε^-5), while being computationally efficient"
  - [section]: "The algorithm has a double-loop structure, where at each iteration t we run one step of stochastic gradient ascent for β, and also an inner loop which runs K iterations of stochastic gradient descent on θ"
- Break condition: If K is too small, the inner loop won't converge to a good approximation of the value function, causing the outer loop to make poor updates.

### Mechanism 3
- Claim: The coverage ratio C_ϕ,c (π* ;πB) captures the partial coverage assumption and directly bounds the suboptimality gap.
- Mechanism: The coverage ratio measures how well the behavior policy covers the features visited by the optimal policy. The algorithm's error scales with this ratio, allowing it to work under partial coverage rather than requiring uniform coverage.
- Core assumption: The behavior policy's occupancy measure has sufficient overlap with the optimal policy's feature visitation.
- Evidence anchors:
  - [abstract]: "Our method finds an ε-optimal policy with O(ε^-4) samples, improving on the previous O(ε^-5), while being computationally efficient for infinite-horizon discounted and average-reward MDPs with realizable linear function approximation and partial coverage."
  - [section]: "We employ a notion of feature coverage ratio for linear MDPs that defines coverage in feature space rather than in state-action space"
- Break condition: If the coverage ratio becomes too large (behavior policy doesn't cover optimal policy's features), the error bounds degrade and the algorithm may fail to find a good policy.

## Foundational Learning

- Concept: Linear MDPs and feature representation
  - Why needed here: The entire algorithm relies on the assumption that transition dynamics and rewards can be expressed as linear functions of known features. This enables the dimensionality reduction from |X|×|A| to d.
  - Quick check question: If an MDP is not linear in the given features, can this algorithm still find an optimal policy? (Answer: No, because the Bellman equations won't be satisfied by linear combinations of features)

- Concept: Primal-dual optimization and saddle-point problems
  - Why needed here: The algorithm solves the RL problem by finding a saddle point of the Lagrangian, which is a convex-concave optimization problem. Understanding this framework is crucial for grasping why the reparametrization works.
  - Quick check question: Why does finding a saddle point of the Lagrangian correspond to solving the original LP? (Answer: Because the Lagrangian encodes the constraints as penalty terms, and at the saddle point the constraints are satisfied)

- Concept: Coverage ratios and partial coverage assumptions
  - Why needed here: The algorithm's sample complexity and error bounds depend on the coverage ratio, which measures how well the behavior policy covers the optimal policy's feature visitation. This is a weaker assumption than uniform coverage.
  - Quick check question: How does the coverage ratio C_ϕ,1/2 compare to the standard feature coverage ratio C⋄? (Answer: C_ϕ,1/2 ≤ C⋄ due to Jensen's inequality, making it a lower-variance version)

## Architecture Onboarding

- Component map:
  - Outer loop: Stochastic gradient ascent on β (dual variable)
  - Inner loop: Stochastic gradient descent on θ (primal variable) for K steps
  - Policy update: Softmax over accumulated θ values
  - Data sampling: Independent samples from behavior policy's occupancy measure
  - Key data structures: Feature matrix Φ, covariance matrix Λ, parameter vectors θ, β

- Critical path:
  1. Sample data point (X_t, A_t, R_t, X'_t)
  2. Compute gradient estimate ˜g_β,t using current θ_t and v_t
  3. Update β_{t+1} via projected gradient ascent
  4. Inner loop: For k=1 to K-1, sample (X_{t,k}, A_{t,k}, X'_{t,k}) and update θ_{t,k+1}
  5. Average inner loop results to get θ_t
  6. Compute v_t and µ_t symbolically
  7. Update policy π_{t+1} = softmax(α∑Φθ_i)

- Design tradeoffs:
  - c=1 (unknown Λ) vs c=1/2 (known Λ): Tradeoff between requiring knowledge of behavior policy vs tighter error bounds
  - K inner loop steps: More steps → better value function approximation but higher computational cost
  - Learning rates α, ζ, η: Need to balance convergence speed with stability

- Failure signatures:
  - Large gradient variance: Indicates poor coverage or ill-conditioned Λ
  - Policy not improving: Suggests inner loop K is too small or learning rates are mis-tuned
  - Numerical instability: May occur if Λ is near-singular (poor coverage)

- First 3 experiments:
  1. Verify gradient estimator unbiasedness: Run algorithm with known optimal policy and check if E[˜g_β,t] = g_β,t
  2. Test coverage ratio impact: Compare performance with behavior policies having different coverage ratios
  3. Validate sample complexity: Measure ε vs n to confirm O(ε^-4) scaling

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the sample complexity be improved to the optimal O(ε^-2) rate for offline RL in linear MDPs?
- Basis in paper: [explicit] The paper states "By inspecting our proofs, it should be clear that the extra O(ε^-2) factor is due to the nested-loop structure of the algorithm. Therefore, we find it likely that our result can be improved using optimistic descent methods [6] or a two-timescale approach [15, 30]."
- Why unresolved: The current algorithm uses a nested-loop structure which introduces an extra O(ε^-2) factor in the sample complexity. The paper suggests that using alternative optimization methods could potentially remove this factor.
- What evidence would resolve it: Developing and analyzing a single-loop algorithm based on optimistic descent methods or a two-timescale approach that achieves O(ε^-2) sample complexity would resolve this question.

### Open Question 2
- Question: How can the algorithm be adapted to work with an unknown behavior policy without requiring knowledge of the covariance matrix Λ?
- Basis in paper: [explicit] The paper mentions "However, so does the algorithm from Jin et al. [14]. Zanette et al. [38] remove this requirement at the price of a computationally heavier algorithm." and "When Λ is unknown, our error bounds scale with Cϕ, 1, instead of the smaller Cϕ, 1/2."
- Why unresolved: The current algorithm requires knowledge of Λ to achieve the tighter bound with Cϕ, 1/2. While Zanette et al. [38] removed this requirement, their algorithm is computationally heavier.
- What evidence would resolve it: Designing an efficient algorithm that works with an unknown behavior policy and achieves the same sample complexity as when Λ is known would resolve this question.

### Open Question 3
- Question: How does the performance of the algorithm change when extending to non-linear function approximation?
- Basis in paper: [inferred] The paper focuses on linear function approximation in linear MDPs, but mentions that "Although function approximation, especially with neural networks, is widely used in practice, its theoretical understanding in the context of decision-making is still rather limited."
- Why unresolved: The theoretical guarantees of the algorithm are specific to linear function approximation in linear MDPs. Extending these guarantees to non-linear function approximation would require new theoretical analysis.
- What evidence would resolve it: Analyzing the algorithm's performance with non-linear function approximation, such as neural networks, and establishing sample complexity bounds would resolve this question.

## Limitations

- The algorithm relies heavily on the linear MDP assumption, which may not hold in many practical settings
- Requires either knowledge of the behavior policy's covariance matrix Λ or accepts looser error bounds
- The double-loop structure introduces computational overhead compared to single-loop alternatives
- Theoretical analysis doesn't include empirical validation or computational complexity analysis

## Confidence

- **Mechanism 1 (Reparametrization)**: High confidence - the mathematical derivation is rigorous and the low-variance property is well-established
- **Mechanism 2 (Double-loop structure)**: Medium confidence - while theoretically justified, the optimal choice of K and learning rates is not fully explored
- **Mechanism 3 (Coverage ratio)**: Medium confidence - the concept is novel but its practical implications and relationship to other coverage measures need further empirical validation
