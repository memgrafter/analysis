# Graph Mixer Networks

## Executive Summary
Graph Mixer Networks (GMN), also called Graph Nasreddin Nets (GNasNets), introduce a novel approach that applies MLP-Mixer principles to graph-structured data. The architecture builds upon a PNA model foundation with multiple aggregators and incorporates a Mixer block to enhance performance while reducing computational complexity. The method is evaluated on the ZINC dataset for graph regression tasks predicting chemical compound solubility.

## Method Summary
GMN adapts the MLP-Mixer architecture for graph data by using a PNA model with multiple aggregators as its foundation. The key innovation is the integration of a Mixer block that processes aggregated node features through layer normalization, linear layers, and residual connections. This block is applied after the PNA model aggregates features from multiple aggregators and degree scalers. The overall architecture aims to capture both local graph structure through the PNA foundation and global patterns through the Mixer block, achieving improved performance on graph regression tasks.

## Key Results
- GMN achieves a mean absolute error (MAE) of 0.212 on the ZINC dataset for predicting chemical compound solubility
- Outperforms Graph Transformers and baseline methods including GCN, GAT, and MPNN on the ZINC dataset
- Demonstrates reduced computational complexity compared to Graph Transformers while maintaining superior performance
