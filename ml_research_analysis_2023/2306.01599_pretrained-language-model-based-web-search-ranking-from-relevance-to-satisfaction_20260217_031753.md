# Pretrained Language Model based Web Search Ranking: From Relevance to Satisfaction

## Quick Facts
- **arXiv ID**: 2306.01599
- **Source URL**: https://arxiv.org/abs/2306.01599
- **Reference count**: 40
- **Primary result**: SAT-Ranker framework significantly improves user satisfaction in web search through multi-field PLM modeling

## Executive Summary
This paper addresses the challenge of ranking user satisfaction in web search by proposing SAT-Ranker, a framework that leverages pretrained language models (PLMs) to comprehensively model multiple dimensions of user satisfaction beyond traditional relevance metrics. The authors present a novel multi-field input schema that incorporates both textual and numerical features, modularizing each satisfaction dimension (relevance, quality, authority, recency) as separate input fields. The framework is designed for extensibility and practical industrial deployment, and has been successfully implemented in Baidu's search engine, demonstrating significant improvements in ranking performance across various evaluation sets.

## Method Summary
SAT-Ranker introduces a multi-field input schema that leverages PLMs to comprehensively model user satisfaction in web search. The framework modularizes different satisfaction dimensions as separate input fields, allowing the model to capture nuanced aspects of user experience including relevance, quality, authority, and recency. By incorporating both textual and numerical features in a unified framework, SAT-Ranker provides a more holistic approach to ranking compared to traditional relevance-focused methods. The modular design enables easy extension and adaptation to different satisfaction criteria, making it suitable for industrial applications.

## Key Results
- SAT-Ranker significantly improves user satisfaction across various evaluation sets
- The framework achieves remarkable gains in ranking performance compared to traditional methods
- SAT-Ranker is now fully deployed in Baidu's search engine, enhancing its usability

## Why This Works (Mechanism)
The framework works by comprehensively modeling multiple dimensions of user satisfaction through a multi-field input schema. Each dimension (relevance, quality, authority, recency) is modularized as an input field, allowing the PLM to learn distinct representations for each aspect. This approach enables the model to capture nuanced relationships between different satisfaction factors and their combined impact on user experience. The integration of both textual and numerical features provides a richer representation of query-document relationships, leading to more accurate satisfaction predictions.

## Foundational Learning
- **Pretrained Language Models (PLMs)**: Large-scale neural networks trained on massive text corpora that capture rich linguistic patterns and semantic relationships. Why needed: PLMs provide strong contextual representations that can encode complex relationships between queries and documents. Quick check: Verify that the PLM can effectively encode both textual and numerical features in the multi-field schema.
- **Multi-field Input Schema**: A design pattern where different aspects of input data are represented as separate fields. Why needed: Allows the model to learn distinct representations for each satisfaction dimension. Quick check: Ensure each field contributes meaningfully to the final ranking decision.
- **Modular Satisfaction Dimensions**: Breaking down user satisfaction into discrete components (relevance, quality, authority, recency). Why needed: Enables targeted modeling of different aspects of user experience. Quick check: Validate that each dimension captures meaningful variance in satisfaction scores.

## Architecture Onboarding

**Component Map**: User Query -> Multi-field Encoder -> Satisfaction Score -> Ranking

**Critical Path**: The critical path involves processing the user query through the multi-field encoder, which combines representations from each satisfaction dimension field to produce a final satisfaction score used for ranking.

**Design Tradeoffs**: The framework trades increased model complexity and computational cost for improved satisfaction modeling. While traditional methods focus on relevance alone, SAT-Ranker's multi-field approach requires more sophisticated architecture but captures a richer representation of user needs.

**Failure Signatures**: Potential failures include overfitting to Baidu's specific satisfaction metrics, underperformance on domains with different satisfaction criteria, and computational bottlenecks when scaling to massive query volumes.
