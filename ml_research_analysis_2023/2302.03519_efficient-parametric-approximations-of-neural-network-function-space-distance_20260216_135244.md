# Efficient Parametric Approximations of Neural Network Function Space Distance

## Quick Facts
- arXiv ID: 2302.03519
- Source URL: https://arxiv.org/abs/2302.03519
- Authors: 
- Reference count: 33
- Key outcome: Bernoulli Gated Linear Network (BGLN) achieves 99.77% average accuracy on Split MNIST while requiring significantly less memory than nonparametric FSD methods

## Executive Summary
This paper introduces a novel method for efficiently approximating the Function Space Distance (FSD) between neural networks, addressing a key challenge in continual learning and influence function estimation. The authors propose Linearized Activation Function TRick (LAFTR), which approximates networks as linear networks with stochastic gating, capturing nonlinear parameter interactions that second-order Taylor approximations miss. The resulting Bernoulli Gated Linear Network (BGLN) provides an efficient parametric FSD approximation specifically designed for ReLU networks.

## Method Summary
The method consists of two main components: LAFTR and BGLN. LAFTR linearizes the network's computation with respect to inputs rather than parameters, preserving nonlinear interactions between parameters across different layers. BGLN models ReLU activations as independent Bernoulli random variables and computes FSD using only first and second moments of activations and input data. The approach includes two variants: BGLN-S (stochastic) using Monte Carlo sampling for optimization, and BGLN-D (deterministic) using moment propagation for accurate FSD estimation.

## Key Results
- BGLN achieves 99.77% average accuracy on Split MNIST, competitive with state-of-the-art nonparametric methods
- Strong correlations with true FSD (Spearman rank-order: 96.36, Kendall's Tau: 79.19)
- Memory efficient: requires only P + A + d + d² storage versus nonparametric methods needing full dataset
- Accurately estimates influence functions without iterating over entire dataset

## Why This Works (Mechanism)

### Mechanism 1
LAFTR captures nonlinear parameter interactions that second-order Taylor approximations miss by linearizing with respect to inputs instead of parameters. This preserves nonlinear interactions between parameters across different layers that are lost in parameter-space linearization. The core assumption is that the dominant source of nonlinearity comes from activation functions rather than parameter interactions in linear layers.

### Mechanism 2
BGLN achieves memory efficiency by storing only first and second moments of activations and Bernoulli gating parameters. The FSD under squared Euclidean distance depends only on these moments, which can be computed recursively through the network. The core assumption is that activation functions are well-modeled by independent Bernoulli variables.

### Mechanism 3
BGLN-S provides practical stochastic approximation suitable for continual learning optimization by sampling from Bernoulli gating distribution and Gaussian input distribution. This provides an unbiased estimate of FSD computable in a single forward pass, making it suitable for stochastic gradient-based optimization. The core assumption is that the stochastic estimate correlates well enough with true FSD to serve as effective regularization.

## Limitations

- Limited evaluation to ReLU networks and standard vision datasets, performance on complex architectures with batch normalization or attention mechanisms remains uncertain
- Assumes ReLU activations can be accurately modeled as independent Bernoulli random variables, which may not hold for networks with significant unit co-adaptation
- While memory efficient compared to nonparametric methods, the storage requirement still scales quadratically with input dimensionality (d² term)
