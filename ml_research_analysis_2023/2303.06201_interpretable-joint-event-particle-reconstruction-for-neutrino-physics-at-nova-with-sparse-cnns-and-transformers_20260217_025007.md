# Interpretable Joint Event-Particle Reconstruction for Neutrino Physics at NOvA with Sparse CNNs and Transformers

## Quick Facts
- arXiv ID: 2303.06201
- Source URL: https://arxiv.org/abs/2303.06201
- Reference count: 40
- Primary result: 90% event classification accuracy and 6% improvement in per-particle reconstruction

## Executive Summary
This work presents TransformerCVN, a novel architecture combining sparse CNNs and transformer attention for joint neutrino event classification and particle reconstruction at NOvA. The model processes sparse 2D pixel-maps from simulated NOvA data using Minkowski sparse convolutions to embed spatial information, then applies shared transformer encoders to fuse context between particle prongs and the full event. Training employs focal loss to handle class imbalance, achieving 90% event classification accuracy and improving per-particle reconstruction by 6% over baselines. The approach demonstrates strong interpretability through attention and saliency analyses that reveal physically meaningful patterns.

## Method Summary
TransformerCVN embeds sparse 2D pixel-maps (100x80) from two detector views into dense vectors using Minkowski sparse convolutions with DenseNet architecture. These embeddings are processed by shared transformer encoders that allow contextual information to flow between prongs and the full event representation. Separate classifiers then output event types and per-prong particle identities. The model is trained on 6.3M simulated NOvA events using focal loss and AdamW optimization with cosine learning rate scheduling.

## Key Results
- Achieves 90% accuracy in classifying neutrino interaction types (νe CC, νμ CC, NC)
- Improves per-particle reconstruction accuracy by 6% over baseline models
- Demonstrates interpretable attention patterns that align with known particle physics principles

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Sparse CNN embeddings preserve spatial detail while reducing noise from zero-valued pixels
- Mechanism: Minkowski sparse convolutions compute only where data exists, preventing dilution of sparse signal by zeros
- Core assumption: Non-zero pixels in neutrino pixel-maps contain sufficient spatial correlation for meaningful convolution
- Evidence anchors: Pixel-maps are 0.84% non-zero on average; convolutions computed only at non-zero centers

### Mechanism 2
- Claim: Shared transformer encoders fuse particle-level context into individual prong classifications
- Mechanism: Self-attention allows each prong embedding to incorporate information from all other prongs and the full event representation
- Core assumption: Prong identities are interdependent and benefit from joint contextual reasoning
- Evidence anchors: Shared transformer encoder used for both prong and event embeddings; attention improves prong AUC across particle types

### Mechanism 3
- Claim: Attention weights reveal physically meaningful relationships between particle types and event classes
- Mechanism: Aggregated attention scores quantify how presence of specific particle types influences event classification decisions
- Core assumption: Network learns correlations that align with physical particle production mechanisms
- Evidence anchors: Attention patterns show diagonal structure with exceptions revealing physically meaningful interactions; electrons, muons, and neutral pions have largest impacts on respective event types

## Foundational Learning

- Sparse convolutions: Why needed here: Neutrino pixel-maps are 99.16% zeros on average, making standard dense convolutions computationally wasteful and potentially misleading
  - Quick check question: Why not simply threshold or crop the pixel-maps before applying standard convolutions?

- Set-based classification with transformers: Why needed here: Each event contains variable numbers of prongs with no inherent ordering, requiring permutation-invariant processing
  - Quick check question: How does the transformer architecture ensure order invariance without position embeddings?

- Focal loss for imbalanced classification: Why needed here: Particle types are unevenly distributed, with background classes dominating the dataset
  - Quick check question: What happens to classification accuracy if standard cross-entropy is used instead of focal loss?

## Architecture Onboarding

- Component map: Sparse DenseNet CNN (pixel-map embedding) → Shared transformer encoder → Per-prong and event classifiers
- Critical path: Pixel-map → Sparse convolution → Embedding → Transformer attention → Classification
- Design tradeoffs: Shared transformer weights save parameters but may limit specialization; focal loss improves minority class accuracy but can overfit
- Failure signatures: Prong confusion increases if transformer layers are too shallow; event classification drops if CNN embedding dimension is too low
- First 3 experiments:
  1. Remove transformer layer and classify prongs independently to measure attention contribution
  2. Replace sparse convolutions with dense convolutions to quantify sparsity benefit
  3. Train without focal loss to assess class imbalance handling

## Limitations
- Limited validation on real experimental data rather than simulated NOvA events
- Reliance on specific sparse CNN implementations that may not generalize to denser particle physics datasets
- Computational efficiency of sparse operations versus dense alternatives not benchmarked
