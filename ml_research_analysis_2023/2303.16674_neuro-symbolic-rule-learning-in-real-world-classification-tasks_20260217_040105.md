# Neuro-symbolic Rule Learning in Real-world Classification Tasks

## Quick Facts
- arXiv ID: 2303.16674
- Source URL: https://arxiv.org/abs/2303.16674
- Reference count: 40
- Primary result: Neural DNF-EO achieves accuracy=1 on multi-class classification while providing interpretable ASP rules

## Executive Summary
This work extends neural DNF modules to real-world multi-class and multi-label classification tasks. The authors propose neural DNF-EO with a constraint layer for enforcing mutual exclusivity in multi-class settings, and evaluate both vanilla neural DNF and DNF-EO on CUB-200-2011 and TMC2007-500 datasets. The results show that neural DNF-EO matches pure neural network performance while providing interpretable rules, and scales better than symbolic learners like FastLAS when the number of classes grows large.

## Method Summary
The approach uses semi-symbolic layers that approximate logical operations through weighted sums followed by tanh activation with bias parameters. For multi-class classification, neural DNF-EO adds a constraint layer with fixed weights to enforce mutual exclusivity. The training process uses cross-entropy loss, followed by a post-training pipeline of pruning, finetuning, thresholding, and rule extraction to convert continuous weights into symbolic ASP rules. The method is evaluated on CUB-200-2011 for bird classification and TMC2007-500 for anomaly detection from text.

## Key Results
- Neural DNF-EO achieves accuracy=1 on CUB-200-2011, matching pure neural network performance
- Rule extraction from neural DNF-EO produces interpretable ASP rules while maintaining classification accuracy
- Neural DNF-EO scales to 200 classes successfully, while FastLAS fails to learn in the same setting
- Vanilla neural DNF struggles with multi-label classification on TMC datasets, showing decreasing macro F1 scores as label count increases

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Neural DNF-EO enforces mutual exclusivity in multi-class classification while remaining trainable with cross-entropy loss
- Mechanism: Adds a constraint layer (C2) with fixed weights (-61) that implements the symbolic constraint "← class(X), class(Y), X ≠ Y". During training, this layer ensures that only one class can be true at a time, while at inference the layer is removed.
- Core assumption: The constraint layer's fixed weights are sufficiently strong (6 or -6) to saturate the tanh activation and enforce the logical constraint
- Evidence anchors: [abstract] "neural DNF-EO (Exactly One) which enforces mutual exclusivity in multi-class classification"

### Mechanism 2
- Claim: The semi-symbolic layer approximates logical conjunction/disjunction while avoiding gradient vanishing
- Mechanism: Uses weighted sum followed by tanh activation with bias parameter δ that controls logical behavior. When |δ| approaches 1, the layer behaves like conjunction or disjunction rather than multiplication-based t-norms.
- Core assumption: The tanh activation with controlled bias can approximate logical operations without suffering from vanishing gradients
- Evidence anchors: [section] "The semi-symbolic layer is defined as: y = f(∑ᵢ wᵢxᵢ + β) where β = δ(maxᵢ|wᵢ| - ∑ᵢ|wᵢ|)"

### Mechanism 3
- Claim: Post-training pipeline (pruning → finetuning → thresholding → extraction) successfully converts continuous weights to symbolic rules
- Mechanism: Prunes weights below threshold, retrains pruned model, discretizes remaining weights to ±6 based on validation performance, then extracts rules from saturated connections
- Core assumption: The thresholding process can identify weights that capture meaningful logical patterns without losing classification performance
- Evidence anchors: [section] "Our post-training pipeline consists of 4 stages: pruning, finetuning, thresholding and extraction"

## Foundational Learning

- Concept: Disjunctive Normal Form (DNF) logic
  - Why needed here: The neural DNF module is built on DNF principles to represent logical rules as conjunctions of literals combined by disjunctions
  - Quick check question: Can you explain why DNF is useful for representing classification rules compared to other logical forms?

- Concept: Mutual exclusivity constraint
  - Why needed here: Multi-class classification requires exactly one class to be true at a time, which is a logical constraint that standard MLPs don't enforce
  - Quick check question: What happens to an MLP's softmax output if you interpret values above 0.5 as "true"? Does it maintain mutual exclusivity?

- Concept: Differentiable logic operations
  - Why needed here: The semi-symbolic layers approximate logical operations (AND, OR, NOT) using continuous functions to enable gradient-based training
  - Quick check question: How does the tanh activation with bias parameter δ approximate logical conjunction versus disjunction?

## Architecture Onboarding

- Component map:
  Input layer → Semi-symbolic Conjunctive layer → Semi-symbolic Disjunctive layer → (Optional) Constraint layer → Output
  Post-training pipeline: Pruning → Finetuning → Thresholding → Rule extraction
  For multi-label: Vanilla neural DNF (no constraint layer)
  For multi-class: Neural DNF-EO (with constraint layer)

- Critical path:
  1. Data preprocessing (attribute extraction and filtering)
  2. Model training with appropriate loss function
  3. Post-training pipeline execution
  4. Rule extraction and validation

- Design tradeoffs:
  - Width of conjunctive layer vs. overfitting (wider allows more complex rules but may overfit)
  - Strength of constraint layer weights vs. training difficulty
  - Thresholding aggressiveness vs. rule quality and mutual exclusivity maintenance

- Failure signatures:
  - Multiple classes predicted as true (mutual exclusivity violation)
  - Rule extraction yields poor performance compared to trained model
  - Model fails to learn on datasets with limited general patterns
  - Memory issues when scaling to large numbers of classes/labels

- First 3 experiments:
  1. CUB-3 (small multi-class): Verify mutual exclusivity and rule extraction work on simple case
  2. TMC-3 (small multi-label): Test vanilla neural DNF performance on independent labels
  3. CUB-10 (medium multi-class): Check scalability and whether constraint layer maintains performance

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Why does the vanilla neural DNF model struggle with multi-label classification on the TMC dataset despite performing well on synthetic multi-label data?
- Basis in paper: [explicit] The authors note that the vanilla neural DNF model performs poorly on TMC-3, -5, -10, -15, and -22 datasets, with macro F1 scores decreasing as the number of labels increases, while performing well on synthetic datasets.
- Why unresolved: The paper attributes this to the TMC dataset potentially lacking general patterns/regularities, but this is speculative and not empirically tested. The authors suggest that the logically constrained bias in the semi-symbolic layers makes training more difficult, but do not explore alternative training strategies or model architectures.
- What evidence would resolve it: Comparative experiments testing the vanilla neural DNF on other multi-label datasets with varying degrees of complexity and regularity, or ablation studies isolating the effect of the logical constraints during training.

### Open Question 2
- Question: What is the root cause of the performance degradation in rule extraction from neural DNF-EO models as the number of classes increases beyond 20?
- Basis in paper: [explicit] The authors observe that the performance gap between the trained plain neural DNF and the thresholded version increases significantly after CUB-20, and attribute this to the thresholding process failing to maintain mutual exclusivity with more classes.
- Why unresolved: While the authors identify the thresholding process as the bottleneck, they do not propose or test alternative methods for maintaining mutual exclusivity during rule extraction, nor do they explore whether the underlying model architecture itself becomes insufficient for larger class spaces.
- What evidence would resolve it: Testing alternative thresholding strategies, exploring different architectures for the constraint layer, or applying the model to datasets with larger numbers of classes to determine if the issue is specific to the CUB dataset structure.

### Open Question 3
- Question: How does the scalability of neural DNF-based models compare to other neuro-symbolic approaches when applied to datasets with thousands of classes or labels?
- Basis in paper: [inferred] The authors demonstrate that neural DNF-EO scales well up to 200 classes (CUB-200) while FastLAS fails, but do not test the limits of this scalability or compare against other differentiable ILP methods on larger-scale problems.
- Why unresolved: The experiments focus on datasets with at most 200 classes and 22 labels. The paper does not explore whether the neural DNF architecture maintains its performance and interpretability advantages on datasets with orders of magnitude more classes/labels.
- What evidence would resolve it: Experiments applying neural DNF-based models to large-scale multi-class datasets (e.g., ImageNet with 1000+ classes) or extreme multi-label datasets (e.g., Wikipedia with thousands of labels), comparing performance and rule extraction quality against other neuro-symbolic approaches.

## Limitations
- Limited scalability testing: Only two datasets tested, with maximum of 200 classes
- Unexplored failure modes: Performance degradation on datasets with limited general patterns is only speculated upon
- Underspecified implementation details: Exact semi-symbolic layer implementation and constraint layer gradient flow not fully described

## Confidence
- High confidence: The neural DNF-EO model maintains classification performance comparable to MLPs while providing interpretable rules (supported by CUB-200-2011 and TMC2007-500 results)
- Medium confidence: The constraint layer successfully enforces mutual exclusivity without degrading training (mechanism plausible but limited validation)
- Low confidence: The scalability advantages over symbolic learners in large search spaces (only two datasets tested, FastLAS failure mode not fully characterized)
