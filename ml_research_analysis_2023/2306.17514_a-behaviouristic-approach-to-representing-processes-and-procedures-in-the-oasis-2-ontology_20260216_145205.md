# A behaviouristic approach to representing processes and procedures in the OASIS 2 ontology

## Quick Facts
- arXiv ID: 2306.17514
- Source URL: https://arxiv.org/abs/2306.17514
- Reference count: 31
- Extends OASIS 2 ontology to include processes and procedures for agent behavior representation

## Executive Summary
This paper extends the OASIS 2 ontology, a foundational OWL 2 framework for representing agent behavior, by adding support for processes and procedures. While OASIS 2 previously modeled agents, goals, tasks, and plans, it lacked mechanisms for representing multi-step processes that agents can repeatedly execute. The extension introduces new ontological classes including Process, Procedure, ProcedureState, and Event, integrating them with existing constructs for roles, tasks, and actions.

The resulting ontology provides a theoretical foundation for representing complex processes and procedures in semantic web applications, enabling more sophisticated agent planning capabilities. The behavioristic approach focuses on observable agent actions and their relationships rather than internal mental states, making it particularly suitable for web-based agent systems where interoperability and explicit representation are crucial.

## Method Summary
The authors extend OASIS 2 by introducing new ontological classes and relationships specifically designed to represent processes and procedures. They define Process as a general class for multi-step activities, Procedure as a specific type of process with defined steps, ProcedureState to track execution status, and Event to capture occurrences within processes. These new constructs are formally integrated with existing OASIS 2 components including agent roles, tasks, and actions through well-defined ontological relationships. The extension maintains OWL 2 compatibility while expanding the representational capabilities of the ontology to handle complex, repeatable agent behaviors.

## Key Results
- Introduces Process, Procedure, ProcedureState, and Event classes to OASIS 2 ontology
- Provides formal integration mechanisms between new process-related classes and existing OASIS 2 constructs
- Enables representation of multi-step, repeatable processes for agent planning in semantic web applications
- Maintains OWL 2 compatibility while significantly expanding ontological expressiveness

## Why This Works (Mechanism)
The extension works by creating a structured ontological framework that explicitly represents the temporal and causal relationships between process steps. By introducing ProcedureState, the ontology can track execution progress, while Event captures discrete occurrences that trigger or result from process steps. The integration with existing OASIS 2 constructs for roles and tasks ensures that processes can be properly contextualized within agent behavior frameworks, allowing for coherent planning and execution in semantic web environments.
