# Stimulating student engagement with an AI board game tournament

## Quick Facts
- arXiv ID: 2304.11376
- Source URL: https://arxiv.org/abs/2304.11376
- Reference count: 13
- Primary result: All student groups successfully implemented AI agents, with some using advanced minimax techniques, and reported high engagement through tournament competition

## Executive Summary
This paper presents a project-based course design that introduces second-year students to AI search techniques through building competitive game-playing agents. The course combines traditional lectures on programming paradigms and classical AI with hands-on implementation of AI agents for board games, culminating in a tournament competition. The pedagogical approach leverages gamification and peer-based learning to increase student motivation and engagement, with students working in groups to create agents that compete against each other using a custom game server protocol.

## Method Summary
The course structure integrates lectures on programming paradigms, classical AI for board games, and source code management with a group project requiring students to implement an AI agent for competitive gameplay. Students are evaluated through programming exercises, the quality of their AI agent implementation, and tournament performance. The tournament system employs a game server with a custom protocol for matchmaking between student agents. The course design emphasizes practical application of search methods through competitive programming, with evaluation based on both technical implementation and competitive success.

## Key Results
- All student groups successfully implemented functional AI agents
- Some groups experimented with advanced techniques like minimax with alpha-beta pruning
- High attendance and strong student interest were reported throughout the course

## Why This Works (Mechanism)
The competitive tournament format creates intrinsic motivation through gamification, encouraging students to apply theoretical knowledge to practical problems. Peer-based learning emerges naturally as students observe and learn from each other's implementations during the tournament. The project-based approach provides hands-on experience with AI concepts, making abstract search methods concrete through real-time gameplay. The combination of lectures and implementation ensures students understand both theoretical foundations and practical considerations.

## Foundational Learning
- Game tree search algorithms (Minimax, Alpha-Beta Pruning) - Needed for efficient decision-making in games; Quick check: Can explain time/space complexity trade-offs
- Search space complexity - Essential for understanding why optimization techniques matter; Quick check: Can calculate branching factor impacts
- Game state representation - Critical for efficient implementation; Quick check: Can design compact state encoding
- Protocol design for client-server communication - Required for tournament integration; Quick check: Can implement message parsing
- Source code management practices - Necessary for collaborative development; Quick check: Can use version control for team projects

## Architecture Onboarding
Component map: Lecture content -> Student implementation -> Game server -> Tournament matchmaking -> Performance evaluation
Critical path: Students learn search algorithms → Implement AI agent → Connect to game server → Compete in tournament → Receive evaluation
Design tradeoffs: Simple protocol vs. feature-rich communication; individual vs. group work; deterministic vs. probabilistic game outcomes
Failure signatures: Communication protocol mismatches, inefficient search causing timeouts, incorrect game state evaluation
First experiments: 1) Test basic client-server connectivity, 2) Verify game state synchronization, 3) Validate move legality checking
