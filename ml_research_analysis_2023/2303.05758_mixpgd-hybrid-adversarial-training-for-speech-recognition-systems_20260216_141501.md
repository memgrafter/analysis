# MIXPGD: Hybrid Adversarial Training for Speech Recognition Systems

## Quick Facts
- arXiv ID: 2303.05758
- Source URL: https://arxiv.org/abs/2303.05758
- Reference count: 0
- Key outcome: Hybrid adversarial training approach combining CTC loss with optimal transport distance achieves 4.1% WER improvement over previous best methods under PGD20 attack

## Executive Summary
mixPGD introduces a hybrid adversarial training approach for automatic speech recognition (ASR) systems that combines supervised connectionist temporal classification (CTC) loss with unsupervised optimal transport (OT) distance during adversarial sample generation. The method generates stronger adversarial examples than existing approaches by leveraging both label-based information and inter-sample relationships. Evaluated on LibriSpeech using a ResCNN+Bi-RNN architecture, mixPGD demonstrates superior robustness against various white-box attacks (FGSM, MIFGSM, PGD20, PGD100) and maintains performance under transfer-based black-box attacks.

## Method Summary
The mixPGD approach generates adversarial samples by combining CTC loss (supervised) with optimal transport distance (unsupervised) to create a hybrid loss function. This iterative process initializes adversarial examples with Gaussian noise, then updates them over multiple steps using gradients of the combined loss, constrained by maximum perturbation. The generated samples are used to train the ASR model, which consists of a residual convolutional neural network followed by bidirectional recurrent neural networks and fully connected layers. The method achieves improved robustness by training on adversarially crafted examples that are more challenging to defend against than those generated by standard methods.

## Key Results
- 28.75% WER on clean LibriSpeech test data
- 4.1% WER improvement over previous best methods under PGD20 white-box attack
- Superior performance against multiple attack types including FGSM, MIFGSM, PGD20, and PGD100
- Maintains robustness under transfer-based black-box attacks
- Ablation studies confirm OT distance outperforms KL divergence for unsupervised component
