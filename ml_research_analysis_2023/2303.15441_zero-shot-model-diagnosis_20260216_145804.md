# Zero-shot Model Diagnosis

## Quick Facts
- arXiv ID: 2303.15441
- Source URL: https://arxiv.org/abs/2303.15441

## Executive Summary
This paper presents ZOOM, a zero-shot method for diagnosing deep vision models by evaluating their sensitivity to arbitrary visual attributes. The approach leverages a pre-trained generative model (StyleGAN) and CLIP to automatically search for semantic counterfactual images that flip model predictions based on user-defined text prompts. ZOOM generates counterfactual images and provides sensitivity histograms quantifying the impact of each attribute on model performance. Extensive experiments across classification, keypoint detection, and segmentation tasks demonstrate the method's effectiveness in producing counterfactual images and offering sensitivity analysis without requiring labeled test sets. The approach also improves model robustness through fine-tuning with generated counterfactuals.

## Method Summary
ZOOM operates by using CLIP to extract attribute edit directions in StyleGAN's style space, then optimizing these directions to generate counterfactual images that flip model predictions while preserving ground truth. The method employs a three-term loss function combining targeted adversarial loss, structural loss for preserving image statistics, and attribute consistency loss. Sensitivity histograms are computed by measuring probability changes across sampled images for each attribute. The approach requires only a pre-trained generative model, CLIP, and user-defined text prompts, eliminating the need for labeled test data.

## Key Results
- ZOOM successfully generates counterfactual images that flip predictions across multiple visual domains and tasks
- Sensitivity histograms effectively quantify attribute impact on model performance without labeled test sets
- Fine-tuning with counterfactual images improves model distributional robustness
- The method works across classification, keypoint detection, and segmentation tasks

## Why This Works (Mechanism)

### Mechanism 1
- Claim: CLIP can map user text prompts to visual attribute directions in the StyleGAN latent space.
- Mechanism: The method uses CLIP's text encoder to generate embeddings for attribute prompts, then projects these embeddings through a learned channel relevance matrix to obtain style space directions. These directions control attribute intensity via linear combination.
- Core assumption: CLIP embeddings capture sufficient semantic information to control fine-grained visual attributes when projected through StyleGAN's latent space.
- Evidence anchors:
  - [abstract]: "CLIP enables text-driven applications that map user text representations to visual manifolds"
  - [section 3.2]: "CLIP text embedding difference ∆t by: ∆t = CLIPtext(p ⊕ a) − CLIPtext(p)"
  - [corpus]: Weak - no direct citations to CLIP-based attribute editing literature, though StyleCLIP [21] is cited in the paper
- Break condition: If CLIP fails to capture attribute semantics or the channel relevance matrix poorly maps text to style space, the attribute directions will not produce meaningful counterfactuals.

### Mechanism 2
- Claim: Adversarial optimization in attribute space generates counterfactual images that flip model predictions while preserving ground truth.
- Mechanism: The method optimizes attribute weights to minimize a loss combining targeted adversarial loss (flip prediction), structural loss (preserve image statistics), and attribute consistency loss (preserve original attributes).
- Core assumption: The attribute space is sufficiently disentangled that optimizing along these directions produces meaningful semantic changes without collapsing image quality.
- Evidence anchors:
  - [abstract]: "automatically search for semantic counterfactual images (i.e., synthesized images that flip the prediction)"
  - [section 3.3]: "L(s, w) = αLtarget(ˆ x) + βLstruct(ˆ x) + γLattr(ˆ x)"
  - [corpus]: Weak - no citations showing this specific multi-term loss formulation for counterfactual generation
- Break condition: If attribute space entanglement is high, optimizing one attribute will inadvertently change others, breaking the semantic consistency of the counterfactual.

### Mechanism 3
- Claim: Sensitivity histograms computed from probability changes across sampled images quantify attribute importance for model failure.
- Mechanism: For each attribute, the method generates counterfactuals, measures prediction probability change, and averages across images to create a normalized sensitivity score.
- Core assumption: The generated counterfactuals adequately sample the attribute space and the probability changes reflect true model sensitivity to that attribute.
- Evidence anchors:
  - [abstract]: "provides a sensitivity histogram quantifying the impact of each attribute"
  - [section 3.4]: "hi = Ex∼P(x),ˆ x=ZOOM(x,ai)|fθ(x) − fθ(ˆ x)|"
  - [corpus]: Weak - no citations to histogram-based sensitivity analysis in computer vision
- Break condition: If the sampling distribution from StyleGAN does not cover the attribute space adequately, or if the optimization gets stuck in local minima, the sensitivity scores will be inaccurate.

## Architecture Onboarding

- Component map: User text prompts → CLIP encoder → Channel relevance matrix → Attribute edit directions → StyleGAN generator → Counterfactual images → Target model → Loss computation → Weight optimization → Sensitivity analysis
- Critical path: Text → CLIP → Edit directions → Optimization → Counterfactual generation → Model evaluation → Sensitivity computation
- Design tradeoffs: Zero-shot diagnosis trades off perfect coverage of attribute space for avoiding labeled data collection; generative model quality affects counterfactual realism
- Failure signatures: Poor counterfactuals (unrealistic images, wrong attribute changes); sensitivity histograms that don't match known biases; optimization that fails to converge
- First 3 experiments:
  1. Generate counterfactuals for a simple binary classifier with one attribute to verify the optimization works
  2. Create synthetic imbalanced data to validate sensitivity histogram accuracy against ground truth
  3. Test multi-attribute counterfactual generation to verify linear combination of edit directions produces expected semantic changes

## Open Questions the Paper Calls Out

### Open Question 1
- Question: Can the proposed method handle non-face domains and abstract visual concepts?
- Basis in paper: [explicit] The paper mentions that StyleGAN2-ADA struggles with generating out-of-domain samples, but the method could be adapted to other generative models like stable diffusion. It also mentions that the method was tested on various domains including cars and churches.
- Why unresolved: The paper doesn't provide concrete results on non-face domains or abstract visual concepts. The extension to other generative models is proposed but not implemented or evaluated.
- What evidence would resolve it: Successful application of the method to diverse domains beyond faces, with quantitative and qualitative results demonstrating its effectiveness on abstract visual concepts and non-face objects.

### Open Question 2
- Question: How does the choice of text prompts affect the quality and interpretability of the generated counterfactuals?
- Basis in paper: [explicit] The paper mentions that the wording of prompts affects the resulting counterfactual image and provides examples of different phrasing for similar concepts.
- Why unresolved: While the paper shows some examples of prompt variations, it doesn't systematically study the impact of prompt choice on the quality and interpretability of counterfactuals.
- What evidence would resolve it: A comprehensive study comparing counterfactuals generated with different prompt phrasings for the same attribute, measuring both visual quality and alignment with the intended attribute.

### Open Question 3
- Question: What is the impact of the hyperparameter λ on the attribute editing process and the quality of generated counterfactuals?
- Basis in paper: [explicit] The paper mentions that λ primarily influences intensity control and denoising in the attribute editing process, but doesn't provide a detailed analysis of its impact.
- Why unresolved: The paper doesn't systematically study the effect of λ on the quality of generated counterfactuals or provide guidelines for choosing its value.
- What evidence would resolve it: An ablation study varying λ values and measuring their impact on counterfactual quality, sensitivity analysis accuracy, and visual fidelity of generated images.

## Limitations

- The method's effectiveness depends heavily on the quality and coverage of the generative model, potentially degrading for underrepresented or novel attribute combinations
- Critical hyperparameters (α, β, γ in the loss function, optimization step size, threshold λ) are not fully specified, requiring extensive tuning for different domains
- The approach assumes attributes are sufficiently disentangled in the latent space, which may not hold for highly correlated attributes or complex visual relationships

## Confidence

- High Confidence: The core methodology of using CLIP for attribute direction extraction and StyleGAN for counterfactual generation is technically sound and leverages established techniques.
- Medium Confidence: The effectiveness of the three-term loss function for generating semantically meaningful counterfactuals that flip predictions while preserving other attributes is demonstrated but may require domain-specific tuning.
- Medium Confidence: The sensitivity histogram as a diagnostic tool provides useful insights but may not capture all failure modes, particularly for attributes that interact in complex ways.

## Next Checks

1. **Cross-Domain Robustness Test**: Apply ZOOM to domains not covered in the paper (e.g., medical imaging, satellite imagery) to evaluate generalizability and identify domain-specific failure modes.

2. **Ablation Study on Loss Components**: Systematically remove each component (structural loss, attribute consistency loss) from the optimization to quantify their individual contributions to counterfactual quality and diagnostic utility.

3. **Attribute Interaction Analysis**: Design experiments with highly correlated attributes to test whether the method can disentangle their effects or if it produces confounded sensitivity scores.
