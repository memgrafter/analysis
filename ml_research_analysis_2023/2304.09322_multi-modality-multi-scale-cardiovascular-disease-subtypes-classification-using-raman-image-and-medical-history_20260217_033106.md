# Multi-Modality Multi-Scale Cardiovascular Disease Subtypes Classification Using Raman Image and Medical History

## Quick Facts
- arXiv ID: 2304.09322
- Source URL: https://arxiv.org/abs/2304.09322
- Reference count: 40
- Primary result: M3S model achieves 0.9330 accuracy, 0.9379 precision, 0.9291 recall, 0.9752 specificity, and 0.9334 F1 score for CVD subtype classification

## Executive Summary
This paper introduces a novel multi-modality multi-scale (M3S) deep learning model for classifying cardiovascular disease subtypes using Raman spectroscopy and medical history data. The model features a two-branch architecture that processes both spectral data (converted to images via Gramian Angular Fields) and medical history information, with a sophisticated fusion mechanism that combines features through probability and trainable weight matrices. Evaluated on an in-house dataset, the M3S model demonstrates superior performance compared to state-of-the-art methods, showing promise for non-invasive CVD diagnosis in clinical applications.

## Method Summary
The M3S model consists of two key components: a multi-scale feature extraction module and a multi-modality data fusion module. The feature extraction module converts Raman spectroscopy data into images of varying resolutions using Gramian Angular Fields (GAF), then processes these through a two-branch convolutional neural network to extract rich spectral features. The data fusion module combines these extracted Raman features with medical history information using a probability matrix and a trainable weight matrix, allowing the model to leverage complementary information from both data sources for improved classification performance. The model is trained and evaluated on an in-house dataset of cardiovascular disease patients.

## Key Results
- M3S model achieves 0.9330 accuracy, 0.9379 precision, 0.9291 recall, 0.9752 specificity, and 0.9334 F1 score
- Outperforms state-of-the-art methods in CVD subtype classification
- Demonstrates effectiveness of combining Raman spectroscopy with medical history data

## Why This Works (Mechanism)
The M3S model's superior performance stems from its ability to extract multi-scale spectral features through Gramian Angular Field conversion and CNN processing, combined with the integration of complementary medical history information via a sophisticated fusion mechanism. The multi-scale approach captures both local and global spectral patterns, while the fusion module enables the model to weigh the importance of spectral versus clinical features dynamically through trainable weight matrices. This multi-modal integration allows the model to leverage the full diagnostic potential of both data sources, resulting in more accurate CVD subtype classification than either modality alone could achieve.

## Foundational Learning

- Gramian Angular Fields (GAF): Transform time-series data into images by encoding temporal correlation; needed for converting Raman spectra to visual format suitable for CNN processing; quick check: visualize GAF outputs for different Raman spectra

- Multi-scale feature extraction: Process data at multiple resolutions to capture both local and global patterns; needed to extract comprehensive information from Raman images; quick check: compare single-scale vs multi-scale performance

- Multi-modality data fusion: Combine complementary information from different data sources; needed to leverage both spectral and clinical features for improved classification; quick check: ablate medical history component and measure performance drop

## Architecture Onboarding

- Component map: Raman spectra -> GAF conversion -> Multi-scale CNN -> Feature extraction -> Fusion module <- Medical history -> Probability matrix -> Trainable weight matrix -> Classification output

- Critical path: Raman data → GAF → CNN → Fusion → Output (primary classification pipeline)

- Design tradeoffs: Multi-scale processing increases computational cost but improves feature extraction; fusion mechanism adds complexity but enables complementary information utilization

- Failure signatures: Poor GAF conversion quality leads to inadequate spectral representation; imbalanced medical history data causes fusion bias; overfitting to in-house dataset reduces generalization
