# Forecasting Pressure Of Ventilator Using A Hybrid Deep Learning Model Built With Bi-LSTM and Bi-GRU To Simulate Ventilation

## Quick Facts
- arXiv ID: 2302.09691
- Source URL: https://arxiv.org/abs/2302.09691
- Reference count: 17
- Primary result: Hybrid Bi-LSTM/Bi-GRU model achieves 0.145 MAE and 0.094 MSE for ventilator pressure forecasting

## Executive Summary
This paper presents a hybrid deep learning model combining Bi-LSTM and Bi-GRU networks with SELU activation for forecasting ventilator pressure. The model processes time-series sensor data from mechanical ventilators to predict pressure values, supporting simulation-based ventilation systems. Using robust scaling for preprocessing and Adam optimization, the architecture demonstrates strong predictive performance with low error rates. The approach outperforms three recent baseline methods while maintaining effective convergence characteristics.

## Method Summary
The proposed method employs a hybrid deep learning architecture consisting of seven Bi-LSTM layers, five Bi-GRU layers, four multiply layers, and five batch normalization layers. The model uses SELU activation functions and is trained with the Adam optimizer using a batch size of 512. Input data undergoes robust scaling preprocessing to handle potential outliers in ventilator pressure measurements. The architecture processes time-series features including airway resistance, lung compliance, solenoid valve controls, and time-step information to predict pressure values.

## Key Results
- Achieved 0.145 MAE and 0.094 MSE on test data
- Outperformed three recent baseline approaches
- Demonstrated effective convergence with low error rates
- Successfully handled time-series dependencies in ventilator pressure data

- Core assumption: The dataset exhibits both short-term and long-term dependencies that benefit from parallel bidirectional processing.

### Mechanism 2
- Claim: SELU activation maintains self-normalizing properties, accelerating convergence and reducing internal covariate shift.
- Mechanism: SELU automatically scales and shifts activations to preserve mean and variance across layers, eliminating the need for batch normalization in some cases and improving training stability.
- Core assumption: The network depth (12+ layers) benefits from activation functions that maintain statistical properties across layers.

- Claim: Robust scaling handles outliers in ventilator pressure measurements better than standard normalization.
