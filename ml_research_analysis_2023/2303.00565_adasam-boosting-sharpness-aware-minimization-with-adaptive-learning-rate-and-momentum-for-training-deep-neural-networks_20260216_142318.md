# AdaSAM: Boosting Sharpness-Aware Minimization with Adaptive Learning Rate and Momentum for Training Deep Neural Networks

## Quick Facts
- **arXiv ID**: 2303.00565
- **Source URL**: https://arxiv.org/abs/2303.00565
- **Reference count**: 40
- **Key outcome**: AdaSAM achieves O(1/√(bT)) convergence rate with linear speedup w.r.t. batch size b

## Executive Summary
AdaSAM introduces a novel optimizer that combines Sharpness-Aware Minimization (SAM) with adaptive learning rates and momentum acceleration. The key innovation is a delayed second-order momentum term that decouples the SAM perturbation from the adaptive learning rate computation, enabling theoretical convergence guarantees. The authors prove that AdaSAM achieves a convergence rate of O(1/√(bT)), demonstrating linear speedup with respect to mini-batch size. Experiments on GLUE benchmark tasks show AdaSAM outperforms SGD, AMSGrad, and SAM in both convergence speed and final accuracy.

## Method Summary
AdaSAM integrates SAM's perturbation step with Adam-like adaptive learning rates and momentum acceleration. The algorithm introduces a delayed second-order momentum term to decouple the stochastic gradient steps from the adaptive learning rate computation during convergence analysis. The adaptive learning rate ηt = 1/√vt is bounded through the second-order momentum term, enabling theoretical analysis. The method maintains SAM's double gradient computation while adding momentum and adaptive learning rate components, resulting in three hyperparameters (ρ, γ, β1) to tune.

## Key Results
- Proven convergence rate of O(1/√(bT)) where b is mini-batch size and T is iteration count
- Linear speedup with respect to batch size demonstrated theoretically
- Outperforms SGD, AMSGrad, and SAM on GLUE benchmark tasks
- Demonstrates faster convergence and higher final accuracy on NLP tasks

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: AdaSAM achieves linear speedup with respect to mini-batch size b by bounding the adaptive learning rate to a limited range.
- **Mechanism**: The adaptive learning rate ηt = 1/√vt is bounded due to the second-order momentum term vt being limited by the bounded gradient assumption, allowing decoupling of stochastic gradient steps from adaptive learning rate and momentum steps.
- **Core assumption**: Stochastic gradients are uniformly bounded (∥∇fi(x)∥∞ ≤ G) and adaptive learning rate remains within finite range.
- **Evidence anchors**: [abstract], [section III-B], [corpus] (weak)
- **Break condition**: Unbounded gradients or unlimited growth of second-order momentum term breaks linear speedup proof.

### Mechanism 2
- **Claim**: Delayed second-order momentum term decouples SAM perturbation step from adaptive learning rate computation.
- **Mechanism**: Delayed momentum term allows decomposition of E[gt⊙ηt] into E[gt⊙ηt−1] + E[gt⊙(ηt−ηt−1)], where first term is bounded using L-smooth condition and second term is shown small.
- **Core assumption**: Perturbed gradient gt can be approximated as ∇xfb(xt + ρ∇f(xt)/∥∇f(xt)∥) when taking expectations.
- **Evidence anchors**: [abstract], [section III-B], [corpus] (weak)
- **Break condition**: Breakdown of gradient approximation in highly non-convex landscapes.

### Mechanism 3
- **Claim**: Momentum acceleration introduces extra term absorbed by auxiliary sequence without hurting convergence.
- **Mechanism**: Momentum term Emt−1⊙ηt is bounded by introducing auxiliary sequence zt = xt + β1/(1−β1)(xt−xt−1), showing summation over iterations is controllable.
- **Core assumption**: Difference between consecutive adaptive learning rates ∥ηt−1−ηt∥ remains bounded and diminishes over time.
- **Evidence anchors**: [section III-B], [section III-C], [corpus] (weak)
- **Break condition**: If ∥ηt−1−ηt∥ does not diminish or grows large, momentum-induced term cannot be absorbed.

## Architecture Onboarding

- **Component map**: SAM perturbation (δ(xt) = ρst/∥st∥) → Gradient computation (st = ∇xfb(xt)) → Momentum update (mt = β1mt−1 + (1−β1)gt) → Adaptive learning rate computation (ηt = 1/√vt) → Parameter update

- **Critical path**: SAM perturbation → Gradient computation → Momentum update → Adaptive learning rate computation → Parameter update

- **Design tradeoffs**:
  - Computational cost: Double gradient computation (like SAM) vs. improved convergence and generalization
  - Hyperparameter sensitivity: Three hyperparameters (ρ, γ, β1) vs. automatic learning rate tuning
  - Memory overhead: Additional momentum terms vs. better performance

- **Failure signatures**:
  - Divergence: If learning rate grows unbounded or momentum term oscillates
  - Slow convergence: If perturbation radius ρ is too small or adaptive learning rate is too conservative
  - Poor generalization: If balance between SAM perturbation and adaptive learning rate is suboptimal

- **First 3 experiments**:
  1. Compare AdaSAM vs. AMSGrad on simple convex problem (logistic regression) to verify adaptive learning rate component works correctly
  2. Test AdaSAM on non-convex problem (small neural network) with varying perturbation radii ρ to understand impact
  3. Benchmark AdaSAM vs. SAM and AMSGrad on GLUE tasks with different batch sizes to verify linear speedup property

## Limitations
- Theoretical analysis relies on strong assumptions including bounded gradients and sufficiently small perturbation radius
- Limited ablation studies to isolate contribution of each component (SAM, adaptive learning rate, momentum)
- Hyperparameter sensitivity analysis is limited with justification for specific values not fully provided
- Assumes deterministic gradients in several lemmas while practical algorithm operates in stochastic setting

## Confidence
- **High Confidence**: Core convergence rate of O(1/√(bT)) and its implication of linear speedup with batch size - proof structure is mathematically rigorous
- **Medium Confidence**: Practical effectiveness of decoupling technique using delayed second-order momentum - theoretically sound but empirical benefits depend on problem characteristics
- **Low Confidence**: Assumption that momentum-induced term can always be absorbed by auxiliary sequence without affecting convergence guarantees, particularly in highly non-convex landscapes
