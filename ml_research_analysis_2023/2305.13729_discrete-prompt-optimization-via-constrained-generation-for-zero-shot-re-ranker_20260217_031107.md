# Discrete Prompt Optimization via Constrained Generation for Zero-shot Re-ranker

## Quick Facts
- arXiv ID: 2305.13729
- Source URL: https://arxiv.org/abs/2305.13729
- Reference count: 21
- Key outcome: Proposes Co-Prompt method that generates interpretable prompts through discriminator-guided beam search, achieving state-of-the-art re-ranking performance without parameter updates.

## Executive Summary
This paper introduces Constrained Prompt generation (Co-Prompt), a novel method for optimizing discrete prompts in zero-shot re-ranking scenarios. The approach uses a pre-trained language model as a generator to sample prompt candidates, while a zero-shot re-ranker acts as a discriminator to evaluate prompt quality based on query generation scores. By iteratively generating and evaluating prompts through beam search without updating model parameters, Co-Prompt discovers high-quality prompts that significantly improve document ranking performance compared to manual prompts and other optimization methods. The method also produces more interpretable prompts that follow human language patterns.

## Method Summary
Co-Prompt optimizes prompts through a constrained generation framework where a generator (decoder-only PLM like GPT-2) samples prompt tokens based on prior probabilities, and a discriminator (zero-shot re-ranker like T0) evaluates prompt quality by computing likelihood scores for document-query pairs. The method employs beam search to efficiently explore the discrete prompt space, iteratively building prompt sequences up to a maximum length. At each step, the generator samples top-K tokens, the discriminator evaluates the top-K prompt sequences, and the best-K sequences are selected for the next iteration. This process continues until the maximum prompt length is reached, after which the top-N final prompts are selected for re-ranking documents and evaluating performance.

## Key Results
- Co-Prompt achieves superior re-ranking performance compared to baseline methods (Null Prompt, Manual Prompt, P-Tuning, RL-Prompt) on MS-MARCO and Natural Questions datasets.
- Generated prompts demonstrate better interpretability and human-like language patterns compared to ungrammatical outputs from other optimization methods.
- Performance improvements are consistent across different metrics (ACC, nDCG, MAP) and model architectures (T0, OPT).

- Core assumption: Higher query generation scores from the re-ranker indicate better prompts for distinguishing relevant documents.

## Architecture Onboarding

- Component map:
  - Retriever (BM25 or DPR) -> Zero-shot Re-ranker (T0 or OPT) -> Generator (GPT-2 or OPT) -> Prompt Optimizer (Co-Prompt) -> Evaluation Metrics (ACC, nDCG, MAP)

- Critical path:
  1. Initialize with start token and beam width
  2. For each position in prompt sequence:
     - Generator samples top-K tokens based on prior
     - Discriminator evaluates top-K prompt sequences
     - Select best-K sequences for next iteration
  3. After reaching maximum length, select final top-N prompts
  4. Use selected prompts to re-rank documents and evaluate performance

- Design tradeoffs:
  - Beam width vs. computational cost: Larger beam width explores more candidates but increases computation
  - Maximum prompt length vs. prompt quality: Longer prompts may capture more nuance but risk becoming verbose
  - Generator choice vs. vocabulary compatibility: Using GPT-2 with T0 introduces vocabulary mismatch but maintains decoder-only architecture

- Failure signatures:
  - Prompts remain ungrammatical despite multiple iterations
  - Performance plateaus below baseline with manual prompts
  - Computational cost becomes prohibitive with large beam sizes
  - Generated prompts show vocabulary mismatch artifacts

- First 3 experiments:
  1. Baseline comparison: Run Co-Prompt with null prompt, manual prompt, and compare against P-tuning and RL-Prompt on MS-MARCO dataset
  2. Generator ablation: Test Co-Prompt with different generator models (GPT-2 Base, GPT-2 Large, GPT-2 XL) to observe impact on prompt quality
  3. Metric ablation: Compare base metric vs. contrastive metric to understand impact on re-ranking performance

## Limitations

- The computational cost of beam search grows exponentially with beam width and prompt length, making scalability challenging for longer prompts or larger vocabulary sizes.
- The vocabulary mismatch between GPT-2 (generator) and T0 (re-ranker) introduces complexity that may affect prompt generation quality and requires careful handling.
- The assumption that higher query generation scores indicate better prompts for distinguishing relevant documents needs empirical validation, as the correlation between the metric and actual prompt quality is not guaranteed.

## Confidence

**High Confidence**: The claim that Co-Prompt improves re-ranking performance over baseline methods (Null Prompt, Manual Prompt, P-Tuning, RL-Prompt) on MS-MARCO and Natural Questions datasets. This is supported by multiple experimental results across different metrics (ACC, nDCG, MAP) and models (T0, OPT).

**Medium Confidence**: The claim that Co-Prompt generates more interpretable prompts than other optimization methods. While the paper provides qualitative comparisons showing Co-Prompt produces grammatical prompts versus ungrammatical outputs from RL-Prompt, interpretability is inherently subjective and the paper lacks systematic human evaluation.

**Low Confidence**: The claim that the re-ranker's metric directly guides the generator toward optimal prompts through the Bayes' rule formulation. The paper presents this mechanism but does not provide ablation studies or alternative formulations to validate that this specific approach is necessary or superior to simpler optimization strategies.

## Next Checks

1. **Metric Correlation Validation**: Conduct experiments that directly test the correlation between prompt quality (measured by human evaluation or downstream task performance) and the re-ranker's likelihood scores. This would validate whether the discriminator's metric actually captures what makes a prompt effective for re-ranking.

2. **Computational Efficiency Analysis**: Measure the exact computational cost (time and memory) of Co-Prompt with different beam widths and prompt lengths, then compare against the performance gains. This would quantify the practical trade-off between exploration breadth and computational feasibility.

3. **Vocabulary Mismatch Investigation**: Implement a controlled experiment using the same model for both generator and re-ranker (e.g., both GPT-2 or both T0) to isolate the impact of vocabulary compatibility on prompt quality and re-ranking performance.
