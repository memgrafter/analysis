# Offline Multi-Agent Reinforcement Learning with Coupled Value Factorization

## Quick Facts
- arXiv ID: 2306.08900
- Source URL: https://arxiv.org/abs/2306.08900
- Authors: Multiple
- Reference count: 40
- Primary result: OMAC achieves state-of-the-art performance on offline StarCraft II micro-management tasks through coupled value factorization and in-sample learning

## Executive Summary
This paper addresses the challenge of offline multi-agent reinforcement learning (MARL) by introducing OMAC, a method that combines coupled value factorization with in-sample learning. The approach decomposes the global value function into local and shared components while maintaining credit assignment consistency, enabling stable learning from offline datasets without distributional shift. OMAC achieves state-of-the-art performance on SMAC benchmarks while demonstrating superior data efficiency compared to existing offline MARL methods.

## Method Summary
OMAC uses a coupled value factorization (CVF) scheme that decomposes the global Q-value function into local and shared components, allowing agents to learn from offline datasets without evaluating out-of-distribution actions. The method performs in-sample learning on decomposed local state-value functions using expectile regression, implicitly conducting max-Q operations at the local level while avoiding distributional shift. Coupled credit assignment (CCA) enforces consistency between state-value and Q-value functions by sharing observation encoding between weight functions. Value functions and policies are learned separately, with policies updated using advantage-weighted regression after value learning converges.

## Key Results
- OMAC achieves state-of-the-art performance on four SMAC offline tasks, outperforming baseline methods including ICQ, OMAR, BCQ-MA, and CQL-MA
- The method demonstrates superior data efficiency, achieving higher returns with less training data
- Ablation studies show that both coupled value factorization and coupled credit assignment contribute significantly to OMAC's performance and stability

## Why This Works (Mechanism)

### Mechanism 1
- Claim: OMAC's coupled value factorization enables in-sample learning that avoids distributional shift while implicitly performing max-Q operation at the local level.
- Mechanism: The global value function is decomposed into local state-value functions and shared components. Local state-value functions are learned as upper expectiles of target Q-values from the dataset, implicitly capturing max-Q without querying out-of-distribution actions.
- Core assumption: The expectile regression with high 𝜏 (close to 1) can approximate the maximum Q-value over dataset-constrained actions.
- Evidence anchors:
  - [abstract]: "OMAC performs in-sample learning on the decomposed local state-value functions, which implicitly conducts max-Q operation at the local level while avoiding distributional shift"
  - [section 4.2.1]: "we can implicitly perform the above max-Q operation by leveraging the decomposed state-value functions 𝑉𝑖, while also avoiding explicitly learning the behavior policy 𝜋𝛽"
  - [corpus]: No direct evidence found in neighboring papers about expectile-based max-Q approximation in offline MARL.
- Break condition: If the dataset is too small or sparse, the expectile may not capture the true maximum Q-value, leading to suboptimal policies.

### Mechanism 2
- Claim: Coupled credit assignment (CCA) improves learning stability by enforcing consistency between state-value and Q-value credit assignment.
- Mechanism: CCA shares observation encoding between 𝑤𝑣 and 𝑤𝑞 weight functions, making training on one update parameters of the other, leading to more regularized global-local relationships.
- Core assumption: Sharing observation encoding between weight functions creates beneficial coupling that improves credit assignment consistency.
- Evidence anchors:
  - [abstract]: "OMAC poses an extra coupled credit assignment scheme between state-value and Q-value functions to enforce consistency"
  - [section 4.1.2]: "CCA enforces a coupled relationship between 𝑤𝑣(𝒐) and 𝑤𝑞(𝒐,𝒂) by sharing the same observation encoding structure"
  - [section 6.4.2]: "OMAC has better performance and stability than OMAC-CVF-w/o-CCA, suggesting the important contribution of CCA"
- Break condition: If the network architecture is too shallow or the coupling is too restrictive, it may limit the model's expressiveness and harm performance.

### Mechanism 3
- Claim: Separated learning of value functions and policies improves stability by avoiding bootstrapping error accumulation.
- Mechanism: Local state-value and Q-value functions are learned completely from data without involving policies, then policies are learned separately using advantage-weighted regression.
- Core assumption: Learning value functions without policy involvement prevents distributional shift caused by evaluating OOD actions from policies.
- Evidence anchors:
  - [abstract]: "OMAC performs in-sample learning on the decomposed local state-value functions, which implicitly conducts max-Q operation at the local level while avoiding distributional shift caused by evaluating out-of-distribution actions"
  - [section 4.2.2]: "The learning of both local and global value functions in OMAC is completely performed in an in-sample manner without the involvement of the agent policies 𝜋𝑖"
  - [section 6.4.3]: "OMAC performs much better than CVF-maxQ, which clearly suggests the advantage of performing local max-Q operation in an implicit and in-sample manner under offline learning"
- Break condition: If the advantage-weighted regression for policy learning is too conservative (low 𝛽), it may lead to overly cautious policies that don't exploit learned value functions effectively.

## Architecture Onboarding

- Component map:
  - Local state-value networks 𝑉𝑖 (one per agent) -> Local Q-value networks 𝑄𝑖 (one per agent) -> Shared state-value network 𝑉𝑠ℎ𝑎𝑟𝑒 -> Weight networks 𝑤𝑣 and 𝑤𝑞 for credit assignment -> Policy networks 𝜋𝑖 (one per agent) -> Target networks ¯𝑄𝑖 for stability

- Critical path:
  1. Sample batch (𝒐, 𝒂, 𝑟, 𝒐′) from dataset
  2. Update local state-value functions 𝑉𝑖 via expectile regression
  3. Compute global value functions 𝑉𝑡𝑜𝑡 and 𝑄𝑡𝑜𝑡 using coupled factorization
  4. Update local Q-value and weight networks using TD loss
  5. Soft update target networks
  6. After value learning converges, update policies using advantage-weighted regression

- Design tradeoffs:
  - High expectile parameter 𝜏 (close to 1) gives better approximation of max-Q but may be less stable with limited data
  - Temperature parameter 𝛽 in policy learning trades off between exploitation and conservatism
  - Coupled vs independent credit assignment affects expressiveness vs stability

- Failure signatures:
  - High variance in training curves suggests instability in value function learning
  - Performance plateauing below dataset quality suggests insufficient max-Q approximation
  - Policy performance much worse than value functions suggests conservative policy learning

- First 3 experiments:
  1. Verify expectile regression correctly approximates maximum Q-values on a simple dataset
  2. Test coupled vs independent credit assignment on a small SMAC task
  3. Validate in-sample learning prevents distributional shift by comparing OOD action evaluation
