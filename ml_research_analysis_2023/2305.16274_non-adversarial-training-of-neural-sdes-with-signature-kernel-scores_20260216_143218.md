# Non-adversarial training of Neural SDEs with signature kernel scores

## Quick Facts
- arXiv ID: 2305.16274
- Source URL: https://arxiv.org/abs/2305.16274
- Reference count: 40
- Primary result: Novel non-adversarial training of Neural SDEs using signature kernel scores for time series generation with memory-efficient backpropagation

## Executive Summary
This paper introduces a novel approach to training Neural Stochastic Differential Equations (SDEs) for time series generation using signature kernel scores. Unlike adversarial training methods that require min-max optimization, this framework minimizes a strictly proper scoring rule based on signature kernels. The method provides theoretical guarantees through the characteristic property of signature kernels on compact path spaces and enables memory-efficient training via linear path-dependent PDEs. The framework is demonstrated on synthetic and real-world financial data including rough volatility models, forex forecasting, and limit order book dynamics.

## Method Summary
The method trains Neural SDEs by minimizing expected signature kernel scores between generated and real data paths. The signature kernel score is computed by solving a system of linear path-dependent PDEs, which allows for memory-efficient adjoint-based backpropagation. The framework extends to infinite-dimensional spaces, enabling spatiotemporal data generation. Training involves sampling from both the data distribution and the Neural SDE, interpolating paths to continuous form, evaluating signature kernel scores via PDE solvers, and updating the Neural SDE parameters through gradient descent.

## Key Results
- Achieves better performance than GAN-based methods on rough volatility modeling, forex forecasting, and limit order book simulation
- Provides existence and uniqueness guarantees for the minimizer through strict properness of signature kernel scores
- Enables memory-efficient backpropagation through linear PDE formulations instead of storing intermediate SDE solver states
- Successfully extends to spatiotemporal data generation with natural treatment of infinite-dimensional path spaces

## Why This Works (Mechanism)

### Mechanism 1
The signature kernel score provides a strictly proper scoring rule that ensures the trained Neural SDE converges to the true data distribution. The signature kernel is characteristic on compact path spaces, meaning it uniquely identifies probability measures. The score ϕsig(P, y) = E[ksig(x, x')] - 2E[ksig(x, y)] assigns the lowest expected score when the proposed distribution P matches the true distribution Q. This strict properness guarantees that minimizing the score objective leads to the true data distribution. The core assumption is that data paths have bounded variation and the signature kernel remains characteristic on the relevant path space topology.

### Mechanism 2
The linear path-dependent PDE formulation enables memory-efficient backpropagation through the generator-discriminator pair. The signature kernel evaluation via equation (2) reduces to solving a linear hyperbolic PDE system. This allows adjoint-based backpropagation that is more memory-efficient than standard SDE solver backpropagation. The PDE solution provides the gradient information needed for training without storing intermediate states. The core assumption is that the PDE solver provides sufficiently accurate approximations of the signature kernel for gradient computation.

### Mechanism 3
The framework extends naturally to infinite-dimensional path spaces, enabling spatiotemporal data generation. The signature kernel is well-defined for paths with values in Hilbert spaces, including infinite-dimensional function spaces like L²(D). This allows the same training framework to generate spatiotemporal signals by treating each spatial location as an additional dimension in the path space. The core assumption is that inner products in the infinite-dimensional space can be approximated using discrete observations.

## Architecture Onboarding

- Component map:
  Generator -> Signature Kernel Score Evaluator -> Loss -> Gradient -> Generator Update
  Data Pipeline -> Path Interpolator -> Continuous Paths -> Signature Kernel Evaluator

- Critical path:
  1. Sample batch from data distribution
  2. Generate corresponding batch from Neural SDE
  3. Interpolate both sets of paths to continuous form
  4. Evaluate signature kernel scores via PDE solver
  5. Compute gradient and update Neural SDE parameters

- Design tradeoffs:
  - PDE solver accuracy vs training speed: Higher dyadic refinement levels give more accurate gradients but slower training
  - Path scaling: Too small → lower-order terms dominate; too large → numerical overflow
  - Kernel smoothing parameter: Affects expressivity vs generalization

- Failure signatures:
  - Oscillating loss during training → potential mode collapse or improper learning rate
  - Loss plateauing early → insufficient expressivity in generator networks
  - Numerical instability in PDE solver → path scaling issues or discretization problems

- First 3 experiments:
  1. Train on geometric Brownian motion data with simple Neural SDE architecture to verify basic functionality
  2. Test different PDE solver refinement levels to understand accuracy-speed tradeoff
  3. Validate signature kernel characteristic property on synthetic path distributions

## Open Questions the Paper Calls Out

### Open Question 1
The paper notes that "sample paths from a Stratonovich SDE are not of bounded variation almost surely" and mentions that this is a theoretical limitation for rough volatility models. While the paper suggests potential solutions through limiting arguments and changing the underlying topology on pathspace, it does not provide concrete methods or demonstrate their effectiveness.

### Open Question 2
The paper mentions that "the interpolation choice is usually unimportant and simple linear interpolation is often sufficient" but acknowledges that other choices exist in the literature. However, it does not provide comparative analysis of different interpolation methods or guidelines for when to use alternatives to linear interpolation.

### Open Question 3
While the paper demonstrates success on limit order book data, it notes that "spatiotemporal results can be extended to more complex structures" without providing concrete methods for scaling to higher dimensions. The paper only provides results for a specific 2D spatial domain (D = [0,1]) and doesn't address computational complexity issues that arise with higher-dimensional spaces.

## Limitations
- Theoretical guarantees rely on compactness assumptions that may not hold for real-world financial data with heavy tails
- Memory-efficiency gains require careful numerical implementation, with linear system scaling potentially prohibitive for high-frequency data
- Infinite-dimensional extension lacks empirical validation on truly continuous spatiotemporal datasets

## Confidence

- High Confidence: The signature kernel formulation as a scoring rule and its mathematical properties (characteristic property on compact spaces)
- Medium Confidence: The PDE reduction approach and its memory efficiency claims, given the theoretical foundation but potential practical implementation challenges
- Medium Confidence: The empirical performance claims on synthetic data, though real-world financial data results may depend heavily on hyperparameter choices

## Next Checks
