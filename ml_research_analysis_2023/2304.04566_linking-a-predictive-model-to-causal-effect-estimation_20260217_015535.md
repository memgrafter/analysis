# Linking a predictive model to causal effect estimation

## Quick Facts
- arXiv ID: 2304.04566
- Source URL: https://arxiv.org/abs/2304.04566
- Reference count: 40
- One-line primary result: A predictive model built on all direct causes of the outcome can estimate causal effects without requiring the full causal graph.

## Executive Summary
This paper bridges the gap between predictive modeling and causal inference by showing that when a predictive model is built on all direct causes of the outcome and no variables affected by the outcome, it can directly estimate causal effects without requiring knowledge of the underlying causal graph. The key insight is that under certain assumptions, the interventional probability equals the observational probability for features that are direct causes, enabling causal effect estimation directly from model predictions. The authors propose the MODE algorithm that discovers direct causes of the outcome, builds a predictive model on them, and estimates causal effects of each feature using the model.

## Method Summary
The proposed approach, MODE (Model for Discovering and Estimating causal effects), works by first identifying the direct causes of the outcome variable using causal discovery algorithms like the PC algorithm. Once these parents of the outcome are identified, any supervised machine learning model can be trained on them to predict the outcome. The key insight is that under certain assumptions (Markov condition, faithfulness, complete direct causes, no descendants of outcome), the predictions from this model can be used to estimate the conditional direct effects (CDE) of each feature on the outcome for a given instance. The algorithm then ranks features by their causal effects to provide personalized recommendations.

## Key Results
- Predictive models built on direct causes can estimate causal effects as accurately as state-of-the-art causal effect estimation methods
- Causally interpretable predictive models built on parents of the outcome are more robust to environmental changes than models built on all features
- The MODE algorithm enables personalized decision making by identifying which features have the highest causal effects on the outcome for a given individual

## Why This Works (Mechanism)

### Mechanism 1
- Claim: A predictive model built on all direct causes of the outcome can estimate causal effects of each feature without requiring the full causal graph.
- Mechanism: By satisfying Assumptions 1, 2, 3, and 4 (Markov condition, faithfulness, complete direct causes, no descendants of outcome), the interventional probability equals the observational probability for features that are direct causes, enabling causal effect estimation directly from model predictions.
- Core assumption: The dataset contains all direct causes of the outcome and no variables affected by the outcome (no descendants of Y).
- Evidence anchors:
  - [abstract]: "the model can directly estimate causal effects without requiring knowledge of the underlying causal graph."
  - [section]: "Causal effect estimation is a main topic in the causal inference area, and most causal effect estimation methods assume a fixed treatment variable and a given set of covariates."
  - [corpus]: Weak. No direct evidence in neighbors about using predictive models for causal effect estimation without full graphs.
- Break condition: If the dataset lacks any direct cause of the outcome or includes descendants of the outcome, the model cannot accurately estimate causal effects.

### Mechanism 2
- Claim: Predictive models built on direct causes are more robust to environmental changes than models built on all features.
- Mechanism: Models using descendants of the outcome introduce spurious associations that involve unobserved variables, making predictions unreliable when the environment changes. Models using only parents avoid these spurious associations.
- Core assumption: Unobserved variables exist and affect variables downstream from the outcome.
- Evidence anchors:
  - [abstract]: "the paper shows that such causally interpretable predictive models for robust predictions"
  - [section]: "A model built on PA(Y) will be more robust than a model built on all features associated with Y."
  - [corpus]: Weak. No direct evidence in neighbors about robustness related to using parents vs. all features.
- Break condition: If no unobserved variables exist or all relevant variables are observed, the robustness advantage may not manifest.

### Mechanism 3
- Claim: The MODE algorithm enables personalized decision making by identifying which features have the highest causal effects on the outcome for a given individual.
- Mechanism: By estimating the causal effects of each feature (as treatment) on the outcome while keeping other features constant, the algorithm can rank features by their potential impact and suggest the most effective interventions for individuals.
- Core assumption: The assumptions for causal interpretability are satisfied, allowing accurate estimation of causal effects for individual instances.
- Evidence anchors:
  - [abstract]: "many real world problems such as personalised decision making, recommendation, and fairness computing, need to know the causal effect of any feature on the outcome for a given instance."
  - [section]: "For a personalised decision, there needs to estimate the causal effect of each Xi ∈ X on Y when other variable values in x are kept unchanged for all Xj ≠ Xi."
  - [corpus]: Weak. No direct evidence in neighbors about personalized decision making using causal effects from predictive models.
- Break condition: If the model cannot accurately estimate causal effects due to violated assumptions, the personalized recommendations will be unreliable.

## Architecture Onboarding

- Component map:
  - Data preprocessing: Binarization of categorical variables, handling numerical variables
  - Causal discovery: PC algorithm or similar to identify parents of Y
  - Model building: Any supervised ML model (LR, DT, RF, SGD, MLP, GBR)
  - Causal effect estimation: Calculation of CDE for each feature using model predictions
  - Personalized recommendations: Ranking features by CDE for individual instances

- Critical path:
  1. Data preprocessing and causal discovery
  2. Model training on identified parents of Y
  3. Outcome prediction for input instance
  4. CDE estimation for each feature
  5. Feature ranking and personalized recommendations

- Design tradeoffs:
  - Model choice: Simpler models (LR, DT) are more interpretable but may have lower accuracy; complex models (MLP, RF) may be more accurate but less transparent
  - Causal discovery algorithm: Different algorithms may find different parent sets; trade-off between accuracy and computational cost
  - Binarization approach: Different methods may affect model performance and causal effect estimates

- Failure signatures:
  - Poor outcome prediction accuracy: Indicates issues with model choice, data quality, or violated assumptions
  - Inconsistent CDEs across similar instances: Suggests problems with model stability or violated assumptions
  - Large discrepancy between CDEs and actual outcome changes: Indicates potential violations of assumptions about direct causes or absence of descendants

- First 3 experiments:
  1. Verify causal discovery on synthetic data with known causal structure to ensure correct identification of parents of Y
  2. Compare outcome prediction accuracy using parents vs. all features on synthetic data to demonstrate the importance of using parents
  3. Test robustness to environmental changes by training on one synthetic dataset and testing on another with different unobserved variables, comparing models using parents vs. all features

## Limitations

- The approach depends critically on the assumption that all direct causes of the outcome are included in the dataset and that no descendants of the outcome are present, which may not hold in many real-world datasets.
- The paper demonstrates the method primarily on synthetic data with known causal structures, and while some experiments use semi-synthetic data, the generalizability to complex real-world scenarios with unknown causal structures remains uncertain.
- The robustness claims rely on the existence of unobserved variables affecting descendants of the outcome, which may not always be the case in practice.

## Confidence

- High confidence: The theoretical framework linking predictive modeling to causal effect estimation when assumptions are satisfied.
- Medium confidence: The practical effectiveness of the MODE algorithm in real-world scenarios, as most experiments use synthetic data.
- Medium confidence: The generalizability across different types of predictive models for causal effect estimation, though the paper demonstrates this on several model types.
