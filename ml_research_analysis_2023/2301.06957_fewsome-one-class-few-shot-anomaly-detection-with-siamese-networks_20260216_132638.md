# FewSOME: One-Class Few Shot Anomaly Detection with Siamese Networks

## Quick Facts
- arXiv ID: 2301.06957
- Source URL: https://arxiv.org/abs/2301.06957
- Reference count: 29
- Primary result: Achieves state-of-the-art performance with only 30 normal training samples

## Executive Summary
FewSOME is a one-class anomaly detection algorithm that leverages Siamese network architecture and pretrained weights to achieve exceptional performance with minimal training data. The model addresses the critical challenge of representational collapse through a novel "Stop Loss" mechanism that anchors feature embeddings to prevent them from converging to a single point. By training on just 30 normal samples from benchmark datasets including MNIST, CIFAR-10, F-MNIST, and MVTec AD, FewSOME demonstrates that high-quality anomaly detection is possible without the massive training sets required by previous methods.

## Method Summary
FewSOME uses a Siamese network with shared weights trained on pairs of normal samples to learn a feature embedding space where normal samples cluster together. The architecture employs VGG-3 for smaller datasets and ResNet-18 for MVTec AD, initialized with either Kaiming or ImageNet weights. The training process uses a custom loss function combining Ldist (Euclidean distance between sample embeddings) and Lstop (distance to a frozen anchor embedding) to prevent representational collapse. The model is trained with Adam optimization and early stopping when training loss decrease falls below 0.5% for 2 consecutive epochs.

## Key Results
- Outperforms state-of-the-art methods on MNIST, CIFAR-10, F-MNIST, and MVTec AD
- Achieves good performance with as few as 2 normal samples, plateauing around 30 samples
- Maintains robustness to contaminated datasets with up to 20% anomaly contamination
- Demonstrates superior F1 score and Balanced Accuracy compared to existing one-class methods

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Siamese network architecture with shared weights enables FewSOME to learn common features between normal samples without requiring negative examples.
- Mechanism: By training on pairs (or groups) of normal samples and minimizing the Euclidean distance between their feature embeddings, the network learns to map similar normal samples close together in the feature space while pushing dissimilar normal samples apart.
- Core assumption: Normal samples from the same class share enough common features that their embeddings can be meaningfully clustered together in a lower-dimensional space.

  - [section]: "The distance component of the loss function, D(r) consists of Ldist and Lstop (Equation 1). In each epoch of the training process, D(ri) is computed for each ri∈rN"
  - [corpus]: Weak evidence. Corpus mentions few-shot and Siamese networks but doesn't provide direct support for the specific distance-based learning mechanism.
- Break condition: If normal samples are too diverse within the class, the network may struggle to find meaningful commonalities, leading to poor anomaly detection performance.

### Mechanism 2
- Claim: The "Stop Loss" component prevents representational collapse by anchoring feature embeddings to a fixed reference point.
- Mechanism: By computing the distance between each sample's embedding and a frozen anchor embedding (obtained from the first pass through the model), the loss function ensures that not all embeddings collapse to the same point in feature space.
- Core assumption: A fixed anchor point provides a stable reference that prevents the model from mapping all inputs to a constant output.
- Evidence anchors:
  - [abstract]: "FewSOME uses a Siamese network architecture with shared weights and is trained using a proposed loss function called 'Stop Loss' to prevent representational collapse"
  - [section]: "The term stopgrad in Equation 1 highlights that the backﬂow of gradients is prevented i.e. the weights are updated so that f (ri) is moved closer to f (xa), rather than the weights updating to move both f (ri) and f (ra) closer to each other"
  - [corpus]: No direct evidence. Corpus doesn't mention representational collapse or the Stop Loss mechanism.
- Break condition: If the anchor point is poorly chosen (e.g., too far from the cluster of normal samples), it may not effectively prevent collapse or could introduce bias.

### Mechanism 3
- Claim: Pretrained weights on ImageNet provide a strong initialization that improves FewSOME's performance, especially with limited training data.
- Mechanism: The model starts with weights that already capture useful visual features from the ImageNet dataset, which helps it learn normal patterns more efficiently with only 30 training samples.
- Core assumption: Visual features learned from ImageNet are transferable to the target datasets (MNIST, CIFAR-10, F-MNIST, MVTec AD) and help with anomaly detection.
- Evidence anchors:
  - [abstract]: "FewSOME is aided by pretrained weights with an architecture based on Siamese Networks"
  - [section]: "As is common in recent AD techniques, FewSOME beneﬁts from weight initialisation on ImageNet [9,8,19]"

- Break condition: If the target domain is significantly different from ImageNet (e.g., medical imaging with different modalities), pretraining may not provide meaningful benefits.

## Architecture Onboarding

- Component map:
  Input layer -> Shared-weight backbone (VGG-3/ResNet-18) -> Sigmoid layer -> Distance computation module -> Loss aggregation -> Weight update
- Critical path: Input → Shared-weight backbone → Feature embeddings → Distance computation → Loss aggregation → Weight update
- Design tradeoffs:
  - Small Reference Set (N=30) vs. comprehensive coverage of normal patterns
  - Simple architecture (VGG-3) vs. model capacity and performance
  - Stop Loss anchoring vs. potential bias introduction
  - Pretrained weights vs. domain-specific adaptation needs
- Failure signatures:
  - Representational collapse: All feature embeddings converge to the same point
  - Poor anomaly detection: Normal samples and anomalies have similar distances to the anchor
  - Overfitting: Model performs well on training data but poorly on test data
  - Underfitting: Model fails to learn meaningful normal patterns even with 30 samples
- First 3 experiments:
  1. Test representational collapse by training without Lstop and monitoring training loss convergence
  2. Evaluate sensitivity to Reference Set size by varying N from 2 to 50 and measuring AUC performance
  3. Compare performance with and without pretrained weights to quantify the initialization benefit

## Limitations
- Limited ablation studies: The paper lacks quantitative comparison of model performance with and without the Lstop component
- Transferability concerns: Reliance on pretrained ImageNet weights may not generalize to domains substantially different from natural images
- Small sample limitation: While impressive, the 30-sample limit may not generalize well to highly diverse normal classes or complex variation patterns

## Confidence
- High confidence: The overall experimental results showing FewSOME outperforming baselines on benchmark datasets
- Medium confidence: The effectiveness of the Stop Loss mechanism in preventing representational collapse
- Medium confidence: The data efficiency claim of achieving state-of-the-art results with only 30 training samples
- Low confidence: The generalizability of pretrained weights to domains substantially different from ImageNet
