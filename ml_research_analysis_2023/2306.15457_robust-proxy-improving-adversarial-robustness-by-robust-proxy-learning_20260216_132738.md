# Robust Proxy: Improving Adversarial Robustness by Robust Proxy Learning

## Quick Facts
- arXiv ID: 2306.15457
- Source URL: https://arxiv.org/abs/2306.15457
- Reference count: 40
- Improves adversarial robustness of deep networks by explicitly learning adversarially robust features

## Executive Summary
This paper introduces Robust Proxy Learning, a novel training framework that improves adversarial robustness by explicitly learning robust features. The key innovation is the use of class-wise robust perturbations to generate robust proxies, which serve as class-representative features during training. The model learns to pull data points of the same class close to their proxy while pushing different classes apart in feature space. Experimental results demonstrate consistent improvements over state-of-the-art adversarial training methods across multiple attack settings on CIFAR-10 and Tiny-ImageNet datasets.

## Method Summary
Robust Proxy Learning works by first generating class-wise robust perturbations (CRP) that create semantically meaningful perturbations within each class. These perturbations are added to input data to create robust proxies - class-representative features that capture the robust characteristics of each class. During training, the model simultaneously learns to minimize standard classification loss while maximizing similarity between data points and their corresponding proxies, and dissimilarity between data points and proxies of other classes. This approach explicitly encourages the network to learn features that are both discriminative and robust to adversarial perturbations.

## Key Results
- Achieves 55.3% PGD-20 accuracy on CIFAR-10 with ResNet-18, compared to 53.0% for TRADES baseline
- Shows consistent improvements across white-box attacks (PGD, CW) and black-box attacks
- Demonstrates better robustness under unseen L2-norm bounded attacks compared to baseline methods
- Maintains improvements when integrated with existing adversarial training frameworks (Madry, TRADES, MART, HELP)

## Why This Works (Mechanism)
The method works by explicitly creating a robust feature space where each class is represented by a robust proxy. By training the model to align data points with their class proxies while separating them from other class proxies, the network learns features that are inherently more robust to adversarial perturbations. The class-wise robust perturbations ensure that the proxies capture semantically meaningful variations within each class that are still consistent with the class identity under adversarial conditions.

## Architecture Onboarding

Component Map: Input Data -> Feature Distillation -> CRP Generation -> Robust Proxy Learning -> Improved Robustness

Critical Path: CRP Generation (Class-wise Perturbations) → Proxy Creation → Training with Proxy Loss → Improved Robustness

Design Tradeoffs:
- CRP generation adds computational overhead but provides explicit robustness signal
- Proxy-based learning requires careful balance between classification and alignment objectives
- Method complexity increases training pipeline but improves final robustness

Failure Signatures:
- CRP fails to improve robustness if perturbations are too small or too large
- Proxy learning ineffective if proxies don't capture class semantics
- Performance degradation if proxy alignment conflicts with classification objectives
