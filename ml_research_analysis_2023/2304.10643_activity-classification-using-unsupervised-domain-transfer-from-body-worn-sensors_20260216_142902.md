# Activity Classification Using Unsupervised Domain Transfer from Body Worn Sensors

## Quick Facts
- arXiv ID: 2304.10643
- Source URL: https://arxiv.org/abs/2304.10643
- Reference count: 40
- F1 scores of 67.19%–70.40% when transferring from wrist to torso across three datasets

## Executive Summary
This paper introduces an unsupervised domain transfer method for activity classification that adapts a classifier from one body location to another using only unlabeled simultaneous sensor data. The approach replicates source-domain embeddings at the target domain via a reconstruction loss, enabling the source classifier to be applied without modification. Experiments on PAMAP2, MHealth, and Opportunity datasets demonstrate high F1 scores when transferring from wrist to torso, outperforming direct application of the source model and performing competitively with transfer learning at low data regimes.

## Method Summary
The method uses a CNN-LSTM architecture to process IMU data and extract temporal features for activity recognition. A source model trained on labeled data from one body location (e.g., wrist) is adapted to a target location (e.g., torso) by training a target embedding extractor to minimize reconstruction loss between source and target embeddings using simultaneous unlabeled data. The source classifier is then applied directly to the target embeddings without retraining, reducing labeling costs and leveraging existing models efficiently.

## Key Results
- F1 scores of 67.19%–70.40% when transferring from wrist to torso across three datasets
- Outperforms direct application of source model without adaptation
- Performs competitively with transfer learning approaches at low data regimes
- Demonstrates 1.7× reduction in test error compared to applying source model directly

## Why This Works (Mechanism)

### Mechanism 1
The source model's embeddings can be replicated at the target domain using simultaneous unlabeled sensor data. The embedding extractor ET is trained to minimize a reconstruction loss between its output eT and the source embeddings eS for simultaneous measurements, effectively learning a mapping from target sensor signals to source domain embeddings. Core assumption: The embeddings eS contain shared discriminative features across body locations for certain activity classes.

### Mechanism 2
Using the source domain classifier CS directly on target embeddings eT enables activity classification without retraining the classifier. Once ET is trained to produce embeddings eT similar to eS, the classifier CS trained on eS can be applied directly to eT to classify activities at the target location. Core assumption: The classifier CS is sufficiently invariant to domain-specific embedding variations.

### Mechanism 3
Simultaneous data collection enables cross-domain embedding alignment without labels. The method relies on having pairs of simultaneous IMU readings from source and target domains to align their embeddings, so no activity labels are required at the target. Core assumption: The simultaneous measurements capture the same activity states at both body locations.

## Architecture Onboarding

- Component map: Source model MS = embedding extractor ES + classifier CS; Target model MT = embedding extractor ET + classifier CT; Loss function L (e.g., MAE, MSE, cosine similarity) + optional L1/L2 regularization
- Critical path: 1) Train MS on labeled source data (supervised); 2) Collect simultaneous unlabeled source-target data DST; 3) Train ET to minimize L(eS, eT) using DST; 4) Apply CS (weights WS) to target embeddings eT
- Design tradeoffs: Loss function choice (MAE vs MSE vs cosine similarity) affects convergence and embedding alignment quality; Regularization terms prevent overfitting but may slow embedding alignment; Simultaneous data requirement limits scenarios but enables label-free adaptation
- Failure signatures: Poor F1 scores if source and target embeddings are not aligned; High variance across runs if random initialization affects ET training; Degradation when switching source/target roles if embeddings lack shared discriminative features
- First 3 experiments: 1) Evaluate MS on DST to establish baseline performance without adaptation; 2) Train MT with MAE + L2 regularization and evaluate on DST; 3) Compare MT performance with and without regularization for different loss functions

## Limitations
- The method assumes simultaneous measurements capture the same activity states, which may not hold for all body location pairs
- Performance on body location pairs with minimal shared discriminative features (e.g., typing vs. pelvic movements) remains untested
- The approach requires simultaneous data collection, limiting scenarios where source and target data can be aligned in time

## Confidence
- Core claims about unsupervised domain transfer: Medium
- Performance claims on tested datasets: Medium
- Generalizability to other body location pairs: Low

## Next Checks
