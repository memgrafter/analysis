# Projected Subnetworks Scale Adaptation

## Quick Facts
- arXiv ID: 2301.11487
- Source URL: https://arxiv.org/abs/2301.11487
- Reference count: 13
- Primary result: SNP achieves optimal balance between positive and negative backward transfer in continual learning for vision-language models

## Executive Summary
This work introduces Subnetwork Projection (SNP) to address the challenge of maintaining zero/few-shot performance while updating large models in online/continual learning settings. SNP projects task-specific subnetworks as equidimensional base parameters within the same parameter space as meta parameters. By optimizing meta parameters through gradient-based meta learning, the method enables models to sustain greater parameter drift while retaining access to original base parameters. The approach is evaluated on vision-language models (CLIP) and demonstrates superior performance in retaining seen and unseen zero/few-shot performance across tasks compared to various continual learning baselines.

## Method Summary
The method projects task-specific subnetworks as equidimensional base parameters in the same parameter space as meta parameters. Meta parameters are optimized using a gradient-based meta learning approach, training models to sustain greater parameter drift while retaining access to original base parameters. The authors also introduce SNP++, which employs a memory buffer to access and manipulate subnetworks encoded in meta parameters, enabling addition, removal, combination, and switching of subnetworks.

## Key Results
- SNP outperforms existing continual learning methods in retaining seen and unseen zero/few-shot performance across tasks
- Achieves optimal balance between positive and negative backward transfer
- SNP++ enables dynamic manipulation of encoded subnetworks through memory buffer operations

## Why This Works (Mechanism)
SNP works by maintaining a dual-parameter system where task-specific subnetworks are projected as base parameters alongside meta parameters. The gradient-based meta learning approach allows the model to adapt to new tasks while preserving access to original task capabilities through the base parameters. This architecture enables controlled parameter drift during continual learning without catastrophic forgetting.

## Foundational Learning
- **Gradient-based meta learning**: Why needed - enables adaptation to new tasks while preserving old knowledge; Quick check - verify meta parameter updates follow expected gradients
- **Parameter space projection**: Why needed - allows task-specific subnetworks to coexist in same dimensional space; Quick check - confirm equidimensional projection maintains representational capacity
- **Memory buffer operations**: Why needed - enables dynamic manipulation of encoded subnetworks; Quick check - validate add/remove/combine/switch operations maintain network integrity

## Architecture Onboarding

**Component Map**: Vision-language model -> Base parameters -> Meta parameters -> Memory buffer (SNP++)

**Critical Path**: Input task data → Parameter projection → Meta parameter optimization → Subnetwork retrieval/manipulation

**Design Tradeoffs**: 
- Memory overhead from maintaining multiple parameter sets vs. performance retention
- Computational cost of gradient-based meta learning vs. traditional fine-tuning
- Memory buffer requirements for SNP++ vs. dynamic subnetwork manipulation capabilities

**Failure Signatures**:
- Degraded performance on previously learned tasks
- Subnetwork manipulation errors in SNP++
- Meta parameter updates causing instability in base parameters

**First Experiments**:
1. Verify basic SNP implementation maintains performance across sequential task learning
2. Test SNP++ subnetwork manipulation operations (add, remove, combine, switch)
3. Compare memory and computational overhead against baseline continual learning methods

- Limited comparison across different vision-language architectures beyond CLIP
- Memory buffer requirements for SNP++ may be prohibitive for truly online learning scenarios
