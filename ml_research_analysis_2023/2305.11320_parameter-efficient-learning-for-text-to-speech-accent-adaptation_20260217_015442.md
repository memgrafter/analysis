# Parameter-Efficient Learning for Text-to-Speech Accent Adaptation

## Quick Facts
- arXiv ID: 2305.11320
- Source URL: https://arxiv.org/abs/2305.11320
- Authors: 
- Reference count: 0

## Executive Summary
This paper addresses low-resource accent adaptation in text-to-speech systems by proposing a parameter-efficient learning approach to adapt a pre-trained TTS model from Mainland Chinese to Taiwanese Mandarin. The method uses only a small fraction (1.2% to 0.8%) of the original trainable parameters through techniques like input reprogramming, latent adapter learning, and model reprogramming. An auxiliary unsupervised loss based on optimal transport (using sliced Wasserstein distance or maximum mean discrepancy) is introduced to maximize the difference between source and target domain features. The results show that the adapted model successfully transfers the Taiwanese Mandarin accent while maintaining speech quality, with the latent adapter method with MMD loss showing the best performance.

## Method Summary
The proposed method adapts a pre-trained Conformer-FastSpeech2 TTS model to a new accent using parameter-efficient learning techniques. The approach involves freezing the backbone model and updating only 1.2% to 0.8% of parameters through three main techniques: input reprogramming (trainable feature extractor for input), latent adapter learning (adapter layers in latent space), and model reprogramming (reprogramming layers in latent space). An auxiliary unsupervised loss based on optimal transport is added to maximize the distance between source and target domain features. The method is evaluated on adapting from Mainland Chinese to Taiwanese Mandarin using a small 40-minute dataset, with performance measured through MOS scores, MCD, and CER on ASR models.

## Key Results
- PEL methods achieve competitive naturalness scores with parameter-efficient decoder fine-tuning
- The latent adapter method with MMD loss shows the best overall performance
- Adapted models successfully transfer Taiwanese Mandarin accent while maintaining speech quality
- Only 1.2% to 0.8% of original trainable parameters are used for adaptation

## Architecture Onboarding

- Component map:
  - Input text -> Phoneme embedding and encoder -> Variance adapter -> Mel decoder (with latent adapter, input reprogramming, and latent reprogramming layers) -> Speech spectrogram

- Critical path:
  1. Input text is processed through phoneme embedding and encoder
  2. Encoded features are passed through variance adapter and Mel decoder
  3. Additional layers (input reprogramming, latent adapter, latent reprogramming) are applied in the input and latent spaces of Mel decoder
  4. Mel decoder outputs are used to synthesize the speech spectrogram
  5. Auxiliary unsupervised loss based on OT is calculated and added to the supervised training loss

- Design tradeoffs:
  - Number of trainable parameters: Increasing the number of trainable parameters (e.g., using more adapter layers) may improve performance but also increases computation cost.
  - Choice of distance metric: SWD and MMD have different properties and may perform differently depending on the specific accent adaptation task.
  - Warm-up strategy: Gradually increasing the coefficient of the regularization term can help stabilize the model during training.

- Failure signatures:
  - Poor accent transfer: If the input or latent feature spaces are not effectively reprogrammed or adapted, the synthesized speech may not capture the target accent.
  - Low speech quality: If the backbone model is not sufficiently generalizable or the auxiliary unsupervised loss is not well-designed, the naturalness of the synthesized speech may be compromised.
  - High computation cost: If too many parameters are updated during adaptation or the model architecture is not optimized, the adaptation process may be computationally expensive.

- First 3 experiments:
  1. Compare the performance of input reprogramming, latent adapter, and latent reprogramming techniques using the same number of trainable parameters.
  2. Evaluate the impact of the auxiliary unsupervised loss (SWD vs. MMD) on accent transfer and speech quality.
  3. Investigate the effect of different warm-up strategies for the regularization term on model stability and performance.

## Limitations

- Extremely limited target dataset (only 40 minutes from one speaker) raises questions about generalizability to more diverse scenarios
- Comparison with only one baseline (decoder fine-tuning) is insufficient to establish superiority across different adaptation strategies
- Missing comparison with full fine-tuning baseline prevents demonstrating true parameter efficiency benefits

## Confidence

- High confidence: The parameter-efficient learning framework itself (input reprogramming, latent adapter, latent reprogramming) is technically sound and well-implemented.
- Medium confidence: The specific implementation details and hyperparameter choices (learning rates, warm-up schedules, loss coefficients) are reasonable but not thoroughly validated.
- Low confidence: The generalizability of results to different accent pairs, larger datasets, or multi-speaker scenarios.
