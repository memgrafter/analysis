# Learning the Effects of Physical Actions in a Multi-modal Environment

## Executive Summary
This work tackles the problem of predicting the effects of actions on physical attributes of objects in multi-modal settings. The authors propose PIGLeT-Vis, a model that uses images and natural language to predict action outcomes without relying on symbolic representations. The model extends an LLM with a vision component to extract latent representations of objects from images. Experiments on the PIGPeN-Vis dataset show that combining images and language improves performance, with the base+images+text-labels model achieving 47.55% overall accuracy. The results demonstrate the potential of multi-modal models to generalize physical commonsense reasoning to novel actions and objects.

## Method Summary
PIGLeT-Vis is a transformer-based model that predicts symbolic attributes of objects after actions are applied. It uses a RoBERTa-base encoder for action descriptions, a DETR-based vision object encoder with attention over bounding boxes for visual inputs, and a transformer-based action apply module to fuse action and object representations. The object decoder then predicts symbolic attributes. The model is trained on PIGPeN-Vis, a dataset of image-action-attribute triplets, and evaluated using both standard and zero-shot settings where specific objects and action-object pairs are held out during training.

## Key Results
- The base+images+text-labels model achieves 47.55% overall accuracy on the test set
- Combining images and language improves performance compared to using either modality alone
- Zero-shot evaluation shows the model can generalize to novel actions and objects, though with lower accuracy

## Architecture Onboarding

- Component map: Action Encoder -> Action Apply -> Object Decoder
  Vision Object Encoder provides object representations to Action Apply
- Critical path: Action → Action Encoder → Action Apply → Object Decoder → Output
- Design tradeoffs:
  - Using pre-trained DETR vs. training from scratch: Faster development but potential domain mismatch
  - Small hidden size (h=64) vs. larger: Faster training but may limit representation capacity
  - Attention over all bounding boxes vs. object-specific detection: More flexible but potentially noisier
- Failure signatures:
  - Low zero-shot accuracy but high overall accuracy: Model is memorizing rather than generalizing
  - Attention maps focus on wrong bounding boxes: Vision component not properly grounding object names
  - High variance across seeds: Model is unstable, likely due to noise in multi-modal inputs
- First 3 experiments:
  1. Run base model (no symbolic inputs) to establish lower bound performance
  2. Run base+symbolic model to establish upper bound performance
  3. Run base+images model to test vision component contribution

## Limitations

- The zero-shot evaluation uses very small test sets (8-28 examples), making reported accuracy improvements potentially unreliable
- The vision component relies on pre-trained DETR without fine-tuning on the PIGPeN dataset, potentially limiting its effectiveness
- The symbolic attributes used (size, temperature, location, distance, support) may not capture the full range of physical commonsense reasoning

## Confidence

**High Confidence**: The base model's performance (37.38% accuracy) on the PIGPeN dataset establishes a solid baseline for physical commonsense reasoning without symbolic inputs. This result is reproducible given the clear methodology and the relatively large training set (6,814 examples).

**Medium Confidence**: The claim that multi-modal inputs improve performance (47.55% for base+images+text-labels vs 37.38% for base) is supported by the data but limited by small test set sizes in the zero-shot setting. The 10.17 percentage point improvement is statistically significant but may not generalize to larger, more diverse test sets.

**Low Confidence**: The assertion that the vision component specifically enables better zero-shot generalization is the weakest claim. With only 8 test examples for the base+images model and 28 for base+images+text-labels in the zero-shot setting, the reported improvements (though directionally consistent) lack statistical power for strong conclusions.

## Next Checks

1. **Statistical significance testing with bootstrap resampling**: Given the small test set sizes in zero-shot settings, conduct bootstrap analysis on the accuracy metrics to establish confidence intervals and determine if observed improvements are statistically significant rather than noise.

2. **Ablation study on DETR performance**: Quantify DETR's object detection accuracy specifically on the PIGPeN dataset images, including precision/recall curves and mAP scores. This would validate whether the vision component is actually providing useful information or if improvements are coming from other aspects of the model.

3. **Cross-dataset generalization test**: Evaluate the trained models on a held-out physical commonsense dataset (such as the physical reasoning portions of CommonsenseQA or a similar benchmark) to determine if the learned representations transfer beyond the PIGPeN domain, testing true generalization rather than memorization of dataset-specific patterns.
