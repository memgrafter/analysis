# FedSSC: Shared Supervised-Contrastive Federated Learning

## Quick Facts
- arXiv ID: 2301.05797
- Source URL: https://arxiv.org/abs/2301.05797
- Reference count: 18
- Primary result: FedSSC achieves 69.3% top-1 accuracy on CIFAR-10, outperforming MOON (68.6%) and FedAvg (65.8%)

## Executive Summary
FedSSC addresses the non-IID data distribution challenge in federated learning by combining MOON's regularization with supervised contrastive learning using shared class-wise feature representations. The method introduces a regularization term that minimizes cosine similarity distance between local and shared global feature maps for the same class while maximizing it for different classes. This approach effectively bridges the gap between local and global model representations in federated settings where data distributions vary across devices.

## Method Summary
FedSSC builds upon MOON's regularization framework by incorporating a supervised contrastive loss that leverages shared class-wise feature representations across federated devices. The method introduces a regularization term that minimizes the cosine similarity distance between local and shared global feature maps for the same class while maximizing it for different classes. This dual objective helps align feature representations across devices while maintaining discriminative power. The approach combines the strengths of MOON's regularization with the class-aware feature alignment from supervised contrastive learning.

## Key Results
- FedSSC achieves 69.3% top-1 accuracy on CIFAR-10, outperforming MOON (68.6%) and FedAvg (65.8%)
- Converges faster, reaching 68% accuracy in 41 communication rounds versus 61 for MOON and over 100 for FedAvg
- Shows consistent performance improvements across different non-IID scenarios
- Demonstrates that MOON loss and global contrastive loss are complementary

## Why This Works (Mechanism)
The effectiveness of FedSSC stems from its dual regularization approach that addresses both local-global feature alignment and class-wise discriminative learning. By combining MOON's regularization with supervised contrastive learning, the method ensures that feature representations from different devices for the same class become more similar while maintaining class separability. The shared feature representations across devices help mitigate the impact of non-IID data distributions by creating a common feature space that all devices can align with.

## Architecture Onboarding

### Component Map
Client devices -> Local feature extraction -> MOON regularization -> Supervised contrastive loss -> Shared global feature representations -> Model aggregation

### Critical Path
The critical path involves computing local features, applying MOON regularization, calculating the supervised contrastive loss with shared global features, and aggregating model updates. This sequence ensures that each device contributes to building a common feature space while maintaining local discriminative power.

### Design Tradeoffs
The method trades additional computational overhead for improved accuracy and faster convergence. The supervised contrastive loss adds complexity but provides better feature alignment across non-IID distributions. The balance between MOON regularization and contrastive learning needs careful tuning for optimal performance.

### Failure Signatures
- Poor convergence when the regularization strength is misconfigured
- Degraded performance if the shared feature representations become too dominant
- Communication bottlenecks if feature maps are too large for efficient transmission

## Limitations
- Limited to CIFAR-10 dataset with specific non-IID partitioning schemes
- Performance gains are relatively modest (0.7% over MOON, 3.5% over FedAvg)
- Limited evaluation under realistic federated conditions with device heterogeneity

## Confidence
The confidence level for the core claims about FedSSC's effectiveness is Medium. While the theoretical framework combining MOON's regularization with supervised contrastive learning is sound, the limited empirical evaluation prevents high confidence in its general applicability.
