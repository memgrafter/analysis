# Multi-Modality in Music: Predicting Emotion in Music from High-Level Audio Features and Lyrics

## Quick Facts
- arXiv ID: 2302.13321
- Source URL: https://arxiv.org/abs/2302.13321
- Reference count: 40
- Primary result: Multi-modal features (Spotify audio + lyrics) outperform uni-modal approaches for valence prediction (R² = 0.235), while audio-only performs similarly to multi-modal for arousal (R² = 0.196)

## Executive Summary
This study investigates whether combining high-level audio features from Spotify with lyrics features (sentiment, TF-IDF, and ANEW) improves emotion prediction in music compared to using either modality alone. Using 12,471 English songs from the Deezer Mood Detection Dataset and four regression models (Linear Regression, Random Forest, SVR, and MLP), the research demonstrates that multi-modal approaches significantly outperform uni-modal methods for predicting valence (emotional positivity/negativity) but show similar performance to audio-only models for arousal (emotional intensity). The best results were achieved with selected features including danceability, energy, instrumentalness, valence, and mode from audio, combined with TF-IDF and Vader sentiment scores from lyrics. These findings suggest that audio and textual modalities provide complementary information specifically for valence prediction, while arousal remains more challenging to predict from lyrics features.

## Method Summary
The study employs a multi-modal machine learning approach to predict music emotion dimensions of valence and arousal. The dataset consists of 12,471 English songs from the Deezer Mood Detection Dataset, with each song rated by 10 users on valence and arousal scales. Four regression models are evaluated: Linear Regression, Random Forest, Support Vector Regression, and Multi-Layer Perceptron. Features are extracted from two modalities: high-level audio features from Spotify's API (including danceability, energy, instrumentalness, valence, tempo, and mode) and lyrics features processed through sentiment analysis (VADER), TF-IDF vectorization, and the Affective Norms for English Words (ANEW) database. Both feature selection and feature fusion techniques are employed, with models trained on uni-modal and multi-modal feature sets. Performance is evaluated using R² score, RMSE, and MAE metrics across five-fold cross-validation and a held-out test set.

## Key Results
- Multi-modal features significantly outperform uni-modal approaches for valence prediction (R² = 0.235 vs. ~0.15 for audio-only and lyrics-only)
- For arousal prediction, audio-only features perform similarly to multi-modal approaches (R² ≈ 0.19-0.20)
- The best performance is achieved with selected features: danceability, energy, instrumentalness, valence, and mode from audio combined with TF-IDF and Vader sentiment from lyrics
- MLP model with multi-modal selected features achieves the highest R² scores of 0.235 for valence and 0.196 for arousal on the test set
- Feature selection improves performance by reducing dimensionality and focusing on the most predictive features

## Why This Works (Mechanism)
The study demonstrates that music emotion prediction benefits from multi-modal integration, but the effectiveness varies by emotion dimension. For valence prediction, combining audio and lyrics features provides complementary information that neither modality alone can fully capture. Audio features like danceability, energy, and valence directly relate to perceived emotional positivity, while lyrics sentiment and TF-IDF features capture emotional content expressed through language. The significant improvement over uni-modal approaches indicates that these modalities encode different aspects of emotional expression. However, for arousal prediction, audio features alone perform comparably to multi-modal approaches, suggesting that arousal-related information is more strongly represented in audio characteristics (tempo, energy, instrumentalness) than in lyrics content. This modality-specific effectiveness highlights that emotion dimensions in music are encoded through different channels and require different feature combinations for optimal prediction.

## Architecture Onboarding

**Component Map:** Spotify API -> Audio features extraction -> Feature selection -> Regression models; Lyrics preprocessing -> Sentiment analysis (VADER) + TF-IDF + ANEW -> Feature selection -> Regression models; Multi-modal fusion -> Combined feature vector -> Regression models

**Critical Path:** Data preprocessing -> Feature extraction (audio and lyrics) -> Feature selection -> Model training (with cross-validation) -> Performance evaluation (R², RMSE, MAE) -> Test set validation

**Design Tradeoffs:** High-level vs. low-level audio features - The study uses Spotify's high-level features for convenience but may miss nuanced audio characteristics. Lyrics preprocessing approach - Pre-trained sentiment dictionaries (VADER, ANEW) provide quick analysis but may not capture music-specific language. Regression model selection - Four different models are tested, with MLP achieving best performance, suggesting nonlinear relationships in the data.

**Failure Signatures:** Low R² scores across all models (0.19-0.24) indicate that even combined modalities explain limited variance in emotion ratings. Comparable performance of audio-only vs. multi-modal for arousal suggests lyrics features may not capture arousal-related information effectively. Overfitting risk from high-dimensional feature spaces, mitigated through feature selection.

**First 3 Experiments:** 1) Train Linear Regression on audio-only features to establish baseline performance. 2) Train MLP on multi-modal selected features to verify improvement over baseline. 3) Conduct ablation study by removing individual features (danceability, energy, instrumentalness) to identify most predictive audio features.

## Limitations
- Modest R² scores (0.235 for valence, 0.196 for arousal) indicate that models explain less than a quarter of variance in emotion ratings
- Focus on English-language songs limits generalizability across musical genres, languages, and cultural contexts
- Reliance on Spotify's high-level audio features may miss nuanced audio characteristics relevant to emotion
- Use of pre-existing sentiment dictionaries (VADER, ANEW) may not fully capture music-specific language and metaphors
- Correlation-based analysis identifies associations but not causal mechanisms underlying music emotion

## Confidence
- Multi-modal superiority for valence prediction: Medium confidence (R² improvement from ~0.15 to 0.235, but still modest absolute performance)
- Comparable audio-only performance for arousal: Medium confidence (similar R² scores suggest modality-specific effectiveness)
- Feature selection importance: High confidence (consistent improvement across models when using selected vs. full feature sets)
