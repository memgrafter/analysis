# Swapped goal-conditioned offline reinforcement learning

## Quick Facts
- arXiv ID: 2302.08865
- Source URL: https://arxiv.org/abs/2302.08865

- Outperforms state-of-the-art offline GCRL approaches on nine benchmark tasks, including challenging dexterous in-hand manipulation

## Executive Summary
This paper tackles the challenge of generalization in offline goal-conditioned reinforcement learning by introducing two key innovations: goal-swapping data augmentation and a deterministic Q-Advantage policy gradient method. The goal-swapping technique creates new state-goal pairs across trajectories, expanding the dataset and enabling the agent to learn more general skills. The deterministic Q-Advantage policy gradient (DQAPG) method improves learning from noisy data by combining deterministic policy gradient with advantage-weighted behavioral cloning. Experiments on nine benchmark tasks, including complex dexterous in-hand manipulation, demonstrate that these methods outperform existing state-of-the-art offline GCRL approaches, particularly in scenarios where prior methods failed.

## Method Summary
The paper proposes two main innovations to improve offline goal-conditioned reinforcement learning. First, goal-swapping data augmentation creates new state-goal pairs by pairing states from one trajectory with goals from another, expanding the effective dataset and improving generalization. Second, the deterministic Q-Advantage policy gradient (DQAPG) method combines deterministic policy gradient with advantage-weighted behavioral cloning to improve learning from noisy offline data. These techniques are evaluated on nine benchmark tasks, including challenging dexterous manipulation, showing significant performance gains over state-of-the-art methods.

## Key Results
- Outperforms state-of-the-art offline GCRL approaches on nine benchmark tasks
- Achieves significant performance gains in tasks where prior methods failed, including dexterous in-hand manipulation
- Demonstrates improved generalization through goal-swapping data augmentation

## Why This Works (Mechanism)
The goal-swapping augmentation expands the dataset by creating new state-goal pairs across trajectories, enabling the agent to learn more general skills. DQAPG improves learning from noisy data by combining deterministic policy gradient with advantage-weighted behavioral cloning, which helps the agent learn from the offline dataset more effectively.

## Architecture Onboarding

Component Map:
Goal-swapping data augmentation -> Deterministic Q-Advantage policy gradient (DQAPG) -> Policy evaluation and improvement

Critical Path:
1. Collect trajectories from offline dataset
2. Apply goal-swapping augmentation to create new state-goal pairs
3. Train Q-function using augmented dataset with DQAPG
4. Update policy using deterministic policy gradient and advantage-weighted behavioral cloning
5. Evaluate policy on benchmark tasks

Design Tradeoffs:
- Goal-swapping augmentation increases dataset size but may introduce unrealistic state-goal pairs
- DQAPG balances deterministic policy gradient with behavioral cloning, trading off exploration for stability
- The approach requires careful tuning of augmentation and learning parameters to avoid overfitting

Failure Signatures:
- Poor performance on tasks not present in the offline dataset
- Instability in policy learning due to incorrect Q-value estimates
- Overfitting to specific state-goal pairs created through augmentation

First Experiments:
1. Test goal-swapping augmentation on a simple grid-world task to verify improved generalization
2. Evaluate DQAPG on a continuous control benchmark to assess learning from noisy data
3. Conduct ablation studies to isolate the contributions of goal-swapping and DQAPG on a subset of benchmark tasks
