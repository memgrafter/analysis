# Self-Explainable Graph Neural Networks for Link Prediction

## Quick Facts
- arXiv ID: 2305.12578
- Source URL: https://arxiv.org/abs/2305.12578
- Reference count: 40
- Key outcome: Achieves state-of-the-art link prediction with AUC scores up to 98.23% while providing interpretable explanations

## Executive Summary
This paper introduces ILP-GNN, a self-explainable graph neural network framework for link prediction that simultaneously provides accurate predictions and interpretable explanations. The key innovation is an interpretable neighbor aggregation module that identifies K important neighbors of each node pair based on both node and high-order structure similarity, enabling pair-specific representations for link prediction. A novel loss function is proposed to enhance explanation quality and improve prediction performance. Experiments on real-world datasets (Cora, Citeseer, Photo, Ogbn-arxiv, Ogbn-collab) and synthetic datasets demonstrate the effectiveness of the framework, achieving state-of-the-art link prediction performance with superior explanation quality compared to baselines.

## Method Summary
The ILP-GNN framework addresses the challenge of lacking interpretability in GNNs for link prediction by providing clear explanations for why links are predicted between node pairs. The method uses an interpretable neighbor aggregation module that identifies K important neighbors for each node pair based on both node and high-order structure similarity. A novel loss function balances classification performance with explanation enhancement. The framework constructs pair-specific representations by aggregating information from important neighbors, enabling both accurate predictions and interpretable explanations simultaneously.

## Key Results
- Achieves state-of-the-art link prediction performance with AUC scores up to 98.23%
- Provides superior explanation quality with precision@1, precision@2, and fidelity scores outperforming baselines
- Demonstrates effectiveness across multiple real-world datasets (Cora, Citeseer, Photo, Ogbn-arxiv, Ogbn-collab) and synthetic datasets

## Why This Works (Mechanism)
The framework works by creating interpretable representations for link prediction through selective neighbor aggregation. By identifying K important neighbors based on both node features and high-order structural similarity, the model can construct pair-specific representations that capture the most relevant information for predicting links. The explanation enhancement loss ensures that the selected neighbors are not only useful for prediction but also provide meaningful explanations. This dual objective of prediction accuracy and explanation quality is achieved through a carefully designed loss function that balances these competing goals.

**Component Map**

**Critical Path**
1. Data preparation and graph construction
2. Neighbor selection using interpretable aggregation
3. Pair-specific representation learning
4. Link prediction with explanation generation

**Design Tradeoffs**
- K neighbors: Balance between explanation quality and computational efficiency
- Loss function weights (λ, α, δ): Trade-off between prediction accuracy and explanation enhancement
- High-order structure similarity: Additional computation cost for potentially better explanations

**Failure Signatures**
- Poor prediction accuracy: Incorrect neighbor selection or imbalanced loss function weights
- Low explanation quality: Poorly tuned explanation enhancement parameters or inadequate K selection
- High computational cost: Excessive K value or inefficient similarity calculations

## Limitations
- Relies on hyperparameter K that requires careful tuning for different graph structures
- Computational complexity scales with K, potentially problematic for large graphs
- Explanation quality metrics may not fully capture semantic relevance across all application domains
