# Witscript 2: A System for Generating Improvised Jokes Without Wordplay

## Quick Facts
- arXiv ID: 2302.03036
- Source URL: https://arxiv.org/abs/2302.03036
- Reference count: 3
- Primary result: Witscript 2 generates common-sense-based jokes with 46% human-rated humor success rate

## Executive Summary
Witscript 2 is a computational humor system that generates conversational jokes without relying on wordplay, instead using common sense reasoning. The system executes a structured 5-step joke-writing algorithm using GPT-3, selecting topic handles, generating associations, creating punch lines, and connecting them to the original topic. Human evaluators judged 46% of Witscript 2's responses as jokes, compared to 70% for human-written responses, demonstrating computational creativity through novelty, value, and intentionality.

## Method Summary
The system uses GPT-3 (text-davinci-002) without fine-tuning, instead relying on carefully crafted prompts to execute a 5-step Basic Joke-Writing Algorithm. The algorithm selects topic handles from user input, generates associations for each handle, creates a punch line from those associations, and produces an angle connecting the topic to the punch line. Human evaluators rate outputs on a 1-4 scale to assess joke quality, with the system demonstrating commonsense knowledge by making humorous inferences based on everyday relational reasoning.

## Key Results
- Human evaluators judged 46% of Witscript 2's responses as jokes
- GPT-3 alone achieved 25% joke recognition rate in comparison
- Human comedy writer achieved 70% joke recognition rate
- System demonstrates novelty, value, and intentionality in outputs

## Why This Works (Mechanism)

### Mechanism 1
The system generates novel, contextually relevant jokes by combining common sense reasoning with large language model execution of structured joke-writing algorithms. It follows a 5-step Basic Joke-Writing Algorithm using GPT-3 prompted with examples and domain knowledge rather than fine-tuning. Core assumption: LLMs can reliably execute structured, step-by-step instructions when prompted correctly and can generate novel outputs satisfying human-defined humor criteria.

### Mechanism 2
The system exhibits computational creativity through novelty, value, and intentionality in its joke outputs. It produces novel jokes by generating unique associations and punch lines for each new input. Value is demonstrated through human ratings (46% judged as jokes). Intentionality is shown by using domain knowledge, example-based prompting, and a filtering process to reject low-value outputs.

### Mechanism 3
The system demonstrates commonsense knowledge by using everyday relational reasoning to create humorous connections. It uses commonsense inference (e.g., taxonomic reasoning, property association) to link topic handles with associations in a humorous way, as shown in the fighter jets/Switzerland example. Core assumption: LLMs have internalized enough commonsense knowledge to perform necessary inferences when prompted with the right examples and instructions.

## Architecture Onboarding

- **Component map**: Input sentence -> GPT-3 API (5-step execution) -> Joke response -> Human evaluation
- **Critical path**: 1) Receive input sentence, 2) Prompt GPT-3 to select topic handles, 3) Prompt GPT-3 to generate associations, 4) Prompt GPT-3 to create punch line, 5) Prompt GPT-3 to generate connecting angle, 6) Output final joke
- **Design tradeoffs**: Using GPT-3 without fine-tuning trades control for speed and simplicity; relying on human ratings trades automation for reliability; focusing on common sense jokes trades breadth for depth
- **Failure signatures**: Low joke ratings (below 30%), GPT-3 outputs not following prompt instructions, repetitive or nonsensical jokes for different inputs
- **First 3 experiments**: 1) Test with 5 new input topics, measure joke ratings, 2) Swap GPT-3 for Claude or PaLM, compare ratings, 3) Add filtering step rejecting low-humor punch lines, measure effect on final ratings

## Limitations

- Evaluation relies on non-professional raters rather than comedy writers
- Comparison uses only one professional comedy writer rather than broader sample
- System depends on GPT-3's general knowledge, may fail with specialized understanding
