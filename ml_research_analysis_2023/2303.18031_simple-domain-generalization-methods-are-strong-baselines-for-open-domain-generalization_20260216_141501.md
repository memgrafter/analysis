# Simple Domain Generalization Methods are Strong Baselines for Open Domain Generalization

## Quick Facts
- arXiv ID: 2303.18031
- Source URL: https://arxiv.org/abs/2303.18031
- Reference count: 40
- Simple DG methods (CORAL, MMD) achieve competitive performance with state-of-the-art DAML in ODG

## Executive Summary
This paper evaluates domain generalization (DG) methods for open domain generalization (ODG), which combines DG with open-set recognition. The authors demonstrate that simple DG methods, CORAL and MMD, perform competitively with the state-of-the-art DAML method on datasets where data augmentation is less effective. They propose extensions of these methods incorporating ensemble learning, Dirichlet mixup data augmentation, and knowledge distillation. Experimental results show these extended methods achieve comparable performance to DAML on datasets where data augmentation is effective, with lower computational costs. The key finding is that simple DG methods and their extensions are strong baselines for ODG.

## Method Summary
The paper proposes extensions to two simple DG methods: CORAL (Correlation Alignment) and MMD (Maximum Mean Discrepancy). The core approach involves training separate models for each source domain and combining their predictions through ensemble learning. Extensions include Dirichlet mixup data augmentation, which creates synthetic samples by mixing features from different domains with Dirichlet-distributed weights, and knowledge distillation. The methods are evaluated on image classification tasks using PACS, Office-Home, and Multi-Datasets with predefined source/target domain splits. The evaluation uses pre-trained ResNet-18 feature extractors with cross-entropy loss combined with domain alignment losses, and threshold-based unknown class detection.

## Key Results
- CORAL and MMD achieve competitive performance with DAML on PACS and Office-Home datasets where data augmentation is less effective
- Ensemble extensions (E-CORAL, E-MMD) significantly improve performance and outperform ERM
- Dirichlet mixup augmentation (EDir-CORAL, EDir-MMD) provides performance gains on PACS dataset
- Extended methods achieve comparable performance to DAML on datasets where data augmentation is effective, with lower computational costs

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Simple DG methods (CORAL, MMD) achieve competitive performance in ODG without the complexity of DAML
- Mechanism: CORAL minimizes covariance matrix differences across domains while MMD minimizes feature distribution distances, both providing effective regularization against domain shift
- Core assumption: Domain shift is the primary challenge, and these simple distance-based regularizations are sufficient to address it
- Evidence anchors:
  - [abstract] "two simple DG methods, CORrelation ALignment (CORAL) and Maximum Mean Discrepancy (MMD), are competitive with DAML in several cases"
  - [section 2.1] "CORAL uses the loss ofℓCORAL, which is the sum of the difference in the covariance matricesCi andCj of the features for each source domain"
- Break condition: When data augmentation becomes highly effective (open domain Office-Home, Multi-Datasets), the simple methods lose their competitive edge

### Mechanism 2
- Claim: Ensemble learning significantly improves CORAL and MMD performance in ODG
- Mechanism: By training separate models for each source domain and combining their predictions, the ensemble captures domain-specific characteristics while maintaining generalization
- Core assumption: Different source domains contain complementary information that can be effectively combined through ensemble methods
- Evidence anchors:
  - [section 3.2.1] "We prepare M neural network models {M1,..., MM} in which the i-th model Mi = Gi◦Fi corresponds to the i-th source domain"
  - [section 4.3.3] "In particular, E-CORAL and E-MMD exhibit the best performance and outperform ERM"
- Break condition: When domain shift is minimal or when computational overhead becomes prohibitive

### Mechanism 3
- Claim: Dirichlet mixup data augmentation provides significant performance gains for CORAL and MMD in certain datasets
- Mechanism: Creating synthetic samples by mixing features from different domains with Dirichlet-distributed weights forces the model to learn domain-invariant representations
- Core assumption: The mixed samples created through Dirichlet distribution capture meaningful cross-domain relationships
- Evidence anchors:
  - [section 3.2.2] "We further extend E-CORAL and E-MMD by incorporating Dir-mixup data augmentation"
  - [section 4.3.2] "For the open domain PACS, EDir-CORAL and EDir-MMD have succeeded in improving the performance"
- Break condition: When the dataset is already highly augmented or when the domain characteristics are too dissimilar for meaningful mixing

## Foundational Learning

- Concept: Domain generalization vs. domain adaptation
  - Why needed here: Understanding that DG methods cannot access target domain data during training is crucial for implementing the proposed methods correctly
  - Quick check question: Can CORAL or MMD use any target domain data during training? (Answer: No)

- Concept: Open-set recognition
  - Why needed here: ODG requires detecting unknown classes in addition to handling domain shift, which affects how the model's output is interpreted
  - Quick check question: How does the proposed method detect unknown classes? (Answer: By thresholding class probabilities as in Eq. 8)

- Concept: Ensemble learning
  - Why needed here: The E-CORAL and E-MMD methods rely on training separate models for each domain and combining their outputs
  - Quick check question: How many models are trained in E-CORAL? (Answer: M models, one for each source domain)

## Architecture Onboarding

- Component map:
  Feature extractor (Fi) -> Regularization (CORAL/MMD) -> Classifier (Gi) -> Ensemble combiner (averaging) -> Thresholding (unknown class detection)

- Critical path:
  1. Extract features from each source domain using Fi
  2. Apply regularization (CORAL or MMD) to feature distributions
  3. Classify using Gi
  4. Combine predictions across ensemble (for E-CORAL/E-MMD)
  5. Apply thresholding for unknown class detection

- Design tradeoffs:
  - CORAL vs MMD: CORAL focuses on covariance alignment, MMD on distribution distance
  - Ensemble vs single model: Ensemble provides better performance but higher computational cost
  - With vs without Dir-mixup: Dir-mixup helps in some datasets but adds complexity

- Failure signatures:
  - Poor performance on source domains: Regularization too strong
  - No improvement over ERM: Domain shift may be minimal or augmentation ineffective
  - High variance across trials: Need more robust hyperparameters or training procedure

- First 3 experiments:
  1. Implement basic CORAL and MMD on a single dataset without ensemble to establish baseline
  2. Add ensemble learning to CORAL and MMD to verify performance improvement
  3. Test Dir-mixup augmentation on CORAL/MMD ensemble to identify datasets where it helps

## Limitations

- The paper lacks clarity on precise implementation details for ensemble learning and knowledge distillation components
- Evaluation is primarily focused on image classification tasks, limiting generalizability to other domains
- The paper does not provide extensive analysis of computational complexity or memory requirements compared to DAML

## Confidence

- **High confidence**: CORAL and MMD as competitive baselines for ODG - supported by multiple experimental results across different datasets
- **Medium confidence**: Ensemble extensions (E-CORAL, E-MMD) - results show consistent improvement but depend on implementation details
- **Medium confidence**: Dirichlet mixup effectiveness - shows dataset-specific benefits but lacks theoretical justification
- **Low confidence**: Knowledge distillation extensions - limited experimental validation and implementation details unclear
