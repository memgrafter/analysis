# Confidence-based Ensembles of End-to-End Speech Recognition Models

## Executive Summary
This paper proposes a confidence-based ensemble approach for end-to-end speech recognition that dynamically selects outputs from the most confident model rather than combining them. The method addresses two key challenges: improving multilingual ASR performance by combining monolingual models and mitigating catastrophic forgetting during accent/dialect adaptation by combining base and adapted models. The authors demonstrate that confidence scores can be reliably estimated from intermediate layers when models are trained with intermediate CTC loss, enabling runtime efficiency improvements of up to 4.5x. The approach consistently outperforms language identification-based model selection and constraint adaptation baselines across multiple language pairs and adaptation scenarios.

## Method Summary
The proposed method trains multiple monolingual or adaptation-specific E2E ASR models and uses confidence scores to select the most appropriate output for each utterance. Confidence is estimated from intermediate CTC layers, allowing the system to evaluate only the most promising model at runtime. For multilingual scenarios, the approach combines monolingual models to handle language switches more effectively than language identification-based selection. For adaptation tasks, it combines base and adapted models to preserve base model performance while benefiting from accent-specific improvements. The confidence estimation framework enables efficient runtime selection by avoiding full decoding of all models.

## Key Results
- Up to 10% relative WERR improvement on multilingual datasets compared to LID-based model selection
- 10-50% WERR improvement on accent/dialect adaptation tasks compared to constraint adaptation approaches
- Up to 4.5x runtime efficiency improvement by using confidence scores from intermediate layers instead of full model outputs

## Why This Works (Mechanism)
The method works by leveraging the complementary strengths of multiple specialized models while using confidence as a reliable proxy for model competence. Monolingual models excel in their respective languages but struggle with language switches, while the confidence-based selection ensures the right model handles each utterance. During adaptation, the base model retains general performance while the adapted model captures accent-specific patterns, with confidence guiding the selection between them. The intermediate CTC layer provides an efficient confidence signal that correlates well with final model performance, enabling fast model selection without full decoding overhead.

## Architecture Onboarding

**Component map:** Input audio -> Feature extraction -> Multiple E2E ASR models -> Intermediate CTC layers -> Confidence estimation -> Model selection -> Final output

**Critical path:** Audio features → Intermediate CTC layer → Confidence score → Model selection → Output

**Design tradeoffs:** Intermediate CTC loss vs. end-only CTC (efficiency vs. flexibility), full decoding vs. confidence-based selection (accuracy vs. speed), monolingual vs. multilingual models (specialization vs. coverage)

**Failure signatures:** Poor confidence calibration leading to wrong model selection, intermediate CTC scores not correlating with final performance, language identification errors in multilingual settings, catastrophic forgetting in adaptation scenarios

## Limitations
- Limited evaluation to bilingual language pairs, not tested on trilingual/multilingual scenarios
- Reliance on intermediate CTC loss for confidence estimation limits applicability to architectures without this feature
- No comprehensive analysis of confidence calibration across different model sizes and domains
