# On Coherence-based Predictors for Dense Query Performance Prediction

## Quick Facts
- arXiv ID: 2310.11405
- Source URL: https://arxiv.org/abs/2310.11405
- Reference count: 40
- Primary result: PairRatio variants outperform supervised BERT-based QPP models for dense retrieval on NDCG@10 and MRR@10.

## Executive Summary
This paper introduces unsupervised coherence-based predictors for dense retrieval models (ANCE and TCT-ColBERT) by adapting existing sparse predictors to use dense embeddings. The authors propose pairRatio, a new metric leveraging rank-based pairwise similarity, and evaluate these predictors on TREC Deep Learning Track datasets. Results show significant improvements over sparse variants and competitive performance against supervised BERT-based predictors. Statistical analysis reveals that query type explains up to 35% of variance in prediction performance, a factor unique to dense retrieval.

## Method Summary
The authors adapt spatial autocorrelation and network metrics (AC, WAND, WD) with dense embeddings and propose pairRatio and A-pairRatio metrics. They evaluate these predictors on ANCE and TCT-ColBERT dense retrieval models using TREC Deep Learning Track 2019 and 2020 datasets. Performance is measured using Kendall's τ correlation between predicted and actual effectiveness metrics (NDCG@10, MAP@100, MRR@10). The study also employs linear mixed effects models to analyze the influence of query type on predictor performance.

## Key Results
- PairRatio variants outperform supervised BERT-based QPP models for dense retrieval on NDCG@10 and MRR@10.
- Changing document representations from sparse TF-IDF to dense embeddings improves coherence-based QPP predictor accuracy for both sparse and dense retrieval systems.
- Query type (e.g., Experience, Factoid, Reason) explains up to 35% of variance in QPP performance for dense retrieval, a factor not present in sparse retrieval.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: PairRatio variants outperform supervised BERT-based QPP models for dense retrieval on NDCG@10 and MRR@10.
- **Mechanism**: These predictors capture relative coherence of document embeddings by comparing average similarity of top-ranked vs. lower-ranked documents. Using embedding similarity matrix directly aligns with dense retrieval's representation space, improving accuracy over sparse TF-IDF-based coherence measures.
- **Core assumption**: Document embeddings produced by dense retrieval models are spatially coherent for high-performing queries, and contrast between high-rank and low-rank document similarities reflects retrieval effectiveness.
- **Evidence anchors**:
  - [abstract]: "pairRatio, a new metric leveraging rank-based pairwise similarity... show significant improvements over sparse variants (up to 92% for TCT-ColBERT and 188% for ANCE in accuracy)"
  - [section]: "we observe that our pairRatio predictors outperform not only supervised predictors, but also NQC (the best performing unsupervised predictor) for NDCG@10 and MRR@10"
- **Break condition**: If dense embeddings fail to preserve semantic similarity structure (e.g., due to poor model training), PairRatio's signal will degrade and underperform score-based predictors.

### Mechanism 2
- **Claim**: Changing document representations from sparse TF-IDF to dense embeddings improves coherence-based QPP predictor accuracy for both sparse and dense retrieval systems.
- **Mechanism**: Dense embeddings capture semantic similarity that TF-IDF misses, so spatial autocorrelation (AC-embs) and network metrics (WAND-embs, WD-embs) gain discriminative power when applied in embedding space. This increases sensitivity to query effectiveness patterns.
- **Core assumption**: Semantic similarity in embedding space is more indicative of document relevance relationships than lexical overlap, especially in dense retrieval where ranking is based on embedding proximity.
- **Evidence anchors**:
  - [abstract]: "improved accuracy upon dense retrieval (up to 92% compared to sparse variants for TCT-ColBERT and 188% for ANCE)"
  - [section]: "surprisingly, AC-embs variant is the best performing predictor for AP@100, and for NDCG@10 on 2020... changing the type of representations from sparse to dense increases the performance of coherence-based predictors"
- **Break condition**: If embeddings are not well-trained or are too compressed to preserve fine-grained similarity, the performance gain will disappear.

### Mechanism 3
- **Claim**: Query type explains up to 35% of variance in QPP performance for dense retrieval, a factor not present in sparse retrieval.
- **Mechanism**: Different query categories exhibit distinct effectiveness patterns, and dense retrieval models are more sensitive to these differences. Mixed-effects modeling reveals that query type interacts with predictor performance, causing unstable predictions if not accounted for.
- **Core assumption**: Query categories represent meaningful differences in difficulty that are amplified by the embedding-based ranking mechanisms of dense retrieval, but not by lexical BM25 scoring.
- **Evidence anchors**:
  - [abstract]: "query types further significantly influence query performance (and are up to 35% responsible for the unstable performance of QPP predictors), and that this sensitivity is unique to dense retrieval models"
  - [section]: "we detect a unique sensitivity of dense retrieval methods, which are affected by query type (up to 35% increase in query performance variations due to query categorisation)"
- **Break condition**: If query type categories are poorly defined or if dense retrieval embeddings become robust to query semantic structure, the explained variance will drop.

## Foundational Learning

- **Concept**: Linear Mixed Effects Models (LMEs)
  - **Why needed here**: To partition variance in QPP performance into within-query (differences across predictors) and between-query (differences across query types) components, enabling precise identification of sources of instability.
  - **Quick check question**: In an LME with query type as a between-query factor and predictor as a within-query factor, what does a significant interaction term (𝛾11) tell us about predictor performance?

- **Concept**: Pairwise similarity matrices in embedding space
  - **Why needed here**: The PairRatio predictor relies on comparing average similarity of high-rank vs. low-rank document pairs. Understanding how to compute and interpret these matrices is critical for implementing the method.
  - **Quick check question**: Given a similarity matrix W for the top-k documents, how would you compute the ratio of mean similarity above rank 𝜏 to mean similarity below rank 𝜏?

- **Concept**: Evaluation metrics for QPP
  - **Why needed here**: QPP is evaluated via Kendall's 𝜏 correlation and sARE (scaled Absolute Rank Error). Knowing the difference between these measures helps interpret predictor performance correctly.
  - **Quick check question**: If a predictor has high Kendall's 𝜏 but high sARE, what does that imply about its performance across individual queries?

## Architecture Onboarding

- **Component map**: Input rankings -> Embedding similarity computation -> Coherence-based predictors (AC-embs, WAND-embs, WD-embs, PairRatio, A-pairRatio) -> Kendall's τ and sARE evaluation -> (Optional) LME analysis
- **Critical path**:
  1. Retrieve top-k documents per query using dense model
  2. Extract query and document embeddings
  3. Build similarity matrix (dense variant)
  4. Apply PairRatio or other coherence measures
  5. Correlate predictions with ground truth effectiveness
  6. (Optional) Run mixed-effects model on sARE values
- **Design tradeoffs**:
  - PairRatio requires tuning of rank thresholds (𝜏) and adds computational overhead; simpler variants like AC-embs avoid this but may be less discriminative.
  - Using dense embeddings assumes access to the same model that generated the ranking; if not available, must store embeddings.
  - LME analysis is computationally heavier but provides richer diagnostic information.
- **Failure signatures**:
  - Low variance in pairwise similarities → PairRatio signal collapses
  - High correlation but poor sARE → predictor may be biased toward aggregate trends, not individual query quality
  - High sensitivity to query type in sparse retrieval → likely bug in preprocessing or data split
- **First 3 experiments**:
  1. Compare AC-embs vs. AC on a subset of queries to confirm embedding-space gain
  2. Tune PairRatio thresholds on held-out queries and evaluate NDCG@10 improvement
  3. Run LME analysis to confirm query type effect size differs between dense and sparse retrieval

## Open Questions the Paper Calls Out

### Open Question 1
- **Question**: How do the pairRatio and A-pairRatio predictors specifically respond to different query types, and can this be leveraged to improve query performance prediction accuracy?
- **Basis in paper**: [explicit] The paper discusses the interaction of query types with predictors, particularly noting that Experience and Reason queries perform differently across predictors.
- **Why unresolved**: The paper identifies the interaction but does not provide detailed insights into how specific predictors can be optimized for different query types.
- **What evidence would resolve it**: Experimental results showing the performance of pairRatio and A-pairRatio across different query types, and analysis of how these predictors can be tuned or adapted for specific query categories.

### Open Question 2
- **Question**: What are the limitations of applying BERT-based models for query performance prediction in dense retrieval settings, and how can these limitations be addressed?
- **Basis in paper**: [explicit] The paper finds that BERT-QPP models are less effective than unsupervised predictors for dense retrieval, suggesting a potential misdirection of resources.
- **Why unresolved**: The paper does not explore the specific reasons for the limitations of BERT-QPP in dense retrieval or propose solutions to overcome these challenges.
- **What evidence would resolve it**: Comparative studies of BERT-QPP and other models in dense retrieval, identifying specific weaknesses and potential improvements.

### Open Question 3
- **Question**: How can the findings on query type sensitivity in dense retrieval be used to develop more effective query performance prediction models?
- **Basis in paper**: [explicit] The paper highlights the significant influence of query types on prediction performance, especially in dense retrieval, suggesting a need for tailored predictors.
- **Why unresolved**: The paper does not provide concrete methods for developing predictors that account for query type differences.
- **What evidence would resolve it**: Development and testing of new QPP models that incorporate query type information, demonstrating improved accuracy across diverse query categories.

## Limitations
- The study lacks direct corpus validation for the assumption that dense embeddings preserve semantic similarity correlating with retrieval quality.
- The findings may not generalize beyond TREC DL datasets and MSMARCO domain, with no examination of robustness across different retrieval domains.
- Reliance on Kendall's τ and sARE as sole evaluation metrics may obscure other dimensions of predictor performance, such as calibration or stability under distributional shift.

## Confidence
- **High**: Relative performance improvements of pairRatio and embedding-based predictors over sparse baselines, given clear statistical trends and replication potential.
- **Medium**: Claim about query type variance (35% explained), as mixed-effects model supports the effect but lacks external validation.
- **Low**: Dense embedding coherence assumption, as it is derived from observed performance gains rather than grounded in verified theoretical model.

## Next Checks
1. **Cross-domain validation**: Test coherence-based predictors on non-MSMARCO datasets (e.g., TREC CAR, Robust04) to verify generalization.
2. **Embedding space sanity check**: Visualize embedding similarity matrices for top-ranked vs. bottom-ranked documents to confirm coherence signal before applying PairRatio.
3. **Robustness analysis**: Apply LME modeling on sARE values stratified by query length and vocabulary diversity to isolate whether query type effects persist beyond the proposed taxonomy.
