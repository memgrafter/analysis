# Subequivariant Graph Reinforcement Learning in 3D Environments

## Quick Facts
- **arXiv ID:** 2305.18951
- **Source URL:** https://arxiv.org/abs/2305.18951
- **Reference count:** 40
- **Primary result:** SubEquivariant Transformer (SET) improves policy generalization in 3D environments by enforcing O(3)-equivariance, outperforming state-of-the-art methods like SWAT and SMP.

## Executive Summary
This paper addresses the challenge of extending morphology-agnostic reinforcement learning to complex 3D environments where agents start from arbitrary configurations and move toward arbitrary targets. The key insight is that traditional invariance constraints are insufficient for 3D spaces with enlarged state-action spaces. The authors propose SubEquivariant Graph Reinforcement Learning (3D-SGRL) with a novel SubEquivariant Transformer (SET) architecture that injects geometric symmetry—specifically subequivariance under O(3)—into the policy network. This approach enables the policy to generalize across all orientations while maintaining expressive message passing capabilities. The method is evaluated on single-task, multi-task, and zero-shot scenarios, consistently outperforming state-of-the-art baselines and demonstrating superior generalization under orientation shifts.

## Method Summary
The method extends morphology-agnostic RL to 3D environments by proposing a SubEquivariant Transformer (SET) that enforces O(3)-equivariance in the policy network. SET processes each limb's state into directional geometric vectors and scalar features, then performs self-attention with O(3)-invariant matrices and queries. The actor module generates O(3)-invariant torques from SET's subequivariant output, while the critic module computes Q-values using invariant matrices from SET. The framework is trained using TD3 with separate SETs for actor and critic. The approach is evaluated on modified 3D MuJoCo environments (Hopper, Walker, Humanoid, Cheetah) with increased joint DoF and arbitrary initial configurations, comparing against SWAT, SMP, and Monolithic baselines.

## Key Results
- SET consistently outperforms state-of-the-art methods (SWAT, SMP) across single-task, multi-task, and zero-shot scenarios
- Achieves notably higher rewards in 3D environments with arbitrary starting configurations and target directions
- Ablations confirm subequivariance is necessary for the performance gains
- Demonstrates better generalization than invariant methods under orientation shifts

## Architecture Onboarding

- **Component map:** Input Processing -> SET -> Actor Module -> Actions -> Environment -> Critic Module -> Q-values -> TD3 Optimization

- **Critical path:** Input Processing → SET → Actor Module → Actions → Environment → Critic Module → Q-values → TD3 Optimization

- **Design tradeoffs:**
  - Expressiveness vs. Symmetry Preservation: The SET architecture needs to balance the expressive power of transformers with the symmetry-preserving properties of GNNs.
  - Computational Complexity: The self-attention mechanism in SET can be computationally expensive, especially for large morphological graphs.
  - Generalization vs. Specificity: The subequivariant constraint helps with generalization across orientations but may limit the policy's ability to capture specific environment features.

- **Failure signatures:**
  - Poor policy performance in 3D environments with arbitrary starting configurations and target directions.
  - Instability in the learning process, such as the policy getting stuck in local minima.
  - Inability to effectively capture the interactions between limbs and joints, leading to suboptimal actions.

- **First 3 experiments:**
  1. Evaluate the policy performance on a simple 3D environment with a fixed agent morphology and varying initial configurations and target directions.
  2. Compare the performance of SET with a standard transformer and a GNN on a 3D environment with multiple agent morphologies.
  3. Analyze the learned policy's behavior in response to different gravity directions and target orientations to verify the subequivariant properties.

## Limitations
- Relies on simulated 3D environments, leaving open questions about real-world transfer
- Subequivariance constraint may limit expressiveness for tasks requiring asymmetric dynamics
- SET architecture introduces computational overhead through multi-head attention across all limb-joint pairs

## Confidence
- **High confidence:** The empirical superiority of SET over SWAT and SMP in the tested environments, given the consistent performance gains across multiple metrics and scenarios.
- **Medium confidence:** The theoretical underpinnings of subequivariance and its necessity for 3D generalization, as the paper provides formal definitions but limited formal proofs of optimality.
- **Low confidence:** The robustness of SET to extremely diverse morphologies beyond the tested set (Hopper, Walker, Humanoid, Cheetah), as the evaluation scope remains relatively narrow.

## Next Checks
1. **Zero-shot transfer to novel morphologies:** Test SET on entirely unseen agent structures (e.g., multi-legged robots, snake-like morphologies) without fine-tuning to verify true morphology-agnostic capabilities.

2. **Real-world deployment validation:** Implement SET on a physical robot platform to assess whether the subequivariant properties hold under sensor noise, actuator delays, and imperfect dynamics modeling.

3. **Ablation on symmetry constraint strength:** Systematically vary the degree of subequivariance enforcement (e.g., partial vs. full O(3) invariance) to determine the optimal balance between generalization and task-specific performance.
