# Verbalized Machine Learning: Revisiting Machine Learning with Language Models

## Quick Facts
- **arXiv ID:** 2406.04344

## Executive Summary
Verbalized Machine Learning (VML) introduces a framework that reimagines language models as function approximators whose parameters are human-interpretable natural language prompts. This approach enables encoding inductive bias, automatic model class selection, and interpretable model updates through iterative optimization between a learner LLM and an optimizer LLM. The method demonstrates that classical machine learning problems can be solved using text-based representations while maintaining interpretability of the learned parameters and updates.

## Method Summary
VML treats language models as function approximators parameterized by natural language prompts rather than traditional numerical parameters. The framework operates through an iterative optimization process where a learner LLM is updated by an optimizer LLM via text prompt optimization. Natural language prompts serve as interpretable parameters that can encode prior knowledge and inductive biases directly. The method leverages the linguistic capabilities of LLMs to perform regression and classification tasks while maintaining human interpretability throughout the learning process.

## Key Results
- VML successfully solves classical ML regression and classification tasks using interpretable natural language prompts
- The framework enables automatic model class selection based on the structure of the natural language prompts
- VML generates interpretable updates that can be directly understood by humans, unlike traditional numerical parameter updates
- Experimental results demonstrate the framework's ability to encode inductive bias through carefully crafted prompts

## Why This Works (Mechanism)
VML works by leveraging the linguistic understanding capabilities of large language models to approximate mathematical functions. By parameterizing LLMs with natural language prompts rather than numerical weights, the framework transforms abstract mathematical operations into interpretable linguistic descriptions. The iterative optimization process allows the model to refine its understanding through textual feedback, effectively translating mathematical optimization into a language-based reasoning task that LLMs can process.

## Architecture Onboarding

**Component Map:**
Optimizer LLM -> Learner LLM -> Data Samples -> Performance Evaluation -> Feedback Loop

**Critical Path:**
1. Initial prompt formulation for learner LLM
2. Data evaluation by learner LLM
3. Optimizer LLM analysis of performance
4. Prompt refinement and update
5. Iterative loop until convergence

**Design Tradeoffs:**
- **Interpretability vs Performance:** Natural language prompts sacrifice some mathematical precision for human readability
- **Computational Efficiency:** Text-based optimization is slower than gradient-based methods but provides explanations
- **Prompt Engineering Complexity:** Careful prompt design required to encode appropriate inductive biases

**Failure Signatures:**
- High variance in LLM function evaluation leading to numerical instability
- Difficulty scaling to high-dimensional problems due to prompt complexity
- Convergence issues when optimizer LLM cannot generate effective prompt refinements

**3 First Experiments:**
1. Simple linear regression using interpretable prompts to establish baseline performance
2. Model selection task where different prompt structures automatically select appropriate model classes
3. Knowledge incorporation test where prior domain knowledge is embedded in prompts and evaluated

## Limitations
- High variance in LLM function evaluation causes numerical errors that affect training stability
- Computational overhead compared to traditional gradient-based optimization methods
- Limited scalability to complex, high-dimensional problems due to prompt complexity constraints

## Confidence

**Major Claim Confidence:**
- **High confidence:** Language models can serve as interpretable function approximators using natural language prompts
- **Medium confidence:** VML provides meaningful interpretability advantages over traditional ML approaches
- **Low confidence:** VML can effectively replace traditional ML methods for practical, large-scale problems
