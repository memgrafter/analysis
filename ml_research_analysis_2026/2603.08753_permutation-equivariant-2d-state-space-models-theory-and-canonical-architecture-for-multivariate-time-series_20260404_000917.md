# Permutation-Equivariant 2D State Space Models: Theory and Canonical Architecture for Multivariate Time Series

## Quick Facts
- **ArXiv ID**: 2603.08753  
- **Source URL**: https://arxiv.org/abs/2603.08753  
- **Reference count**: 40  
- **Primary result**: Introduces permutation-equivariant 2D SSMs, achieving O(1) variable-axis depth, SOTA on 4/8 forecasting datasets, and best anomaly detection F1 (87.24), with near-constant compute scaling.

## Executive Summary
Multivariate time series often exhibit exchangeability among variables, yet standard 2D state space models impose an arbitrary sequential ordering along the variable dimension, hindering both theoretical analysis and computational efficiency. This paper resolves this by developing a theoretical framework for permutation-equivariant 2D SSMs, proving that any linear equivariant coupling decomposes into local self-dynamics and a global pooled interaction. The resulting Variable-Invariant 2D SSM replaces ordered recurrence with a permutation-invariant aggregation, drastically reducing the variable-axis dependency depth from O(C) to O(1) and simplifying stability analysis to two scalar modes. The authors further extend the design to VI 2D Mamba, which combines long- and short-term temporal processing with a frequency-domain pathway. Empirical evaluation across long-term forecasting and anomaly detection tasks shows state-of-the-art accuracy, constant computational cost as the number of variables grows, and a 3.8× training speedup over conventional 2D-SSM, while maintaining robustness to variable permutations.

## Method Summary
The core innovation lies in replacing the sequential recurrence along the variable axis of traditional 2D SSMs with a permutation-invariant aggregation (e.g., mean or attention-based pooling). Theoretically, for linear time-invariant dynamics, any coupling that respects permutation symmetry can be expressed as a sum of a local term (acting on each variable independently) and a global term (acting on the pooled representation of all variables). This canonical decomposition yields a model with a fixed-depth variable processing pipeline regardless of the number of variables, and reduces stability considerations to two scalar subsystems. The practical VI 2D Mamba instantiates this idea by incorporating multiple temporal branches (long and short) and a separate frequency branch, enabling the capture of diverse temporal patterns while preserving permutation equivariance through shared global pooling. Data-dependent parameters (e.g., selective scanning) and optional attention aggregators further enhance expressiveness beyond the linear theory.

## Key Results
- Reduces variable-axis dependency depth from O(C) to O(1) while stability simplifies to two scalar modes.
- Achieves top‑1 MSE on 4 of 8 long‑term forecasting benchmarks (e.g., ETTm1 MSE 0.345) and the highest anomaly detection F1 score (87.24 averaged).
- Maintains near‑constant computational cost as the number of variables increases, with a 3.8× training speedup versus conventional 2D‑SSM and negligible performance variance across variable permutations.

## Why This Works (Mechanism)
The theoretical foundation shows that any linear, permutation-equivariant coupling matrix can be decomposed into a sum of two rank‑one matrices: one corresponding to identical local dynamics applied to each variable, and another representing global interaction via a pooled summary of all variables. This decomposition is enforced by the symmetry group (the symmetric group on C variables) and yields a model where the variable axis is processed in constant depth: each variable’s state is first updated locally, then a permutation‑invariant function aggregates all states into a global context, which is then broadcast back to each variable. The resulting architecture eliminates the sequential dependence of one variable’s update on the previous variable’s state, drastically simplifying the Jacobian and reducing stability analysis to the eigenvalues of two scalar operators (the local and global dynamics). The practical model preserves this structure even with nonlinearities by using data‑dependent parameters and attention‑based pooling, which still maintain permutation equivariance by design, thereby inheriting the computational and stability benefits within a more expressive nonlinear framework.

## Foundational Learning
- **Permutation Equivariance**: A property ensuring that permuting input variables leads to a consistent permutation of the output. *Why needed*: Real-world multivariate series often have exchangeable variables; imposing this symmetry prevents the model from learning spurious orderings. *Quick check*: Randomly shuffle the variable dimension of a batch; the model’s loss and predictions should remain unchanged (or change predictably if the task is equivariant rather than invariant).
- **State Space Models (SSMs)**: Continuous‑time or discrete‑time dynamical systems that map an input sequence to a latent state sequence and an output. *Why needed*: SSMs provide a principled way to model temporal dependencies with linear complexity. *Quick check*: Implement a linear SSM and verify that it can reconstruct a known simple process (e.g., a damped oscillator) via forward simulation.
- **2D State Space Models**: SSMs extended to two dimensions (time and variables), typically processing both axes with recurrent or convolutional operations. *Why needed*: They capture interactions across time and variables in a unified manner. *Quick check*: Compare a standard 2D‑SSM against independent univariate SSMs on a synthetic coupled dataset to confirm the benefit of cross‑variable coupling.
- **Permutation‑Invariant Aggregation**: Functions such as mean, sum, or attention that treat all variables symmetrically. *Why needed*: Enforces exchangeability and reduces variable‑axis depth. *Quick check*: Apply the aggregation to a tensor with permuted variable slices; the result should be identical.
- **Stability Analysis for Linear Systems**: Examining eigenvalues of the state transition matrix. *Why needed*: Guarantees boundedness of latent states; the paper shows stability reduces to two scalar operators. *Quick check*: For a linear VI‑2D‑SSM, compute eigenvalues of the local and global transition matrices; ensure they lie inside the unit circle.
- **Frequency‑Domain Processing**: Analyzing signals in the frequency basis (e.g., via Fourier transform). *Why needed*: Complements time‑domain branches to capture periodicities. *Quick check*: Apply a known sinusoid to the frequency branch and verify peak at corresponding frequency in the spectrum.

## Architecture Onboarding
**Component map**:  
Input sequence (batch × time × variables) -> Permutation‑Invariant 2D SSM core (local update per variable + global pooled interaction) -> Split into temporal branches (long‑term & short‑term) and frequency branch -> Task‑specific head (e.g., linear projection for forecasting or classification for anomaly detection) -> Output.

**Critical path**: The most essential flow is: variable‑wise local state update → permutation‑invariant aggregation of all variable states → broadcast global context back to each variable → repeat across time or scan along time. The temporal branches and frequency branch operate in parallel and are fused before the final head.

**Design tradeoffs**:
- *Aggregation choice*: Mean/sum are simple and fast but may under‑express complex interactions; attention is more expressive but adds computational overhead and may break strict equivariance if not symmetrized.
- *Number of temporal branches*: More branches increase capacity to model multi‑scale dynamics but also increase parameters and risk overfitting.
- *Separate frequency branch*: Improves handling of periodic patterns but doubles the number of parameters and requires careful regularization.

**Failure signatures**:
- Model performance degrades significantly when the exchangeability assumption is violated (e.g., variables have distinct roles).
- Training becomes unstable if the global pooled interaction magnitude is not properly normalized, leading to exploding latent states.
- The constant‑depth benefit collapses if the permutation‑invariant aggregation is replaced with a sequence‑dependent operation (e.g., ordered scan).

**First three experiments**:
1. *Permutation invariance test*: Randomly shuffle the variable order across batches and compute the variance of predictions; expect near‑zero variance.
2. *Scaling with variable count*: Train on synthetic data with increasing numbers of variables (e.g., C=16,32,64,128) and measure accuracy and training time; expect flat cost curve and stable accuracy.
3. *Benchmark against conventional 2D‑SSM*: Run both models on a standard dataset (e.g., ETTm1) with identical hyperparameters; compare MSE and training throughput to verify claimed 3.8× speedup and SOTA performance.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: How do non-linear components (data-dependent parameters, attention pooling) affect the canonical decomposition and stability of permutation-equivariant 2D SSMs?
- Basis in paper: [inferred] The theoretical results (Theorem 1,3) assume linear coupling, but the implemented model includes data-dependent Δ, B, C (Section IV-B) and optional attention aggregation (Section IV-B-1).
- Why unresolved: The stability analysis and equivariance derivation rely on linear time-invariant dynamics; non-linearities invalidate these assumptions, leaving stability and equivariance unverified for the full model.
- What evidence would resolve it: Formal stability conditions for the non-linear system; systematic empirical evaluation of how data-dependent parameters impact performance and robustness.

### Open Question 2
- Question: What are the trade-offs between different permutation-invariant aggregation functions (e.g., mean, sum, attention) in terms of expressiveness, computational cost, and task suitability?
- Basis in paper: [inferred] The architecture permits any invariant ϕ (Section IV-B-1) and employs mean pooling for forecasting and attention for classification/anomaly detection (Section VI-C) without theoretical justification.
- Why unresolved: The impact of ψ on the model's representational capacity and efficiency is not analyzed; the choice is heuristic and task-dependent.
- What evidence would resolve it: Theoretical comparison of aggregators' effects on the effective coupling spectrum; comprehensive benchmarks measuring accuracy, memory, and FLOPs across variable counts C and task types.

### Open Question 3
- Question: Can the framework be extended to incorporate partial or structured symmetries (e.g., graph-based variable relationships) while preserving computational benefits?
- Basis in paper: [inferred] The model assumes full variable exchangeability (Definition 1), but the introduction notes that sequential scanning is natural in spatial domains, implying that not all settings admit full permutation symmetry.
- Why unresolved: The design hinges on global pooling under the full symmetric group; other group structures require fundamentally different invariant/equivariant constructions.
- What evidence would resolve it: Develop layers equivariant to arbitrary group actions (e.g., graph automorphisms); evaluate on datasets with known variable graphs to test accuracy and scalability.

### Open Question 4
- Question: Does the global pooling mechanism maintain predictive performance as the number of variables C grows very large, or does it lose fine-grained variable-specific information?
- Basis in paper: [inferred] The C-scaling experiment (Section VI-B, Table IV) shows stable MAE up to C=256 on a linear VAR process, but real-world high-dimensional MTS may involve complex, non-linear interactions.
- Why unresolved: The evaluation uses a simple linear data-generating process; it remains unclear whether the model scales to high-dimensional data with sparse, non-linear, or long-range dependencies.
- What evidence would resolve it: Test on synthetic high-C datasets with increasing complexity (e.g., coupled chaotic systems, graphical structures); measure accuracy decay and permutation sensitivity as C increases.

## Limitations
- Theoretical guarantees are limited to linear equivariant couplings; the actual model employs nonlinear data‑dependent parameters and attention, so the O(1) depth and two‑scalar stability are not rigorously proven for the full architecture.
- State‑of‑the‑art claims rely on partial dataset coverage (4/8 forecasting tasks) and may omit fair comparisons with recent competitors like TiVaT and VCformer.
- Efficiency assertions (3.8× speedup, constant compute) depend on the specifics of the baseline implementation and hardware, which are not fully detailed.
