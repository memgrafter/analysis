# IRPAPERS: A Visual Document Benchmark for Scientific Retrieval and Question Answering

## Quick Facts
*   **arXiv ID:** 2602.17687
*   **Source URL:** https://arxiv.org/abs/2602.17687
*   **Reference Count:** 40
*   **Primary Result:** Multimodal hybrid search (text + image) achieves 49% Recall@1, outperforming unimodal text (46%) and image (43%) baselines on a new 3,230-page scientific QA benchmark.

## Executive Summary
This paper introduces IRPAPERS, a benchmark of 3,230 scanned pages from information retrieval papers with 180 human-authored questions, to evaluate unimodal (text-only, image-only) and multimodal retrieval and question-answering systems for scientific documents. The core finding is that a hybrid approach combining text and image modalities consistently outperforms any single modality in both retrieval and QA, revealing complementary failure modes where each modality uniquely succeeds. The work suggests that advanced scientific documents contain information (e.g., spatial relationships in abstract plots) poorly captured by text transcriptions alone, motivating future agentic systems that can dynamically route queries to the appropriate modality.

## Method Summary
The study constructs the IRPAPERS benchmark by collecting PDFs, extracting high-resolution page images, and generating OCR text. A unimodal text baseline uses BM25 for lexical search and Arctic embeddings for semantic search, combined via hybrid fusion. The unimodal image baseline employs ColModernVBERT to produce multi-vector representations per page. A multimodal hybrid system fuses scores from both unimodal retrievers with a static weight (α). Retrieved context is fed to a text-based RAG system (GPT-4) for answer generation. Experiments compare these pipelines against closed-source models (e.g., Cohere Embed v4) on retrieval (Recall@k) and QA (alignment with human reference).

## Key Results
*   **Retrieval:** Text-only achieves 46% Recall@1, image-only 43%, multimodal hybrid 49%. Cohere Embed v4 (image) reaches 58% Recall@1.
*   **QA:** Text-based RAG scores 0.82 alignment at k=5 versus 0.71 for image-based; performance gains are observed with increased context depth (k=5).
*   **Complementarity:** Analysis of 40 queries shows 22 with text-only success and 18 with image-only success, indicating modality-specific strengths (e.g., t-SNE plots for images, exact acronyms for text).

## Why This Works (Mechanism)
The paper does not provide a dedicated mechanism or onboarding analysis section. The observed performance benefits are attributed to the complementary nature of textual and visual information in scientific documents, where exact lexical matches and symbolic precision are best served by text, while spatial, geometric, or layout-dependent information (e.g., cluster diagrams) requires image representations.

## Foundational Learning
*   **Multimodal Document Understanding:** Why needed: Scientific papers integrate text, formulas, and complex figures; a single modality cannot capture all information. Quick check: Can an OCR-only system answer questions about a scatter plot's quadrant distribution?
*   **Dense Vector Retrieval:** Why needed: Enables semantic search beyond keyword matching for both text (embeddings) and images (vision-language models). Quick check: Does replacing BM25 with embeddings improve recall for synonym-heavy queries?
*   **Hybrid Search Fusion:** Why needed: Combines strengths of lexical (BM25) and semantic (embedding) methods. Quick check: Is performance linear when interpolating BM25 and embedding scores?
*   **Retrieval-Augmented Generation (RAG):** Why needed: Grounds generative LLMs in retrieved context to minimize hallucination. Quick check: Does answer alignment improve with more retrieved passages (k)?
*   **Visual Document Understanding (VDU):** Why needed: Treats a page as an image to preserve layout and non-textual elements. Quick check: Does a VDU model outperform OCR+text models on layout-sensitive queries?

## Architecture Onboarding
**Component Map:**
User Query -> [Text Retriever (BM25 + Arctic)] -> Score_T
User Query -> [Image Encoder (ColModernVBERT) -> Page Embeddings] -> Score_I
Fusion (α * Score_T + (1-α) * Score_I) -> Top-K Pages -> RAG (GPT-4) -> Answer

**Critical Path:** The pipeline's efficiency hinges on the image encoder's processing time and the fusion parameter α. The RAG step is downstream and dependent on retrieval quality.

**Design Tradeoffs:** Using static fusion (α) is simple but not adaptive to query type. Image-based retrieval requires high-resolution page images, increasing storage and compute versus text-only. The benchmark's small size (180 questions) limits statistical power for failure mode analysis.

**Failure Signatures:** Text-only failures occur on queries about spatial arrangements or visual styles lost in OCR (e.g., "What shape is the cluster in Fig 3?"). Image-only failures occur on queries requiring exact string matches, precise numbers, or acronyms where OCR text is more reliable.

**First Three Experiments:**
1.  Ablate the hybrid system: Run pure BM25, pure Arctic, and pure ColModernVBERT to isolate each component's contribution.
2.  Failure mode categorization: Manually label the 40 complementary queries into types (e.g., "spatial layout", "exact match", "symbolic") to quantify modality strengths.
3.  Sensitivity to fusion weight α: Sweep α from 0 to 1 to find the optimal fixed point and compare against a learned weighting scheme.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Under what conditions do image-based representations uniquely enable retrieval and QA that text transcriptions cannot support?
- **Basis in paper:** [explicit] The paper explicitly asks "Do image representations contain answers to questions that would be impossible to answer with text transcriptions?" and provides the t-SNE plot example where spatial relationships are lost in OCR.
- **Why unresolved:** The study is confined to information retrieval papers and identified only a few abstract visuals (e.g., t-SNE) that resist textual serialization; the rarity in this corpus suggests many scientific domains may have richer geometric or spatial visuals untested.
- **What evidence would resolve it:** Systematically generate adversarial questions targeting diverse visual elements (e.g., vector fields, manifold diagrams, complex schematics) across multiple scientific corpora; evaluate both modalities under oracle retrieval to isolate representational limitations.

### Open Question 2
- **Question:** Conversely, when do text-based representations uniquely enable retrieval and QA that image embeddings cannot support?
- **Basis in paper:** [inferred] The paper implies this inverse question by discussing BM25's role in exact lexical matching and noting images lack mechanisms for symbolic precision; it suggests agentic systems to address such cases.
- **Why unresolved:** Not directly evaluated; the complementary failure modes show text-exclusive successes (22 queries) but the specific content types requiring exact text (e.g., acronyms, precise formulas) are not categorized or quantified.
- **What evidence would resolve it:** Construct a test suite of queries requiring exact string matches, numerical precision, or symbolic integrity; compare image vs. text retrieval and QA performance, analyzing failure cases to identify patterns in information loss.

### Open Question 3
- **Question:** How can agentic search systems dynamically combine text and image modalities at query time to optimize retrieval for heterogeneous scientific queries?
- **Basis in paper:** [explicit] The paper proposes "agentic search systems that decompose queries into semantic retrieval and structured constraints" as a future direction to address modality-specific strengths.
- **Why unresolved:** Multimodal hybrid search in the paper uses static fusion weights (α); no adaptive mechanism that routes queries based on predicted modality benefit is implemented or evaluated.
- **What evidence would resolve it:** Develop and benchmark query classifiers (e.g., via LLM prompting or learned models) that predict whether a query is visually or textually grounded; test dynamic weighting strategies on IRPAPERS and measure gains over fixed fusion, including computational trade-offs.

## Limitations
*   The IRPAPERS benchmark is small (3,230 pages, 180 questions), limiting generalizability across scientific domains and statistical robustness of failure mode analysis.
*   The image-based methods (e.g., ColModernVBERT) may not reflect the current state-of-the-art in vision-language models, potentially understating image-only performance.
*   The observed "complementary failure modes" are descriptive and lack statistical significance testing or cross-validation to confirm non-random patterns.

## Confidence
*   Hybrid multimodal search outperforms any single modality: **High** (direct, consistent result across retrieval and QA tasks).
*   Cohere Embed v4 image embeddings achieve 58% Recall@1: **Medium** (promising but compared against a specific text baseline; not benchmarked against other modern image encoders).
*   Text and image modalities have complementary failure patterns: **Medium** (observational finding from 40 queries; not validated with confidence intervals or on external datasets).

## Next Checks
1.  Scale IRPAPERS to 10,000+ pages from diverse STEM fields (e.g., biology, engineering) to test generalizability of the 49% hybrid retrieval score.
2.  Re-run experiments using modern open-source vision-language models (e.g., BLIP-2, GIT) as image encoders to verify if Cohere v4's result holds against stronger baselines.
3.  Perform statistical tests (e.g., chi-square) on the 40 complementary success/failure queries to determine if the observed pattern is significantly non-random.
