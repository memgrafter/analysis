# Multivariate Spatio-Temporal Neural Hawkes Processes

## Quick Facts
- arXiv ID: 2602.23629
- Source URL: https://arxiv.org/abs/2602.23629
- Reference count: 40
- Primary result: MSTNHP successfully models multivariate spatio-temporal point processes with flexible excitation/inhibition, capturing spatial intensity structures that temporal-only models miss.

## Executive Summary
Modeling multivariate spatio-temporal point processes (e.g., terrorism events) requires flexible excitation and inhibition without predefined kernels. Existing temporal neural Hawkes processes fail to capture spatial intensity structures and can produce unrealistic fits despite competitive likelihoods. The proposed Multivariate Spatio-Temporal Neural Hawkes Process (MSTNHP) extends continuous-time neural Hawkes by integrating spatial decay into latent state evolution via a continuous-time LSTM, allowing learned spatio-temporal dynamics. Simulations show MSTNHP accurately recovers true temporal and spatial intensity structures, while temporal-only models fail. Applied to Pakistan terrorism data, MSTNHP captures complex cross-group interactions, whereas a temporal-only model yields distorted intensities despite similar log-likelihoods, highlighting that likelihood alone is insufficient and structural diagnostics are needed.

## Method Summary
MSTNHP builds on the Neural Hawkes Process (NHP) by modifying its continuous-time LSTM core. The model accepts event streams (type, time, location), normalizes coordinates, and processes events sequentially. At each event, LSTM gates are updated to produce a new memory cell and output gate. Between events, the cell state for any query location (s,t) is computed via an analytic decay that incorporates both temporal and spatial components: c(s,t) = ¯c_{i-1} + (c_{i-1} - ¯c_{i-1}) exp(-δ(t)Δt - δ(s)||s-s_{i-1}||), where δ(t) and δ(s) are learned decay rates. The hidden state h(s,t) = o_i ⊙ (2σ(2c(s,t))-1) then parameterizes the conditional intensity λ_k(s,t) = softplus(w_k^T h(s,t)). The model maximizes the log-likelihood, with the intensity integral approximated via Monte Carlo sampling.

## Key Results
- MSTNHP accurately recovers true temporal and spatial intensity structures in simulations, while temporal-only models fail.
- On Pakistan terrorism data, MSTNHP captures complex cross-group interactions; temporal-only model yields distorted intensities despite similar log-likelihoods.
- Likelihood alone is insufficient; structural diagnostics (intensity recovery, spatial maps) are necessary for proper evaluation.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Incorporating a continuously evolving latent state via a continuous-time LSTM allows the model to capture complex, non-Markovian temporal dependencies and both excitation/inhibition without predefined kernels.
- **Mechanism:** Past events modify the LSTM's memory cell c(s,t) and output gate o_i. Between events, each cell dimension decays exponentially toward a learned steady state at a rate δ. At any time t, the hidden state h(s,t) is derived from these gates/cells and directly parameterizes the intensity via a learned weight w_k and softplus link. This creates a persistent, flexible memory of history.
- **Core assumption:** The continuous-time LSTM formulation, with its analytically solvable decay between events, provides a sufficient and computationally tractable representation of the history's influence on the instantaneous rate.
- **Evidence anchors:**
  - [abstract] "integrating spatial information into latent state evolution through learned temporal and spatial decay dynamics"
  - [section II-C & II-D] The comparison shows NHP (continuous-time LSTM) uniquely recovers true temporal intensity vs. other neural TPPs; Section II-D details the continuous-time LSTM equations (3,4).
  - [corpus] The neighbor paper "Mamba Hawkes Process" (arXiv:2407.05302) also builds on sequential state evolution for TPPs, implying community recognition of this mechanism's value, though it uses a different architecture.
- **Break condition:** If the underlying process requires memory effects that cannot be well-approximated by exponential decay of independent cell dimensions (e.g., highly oscillatory or long-period cycles beyond the LSTM's capacity), the model may fail to capture true dynamics despite likelihood gains.

### Mechanism 2
- **Claim:** Extending the temporal decay to include a learned spatial component δ(s) within the same LSTM cell evolution enables joint modeling of space-time clustering without assuming spatio-temporal separability.
- **Mechanism:** The memory cell decay (Eq. 5) incorporates both a temporal term e^{-δ(t)(t-t_{i-1})} and a spatial term e^{-δ(s)||s-s_{i-1}||}, scaled by learned decay rates. This means the influence of a past event attenuates with both elapsed time *and* Euclidean distance from the current spatial location s, all within the same latent state.
- **Core assumption:** The spatio-temporal influence of past events on the current intensity at location s and time t can be effectively factorized into independent temporal and spatial decay components applied to the LSTM cell state.
- **Evidence anchors:**
  - [abstract] "integrating spatial information into latent state evolution through learned temporal and spatial decay dynamics"
  - [section III-A] Explicitly presents Eq. (5) as the key extension from temporal NHP, adding the -δ(s)||s-s_{i-1}|| term.
  - [section IV-C & V] Simulation and real data results show MSTNHP recovers spatial intensity maps (Figure 6, 9) while a temporal-only model fails, validating the spatial component's necessity.
- **Break condition:** For data with strong non-separable spatio-temporal effects (e.g., a triggering kernel where the spatial decay rate depends on the time lag, or vice-versa), the separable decay in Eq. (5) would be misspecified, potentially leading to biased intensity estimates.

### Mechanism 3
- **Claim:** The model's flexibility (learning δ(t), δ(s), and cell steady states ¯c per event) allows it to capture time-varying and context-dependent excitation/inhibition patterns, including complex cross-type interactions.
- **Mechanism:** The LSTM gates (input, forget, output) and the cell update at each event time are event-type specific (implied by the weight w_k in intensity). The decay rates (δ(t), δ(s)) and steady states (¯c) are updated at each event based on the new hidden state, meaning the "memory half-life" and baseline for future decay can change dynamically after every observed event, for every cell dimension. This lets the posterior influence of a past event depend on the entire subsequent sequence of events.
- **Core assumption:** A high-dimensional LSTM state, with per-event updates to decay parameters and steady states, can learn complex, non-stationary triggering structures from data without overfitting, given sufficient model capacity (hidden size D) and data.
- **Evidence anchors:**
  - [section II-D] Describes how NHP (temporal core) allows "complex changes in triggering structures over time" and captures "both excitation and inhibition."
  - [section IV-B] Fitted intensities for Biv 2 (with negative cross-triggering) show MSTNHP recovers inhibitory periods.
  - [section V] Pakistan data results (Figure 8,9) show time-varying intensity patterns and complex spatial interactions across groups.
  - [corpus] The corpus lacks direct, high-confidence evidence for this *specific* mechanism (learned per-event decay rates) as a key driver, though papers like "Flexible Parametric Inference..." (arXiv:2406.06849) address non-stationarity, suggesting it's a recognized challenge.
- **Break condition:** With limited events per sequence or too small a hidden state D, the model may overfit or fail to disentangle the many per-event parameters, leading to unstable intensity estimates or poor generalization.

## Foundational Learning
- **Concept: Point Processes & Conditional Intensity**
  - **Why needed here:** MSTNHP models the fundamental object: the conditional intensity function λ_k(s,t|H_t). Understanding this as an instantaneous rate given full history is prerequisite to grasping what the model is learning and how likelihood (Eq. 6) is constructed.
  - **Quick check question:** "If an event occurs at (s,t), what does a high value of λ_k(s,t|H_t) imply about the model's assessment of the event's 'surprise' or 'expectedness' given everything before t?"
- **Concept: Neural Temporal Point Processes (e.g., NHP)**
  - **Why needed here:** MSTNHP is a direct extension of the Neural Hawkes Process. One must understand the temporal-only baseline—continuous-time LSTM, hidden state h(t), latent memory cell c(t) with exponential decay—to see what the spatial modification adds.
  - **Quick check question:** "In NHP, what is the role of the steady-state ¯c in the cell decay equation (4), and how does it differ from a simple exponential decay from zero?"
- **Concept: Continuous-Time LSTM & ODEs**
  - **Why needed here:** The core machinery is a continuous-time version of LSTM. The decay equations (4) and (5) are analytic solutions to an ODE defining cell evolution between discrete events. This is distinct from discrete-time RNNs or ODE-based methods requiring numerical solvers (like ODETPP).
  - **Quick check question:** "Why is the analytic solution for c(t) between events (Eq. 4/5) computationally advantageous compared to using a generic neural ODE solver for the same evolution?"

## Architecture Onboarding
- **Component map:** Input Handler -> Spatio-Temporal LSTM Core -> Intensity Head -> Loss Module
- **Critical path:** Event sequence → LSTM update → store (c_i, o_i, δ_i, ¯c_i) → for MC samples, evaluate c(s,t) via spatial-temporal decay → h(s,t) → λ(s,t) → aggregate for loss → backprop
- **Design tradeoffs:**
  - **Hidden size D:** Larger D increases capacity to model complex interactions but raises parameter count and risk of overfitting. See Section II-B, S.1 for runtime tradeoffs.
  - **Spatial domain S:** Using a fixed polygon/bounding box simplifies MC integration. A complex boundary may require rejection sampling.
  - **MC sample count:** More samples reduce integral variance but increase per-epoch cost. Must balance with batch size.
  - **Separable decay assumption (Eq. 5):** Simpler and differentiable, but may miss non-separable effects. A non-separable parameterization (e.g., exp(-δ(t)||s-s_{i-1}|| - δ(s)(t-t_{i-1})) or a neural net) is a clear, more flexible but less stable extension (Section VI).
- **Failure signatures:**
  - **Likelihood converges but fitted intensities are jagged/oscillatory** (like MTNHP on spatio-temporal data, Figure 7): Likely due to spatial misspecification; model is forcing spatially heterogeneous clusters into a temporal-only intensity.
  - **Intensity maps are spatially uniform or overly smoothed:** Model may be ignoring spatial decay (δ(s) near zero) or D too small.
  - **Training instability/NaNs:** Often from unphysically large decay rates (δ) or cell values. Gradient clipping and careful initialization of δ (small positive) are needed.
  - **Poor performance on new geographical regions:** Model may have overfit to the specific spatial domain S of training data; consider spatial data augmentation.
- **First 3 experiments:**
  1. Reproduce NHP on temporal-only simulation: Confirm implementation by recovering the temporal intensity from a known bivariate temporal Hawkes process (as in Section II-C, Figure 2 vs 3a). Validate loss decreases and intensity matches ground truth.
  2. Run MSTNHP on separable spatio-temporal simulation (Biv 1): Verify recovery of *both* temporal (Figure 5b) and spatial (Figure 6 row1 col2) intensity surfaces. Check that δ(s) learned is >0 and correlates with spatial triggering range σ.
  3. Compare MSTNHP vs. MTNHP on same spatio-temporal simulation: Demonstrate that MTNHP (collapsed data) fails to recover true temporal intensity (Figure 7a vs 5b), while MSTNHP succeeds. This diagnostic is crucial (Section VI).

## Open Questions the Paper Calls Out
- **Question 1:** How can the spatio‑temporal memory cell be extended to model nonseparable and nonstationary dependencies?
  - **Basis:** The authors state that “extending it to spatio‑temporal nonseparable or nonstationary structure may further help with real applications with complex spatio‑temporal point patterns.”
  - **Why unresolved:** The current model uses a separable exponential decay (Equation 5), which cannot capture interactions where spatial and temporal effects are coupled or vary across space/time.
  - **What evidence would resolve it:** Develop and compare alternative nonseparable decay parameterizations on synthetic datasets with known nonseparable ground‑truth intensities; assess recovery of spatial and temporal structures.
- **Question 2:** What are more effective ways to integrate advanced neural architectures (e.g., transformers, normalizing flows) with Hawkes processes?
  - **Basis:** The authors write that “exploring potentially more effective ways of integrating advanced modeling frameworks with Hawkes processes is left for future research.”
  - **Why unresolved:** Existing neural Hawkes models primarily use LSTM or attention; many promising deep learning architectures remain unexplored for point processes, and their trade‑offs are unclear.
  - **What evidence would resolve it:** Conduct systematic empirical comparisons of diverse architectures on standard spatio‑temporal point process benchmarks, evaluating both likelihood and structural fidelity (e.g., intensity shape recovery).
- **Question 3:** What diagnostic tools should be used to evaluate neural point process models beyond log‑likelihood?
  - **Basis:** The paper reveals that competitive log‑likelihoods can coexist with severely distorted intensity functions and recommends “structural diagnostics such as intensity recovery and spatial intensity maps” but does not define a comprehensive suite.
  - **Why unresolved:** Reliance on likelihood alone can mask model failures; without standardized diagnostics, assessing whether a model has truly learned the underlying dynamics is subjective and inconsistent.
  - **What evidence would resolve it:** Propose quantitative diagnostic measures (e.g., coverage of credible intervals, recovery of summary statistics, calibration tests) and validate them on simulated data where true intensities are known.
- **Question 4:** How does MSTNHP scale to higher‑dimensional mark spaces (i.e., many event types) and what architectural adjustments are needed?
  - **Basis:** The method was tested on at most four terrorist groups; the paper does not analyze computational complexity or performance as the number of event types grows.
  - **Why unresolved:** Model parameters include separate weight vectors per type; increasing the number of types may lead to parameter explosion, interference, or degraded accuracy, but these issues are unexamined.
  - **What evidence would resolve it:** Run experiments with synthetic datasets containing a varied number of event types (e.g., K = 10, 20, 50); measure training time, memory usage, and accuracy, and investigate parameter‑sharing or dimensionality‑reduction strategies if needed.

## Limitations
- Separable spatio-temporal decay (Eq. 5) may be misspecified for non-separable kernels.
- Monte Carlo integral approximation depends on sample count and spatial sampling strategy; no bias analysis.
- Real data evaluation lacks quantitative spatial metrics; relies on visual inspection.

## Confidence
- **Temporal flexibility (continuous-time LSTM):** High
- **Spatial decay integration:** High for separable processes, Medium for general cases due to separable assumption.
- **Complex cross-group interactions:** Medium

## Next Checks
1. **Non-separable synthetic test:** Generate Hawkes process with kernel K(t,s)=exp(-α t - β ||s|| - γ t·||s||). Compare MSTNHP fit; expect degradation if separable assumption fails.
2. **Ablation on spatial decay dynamics:** Freeze δ(s) to zero/constant; measure drop in spatial recovery (e.g., WASD) on simulations.
3. **Quantitative spatial diagnostics:** Compute 2-Wasserstein distance between predicted and true spatial intensity distributions (integrated over time) on test simulations; compare to baselines like MTNHP.
