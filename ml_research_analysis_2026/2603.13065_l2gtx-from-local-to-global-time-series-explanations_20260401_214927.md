# L2GTX: From Local to Global Time Series Explanations
## Quick Facts
- arXiv ID: 2603.13065
- Source URL: https://arxiv.org/abs/2603.13065
- Reference count: 24
- Primary result: L2GTX generates compact, model-agnostic global explanations for time series classifiers with stable faithfulness (R² 0.50–0.83) by aggregating local event-based primitives via clustering, submodular selection, and summarization.

## Executive Summary
L2GTX addresses the lack of model-agnostic, global explanations for time series classifiers. It aggregates local event-based explanations generated by the LOMATCE method, which extracts parameterized temporal event primitives such as trends and extrema. Through hierarchical merging of similar clusters and submodular optimization for selecting representative instances, L2GTX produces concise class-wise summaries. Experiments on six UCR datasets demonstrate that these summaries are both interpretable and faithful, with global faithfulness (mean local surrogate R²) typically ranging from 0.59 to 0.83 for FCN models and 0.50 to 0.83 for LSTM-FCN models.

## Method Summary
L2GTX operates on univariate time series classifiers without requiring access to internal model parameters. First, it samples a set of instances from each class. For each instance, the LOMATCE explainer perturbs the input, extracts parameterized event primitives (PEPs) — including increasing/decreasing trends and local extrema — and clusters them locally. A ridge regression surrogate trained on the event count matrix assigns an importance score to each local PEP cluster. Next, L2GTX merges similar PEP clusters across all instances using agglomerative clustering, with a merge percentile threshold controlling granularity. This creates a set of global clusters. An instance‑cluster importance matrix is then built by summing the importances of local clusters that fall into each global cluster. Global cluster importances are derived from this matrix. Under a predefined budget B, a greedy submodular selection algorithm chooses a subset of instances that maximally covers the most important global clusters. Finally, events from the selected instances are flattened into the global clusters, and their attributes (e.g., start time, duration, magnitude) are summarized with mean ± standard deviation. The output consists of class‑wise global explanations, typically visualized with bar charts depicting event types, timing, and strength.

## Key Results
- L2GTX yields compact, interpretable global explanations that capture class‑discriminative temporal patterns.
- Global faithfulness (average local surrogate R²) is stable across merger thresholds, ranging from 0.59 to 0.83 for FCN and 0.50 to 0.83 for LSTM-FCN models.
- The method effectively aggregates parameterized event primitives into actionable class summaries without sacrificing fidelity.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Local Parameterized Event Primitives (PEPs) extracted by LOMATCE provide semantically meaningful temporal patterns that align with human interpretation of time series, enabling interpretable aggregation.
- **Mechanism:** LOMATCE perturbs input time series, extracts events (increasing/decreasing trends, local extrema) parameterized by attributes like start time, duration, and value, and assigns importance scores via a weighted ridge regression surrogate. These structured events, rather than raw attribution scores, serve as the basis for clustering and global synthesis.
- **Core assumption:** These parameterized primitives correspond to domain-relevant behavioral motifs (e.g., a spike, a rising trend) and are stable enough across instances to be clustered meaningfully.
- **Evidence anchors:**
  - [abstract]: "extracts clusters of parameterised temporal event primitives, such as increasing or decreasing trends and local extrema"
  - [section 1]: "LOMATCE represents explanations using parameterised event primitives... yielding event-based explanations that align with how humans typically interpret time series"
  - [section 3.1]: Details LOMATCE's PEP extraction and importance assignment.
  - [corpus]: Corpus shows related work on event-based XAI (e.g., shapelets, primitives) but provides no direct validation that PEPs improve interpretability over other representations.
- **Break condition:** If extracted PEPs are noisy, inconsistent across instances, or fail to capture class-discriminative patterns, the global aggregation will produce incoherent or uninterpretable summaries.

### Mechanism 2
- **Claim:** Submodular optimization for instance selection ensures that a limited set of representative instances maximally covers the most globally important PEP clusters, balancing diversity and relevance.
- **Mechanism:** Given an instance-cluster importance matrix and global cluster importances, a greedy algorithm iteratively selects an instance that adds the most uncovered, high-importance clusters. This addresses the NP-hard set cover problem with a (1-1/e) approximation guarantee for submodular functions.
- **Core assumption:** A small, diverse subset of instances can collectively represent the majority of decision-relevant temporal patterns for a class, and cluster coverage correlates with global model behavior.
- **Evidence anchors:**
  - [abstract]: "selects a representative subset of instances via submodular optimization to maximize coverage of important clusters under a budget"
  - [section 3.4]: Formally defines the greedy selection objective using coverage indicator and global importance weights.
  - [section 5]: States that selected instances "maximise coverage of influential clusters" and that faithfulness remains stable.
  - [corpus]: Corpus includes SP-LIME (instance selection for tabular data) but not its adaptation to time-series event clusters; assumes transferability of submodular properties.
- **Break condition:** If influential clusters are highly dispersed across many instances or if the budget B is too small relative to cluster diversity, coverage will be incomplete, leading to biased global explanations that miss key patterns.

### Mechanism 3
- **Claim:** Hierarchical merging of similar PEP clusters across instances reduces redundancy in the explanation space while preserving global faithfulness, enabling compact yet accurate class-wise summaries.
- **Mechanism:** Agglomerative clustering merges local PEP clusters of the same type (e.g., all "increasing" trends) based on centroid Euclidean distance, using a user-defined merge percentile threshold τ. This creates a global cluster set; flattening events from selected instances into these global clusters and summarizing attributes (mean ± std) yields concise descriptions.
- **Core assumption:** PEPs with similar parameterized shapes (centroids) represent the same underlying temporal pattern, and merging them does not lose explanatory power if they are truly redundant.
- **Evidence anchors:**
  - [abstract]: "merges similar clusters globally"
  - [section 3.2]: Describes agglomerative merging based on centroid distance and threshold τ from percentile p.
  - [section 5]: "as p increases, the number of global clusters decreases monotonically... this consolidation does not degrade explanation faithfulness"
  - [ Figures 2, 3–6] illustrate cluster reduction and resulting summaries.
  - [corpus]: Corpus contains work on clustering time series segments/shapelets but not on merging locally explained event primitives for global synthesis.
- **Break condition:** Over-merging (high p) may conflate semantically distinct patterns (e.g., short vs. long increasing trends), while under-merging (low p) retains noise and redundancy. Faithfulness may degrade if merged clusters combine events with opposing importance directions.

## Foundational Learning
### Concept: Model-agnostic post-hoc explainability
  - *Why needed here:* L2GTX must work with any black-box time series classifier (FCN, LSTM-FCN) without relying on internal architecture. This requires treating the model as an oracle and using perturbation-based surrogates (LOMATCE) to infer behavior.
  - *Quick check question:* What are the trade-offs of a model-agnostic approach versus a model-specific one (e.g., CAM-based methods) in terms of generality and fidelity?

### Concept: Parameterized temporal event primitives (PEPs)
  - *Why needed here:* Traditional saliency maps assign importance to time steps or segments but lack semantic structure. PEPs encode trends and extrema with explicit parameters (start, duration, value), enabling meaningful aggregation, comparison, and domain interpretation (e.g., "a sharp peak at t=50").
  - *Quick check question:* How do PEPs differ from shapelets or motifs in terms of explainability purpose and parameterization?

### Concept: Submodular set cover for instance selection
  - *Why needed here:* To build a global explanation under a budget B, we must pick a small set of instances that collectively "cover" (i.e., contain) as many important PEP clusters as possible. The greedy algorithm provides a near-optimal solution efficiently.
  - *Quick check question:* Why is the coverage function (sum of importance of newly covered clusters) submodular, and what guarantees does the greedy algorithm provide?

## Architecture Onboarding
### Component map
1. **Input Sampler:** Draws `n_inst` instances per class from dataset.
2. **LOMATCE Explainer:** For each instance, generates local PEP clusters and importance scores (ridge surrogate on event-count matrix).
3. **Meta-Cluster Merger:** Agglomeratively clusters PEP centroids globally by type using distance threshold τ (from percentile p). Produces global cluster mapping.
4. **Matrix Builder:** Constructs instance-cluster matrix `M` where `M[i,j]` = sum of local importance scores for instance `i` in global cluster `j`.
5. **Global Importance Calculator:** Computes `I[j]` as sqrt of sum of absolute `M[:,j]`.
6. **Submodular Selector:** Greedily picks `B` instances maximizing weighted coverage of clusters via `I`.
7. **Event Aggregator:** Flattens events from selected instances' clusters into global clusters, computes mean ± std per event attribute.
8. **Output Summarizer:** Formats class-wise global explanations (bar charts with event types, timing, magnitude).

### Critical path
Sampled instances → LOMATCE per instance → meta-clustering → `M` matrix → `I` vector → submodular selection → event aggregation → global summaries. Any failure in LOMATCE (poor local explanations) or merging (incorrect τ) propagates to final output.

### Design tradeoffs
- **Merge percentile `p` vs. granularity:** High `p` (e.g., 95) yields few, broad clusters (compact explanations); low `p` preserves fine-grained distinctions (more clusters). Trade-off between conciseness and pattern specificity.
- **Budget `B` vs. coverage:** Larger `B` improves cluster coverage but reduces global compactness. `B` set to `n_inst` in experiments.
- **LOMATCE parameters:** Neighborhood size `S` and number of local clusters `K` affect fidelity and computational cost. Silhouette-based `K` estimation is heuristic.

### Failure signatures
1. **Low global faithfulness (GF):** Check if local LOMATCE fidelity is low first; if local is high but global drops, likely over-merging (increase `p`) or poor instance selection (increase `B`).
2. **Excessive clusters after merging:** Decrease `p` (lower threshold) or verify PEP extraction consistency; may indicate that centroids are too dispersed.
3. **Selected instances lack diversity:** Inspect `M` matrix sparsity; if many rows are similar, submodular may pick redundant instances. Could indicate clustering failure or dataset homogeneity.
4. **Visual explanations show overlapping or nonsensical events:** Likely incorrect merging across different event types or outlier PEPs; enforce type-separate merging (done in paper).

### First 3 experiments
1. **Merge percentile sweep:** Run L2GTX with `p ∈ {25,50,75,95}` for each dataset-model pair, record number of global clusters and GF (Tables 3,4). Expected: monotonic cluster decrease, stable GF.
2. **Instance selection visualization:** For a given class, plot the time series of selected instances (from submodular output) and overlay their PEPs. Verify that selected instances are diverse and cover different temporal regions.
3. **Class-wise explanation inspection:** Generate global explanations for two classes (e.g., ECG200 Normal vs. Infarction) and assess whether events align with domain knowledge (e.g., ECG morphology differences). Use Figures 3,4 as reference.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can L2GTX be extended to multivariate time series while preserving model-agnostic interpretability and explanation quality?
- **Basis in paper:** [explicit] "Future work will extend L2GTX to multivariate time series, where capturing interactions and dependencies across channels introduces additional challenges for global interpretability." (Section 6)
- **Why unresolved:** The current method only handles univariate series; multivariate data requires modelling cross-channel interactions, which the existing event primitive extraction and clustering framework does not support.
- **What evidence would resolve it:** A successful extension that defines suitable multivariate event primitives or adapts the clustering to multiple channels, validated on multivariate datasets with stable global faithfulness and clear visual explanations.

### Open Question 2
- **Question:** How do domain experts perceive the clarity, usefulness, and trustworthiness of L2GTX’s global explanations in real-world decision-making?
- **Basis in paper:** [explicit] "Human-centred evaluation of global explanations, including structured assessments with domain experts, could further examine the perceived usefulness, clarity, and trustworthiness of the generated class-level summaries in real-world decision-making settings." (Section 6)
- **Why unresolved:** The paper only evaluates quantitative fidelity (R²) and does not include any user studies to gauge whether the explanations are comprehensible or actionable for practitioners.
- **What evidence would resolve it:** Controlled user studies with domain experts from fields like healthcare or finance, measuring ratings of explanation quality and effects on decision confidence or task performance.

### Open Question 3
- **Question:** How should the merge percentile parameter be chosen to balance explanation compactness and faithfulness, and can it be set automatically?
- **Basis in paper:** [inferred] The method relies on a user-defined merge percentile *p* to control cluster consolidation. The paper tested values {25, 50, 75, 95} and observed stable faithfulness but gave no guidance on selecting *p* for new datasets; the default *p*=95 was chosen ad hoc for visualization.
- **Why unresolved:** The optimal *p* may vary with dataset characteristics or model architecture, and leaving it to manual tuning hinders usability and reproducibility.
- **What evidence would resolve it:** An empirical analysis linking *p* to external quality metrics (e.g., human interpretability, cluster stability) or an automatic selection procedure (e.g., using validation-based criteria) that consistently yields high-quality explanations across diverse scenarios.

### Open Question 4
- **Question:** Can the computational overhead of LOMATCE’s event clustering be reduced to allow scaling to longer time series or larger neighbourhood samples?
- **Basis in paper:** [inferred] "A practical limitation of the proposed method arises from the clustering of parameterised event primitives within LOMATCE, which constitutes the most computationally demanding stage... there remains room for further improvement in the scalability and efficiency of event-level clustering, particularly for large-scale or resource-constrained settings." (Section 5)
- **Why unresolved:** The current hierarchical clustering on extracted events may become prohibitively slow for long series or many instances, limiting the method’s applicability to massive datasets.
- **What evidence would resolve it:** Development of more efficient clustering algorithms (e.g., approximate or incremental methods) and experimental results showing significant speed-ups with negligible loss in explanation fidelity on large-scale benchmarks.

## Limitations
- Incomplete LOMATCE implementation details (silhouette method, perturbation strategies) hinder exact replication.
- No human evaluation; interpretability is inferred from visual examples alone.
- Evaluation restricted to six univariate UCR datasets; no comparisons to other model-agnostic global methods and no testing on multivariate or longer series.

- Submodular instance selection: High
