# TRACE: Temporal Reasoning via Agentic Context Evolution for Streaming Electronic Health Records (EHRs)

## Quick Facts
- arXiv ID: 2602.12833
- Source URL: https://arxiv.org/abs/2602.12833
- Reference count: 16
- Primary result: Dual-memory agentic architecture improves next-event prediction Recall@5 by over 85% versus long-context baselines on MIMIC-IV, with >92% protocol adherence.

## Executive Summary
TRACE introduces a novel architecture to overcome large language models' inability to maintain reliable clinical reasoning over long, irregular streams of electronic health records. It replaces unbounded context windows with a dual-memory system: a static Global Protocol encoding institutional rules and a dynamic Individual Protocol tracking patient state. Four specialized agents (Router, Reasoner, Auditor, Steward) coordinate over this structured memory, while an offline Reflector induces improved rules from past failures. Evaluated on MIMIC-IV for next-event prediction, TRACE substantially outperforms long-context and RAG baselines across medication, lab, and procedure tasks, while maintaining high protocol adherence and bounded computational cost.

## Method Summary
The core method is a dual-memory, multi-agent framework. The Global Protocol stores fixed clinical guidelines and constraints. The Individual Protocol holds the evolving, structured representation of a patient's state. For each new EHR event, the Router assigns the task to the Reasoner, which updates the Individual Protocol and generates predictions. The Auditor checks adherence to the Global Protocol, flagging violations. The Steward manages memory, pruning or summarizing state to bound size. An offline Reflector analyzes flagged failures to induce new rules, which update the Global Protocol. This structure explicitly separates immutable institutional knowledge from mutable patient-specific state, and uses conditional auditing to limit overhead.

## Key Results
- Next-event prediction Recall@5 shows large gains: medications (0.5986 vs. 0.3192), lab orders (0.4176 vs. 0.2119), procedures (0.4184 vs. 0.3511) compared to long-context and RAG baselines.
- Clinical equivalence scores (rated against clinician judgments) range from 3.56 to 3.96 on a 5-point scale.
- Protocol adherence exceeds 92%, and conditional auditing activates on only 5–9% of processing steps, ensuring bounded inference cost.

## Why This Works (Mechanism)
TRACE works by enforcing a strict separation between static, institution-wide rules and dynamic, patient-specific state. This prevents the corruption of long-term memory by noisy, irregular EHR streams. The agentic coordination ensures that each processing step is validated against the Global Protocol, catching deviations early. The conditional auditing mechanism (Steward-triggered) provides a safety net without requiring exhaustive checking, keeping costs low. The offline Reflector creates a closed loop: failures in the Individual Protocol lead to new or refined Global Protocol rules, progressively hardening the system against repeat errors. This design directly addresses the core challenge of temporal consistency in streaming clinical data.

## Architecture Onboarding
Router -> Reasoner -> Auditor -> Steward; Reflector periodically updates Global & Individual Protocols.
Critical path: New EHR event -> Router assigns to Reasoner -> Reasoner updates Individual Protocol & predicts -> Auditor checks against Global Protocol -> Steward manages memory (prune/summarize) -> if violation, feed to Reflector for offline rule induction.
Design tradeoffs: Bounded context vs. comprehensive history (Steward's pruning may lose details); static global rules vs. adaptive learning (Reflector may introduce spurious rules); automated reasoning vs. human oversight (auditing is automated but low-coverage).
Failure signatures: (1) Auditor flags protocol violation, (2) Reasoner produces low-confidence prediction, (3) Steward triggers memory compression, (4) Reflector identifies recurring failure patterns.
First three experiments: (1) Ablate Global Protocol (use only Individual Protocol) and measure recall drop. (2) Replace structured Individual Protocol with raw EHR token stream and evaluate. (3) Run TRACE on a non-ICU dataset (e.g., outpatient records) to test generalizability.

## Limitations
- Generalizability: Evaluation is limited to MIMIC-IV (single US ICU dataset); performance on other settings is unknown.
- Clinical Impact: Improvements in recall and equivalence scores lack direct evidence of effect on patient outcomes or clinician workflow.
- Auditing Trade-off: Low activation rate (5–9%) raises questions about false negative rate within the audited subset and what critical errors might be missed.

## Confidence
- Architectural Design & Mechanism: High.
- Performance on MIMIC-IV: Medium (strong results but single-benchmark).
- Protocol Adherence & Cost: Medium (specific to experimental setup; real-world scalability untested).
- Clinical Equivalence Scores: Medium-Low (evaluation details and rater reliability unspecified).
