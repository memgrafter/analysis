# Can AI Scientist Agents Learn from Lab-in-the-Loop Feedback? Evidence from Iterative Perturbation Discovery

## Quick Facts
- **arXiv ID:** 2603.26177  
- **Source URL:** https://arxiv.org/abs/2603.26177  
- **Reference count:** 40  
- **Primary result:** An LLM agent using in-context learning from experimental feedback (ICL-EF) achieves a +53.4% increase in perturbation discoveries per feature over zero-shot, but only when model capability (measured by hallucination rate) crosses a critical threshold.

## Executive Summary
This paper investigates whether large language models (LLMs) can genuinely adapt to laboratory feedback during iterative experimental design. Using 800 independent experiments across 10 Cell Painting features, the authors compare an LLM agent with in-context learning from feedback (ICL-EF) to a zero-shot baseline. ICL-EF yields a significant +53.4% increase in discoveries, but this effect emerges only after upgrading from Claude Sonnet 4.5 to 4.6, which reduces gene hallucination from ~33–45% to ~3–9%. A random feedback control eliminates the improvement, proving the gain depends on structured feedback content rather than prompt artifacts. The study concludes that effective in-context learning from lab feedback requires a baseline level of model capability and demonstrates that advanced agents can perform phenotypic state inference to discover convergently acting genes across disjoint pathways.

## Method Summary
The task is iterative perturbation discovery: over 10 iterations, an agent selects 100 genes per batch to test on a target CellProfiler feature, aiming to maximize p-value hits (p < 0.05). The dataset is the JUMP Cell Painting CRISPR perturbation screen (~7,975 genes, 4,672 features). Agent variants include: Zero-shot (no feedback), ICL-EF (receives binary hit/miss history plus top gene-prefix hints), ICBR-EF (adds phenotypic fingerprints and a persistent JSON hypothesis register), and Random Feedback (ICL-EF with permuted labels). Experiments are run with Claude Sonnet 4.5 and 4.6, with 10 replicates per feature per condition (800 total). Performance is measured by cumulative unique discoveries, analyzed via paired sign-flip permutation tests with FDR correction.

## Key Results
- ICL-EF outperforms zero-shot by +53.4% in discoveries per feature (p=0.003).
- Model capability is critical: Sonnet 4.5 shows no significant ICL effect (mean +1.7, 99% CI [-1.35,+5.64]), while Sonnet 4.6 shows a large effect (mean +8.9, 99% CI [+4.43,+15.29]).
- Random feedback control performs at or below zero-shot and is significantly worse than true ICL-EF (e.g., 18.4 vs. 29.3 hits, p=0.003), confirming learning comes from feedback content.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Sufficient model capability (low hallucination, strong instruction-following) is a prerequisite for effective in-context learning from experimental feedback.
- **Mechanism:** Capable models can reliably constrain outputs to the provided gene library, execute multi-step biological reasoning, and update strategies based on feedback patterns. Lower-capability models hallucinate invalid genes, wasting budget and preventing coherent strategy formation.
- **Core assumption:** The model upgrade (Sonnet 4.5→4.6) improves multiple capabilities simultaneously (instruction adherence, reasoning, world knowledge), but the ICL effect manifests only when hallucination drops below a threshold that allows the agent to act on its reasoning.
- **Evidence anchors:**  
  abstract: "Upgrading from Claude Sonnet 4.5 to 4.6 reduces gene hallucination rates from ∼33%–45% to ∼3–9%, converting a non-significant ICL effect (+0.8, p=0.32) into a large and highly significant improvement (+11.0, p=0.003)."  
  section 4.4: Sonnet 4.5's ICL effect is non-significant (mean +1.7, 99% CI [-1.35,+5.64]) while 4.6's is large and significant (mean +8.9, 99% CI [+4.43,+15.29]).
- **Break condition:** If hallucination rate remains persistently high (>30%), the ICL effect will not emerge regardless of feedback structure, as the agent cannot reliably propose valid genes to test.

### Mechanism 2
- **Claim:** The performance gain arises from genuine sensitivity to the *content* of experimental feedback (hit/miss labels linked to specific genes), not from spurious cues like prompt length or static prior knowledge.
- **Mechanism:** The agent forms and updates search strategies by detecting patterns in the feedback—e.g., "gene family X contains multiple hits" or "genes with phenotype Y succeed"—and adjusts subsequent selections accordingly. Random permutation of feedback labels destroys these correlations, leading to misplaced exploitation and worse performance than no feedback.
- **Core assumption:** If improvements were due to recall of pretraining knowledge alone, a randomly permuted feedback prompt (with same length and structure) should yield similar gains, as the agent would ignore labels and fall back on priors.
- **Evidence anchors:**  
  abstract: "To test whether this improvement arises from genuine feedback-driven learning rather than prompt-induced recall of pretraining knowledge, we introduce a random feedback control... Under this control, the performance gain disappears."  
  section 4.6: Random FB agent discovers 18.4 hits vs. zero-shot's 20.4 (difference -2.0, p=0.15), while true ICL-EF discovers 29.3 (+10.9 over Random FB, p=0.003). Random feedback actively harms performance on hardest features.
- **Break condition:** If random feedback control consistently matches or exceeds the true feedback agent's performance, the learning is not driven by feedback content.

### Mechanism 3
- **Claim:** Advanced agents (ICBR-EF) achieve superior performance by performing phenotypic state inference and maintaining a persistent hypothesis register, enabling jumps across disjoint biological pathways that share morphological signatures.
- **Mechanism:** The agent receives multi-dimensional phenotypic fingerprints (top co-affected CellProfiler features) for each tested gene. It clusters hits by these phenotypic signatures rather than by gene name/family, discovering that genes from different pathways (e.g., DNA repair, cyclins, mitotic kinases) converge on the same cellular state (e.g., mitotic arrest). The hypothesis register tracks mechanistic beliefs across iterations, preventing drift and enabling systematic space closure.
- **Core assumption:** Morphological phenotypes in Cell Painting capture underlying cellular states that transcend individual gene families, and an LLM can infer these states from the feature co-occurrence data.
- **Evidence anchors:**  
  section 4.5: "The ICBR-EF agent recognized that hits spanning disjoint functional pathways... all produced identical perturbations in 'angular second moment' and 'nuclear texture.' The agent correctly deduced these diverse targets converged on the same underlying physiological state: mitotic arrest."  
  section 4.5: "The ICBR-EF agent, by contrast, carries forward a structured hypotheses register across iterations, explicitly tracking the lifecycle of its theories... This persistent reasoning scaffold prevents interpretive drift."
- **Break condition:** If the target phenotype lacks multi-dimensional morphological features with strong co-occurrence patterns, or if the model cannot reliably interpret the feature space, phenotypic clustering will not yield additional discoveries over name-based exploitation (ICL-EF).

## Foundational Learning
- **Concept: In-Context Learning (ICL)**  
  *Why needed here:* The entire premise tests whether LLMs can use the experimental history provided in the prompt to adapt their future selections. Understanding that ICL is ephemeral (per-session) and distinct from weight updates is key to interpreting the results.  
  *Quick check question:* If the model's behavior changes based on the specific hit/miss labels in the prompt, what does that imply about where learning occurs?

- **Concept: Gene Family & Pathway Exploitation**  
  *Why needed here:* The ICL-EF agent's primary strategy is to identify enriched gene families/prefixes from hits and exhaustively test remaining members. This is a core biological heuristic that leverages the dataset's correlation structure.  
  *Quick check question:* Why does exploiting a discovered hit in a gene complex (e.g., SWI/SNF) yield many more hits than random sampling from that complex?

- **Concept: Phenotypic Clustering vs. Nominal Clustering**  
  *Why needed here:* ICBR-EF moves beyond name-based (nominal) clustering to group genes by their multi-dimensional morphological effect signatures. This is the key innovation allowing pathway-agnostic discovery.  
  *Quick check question:* How can two genes with completely different names and known functions be considered "similar" for the purpose of experimental design in this framework?

## Architecture Onboarding
- **Component map:**  
  LLM Core -> Feedback Buffer -> Prompt Composer -> Output Parser & Validator -> Experimental Simulator  
  (ICBR-EF adds: Phenotypic Fingerprint Extractor -> Hypothesis Register, with register updates feeding back into Prompt Composer)

- **Critical path (per iteration):**  
  1. Fetch untested gene pool.  
  2. Compose prompt: include full history (and phenotypic data/register if ICBR-EF).  
  3. Call LLM API.  
  4. Parse output → candidate gene list.  
  5. Validate: Check all genes exist in untested pool. If any invalid, trigger fallback (e.g., re-prompt, sample random valid genes).  
  6. Execute: get outcomes (p-value, features) from simulator.  
  7. Update Feedback Buffer.  
  8. (ICBR-EF only) LLM updates hypothesis register based on new outcomes.  
  9. Loop to next iteration.

- **Design tradeoffs:**  
  - Context length vs. history depth: Longer campaigns exhaust context windows. Mitigation: summarize history or use retrieval, but may lose nuance.  
  - Phenotypic fingerprint detail: More co-affected features improve clustering but increase token cost; paper uses top-5 or top-10.  
  - Hypothesis register complexity: More entries increase parsing difficulty and token usage; modest gains (+2.1 discoveries) suggest diminishing returns.  
  - Fallback strategy: Critical for low-capability models; simple switch to sampling from most frequent successful prefix families.

- **Failure signatures:**  
  - High hallucination rate (>30%): Model ignores untested gene list. Mitigation: strengthen validation prompt, add few-shot examples, lower temperature.  
  - Flat learning curve: ICL agent's discoveries parallel zero-shot. Check: are hit rates by family actually enriched?  
  - Rapid early exhaustion: Agent finds 1-2 family anchors and tests all members, then plateaus (often a success for efficient exploitation, but may indicate lack of phenotypic pivot ability).  
  - Random FB underperforms zero-shot: Indicates agent is actively misled by false positives ("misplaced obstinacy"), confirming sensitivity to feedback content.

- **First 3 experiments:**  
  1. **Sanity check model capability:** Run 10 iterations of zero-shot and ICL-EF on a single feature with Sonnet 4.5. Expected: minimal ICL gain, high hallucination. Repeat with 4.6. Expected: clear ICL gain, low hallucination.  
  2. **Validate random feedback control:** Run ICL-EF vs. Random FB on 3 features (2 easy, 1 hard). Expected: Random FB ≤ zero-shot (or worse), ICL-EF >> Random FB.  
  3. **Test phenotypic clustering value:** Compare ICL-EF vs. ICBR-EF on 1 feature with strong gene-family structure. Expected: small ICBR-EF advantage. Then test on 1 feature where known hits span multiple pathways. Expected: larger ICBR-EF advantage if phenotypic convergence exists.

## Open Questions the Paper Calls Out
- **How robust is ICL to experimental noise and delayed feedback?**  
  *Basis:* Explicitly stated as an open question.  
  *Why unresolved:* Study used clean, binary feedback from precomputed p-values; real experiments involve batch effects, measurement noise, and variable hit rates.

- **Do these findings generalize to other experimental domains, open-source models, and noisier feedback settings?**  
  *Basis:* Explicitly stated as an open question.  
  *Why unresolved:* Evaluation restricted to two proprietary Claude models on a single assay; unclear if results hold for other biological screens, open-source LLMs, or different feedback regimes.

- **Can reinforcement learning agents achieve superior performance and transferability compared to pure ICL agents for iterative perturbation design?**  
  *Basis:* Explicitly stated as a future direction.  
  *Why unresolved:* ICL learning is ephemeral and limited by context window; RL could enable permanent weight updates and better exploration-exploitation trade-offs but remains untested.

- **How does the pure ICL approach compare to the hybrid LLMNN method proposed by Gupta et al.?**  
  *Basis:* Explicitly stated as a left-for-future comparison.  
  *Why unresolved:* LLMNN delegates iterative updates to a nearest-neighbor algorithm while using the LLM only for initialization; unclear which approach is more effective under different model capabilities and dataset structures.

## Limitations
- Exact feature mapping (F0–F90) and dataset filtering not disclosed, hindering precise replication.
- GP-UCB hyperparameters (kernel, exploration constant, likelihood) omitted, leaving baseline performance uncertain.
- Generalizability limited to a single biological domain (Cell Painting); validity for other assays is unknown.

## Confidence
- **Capability threshold:** High – Direct model comparison shows hallucination drop and ICL emergence.
- **Feedback content sensitivity:** High – Random-feedback control eliminates improvement.
- **Phenotypic clustering advantage:** Medium – Positive but small effect; needs cross-dataset validation.

## Next Checks
1. **Cross-dataset replication:** Run agents on an independent perturbation dataset (e.g., LINCS L1000) to test generalizability of the capability threshold and clustering mechanisms.
2. **Hypothesis register ablation:** Remove the persistent register in ICBR-EF and compare performance to isolate its contribution.
3. **GP-UCB robustness sweep:** Re-implement GP-UCB with varied exploration constants and kernel preprocessing to ensure the reported baseline is not artificially weak.
