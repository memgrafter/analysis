# Escaping Offline Pessimism: Vector-Field Reward Shaping for Safe Frontier Exploration
## Quick Facts
- **arXiv ID**: 2603.18326  
- **Source URL**: https://arxiv.org/abs/2603.18326  
- **Reference count**: 20  
- **Primary result**: Vector-field reward shaping enables safe frontier exploration in offline RL by preventing degenerate parking and sustaining boundary traversal while maintaining low unsafe transition rates.

## Executive Summary
Offline reinforcement learning (RL) typically suffers from pessimism, causing agents to avoid uncertain regions and miss opportunities for safe online data collection. This paper introduces a novel vector-field reward shaping approach that combines gradient alignment (attracting the agent toward a target uncertainty level) and rotational flow (promoting motion along the uncertainty boundary). Theoretical analysis guarantees that this combination prevents the agent from parking at a single point and instead induces sustained traversal of the uncertainty frontier. Empirical validation in a 2D continuous navigation task shows that the agent explores the uncertainty boundary effectively while still completing the primary goal. Compared to a state-based baseline, the method achieves broader coverage of the state manifold with continuous orbital motion and keeps unsafe transitions at a low rate.

## Method Summary
The task is a 2D navigation problem where an agent starts at the bottom-left corner and must reach the top-right goal. An uncertainty oracle models simulator unreliability as a Gaussian function \(U(s)=A \exp(-||s-c||^2/(2\sigma^2))\). The target exploration manifold is the set of states where uncertainty equals a chosen level \(U_{\text{mid}}\). The agent receives a task reward: dense progress (scaled negative distance change), a small step penalty, and a large goal bonus. The additional exploration reward is a vector field defined as \(r'(s,a,s') = \alpha(s) \langle \nabla U(s), \Delta s \rangle + \beta(s) \langle W \nabla U(s), \Delta s \rangle\), where \(\Delta s = s' - s\), \(W = \begin{bmatrix}0 & 1 \\ -1 & 0\end{bmatrix}\) provides a 90° rotation, \(\alpha(s)=\text{sign}(U_{\text{mid}}-U(s))\tanh(|U(s)-U_{\text{mid}}|)\) governs radial attraction/repulsion, and \(\beta(s)=1-|\tanh(U(s)-U_{\text{mid}})|\) controls rotational strength. The total reward is the sum of task and exploration components. The agent is trained offline using Soft Actor-Critic (SAC) with a Normalizing Flow actor (32–64 blocks) and MLP critics. Hyperparameters: actor learning rate \(1\mathrm{e}{-6}\), critic learning rate \(5\mathrm{e}{-4}\), batch size 256, discount \(\gamma=0.99\), target smoothing \(\tau=1\mathrm{e}{-4}\). After offline training, the policy is frozen and evaluated on its ability to explore the uncertainty frontier while achieving the goal.

## Key Results
- The vector-field reward theoretically and empirically prevents degenerate parking and induces sustained boundary traversal.
- Compared to a state-based baseline, the agent achieves broader manifold coverage with continuous orbital motion.
- The method maintains a low unsafe transition rate (few steps where uncertainty exceeds the threshold).

## Why This Works (Mechanism)
The gradient alignment term \(\alpha\langle \nabla U, \Delta s \rangle\) exerts a force that moves the agent toward or away from the center of the Gaussian, depending on whether the current uncertainty is below or above \(U_{\text{mid}}\). This radial component pulls the agent toward the desired uncertainty level. The rotational term \(\beta\langle W\nabla U, \Delta s \rangle\) is orthogonal to the gradient and thus tangent to the uncertainty contour; it acts like a “vortex” that encourages motion along the boundary. Together, these terms create a vector field that has no stable fixed points on the target manifold (except possibly on the boundary itself), which theoretically rules out parking. Instead, the agent is compelled to circulate around the uncertainty region while being confined to a narrow band around \(U_{\text{mid}}\). This sustained tangential exploration allows the agent to gather information across the entire frontier without repeatedly visiting the same points, addressing the pessimism problem in offline RL. The theoretical analysis supports these properties, and the empirical results confirm their realization in the 2D navigation task.

## Architecture Onboarding
### Component Map
State \(s\) → Gaussian Uncertainty Oracle → \(U(s)\), \(\nabla U(s)\)  
Action \(a\) (from Actor: Normalizing Flow) → Environment → Next state \(s'\)  
Compute \(\Delta s\), \(\alpha(s)\), \(\beta(s)\) → Vector‑field reward \(r'\)  
Combine with task reward \(r_{\text{task}}\) → Total \(r\)  
Store \((s,a,r,s')\) in Replay Buffer  
SAC updates: Critic networks (MLP) minimize Bellman error; Actor (NF) maximizes \(Q\) plus entropy; Target networks soft update.

### Critical Path
1. Sample minibatch from replay buffer.  
2. Compute target Q-values using next‑state critics and entropy term.  
3. Update critic parameters by gradient descent on MSE loss.  
4. Update actor parameters by gradient ascent on \(\mathbb{E}[Q(s,\pi(s)) - \alpha \log \pi(s)]\).  
5. Periodically update target critic networks.

### Design Tradeoffs
- **α/β scaling**: Non‑linear \(\tanh\) functions balance radial vs. rotational forces; overly large \(\alpha\) may push agent off the manifold, while small \(\beta\) fails to generate tangential motion.  
- **Normalizing Flow complexity**: More blocks increase expressivity but require careful tuning and computational cost.  
- **Goal vs. exploration reward weighting**: If the exploration reward dominates, the agent may neglect the primary objective; if too weak, it may not overcome pessimism.  
- **Offline-only training**: No environment interaction after policy collection simplifies deployment but limits adaptation to new dynamics.

### Failure Signatures
- **Parking**: State visitation plot shows a tight cluster at a single point on \(U = U_{\text{mid}}\) instead of a continuous band.  
- **Excessive unsafe transitions**: High fraction of steps where \(U(s')\) significantly exceeds \(U_{\text{mid}}\) (e.g., > threshold).  
- **No tangential motion**: Low average speed along the uncertainty contour (measured by projecting \(\Delta s\) onto the tangent direction) despite successful radial positioning.

### First Experiments
1. **Environment Verification**: Implement the 2D world, compute \(U(s)\) and \(\nabla U(s)\) analytically, and visualize uncertainty contours to ensure correctness.  
2. **Ablation Study**: Train agents with only the gradient term (\(\beta=0\)) and only the rotational term (\(\alpha=0\)) separately; quantify parking incidence and coverage compared to the full method.  
3. **Baseline Comparison**: Implement a standard uncertainty‑based intrinsic reward (e.g., \(-U(s)\) or prediction error) using identical SAC and Normalizing Flow hyperparameters; compare state‑visitation coverage, tangential speed, and unsafe transition rate directly.

## Limitations
- The exact Gaussian uncertainty parameters (amplitude \(A\), center \(c\), scale \(\sigma\)) and the target level \(U_{\text{mid}}\) are not specified, preventing exact replication of the experimental setup.

- Training details such as number of SGD steps, number of evaluation episodes, and the time‑embedding mechanism for goal‑directed exploration are missing.
