# FastBUS: A Fast Bayesian Framework for Unified Weakly-Supervised Learning

## Quick Facts
- arXiv ID: 2603.00517
- Source URL: https://arxiv.org/abs/2603.00517
- Reference count: 40
- Primary result: FastBUS achieves state-of-the-art results in weakly-supervised learning with up to 480x speedup

## Executive Summary
FastBUS addresses the fundamental challenge of inferring true label distributions from imprecise labels in weakly-supervised learning scenarios. The framework compresses diverse weakly supervised DFS tree structures into a shared Bayesian network, expressing the brute-force search process as a probabilistic transition of label variables. By introducing low-rank matrix approximation and an end-to-end state evolution module, FastBUS achieves dramatic computational acceleration while maintaining or improving accuracy across multiple weakly supervised learning settings.

## Method Summary
FastBUS transforms the problem of weakly-supervised learning by modeling label inference as a probabilistic transition process within a Bayesian network. The framework employs two key acceleration strategies: low-rank matrix approximation to reduce computational complexity, and an end-to-end state evolution module that enables batch processing of label transitions. This unified approach handles various forms of weak supervision including noisy labels, semi-supervised data, and multi-instance scenarios through a shared probabilistic framework.

## Key Results
- Achieves state-of-the-art performance across most weakly supervised learning settings
- Provides up to hundreds of times faster acceleration compared to general methods
- Demonstrates up to 480x speedup in multi-instance learning scenarios

## Why This Works (Mechanism)
FastBUS works by fundamentally reframing weakly-supervised learning as a probabilistic inference problem rather than a deterministic optimization task. By expressing label transitions as probabilistic operations within a Bayesian network, the framework can leverage efficient inference techniques while naturally handling uncertainty in the labels. The low-rank matrix approximation reduces the dimensionality of the problem space, making computations tractable even for large datasets. The state evolution module enables parallel processing of multiple label transitions, dramatically reducing wall-clock time while preserving the statistical properties of the inference process.

- Critical path: Data preprocessing → Network initialization → Iterative inference → Final label prediction
- Design tradeoffs: Accuracy vs. speed (low-rank approximation may lose some information but enables faster computation)
- Failure signatures: Poor approximation rank leading to degraded accuracy; convergence issues in state evolution
