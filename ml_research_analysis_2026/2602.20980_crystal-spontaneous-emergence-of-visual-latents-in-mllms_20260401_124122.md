# CrystaL: Spontaneous Emergence of Visual Latents in MLLMs
## Quick Facts
- arXiv ID: 2602.20980
- Source URL: https://arxiv.org/abs/2602.20980
- Reference count: 22
- Primary result: Achieves state-of-the-art on perception benchmarks (76.6% 2D CVBench, 84.4% 3D CVBench), surpassing Qwen2.5-VL-7B by 4.3% average with only 16k training samples.

## Executive Summary
CrystaL introduces a single-stage, self-supervised framework for Multimodal Large Language Models (MLLMs) that aligns supervision signals with latent reasoning states. It uses a dual-path architecture: an intact path processes pristine images, while a corrupted path processes degraded images. Latent states from the intact path are copied into the corrupted path, and consistency is enforced via KL divergence on output distributions and Frobenius norm on attention maps. This mechanism forces visual latent tokens to encode robust, task-relevant semantics without external modules or annotations. On perception-intensive benchmarks (CVBench, HRBench, VStarBench, POPE), CrystaL achieves state-of-the-art results, notably 76.6% on 2D CVBench and 84.4% on 3D CVBench, outperforming baselines like Qwen2.5-VL-7B by an average of 4.3%. It also demonstrates superior data efficiency, reaching peak performance with only 16k training samples.

## Method Summary
CrystaL modifies a base MLLM (e.g., Qwen2.5-VL) by adding a dual-path forward pass and a corruption module. The input image is degraded via Stochastic Image Corruption (SIC) into a corrupted version. During training, the model processes both images in parallel through the LLM. Hidden states of designated visual latent tokens from the intact path are copied into the corresponding positions of the corrupted path. The total loss combines: (1) cross-entropy on answer tokens for both paths, (2) KL divergence between their output distributions (predictive consistency), and (3) Frobenius norm between attention maps from answer tokens to latent tokens (mechanistic consistency). This self-supervised approach directly supervises latent representations to be semantically robust and functionally indispensable for correct prediction, all in a single training stage with LoRA.

## Key Results
- State-of-the-art on CVBench: 76.6% (2D) and 84.4% (3D).
- Average 4.3% improvement over Qwen2.5-VL-7B across perception benchmarks (HRBench, VStarBench, POPE, etc.).
- Superior data efficiency: achieves top performance with only 16k training samples.

## Why This Works (Mechanism)
### Mechanism 1: Bottleneck by Design
The dual-path architecture creates a functional bottleneck: the corrupted path receives degraded images but relies on latent tokens copied from the intact path. To generate correct answers, the corrupted path must depend on these borrowed latent states, forcing them to encode robust, semantically rich visual features that compensate for input corruption. Evidence: latent copy operation (Sec 3.3), ablation showing Gaussian blur (moderate corruption) works best (Tab 5).

### Mechanism 2: Latent State Alignment
By overwriting the autoregressive hidden states of visual latent tokens in the corrupted path with those from the intact path, the model directly injects clean visual semantics into the corrupted stream. The subsequent transformer layers and next-token prediction loss then supervise these latents to steer generation correctly despite the poor input. Evidence: explicit copy in Fig 3, loss formulation `L_cor^ce` encouraging reliance on visual latents (Sec 3.4).

### Mechanism 3: Consistency Regularization
KL divergence loss (`L_kl`) aligns output distributions across paths, while attention alignment loss (`L_attn`) minimizes the Frobenius norm between answer-to-latent attention maps. These consistency losses "crystallize" latent representations by ensuring both paths exhibit similar predictive behavior and reasoning patterns (i.e., attending to the same latent features). This pushes latents to encode invariant, task-critical semantics. Evidence: loss definitions (Sec 3.4), ablation showing both losses are necessary and that "Answer to Latents" alignment outperforms "Answer to All" (Tab 4).

## Architecture Onboarding
- **Component map:** Base MLLM -> Stochastic Image Corruption Module -> Dual-Path Forward Manager -> Latent State Copy Hook -> Loss Calculator
- **Critical path:** Input image -> SIC generates `I_cor` -> Two parallel forward passes: (1) Intact path on `I` stores latent states `T_lat`; (2) Corrupted path on `I_cor` copies `T_lat` into visual token positions -> Compute losses (`L_int_ce`, `L_cor_ce`, `L_kl`, `L_attn`) -> Backpropagate total loss.
- **Design tradeoffs:**
  - Corruption severity: Too extreme (e.g., large mask) destroys recoverable signal; too mild (e.g., slight blur) doesn't force latent reliance. Gaussian blur optimally balances suppression and preservation.
  - Latent token count: More tokens increase capacity but risk dilution or overfitting; 8 tokens optimal in experiments.
  - Loss weighting: λ_kl and λ_attn are hyperparameters; overweighting consistency may harm generation quality or cause instability.
  - Copy layer selection: Copying at which decoder layers affects how early/late clean latents are injected into the corrupted stream.
- **Failure signatures:**
  - Corrupted path loss (`L_cor_ce`) close to intact path loss: latent copying ignored; corruption too mild or token design malconfigured.
  - Attention alignment loss (`L_attn`) dominates or fails to converge: unstable training; verify attention map similarity visually.
  - No gain on perception benchmarks: ablate loss components; expected full combination best.
  - Performance drop on non-perception tasks: reduce λ weights or increase `L_int_ce` weight to preserve general capabilities.
- **First 3 experiments:**
  1. Corruption type ablation: Implement each SIC primitive (Gaussian blur, random mask, jigsaw, noise, color distortion) and measure on CVBench/HRBench. Expect Gaussian blur to yield highest accuracy per Table 5.
  2. Latent token quantity/diversity test: Vary number of visual latent tokens (4, 8, 16) and whether they are identically or diversely initialized. Expect 8 diverse tokens to perform best per Table 3.
  3. Loss component ablation: Train with combinations: only `L_int_ce + L_cor_ce`, plus `L_kl`, plus `L_attn`, and all together. Expect the full combination to score highest, and removing either consistency loss to degrade significantly per Table 4.

## Open Questions the Paper Calls Out
### Open Question 1
Why does Gaussian blur consistently outperform alternative corruption strategies? The paper hypothesizes that spatial perturbations (masking, jigsaw) introduce edge artifacts causing feature distribution shifts, whereas blur better balances information suppression with semantic preservation. However, this remains a qualitative assertion without quantitative analysis of feature distributions or semantic preservation metrics. Resolution requires systematic comparison of corrupted feature statistics and correlation with downstream performance.

### Open Question 2
Why does restricting attention alignment to answer-token queries and latent-token keys ("Answer to Latents") yield superior performance compared to aligning answer tokens to all tokens ("Answer to All")? Table 4 shows "Answer to All" achieves lower accuracy. The paper documents the finding but offers no analysis of whether answer-to-image attention is already sufficiently aligned or whether aligning it introduces noise. Resolution requires comparative analysis of attention distribution entropy and correlation between alignment loss reduction and accuracy gains.

### Open Question 3
What explains the non-monotonic performance relationship with the number of latent tokens, where 8 tokens are optimal but both fewer (4) and more (16) tokens degrade performance? Table 3 shows this pattern clearly. The paper acknowledges the phenomenon but investigates neither the capacity-interference trade-off nor optimization dynamics. Potential causes like representational redundancy or gradient interference remain speculative. Resolution requires analyzing gradient norms, representational similarity among tokens, and scaling experiments with model size.

### Open Question 4
What specific visual semantics or invariances do the emergent latent tokens encode that enable recovery from corrupted inputs? The paper claims latents "crystallize" into "task-relevant visual semantics" but provides no analysis of actual content. The information structure and attributes (shape, texture, spatial relations) preserved in latent tokens remain opaque. Resolution requires probing studies, attention-based visualization mapping latents to image regions, and controlled corruption experiments targeting specific visual features.

## Limitations
- Unspecified corruption parameters: exact Gaussian blur radius, sampling schedule, and full SIC configurations beyond blur are not detailed.
- Vague architecture details: precise number/position of visual latent tokens and which decoder layers (`L_sub`) for attention alignment are not specified.
- Missing loss weights: hyperparameters λ_kl and λ_attn and any annealing strategy are not provided.
- Lack of interpretability: no analysis of what specific semantics or invariances the latent tokens actually encode.
