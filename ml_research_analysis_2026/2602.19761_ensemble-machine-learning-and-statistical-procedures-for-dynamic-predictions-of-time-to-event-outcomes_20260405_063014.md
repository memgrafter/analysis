# Ensemble Machine Learning and Statistical Procedures for Dynamic Predictions of Time-to-Event Outcomes

## Quick Facts
- arXiv ID: 2602.19761
- Source URL: https://arxiv.org/abs/2602.19761
- Reference count: 40
- Primary result: The ensemble achieved equal or better predictive accuracy than any individual base learner, with time-dependent weights optimizing performance across different prediction windows.

## Executive Summary
This study extends the Super Learner ensemble framework to dynamic predictions of time-to-event outcomes with longitudinal data. By combining predictions from diverse base learners (joint models, landmarking, machine learning) using time-dependent weights optimized via cross-validation and appropriate loss functions (Brier Score, integrated Brier Score, time-varying AUC) with inverse probability of censoring weighting (IPCW), the method addresses the lack of a universally superior dynamic prediction model. Applied to primary biliary cholangitis patient data, the ensemble matched or exceeded the accuracy of all individual base learners. A simulation confirmed the oracle property, though informative censoring was found to bias performance metrics.

## Method Summary
The method builds a diverse library of base learners for dynamic prediction: joint models (via JMbayes2), landmarking models (one-stage and two-stage Cox models, including boosted variants via mboost), each producing survival probabilities π(u|t) for a landmark t and future time u. Cross-validation (V-fold, stratified by event) generates out-of-sample predictions for each base learner. For each prediction window, ensemble weights are optimized by minimizing a chosen loss function (Brier Score, integrated Brier Score, or time-varying AUC) with IPCW correction for censoring, under constraints that weights are nonnegative and sum to one. After weight estimation, all base learners are refitted on the full training set, and final predictions are the weighted combination. The approach is evaluated on a held-out test set using the same IPCW-weighted metrics.

## Key Results
- The ensemble (eSL) achieved equal or better predictive accuracy than any individual base learner on Brier Score, integrated Brier Score, and time-varying AUC in the PBC dataset.
- Weights were time-dependent: for later prediction windows, models with more flexible longitudinal components (e.g., spline-based) received higher weights, while earlier windows favored simpler landmark models.
- Simulation studies verified the oracle property: as sample size increased, eSL performance approached that of the best base learner (oracle). However, when censoring depended on longitudinal biomarkers (informative censoring), Brier Score inflated and time-varying AUC deflated, exposing a limitation of Kaplan-Meier IPCW.

## Why This Works (Mechanism)
### Mechanism 1: Ensemble diversity reduces model selection risk
The Super Learner combines predictions from a diverse library of base learners (joint models, landmarking, machine learning) using V-fold cross-validation to estimate out-of-sample performance and optimize convex weights under a chosen loss function. This ensures the ensemble's prediction lies within the convex hull of base learner predictions, approximating the optimal model as long as the library contains a sufficiently good learner and the loss is appropriate. The oracle property guarantees that, asymptotically, the ensemble matches the best possible base learner. Evidence includes abstract results showing equal or better accuracy, and theoretical literature on Super Learner. Limitations arise if the library is narrow or base learners are highly correlated; also, small sample sizes may cause weight instability.

### Mechanism 2: Time-dependent weighting adapts to prediction horizon
The relative performance of base learners changes with the prediction window (landmark t and horizon u). Super Learner estimates separate weights for each window by recomputing cross-validated predictions and re-optimizing the loss. This allows models that excel in short-term predictions to be upweighted early, while those better for long-term predictions gain weight later. Evidence: Table 1 in the paper shows weight shifts between windows {6,9} and {9,12} (e.g., weight for M8 increases from 0% to 100% under IBS). The approach is supported by related work on dynamic Super Learning. Break conditions: very short windows with few events cause unstable weights; if the best model is constant across time, time-dependence adds noise.

### Mechanism 3: Inverse probability of censoring weighting (IPCW) corrects loss estimation
Right-censoring complicates evaluation of survival predictions. IPCW weights each subject by the inverse probability of not being censored before the prediction window, estimated via Kaplan-Meier under the assumption of non-informative censoring. This yields an unbiased estimate of the loss function (e.g., Brier Score) as if all outcomes were fully observed. The paper explicitly uses IPCW in equations and demonstrates via simulation that when censoring is informative (dependent on longitudinal biomarkers), the Kaplan-Meier IPCW fails, inflating Brier Score and deflating AUC. Thus, IPCW is essential but relies on the non-informative censoring assumption.

## Architecture Onboarding
Component map: Data input (longitudinal biomarkers, baseline covariates, survival outcome) -> Base learner library (joint models, landmarking models, boosted models) -> Cross-validation module (V-fold splits, stratified by event) -> Meta-optimizer (weight optimization per prediction window using loss function with IPCW) -> Prediction module (refit on full training, combine predictions) -> Evaluation module (test set metrics with IPCW)

Critical path:
1. Define prediction windows (e.g., {6,9}, {9,12}) and identify risk sets at each landmark t.
2. For each CV fold v: train all base learners on V-1 folds, predict survival probabilities for subjects at risk in the held-out fold.
3. Compute IPCW weights for each subject in the held-out fold based on censoring distribution estimated from training folds.
4. Optimize ensemble weights for the window by minimizing the chosen loss function (or select best single model for discrete SL), subject to non-negativity and sum-to-one constraints.
5. After cross-validation, refit all base learners on the full training dataset.
6. For the test set, compute final predictions as the weighted combination of the refitted base learners.
7. Evaluate predictive accuracy on the test set using the same loss functions with IPCW.

Design tradeoffs:
- Library diversity vs. computational cost: Adding more base learners (especially joint models) increases chances of including a good model but amplifies computational burden, as joint models are slow to fit.
- Number of folds V: Higher V reduces bias in weight estimates but may lead to unstable loss estimates if events per fold are too few; stratification helps ensure enough events.
- Loss function choice: Brier Score balances discrimination and calibration; tv-AUC focuses on discrimination but may have convergence issues; IBS averages error over the interval but may dilute censoring effects.
- Time window granularity: More windows allow finer adaptation but reduce data per window for weight estimation.
- Discretized vs. continuous time: The paper uses continuous time; discretizing simplifies computation but loses precision.

Failure signatures:
- Non-convergence during weight optimization, especially for tv-AUC (observed 12% failure rate in the PBC analysis). Remedies: run optimization multiple times with different starting values.
- Extreme weights (one model gets ~1): may indicate insufficient diversity or one model is overwhelmingly best; consider removing redundant models.
- Poor test performance relative to individual base learners: could indicate overfitting during weight estimation or library mismatch; try reducing library size or increasing CV folds.
- High variance in performance metrics across simulation replicates: suggests unstable weight estimation; may need more events per fold or simpler base learners.
- IPCW weights with high variability: if censoring distribution is hard to estimate (few censored observations), weights may be noisy; consider alternative censoring models.

First 3 experiments:
1. Reproduce PBC analysis: Implement the ensemble with the same library (9 base learners) on the Global PBC dataset. Verify that the eSL matches or exceeds the best base learner on Brier Score, IBS, and tv-AUC in the test set, and observe time-dependent weight shifts as in Table 1.
2. Simulation oracle check: Using the simulation design from Section 4 (no censoring), confirm that the eSL's performance approaches that of the oracle model (best base learner in test set) as the number of simulations increases, demonstrating the oracle property.
3. Censoring sensitivity: Replicate the three censoring scenarios (no censoring, random censoring, informative censoring) and measure the bias in Brier Score and tv-AUC when using Kaplan-Meier IPCW under informative censoring. This validates the need for proper censoring handling.

## Open Questions the Paper Calls Out
1. **Integration of discretized-time methods**: How can discretized-time dynamic prediction methods be effectively integrated into the continuous-time Super Learner framework without compromising predictive accuracy or introducing undue subjectivity? This is unresolved because discretization involves trade-offs like information loss and subjective interval width choices; empirical comparisons across datasets are needed.
2. **Loss functions for competing risks**: What loss functions or performance metrics are most appropriate for optimizing Super Learner ensembles in contexts with competing risks? Standard metrics (Brier Score, tv-AUC) are for single outcomes; extensions for competing risks (cause-specific or subdistribution-based) are not established, and it is unclear which would guide the ensemble to maximize clinically relevant accuracy across event types.
3. **Mitigating informative censoring bias**: What practical methods can mitigate bias in predictive performance estimates caused by informative censoring when using Super Learner? Current IPCW (Kaplan-Meier) assumes non-informative censoring; when censoring depends on longitudinal biomarkers, bias arises. Robust alternatives (e.g., model-based IPCW) have not been proposed or tested within the SL framework.
4. **Counterfactual prediction via Targeted Learning**: Can the Super Learner framework be extended to perform counterfactual prediction (e.g., "what-if" for interventions) using Targeted Learning? This would require a two-stage procedure (SL then targeted update) and assumptions like sequential exchangeability; the specific TMLE step for dynamic survival predictions remains undeveloped.

## Limitations
- Exact cross-validation fold assignments and random seeds for data splitting are unreported, preventing exact replication.
- Base learner hyperparameters and implementation details (e.g., mboost tree depth, JMbayes2 priors, MCMC settings) are not fully specified.
- IPCW using Kaplan-Meier fails under informative censoring, threatening validity when censoring depends on longitudinal biomarkers.
