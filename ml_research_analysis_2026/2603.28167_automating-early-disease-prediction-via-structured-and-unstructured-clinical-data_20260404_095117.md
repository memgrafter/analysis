# Automating Early Disease Prediction Via Structured and Unstructured Clinical Data

## Quick Facts
- **arXiv ID**: 2603.28167
- **Source URL**: https://arxiv.org/abs/2603.28167
- **Reference count**: 0
- **Primary result**: Enriching structured EHRs with NLP-extracted features from discharge reports doubled MCC (0.11→0.20) and increased accuracy (0.65→0.66) for AF progression prediction, outperforming clinical scores (~0.60 accuracy).

## Executive Summary
This study tackles the challenge of incomplete structured EHR data by introducing a fully automated pipeline that uses NLP to extract predictive features from unstructured Spanish discharge reports. Applied to predicting atrial fibrillation progression, the enriched dataset—combining text-derived and structured features—significantly improved model performance over using structured data alone and surpassed traditional clinical risk scores. The pipeline also automates cohort selection and outcome labeling, demonstrating that integrating unstructured clinical text can enhance data completeness and model reliability for early disease prediction.

## Method Summary
The pipeline consists of three core modules: R2V for processing discharge reports (section identification, entity recognition with negation, regex-based feature extraction), S2V for extracting identical features from structured EHR, and VectorMerger for combining both sources into patient-level vectors. AF progression labels are automatically generated by reconstructing AF history from reports. Models are trained using TabPFN on either the structured-only dataset or the enriched dataset with silver (automatic) or gold (manual) labels. Evaluation on a held-out test set compares performance metrics (accuracy, MCC) against clinical scores.

## Key Results
- Enriched models (structured + report features) achieved MCC 0.20 and accuracy 0.66, doubling MCC from the structured-only baseline (0.11, 0.65).
- Enriched models outperformed clinical scores (CHADS2-VASc, HATCH, APPLE), which had accuracies ~0.60 and MCCs near zero.
- Automatic labeling of AF progression from discharge reports showed 0.82 agreement with expert annotations.

## Why This Works (Mechanism)
The pipeline addresses missing data in structured EHRs by extracting complementary information from unstructured discharge reports. Clinical details often documented narratively (e.g., exam findings, symptom descriptions) are not captured in codified fields. NLP extraction fills these gaps, creating a more complete feature set for prediction. This enrichment reduces bias from missingness, provides additional predictive signals (e.g., left atrial size from reports), and enables automated cohort selection and labeling, which standardizes the dataset construction process and improves model generalizability.

## Architecture Onboarding
**Component map**: Discharge Reports -> R2V (Section ID + Entity Recognition + Regex) -> Extracted Features -> VectorMerger <- S2V (Structured Features) -> TabPFN -> Predictions

**Critical path**: R2V extraction accuracy -> correct feature alignment in VectorMerger -> TabPFN training with enriched vectors. Failure at any stage degrades downstream performance.

**Design tradeoffs**: 
- Rule-based regex vs. ML entity recognition: Regex offers precision for known patterns but lacks flexibility; ML generalizes but requires annotated training data.
- Vector merging (late fusion) vs. joint multimodal modeling: Merging is simple and interpretable but may miss interactions between text and structured data; joint modeling is complex but could capture deeper synergies.
- Silver (automatic) vs. gold (manual) labels: Silver scales but introduces noise; gold is accurate but costly.

**Failure signatures**: 
- Low extraction recall (<70%) for key features like left atrial size.
- No reduction in missingness after enrichment.
- Enriched model MCC does not exceed structured-only baseline.
- Large performance gap between silver and gold labels (>0.1 MCC).

**First three experiments**:
1. Evaluate R2V component individually: On 100 manually annotated discharge reports, compute precision, recall, and F1 for the 84 target features. Target >80% F1 for core features.
2. Measure enrichment impact on missingness: For the 84 features, calculate percentage missing in structured-only vs. enriched vectors. Expect significant reduction (e.g., >20% absolute drop for features like albumin).
3. Compare silver vs. gold label impact: Train TabPFN on the same enriched dataset using silver labels and gold labels (on overlapping subset). Report MCC difference; acceptable delta <0.05.

## Open Questions the Paper Calls Out
1. **Generalizability to other diseases**: Does the pipeline work for conditions beyond AF progression with different predictive features and documentation patterns?
2. **Multi-center validation**: How does performance vary across hospitals with different EHR systems and reporting styles?
3. **LLM integration**: Can large language models improve extraction and labeling accuracy over the current fine-tuned BERT and regex approach?
4. **Multimodal modeling**: Would joint processing of structured and unstructured data (vs. vector merging) yield better predictions?
5. **Longitudinal dynamics**: Does incorporating temporal sequences from multiple reports and EHR entries improve progression forecasting?

## Limitations
- The NLP pipeline (R2V) details and code are not open-sourced, blocking exact replication.
- TabPFN's internal preprocessing and hyperparameters are not fully disclosed, introducing variability.
- The study relies on a single healthcare system's data, limiting external validity.
- Automatic labeling logic for AF progression, while agreed with experts, may not generalize to other text styles.

## Confidence
- **High**: Enriching structured EHRs with NLP-extracted features improves predictive performance for AF progression compared to structured-only models and clinical scores.
- **Medium**: Silver labels generated automatically achieve sufficient agreement (~0.82) with gold manual labels for model training.
- **Low**: The full pipeline can be faithfully reproduced in a different clinical setting with distinct EHR structures and documentation practices.

## Next Checks
1. **Audit NLP extraction fidelity**: On a small, manually annotated sample of discharge reports, compute precision/recall for key extracted features to quantify noise and identify error modes.
2. **Measure enrichment effect on missingness**: In a new dataset, compare the reduction in missing values per feature after applying the enrichment pipeline versus the structured-only baseline.
3. **Compare silver vs. gold model performance**: Train TabPFN on the same enriched dataset using either automatic (silver) or manual (gold) progression labels on a held-out subset; quantify the performance delta to validate label reliability.
