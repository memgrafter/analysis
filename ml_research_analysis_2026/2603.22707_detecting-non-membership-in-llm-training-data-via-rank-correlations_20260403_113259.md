# Detecting Non-Membership in LLM Training Data via Rank Correlations
## Quick Facts
- arXiv ID: 2603.22707
- Source URL: https://arxiv.org/abs/2603.22707
- Reference count: 40
- Primary result: PRISM detects dataset-level non-membership with high accuracy (p ≤ 0.0001 for non-members vs. p ≈ 1 for members) using only grey-box logit access.

## Executive Summary
PRISM is a novel method for determining whether a dataset was excluded from an LLM's training, requiring only grey-box model access. It compares Spearman rank correlations of Min-K%++ scores between the target model, a reference model never trained on the dataset, and a distilled reference model trained on the dataset. Across eight datasets, PRISM achieves clear statistical separation between member and non-member scenarios, works with as few as 100 documents, and avoids false positives—a key limitation of prior membership inference attacks. The approach leverages the insight that memorization distorts a model's ranking of documents by surprisal relative to an unexposed model.

## Method Summary
Given a target model MT, a reference model MR (known not trained on dataset D), and D itself, PRISM computes the Min-K%++ score for each document in D under MT, MR, and a distilled reference MD. MD is obtained by fine-tuning MR on D with knowledge distillation from MT, mimicking MT's behavior while internalizing D-specific patterns. The Spearman rank correlation ρRT between MT and MR scores and ρDT between MT and MD scores are calculated. A one-sided bootstrap test on Δ = ρRT − ρDT yields a p-value; small p (≤ 0.05) indicates non-membership. The method operates at dataset level and requires only model logits.

## Key Results
- Non-member targets yield very low p-values (≤ 0.0001) while member targets yield high p-values (≈ 1.0) across eight diverse datasets.
- Detection remains effective with as few as 100 documents; smaller datasets increase variance.
- PRISM produces no false positives, overcoming a major limitation of prior membership inference techniques that cannot reliably confirm non-membership.

## Why This Works (Mechanism)
### Mechanism 1: Rank Correlation Divergence
**Claim:** If D was not in MT's training data, the rank correlation of Min-K%++ scores between MT and MR (both unexposed) is higher than between MT and MD (exposed via distillation).  
**Mechanism:** Unexposed models develop similar difficulty rankings; memorization in MT (or MD) alters its rankings relative to an unexposed model. The distilled reference MD approximates a counterfactual MT trained on D, so higher correlation with MR indicates lack of shared exposure.  
**Core assumption:** Memorization selectively reduces surprisal on D's documents, perturbing rankings.  
**Evidence anchors:** Abstract; Section 3.3 empirical observation with Pythia models; weak corpus relevance.

### Mechanism 2: Distilled Reference as Proxy
**Claim:** MD serves as a valid stand-in for "MT trained on D" via knowledge distillation.  
**Mechanism:** MD is fine-tuned on D with a loss combining cross-entropy on D and KL divergence from MT's output distribution. This transfers D-specific memorization while preserving MT's general priors, isolating the effect of D's exposure.  
**Core assumption:** Distillation successfully decouples global priors from dataset-specific adaptation.  
**Evidence anchors:** Section 4.2 loss function; Section 5.1 cross-architecture effectiveness.

### Mechanism 3: Bootstrap Hypothesis Test
**Claim:** The one-sided bootstrap test on Δ provides a calibrated p-value for non-membership.  
**Mechanism:** Resampling documents from D approximates the sampling distribution of Δ under H0: Δ ≤ 0 (non-membership). A large observed Δ yields a small p-value, rejecting H0 and indicating non-membership.  
**Core assumption:** Bootstrap accurately captures finite-dataset variability; test statistic distribution is well-approximated.  
**Evidence anchors:** Section 4.3; Section 5.1 p-value separation.

## Foundational Learning
- **Min-K%++ score**: Aggregates the lowest K% of normalized token log-probabilities in a document, hypothesized to be sensitive to memorization. *Quick check*: Why average only the lowest K% instead of all tokens?
- **Spearman rank correlation**: Measures monotonic association between ranked document scores, robust to scale differences. *Quick check*: Why prefer Spearman over Pearson here?
- **Knowledge distillation for proxy modeling**: Trains MD to mimic MT's distribution while learning D, creating a controlled comparison point. *Quick check*: What happens if λ=0 or λ=1 in the distillation loss?

## Architecture Onboarding
Input: Dataset D, target MT (grey-box), reference MR (never trained on D).  
Component map: D -> Distilled Reference Trainer -> MD -> Min-K%++ Scorer -> s_MT, s_MR, s_MD -> Rank Correlation Engine -> ρRT, ρDT -> Bootstrap Tester -> p-value -> Decision.  
Critical path: Train MD on D using distillation from MT -> compute Min-K%++ scores for all three models -> compute correlations -> bootstrap resampling -> p-value.  
Design tradeoffs:
- K in Min-K%++: smaller K focuses on memorization-sensitive tokens but increases noise; larger K dilutes signal.
- Distillation hyperparameters (λ, τ): balance between MD learning D and preserving MT's priors.
- Reference model size: larger MR improves baseline correlation and separation.
- Dataset size: ≥150 documents needed for stable p-values.
Failure signatures:
- Δ ≈ 0: inconclusive; may indicate small D, poor MR, or MD not learning D.
- Δ negative: MT correlates less with MR than with MD, possibly due to mismatched MR or overfitted MD.
- Both correlations extremely high: models too similar overall, reducing dynamic range.
First 3 experiments:
1. Replicate Table 2: For known non-member (e.g., Pythia-410m) and member (e.g., Pythia-410m-CPT) targets, confirm p ≈ 0 vs. p ≈ 1 across datasets.
2. Vary dataset size (Figure 3): Subsample D to {50,100,...,500} docs; observe p-values stabilize above 150 docs.
3. Ablate reference model size (Table 5): Use MR of different scales (70m, 160m, 1b) with fixed target; smaller MR yields less separation and higher p-values for non-members.

## Open Questions the Paper Calls Out
1. How can PRISM be applied to datasets without clear release dates, making it infeasible to identify a pre-dating reference model?
2. How does the magnitude of training exposure (e.g., epochs or tokens) on the suspect dataset influence the rank correlation difference?
3. Can PRISM detect partial inclusion of a dataset (some documents used) instead of binary inclusion?
4. How robust is PRISM if the reference model has inadvertently seen some fraction of the suspect dataset (contamination)?
5. What theoretical properties explain why training on a dataset systematically reduces the Spearman rank correlation of Min-K%++ scores between models compared to a non-trained reference?

## Limitations
- Method requires a verifiable reference model never trained on D; establishing this is challenging for many datasets.
- Hyperparameters (e.g., K in Min-K%++, λ, τ) are not fully specified or explored; performance likely sensitive to these choices.
- PRISM is dataset-level only and cannot identify which specific documents were included.
- The test may be underpowered for datasets with fewer than 100 documents.

## Confidence
- Detection accuracy: **High** (clear p-value separation across eight datasets).
- Rank correlation as signal: **Medium** (empirical pattern consistent but lacks formal analysis).
- Distilled reference validity: **Medium** (cross-architecture results promising but hyperparameter sensitivity unclear).
- Bootstrap test calibration: **High** (standard resampling with strong empirical separation).

## Next Checks
1. **Min-K%++ K-sweep**: Vary K from 0.01 to 0.2 and measure stability of p-values for member/non-member scenarios.
2. **Distillation hyperparameter ablation**: Grid-search λ ∈ [0.3,0.9] and τ ∈ [1.0,2.5]; assess impact on Δ and p-values.
3. **Tokenizer/architecture mismatch stress test**: Use reference models with different tokenizers or architectures (e.g., Llama vs. Pythia); identify threshold where baseline correlation becomes too low for reliable detection.
