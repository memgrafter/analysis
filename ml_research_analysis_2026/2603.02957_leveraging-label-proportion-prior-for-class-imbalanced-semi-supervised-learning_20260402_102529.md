# Leveraging Label Proportion Prior for Class-Imbalanced Semi-Supervised Learning

## Quick Facts
- **ArXiv ID:** 2603.02957
- **Source URL:** https://arxiv.org/abs/2603.02957
- **Reference count:** 0
- **Primary result:** Adding Proportion Loss to FixMatch and ReMixMatch yields consistent test accuracy gains on Long-tailed CIFAR-10 across imbalance ratios (γ=10–100) and labeled data ratios (β=2–20%), with improvements up to +2.6% under scarce labels.

## Executive Summary
Semi-supervised learning (SSL) methods like pseudo-labeling often fail under class imbalance because they amplify majority-class bias from the unlabeled data distribution. This paper introduces Proportion Loss, a lightweight, architecture-agnostic regularization term that aligns mini-batch predictions with the global class distribution estimated from the small labeled set. A stochastic variant uses multivariate hypergeometric sampling to model fluctuations in mini-batch class composition. Integrated into FixMatch and ReMixMatch, the approach consistently improves accuracy on Long-tailed CIFAR-10, especially when labeled data are very scarce, and outperforms existing class-imbalanced SSL methods.

## Method Summary
The core method adds Proportion Loss (L_prop = −∑_l q_l log(p̂_l)) to standard SSL objectives. Here, q_l = N_l/N is the target class proportion from the labeled set, and p̂_l is the mini-batch averaged softmax prediction over unlabeled samples. In the deterministic version, q is fixed per epoch; in the stochastic variant, per-iteration class proportions q(t) are sampled via multivariate hypergeometric distribution, reflecting the variability in unlabeled data composition. The regularization weight λ is tuned on validation. This simple add-on requires no architectural changes and leverages the prior knowledge of global class distribution already available from the limited labeled data.

## Key Results
- On FixMatch with γ=10, β=2%, accuracy improves from 80.8% to 81.9%.
- On ReMixMatch with same settings, accuracy improves from 85.5% to 88.1%.
- Gains are consistent across imbalance ratios (γ=10–100) and labeled ratios (β=2–20%), with larger relative improvements under more severe imbalance and fewer labels.
- The method reduces minor-class underestimation compared to baselines and prior CISSL methods like DARP and CReST.

## Why This Works
Proportion Loss regularizes the model to respect the global class distribution learned from the labeled set. This counters the natural tendency of pseudo-labeling to overfit to the majority-class-biased unlabeled distribution. By penalizing deviation between batch predictions and target proportions, the model is discouraged from collapsing minor-class predictions. The stochastic variant further improves stability by explicitly accounting for sampling variance in mini-batch class counts, preventing the model from over-optimizing on atypical batch compositions.

## Architecture Onboarding
**Component map:**  
Labeled dataset → Compute global proportions q → Proportion Loss module  
Unlabeled batch → Pseudo‑labeling (SSL) → SSL loss  
Combine losses: L_total = L_ssl + λ L_prop → Model update  

**Critical path:**  
For each iteration:  
1. Draw unlabeled batch (size |B|).  
2. Compute pseudo‑labels and SSL loss.  
3. Compute batch class predictions p̂.  
4. If stochastic: sample q(t) ~ MultiHG(population=M_l, sample=|B|).  
5. Compute L_prop using q (or q(t)).  
6. Compute L_total and backpropagate.  

**Design tradeoffs:**  
- *Deterministic vs. stochastic L_prop:* Deterministic is stable but ignores batch variability; stochastic better reflects true data sampling but introduces noise.  
- *λ sensitivity:* Too low yields negligible effect; too high forces uniform predictions, harming overall accuracy. Requires careful tuning.  

**Failure signatures:**  
- Minor‑class recall either too low (under‑regularization) or unnaturally high (over‑regularization).  
- L_prop values highly volatile across iterations (stochastic variant with small batches).  
- Baseline SSL accuracy significantly diverges from reported numbers (implementation mismatch).  

**Three first experiments:**  
1. **Baseline replication:** Train vanilla FixMatch/ReMixMatch on Long‑tailed CIFAR‑10 at (γ,β)=(10,2%) and verify test accuracy matches paper (80.8% for FixMatch, 85.5% for ReMixMatch).  
2. **λ sensitivity sweep:** Tune λ on a fixed validation set (e.g., 500/class) for deterministic L_prop; plot per‑class recall and overall accuracy vs. λ to find sweet spot.  
3. **Deterministic vs. stochastic comparison:** Fix random seed; train both variants with same λ; compare test accuracy and L_prop variance across iterations to assess stability gain.
