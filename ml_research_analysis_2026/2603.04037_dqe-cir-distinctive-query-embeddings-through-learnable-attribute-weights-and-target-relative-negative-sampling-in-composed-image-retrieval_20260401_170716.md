# DQE-CIR: Distinctive Query Embeddings through Learnable Attribute Weights and Target Relative Negative Sampling in Composed Image Retrieval
## Quick Facts
- **arXiv ID:** 2603.04037  
- **Source URL:** https://arxiv.org/abs/2603.04037  
- **Reference count:** 40  
- **Primary result:** DQE-CIR achieves state-of-the-art on FashionIQ (average Recall@10/50 = 54.60/75.94), outperforming prior best (QuRe) by ~2 points, with consistent gains on CIRR and CIRCO.

## Executive Summary
Composed image retrieval (CIR) retrieves a target image based on a reference image and a modification text. Standard contrastive learning treats all non-target images as negatives, which introduces relevance suppression (semantically correct but non-target images penalized) and semantic confusion (overlapping intents), harming fine-grained discrimination. DQE-CIR introduces two complementary innovations: (1) **Learnable Attribute Weights** adaptively modulate color- and shape-sensitive sub-queries extracted from a BLIP-2 Q-Former, emphasizing distinctive features aligned with the modification text; (2) **Target Relative Negative Sampling (TRNS)** selects a single negative from a mid-zone of the target-relative similarity difference (ΔS) distribution, avoiding extremely easy negatives and ambiguous false negatives. These are trained with a pairwise ranking loss and auxiliary attribute losses to construct a sharper embedding space. DQE-CIR sets new records on FashionIQ, CIRR, and zero-shot CIRCO, demonstrating broad effectiveness.

## Method Summary
DQE-CIR uses a frozen BLIP-2 image encoder and a trainable Q-Former. Given a reference image and modification text, the Q-Former produces a base query `q` and attribute-specific sub-queries `q_color` and `q_shape` (extracted via attention on color-/shape-related text tokens). The final query is `q* = q + w_color·q_color + w_shape·q_shape`, where scalars `w_color`, `w_shape` are learned to amplify distinctive attributes. For training, TRNS computes cosine similarity differences ΔS between the target and every candidate image in the corpus; a single negative is sampled uniformly from the mid-zone `M = {j | α ≤ ΔS_j ≤ β}` (e.g., α=0.2, β=0.8). The loss combines: KL divergence between predicted distribution and one-hot target, a pairwise margin loss `max(0, m - s_tar + s_neg)` applied to `q*` and each sub-query, and auxiliary attribute margin losses. The Q-Former, projection layers, and attribute weights are updated; the image encoder stays frozen. Training uses warm-up followed by interval updates (e.g., every 5 epochs) to recompute the negative set.

## Key Results
- **FashionIQ:** Average Recall@10/50 = 54.60/75.94, beating QuRe (52.50/73.80) by ~2 points.
- **CIRR:** Average score = 82.16 (QuRe: 80.52), with Recall@1 = 54.05 and Recallsubset@1 = 80.14.
- **CIRCO (zero-shot):** mAP@50 = 28.13 (vs. QuRe 27.24).

## Why This Works (Mechanism)
### Mechanism 1: Learnable Attribute Weighting for Distinctive Sub-Queries
- **Claim:** Modulating color- and shape-sensitive sub-queries with learnable scalar weights yields query embeddings that more precisely align with fine-grained modification intents, reducing semantic confusion.
- **Mechanism:** The BLIP-2 Q-Former generates a base query `q`. Parallel attribute-specific sub-queries (`q_color`, `q_shape`) are extracted via attention conditioned on textual attribute terms. The final query is `q* = q + w_color·q_color + w_shape·q_shape`, where `w_color`/`w_shape` are learned to amplify features critical to the modification.
- **Core assumption:** Explicitly disentangling and adaptively weighting attribute-specific features prevents collapse of different modification intents into overlapping embedding regions.
- **Evidence anchors:**
  - Abstract: "emphasize distinctive visual features conditioned on the modification text"
  - Section 3.2: Equation (1) defines weighted summation; auxiliary losses `L_color`, `L_shape` enforce attribute-aware ranking margins.
  - Corpus: Neighbors (e.g., SPRC, QuRe) focus on prompt tuning or negative sampling but do not jointly model adaptive attribute modulation; methodological contrast establishes novelty.
- **Break condition:** If the modification text lacks explicit color/shape terms, attribute sub-queries may receive uninformative gradients, causing `w_color`/`w_shape` to stagnate or amplify noise.

### Mechanism 2: Target Relative Negative Sampling (TRNS)
- **Claim:** Selecting a single negative from a mid-zone of the target-relative ΔS distribution provides semantically informative supervision while avoiding false positives (relevance suppression) and overly easy negatives.
- **Mechanism:** For each query, compute cosine similarities `s_tar` (target) and `s_j` (all candidates). Define `ΔS_j = s_tar - s_j`. The mid-zone `M = {j | α ≤ ΔS_j ≤ β}` excludes:
  - Easy negatives (large `ΔS`, far from target)
  - Ambiguous/false negatives (`ΔS ≈ 0`, semantically relevant but not exact target).
  A random `j- ∈ M` is sampled for pairwise ranking.
- **Core assumption:** The ΔS distribution reveals a "useful confusion" band where negatives are challenging but not misleading; focusing here improves discriminativeness for fine-grained changes.
- **Evidence anchors:**
  - Abstract: "excludes both easy negatives and ambiguous false negatives"
  - Section 3.3: Formal ΔS computation and mid-zone definition (Eq. 4).
  - Section 4.5: Tab. 4 shows optimal performance at `α=0.20, β=0.80`; narrower/wider ranges degrade results, confirming the mid-zone's role.
- **Break condition:** If the embedding space is poorly calibrated (e.g., early training), the ΔS distribution may not separate target-relevant candidates cleanly, causing the mid-zone to include false negatives or only trivial negatives.

### Mechanism 3: Single-Negative Pairwise Ranking Optimization
- **Claim:** Optimizing a margin-based ranking loss against a single TRNS-negative (instead of many negatives) creates a clearer preference structure, mitigating semantic confusion.
- **Mechanism:** For the main query and each attribute sub-query, loss `L = max(0, m - s_tar + s_neg)` enforces that target similarity exceeds negative similarity by margin `m`. Combined with KL divergence `L_KL` (aligns query distribution to target), this forms a compact ranking constraint.
- **Core assumption:** Focusing on one "informative" negative per step provides a stronger gradient for fine-grained discrimination than multi-negative contrastive losses, which can dilute learning signals.
- **Evidence anchors:**
  - Abstract: "pairwise learning... focuses on a single selected negative... strengthens the ranking margin"
  - Section 3.4: Eq. (6) and (7) define `L_main` and `L_a`; Algorithm 1 integrates them.
  - Section 4.2: Metrics (Recall@K, Recallsubset@K) measure ranking quality; improvements validate the pairwise approach.
- **Break condition:** If the sampled negative is not truly "informative" (e.g., mid-zone mis-specified), the ranking constraint may push the query away from semantically relevant candidates, harming recall.

## Foundational Learning
- **Concept: Contrastive Learning in CIR**  
  - **Why needed:** DQE-CIR modifies standard contrastive learning (all non-targets as negatives). Understanding its limitations—relevance suppression and semantic confusion—is essential to grasp the motivation for TRNS and pairwise ranking.  
  - **Quick check:** Why might an image that correctly applies the modification (but is not the exact target) be harmful if treated as a negative in standard CIR training?  

- **Concept: Vision-Language Backbone (BLIP-2)**  
  - **Why needed:** DQE-CIR builds on BLIP-2's Q-Former for multimodal fusion. Knowing its role (frozen image encoder, trainable Q-Former) clarifies which components are adapted.  
  - **Quick check:** What is the functional role of the Q-Former in BLIP-2, and why is it a suitable base for learning attribute-sensitive queries?  

- **Concept: Composed Image Retrieval Evaluation (FashionIQ, CIRR)**  
  - **Why needed:** Metrics like Recall@K and Recallsubset@K measure distinct aspects (global ranking vs. fine-grained subset discrimination). Interpreting results requires understanding these protocols.  
  - **Quick check:** How does Recallsubset@1 on CIRR specifically test a model's ability to handle visually similar distractors?

## Architecture Onboarding
- **Component map:**  
  Input encoders (frozen BLIP-2 image encoder, text encoder) -> Q-Former (base query & attribute sub-queries) -> Attribute weighting (w_color, w_shape) -> Distinctive query q* -> Compute similarities with corpus -> TRNS module (ΔS, mid-zone M) -> Sample single negative -> Losses (L_KL, L_main, L_color, L_shape) -> Total loss -> Update Q-Former, projection layers, attribute weights  
- **Critical path:**  
  (ref_img, mod_text) -> Q-Former -> base_q & attribute_sub-queries -> weighted_q* -> compute s_tar, all s_j -> ΔS distribution -> mid-zone M -> sample negative -> compute s_neg -> pairwise/attribute losses -> total loss -> update weights.  
- **Design tradeoffs:**  
  - **TRNS interval frequency:** Updating mid-zone every N epochs (paper uses 5 intervals) balances stability vs. adapting to evolving embedding space; more frequent increases cost.  
  - **Mid-zone width (α, β):** Requires validation tuning; too narrow limits negative diversity, too broad risks false negatives.  
  - **Attribute granularity:** Paper uses only color/shape; extending to more attributes (e.g., texture, count) increases complexity but may help richer domains.  
- **Failure signatures:**  
  - **Empty mid-zone:** If mid-zone size collapses to 0 (all candidates too easy/hard), training fails to get negatives; check ΔS histogram.  
  - **Attribute weight collapse:** If w_color or w_shape approach 0, attribute sub-queries ignored; verify gradients during early epochs.  
  - **Pairwise loss saturation:** If s_tar - s_neg consistently exceeds m, L_main vanishes; model stops learning from negatives—reduce m or widen mid-zone.  
- **First 3 experiments:**  
  1. Baseline replication: BLIP-2 + standard contrastive loss (all non-targets negative).  
  2. Ablation - TRNS only: Add TRNS + pairwise loss to baseline, remove attribute weighting; measure impact on Recallsubset@1.  
  3. Ablation - Attribute weights only: Add learnable w_color/w_shape to baseline, keep standard negative sampling; check attribute-specific accuracy.

## Open Questions the Paper Calls Out
- **How can the mid-zone range (α, β) in Target Relative Negative Sampling be determined automatically across different datasets?**  
  Basis: Section 3.3 defines mid-zone M = { j | α ≤ ΔS_j ≤ β } and Section 4.5 (Table 4) shows performance varies with the interval, indicating a hyperparameter needing tuning. Why unresolved: Manual search for optimal α and β per dataset reduces plug-and-play usability. What evidence would resolve: A data-driven selection (e.g., 30-70th percentile of ΔS) that yields comparable results on multiple datasets without per-dataset tuning.

- **Can the learnable attribute weighting mechanism be extended to dynamically incorporate arbitrary attributes conditioned on the modification text, beyond the fixed color and shape?**  
  Basis: Section 3.2 uses only color and shape sub-queries, extracted from Q-former attention outputs conditioned on color-related and shape-related terms, without specifying term identification or additional attributes. Why unresolved: Closed set of attributes limits handling modifications involving other attributes (e.g., texture, pattern) or implicit attributes. What evidence would resolve: Replace fixed modules with an end-to-end attribute detector that outputs attribute queries from text, evaluate on a dataset with rich annotations to show gains.

- **Does the single-negative pairwise ranking loss fully exploit the mid-zone negatives, or would incorporating multiple negatives improve fine-grained discriminativeness?**  
  Basis: Algorithm 1 samples exactly one negative j⁻ from M and applies L_main = max(0, m - s_tar + s_j⁻); no comparison with multi-negative baselines. Why unresolved: Single-negative approach may ignore other relevant negatives within the mid-zone that could provide stronger supervision or regularize the margin. What evidence would resolve: Implement variants using top-K negatives from M (e.g., triplet with multiple negatives or listwise loss) and compare accuracy and convergence.

- **How transferable are the DQE-CIR improvements to other vision-language model backbones, particularly those without a Q-Former architecture?**  
  Basis: All experiments use BLIP or BLIP-2 backbones; no other VLMs (e.g., CLIP, ALIGN, Flamingo) evaluated. Why unresolved: Method built on BLIP-2's Q-Former; unclear if gains are architecture-specific. What evidence would resolve: Port DQE-CIR to at least two other VLMs (e.g., CLIP-ViT-L/14, diffusion-based VL model) and replicate FashionIQ/CIRR experiments to see if improvements persist.

## Limitations
- **Unspecified attribute sub-query extraction:** Method for deriving color/shape queries from Q-Former attention (layers, pooling, keyword list) is not described; choices could impact results.
- **Incomplete hyperparameter reporting:** Exact values for temperature τ, margins, loss weights, learning rate, warm-up length, TRNS interval schedule are not provided; optimal values may vary by dataset.
- **Corpus-scale memory burden:** TRNS requires full-corpus similarity computation each interval; no details on approximate search or caching, raising scalability concerns.
