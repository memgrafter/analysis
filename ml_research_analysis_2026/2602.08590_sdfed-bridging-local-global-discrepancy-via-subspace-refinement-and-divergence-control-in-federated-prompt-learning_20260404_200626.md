# SDFed: Bridging Local Global Discrepancy via Subspace Refinement and Divergence Control in Federated Prompt Learning

## Quick Facts
- arXiv ID: 2602.08590
- Source URL: https://arxiv.org/abs/2602.08590
- Reference count: 40
- Primary result: SDFed achieves peak accuracy of 99.35% on Flowers102 and up to 3.44% gains over baselines, with minimal computational overhead (<1% runtime).

## Executive Summary
Federated prompt learning under client heterogeneity struggles with conflicts between global aggregation and local personalization. SDFed addresses this by decoupling the two processes: a fixed-length global prompt guides consistency, while variable-length local prompts allow adaptation. It introduces subspace refinement—using SVD on the global prompt to project local prompts onto its null-space—suppressing directions already captured globally. An information retention strategy combines stretch loss (aligning local and refined features) and separation loss (enforcing a margin from global features) to preserve local semantics while maintaining separability. Extensive experiments on seven benchmark datasets show SDFed consistently outperforms methods like UOPP and GPT-FL, and remains robust under model heterogeneity and low-shot settings with negligible overhead.

## Method Summary
SDFed operates iteratively. First, a global prompt is learned via federated averaging. In each subsequent round, every client computes the SVD of the current global prompt and projects its local prompt onto the null-space of the right singular vectors, removing components already represented globally. Local training then minimizes a combined loss: stretch loss maximizes similarity between local prompts and the projected refined features (retaining semantics), while separation loss pushes the local feature distribution away from the global one (ensuring discriminability). Updated local prompts are aggregated to refresh the global prompt. This cycle separates the refinement of globally shared knowledge from the capture of client-specific patterns.

## Key Results
- State-of-the-art performance across Flowers102, DTD, Food101, OxfordPets, Caltech101, Office31, and OfficeHome.
- Peak accuracy of 99.35% on Flowers102 (ViT-B16) with gains up to 3.44% over UOPP and GPT-FL.
- Robustness in model-heterogeneous and low-shot regimes, with subspace refinement adding less than 1% to runtime.

## Why This Works (Mechanism)
SDFed mitigates client heterogeneity by explicitly decoupling global and local prompt spaces. Subspace refinement isolates the orthogonal complement of the global prompt’s dominant directions, preventing local updates from reinforcing already-learned global features and reducing interference. The divergence control strategy balances two objectives: stretch loss preserves local semantic alignment by keeping projected local features close to the refined representation, while separation loss enforces a margin between local and global feature distributions, ensuring that personalization remains distinct. This dual mechanism maintains global consistency without sacrificing local adaptability, avoiding catastrophic forgetting and enabling both shared and unique knowledge to coexist.

## Architecture Onboarding
**Component map:**  
Global Prompt -> SVD Decomposition -> Null-Space Definition -> Local Prompt Projection -> Feature Extraction -> Stretch Loss & Separation Loss -> Local Prompt Update -> Federated Averaging -> Updated Global Prompt

**Critical path:**  
1. Server distributes global prompt to clients.  
2. Each client computes SVD of global prompt, obtains null-space basis.  
3. Local prompt is projected onto null-space.  
4. Local model processes data; features from both local and projected prompts are extracted.  
5. Stretch loss (local vs. projected features) and separation loss (local vs. global features) are computed and combined.  
6. Local prompt is updated via gradient descent.  
7. Updated local prompts are sent to server and averaged to form new global prompt.

**Design tradeoffs:**  
- Fixed-length global vs. variable-length local prompts: global ensures uniformity but may limit expressiveness; local allows adaptation but risks divergence.  
- Stretch loss vs. separation loss: stretch preserves semantics but may reduce inter-client separation; separation increases discriminability but could distort local meaning if weighted too high.  
- SVD overhead: negligible for small prompt dimensions, but could grow with prompt length; authors report <1% runtime impact.

**Failure signatures:**  
- Local prompts collapse into the global subspace (separation loss weight too low or missing).  
- Local semantics degrade (stretch loss weight too low or projection too aggressive).  
- Slow or unstable convergence if local prompt lengths are mismatched or learning rates are misconfigured.

**Three first experiments:**  
1. Ablate subspace refinement: disable null-space projection and compare performance to quantify its contribution.  
2. Sweep local prompt length (e.g., 1–20 tokens) to study the personalization–efficiency tradeoff.  
3. Evaluate on highly skewed non-IID data (Dirichlet α=0.05) with heterogeneous client model architectures to stress-test robustness claims.

## Limitations
- Missing ablation studies to disentangle the impact of subspace refinement versus the divergence losses.
- Experimental comparison limited to two baselines (UOPP, GPT-FL); recent federated prompt methods are not evaluated.
- No statistical analysis (e.g., variance across runs, significance tests) reported.

## Confidence
- Effectiveness: High (consistent gains across 7 datasets, but narrow baseline selection).
- Efficiency: Medium (claimed overhead <1% plausible but lacks context on hardware/conditions).
- Robustness: Medium (mentioned but superficially evaluated; needs extreme heterogeneity tests).
- Novelty: Medium (subspace refinement resembles prior linearized frameworks; incremental contribution).
