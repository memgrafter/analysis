# Kimodo: Scaling Controllable Human Motion Generation

## Quick Facts
- arXiv ID: 2603.15546
- Source URL: https://arxiv.org/abs/2603.15546
- Reference count: 40
- Primary result: Kimodo scales controllable motion generation to 700h mocap, achieving 2.67 cm average full-body keyframe error, 71.9% R-Precision, and 1.85 FID.

## Executive Summary
Current motion generation models suffer from limited quality and controllability due to small public mocap datasets. Kimodo addresses this by training on 700 hours of high-quality optical mocap data and introducing two key innovations: (1) a smoothed root motion representation that decouples natural pelvic sway from intended path constraints, reducing foot skating; (2) a two-stage denoiser architecture that first predicts global root motion and then body motion conditioned on a local root representation. The paper also conducts a comprehensive scaling study across data, model size, and batch dimensions.

Results on a held-out test set show state-of-the-art performance: average full-body keyframe error of 2.67 cm, end-effector position error 3.09 cm, rotation error 4.18°, and 2D root path error 2.90 cm. Foot skating is measured at 3.87 cm/s. For text-driven generation, R-Precision reaches 71.9% and motion quality FID is 1.85. The scaling analysis confirms that increasing dataset size (up to 700h), model capacity (up to 282M parameters), and batch size all contribute to these gains.

## Method Summary
Kimodo employs an explicit pose-space representation: for each frame, it includes a smoothed global root position (heavy smoothing of horizontal pelvis components, preserving vertical height) and heading, global joint positions (2D relative to smoothed root XY, absolute Y), global velocities, 6D rotations for 27 joints, and foot contact flags. This representation enables direct imputation of sparse constraints via a mask mechanism: during training, constraints are mixed into the noisy input as `x̃^t = m ⊙ x_tgt + (1-m) ⊙ x^t`, and the mask `m` is concatenated to the input.

The generative model is a diffusion probabilistic model with a two-stage transformer denoiser. Stage 1 (Root Denoiser) predicts global root motion from the full noisy input. Its output is converted to a local velocity-based root representation (`r_local`) via finite differences. Stage 2 (Body Denoiser) predicts body joint positions, velocities, rotations, and foot contacts conditioned on the input's body features concatenated with `r_local`. This decomposition isolates the global trajectory prediction and provides an invariant conditioning signal for the body, reducing alignment artifacts. Training proceeds in two phases: first, a text-only phase (500k steps) with 10% text dropout to learn a strong motion prior; second, a mixed phase (500k steps) where random constraint patterns (full-body keyframes, end-effectors, root paths, contacts) are introduced without dropout, using a diffusion loss with component-specific weights. At inference, classifier-free guidance combines text and constraint conditions, and sampling uses DDIM (100 steps). Additional techniques include LLM-based text paraphrasing, random first-frame heading augmentation, and motion stitching for data augmentation.

## Key Results
- Motion quality: average full-body keyframe error 2.67 cm, foot skate velocity 3.87 cm/s, FID 1.85.
- Constraint accuracy: end-effector position error 3.09 cm, joint rotation error 4.18°, 2D root path error 2.90 cm.
- Text following: R-Precision 71.9%.

## Why This Works (Mechanism)

**Mechanism 1: Smoothed Root Representation**  
Claim: The smoothed root motion representation minimizes foot skating and provides a stable reference for joint positions when following 2D path constraints. Mechanism: Instead of using the raw pelvic trajectory, the root motion is defined by heavily smoothing the horizontal components of the pelvis position while preserving vertical height. Joint positions are then defined relative to this smoothed root, decoupling natural pelvic sway from the intended path and preventing extreme compensatory motions that cause foot sliding. Core assumption: A smooth root trajectory is a more stable and natural frame of reference than the raw, noisy pelvic path. Evidence: Abstract, Section 4.1, Figure 8; neighboring papers do not directly validate this design. Break condition: If the 95th percentile error between projected pelvis and smoothed root constraint exceeds ~10 cm, the model fails to reconcile constraints with natural sway, producing unnatural motions (e.g., "stealthy" walks).

**Mechanism 2: Two-Stage Denoiser**  
Claim: The interleaved two-stage denoiser architecture (global root then body) improves motion quality and constraint accuracy by decomposing prediction and using a locally invariant root for body conditioning. Mechanism: Stage 1 predicts global root `r_glob`, which is converted to local `r_local` via finite differences. Stage 2 predicts body motion `b` conditioned on `r_local`. Global root enables direct imputation of sparse constraints; local root provides an invariant, first-order description that simplifies body prediction and reduces misalignment. Core assumption: Conditioning body motion on local root is easier and more stable than on global root. Evidence: Abstract, Section 4.2, Table 1 ("Second Stage Global" ablation shows increased skate). Break condition: If "Second Stage Global" ablation performs comparably or better, or if a matched single-stage model matches/exceeds performance, the decomposition's benefit is falsified.

**Mechanism 3: Scaling Synergy**  
Claim: Performance on text+constraint motion generation improves monotonically with increases in data, model size, and batch size. Mechanism: Larger datasets increase motion diversity and exposure to rare actions; larger models (up to 282M) have capacity to learn complex mappings; larger batches provide accurate gradients. The three factors synergize. Core assumption: Task performance is a jointly constrained function of these scaling axes. Evidence: Abstract, Section 6.3, Table 2, Figure 5 show monotonic gains across R@3, FID, foot skate, constraint errors when scaling each axis. Neighboring papers (Motion-X, Scamo, Hy-motion) report similar trends, offering moderate corroboration. Break condition: Scaling beyond 500M parameters with only 700h data leads to training instability; diminishing returns may appear if one axis is saturated without increases in others.

## Foundational Learning

**Diffusion Probabilistic Models (DDPM/DDIM)**  
Why needed: The core generative process is a denoising diffusion model that iteratively converts noise into motion, conditioned on text and constraints. Understanding forward noising and reverse denoising, as well as classifier-free guidance for mixing conditions, is essential.  
Quick check: How does classifier-free guidance (`D = D_∅ + w_text(D_text - D_∅) + w_constr(D_constr - D_∅)`) allow separate control over text and constraint adherence during sampling?

**Explicit vs. Latent Motion Representations**  
Why needed: Kimodo uses an explicit pose-space representation (joint positions, rotations, root features) to enable direct imputation of sparse constraints via `x̃^t = m ⊙ x_tgt + (1-m) ⊙ x^t`. A latent representation would complicate constraint specification.  
Quick check: Why is a global (world-space) joint rotation representation advantageous for supporting sparse rotation constraints compared to a parent-relative (local) representation like SMPL?

**Two-Stage Training Curriculum**  
Why needed: The model is first pre-trained on text-only generation (500k steps) to establish a strong motion prior, then fine-tuned on a mix of text and constraint patterns (500k steps). This curriculum ensures the denoiser learns natural motion distributions before specializing in precise constraint satisfaction.

## Architecture Onboarding

**Component map:** Data Loader & Augmenter → Motion Encoder (Imputation) → Conditioning Encoder → Root Denoiser → Root-to-Local Converter → Body Denoiser → Output Assembly → Loss Calculator → Sampler (DDIM)

**Critical path:** The core innovation and performance hinge on the interleaved two-stage denoiser: Stage 1 predicts global root, which is converted to local root and fed to Stage 2 to predict body motion. This flow must preserve alignment between root and body predictions at every diffusion step. The smoothed root representation and imputation conditioning are prerequisites for accepting sparse constraints effectively.

**Design tradeoffs:**  
- Global vs. Local Root: Stage 1 uses global root to directly handle sparse constraints, but global root is not invariant to heading flips. Converting to local for Stage 2 provides invariance at the cost of added complexity.  
- Extra Tokens (P=49 zero tokens): They boost capacity and expressiveness without extra parameters but slightly increase compute.  
- Phased Curriculum: Pre-training on text-only builds a strong prior, but risks ignoring constraints during fine-tuning if the mix is unbalanced; the 10% text dropout in Phase 1 and its removal in Phase 2 are critical design choices.

**Failure signatures:**  
- High foot skate: likely due to disabling smoothed root or using global root in Stage 2.  
- Poor constraint accuracy: could be insufficient constraint diversity, broken imputation (mask not applied), or failed curriculum.  
- Mode collapse / low diversity: from excessive text dropout, lack of stochasticity in sampling, or training on repetitive subsets.  
- Heading/rotation discontinuities: from missing first-frame heading augmentation.

**First 3 experiments:**  
1. **Ablate the Two-Stage Design:** Train a single-stage model with matched parameter count; compare foot skate and full-body constraint error against Kimodo. Expect worse metrics, confirming decomposition's utility.  
2. **Validate Smoothed Root:** Replace smoothed root with raw pelvis projection in the same architecture. Generate motions with straight-line root constraints; measure 2D pelvis deviation and foot skate. Expect higher errors and qualitatively unnatural "stealthy" gaits.  
3. **Test Scaling Sensitivity:** Train a small model (56M params) on 10% of the data (70h) with small batch size. Measure drops in R@3, FID, and constraint errors. Expect significant degradation, confirming data diversity importance.

## Open Questions the Paper Calls Out

**1. Integration of large-scale low-quality video data with high-quality mocap**  
*Basis:* Future Challenges: scaling up with internet video data.  
*Why unresolved:* Existing models rely on clean mocap; mixing noisy videos risks artifacts; effective fusion strategies unknown.  
*What evidence:* Train models on varying mixtures of Bones Rigplay and video-derived motions (e.g., Motion-X), evaluate trade-offs in FID, constraint errors, foot skate; explore data weighting or curriculum methods.

**2. Architectural modifications for real-time, reactive motion generation**  
*Basis:* Future Challenges: robotics and digital twins require runtime dynamic control.  
*Why unresolved:* Diffusion models are iterative and slow (seconds), unsuitable for real-time; latent/autoregressive alternatives for high-quality controllable motion are unproven.  
*What evidence:* Implement Kimodo variants in latent space or with autoregressive decoding; quantify inference latency (<100ms) while maintaining quality/control; benchmark in interactive simulation or real robot tasks.

**3. Collecting or synthesizing large-scale motion data with rich scene/object interactions**  
*Basis:* Future Challenges: scene and object interactions are crucial but data scarce.  
*Why unresolved:* Existing datasets (Bones Rigplay) focus on isolated motions; scalable capture or creation of interactive human-scene data remains unsolved.  
*What evidence:* Develop new capture setups (VR, multi-camera) or synthetic pipelines with physics simulation to produce interactive motion datasets; evaluate whether models generate more plausible interactions via human studies or task-specific metrics.

**4. Sufficiency of current evaluation metrics**  
*Basis:* Section 6.3: Authors note R-Precision/FID are insensitive to fine-grained motion variations affecting control accuracy.  
*Why unresolved:* Over-reliance on these metrics may overlook subtleties critical for control; discrepancies between metric scores and actual control performance are not understood.  
*What evidence:* Correlate metric scores with human evaluations of naturalness and constraint adherence; design new metrics quantifying local motion smoothness, joint deviation, or constraint violations; test correlation across diverse models and datasets.

## Limitations
- Proprietary Bones Rigplay dataset (700h) and unspecified data augmentation (LLM paraphrasing, motion stitching) prevent faithful replication.
- Incomplete specification of key architectural hyperparameters (MLP ratios, dropout rates, DDIM schedule) and exact integration of extra tokens requires reverse-engineering.
- Weak external evidence: neighboring papers (KinMo, etc.) explore related kinematic representations but do not directly validate Kimodo's specific smoothed root or two-stage denoiser mechanisms.

## Confidence
- Smoothed root representation efficacy: Medium (supported by internal ablation but lacking external corroboration; break condition not explicitly tested).
- Two-stage denoiser decomposition: Medium (backed by "Second Stage Global" ablation, but no matched single-stage baseline comparison).
- Scaling laws (data, model, batch): High (monotonic improvements thoroughly documented; moderate support from neighbor papers).
- Full reproducibility of results: Low (due to proprietary data and underspecified implementation details).
