# ContiGuard: A Framework for Continual Toxicity Detection Against Evolving Evasive Perturbations

## Quick Facts
- arXiv ID: 2603.14843
- Source URL: https://arxiv.org/abs/2603.14843
- Reference count: 40
- Primary result: ContiGuard achieves 86.47% average accuracy across nine evolving text perturbation types, significantly outperforming existing toxicity detectors.

## Executive Summary
Static toxicity detectors fail against evolving evasive perturbations (e.g., homoglyphs, character repeats) that corrupt semantics and introduce noise. ContiGuard addresses this as a domain‑incremental learning problem, where each new perturbation type constitutes a new domain. It combines three novel strategies: (1) LLM‑powered semantic enrichment to inject recovered meaning into perturbed text, (2) discriminability‑driven feature learning that amplifies critical features and suppresses non‑critical ones via attribution analysis, and (3) historical capability replay with feature alignment to mitigate catastrophic forgetting. On the constructed DynEscape dataset (nine perturbation types, ~2.5 K training samples each), ContiGuard attains 86.47% average accuracy after learning all domains, with strong generalization to the NoisyHate dataset.

## Method Summary
ContiGuard builds upon a BERT‑base encoder with a two‑layer classification head. It processes inputs sequentially as new perturbation types emerge. For each perturbed text, an LLM (gpt‑4o‑mini) generates auxiliary clues about possible original meaning and toxicity hints using a How‑Why‑What prompting scheme; these clues are dynamically merged with the perturbed text. The combined input is fed to BERT to extract features. Discriminability‑driven learning applies integrated gradients to measure feature contributions; features with high discriminative power are globally flipped (enhanced), while non‑discriminative features are unlearned toward a uniform distribution. To prevent forgetting, a memory buffer stores top‑k samples from previously learned domains; during training on a new domain, the current model’s features for these memory samples are aligned with those of the old model via cosine similarity. The total loss combines classification loss, discriminability losses (weighted by λ), and alignment loss (weighted by γ). Training uses AdamW (LR=2e‑5), early stopping, and runs on an A800 GPU.

## Key Results
- Average accuracy 86.47% at T9 (after nine domains) on DynEscape, with a maximum relative drop of 35.8% compared to baselines.
- Ablation studies confirm the contribution of each component; LLM enrichment and discriminability learning are particularly effective.
- Cross‑dataset evaluation on NoisyHate shows robust generalization, maintaining high performance.

## Why This Works (Mechanism)
The three strategies synergistically tackle core challenges: LLM enrichment restores semantic information corrupted by perturbations, leading to more stable gradients and meaningful feature extraction. Discriminability‑driven learning explicitly shapes the feature space: attribution identifies which features the model relies on, flipping amplifies toxic signals, and unlearning reduces noise from non‑discriminative tokens. Historical replay with feature alignment preserves representations of past domains, directly combating catastrophic forgetting. Together, they enable the model to adapt to new evasion tactics while retaining competence on earlier ones.

## Foundational Learning
- **Domain‑incremental learning** – Treats each perturbation type as a separate domain that arrives sequentially; needed because static training cannot adapt to evolving attacks. *Quick check*: Verify accuracy on early domains does not degrade after learning later ones.
- **Integrated gradients for attribution** – Computes feature importance scores; needed to identify discriminative vs. non‑discriminative features. *Quick check*: Confirm that high‑attribution tokens correlate with semantic toxicity cues.
- **LLM‑based semantic enrichment** – Uses prompting to recover original meaning; needed to counteract semantic corruption from perturbations. *Quick check*: Human evaluation of enriched texts should show plausible reconstruction.
- **Feature flipping and unlearning** – Explicitly modifies feature distributions; needed to enhance toxic signals and suppress noise. *Quick check*: Inspect feature histograms to see increased separation between toxic and non‑toxic samples.
- **Historical replay with feature alignment** – Stores memory samples and aligns features; needed to retain past knowledge. *Quick check*: Measure retention rate on old domains; should remain high when replay is active.

## Architecture Onboarding
- **Component map**: Perturbed text -> LLM Enricher -> Enriched text -> BERT Encoder -> Feature vector -> Discriminability Module (Flipping/Unlearning) -> Adjusted features -> Classifier -> Toxicity prediction. Memory buffer interacts with Discriminability Module and Feature Alignment during training.
- **Critical path**: (1) For a new domain, (2) enrich all samples via LLM, (3) extract features via BERT, (4) compute discriminability losses to reshape features, (5) select memory samples from previous domains, (6) align memory features between current and old model, (7) backpropagate total loss, (8) update model.
- **Design tradeoffs**: LLM enrichment improves semantics but adds latency and non‑determinism; discriminability learning risks over‑suppression of useful features; memory size limits storage and alignment cost; alignment strength (γ) trades off plasticity vs. stability.
- **Failure signatures**: Catastrophic forgetting (accuracy drop on early domains), LLM API failures, feature collapse (all features flipped/unlearned, degrades classification), memory misalignment (negative transfer, increased loss).
- **First three experiments**: (1) Ablate each of the three strategies individually to quantify their isolated impact; (2) Vary memory buffer size (k) to observe the trade‑off between forgetting and computational overhead; (3) Train with different perturbation orders to evaluate order‑sensitivity.
