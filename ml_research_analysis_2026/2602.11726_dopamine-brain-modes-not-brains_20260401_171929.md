# Dopamine: Brain Modes, Not Brains

## Quick Facts
*   **arXiv ID:** 2602.11726
*   **Source URL:** https://arxiv.org/abs/2602.11726
*   **Reference Count:** 16
*   **Primary Result:** TauGate achieves specialized accuracy (0.850±0.010) on a rotated MNIST mode using only 512 trainable parameters, trading some accuracy for fewer parameters and an interpretable neuron-gating mechanism compared to LoRA.

## Executive Summary
This paper introduces TauGate, a parameter-efficient fine-tuning (PEFT) method that adapts a frozen neural network by learning per-neuron activation thresholds and gains instead of modifying weights. This approach enables explicit, interpretable conditional computation by gating which pre-existing features in the base model are active for a target task. In a proof-of-concept on a multi-mode MNIST foundation model, TauGate specializes to a rotated digit mode with just 512 parameters, achieving competitive accuracy to LoRA while producing sparse, "which-neurons-fire" activation patterns.

## Method Summary
TauGate freezes all backbone weights and introduces two small, trainable parameters per neuron in selected layers: a threshold (τ) and a gain (γ). During a forward pass, a neuron's pre-activation `z` is adjusted: `gate = σ(s·(z−τ))`, where `s` is a sharpness scalar. The final output is `h = (γ ⊙ ϕ(z)) ⊙ gate`, with `ϕ` as the base activation (e.g., ReLU). A sparsity penalty `λ * E[mean(gate)]` encourages low mean gate activity. At inference, gates can be hardened to a binary mask `1[z > τ]`, explicitly selecting a task-specific subnetwork. The method assumes the frozen foundation model already contains features relevant to the new task; adaptation is a process of selection and reweighting.

## Key Results
*   On a foundation MLP pretrained on mixed (0° and 45°) MNIST, TauGate specialized to the 45° mode, improving test accuracy over the frozen baseline (0.850±0.010 vs. 0.833±0.016) with only 512 trainable parameters.
*   An ablation showed gain modulation (`γ`) accounts for nearly all the accuracy improvement, while threshold tuning (`τ`) primarily provides the gating semantics and sparsity.
*   With sparsity regularization, the method achieved partial activation sparsity, with only ~28% of units strongly active (gate value > 0.9) on the specialized task.

## Why This Works (Mechanism)
### Mechanism 1
*   **Claim:** TauGate adapts by learning per-neuron thresholds that select which pre-existing features in the frozen backbone participate in the target mode.
*   **Mechanism:** A learnable τ shifts the pre-activation distribution `z`. The gate `g = σ(s(z−τ))` softly masks the neuron's output. A hard gate at inference (`1[z > τ]`) creates a clear, task-specific subnetwork.
*   **Core Assumption:** The frozen backbone contains neurons whose activation patterns are useful for the target mode; adaptation requires selection, not new feature creation.
*   **Break Condition:** The backbone lacks neurons with activation patterns relevant to the target mode.

### Mechanism 2
*   **Claim:** Per-neuron gain parameters (`γ`) are the primary driver of accuracy improvement, rescaling the output of selected neurons.
*   **Mechanism:** The gain `γ` multiplies the activated neuron output after gating, allowing fine-grained reweighting of features deemed important by the threshold.
*   **Core Assumption:** The raw magnitude of useful features in the base model is suboptimal for the new task and can be corrected multiplicatively.
*   **Break Condition:** Base model feature magnitudes are already well-calibrated for the target mode.

### Mechanism 3
*   **Claim:** A sparsity penalty on mean gate activity induces interpretable, partial activation sparsity.
*   **Mechanism:** The loss term `λ * E[mean(g)]` encourages gates to be low on average. When hardened, this results in a minority of units being active per input.
*   **Core Assumption:** Sparse, mode-specific activation patterns exist within the frozen model and can be encouraged without significant accuracy loss.
*   **Break Condition:** The target task requires a dense, distributed representation where most neurons must be active.

## Architecture Onboarding
*   **Component map:**
    Frozen Backbone (weights W, biases b) -> Compute z = W·h_prev + b -> Apply Gate: g = σ(s(z−τ)) -> h = (γ ⊙ ϕ(z)) ⊙ g -> Output
*   **Critical path:**
    1. Forward: Compute frozen `z` from backbone.
    2. Gate: Apply smooth gate `g` to `ϕ(z)`, scaled by `γ`.
    3. Loss: Task loss + sparsity penalty `λ Σₗ E[mean(gₗ)]`.
    4. Backward: Gradients update only `τ` and `γ`; backbone weights are frozen.
*   **Design tradeoffs:**
    *   **Expressivity vs. Interpretability/Params:** Threshold/gate tuning is less expressive than LoRA's weight deltas but provides clear "which units" attribution and far fewer parameters.
    *   **Sparsity vs. Accuracy:** Higher `λ` increases sparsity but risks discarding necessary features.
    *   **Gate Sharpness (s):** High `s` approximates hard gates (clear subnetwork) but risks vanishing gradients; low `s` eases optimization but blurs attribution.
*   **Failure signatures:**
    *   **No accuracy gain over frozen baseline:** Frozen backbone lacks relevant features for the target mode.
    *   **Gradient vanishing/exploding:** Caused by extreme `τ` initialization or inappropriate `s`. Monitor gate saturation.
    *   **High sparsity with severe accuracy drop:** `λ` is too large, pruning critical units.
    *   **"Gain Only" matches full TauGate:** As in MNIST ablation, indicates thresholds provide semantics, not accuracy, in that setting.
*   **First 3 experiments:**
    1. Replicate the MNIST rotation specialization experiment (`run_mnist_rotation_peft.py --foundation-mix --rotation-degrees 45`), verifying TauGate improves rotated accuracy over frozen and achieves ~28% high-activation fraction.
    2. Ablate components ("Gain Only" vs. "Tau Only" vs. full) to confirm gain drives accuracy and thresholds drive sparsity/semantics.
    3. Inspect learned gates: compute histogram of gate values on a held-out batch, visualize `τ` and `γ` distributions, and test inference with hard gates for accuracy and potential FLOPs reduction.

## Open Questions the Paper Calls Out
*   **Scalability:** Does TauGate maintain its advantages on large-scale transformers (e.g., NLP, vision) compared to LoRA? The current evaluation is on a small MLP.
*   **Contextual Thresholds:** How can τ be made dynamic (prompt- or task-dependent) to enable multi-mode switching in a single model without interference?
*   **Inference Speedups:** Can the observed sparse activation patterns be leveraged on hardware with sparse kernels to yield measurable runtime improvements?

## Limitations
*   **Generalization:** Evaluation is limited to a small MLP on a synthetic MNIST rotation task; applicability to large models and real-world tasks is unproven.
*   **Backbone Dependence:** Performance relies on the frozen foundation model containing relevant features; if not, TauGate fails.
*   **Interpretability Unverified:** Reported sparsity (28% active units) is not validated to correspond to semantically meaningful neuron selectivity.

## Confidence
*   **Parameter-efficient accuracy gain:** High (direct experimental comparison).
*   **Gain modulation as primary accuracy driver:** Medium-High (strong internal ablation on one task).
*   **Sparse, interpretable gating:** Medium (sparsity demonstrated, semantic interpretability not assessed).
*   **Broader applicability to transformers:** Low (no evidence beyond MLP).
*   **Hyperparameter choices:** Medium (results are reported but key values like `s` and `λ` are not specified in the main text).
