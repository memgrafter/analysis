# TAP-SLF: Parameter-Efficient Adaptation of Vision Foundation Models for Multi-Task Ultrasound Image Analysis

## Quick Facts
- **arXiv ID**: 2603.00433
- **Source URL**: https://arxiv.org/abs/2603.00433
- **Reference count**: 0
- **Primary result**: Achieved 5th place on the FMC UIA 2026 Challenge test set using only 6.8% trainable parameters, with superior segmentation, classification, detection, and regression performance on the released training split.

## Executive Summary
TAP-SLF is a parameter-efficient fine-tuning framework for multi-task ultrasound image analysis that adapts the Florence-2 vision foundation model. It introduces task-specific soft prompts for segmentation, classification, and regression tasks while excluding them from detection to maintain spatial alignment. Adaptation is performed via LoRA applied selectively to the top 30% of encoder layers, freezing the bottom 70%. This approach yields high performance with minimal trainable parameters (6.8%), demonstrated on the FMC UIA 2026 dataset.

## Method Summary
The method adapts Florence-2’s DaViT encoder for four tasks: segmentation, classification, detection, and regression. For segmentation, classification, and regression, learnable soft prompts (length 10) are prepended to image patch tokens; detection uses no prompts. LoRA (rank 8, scale 16) is applied only to the query, key, value, and output projections of the top 30% encoder blocks; the remaining layers are frozen. Task-specific heads are used: a Feature Pyramid Network (FPN) decoder processes multi-scale features from the last four encoder blocks for dense tasks (segmentation, detection), while a Global Average Pooling (GAP) layer followed by a linear head handles global tasks (classification, regression). The model is trained jointly with equal task weights using AdamW (lr=1e-4, weight decay=1e-4) for 100 epochs.

## Key Results
- Segmentation: DSC 0.9423 (vs. baseline 0.7203)
- Classification: AUC 0.9038
- Detection: mIoU 0.6867
- Regression: Mean Radial Error (MRE) 22.98 (vs. baseline 60.17)
- Parameter efficiency: Only 6.8% of parameters are trainable.

## Why This Works (Mechanism)
The approach works by combining targeted, lightweight adaptations that preserve the foundation model’s pretrained knowledge while enabling task specialization. Freezing the bottom 70% of encoder layers retains low-level visual features robustly learned during pretraining. Selective LoRA on the top 30% layers allows high-level semantic features to adapt efficiently to medical ultrasound without overfitting. Task-specific soft prompts inject minimal, learnable signals that guide the shared encoder toward each task’s objective without altering core representations. Excluding prompts from detection prevents corruption of spatial correspondence critical for localization. Joint training leverages shared representations across tasks, improving data efficiency.

## Architecture Onboarding
**Component Map**  
Input Image (256x256) -> Task-Specific Prompt Prep -> DaViT Encoder (Top 30% with LoRA, Bottom 70% frozen) -> Feature Extraction (last 4 blocks) -> Task Heads (FPN for seg/det, GAP+Linear for cls/reg) -> Task Outputs

**Critical Path**  
1. Image resized to 256×256.
2. For seg/cls/reg: learnable prompt tokens concatenated with image patch tokens; for det: image patches only.
3. Positional embeddings extended to accommodate prompts.
4. Encoder processes tokens; only top 30% blocks have LoRA-updated attention.
5. Multi-scale features from last 4 blocks fed to FPN (seg/det) or pooled (cls/reg).
6. Task heads produce predictions; losses computed and summed.

**Design Tradeoffs**  
- *Frozen bottom layers*: Preserves pretrained low-level features but limits adaptation to new data distributions. Increasing frozen ratio may reduce overfitting but hurt performance if ultrasound differs significantly from pretraining data.
- *Prompt exclusion in detection*: Maintains spatial integrity for localization but forfeits potential task conditioning. Including prompts could improve detection if carefully implemented.
- *Joint multi-task training*: Encourages shared representations but risks task interference; equal loss weighting may imbalance tasks with different convergence speeds or difficulties.

**Failure Signatures**  
- Prompt leakage in detection: Detection performance drops if prompts are accidentally included.
- Incorrect LoRA coverage: Performance degrades if LoRA is applied to too many/few layers; expected trend: diminishing returns beyond top 30%.
- Multi-task imbalance: One task’s metrics stagnate while others improve, indicating improper loss scaling or sampling.
- Overfitting: Validation metrics deteriorate while training metrics improve, especially with higher LoRA ranks or lower frozen ratios.

**First 3 Experiments**  
1. **Detection prompt ablation**: Run detection with and without prompts; performance should degrade if prompts are mistakenly included in the detection forward pass.
2. **LoRA coverage audit**: Vary the percentage of top layers adapted (10%, 30%, 50%, 70%) and measure segmentation/classification performance to confirm the 30% optimum.
3. **Per-task loss monitoring**: During joint training, log individual task losses; if any task shows negligible decrease, adjust loss weights or implement gradient surgery.
