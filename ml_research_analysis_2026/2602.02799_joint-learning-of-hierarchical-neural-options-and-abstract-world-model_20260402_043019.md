# Joint Learning of Hierarchical Neural Options and Abstract World Model

## Quick Facts
- **ArXiv ID:** 2602.02799
- **Source URL:** https://arxiv.org/abs/2602.02799
- **Reference Count:** 40
- **Primary Result:** AgentOWL masters a higher fraction of goal-conditioned options in OCAtari games using far fewer environment steps than baselines by jointly learning an abstract world model and hierarchical neural options.

## Executive Summary
AgentOWL introduces a framework for sample-efficient hierarchical reinforcement learning by jointly learning an abstract world model and a library of neural options. The world model (PoE-World) uses symbolic experts and a frame axiom prior to predict abstract state transitions, enabling planning over long horizons with few imagined steps. An LLM proposes new sub-goals to bootstrap the option hierarchy when planning fails, while a stabilized hierarchical DQN trains option policies without collapse from non-stationary sub-policy updates. Evaluated on three challenging OCAtari games, the approach achieves superior mastery of goal-conditioned options with markedly lower sample complexity compared to strong baselines. Ablations confirm the necessity of LLM-guided sub-goal proposals and the stabilization mechanism.

## Method Summary
The method centers on a cyclic interaction between a symbolic abstract world model and a growing hierarchy of neural options. The world model, implemented as a Product-of-Experts (PoE-World), predicts transitions between abstract states defined by goal predicates. It conditions on the full environment state but outputs changes only for goals relevant to a given option, leveraging a frame axiom prior to incorporate domain knowledge. When a high-level goal lacks viable sub-options, an LLM suggests a new sub-goal to serve as a stepping stone, instantiating a new option and its corresponding world model component. Option policies are trained with a stabilized hierarchical DQN that filters out experience trajectories containing unstable sub-options, preventing destabilizing feedback loops. The agent alternates between improving the world model from real interactions and training policies using a mix of model-based imagination and model-free execution.

## Key Results
- AgentOWL masters a significantly higher fraction of tested goal-conditioned options in Montezuma’s Revenge, Pitfall, and Private Eye compared to baselines (e.g., Option-Critic, DreamerV3, MT-HRL).
- Achieves this mastery with two orders of magnitude fewer environment steps than the strongest prior methods.
- Ablations show that removing LLM sub-goal proposals or the stabilization filter leads to substantial performance degradation, confirming their critical roles.
- The approach demonstrates zero-shot generalization to novel start states and implicit improvement of sub-options during parent-goal training.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Joint learning of a temporally and state-abstracted world model with hierarchical options enables sample-efficient planning over long horizons.
**Mechanism:** The abstract world model predicts the outcome of executing a high-level option in a single step by using symbolic experts and a frame axiom prior. This abstracts away low-level temporal redundancy, allowing a planner (or learned policy, π_wm) to evaluate sequences of options with few imagined steps. The model conditions on the full state *s* but predicts only abstract features *f'* tied to goal predicates, creating a "compressed" Semi-MDP model.
**Core assumption:** The state abstraction *f(s)* (goal predicates) is sufficient to predict relevant option effects; low-level unpredictability is masked by conditioning on the full current state.
**Break condition:** If the abstract state fails to capture necessary state for planning (e.g., hidden objects not in goal predicates), chained option execution degrades because the model cannot condition on missing critical features.

### Mechanism 2
**Claim:** LLM-guided sub-goal proposal bootstraps the expansion of the option hierarchy by hypothesizing useful preconditions for new options, avoiding random exploration in high-dimensional action spaces.
**Mechanism:** When planning for a target goal *g* fails because no existing sub-option is stable or effective, an LLM is prompted with the current state and list of achieved goals to suggest a sub-goal *h* as a stepping stone. A new option *o_{h→g}* is instantiated with a randomly initialized policy, and its hypothetical model is added to the world model. This focuses subsequent learning on a promising sub-task.
**Core assumption:** The LLM, given diverse examples and a sampled state, can propose a *h* that is a necessary or highly useful precondition for *g* in the current dynamics.
**Break condition:** LLM suggests irrelevant or impossible preconditions, wasting samples. The paper notes this risk but does not quantify suggestion quality.

### Mechanism 3
**Claim:** Stabilized hierarchical DQN, which only updates option policies with data from episodes where all executed sub-options are "stable," prevents non-stationarity collapse during joint learning of a growing option set.
**Mechanism:** Training a lower-level option changes the MDP seen by higher-level options. To avoid destabilizing higher-level policies with data from poorly trained sub-options, the algorithm discards entire episodes if any sub-option executed has fewer than *n* samples or a goal completion rate below *δ*. This ensures higher-level policies bootstrap only from reliable subordinates.
**Core assumption:** An option with enough samples (*n*) or high success rate (*δ*) provides a reasonably stationary sub-policy; ignoring data from unstable subordinates allows higher-level convergence.
**Break condition:** If a parent option intrinsically requires a sub-option that is hard to stabilize (needs many samples to reach *δ*), the filter may permanently exclude data containing that sub-option, starving the parent of learning signal.

## Foundational Learning
- **Options Framework (Sutton et al., 1999):** Formalizes skills as options (policy + termination condition) that can call other options. Needed to understand the hierarchical skill structure and call-and-return execution. Quick check: What does it mean for an option's policy to be "call-and-return" in this context?
- **State & Temporal Abstraction:** The world model abstracts state to goal predicates and abstracts time to option duration, making planning tractable. Confusing this with simple feature selection breaks the modeling assumption. Quick check: Why does the abstract world model predict *f'* conditioned on full state *s*, rather than on abstract state *f*?
- **Product-of-Experts (PoE) World Models:** AgentOWL's world model efficiency comes from PoE-World's use of symbolic programs as experts with sparse weight learning. This is non-standard compared to neural dynamics models. Quick check: How does the frame axiom prior (Gaussian weight priors) incorporate domain knowledge into the PoE structure?
- **Hierarchical Reinforcement Learning Instability:** The "change-of-variable" problem—training lower-level policies alters the MDP seen by higher levels—motivates the stabilization mechanism. Quick check: In the algorithm, why is an episode discarded if any sub-option has a success rate below the threshold?

## Architecture Onboarding
- **Component map:** World Model Module (PoE-World) -> Option Library (Ω) -> LLM Sub-Goal Proposer -> Hierarchical DQN Trainer (manages buffers, stabilization, ϵ-annealing) -> Policy Networks (π_real, π_wm). The world model and option library co-evolve; the LLM proposer adds new options to the library and models to the world model; the trainer orchestrates learning and execution.
- **Critical path:** Main loop: 1) Check if target goal is mastered. 2) If not and no stable sub-options exist, use LLM to add new sub-option and its world model. 3) Train π_wm from scratch in the abstract world model. 4) Train hierarchical π_real using stabilized DQN, with exploration mixing π_real and π_wm. 5) Update world model with all new transitions via PoE-World MLE/MAP.
- **Design tradeoffs:** 
  - Symbolic vs. Neural Abstraction: Using PoE-World requires symbolic state (OCAtari), sacrificing pixel generality for sample efficiency. A neural world model would need more data.
  - LLM as proposer vs. oracle: LLM proposals are heuristic and unverified; they can introduce bad options that waste samples. The paper uses a simple filter but doesn't validate outputs.
  - Separate π_wm and π_real: Maintaining two policies increases compute but provides robustness to model bias. Could share weights, but paper says no.
  - Per-option replay buffers: Simpler implementation (no interference) but less sample-efficient than a shared buffer. Authors note this as future work.
- **Failure signatures:** 
  - World model predicts failure (*f'=0*) for all states for an option -> experts poorly generated or weights stuck at prior.
  - Stabilization filter discards all episodes for a high-level option because it always uses an unstable sub-option -> parent never trains.
  - LLM repeatedly proposes the same ineffective sub-goal -> prompt lacks diversity.
  - π_real fails to improve despite π_wm working -> exploration anneals too fast or model bias misleads π_real.
- **First 3 experiments:** 
  1. Validate world model prediction: Train on a simple goal transition, sample states, and check if *pₒ(f'=g_o=1|s)* is high for the correct goal and near 0.5 for unrelated goals.
  2. Test sub-goal proposal diversity: For a target goal, run the LLM proposer 10 times with different state samples. Compute proposal entropy; low entropy indicates poor diversity.
  3. Stress test stabilization: Train with *n_threshold=0* and *δ_threshold=0* on Pitfall. Compare learning curves of a mid-level option (e.g., "get key") to the stabilized version. Expect unstable, non-monotonic performance without stabilization.

## Open Questions the Paper Calls Out
- How to validate the quality and diversity of LLM-proposed sub-goals? The paper does not measure success rates of proposals.
- What are the exact failure modes when the symbolic abstraction is insufficient? The reliance on goal predicates is a strong assumption.
- Can per-option replay buffers be replaced with a shared buffer without harming stability? The authors suggest this as future work.
- How does the approach scale to environments without readily available symbolic state representations?

## Limitations
- The method depends on a predefined set of symbolic goal predicates, limiting applicability to domains without such abstractions (e.g., pixel-based observations).
- LLM sub-goal proposals are heuristic and unvalidated; poor proposals can waste significant exploration budget.
- The stabilization mechanism may permanently exclude learning signals for parent options that inherently require hard-to-stabilize sub-tasks, potentially limiting scalability.

## Confidence
- **Joint abstract world model + hierarchical options enables sample-efficient planning:** Medium. Strong internal evidence (ablations, design) but relies on symbolic state; no pixel-domain tests.
- **LLM-guided option expansion is a key contributor:** Low. Contribution confirmed by ablation, but the mechanism is heuristic with unvalidated output quality.
- **Stabilization prevents hierarchical collapse:** High. Clear ablation and algorithmic rationale align with known HRL instability issues.

## Next Checks
1. **Test world model on "hidden variable" states:** In Montezuma, generate states where a critical object (e.g., key) exists but is off-screen (not in goal predicates). Measure prediction accuracy *pₒ(f'|s)* for options requiring that object.
2. **Analyze LLM proposal diversity & utility:** Log all LLM-proposed sub-goals for a target *g* across 100 runs. Compute (a) proposal entropy and (b) eventual success rate of options instantiated from each proposal.
3. **Measure stabilization-induced starvation:** For a high-level option (e.g., "complete room 2"), track the fraction of its training episodes discarded due to sub-option instability over time. A persistently high discard rate (>80%) suggests the parent is starved of signal.
