# Uni-FinLLM: A Unified Multimodal Large Language Model with Modular Task Heads for Micro-Level Stock Prediction and Macro-Level Systemic Risk Assessment

## Quick Facts
- **arXiv ID:** 2601.02677  
- **Source URL:** https://arxiv.org/abs/2601.02677  
- **Reference count:** 12  
- **Primary result:** Uni-FinLLM unifies micro- and macro-financial modeling, achieving 67.4% stock directional accuracy (vs. 61.7%), 84.1% credit-risk accuracy (vs. 79.6%), and 82.3% macro early-warning accuracy.

## Executive Summary
Existing financial models treat micro-level stock prediction and macro-level systemic risk assessment as separate tasks, missing cross-scale dependencies. This work proposes Uni-FinLLM, a unified multimodal LLM using a shared Transformer backbone with modular task heads to jointly process text, numerical time series, fundamentals, and visual data via cross-modal attention. The model significantly outperforms baselines on three key tasks, demonstrating that a single framework can effectively capture interactions between individual asset movements and system-wide stability.

## Method Summary
Uni-FinLLM processes four modalities: financial text (via FinBERT), numerical time series (temporal attention), macroeconomic indicators (MLP), and financial networks (GAT). A shared Transformer backbone aligns these modalities through cross-modal attention and a contrastive loss. Three modular task heads—an autoregressive decoder for stock forecasting, a classifier for credit risk, and a GNN-based early-warning module for systemic risk—are built atop the backbone. Training occurs in four stages: unimodal pretraining, multimodal alignment, multi-task joint optimization with weighted losses, and reinforcement learning fine-tuning that adds a systemic-risk penalty to the reward.

## Key Results
- Stock directional accuracy: **67.4%** (baseline 61.7%)  
- Credit-risk accuracy: **84.1%** (baseline 79.6%)  
- Macro early-warning accuracy: **82.3%**

## Why This Works (Mechanism)
### Mechanism 1: Shared Multimodal Transformer Backbone
- **Claim:** A shared multimodal Transformer backbone jointly learns a coherent representation from heterogeneous financial data (text, time series, fundamentals, graphs), enabling cross-scale pattern capture.  
- **Mechanism:** Cross-modal attention layers align disparate modalities (e.g., news sentiment, price volatility, network centrality) into a unified embedding space. This shared representation allows knowledge transfer between micro-level (stock) and macro-level (systemic) tasks, as the same latent features inform multiple prediction heads.  
- **Core assumption:** Financial phenomena from asset price movements to system-wide stress exhibit latent dependencies that can be synthesized into a single representation space without catastrophic interference.  
- **Evidence anchors:**  
  - [abstract] "jointly process financial text, numerical time series, fundamentals, and visual data... learns a coherent representation for micro-, meso-, and macro-level predictions."  
  - [section 3.1] Describes the Transformer backbone and contrastive alignment objective (Eq. 3) that enforces semantic proximity across modalities.  
  - [corpus] Weak/absent direct evidence; neighboring papers explore similar fusion but do not validate cross-scale transfer.  
- **Break condition:** If cross-modal attention fails to align semantically related features (e.g., a negative news event and a concurrent price drop), the unified representation loses coherence, degrading all task performance. Empirically, this would manifest as performance gains from multimodal fusion that vanish under controlled ablation of one modality.

### Mechanism 2: Modular Task Heads
- **Claim:** Modular task heads (micro-prediction, macro-risk, policy assistant) built atop the shared backbone enable task-specific specialization while leveraging common representations, preventing negative transfer.  
- **Mechanism:** Each head (e.g., autoregressive decoder for stock forecasting, GNN-based contagion model for systemic risk) is initialized from the shared backbone but trained with task-specific loss functions (Eq. 9). Modularity isolates parameters that optimize for distinct output distributions (e.g., directional accuracy vs. crisis F1-score), while still allowing gradient flow into the shared backbone.  
- **Core assumption:** The shared backbone can extract features general enough to support multiple, potentially conflicting, prediction objectives (e.g., short-term alpha vs. long-term stability signals).  
- **Evidence anchors:**  
  - [section 3.2] Explicitly defines three modular heads and their respective architectures.  
  - [section 4.4] Attributes performance gains to "shared representation transfer between micro-level and macro-level tasks."  
  - [corpus] Neighbors use separate experts but lack macro-micro integration; Uni-FinLLM’s *shared* backbone + *modular* heads is distinctive.  
- **Break condition:** If tasks are too dissimilar or training data is insufficiently diverse, the shared backbone may form a "compromise" representation that suboptimally serves all heads. Symptoms: marginal gains from multi-task training vs. single-task baselines, or significant performance drop on one task when another is added.

### Mechanism 3: Risk-Aware Reinforcement Learning Feedback Loop
- **Claim:** A risk-aware RL feedback loop creates a macro–micro interaction, where predictive actions are penalized if they increase simulated systemic risk, aligning model behavior with regulatory stability goals.  
- **Mechanism:** The RL reward (Eq. 7) combines micro-prediction accuracy (e.g., stock direction) with a systemic-risk penalty (e.g., estimated SRISK contribution). The policy gradient update adjusts the backbone and prediction heads to avoid actions that, while locally accurate, would propagate risk in the simulated financial network.  
- **Core assumption:** The model’s micro-level predictions can be meaningfully linked to macro-level systemic metrics via a differentiable simulation of contagion.  
- **Evidence anchors:**  
  - [section 3.3] Details the RL formulation, reward structure, and its role in forming a "macro–micro feedback loop."  
  - [section 4.4] Notes the framework’s suitability for "regulatory environments" where actions must avoid increasing systemic risk.  
  - [corpus] No direct equivalent; prior systemic-risk models lack this action-oriented, predictive integration.  
- **Break condition:** If the systemic-risk penalty term is poorly calibrated (e.g., too weak/strong), the model may ignore risk or become overly conservative. The RL loop also assumes a stable mapping from actions to systemic impact; structural market breaks could invalidate the learned penalty signal.

## Foundational Learning
- **Transformer-based multimodal fusion:**  
  *Why needed:* Aligns text, time series, and graph data via attention into a shared space.  
  *Quick check:* How would you design query/key/value projections to handle both sequential (time series) and graph (network) structural information in a single attention layer?
- **Multi-task learning with shared backbone:**  
  *Why needed:* Jointly optimizes forecasting (regression), risk classification (binary), and RL (policy) without catastrophic interference.  
  *Quick check:* What happens if the macro-risk classification loss is weighted much higher than the stock-prediction loss during joint training?
- **Risk-aware reinforcement learning:**  
  *Why needed:* Closes the loop between prediction and systemic impact via a differentiable risk penalty.  
  *Quick check:* If the systemic-risk simulator is imperfect, how might that bias the RL policy’s learning?

## Architecture Onboarding
Modal encoders (text, time series, macro, graph) → Shared Transformer backbone (cross-modal attention + contrastive alignment) → Task heads (micro decoder, macro classifier, policy LLM) → RL loop (reward = micro accuracy - λ * risk penalty) → Staged training (unimodal pretraining → alignment → multi-task → RL fine-tuning).

**Critical path:** Raw data → modality encoders → shared backbone projection → task-specific heads → multi-task loss + RL reward → weighted sum loss → backpropagation.

**Design tradeoffs:**  
- Shared backbone reduces redundancy but risks negative transfer; modular heads mitigate this but increase parameters.  
- RL adds regulatory alignment but requires a credible systemic-risk simulator and risks training instability.  
- Cross-modal attention treats all modalities similarly; specialized positional encodings may be needed for time vs. graph structure.

**Failure signatures:**  
- High micro accuracy but poor macro F1: RL penalty weight too low or systemic simulator inaccurate.  
- All tasks mediocre: Contrastive alignment loss too weak; modalities not properly aligned.  
- Training instability in RL stage: Reward scale mismatch or high variance in gradient estimates.

**First 3 experiments:**  
1. **Ablation: Unimodal vs. multimodal backbone.** Train with (a) text only, (b) time series only, (c) full multimodal. Expect: Multimodal matches/exceeds best unimodal on *all* tasks.  
2. **Head isolation test.** Freeze backbone, train only one task head at a time. Measure performance drop when adding a second head vs. training jointly. Expect: Small drop, indicating backbone generality.  
3. **RL sensitivity sweep.** Vary λ₄ (risk penalty weight) from 0 to 1. Plot micro accuracy vs. macro F1. Expect a Pareto frontier; extreme values degrade one metric.

## Limitations
- Lack of external validation for cross-scale representation coherence (Mechanism 1).  
- Reliance on an unvalidated systemic-risk simulator in the RL loop (Mechanism 3).  
- Unknown hyperparameters and data construction details (e.g., interbank graphs, visual data specification) block faithful reproduction.

## Confidence
- **Mechanism 1 (shared multimodal representation):** Medium confidence (proposed but not externally validated).  
- **Mechanism 2 (modular task heads):** High confidence (explicit architecture, supported by ablations).  
- **Mechanism 3 (RL feedback loop):** Medium confidence (novel but depends on unvalidated simulator).

## Next Checks
1. Ablate contrastive alignment loss (Eq. 3) to measure its impact on all tasks.  
2. Sweep RL penalty weight λ₄ to identify Pareto frontier between micro accuracy and macro F1.  
3. Audit for temporal data leakage using strictly chronological splits and rolling validation.
