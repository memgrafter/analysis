# A theoretical model of dynamical grammatical gender shifting based on set-valued set function
## Quick Facts
- **arXiv ID:** 2603.03510
- **Source URL:** https://arxiv.org/abs/2603.03510
- **Reference count:** 16
- **Primary result:** The paper introduces the Template‑Based and Modular Cognitive (TBMC) model, using set‑valued set functions to deterministically predict grammatical gender shifts via template reassignment.

## Executive Summary
The paper tackles the problem of inter‑word variation in grammatical gender marking, which existing semantics‑driven theories cannot uniformly explain. It proposes the Template‑Based and Modular Cognitive (TBMC) model, a formal framework that maps lexical items to morphological templates using set‑valued set functions. Gender shifts arise from dynamic template reassignment during word formation, governed by gradient conditions based on symmetric difference operations. The authors demonstrate the formal possibility of intra‑lexical conversion, define two gradient conditions that predict gender shifts, identify initial unmarked templates in Riffian, and offer a unified account for cross‑linguistic patterns in synthetic languages, challenging the separation of derivation and inflection and the notion of derivational gender affixes.

## Method Summary
The TBMC model treats morphological templates as sets of grammatical features. Lexical items are associated with a cognitive set (e.g., countable, uncountable, actions) which determines an initial unmarked template. When a lexical change (derivation or inflection) occurs, the item is reassigned to a new template via a set‑valued function. The symmetric difference between the old and new template sets is computed, and two deterministic gradient conditions decide whether the grammatical gender shifts (non‑stationary) or stays the same (stationary). The model is illustrated with Riffian data, where initial templates for different cognitive sets are empirically identified.

## Key Results
- Formal demonstration that intra‑lexical conversion (noun‑to‑noun derivation) is possible within the TBMC framework.
- Definition of two gradient conditions that deterministically predict gender shift or non‑shift after lexical change.
- Identification of initial unmarked templates for countable, uncountable, and action nouns in Riffian.

## Why This Works (Mechanism)
The mechanism hinges on representing morphological templates as sets of features. Gender shifts are triggered when the symmetric difference between the pre‑change and post‑change template sets crosses a threshold defined by the gradient conditions. Because the mapping from lexical items to templates is set‑valued and determined by the cognitive set, the model captures systematic variation in gender assignment across derived forms without positing separate derivational affixes. The use of symmetric difference provides a mathematically precise measure of template distance, allowing deterministic prediction of gender change.

## Architecture Onboarding
**Component map:**  
Lexical Item → Cognitive Set → Initial Template → Set‑valued mapping → New Template (after change) → Symmetric Difference → Gradient Condition → Gender Shift decision  

**Critical path:**  
1. Determine the cognitive set of the noun (e.g., countable).  
2. Retrieve the initial unmarked template for that set.  
3. Apply a morphological operation (derivation/inflection) that triggers reassignment.  
4. Compute the new template via the set‑valued function.  
5. Calculate the symmetric difference between old and new template sets.  
6. Evaluate the two gradient conditions to output “shift” or “no shift”.

**Design tradeoffs:**  
- *Abstraction vs. empirical detail:* The model abstracts templates to feature sets, which simplifies analysis but may overlook lexical irregularities.  
- *Binary gender assumption:* The framework treats gender as binary, which fits many synthetic languages but excludes non‑binary systems.  
- *Unmarked template identification:* Initial templates must be empirically derived per language, requiring substantial data collection.

**Failure signatures:**  
- Incorrect gender predictions for irregular or lexicalized forms.  
- Model breakdown when symmetric difference equals zero but a gender change occurs.  
- Inability to handle interactions with number, case, or definiteness that are not encoded in the template set.

**First experiments:**  
1. Reproduce the formal proof of intra‑lexical conversion using set‑theoretic notation.  
2. Manually apply gradient conditions to a selection of 20 Riffian nouns with known derivations to verify predictions.  
3. Visualize template sets for two cognitive sets (e.g., countable vs. uncountable) to explore their overlap and differences.

## Limitations
- Narrow empirical base: only Riffian data; cross‑linguistic generalizability unverified.  
- No treatment of irregular/lexicalized gender shifts; deterministic rules may not cover exceptions.  
- Cognitive set definitions lack universal justification; number, case, definiteness interactions oversimplified.

## Confidence
- Formal possibility of intra‑lexical conversion: **High**  
- Two gradient conditions for gender shift: **Medium**  
- Identification of initial unmarked templates (Riffian): **Low**  
- Unified cross‑linguistic account challenging derivational affixes: **Low**
