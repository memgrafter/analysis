# Efficient Estimation of Kernel Surrogate Models for Task Attribution

## Quick Facts
- **ArXiv ID**: 2602.03783
- **Source URL**: https://arxiv.org/abs/2602.03783
- **Reference count**: 40
- **Primary result**: Kernel surrogate models improve task attribution correlation by 25% over linear surrogates and influence functions, with estimation error <2% on models up to 34B parameters.

## Executive Summary
Task attribution seeks to measure the impact of individual training tasks on the performance of a target task. Direct leave-one-out retraining is prohibitively expensive, while linear surrogate models and influence functions fail to capture nonlinear interactions between tasks. This paper introduces kernel surrogate models that use radial basis function (RBF) kernels to represent complex, second-order task effects. To avoid repeated retraining, the authors propose GradEx, a gradient-based estimation procedure that leverages a first-order Taylor approximation of a pretrained model to predict performance on arbitrary task subsets. Across arithmetic reasoning, in-context learning, and multi-objective reinforcement learning, kernel surrogates achieve a 25% higher correlation with true leave-one-out estimates compared to linear surrogates and influence functions. For downstream task selection, they yield a 40% improvement while maintaining runtime comparable to linear models. The estimation error remains below 2% even for models with up to 34B parameters.

## Method Summary
The method constructs a kernel surrogate model to approximate the performance function \(F(s)\) over subsets \(s\) of training tasks. First, a model is pretrained on all tasks. For each sampled subset \(s^{(i)}\) (drawn via Bernoulli sampling), the authors approximate the test performance \(\hat{F}(s^{(i)})\) without retraining: they precompute model outputs and gradients on the training data, then solve a low-dimensional \(\ell_2\)-regularized regression to find a parameter perturbation \(Z^\star\) that mimics training on that subset. The linearized model \(f_{W_0}(x) + \langle \nabla f_{W_0}(x), Z^\star \rangle\) is evaluated on a test set to obtain \(\hat{F}(s^{(i)})\). After collecting pairs \((s^{(i)}, \hat{F}(s^{(i)}))\) for many subsets, a kernel ridge regression model with an RBF kernel is fitted to produce the final surrogate \(g_\theta(s)\). Task-level attributions are derived from the surrogate (e.g., by averaging influences over subsets that contain the task). This pipeline replaces costly retraining with gradient computations and efficient kernel regression.

## Key Results
- Improves correlation with leave-one-out estimates by 25% over linear surrogates and influence functions across arithmetic reasoning, in-context learning, and multi-objective RL.
- For downstream task selection, achieves a 40% improvement (lower loss or higher rewards) while keeping runtime similar to linear methods.
- Estimation error stays below 2% on models up to 34B parameters.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Linear surrogate model coefficients and influence functions both estimate the gradient of performance with respect to task weights, making them approximately equivalent when second-order task interactions are negligible.
- **Mechanism**: The performance function \(F(s)\) is expanded around the all-ones vector using a second-order Taylor series. The ordinary least squares (OLS) coefficients of a linear surrogate model are shown to equal \(\nabla_s F(s^\star)\) plus bias terms that depend on the sampling distribution and the Hessian matrix \(H_s\) of second-order interactions. If \(\|H_s\|_2\) is small, these bias terms vanish, and the linear surrogate approximates the influence function (which itself equals \(\nabla_s F(s^\star)\) because influence functions apply the chain rule to task-weight perturbations).
- **Core assumption**: The training loss landscape is nearly linear in the task-weight subspace; specifically, the spectral norm of the Hessian is bounded by a small constant \(c_2\).
- **Evidence anchors**:  
  - [abstract]: "We first consider a unified task weighting framework for analyzing task attribution methods, and show a new connection between linear surrogate models and influence functions through a second-order analysis."  
  - [section, Proposition 3.1 and Corollary 3.2]: "The surrogate coefficients \(\hat{\beta}\) recover the gradient of \(F(s^\star)\) with respect to the weights up to two terms induced by the Binomial distribution... under this first-order approximation (\(\|H_s\|_2 \le c_2\)), both methods estimate the same underlying quantity \(\nabla_s F(s^\star)\)."  
  - [corpus]: Prior work such as "Faithful and Efficient Explanations for Neural Networks via Neural Tangent Kernel Surrogate Models" also studies kernel surrogates but not the specific linear–influence equivalence; the corpus does not directly contradict this mechanism.
- **Break condition**: When the Hessian magnitude becomes large, the surrogate coefficients deviate from the gradient, missing synergistic or antagonistic effects; the linear surrogate will then poorly approximate true task influence.

### Mechanism 2
- **Claim**: Kernel surrogate models (e.g., with an RBF kernel) capture nonlinear interactions between training tasks that linear surrogates cannot, improving attribution accuracy.
- **Mechanism**: The kernel surrogate maps the discrete subset space \(\{0,1\}^K\) into a reproducing kernel Hilbert space (RKHS) using a positive-definite kernel such as the RBF: \(k(s,s') = \exp(-\gamma \|s-s'\|^2)\). The resulting function \(g(s) = \sum_i \theta_i k(s^{(i)}, s)\) is trained via kernel ridge regression on a small set of sampled subsets. This nonparametric form is universal on finite sets and can represent arbitrarily complex relationships, including second-order (pairwise) and higher-order interactions.
- **Core assumption**: The true performance function \(F(s)\) is smooth with respect to the Hamming distance between subsets; a sufficient number of sampled subsets is available to fit the kernel model.
- **Evidence anchors**:  
  - [abstract]: "Then, we introduce kernel surrogate models, which more effectively represent second-order task interactions."  
  - [section, 3.2]: "Kernel surrogates — such as those based on radial basis function (RBF) kernels — naturally capture geometric relationships in the 0–1 subset space... This enables modeling complex, non-additive task interactions."  
  - [table, Table 1]: Empirical residual errors show the RBF kernel reduces error relative to linear surrogates on multiple datasets.  
  - [corpus]: Neighbor papers like "Scalable Linearized Laplace Approximation via Surrogate Neural Kernel" and "Faithful and Efficient Explanations..." demonstrate that kernel methods are effective for surrogate modeling in related attribution settings, supporting the principle that kernels capture nonlinearities.
- **Break condition**: If the performance landscape is not locally smooth in Hamming distance (e.g., purely combinatorial XOR effects with no continuity), an RBF kernel may require many samples to approximate; also, with very few subsets the kernel may overfit due to high model complexity.

### Mechanism 3
- **Claim**: Gradient-based estimation allows efficient construction of kernel surrogates without repeatedly retraining models on different subsets, by using a first-order Taylor approximation of the model around the pretrained parameters.
- **Mechanism**: For a pretrained model with weights \(W_0\), the output on an input \(x\) is approximated as \(f_W(x) \approx f_{W_0}(x) + \langle \nabla f_{W_0}(x), Z \rangle\), where \(Z = W - W_0\) is a perturbation. For a given subset \(s^{(i)}\), we solve for \(Z^\star\) that minimizes the approximate weighted loss on that subset, using projected gradients to reduce dimensionality. The test performance \(F(s^{(i)})\) is then approximated by evaluating this linearized model on the test set. This replaces \(m\) full training runs with a single gradient computation (once per training sample) and a small regression per subset.
- **Core assumption**: The first-order Taylor residual error \(\epsilon_W(x)\) is uniformly small across the training domain and relevant perturbations, and random projection preserves inner products well enough.
- **Evidence anchors**:  
  - [abstract]: "To efficiently learn the kernel surrogate, we develop a gradient-based estimation procedure that leverages a first-order approximation of pretrained models; empirically, this yields accurate estimates with less than 2% relative error without repeated retraining."  
  - [section, 3.3]: "Consider a first-order Taylor expansion of model outputs around the initialization... This eliminates the need for repeated training and dramatically speeds up the estimation procedure, and is practical even for very large m since the estimation procedure can be executed entirely on CPUs."  
  - [table, Table 2]: Approximation errors \(\epsilon_W(x)\) are below 1% across diverse tasks and models up to 34B parameters.
- **Break condition**: If the model is highly nonlinear (e.g., after large fine-tuning) or the Hessian is large, the first-order approximation may be inaccurate, leading to errors in \(F(s^{(i)})\) estimates beyond acceptable bounds.

## Architecture Onboarding

### Component Map
Pretrained model \(f_{W_0}\) and its gradients \(\nabla f_{W_0}(x)\) → Subset sampler (Bernoulli \(p\)) → Gradient projection layer (random matrix \(P\)) → Low-dimensional regression solver → Test loss evaluator (linearized model) → Kernel matrix constructor & kernel ridge regression → Attribution extractor.

### Critical Path
1. Precompute model outputs and gradients for all training samples.
2. Sample \(m\) subsets \(s^{(i)}\) via Bernoulli distribution.
3. For each subset: project gradients to low dimension, solve low‑dimensional regression to obtain perturbation \(Z^\star\), evaluate linearized model on test set to get \(\hat{F}(s^{(i)})\).
4. Assemble dataset \(\{(s^{(i)}, \hat{F}(s^{(i)}))\}\).
5. Fit kernel ridge regression (e.g., RBF kernel) to obtain surrogate \(g_\theta\).
6. Extract task attributions from the surrogate (e.g., by marginal contributions).

### Design Tradeoffs
- **Number of subsets \(m\)**: Larger \(m\) improves surrogate accuracy but increases memory for kernel matrix and regression time.
- **Projection dimension \(k\)**: Smaller \(k\) speeds up regression but may distort inner products; typically \(k = O(\log N / \epsilon^2)\).
- **Kernel hyperparameters**: RBF width \(\gamma\) and regularization \(\lambda\) control smoothness vs. overfitting; cross‑validation is used.
- **Sampling distribution**: Bernoulli probability \(p\) influences bias/variance of linear surrogate coefficients; the paper uses \(p \approx 0.9\).

### Failure Signatures
- **High Taylor residual error** \(\epsilon_W(x)\) (e.g., >5%) indicates unreliable first-order approximation.
- **Poor correlation** (LDS) between surrogate predictions and true retrained model outputs (<0.5) suggests insufficient model capacity or too few samples.
- **Ill‑conditioned kernel matrix** (large condition number) when \(\gamma\) is too large or \(m\) too large; mitigate by increasing \(\lambda\).
- **Exploding memory usage** if the number of subsets \(m\) is huge; random projection and low‑dimensional regression keep CPU usage modest.

### First 3 Experiments
1. **Modular arithmetic reasoning** – test on addition and quadratic tasks with a small decoder‑only transformer to validate capture of XOR‑like nonlinearities.
2. **In‑context learning demonstration selection** – use Qwen3‑8B on SST‑2 and coin‑flip tasks to evaluate large‑scale language models.
3. **Multi‑objective reinforcement learning** – evaluate on Meta‑World MT10 with Soft Actor‑Critic, assessing sequential decision‑making under shifting distributions.

## Open Questions the Paper Calls Out

### Open Question 1
**Question**: Can KERNELSM be extended to attribute influence for planning or higher‑order reasoning capabilities in language models?  
**Basis in paper**: The conclusion identifies “extending our attribution framework to examine other aspects of language models such as planning abilities” as an open question, noting the current evaluation “primarily focuses on prediction tasks.”  
**Why unresolved**: The method was tested only on prediction (classification/regression) and simple RL; planning involves temporally extended decisions that may not be captured by the current formulation of \(F(s)\).  
**What evidence would resolve it**: Apply KERNELSM to a planning benchmark (e.g., ALFWorld, WebArena) where test performance depends on long‑horizon strategies, and compare attributions against leave‑one‑out task removals to validate accuracy.

### Open Question 2
**Question**: Can KERNELSM help explain the generalization gap between supervised fine‑tuning (SFT) and reinforcement learning (RL) by contrasting task influence patterns?  
**Basis in paper**: The conclusion mentions: “this approach may explain the generalization gaps between SFT and RL (Wang et al., 2025); we leave a detailed exploration of this connection to future work.”  
**Why unresolved**: The paper uses multi‑objective RL but does not directly compare with SFT or analyze why RL generalizes differently; the attribution framework has not been applied to disentangle the two training paradigms.  
**What evidence would resolve it**: Train identical model architectures on a suite of tasks using both SFT and RL objectives, compute task attributions via KERNELSM, and identify systematic differences in influential tasks that correlate with generalization performance on held‑out evaluations.

### Open Question 3
**Question**: Why do kernel surrogate models remain robust under high loss curvature (large Hessian), while linear surrogates break down?  
**Basis in paper**: Figure 3 shows linear surrogates fail with SGD (high Hessian) but kernel surrogates remain accurate across SAM/NSO regularization; the paper does not provide theoretical justification for this robustness.  
**Why unresolved**: The analysis for linear surrogates explicitly depends on a small Hessian (Proposition 3.1), but the kernel case lacks any bound relating accuracy to curvature; the empirical observation is unexplained.  
**What evidence would resolve it**: Derive error bounds for kernel surrogates that incorporate higher‑order terms, showing that the RBF kernel implicitly smooths over high‑curvature directions, or perform a controlled study varying Hessian magnitude and kernel hyperparameters to isolate the effect.

## Limitations
- Hyperparameters (λ, γ, k, p) are not fully specified; defaults may require tuning for new domains.
- The first‑order approximation in GradEx may exceed 2% error when parameter shifts are large (e.g., high Hessian), with the failure regime not fully mapped.
- The kernel smoothness assumption may break for discrete, non‑smooth task interactions (e.g., XOR), requiring many samples to achieve good approximations.
