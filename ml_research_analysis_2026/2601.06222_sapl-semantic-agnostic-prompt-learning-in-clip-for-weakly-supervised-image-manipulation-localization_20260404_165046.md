# SAPL: Semantic-Agnostic Prompt Learning in CLIP for Weakly Supervised Image Manipulation Localization

## Quick Facts
- **ArXiv ID**: 2601.06222
- **Source URL**: https://arxiv.org/abs/2601.06222
- **Reference count**: 40
- **Primary result**: SAPL achieves state-of-the-art under weak supervision, improving average I-AUC by +4.6% and P-F1 by +3.9% over prior weakly supervised methods, and surpasses fully supervised models like MVSS-Net by +9.2% in average I-AUC.

## Executive Summary
SAPL addresses weakly supervised image manipulation localization (only image-level labels) by overcoming the neglect of critical boundary-edge artifacts in existing methods. It introduces Semantic-Agnostic Prompt Learning within a CLIP framework, steering the model away from high-level object semantics toward manipulation edges. Two complementary modules enable this: Edge-aware Contextual Prompt Learning (ECPL) embeds image-specific, non-semantic edge cues into learnable text prompts; Hierarchical Edge Contrastive Learning (HECL) sharpens discrimination between genuine and manipulated edge patches via contrastive learning across multiple visual feature layers. Evaluated on five standard datasets (CASIAv1, Columbia, COVERAGE, IMD2020, NIST16), SAPL substantially outperforms prior weakly supervised approaches and even exceeds fully supervised models, demonstrating the effectiveness of edge-centric multimodal supervision.

## Method Summary
SAPL builds on a frozen CLIP ViT-L/14@336px backbone, with LoRA adapters applied to the image encoder for efficient tuning. An Adaptive Soft Edge Generator processes each input image to produce a continuous edge-weight map. ECPL then fuses this soft edge map with multi-layer patch features using a multi-head self-attention block to dynamically personalize learnable prompts (“REAL”/“FAKE”), ensuring the text embeddings carry boundary-centric, semantic-agnostic information. Meanwhile, HECL operates on selected encoder layers: it weights patch-text similarity with the soft edge map, selects high-confidence edge patches for both classes, and applies contrastive loss using dynamic dual queues that aggregate prototypes across batches. The total loss combines image-text classification (`L_cls`) and the hierarchical contrastive loss (`L_HECL`). During inference, patch-text similarity maps from all layers are aggregated to produce a pixel-level localization map, while the classification score is derived from the CLS token.

## Key Results
- State-of-the-art performance under weak supervision: +4.6% average I-AUC and +3.9% average P-F1 over prior weakly supervised methods.
- Surpasses fully supervised models (e.g., MVSS-Net) by +9.2% in average I-AUC.
- Ablation studies confirm additive contributions: ECPL (+4.6% I-AUC, +54.0% P-F1), HECL (+4.2% I-AUC, +77.8% P-F1), both together (+5.5% I-AUC, +81.8% P-F1).

## Why This Works (Mechanism)
### Mechanism 1: Edge-aware Contextual Prompt Learning (ECPL)
ECPL steers CLIP’s multimodal similarity away from high-level object semantics toward manipulation boundary artifacts by embedding image-specific, non-semantic edge cues into learnable text prompts. An Adaptive Soft Edge Generator creates a continuous edge-weight map from the image. This map, combined with multi-layer patch features via a multi-head self-attention mechanism, dynamically personalizes the learnable prompts (“REAL”/“FAKE”). The resulting text embeddings carry boundary-centric, semantic-agnostic information, causing the image-text similarity to peak at manipulated edge regions rather than semantically salient objects. Core assumption: manipulation boundaries exhibit distinct low-level statistical properties (e.g., gradient, noise variance) that are more reliable than object semantics under weak supervision.

### Mechanism 2: Hierarchical Edge Contrastive Learning (HECL)
HECL enhances the discriminative power of visual edge representations by enforcing consistency among high-confidence manipulated edge patches and separation from authentic edge patches across multiple feature depths. For selected encoder layers, a weighted similarity map (using the soft edge map) identifies top-K high-confidence edge patch features for each class. These features are projected and stored in dynamic dual queues (positive/negative). Contrastive loss attracts features to their class prototype in the queue and repels them from the opposing class prototype, hierarchically refining edge representations from coarse to fine. Core assumption: manipulation-induced edge artifacts produce patch features that are more homogeneous within the manipulated class than between classes, and this separability exists across multiple transformer layers.

### Mechanism 3: Synergistic Multimodal Supervision
The combination of ECPL (text-space edge guidance) and HECL (visual-space edge discrimination) creates complementary multimodal supervision that enables precise pixel-level localization using only image-level labels. ECPL biases the global image-text alignment toward edge regions in the textual embedding space. HECL simultaneously refines the local patch-level feature embeddings of those same edge regions via contrastive learning. The final localization map is derived from patch-text similarities influenced by both mechanisms, while the classification loss provides the weak supervisory signal. Core assumption: boundary artifacts are the most consistent and discriminative indicator of manipulation across diverse tampering types, and leveraging them in both modalities is more effective than using either alone or using non-edge features.

## Foundational Learning
- **Weak Supervision (Image-Level Labels)**
  - *Why needed*: SAPL operates in the practical scenario where only image-level binary labels (real/forged) are available. All mechanisms (prompt learning, contrastive sampling) must infer pixel-level boundaries from this coarse signal.
  - *Quick check*: Given an image labeled “manipulated” but no mask, what indirect signals can a model use to hypothesize *where* the manipulation occurred?
- **CLIP’s Contrastive Pre-training and Prompt Tuning**
  - *Why needed*: SAPL relies on CLIP’s pre-aligned image-text space. Understanding that CLIP maps images and text into a shared latent space where similarity indicates semantic match is crucial. ECPL innovates by manipulating the *text* side (prompts) to encode non-semantic cues.
  - *Quick check*: If standard CLIP prompts like “a photo of a [class]” focus on semantics, how might one modify the prompt or its embedding to make the model attend to low-level image artifacts instead?
- **Edge Detection as a Forensic Prior**
  - *Why needed*: Both ECPL (soft edge map) and HECL (patch selection) depend on the assumption that manipulation boundaries coincide with strong edge responses. Understanding how to generate and use edge maps (e.g., Canny, distance transform) is foundational.
  - *Quick check*: Why might a binary Canny edge map be insufficient for prompt generation and contrastive patch selection in this context?

## Architecture Onboarding
- **Component map**: Input Image → Adaptive Soft Edge Generator + CLIP Image Encoder (with LoRA) → ECPL module (MHSA) → Edge-aware prompts → CLIP Text Encoder (frozen) + HECL modules (per selected layer) → Combined Loss → Training. During inference: multi-layer patch features → patch-text similarity maps → aggregated localization map.
- **Critical path**: For training, an image yields a soft edge map and multi-layer patch features. ECPL fuses these to produce edge-aware text embeddings. HECL uses the soft edge map to select high-confidence edge patches per layer and applies contrastive loss with dynamic queues. The total loss (`L_cls + w(t)*L_HECL`) updates LoRA and module parameters. For inference, similarity maps from all layers are combined to produce a localization map; classification uses the highest CLS-similarity.
- **Design tradeoffs**:
  - Soft vs. binary edges: Soft edges provide continuous weighting for prompts and patch selection but require tuning of decay parameter `k`; binary maps are sparse and unstable for training.
  - Queue size (`L2`): Larger queues (e.g., 4096) improve contrastive stability but increase memory; smaller queues (256) are efficient but risk noisy prototypes.
  - Prompt length (`L1`): Longer prompts (16–20 tokens) can capture more patterns but may overfit or dilute the edge signal; shorter prompts (8) are constrained.
  - LoRA tuning: Freezing CLIP preserves pre-trained knowledge but limits adaptability; LoRA offers a parameter-efficient compromise.
- **Failure signatures**:
  - ECPL failure: Similarity maps highlight large semantic object regions instead of fine boundaries, even if classification is correct. Soft edge map is overly diffuse or misses boundaries.
  - HECL failure: t-SNE visualization shows overlapping clusters for “Real Edge” and “Fake Edge” features; contrastive loss does not decrease, and P-F1 remains low despite good I-AUC.
  - Combined failure: Model achieves image-level accuracy but produces blob-like, non-boundary localization maps; ablation shows both modules needed for best P-F1.
- **First 3 experiments**:
  1. Baseline: Train CLIP (ViT-L/14) with only LoRA on the image encoder and `L_cls` loss. Record I-AUC and P-F1 on CASIAv1/IMD2020 to establish the weak baseline.
  2. ECPL isolation: Add ECPL (with soft edge generation and MHSA) to the baseline; disable HECL. Train and evaluate. Observe improvement in P-F1.
  3. HECL isolation: Disable ECPL (use standard “a photo of a real/fake image” prompts). Add HECL with contrastive queues. Train and evaluate. Observe improvement in P-F1 and feature separation in t-SNE.

## Open Questions the Paper Calls Out
- **Global manipulations**: How can SAPL handle full-image edits (e.g., color filters) where boundary cues are absent? The current edge-centric design may fail.
- **Frequency-domain integration**: Can incorporating frequency artifacts (DCT, noise residuals) improve robustness against post-processing like JPEG compression?
- **Edge-sparse robustness**: How does SAPL perform when manipulation boundaries are blurred or degraded by noise/compression? The soft edge generator’s reliability may degrade.
- **Layer-wise contribution**: Which specific layers in HECL are most critical for edge discrimination? The paper uses layers 6, 12, 18, 24 without analyzing individual impact.
- **Zero-shot transfer**: Do the learned prompts generalize to unseen manipulation types (e.g., GAN-based edits) without retraining? The prompts might overfit to training tampering patterns.

## Limitations
- Exact LoRA hyperparameters (rank/alpha) are not specified, complicating faithful reproduction.
- Precise HECL patch selection criteria (top-K vs. threshold) and the adaptive `k` formula for the soft edge generator are ambiguous.
- Queue update protocol (enqueue/dequeue frequency, prototype aggregation) is not detailed, hindering contrastive stability.

## Confidence
- **High**: Performance claims (I-AUC/P-F1 improvements) are supported by multi-dataset experiments and ablations.
- **Medium**: Mechanistic explanations (ECPL steering, HECL refinement) rely on internal visualizations without independent validation.
- **Medium**: Generalization assumption that manipulation boundaries are consistently edge-detectable across tampering types is plausible but lacks stress‑testing on edge‑sparse cases.

## Next Checks
- Stress-test the soft edge generator: Quantify boundary recall/continuity of `E_soft` across manipulation types and under perturbations (noise, blur).
- Ablate HECL queue design: Vary queue length (256–4096) and update frequency (per-batch vs. per-iteration) to measure impact on contrastive loss stability and P-F1.
- Evaluate edge-sparse failure mode: Curate test images with minimal ground-truth edge contrast (e.g., uniform backgrounds) and compare degradation to fully supervised methods to validate the claimed break condition.
