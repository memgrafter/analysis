# Beyond SGD, Without SVD: Proximal Subspace Iteration LoRA with Diagonal Fractional K-FAC
## Quick Facts
- arXiv ID: 2602.16456
- Source URL: https://arxiv.org/abs/2602.16456
- Reference count: 40
- Primary result: LoRA fine-tuning made efficient via proximal subspace iteration (LoRSum) with diagonal K-FAC, achieving comparable or better performance with robust learning rates.

## Executive Summary
The paper tackles ill-conditioning in LoRA fine-tuning, which traditionally relies on expensive full SVD to obtain optimal low-rank updates. The authors propose LoRSum, a memory-efficient subroutine that approximates the rank‑r projection of a full gradient update using proximal alternating least squares. They prove LoRSum implicitly performs a block power method, guaranteeing convergence to the same subspace as SVDLoRA. To improve conditioning, F‑LoRSum augments this with a diagonal Kronecker‑factored preconditioner (K‑FAC/Shampoo). The resulting optimizers, PSI‑LoRA and Scaled PSI‑LoRA, preserve LoRA’s parameter efficiency while matching or exceeding baselines on CIFAR‑100, GLUE, SQuAD v2, and WikiText‑103, with only modest compute overhead and robust learning‑rate choices.

## Method Summary
LoRSum replaces the SVD step in SVDLoRA with an iterative proximal alternating least squares procedure. Starting from an initial low‑rank factorization, LoRSum alternately solves for left and right factors under a proximal term that keeps them close to the full‑gradient range. This process is mathematically equivalent to a block power method, ensuring convergence to the dominant singular subspace without ever forming a full SVD. For further gains, F‑LoRSum applies a diagonal Kronecker‑factor approximation of the Fisher matrix (K‑FAC style) to precondition the full update before LoRSum, thereby addressing ill‑conditioning while maintaining low memory. PSI‑LoRA and Scaled PSI‑LoRA integrate these steps into standard LoRA fine‑tuning pipelines.

## Key Results
- Introduced LoRSum, a memory‑efficient alternative to SVD for optimal rank‑r projection in LoRA updates.
- Showed LoRSum converges to the SVDLoRA solution via an implicit block power method.
- PSI‑LoRA and Scaled PSI‑LoRA match or improve baselines on CIFAR‑100, GLUE, SQuAD v2, and WikiText‑103 with robust learning rates and only modest additional compute.

## Why This Works (Mechanism)
The proximal alternating least squares in LoRSum effectively performs a power iteration on the gradient matrix, extracting its top singular subspace without explicit SVD. The diagonal K‑FAC preconditioner approximates the loss curvature using layer‑wise Kronecker factors, adaptively scaling gradient directions to improve conditioning. Together they maintain LoRA’s low‑rank structure while mitigating ill‑conditioning, leading to stable training and reduced sensitivity to learning‑rate choices.

## Foundational Learning
- **LoRA (Low-Rank Adaptation)**: Freezes pretrained weights and injects trainable low‑rank matrices for efficient adaptation. *Why needed*: Baseline parameter‑efficient fine‑tuning method. *Quick check*: Setting LoRA rank to zero should recover original model outputs.
- **Singular Value Decomposition (SVD)**: Factorizes a matrix into orthogonal singular vectors and singular values. *Why needed*: SVDLoRA uses SVD to find the optimal rank‑r projection of the full gradient. *Quick check*: Reconstruct a matrix exactly from its top‑k SVD components.
- **Proximal Alternating Least Squares**: An optimization scheme that solves for matrix factors with a proximal regularization term. *Why needed*: Enables LoRSum to iteratively refine low‑rank factors without SVD. *Quick check*: Each subproblem should decrease the objective while respecting constraints.
- **Block Power Method**: Iterative algorithm for dominant singular vectors via repeated matrix multiplication and orthonormalization. *Why needed*: LoRSum is proven to be an instance of this method, guaranteeing convergence. *Quick check*: Apply power method to a random matrix and observe convergence to top singular vectors.
- **Diagonal K‑FAC (Kronecker‑Factored Approximate Curvature)**: Second‑order optimizer that uses a diagonal approximation of Kronecker‑factored Fisher information. *Why needed*: Provides curvature‑based preconditioning at low memory cost. *Quick check*: Preconditioned gradients should better align with the natural gradient.
- **Ill‑conditioning**: Loss landscapes with highly varying curvatures across directions, causing slow/unstable training. *Why needed*: LoRA updates suffer from this; the proposed methods directly address it. *Quick check*: Without preconditioning, gradient norms across parameters often vary by orders of magnitude.

## Architecture Onboarding
### Component Map
Full gradient update → LoRSum (proximal alternating least squares) → Approximate rank‑r projection → LoRA factor update.  
Preconditioned path: Gradient statistics → Diagonal K‑FAC → Preconditioned full update → LoRSum.

### Critical Path
1. Compute full gradient update for a weight layer.
2. (Optional) Precondition the update using diagonal K‑FAC statistics.
3. Apply LoRSum: initialize low‑rank factors; iterate between solving left/right factors with proximal term.
4. Obtain low‑rank approximation of the full update.
5. Update LoRA matrices with the approximate projection.

### Design Tradeoffs
- **Memory**: LoRSum eliminates full SVD; diagonal K‑FAC keeps preconditioning memory low compared to full K‑FAC.
- **Computation**: Additional iterative passes over the update matrix add modest overhead but remain cheap due to low rank.
- **Accuracy**: Diagonal K‑FAC may underperform full K‑FAC in highly anisotropic settings; LoRSum’s fixed rank r could truncate important directions if singular values decay slowly.

### Failure Signatures
- LoRSum fails to converge if proximal parameters or step size are poorly chosen (e.g., objective does not decrease).
- Diagonal K‑FAC preconditioning may degrade if the Kronecker‑factor assumption breaks (e.g., correlated activations), leading to slower or unstable training.
- Choosing too small rank r can discard informative directions, harming final performance.

### First Three Experiments
1. **Synthetic Convergence Test**: Generate a matrix with known singular structure; verify LoRSum recovers the same top‑r subspace as exact SVD.
2. **Benchmark Comparison**: Train a small transformer on CIFAR‑100 using PSI‑LoRA, SVDLoRA, and standard LoRA; compare validation accuracy and training dynamics.
3. **Large‑Scale Validation**: Fine‑tune LLaMA‑2 7B on a GLUE task using Scaled PSI‑LoRA; measure throughput, memory usage, and task performance versus LoRA and full fine‑tuning.

## Limitations
- Theoretical analysis relies on strong assumptions about gradient statistics and step‑size regimes that may not hold in practice.
- Empirical evaluation is restricted to standard academic benchmarks; performance on very large models (>7B) or diverse architectures is unknown.
- The claimed “modest” compute and memory overhead of LoRSum with diagonal K‑FAC is not quantitatively benchmarked against SVDLoRA or full fine‑tuning.

## Confidence
- Theory (convergence to SVDLoRA): Medium.
- Empirical results (on reported benchmarks): High.
- Generalization beyond tested scales/tasks: Low.
- Efficiency claims (memory/compute): Medium.
