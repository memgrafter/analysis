# Training data generation for context-dependent rubric-based short answer grading

## Quick Facts
- **arXiv ID**: 2603.28537
- **Source URL**: https://arxiv.org/abs/2603.28537
- **Reference count**: 0
- **Primary result**: A rank-based selection method using unreduced features yields statistically significant accuracy improvement (p=0.00091, avg gain 0.0206) over random subsampling when training a grading model on synthetic data.

## Executive Summary
The paper tackles the challenge of creating large-scale, domain-specific training data for automatic short answer grading when only a small, confidential reference dataset (from PISA tests) is available. The proposed solution generates a massive synthetic candidate dataset via a multi-stage LLM prompting pipeline, producing context-question-rubric-answer tuples without accessing the confidential content. A critical innovation is a three-method selection framework to identify a high-quality subset whose feature distribution matches the reference. The key finding is that only the third method—which ranks synthetic points by their nearest-neighbor similarity to the reference set in the full, unreduced feature space—produces a statistically significant boost in model accuracy. This demonstrates that preserving fine-grained feature relationships, not just aggregate statistics, is essential for effective surrogate dataset construction.

## Method Summary
The method comprises two main phases: **synthetic data generation** and **subset selection**. Generation uses a pipeline where a context is extracted from open web text, then LLMs sequentially generate a question, a rubric, and an answer, each followed by a judge LLM that filters outputs against explicit criteria (e.g., "answer must be written as a high school student might write them"). This yields a large pool of candidate datapoints. For selection, 19 hand-crafted linguistic and semantic features (e.g., embedding similarities, n-gram recalls, lexical density) are computed for both the synthetic pool and the confidential reference set. Three selection strategies are then tested: (1) matching the synthetic mean feature vector to each reference class mean; (2) clustering synthetic data and matching cluster centroids to reference class means; (3) ranking synthetic points by the average rank of their 5 nearest reference neighbors in the combined unreduced feature space. The top-ranked synthetic points from method three are used to train the final grading model.

## Key Results
- Only the third selection method (nearest-neighbor ranking on unreduced features) produced a statistically significant improvement in model accuracy on the reference test set (Wilcoxon signed-rank test p-value = 0.00091).
- This method achieved an average accuracy gain of 0.0206 (2.06%) over training on a randomly subsampled 5% of the synthetic data.
- The first two methods (using class means or clustering on reduced features) did not yield significant gains, indicating that matching aggregate feature distributions is insufficient for effective training data selection.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: Large-scale domain-specific training data can be generated from scratch using LLM prompting, guided by multi-stage quality filters.
- **Mechanism**: A pipeline extracts raw contexts from open web texts, then sequentially generates questions, rubrics, and answers via LLMs. Each stage uses a judge LLM to verify adherence to explicit criteria (e.g., "answer must be written as a high school student might write them"). This iterative refinement aims to produce outputs that structurally mirror the target PISA format without using confidential content.
- **Core assumption**: LLMs can be steered to produce pedagogically plausible, context-dependent items via carefully crafted prompts and automated validation.
- **Evidence anchors**: [section 3.2] describes the multi-stage prompting and judge-based filtering. [abstract] states they "leverage a set of very simple derived text formats to preserve confidentiality" and generate "synthetic candidate datasets via LLM prompting."
- **Break condition**: If judge LLMs frequently reject outputs or generated items fail basic coherence checks (e.g., questions unanswerable from context), the pipeline yields low-quality candidates that cannot be salvaged by later selection.

### Mechanism 2
- **Claim**: Selecting a subset based on similarity of *reduced* feature distributions (averaged class means or cluster centroids) to the reference dataset improves superficial alignment but does not yield training benefits.
- **Mechanism**: For each datapoint, a fixed set of 15 linguistic/semantic features is computed. The synthetic dataset is subsampled by keeping points whose feature vector is closest (L2 distance) to the mean feature vector of the corresponding correctness class in the reference set, or to the nearest of k-means cluster centroids.
- **Core assumption**: A small set of aggregate features can capture the essential distributional properties of the reference dataset, and matching these aggregates is sufficient for the subset to be functionally equivalent for model training.
- **Evidence anchors**: [section 3.3] lists the extracted features, noting they focus on "relations between different sections of a datapoint." [section 3.4] details the first and second selection methods using class means and k-means clustering on reduced features.
- **Break condition**: If the reduced features are insufficiently expressive (averaging away critical interactions or rare patterns), the selected subset may match aggregate statistics but lack nuanced distributional characteristics needed for learning.

### Mechanism 3
- **Claim**: Selecting synthetic data points that are *rank*-similar to the reference dataset in the full feature space (using unreduced vectors) yields a subset that demonstrably improves model training accuracy.
- **Mechanism**: For each synthetic candidate, the full unreduced feature vector is compared against all reference feature vectors. The candidate is scored by the average rank (in a combined sorted list by L2 distance) of the *k* nearest reference neighbors (k=5). Lower scores indicate the candidate sits "among" similar reference points in feature space. The top-scoring synthetic points are selected.
- **Core assumption**: The full-dimensional feature relationships (not reduced aggregates) encode the structural similarities between reference and synthetic data, and a nearest-neighbor ranking best approximates membership in the reference distribution.
- **Evidence anchors**: [section 3.4] describes the third selection method using "the rank of the first 5 closest datapoints from the reference dataset." [section 4.3] reports the statistically significant accuracy gain (p=0.00091, avg gain 0.0206).
- **Break condition**: If the reference dataset is too small, the ranking becomes noisy. Also, if synthetic data has modes absent in the reference, ranking may select outlier-similar points that are not truly representative.

## Foundational Learning
- **Concept**: **Derived Text Formats (DTFs) for Confidential Data Protection**
  - **Why needed**: The reference PISA dataset is under NDA; DTFs allow working with its *statistical properties* (features) without exposing raw text, enabling safe generation and selection of proxy data.
  - **Quick check**: What is a key risk of using DTFs based solely on aggregate features (like means) versus unreduced vectors?
- **Concept**: **Feature Engineering for Context-Dependent Grading**
  - **Why needed**: The task requires understanding alignment between context, question, rubric, and answer. Hand-crafted features (e.g., `context-answer cosine similarity`, `recall_2gram context overlap with answer minus question`) operationalize these alignments for distribution matching.
  - **Quick check**: Which feature might detect an answer that copies context text verbatim but fails to address the question?
- **Concept**: **Subset Selection for Distribution Matching (vs. Coreset Selection)**
  - **Why needed**: Goal is to create a *training* dataset whose distribution matches a confidential reference, not just a *evaluation* coreset. Methods like GRAD-MATCH optimize for training dynamics; here, static feature similarity is used due to computational constraints and data structure.
  - **Quick check**: Why might gradient-based subset selection (e.g., GRAD-MATCH) be infeasible for this multi-field, context-rich data?

## Architecture Onboarding
- **Component map**: Synthetic Generator -> Feature Extractor -> Selector -> Model Trainer -> Evaluator
- **Critical path**: Feature extraction must be consistent across reference and synthetic data. The selector's output directly determines training data quality, making the third selection method's reliance on *unreduced features* a bottleneck—requires storing/processing full feature matrices.
- **Design tradeoffs**:
  - **Method 3 vs. 1/2**: Method 3 preserves feature covariance and neighborhood structure (better accuracy gain) but is computationally heavier (O(N_ref * N_synth) pairwise distances). Methods 1/2 are scalable but lose expressive power.
  - **LLM generation vs. fidelity**: More LLM refinement iterations (up to 10 for rubrics) improve quality but increase cost and latency.
- **Failure signatures**:
  - No accuracy gain in E3 (Wilcoxon p > 0.05).
  - Feature distribution gaps remain large for key metrics (e.g., `recall_2gram NC answer` in Table 1).
  - Judge LLM rejection rates are high (>50%) in any generation stage, indicating prompt/ criteria mismatch.
- **First 3 experiments**:
  1. **Replication with different seeds**: Run E3 (third selection method) with 5 different random subsamplings and model initializations to confirm p-value stability.
  2. **Feature ablation**: Remove groups of features (e.g., all embedding-based, all n-gram-based) from the third selection method to identify which features drive the improvement.
  3. **Model transfer test**: Train a different architecture (e.g., DeBERTa-v3-base) on the third-method subset versus random, to see if gains generalize beyond ModernBERT-nli.

## Open Questions the Paper Calls Out
- **Open Question 1**: Does the third selection method improve model training across diverse models, domains, and dataset sizes?
  - **Basis**: [explicit] "determining whether this method truly selects useful data for the purposes of training in general would require more thorough experiments on many different models."
  - **Why unresolved**: Only one base model (ModernBERT-base-nli) and one PISA-derived dataset were used.
  - **What evidence would resolve it**: Systematic experiments varying model architectures, multiple educational datasets, and training set sizes, reporting statistically significant gains.
- **Open Question 2**: How can reduced-feature selection methods become more expressive without costly hyperparameter tuning?
  - **Basis**: [explicit] Simple averaged features "are often not expressive enough" and weighting them needs "resource-intensive selection."
  - **Why unresolved**: First and second methods failed; it's unclear which feature improvements would work.
  - **What evidence would resolve it**: Evaluate alternative feature representations (e.g., learned embeddings, interaction features) and their selection efficacy with minimal tuning.
- **Open Question 3**: Why does rank-based selection on unreduced features succeed where mean-based selection on reduced features fails?
  - **Basis**: [inferred] The third method uses unreduced features and nearest-neighbor ranking, unlike the first two; the performance gap is not explained.
  - **Why unresolved**: Understanding this could guide design of efficient selection strategies.
  - **What evidence would resolve it**: Compare selected subsets' diversity and feature distributions; conduct controlled experiments swapping feature representations.

## Limitations
- **Synthetic data fidelity**: Exact LLM prompts, temperatures, and web sources for context extraction are undisclosed, making replication of the synthetic distribution speculative.
- **Reference feature accessibility**: The confidential PISA reference set’s full unreduced feature vectors are unavailable to external researchers, blocking direct validation of the third selection method’s ranking logic.
- **Feature expressiveness sufficiency**: Why unreduced features succeed where reduced aggregates fail is not fully dissected; it may be due to preserved covariance or neighborhood structure, but this is inferred, not proven.

## Confidence
- **Major limitation #1 (Synthetic data fidelity)**: Low confidence. Without generation specifics, replicating the synthetic distribution is impossible.
- **Major limitation #2 (Reference feature accessibility)**: High confidence. The confidentiality constraint is inherent and unchangeable.
- **Major limitation #3 (Feature expressiveness sufficiency)**: Medium confidence. The inference about unreduced features preserving structure is plausible but unverified.
