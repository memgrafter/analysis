# FaST: Efficient and Effective Long-Horizon Forecasting for Large-Scale Spatial-Temporal Graphs via Mixture-of-Experts

## Quick Facts
*   **arXiv ID:** 2601.05174
*   **Source URL:** https://arxiv.org/abs/2601.05174
*   **Reference Count:** 40
*   **Primary Result:** Achieves state-of-the-art accuracy (4.4%–18.4% error reduction) and 1.3×–2.2× speedups for long-horizon forecasting on large-scale graphs (up to 8,600 nodes), with linear computational scaling.

## Executive Summary
FaST is a novel framework for scalable long-horizon forecasting on large spatial-temporal graphs (STGs). It addresses the prohibitive quadratic costs of standard spatial and temporal attention through two core innovations: an adaptive graph agent attention (AGA-Att) mechanism that approximates node interactions via a small set of learnable agent tokens, and a heterogeneity-aware mixture-of-experts (HA-MoE) module with parallel gated linear units for efficient temporal feature extraction. Evaluated on the LargeST benchmark (up to 8,600 nodes), FaST delivers superior accuracy and efficiency, enabling practical deployment on massive STGs where previous methods fail.

## Method Summary
FaST processes a spatial-temporal graph with N nodes and T historical steps through an input layer that first applies the HA-MoE module for temporal compression, producing dense node embeddings augmented with spatial and periodic temporal encodings. This embedding is passed through a residual backbone of L identical blocks. Each block first performs AGA-Att, where node tokens interact with a small set of a learnable agent tokens to capture spatial dependencies in O(N·a) complexity, followed by RMSNorm and another HA-MoE layer for temporal feature enhancement. Finally, outputs from all blocks are concatenated and fed to an MLP prediction head to forecast the next H steps. The HA-MoE router incorporates spatial location and temporal cycle biases (time-of-day, day-of-week) to mitigate expert polarization, while its expert networks use parallel GLU operations for computational efficiency.

## Key Results
*   **Accuracy:** On LargeST (4 datasets, N up to 8,600), FaST reduces MAE/RMSE/MAPE by 4.4%–18.4% relative to the best baseline for horizons up to 672 steps.
*   **Efficiency:** FaST is 1.3×–2.2× faster in training and inference than competing methods, with memory usage scaling linearly with nodes N and horizon H.
*   **Scalability:** Linear O(N·a) spatial complexity and efficient temporal processing enable practical long-horizon forecasting on graphs orders of magnitude larger than prior state-of-the-art.

## Why This Works (Mechanism)

### Mechanism 1: Adaptive Graph Agent Attention (AGA-Att)
*   **Claim:** Adaptive graph agent attention reduces spatial computational complexity from quadratic to linear in the number of nodes.
*   **Mechanism:** Introduces a small set of learnable agent tokens (a ≪ N) that first aggregate information from all nodes via node-to-agent attention and then distribute back to nodes via agent-to-node attention. This bypasses direct pairwise node interactions.
*   **Core assumption:** Node representations can be well-approximated by a low-dimensional manifold spanned by a limited number of agent tokens (i.e., spatial redundancy exists).
*   **Evidence anchors:** [abstract] "reduces spatial complexity from O(N²) to O(N·a)"; [section 3.4] Equations (10), (11), (12) detail the two-stage attention; ablation shows significant accuracy drops when removed (Figure 4).
*   **Break condition:** If spatial redundancy is low (nodes highly heterogeneous), the approximation error grows; increasing agent tokens helps but increases cost linearly.

### Mechanism 2: Heterogeneity-Aware Mixture-of-Experts (HA-MoE) Router
*   **Claim:** The heterogeneity-aware router mitigates expert polarization by dynamically routing nodes and time steps based on spatial-temporal biases.
*   **Mechanism:** The router computes expert scores as g^ℓ(X^t) ⊕ R_S ⊕ R_T^t ⊕ R_W^t, where R_S, R_T, R_W are learnable biases capturing spatial location, time-of-day, and day-of-week preferences. This biases routing toward relevant experts for each node and temporal context.
*   **Core assumption:** STG data exhibits spatial-temporal heterogeneity; a static router (using only hidden features) leads to expert underutilization.
*   **Evidence anchors:** [abstract] "heterogeneity-aware mixture-of-experts"; [section 3.3] Equation (5) defines the scoring function; ablation "w/o HA-Router" shows significant performance drop (Figure 4).
*   **Break condition:** If the dataset lacks strong spatial-temporal heterogeneity, the router may not improve load balancing; however, large-scale STGs typically exhibit diverse patterns.

### Mechanism 3: Parallel GLU Expert Networks
*   **Claim:** Parallelized GLU expert networks enable efficient feature extraction within MoE by merging all experts' linear transformations into a single operation.
*   **Mechanism:** Instead of separate FFN experts, a single linear layer produces a concatenated output split into two tensors (F_1, F_2). Element-wise multiplication after sigmoid on F_1 and F_2 yields all expert outputs simultaneously after reshaping.
*   **Core assumption:** Experts can be computed in parallel via tensor operations; GLU nonlinearity preserves capacity while avoiding sequential expert loops.
*   **Evidence anchors:** [abstract] "parallel gated linear units"; [section 3.3] Equation (8) and text describe implementation; Table 2 shows GLU-Expert matches FFN-Expert accuracy with 1.4× speed-up.
*   **Break condition:** If expert interactions require more complex cross-expert communication, the parallel GLU may limit expressiveness; but empirical results show no accuracy loss.

## Architecture Onboarding
*   **Component map:** Input Layer (HA-MoE + Embeddings) -> Backbone (L × [AGA-Att -> RMSNorm -> HA-MoE -> RMSNorm] with skip connections) -> Prediction Layer (MLP head)
*   **Critical path:** X^t -> HA-MoE (temporal compression) -> H^0_t -> [Block_1: AGA-Att -> HA-MoE -> H^1_t, ..., Block_L] -> Concat(H^1_t...H^L_t) -> MLP -> ˆY_t
*   **Design tradeoffs:**
    *   *Number of agents (a):* More agents improve reconstruction fidelity but increase O(N·a) cost; typical 16–32.
    *   *Number of experts (e):* More experts capture more heterogeneity but increase parameters and compute; typical 8–32.
    *   *Depth (L):* Deeper models learn richer patterns but may overfit on smaller datasets; optimal L varies by dataset size.
*   **Failure signatures:**
    *   *Expert polarization:* One expert gets >90% weights; indicates router failure (check bias initialization, learning rate).
    *   *High agent reconstruction error (ε_avg > 0.75):* Too few agents or poor training; increase a or train longer.
    *   *Out-of-memory on large graphs:* Likely due to large a, e, or d; reduce these or use gradient checkpointing.
*   **First 3 experiments:**
    1.  *Ablation study:* Remove HA-MoE or AGA-Att to quantify their contributions (Section 4.3, Figure 4).
    2.  *Hyperparameter sensitivity:* Sweep #experts, #layers, #agents, #dimension to find optimal tradeoffs (Section 4.4, Figure 5).
    3.  *Efficiency comparison:* Measure GPU memory and training/inference time across horizons (96→48/96→672) and node scales (SD→CA) (Section 4.5, Figures 6, Tables 3–4).

## Open Questions the Paper Calls Out
### Open Question 1
*   **Question:** How can FaST be effectively integrated with emerging time series foundation models to improve scalability and predictive accuracy for extremely large-scale and long-horizon forecasting tasks?
*   **Basis in paper:** [explicit] The conclusion explicitly states: "In future work, we plan to explore the integration of time series foundation models to further enhance the framework’s capabilities and scalability."
*   **Why unresolved:** The paper does not implement or evaluate any integration with foundation models; it remains a proposed direction without empirical validation or methodological details.
*   **What evidence would resolve it:** Concrete implementations of FaST combined with state-of-the-art time series foundation models (e.g., Moirai-MoE), tested on the LargeST or similar benchmarks, with comparative analyses of accuracy, memory usage, and training/inference times.

### Open Question 2
*   **Question:** What automated or adaptive mechanisms can optimally configure FaST’s key hyperparameters—such as the number of agent tokens (#agents), experts (#experts), and layers (#layers)—across diverse datasets and graph structures without relying on manual tuning?
*   **Basis in paper:** [inferred] The hyperparameter sensitivity analysis (Section 4.4) reveals that optimal values vary significantly with dataset size (e.g., #layers=3 vs. 4/5 for different datasets), yet the paper uses fixed configurations for fairness.
*   **Why unresolved:** The study highlights dataset-dependent optimal settings but does not propose or test any adaptive hyperparameter selection strategy, leaving a gap for robust deployment on unseen data.
*   **What evidence would resolve it:** Development of a meta-learning or reinforcement learning-based hyperparameter tuner for FaST, evaluated on a suite of varied spatial-temporal graphs to demonstrate consistent performance with reduced tuning effort.

### Open Question 3
*   **Question:** How robust and generalizable is the heterogeneity-aware router (HA-Router) in handling diverse spatial and temporal heterogeneity patterns, and are there alternative routing designs that could further mitigate expert polarization or capture nuanced dependencies?
*   **Basis in paper:** [inferred] The HA-Router is shown to reduce polarization via spatial/temporal biases (Section 3.3 and Figure 7), but evaluation is limited to a few nodes on one dataset (SD), without exploring varied heterogeneity scenarios or comparing to other MoE routing methods.
*   **Why unresolved:** The paper does not systematically test the router’s sensitivity to different heterogeneity types (e.g., abrupt vs. gradual changes, cross-node correlations) or benchmark against advanced routing techniques like expert choice routing.
*   **What evidence would resolve it:** Controlled experiments using synthetic datasets with injectable heterogeneity patterns, along with comparative studies against alternative routers (e.g., from TESTAM or ST-MoE), measuring load balancing, accuracy, and training stability.

### Open Question 4
*   **Question:** What are the theoretical and practical limits of the adaptive graph agent attention (AGA-Att) mechanism in preserving spatial information for large graphs, and how does the number of agent tokens (#agents) trade off fidelity against computational gains across different graph topologies?
*   **Basis in paper:** [inferred] Appendix A provides reconstruction error bounds and empirical results for #agents ∈ {16,32,64,128} on SD, showing correlation with forecasting error, but analysis is confined to one dataset and does not explore graph structural variations (e.g., density, modularity).
*   **Why unresolved:** The theoretical bounds are derived under simplifying assumptions, and empirical validation is narrow; the impact on diverse graph structures and the potential for adaptive agent allocation remain unexamined.
*   **What evidence would resolve it:** Extending reconstruction error analysis to multiple datasets with varying graph properties, correlating with forecasting metrics, and investigating dynamic agent allocation strategies that adjust based on graph characteristics.

## Limitations
*   **Assumption-dependent performance:** Efficacy relies on significant spatial redundancy (for AGA-Att) and strong spatial-temporal heterogeneity (for HA-Router); performance may degrade on graphs with minimal redundancy or weak periodic patterns (e.g., ad-hoc social networks).
*   **Unproven generalizability:** Evaluations are confined to traffic and climate domains (LargeST benchmark); applicability to other large-scale STG domains (e.g., epidemiology, finance) remains untested.
*   **Scale untested at extremes:** Linear scaling is validated up to N≈8,600; memory overheads and deviations from O(N·a) at extreme scales (N>50k, H>1000) are not stress-tested.

## Confidence
*   **High:** Spatial complexity reduction via agent attention (theoretically grounded, empirically validated on LargeST).
*   **Medium–High:** HA-router’s role in mitigating expert polarization (ablation shows gain, but limited dataset diversity).
*   **High:** Parallel GLU efficiency (clear speed-up demonstrated with no accuracy loss).
*   **Medium:** Overall scalability claims (validated up to 8.6k nodes; larger scales inferential).
