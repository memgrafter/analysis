# TianJi: An autonomous AI meteorologist for discovering physical mechanisms in atmospheric science

## Quick Facts
- **arXiv ID:** 2603.27738  
- **Source URL:** https://arxiv.org/abs/2603.27738  
- **Reference count:** 36  
- **Primary result:** Achieved expert-level, zero-intervention experiments on squall-line cold pools and typhoon track deflection, compressing research cycles from weeks to hours and autonomously correcting a flawed human hypothesis to reveal a novel nonlinear intensity-track coupling mechanism.

## Executive Summary
TianJi is an LLM-driven multi-agent system designed to automate the discovery of physical mechanisms in atmospheric science. It addresses a critical gap in AI-driven weather forecasting—the inability to autonomously generate and verify scientific hypotheses—by decoupling the process into two modules: hypothesis generation via structured multi-agent debate, and hypothesis verification via a meta-planner that orchestrates specialized workers to execute and analyze WRF numerical simulations. The system demonstrated robust, end-to-end autonomy across complex mesoscale cases (squall lines, typhoons), achieving expert-level outcomes with automatic fault recovery over 164+ API calls. TianJi compresses traditional research cycles to hours and has already produced validated physical insights, such as a 20.4% reduction in cold pool temperature deficit under soil moisture perturbations, while also autonomously correcting a mistaken human hypothesis about SST anomalies.

## Method Summary
TianJi solves autonomous mechanism discovery through a two-layer multi-agent architecture. The **hypothesis generation module** employs researcher, host, and chief scientist agents in an iterative debate loop, scoring proposals on scientificity, rationality, novelty, and effectiveness to converge on a testable hypothesis. The **hypothesis verification module** uses a meta-planner to decompose the hypothesis into a sequential experimental roadmap (e.g., WPS configuration, WRF initialization, simulation, analysis) and dispatches specialized worker agents—each expert in a specific tool bus (WRF driver, tensor analysis, visualization, basic commands)—to execute discrete API calls. A state monitor validates outputs after each step and triggers automatic fault repair for common WRF errors (e.g., namelist mismatches). The system operates in simple mode for trivial tasks and complex mode for full experiments, enabling zero-human-intervention runs from natural language inputs to final scientific reports.

## Key Results
- Achieved fully autonomous, expert-level verification experiments on squall-line cold pools and typhoon track deflection, reducing typical research cycles from weeks to hours.
- Validated a soil-moisture hypothesis, quantifying a 20.4% reduction in cold pool temperature deficit, and autonomously identified a flaw in a human-proposed SST anomaly hypothesis, revealing a previously unreported nonlinear intensity-track coupling mechanism.
- Demonstrated robust operation with automatic fault repair across 164+ API calls, successfully recovering from configuration errors (e.g., WPS prefix mismatches, metgrid level mismatches, MPI overflows) without intervention.

## Why This Works (Mechanism)
**Structured multi-agent debate** suppresses LLM hallucinations and improves hypothesis scientificity by simulating peer review: researcher agents propose and rebuttal hypotheses iteratively, a host agent scores each round on scientificity, rationality, novelty, and effectiveness, and a chief scientist selects the final proposal. Full-domain transparency ensures coherence, but the system fails if scores plateau, rebuttals circularize, or hypotheses contradict retrieved literature.

**Decoupling cognitive planning from engineering execution** bridges natural language to WRF simulations: a meta-planner interprets the hypothesis, devises a feasible subtask roadmap, and dynamically schedules specialized workers (each expert in one tool bus). This hierarchy prevents context overload and handles cross-modal steps (Fortran config, NetCDF analysis). Breakdowns occur if the meta-planner generates an infeasible sequence or cannot reschedule after worker errors.

**Automatic fault detection and repair** ensures zero-intervention robustness: the state monitor checks each API call output; on error, it diagnoses causes (e.g., namelist parameter mismatch) and applies corrective patches (e.g., adjusting `e_vert`, fixing GRIB prefixes) before restarting. This works for predictable WRF failures but may fail on non-deterministic HPC issues or deep physics incompatibilities requiring human insight.

## Architecture Onboarding
**Component map:**  
User Input → Hypothesis Generation Module (Researcher Agents + Host + Chief Scientist) → Final Hypothesis → Hypothesis Verification Module (Meta-planner → Specialized Workers: `wps_configurer`, `fnl_processor`, `wrf_real_executor`, `wrf_main_simulator`, `trajectory_analyzer`) → Tool Buses (WRF Driver, NetCDF/Tensor Ops, Visualization, Basic Tools) → State Monitor (Validation/Repair) → Final Report.

**Critical path:** Hypothesis → Meta-planner roadmap → WPS config → FNL processing → WRF init → WRF main run → Trajectory/analysis → Final report. Each step must succeed sequentially; failure at any stage breaks the chain.

**Design tradeoffs:**  
- *Specialization vs. Flexibility:* Fixed worker types ensure WRF reliability but limit novel analyses; adding new diagnostics requires coding new workers.  
- *Debate Depth vs. Cost:* More rounds improve hypothesis quality but increase LLM calls and time; default 6 rounds balances cost/convergence.  
- *Auto-repair Scope:* Repair rules cover common WRF errors; unknown errors still need human intervention.

**Failure signatures:**  
- *Stuck debate:* Agent scores plateau below threshold (e.g., <35/50) after 3+ rounds; hypotheses repeat or contradict literature.  
- *Roadmap deadlock:* Meta-planner requests impossible subtask sequence (e.g., analysis before simulation) or fails to schedule required worker.  
- *Silent physics violation:* Simulation completes but violates conservation laws (e.g., energy drift); not caught by state monitor.

**First 3 experiments:**  
1. **Simple mode sanity check:** "Plot 2-m temperature from last wrfout file." Validates easy-task mode, tensor ingestion, and basic plotting without WRF run.  
2. **Single-parameter perturbation:** "Change radiation scheme from RRTMG to Dudhia." Tests worker ability to modify namelist, rerun `real.exe`/`wrf.exe`, and compare outputs.  
3. **Full hypothesis verification (copy squall line):** Replicate Section 3.2 exactly. Tests end-to-end chain: hypothesis parsing → WRF soil moisture perturbation → fault repair → result analysis. Measures time-to-completion and self-correction rate.

## Open Questions the Paper Calls Out
**Generalization to climate simulations and coupled Earth system models:** The current system focuses on short-term mesoscale WRF runs; long-term climate simulations involve model drift, century-scale resource management, and multi-sphere coupling (atmosphere-ocean-land-ice). The architecture and tool buses are optimized for mesoscale WRF and may not handle extended integrations or complex coupling interfaces without major redesign. *Resolution evidence:* Test on standard climate benchmarks (e.g., CMIP experiments) with a coupled model, measuring autonomous configuration, run stability, and diagnostic plausibility over decades.

**Integration of real-time data assimilation:** TianJi operates offline with pre-generated initial/boundary conditions. Real-time assimilation introduces asynchronous observations, quality control, and iterative corrections (e.g., EnKF), which could disrupt the deterministic planning-execution loops and increase error complexity. *Resolution evidence:* Implement an assimilation module and test on cases where observations are critical (e.g., tropical cyclone intensity), assessing stable operation, correct configuration, and improved agreement with observations.

**Fully autonomous closed-loop discovery cycle:** Hypothesis generation and verification currently run sequentially but not cyclically; results do not automatically feed back to refine or generate new hypotheses. True autonomy requires meta-cognitive looping—evaluating confidence, identifying conflicts, and formulating follow-ups—beyond the current meta-planner. *Resolution evidence:* Conduct an end-to-end experiment where TianJi receives a broad question, generates multiple hypotheses, tests them, analyzes outcomes, and iteratively refines hypotheses without human intervention, tracking convergence and novelty against expert benchmarks.

**Adaptation to other Earth system models (e.g., CESM, ICON):** TianJi's tool buses and worker behaviors are hard-wired for WRF's NetCDF I/O, namelists, and preprocessing (WPS). Other models have different architectures, configuration languages, coupling strategies, and output formats, requiring significant abstraction while preserving physical reasoning. *Resolution evidence:* Port the framework to another major model using a common abstraction layer, test on a benchmark (e.g., aquaplanet), and compare autonomous success rates (configuration, run, analysis) and derived physical insights against WRF results.

## Limitations
- **Implementation secrecy:** Exact LLM models, hyperparameters, and prompt engineering are undisclosed, hindering exact replication and independent performance benchmarking.
- **Uncorroborated novelty:** The automatic fault-repair logic for WRF errors lacks validation in neighboring autonomous systems; its generalizability is unproven.
- **Scalability unknowns:** System behavior with more complex hypotheses (e.g., mesoscale convective systems) or different numerical models (e.g., MPAS) is not explored.
