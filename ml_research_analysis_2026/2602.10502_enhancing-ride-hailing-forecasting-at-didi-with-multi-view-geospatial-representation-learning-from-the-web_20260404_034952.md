# Enhancing Ride-Hailing Forecasting at DiDi with Multi-View Geospatial Representation Learning from the Web

## Quick Facts
- **arXiv ID:** 2602.10502
- **Source URL:** https://arxiv.org/abs/2602.10502
- **Reference Count:** 40
- **Primary Result:** MVGR-Net achieves state-of-the-art WMAPE improvements of 1.7%-2.2% (Call) and 1.0%-1.9% (TSH) offline, with online A/B gains of 2.3%-3.6% in August 2025.

## Executive Summary
Ride-hailing demand forecasting is hampered by extreme geospatial heterogeneity across regions and sensitivity to external events like weather and holidays. This paper introduces MVGR-Net, a two-stage framework. First, it learns comprehensive geospatial representations by fusing Points-of-Interest (semantic view) and temporal mobility patterns (temporal view) via dual cross-attention. Second, it integrates these representations into a prompt-empowered fine-tuning of a Large Language Model, which also processes textual descriptions of external variables. Evaluated on DiDi's real-world data across 392 counties, MVGR-Net sets new performance benchmarks and demonstrates consistent gains in online A/B testing.

## Method Summary
MVGR-Net operates in two stages. Stage 1 pre-trains a multi-view geospatial encoder: a POI branch processes spatial proximity, hierarchical categories, and LLM-generated textual descriptions into a semantic vector; a temporal branch compresses historical mobility into daily/weekly cycles. Dual cross-attention fuses these views into a unified grid-level representation, regularized by multi-view consistency and holistic-part contrastive losses before pooling to county-level vectors. Stage 2 builds a prompt generation network (PGN) that maps these county vectors to a library of learned mobility prototypes, producing a region-specific prompt. This prompt, along with patchified time-series features and textual encodings of external events (rainfall, holidays), is fed to an LLM fine-tuned with LoRA to produce the final forecast.

## Key Results
- Offline, MVGR-Net reduces WMAPE by 1.7%-2.2% for Call and 1.0%-1.9% for Total Supply Hours (TSH) against strong baselines on DiDi’s multi-year, 392-county dataset.
- Online A/B testing in August 2025 confirms consistent operational gains: WMAPE improved by 3.6% (C1 Call), 2.3% (C3 Call), 2.7% (C1 TSH), and 2.8% (C3 TSH).
- Ablation studies show the multi-view fusion, PGN, and external variables each contribute significantly, with external variables providing the largest single gain in some years.

## Why This Works (Mechanism)

### Mechanism 1: Multi-View Geospatial Fusion
- **Claim:** MVGR-Net captures geospatial heterogeneity by fusing complementary semantic (POI) and temporal mobility views, producing region representations that reflect both static functionality and dynamic rhythms.
- **Mechanism:** POI data is encoded via spatial proximity (KNN), hierarchical category semantics (graph random walks), and LLM-generated text into Z_P. Temporal patterns are compressed into daily/weekly cycles and encoded into Z_M. Dual cross-attention enables adaptive interaction between Z_P and Z_M, followed by multi-view consistency losses to align the fused representation Z_F with each source. Grid-level Z_F is pooled to county-level H with a holistic-part loss to align constituent grids.
- **Core Assumption:** Geospatial heterogeneity is bidirectionally informed by what a region *is* (POIs) and how it *moves* (temporal patterns); isolating either view loses essential information.
- **Evidence Anchors:** Abstract and Section 3.1 define the two-view fusion and losses. Ablation removing the multi-view framework hurts performance. Corpus works combine multi-source data, but MVGR-Net’s specific dual cross-attention with consistency regularization is novel.
- **Break Condition:** If either POI or temporal data is missing, or cross-attention fails to learn meaningful interaction, the fused representation collapses to a single-view signal, degrading performance.

### Mechanism 2: Prompt-Empowered LLM Adaptation
- **Claim:** The Prompt Generation Network (PGN) dynamically maps pre-trained geospatial representations to a library of learned mobility prototypes, providing the LLM with adaptive, region-specific prompts without full fine-tuning.
- **Mechanism:** A shared memory pool MP stores M learnable key-value pairs. The county-level representation H_r acts as a query to compute cosine similarity with keys; the top k_p keys are selected, and their values are weighted-summed to produce prompt P_r. P_r is concatenated with time-series features U and cross-attended with textual features T before entering the LLM.
- **Core Assumption:** Urban regions can be clustered into a discrete set of “mobility prototypes” (keys), and a continuous representation H_r can be reliably matched to these prototypes via similarity.
- **Evidence Anchors:** Abstract mentions prompt-empowered LLM fine-tuning. Section 3.2.2 mathematically defines PGN and retrieval (Eq. 10–11). Corpus work *HimNet* [13] uses a query-pool paradigm for heterogeneity, supporting plausibility.
- **Break Condition:** If the memory pool is too small (M insufficient) or key-value mappings fail to converge, prompts become uninformative/noisy. Ablation removing PGN causes significant performance drop.

### Mechanism 3: External Events via Textual Abstraction
- **Claim:** External events (rainfall, holidays, special events) are effectively incorporated by converting them into natural language descriptions, leveraging the LLM’s semantic reasoning to capture sporadic impacts on demand.
- **Mechanism:** For each external variable, a prompt generates a textual description covering nature attribute, trend, periodicity, stability, and noise. An LLM encoder produces textual features T. Time-series patches and external variables are processed through patch-based self-attention with an [EOS] token to produce feature vectors, fused with T via cross-attention (Eq. 12).
- **Core Assumption:** LLMs can interpret numerical time-series and external factors through natural language abstractions, bridging raw exogenous data and high-level contextual reasoning.
- **Evidence Anchors:** Abstract notes incorporation of external events. Section 3.2.1 describes textual description generation and fusion. Corpus baseline *ExoLLM* [23] uses textual descriptions for exogenous variables, providing direct precedent.
- **Break Condition:** If textual descriptions are omitted or LLM encoder fails, the model cannot respond to external events. Ablation shows external variables contribute the largest single gain in some years; case study (Figure 6) shows improved handling of event-driven spikes.

## Foundational Learning
- **Geospatial Heterogeneity:** Ride-hailing demand varies drastically across regions due to urban function, economics, and population. A one-size-fits-all model averages out patterns, causing systematic errors in distinctive areas. *Quick check:* Do regions with similar POI distributions and weekly mobility patterns exhibit similar demand fluctuations? (Expected: Yes, per T-SNE clustering in Figure 7.)
- **Multi-View Representation Learning:** No single modality fully characterizes a region; POIs capture static semantics but ignore temporal rhythms, while time-series capture dynamics but lack functional context. Fusion yields robust representation. *Quick check:* Does a model that concatenates raw POI counts and time-series without learned interaction underperform dual cross-attention fusion? (Expected: Yes.)
- **Prompt-Empowered LLM Adaptation:** Pre-trained LLMs lack specific spatio-temporal patterns. Full fine-tuning is costly/overfitting; prompt learning injects domain priors efficiently. *Quick check:* Does adding a learnable prompt derived from geospatial data improve LLM forecasting over using only time-series patches? (Expected: Yes, per PGN ablation.)

## Architecture Onboarding
- **Component Map:** POI Encoder (spatial, hierarchical, text) -> Z_P; Temporal Mobility Encoder (daily/weekly cycles) -> Z_M; Dual Cross-Attention -> Z_F; Attentional Pooling -> County-level H; Prompt Generation Network (Memory Pool) -> P_r; Patchifier & EOS Aggregator -> U; Text Encoder (LLM) -> T; Cross-Attention (U, T) -> LLM (LoRA) -> Forecast.
- **Critical Path:** 1. Pre-train Stage 1 to embed counties -> store H_r. 2. For new forecast: load H_r. 3. Process historical series X and externals into patch features. 4. Generate P_r via PGN from H_r. 5. Concatenate P_r with time-series features -> U. 6. Generate textual descriptions T for time window. 7. Cross-attend U with T. 8. Feed into LLM+LoRA; output prediction.
- **Design Tradeoffs:** Grid granularity: finer (600m) captures micro-heterogeneity but increases memory/sparsity; coarser counties reduce noise but blur local patterns. Memory pool size M: larger M represents more prototypes but slows retrieval/overfits. LoRA rank r: lower saves parameters but may limit adaptation; higher risks overfitting. LLM size: larger improves reasoning but increases latency/cost.
- **Failure Signatures:** Poor clustering: T-SNE of H shows no grouping by region type -> representation failure. Event miss: high errors on holiday/rainy days despite correct time-series pattern -> external fusion inadequate. PGN ablation impact: removing PGN causes consistent drop -> prompts essential. Over-smoothing: predictions average out peak spikes -> dual attention may have collapsed; check attention weights.
- **First 3 Experiments:** 1. Ablation: remove PGN, LoRA, external variables individually (Figure 4). 2. Hyperparameter sweep: vary prompt pairs M and LoRA rank r (Figure 5). 3. Representation visualization: T-SNE on H to validate clustering by region type (Figure 7).

## Limitations
- **Data Dependency:** Core results rely on DiDi’s proprietary POI taxonomy (18/218 categories) and 392-county hierarchy; reproduction with open-source substitutes (e.g., OSM) introduces unavoidable domain shift.
- **Hyperparameter Gaps:** Critical training details (loss weights, temperature τ, LoRA rank, attention heads) are omitted, limiting faithful replication and sensitivity analysis.
- **External Event Encoding:** The incremental gain of LLM-generated textual descriptions over simpler numeric encoding is not isolated in ablation; the claimed semantic reasoning advantage remains plausible but unproven within MVGR-Net’s specific fusion.

## Confidence
- **Geospatial Heterogeneity Capture (Mechanism 1):** **High** (Strong ablation effect, clustering visualization, consistent SOTA gains.)
- **Prompt-Empowered LLM Adaptation (Mechanism 2):** **Medium** (PGN ablation shows benefit, but memory pool design optimality not justified via sweep; failure condition theoretical.)
- **External Event Fusion (Mechanism 3):** **Medium-High** (Ablation indicates contribution; ExoLLM precedent exists, but textual-abstraction advantage not isolated.)
- **Portability to New Regions:** **Low** (Proprietary data/taxonomy dependency; open-source substitutes likely cause domain shift.)
- **Exact Performance Replication:** **Medium** (Hyperparameter gaps introduce uncertainty despite clear overall methodology.)

## Next Checks
1. **Clustering Quality Test:** Compute T-SNE on Stage 1 county embeddings H. Quantify cluster cohesion (e.g., silhouette score) by known region types (commercial/residential/industrial). Expect high scores; low scores indicate representation failure.
2. **PGN Sensitivity Sweep:** Ablate memory pool size M (256, 512, 1024) and top-k (64, 128, 256). Measure WMAPE change. Larger M should help until diminishing returns; sharp declines signal overfitting/retrieval noise.
3. **External Event Isolation:** Re-run with only rainfall/holiday variables (no special events) and with only numeric (vs. textual) event encodings. Compare performance on event-day windows. A significant drop with numeric-only would confirm textual abstraction’s value.
