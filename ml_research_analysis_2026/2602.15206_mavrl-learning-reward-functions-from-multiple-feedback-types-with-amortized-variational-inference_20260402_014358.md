# MAVRL: Learning Reward Functions from Multiple Feedback Types with Amortized Variational Inference

## Quick Facts
- arXiv ID: 2602.15206
- Source URL: https://arxiv.org/abs/2602.15206
- Reference count: 25
- Primary result: Combining demonstrations, preferences, ratings, and stops (PDR) yields superior policy performance and robustness across multiple environments.

## Executive Summary
MAVRL tackles the problem of learning reward functions from heterogeneous human feedback without manual loss weighting. It frames the task as Bayesian inference over a shared latent reward, assigning each feedback type (demonstrations, comparisons, ratings, stops) an explicit likelihood. A scalable amortized variational inference approach learns a shared reward encoder and feedback-specific decoders by optimizing a single evidence lower bound (ELBO). A TD-error constraint ties the inferred reward to the environment dynamics via an auxiliary Q-function. Experiments on grid-worlds and continuous control benchmarks show that multi-modal reward learning (PDR) consistently outperforms single-modality baselines in normalized returns and yields policies that degrade more gracefully under dynamics perturbations.

## Method Summary
MAVRL models reward learning from multiple feedback types as Bayesian inference with a shared latent reward R. Each modality has an explicit likelihood p(y|R, Q) depending on a Q-value function. The posterior p(R|D) is approximated via amortized variational inference using a shared encoder q_θ(R|s,a,s') that outputs a Gaussian reward distribution. The ELBO aggregates the log-likelihoods from all modalities plus a KL penalty on q_θ. An auxiliary Q-network Q_ϕ is trained jointly with a TD loss that ties reward samples to one-step Bellman errors, ensuring consistency with the MDP dynamics. The entire system is trained end-to-end.

## Key Results
- Multi-modal feedback (PDR) achieves the highest normalized return in 5 of 6 environments, significantly outperforming single-modality baselines (e.g., 90.8 vs. 62.6 in grid_cliff).
- Policies learned from multi-modal rewards degrade more gracefully under environment perturbations (e.g., dynamics changes, increased stochasticity) compared to single-feedback or imitation learning approaches.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Joint Bayesian inference over a shared latent reward function allows heterogeneous feedback types to contribute complementary information without manual loss weighting.
- **Mechanism:** Each feedback modality (demonstrations, comparisons, ratings, stops) is modeled with an explicit likelihood function `p(D^(m) | R)`. The joint posterior `p(R | D) ∝ ∏_m p(D^(m) | R) p(R)` is then approximated via variational inference, where the shared reward encoder `q_θ(R | s,a,s')` serves as the variational posterior. The ELBO aggregates log-likelihoods from all modalities, letting their relative influence emerge from the probabilistic models rather than hand-tuned coefficients.
- **Core assumption:** Each feedback type provides a valid, conditionally independent probabilistic signal about the same underlying reward function `R*`. The likelihood models accurately reflect how humans generate that feedback given `R*`.
- **Evidence anchors:** [abstract] "formulating reward learning from multiple feedback types as Bayesian inference over a shared latent reward function, where each feedback type contributes information through an explicit likelihood... eliminates the need for manual loss balancing." [section 4] Defines modality-specific likelihoods (e.g., Bradley-Terry for preferences, Boltzmann for demonstrations, ordered logit for ratings, hazard model for stops) and states they "together induce the joint data likelihood p(D|R)". [corpus] Weak direct evidence; neighbor papers explore multi-feedback RL but do not implement this exact unified Bayesian scheme.
- **Break condition:** Mis-specification of any likelihood model (e.g., wrong noise assumption) would corrupt the joint posterior, as all modalities are coupled through the shared `q_θ`.

### Mechanism 2
- **Claim:** Amortized variational inference (learning a shared reward encoder `q_θ` and feedback-specific decoders `p_ψ`) enables scalable posterior approximation without inner-loop RL.
- **Mechanism:** The encoder `q_θ` maps transitions `(s,a,s')` to reward distribution parameters. Reparameterized reward samples `R ~ q_θ` are fed into each modality's decoder `p_ψ(y|R, Q_ϕ)` to compute log-likelihoods. The entire network (encoder, Q-value model `Q_ϕ`, decoders) is trained end-to-end by maximizing the single ELBO, amortizing the cost of inference across all feedback instances and types.
- **Core assumption:** The encoder network can generalize to produce valid reward samples for any transition encountered, and the decoders can accurately compute likelihoods from those samples. The reparameterization trick allows gradient flow through sampling.
- **Evidence anchors:** [abstract] "introduce a scalable amortized variational inference approach that learns a shared reward encoder and feedback-specific likelihood decoders and is trained by optimizing a single evidence lower bound." [section 5.1] Details the architecture: "the reward encoder itself is agnostic to the type and structure of feedback; all feedback-specific semantics are captured entirely by the corresponding likelihood functions." [corpus] Related work (e.g., AVRIL) established amortized VI for Bayesian IRL; MAVRL extends this to multi-modal feedback.
- **Break condition:** Encoder fails to produce meaningful reward distributions (e.g., collapses to prior), or decoders are mis-calibrated, causing degenerate ELBO gradients.

### Mechanism 3
- **Claim:** A TD-error constraint aligns the inferred reward distribution with the true MDP dynamics, bridging latent reward samples and required value estimates for certain feedback types.
- **Mechanism:** The auxiliary Q-value model `Q_ϕ` is trained jointly. The TD loss `L_TD` penalizes deviations between one-step Bellman differences `δ_ϕ = Q_ϕ(s,a) - γ Q_ϕ(s',a')` and the reward samples from the encoder: `log N(δ_ϕ; μ_θ, σ²_θ)`. This regularizes the reward space to be consistent with a valid value function, which is necessary for feedback types (demonstrations, ratings, stops) that depend on `Q*_R(s,a)` or trajectory returns.
- **Core assumption:** The TD constraint is sufficient to prevent the encoder from learning reward functions that are arbitrarily disconnected from the environment's transition dynamics. The Q-model accurately approximates the optimal value function for the current reward posterior.
- **Evidence anchors:** [abstract] "A TD-error constraint aligns reward and Q-value estimates through one-step Bellman differences." [section 5.1] "enforces consistency between the inferred reward distribution and the auxiliary action-value function... encourages rewards predicted by the encoder to agree with the one-step Bellman differences implied by Q_ϕ." [corpus] Not directly addressed in neighbor papers; this is a specific adaptation from AVRIL to the multi-feedback setting.
- **Break condition:** Q-model fails to converge or becomes biased (e.g., due to insufficient data), causing the TD constraint to misalign reward samples with true optimal values, degrading all downstream likelihoods.

## Foundational Learning
- **Concept: Bayesian inference for reward learning**  
  **Why needed:** The entire framework treats the reward as a latent variable and seeks its posterior given evidence. Understanding priors, likelihoods, and the intractability of marginal likelihoods is essential to grasp why variational inference is used.  
  **Quick check question:** How does the factorization `p(D|R) = ∏_m p(D^(m)|R)` simplify the Bayesian update, and why does it still require approximation?
- **Concept: Variational Autoencoders (VAEs) and amortization**  
  **Why needed:** MAVRL's architecture is a conditional VAE where the encoder outputs a reward distribution and decoders are feedback-specific likelihood models. Amortization means training one encoder/decoder set to approximate posteriors for all data points, avoiding costly per-instance optimization.  
  **Quick check question:** What is the role of the reparameterization trick in enabling gradient-based learning of the reward encoder `q_θ`?
- **Concept: Reinforcement learning fundamentals (MDPs, Q-values, policy evaluation)**  
  **Why needed:** The feedback likelihoods (Boltzmann for demos, hazard for stops) depend on `Q*_R(s,a)`. The TD constraint explicitly links reward samples to value differences. Without understanding value iteration and Bellman equations, the design is opaque.  
  **Quick check question:** Why do the demonstrations, ratings, and stops likelihoods require access to a Q-function rather than just immediate reward values?

## Architecture Onboarding
### Component Map
The architecture consists of:
1. Reward Encoder `q_θ(s,a,s')`: MLP outputting mean μ_θ and variance σ²_θ for a Gaussian reward sample R.
2. Q-value Model `Q_ϕ(s,a)`: Separate MLP estimating state-action values.
3. Feedback-Specific Decoders `p_ψ^(m)(y|R, Q_ϕ)`: Small networks or closed-form formulas (e.g., Bradley-Terry, logistic CDF) computing modality-specific likelihoods.
4. Loss Aggregator: Computes NLL for each modality, adds KL divergence `λ_KL * KL(q_θ || N(0,I))` and TD loss `λ_TD * L_TD`.

### Critical Path
Data (trajectories/fragments) → extract `(s,a,s')` pairs & feedback labels → encoder produces `(μ,σ²)` → reparameterize `R = μ + σ * ε` → compute `Q_ϕ(s,a)` for relevant transitions → each decoder evaluates `log p_ψ^(m)(y|R, Q_ϕ)` → sum losses + regularization → backpropagate to update `θ, ϕ, ψ`.

### Design Tradeoffs
- **Shared encoder vs. separate encoders:** Shared encoder enforces a single reward posterior across modalities but may struggle if modalities require different feature representations. Separate encoders would break the unified posterior assumption.
- **Auxiliary Q-model:** Adding `Q_ϕ` introduces extra parameters and requires TD data, but is necessary for feedback types that depend on returns/values. Omitting it would limit applicable modalities.
- **Gaussian posterior:** Simplifies reparameterization but may not capture multi-modal reward posteriors; non-Gaussian families increase complexity.

### Failure Signatures
- High variance in `σ²_θ` without reduction → encoder uncertain, perhaps due to conflicting feedback.
- `Q_ϕ` converges to a constant → TD constraint ineffective; reward samples become arbitrary.
- Single-modality performance << known baselines → likelihood models or encoder capacity inadequate.
- Combination performance worse than single modality → likely conflicting gradients from poorly scaled likelihoods.

### First 3 Experiments
1. **Qualitative grid-world visualization (Sec 6.1, Fig 2):** Train MAVRL on single and combined feedback in a small MDP. Inspect mean/variance of `μ_θ`. Expect: demonstrations yield high certainty along expert path, ratings pinpoint goal, stops highlight bad states; combination covers both high and low reward regions accurately.
2. **Policy performance table (Sec 6.2, Table 1):** For each combination of modalities (P, D, R, PD, etc.), learn reward, then train a policy (e.g., PPO). Evaluate normalized return vs. ground truth. Expect: PDR combination consistently near or at top; no single modality dominates all environments.
3. **Robustness perturbation (Sec 6.3, Fig 3):** Fix trained reward models, retrain policies in perturbed dynamics (e.g., increased stochasticity, changed link lengths). Compare normalized return degradation. Expect: multi-feedback (PDR) policies degrade more gracefully than single-feedback or imitation baselines.

## Open Questions the Paper Calls Out
1. **Question:** How does MAVRL perform when applied to real human feedback, which may exhibit systematic biases, inconsistencies, or context-dependent judgments?  
   **Basis in paper:** Limitations section states that applying MAVRL to real human feedback remains an important direction for future work.  
   **Why unresolved:** Current experiments rely on synthetic feedback; real human behavior may deviate from idealized likelihood models.  
   **What evidence would resolve it:** Conduct user studies with participants providing heterogeneous feedback; compare policy performance against synthetic baselines and analyze correlations with feedback inconsistency measures.

2. **Question:** How can the reward uncertainty estimated by MAVRL be leveraged for active learning of heterogeneous feedback to improve sample efficiency?  
   **Basis in paper:** Limitations note that uncertainty is not yet exploited for guiding feedback collection.  
   **Why unresolved:** It is unknown how to effectively query different feedback types based on current uncertainty to maximize learning.  
   **What evidence would resolve it:** Implement an active MAVRL with an acquisition function (e.g., mutual information) to select feedback types; compare total feedback needed to reach target performance against passive collection.

3. **Question:** What causes the observed conflicts between certain feedback modalities (e.g., demonstrations and preferences) that lead to underperformance compared to single-modality baselines?  
   **Basis in paper:** Section 6.2 reports underperformance for combinations like PR in CartPole; hypothesizes gradient conflicts.  
   **Why unresolved:** The root cause (e.g., mismatched scales, contradictory information) is not investigated.  
   **What evidence would resolve it:** Ablations: analyze gradient magnitudes and alignment; visualize where each modality assigns high/low reward; vary relative weighting; test scenarios with aligned vs. conflicting signals.

4. **Question:** How robust is MAVRL to misspecification in the probabilistic models (likelihoods) for different feedback types?  
   **Basis in paper:** Inferred; the method relies on fixed likelihood families with parameters; no sensitivity analysis.  
   **Why unresolved:** If the assumed likelihood is incorrect, inferred reward may be biased; robustness unknown.  
   **What evidence would resolve it:** Generate synthetic feedback with a “true” model differing from the learner’s assumptions (e.g., different rationality parameter β_true); evaluate performance across mismatches and compare alternative likelihoods.

## Limitations
- Likelihood mis-specification: The joint posterior assumes accurate, conditionally independent likelihood models; errors in any modality can corrupt the reward estimate.
- Amortization generalization: The shared encoder may not extrapolate to out-of-distribution transitions or feedback patterns, leading to degenerate reward estimates.
- TD-constraint dependency: The Q-model’s convergence is critical; if it fails, the reward alignment becomes unreliable.

## Confidence
- Joint Bayesian formulation: High
- Multi-feedback superiority: Medium
- Robustness to perturbations: Medium
- Amortization scalability: Medium-Low

## Next Checks
1. Cross-benchmark replication: Reimplement MAVRL and test on additional multi-feedback suites (e.g., Meta-World, DMControl) with diverse combinations to verify consistent performance improvements.
2. Likelihood sensitivity analysis: Systematically perturb the generative assumptions (e.g., different rationality parameter β_true vs. β_learner, non-Bradley-Terry noise) and measure degradation in reward recovery (EPIC distance) and policy returns.
3. Scalability stress test: Apply MAVRL to high-dimensional continuous control tasks (e.g., humanoid from pixels) to evaluate training stability, sample efficiency, and whether the amortized encoder/decoder architecture scales without reward collapse.
