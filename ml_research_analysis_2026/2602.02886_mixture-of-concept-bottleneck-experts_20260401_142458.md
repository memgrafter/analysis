# Mixture of Concept Bottleneck Experts

## Quick Facts
- **arXiv ID**: 2602.02886
- **Source URL**: https://arxiv.org/abs/2602.02886
- **Reference count**: 40

## Executive Summary
Existing Concept Bottleneck Models (CBMs) restrict the task predictor to a single linear or Boolean expression, which limits accuracy and adaptability. This work introduces the Mixture of Concept Bottleneck Experts (M-CBE), a generalization that varies both the number of experts and the functional form of each expert (e.g., linear, symbolic expressions under user-defined operators). Two instantiations are presented: Linear M-CBE and Symbolic M-CBE, the latter employing symbolic regression to discover interpretable expressions. Evaluated on nine datasets, M-CBEs achieve superior accuracy-interpretability trade-offs: algebraic forms outperform Boolean logic by up to 65% accuracy in high-dimensional settings, multiple experts mitigate incomplete concept sets, and Symbolic M-CBE recovers ground-truth mechanisms with near-zero Tree Edit Distance and high intervention responsiveness. Moreover, the framework adapts post-hoc to user-specified operator vocabularies without retraining.

## Method Summary
The M-CBE framework formulates the task predictor as a conditional mixture over \(M\) expression trees: \(p(y,c|x) = p(c|x) \sum_{m=1}^M p(m|x) p(y|c, t_m)\), where \(p(c|x)\) is the concept encoder, \(p(m|x)\) is a selector network, and each expert \(t_m\) is an expression tree with a fixed functional form. Two instantiations are explored: Linear M-CBE, where each expert is a linear model (fixed tree structure with learnable weights and \(\ell_1\) regularization), and Symbolic M-CBE, which discovers interpretable symbolic expressions via PySR. Training uses AdamW with loss weighting \(\lambda_c=1.0\), \(\lambda_y=0.1\), and includes hard thresholding for Linear M-CBE. Symbolic M-CBE follows a three-stage pipeline: (1) train encoder, selector, and MLP experts; (2) collect predictions and run symbolic regression on each expert’s assigned data subset to obtain a symbolic tree constrained to a user-specified operator set; (3) replace MLPs with symbolic expressions and fine‑tune parameters. The method supports post‑hoc adaptation by changing the operator vocabulary and re‑running symbolic regression without full retraining.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: A mixture of expert expression trees improves accuracy and robustness by capturing heterogeneous concept-to-task relationships.
- **Mechanism**: The task predictor is a conditional mixture over \(M\) expression trees. A selector network \(p(m|x)\) routes each input to one expert; each expert implements a fixed functional form (e.g., linear, symbolic). This allows different input regions to use different combining functions.
- **Core assumption**: The data-generating process can be partitioned into \(M\) subspaces where a single simple expression is sufficient within each subspace.
- **Evidence anchors**: Abstract (multiple experts compensate); Section 3.2 (Equation 3, Theorem 2); corpus (mixtures for interpretable predictors underexplored).

### Mechanism 2
- **Claim**: Algebraic functional forms (e.g., linear, symbolic expressions) scale to high-dimensional concept spaces, while rigid Boolean logic degrades.
- **Mechanism**: Expression trees with continuous operators (+, ×, sin, etc.) aggregate concept predictions. Errors in individual concepts are smoothed by continuous summation. In contrast, purely Boolean formulas fail entirely if any concept is mispredicted.
- **Core assumption**: Concept predictions are noisy; task functions are better approximated by continuous combinations than discrete logic in high dimensions.
- **Evidence anchors**: Abstract (algebraic forms outperform Boolean); Section 5.1 (Figure 4, Figure 8); corpus (most assume Boolean/linear).

### Mechanism 3
- **Claim**: Symbolic M‑CBE adapts to user‑specified operator vocabularies post‑hoc without full retraining, enabling user‑aligned interpretability.
- **Mechanism**: After training the concept encoder and selector with placeholder black‑box experts (MLPs), symbolic regression (e.g., PySR) distills each expert’s function from its assigned data subset, constrained to a user‑provided operator set \(W\). Only numeric parameters of the symbolic expressions are fine‑tuned.
- **Core assumption**: The learned concept embeddings are sufficiently expressive and disentangled that symbolic regression can recover accurate expressions under different operator constraints.
- **Evidence anchors**: Abstract (post‑hoc adaptation); Section 4 (three‑stage pipeline, Table 2); corpus (symbolic regression used for surrogate modeling but not customizable CBMs).

## Architecture Onboarding
**Component map**: Input -> Concept encoder (shared) -> Concept predictions -> Selector (MLP) -> Distribution over M experts -> Sampled expert index m -> Expert m (expression tree with parameters Θₘ) -> Task output.

**Critical path**:
- Linear M-CBE: End‑to‑end training of encoder, selector, and linear experts with ℓ₁ regularization and hard thresholding.
- Symbolic M-CBE: (1) Train encoder, selector, and MLP experts. (2) Collect predictions, run PySR on each expert’s assigned data subset to obtain symbolic tree. (3) Replace MLPs with symbolic expressions and fine‑tune parameters.

**Design tradeoffs**:
- Number of experts M: Increasing M improves accuracy (Theorem 2) but reduces global interpretability (more expressions to inspect).
- Functional form: Linear → simplest and stable; symbolic → more expressive but complex; Boolean → brittle in high‑dimensional settings.
- Post‑hoc adaptability: Only Symbolic M-CBE supports changing operator vocabulary without retraining; requires symbolic regression step.

**Failure signatures**:
- Boolean experts (CMR, DCR) suffer near‑100% error on high‑dimensional datasets (e.g., CUB200, CIFAR10 with >100 concepts).
- Selector network is a black box; no guarantee of semantically meaningful routing.
- Symbolic regression may yield overly complex expressions if operator set is large or sparsity regularization is weak.

**First 3 experiments**:
1. **Pareto frontier**: Train M‑CBE variants (M=1…5, linear/symbolic) on all datasets. Plot task accuracy vs. total node count. Verify algebraic forms dominate Boolean in high dimensions and multiple experts help incomplete concepts.
2. **Intervention response**: Replace predicted concepts with ground truth at increasing fractions. Compute task error drop. Expect Sym‑M‑CBE to nearly reach zero error on regression (ground‑truth mechanisms recovered); Lin‑M‑CBE best on classification.
3. **Operator adaptability**: For Sym‑M‑CBE, after full training, change operator vocabulary (e.g., remove sin) and re‑evaluate without retraining. Accuracy should remain stable if the true function uses only retained operators.

## Open Questions the Paper Calls Out
- **Open Question 1**: How can the selector network's routing decisions in M‑CBEs be made interpretable? The current MLP‑based selector is a black box, undermining global interpretability.
- **Open Question 2**: Can symbolic regression in Sym‑M‑CBE be optimized for computational efficiency in large‑scale settings? The heuristic search (e.g., genetic algorithms) is computationally intensive.
- **Open Question 3**: What data‑driven method can automatically determine the optimal number of experts M in M‑CBEs? Manual tuning is tedious and may not generalize.
- **Open Question 4**: How can Boolean‑based Concept Bottleneck Models be enhanced to scale effectively with high‑dimensional concept spaces? Boolean rules are brittle; need robust extensions.

## Limitations
- Hyperparameter details (learning rates, batch sizes, architecture specifics) are not fully disclosed, hindering exact replication.
- The selector network operates as a black box, so its routing decisions lack semantic interpretability.
- The method assumes the data can be partitioned into subspaces where simple expressions suffice; if the true mapping is globally smooth, the mixture may overfit.

## Confidence
