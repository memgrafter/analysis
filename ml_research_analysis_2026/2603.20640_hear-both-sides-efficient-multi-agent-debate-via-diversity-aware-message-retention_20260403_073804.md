# Hear Both Sides: Efficient Multi-Agent Debate via Diversity-Aware Message Retention

## Quick Facts
- **arXiv ID:** 2603.20640
- **Source URL:** https://arxiv.org/abs/2603.20640
- **Reference count:** 40
- **Primary result:** DAR improves multi-agent debate accuracy by up to ~10% relative and reduces token waste via diversity-aware filtering, with gains scaling to more agents.

## Executive Summary
Multi-agent debate (MAD) iteratively exchanges agent responses to improve reasoning, but broadcasting all messages each round introduces noise and redundancy that degrade performance and waste computational resources. This paper proposes Diversity-Aware Retention (DAR), a lightweight framework that selects at each round only the most diverse and disagreeing subset of peer responses for broadcast. DAR uses an index-based filter that outputs agent IDs, preserving original content unchanged, and augments prompts with uncertainty scores and majority votes to guide generation. Experiments across six reasoning/QA benchmarks and four LLM backbones (1.5B–8B) show DAR consistently outperforms strong baselines, with benefits growing as the number of agents increases, demonstrating that controlling what agents hear is as crucial as what they say.

## Method Summary
DAR modifies standard MAD by inserting a filtering step between rounds. After each round, a dedicated filter agent `F` (using the same LLM backbone) selects a subset of peer responses that maximally disagree with each other and with the previous majority vote. The filter outputs only the IDs of these responses; the original, unmodified messages are then retrieved and broadcast to all agents. Agent prompts are augmented with (a) the retained responses, (b) the prior majority vote, and (c) uncertainty scores (ANLL) for each peer response. A fallback reverts to broadcasting all responses if no meaningful disagreement is detected. This separation of selection from generation aims to reduce noise while preserving authentic alternative reasoning paths.

## Key Results
- DAR achieves average accuracy gains up to ~10% relative over baselines like Society Of Mind, MAD-M2, and majority vote across six benchmarks (Arithmetics, Formal Logic, CommonsenseQA, etc.).
- Efficiency improves via token reduction; DAR retains fewer messages per round without sacrificing accuracy.
- Benefits scale positively with more agents (N=2,4,8), where noise accumulation is most severe, outperforming baselines by larger margins at N=8.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Selective message broadcasting reduces noise and redundancy that degrade debate quality and waste resources.
- **Mechanism:** At each debate round, DAR filters the full set of peer responses to retain only a diverse subset before broadcasting to all agents. This avoids overwhelming agent context with repetitive or low-value content.
- **Core assumption:** Not all agent responses contribute equally to productive debate; redundant or noisy responses harm collective reasoning more than they help.
- **Evidence anchors:**
  - [abstract] "broadcasting all messages each round introduces noise and redundancy that degrade performance and waste resources."
  - [section 1] "This broadcasting of all messages introduces two compounding problems. First, redundant responses... provide little additional signal while consuming significant token capacity. Second, noisy or low-quality generations can actively mislead other agents."
  - [corpus] Related work (e.g., "Multi-Agent Debate with Memory Masking") also identifies noise accumulation as a key scalability challenge.
- **Break condition:** If all agent responses are already highly dissimilar or the filtering module fails to identify meaningful disagreement (fallback to standard MAD).

### Mechanism 2
- **Claim:** Preserving *informative disagreement*—responses that are mutually diverse and opposed to the majority—enhances reasoning more than filtering by confidence or simple diversity.
- **Mechanism:** The filter agent `F` selects IDs of responses that maximally disagree with each other and with the last majority vote. This explicitly retains alternative reasoning paths that might contain correct insights, even if they are minority positions.
- **Core assumption:** Disagreement is a more reliable signal for useful information than confidence, which is often miscalibrated; diverse perspectives increase the probability of correct convergence.
- **Evidence anchors:**
  - [section 3.4] "We formulate the selection objective as `Sr =arg max S ⊆Gr−1 Diversity(S)−λ|S |`... retain a compact subset of responses that preserves the diversity of opinions."
  - [section 4.3.1] "LLM-based filtering performs soft reasoning-aware selection, retaining responses with different reasoning paths while discarding redundant or weak answers."
  - [corpus] Corpus shows emerging interest in "confidence and diversity" (e.g., "Demystifying Multi-Agent Debate"), but DAR's specific diversity-aware retention is a novel operationalization.
- **Break condition:** When all responses converge to identical answers (no meaningful disagreement exists), DAR falls back to retaining all responses.

### Mechanism 3
- **Claim:** Index-based retention (outputting only agent IDs) preserves original response authenticity and avoids content distortion, while still enabling controlled information flow.
- **Mechanism:** The filter outputs a list of IDs; the original, unmodified messages at those IDs are retrieved and broadcast. This separates the *selection* decision from *content generation*, preventing the filter from inadvertently altering or paraphrasing retained messages.
- **Core assumption:** Using an LLM-based judge to directly edit or regenerate responses risks introducing new errors or biases, especially for smaller models. Selection without modification is safer and more interpretable.
- **Evidence anchors:**
  - [section 3.4] "F outputs only agent IDs, ensuring retained content remains unchanged and avoiding unintended modifications from LLM-based editing... This enforces selection rather than regeneration, preserving disagreement while reducing redundancy."
  - [abstract] "Through an explicit index-based retention mechanism, DAR preserves the original messages without modification, ensuring that retained disagreements remain authentic."
  - [corpus] Corpus does not directly address index-based filtering; this is an assumed design advantage based on the paper's rationale.
- **Break condition:** If the filter produces invalid IDs or an empty set (handled by fallback to standard MAD).

## Foundational Learning
- **Concept: Multi-Agent Debate (MAD) protocol**
  - Why needed here: DAR is a modification of standard MAD; understanding the baseline decentralized broadcast topology (all agents see all peers' responses each round) is essential to see what DAR changes.
  - Quick check question: In standard MAD, what information does each agent receive at the start of round `r`, and what is the primary scalability problem as `N` agents increase?

- **Concept: Uncertainty estimation in LLMs (ANLL)**
  - Why needed here: DAR *incorporates* uncertainty scores (via ANLL) into prompts to *guide* agent generation, but deliberately does *not* use them for filtering. Distinguishing this use case from uncertainty-based filtering (like MAD-M2) is key.
  - Quick check question: What is Average Negative Log-Likelihood (ANLL) and why might it be miscalibrated for filtering responses in MAD?

- **Concept: Diversity metrics for text**
  - Why needed here: DAR's filter optimizes for "maximal disagreement." Understanding this as something like pairwise dissimilarity (e.g., embedding distance) or answer variance is necessary to grasp the selection criterion.
  - Quick check question: How might one operationally define "disagreement" among a set of free-text LLM responses? What are the trade-offs of using semantic similarity vs. exact answer match?

## Architecture Onboarding
- **Component map:** Agent Pool (N identical LLMs) -> Filter Module F (LLM) outputs IDs of retained messages -> Prompt Template adds uncertainty scores and majority vote -> Fallback Handler (reverts to all if no disagreement) -> Broadcast retained responses -> Agents generate new round -> Majority Vote Calculator aggregates final answer.
- **Critical path:** Round r start -> Compute v_{r-1} from S_{r-1} -> Compute ANLL for each in S_{r-1} -> Call F(G_{r-1}, v_{r-1}) → I_ret_r -> Fallback check -> Build prompt for each agent using S_r = {g_{r-1,i} for i in I_ret_r} + v_{r-1} + uncertainties -> Generate G_r -> Repeat until R rounds -> Final majority vote from G_R.
- **Design tradeoffs:**
  - **Index-based vs. content-based filtering:** Index-based preserves authenticity but relies on a separate LLM call for selection; content-based (e.g., rewriting) risks distorting original disagreements.
  - **Filter LLM choice:** Using the same backbone as agents is training-free and consistent, but the filter's own biases/calibration affect selection quality.
  - **Fallback strategy:** Simple (retain all on no disagreement) avoids over-filtering but may not reduce noise when all responses are redundant but incorrect.
- **Failure signatures:**
  - **Filter misselection:** `F` returns IDs that are *not* diverse (e.g., picks only majority answers) due to poor prompt design or model capability. Symptom: performance degrades vs. standard MAD.
  - **Prompt formatting error:** Uncertainty scores or majority vote not inserted correctly into agent prompts. Symptom: agents ignore guidance, performance drops.
  - **Scaling with `N`:** Filter may become less effective as `N` grows, if it cannot identify a sufficiently diverse subset from many similar responses. Monitor diversity metric (e.g., avg pairwise distance) of `S_r`.
  - **Fallback over-triggering:** Filter too often sees "no disagreement" due to strict criteria, nullifying DAR's benefits.
- **First 3 experiments:**
  1. Replicate Table 1 (Decentralized MAD, N=4): Verify DAR outperforms baselines (Society Of Mind, MAD-M2, Uncertain Prompt, Majority Vote, Vote Prompt) across all models/datasets. Check if gains are consistent, especially on Arithmetics/Form.Log.
  2. Ablation: Disable Filter Components (Table 3): Run DAR without Uncertain Prompt, without Vote Prompt, and with hard-coded "certain/similar answers" selection. Expect full DAR to perform best, confirming synergy of LLM-based diversity filter + prompt guidance.
  3. Scaling Experiment (Figure 2): Increase `N` from 2 to 8. Expect DAR's relative advantage over baselines (especially Majority Vote) to grow as `N` increases, demonstrating effective noise control in larger debates.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can we reliably filter messages in multi-agent debate without relying on miscalibrated uncertainty estimates?  
  *Basis in paper:* [explicit] The paper explicitly critiques uncertainty-based filtering as unreliable due to miscalibrated confidence scores and threshold sensitivity.  
  *Why unresolved:* The paper proposes diversity as one solution, but other potential filtering criteria (e.g., novelty, correctness proxies) remain unexplored.  
  *What evidence would resolve it:* Develop and evaluate alternative filtering mechanisms that do not use uncertainty, comparing their performance and robustness against DAR across diverse benchmarks and models.

- **Open Question 2:** Can the LLM-based filter in DAR be replaced with a lightweight, non-LLM diversity metric (e.g., embedding-based) without significant performance loss?  
  *Basis in paper:* [inferred] DAR uses an LLM agent to select messages, adding computational cost and potential generation issues; the paper does not consider simpler, deterministic diversity metrics.  
  *Why unresolved:* A non-LLM filter could improve efficiency and scalability, especially for large numbers of agents or rounds, but might lack the soft reasoning of an LLM.  
  *What evidence would resolve it:* Implement DAR with various diversity metrics (e.g., cosine similarity of embeddings, lexical diversity) and compare accuracy, speed, and robustness on the same benchmarks.

- **Open Question 3:** Does DAR's advantage hold for very large-scale debates (e.g., hundreds of agents) and many rounds?  
  *Basis in paper:* [inferred] Experiments only scale up to N=8 and R=7; the claim that DAR scales well is based on limited scaling results.  
  *Why unresolved:* The filter’s computational complexity and the nature of noise/redundancy may change dramatically with scale, potentially altering the cost-benefit trade-off.  
  *What evidence would resolve it:* Conduct simulations or experiments with N=50–100 agents and R=10–20, measuring accuracy, diversity metrics, and wall-clock time to assess scalability.

- **Open Question 4:** Is there an optimal number of messages to retain per debate round, and should this be adaptive to the debate state?  
  *Basis in paper:* [inferred] DAR selects a variable number of messages based on disagreement without explicit control over subset size; the trade-off between information and noise remains unstudied.  
  *Why unresolved:* Retaining too few messages may lose critical information; too many may reintroduce noise. An adaptive strategy could tune retention based on round, agent count, or task.  
  *What evidence would resolve it:* Systematically vary the maximum number of retained messages (e.g., from 1 to N) across rounds and benchmarks, analyzing the impact on final accuracy and efficiency.

## Limitations
- Filter LLM biases may skew selection; using the same backbone inherits its inclinations (e.g., favoring certain reasoning styles).
- Overhead of an extra filter call may erode efficiency gains; paper reports token savings but not end-to-end latency.
- Evaluation restricted to reasoning/QA benchmarks with models ≤8B; generalization to larger models or other tasks (e.g., dialogue, coding) is unclear.
- Fallback to broadcasting all when disagreement is low might re‑introduce noise if all responses are redundantly wrong.
- Diversity metric implementation is underspecified; likely based on LLM judgments, reducing reproducibility.

## Confidence
- *DAR improves accuracy and token efficiency vs. baselines*: **High** (consistent across 6 datasets, 4 models, N=2,4,8).
- *Diversity‑aware retention captures informative disagreement*: **High** (ablation in Table 3 shows filter + prompts essential; scaling benefits).
- *Index‑based retention preserves authenticity*: **Medium** (plausible rationale but no direct comparison to content‑based alternatives).
