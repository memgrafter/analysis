# Effect-Level Validation for Causal Discovery

## Quick Facts
- **arXiv ID:** 2602.08340
- **Source URL:** https://arxiv.org/abs/2602.08340
- **Reference Count:** 31
- **Primary Result:** Graph-level accuracy metrics (e.g., SHD) are inadequate proxies for causal reliability; effect-level admissibility and validation are necessary for trustworthy inference in feedback-driven telemetry systems.

## Executive Summary
The paper addresses a critical gap in causal discovery for telemetry data: standard graph recovery metrics do not guarantee reliable causal effect estimates needed for decision-making in systems with strong self-selection. The authors propose an effect-centric framework that re-frames discovered graphs as structural hypotheses, subject to an admissibility gate (checking identifiability and positivity) before effect estimation, followed by stability and falsification validation. Applied to real game telemetry studying early gameplay on retention, they find that many statistically plausible graphs become inadmissible under minimal temporal and semantic constraints, highlighting identifiability as a primary bottleneck. Despite structurally divergent outputs, certain algorithm families (PC, GRaSP, BOSS) converge to a stable effect estimate (~0.143 risk difference) that survives multiple refutation tests, while other methods show sporadic admissibility and sensitivity. The work demonstrates that moving from graph-centric to effect-centric evaluation is essential for trustworthy causal conclusions.

## Method Summary
The proposed pipeline treats a discovered graph not as a final truth but as a hypothesis to be vetted for a specific causal query (e.g., ATE of early gameplay on retention). First, an admissibility filter checks if the graph structure and imposed constraints (temporal, semantic) allow point identification of the effect and satisfy positivity. Inadmissible graphs are discarded. For admissible graphs, the causal effect is estimated (e.g., via adjustment). Finally, a validation stage assesses robustness through stability checks (varying algorithm parameters, subsampling) and falsification tests (placebo outcomes, sensitivity analysis with E-values). A heuristic decision rubric ("Trust", "Caution", "Reject") synthesizes these diagnostics. The approach is evaluated on a large telemetry dataset from a competitive game, comparing numerous discovery algorithms under varying constraint sets.

## Key Results
- Standard graph recovery metrics (e.g., SHD) are poor proxies for effect-level reliability; many graphs with high structural accuracy fail the admissibility gate for the target query.
- Identifiability is the critical bottleneck: enforcing minimal temporal and semantic constraints causes a large fraction of outputs (especially from latent-aware methods like FCI) to yield undefined effects.
- Despite divergent graph structures (some lacking a direct treatment-outcome edge), PC, GRaSP, and BOSS converge to a stable, decision-consistent effect estimate (~0.143) that passes placebo, subsampling, and sensitivity refutation (E-value 1.66), while other methods do not.

## Why This Works (Mechanism)
The framework succeeds by decoupling *graph plausibility* from *effect reliability*. A graph may be a statistically good fit to the data (low SHD) but still fail to support a valid, identifiable estimate for the specific query due to latent confounding or violation of positivity. The admissibility gate explicitly checks these query-specific conditions before any effect is computed, discarding graphs that would lead to untrustworthy estimates. The subsequent validation layer then tests whether the estimated effect from the remaining graphs is stable to modeling choices and resistant to obvious falsification. This two-stage filter (admissibility then validation) ensures that a "trusted" effect is not only identifiable in principle but also empirically robust, moving the focus from recovering a "true" graph to securing a reliable decision-enabling estimate.

## Foundational Learning
- **Causal Effect Identifiability**: Whether a target causal query (e.g., ATE) can be expressed as a function of the observed data distribution given a graph. *Why needed*: The admissibility gate requires checking if the discovered graph, with constraints, allows a non-ambiguous effect formula. *Quick check*: Can you write the do-calculus expression for P(Y|do(X)) using only observed variables?
- **Positivity (Overlap)**: The assumption that every combination of treatment and covariates has non-zero probability in the data. *Why needed*: Even if identifiability holds, effect estimation (e.g., via weighting) fails if some strata are unsupported. *Quick check*: For a proposed adjustment set, do all treatment-covariate cells have sufficient samples?
- **Conditional Independence Testing**: The statistical engine of constraint-based discovery (e.g., PC, FCI). *Why needed*: Graph skeleton and orientation depend entirely on CI test outcomes, which are sensitive to sample size, test choice, and α threshold. *Quick check*: How does changing the α threshold affect the number of CI rejections and the resulting graph?
- **Markov Equivalence**: The set of graphs encoding the same conditional independence relations. *Why needed*: Different algorithms may output graphs from different MECs; effect equivalence across MECs is not guaranteed. *Quick check*: Given two output graphs, are they Markov equivalent? Do they imply the same set of valid adjustment sets for X→Y?
- **Temporal and Semantic Constraints**: Domain knowledge used to break symmetries and enforce causal direction (e.g., "session start" cannot be caused by "end-game match"). *Why needed*: Without such constraints, many graphs are admissible but uninformative; with them, identifiability becomes a hard filter. *Quick check*: Which constraints are necessary to orient a specific edge (e.g., R1→Total_Session)?
- **Refutation Diagnostics**: Methods like placebo tests, subsampling robustness, and sensitivity analysis (E-value) to probe effect stability. *Why needed*: A single admissible graph and effect estimate are never definitive; these tests assess vulnerability to hidden bias or sampling variation. *Quick check*: Does the effect estimate survive when the outcome is replaced with a pre-treatment variable?

## Architecture Onboarding
**Component Map:** Raw Telemetry -> Causal Discovery Algorithms -> Graph Outputs -> Admissibility Filter (Identifiability + Positivity) -> Effect Estimation -> Validation Suite (Stability + Falsification) -> Trust Decision

**Critical Path:** The core path from data to decision passes through the admissibility filter. Any graph failing identifiability or positivity is terminated immediately; only survivors proceed to effect estimation and validation. The trust decision depends on both the admissibility pass and the validation suite outputs.

**Design Tradeoffs:**  
- *Constraint Strictness*: Tighter temporal/semantic constraints increase identifiability rates but risk excluding valid structures (false negatives). The paper uses a manually specified set (C1-C3), trading off generalizability for domain specificity.  
- *Algorithm Selection*: The framework is algorithm-agnostic, but output diversity affects the validation. Methods prone to sparse graphs (e.g., BOSS) may have different failure modes than dense ones (e.g., GES).  
- *Validation Thresholds*: The "Trust"/"Caution"/"Reject" buckets use heuristic cutoffs (e.g., effect SD < 0.01). These are not theoretically derived and may be context-sensitive.

**Failure Signatures:**  
1. Graph fails admissibility: No valid adjustment set exists under constraints, or positivity is violated.  
2. Effect instability: Large variance across algorithm hyperparameters (α), subsamples, or constraint variants.  
3. Falsification: Placebo test yields significant effect; low E-value indicates high sensitivity to unmeasured confounding.

**First 3 Experiments:**  
1. Apply the complete pipeline to a second telemetry dataset from a different game genre, checking if the convergent effect (~0.143) and algorithm family performance (PC/GRaSP/BOSS stability) replicate.  
2. Run a simulation study with known DAGs: generate data matching the telemetry schema, apply discovery+validation, and measure how often the "Trust" effect recovers the true ATE versus graph-level SHD.  
3. Conduct a systematic constraint ablation: turn on/off each individual constraint (C1, C2, C3) and measure the change in (a) admissibility rate per algorithm, (b) effect estimate variance, and (c) trust decision rate.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How can causal discovery pipelines be systematically adapted to guarantee effect identifiability in feedback-driven telemetry systems with strong self-selection, given that many statistically plausible graphs fail the admissibility gate?
- **Basis in paper**: [explicit] The authors repeatedly identify identifiability as the "critical bottleneck" and "primary bottleneck" (Abstract, Sections 5.6, 5.8), noting that "many statistically plausible discovery outputs do not admit point-identified causal queries once minimal temporal and semantic constraints are enforced" (Abstract). They observe this failure is particularly acute for latent-aware methods (e.g., FCI, GRaSP-FCI).
- **Why unresolved**: The paper demonstrates the problem empirically but does not provide a theoretical or algorithmic explanation for *why* certain method families (PC, BOSS, GRaSP) consistently produce identifiable structures while others (FCI-family) do not under the same constraints. The underlying causal assumptions of the algorithms and their interaction with the temporal/semantic constraints remain uncharacterized.
- **What evidence would resolve it**: A formal analysis comparing the_search procedures_, conditional independence test properties, and latent variable handling strategies across algorithm families under the specific constraint regime used in the paper (e.g., mixed data, temporal slicing, domain priors). This would require synthetic experiments where ground-truth identifiability for the target query is known, allowing the decomposition of failure modes by algorithm type.

### Open Question 2
- **Question**: What is the minimal set of domain constraints (temporal, semantic, measurement) required to ensure both identifiability of a target causal effect and generalizability (i.e., robustness to misspecification) across discovery algorithms?
- **Basis in paper**: [inferred] The constraint ladder ablation (Section 5.3, Table 3) shows that tightening constraints increases the identifiability rate (0% -> 33%) while stabilizing the effect magnitude. However, the "minimal" constraint set that guarantees identifiability for the widest range of methods is not systematically determined. The choice of constraints (C1-C3) appears ad hoc based on telemetry semantics (Appendix B). The trade-off between constraint strictness (which may rule out valid structures) and permissiveness (which admits non-identifiable graphs) is not quantified.
- **Why unresolved**: The paper uses a fixed, manually specified constraint set. The sensitivity of identifiability and effect stability to *which* constraints are enforced (as opposed to just how many) is unexplored. A constraint that eliminates non-identifiable graphs might also inadvertently exclude structures that would yield the same stable effect estimate.
- **What evidence would resolve it**: A systematic constraint ablation study that varies the presence/absence of each individual constraint type (e.g., forbidding R1→*, forbidding *→Web3, enforcing PvE→Total_Session) across multiple algorithms and synthetic datasets with known identifiability properties. The outcome would be a map of constraint combinations that maximize the "trust" label rate (from the decision protocol in Appendix E) without overfitting to the specific telemetry schema.

### Open Question 3
- **Question**: Under what conditions do structurally divergent causal graphs (including those lacking a direct treatment-outcome edge) yield convergent and robust total effect estimates for a given target query?
- **Basis in paper**: [explicit] A key finding is that "several algorithm families converge to similar, decision-consistent effect estimates despite producing substantially different graph structures, including cases where the direct treatment–outcome edge is absent and the effect is preserved through indirect causal pathways" (Abstract, Section 5.7). This convergence is observed for PC, GRaSP, and BOSS.
- **Why unresolved**: The paper observes this phenomenon but does not explain the sufficient graph-theoretic or data-generating conditions that cause it. Is convergence guaranteed if all admissible graphs encode the same set of *unshielded colliders* or *immoralities* involving the treatment and outcome? Does it require that all admissible adjustment sets (though potentially different) condition on the same *minimal* sufficient covariates? The theoretical conditions for effect equivalence under graph uncertainty are not derived.
- **What evidence would resolve it**: Analytical proofs or extensive simulations on structural causal models (SCMs) where the true DAG is known. By enumerating all DAGs consistent with a given conditional independence pattern (Markov equivalence class) and minimal constraints, one could characterize when the do-calculus yields the same ATE expression. Empirically, one would correlate convergence with graph metrics like the number of distinct minimal adjustment sets or the complexity of indirect paths (path length, mediator count).

### Open Question 4
- **Question**: How should multiple validation diagnostics (stability across algorithms/thresholds, placebo/subampling refutation, sensitivity E-values) be integrated into a single, operational "trust" metric for decision-making, rather than assessed in a离散 qualitative fashion?
- **Basis in paper**: [inferred] The proposed validation protocol (Appendix E) uses a decision rubric: "Trust: Effect stable and falsification passed; Caution: Sign-consistent but magnitude sensitive; Reject: Effect unstable or falsified." This dichotomizes continuous diagnostics (e.g., effect SD across α, E-value magnitude, p-value from placebo test) into coarse buckets. The authors note that "no single robustness metric is decisive" and that E-values should be "interpreted jointly" (Section 5.5), implying a need for a composite score.
- **Why unresolved**: The integration rule is heuristic and not formalized. For instance, what magnitude of effect instability (SD) is acceptable given a high E-value? How to weight a robust placebo test against moderate sensitivity to unmeasured confounding? The threshold for "stable" (e.g., SD < 0.01?) is arbitrary. This makes the "trust" decision subjective and not reproducible across analysts.
- **What evidence would resolve it**: Development of a formal multi-criteria decision analysis (MCDA) framework or a probabilistic model that combines the outputs of stability (variance across runs), falsification (p-values from placebo/subsampling), and sensitivity (E-value) into a posterior probability of "causal reliability" or a continuous trust score. This would require defining utility functions for decision outcomes (e.g., cost of false positive vs. false negative intervention) and calibrating the composite metric on historical cases where intervention outcomes are eventually known.

### Open Question 5
- **Question**: To what extent does endpoint ambiguity in telemetry variables (e.g., defining "retention" over a specific time window) causally bias discovered structures and their identified effects, and how can this be mitigated during discovery?
- **Basis in paper**: [explicit] The authors state that some methods exhibit "sporadic admissibility and threshold-sensitive or attenuated effects due to **endpoint ambiguity**" (Abstract, Section 5.8). This is contrasted with the stable estimates from PC/GRaSP/BOSS. The problem is gestured at but not defined or investigated.
- **Why unresolved**: The paper mentions "endpoint ambiguity" as a cause of admissibility failure and effect attenuation but does not define it operationally. Does it refer to the arbitrary choice of outcome window (24-48h)? To the coarseness of binary retention? To the aggregation of session counts? The mechanism by which endpoint specification affects conditional independence testing and edge orientation is not analyzed. This is a critical gap, as temporal binning is universal in telemetry analysis.
- **What evidence would resolve it**: A sensitivity analysis varying the outcome definition (e.g., Day-1 vs. Day-3 retention, binary vs. continuous engagement metric) across discovery algorithms. One would measure the change in (a) admissibility rate, (b) graph structure (e.g., edge orientation flips involving the outcome node), and (c) effect magnitude. Additionally, one could simulate data with known ground truth where the outcome is measured with different temporal granularities to see how discovery accuracy degrades. This would clarify whether "endpoint ambiguity" is a methodological flaw or an inherent data limitation.

## Limitations
- Single real-world dataset: Findings on algorithm convergence and effect stability may not generalize to other domains or data-generating processes.
- Subjective constraint specification: The admissibility constraints (C1-C3) are manually tailored to the telemetry schema; their necessity and sufficiency for identifiability are not theoretically grounded.
- Modest E-value (1.66): The surviving effect estimate shows some sensitivity to unmeasured confounding, limiting confidence for high-stakes decisions.
- Incomplete algorithm coverage: The evaluation includes many but not all popular causal discovery methods; results may depend on the chosen algorithm set.

## Confidence
- Graph-level metrics inadequacy: Medium. Supported by consistent across-algorithm patterns in one dataset, but lacking broader validation.
- Effect-centric admissibility framework improves trustworthy inference: Medium. Internal consistency and refutation tests are promising, but external validity uncertain.
- Identifiability as a key bottleneck: High. Directly demonstrated by high failure rate of graphs under minimal constraints.
- Convergent effect estimate (0.143) is robust: Low. Survives some refutation but E-value low; effect size small.
