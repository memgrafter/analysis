# Efficient Imputation for Patch-based Missing Single-cell Data via Cluster-regularized Optimal Transport

## Quick Facts
*   **arXiv ID:** 2601.14653
*   **Source URL:** https://arxiv.org/abs/2601.14653
*   **Reference count:** 0
*   **Primary result:** CROT achieves state-of-the-art imputation accuracy (highest PCC, lowest MAE) and clustering preservation (highest ARI/NMI/Purity) on patch-missing single-cell data while reducing runtime to ~1-2% of competing methods.

## Executive Summary
CROT is a novel imputation method designed for a challenging scenario in single-cell sequencing: entire feature blocks (e.g., an entire assay modality) are missing for a batch of cells. It addresses this by aligning the distribution of the incomplete data to a complete reference dataset using optimal transport. A key innovation is a cluster-regularization term that preserves biological cell-type identity during this alignment by matching cluster centroids between the two datasets. The method leverages entropic regularization and stochastic sampling for computational efficiency, making it significantly faster than existing imputation tools while producing more accurate recovered values and better downstream clustering.

## Method Summary
CROT treats imputation as an optimization problem with two datasets: a complete reference matrix `X1` and an incomplete target matrix `X2` where an entire set of columns (a "patch") is missing. Missing values in `X2` are initialized with column means from `X1` plus noise and then treated as continuous parameters to be optimized. The core loss function combines two Sinkhorn divergences (entropy-regularized Wasserstein distances): one aligns the row distributions of `X1` and the current `X2` to match global structure, and a second aligns the centroids of clusters found within each dataset to preserve biological groupings. Optimization proceeds via stochastic gradient descent (Adam), where in each iteration a random subset of rows is sampled, k-means clustering is performed on both samples to obtain centroids, the total loss is computed, and gradients update only the missing entries in `X2`. Preprocessing involves log1p normalization and selection of highly variable genes/proteins.

## Key Results
*   **Superior Accuracy:** On Citeseq, Multiome, and PBMC datasets, CROT achieves the highest Pearson Correlation Coefficient (PCC) and lowest Mean Absolute Error (MAE) for imputing the truly missing feature patch compared to other methods.
*   **Dramatic Efficiency Gain:** Runtime is reduced to approximately 1-2% of the average time required by competing imputation methods.
*   **Enhanced Cluster Preservation:** CROT yields the best scores on Adjusted Rand Index (ARI), Normalized Mutual Information (NMI), and Purity for cell-type clustering after imputation.

## Why This Works (Mechanism)
### Mechanism 1: Distribution Alignment via Optimal Transport
*   **Claim:** CROT imputes missing feature blocks by aligning the distribution of the incomplete data (`X2`) with a complete reference dataset (`X1`) using an optimal transport (OT) mapping.
*   **Mechanism:** The core loss minimizes the Sinkhorn divergence between the row distributions of `X1` and the imputed `X2`. This finds a transference plan that moves probability mass (cells) in `X2` to match `X1`'s distribution, filling missing features according to the reference's global manifold structure.
*   **Core assumption:** The incomplete batch (`X2`) shares the same underlying probabilistic data manifold as the complete batch (`X1`), despite a subset of features being entirely absent.
*   **Evidence anchors:** Abstract and Section 4.1 explicitly state the goal of aligning distributions. Section 5.7 (ablation) shows removing this term degrades global imputation metrics.
*   **Break condition:** If the missing patch corresponds to a fundamentally different biological condition or batch effect that shifts the entire feature distribution, aligning to a single `X1` reference may impose incorrect structure.

### Mechanism 2: Cluster Structure Preservation via Regularization
*   **Claim:** A cluster-regularization term preserves biological cell-type identity during imputation by aligning the centroids of cell clusters between `X1` and `X2`.
*   **Mechanism:** In each optimization iteration, k-means clustering is applied to sampled rows from `X1` and the current `X2` imputation. The second loss term penalizes the Sinkhorn divergence between the sets of cluster centroids (`C1`, `C2`). This encourages that imputed cells of a given type maintain a similar prototype expression profile to the same type in the reference.
*   **Core assumption:** Distinct cell types/clusters exist and are identifiable in the complete reference data (`X1`), and these cluster structures are preserved and recoverable in the incomplete data (`X2`) after imputation.
*   **Evidence anchors:** Abstract and Section 4.1 describe the regularization. Table 3 (ablation) shows removing the cluster loss (`L2`) degrades ARI/NMI, confirming its role.
*   **Break condition:** If the missing feature patch is highly discriminative for a specific cell type, cluster centroids for that type may be poorly estimated in `X2`, making alignment to `C1` misleading.

### Mechanism 3: Stochastic Efficiency via Sampling and Entropic OT
*   **Claim:** Computational efficiency and scalability are achieved through (a) entropic regularization of OT (Sinkhorn divergence) and (b) stochastic sampling of data rows during optimization.
*   **Mechanism:** The Sinkhorn algorithm replaces the costly combinatorial OT problem with an iterative scaling procedure on a transport matrix of size `l x l` (where `l` is the sample batch size). Furthermore, a small random subset (`l`) is sampled each iteration to compute both losses, avoiding full-data operations.
*   **Core assumption:** A random subset of cells (`l`) is sufficiently representative to estimate the gradient direction for aligning the full distributions of `X1` and `X2`.
*   **Evidence anchors:** Section 4.3 complexity analysis highlights cost dependence on `l`, not total cells `m`. Section 5.6 (Figure 1) runtime results show ~1-2% of other methods' time.
*   **Break condition:** If the sample size `l` is too small relative to the number of true biological clusters `k`, the mini-batch may not contain representatives from all clusters, causing unstable centroid estimation.

## Foundational Learning
*   **Entropic Regularization & Sinkhorn Divergence:** Provides a differentiable, efficiently computable surrogate for the Wasserstein distance, enabling gradient-based optimization in high dimensions. *Why needed here:* Replaces intractable combinatorial OT with iterative scaling. *Quick check:* How does the entropy regularization parameter `ε` trade off accuracy vs. speed of OT computation?
*   **k-means Clustering for Prototype Estimation:** Generates the cluster centroids (`C1`, `C2`) that are regularized to align, acting as a low-dimensional summary of cell-type identity. *Why needed here:* Creates biologically meaningful anchors for the regularization term. *Quick check:* Why are cluster centroids (means) used as prototypes instead of, say, full covariance structures?
*   **Stochastic Gradient-based Imputation:** Treats missing entries in `X2` as continuous parameters optimized via gradient descent (Adam), using a loss defined on samples. *Why needed here:* Enables scalable, direct optimization of the imputation task without discrete steps. *Quick check:* What is the risk of using gradient-based updates directly on the data matrix `X2` for imputation?

## Architecture Onboarding
*   **Component map:**
    Initialization (fill missing with `X1` means + noise) -> Clustering Module (k-means on `X1_sample` & `X2_current`) -> Loss Calculator (`L = Sinkhorn(data) + α * Sinkhorn(centroids)`) -> Optimizer (Adam step updates only missing entries in `X2`) -> Repeat for `T` iterations.
*   **Critical path:** The iterative loop: Sample rows -> Cluster to get `C1, C2` -> Compute total loss `L` -> Update `X2`'s missing values via gradient -> Repeat.
*   **Design tradeoffs:**
    *   `α`: Balances global distribution alignment vs. cluster structure preservation. High `α` risks distorting global fit.
    *   Sample size `l`: Larger `l` improves gradient estimate and cluster stability but increases per-iteration cost (O(l²)).
    *   `k`: Must be pre-set via Elbow method on `X1`. Incorrect `k` harms regularization's biological meaning.
*   **Failure signatures:**
    *   **No convergence:** Loss oscillates or plateaus high. Check `ε` (Sinkhorn reg) and learning rate.
    *   **Collapsed clusters:** Post-imputation UMAP shows all cells merged. Cluster loss weight `α` may be too low.
    *   **Over-smoothed values:** PCC high but ARI low. Indicates global alignment succeeded but cluster structure lost; increase `α`.
*   **First 3 experiments:**
    1.  **Sanity Check on Synthetic Data:** Create 2D data with two Gaussian clusters, mask one entire dimension for 50% of points. Verify imputed dimension separates clusters visually and centroids align.
    2.  **Ablation of `α`:** On Citeseq, run CROT with `α ∈ {0.0, 0.5, 1.0, 2.0}`. Plot PCC (global fit) and ARI (cluster preservation) vs. `α`. Expect `α=0` decent PCC but poor ARI.
    3.  **Convergence & Initialization Impact:** Track RMSE, PCC, and ARI every 10 iterations from t=0 to convergence. Confirm initial RMSE drop then rise pattern and monotonic PCC/ARI improvement after early iterations.

## Open Questions the Paper Calls Out
*   **Open Question 1:** How can the class constraint strategy be refined to more effectively preserve biological cluster structures, given that current improvements in UMAP visualizations are subtle? (Appendix A.3 states: "Our effect is not obvious yet, and we expect to further refine the class constraint strategy in the future.")
*   **Open Question 2:** Can CROT be adapted to scenarios where no fully complete reference dataset is available, such as when all batches contain some missing data? (Section 4.1 describes requiring a complete `X1`, but real-world studies often lack this.)
*   **Open Question 3:** How robust is CROT to violations of the assumed similarity in cluster structures between complete and incomplete data, such as when batch effects cause divergent cell-type compositions or cluster numbers? (Experiments only use batches from the same dataset, implicitly assuming shared structures.)
*   **Open Question 4:** What is the sensitivity of CROT to key hyperparameters—particularly `α` and `k`—and how can they be optimally tuned without extensive manual search? (Section 4.1 fixes `α=1` empirically; `k` chosen via Elbow without sensitivity analysis.)

## Limitations
*   **Hyperparameter Gaps:** Critical parameters for the Sinkhorn solver (`ε`, inner iterations) and outer loop `T` are unreported, creating a significant tuning burden and blocking faithful replication.
*   **Ambiguous `k` Selection:** The Elbow method for determining cluster count `k` lacks specifics (tested range, quantitative elbow criterion), risking biologically inappropriate choices.
*   **Assumption Sensitivity:** Performance depends on the assumption that the incomplete batch shares the same manifold and cluster structure as the complete reference; violations (e.g., disease vs. healthy) may cause failure.

## Confidence
*   **Runtime Efficiency:** High. The algorithmic design (stochastic sampling + Sinkhorn) logically and consistently leads to massive speedups.
*   **Imputation Accuracy & Clustering:** Medium. Results are plausible and supported by ablations but are highly sensitive to unreported hyperparameters (`ε`, `T`, `α`, `k`).
*   **Biological Generalization:** Low. The method's core assumption may not hold across divergent biological conditions, and the paper provides no stress-testing.
