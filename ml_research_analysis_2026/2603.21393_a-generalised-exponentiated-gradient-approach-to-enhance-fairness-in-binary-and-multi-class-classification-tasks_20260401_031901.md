# A Generalised Exponentiated Gradient Approach to Enhance Fairness in Binary and Multi-class Classification Tasks

## Quick Facts
- arXiv ID: 2603.21393
- Source URL: https://arxiv.org/abs/2603.21393
- Reference count: 40
- Primary result: GEG achieves up to 92% fairness improvement with accuracy drops up to 14% and yields more Pareto-optimal solutions than six state-of-the-art baselines.

## Executive Summary
The paper proposes the Generalised Exponentiated Gradient (GEG) method for mitigating bias in both binary and multi-class classification tasks. GEG frames fair learning as a multi-objective optimization problem subject to multiple linear fairness constraints, extending the classic Exponentiated Gradient algorithm. Through extensive experiments on ten datasets (seven multi-class, three binary) and employing four effectiveness metrics alongside three fairness definitions, GEG demonstrates substantial fairness improvements (up to 92%) at a modest cost in accuracy (up to 14%). Moreover, it consistently outperforms six state-of-the-art baselines in generating Pareto-optimal solutions across various fairness-effectiveness trade-offs.

## Method Summary
GEG extends the Exponentiated Gradient algorithm to handle multiple linear fairness constraints simultaneously. It treats fairness as a set of constraints that must be satisfied while optimizing classification accuracy. The method iteratively updates a distribution over model parameters, using exponentiated gradient updates to balance competing objectives. By formulating the problem as multi-objective optimization, GEG can produce a spectrum of models representing different trade-offs between fairness and effectiveness. The approach is applicable to both binary and multi-class classification settings.

## Key Results
- Fairness improvements of up to 92% compared to baseline models.
- Accuracy reductions limited to at most 14%.
- GEG yields a higher number of Pareto-optimal solutions than six evaluated state-of-the-art baselines.

## Why This Works (Mechanism)
GEG works by generalizing the Exponentiated Gradient method to accommodate multiple linear constraints. This allows the algorithm to navigate the trade-off surface between fairness and accuracy effectively. The exponentiated gradient update rule ensures that constraints are gradually satisfied while maintaining progress on the primary objective, leading to a diverse set of Pareto-optimal solutions. The linear constraint formulation makes the method scalable and applicable to various fairness definitions that can be expressed as linear equations (e.g., demographic parity, equalized odds).

## Architecture Onboarding
**Component Map**: Data -> Base Learner -> GEG Constraint Solver -> Fair Classifier

**Critical Path**: 
1. Train a base classifier (e.g., logistic regression, neural network) on the given data.
2. Define a set of linear fairness constraints based on chosen fairness metrics.
3. Initialize a distribution over model parameters (or predictions).
4. Iteratively compute gradient information for each constraint and the accuracy objective.
5. Update the distribution using the exponentiated gradient rule to improve constraint satisfaction while maintaining accuracy.
6. Extract a final model from the distribution (e.g., by averaging or selecting a solution on the Pareto front).

**Design Tradeoffs**:
- Number of constraints: More constraints increase complexity but may improve overall fairness.
- Choice of base learner: Simpler learners may converge faster but could limit expressiveness.
- Trade-off parameter: Controls emphasis on constraints vs. accuracy; affects the Pareto front shape.

**Failure Signatures**:
- Constraints remain violated after many iterations (non-convergence).
- Accuracy drops significantly beyond acceptable limits.
- The algorithm produces no diversity in solutions (all solutions cluster).

**First Three Experiments**:
1. Apply GEG to a binary classification dataset (e.g., Adult Income) with statistical parity constraint; measure fairness and accuracy.
2. Apply GEG to a multi-class dataset (e.g., MNIST) with equalized odds constraints; compare Pareto front size to a baseline method.
3. Evaluate GEG's sensitivity to the number of constraints by running with 1, 2, and 3 fairness definitions on a common dataset.
