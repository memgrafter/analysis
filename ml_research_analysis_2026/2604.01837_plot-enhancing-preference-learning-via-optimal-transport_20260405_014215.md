# PLOT: Enhancing Preference Learning via Optimal Transport

## Quick Facts
- **arXiv ID:** 2604.01837
- **Source URL:** https://arxiv.org/abs/2604.01837
- **Reference count:** 35
- **Primary result:** PLOT reduces Attack Success Rate by up to 9.83 percentage points (e.g., 25.75% → 16.92% on Llama3.2-3B) with only ~2.67% additional training time, while improving helpfulness and logical reasoning.

## Executive Summary
PLOT is a novel loss function for large language model (LLM) preference alignment that reformulates token-level learning as an Optimal Transport (OT) problem. It addresses key limitations of existing methods—high computational cost, hyperparameter sensitivity, and inadequate modeling of global token relationships—by minimizing the Wasserstein-1 distance between the model’s output distribution and a semantically constructed target preference distribution. The target distribution is derived from token-frequency differences between chosen and rejected responses, while the OT cost matrix uses L2 norms of token embeddings to capture inter-token semantic proximity. Integrated seamlessly as a supplementary loss into standard frameworks like DPO, PLOT yields consistent gains across harmlessness, helpfulness, and logic benchmarks with minimal overhead.

## Method Summary
PLOT adds an OT-based regularization term to existing preference learning losses (e.g., DPO). For a given batch, it constructs a target preference distribution \( P_t \) from the normalized token-frequency difference between chosen and rejected responses (shifted to ensure non-negativity). The model’s token distribution \( Q_\theta \) over chosen responses is computed via scattered probabilities from the forward pass. The 1-Wasserstein distance \( W_1(Q_\theta, P_t) \) is then calculated efficiently using a sorted cumulative distribution function (CDF) approach, with the sorting order determined by the L2 norms of token embeddings. This defines a cost matrix implicitly where moving probability mass between tokens with similar embedding norms is cheaper. The final loss is \( \mathcal{L} = \mathcal{L}_{\text{vanilla}} + \alpha \cdot W_1(Q_\theta, P_t) \), where \( \alpha \) is a scalar weight. Precomputation of \( P_t \) and embedding norm sort orders keeps per-batch overhead low.

## Key Results
- Reduces Attack Success Rate (ASR) under multiple red-teaming attacks by up to 9.83 pp (e.g., SFS attack on Llama3.2-3B: 25.75% → 16.92% with DPO).
- Improves helpfulness/humanity (GPT-4 rating: 7.87 → 8.74) and logical task accuracy (GSM8K: 67.52 → 68.36).
- Maintains model fluency and incurs only ~2.67% additional training time.

## Why This Works (Mechanism)

### Mechanism 1: Stabilizing Optimization via Distributional Preservation
PLOT reduces computational cost and training instability by framing preference learning as an OT problem that preserves the model's original output distribution. Instead of directly manipulating token probabilities (e.g., via KL penalties), it computes the minimal transport cost (Wasserstein-1 distance) between the model’s distribution \( Q_\theta \) and a semantically constructed target \( P_t \). This intrinsic property of OT—minimizing “movement” of probability mass—encourages smaller, more stable updates to the model distribution. If \( P_t \) is poorly constructed from noisy preference data, the OT solution may transport mass toward undesirable regions, increasing computational cost without performance gains.

### Mechanism 2: Capturing Global Semantic Structure via Token Embeddings
PLOT achieves more holistic preference learning by incorporating token-level semantic relationships through embeddings. The cost matrix is defined using the L2 norms of token embeddings (\( c_{ij} = |\|e_i\|_2 - \|e_j\|_2| \)), making transport cost sensitive to semantic proximity: moving mass between semantically similar tokens is cheaper. This allows the model to adjust its distribution considering the global semantic landscape, not just per-token modifications. If the model’s embedding space is poorly aligned with the preference task’s semantics (e.g., for out-of-distribution tokens), the norm-based cost may misrepresent true token relationships, leading to suboptimal transport plans.

### Mechanism 3: Enhancing Hyperparameter Robustness through Principled Distance Metric
PLOT exhibits lower sensitivity to hyperparameter choices (e.g., loss weight \( \alpha \)) compared to heuristic token-level methods. The OT loss computes a well-defined geometric distance (Wasserstein-1) between distributions, which is less prone to extreme values than pointwise operations (e.g., element-wise multiplication in DEFT’s \( R_Q \)). The minimization of a convex transport problem provides a smoother optimization landscape. If \( P_t \) is multi-modal or complex, the 1-Wasserstein distance may not capture higher-order statistical differences, making performance still sensitive to \( \alpha \) for certain preferences.

## Architecture Onboarding
Model forward pass -> Target preference distribution builder \( \Phi(P_t) \) -> Token embedding extractor -> Cost matrix generator (L2-norm differences) -> OT solver (sorted CDF integral for \( W_1 \)) -> Loss combiner (adds \( \alpha \cdot L_{\text{PLOT}} \) to baseline loss). Critical path: For each batch, compute \( Q_\theta \) and \( P_t \), extract embeddings and compute sorted norms, compute \( W_1 \) via CDF, backpropagate combined loss. Embedding table is cached after first retrieval. Design tradeoffs: norm-based cost is computationally cheap vs. full pairwise embeddings; simple batch-level \( P_t \) construction vs. nuanced sample-specific distributions. Failure signatures: training divergence if \( \alpha \) too large; no ASR improvement if embedding space misaligned; high memory for large vocabularies if full cost matrix stored. First 3 experiments: 1) Harmlessness evaluation (ASR reduction across six attacks). 2) Ablation on embedding efficacy (remove embedding-based cost). 3) Hyperparameter stability (vary \( \alpha \)).

## Open Questions the Paper Calls Out
- **Open Question 1:** How does PLOT's alignment performance and computational overhead scale when applied to significantly larger LLMs (e.g., >10B parameters)? Basis: experiments not extended due to resource constraints. Resolution requires training/evaluation on larger models with resource tracking.
- **Open Question 2:** What is the sensitivity of PLOT's effectiveness to the volume and diversity of preference training data? Basis: training data restricted to a single sample set. Resolution requires controlled experiments varying dataset sizes across preferences.
- **Open Question 3:** Does the choice of semantic cost metric (e.g., L2 norm vs. cosine similarity) critically impact PLOT's ability to model global token relationships? Basis: L2 used without comparison. Resolution requires variants with alternative cost matrices and correlation analysis.

## Limitations
- Unspecified baseline hyperparameters (DPO learning rate, β) hinder exact replication.
- Ambiguities in \( Q_\theta \) construction (chosen-only? padding handling?) and embedding usage (tied? frozen?).
- Simplified cost matrix (L2-norm difference) may not fully capture semantic relationships.

## Confidence
- **ASR reduction (safety):** High – consistent across six attacks.
- **Helpfulness & logical gains:** Medium – modest improvements possibly dataset-specific.
- **Fluency preservation:** Medium – claim based on qualitative observation, no metric.
- **Hyperparameter robustness:** High – stability demonstrated vs DEFT.
- **Low computational overhead:** Medium – reported but not extensively benchmarked.
