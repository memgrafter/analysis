# Deep Learning-Based Meat Freshness Detection with Segmentation and OOD-Aware Classification

## Quick Facts
- **ArXiv ID:** 2603.00368
- **Source URL:** https://arxiv.org/abs/2603.00368
- **Reference count:** 40
- **Primary result:** Two-stage pipeline with U-Net segmentation and OOD-aware classification achieves up to 98.10% ID accuracy and AUROC 0.999 for OOD detection, enabling real-time mobile inference.

## Executive Summary
This paper presents a practical system for meat freshness assessment using RGB images. It addresses challenges like background clutter and packaging occlusions through a two-stage approach: first segmenting the meat region with a U-Net, then classifying freshness with an OOD-aware mechanism that can abstain on uncertain inputs. Evaluations on a combined dataset of 6,256 images show high classification accuracy (up to 98.10%) and excellent OOD detection (AUROC up to 0.999). The system is optimized for mobile deployment with low latency, offering a low-cost solution for consumer-level meat quality monitoring.

## Method Summary
The authors construct a dataset merging three public unpackaged meat datasets (2,265 images) and a newly collected packaged set (3,734 images). After deduplication, 6,256 unique images span four freshness classes; an additional 800 “No Result” images serve as OOD. The pipeline first applies a U-Net with ResNet-34 encoder, trained on pseudo-masks from GrabCut using a hybrid BCE+Dice loss. The segmented meat region is then fed to one of five classification backbones (ResNet-50, ViT-B/16, Swin-T, EfficientNet-B0, MobileNetV3-Small) with a custom FC head. Nested 5×3 cross-validation selects hyperparameters; final models are retrained on full training data. OOD-aware abstention uses a confidence threshold (e.g., max softmax probability) to output either a freshness class or “No Result”. Performance is evaluated on held-out ID test (843 images) and OOD set, with mobile latency measured via TensorFlow Lite.

## Key Results
- Segmentation: U-Net with ResNet-34 achieves 74.94% IoU and 81.88% Dice.
- Classification: EfficientNet-B0 attains highest held-out ID test accuracy (98.10%) and macro-F1; MobileNetV3-Small matches 97.63% accuracy.
- OOD detection: Energy-based method yields AUROC up to 0.999.
- Mobile latency: MobileNetV3-Small (6.36 ms) and EfficientNet-B0 (17.21 ms) on Samsung Galaxy A55.

## Why This Works (Mechanism)
The segmentation step isolates the meat region, reducing variability from backgrounds, packaging, and lighting, which standardizes inputs for the classifier. The OOD-aware mechanism enhances safety and reliability by detecting inputs that deviate from the training distribution (e.g., empty trays, non-meat objects) and abstaining rather than risking misclassification. Using a diverse set of architectures and nested cross-validation ensures robust model selection, while mobile-optimized backbones (EfficientNet, MobileNet) provide a favorable accuracy-latency trade-off for on-device deployment.

## Architecture Onboarding
- **Component map:** RGB Image -> U-Net (ResNet-34) -> Segmented Meat ROI -> Classifier Backbone (E.g., EfficientNet-B0) -> Custom Head (FC 512 + dropout 0.3) -> Softmax -> OOD Confidence (MSP/Energy) -> Threshold Check -> Output (Freshness Class or "No Result")
- **Critical path:** The segmentation must reliably isolate meat; subsequent classification depends on ROI quality. OOD check runs after classification but can short-circuit based on confidence.
- **Design tradeoffs:** Segmentation adds complexity and latency but improves robustness; lightweight backbones sacrifice some accuracy for mobile speed; abstention threshold balances coverage vs. safety; pseudo-labels avoid manual annotation cost but may introduce noise.
- **Failure signatures:** (1) Segmentation fails on glare/occlusion -> meat omitted or background included -> misclassification; (2) Low confidence on some ID samples due to ambiguous freshness -> unnecessary abstention; (3) Model overfitting indicated by large train-val gap; (4) Mobile latency higher than expected due to TFLite configuration.
- **First three experiments:** (1) Visualize segmentation masks on validation samples across all classes and packaging types; record failure cases (e.g., missing meat, extra background). (2) Train classifiers on original (non-segmented) images using same protocols; compare accuracy to segmented pipeline to quantify segmentation contribution. (3) For each model, sweep confidence threshold τ on MSP/Energy/ODIN; choose operating point (e.g., 95% OOD rejection) and compare ID coverage and OOD AUROC.

## Open Questions the Paper Calls Out
1. **Quantitative contribution of segmentation:** The paper does not isolate the impact of the U-Net preprocessing by comparing with and without segmentation under identical conditions. An ablation experiment using the same backbones and CV protocol on both segmented and original images would measure the accuracy gain solely from foreground extraction.
2. **Robustness to external data:** All evaluation uses a held-out test set from the same collection process. Performance on a fully independent dataset from different retailers, environments, or cameras remains unknown. External validation is needed to test generalization across acquisition conditions and product variations.
3. **Inter-annotator agreement for labels:** Freshness labels were assigned by student annotators without measuring consensus. The reliability of ground truth compared to domain experts is unclear. A subset reviewed by multiple meat science experts, with Cohen’s kappa computed, would benchmark label quality and alignment with expert judgment.
4. **Correlation with microbiological/physicochemical spoilage measures:** The labels rely on visual cues and time-based rules, not validated against objective spoilage indicators. Concurrent collection of images and lab measures (e.g., total viable counts, pH) followed by correlation analysis would establish whether visual predictions reflect actual microbiological spoilage.

## Limitations
- Exact final hyperparameters and the chosen abstention threshold for each model are not explicitly reported; reproduction requires rerunning nested CV or assuming frequent configurations.
- Segmentation masks are pseudo-labeled via GrabCut, which may fail on challenging conditions (glare, heavy occlusion), limiting segmentation quality and downstream classification.
- The 800-image OOD “No Result” set is not publicly available, hindering exact replication of OOD detection experiments.
- Train-test leakage could occur if near-duplicate images (by pHash) are split across sets; proper grouping during splitting is needed but not guaranteed.
