# The emergence of numerical representations in communicating artificial agents

## Quick Facts
- **arXiv ID**: 2602.10996
- **Source URL**: https://arxiv.org/abs/2602.10996
- **Reference count**: 8
- **Primary result**: Communication pressure alone enables precise in-distribution transmission of trained numerosities but does not yield compositional or generalisable numerical codes.

## Executive Summary
The paper investigates whether communication pressure in a referential game can give rise to numerical representations without pre-defined numeric concepts. Neural agents are trained to communicate dot numerosities (1–5) via discrete token sequences or continuous line sketches. They achieve near-perfect accuracy and low conditional entropy on the trained set, indicating precise symbol–meaning associations. However, when tested on unseen higher numerosities, agents fail to generalise: discrete agents reuse the message for the largest trained value, while continuous agents collapse onto a single sketch, yielding chance-level performance. Moreover, manipulating the frequency of numerosity exposure does not lead to more efficient (shorter) codes. The findings suggest that while communication pressure suffices for learning accurate mappings of trained stimuli, additional pressures (e.g., iterative learning, production costs) are necessary to induce compositional numerical systems.

## Method Summary
The study employs referential games where a sender and a receiver cooperate. The sender observes an image containing a specific number of black dots (1–5) and encodes it using a pretrained Vision Transformer (ViT). The encoded representation is transformed into a message: either a discrete token sequence produced by an LSTM with Gumbel-Softmax sampling, or a continuous sketch consisting of five straight lines generated by an MLP. The receiver processes the message (with its own LSTM for discrete messages, or the same ViT for sketches) and scores candidate target images, selecting the one matching the sender’s numerosity. Training uses a multi-class hinge loss to ensure the correct target scores higher than distractors. Agents are evaluated on in-distribution numerosities (1–5) and on out-of-distribution numerosities (e.g., 6, 10, 15, 20) to test generalisation. Additional ablations vary the training frequency of each numerosity to probe code efficiency. The primary metrics are task accuracy, conditional entropy H(numerosity|message), message length (discrete) or sketch complexity (continuous), and generalisation accuracy.

## Key Results
- **Precision on trained set**: Agents attain high in-distribution accuracy (up to 1.00 for discrete, above 0.85 for continuous) and low conditional entropy (0.2–0.4), demonstrating precise, learned associations.
- **Non‑compositional generalisation**: For numerosities beyond the training range, agents typically reuse the message for the largest trained value (discrete) or collapse onto a sketch resembling that value (continuous), yielding near-chance accuracy.
- **No efficiency gain from frequency**: Varying the frequency of numerosity samples during training does not produce shorter or simpler messages for common numerosities, indicating a lack of pressure for economical coding.

## Why This Works (Mechanism)
Communication pressure drives agents to differentiate the trained numerosity classes by assigning distinct messages, because the referential game reward is contingent on correctly identifying the target among distractors. With a fixed, small output vocabulary or a bounded sketch complexity, the sender can allocate a unique code to each of the five trained numbers, and the receiver can learn to map each code back to the correct class. This yields high in-distribution accuracy and low conditional entropy. However, the task does not require the agents to handle novel numerosities; the training distribution is uniform and the set of target classes is closed. Consequently, there is no selective advantage to developing a systematic mapping (e.g., monotonic or compositional) across the number continuum. Instead, agents adopt a "default to the largest known" heuristic for unseen larger values — a simple extrapolation that minimises error given the absence of any pressure to discriminate among them. The failure to develop compositionality underscores that additional inductive biases (e.g., recursive combination of sub‑symbols, explicit magnitude ordering, or effort costs) are needed for numerical abstractions to generalise.

## Architecture Onboarding
**Component Map** (discrete vs continuous):
- Discrete: Image → ViT Encoder → Sender LSTM → Discrete Token Sequence → Receiver LSTM → Classification Head → Numerosity Prediction.
- Continuous: Image → ViT Encoder → Sender MLP → Sketch (5 straight lines) → (Sketch rendered to image) → ViT Encoder (shared) → Classification Head → Numerosity Prediction.

**Critical Path**: The sender encodes the target image, generates a message (tokens or sketch), transmits it to the receiver, who then scores a set of candidate target images. The hinge loss updates both agents to increase the score of the correct target relative to the others.

**Design Tradeoffs**:
- *Discrete vs. continuous channels*: Discrete tokens allow straightforward analysis of message–meaning mapping but may limit expressivity; continuous sketches offer richer signals but require discretisation (e.g., clustering) for entropy computation.
- *Frozen vs. fine‑tuned ViT*: Using a frozen pretrained encoder speeds training and leverages generic visual features, but may hinder the learning of task‑specific numerosity representations.
- *Length regularisation*: Adding a penalty for longer messages encourages efficiency, but too strong a penalty can impede learning of discriminative codes.

**Failure Signatures**:
- In‑distribution accuracy below ~0.8 or conditional entropy above 1.0.
- OOD generalisation showing a single message/sketch dominating all unseen numerosities (confusion matrix with one row/column active).
- Frequency manipulation experiments yielding no systematic change in average message length across classes.

**First Three Experiments**:
1. **Baseline replication**: Train the discrete setup with uniform class frequencies, frozen ViT, and default hyperparameters (Adam lr=1e‑4, batch 64, hinge margin 0.1, length reg λ=0.005). Expect in-distribution accuracy >0.95 and entropy <0.5.
2. **OOD generalisation test**: After baseline training, evaluate on numerosities 6, 10, 15, 20. Confirm near-chance accuracy (~0.2 for 5‑way?) and that all OOD samples are assigned the message for class 5.
3. **Frequency manipulation**: Train with increasing sample counts for classes 1→5 (100,200,300,400,700). Measure average message length per class; a robust frequency effect would show decreasing length with higher frequency, but the paper reports no such trend.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Is communication pressure alone sufficient to induce compositional numerical representations that generalise to unseen numerosities, or are additional pressures (e.g., iterated learning, population structure, or cognitive biases) necessary?
- **Basis in paper:** [explicit] The authors conclude that "communication pressure alone suffices for precise transmission of learned numerosities, but additional pressures are needed to yield compositional codes and generalisation abilities" and state that "inducing such compositionality in this context remains a key challenge."
- **Why unresolved:** The paper demonstrates that agents achieve high in-distribution accuracy with precise, low-entropy mappings but fail at generalisation, exhibiting non-compositional reuse of symbols for higher numerosities. This indicates communication pressure alone is insufficient for systematic structure.
- **What evidence would resolve it:** Experiments introducing specific pressures (e.g., iterated learning across generations, vocabulary size constraints, or meta-learning objectives) and testing whether emergent codes develop compositional rules (e.g., recursive merging of sub-symbols) that allow accurate zero-shot generalisation to novel numerosities.

### Open Question 2
- **Question:** How can arbitrary but systematic partitioning of a single ordered dimension (numerosity) be induced in emergent communication systems, given that numbers lack inherently decomposable perceptual features unlike multi-attribute referents?
- **Basis in paper:** [explicit] The authors note: "Successful generalisation... requires the emergence of an arbitrary but systematic partitioning of this dimension, rather than the transparent mapping of perceptual features. How such a structure can be induced remains an open question."
- **Why unresolved:** Agents in referential games typically exploit perceptual decompositions (e.g., colour + shape) to achieve compositionality, but numerosity is a unitary, abstract dimension. The paper shows agents default to holistic labels without developing ordinal or magnitude-based structuring.
- **What evidence would resolve it:** Architectures or training regimes that explicitly bias agents toward ordinal representation (e.g., latent space regularization enforcing monotonicity, or auxiliary tasks predicting relative magnitude) and analysis of whether messages become systematically related (e.g., via edit distance or embedding similarity) across the numerosity continuum.

### Open Question 3
- **Question:** Why does manipulating the frequency of numerosity exposure fail to yield more efficient (shorter or simpler) codes, and what additional transmission costs (e.g., production effort, perceptual robustness) might be necessary to replicate human-like Zipfian compression?
- **Basis in paper:** [inferred] The authors report that "manipulating class frequency barely changes accuracy and does not induce shorter codes for frequent numerosities," suggesting the absence of explicit costs for message length or complexity weakens pressure for economy. They hypothesise that "adding production and perception costs could aid the brevity of the emergent codes."
- **Why unresolved:** The experimental setup only optimises for accuracy, whereas natural language evolves under multiple constraints. The lack of frequency effect implies that without explicit effort-based losses or channel limitations, agents have no incentive to simplify frequent symbols.
- **What evidence would resolve it:** Re-running frequency experiments with added penalties for message length, stroke count, or cognitive load (e.g., noise during transmission) and measuring whether codes then compress systematically for high-frequency numerosities, aligning with Zipf’s law.

### Open Question 4
- **Question:** Do discrete (symbolic) and continuous (iconic) communication channels inherently differ in their potential to develop numerical compositionality, or do both fail for the same underlying reason (lack of inductive biases for systematicity)?
- **Basis in paper:** [explicit] The paper studies both channels and finds similar failures: discrete agents reuse the highest-trained symbol for extrapolation, while continuous agents collapse onto a single sketch resembling the largest trained numerosity. Both exhibit non-compositional holistic signalling.
- **Why unresolved:** Although sketches show some iconic scaling (e.g., spatial span correlating with numerosity), neither channel develops systematic rules. It is unclear whether the failure is due to the referential game structure itself or if iconic vs. symbolic media impose different constraints on learning numerical abstractions.
- **What evidence would resolve it:** Directly comparing agent architectures with matched inductive biases across channels, or introducing channel-specific pressures (e.g., forcing sketch discretisation vs. symbolic recombination), and testing whether one modality more readily supports interpolation/extrapolation under identical training conditions.

### Open Question 5
- **Question:** What specific architectural or training modifications can break the "largest-trained-numerosity" default strategy observed during generalisation, prompting instead the emergence of ordinal or approximate number system (ANS)-like representations that support crude but meaningful extrapolation?
- **Basis in paper:** [inferred] In both discrete and continuous settings, agents "typically reuse the message for the largest trained numerosity" for unseen higher values, achieving accuracy near chance. The paper suggests this reflects a lack of compositionality but does not explore whether simpler heuristics (e.g., monotonic mapping) could emerge.
- **Why unresolved:** The default strategy indicates agents treat numerosities as categorical rather than ordinal. No experiment probes whether agents can learn a monotonic relationship between message features and numerosity magnitude, which would at least allow ordering-based generalisation even without exact symbols.
- **What evidence would resolve it:** Analyses of message embeddings or sketch features to test for monotonicity with respect to numerosity; training with losses encouraging ordinal consistency (e.g., ranking loss); or evaluating performance on relative judgements (e.g., "which is larger?") for unseen numerosities to see if implicit magnitude encoding exists.

## Limitations
- **Pretrained vision encoder**: The exact CLIP ViT variant (e.g., ViT‑B/16) and whether it is frozen or fine‑tuned are unspecified, which may affect feature richness and generalisation.
- **Training hyperparameters**: Key settings (LSTM hidden size, optimizer parameters, hinge margin, length regularisation schedule) are missing, hindering reproducibility and robustness assessment.
- **Sketch discretisation**: The method for converting continuous sketches into discrete codes for entropy calculation (e.g., number of clusters, feature space) is not detailed, potentially impacting precision measurements.

## Confidence
- **Precise in-distribution mappings**: **High** confidence. Metrics directly observable and robust to minor architectural variations.
- **Non-compositional generalisation**: **Medium** confidence. Pattern is clear but could shift with different hyperparameters.
- **Inefficiency of frequency manipulation**: **Low** confidence. Strongly dependent on unstated regularisation strength and optimisation dynamics.
