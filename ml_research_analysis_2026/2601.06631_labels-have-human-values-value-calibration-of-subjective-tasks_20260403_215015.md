# Labels have Human Values: Value Calibration of Subjective Tasks

## Quick Facts
- **arXiv ID:** 2601.06631
- **Source URL:** https://arxiv.org/abs/2601.06631
- **Reference Count:** 40
- **Primary Result:** MC-STL, which clusters annotations by latent human values and enforces cluster-wise calibration, consistently outperforms baselines that ignore value structure across discrimination, calibration, and minority opinion metrics.

## Executive Summary
This paper tackles the misalignment between NLP systems and diverse human values in subjective tasks (e.g., toxicity detection, preference judgment), where standard practices often treat annotator disagreement as noise. The proposed MultiCalibrated Subjective Task Learner (MC-STL) explicitly models latent value groups underlying annotation variation. It partitions data into value-based clusters using three signals—annotator rationales, expert taxonomies (e.g., Schwartz), or sociocultural descriptors—learns cluster-specific representational adjustments, and optimizes a loss combining standard cross-entropy with a multicalibration term (KL divergence) that aligns per-cluster predictions with true label distributions. Evaluated on multiple datasets, MC-STL improves overall discrimination, per-group calibration, and handling of minority opinions, demonstrating a path toward pluralistically aligned systems.

## Method Summary
MC-STL operates in three stages: (1) **Clustering:** Annotations are grouped into K value clusters C_k using one of three methods: K-means on rater rationale embeddings, mapping to Schwartz value categories, or using annotator demographics. Each annotation y_ij is associated with a set of clusters S_ij. (2) **Value-Aware Modeling:** A frozen text encoder produces e(x_i). For each annotation, a learnable cluster embedding v_k is retrieved for every k in S_ij and summed to form V(y_ij). This is additively combined with e(x_i) to create a value-aware representation f(x_i, y_ij) = e(x_i) + V(y_ij). Task-specific heads (sigmoid for binary, CORAL for ordinal 3-class, Bradley-Terry with cluster temperature for preference) produce predictions. (3) **Multicalibration Training:** The loss combines per-annotation cross-entropy with a weighted KL divergence term that matches the model's aggregated predicted distribution Q_k to the empirical label distribution P_k for each cluster C_k, plus L2 regularization on v_k. This encourages the model to be well-calibrated for every value group.

## Key Results
- MC-STL significantly outperforms baselines (global model, majority-vote) in macro-AUC and pairwise accuracy across toxicity, offensiveness, and preference datasets.
- Multicalibration metrics (slope and bias from decile plots) improve substantially, with predictions per value cluster closely matching true label frequencies.
- On instances with non-majority annotations, MC-STL reduces the Earth Mover's Distance (1-EMD), indicating better modeling of minority opinions within value groups.

## Why This Works (Mechanism)

### Mechanism 1: Value Clustering Captures Latent Structure
- **Claim:** Partitioning annotations into value-based clusters captures the latent human value structure driving subjective label variation.
- **Mechanism:** Annotations are grouped using (i) semantic similarity of rater rationales (K-means on embeddings), (ii) mapping to expert-defined value taxonomies (Schwartz), or (iii) annotator sociocultural descriptors. Each cluster C_k represents a distinct value perspective.
- **Core Assumption:** Differences in human values are a primary source of annotator disagreement and can be operationalized via the chosen grouping signal.
- **Evidence Anchors:** Abstract and Section 2.1 detail the three clustering approaches and the premise that subjectivity arises from K latent human value groups. Neighboring work (e.g., Crowd-Calibrator) also model subjectivity via annot disagreement or descriptors.
- **Break Condition:** If the clustering signal produces semantically incoherent clusters (e.g., rationales cluster by topic not value stance), the value group representation is invalid.

### Mechanism 2: Cluster-Specific Embeddings Adapt Representations
- **Claim:** Learning cluster-specific embeddings v_k allows the model to adapt its internal representations to the inductive biases of each value perspective.
- **Mechanism:** For an annotation y_ij with cluster set S_ij, a value-specific representation V(y_ij) = Σ_{k ∈ S_ij} v_k is computed by summing the learnable embeddings of its associated clusters. This is additively combined with the text embedding: f(x_i, y_ij) = e(x_i) + V(y_ij).
- **Core Assumption:** Different human value groups require distinct feature transformations; a single global model is insufficient.
- **Evidence Anchors:** Section 2.2 defines the learnable embeddings v_k and the additive fusion formulation, stating they capture value-specific inductive biases.
- **Break Condition:** If value clusters are highly overlapping or non-distinct, the embeddings may not learn separable representations, causing overfitting.

### Mechanism 3: Multicalibration Aligns Predictive Distributions
- **Claim:** Enforcing multicalibration via a KL divergence term aligns the model's predicted probability distribution for each value cluster with the true label distribution of that cluster, achieving group-level predictive parity.
- **Mechanism:** The composite loss combines cross-entropy with a weighted KL term: λ₁ Σ_k α_k KL(P_k || Q_k). P_k is the empirical label mean for C_k; Q_k is the mean predicted probability for items in C_k (using a soft-thresholding approximation). α_k weights clusters by their divergence from the overall distribution.
- **Core Assumption:** A model is value-aligned if, for every value group, its average predicted probabilities match the group's actual label frequencies.
- **Evidence Anchors:** Abstract mentions encouraging multicalibration for value groups. Section 2.3 specifies the full loss function, including the KL term and weighting.
- **Break Condition:** If a cluster C_k has very few annotations (n_k small), the KL term becomes noisy and may destabilize training.

## Foundational Learning
- **Multicalibration (Group Calibration):** A fairness/alignment guarantee requiring that for every predefined group (here, value clusters), a model's predicted probability distribution matches the group's true outcome distribution. It is critical for subjective tasks to ensure no value group is systematically miscalibrated. *Quick Check:* How does multicalibration differ from standard (global) calibration, and why is group-wise calibration necessary when human values diverge?
- **Schwartz Theory of Basic Human Values:** An expert-defined, cross-culturally validated taxonomy of ten universal values (e.g., Universalism, Benevolence, Security). Used as one clustering signal, it provides an interpretable mapping from annotators to value dimensions. *Quick Check:* How might a "Universalism"-oriented rater versus a "Security"-oriented rater differ in labeling the same text as toxic?
- **Ordinal Classification with CORAL (Consistent Rank Logits):** A method for ordinal outcomes (e.g., Support > Neutral > Oppose) that enforces monotonicity on logits via parallel binary classification tasks with shared weights but separate biases. MC-STL uses CORAL for its 3-class settings. *Quick Check:* Why can't a standard 3-way softmax properly model ordered labels like Support/Neutral/Oppose, and how does CORAL's two-bias design enforce the required ordering?

## Architecture Onboarding
- **Component Map:** Text Encoder → Value-Aware Fusion (adds cluster embeddings) → Task-Specific Heads → Predictions. Cluster Embedding Bank (v_k) is queried during fusion. Loss Calculator aggregates CE and KL terms over clusters.
- **Critical Path:** Input text x_i → Text Encoder (e(x_i)) → For each annotation (y_ij, S_ij): compute V(y_ij)=Σ_{k∈S_ij} v_k → f(x_i,y_ij)=e(x_i)+V(y_ij) → Task Head → prediction ˆp_ij. After all items: aggregate predictions per cluster C_k to get Q_k → compute KL(P_k||Q_k) → total loss L = Σ L_CE + λ₁ Σ α_k KL + λ₂ Σ ||v_k||² → backpropagate to update encoder (if finetuned), v_k, task head weights.
- **Design Tradeoffs:** 
  - *Additive Fusion (e + V):* Simple, preserves dimensionality, supports mixed membership (summing v_k). Risk: limited interaction between text and value signals.
  - *Single Global Encoder:* Shares textual knowledge across clusters, reducing parameters. May limit cluster-specific feature extraction.
  - *λ₁ (KL weight) and λ₂ (regularizer):* λ₁ controls multicalibration strength; too high may hurt discrimination. λ₂ prevents v_k explosion. Tuned via grid search.
- **Failure Signatures:**
  - **Poor cluster separation:** Incoherent clusters (e.g., rationales grouping by topic) lead to meaningless v_k. Diagnostic: inspect cluster summaries or within-cluster label variance.
  - **Calibration decay:** Cluster-level slope/bias deviates from ideal (1,0) despite AUC gains. Diagnostic: per-cluster calibration plots; remedy: increase λ₁.
  - **Minority opinion suppression:** Low 1-EMD despite good AUC. Diagnostic: compare model predictions against minority annotations; remedy: adjust α_k weighting or increase model capacity.
- **First 3 Experiments:**
  1. **Cluster Quality Validation:** For rationale clustering, run K-means (K=2..6), generate cluster summaries via LLM (prompt from Appendix A.3), and have an expert select K with most distinct, interpretable value profiles.
  2. **Calibration Plot Inspection:** For each value cluster, bin predictions into deciles, plot average predicted probability vs. average true label, compute slope and bias. Verify multicalibration (slope≈1, bias≈0).
  3. **Disagreement-Aware Evaluation:** Compute 1-EMD on instances with non-majority annotations. Compare MC-STL against baselines (global model, majority-vote).

## Open Questions the Paper Calls Out
- **Alternative Value Representations:** Can MC-STL benefit from other value frameworks (e.g., Moral Foundations) or from combining the three existing clustering signals (rationales, expert taxonomies, demographics)? The paper only evaluates each independently.
- **LLM-Generated Rationales:** How do LLM-extracted or LLM-generated annotator rationales affect clustering quality and subsequent calibration? The current work assumes human-provided rationales.
- **Extension to Text Generation:** Can the MC-STL principle be extended to value-aligned text generation? The paper notes this as an important future direction but does not address the required modifications for decoding control.

## Limitations
- **Missing Specifications:** The architecture of the dense network o(·), exact training hyperparameters (learning rate, batch size, epochs), and temperature initialization details are not reported, hindering faithful reproduction.
- **Subjective Cluster Selection:** The rationale clustering requires expert inspection to choose K, introducing non-reproducibility; the paper reports specific K values (e.g., VP-Duty K=3) but the selection process is inherently subjective.
- **Ambiguous Evaluation Protocol:** Details on test split stratification and handling of multi-annotation items for 1-EMD are not fully specified, leaving room for interpretation.

## Next Checks
1. **Ablation Study:** Systematically remove the KL multicalibration term and/or the cluster embeddings v_k to isolate their individual contributions to discrimination and calibration.
2. **Clustering Robustness:** Vary the number of clusters K and the embedding model used for rationale clustering to test the stability of value groups and resulting performance.
3. **Demographic Fairness Audit:** Evaluate MC-STL's performance across intersecting demographic subgroups (age, gender, ethnicity) to ensure gains in value calibration do not come at the cost of fairness toward protected groups.
