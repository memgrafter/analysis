# HypCBC: Domain-Invariant Hyperbolic Cross-Branch Consistency for Generalizable Medical Image Analysis

## Quick Facts
*   **arXiv ID:** 2602.03264
*   **Source URL:** https://arxiv.org/abs/2602.03264
*   **Reference Count:** 26
*   **Primary Result:** HypCBC achieves an average +2.1% AUC improvement over state-of-the-art Euclidean domain generalization methods on three benchmarks (Fitzpatrick17k, Camelyon17-WILDS, Retina), with statistically significant gains (Wilcoxon, p<0.05).

## Executive Summary
Medical image analysis models suffer from poor generalization due to covariate shifts from varying hardware and protocols. Existing Euclidean methods struggle to model the hierarchical structure of clinical data (e.g., disease taxonomies). HypCBC introduces a two-branch framework built on a frozen Euclidean backbone. Features are projected into high-dimensional (128D) and low-dimensional (2D) hyperbolic (Poincaré ball) spaces. The low-dimensional branch, constrained by an information bottleneck, produces soft logits that regularize the high-dimensional branch via a KL consistency loss. This promotes domain-invariant representations without requiring domain labels. Across eleven in-distribution datasets, hyperbolic single-branch models (HypERM) significantly outperform Euclidean baselines. On three domain generalization benchmarks, HypCBC consistently surpasses state-of-the-art Euclidean methods.

## Method Summary
HypCBC uses a frozen pre-trained Euclidean backbone (e.g., ViT) to extract features. Two lightweight linear projection heads map these features to separate Euclidean embeddings: one high-dimensional (128D) and one low-dimensional (2D). Both are then mapped via an exponential function onto the Poincaré ball of curvature `c=1.0`, yielding hyperbolic embeddings. A hyperbolic multiclass logistic regression (MLR) classifier, operating with gyrovector arithmetic and geodesic distances, produces class logits from each branch (`ŷ1`, `ŷ2`). The total loss combines standard cross-entropy for both branches with a KL divergence consistency loss `L_KL(ŷ1, ŷ2)`, which uses the low-dimensional branch's predictions to regularize the high-dimensional branch. Only the high-dimensional branch is used at inference.

## Key Results
*   Hyperbolic single-branch classifiers (HypERM) yield statistically significant accuracy gains over their Euclidean equivalents across eleven in-distribution medical datasets (p<0.05).
*   On domain generalization benchmarks (Fitzpatrick17k, Camelyon17-WILDS, Retina), HypCBC outperforms state-of-the-art Euclidean DG methods by an average +2.1% AUC (Wilcoxon, p<0.05).
*   Ablations confirm the 2D hyperbolic bottleneck strongly suppresses domain predictability (measured via linear probe AUC) while retaining label-discriminative power, and hyperbolic cross-branch consistency delivers gains where Euclidean consistency does not.

## Why This Works (Mechanism)
### Mechanism 1: Hyperbolic Embeddings Capture Hierarchical Structure
Representing features on a hyperbolic manifold better encodes inherent clinical hierarchies (e.g., disease subtypes) than flat Euclidean space. The constant negative curvature provides exponentially greater separation capacity for semantically similar classes. The `exp_c` map projects features into this space, where a hyperbolic MLR classifier uses geodesic distances to class prototypes. *Core assumption:* The discriminative signal has a latent hierarchical structure aligning with hyperbolic geometry. *Evidence:* Consistent statistical improvements of HypERM over Euclidean across ID datasets (p<0.05). *Break condition:* Performance diminishes if the label space lacks hierarchical structure.

### Mechanism 2: Low-Dimensional Bottleneck Induces Domain Invariance
Projecting into a 2D hyperbolic subspace forces the branch to retain only the most domain-agnostic, label-relevant features, discarding higher-dimensional domain-specific variations (e.g., scanner-specific textures). The high-dimensional branch is then regularized by this "purified" low-dimensional representation. *Core assumption:* Domain-specific covariate information is higher-dimensional than the core class signal. *Evidence:* Domain predictability (via linear probe) is lowest at `d=2` for both manifolds, while label accuracy remains high. *Break condition:* Catastrophic failure if core discriminative signal is high-dimensional and inseparable from domain features in 2D.

### Mechanism 3: Cross-Branch Consistency Transfers Invariance
The KL loss `L_KL(ŷ1, ŷ2)` aligns the high-dimensional branch's predictions with the domain-invariant "consensus" of the low-dimensional branch. This regularizes `z1` to avoid overfitting to domain-specific patterns in its higher-capacity space, without needing domain labels or adversarial training. *Core assumption:* Aligning final predictions encourages alignment of underlying features. *Evidence:* HypCBC yields consistent AUC gains across datasets and bottleneck sizes, while Euclidean CBC does not. *Break condition:* Could mislead if `ŷ2` is poorly calibrated or biased (e.g., from extreme class imbalance).

## Architecture Onboarding
*   **Component map:** Input -> Frozen Euclidean Backbone (`Φ`) -> Projection Heads (`h1`→128D, `h2`→2D) -> Exponential Maps (`exp_c`) -> Hyperbolic Embeddings (`z1`, `z2`) -> Hyperbolic MLR Heads -> Logits (`ŷ1`, `ŷ2`) -> Loss Aggregator.
*   **Critical path:** Gradient from `L_KL` flows into `h1`'s parameters, regularizing the high-dimensional branch toward the low-dimensional branch's domain-invariant predictions. `h2` is trained via its own CE loss.
*   **Design tradeoffs:** Frozen backbone (stability vs. lost adaptation); bottleneck dimension `d2` (invariance vs. discriminative power, `d2=2` optimal); fixed curvature `c=1.0` (simplicity vs. potential dataset-specific adaptation); loss weight `λ` (regularization strength, `λ=0.2` used).
*   **Failure signatures:** Domain AUC not suppressed with `d2=2` (bottleneck failed); HypCBC underperforms HypERM (inconsistent regularization/`λ` too high); Euclidean CBC improves (contradicts paper's finding, possible dataset-specific effect or bug).

## Open Questions the Paper Calls Out
*   The hyperbolic benefit may stem from classifier geometry rather than capturing true hierarchical relationships in the data.
*   The 2D bottleneck's domain suppression assumes domain-specific features are high-dimensional; this may fail for low-dimensional shifts (e.g., color bias).
*   Consistency loss on logits lacks theoretical guarantees and could be sensitive to weighting and training instability.
*   Evaluation covers only three DG benchmarks (skin, histopathology, retina); conclusions may not transfer to other modalities or tasks.
*   Freezing the backbone limits representation learning; fine-tuning could break invariance properties.

## Limitations
*   The frozen pretrained backbone may limit the adaptation of feature extractor to new domains.
*   The core method assumes domain-specific covariate information requires higher-dimensional representations than the invariant class signal, which may not hold for all shift types (e.g., low-dimensional color or illumination changes).
*   Demonstrated gains are shown on a narrow set of three domain generalization benchmarks; broader validation across modalities and tasks is needed.

## Confidence
*   **Hyperbolic embeddings capture hierarchy (for ID tasks):** Medium. ID improvements are statistically significant, but direct evidence of captured hierarchy (e.g., dendrogram correlation) is not provided.
*   **2D bottleneck induces domain invariance:** High. Domain predictability consistently drops at `d=2` while label accuracy remains high, supported by probe experiments.
*   **Cross-branch consistency transfers invariance:** Medium-High. HypCBC beats single-branch baselines across datasets; Euclidean CBC fails, suggesting a hyperbolic-specific interaction.
*   **Overall DG superiority:** Medium. Gains on three benchmarks are significant but evaluation is limited; could be dataset-specific.

## Next Checks
1.  **Direct hierarchy probe:** Compare hyperbolic embedding distances against a validated clinical taxonomy (e.g., using cophenetic correlation from a dendrogram) and contrast with Euclidean distances for the same classes.
2.  **Bottleneck robustness test:** Apply HypCBC with varying `d2` on synthetic or real shifts of known/low dimensionality (e.g., color jitter, Gaussian blur) to test the "domain info is high-D" assumption. Expect `d2=2` to fail on truly low-D shifts.
3.  **Consistency objective ablation:** Replace the KL logits loss with alternatives (e.g., feature MSE, contrastive loss) or remove it entirely. Measure impact on DG performance to identify the optimal alignment objective and validate the specific mechanism.
