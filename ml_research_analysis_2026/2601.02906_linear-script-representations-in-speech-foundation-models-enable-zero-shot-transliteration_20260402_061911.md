# Linear Script Representations in Speech Foundation Models Enable Zero-Shot Transliteration

## Quick Facts
- **arXiv ID**: 2601.02906  
- **Source URL**: https://arxiv.org/abs/2601.02906  
- **Reference count**: 17  
- **Primary result**: Linear script vectors extracted from Whisper’s decoder enable zero-shot script steering, achieving up to 0.93 accuracy on Serbian Cyrillic and generalizing to unseen language-script pairs (e.g., Italian→Cyrillic 43%).

## Executive Summary
This work addresses script confusion in multilingual speech foundation models like Whisper, where the same language may be transcribed in different scripts (e.g., Serbian Latin vs. Cyrillic). The authors hypothesize that script information is linearly encoded in the decoder’s activation space. They extract “script vectors” by averaging decoder activations for examples in a source and target script and taking their difference. At inference, adding this vector to the decoder’s activations steers the output toward the desired script. Evaluated on Serbian and Chinese script pairs, the method outperforms prompting, especially in smaller models, and generalizes zero-shot to novel language-script combinations (e.g., romanization). The approach requires no model retraining, works with minimal examples, and is supported by linear probing confirming script separability across decoder layers.

## Method Summary
The method involves two stages: vector extraction and inference-time steering. For extraction, the model transcribes a small set of audio transcripts in a source and target script (e.g., Serbian Latin and Cyrillic). Decoder activations at each layer are collected for corresponding tokens, and the mean activation difference between scripts defines the script vector. At inference, this vector is added to the decoder’s activations at every layer during generation, shifting the output distribution toward the target script. Ablations show full-layer addition works best, consistent with linear separability across all decoder layers. The technique is applied to transliteration tasks (e.g., romanization, cyrillization) and evaluated on accuracy against gold script-labeled references. Pseudo-label training—using steered outputs as additional training data—further improves results.

## Key Results
- Achieves 0.93 accuracy on Serbian Cyrillic transcription with Whisper large-v2, surpassing prompting baselines.
- Demonstrates zero-shot generalization to novel language-script pairs, e.g., Italian→Cyrillic (43% accuracy) and romanization (up to 69%).
- Script vectors remain effective with as few as one example per script; pseudo-label training boosts performance across board.

## Why This Works (Mechanism)
The mechanism relies on the linear separability of script information in the decoder’s activation space. Whisper, trained on multilingual data with mixed scripts, develops distinct activation clusters for different scripts. By averaging activations for a given script pair, the extracted vector captures the direction that separates them in representation space. Adding this vector during inference nudges the decoder’s hidden states toward the target script’s manifold, effectively “translating” the internal representation without altering weights. Linear probing confirms high separability in all decoder layers, justifying full-layer steering. The approach works zero-shot because script manifolds are shared across languages—the vector for “Cyrillic” derived from Serbian can partially steer Italian outputs if the model already encodes script as a linear attribute.

## Foundational Learning
- **Speech foundation models**: Pre-trained on large-scale audio-text pairs, acquiring multilingual and multi-script representations. *Why needed*: Provides the base model whose internal activations contain script signals. *Quick check*: Does the model confuse scripts for the same language in standard transcription?
- **Linear representations**: Concepts encoded as directions in neural activation space, enabling arithmetic manipulation. *Why needed*: Underlies the vector addition steering mechanism. *Quick check*: Train a linear classifier on decoder activations to predict script; accuracy should be high.
- **Script confusion**: A model outputs inconsistent scripts for identical language content (e.g., Latin vs. Cyrillic for Serbian). *Why needed*: The core problem this method solves. *Quick check*: Evaluate model transcriptions on multi-script test sets for mixed-script output.
- **Zero-shot transliteration**: Applying script steering to unseen language-script pairs without in-language examples. *Why needed*: Demonstrates generalization beyond trained script pairs. *Quick check*: Extract script vector from pair A–B, apply to language C, measure accuracy against B-script references.
- **Linear probing**: Training a simple linear model on frozen neural activations to predict a target property (here, script). *Why needed*: Empirically verifies linear separability. *Quick check*: Probe each decoder layer separately; report accuracy > random.
- **Pseudo-label training**: Using model-generated outputs (e.g., steered transcriptions) as additional training data. *Why needed*: Amplifies and refines the script vector effect. *Quick check*: Compare accuracy with and without iterative pseudo-label updates.

## Architecture Onboarding
- **Component map**: Audio input -> Whisper Encoder -> Whisper Decoder (with script vector added at each layer) -> Output transcript
- **Critical path**: 1) Encoder converts audio to hidden states. 2) Decoder autoregressively generates tokens, using cross-attention to encoder states. 3) At each decoder layer, the script vector is added to the layer’s activation before self-attention/FFN. 4) Output distribution is shifted toward target script tokens.
- **Design tradeoffs**: 
  - *Simplicity vs. generality*: No retraining needed, but assumes linearity and may fail for non-linear script relationships.
  - *Data efficiency vs. noise*: Works with few examples, but script vector quality degrades if example data is noisy or misaligned.
  - *Full-layer vs. single-layer*: Full-layer addition works best, but may over-steer; single-layer is subtler but less effective.
- **Failure signatures**: 
  - Low accuracy on distant script pairs (e.g., Arabic to Latin) due to non-linear orthographic mappings.
  - Named entities and loanwords reduce steering success if not represented in example set.
  - Oversteering produces nonsensical output when vector magnitude is too high.
- **First experiments**:
  1. Apply method to Arabic script pairs (e.g., Arabic vs. Latin transliteration) to test generalizability beyond Cyrillic/Chinese.
  2. Ablate by adding script vector only to specific decoder layers (e.g., first vs. last) to identify critical layers.
  3. Vary number of examples per script from 1 to 100 to plot performance curve and determine minimal reliable sample size.

## Open Questions the Paper Calls Out
1. How do cross-script alignments develop during training of speech foundation models? The paper shows script is linearly representable at inference but does not study training dynamics. Tracking script separability across checkpoints or varying multi-script data proportions could reveal emergence mechanisms.
2. Do encoder-only models or models with phoneme recognition tasks exhibit stronger linear script representations than Whisper? Other architectures (e.g., HuBERT, wav2vec 2.0) with auxiliary phoneme objectives might foster different cross-script alignment. Applying the same probing and steering to such models would test this.
3. How do script vectors generalize to script pairs beyond Latin/Cyrillic and Simplified/Traditional Chinese? Scripts from different systems (e.g., Arabic abjad, Devanagari abugida) may have different orthographic-phonetic mappings affecting linearity and transfer. Evaluating on diverse script pairs is needed.
4. What role do named entities and cross-lingual loanwords play in facilitating script vector extraction? The paper hypothesizes these ease steering (e.g., Italian→Cyrillic success) but offers no systematic evidence. Correlating steering performance with lexical properties like named entity density could clarify.

## Limitations
- **Script diversity limited**: Evaluations focus on Serbian and Chinese; performance on structurally distinct scripts (e.g., Arabic, Devanagari) remains unverified.
- **Causal role unclear**: Linear probing confirms separability but does not prove script vectors fully capture or causally control script representation.
- **Zero-shot bound ambiguous**: Success on Italian→Cyrillic (43%) is promising but accuracy drops for distant pairs; boundary conditions for transfer are not mapped.

## Confidence
- **Linear script separability in Whisper decoder**: Medium (supported by probing but restricted to evaluated models/layers).
- **Script vector steering effectiveness for seen scripts**: Medium-High (strong empirical results on Serbian/Chinese).
- **One-example effectiveness**: Low (anecdotal; needs systematic testing with noisy/limited data).
- **Zero-shot generalization**: Medium-Low (inconsistent accuracy across language-script pairs).

## Next Checks
1. **Expand script/linguistic diversity**: Evaluate on ≥10 language-script pairs including Arabic (Arabic/Latin), Hindi (Devanagari/Latin), and Thai, measuring accuracy variance and failure modes.
2. **Layer-wise ablation & causal intervention**: Test steering using vectors from individual decoder layers vs. full-layer averaging, and perform targeted perturbation to confirm script vector causality.
3. **Cross-model generalization**: Replicate the method on recent multilingual speech models (e.g., Google USM, Meta’s MMS) to assess portability of linear script representations beyond Whisper.
