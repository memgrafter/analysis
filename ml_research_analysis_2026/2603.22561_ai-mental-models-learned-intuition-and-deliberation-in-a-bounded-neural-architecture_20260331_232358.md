# AI Mental Models: Learned Intuition and Deliberation in a Bounded Neural Architecture

## Quick Facts
- **arXiv ID:** 2603.22561
- **Source URL:** https://arxiv.org/abs/2603.22561
- **Reference count:** 0
- **Primary result:** A bounded dual-path neural network separates intuition (4-state) and deliberation (5-gated 4-state candidates) pathways on syllogistic reasoning; deliberation significantly outperforms intuition (aggregate test r = 0.8152 vs. 0.7272, p = 0.0101) and develops sparse, functionally differentiated internal states.

## Executive Summary
This study investigates whether a small, bounded neural architecture can internally organize into distinct intuition and deliberation systems when trained to mimic human syllogistic reasoning. Using a dual-path model with fixed-size state representations, the authors find that the deliberation pathway—employing a learned soft gate over five candidate states—achieves significantly higher correlation with human response distributions than the intuition pathway or a single-pass baseline. Interpretability analyses reveal that the deliberation pathway develops sparse, specialized internal states, with one state becoming a dominant "workhorse" and others showing functional leanings (e.g., for specific invalid conclusion types). Ablation experiments confirm these roles are causal. The work suggests that meaningful reasoning-like structure can emerge in constrained architectures without explicit symbolic reasoning components.

## Method Summary
The task is to predict normalized 9-way human response distributions for 64 canonical syllogisms (from Khemlani & Johnson-Laird, 2012) given a structured 29-dimensional premise encoding. Models are trained to minimize KL divergence between predicted and target distributions. Evaluation uses 5-fold cross-validation, with primary metric Pearson correlation (r) on held-out test folds; significance assessed via paired t-test on fold-wise correlations. The main comparison is between: (1) a direct MLP baseline (single hidden layer); and (2) a bounded dual-path model with separate intuition encoder (4-unit state) and deliberation pathway (five 4-dim candidate states plus a deliberation state, gated via softmax). Both pathways output 9-way softmax distributions; losses are combined equally. Training uses Adam (lr=1e-3) for 4000 epochs.

## Key Results
- Deliberation pathway significantly outperforms intuition pathway (aggregate test r = 0.8152 vs. 0.7272, p = 0.0101) and the direct MLP baseline (r ~0.71).
- The largest deliberation gains are for rejection responses (NVC) and particular invalid conclusion types (Eca, Oca).
- Deliberation pathway learns sparse, functionally differentiated internal states: one candidate becomes a dominant "workhorse," one specializes toward Oac-leaning responses, and several are rarely or never used as gate winners.
- State role structures (e.g., which index is workhorse) recur across random seeds despite different state indices.
- Ablation confirms causal specialization: removing the dominant workhorse state causes a dramatic performance drop (Δr ≈ –0.55), while removing weakly used states has negligible effect.

## Why This Works (Mechanism)
The gated deliberation pathway enables the model to dynamically select among a small set of specialized, linearly represented "reasoning strategies." Sparse gating forces each candidate state to capture a coherent mode of responding (e.g., endorsing certain conclusion forms or rejecting arguments), leading to a modular internal organization that generalizes better than a monolithic intuition pathway or a single-pass network. The bounded state size (4 dimensions) constrains each strategy’s capacity, promoting efficiency and preventing overfitting on the small 64-item benchmark.

## Architecture Onboarding
**Component map:**  
Input (29-dim) → [Intuition Encoder] → Intuition State (4-dim) → Intuition Output (9-way softmax)  
Input (29-dim) → [Deliberation Encoder] → Deliberation State (4-dim) → [Gate: softmax over 5 candidate scores] → Weighted sum of 5×[Candidate State (4-dim)] → Deliberation Output (9-way softmax)

**Critical path:** Deliberation pathway’s gated selection from candidate states is the core mechanism enabling sparse specialization and performance gain.

**Design tradeoffs:**  
- *Bounded size vs. expressiveness:* Fixed 4-dim states limit each strategy’s capacity but encourage efficient, generalizable features.  
- *Gated sparsity vs. stability:* Sparse gating promotes specialization but may complicate training; softmax gate ensures differentiability.

**Failure signatures:**  
- Uniform gate usage across all 5 candidates (no specialization).  
- No significant performance gap between deliberation and intuition pathways.  
- Ablation removing any candidate state causes similar performance drops (no causal roles).

**First three experiments to run:**  
1. Replicate direct MLP baseline: verify aggregate test r ≈ 0.71 under 5-fold CV.  
2. Inspect deliberation gate winners: confirm heavy-tailed distribution (e.g., one candidate wins >50% of items, one never wins).  
3. Perform candidate-state ablation: remove alleged dominant workhorse state and measure Δr; expect large drop (~–0.55), negligible for others.

## Limitations
- Benchmark scale: Only 64 syllogisms risks overfitting; findings may not generalize to larger or different reasoning tasks.
- Architecture details: Encoder layers and exact gate mechanism are unspecified, hindering exact replication.
- Scope of reasoning claims: Evidence limited to syllogistic response prediction; no claims about general reasoning or symbolic processing.
