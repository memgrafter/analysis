# Neural-Symbolic Logic Query Answering in Non-Euclidean Space

## Quick Facts
- **arXiv ID:** 2603.15633
- **Source URL:** https://arxiv.org/abs/2603.15633
- **Reference count:** 40
- **Primary result:** HYQNET achieves state-of-the-art performance on FB15k, FB15k-237, and NELL995, outperforming baselines in mean reciprocal rank (MRR) and Hits@1, with notable gains on queries involving intersection and negation.

## Executive Summary
The paper addresses the challenge of answering complex first-order logic queries on incomplete knowledge graphs, where symbolic methods fail due to incompleteness and neural methods lack interpretability. The proposed HYQNET model combines neural-symbolic reasoning with hyperbolic geometry. It decomposes queries into fuzzy set operations (conjunction, disjunction, negation) and employs a hyperbolic graph neural network with learned curvature for relation projection, effectively capturing hierarchical query structures. Experiments on standard benchmarks show consistent state-of-the-art results, particularly on intersection and negation queries, and superior performance in predicting answer set cardinalities.

## Method Summary
HYQNET parses first-order logic queries into computation graphs. Relation projections are executed via a hyperbolic graph neural network that propagates entity embeddings along knowledge graph edges. Logical connectives are implemented as differentiable fuzzy set operations (product t-norm for AND, probabilistic sum for OR, complement for NOT) over membership vectors, enabling end-to-end training while maintaining an interpretable execution trace. The model uses the Poincaré ball model with per-layer learned curvature to adapt geometric scaling during propagation, allowing flexible handling of exponential branching in query trees. Training employs binary cross-entropy loss to rank answer entities.

## Key Results
- HYQNET achieves state-of-the-art mean reciprocal rank (MRR) and Hits@1 on FB15k, FB15k-237, and NELL995.
- Significant improvements on queries with intersection (e.g., 2i, 3i) and negation (e.g., 2in, pin) compared to baselines like GNN-QE.
- Superior Spearman correlation in predicting answer set cardinalities, indicating better calibration of confidence.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Hyperbolic embeddings capture the hierarchical, tree-like structure of logical query decomposition more effectively than Euclidean space.
- **Mechanism:** The hyperbolic Poincaré ball model provides exponential growth in representational capacity with distance from the origin. This property aligns with recursive variable bindings during multi-hop relation projection, where candidate sets can expand exponentially. The hyperbolic GNN propagates messages within this space, using learned curvature to scale transformations, preserving hierarchical dependencies without Euclidean distortion.
- **Core assumption:** The recursive tree structure from projecting relations through a query's computation graph is inherently hierarchical with exponential branching, which hyperbolic geometry models efficiently.
- **Evidence anchors:** Abstract states hyperbolic representations capture hierarchical projection reasoning better. Section 4.2 argues hyperbolic embeddings suit exponential neighborhood growth that standard GNNs struggle with.
- **Break condition:** If query structures are primarily graph-like with dense cycles or relation projections lack exponential fan-out, hyperbolic overhead may harm performance.

### Mechanism 2
- **Claim:** Decomposing FOL queries into fuzzy set operations provides a continuous, differentiable, and interpretable execution trace.
- **Mechanism:** Logical operations are defined as algebraic functions over membership degree vectors: conjunction as element-wise product (independent joint belief), disjunction as probabilistic sum, negation as complement. This decomposes complex queries into primitive neural-symbolic steps (projection → fuzzy op → projection), allowing inspection of intermediate fuzzy sets to understand inclusion/exclusion at each reasoning step.
- **Core assumption:** Boolean logic can be soundly relaxed to fuzzy logic in the [0,1] domain without violating key inference properties for learning and ranking.
- **Evidence anchors:** Abstract mentions decomposition enhances interpretability. Section 3.1 explicitly defines the fuzzy operators and their role in combining projection results.
- **Break condition:** If fuzzy operators fail to preserve logical laws (e.g., De Morgan’s) under the learned geometry, chaining could compound errors, especially for deep negation compositions.

### Mechanism 3
- **Claim:** Layer-wise learned curvature in the hyperbolic GNN allows adaptive geometric scaling per propagation step, improving relation projection flexibility.
- **Mechanism:** Each GNN layer learns its own curvature parameter `c_l`. The exponential and logarithmic maps use `c_l` to transform between tangent space and manifold. Earlier layers (near anchor entities) can use higher curvature for fine-grained local structure, while later layers (deeper in query tree) use lower curvature to merge broader candidate sets, adapting to evolving abstraction levels.
- **Core assumption:** The optimal geometric "tightness" for encoding relational dependencies varies with depth and branching factor of the query tree.
- **Evidence anchors:** Abstract notes learned curvature increases flexibility and improves reasoning. Section 4.2 describes the update equations with per-layer `c`.
- **Break condition:** If curvature parameters become unstable (e.g., diverge) or the dataset's relational patterns do not exhibit varying hierarchical densities per hop, learned curvature may overfit or provide no gain over fixed curvature.

## Architecture Onboarding
- **Component map:** Query Parser -> Hyperbolic GNN Projector -> Fuzzy Logic Module -> Scoring & Loss
- **Critical path:** For a query like `π_r1 (A ∧ π_r2 B)`: Start with anchor `A`'s embedding → `π_r2` on `B` yields fuzzy set Y → `C(A, Y)` via product → `π_r1` on result → final sigmoid scoring.
- **Design tradeoffs:**
  - Hyperbolic vs. Euclidean: Hyperbolic better for deep hierarchical projections but incurs O(n²) distance computation and numerical instability near boundary; Euclidean simpler but may need higher dimensions for same expressivity.
  - Fuzzy logic choice: Product t-norm is interpretable and aligns with probabilistic independence but is "sharp" (0 if any input 0); other t-norms (Gödel, Łukasiewicz) trade off different logical properties.
  - Learned curvature: Adds flexibility but also hyperparameters (initialization, regularization) and risk of collapse (c→0 becomes Euclidean; c large causes gradient issues).
- **Failure signatures:**
  - Sudden NaN losses → likely hyperbolic map instability (curvature too high or embeddings near boundary).
  - Poor performance on negation queries (2in, pin, pni) → fuzzy NOT may not be sufficiently discriminative or hyperbolic GNN fails to propagate negative evidence.
  - Performance gap between training and test query types → overfitting to seen query structures; consider query augmentation.
- **First 3 experiments:**
  1. Baseline replication: Run HYQNET and GNN-QE (Euclidean GNN) on FB15k-237 with identical hyperparameters (layers, dim, lr). Expect HYQNET ≥ GNN-QE on MRR, especially on 2i, 3i, 2in.
  2. Ablation - curvature: Fix all layer curvatures to a small constant (e.g., c=1.0) vs. learned. If learned curvature helps, fixed should show consistent drop, particularly on deeper queries (3p, 3i).
  3. Fuzzy operator sanity check: Replace product fuzzy ops with Euclidean-based ops from GNN-QE (e.g., cosine similarity for AND) while keeping hyperbolic GNN. Performance drop would indicate fuzzy ops are a key contributor beyond geometry.

## Open Questions the Paper Calls Out
- How can HYQNET be extended to incorporate more expressive first-order logic operations, such as universal quantification or complex nesting?
- What performance gains can be achieved by implementing adaptive curvature learning in hyperbolic GNNs, where curvature is dynamically adjusted per relation or query context?
- How does the computational efficiency of HYQNET scale with knowledge graph size, given the overhead of hyperbolic operations and recursive tree propagation?
- Can HYQNET generalize to arbitrary, natural-language-derived FOL queries that deviate from the synthetic query structures in the training set?

## Limitations
- No comprehensive ablation to separate contributions of hyperbolic space, fuzzy ops, and curvature learning.
- Evaluation on standard KGs may suffer from false negative issue; not tested on more realistic, larger-scale data.
- Computational complexity and scalability of hyperbolic GNN not reported; theoretical connection between hyperbolic geometry and exponential query expansion remains informal.
- Interpretability claim not substantiated by qualitative examples or user studies.

## Confidence
- Overall SOTA performance: High
- Hyperbolic geometry for hierarchy: Medium
- Fuzzy set decomposition: Medium
- Layer-wise learned curvature: Low

## Next Checks
1. Component ablation: Replace hyperbolic GNN with Euclidean GNN, fix curvature, and switch fuzzy operators (e.g., to Gödel t-norm) to quantify each factor's impact on MRR/Hits across query types.
2. Curvature behavior analysis: Track per-layer curvature values during training, correlate with query depth/branching factors, and test robustness to different initializations and regularization strengths.
3. Broader evaluation: Run HYQNET on a larger KG (e.g., Wikidata) using a more rigorous negative sampling strategy; measure training/inference time, memory usage, and performance on out-of-distribution query structures.
