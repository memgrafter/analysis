# Small Language Models for Privacy-Preserving Clinical Information Extraction in Low-Resource Languages
## Quick Facts
- arXiv ID: 2602.21374
- Source URL: https://arxiv.org/abs/2602.21374
- Reference count: 36
- Primary result: Qwen2.5-7B-Instruct achieved median macro-F1 of 0.899 and MCC of 0.797 on extracting 13 binary clinical features from Persian palliative care transcripts via translation-augmented few-shot prompting.

## Executive Summary
This study tackles structured clinical data extraction from Persian medical transcripts in low-resource settings without model fine-tuning. It proposes a two-step pipeline: first translating Persian text to English using Aya-expanse-8B, then applying few-shot prompting with small language models (SLMs) to extract 13 binary clinical features. Evaluated on 1,221 palliative care call transcripts, larger SLMs (7B–8B parameters) significantly outperformed smaller ones, with Qwen2.5-7B-Instruct reaching the highest overall performance (median macro-F1: 0.899; MCC: 0.797). Translating to English improved sensitivity and reduced missing outputs, enhancing robustness to class imbalance, although it slightly reduced specificity and precision. While physiological symptoms like pain and fever were reliably extracted, psychological complaints, administrative requests, and complex somatic features remained consistently difficult across all models.

## Method Summary
The pipeline comprises two sequential steps. Step 1: Persian transcripts are translated to English using Aya-expanse-8B with temperature=0.3 and max_new_tokens=2048. Step 2: Five open-source SLMs (Qwen2.5-7B-Instruct, Llama-3.1-8B-Instruct, Llama-3.2-3B-Instruct, Qwen2.5-1.5B-Instruct, Gemma-3-1B-it) and Aya-expanse-8B in both languages are prompted with a fixed system message and three few-shot examples (greedy decoding, max_new_tokens=512). The model outputs are post-processed to extract 13 binary fields; missing values are treated as False. Performance is assessed using macro-averaged F1-score, Matthews correlation coefficient (MCC), sensitivity, specificity, precision, and accuracy against manual annotations.

## Key Results
- Qwen2.5-7B-Instruct achieved the highest overall performance (median macro-F1: 0.899; MCC: 0.797).
- Translating Persian to English improved sensitivity and reduced missing outputs, enhancing robustness to class imbalance, but slightly lowered specificity and precision.
- Physiological symptoms (pain, fever) were reliably extracted, while psychological complaints, administrative requests, and complex somatic features remained difficult for all models.

## Why This Works (Mechanism)
Translation to English leverages the stronger English-language capabilities of SLMs, improving sensitivity and reducing missing outputs by mitigating class imbalance. Larger models (7B–8B parameters) possess sufficient capacity to follow few-shot prompts and extract structured data accurately without fine-tuning. The fixed few-shot examples provide consistent in-context learning anchors, and the post-processing ensures reliable binary output conversion even with minor formatting variations.

## Foundational Learning
- **Few-shot prompting**  
  *Why needed*: Enables SLMs to perform tasks without fine-tuning, essential for low-resource settings with limited labeled data.  
  *Quick check*: Verify model adheres to the output template with 3 demonstrations; measure format compliance rate.
- **Translation for low-resource languages**  
  *Why needed*: Persian clinical data is scarce; translation accesses richer English-language model knowledge.  
  *Quick check*: Sample translations for clinical term accuracy; compare feature extraction performance between direct Persian (if feasible) and translated English.
- **Small language models (SLMs)**  
  *Why needed*: Lower computational cost and memory footprint suit deployment in resource-constrained environments.  
  *Quick check*: Confirm model fits within target GPU memory (e.g., 24GB VRAM with FP16/BF16); benchmark inference speed.
- **Binary clinical feature extraction**  
  *Why needed*: Produces structured data for clinical decision support; binary labels simplify annotation and evaluation.  
  *Quick check*: Compute per-feature macro-F1; identify features with near-chance performance.
- **Robust evaluation metrics**  
  *Why needed*: Class imbalance requires metrics beyond accuracy; macro-F1 and MCC provide balanced assessment.  
  *Quick check*: Compare sensitivity–specificity trade-offs; track missing output rates across models.

## Architecture Onboarding
- **Component map**: Persian transcript -> Aya-expanse-8B (translation) -> English text -> SLM (few-shot prompt) -> raw output -> post-processing -> binary predictions
- **Critical path**: Translation must complete before extraction; both steps execute sequentially per transcript.
- **Design tradeoffs**: Translation adds latency but improves sensitivity; fixed few-shot examples ensure consistency but may not capture linguistic diversity; greedy decoding reduces randomness but may miss valid outputs.
- **Failure signatures**: Non-conforming model outputs (extra text, missing fields) causing parsing failures; poor translation of clinical nuances leading to feature misclassification; high missing rates for psychological/administrative features.
- **First three experiments**:  
  1. Run end-to-end pipeline on 10 random transcripts; manually inspect translations and model outputs for format adherence.  
  2. Compare Aya-expanse-8B performance on direct Persian vs. translated English to isolate translation impact.  
  3. Test stability of Qwen2.5-7B-Instruct by swapping few-shot examples (if available) and measuring metric variance.

## Limitations
- Few-shot examples are undisclosed; possible test set overlap may inflate reported scores.
- Translation is fixed to Aya-expanse-8B; robustness to other translators or direct Persian processing is unknown.
- Treating parsing failures as False biases metrics; translation artifacts likely affect nuanced feature extraction.
- Psychological, administrative, and complex somatic features remain consistently difficult across models.

## Confidence
- Larger models (7B–8B) superiority: **High**
- Translation trade-off (improved sensitivity vs. lowered specificity): **Medium**
- Hard feature difficulty (psychological, administrative, complex somatic): **Medium**
- Exact reproducibility due to undisclosed few-shot details: **Low**

## Next Checks
1. Confirm that the three few-shot examples are excluded from the 1,221 test set; if included, re-evaluate metrics without overlap.
2. Quantify translation quality (e.g., human review or automatic metrics like chrF) on a clinical-term subset; correlate errors with extraction failures; test alternative translator models.
3. Perform detailed error analysis on mispredicted hard features (psychological, administrative, complex somatic) to identify common failure patterns and iteratively refine prompts.
