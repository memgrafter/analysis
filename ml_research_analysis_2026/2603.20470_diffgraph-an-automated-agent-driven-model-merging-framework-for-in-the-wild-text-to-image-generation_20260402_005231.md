# DiffGraph: An Automated Agent-driven Model Merging Framework for In-the-Wild Text-to-Image Generation
## Quick Facts
- **arXiv ID:** 2603.20470
- **Source URL:** https://arxiv.org/abs/2603.20470
- **Reference count:** 40
- **Primary result:** DiffGraph significantly outperforms existing merging baselines, achieving ImageReward 73.11 vs. 29.94 (SDv1.5) and 148.75 vs. 124.51 (FLUX).

## Executive Summary
DiffGraph is a framework that automatically merges diverse, publicly available text-to-image expert models (checkpoints and LoRAs) to handle arbitrary user prompts. It constructs a universal skill graph of experts by registering nodes via LLM-generated descriptions and calibrating edges with performance scores on reference prompts. At inference, an LLM-powered agent selects a relevant subgraph of experts, and a variational graph autoencoder (VGAE) predicts optimal merging coefficients. This approach dynamically assembles specialized models without retraining, substantially improving image quality metrics over prior merging methods on standard benchmarks.

## Method Summary
The method has three stages: (1) **Universal Graph Construction**: Each expert model is registered as a node with an LLM-generated skill description (encoded via a sentence transformer). Experts are calibrated by evaluating their performance on a set of reference prompts using multiple image quality metrics; these scores become edge features linking experts to reference prompt nodes. (2) **Dynamic Subgraph Activation**: For a user prompt, an Expert Selection Agent (ESA)—an LLM—parses the prompt, retrieves candidate experts by embedding similarity, and filters to a final set. (3) **Merging Planner (MP)**: A VGAE takes the subgraph (selected experts, relevant reference nodes, user prompt node) and predicts Beta-distributed merging coefficients for checkpoint and PEFT experts separately. The experts are merged using these coefficients. Only the VGAE is trained via policy gradient to maximize image quality; the LLM agents are frozen.

## Key Results
- On Stable Diffusion v1.5, DiffGraph achieves ImageReward 73.11 vs. 29.94 (DiffAgent) and HPSv2 30.06 vs. 27.83.
- On FLUX, it achieves ImageReward 148.75 vs. 124.51 (DiffAgent) and HPSv2 32.36 vs. 30.26.
- The framework scales to new expert models without retraining the VGAE.

## Why This Works (Mechanism)
DiffGraph works because it decouples expert skill characterization from dynamic, prompt-specific merging. The universal graph provides a structured memory of expert capabilities based on actual performance on diverse reference prompts, not just metadata. The ESA uses LLM reasoning to map user intents to relevant skills, bypassing brittle keyword matching. The VGAE planner learns to combine experts optimally for a given subgraph context, generalizing across expert combinations. This pipeline leverages the abundance of online models by treating them as modular components whose collective strength is maximized through learned merging policies, rather than relying on a single model or uniform averaging.

## Foundational Learning
- **Model Merging (Checkpoint & PEFT)**: Needed to combine strengths of multiple fine-tuned models. *Quick check:* Can interpolate two model checkpoints via weighted average without degradation?
- **Graph Neural Networks (GCN for VGAE)**: Needed to encode subgraph structure and predict merging coefficients. *Quick check:* Does a 2-layer GCN on a small expert graph produce sensible node embeddings?
- **LLM as Agent (ESA)**: Needed to parse natural prompts and make high-level selection decisions. *Quick check:* Can GPT-4o extract visual attributes from a user prompt consistently?
- **Variational Graph Autoencoder (VGAE)**: Needed to model distributions of merging weights. *Quick check:* Does the VGAE decoder output valid Beta parameters (α,β > 0)?
- **Reinforcement Learning (Policy Gradient)**: Needed to optimize non-differentiable image quality metrics. *Quick check:* Does REINFORFE update increase reward on a held-out validation set?
- **Embedding-based Retrieval (Sentence Transformer)**: Needed to match prompt/description semantics. *Quick check:* Do cosine similarities rank relevant expert descriptions above unrelated ones for sample prompts?

## Architecture Onboarding
### Component Map
User Prompt -> ESA (LLM) -> Selected Experts + Reference Nodes -> Subgraph -> VGAE (MP) -> Merging Coefficients -> Weighted Merge -> Generated Image

### Critical Path
The core pipeline runs from user prompt through ESA selection to VGAE-based merging. The graph construction phase is offline; the online path is ESA -> Subgraph Assembly -> VGAE Inference -> Merging.

### Design Tradeoffs
- **LLM Flexibility vs. Cost/Stability**: Using GPT-4o for ESA enables nuanced reasoning but introduces API cost, latency, and non-determinism.
- **VGAE Training Stability vs. Performance**: Policy gradient on non-differentiable rewards is sample-inefficient and may converge to trivial solutions without careful reward shaping.
- **Graph Scalability vs. Relevance**: Adding more experts enriches the graph but increases ESA retrieval space and subgraph size, risking memory overflow or noise.

### Failure Signatures
- **ESA failure**: Selected experts are irrelevant to prompt (e.g., selects “anime” experts for photorealistic prompt). Diagnose by manual inspection of retrieved/final lists.
- **VGAE failure**: Predicted coefficients are near-uniform or highly erratic across prompts. Diagnose by tracking coefficient variance during training/validation.
- **Graph calibration failure**: Edge features (metric scores) do not correlate with held-out prompt performance. Diagnose by computing correlation between reference scores and performance on new prompts.

### First Three Experiments
1. **Baseline metric replication**: Re-implement Diffusion Soup and Model Swarms using identical metric code (model versions, preprocessing) to match paper’s baseline scores.
2. **ESA selection audit**: For 20 diverse user prompts, log ESA’s retrieved candidates, final selections, and embedding similarities; manually evaluate relevance.
3. **VGAE training stability**: Train VGAE on a small fixed expert subset; monitor reward progression and coefficient distribution to detect collapse or divergence.

## Open Questions the Paper Calls Out
None explicitly raised by the authors.

## Limitations
- Exact LLM prompt templates for skill description generation and ESA are unspecified, risking agent behavior deviations.
- Reference prompt set construction (size, diversity metric, linguistic features) is unclear, potentially weakening graph calibration.
- VGAE hyperparameters (layers, dimensions, training schedule) and merging mechanics (coefficient normalization, PEFT application) are not detailed, affecting reproducibility.
- Metric implementations (exact model versions for ImageReward, HPSv2) may diverge, undermining result comparison.

## Confidence
- **Performance claims** (ImageReward/HPSv2 gains): **Medium** – dependent on metric consistency and unverified VGAE training stability.
- **Graph construction & agent selection**: **Medium** – methodological clarity exists, but missing templates/hyperparameters introduce variability.
- **Scaling to new experts without retraining**: **Low** – plausible by design but unvalidated empirically in reproduction.

## Next Checks
1. Replicate baseline results (Diffusion Soup, Model Swarms) using identical metric wrappers to confirm score alignment before testing DiffGraph.
2. For a sample of user prompts, manually inspect ESA’s selected experts and compute embedding similarities to diagnose selection relevance.
3. During VGAE training, track predicted coefficient variance and held-out reward; near-zero variance or stagnant reward indicates learning failure.
