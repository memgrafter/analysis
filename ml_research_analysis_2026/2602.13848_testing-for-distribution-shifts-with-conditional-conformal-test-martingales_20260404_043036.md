# Testing For Distribution Shifts with Conditional Conformal Test Martingales

## Quick Facts
- **arXiv ID:** 2602.13848
- **Source URL:** https://arxiv.org/abs/2602.13848
- **Reference count:** 40
- **Primary result:** Proposes conditional conformal test martingales that avoid test-time contamination by using a fixed reference set and DKW error correction, achieving higher power and faster detection than standard CTM.

## Executive Summary
The paper tackles a critical flaw in existing conformal test martingales (CTMs) for streaming data: test-time contamination. In standard CTM, the reference set grows with each new test observation, so after a distribution shift, later post-shift points are compared against a mixture of pre- and post-shift data, which dilutes the evidence and delays detection. The authors introduce the **conditional CTM**, which uses a fixed reference dataset and explicitly accounts for the error in the empirical CDF estimate via uniform confidence bounds (e.g., DKW inequality). This correction preserves the martingale property under the null while maintaining sensitivity. The method learns the betting parameter online via the Online Newton Step. Theoretically, it guarantees finite-sample type‑I error control and asymptotic power one. Empirical evaluations on synthetic shifts and ImageNet‑C corruptions show that conditional CTM consistently outperforms standard CTM, with particularly large gains when the reference set contains 500 or more samples.

## Method Summary
The conditional CTM processes a stream of univariate scores against a fixed reference set \(D_0\) of size \(n\) drawn from the null distribution. For each test sample \(X_t\), it computes a conformal p‑value \(\hat p_t = \hat F_0(X_t)\), where \(\hat F_0\) is the empirical CDF of \(D_0\). Because \(\hat F_0\) is a noisy estimate of the true CDF \(F\), the method applies a uniform confidence band (via the Dvoretzky‑Kiefer‑Wolfowitz inequality) that holds with probability \(\ge 1-\delta\) over the reference draw. The betting function multiplies the wealth process by a term \(1 + C\big(\eta_t(\hat p_t-0.5) - \sqrt{\eta_t^2+k^2}\;\epsilon\big)\), where \(\epsilon\) is the confidence band half‑width. This penalty ensures the wealth is a supermartingale under the null. The betting parameter \(\eta_t\) is updated online via the Online Newton Step algorithm, with a small smoothing constant \(k\) and a clipping mechanism to prevent unnecessary decay. In contrast, the standard CTM uses a growing reference set that incorporates test data, leading to contamination and no finite‑sample guarantee.

## Key Results
- Finite‑sample type‑I error controlled at level \(\alpha\) with probability \(\ge 1-\delta\) over the reference.
- Asymptotic power one under any fixed alternative distribution \(Q \neq P\).
- Expected detection delay scales as \(O(1/\Delta^2 \log(1/(\alpha\Delta)))\) for effective signal \(\Delta\).
- Empirical results on synthetic and ImageNet‑C benchmarks show conditional CTM achieves significantly higher power and faster detection than standard CTM, especially for reference set sizes \(n \ge 500\).

## Why This Works (Mechanism)
**Mechanism 1: Test‑time contamination in standard CTM**  
The standard CTM’s reference set \(D_t = D_0 \cup \{X_1,\dots,X_t\}\) grows over time. After a distribution shift, new test points are added to \(D_t\), so subsequent p‑values are computed relative to a mixture of pre‑shift and post‑shift data. This makes shifted samples appear less atypical as more post‑shift data accumulate, causing the mean p‑value to drift back toward 0.5 and erasing evidence. The severity depends on how quickly \(|D_t|\) becomes large relative to the number of post‑shift samples.

**Mechanism 2: Fixed reference set avoids contamination**  
Conditional CTM uses a fixed reference set \(D_0\) for all test points. The null distribution estimate \(\hat F_0\) never changes, so each sample is consistently compared to the same baseline. This design eliminates contamination by construction, provided \(D_0\) adequately represents the null distribution.

**Mechanism 3: Error‑corrected martingale via confidence bounds**  
The betting function subtracts a penalty proportional to the DKW confidence band half‑width \(\epsilon(\hat p_t)\). Specifically, the term \(-\sqrt{\eta_t^2+k^2}\;\epsilon(\hat p_t)\) ensures that, even with a finite reference set, the conditional expectation of the bet satisfies \(E[ b_t(\hat p_t) \mid \mathcal{F}_{t-1}, D_0 ] \le 1\) under the null. This preserves the martingale (actually supermartingale) property, which is the foundation of the finite‑sample type‑I guarantee.

- **Dvoretzky–Kiefer–Wolfowitz (DKW) inequality**  
  Provides a finite‑sample, distribution‑free uniform confidence band for an empirical CDF: \(P( \sup_x |\hat F_0(x)-F(x)| > \epsilon ) \le 2e^{-2n\epsilon^2}\). The half‑width scales as \(\epsilon = \sqrt{\frac{1}{2n}\ln\frac{2}{\delta}}\).

## Architecture Onboarding
**Component map:**  
Fixed Reference Set \(D_0\) → ECDF Estimator \(\hat F_0\) → Confidence Band Calculator \(\epsilon(\cdot)\) → Betting Function \(b_t(\hat p_t)\) → Wealth Process \(S_t\). The ONS Learner updates \(\eta_t\) using gradients from \(\hat p_t\) and \(\epsilon(\hat p_t)\). The Clipping Module zeroes \(\eta_t\) if its magnitude falls below a threshold \(\tau\).

**Critical path:**  
1. Pre‑compute \(\hat F_0\) from \(D_0\); initialize \(S_0=1\), \(\eta_1=0\).  
2. For each stream sample \(X_t\):  
   a. Compute \(\hat p_t = \hat F_0(X_t)\).  
   b. Evaluate \(\epsilon = \sqrt{\frac{1}{2n}\ln\frac{2}{\delta}}\) (constant‑width DKW).  
   c. Compute \(b_t = 1 + C\big(\eta_t(\hat p_t-0.5) - \sqrt{\eta_t^2+k^2}\;\epsilon\big)\) with \(C = 1/(0.5 + \sqrt{1+k^2}\,\epsilon)\).  
   d. Update \(S_t \gets S_{t-1} \cdot b_t\).  
   e. If \(S_t \ge 1/\alpha\), reject \(H_0\).  
   f. Compute gradient \(g' = C\big((\hat p_t-0.5) - \frac{\eta_t}{\sqrt{\eta_t^2+k^2}}\;\epsilon\big)\) and scaled gradient \(z = g'/(1+b_t-1)\).  
   g. Update \(a \gets a + z^2\), then \(\eta_{t+1} \gets \operatorname{clip}(\eta_t + 4z/a,\,-0.5,\,0.5)\).  
   h. Apply clipping: if \(|\eta_{t+1}| < \tau\) set \(\eta_{t+1}=0\).

**Design tradeoffs:**  
- **Reference size \(n\):** Larger \(n\) yields smaller \(\epsilon\) → higher power but requires more offline null data. Gains saturate beyond \(n \approx 500\).  
- **Confidence level \(\delta\):** Smaller \(\delta\) tightens bounds and increases power but weakens the finite‑sample guarantee (Theorem 3.1 holds with probability \(\ge 1-\delta\) over \(D_0\)). Typical \(\delta=0.1\).  
- **Clipping threshold \(\tau\):** Prevents wealth decay under null by halting bets when \(|\eta_t|\) is small. \(\tau=0.1\) used in experiments; higher values delay detection, lower values allow unnecessary decay.  
- **Smoothing \(k\):** Ensures differentiability for ONS; must be tiny (\(10^{-6}\)) to avoid bias. Theoretically taken to 0 for power analysis (Theorem 3.3).

**Failure signatures:**  
- **High false alarm rate:** DKW bounds fail (e.g., \(\delta\) too large) or null misspecified (non‑i.i.d. \(D_0\)).  
- **Low power / delayed detection:** Reference set \(n\) too small (wide \(\epsilon\)), shift magnitude too small (\(\Delta \le 0\)), clipping \(\tau\) too high, or ONS step size (factor 4) mis‑tuned.  
- **Wealth decay under null:** ONS produces non‑zero \(\eta_t\) during null; monitor \(\ln S_t\) trend during warm‑up.  
- **ONS instability:** \(\eta_t\) hits bounds \(\pm0.5\) quickly; check \(a_t\) growth rate.

**First 3 experiments:**  
1. **Type I Error Calibration:** Stream of null samples (\(X_t \sim \mathcal{N}(0,1)\)). Verify empirical false‑alarm rate \(P(S_t \ge 1/\alpha) \le \alpha\) across different \(n\). (Figure 2 left).  
2. **Power vs. Standard CTM:** Simulate immediate shift (\(\mathcal{N}(0,1) \to \mathcal{N}(1,1)\)). Compare cumulative rejection probability over time. Conditional CTM should reject faster for \(n \ge 500\). (Figure 2 right).  
3. **Parameter Ablation:** Vary clipping threshold \(\tau\) on a delayed change‑point (shift at \(t=200\)). Confirm \(\tau=0.1\) maximizes early power while maintaining type‑I control. (Appendix F, Figure 5).

## Open Questions the Paper Calls Out
**Open Question 1:** How can synthetic data methods be effectively integrated into the conditional CTM framework to improve power when the reference set is small, while preserving finite‑sample type‑I error control?  
*Basis:* Authors state: “We believe that recent methods that utilize synthetic data can be used to mitigate this limitation” but provide no implementation or analysis.  
*Why unresolved:* Small \(n\) yields wide DKW bands and conservative tests. Synthetic data could augment \(D_0\), but must be incorporated without violating the martingale property.  
*Resolving evidence:* A construction showing how to martingale‑transform synthetic data (e.g., via importance weighting or conformal synthesis) so that the betting function remains a valid supermartingale under \(H_0\); empirical evaluation across corruption types and reference sizes.

**Open Question 2:** What alternative betting functions beyond the linear (plus smoothed absolute) term used herein can achieve higher power against a broader class of distribution shifts while maintaining validity?  
*Basis:* Authors mention: “Another future direction is to extend our conditional CTM test to utilize other betting functions, with the goal of further enhancing statistical power.” Only the specific function (7)/(8) is studied.  
*Why unresolved:* The linear form may be suboptimal for shifts affecting distributional shape (heavy tails, multimodality) rather than just the mean of conformal p‑values. More expressive martingales could react faster.  
*Resolving evidence:* Derivation of new betting functions that incorporate higher‑order moments or shape‑aware terms, with proofs that they satisfy the conditional martingale property using confidence bands; simulations contrasting performance on synthetic shifts with varying characteristics.

**Open Question 3:** Can the theoretical guarantees (asymptotic power one, bounded expected detection delay) be extended beyond the i.i.d. alternative assumption (\(H_1\): \(X_t \sim Q\)) to more realistic non‑stationary or gradual drift scenarios?  
*Basis:* Power analysis assumes \(X_t\) i.i.d. under the alternative (Equation 11). Experiments include a gradual drift (linear mean shift), but no theory covers non‑i.i.d. processes.  
*Why unresolved:* Real‑world streams often exhibit time‑varying distributions or autocorrelation; understanding behavior under these conditions is crucial.  
*Resolving evidence:* Formal definitions of broad classes of drifting alternatives (e.g., slowly varying, \(\beta\)-mixing); establishing martingale properties and deriving analogous power results under those assumptions; validation on time‑series datasets with complex dynamics.

## Limitations
- **Reference quality dependence:** Requires a large, i.i.d. null sample; small or unrepresentative \(D_0\) reduces power or inflates type‑I error.
- **Hyperparameter sensitivity:** Choices for \(\delta\), clipping threshold \(\tau\), and ONS step factor (4) are loosely justified and can affect validity and performance.
- **DKW conservatism:** Constant‑width confidence band may be overly cautious; data‑dependent bands could improve power but would require different theoretical analysis.
- **Warm‑up inconsistency:** The ImageNet‑C experiments use a warm‑up phase not clearly defined; synthetic replication omits it, potentially biasing comparisons.

## Confidence
- **Test‑time contamination:** Medium (supported by illustration and intuition; lacking formal proof).
- **Fixed reference avoids contamination:** High (by design; Theorem 3.1 guarantees).
- **Error‑corrected martingale & type‑I control:** High (Theorem 3.1).
- **Asymptotic power & detection delay:** High (Theorem 3.3).
- **Empirical superiority vs. standard CTM:** Medium (results depend on precise hyperparameters and baseline implementation details).
