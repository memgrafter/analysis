# Improving Coherence and Persistence in Agentic AI for System Optimization

## Quick Facts
- **arXiv ID:** 2603.21321  
- **Source URL:** https://arxiv.org/abs/2603.21321  
- **Reference count:** 40  
- **Primary result:** Engram avoids context degradation and evolutionary neighborhood bias, consistently outperforming evolutionary (OpenEvolve) and iterative (Glia) agentic baselines across nine system optimization tasks, exceeding human state‑of‑the‑art in eight of nine ADRS benchmark problems.

## Executive Summary
Engram introduces a multi‑agent framework for long‑horizon LLM‑based system optimization. By resetting the context between agents, distilling insights into a persistent Research Digest, and archiving detailed logs, it overcomes the coherence ceiling and evolutionary neighborhood bias that hinder single‑agent or pure evolutionary approaches. Across nine diverse optimization tasks, Engram achieves superior performance, including lower costs, reduced response times, and higher scores than both prior automated methods and human experts. The design enables cumulative progress, faster convergence, and robustness to non‑monotonic intermediate results.

## Method Summary
Engram orchestrates a sequence of LLM‑based agents, each operating in a fresh context window. At the end of an agent’s run, its findings are condensed into a structured Research Digest and all raw data (code, logs, results) are stored in a persistent Archive. The next agent begins by reading the Digest to build on prior insights while retaining access to archived details via on‑demand retrieval. This separation prevents context degradation, ensures high‑level knowledge transfer, and preserves exhaustive experimental traces without overloading the LLM’s context. Agents follow hypothesize‑implement‑experiment‑analyze cycles, concluding when further improvement stalls.

## Key Results
- Outperforms OpenEvolve and Glia on all nine system optimization tasks, demonstrating consistent gains.  
- Exceeds human state‑of‑the‑art in eight of nine ADRS problems (e.g., multi‑cloud multicast cost: $622 vs. $626).  
- Achieves superior results on LLM inference routing (23.9 s vs. 25.7 s) and KV cache reuse (0.721 score).  
- Reaches peak performance faster than OpenEvolve, indicating effective knowledge transfer.

## Why This Works (Mechanism)

### Mechanism 1 – Avoiding Context Degradation
- **Claim:** Engram avoids context degradation by resetting the LLM context between agents.  
- **How:** A new agent is instantiated with an empty context window; it reads the current Research Digest, explores, and upon concluding appends its summary to the Digest and archives all details.  
- **Evidence:** Abstract mentions “decoupling long‑horizon exploration from the constraints of a single context window”; Section 3.2 details the handoff process, including the fresh start and archiving.  
- **Break condition:** If the Research Digest fails to capture essential context, the fresh start may discard critical information, leading to repeated exploration of dead ends.

### Mechanism 2 – Long‑Horizon Cumulative Progress
- **Claim:** Engram enables long‑horizon cumulative progress by distilling high‑level insights from each agent into a compact Research Digest that subsequent agents read.  
- **How:** At handoff, the outgoing agent writes a structured summary of its approaches, key insights, ineffective strategies, and recommended next steps to the Digest. The incoming agent reviews this Digest to formulate its plan.  
- **Evidence:** Abstract: “distills high‑level modeling insights into a compact, persistent Research Digest”; Section 3.2: the Digest “serves as guidance for subsequent agents”.  
- **Break condition:** If the Digest becomes too long or loses nuance, later agents might misinterpret prior work or overlook essential insights.

### Mechanism 3 – Preserving Detailed Logs without Overloading Context
- **Claim:** Engram preserves all experimental details in a persistent Archive to enable backtracking, debugging, and detailed analysis without overloading the context.  
- **How:** At handoff, the agent stores code snapshots, execution logs, and results under a dedicated Archive directory. Agents can retrieve specific files on demand using tools, keeping the LLM context lean.  
- **Evidence:** Abstract: “stores code snapshots, logs, and results in a persistent Archive”; Section 3.2 describes archival; Figure 3 shows Archive structure.  
- **Break condition:** If the Archive grows large and lacks organization, retrieval may become inefficient, causing agents to waste time or miss critical information.

## Architecture Onboarding

### Component map
Agent -> Workspace (initial_program.py, task files) -> Tools (run_simulation, shell, read_file, write_file) -> Archive (/Archive/agent_*)
Agent -> Research Digest (/research_digest.md)
Handoff: current agent writes to Digest & Archive, then new agent is instantiated with empty context.

### Critical path
1. New agent starts, reads `/research_digest.md` and scans `/Archive/agent_*`.  
2. Formulates plan, implements changes in `new_algorithm.py`.  
3. Calls `run_simulation` to test code, receives score and logs.  
4. Analyzes results, decides to iterate or conclude.  
5. If concluding, appends summary to Research Digest and archives all files under `/Archive/agent_N/`.  
6. System terminates this agent and starts the next one (handoff).

### Design tradeoffs
- **Fresh context vs. persistent knowledge:** Resetting context avoids degradation but risks losing details; Digest and Archive mitigate.  
- **Compact Digest vs. detailed Archive:** Digest provides quick overview but may oversimplify; Archive provides depth but requires on‑demand access.  
- **Exploration flexibility vs. structure:** Agents have freedom to explore, but the handoff structure enforces disciplined knowledge transfer.  
- **Performance vs. resource usage:** Each agent consumes simulation budget; archiving all data uses storage but enables backtracking.

### Failure signatures
- Agent exhausts budget without improvement → poor exploration or getting stuck.  
- Digest entries become vague or repetitive → agent not generating meaningful insights.  
- Archive grows disorganized → retrieval becomes inefficient.  
- Next agent ignores or misreads Digest → knowledge transfer failure.  
- Single‑agent performance degrades over many iterations → context rot; timely handoff needed.

### First 3 experiments
1. **Reproduce baseline:** Run Engram on multi‑cloud multicast with the direction prompt and `o3` model (Section 4.1). Verify that best cost improves across handoffs and surpasses OpenEvolve.  
2. **Ablate Digest:** Run the Sequential variant (no Digest) from Section 5 on multiple tasks. Compare final performance and convergence speed against full Engram to quantify the Digest’s impact.  
3. **Inspect Archive:** After a full run, list contents of `/Archive/agent_1/` and `/Archive/agent_2/` to verify storage structure and that logs/code are properly archived.

## Limitations
- Digest‑centric knowledge transfer may lose critical details or become unwieldy over many agents, hindering cumulative progress.  
- Evaluation covers only nine tasks with no statistical testing or multi‑seed variance, limiting robustness and generalizability claims.  
- Resource overhead from multiple agent runs and persistent storage may reduce scalability to very long horizons.

## Confidence
- Performance claims (outperforming OpenEvolve/Glia, exceeding human SOTA, faster convergence): **Medium**  
- Mechanistic explanations (fresh context avoids rot, Digest enables long‑horizon progress, Archive preserves details): **Medium**

## Next Checks
1. Evaluate statistical robustness: Run each experiment with multiple random seeds to measure performance variance, addressing the limitation of no multi‑seed evaluation.  
2. Test generalizability: Apply Engram to a broader set of optimization tasks beyond the nine reported to determine if gains are consistent across diverse problems.  
3. Analyze Digest growth: Monitor the Research Digest size and content over many agents to detect potential information loss or verbosity issues, as suggested by the limitation on digest-centric transfer.
