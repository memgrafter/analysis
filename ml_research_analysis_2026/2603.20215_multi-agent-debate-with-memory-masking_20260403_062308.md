# Multi-Agent Debate with Memory Masking
## Quick Facts
- **ArXiv ID**: 2603.20215  
- **Source URL**: https://arxiv.org/abs/2603.20215  
- **Reference count**: 40  
- **Primary result**: MAD-M² filters erroneous memories each debate round, improving reasoning accuracy on math and MMLU-Pro benchmarks and reducing token consumption by ~30% with objective masking.

## Executive Summary
Multi-agent debate (MAD) enhances large language model (LLM) reasoning by having multiple agents iteratively discuss and refine answers, but it is vulnerable to erroneous memories that propagate across rounds. This paper introduces MAD with memory masking (MAD-M²), a framework that critically evaluates and masks incorrect memories at the start of each round, preserving only reliable ones. Two masking strategies are explored: subjective (agents self-evaluate memories as YES/NO/NOT SURE) and objective (select the memory with lowest perplexity). The authors provide theoretical analysis showing that reducing erroneous memories consistently boosts performance. Evaluations on GSM8K, MATH, AIME24/25, and MMLU-Pro using four LLMs demonstrate that MAD-M² outperforms standard MAD in most settings. Notably, with Qwen2.5-Math-7B, objective masking yields absolute gains of 2.8% on MMLU_Pro, 9.0% on MATH, and 6.6% on both AIME benchmarks, while cutting token usage by ~30%. The efficacy of masking strategy also depends on model scale: subjective masking benefits smaller models, while objective masking excels with larger ones.

## Method Summary
No explicit reproduction notes were provided; the core method is as follows. Standard Multi-Agent Debate (MAD) proceeds in rounds: each agent initially answers a query, and in subsequent rounds generates new responses conditioned on all previous responses (memories). MAD-M² inserts a masking step before each non-initial round. Memories are evaluated either subjectively (each agent judges each memory as YES/NO/NOT SURE) or objectively (the memory with lowest perplexity is selected). The evaluation produces either a binary mask (subjective) or a single retained memory (objective). Agents then generate new responses using only the filtered memories as context. After the final round, a majority vote determines the answer. The theoretical model assumes an agent’s probability of correct reasoning decays exponentially with the number of erroneous memories \(N_e\), leading to a bound where decreasing \(N_e\) strictly increases the overall correctness probability.

## Key Results
- MAD-M² surpasses standard MAD on GSM8K, MATH, AIME24/25, and MMLU-Pro across four LLMs.
- With Qwen2.5-Math-7B, objective masking (MAD-M²(O)) delivers absolute gains of 2.8% (MMLU_Pro), 9.0% (MATH), and 6.6% (both AIME benchmarks) while reducing token consumption by ~30% relative to MAD.
- Subjective masking (MAD-M²(S)) tends to benefit smaller models like Qwen2.5-7B, whereas objective masking is more effective for larger models such as Qwen2.5-Math-7B and QwQ-32B.

## Why This Works (Mechanism)
#### Mechanism 1: Filtering erroneous memories prevents error propagation
- **Claim**: Masking erroneous memories improves subsequent reasoning by ensuring agents base responses on more accurate contextual information.
- **Mechanism**: At the start of each round, memories (previous responses) are evaluated (subjectively via self-ratings or objectively via perplexity). A binary mask (subjective) or a single selection (objective) is applied to retain only reliable memories. Agents then generate new responses conditioned solely on the filtered set, breaking the chain of error propagation.
- **Core assumption**: The evaluation method can accurately distinguish correct from erroneous memories; success depends on the model’s self‑assessment ability or the correlation between perplexity and truth.
- **Evidence anchors**: Abstract: "...critically evaluates and masks incorrect memories..." ; Section 3.1: "a binary mask vector will be generated..." ; Corpus: neighboring MAD works do not address memory filtering.
- **Break condition**: Misclassification (e.g., poor self‑evaluation or weak perplexity–truth correlation) can degrade performance by removing useful information or retaining harmful content.

#### Mechanism 2: Theoretical guarantee that reducing erroneous memories raises success probability
- **Claim**: Theoretical analysis shows that lowering the number of erroneous memories \(N_e\) consistently increases the probability of correct final answers; simply adding more agents can be detrimental if \(N_e\) is large.
- **Mechanism**: Under Assumption 2.1, an agent’s success probability given memories decays as \(e^{-\alpha N_e}\). Proposition 2.3 bounds MAD’s overall correctness as a function of \(N_e\) and the initial round distribution; as \(N_e\) decreases, the upper bound approaches 1, guaranteeing improvement in both easy and hard problem settings.
- **Core assumption**: The exponential vulnerability model and independence of agent errors (binomial distribution) are valid simplifications.
- **Evidence anchors**: Section 2.2.1: "probability ... based on the previous memories is assumed to be e⁻αNe." ; Section 2.2.2: "reducing erroneous memories ... consistently improves the performance of MAD." ; Corpus: related theoretical work does not derive such bounds.
- **Break condition**: If agents are nearly error‑immune (\(\alpha \approx 0\)), improvement is negligible; correlated errors violate independence assumptions.

#### Mechanism 3: Model size dictates optimal masking strategy
- **Claim**: The choice between subjective and objective masking should align with the LLM’s capability: subjective masking helps smaller models, objective masking helps larger ones.
- **Mechanism**: Subjective masking uses the agent’s own judgment (YES/NO/NOT SURE) to keep memories, preserving semantic correctness but adding evaluation tokens. Objective masking selects the single memory with lowest perplexity, which reduces token consumption by ~30% but depends on perplexity’s faithfulness to truth. Empirically, weaker models (e.g., Qwen2.5–7B) perform better with subjective, while stronger models (Qwen2.5–Math–7B, QwQ–32B) gain more from objective.
- **Core assumption**: Self‑evaluation quality and perplexity–correctness correlation improve predictably with model scale.
- **Evidence anchors**: Section 4.2: "The efficacy of masking strategies is highly dependent on the intrinsic capability of LLMs." ; Table 1 shows MAD–M²(S) often better for Qwen2.5–7B, while MAD–M²(O) wins for larger models; token reduction noted for objective masking.
- **Break condition**: If small models are miscalibrated (overconfident on wrong answers), subjective masking backfires; if perplexity loses correlation with correctness in large models (e.g., due to over‑generation), objective masking fails.

## Architecture Onboarding
**Component map**: Input query -> initial agents (N) -> memory buffer; for each subsequent round (2 to R): (a) Evaluation: compute mask (subjective self-ratings or objective perplexity), (b) Mask generator: binary mask (subjective) or single-memory selection (objective), (c) Filter memories -> agents generate new responses; after final round: majority vote selects answer.

**Critical path**: Memory collection → evaluation/masking → next‑round debate (repeat) → final voting.

**Design tradeoffs**:
- Subjective vs. objective: subjective preserves semantic diversity but adds evaluation tokens (~30% increase); objective reduces tokens (~30% reduction) but relies on perplexity’s truthfulness.
- Granularity: keeping all “YES” memories vs. a single lowest-perplexity memory trades diversity for noise reduction.
- Round/agent count: more rounds/agents increase cost; masking aims to control cost while maintaining/improving performance.

**Failure signatures**:
- Empty filtered set (subjective: all NO) → agents lose context, random reasoning.
- Persistent inclusion of wrong memories (perplexity fails) → error propagation continues.
- Over‑filtering to a single memory → loss of diversity, potentially missing correct solutions.
- Token explosion in subjective mode: evaluation turns roughly double per round.

**First 3 experiments**:
1. Mask sanity check: handcrafted memory set (half correct, half wrong) verify subjective yields mask retaining mostly correct memories, objective selects lowest perplexity memory (often correct).
2. End‑to‑end smoke test: run MAD-M²(S) with 2 agents, 2 rounds on 5 GSM8K examples; compare accuracy and token usage against MAD; expect similar/higher accuracy, higher tokens for subjective.
3. Replication of Table 1 trend: on Qwen2.5‑7B and GSM8K, reproduce that MAD-M²(S) outperforms MAD-M²(O) in both accuracy and token consumption.

## Open Questions the Paper Calls Out
1. Does the exponential decay assumption (Assumption 2.1) hold universally across LLM architectures and tasks? The theoretical model assumes the probability of correct reasoning decays as \(e^{-\alpha N_e}\) with erroneous memories, but this lacks empirical validation across models and difficulties.
2. Could continuous memory weighting (e.g., confidence scores) outperform binary or single‑memory masking? MAD-M² uses binary masks (subjective) or top‑1 perplexity selection; graded retention might better balance noise removal and information preservation.
3. What causes observed performance degradation with many debate rounds for strong models (e.g., DeepSeek-Math-7B) and how can MAD design mitigate it? Accuracy drops after ~4 rounds on AIME; the cause (over‑masking, prompt length, suboptimal equilibria) is unknown.
4. How well do MAD-M²’s findings generalize beyond math and MMLU-Pro to other domains? Evaluations are limited to GSM8K, MATH, AIME24/25, MMLU‑Pro; error characteristics differ in other tasks.
5. How reliable are LLM agents’ self‑evaluations of memory correctness compared to ground truth? Subjective masking relies on agents labeling memories; miscalibration could harm performance.

## Limitations
- Masking reliability is unverified: self‑evaluation is often miscalibrated, and perplexity’s correlation with truth may not hold across tasks.
- Theoretical assumptions (independent agent errors, exponential decay of success probability) likely oversimplify real MAD dynamics with correlated failures.
- Experiments cover only four LLMs and math‑oriented benchmarks; generalization to other domains and model families remains unclear.

## Confidence
- MAD-M² improves accuracy over standard MAD: Medium  
- Model‑size dependent masking superiority (subjective for small, objective for large): Low  
- Theoretical bounds guarantee improvement from reducing erroneous memories: Medium
