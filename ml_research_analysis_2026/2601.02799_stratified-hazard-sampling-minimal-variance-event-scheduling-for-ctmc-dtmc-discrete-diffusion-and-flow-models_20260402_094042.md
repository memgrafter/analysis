# Stratified Hazard Sampling: Minimal-Variance Event Scheduling for CTMC/DTMC Discrete Diffusion and Flow Models

## Quick Facts
- arXiv ID: 2601.02799
- Source URL: https://arxiv.org/abs/2601.02799
- Reference count: 17
- Primary result: Replaces independent Bernoulli decisions per step with a single random phase per position, achieving minimal conditional variance (≤1/4) in edit counts and lowering generative perplexity by up to 17.3% in low-step regimes while preserving multimodality.

## Executive Summary
Uniform-noise discrete diffusion and flow models suffer from high variance in per-position edit counts due to independent Bernoulli draws at each step, leading to under-editing (residual noise) and over-editing (cascading substitutions). Stratified Hazard Sampling (SHS) solves this by assigning each position a uniform random phase once at the start; edits occur when cumulative hazard crosses unit-spaced thresholds tied to that phase. This coupling minimizes conditional variance among unbiased integer estimators while preserving expected edits and multimodality. Experiments on UDLM, GIDD, and a 3B uniform diffusion model show consistent perplexity reductions and greater robustness under lexical constraints.

## Method Summary
SHS is a training-free, hyperparameter-free inference adjustment. For each token position i, draw θ_i ∼ Uniform(0,1) initially. Over NFE reverse steps (t_k = k/NFE), compute per-step change mass p_{i,k} and destination distribution q_{k,i} from the model. Maintain cumulative hazard S_i and jump count m_i. At each step, update S_i ← S_i + p_{i,k}. If S_i ≥ θ_i + m_i, sample a new token from q_{k,i} and increment m_i. The destination distribution may be renormalized for lexical filtering, but p_{i,k} remains unchanged. This replaces the standard per-step independent Bernoulli tosses with a deterministic threshold-crossing mechanism that exactly matches the expected number of edits (∑_k p_{i,k}) but collapses the distribution of total jumps J_i to a shifted Bernoulli with conditional variance ≤1/4.

## Key Results
- Reduced generative perplexity by up to 17.3% in low-step regimes (e.g., UDLM NFE=4) compared to standard Bernoulli sampling.
- Under lexical blacklists of increasing severity, SHS degrades more gradually, indicating greater robustness.
- Achieved minimal conditional variance (≤ 1/4) for per-position edit counts, eliminating the heavy-tailed no-edit distribution of standard samplers.

## Why This Works (Mechanism)
The variance of the sum of independent Bernoulli variables (Poisson-binomial) grows with the number of steps, causing unpredictable edit counts. SHS couples all steps via a single uniform random phase θ_i, making the edit count J_i = ⌊S_i + θ_i⌋, where S_i = ∑_k p_{i,k} is deterministic given the trajectory. The integer rounding of a uniform shift has variance at most 1/4, regardless of NFE. Because thresholds are unit-spaced, E[J_i] = S_i exactly, so the expected number of edits is preserved. The random phases differ across positions, preserving multimodality: jumps occur at step-specific deterministic thresholds, allowing diverse patterns. The mechanism neither alters destination sampling nor introduces bias, so the marginal token distribution remains unchanged while sample trajectory variance collapses.

## Foundational Learning
- **Discrete diffusion/flow models**: Stochastic processes that iteratively corrupt and denoise sequences; inference requires predicting per-token change probabilities p and destination distributions q.
- **CTMC/DTMC event scheduling**: Modeling edits as jumps in continuous or discrete time; the hazard (intensity) governs when jumps occur.
- **Variance reduction via common random numbers**: Using a single random variable (θ_i) across multiple decisions to reduce variability of a sum (common in Monte Carlo).
- **Minimal variance rounding**: For any real number S, the distribution of ⌊S+U⌋ with U∼Uniform(0,1) has conditional variance ≤1/4 and is unbiased.
- **Multimodality in sampling**: Diversity of generated sequences; preserved in SHS because destination choices remain independent of timing.
- **Lexical constraints**: Hard restrictions on allowed tokens; implemented by masking q and renormalizing while keeping p unchanged (destination-only filtering).

## Architecture Onboarding
SHS is an inference-time wrapper around a discrete diffusion/flow model. The data flow is:

Model forward (per step k) → compute p_{i,k}, q_{k,i} for each i → update S_i ← S_i + p_{i,k} → compare S_i with θ_i + m_i → if exceeded: sample token from q_{k,i}, m_i++ → proceed to next step.

Design tradeoffs: minimal compute overhead (one uniform draw per position, a few adds/comparisons). Requires p_{i,k} ≤ 1; if violated, clip or increase NFE. Does not modify model weights or training.

Failure signatures:
- High edit-count variance persists → θ_i re-sampled each step (should be fixed per position).
- Expected edit count deviates → off-by-one in threshold check (must increment m_i inside conditional).
- p_{i,k} > 1 uncorrected → multiple thresholds crossed at once, breaking variance guarantee.

First three onboarding experiments:
1. Constant-p simulation: fix p=0.6, NFE=2; compute Var(J) and compare to theoretical ≤0.25.
2. Jump time uniformity: for random θ, S_i values after constant p steps, verify S_i at jumps spreads uniformly over (θ, θ+1).
3. Marginal parity: generate many samples from SHS and standard; compute per-token frequency TVD; should be near zero.

## Open Questions the Paper Calls Out
- Will SHS provide similar gains for code generation tasks and discrete flow matching models, which have different dynamics from diffusion?
- How do state-dependent p_{i,k}(x) (where the state x evolves) affect the variance bound? The analysis assumes fixed masses.
- Can SHS be combined with exact conditional samplers (e.g., Doob h-transform) to enforce hard constraints while maintaining low variance?
- Does tightening edit-count distribution inadvertently reduce output diversity (e.g., distinct-n) despite similar token entropy?

## Limitations
- Exact pretrained checkpoints for UDLM, GIDD, and the 3B model are not provided, complicating replication.
- Theoretical results assume p_{i,k} are fixed; in practice they depend on the stochastic state trajectory, potentially weakening guarantees.
- Blacklist experiments use destination-only filtering, not exact conditioning, so robustness may not hold for stricter constraint schemes.

## Confidence
- Theoretical minimal variance guarantee (≤1/4): **High**
- Empirical perplexity improvements on reported models: **Medium** (depends on correct checkpoint access)
- Robustness under lexical blacklists: **Low-Medium** (filtering protocol details not fully specified)
