# Any-Subgroup Equivariant Networks via Symmetry Breaking

## Quick Facts
- **ArXiv ID**: 2603.19486  
- **Source URL**: https://arxiv.org/abs/2603.19486  
- **Reference count**: 40  
- **Primary result**: ASEN equips a single model with equivariance to multiple permutation subgroups via symmetry-breaking inputs and 2‑closure approximation, achieving competitive results on pose estimation, traffic prediction, and image classification, and showing improved sample efficiency in synthetic sequence tasks.

## Executive Summary
Equivariant neural networks are typically rigidly tied to a single symmetry group, limiting their flexibility across tasks. Any‑Subgroup Equivariant Networks (ASEN) address this by starting from a base model that is equivariant to a large permutation group and then breaking symmetry to a desired subgroup using an auxiliary input whose automorphism group equals that subgroup. Exact symmetry breaking is NP‑hard; ASEN approximates the subgroup efficiently via the 2‑closure, yielding a polynomial‑time algorithm to construct edge features. Theoretically, ASEN attains exact equivariance under mild conditions and inherits universality from the base model. Empirically, a single ASEN backbone matches or exceeds specialized baselines on Human3.6M pose estimation, METR‑LA traffic prediction, and Pathfinder64 classification, while multitask training on synthetic tasks further improves low‑data performance. This framework opens the door to adaptable equivariant models that can be tailored to diverse symmetries without retraining from scratch.

## Method Summary
ASEN augments a fully permutation‑equivariant base model (e.g., a graph neural network) with a symmetry‑breaking input tensor \(v\) that encodes the desired subgroup \(G'\) via \(\text{Aut}(v) = G'\). The composite function \(f_\theta(x) = h_\theta(x, v)\) inherits \(G'\)‑equivariance from the base model \(h_\theta\) because \(v\) itself is invariant under \(G'\) and not under larger permutations. To avoid the NP‑hard problem of constructing \(v\) exactly, ASEN uses the 2‑closure \(G'(2)\) of the target subgroup; edge features are derived from the orbits of the group acting on node pairs, and the resulting hypergraph satisfies \(\text{Aut}(H) = G'(2)\). For many common groups (cyclic, nilpotent, totally 2‑closed), \(G'(2) = G'\). The algorithm computes these edge orbits efficiently from the generators of \(G'\) (Algorithm 1). ASEN’s architecture includes: an optional TokenEmbedder for discrete node features; a precomputation step that produces EdgeEmbedder outputs (edge indices and feature embeddings); a backbone of permutation‑equivariant GNN layers (e.g., GATv2) that inject edge information into messages; and task‑specific output layers. The framework is universal if the base model is universal for \(G\)‑equivariant functions, and it can simulate order‑1 \(G\)‑MLPs using \(K=2\) hypergraph features.

## Key Results
- A single ASEN backbone reaches **40.67 P‑MPJPE** on Human3.6M pose estimation, beating the prior S6_2 baseline (47.54), and **2.69 MAE** on METR‑LA traffic prediction; on Pathfinder64 it achieves **0.827 test accuracy** with patch‑wise symmetry.  
- On synthetic permutation‑subgroup tasks (Intersect, Palindrome, etc.), ASEN with the correct symmetry converges faster and attains lower loss than non‑equivariant baselines; multitask training further boosts performance in low‑data regimes.

## Why This Works (Mechanism)

### Mechanism 1: Symmetry Breaking via Auxiliary Input
The base model \(h_\theta\) is equivariant to a large group \(G\): \(h_\theta(gx, gv) = g\,h_\theta(x,v)\) for all \(g\in G\). By choosing a symmetry‑breaking input \(v\) such that \(\text{Aut}(v)=G'\), we have \(gv=v\) for \(g\in G'\), so \(f_\theta(x)=h_\theta(x,v)\) becomes \(G'\)‑equivariant: \(f_\theta(gx)=h_\theta(gx,v)=h_\theta(gx,gv)=g\,h_\theta(x,v)=g f_\theta(x)\). For \(g\notin G'\), typically \(gv\neq v\); if \(h_\theta\) is sufficiently injective in \(v\), the extra symmetries are truly broken. This construction requires only a fixed \(v\) (not one per input), enabling flexible subgroup selection.

### Mechanism 2: Practical Symmetry Breaking via 2‑Closure
Exact construction of \(v\) with \(\text{Aut}(v)=G'\) is NP‑hard. ASEN circumvents this by using the **2‑closure** \(G'(2)\), the smallest group containing \(G'\) that acts identically on all node pairs. We build a hypergraph \(H\) with positional and 2‑edge features; for each unordered pair \((i,j)\), we assign a feature constant on the \(G'\)‑orbit of \((i,j)\). Then \(\text{Aut}(H)=G'(2)\). For groups that are *totally 2‑closed* (includes many natural subgroups), \(G'(2)=G'\). Computing the orbits is efficient: Algorithm 1 lifts the generators of \(G'\) to act on \(\binom{[n]}{2}\) and computes the orbits of edges, yielding the edge feature matrix \(A^{(2)}\). The resulting edge features, when fed to an injective MPNN, yield a model equivariant exactly to \(G'(2)\).

### Mechanism 3: Universality and Expressivity
If the base model is universal for \(G\)‑equivariant functions, ASEN inherits this property. More concretely, an order‑1 \(G\)‑equivariant MLP (linear layer with weight‑sharing defined by \(G\)‑orbits) can be simulated by an ASEN with \(K=2\) and an MPNN backbone by encoding each orbit as a distinct edge feature and using message‑passing to aggregate neighbor information. Higher‑order equivariant MLPs may require larger \(K\) (hypergraph order), suggesting a hierarchy of expressivity analogous to increasing \(K\).

## Foundational Learning

- **Equivariance**  
  *Why needed*: ASEN builds on permutation‑equivariant base layers; understanding how group actions propagate through the network is essential for designing symmetry‑breaking and proving theoretical guarantees.  
  *Quick check*: If \(f\) is \(G\)‑equivariant and \(g\in G\), what is the relationship between \(f(gx)\) and \(g f(x)\)?

- **Automorphism Groups of Relational Structures**  
  *Why needed*: The symmetry‑breaking input \(v\) is chosen so that its automorphism group exactly matches the desired subgroup \(G'\). For graphs/hypergraphs, this involves computing groups from edge features.  
  *Quick check*: For a graph with adjacency matrix \(A\), what does \(\text{Aut}(A)\) represent in terms of node permutations?

- **Closure Operations (2‑closure) and Group Approximation**  
  *Why needed*: Exact computation of \(\text{Aut}(v)=G'\) is infeasible; the 2‑closure provides a polynomial‑time proxy that often coincides with \(G'\) for common groups.  
  *Quick check*: If \(G \le S^n\), what does \(G^{(2)}\) contain in addition to \(G\)? When does \(G^{(2)} = G\)?

## Architecture Onboarding

**Component map**  
Input (node features \(X\), optional adjacency \(A\)) → TokenEmbedder → initial node embeddings → EdgeEmbedder (precomputed edge indices and edge features) → Backbone (GNN layers, e.g., GATv2) → Output projection/aggregation → task output.

**Critical path**  
1. *Precomputation*: Given generators of the target subgroup \(G'\), run Algorithm 1 to compute the edge orbit matrix \(A^{(2)}\). This defines edge features such that \(\text{Aut}(A^{(2)}) = G'(2)\).  
2. *Training*: TokenEmbedder maps node features to embeddings. These are processed by the GNN backbone, which uses the precomputed edge indices and features to pass messages while preserving the permutation symmetry determined by the edge orbits.  
3. *Inference*: Final node representations are pooled or projected to produce predictions.

**Design tradeoffs**  
- *K (hypergraph order)*: Higher \(K\) captures more expressive symmetries but increases computational and memory costs.  
- *Sparse vs. fully‑connected*: Sparse edges respect domain structure (e.g., skeleton edges) and reduce \(O(n^2)\) overhead, but may miss some orbits; fully‑connected edges capture all pairs at higher cost.  
- *Exact vs. approximate symmetry*: Using the 2‑closure yields efficient construction but risks over‑approximating the subgroup (\(G'(2) > G'\)), introducing unwanted invariances.

**Failure signatures**  
- *Over‑constrained symmetry*: Model becomes equivariant to a supergroup \(G'(2) \supset G'\), leading to underfitting on tasks that break the extra symmetries.  
- *Insufficient injectivity*: Non‑injective components (e.g., ReLU) in the MPNN may fail to distinguish different symmetry‑breaking inputs, leaving residual symmetries.  
- *Trivial group mis‑implementation*: When aiming for \(\text{Aut}(v)=I\), using too few distinct edge features leaves nontrivial automorphisms.

**First 3 experiments**  
1. *Human Pose Estimation*: Varied edge feature sparsity and symmetry groups (\(S_2\), \(S_2^2\), \(S_6^2\)) on Human3.6M; weakly‑sparse edges gave the best P‑MPJPE (40.67).  
2. *Traffic Prediction*: On METR‑LA, positional features with coarser sensor groupings (two‑cluster \(S^{n_1}\times S^{n_2}\)) outperformed finer (nine‑cluster) and full permutation, achieving 2.69 MAE.  
3. *Pathfinder Classification*: Applied 2D positional encodings with patch‑wise permutation symmetry (\((S_4)^{1024}\), \((S_9)^{455}\)); local symmetry improved test accuracy to 0.827.

## Open Questions the Paper Calls Out

**Open Question 1 – Incorporating Local Symmetries**  
*Question*: How can ASEN be extended to incorporate local symmetries, such as those found in molecular graphs where atom environments define local rigid motions?  
*Basis*: Explicitly mentioned in the conclusion.  
*Why unresolved*: The current framework only handles global permutation subgroups via hypergraph features; local symmetries involve stabilizers of subgraphs and require different symmetry‑breaking constructions.  
*Resolution evidence*: A theoretical characterization of local symmetry‑breaking inputs (e.g., via local hypergraph patterns) and validation on molecular property benchmarks.

**Open Question 2 – Effects of Symmetry Model Misspecification**  
*Question*: What is the impact when the chosen 2‑closure group \(G'(2)\) strictly contains the target subgroup \(G'\), and how can we mitigate it?  
*Basis*: Explicitly noted as a key avenue; Appendix C.5 shows a failure case for the sign‑invariant task where \(A_n^{(2)} = S_n\).  
*Why unresolved*: Only one negative example is provided; no systematic analysis across group families or adaptive algorithms to detect/correct mismatches.  
*Resolution evidence*: Experimental characterization of approximation error for various group families (e.g., alternating vs. symmetric) and methods to learn correct orbit structure from data or dynamically adjust symmetry‑breaking input.

**Open Question 3 – Relation Between MLP Order and Hypergraph Order K**  
*Question*: What is the relationship between the order of equivariant MLPs and the hypergraph order \(K\) in ASEN regarding expressive power?  
*Basis*: Inferred; Theorem 1 shows order‑1 \(G\)-MLPs are simulable with \(K=2\), but the paper speculates that increasing \(K\) may correspond to higher‑order MLPs.  
*Why unresolved*: No theoretical or empirical comparison exists beyond order 1 and \(K=2\).  
*Resolution evidence*: Proof that ASEN with \(K\) can approximate order‑\(k\) \(G\)-MLPs (or vice versa) and experiments comparing learning efficiency on tasks requiring higher‑order interactions.

**Open Question 4 – Multitask Training and Symmetry Group Similarity**  
*Question*: Under what conditions does multitask training with ASEN yield improved generalization, and how does task similarity in terms of symmetry group structures affect transfer?  
*Basis*: Inferred; Figure 6 shows multitask training benefits Intersect but not Cyclicsum/Palindrome, yet no analysis explains the discrepancy.  
*Why unresolved*: Interplay between symmetry group compatibility and knowledge sharing is not studied; metrics based on group inclusions or orbit structures are absent.  
*Resolution evidence*: Controlled multitask experiments varying subgroup relationships (nested, overlapping, disjoint) and measurement of transfer gains; theoretical bounds relating group distances to representation similarity.

## Limitations
- The 2‑closure approximation may over‑approximate the target subgroup for groups that are not totally 2‑closed (e.g., alternating groups), introducing unintended symmetries.  
- Precomputation of edge orbits via Algorithm 1 scales quadratically with the number of nodes, limiting applicability to large graphs.  
- Theoretical guarantees rely on the base model being sufficiently injective; common GNN activations like ReLU often violate strict injectivity, risking residual symmetries.

## Next Checks
1. **Non‑2‑closed subgroup test**: Evaluate ASEN on tasks where the desired subgroup (e.g., \(A_5\)) is not totally 2‑closed. Compare performance against exact symmetry breaking (via brute‑force for small \(n\)) to quantify over‑approximation effects.  
2. **Injectivity probe**: For a small graph, design distinct symmetry‑breaking inputs \(v_1, v_2\) with \(\text{Aut}(v_1)=\text{Aut}(v_2)=G'\). Measure distances between intermediate node/edge representations across GNN layers; significant divergence indicates sufficient injectivity, while near‑identical outputs suggest a failure to break extra symmetries.  
3. **Scalability benchmark**: Implement Algorithm 1 and record runtime and memory usage for increasing node counts (e.g., \(n=50,100,200,500,1000\)) on randomly generated permutation groups. Identify the practical size limit and evaluate whether optimizations (e.g., sparse edge handling) are necessary.
