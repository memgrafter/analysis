# Efficient Benchmarking of AI Agents

## Quick Facts
- arXiv ID: 2603.23749
- Source URL: https://arxiv.org/abs/2603.23749
- Reference count: 32
- Primary result: Mid-Range Difficulty Filter reduces AI agent benchmark tasks by 44-70% while maintaining rank fidelity (mean ρ=0.94, worst-case 0.87)

## Executive Summary
Evaluating AI agents on comprehensive benchmarks is costly due to interactive tool-use rollouts, and agent performance depends on the scaffold (harness), causing distribution shift. This paper reveals an asymmetry: rank-order prediction (Spearman ρ) stays robust (0.86-0.92) across scaffold and temporal shifts, while absolute score prediction (R²) collapses (0.50-0.65). Leveraging this, the authors propose the Mid-Range Difficulty Filter: a simple, optimization-free rule that selects tasks with historical pass rates between 30-70%. Motivated by Item Response Theory, this band captures tasks with maximal discriminative power. In a large-scale study across eight benchmarks, 33 agent scaffolds, and 70+ model configurations, the filter reduces the number of tasks by 44-70% while maintaining high rank fidelity (mean ρ=0.94, worst-case 0.87). It consistently outperforms random sampling, greedy forward selection, stratified sampling, and extreme-difficulty baselines under proper nested cross-validation and five shift protocols.

## Method Summary
The Mid-Range Difficulty Filter selects tasks with historical pass rates between 30-70% based on Item Response Theory's Fisher information principle. The method uses nested cross-validation where task selection occurs inside the outer CV loop to avoid data leakage. For each fold, pass rates are computed on training agents only, and the MR filter is applied to obtain a task subset. Performance is evaluated using Spearman rank correlation (primary) and R² (secondary) across five shift protocols: leave-one-agent-out, leave-one-scaffold-out, random splits, leave-one-subset-out, and temporal expanding windows. Ridge regression (α=1.0) is optionally used for score calibration when absolute predictions are needed.

## Key Results
- MR filter reduces tasks by 44-70% while maintaining mean rank fidelity ρ=0.94 (worst-case 0.87)
- Rank-order prediction (ρ) stays robust (0.86-0.92) across scaffold and temporal shifts, while absolute score prediction (R²) collapses (0.50-0.65)
- MR consistently outperforms random sampling, greedy forward selection, stratified sampling, and extreme-difficulty baselines
- Filter requires 5-10 initial full-benchmark evaluations for cold-start, then enables reduced testing

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Agent benchmark rankings are preserved under scaffold and temporal shifts while absolute scores degrade, enabling reduced-task evaluation.
- **Mechanism**: The composed transformation from subset selection to full-benchmark scoring under new scaffolds remains approximately monotone (α > 0 in affine approximation) even when scale calibration fails. This is because scaffold engineering has practical limits: it is difficult to design a harness that reverses ordering imposed by underlying capability differences for sufficiently challenging tasks.
- **Core assumption**: Agent capabilities differing substantially in absolute terms will maintain their relative ordering across diverse scaffolds unless the scaffold effect size rivals the capability gap.
- **Evidence anchors**:
  - [abstract] "rank-order prediction (Spearman ρ) stays robust (0.86-0.92) across scaffold and temporal shifts, while absolute score prediction (R²) collapses (0.50-0.65)"
  - [section 4.1] Table 3 shows ρ stable at 0.90–0.96 across protocols while R² falls from 0.90 to 0.50; LOSO gives ρ=0.87, R²=0.50.
- **Break condition**: A new scaffold type that systematically reverses ordering for a large fraction of agent pairs would violate approximate monotonicity and cause ρ to drop.

### Mechanism 2
- **Claim**: Filtering tasks to historical pass rates 30–70% (mid-range) retains maximal discriminative power under Item Response Theory, yielding high-fidelity rankings with 44–70% fewer tasks.
- **Mechanism**: Under a Bernoulli IRT model with logistic link, Fisher information I(θ) = p(1-p) is maximized at p=0.5. Tasks near 50% pass rate thus carry the most information about latent agent ability. Including only these tasks minimizes the residual ε in the subset-to-full mapping while excluding low-information ceiling/floor tasks that add noise.
- **Core assumption**: The latent ability ordering that governs performance on mid-range tasks is similar to that governing the full benchmark.
- **Evidence anchors**:
  - [abstract] "Motivated by Item Response Theory, this band captures tasks with maximal discriminative power."
  - [section 3.3] Explicit derivation: "I(θ) = p(1-p). This quantity is maximized at p=0.5."
  - [section 4.2] Figure 2 shows MR achieves mean ρ=0.94 with worst-case 0.87, outperforming other baselines in robustness.
- **Break condition**: A benchmark where the mid-range tasks are qualitatively different than the harder/easier tasks that define the full benchmark's ordering will yield spurious orderings.

### Mechanism 3
- **Claim**: The MR filter's robustness stems from excluding hard/easy tasks, not from selecting a particular subset; it outperforms greedy and random because it avoids overfitting to the specific agent population used for selection.
- **Mechanism**: Greedy forward selection maximizes within-population R² on the training set, which overfits to noise and specific scaffold-model interactions. Random sampling has high variance because it includes hard tasks (noise) and ceiling tasks (uninformative). MR deterministically excludes these regimes regardless of agent sample, making selection independent of the specific historical agent population.
- **Core assumption**: The set of agents used to compute historical pass rates is sufficiently diverse that the pass-rate ordering of tasks is stable across time/scaffolds.
- **Evidence anchors**:
  - [section 4.2] "Both MR and Easiest-k succeed because they drop the hardest tasks, which contribute noise rather than signal." "Greedy-k systematically overfits and thus has less reliable performance under temporal and scaffold shift."
  - [section 4.2] Table 4: Greedy worst-case ρ=0.56 vs MR worst-case ρ=0.87 across benchmarks; Random worst-case ρ = -0.19.
- **Break condition**: If the task difficulty distribution shifts dramatically (e.g., due to a new agent class that solves previously hard tasks easily), the MR band computed from historical data may now contain mostly easy tasks for the new population, losing discriminative power.

## Foundational Learning

**Concept: Rank vs. Score Prediction**
- **Why needed here**: The paper's core insight is that rankings survive distribution shift when scores do not. Implementers must understand that preserving order (monotonicity) is easier than predicting calibrated values (affine transformation), which informs why reduction is possible.
- **Quick check question**: If subset scores correlate ρ=0.95 with full scores, but the Ridge-predicted R²=0.5, what does this imply about the relationship between the two scales?

**Concept: Item Response Theory (IRT) Fisher Information**
- **Why needed here**: The 30–70% rule derives from p(1-p) maximizing at p=0.5. Understanding this helps adapt the band if needed (e.g., to 15–85% where information is >50% of maximum).
- **Quick check question**: For a task with historical pass rate 0.2, what is the relative Fisher information compared to the maximum? (Compute p(1-p)/0.25.)

**Concept: Nested Cross-Validation for Task Selection**
- **Why needed here**: Proper evaluation must avoid leakage: task selection must occur inside the CV loop, using only training agents' data. Skipping this inflates performance estimates and invalidates conclusions about robustness.
- **Quick check question**: In leave-one-agent-out (LOAO), when selecting tasks for the test fold, on which agents' performance data should the pass rates be computed?

## Architecture Onboarding

**Component map**:
1. Performance matrix X: n×m binary/fractional success data (agents × tasks)
2. Task selection module: Given historical X_train, computes pass rates and applies filter (MR) or optimization (Greedy-k)
3. Score prediction module: For MR/A.3: optionally trains Ridge regression (α=1.0) to predict full-benchmark scores from subset scores
4. Evaluation harness: Runs nested CV loops (LOAO, LOSO, temporal, random splits) and computes ρ, τ, R² on held-out agents
5. Protocol manager: Orchestrates five shift protocols and aggregates results

**Critical path**:
1. Load per-task, per-agent outcome data (CSV format recommended in Section 5.2)
2. For each CV fold:
   a. Split agents into train/test (never use test agent data for selection)
   b. On training agents: compute task pass rates → apply selection strategy to obtain task subset S
   c. Fit Ridge (if score prediction needed) on train agents' subset scores → predict for test agent
   d. Compare predictions (or raw means for rank) against true full-benchmark scores on test agent
3. Aggregate ρ, τ, R² across folds to evaluate strategy
4. For MR deployment: compute historical pass rates once, fix S, run new agents on S only, report Ridge-predicted scores if absolute numbers needed.

**Design tradeoffs**:
- **Fixed MR filter vs. adaptive threshold**: Paper uses fixed 30–70%. Tradeoff: simplicity and reproducibility vs. potential suboptimality for benchmarks with unusual difficulty distributions. Adaptive (e.g., to achieve k=~50% tasks) would require tuning on historical data and might overfit.
- **Ridge calibration vs. raw means**: MR uses raw mean for ranking (sufficient), but Ridge helps if absolute scores are required. Ridge introduces a hyperparameter (α=1.0 predetermined) and training variance.
- **Single historical pool vs. rolling window**: For temporal shift, they use expanding window. A rolling window (e.g., last 20 agents) might better track recent scaffold trends but loses data early.

**Failure signatures**:
- **Hot failure**: MR subset yields ρ < 0.75 on a full-benchmark validation run. Trigger: full-benchmark run on 5–10 new agents every few months to monitor.
- **Cold failure**: Fewer than 10% of tasks fall in 30–70% band (e.g., SciCode: only 4/65). Signal: histogram of task pass rates heavily skewed. Remedy: widen to 25–75% or 15–85% (Section 5.1 Phase 1).
- **Concept drift**: Sudden jump in pass rates across many tasks (e.g., due to capability leap) causes MR-selected tasks to become too easy (ceiling effects). Detection: monitor mean pass rate of selected tasks; rapid increase >20% suggests reselection.

**First 3 experiments**:
1. **Replicate ρ–R² divergence on your benchmark**: Using existing full-benchmark data, run LOAO and LOSO protocols. Compute ρ and R² for full-benchmark prediction using all tasks (should be 1.0 by construction for in-distribution, but R² will be 1.0 only if you use same tasks for selection and prediction—need to use proper CV). Aim to confirm that ranking stability exceeds score calibration under scaffold shift.
2. **Test MR filter sensitivity on your benchmark**: Apply MR with bands [10-90], [20-80], [30-70], [40-60]. Plot ρ vs. task reduction (like Figure 5). Check if your benchmark's difficulty distribution supports a mid-range band with >10% tasks. If not, note that MR may be unsuitable.
3. **Compare MR versus greedy on temporal split**: Hold out the most recent 20% of agents by submission date. Compute ρ for MR and greedy (with k matched to MR's size). Greedy should show larger drop, demonstrating overfitting to historical population.

## Open Questions the Paper Calls Out

### Open Question 1
- Question: What is the theoretically optimal mid-range difficulty band for task selection that balances rank fidelity and cost reduction, beyond the heuristic 30–70% band?
- Basis in paper: [explicit] The authors state: "The 30–70% difficulty band is a practical heuristic motivated by item response theory and cost reduction targets, rather than a theoretically unique or optimal choice."
- Why unresolved: The paper uses a fixed band without deriving an optimal value that accounts for varying benchmark difficulty distributions, evaluation protocols, or the rank-fidelity vs. reduction trade-off.
- What evidence would resolve it: Systematic empirical exploration across a wider range of bands; formal optimization from IRT incorporating item discrimination; or a theoretical analysis that yields an optimal band as a function of benchmark statistics.

### Open Question 2
- Question: What mechanisms underlie the empirical stability of rank predictions under scaffold-induced distribution shift, and can we predict when rankings are likely to invert?
- Basis in paper: [explicit] In Appendix A.1, the authors note: "These explanations are not mutually exclusive, and our data do not distinguish between them." They propose two factors (limits of scaffold engineering and dilution of co-optimized scaffolds) but lack data to isolate them.
- Why unresolved: The paper demonstrates the phenomenon but does not identify causal drivers or conditions under which rank stability breaks down.
- What evidence would resolve it: Controlled experiments holding model constant while varying scaffold designs; measuring scaffold-model interaction effects; or collecting fine-grained data on scaffold engineering choices to model their impact as covariates in a mixed-effects framework.

### Open Question 3
- Question: For benchmarks with highly skewed difficulty distributions (e.g., SciCode) where few tasks fall in the mid-range band, what alternative task selection strategies can achieve reliable rank prediction?
- Basis in paper: [explicit] The authors state: "MR requires a populated mid-range difficulty band to function properly."
- Why unresolved: MR fails on SciCode; the paper does not explore robust alternatives for such cases, beyond perhaps widening the band or using other strategies like stratified sampling.
- What evidence would resolve it: Empirical evaluation of alternative strategies (e.g., wider bands, information-theoretic selection using IRT item parameters, or clustering tasks by difficulty) on benchmarks with skewed distributions; development of a diagnostic to identify benchmarks where MR is unsuitable.

## Limitations

- Data Scope and Generalizability: The study is based on eight specific benchmarks and 70+ agent configurations, limiting generalizability to domains with different difficulty distributions.
- Temporal Stability of Pass Rates: The MR filter depends on historical pass rates being stable predictors of task difficulty over time, which may not hold under capability discontinuities.
- Distribution Shift Mechanisms: The paper doesn't fully characterize which scaffold engineering patterns would reverse agent orderings, leaving the monotonicity assumption's limits unclear.

## Confidence

- Mechanism 1 (Rank preservation): High confidence - extensively validated across multiple benchmarks and protocols with consistent ρ–R² divergence patterns.
- Mechanism 2 (IRT justification): Medium confidence - theoretically sound derivation but relies on untested assumption that mid-range tasks share the same latent ability construct as full benchmark.
- Mechanism 3 (MR vs. alternatives): High confidence - rigorous nested CV design and clear overfitting patterns in greedy selection support the conclusions.

## Next Checks

1. **Cross-benchmark transferability test**: Apply the MR filter from one benchmark to another (e.g., use SciCode's pass rates to select tasks in MathVista). Measure whether the transferred subset maintains ranking fidelity (ρ ≥ 0.85). This tests whether the 30–70% band captures universal discriminative tasks or is benchmark-specific.

2. **Synthetic scaffold robustness analysis**: Generate artificial scaffolds that systematically boost weaker agents on mid-range tasks (e.g., by providing targeted hints or tool assistance). Re-run the evaluation protocols to measure at what scaffold effect size ρ begins to degrade. This quantifies the limits of the monotonicity assumption.

3. **Concept drift monitoring simulation**: Using historical data, simulate capability jumps by artificially lowering pass rates for older agents on current tasks. Recompute MR subsets under these shifted pass rates and evaluate whether the selected tasks remain discriminative. This stress-tests the temporal stability assumption.
