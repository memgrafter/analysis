# Lipschitz Dueling Bandits over Continuous Action Spaces

## Quick Facts
- **arXiv ID:** 2604.00523
- **Source URL:** https://arxiv.org/abs/2604.00523
- **Reference count:** 32
- **Primary result:** LOG-DUELLI is the first algorithm for stochastic dueling bandits over continuous Lipschitz action spaces, achieving regret $\tilde{O}(T^{(d_z+1)/(d_z+2)})$ with $O(\log T)$ memory.

## Executive Summary
This paper studies stochastic dueling bandits in continuous action spaces where the learner only receives noisy pairwise preferences. The key challenge is that comparative feedback is relative, making estimates from different regions hard to compare. The authors introduce LOG-DUELLI, which uses a fixed reference arm per round to anchor comparisons across a hierarchical cube partition. By leveraging Lipschitz continuity, the algorithm safely eliminates suboptimal cubes and adaptively updates the reference arm to progressively localize the optimal arm. The regret bound matches the known lower bound for Lipschitz bandits up to logarithmic factors, and memory usage is optimal at $O(\log T)$.

## Method Summary
LOG-DUELLI operates in $B = \lfloor \log_2 T/(d_z+2) \rfloor + 1$ rounds. Each round $m$ uses a fixed reference arm $X^{m-1}$ to compare arms sampled from cubes at depth $h$. For a cube $C$, the algorithm samples $n_h = 16 \log(T/\delta)/r_h^2$ arms uniformly and estimates the preference gap relative to $X^{m-1}$. If the empirical gap is sufficiently worse than the current best gap $\tilde{\Delta}^{m-1}$ (accounting for estimation error and Lipschitz-induced variation $2 r_h (1+\Gamma)$), the cube is eliminated; otherwise it is refined into $2^d$ subcubes. At depth $h=m$, the cube with largest gap becomes the new reference $X^m$. After $B$ rounds, the algorithm plays $X^B$ repeatedly. A depth-first recursion ensures $O(\log T)$ memory.

## Key Results
- LOG-DUELLI achieves $\tilde{O}(T^{(d_z+1)/(d_z+2)})$ regret, where $d_z$ is the zooming dimension of the near-optimal region.
- The algorithm uses $O(\log T)$ memory, which is optimal for continuous-space bandit algorithms.
- Theoretical analysis shows the Condorcet winner is never eliminated with high probability.

## Why This Works (Mechanism)
### Mechanism 1: Reference Arm Anchoring
Within each round $m$, all comparisons use the same reference arm $X^{m-1}$. This makes empirical gap estimates $b\Delta^m_h(C)$ for different cubes directly comparable, because they are all relative to a fixed point. The stochastic triangle inequality (Assumption 3.3) ensures that transitivity of preferences holds in expectation, enabling geometric reasoning across the space.

### Mechanism 2: Safe Elimination via Lipschitz Bounds
For a cube $C$ at depth $h$, if $\tilde{\Delta}^{m-1} - b\Delta^m_h(C) > 2.5 r_h (1+\Gamma)$, then all arms in $C$ are provably suboptimal (Lemma 5.2). The margin accounts for: (i) concentration error $\tilde{O}(\sqrt{\log T / n_h})$ from finite samples, and (ii) the worst-case difference in preference gaps across the cube, bounded by $\Gamma r_h$ due to Lipschitz continuity of the transfer function $\rho$. This guarantees elimination never discards the Condorcet winner under the event $E$.

### Mechanism 3: Adaptive Reference Localization
At the end of round $m$, the reference arm $X^m$ is taken from the cube with the largest empirical gap observed at depth $h=m$. Under event $E$, Lemma 5.3 shows any surviving cube at depth $h$ contains arms with Condorcet gap at most $4 r_{h-1}(1+\Gamma)$. Thus, as rounds progress and $h$ increases, the reference arm concentrates in a shrinking neighborhood of the optimal arm $x^*$.

## Foundational Learning
- **Lipschitz continuity:** Ensures that small moves in action space induce small changes in preference probabilities. This allows the algorithm to generalize from a few samples to whole cubes.  
  *Quick check:* For arms $x,y$ in a cube of edge length $r_h$, the maximum difference between $P(x\succ y)$ and $P(x'\succ y')$ for any $x',y'$ in that cube is bounded by $2 r_h (1+\Gamma)$.

- **Zooming dimension ($d_z$):** Replaces explicit dimension $d$ as the intrinsic complexity measure. It captures how the near-optimal set $S(\varepsilon)$ can be covered by $\varepsilon$-balls. A lower $d_z$ yields faster learning.  
  *Quick check:* If $S(\varepsilon)$ is a $d'$-dimensional manifold with $d' < d$, then typically $d_z \approx d'$.

- **Condorcet winner existence:** The learning target is an arm $x^*$ such that $P(x^* \succ y) \geq 1/2$ for all $y$. Under Lipschitz $f$ and monotone $\rho$, $x^* = \arg\max f(x)$ exists (compactness) and is Condorcet.  
  *Quick check:* If $f$ is Lipschitz and $\rho$ non-decreasing, then $f(x^*) > f(y) \Rightarrow P(x^* \succ y) > 1/2$.

## Architecture Onboarding
### Component Map
ReferenceArmManager -> CubeTree -> EliminationRule -> Sampler -> RegretTracker

### Critical Path
1. Initialize reference arm $X^0$ randomly.
2. For round $m=1$ to $B$: start depth-first recursion at depth $h=1$.
3. For current cube $C$ at depth $h$: set sample size $n_h = 16 \log(T/\delta)/r_h^2$.
4. Sample $n_h$ arms from $C$, duel each with $X^{m-1}$, compute empirical gap $b\Delta^m_h(C)$.
5. If $h = m$ (maximum depth): compare $b\Delta^m_h(C)$ to current best; possibly update $\tilde{\Delta}^m$ and $X^m$.
6. If $h < m$: if $\tilde{\Delta}^{m-1} - b\Delta^m_h(C) \leq 2 r_h (1+\Gamma)$, recurse into $2^d$ children; else eliminate $C$.
7. After all cubes processed, set $X^{m-1} \leftarrow X^m$.
8. After $B$ rounds, play $X^B$ for remaining time.

### Design Tradeoffs
- **Space vs. time:** Depth-first recursion yields $O(\log T)$ memory but may have poor cache locality; breadth-first would use $O(T)$ space.
- **Round depth $B$:** Larger $B$ gives finer resolution but increases setup cost and cleanup regret. The choice $B \approx \log_2 T/(d_z+2)$ balances terms.
- **Sample size $n_h$:** Constant 16 comes from proof; too small risks false elimination, too large wastes queries.

### Failure Signatures
- **Reference degradation:** $X^m$ fails to improve ($\tilde{\Delta}^m$ plateaus) → insufficient $n_h$ or overly noisy $\rho$.
- **Optimal cube elimination:** Cube containing $x^*$ eliminated → check $n_h$ for current $r_h$ or underestimate of $\Gamma$.
- **Memory blowup:** Recursion depth exceeds $O(\log T)$ → bug in depth tracking or miscalculated $B$.

### First 3 Experiments
1. **Convergence of reference arm:** On 1D $f(x)=x$ with logistic $\rho$, track $X^m$ across rounds; should converge monotonically to $x^*=1$ and $\tilde{\Delta}^m$ should increase.
2. **Elimination safety under noise:** For 2D $f$ with known $x^*$, inject Bernoulli noise in duels. Count eliminations of the cube containing $x^*$ at each depth; should be $\leq \delta$ per round.
3. **Space complexity scaling:** Instrument maximum recursion depth. Run for increasing $T$ (e.g., $10^3,10^4,10^5$). Memory should grow as $O(\log T)$ (constant slope on log-log plot).

## Open Questions the Paper Calls Out
### Open Question 1
Is the $\tilde{O}(T^{(d_z+1)/(d_z+2)})$ regret bound tight for Lipschitz dueling bandits? The paper matches the known lower bound for Lipschitz bandits but does not prove a lower bound for the dueling setting. Dueling feedback is purely comparative, so the fundamental limit may differ.

### Open Question 2
Can LOG-DUELLI be adapted to general compact metric spaces beyond the $\ell_\infty$ hypercube? The analysis relies on multiscale partitioning and covering properties; extension to arbitrary metrics would require handling non‑cubic partitions and possibly different intrinsic dimensions (e.g., doubling dimension).

### Open Question 3
Is knowledge of the zooming dimension $d_z$ necessary? LOG-DUELLI sets $B = \lfloor \log_2 T/(d_z+2) \rfloor + 1$, requiring $d_z$ a priori. An adaptive algorithm that automatically adjusts to unknown $d_z$ while maintaining the same rate is unknown.

## Limitations
- The number of rounds $B$ depends on the unknown zooming dimension $d_z$, so practical deployment requires estimating $d_z$ or choosing $B$ heuristically.
- Constants (16 for sample size, 2.5 for elimination margin) are derived from worst-case analysis; their empirical necessity and sensitivity are unclear.
- No experimental validation is provided; performance under noise, high dimension, or misspecified Lipschitz constant $\Gamma$ remains untested.

## Confidence
- Regret bound $\tilde{O}(T^{(d_z+1)/(d_z+2)})$ and memory $O(\log T)$: **High** (rigorous proofs under assumptions).
- Elimination safety (Condorcet winner never eliminated): **High** (Lemma 5.2).
- Adaptive reference arm convergence: **Medium** (theoretically argued but not empirically validated).
- Robustness to assumption violations (non‑Lipschitz $f$, unknown $\Gamma$): **Low** (assumptions strong and untested).

## Next Checks

2. **Constant and $B$ sensitivity:** Vary $B=\lfloor\log_2 T/k\rfloor$, $k\in\{1,\dots,5\}$ and sample factor $c\in\{8,16,32\}$. Record regret and frequency of optimal cube elimination to identify robust settings.
