# Which Algorithms Can Graph Neural Networks Learn?

## Quick Facts
- **arXiv ID:** 2602.13106  
- **Source URL:** https://arxiv.org/abs/2602.13106  
- **Reference Count:** 40  
- **Primary Result:** Finite Lipschitzness plus a bounded Lipschitz certificate enables message‑passing graph neural networks (MPNNs) to learn algorithms such as Bellman‑Ford, minimum spanning trees, and 0‑1 knapsack with uniform generalization from a finite training set.

## Executive Summary
This paper investigates when message‑passing graph neural networks (MPNNs) can learn to execute discrete algorithms and generalize to graphs of any size. The authors introduce a theoretical framework based on finite Lipschitzness: if the MPNN hypothesis class is a finite Lipschitz class with respect to a suitable pseudo‑metric on graph‑vertex pairs, and the target algorithm is approximable with a bounded Lipschitz certificate, then training on a finite dataset with appropriate regularization provably yields uniform approximation on all graphs. The results cover algorithms such as single‑source shortest paths (Bellman–Ford), minimum spanning trees, and 0–1 knapsack. For Bellman–Ford, they construct a minimal training set (K+1 paths) and propose a differentiable ℓ1‑regularization term that guarantees size generalization, improving upon previous non‑differentiable penalties. Experiments confirm strong generalization across graph sizes (test scores ~0.003). The paper also establishes impossibility results for standard MPNNs and sufficient conditions for more expressive variants (1‑iWL and (1,1)‑WL‑simulating).

## Method Summary
The learning setup targets the Bellman‑Ford algorithm for single‑source shortest paths. The architecture is a K‑layer min‑aggregation MPNN; each layer applies a min‑aggregation of neighbor messages followed by a two‑layer feedforward neural network (hidden dimension 64, ReLU activations) as the update function. The training set consists of K+1 simple path graphs with specially scaled edge weights (TS<sub>x,K</sub>) and a large bias β for the source vertex. The loss combines mean absolute error between the network’s vertex predictions and the K‑step Bellman‑Ford distances, plus a differentiable ℓ1‑regularization term that penalizes weight norms to control the Lipschitz certificate. Training uses Adam (learning rate 0.001) for 160 000 steps with a regularization coefficient η=0.1. The theoretical guarantee ensures that a near‑optimal solution on this minimal cover generalizes uniformly to any graph size, provided the MPNN’s representation space is compact and the target algorithm’s Lipschitz certificate is bounded. Evaluation on Erdős–Rényi and other graph families yields normalized test errors around 0.003.

## Key Results
- Proved that MPNNs which are finite Lipschitz classes can learn algorithms like Bellman‑Ford, MST, and knapsack with guaranteed size generalization when trained with suitable regularization on a finite dataset.
- Demonstrated that standard MPNNs (1‑WL) cannot represent these algorithms, while variants simulating stronger Weisfeiler‑Leman tests (1‑iWL, (1,1)-WL) can.
- Constructed a minimal training set (K+1 paths) and introduced a differentiable ℓ1‑regularization term that achieves consistent generalization to large graphs (test error ~0.003), improving over prior non‑differentiable approaches.

## Why This Works (Mechanism)

### Finite Lipschitzness
- **Claim:** If the MPNN hypothesis class is a finite Lipschitz class and the target algorithm has a bounded Lipschitz certificate, training on a finite ε‑cover with regularization yields uniform approximation on all graphs.
- **Mechanism:** The pseudo‑metric on graph‑vertex pairs (e.g., based on iterated degrees or Hausdorff distance) induces a compact representation space, guaranteeing finite covering numbers. By bounding both the empirical loss and the Lipschitz certificate via regularization, the learned function approximates the target uniformly.
- **Core assumption:** The algorithm can be approximated within the MPNN class with some certificate B<sub>f*</sub>.
- **Evidence:** Theorem 3 (general framework) and Theorem 4 (finite Lipschitzness for sum/mean via iterated degree compactness, and for max/min via neighborhood‑set compactness).
- **Break condition:** Unbounded degrees, unbounded edge weights, or an algorithm requiring an unbounded certificate violate finiteness.

### Differentiable Regularization
- **Claim:** Using a weighted ℓ1 penalty on parameters (instead of non‑differentiable ℓ0) directly controls the Lipschitz certificate B<sub>θ</sub> and drastically reduces the required training set.
- **Mechanism:** The loss L(θ)=L<sub>emp</sub>(θ)+η ∑ w<sub>j</sub> ‖param<sub>j</sub>‖<sub>1</sub> bounds B<sub>θ</sub> (product of norms). With sufficiently large η and a covering dataset, near‑optimal loss forces both small empirical error and small B<sub>θ</sub>, yielding uniform generalization.
- **Core assumption:** η and training‑set scale satisfy theoretical bounds (e.g., η ≥ 2K exp(m(K²+3K))).
- **Evidence:** Section 3.3 and Theorem 17 for Bellman‑Ford; experiments show successful size generalization with the ℓ1 regularizer.
- **Break condition:** η too small → certificate grows; training set not an ε‑cover → failure; excessive η → underfitting.

### Expressivity Alignment
- **Claim:** The algorithm’s distinguishing power must be no greater than the MPNN’s expressive power (via WL simulation) for the algorithm to be learnable.
- **Mechanism:** MPNNs can simulate 1‑WL, 1‑iWL, (1,1)‑WL. If the target invariant is captured by one of these tests, the MPNN can represent or approximate it. Combined with Lipschitzness, this yields learnability.
- **Core assumption:** ρ<sub>V<sup>k</sup></sub>(alg) ⊆ ρ<sub>V<sup>k</sup></sub>(f<sub>θ</sub>), i.e., whenever the architecture cannot distinguish two inputs, the algorithm does not either.
- **Evidence:** Proposition 6 shows standard MPNNs cannot approximate SSSP or MST, while 1‑iWL‑simulating MPNNs can approximate SSSP and (1,1)-WL‑simulating ones can approximate MST (Section 4.1).
- **Break condition:** Algorithms requiring finer distinctions (e.g., higher‑WL tests) are not expressible; expressivity alone is insufficient without Lipschitzness.

## Foundational Learning
**Pseudo‑metric spaces and covering numbers**  
- *Why needed:* Quantify the “density” of graph‑vertex instances; finite covering numbers guarantee that a finite, carefully chosen training set can uniformly approximate the entire space.  
- *Quick check:* Given a pseudo‑metric d on V¹(𝒢), how would you construct an ε‑cover and why must it be finite for Theorem 3 to apply?

**Lipschitz continuity and certificates**  
- *Why needed:* A Lipschitz bound ensures that small changes in the input (according to the pseudo‑metric) lead to bounded changes in the network output. The certificate B<sub>θ</sub> is a computable upper bound on the Lipschitz constant that can be penalized during training.  
- *Quick check:* If a two‑layer MLP uses ReLU activations and weight matrices with spectral norms ‖W⁽¹⁾‖₂=1.5, ‖W⁽²⁾‖₂=2.0, what is a simple Lipschitz certificate for the whole network?

**Weisfeiler‑Leman (WL) hierarchy**  
- *Why needed:* WL tests characterize the maximum expressive power of MPNNs. An algorithm is learnable only if its invariant is not finer than the WL level simulated by the architecture.  
- *Quick check:* Why can standard MPNNs (simulating 1‑WL) not distinguish two graphs that differ in minimum spanning tree cost, as shown in Proposition 6?

## Architecture Onboarding
**Component map:**  
Input Graph -> Min‑aggregation MPNN (K layers, each with 2‑layer FNN) -> Vertex Predictions -> Loss = MAE + η·ℓ1 regularizer -> Optimizer (Adam)

**Critical path:**  
1. Choose Lipschitz‑continuous aggregation/update functions (min, sum/mean, max).  
2. Map each graph‑vertex pair to an iterated representation (IDM for sum/mean; neighborhood set for max/min) in a compact pseudo‑metric space.  
3. Prove layer‑wise operations are Lipschitz w.r.t. the induced metric.  
4. Show the representation space is compact → finite covering numbers.  
5. Ensure the target algorithm’s invariant lies within the approximable class (WL alignment).  
6. Construct a minimal ε‑cover dataset (e.g., K+1 paths for Bellman‑Ford) and add differentiable ℓ1 regularization.  
7. Train to small regularized loss; Theorem 3 guarantees uniform generalization.

**Design tradeoffs:**  
- Sum vs. mean: sum is simpler but may grow with graph size; mean normalizes by degree but requires handling variable denominators.  
- Aggregation choice: max/min needed for shortest‑path‑type updates but necessitates Hausdorff‑metric analysis; sum/mean use probability‑measure (Kantorovich) approach.  
- Regularizer: ℓ1 yields sparsity and differentiability; ℓ2 is smoother but may not enforce the required pattern.  
- Depth: must match algorithmic steps; deeper networks increase capacity but risk violating Lipschitz bounds without careful regularization.  
- Hidden dimension: larger dimension may improve expressive power but can break the one‑dimensional aggregation assumption; for higher dimensions, additional edge‑case graphs might be needed.

**Failure signatures:**  
- Training loss plateaus above global minimum → regularization too strong or architecture mismatch.  
- Test error grows with graph size → covering set inadequate or Lipschitz condition violated (e.g., unbounded degrees).  
- Biases diverge → insufficient regularization on biases; they should decay to near zero.  
- Negative weight entries remain large → regularization fails to push them to zero, breaking the compactness argument.  
- Instability in training (exploding gradients) → Lipschitz constants not properly controlled; consider weight clipping or smaller learning rates.

**First 3 experiments:**  
1. **Lipschitz sanity check:** Train on two near‑identical graphs (perturb one vertex feature) and verify that the output difference does not exceed M<sub>θ</sub>·d(·,·).  
2. **Size generalization:** Train on 64‑node graphs only; evaluate MAE on 128, 256, 512, 1024‑node graphs. A flat test curve indicates success.  
3. **Regularizer ablation:** Compare no regularization, ℓ2 penalty, and the proposed ℓ1 certificate penalty; the latter should yield the smallest covering dataset size and tightest test bounds.

## Open Questions the Paper Calls Out
- Can training sets be sampled efficiently to guarantee size generalization? The paper calls for high‑probability, sampling‑based methods for constructing ε‑covers with provable size guarantees.
- Does gradient descent converge to a parameter set achieving the small regularized loss needed for size generalization? The analysis does not cover the implicit bias of GNNs under Lipschitz regularization.
- Can the finite Lipschitzness framework be extended to approximation algorithms for NP‑hard problems, and can data‑dependent distributions improve worst‑case ratios?
- Is the exponential dependence on η and the one‑dimensional aggregation assumption necessary, or can they be removed while preserving size generalization? (Conjecture: adding an edge‑case graph may relieve the d=1 restriction and reduce exponential factors.)

## Limitations
- The finite Lipschitzness assumption may be violated for graphs with unbounded degrees or unbounded edge weights, limiting applicability.
- Bounded Lipschitz certificates are algorithm‑specific and have only been derived for a few cases (Bellman‑Ford, MST, knapsack); deriving them for new tasks is challenging.
- The theoretical lower bound on the regularization coefficient η is exponential in network parameters, yet experiments use a small constant (0.1), indicating a potential gap between theory and practice.
- Training sets are algorithm‑specific; constructing minimal covers automatically is unsolved.
- Experiments were limited to modest graph sizes (≤1024 vertices) and shallow networks (K=2), so scalability to larger, deeper models remains untested.

## Confidence
- Core theorem (finite Lipschitzness + bounded certificate → uniform generalization): **High**  
- Expressivity alignment (WL‑simulation) as necessary/sufficient condition: **Medium**  
- Differentiable ℓ₁ regularizer for size generalization (Bellman‑Ford): **High** (specific case) – **Low** (general applicability)  
- Empirical validation of size generalization (test score ~0.003): **Medium** (limited scale, some details missing)

2. **Certificate monitoring:** Compute the Lipschitz certificate B<sub>θ</sub> during training; ensure it stays below the theoretical B<sub>f*</sub> and test sensitivity to the choice of η.
