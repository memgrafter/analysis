# Skip to the Good Part: Representation Structure & Inference-Time Layer Skipping in Diffusion vs. Autoregressive LLMs

## Quick Facts
*   **arXiv ID:** 2603.07475
*   **Source URL:** https://arxiv.org/abs/2603.07475
*   **Reference count:** 40
*   **Primary result:** Native diffusion LLMs (LLaDA) exhibit substantial early-layer representational redundancy, enabling up to 18.75% FLOPs reduction via static layer skipping while retaining >90% performance; autoregressive models (Qwen2.5) degrade sharply under comparable skipping.

## Executive Summary
This paper investigates how the training objective of a language model—specifically, diffusion versus autoregressive (AR)—shapes its internal layer-wise representations and how these differences impact inference efficiency. Through cosine similarity analysis of hidden states across layers and tokens, the authors find that native diffusion models (LLaDA) develop hierarchical, coarse-to-fine representations with high similarity between early layers, creating computational redundancy. In contrast, AR models (Qwen2.5) maintain tight, token-dependent updates throughout depth with low inter-layer similarity. An AR-initialized diffusion model (Dream-7B) retains AR-like representational patterns, highlighting a strong initialization bias. Leveraging the observed redundancy, the authors propose a simple, static layer-skipping policy that requires no architectural changes. Native diffusion models achieve significant FLOP reduction with minimal performance loss, while AR models are highly brittle to even minimal skipping. The work directly links training objective to internal structure and demonstrates a practical, cache-orthogonal efficiency gain for diffusion LLMs.

## Method Summary
The study requires no training; it is an analysis and inference-time intervention. The core method involves:
1.  **Representational Analysis:** Forward passes are run on evaluation prompts using pre-trained models (LLaDA-8B, Qwen2.5-7B, Dream-7B). Hidden states from each layer are collected.
2.  **Similarity Profiling:** Cosine similarity is computed between the output of layer ℓ and the input to layer ℓ+1, aggregated across tokens and (for diffusion) denoising steps. This quantifies functional redundancy between consecutive layers.
3.  **Static Skipping Policy:** A calibration set is used to compute average similarity per layer pair. A skip set S is selected using a threshold (θ=0.95) and a constraint that no two skipped layers are adjacent (to prevent collapse). During inference, layers in S are bypassed without altering the model's architecture.
4.  **Evaluation:** The modified model is evaluated on reasoning (GSM8K, MATH-500) and code (HumanEval, MBPP) benchmarks. Performance retention (%) relative to the full model is measured against the FLOPs reduction from skipping layers.

## Key Results
*   Native diffusion (LLaDA) achieves up to 18.75% FLOPs reduction (skipping 6/32 layers) while maintaining over 90% performance on reasoning and code benchmarks.
*   Autoregressive models (Qwen2.5) show severe brittleness: skipping just 2 layers results in 34.9–75.3% performance retention.
*   The AR-initialized diffusion model (Dream-7B) exhibits intermediate behavior, mirroring AR models' representational structure and skipping sensitivity, demonstrating a strong initialization bias.

## Why This Works (Mechanism)
### Mechanism 1: Diffusion training induces representational redundancy
Diffusion's full-sequence denoising objective encourages a coarse-to-fine hierarchy. Early layers establish globally consistent, abstract representations quickly, leading to high cosine similarity (>0.95) between consecutive layer outputs. This functional redundancy means bypassing these early layers does not alter the representational trajectory, as later layers perform iterative refinement on a stable foundation.
*   **Break condition:** If early layers show low similarity (as in AR models), skipping them critically disrupts the computational graph.

### Mechanism 2: Autoregressive models enforce token-dependent depth
Left-to-right next-token prediction forces every layer to integrate each new token incrementally. This creates tightly coupled, non-redundant depth: representations change significantly between consecutive layers for all tokens due to strong recency bias. Consequently, skipping any layer breaks the sequential refinement process, causing sharp performance drops.
*   **Break condition:** Skipping even 2 layers causes large degradation because each layer's transformation is essential for the next token's processing.

### Mechanism 3: Initialization bias persists through diffusion fine-tuning
An AR-pretrained model fine-tuned with a diffusion objective (Dream-7B) retains the representational geometry of its AR initialization, including recency bias and low inter-layer similarity. The fine-tuning operates within the basin of attraction defined by the AR weights, preventing the development of native dLLM-like hierarchical redundancy.
*   **Break condition:** If diffusion fine-tuning fully erased initialization effects, Dream-7B would show patterns and skipping robustness similar to LLaDA.

## Architecture Onboarding
*   **Component map:** Calibration prompts -> Model forward pass -> Collect hidden states (per layer, per token/step) -> Compute cosine similarity matrix -> Apply static skip policy (threshold θ=0.95, no adjacent skips) -> Define skip set S -> Inference with layer bypassing (h_{l+1} = f_l(h_l) skipped if l ∈ S) -> Evaluation on benchmarks.
*   **Critical path:** 1) Load pre-trained models (LLaDA, Qwen2.5, Dream-7B). 2) Run calibration: forward pass on ~100 diverse prompts, record hidden states. 3) Compute average cosine similarity between consecutive layers (aggregated over tokens). 4) Select skip layers via greedy non-adjacent selection from highest-similarity pairs. 5) Modify inference loop to skip selected layers. 6) Run full evaluation on GSM8K, MATH-500, HumanEval, MBPP.
*   **Design tradeoffs:**
    *   Static vs. dynamic: Static policy is simple and cache-orthogonal but cannot adapt to input difficulty; dynamic policies could yield more gains but require per-input routing logic.
    *   Consecutive skipping: Forbidding adjacent skips is critical; allowing contiguous skipped blocks causes catastrophic collapse (e.g., Dream-7B GSM8K retention 14.1% vs 76.8%).
    *   Threshold selection: θ=0.95 balances efficiency and quality; lower thresholds risk skipping non-redundant layers.
*   **Failure signatures:**
    *   >10% relative performance drop on reasoning/code benchmarks after minimal skipping.
    *   Selection of two adjacent layers in the skip set.
    *   AR models showing <75% retention after skipping just 2 layers.
    *   Calibration set too small/non-diverse causing unstable skip sets.
*   **First 3 experiments:**
    1.  **Baseline establishment:** Run full inference (0 skipped layers) on a small validation set for all three models to confirm scores match expected baselines (e.g., LLaDA GSM8K ~0.83).
    2.  **Similarity profiling validation:** Compute layer-wise cosine similarity across 100 random prompts. Verify LLaDA shows high early-layer similarity (coarse hierarchy) while Qwen2.5 shows uniformly low similarity across all layers.
    3.  **Skipping validation:** Apply the static policy to skip exactly 2 layers. Confirm LLaDA retains >90% while Qwen2.5 retention drops below 75%. Then vary θ and the adjacency constraint to observe their effects.

## Open Questions the Paper Calls Out
*   **Open Question 1:** Can input-adaptive layer-skipping policies yield further efficiency improvements over the static policy for diffusion LLMs? *Basis:* Future work suggests dynamic/allocation based on difficulty.
*   **Open Question 2:** Does combining layer skipping with KV-caching yield multiplicative speedups in diffusion LLMs without degradation? *Basis:* Future work notes KV-caching as complementary.
*   **Open Question 3:** Can lightweight fine-tuning (e.g., via adapters) reshape dLLM representations to enable more aggressive layer skipping? *Basis:* Future work proposes adapters to induce robustness/pruning.
*   **Open Question 4:** Do the hierarchical abstraction and early-layer redundancy patterns generalize to multimodal diffusion architectures? *Basis:* Future work calls for extension to image/video generation models.

## Limitations
*   **Calibration specifics unclear:** The exact size and source of the calibration set used to derive skip policies are not specified, which could affect reproducibility and threshold robustness.
*   **Token scope ambiguity:** It is unclear whether similarity analysis and skip policy derivation used only prompt tokens or the full generated sequence; this impacts the stability and generality of the skip set.
*   **dLLM-specific parameters:** The handling of diffusion-specific parameters (e.g., which denoising step(s) to average similarity over, exact FLOPs formula across steps) is not fully detailed, leaving room for variation in implementation.

## Confidence
*   **Diffusion-induced redundancy claim:** **Medium**. Supported by consistent cosine similarity patterns and successful skipping, but relies on similarity as a proxy for functional redundancy.
*   **AR token-dependent depth claim:** **Medium**. Skipping brittleness is clear empirically; the mechanistic link via similarity is indirect but plausible.
*   **Initialization bias persistence claim:** **Low**. A novel observation with limited external corroboration; could be specific to the Dream-7B fine-tuning setup.

## Next Checks
1.  **Calibration robustness:** Vary calibration set size (100–500 prompts) and source (mix of train/test splits) to verify the stability of the chosen skip layers and the θ=0.95 threshold.
2.  **Token scope ablation:** Compute similarity and derive skip policies using only prompt tokens vs. full sequence (prompt + generated tokens). Compare the resulting skip sets and final retention-FLOP trade-offs.
3.  **Denoising step sensitivity:** For native dLLMs, compute cosine similarity separately for each diffusion step (t=1…T). Test whether using a step-specific or averaged similarity profile for the skip policy yields better performance retention at equivalent FLOP reductions.
