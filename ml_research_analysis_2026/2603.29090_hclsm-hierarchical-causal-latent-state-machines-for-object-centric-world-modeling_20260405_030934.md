# HCLSM: Hierarchical Causal Latent State Machines for Object-Centric World Modeling

## Quick Facts
- **arXiv ID:** 2603.29090
- **Source URL:** https://arxiv.org/abs/2603.29090
- **Reference count:** 3
- **Primary result:** A 68M-parameter HCLSM model achieves 0.008 MSE next-state prediction loss and 0.0075 SBD loss on the PushT robotic manipulation benchmark, with emergent spatial decomposition and learned event boundaries.

## Executive Summary
HCLSM introduces a world model architecture that overcomes flat, entangled latent representations in video prediction by combining object-centric decomposition, hierarchical temporal dynamics, and causal structure learning. It uses slot attention with a spatial broadcast decoder (SBD) to enforce spatial specialization via a two-stage training protocol. Continuous object physics are modeled with selective state space models (SSMs), discrete events with sparse transformers, and abstract goals with compressed transformers. Causal interactions are mediated by a graph neural network (GNN) with structural regularizers. Evaluated on the PushT benchmark, the model demonstrates strong next-state prediction and spatial reconstruction, alongside a custom Triton SSM kernel providing a 38x speedup.

## Method Summary
The model processes video frames through a Vision Transformer encoder. Slot Attention decomposes patch features into a fixed set of object-centric slots. Training is two-stage: Stage 1 uses the Spatial Broadcast Decoder to reconstruct frozen ViT features, forcing slots to specialize spatially before dynamics training begins in Stage 2. Dynamics operate hierarchically: per-slot selective SSMs model continuous motion; an event detector triggers a sparse transformer at discrete boundaries; a goal transformer compresses event sequences. A GNN processes slot states to learn a causal adjacency matrix, regularized with NOTEARS and L1 sparsity to encourage acyclicity and sparsity.

## Key Results
- Next-state prediction MSE of 0.008 on PushT.
- Spatial broadcast decoder (SBD) reconstruction loss of 0.0075.
- Emergent spatial decomposition (distinct slot masks) and learned event boundaries aligned with state changes.

## Why This Works (Mechanism)

### Mechanism 1: Spatial specialization via two-stage training
- **Claim:** Object-centric slot specialization is enforced by spatial reconstruction pressure before dynamics training.
- **Mechanism:** The SBD reconstructs frozen ViT features at each spatial location. Softmax-normalized alpha masks create pixel-level competition between slots, forcing each to "own" a distinct region to minimize its reconstruction error.
- **Core assumption:** Spatial decomposition is prerequisite for learning object-specific dynamics; entangled slots allow prediction loss to be minimized by distributed codes without slot specialization.
- **Evidence anchors:**
  - [abstract] "two-stage training protocol where spatial reconstruction forces slot specialization before dynamics prediction begins."
  - [section 3.2] Reconstruction target is frozen ViT patch features, giving slots a semantic decomposition signal.
  - [section 5.2] Without SBD, prediction loss is lower (0.002) but slots remain entangled; with SBD, prediction loss is higher (0.008) but SBD loss decreases, indicating spatial ownership.
- **Break condition:** SBD loss must decrease during Stage 1 (first 40% of steps). If not, slots fail to specialize and collapse to flat representation during Stage 2.

### Mechanism 2: Hierarchical temporal dynamics engine
- **Claim:** Multi-scale temporal dynamics require distinct computational engines: continuous physics (SSM), discrete events (sparse transformer), and abstract goals (compressed transformer).
- **Mechanism:** A hierarchical manager routes object slot states: (1) per-object selective SSMs for frame-to-frame continuous motion, (2) an event detector triggers a sparse transformer only at detected boundaries, (3) a goal-level transformer compresses the event sequence into summaries. This avoids dense all-timestep transformer attention.
- **Core assumption:** Physical dynamics operate at different temporal granularities unsuited to a single recurrent or transformer module; one model for all scales leads to information loss or computational waste.
- **Evidence anchors:**
  - [abstract] "hierarchical temporal dynamics through a three-level engine combining selective state space models for continuous physics, sparse transformers for discrete events, and compressed transformers for abstract goals."
  - [section 3.3] Sparse Event Transformer operates on gathered timesteps with cost O(K·N²) instead of O(T·N²).
  - [section 5.4] Event detector identifies 2–3 events per 16-frame sequence, corresponding to moments of significant state change.
- **Break condition:** Event detector must fire at meaningful transitions (e.g., contact events in PushT). If it fails, the sparse transformer receives no informative timesteps and the hierarchy collapses to only the SSM level.

### Mechanism 3: Causal interactions via GNN with structural regularization
- **Claim:** Causal object interactions emerge from GNN-mediated message passing with structural regularization, not from the dynamics objective alone.
- **Mechanism:** A GNN processes all-pair slot features to produce edge weights that gate message passing. A NOTEARS-style DAG regularizer and L1 sparsity encourage acyclicity and sparsity in the learned adjacency matrix, interpreted as causal influence strengths.
- **Core assumption:** Without an explicit structural prior, gradient descent on prediction loss alone will not recover a disentangled causal graph; the model can exploit spurious correlations without learning true influence.
- **Evidence anchors:**
  - [abstract] "causal structure learning through graph neural network interaction patterns."
  - [section 3.4] Causal adjacency matrix W∈R^(N×N) learned with Gumbel-softmax binary sampling, L1 sparsity, and NOTEARS DAG constraint.
  - [section 6 (Limitations)] The explicit causal adjacency matrix learns no edges (all weights collapse to zero under sparsity regularization). *This is a negative result, showing mechanism fragility.*
- **Break condition:** If GNN edge weights collapse to zero or become dense without structure under regularization, the causal signal is not being learned; current training regime may be insufficient.

## Foundational Learning
- **Concept:** Slot Attention (object-centric decomposition)
  - **Why needed here:** Provides basic mechanism for grouping image patches into discrete slot representations. Without this, the model cannot propose candidate objects.
  - **Quick check question:** How does the softmax over slots (Equation 1) create competition that encourages different slots to explain different spatial regions?
- **Concept:** Selective State Space Models (temporal continuity)
  - **Why needed here:** Enables linear-complexity modeling of continuous per-object dynamics at finest timescale, computationally cheaper than a transformer for long frame sequences.
  - **Quick check question:** What does "selective" mean in Mamba/SSM, and why is input-dependence important for modeling different object motions?
- **Concept:** Causal Representation Learning (structure vs. correlation)
  - **Why needed here:** Motivates need for explicit interaction graph rather than flat latent space; the goal is to model *why* objects move, not just *how*.
  - **Quick check question:** According to Schölkopf et al., what is the key difference between associative and causal representation learning?

## Architecture Onboarding
- **Component map:** ViT Encoder -> Slot Attention -> (SBD loss in Stage 1) -> Slot States -> Hierarchical Dynamics (Level 0: per-slot selective SSM -> Event Detector -> Level 1: Sparse Event Transformer -> Level 2: Goal Transformer) -> GNN (with causal adjacency) -> Causal loss. Memory components: Hopfield network + EWC (mentioned but not detailed).
- **Critical path:** Video frame -> ViT patches -> Slot Attention (with SBD loss in Stage 1) -> Slot states -> Hierarchical Dynamics (SSM -> Event gather -> Sparse Tfm -> Goal Tfm) -> GNN message passing (using final states) -> Causal adjacency loss.
- **Design tradeoffs:**
  - Two-stage training vs. end-to-end: Two-stage prevents collapse but requires fixed decomposition; end-to-end is more flexible but risks slot entanglement.
  - Fixed slot count vs. adaptive: Fixed Nmax=32 is simple but inefficient for scenes with fewer objects; adaptive slots (Fan, 2024) could match object count but add complexity.
  - Sparse event transformer vs. full: Saves compute but depends on a learned detector; missed events lose information.
- **Failure signatures:**
  - NaNs during bf16 training: Often from slot attention GRU or SSM exponent overflow; check clamping and Alog initialization.
  - Slots don't specialize: SBD loss remains high; Stage 1 duration may be insufficient.
  - No event detections: Event detector threshold not learned; event loss weight too low.
  - Causal graph collapse: All adjacency weights zero; causal loss weight λ_causal too high or training unstable.
- **First 3 experiments:**
  1. **Stage 1 SBD Check:** Train for 5K steps with SBD loss only. Verify SBD loss decays and per-slot alpha masks show distinct spatial regions (like Figure 2).
  2. **Event Boundary Alignment:** After Stage 2, run inference on a held-out PushT clip. Compute frame-difference magnitude and check correlation with event probability scores; expect spikes aligned.
  3. **Hierarchy Ablation:** Disable the event transformer (feed SSM outputs directly to goal transformer). Compare prediction loss and interpretability; expect worse long-horizon prediction if events are meaningful.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can HCLSM implement adaptive slot allocation that dynamically matches the number of objects in a scene while maintaining training stability?
- **Basis in paper:** Inferred from the limitation that fixed 32 slots remain alive, reducing Nmax to 8 causes NaN instability, and adaptive slot methods (e.g., Fan, 2024; MetaSlot, 2025) are proposed as promising.
- **Why unresolved:** The existence head fails to deactivate unused slots, leading to inefficient object decomposition where each object is split across multiple slots; adaptive mechanisms are not implemented and pose numerical challenges.
- **What evidence would resolve it:** Integrate an adaptive slot attention module (e.g., with learnable slot birth/death or codebook deduplication), train on multi-object datasets, and show stable convergence with slot counts automatically aligning with object numbers, measured via reduced SBD loss and increased slot diversity.

### Open Question 2
- **Question:** Can the GNN-mediated edge weights in HCLSM be validated as representing true causal relationships between objects, and can explicit causal graph learning be stabilized?
- **Basis in paper:** Explicitly stated that the explicit causal adjacency matrix learns no edges under sparsity regularization and training caused NaN at bf16; GNN weights provide implicit structure but lack verification on environments with known causality.
- **Why unresolved:** Joint training of dynamics and causal modules leads to numerical instability; no intervention-based evaluation confirms if learned edges correspond to ground-truth causal influences, limiting interpretability and robustness.
- **What evidence would resolve it:** Train HCLSM on synthetic benchmarks with known causal graphs (e.g., with controlled interventions), compute structural hamming distance or intervention accuracy between learned edges and ground truth, and resolve NaN issues via gradient scaling or fp32 paths to enable stable DAG learning.

### Open Question 3
- **Question:** What modifications are necessary to scale HCLSM beyond the Small configuration (68M) to Base (262M) and Large (3B) models, and can it be trained on larger, diverse robot datasets without numerical failures?
- **Basis in paper:** Explicitly noted that Base and Large configurations suffer NaN gradient issues at batch size ≥4, multi-GPU training (FSDP) failed due to NCCL incompatibility, and seed sensitivity causes 40–60% run divergence.
- **Why unresolved:** Gradient overflow in the slot attention GRU at bf16 precision and infrastructure issues prevent scaling; current training is limited to PushT (206 episodes) with a single GPU, hindering generalizability.
- **What evidence would resolve it:** Implement bf16 stability fixes (e.g., gradient clipping, selective fp32 computation), resolve NCCL version conflicts for multi-GPU training, and successfully train Base configuration on a diverse subset of Open X-Embodiment with >90% successful runs across random seeds, measured by consistent loss reduction.

### Open Question 4
- **Question:** Does initializing the Vision Transformer encoder with pre-trained weights (e.g., from V-JEPA 2) improve HCLSM's object decomposition, spatial broadcast decoder loss, and downstream dynamics prediction?
- **Basis in paper:** Explicitly listed as a future direction to initialize ViT from V-JEPA 2 checkpoints to provide richer patch features as SBD targets and reduce perception learning burden.
- **Why unresolved:** The current model uses a randomly initialized or scratch-trained ViT; pre-trained features could enhance semantic decomposition and stabilize training, but this remains untested.
- **What evidence would resolve it:** Load V-JEPA 2 pre-trained weights into the ViT encoder, compare SBD reconstruction loss, slot diversity, and next-state prediction MSE against the current baseline on PushT and multi-object scenes, and assess whether richer features lead to cleaner spatial segmentation and faster convergence.

## Limitations
- **Causal graph failure:** The explicit GNN-based causal adjacency matrix collapsed to zero under sparsity regularization (Section 6), indicating the current regularization scheme may be too aggressive or the training signal insufficient for structure discovery, undermining the core claim of learned object interactions.
- **Fixed slot count & two-stage rigidity:** The model uses a fixed maximum of 32 slots and requires a separate spatial pre-training stage. This is inefficient for scenes with fewer objects and prevents end-to-end learning of decomposition and dynamics, potentially limiting generalizability.
- **Evaluation scope:** Results are reported only on the PushT manipulation benchmark with a single model size. It is unclear if the hierarchical dynamics architecture (SSM → Event Tfm → Goal Tfm) is necessary for simpler datasets or if gains are specific to this complex, contact-rich task.

## Confidence
- **High:** Spatial decomposition via SBD + two-stage training; speedup from custom Triton SSM kernel; quantitative next-state prediction results on PushT.
- **Medium:** Hierarchical temporal dynamics as a necessary design; event detector identifying meaningful boundaries; overall architectural integration.
- **Low:** Success of causal structure learning via GNN; claims about abstract goal-level representations; generalizability beyond the reported single benchmark.

Expected: Joint training with adaptive slots fails (slot collapse), confirming the necessity of the two-stage protocol for this model.
