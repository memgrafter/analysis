# A comprehensive study of LLM-based argument classification: from Llama through DeepSeek to GPT-5.2

## Quick Facts
- **ArXiv ID**: 2603.19253
- **Source URL**: https://arxiv.org/abs/2603.19253
- **Reference count**: 33

## Executive Summary
This paper evaluates large language models (LLMs) on the task of argument relation classification using the UKP and Args.me corpora. The authors compare state-of-the-art models including GPT-5.2, Llama 4, and DeepSeek, employing advanced prompting strategies such as rephrased prompts, multi-prompt voting, and certainty estimation. The best-performing model, GPT-5.2, achieved 78.0% accuracy on the UKP dataset and 91.9% on Args.me. Prompt engineering and voting ensembles yielded improvements of 2–8 percentage points across all models. Qualitative analysis uncovered systematic failure modes, including sensitivity to prompt formulation and challenges with implicit criticism and complex discourse structures. Notably, a smaller open-weight model (gpt-oss-120b) approached the performance of GPT-5.2 when augmented with these techniques.

## Method Summary
The study does not provide detailed reproduction notes. However, the core method involves fine-tuning and evaluating multiple LLMs on two argument relation classification datasets. Advanced prompting techniques, including rephrased prompts, multi-prompt voting, and certainty estimation, are used to enhance performance. Models are compared on accuracy metrics.

## Key Results
- GPT-5.2 achieved 78.0% accuracy on UKP and 91.9% on Args.me.
- Prompt engineering and voting ensembles improved accuracy by 2–8 percentage points across models.
- A smaller open-weight model (gpt-oss-120b) reached performance close to GPT-5.2 when using these techniques.

## Why This Works (Mechanism)
The paper attributes the performance gains primarily to the use of advanced prompting strategies. Rephrased prompts help mitigate biases in the model's interpretation, multi-prompt voting aggregates diverse predictions to reduce variance, and certainty estimation allows for filtering uncertain outputs. These techniques collectively improve robustness and accuracy on the argument classification task.

## Foundational Learning
1. **Argument Relation Classification**: The task of determining the logical relationship (e.g., support, attack) between two arguments. *Why needed*: This is the core problem the study addresses. *Quick check*: Can you distinguish between a supporting and an attacking argument pair?
2. **Prompt Engineering**: Crafting input prompts to guide LLMs toward desired outputs. *Why needed*: Central technique used to improve model performance. *Quick check*: How would you rephrase a classification prompt to be more explicit?
3. **Ensemble Voting (Multi-prompt voting)**: Combining predictions from multiple prompt variants to produce a final classification. *Why needed*: Increases robustness by reducing the influence of any single prompt's quirks. *Quick check*: What are the advantages and disadvantages of majority voting versus weighted voting?
4. **Certainty Estimation**: Assessing the confidence of the model's prediction. *Why needed*: Allows filtering of low-confidence predictions, potentially improving precision. *Quick check*: Why might certainty scores be unreliable for LLMs?

## Architecture Onboarding
- **Component Map**: Input (argument pair) → Prompt Variants → LLM Inference → Voting/Aggregation → Output (relation label).
- **Critical Path**: The essential flow is: generate multiple prompt versions for the input, obtain model responses for each, apply voting/consensus, and optionally use certainty estimation to resolve ties or filter outputs. The most computationally intensive step is LLM inference; prompt generation and voting are relatively lightweight.
- **Design Tradeoffs**: Using multiple prompts increases accuracy (2–8 pp gains) but also multiplies inference cost and latency. Certainty estimation adds overhead but can improve precision by discarding uncertain predictions. Simpler single-prompt approaches are faster but less accurate.
- **Failure Signatures**: The study identifies systematic errors: (1) high sensitivity to the exact wording of prompts; (2) difficulty interpreting implicit criticism (e.g., sarcasm or nuanced attacks); (3) errors on arguments with complex discourse structures. These manifest as inconsistent predictions across prompt variants or low certainty scores.
- **First Experiments**: To onboard to this system, we would run: (1) Baseline: evaluate a single prompt across models; (2) Add multi-prompt voting and compare to baseline; (3) Analyze error cases by manually labeling a sample of failures to confirm the identified failure signatures.
