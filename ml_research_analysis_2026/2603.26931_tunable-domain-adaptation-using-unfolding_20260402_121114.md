# Tunable Domain Adaptation Using Unfolding
## Quick Facts
- **arXiv ID:** 2603.26931
- **Source URL:** https://arxiv.org/abs/2603.26931
- **Reference count:** 40
- **Primary result:** Tunable domain adaptation (TDA) via unrolled networks matches per-domain models and outperforms joint training across multiple inverse problems, using either known domain parameters (P-TDA) or data-driven inference (DD-TDA).

## Executive Summary
This paper addresses domain shift in regression tasks, particularly inverse problems, by proposing tunable domain adaptation (TDA) for unrolled networks. The key insight is that in models like LISTA, only a small subset of parameters (e.g., soft-threshold β) varies with domain characteristics (e.g., noise level), while other parameters (e.g., weight matrices) remain invariant. Two variants are introduced: P-TDA, which uses known domain parameters to set β, and DD-TDA, which infers β directly from measurements. Evaluated on compressed sensing, blind gain calibration, and sparse phase retrieval, both variants achieve performance comparable to models trained separately on each domain and consistently beat joint training. The results demonstrate that targeted adaptation with minimal extra parameters is effective, and DD-TDA works even without explicit domain labels.

## Method Summary
TDA exploits the structure of unrolled optimization networks. For a given inverse problem, the authors first identify that parameters associated with the inverse operator (α) are stable across domains, while the regularization strength (β) must adapt. In P-TDA, a small mapping function g_φ converts a known domain parameter θ (e.g., noise σ) into β for each layer; only α and φ are learned from mixed-domain data. In DD-TDA, a data-driven module h_φ directly outputs β from the measurement y, removing the need for θ. The backbone (e.g., LISTA) is shared across domains, with β injected per layer. Training uses standard regression loss (MSE) on mixed data, enabling the network to generalize to new domains at inference by simply adjusting β via g_φ or h_φ.

## Key Results
- On MNIST compressed sensing (-10 dB SNR), P-TDA achieves NMSE -12.83 dB and OCR 51.00%, beating joint training (-10.98 dB, 34.55%) and approaching per-domain training.
- DD-TDA reaches NMSE -12.19 dB and OCR 48.65% without using noise level.
- Across blind gain calibration and sparse phase retrieval, both TDA variants match per-domain performance, showing robustness to structured gain variations and sparsity levels. DD-TDA in phase retrieval requires auxiliary Cauchy measurements to maintain accuracy at high sparsity.

## Why This Works (Mechanism)
### Parameter Invariance in Unrolled Networks
Unrolled networks such as LISTA translate iterative algorithms (e.g., ISTA) into deep models with tied weights. Parameters like the linear transforms (W₁, W₂) and step size (λ) are derived from the measurement matrix A and signal statistics; these remain largely unaffected by nuisance domain parameters like noise variance or multiplicative gains. In contrast, the soft-threshold β directly controls sparsity regularization and must compensate for domain-specific conditions (e.g., higher noise requires stronger thresholding). The paper empirically shows that across different noise levels, the Frobenius norms of W₁, W₂ vary little (low Δ_m), while β changes significantly. This separation enables adaptation by tuning only β.

### Parametric Tuning via Known Domain Variables (P-TDA)
When a domain parameter θ is available (e.g., σ, gain vector c, sparsity L), a single network can generalize by learning a parametric function g_φ that maps θ to the tunable β. During training on mixed-domain data, the network minimizes loss over all domains while sharing the invariant α and learning g_φ. At inference, θ is fed into g_φ to produce β dynamically. This approach avoids training separate networks per domain and adds only a small number of parameters (e.g., an MLP). Experiments show P-TDA nearly matches per-domain trained models on noise-adaptive CS, gain calibration, and phase retrieval (with true L).

### Data-Driven Tuning without Domain Labels (DD-TDA)
When θ is unknown, the network can still adapt by inferring appropriate β directly from the measurement y via a learned module h_φ. h_φ processes y (and possibly auxiliary data) and outputs per-layer β. The mapping is learned end-to-end on mixed-domain data, forcing h_φ to extract domain-relevant cues (e.g., noise level from residual statistics, gain from intensity distribution, sparsity from auxiliary Cauchy measurements). DD-TDA achieves performance close to P-TDA and per-domain models on the evaluated tasks, demonstrating that the measurement itself often contains sufficient information for adaptation. However, in phase retrieval, auxiliary Cauchy measurements improve high-sparsity estimation; without them, DD-TDA degrades.

## Foundational Learning
### Concept: Unrolled/Unfolding Networks
**Why needed here:** Unrolled networks provide interpretability: each layer corresponds to an algorithm iteration, making it possible to identify which parameters should be invariant (e.g., linear transforms) and which should be tunable (e.g., thresholds). Without such structure, the parameter roles are opaque, hindering targeted adaptation.
**Quick check question:** Given an ISTA update \(x^{k+1} = S_\beta(W_1 y + W_2 x^k)\), which parameters would you expect to vary with measurement noise level and why?

### Concept: Domain Parameterization
**Why needed here:** The TDA approach assumes domains are characterized by a low-dimensional physical parameter θ (e.g., noise σ, gain c, sparsity L). This structure allows the adaptation module to learn a deterministic mapping β = g(θ) or infer θ from y. Without such parameterization, adaptation would require a black-box approach with higher complexity.
**Quick check question:** If sensor gain c varies across domains but A and noise σ are fixed, which component of \(y = \text{diag}(c)Ax + \eta\) is most informative about c for a tuning function to exploit?

### Concept: Sparsity and Regularization Paths
**Why needed here:** In compressed sensing and phase retrieval, sparsity level (or regularization strength) crucially determines the solution. Domain shifts like noise or gain alter the effective optimal regularization. Tuning β across domains allows the unrolled network to follow the appropriate regularization path.
**Quick check question:** In a noiseless CS problem \(y = Ax\) with fixed A, how would you expect the optimal threshold β* to change if the sparsity of x doubles?

## Architecture Onboarding
Component Map:
- Backbone: Tied LISTA (or phase retrieval-specific) layers with invariant parameters α = {W₁, W₂, λ} and tunable per-layer thresholds β. For blind gain calibration, an additional tunable pre-deconvolution vector B is inserted before the LISTA layers.
- Tuning module: For P-TDA, a small MLP g_φ takes known θ (e.g., σ or c) and outputs a K-dimensional β vector (one per layer). For DD-TDA, a module h_φ takes measurement y (and possibly auxiliary data y_c) and outputs β. In phase retrieval DD-TDA, h_φ includes a sparsity estimator SE(·) with learnable parameters.
- Training loop: Joint optimization of α and φ using mixed-domain data, with MSE loss. In phase retrieval, the sparsity estimator is pre-trained and then frozen.

Critical Path:
1. Diagnose α/β split: Train separate per-domain (PT) models, compute cross-domain deviation scores Δ_m for parameter blocks. Blocks with small Δ_m are designated invariant (α); those with large Δ_m become tunable (β). Validate by freezing α and retraining β on mixed data—performance should approach PT.
2. Design g_φ/h_φ: Start with a lightweight MLP (2–3 layers) whose input dimension matches θ or y, and output dimension equals number of layers K. Keep capacity low to avoid overfitting and minimize overhead.
3. Train: Use Adam (lr≈0.001), batch size 64, early stopping on validation loss. Ensure α is initialized consistently (e.g., from ISTA formulas). Monitor per-domain validation performance to prevent neglect of any domain.

Design Tradeoffs:
- P-TDA vs. DD-TDA: P-TDA requires known θ and adds minimal parameters (g_φ), often achieving slightly better performance; DD-TDA removes the need for θ but adds h_φ and inference cost, and may generalize poorly to out-of-support θ.
- Tuning granularity: β can be shared across layers or per-layer. Per-layer offers flexibility but increases h_φ size; the paper uses per-layer.
- Auxiliary data: For phase retrieval DD-TDA, auxiliary Cauchy measurements y_c improve high-sparsity estimation; without them, performance degrades notably for L=10.

Failure Signatures:
- α-variance: If PT models show large differences in W₁/W₂ (high Δ_m), then α is not invariant; TDA will fail because freezing α discards essential adaptation. Remedy: move more blocks to β.
- h_φ underfitting: DD-TDA performance similar to joint training but far below PT indicates h_φ cannot infer β from y. Check correlation between predicted β and true θ (if available); increase h_φ capacity or add auxiliary inputs.
- Over-parameterized h_φ: Low training loss but high variance across test domains suggests overfitting to training domains. Simplify h_φ or increase domain diversity.
- Catastrophic cross-domain PT: If PT-D1 performs poorly on D3 (and vice versa) with huge NMSE gap (>20 dB), the domain shift is severe; TDA may still work if β can compensate, but verify β variation is smooth.

First 3 Experiments:
1. Noise-Adaptive LISTA on MNIST-CS: Train JT, PT (3 SNRs), P-TDA, DD-TDA on mixed SNRs (−10, −5, 0, +5, +10 dB). Evaluate per-SNR NMSE and OCR. Expect P-TDA/DD-TDA to match PT and beat JT, especially at extremes. Verify α invariance via S(W) metric.
2. Blind Gain Calibration: Train on 3 domains with different sinusoidal gain vectors c. Test cross-domain. Expect JT to fail, PT to succeed per domain, and P-TDA/DD-TDA to match PT. Check that learned tunable B correlates with c.
3. Sparse Phase Retrieval: Train JT (L=10 fixed), PT per L (10,7,4), P-TDA (true L given), DD-TDA (with Cauchy y_c). Test on all three L. Expect PT-D1 (L=10) to partially work on L=4 but not vice versa; P-TDA/DD-TDA to succeed across all. Ablate Cauchy to see DD-TDA drop at L=10.

## Open Questions the Paper Calls Out
- What is a systematic, reliable procedure to identify the subset of tunable parameters (β) versus invariant parameters (α) in an unrolled network when faced with a novel domain shift? The proposed Δ_m heuristic lacks theoretical guarantees and may fail for subtle or multi-block shifts.
- Can sparsity be estimated directly from magnitude-only compressed measurements in phase retrieval without auxiliary Cauchy measurements, enabling a fully self-contained DD-TDA? The current estimator relies on distributional contrast; a data-driven h_φ(y) for high sparsity remains elusive.
- What are the theoretical limits of generalization for DD-TDA to domain parameters outside the training range (extrapolation), and how does the number of training domains J affect this? No formal bounds are provided on error growth with distance from training domains.
- Does the TDA framework extend to non-unrolled deep networks (e.g., standard CNNs) for regression tasks while preserving the benefits of low-parameter adaptation? The paper focuses on unrolled models due to interpretability; applicability to black-box architectures is uncertain.

## Limitations
- Invariance of α is only validated on noise-level shifts in compressed sensing; its robustness to other shifts (e.g., changes in sensing matrix A, signal distribution) is unknown.
- DD-TDA's claim of not requiring explicit domain parameters is compromised by the use of auxiliary Cauchy measurements in phase retrieval, which indirectly provide sparsity information.
- All evaluations are on synthetic or standard datasets; real-world domain shift (e.g., hardware variations, natural image statistics) remains untested.
- Generalization to unseen domain parameters lacks formal analysis; extrapolation performance is unclear.

## Confidence
- Invariance of α: Medium
- P-TDA effectiveness: High
- DD-TDA effectiveness: Medium
- Generalization to unseen domains: Low

## Next Checks
1. Invariance stress test: Train PT models across diverse shifts (varying A conditioning, sparsity levels, noise types) and compute Δ_m for all parameter blocks. Verify which blocks remain invariant; adjust α/β split accordingly.
2. DD-TDA without auxiliary data: Remove Cauchy measurements in phase retrieval and assess DD-TDA performance as sparsity L varies, especially at high L where auxiliary data was most helpful.
3. Real-world transfer: Deploy P-TDA/DD-TDA on actual hardware (e.g., a camera for phase retrieval or a sensor array for CS) with naturally occurring domain variations (e.g., temperature, aging) and compare to JT and PT-oracle.
