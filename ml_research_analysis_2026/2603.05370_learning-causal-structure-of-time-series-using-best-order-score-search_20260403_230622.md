# Learning Causal Structure of Time Series using Best Order Score Search

## Quick Facts
- **arXiv ID:** 2603.05370
- **Source URL:** https://arxiv.org/abs/2603.05370
- **Reference count:** 18
- **Primary result:** TS-BOSS extends the static Best Order Score Search (BOSS) to time series by enforcing temporal ordering constraints and using grow-shrink trees for efficient scoring, achieving higher adjacency recall than the constraint-based PCMCI+ baseline in high autocorrelation regimes while maintaining comparable precision.

## Executive Summary
This paper introduces TS-BOSS, a score-based method for learning causal structures from multivariate time series. It adapts the permutation-based Best Order Score Search (BOSS) to the time series setting by incorporating temporal ordering constraints that restrict the search space over contemporaneous variables while fixing lagged predecessors. The algorithm employs grow-shrink trees to cache intermediate score computations, preserving scalability. Theoretical guarantees establish soundness and extend subgraph minimality to dynamic Bayesian networks under standard causal assumptions. In synthetic experiments, TS-BOSS consistently outperforms PCMCI+ in adjacency recall, particularly when autocorrelation is high, and demonstrates strong empirical performance, offering an effective approach for time series causal discovery.

## Method Summary
TS-BOSS operates in two phases. First, it performs a permutation-based search over the contemporaneous variables of a windowed time series representation, respecting temporal order (lagged blocks remain fixed). For each permutation, parent sets are selected using a locally consistent score (e.g., BIC) via grow-shrink trees that efficiently compute score improvements by caching subsets. The search iteratively moves variables within the contemporaneous block to improve the global score. Second, a backward edge deletion phase (TS-BES) refines the result to converge to the true Markov equivalence class under consistency assumptions. The method assumes stationarity, known maximum lag τ_max, causal sufficiency, and decomposable scores.

## Key Results
- TS-BOSS achieves higher adjacency recall than PCMCI+ in synthetic experiments, especially under high autocorrelation.
- Precision remains comparable to PCMCI+ across tested settings.
- The method scales well with number of variables and lags due to grow-shrink tree caching, and theoretical guarantees hold under stated assumptions.

## Why This Works (Mechanism)

### Mechanism 1: Temporal ordering constraints reduce the combinatorial search space while preserving all admissible time series DAGs under stationarity.
The algorithm fixes the order of lagged variables (by increasing time lag) and only permutes contemporaneous variables. For each permutation, parent sets are constructed by including predecessors that improve the score. This respects the temporal precedence of lagged causes and restricts contemporaneous search to a smaller block. Core assumption: Assumption 4 (stationary causal structure) ensures the full ts-DAG can be reconstructed from a single window. Evidence: The abstract mentions "temporal ordering constraints"; Section 4.2 defines permutation form π = (lagged block | contemporaneous block). Break condition: Non-stationarity invalidates the fixed lagged block approach.

### Mechanism 2: Grow-shrink trees cache intermediate score computations for efficient evaluation during permutation search.
For each contemporaneous node, a binary tree stores scores for all subsets of candidate parents. The "grow" phase traverses the tree to find the best addition allowed by the permutation order; the "shrink" phase prunes redundant variables. This avoids recomputing scores from scratch for each permutation candidate. Core assumption: The scoring criterion is decomposable (local score equivalence). Evidence: Abstract notes "grow–shrink trees to cache intermediate score computations"; Section 4.1 details the grow/shrink algorithms. Break condition: Non-decomposable scores would destroy caching efficiency.

### Mechanism 3: Theoretical soundness is established via a two-phase process: Phase 1 yields a window subgraph-minimal TS-DAG, and Phase 2 (TS-BES) asymptotically recovers the correct Markov equivalence class.
Under Assumptions 1–5 (Markov, faithfulness, sufficiency, known τ_max, stationarity) and a locally consistent score, Phase 1 produces a minimal graph (Theorem 5, Lemma 6). TS-BES then removes superfluous edges, guaranteed to converge to the true MEC if the initial graph contains it (Lemma 7). Evidence: Abstract states "theoretical guarantees establish soundness"; Section 5 and Appendix A contain formal results. Break condition: Violation of any assumption (e.g., latent confounders, non-stationarity, inconsistent scores) breaks the guarantee.

## Architecture Onboarding
Input Handler -> Unroller -> GST Builder -> Permutation Search Loop -> Projector -> CPDAG Converter -> TS-BES Refinement

**Critical path:** Data → Unroll → Init GSTs → while loop (BestTSMove) → Project → CPDAG → (optional) TS-BES → Output TS-CPDAG. The core bottleneck is the BestTSMove loop, which repeatedly queries GSTs for scores of altered permutations.

**Design tradeoffs:**
- Temporal constraint vs. expressiveness: Fixed lagged block reduces search space but assumes stationarity; non-stationary graphs require a different representation.
- GST memory vs. speed: GSTs cache O(2^p) scores (p = number of candidate parents); fast for small p but memory-intensive for many lagged parents (p ≈ m·τ_max).
- Phase 1 vs. Phase 2: Phase 1 finds a minimal graph efficiently but may not be maximally sparse; Phase 2 (TS-BES) is needed for asymptotic optimality but adds cost.

**Failure signatures:**
- Runtime explosion with many nodes/lags: GST memory grows exponentially with candidate parent count (m·τ_max).
- Poor recall in low autocorrelation: Weak lagged signals may be missed; PCMCI+ may outperform (as seen in paper Fig 3d).
- Non-stationarity: Violates repeating edge assumption; window graph fails to reconstruct full ts-DAG.
- GST suboptimality: Greedy grow-shrink may not find optimal parent sets, especially in dense graphs.

**First 3 experiments:**
1. Sample size (T) sweep: Verify consistency – recall/orientation should increase with T.
2. Autocorrelation (a) sweep: Validate main claim – TS-BOSS recall should improve or remain stable as autocorrelation increases, while PCMCI+ recall drops.
3. Graph density (d) sweep: Test scalability and accuracy in denser regimes; TS-BOSS should maintain recall better than PCMCI+ as density increases.

## Open Questions the Paper Calls Out
- **What theoretical guarantees exist for TS-BOSS in single multivariate time series settings where samples are temporally dependent?** The paper's soundness proofs assume i.i.d. window data, but sliding windows from a single series produce dependence; empirical results only are provided.
- **How sensitive is TS-BOSS to misspecification of the maximum time lag τ_max?** The algorithm assumes τ_max is known; the impact of incorrect τ_max on causal recovery is unstudied.
- **Can TS-BOSS robustly handle violations of orientation faithfulness?** Score-based methods may be less transparent than constraint-based methods when faithfulness is violated; this is not investigated.

## Limitations
- Data generation details (e.g., exact lag coefficient distribution, autocorrelation sampling) are underspecified, hindering exact replication.
- Grow-shrink trees cache O(2^{p}) scores; with p = m·τ_max, memory may explode for realistic multivariate series.
- Theoretical guarantees require strict conditions (stationarity, sufficiency, correct τ_max, consistent scores) often violated in practice.

## Confidence
- **Theoretical soundness under stated assumptions:** High
- **Superior adjacency recall in high autocorrelation synthetic experiments:** Medium
- **Scalability and efficiency claims:** Medium
- **Applicability to real-world, possibly non-stationary data:** Low
