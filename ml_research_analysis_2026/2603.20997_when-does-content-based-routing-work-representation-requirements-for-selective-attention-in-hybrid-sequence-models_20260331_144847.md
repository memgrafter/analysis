# When Does Content-Based Routing Work? Representation Requirements for Selective Attention in Hybrid Sequence Models

## Quick Facts
- arXiv ID: 2603.20997
- Source URL: https://arxiv.org/abs/2603.20997
- Reference count: 36
- Primary result: One layer of softmax attention creates a latent ~34-dimensional subspace enabling 98.4% routing precision, while zero layers yield only 1.2%, establishing a two-regime hierarchy for content-based routing.

## Executive Summary
This paper investigates the conditions under which content-based routing succeeds in hybrid recurrent-attention architectures, addressing the 'routing paradox'—the apparent need to avoid expensive pairwise computations while relying on them implicitly. Through over 20 controlled experiments using a modular FCI test bed across synthetic, MQAR, and HotpotQA tasks, the authors map the routing landscape and discover a sharp two-regime hierarchy. With at least one softmax attention layer, a latent ~34-dimensional subspace emerges via value aggregation, enabling near-perfect (98.4%) routing precision; without attention, precision remains at chance levels (~1.2%). Non-learned indices like Bloom filters and BM25 achieve high precision for exact/keyword matching, but learned routers fail unless provided with attention-transformed representations. These results reframe attention as a representation constructor that embeds relational structure into token embeddings, fundamentally shaping the design of efficient hybrid sequence models.

## Method Summary
The authors use a modular hybrid architecture called FCI (Flow, Council, Investigator) to isolate the effects of representation and routing mechanisms. The Flow processes the sequence, the Investigator scores and selects tokens for routing, and the Council performs sparse attention on selected tokens. They systematically vary the presence of a softmax attention preprocessing layer and the type of router (learned projections, bandits, linear attention, etc.) across three tasks: synthetic exact-match, MQAR (multi‑query associative recall), and HotpotQA (semantic QA). Routing precision is measured against ground‑truth token selections. This setup allows controlled analysis of how representation quality, as influenced by attention, impacts the success of content‑based routing. The investigation includes ablations such as random projections, contrastive pretraining, and non‑learned indices (Bloom filter, BM25) to understand the necessity of value aggregation and the limits of pairwise similarity.

## Key Results
- **Attention subspace:** One softmax attention layer induces a latent ~34‑dimensional subspace (via value aggregation) that yields 98.4% routing precision; without it, precision is only 1.2%.
- **Non‑learned indices:** For exact/keyword matching, Bloom filters (90.9%) and BM25 (82.7%) achieve high precision without learned representations.
- **Alternative mechanisms:** Twelve learned routing strategies (including recurrence, linear attention, and bandits) consistently perform poorly (15–29%), and contrastive pretraining also fails (1.6–2.2%).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** One layer of softmax attention creates a latent ~34-dimensional subspace via value aggregation that enables high-precision (98.4%) content-based routing, whereas zero layers yield only 1.2% precision.
- **Mechanism:** Attention computes pairwise matching scores (QK⊤) and aggregates matching values (softmax(QK⊤/√d)V) into each token’s representation. This writes relational information into the embeddings, forming a low‑dimensional subspace that a learned router can read via linear projections.
- **Core assumption:** The router operates on representations already transformed by at least one softmax attention layer; without this transformation, the matching signal is absent.
- **Evidence anchors:**
  - Abstract: “One layer of softmax attention creates a latent ∼34-dimensional subspace enabling 98.4% routing precision; zero layers yield 1.2%.”
  - Section 4.2: “SVD reveals the combined routing matrix WqWk⊤ concentrates 90% of its energy in 34 of 128 dimensions.”
  - Corpus: Includes work on content‑based routing that relies on attention (e.g., *Mixture of Sparse Attention: Content‑Based Learnable Sparse Attention via Expert‑Choice Routing*), consistent with attention’s central role.
- **Break condition:** Removing the attention layer or destroying the subspace (e.g., applying random projections to the representations) reduces routing precision to chance levels (~2.6%).

### Mechanism 2
- **Claim:** For exact or keyword matching, non‑learned indices (Bloom filter: 90.9%, BM25: 82.7%) achieve high routing precision without any learned representations, completely bypassing the representation bottleneck.
- **Mechanism:** They operate directly on raw token identities or lexical overlap (e.g., set membership for Bloom filters, term frequency for BM25), avoiding the need for relational embeddings.
- **Core assumption:** The matching criterion is symbolic (exact token match, keyword overlap). Semantic similarity beyond this cannot be captured.
- **Evidence anchors:**
  - Abstract: “Non‑learned indices (Bloom filter: 90.9%; BM25: 82.7%) succeed for exact/keyword matching.”
  - Section 4.3: “Bloom filter achieves 90.9% with zero learned parameters… BM25 achieves 82.7% on HotpotQA.”
  - Corpus: Evidence for exact‑match routing is strong in the retrieval literature, but the specific numbers come from the paper; the corpus provides general context but not direct quantitative support.
- **Break condition:** When the task requires semantic matching (e.g., paraphrases), non‑learned indices degrade sharply, and the gap to attention‑based routing reappears.

### Mechanism 3
- **Claim:** Contrastive pretraining (InfoNCE) fails to create the latent subspace needed for routing (1.6–2.2% precision), proving that pairwise comparison alone is insufficient; value aggregation is the critical component of attention.
- **Mechanism:** Contrastive loss supervises only the first step of attention (pairwise similarity). Without the third step—writing match results back into representations via value aggregation—the embeddings lack the relational structure that the router requires.
- **Core assumption:** The router’s signal depends on representations that have been *transformed* to encode pairwise relationships, not just on raw token similarities.
- **Evidence anchors:**
  - Abstract: “This signal … cannot be recreated by contrastive pretraining.”
  - Section 4.4: “Contrastive pretraining achieves only 1.6–2.2%, no improvement over the 1.2% baseline.”
  - Corpus: Corpus evidence for this negative result is absent; it is a novel finding specific to this work.
- **Break condition:** If the pretraining objective does not include a value‑aggregation style operation (e.g., only contrastive or only reconstruction), the latent subspace does not form and routing fails.

## Foundational Learning
### Concept: Attention as a representation constructor
Why needed here: The paper shifts the view of attention from a computation that combines information to a mechanism that *writes* relational structure into embeddings. This is key to understanding why routing works only after attention.
Quick check question: What is the difference between a representation that contains information and one that encodes relationships?

### Concept: Routing paradox
Why needed here: The paradox—that learned routing requires the pairwise computation it is meant to avoid—explains the fundamental limitation of hybrid architectures and motivates the two‑regime hierarchy.
Quick check question: Why does content‑based routing inherently need the same pairwise interactions that expensive attention computes?

### Concept: Latent subspace and linear probing
Why needed here: The routing signal lives in a low‑dimensional subspace invisible to full‑space metrics like cosine similarity; probing requires the correct learned projections. This explains why random projections destroy the signal.
Quick check question: How can information be present in an embedding yet undetectable by simple similarity measures?

## Architecture Onboarding
### Component Map
Token embeddings → Flow (recurrent backbone) → [Optional: 1× Transformer layer] → Investigator (router) → Council (sparse attention + FFN) → Prediction head

### Critical Path
1. Token embeddings are processed by Flow to produce recurrent states.
2. (Optional) One Transformer layer preprocesses states into relational embeddings.
3. Investigator computes routing scores on the preprocessed states via dot product of learned query/key projections.
4. Top‑k selection (with neighbor expansion) determines which positions Council will attend.
5. Council’s sparse attention aggregates information from selected positions; a feed‑forward network refines the representation.
6. The final token representation is fed to the prediction head to produce the output.

### Design Tradeoffs
- **Preprocessing layers:** Adding one Transformer layer dramatically improves routing precision (1.2% → 98.4%) but introduces O(n²) cost.
- **Router dimensionality:** The effective signal occupies ~34 of 128 dimensions; overly aggressive dimensionality reduction risks losing the routing signal.
- **Granularity:** Token‑level routing offers high precision; segment‑level (e.g., sentence‑level) is computationally cheaper but may miss fine‑grained matches.
- **Non‑learned vs. learned indices:** Non‑learned indices (Bloom filters, BM25) are efficient and precise for symbolic matching but cannot handle semantic similarity; learned routers with attention handle semantics but at higher compute cost.

### Failure Signatures
- Routing precision near chance (≤2%) indicates the absence of the attention‑created latent subspace.
- Negative cosine similarity gap between matching tokens; SVD shows no concentrated energy in a few dimensions.
- Contrastive pretraining does not improve routing over raw recurrent states.
- Bandit‑based routers (LinUCB, Thompson Sampling) uniformly fail regardless of representation quality.

### First 3 Experiments
1. **Baseline:** Route using 0 Transformer layers (raw embeddings or Flow states). Expected precision ≈1.2%.
2. **Add preprocessing:** Introduce 1 Transformer layer before routing. Expected precision jumps to ≈98.4%, confirming the phase transition.
3. **Random projections:** Keep 1 Transformer layer but replace the router’s learned Wq and Wk with random matrices. Expected precision drops to ≈2.6%, proving the signal resides in a specific learned subspace.

## Limitations
- Generalization limited to synthetic, MQAR, and HotpotQA tasks; applicability to other domains (e.g., code, multilingual) remains unknown.
- Contrastive pretraining evaluated only with InfoNCE; other self‑supervised objectives might yield different results.
- The identified subspace dimensionality (~34) is based on a hidden size of 128; scaling behavior with larger models is unexplored.

## Confidence
- **High:**
  - One softmax attention layer creates a latent subspace enabling 98.4% routing precision (vs. 1.2% with zero layers).
  - Non‑learned indices (Bloom filter, BM25) achieve high precision for exact/keyword matching.
  - A sharp two‑regime hierarchy exists for learned content‑based routing.
- **Medium:**
  - Contrastive pretraining fails to induce the subspace (1.6–2.2% precision).
  - Twelve alternative mechanisms (recurrence, linear attention, bandits) cluster at 15–29% routing precision.

## Next Checks
1. Cross‑architecture replication: Implement the FCI test bed with alternative recurrent backbones (e.g., S4, Mamba) and transformer variants to verify subspace emergence and scaling laws.
2. Diverse task evaluation: Test on additional semantic matching tasks (e.g., natural language inference, code search) to confirm the two‑regime pattern beyond the current dataset suite.
3. Contrastive variant analysis: Train contrastive models that incorporate explicit value‑aggregation (e.g., via cross‑attention decoder) and measure routing precision; low performance would further support the insufficiency of pairwise comparison.
