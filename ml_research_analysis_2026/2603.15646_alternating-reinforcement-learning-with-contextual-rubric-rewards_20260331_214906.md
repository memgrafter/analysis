# Alternating Reinforcement Learning with Contextual Rubric Rewards
## Quick Facts
- **arXiv ID:** 2603.15646  
- **Source URL:** https://arxiv.org/abs/2603.15646  
- **Reference count:** 34  
- **Primary result:** ARL-RR uniformly outperforms scalarized RLRR baselines across model scales (1.7B–14B), e.g., Qwen3-4B achieves 0.716 vs. 0.690.

## Executive Summary
The paper addresses a key limitation in Reinforcement Learning with Rubric Rewards (RLRR): fixed linear scalarization of multi-dimensional rubric rewards reduces the variance of the learning signal and fails to capture correlations between evaluation criteria. To solve this, the authors propose Alternating Reinforcement Learning with Rubric Rewards (ARL-RR), which decomposes rubric criteria into semantic meta-classes (e.g., accuracy, completeness) and optimizes them alternately during RL training. This eliminates scalarization, preserving signal variance and forcing the policy to learn each objective explicitly. On the HealthBench medical dataset, ARL-RR consistently achieves higher evaluation scores than scalarized baselines across model sizes from 1.7B to 14B parameters. Theoretical analysis proves scalarization contracts reward variance, and empirical measurements confirm this effect. A lightweight search-based adaptation further optimizes the meta-class order, yielding additional gains.

## Method Summary
ARL-RR first groups rubric criteria into semantic meta-classes (e.g., accuracy, completeness) using expert labels or synthetic LLM classification. During training with Group Relative Policy Optimization (GRPO), the policy is updated using a reward computed solely from the active meta-class at each stage. The training schedule cycles through all meta-classes, either in a fixed order or via a dynamic search that evaluates each class on a small data subset to select the next one. This alternation transforms the multi-objective problem into a sequence of single-objective sub-problems, ensuring that improvements in one dimension are not masked by failures in another. The total number of updates matches scalarized RLRR baselines for fair comparison. A meta-class reward aggregates weighted binary judgments for criteria within that class, normalized by the sum of weights, as provided by a rubric reward model (e.g., Qwen3-32B).

## Key Results
- ARL-RR uniformly surpasses scalarized RLRR across model scales: Qwen3-4B improves from 0.690 to 0.716, with similar gains for 1.7B, 8B, and 14B variants.
- Rollout reward variance analysis validates the core mechanism: scalarized reward variance is 0.10, while individual meta-class variances range 0.16–0.20, confirming scalarization contracts signal.
- Lightweight search-based adaptation further enhances performance; with p=20% subset search, Qwen3-4B score increases from 0.712 (fixed order) to 0.738, at ~20% additional compute cost.

## Why This Works (Mechanism)
**Mechanism 1: Scalarization contracts reward variance, weakening RL signal.** Linear scalarization averages meta-class rewards; under imperfect correlation (ρ < 1), this averaging reduces variance compared to any individual meta-class. Lower variance makes it harder for group-based policy gradient methods (like GRPO) to distinguish high-quality from mediocre rollouts, impairing credit assignment. Evidence: Theorem 3.1 formally proves variance contraction; Table 2 empirically shows scalarized variance = 0.10 vs. 0.16–0.20 for meta-classes. Break condition: if meta-class rewards are perfectly correlated (ρ = 1), variance contraction does not occur.

**Mechanism 2: Alternating optimization prevents objective collapse.** By decomposing criteria into distinct meta-classes and optimizing one at a time, ARL forces the policy to learn the nuances of each dimension explicitly. This prevents the model from sacrificing a harder objective (e.g., accuracy) to maximize an easier one (e.g., completeness), which can happen under joint scalarized optimization. Evidence: The abstract states ARL "forces the policy to learn the nuances... preventing the model from maximizing an easy metric... to mask failures." Section 3.1 details the alternation process. Break condition: if meta-classes are perfectly aligned (highly correlated), alternation offers no benefit over joint optimization.

**Mechanism 3: Search-based adaptation dynamically prioritizes critical meta-classes.** A lightweight search at each training level uses a small data subset (p%) to evaluate all remaining meta-classes and selects the one with best performance for full-data training. This constructs an optimized order, allowing the policy to focus on objectives that yield the greatest improvement at each stage. Evidence: Section 4.5 describes the search; Table 4 shows score improvement from 0.712 to 0.738 with p=20%. Break condition: if the small subset is unrepresentative or performance estimates are noisy, search may select suboptimal orders.

## Architecture Onboarding
Actor Model -> Rubric Reward Model -> Meta-Class Decomposer -> [Search Module (optional)] -> RL Optimizer (GRPO).  
Critical path:  
1. For a batch of prompts, obtain full rubric annotations (weights wk and binary judgments ck).  
2. Decompose criteria into M meta-classes Cm using expert labels or synthetic classification.  
3. Determine training schedule: fixed order or dynamic via search.  
4. For each training stage t:  
   a. Set active meta-class m.  
   b. Sample G rollouts from current policy.  
   c. Compute active meta-class reward rm for each rollout.  
   d. Calculate group advantages Ai = (ri - mean(rm)) / std(rm).  
   e. Perform GRPO update with KL penalty.  
5. If using search, after full-data training on selected meta-class, repeat with remaining classes via search.  
Design tradeoffs:  
- Fixed vs Dynamic Order: Fixed is simpler but suboptimal; dynamic search adds overhead but improves final score.  
- Meta-Class Granularity: Coarser classes reduce compute but lose nuance; finer partition risks over-partitioning and higher variance.  
- Synthetic vs Expert Meta-Classes: Synthetic avoids human annotation but introduces noise, slightly hurting performance.  
Failure signatures:  
- Poor meta-class definition: overlapping or unclear classes cause inconsistent signals.  
- High correlation between meta-classes: if ρ ≈ 1, ARL's benefits vanish.  
- Search instability: with small p% or noisy estimates, order may flip-flop.  
- Reward model bias: systematic errors mislead meta-class optimization.  
First 3 experiments:  
1. Reproduce variance contraction with frozen policy, sample G=16 rollouts, compare variances.  
2. Test fixed order sensitivity: train ARL with at least three different orders, compare scores and curves.  
3. Implement and evaluate search: run with p ∈ {10%, 20%, 30%}, record score and time overhead.

## Limitations
- Replication is hindered by unspecified details: exact training duration, handling of zero-denominator meta-class rewards, and precise baseline configuration.
- Performance gains diminish if meta-class rewards are highly correlated (ρ ≈ 1) or if synthetic meta-classification is too noisy.
- The framework relies on a high-fidelity reward model; systematic biases may mislead alternating optimization.

## Confidence
- Claim 1 (Scalarization contracts variance): High confidence (Theorem 3.1 and Table 2 support).
- Claim 2 (Alternation prevents collapse): Medium confidence (depends on non-aligned meta-class dynamics; break condition if highly correlated).
- Claim 3 (Search adaptation improves performance): Medium confidence (empirical gains but depends on subset representativeness; break condition if noisy).
