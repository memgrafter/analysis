# Implicit Style Conditioning: A Structured Style-Rewrite Framework for Low-Resource Character Modeling

## Quick Facts
- **arXiv ID:** 2603.05933
- **Source URL:** https://arxiv.org/abs/2603.05933
- **Reference Count:** 40
- **Primary Result:** A 1.7B model achieves a Valid Style Score of 0.569—a 56% improvement over a 4B vanilla SFT baseline—while preserving semantic fidelity (Semantic Score >0.83).

## Executive Summary
Low-resource character modeling—creating stylized dialogue for fictional personas with limited data—suffers from out-of-character generation in small language models. This work introduces a structured style-rewrite framework that decomposes character style into lexical, syntactic, and pragmatic components. By training with Chain-of-Thought (CoT) supervision and a context-aware style refiner to handle noisy labels, the model learns implicit style conditioning. Evaluations on anime characters show substantial gains in style intensity without sacrificing semantic faithfulness, enabling high-fidelity character modeling on consumer hardware.

## Method Summary
The pipeline begins by extracting a structured style vector **S** from a small character corpus. Lexical style is captured via TF-PMI keywords, syntactic style via aggregated PCFG rule frequencies into 13 dimensions, and pragmatic style via a context-aware multi-label classifier (the style refiner). Synthetic parallel data are then created: original stylized utterances are neutralized (via an LLM), and the neutral sentences are rewritten back into the target style conditioned on **S**, with CoT traces explaining the transformation. A 1.7B backbone (Qwen-1.7B) is fine-tuned with LoRA using a multi-task loss (language modeling, syntactic reconstruction, pragmatic classification) on these synthetic pairs. At inference, only the neutral input and the target **S** are provided; no explicit CoT tokens are generated.

## Key Results
- Valid Style Score of 0.569 (+56% relative to 4B SFT baseline) with Semantic Score >0.83.
- Under a strict semantic threshold (0.80), performance drops only 12% vs. ~50% for baselines.
- Human evaluation: Semantic Faithfulness 4.24, Style Intensity 3.51 (5-point scale).

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Disentangling character style into lexical, syntactic, and pragmatic components yields a controllable style vector that reduces interference between style aspects and preserves semantic content.  
**Mechanism:** The framework extracts each component separately: TF‑PMI for lexical keywords, PCFG rule frequencies for syntax, and a context‑aware multi‑label classifier for pragmatics. These are concatenated into a structured vector **S** that conditions generation via a learnable style prefix. Multi‑task auxiliary losses enforce that the prefix encodes each aspect faithfully.  
**Core assumption:** Style dimensions are approximately separable and the chosen statistical features capture essential variation.  
**Evidence anchors:** [abstract] “explicitly disentangles style into three interpretable dimensions…”; [section 3.2] extraction details; [Table 2] Model v2 achieves higher Valid Style Score than baselines.  
**Break condition:** If a character’s style relies on subtle cross‑dimensional interactions (e.g., sarcasm depending on word choice and syntax), the disentangled representation may fail. If TF‑PMI or PCFG features are not discriminative, the style vector loses signal.

### Mechanism 2
**Claim:** Chain‑of‑Thought (CoT) supervision during training acts as an inductive bias that aligns the model’s latent representations with structured style features, enabling implicit style conditioning at inference without explicit reasoning tokens.  
**Mechanism:** Each training example includes a CoT trace explaining the neutral→stylized transformation. The model is trained with the standard language modeling loss on both the trace and the final output, forcing internalization of the reasoning process. After training, the model generates stylized outputs directly.  
**Core assumption:** The CoT traces provide a correct and generalizable decomposition, and model capacity is sufficient.  
**Evidence anchors:** [abstract] “implicit style conditioning strategy via Chain‑of‑Thought (CoT) distillation…” ; [section 3.3.3] formal CoT supervision; [Table 2 & Figure 2] Model v2 (Inference‑only) reaches Valid Style 0.569 with Semantic >0.83.  
**Break condition:** If CoT traces lack diversity or coverage, the model may not learn robust implicit conditioning. For extreme pragmatic inversion (e.g., strong tsundere), explicit reasoning might still be necessary at inference.

### Mechanism 3
**Claim:** A context‑aware style refiner corrects noisy pseudo‑labels in low‑resource settings by combining clustering‑based style prototypes with contextual embeddings, yielding reliable pragmatic style supervision.  
**Mechanism:** The refiner (lightweight MLP) takes an utterance embedding, its dialogue context embedding, and a cluster‑based style prototype, and predicts a multi‑label style distribution. Trained on a small manually annotated set (731 samples) with weighted binary cross‑entropy, it generates the pragmatic component of **S**.  
**Core assumption:** Style prototypes capture central tendencies, and context resolves ambiguities (same phrase may convey different styles).  
**Evidence anchors:** [abstract] “Context‑Aware Style Refiner mitigates label noise…” ; [Appendix E.3 & E.5] architecture and macro‑F1=0.79 vs. 0.10 for centroid‑only; [Table 13] corpus‑level pragmatic profiles show distinct distributions.  
**Break condition:** If clustering prototypes are biased/unrepresentative, the refiner propagates errors. If the context encoder fails to capture pragmatic cues, refinement is ineffective.

## Architecture Onboarding

**Component map:**  
Style Extractor (computes lexical, syntactic, pragmatic components) → Structured Style Vector **S** → Rewrite Engine (Qwen-1.7B + LoRA, conditioned on **S**) → Training Pipeline (synthetic data generation with CoT, multi-task loss) → Inference Module (style prefix injection, no CoT).

**Critical path:**  
1. Collect small character corpora (25–200 utterances).  
2. Extract **S** using TF-PMI, PCFG aggregation, and style refiner.  
3. Construct training data: neutralize original utterances via LLM; rewrite neutrals into stylized outputs conditioned on **S** with CoT traces.  
4. Fine-tune Qwen-1.7B with LoRA, using **S** as prefix and multi-task loss.  
5. At inference, given new neutral input and target **S**, generate stylized output without CoT.

**Design tradeoffs:**  
- Disentanglement vs. completeness: Using only 13 PCFG dimensions covers ~80% of rules but may miss rare patterns; more dimensions risk overfitting and reduce interpretability.  
- CoT supervision vs. inference cost: Adding CoT traces increases training compute but removes test‑time reasoning, yielding faster inference.  
- Style refiner complexity: The MLP adds minimal overhead but requires a small gold dataset (731); a simpler centroid approach fails (F1=0.10), so context is essential but depends on contextual embeddings.

**Failure signatures:**  
- Semantic drift: High Style Score but low Semantic Score (<0.75) indicates memorization over rewriting.  
- Low Valid Style Score under strict semantic threshold (τ=0.80) suggests the model sacrifices style for semantics or has a weak style vector.  
- Pragmatic classification degradation: If the style refiner’s macro‑F1 drops on validation, label noise is likely harming performance.  
- Inference‑only degradation: If disabling CoT at inference causes a large drop, implicit conditioning was not learned.

**First 3 experiments:**  
1. **Baseline replication:** Train vanilla SFT (Baseline C) on same synthetic data without disentanglement/CoT; verify lower Valid Style Score.  
2. **Ablation – style dimensions:** Remove one component (lexical, syntactic, pragmatic) from conditioning at inference; measure drop in Style Score (Table 5).  
3. **Implicit conditioning test:** Compare Model v2 (Inference‑only) vs. Model v2 (with CoT at inference); also compare against a model trained without CoT supervision.

## Open Questions the Paper Calls Out
1. How can we incorporate long-term memory and dynamic style adjustments to maintain character consistency across multi-turn dialogues?
2. How can we capture subtle stylistic phenomena such as sarcasm, wordplay, and culturally specific metaphors in low-resource character modeling?
3. How can we generate or obtain truly neutral source sentences to avoid implicit style bias in training data?
4. How can we develop more objective evaluation metrics that reliably detect style hallucination and balance fluency and faithfulness?
5. How can we establish a consistent, quantifiable standard for evaluating character style fidelity to reduce subjectivity in human evaluations?

## Limitations
- **Style Refiner reproducibility:** Clustering method, prototype updates, and threshold selection unspecified; 731-sample gold set splits not released.
- **PCFG mapping opacity:** 48‑rule‑to‑13‑dim mapping lacks linguistic justification; 79.5% coverage claim is corpus‑agnostic.
- **CoT trace generation:** Few‑shot examples omitted; reproduction of trace distribution uncertain.

## Confidence
- **Disentanglement (Mechanism 1):** Medium. Ablations show per‑dimension contribution, but cross‑dimensional interactions not fully explored.
- **CoT supervision (Mechanism 2):** High. +56% Valid Style improvement with strong semantic preservation confirms effect.
- **Style Refiner (Mechanism 3):** Medium‑High. Macro‑F1=0.79 vs. 0.10 proves context utility, but depends on cluster quality and small gold set.

## Next Checks
1. **CoT ablation:** Train without CoT traces; compare implicit generation to confirm inductive bias.
2. **Disentanglement stress test:** On sarcasm‑heavy characters, ablate each style component and measure style integrity.
3. **Refiner reproduction:** Retrain from 731 samples with described MLP; ablate context input to validate its necessity.
