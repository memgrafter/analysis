# Federated Proximal Optimization for Privacy-Preserving Heart Disease Prediction: A Controlled Simulation Study on Non-IID Clinical Data

## Quick Facts
- arXiv ID: 2601.17183
- Source URL: https://arxiv.org/abs/2601.17183
- Reference count: 40
- Primary result: FedProx achieves 85.00% accuracy, exceeding centralized learning (83.33%) and isolated local models (78.45% average), while reducing cross-hospital performance variance by 56%.

## Executive Summary
This study investigates Federated Proximal Optimization (FedProx) for heart disease prediction in a privacy-preserving federated learning setting. Using the UCI Cleveland dataset, the authors simulate four heterogeneous hospitals via demographic stratification to mimic real-world statistical heterogeneity. FedProx introduces a proximal regularization term to local training objectives, mitigating "client drift" caused by non-IID data. With optimal hyperparameter µ=0.05, FedProx surpasses both centralized training and standard Federated Averaging (FedAvg) in accuracy, convergence speed, and fairness across clients. The work demonstrates that carefully regularized federated learning can not only match but exceed centralized performance under heterogeneity, offering a viable path for collaborative healthcare AI without data sharing.

## Method Summary
The method employs FedProx, an extension of Federated Averaging, which modifies each client's local optimization problem by adding a proximal term: `min_w h_k(w; w^t) = F_k(w) + (µ/2)||w - w^t||²`. This penalizes deviations of the local model `w` from the current global model `w^t`, thereby constraining local updates to remain similar to the global consensus while still allowing adaptation to local data. Experiments are conducted on the UCI Cleveland heart disease dataset (293 patients). To simulate a federated environment with four hospitals, the dataset is partitioned by sorting patients by age and creating four overlapping age windows with random subsampling. This induces heterogeneity in age distribution (18-year span), disease prevalence (26.2 percentage point variance), and sample size (2.5× imbalance). Models are logistic regression classifiers, trained over multiple communication rounds with hyperparameter µ varied across {0, 0.01, 0.05, 0.1, 0.5}. Performance is evaluated on global accuracy, per-client accuracy, convergence speed, and stability across 50 randomized seeds.

## Key Results
- FedProx with µ=0.05 achieves 85.00% accuracy, outperforming centralized learning (83.33%) and FedAvg (83.90%).
- FedProx converges 18% faster than FedAvg (reaching 95% of final accuracy in ~18 vs. ~22 rounds).
- Cross-hospital performance variance is reduced by 56% compared to FedAvg, demonstrating improved fairness.

## Why This Works (Mechanism)
### Mechanism 1
FedProx mitigates client drift caused by non-IID clinical data by constraining local model updates to remain proximal to the global model. During local training, the proximal term `(µ/2)||w - w^t||²` penalizes deviations from the global model `w^t`, pulling local solutions toward consensus while permitting adaptation to local patterns. Evidence includes the abstract's explicit claim, the mathematical formulation in section 2.3, and the degradation of performance when µ is too large (over-constraint) or too small (insufficient regularization). The core assumption is that unconstrained local updates in heterogeneous settings diverge across clients, preventing global convergence. Break condition: µ > optimal (e.g., 0.5) suppresses local learning and harms accuracy.

### Mechanism 2
The controlled simulation methodology—demographic-based stratification of a single-institution dataset—creates realistic non-IID partitions that mimic multi-hospital heterogeneity. By sorting the Cleveland data by age and defining four overlapping windows with random subsampling, the authors induce heterogeneity in age distribution, disease prevalence, and sample size. This allows reproducible evaluation without actual multi-institutional data. Evidence is in section 3.2 (partitioning algorithm) and 3.3 (quantitative heterogeneity metrics: 18-year age span, 26.2 pp prevalence variation, Gini=0.235). Break condition: if the base dataset lacks demographic diversity, the induced heterogeneity will not reflect real-world hospital variation.

### Mechanism 3
FedProx's proximal regularization enables the global model to surpass centralized performance through an implicit ensemble effect. The proximal term allows each hospital to learn locally relevant patterns (e.g., age-specific presentations) without catastrophic deviation. During aggregation, the weighted average combines these specialized views into a more robust predictor than a single centralized model trained on the pooled data, which may suffer from conflicting signal dilution. Evidence includes the abstract's accuracy comparison and section 6's contribution on implicit ensembling. Break condition: if local distributions are non-overlapping (disjoint feature spaces), specialization may harm global generalization and the benefit over centralized would vanish.

## Architecture Onboarding
**Component map:**  
Central Server <-> Client Hospitals (K nodes, each with dataset D_k)  
Data Partitioning Module -> Client Hospitals (provides heterogeneous D_k)  
Evaluation Harness <- Central Server (receives final global model w^T, computes metrics)

**Critical path:**  
Initialize global model w^0 → For each communication round t: Server broadcasts w^{t-1} to all clients → Each client runs ProximalClientUpdate(w^{t-1}, µ) → Clients send updated local models w_k^t to server → Server aggregates: w^t = Σ (n_k/n) * w_k^t → Log metrics → Repeat until convergence → Return final w^T.

**Design tradeoffs:**  
- µ tuning: Low µ risks client drift; high µ over-constrains and slows convergence. Optimal µ=0.05 found via grid search.  
- Model simplicity: Logistic regression chosen for interpretability vs. potential accuracy gains from deep networks.  
- Simulation fidelity: Demographic stratification offers reproducibility but cannot model institutional measurement biases or geographic factors.

**Failure signatures:**  
- Accuracy decreases as µ increases beyond optimum (e.g., µ=0.5).  
- High variance in per-client accuracy indicates poor fairness/high drift.  
- Oscillating convergence curve (as in FedAvg) signals unmitigated client drift.  
- Mismatch between simulated partition statistics and real-world heterogeneity ranges may invalidate conclusions.

**First 3 experiments:**  
1. Replicate Table 2: Train FedAvg (µ=0) and FedProx (µ=0.05) for 50 seeds; confirm FedProx mean accuracy > centralized baseline with statistical significance (t-test, p<0.01).  
2. Ablation over µ: Grid search µ ∈ {0, 0.01, 0.05, 0.1, 0.5}; plot accuracy vs. µ, verify inverted-U curve and optimum at µ=0.05.  
3. Convergence speed test: Record accuracy per round for FedAvg vs. FedProx; compute rounds to reach 95% of final accuracy; expect FedProx ~18% faster (18 vs. 22 rounds).

## Open Questions the Paper Calls Out
- How does FedProx's performance degrade when applied to truly distributed multi-institutional clinical data, as opposed to single-institution simulated partitions?
- Does the identified optimal proximal parameter (µ=0.05) and the overall efficacy of FedProx generalize to modern, large-scale clinical datasets and deep learning architectures for medical imaging or time-series data?
- Can incorporating formal differential privacy (DP) mechanisms into FedProx maintain its performance advantages while providing verifiable, mathematical privacy guarantees against gradient leakage attacks?
- How does the performance gap between local-only models and the federated global model change as the number of participating hospitals scales from 4 to dozens or hundreds, and how does this impact the practical value proposition of federated learning?
- Does FedProx's proximal regularization introduce unintended biases or reduce model fairness for underrepresented patient subgroups (e.g., by race, socioeconomic status) when applied to demographic-stratified non-IID data?

## Limitations
- Simulation fidelity: Non-IID partitions derived from a single-institution dataset via age stratification may not capture real-world hospital heterogeneity (e.g., measurement bias, geographic disease patterns).
- Model simplicity: Logistic regression limits ability to assess FedProx under complex, non-linear clinical relationships; conclusions may not generalize to deep learning architectures.
- Implicit ensemble effect hypothesis: The claim that FedProx surpasses centralized training via *implicit ensembling* is inferred but not directly validated (e.g., no ablation to isolate specialization benefits).

## Confidence
- FedProx > centralized/FedAvg in accuracy: Medium (validated on one dataset with simulated heterogeneity; external validation needed).
- Client drift mitigation via proximal term: High (supported by hyperparameter ablation and convergence analysis).
- Implicit ensemble benefit over centralized: Low (plausible but not experimentally isolated; alternative explanations possible).
