# Deep reflective reasoning in interdependence constrained structured data extraction from clinical notes for digital health

## Quick Facts
- **arXiv ID:** 2603.20435
- **Source URL:** https://arxiv.org/abs/2603.20435
- **Reference count:** 0
- **Primary result:** An iterative LLM-agent framework that enforces consistency among interdependent variables improves extraction accuracy across three oncology tasks (e.g., CRC categorical F1 from 0.828 to 0.911).

## Executive Summary
Clinical notes contain critical but unstructured data. Extracting structured variables that are logically interdependent (e.g., tumor size, location, and stage) is error-prone for standard LLM queries, which often produce inconsistent outputs. This paper proposes **deep reflective reasoning**, an LLM-agent framework where the model iteratively self-critiques its prior extractions against the source text and domain knowledge, revising all variables together until outputs converge. Evaluated on colorectal, sarcoma, and lung cancer reports, the method significantly boosts accuracy and consistency, demonstrating a viable path toward reliable automated data structuring for digital health.

## Method Summary
The approach extends a baseline retrieval-augmented generation (RAG) pipeline. Initially, each clinical variable is extracted independently using a prompt that includes the relevant note section and retrieved domain knowledge (e.g., CAP guidelines). For deep reflective reasoning, the LLM agent enters an iterative loop: in each round, it reviews its previous `p` rounds of full outputs (the "back-view"), identifies inconsistencies between its extractions and the source text (Type 1) or among the extracted variables themselves (Type 2), and revises all variable values in a single JSON-structured response. The process stops when all variable values exactly match the prior round (convergence) or a maximum number of rounds `m` is reached. Temperature is set to 0 for determinism; no external supervision is used.

## Key Results
- Colorectal cancer synoptic reporting (n=217): average F1 for eight categorical variables improved from 0.828 (baseline) to 0.911 (reflective); numeric correct rate from 0.806 to 0.895.
- Ewing sarcoma CD99 immunostaining (n=200): accuracy improved from 0.870 to 0.927.
- Lung cancer staging (n=100): overall stage accuracy from 0.680 to 0.833; pT from 0.842 to 0.884; pN from 0.885 to 0.948.

## Why This Works (Mechanism)
Interdependent clinical variables form a constraint network; a value for one variable (e.g., tumor size) logically restricts possible values for others (e.g., T stage). Standard single-query extraction ignores these links, allowing inconsistent triples to pass. Deep reflective reasoning forces the LLM to explicitly consider the entire set of variables as a unified, interdependent structure. By repeatedly comparing the current set against the source text and formal domain rules, the agent can detect and resolve local contradictions that are invisible in isolation. Convergence acts as a consistency heuristic: stable outputs suggest a self-consistent state that aligns with both text and knowledge constraints.

## Foundational Learning
- **Interdependency Constraints:** Why needed: Clinical variables are not independent; rules (e.g., staging systems) create hard/soft constraints. Quick check: List all constraint pairs (e.g., if "Tumor Site=colon" then "Primary Tumor Type=adenocarcinoma").
- **Retrieval-Augmented Generation (RAG):** Why needed: LLMs lack up-to-date, specialized medical knowledge. Quick check: Verify retrieved knowledge chunks contain the specific rule (e.g., "T2: tumor invades submucosa") used in a sample extraction.
- **Iterative Self-Critique / Reflection:** Why needed: One-pass extraction is often overconfident and erroneous. Quick check: For a failed case, inspect the LLM's cited evidence in round 1 vs. round 3; does it correct a misattributed text span?
- **Convergence Criterion:** Why needed: Provides a stopping condition implying internal consistency. Quick check: Track a case where values flip between two states (oscillation); note the round where it stabilizes or times out.
- **Domain Knowledge Packaging:** Why needed: Rules must be presented in a parseable, relevant format (e.g., section-level CAP guidelines). Quick check: Ensure a knowledge file includes the exact variable values and rules for the target template (e.g., synoptic report options).

## Architecture Onboarding
### Component Map
Clinical Note -> RAG (Knowledge Retrieval) -> Baseline One-by-One Extraction -> Reflection Loop [History Review -> Inconsistency Detection -> Joint Revision] -> Convergence Check -> Converged Structured JSON Output

### Critical Path
1.  Receive a clinical note and a variable template.
2.  Retrieve relevant knowledge sections (LlamaIndex).
3.  Generate baseline: query each variable independently.
4.  Enter reflection: for round `t>1`, construct prompt with note, knowledge, template, and previous `p` JSON outputs.
5.  LLM revises all variables; compare new JSON to round `t-1`. If identical, stop; else repeat up to `m`.

### Design Tradeoffs
- **Determinism vs. Creativity:** Temperature=0 ensures reproducibility but may limit exploration of alternative consistent states.
- **Back-view Length (`p`):** Larger `p` provides more revision history for conflict detection but increases prompt length and cost; optimal `p` is task-specific (e.g., 10 for lung cancer, 2 for CD99).
- **Convergence Strictness:** Exact string match is simple but brittle to minor phrasing changes in LLM explanations; a semantic match might be more robust but is not implemented.

### Failure Signatures
- **Oscillation:** A variable value alternates between two states across rounds without settling (e.g., "Tumor Extent" flipping). Indicates irresolvable ambiguity in text or knowledge.
- **Error Propagation:** Initial baseline error (e.g., wrong "Tumor Site") persists through all reflection rounds. Suggests the LLM consistently misinterprets the same evidence.
- **Non-convergence:** After `m` rounds, at least one variable still changes. Implies the constraint network is unsatisfiable given the note and retrieved knowledge.

### First Three Experiments
1.  **Baseline Validation:** Implement the one-by-one RAG extraction on a small subset (n=20). Measure per-variable accuracy and identify initial error patterns (e.g., anatomical misclassifications).
2.  **Reflection Loop Smoke Test:** Apply the reflection loop with `p=1`, `m=3` to 10 cases. Verify that: (a) the prompt correctly injects prior JSON, (b) the LLM outputs valid JSON with all variables, (c) convergence can be detected.
3.  **Hyperparameter Probe:** For a single task (e.g., CRC), run the full reflective process varying `p` in {1,5,10} and `m` in {5,10,16}. Record convergence rate and final F1 to identify a Pareto front of accuracy vs. compute cost.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can knowledge engineering be improved to enhance LLM reasoning for interdependent clinical variable extraction?
- **Basis in paper:** The authors state they will "extend our research in the direction of enhancing LLM agents reasoning capability via more effective knowledge engineering."
- **Why unresolved:** Current RAG-based retrieval (section-level) still yields errors in complex anatomical reasoning and non-convergence in some cases.
- **What evidence would resolve it:** Systematic comparison of knowledge granularities, incorporation of structured medical ontologies, and evaluation of convergence rates and accuracy across diverse clinical datasets.

### Open Question 2
- **Question:** How can image feature recognition be integrated into the LLM-based synoptic reporting workflow to assist pathologists?
- **Basis in paper:** The authors plan to "extend our LLM facilitated workflow of synoptic reporting to include image feature recognition from digital slides, to build a copilot for pathologists."
- **Why unresolved:** The existing framework processes only text; integrating visual features from histopathology slides could improve data extraction and reduce pathologist burden.
- **What evidence would resolve it:** Development and validation of multimodal LLM agents that combine text and image inputs on pathology datasets with both gross descriptions and slide images.

### Open Question 3
- **Question:** Can deep reflective reasoning be effectively applied to disease diagnosis and prognosis using structured data extracted from multiple clinical sources?
- **Basis in paper:** The authors aim to "apply deep reflective reasoning in disease diagnosis and prognosis by using structured data extracted from multiple sources such as encounter notes, progress notes, pathology reports, CT notes, MRI notes, and others."
- **Why unresolved:** The method has only been evaluated on single-note extraction tasks; its scalability and reliability for integrative diagnosis/prognosis across diverse note types remain unknown.
- **What evidence would resolve it:** Prospective studies applying the framework to multi-source clinical data for specific diseases, measuring impact on diagnostic accuracy and prognostic prediction.

### Open Question 4
- **Question:** Why does deep reflective reasoning sometimes fail to correct clinically inconsistent outputs, and how can convergence be guaranteed?
- **Basis in paper:** Case analyses reveal that reflections occasionally do not correct errors (e.g., tumor site misclassification) and may oscillate without converging (24 cases in CRC experiment).
- **Why unresolved:** The underlying causes—such as insufficient anatomical knowledge, limited backtracking, or prompt design—are not fully understood, limiting clinical reliability.
- **What evidence would resolve it:** Comprehensive error analysis across failed cases to identify patterns; experiments varying reflection depth, back-view length, and incorporating external validation rules; development of formal convergence guarantees.

## Limitations
- **Prompt & implementation underspecification:** Exact reflection prompt phrasing, JSON schema constraints, and `inconsistency_examples` are inferred from supplementary figures, risking replication drift.
- **Hyperparameter sensitivity:** Optimal back-view rounds (`p`) and max rounds (`m`) are task-specific with no clear selection rationale; convergence criteria (exact string match) may be brittle to LLM phrasing variations.
- **Domain & generalizability limits:** Evaluation restricted to three oncology subdomains; performance on non-oncology or noisier notes (e.g., progress notes) is unknown. Reflection may fail on ambiguous/conflicting evidence, leading to non-convergence or error propagation.

## Confidence
- **Claim:** "Deep reflective reasoning systematically improves extraction accuracy under interdependence constraints."  
  **Confidence:** **High** – robust gains across three tasks with reasonable sample sizes (n=217, 200, 100) and consistent metric improvements.
- **Claim:** "Framework reliably achieves convergence and clinical consistency."  
  **Confidence:** **Medium** – convergence reported but failure modes (oscillation, unresolved contradictions) noted; no statistical analysis of convergence rate or clinical error reduction.
- **Claim:** "Approach generalizes to diverse clinical note types."  
  **Confidence:** **Low** – tested only on structured pathology/clinical oncology notes; generalizability to other specialties or note formats unvalidated.

## Next Checks
1.  **Hyperparameter sensitivity sweep:** Systematically vary `p` (1–15) and `m` (5–20) across all three tasks, measuring convergence rate, performance delta, and compute cost to establish optimal defaults and robustness thresholds.
2.  **Qualitative reasoning audit:** For a stratified sample of 50 converged and 50 non-converged cases, manually inspect the LLM’s cited evidence and explanations in reflection rounds to quantify: (a) frequency of correct inconsistency detection, (b) sources of unresolved contradictions (e.g., ambiguous text, missing knowledge).
3.  **Cross-domain portability test:** Apply the identical framework (with task-adapted knowledge) to 100 non-oncology clinical notes (e.g., cardiology discharge summaries with interdependent variables like ejection fraction, medications, procedures) to measure transferability of gains.
