# Telogenesis: Goal Is All U Need

## Quick Facts
- **arXiv ID:** 2603.09476
- **Source URL:** https://arxiv.org/abs/2603.09476
- **Reference count:** 3
- **Primary result:** Attentional priorities emerge endogenously from epistemic gaps (ignorance, surprise, staleness); under change detection latency, priority-guided allocation outperforms rotation, and learnable staleness decay recovers latent environmental volatility without supervision.

## Executive Summary
This paper investigates whether useful attentional priorities can arise without external goals, driven solely by an agent's internal epistemic gaps. It proposes a priority function combining ignorance (posterior variance), surprise (prediction error), and staleness (temporal decay) to direct limited observational resources. The central finding is a metric-dependent reversal: while a simple rotation strategy minimizes global prediction error (an oracle metric), the priority function drastically reduces change detection latency—a metric aligned with the agent's partial observability—with performance advantage scaling with problem dimensionality. Furthermore, when the staleness decay rate is made learnable per variable, the system spontaneously recovers the environment's latent volatility structure from interaction alone. The work suggests that goal-free attention allocation may be a foundational precursor to more complex adaptive behavior.

## Method Summary
The study uses two simulated partially observable environments. In the minimal system, an agent tracks N scalar variables whose dynamics switch regimes periodically. The agent maintains a Bayesian Gaussian world model for each variable, updating its mean and variance upon observation. Unobserved variables have their variances inflated each tick to model non-stationarity. The agent's priority function computes a score for each variable: a weighted sum of normalized posterior variance (ignorance), normalized prediction error (surprise), and a staleness term (1 - e^{-λ Δt}). Using a softmax over scores, it selects b ≪ N variables to observe per timestep. Baselines include random, deterministic rotation, and greedy error-driven selection. Performance is evaluated under two metrics: global prediction error (omniscient) and change detection latency (agent-centric). A second "Liminal" environment features 16 variables in 4 modules with heterogeneous transition probabilities. In a key extension, the staleness decay constant λ is made learnable per variable via a surprise-weighted moving average.

## Key Results
- **Metric-dependent reversal:** Under global prediction error, rotation (coverage) wins; under change detection latency, priority-guided allocation wins, with advantage growing with dimensionality (Cohen's d = -0.95 at N=48, p < 10⁻⁶).
- **Power law scaling:** Detection latency follows L ∝ b^(-ε) with a steeper exponent for priority-guided allocation (ε = 0.55) than rotation (ε = 0.40), indicating disproportionate gains from increased attention budget.
- **Unsupervised volatility discovery:** When decay rates λ_i are learned per variable, the system spontaneously partitions variables into high- and low-volatility groups matching the environment's latent structure (paired t-test t = 22.5, p < 10⁻⁶).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Attentional priorities can emerge endogenously from an agent’s internal epistemic gaps (ignorance, surprise, staleness) without external goals.
- **Mechanism:** A priority function π_i(t) = w₁σ̃²_i(t) + w₂S̃_i(t) + w₃(1−e^(−λΔt_i)) scores each variable. Softmax selection over scores directs limited observations (b ≪ N). Ignorance (posterior variance) pushes toward under-sampled regions; surprise (normalized prediction error) reacts to model mismatch; staleness (temporal decay) creates urgency for unobserved variables.
- **Core assumption:** The environment is non-stationary; unobserved variables may change over time, making temporal coverage essential.
- **Evidence anchors:** The abstract and Eq. 1 define the three terms and softmax selection. Ablation shows all three components are necessary; removing any degrades performance.
- **Break condition:** If the environment is stationary, staleness becomes irrelevant and the mechanism may degenerate.

### Mechanism 2
- **Claim:** The apparent superiority of an allocation strategy is metric-dependent; priority-guided allocation outperforms rotation under change detection latency but not under global prediction error.
- **Mechanism:** Global error (available only with omniscient access) rewards guaranteed coverage (rotation) because it minimizes aggregate miss-rate. Under latency—a metric aligned with the agent’s partial observability—staleness and surprise direct attention to recently changed variables faster, while rotation’s fixed cycle imposes linear latency scaling with N.
- **Core assumption:** Evaluation should use metrics the agent itself can approximate (e.g., detection latency via observed prediction deviations), not oracle-accessible global error.
- **Evidence anchors:** Figure 1 and Table 3 show latency advantage growing with N. The reversal is a direct property of the metric choice.
- **Break condition:** If evaluation insists on global prediction error, priority appears inferior; the result hinges on using an agent-centric metric.

### Mechanism 3
- **Claim:** When the staleness decay rate λ is made learnable per variable, the system spontaneously recovers the environment’s latent volatility structure without supervision.
- **Mechanism:** Each variable i has λ_i updated by a surprise-weighted moving average (λ_i ← (1−τ)λ_i + τ·S_i(t)). High-surprise observations increase λ_i, accelerating staleness growth and causing quicker revisits to volatile variables; low surprise decreases λ_i. The closed loop (priority → observation → surprise → λ update) self-organizes into a volatility model.
- **Core assumption:** Volatility differences between variable groups are stable and observable through consistent surprise patterns.
- **Evidence anchors:** Table 4 and Figure 3 show clear separation of λ_i between high- and low-volatility modules. The statistical test (t = 22.5) strongly supports recovery.
- **Break condition:** If volatility differences are too subtle or dynamics too chaotic, λ_i may not converge to distinguishable values; the update rule is heuristic, not guaranteed optimal.

## Foundational Learning
- **Concept:** Bayesian posterior variance
  - *Why needed here:* Quantifies ignorance (σ̃²_i) in the priority function; drives exploration of underdetermined variables.
  - *Quick check question:* How does posterior variance change when a variable is observed versus withheld?
- **Concept:** Normalized prediction error (surprise)
  - *Why needed here:* Signals model mismatch for observed variables; redirects attention to changing state.
  - *Quick check question:* Why normalize prediction error by predictive uncertainty (ˆσ_i + ϵ)?
- **Concept:** Temporal decay and exponential weighting
  - *Why needed here:* Generates priority for unobserved variables via staleness; implements “recency bias” under non-stationarity.
  - *Quick check question:* What happens to priority if Δt_i is very large but λ is small?
- **Concept:** Metric design for partial observability
  - *Why needed here:* Choosing detection latency vs. global error changes strategy rankings; aligns evaluation with agent’s perspective.
  - *Quick check question:* Is a metric like global prediction error computable by the agent itself? Why or why not?
- **Concept:** Power law scaling in resource-limited systems
  - *Why needed here:* Shows structured allocation (priority) extracts disproportionate gains from extra attention budget.
  - *Quick check question:* What does a steeper exponent (0.55 vs. 0.40) imply about marginal benefit of additional observations?

## Architecture Onboarding
- **Component map:**
  World model -> Priority calculator -> Observation scheduler -> World model
                                    |
                                    v
                                (Optional) λ learner
- **Critical path:** State update → prediction → compute gaps (ignorance, surprise, staleness) → priority scores → softmax selection → observe → update model and possibly λ_i.
- **Design tradeoffs:**
  - Fixed λ vs. learnable λ: Fixed is simpler but cannot adapt to heterogeneous volatility; learnable enables unsupervised structure discovery but adds instability risk.
  - Metric choice: Using global error favors coverage strategies; using latency favors priority-guided selection—must match evaluation to agent’s partial observability.
  - Attention budget b: Smaller b increases reliance on priority’s efficiency; larger b reduces differences.
- **Failure signatures:**
  - Ablation failure: Removing any gap term (ignorance, surprise, staleness) causes performance drop.
  - Metric mismatch: Reporting only global prediction error obscures priority’s latency advantage.
  - λ divergence: In high-noise settings, λ_i may oscillate or not separate cleanly if volatility gaps are small.
- **First 3 experiments:**
  1. Minimal system (N=6, 2000 runs): Establish necessity of all three gap terms via ablation; show priority wins on latency but not global error.
  2. Liminal environment (N=16, budget=2): Replicate minimal results in a modular, partially observable world; demonstrate error-driven allocation collapse without staleness.
  3. Emergent structure (learnable λ, 16 variables, 4 modules): Show spontaneous recovery of volatility partition (high vs. low) without supervision (t=22.5, p<10⁻⁶).

## Open Questions the Paper Calls Out
- **Open Question 1:** Does the Telogenesis priority mechanism scale to action selection, planning, and resource allocation in richer, embodied environments beyond attention allocation?
  - *Basis in paper:* The authors state in the Discussion and Limitations: "Whether the same principle extends to action selection, planning, and resource allocation in richer environments is a question we leave to future work."
  - *Why unresolved:* The current work validates the priority function only in simulated attention-allocation tasks with known Bayesian models. Extending to full agent control (actions affecting state) in realistic environments introduces partial observability, delayed consequences, and credit assignment challenges not addressed here.
  - *What evidence would resolve it:* Implement the priority function as a goal-generation module driving action policies in a complex, partially observable domain (e.g., 3D navigation, robotic manipulation). Compare performance against baseline exploration strategies using metrics like task completion rate or cumulative extrinsic reward, while verifying that emergent goals correlate with epistemic gaps.
- **Open Question 2:** Can the learned per-variable decay rate (λ_i) mechanism recover finer-grained, non-binary environmental volatility structures (e.g., a continuous spectrum of change rates)?
  - *Basis in paper:* The authors note in Experiment 3: "whether the mechanism recovers finer-grained structure under smaller volatility differences remains an open question."
  - *Why unresolved:* Experiment 3 only tested recovery of a stark binary partition (high vs. low volatility with a 7.5× transition probability gap). The robustness of the λ_i update rule to subtler gradations and its capacity to represent continuous volatility landscapes are unknown.
  - *What evidence would resolve it:* Design an environment with 4+ volatility tiers (e.g., transition probabilities linearly spaced between 0.02 and 0.15). Run the learned-λ system and measure the correlation between ground-truth volatility and mean learned λ_i per variable/tier. A significant monotonic relationship would support finer-grained recovery.
- **Open Question 3:** Is the metric-dependent reversal (priority wins on detection latency, rotation wins on global error) robust to alternative, more agent-centric definitions of "detection" (e.g., requiring prediction error to exceed a learned threshold)?
  - *Basis in paper:* The authors define detection latency as "the first observation of an affected variable" and note: "an alternative definition requiring prediction deviation above a threshold would be more conservative but introduces an arbitrary parameter."
  - *Why unresolved:* The current detection metric uses the earliest possible signal (first observation post-switch). A threshold-based metric might align better with an agent's internal uncertainty monitoring but introduces a free parameter. It is unknown whether the priority advantage persists under this more stringent, potentially more realistic, definition.
  - *What evidence would resolve it:* Re-run the main experiments (e.g., Liminal with varying N) using a detection definition where a "change" is only registered if the absolute prediction error |x_i - x̂_i| exceeds a threshold θ. This θ could be set as a quantile (e.g., 95th percentile) of pre-switch prediction errors. Compare scaling of detection latency between PRIORITY and ROTATION under this new metric.

## Limitations
- **Environment specification gap:** The precise generative model for the "Liminal" environment (variable coupling, transition dynamics) is underspecified, requiring reconstruction forExperiments 2 & 3. This is the primary barrier to exact quantitative replication.
- **Hyperparameter ambiguity:** Exact values for priority weights (w1,w2,w3), temperature (τ), normalization schemes for σ̃² and S̃, and variance inflation rate (γ) are not reported. Assumed defaults may significantly affect relative performance metrics.
- **External validation deficit:** Corpus analysis shows no direct citations or closely related prior work validating the specific three-gap priority function or the metric-dependent reversal claim. Evidence is primarily paper-intrinsic simulations.

## Confidence
- **Core mechanism (priority function efficacy):** Medium. Strong internal ablation evidence (all terms necessary), but no external corroboration.
- **Metric-dependent reversal:** High. Directly tested and shown in experiments; logic is self-consistent and clear.
- **Unsupervised volatility recovery (learnable λ):** Medium. Robust statistical result (t=22.5) on a designed task, but the mechanism is heuristic and may not generalize to less distinct volatility structures.
