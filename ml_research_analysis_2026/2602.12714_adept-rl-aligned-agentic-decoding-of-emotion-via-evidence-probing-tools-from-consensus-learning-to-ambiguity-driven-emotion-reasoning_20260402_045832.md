# ADEPT: RL-Aligned Agentic Decoding of Emotion via Evidence Probing Tools -- From Consensus Learning to Ambiguity-Driven Emotion Reasoning

## Quick Facts
- arXiv ID: 2602.12714
- Source URL: https://arxiv.org/abs/2602.12714
- Reference count: 40
- Primary result: ADEPT improves primary emotion accuracy (Macro-F1 0.4224 vs. fine-tuned WavLM's 0.3640) and minor emotion recovery (Set Recall 0.6192, Jaccard 0.4751) on MSP-Podcast; zero-shot on IEMOCAP achieves Set Recall 0.5480, surpassing supervised SOTA (0.5230).

## Executive Summary
ADEPT addresses two critical gaps in Speech Emotion Recognition: the lack of evidence grounding and the loss of nuance from discarding minority annotator votes. It reframes SER as a multi-turn inquiry process where an agentic framework adaptively invokes semantic and acoustic probing tools to build an auditable evidence trail. The system uses Group Relative Policy Optimization with an Evidence Trust Gate to align tool usage with prediction accuracy. On MSP-Podcast, ADEPT improves primary Macro-F1 (0.4224 vs. 0.3640) and yields strong minor recovery (Set Recall 0.6192, Jaccard 0.4751). Zero-shot on IEMOCAP, it exceeds the supervised state-of-the-art (Set Recall 0.5480 vs. 0.5230), demonstrating robust ambiguity handling.

## Method Summary
ADEPT processes audio and transcripts from MSP-Podcast V2.0, constructing labels via plurality: tied emotions become primary; remaining standard categories become minor emotions. The core pipeline has three phases. Phase 1 (Global Perception) uses Qwen-3-Omni to generate a high-recall candidate set and tie flag without tools. Phase 2 (Evidence Verification) employs a toolkit: StructuralPriorTool for scheduling, semantic probes (e.g., run_semantic_gate, compare_emotions), acoustic probes (e.g., find_acoustic_hotspots, analyze_acoustic_segment), and refinement tools (replay_audio, check_semantic_alignment). These tools produce observations only; no emotion labels are emitted. Phase 3 (Evidence-Closed Adjudication) disables tools and produces final decisions based solely on Phase 2 observations, ensuring an auditable trail. Training uses Group Relative Policy Optimization (GRPO) with a composite reward (format, phase integrity, outcome, gated evidence/tool). An Evidence Trust Gate (τEIR) scales evidence rewards based on group-relative evidence scores to prevent reward hacking. The model is trained on 169k samples, batch 256, K=8 rollouts, for 2 epochs (1250 steps).

## Key Results
- Primary Macro-F1 on MSP-Podcast: 0.4224 (vs. fine-tuned WavLM 0.3640).
- Minor emotion recovery: Set Recall 0.6192, Jaccard 0.4751.
- Zero-shot on IEMOCAP: Set Recall 0.5480, exceeding supervised SOTA (0.5230).
- Tool usage scales with annotation ambiguity, confirming adaptive computation.

## Why This Works (Mechanism)
**Mechanism 1: Structured evidence accumulation resolves ambiguity**  
ADEPT separates hypothesis formation (Phase 1), active evidence acquisition (Phase 2), and adjudication (Phase 3). The evidence-closed constraint in Phase 3 ensures predictions rely only on tool observations, not latent knowledge, enabling auditability and preventing hallucination. The core assumption is that human affect is pluralistic; minority votes are valid signals. MSP-Podcast shows high tie rates (17.8–18.4%) and average 2.55–2.58 labels per audio, confirming ambiguity. Failure occurs if Phase 3 uses StructuralPriorTool outputs or latent knowledge.

**Mechanism 2: Evidence Trust Gate aligns incentives**  
GRPO is complemented by τEIR, which gates evidence rewards: they contribute fully only when correct trajectories exhibit stronger evidence-seeking than incorrect ones within the same rollout group. This prevents reward hacking by ensuring tool use correlates with accuracy. Ablation reduces Jaccard (44.96 vs. 47.51). Tool usage scales with ambiguity, supporting adaptive gating. A break condition: if µ⁺ < µ⁻ (incorrect trajectories show higher evidence scores), τEIR suppresses rewards, possibly stalling learning for genuinely complex cases.

**Mechanism 3: Ambiguity-driven labeling leverages minority votes**  
Instead of strict majority voting, ADEPT retains all tied emotions as primary and includes any non-primary standard category as minor. This treats annotator disagreement as informative supervision for co-occurrence, improving recovery of peripheral emotions (Contempt, Disgust, Fear) which have high tie rates (60–73%). Risk: if minority votes are systematically biased (e.g., cultural artifacts), preservation could introduce noise, harming primary accuracy.

## Foundational Learning
- **Explicit Information Retrieval (EIR)**: Ensures every reasoning step in Phase 3 is causally traceable to tool observations, not latent knowledge. Needed to separate perception from interpretation for auditability. Quick check: In Phase 3, which sources are prohibited? Answer: StructuralPriorTool outputs and any non-tool observations; only semantic spans and acoustic bins from Phase 2.
- **Group Relative Policy Optimization (GRPO)**: Uses within-group relative advantages instead of absolute reward scales, stabilizing RL training for tool-augmented agents. Needed because composite rewards have heterogeneous magnitudes and sparse feedback. Quick check: How does GRPO avoid PPO’s reward scaling problem? Answer: Advantages are computed relative to other trajectories in the same rollout group, making optimization invariant to absolute magnitudes.
- **Structural Prior from Co-occurrence Statistics**: Provides instance‑free scheduling signals derived from training set co‑occurrence, independent of the agent’s potentially miscalibrated uncertainty. Needed for efficient budget allocation in Phase 2 given preserved ambiguity. Quick check: Why not let the agent self‑schedule based on confidence? Answer: Self‑confidence may be overfit; corpus‑level co‑occurrence offers stable, model‑independent cues for high‑confusion pairs.

## Architecture Onboarding
**Component map**:  
Base model: Qwen-3-Omni -> Phase 1: High-recall candidate generator (no tools) -> Phase 2: Evidence Probing Toolkit (StructuralPriorTool, Semantic tools, Acoustic tools, Refinement tools) -> Phase 3: Evidence-closed adjudicator (tools disabled). Training uses GRPO with composite reward and Evidence Trust Gate.

**Critical path**:  
1. Phase 1 must produce ≥2 candidates; single-label output risks failure on ambiguous cases.  
2. Phase 2 must call StructuralPriorTool early; tool call count should scale with ambiguity (typically 2–8).  
3. Phase 3 must contain zero tool calls; any call violates evidence-closed constraint.  
4. Throughout, JSON output must be parseable and emotions restricted to canonical 8‑class set.

**Design tradeoffs**:  
- EIR strictness vs. flexibility: Strict separation ensures auditability but blocks pretrained knowledge in Phase 3, possibly hurting tool‑insufficient cases.  
- Tool coverage vs. budget: Minimal acoustic probes may miss subtle cues if initial focus misdirected.  
- Prior design: Corpus-level co‑occurrence is symmetric and stable but ignores speaker/domain variability.

**Failure signatures**:  
- Phase 1: Candidate set size =1 or tie_prediction=False on high-disagreement samples.  
- Phase 2: Tool count <2 (superficial) or >8 (spam); missing semantic gate; acoustic metrics lack dual‑reference bins.  
- Phase 3: Tool calls present; primary emotion not in Phase 1 candidate set; reasoning cites prior scores.  
- Training: τEIR persistently near 0 → evidence rewards not correlated with correctness.

**First 3 experiments**:  
1. **Phase 1 recall sanity**: Run on a known tie‑case (e.g., MSP‑Podcast with Neutral+Happiness tie). Verify candidate set includes both and tie_prediction=True.  
2. **Tool output validity**: Inspect semantic tool returns — extracted spans must be verbatim transcript substrings. Acoustic tool returns must include dual‑reference bins (e.g., "pitch_level: global=High, local=Mid").  
3. **Trust gate dynamics**: After initial GRPO steps, compute evidence score (Sevid) for correct vs incorrect rollouts in same rollout group. Confirm τEIR > 0.5 when µ⁺ > µ⁻; if τEIR=0, adjust reward weights or rollout sampling.

## Open Questions the Paper Calls Out
**Open Question 1**: How can ADEPT integrate MSP‑Podcast’s full secondary label set (16 emotions) without overwhelming Phase 2’s adaptive evidence acquisition?  
Basis: Authors leave integration of expanded secondary labels as future work.  
Why unresolved: Larger label space could explode candidate pairs, violating EIR or causing intractable RL exploration.  
Resolution evidence: Run ADEPT on full secondary labels, measure accuracy as candidate set grows, and test hierarchical pruning.

**Open Question 2**: Can the Evidence Trust Gate (τEIR) be replaced with a learned, instance‑specific mechanism?  
Basis: τEIR uses group‑level statistics; not directly optimized.  
Why unresolved: Group thresholds may not generalize; instance‑adaptive gate could better tie tool use to accuracy.  
Resolution evidence: Introduce a neural gating network trained jointly, evaluate cross‑corpora generalization, and correlate gate values with correctness.

**Open Question 3**: How robust are acoustic binning thresholds to speaker/domain variations, and can they be made speaker‑adaptive?  
Basis: Dual‑reference bucketing uses fixed global/utterance thresholds without speaker normalization.  
Why unresolved: Thresholds tuned on podcasts may fail on telephone speech, children’s voices, or low‑resource languages.  
Resolution evidence: Test on diverse domains, analyze per‑speaker bin distributions, and implement speaker‑adaptive references.

## Limitations
- Incomplete specifications: acoustic binning thresholds, feature extraction details, JSON schema, GRPO hyperparameters omitted, hindering faithful reproduction.
- Evidence Trust Gate calibration risk: noisy group estimates could lead to τEIR ≈ 0, suppressing valid evidence‑seeking and stalling learning.
- Acoustic evidence noise: F0/energy estimation errors on noisy podcast speech may produce misleading bins and misguide probing.
