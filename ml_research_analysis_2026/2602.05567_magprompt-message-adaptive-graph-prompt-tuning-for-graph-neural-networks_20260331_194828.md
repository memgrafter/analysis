# MAGPrompt: Message-Adaptive Graph Prompt Tuning for Graph Neural Networks

## Quick Facts
- **arXiv ID**: 2602.05567
- **Source URL**: https://arxiv.org/abs/2602.05567
- **Reference count**: 40
- **Primary result**: MAGPrompt+ achieves average 5-shot node classification accuracy 46.85% (vs. 45.05% for EdgePrompt+), 50-shot graph classification accuracy 61.87% (vs. 60.45%), and full-shot MoleculeNet ROC-AUC 78.74% (vs. 76.25% for GPF, 75.85% for fine-tuning).

## Executive Summary
Pre-trained graph neural networks (GNNs) often encounter objective mismatch when adapting to downstream tasks, as the pre-training objective (e.g., contrastive learning) differs from the target task (e.g., classification). Existing graph prompt tuning methods modify inputs or representations but leave the message-passing mechanism unchanged, limiting their ability to adapt neighborhood interactions. MAGPrompt addresses this by injecting lightweight trainable prompts directly into the message-passing step, enabling adaptive reweighting of neighbor contributions and the addition of task-specific prompt vectors while keeping the backbone frozen. This approach is compatible with common GNN architectures and various pre-training strategies.

Experiments across node and graph classification benchmarks demonstrate that MAGPrompt, especially its compositional variant MAGPrompt+, consistently outperforms prior prompting methods. In few-shot settings (5-shot, 50-shot), MAGPrompt+ achieves higher accuracy than EdgePrompt+ and other baselines. On full-shot MoleculeNet tasks, it attains superior ROC-AUC compared to GPF and fine-tuning. These results validate the effectiveness of message-adaptive prompting in aligning pre-trained GNN knowledge with downstream tasks.

## Method Summary
MAGPrompt modifies each message-passing layer of a frozen pre-trained GNN by introducing two trainable components: a gating module and an additive prompt module. For each edge \((i,j)\), the original message \(m_{ij}\) from the backbone’s MSG function is reweighted by a scalar weight \(a_{ij}\) computed via an attention-style operation on the source and target node features. A prompt vector is then added: in MAGPrompt the prompt is a shared vector \(p^{(l)}\) per layer; in MAGPrompt+ it is an edge‑adaptive mixture of multiple basis vectors \(p_m^{(l)}\), with mixture coefficients generated by a small network. The modified message \(\tilde{m}_{ij} = a_{ij} \cdot m_{ij} + p_{ij}\) is fed into the backbone’s aggregation and update functions unchanged. MAGPrompt+ additionally employs a prompt‑collapse regularizer \(L_{\text{pc}}\) that encourages uniform usage of the prompt bases, preventing the model from relying on a small subset. Training uses Adam (learning rate \(10^{-3}\), batch size 32, 200 epochs) with key hyperparameters: attention head dimension \(d_a=16\), gate residual lower bound \(\beta=0.5\), prompt basis count \(M_l=10\) for node tasks and 20 for graph tasks, and \(\lambda_{\text{pc}}\) tuned in \(\{0,0.01,0.1,1\}\). A linear classifier on top produces the final predictions.

## Key Results
- 5‑shot node classification: MAGPrompt+ average accuracy **46.85%** vs. 45.05% for EdgePrompt+.
- 50‑shot graph classification: MAGPrompt+ average accuracy **61.87%** vs. 60.45% for the strongest baseline.
- Full‑shot MoleculeNet: MAGPrompt+ average ROC‑AUC **78.74%**, outperforming GPF (76.25%) and fine‑tuning (75.85%).

## Why This Works (Mechanism)
### Mechanism 1: Learned Neighbor Reweighting
MAGPrompt introduces per‑edge scalar gates that adaptively reweight neighbor messages during aggregation. At each layer, for edge \((i,j)\), a gating module projects node representations \(h_i^{l-1}\) and \(h_j^{l-1}\) into a low‑dimensional space, computes attention‑style scores, and produces a bounded scalar \(a_{ij} \in [\beta,1]\). The backbone’s original message \(m_{ij}\) is scaled by \(a_{ij}\), yielding a reweighted message \(a_{ij} \cdot m_{ij}\). This allows the model to amplify or suppress specific neighbor contributions based on the downstream task, assuming the optimal neighborhood mixing pattern differs between pre‑training and downstream tasks. Break condition: if the backbone already contains strong adaptive neighbor weighting (e.g., GAT), additional gating may offer marginal benefit and could overfit; setting \(\beta\) too high restricts the gate’s range.

### Mechanism 2: Additive Message-Level Prompting
MAGPrompt injects task‑specific prompt vectors into each message before aggregation, shifting the message content without altering backbone parameters. For each layer, either a shared prompt \(p^{(l)}\) (MAGPrompt) or an edge‑adaptive mixture \(p_{ij} = \sum_m \pi_{ijm} p_m^{(l)}\) (MAGPrompt+) is added to the reweighted message: \(\tilde{m}_{ij} = a_{ij} \cdot m_{ij} + \text{prompt}\). The modified messages are then aggregated and updated normally. The core assumption is that the backbone’s messages capture general graph semantics, but downstream tasks require small, task‑specific adjustments that additive prompts can provide while preserving pre‑trained knowledge. Break condition: if the backbone’s message distribution is already well‑aligned, additive prompts may distort useful representations; without regularization, MAGPrompt+’s prompt bases may collapse.

### Mechanism 3: Prompt‑Collapse Regularization (MAGPrompt+)
To maintain diversity among multiple prompt basis vectors, MAGPrompt+ introduces a regularization term \(L_{\text{pc}}\) that encourages balanced usage. For a mini‑batch, aggregate mixture weights \(\pi_{ijm}\) over edges to obtain usage counts \(s_m\) for each basis \(m\). \(L_{\text{pc}} = \frac{1}{M_l} \sum_m \frac{(s_m - \bar{s})^2}{\bar{s}^2 + \epsilon}\) penalizes variance of usage around the mean \(\bar{s}\). This prevents the model from ignoring most bases, which would effectively reduce capacity. The assumption is that without such regularization the model might converge to using only a subset of bases. Break condition: excessively high \(\lambda_{\text{pc}}\) forces overly uniform usage, hindering specialization, and poorly initialized bases may defy recovery even with regularization.

## Architecture Onboarding
#### Component Map
Input Graph → Frozen Backbone (pre‑trained GNN) → Message‑Adaptive Gating Module (produces \(a_{ij}\)) → Additive Prompt Module (produces \(p_{ij}\)) → Modified Messages (\(\tilde{m}_{ij} = a_{ij} \cdot m_{ij} + p_{ij}\)) → Standard Aggregation & Update → Task Head. For MAGPrompt+ the prompt module uses multiple basis vectors and a mixture network, and a Prompt‑Collapse Regularizer is applied to the mixture weights.

#### Critical Path (Forward Pass per Layer)
1. Backbone computes base messages: \(m_{ij} = \text{MSG}^{(l)}(h_i^{l-1}, h_j^{l-1}, e_{ij})\).
2. Gating module: project node features, compute attention‑style scores, output \(a_{ij}\) (Eqs. 6‑9).
3. Prompt generation: either shared \(p^{(l)}\) (MAGPrompt) or edge‑adaptive \(p_{ij} = \sum_m \pi_{ijm} p_m^{(l)}\) (MAGPrompt+, Eqs. 10, 13‑15).
4. Combine: \(\tilde{m}_{ij} = a_{ij} \cdot m_{ij} + p_{ij}\).
5. Aggregate: \(\bar{m}_i = \text{AGG}^{(l)}(\{\tilde{m}_{ij}\})\).
6. Update: \(h_i^{(l)} = \text{UPD}^{(l)}(h_i^{l-1}, \bar{m}_i)\).
7. (MAGPrompt+) Compute prompt‑collapse loss \(L_{\text{pc}}\) from mixture weights and add to total loss with weight \(\lambda_{\text{pc}}\).

#### Design Tradeoffs
- MAGPrompt vs. MAGPrompt+: MAGPrompt+ yields edge‑specific prompts (more expressive) but adds parameters and collapse risk; requires \(L_{\text{pc}}\). MAGPrompt is simpler and more robust for small datasets.
- Attention head dimension \(d_a\): larger increases capacity but may overfit; moderate (e.g., 16) often optimal.
- Prompt basis size \(M_l\): more bases capture finer heterogeneity but risk collapse; \(L_{\text{pc}}\) mitigates.
- Gate residual \(\beta\): \(\beta=0\) gives full adaptivity but may cause vanishing gradients; \(\beta>0\) provides lower bound; \(\beta=0.5\) works well.
- Regularization \(\lambda_{\text{pc}}\): balances diversity vs. specialization; optimal range \([0.01, 0.1]\) empirically.

#### Failure Signatures
- **Prompt collapse**: mixture weights concentrate on few bases; monitor usage distribution; performance drops with large \(M_l\).
- **Gate collapse**: \(a_{ij}\) nearly constant (e.g., all \(\approx \beta\)); indicates gating module not learning; may stem from insufficient gradients or too high \(\beta\).
- **Additive prompt domination**: \(\|p_{ij}\| \gg \|a_{ij} \cdot m_{ij}\|\); prompts may override backbone knowledge.
- **Overfitting**: large train‑validation accuracy gap in few‑shot settings; reduce \(d_a\) or \(M_l\), increase \(\lambda_{\text{pc}}\).

#### First 3 Experiments
1. **Benchmark Comparison**: MAGPrompt/MAGPrompt+ vs. prior graph prompt tuning methods (GPF, EdgePrompt+, GraphTOP, etc.) on 5‑shot node classification (Cora, CiteSeer, Pubmed, ogbn‑arxiv, Flickr) and 50‑shot graph classification (TUDataset), plus full‑shot MoleculeNet. Consistent improvements across diverse backbones and tasks.
2. **Ablation Study**: Isolate contributions of message reweighting and edge‑adaptive prompts by turning each component on/off. Both components contribute gains; their combination yields best performance, validating the design.
3. **Hyperparameter Sensitivity**: Systematically vary \(M_l\), \(\lambda_{\text{pc}}\), \(\beta\), \(d_a\). Performance stable for moderate values (e.g., \(d_a=16\), \(\lambda_{\text{pc}}\in[0.01,0.1]\), \(\beta\in[0.25,0.75]\)); \(L_{\text{pc}}\) crucial for preventing collapse as \(M_l\) grows.

## Limitations
- Pre‑training details (checkpoints, objectives) and few‑shot protocols are not fully disclosed; backbone implementation quirks (BatchNorm, dropout, readout) remain unspecified, hindering exact replication.

- Risks of prompt collapse, gate collapse, and limited evaluation on large graphs reduce practical confidence.
