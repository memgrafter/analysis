# Locally Coherent Parallel Decoding in Diffusion Language Models

## Quick Facts
- **arXiv ID**: 2603.20216
- **Source URL**: https://arxiv.org/abs/2603.20216
- **Reference count**: 40
- **Primary result**: CoDiLA resolves local incoherence in diffusion language models by using a small auxiliary autoregressive model soft-conditioned on the diffusion model's token marginals, achieving higher accuracy at same throughput or over 2× speedup while maintaining near-sequential accuracy.

## Executive Summary
Diffusion language models (DLMs) generate text in parallel by denoising masked tokens, but standard decoding samples each token independently from its marginal distribution, breaking multi-token local structures (e.g., code syntax). This paper introduces CoDiLA, which partitions sequences into contiguous blocks and uses a lightweight auxiliary autoregressive (AR) model to decode each block coherently. The DLM provides global context via its token marginals, which are fed as soft embeddings to the AR model. The AR model then generates the entire block autoregressively, preserving local coherence while retaining the DLM's bidirectional capabilities. CoDiLA is trained by finetuning the AR model on a code dataset while keeping the DLM frozen. Experiments on code generation benchmarks show that CoDiLA eliminates coherence artifacts, reduces training loss with larger block sizes, and establishes a new accuracy-throughput Pareto frontier: under static parallelism, it achieves higher Pass@1 than baselines at the same throughput; under dynamic parallelism, it maintains near-sequential accuracy with over 2× speedup. Ablations confirm that soft-conditioning on the full marginal distribution is essential; conditioning on only the top-1 token leads to significant accuracy drops.

## Method Summary
CoDiLA operates by dividing a sequence into fixed-size contiguous blocks (e.g., size B=4). During training, the forward diffusion process masks entire blocks (rather than individual tokens) according to a stochastic schedule. For each masked block, the frozen DLM (Dream-Coder-Instruct-7B) produces token-wise marginal distributions over the vocabulary. These marginals are transformed into "soft embeddings": for each position j in the block, the embedding is the expectation of the AR model's token embeddings weighted by the marginal probability. These soft embeddings are concatenated with special tokens (<think>,) to form a prompt for a small auxiliary AR model (Qwen3-0.6B), which is finetuned to generate the true block tokens autoregressively. The loss is computed only on the masked block tokens. At inference, the DLM and AR model collaborate in iterative denoising steps: the scheduler identifies candidate masked blocks (default nearest 10 to the current frontier), computes their soft embeddings, and queries the AR model to decode each block. The AR model's average token entropy per block guides unmasking: in static parallelism, the block with lowest entropy is fully unmasked; in dynamic parallelism, partial blocks with entropy below a threshold τ are unmasked. This leverages the AR model's local coherence judgments while the DLM supplies global context.
