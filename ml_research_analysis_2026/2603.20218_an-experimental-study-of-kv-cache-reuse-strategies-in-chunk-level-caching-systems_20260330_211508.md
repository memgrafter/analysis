# An experimental study of KV cache reuse strategies in chunk-level caching systems

## Quick Facts
- arXiv ID: 2603.20218
- Source URL: https://arxiv.org/abs/2603.20218
- Reference count: 33
- Key outcome: PSR design achieves up to 5% better accuracy than single approaches by combining prefix tokens, scaled context attention, and selective recomputation

## Executive Summary
This paper investigates accuracy degradation in chunk-level caching (CLC) for retrieval-augmented generation (RAG) systems. The core problem is that cached KV states miss cross-chunk attention dependencies, causing accuracy loss compared to full prefill. Through extensive experimental study of existing CLC approaches, the authors demonstrate that current methods have fundamental limitations: static recomputation strategies are suboptimal, dynamic ones lack cross-chunk attention information in cached activations, and attention-reshaping techniques cannot fully compensate for missing cross-attention. Based on these insights, they propose PSR (Prefix-Scale-Recompute), a new design that combines three complementary techniques to address these limitations and achieve superior accuracy.

## Method Summary
The authors conduct an extensive experimental study of existing CLC approaches including Cacheblend, EPIC/Link0, Cacheclip, Droidspeak, APE, and BlockAttention. They implement these approaches and compare them against a full prefill baseline using Llama3.1-8B-Instruct, Qwen3-8B, and Mistral-7B-Instruct-v0.3 models on 2WikiMQA, Musique, and RULER datasets. The study evaluates F1 scores on multi-hop reasoning Q&A tasks to measure accuracy degradation. Based on observed limitations of existing approaches, they propose PSR (Prefix-Scale-Recompute) which combines prefix tokens to absorb attention sinks, scaled context attention, and selective KV cache recomputation. The authors run ablation studies to validate their design and demonstrate up to 5% better accuracy than single-approach methods.

## Key Results
- PSR achieves up to 5% better accuracy than single-approach methods across multiple models and datasets
- Static recomputation strategies (like Cacheblend) show poor token overlap across layers and suboptimal performance
- Dynamic recomputation approaches fail when cached activations lack cross-attention information
- Attention-reshaping techniques cannot fully compensate for missing cross-attention dependencies

## Why This Works (Mechanism)
The effectiveness of PSR stems from addressing the fundamental limitation that cached KV states miss cross-chunk attention dependencies. By combining three complementary techniques—prefix tokens to absorb attention sinks, scaled context attention to preserve information flow, and selective recomputation to recover critical information—PSR mitigates the accuracy degradation that occurs when using chunk-level caching compared to full prefill. The prefix tokens help maintain context continuity across chunk boundaries, while scaled attention preserves the relative importance of different tokens when some information is missing. Selective recomputation strategically recovers the most critical tokens that would otherwise cause accuracy loss.

## Foundational Learning
- Chunk-level caching limitations: CLC systems cache KV states independently per chunk, losing cross-chunk attention dependencies that are critical for accuracy
- Cross-attention importance: Missing cross-attention information in cached activations prevents dynamic recomputation from effectively selecting which tokens to recompute
- Attention sink problems: Without prefix tokens, attention mechanisms struggle to maintain context across chunk boundaries
- Recomputation strategies: Static methods like Cacheblend use metrics like ΔK for token selection but show poor overlap across layers
- Auxiliary model limitations: Approaches like Cacheclip use additional models for token selection but suffer from information loss in cached states
- Scaling as compensation: Attention scaling can partially compensate for missing information but cannot fully recover accuracy

## Architecture Onboarding

Component map: KV cache storage -> Prefix token injection -> Attention scaling -> Selective recomputation -> Output generation

Critical path: Input chunking → KV cache computation/reuse → Prefix token addition → Scaled attention application → Token selection for recomputation → Final generation

Design tradeoffs: Storage vs accuracy (storing more contextualizations improves accuracy but increases memory), computation vs latency (more recomputation improves accuracy but increases processing time), complexity vs maintainability (more sophisticated approaches are harder to implement and debug)

Failure signatures: 
- Low accuracy with junk tokens in outputs (missing cross-chunk attention)
- Dynamic approaches failing to select optimal tokens (cached activations lack cross-attention info)
- Attention-reshaping approaches producing suboptimal results (cannot fully compensate for missing cross-attention)

## Open Questions the Paper Calls Out

### Open Question 1
How can cached cross-chunk attention be preserved while maintaining the performance benefits of independent chunk caching? Current CLC systems compute KV caches independently, losing cross-chunk attention. Cachecraft addresses this but requires complex benchmarking and storage trade-offs that remain unexplored.

### Open Question 2
What is the optimal token selection strategy for dynamic KV cache recomputation that incorporates information from multiple layers? Current static methods like Cacheblend show poor token overlap across layers, while dynamic approaches like Droidspeak fail when cached activations lack cross-attention information.

### Open Question 3
How can benchmarking tools be developed to evaluate CLC systems across diverse workloads beyond single-shot Q&A tasks? Current evaluations focus narrowly on multi-hop reasoning Q&A datasets, limiting generalizability of findings to other LLM applications.

### Open Question 4
What are the optimal strategies for managing storage vs accuracy trade-offs when storing multiple KV cache versions for the same chunk? The trade-off between storage overhead and accuracy improvement remains unexplored, with no systematic analysis of cache selection heuristics.

## Limitations

- Implementation details for Cacheclip's auxiliary model and token selection mechanism are not fully specified, preventing exact replication
- Hyperparameters for APE (temperature, scaling factor) and tuning methodology remain unspecified
- Experimental scope is limited to three specific models and three datasets, potentially missing broader applicability
- Study focuses exclusively on F1 score, potentially overlooking other important evaluation dimensions
