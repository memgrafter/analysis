# Statistical Parsing for Logical Information Retrieval

## Quick Facts
- arXiv ID: 2602.12170
- Source URL: https://arxiv.org/abs/2602.12170
- Reference count: 10
- Key outcome: QBBN extended with negation/backward reasoning; slot grammar parser achieves zero-ambiguity parsing on 33 sentences

## Executive Summary
This paper addresses two gaps in Quantified Boolean Bayesian Networks (QBBN): the lack of negation/backward reasoning and the absence of a natural language parser. It introduces NEG factors enforcing probabilistic complementarity (P(x) + P(¬x) = 1), enabling contrapositive reasoning via backward λ messages and completing Prawitz's simple elimination rules. A typed slot grammar parser deterministically compiles disambiguated sentences to logical form, with LLMs handling preprocessing disambiguation at 95% PP attachment accuracy. The unified architecture combines LLM preprocessing, grammar parsing, LLM reranking, and QBBN inference. Results show the inference engine correctly handles all 44 test cases across 22 reasoning patterns, and the grammar produces zero-ambiguity parses for all 33 test sentences.

## Method Summary
The paper extends QBBN with NEG factors that enforce probabilistic complementarity (P(x) + P(¬x) = 1), enabling backward reasoning via λ messages and completing Prawitz's elimination rules. A typed slot grammar parser deterministically compiles disambiguated sentences to logical form. LLMs are used for preprocessing disambiguation tasks (95% PP attachment accuracy) but fail at direct structured parsing (12.4% UAS). The architecture integrates LLM preprocessing, grammar parsing, LLM reranking, and QBBN inference. The inference engine is tested on 44 cases covering 22 reasoning patterns, while the grammar is evaluated on 33 test sentences achieving zero-ambiguity parsing.

## Key Results
- QBBN inference engine correctly handles all 44 test cases across 22 reasoning patterns
- Slot grammar parser achieves zero-ambiguity parsing for all 33 test sentences
- LLM-based preprocessing achieves 95% PP attachment accuracy in isolation

## Why This Works (Mechanism)
The QBBN extension works by adding NEG factors that enforce the probabilistic complementarity constraint P(x) + P(¬x) = 1. This enables backward reasoning through λ messages that propagate probabilistic information in reverse, allowing modus tollens-style inference. The slot grammar parser deterministically maps natural language to logical form by enforcing strict typing and slot constraints, eliminating ambiguity at the parsing stage.

## Architecture Onboarding

Component map: LLM preprocessing -> Slot grammar parsing -> LLM reranking -> QBBN inference

Critical path: Input sentence → LLM disambiguation → Slot grammar → Logical form → QBBN inference → Answer

Design tradeoffs: Deterministic parsing (zero ambiguity) vs. flexibility; LLM preprocessing (high accuracy on PP attachment) vs. direct parsing (poor structural accuracy)

Failure signatures: Preprocessing errors propagate to parsing; slot grammar rigidity may miss valid interpretations; QBBN inference fails on complex dependencies
