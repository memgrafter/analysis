# PC2P: Multi-Agent Path Finding via Personalized-Enhanced Communication and Crowd Perception

## Quick Facts
- **ArXiv ID:** 2601.03301
- **Source URL:** https://arxiv.org/abs/2601.03301
- **Reference count:** 34
- **Primary result:** PC2P achieves state-of-the-art success rates on large-scale MAPF benchmarks, e.g., 97% vs. 29% for EPH* at 768 agents.

## Executive Summary
PC2P tackles the challenge of scaling Multi-Agent Path Finding (MAPF) in distributed, partially observable environments. It introduces a three-stage personalized communication mechanism that leverages dynamic graph attention for selective inter-agent messaging, a crowd perception module combining static and dynamic congestion metrics, and a region-based expert-guided deadlock-breaking strategy. Evaluated on large maps (up to 240x240 with 768 agents), PC2P significantly outperforms prior methods like EPH* in success rate and path length. Ablation studies confirm the contribution of each module, particularly in high-density scenarios.

## Method Summary
The core of PC2P is a decentralized agent architecture where each agent processes its local observation and employs personalized communication to share relevant information. The communication mechanism operates in three stages: selection identifies the most relevant neighboring agents using a dynamic graph attention network; generation produces informative messages conditioned on the agent's state and selected neighbors; aggregation fuses received messages to augment the agent's representation. Complementing this, crowd perception computes local congestion metrics based on static obstacles and dynamic neighbor densities, guiding path planning to avoid bottlenecks. When deadlocks are detected, a region-based expert strategy coordinates agents to break stalemates while minimizing disruption. The planning component integrates these inputs to produce actions that balance individual progress and collective coordination.

## Key Results
- Significantly higher success rates than baseline methods: 97% vs. 29% for EPH* at 768 agents on large maps.
- Shorter episode lengths, indicating more efficient paths.
- Ablation studies show each module (communication, crowd perception, deadlock-breaking) contributes to performance, with crowd perception especially critical in dense scenarios.

## Why This Works (Mechanism)
Personalized communication ensures that messages are tailored to relevance, reducing noise and bandwidth while preserving critical coordination signals. Dynamic graph attention allows the communication graph to adapt to the evolving agent distribution, capturing meaningful interactions even under partial observability. Crowd perception provides anticipatory awareness of congestion, enabling agents to proactively detour around high-traffic areas. The deadlock-breaking strategy, grounded in regional expertise, resolves impasses efficiently without requiring global information. Together, these components address the scalability bottleneck of distributed MAPF by improving situational awareness and coordination in a communication-efficient manner.

## Architecture Onboarding
Component map (plain text):
Observation Input -> Perception (Crowd Metrics) -> Communication Selection (Dynamic Graph Attention) -> Message Generation -> Message Aggregation -> Planning (Expert-Guided with Deadlock Handling) -> Action Output

Critical path:
1. Agent receives local observation (neighbors within radius, static obstacles, own position/goal).
2. Perception module computes static and dynamic congestion values for the local region.
3. Communication selection identifies top-k relevant neighbors using attention weights.
4. For each selected neighbor, generate a message (e.g., intended direction, congestion estimate).
5. Aggregate received messages to augment the agent's state representation.
6. Planning module (e.g., a heuristic or lightweight policy) uses the augmented state to propose a motion, consulting deadlock-breaking rules if needed.
7. Execute the chosen action.

Design tradeoffs:
- **Communication Efficiency vs. Information Richness**: Limiting communication partners reduces bandwidth but risks omitting critical information; the attention mechanism aims to preserve the most useful messages.
- **Local Perception vs. Global Optimality**: Partial observability makes planning myopic; crowd perception extends the effective horizon by predicting congestion.
- **Reactive Deadlock Resolution vs. Path Stability**: Aggressive deadlock breaking can cause oscillations; the region-based expert tries to minimize disruption by focusing on compact groups.

Failure signatures:
- **Communication Breakdown**: Attention scores become uniform or degenerate, causing random partner selection and loss of coordination; manifested as increased collisions or idle agents.
- **Congestion Misestimation**: Underestimation of dynamic density leads agents into bottlenecks; observed as growing clusters and reduced progress.
- **Deadlock Resolution Failure**: Repeated deadlocks in the same region despite expert intervention, indicating either poor detection or ineffective resolution rules.

First experiments:
1. **Baseline Reproduction**: Run PC2P on the 64x100 map with 256 agents and compare success rate and episode length against EPH* and COMs as reported.
2. **Communication Ablation**: Disable the communication module (or replace with random selection) to quantify its impact on performance in low (128 agents) and high (512 agents) densities.
3. **Congestion Metric Variant**: Replace the crowd perception with a simpler metric (e.g., only static obstacles) and evaluate on a map with dynamic obstacles to test robustness.
