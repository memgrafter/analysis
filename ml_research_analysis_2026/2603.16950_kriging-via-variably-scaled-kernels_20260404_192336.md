# Kriging via variably scaled kernels

## Quick Facts
- arXiv ID: 2603.16950
- Source URL: https://arxiv.org/abs/2603.16950
- Reference count: 40
- Primary result: Variably scaled kernels (VSKs) enable non-stationary Gaussian process regression by lifting the input space with a scaling function, achieving lower reconstruction errors on discontinuous functions compared to stationary kernels.

## Executive Summary
This paper introduces variably scaled kernels (VSKs), a novel approach to non-stationary Gaussian process (GP) regression. VSKs augment the input space with a scaling function ψ and apply a stationary kernel in this lifted space, thereby encoding spatially heterogeneous correlation structures. For targets with known discontinuities, a piecewise constant ψ decouples correlations across jump boundaries, yielding improved accuracy and appropriate uncertainty quantification at those boundaries. Extensive experiments on synthetic 1D and 2D functions demonstrate substantial reductions in root mean square error (RMSE) compared to stationary Matérn kernels. Theoretical analysis shows that VSK covariances locally approximate Gibbs and Paciorek–Schervish kernels, but numerical evidence indicates this equivalence is only asymptotic near training points and fails globally, highlighting VSKs' unique geometric expressivity.

## Method Summary
The VSK framework defines a covariance function k(x, x') = k_stationary( (x - μ)/ψ(x), (x' - μ)/ψ(x') ), where ψ: ℝ^d → ℝ^+ is a positive scaling function applied per input dimension. By varying ψ across the input space, the effective length-scale of the stationary kernel changes, inducing non-stationarity. For discontinuous targets with a priori known jump locations, one can set ψ to be piecewise constant, causing the kernel to vanish across region boundaries and thus decouple correlations between different segments. Hyperparameters (including ψ’s parameters) are learned via maximum likelihood estimation (MLE). The method retains the computational complexity of standard GPs (O(N^3) for inversion) but requires evaluating ψ for each input during kernel computation.

## Key Results
- On a 1D discontinuous function with increasing sample sizes (N=27 to 791), VSKs reduced RMSE from 0.536 to 0.140 at N=81 relative to stationary Matérn C4 kernels.
- For a 2D highly irregular Weierstrass function (N=25), progressively matching ψ to the target’s dominant frequencies decreased RMSE from 0.020 to 0.002.
- For corner-type singularities, smooth ψ functions designed to capture gradient discontinuities yielded reconstructions with up to 40% lower RMSE and lower posterior uncertainty than stationary models.

## Why This Works (Mechanism)
VSKs exploit input-dependent scaling to modulate the effective distance in the kernel’s stationary reference space. A stationary kernel k0(Δ) depends only on the difference Δ = x - x'. By replacing Δ with (x/ψ(x) - x'/ψ(x')), points that are far apart in the scaled space have low correlation, even if they are close in the original space. Piecewise constant ψ creates distinct regions where the scaling is constant; across region boundaries, the scaled distance becomes large, effectively nullifying cross-region correlations. This decoupling prevents the GP from “smearing” across discontinuities, preserving sharp jumps and concentrating uncertainty exactly at the boundaries. The local asymptotic equivalence to Gibbs/Paciorek–Schervish kernels arises because, near any training point, the varying ψ can be approximated by a constant, making the kernel locally stationary; however, globally the scaling pattern can encode arbitrary non-stationarity beyond the stationary local approximation.

## Architecture Onboarding
Component map: Input (X, y) -> Scaling function ψ -> Lifted coordinates Z = X ./ ψ(X) -> Stationary kernel matrix K(Z) -> Add noise term -> Covariance matrix -> Cholesky decomposition -> Log marginal likelihood -> Optimize ψ -> Final GP with predictive distribution.

Critical path: The main computation involves constructing the kernel matrix K, which depends on ψ, then performing Cholesky decomposition to compute the log marginal likelihood and its gradients for optimizing ψ. This pipeline is repeated during hyperparameter optimization.

Design tradeoffs: Choice of ψ involves a trade-off between flexibility and prior knowledge. Piecewise constant ψ gives exact decoupling but requires known jump locations; smooth ψ (e.g., neural network) can learn arbitrary variations but may overfit and produce less calibrated uncertainty. The stationary kernel type (e.g., Matérn) controls smoothness within each region but adds computational overhead for higher degrees.

Failure signatures: (1) If jump locations are misspecified, correlations across true discontinuities remain, leading to oversmoothed reconstructions; (2) If ψ varies too rapidly, the kernel matrix may become ill-conditioned, causing numerical instability; (3) Overly complex ψ can overfit noise, yielding overconfident predictions and poor generalization.

## Limitations
- Piecewise constant ψ requires a priori knowledge of jump locations; performance degrades if discontinuities are unknown or incorrectly placed.
- Theoretical equivalence to Gibbs/Paciorek–Schervish kernels is only asymptotic near training points; global behavior remains unverified and may differ.
- Experimental validation is restricted to synthetic 1D/2D functions; applicability to high-dimensional real-world data and scalability to large N are not demonstrated.

## Confidence
- VSKs can model heterogeneous correlations via lifted stationary kernels: **High**
- Piecewise constant ψ yields decoupled correlations and improved reconstruction at discontinuities: **Medium**
- Asymptotic equivalence to Gibbs/Paciorek–Schervish kernels and distinct geometric expressivity: **Low**
