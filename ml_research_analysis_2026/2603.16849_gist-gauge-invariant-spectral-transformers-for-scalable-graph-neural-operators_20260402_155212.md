# GIST: Gauge-Invariant Spectral Transformers for Scalable Graph Neural Operators

## Quick Facts
- **arXiv ID:** 2603.16849
- **Source URL:** https://arxiv.org/abs/2603.16849
- **Reference count:** 40
- **Primary result:** Achieves 99.50% micro-F1 on PPI and state-of-the-art aerodynamic prediction (20.10% relative L2) on DrivAerNet with graphs up to 750K nodes, while maintaining O(N) scalability and discretization invariance.

## Executive Summary
GIST addresses catastrophic generalization in graph transformers caused by gauge dependence in spectral embeddings and cubic eigendecomposition costs. It introduces gauge-invariant spectral transformers that use random projections to approximate Laplacian eigenmaps in O(N) time, and restricts attention to inner products between projected embeddings to preserve invariance. The method combines this with linear attention and multi-scale branches, achieving O(N) end-to-end complexity. Key results include state-of-the-art performance on PPI (99.50% micro-F1) and DrivAerNet (20.10% relative L2), and successful transfer across mesh resolutions where non-invariant baselines fail.

## Method Summary
GIST computes approximate spectral embeddings via Fast Random Projections (FastRP) from the adjacency matrix in O(N·r·k) time. The core is gauge-invariant spectral self-attention: queries and keys are these projected embeddings, values are node features, and attention weights depend only on inner products between embeddings, which are approximately preserved by the Johnson-Lindenstrauss lemma. Gauge-equivariant spectral attention rescales embeddings based on features. Multiple such blocks form a multi-scale architecture with three branches: a feature branch (linear transformer on node features), a local branch (graph convolution plus linear transformer), and a global branch (combining invariant and equivariant spectral attention with linear transformer). End-to-end complexity is O(N(d² + r·k)) under sparse graphs.

## Key Results
- 99.50% micro-F1 on PPI node classification.
- State-of-the-art relative L2 error: 20.10% on DrivAerNet and 18.60% on DrivAerNet++ for aerodynamic prediction on graphs up to 750K nodes.
- Discretization invariance: gauge-invariant model transfers from coarse to fine mesh with only 15% drop vs. 47% for non-invariant baseline.

## Why This Works (Mechanism)
### Mechanism 1: Gauge Invariance via Inner-Product Restriction
Claim: Gauge invariance is preserved by restricting attention to inner products between approximate spectral embeddings.  
Mechanism: Random projections (FastRP) produce embeddings ˜ϕi = Rϕi. While R breaks gauge symmetry, inner products ˜ϕi⊤˜ϕj = ϕi⊤(R⊤R)ϕj ≈ ϕi⊤ϕj are approximately invariant by Johnson-Lindenstrauss. Attention weights are computed solely from these inner products.  
Core assumption: Random projection matrices R satisfy R⊤R ≈ I with high probability.  
Evidence anchors: [abstract] "preserves gauge invariance by restricting attention to inner products between projected embeddings"; [section 3.2] "inner products between projected embeddings ⟨Rϕi, Rϕj⟩ = ϕi⊤(R⊤R)ϕj ≈ ϕi⊤ϕj remain approximately invariant".

### Mechanism 2: O(N) Scalability
Claim: End-to-end O(N) computational complexity is achieved.  
Mechanism: FastRP computes approximate Laplacian eigenmaps in O(N·r·k) time. Linear attention (φ(Q)(φ(K)⊤V)) replaces quadratic softmax, yielding O(N·d²) per layer. Overall complexity: O(N(d² + r·k)).  
Core assumption: Graph has bounded average degree and linear attention with ReLU feature map is used.  
Evidence anchors: [abstract] "achieving end-to-end O(N) complexity through random projections"; [section 3.2] "linear transformer block... scales as O(N·d²)... Overall, this gives end-to-end O(N·d² + N·r·k) scaling".

### Mechanism 3: Discretization-Invariant Operator Learning
Claim: GIST enables discretization-invariant neural operator learning with bounded mismatch error O(n^{-1/(m+4)}) that vanishes as mesh resolution increases.  
Mechanism: Gauge-invariant attention kernel depends on inner products converging to continuum Green's function. Spectral convergence and random projection preservation together ensure bounded mismatch between discretizations.  
Core assumption: Underlying manifold is smooth, graphs are sampled appropriately (e.g., ε-neighborhood), and eigenvector convergence rates apply.  
Evidence anchors: [abstract] "proves GIST achieves discretization-invariant learning with bounded mismatch error"; [section 4.1] Proposition statement and proof; [section 4.2] Controlled experiment showing gauge-invariant model transfers successfully while non-invariant fails.

## Foundational Learning
**Graph Laplacian and spectral embeddings**: Needed to understand resistance distance via Laplacian eigenmaps. Quick check: How does resistance distance Ω(i,j) relate to Laplacian eigenmaps ϕi? Ans: Ω(i,j) = ||ϕi - ϕj||².  
**Johnson-Lindenstrauss lemma and random projections**: Justifies inner product preservation for gauge-invariant attention. Quick check: Required embedding dimension r to preserve inner products within ε with high prob? Ans: r = O(log N / ε²).  
**Linear attention and feature maps (e.g., ReLU)**: Avoids quadratic scaling; ReLU's kernel depends only on inner products, preserving gauge invariance. Quick check: Why φ(x)=ReLU chosen? Ans: It induces kernel k₀(a⊤b), so attention depends only on inner products.

## Architecture Onboarding
Component map: FastRP computes projected spectral embeddings. These feed into multi-scale GIST blocks: each block has three branches – (1) feature branch: linear transformer on node features, (2) local branch: GraphConv followed by linear transformer, (3) global branch: gauge-invariant spectral attention (Q,K=projected embeddings, V=features), gauge-equivariant spectral attention (Q,K=features, V=projected embeddings), then linear transformer. Branch outputs are combined (method unspecified: sum/concat?) and passed to next block. Final readout for prediction.  
Critical path: Input graph → FastRP embeddings → stack of multi-scale GIST blocks → task head.  
Design tradeoffs: Gauge invariance limits positional transformations but ensures invariance; embedding dimension r trades accuracy vs. memory; power iterations k trade spectral fidelity vs. preprocessing cost.  
Failure signatures: Catastrophic drop on mesh transfer indicates gauge leakage; VRAM/time not scaling linearly suggests quadratic attention or full eigendecomposition; performance saturation as r increases indicates over-projection.  
First 3 experiments: 1) Ablation study on PPI removing each branch to quantify contribution. 2) Scalability test: measure VRAM and time vs. graph size on DrivAerNet up to 750K nodes. 3) Discretization invariance: train on coarse mesh, test on fine mesh; compare gauge-invariant vs. non-invariant baseline.

## Limitations
- Branch fusion mechanism (sum vs. concat) unspecified, hindering exact reproduction.
- FastRP hyperparameters (r, k) for large graphs not reported; scaling with N unclear.
- Theoretical assumptions (smooth manifold, bounded degree, projection sparsity) not validated on real meshes.

## Confidence
- Gauge invariance: Medium (relies on JL approximation; small r may break).
- O(N) complexity: Medium (assumes sparse graphs; implementation details missing).
- SOTA accuracy: High (clear benchmark numbers).
- Discretization invariance: Medium (bound depends on unverified smoothness; only coarse-to-fine shown).
