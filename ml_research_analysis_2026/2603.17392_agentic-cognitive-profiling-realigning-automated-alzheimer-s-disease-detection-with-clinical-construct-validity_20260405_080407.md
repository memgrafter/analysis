# Agentic Cognitive Profiling: Realigning Automated Alzheimer's Disease Detection with Clinical Construct Validity

## Quick Facts
- **arXiv ID:** 2603.17392  
- **Source URL:** https://arxiv.org/abs/2603.17392  
- **Reference count:** 40  
- **Primary result:** ACP achieves 90.5% score match rate on task examination and 85.3% accuracy in supervised AD prediction, while generating interpretable cognitive profiles grounded in clinical evidence.

## Executive Summary
Automated Alzheimer's disease detection often relies on inductive pattern recognition, which sacrifices alignment with clinical cognitive constructs. This paper introduces Agentic Cognitive Profiling (ACP), an agentic framework that decomposes standardized assessments (e.g., MoCA, HKLLT) into atomic, clinically-defined cognitive tasks. Specialized LLM agents process each subtask, using deterministic function calling for quantification and a verification loop to correct errors. Evaluated on 402 participants across eight cognitive tasks, ACP matches human-assigned scores at 90.5% and predicts AD with 85.3% accuracy under supervised learning, outperforming baselines. Crucially, it produces interpretable domain-level reports that reflect the underlying clinical reasoning, realigning automated screening with construct validity.

## Method Summary
ACP operationalizes clinical assessment protocols by segmenting test transcripts into discrete subtasks (e.g., picture naming, digit span). Each subtask is assigned to a dedicated Examiner LLM agent, which parses natural language responses but delegates all numerical scoring to deterministic, rule-based functions (e.g., `list_length()`, `keyword_check()`) to prevent hallucination. A Verifier agent then reviews each Examiner's output against the original transcript, providing feedback for regeneration if discrepancies are found (up to 3 iterations). Verified scoring primitives are aggregated into a unified JSON profile, normalized using demographic-stratified normative tables, and fed into either a supervised SVM classifier or a zero-shot engine applying clinical thresholds. A Meta Analyst agent simultaneously generates an interpretable narrative report from the normalized profile, highlighting domain-specific deficits and supporting evidence.

## Key Results
- 90.5% score match rate on task-level examination compared to human assessors.
- 85.3% accuracy in supervised AD prediction, surpassing baseline models.
- Generates clinically interpretable cognitive profiles with verifiable evidence for each construct.

## Why This Works (Mechanism)

1. **Decomposition restores construct validity:** By breaking assessments into atomic tasks mirroring clinical subtests, ACP ensures extracted evidence directly corresponds to specific, validated cognitive constructs rather than spurious correlations. This alignment with clinical protocol logic is evidenced by the 90.5% task match rate across 402 participants.

2. **Deterministic scoring mitigates hallucination:** Semantic interpretation (e.g., extracting "lion" from "a lion, uh, a big cat") is decoupled from quantification, which is performed by reliable, rule-based functions. This prevents LLMs from fabricating or miscalculating scores. Ablation studies confirm this: removing function calling causes MAE on HKLLT Trial-4 to jump from 0.07 to 2.23.

3. **Verification loop corrects Examiner errors:** A dedicated Verifier agent checks Examiner outputs against transcripts, triggering regeneration for detected hallucinations or reasoning errors. This iterative loop (up to 3 retries) catches subtle mistakes, particularly on high-inference tasks. Evidence: Abstraction task accuracy improves from 64.7% (no Verifier) to 82.3% with verification.

## Foundational Learning

- **Clinical Construct Validity:** Ensures a test measures the theoretical cognitive construct it claims (e.g., memory) rather than irrelevant proxies (e.g., speech fluency). Needed because ACP prioritizes clinical alignment over black-box prediction. Quick check: What construct-irrelevant variance might a pattern-recognition AD detector accidentally learn? (e.g., disfluency patterns unrelated to cognition).

- **Standardized Cognitive Assessment Protocols:** Understanding the structure (subtasks, scoring rules, normative tables) of tests like MoCA and HKLLT is essential to appreciate ACP's decomposition and normalization. Quick check: Why are HKLLT Trial 4 and Trial 5 (delayed recall) clinically significant compared to immediate recall trials?

- **Agentic Workflows with Tool Calling:** LLM agents specialized for specific tasks, using deterministic tools and interacting in loops, form the implementation substrate. Needed because this architecture enables decomposition, reliable measurement, and error correction. Quick check: Why is unidirectional feedback (Verifier to Examiner) important in the verification loop design?

## Architecture Onboarding

Component map: Demographics + Segmented Transcripts -> Assigner -> Examiner Agents (x8) with function calling -> Verifier Agent (loop up to 3) -> Verified Primitives JSON -> Aggregator -> Norm Lookup -> [Zero-Shot Engine OR Supervised Classifier] -> Prediction Label; Meta Analyst operates in parallel to generate Cognitive Profile Report.

Critical path: Raw Transcript -> Examiner Agent (with function calls) -> Verifier Loop -> Verified Primitives -> Normalization -> Classifier/Thresholding -> Final Prediction.

Design tradeoffs:
- Granularity vs. Scalability: Decomposing into 8 tasks yields rich profiles but requires structured administration and segmented transcripts, limiting use on raw speech.
- Determinism vs. Flexibility: Fixed functions ensure reliable scoring but cannot handle novel or ambiguous clinical rules requiring judgment.
- LLM Size vs. Cost: Larger models reduce hallucination but increase deployment expense; verification loop mitigates smaller-model issues but adds latency.
- Interpretability vs. Performance: Supervised SVM on primitives is fully interpretable but may underfit compared to end-to-end PLMs; zero-shot path maximizes interpretability but depends on primitive quality and norms.

Failure signatures:
- Examination Failure: Low task-specific score match rate (SMR) indicates Examiner/Verifier pipeline issues; check prompt clarity, Verifier feedback efficacy, transcript quality.
- Normalization Failure: Mismatch between MoCA-SL and full MoCA scores suggests proportional rescaling is invalid for a subgroup.
- Prediction Failure: Discrepancy between zero-shot and supervised predictions (using same primitives) indicates classifier problems (e.g., imbalance) or suboptimal clinical thresholds.
- Profile Inconsistency: Meta Analyst report contradicts numerical evidence (e.g., claims "normal memory" but HKLLT z-score = -1.8); indicates flawed domain knowledge prompt or reasoning.

First experiments:
1. **Task-Specific Sanity Check:** Run Examination Engine on a hand-validated subset (e.g., 10 transcripts per task) to isolate initial Examiner SMRs before Verifier intervention; identify high-inference tasks needing robust Verifier design.
2. **Verification Loop Stress Test:** For a high-error task (e.g., Serial 7s), compare SMR with `Nmax=0` (no Verifier) vs. `Nmax=3`; audit Verifier feedback logs to distinguish hallucination correction from reasoning correction.
3. **Normative Table Sanity Check:** Plot MoCA-SL scores for the HC group against the adopted normative table; verify that the 16th percentile cutoff aligns with expected HC/AD separation and detect demographic biases.

## Limitations
- **Generalizability:** Evaluation on 402 participants across 8 tasks is narrow; unknown performance on diverse populations (e.g., early-stage AD, comorbidities) or other assessments (e.g., MMSE).
- **Normative Table Validity:** Proportional rescaling for MoCA-SL assumes linear relationship with full MoCA; demographic mismatches could distort percentile cutoffs.
- **Transcript Dependency:** Requires pre-segmented, task-specific responses, limiting applicability to raw clinical conversations.

## Confidence
- Decomposition restores construct validity: **Medium** (90.5% task match supports alignment, but clinical adoption beyond study tasks is unproven).
- Deterministic function calling mitigates hallucination: **High** (ablation shows catastrophic degradation without it, e.g., HKLLT MAE 0.07→2.23).
- Verification loop corrects Examiner errors: **Medium** (improves high-inference tasks like Abstraction 64.7%→82.3%, but may miss subtle, consensus-based errors).
