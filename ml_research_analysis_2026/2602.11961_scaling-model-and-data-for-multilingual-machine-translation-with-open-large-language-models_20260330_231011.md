# Scaling Model and Data for Multilingual Machine Translation with Open Large Language Models
## Quick Facts
- **arXiv ID**: 2602.11961
- **Source URL**: https://arxiv.org/abs/2602.11961
- **Reference count**: 24
- **Key outcome**: Open model scaling (12B params) achieves competitive multilingual translation across 46 languages

## Executive Summary
This study addresses the challenge of achieving competitive multilingual machine translation performance using open large language models. The authors adapt the Gemma3 model family through a two-stage process: continual pretraining on a massive parallel corpus (4.9B sentence pairs) followed by instruction finetuning on high-quality data (264K pairs). The resulting MiLMMT-46 model suite demonstrates that both model and data scaling significantly improve translation quality across 46 languages, outperforming recent open-source baselines and achieving competitive performance against proprietary systems like Google Translate and Gemini 3 Pro.

## Method Summary
The core methodology involves adapting Gemma3 through continual pretraining on a large-scale parallel corpus, followed by instruction finetuning on a curated dataset. The approach leverages model and data scaling, with larger models (12B parameters) showing superior data efficiency. The study systematically evaluates performance across 46 languages using FLORES+ and WMT24++ benchmarks, demonstrating that open models can achieve competitive multilingual translation quality when properly scaled and trained.

## Key Results
- MiLMMT-46 model suite consistently outperforms recent open-source baselines (TranslateGemma, Seed-X) on FLORES+ and WMT24++ benchmarks
- Larger models (12B parameters) demonstrate superior data efficiency and translation quality
- MiLMMT-46-12B achieves competitive performance against proprietary systems (Google Translate, Gemini 3 Pro) across 46 languages
- Tokenizer efficiency from Gemma3 contributes to better non-English representation

## Why This Works (Mechanism)
The study demonstrates that multilingual machine translation quality scales predictably with both model size and training data quantity. Larger models show improved data efficiency, meaning they extract more value from each training example. The two-stage training approach (continual pretraining + instruction finetuning) allows models to first learn general multilingual representations before specializing in translation tasks. The efficient tokenizer inherited from Gemma3 helps maintain quality across non-English languages by better handling linguistic diversity.
