# Upper Entropy for 2-Monotone Lower Probabilities

## Quick Facts
- **arXiv ID:** 2603.23558  
- **Source URL:** https://arxiv.org/abs/2603.23558  
- **Reference Count:** 15  
- **Primary Result:** Upper entropy for credal sets induced by 2-monotone lower probabilities can be computed in strongly polynomial time via supermodular optimization, with specialized algorithms achieving near-linear complexity for important subclasses.

## Executive Summary
This paper tackles the efficient computation of upper entropy—a fundamental uncertainty measure—for credal sets defined by 2-monotone lower probabilities, a widely used model in imprecise probability. The core contribution is a rigorous complexity analysis that reinterprets a known algorithm (Abellán–Moral) through supermodular optimization, proving it runs in strongly polynomial time. A decomposition algorithm is introduced that reduces the number of required supermodular function maximization (SFM) calls from quadratic to linear. For special cases like belief functions, possibility distributions, and probability intervals, tailored algorithms achieve even better complexities (e.g., O(n) max-flow, O(n) convex hull, O(n log n/ε) hybrid search). An approximate Frank–Wolfe method is proposed for large-scale problems, and experiments on probability intervals show orders-of-magnitude speedups over prior work.

## Method Summary
The input is a 2-monotone lower probability μ (supermodular) given by an oracle, or one of three special cases: a belief function (mass function), a possibility distribution (π), or coordinate-wise probability intervals (l_i, u_i). The core engine selects an algorithm: for general 2-monotone sets, a decomposition algorithm (Algorithm 2) solves the entropy maximization over the base polyhedron B(¯μ) using O(n) SFM calls; for special cases, reductions to max-flow (belief), convex hull (possibility), or a hybrid Newton–binary search (intervals) are applied. For very large n, an approximate Frank–Wolfe method uses a linear minimization oracle over the credal set. Validation involves comparing exact outputs with brute-force for tiny n and benchmarking runtimes against prior methods.

## Key Results
- The Abellán–Moral algorithm for upper entropy runs in strongly polynomial time (O(n²) SFM calls) via a reduction to supermodular function maximization.
- A decomposition algorithm computes upper entropy with only O(n) SFM calls by exploiting the base polyhedron structure of 2-monotone credal sets.
- Specialized algorithms achieve improved complexities: O(n) max-flow for belief functions; O(n) convex hull for possibility distributions; O(n log n/ε) hybrid Newton–binary search for probability intervals.
- The approximate Frank–Wolfe method scales to large n, and empirical results on probability intervals show significant speedups over the O(n²) baseline.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The Abellán–Moral algorithm runs in strongly polynomial time because its key optimization reduces to O(n) supermodular function maximization (SFM) problems.
- **Mechanism:** Finding A maximizing μ(A)/|A| is equivalent to solving g(λ)=max_{B≠∅} μ(B)−λ|B| for λ* via Dinkelbach’s method. Since μ is supermodular, μ_λ(A)=μ(A)−λ|A| remains supermodular, so each g(λ) evaluation is an SFM. The finite set of candidate λ values (M_k/k) ensures O(n) SFM calls.
- **Core assumption:** μ is 2-monotone (supermodular).
- **Evidence anchors:** [abstract] "reinterprets the existing Abellán–Moral algorithm through the lens of supermodular optimization, proving it runs in strongly polynomial time (O(n²) SFM calls)." [section 3, Lemma 1] Explicit reduction of argmax to SFM via supermodularity of μ(A)−λ|A|.
- **Break condition:** If μ is not supermodular, the SFM reduction fails; the algorithm may become exponential.

### Mechanism 2
- **Claim:** The decomposition algorithm (Algorithm 2) computes upper entropy with only O(n) SFM calls by exploiting the base polyhedron structure.
- **Mechanism:** The problem min_{p∈B(ν)} Σ p_i log p_i is solved by constructing a chain ∅=S_0⊂⋯⊂S_l=Ω where each S_j maximizes ν(A)−α Σ_{i∈A} b_i for α in an interval. The recursive DA(S,S') procedure finds these sets via SFM at each breakpoint, requiring O(n) total calls.
- **Core assumption:** For 2-monotone μ, the credal set P(μ) equals the base polyhedron B(¯μ).
- **Evidence anchors:** [abstract] "a decomposition algorithm requiring only O(n) SFM calls." [section 3, Proposition 2] Direct mapping of Algorithm 2 to upper entropy with ν=¯μ, b=1.
- **Break condition:** If the base polyhedron representation fails (e.g., μ not 2-monotone), Algorithm 2 no longer computes upper entropy.

### Mechanism 3
- **Claim:** Special cases (belief functions, possibility distributions, probability intervals) admit faster algorithms by leveraging their specific structure.
- **Mechanism:** Belief functions reduce min_A Pl(A)−α|A| to a minimum cut in a bipartite flow network. Possibility distributions convert the lower envelope of lines Π(A)−α|A| into an upper convex hull problem. Probability intervals solve f(x)=Σ_i min{max{x,l_i},u_i}=1 via a hybrid Newton–binary search.
- **Core assumption:** The credal set matches the special case structure (mass function for belief, possibility ranking π, or coordinate-wise intervals).
- **Evidence anchors:** [abstract] "O(n) max-flow for belief functions, O(n) for possibility distributions via convex hull computation, and O(n log n/ε) for probability intervals via a hybrid Newton–binary search." [section 4] Propositions 3–7 detail each reduction.
- **Break condition:** Mismatch between credal set and special case structure forces fallback to the general decomposition or Frank–Wolfe.

## Architecture Onboarding
Input handler -> Case detector -> Core engine -> Output formatter

**Critical path:**
1. Case detector checks if input matches a special case (belief/possibility/intervals); if yes, use the corresponding tailored algorithm.
2. Else, for moderate n and exact solution, run the decomposition algorithm (Algorithm 2) with an SFM oracle (e.g., Orlin’s algorithm).
3. For large n or when approximation is acceptable, use the Frank–Wolfe method with a smooth surrogate entropy.

**Design tradeoffs:**
- Exact vs approximate: Decomposition guarantees exactness but requires O(n) SFM calls; Frank–Wolfe is heuristic but scales better.
- General vs specialized: Specialized algorithms exploit structure (max-flow O(|F|), convex hull O(n)) but apply only to specific credal sets.
- Initial point cost: Frank–Wolfe’s initial p⁰>0 construction is O(n²) but can be avoided with a surrogate and linear-time projection.

**Failure signatures:**
- Non-supermodular μ: decomposition or SFM reductions fail; fallback to enumeration (exponential).
- Empty credal set (e.g., Σ l_i > 1 or inconsistent intervals): algorithms may loop or crash; requires pre-check feasibility.
- Frank–Wolfe divergence: if ¯μ({i})=0 for some i, no p⁰>0 exists; must use surrogate or handle zeros separately.

**First 3 experiments:**
1. Unit test on synthetic 2-monotone μ: For n=5, verify decomposition output matches brute-force entropy maximization over P(μ).
2. Benchmark against Abellán–Moral: On probability intervals, compare hybrid Newton–binary search (Alg4) runtime vs. the O(n²) method of Abellán & Moral (2003) for n=10⁷; expect orders-of-magnitude speedup.
3. Scalability stress test: For general 2-monotone μ with n=5×10⁵, compare decomposition (using Orlin SFM) vs. Frank–Wolfe with surrogate; Frank–Wolfe should complete while decomposition times out.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How do the proposed algorithms scale and perform across all credal set types?
- **Basis in paper:** [explicit] The conclusion states: "In the future, we aim to perform much more comprehensive experiments."
- **Why unresolved:** Current experiments cover only 2-monotone lower probabilities and probability intervals; belief functions and possibility distributions were not evaluated, and scalability beyond n≈2×10⁵ (2-monotone) or n≈10⁸ (probability intervals) is unknown.
- **What evidence would resolve it:** Systematic large-scale benchmarks (n up to 10⁶) for every special case (belief functions with many focal sets, possibility distributions, ε-contamination models) on real-world ML tasks (e.g., active learning, conformal prediction), reporting runtime, memory usage, and accuracy for exact and approximate methods.

### Open Question 2
- **Question:** For belief functions, which approach is more practical: the exact max-flow algorithm or the approximate Frank–Wolfe method?
- **Basis in paper:** [explicit] The conclusion explicitly calls for comparing "the exact resolution approach using maximum-flow algorithms with the approximate one via Frank–Wolfe."
- **Why unresolved:** The exact O(n) max-flow algorithm was presented but not tested; Frank–Wolfe was applied only to general 2-monotone sets and probability intervals, not to belief functions. No empirical or theoretical comparison exists.
- **What evidence would resolve it:** Implement both algorithms on belief functions; vary the number of focal sets and mass function sparsity; measure computation time, memory, and approximation error (duality gap); possibly derive convergence rates for Frank–Wolfe in this polyhedral setting.

### Open Question 3
- **Question:** Can submodular optimization be leveraged to compute other robust uncertainty measures (KL divergence, Wasserstein metric, optimal transport) for 2-monotone credal sets?
- **Basis in paper:** [explicit] The conclusion asks: "to which extent classical results issued from submodular optimization can help... for KL divergences, Wasserstein metrics. Another interesting topic ... is optimal transport."
- **Why unresolved:** The paper only treats upper entropy; other crucial measures remain unexplored computationally for 2-monotone credal sets.
- **What evidence would resolve it:** Formulate each measure as an optimization over base polyhedra; prove polynomial solvability (exact or approximate); design and implement scalable algorithms; test on synthetic and real data; establish worst-case complexity bounds.

## Limitations
- The algorithm relies on an oracle for supermodular function maximization; actual runtime depends on the underlying SFM method, and a strongly polynomial SFM algorithm is not known in general.
- Frank‑Wolfe is only approximate; no guarantee on the number of iterations to reach a target accuracy, particularly for the non‑smooth entropy objective.
- The O(n) claim for belief functions assumes a max‑flow solver with linear time complexity; standard implementations (e.g., Dinic) have super‑linear worst‑case bounds.

## Confidence
- **Abellán–Moral complexity (O(n²) SFM calls):** High – the reduction via Lemma 1 and the finite λ set is mathematically sound under supermodularity.
- **Decomposition algorithm (O(n) SFM calls):** High – Proposition 2 maps the problem to the base polyhedron and the chain construction uses at most n breakpoints.
- **Special‑case algorithms:**  
  - Belief functions (max‑flow) and possibility distributions (convex hull): High.  
  - Probability intervals (hybrid Newton–binary): Medium – worst‑case complexity of the iterative method is not rigorously proven.
- **Frank–Wolfe approximation:** Medium – empirical evidence supports speed, but theoretical iteration bounds are missing and convergence may be slow for degenerate credal sets.
