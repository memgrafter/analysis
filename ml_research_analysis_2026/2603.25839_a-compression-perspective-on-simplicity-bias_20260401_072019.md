# A Compression Perspective on Simplicity Bias

## Quick Facts
- **ArXiv ID**: 2603.25839  
- **Source URL**: https://arxiv.org/abs/2603.25839  
- **Reference count**: 11  
- **Primary result**: Neural networks' simplicity bias-driven feature selection transitions across dataset sizes are precisely predicted by MDL theory, with empirical crossovers aligning strongly (r=0.976), revealing a robustness window where limited data acts as complexity-based regularization.

## Executive Summary
This paper formalizes supervised learning under simplicity bias as a Minimum Description Length (MDL) two-part compression problem. Using a semi-synthetic MNIST benchmark with controllable spurious (color) and complex (watermark) features, the authors show that dataset size dictates whether neural networks favor simple shortcuts or robust/complex features. Theoretical transition points derived from compression cost trade-offs match empirical observations with high correlation (Pearson r=0.976). This reveals a double-edged effect: increasing data first eliminates spurious cues (promoting robustness) but later may encourage reliance on complex environmental cues, making data limitation a form of complexity regularization.

## Method Summary
The study builds a binary classification task on modified EMNIST digits with three injectable features: digit shape (robust), color (simple spurious), and watermark (complex environmental). For each candidate feature-specific model, the fixed description length is estimated via prequential coding, and the variable data encoding cost is measured as held-out cross-entropy. The total MDL cost as a function of dataset size N yields affine lines whose lower envelope predicts which feature is optimal at each N. Empirically, MLPs are trained on varying N, and feature reliance is measured via permutation importance and feature-specific test sets. The crossover points where dominant feature switches are compared to theoretical predictions across variations like watermark bank size and noise levels.

## Key Results
- Supervised learning under simplicity bias minimizes a two-part MDL objective: fixed model description length plus N times average KL divergence to the data distribution.
- Empirical dataset-size transitions between spurious and robust features align strongly with MDL-predicted crossover points (r=0.976).
- A robustness window exists: moderate data sizes favor robust features; too little data favors spurious shortcuts, while too much may enable complex environmental cues.

## Why This Works (Mechanism)
The two-part MDL objective creates a trade-off: simpler models have lower fixed cost but higher variable cost if less predictive; as N grows, variable cost dominates, pushing toward more predictive (often more complex) models. The predicted transition between two candidate models is \(N^* = \frac{L_L(p_2) - L_L(p_1)}{\mathbb{E}[D_{KL}(p^* \| p_1)] - \mathbb{E}[D_{KL}(p^* \| p_2)]}\), where \(L_L\) is description length and KL is predictive inaccuracy. This yields a robustness window: spurious features win at small N, robust at intermediate N, and Bayes-optimal complex features at large N. The strong empirical correlation confirms neural networks approximate MDL-optimal compressors, and simplicity bias governs learning dynamics via these compression cost-benefit thresholds.

## Architecture Onboarding
**Component map**:  
Data generator -> Feature-isolated datasets -> [Prequential coding estimator & Cross-entropy evaluator] -> Compression envelope -> Theoretical transition prediction. Parallel: Neural network trainer -> Empirical feature reliance measurement -> Empirical transition. Comparison -> Correlation analysis.

**Critical path**:  
1. Choose scenario parameters (e.g., Scenario A: pe=0.25, pflip=0, no watermark).  
2. For each feature (digit, color, watermark): create isolated dataset, train converged model, compute prequential code length \(L_L(p)\) and held-out cross-entropy \(\ell(p)\).  
3. Generate intermediate models by truncating prequential curves at exponentially increasing points to obtain pairs \((L_L(p_{N_t}), \ell(N_t))\).  
4. For each N, compute total cost \(J(p,N)=L_L(p)+N\cdot\ell(p)\) for all intermediate models; find lower envelope; record theoretical transition \(N_{theory}\).  
5. Train neural networks on original dataset for each N.  
6. Evaluate networks via permutation importance and feature-specific test sets; determine empirical transition \(N_{empirical}\).  
7. Compare \(N_{theory}\) and \(N_{empirical}\); repeat for varied task parameters (e.g., watermark bank size K).

**Design tradeoffs**:  
- Semi-synthetic data offers control but lacks real-world complexity; real data introduces confounders.  
- MLP architecture reduces computational cost but may not reflect modern networks; however, theory is architecture-agnostic.  
- Block-wise prequential approximation makes computation feasible but introduces bias; exponential block sizes mitigate error.  
- Disjoint feature models assume exclusive feature use; real networks blend features, leading to gradual transitions.  
- Feature-specific test sets require perfect isolation; imperfect randomization leaks signals.

**Failure signatures**:  
- Prequential estimates are noisy, non-monotonic, or don't scale with model complexity.  
- Compression envelope lines don't cross cleanly; multiple intersections.  
- Empirical feature reliance shows no clear transition (e.g., spurious remains dominant at large N in Scenario A).  
- Theoretical vs empirical correlation low (\(r < 0.9\)).  
- Feature-isolated models fail to converge or show unexpected hierarchies.

**First 3 experiments**:  
1. Reproduce Scenario A transition: pe=0.25, pflip=0. Verify color dominates at small N (100–1,000), digit dominates at large N (100,000); crossover matches envelope prediction within factor 2.  
2. Reproduce Scenario B transition: pe=0.5, pflip=0.15, K=50. Verify digit dominates at intermediate N (1,000–10,000), watermark at large N (100,000); check peak in digit reliance near transition.  
3. Validate complexity scaling: In Scenario B, vary watermark bank size K (1,10,50,100). Plot theoretical vs empirical transition N for each K; expect monotonic increase in N with K and correlation >0.95.

## Open Questions the Paper Calls Out
**Open Question 1**: How does the MDL-based feature selection framework extend to scenarios where multiple features are partially predictive and entangled, rather than disjoint? The framework assumes candidate models exploit strictly disjoint feature subsets; real-world tasks involve overlapping, correlated cues that may lead to blended behaviors not captured by sharp transitions. Evidence to resolve: design controlled datasets with partially predictive correlated features; estimate compression envelopes for models combining features; compare predicted vs empirical feature reliance.

**Open Question 2**: To what extent does the description length \(L_L(p)\) depend on the specific learning algorithm (optimizer, architecture, initialization), and how does this affect predicted transition points? Prequential coding inherently depends on training procedure; different algorithms might yield different \(L_L(p)\) estimates, shifting crossover points. Evidence to resolve: estimate \(L_L(p)\) for candidate models trained with different algorithms (SGD vs Adam, different architectures) on the same tasks; correlate variations in \(L_L(p)\) with changes in empirical N.

**Open Question 3**: Why do neural networks exhibit continuous, gradual shifts in feature reliance around the predicted transition point, whereas the MDL envelope predicts a discrete switch? Theory assumes models that perfectly capture one feature; real networks may learn incomplete representations of multiple features simultaneously, smoothing the transition. Evidence to resolve: construct intermediate models that deliberately blend features; compute their compression costs; check if lower envelope over hybrids becomes continuous, matching empirical gradual transitions.

**Open Question 4**: Does the MDL-based prediction hold for architectures beyond simple MLPs and for more complex, natural image datasets? Experiments use 2-layer MLP on semi-synthetic MNIST; the theory may generalize but lacks validation on CNNs, transformers, or non-synthetic data. Evidence to resolve: replicate pipeline with ResNet, ViT on benchmarks like Waterbirds or COCO with controlled spurious/complex cues; compare theoretical vs empirical transitions.

## Limitations
- Prequential coding schedule (block sizes) not detailed in paper; critical for accurate \(L_L(p)\) estimation.
- Envelope construction from truncated prequential curves is ambiguous; how intermediate models are obtained is unspecified.
- Semi-synthetic data may not capture real-world feature complexity and confounders.
- Feature isolation assumption (disjoint models) often unrealistic; networks blend features, causing gradual transitions.

## Confidence
- **MDL two-part formulation as simplicity bias**: Medium (theoretically plausible but not directly verified).
- **Transition point formula**: High (empirical correlation strong, but depends on uncertain \(L_L(p)\) estimates).
- **Robustness window**: Medium (supported by controlled experiments, but limited to specific tasks).
