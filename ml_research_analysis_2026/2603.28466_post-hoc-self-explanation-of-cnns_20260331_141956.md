# Post-hoc Self-explanation of CNNs

## Quick Facts
- **arXiv ID:** 2603.28466
- **Source URL:** https://arxiv.org/abs/2603.28466
- **Reference count:** 13
- **Primary result:** Standard CNNs can be reinterpreted as self-explainable models; replacing the final linear layer with k-means centroids (KMEx) aligns prototypes with data clusters while maintaining classification accuracy, and using intermediate feature maps (B234) generates dense, concept-based explanation maps at the cost of accuracy.

## Executive Summary
The paper establishes that standard CNNs with average pooling followed by a linear classifier are mathematically equivalent to self-explainable models (SEMs), where classifier weights act as prototypes. To improve prototype representativeness, the authors propose KMEx, which replaces the linear classifier's weight vectors with k-means centroids learned from the encoder's pooled features. KMEx significantly increases the alignment between prototypes and class embeddings without sacrificing classification accuracy. For richer explanations, the approach is extended to intermediate feature activations (e.g., B234, using the last three residual blocks) by concatenating spatially upsampled features and clustering them. This yields dense, concept-based segmentation maps and gradient-free attribution, though with a notable drop in classification accuracy on fine-grained datasets.

## Method Summary
The method operates on a frozen pretrained ResNet34. For KMEx, the avgpool output (512-dim vector) is extracted for all training images; class-wise k-means is run to learn `K/C` centroids per class, where `K` is total prototypes and `C` is number of classes. Prediction assigns a new pooled vector to its nearest centroid. For B234, outputs from blocks 2, 3, and 4 are upsampled to a shared resolution (56×56), each channel is separately L2-normalized over space, then concatenated to a 896-dim feature per location. Class-wise k-means on these spatial features learns prototypes. For an image, each spatial location is assigned to a prototype; class predictions are made by pooling assignments over all locations. Explanation maps are the prototype assignment matrices. Attribution maps are generated by first computing a CAM-like score on block4 using the classifier's weight for the predicted class, then recursively upsampling and averaging these scores within prototype-defined segments from deeper to shallower blocks.

## Key Results
- Standard CNN classifier weights have low cosine similarity (~0.5) with class text embeddings; KMEx increases this to ~0.9, showing much better alignment.
- KMEx matches the backbone's classification accuracy (e.g., 79.1% on CUB-200 test) while providing more data-representative prototypes.
- Using B234 (intermediate features) improves semantic fidelity of explanation maps but causes a large accuracy drop (52.8% vs. B4's 75.2% on CUB-200).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Standard CNNs with average pooling followed by a linear classifier are structurally equivalent to self-explainable models (SEMs), where classifier weights act as prototypes.
- **Mechanism:** The commutativity of average pooling and the dot product allows the final prediction to be expressed as the average of per-spatial-location similarities to classifier columns (`cj`), mathematically equating the CNN to an SEM with `C` prototypes.
- **Core assumption:** The architecture strictly follows `encoder -> average pooling -> linear classifier`.
- **Evidence anchors:**
  - [abstract] States CNNs can be "mathematically reinterpreted as Self-Explainable Models".
  - [section 3.1] Provides Theorem 1 and Equation 5 proving the equivalence via commutativity.
  - [corpus] Corpus shows weak relatedness; no direct evidence found. *Assumption: This mathematical property holds for any architecture conforming to the specified structure.*
- **Break condition:** If the model omits average pooling, uses a non-linear classifier head, or employs global average pooling *after* the linear layer, the equivalence does not hold.

### Mechanism 2
- **Claim:** Replacing the linear classifier's weight vectors with k-means centroids (KMEx) aligns prototypes with actual data clusters, improving representativeness without sacrificing classification accuracy.
- **Mechanism:** For each class, `K/C` centroids are learned via k-means on the pooled encoder features (`z`). Prediction uses a nearest-prototype rule with an RBF-like similarity (`exp(-||h-pk||²)`), projecting to a one-hot class vector. Centroids are data-driven, not merely the direction of class embeddings.
- **Core assumption:** K-means clustering on the training set's final-layer features yields centroids that are more representative of the underlying data distribution than the original classifier's weight vectors.
- **Evidence anchors:**
  - [abstract] Claims KMEx "aligns prototypes with data clusters while maintaining classification accuracy."
  - [section 3.2] Details the KMEx procedure: class-wise k-means, RBF similarity, nearest-neighbor projection.
  - [Table 1] Shows CNN classifier cosine similarity with class embeddings ~0.5 vs. KMEx ~0.9, indicating poor vs. strong alignment.
- **Break condition:** If the feature space is highly non-convex or clusters are irregularly shaped, k-means centroids may be poor representatives. Performance drop would occur if the classifier's weight vectors, while misaligned, already captured a discriminative decision boundary that k-means disrupts.

### Mechanism 3
- **Claim:** Extending k-means explanations to intermediate feature activations (e.g., B234: last three residual blocks) generates dense, concept-based explanation maps by leveraging the spatial consistency of convolutional feature maps.
- **Mechanism:** Intermediate outputs from multiple depths are upsampled to a common resolution, concatenated after normalization, and clustered with k-means. The cluster assignments form a low-res segmentation map (explanation map). Feature importance (attribution) is propagated from the classifier's weights upwards via segment-wise averaging of CAM-style scores, using the spatial correspondence ensured by the convolutional architecture.
- **Core assumption:** The spatial correspondence between features at different depths (due to strided convolutions/pooling) allows valid upsampling and assignment propagation. Concepts are represented by consistent regions across depths.
- **Evidence anchors:**
  - [abstract] Mentions "dense, concept-based explanation maps via gradient-free spatial averaging" from intermediate activations (B234).
  - [section 3.3] Defines the process: multi-depth concatenation (Equation 8), cluster assignment matrix `qs` as explanation map (Equation 9), and gradient-free attribution via segment-wise averaging.
  - [Figure 1] Visualizes B234 producing finer-grained maps compared to B4.
- **Break condition:** If the network uses aggressive spatial downsampling (e.g., large stride early on) or non-local operations (like attention), the spatial correspondence assumption breaks, making upsampling and propagation invalid. Concept purity would degrade if intermediate features are too noisy or texture-biased.

## Foundational Learning
- **Concept: CNN Encoder-Block Decomposition**  
  **Why needed:** To access and combine intermediate feature maps (as in B234), one must understand how a standard ResNet is structured into sequential blocks with decreasing spatial resolution.  
  **Quick check:** If a ResNet34 has four residual blocks, what are the typical spatial resolutions (height/width) of the outputs of block2 (B2), block3 (B3), and block4 (B4) for a 224x224 input? *(Expected: B2 ~56x56, B3 ~28x28, B4 ~7x7)*
- **Concept: k-means Clustering**  
  **Why needed:** The core of KMEx and B234 is learning prototype vectors via k-means on frozen feature representations. Understanding its objective (minimizing within-cluster sum of squares) and sensitivity to initialization/scale is crucial.  
  **Quick check:** Why is it important to normalize feature rows (`u(b)/||u(b)||`) before concatenation in Equation 8 before running k-means? *(Expected: To prevent features from blocks with larger channel dimensions (`Db`) from dominating the Euclidean distance.)*
- **Concept: Spatial Consistency in Convolutional Networks**  
  **Why needed:** The gradient-free attribution propagation in B234 relies on the fact that a pixel in a higher-resolution map corresponds to a fixed receptive field in the lower-resolution map, allowing meaningful segment-wise averaging.  
  **Quick check:** If a 2x2 max-pooling layer reduces spatial dimensions by half, what is the receptive field ratio between the input and output pixels? *(Expected: Each output pixel aggregates a 2x2 region from the input.)*

## Architecture Onboarding
**Component map:**  
Input → Frozen ResNet34 backbone → Feature extraction from specified blocks (B2, B3, B4) → Preprocessing (upsample to common resolution, per-channel normalization, concatenation into `qh`) → k-means prototype learning per class → For prediction: assign each spatial location to nearest prototype (`qs`), then pool assignments per class to get prediction `y`. Attribution: compute CAM-like scores on B4, then recursively upsample and average by prototype segments from deeper to shallower blocks.

**Critical path:** The forward path is: Input → Backbone → Multi-depth Feature Extraction & Concatenation (`qh`) → k-means Assignment (`qs`) → Class Prediction (`y`) & Segmentation Map. Attribution flows backward from classifier weights through B4, then segmented upsampling to shallower layers.

**Design tradeoffs:**
- *Depth vs. Fidelity:* Using only B4 (final output) maintains accuracy but yields coarse, less semantically meaningful concepts. Using B234 (shallower outputs) improves concept granularity and alignment but hurts classification accuracy (52.8% vs 75.2% on CUB-200).
- *Prototype Count (K):* More prototypes per class (higher `K/C`) can better cover intra-class variation but increases computational cost for k-means and assignment.
- *Preprocessing:* The choice of shared resolution `R'` and normalization scheme (`u(b)/||u(b)||`) balances information from different depths but is heuristic.

**Failure signatures:**
- **Poor Prototype Diversity:** k-means produces redundant centroids (e.g., one dominant direction per class). Check: Cosine similarity between learned prototypes within a class is very high.
- **Spatial Misalignment:** Explanation maps `qs` appear noisy or discontinuous across depths, indicating violated spatial consistency assumption. Check: Visual inspection of `qs` at different depths for the same input.
- **Severe Accuracy Drop** (B234): Test accuracy drops far below the backbone (e.g., >10% on CUB-200). Suggests the combined multi-depth features are not discriminative enough for the linear projection step.
- **K-means Scalability:** Memory/time explosion on large datasets (e.g., ImageNet-scale). The paper notes this as a primary limitation.

**First 3 experiments:**
1. **Replication of KMEx (Classifier-only):** On CUB-200, replace the final linear layer of a frozen ResNet34 with a k-means classifier (`K/C=10`). Verify accuracy matches backbone (~79.1%) and prototype-class cosine similarity increases to ~0.9 (Table 1).
2. **B4 vs. B234 Comparison:** Extract features from B4-only and B234 (B2+B3+B4). Train k-means and evaluate classification accuracy and segmentation map quality. Expect B234 accuracy ~52.8% on CUB-200 with finer maps (Figure 1).
3. **Attribution Map Validation:** For B234, compute the gradient-free attribution maps. Compare them qualitatively to Grad-CAM on sample images. Expect maps that highlight class-relevant regions without gradient artifacts, but possibly with blocky, segment-averaged appearance.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can the k-means-based post-hoc explanation framework be scaled to handle very large datasets without compromising prototype quality?  
  *Basis in paper:* [explicit] The conclusion states: "The primary limitation is the scalability of k-means to large datasets, though preliminary results suggest that performance remains stable on subsets of the training data."  
  *Why unresolved:* Standard k-means has linear time complexity in the number of samples; for millions of images it becomes computationally prohibitive. The authors note stability on subsets but do not explore scalable approximations or sampling strategies.  
  *What evidence would resolve it:* Empirical evaluation of approximate k-means variants (e.g., MiniBatch k-means, coreset-based methods) on large-scale datasets (e.g., ImageNet), measuring prototype diversity (e.g., average within-class cosine similarity) and classification accuracy. A theoretical analysis of approximation guarantees would also strengthen the solution.
- **Open Question 2:** Why do models using k-means cluster centroids (KMEx) or multi-depth cluster distributions (B4/B234) maintain classification accuracy comparable to the original CNN?  
  *Basis in paper:* [explicit] The conclusion says: "The sustained classification performance of B4 and B234 using cluster distributions calls for further investigation."  
  *Why unresolved:* It is surprising that replacing the learned linear classifier with nearest-centroid decisions (or aggregating cluster counts across layers) does not degrade accuracy. Understanding why this works could reveal key properties of the feature space and the robustness of the post-hoc approach.  
  *What evidence would resolve it:* Analyze the decision boundaries of nearest-centroid vs. linear classifiers; measure intra-class compactness and inter-class separation; conduct controlled experiments where centroids are perturbed (e.g., random shifts, reduced numbers) to test sensitivity and identify the factors preserving accuracy.
- **Open Question 3:** Can the accuracy drop in B234 (using shallower activations) be reduced while preserving its high semantic fidelity (i.e., detailed concept maps)?  
  *Basis in paper:* [inferred] The abstract and Section 4 highlight a trade-off: B234 improves semantic fidelity but suffers a noticeable accuracy loss (e.g., 52.8% vs. 75.2% on CUB-200). The paper does not investigate ways to close this gap.  
  *Why unresolved:* The drop suggests that extra spatial detail from shallower layers introduces noise or redundancy that interferes with classification. If the gap could be closed, B234 would offer both high interpretability and performance.  
  *What evidence would resolve it:* Systematically study fusion strategies for multi-depth features (e.g., learned attention, weighted averaging, gating mechanisms); vary the set of included blocks; add a lightweight calibration layer on a validation set; evaluate both accuracy and semantic fidelity (e.g., prototype alignment, qualitative map clarity).
- **Open Question 4:** How does the number of prototypes per class (K/C) affect the balance between interpretability, diversity, and accuracy in KMEx?  
  *Basis in paper:* [inferred] The paper generally fixes K/C=5 and only briefly compares K/C=1 vs. 5 in Table 1, showing differences in cosine similarity. No comprehensive analysis of this hyperparameter is provided.  
  *Why unresolved:* The number of prototypes per class controls the granularity of class representation. Too few may not capture intra-class variation; too many may cause redundancy or overfitting. Understanding its impact is crucial for practical deployment.  
  *What evidence would resolve it:* Conduct controlled experiments over a range of K/C values (e.g., 1, 5, 10, 20) on multiple datasets, measuring: prototype-class alignment (avg. cosine), cluster purity, classification accuracy, and—if possible—human evaluation of prototype meaningfulness. This would clarify the trade-offs and guide selection.

## Limitations
- Exact normalization and scaling in Eq. (8) ("normalized and scaled") is unspecified; per-channel L2 vs. global Frobenius could affect results.
- The spatial correspondence assumption may fail with aggressive downsampling or non-local operations (e.g., attention), invalidating upsampling and propagation.
- K-means scalability is a primary limitation; memory/time complexity may be prohibitive for large datasets like ImageNet.

## Confidence
- **CNN-to-SEM equivalence (avg pool + linear):** High – mathematical proof (Thm 1) holds under strict structural constraint.
- **KMEx alignment & accuracy parity:** Medium – empirical support (cosine ~0.9, accuracy match on CUB-200), but relies on k-means capturing data distribution; break if clusters non‑convex.
- **B234 dense explanations:** Low‑Medium – qualitative improvements shown, but large accuracy drop and heuristic preprocessing (normalization, upsampling) weaken confidence.
