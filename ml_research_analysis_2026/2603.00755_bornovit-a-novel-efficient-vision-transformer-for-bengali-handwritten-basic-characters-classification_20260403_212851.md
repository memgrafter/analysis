# BornoViT: A Novel Efficient Vision Transformer for Bengali Handwritten Basic Characters Classification

## Quick Facts
- **arXiv ID**: 2603.00755
- **Source URL**: https://arxiv.org/abs/2603.00755
- **Reference count**: 18
- **Primary result**: BornoViT achieves 95.77% accuracy on BanglaLekha-Isolated with 0.65M parameters, 0.62 MB model size, and 0.16 GFLOPs, outperforming DenseNet and Xception in efficiency while maintaining higher accuracy.

## Executive Summary
BornoViT is a lightweight Vision Transformer designed for Bengali handwritten character classification, addressing the computational costs of existing models. It adopts a patch-based architecture with 16×16 non-overlapping patches, a shallow transformer stack (4 blocks), and transfer learning from the large Ekush dataset. On the BanglaLekha-Isolated dataset it reaches 95.77% accuracy with only 0.65 million parameters, 0.62 MB size, and 0.16 GFLOPs, significantly improving the efficiency-accuracy trade-off. On a self-collected Bornomala dataset it achieves 91.51% accuracy, demonstrating robustness across diverse handwriting styles.

## Method Summary
The proposed BornoViT architecture consists of a patch embedding layer that splits a 224×224 image into 16×16 patches and projects them to 128-dimensional tokens. Four transformer blocks with 2 attention heads each refine these tokens via self‑attention and MLP layers with GELU activations. A learnable [CLS] token is used for classification. The model is first pretrained on the Ekush dataset (154,824 images, 122 classes) for 100 epochs, then fine‑tuned on target datasets (BanglaLekha-Isolated and Bornomala) using the Adam optimizer (lr=0.0001, batch=128) and early stopping. Data augmentation includes random affine shifts and color jitter. Performance is measured by classification accuracy and computational metrics (parameters, FLOPs, model size) with 5‑fold cross‑validation.

## Key Results
- BanglaLekha-Isolated accuracy: 95.77% (0.65M params, 0.62 MB, 0.16 GFLOPs)
- Outperforms DenseNet and Xception in efficiency while achieving higher accuracy.
- Bornomala accuracy: 91.51%

## Why This Works (Mechanism)
BornoViT’s success rests on three intertwined mechanisms. First, its patch‑based Vision Transformer reduces computational burden by dividing the input into 16×16 non‑overlapping patches and linearly embedding them into tokens; self‑attention then captures global relationships without the heavy convolutional cost of deep CNNs, while the patch size retains sufficient stroke detail for Bengali glyphs. Second, transfer learning from the large‑scale Ekush dataset (122 classes, 154k+ samples) provides a strong inductive bias, initializing the model with generalizable Bengali handwriting patterns and enabling effective fine‑tuning on smaller target sets. Third, the deliberate use of a shallow, narrow transformer—4 blocks, embedding dimension 128, 2 attention heads—slashes parameters (0.65M) and FLOPs (0.16 GFLOPs) while retaining enough capacity for the 60‑class basic character task; the high‑quality pretrained features compensate for the reduced model depth.

## Architecture Onboarding
**Component map**: Input → Patch Embedding (16×16 conv, 128‑D) → Prepend [CLS] token → Add Positional Embedding → Dropout → Transformer Blocks (×4, each: LayerNorm, MHA with 2 heads, MLP with GELU) → Extract [CLS] token → Linear Classifier

**Critical path**: The image is converted to a sequence of patch tokens, enriched with positional information, processed through four transformer blocks to model global context, and the final [CLS] token is fed to a linear layer for classification.

**Design tradeoffs**:
- *Patch size (16×16)*: Larger patches reduce token count/FLOPs but risk losing fine stroke detail; smaller patches preserve detail but increase computation. 16×16 is a chosen compromise.
- *Depth (4 blocks)*: Shallower networks are faster/smaller but may underfit; 4 blocks were found sufficient for the 60‑class basic character problem.
- *Embedding dimension (128)*: Smaller dimensions cut parameters throughout the model but limit representational capacity.
- *Attention heads (2)*: Fewer heads reduce QKV projection parameters but restrict the model’s ability to attend to diverse feature subspaces.

**Failure signatures**:
- Inter‑class confusion between visually similar characters (e.g., ‘kha’ vs. ‘tha’).
- Poor handling of intra‑class variation (stroke thickness, slant) due to limited augmentation or capacity.
- Accuracy drop on Bornomala (91.51%) versus BanglaLekha‑Isolated (95.77%) indicates domain shift not fully compensated by pretraining.

**First 3 experiments**:
1. Ablate transfer learning: Train BornoViT from random initialization on BanglaLekha‑Isolated; expect significantly lower accuracy, confirming dependence on Ekush pretraining.
2. Vary patch size: Replace 16×16 with 14×14 (256 tokens) and 32×32 (49 tokens); measure accuracy vs. FLOPs to test the hypothesis that 32×32 degrades accuracy while 14×14 may slightly improve but increase computation.
3. Modify transformer depth: Train variants with 2, 4 (baseline), and 8 blocks; identify the depth that yields the best efficiency‑accuracy trade‑off, expecting 4 blocks to be optimal.

## Limitations
- Ekush dataset provenance is unclear; the paper provides no download link, preprocessing details, or confirmation of the 122‑class structure, blocking reliable replication of the pretraining stage.
- Architecture ambiguity: the custom ViT configuration (4 blocks, embed_dim=128, 2 heads) does not match standard `timm` presets, and it is uncertain whether the authors used off‑the‑shelf pretrained weights or a custom initialization.
- The self‑collected Bornomala dataset is not publicly available, preventing independent verification of its reported 91.51% accuracy and its claimed diversity.
