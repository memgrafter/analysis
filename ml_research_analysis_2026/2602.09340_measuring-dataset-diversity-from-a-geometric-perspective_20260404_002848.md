# Measuring Dataset Diversity from a Geometric Perspective
## Quick Facts
ArXiv ID: 2602.09340  
Source URL: https://arxiv.org/abs/2602.09340  
Reference count: 40  
Primary result: PLDiv, a topology-based diversity metric, outperforms existing methods on curvature prediction, text, and image tasks by directly capturing geometric structure.

## Executive Summary
Dataset diversity metrics have traditionally focused on distributional properties, overlooking geometric structure. This paper introduces PLDiv, a metric derived from topological data analysis that quantifies diversity by summing squared lifetimes of 0-dimensional persistent homology features across scales. PLDiv satisfies formal diversity axioms and directly links diversity to data geometry. Extensive experiments show that PLDiv outperforms state-of-the-art metrics such as Vendi Score, DCScore, and MAGAREA on tasks including curvature prediction (MSE 0.039 vs 0.053), text embedding evaluation, and image embedding correlation (Pearson 0.998). PLDiv reliably distinguishes structural variations like loops and clusters, offering a robust, geometry-aware tool for evaluating dataset diversity.

## Method Summary
PLDiv operates on a point cloud or a precomputed distance matrix. It first constructs the Vietoris–Rips filtration over the data, varying a distance threshold and forming simplicial complexes as edges appear. For each threshold, connected components are tracked, yielding birth and death times for 0-dimensional homological features. The metric is computed as \( \text{PLDiv} = \frac{1}{4} \sum_{i} (d_i - b_i)^2 \), where the sum runs over all non-infinite intervals (ignoring the last component that never dies). This closed-form expression corresponds to the squared L2 norm of the persistence landscape. An optional sparse approximation uses a (1+ε)-approximate Rips graph and its minimum spanning tree to reduce computational overhead while preserving accuracy.

## Key Results
- PLDiv captures geometric structure by summation of squared lifetimes of topological features, satisfying diversity axioms.
- Outperforms Vendi Score, DCScore, and MAGAREA on curvature prediction (MSE 0.039 vs 0.053), text embeddings (lowest MSE), and image embeddings (Pearson 0.998).
- Reliably distinguishes structural variations like loops and clusters, providing a geometry-aware evaluation tool.

## Why This Works (Mechanism)
Persistence landscapes summarize the entire persistence diagram into a functional object; the L2 norm (or sum of squared lifetimes) aggregates information about how long features persist over scale. Long-lived intervals correspond to meaningful geometric separations (e.g., distinct clusters) that survive over a range of thresholds, whereas short-lived intervals typically reflect noise or sampling artifacts. By summing squares, PLDiv emphasizes robust structures while still accounting for all features, thereby satisfying diversity axioms such as monotonicity and effective size. This geometric sensitivity allows PLDiv to detect nuanced variations like curvature or presence of loops, which distribution-only metrics miss.

## Foundational Learning
- **Topological Data Analysis (TDA)**: A mathematical framework for quantifying shape in data. *Why needed*: Provides tools to reason about geometric properties like connectivity and holes. *Quick check*: Compute the Betti numbers of a torus (β₁=2, β₂=1).
- **Persistent Homology**: Computes homology groups across a filtration, outputting birth/death pairs. *Why needed*: Captures multi-scale topology, distinguishing noise from robust features. *Quick check*: For three collinear points with threshold covering two edges, the persistence diagram shows one interval born at 0 and dying when the third point connects.
- **Vietoris–Rips Filtration**: A simplicial complex construction based on pairwise distances. *Why needed*: Enables efficient approximation of true shape for point clouds. *Quick check*: Given four points with all pairwise distances ≤ ε, the Rips complex is a filled tetrahedron.
- **Persistence Landscapes**: Functional summary of a persistence diagram formed by taking pointwise maximum of triangular functions from intervals. *Why needed*: Converts diagram to a vector in L², enabling norms and statistical operations. *Quick check*: For two intervals [0,2] and [1,3], the landscape at t=1.5 is max(1.5, 0.5)=1.5.
- **Diversity Axioms**: Formal properties (monotonicity, symmetry, effective size, etc.) that a diversity measure should satisfy. *Why needed*: Guides metric design and allows theoretical comparison. *Quick check*: Show that PLDiv increases when adding a point far from existing clusters.

## Architecture Onboarding
Component map: Point cloud → Distance matrix → Vietoris–Rips filtration → 0-dimensional persistent homology → Persistence intervals (birth/death) → PLDiv = (1/4) Σ (death - birth)². Optional: sparse Rips graph → MST → same pipeline.  
Critical path: The most expensive step is computing the Vietoris–Rips filtration and persistent homology; this dominates runtime and memory. Sparse approximations shift the bottleneck but still require graph construction.  
Design tradeoffs: Full Rips guarantees exact topological information but has high computational complexity O(n²) for edges and O(n³) for PH; sparse Rips reduces edge count at the cost of approximating the filtration. The maximum radius parameter controls the scale at which connectivity is observed; too small truncates global structure, too large introduces noise. No automatic scaling is provided.  
Failure signatures: (1) Unexplained drop in PLDiv when dataset size changes, indicating lack of normalization. (2) High variance under small perturbations, suggesting sensitivity to noise. (3) Inconsistent ranking across different max-radius choices, implying parameter dependence.  
First experiments:
1. Implement PLDiv and validate on synthetic shapes (e.g., two clusters, concentric rings); confirm that geometrically richer sets yield higher scores.
2. Examine sensitivity to max-radius by varying percentile of pairwise distances and reporting PLDiv stability on a fixed dataset.
3. Replicate curvature prediction on Turkes et al. dataset: compute PLDiv with a justified cutoff (e.g., until single component remains), train SVR with 5-fold CV, report MSE, and compare against baseline metrics using consistent implementations.

## Open Questions the Paper Calls Out
1. **Computational scalability**: Can PLDiv's computational efficiency be improved to scale to massive datasets while preserving accuracy?  
   *Basis*: The Limitations section notes PLDiv is more computationally intensive than DCScore and that sparse Rips filtrations reduce but do not eliminate this gap.  
   *Why unresolved*: Current sparse approximations trade geometric fidelity for speed; a fundamental algorithmic breakthrough is needed.  
   *Resolving evidence*: A near-linear time algorithm (e.g., streaming TDA or learned approximations) that matches full PLDiv correlation on billion-point benchmarks.

2. **Filtration choice**: For which modalities do alternative filtrations (Čech, Alpha Complex, witness complexes) outperform Vietoris–Rips in PLDiv?  
   *Basis*: Limitations state other filtrations may be more effective in specific domains, but this is unexplored.  
   *Why unresolved*: Only H0 with Rips was tested; different filtrations capture different nuances.  
   *Resolving evidence*: Systematic benchmarks across modalities (3D scans, graphs, biomedical images) comparing PLDiv with various filtrations against ground-truth diversity.

3. **Automatic scale selection**: How sensitive is PLDiv to the maximum-edge parameter, and can an automatic, theoretically grounded selection method be derived?  
   *Basis*: Limitations note the maximum-edge parameter may need tuning and no automatic method exists.  
   *Why unresolved*: Scale choice is heuristic; inappropriate cutoffs harm comparability across datasets.  
   *Resolving evidence*: A rule (e.g., based on landscape decay or statistical significance) that yields stable PLDiv across diverse datasets with known diversity shifts.

4. **Higher-dimensional homology**: Do H₁, H₂ features add predictive power for diversity in domains where loops/voids are meaningful?  
   *Basis*: Paper only uses H₀, but theory suggests broader topological structure matters; related work uses multi-scale persistence for curvature.  
   *Why unresolved*: H₀ may not capture higher-order structure; authors did not test multi-homology.  
   *Resolving evidence*: Experiments on synthetic and real datasets where ground-truth diversity is defined by loops/voids, comparing H₀-only vs. multi-homology PLDiv.

5. **Generative model monitoring**: Can PLDiv detect subtle homogenization trends in large-scale generative outputs over time as an early-warning system?  
   *Basis*: Introduction mentions homogenization risk, but paper only evaluates static datasets.  
   *Why unresolved*: Cross-sectional validation does not confirm sensitivity to temporal collapse.  
   *Resolving evidence*: Longitudinal study tracking PLDiv for successive model versions on controlled prompts, correlating drift with qualitative reports of uniformity.

## Limitations
- Filtration parameters (maximum edge length) and potential normalization for point cloud size are not specified, which may affect reproducibility and cross-dataset comparability.
- Evaluation baselines (Vendi Score, DCScore, MAGAREA) lack hyperparameter details (e.g., RBF γ, temperature τ), hindering exact performance replication.
- PLDiv’s computational demand may limit its application to very large datasets despite sparse approximations; scaling behavior and memory usage remain concerns.
