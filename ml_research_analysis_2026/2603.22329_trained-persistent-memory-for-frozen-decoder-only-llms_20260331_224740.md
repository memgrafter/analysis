# Trained Persistent Memory for Frozen Decoder-Only LLMs

## Quick Facts
- **arXiv ID:** 2603.22329
- **Source URL:** https://arxiv.org/abs/2603.22329
- **Reference count:** 21
- **Primary result:** Six memory adapters trained on a frozen GPT-2 backbone; only methods with strong architectural priors (parallel cross-attention, Hebbian, slot-based sparse write) achieve non-trivial retained memory (7–18%) at standard capacity (1×), while all six converge to similar performance (7.6–10.3%) when capacity is increased tenfold (10×).

## Executive Summary
This work investigates retrofitting persistent memory into frozen decoder-only language models by training only a small adapter. Six distinct memory architectures are evaluated, differing in how stored information is read (injected into the self-attention mechanism) and written (updated with new information). Experiments on the LoCoMo benchmark reveal a stark dichotomy at standard memory capacity: methods with strong inductive biases—parallel cross-attention, Hebbian learning, and slot-based sparse writes—succeed, while simpler approaches like raw KV prefix injection fail. Scaling memory capacity tenfold eliminates this gap, indicating that initial failures stem from capacity constraints rather than fundamental incompatibility with the decoder-only architecture.

## Method Summary
The framework inserts a trainable memory module into a frozen transformer backbone (GPT-2). Each turn, a persistent memory bank \( P_{t-1} \) is read via method-specific projections (e.g., prepending key-value pairs to every layer’s attention cache, inserting cross-attention layers, or using a gated branch) and then updated with a shared differentiable write rule (or method-specific variants like sparse slot writes). Only the adapter parameters \( \theta_{\text{Mem}} \) are trained on turn-level QA losses via backpropagation through the frozen model, while write-side projections may be fixed random maps. Six instantiations are tested: KV prefix (M.1), gated branch (M.3), parallel cross-attention (M.2), Hebbian matrix (M.4), linear auto-associative (M.5), and slot-based sparse write (M.6).

## Key Results
- At 1× capacity (\( n_P = 64 \)), only M.2 (parallel XAttn, 17.8%), M.4 (Hebbian, 7.6%), and M.6 (slot-based, 17.2%) achieve non-trivial retained-memory scores; M.1, M.3, M.5 fail (<0.4%).
- At 10× capacity (\( n_P = 640 \)), all six methods converge to a narrow performance band (7.6–10.3% retained-memory).
- M.6 (slot-based) also achieves the highest knowledge accumulation (\( \Delta K = 9.7 \)) among the strong methods at 1×.

## Why This Works (Mechanism)

### Mechanism 1: KV Prefix Injection as Soft Token Context
Memory entries are projected into key-value pairs per layer and prepended to the self-attention cache, treating them as prior tokens. The frozen self-attention heads must learn to route information from these soft-token memory entries despite never seeing such projections during pre-training. Failure at 1× capacity (M.1: 0.02%) suggests the representational gap is too large for the given dimensionality; success at 10× indicates raw capacity can eventually bridge it.

### Mechanism 2: Parallel Cross-Attention Insertion
A dedicated cross-attention layer is inserted after each frozen self-attention block, allowing the hidden states to directly attend to the memory bank. This provides a strong inductive bias analogous to encoder-decoder models (e.g., Flamingo), giving the frozen backbone a clear pathway to integrate memory without disrupting the original self-attention flow. It succeeds even at low capacity (17.8% at 1×).

### Mechanism 3: Slot-Based Sparse Write with Associative Addressing
The memory bank is organized into discrete slots. Writes are sparse (top-k slots selected via content-based addressing) to prevent dilution of stored facts when capacity is limited. Read uses KV prefix injection from the updated bank. The addressing mechanism (affinity between current hidden state and slot keys) provides a crucial bias that maintains memory fidelity across many sessions, explaining its strong performance at 1× (17.2%) and highest \( \Delta K \).

## Foundational Learning
- **Causal self-attention & KV caching:** The frozen decoder-only model processes tokens causally; memory must be injected in a way compatible with this mask. KV prefix prepends memory as earlier context.
- **Parameter-efficient fine-tuning (PEFT):** Only small adapter parameters are trained; the massive backbone is frozen. This is central to the retrofit claim but limits expressiveness to what the frozen model can absorb.
- **Retained-memory score:** The primary metric. For each QA fact, answers are scored across lag buckets (temporal distance from memory turn). The non-increasing isotonic fit (PAV A) aggregates scores; a non-zero long-lag score implies persistent recall.
- **Memory capacity vs. inductive bias:** The core trade-off: simple read/write mechanisms require more capacity to succeed, while biased mechanisms (sparse writes, dedicated read paths) succeed with less.

## Architecture Onboarding
Frozen GPT-2 backbone -> Memory Bank \( P_{t-1} \) (persistent matrix) -> Read adapter (method-specific projections) -> Modified forward pass (e.g., extended KV cache or added cross-attention) -> Hidden states \( H_t \) -> Write rule (shared or slot-based) -> Updated \( P_t \).

1. Load \( P_{t-1} \) at turn \( t \).
2. Inject \( P_{t-1} \) via read strategy (e.g., compute \( K_{\text{Mem}}^{(\ell)}, V_{\text{Mem}}^{(\ell)} \) and prepend to layer \( \ell \)'s KV cache).
3. Run frozen forward pass through all layers with modified attention/branch to produce \( H_t \).
4. Compute write: use \( H_t \) and \( P_{t-1} \) with write projections to produce \( P_t \). For slots, compute addressing scores, select top-k, and update only those.
5. Save \( P_t \).
6. Compute output \( \hat{y}_t \) from \( H_t \); calculate loss.

- **Design tradeoffs:** KV prefix: low parameter cost (~2.4M), weak bias → fails at 1×. Parallel XAttn: higher cost (~4.1M), strong bias → succeeds at 1×. Slot-based: moderate cost (~1.8M), sparse write bias → excels at accumulation.
- **Failure signatures:** Retained-memory score near zero across all lags; forgetting curve identical to stateless baseline; for slots, uniform addressing scores leading to dilution.
- **First 3 experiments:**
  1. Train all six adapters on GPT-2 with 1× capacity on LoCoMo; evaluate retained-memory and \( \Delta K \). Expect only M.2, M.4, M.6 to show substantial gains.
  2. Repeat with 10× capacity; expect all six to converge to ~7-10% retained-memory.
  3. Ablate write rule for M.6: replace sparse top-k write with simple append (no decay, no addressing); expect severe degradation.

## Open Questions the Paper Calls Out
1. **Extension to encoder-only and multimodal models:** The framework is validated only on decoder-only (GPT-2). Encoder-only (e.g., BERT) and multimodal architectures have different attention patterns; new read strategies may be needed.
2. **End-to-end learning of write projections:** Currently fixed random maps; learning them could improve performance but requires backpropagation through the full conversation history, which is computationally costly and potentially unstable.
3. **Scaling to larger backbones:** All experiments used GPT-2 (124M). Larger models (e.g., LLaMA-7B, GPT-3) may have different capacity and attention dynamics that could alter the observed inductive bias dichotomy and capacity scaling effects.

## Limitations
- Findings are limited to GPT-2 and the LoCoMo QA benchmark; generalization to larger models, other architectures, or diverse tasks is uncertain.
- Capacity scaling explored only at 1× and 10×; intermediate points and efficiency (compute/memory trade-offs) are unstudied.
- Write rule hyperparameters (decay \( \gamma \), sparsity \( k \)) are not systematically ablated across methods; optimal settings may vary.
- Metrics focus on QA accuracy; memory quality aspects like coherence, interference, or factual precision are not measured.

## Confidence
- **Capacity-driven gap (1× vs 10× convergence):** Medium. Supported by two capacity points on one model; needs broader validation across models and intermediate capacities.
- **Strong-bias methods succeed at low capacity:** High. Direct experimental evidence: M.2, M.4, M.6 substantially outperform others at 1×.
- **Write rule necessity:** Medium. Ablation on M.6 shows degradation; needs verification for other methods.
- **Retrofit feasibility (adapting frozen LLMs):** High. All six adapters trained successfully on frozen backbone, proving the concept.

## Next Checks
1. **Scale study:** Replicate the 1× and 10× capacity experiments on a larger decoder-only model (e.g., LLaMA-7B) with additional intermediate capacities (2×, 5×) to confirm the scaling pattern and inductive bias dichotomy.
2. **Write rule ablation:** For each method, replace the designed write rule with a naive append (no decay, no addressing) and measure the drop in retained-memory and \( \Delta K \); also systematically vary \( \gamma \) and \( k \) for slot-based method.
3. **Memory content analysis:** Probe the stored memory matrices \( P_t \) with classifiers or retrieval tests to quantify factual retention, semantic clustering, and interference across turns; correlate these internal metrics with downstream QA performance.
