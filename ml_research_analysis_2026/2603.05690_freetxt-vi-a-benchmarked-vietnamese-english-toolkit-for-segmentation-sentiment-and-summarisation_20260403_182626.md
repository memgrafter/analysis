# FreeTxt-Vi: A Benchmarked Vietnamese-English Toolkit for Segmentation, Sentiment, and Summarisation

## Quick Facts
- **ArXiv ID:** 2603.05690
- **Source URL:** https://arxiv.org/abs/2603.05690
- **Reference count:** 3
- **Primary result:** FreeTxt-Vi is a free, open-source web toolkit for bilingual Vietnamese-English text analysis, achieving state-of-the-art results: 98.1% F1 segmentation (Vietnamese), 95.2% accuracy sentiment (Vietnamese), and ROUGE-L 48.4 (Vietnamese).

## Executive Summary
FreeTxt-Vi addresses the scarcity of accessible bilingual Vietnamese-English text analysis tools for non-programmers by integrating corpus linguistics features—such as concordancing, keyword analysis, and interactive visualisations—with transformer-based NLP components. The system employs a hybrid segmentation strategy (VnCoreNLP + BPE), a fine-tuned TabularisAI sentiment classifier, and a fine-tuned Qwen2.5 model for abstractive summarisation, alongside aspect detection to guide thematic summarisation. Evaluated on standard Vietnamese (VLSP2013, VLSP2016, VNDS) and English (Wikipedia/OpenWebText, IMDb, CNN/DailyMail) benchmarks, the toolkit demonstrates competitive or superior performance across tasks, making advanced NLP capabilities readily available for qualitative research and applied analytics in both languages.

## Method Summary
The toolkit follows a modular pipeline: user data (various file formats) enters via a web interface, where a lightweight language detector routes text to appropriate preprocessing. Vietnamese text is segmented using the rule-based VnCoreNLP to identify multi-syllable words, followed by Byte Pair Encoding (BPE) to handle rare terms and align with transformer tokenizers. English text undergoes standard tokenization and sentence splitting. For sentiment analysis, a multilingual TabularisAI model is jointly fine-tuned on Vietnamese (VLSP2016) and English (IMDb) review data, producing language-agnostic representations. Summarisation offers both extractive (TextRank) and abstractive modes; the latter uses a Qwen2.5 model fine-tuned via LoRA on Vietnamese (VNDS) and English (CNN/DailyMail) corpora, with an aspect-detection module enabling theme-focused generation. Results are aggregated, statistically compared against reference corpora, and visualised through interactive concordances, word clouds, and sentiment charts.

## Key Results
- **Segmentation:** 98.1% F1 (Vietnamese), 99.94% accuracy (English)
- **Sentiment:** 95.2% accuracy (Vietnamese), 95.0% accuracy (English)
- **Summarisation:** ROUGE-1/2/L: Vietnamese 53.1/27.5/48.4; English 52.4/27.0/48.0

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The hybrid VnCoreNLP + BPE segmentation pipeline achieves high segmentation accuracy for Vietnamese while maintaining compatibility with transformer-based NLP components.
- **Mechanism:** VnCoreNLP performs linguistically informed, rule-based segmentation of Vietnamese multi-syllable words, while Byte Pair Encoding (BPE) subword tokenization is applied subsequently to handle rare/out-of-vocabulary terms and ensure alignment with the token expectations of transformer models (e.g., Qwen2.5, TabularisAI).
- **Core assumption:** Vietnamese orthography requires a dedicated word segmenter to correctly identify meaningful lexical units, but downstream neural models still require subword decomposition for robust open-vocabulary processing.
- **Evidence anchors:**  
  [abstract] States: "integrates a hybrid VnCoreNLP + Byte Pair Encoding (BPE) segmentation strategy."  
  [section 3.1] Explains: "Vietnamese text is processed using VnCoreNLP... Accurate segmentation is particularly important for Vietnamese since words often consist of multiple whitespace-separated syllables."  
  [corpus] Neighbor paper "Is word segmentation necessary for Vietnamese sentiment classification?" indicates this is an active research question, supporting the core assumption that segmentation is a non-trivial, necessary step for high-quality Vietnamese NLP.
- **Break condition:** If BPE overly fragments valid Vietnamese words (e.g., splitting meaningful compounds introduced by VnCoreNLP), it could degrade performance in collocation analysis or keyword extraction by treating cohesive phrases as disjoint subwords.

### Mechanism 2
- **Claim:** A single, jointly fine-tuned multilingual transformer (TabularisAI) can perform high-accuracy sentiment analysis for both Vietnamese and English, avoiding the need for separate language-specific models.
- **Mechanism:** A base multilingual model (tabularisai/multilingual-sentiment-analysis) is fine-tuned on a combined dataset of VLSP2016 (Vietnamese) and IMDb (English) reviews. This encourages the model to develop language-agnostic sentiment representations while preserving language-specific lexical knowledge.
- **Core assumption:** Shared latent representations exist across languages for sentiment expressions, and bilingual fine-tuning can improve generalisation for the lower-resource language (Vietnamese) without harming performance on the higher-resource one (English).
- **Evidence anchors:**  
  [abstract] Notes the "fine-tuned TabularisAI sentiment classifier" is part of the unified pipeline.  
  [section 4.3] Table 2 shows the fine-tuned model achieves the highest accuracy on both VLSP2016 (95.2%) and IMDb (95.0%), outperforming both the base multilingual model and monolingual PhoBERT.  
  [section 4.5] States: "bilingual fine-tuning improves Vietnamese performance (+1.4% over multilingual base) without degrading English accuracy."
- **Break condition:** If the fine-tuning data is heavily imbalanced (e.g., vastly more English than Vietnamese examples), the model may exhibit catastrophic forgetting of Vietnamese patterns or develop a bias toward English-centric representations.

### Mechanism 3
- **Claim:** Integrating an aspect-detection pre-step with a fine-tuned LLM (Qwen2.5) enables interpretable, thematic abstractive summarisation for qualitative data analysis.
- **Mechanism:** The system first uses heuristics or an auxiliary classifier to detect salient aspects (e.g., "social," "academic") present in the input documents. A user's selection of an aspect then conditionally prompts the fine-tuned Qwen2.5 model to generate a summary focused on that theme. This combines the generative fluency of LLMs with guided thematic extraction.
- **Core assumption:** LLM-generated summaries can be steered via prompt engineering to isolate and elaborate on specific semantic dimensions within a text corpus, providing more actionable insights than a general summary.
- **Evidence anchors:**  
  [abstract] Mentions "fine-tuned Qwen2.5 model for abstractive summarisation" and the toolkit's "aspect-guided summarisation."  
  [section 3.3] Details: "The system automatically detects salient aspects... Users can then select a specific aspect... to generate a focused summary."  
  [section 4.4] Table 3 shows the fine-tuned Qwen2.5 outperforms baselines on ROUGE metrics, suggesting the fine-tuning preserves task adherence.
- **Break condition:** If the aspect detection step is inaccurate (e.g., misclassifying the dominant theme), the guided summary will be irrelevant or misleading. Additionally, the LLM may hallucinate details not present in the source texts to satisfy the thematic prompt.

## Foundational Learning

### Corpus Linguistic Methods (concordancing, keyword analysis, keyness)
- **Why needed here:** These are the foundational analysis features that define FreeTxt-Vi's core value for non-programmers. Users must understand what a concordance (KWIC display) or a keyness score (statistical distinctiveness vs. a reference corpus) represents to interpret the visualisations correctly.
- **Quick check:** *What is the difference between a frequency-based word cloud and a keyness-based word cloud, and when would you use each?*

### The Word Segmentation Challenge for Vietnamese
- **Why needed here:** Users need to understand why Vietnamese text cannot be simply split on whitespace. Misunderstanding this leads to confusion over token counts, collocation results, and why a dedicated segmenter like VnCoreNLP is indispensable.
- **Quick check:** *Why would the single Vietnamese phrase "học sinh" (student) be incorrectly treated as two separate tokens by a standard English tokenizer, and what analysis errors could this cause?*

### Transformer Model Fine-Tuning for Low-Resource Languages
- **Why needed here:** To appreciate why FreeTxt-Vi's contributions (competitive results) are non-trivial. Users should grasp that pretrained models like mBERT or Qwen2.5 are not initially optimal for Vietnamese and require targeted adaptation on domain-specific datasets (VLSP, VNDS).
- **Quick check:** *What is the practical difference between using a generic multilingual model "out-of-the-box" and using the same model after it has been fine-tuned on a Vietnamese sentiment dataset?*

## Architecture Onboarding
Component map:
Interface Layer (web frontend) → Processing Orchestrator (backend) → Preprocessing Layer (VnCoreNLP for Vietnamese, spaCy/NLTK for English) → NLP Component Layer (TabularisAI sentiment, Qwen2.5 summarisation, TextRank, Aspect detection) → Visualisation Layer → Reference Data Layer

Critical path:
User data upload → Language detection → Appropriate preprocessing → Segmentation/Tokenization → Parallel Sentiment analysis & Summarisation → Aggregation & Statistical comparison with reference corpora → Interactive visualisation rendering.

Design tradeoffs:
- Bilingual unity vs. monolingual peak performance: A single pipeline simplifies deployment but may not match the absolute performance of specialized monolingual models trained on more data.
- LLM flexibility vs. computational cost: Abstractive summarisation with Qwen2.5 offers rich, promptable outputs but is slower and more resource-intensive than extractive TextRank; both are provided.
- Linguistic accuracy vs. speed: VnCoreNLP is accurate but slower than pure subword tokenizers; the hybrid approach balances this but segmentation remains a bottleneck for large uploads.

Failure signatures:
- Segmentation anomalies: unusually high frequency of single-syllable "words" in Vietnamese output suggests VnCoreNLP failed or was bypassed.
- Sentiment incoherence: a sentiment distribution with nearly all "neutral" results on clearly opinionated text indicates model-data mismatch or failed language detection.
- Summarisation hallucination/low ROUGE: generated summaries containing factual details not present in the source, or that are overly generic, point to poor fine-tuning or prompt misconfiguration.
- Visualisation errors: empty word clouds or error messages often trace back to failed preprocessing (non-UTF-8 files) or missing reference frequency dictionaries.

First 3 experiments:
1. Segmentation sanity check: Upload a small, well-known Vietnamese sentence with a clear multi-word unit (e.g., "Bộ giáo dục và đào tạo"). Verify the concordance shows it as a single token, not split. Check speed metrics against baseline.
2. Bilingual sentiment verification: Upload a paired dataset (e.g., 50 English and 50 Vietnamese movie reviews with known labels). Run sentiment analysis. Accuracy should be ~95% for both. If Vietnamese accuracy drops significantly, investigate the VnCoreNLP integration point.
3. Aspect-guided summarisation test: Input a set of Vietnamese education survey responses containing clear themes (e.g., "curriculum," "facilities," "teacher quality"). Use the aspect summarisation feature for each theme. The outputs should be coherent and should not discuss themes outside the selected aspect.

## Open Questions the Paper Calls Out

- **Open Question 1:** How can the FreeTxt-Vi pipeline be adapted to support other Southeast Asian languages (e.g., Thai, Indonesian) with distinct orthographic and segmentation challenges while preserving its unified bilingual architecture?  
  *Basis:* The conclusion states future work will focus on expanding coverage to additional Southeast Asian languages.  
  *Why unresolved:* Each language has unique linguistic features requiring language‑specific preprocessing; the current hybrid segmentation is tailored for Vietnamese.  
  *What evidence would resolve it:* Implement and integrate language‑specific segmentation modules for target languages, evaluate on standardized benchmarks, and compare performance against existing monolingual tools.

- **Open Question 2:** To what extent does bilingual fine‑tuning contribute to the superior Vietnamese sentiment performance of the TabularisAI‑based model, and does this joint training incur any trade‑offs in English accuracy or computational efficiency?  
  *Basis:* Table 2 shows the fine‑tuned bilingual model outperforms monolingual Vietnamese baselines and the base multilingual TabularisAI, yet the paper lacks an ablation isolating the effect of English data.  
  *Why unresolved:* The improvement could stem from increased training data, model capacity, or the bilingual signal itself; without controlled experiments, the specific contribution of English data remains unknown.  
  *What evidence would resolve it:* Conduct ablation studies training identical model architectures on (i) Vietnamese‑only, (ii) English‑only, and (iii) combined datasets (keeping data volume constant), then compare performance, inference speed, and memory usage.

- **Open Question 3:** How effective and user‑perceived is the aspect‑guided abstractive summarisation in generating theme‑focused summaries compared to standard abstractive summarisation for qualitative Vietnamese–English data?  
  *Basis:* Section 3.3 introduces aspect‑guided summarisation but provides no evaluation of aspect detection accuracy or user satisfaction.  
  *Why unresolved:* The reliability of automatic aspect detection and the practical utility of aspect‑focused outputs for analysts have not been measured; it is unclear whether the detected aspects align with human interpretations or improve analysis efficiency.  
  *What evidence would resolve it:* Annotate a Vietnamese dataset with gold‑standard aspects, evaluate aspect detection precision/recall, and conduct user studies where domain experts compare generic vs. aspect‑focused summaries for tasks like theme identification or insight extraction.

- **Open Question 4:** How robust is the hybrid VnCoreNLP+BPE segmentation pipeline when applied to informal Vietnamese text (e.g., social media, user‑generated content) containing spelling variations, code‑switching, and non‑standard grammar?  
  *Basis:* The segmentation evaluation uses the VLSP2013 newswire corpus; informal genres are not addressed despite the toolkit’s stated applicability to such domains.  
  *Why unresolved:* Formal training data may not capture the noise and irregularities of informal text, leading to segmentation errors that propagate to downstream tasks.  
  *What evidence would resolve it:* Test the pipeline on a corpus of informal Vietnamese (e.g., Facebook posts) with manually segmented gold standards, quantify error rates, and analyze failure modes to inform adaptive strategies.

## Limitations
- Hybrid segmentation pipeline details (BPE training, fusion method) are not fully specified, hindering faithful reproduction.
- Fine-tuning protocols (preprocessing, class balancing, early stopping) are absent; only high-level hyperparameters are given.
- No empirical user evaluation; claims of non-programmer accessibility remain anecdotal.
