# Dual-Teacher Distillation with Subnetwork Rectification for Black-Box Domain Adaptation

## Quick Facts
- **arXiv ID:** 2603.22908
- **Source URL:** https://arxiv.org/abs/2603.22908
- **Reference count:** 40
- **Primary result:** DDSR achieves state-of-the-art black-box domain adaptation with average accuracies of 93.1% on Office-31, 83.2% on Office-Home, and 90.6% on VisDA-17.

## Executive Summary
Black-box domain adaptation (BBDA) addresses scenarios where source data and model are inaccessible, limiting adaptation to only querying the source model’s predictions on target samples. Existing BBDA methods struggle with noisy pseudo-labels and underutilize vision-language model (ViL) semantics. The proposed Dual-Teacher Distillation with Subnetwork Rectification (DDSR) combines a black-box source model and CLIP as two teachers, fusing their predictions adaptively based on entropy and target domain size. Knowledge distillation transfers the fused soft labels to a target student model, regularized by a subnetwork that shares early layers. Iterative refinement via exponential moving average (EMA) and CLIP prompt tuning progressively improves pseudo-labels and semantic alignment. A second stage employs class-wise prototypes for self-training, yielding robust target model performance.

## Method Summary
DDSR employs a two-stage training pipeline. Stage One distills knowledge from the dual teachers: predictions from the black-box source model and CLIP are fused using an entropy- and target-size-based rule to generate reliable pseudo-labels. The student (target) model is trained with a distillation loss (KL divergence), Mixup consistency, and information maximization to combat collapse. A subnetwork, created by taking the first 84% of the target model’s parameters, provides regularization through output alignment (JS divergence) and weighted gradient discrepancy, curbing overfitting to noisy labels. Pseudo-labels are iteratively refined via EMA, while CLIP’s text prompts are fine-tuned to align with the target model’s predictions. Stage Two computes class-wise prototypes from the Stage One features and predictions, reassigns pseudo-labels by nearest prototype (cosine distance), and fine-tunes the target model with cross-entropy.

## Key Results
- **Office-31:** 93.1% average accuracy (up to +3.3% over prior BBDA).
- **Office-Home:** 83.2% average accuracy (+2.6% over best ViL-based BBDA).
- **VisDA-17:** 90.6% average accuracy (matches the best prior result).
- Ablation studies confirm each component contributes positively, with the adaptive fusion and subnetwork rectification being particularly impactful.

## Why This Works (Mechanism)
### Mechanism 1: Adaptive Prediction Fusion
- **Claim:** Fusing the black-box source model and CLIP predictions adaptively based on entropy and target domain size generates more reliable pseudo-labels than either teacher alone or fixed averaging.
- **Mechanism:** Compute average prediction entropy of each teacher over the target set. Fusion weight α = Hc/(Hb+Hc). For large target domains (nt > 1000), CLIP’s weight increases to (1-α/2); for small domains, the source model’s weight increases. This dynamically balances contributions.
- **Core assumption:** Entropy is a valid online proxy for prediction reliability on the target domain, and optimal weighting depends non-monotonically on target sample count.
- **Evidence anchors:** Section III-B1 (Eq. 3 derivation); abstract mentions "adaptively integrates their complementary predictions".
- **Break condition:** Entropy miscalibration (e.g., overconfident CLIP on OOD data) or the domain-size threshold (ṅt=1000) is poorly chosen for the dataset.

### Mechanism 2: Subnetwork Regularization
- **Claim:** A subnetwork sharing early layers with the target model mitigates overfitting to noisy pseudo-labels via output alignment and controlled gradient divergence.
- **Mechanism:** Subnetwork uses first γ=84% of parameters layer-wise. Losses: L_od (JS divergence between subnetwork and full model outputs) and L_wg (weighted cosine similarity between their gradients w.r.t. L_od, weighted by subnetwork entropy).
- **Core assumption:** A partially overlapping subnetwork provides a useful, divergent learning signal without collapsing; forcing output alignment while encouraging gradient diversity prevents catastrophic overfitting to a single noisy supervision stream.
- **Evidence anchors:** Section III-B2 (definition of L_od, L_wg); Section IV-E ablation (removing L_sr degrades avg by ~0.6%).
- **Break condition:** Subnetwork too similar (γ→1) or too different (γ too small); gradient weighting heuristic fails if subnetwork entropy is a poor uncertainty measure.

### Mechanism 3: Iterative Refinement Loop
- **Claim:** Updating pseudo-labels via EMA and fine-tuning CLIP prompts creates a positive feedback loop that progressively enhances both pseudo-label quality and ViL semantic alignment.
- **Mechanism:** Pseudo-label ˆy updated: ˆy ← βˆy + (1-β)ˆyt (β=0.9). CLIP prompts optimized with L_cm = -ˆyt·ˆyc to align CLIP output ˆyc with current target predictions ˆyt.
- **Core assumption:** Target model predictions become increasingly accurate over training, serving as a better supervisory signal; CLIP prompts adapt to the target domain without catastrophic forgetting.
- **Evidence anchors:** Abstract mentions "refined target predictions iteratively enhance"; Section III-B3 (Eqs. 11, 12); training curves in Fig. 3 show steady improvement.
- **Break condition:** Early errors become entrenched via EMA and prompt co-adaptation, leading to confirmation bias and performance degradation.

## Foundational Learning
- **Knowledge Distillation (KD):** Why needed: BBDA requires transferring knowledge from inaccessible black-box teachers to a student via soft predictions. DDSR uses KL divergence in L_kd to absorb the fused teacher distribution. Quick check: Why KL divergence instead of cross-entropy with hard pseudo-labels? (Answer: Soft labels provide richer, distributional information that mitigates overconfident errors and encourages smoother decision boundaries.)
- **Entropy Minimization & Information Maximization:** Why needed: L_im combats model collapse common in self-training with noisy pseudo-labels. It minimizes per-sample entropy (encouraging confident predictions) while maximizing the entropy of the average prediction (encouraging exploration of all classes). Quick check: How does maximizing average prediction entropy prevent collapse to a single class? (Answer: It prevents the model from assigning all samples to a dominant class by incentivizing a uniform class distribution globally, thus maintaining diversity.)
- **Class-wise Prototypes for Self-Training:** Why needed: In Stage 2, class prototypes (mean feature vectors per predicted class) correct noisy instance-level pseudo-labels by aligning samples with the central tendency of their hypothesised class cluster. Quick check: What is the risk of using prototypes computed from noisy pseudo-labels, and how does cosine distance assignment mitigate it? (Answer: Noisy labels bias prototype centers; cosine distance focuses on feature direction rather than magnitude, offering some robustness to outliers and label noise.)

## Architecture Onboarding
- **Component map:** Black-box source model → CLIP → Fusion Controller → Pseudo-label → Target Model (with Subnetwork shadow) → EMA Manager → CLIP Prompt Optimizer → (Stage 2) Prototype Bank → Reassigned Labels → Target Model Fine-tune.
- **Critical path:** For each batch: 1) Query source and CLIP for predictions. 2) Compute entropies, fuse via Eq. 3. 3) Forward target model and subnetwork. 4) Compute L_kd, L_mix, L_im, L_od, L_wg; backpropagate total loss. 5) Update pseudo-label ˆy via EMA. 6) Update CLIP prompts via L_cm. After Stage 1: 7) Compute class prototypes from target features and predictions. 8) Reassign all pseudo-labels via nearest prototype. 9) Fine-tune target model with cross-entropy.
- **Design tradeoffs:** 
  - *Fusion strategy:* Entropy+size threshold is simple and parameter-free but brittle if entropy miscalibrates; a learned fusion weight might be more robust but adds complexity.
  - *Subnetwork ratio (γ):* 84% is empirical; too low → weak regularization, too high → vanishes. Broad stability suggested (Fig. 4) but not guaranteed.
  - *Two-stage design:* Decouples robust initialization from refinement, improving performance but increasing training time; could potentially be merged with sufficient computation.
- **Failure signatures:** 
  - Stage 1 accuracy plateaus at source model level → fusion dominated by noisy teacher (check entropy values in Fig. 7) or L_sr weights (ϵ, ζ) too low.
  - Stage 2 accuracy drops after prototype reassignment → Stage 1 prototypes corrupted; consider confidence-weighted prototype construction or later-stage EMA.
  - t-SNE (Fig. 2) shows no cluster improvement → subnetwork inactive (γ too high) or L_kd too weak.
  - High target prediction entropy persists → L_im weighting may be off or pseudo-labels too noisy.
- **First 3 experiments:**
  1. **Adaptive fusion ablation:** Replace adaptive fusion with fixed 0.5/0.5 averaging on a small task (e.g., D→A). Expect ~1-2% drop if mechanism works (as in Fig. 6).
  2. **Subnetwork sensitivity sweep:** Vary γ from 0.5 to 0.99 on one task (e.g., D→A). Plot accuracy to confirm peak near 0.84 and identify collapse thresholds.
  3. **Prototype corruption test:** After Stage 1, manually corrupt 20% of pseudo-labels before prototype computation. Re-run Stage 2; large accuracy drop indicates high sensitivity to Stage 1 noise.

## Open Questions the Paper Calls Out
1. **Category shifts:** How to extend DDSR to open-set or partial domain adaptation where target label space differs? The conclusion explicitly states this is future work; current method assumes Y_s = Y_t, which is restrictive. Resolution would require novelty detection or contrastive learning with unknown-class prototypes under BBDA constraints.
2. **Theoretical justification for adaptive fusion:** The counterintuitive weighting (favoring source model on small target domains) is empirically validated but lacks a theoretical model linking domain size to teacher reliability or noise properties. A bias-variance analysis or domain generalization theory could provide first-principles derivation.
3. **Subnetwork design impact:** The subnetwork uses fixed early-layer sharing (γ=84%). This ad-hoc choice is not systematically optimized; alternative architectures (random layer sampling, bottleneck, learnable routing) might yield better regularization. Evidence would come from extensive ablation across various subnetwork configurations and their effects on L_od/L_wg under noisy labels.
4. **Iterative refinement stability:** The closed-loop system (EMA updates + prompt tuning) may converge or diverge; no theoretical or empirical stability analysis is provided. Evidence would include a fixed-point iteration analysis or controlled experiments measuring pseudo-label quality over epochs with early-stopping criteria based on consistency checks.

## Limitations
- **Ambiguity in subnetwork construction:** "Selecting the first γ·100% of the weights from each layer" is vague (per-layer parameter count vs. block-wise); this can lead to implementation variability and affect reproducibility.
- **Unspecified prompt tuning details:** Unclear whether prompts are updated per batch or epoch, number of learnable tokens, and whether CLIP text encoder is frozen.
- **EMA update timing:** Not specified whether pseudo-labels are updated before or after each epoch, and initialization state (Stage One fused predictions or previous epoch?).
- **Mixup implementation uncertainty:** Unclear whether Mixup uses current batch predictions or EMA pseudo-labels.
- **Fusion reliability risk:** Adaptive weighting depends on entropy as a trust signal; entropy may be miscalibrated on OOD target data, and fixed threshold (ṅ_t=1000) may not generalize across datasets.

## Confidence
- **Mechanism 1 (Adaptive Fusion):** Medium. Ablation (Fig. 6) shows benefit, but mechanism is vulnerable to entropy miscalibration and the heuristic size threshold lacks theoretical grounding.
- **Mechanism 2 (Subnetwork Rectification):** High. Removal of L_sr causes a clear ~0.6% drop (Table IV-E), and the dual loss design is well-motivated for regularization.
- **Mechanism 3 (Iterative Refinement):** Low. Risk of confirmation bias via EMA and prompt co-adaptation; training curves alone cannot disentangle refinement benefits from other components.

## Next Checks
1. **Fusion ablation:** Replace adaptive fusion with fixed 0.5/0.5 averaging on Office-31 tasks; additionally implement a learned fusion weight (e.g., small network) and compare robustness to noise.
2. **Subnetwork sensitivity sweep:** Vary γ (0.5–0.95) on a single task (e.g., D→A) and plot accuracy to verify optimum around 0.84 and identify collapse points.
3. **Prototype purity test:** After Stage 1, recompute class prototypes using only high-confidence pseudo-labels (e.g., top 80% by max class probability). Re-run Stage 2 and measure accuracy change to quantify sensitivity to noisy labels.
