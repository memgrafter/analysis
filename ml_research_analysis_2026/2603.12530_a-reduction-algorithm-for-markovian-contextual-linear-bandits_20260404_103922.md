# A Reduction Algorithm for Markovian Contextual Linear Bandits

## Quick Facts
- **arXiv ID**: 2603.12530
- **Source URL**: https://arxiv.org/abs/2603.12530
- **Reference count**: 40
- **Primary result**: For known stationary distribution, achieves $O(d\sqrt{T}\log T)$ regret; for unknown, $O\!\left(d\sqrt{\frac{T\log T}{1-\beta}}\right)$; both improve over LinUCB.

## Executive Summary
The paper addresses Markovian contextual linear bandits where contexts evolve via an exogenous Markov chain, extending beyond i.i.d. assumptions. It proposes a reduction to a stationary surrogate linear bandit problem using the expected greedy action under the stationary distribution. A delayed-feedback scheme, with delay scaling as $\log T/(1-\beta)$, controls bias from nonstationary context distributions. For known stationary distribution, the method attains $O(d\sqrt{T}\log T)$ regret, matching standard linear bandit rates. For unknown distribution, a phased algorithm learns the surrogate online, yielding $O\!\left(d\sqrt{\frac{T\log T}{1-\beta}}\right)$ regret, with only mild dependence on the mixing time. Empirical results show consistent improvement over LinUCB.

## Method Summary
The core is constructing a surrogate action set $X^\pi = \{g^\pi(\theta) : \theta \in \Theta\}$ where $g^\pi(\theta) = \mathbb{E}_{A\sim\pi}[\arg\max_{a\in A} \langle a, \theta \rangle]$, using the stationary distribution $\pi$ of the Markov context chain. For known $\pi$, a standard linear bandit oracle (e.g., OFUL) runs on the fixed surrogate set. At each round $t$, the current context set $A_t$ is drawn, and the agent selects $a_t = \arg\max_{a\in A_t} \langle a, \theta_t \rangle$ such that $g^\pi(\theta_t)$ matches the oracle’s chosen proxy. The reward $r_{t-\tau}$ (with delay $\tau = \lceil c_\tau \log T/(1-\beta) \rceil$) is then fed to the oracle. For unknown $\pi$, a phased algorithm (Algorithm 2) builds an empirical surrogate $g^{(m)}$ from past greedy actions and employs a misspecification-robust linear bandit algorithm (e.g., Phased Elimination) on the corresponding surrogate set, again using delayed feedback. The delay ensures the effective context distribution is close to stationary, enabling the reduction.

## Key Results
- Known $\pi$: High-probability regret $O(d\sqrt{T}\log T)$, matching the i.i.d. contextual linear bandit lower bound up to log factors.
- Unknown $\pi$: High-probability regret $O\!\left(d\sqrt{\frac{T\log T}{1-\beta}}\right)$, with only a lower-order dependence on the mixing time.
- Empirical evaluations show the reduction-based algorithms outperform LinUCB in cumulative regret across various mixing parameters.

## Why This Works (Mechanism)
The reduction exploits the Markov chain’s stationary distribution to define a surrogate that averages out nonstationarity. The delayed feedback mechanism ensures that the data used by the linear bandit oracle (rewards and proxy actions) corresponds to contexts whose distribution is close to $\pi$. With delay $\tau = O(\log T/(1-\beta))$, the total variation distance between the distribution of the delayed context and $\pi$ decays polynomially, making the bias subleading. For unknown $\pi$, the phased approach balances learning the surrogate mapping $g^\pi$ (by accumulating empirical greedy actions) and exploiting it, using a misspecification-robust oracle to handle the approximation error $\epsilon_m$. The surrogate set remains a good approximation of the true greedy region, allowing linear bandit techniques to succeed under Markovian contexts.

## Foundational Learning
- **Markovian Contextual Bandits**: Context sets follow a Markov chain, breaking i.i.d. assumptions. *Why needed*: The paper’s setting is a Markovian instance. *Quick check*: Verify geometric ergodicity (e.g., finite state, aperiodic, spectral gap $1-\beta > 0$).
- **Linear Bandits**: Stochastic bandits with linear reward structure. *Why needed*: The surrogate reduction yields a linear bandit problem. *Quick check*: Actions have bounded $\ell_2$ norm, noise is sub-Gaussian.
- **Stationary Distribution ($\pi$)**: Invariant distribution of the Markov context chain. *Why needed*: The surrogate set $X^\pi$ is defined via $\pi$. *Quick check*: Solve $\pi P = \pi$ and check $\pi$ matches the design (e.g., uniform).
- **Mixing Time / Spectral Gap ($\beta$)**: Governs convergence to stationarity; $1-\beta$ is the spectral gap. *Why needed*: Determines required delay $\tau$. *Quick check*: Compute $\beta$ from $P$; $\tau$ should scale as $1/(1-\beta)$.
- **Surrogate Action Set ($X^\pi$)**: Convex hull of expected greedy actions under $\pi$. *Why needed*: Enables reduction to a stationary linear bandit. *Quick check*: For any $\theta$, $g^\pi(\theta)$ is a convex combination of actions from greedy sets across contexts.
- **Misspecification-Robust Linear Bandits**: Algorithms tolerating an approximate linear model (e.g., Phased Elimination). *Why needed*: For unknown $\pi$, the learned surrogate introduces misspecification. *Quick check*: Regret degrades gracefully with misspecification $\epsilon_m$ (e.g., additive $\epsilon_m\sqrt{T}$ term).

## Architecture Onboarding
- **Component map**: Markov Context Generator -> Current Context Set $A_t$ -> Agent selects $a_t$ using linear bandit oracle’s $\theta_t$ via $a_t = \arg\max_{a\in A_t}\langle a,\theta_t\rangle$ and maps to proxy $g^\pi(\theta_t)$ (or empirical $g^{(m)}(\theta_t)$) -> Reward $r_t$ -> Delay Buffer (size $\tau$) -> After $\tau$ steps, feed $(g^\pi(\theta_{t-\tau}), r_{t-\tau})$ to Linear Bandit Oracle -> Oracle updates $\theta_{t+1}$ -> Repeat.
- **Critical path**: The delay buffer ensures feedback uses contexts near stationarity. The surrogate construction (precomputed or online) must accurately approximate $g^\pi$. The linear bandit oracle must be tuned (regularization, confidence width) to match the analysis.
- **Design tradeoffs**: Known $\pi$ vs. unknown $\pi$: Precomputation cost vs. online learning overhead. Delay $\tau$: Larger $\tau$ reduces bias but increases memory and initial transient. Surrogate discretization: finer nets reduce misspecification but raise computation. Oracle choice: OFUL simplicity vs. Phased Elimination’s robustness to misspecification.
- **Failure signatures**: 
  - Linear regret growth indicates insufficient delay ($\tau$ too small) or mixing misestimation.
  - Regret exceeding LinUCB in low-mixing regimes suggests poor surrogate approximation or mis-specified oracle parameters.
  - Sudden regret spikes after phase changes indicate unstable surrogate updates.
- **First three experiments**:
  1. Validate bias decay: Plot per-round bias $|\langle a_t - g^\pi(\theta_t), \theta^*\rangle|$ vs. $t$ for different $\tau$; expect exponential decay $\sim \beta^\tau$.
  2. Compare known-$\pi$ algorithm against LinUCB for varying $\beta$; observe consistent improvement and empirical $O(\sqrt{T})$ scaling with constant increasing in $1/(1-\beta)$.
  3. Test unknown-$\pi$ algorithm with varying net resolutions; verify $O\!\left(\sqrt{T\log T/(1-\beta)}\right)$ trend and monitor $\epsilon_m$.

## Limitations
- Oracle hyperparameters (regularization $\lambda$, UCB width $\alpha$) and exact algorithm (OFUL vs. Phased Elimination) are not specified, leading to implementation ambiguity.
- The $1/T$-net $\Theta'$ construction for the surrogate in Algorithm 2 is underspecified, affecting misspecification $\epsilon_m$ and regret constants.
- Delayed feedback buffering and synchronization across phase changes in Algorithm 2 lack detail, risking violations of the analysis.

## Confidence
- Known $\pi$ regret bound: **Medium** (analysis plausible but depends on correct oracle and delay scaling).
- Unknown $\pi$ regret bound: **Low** (online surrogate learning introduces many unspecified details).
- Empirical superiority over LinUCB: **Low** (no experimental details provided).
