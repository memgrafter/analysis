# Learning Long-Range Dependencies with Temporal Predictive Coding

## Quick Facts
- arXiv ID: 2602.18131 (URL: https://arxiv.org/abs/2602.18131)  
- Reference count: 40  
- Primary result: tPC RTRL matches BPTT performance on sequence copy, language modeling, and translation tasks while retaining local computation and O(P) memory.

## Executive Summary
Predictive Coding (PC) is a biologically-inspired learning framework that operates via local, parallelizable updates, making it suitable for energy-efficient neuromorphic hardware. However, PC struggles with long-range temporal dependencies in recurrent neural networks (RNNs), where Backpropagation Through Time (BPTT) remains dominant despite its high memory and energy costs. This paper introduces Temporal Predictive Coding with Real-Time Recurrent Learning (tPC RTRL), which combines PC's local error-driven inference with an approximate RTRL mechanism to enable effective credit assignment across time without storing full unrolled networks. tPC RTRL achieves performance nearly identical to BPTT on three benchmarks: synthetic sequence copy (1.0000 accuracy), WikiText-2 language modeling (99.19 perplexity), and English-French translation (7.62 perplexity, 20.71 BLEU). These results demonstrate the first successful large-scale application of tPC to complex sequential tasks while preserving its inherent locality.

## Method Summary
tPC RTRL is a learning algorithm for recurrent neural networks that integrates Predictive Coding's local inference with an approximate Real-Time Recurrent Learning (RTRL) credit assignment. During each timestep, the model performs iterative inference to converge hidden states by minimizing a free energy composed of local prediction errors; these updates use only top-down predictions and temporal inputs, preserving locality. For parameter updates, tPC RTRL maintains an influence matrix M(t) that recursively tracks the effect of parameters on the current hidden state, enabling gradients for long-range dependencies without full unrolling. To reduce memory from O(n³) to O(P), the recurrent unit is element-wise (e.g., Linear Recurrent Unit, LRU), which diagonalizes the influence matrix. Recurrent weights are updated using a combination of immediate free energy gradients and the historic influence term, while readout weights use standard PC. This yields a method that is local, parallelizable, and avoids BPTT's O(T) memory cost, making it suitable for neuromorphic hardware.

## Key Results
- Synthetic copy task (10-step delay): test accuracy 1.0000 vs BPTT 0.9993.  
- WikiText-2 language modeling: test perplexity 99.19 (BPTT 98.62).  
- English-French translation (15M parameters): test perplexity 7.62, BLEU 20.71 (BPTT 7.49, 21.11).

## Why This Works (Mechanism)

### Mechanism 1: Local Error-Driven Inference for Stable Dynamics
- **Claim:** The model uses iterative, local minimization of prediction errors (free energy) to converge hidden states, providing a stable dynamical system for learning.
- **Mechanism:** At each time step, neuron activations (latent variables) are adjusted via gradient descent on layer-wise prediction errors (εₗ = xₗ - μₗ), where μₗ is a top-down prediction. This inference process (E-step) is local, relying only on pre-synaptic activity and prediction errors.
- **Core assumption:** The system reaches a quasi-stable "explained" state (free energy minimized) before parameter updates are applied, ensuring learning targets meaningful hypotheses about hidden causes.
- **Evidence anchors:**
  - [abstract] "characterised by local, parallelisable operations"
  - [section 2.1] "the free energy... reduces to a sum of precision-weighted local errors" and "iterative inference phase where the free energy is minimised"
  - [section 3.1] "the converged hidden state does not necessarily take the value of the predicted hidden state"
- **Break condition:** If inference iterations are insufficient or learning rate too high, activations may not converge, leading to poor gradient estimates and unstable training. Evidence: Appendix D shows tuning of inference LR/iterations was necessary.

### Mechanism 2: Approximate RTRL for Temporal Credit Assignment
- **Claim:** The influence matrix M(t) propagates parameter sensitivities across time steps, enabling credit assignment for past events without unrolling the full graph (like BPTT).
- **Mechanism:** M(t) is recursively updated: M(t) ≈ ∂μ(t)/∂W(t) + ∂μ(t)/∂x̂(t-1) M(t-1). This captures historic parameter influence on current predictions via the Jacobian of the hidden state transition. In tPC, μ(t) (prediction) is substituted for x̂(t) (converged state) in the update.
- **Core assumption:** The divergence between μ(t) and x̂(t) (internal prediction error) is small enough that using μ(t) in the influence update is a valid approximation for gradient descent.
- **Evidence anchors:**
  - [section 2.2] Describes exact RTRL: M(t) = M̄(t) + J(t)M(t-1)
  - [section 3.1] "the key difference... is that the converged hidden state x̂(t) is substituted for the predicted hidden state μ(t)" and "this approximation is sufficient"
  - [section 4] tPC RTRL matches BPTT on long-range tasks, empirically supporting the approximation.
- **Break condition:** Accumulated errors in M(t) from the approximation could cause gradient drift over very long sequences, though experiments (Section 4) show robustness up to 128-token translation tasks.

### Mechanism 3: Architectural Scaling via Element-wise Recurrence
- **Claim:** Using an element-wise recurrent unit (LRU) diagonalizes the influence matrix, reducing memory from O(n³) to O(P), making tPC RTRL tractable for larger models.
- **Mechanism:** In a standard RNN, the influence matrix M(t) is dense (n×P, with n hidden units, P parameters). Element-wise recurrence (each unit depends only on its own past state and a distinct subset of parameters) makes the Jacobian J(t) approximately diagonal, so M(t) becomes sparse/low-rank.
- **Core assumption:** The expressive power of element-wise units (like LRU) is sufficient for the target tasks despite the restricted connectivity.
- **Evidence anchors:**
  - [section 2.2] "nP≈O(n³) memory... using an element-wise recurrent unit... reduces... to O(P)"
  - [section 4.2 & 4.3] All large-scale experiments use LRU architecture.
  - [section 5] "multi-layer RNNs require storing O(L²) influence matrices... prior work suggests layer-local assumptions recover some benefits"
- **Break condition:** Deep multi-layer recurrence or complex cross-unit dependencies may exceed the modeling capacity of element-wise units, potentially harming performance on tasks requiring rich inter-unit temporal interactions.

## Architecture Onboarding

### Component Map
Input sequence → Inference Unit (iterative E-step: computes predictions μ(t), errors ε(t), updates hidden states x(t) to x̂(t)) → x̂(t) fed to Influence Tracker and Readout Head. Influence Tracker uses x̂(t) and previous M(t-1) to update M(t). Parameter gradients are computed from (∂F/∂μ) * (∂μ/∂x̂) * M(t-1) for recurrent weights and ∂F/∂W for readout. Optimizer (Adam) applies updates.

### Critical Path
1. Initialize: x̂(0) and M(0) to zero.
2. Per time step t:
   - Initialize x(t) via feedforward sweep.
   - **Inference loop (N_iter times):** Compute μₗ(t), εₗ(t), update xₗ(t) via -α ∂F/∂xₗ.
   - Set converged state x̂(t) = x(t).
   - **Update M(t)** using Eq. 13 (substituting x̂(t) for μ(t) in the influence recursion).
   - **Accumulate gradients:** ΔW = -η (∂F/∂μ * ∂μ/∂x̂ * M(t-1) + ∂F/∂W) for recurrent params; ΔW = -η ∂F/∂W for readout.
3. After sequence T, apply accumulated ΔW.

### Design Tradeoffs
- **Accuracy vs. Memory:** tPC RTRL (O(P) memory) vs. BPTT (O(T) memory). tPC RTRL trades exact BPTT gradients for lower memory footprint.
- **Inference cost vs. Performance:** More inference iterations (N_iter) and higher inference LR (α) improve convergence of x̂(t) but increase per-step compute. Appendix D shows task-specific tuning.
- **Architectural expressivity vs. Scalability:** Element-wise recurrence (LRU) enables tractable RTRL but may limit representational power compared to dense RNNs. Multi-layer extension requires O(L²) M matrices or local approximations.

### Failure Signatures
- Divergent/increasing free energy F(t): Inference LR α too high or N_iter too low → activations oscillate.
- Stagnant training loss with high internal error: Model fails to reduce prediction errors εₗ, suggesting poor inference-parameter update coordination.
- Poor long-range performance but good short-range: tPC RTRL may underfit if M(t) degrades over very long sequences (>128 steps) or element-wise capacity insufficient.
- Sensitivity to initialization: x̂(0) and M(0) zero-init assumed; poor random init could cause early instability.

### First Experiments
1. **Synthetic Copy Task (Section 4.1):** Validates tPC RTRL can learn a necessary long-range dependency (10-step delay) that spatial BP and baseline tPC fail at.
2. **WikiText-2 Language Modeling (Section 4.2):** Tests on real sequential data; performance gain is modest (99.19 vs 98.62 perplexity), showing competitiveness.
3. **English-French Translation (Section 4.3):** Stress-test on a task with critical long-range dependencies; tPC RTRL matches BPTT (7.62 vs 7.49 ppl, 20.71 vs 21.11 BLEU) at scale (15M params).

## Open Questions the Paper Calls Out
1. Can tPC RTRL be effectively implemented on neuromorphic hardware to achieve measurable energy savings compared to BPTT-trained RNNs?
2. What systematic principles or "best practices" can be established for robustly tuning the inference hyperparameters (e.g., learning rate, iterations) of tPC RTRL across diverse tasks, given its noted sensitivity?
3. Can the layer-local influence matrix approximations (which avoid O(L²) scaling) successfully scale tPC RTRL to deep multi-layer RNNs without significant performance degradation?
4. To what extent can sparse or factorised approximations of the influence matrix M(t) reduce the computational and memory burden of tPC RTRL for very large recurrent layers, and at what cost to learning performance?
5. Is the strong performance of tPC RTRL on the tested tasks primarily attributable to the (approximate) RTRL mechanism, or would simpler temporal credit assignment methods (e.g., eligibility traces, truncated BPTT with large windows) achieve similar results with less computational overhead?

## Limitations
- Implementation details of the Linear Recurrent Unit (LRU) are inherited from prior work and not fully elaborated, introducing potential instability or divergence in replication.
- The method has only been validated for single-layer RNNs; scaling to deep recurrent architectures is unspecified and may require nontrivial approximations.
- Long-sequence performance beyond 128 steps remains untested, and the influence matrix's numerical stability (e.g., initialization, damping) is not analyzed.
