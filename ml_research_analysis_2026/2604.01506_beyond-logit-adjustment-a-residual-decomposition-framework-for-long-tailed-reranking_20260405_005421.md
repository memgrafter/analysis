# Beyond Logit Adjustment: A Residual Decomposition Framework for Long-Tailed Reranking

## Quick Facts
- **arXiv ID:** 2604.01506
- **Source URL:** https://arxiv.org/abs/2604.01506
- **Reference count:** 40
- **Primary result:** REPAIR, a residual decomposition reranking framework, significantly improves rare-class accuracy on long-tailed tasks, with especially large gains (+19.4%) on the RareBench medical dataset.

## Executive Summary
Long-tailed classification models systematically underrank rare classes due to imbalanced training. Standard post-hoc methods like logit adjustment apply fixed classwise offsets, but these cannot correct instance-specific biases where the optimal correction for a pair of classes varies across inputs. This paper introduces REPAIR, a residual decomposition framework derived from the Bayes-optimal solution. The optimal correction splits into a constant classwise term (averaged over contexts) and an input-dependent pairwise term that captures competition between shortlisted classes. REPAIR estimates both from a held-out calibration set: a shrinkage-stabilized classwise offset and a linear pairwise correction using hand-crafted features (e.g., semantic similarity, co-occurrence, and for medical data, HPO-based similarity). On five benchmarks, REPAIR outperforms classwise-only adjustment and logit adjustment. Gains are modest on vision tasks (iNaturalist +0.2%, ImageNet-LT +0.2%, Places-LT +0.4% in Hit@1) but substantial on rare disease diagnosis (GMDB +0.9%, RareBench +19.4%). It also significantly improves hardest-rival flip rate, and the improvement magnitude correlates with a theoretical measure of threshold dispersion, supporting the need for pairwise correction when the setting is non-class-separable.

## Method Summary
REPAIR is a post-hoc reranking method for long-tailed multiclass classification. Given a pretrained base model that outputs scores \(g_y\) for all classes, REPAIR first constructs a shortlist \(S(x)\) of the top-\(k\) (e.g., \(k=10\)) classes for each input \(x\). The reranking score for a candidate class \(y \in S(x)\) is defined as \(r_y = g_y + a_y + \ell_y\), where \(a_y\) is a classwise offset and \(\ell_y\) is a pairwise correction that aggregates information about competing classes \(j \in S(x) \setminus \{y\}\). The pairwise term uses hand-crafted features \(f_{y,j}\) (e.g., semantic similarity, co-occurrence, and for medical tasks HPO Jaccard similarity) and a learned weight vector \(\theta\): \(\ell_y = \theta^\top \left(\frac{1}{|S(x)|-1} \sum_{j \in S(x) \setminus \{y\}} f_{y,j}\right)\). Parameters \(a\) and \(\theta\) are learned by maximizing a regularized conditional log-likelihood on a calibration set where the true label lies within the shortlist. Classwise offsets \(a\) are first initialized via maximum likelihood and then stabilized using empirical Bayes shrinkage, grouping classes by frequency (one group per dataset). At inference, REPAIR adds both terms to the base scores and reranks the shortlist.

## Key Results
- Vision benchmarks: modest improvements in Hit@1—iNaturalist +0.2%, ImageNet-LT +0.2%, Places-LT +0.4%—over classwise-only baselines.
- Rare disease diagnosis: large gains—GMDB +0.9% Hit@1, RareBench +19.4% Hit@1—and significant improvements in hardest-rival flip rate (HFR).
- REPAIR consistently outperforms standard logit adjustment and the classwise-only variant; performance gain strongly correlates with a dataset-specific measure of threshold dispersion \(D_y\), confirming the theoretical prediction that pairwise correction helps when the setting is non-class-separable.

## Why This Works (Mechanism)
The Bayes-optimal post-hoc correction for long-tailed ranking decomposes into a constant classwise bias (the average adjustment over all inputs) and an input-dependent pairwise term that captures context-specific interactions between the true class and its competitors. The classwise term corrects global frequency-related shifts, while the pairwise term refines decisions based on the specific set of top contenders, addressing cases where a rare class is systematically confused with a particular head class. By modeling both, REPAIR can adjust not only overall under/overestimation but also instance-level competition effects, leading to substantial improvements on tasks with high class confusion (e.g., rare disease diagnosis) while retaining modest gains on vision benchmarks.

## Foundational Learning
- **Long-tailed classification**: The core problem where class frequencies span orders of magnitude, causing models to bias toward head classes. *Why needed:* It defines the distributional setting REPAIR targets. *Quick check:* Verify the training set follows a Pareto-like frequency distribution (many classes with few samples).
- **Post-hoc reranking**: Adjusting model outputs without retraining, often using a held-out calibration set. *Why needed:* REPAIR is designed as a plugin to existing classifiers. *Quick check:* Ensure the base model's shortlist includes the true label for a high proportion of calibration examples (Recall@k).
- **Logit adjustment**: A baseline that adds fixed classwise offsets (e.g., \(\tau \log \pi_y\)) to logits. *Why needed:* It represents the simplest frequency-based correction. *Quick check:* Tune the \(\tau\) hyperparameter on the calibration set to match reported baselines.
- **Residual decomposition**: The theoretical insight that the Bayes-optimal correction splits into classwise and pairwise components. *Why needed:* It justifies the two-term structure of REPAIR. *Quick check:* Estimate the class-separability metric \(D_y\) on calibration data; high values suggest a non-zero pairwise term.
- **Pairwise competition features**: Hand-crafted descriptors of relationships between two classes (e.g., semantic similarity, co-occurrence, HPO overlap). *Why needed:* They provide the input-dependent signal for the pairwise correction. *Quick check:* Confirm feature dimensions match Table 3 (5 for vision, 4 for Places-LT, 2 for medical).
- **Shrinkage estimation**: Empirical Bayes technique to stabilize classwise offset estimates by pulling extreme values toward a group mean. *Why needed:* Prevents overfitting on rare classes with few calibration examples. *Quick check:* Compare raw offset variance before and after shrinkage; expect reduction without substantial bias change.

## Architecture Onboarding
**Component map (plain text):**  
Base model (predicts \(g_y\)) → Shortlist \(S(x)\) (top-k) → For each \((x,y,j)\) with \(y\in S, j\neq y\): extract pairwise features \(f_{y,j}\) → Calibration: initialize \(a\) via MLE → shrink \(a\) → jointly optimize \(a, \theta\) via L-BFGS-B → Inference: compute \(r_y = g_y + a_y + \theta^\top (\text{mean}_{j} f_{y,j})\) for \(y\in S(x)\) → rerank.

**Critical path:** Shortlist construction with high recall → reliable pairwise feature extraction → stable classwise offset estimation (initialization + shrinkage) → joint optimization of \(\theta\) → correct application during inference. Any break (e.g., poor feature design or insufficient calibration coverage) degrades performance.

**Design tradeoffs:**  
- Linear vs. non-linear pairwise model: Linear chosen for simplicity and to avoid overfitting on small calibration sets; non-linear might capture interactions but risks overfitting.  
- Shrinkage grouping: Using one group per dataset (as in paper) simplifies implementation but may under-shrink; frequency bins could improve but require validation.  
- Feature engineering: Hand-crafted domain-specific features yield strong results (especially HPO similarity for medical) but require domain knowledge; generic embeddings (e.g., cosine similarity of classifier weights) could be more broadly applicable but need empirical verification.  
- Regularization strength (\(\lambda_a, \lambda_\theta\)): Must be tuned per dataset to balance fit and overfitting.

**Failure signatures:**  
- Shortlist recall on calibration lower than reported (e.g., <80%) caps maximum possible gain.  
- Pairwise feature dimension mismatch (e.g., using 5 features for Places-LT instead of 4) causes runtime errors or performance drop.  
- High variance in classwise offsets after shrinkage indicates insufficient data or inappropriate grouping.  
- Discrepancy between calibration and test feature distributions (e.g., due to dataset shift) reduces pairwise term effectiveness; monitor performance on a validation slice.  
- Overfitting: calibration loss decreases but test metrics worsen; reduce regularization or increase calibration data.

## Open Questions the Paper Calls Out
- **Can cosine similarity between base model class embeddings replace hand‑crafted pairwise features in REPAIR without sacrificing accuracy?** The paper mentions this as future work; embedding‑based similarity has not been tested.
- **Can a simple diagnostic (e.g., average \(D_y\)) predict when REPAIR will significantly outperform classwise‑only adjustment?** While a correlation is shown, no quantitative threshold or decision rule exists.
- **Does a non‑linear pairwise model (e.g., a small MLP) further improve REPAIR on highly non‑class‑separable tasks?** The linear parameterization might be a bottleneck; non-linear extensions remain unexplored.
- **Under what conditions on the data distribution and base model is the residual correction \(\beta^\star\) class‑separable, making fixed offsets sufficient for Bayes‑optimal reranking?** The theory provides structure but no characterization of when the pairwise term vanishes.

## Limitations
- Missing checkpoints and official splits for rare-disease benchmarks (GMDB, RareBench) prevent full independent verification.
- Shrinkage grouping strategy (one group vs. frequency bins) is unspecified; implementation choices may affect stability.
- Places-LT pairwise feature set is ambiguous (domain similarity omitted but 4-dimensional claim not defined).
- Small calibration sets (e.g., RareBench with only 117 examples) risk high variance in pairwise weight estimates.

## Confidence
- **Theoretical decomposition:** Medium (plausible but relies on strong separability assumptions).
- **Empirical gains:** Medium (vision results marginal; medical results large but depend on inaccessible resources).
- **Pairwise correction efficacy:** Low-Medium (correlation evidence indirect; replication needed).
