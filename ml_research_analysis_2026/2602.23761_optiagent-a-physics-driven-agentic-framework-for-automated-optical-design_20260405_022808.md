# OPTIAGENT: A Physics-Driven Agentic Framework for Automated Optical Design

## Quick Facts
- **ArXiv ID:** 2602.23761
- **Source URL:** https://arxiv.org/abs/2602.23761
- **Reference count:** 28
- **Primary result:** OPTIAGENT achieves a 90.1% success rate in generating physically valid optical designs from user specifications, with a low EFFL relative error of 0.98%.

## Executive Summary
Optical lens design is a complex non-convex optimization problem traditionally reliant on human expertise. This paper introduces OPTIAGENT, a physics-driven agentic framework that automates the generation of viable optical systems from user specifications. The method trains a large language model (LLM) using DrGRPO with a hierarchical Optical Lexicographic Reward, injects domain knowledge via an Optical Prescription Completion auxiliary task, and integrates Zemax for final refinement. On the OptiDesignQA test set, OPTIAGENT demonstrates a 90.1% success rate—far surpassing state-of-the-art LLMs like ChatGPT and Qwen—while maintaining high precision (EFFL error ~1%) and producing manufacturable designs after Zemax optimization.

## Method Summary
The approach treats optical prescription generation as a reinforcement learning task. An LLM policy (Qwen3-4B-Instruct) is trained with DrGRPO to output lens prescriptions in a structured ODDL format. A hierarchical reward enforces a strict validity cascade: format compliance, structural rules (e.g., positive thicknesses, stop placement), paraxial ray tracing accuracy (target EFFL and image height), and finally RMS spot size—but only if first-order properties pass gated thresholds. An auxiliary Optical Prescription Completion task, where the model fills masked values in partial prescriptions, injects geometric interdependencies. At inference, the LLM generates an initial design (L₀), which Zemax refines via local optimization, exploiting separation of concerns: RL for global topology, Zemax for continuous parameter tuning.

## Key Results
- 90.1% success rate in producing physically valid designs on OptiDesignQA.
- Low EFFL relative error of 0.98% and initial RMS spot size of 672.09 µm.
- After Zemax refinement, achieves final RMS of 41.23 µm, significantly outperforming ChatGPT and Qwen.

## Why This Works (Mechanism)
1. **Optical Prescription Completion**: Masking parts of lens prescriptions forces the model to learn geometric couplings (e.g., curvature-thickness-material relationships) to maintain focal length. This internalizes spatial logic beyond text patterns, ensuring physically coherent fills. Ablation in Table 3 shows success rate jumps from 28.8% (no completion) to 90.1% (full completion ratio).
2. **Hierarchical Optical Lexicographic Reward**: The reward is a product of gated components: format (binary) → structure (binary) → paraxial ray tracing → (if thresholds met) RMS. This prevents premature optimization of fine metrics and avoids instability from conflicting objectives. Table 2 shows naive combination of ray tracing and RMS causes divergence, while the gated "Ray Tracing→RMS" strategy yields stable convergence.
3. **Zemax Integration**: The RL agent excels at global structural synthesis (discrete topology), producing valid initial designs that serve as high-quality seeds for Zemax's local continuous optimizer. Figure 4 shows all methods improve after Zemax, but OPTIAGENT's superior initial designs lead to the best final RMS, confirming the synergy.

## Foundational Learning
- **Paraxial Ray Tracing**: Needed to compute the core physics reward (EFFL accuracy, convergence) via a differentiable first-order tracer. Quick check: For a two-lens system, how does a convex (positive R) vs. concave (negative R) surface affect the ray angle after refraction?
- **GRPO/DrGRPO**: The RL algorithm that updates the LLM policy using group-relative advantages; removing standard deviation normalization mitigates length bias in generative tasks. Quick check: Why does DrGRPO omit advantage normalization, and how does this help in generative tasks?
- **Optical Prescription Format (ODDL)**: Enforces a specific, parsable data representation with strict topological constraints. Quick check: List four constraints (e.g., OBJ at index 0, STOP between surfaces) and explain why the last material must be AIR/VAC with positive thickness.

## Architecture Onboarding
**Component map:**  
Input Specification (P) -> LLM Policy Agent -> Physics Evaluator -> DrGRPO Trainer -> (Inference) -> Zemax Refinement Module -> Final Design

**Critical path:** User spec prompts LLM to generate prescription (L); Physics Evaluator computes hierarchical reward (R_lex); DrGRPO updates policy. At inference, best L₀ is refined by Zemax.

**Design tradeoffs:**
- Compute vs. Generality: Differentiable paraxial tracer is cheap but approximate; Zemax is accurate but expensive.
- Reward Complexity vs. Stability: Early RMS activation causes instability; gating ensures stability but delays fine-grained learning.
- Auxiliary Task Ratio: Too little completion training fails to inject geometric knowledge; too much dilutes main task (collapse beyond 100% masking).

**Failure signatures:**
- Low Success Rate: Likely S_fmt/S_stru failures (format errors, missing STOP, negative thickness). Strengthen prompts or pre-SFT on parsing.
- High EFFL Error: Paraxial tracer signal too weak; verify reward weighting (w_f=0.6) and differentiable implementation.
- High RMS despite good EFFL: δ_pass gate too lenient or RMS scaling (γ) mismatched; adjust thresholds and field/pupil sampling.
- Training Instability: Simultaneous high-variance rewards; ensure strict hierarchical multiplication and tune KL penalty (β).

**First 3 experiments:**
1. Train solely on Optical Prescription Completion (mask ratio ~50%) to verify the model learns geometric coupling, not memorization.
2. Incrementally add reward components (format/structure → +ray tracing → +RMS) to isolate contributions and confirm gating necessity.
3. For a fixed policy, compare Initial vs. Final RMS after Zemax and record convergence iterations to quantify refinement value and validate L₀ basin quality.

## Open Questions the Paper Calls Out
1. **Optimal completion task proportion:** The ablation shows success rate improves from 28.8% (0%) to 90.1% (100%) but collapse beyond 100% masking. What is the theoretical optimum, and how does completion transfer to full design?
2. **Reward threshold sensitivity:** Gating thresholds (ϵ < 0.05, |y_img| < 0.1 mm) are heuristic. How do they affect trade-offs between success rate and precision, and do they generalize across spec ranges?
3. **SFT vs. RL failure modes:** Why does supervised fine-tuning yield only 36.1% SR while RL achieves 90.1%? Which RL components (group-relative advantages, KL penalty) are essential for physical reasoning?

## Limitations
- OptiDesignQA dataset is not public, preventing independent verification of metrics.
- Exact Zemax scripting interface and optimizer settings are undisclosed; open-source alternatives may not replicate final RMS.
- Glass library (material properties) is unknown, affecting structural checks and RMS calculations.
- Corpus shows high FMR but zero citations, suggesting niche or very recent work with limited cross-validation.

## Confidence
- **Mechanism 1 (Completion Task):** High – well-specified and directly supported by Table 3 ablation.
- **Mechanism 2 (Hierarchical Reward):** Medium-High – mathematically defined and Table 2 shows gating necessity.
- **Mechanism 3 (Zemax Synergy):** Medium – logically sound but unverified assumption about L₀ basins; no failure rates reported.
- **Overall performance claims (90.1% SR, 0.98% error):** Low-Medium – constrained by dataset secrecy, implementation gaps, and unvalidated format rules.

## Next Checks
1. **Public Dataset Replication:** Re-train using public lens databases (e.g., LensDesign.org) to quantify dataset bias and validate reported metrics.
2. **Reward Function Audit:** Implement exact hierarchical reward (R_lex) and run incremental reward validation, logging δ_pass activation to verify gating behavior and identify reward starvation.
3. **Zemax Sensitivity Analysis:** For 50 converged L₀ designs, vary Zemax tolerances and apply ±5% parameter jitter to measure convergence rate and final RMS spread, testing robustness to optimizer hyperparameters.
