# Memory-Conditioned Flow-Matching for Stable Autoregressive PDE Rollouts

## Quick Facts
- arXiv ID: 2602.06689
- Source URL: https://arxiv.org/abs/2602.06689
- Reference count: 40
- Primary result: MCRF reduces final-time relative ℓ2 error by 43.3% on CE-RM for 20-step dense rollouts vs. memoryless baseline.

## Executive Summary
Autoregressive PDE solvers based on diffusion or flow matching produce accurate one-step predictions but often drift over long rollouts, particularly in coarse-to-fine settings where each step must regenerate unresolved fine scales. This drift stems from a fundamental omission: under Mori–Zwanzig theory, eliminating unresolved variables introduces a history-dependent memory term that Markovian closures ignore.

The authors propose Memory-Conditioned Flow Matching (MCRF) to address this issue. MCRF augments a rectified-flow transition kernel with a compact online memory state that captures cross-scale transfer statistics and shapes a conditional prior for unresolved modes, thereby reducing the transport needed to populate missing frequencies. Theoretical analysis yields Wasserstein stability guarantees and discrete Grönwall rollout bounds that separate memory approximation error from generation error. Experiments on 2D compressible Euler—including shocks and multiscale mixing—demonstrate that MCRF improves long-horizon stability. Compared to a memoryless baseline, it reduces final-time relative ℓ2 error by 43.3% on CE-RM for 20-step dense rollouts (versus 1.9% for 10 steps), with gains concentrated on low and mid frequencies (29–61% error reduction in spectral bands). The method shows further improvements under degraded conditioning and variable lead-time schedules, evidencing scaling with rollout horizon and resilience to distribution shift.

## Method Summary
MCRF is a memory-conditioned rectified flow approach for autoregressive PDE solving. It processes a coarse state ˜u_n and a physical time step Δt_n. An encoder Eψ produces an embedding e_n, which is appended to a FIFO buffer of maximum length 16. A state-space (S4) layer processes the buffer to generate a memory state m_n. A U-Net backbone (3 levels, attention at bottleneck) ingests a noisy target u_τ along with the stacked conditioning state ˜u_n. At the bottleneck, m_n is injected via a gated fusion mechanism, influencing the high-level features that control frequency generation. The vector field vθ outputs a drift conditioned on internal time τ and the fused context. The base prior is fixed as standard Gaussian N(0,I). Training mixes autoregressive pairs (A2A) and short sequences (length 3–12) with teacher forcing (probability 0.8) and minimizes a flow-matching mean squared error loss. At inference, memory is updated online using detached embeddings of ˜u_n.

## Key Results
- MCRF reduces final-time relative ℓ2 error by 43.3% on CE-RM for 20-step dense rollouts, compared to only 1.9% improvement for 10 steps.
- The error reduction is concentrated on low and mid frequencies, with spectral band errors decreased by 29–61%.
- Under degraded conditioning and variable lead-time schedules, memory amplifies stability improvements, demonstrating scaling with rollout horizon and resilience to distribution shift.

## Why This Works (Mechanism)

### Mechanism 1: Memory approximates the Mori–Zwanzig memory integral
- **Claim**: Memory approximates the Mori–Zwanzig memory integral, addressing the structural omission in Markovian closures.
- **Mechanism**: The MZ decomposition shows that projecting out unresolved modes adds a history-dependent convolution term. MCRF uses a compact recurrent state (S4) within the memory module to approximate this convolution, injecting the summary into the denoising bottleneck.
- **Core assumption**: The relevant history can be compressed into a finite-dimensional state that evolves approximately linearly with the resolved embeddings.
- **Evidence**: Abstract reference to MZ theory; Section 2.2 (MZ identity) and 3.1 (linear-Gaussian tail surrogate); corpus alignment on flow matching stability (FMR=0.518).
- **Break condition**: If the memory kernel weights decay slowly, a short buffer cannot capture enough history and the approximation error dominates.

### Mechanism 2: Memory shapes a structured conditional prior for unresolved high-frequency shells
- **Claim**: Memory shapes a structured conditional prior for unresolved high-frequency shells, reducing Wasserstein transport needed during generation.
- **Mechanism**: In flow matching, internal τ corresponds to noise level; high-frequency shells often stay low-SNR. Theorem 3.1 shows the optimal denoiser uses the prior mean, which is history-driven. Memory approximates this mean, shrinking W2 mismatch between true tail law and base prior.
- **Core assumption**: The tail statistics follow a linear-Gaussian process driven by resolved embeddings (conditional isotropic covariance).
- **Evidence**: Abstract statement about cross-scale transfer; Theorem 3.1 (shell-wise posterior mean) and Section 3.4 (Lemma 3.5, Proposition 3.6); comparison to works like UniFluids and CFO that lack explicit memory.
- **Break condition**: When σ(τ) never dominates shell variances s_j (all shells high SNR throughout), the denoiser relies on observation not prior, diminishing memory's effect.

### Mechanism 3: Rollout error bound reveals memory’s role and scaling
- **Claim**: The rollout error bound separates memory approximation from conditional generation error, predicting scaling with horizon and shift.
- **Mechanism**: Under one-step law stability (Assumption A.1) and kernel Lipschitz in memory (A.2), the error satisfies dn ≤ e^{β0,n} d0 + Σ e^{βk+1,n} ϵ_k, with ϵ_k ≤ L_mem ∥bm - m*∥ + ε_gen. Memory reduces ϵ_k by improving match to m* and conditional kernel.
- **Core assumption**: (i) True PDE dynamics are stable enough (α_n bounded). (ii) Learned kernel is Lipschitz in memory (Proposition G.4).
- **Evidence**: Abstract stability proof; Theorem 3.8 and Assumptions A.1/A.2; Proposition G.4.
- **Break condition**: If α_n are large (expansive regime) or L_mem is large, memory errors may amplify, potentially making memory harmful on very long horizons.

## Architecture Onboarding

**Component map**:  
Encoder Eψ (˜u_n, Δt_n) → e_n → push to FIFO buffer (max 16) → S4 layer → memory state m_n → spatial broadcast → Conv1×1(d_h) → gated addition with U-Net bottleneck features h → vector field vθ (τ, context) → drift. Base prior: N(0,I).

**Critical path**:  
Input ˜u_n, Δt_n → Eψ → e_n → buffer update & S4 → m_n → spatial broadcast → Conv1×1(d_h) → gate computation → gated fusion with U-Net bottleneck h → vθ(τ, context) → Euler/Heun integration (K steps) → b_{n+1}. Memory updates once per physical step with current conditioning embedding (detached).

**Design tradeoffs**:
- Memory dimension (128) vs. buffer length (16): trade-off between expressiveness and computational cost; S4 provides linear complexity in buffer size.
- Injection at bottleneck (rather than earlier layers) ensures memory influences high-level features that govern frequency generation.
- Fixed base law (N(0,I)) vs. making it conditional: experiments showed no benefit from a memory-dependent prior.

**Failure signatures**:
- Spectral error pattern: If memory is ineffective, the relative ℓ2 error increase is concentrated in low and mid frequency bands.
- Memory collapse: The norm of m_n becomes nearly constant across steps, indicating the memory module fails to aggregate meaningful information.
- Scaling mismatch: No improvement on short rollouts (<5 steps) but positive scaling with horizon; absence of this pattern suggests memory not operational.

**First 3 experiments**:
1. Single-step supervised accuracy: verify that adding memory does not degrade one-step performance.
2. Autoregressive rollout under varied Δt schedules (uniform, sparse, increasing): evaluate stability as rollout horizon increases (10 vs. 20 steps).
3. Spectral decomposition: measure error in radial frequency bands (low, mid, high) and test robustness to degraded conditioning (blurred inputs).

## Open Questions the Paper Calls Out
1. **Scaling to higher Reynolds numbers**: The conclusion identifies scaling MCRF to higher Re as an open challenge. Unresolved because the theoretical bounds involve constants (α_n, L_mem) that may grow in chaotic, high-Re regimes. Resolution requires systematic experiments on 3D turbulent flows (e.g., forced incompressible Navier-Stokes at Re > 10^4) with diagnostics of these constants.
2. **Interaction with invariant-measure regularization**: How does memory interact with invariant-measure objectives (e.g., DySLIM) for combined stability? Unresolved: it is unclear whether these objectives are complementary, redundant, or conflicting, especially under distribution shift. Resolution: ablation studies combining flow-matching with MMD or DySLIM-style losses, comparing long-horizon drift and spectral fidelity.
3. **Extension to 3D and other PDE families**: The authors call for extending MCRF to 3D turbulent flows and other equations (e.g., Navier-Stokes, reaction-diffusion). Unresolved because the spectral decomposition and coarse-to-fine generation may not transfer to different cascade physics. Resolution: apply MCRF to 3D benchmarks (e.g., decaying isotropic turbulence) and to other PDEs (e.g., Kuramoto–Sivashinsky), measuring stability gains and memory statistics.
4. **Realism of Lipschitz assumptions**: The analysis relies on per-step stability (Assumption A.1) and memory-Lipschitz (A.2) constants. Unresolved whether these hold for high-dimensional chaotic systems and how they scale with resolution. Resolution: empirically estimate α_n and L_mem across training states and resolutions; if they grow, develop adaptive analyses or alternative guarantees.
5. **Fixed cutoff and linear-Gaussian tail surrogate**: The theory assumes a fixed dyadic spectral cutoff J and linear-Gaussian tail dynamics (Eq. 7). Unresolved if this captures essential memory for complex subgrid physics which may be nonlinear and non-Gaussian. Resolution: compare learned memory against nonlinear summaries; test adaptive cutoff schemes; evaluate gains with more realistic tail models.

## Limitations
- Tail surrogate realism: The linear-Gaussian assumption for unresolved scales may fail in shocked or strongly nonlinear regimes, potentially limiting gains or causing instability.
- Memory capacity and horizon scaling: The fixed buffer (L=16) and S4 state (dim=64) may be insufficient if the true memory kernel decays slowly, and the stability bounds assume bounded α_n and L_mem which might grow with resolution or rollout length.
- Generalization beyond 2D Euler: All experiments are on 2D compressible Euler; applicability to other PDE families (e.g., incompressible, 3D turbulent) remains unproven.

## Next Checks
1. **Surrogate stress test**: Evaluate MCRF on shocked 2D Euler with higher Mach numbers or on a PDE with known non-Gaussian intermittency (e.g., 2D incompressible vortex merging). Compare tail residuals against linear-Gaussian fit to quantify mismatch.
2. **Memory capacity ablation**: Train variants with buffer lengths L=4, 32, 64 (adjust S4 state) on CE-RM. Measure final-time error vs. rollout horizon (up to 50 steps) and track memory state norm/auto-correlation to test scaling predictions.
3. **Cross-PDE transfer**: Fine-tune only the memory module (freeze backbone) on a different PDE family (e.g., 2D Navier-Stokes) using the same coarse-to-fine schedule. Compare rollout stability to a memoryless baseline to assess generalization.
