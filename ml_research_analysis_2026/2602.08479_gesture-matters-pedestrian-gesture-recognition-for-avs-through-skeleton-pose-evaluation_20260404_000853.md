# Gesture Matters: Pedestrian Gesture Recognition for AVs Through Skeleton Pose Evaluation

## Quick Facts
- **arXiv ID:** 2602.08479
- **Source URL:** https://arxiv.org/abs/2602.08479
- **Reference count:** 33
- **Primary result:** A framework combining static and dynamic skeletal features from 2D pose estimation achieves 87.04% classification accuracy on a four-class pedestrian gesture dataset.

## Executive Summary
This study addresses a critical gap in autonomous vehicle perception: interpreting pedestrian gestures. The authors develop a framework using 2D skeleton pose estimation on real-world pedestrian videos, focusing on four gesture classes (Stop, Go, Thank & Greet, No Gesture). They extract 76 normalized features—both static (pose configuration) and dynamic (movement kinematics)—and train a random forest classifier. The combined feature set significantly outperforms using either static or dynamic features alone, achieving 87.04% accuracy. The analysis identifies hand velocity and hand-to-hand distance as the most discriminative features, substantially improving recognition for the challenging "Stop" class.

## Method Summary
The method uses the WIVW dataset (180 cropped, pedestrian-centric videos, 60 FPS). A 2D pose estimator (MMPose/RTMPose-m) extracts 17 COCO-format keypoints per frame. A torso-based normalization transforms keypoints into a body-centric coordinate system using the mid-hip as the center and average shoulder-hip cross-distances as the scale metric. From these normalized sequences, 71 static features (mean/max positions, pairwise distances) and 5 dynamic features (hand velocity/acceleration, velocity ratio) are computed per video. A random forest classifier is trained on these feature vectors to predict one of four gesture classes, with performance evaluated via accuracy, confusion matrices, t-SNE visualization, and Gini feature importance.

## Key Results
- Combined static and dynamic features yield 87.04% classification accuracy, significantly higher than static-only (83.33%) or dynamic-only (66.67%).
- Hand velocity (especially left hand) and hand-to-hand distance are ranked as the most discriminative features.
- The combined approach increases "Stop" class accuracy from 59% to 71%, reducing confusion with "Thank & Greet."

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Torso-based skeleton normalization improves feature robustness across varying pedestrian postures and viewing angles.
- **Mechanism:** Normalization uses a body-centric coordinate system (mid-hip center, torso size metric) to remove perspective and scale variance, making gesture kinematics comparable across frames and subjects.
- **Core assumption:** Torso dimensions (shoulder-hip cross-distances) remain relatively invariant during gesturing.
- **Evidence anchors:**
  - [section III] Torso size `tst` defined as average of four cross-distances to "reduce variance of bent torsos."
  - [section III] Mid-hip chosen as center because it "rarely changes when pedestrians are gesturing."
  - Corpus: Weak support; neighboring works focus on VLMs and micro-gestures, not this specific normalization.
- **Break condition:** Failure if torso keypoints (shoulders/hips) are consistently occluded or poorly estimated.

### Mechanism 2
- **Claim:** Hybrid static and dynamic skeletal features capture complementary pose and movement signatures essential for distinguishing ambiguous gestures.
- **Mechanism:** Static features encode sustained pose shape; dynamic features encode motion tempo. The combination resolves intra-class ambiguity (e.g., "Stop" vs. "Thank & Greet").
- **Core assumption:** Gesture semantics are encoded in both posture and kinematic profile.
- **Evidence anchors:**
  - [abstract] Combined accuracy 87.04% vs. static 83.33% and dynamic 66.67%.
  - [section IV.A] Static-only confusion between "Stop" and "Thank & Greet" due to similar hand positions.
  - [section IV.B] Dynamic-only clustering poor (silhouette 0.114).
  - [section IV.C] Combined improves "Stop" recall from 59% to 71%, silhouette to 0.239.
- **Break condition:** Failure if gesture classes share nearly identical motion kinematics or frame rate (60 FPS) is insufficient for subtle gestures.

### Mechanism 3
- **Claim:** Hand velocity (especially left hand) and hand-to-hand distance are the most discriminative features for the defined taxonomy.
- **Mechanism:** Random forest Gini importance ranks these features highest. Left-hand prominence attributed to right-hand traffic (near-side signaling); hand-to-hand distance distinguishes bimanual vs. unimanual gestures.
- **Core assumption:** Feature importance scores generalize to underlying causal factors.
- **Evidence anchors:**
  - [section IV.C] Left hand velocity has highest contributing factor; right hand serves as anchor for hand-to-hand distance.
  - [section IV.A] Hand-to-hand distance is second-highest in static ranking.
  - [section I] Taxonomy acknowledges intra-class variation (e.g., "Stop" may involve raised or extended arms).
- **Break condition:** Failure if dataset demographic (e.g., all right-traffic participants) or gesture sampling biases feature importance; no testing of geographical/cultural variations.

## Foundational Learning
- **Concept: 2D Pose Estimation (COCO format)**
  - **Why needed:** The entire pipeline depends on accurate extraction of 17 skeletal keypoints from video frames. MMPose/RTMPose is chosen for robustness.
  - **Quick check:** If the pose estimator misses a wrist keypoint in a frame, how would that impact the calculation of left wrist velocity?
- **Concept: Torso-Centric Normalization**
  - **Why needed:** To achieve pose invariance to camera distance, pedestrian height, and slight torso articulation. Without it, raw pixel coordinates are not comparable across sequences.
  - **Quick check:** What would happen to the normalized coordinate if the pedestrian's torso is twisted relative to the camera, but the mid-hip point is still detectable?
- **Concept: Random Forest Classifier & Gini Importance**
  - **Why needed:** Provides a non-deep-learning baseline with inherent feature explainability. Gini score ranks which normalized features are most useful for splitting classes.
  - **Quick check:** Why might a random forest still struggle to classify "Stop" even with good features, as seen in the static-only confusion matrix?

## Architecture Onboarding
- **Component map:** Input (cropped pedestrian video) -> Pose Estimator (MMPose/RTMPose-m) -> Normalization Module (torso-based) -> Feature Engineering (static & dynamic) -> Classifier (Random Forest) -> Analyzer (t-SNE, Gini importance)
- **Critical path:** Video must first be processed by pose estimation, then normalized, then features extracted per sequence (not per frame), finally classified.
- **Design tradeoffs:**
  - **Static vs. Dynamic features:** Static are robust to noise but ambiguous; dynamic are discriminative but sensitive to FPS and motion continuity.
  - **Random Forest vs. LSTM:** Random Forest offers explainability and works on handcrafted features; LSTM could model long-term dependencies but is a black box and needs more data.
  - **COCO vs. Whole-Body Pose:** Using 17 COCO keypoints ignores face/feet; authors justify focusing on hands/arms. Adding more keypoints might introduce noise.
- **Failure signatures:**
  - **Normalization failure:** Torso keypoints (shoulders/hips) have low confidence scores → unstable scale/center metrics.
  - **Feature extraction failure:** Hand keypoints (wrists) intermittently missing → broken velocity/acceleration calculation.
  - **Classifier failure:** High correlation between static and dynamic features may cause redundant splits, reducing generalizability.
- **First 3 experiments:**
  1. **Pose Quality Audit:** Run MMPose on a stratified sample of 50 videos. Record mean per-keypoint confidence; flag sequences where wrist confidence < 0.8 for >30% of frames.
  2. **Normalization Invariance Test:** For a single "Go" sequence, apply synthetic zoom (1.2x) and pan. Re-run pipeline; check that feature vector changes minimally after normalization vs. drastically without it.
  3. **Ablation Study Replication:** Train three random forests (static-only, dynamic-only, combined) on same train/test split (or 5-fold CV). Verify accuracy gap: Static ~83% < Combined ~87% and Dynamic ~67%. Confirm "Stop" recall jump from 59% to 71%.

## Open Questions the Paper Calls Out
- **Open Question 1:** Can incorporating temporal sequence models (e.g., LSTMs) or frequency-domain features significantly improve classification accuracy beyond 87.04%?  
  *Basis:* Explicitly suggested in conclusion; current framework uses engineered features.  
  *Why unresolved:* No comparative study of deep temporal or spectral features has been conducted.
- **Open Question 2:** How robust is the four-class taxonomy and classifier to inter-cultural variations not in WIVW?  
  *Basis:* Paper acknowledges cross-cultural gesture variation but uses a single dataset likely reflecting a specific demographic.  
  *Why unresolved:* No testing on diverse geographic/cultural data; aggregated classes may hide unseen variations.
- **Open Question 3:** To what extent does torso-based normalization fail under occlusion, unusual clothing, or non-standard orientations?  
  *Basis:* Inferred; normalization relies on clear shoulder/hip keypoints and upright posture.  
  *Why unresolved:* No robustness analysis under real-world perturbations like partial occlusion or baggy clothing.
- **Open Question 4:** Does adding gesture duration as a feature effectively separate "Go" and "Thank & Greet"?  
  *Basis:* Authors suggest duration to resolve t-SNE overlap but did not test it; Fig. 2 shows similar duration distributions for these classes.  
  *Why unresolved:* Unclear if duration alone provides statistically meaningful separation; not implemented or validated.
- **Open Question 5:** What specific kinematic signatures beyond hand velocity and hand-to-hand distance are critical for disambiguating "Stop" from "Thank & Greet"?  
  *Basis:* Inferred; combined model still confuses 29% of "Stop" as "Thank & Greet."  
  *Why unresolved:* No error analysis on misclassified "Stop" instances to identify missing discriminative cues (e.g., acceleration patterns, joint angle variance).

## Limitations
- Missing critical implementation details: random forest hyperparameters, exact gesture-positive frame trimming algorithm, and train/test split strategy hinder faithful replication.
- Dataset constraints: WIVW (180 videos) is small and may have subject leakage; geographic/cultural bias unaddressed (e.g., left-hand importance assumes right-hand traffic).
- Feature robustness risks: Torso-based normalization depends on reliable shoulder/hip keypoints; dynamic features sensitive to frame rate and gesture boundary accuracy.

## Confidence
- **Claim 1 (Combined feature set yields 87.04% accuracy):** High confidence. Directly supported by reported results and ablation data.
- **Claim 2 (Torso-centric normalization improves robustness):** Medium confidence. Mechanistically plausible and partially evidenced by design, but no explicit invariance experiment.
- **Claim 3 (Hand velocity & hand-to-hand distance are most discriminative):** Medium confidence. Supported by Gini importance on this dataset, but generalizability uncertain due to dataset-specific biases.
