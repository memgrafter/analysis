# MedInjection-FR: Exploring the Role of Native, Synthetic, and Translated Data in Biomedical Instruction Tuning
## Quick Facts
- arXiv ID: 2603.06905
- Source URL: https://arxiv.org/abs/2603.06905
- Reference count: 0
- Primary result: Native data yields strongest performance (41.29 EM); native+translated combination provides complementary gains; synthetic data benefits when balanced with native but alone is weak.

## Executive Summary
The paper tackles the scarcity of high-quality French biomedical instruction data for tuning large language models. It introduces MedInjection-FR, a dataset of 571K instruction-response pairs curated from native French medical resources, synthetic generation, and translated English biomedical data. Using Qwen-4B-Instruct fine-tuned under seven controlled configurations, the study finds that native data alone achieves the best results on multiple-choice QA (up to 41.29 Exact Match). Combining native with translated data yields complementary benefits, while synthetic data alone performs poorly but can add value when mixed with native data. For open-ended QA, evaluation using the LLM-as-a-judge approach (with MedGemma-27B) shows the best correlation with human ratings (Pearson r=0.61), though the judge exhibits sensitivity to response verbosity. The findings demonstrate that data authenticity and diversity jointly improve model adaptation in low-resource biomedical domains.

## Method Summary
The authors assembled MedInjection-FR, a large-scale French biomedical instruction dataset comprising 571,436 examples from three sources: native (authentic French medical materials), synthetic (LLM-generated from French clinical abstracts), and translated (high-quality English biomedical datasets rendered into French). To control for data volume, each training configuration used exactly 33,493 examples: single-source (native, synthetic, translated) and mixed (native+translated, native+synthetic, translated+synthetic, all). The base model (Qwen-4B-Instruct, 4B parameters) was fine-tuned with DoRA (low-rank adaptation) for 10 epochs using standard hyperparameters (LR 1e-4, batch size 12, gradient accumulation 8). Performance was evaluated on multiple-choice questions (MCQ/MCQU) using Exact Match and Hamming scores, and on open-ended questions (OEQ) via automatic metrics (BLEU, ROUGE, etc.) and an LLM judge (MedGemma-27B) for binary equivalence. The study systematically compared the effect of data origin on model adaptation to French biomedical tasks.

## Key Results
- Native data alone yields the strongest MCQ performance (up to 41.29 Exact Match).
- Combining native with translated data provides complementary benefits, achieving the highest overall accuracy.
- Synthetic data alone is less effective, but can contribute positively when balanced with native supervision.
- For open-ended QA, MedGemma-27B as judge correlates best with human ratings (Pearson r=0.61), but shows sensitivity to response verbosity.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Native French biomedical data provides the strongest linguistic and domain alignment for instruction tuning.
- **Mechanism:** Native data originates from authentic French medical resources (e.g., exams, textbooks), embedding culturally specific terminology, phrasing conventions, and clinical reasoning patterns. This reduces linguistic noise and aligns the model's output distribution with the target distribution of French medical discourse.
- **Core assumption:** The authenticity of language use in native data creates a more deterministic learning signal for domain-specific instruction following compared to translated or generated text.
- **Evidence anchors:**
  - [abstract] "native data yield the strongest performance... Combining native with translated data provides complementary benefits."
  - [section 5.1] "Models fine-tuned on native data (QWEN-4B-NAT) achieve the largest improvement... underscoring the importance of linguistic alignment."
  - [section 3.2] Details the curation from French medical exams and resources.
- **Break condition:** If native data is extremely scarce (<10K examples), the benefit plateaus and combination with other sources becomes necessary for robust performance.

### Mechanism 2
- **Claim:** Combining native with translated data yields complementary benefits by enhancing conceptual diversity while preserving linguistic alignment.
- **Mechanism:** Translated data (from high-quality English biomedical datasets) introduces broader medical concepts and question formulations. When combined with native data, it exposes the model to a wider range of medical reasoning patterns without sacrificing French linguistic coherence, as the native component anchors the learning.
- **Core assumption:** The semantic neighborhoods of native and translated instructions overlap sufficiently (as suggested by t-SNE visualization) to allow joint learning, while their differences add beneficial diversity.
- **Evidence anchors:**
  - [abstract] "Combining native with translated data provides complementary benefits."
  - [section 5.1] "NAT-TRAD configuration achieves the highest overall accuracy... confirming the strong complementarity."
  - [section 4.1] t-SNE visualization shows "native and translated instructions exhibit strong local mixing."
- **Break condition:** If the translated data introduces significant translation artifacts or domain drift (e.g., from non-biomedical English sources), the combination may degrade performance relative to native-only.

### Mechanism 3
- **Claim:** Synthetic data alone is less effective due to factual and stylistic noise but can contribute positively when balanced with native supervision.
- **Mechanism:** Synthetic data (LLM-generated from French clinical abstracts/cases) expands task diversity but introduces generation errors, hallucination risks, and non-native phrasing. When mixed with high-quality native data, it acts as a regularizer, exposing the model to varied task structures while native data provides a factual grounding to filter noise.
- **Core assumption:** The noise in synthetic data is diverse and systematic, which can be mitigated by a majority of authentic supervision signals.
- **Evidence anchors:**
  - [abstract] "Synthetic data alone remains less effective but can help when balanced with native supervision."
  - [section 5.1] "QWEN-4B-SYN yields the weakest results... NAT-SYN configuration also yields competitive results."
  - [section 3.4] LLM-based quality scores show "variability across tasks and response types," indicating residual noise.
- **Break condition:** If the synthetic generation pipeline is of very low quality (e.g., <50% high-quality ratings in pilot evaluation) or if its proportion exceeds native data by a large margin (>2:1), the negative impact outweighs benefits.

## Foundational Learning
- **Concept:** Instruction Tuning for Domain Adaptation
  - *Why needed here:* The paper assumes SFT with (instruction, response) pairs is necessary to adapt a pretrained multilingual LLM (Qwen-4B-Instruct) to follow French medical prompts, as continued pretraining alone may degrade instruction-following behavior.
  - *Quick check question:* Why might continued pretraining on French biomedical text fail to improve instruction-following, necessitating SFT?

- **Concept:** Data Provenance and Its Impact on Learning Signal
  - *Why needed here:* The core experimental manipulation is data source (native, synthetic, translated). Understanding how origin affects semantic fidelity, linguistic authenticity, and noise is critical to interpreting performance differences.
  - *Quick check question:* What are two specific ways translated data might differ from native data beyond surface language?

- **Concept:** Evaluation Metric Selection for Biomedical QA
  - *Why needed here:* The choice between Exact Match, Hamming score, and LLM-as-a-judge significantly impacts perceived model performance, especially for open-ended QA where lexical overlap is insufficient.
  - *Quick check question:* Why does a high BLEU score not necessarily indicate a medically accurate answer?

## Architecture Onboarding
- **Component map:** Dataset -> Model (Qwen-4B-Instruct + DoRA adapters) -> SFT Training (10 epochs, LR 1e-4, gradient accumulation 8) -> Evaluation (MCQ: EM/Hamming with permutation; OEQ: auto metrics + MedGemma judge) -> Analysis (t-SNE, correlation, length bias)
- **Critical path:** Data curation & split → Build 7 configs (NAT, TRAD, SYN, NAT-TRAD, NAT-SYN, TRAD-SYN, ALL) → Fine-tune Qwen-4B-Instruct with DoRA per config → Evaluate on MCQ/MCQU (greedy & constrained, with 3 randomized answer permutations) → Evaluate OEQ (auto metrics + MedGemma-27B judge) → Compare config performances → Analyze failure modes (verbosity, position bias)
- **Design tradeoffs:**
  - *Controlled sample size vs. scale:* All configs fixed at 33,493 examples to isolate provenance effect; this limits studying scale interactions with source quality.
  - *Multiple-choice vs. open-ended evaluation:* MCQ provides clean EM but may not reflect real-world reasoning; OEQ is realistic but relies on imperfect LLM judges.
  - *Single model vs. generalization:* Using only Qwen-4B-Instruct limits conclusions about model-size or architecture sensitivity.
- **Failure signatures:**
  1. **Position bias:** Large EM drop under answer permutation (Table 7) indicates the model learns positional shortcuts rather than pure medical reasoning.
  2. **Verbosity inflation:** Base model's higher LLM-judge score correlates with 28x longer outputs (Figure 6), suggesting judge sensitivity to length over conciseness.
  3. **Synthetic degradation:** SYN-only config underperforms consistently across MCQ and OEQ, signaling generation quality issues that may propagate if not filtered.
- **First 3 experiments:**
  1. **Ablation test:** Train NAT, TRAD, SYN separately. Expect NAT > TRAD > SYN in MCQ constrained EM. Confirms native primacy.
  2. **Complementarity test:** Train NAT-TRAD and NAT-SYN. Expect NAT-TRAD to match or beat NAT, showing translated data adds value without harming alignment.
  3. **Judge calibration:** Run OEQ evaluation with 5 LLM judges + human on 100 samples. Expect MedGemma-27B (domain expert) to correlate best (r=0.61), validating its use as judge.

## Open Questions the Paper Calls Out
#### Open Question 1
- **Question:** To what extent can synthetic and translated French biomedical instructions substitute or complement native data for effective LLM fine-tuning?
- **Basis:** Explicit in Introduction and Section 4.1, where the authors directly pose how different data sources impact performance and whether combinations yield benefits.
- **Why unresolved:** Native data yields the strongest results, but mixed setups (e.g., native+translated) are competitive even with less native data. The precise contribution of each source and the minimum viable native proportion remain unclear.
- **What evidence would resolve it:** Systematic ablation varying the ratio of native to synthetic/translated data while keeping total examples constant, combined with analysis of topic distribution overlap (e.g., via embedding similarity) to isolate linguistic vs. content effects.

#### Open Question 2
- **Question:** Does quality-controlled filtering of synthetic instruction data improve its effectiveness in biomedical instruction tuning?
- **Basis:** Inferred from Section 8 (limitations): synthetic data were not filtered by LLM-evaluated quality scores before fine-tuning, leaving open whether low-quality examples harm performance.
- **Why unresolved:** Synthetic-only models underperform, but it is unknown if all synthetic examples contribute equally or if only a high-quality subset is useful when combined with native data.
- **What evidence would resolve it:** Fine-tune models on synthetic subsets stratified by quality scores (e.g., top 25% vs. bottom 25% per LLM judge), then measure performance differences on biomedical QA benchmarks to quantify the impact of synthetic data quality.

#### Open Question 3
- **Question:** Do findings on data provenance generalize to larger or differently pre-trained LLMs beyond Qwen-4B-Instruct?
- **Basis:** Inferred from Section 8: experiments were limited to a single 4B-parameter multilingual model, raising questions about scalability and architectural dependence.
- **Why unresolved:** Model scale and pre-training distribution may affect how models leverage non-native or synthetic data (e.g., larger models might better handle translation artifacts or generate more coherently from synthetic prompts).
- **What evidence would resolve it:** Replicate the seven training configurations using models of varying sizes (e.g., 7B, 70B) and pre-training backgrounds (e.g., English-centric vs. multilingual), then compare performance trends to those observed with Qwen-4B.

## Limitations
- Dataset provenance details (exact upstream source mappings, translation generation parameters) are not fully disclosed, blocking perfect recreation.
- The open-ended evaluation relies on a single LLM judge (MedGemma-27B) with noted verbosity bias, making absolute scores less trustworthy.
- Findings are specific to Qwen-4B-Instruct; generalizability to other model architectures and scales remains unknown.

## Confidence
- **Native data primacy**: Medium
- **Native+translated complementarity**: High
- **Synthetic data utility**: Medium
