# Logi-PAR: Logic-Infused Patient Activity Recognition via Differentiable Rule
## Quick Facts
- **arXiv ID**: 2603.05184
- **Source URL**: https://arxiv.org/abs/2603.05184
- **Reference count**: 10
- **Primary result**: SOTA on VAST (91.8% F1, 0.96 AUC, 4.8% false alarm) and OmniFall (89.4% CGS, 93.1% mAP) with interpretable rule-based reasoning.

## Executive Summary
Logi-PAR is a neuro-symbolic framework for patient activity recognition that addresses the brittleness of existing models by combining multi‑view visual perception with differentiable logic rules. It extracts atomic facts (e.g., `rail_down`, `edge_sit`) from synchronized camera feeds using an uncertainty‑aware fusion mechanism, then composes them via a sparse set of learned, human‑interpretable rules to infer risk states. The system produces auditable explanations through rule activation traces and counterfactual interventions. Evaluations on the VAST and OmniFall benchmarks demonstrate state‑of‑the‑art performance while maintaining clinically relevant interpretability.

## Method Summary
Logi-PAR comprises three modules. (1) **Multi‑view perception**: A Swin‑Transformer backbone processes images from V cameras. For each view, two heads predict atomic fact logits and a reliability score. Facts are fused across views by weighting logits with reliability‑derived attribution weights, yielding robust fact confidences. (2) **Differentiable logic layer**: A set of M rules is induced during training. Each rule uses a Gumbel‑Softmax selection matrix to choose literals and a learned negation gate to optionally invert a fact’s truth. Literal truth values (based on the fact confidences) are combined via a T‑norm (product) for the rule’s conjunction, and final state probabilities are a weighted sum of rule strengths. (3) **Explanation generation**: After training, discrete rules are extracted via thresholding, and counterfactual explanations are produced by solving a minimal L1‑perturbation problem over the fact vector to find the smallest change that flips the predicted risk. Training uses a two‑phase curriculum: first warm‑up the perception module with fact supervision (if available), then end‑to‑end fine‑tuning with a total loss combining risk cross‑entropy, fact grounding, and sparsity regularization.

## Key Results
- **VAST**: 91.8% F1‑score, 0.96 AUC, 4.8% false alarm rate.
- **OmniFall**: 89.4% Compositional Generalization Score (CGS), 93.1% mAP.
- Outperforms Vision‑Language Models and transformer baselines by significant margins.

## Why This Works (Mechanism)
**Multi‑View Fact Fusion via Uncertainty‑Aware Logit Pooling**  
The mechanism dynamically weights evidence from each camera view based on learned reliability scores. For a given atomic fact, per‑view logits are combined using a softmax over reliability scores, producing a fact confidence that discounts poor‐quality or occluded views. Core assumption: visibility of a specific fact (e.g., bed rail state) varies across views, and this variation is predictable from the feature representation. Evidence: Section 4.2 describes reliability‑weighted fusion; ablations show that removing reliability weighting degrades performance.

**Neural‑Guided Differentiable Logic Rule Induction**  
Rules are induced by learning, per rule, which facts to include (selection matrix Γ) and whether to use their presence or absence (negation gate η). Gumbel‑Softmax enables differentiable sampling of discrete selections. Rule strength is the product (T‑norm) of its literal truth values; final prediction is a weighted disjunction of all rule strengths. This yields a sparse set of interpretable soft‑logic rules that can generalize to unseen fact combinations. Core assumption: clinically meaningful risk states are Boolean compositions of a small number of atomic facts. Evidence: Ablating this component drops CGS from 89.4% to 65.0% (Section 5.7), proving its necessity for compositional generalization.

**Counterfactual Sensitivity Analysis for Causal Explanations**  
For a high‑risk prediction, the system solves a constrained L1‑minimization to find the minimal binary perturbation to the fact confidence vector that changes the argmax risk class. The resulting perturbation vector δ identifies the pivotal facts whose alteration would negate the risk, providing a minimal and actionable explanation. Core assumption: A factual explanation corresponds to the smallest set of atomic changes that would flip the decision. Evidence: The paper reports a counterfactual validity metric and describes the optimization in Section 4.4.

## Foundational Learning
- **Differentiable Logic & Fuzzy Operators**  
  *Why needed*: Soft approximations (product for AND, weighted sum for OR, Gumbel‑Softmax for selection) allow gradients to flow through discrete rule structures, enabling end‑to‑end learning.  
  *Quick check*: Why can’t standard hard Boolean logic be used directly? The trade‑off is that T‑norms provide smooth gradients but yield soft thresholds, not crisp logical evaluations.

- **Multi‑View Sensor Fusion**  
  *Why needed*: Clinical environments contain occlusions; no single camera reliably sees all cues. Combining multiple views into a unified representation is essential for robustness.  
  *Quick check*: How does view attribution weight differ from a simple average? If the reliability predictor is uncalibrated, fusion may erroneously discount good views or overweight bad ones, harming fact confidence estimates.

- **Neuro‑Symbolic Rule Sparsity**  
  *Why needed*: Interpretability requires a compact rule set with few literals. L1 regularization on selection distributions and rule weights forces parsimony.  
  *Quick check*: What happens if the sparsity coefficient (λ_s) is set to zero? The model learns many redundant rules (Figure 3), sacrificing interpretability.

## Architecture Onboarding
**Component map**: Multi‑view Images → Shared Swin‑B Backbone → Per‑View Prediction Heads (fact logits & reliability) → Fact Fusion (reliability‑weighted pooling) → Fused Fact Confidence Vector → Differentiable Logic Layer (rule selection, negation, conjunctions) → State Classifier → Final Risk State + Rule Trace + Counterfactual Explanation.

**Critical path**: The pivotal symbolic interface is the fused fact vector *c*, which bridges visual perception and logical reasoning.

**Design tradeoffs**:
- *Rule capacity vs. Interpretability*: More literals per rule can capture complex states but obscure reasoning; sparsity loss trades accuracy for clarity.
- *Fusion complexity vs. Robustness*: Simple averaging is faster but vulnerable to occluded views; reliability prediction adds parameters but is essential for occlusion robustness.
- *Differentiability vs. Discrete Logic*: Fuzzy operators enable learning but mean rules are soft thresholds; final rule extraction is a post‑training discretization.

**Failure signatures**:
- High False Alarm Rate: Often from insufficient causal constraints or unreliable fact fusion; monitor uniformity of view attribution weights.
- Rule explosion: Active rules > 10 per class indicate sparsity λ_s too low.
- Poor Compositional Generalization (low CGS): Indicates overfitting to training fact co‑occurrences; test on held‑out fact combinations.
- Inconsistent multi‑view outputs: High entropy in view attribution weights suggests the reliability head is not learning useful signals.

**First 3 experiments**:
1. *Atomic Fact Probe*: Isolate perception module ϕ. Train only with fact annotations (if available) and evaluate per‑fact mAP on a held‑out set to validate that *c* is a reliable symbol grounder.
2. *Rule Extraction Validation*: After full training, extract discrete rules and have clinical experts assess them for meaningfulness, logical soundness, and completeness.
3. *Counterfactual Robustness Test*: For high‑risk predictions, intervene by flipping the fact with the highest counterfactual δ. Verify that the prediction becomes low‑risk and that the flipped fact is clinically plausible.

## Open Questions the Paper Calls Out
1. **Clinical knowledge alignment**: Automatically learned rules have not been vetted by medical experts. Without clinical validation, rules may capture spurious correlations, limiting trust and adoption.
2. **Atomic fact coverage**: The predefined predicate set (e.g., `rail_down`, `edge_sit`) may omit clinically relevant cues. The selection process is opaque, potentially hindering generalization across settings.
3. **Weak supervision performance**: The framework expects atomic fact annotations for training, but VAST has only implicit labels. The mechanism for learning facts under weak supervision is unclear.
4. **Logic semantics impact**: The choice of T‑norm for fuzzy conjunction is not justified relative to other neuro‑symbolic frameworks (e.g., probabilistic or Boolean). Its effect on interpretability and robustness is unknown.
5. **Clinical utility of counterfactuals**: Quantitative metrics like CF@val do not guarantee that explanations lead to correct clinical actions, reduced alarm fatigue, or improved trust; no user studies exist.

## Limitations
- **Hyperparameter underspecification**: Values for λ_f, λ_s schedule, number of rules M, literals per rule L, and pruning thresholds are not provided; manual tuning required.
- **Reliability head design**: Architecture of h_rel and handling of weak supervision for fact grounding on VAST are not detailed.
- **Break conditions**: System may fail if reliability predictor miscalibrates under domain shift, if sparsity regularization is mis‑set, or if counterfactual optimization cannot find minimal perturbations near decision boundaries.
- **Limited external validation**: Results are only on VAST and OmniFall; generalizability to other clinical settings remains unproven.

- Neural‑Guided Rule Induction: Medium‑High

## Next Checks
1. **Reliability predictor calibration**: On a held‑out set with known fact visibility, compute correlation between view attribution weights and ground‑truth visibility; target Pearson’s r > 0.7.
2. **Rule sparsity sensitivity**: Systematically vary λ_s and maximum literals L on OmniFall; measure active rule count, CGS, and expert‑rated interpretability (scale 1‑5). Target: < 8 active rules per class with < 5% CGS drop.
3. **Counterfactual clinical plausibility**: For 100 high‑risk predictions, have clinicians rate the suggested minimal interventions for realism and usefulness; target > 80% rated “plausible and useful.”
