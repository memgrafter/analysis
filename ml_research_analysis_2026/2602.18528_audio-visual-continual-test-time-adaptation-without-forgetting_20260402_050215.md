# Audio-Visual Continual Test-Time Adaptation without Forgetting

## Quick Facts
- **arXiv ID:** 2602.18528  
- **Source URL:** https://arxiv.org/abs/2602.18528  
- **Reference count:** 40  
- **Primary result:** AV-CTTA achieves state-of-the-art mean accuracy (50.29% on Kinetics50-2C, 43.51% on VGGSound-2C) with limited forgetting (2.9% vs. 27.9% for READ).

## Executive Summary
AV-CTTA presents a method for continual test-time adaptation (CTTA) in audio-visual models without access to source data. The approach targets the attention fusion layer of a transformer-based architecture, storing its parameters along with simple modality statistics in a buffer. At test time, a novel retrieval mechanism selects the most relevant stored parameters using KL divergence between current input statistics and stored Gaussian models. Retrieved parameters are briefly adapted via READ losses and smoothed with exponential moving averages. A buffer management strategy merges redundant elements to keep memory bounded. Extensive experiments on corrupted Kinetics50 and VGGSound show AV-CTTA significantly outperforms prior CTTA methods while mitigating catastrophic forgetting.

## Method Summary
The source model is CAV-MAE, a pretrained audio-visual transformer. Only the Query/Key/Value projection matrices of its joint encoder (the fusion layer) are adapted during test time. For each incoming batch, the method computes channel-wise mean and variance of audio and visual inputs, modeling each modality as a Gaussian. The buffer stores tuples of these statistics and the corresponding fusion parameters. If the buffer is non-empty, the algorithm retrieves the buffer element whose statistics minimize the summed KL divergences to the current batch statistics, provided the minimum distance is below a threshold τ. When retrieval occurs, the retrieved fusion parameters are plugged into the joint encoder, the model processes the batch, and the READ loss (confidence + negative entropy) is backpropagated to update only those parameters. After adaptation, the selected buffer element’s parameters and statistics are updated via an exponential moving average (EMA). If no relevant element is found, the current parameters and statistics are added as a new buffer entry. To bound memory, when the buffer size exceeds a limit η, the two most statistically similar elements are merged by averaging their parameters and statistics.

## Key Results
- Mean accuracy: 50.29% on Kinetics50-2C and 43.51% on VGGSound-2C, beating READ (42.01%, 29.74%) by large margins.
- Forgetting: only a 2.9% drop on VGGSound-2C compared to READ’s 27.9% degradation.
- AV-CTTA consistently outperforms all baselines across unimodal and bimodal corruption settings while using bounded memory.

## Why This Works (Mechanism)
### Mechanism 1: Fusion layer parameters transfer across related domains
- **Claim:** Adapting only the attention fusion layer to a target domain improves performance not only on that domain but also on subsequent ones.
- **Mechanism:** Updates to WQ, WK, WV capture domain-invariant cross-modal correlations that generalize within a corruption category and sometimes across categories.
- **Break condition:** Transferability may degrade if the first domain is highly atypical or adaptation overfits.

### Mechanism 2: Selective parameter retrieval via Gaussian KL
- **Claim:** The model reuses past fusion parameters by matching current input statistics (channel-wise means and variances) to stored statistics using KL divergence, enabling data-free knowledge retrieval.
- **Mechanism:** For a batch, compute Gaussian N(µ_t^v, Σ_t^v) and N(µ_t^a, Σ_t^a). Compute KL to each buffer element’s stored Gaussians. If the smallest total distance < τ, retrieve the corresponding parameters. Adapt them with READ losses and EMA-update.
- **Break condition:** Noisy statistics (very small batches) or extreme corruption may lead to irrelevant retrievals.

### Mechanism 3: Bounded buffer via statistical merging
- **Claim:** The buffer size is kept bounded by merging statistically similar elements, preserving diversity without unbounded growth.
- **Mechanism:** When buffer size reaches η, find the pair with the smallest KL divergence between their stored statistics. Merge them by averaging their parameters and statistics, freeing a slot.
- **Break condition:** Aggressive merging might collapse distinct domain knowledge; if all elements become too similar, coverage is lost.

## Architecture Onboarding
**Component map:**  
Audio Encoder -> Visual Encoder -> Joint Encoder (Fusion Layer) -> Classifier;  
Buffer <-> Retrieval -> Fusion Parameters;  
Adaptation (READ loss) updates Fusion Parameters;  
EMA updates Fusion Parameters and Buffer Statistics;  
Buffer Manager adds/merges Buffer elements.

**Critical path:**
1. Compute batch statistics (means, variances) for audio and visual inputs.
2. If buffer non-empty, compute KL distances to all stored statistics; if minimum < τ, retrieve corresponding fusion parameters.
3. Forward pass with retrieved (or current) fusion weights, compute READ loss.
4. Backpropagate one Adam step (lr=1e-4) to update only WQ,WK,WV.
5. EMA-update the retrieved buffer element’s parameters and statistics (β=0.99).
6. If no retrieval occurred, add current parameters and statistics as a new buffer element.
7. If buffer size > η, merge the two most similar elements by averaging their parameters and statistics.

**Design tradeoffs:**
- Adapting only the fusion layer protects earlier knowledge but may not handle modality-specific corruption.
- Buffer size η trades off memory consumption against coverage of domain shifts.
- Threshold τ balances retrieval precision and recall; setting it is corruption-dependent.
- Gaussian statistics are cheap but may miss higher-order distribution changes.
- EMA factor β: larger values stabilize knowledge but slow adaptation to new domains.

**Failure signatures:**
- High forgetting on earlier tasks suggests buffer too small or merging too aggressive.
- Low accuracy across all tasks indicates τ is poorly set (either too high causing irrelevant retrievals or too low forcing frequent additions).
- Performance drops sharply with small batch sizes (e.g., <16) indicate noisy statistics; consider robust statistics or adjusting τ.
- If task order is highly dissimilar, early merging might discard useful distinct knowledge.

**First 3 experiments:**
1. Test transferability of fusion parameters by adapting on the first domain of a category and evaluating on remaining domains; expect improvement over source model.
2. Run full AV-CTTA on Kinetics50-2C and compare task-wise accuracies and forgetting to READ; expect higher mean and lower forgetting.
3. Perform buffer size ablation on VGGSound-2C: vary η (e.g., 10, 50, 100, ∞), plot mean accuracy and forgetting; observe stability across a range and diminishing returns for large η.

## Open Questions the Paper Calls Out

- How can the Gaussian statistics be enhanced to capture more complex distribution shifts without excessive computational overhead?

## Limitations
- Exact corruption implementations and task orders for VGGSound-2C are not fully disclosed, hindering exact replication.
- The CAV-MAE checkpoint (epoch, fine-tuning details) is unspecified; mismatched weights may affect results.
- Gaussian statistics may be insufficient for complex corruptions; richer descriptors could improve retrieval but increase cost.
- Buffer merging’s impact on the memory–accuracy trade-off was not thoroughly explored (main results used unlimited buffer).
- Evaluation is limited to synthetic severity‑5 corruptions on two datasets; real-world applicability remains untested.
