# Qiana: A First-Order Formalism to Quantify over Contexts and Formulas with Temporality

## Quick Facts
- **arXiv ID:** 2604.01952
- **Source URL:** https://arxiv.org/abs/2604.01952
- **Reference count:** 0
- **Primary result:** Qiana is a first-order logic with quoting and context predicates that is finitely axiomatizable (O(|Σ|²)) and compatible with automated theorem provers, successfully modeling event calculus and modal logics (K, T, S4, S5, D) and proving a Romeo and Juliet scenario in 0.05 seconds with Vampire.

## Executive Summary
Qiana is a first-order logic formalism designed to reason about contexts and quoted formulas with temporal aspects. It introduces a quoting function (∼) to reify formulas as first-order terms and an escape operator (Q) to nest quotations. Truth in a specific context is expressed via the `ist` predicate, while real-world truth uses `T`. Axiom schemas A1–A11 provide logical properties for these predicates. A key innovation is a finite axiomatization technique that translates any finite Qiana theory into an equisatisfiable standard first-order theory of size quadratic in the signature, enabling use with existing automated theorem provers. The authors demonstrate Qiana’s expressiveness by encoding event calculus and various modal logics, and provide a Python implementation that outputs TPTP files. In a proof-of-concept, Vampire proves a complex Romeo and Juliet scenario in 0.05 seconds on an 8th‑gen Intel laptop.

## Method Summary
The core method is a two‑phase translation. First, a Qiana theory (with `ist`, `T`, quoting, and context quantification) is extended with new utility symbols (`Sub`, `E`, `Wft`, `Term`) and a finite set of axioms (A12–A34) that capture substitution, evaluation, and well‑formedness. Second, the infinite axiom schemas for truth (A1–A4) and context quantification (A11) are replaced by finite counterparts (A1ᶠⁱⁿ–A4ᶠⁱⁿ, A11ᶠⁱⁿ) that restrict quantification to well‑formed terms and use the utility symbols. This yields a finite first‑order theory Bᶠⁱⁿ⁺ that is equisatisfiable with the original Qiana closure B^Δ (Theorem 1) and has size O(|Σ|²) (Proposition 6). The process is implemented in a Python tool that parses Qiana input, generates the finite theory, and exports it in TPTP format for downstream automated theorem proving.

## Key Results
- Qiana meets all four desiderata: truth representation, formula quantification, context quantification, and semi‑decidability.
- Any finite Qiana theory can be translated into a first‑order theory of size O(|Σ|²).
- The Python implementation successfully translates and Vampire proves the Romeo and Juliet scenario (both protagonists die) in ~0.05 seconds on commodity hardware.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Quoting and unquoting with escape operator Q enables formula reification and nested contexts without resorting to higher‑order logic.
**Mechanism:** The quotation function ∼ maps quotable formulas (Lε) to first‑order terms; Q allows nesting by turning a value into a quotation. Unquote ∼⁻¹ reverses on well‑formed quotations. The restriction Lε excludes the truth predicate T, avoiding Tarski’s paradox.
**Evidence:** Abstract mentions quoting function and Q for nesting; Section 4 defines ∼, Q, and Lε; Proposition 3 shows inconsistency if T is quoted.

### Mechanism 2
**Claim:** Axioms A1–A11 govern truth predicates T and ist, providing truth representation and context quantification while avoiding logical omniscience.
**Mechanism:** A1–A4 define T on quoted formulas by linking T(∼φ) ↔ φ via unquoting. A5–A10 give ist properties like modus ponens and quantifier distribution. A11 enables universal instantiation inside contexts using substitution with Q.
**Evidence:** Section 5 presents axioms; Proposition 4 shows A1–A4 imply the intended truth schema; abstract states A1–A11 provide logical properties.

### Mechanism 3
**Claim:** Finite axiomatization via utility symbols and finite schema counterparts ensures ATP compatibility and semi‑decidability for finite theories.
**Mechanism:** For a finite theory B, augment the signature with `Sub`, `E`, `Wft`, `Term`. Add helper axioms (A12–A34) to define substitution, evaluation, and well‑formedness. Replace infinite schemas A1–A4 and A11 with finite versions (A1ᶠⁱⁿ–A4ᶠⁱⁿ, A11ᶠⁱⁿ) that operate on `Wft` terms. The resulting Bᶠⁱⁿ⁺ is equisatisfiable with B^Δ and has size O(|Σ|²).
**Evidence:** Section 7 details the construction; Theorem 1 proves equisatisfiability; Proposition 6 gives the cardinality bound; abstract highlights finite axiomatization for ATP compatibility.

## Architecture Onboarding
- **Component map:** Parser -> Signature augmenter -> Quoting engine -> Finite axiomatizer -> TPTP exporter -> ATP wrapper -> Result interpreter.
- **Critical path:** Input Qiana theory -> parse -> identify necessary quoted formulas -> generate finite axioms -> export TPTP -> run ATP -> interpret result. ATP solving is the heaviest step; finite axiomatization is polynomial in |Σ|².
- **Design tradeoffs:** Untyped vs. typed Qiana (typed adds safety but complicates axiomatization); handling infinite signatures (requires restricting to a finite subset); ATP choice (Vampire works but other provers may need tweaks).
- **Failure signatures:** Inconsistent input (ATP reports unsatisfiable); non‑quotable elements (quoting T is rejected); ATP non‑termination (semi‑decidable); finite axiomatization bugs (breaks equisatisfiability).
- **First 3 experiments:**  
  1. *Romeo and Juliet:* Encode hypotheses (1)–(25) and verify both protagonists die. Expected: Vampire proves `dead(Romeo)` and `dead(Juliet)` in ~0.05 s.  
  2. *Paraconsistency check:* Encode contradictory beliefs in a context and verify it does not believe arbitrary formulas like `alive(Elvis)`. Expected: ATP does not derive `ist(believes(Romeo), alive(Elvis))`.  
  3. *Modal logic D:* Encode premises □(A∨B), □(A→C), □(B→C) and prove ◊C. Expected: ATP proves `◇C` using Qiana’s D axioms.

## Limitations
- The quoting restriction Lε (excluding T) limits expressiveness; augmenting signatures with `Q` or `∼` can cause clashes.
- Finite axiomatization scalability is theoretical (O(|Σ|²)); constant factors and performance on large, nested scenarios are unvalidated.
- Empirical validation is minimal (only Romeo & Juliet); broader claims about modal logics and event calculus lack benchmarking.

## Confidence
- *Core formalism (quoting, axioms A1–A11):* Medium – sound under Lε restriction, but broader adequacy relies on limited examples.
- *Finite axiomatization (Theorem 1, Proposition 6):* High – rigorous proofs guarantee polynomial‑size translation for finite signatures.
- *Practical viability (Python tool + Vampire):* Medium – one benchmark; performance on larger inputs unknown.
