# Discovering Data Manifold Geometry via Non-Contracting Flows

## Quick Facts
- **arXiv ID**: 2602.02611  
- **Source URL**: https://arxiv.org/abs/2602.02611  
- **Reference count**: 40  
- **Primary result**: A method to learn global coordinate systems on unknown data manifolds without assuming flatness, by using non-contracting flows and commutativity to ensure scalability, achieving accurate tangent field alignment on synthetic manifolds and competitive classification on CIFAR-10 albeit with high computational cost.

## Executive Summary
This paper addresses the unsupervised construction of global coordinate charts for data lying on a smooth unknown manifold embedded in Euclidean space. The key idea is to learn a set of smooth vector fields whose flows transport all data points to a common reference point. The arc‑lengths traveled along each field become the coordinates. To avoid trivial collapse to the reference, the authors impose a non‑shrinking condition: the Lie derivative of a conformal Euclidean metric along each field is positive semidefinite. Commutativity of the fields is enforced, which allows the composition of flows to be represented as a single autonomous ODE, enabling a flow‑matching objective that avoids numerical integration. Theoretically, when the manifold admits a global chart and the number of fields matches its intrinsic dimension, the method recovers the true coordinates; if fewer fields are used, the loss is bounded away from zero. Empirically, on synthetic 2‑D manifolds (sphere, torus, Swiss roll, hyperbolic paraboloid) the learned vector fields are nearly tangent, and global coordinates are coherent; on the sphere (non‑parallelizable) singularities appear near the poles as expected. On CIFAR‑10 (intrinsic dimension 20) the coordinates achieve 42.0% linear classification accuracy, slightly below a standard autoencoder (45.0%), but training requires 20× more time and over double memory usage.

## Method Summary
The method learns *m* ambient vector fields **F**₁,…,**F**ₘ: ℝᵈ → ℝᵈ, positive time‑scale functions *T*ᵢ, an optional conformal scaling σᵢ, and a reference point **C**. The flows φᵢᵗ corresponding to each field are defined via ODEs. The goal is that composing the flows (φₘ^∞ ∘ … ∘ φ₁^∞) sends every data point **x** to **C**. The associated arc‑lengths along each flow become the coordinates ℓᵢ(**x**) = ∫₀^∞ ‖**F**ᵢ(φᵢᵗ(**x**))‖ dt, or more conveniently approximated via *T*ᵢ (since *T*ᵢ encodes the speed). To prevent all points from collapsing trivially to **C** via normal contraction, the Lie derivative *L*_{**F**ᵢ} *g* (for a conformal Euclidean metric *g*) is constrained to be positive semidefinite everywhere, which forces **F**ᵢ to be tangent to the data manifold. Commutativity of the fields ([**F**ᵢ,**F**ⱼ]=0) is enforced; under this condition the sequential flow composition equals the flow of a single autonomous vector field **G** = Σᵢ *T*ᵢ **F**ᵢ (Theorem 3.3). The training objective uses a flow‑matching loss: sample a smooth interpolant *u*ₛ(t,**x**,**C**) between **x** and **C** (e.g., a straight line); then match the velocity of **G** at the intermediate point *u*ₛ(t,**x**,**C**) to the known derivative ∂ₜ*u*ₛ. This avoids integrating ODEs during training. Additional regularizers enforce the non‑shrinking condition (via a smooth proxy for the minimum eigenvalue of *L*_{**F**ᵢ} *g*), commutativity (Lie bracket penalty), and the relationship between *T*ᵢ and the flow (∇*T*·**F** + 1 = 0). The model is trained end‑to‑end with stochastic estimates of Jacobians (e.g., Hutchinson) for the spectral and bracket penalties.

## Key Results
- Learned vector fields achieve mean angular errors <7° with ground‑truth tangents on synthetic 2‑D manifolds; on the sphere (non‑parallelizable) singularities appear near poles as predicted by topology.
- On CIFAR‑10, coordinates yield 42.0% linear classification accuracy, slightly below a standard autoencoder (45.0%), but training requires 20× more time and >2× memory.
- Ablation studies confirm the non‑shrinking constraint is necessary: without it, loss can vanish even when *m* is smaller than intrinsic dimension; with it, loss only vanishes when *m* matches true dimension.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim**: Enforcing a positive semidefinite Lie derivative of a conformal Euclidean metric along each vector field (LFg⪰0) prevents trivial collapse to the reference point and aligns the fields with the tangent spaces of the data manifold.
- **Mechanism**: The Lie derivative of the metric measures the instantaneous rate of change of squared infinitesimal distances under the flow. LFg⪰0 ensures these distances do not decrease to first order, ruling out local contraction. Combined with the loss that drives flows to collapse the manifold onto a single point, the only nontrivial minimizers arise when the flows are tangent everywhere, because normal components would induce contraction in at least one direction, violating non‑contraction somewhere.
- **Core assumption**: The data lies on a smooth, compact embedded submanifold of ℝⁿ.
- **Evidence anchors**:
  - [abstract] "To prevent trivial collapse to C, impose a non-shrinking condition: the Lie derivative of a conformal Euclidean metric is positive semidefinite along each field."
  - [section 3.1] "Without additional structure, the optimization problem admits degenerate solutions... To prevent this behavior, we impose a non-shrinking condition... This condition enforces local non-contraction and rules out degenerate collapsing solutions."
  - [corpus] Neighbor papers on Riemannian geometry (e.g., "Score-based Pullback Riemannian Geometry") also use metric constraints, supporting the principle that metric properties govern tangent behavior.
- **Break condition**: If the manifold is not smooth, or if the data contains significant noise/outliers off the manifold, the smoothness assumptions underlying the Lie derivative condition fail, potentially allowing nontangent solutions with near-zero loss or causing optimization instability.

### Mechanism 2
- **Claim**: Commutativity of the learned vector fields ([Fᵢ, Fⱼ] = 0) reduces the composition of *m* neural ODEs to a single autonomous ODE, enabling integration‑free and scalable training.
- **Mechanism**: When vector fields commute, their flows are interchangeable (flowing along Fᵢ then Fⱼ equals flowing along Fⱼ then Fᵢ). The sequential composition φₘ∘…∘φ₁ is therefore equivalent to flowing along the combined vector field **G** = Σᵢ *T*ᵢ**F**ᵢ for an infinite time (Theorem 3.3). This replaces the need to numerically integrate *m* separate ODEs in sequence, which would be prohibitive for large *m*.
- **Core assumption**: The data manifold admits (at least locally) a coordinate frame of commuting vector fields—i.e., it is (locally) parallelizable.
- **Evidence anchors**:
  - [abstract] "Scalability is achieved by enforcing commutativity of the vector fields (so sequential flows equal a single flow)..."
  - [section 3.3] "By enforcing that the field line bundles commute... the composition of flows can be equivalently evaluated as a single flow."
  - [corpus] Neighbor work on "Equivariant Manifold Neural ODEs" emphasizes that commuting fields correspond to coordinate bases on manifolds.
- **Break condition**: If the intrinsic manifold geometry is not parallelizable globally (e.g., sphere), exact commutativity cannot hold everywhere. The method still works approximately because data covers only an open dense subset, but singularities may appear (as seen on the sphere experiment). Forcing strict commutativity could bias the learned fields in regions where no global frame exists.

### Mechanism 3
- **Claim**: A flow‑matching objective that aligns the instantaneous velocity of a learned autonomous flow with that of a prescribed interpolation between data point and reference point avoids long‑time ODE integration and stabilizes training.
- **Mechanism**: Instead of minimizing error after integrating to *t* → ∞ (≈ **C**), the loss matches the velocity field **G** = Σᵢ *T*ᵢ**F**ᵢ to ∂ₜ*u*ₛ(t,**x**,**C**) at sampled intermediate times *t*∈[0,1] along a fixed smooth path *u*ₛ (Eq. 3). This makes training independent of how close the numerical trajectory actually gets to **C** at finite time, sidestepping issues of numerical convergence and step‑size sensitivity.
- **Core assumption**: There exists a simple geometric path (e.g., straight line) from any data point **x** to the reference **C** that captures the intended global coordinate structure.
- **Evidence anchors**:
  - [abstract] "Scalability is achieved... by using a flow‑matching objective that avoids numerical ODE integration."
  - [section 3.3] "Rather than requiring the numerical trajectory to land exactly at C, we only require its speed at each time *t* to align with the speed of a known reference path."
  - [corpus] Neighbor "Metric Flow Matching for Smooth Interpolations..." directly addresses flow‑matching on manifolds, providing a related methodological foundation.
- **Break condition**: If the chosen interpolation *u*ₛ does not respect the manifold geometry (e.g., straight line through ambient space that leaves the manifold), the learned vector fields may still satisfy the matching loss but fail to be tangent. The non‑contraction constraint is crucial to correct this, but if that constraint is too weak, the method could learn fields that match velocities off‑manifold.

## Foundational Learning
- **Concept**: Smooth embedded submanifold and tangent space  
  **Why needed here**: The data is assumed to lie on a smooth manifold embedded in ℝⁿ. Understanding tangent spaces is essential because the vector fields must lie in these tangent spaces everywhere to define intrinsic flows.  
  **Quick check question**: Given a point *x* on a known sphere *S*²⊂ℝ³, what is the tangent space *T*ₓ*S*², and how would you test if a vector **v**∈ℝ³ is tangent at *x*?

- **Concept**: Lie derivative of a metric and non‑contraction  
  **Why needed here**: The non‑shrinking condition is expressed as the Lie derivative of a conformal Euclidean metric being positive semidefinite. This encodes that infinitesimal distances along the flow do not decrease.  
  **Quick check question**: For a constant Euclidean metric *g* on ℝⁿ and a linear vector field **F**(**x**) = *A**x*, compute the symmetric matrix of *L*_{**F**} *g*. What does *L*_{**F**} *g*⪰0 imply about the eigenvalues of *A* + *A*ᵀ?

- **Concept**: Commuting vector fields and integrable distributions  
  **Why needed here**: Commutativity ([**F**ᵢ,**F**ⱼ]=0) ensures the distribution spanned by the **F**ᵢ is integrable (Frobenius theorem), which guarantees that flows can be combined without order dependence and that there exist local coordinates in which the fields are coordinate basis vectors.  
  **Quick check question**: In ℝ² with standard coordinates (*x*,*y*), do the vector fields ∂/∂*x* and *y*∂/∂*y* commute? Compute their Lie bracket.

- **Concept**: Global coordinate chart and parallelizability  
  **Why needed here**: The goal is to produce global coordinates (ℓ₁,…,ℓₘ) that are smooth and one‑to‑one on the whole manifold. Parallelizability (existence of *m* everywhere independent tangent fields) is sufficient but not necessary; a frame exists almost everywhere on many non‑parallelizable manifolds.  
  **Quick check question**: Is the circle *S*¹ parallelizable? What about the 2‑sphere *S*²? Explain using the Hairy Ball theorem.

## Architecture Onboarding
- **Component map**:  
  Input → Minibatch of data points **x** ∈ ℝᵈ → Neural networks: *m* vector fields **F**ᵢ(**z**) (MLP/CNN), *m* time functions *T*ᵢ(**z**) (positive via softplus), optional conformal factors σᵢ(**z**) (scalar), interpolator network *s*(*t*,**x**,**C**) giving *u*ₛ(*t*,**x**,**C**) = (1−*t*)**x** + *t***C** + *t*(1−*t*)*s*(*t*,**x**,**C**), learnable reference **C**. Loss: 𝓛 = 𝓛_flow‑match + α·*R*_λ + β·*R*_commute + ζ·*R*_time (+ η·*R*_metric). Regularizers: *R*_λ enforces LFg PSD via spectral penalty; *R*_commute penalizes Lie brackets; *R*_time enforces ∇*T*·**F** = −1; *R*_metric keeps conformal factor reasonable. Optimizer: Adam or SOAP with weight decay; learning‑rate schedule.

- **Critical path** (training loop):  
  1. Initialize networks (Glorot normal) and reference **C** randomly.  
  2. For each minibatch of **x**:  
     a. Sample *t* ∼ Uniform[0,1] and a random field index *i* (for stochastic *R*_λ).  
     b. Compute interpolant **u** = *u*ₛ(*t*,**x**,**C**).  
     c. Compute flow‑matching loss: 𝓛_match = ‖ Σᵢ **F**ᵢ(**u**) *T*ᵢ(**u**) − ∂ₜ*u*ₛ ‖². (∂ₜ*u*ₛ is obtained analytically or via autograd.)  
     d. For sampled *i*, compute *R*_λ (spectral penalty on *L*_{**F**ᵢ} *g* estimated via Hutchinson trace estimator).  
     e. Compute *R*_commute = Σ_{i≠j} ‖[**F**ᵢ,**F**ⱼ]‖² / (*T*ᵢ*T*ⱼ), and *R*_time = ‖ (J_T · Fmat + I) ⊙ S ‖_F² (with scaling matrix *S*).  
     f. Total loss 𝓛 = 𝓛_match + α *R*_λ + β *R*_commute + ζ *R*_time (+ η *R*_metric).  
     g. Backpropagate and update parameters.  

- **Design tradeoffs**:  
  • *Jacobian efficiency vs. accuracy*: Full Jacobians expensive; Hutchinson trace with Lanczos trades variance for speed; more Lanczos steps improve accuracy but increase cost.  
  • *Stochastic regularization*: Sampling one field per batch for *R*_λ reduces cost but may bias if *m* large; ensure all fields seen equally.  
  • *Commutativity enforcement*: Penalty weight β must balance; too strong forces rigid frames that may not adapt to complex geometries.  
  • *Reference point **C****: Learned jointly; indirectly constrained by flow‑matching and non‑contraction; no explicit regularizer.  
  • *Time functions *T*ᵢ**: Must remain strictly positive; softplus used. Condition ∇*T*·**F** = −1 is approximate via *R*_time; inadequate ζ causes trajectories to miss **C**.

- **Failure signatures**:  
  1. **Loss does not decrease** → Check learning rate, activation (LipSwish), initialization.  
  2. **Loss per dimension > 0 when intrinsic *m* matches** (e.g., linear plane) → *m* too small or regularization weights too low; collapse may still occur.  
  3. **High angular error on synthetic tangents** → Non‑contraction constraint ineffective (α too small) or optimization issue.  
  4. **Large normal components in fields** → Same as above; also check *T*ᵢ not saturating (huge values) to fake non‑contraction.  
  5. **Singularities on sphere expected**, but if they spread → commutativity penalty too weak or data not well covering manifold.  
  6. **Memory/time blowup** → Jacobian computation via autograd for high‑dim data; reduce Lanczos steps, use smaller batch, or simpler ReLU‑based penalty for large datasets.

- **First 3 experiments**:  
  1. **Linear manifold sanity check**: Train on uniformly sampled 3‑D plane embedded in ℝ⁴ with varying *m*. With LFg⪰0, loss only vanishes when *m* = 3; without it, loss drops to zero even for *m* < 3 due to collapse.  
  2. **Curved manifolds** (sphere, torus, Swiss roll, hyperbolic paraboloid): Compute mean angular error between learned fields (aggregated into an orthonormal frame via Gram‑Schmidt) and ground‑truth normals. Errors are small (<7°) except Torus slightly higher, confirming tangency.  
  3. **Sphere singularities**: Visualize combined vector field **F** = Σ **F**ᵢ on the sphere. Defects appear near poles, consistent with non‑parallelizability of *S*²; demonstrates method respects topological constraints.

## Open Questions the Paper Calls Out
1. **Multiple local reference systems**: How can the method be extended to learn multiple local coordinate charts to handle manifolds that do not admit a global chart? The current method exhibits singularities on non‑parallelizable manifolds (e.g., sphere poles), limiting applicability.  
2. **Incorporating data density**: The framework does not model data density along the manifold. Adding density estimation would enable generative modeling and likelihood‑based evaluation.  
3. **Architectures with built‑in Lie derivative positivity**: Can neural architectures be designed such that the LFg⪰0 constraint holds by construction, eliminating the need for expensive spectral penalties?  
4. **Necessity of commutativity**: Is exact commutativity required for a consistent coordinate chart, or can it be relaxed? What does enforcing approximate commutativity imply about the manifold’s geometry, especially on non‑parallelizable manifolds?

## Limitations
- Training details (e.g., Lanczos implementation, exact schedule) are underspecified, hindering full reproducibility.  
- High computational overhead (20× training time, >2× memory vs. autoencoders) makes scaling to large datasets impractical.  
- The method assumes smooth, noise‑free manifolds and enforces commutativity; on non‑parallelizable manifolds singularities are inevitable, restricting general applicability.
