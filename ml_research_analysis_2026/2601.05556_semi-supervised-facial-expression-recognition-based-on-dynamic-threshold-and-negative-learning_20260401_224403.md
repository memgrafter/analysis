# Semi-Supervised Facial Expression Recognition based on Dynamic Threshold and Negative Learning

## Quick Facts
- arXiv ID: 2601.05556
- Source URL: https://arxiv.org/abs/2601.05556
- Reference count: 0
- Primary result: Achieves state-of-the-art semi-supervised facial expression recognition with up to 2.2% accuracy improvement on RAF-DB (64.06% with 100 labels) and AffectNet (54.91% with 2000 labels), even outperforming fully supervised models without using all labels.

## Executive Summary
Facial expression recognition (FER) often suffers from limited and imbalanced labeled data. This paper introduces a semi-supervised framework that combines Dynamic Threshold Adjustment (DTA) and Selective Negative Learning (SNL) to leverage large amounts of unlabeled data. DTA dynamically sets per-category confidence thresholds to select high-quality pseudo-labels, while SNL mines useful information from low-confidence samples via complementary labels. The framework also employs a feature extractor with local attention enhancement and random feature map dropout for robustness. Experiments on RAF-DB and AffectNet demonstrate state-of-the-art performance, achieving notable accuracy gains in low-label regimes and surpassing fully supervised results without utilizing all available labels.

## Method Summary
The method consists of three main components. First, a feature extraction network with local attention modules and random feature map dropout processes input faces. Second, the Dynamic Threshold Adjustment (DTA) module assigns each emotion category an adaptive confidence threshold that evolves during training, selecting pseudo-labels only from unlabeled samples whose maximum classifier confidence exceeds the respective threshold. Third, the Selective Negative Learning (SNL) module treats the remaining low-confidence unlabeled samples by assigning them complementary labels (labels known not to be the true class) and uses a negative loss to learn from these samples. Training combines supervised loss on labeled data, pseudo-label loss on high-confidence unlabeled samples, and complementary loss on low-confidence samples. The thresholds and loss weights are updated based on validation performance.

## Key Results
- Achieves up to 2.2% absolute accuracy improvement over previous semi-supervised methods on RAF-DB (64.06% with 100 labeled samples) and AffectNet (54.91% with 2000 labeled samples).
- Surpasses fully supervised models trained on all labels without using the full labeled set.
- Ablation studies confirm that both DTA and SNL modules contribute positively, with the combination yielding the best performance.

## Why This Works (Mechanism)
Dynamic thresholds allow the model to handle varying difficulty and class imbalance by adjusting selectivity per category, preventing the dominance of easy classes. Selective Negative Learning turns uncertain samples into a learning signal via complementary labels, avoiding the noise that would arise from treating them as hard pseudo-labels. The local attention mechanism focuses on discriminative facial regions, while feature dropout improves generalization. Together, these components enable effective learning from both reliable and unreliable predictions, maximizing the utility of limited labeled data.

## Architecture Onboarding
**Component map** (plain text):
Data (labeled & unlabeled) -> FeatureExtractor (ResNet+LocalAttention+Dropout) -> Classifier -> ConfidenceScores -> DTA (per-category threshold) -> {HighConf: pseudo-label, LowConf: SNL (complementary label)} -> Loss=L_sup+L_pseudo+L_comp -> Backprop -> Update thresholds & weights

**Critical path** (training loop):
1. Extract features for a mixed batch.
2. Compute class probabilities via classifier.
3. For unlabeled samples, take max probability as confidence.
4. Apply DTA to split high- and low-confidence groups.
5. Assign pseudo-labels to high-confidence (argmax) and random complementary labels to low-confidence.
6. Compute supervised loss on labeled, pseudo-label loss (cross-entropy) on high-confidence, and complementary loss on low-confidence.
7. Sum losses, backpropagate, and update model parameters.
8. Periodically adjust DTA thresholds based on validation pseudo-label precision.
9. Repeat.

**Design tradeoffs**:
- *Dynamic thresholds*: Offer per-category selectivity but introduce hyperparameters (initial value, decay schedule) that require tuning; heuristics may not transfer across datasets.
- *Selective Negative Learning*: Utilizes uncertain samples, yet complementary labels can be noisy if confidence estimates are poorly calibrated; incorrect negatives may harm learning.
- *Feature dropout and attention*: Improve robustness and focus but increase computational cost and may slow convergence if dropout rate is high.

**Failure signatures**:
- DTA thresholds collapse (e.g., all become too high) causing almost no pseudo-labels; monitor number of selected samples.
- SNL introduces errors when complementary labels overlap with true classes; check validation loss spikes when SNL weight is high.
- Feature dropout over-regularizes, leading to underfitting; training accuracy plateaus early.
- Confidence miscalibration results in poor separation between high- and low-confidence groups; track precision-recall of pseudo-labels.

**First three experiments**:
1. **DTA hyperparameter sensitivity**: Vary initial threshold and decay schedule, measure impact on accuracy and pseudo-label selection rate.
2. **SNL necessity**: Ablate SNL while keeping DTA, and compare with random negative label assignment to confirm the benefit of complementary learning.
3. **Feature module ablation**: Remove local attention and/or dropout individually to quantify their contributions to overall performance.

## Limitations
- Evaluated only on RAF-DB and AffectNet; generalization to other FER datasets (e.g., FER2013, CK+) remains uncertain.
- Dynamic threshold adjustment relies on heuristic design; its hyperparameters (initial thresholds, decay) are not systematically studied, and it lacks theoretical grounding.
- Reported accuracy improvements are modest (≤2.2%) and no statistical significance tests (e.g., across multiple random seeds) are provided, raising questions about robustness of gains.

## Confidence
- **Superior performance in low-label regimes**: Medium
- **Each module’s independent contribution**: Medium
- **Surpassing fully supervised models with fewer labels**: Low–Medium
