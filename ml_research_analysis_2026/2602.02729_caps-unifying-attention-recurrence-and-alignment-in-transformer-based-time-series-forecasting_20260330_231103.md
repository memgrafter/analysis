# CAPS: Unifying Attention, Recurrence, and Alignment in Transformer-based Time Series Forecasting

## Quick Facts
- arXiv ID: 2602.02729
- Source URL: https://arxiv.org/abs/2602.02729
- Reference count: 40
- Primary result: CAPS outperforms LinAttn+RoPE on all 10 tested forecasting datasets with average MSE reduction of 6.1%

## Executive Summary
CAPS introduces a structured attention mechanism that decouples three core time series forecasting challenges—global trend aggregation, local causal decay, and seasonal alignment—through additive gating paths within linear attention. By replacing softmax normalization with Riemann softmax for global aggregation, prefix-product gates for causal decay, and a learned Clock baseline for temporal weighting (combined with SO(2) rotations for alignment), CAPS captures distinct temporal inductive biases without coupling them. Empirical results show consistent outperformance over LinAttn+RoPE baselines across ten benchmarks, achieving an average rank of 2.3 with four first-place finishes while using fewer parameters than competing Transformers.

## Method Summary
CAPS replaces standard softmax attention with a linear attention mechanism that separates trend, shock, and seasonality modeling through three additive gating paths. The global trend path uses Riemann softmax for order-independent aggregation, the local shock path employs prefix-product gates for causal decay, and the seasonal path incorporates a learned Clock baseline with SO(2) rotations for phase alignment. This decoupling allows each temporal inductive bias to be modeled independently within the same attention layer. The architecture is specifically optimized for linear attention, as gains disappear when using softmax normalization.

## Key Results
- CAPS achieves 6.1% average MSE reduction over LinAttn+RoPE across ten forecasting benchmarks
- Outperforms on all datasets, with maximum improvement of 26.8% on PEMS03
- Achieves average rank of 2.3 with four first-place finishes while using fewer parameters than iTransformer

## Why This Works (Mechanism)
CAPS succeeds by structurally separating three conflicting temporal requirements that standard attention couples together. Standard softmax attention forces global normalization to simultaneously handle trend aggregation, causal decay, and seasonal alignment, creating interference between these operations. By using linear attention with additive gating paths, CAPS allows each temporal bias to be optimized independently—Riemann softmax handles global aggregation without being constrained by causal dependencies, prefix-product gates model local decay without affecting global patterns, and the Clock baseline with SO(2) rotations manages seasonal alignment without coupling to content-based selection. This decoupling directly addresses the fundamental tension in time series forecasting between order-independent aggregation, order-dependent decay, and phase-sensitive periodicity.

## Foundational Learning
- Linear attention vs softmax attention: Linear attention enables decoupling of temporal operations by avoiding global normalization constraints; quick check: verify gradient flow through prefix-product gates
- Riemann softmax: Alternative normalization that supports order-independent aggregation while maintaining linear attention properties; quick check: confirm proper scaling behavior with varying sequence lengths
- Prefix-product gates: Mechanism for modeling causal decay without affecting non-causal relationships; quick check: validate that prefix products maintain correct temporal ordering
- SO(2) rotations for alignment: Periodic function encoding that handles phase shifts without explicit positional encoding; quick check: test rotation invariance across different seasonal patterns
- Additive gating paths: Architecture that allows independent optimization of different temporal biases; quick check: confirm that each path contributes independently to final output
- Clock baseline: Learned temporal weighting that provides consistent seasonal reference; quick check: verify Clock parameters converge to meaningful seasonal periods

## Architecture Onboarding

Component map: Input sequence → Riemann softmax path + Prefix-product path + Clock baseline path → Additive combination → Output

Critical path: Input → Linear attention with three gating paths → Riemann softmax for trend aggregation → Prefix-product for causal decay → Clock baseline with SO(2) rotations for seasonal alignment → Final additive combination

Design tradeoffs: Linear attention vs softmax (speed/scale vs expressiveness), decoupled paths vs unified attention (specialization vs simplicity), learned Clock vs fixed seasonal patterns (adaptability vs prior knowledge)

Failure signatures: Degraded performance with softmax normalization, loss of gains without all three paths, parameter inefficiency compared to deeper Transformers

First experiments:
1. Replace standard attention with linear attention while maintaining single gating path to verify baseline performance
2. Add Riemann softmax path to test global aggregation capabilities independent of causal modeling
3. Introduce prefix-product gates to validate causal decay modeling without seasonal alignment

## Open Questions the Paper Calls Out
Major uncertainties remain regarding CAPS' scalability beyond evaluated dataset sizes and robustness to distributional shifts in real-world deployment. The study focuses on fixed forecasting horizons and synthetic noise injection, leaving open questions about performance degradation with longer sequences or extreme temporal anomalies. Additionally, the linear attention optimization is critical to CAPS' gains—results suggest softmax variants fail to capture decoupled inductive biases—but ablation on alternative linear attention architectures was not explored.

## Limitations
- Scalability uncertainty beyond tested dataset sizes (>10k time steps not evaluated)
- Limited testing to fixed forecasting horizons without exploring extreme temporal anomalies
- Absence of stress tests for distributional shifts (e.g., COVID-like disruptions)
- No comparison with specialized non-Transformer SOTA methods on identical benchmarks
