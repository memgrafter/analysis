# Traces of Social Competence in Large Language Models

## Quick Facts
- **arXiv ID:** 2603.04161
- **Source URL:** https://arxiv.org/abs/2603.04161
- **Reference count:** 40
- **Primary result:** LLMs show a crossover effect where explicit mental-state cues (e.g., "X thinks") improve False Belief but harm True Belief accuracy, linked to stereotypical training patterns and amplified by scale.

## Executive Summary
This paper investigates the reliability of the False Belief Test (FBT) for assessing Theory of Mind in large language models. Testing 17 open-weight models on 192 balanced FBT variants, the authors find that scaling model size improves False Belief performance but damages True Belief accuracy, creating a growing performance gap. A central discovery is a crossover interaction: explicitly stating a character's belief (e.g., "X thinks") aids False Belief answers but impairs True Belief answers. This pattern is tied to stereotypical associations of the word "think" with epistemic divergence in training data. Instruction tuning partially mitigates the effect, while reasoning-oriented fine-tuning amplifies it. A case study on OLMo 2 traces the emergence of this behavior during pre-training and uses vector steering to isolate a causal "think vector" that drives the response patterns.

## Method Summary
Models were evaluated on a battery of 192 stimuli derived from Trott et al. (2023), combining 12 social scenarios with 16 manipulations crossing knowledge state (False/True Belief) and knowledge cue presentation (explicit "thinks" vs. implicit "goes to get"). For each prompt, the model's next-token probability distribution was computed and normalized to compare conditional probabilities for the two possible location answers. The primary analysis used Bayesian multilevel logistic regression with fixed effects for model size, training variant, knowledge state, and knowledge cue, and a random intercept for model family/version. A focused longitudinal case study examined OLMo 2 checkpoints during pre-training and applied causal vector steering by extracting a "think vector" from hidden state differences and injecting it at intermediate layers.

## Key Results
- Scaling model size significantly improves False Belief accuracy but harms True Belief accuracy, widening the performance gap between the two.
- Explicit knowledge cues (using "thinks") facilitate False Belief responses but impair True Belief responses, creating a robust crossover interaction across model families.
- Instruction tuning (e.g., SFT, DPO) partially mitigates the crossover, while reasoning-oriented fine-tuning (e.g., chain-of-thought) amplifies sensitivity to the explicit/implicit cue manipulation.
- Vector steering using a "think vector" extracted from OLMo 2 causally shifts model predictions, improving implicit False Belief and harming explicit True Belief when added, and vice versa when subtracted.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Explicit propositional attitude cues (e.g., "X thinks") enhance False Belief performance but impair True Belief performance due to stereotypical patterns in training data linking "think" to epistemic divergence.
- **Mechanism:** The verb "think" is pragmatically associated with contexts where the speaker's belief differs from reality or common knowledge. In False Belief scenarios, this association aligns with the character's incorrect belief, aiding prediction. In True Belief scenarios, it conflicts with the character's correct belief, impairing prediction. This creates a crossover interaction.
- **Core assumption:** LLMs learn distributional patterns of mental-state vocabulary that overgeneralize to the FBT structure, irrespective of scenario semantics.
- **Evidence anchors:** Explicit cues facilitate False Belief but hurt True Belief performance; "think" can be expected to be frequently used to mark epistemic divergence in training corpora.
- **Break condition:** If explicit cues did not significantly impair True Belief accuracy across model families and training variants, the hypothesized stereotypical pattern-association would be falsified.

### Mechanism 2
**Claim:** Scaling model size improves False Belief performance but harms True Belief accuracy because larger models amplify learned scenario-specific heuristics rather than acquiring robust, generalized Theory of Mind.
- **Mechanism:** Increased capacity allows models to better memorize and apply superficial patterns associated with False Belief test structures (e.g., character absent, object moved). However, this specialization comes at the cost of flexibility, making models more susceptible to the explicit/implicit cue manipulation and less able to handle the True Belief variant where the character witnesses the move.
- **Core assumption:** ToM competence requires consistent performance across knowledge states; a dichotomy indicates reliance on narrow heuristics.
- **Evidence anchors:** Scaling strongly benefits False Belief, though harms performance in the True Belief cases; the performance gap grows as model size increases.
- **Break condition:** If scaling showed a positive, uniform effect on both False and True Belief tasks across model families, the claim of heuristic amplification would be unsupported.

### Mechanism 3
**Claim:** Instruction tuning partially mitigates the crossover effect by instilling cooperative communication principles that encourage perspective-taking, while reasoning-oriented fine-tuning amplifies it by promoting meticulous attention to prompt details, including lexical cues.
- **Mechanism:** Instruction tuning aligns models to follow user intent and be helpful, which may override some heuristic patterns. Reasoning tuning (e.g., "think step-by-step") increases focus on surface-form features and logical structure, making models more sensitive to the presence of "think" and thus exacerbating the crossover.
- **Core assumption:** Post-training objectives differentially shape how models process propositional attitude verbs in social scenarios.
- **Evidence anchors:** Instruct training partially rescues the implicit False Belief deficit; reasoning-oriented finetuning worsens the implicit False Belief impairment, amplifying sensitivity to knowledge cue type.
- **Break condition:** If reasoning fine-tuning consistently improved True Belief performance or eliminated the crossover, the amplification claim would fail.

## Architecture Onboarding
- **Component map:** Stimuli (192 FBT variants) -> Models (17 open-weight, varied sizes/variants) -> Probing (conditional location probability) -> Primary Analysis (Bayesian multilevel regression) -> OLMo 2 Case Study (training checkpoints, vector steering) -> Steering (think vector extraction & injection).
- **Critical path:** 1. Validate no data leakage for your model/training corpus. 2. Replicate the core crossover analysis (explicit/implicit × FB/TB) to confirm pattern. 3. Isolate effects by testing Base, Instruct, and Reasoning variants separately. 4. If checkpoints exist, plot accuracy evolution during pre-training. 5. Conduct causal vector steering test via leave-one-out extraction.
- **Design tradeoffs:** Artificial, balanced stimuli offer control but lack ecological validity; vector steering provides causality but is labor-intensive and layer-specific; strict accuracy (both cues correct) is a stringent ToM measure but may conflate language competence.
- **Failure signatures:** No crossover effect observed; random intercept variance dominates fixed effects; steering vector manipulation produces no significant accuracy change; abrupt performance jumps mid-training due to model merging; confusion between True/False Belief correct location.
- **First 3 experiments:** 1. Replicate the 192-item battery on a target model (e.g., OLMo 2 7B Instruct) and verify the explicit/implicit × FB/TB crossover. 2. Extract a "think vector" via leave-one-out and apply ±1.0 steering; expect opposite effects on implicit-FB vs. explicit-TB accuracy. 3. Perform a semantic similarity search between your training data and the FBT premises to catch non-verbatim contamination; test on a novel adversarial FBT variant.

## Open Questions the Paper Calls Out
- **Open Question 1:** What specific design principles constitute a robust, contamination-resistant benchmark for assessing socio-cognitive competence in LLMs?
- **Open Question 2:** What is the precise computational or representational mechanism underlying the observed crossover interaction between knowledge state (FB/TB) and knowledge cue explicitness?
- **Open Question 3:** Why does increasing model size improve False Belief performance while harming True Belief accuracy, and why does this dichotomy strengthen with scale?
- **Open Question 4:** What specific aspects of post-training (instruction tuning vs. reasoning-oriented fine-tuning) cause their divergent effects on the FB/TB crossover and overall robustness?
- **Open Question 5:** How generalizable is the isolated 'think vector' across different model architectures, sizes, and FBT scenario variants?

## Limitations
- The fixed 192-item FBT set may overfit to specific patterns and lacks ecological validity.
- Missing exact model identifiers (Appendix B) hinders precise replication and comparison across releases.
- Broad training categories (Base/Instruct/Reasoning) mix distinct fine-tuning approaches (SFT, DPO, RLVR), confounding effect isolation.

## Confidence
- **Crossover effect:** Medium – consistent across models but relies on artificial stimuli.
- **Scaling & fine-tuning effects:** Medium – correlations appear robust, yet confounded by architecture/data differences.
- **Think vector causality:** Low–Medium – steering results sensitive to implementation; replication unclear.

## Next Checks
1. Test the crossover effect on a new, diverse FBT battery (≥200 scenarios) to verify generalizability beyond the Trott et al. set.
2. Expand leakage analysis by computing semantic similarity between training data and test items using embeddings, beyond verbatim matching.
3. Systematically vary steering hyperparameters (layer range, λ scaling, injection point) and report the distribution of effect sizes to assess robustness.
