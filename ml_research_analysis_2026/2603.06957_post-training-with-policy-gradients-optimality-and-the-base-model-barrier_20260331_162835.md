# Post-Training with Policy Gradients: Optimality and the Base Model Barrier

## Quick Facts
- **arXiv ID:** 2603.06957
- **Source URL:** https://arxiv.org/abs/2603.06957
- **Reference count:** 40
- **Primary result:** Outcome-reward post-training converges in O(1/(αγ²ε)) iterations for samples with base likelihood ≥ α, but overall error limited by base model’s Likelihood Quantile (LQ), leading to exponential reward queries for off‑support samples; process‑reward post-training replaces LQ with token‑level LQ, achieving polynomial dependence on sequence length N.

## Executive Summary
This paper studies policy gradient (PG) post‑training of linear autoregressive models under two reward paradigms: outcome reward models (ORM) that give a binary signal only at the end of a full sequence, and process reward models (PRM) that provide binary feedback after each token. Under a γ‑margin assumption on feature separability, the authors derive conditional convergence rates: with ORM, PG reduces error as O(1/(αγ²T)) for test samples where the base model’s likelihood is at least α; with PRM, the dependence on sequence length N is eliminated by focusing on token‑level correctness. A central concept is the Likelihood Quantile (LQ) of the base model, which characterizes the tail of its likelihood distribution. For ORM, the number of reward queries needed to achieve final error ε scales as Q_q(ε)⁻¹/γ² and can be exponential in N unless the base model’s LQ is polynomially small. For PRM, the relevant Token‑Level LQ replaces the sequence‑level LQ, leading to a sample complexity of O(N·TL‑LQ⁻¹/γ² + 1/(γ²ε)). Finally, the paper proves a minimax lower bound showing that SGD pre‑training cannot produce a base model with polynomially small LQ in N without exponential supervised data, establishing a fundamental barrier.

## Method Summary
The study focuses on linear autoregressive models p_w(y|x) = ∏_{i=1}^N softmax(⟨w, ϕ(x, y_{<i}, y_i)⟩). The base model q = p_{w0} is obtained via supervised pre‑training with negative log‑likelihood using Adagrad. Post‑training then proceeds with policy gradient updates: samples are drawn from a behavior policy, and the gradient estimator uses either full‑sequence (ORM) or token‑level (PRM) advantages. For ORM, behavior is typically a mixture of the base policy and uniform sampling; for PRM, Algorithm 2 constructs sequences token‑by‑token, trying multiple candidates from the base and a uniform mix to hit correct prefixes. The adaptive learning rate η_t = (λ + ∥∇ℓ_t∥_2)⁻¹ is key to removing N‑dependence. Evaluation metrics include per‑token and sequence‑level likelihoods, test error (1−p_w(y*|x)), and the likelihood quantiles (LQ, TL‑LQ) of the base model. Experiments use synthetic mixture and hypercube datasets to isolate the effect of reward type and pre‑training progress.

## Key Results
- **ORM convergence & LQ barrier:** For samples where q(y*|x) ≥ α, PG attains error ε in ~O(1/(αγ²ε)) iterations. However, the overall expected error is bounded below by LQ, and the reward query count scales as Q_q(ε)⁻¹/γ², which is exponential in N for typical SGD‑trained base models.
- **PRM advantage:** With process rewards, the relevant quantity is the Token‑Level Likelihood Quantile (TL‑LQ). The required reward queries become ~O(N·TL‑LQ⁻¹/γ² + 1/(γ²ε)), i.e., polynomial in N, k, and γ⁻².
- **Fundamental pre‑training limit:** Any algorithm that pre‑trains a base model with n supervised samples suffers LQ ≤ k⁻ᴺ/(1−O(γ²nε)) in the worst case; thus, achieving polynomially small LQ demands exponential n.

## Why This Works (Mechanism)
**Mechanism 1: Conditional improvement with ORM**  
For test samples where the base model assigns non‑negligible probability (q(y*|x) ≥ α), the policy gradient update with outcome reward converges at rate O(1/(αγ²T)). The γ‑margin assumption (linear separability of token‑wise feature vectors) ensures that the expected advantage is well‑behaved, and an adaptive learning rate normalizes by gradient norm to keep steps stable. This mechanism relies on the behavior policy putting enough mass on the correct response (e.g., via mixing with uniform). Breakdown occurs if α is exponentially small in N, as the iteration count then becomes polynomial in α⁻¹, i.e., exponential in N.

**Mechanism 2: LQ as fundamental barrier for ORM**  
The Likelihood Quantile (LQ) quantifies the tail of the base model’s likelihood distribution: Q_q(ε) = sup{α : P_x(q(y*|x) ≤ α) ≤ ε}. The number of reward queries needed to reduce error below ε is essentially Q_q(ε)⁻¹/γ². For a base model produced by SGD, one can prove a minimax lower bound: Q_q(ε) cannot be polynomially small in N unless the supervised sample size n is exponential. Hence, ORM post‑training cannot overcome the poor tail of the base model without exponentially many reward queries—this is the base model barrier.

**Mechanism 3: PRM replaces sequence‑level LQ with token‑level LQ**  
Process rewards give immediate binary feedback after each token. The post‑training algorithm can then correct one bad token at a time, and the relevant quantile becomes the Token‑Level LQ: the smallest per‑token conditional probability along the optimal prefix. This quantity is much larger in practice (e.g., 1/k for a uniform base). The query complexity then scales as O(N·TL‑LQ⁻¹/γ² + 1/(γ²ε)), which is polynomial in N and avoids the exponential dependence that plagues ORM. The adaptive learning rate further eliminates an explicit N factor in the convergence rate.

## Architecture Onboarding
**Component map:** Pre‑training module → Reward module → Behavior policy module → PG optimizer → Evaluation  
**Critical path:**  
1. Pre‑train base model on supervised data (SGD/Adagrad).  
2. Estimate LQ/TL‑LQ from the base model or choose reward type (ORM/PRM).  
3. Initialize PG weights from the base model.  
4. Run PG for T iterations with adaptive learning rate and appropriate behavior policy (mixture or best‑of‑m).  
5. Evaluate on held‑out test set; adjust hyperparameters if needed.  
**Design tradeoffs:**  
- ORM is cheaper per rollout (1 query) but may require exponential queries for off‑support samples; PRM costs O(mN) per rollout but scales polynomially in N.  
- Behavior policy: uniform exploration gives clean worst‑case bounds but is inefficient; mixing with the base model improves on‑support convergence.  
- Learning rate: static vs adaptive; adaptive adds computation but removes N‑dependence.  
- Batch size: larger batches reduce variance but increase per‑iteration cost.  
**Failure signatures:**  
- ORM fails to improve likelihood of off‑support samples (stuck near zero).  
- Divergence or extremely slow progress when using constant LR with long sequences.  
- PRM suffers high variance if the base model’s token‑level accuracy is very low (requires large best‑of‑m).  
- Violation of the γ‑margin assumption leads to suboptimal convergence or instability.  
**First 3 experiments:**  
1. Reproduce pre‑training curves on the synthetic mixture dataset; measure LQ decay with training steps and compare to the theoretical lower bound.  
2. Compare ORM vs PRM post‑training: run 4000 PG steps and plot (a) average likelihood of off‑support mixture centers, (b) overall test error, (c) individual likelihood trajectories.  
3. Vary the best‑of‑m parameter (for ORM: mixture proportion; for PRM: candidate draws per token) and measure final test error vs. total reward queries.

## Open Questions the Paper Calls Out
1. How can we efficiently learn an accurate process reward model from data, achieving both statistical and computational efficiency, given that the analysis assumes access to an accurate PRM?
2. How can the theoretical results be extended to settings with noisy and non‑separable responses, and develop optimal post‑training algorithms accordingly?
3. Does the base model barrier (exponential dependence on sequence length for outcome rewards) persist for modern large language models that use nonlinear architectures and overparameterization?
4. Can we design pre‑training strategies that yield base models with polynomially small token‑level likelihood quantiles (TLQ) without requiring exponential supervised samples, thus enhancing post‑training with process rewards?

## Limitations
- Theoretical analysis is restricted to linear autoregressive models with a fixed γ‑margin; real‑world models (e.g., transformers) may not satisfy these assumptions.
- Empirical evaluation uses only synthetic mixture and hypercube datasets; generalization to natural language or vision tasks with noisy rewards remains unverified.
- Critical experimental details (e.g., exact value of best‑of‑m for PRM, number of pre‑training checkpoints) are omitted, making exact replication difficult and raising reproducibility concerns.

## Confidence
- **ORM convergence rate and LQ limitation:** High (rigorous theorems under clear assumptions).
- **PRM token‑level LQ advantage:** High theoretically, Medium empirically (due to limited experimental detail).
- **Generalizability beyond linear models:** Low (no theoretical or empirical evidence provided).
