# On the Out-of-Distribution Generalization of Reasoning in Multimodal LLMs for Simple Visual Planning Tasks

## Quick Facts
- **arXiv ID:** 2602.15460
- **Source URL:** https://arxiv.org/abs/2602.15460
- **Reference count:** 19
- **Primary result:** Mixed-format chain-of-thought (grid/table + description) yields non‑trivial out‑of‑distribution generalization (up to 41% on 10×10 maps), while most models rely on pattern matching rather than algorithmic learning.

## Executive Summary
The paper investigates how well multimodal large language models (LLMs) generalize their reasoning to new scenarios in a simple visual planning task. Using the FROZENLAKE grid navigation environment, the authors fine‑tune Qwen2.5‑VL‑7B‑Instruct with various input representations (image, description, table, grid) and chain‑of‑thought (CoT) formats. Models are evaluated on in‑distribution (small maps, short start‑goal distances) and out‑of‑distribution (larger maps, longer distances) settings. Results show that text‑based inputs and structured representations (grid/table) substantially improve accuracy, and that combining grid/table with natural‑language descriptions in the CoT trace leads to the best OOD performance. However, performance generally degrades on harder OOD conditions, indicating that current LLMs rely on short‑range pattern matching rather than acquiring robust planning algorithms.

## Method Summary
The study uses a supervised fine‑tuning (SFT) approach on the Qwen2.5‑VL‑7B‑Instruct model. Training data consists of 1,000 FrozenLake maps of sizes 3×3 to 6×6, with start‑goal L∞ distance ≤5. Each map is rendered in four formats (image, textual description, table, grid) and paired with optional CoT traces that mimic step‑by‑step reasoning; CoT formats include description, table, grid, and combinations such as grid+description. The model is trained with TRL’s SFTTrainer for 10 epochs using standard hyperparameters. Evaluation simulates the model’s predicted move sequence in the FrozenLake gym environment and computes success accuracy. OOD test sets include larger maps (7×7–10×10) and fixed‑size maps with enforced start‑goal distances ≥6, allowing the authors to measure generalization beyond the training distribution.

## Key Results
- Mixed-format CoT (grid/table + description) achieves up to 41% OOD accuracy on 10×10 maps, whereas single‑format CoTs drop near zero on hard OOD conditions.
- Text‑based input representations (description, table, grid) consistently outperform image‑based inputs in both ID and OOD settings; image‑based models never exceed 74% ID accuracy and show weak OOD generalization.
- Overall, models exhibit brittle pattern matching: most fail to generalize to larger maps or longer start‑goal distances, confirming that algorithmic learning remains a challenge for current LLMs.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Combining structured text representations (grid/table) with natural language descriptions in chain‑of‑thought (CoT) traces enhances out‑of‑distribution (OOD) generalization for spatial planning tasks.
- **Mechanism:** The structured component provides a token‑efficient scaffold for tracking map state changes at each reasoning step, while the description forces explicit directional reasoning. This multimodal trace may help the model internalize the planning algorithm rather than memorizing surface patterns.
- **Core assumption:** The Qwen2.5‑VL model can integrate symbolic (grid/table) and semantic (description) information within a single CoT sequence to form a more robust internal representation of the planning process.
- **Evidence anchors:** Abstract states "reasoning traces which combine multiple text formats yield the best (and non‑trivial) OOD generalization"; Section 4.3 shows models using grid input with grid+description CoT retain 20% accuracy on 10×10 maps with d∞≥6, while single‑format CoTs collapse.
- **Break condition:** If the structured component (grid/table) is removed, OOD performance collapses even with description CoT, indicating the visual‑tracking aspect is necessary.

### Mechanism 2
- **Claim:** Text‑based input representations (description, table, grid) consistently outperform image‑based inputs for both in‑distribution and OOD spatial reasoning in multimodal LLMs.
- **Mechanism:** Textual encodings align better with the model’s pretraining on structured language data, enabling precise symbolic manipulation. Image inputs require additional perceptual processing and may suffer from modality interference or latent‑space noise that hinders algorithmic learning.
- **Core assumption:** The model’s architecture and training data bias it toward processing discrete, tokenized structures over continuous pixel representations for planning tasks.
- **Evidence anchors:** Abstract notes "purely text‑based models consistently outperform those utilizing image‑based inputs"; Section 4.2 shows image inputs max 74% ID avg vs. text 91%; Section 4.4 shows image+CoT underperforms even Mirage’s latent reasoning.
- **Break condition:** For tasks requiring recognition of visual textures or non‑symbolic patterns, image inputs might become advantageous, but for grid navigation text dominates.

### Mechanism 3
- **Claim:** Current CoT improvements primarily reflect short‑range pattern matching rather than acquisition of generalizable algorithmic procedures, leading to rapid OOD degradation.
- **Mechanism:** Fine‑tuning on limited map sizes (≤6×6) and short start‑goal distances (d∞≤5) trains the model to recognize local configurations and short solution templates. Without exposure to longer‑range dependencies, the model cannot extrapolate the underlying search algorithm (e.g., A*) to larger maps or longer distances.
- **Core assumption:** The FROZENLAKE task has a well‑defined optimal algorithmic solution that a model could learn if presented with sufficient distributional coverage during training.
- **Evidence anchors:** Abstract states results indicate "reliance on pattern matching rather than algorithmic learning"; Section 4.3 shows most models drop below 10% accuracy on 7×7 maps with d∞≥6; Table 3 shows description CoT falls to ~0% at d∞=6 while grid+description maintains 29%.
- **Break condition:** If training data covered a broad range of map sizes and distances, OOD performance would improve; the paper intentionally uses a narrow training set to test generalization limits.

## Architecture Onboarding
**Component map:**  
Data generator → (maps + CoT traces) → Fine‑tuning pipeline (SFTTrainer) → Trained model checkpoints → Evaluator (simulated rollouts) → Analysis module (metrics, plots)

**Critical path:**  
1. Generate training data (1,000 maps with required input/CoT formats).  
2. Fine‑tune Qwen2.5‑VL for each format combination using SFT (10 epochs).  
3. Evaluate each checkpoint on ID and OOD test sets by simulating move sequences.  
4. Analyze accuracy by map size, start‑goal distance, and solution length.

**Design tradeoffs:**  
- Token length vs. information richness: Mixed‑format CoT (e.g., table+description) yields longer sequences but better OOD accuracy; single‑format is cheaper but less robust.  
- Image vs. text inputs: Text inputs are token‑efficient and more effective; image inputs add perceptual overhead and currently underperform.  
- Training epochs: Extending beyond 10 epochs provides minimal gains, so 10 epochs balances cost and accuracy.

**Failure signatures:**  
- OOD accuracy collapse for single‑format CoT models on maps with d∞≥6 or size ≥7×7.  
- Image‑based models show uniformly poor OOD generalization, even with CoT.  
- Models without CoT or with only description CoT fail beyond very short distances (d∞≤5).  
- High token‑count CoT does not guarantee better ID performance; grid+description is more efficient.

**First 3 experiments:**  
1. **Baseline ID comparison:** Fine‑tune models with each input format (image, description, grid, table) either without CoT or with same‑format CoT. Measure ID accuracy on 3×3–6×6 maps. Expected outcome: text > image, CoT > no CoT.  
2. **Mixed CoT ablation:** For grid and table inputs, compare same‑format CoT vs. grid+description / table+description CoT on OOD maps (7×7–10×10, random d∞). Expected: mixed CoT yields non‑trivial OOD accuracy (>30% on 10×10).  
3. **Start‑goal distance isolation:** Train on 10×10 maps with embedded small maps (d∞≤5), test on 10×10 with d∞∈{2,…,9}. Expected: only grid+description CoT maintains accuracy at d∞≥6; others drop to near zero.

## Open Questions the Paper Calls Out
### Open Question 1
**Question:** Why does combining grid/table with description in CoT traces yield superior OOD generalization compared to single‑format CoTs?  
**Basis in paper:** Table 1 shows grid/table + description CoT achieves up to 41% OOD accuracy on 10×10 maps, while others drop to near 0%. The authors conjecture that grid/table aids progress tracking and description aids decision‑making (Sec 4.3), but provide no analysis.  
**Why unresolved:** The synergistic mechanism is unknown; it could be due to complementary information, representation structure, or training dynamics.  
**What evidence would resolve it:** Ablations removing one component; interpretability studies (attention, hidden states); testing on varied planning tasks.

### Open Question 2
**Question:** Are the advantages of text‑based inputs and mixed‑format CoT consistent across different multimodal LLM architectures?  
**Basis in paper:** The study uses only Qwen2.5‑VL‑7B‑Instruct due to budget constraints; the authors note that "Other models may interact slightly differently" (Limitations).  
**Why unresolved:** Results may be model‑specific; unknown if larger or differently trained models show the same pattern.  
**What evidence would resolve it:** Replicating experiments with a diverse set of models (e.g., GPT‑4V, Claude 3, LLaVA) and comparing format performances.

### Open Question 3
**Question:** What fundamental limitations cause transformer‑based LLMs to fail at algorithmic learning for planning tasks, resorting to brittle pattern matching?  
**Basis in paper:** The authors conclude that models "appear to be relying more on pattern matching than algorithmic learning" (Sec 5), citing prior work, but offer no theoretical explanation.  
**Why unresolved:** The root cause (inductive biases, training data, fine‑tuning objective) is unclear, hindering design of truly generalizable reasoning models.  
**What evidence would resolve it:** Theoretical analysis of transformers’ capacity for algorithmic tasks; controlled experiments varying model size, data distribution, and objectives (e.g., process‑based rewards).

## Limitations
- The exact prompt wording and CoT template formatting (e.g., grid cell separators, description phrasing) are not disclosed, risking replication gaps.
- The training distribution is narrow (maps ≤6×6, d∞≤5); OOD claims rely on relatively modest extrapolation.
- Neighboring work provides weak external validation for mixed‑format CoT in spatial planning, so the finding may be context‑specific.

## Confidence
- **Mixed‑format CoT enhances OOD robustness:** High (directly supported by Table 3/section 4.3).
- **Text inputs outperform image‑based:** High (consistent ID/OOD gaps across sections).
- **Models rely on pattern matching, not algorithmic learning:** Medium (inferred from OOD collapse; lacks direct mechanistic evidence).

## Next Checks
1. **Replicate with exact templates** – Use the (unreported) prompt and CoT formatting from the authors’ repository to verify mixed‑format superiority; divergence would indicate template sensitivity.
2. **Cross‑task generalization** – Apply the best configuration (grid+description CoT) to other grid‑planning environments (e.g., Maze, Sokoban) to test robustness across tasks.
3. **Mechanistic interpretability probe** – Analyze attention patterns or hidden‑state similarity across reasoning steps to determine whether models execute state tracking or memorize local configurations, directly probing the pattern‑matching hypothesis.
