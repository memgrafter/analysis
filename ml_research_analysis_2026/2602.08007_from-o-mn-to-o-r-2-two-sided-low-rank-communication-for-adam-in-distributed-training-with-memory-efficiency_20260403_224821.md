# From $O(mn)$ to $O(r^2)$: Two-Sided Low-Rank Communication for Adam in Distributed Training with Memory Efficiency

## Quick Facts
- **arXiv ID:** 2602.08007  
- **Source URL:** https://arxiv.org/abs/2602.08007  
- **Reference count:** 40  
- **Primary result:** Reduces per-step communication from $O(mn)$ to $O(r^2)$ while matching dense AdamW performance, cutting average communicated bytes per step by up to 25×.

## Executive Summary
Distributed training of large models is bottlenecked by gradient synchronization, especially for Adam-type optimizers that require dense gradient all‑reduce. TSR‑Adam replaces full‑gradient exchange with a two‑sided low‑rank scheme: each worker computes a compact core $U^\top G V \in \mathbb{R}^{r\times r}$ from shared orthonormal bases $U,V$; the cores are all‑reduced and used to reconstruct the gradient update inside the same low‑rank subspace. Adam’s moment estimates are stored as $r\times r$ matrices, drastically shrinking both communication and optimizer memory. A randomized SVD refresh exchanges only small sketches ($Q$, $Q^\top G$) to renew the bases without ever synchronizing the full gradient. The same idea extends to embedding layers with dedicated ranks and refresh schedules. Across pretraining of 60M–1B LLaMA models, TSR‑Adam lowers average communication by 13× and by 25× on GLUE fine‑tuning, with negligible accuracy loss.

## Method Summary
TSR‑Adam operates in data‑parallel training. For every matrix parameter $W\in\mathbb{R}^{m\times n}$, workers maintain orthonormal bases $U\in\mathbb{R}^{m\times r}$ and $V\in\mathbb{R}^{n\times r}$. Each step: compute local gradient $G_i$; project to core $C_i = U^\top G_i V$; all‑reduce $\bar{C}$; update Adam’s first and second moments ($m,v$) as $r\times r$ matrices in the core space; compute core step $D = \mathrm{Adam}(\bar{C}, m, v)$; lift to full update $\Delta W = U D V^\top$, then apply weight decay. Every $K$ steps, a refresh uses a shared Gaussian sketch $\Omega\in\mathbb{R}^{n\times k}$ ($k = r + p$): each worker computes $Y_i = G_i\Omega$, orthonormalizes to $Q_i$ (thin QR), optionally performs one power iteration, computes $B_i = Q_i^\top G_i$, and all‑reduces $Q_i$ and $B_i$. An SVD on the average $\bar{B}$ gives new bases $U,V$. Embedding layers are handled similarly with independent rank $r_\text{emb}$ and refresh interval $K_\text{emb}$. Non‑matrix parameters use dense AdamW.

## Key Results
- Pretraining 60M–1B models: average communicated bytes per step reduced by **13×** with comparable loss.  
- GLUE fine‑tuning: communication reduced by **25×**, minimal task accuracy drop.  
- Theoretical stationarity analysis supports convergence of the proposed update.

## Why This Works (Mechanism)

### 1. Core‑only synchronization
**Claim:** Synchronizing the low‑dimensional core $U^\top G V$ reduces per‑step communication from $O(mn)$ to $O(r^2)$ while keeping Adam’s moments in the same space.  
**Mechanism:** Orthonormal bases $U,V$ span the column and row subspaces of the gradient. The local core $C_i = U^\top G_i V$ captures the projection of $G_i$ onto these subspaces. After all‑reduce, the full gradient is approximated by $U\bar{C}V^\top$. Adam updates $m,v$ as $r\times r$ matrices using $\bar{C}$, avoiding full‑size states.  
**Core assumption:** The true gradient $G$ lies approximately in the column space of $U$ and row space of $V$, so $U C V^\top$ is accurate.  
**Evidence anchors:** Abstract, Section 3.3, and neighboring communication‑reduction papers.  
**Break condition:** If $r$ approaches $\min(m,n)$ (especially when one dimension is small), $O(r^2)$ may exceed one‑sided $O(rn)$, eroding the advantage.

### 2. Randomized SVD refresh without full‑gradient exchange
**Claim:** A randomized SVD‑based refresh avoids full‑gradient synchronization, drastically lowering peak communication on refresh steps.  
**Mechanism:** Every $K$ steps, workers sample a shared Gaussian matrix $\Omega$ ($n\times k$ with $k=r+p$). Each computes $Y_i = G_i\Omega$, orthonormalizes to $Q_i$ (thin QR), optionally applies one power iteration, then computes $B_i = Q_i^\top G_i$. Only the sketches $Q_i$ ($m\times k$) and $B_i$ ($k\times n$) are all‑reduced. An SVD on the averaged $\bar{B}$ yields new bases $U,V$. The full gradient is never communicated.  
**Core assumption:** Randomized SVD with oversampling $p$ and optional power iterations reliably captures the dominant subspace even from sketches.  
**Evidence anchors:** Abstract, Section 3.5, and prior work on sketch‑based orthonormalization.  
**Break condition:** Extremely flat or abruptly changing gradient spectra may cause inaccurate bases, leading to stale projections and convergence degradation.

### 3. Dedicated handling of embedding layers
**Claim:** Applying two‑sided low‑rank communication to embedding matrices with separate ranks and refresh schedules yields additional communication and memory savings.  
**Mechanism:** For the embedding matrix $E\in\mathbb{R}^{|\mathcal{V}|\times d}$, independent bases $U_\text{emb}\in\mathbb{R}^{|\mathcal{V}|\times r_\text{emb}}$, $V_\text{emb}\in\mathbb{R}^{d\times r_\text{emb}}$ are maintained. The core $C_\text{emb}=U_\text{emb}^\top G_\text{emb} V_\text{emb}$ is synchronized analogously, with its own refresh interval $K_\text{emb}$. This decouples embedding compression from linear layers, useful because embedding dimensions differ and embeddings often dominate communication in smaller models.  
**Core assumption:** Embedding gradients also admit a low‑rank structure and benefit from independent hyperparameters.  
**Evidence anchors:** Abstract and Section 3.6.  
**Break condition:** If $r_\text{emb}$ is too small, the approximation error may harm model quality, especially with large vocabularies.

## Foundational Learning
- **Low‑rank matrix approximation**  
  *Why needed:* TSR‑Adam represents a large gradient as $U C V^\top$; understanding projection and reconstruction error $\|G - U C V^\top\|_F$ is essential.  
  *Quick check:* Given orthonormal $U,V$, what is the optimal core $C$ minimizing Frobenius error? (Answer: $C = U^\top G V$.)

- **Adam optimizer**  
  *Why needed:* Adam’s adaptive updates are adapted to the low‑rank core space; bias correction and element‑wise scaling appear in the analysis and implementation.  
  *Quick check:* In Adam, what do $\beta_1$ and $\beta_2$ control, and why is bias correction applied? (Answer: $\beta_1$ decays the first moment (momentum), $\beta_2$ decays the second moment (scale); bias correction compensates for initialization bias.)

- **Distributed data‑parallel training**  
  *Why needed:* The setting is data parallelism where all‑reduce of gradients is the main communication bottleneck.  
  *Quick check:* Which collective operation aggregates gradients from all workers? (Answer: All‑reduce.)

- **Randomized SVD**  
  *Why needed:* The refresh mechanism uses sketching ($G\Omega$) and orthonormalization to approximate top singular vectors without full‑gradient exchange.  
  *Quick check:* How does oversampling $p>0$ improve accuracy? (Answer: It captures more of the tail singular values, reducing error for non‑rapidly decaying spectra.)

## Architecture Onboarding
**Component map:**  
Worker → (local gradient) → All-reduce (cores or sketches) → Worker (update moments/reconstruct)  
Refresh controller → triggers refresh every $K$ steps → Worker generates sketches → All-reduce sketches → SVD → new bases $U,V$ → Worker  

**Critical path (non‑refresh step, single layer):**  
1. Forward/backward → $G_i$.  
2. Compute core $C_i = U^\top G_i V$.  
3. `all_reduce(C_i)` → $\bar{C}$.  
4. Update $m \leftarrow \beta_1 m + (1-\beta_1)\bar{C}$, $v \leftarrow \beta_2 v + (1-\beta_2)\bar{C}\odot\bar{C}$.  
5. Bias‑correct $\hat{m},\hat{v}$; compute $D = \hat{m} \oslash (\sqrt{\hat{v}}+\epsilon)$.  
6. Lift update $\Delta W = U D V^\top$.  
7. Apply weight decay: $W \leftarrow W - \eta (\Delta W + \lambda W)$.

**Design tradeoffs:**  
- **Rank $r$:** Larger $r$ ↓ approximation error but ↑ $O(r^2)$ communication and $2r^2$ moment memory.  
- **Refresh interval $K$:** Smaller $K$ fresher bases, ↓ error but ↑ peak communication; larger $K$ ↑ staleness risk.  
- **Embedding rank $r_\text{emb}$ and $K_\text{emb}$:** Independent tuning; often $r_\text{emb} \ll r$ and $K_\text{emb}$ larger due to slower subspace drift.  
- **Oversampling $p$ and power iterations $q$:** ↑ accuracy of randomized SVD at modest local compute cost.

**Failure signatures:**  
- Loss plateau/rise → likely $r$ too small or $K$ too large.  
- Unexpected peak communication spikes → may indicate refresh overhead too high.  
- Memory not reduced → verify moments stored as $r\times r$, not full‑size.  
- Convergence slower than dense Adam → consider subspace tracking issues.

**First 3 experiments:**  
1. **One‑sided vs. two‑sided compression:** Compare GaLore and TSR‑Adam on LLaMA‑60M with comparable total rank; expect TSR to cut communication by ~2/3 with negligible loss difference.  
2. **Normal SVD vs. randomized SVD:** Replace randomized refresh with exact SVD (full‑gradient all‑reduce on refresh); compare loss, bytes/step, and refresh time. Expect similar loss but ~2× higher communication and refresh time for exact SVD.  
3. **Refresh interval $K$:** Test $K \in \{20,50,100,200\}$ on LLaMA‑60M; anticipate $K=100$ best balances loss vs. communication; $K=20$ adds overhead, $K=200$ degrades loss.

## Open Questions the Paper Calls Out
- **Convergence with full AdamW (bias correction):** The analysis assumes a simplified momentum variant; does TSR‑Adam converge when using AdamW’s bias correction?  
- **Optimal hyperparameter selection:** How to choose refresh interval $K$ and oversampling $p$ across layers and model scales to minimize communication without sacrificing accuracy?  
- **Combination with gradient quantization:** Can TSR‑Adam be combined with quantization (e.g., 8‑bit, 1‑bit) for further savings, and what are the convergence guarantees?  
- **Intrinsic rank requirements:** What determines the minimum rank $r$ needed to match dense AdamW performance, and how does it relate to gradient spectrum geometry?

## Limitations
- Rank allocation per layer is not specified; uniform $r$ may be inefficient.  
- Randomized SVD hyperparameters ($p$, $q$) are chosen heuristically, not tuned per model.  
- Embedding‑specific refresh interval $K_\text{emb}$ is not defined and may differ from linear $K$.  
- The assumption of low‑rank gradients may not hold for all layers, increasing error.  
- Sketch communication on refresh is $O(r(m+n))$, still dependent on model dimensions.

## Confidence
- **Core communication reduction (mechanism 1):** High  
- **Randomized SVD refresh (mechanism 2):** High  
- **Embedding extension (mechanism 3):** Medium
