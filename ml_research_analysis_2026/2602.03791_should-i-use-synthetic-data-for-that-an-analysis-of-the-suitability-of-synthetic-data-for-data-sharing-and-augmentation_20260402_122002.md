# Should I use Synthetic Data for That? An Analysis of the Suitability of Synthetic Data for Data Sharing and Augmentation

## Quick Facts
- **arXiv ID:** 2602.03791
- **Source URL:** https://arxiv.org/abs/2602.03791
- **Reference Count:** 18
- **Primary Result:** Synthetic data suitability is highly conditional; each use case (sharing, ML augmentation, statistical estimation) faces distinct fundamental constraints that often render proposed applications a poor fit.

## Executive Summary
This paper provides a rigorous analysis of synthetic data's suitability for three primary use cases: serving as a privacy-preserving proxy for proprietary data sharing, augmenting machine learning training sets, and augmenting data for statistical estimation. The core finding is that synthetic data is not a universal solution. For data sharing, fundamental privacy-utility trade-offs (via the law of information recovery) prevent simultaneous guarantees of validity for arbitrary analyses and strong privacy. For ML augmentation, improvements over using only real data require an external augmentation source that contains complementary information about the target deployment distribution, along with accessible validation data from that target. For statistical estimation, naive use of synthetic data invalidates standard inference; specialized, and currently limited, procedures are necessary. The paper concludes that successful application demands precise problem formulation and awareness of these conditional constraints.

## Method Summary
The paper's analysis combines formal theoretical modeling with empirical case studies. It formally defines each use case (Sharing, ML Augmentation, Estimation) with precise notation for the base data, synthetic generator, and objective. The theoretical work establishes impossibility results (e.g., privacy-validity trade-off) and necessary conditions (e.g., requirement for external information sources). Case studies illustrate these principles using real-world data (e.g., US Census for sharing, clinical trials for augmentation, diffusion models for fairness). A minimum viable reproduction for the ML augmentation use case involves: selecting a classification task with a minority subgroup (e.g., UCI Adult), artificially undersampling to create a base distribution *P* and a target distribution *Q*, generating synthetic data via bootstrapped (GAN on *P*) and external (GAN on full data) methods, and comparing model performance (overall and subgroup) on a held-out test set from *Q*.

## Key Results
- **Sharing as Proxy:** It is impossible for a synthetic dataset to simultaneously guarantee statistical validity for a broad, arbitrary family of analyses and preservation of individual privacy due to the fundamental law of information recovery. Validity + privacy is only possible for narrow, pre-specified analysis families using specialized, privacy-aware generators.
- **ML Augmentation:** Augmentation with synthetic data generated solely from the base dataset (*bootstrapped*) yields at most modest, in-distribution gains. Any meaningful improvement for a *target distribution Q* requires an external augmentation source containing complementary information about Q and access to validation data from Q.
- **Statistical Estimation:** Naively treating synthetically augmented data as real samples invalidates standard confidence intervals and tests (incorrect coverage, inflated Type I error). Valid inference requires specialized procedures (e.g., Prediction-Powered Inference) that explicitly account for synthetic data error, but these are currently limited in scope.

## Why This Works (Mechanism)

### Mechanism 1: The Privacy-Validity Trade-off in Data Sharing
- **Claim:** Synthetic data cannot simultaneously guarantee statistical validity for arbitrary analyses and preservation of individual privacy.
- **Mechanism:** The *fundamental law of information recovery* states that a dataset providing sufficiently accurate answers to a large enough collection of statistical queries inherently allows an adversary to reconstruct private individual records. If the synthetic dataset is guaranteed valid for a set of analyses F_use, it contains enough information for reconstruction attacks.
- **Core assumption:** The primary goal is protection against membership disclosure or record reconstruction.
- **Evidence anchors:** Abstract and Section 2.3 explicitly link validity guarantees for F_use to reconstruction vulnerability. Corpus context shows this is a theoretical bedrock for privacy research.
- **Break condition:** The intended analysis family F_use is narrow, pre-specified, and compatible with specialized generators (e.g., those preserving low-order marginals). Validity for that specific family can be formally guaranteed with privacy.

### Mechanism 2: The Need for Complementary Information in ML Augmentation
- **Claim:** Bootstrapped augmentation (synthetic data from the base dataset alone) provides at most modest gains; improvement for a target distribution Q requires an external source with complementary Q-relevant information.
- **Mechanism:** The model's generalization error L_Q(θ_aug) vs. L_Q(θ_base) depends on whether augmentation introduces new information about Q not in S_base ~ P. Bootstrapped augmentation only samples from P, so it cannot add information about Q if P ≠ Q. An external source S_aug can bridge the gap if it encodes information about Q.
- **Core assumption:** The goal is to improve performance on a target distribution Q different from the base distribution P, with access to validation data from Q.
- **Evidence anchors:** Abstract and Section 3.2 state that misaligned augmentation sources cannot be expected to help. Case studies align with distribution shift literature.
- **Break condition:** A suitable, accessible external augmentation source S_aug exists that shares information with Q, **and** a representative validation set from Q is available to empirically confirm improvement.

### Mechanism 3: Invalidity of Naive Statistical Inference with Synthetic Data
- **Claim:** Applying standard statistical methods (e.g., sample mean) to synthetically augmented data yields invalid inferences (incorrect coverage, inflated errors).
- **Mechanism:** Standard estimators assume all observations are independent samples from the target population. Synthetic data are generated from a model G, introducing dependent, biased structure. Treating them as real ignores this extra randomness, breaking probabilistic guarantees.
- **Core assumption:** The objective is valid inference (correct CI coverage, test error rates) on a population parameter θ. Synthetic data is used to reduce variance but does not perfectly replicate the true data-generating process.
- **Evidence anchors:** Abstract and Section 4.2 state that naive application is invalid and specialized procedures like PPI are necessary. Corpus shows active methodological work on imputation and PPI.
- **Break condition:** The practitioner uses a formally validated procedure (e.g., PPI, multiple imputation) that provides provable validity guarantees for their specific estimator and augmentation scheme, **and** the augmentation quality meets the required conditions for those guarantees.

## Foundational Learning
- **Differential Privacy & Reconstruction Attacks:** Needed to understand the theoretical trade-off in data sharing. Differential privacy provides a formal guarantee, but reconstruction attacks define its limits. *Quick check:* If a synthetic dataset perfectly preserves all 2-way marginals, the fundamental law implies an adversary can reconstruct private records, violating strong privacy.
- **Distribution Shift & Domain Generalization:** Central to assessing ML augmentation. Distinguishing in-distribution regularization (bootstrapped) from out-of-distribution generalization (requires external source) is critical. *Quick check:* Augmenting a hospital's historical records with synthetic data unlikely helps a model deployed at a different hospital with a different patient population because the augmentation source lacks information about the new population.
- **Validity vs. Utility in Statistical Inference:** Needed to contrast Mechanism 3. Synthetic data can improve a point estimate's variance (utility) while destroying valid uncertainty quantification (validity). *Quick check:* Synthetic augmentation can reduce MSE on the observed (synthetic+real) dataset while causing a 95% CI to cover the true parameter only 80% of the time because synthetic data introduces dependence and bias ignored by standard formulas.

## Architecture Onboarding
Use Case Classifier -> Analysis Family / Target Specifier -> Data Source Inventory -> Generative Model -> Validation & Evaluation Harness -> Decision Engine

**Critical Path:**
1.  **Problem Formalization:** Unambiguously state the goal: replicate analyses (Sharing), improve a learned model's performance (ML Aug), or reduce variance of a statistical estimate (Estimation).
2.  **Feasibility Prerequisite Check:** For Sharing: Is F_use narrow and known? For ML Aug: Is there an external S_aug *and* a T ~ Q? For Estimation: Is there a valid PPI-style procedure for your estimand?
3.  **Generator Specification:** Select/design G constrained by the prerequisite (e.g., DP algorithm for Sharing, external-source-conditioned model for ML Aug).
4.  **Validation Execution:** Run the appropriate harness. The harness must be designed with what it can and cannot measure (e.g., internal validation on S_base is meaningless for ML Aug if Q != P).
5.  **Suitability Verdict:** Apply decision logic: if prerequisites fail, synthetic data is unsuitable. If they pass, proceed with transparency about remaining limitations.

**Design Tradeoffs:**
- **Sharing:** Privacy budget (ε) vs. number/type of queries preserved (size/complexity of F_use).
- **ML Augmentation:** Fidelity to S_aug vs. diversity of generated samples. Overfitting S_aug hurts generalization to Q if S_aug is noisy.
- **Estimation:** Synthetic sample size vs. model bias. More synthetic samples reduce variance but amplify systematic bias if the procedure isn't validity-preserving.

**Failure Signatures:**
- **Sharing:** Reconstruction attack succeeds on shared ˜S. Empirical fidelity (F_test) is high, but a new, simple query f' not in F_test yields wildly inaccurate f'(˜S).
- **ML Augmentation:** Model performance on *internal* validation (from P) improves but degrades on *target* test set T ~ Q. Gains vanish or reverse with slightly different S_aug.
- **Estimation:** Coverage probability of a CI built from (S_base, ˜S) deviates significantly from nominal level (e.g., 95% CI covers true θ only 80% of the time) in simulation studies.

**First 3 Experiments:**
1.  **Reconstruction Attack Sanity Check (Sharing):** Run a known membership inference or reconstruction attack (e.g., Dinur & Nissim) on the proposed synthetic dataset ˜S. Success immediately violates privacy.
2.  **Baseline Comparison & Ablation (ML Augmentation):** Train models on (a) S_base only, (b) S_base + bootstrapped synthetic, (c) S_base + external synthetic. Compare L_Q on the *target validation set T*. If (b) is not better than (a) and (c) is not better than (b), the external source provides no complementary information.
3.  **Coverage Validation via Simulation (Estimation):** Using a simulator with known true θ, apply the planned ˆθ(S_base, ˜S) and its claimed valid CI procedure over many repetitions. Measure actual coverage. Failure indicates the method's guarantees are not met.

## Open Questions the Paper Calls Out
- **Open Question 1:** What is the precise boundary of analysis families for which synthetic data can simultaneously achieve differential privacy and bounded statistical error? Can we formally characterize this trade-off for modern generative models like diffusion models?
- **Basis:** "Extending the available toolbox to support more complex analysis families with validity guarantees is an important direction for future research." (Section 2.5)
- **Why unresolved:** The fundamental trade-off is clear, but exact thresholds for complex analyses (e.g., causal inference) and state-of-the-art DP synthetic methods are unknown. Current tools handle only low-order marginals.
- **What evidence would resolve it:** Theoretical bounds linking query complexity, privacy loss ε, and generative model family; empirical validation on diverse complex analysis families using DP synthetic data; a complexity-theoretic classification of feasible query classes.

- **Open Question 2:** How can practitioners reliably evaluate whether synthetic data augmentation will improve a machine learning model’s performance on a target distribution when no labeled data from that distribution is available for validation?
- **Basis:** "Without access to representative test data from the target distribution during development, the hospital has no way to validate that its augmentation strategy is appropriate for external deployment." (Section 3.3)
- **Why unresolved:** The lack of target validation often motivates augmentation, creating a circular dependency. Existing heuristics (distribution similarity) may not correlate with actual performance.
- **What evidence would resolve it:** Development of robust proxy metrics computable from base/synthetic data that strongly predict true target improvement; large-scale benchmarking across domain shifts to validate such proxies.

- **Open Question 3:** Can we design valid inference procedures (e.g., confidence intervals with correct coverage) for datasets augmented with fully synthetic records, supporting arbitrary estimands such as causal parameters?
- **Basis:** "Extending these methods to broader settings is an important research direction." (Section 4.4) and "most of the methods above only apply to partially imputed data, and the study of guarantees with fully synthetic data has only started recently."
- **Why unresolved:** Existing frameworks (e.g., PPI) assume partial imputation; fully synthetic data introduces different biases. No general theory guarantees validity for complex estimands like hazard ratios.
- **What evidence would resolve it:** Theoretical extensions of PPI to fully synthetic data; empirical demonstration of correct coverage for non-linear/causal estimands; a general framework based on influence functions or doubly robust estimation.

- **Open Question 4:** What combination of empirical evaluations (e.g., fidelity metrics, privacy audits, downstream task checks) provides the most reliable indicator that synthetic data is suitable for a specific high-stakes application when direct testing on the true target is infeasible?
- **Basis:** Concluding remarks: "The problem of verifying or ensuring that synthetic data achieves its intended goal... results remain in an epistemic limbo." and the decision chart suggests conditions but not concrete protocols.
- **Why unresolved:** No standardized validation suite exists; practitioners often rely on limited metrics (e.g., pairwise marginal preservation) that may not capture task-specific utility.
- **What evidence would resolve it:** A comprehensive benchmarking study comparing evaluation protocols across multiple synthetic methods and downstream tasks; development of a risk assessment framework (e.g., synthetic data cards) for transparent reporting.

## Limitations
- The precise quantitative boundary for "narrow, predefined analysis family" in sharing remains vague; operationalizing "simultaneously valid" for practical F_use lacks a universal metric.
- The condition of "complementary target-domain information" in the augmentation source is necessary but not formally characterized; no pre-diagnostic measure exists to determine if an external S_aug qualifies before validation.
- Specialized inference procedures (e.g., PPI) are theoretically sound but have limited empirical scope beyond linear/GLM settings and may require strong model calibration assumptions.

## Confidence
- **Sharing (Privacy-Validity Trade-off):** High. The impossibility for arbitrary F_use is theoretically solid based on the fundamental law of information recovery.
- **ML Augmentation (Need for External Source):** Medium. The requirement for external Q-relevant information is logically sound and empirically supported, but the "modest gains" from bootstrapped augmentation may vary by generative model and task.
- **Statistical Estimation (Invalidity of Naive Use):** High. The invalidity of standard methods is well-established. Medium confidence in the universality and current practicality of specialized corrections beyond simple estimators.

## Next Checks
1.  **For Sharing:** Implement a known reconstruction attack (e.g., membership inference) on a synthetically shared dataset claiming broad validity. Success would falsify the claim of simultaneous privacy and arbitrary-analysis utility.
2.  **For ML Augmentation:** Conduct an ablation where the external augmentation source S_aug is systematically altered (e.g., by adding label noise or shifting feature distributions) to identify the minimal "complementary information" threshold needed for improvement on a held-out T ~ Q.
3.  **For Estimation:** Run a Monte Carlo simulation study for a non-linear estimand (e.g., a quantile) using a state-of-the-art PPI implementation. Measure coverage degradation when the synthetic data generator G is misspecified (e.g., a GAN trained on insufficient data).
