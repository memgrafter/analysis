# Dataset Distillation Efficiently Encodes Low-Dimensional Representations from Gradient-Based Learning of Non-Linear Tasks

## Quick Facts
- **arXiv ID:** 2603.14830
- **Source URL:** https://arxiv.org/abs/2603.14830
- **Reference count:** 40
- **Primary result:** Gradient-based dataset distillation for two-layer ReLU networks on multi-index models compresses data by first encoding the low-dimensional principal subspace with only Θ(r²) synthetic points and then reconstructing the second-layer parameters with Θ(L) points, reducing overall memory from Θ(d³ ∨ d²/ϵ ∨ d/ϵ⁴ ∨ dL) to ~Θ(r²d + L).

## Executive Summary
This paper provides a theoretical analysis of gradient-based dataset distillation (DD) for two-layer ReLU networks trained on multi-index models—nonlinear tasks with an intrinsic low-dimensional structure. The authors introduce a progressive two-phase distillation framework. They prove that the first distilled set captures the principal r-dimensional subspace of the task using only M₁ = Θ(r²) samples. The second distilled set then encodes the linear second-layer parameters with M₂ = Θ(L) samples, enabling near-original generalization when retraining from a reference initialization. The theory shows a dramatic reduction in memory cost compared to training on the full dataset, and experiments on synthetic single- and multi-index models confirm the findings, including effective transfer learning when the first distilled set is reused across related tasks.

## Method Summary
The method is a progressive two-phase dataset distillation algorithm applied to a two-layer ReLU network learning a multi-index model. In phase 1, gradient matching (GM) distills a set D_S₁ of size M₁ = Θ(r²) to encode the principal subspace S* underlying the target function. The teacher network is trained on the full data, and synthetic points are updated so that their gradients match the average teacher gradients across multiple random initializations. After retraining the first-layer weights W from a reference initialization on D_S₁, phase 2 begins. The first layer is frozen, biases are re-initialized, and the second-layer weights a are trained via ridge regression on the fixed features. A second distilled set D_S₂ of size M₂ = Θ(L) is constructed with inputs designed to ensure a full-rank kernel matrix. Labels for D_S₂ are optimized via one-step GM or performance matching (PM) to reconstruct the teacher’s a. The final student model is obtained by retraining a (with W fixed) from zero on D_S₂. The overall memory cost is M₁d + M₂d + L ≈ r²d + L.

## Key Results
- The first distilled set requires only M₁ = Θ(r²) samples to preserve the low-dimensional structure of a multi-index model with intrinsic dimension r.
- The total memory cost to achieve test error ≤ ϵ is reduced from Θ(d³ ∨ d²/ϵ ∨ d/ϵ⁴ ∨ dL) (full-data training) to ~Θ(r²d + L).
- For single-index tasks (r=1), a single synthetic point suffices for phase 1.
- A regularity condition on the kernel matrix and an explicit construction for D_S₂ inputs guarantee that phase 2 reconstructs the second-layer parameters with high accuracy.
- Transfer learning experiments show that D_S₁ distilled for one activation can be reused to pre-train W for a different activation sharing the same principal subspace, significantly reducing data needs.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** The first distillation phase encodes the principal subspace S* of the multi-index task into synthetic data.
**Mechanism:** Gradient matching updates synthetic inputs x̃(1) so that their alignment with the Hessian H of the target function f* emerges from the population gradient. The empirical gradient across many initializations concentrates around H x̃, effectively projecting synthetic points onto S* (Theorem 4.1, Lemma B.14).
**Core assumptions:** The task follows a multi-index model with well-conditioned Hessian (Assumption 3.3), symmetric initialization, and a student activation h with bounded derivatives (Assumption 3.8; analysis uses a smooth surrogate, experiments use ReLU).
**Evidence anchors:** Abstract: "We prove that the low-dimensional structure of the problem is efficiently encoded into the resulting distilled data." Section 4.1: "We show that the teacher gradient extracts information from the principal subspace … leading to DS1 projected onto S*."
**Break condition:** Requires M₁ ≥ ~Θ(r²) samples; fails if H is ill-conditioned, batch size J is too small, or initialization is not symmetric.

### Mechanism 2
**Claim:** The second distilled dataset DS₂ enables reconstruction of the second-layer parameters a* with only ~Θ(L) memory, achieving near-original generalization.
**Mechanism:** After phase 1, training reduces to linear ridge regression on fixed features (W). One-step GM or PM with synthetic points satisfying the regularity condition (full-rank kernel matrix) encodes a* into DS₂ labels; retraining from a=0 recovers a* with the same error bound (Theorem 4.5).
**Core assumptions:** Phase 2 is linear regression; DS₂ initialization yields a kernel matrix of maximum attainable rank (Assumption 4.4).
**Evidence anchors:** Abstract: "This dataset reproduces a model with high generalization ability for a required memory complexity of ~Θ(r²d+L)." Section 4.2: "Under regularity condition 4.4, one-step GM and one-step PM can directly create DS₂ that reconstructs the final layer."
**Break condition:** If DS₂ kernel rank is deficient (e.g., duplicate points or bias not exploited), reconstruction fails; requires M₂ ≥ L and careful construction (Lemma B.38).

### Mechanism 3
**Claim:** Progressive distillation separates low-level feature capture from high-level parameter tuning, yielding transferable compressed representations.
**Mechanism:** The two-phase approach isolates information: DS₁ captures the principal subspace (transferable across tasks sharing S*), while DS₂ encodes specific second-layer weights. This avoids mixing and creates compact summaries for each phase.
**Core assumptions:** Optimization dynamics decouple into feature learning (phase 1) and linear head training (phase 2) as in the analyzed procedure.
**Evidence anchors:** Section 6: "Distilling earlier training phases may capture intrinsic features that are not captured later." Section 5.2: Transfer learning experiment shows DS₁ from one σ* can be fine-tuned for a new σ* with little data.
**Break condition:** Benefits diminish if the network lacks clear phase separation (e.g., shallow nets, batch normalization) or if tasks have different S*.

## Foundational Learning
- **Dataset Distillation (DD):** Goal is to compress training data into small synthetic sets that reproduce model performance. Algorithms include gradient matching (match gradients) and performance matching (match training loss). *Why needed:* The paper’s analysis focuses specifically on gradient-based DD. *Quick check:* What is the key difference in the objectives of PM and GM?
- **Multi-index Model:** A nonlinear target f*(x)=σ*(Bᵀx) with intrinsic dimension r (column space of B is S*). *Why needed:* Defines a class of low-dimensional nonlinear tasks to analyze. *Quick check:* How does intrinsic dimension r affect the size of the first distilled set M₁?
- **Feature Learning via Gradient Descent:** For two-layer networks, gradient descent on the first layer learns features aligned with the Hessian of the target. *Why needed:* The mechanism for phase 1 relies on gradients concentrating along the principal subspace. *Quick check:* What property of H ensures that gradient matching captures S*?
- **Progressive Distillation:** Splits training into phases with separate synthetic sets. *Why needed:* Allows isolating the encoding of low-dimensional structure from parameter-specific tuning. *Quick check:* Why might a single-phase distillation be insufficient for deep networks?

## Architecture Onboarding
Component map:
Original Dataset D_T → Teacher Training (Phase 1: GD on W) → Compute Gradients (J initializations) → Distillation Update (GM on D_S₁) → Retrain W on D_S₁ → Freeze W, Reinitialize b → Teacher Training (Phase 2: GD on a) → Compute Gradient Sum G_sum → Construct D_S₂ inputs (full-rank kernel) → Distillation Update (GM/PM on D_S₂ labels) → Retrain a on D_S₂ → Final Student Model.

Critical path:
1. Preprocess D_T (center y and x: α, γ).
2. Phase 1: For j=0..J, run teacher and student on D_T and D_S₁; compute gradient alignment loss m; update D_S₁ via ∇_{D_S₁} m with step η_D¹; retrain W from reference θ⁽⁰⁾ on D_S₁ with step η_R¹.
3. Reinitialize biases b ~ N(0,I).
4. Phase 2: Sample new J initializations for a (including a₀=0). Run teacher GD on a for ξ_T² steps, accumulating G_sum,j. Construct D_S₂ inputs x_m using direction v and hinge points τ_i (Lemma B.38). Initialize labels y_m=0. Compute student one-step gradients g_S,j on D_S₂; loss m₂ = average alignment of G_sum,j and g_S,j; update y via ∇_y m₂ with η_D² = M₂·η_T².
5. Retrain a from 0 on D_S₂ to convergence.
6. Return D_S₁ ∪ D_S₂.

Design tradeoffs:
- Memory vs compute: Storage reduced to ~Θ(r²d+L) but computation increased by J initializations and multiple teacher-student loops.
- GM vs PM: GM has higher distillation cost (second-order gradients) but lower retraining cost; PM opposite (Section 6).
- DS₁ size: Must be at least ~Θ(r²) to capture subspace; scaling depends on r, not d.
- DS₂ regularity: Kernel matrix must achieve maximum rank; compact construction exists (Lemma B.38) but requires careful bias handling and M₂ ≈ 2(L+1).

Failure signatures:
- Phase 1: Synthetic inputs fail to align with principal subspace (check projection onto top eigenvectors of data covariance or H). Could be due to small J, N, ill-conditioned H, or unstable η_D¹.
- Phase 2: Retraining error much larger than teacher’s; likely DS₂ kernel rank deficiency (compute rank of K̃). Also if L large and M₂ < L, rank limited.
- Overall: If M₁ scales with d, not r², low-dimensional structure not leveraged; revisit task assumptions or initialization symmetry.

First 3 experiments:
1. **Single-index validation:** Set r=1, d=10, L=100. Distill D_S₁ with M₁=1. Vary N and J*; test MSE should match full-data training for large N, J* (replicate Figure 1 left).
2. **Multi-index scaling:** Increase r (e.g., 2,4,6). Measure required M₁ to match teacher performance; expect scaling ~r² (replicate Figure 1 right).
3. **Transfer learning:** Distill D_S₁ using one activation σ* (e.g., degree-4 polynomial). Freeze W from that distillation, then fine-tune a on a new task with different activation σ_g (e.g., He₃/√3!) but same β. Compare sample complexity vs. random W initialization (replicate Figure 2).

## Open Questions the Paper Calls Out
- **Extension to deeper networks:** The analysis is limited to two-layer networks; extending the theory to deeper architectures and more general initialization strategies is an open problem.
  - *Basis:* The authors state that extending to deeper networks "is left for future work" and note that "The initialization of DS₁ and DS₂ may also look too model‑specific."
  - *Why unresolved:* Current analysis relies on explicit dynamics of two-layer training; deeper networks involve more complex feature learning.
  - *What evidence would resolve it:* A theoretical framework (e.g., mean-field or tensor methods) for arbitrary depth, plus experiments on standard deep networks showing similar compression.
- **Generality beyond multi-index models:** Whether the memory complexity bounds hold for more realistic task distributions (e.g., manifold-structured data, hierarchical composition) is unknown.
  - *Basis:* The authors identify as a limitation that "the function class we analyze, that of multi‑index models, may not fully represent practical settings."
  - *Why unresolved:* Real-world data often have more complex low-dimensional structure not captured by the multi-index form.
  - *What evidence would resolve it:* Generalizing the analysis to broader function classes (additive models, manifolds) and empirical validation on real datasets.
- **Improving polynomial dependencies:** The required batch size J scales as a high polynomial in d (e.g., d⁴); it is unclear if these exponents are fundamental or can be improved.
  - *Basis:* The paper notes that "J scales with d" and expects "the exponents can be improved."
  - *Why unresolved:* Current bounds may be artifacts of proof techniques; lower bounds are unknown.
  - *What evidence would resolve it:* Tighter theoretical bounds with smaller exponents, lower‑bound proofs, and empirical success with smaller J than theory predicts.

## Limitations
- Theoretical step sizes (η_D¹, η_R¹, η_T², etc.) and regularization are given asymptotically; concrete values require empirical tuning, which may affect reproducibility.
- Analysis requires a large effective batch size J* ≳ d⁴ and a well‑conditioned Hessian; these conditions may not hold in practice, breaking the subspace encoding guarantee.
- The theory uses a smooth surrogate activation for second-order gradients, while implementations often use ReLU, leading to potential numerical instability.
- The assumed phase separation (feature learning then linear head training) is strong; architectures with batch normalization or different training dynamics may not decouple.
- Transferability claims are based on a single experiment with a shared subspace; broader validation across diverse tasks and subspaces is lacking.

## Confidence
- **Mechanism 1 (Phase 1 encodes principal subspace):** Medium. Theory and synthetic results support it, but sensitivity to Hessian conditioning and batch size is high.
- **Mechanism 2 (Phase 2 reconstructs second-layer parameters):** Medium. The regularity condition is theoretically sufficient but practically delicate; experiments on synthetic data are promising but not broadly validated.
- **Mechanism 3 (Progressive distillation yields transferable representations):** Low. Evidence is limited to one transfer setting; broader validation across diverse tasks and subspaces is lacking.

## Next Checks
1. **Vary J* below threshold:** Train with decreasing J* (e.g., 10³, 10², 10¹) and measure alignment of learned first-layer principal subspace with true β (cosine similarity). Expect degradation when J* ≪ d⁴.
2. **Stability under activation choice:** Implement phase 1 with ReLU vs. softplus; monitor synthetic point norms and test MSE. Large divergence or NaNs with ReLU would confirm sensitivity to smoothness assumptions.
3. **Cross-subspace transfer evaluation:** Distill D_S₁ using one subspace S* (direction β), then fine‑tune the second layer on a new task with a different subspace S′ (e.g., rotated β′). Compare sample efficiency against random initialization to test true transferability.
