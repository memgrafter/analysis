# Predicting Anemia Among Under-Five Children in Nepal Using Machine Learning and Deep Learning

## Quick Facts
- **arXiv ID:** 2602.01005
- **Source URL:** https://arxiv.org/abs/2602.01005
- **Reference count:** 40
- **Primary result:** Machine learning and deep learning models effectively predict childhood anemia in Nepal using sociodemographic proxies; logistic regression achieved recall 0.701 and F1-score 0.649, DNN attained accuracy 0.709, and SVM yielded AUC 0.736.

## Executive Summary
This study leverages the Nepal Demographic and Health Survey (NDHS) 2022 data to predict anemia among children aged 6–59 months. With 1,855 children and 48 initial features, the authors apply four feature selection techniques to identify 13 key predictors, including child age, recent fever, household size, maternal anemia, and parasite deworming. They compare eight traditional machine learning classifiers and two deep learning models, addressing class imbalance via SMOTE. Logistic regression, DNN, and SVM each excel in different metrics, demonstrating that sociodemographic and health proxies can be effectively used for risk stratification in resource-limited settings.

## Method Summary
The study performs binary classification of anemia status using NDHS 2022 microdata. After data cleaning and imputation, 48 sociodemographic, maternal, and child health features are reduced to 13 through consensus among four feature selection methods (Chi-square, mutual information, point-biserial correlation, Boruta). All features are converted to categorical. The dataset is split 80% train / 20% test (stratified). Class imbalance is handled with SMOTE, integrated into an imbalanced-learn pipeline to avoid data leakage. Eight traditional ML models (LR, KNN, DT, RF, XGBoost, SVM, NB, LDA) and two DL models (DNN, TabNet) are trained. Hyperparameter tuning uses GridSearchCV with repeated stratified 5-fold cross-validation (3 repeats), optimizing primarily for F1-score due to imbalance. Performance is evaluated on the held-out test set using accuracy, precision, recall, F1-score, AUC, and Cohen’s Kappa.

## Key Results
- Logistic regression achieved the best recall (0.701) and highest F1-score (0.649).
- Deep neural network (DNN) attained the highest accuracy (0.709).
- Support vector machine (SVM) yielded the strongest discrimination with AUC (0.736).

## Why This Works (Mechanism)
The models succeed by leveraging sociodemographic and maternal-child health proxies that strongly correlate with anemia risk. Key predictors—child age, recent fever, household size, maternal anemia, and parasite deworming—capture nutritional, infectious, and caregiving factors. By learning patterns from these readily observable features, the classifiers effectively stratify children into high- and low-risk groups without requiring direct hemoglobin measurements, enabling targeted interventions in primary care and community health programs.

## Architecture Onboarding
Data flow and modeling pipeline:
Raw NDHS 2022 -> Cleaning & Imputation -> Feature Selection (4 methods) -> Consensus 13 features -> Train/Test Split (80/20) -> SMOTE (on train only) -> Model Training with CV Tuning -> Test Evaluation

Critical path:
1. Data preprocessing (cleaning, imputation, categorical encoding)
2. Feature selection consensus
3. SMOTE integration within CV pipeline
4. Hyperparameter grid search per model
5. Final test assessment

Design tradeoffs:
- SMOTE vs. SMOTENC: Paper uses SMOTE on categorical-converted data; SMOTENE would be more appropriate but may change synthetic sample generation.
- Model complexity: DNN and TabNet risk overfitting on n=1,855; simpler models (LR, SVM) offer better generalization.
- Interpretability: LR and DT provide direct feature importance; ensemble and DL models sacrifice transparency for potential gains.

Failure signatures:
- Data leakage: Synthetic samples from SMOTE appear in test sets or CV folds.
- KNN underperformance: Distance metrics fail with high-dimensional categorical data, leading to poor recall.
- Overfitting: Large gaps between training and test metrics (e.g., >0.1 F1) for trees or DNN.

## Limitations
- Feature set ambiguity: Only 5 of the 13 consensus features are explicitly named; the full list is unspecified.
- Hyperparameter search grids are not provided, preventing exact replication of training conditions.
- SMOTE application to categorical-only data is unclear; possible mismatch between oversampling technique and feature types.
- Data leakage risk if SMOTE is not strictly confined to training folds within cross-validation.
