# Influencing LLM Multi-Agent Dialogue via Policy-Parameterized Prompts

## Quick Facts
- ArXiv ID: 2603.09890
- Source URL: https://arxiv.org/abs/2603.09890
- Reference count: 40
- Primary result: Parameterized prompts can steer multi-agent LLM dialogue dynamics without model training.

## Executive Summary
The paper addresses the lack of principled policy methods in LLM-based multi-agent dialogue, where prompts are usually ad hoc. It introduces a framework that treats prompts as parameterized actions composed of five components: task/persona (T), memory (M), knowledge (D), rule template (R), and weights (W). This allows dynamic behavior steering without retraining. Evaluated on two public discussion scenarios with different LLMs, the framework shows measurable influence on dialogue dynamics across five metrics (responsiveness, rebuttal, evidence usage, non-repetition, stance shift). Variations in rule templates and weights produce specific effects: Light rules enhance evidence usage, Struct rules reduce repetition, and higher T weight increases rebuttals. Adaptive weights further modulate trajectories, demonstrating the method's potential as an interpretable control mechanism for social simulations.

## Method Summary
The proposed framework constructs prompts for each agent at each dialogue turn by combining five parameterized components: task/persona (T) defines the agent's role and objective; memory (M) stores past interactions; knowledge (D) provides factual information; rule template (R) structures the prompt (e.g., None, Light, Struct); and weights (W) determine the relative emphasis of each component. During dialogue, these components are dynamically assembled into a prompt, which is fed to the LLM to generate a response. The response then updates the dialogue history and memory, closing the loop. The framework does not require model training; instead, it steers behavior by tuning the prompt parameters, effectively implementing a policy over prompt space.

## Key Results
- Rule templates (None, Light, Struct) significantly affect evidence usage, repetition, and rebuttal rates; Light rules boost evidence usage, Struct rules minimize repetition.
- Weight adjustments, particularly higher weight on task/persona (T), increase rebuttal rates.
- Adaptive weight modulation further influences dialogue trajectories, confirming the method's steerability.

## Why This Works (Mechanism)
The parameterization acts as a high-level policy that shapes the LLM's context window, biasing generation toward desired behaviors. By controlling the salience of task, memory, knowledge, and rules, the framework effectively conditions the LLM without altering its parameters, leveraging the model's in-context learning capabilities. Weights provide continuous control, while rule templates offer discrete structural guidance.

## Architecture Onboarding
Component map: T + M + D + R + W -> Prompt -> LLM Response -> Dialogue History Update -> M Update (optional) -> next turn

Critical path:
- Input: current dialogue state, agent's T, current M, D.
- Retrieve relevant M snippets and D facts based on context.
- Combine T, retrieved M, D according to R (template) and scale by W.
- Generate prompt string, send to LLM.
- Parse response, add to dialogue history.
- Update M (e.g., summarize new info).
- If adaptive, adjust W based on metrics.

Design tradeoffs:
- Interpretability vs. automation: Manual weight tuning is transparent but labor-intensive; adaptive weighting adds automation but may be less predictable.
- Prompt length vs. richness: Including large M and D can exceed context limits; requires compression or selection.
- Generality vs. specificity: Generic templates may not capture domain nuances; custom templates improve fit but reduce portability.

Failure signatures:
- Incoherent/off-topic responses: often due to conflicting components or overly noisy prompt.
- High repetition despite Struct rules: indicates insufficient rule enforcement or weight imbalance.
- Memory overflow: prompt exceeds LLM context length, causing truncation.
- Weight instability: adaptive weights oscillate or diverge, leading to erratic behavior.

First experiments:
1. Evaluate rule templates (None, Light, Struct) on evidence usage and repetition metrics across both scenarios.
2. Perform weight sensitivity analysis: vary weight on T while holding others constant, measure rebuttal rate.
3. Compare static vs. adaptive weight schemes: implement a simple adaptive rule (e.g., increase weight on component associated with lowest metric) and assess trajectory changes.

## Limitations
- Evaluation limited to two public discussion scenarios; generalizability to other domains (e.g., negotiation, therapy) is unknown.
- No baseline comparisons against alternative control methods (e.g., fine-tuning, RL-based prompting), making relative efficacy unclear.
- Metrics (e.g., "rebuttal", "stance shift") lack standardized definitions, raising validity concerns.

## Confidence
- Parameterization influences dialogue dynamics: Medium
- Rule templates/weights produce specific effects: Medium
- Adaptive weights modulate trajectories: Low
