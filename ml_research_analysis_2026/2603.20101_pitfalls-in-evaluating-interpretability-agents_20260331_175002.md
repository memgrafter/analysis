# Pitfalls in Evaluating Interpretability Agents
## Quick Facts
*   **arXiv ID:** 2603.20101
*   **Source URL:** https://arxiv.org/abs/2603.20101
*   **Reference count:** 40
*   **Primary result:** Agentic and one-shot interpretability systems achieve moderate extrinsic accuracy (0.2–0.8) but do not consistently exceed human performance; evaluation pitfalls include memorization, subjective human labels, and outcome-only metrics, mitigated by a swap-based intrinsic evaluation.

## Executive Summary
This paper investigates the evaluation of autonomous LLM agents tasked with reverse-engineering neural network circuits. It finds that current replication-based evaluation, which compares agent outputs to prior human expert explanations, is deeply flawed: human interpretations are subjective and incomplete, outcome-based scoring ignores the research process, and agents may succeed via memorization or guessing rather than genuine reasoning. As a scalable alternative, the authors propose an unsupervised intrinsic metric based on functional interchangeability—using swap-based neural perturbations to measure cluster coherence. This metric correlates positively with extrinsic agreement and reveals that expert-defined clusters are more behaviorally cohesive than those produced by the agent, though some agent runs achieve parity. The work calls for new benchmarks and process-aware evaluations to reliably assess automated interpretability.

## Method Summary
The core method is an agentic system (using Claude Opus 4.1) that autonomously analyzes individual circuit components (e.g., attention heads) within a transformer. Given a task-specific model, a set of prompts, and a list of components, the agent iteratively examines pre-computed logit lens and attention data, proposes hypotheses, calls experimental tools (e.g., activation patching), and refines its analysis until emitting a functional description. After processing all components, a separate LLM call clusters the descriptions by shared function. Evaluation has two arms: **extrinsic**, where an LLM judge (GPT-5) matches system outputs to human expert labels from prior work, and **intrinsic**, where pairwise head distances are computed by swapping KQ/OV circuits and measuring output distribution divergence, then aggregated into average silhouette scores for each clustering.

## Key Results
*   The agentic system and one-shot baseline achieve similar, moderate extrinsic accuracies (component functionality 0.2–0.8), with no consistent superiority for the agent, indicating that iterative experimentation did not reliably improve final descriptions.
*   Expert-defined clusters exhibit significantly higher intrinsic silhouette scores than agentic or one-shot clusterings (which often approach random), demonstrating that the agent struggles to group heads by true behavioral similarity.
*   A positive Kendall correlation between intrinsic quality (silhouette) and extrinsic agreement suggests the swap-based metric captures meaningful functional structure, though it does not assess semantic correctness.

## Why This Works (Mechanism)

### Mechanism 1: Memorization Inflates Apparent Replication
The LLM backbone (Claude Opus 4.1) has ingested published circuit analyses (e.g., IOI). When prompted to describe a component, it may retrieve memorized descriptions instead of deriving explanations from experimental data. This is evidenced by direct recall prompts yielding accurate head indices and roles, and by the judge (GPT-5) showing similar recall. The mechanism fails if evaluated on circuits absent from training data or with heavily noised experiments.

### Mechanism 2: Outcome-Only Scoring Allows Circumvention
Extrinsic evaluation compares only final functional descriptions to human labels, discarding the research process. Thus, an agent can produce correct outputs without genuine iterative reasoning (e.g., via informed guessing) and still score highly. This is supported by the one-shot baseline matching the agentic system’s extrinsic performance despite no experimentation. The mechanism would be blocked by process-aware metrics that reward valid experimental design or exploration diversity.

### Mechanism 3: Intrinsic Metric Measures Behavioral Coherence
Functional interchangeability posits that components sharing a function are interchangeable; swapping their KQ/OV circuits should minimally alter model outputs. Pairwise Jensen-Shannon divergence from swaps feeds into a silhouette score for any clustering. Expert clusters score higher than agentic ones, and intrinsic scores correlate with extrinsic agreement, indicating the metric captures real structure. The metric is limited to attention heads and does not judge semantic accuracy of descriptions.

## Architecture Onboarding

### Component map
ModelInvest API -> Research Agent (Claude Opus 4.1) -> Clustering Module (Claude Opus 4.1). Judge System (GPT-5) and Intrinsic Evaluator operate on agent outputs. The Agent calls ModelInvest tools (logit_lens, patching, etc.) in a loop.

### Critical path
1. Task setup: select circuit task, load model checkpoint, 20 prompts, and component list. Pre-compute initial results (logit lens, attention patterns) for first 10 prompts.
2. Per-component analysis: for each circuit component, the agent iteratively proposes hypotheses and requests experiments via ModelInvest tools until a final hypothesis is emitted.
3. Clustering: all component descriptions are sent to the clustering module to produce functionally similar groups.
4. Evaluation: extrinsic judge matches outputs to human references; intrinsic evaluator computes pairwise swap distances and silhouette scores.

### Design tradeoffs
Agent autonomy (many tool calls, high LLM cost) vs. one-shot efficiency. Intrinsic evaluation is scalable but limited to attention heads; extrinsic evaluation uses human expertise but is vulnerable to memorization and subjectivity. Tools are transformer-specific (TransformerLens), hindering generalization.

### Failure signatures
High run-to-run variance in scores; agentic/one-shot intrinsic scores near random; direct recall of circuit details by backbone LLM; no extrinsic improvement from agentic iteration; discrepant high extrinsic/low intrinsic scores.

### First 3 experiments
1. Replicate the one-shot system on IOI (GPT-2-small) and verify component functionality accuracy matches paper numbers.
2. Probe Claude Opus 4.1 for direct recall of the IOI circuit (no experimental context) and check accuracy of head indices/roles.
3. Compute swap-based distances and silhouette for expert-defined IOI clusters; confirm within-cluster distances are lower and silhouette ~0.21.

## Open Questions the Paper Calls Out
*   **Open Question 1:** How can evaluation metrics for interpretability agents incorporate information about the research process, not just final explanations?
*   **Open Question 2:** How can we reliably detect and quantify memorization or informed guessing in LLM-based interpretability agents?
*   **Open Question 3:** Can the proposed intrinsic evaluation based on functional interchangeability be enhanced to also assess the semantic correctness and completeness of component descriptions?
*   **Open Question 4:** How can future benchmarks for automated circuit analysis be constructed to reduce memorization risks while remaining scalable and diverse?

## Limitations
*   Reproduction is hindered by lack of public access to Claude Opus 4.1 and GPT-5, forcing substitutions that may alter numeric results.
*   Exact prompts and system messages are not fully disclosed, risking implementation drift and inconsistent behavior.
*   The intrinsic metric applies only to attention heads; its extension to MLPs or other architectures is unproven.

## Confidence
*   **Memorization risk:** Medium. Direct recall is demonstrated, but its quantitative contribution to agent performance is not isolated.
*   **Extrinsic evaluation flaws:** High. One-shot parity and human subjectivity are clearly shown across multiple tasks.
*   **Intrinsic metric validity:** Medium. Correlation with extrinsic agreement is positive, but the metric ignores semantic accuracy and is architecture-limited.

## Next Checks
1. Evaluate the agent on novel circuits published after the LLM’s knowledge cutoff; a significant drop would confirm memorization as a major factor.
2. Design a process-aware extrinsic benchmark that rewards iterative experimentation (e.g., counting causally valid patching experiments) and verify whether the agentic system then surpasses the one-shot baseline.
3. Generalize the swap-based distance to MLPs using activation patching and compute silhouette scores; compare against expert-defined MLP clusters to test scalability beyond attention heads.
