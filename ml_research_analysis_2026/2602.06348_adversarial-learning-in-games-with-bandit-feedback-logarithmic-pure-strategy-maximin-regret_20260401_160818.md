# Adversarial Learning in Games with Bandit Feedback: Logarithmic Pure-Strategy Maximin Regret

## Quick Facts
- **arXiv ID**: 2602.06348
- **Source URL**: https://arxiv.org/abs/2602.06348
- **Reference count**: 40
- **Primary result**: For adversarial zero-sum games with bandit feedback, the paper provides algorithm-specific instance-dependent regret bounds (often logarithmic in T) for both normal-form and bilinear games, with and without knowledge of the opponent's action, and shows gap-dependent lower bounds.

## Executive Summary
The paper studies learning in adversarial zero-sum games under bandit feedback, where only partial information about the game is revealed after each play. The learner aims to minimize Pure-Strategy Maximin Regret (PSMR) against an adaptive adversary. Four algorithms are introduced: Tsallis-INF for uninformed normal-form games (only reward observed), Maximin-UCB for informed normal-form (reward and opponent action observed), and their bilinear extensions Tsallis-FTRL-SPM and Maximin-LinUCB. The analysis yields regret bounds that are logarithmic in the time horizon T when a strict pure-strategy Nash equilibrium exists, and either constant or square-root dependence otherwise. Matching lower bounds are provided for several cases, demonstrating that the gap-dependent dependencies are necessary. The results bridge concepts from adversarial bandits, game theory, and online convex optimization.

## Method Summary
The core methodology combines Follow-the-Regularized-Leader (FTRL) with Tsallis entropy for the uninformed setting and Upper Confidence Bound (UCB) strategies for the informed setting. Both approaches incorporate instance-dependent gap parameters from the game matrix to achieve tight regret. In the bilinear case, the algorithms exploit low-dimensional structure (via feature vectors) to avoid polynomial dependence on the number of actions: Tsallis-FTRL-SPM uses a covariance-based stabilization term, while Maximin-LinUCB employs ridge regression and Mahalanobis confidence ellipsoids. The reproduction plan involves implementing these algorithms, generating game matrices or bilinear instances, and measuring PSMR under various adversary models (e.g., always playing best response, stochastic mixing).

## Key Results
- **Uninformed normal-form (Tsallis-INF)**: PSMR = O((∑_{x≠x*} log T/∆r_x)/∆c_min) if a strict PSNE exists; otherwise O(m_x/∆_mix). Lower bound confirms the 1/(∆r ∆c) dependency is necessary.
- **Informed normal-form (Maximin-UCB)**: Instance-dependent PSMR = O(∑_{x,y:∆_xy>0}(∆_xy + log T/∆_xy)) always, and worst-case O(√(m_x m_y T) log T).
- **Bilinear settings**: Uninformed Tsallis-FTRL-SPM gives worst-case O(√(d_x T) log m_x + m_x log m_x) and with strict PSNE O((d_x log m_x log T)/(∆r_min ∆c_min) + m_x log m_x). Informed Maximin-LinUCB yields worst-case O(d_x d_y √T log T) and instance-dependent O((d_x² d_y² log² T)/∆_lin).

## Why This Works (Mechanism)
### Mechanism 1: Tsallis-INF for Uninformed Normal-Form Games
The algorithm uses FTRL with Tsallis entropy regularizer (α=1/2) and learning rate η_t = 1/(2√t). Importance-weighted reward estimators make the expected update unbiased despite only one action’s reward being observed. The Tsallis entropy naturally balances exploration and exploitation, yielding logarithmic regret when strict PSNE gaps (Δ_r, Δ_c) are positive. Evidence appears in the abstract and Section 3, with the analysis hinging on the gap structure. The method fails when Δ_min=0 (no strict PSNE), reducing to O(m_x/∆_mix) or even Ω(√T) for non‑strict PSNE; the dependence 1/(Δ_r Δ_c) is shown necessary by the lower bound (Theorem 2).

### Mechanism 2: Maximin-UCB for Informed Normal-Form Games
For each action pair (x,y), the algorithm maintains an upper confidence bound U^{(t)}(x,y) = empirical mean + √(4 log(1/δ) + 2 log(1+N^{(t-1)}(x,y)))/N^{(t-1)}(x,y) with δ=1/T. At each round t it plays the pure maximin action: x_t = arg max_x min_y U^{(t)}(x,y). The confidence intervals guarantee that the true utility lies below the UCB with high probability, enabling optimistic yet safe play. The setting assumes the opponent’s action y^{(t)} is observed, allowing direct matrix estimation. Instances where some Δ_xy are tiny may cause excessive exploration, as the bound N(T)(x,y) ≲ (6/Δ_{xy}²) log T forces many pulls. Evidence: abstract and Section 4 detail the instance‑dependent bound.

### Mechanism 3: Bilinear Game Extensions (Tsallis-FTRL-SPM & Maximin-LinUCB)
Both algorithms handle large/continuous action sets via low‑dimensional features (x∈ℝ^{d_x}, y∈ℝ^{d_y}) and linear payoff u(x,y)=⟨x,Ay⟩.

- **Tsallis-FTRL-SPM** (uninformed) employs FTRL with a Tsallis entropy variant that includes a stability penalty matching term φ_{1-α}. The reward estimator g^{(t)}_x = r_t ⟨x^{(t)}, S(p^{(t)})^{-1} x⟩ uses the covariance S(p)=E_{x∼p}[x x^T] to reduce variance. This design avoids polynomial dependence on m_x, leading to worst‑case O(√(d_x T) log m_x + m_x log m_x) and, with strict PSNE, an additional gap‑dependent logarithmic term (Theorem 5).

- **Maximin-LinUCB** (informed) maintains a ridge regression estimate of vec(A) using accumulated feature vectors V^{(t)} and vectorized rewards b^{(t)}. The confidence radius β_t = √(λ d_x d_y + √(2 log(1/δ) + d_x d_y log(1 + t/(λ d_x d_y)))}) (δ=1/T) yields a Mahalanobis‑norm UCB U^{(t)}(x,y)=⟨x,Â^{(t)} y⟩ + β_t √(x^T V^{-1} x · y^T V^{-1} y). The algorithm then plays the arg max_x min_y U^{(t)}(x,y). This achieves worst‑case O(d_x d_y √T log T) and instance‑dependent O((d_x² d_y² log² T)/Δ_lin) (Theorem 6). Both rely on bounded action norms (∥x∥,∥y∥≤1) and ∥A∥₂≤1.

## Foundational Learning
- **Zero-sum game minimax theory**  
  - *Why needed*: To define PSMR, the pure‑strategy maximin value v^*, and gap parameters (Δ_r, Δ_c, Δ_mix) that appear in regret bounds.  
  - *Quick check*: Why does v^* ≤ v_Nash, and when are they equal?

- **Adversarial multi-armed bandits**  
  - *Why needed*: Provides the baseline problem (bandit feedback) and the Ω(√T) external regret lower bound against an adaptive adversary; explains why naïve bandit methods cannot achieve logarithmic regret without exploiting game structure.  
  - *Quick check*: What is external regret and why can’t it be improved below O(√T) against an adaptive adversary?

- **Follow-the-Regularized-Leader (FTRL)**  
  - *Why needed*: Serves as the optimization backbone for Tsallis-INF and Tsallis-FTRL-SPM; the choice of regularizer and time‑varying learning rate yields the desired regret decomposition. Unbiased importance‑weighted reward estimation under bandit feedback is a key subroutine.  
  - *Quick check*: Why is the importance‑weighted estimator in Tsallis-INF unbiased even though only one action’s reward is observed?

## Architecture Onboarding
**Component map**:  
Game representation → Feedback processor → Uncertainty estimator → Decision rule → Update module.

**Critical path**:  
- *Uninformed*: Compute importance‑weighted reward vector g^{(t)} → run FTRL update to get distribution p^{(t)} → sample pure action x^{(t)}.  
- *Informed*: Update matrix estimates (UCB or ridge) → compute optimistic maximin pure action x^{(t)} → observe opponent y^{(t)} and reward → update estimates.

**Design tradeoffs**:  
- *Uninformed vs Informed*: Informed algorithms (observe opponent’s action) achieve better instance‑dependent rates but require more feedback.  
- *Pure vs Mixed*: Maximin‑UCB and Maximin-LinUCB play pure strategies, matching PSMR; mixed strategies could improve Nash regret but add complexity.  
- *Gap parameter sensitivity*: Different algorithms depend on different gap sets (Δ_r,Δ_c vs Δ_xy vs Δ_lin); for a given game one gap may be much smaller, making one algorithm preferable.  
- *Dimensionality scaling*: Bilinear algorithms either scale with d_x d_y (informed) or with m_x (uninformed additive term); depending on m_x and d_x, one may dominate.

**Failure signatures**:  
1. External regret scaling as √T indicates the algorithm is not exploiting game structure (e.g., using Exp3).  
2. Empirical PSMR growing faster than O(log T) for a strict PSNE suggests exploration failure or mis‑tuned learning rates/confidence.  
3. For Maximin‑UCB, excessive pulls on suboptimal pairs despite tiny Δ_xy → confidence bonus too small or log miscount.  
4. For Maximin‑LinUCB, constant β_t instead of the prescribed growing schedule leads to under‑exploration.  
5. Edge case: N(x,y)=0 must trigger infinite UCB (or a large default) to guarantee all pairs are tried.

**First 3 experiments**:  
1. **Validation on 2×2 games**: Test Tsallis-INF and Maximin-UCB on A=[[1,0],[0,-ε]] (ε small). Expected PSMR ~ log T/ε; confirm slope ~1 on log‑log plot.  
2. **Non-strict PSNE**: Use A=[[0,0],[0,-1]]. Expect PSMR to converge to a constant O(m_x/Δ_mix), not logarithmic.  
3. **Bilinear scaling**: For d_x=5, d_y=3, generate random A and action sets of size \(m_x∈\{100,1000\}\); check that Maximin-LinUCB’s regret increases only logarithmically with \(m_x\) while Tsallis-FTRL-SPM’s regret increases by roughly \(m_x \log m_x\).

## Open Questions the Paper Calls Out
1. Can a single algorithm for the informed setting simultaneously attain the favorable instance‑dependent guarantees of Tsallis‑INF (for games with a strict PSNE) and Maximin‑UCB (which can be better in other games)? What are the instance‑optimal regret bounds for the informed setting?  
2. For general bilinear zero‑sum games under bandit feedback, what fundamental instance‑dependent parameter characterizes the optimal regret? Are the provided bounds (e.g., O((d_x log m_x log T)/(Δ^r_min Δ^c_min) + m_x log m_x) for uninformed with strict PSNE) instance‑optimal, or is there a gap compared to a lower bound?  
3. Can we achieve instance‑dependent polylogarithmic Nash‑value regret (NReg) against arbitrary adversaries with bandit feedback in general zero‑sum games, even when no pure‑strategy Nash equilibrium exists? This extends the current results that achieve such rates only for PSMR when a PSNE exists.

## Limitations
- Theoretical constants are loose; empirical regret may be significantly smaller than the worst‑case predictions, making it hard to validate tightness.
- The exploration distribution \(p^{\circ}\) required by Tsallis‑FTRL‑SPM for general action sets (satisfying condition (10)) is non‑constructive beyond simple bases; designing it efficiently for arbitrary \(\mathcal{X}\) is an open implementation challenge.
- The additive term \(O(m_x \log m_x)\) in the uninformed bilinear bound can dominate for large action sets, limiting practical applicability.
