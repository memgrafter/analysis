# PathoScribe: Transforming Pathology Data into a Living Library with a Unified LLM-Driven Framework for Semantic Retrieval and Clinical Integration

## Quick Facts
- **arXiv ID**: 2603.08935
- **Source URL**: https://arxiv.org/abs/2603.08935
- **Reference count**: 40
- **Primary result**: On 70,000 pathology reports, PathoScribe achieved perfect Recall@10 for natural language case retrieval, assembled research cohorts in a mean 9.2 minutes with 91.3% agreement to human reviewers, improved IHC panel recommendation Hit@1 by 4.8×, and delivered high-fidelity report transformations.

## Executive Summary
Pathology narrative reports remain largely inaccessible, creating bottlenecks in real-time case retrieval and manual cohort construction that can take months. PathoScribe addresses this by providing a unified retrieval-augmented LLM framework that converts static report archives into an interactive, searchable library. Leveraging hybrid dense‑sparse retrieval and a Mistral‑7B generator, the system demonstrates exceptional performance on 70,000 reports: perfect recall for natural language queries, rapid cohort assembly with high human agreement, a 4.8‑fold improvement in immunohistochemistry panel recommendation, and high‑quality text transformations. While promising, the lack of external validation and detailed baseline comparisons leaves questions about real‑world robustness and clinical impact.

No reproduction notes were provided. ## Key Results
- Perfect Recall@10 for natural language case retrieval across 70,000 pathology reports.
- Cohort assembly completed in a mean of 9.2 minutes with 91.3% agreement to human reviewers and zero eligible exclusions.
- IHC panel recommendation Hit@1 improved by 4.8×, from 11.9% to 57.4%.

## Why This Works (Mechanism)
PathoScribe’s effectiveness stems from its hybrid retrieval strategy, which combines semantic dense search (capturing conceptual similarity) with sparse lexical matching (handling precise medical terminology). This dual approach ensures high recall across varied query styles. The Mistral‑7B generator, fine‑tuned on pathology data, produces accurate, context‑aware outputs while the retrieval‑augmentation grounds the generation in real cases, minimizing hallucinations. The unified design allows seamless integration of retrieval and generation for both search and transformation tasks.

- **Hybrid Fusion**: Combines scores from dense and sparse retrievers to leverage strengths of both. Quick check: Does the system fuse results? Yes, “hybrid dense‑sparse”.

## Architecture Onboarding
**Component Map**: Query -> Dense Retriever -> Candidate Set A; Query -> Sparse Retriever -> Candidate Set B; Fusion of A & B -> Top‑K Context -> Mistral‑7B Generator -> Output

**Critical Path**: 1) Receive natural language query. 2) Compute dense and sparse retrieval scores. 3) Fuse results to select relevant report excerpts. 4) Construct prompt with retrieved context. 5) Generate response or transformed report using Mistral‑7B. 6) Return output to user.

**Design Tradeoffs**: Hybrid retrieval improves recall but increases computational cost and latency. Mistral‑7B balances quality and resource demands but may still be heavy for real‑time use without optimization. Retrieval augmentation reduces hallucinations but can propagate errors if retrieved documents are irrelevant. The framework prioritizes accuracy over speed for research tasks.

**Failure Signatures**: Persistent low recall despite hybrid retrieval (indicating mismatch in embedding space or BM25 parameters); high hallucination rates in generated text (suggesting inadequate grounding or model misalignment); slow response times exceeding several seconds (due to retrieval or generation overhead); outputs that do not conform to requested transformation (e.g., wrong template).
