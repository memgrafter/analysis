# How Do Language Models Understand Tables? A Mechanistic Analysis of Cell Location
## Quick Facts
- **arXiv ID**: 2602.08548
- **Source URL**: https://arxiv.org/abs/2602.08548
- **Reference Count**: 40
- **Primary Result**: LLMs locate table cells via a three-stage pipeline (Semantic Binding, Coordinate Localization, Information Extraction) using delimiter counting; column indices are encoded linearly (R² up to 0.95).

## Executive Summary
This paper investigates how large language models process linearized tables, focusing on the atomic task of cell location. Using activation patching, linear probing, and ablation, the authors identify a three-stage pipeline: Semantic Binding aligns the query with table headers in early layers, Coordinate Localization navigates to the target cell via a delimiter-counting mechanism in middle layers, and Information Extraction propagates the answer to the output in late layers. The model encodes column indices in a linear subspace, enabling precise steering through additive vector arithmetic. The mechanism generalizes to multi-cell queries by reusing the same attention heads in parallel. Linear probes achieve R² scores up to 0.95 for column indices, confirming an implicit coordinate system based on discrete delimiter counting rather than semantic matching.

## Method Summary
The authors apply mechanistic interpretability techniques—activation patching to isolate causal effects of specific layers or heads, linear probing to decode representations (e.g., column indices) from frozen activations, and ablation to test the necessity of components. Experiments are conducted on a single large language model using synthetic linearized tables, with systematic variations in query types and table structures to dissect the cell location mechanism.

## Key Results
- Discovered a three-stage processing pipeline: Semantic Binding (early layers), Coordinate Localization (middle layers), Information Extraction (late layers).
- Coordinate Localization relies on counting delimiter tokens (e.g., pipes) to determine column indices; the column index is encoded in a linear subspace (linear probes achieve R² up to 0.95).
- The mechanism generalizes to multi-cell queries by reusing the same attention heads in parallel; additive vectors can steer the model to specific columns.

## Why This Works (Mechanism)
Semantic Binding: The query token attends to header tokens in early layers to align semantics and identify the relevant column header. Coordinate Localization: Middle-layer attention heads count delimiter tokens (e.g., `|`) to compute the exact column coordinate; this position is represented as a linear direction in activation space. Information Extraction: Late layers propagate the value of the target cell to the output, completing the answer. The linear encoding of column indices allows precise control via additive vector arithmetic, and the same heads operate in parallel for multi-cell queries.

## Foundational Learning
- **Delimiter Counting**: Mechanism for determining column position by counting separator tokens. *Why needed*: Core of coordinate localization. *Quick check*: Given a linearized table with pipes, how would you compute a cell’s column index using delimiter count?
- **Linear Subspace Encoding**: Representation of column indices as a direction in activation space. *Why needed*: Enables steering via additive vectors. *Quick check*: If a linear probe predicts column index with high R², what does that imply about the representation?
- **Activation Patching**: Causal intervention replacing activations from a clean run with those from a corrupted run. *Why needed*: Identifies which layers/heads are necessary for the task. *Quick check*: What does a significant performance drop after patching a specific layer indicate?
- **Linear Probing**: Training a linear classifier/regressor on frozen model activations to decode a property. *Why needed*: Provides evidence for linear representations (e.g., column index). *Quick check*: What does a high R² score in a linear probe tell you about the underlying representation?

## Architecture Onboarding
Component map: Input tokens -> Early Transformer layers (Semantic Binding) -> Middle Transformer layers (Coordinate Localization) -> Late Transformer layers (Information Extraction) -> Output softmax.

Critical path: Query token binds to headers → compute column index via delimiter counting → attend to target cell → extract value → produce answer.

Design tradeoffs: Delimiter-based coordinates are simple and scale with table width but require consistent formatting; alternative semantic matching could be more format-agnostic but less efficient. Linear encoding of indices allows easy arithmetic manipulation but may limit precision for very large tables.

Failure signatures: Missing or extra delimiters corrupt column counts; ambiguous headers disrupt Semantic Binding; corrupted delimiter tokens in middle layers break Coordinate Localization; tables exceeding positional capacity cause delimiter counting to fail.

First experiments:
1. Train linear probes for column index on activations from each layer; expect sharp R² increase in middle layers.
2. Perform activation patching: replace middle-layer activations with those from a table with a different column count; observe if output shifts accordingly.
3. Ablate delimiter tokens (e.g., replace with null) and measure degradation in cell location accuracy.

## Limitations
- Findings are based on a single model; may not generalize across architectures or scales.
- Mechanism relies on clean delimiters; real-world tables with inconsistent formatting may break it.
- Handling of ambiguous or missing headers in the Semantic Binding stage is unclear.

## Confidence
- Three-stage pipeline: Medium
- Delimiter-counting mechanism: Medium
- Parallel head reuse for multi-cell queries: Low
- Steering via additive vectors: Medium

## Next Checks
1. Cross-architecture replication: Test identified mechanisms on additional LLM families (e.g., Llama 2, Claude) with varying positional encoding schemes.
2. Stress-test with realistic tables: Evaluate linear probe R² for column indices on a diverse corpus of real-world tables (e.g., Wikipedia, spreadsheets) containing merged cells and inconsistent formatting.
3. Ablation of delimiter tokens: Perform systematic token-level ablation (e.g., removing or corrupting pipe/line-break) to quantify the causal necessity of delimiters for coordinate localization.
