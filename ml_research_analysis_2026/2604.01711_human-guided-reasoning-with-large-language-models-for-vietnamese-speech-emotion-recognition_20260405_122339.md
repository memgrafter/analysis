# Human-Guided Reasoning with Large Language Models for Vietnamese Speech Emotion Recognition

## Quick Facts
- arXiv ID: 2604.01711
- Source URL: https://arxiv.org/abs/2604.01711
- Reference count: 14
- Primary result: Achieves up to 86.59% accuracy on Vietnamese speech emotion recognition, approaching human-level performance (88–90%).

## Executive Summary
This paper introduces a human-machine collaborative framework for Vietnamese speech emotion recognition (SER) to address challenges of ambiguous acoustic patterns and scarce reliable data. The system uses a confidence-based routing mechanism to delegate uncertain samples from an acoustic classifier to an LLM-based reasoning module. The LLM is guided by structured rules derived from human annotation behavior, and an iterative refinement loop updates these rules based on error analysis. Evaluated on a Vietnamese dataset with high inter-annotator agreement, the method attains accuracy up to 86.59% and Macro F1 around 0.85–0.86, nearing human performance and demonstrating robustness across multiple LLM backbones.

## Method Summary
The framework begins with preprocessing and acoustic feature extraction (pitch, energy, MFCC) from raw speech. A Support Vector Machine (SVM) is trained on these features to produce predictions and confidence scores. A routing module compares the confidence to a threshold; high-confidence samples are output directly, while low-confidence samples are sent to an LLM. The LLM reasons using heuristic rules extracted from human annotators (e.g., linking pitch instability to "panic") encoded in the prompt. Misclassifications are analyzed offline to refine rules, forming a feedback loop. The system is evaluated on a Vietnamese dataset of 2,764 audio segments (calm, angry, panic) with a held-out test set of 671 samples, using Accuracy and Macro F1 as metrics.

## Key Results
- Achieves peak accuracy of 86.59% and Macro F1-score of 0.85–0.86 on the Vietnamese SER dataset.
- Performance approaches human-level accuracy (88–90%) and shows model-agnostic robustness across several LLM backbones (e.g., Qwen2.5-7B, LLaMA3.2-3B).
- The confidence-based routing and rule-guided LLM reasoning effectively reduce error rates on ambiguous samples compared to acoustic-only baselines.

## Why This Works (Mechanism)
**Mechanism 1: Confidence-Based Routing**. The SVM classifier outputs a confidence score; samples below a threshold are routed to the LLM, while high-confidence samples use the SVM label. This leverages the SVM's efficiency on clear cases and the LLM's reasoning on ambiguous ones. Evidence includes the abstract's description of a confidence-based routing mechanism and Section III.D's distinction between easy and ambiguous samples. A break condition is poor SVM confidence calibration, leading to misrouting.

**Mechanism 2: Human-Derived Structured Rules**. Human annotators' implicit heuristics (e.g., "high pitch variance indicates panic") are extracted and formalized into rules injected into the LLM prompt, guiding reasoning along human-like pathways. The abstract and Section III.C support this. Risks include incomplete or context-dependent rules that over-constrain the LLM.

**Mechanism 3: Iterative Rule Refinement**. Misclassifications are analyzed to identify recurring error patterns (e.g., angry vs. panic confusions), which are translated into updated rules and prompt adjustments. This feedback loop progressively improves consistency on hard samples, as per the abstract and Section III.E. Break conditions include biased error analysis or spurious correlations causing overfitting.

## Foundational Learning
- **Acoustic Feature Extraction**: Raw audio is transformed into structured descriptors (pitch, energy, MFCC statistics) consumable by both SVM and LLM. Without reliable features, routing confidence and rule-based reasoning lack foundation. Quick check: How would you compute and describe extreme pitch variance in a 2-second window for LLM input?
- **Confidence-Aware Routing**: This operationalizes ambiguity by thresholding SVM confidence to decide when to invoke the LLM, trading latency for accuracy. Quick check: What happens to accuracy, latency, and routing proportion if the confidence threshold is increased? What is the risk of setting it too high?
- **Human-in-the-Loop Knowledge Elicitation**: Converting annotator intuitions (e.g., "panicky speech is faster") into discrete, testable rules is essential for embedding human reasoning. Quick check: How would you design an annotation study to elicit acoustic cues distinguishing "angry" from "panic", and formalize a quote into a binary rule?

## Architecture Onboarding
- **Component map**: Raw speech waveform -> Preprocessing & Feature Extraction (pitch, energy, MFCC) -> Acoustic Classifier (SVM) with confidence -> Routing Module (threshold check) -> [If high confidence: SVM label] / [If low: LLM Reasoning Module with structured rules] -> Final output. Offline: Error analysis -> Rule updates -> Prompt adjustment.
- **Critical path**: Speech waveform -> Feature Extraction -> SVM (confidence) -> Confidence Check (τ) -> Conditional branch (SVM output or LLM prompt) -> Final output.
- **Design tradeoffs**: Latency vs. accuracy (τ adjustment); rule complexity vs. generalizability; LLM size vs. cost.
- **Failure signatures**: High-confidence SVM errors (fundamental acoustic model flaw); LLM failures on routed samples (poor prompt/rules/confidence proxy); rule degeneration during iterative refinement (overfitting).
- **First 3 experiments**: (1) Ablate routing: vary τ, plot accuracy vs. routing rate, assess SVM confidence calibration. (2) Rule impact: compare LLM with no rules, generic instruction, full rules on low-confidence subset. (3) Backbone robustness: test fixed τ/rules across diverse LLMs (1B–7B) to confirm stability.

## Open Questions the Paper Calls Out
- How should the confidence threshold for routing be optimally determined and adapted? The paper describes the mechanism but not how to set or calibrate τ.
- What is the precise methodology for extracting and formalizing the "structured rules" from human annotation behavior? The conversion process from annotator reasoning to prompt rules is not detailed.
- What specific error patterns trigger updates in the iterative refinement loop, and how are they translated into new or modified reasoning rules? The operational criteria for "recurring patterns" and translation mechanism are unclear.
- To what extent does the framework generalize to other low-resource languages and more granular emotion taxonomies? The current evaluation uses only three broad classes and Vietnamese-specific data.
- How does the dataset's speaker demographic and dialect representation impact performance across subgroups? No stratified analysis by age, gender, or accent is provided.

## Limitations
- Exact confidence threshold (τ) for routing is undisclosed, hindering replication.
- Complete set of human-derived reasoning rules and their prompt formulation are not provided.
- SVM hyperparameters and feature aggregation details are vague; small test set (671 samples) may yield high variance.

## Confidence
- Routing improves accuracy on ambiguous samples: Medium
- Structured rules enhance LLM reasoning: Medium
- Iterative refinement boosts robustness: Low
- Near-human performance (86.59% accuracy): Medium

## Next Checks
- Conduct a threshold sensitivity ablation: vary τ on a held-out set, plot accuracy vs. routing rate, and assess SVM confidence calibration.
- Perform rule ablation: evaluate LLM on routed samples with no rules, generic instruction, and full rule set to isolate rule contribution.
- Validate model-agnostic robustness: test fixed τ and rule set across diverse LLM backbones (e.g., 1B–7B parameters) to confirm stable performance.
