# REFORGE: Multi-modal Attacks Reveal Vulnerable Concept Unlearning in Image Generation Models

## Quick Facts
- **arXiv ID:** 2603.16576  
- **Source URL:** https://arxiv.org/abs/2603.16576  
- **Reference Count:** 34  
- **Primary Result:** REFORGE achieves the highest average attack success rate (66.55%) against six image generation model unlearning (IGMU) defenses, with superior semantic alignment (CLIP Score: 24.19) and greater efficiency (~35s per attack).

## Executive Summary
Image generation model unlearning (IGMU) aims to erase unwanted concepts from text-to-image models, but current methods lack robustness evaluation against black-box adversarial image inputs. REFORGE is a novel black-box red-teaming framework that generates adversarial image prompts by combining stroke-based initialization, cross-attention-guided masking, and masked latent alignment optimization in a proxy model. Across three unlearning tasks (Nudity, Object-Parachute, Van Gogh-Style) and six IGMU defenses, REFORGE consistently outperforms existing baselines in attack success rate, semantic fidelity, and efficiency, revealing persistent vulnerabilities in unlearned models to multi-modal attacks.

## Method Summary
REFORGE operates under a strict black-box threat model with no access to target model gradients or weights. It uses a publicly available proxy diffusion model (same architecture as the target) to construct adversarial images. First, a reference image containing the target concept is transformed via stroke-based initialization into a coarse, semantically aligned starting point that preserves global composition while discarding fine details. Second, cross-attention maps from the proxy model for the given text prompt guide a spatial mask that identifies concept-relevant regions. Third, the adversarial image is iteratively optimized in the proxy’s VAE latent space using a masked MSE loss that aligns its latent representation with the reference image’s latent only within the masked regions. The final adversarial image, combined with the original text prompt, is then queried from the target unlearned model to test for concept re-emergence.

## Key Results
- **Highest Attack Success Rate (ASR):** REFORGE achieves an average ASR of 66.55% across six IGMU defenses, surpassing the best baseline (58.55%).
- **Superior Semantic Alignment:** Attains a CLIP Score of 24.19 vs. 16.52 for the best baseline, indicating generated images better match the text prompt.
- **Greater Efficiency:** Requires only ~35 seconds per attack, significantly faster than baselines (290–1000 seconds).

## Why This Works (Mechanism)

### Stroke-Based Initialization
REFORGE begins by converting a reference image into a coarse stroke-based representation using a large-kernel median filter (size 47), color quantization (k=6), and region-based stroke rendering. This preserves the global layout and dominant colors while removing high-frequency textures. The core assumption is that unlearning methods primarily suppress fine-grained features, so a coarse but structurally aligned image provides a stable foundation that can be later perturbed to reactivate the concept without triggering low-level filters. Evidence from the paper’s design and ablations shows this initialization avoids premature detection and sets effective optimization boundaries.

### Cross-Attention-Guided Masking
For a given prompt and initial adversarial image, the proxy diffusion model computes cross-attention maps at selected layers and timesteps. These maps are aggregated and normalized into a spatial mask that highlights regions the model associates with the target concept. During optimization, gradient updates are multiplied by this mask, concentrating perturbations only in concept-relevant areas. This improves attack efficiency and visual imperceptibility. The mechanism assumes that the proxy’s attention routing remains predictive of the target’s attention post-unlearning. Ablations confirm that using attention masks significantly boosts ASR compared to unmasked optimization.

### Masked Latent Alignment Optimization
The adversarial image and reference image are encoded into latents using the proxy’s VAE. The optimization minimizes the MSE loss between these latents, but gradients are scaled by the attention mask so that alignment is enforced only in highlighted regions. This drives the adversarial latent toward the reference latent specifically in concept-relevant subspaces. The underlying assumption is that the proxy and target share aligned latent spaces due to identical architecture, and that unlearning leaves the concept representation dormant rather than excised. Success across multiple tasks and defenses validates this transferability, though it may falter with architectural mismatches.

## Architecture Onboarding
- **Component map:**  
  `StrokeInitializer -> CrossAttentionExtractor -> LatentAlignmentOptimizer -> TargetEvaluator`  
  (Uses ProxyModel for attention/latent computations)
- **Critical path:**  
  1. Input: reference image P_ref and text prompt P_text.  
  2. Generate P_adv* via stroke-based initialization.  
  3. Compute spatial mask M using proxy cross-attention on (P_adv*, P_text).  
  4. Optimize P_adv from P_adv* over K iterations using masked MSE loss between latents of P_ref and P_adv.  
  5. Query target unlearned model with (P_adv, P_text) to generate I*.  
  6. Evaluate I* with concept classifier to determine attack success.
- **Design tradeoffs:**  
  - Effectiveness vs. Imperceptibility: Stronger perturbations increase ASR but may degrade CLIP score or visual fidelity; masking and stroke initialization balance this.  
  - Efficiency vs. Performance: More optimization iterations (K) improve ASR but increase runtime; REFORGE uses modest K for ~35s per attack.  
  - Proxy-Target Alignment: Shared architecture (SD v1.4) ensures transfer; different VAE or fine-tuning reduces performance.  
  - Mask Granularity: Coarse masks are faster but less precise; fine masks capture more relevant details but may include noise.
- **Failure signatures:**  
  - Low ASR: Mismatched proxy attention, poor mask timestep/layer, or robust unlearning.  
  - Low CLIP Score: Over-perturbation; adjust initialization or loss weights.  
  - Uniform mask M: Proxy failed to localize concept; try different prompt or proxy.  
  - Slow optimization: Reduce mask resolution or iteration count.
- **First 3 experiments:**  
  1. **Main evaluation:** Test REFORGE on three unlearning tasks against six IGMU methods and three baselines; report ASR, CLIP Score, and Attack Time in Table I. REFORGE tops all metrics.  
  2. **Reference image sensitivity:** Ablate using four random references and one prompt-aligned reference per task; ASR remains high, showing robustness to reference choice.  
  3. **Cross-attention design ablations:** Vary layer selection (Shallow to Deep), timestep (T=800,400,100), and loss function (Cosine, L2, MSE). Optimal layer selection improves ASR; timestep optimal varies by concept; MSE loss consistently best.

## Open Questions the Paper Calls Out
1. How can IGMU methods be made inherently robust against black-box multi-modal adversarial attacks like those generated by REFORGE?
2. To what extent does REFORGE's reliance on a proxy diffusion model for optimization limit its effectiveness when targeting unlearned models based on substantially different architectures or unlearning methods?
3. What is the fundamental reason behind the task-dependent variation in optimal timesteps for extracting cross-attention masks?
4. Can the core idea of REFORGE—using stroke-based initialization with attention-guided masking—be effectively adapted for non-diffusion image generative models (e.g., GANs, autoregressive models) that lack a cross-attention mechanism?
5. Is the superior efficiency of REFORGE primarily due to its stroke-based initialization, its spatially masked optimization, or the synergy between both?

## Limitations
- **Proxy-target architecture dependence:** Performance may degrade if target uses a different VAE or fine-tuned encoder.
- **Cross-attention mask tuning:** Optimal layer/timestep choices vary by concept and require empirical selection.
- **Evaluation scope:** Only three unlearning tasks and six defenses tested; broader concepts and methods remain unexplored.

## Confidence
- Stroke-based initialization: Medium  
- Cross-attention-guided masking: Medium  
- Masked latent alignment: Medium
