# Self-Conditioned Denoising for Atomistic Representation Learning

## Quick Facts
*   **arXiv ID:** 2603.17196
*   **Source URL:** https://arxiv.org/abs/2603.17196
*   **Reference Count:** 40
*   **Primary Result:** Self-Conditioned Denoising (SCD) enables self-supervised pretraining on diverse atomistic data (including non-equilibrium structures) and matches or exceeds supervised force-energy pretraining while using smaller, faster models.

## Executive Summary
The paper addresses a key limitation in self-supervised learning (SSL) for atomistic systems: prior SSL methods were restricted to ground-state geometries and single domains, while supervised pretraining on DFT force-energy labels, though effective, is computationally prohibitive. The proposed solution, Self-Conditioned Denoising (SCD), is a backbone-agnostic framework that uses self-generated embeddings to conditionally denoise corrupted atomic structures. This allows pretraining on a wide variety of data, including non-equilibrium conformers and periodic materials. Results on QM9 (HOMO prediction), Matbench (bandgap), and ligand binding affinity show SCD surpassing previous SSL approaches and performing on par with models pretrained on large-scale supervised force-energy data.

## Method Summary
SCD uses a single model as both an embedder and a denoiser. During pretraining, a clean atomic structure is passed through the model to obtain an invariant (L0) embedding, which is pooled into a global conditioning vector `c`. Separately, a corrupted version of the structure (with atomic displacements drawn from Gaussian noise, σ=0.04 Å) is processed, with its representation conditioned on `c` via adaptive normalization (AdaNorm). The model predicts the applied noise in the L1 channel space, with a denoising mean squared error loss. A key design is random conditioning dropout (20%), where `c` is zeroed to force the model to learn robust representations. The same model backbone (e.g., CT or CGT) is used for both steps. Finetuning for downstream tasks uses a single forward pass on clean structures without conditioning, attaching a regression head to the L0 embeddings.

## Key Results
*   On QM9 HOMO prediction, SCD (CT backbone) achieves a test MAE of **12.7 meV**, improving over prior SSL methods Frad (15.2 meV) and SliDe (13.6 meV).
*   On Matbench periodic bandgap prediction (mp-gap), SCD reaches **0.123 eV MAE**, matching the performance of much larger models pretrained on 120M force-energy labels.
*   On the ligand binding affinity (LBA) benchmark, SCD variants achieve state-of-the-art results, with a best RMSE of **1.304**.

## Why This Works (Mechanism)
SCD’s conditioning mechanism allows the model to disentangle structural features from the specific instance of noise corruption. By forcing the denoising objective to depend on a summary of the clean structure, the model learns representations that are invariant to noise but sensitive to chemically relevant variations. This enables effective pretraining on non-equilibrium geometries (e.g., MD snapshots, conformers) that prior node-denoising SSL could not use, as those methods treat each corrupted structure in isolation. The conditional denoising task thus creates a richer, more generalizable representation than standard denoising autoencoders.

## Foundational Learning
*   **Self-Supervised Pretraining:** Unsupervised representation learning from unlabeled data, crucial for atomistic ML where labeled DFT data is scarce. *Why needed:* Provides a powerful initialization that transfers to downstream property prediction. *Quick check:* Model should show improved downstream performance after pretraining vs. random initialization.
*   **Denoising Autoencoder:** Model trained to reconstruct clean data from a corrupted version. *Why needed:* Simple, stable SSL objective that encourages learning of data manifold. *Quick check:* Pretraining loss (noise prediction MSE) should decrease steadily.
*   **Conditional Normalization (AdaNorm):** Feature normalization statistics modulated by an external conditioning vector. *Why needed:* Allows the same denoiser network to handle diverse structures by steering its normalization based on the global embedding. *Quick check:* Ablating conditioning (setting dropout=0%) should degrade performance.
*   **Invariant Representations (L0):** Geometric deep learning representations that are equivariant to rotations and translations but have no directional information. *Why needed:* For global pooling and conditioning. *Quick check:* Sum-pooled L0 embeddings should be invariant to rigid body transformations.
*   **Equivariant Representations (L1):** Representations that transform predictably under rotations/translations. *Why needed:* For predicting the noise vector (an equivariant quantity). *Quick check:* Predicted noise should rotate/translate with the input atoms.
*   **Data Augmentation via Corruption:** Adding random noise to atomic positions. *Why needed:* Creates the denoising task. *Why specific σ=0.04 Å:* Matches typical thermal fluctuation scales in molecules; ablation shows sensitivity.

## Architecture Onboarding
**Component Map:** Clean Structure → Embedder (Backbone) → L0 Embedding → Global Pooling → Conditioning Embedding `c`  
Corrupted Structure + `c` → Conditional Denoiser (Same Backbone + AdaNorm) → L1 Noise Prediction

**Critical Path (Pretraining):** For each batch, 1) generate clean embeddings, pool to get `c`, 2) corrupt atom positions, 3) run denoiser conditioned on `c`, 4) compute MSE between predicted and true noise, 5) backpropagate. Conditioning dropout is applied to `c` with 20% probability.

**Design Tradeoffs:**
*   *Noise Scale (σ_corr):* Larger σ increases task difficulty but may distort chemical meaning; σ=0.04 Å balances denoising and chemistry preservation.
*   *Conditioning Dropout:* 20% dropout prevents the model from becoming over-reliant on `c` and encourages learning within the denoiser itself. 0% dropout causes significant performance drop.
*   *Backbone Choice:* CT vs. CGT tradeoff between expressivity and computational cost; both work, showing backbone-agnosticism.

**Failure Signatures:**
*   **Training Instability (NaNs/Exploding Loss):** Often due to unfrozen element embeddings during pretraining. **Remedy:** Freeze element embeddings and use drop_path (0.1).
*   **Poor Downstream Transfer:** Likely missing conditioning dropout or incorrect noise scales. **Diagnostic:** Compare denoising loss curves; visualize pooled embeddings (UMAP) to check atom count correlation.
*   **Periodic Data Failure:** Model performs poorly on Matbench if crystal augmentation (unit cell repeats) is disabled during AMP20/ALL pretraining.

**First Three Experiments:**
1.  **Replicate PCQ Pretraining:** Pretrain a CT backbone on PCQ for 800k steps (effective batch 512) with σ_corr=0.04 Å, σ_reg=0.005 Å, and element embeddings frozen. Monitor denoising MSE convergence.
2.  **QM9 HOMO Finetuning:** From the pretrained checkpoint, finetune on QM9 HOMO for 300k steps (batch 128, LR 5e-4). Target test MAE should be ≤13.0 meV.
3.  **Ablate Conditioning Dropout:** Repeat Experiment 2 with `--cond_dropout 0.0`. Expect a significant degradation (>1 meV MAE increase on HOMO), demonstrating the necessity of conditional denoising.

## Limitations
*   **Reproducibility Gaps:** Exact random seeds, data splits, and full preprocessing details (e.g., reference energies for QM9 targets) are not disclosed, introducing variance in reproduced metrics.
*   **Evaluation Scope:** Results are shown on a limited set of benchmarks (QM9, Matbench, LBA). Generalization to broader chemical and materials spaces is unproven.
*   **Cost Comparison:** While SCD uses smaller models, the total pretraining computational cost is not benchmarked against full supervised force-energy pretraining on large datasets.

## Confidence
*   **SCD outperforms prior SSL on QM9 HOMO:** **Medium** – result is clear but sensitive to unreported training details (seeds, hyperparameters).
*   **SCD matches supervised force-energy pretraining on Matbench:** **Low** – comparison involves models of different scales; a controlled ablation isolating data volume effect is needed.
*   **Backbone-agnostic efficacy (CT/CGT):** **High** – method definition and results for both architectures are explicit.

## Next Checks
1.  **Controlled Replication:** Fix a random seed, pretrain SCD (CT) on PCQ, and finetune on QM9 HOMO. Confirm test MAE within 0.3 meV of the reported 12.7 meV.
2.  **Sensitivity Ablation:** Systematically vary conditioning dropout (0%, 10%, 20%) and corruption noise σ (0.03, 0.04, 0.05 Å) during pretraining. Measure impact on downstream HOMO MAE; expect optimal performance at reported settings.
3.  **Out-of-Distribution Generalization:** Evaluate a model pretrained on PCQ/GEOM10 on a disjoint dataset like ANI-1x or a solid-state property benchmark (e.g., JARVIS) to test transfer beyond the paper's evaluated domains.
