# Mem-Gallery: Benchmarking Multimodal Long-Term Conversational Memory for MLLM Agents

## Quick Facts
*   **arXiv ID:** 2601.03515
*   **Source URL:** https://arxiv.org/abs/2601.03515
*   **Reference count:** 40
*   **Primary result:** Explicit multimodal memory (storing raw images) significantly outperforms textual memory with captions, but memory reasoning and knowledge management remain major bottlenecks.

## Executive Summary
This paper introduces Mem-Gallery, a novel benchmark designed to evaluate multimodal long-term conversational memory in Multimodal Large Language Model (MLLM) agents. It addresses a critical gap: prior benchmarks focus solely on text-only multi-session memory or single-session multimodal understanding. Mem-Gallery provides 240 long-horizon conversations (12 sessions average) grounded in both images and text, featuring rich cross-session dependencies. The benchmark evaluates memory across three functional dimensions—memory extraction & adaptation, memory reasoning, and memory knowledge management—encompassing nine specific tasks. Evaluations of 13 memory systems using Qwen-2.5-VL-7B reveal that preserving raw visual data (e.g., via MuRAG) is essential for peak performance, while reasoning over stored memories and managing knowledge conflicts persist as significant unsolved challenges, compounded by substantial computational overhead.

## Method Summary
Mem-Gallery constructs a dataset of 240 human-annotated, multi-session conversations where each session contains image-text dialogue turns. Conversations are designed to require recalling facts, reasoning over temporally distributed clues, and resolving knowledge updates from previous sessions. The associated evaluation framework defines nine tasks grouped into three dimensions: (1) **Extraction & Adaptation** (e.g., fact retrieval, visual-centric search, test-time learning), (2) **Reasoning** (e.g., temporal reasoning, visual-centric reasoning, multi-entity reasoning), and (3) **Knowledge Management** (e.g., knowledge resolution, conflict detection, answer refusal). Baselines include textual memory methods (e.g., MemGPT), multimodal memory (e.g., MuRAG, Full Memory), and structured memory (e.g., AUGUSTUS), all built upon a consistent MLLM backbone (Qwen-2.5-VL-7B) to isolate the memory architecture's effect.

## Key Results
*   Explicit multimodal preservation (MuRAG: 0.6966 F1) significantly outperforms the best textual memory with captions (0.6228 F1), demonstrating the critical importance of retaining raw visual information.
*   Memory reasoning and knowledge management tasks are persistent challenges; even the best systems show low performance on temporal, visual-centric, and conflict detection scenarios, with minimal improvement from scaling the backbone model.
*   Naïve multimodal memory (Full Memory MM) incurs prohibitive efficiency costs and performs worse than structured retrieval methods, highlighting the need for selective retrieval and principled organization.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** Explicit multimodal preservation (storing raw visual data) significantly outperforms textual memory with image captions for multimodal long-term conversational memory.
*   **Mechanism:** Multimodal memory methods encode images into joint vision–language embeddings, preserving fine-grained visual details (e.g., textures, subtle patterns) that captions often lose. This enables precise retrieval of image-relevant facts and supports visual-centric reasoning.
*   **Core assumption:** Visual information contains irreplaceable, high-fidelity details critical for tasks like visual-centric search and test-time learning, which textual summaries cannot fully capture.
*   **Evidence anchors:** Abstract ("explicit multimodal preservation (MuRAG: 0.6966 F1) significantly outperforms textual memory with captions (best: 0.6228 F1)"), Section 4.2 RQ1 (11.85% F1 improvement).

### Mechanism 2
*   **Claim:** Principled organization and selective retrieval are critical because naïve multimodal accumulation incurs prohibitive token overhead and performance degradation.
*   **Mechanism:** Including all raw images (Full Memory MM) consumes many tokens and introduces noise, crowding out informative text. Structured methods (e.g., MuRAG's dense retrieval) select only relevant visual entries, reducing context length while maintaining signal.
*   **Core assumption:** Visual tokens are far more expensive than text tokens; indiscriminate inclusion degrades performance by adding irrelevant visual noise and limiting space for textual context.
*   **Evidence anchors:** Abstract ("multimodal memory introduces substantial efficiency overhead"), Section 4.2 RQ2 (Full Memory MM performs 8.08% and 51.85% worse F1 than Full Memory Text and MuRAG), Section 4.3 (Figure 5 shows higher time costs).

### Mechanism 3
*   **Claim:** Memory reasoning and knowledge management remain persistent bottlenecks, as existing models focus on storage/retrieval but not cross-modal integration or dynamic state tracking.
*   **Mechanism:** Models achieve moderate success in factual retrieval but falter on temporal reasoning, visual-centric reasoning, multi-entity reasoning, conflict detection, and answer refusal. This stems from lacking mechanisms to link multimodal clues over time or update beliefs when contradictions appear.
*   **Core assumption:** Long-horizon conversational memory requires not just recall but also reasoning over distributed multimodal evidence and regulating knowledge under evolution.
*   **Evidence anchors:** Abstract ("memory reasoning and knowledge management remain persistent challenges"), Section 4.2 RQ3 (struggles on reasoning tasks, limitations with updates/conflicts), Section 4.6.1 (reasoning scores improve only marginally with stronger backbones).

## Foundational Learning
*   **Concept:** Multimodal Memory
    *   *Why needed here:* Distinguishes storing raw images vs. textual captions; core to understanding why explicit visual preservation helps.
    *   *Quick check:* "Can a caption fully represent a dog’s breed-specific coat pattern for a visual-centric search task?"
*   **Concept:** Memory Extraction & Adaptation
    *   *Why needed here:* Baseline capability; if agents cannot retrieve facts or adapt to new multimodal examples, higher-level reasoning fails.
    *   *Quick check:* "Is the model recalling information from Session 1 when asked in Session 12, or just using recent context?"
*   **Concept:** Memory Knowledge Management
    *   *Why needed here:* Conversational memory evolves; agents must detect contradictions, update beliefs, and refuse unsupported queries to avoid hallucinations.
    *   *Quick check:* "When the user corrects earlier information, does the model discard the outdated fact or still use it?"

## Architecture Onboarding
*   **Component map:** Stream (Sessions) -> Update operator Φ -> Memory (M) -> Retriever R -> Retrieved Memory (M_ret) -> Generator (MLLM) -> Answer (y)
*   **Critical path:**
    1.  Stream conversation sessions → Φ incrementally updates external memory M.
    2.  At evaluation query, R retrieves K entries from M.
    3.  Concatenate C ⊕ M_ret ⊕ q → MLLM → answer.
    4.  Evaluate across three dimensions: extraction/adaptation, reasoning, knowledge management.
*   **Design tradeoffs:**
    *   *Storage:* Raw images (high fidelity, high token cost) vs. captions (lossy, cheap).
    *   *Retrieval size K:* Larger K improves recall but lowers precision; moderate K (≈10) often optimal.
    *   *Organization:* Unstructured (Full Memory) vs. structured (MuRAG’s joint embedding, AUGUSTUS’s concept graph) – structure improves precision but adds complexity.
*   **Failure signatures:**
    *   *Extraction:* Low FR/VS/TTL scores despite strong backbone → inadequate visual preservation.
    *   *Reasoning:* Discrepancy between retrieval success and answer correctness → weak multimodal reasoning.
    *   *Knowledge management:* High answer refusal for correct queries or missed contradictions → poor conflict detection/update.
    *   *Efficiency:* Orders-of-magnitude higher time for multimodal memory → token bloat or inefficient retrieval.
*   **First 3 experiments:**
    1.  **Multimodal vs. textual memory ablation:** Run MuRAG (multimodal) vs. MemGPT (textual + captions) on FR/VS/TTL tasks; expect clear multimodal advantage.
    2.  **Retriever size analysis:** Sweep K ∈ {5,10,15,20} for MuRAG/UniversalRAG; plot performance vs. precision to identify saturation point.
    3.  **Backbone scaling:** Test Qwen-2.5-VL-3B, 7B, GPT-4.1-Nano, Gemini-2.5-Flash-Lite with same memory method (e.g., A-Mem); observe whether reasoning gaps narrow.

## Open Questions the Paper Calls Out
### Open Question 1
*   **Question:** How can multimodal memory systems be architecturally designed to support effective reasoning over temporally distributed and modality-fused information in long conversations?
*   **Basis in paper:** [explicit] The paper states that multimodal memory methods "still primarily focus on the storage and retrieval of multimodal information, yet how to effectively reason over multimodal contents in memory remains largely unexplored" (RQ3-1).
*   **Why unresolved:** Current systems show poor performance on temporal, visual-centric, and multi-entity reasoning tasks, indicating a lack of mechanisms to integrate and infer from multimodal clues across sessions.
*   **What evidence would resolve it:** Introduce new reasoning modules or memory structures evaluated on Mem-Gallery reasoning subtasks with significant improvements over baselines.

### Open Question 2
*   **Question:** What memory maintenance mechanisms can enable dynamic knowledge resolution and accurate conflict detection when conversational information updates or contradicts prior entries?
*   **Basis in paper:** [explicit] The paper notes that "for both knowledge resolution and conflict detection tasks, neither multimodal nor textual memory methods achieve satisfactory performance" (RQ3-2), and highlights a trade-off in refusal behavior.
*   **Why unresolved:** Existing methods fail to update outdated beliefs or detect inconsistencies, leading to hallucinations or missed corrections.
*   **What evidence would resolve it:** Systems that achieve >80% F1 on KR and CD tasks in Mem-Gallery while maintaining high refusal accuracy.

### Open Question 3
*   **Question:** How can selective retrieval strategies be optimized to balance multimodal recall precision and computational overhead in long-horizon conversations?
*   **Basis in paper:** [explicit] The paper identifies an "efficiency bottleneck" where multimodal memory incurs "higher overhead" and shows that increasing retrieval size K leads to noise (A.6.2).
*   **Why unresolved:** Naive accumulation of visual tokens degrades performance; current multimodal retrievers have high recall but low precision at large K.
*   **What evidence would resolve it:** Retrieval methods that maintain >85% precision at K=10 while achieving comparable recall, reducing memory storage and retrieval time by >50% compared to Full Memory (MM).

### Open Question 4
*   **Question:** Beyond vision–language, how can multimodal memory benchmarks and systems incorporate additional modalities (e.g., audio, embodied signals) to evaluate real-world agentic memory?
*   **Basis in paper:** [explicit] In Limitations: "the benchmark focuses on vision–language conversational settings and does not explicitly cover other modalities such as audio or embodied signals."
*   **Why unresolved:** Real agents interact with diverse sensory inputs; current evaluation is limited to VL.
*   **What evidence would resolve it:** Extend Mem-Gallery or create new benchmarks with audio-visual or embodied data, and systems that unify multiple modalities in memory.

### Open Question 5
*   **Question:** What are the key architectural principles for organizing multimodal memory to maximize long-term retention and reasoning efficacy across varying backbone capabilities?
*   **Basis in paper:** [inferred] From A.6.1, the relative performance of memory methods remains stable across backbones, suggesting architecture matters more than backbone scaling. Also, RQ1 shows that simple multimodal preservation (MuRAG) outperforms complex structured models.
*   **Why unresolved:** It’s unknown how to balance raw multimodal storage vs. structured organization, and how these interact with MLLM capacity.
*   **What evidence would resolve it:** Ablation studies on memory structures (e.g., graph-based vs. vector-based) across multiple MLLMs, identifying configurations that consistently improve reasoning and management tasks.

## Limitations
*   Benchmark size (240 conversations, ~12 sessions) may not capture full diversity of real multimodal dialogues.
*   All experiments use Qwen-2.5-VL-7B; results could differ with other MLLMs.
*   Advantage of raw images assumes captions stay imperfect; future MLLMs might generate near-perfect captions, narrowing the gap.

## Confidence
*   **Explicit multimodal preservation > textual captions:** Medium (empirical gap strong but limited backbone variety and caption-quality dependence).
*   **Selective retrieval is essential:** High (clear performance drop and overhead with naive accumulation).
*   **Reasoning/knowledge management bottlenecks:** High (low scores persist across tasks and show minimal improvement with stronger backbones).

## Next Checks
1.  Replicate the benchmark with multiple MLLM backbones (e.g., GPT-4V, Claude 3, LLaVA) to test generalizability of findings.
2.  Ablate caption quality: use human annotations or state-of-the-art captioning models to see if raw-image advantage diminishes.
3.  Evaluate advanced retrieval methods (cross-encoder reranking, learned sparse retrieval) on memory reasoning tasks to assess whether improved selection alleviates the bottlenecks.
