# MiMo-V2-Flash Technical Report

## Quick Facts
- **arXiv ID:** 2601.02780
- **Source URL:** https://arxiv.org/abs/2601.02780
- **Reference count:** 31
- **Primary result:** MiMo-V2-Flash achieves competitive reasoning and agentic performance (e.g., 73.4% SWE-Bench Verified, 94.1% AIME25) with only 15B active parameters (309B total) through hybrid attention and multi-token prediction, delivering up to 2.6× decoding speedup.

## Executive Summary
MiMo-V2-Flash is a language model designed for efficient long-context reasoning and agentic tasks. It employs a hybrid attention mechanism that interleaves sliding window attention (SWA) with global attention in a 5:1 ratio, complemented by learnable attention sinks to reduce KV-cache overhead. A lightweight multi-token prediction (MTP) module acts as both a training objective and a speculative draft model, enabling significant decoding speedups. Post-training uses Multi-Teacher On-Policy Distillation (MOPD) to combine domain-specialized teacher rewards, facilitating mastery of diverse capabilities. With 309B total parameters but only 15B active during inference—half to one-third of comparable models—it matches or exceeds leading models like DeepSeek-V3.2 and Kimi-K2 on benchmarks including SWE-Bench and AIME25, while supporting near-perfect retrieval over 256K tokens.

## Method Summary
The architecture consists of 48 layers. Layer 0 uses global attention with a dense feed-forward network (FFN). Layers 1–47 repeat a pattern of five sliding window attention (SWA) blocks with Mixture-of-Experts (MoE) FFN followed by one global attention block with MoE FFN, forming seven hybrid groups. Each attention head incorporates a learnable sink bias to reduce cache size. The MTP module comprises a dense FFN preceded by SWA; during pre-training one head is attached to the main model with a loss weight of 0.3 (later 0.1), and after pre-training it is replicated to three heads for speculative inference. Pre-training proceeds in three stages: initial 22T tokens at 32K context, followed by code-upsampled data and synthetic reasoning, and finally extension to 256K context via increasing the global attention RoPE base. Post-training includes supervised fine-tuning on instruction data and reinforcement learning with MOPD, where domain-specific teachers provide token-level rewards combined with outcome rewards, using Rollout Routing Replay to maintain routing consistency.

## Key Results
- **Reasoning & coding:** 73.4% on SWE-Bench Verified, 71.7% on SWE-Bench Multilingual, 94.1% on AIME25.
- **Efficiency:** Up to 3.6 accepted tokens per MTP step and 2.6× overall decoding speedup.
- **Long context:** Near-perfect retrieval accuracy up to 256K tokens.
- **Parameter efficiency:** Matches or exceeds DeepSeek-V3.2 and Kimi-K2 with only 15B active parameters (309B total).

## Why This Works (Mechanism)
The hybrid attention design balances local computation (SWA) with periodic global coordination (GA), enabling efficient processing of long sequences without sacrificing the ability to integrate information across the entire context. Learnable attention sinks further compress the key-value cache by storing only a small, learnable set of tokens per head, reducing memory and accelerating attention. The MTP module, trained with a next-token prediction loss, provides draft tokens that are accepted at a high rate because its cross-entropy strongly predicts acceptance length; this speculative decoding yields substantial speedups. MOPD merges token-level rewards from specialized teachers (e.g., code, web agents) with outcome rewards, allowing the student to inherit peak capabilities without interference, while the reverse KL penalty prevents divergence. The MoE routing, combined with R3, ensures consistent expert activation between rollout and training, maintaining stability.

## Foundational Learning
**Hybrid Sliding Window + Global Attention:** Combines efficient local computation with periodic global integration; essential for scaling to long contexts. *Quick check:* Verify alternating block pattern in layer configuration.  
**Learnable Attention Sinks:** Reduces KV-cache by biasing queries toward a small set of cached keys; cuts memory while preserving accuracy. *Quick check:* Inspect query projection bias and cache size reduction.  
**Multi-Token Prediction (MTP):** Lightweight draft model that predicts multiple tokens per forward pass; drives speculative decoding. *Quick check:* Measure average acceptance length on validation set.  
**Multi-Teacher On-Policy Distillation (MOPD):** Distills multiple domain-specific teachers into a single student using combined token-level and outcome rewards. *Quick check:* Monitor token-level KL and task-specific performance during distillation.  
**Mixture of Experts (MoE):** Scales model capacity with sparse activation, keeping active parameters low. *Quick check:* Track expert load balance (gradient num-zeros) to detect routing collapse.  
**Rollout Routing Replay (R3):** Freezes rollout routing during training to avoid mismatch between training and inference expert assignments. *Quick check:* Compare expert activation distributions in rollout vs. training.

## Architecture Onboarding
**Component Map:**  
Input -> Token Embedding -> Layer0 (Global Attention + Dense FFN) -> [HybridGroup x7: (SWA + MoE FFN) x5 + (Global Attention + MoE FFN)] -> Final Norm -> Output Logits.  
Additionally: MTP Module (per head: RMSNorm -> SWA -> Dense FFN) attached during pre-training (1 head) and inference (3 heads). Learnable sink biases added to each attention head's query projection.

**Critical Path:**  
Data flows sequentially through the 48 layers. Each layer computes attention (either SWA or GA) using cached key-value pairs; GA uses full context while SWA uses a 128-token window. The FFN either dense (layer0) or MoE (others) with 256 experts, activating 8 per token. During inference, the MTP module runs in parallel to draft tokens, which are then verified by the main model in a single forward pass per accepted token.

**Design Tradeoffs:**  
- Sliding window size (128) vs. global attention ratio (5:1): smaller windows reduce computation but limit long-range interaction; periodic GA restores global coherence.  
- Attention sinks: smaller cache size improves memory but may risk losing peripheral information.  
- MTP depth (1 layer): deeper drafts increase acceptance rate but add overhead; 1 layer gives best tradeoff.  
- MoE expert count (256): more experts increase capacity but routing complexity; 8 active experts balances sparsity and performance.

**Failure Signatures:**  
- MoE load imbalance: increasing gradient `num-zeros` indicates routing collapse.  
- Low MTP acceptance: cross-entropy >0.2 suggests draft model divergence.  
- Lost-in-the-middle: accuracy drop for needles in the middle of long contexts.  
- Reward hacking in code tasks: presence of prohibited git commands in rollouts.  
- MOPD collapse: excessive KL divergence or plummeting acceptance rates.  
- FP8 instability: numerical errors in attention outputs or router logits.

**First Experiments:**  
1. **Active Parameter Verification:** Execute a forward pass on a dummy batch and count exactly non-zero parameters to confirm 15B active count.  
2. **MTP Acceptance Rate Replication:** Pre-train a small proxy model with single-head MTP, then expand to three heads and measure average acceptance length on held-out data; target >3.0.  
3. **Long-Context Retrieval Stress Test:** Perform a needle-in-haystack test at 128K and 256K context lengths, varying needle position, to verify retention near 100% accuracy.

## Open Questions the Paper Calls Out
1. **Scaling Efficiency:** How can the model's parameter efficiency be maintained while scaling up size and compute to close the gap with closed-weight models? The paper notes the current parameter count is only half to one-third of rivals, but scaling risks losing the efficiency gains from hybrid attention and MTP. Evidence needed: systematic scaling experiments preserving the 5:1 SWA:GA ratio and MTP design.  
2. **Architectural Trade-offs:** What are the fundamental trade-offs between sliding window size, hybrid ratio, and attention sink mechanisms? The current exploration is preliminary; theoretical understanding of why W=128 outperforms W=512 or all-GA is lacking. Evidence needed: ablation studies across model scales (1B–100B) with diagnostics on attention patterns and routing.  
3. **MOPD Scalability:** How far can Multi-Teacher On-Policy Distillation scale? The co-evolution cycle's stability and potential for catastrophic interference when using many teachers or conflicting capabilities are unknown. Evidence needed: scaling experiments with increasing numbers of domain teachers, measuring capability retention and gradient conflicts.  
4. **Entropy-Acceptance Correlation:** Does the strong correlation (R²=0.995) between next-token cross-entropy and MTP acceptance length generalize across architectures and data distributions? The correlation is derived from a single model; it may not hold under distribution shifts. Evidence needed: cross-architecture validation on diverse models and held-out domains, with causal interventions.  
5. **Agentic Optimal Balance:** What is the optimal local/global attention balance for agentic workflows? The current 5:1 ratio is tuned for general reasoning; agentic tasks (tool use, state tracking) may require different configurations. Evidence needed: systematic evaluation of hybrid SWA variants on agentic benchmarks (e.g., SWE-Bench, Tau2-Bench) with attention pattern diagnostics.

## Limitations
- The exact composition and preprocessing of the 27T pre-training corpus are not disclosed, hindering data-scale reproduction.  
- Critical reinforcement learning hyperparameters (e.g., KL coefficient, PPO clip range, rollout batch size) and implementation details of Rollout Routing Replay and Toolbox/Tool Manager are omitted.  
- The context extension to 256K tokens is achieved by changing the GA RoPE base, but it is unclear whether naive extrapolation or techniques like NTK-aware scaling are used, affecting long-context reliability.
