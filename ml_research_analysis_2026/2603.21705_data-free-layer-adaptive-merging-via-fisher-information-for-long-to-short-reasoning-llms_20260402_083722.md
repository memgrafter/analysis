# Data-Free Layer-Adaptive Merging via Fisher Information for Long-to-Short Reasoning LLMs

## Quick Facts
*   **arXiv ID:** 2603.21705
*   **Source URL:** https://arxiv.org/abs/2603.21705
*   **Reference count:** 40
*   **Primary result:** FIM-TIES merging achieves state-of-the-art accuracy on L2S benchmarks (e.g., +6.2 on MATH500 for 7B models) while reducing output length by ~92.6%, all without domain-specific data.

## Executive Summary
This paper addresses the challenge of merging a concise base model with a verbose long-chain-of-thought (long-CoT) model to create a model that retains the long-CoT's reasoning accuracy but produces shorter, more efficient outputs—a task termed Long-to-Short (L2S) reasoning. Standard model merging techniques like Task Arithmetic, which linearly interpolate model parameters, fail for L2S due to large, non-uniform parameter changes across layers. The authors theoretically link merging error to the per-layer Hessian norm and task vector magnitude, then propose a practical, data-free method to compute adaptive merging coefficients using the diagonal Fisher Information Matrix (FIM) as a Hessian proxy. Their FIM-Merging framework, implemented with TIES-Merging (FIM-TIES), assigns conservative merging coefficients to early layers and aggressive ones to later layers, significantly improving accuracy-efficiency trade-offs on reasoning benchmarks.

## Method Summary
FIM-Merging is a layer-adaptive merging framework that eschews task-specific calibration data. It first computes a diagonal Fisher Information Matrix (FIM) for the base model using only a small set of random token sequences, which serves as a data-free proxy for the per-layer Hessian norm. It then calculates a per-layer "importance score" by taking the logarithm of the product of this FIM and the squared norm of the task vector (δ = θ_finetuned - θ_base). These scores are adaptively normalized and passed through a sigmoid function to derive conservative-to-aggressive merging coefficients (α_l) for each layer. This coefficient assignment is combined with an enhanced TIES-Merging procedure, which includes scale-dependent pruning of task vector entries based on FIM-weighted magnitudes, protection of projection gate parameters, and residual norm calibration to ensure stable merging.

## Key Results
*   On the 1.5B benchmark, FIM-TIES achieves 47.3% average accuracy, surpassing the prior ACM-TIES method by +3.9 points, while reducing average response length by 92.6% relative to the long-CoT model.
*   On the 7B benchmark, it achieves state-of-the-art results on five out of six evaluations, including a significant +6.2 point gain on MATH500 (90.2% vs. 84.0%).
*   With self-consistency decoding (n=16), FIM-TIES reaches 36.7% on AIME24, exceeding ACM-TIES (33.3%) without any domain-specific calibration data.

## Why This Works (Mechanism)
### Mechanism 1: Error Bound for Linear Interpolation
**Claim:** The error from linearly merging models (Task Arithmetic) is bounded by a term proportional to the per-layer Hessian norm and the squared norm of the task vector. This bound explains why large, heterogeneous per-layer changes in L2S cause the linearity assumption to fail.
**Mechanism:** A second-order Taylor expansion of the model output around the base parameters shows that first-order terms cancel, leaving an error term of the form δᵀHδ. Bounding this by the operator norm yields ∥δ∥²∥H∥. Applied per-layer, this indicates higher merging error in layers where either the task vector norm (∥δₗ∥²) or the Hessian norm (∥Hₗ∥) is large.
**Evidence:** The paper provides a formal proof in Section 3.1 (Proposition 1, Equation 4). The abstract explicitly states this theoretical contribution.
**Break condition:** When per-layer task vector norms vary widely and Hessian norms are high—typical in L2S where reasoning capabilities are deeply embedded—the linearity violation becomes severe, increasing error.

### Mechanism 2: FIM as a Data-Free Hessian Proxy
**Claim:** The diagonal Fisher Information Matrix (FIM) computed at the base model is a valid, data-free proxy for the diagonal Hessian norm, enabling layer-adaptive merging without domain-specific calibration data.
**Mechanism:** At a local optimum of the negative log-likelihood, the Fisher-Hessian equivalence holds: F(θ*) = -𝔼[H log p(θ*)]. The diagonal FIM, estimated by averaging the squared gradients from forward/backward passes on random token inputs, approximates the diagonal of the Hessian. This estimated curvature scales with the difficulty of merging in each layer.
**Evidence:** Derived in Section 3.2 (Equation 6). The abstract emphasizes the data-free computation using random inputs.
**Break condition:** If the base model is poorly optimized (far from a likelihood optimum) or if random uniform token samples fail to capture salient features of the true data distribution, the FIM estimate becomes noisy, leading to suboptimal coefficient assignment.

### Mechanism 3: Adaptive Coefficient Mapping
**Claim:** Converting the FIM·∥δ∥² scores to per-layer coefficients via adaptive log-normalization and sigmoid mapping mitigates error by conservatively merging high-risk (high-score) early layers and aggressively merging low-risk later layers.
**Mechanism:** For each layer, an importance score sₗ = log(FIMₗ·∥δₗ∥²) is computed. These scores are median-normalized to ˜sₗ. An adaptive scaling parameter θ_adapt = 1 / range(˜sₗ) is set based on the score distribution. The final coefficient αₗ = 1 - σ(θ_adapt(˜sₗ - max ˜sₗ)) is derived via a sigmoid, creating a monotonic mapping from higher error risk (higher sₗ) to lower αₗ (more conservative merging).
**Evidence:** Described in the abstract and detailed in Section 4.1 (Equations 8-11, Figure 2 visualizes the resulting coefficient distribution).
**Break condition:** If the product FIM·∥δ∥² does not actually correlate with the per-layer merging error bound (e.g., due to model-specific nonlinearities not captured by the diagonal FIM), or if the adaptive θ_adapt is misestimated due to an atypical score distribution, the αₗ assignments become suboptimal.

## Architecture Onboarding
**Component map:** Base Model (θ₀) & Fine-tuned Model (θ₁) -> FIM Computation (N random sequences on θ₀) -> Task Vector Analysis (δ = θ₁ - θ₀, ∥δₗ∥²) -> Score Calculation (sₗ = log(FIMₗ·∥δₗ∥²)) -> Adaptive Normalization & Sigmoid (θ_adapt, αₗ) -> Enhanced TIES-Merging (FIM-weighted pruning, gate protection, norm calibration) -> Merged Model (ˆθ).

**Critical path:**
1.  Compute diagonal FIM on θ₀ using N=8 random token sequences via forward/backward passes.
2.  Compute task vector δ and its per-layer squared norms ∥δₗ∥².
3.  Calculate importance scores sₗ = log(FIMₗ·∥δₗ∥²), median-normalize to ˜sₗ, derive θ_adapt = 1 / range(˜sₗ), and compute final coefficients αₗ = 1 - σ(θ_adapt(˜sₗ - max ˜sₗ)).
4.  For each layer, weight task vector entries by FIMₗ·|δₗ| and prune below the (1-r)-th percentile (r=0.2 for 1.5B, r=0.4 for 7B).
5.  Apply αₗ to the pruned δₗ, with gate protection (αₗ_gate = 0.7·αₗ) for MLP projection layers.
6.  Merge: ˆθₗ = θ₀ₗ + αₗ·δₗ, then perform residual norm calibration (ϵ=0.05) if output norm deviates significantly.

**Design tradeoffs:**
*   **Data-free FIM vs. Calibration Data:** Random inputs are cheap and general but may miss domain-specific curvature. Using a small set of in-distribution calibration samples could improve the FIM proxy but breaks the data-free promise.
*   **Scale-dependent TIES Threshold:** Smaller models (1.5B) have lower parameter redundancy, so more aggressive pruning (r=0.2) removes noise. Larger models (7B) tolerate retaining more parameters (r=0.4). This is heuristic and not theoretically derived.
*   **Adaptive θ_adapt:** Avoids manual tuning by scaling the sigmoid to the score distribution's range. However, it assumes the score distribution's shape is consistent across model scales and tasks, which may not hold universally.

**Failure signatures:**
*   High variance in FIM estimates if the number of random sequences N is too small (<4), causing unstable and inconsistent αₗ across runs.
*   Degraded accuracy if the product FIM·∥δ∥² fails to predict actual per-layer interpolation error, possibly due to nonlinearities or off-diagonal Hessian terms ignored by the diagonal approximation.
*   Over-conservative merging (all αₗ near zero) if the range of normalized scores ˜sₗ is misestimated, leading to a merged model that is nearly identical to the base model and lacks the long-CoT's reasoning gains.
*   Post-merge residual norm deviation exceeding 5% typically indicates instability, often caused by overly aggressive αₗ in layers with high-norm task vectors.

**First 3 experiments:**
1.  **FIM Stability Test:** Vary the number of random sequences N (1, 2, 4, 8, 16) and measure the variance of the resulting αₗ coefficients across multiple random seeds. Expect coefficient variance to stabilize by N=8.
2.  **Coefficient Distribution Validation:** On a held-out small validation set, plot the final αₗ as a function of layer depth. Verify the expected monotonic pattern: early layers have low α (conservative), and later layers have high α (aggressive), matching Figure 2 in the paper.
3.  **Threshold Sensitivity Sweep:** For the target model scale, sweep the TIES pruning threshold r (e.g., 0.1, 0.2, 0.4, 0.6) on a small validation set and measure accuracy. Confirm the optimal r aligns with the paper's findings (0.2 for ~1.5B, 0.4 for ~7B models).

## Open Questions the Paper Calls Out
### Open Question 1
*   **Question:** What theoretical principle determines the optimal TIES threshold ratio as a function of model scale and parameter redundancy?
*   **Basis in paper:** The authors empirically find 20% for 1.5B and 40% for 7B models, attributing this to differences in parameter redundancy, but no formal derivation is provided.
*   **Why unresolved:** Without a theory, threshold selection remains a heuristic that may not generalize to other scales or architectures.
*   **What evidence would resolve it:** Derive a formula linking the threshold to metrics like the Fisher spectrum or task vector sparsity; validate across a wide range of model scales and architectures.

### Open Question 2
*   **Question:** Why does FIM-TIES achieve lower greedy decoding accuracy on AIME24 compared to ACM-TIES, while surpassing it with self-consistency decoding?
*   **Basis in paper:** Table 4 shows FIM-TIES at 23.3% (greedy) vs. ACM-TIES 33.3%, but FIM-TIES with n=16 reaches 36.7%.
*   **Why unresolved:** The paper does not analyze whether the gap arises from differences in output calibration, diversity of reasoning paths, or other factors.
*   **What evidence would resolve it:** Compare output entropy, confidence distributions, or reasoning path variability between the two methods on AIME24; conduct diagnostic probing to isolate the source of the greedy performance gap.

### Open Question 3
*   **Question:** Does computing the diagonal Fisher Information solely at the base model θ₀ accurately approximate the per-layer Hessian norm bound along the full merging trajectory?
*   **Basis in paper:** Proposition 1 bounds error by sup_t ∥H(θ₀ + tδ)∥, but FIM-Merging uses FIM(θ₀) only as a proxy.
*   **Why unresolved:** For large task vectors in L2S, the Hessian may vary significantly along the interpolation path, potentially invalidating the θ₀-only approximation.
*   **What evidence would resolve it:** Empirically compute Hessian diagonals at intermediate points between θ₀ and θ₁; correlate FIM(θ₀) with actual per-layer interpolation error; analyze conditions under which the single-point approximation holds.

## Limitations
*   The optimal TIES pruning threshold (r) is determined empirically per model scale, lacking a general theoretical formula for parameter redundancy.
*   The diagonal FIM approximation ignores off-diagonal Hessian terms and relies on the base model being near a local optimum and random inputs being representative, which may not always hold.
*   The paper does not provide an analysis for the specific greedy vs. self-consistency performance discrepancy on AIME24, leaving the underlying cause of the greedy decoding weakness unclear.
