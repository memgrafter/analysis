# Feature-Aware One-Shot Federated Learning via Hierarchical Token Sequences

## Quick Facts
- **arXiv ID:** 2601.03882
- **Source URL:** https://arxiv.org/abs/2601.03882
- **Reference count:** 15
- **Primary result:** FALCON improves one-shot federated learning on non-IID data (especially medical imaging) using hierarchical token sequences and distillation, achieving an average 9.58% accuracy gain over the strongest OSFL baseline, with up to 10.72% improvement on Tuberculosis.

## Executive Summary
FALCON is a one-shot federated learning framework designed for highly non-IID data, particularly in medical imaging. Instead of exchanging model weights, clients upload synthetic token sequences generated from a fixed pretrained visual encoder using hierarchical scale encoding (HSE) to capture multi-scale features (global context and local details). A multi-scale autoregressive (M-AR) transformer models the token distribution, while local classifiers are trained on real tokens. The server trains a global classifier on the aggregated synthetic tokens using knowledge distillation from the ensemble of local classifiers, reducing reliance on perfect synthesis.

Across six medical and natural datasets under feature and label non-IID splits, FALCON achieves an average accuracy boost of 9.58% over previous OSFL methods, with generation cost as low as 0.46 GFLOPs per sample and strong privacy (SSIM ~0.15).

## Method Summary
Each client applies Hierarchical Scale Encoding (HSE) to its images: a downsampled global view yields one coarse token, and a sliding window at original resolution produces multiple regional tokens. The sequence is processed by a fixed pretrained encoder (DINOv2-base). The client then trains (a) a local classifier on real token sequences via cross-entropy, and (b) a lightweight M-AR transformer generator that models the hierarchical token distribution using a block-wise causal mask and mixture density heads. After training, the client samples synthetic token sequences and uploads them along with its local classifier (or uploads the generator if the dataset is large). The server aggregates all synthetic sequences and trains a global classifier with a combined loss: cross-entropy on synthetic labels plus knowledge distillation from the ensemble of local classifiers. The final global model combines the fixed encoder with the trained classifier head.

## Key Results
- FALCON achieves an average accuracy improvement of 9.58% over the strongest OSFL baseline across six medical and natural datasets, with a peak gain of 10.72% on the Tuberculosis dataset.
- Generation cost is extremely low: 0.46 GFLOPs per sample, compared to 7600 GFLOPs for diffusion-based methods.
- Reconstructions from synthetic tokens yield low SSIM (0.15), demonstrating strong privacy preservation.

## Why This Works (Mechanism)
**Mechanism 1: Hierarchical Scale Encoding (HSE) mitigates feature misalignment.**  
The fixed pretrained encoder cannot be fine-tuned locally, so clients use HSE to extract a hierarchical token sequence: one global token from a downsampled image, plus multiple regional tokens from sliding windows at original resolution. This captures both global semantics and high-resolution local details without any local adaptation, reducing the domain shift between clients’ non-IID data and the encoder’s pretraining distribution.

**Mechanism 2: Multi-scale autoregressive (M-AR) generator respects hierarchical dependencies.**  
The generator models the joint distribution of the hierarchical token sequence by factorizing it into the global token distribution and the conditional distribution of region tokens given the global token. A transformer with block-wise causal mask enforces the coarse-to-fine generation order, while mixture density heads output continuous token embeddings. This structure learns meaningful dependencies between global and local features, yielding synthetic tokens that better match the real distribution.

**Mechanism 3: Knowledge distillation stabilizes global training despite imperfect synthesis.**  
The server trains the global classifier not only with synthetic labels but also with a distillation loss that aligns its softened outputs with the average softened outputs of all local classifiers (teachers). This ensemble knowledge compensates for distribution shifts between real and synthetic tokens, especially under severe non-IID conditions, making the final model less dependent on perfect generative modeling.

## Architecture Onboarding
**Component map:**  
Raw Data → Hierarchical Scale Encoding (HSE) using fixed Pretrained Encoder (f) → Real Token Sequence S_real → (parallel) Train Local Classifier (h_n) and Train M-AR Generator (g_n) → Sample Synthetic Sequences S_syn → Upload {h_n, S_syn} (or upload g_n if large) → Server aggregates S_syn → Train Global Classifier (h) with Distillation → Global Model w = f·h.

**Critical path:**  
1. Client extracts multi-scale tokens via HSE.  
2. Client trains local classifier on real tokens and generator on real tokens.  
3. Client synthesizes token sequences and uploads them (or generator).  
4. Server trains global classifier on synthetic tokens using combined cross-entropy and knowledge distillation from local classifiers.  
5. Final model = fixed encoder + global classifier head.

**Design tradeoffs:**  
- Generator fidelity vs. cost: M-AR captures dependencies but is slightly more complex than independent models; still very lightweight (0.46 GFLOPs) compared to diffusion (7600).  
- Fixed encoder vs. adapted: Not fine-tuning avoids client divergence but limits domain adaptability; HSE partly compensates by adjusting input scales.  
- Upload tokens vs. generator: Clients choose based on dataset size; threshold ~9,850 tokens (~147 MB) vs. 144 MB generator.  
- Distillation weight α: Fixed at 0.5; may need tuning for extreme non-IID.

**Failure signatures:**  
- High MMD between real and synthetic tokens → generator not modeling distribution; check training loss, GMM components, or causal mask.  
- Poor SSIM reconstruction → synthetic tokens lack identifiable information (good for privacy) but may be too degenerate; if SSIM too high, privacy broken.  
- Global accuracy drops when removing KD (α=0) → confirms distillation stabilizes; if not, verify local classifiers are well-trained and teacher ensemble is consistent.  
- Extreme non-IID (Dirichlet α=0.1) causing large gap between local and global accuracy → check HSE window coverage or consider larger regional token count; aggregation may be averaging biased classifiers.

**First 3 experiments:**  
1. **HSE ablation:** Train FALCON without HSE (only global token) on a medical dataset (e.g., PMRAM). Expect ~3–4% absolute drop in global accuracy, validating the need for regional tokens.  
2. **Generator architecture comparison:** Train AR, NAR, and M-AR generators on the same client data; compute MMD between real and synthetic token sequences. Expect M-AR to achieve the lowest MMD, confirming its hierarchical dependency modeling.  
3. **Distillation ablation:** Train global classifier with (α=0.5) and without (α=0) distillation under varying non-IID strengths. Without KD, expect a ~3.1% average accuracy drop, especially under high non-IID (Dirichlet α=0.1), isolating KD’s compensatory role.

## Open Questions the Paper Calls Out
- **How can hierarchical scale encoding (HSE) be standardized across heterogeneous clients in one-shot FL without sacrificing domain-specific adaptability?** Current HSE uses fixed sliding window parameters and a shared pretrained encoder, but clients have varying resolutions, computational resources, or data characteristics. Future work could develop adaptive HSE frameworks that allow client-specific adjustments while maintaining global consistency.  
- **Can generative models beyond the multi-scale autoregressive (M-AR) transformer significantly improve fidelity and efficiency for modeling hierarchical token sequences?** M-AR uses block-wise causal masking and GMM heads, but may not fully capture complex dependencies in high-resolution medical images. Alternatives like diffusion, normalizing flows, or more expressive transformers could offer better trade-offs, provided they remain computationally light.  
- **Under what distributional mismatch between real and synthetic token sequences does knowledge distillation fail, and how can the distillation mechanism be made more robust?** In extreme non-IID or poor generative quality, the ensemble of local classifiers may be noisy or biased, harming global training. Understanding failure modes and designing adaptive distillation (e.g., confidence-weighted KL) is needed for reliability.

## Limitations
- **HSE rigidity:** The fixed window/stride (224 for 448×448 images) yields only four regional tokens; may not generalize well to varying resolutions or aspect ratios without position interpolation distortions, potentially losing fine details.  
- **M-AR specification ambiguity:** The exact block-wise causal mask pattern (whether region tokens attend autoregressively among themselves or only to the global token) is underspecified, leading to implementation uncertainty and reproducibility challenges.  
- **Privacy guarantees informal:** While low SSIM reconstructions suggest privacy, there is no formal analysis (e.g., differential privacy, membership inference resistance), leaving the privacy-utility trade-off not fully quantified.

## Confidence
- **Fixed encoder generalizes to medical domains:** Low – no in-domain pretraining, yet gains are large; success may rely on HSE compensating or incidental inclusion of medical textures in web pretraining.  
- **HSE captures multi-scale features effectively:** High – ablation studies show ~3–4% drop without HSE; multi-scale tokens clearly benefit non-IID scenarios.  
- **M-AR generator improves distribution matching:** Medium – MMD ablation favors M-AR, but causal mask details are ambiguous and alternative architectures not exhaustively tested.  
- **Distillation stabilizes training despite imperfect synthesis:** High – removing KD causes ~3.1% average accuracy drop, confirming its compensatory role.

## Next Checks
1. **HSE window/stride sensitivity:** Systematically vary stride (e.g., 112, 224) and patch size on a medical dataset (PMRAM) to measure impact on global accuracy and local classifier performance. If accuracy drops with smaller strides, generator capacity may become a bottleneck.  
2. **M-AR causal mask implementation:** Implement two variants: (a) full causal mask across all hierarchical tokens (global first, then regions in raster order), (b) block-wise mask that isolates regions from each other (only attend to global). Evaluate MMD and final accuracy to resolve the independence vs. autoregression tension.  
3. **Distillation teacher ensemble robustness under extreme non-IID:** Under Dirichlet α=0.05, measure variance of local classifier predictions on synthetic tokens. If high, test alternatives: median aggregation or confidence-weighted teacher averaging, and monitor global accuracy to diagnose whether current averaging is optimal.
