# Learning to Forget: Sleep-Inspired Memory Consolidation for Resolving Proactive Interference in Large Language Models

## Quick Facts
- arXiv ID: 2603.14517
- Source URL: https://arxiv.org/abs/2603.14517
- Reference count: 40
- Primary result: SleepGate achieves near-perfect retrieval accuracy (99.5% at PI depth 5, 97.0% at depth 10) while baselines fall below 18%.

## Executive Summary
Proactive interference (PI) in large language models occurs when outdated context entries in the KV cache interfere with retrieval of newer information, causing accuracy to degrade log-linearly with context length. The paper introduces SleepGate, a sleep-inspired memory consolidation framework that periodically performs micro "sleep" cycles during inference. These cycles use a conflict-aware tagger to identify superseded entries, a learned forgetting gate to selectively evict or compress them, and a consolidation module to merge related entries, triggered by an entropy-based metric. SleepGate dramatically reduces effective interference horizon from O(n) to O(log n) and achieves >97% retrieval accuracy even under high PI depths, far outperforming five strong baselines.

## Method Summary
SleepGate operates alongside the transformer during inference, periodically activating a sleep cycle on the KV cache. First, a conflict-aware tagger scans the cache to mark entries that have been superseded by newer information, based on semantic similarity and attention patterns. Next, a learned forgetting gate decides whether each tagged entry should be evicted entirely or compressed (e.g., via summarization or averaging). Finally, a consolidation module merges compatible entries to preserve relevant context while reducing noise. The cycle is triggered when the entropy of the attention distribution exceeds a threshold, indicating growing uncertainty. This biologically inspired process mirrors sleep-dependent memory consolidation, aiming to prune stale memories and strengthen important ones.

## Key Results
- SleepGate achieves 99.5% retrieval accuracy at PI depth 5 and 97.0% at PI depth 10.
- All five baselines (full KV, sliding window, H2O, StreamingLLM, decay-only) remain below 18% accuracy under the same conditions.
- Theoretical analysis: effective interference horizon reduced from O(n) to O(log n).

## Why This Works (Mechanism)
Proactive interference arises because the KV cache retains all past tokens, causing outdated keys to compete with current ones during attention. SleepGate mitigates this by dynamically identifying and removing or compressing superseded entries, thus reducing the noise in the attention mechanism. The conflict-aware tagger detects when a newer token renders an older one obsolete (e.g., contradictory facts), the forgetting gate makes selective eviction decisions learned to preserve critical information, and consolidation merges related entries to maintain coherence. The entropy trigger ensures cycles run only when interference becomes severe, minimizing disruption. Together these steps maintain a compact, high-fidelity context representation, effectively shrinking the interference horizon from linear to logarithmic in context length.

## Foundational Learning
1. **Proactive Interference (PI)**  
   *Why needed:* PI describes the phenomenon where older memories hinder recall of newer ones, directly motivating the need for memory management in LLMs.  
   *Quick check:* Does accuracy degrade as context length increases? Yes → PI present.

2. **KV Cache Management**  
   *Why needed:* The KV cache stores past key-value pairs for autoregressive decoding; its growth leads to computational and interference challenges.  
   *Quick check:* Is the cache size proportional to sequence length? Yes → needs pruning.

3. **Attention Entropy as Uncertainty Signal**  
   *Why needed:* High entropy indicates attention is spread thinly, often due to interference; used to trigger sleep cycles.  
   *Quick check:* Compute entropy of attention distribution; if above threshold, interference likely.

4. **Memory Consolidation (Biological Inspiration)**  
   *Why needed:* Sleep in biological systems strengthens memories and discards irrelevant ones; provides a high-level framework for artificial memory cleaning.  
   *Quick check:* Does periodic consolidation improve retention? In SleepGate, yes.

5. **Learned Forgetting Mechanisms**  
   *Why needed:* A parametric gate learns which entries to forget/compress, adapting to task-specific interference patterns.  
   *Quick check:* Trainable parameters control eviction; performance sensitive to their values.

## Architecture Onboarding
**Component Map**  
Conflict-Aware Tagger -> Learned Forgetting Gate -> Consolidation Module -> (updated KV cache)

**Critical Path**  
During inference, after processing a new token, the system monitors attention entropy. When entropy exceeds trigger threshold, it initiates a sleep cycle: the tagger marks stale entries, the forgetting gate decides eviction/compression, consolidation merges entries, and the KV cache is updated. Then inference resumes.

**Design Tradeoffs**  
- *Eviction vs. Compression:* Aggressive eviction reduces cache size but risks losing information; compression retains more but adds computational overhead.  
- *Trigger Frequency:* Too frequent cycles increase latency; too infrequent may let interference accumulate.  
- *Consolidation Granularity:* Merging too broadly can blur distinct concepts; too fine-grained yields limited benefit.

**Failure Signatures**  
- Drop in retrieval accuracy on recent queries, especially after many tokens.  
- High entropy persists without reduction after a sleep cycle, indicating ineffective tagger or gate.  
- Latency spikes correlated with sleep cycles if consolidation is too expensive.
