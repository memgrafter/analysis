# Not Too Short, Not Too Long: How LLM Response Length Shapes People's Critical Thinking in Error Detection
## Quick Facts
- **arXiv ID:** 2603.06878
- **Source URL:** https://arxiv.org/abs/2603.06878
- **Reference count:** 15
- **Primary result:** Medium-length LLM explanations yield highest error-detection accuracy (54%) when the explanation is incorrect, compared to short (25%) or long (31%); accuracy is uniformly high for correct explanations regardless of length (71%-81%).

## Executive Summary
This study examines how the length of AI-generated explanations influences people's ability to critically evaluate those explanations for correctness. In a within-subjects experiment, 24 participants assessed 15 critical thinking items, each paired with an LLM explanation that varied in length (short, medium, long) and contained either a correct or incorrectly planted conclusion. The key finding is a significant interaction: when the LLM explanation was incorrect, medium-length outputs led to substantially higher error-detection accuracy than shorter or longer ones. When explanations were correct, accuracy remained high across all lengths. This indicates a "sweet spot" where a moderate amount of text optimally supports human scrutiny of flawed AI reasoning.

## Method Summary
Participants evaluated 15 modified Watson–Glaser critical thinking questions. For each, they saw an LLM-generated explanation consisting of step-by-step reasoning and a final yes/no conclusion. Explanations were manipulated to be short, medium, or long in word count and to either correctly answer the question or contain a planted error in the final conclusion (while the reasoning steps remained sound). Each participant saw all 15 items in random order, with length and correctness conditions counterbalanced across the sample. Accuracy was measured as the binary correctness of the participant's judgment about the LLM's output. Data were analyzed using a mixed-effects logistic regression with a random intercept for question to account for item difficulty and within-subject correlations.

## Key Results
- For incorrect LLM explanations, participant accuracy was highest with medium length (54% predicted probability) versus short (25%) or long (31%).
- For correct LLM explanations, accuracy was uniformly high across all lengths (71%-81%).
- The significant interaction indicates a non-linear length effect: medium-length text provides a "sweet spot" for detecting errors in flawed AI outputs, while longer explanations do not improve—and may impair—scrutiny.

## Why This Works (Mechanism)
**Mechanism 1: Optimal Cognitive Balance**  
Medium-length explanations strike a balance between providing sufficient reasoning detail and avoiding cognitive overload, enabling better error detection when the LLM is incorrect. Short explanations may lack transparency, making errors harder to spot; long explanations exceed working memory capacity, prompting heuristic trust rather than analytical processing. The encoding-storage paradigm suggests effective evaluation requires adequate encoding without excessive load. Break condition: If task complexity is extreme or users are highly expert, the sweet spot may collapse.

**Mechanism 2: Authority Heuristic Mitigation**  
Longer explanations inflate perceived authority due to processing fluency heuristics, increasing uncritical acceptance of incorrect conclusions. LLM outputs are inherently fluent and verbose; thus, longer texts amplify the illusion of correctness and reduce scrutiny. Medium length does not trigger this bias as strongly, preserving some analytical engagement. Break condition: User training to distrust verbosity or system warnings about length-trust bias could attenuate the effect.

**Mechanism 3: Inconsistency Visibility**  
Medium-length step-by-step reasoning chains allow users to hold the entire sequence in working memory and spot contradictions between intermediate steps and the final conclusion. Short explanations omit key premises; long explanations bury the logical trail within excessive detail. The study's explanation structure (analysis + conclusion) supports this coherence-checking mechanism. Break condition: If reasoning flaws appear consistent or the conclusion is correct despite flawed steps, errors may remain undetected regardless of length.

## Architecture Onboarding
**Component map:**  
User → Query Interface → Explanation Engine (with Length Controller) → Presentation Module → User Judgment → Feedback Collector → Analytics Backend

**Critical path:**  
User submits a critical thinking item → Query Interface captures the prompt → Explanation Engine generates an LLM response with a specified length constraint → Length Controller ensures output complies with the target length → Presentation Module renders the explanation (with analysis and conclusion clearly separated) → User provides a correctness judgment → Feedback Collector records the decision and optional rationale → Analytics Backend aggregates data for system adaptation.

**Design tradeoffs:**  
- Fixed length categories (short/medium/long) simplify implementation but may not capture nuanced optimal lengths for all items or users; continuous control offers precision but adds complexity.  
- Automatic correctness validation (e.g., via LLM self-consistency) could avoid showing incorrect outputs but introduces latency and reliability concerns.  
- Transparency vs. cognitive load: Longer explanations improve detail but risk overwhelming users; medium length is a compromise but may not suit all tasks or expertise levels.  
- Real-time adaptation: Dynamically adjusting length based on user performance could personalize support but requires robust profiling and may increase system opacity.

**Failure signatures:**  
- Elevated user agreement with incorrect LLM outputs specifically when explanations are long, indicating trust inflation.  
- Users making judgments almost immediately after viewing an explanation, suggesting superficial processing.  
- System-generated outputs that violate length constraints (e.g., too long/short), leading to inconsistent study results.  
- Analytics showing no variation in detection accuracy across length conditions, implying possible content mismatch or failed manipulation.

**First 3 experiments:**  
1. **Replication with Model Diversity:** Conduct a between-subjects experiment using at least three distinct LLMs (e.g., GPT-4, Claude 3, Llama 3) to confirm the length × correctness interaction is not model-specific.
2. **Structural Separation Test:** Compare two presentation formats: integrated (analysis and conclusion combined) vs. separated (distinct visual panels). Hypothesis: separation improves error detection for medium-length explanations by making inconsistencies more salient.
3. **Adaptive Length Pilot:** Implement a system starting with medium length and offering a "Show more detail" button. Measure whether user-controlled expansion yields higher accuracy than fixed medium length, and whether users actually expand when needed.

## Open Questions the Paper Calls Out
1. **Cross-Model Variation:** Do different LLM models (e.g., GPT-5 vs. Gemini vs. Claude) produce outputs that differentially impact users' critical thinking accuracy when varying in length and correctness?
2. **Multilingual and Cultural Effects:** Does the optimal LLM output length for supporting error detection vary across languages and cultural contexts, given potential differences in information density and communication norms?
3. **Causal Role of Word Count:** When LLM output information content is held constant, what is the causal effect of word count on critical thinking accuracy, independent of reading time and cognitive load?

## Limitations
- **Stimulus generation:** The exact prompting strategy to vary length while keeping reasoning content consistent is unspecified, risking confounding between verbosity and explanation quality.
- **Error manipulation:** Criteria for planting errors in the LLM's conclusion (e.g., opposite answer, different choice) and validation methods are not detailed, leaving uncertainty about error type balance.
- **Generalizability:** Findings are based on a single LLM (GPT-5), a small professional sample (N=24), and a specific critical thinking task, limiting applicability to other models, user groups, or domains.

## Confidence
- **Primary interaction effect (medium-length best for incorrect outputs):** High – Direct, pre-registered outcome of the primary analysis.
- **Proposed mechanisms (cognitive load, authority heuristic, inconsistency visibility):** Medium – Plausible post-hoc interpretations supported by qualitative data and prior literature, but not causally isolated.
- **Sweet spot generalization (universal optimal length):** Low – Effect is specific to incorrect outputs in this task; may not hold for different complexities, tasks, or expert users.

## Next Checks
1. **Replication with Model Diversity:** Run a between-subjects study using multiple LLMs (e.g., GPT-4, Claude 3, Llama 3) to generate length-controlled outputs and test whether the interaction replicates across models.
2. **Content-Quality Control Pilot:** For new stimuli, have independent raters blind to length condition evaluate the reasoning steps (excluding the conclusion) for logical soundness. Only include items where reasoning quality is statistically equivalent across lengths to isolate word count effects.
3. **Presentation Format A/B Test:** Experimentally compare integrated vs. structurally separated explanation displays, measuring error detection accuracy for each length condition to directly test the "inconsistency visibility" mechanism.
