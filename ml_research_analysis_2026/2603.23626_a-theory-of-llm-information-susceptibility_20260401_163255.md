# A Theory of LLM Information Susceptibility

## Quick Facts
- arXiv ID: 2603.23626  
- Source URL: https://arxiv.org/abs/2603.23626  
- Reference count: 40  
- Primary result: A fixed LLM layer cannot improve the asymptotic performance susceptibility (∂J/∂B) relative to the base algorithm; nested co‑scaling architectures can exceed this bound.

## Executive Summary
This paper investigates whether inserting a fixed large language model (LLM) into an optimization pipeline can enhance the rate at which performance scales with computational budget. It hypothesizes that for fixed architectures, the performance susceptibility (the derivative of performance with respect to budget) of an LLM‑derived strategy set cannot exceed that of the base strategy set in the large‑budget limit, implying a relative sensitivity α ≤ 1. The hypothesis is grounded in an information‑theoretic argument: the LLM acts as a finite‑capacity channel that cannot amplify the mutual information between the base strategies and the optimum. Empirical validation across four domains (Tetris, 0/1 Knapsack, world‑knowledge Ranking, AIME mathematics) using Qwen models from 7B to ~200B parameters consistently shows that while LLMs may boost absolute performance at finite budgets, the susceptibility of LLM‑derived strategies is never greater than that of the base algorithms once computational resources are sufficiently large. However, nested architectures where the generator and selector co‑scale can achieve total susceptibility α_total > 1, suggesting that co‑scaling is a structural condition for exceeding the susceptibility bound.

## Method Summary
The paper compares base algorithms (beam search, majority vote, etc.) and LLM‑derived strategies across a range of compute budgets. For each budget level, a base strategy set is generated and then processed by an LLM (either fixed or nested) to produce a derived set. Performance J (domain‑specific metrics: lines cleared, total value, accuracy) is measured for both. Susceptibility α is defined as the ratio of the performance slope (∂J/∂B) for the derived strategy to that for the base. For nested architectures with multiple co‑varying budget variables (e.g., generator size and selector size), a multi‑variable linear response framework computes total sensitivity. Experiments use Qwen models of increasing size on four tasks, sweeping key budget parameters (beam width, sample count, model size) and repeating over random seeds to estimate slopes reliably.

## Key Results
- Fixed LLM intervention never increases asymptotic susceptibility (α ≤ 1) across all four domains.
- For AIME mathematics, the relative susceptibility α for fixed selectors drops below 1 around k ≈ 12 samples.
- Nested architectures (generator and selector co‑scaling) can achieve total susceptibility α_total > 1 under positive coupling, surpassing the bound for fixed configurations.

## Why This Works (Mechanism)
### Mechanism 1
- Claim: A fixed LLM cannot increase asymptotic performance susceptibility because it acts as a finite‑capacity information channel.
- Mechanism: The LLM receives the base strategy set and outputs a derived set, forming a channel with limited capacity (context window, parameters). By the data‑processing inequality, mutual information *I*(derived; optimum) ≤ *I*(base; optimum). As budget *B* grows, *I*(base; optimum) increases, but the channel cannot amplify this information gain, so the marginal performance improvement per unit budget (∂*J*/∂*B*) does not increase.
- Core assumption: The LLM mapping is fixed and does not scale with budget; its capacity is finite and independent of *B*.
- Evidence anchors:
  - [abstract] The abstract states: "We hypothesize that when computational resources are sufficiently large, the intervention of a fixed LLM does not increase the performance susceptibility… The fixed LLM can be viewed as a deterministic channel with finite capacity… cannot amplify the marginal information content of additional budget."
  - [section, Page 2] "a fixed LLM can be viewed as a deterministic (or fixed‑distribution) channel with finite capacity: it compresses the input strategy set through a fixed‑dimensional representation… Since the mutual information between the derived set and the optimal strategy cannot exceed that between the base set and the optimal strategy by data‑processing‑inequality reasoning, the marginal return on budget cannot increase through the LLM intervention."
  - [corpus] Limited direct evidence; the corpus contains work on agentic AI but does not directly address information‑theoretic limits.
- Break condition: The bound may fail if the LLM’s effective capacity scales with budget (e.g., using a larger model at higher *B*) or if the channel is effectively infinite‑dimensional.

### Mechanism 2
- Claim: At large budgets, the base strategy set nearly attains optimal performance, leaving little residual improvement for any post‑processing.
- Mechanism: As *B*→∞, *J*(*P*<sub>*B*</sub>) → *J*<sub>∞</sub>, so the residual gap Δ = *J*<sub>∞</sub> − *J*(*P*<sub>*B*</sub>) → 0. Any transformation of *P*<sub>*B*</sub> cannot create strategies beyond those reachable from *P*<sub>*B*</sub>, so *J*(*P*′<sub>*B*</sub>) cannot converge faster than *J*(*P*<sub>*B*</sub>), implying α ≤ 1.
- Core assumption: The base algorithm is asymptotically optimal; given enough budget it can approach *J*<sub>∞</sub> arbitrarily closely.
- Evidence anchors:
  - [abstract] "As *B*→∞, the performance *J*(*P*<sub>*B*</sub>) converges toward the global optimum *J*<sub>∞</sub>… Any mapping… cannot inject strategies that are not computable from the information contained in *P*<sub>*B*</sub> and the LLM’s fixed parameters."
  - [section, Page 2] "As *B* → ∞ , the performance *J*(*P*<sub>*B*</sub>) converges toward the global optimum *J*<sub>∞</sub>, so the residual improvable gap shrinks. Any mapping applied to *P*<sub>*B*</sub>, including the LLM, can only redistribute probability mass among strategies already present in or reachable from *P*<sub>*B*</sub>."
  - [corpus] No direct corroboration; the corpus focuses on practical agent designs rather than asymptotic optimality.
- Break condition: If *P*<sub>*B*</sub> does not converge to *J*<sub>∞</sub> (e.g., due to algorithmic bias) or if the LLM can generate strategies outside the closure of *P*<sub>*B*</sub>, the bound may be violated.

### Mechanism 3
- Claim: The susceptibility bound emerges from linear response theory; for a fixed architecture with one effective budget variable, α ≤ 1. However, when multiple budget channels co‑vary (nested architectures), the total susceptibility can exceed 1 if inter‑layer coupling is positive.
- Mechanism: The utility function *J* depends on all budget variables. The gradient ∇<sub><b>B</b></sub>*J* is the susceptibility vector. The total sensitivity along a reference budget *B*<sub>ref</sub> is α<sub>total</sub> = Σ (∂*J*/∂*B*<sub>*i*</sub>)·(d*B*<sub>*i*</sub>/d*B*<sub>ref</sub>). For a fixed architecture, only one *B*<sub>*i*</sub> varies, so α<sub>total</sub> = (∂*J*/∂*B*<sub>*i*</sub>)/(∂*J*<sub>base</sub>/∂*B*<sub>ref</sub>) ≤ 1. When multiple components scale together (e.g., generator and selector), cross‑terms appear; if positive coupling yields a sum > 1.
- Core assumption: *J* is smooth with respect to budget variables and the scaling protocol is differentiable; linear response holds in the large‑budget limit.
- Evidence anchors:
  - [abstract] "We develop a multi‑variable utility‑function framework that generalizes this hypothesis to architectures with multiple co‑varying budget channels, and discuss the conditions under which co‑scaling can exceed the susceptibility bound."
  - [section, Page 4] Equations (3) and (4) define α<sub>total</sub> and analyze three coupling regimes: decoupled, negative, and positive; the positive coupling case yields α<sub>total</sub> > 1.
  - [corpus] The corpus includes papers on scaling agent systems but does not derive this framework; support is internal.
- Break condition: If *J* exhibits discontinuities or phase transitions that invalidate linear response, or if the scaling protocol is non‑linear, the formula may not hold. Also, non‑positive coupling prevents exceeding 1.

## Foundational Learning
- **Mutual Information & Data‑Processing Inequality**: The data‑processing inequality states that processing data through a channel cannot increase mutual information with a target variable. This is needed because the LLM is modeled as a channel; it cannot amplify the information about the optimum contained in the base strategy set, limiting susceptibility. *Quick check*: For a Markov chain X → Y → Z, if I(X;Y)=2 bits, what is the maximum possible I(X;Z)? Answer: ≤ 2 bits.
- **Linear Response Susceptibility**: Susceptibility (∂J/∂B) quantifies how performance responds to additional compute. It is needed to compare scaling efficiency between base and derived strategies. *Quick check*: If J(B)=3B+5, what is the susceptibility? Answer: 3.
- **Multi‑variable Chain Rule**: When architecture has multiple budget variables that co‑vary, the total derivative along a scaling path combines partial derivatives via the chain rule. This generalizes α to nested systems. *Quick check*: Given J(B₁,B₂)=B₁B₂ and protocol B₂=2B₁, compute dJ/dB₁. Answer: ∂J/∂B₁ + (∂J/∂B₂)·(dB₂/dB₁) = B₂ + B₁·2 = 2B₁ + 2B₁ = 4B₁.

## Architecture Onboarding
### Component map
Base strategy generator → LLM‑derived processor → Utility function J. Supporting components: Budget variables (e.g., beam width, sample count, model sizes), Evaluation harness (seeds, statistical estimation).

### Critical path
1. Set budget configuration (B, k, model sizes).
2. Generate base set P<sub>B</sub>.
3. Feed P<sub>B</sub> to LLM to obtain derived set P′<sub>B</sub>.
4. Evaluate J(P<sub>B</sub>) and J(P′<sub>B</sub>).
5. Repeat across budget levels to estimate slopes ∂J/∂B; for nested cases use multi‑variable derivative formula.

### Design tradeoffs
- **Fixed LLM wrapper**: Simple, may improve finite‑budget performance, but α ≤ 1 asymptotically. Best for limited compute.
- **Nested co‑scaling** (generator & selector grow together): Can achieve α_total > 1 under positive coupling, enabling open‑ended improvement, but costs more compute and requires careful alignment.
- **Budget allocation**: After crossover (e.g., k∼12 in AIME), investing in base generation yields higher marginal returns than adding a fixed selector.
- **Measurement**: Need sufficient budget levels and random seeds to reliably fit slopes; noise can mask α ≤ 1.

### Failure signatures
- α > 1 in a fixed architecture → likely artifact (LLM size changed with B, insufficient budget range).
- No α < 1 crossover in AIME → base majority vote not yet asymptotic; increase k or generator size.
- Negative coupling (α_total < α_gen) when co‑scaling → selector bottleneck; consider uncoupling or improving selector.
- High variance in Δ(B) across models → prompt sensitivity; standardize prompts and increase seeds.

### First 3 experiments
1. **Tetris beam sweep**: Compare beam search (DFS) vs fixed LLM‑derived (Qwen‑32B) for B ∈ {1,2,4,8,16,32}. Compute slopes; verify LLM slope ≤ base (Figure 1).
2. **Prompt/reward robustness**: In Tetris, test four prompts and three reward functions. For each, estimate α; confirm α ≤ 1 holds (Figure 2).
3. **AIME sample transition**: For each fixed selector (5 models), vary k ∈ {3,5,9,15,17,19,21} and generator size (5 models). For each selector, fit α(k) = slope of agent vs majority vote across generator sizes; average over selectors to get ¯α(k). Observe ¯α crossing below 1 around k ∼ 12 (Figure 3).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: Can the susceptibility hypothesis be formally proven?
- **Basis in paper**: [explicit] "developing a formal proof would place the bound on firmer theoretical ground."
- **Why unresolved**: The current support is empirical; a general proof is lacking.
- **What evidence would resolve it**: A mathematical derivation showing that for any fixed LLM mapping, the large‑budget susceptibility derivative cannot exceed that of the base strategy.

### Open Question 2
- **Question**: Does the susceptibility bound α ≤ 1 hold for domains with long horizons, multi‑agent interaction, or continuous action spaces?
- **Basis in paper**: [explicit] "the four domains tested... do not cover settings with very long horizons, multi‑agent interaction or continuous action spaces... exploring these settings would clarify the boundary conditions."
- **Why unresolved**: Experiments are limited to four specific tasks; other domains may violate the bound.
- **What evidence would resolve it**: Measure α in those new domains. If α consistently ≤ 1, the bound generalizes; if not, refine the theory.

### Open Question 3
- **Question**: What is the quantitative scaling law for nested susceptibility α_total when generator and selector co‑scale?
- **Basis in paper**: [explicit] "deriving a quantitative scaling law for nested susceptibility is perhaps the most important open question."
- **Why unresolved**: Co‑scaling experiments show α_total > 1 but lack a functional relationship with co‑scaling rates.
- **What evidence would resolve it**: Systematically vary generator and selector budgets, fit α_total = f(B_gen, B_sel, dB_sel/dB_gen) to predict marginal gains.

### Open Question 4
- **Question**: Is nested co‑scaling necessary for open‑ended LLM self‑evolution?
- **Basis in paper**: [explicit] "nested architectures may be a necessary structural condition for open‑ended agentic self‑improvement" and "self‑evolution may require nested co‑scaling... approaching testability."
- **Why unresolved**: The necessity is inferred but unverified; fixed architectures might circumvent the bound via other means.
- **What evidence would resolve it**: Long‑term self‑improvement runs comparing fixed vs. nested agents, checking if sustained improvement occurs only with nesting.

### Open Question 5
- **Question**: Can system‑level performance be predicted from composable single‑layer susceptibility measurements?
- **Basis in paper**: [explicit] "by measuring the susceptibility of individual architectural layers... one could in principle reconstruct the full utility function J."
- **Why unresolved**: This composability assumption is untested.
- **What evidence would resolve it**: For a multi‑layer agent, measure single‑layer susceptibilities, predict J using the multi‑variable formula, and compare to end‑to‑end evaluations across budgets.

## Limitations
- Missing implementation details (Tetris heuristic weights beyond line‑clearing weight, Ranking noise scales, AIME formatting) hinder exact replication.
- Prompt specifications for each domain are not provided; LLM behavior may be prompt‑sensitive.
- Model accessibility: Qwen3‑Max (~200B) is likely unavailable, limiting validation of nested co‑scaling at the largest scale.

## Confidence
- Fixed LLM α ≤ 1 asymptotically: High
- Empirical support across domains: Medium
- Nested co‑scaling α_total > 1: Medium
- AIME crossover at k≈12: Low
