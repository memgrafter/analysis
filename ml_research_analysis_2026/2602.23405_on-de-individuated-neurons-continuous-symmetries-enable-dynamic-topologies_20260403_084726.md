# On De-Individuated Neurons: Continuous Symmetries Enable Dynamic Topologies

## Quick Facts
- **arXiv ID:** 2602.23405
- **Source URL:** https://arxiv.org/abs/2602.23405
- **Reference count:** 40
- **Primary result:** Introduces isotropic activation functions enabling exact network function invariance under neurogenesis and approximated invariance under neurodegeneration, validated on CIFAR-10 with dynamic width adaptation (8–32 neurons).

## Executive Summary
This paper tackles the challenge of real-time neural network structural plasticity—adding (neurogenesis) and removing (neurodegeneration) neurons—while preserving learned functionality. It does so by replacing standard activation functions with *isotropic* ones, which are derived from and obey continuous orthogonal group equivariance. This symmetry-principled design allows network layers to be reparameterized via singular value decomposition (SVD) into a diagonal form with clear one-to-one neuron mappings. Neurons with near-zero singular values can be pruned, and new "scaffold" neurons can be inserted without altering the computed function, aided by an intrinsic length parameter that absorbs residual biases. The approach is theoretically grounded, proving that isotropic dense networks can achieve up to 50% sparsity with exact functional preservation, and is empirically demonstrated on CIFAR-10 with MLPs that dynamically adjust width with minimal accuracy loss.

## Method Summary
The method hinges on using isotropic activation functions (e.g., `f(x) = tanh(||x||) * x / ||x||`), which are equivariant to all orthogonal transformations. For any layer pair, the weight matrix of the first layer is decomposed via SVD (`W = UΣVᵀ`). The network's function is preserved by transforming the effective weights to `ΣVᵀ` and passing `U` to modify the next layer's weights (`W_next ← W_next * U`). This diagonalization exposes singular values `Σ_ii` as a per-neuron importance measure. Pruning removes rows/columns associated with `Σ_ii` below a threshold `θ`, while growth appends zero rows/columns and a new bias term constrained by an *intrinsic length* parameter `o`, which absorbs bias residuals. After structural change, the network continues training with the updated architecture.

## Key Results
- Networks achieve **exact functional invariance** under neurogenesis (adding scaffold neurons) and **well-approximated invariance** under neurodegeneration (pruning), up to a tunable threshold.
- Theoretical proof shows isotropic dense networks can asymptotically reach **50% sparsity while retaining exact functionality**.
- Empirical tests on CIFAR-10 with MLPs show dynamic width changes (8–32 neurons) incur **minimal accuracy loss**, and wider initial networks prune to higher final accuracy, mirroring biological neural plasticity.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Isotropic activation functions enable continuous basis reparameterizations that preserve network output.
- **Mechanism:** Orthogonal group equivariance (`∀ R ∈ O(n): f(Rx) = R f(x)`) allows a layer's weights to be transformed via SVD into a diagonal form without changing the function computed by the network.
- **Core assumption:** The activation function is isotropic (basis-independent).
- **Evidence anchors:** [abstract] "basis-independent primitives... enables network structural changes that are invariant under symmetry reparameterisations." [section 2.1] Equation 1 defines isotropic functions. [corpus] Weak; neighboring works focus on discrete permutation symmetries.
- **Break condition:** Using a non-isotropic activation breaks equivariance, preventing diagonalization and dynamic topology.

### Mechanism 2
- **Claim:** Diagonalized layers with ordered singular values allow neurons to be removed or added with minimal functional change.
- **Mechanism:** After diagonalization, each neuron corresponds to a singular value `Σ_ii`. Pruning a neuron with `Σ_ii ≈ 0` removes a weakly contributing unit. Adding a "scaffold" neuron with `Σ_ii = 0` introduces a functionally inert unit.
- **Core assumption:** Layers can be fully or partially diagonalized via SVD.
- **Evidence anchors:** [abstract] "reparameterized via singular value decomposition into diagonalized forms with ordered one-to-one neuron connectivity." [section 2.3] "This indicates which one-to-one neuron-to-neuron communications are strongly impactful... Inconsequential neurons can thus be removed."
- **Break condition:** Incorrect ordering or pruning a neuron with `Σ_ii > θ` causes significant function degradation.

### Mechanism 3
- **Claim:** An intrinsic length parameter `o` absorbs residual biases during pruning, maintaining functional invariance.
- **Mechanism:** When a neuron is pruned (`Σ_ii → 0`), its bias `b_i` remains in the norm term of the isotropic activation. Adjusting `o` (Equation 29) absorbs `b_i²`, while the linear part is corrected via the subsequent layer's weights.
- **Core assumption:** `o > 0` and is updated correctly during pruning (Section 3.1).
- **Evidence anchors:** [abstract] "An 'intrinsic length' parameter analytically absorbs residual biases during pruning." [section 3.1] Equation 29 shows bias absorption.
- **Break condition:** Failure to update `o` causes bias accumulation and output drift.

## Foundational Learning
- **Concept: Symmetry-led primitive design**
  - *Why needed here:* Reverses the neuron-centric view; symmetries define functional forms, enabling basis-independent operations.
  - *Quick check:* Given `f(Rx) = R f(x)` for all `R ∈ O(n)`, derive a valid isotropic activation function (e.g., `f(x) = σ(||x||) * x / ||x||`).
- **Concept: Orthogonal group equivariance**
  - *Why needed here:* Provides the continuous symmetry necessary for diagonalization and reparameterization.
  - *Quick check:* Does your layer's activation satisfy `f(Rx) = R f(x)` for any rotation matrix `R`? How would you test this?
- **Concept: SVD-based layer diagonalization**
  - *Why needed here:* Isolates one-to-one neuron connections, making importance (via singular values) explicit for pruning/growth.
  - *Quick check:* For a weight matrix `W`, compute its SVD, order the singular values, and explain how the diagonal `Σ` represents neuron-to-neuron strengths.

## Architecture Onboarding
- **Component map:** Isotropic activation -> Affine layer (W, b) -> Diagonalization module (SVD) -> Scaffold neuron buffer (Ξ) -> Intrinsic length (o) -> Next layer (W_next modified by U)
- **Critical path:**
  1. Train isotropic network to convergence.
  2. For target layer, compute SVD: `W1 = UΣVᵀ`; set effective weights to `ΣVᵀ` and modify next layer: `W2 ← W2 * U`.
  3. Count neurons with `Σ_ii < θ`.
  4. If count < Ξ, grow: append zero row to `Σ`, zero column to `ΣVᵀ` and `W2`, add bias `b*` with `b*² < o`, update `o ← o - b*²`.
  5. If count > Ξ, prune: delete row(s) of smallest `Σ_ii`, delete corresponding columns, remove bias entry, update `o ← o + b*²`.
  6. Train with updated architecture; repeat adaptation schedule.
- **Design tradeoffs:**
  - Full vs. partial diagonalization: Full gives clearer mapping but requires more affine transformations; partial is cheaper but less interpretable.
  - Threshold `θ`: Too low risks over-pruning; too high limits sparsity.
  - Scaffold count `Ξ`: Larger buffers allow more future growth but may underutilize capacity.
  - Isotropic activation choice: Affects gradient flow and scaling; may require isotropic normalizers (e.g., chi-normalizer).
- **Failure signatures:**
  - Sudden accuracy drop after pruning: `θ` too low or incorrect bias adjustment (`o` update).
  - Function divergence under reparameterization: Diagonalization not maintained or isotropic property violated.
  - Vanishing/exploding gradients: Poor scaffold neuron initialization or missing normalization.
  - `o` not updating: Biases accumulate, causing norm miscalculation.
- **First 3 experiments:**
  1. **Exact invariance test:** Add scaffold neurons to a frozen network; verify predictions unchanged on a fixed batch.
  2. **Pruning tolerance curve:** Incrementally increase neurodegeneration rate; plot accuracy vs. sparsity. Aim for ~50% sparsity with <1% accuracy loss.
  3. **Biological phenomenon replication:** Train at multiple initial widths (8, 16, 32 neurons) with dynamic adaptation; verify wider initial networks achieve higher final accuracy after pruning.

## Open Questions the Paper Calls Out
- **Question 1:** How does reparameterization-induced gradient coupling in isotropic networks affect optimization trajectories, and can adaptive optimizers be modified to preserve functional invariance while maintaining learning consistency?
  - *Basis:* [explicit] Section D notes gradient trajectory divergence under orthogonal reparameterizations, unlike anisotropic cases; Section 3.2 calls it a key future direction.
  - *Why unresolved:* Phenomenon is mathematically noted but empirically uncharacterized; no mitigation strategies provided.
  - *Needed evidence:* Comparative experiments training identical isotropic networks under different valid reparameterizations, measuring loss curves, final accuracy, and optimizer sensitivity.
- **Question 2:** What isotropic normalization schemes can prevent hyper-spherical shell collapse while mitigating performance degradation during neuron pruning, and how do they interact with the intrinsic length parameter?
  - *Basis:* [explicit] Section 3.1 argues standard normalizers (LayerNorm, BatchNorm) are insufficient; Appendix C shows certain normalizations collapse expressivity; chi-normalizer [15] is a candidate but unvalidated.
  - *Why unresolved:* Normalization design space is unexplored; interaction with `o` is noted but not analyzed.
  - *Needed evidence:* Systematic evaluation of isotropic normalizers on pruning robustness, measuring accuracy retention, gradient norms, and preserved functional properties.
- **Question 3:** How does the number of scaffold neurons (Ξ) influence learning dynamics, specialization, and final performance in isotropic dynamical networks?
  - *Basis:* [explicit] Footnote 7: gradients are non-local and depend on dimensionality, so differing Ξ are not equivalent; Section 3.3 uses Ξ=2 empirically without justification.
  - *Why unresolved:* Treated as a hyperparameter; no systematic study of its impact on gradient coupling or symmetry breaking.
  - *Needed evidence:* Controlled experiments varying Ξ (e.g., 1–10) across tasks, tracking scaffold neuron activation, convergence speed, final accuracy, and representation diversity (CKA).
- **Question 4:** Can isotropic dynamical networks effectively merge trained models with different initial functions or tasks, enabling knowledge transfer and continual learning without catastrophic forgetting?
  - *Basis:* [explicit] Conclusion suggests merging networks with differing functions as future work; diagonalization suggests interoperability but merging is unaddressed.
  - *Why unresolved:* Aligning basis choices between independently trained networks without shared history is a non-trivial extension.
  - *Needed evidence:* Experiments combining two separately trained isotropic networks (e.g., split CIFAR-10) by aligning diagonalized representations, evaluating combined task performance versus fine-tuning or EWC baselines.

## Limitations
- **Implementation details omitted:** Critical hyperparameters (pruning threshold `θ`, scaffold count `Ξ`), intrinsic length `o` optimization specifics, adaptation schedule, and stable zero-norm handling for isotropic activations are not provided.
- **Empirical scope narrow:** Experiments limited to shallow MLPs on CIFAR-10; generalizability to deeper, convolutional, or recurrent architectures is unverified.
- **Reproducibility concerns:** Lack of statistical reporting, unclear training dynamics, and missing ablation studies undermine confidence in empirical claims.

## Confidence
- **Theoretical foundation (orthogonal equivariance, exact invariance under neurogenesis):** High. Proofs are rigorous and self-contained.
- **Practical algorithm (singular-value-based pruning/growth):** Medium. Well-motivated but relies on unspecified hyperparameters and approximate invariance for neurodegeneration.
- **Empirical results (dynamic width adaptation on CIFAR-10):** Low. Missing training details, narrow architecture, and lack of statistical reporting hinder reproducibility.
