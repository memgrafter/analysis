# FourierMoE: Fourier Mixture-of-Experts Adaptation of Large Language Models
## Quick Facts
- arXiv ID: 2604.01762
- Source URL: https://arxiv.org/abs/2604.01762
- Reference count: 40
- Primary result: FourierMoE achieves higher accuracy than PEFT and MoPE baselines on 28 benchmarks with only ~0.06% tunable parameters (e.g., 83.95% on LLaMA‑2 7B multi‑task commonsense reasoning), demonstrating superior efficiency‑accuracy trade‑offs.

## Executive Summary
Standard parameter‑efficient fine‑tuning (PEFT) methods struggle with task interference and limited representational capacity in multi‑task settings, while existing mixture‑of‑experts (MoPE) approaches introduce structural redundancy. FourierMoE addresses these issues by reparameterizing weight updates into the spectral domain. A frequency‑adaptive router dynamically dispatches tokens to experts specialized for specific frequency bands; each expert learns conjugate‑symmetric complex Fourier coefficients that are losslessly converted to real‑valued spatial updates via the inverse discrete Fourier transform (IDFT). Across 28 benchmarks—including commonsense reasoning, math, image classification, and natural language understanding—FourierMoE consistently outperforms competitive baselines (FFT, single‑PEFT, MoPE) while using significantly fewer trainable parameters (e.g., an order of magnitude less than GOAT on LLaMA‑2 7B). The method provides a highly parameter‑efficient adaptation mechanism without sacrificing accuracy.

## Method Summary
FourierMoE begins by representing weight updates as Fourier coefficients rather than direct spatial deltas. During training, a frequency‑adaptive router examines each input token and determines which frequency bands are most relevant. The router then assigns the token to a set of experts, each responsible for a distinct frequency band. These experts predict complex Fourier coefficients, constrained to be conjugate‑symmetric to ensure the inverse DFT yields real numbers. After all assigned experts produce their coefficients, they are merged and transformed back to the spatial domain using the inverse DFT, resulting in a compact weight update. This update is applied to the model parameters, integrating the spectral specialization into the fine‑tuning process. The spectral representation reduces redundancy because different frequency bands often carry independent information, and the router’s dynamic assignment mitigates task interference by allowing tokens to use only the necessary experts. The approach is compatible with any architecture that can be fine‑tuned via weight deltas (e.g., decoder‑only LLMs, CLIP, RoBERTa) and incurs minimal extra parameters—the experts and router are very small relative to the base model.

## Key Results
- **State‑of‑the‑art efficiency‑accuracy trade‑offs:** On 28 benchmarks, FourierMoE matches or exceeds full fine‑tuning and other PEFT methods while using as little as 0.06% tunable parameters.
- **LLaMA‑2 7B multi‑task commonsense reasoning:** Achieves 83.95% average accuracy versus GOAT’s 82.73% with ten times fewer trainable parameters.
- **Broad applicability:** Similar gains are shown on LLaMA‑3 8B math reasoning, CLIP image classification, and RoBERTa‑large GLUE tasks.

## Why This Works (Mechanism)
FourierMoE works because reparameterizing weight updates into the frequency domain exposes an orthogonal decomposition of information. Frequency bands act as complementary subspaces that experts can specialize in, reducing task interference. The conjugate‑symmetric constraint guarantees that the inverse DFT produces valid real‑valued spatial updates without loss of phase or amplitude. This spectral decomposition is known to be compact and energy‑concentrated, meaning fewer parameters are needed to capture the essential directions of weight change. Additionally, the frequency‑adaptive router ensures that each token exploits only the relevant experts, further enhancing parameter efficiency and avoiding the “one‑size‑fits‑all” limitation of static PEFT adapters. The combination yields a method that maintains the low parameter overhead of PEFT while approaching the capacity of full fine‑tuning.

## Foundational Learning
- **Discrete Fourier Transform (DFT)**  
  *Why needed*: Converts spatial weight updates into the frequency domain where experts operate on compact, complementary bands.  
  *Quick check*: Apply IDFT to DFT coefficients of a random vector; verify reconstruction matches the original within floating‑point tolerance.

- **Conjugate Symmetry**  
  *Why needed*: Ensures that IDFT of learned complex coefficients yields real‑valued updates, preserving compatibility with real‑valued model weights.  
  *Quick check*: Compute the DFT of a real‑valued signal and confirm that \(X[k] = \overline{X[N-k]}\) (Hermitian symmetry).

- **Mixture‑of‑Experts (MoE)**  
  *Why needed*: Enables dynamic computation routing to specialized sub‑networks, reducing parameter redundancy and mitigating interference across tasks.  
  *Quick check*: In a small MoE, check that the gating distribution sums to 1 and that different inputs produce distinct expert selections.

- **Parameter‑Efficient Fine‑Tuning (PEFT)**  
  *Why needed*: Provides a baseline for adapting large models with minimal new parameters; FourierMoE improves upon it via spectral specialization.  
  *Quick check*: Count trainable parameters in a LoRA adapter and confirm it is <1% of the total model parameters.

## Architecture Onboarding
**Component map**  
Token → Frequency‑Adaptive Router → Expert Band 1, Expert Band 2, … → IDFT Merge → Spatial Delta → Model Update  

**Critical path**  
1. Input token passes through the router.  
2. Router selects one expert per frequency band (or a subset).  
3. Each expert predicts Fourier coefficients for its band.  
4. Coefficients are combined and transformed via IDFT.  
5. Resulting delta is applied to the model’s weights (or used in the forward pass).  

**Design tradeoffs**  
- *Computational overhead*: DFT/IDFT and router add per‑token latency versus static PEFT.  
- *Band partition*: Fixed equal‑width bands are simple but may not align with task‑wise frequency importance; adaptive bands increase flexibility but add complexity.  
- *Number of experts*: More experts better cover the spectrum but increase router and memory costs.  
- *Router complexity*: Frequency‑adaptive gating improves specialization but requires additional parameters and computation.  

**Failure signatures**  
- *Router collapse*: One expert dominates selection across all tokens, indicating poor specialization.  
- *Reconstruction error*: IDFT output diverges significantly from expected spatial patterns, causing training instability.  
- *No gain over baselines*: Performance similar to or worse than LoRA/FFT, suggesting spectral decomposition is not beneficial for the given data distribution.  
- *Excessive memory usage*: Unoptimized IDFT implementations cause out‑of‑memory errors.  

**First experiments**  
1. Replication: Run FourierMoE on LLaMA‑2 7B with a commonsense reasoning dataset (e.g., BoolQ) using the reported hyperparameters; verify accuracy near 83.95% and confirm ~0.06% tunable parameters.  
2. Ablation: Replace the frequency‑adaptive router with random or uniform routing; measure drop in performance to isolate router contribution.  
3. Computational profile: Compare training step time, memory consumption, and inference latency of FourierMoE against LoRA on a single GPU; quantify overhead from IDFT and routing.

## Limitations
- Computational overhead of IDFT transformations and frequency‑adaptive routing is not quantified; may impact training/inference speed despite parameter efficiency.  
- Generalization beyond the 28 reported benchmarks (e.g., long‑context, multilingual, or specialized domains) remains unverified.  
- Architectural compatibility constraints are unclear (e.g., decoder‑only vs. encoder‑only models, vision‑language tasks).
