# Proactive Guiding Strategy for Item-side Fairness in Interactive Recommendation

## Quick Facts
- **arXiv ID:** 2603.03094
- **Source URL:** https://arxiv.org/abs/2603.03094
- **Reference count:** 13
- **Primary result:** HRL4PFG significantly improves fairness (lower Gini Index) and user engagement (higher cumulative reward and interaction length) compared to state-of-the-art baselines in simulated interactive recommendation.

## Executive Summary
Item-side fairness in recommender systems aims to ensure equitable exposure of items, particularly long-tail content, without compromising user satisfaction. This paper introduces HRL4PFG, a hierarchical reinforcement learning framework that proactively guides user preferences toward fairness-promoting targets. The macro-level agent sets medium-term fairness-guided targets based on multi-step feedback, while the micro-level agent filters and recommends items that progressively steer user preference toward these targets while maintaining immediate satisfaction. Evaluations on KuaiRec and KuaiRand simulators show that HRL4PFG substantially outperforms the strongest baseline DNAIR, achieving higher cumulative interaction reward, longer interaction sequences, and a lower Gini Index. The results demonstrate that hierarchical guidance resolves the misalignment between short-term satisfaction and long-term fairness inherent in flat approaches.

## Method Summary
The task is to maximize long-term user engagement while promoting equitable item exposure in an interactive recommendation setting. The system interacts with a simulated user model derived from the KuaiRec and KuaiRand datasets. At each step, the agent observes a state summarizing recent interactions, selects an item to recommend, and receives feedback that updates the user state and contributes to a reward comprising accuracy (user satisfaction) and fairness (exposure inequality). HRL4PFG employs two synchronized agents: a high-level agent (HRA) that operates every *M* steps, generating a fairness-guided target vector in the item embedding space; and a low-level agent (LRA) that acts per recommendation, selecting items from a candidate pool filtered to be closest to the current target. The HRA uses a Gaussian actor and critic, with rewards aggregated over *M* steps. The LRA’s state concatenates the user’s current preference embedding and the target; its reward combines accuracy and a guidance term proportional to the reduction in distance to the target. This hierarchical decomposition allows the fairness objective to be pursued at a suitable temporal abstraction while the micro-agent focuses on immediate user satisfaction.

## Key Results
- **Cumulative interaction reward:** 29.99 on KuaiRec (Max Len=30) vs. 17.40 for the best baseline (DNAIR).
- **Maximum interaction length:** 27.82 vs. 21.04.
- **Gini Index:** 98.20% vs. 99.20% (lower indicates better fairness).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** A high-level agent generates dynamic, fairness-guided targets based on multi-step user feedback, providing a stable guiding objective for the low-level agent.
- **Mechanism:** The macro-learning phase uses a high-level actor (Gaussian policy) and critic. The critic evaluates state returns (Equation 3) using multi-step rewards (Equation 7), which combine accuracy (`r_a`) and fairness (`r_f`) over the next *M* steps. The actor is updated via policy gradient with advantage (Equation 4), shaping it to produce targets that optimize long-term fairness-satisfaction trade-offs.
- **Core assumption:** Setting medium-term targets (over *M* steps) is more effective for gradual preference alignment than myopic, per-step fairness rewards.
- **Evidence anchors:**
  - [abstract]: "macro-level process that generates fairness-guided targets based on multi-step feedback"
  - [section 3.3]: Describes high-level actor-critic, reward function (Equation 7), and the multi-step return `R^h_t`.
  - [corpus]: Weak corpus support. Neighbors discuss fairness or proactive recommendation but not hierarchical target generation.
- **Break condition:** If the generated target `g_t` falls outside the valid item embedding space (violates Equation 6), the high-level reward is zero, halting learning updates for that target.

### Mechanism 2
- **Claim:** A low-level agent progressively steers user preferences toward the high-level target by filtering candidate items and shaping rewards to balance immediate satisfaction with long-term guidance.
- **Mechanism:** The micro-learning phase constructs a low-level state `s^l_t` concatenating current user preference `p_t` with the target `g_t` (Equation 9). A masking filter selects top-*L* items closest to `g_t` (L2 distance) as candidates. The low-level actor samples from these. The reward `r^l_t` (Equation 11) combines accuracy `r_a` and a guidance reward `r_g` (Equation 12), which is the *reduction* in L2 distance from preference to target between steps.
- **Core assumption:** Guiding is most effective when recommendation candidates are pre-filtered to be directionally aligned with the target, preventing random, misaligned long-tail pushes.
- **Evidence anchors:**
  - [abstract]: "micro-level process that fine-tunes recommendations in real time according to both these targets and evolving user preferences"
  - [section 3.4]: Details state composition, candidate filtering via `Mask`, and guidance reward `r_g` as `Distance(p_t, g_t) - Distance(p_{t+1}, g_t)`.
  - [corpus]: Neighbor paper "Proactive Recommendation with Iterative Preference Guidance" (FMR 0.61) supports iterative guidance concept but not the specific hierarchical filtering mechanism.
- **Break condition:** If the high-level target `g_t` is invalid (violates Equation 6), the low-level reward is zero, preventing policy updates and stalling guidance.

### Mechanism 3
- **Claim:** Hierarchical decomposition (macro target-setting, micro action-selection) resolves the misalignment between immediate user satisfaction and long-term fairness goals inherent in flat RL approaches.
- **Mechanism:** The two-level structure operates at different temporal abstractions. The HRA sets a target for a segment of *M* steps. The LRA then has *M* steps to execute actions that gradually satisfy the user *and* move preference toward `g_t`. This separates the *fairness objective* (macro) from the *user satisfaction objective* (micro), allowing each to be optimized with appropriate reward signals and state representations.
- **Core assumption:** User preference can be steered progressively; a sudden shift causes user exit, but a gradual shift over multiple interactions is feasible.
- **Evidence anchors:**
  - [introduction]: "dividing the guiding process into two phases: macro-learning and micro-learning"
  - [section 3.2]: "The low-level agent aims to steer user preference toward the fairness-guided target while ensuring sustained user satisfaction."
  - [corpus]: Corpus shows related work on "influential recommender system" (ICDE 23) and "proactive recommendation" but not the specific HRL architecture for fairness.
- **Break condition:** If either agent's policy converges poorly (e.g., HRA sets unreachable targets, LRA cannot move preference), the hierarchy fails to coordinate, leading to low cumulative reward and short interaction length.

#### Reinforcement Learning (Markov Decision Processes)
**Why needed here:** The entire framework models interactive recommendation as an MDP where the agent (system) takes actions (recommends items) in a state (user history), receives rewards (satisfaction/fairness), and transitions to a new state. Understanding MDPs is prerequisite to grasping policy optimization.

#### Actor-Critic Methods
**Why needed here:** Both macro and micro agents use actor-critic architectures (Sections 3.3 & 3.4). The actor defines the policy (probability of actions/targets), the critic estimates value (expected return) to reduce variance. Knowing this is key to understanding the loss functions (Equations 3, 4).

## Architecture Onboarding
- **Component map:** 
  - High-Level Agent (HRA): State Tracker (attention over last N interactions) → Actor (Gaussian policy → target `g_t`) & Critic (value estimate `V^h`).
  - Low-Level Agent (LRA): State Tracker (user preference `p_t` via attention) + `g_t` → concatenation `s^l_t` → Actor (MLP + Mask filter → item prob.) & Critic (value estimate `V^l`).
  - Reward Functions: `r^h_t` (macro, multi-step accuracy+fairness, Eq 7) and `r^l_t` (micro, per-step accuracy+guidance, Eq 11).

- **Critical path:** 1) HRA observes history, samples `g_t`. 2) `g_t` is fed to LRA for next *M* steps. 3) Each step: LRA filters candidates w.r.t `g_t`, selects item, gets user feedback. 4) After *M* steps, HRA receives aggregated rewards `R^h_t`, updates. 5) LRA updates every step with `r^l_t`.

- **Design tradeoffs:** 
  - Target validity constraint (Eq 6) vs. exploration: Tight constraint ensures targets are in-item-space but may limit diversity of guiding directions.
  - Filter size L (Eq 10): Larger L increases candidate diversity but risks including items misaligned with `g_t`, weakening guidance.
  - Guidance weight λ_g (Eq 11): Higher λ_g forces faster preference shift but risks user dissatisfaction if too abrupt.

- **Failure signatures:**
  - Cumulative Reward (`R_cum`) & Interaction Length (`Len`) collapse: Indicates LRA failed to maintain satisfaction during guidance, likely from over-aggressive `λ_g` or invalid `g_t`.
  - Gini Index remains high: Indicates HRA is not generating effective fairness-guided targets (e.g., targets close to popular items) or LRA ignores them.
  - High variance across seeds: Suggests unstable training, possibly from critic overestimation (why TD3 is a baseline) or poor exploration in HRA's Gaussian policy.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How can HRL4PFG be enhanced to autonomously determine the optimal trade-off between fairness guidance and user satisfaction without relying on manually tuned hyper-parameters like λ_g?
- **Basis in paper:** [explicit] The paper explicitly states that "striking a balance between guiding user preference toward long-tail items and ensuring user satisfaction remains a complex and unresolved challenge" and shows through hyper-parameter sensitivity analysis that performance varies with λ_g.
- **Why unresolved:** The current framework uses a fixed λ_g, which requires manual tuning for different environments and may not adapt to dynamic user contexts or evolving preferences during interaction.
- **What evidence would resolve it:** Development of an adaptive mechanism within the hierarchical RL that adjusts guidance strength in real-time based on user feedback signals, validated by experiments demonstrating improved robustness and performance across diverse, unseen environments without per-setting tuning.

### Open Question 2
- **Question:** Can the HRL4PFG framework be extended to jointly optimize for multiple fairness objectives, such as item-side fairness and demographic fairness, while preserving user satisfaction in interactive recommendation?
- **Basis in paper:** [explicit] The conclusion explicitly lists "adapting HRL4PFG to other fairness goals like demographic fairness" as a future direction, indicating it is not addressed in the current work.
- **Why unresolved:** HRL4PFG is designed solely for item-side fairness via long-tail exposure; incorporating additional fairness constraints requires modifications to the macro-level target generation and reward mechanisms, which may introduce conflicts or complexity.
- **What evidence would resolve it:** A multi-objective extension of the high-level agent that generates fairness-guided targets balancing multiple metrics, evaluated on datasets with demographic annotations to measure trade-offs and ensure no degradation in user satisfaction metrics.

### Open Question 3
- **Question:** What are the long-term effects of proactive fairness-guiding strategies like HRL4PFG on user retention, platform engagement, and overall ecosystem equity when deployed in real-world interactive recommender systems?
- **Basis in paper:** [explicit] The conclusion calls for "conducting real-world studies to assess long-term effects on fairness and satisfaction," highlighting that current evaluations are limited to simulated environments.
- **Why unresolved:** All experiments use offline simulators (KuaiRec, KuaiRand) that may not capture real-world complexities such as user churn, diverse content dynamics, or sustained behavioral changes over months or years.
- **What evidence would resolve it:** Longitudinal A/B tests or field deployments in live platforms measuring metrics like user lifetime value, churn rate, and fairness indicators (e.g., Gini Index) over extended periods, compared against baseline systems.

### Open Question 4
- **Question:** How accurately do existing simulation environments for interactive recommendation (e.g., KuaiRec, KuaiRand) model the causal impact of proactive guidance on user preference evolution, and what enhancements are needed to improve simulation fidelity?
- **Basis in paper:** [inferred] The paper relies entirely on these simulators for evaluation but suggests real-world studies, implying potential limitations in how well simulators replicate the dynamic, guiding effects on users.
- **Why unresolved:** Simulators are built from historical interaction logs and assume stationary user models; they may not account for the psychological or behavioral shifts induced by gradual preference steering, leading to overestimated or misplaced performance.
- **What evidence would resolve it:** Comparative analyses between simulator predictions and actual user responses from controlled online experiments, coupled with incorporating theories of preference dynamics (e.g., from psychology) into user models within simulators to better capture progressive guidance effects.

## Limitations
- Hyperparameter values (e.g., learning rates, `M`, `L`, `λ`) are not fully reported, hindering exact replication.
- State encodings (attention dimensions, item embedding space) and reward scaling (`r_a`, `r_f`) remain underspecified.
- Evaluation is confined to simulators (KuaiRec/KuaiRand); real‑user studies are absent, limiting ecological validity.
