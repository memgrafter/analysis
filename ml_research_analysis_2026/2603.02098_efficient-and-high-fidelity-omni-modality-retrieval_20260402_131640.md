# Efficient and High-Fidelity Omni Modality Retrieval

## Quick Facts
- arXiv ID: 2603.02098
- Source URL: https://arxiv.org/abs/2603.02098
- Reference count: 40
- Primary result: State-of-the-art retrieval on 12/13 M-BEIR tasks and ACM benchmark, with notable improvements in composed, audio, and video retrieval.

## Executive Summary
Universal multimodal retrieval that handles composed queries across text, vision, and audio is hindered by computational inefficiency from large token sequences and information loss when compressing modalities into a single vector. OmniRet addresses these limitations with two core innovations: a Shared Media Resampler that condenses media tokens into a fixed-size set, and Attention Sliced Wasserstein Pooling (ASWP) that aggregates LLM hidden states while preserving fine-grained details. Trained on approximately 6 million query-target pairs across 30 datasets, OmniRet achieves state-of-the-art performance in 12 of 13 tasks on the extended M-BEIR benchmark, with particularly large gains in composed retrieval, audio, and video. It also establishes a new Audio-Centric Multimodal (ACM) benchmark and demonstrates strong results on composed audio and audio-visual retrieval, outperforming baselines like ImageBind, CLAP, and text-only pipelines.

## Method Summary
OmniRet is a unified multimodal retrieval model that processes text, image, and audio inputs within a Large Language Model (LLM) framework. Raw media features from modality-specific encoders (SigLIP for vision, QwenAudio for audio, and a text LLM) are compressed via a Shared Media Resampler—a Perceiver-based module that reduces variable-length token sequences to a fixed set of 64 latent vectors. This resampling mitigates computational costs while preserving modality diversity through shared and modality-specific latent queries. The LLM then generates hidden state sequences conditioned on instructions and the resampled tokens. To aggregate these hidden states into a final embedding, the model employs Attention Sliced Wasserstein Pooling (ASWP), which models the token set as a distribution and computes sliced Wasserstein distances against learnable reference vectors, selecting fine-grained features via a Straight-Through Maximum estimator. Training proceeds in two stages: a warm-up phase with frozen LLM and a fine-tuning phase with LoRA adapters, using a combination of hard-negative InfoNCE, triplet, and diversity losses across ~6M query-target pairs from 30 datasets.

## Key Results
- SOTA on 12/13 tasks in the extended M-BEIR benchmark, with large gains in composed retrieval (e.g., V,T→V R@5 86.2) and audio (A→T R@5 66.8 vs CLAP 63.9).
- New ACM benchmark: strong performance on composed audio (A,T→A R@5 23.0) and audio-visual (A→V 35.5, V→A 34.4).
- Outperforms baselines like ImageBind, CLAP, and text-only pipelines.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The Shared Media Resampler improves computational efficiency by condensing high-volume media token sequences (e.g., >500 tokens from vision/audio encoders) into a small, fixed set of latent vectors before LLM processing, enabling larger batch sizes for contrastive learning.
- **Mechanism:** A Perceiver-based architecture with cross-attention uses shared learnable latent queries (N=64) to compress variable-length media token sequences into a fixed N×D matrix. Modality-specific latents are added to shared latents to preserve modality information while enabling weight sharing across modalities. This reduces the sequence length fed into the LLM, cutting quadratic attention costs.
- **Core assumption:** A small set of learned latents can preserve sufficient discriminative information from high-dimensional media features if trained with appropriate diversity regularization.
- **Evidence anchors:**
  - [abstract] "...feeding massive token sequences from modality-specific encoders to Large Language Models (LLMs) is computationally inefficient. We therefore introduce an attention-based resampling mechanism to generate compact, fixed-size representations..."
  - [section 3.2] "This shared module is designed to maintain representational diversity and generalization capabilities while remaining sensitive to modality-specific information."
  - [corpus] Weak direct evidence—neighbor papers (e.g., Omni-C [2603.05528]) explore similar compression but not with this specific shared latent design. Assumption: shared resampling generalizes across modalities.
- **Break condition:** If N is too small (<16 ablations show >2pt drop), information loss occurs; if modality-specific latents are omitted, performance degrades (~0.4pt).

### Mechanism 2
- **Claim:** Attention Sliced Wasserstein Pooling (ASWP) preserves fine-grained token-level details from LLM hidden states when aggregating to a single vector, avoiding the information bottleneck of mean/max pooling.
- **Mechanism:** LLM output tokens are first resampled to S latent vectors (Z). Sliced Wasserstein distance compares Z to learnable reference vectors (X) across L random 1D projections (Θ). This yields a per-slice alignment descriptor Z′ (S×L). A Straight-Through Maximum (STM) estimator selects per-slice max indices, forming a final embedding via column-wise sum. This captures distributional similarity at slice-level granularity.
- **Core assumption:** Modeling token sets as distributions and computing sliced Wasserstein distance retains more fine-grained relevance signals than scalar pooling, while STM maintains differentiability.
- **Evidence anchors:**
  - [abstract] "...compressing rich omni-modal data into a single embedding vector inevitably causes information loss... We propose Attention Sliced Wasserstein Pooling to preserve these fine-grained details..."
  - [section 3.2] "ASWP compares Z and X across L1D projections... producing Z′... a learnable histogram-like descriptor that preserves fine-grained distributional information."
  - [corpus] Inspired by PSWE [NeurIPS 2021], but adaptation to LLM hidden states and STM selection is novel. No direct corpus validation for this specific application.
- **Break condition:** If L or S is too small (ablations: L=1536/S=128 optimal), performance drops; replacing STM with average pooling causes catastrophic failure (-29.5pt).

### Mechanism 3
- **Claim:** Multi-task training on ~6M diverse query-target pairs, with hard-negative InfoNCE and triplet loss, builds a unified embedding space that generalizes across modalities and composed queries without task-specific parameters.
- **Mechanism:** A single LLM-based encoder f(q_inst) maps instructed queries and raw candidates to shared space. Hard-negative weighting adapts to in-batch difficulty. Triplet loss enforces margin between positive/negative. Diversity loss on resampled media tokens (L_div) encourages orthogonal latent representations, preventing collapse.
- **Core assumption:** A unified model with instruction prompts and modality-agnostic architecture can learn all-to-all retrieval if exposed to sufficiently diverse multimodal data with appropriate losses.
- **Evidence anchors:**
  - [abstract] "OmniRet is trained on an aggregation of approximately 6 million query-target pairs spanning 30 datasets."
  - [section 3.1] "We train f using a Hard-negative InfoNCE loss... To further providing a strong discriminative learning signal... we also adopt the hinge-based triplet loss."
  - [corpus] Multi-task retrieval training is established (UniIR, MM-Embed), but scaling to audio-visual-text composition is novel. Corpus shows trend toward unified training but not this specific combination.
- **Break condition:** Removing L_div causes -3.1pt drop; without video data in warm-up, video performance suffers. Model size (1.5B LLM) may limit upper bound—scaling likely needed for further gains (limitations section).

## Architecture Onboarding
### Component Map
1. Modality encoders (SigLIP for vision, QwenAudio for audio) → high-token features.
2. Projectors (2-layer MLP) → LLM embedding space.
3. Shared Media Resampler (Perceiver with shared + modality latents) → fixed N×D tokens.
4. LLM (GTE-Qwen2-1.5B-Instruct + LoRA) with instruction template → hidden states sequence.
5. Attention Resampler (identical to #3) → S latent vectors from LLM outputs.
6. ASWP (projections Θ, references X′, STM selection) → final D-dim embedding.
7. Losses: L_cont, L_triplet, L_div.

### Critical Path
Media tokens → Resampler → LLM → Attention Resampler → ASWP → embedding. Each stage reduces dimensionality while attempting to preserve information.

### Design Tradeoffs
- Resampler N (tokens): larger N preserves detail but increases LLM input size; N=64 max under memory constraints.
- ASWP L (projections) and S (references): higher values improve fidelity but increase compute; L=4096/S=128 chosen for speed/accuracy tradeoff.
- Shared vs. separate resamplers: sharing improves generalization but requires modality latents to avoid interference.

### Failure Signatures
- Poor audio-visual retrieval (A→V, V→A) if modality-specific latents omitted or L_div too strong.
- Degraded composed retrieval (e.g., A,T→A) if ASWP replaced by average pooling or STM disabled.
- Training instability if batch size too small (due to hard-negative sampling) or gradient accumulation not used in Stage 2.

### First 3 Experiments
1. Ablate resampler: train without it (feed raw tokens to LLM) → expect >3pt drop on average recall (Table 5d), especially on video/audio due to token explosion.
2. Ablate ASWP: replace with [EOS] vector or average pooling → expect >6pt drop (Table 5a,c), proving fine-grained preservation necessity.
3. Test diversity loss variants: remove dropout or use L2 → expect 1.5–2.2pt drop (Table 13), confirming L_div's role in preventing resampler collapse.

## Open Questions the Paper Calls Out
1. **Scaling LLM and Data**: How does scaling the LLM backbone and training data affect performance? Evidence needed: train larger models (e.g., 7B) with more data.
2. **Extending to More Modalities**: Can a single unified model handle more tasks and modalities (e.g., depth, 3D point clouds, speech)? Evidence: build multi-modal multi-task dataset and train unified model.
3. **Interleaved Mixed-Media Documents**: How can the ACM benchmark be extended to interleaved, mixed-media documents? Evidence: define new tasks with interleaved queries/targets, collect data, benchmark.
4. **Increasing Resampled Tokens N**: What performance benefits can be gained by increasing N in the Shared Media Resampler? Evidence: train with larger N (128, 256) and measure accuracy/efficiency.

## Limitations
- Undisclosed training details (instruction templates, data splits, sampling) hinder exact reproduction.
- Efficiency gains lack direct runtime benchmarks; speedup inferred from batch size, not measured.
- Dependency on large proprietary encoders (QwenAudio, SigLIP) and a 1.5B LLM reduces accessibility and obscures component contributions.

## Confidence
- **Resampler effectiveness**: High (ablations show >2pt drop when removing modality latents or reducing N).
- **ASWP preservation**: High (average pooling replacement causes >29pt drop; optimal L/S validated).
- **Unified multi-task training**: High (SOTA on 12/13 M-BEIR + ACM; diversity loss +3.1pt).
- **Computational efficiency**: Medium (implied by batch size, no direct metrics).

## Next Checks
1. **Resampler ablation**: Vary shared/modality latent counts (N=16,32,64) and record accuracy (R@5) and memory to map trade-offs.
