# Enhancing Psychologists' Understanding through Explainable Deep Learning Framework for ADHD Diagnosis

## Quick Facts
- **arXiv ID**: 2602.02535
- **Source URL**: https://arxiv.org/abs/2602.02535
- **Reference count**: 16
- **Primary result**: Achieved 99% F1-score on binary ADHD classification and 94.2% accuracy on multi-class categorization using an explainable hybrid DNN-RNN model.

## Executive Summary
This paper presents an explainable deep learning framework to improve the reliability and transparency of ADHD diagnosis. The core contribution is a fine-tuned hybrid model (HyExDNN-RNN) that combines dense and recurrent neural network layers to capture both spatial and sequential patterns in clinical data. To bridge the gap between AI predictions and clinical practice, the framework integrates SHAP and PFI for interpretability, providing psychologists with insights into feature importance and decision logic. Evaluated on the ADHD200 dataset, the model outperforms several baselines, and the XAI components are designed to align model explanations with domain knowledge, fostering trust and collaborative human-AI decision-making.

## Method Summary
The framework processes the ADHD200 dataset through a pipeline: data loading, mean imputation for missing values, label encoding of categoricals, and standardization. A Pearson correlation-based feature selection removes one of any feature pair with absolute correlation >0.95 to reduce multicollinearity. The HyExDNN-RNN architecture stacks two dense layers (256, 128 units, ReLU), dropout (0.5), two RNN layers (64, 32 units), another dense layer (16 units, ReLU), and an output layer (sigmoid for binary, softmax for multi-class). The model is trained with Adam optimizer and cross-entropy loss over 120 epochs, using fixed train-test splits (75/25 binary, 80/20 multi-class). Post-training, SHAP (likely KernelExplainer) generates local/global feature attributions, and permutation feature importance (PFI) measures global relevance via accuracy drop upon feature shuffling. Visualizations (SHAP summary plots, PFI bar charts, confusion matrices) are delivered alongside the diagnosis.

## Key Results
- HyExDNN-RNN achieved 99% F1-score on binary ADHD vs. control classification.
- Multi-class categorization (TDC, combined, hyperactive, inattentive) reached 94.2% accuracy.
- The model outperformed multiple machine learning and deep learning baselines.
- SHAP and PFI provided interpretable feature importance aligned with clinical symptoms, aiming to enhance psychologist trust.

## Why This Works (Mechanism)
### Mechanism 1: Hybrid Spatial-Temporal Modeling
- **Claim**: The DNN-RNN hybrid improves classification accuracy by capturing both cross-feature (spatial) and sequential (temporal) patterns.
- **Mechanism**: Dense layers with ReLU extract complex non-linear spatial representations; these sequences are fed into RNN layers (with return_sequences) to model dependencies across the feature order. Dropout regularizes to prevent overfitting.
- **Core assumption**: The feature set has an inherent sequential structure (e.g., ordered by brain region or assessment type) that RNNs can exploit.
- **Evidence anchors**: [abstract] "fine-tuned hybrid Deep Neural Network (DNN) and Recurrent Neural Network (RNN)"; [section 3.4] "HyExDNN‑RNN models allow the integration of both spatial and temporal features".
- **Break condition**: If feature order is arbitrary, the RNN may add noise and harm performance.

### Mechanism 2: XAI for Clinical Trust
- **Claim**: SHAP and PFI explanations increase psychologist trust by translating model decisions into interpretable feature attributions.
- **Mechanism**: SHAP computes Shapley values for local and global feature contributions; PFI measures global importance via permutation-induced accuracy drops. Visualizations help clinicians relate top features (e.g., symptom scores) to diagnostic reasoning.
- **Core assumption**: Psychologists can understand feature-level explanations and the model's important features are clinically relevant; explanations must remain faithful.
- **Evidence anchors**: [abstract] "XAI approaches, in particular SHAP and PFI, provided important insights... we aim to bridge the gap"; [section 5] "generate acceptable and intuitive explanations that can be used to examine... the features used".
- **Break condition**: If explanations highlight irrelevant features, are inconsistent, or are too complex for clinicians, trust-building fails.

### Mechanism 3: Correlation-Based Feature Selection
- **Claim**: Removing highly correlated features (|r| > 0.95) via Pearson correlation reduces multicollinearity, decreases noise, and improves generalization/interpretability.
- **Mechanism**: Compute Pearson correlation matrix; iteratively discard one feature from each pair with |r| > 0.95, keeping features with unique linear information.
- **Core assumption**: High linear correlation indicates redundant information; retaining both harms stability without predictive benefit. The 0.95 threshold is conservative.
- **Evidence anchors**: [section 3.3] "The main objective... is to select the features with unique and non‑redundant information. ... a 95% criterion is set for feature removal."
- **Break condition**: Aggressive removal may discard diagnostically valuable correlated features (e.g., inattentive and hyper/impulsive scores); Pearson misses nonlinear redundancies.

## Architecture Onboarding
- **Component map**:
  Data loader -> Preprocessor -> Feature selector -> Model trainer -> XAI engine -> Visualizer -> Output interface
- **Critical path**:
  1. Load and concatenate ADHD200 subsets.
  2. Preprocess: impute missing values (column mean), encode categoricals, standardize features.
  3. Apply Pearson feature selection on training split only.
  4. Split data (binary: 75/25; multi-class: 80/20) with 20% validation.
  5. Train HyExDNN-RNN and baseline models; save checkpoint.
  6. Compute SHAP values on test set (or subset).
  7. Compute PFI via feature permutation and accuracy drop measurement.
  8. Generate metrics (accuracy, F1, ROC-AUC) and plots.
  9. Deliver diagnosis label and explanation visuals to psychologist.
- **Design tradeoffs**:
  - *Hybrid complexity*: RNN adds parameters/time but may capture sequences; XAI compensates interpretability loss.
  - *Feature reduction*: 0.95 threshold is aggressive; may discard informative correlated features.
  - *XAI selection*: SHAP offers local detail but is slow; PFI is fast/global but model-agnostic.
  - *Evaluation*: Comparing many models increases compute and risks test-set leakage if splits aren't fixed.
  - *Class imbalance*: No resampling; rare classes (e.g., Hyperactive, n=5) may be poorly learned.
- **Failure signatures**:
  - Overfitting: Large train/test accuracy gap; validation loss rises.
  - Data leakage: Feature selection applied before train/test split.
  - Unfaithful explanations: SHAP/PFI highlight known irrelevant features or conflict with clinical knowledge.
  - Minority class failure: Confusion matrix shows all rare-class instances misclassified.
  - Computational failure: Training or SHAP extraction times out without adequate resources.
- **First 3 experiments**:
  1. Replicate Table 1 and Table 2 results for HyExDNN-RNN using exact hyperparameters and splits; confirm binary F1=99% and multi-class accuracy=94.2%.
  2. Ablate the RNN: replace RNN layers with additional dense layers (similar parameter count) to isolate sequential modeling contribution.
  3. XAI consistency check: compute SHAP for a logistic regression on same data; compare top features with HyExDNN-RNN. Large divergence may indicate deep model captures different patterns or SHAP instability.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How do different feature selection strategies impact the trade-off between model performance and explanation interpretability for psychologists?
- **Basis in paper:** The framework uses Pearson correlation and mentions future work on other strategies but does not compare their effects on metrics or XAI quality.
- **Why unresolved:** Feature choice influences both accuracy and the narrative from SHAP/PFI; a method improving F1 might yield less coherent clinical explanations.
- **What evidence would resolve it:** Systematic ablation holding model constant while varying feature selection methods, measuring performance and psychologist-centric evaluation (trust, relevance surveys).

### Open Question 2
- **Question:** Between SHAP and PFI, which XAI method more effectively enhances psychologist trust and diagnostic understanding?
- **Basis in paper:** The paper employs both and claims SHAP provides "a more comprehensive understanding" based on technical properties, not user studies.
- **Why unresolved:** No empirical validation with clinicians; psychologists might prefer PFI's global rankings or find SHAP's local detail confusing.
- **What evidence would resolve it:** Within-subject study where clinicians review predictions with SHAP vs. PFI visualizations, quantifying trust, perceived reliability, and ability to identify key features.

### Open Question 3
- **Question:** Does the HyExDNN-RNN's exceptional performance generalize beyond ADHD200 to other clinical populations or real-world settings?
- **Basis in paper:** Evaluation is solely on the curated ADHD200 dataset; no external validation or discussion of dataset biases (site effects, demographic skew).
- **Why unresolved:** High performance on one dataset does not guarantee robustness to distribution shifts common in healthcare; risk of overfitting to dataset idiosyncrasies.
- **What evidence would resolve it:** Replication on independent datasets from different hospitals/studies; performance reporting with calibration metrics and subgroup analyses (by site, age, gender).

### Open Question 4
- **Question:** How does severe class imbalance in multi-class subtypes (e.g., only 5 Hyperactive cases) affect reliability for rare subtypes, and can XAI reliably explain errors in underrepresented classes?
- **Basis in paper:** Figure 2 shows extreme imbalance; only aggregate accuracy (94.2%) is reported, with no per-class metrics or analysis of XAI stability on rare-class predictions.
- **Why unresolved:** Model may ignore minority classes; SHAP values for low-confidence rare-class predictions can be unstable, posing clinical risks.
- **What evidence would resolve it:** Detailed per-class performance (F1 per subtype) and case studies of SHAP/PFI for rare-class true/false positives; statistical tests on explanation consistency for same rare instances.

### Open Question 5
- **Question:** What specific aspects of psychologist clinical expertise are most challenging to integrate with current XAI outputs, and how should the framework evolve for collaborative human-AI decision-making?
- **Basis in paper:** The goal is to "bridge AI with human expertise" but no investigation into how psychologists interact with explanations or where the interface breaks down.
- **Why unresolved:** Diagnostic reasoning is nuanced, context-rich, and hypothesis-driven; mismatches may exist between algorithmic feature importance (e.g., "QC_Rest_4") and clinical constructs.
- **What evidence would resolve it:** Ethnographic or task-based user studies observing psychologists using the tool; metrics: diagnostic confidence, time, identification of contradictions, willingness to override AI. Findings would drive explanation interface redesign (e.g., linking SHAP features to clinical scales).

## Limitations
- Unspecified RNN cell type (LSTM/GRU/SimpleRNN) affects temporal modeling capacity and results.
- Feature selection using Pearson (>0.95) lacks detailed removal strategy; risk of discarding informative correlated features.
- Potential data leakage if feature selection precedes train/test split; procedure is ambiguously described.
- Severe class imbalance in multi-class (e.g., only 5 Hyperactive samples) threatens generalizability and per-subtype reliability.
- Claims about XAI enhancing psychologist trust lack qualitative or user-study validation.
- Assumed sequential order of features is not justified; arbitrary ordering could render RNN ineffective.
- SHAP implementation (Kernel/Deep) and computational parameters are not specified, affecting explanation quality.

## Confidence
- **Hybrid DNN-RNN improves accuracy**: Medium – plausible given results but vulnerable if feature order is arbitrary or RNN type is suboptimal.
- **XAI enhances psychologist trust**: Low – no empirical user-centered evidence; trust claim is speculative.
- **Pearson correlation feature selection helps**: Medium – reasonable for reducing linear redundancy, but aggressive threshold may harm predictive power.
