# Coden: Efficient Temporal Graph Neural Networks for Continuous Prediction

## Quick Facts
- arXiv ID: 2602.12613
- Source URL: https://arxiv.org/abs/2602.12613
- Reference count: 40
- Primary result: CODEN achieves up to 44.80× training acceleration compared to state-of-the-art TGNNs while matching or exceeding their prediction accuracy.

## Executive Summary
CODEN addresses the inefficiency of existing temporal graph neural networks (TGNNs) for continuous prediction, where models must frequently update forecasts as graphs evolve. By decoupling graph propagation from temporal processing using parameter-free Personalized PageRank (PPR) embeddings and a lazy-sampling strategy, CODEN reduces computational cost significantly. State updates are handled by a state space model (SSM), enabling efficient compression of historical information. Experiments on five dynamic datasets, including the billion-scale Papers100M graph, demonstrate up to 44.80× speedup over prior methods while maintaining or improving accuracy.

## Method Summary
CODEN processes continuous-time dynamic graphs by maintaining incremental PPR embeddings via Forward Push with bounded error ϵ. For each edge update, it computes a shift bound and accumulates it; when the threshold λ is exceeded, it samples the current embedding and updates the SSM state. The SSM (M(t+1) = A M(t) + B H(t+1)) efficiently compresses historical information, and a prediction head (MLP) uses the state for classification. Training involves iterating over batches of edge events, applying lazy-sampling to produce embedding sequences, and backpropagating losses on training nodes at batch ends.

## Key Results
- Training acceleration up to 44.80× compared to SOTA TGNNs.
- Matches or exceeds prediction accuracy on five dynamic datasets.
- On billion-scale Papers100M, completes continuous prediction in 3.3 hours vs. 98.3 hours for prior best.

## Why This Works (Mechanism)

**Mechanism 1: Incremental PPR Embeddings**
Claim: Parameter-free PPR embeddings enable efficient, incremental graph propagation without retraining.
Mechanism: Node embeddings are updated via Forward Push with error guarantee ||H(t) - Z(t)||₁ ≤ n(t)ϵ. Changes from edge updates are compensated by propagating a derived vector along the updated graph, avoiding full recomputation.
Core assumption: Edge updates affect only local neighborhoods; most node embeddings change minimally.
Break condition: If updates cause widespread topological shifts, approximation error may grow unbounded.

**Mechanism 2: Lazy-Sampling Discretization**
Claim: Lazy-sampling discretizes the continuous update sequence, reducing state updates by skipping embeddings with insignificant shifts.
Mechanism: For each edge update, compute an upper bound on embedding shift (Lemma 1). Accumulate bounds; when total exceeds λ, sample the current embedding and reset accumulator. This implicitly compresses intermediate embeddings.
Core assumption: Embedding shift per update is bounded and accumulates linearly; skipped embeddings lose negligible information.
Break condition: If shift bound is loose or non-informative, lazy-sampling may skip critical temporal signals.

**Mechanism 3: SSM with RNN-Attention Duality**
Claim: SSM updates with lazy-sampled embeddings achieve RNN-Attention duality, combining efficient recurrence with expressive aggregation.
Mechanism: State updates follow M(t+1) = A M(t) + B H(t+1). Under constraints, this reduces to a gated RNN; unrolled dynamics equal masked kernel attention (Eq. 8).
Core assumption: SSM parameters can effectively weight historical embeddings; lazy-sampled embeddings preserve essential patterns.
Break condition: If SSM parameters cannot learn appropriate masks, model may underfit or overfit.

## Foundational Learning

- **Personalized PageRank (PPR)**: Provides parameter-free, locality-sensitive embeddings that can be updated incrementally with bounded error, avoiding costly GNN retraining on every graph change. Quick check: How does Forward Push achieve O(||x(0)||₁/αϵ) time for a single PPR vector?
- **State Space Models (SSMs)**: Offer linear-time sequence modeling via recurrent state updates, theoretically compressing long histories efficiently (O(1) per step) compared to O(T²) attention. Quick check: What are the continuous-time and discrete-time SSM equations, and how does zero-order hold (ZOH) discretization connect them?
- **Lazy-sampling**: Controls effective sequence length for SSM by sampling embeddings only when accumulated shift exceeds λ, trading micro-accuracy for macro-efficiency. Quick check: According to Lemma 1, what three terms bound the embedding shift per edge update, and how does λ relate to the number of sampled embeddings?

## Architecture Onboarding

Component map: Edge Updates -> PPR Embedding Module -> Lazy-sampling Controller -> SSM State Updater -> Prediction Head

Critical path:
1. Receive batch of edge updates between tₖ and tₖ₊₁.
2. For each update, compute shift bound (Lemma 1) and accumulate σ.
3. If σ > λ or end of batch, run embedding update (Alg. 3) to get H(t), then SSM update to M(t).
4. Predict Y(t) = MLP(M(t)).
5. Repeat until all batches processed.

Design tradeoffs:
- λ (lazy threshold): Smaller → more samples → higher accuracy, slower; larger → fewer samples → faster, riskier.
- ϵ (PPR error): Smaller → more accurate embeddings, higher propagation cost.
- F′ (SSM hidden dim): Larger → more capacity, slower; smaller → faster, may underfit.
- α (PPR teleport): Balances locality vs. global influence; fixed in paper but could be tuned.

Failure signatures:
- **Accuracy collapse on long sequences**: Indicates insufficient memory retention or lazy-sampling skipping too much (λ too large).
- **Memory blow-up**: If lazy-sampling ineffective (λ too small), many embeddings sampled, SSM state grows large.
- **Slow per-update latency**: If PPR update not truly incremental or lazy-sampling rarely triggers, overhead approaches RNN/attention baselines.

First 3 experiments:
1. **Accuracy over time (Fig. 4)**: CODEN shows stable or improving Micro-F1 across prediction steps, while baselines fluctuate. Validates effective temporal information compression.
2. **Scalability on Papers100M (Tab. VI)**: CODEN completes in 3.3h vs. TGL's 98.3h. Demonstrates linear efficiency from decoupled propagation and SSM.
3. **Ablation (Tab. VII)**: CODEN-S (no temporal) drops accuracy; CODEN-A (attention) much slower but not more accurate; CODEN-R (RNN-constrained) slightly worse than full CODEN. Confirms necessity of full SSM with lazy-sampling.

## Open Questions the Paper Calls Out

- **How does lazy-sampling threshold λ affect trade-off between efficiency and accuracy across different graph dynamics and scales?** The paper introduces lazy-sampling with λ but provides no guideline for setting λ based on graph characteristics, limiting adaptability.
- **Under what conditions on SSM parameters does CODEN effectively avoid over-smoothing compared to attention-based models, and are these conditions consistently met during training?** Lemma 5 gives a condition involving parameter matrices, but it's unclear if standard optimization satisfies it or how deviations affect performance.
- **Can CODEN be extended to continuous edge-level prediction tasks while maintaining efficiency guarantees?** The framework focuses on node classification; adapting it for edge prediction might require additional computation, potentially violating O(1) update complexity.
- **How do PPR approximation errors and lazy-sampling accumulate over long time horizons, and what is their cumulative impact on prediction accuracy?** Per-step error bounds exist, but cumulative error over thousands of updates is not analyzed, which is critical for real-world applications.

## Limitations
- Unspecified hyperparameters (SSM initialization, MLP architecture, feature normalization, batching strategy) hinder exact replication.
- Assumptions about local invariance of PPR embeddings and linear shift accumulation may break under high graph churn.
- Lazy-sampling bound (Lemma 1) could be loose, causing skipped embeddings to carry critical temporal signals.

## Confidence
- **Efficiency & scalability**: High (strong empirical results on billion-scale graph).
- **Accuracy**: High (consistent Micro-F1 improvements).
- **Theoretical duality**: Medium (proof holds under ideal constraints; practical parameterization may deviate).
- **Lazy-sampling approximation**: Medium (theoretical guarantee assumes independent shifts; real correlations may loosen bound).
- **Incremental PPR correctness**: High (based on established Forward Push error bound).
