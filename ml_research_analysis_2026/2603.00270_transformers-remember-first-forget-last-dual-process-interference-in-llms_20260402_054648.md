# Transformers Remember First, Forget Last: Dual-Process Interference in LLMs

## Quick Facts
- **arXiv ID:** 2603.00270
- **Source URL:** https://arxiv.org/abs/2603.00270
- **Reference count:** 15
- **Primary result:** LLMs universally exhibit stronger proactive interference (PI) than retroactive interference (RI), protecting early memories at the expense of recent ones—opposite to typical human memory patterns.

## Executive Summary
This study adapts classical AB‑AC interference paradigms from cognitive psychology to probe how large language models handle conflicting information in context. Testing 39 models across architectures and scales, the authors measure two forms of interference: retroactive interference (RI, forgetting initial values after updates) and proactive interference (PI, inability to recall the latest value due to earlier ones). All models show PI > RI, a universal asymmetry that reverses as model size grows: larger models become more resistant to RI but not to PI. Error analysis reveals distinct failure modes—RI errors are mostly passive retrieval failures, while PI errors are active intrusions of early values. The findings suggest two dissociable memory processes in transformers, rooted in architectural constraints (causal attention’s primacy bias) and representational capacity (superposition).

## Method Summary
The authors built a stimulus dataset spanning 46 semantic categories (e.g., fruit varieties, chemical elements, painting mediums), each with 50–70 unique values. For each model and interference level N (3, 10, 50, 100, 200, 300 updates), they generated a random interleaving of updates across categories. After presenting an initial 46 category‑value pairs followed by the updates, they queried either the initial value (RI condition) or the last value (PI condition). Model accuracy at each N was recorded over three runs. Two metrics were computed: RIES (Retroactive Interference Endurance Score) and PIES (Proactive Interference Endurance Score), both defined as the area under the accuracy‑versus‑interference curve on a log‑scaled x‑axis using trapezoidal integration. The study also performed correlation and error‑taxonomy analyses across 39 pre‑trained LLMs.

## Key Results
- **PI > RI asymmetry:** All 39 models show significantly higher PIES than RIES (Cohen’s d = 1.73, p < 0.0001), meaning early encodings are better protected than recent ones.
- **RI scales with size, PI does not:** Model parameter count predicts RI resistance (R² = 0.49), but not PI resistance (R² = 0.06, not significant).
- **Error dissociation:** RI failures are mainly passive retrieval failures (51%) where the model omits or gives a later value; PI failures are primarily active primacy intrusions (56%) where the model erroneously returns an earlier value.

## Why This Works (Mechanism)

**Mechanism 1 – RI resistance scales with size due to reduced representational superposition.** Larger models allocate more orthogonal feature representations, allowing initial encodings to coexist with subsequent updates without overwriting. Evidence: strong correlation between RI resistance and parameter count (R² = 0.49). Break condition: if RI resistance fails to scale in models beyond 2.5T parameters or in non‑transformer architectures.

**Mechanism 2 – PI dominance stems from causal self‑attention’s primacy bias, an architectural constraint independent of capacity.** In causal attention, early tokens accumulate attention from all subsequent positions, reinforcing their representations; later tokens only receive backward attention, lacking this cumulative reinforcement. Evidence: universal PI > RI across all models; theoretical alignment with attention‑sink phenomena. Break condition: ablating positional biases (e.g., via attention reweighting) eliminates the asymmetry.

**Mechanism 3 – RI and PI failures reflect distinct retrieval dynamics: passive forgetting vs. active intrusion.** RI errors are retrieval failures (overwritten early traces), while PI errors are same‑key intrusions (persistent early traces that actively compete). Evidence: directional split in error taxonomy (51% vs 56%). Break condition: error distributions converge under semantically homogeneous updates or different retrieval cues.

## Architecture Onboarding
**Component map:** Input embeddings → Transformer layers (causal self‑attention + feed‑forward network + residual connections + LayerNorm) → Output logits.

**Critical path:** During the forward pass, each token’s representation is updated via attention over all previous tokens. The cumulative attention to early positions across layers reinforces them, creating a primacy bias. RI resistance depends on how stably the FFN layers preserve initial representations.

**Design tradeoffs:**
- More parameters reduce superposition (improving RI) but do not address the attention‑based PI bias.
- Larger context windows increase competition, potentially worsening both RI and PI.
- Chain‑of‑thought reasoning enhances consolidation (RI) but may exacerbate primacy intrusion (PI).

**Failure signatures:**
- **RI failure:** At high N (≥200) the model returns empty/refusal or a later update value (recency overwriting primacy).
- **PI failure:** The model confidently returns an earlier update value (primacy intrusion), often with position indices.
- **Both:** <1% hallucinations – errors are positional confusion, not fabrication.

**First 3 experiments:**
1. Replicate core RI/PI asymmetry on a small subset (10 categories, N∈{3,100,300}) to verify PI > RI for a target model.
2. Regress RIES against parameter count for a model family; expect strong positive correlation for RI but not PI. Compare MoE vs. dense architectures.
3. Visualize layer‑wise attention weights for RI and PI queries: check whether early‑token attention accumulates across layers; compare patterns in reasoning models.

## Open Questions the Paper Calls Out
- Does the PI > RI asymmetry generalize to ecologically valid, long‑form contexts with organic fact evolution, such as medical records or narrative timelines?
- What specific mechanism in causal self‑attention causes primacy bias—do early tokens accumulate disproportionate attention weights throughout the forward pass compared to recent tokens?
- Can architectural interventions (e.g., recency‑weighted attention, positional debiasing) specifically reduce proactive interference without compromising retroactive interference resistance?
- Do non‑transformer sequential models (e.g., state‑space models like Mamba, RWKV) exhibit the same PI > RI asymmetry, or is primacy bias unique to causal self‑attention?

## Limitations
- Stimulus composition (exact 46 categories and value pools) is unreported; reproduction requires de novo dataset creation, risking distributional mismatches.
- Prompt formatting details are underspecified; minor variations may differentially impact open vs. closed models.
- Proposed mechanisms (superposition scaling, attention bias) are correlational; causal manipulations were not performed.
- Error‑type taxonomy (retrieval failure vs. intrusion) lacks independent validation.

## Confidence
- **PI > RI asymmetry (universal):** High
- **RI resistance scales with model size:** Medium
- **Primacy bias due to causal attention:** Medium
- **RI/PI error dissociation reflects separate processes:** Low
