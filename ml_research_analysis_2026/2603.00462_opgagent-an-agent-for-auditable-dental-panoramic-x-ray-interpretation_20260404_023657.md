# OPGAgent: An Agent for Auditable Dental Panoramic X-ray Interpretation

## Quick Facts
- **arXiv ID:** 2603.00462
- **Source URL:** https://arxiv.org/abs/2603.00462
- **Reference count:** 30
- **Primary result:** OPGAgent achieves a 49.7% aggregate score on the OPG-Bench structured-report protocol, with an Exact Match F1 of 42.3%, outperforming leading VLMs and MedAgent-Pro while reducing false positives.

## Executive Summary
OPGAgent addresses the poor performance of generalist Vision Language Models (VLMs) on dental panoramic X-ray (OPG) interpretation by introducing a hierarchical multi-tool agentic system. The agent decomposes analysis from global anatomy down to individual teeth, orchestrates specialized spatial and detection tools alongside VLM experts, and employs a consensus subagent with anatomical constraints to resolve conflicts. On the newly proposed OPG-Bench benchmark, OPGAgent surpasses state-of-the-art VLMs and medical agents in structured report generation, demonstrating higher precision and fewer false positives. Ablation studies confirm the contribution of each module, particularly the integration of detection tools for spatial grounding.

## Method Summary
OPGAgent operates as a planner (GPT-5.2) using a ReAct loop to drive a three-phase hierarchical analysis: (1) global analysis establishes an anatomical coordinate system (FDI map) using spatial tools (YOLO, MedSAM); (2) quadrant-level screening identifies gross pathologies; (3) tooth-level screening examines high-resolution regions of interest. A specialized toolbox provides deterministic outputs (coordinates, masks, pathology detections) and VLM-based opinions (expert zoos). A consensus subagent aggregates all sources, requiring majority agreement and using tool-derived anatomical constraints to resolve attribute conflicts (e.g., tooth number, severity). A parser agent then converts the consensus memory into a structured report of (Location, Field, Value) triples using constrained decoding.

## Key Results
- Achieves 49.7% aggregate score and 42.3% Exact Match F1 on OPG-Bench, surpassing VLMs and MedAgent-Pro.
- Demonstrates higher precision (43.1% vs. 27.6%) and fewer false positives per case (4.89 vs. 10.58).
- Leads on MMOral-OPG VQA benchmark with 62.53% accuracy.
- Ablation shows full system peaks at 42.30% F1; adding detection tools after expert zoos yields the largest jump.

## Why This Works (Mechanism)

### Mechanism 1: Hierarchical Decomposition
The agent sequentially executes global, quadrant, and tooth-level phases, storing intermediate findings in shared memory. This mirrors clinical workflow, preventing oversight of large-scale anatomy while enabling detailed investigation without overwhelming the system with high-resolution data everywhere. Break condition: failure in global phase (e.g., missed tooth count) cascades to mislocalization in later phases. Evidence: paper describes phased architecture; related work on dental segmentation exists but agent orchestration is novel.

### Mechanism 2: Specialized Tool Integration
A toolbox of domain-specific models (spatial: YOLO, MedSAM; detection: pathology-specific networks; utility: FDI mapper, ROI cropper) provides precise, grounded evidence that compensates for VLMs' weak spatial reasoning. Expert zoos (DentalGPT, etc.) supplement but do not replace tool outputs. Break condition: a critical tool failure (e.g., missed quadrant) creates blind spots only discovered later via consensus. Evidence: toolbox design; corpus supports specialization gains but not this specific integration.

### Mechanism 3: Consensus with Anatomical Constraints
A subagent aggregates votes from tools and VLMs (≥3 sources or ≥2 identical reports). When sources conflict on attributes (e.g., severity), it consults deterministic tool outputs (FDI maps, bounding boxes) to override inconsistent VLM responses, reducing hallucination. Break condition: systematic miss of a finding type across all sources, or ambiguous constraints for overlapping pathologies. Evidence: ablation shows F1 jump from 23.25% to 42.30% when adding detection tools (which provide constraints).

## Foundational Learning
- **Hierarchical Clinical Ontology (FDI, ICDAS, AAP/EFP)**: Standardized anatomy (FDI quadrants/teeth) and pathology scales map all findings; misapplication breaks localization/classification. Quick check: How does the system differentiate tooth 36 (lower left first molar) from 46 based on spatial tool coordinates?
- **Agentic Planning (ReAct) vs. End-to-End Generation**: The LLM is a planner deciding tool calls, not a diagnostician. Confusing this misinterprets ablations where the agent without tools fails. Quick check: What triggers transition from Phase 1 to Phase 2—fixed rule or memory content?
- **Constrained Parsing & Structured Reporting**: Final output must match exact (L,F,V) schema; formatting errors count as failures. Quick check: If a VLM says "decay on upper right first molar," how does the parser map to FDI "16" and ICDAS "3"?

## Architecture Onboarding
- **Component map**: Planner (LLM) -> Memory (shared state) -> Hierarchical Evidence Gathering (phases 1-3) -> Specialized Toolbox (spatial, detection, utility, expert zoos) -> Consensus Subagent -> Parser Agent -> Evaluator.
- **Critical path**: Start -> Planner (Phase 1: Global) -> call Spatial Tools + Expert Zoos -> update Memory (anatomical map) -> Planner (Phase 2: Quadrant) -> for each quadrant: call Utility crop + Expert Zoos -> update Memory (flags) -> Planner (Phase 3: Tooth) -> for flagged teeth: call Utility crop + Detection Tools + Expert Zoos -> Consensus (aggregate/resolve) -> Memory -> Parser -> Structured Report.
- **Design tradeoffs**:
  - Precision vs. Recall: Tool-heavy approach misses rare findings; VLM-heavy introduces hallucinations.
  - Speed vs. Accuracy: Hierarchical calls are slow; suited for diagnostic support, not triage.
  - Generality vs. Specialization: Locked to OPGs/FDI; porting to other modalities requires rebuilding.
- **Failure signatures**:
  - Cascading localization errors: Global phase tooth count error propagates.
  - Hallucinated consensus: Correlated VLM errors lack tool contradiction.
  - Constraint mismatch: Tool outputs too coarse to resolve VLM attribute conflicts.
- **First 3 experiments**:
  1. Baseline agent ablation: Run with all tools disabled; expect very low F1 (~27.78%).
  2. Tool isolation test: Enable only Expert Zoos; expect high precision, very low recall, low FP/case.
  3. Spatial grounding test: Enable Expert Zoos + Spatial Tools; expect recall jump with moderate FP.

## Open Questions the Paper Calls Out
- **Open Question 1**: How to correct evaluation metrics when clinical reports miss incidental findings that the agent correctly detects? Ground truth prioritizes chief complaints, inflating false positives. Resolution: Build multi-expert gold standard covering all findings.
- **Open Question 2**: Can the hierarchical pipeline adapt to other dental imaging (periapical, CBCT)? Designed solely for OPGs with quadrant/tooth phases and FDI. Resolution: Apply to other datasets and report necessary modifications.
- **Open Question 3**: Does confidence-weighted consensus improve accuracy over equal-weight voting? Current consensus ignores source reliability. Resolution: Weight sources by confidence and compare EM F1/FP.
- **Open Question 4**: How does OPGAgent perform under image quality degradations (blur, noise)? Evaluation used clean images; real-world robustness unknown. Resolution: Degrade test images with realistic distortions and measure performance changes.

## Limitations
- Proprietary tool checkpoints (e.g., OralGPT-Omni detectors) and training details are unreleased; proxies may underperform.
- Planner prompts, ReAct traces, and memory schema are unspecified, obscuring decision logic.
- OPG-Bench representativeness is unclear; lack of statistical tests reduces confidence in reported numbers.
- Exact-match F1 (~42%) is modest and penalizes minor format errors, questioning clinical relevance.
- System is tightly bound to OPGs/FDI ontology, limiting portability to other imaging modalities.

## Confidence
- Hierarchical decomposition improves detection completeness: **Medium** (narrative support, no direct ablation).
- Specialized tool integration boosts spatial grounding/precision: **High** (ablation shows large F1 jump).
- Consensus subagent reduces hallucinations: **High** (ablation and design rationale).
- Overall superiority over VLMs/MedAgent-Pro: **Medium** (benchmark lacks variance estimates).
- Auditable pipeline: **High** (tool calls and structured output provide traceability).

## Next Checks
1. **Hierarchical ablation**: Implement a flat-plan variant (all tools on full image) and compare EM F1 to isolate decomposition’s contribution.
2. **External generalization**: Evaluate on an independent OPG dataset (e.g., DENTEX) remapped to FDI triples; measure performance drop.
3. **Failure mode audit**: Classify 100 incorrect predictions as (a) global-phase FDI failure, (b) tool/VLM miss, or (c) consensus error; compute error proportions.
