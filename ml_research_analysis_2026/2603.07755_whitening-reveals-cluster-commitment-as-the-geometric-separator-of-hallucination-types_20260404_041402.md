# Whitening Reveals Cluster Commitment as the Geometric Separator of Hallucination Types

## Quick Facts
- arXiv ID: 2603.07755
- Source URL: https://arxiv.org/abs/2603.07755
- Reference count: 7
- Primary result: PCA-whitening reveals that peak cluster alignment (max_sim) robustly separates Type 2 from Type 3 hallucinations in GPT-2-small, and provides a consistent directional hint for Type 1/2, demonstrating capacity limitations at 124M parameters.

## Executive Summary
Geometric definitions of hallucination types in language models predict a gradient of cluster commitment: Type 2 (wrong-well) commits to a cluster, Type 1 (center-drift) drifts toward the center without commitment, and Type 3 (coverage gap) aligns with no cluster. In GPT-2-small, contextual representations are highly anisotropic (cosine similarities ~0.985), making these subtle angular differences indiscernible in full-dimensional metrics. The authors apply PCA-whitening to equalize variance across principal components, transforming the space into an isotropic regime where micro-signals become detectable. They show that whitened max_sim (maximum cosine similarity to any of 40 cluster centroids) aligns with the theoretical ordering: Type 2 exhibits the highest max_sim, Type 1 intermediate, and Type 3 the lowest.

Whitened max_sim robustly separates Type 2 from Type 3 across 20 random seeds and 30 prompts per condition (Holm-corrected significance, rank-biserial r = –0.31, directional stability 20/20). A weaker but consistent separation of Type 1 from Type 2 also emerges (r = +0.21, 17/20 direction, Holm survival ~15%), suggesting the distinction requires larger model capacity rather than being an artifact of spectral mixing. A false positive using whitened entropy disappears when prompts are expanded from 15 to 30 per group, highlighting the fragility of micro-signal findings to prompt-set composition. Eigenspectrum decomposition localizes this artifact to the dominant principal components (PCs 1–16) and confirms no Type 1/2 separation in any spectral band, rejecting spectral mixing as the cause.

## Method Summary
The pipeline uses GPT-2-small (124M). First, a calibration set of 40 diverse prompts generates ~2400 contextual vectors (last layer, last token). PCA on centered vectors selects the top 256 components (explaining >99.7% variance). The whitening matrix is built as `W[:,i] = v_i / sqrt(λ_i + 1e-5)`; whitening is applied as `w = (h - μ) @ W`. Clustering with MiniBatchKMeans (k=40) on whitened calibration vectors yields fixed centroids. For experimentation, three hallucination prompt groups (Type 1: weak context; Type 2: polysemy/garden-path; Type 3: knowledge boundaries) each provide 30 prompts. Over 20 random seeds, up to 60 tokens are generated per prompt (temperature 1.0). For each token, the whitened vector is computed and three metrics relative to the centroids are recorded: max_sim (maximum cosine similarity), entropy H(v) (softmax over cosine similarities), and vector norm. Token metrics are averaged per prompt. Pairwise Mann-Whitney U tests are performed at the prompt level across seeds; significance is assessed via rank-biserial r, Holm-Bonferroni correction within each metric family, directional stability, and pseudoreplication ratios.

## Key Results
- Whitened max_sim separates Type 2 from Type 3 robustly: Holm-corrected significance in ~40% of seeds, rank-biserial r ≈ –0.31, directional stability 20/20, with mean ordering T2 (0.180±0.004) > T1 (0.172±0.004) > T3 (0.168±0.003).
- An underpowered but consistent hint of Type 1/Type 2 separation appears (r ≈ +0.21, directional stability 17/20), indicating the frontier depends on model capacity beyond 124M parameters.
- A false positive with whitened entropy (strong T1–T3 and T2–T3 at N=15 prompts) collapses when expanding to N=30, demonstrating prompt-set artifact in the micro-signal regime; eigenspectrum analysis localizes this artifact to PCs 1–16 and shows no Type 1/2 separation in any spectral band.

## Why This Works (Mechanism)
PCA-whitening transforms GPT-2's highly anisotropic contextual representations (cosine similarities near 0.985) into an isotropic space where subtle angular differences become first-order measurable. The whitening decorrelates and rescales dimensions so that all directions have unit variance, thus amplifying the micro-signal regime where meaningful differences lie in the fourth decimal place. In this space, the taxonomy's core concept of "cluster commitment" is operationalized as peak cluster alignment (maximum cosine similarity to any cluster centroid). The taxonomy predicts a gradient: Type 2 (wrong-well) exhibits highest commitment, Type 1 (center-drift) intermediate, and Type 3 (coverage gap) lowest. Whitening makes this gradient detectable; without it, full-dimensional angular metrics are compressed into a narrow range with negligible between-condition variance.

However, results in the micro-signal regime are vulnerable to prompt-set artifacts: a fixed prompt set can systematically align with a few dominant principal components (PCs 1–16), producing a spurious separation that replicates across generation seeds but collapses when prompts are diversified. This explains the whitened entropy false positive. Therefore, robustness to prompt diversification and spectral localization are essential sanity checks.

## Foundational Learning
- **PCA Whitening (decorrelation & unit variance)**  
  *Why needed here:* Transforms anisotropic contextual space into isotropic to amplify micro-signals; equalizes variance so angular deviations become measurable.  
  *Quick check:* If data is already perfectly isotropic (identity covariance), whitening is a no-op; clustering results remain unchanged.

- **Cluster Commitment (max_sim metric)**  
  *Why needed here:* Directly operationalizes the taxonomy's gradient; max_sim captures strongest alignment to any centroid, whereas entropy conflates commitment with distributional spread.  
  *Quick check:* A vector moderately similar to one centroid and dissimilar to others yields high max_sim and low entropy; a vector mildly similar to many centroids yields low max_sim and high entropy.

- **Multi-Run Stability Analysis with Prompt-Level Aggregation**  
  *Why needed here:* Distinguishes true between-condition differences from token-level autocorrelation (pseudoreplication) and assesses reliability of small effects across generation randomness.  
  *Quick check:* If token-level significance >> prompt-level significance, the effect likely stems from within-prompt autocorrelation rather than a genuine condition difference.

## Architecture Onboarding
*Component map:*  
Calibration Generator → PCA Whitener → Clusterer → MetricComputer → StatisticalEngine

*Critical path:*  
Calibration data → PCA decomposition → Whitening transform → Clustering → (For each experimental run: generate tokens → whiten vectors → compute metrics → aggregate by prompt) → statistical tests across 20 seeds → interpret Holm survival & directional stability.

*Design tradeoffs:*
- Whitening components (256) vs. computational cost: 256 captures >99.7% variance; using all 768 adds negligible gain but higher cost.
- Cluster count (k=40) vs. granularity: Fixed k based on calibration; different k alters absolute max_sim but relative ordering should be stable.
- Prompt count (N=30) vs. power: Balances cost and detection of ~r=0.2 effects; N=15 is underpowered and prone to artifacts.
- Seed count (20) vs. certainty: Provides directional stability estimates; more seeds would tighten confidence intervals.

*Failure signatures:*
- Prompt-set artifact: Metric (e.g., whitened H(v)) significant at N=15 but collapses at N=30.
- Incorrect whitening: No ordering T2 > T1 > T3 in whitened max_sim; covariance not near identity.
- Pseudoreplication inflation: Token-level significance >> prompt-level significance.
- Clustering instability: Results change drastically with different k or clustering seed.
- Whitened norm destruction: Norm remains significant after whitening (should be non-informative).

*First 3 experiments:*
1. Calibration & Whitening Validation: Verify whitened calibration covariance ≈ identity; raw norm correlates with first PC magnitude.
2. Replication of Paper 2 Raw Norm: With N=30 prompts/type, confirm raw norm ordering T1 > T2 > T3.
3. Whitened max_sim T2–T3 Test: Expect perfect directional stability (20/20), ordering T2 > T1 > T3, inverted pseudoreplication (<1 token vs. prompt significance ratio).

## Open Questions the Paper Calls Out
- **Does scaling model size enable robust Type 1/Type 2 separation?** The current underpowered hint (r=+0.21, 17/20 directional stability) suggests capacity limitations at 124M parameters. Testing larger models (e.g., GPT-2-medium, Llama 2 7B) with the same pipeline could confirm whether T1–T2 separation strengthens, supporting the capacity hypothesis.
- **What prompt-set size and diversity thresholds guarantee stable detection?** The collapse of whitened entropy when expanding from 15 to 30 prompts reveals fragility. Systematically varying prompt count (e.g., 30, 60, 120) and diversity (domains, syntax) would identify minimal robust configuration and cross-validation strategies.
- **Is the tail eigenspectrum signal scalable or an artifact?** The strongest Type 3 effects appear in PCs 513–768 (<0.1% variance). This may become meaningful at larger scale where tail variance increases. Replicating spectral band analysis on >1B parameter models would test scalability.

## Limitations
- Prompt dependence: Exact 30 prompts per condition are not disclosed; reconstruction may introduce bias; micro-signal regime remains vulnerable to prompt-set composition.
- Clustering sensitivity: Choice of k=40 is arbitrary; results may not be robust to different k or clustering seeds.
- Whitening implementation details: Unclear whether whitened vectors are L2-normalized before cosine similarity; regularization ε and PC cut-off specifics require exact replication.
- Statistical correction: It is ambiguous whether Holm adjustment is applied per-seed across the three pairwise tests or across seeds; this affects reported significance rates.

## Confidence
- Whitening amplifies micro-signals: Medium confidence (plausible but untested on isotropic models; break condition possible).
- Peak cluster alignment separates types: High confidence for Type 2 vs. Type 3 (consistent r, 20/20 stability); Medium confidence for the Type 1/Type 2 hint (underpowered but directionally stable).
- Prompt-set artifact and spectral localization: High confidence (collapsed with prompt expansion, confined to PCs 1–16).

## Next Checks
1. Prompt diversity stress test: Generate 60+ diverse prompts per condition; verify whitened max_sim T2–T3 remains robust and any residual H(v) artifact stays absent.
2. Clustering robustness sweep: Vary k ∈ {20,40,60} and clustering random seeds; assess stability of max_sim ordering (T2 > T1 > T3) and T2–T3 effect size (rank-biserial r).
3. Capacity scaling experiment: Apply identical pipeline to larger GPT-2 variants (355M, 774M); test whether T1–T2 separation strengthens significantly, as predicted by the capacity hypothesis.
