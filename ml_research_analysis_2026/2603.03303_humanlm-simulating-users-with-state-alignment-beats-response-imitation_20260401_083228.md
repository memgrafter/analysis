# HumanLM: Simulating Users with State Alignment Beats Response Imitation

## Quick Facts
- **arXiv ID:** 2603.03303
- **Source URL:** https://arxiv.org/abs/2603.03303
- **Reference count:** 40
- **Primary result:** HumanLM achieves an average relative improvement of 16.3% in alignment scores over the best baselines and received the highest similarity ratings (41.4% win rate) in a human study, being judged most human-like.

## Executive Summary
The paper introduces HumanLM, a user simulator that captures underlying psychological states (belief, goal, value, stance, emotion, communication) rather than merely imitating surface language patterns. It trains a model to generate explicit latent states aligned with ground-truth responses via reinforcement learning, then synthesizes responses using reasoning traces that integrate these states. Evaluated on the new Humanual benchmark (26k users, 216k responses across six domains), HumanLM outperforms baselines by 16.3% in LLM-judged alignment. A real-time study with 111 participants confirmed its superiority, with a 41.4% win rate for similarity and the highest human-likeness ratings.

## Method Summary
HumanLM employs a two-stage training process. First, it processes user profiles (summarized from up to 20 past responses) and input context to generate explicit latent state descriptions for six psychological dimensions. A batch-wise comparative LLM judge scores multiple rollouts per context, producing rewards for each dimension. The model is updated with GRPO (Group Relative Policy Optimization) using these rewards. Second, the model generates a reasoning trace that enumerates and integrates the aligned states, then synthesizes the final response. At inference, the model produces a full trace covering all six states before generating output. The Humanual benchmark provides diverse domains for training and evaluation, with alignment scores, embedding similarity, and human evaluations as metrics.

## Key Results
- Average relative improvement of 16.3% in LLM-judged alignment scores over best baselines across six domains.
- In a human study (111 participants), HumanLM achieved a 41.4% win rate for response similarity and was rated most human-like.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Explicit latent state alignment via reinforcement learning yields user simulators that better capture real user psychological drivers compared to surface-level response imitation.
- **Mechanism:** HumanLM trains the model to generate explicit natural-language descriptions of six psychologically grounded state dimensions. These latent states are rewarded using comparative alignment scores from an LLM judge, forcing the model to learn the underlying psychological structure that generates real user responses. During inference, the model produces reasoning traces containing these aligned states before synthesizing the final response.
- **Core assumption:** Real human responses are driven by psychologically meaningful states that are more stable and generalizable than surface language patterns; aligning on these states transfers better to unseen contexts.
- **Evidence anchors:** 
  - Abstract: "HumanLM introduces a training framework where the model generates explicit latent states aligned with ground-truth responses across six psychologically grounded dimensions...using reinforcement learning."
  - Section 3.2: "Our idea is to explicitly generate latent states and treat responses as outcomes conditioned on latent states...This reframes the problem. Instead of asking 'given the extracted latent states, is this response well-aligned?' we ask 'how can we generate aligned latent states such that given these states, the synthesized responses are aligned?'"
  - Corpus: Neighbor paper "Beyond Fixed Psychological Personas: State Beats Trait..." argues state matters more than traits, supporting HumanLM's state focus.
- **Break condition:** If state dimensions fail to capture psychological variance driving real responses (e.g., new dimensions emerge in test contexts), the mechanism breaks as latent states become misaligned.

### Mechanism 2
- **Claim:** Batch-based comparative evaluation of latent states provides clearer, less biased reinforcement signals than scoring each state independently.
- **Mechanism:** HumanLM scores a batch of rollouts for the same context side-by-side. The LLM judge comparatively ranks which latent state best aligns with the ground truth response, producing a more precise reward signal that distinguishes between different types of alignment errors.
- **Core assumption:** Absolute scoring of nuanced psychological states is noisy and prone to score inflation; relative comparison within a batch reveals finer-grained quality differences.
- **Evidence anchors:**
  - Section 3.2: "Assigning a score one at a time with an LLM judge introduces significant bias due to the lack of comparison...To avoid bias score assignment, we sample a batch of latent states for the same context...and prompt the LLM judge to score them comparatively."
  - Section 3.2: "The LLM judge may assign the same score of 1.0 to two latent states...when evaluated separately, even though the latter is more comprehensive and accurate."
- **Break condition:** If batch diversity is low (all rollouts similar), comparative scoring loses discriminative power; if judge consistency is poor across batches, reward becomes noisy.

### Mechanism 3
- **Claim:** Reasoning traces that explicitly enumerate and integrate aligned latent states before response generation improve synthesis quality and human-likeness.
- **Mechanism:** HumanLM prompts the model to generate a "think" trace that lists the six state dimensions, describes how each should be expressed, and decides on organization/emphasis. This structured reasoning ensures multiple psychological constraints are unified coherently before the final response is produced.
- **Core assumption:** Human language production involves integrating multiple simultaneous psychological constraints; explicit reasoning yields more natural synthesis than implicit conditioning.
- **Evidence anchors:**
  - Section 3.3: "In the reasoning traces, the model also analyzes how these latent states impact the final response, such as how to organize it...which latent states to emphasize, and which to make more concise."
  - Figure 8: Shows examples where the trace covers all six dimensions and the final response reflects multi-dimensional alignment.
  - Section 5.1: "By explicitly generating latent states, the model receives clear signals to align with latent states in the ground truth. This mitigates local optima when relying only on response alignment scores."
- **Break condition:** If the model learns to generate template traces that don't influence the response, or if multi-step generation introduces unacceptable latency.

## Foundational Learning
### Reinforcement Learning from Reward Signals (PPO/GRPO)
- **Why needed here:** HumanLM optimizes alignment scores (from LLM judge) as rewards rather than token-level cross-entropy. The model must learn from scalar feedback on generated outputs, not ground-truth tokens.
- **Quick check:** "How does the policy gradient update work when rewards are computed at the sequence level rather than per token?"

### Psycholinguistic State Modeling
- **Why needed here:** The six state dimensions (Belief-Desire-Intention, positioning theory, affective science, communication styles) are not standard NLP annotations. Engineers must understand what each dimension captures to design prompts, interpret results, and debug failures.
- **Quick check:** "What's the difference between 'stance' (position on a specific issue) and 'value' (general principle) in this framework? Give an example of a response where these might conflict."

### LLM-as-a-Judge Evaluation
- **Why needed here:** The entire training loop relies on an LLM judge to score alignment. Engineers must understand judge prompt design, bias sources, and calibration to interpret training dynamics and final results.
- **Quick check:** "Why does the paper use batch-based comparative scoring rather than absolute scores? What specific judge bias does this address?"

## Architecture Onboarding
**Component map:**
User Profile (from history) → Context Encoder → Latent State Generator (6 dimensions) → Reasoning Trace Composer → Response Synthesizer → Output
         ↑                                                              ↓
     LLM Judge (for rewards) ←─────────────── GRPO Trainer

**Critical path:**
1. Profile processing: Extract structured persona from user history (using Claude 4.5 Haiku in paper).
2. State generation: For each sampled dimension, generate natural-language state description.
3. Batch formation: Multiple rollouts per context for comparative scoring.
4. Judge scoring: LLM judge compares batch for each dimension, yields rewards.
5. GRPO update: Policy gradient update using rewards for both states and responses.
6. Inference: Generate full reasoning trace with all six states, then synthesize response.

**Design tradeoffs:**
- State granularity: Six dimensions balance comprehensiveness vs. reward sparsity. More dimensions → sparser signals; fewer → loses nuance.
- Batch size for comparison: Larger batches improve judge reliability but increase memory/latency. Paper uses group size 4.
- Sequential vs. parallel state generation: Paper samples one dimension per batch, but inference generates all sequentially. Tradeoff: focused learning vs. efficiency.
- Reasoning trace length: Longer traces allow more explicit reasoning but increase inference cost and risk of incoherence if states contradict.

**Failure signatures:**
- State gaming: Model generates plausible-sounding states that don't influence response (check: ablation where states ignored but scores still high).
- State collapse: Multiple dimensions converge to similar descriptions (e.g., stance and emotion both become "negative"). Indicates reward shaping too coarse.
- Reasoning-response mismatch: Trace contains aligned states but final response contradicts them. Suggests synthesis stage not properly conditioned.
- Over-alignment to judge: Model exploits judge biases without improving real human alignment. Need judge diversity/consistency checks.

**First 3 experiments:**
1. **Ablation - Remove explicit state generation:** Train GRPO directly on response alignment scores without state intermediates. Compare to HumanLM to isolate benefit of explicit state alignment.
2. **State ablation - Zero out specific dimensions:** During training, mask rewards for one dimension (e.g., emotion). Measure drop in response alignment to quantify dimension importance (Figure 7 already shows this empirically).
3. **Judge consistency check:** Use multiple LLM judges (GPT-5-mini, Claude, Gemini) on same rollouts. If rankings differ significantly, reward signal is unreliable; consider judge ensemble or calibration.

## Open Questions the Paper Calls Out
1. **Enhancing response diversity:** How can we enhance the diversity of responses generated by user simulators to reflect real user variability? (The paper notes this as future work; evidence: compare distribution metrics and introduce latent diversity variables.)
2. **Multi-domain training:** What strategies enable effective multi-domain training of user simulators, allowing a single model to perform well across heterogeneous contexts? (Currently separate models per dataset; evidence: train unified model, study domain-specific parameters.)
3. **Sufficiency of state dimensions:** Are the six pre-defined psychological state dimensions sufficient to capture all factors driving user responses, or are important dimensions missing? (Dimensions might be incomplete; evidence: annotate responses, add candidate dimensions.)
4. **Reliability of LLM judges:** How reliable are LLM-based judges for evaluating latent state alignment, and can we develop more objective metrics that correlate with human judgments? (Reliance on LLM judges risks bias; evidence: human evaluation of state alignment, hybrid metrics.)

## Limitations
- GRPO training hyperparameters and schedule are not specified, preventing exact replication.
- Judge prompt formulation and batch-comparison details remain ambiguous, risking noisy rewards.
- The six psychological dimensions may be insufficient to capture all user state variance; untested dimensions could be critical in new domains.
