# SCONE: A Practical, Constraint-Aware Plug-in for Latent Encoding in Learned DNA Storage

## Quick Facts
- **arXiv ID:** 2602.06157  
- **Source URL:** https://arxiv.org/abs/2602.06157  
- **Reference count:** 29  
- **Primary result:** SCONE achieves constraint-aware DNA encoding with 99.7% GC satisfaction (mean 0.500±0.012), homopolymer length ≤3, 1.864 bits-per-nucleotide, <2% encoding latency overhead, and perfect reversibility.

## Executive Summary
SCONE is a novel plug‑in module for learned DNA storage that replaces the standard binary entropy coder with a unified, constraint‑aware quaternary arithmetic coder. By integrating a finite‑state machine (FSM) directly into the probability modeling step, SCONE dynamically enforces biochemical constraints—GC balance and homopolymer limits—during encoding, eliminating the need for post‑hoc correction and its associated redundancy. The design is codec‑agnostic, preserving upstream neural networks and hyperprior pathways. Experiments on 5000 random sequences demonstrate high constraint satisfaction (99.7% GC within target range), low homopolymer runs (≤3), competitive compression (1.864 bits per nucleotide), minimal overhead (<2%), and flawless reversibility.

## Method Summary
SCONE modifies the entropy bottleneck of a hyperprior‑based learned compression pipeline (e.g., from CompressAI). The quantized latent symbols, originally integers, are treated as quaternary nucleotides {A,T,G,C}. Instead of binary arithmetic coding, a custom quaternary arithmetic coder is used. A finite‑state machine tracks a sliding window of the last 20 bases to compute the GC ratio and the current homopolymer base and run length. At each step, the FSM emits a binary mask that disallows bases that would violate constraints. The base probabilities from the hyperprior’s Gaussian conditional model are masked and renormalized, ensuring only valid bases feed the arithmetic coder. This constraint‑aware adaptive coding occurs during entropy encoding, guaranteeing that the generated DNA sequence meets synthesis constraints without any post‑processing. The module is fully reversible and introduces negligible latency.

## Key Results
- **GC constraint satisfaction:** 99.7% of generated sequences achieve mean GC ratio 0.500±0.012 within the target [0.45, 0.55].
- **Homopolymer enforcement:** maximum run length ≤3 across all test sequences.
- **Compression efficiency:** 1.864 bits per nucleotide (bpn), close to the unconstrained theoretical limit.
- **Latency overhead:** less than 2% compared to a standard binary arithmetic coder.
- **Reversibility:** 100% perfect reconstruction of the original latent representation.

## Why This Works (Mechanism)
SCONE’s efficiency stems from three interconnected mechanisms:

1. **Direct quaternary arithmetic coding** – The system bypasses separate binary quantization and mapping steps. Latent symbols are directly interpreted as DNA bases, and a quaternary arithmetic coder operates on the learned distribution. This avoids conversion losses and exploits the natural entropy of the 4‑symbol alphabet.

2. **Constraint‑aware FSM‑guided probability modeling** – The FSM maintains deterministic state (window GC count, homopolymer base and length). It produces a mask that excludes bases that would violate constraints. The hyperprior’s probability distribution is masked and renormalized, ensuring the arithmetic coder only considers valid symbols. Constraints are thus enforced during encoding, with a “fail‑safe relaxation” policy that first relaxes GC if all bases are blocked, preventing deadlock while maintaining homopolymer limits.

3. **Codec‑agnostic plug‑in design** – SCONE replaces only the entropy coder in any hyperprior‑based architecture. Upstream encoder/decoder networks and the hyperprior pathway (which estimates Gaussian parameters for the latent distribution) remain unchanged. This preserves the original rate‑distortion trade‑off while adding constraint awareness, and all non‑quantization operations stay differentiable for optional fine‑tuning.

## Architecture Onboarding
**Component map:** Upstream neural encoder → Quantizer → SCONE Core (FSM module, masking & renormalization, quaternary arithmetic coder) → Hyperprior pathway (provides Gaussian conditional P_GC) → DNA sequence string

**Critical path:** For each symbol in the quantized latent ŷ: (1) query FSM for constraint mask m; (2) obtain base probabilities p from hyperprior model P_GC(µ,σ); (3) apply mask and renormalize to get ṗ; (4) update arithmetic coding interval using ṗ; (5) output the selected DNA base; (6) update FSM state with emitted base; repeat.

**Design tradeoffs:**
- *Determinism vs. rate:* Strict masking can force low‑probability symbols, slightly increasing bpn (e.g., 1.86 vs. unconstrained 2.00).
- *Generality vs. optimality:* Being codec‑agnostic means the latent representation isn’t optimized for DNA constraints; joint training could further improve rate‑distortion.
- *Statefulness:* FSM state is fully recoverable but requires deterministic, identical initialization; any desynchronization (e.g., missing base) breaks reconstruction.

**Failure signatures:**
1. **Empty mask deadlock:** All four bases are masked and the relaxation policy fails; encoding halts.
2. **Bitstream mismatch:** Encoder and decoder FSM states diverge due to asymmetric logic or precision issues, causing irreversible errors.
3. **Excessive bpn:** Consistently >2.0 bpn indicates over‑aggressive masking or poor probability calibration by the hyperprior.

**First 3 experiments:**
1. **Baseline functionality:** Encode/decode a short (L=10) random quaternary sequence with FSM disabled; verify 100% bit‑exact reconstruction and baseline bpn ~2.0.
2. **FSM state verification:** For a short sequence, log FSM state (window GC, homopolymer run) and mask at each step; manually confirm mask logic (e.g., GC >0.55 blocks G/C).
3. **Constraint stress test:** Generate a long (L=1000) sequence from a biased latent distribution (e.g., mostly A/T); verify GC stays within [0.45,0.55] and max homopolymer ≤3 throughout.

## Limitations
- FSM initialization and windowing details (sliding vs. expanding) are unspecified, hindering exact replication.
- The “fail‑safe relaxation” policy’s precise unmasking rules (order, base selection) are not elaborated.
- Codec‑agnosticism is demonstrated on only one hyperprior model; validation across diverse architectures is lacking.

## Confidence
- Mechanism 1 (direct quaternary arithmetic coding): Medium  
- Mechanism 2 (FSM constraint enforcement): Medium  
- Mechanism 3 (plug‑in design): Low  
- Performance metrics (GC satisfaction, bpn, overhead, reversibility): High
