# SemBench: A Universal Semantic Framework for LLM Evaluation

## Quick Facts
- arXiv ID: 2603.11687
- Source URL: https://arxiv.org/abs/2603.11687
- Reference count: 13
- Key outcome: High Spearman correlation (up to 0.93) between SemBench and WiC rankings for English; robust performance in Spanish and Basque.

## Executive Summary
SemBench is a fully automatic, language-independent framework for evaluating LLM semantic understanding by generating benchmarks from dictionary definitions and a sentence encoder, eliminating manual curation. Evaluated on English, Spanish, and Basque with multiple LLMs, it yields rankings strongly correlated with WiC benchmarks: Spearman's ρ=0.930 (Def) and 0.911 (Ex) for English, 0.765 for Spanish, and 0.657 for Basque. Stable rankings require only 250 test instances, and SemBench exhibits greater discriminative power than WiC. It maintains effectiveness across resource levels, notably capturing language-specific competence in low-resource Basque better than WiC.

## Method Summary
SemBench generates test instances by sampling polysemous words from dictionaries, selecting a target sense and a distractor sense. For each instance, the LLM is prompted to generate either an example from a definition (SemBenchDef) or a definition from an example (SemBenchEx). The generated output is compared to the target and distractor definitions using a frozen sentence encoder (EmbeddingGemma 300M). Correctness is determined by whether the output is more similar to the target definition than the distractor. Model rankings are established by accuracy on these instances and correlated with standard WiC rankings. The framework requires only dictionary definitions and no manual data curation, making it applicable to low-resource languages.

## Key Results
- Spearman's ρ between SemBench and WiC rankings: 0.930 (English Def), 0.911 (English Ex), 0.765 (Spanish), 0.657 (Basque)
- Stable model rankings achieved with as few as 250 test instances
- SemBench demonstrates greater discriminative power than WiC across all tested languages
- Successfully evaluated models in low-resource Basque, capturing language-specific competence

## Why This Works (Mechanism)

### Mechanism 1
A model with genuine semantic competence can maintain consistent representations when asked to generate either an example from a definition (SemBenchDef) or a definition from an example (SemBenchEx). The framework tests the LLM's ability to accurately map a word sense between two linguistic forms. For a given sense, the model generates one form from the other. The generated output's semantic fidelity is then evaluated by measuring its similarity to the reference sense versus a distractor sense using a frozen sentence encoder. Correct performance indicates the model's generated output stays within the intended sense boundaries.

### Mechanism 2
The semantic difficulty of a generated instance is controllable and predictive of model performance by selecting distractors based on their encoder-based similarity to the target definition. For a target sense definition, potential distractor definitions are ranked by cosine similarity. Difficulty is set by distractor rank: easy (least similar), mid (median), hard (most similar), or rand (random). A harder distractor requires finer-grained semantic discrimination. The geometric closeness of sense definitions in the encoder's embedding space is a valid proxy for human-judged semantic similarity and task difficulty.

### Mechanism 3
Stable and interpretable cross-model rankings can be achieved with very few test instances (as few as 250). By bootstrapping random subsets of the full test set, the correlation between SemBench and WiC rankings is computed for each subset size. The point at which the correlation curve stabilizes indicates the minimum number of instances needed for reliable ranking. The underlying semantic competence signal is strong and consistent enough that a small, randomly sampled subset of sense pairs can capture the relative ordering of diverse models.

## Architecture Onboarding

**Component map:**
Dictionary (definitions/examples) -> Sentence Encoder (EmbeddingGemma 300M) -> Test Instance Sampler (polysemous word, target/distractor senses) -> LLM (Under Evaluation) -> Scorer (similarity comparison) -> Accuracy/Rankings

**Critical path:**
Sample (w, s_i, s_j) -> Prompt LLM with (d_i, PoS) -> Get LLM output o' (e' or d') -> Encode o' and d_i, d_j -> Compute sim(o', d_i) and sim(o', d_j) -> Update correctness count -> Repeat

**Design tradeoffs:**
- Encoder Choice: Using a single, general-purpose encoder (EmbeddingGemma) simplifies deployment but may introduce bias. An ensemble could be more robust but increases compute.
- Generation vs. Discrimination: SemBenchDef (generate example then definition) is harder but potentially more discriminative; SemBenchEx (generate definition directly) is simpler and more stable (lower variance in results).
- Manual Effort: SemBenchDef requires no examples in the dictionary but needs 5-shot examples for the LLM prompt if used. SemBenchEx requires dictionary examples but needs fewer LLM few-shot exemplars.

**Failure signatures:**
- Low correlation with WiC (ρ < 0.6): The generated benchmark is not measuring the same construct as WiC. Likely causes: poor dictionary quality, inappropriate encoder for the language, or LLM prompt failure.
- No difficulty trend (easy ≈ hard): The distractor selection heuristic is无效; the encoder does not encode sense similarity usefully.
- High variance across bootstrap samples: Too few test instances or the LLM's generations are too stochastic.
- Absolute scores near random (50%): Could indicate the LLM lacks basic semantic competence in that language, or the dictionary definitions are too ambiguous/noisy.

**First 3 experiments:**
1. Validation against English WiC: Run SemBenchDef and SemBenchEx with 5-shot on all models (1,000 rand instances). Compute Spearman's ρ between resulting accuracies and standard WiC accuracies. Expected: ρ > 0.9.
2. Multilingual Generalization: Repeat step 1 for Spanish (SemBenchDef only) and Basque (SemBenchDef). Expected: ρ remains positive and significant (<0.05), though lower for Basque (~0.65).
3. Data Efficiency Analysis: For each variant/difficulty, perform bootstrapping (100 iterations) on random subsets of sizes 50, 250, 500, 750, 1000. Plot correlation ρ vs. subset size. Expected: Curve plateaus by ~500 instances; 250 is sufficient for stable ranking.

## Open Questions the Paper Calls Out

**Open Question 1:** How does the choice of sentence encoder influence the stability and validity of SemBench's model rankings?
Basis: The limitations state that reliance on a single encoder (EmbeddingGemma 300M) may introduce biases and fail to distinguish subtle senses.
Why unresolved: Experiments used only one encoder; no ablation or comparison with alternatives was conducted to assess encoder sensitivity.
What evidence would resolve it: Systematically evaluate SemBench rankings using a diverse set of encoders and measure correlation consistency with WiC across languages and difficulty levels.

**Open Question 2:** Do commercial, closed-source LLMs (e.g., GPT-4, Claude) maintain the same ranking patterns on SemBench as open-weight models?
Basis: The limitations explicitly note the omission of commercial LLMs and suggest their inclusion to assess if SemBench ranks state-of-the-art models effectively.
Why unresolved: The study evaluated only open-weight models; commercial model performance and relative ordering remain unknown.
What evidence would resolve it: Run SemBench on a suite of leading commercial LLMs and compare the resulting rankings against those from open-weight models and WiC benchmarks.

**Open Question 3:** Is the semantic competence measured by SemBench aligned with broader, holistic assessments of model quality (e.g., LLM Arena)?
Basis: The limitations propose comparing SemBench with general evaluation efforts like LLM Arena to check alignment with perceived model quality.
Why unresolved: No correlation analysis between SemBench scores and crowdsourced or aggregate preference-based rankings was performed.
What evidence would resolve it: Correlate SemBench scores (across multiple languages/difficulties) with LLM Arena or similar aggregate leaderboard rankings for overlapping models.

## Limitations

- Reliability may be compromised for very low-resource languages due to dictionary quality and sentence encoder suitability
- Reliance on a single sentence encoder may introduce biases and fail to distinguish subtle sense differences
- The framework assumes dictionary definitions are universally accessible and suitable, without accounting for variations in quality or granularity across languages

## Confidence

- **High**: English results with ρ > 0.93, demonstrating strong correlation and stable rankings
- **Medium**: Spanish results show moderate correlation but may be affected by dictionary quality and encoder bias
- **Low**: Basque results show weaker correlation (ρ ~ 0.66) and low WiC scores suggest potential encoder mismatch rather than true model incompetence

## Next Checks

1. Test the framework with a different multilingual encoder (e.g., mBERT or XLM-R) to verify robustness to encoder choice and assess potential bias in EmbeddingGemma.
2. Conduct a human evaluation on 100 randomly sampled SemBench instances to measure whether generated examples/definitions align with intended senses, directly validating the core mechanism.
3. Replicate the data-efficiency analysis on a synthetic dataset where ground truth model rankings are known, to confirm that correlation plateaus at ~250 instances represent genuine semantic signal rather than noise.
