# From Verbatim to Gist: Distilling Pyramidal Multimodal Memory via Semantic Information Bottleneck for Long-Horizon Video Agents

## Quick Facts
- **arXiv ID:** 2603.01455  
- **Source URL:** https://arxiv.org/abs/2603.01455  
- **Reference count:** 40  
- **Primary result:** MM-Mem achieves state-of-the-art performance on four long-horizon video benchmarks, e.g., 78.1% on Video-MME with subtitles.  

## Executive Summary
This paper introduces MM-Mem, a multimodal memory system designed for long-horizon video understanding in agents. It addresses the trade-off between vision-centric redundancy and text-centric detail loss by employing a pyramidal memory architecture inspired by Fuzzy-Trace Theory, comprising Sensory Buffer, Episodic Stream, and Symbolic Schema layers. Memory construction is guided by a Semantic Information Bottleneck objective optimized via SIB-GRPO, balancing compression and retention. Inference uses entropy-driven top-down retrieval, starting from abstract schemas and drilling down to details when uncertainty is high. Evaluations on Video-MME, MLVU, VStream-QA, and HD-EPIC++ show consistent state-of-the-art improvements.

## Method Summary
MM-Mem processes long videos by first extracting fine-grained visual traces into a Sensory Buffer based on inter-frame variation and near-duplicate suppression. These are summarized into an Episodic Stream of event-level traces, and further abstracted into a Symbolic Schema knowledge graph of semantic entities and relations. The memory manager is trained with SIB-GRPO, a reinforcement learning algorithm that maximizes a reward combining VQA accuracy, trace length penalty, and KL divergence from a reference policy. During inference, for a given query, the system retrieves from the Symbolic Schema and computes predictive entropy; if entropy exceeds a threshold, it drills down to the Episodic Stream and Sensory Buffer to reduce uncertainty before generating an answer.

## Key Results
- 78.1% accuracy on Video-MME (with subtitles)  
- 77.2 M-Avg on MLVU  
- 62.5% accuracy and 4.1 score on VStream-QA-Ego  
- 30.28% accuracy on HD-EPIC++  

## Why This Works (Mechanism)
The mechanism succeeds through hierarchical distillation and adaptive retrieval. The pyramidal memory compresses information across layers, retaining only task-relevant semantics via the Semantic Information Bottleneck. SIB-GRPO explicitly optimizes this trade-off using task rewards, ensuring memories are concise yet sufficient. Entropy-driven retrieval dynamically accesses lower-level details only when high uncertainty persists, avoiding unnecessary computation and focusing on ambiguous queries. This combination reduces redundancy while preserving critical details for long-horizon reasoning.

## Foundational Learning
- **Fuzzy-Trace Theory**: Provides cognitive basis for dual memory traces (gist vs. verbatim). *Why needed:* Motivates the pyramidal design with semantic abstractions and fine details. *Quick check:* Validate if higher layers capture gist and lower layers store verbatim traces through human evaluation.  
- **Semantic Information Bottleneck**: Information-theoretic framework for compression with relevance. *Why needed:* Formalizes the objective to retain task-relevant semantics during memory distillation. *Quick check:* Plot mutual information between memory and query labels against memory size during training.  
- **SIB-GRPO**: Reinforcement learning algorithm (Group Relative Policy Optimization) with semantic bottleneck rewards. *Why needed:* Learns optimal memory construction from downstream task feedback. *Quick check:* Monitor reward components (accuracy, length, KL) to ensure stable optimization.  
- **Hierarchical Memory**: Pyramidal organization from fine to coarse representations. *Why needed:* Enables efficient scaling to long videos by avoiding flat memory explosions. *Quick check:* Compare memory size and retrieval latency against flat memory baselines.  
- **Entropy-driven Retrieval**: Using predictive entropy to trigger deeper memory access. *Why needed:* Minimizes irrelevant detail fetching and adapts to query difficulty. *Quick check:* Correlate entropy levels with accuracy gains from including lower-layer information.  
- **Multimodal Video Understanding**: Integration of visual and linguistic signals over extended sequences. *Why needed:* Defines the application domain requiring long-term context. *Quick check:* Benchmark on diverse long-video QA datasets to assess generalization.  

## Architecture Onboarding
- **Component map**: Sensory Buffer (fine-grained visual traces) → Episodic Stream (event summaries) → Symbolic Schema (semantic abstractions); SIB-GRPO optimizes memory construction; Entropy-driven retrieval accesses layers top-down.  
- **Critical path**: Video input → Memory construction (SIB-GRPO training) → Stored pyramid → Query → Entropy assessment → Layer-wise retrieval (Schema → Stream → Buffer) → Answer generation.  
- **Design tradeoffs**: Compression vs. retention (tuned via SIB-GRPO hyperparameters), computational cost vs. performance (hierarchy adds overhead but improves accuracy), semantic abstraction vs. detail loss (risk of over-generalization in Schema).  
- **Failure signatures**: Persistent high entropy after retrieval (retrieval ineffective), long episodic traces (compression failing), low coverage of query entities in Schema nodes (abstraction too aggressive).  
- **Exactly 3 first experiments**:  
  1. Replicate MM-Mem on HD-EPIC++ train split to validate the full memory construction pipeline and baseline performance.  
  2. Ablate β₁ (length penalty) and β₂ (KL penalty) in SIB-GRPO reward on HD-EPIC++ to quantify their individual impact on compression-retention balance.  
  3. Sweep entropy threshold γ ∈ {0.5, 0.6, 0.7, 0.8} on MLVU long videos, measuring retrieval depth and accuracy to test robustness of top-down triggering.  

## Open Questions the Paper Calls Out
- How can the computational cost of hierarchical memory construction be reduced to enable deployment on resource-constrained edge devices?  
- How can MM-Mem be adapted to utilize stronger, end-to-end trained perception backbones to improve robustness against visual artifacts?  
- Can the SIB-GRPO memory manager be extended to unsupervised or self-supervised settings, enabling lifelong learning without explicit task signals?  
- How can MM-Mem be extended to support dynamic memory updating and forgetting mechanisms for continuous, multi-session interactions in open-ended environments?  

## Limitations
- Symbolic Schema knowledge graph construction and LVLM extractor details are unspecified, risking reproducibility.  
- SIB-GRPO implementation (group sampling, KL computation) is closed-source, making reward tuning opaque.  
- Entropy threshold (γ=0.72) and retrieval weights lack cross-validation, potentially harming generalizability across video types.  

## Confidence
- Architecture novelty (pyramidal memory): Medium  
- SIB-GRPO training efficacy: Low  
- Entropy-driven retrieval robustness: Low  

## Next Checks
