# SCISSR: Scribble-Conditioned Interactive Surgical Segmentation and Refinement
## Quick Facts
- **arXiv ID:** 2603.18544
- **Source URL:** https://arxiv.org/abs/2603.18544
- **Reference count:** 30
- **Primary result:** Achieves 95.41% Dice on EndoVis 2018 and 96.30% Dice on CholecSeg8k with scribble prompts, outperforming point-based methods.

## Executive Summary
Annotating surgical scene segmentation is challenging due to irregular shapes, thin structures, and occlusions, making traditional point or box prompts inefficient. SCISSR introduces a scribble-promptable framework built upon SAM 2, adding a lightweight Scribble Encoder to convert freehand strokes into dense prompt embeddings and employing a dual-track architecture. All accumulated scribbles guide the mask decoder, while the latest correction updates memory attention via Spatial Gated Fusion. Only the new components are trained, keeping the backbone frozen.  

On EndoVis 2018, SCISSR reaches 95.41% Dice after five refinement rounds, and on the out-of-distribution CholecSeg8k dataset, 96.30% Dice after three rounds. It converges faster and achieves higher success rates than iterative point prompting, demonstrating the effectiveness of scribble-based interaction for surgical annotation.

## Method Summary
SCISSR extends SAM 2 by introducing a Scribble Encoder that processes freehand strokes into dense prompt embeddings. The framework uses a dual-track mechanism: all scribbles collected so far are aggregated to condition the mask decoder, providing stable spatial guidance, while the most recent correction is injected into memory attention through a Spatial Gated Fusion module. This fusion selectively modulates memory features to incorporate new information without discarding historical context. Only the Scribble Encoder, the mask decoder, and the fusion module are trained; the SAM 2 backbone remains frozen, preserving pretrained representations and minimizing additional parameters. The design supports iterative refinement, where each round’s output updates the memory bank for subsequent interactions.

## Key Results
- 95.41% Dice on EndoVis 2018 after five scribble refinement rounds.
- 96.30% Dice on CholecSeg8k after three rounds.
- Faster convergence and higher success rates compared to iterative point prompting.

## Why This Works (Mechanism)
Scribble prompts provide dense spatial cues that more fully capture the target region than sparse points, reducing ambiguity for the mask decoder. The Scribble Encoder translates these strokes into embeddings aligned with SAM 2’s feature space. The dual-track architecture separates the roles of accumulated scribbles and the latest correction: accumulated scribbles give a consistent signal to the mask decoder, while the Spatial Gated Fusion updates the memory-attended features with the newest information, allowing the model to refine details without losing earlier context. Keeping the backbone frozen retains the robust visual features learned from large-scale pretraining, and the lightweight additions enable rapid adaptation to the surgical domain with minimal computational overhead.

## Foundational Learning
- **SAM 2:** A promptable segmentation model providing image encoding and mask generation; SCISSR freezes its parameters and adds new modules.  
  *Quick check:* Backbone remains untrained; only new components learn.
- **Scribble Prompting:** Uses freehand strokes as dense interactive input, ideal for complex shapes.  
  *Quick check:** Scribbles cover regions rather than discrete points.
- **Interactive Segmentation:** Iterative refinement where user feedback improves masks over rounds.  
  *Quick check:* SCISSR supports multiple correction cycles with accumulating scribbles.
- **Memory Attention:** Maintains a memory bank of previous predictions to incorporate temporal context.  
  *Quick check:* SAM 2’s memory is updated each round to inform the next.
- **Dual-Track Processing:** Two parallel streams for stable guidance (all scribbles) and dynamic update (latest correction).  
  *Quick check:* Mask decoder sees all scribbles; memory attention sees the latest via fusion.
- **Spatial Gated Fusion:** Modulates memory features using the latest scribble embedding to control update magnitude.  
  *Quick check:* Fusion gates prevent overwriting historical context too aggressively.

## Architecture Onboarding
**Component map:**  
- Image → SAM2 Image Encoder → Image Features  
- Accumulated Scribbles → Scribble Encoder → Scribble Embeddings  
- Image Features + Memory Bank → Memory Attention → Memory-aware Features  
- Latest Scribble → Spatial Gated Fusion → Fused Features (modulated with Memory-aware Features)  
- Scribble Embeddings + Fused Features → SAM2 Mask Decoder → Segmentation Mask  
- Mask → Memory Bank Update  

**Critical path:** For each refinement round: (1) Encode image with frozen SAM2; (2) Encode all scribbles so far; (3) Apply memory attention to image features using the memory bank; (4) Fuse the latest scribble with the memory-aware features; (5) Generate mask using accumulated scribble embeddings and fused features; (6) Update memory bank with the new mask.

**Design tradeoffs:**  
- *Frozen backbone* preserves pretrained knowledge and reduces training cost but limits domain-specific adaptation.  
- *Lightweight additions* keep the model small and fast but may constrain representational capacity.  
- *Dual-track* balances stability (accumulated scribbles) and responsiveness (latest correction), but improper weighting could cause overfitting to early errors or instability.  
- *Scribble prompts* offer dense guidance but require more user effort than points.

**Failure signatures:**  
- Poor performance on thin or highly occluded structures when scribbles are sparse.  
- Memory drift: inaccurate masks propagate and degrade future predictions.  
- Model ignores later corrections if spatial gated fusion fails to modulate effectively.  
- Reduced generalization on out-of-distribution scenes due to frozen backbone.

**First experiments:**  
1. **End-to-end scribble refinement:** On a single test image, provide an initial scribble and iterate for five rounds, plotting Dice per round.  
2. **Ablate Scribble Encoder:** Replace with random embeddings or remove it; compare to full model to quantify its contribution.  
3. **Memory attention with/without fusion:** Disable Spatial Gated Fusion and observe convergence speed and stability relative to the full system.

## Open Questions the Paper Calls Out
### 1. Video-level annotation extension
- **Question:** How can SCISSR be extended to video-level surgical annotation to leverage temporal consistency across frames?  
- **Basis in paper:** The conclusion states: "Future work will extend SCISSR to video-level annotation."  
- **Why unresolved:** The current framework processes each frame independently using a memory bank designed for single-image iterative refinement, without explicit modeling of inter-frame dependencies.  
- **What evidence would resolve it:** A video adaptation that modifies the memory bank to propagate features across time and evaluates on surgical video datasets with frame-wise annotations.

### 2. Human annotator scribble patterns
- **Question:** How do human annotators' scribble drawing patterns and annotation efficiency compare to the synthetic scribbles used in training?  
- **Basis in paper:** The conclusion states: "Future work will... validate usability with human annotators."  
- **Why unresolved:** The adaptive scribble generator creates synthetic corrections based on geometric cues, but real human scribbles may differ in stroke order, density, and error localization strategies.  
- **What evidence would resolve it:** A user study where annotators refine masks with SCISSR using real scribbles, measuring time, number of rounds, and agreement with ground truth versus synthetic-scribble runs.

### 3. Transferability to SAM 3
- **Question:** Does the architecture-agnostic design of SCISSR successfully transfer to SAM 3 or other prompt-driven segmentation backbones without performance degradation?  
- **Basis in paper:** The abstract claims: "the framework is not tied to a single model... the same components transfer to other prompt-driven segmentation architectures such as SAM 3 without structural modification," but experiments are only conducted on SAM 2.  
- **Why unresolved:** Transferability is asserted but not validated; differences in SAM 3's architecture (e.g., concept-based prompts) may require adaptation of the Scribble Encoder or fusion modules.  
- **What evidence would resolve it:** Implement SCISSR's added modules on SAM 3 with identical training and evaluate on EndoVis 2018 and CholecSeg8k, comparing performance to the SAM 2-based model.

### 4. Point vs scribble failure modes
- **Question:** What mechanisms cause point-based prompting to degrade with increased click rounds, while scribble prompting consistently improves?  
- **Basis in paper:** Table 1 and Fig. 6 show point-based methods (SAM2/3 with 1pt/CC and 10pt/ch) often perform worse at R4 than R2, whereas scribble methods improve monotonically; the paper attributes this to "structured spatial layout" but does not analyze the underlying reasons.  
- **Why unresolved:** The paper notes that increased point density (Table 17) actually harms performance beyond 10 points, suggesting point prompts cannot exploit dense spatial signals, but the precise failure mode (e.g., attention confusion, overfitting to sparse cues) is not investigated.  
- **What evidence would resolve it:** Ablation studies analyzing attention maps or feature representations in SAM's mask decoder when conditioned on point streaks versus scribbles, or controlled experiments varying spatial coherence of prompts.

## Limitations
- Evaluation restricted to two datasets; claims of generalization lack broader evidence.
- No statistical significance testing or variance estimates for reported Dice scores.
- Absence of ablation studies to validate the role of each proposed component (Scribble Encoder, dual‑track, Spatial Gated Fusion).
