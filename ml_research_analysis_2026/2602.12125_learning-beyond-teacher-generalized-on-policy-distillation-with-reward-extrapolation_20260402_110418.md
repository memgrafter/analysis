# Learning beyond Teacher: Generalized On-Policy Distillation with Reward Extrapolation

## Quick Facts
- arXiv ID: 2602.12125
- Source URL: https://arxiv.org/abs/2602.12125
- Reference count: 12
- Primary result: G‑OPD with reward extrapolation (λ>1) outperforms standard OPD and domain teachers, yielding +1.7% math and +0.8% code gains, plus an additional +2.3% math improvement when using the teacher’s pre‑RL checkpoint.

## Executive Summary
Standard on‑policy distillation (OPD) learns a student policy by interacting with the environment while regularizing toward a teacher. This work proposes Generalized On‑Policy Distillation (G‑OPD), which augments the OPD objective with a reward‑scaling factor λ and a flexible reference policy. The resulting method, ExOPD (λ>1), amplifies the implicit reward signal to encourage the student to surpass the teacher’s performance. Evaluated on four math (AIME24/25, HMMT25) and three code (HumanEval+, MBPP+, LiveCodeBench) benchmarks, ExOPD consistently improves over standard OPD. In multi‑teacher distillation, it merges domain‑specific experts into a single student that exceeds all teachers, with average gains of +1.7% (math) and +0.8% (code). In strong‑to‑weak distillation, setting the reference to the teacher’s pre‑RL checkpoint further boosts performance, adding +2.3% on math reasoning over standard OPD. These results demonstrate that simple modifications to the distillation objective can yield significant gains across diverse tasks.

## Method Summary
Generalized On‑Policy Distillation (G‑OPD) enhances the standard OPD objective by scaling the teacher’s implicit reward by a factor λ and replacing the fixed teacher policy with a flexible reference policy for KL regularization. The instantiation ExOPD uses λ>1 to amplify the reward signal, pushing the student to seek higher returns than the teacher. The student collects on‑policy trajectories in the environment; the loss combines a scaled reward (λ × teacher-provided reward) and the KL divergence between the student and a chosen reference policy. In strong‑to‑weak distillation, the reference is set to the teacher’s pre‑RL checkpoint, providing a stable prior that still allows improvement. This design supports effective distillation even when the student is much smaller or when merging multiple domain-specific teachers.

## Key Results
- ExOPD (λ>1) consistently outperforms standard OPD (λ=1) across diverse teacher‑student size pairings.
- Multi‑teacher distillation with ExOPD yields a unified student exceeding all domain teachers, with average gains of +1.7% (math) and +0.8% (code).
- In strong‑to‑weak distillation, incorporating the teacher’s pre‑RL checkpoint as reference gives an extra +2.3% improvement on math reasoning over standard OPD.

## Why This Works (Mechanism)
Reward extrapolation works because scaling the implicit reward by λ>1 magnifies the learning signal, pushing the student to seek states with higher returns than the teacher. This compensates for the teacher’s potential suboptimality. The KL divergence to a reference policy acts as a regularizer that prevents the student from straying into implausible regions of the policy space, especially important when λ is large. The reference policy can be chosen, for example, as the teacher before RL fine‑tuning (the “pre‑RL checkpoint”), which encodes a good prior while allowing improvement. Together, these modifications enable effective distillation even when the student is much smaller or when merging multiple teachers.

## Foundational Learning
1. **On‑Policy Distillation (OPD)**  
   *Why needed*: Reduces distribution shift by letting the student collect its own data while staying close to the teacher.  
   *Quick check*: KL loss between student and teacher should decrease or remain bounded.

2. **Reward Scaling (λ)**  
   *Why needed*: Amplifies the learning signal to overcome teacher suboptimality.  
   *Quick check*: Gradient norms should increase with λ, indicating stronger updates.

3. **Reference Policy**  
   *Why needed*: Provides a stable prior for KL regularization; using the teacher’s pre‑RL checkpoint avoids over‑constraining to a possibly shifted RL policy.  
   *Quick check*: Reference policy should achieve non‑trivial performance on the task.

4. **KL Divergence Regularization**  
   *Why needed*: Prevents policy collapse when reward is scaled.  
   *Quick check*: KL loss should remain within a moderate range, not explode.

5. **Multi‑Teacher Distillation**  
   *Why needed*: Combines complementary strengths of domain experts into a single versatile student.  
   *Quick check*: Merged student should outperform each individual teacher on their respective domains on average.

## Architecture Onboarding
Component map:
Student Policy → Environment → Trajectories → Scaled Implicit Reward (λ × reward from Teacher) → Loss = scaled reward + KL(Student vs Reference) → Update Student

Critical path:
1. Student collects on‑policy data from the environment.
2. Teacher (or its value) provides an implicit reward for each transition.
3. The reward is scaled by λ.
4. KL divergence between the student policy and the reference policy is computed.
5. The combined loss is back‑propagated to update the student.

Design tradeoffs:
- λ: Larger values amplify the learning signal but can cause instability; careful tuning per task is required.
- Reference policy: A pre‑RL checkpoint offers a good balance between prior quality and flexibility; a post‑RL teacher may overly restrict improvement.
- KL weight: Fixed at 1 in this work; tuning could further improve stability‑performance trade‑offs.

Failure signatures:
- Sudden performance collapse when λ exceeds a task‑specific threshold.
- Slow convergence or plateau if the reference policy is too far from optimal (e.g., random initialization).
- Over‑regularization if KL loss dominates total loss, stifling improvement.

First experiments:
1. Reproduce standard OPD (λ=1) to validate baseline implementation.
2. Sweep λ across {0.5, 1.0, 1.5, 2.0} on a single task (e.g., a math reasoning benchmark) to identify the beneficial regime.
3. Compare reference policies: teacher pre‑RL, teacher post‑RL, and a random policy to test the reward correction hypothesis.

## Limitations
- Theoretical justification for reward scaling (λ>1) and the precise role of the reference model (e.g., pre‑RL checkpoint) lack detailed ablation or mechanistic explanation.
- Claims are restricted to specific math/code benchmarks; generalizability to other domains (e.g., vision, robotics) or non‑rationale tasks is unknown.

## Confidence
- Empirical performance gains: High
- Methodological soundness of G‑OPD’s modified objective: Medium
- Broad applicability beyond LLM reasoning: Low

## Next Checks
1. Ablate λ sensitivity: Vary λ from 0.5 to 2.0 across teacher‑student size gaps to identify optimal scaling regimes and failure thresholds.
2. Cross‑domain validation: Test ExOPD on non‑reasoning tasks (e.g., vision classification, robotic control) using standard RL benchmarks (DMControl, ProcGen) to assess generalization.
3. Baseline comparisons: Replicate experiments against offline KD, offline RL, and recent OPD variants (e.g., X‑OPD) to isolate the contribution of reward extrapolation.
