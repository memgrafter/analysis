# Ego2Web: A Web Agent Benchmark Grounded in Egocentric Videos

## Quick Facts
- arXiv ID: 2603.22529
- Source URL: https://arxiv.org/abs/2603.22529
- Reference count: 40
- Primary result: Ego2Web introduces the first benchmark linking egocentric video perception to web-agent execution; state-of-the-art agents achieve at most 58.6% success under human evaluation, and raw video input is critical (48.2% SR vs 23.6% with captions).

## Executive Summary
Ego2Web fills a crucial gap in web‑agent benchmarks by connecting egocentric video understanding with web task execution. The authors construct a dataset of 500 video‑task pairs across 18 websites (e.g., Amazon, YouTube) using a semi‑automatic pipeline: an MLLM generates clip captions, an LLM creates instructions, and humans verify feasibility and grounding. They also propose Ego2WebJudge, an automatic evaluator based on an MLLM that agrees with human judgment at ~84%. Experiments reveal that existing state‑of‑the‑art agents struggle, with success rates between 17.8% and 58.6%, and a performance gap of ~40% compared to an oracle. Ablations confirm that raw video input is essential for high performance, underscoring the need for accurate visual grounding in real‑world multimodal agents.

## Method Summary
Benchmark construction proceeds via three stages. First, 5‑second clips from Ego4D’s EgoSchema are captioned using Qwen3‑VL. Second, GPT‑5 generates a web instruction for each caption, ensuring the task can be completed on an active website. Third, human annotators verify that the instruction is correctly grounded in the video, is feasible on the website, and is clearly formulated. The final dataset contains 500 high‑quality pairs spanning e‑commerce, media retrieval, and other domains. For evaluation, agents receive either the raw video or the generated caption plus the instruction, then interact with the website (via Browser‑Use) and produce a trajectory of actions and screenshots. Ego2WebJudge consumes the instruction, the video clip (or its temporal annotation), the action history, and key screenshots; it first extracts key points, selects relevant screenshots, and finally emits a binary success decision.

## Key Results
- State‑of‑the‑art web agents attain success rates between 17.8% and 58.6% under human evaluation, with a ~40% gap to oracle performance.
- Ego2WebJudge achieves ~84% agreement with human judgment, substantially outperforming prior automatic judges.
- Ablation shows raw video input yields 48.2% SR while caption‑only drops to 23.6%, highlighting the importance of accurate visual grounding.

## Why This Works (Mechanism)
Ego2Web works because it forces agents to reason about both the physical world (via egocentric video) and the digital web interface. The video provides contextual cues (e.g., which object the user is holding, their spatial location) that are indispensable for disambiguating web tasks such as “buy the snack I just looked at.” The semi‑automatic pipeline ensures tasks are both realistic and executable, while the human verification step guarantees high quality. The evaluator, Ego2WebJudge, leverages an MLLM to cross‑reference the agent’s actions against the original video, mimicking human assessment of whether the intended goal was achieved. This combination creates a challenging yet reliable benchmark that pushes multimodal agents toward real‑world applicability.

## Foundational Learning
- **Egocentric video perception** – Understanding first‑person visual streams is needed to ground web tasks in the user’s surroundings.  
  *Quick check*: Can the model identify objects, actions, and temporal events from the video?
- **Multimodal LLMs (MLLMs)** – Enable simultaneous processing of images, video, and text; critical for captioning, instruction generation, and automatic evaluation.  
  *Quick check*: Does the MLLM produce accurate, detailed descriptions and consistent judgments?
- **Web automation** – Agents must navigate dynamic websites, fill forms, and retrieve information; this requires robust interaction with HTML/DOM.  
  *Quick check*: Can the agent complete a simple navigation task (e.g., search on Wikipedia) without errors?
- **Semi‑automatic dataset construction** – Balances scalability with quality; automatic generation followed by human verification ensures feasibility and correctness.  
  *Quick check*: Are a random sample of generated tasks executable by a human and properly anchored in the video?
- **Automatic evaluation with Ego2WebJudge** – Provides a scalable proxy for human assessment; must align closely with human intuition.  
  *Quick check*: Does the judge’s binary decision match human evaluation on a diverse subset?

## Architecture Onboarding
Component map:

Video source (Ego4D) -> Qwen3‑VL (caption) -> GPT‑5 (instruction) -> Human verification -> Ego2Web dataset.  
Evaluation flow: Instruction + Video/Caption -> Agent (action execution with Browser‑Use) -> Action trajectory + screenshots -> Ego2WebJudge (MLLM) -> Success label.

Critical path: Dataset creation follows video → caption → instruction → verification; evaluation follows instruction/video → agent run → screenshots → judge.

Design tradeoffs:  
- Quality vs. scalability: limiting to 500 tasks allows thorough human verification but reduces coverage.  
- Proprietary model reliance: using GPT‑5, Gemini‑3‑Flash ensures high performance but introduces access and cost barriers.  
- Raw video vs. captions: raw video offers better grounding but increases computational load and may challenge some agents.

Failure signatures:  
- Temporal misidentification: agent picks the wrong object instance from the video (e.g., a later snack instead of the intended one).  
- Incomplete cross‑modal retrieval: agent finds the object on the website but fails to extract the required attribute (price, calories).  
- Judge–human disagreement: evaluator misinterprets subtle video context or overlooks agent progress.

First experiments:  
1. Run the generation pipeline on 5 sample clips to verify end‑to‑end output quality (captions, instructions).  
2. Execute a baseline agent (e.g., random clicks or a simple script) on 3 tasks to confirm the execution environment and logging setup.  
3. Compare Ego2WebJudge to human evaluation on 20 randomly selected tasks to measure agreement and identify systematic failure modes.

## Limitations
- **Data accessibility**: Egocentric videos from Ego4D require a signed license; exact clips may not be publicly redistributable, preventing full local replication.
- **Proprietary model dependencies**: The pipeline and evaluator rely on models like GPT‑5 and Gemini‑3‑Flash with limited/unclear public access, obstructing faithful recreation.
- **Scope constraints**: 500 clips from EgoSchema may not capture the full diversity of real‑world egocentric contexts or all 18 website domains, risking overfitting or limited generalization.

## Confidence
- Benchmark creation (500 video‑task pairs): Low  
- Ego2WebJudge agreement (~84% with human): Medium  
- Agent success rates (17.8–58.6%): Low  
- Ablation (raw video vs. captions critical): Medium
