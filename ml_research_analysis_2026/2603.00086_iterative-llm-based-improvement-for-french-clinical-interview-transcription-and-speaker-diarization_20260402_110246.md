# Iterative LLM-based improvement for French Clinical Interview Transcription and Speaker Diarization

## Quick Facts
- arXiv ID: 2603.00086
- Source URL: https://arxiv.org/abs/2603.00086
- Reference count: 0
- Primary result: 6.8% relative reduction in Word Diarization Error Rate (WDER) on suicide prevention telephone counseling (p<0.05, n=18) with zero failures and real-time factor 0.32.

## Executive Summary
High Word Diarization Error Rate (WDER) in French clinical ASR degrades both transcription and speaker attribution. This study introduces an iterative LLM post‑processing architecture using Qwen3‑Next‑80B in a zero‑shot, multi‑pass scheme that alternates speaker‑role (SR) and word‑recognition (WR) refinement. On suicide prevention calls, the optimal three‑pass SR‑led configuration achieved a statistically significant 6.8% relative WDER reduction (n=18, p<0.05). The same pattern remained stable on awake neurosurgery consultations (n=10). The system produced no output format failures and operated at a real‑time factor of 0.32, indicating feasibility for offline clinical use.

## Method Summary
Inputs come from WhisperX large‑v3 (ASR text with timestamps) and Pyannote 3.1 (speaker labels), merged into a segment list. For long recordings, segments are chunked (≤500 per chunk). Each chunk undergoes a three‑pass SR‑led loop: Pass 1 applies an SR prompt to map speakers to clinical roles; Pass 2 applies a WR prompt to correct lexical errors and anonymize; Pass 3 reapplies the SR prompt for refinement. Prompts are domain‑adapted (suicide prevention vs. neurosurgery) and enforce strict segment formatting. No training is performed; Qwen3‑Next‑80B is used in zero‑shot mode with 4‑bit AWQ quantization. The final concatenated output yields the improved transcription and diarization.

## Key Results
- 6.8% relative WDER reduction on the suicide prevention dataset (n=18, p<0.05).
- Zero output format failures and real‑time factor of 0.32 with the three‑pass SR‑led configuration.
- Performance remained stable on the awake neurosurgery dataset (n=10).

## Why This Works (Mechanism)
The iterative process leverages complementary error patterns: speaker‑role errors often correlate with lexical mistakes (e.g., domain jargon, homophones). An SR‑first pass establishes a consistent speaker structure, guiding WR correction in Pass 2; a final SR pass then polishes diarization using the refined text. Domain‑adapted prompts steer the LLM toward context‑specific patterns (crisis hotline vs. neurosurgery), while zero‑shot operation taps the model’s broad linguistic knowledge without overfitting. The alternation amplifies mutual correction between the two error types, yielding net WDER improvement.

## Foundational Learning
- **Word Diarization Error Rate (WDER)**: Composite metric combining ASR errors and speaker attribution failures. *Why needed*: Measures end‑to‑end clinical utility where misattributed speech is harmful. *Quick check*: Align system output with reference; compute (misassigned words + ASR errors) / total reference words.
- **Speaker Diarization**: Partitioning audio by speaker identity. *Why needed*: Critical for distinguishing clinician vs. patient in interviews. *Quick check*: Use Pyannote to generate speaker labels and timestamps; evaluate with DER.
- **LLM‑based ASR post‑processing**: Using large language models to correct transcripts via prompting. *Why needed*: Captures long‑range dependencies and domain patterns missed by ASR. *Quick check*: Prompt an LLM with ASR segments and context; measure word error reduction.
- **Zero‑shot prompting**: Task instructions without gradient updates. *Why needed*: Enables rapid adaptation to new domains (e.g., French clinical). *Quick check*: Design prompts specifying format and corrections; verify output adherence.
- **Chunking for long contexts**: Splitting long segment sequences into model‑sized batches. *Why needed*: Avoids exceeding context length; manages GPU memory. *Quick check*: Test chunk sizes (e.g., 500 segments) and monitor continuity across boundaries.
- **Domain‑adapted prompts**: Tailoring prompts to a specific conversational style (e.g., crisis hotline). *Why needed*: Focuses LLM on relevant error patterns (e.g., suicidal language). *Quick check*: Compare domain‑specific vs. generic prompts on a validation set.

## Architecture Onboarding
Component map: WhisperX large‑v3 → Pyannote 3.1 → Segmentation & Chunking → LLM Passes (SR → WR → SR) → Final Output.  
Critical path: The iterative three‑pass loop; each pass consumes the previous pass’s segment list and outputs a corrected version.  
Design tradeoffs:  
- Pass count vs. accuracy/RTF: More passes improve WDER but increase cost nonlinearly; 3 passes found optimal.  
- SR‑led vs. WR‑led order: SR first establishes speaker scaffolding, enabling more effective text correction later.  
- Domain‑specific prompts: Yield gains but require domain data for design; generic prompts may underperform.  
Failure signatures:  
- Unparseable LLM output: free‑form text, merged segments, missing timestamps. Detect with a strict parser; count as format errors.  
- No WDER improvement on new domains: indicates overfitting to the two studied conversational patterns.  
- Excessive RTF (>1): hampers offline batch processing; may necessitate fewer passes or larger chunks.  
First three experiments:  
1. Baseline: Run WhisperX + Pyannote, compute WDER.  
2. Single‑pass: Apply only Pass 1 (SR) or Pass 2 (WR) to isolate individual contributions.  
3. Optimal configuration: Implement three‑pass SR‑led loop with domain‑adapted prompts; verify WDER drop and zero failures.

## Limitations
- Results are restricted to two French clinical contexts (suicide hotlines, awake neurosurgery); transfer to other medical domains (e.g., emergency, primary care) is uncertain.  
- Exact domain‑adapted prompts and the WR correction dictionary are not detailed in the paper; they must be retrieved from the GitHub repository, and minor variations could affect outcomes.  
- Baselines rely on an unspecified specialized French WhisperX alignment model and Pyannote 3.1 settings; different upstream choices could shift the measured improvement.

## Confidence
- Primary claim (6.8% WDER reduction, p<0.05): **High**. Supported by statistical testing and a defined pipeline.  
- Secondary claim (stable on neurosurgery, zero failures, RTF=0.32): **Medium**. Validated on n=10; long‑term robustness across varying call qualities not addressed.  
- Generalization to offline clinical deployment: **Low**. Feasibility shown only on the two studied datasets; operational constraints (privacy, workflow integration) unevaluated.
