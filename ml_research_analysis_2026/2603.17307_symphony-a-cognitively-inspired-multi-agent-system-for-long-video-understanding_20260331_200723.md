# Symphony: A Cognitively-Inspired Multi-Agent System for Long-Video Understanding

## Quick Facts
- **arXiv ID**: 2603.17307  
- **Source URL**: https://arxiv.org/abs/2603.17307  
- **Reference count**: 40  
- **Primary result**: Symphony achieves state-of-the-art performance on four long-video understanding benchmarks (up to 81.0% on MLVU) with a 5.0% absolute improvement on LVBench and reduces inference cost by 41.8% versus an OpenAI o3 baseline.

## Executive Summary
Long-form video understanding (LVU) is challenged by high information density and extended duration, causing existing multi-modal large language model (MLLM) agents to struggle with complex, long-chain reasoning and precise grounding. Symphony addresses this with a cognitively-inspired multi-agent system that decomposes LVU into specialized, functionally decoupled agents. A planning agent orchestrates fine-grained subtasks; a grounding agent uses LLM query decomposition and VLM-based relevance scoring to localize relevant video segments; subtitle and visual perception agents handle modality-specific analysis; and a reflection agent validates reasoning chains iteratively. This dynamic collaboration reduces individual cognitive load and expands solution space exploration.

Symphony attains state-of-the-art results on four LVU benchmarks: LVBench (71.8%), LongVideoBench (77.1%), VideoMME (78.1%), and MLVU (81.0%). It outperforms prior SOTA by 5.0% absolute on LVBench and cuts inference cost by 41.8% compared to a baseline using OpenAI o3. Ablation studies confirm each component’s contribution, notably a 2.5% gain from the reflection agent.

## Method Summary
Symphony’s core innovation is its functionally decoupled multi-agent architecture. The planning agent takes a high-level question and breaks it into manageable subtasks, assigning responsibilities to other agents. The grounding agent identifies the most relevant video segments by first decomposing the query with an LLM and then scoring frame relevance using a vision-language model (VLM). In parallel, the subtitle agent extracts and interprets spoken content from transcripts, while the visual perception agent analyzes visual cues. The reflection agent then integrates these intermediate results, validates the reasoning chain, and decides whether the answer is sufficient or if iterative refinement is needed. This modular design allows each agent to specialize, reducing cognitive burden and enabling more thorough exploration of potential solutions.

## Key Results
- Achieves SOTA on four LVU benchmarks: LVBench (71.8%), LongVideoBench (77.1%), VideoMME (78.1%), MLVU (81.0%).
- 5.0% absolute improvement over prior SOTA on LVBench.
- 41.8% reduction in inference cost compared to an OpenAI o3 baseline.

## Why This Works (Mechanism)
The cognitive-inspired decomposition distributes complex reasoning across specialized agents, preventing any single agent from being overloaded. Functional decoupling allows each agent to focus on its expertise (e.g., grounding on localization, subtitles on speech), improving accuracy in its domain. Dynamic collaboration—where agents share intermediate results and the reflection agent iteratively validates—expands the solution space by exploring alternative interpretations and correcting errors. The grounding agent’s dual use of LLM query decomposition and VLM relevance scoring ensures precise localization even for ambiguous or multi-hop questions. Ablation results (e.g., a 2.5% drop without reflection) empirically confirm that this synergy drives performance gains.

## Architecture Onboarding
**Component map**:  
Planning → Grounding → (Subtitle, Visual) → Reflection → Output  
(Grounding provides localized segments to Subtitle and Visual; Reflection may loop back for re-evaluation.)

**Critical path**:  
1. Planning decomposes the query into fine-grained subtasks.  
2. Grounding localizes relevant video segments using LLM query decomposition and VLM relevance scoring.  
3. Subtitle agent analyzes transcripts; Visual perception agent processes frames.  
4. Reflection aggregates, validates the reasoning chain; on failure, iterate (usually from step 2 or 3).  
5. Upon successful validation, produce final answer.

**Design tradeoffs**:  
- Decoupling improves specialization and parallelization but adds coordination overhead.  
- Reflection increases inference steps (cost) but boosts accuracy (ablation +2.5%).  
- VLM relevance scoring is computationally heavy but essential for precise grounding.  
- Parallel execution of Subtitle and Visual reduces wall-clock time but requires synchronization before reflection.

**Failure signatures**:  
- Grounding failure: Misalignment between localized segments and query intent; may yield irrelevant information even with high VLM scores.  
- Reflection failure: Inability to detect logical inconsistencies, allowing flawed reasoning to propagate.  
- Planning failure: Incomplete decomposition leading to missing information; indicated by unanswered subquestions.

**First three experiments**:  
1. Ablate the reflection agent and measure accuracy drop across benchmarks to quantify its contribution.  
2. Evaluate grounding on queries of varying ambiguity (clear, ambiguous, multi-hop) to characterize error modes.  
3. Benchmark inference cost/latency across configurations (with/without parallelism, with/without reflection) on long videos.

## Limitations
