# Empirical Cumulative Distribution Function Clustering for LLM-based Agent System Analysis
## Quick Facts
- **arXiv ID:** 2602.16131
- **Source URL:** https://arxiv.org/abs/2602.16131
- **Reference Count:** 40
- **Primary Result:** ECDF-based clustering of LLM agent responses reveals interpretable group structures aligned with question topic difficulty, even when standard accuracy metrics are similar across agent settings (persona/temperature variations).

## Executive Summary
Standard evaluation of LLM agent systems aggregates multiple responses (e.g., via majority vote) into a single accuracy score, losing information about the distribution of individual response qualities. This paper introduces a distributional evaluation framework that uses the empirical cumulative distribution function (ECDF) of cosine similarities between generated responses and reference answers. By clustering these ECDFs with a distance derived from their L1 difference, the method uncovers latent patterns in how different agent configurations perform across questions. Experiments on SQuAD show that settings with similar final accuracy can have distinctly different response quality distributions, and the clustering primarily separates questions by topic difficulty, with persona having minimal impact and high temperature disrupting structure.

## Method Summary
The pipeline begins by embedding all reference and generated answers using a fixed model (e.g., paraphrase-MiniLM-L6-v2). For each agent setting, the maximum cosine similarity between each response and any reference answer is computed, forming a sample of response qualities. An ECDF is constructed from these samples without binning. Pairwise distances between ECDFs are calculated as the L1 distance (area between step functions), which equals the 1D L1-Wasserstein distance. A k-medoids clustering (PAM algorithm) is then applied to this distance matrix to group the ECDFs. Finally, cluster assignments are reordered via multidimensional scaling for visualization, and cluster "wins" are computed to summarize quality distributions.

## Key Results
- ECDFs differentiate agent settings (varying persona/temperature) that have similar majority-vote accuracy but distinct response quality distributions, especially for partially correct answers.
- Clustering with k=16 yields groups primarily aligned with question topics/subjects, indicating topic difficulty as a dominant factor shaping response distributions.
- Persona variations have limited effect on cluster membership, while high temperature settings often form separate, disordered clusters, disrupting the topic-based structure.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** ECDFs of cosine similarities preserve distributional information about individual response quality that is lost when aggregating to a single final answer (e.g., via majority vote).
- **Mechanism:** For each agent setting, the system computes the maximum cosine similarity between each generated response and all reference answers. These similarity scores form a sample set. The ECDF is constructed directly from this set without binning, where `ˆF(x)` is the proportion of responses with similarity ≤ `x`. This yields a complete, parameter-free description of the cumulative distribution of response quality.
- **Core assumption:** Cosine similarity between response and reference embeddings is a valid, continuous proxy for semantic correctness/quality, allowing fine-grained distinctions beyond exact matches.
- **Evidence anchors:**
  - [abstract] "propose a novel evaluation framework based on the empirical cumulative distribution function (ECDF) of cosine similarities... enables a more nuanced assessment of response quality beyond exact match metrics."
  - [section 3.1] Defines `v_ij` as the max cosine similarity for each response and constructs `ˆF_v_i` from list `v_i`. Explicitly states: "there is no need to set any hyperparameters to construct an ECDF."
- **Break condition:** If the embedding model `f_ϕ` fails to capture semantic similarity such that cosine scores do not monotonically correlate with human-judged correctness, the ECDFs become meaningless.

### Mechanism 2
- **Claim:** The L1 distance between two ECDFs, computed as the integral of their absolute difference over the combined support, provides a valid metric for clustering response distribution sets.
- **Mechanism:** For two ECDFs `ˆF_v_i` and `ˆF_v_j`, the distance `D_ij` is the area between their step functions. Since the difference changes only at the combined unique similarity values `˜v_ij`, the integral reduces to a sum over intervals between these sorted points, weighted by interval width (Eq. 5). This metric is equivalent to the L1-Wasserstein distance between the underlying empirical measures.
- **Core assumption:** The shape difference between two cumulative distribution functions, measured by L1, meaningfully captures dissimilarity in the underlying quality distributions of response sets.
- **Evidence anchors:**
  - [section 3.2] Derives Eq. 5 from Eq. 4 and notes: "the L1 distance between the ith and jth ECDFs in Eq. (4) is equal to the L1-Wasserstein distance between probability measures µ_i and µ_j."
- **Break condition:** If response quality distributions often have identical ECDF shapes despite originating from different agent configurations (e.g., different personas/temperatures), the L1 distance fails to discriminate, yielding uninformative clustering.

### Mechanism 3
- **Claim:** Clustering ECDFs via k-medoids on the L1 distance matrix reveals interpretable group structures corresponding to latent factors like question topic difficulty, even when final answer accuracy is similar across settings.
- **Mechanism:** The PAM algorithm (k-medoids) partitions the `n` ECDFs (each corresponding to a specific question × agent setting combination) into `m` clusters. The medoid (most central ECDF) represents a typical distribution for that cluster. Reordering the assignment matrix via MDS highlights patterns across questions and settings.
- **Core assumption:** Agent settings that produce similar distributions of response qualities (ECDFs) for a given question share underlying characteristics—primarily the question's topic difficulty, with persona and temperature having secondary, disruptive effects.
- **Evidence anchors:**
  - [section 4.2] "The clustering (k=16) reveals interpretable groupings primarily aligned with question topic difficulty, with persona having limited effect and high temperature disrupting cluster structure." Figures 5 and 7 visually show cluster assignments strongly organized by subject/topic rows.
- **Break condition:** If cluster assignments are randomly distributed with respect to question topics and agent settings, the method fails to uncover meaningful structure, suggesting the ECDF distance is not capturing relevant factors.

## Foundational Learning
- **Concept: Empirical Cumulative Distribution Function (ECDF)**
  - **Why needed:** Core representation replacing single accuracy metrics. An ECDF is a step function built from raw samples (no binning) that fully describes the cumulative distribution of response qualities.
  - **Quick check:** For response qualities [0.2, 0.5, 0.5, 0.9], what is `ˆF(0.6)`? (Answer: 0.75, since 3 of 4 samples ≤ 0.6). How does this compare to a histogram with bins [0-0.5, 0.5-1.0]? (Histogram loses within-bin order and exact values; ECDF retains all order information.)

- **Concept: L1-Wasserstein distance for 1D distributions**
  - **Why needed:** Defines the pairwise distance used for clustering. It measures the "earth mover's" distance between cumulative distributions, equivalent to the area between ECDF curves.
  - **Quick check:** Given two ECDFs identical except one is shifted right by 0.2, what is their L1 distance? (Answer: 0.2, the shift amount.) This relates to the area between the curves being a rectangle of height 1 and width 0.2.

- **Concept: k-medoids clustering (PAM algorithm)**
  - **Why needed:** Clusters the ECDF objects using the custom distance matrix. Medoids are actual observed ECDFs (not means), ensuring interpretable representatives.
  - **Quick check:** Why k-medoids over k-means for ECDFs? (k-means requires a vector space and means; ECDFs are functions with a custom metric. k-medoids works directly on distances and selects real data points as centers.)

- **Concept: Embedding-based semantic similarity**
  - **Why needed:** Provides the continuous quality proxy (cosine similarity) that transforms text responses into numeric values for ECDF construction.
  - **Quick check:** If two responses are semantically similar but lexically different, a good embedding model should yield a high cosine score. Why might a generic embedding model fail here? (It may not capture task-specific nuances, e.g., medical QA vs. general chit-chat.)

- **Concept: Cluster validation for distributional data**
  - **Why needed:** To assess whether the discovered groupings are meaningful and not arbitrary, especially when using a custom distance metric.
  - **Quick check:** What internal validation metric could be used with L1 distance? (Silhouette score, adapted to use the precomputed distance matrix instead of Euclidean.)

## Architecture Onboarding
- **Component map:**
  Data Preprocessor -> Embedding & Similarity Engine -> ECDF Constructor -> Distance Matrix Calculator -> Cluster Engine (PAM) -> Analysis & Visualizer

- **Critical path:** The pipeline flows linearly from raw logs to clustered results. The Distance Matrix Calculator is the computational bottleneck (O(n²) pairwise ECDF distance computations).

- **Design tradeoffs:**
  - **L1 distance vs. other metrics:** L1 is simple and interpretable for step functions but may overemphasize tail differences. Alternatives like Kolmogorov-Smirnov (sup norm) ignore interval widths.
  - **k-medoids vs. k-means:** k-medoids works on arbitrary distances and yields interpretable medoids but scales worse (O(k(n-k)²) per swap) than k-means for large n.
  - **Embedding model choice:** The fixed model (paraphrase-MiniLM-L6-v2) influences all downstream steps. A domain-specific fine-tuned model might yield more meaningful ECDFs but reduces generalizability.

- **Failure signatures:**
  - Uniform ECDFs across many settings: Responses are identical or embedding model saturates (e.g., all responses are near-exact copies).
  - Cluster assignments show no pattern by question topic or setting: The L1 distance fails to discriminate relevant distributional differences.
  - High temperature settings all collapse into one noisy cluster: Confirms temperature's disruptive effect, but if it dominates entirely, other factors become invisible.

- **First 3 experiments:**
  1. Reproduce Figures 2/3: For a fixed agent setting, compute ECDFs grouped by final answer accuracy (0, 1/3, 2/3, 1). Verify ECDFs vary significantly within accuracy bins, especially at low accuracy.
  2. Run full pipeline with k=16 on SQuAD data. Confirm the reordered assignment matrix `C` (via MDS) shows clear banding by question subject (rows) and some separation by setting type (columns).
  3. Ablate distance metric: Replace L1 with L2 (on discretized ECDF vectors) and Kolmogorov-Smirnov distances. Compare clustering quality (silhouette score) and stability of topic-aligned groups.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Does the proposed ECDF clustering method effectively reveal interpretable group structures for LLM agent evaluation on tasks beyond question answering (e.g., scientific debate, software development)?
- **Basis in paper:** Inferred. The paper focuses exclusively on a QA dataset (SQuAD) and mentions other tasks only in the introduction, but provides no experimental results for them.
- **Why unresolved:** The method's behavior could differ for tasks with varied answer formats (e.g., open-ended reasoning, code generation) or different reference answer availability, limiting claims about broad applicability.
- **What evidence would resolve it:** Apply the ECDF clustering pipeline to benchmark datasets from scientific debate (e.g., DebateKG) and software generation (e.g., HumanEval), compute ECDFs using appropriate similarity metrics (e.g., semantic similarity for text, test pass rate for code), and evaluate cluster quality via human interpretation or task-specific metrics.

### Open Question 2
- **Question:** How sensitive are the ECDF-based clustering results to the choice of embedding model used to compute cosine similarities?
- **Basis in paper:** Inferred. The experiments fixed the embedding model to paraphrase-MiniLM-L6-v2 without justification or sensitivity analysis.
- **Why unresolved:** Different embedding models capture semantics differently; variations in embedding quality could alter the shape of ECDFs and thus the distance matrix, potentially changing cluster assignments and interpretations.
- **What evidence would resolve it:** Repeat the clustering experiment with multiple embedding models (e.g., varying size, architecture, domain-specific embeddings) on the same QA data. Compare resulting clusterings using adjusted Rand index or cluster stability metrics, and qualitatively assess whether insights about temperature/persona effects persist.

### Open Question 3
- **Question:** What is an appropriate criterion for selecting the number of clusters (k) in ECDF clustering for LLM agent analysis?
- **Basis in paper:** Explicit. The paper set k=16 arbitrarily: "We applied ECDF clustering... by setting the number of clusters at m=16." No method for choosing k is provided.
- **Why unresolved:** The choice of k fundamentally influences the granularity of the group structure; without a principled selection method, results may be arbitrary or miss meaningful patterns.
- **What evidence would resolve it:** Explore internal validation measures adapted for ECDF distances (e.g., silhouette width using L1 distance, within-cluster sum of distances) on the SQuAD data. Test stability of clusters across different k and consult domain experts to determine at which k the clusters become most interpretable and actionable.

### Open Question 4
- **Question:** To what extent do agent configuration factors other than persona and temperature (e.g., base model size, number of agents, communication topology) shape the distribution of response qualities as captured by ECDFs?
- **Basis in paper:** Explicit. The paper states: "We examined the effects of changing two agent settings, persona and temperature." No other factors are varied.
- **Why unresolved:** The finding that persona has limited effect and high temperature disrupts clusters may not generalize to other dimensions that could more strongly influence response diversity and quality.
- **What evidence would resolve it:** Conduct experiments varying additional factors systematically (e.g., GPT-4 vs. GPT-3.5, 5 vs. 20 agents, star vs. ring communication) while keeping the QA task constant. Compute ECDFs and perform clustering to see whether new dimensions emerge as primary drivers of cluster separation, and compare to existing results.

## Limitations
- **Weak corpus evidence:** The neighboring papers (average FMR 0.48, 0 citations) do not corroborate the ECDF clustering approach, suggesting limited community validation or awareness.
- **Embedding model brittleness:** The entire pipeline hinges on `f_ϕ` producing semantically meaningful cosine similarities; no robustness tests across embedding models are reported.
- **Cluster interpretability subjectivity:** The claim that clusters align with "question topic difficulty" relies on visual inspection (Figures 5,7); quantitative topic-difficulty correlation is not provided.

## Confidence
- **Mechanism 1 (ECDF preserves distribution):** High – Mathematically sound and empirically demonstrated within the paper’s data.
- **Mechanism 2 (L1 distance validity):** Medium – Theoretically justified but not benchmarked against alternative distributional distances (e.g., KS, Wasserstein-2).
- **Mechanism 3 (Clustering reveals latent factors):** Medium – Supported by SQuAD patterns but lacks external validation; risk of overinterpreting visual cluster structure.
