# When Agents Disagree With Themselves: Measuring Behavioral Consistency in LLM-Based Agents

## Quick Facts
*   **arXiv ID:** 2602.11619
*   **Source URL:** https://arxiv.org/abs/2602.11619
*   **Reference Count:** 3
*   **Primary Result:** Behavioral consistency strongly predicts correctness, with a 32–55 percentage point accuracy gap between tasks with high (≤2 unique sequences) and low (≥6 unique sequences) consistency.

## Executive Summary
This study investigates the behavioral consistency of LLM-based ReAct agents on the HotpotQA multi-hop question-answering task. By executing the same query multiple times, the authors find that agents exhibit significant variance in their action sequences, producing 2.0 to 4.2 unique trajectories per 10 runs on average. Crucially, this consistency is a strong predictor of task success: highly consistent runs (few unique sequences) achieve 80–92% accuracy, while highly inconsistent runs achieve only 25–60%. The primary source of divergence is traced to the very first decision—the search query generated at step 2. Lowering the sampling temperature improves both consistency and accuracy, suggesting that reducing stochasticity stabilizes agent behavior.

## Method Summary
The evaluation uses ReAct agents (combining reasoning and acting) deployed on the HotpotQA benchmark. For each of 100 sampled tasks, the same agent (across three different model variants) is run 10 times, generating a total of 3,000 execution trajectories. The primary metric is the number of unique action sequences (e.g., sequences of `search` and `lookup` actions) produced per set of 10 runs for a single query. Accuracy is measured by the final answer's correctness. The analysis correlates consistency (number of unique sequences) with accuracy and pinpoints the step where trajectories first diverge. A controlled comparison varied the temperature setting (0.7 vs. 0.0) to assess the impact on consistency and performance. Implementation specifics and exact model versions are not detailed.

## Key Results
*   Agents produce **2.0–4.2 unique action sequences** per 10 runs on average.
*   **Accuracy gap based on consistency:** Tasks with ≤2 unique sequences achieve 80–92% accuracy, while tasks with ≥6 unique sequences achieve only 25–60%—a difference of 32–55 percentage points.
*   **Early divergence dominates:** 69% of the variation in trajectories is introduced at **step 2**, the first search query formulation.
*   **Lower temperature improves outcomes:** Reducing temperature from 0.7 to 0.0 decreases unique sequences (4.2 → 2.2) and increases accuracy (+5.4 percentage points).
*   **Shorter, more consistent paths correlate with higher accuracy.**

## Why This Works (Mechanism)
The strong link between consistency and correctness suggests that for complex, multi-hop tasks like HotpotQA, arriving at the correct answer requires a specific and stable sequence of information-seeking actions. High variance indicates the agent is exploring suboptimal or incorrect paths early on. The concentration of divergence at step 2 implies that the initial search query is a critical bifurcation point: a poorly formulated query leads the agent down an unproductive trajectory from which it cannot recover, resulting in both inconsistency and incorrect answers. Reducing temperature suppresses this early exploratory noise, leading to more deterministic and often more correct behavior.

## Foundational Learning
*   **ReAct Framework:** Integrates task-oriented reasoning (thoughts) with concrete actions (e.g., search, lookup) in an interleaved loop. *Why needed:* Enables LLMs to interact with external tools and environments for tasks beyond pure text generation. *Quick check:* Can the agent produce a `search[query]` action followed by reasoning on the results?
*   **Behavioral Consistency:** The repeatability of an agent's action sequence across multiple rollouts with identical inputs. *Why needed:* Serves as a proxy for reliability and predictability; low consistency suggests the agent's policy is unstable. *Quick check:* For a fixed query, run the agent N times; compute the number of distinct `(action1, action2, ...)` sequences.
*   **Temperature Sampling:** A decoding parameter that controls randomness; higher values increase diversity, lower values favor higher-probability outputs. *Why needed:* Balances exploration vs. exploitation in agent decision-making. *Quick check:* Compare output variance with temperature=0.0 (deterministic) vs. temperature=0.7 (stochastic).
*   **Multi-Hop Question Answering:** Tasks requiring the aggregation of information from multiple sources or reasoning steps (e.g., HotpotQA). *Why needed:* Tests an agent's ability to plan and execute a sequence of information-gathering actions. *Quick check:* Does the agent's trajectory involve more than two distinct information-seeking actions to answer a single question?
*   **Action Space Design:** The discrete set of operations an agent can perform (e.g., `search`, `lookup`, `finish`). *Why needed:* Defines the agent's interface with its environment; constraints here shape possible behaviors. *Quick check:* Is each step in the trajectory a valid member of the predefined action vocabulary?
*   **Trajectory Analysis:** Logging and examining the full sequence of thoughts, actions, and observations. *Why needed:* Allows for diagnosing failure modes and identifying critical decision points. *Quick check:* Can you reconstruct the exact path from initial question to final answer from the logs?

## Architecture Onboarding
**Component Map:** User Query -> LLM (Thought & Action Generator) -> Action Executor (e.g., Search API) -> Environment (HotpotQA) -> Observation -> LLM ... -> Final Answer

**Critical Path:** The first search query (step 2) is the primary divergence point. The quality and specificity of this initial query fundamentally constrain the subsequent information landscape and reasoning path.

**Design Tradeoffs:** 
*   *Temperature vs. Consistency:* Higher temperature encourages exploration but severely harms consistency and, in this domain, accuracy.
*   *Path Length vs. Efficiency:* Longer trajectories with more steps generally indicate struggle and correlate with lower accuracy; a concise, direct path is desirable but must still be correct.
*   *Action Space Granularity:* A fine-grained action space (many possible actions) may increase flexibility but also variance; a coarse space may limit expressiveness.

**Failure Signatures:**
1.  High number of unique action sequences per query (e.g., >4).
2.  Long trajectory length (many steps before `finish`).
3.  Divergence occurring at the very first action (step 2), especially if the initial search query is vague or mis-specified.

**First Three Experiments:**
1.  **Temperature Sweep:** Run the agent with temperatures {0.0, 0.2, 0.5, 0.7, 1.0} on a fixed query set. Plot unique sequences and accuracy vs. temperature.
2.  **Step-2 Query Analysis:** For all divergent trajectories, extract and cluster the first `search` queries. Manually inspect whether incorrect or overly broad queries at step 2 predict final failure.
3.  **Cross-Task Transfer:** Replicate the entire consistency-accuracy correlation experiment on a different agent benchmark (e.g., WebShop for web navigation, or a coding task) to test domain generalizability.

## Limitations
*   **Reproducibility unknown:** Results rely on unreleased implementation details; no reproduction notes are provided.
*   **Generalizability limited:** Evaluation is confined to a single task domain (HotpotQA) and unspecified model versions; transfer to other agent paradigms (e.g., reflexion, planning) or tasks is unverified.
*   **Confounders unmeasured:** Inherent task difficulty or data distribution quirks may correlate with both consistency and accuracy, complicating causal interpretation.

## Confidence
*   **Consistency predicts correctness:** *Medium* (strong observational correlation in one domain, but causation not established).
*   **Early divergence (step 2) as primary source:** *Medium* (compelling pattern, requires validation on other task structures).
*   **Temperature reduction improves consistency/accuracy:** *High* (direct controlled experimental comparison).
*   **Path length correlates with outcomes:** *Low* (likely confounded by consistency; may not hold independently or in other domains).

## Next Checks
1.  **Replicate across model families and tasks:** Run the identical protocol on latest LLMs (e.g., GPT-4, Claude 3) and diverse agent benchmarks (e.g., WebShop, AgentBench) to test domain and model transfer.
2.  **Hyperparameter sweep beyond temperature:** Systematically vary top-p, max tokens, and prompt variations to isolate the key drivers of behavioral consistency.
3.  **Fine-grained divergence analysis:** Log and categorize all decision points (step 2 onward) across varied task types to determine if early divergence consistently dominates or shifts with task structure (e.g., single-hop vs. multi-hop).
