# Stochastic Event Prediction via Temporal Motif Transitions

## Quick Facts
- arXiv ID: 2603.05874
- Source URL: https://arxiv.org/abs/2603.05874
- Reference count: 40
- Primary result: STEP improves average precision by up to 21.23 percentage points over state-of-the-art baselines on classification and achieves 0.99 precision in sequential forecasting, with lower runtime than competing motif-aware methods.

## Executive Summary
This paper introduces STEP, a method that reformulates temporal link prediction from binary classification into sequential forecasting using Poisson-driven temporal motif transitions. Instead of discretizing time or ignoring event sequences, STEP maintains open motif instances and decides whether to initiate new motifs or extend existing ones through Bayesian scoring of temporal likelihoods and structural transition priors. It also generates compact motif-based feature vectors that can augment any temporal graph neural network without architectural changes. On five real-world datasets, STEP significantly outperforms state-of-the-art baselines in both classification and next-k sequential forecasting tasks while maintaining computational efficiency.

## Method Summary
STEP redefines temporal link prediction as a sequential decision problem over temporal motifs—recurring subgraph patterns with timestamped edges. For each incoming event, the model evaluates whether it belongs to an existing open motif instance or starts a new one, using a Bayesian score that combines a Poisson-based temporal likelihood with a structural prior derived from motif transition statistics. This approach preserves the order and timing of events. Additionally, STEP produces fixed-size motif-aware feature vectors by aggregating motif instance information, which are then concatenated with outputs from any temporal graph neural network (TGN) to enhance its predictions without modifying the TGN architecture.

## Key Results
- Achieves up to 21.23 percentage point improvement in average precision compared to state-of-the-art baselines on classification tasks (e.g., CollegeMsg dataset).
- Attains 0.99 precision in next-k sequential forecasting experiments.
- Demonstrates lower runtime than competing motif-aware methods across all evaluated datasets.

## Why This Works (Mechanism)
STEP succeeds because it directly models the sequential and stochastic nature of temporal graphs. By focusing on temporal motifs—small, recurring interaction patterns—it captures higher-order structural dynamics that pairwise links miss. The Bayesian scoring mechanism balances the temporal plausibility of adding an event to an existing motif (via Poisson process assumption) with the structural coherence of motif transitions (via learned priors). This dual scoring allows STEP to differentiate between continuation and new motif initiation accurately. The subsequent feature augmentation injects this motif-level understanding into any TGN, enabling the TGN to leverage motif-aware context without retraining. This two-stage design (motif management + feature augmentation) decouples motif reasoning from representation learning, making the approach both effective and adaptable.

## Foundational Learning
- **Temporal Link Prediction**: Forecasting future edges in a time-evolving graph; why needed: core task for dynamic network analysis; quick check: given a sequence of past edges, predict next edge(s).
- **Temporal Motifs**: Small, timestamped subgraph patterns (e.g., triads) that recur over time; why needed: capture higher-order interaction semantics beyond pairwise links; quick check: extract all 3-node directed patterns with temporal ordering from a stream.
- **Poisson Process**: A stochastic process modeling independent events at constant rate; why needed: provides a simple likelihood for event timing within motifs; quick check: given inter-event times, compute probability under exponential distribution.
- **Bayesian Scoring**: Combining likelihood and prior to evaluate hypotheses; why needed: formal framework for motif continuation decision; quick check: compute posterior odds for two competing motif assignments.
- **Temporal Graph Neural Networks (TGNs)**: Neural models that learn representations from temporal graphs; why needed: powerful baselines for temporal prediction; quick check: implement a TGN with memory modules and message passing.
- **Feature Augmentation**: Adding external features to model inputs; why needed: allows motif insights to improve any TGN without altering its core; quick check: concatenate motif features to TGN node embeddings before prediction layer.

## Architecture Onboarding
**Component Map**: Incoming Event -> Motif Manager (tracks open motifs) -> Bayesian Scorer (computes continuation vs. new motif) -> Motif Update (extend or initiate motif) -> Feature Aggregator (summarizes motif instances) -> Feature Vector -> TGN (existing model) -> Prediction.

**Critical Path**: The core inference loop processes events one by one: (1) for each event, query motif manager for candidate open motifs; (2) Bayesian scorer evaluates each candidate; (3) decide best assignment (extend motif or start new); (4) update motif manager; (5) periodically recompute motif feature vectors; (6) feed vectors to TGN for link prediction.

**Design Tradeoffs**: 
- Poisson assumption simplifies timing but may misrepresent bursty/self-exciting dynamics.
- Motif vocabulary size: larger vocabulary captures more patterns but increases memory and prior estimation complexity.
- Feature augmentation: adds information without retraining TGN but may introduce distribution shift if motif features are noisy.

**Failure Signatures**:
- High rate of motif initiation errors: indicates poor prior or motif definition mismatch.
- Degraded TGN performance after augmentation: suggests feature noise or scaling issues.
- Memory blowup in motif manager: too many open motifs due to loose closure conditions or large motifs.

**First 3 Experiments**:
1. **Motif Assignment Sanity Check**: Run STEP on a small synthetic temporal graph with known motif transitions; verify that the Bayesian scorer correctly assigns events to true motifs >90% of the time.
2. **Feature Ablation Impact**: Train a TGN with and without STEP features on a validation set; measure change in average precision to confirm augmentation benefit.
3. **Runtime Profiling**: Scale motif vocabulary size and open motif limit; log runtime per event to identify bottlenecks in motif manager or scorer.

## Limitations
- Generalizability of performance gains may be limited to the five datasets used; unclear on extremely sparse or highly periodic networks.
- Causal attribution of improvement is ambiguous; the combined effect of motif modeling, Bayesian scoring, and feature augmentation makes it hard to isolate the novel transition mechanism's contribution.
- Robustness to violations of Poisson assumption and unseen motif patterns is not evaluated.
