# Collaborative Adaptive Curriculum for Progressive Knowledge Distillation

## Quick Facts
- **arXiv ID:** 2603.20296
- **Source URL:** https://arxiv.org/abs/2603.20296
- **Reference count:** 40
- **Primary result:** FAPD achieves 89.42% top-1 accuracy on CIFAR-10, a 3.64% absolute improvement over FedAvg, with 2× faster convergence and over 4.5% gain under extreme non-IID (α=0.1).

## Executive Summary
Federated learning with knowledge distillation faces the challenge of mismatched teacher and student capacities, especially under data heterogeneity. This paper introduces FAPD, a method that uses a consensus-driven curriculum to progressively transfer teacher knowledge. The server decomposes high-dimensional teacher features via PCA on a calibration set, ordering components by variance. Each communication round, clients receive a projection matrix for the current dimensionality k_t. Local training uses a combined loss of cross-entropy, knowledge distillation (KL on projected features), and contrastive learning (InfoNCE with class text embeddings). The server monitors global accuracy stability; if recent accuracies are stable (variance < ε over N rounds), k_t increases. On CIFAR-10, FAPD reaches 89.42% accuracy, outperforming FedAvg by 3.64% and converging twice as fast, and shows robustness under severe non-IID (α=0.1).

## Method Summary
FAPD addresses federated image classification where a centralized teacher model (CLIP ViT-B/32 encoder from Stable Diffusion) provides 512-dimensional features. Clients train local models (e.g., ResNet-10) using a mixture of local supervised loss and two distillation losses: (1) KL divergence between normalized student outputs and normalized projected teacher features, and (2) InfoNCE contrastive loss between student features and class text embeddings. The server initializes a rotation matrix R by performing PCA on a calibration subset of teacher features. The curriculum begins with a low dimensionality k0 = 8 and increments by Δk = 5 whenever the global model's validation accuracy over the last N = 3 rounds changes by less than ε = 0.005. Clients perform E = 10 local SGD epochs with learning rate 0.01. Model updates are aggregated via FedAvg. The process runs for 100 rounds, selecting 5 clients per round.

## Key Results
- Top-1 accuracy on CIFAR-10: **89.42%** (vs. FedAvg's 85.78%, +3.64% absolute).
- Convergence speed: **2× faster** than FedAvg (reaches comparable accuracy in half the rounds).
- Robustness under extreme non‑IID (α=0.1): **outperforms baselines by over 4.5%**.
- Progressive curriculum increases k_t from 8 to up to 512, stabilizing learning.

## Why This Works (Mechanism)
The PCA-based hierarchical decomposition ensures that the most variance-rich components of teacher features are introduced first, providing a meaningful curriculum that stabilizes learning. The consensus-driven stability check (monitoring validation accuracy over the last N rounds with threshold ε) ensures that the global model has assimilated the current knowledge chunk before increasing complexity, preventing distortion. The combined loss (cross‑entropy + KL divergence + InfoNce) aligns the student with both local labels and the teacher's semantic structure, enabling effective knowledge transfer even with heterogeneous client data distributions.

## Architecture Onboarding
- **Component map:**  
  Teacher (CLIP encoder) → Server (PCA calibration, projection matrices, stability monitor) → Clients (local models) → Server (FedAvg aggregation).  
  Data flow: Teacher features precomputed and distributed to clients; Server sends (global model, k_t, P_k) each round; Clients compute losses using teacher features and class embeddings; send updates back.
- **Critical path:**  
  1. Server computes PCA on calibration set, initializes R.  
  2. Round t: Server selects clients, sends current k_t and projection matrix P_k (first k rows of R).  
  3. Clients perform local training: fetch precomputed teacher features (projected), compute loss (CE + 0.5*KD + 0.5*CL), update local model.  
  4. Clients upload model deltas; server FedAvg to produce new global model.  
  5. Server evaluates global model on validation set, updates accuracy history, decides whether to increase k for next round based on stability condition.  
  6. Repeat until 100 rounds.
- **Design tradeoffs:**  
  - Dimensionality increment Δk vs curriculum smoothness: Larger Δk may introduce too much noise; smaller Δk prolongs low‑dim training.  
  - Stability window N and threshold ε: larger N/ε delay progression; too permissive may cause premature jumps and instability.  
  - Calibration set size: Larger set improves PCA reliability but increases one‑time cost; too small may misorder components.
- **Failure signatures:**  
  - k_t stagnates despite converging accuracy: check if stability condition is too strict.  
  - Accuracy drops when k_t increases: possibly due to misaligned PCA (calibration set not representative) or too aggressive jump.  
  - High variance in client updates: heterogeneity may cause instability in curriculum pacing.
- **First experiments (exactly 3):**  
  1. Teacher feature verification: Compute 512‑D features for CIFAR‑10 using CLIP ViT‑B/32, check distribution (mean, std) and sensitivity to preprocessing.  
  2. Validation set pilot: Determine a suitable validation set size (e.g., 1,000 images) and measure stability of accuracy across rounds; adjust ε=0.005 if necessary.  
  3. Calibration sensitivity: Test different calibration set sizes (500, 1,000, 2,000) and compute cumulative explained variance for k=8,13; ensure top components retain sufficient variance (>50% for k=8,13).

## Open Questions the Paper Calls Out
- **How can the PCA‑based hierarchical knowledge decomposition be made robust to non‑representative calibration data?**  
  The paper notes that if the calibration data does not adequately represent the global distribution, the resulting knowledge hierarchy may be suboptimal. This is unresolved; evidence would compare centralized vs. federated aggregation of client covariances and sensitivity to calibration set size.

- **Can the consensus‑driven curriculum be personalized per client or client groups to better accommodate extreme resource and data heterogeneity?**  
  The current unified curriculum may overwhelm weaker clients or underutilize stronger ones. Designing per‑client or clustered adaptive dimension control using local stability signals could yield gains in fairness and efficiency.

- **How can the hierarchical decomposition approach be extended to non‑image modalities (e.g., video, audio) while preserving an effective variance‑based knowledge hierarchy?**  
  Modalities like video have temporal structure and audio has spectral patterns; flattening to vectors for PCA may yield components that are not semantically meaningful. Extensions would require spatio‑temporal or frequency‑aware decomposition methods.

## Limitations
- Teacher model specification is ambiguous (which encoder, feature extraction details).  
- Validation set size and sampling are not defined, affecting curriculum triggers.  
- PCA derived from a potentially small calibration set may not represent global distribution, leading to suboptimal knowledge ordering.
