# Enhancing Pretrained Model-based Continual Representation Learning via Guided Random Projection

## Quick Facts
- arXiv ID: 2603.19145
- Source URL: https://arxiv.org/abs/2603.19145
- Reference count: 40
- Primary result: SCL-MGSM consistently outperforms state-of-the-art in exemplar-free CIL, with higher accuracy and lower forgetting, while automatically determining RPL size.

## Executive Summary
Pretrained models (PTMs) often suffer from large domain gaps when applied to downstream tasks in class incremental learning (CIL). Naively using a randomly initialized random projection layer (RPL) either lacks expressivity or produces ill-conditioned feature matrices that destabilize recursive analytic updates. SCL-MGSM addresses this by constructing the RPL via a data-guided Multi-Grained Supervisory Mechanism (MGSM). MGSM leverages the initial task's data to progressively select target-aligned, non-redundant random bases, automatically determining the RPL size based on a residual threshold. This yields a compact, well-conditioned projection that stabilizes recursive ridge-regression updates without extra stabilization or exemplars. Across seven exemplar-free CIL benchmarks, SCL-MGSM consistently outperforms state-of-the-art methods, achieving up to +2.05% higher final accuracy on ImageNet-R Inc-10 and +1.77% on ObjectNet Inc-10, while also reducing forgetting and memory usage.

## Method Summary
SCL-MGSM is a two-phase approach for continual representation learning with pretrained models. In the construction phase, given a pretrained model and initial task data, MGSM incrementally adds random projection bases to the RPL. Each new basis is selected to maximize reduction in residual reconstruction error of the initial task features, ensuring alignment with the target task and non-redundancy. The process stops when the residual drop falls below a threshold ε, automatically determining the RPL dimension L*. In the incremental learning phase, the pretrained model and the fixed RPL are used to extract features for all tasks, and a linear classifier is updated via recursive ridge regression, which provides stable closed-form updates without storing past data. This design avoids the expressivity-conditioning trade-off of naive random projections and eliminates the need for exemplars or extra stabilization techniques.

## Key Results
- SCL-MGSM surpasses state-of-the-art on seven exemplar-free CIL benchmarks, with notable gains of +2.05% on ImageNet-R Inc-10 and +1.77% on ObjectNet Inc-10.
- It achieves lower forgetting and reduced memory consumption compared to high-dimensional RPL baselines.
- The RPL dimension is automatically determined by MGSM’s residual criterion, removing the need for manual tuning.

## Why This Works (Mechanism)
MGSM works by iteratively building the RPL using the initial task’s feature distribution. Each random basis is chosen from a pool of candidates to maximally reduce the residual of the initial features after projection, ensuring that the selected bases are aligned with the target task’s discriminative directions. Because bases are selected to be non-redundant (orthogonal in the feature space), the resulting projection matrix is well-conditioned, which stabilizes the recursive ridge-regression updates. Moreover, by using only the initial task data, MGSM avoids catastrophic forgetting during RPL construction and keeps the method exemplar-free. The automatic stopping criterion based on residual threshold balances expressivity and conditioning, leading to a compact RPL that generalizes across tasks even under domain shifts.

## Architecture Onboarding
- **Component map**: Initial Task Data -> MGSM (basis selection) -> RPL (fixed weights) -> Feature Extractor (PTM + RPL) -> Recursive Ridge Regression Classifier (updated per task).
- **Critical path**: (1) Train PTM on initial task; (2) Run MGSM on initial task features to construct RPL; (3) Freeze PTM and RPL; (4) For each new task, extract features via PTM+RPL and update classifier using recursive ridge regression with new task data.
- **Design tradeoffs**: 
  - RPL dimension: Automatically determined by residual threshold ε; lower ε yields larger RPL with higher expressivity but potentially worse conditioning, higher ε yields smaller RPL with risk of underfitting.
  - Use of only initial task data for RPL construction: reduces memory and computational cost, but limits adaptability to later domain shifts.
  - Recursive ridge regression: provides stability via regularization, but requires careful tuning of the regularization parameter λ.
- **Failure signatures**:
  - High condition number of RPL feature matrix indicates redundant bases, leading to unstable classifier updates.
  - If MGSM stops too early (large ε), the RPL may be too small to capture discriminative features, causing poor accuracy.
  - Severe domain shift between initial and later tasks may cause the fixed RPL to be misaligned, resulting in high forgetting.
- **First experiments**:
  1. Ablation study: Replace MGSM-guided RPL with a randomly initialized RPL of the same dimension to isolate the effect of guided basis selection.
  2. Cross-modality evaluation: Apply SCL-MGSM to a continual language task using BERT as PTM to test generalizability beyond vision.
  3. Conditioning analysis: Compute condition numbers of feature matrices for SCL-MGSM versus high-dimensional random RPL to verify the claim of well-conditioned matrices.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How can SCL-MGSM be extended to allow the random projection layer to evolve during incremental learning, rather than being fixed after the initial task?
- **Basis in paper**: [explicit] The authors state in the Limitation and Future Work: "In future work, we plan to extend SCL-MGSM toward a dynamic RPL paradigm that can progressively adapt the random projection space across continual learning stages..."
- **Why unresolved**: The current approach constructs the RPL once using only initial-task data; it cannot incorporate new feature directions if later tasks differ substantially. An adaptive mechanism that safely adds or removes bases without destabilizing recursive updates is missing.
- **What evidence would resolve it**: A new algorithm that incrementally updates the RPL (e.g., by applying MGSM to new tasks) with theoretical stability guarantees; evaluation on benchmarks with severe domain shifts showing reduced forgetting and improved accuracy compared to static RPL.

### Open Question 2
- **Question**: What factors determine the final hidden size L* automatically chosen by MGSM, and can we predict L* from characteristics of the domain gap between the PTM and downstream tasks?
- **Basis in paper**: [inferred] SCL-MGSM adaptively stops when residual drops below ε, leading to variable L* across datasets (Table 4). The paper notes that ImageNet-A (largest domain gap) required the most hidden units, but no explicit analysis links domain gap metrics to L*.
- **Why unresolved**: Users currently have no way to anticipate computational cost or memory usage before running MGSM. A predictive model would enable better resource planning and possibly improve the construction algorithm.
- **What evidence would resolve it**: Correlate measures of domain shift (e.g., KL divergence between PTM features on source vs. target data) with L* over a diverse set of benchmarks; develop a theoretical or empirical model that estimates required dimension given such metrics.

### Open Question 3
- **Question**: Does the MGSM mechanism remain effective for continual learning in non-vision domains, such as natural language processing or speech recognition?
- **Basis in paper**: [inferred] The paper only evaluates on image classification datasets with vision transformers or ResNet backbones. The conclusion mentions compatibility with diverse PTM architectures but does not test other modalities.
- **Why unresolved**: Feature spaces of language models differ in dimensionality, activation patterns, and task semantics. MGSM's criterion, derived from residual reduction, may behave differently and could require adjustments.
- **What evidence would resolve it**: Apply SCL-MGSM to continual language tasks using pre-trained models like BERT or GPT; report performance compared to baselines; analyze whether the resulting random bases remain non-redundant and well-conditioned.

## Limitations
- Evaluation is limited to seven image classification benchmarks; applicability to audio, text, or multimodal models is unknown.
- The robustness of automatic RPL size selection across various domain gaps and its sensitivity to the initial task are not thoroughly examined.
- Computational overhead and scalability of MGSM to very high-dimensional pretrained features are not reported.
