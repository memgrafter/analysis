# Multimodal Connectome Fusion via Cross-Attention for Autism Spectrum Disorder Classification Using Graph Learning

## Quick Facts
- **arXiv ID**: 2603.15168
- **Source URL**: https://arxiv.org/abs/2603.15168
- **Reference Count**: 35
- **Primary Result**: AUC 87.3%, accuracy 84.4% (stratified 10-fold CV); average accuracy 82.0% (leave-one-site-out CV); outperforms SOTA by ~3% AUC and ~7% accuracy.

## Executive Summary
This study proposes a multimodal graph learning framework for autism spectrum disorder (ASD) classification by integrating resting-state fMRI (rs-fMRI), structural MRI (sMRI), and phenotypic data. Subjects are represented as nodes in separate population graphs, with modality-specific connectivity features and edges derived adaptively from phenotypic similarity via a Pairwise Association Encoder (PAE). Modality-specific embeddings are learned using Edge-Variational Graph Convolutional Networks (EV-GCNs) and fused through an asymmetric transformer-based cross-attention mechanism that treats functional embeddings as queries and structural embeddings as keys/values, thereby prioritising functional information while incorporating structural context. Evaluated on the ABIDE-I dataset, the method achieves an AUC of 87.3% and accuracy of 84.4% under stratified 10-fold cross-validation, and 82.0% accuracy under leave-one-site-out cross-validation, surpassing existing state-of-the-art approaches by approximately 3% and 7% respectively.

## Method Summary
The framework processes rs-fMRI and sMRI connectivity matrices (Harvard-Oxford and AAL atlases, respectively) along with phenotypic features (age, sex, site). Each modality undergoes preprocessing: recursive feature elimination with ridge regression to select 2400 features, followed by z-score normalisation. Subject nodes are connected by edges computed from a shared PAE: phenotypic features are encoded by a multi-layer perceptron to 128-dimensional latent vectors, and pairwise cosine similarity (offset by +0.5) defines a dense adjacency matrix. Two parallel EV-GCN encoders (each with 4 Chebyshev convolution layers, ReLU, batch normalisation, dropout 0.2) operate on their respective modality features and the shared edge matrix. Multi-scale aggregation concatenates all layer outputs to produce comprehensive node embeddings. The embeddings are fused via asymmetric cross-attention: functional embeddings are linearly projected to queries (Q), structural embeddings serve as keys (K) and values (V); multi-head attention is applied, followed by a residual addition and a refinement MLP (layer norm, linear, GELU, dropout, linear). The fused representation is passed to a linear classifier with softmax, trained end-to-end using cross-entropy loss, Adam optimizer (learning rate 0.01, weight decay 5e-5) for 300 epochs. Performance is assessed via stratified 10-fold and leave-one-site-out cross-validation on ABIDE-I.

## Key Results
- Stratified 10-fold CV: AUC 87.3%, accuracy 84.4%.
- Leave-one-site-out CV: average accuracy 82.0%.
- Outperforms prior state-of-the-art by ~3% AUC and ~7% accuracy.

## Why This Works (Mechanism)
### Mechanism 1: Adaptive Phenotypic Graph Construction
- **Claim**: Adaptive population graph edges derived from phenotypic similarity enable robust multimodal integration across sites.
- **Mechanism**: The Pairwise Association Encoder (PAE) transforms age, sex, site into latent embeddings; cosine similarity between these latent vectors defines edge weights; the adjacency matrix is learned jointly with classification.
- **Core assumption**: Phenotypic affinities (e.g., similar age/sex) correlate with underlying neurobiological similarity, and modelling these relationships adaptively mitigates site-related heterogeneity.
- **Evidence anchors**: The abstract mentions PAE for inter-subject relationships; Section 2.2.3 details PAE architecture and cosine similarity computation; the corpus cites population graph works but does not directly validate this specific design.
- **Break condition**: If phenotypic features are poor proxies for neural similarity (e.g., site dominates), edges may mislink subjects, homogenising diagnostic signals and reducing discriminative power.

### Mechanism 2: Asymmetric Cross-Attention Fusion
- **Claim**: Asymmetric cross-attention preserves the dominant diagnostic role of functional connectivity while allowing structural information to selectively modulate it.
- **Mechanism**: Modality-specific embeddings from EV-GCNs are fused using transformer cross-attention where rs-fMRI embeddings serve as queries (Q) and sMRI embeddings as keys (K) and values (V). This forces functional patterns to “query” structural context, enabling adaptive, attention-weighted integration.
- **Core assumption**: rs-fMRI is the primary modality for ASD classification; sMRI provides complementary but subordinate context.
- **Evidence anchors**: The abstract states the mechanism prioritises functional information; Section 2.3.1 explicitly defines Q=H_f, K=V=H_s and notes this design “ensures functional connectivity remains the principal source”; the corpus includes transformer-based ASD works but not asymmetric designs, providing indirect support via general attention efficacy.
- **Break condition**: If structural embeddings contain high site-specific noise or irrelevant variance, attention may force functional representations to incorporate confounds, degrading performance versus simpler fusion.

### Mechanism 3: Multi-Scale EV-GCN Embeddings
- **Claim**: Modality-specific EV-GCNs with multi-scale aggregation learn population-aware embeddings that capture both local connectivity and global subject relationships.
- **Mechanism**: Each modality’s population graph (nodes = subjects, edges = phenotypic similarity) is processed by an Edge-Variational GCN. Edge weights are learned by PAE and used in graph convolution. Node embeddings from all layers are concatenated to preserve multi-hop neighbourhood information.
- **Core assumption**: Subject-level discriminative patterns exist at multiple interaction scales (local brain region clusters to global subject clusters) and are best captured by multi-layer GCN aggregation on a phenotypic graph.
- **Evidence anchors**: The abstract mentions modality-specific embeddings via Edge-Variational GCNs; Section 2.2.5 describes the multi-scale aggregation strategy; the corpus includes EV-GCN and hierarchical/multi-scale GCN trends for brain disorders.
- **Break condition**: If graph edges are too sparse/noisy or embedding depth insufficient, multi-scale gains vanish; over-smoothing could occur if the number of layers is too high, making all embeddings indistinguishable.

## Foundational Learning
- **Concept**: Population graph construction in neuroimaging.
  - **Why needed**: To model inter-subject relationships via phenotypic similarity, moving beyond single-subject analysis and enabling the PAE and EV-GCN components.
  - **Quick check**: Why might using a phenotypic similarity graph improve classification compared to treating each subject independently?

- **Concept**: Edge-variational graph convolution.
  - **Why needed**: Allows edge weights to be learned from data (via PAE), making the graph structure adaptive to the classification task and handling multi-site heterogeneity.
  - **Quick check**: How does an “edge-variational” approach differ from a standard GCN with fixed adjacency, and what is the trade‑off?

- **Concept**: Asymmetric cross-attention for multimodal fusion.
  - **Why needed**: Explicitly prioritises one modality (functional) as the driver, using attention to incorporate the other (structural), respecting hypothesised modality hierarchy in ASD.
  - **Quick check**: In this asymmetric design, what would happen if you swapped the roles (structural queries, functional keys/values)? Why might that be less effective?

## Architecture Onboarding
### Component Map
1. **Inputs**: rs-fMRI connectivity matrix (Harvard-Oxford atlas, 111 ROIs), sMRI connectivity matrix (AAL atlas, 116 ROIs), phenotypic features (age, sex, site).
2. **Preprocessing**: Recursive feature elimination with ridge regression to select 2400 features per modality; z-score normalisation.
3. **Graph Construction**: PAE takes normalised phenotypic features → MLP → 128‑dim latent embeddings → cosine similarity (+0.5) → shared edge matrix W.
4. **Modality Encoders**: Two separate EV-GCNs. Each takes its modality's feature matrix X and shared W. Multi-layer Chebyshev convolution (K=3, 4 layers) with ReLU, BatchNorm, Dropout=0.2; multi-scale concatenation of all layer outputs → H_f, H_s.
5. **Fusion**: Asymmetric cross-attention: Q = Linear(H_f), K = V = H_s → Multi-Head Attention → residual addition of Q → MLP refinement (LayerNorm, Linear, GELU, Dropout, Linear) → fused Z.
6. **Classification**: Linear layer on Z → softmax → cross-entropy loss.
7. **Training**: End-to-end with Adam (lr=0.01, weight_decay=5e-5), 300 epochs, dropout=0.2.

### Critical Path
Preprocessed connectivity features → PAE (edge learning) → EV-GCNs (embedding learning) → asymmetric cross-attention (fusion) → MLP (classification). The fusion step is the architectural hinge.

### Design Tradeoffs
- **Asymmetric vs. symmetric attention**: Asymmetric enforces functional dominance but risks missing structural-driven patterns; symmetric is more balanced but may dilute functional signal.
- **Shared vs. modality-specific edges**: Shared W reduces parameters and forces phenotypic-driven links to be modality-agnostic, but may overlook modality-specific subject relationships.
- **Multi-scale vs. final-layer GCN embeddings**: Multi-scale preserves fine/coarse patterns but increases dimension; final-layer is simpler but risks losing early-layer features.

### Failure Signatures
- **Poor LOSO-CV** (accuracy near random for a site): Indicates phenotypic graph/attention fails to generalise across scanner/site shifts; likely edges are site-biased.
- **Ablation: no PAE** (random edges): Performance drop, especially in LOSO, showing PAE’s role in cross-site robustness.
- **Ablation: symmetric/concatenation fusion**: Performance drop versus asymmetric, confirming fusion design’s importance.
- **Attention weight entropy near uniform**: Cross-attention isn’t learning to prioritise; may indicate insufficient capacity or mis‑scaled queries/keys.

### First 3 Experiments
1. **Single‑modality validation**: Train EV‑GCN on rs‑fMRI only (with PAE) and sMRI only (with PAE). Expect rs‑fMRI ≫ sMRI (per Table 1). Verifies each modality’s standalone signal and PAE benefit.
2. **Fusion strategy comparison**: Replace asymmetric attention with (a) concatenation, (b) symmetric cross‑attention, keeping all else fixed. Expect asymmetric > others (per Table 3). Isolates fusion mechanism contribution.
3. **PAE ablation**: Remove PAE; use a fixed graph (e.g., k‑NN on phenotypic features) or random edges. Compare performance under 10‑fold and LOSO. Expect largest drop in LOSO, showing PAE’s role in site‑robust edge learning.

## Open Questions the Paper Calls Out
### Open Question 1
**Question**: Is the predefined asymmetric cross‑attention mechanism with functional embeddings as queries universally optimal for multimodal ASD classification, or could alternative attention directions (e.g., structural as queries) or fully learnable attention patterns yield better performance?
- **Basis in paper**: The paper explicitly fixes the asymmetric design to preserve functional dominance based on rs‑fMRI’s reported discriminative power, but does not empirically evaluate whether this a priori hierarchy is optimal or if the model could learn more effective inter‑modality interactions.
- **Why unresolved**: The asymmetric design is not compared against reversed asymmetry or adaptive attention schemes; only symmetric cross‑attention (which performed worse) is tested, leaving open whether the functional‑dominant assumption universally enhances fusion or constrains potential improvements.
- **What evidence would resolve it**: Ablation studies on ABIDE and external datasets comparing (a) the proposed asymmetric design, (b) reversed asymmetry (sMRI as queries), and (c) a trainable attention module where query modality is optimised during training, with performance metrics under both 10‑fold and LOSO‑CV.

### Open Question 2
**Question**: Does sharing phenotypic‑driven edge weights across functional and structural population graphs limit the capture of modality‑specific inter‑subject relationships, and would modality‑specific edge construction via separate PAEs improve multimodal fusion and site generalisation?
- **Basis in paper**: The framework uses a single Pairwise Association Encoder (PAE) to generate shared edge weights for both modality‑specific graphs, assuming phenotypic similarity is modality‑agnostic, but this assumption is not validated against modality‑specific edge learning.
- **Why unresolved**: Phenotypic traits (e.g., age, site) may correlate differently with functional vs. structural connectivity; shared edges could force homogeneous relationships that overlook modality‑specific patterns, potentially suboptimal for fusion, especially under LOSO‑CV where site variability is high.
- **What evidence would resolve it**: Implement separate PAEs for rs‑fMRI and sMRI graphs to learn modality‑specific edges, then compare classification performance (AUC, accuracy) and site‑wise generalisability against the shared‑edge baseline, analysing edge weight distributions and attention maps for interpretability.

### Open Question 3
**Question**: How robust is the multimodal framework to missing or incomplete modalities (e.g., absent sMRI) in real‑world clinical settings, and can it effectively leverage partial data without significant performance degradation?
- **Basis in paper**: The study uses complete multimodal data from ABIDE and does not address scenarios with missing modalities, despite clinical datasets often having incomplete imaging due to practical constraints.
- **Why unresolved**: The current architecture requires all modalities for cross‑attention fusion; its behaviour with missing inputs—such as falling back to single‑modality embeddings or using imputation—is unexplored, limiting practical applicability.
- **What evidence would resolve it**: Simulate missing modalities in ABIDE (e.g., remove sMRI for subsets) and evaluate performance with (a) trained modality dropout, (b) imputation techniques, or (c) dynamic routing to available modalities; test on external ASD datasets with natural missingness to assess robustness and adaptation strategies.

## Limitations
- Hyperparameter details (PAE MLP architecture, refinement MLP sizes, attention heads) are not fully specified, hindering faithful reproduction.
- The assumption that phenotypic similarity (age, sex, site) reliably approximates neural similarity across sites is not empirically validated.
- Evaluation is restricted to the ABIDE‑I dataset with no external validation; site effects may bias results, and leave‑one‑site‑out performance remains moderate (82% accuracy).

## Confidence
- Adaptive phenotypic graph (PAE): Medium
- Asymmetric cross‑attention fusion: Medium
- Overall performance (AUC 87.3%, accuracy 84.4%): Low

## Next Checks
1. **PAE edge necessity under LOSO**: Replace learned PAE edges with random Gaussian matrices and static k‑NN phenotypic edges; run LOSO‑CV. A significant drop (>5% accuracy) would confirm PAE’s role in mitigating site shifts.
2. **Asymmetric fusion symmetry ablation**: Implement symmetric cross‑attention (both modalities query) and structural‑asymmetric (structural queries). Compare against proposed asymmetric in both 10‑fold and LOSO. Proposed should significantly outperform if functional dominance assumption holds.
3. **Multi‑scale depth sensitivity**: Vary EV‑GCN depth (2, 4, 6 layers) and evaluate validation accuracy. Expect peak at moderate depth; degradation at greater depths indicates over‑smoothing, suggesting need for residual connections.
