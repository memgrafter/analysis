# Enhancing Temporal Awareness in LLMs for Temporal Point Processes

## Quick Facts
- **arXiv ID:** 2601.00845
- **Source URL:** https://arxiv.org/abs/2601.00845
- **Reference count:** 40
- **Primary result:** Introduces TPP-TAL, a plug-and-play framework with Temporal Cross-Fusion and Multi-Scale Temporal Bias Transformer, achieving substantial improvements in log-likelihood, accuracy, and RMSE over TPP-LLM on four temporal point process datasets.

## Executive Summary
This paper addresses the challenge of integrating temporal and semantic information in large language models (LLMs) for temporal point processes (TPPs). It proposes TPP-TAL, a plug-and-play framework that enhances temporal awareness by aligning time and semantics within events (via cross-attention) and modeling cross-event dependencies with per-head temporal biases. The method is evaluated on four datasets (US-EQ, SOF, AMZ, NYC) and consistently outperforms the baseline TPP-LLM in log-likelihood, accuracy, and RMSE, demonstrating superior temporal modeling and event prediction.

## Method Summary
TPP-TAL integrates two novel modules with a frozen LLM: Temporal Cross-Fusion (TCF) uses cross-attention to align temporal embeddings with semantic token representations within each event, producing time-fused token matrices and pooled vectors. Multi-Scale Temporal Bias Transformer (MTBT) injects per-head temporal biases based on logarithmically bucketed time differences to model cross-event dependencies. Events are encoded with semantic and temporal embeddings, processed through TCF and MTBT, and fed as a structured sequence into a pretrained LLM (TinyLlama-1.1B-Chat-v1.0) without fine-tuning. The model jointly optimizes log-likelihood, event type classification, and time prediction using a multi-task loss.

## Key Results
- **Log-likelihood improvement:** Substantial gains across datasets (e.g., SOF: -1.8482 to -0.4748).
- **Accuracy improvement:** Significant accuracy increases (e.g., SOF: 0.4386 to 0.7962).
- **RMSE reduction:** Notable decrease in time prediction error (e.g., SOF: 0.4819 to 0.3641).

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Cross-attention fusion in TCF dynamically modulates semantic token representations using temporal embeddings, enabling fine-grained alignment of time and meaning within each event.
**Core assumption:** Temporal information should actively influence semantic features at token granularity; passive concatenation or addition is insufficient for complex time-semantic interactions.
**Evidence anchors:** Abstract mentions "cross-attention to align time and semantics within events"; equations (10)–(12) and TCF description in section 3.4; TPP-LLM baseline uses simple concatenation, whereas TPP-TAL's cross-attention yields large gains.

### Mechanism 2
**Claim:** MTBT injects per-head temporal biases computed from logarithmic bucketized time differences, enabling multi-scale temporal dependency modeling across events.
**Core assumption:** Attention weights should explicitly reflect temporal proximity; distinct attention heads can specialize in short-term, medium-term, and long-term temporal patterns.
**Evidence anchors:** Abstract mentions "per-head temporal biases based on time differences to model cross-event dependencies"; equations (14)–(21) detail bias computation and multi-scale design; prior works incorporate time into attention, but per-head bias and logarithmic bucketization are novel extensions.

### Mechanism 3
**Claim:** Plug-and-play integration of TCF and MTBT outputs into a frozen LLM preserves pretrained semantic knowledge while injecting temporal awareness, leading to efficient training and strong performance.
**Core assumption:** LLMs possess robust semantic reasoning but lack fine-grained temporal mechanisms; providing temporally enriched inputs is sufficient to activate temporal modeling without modifying internal weights.
**Evidence anchors:** Abstract states "explicitly aligns temporal dynamics with contextual semantics before feeding this information into the LLM"; section 3.6 describes the hybrid input format and frozen LLM; TPP-TAL avoids LoRA fine-tuning, showing simpler input-level adaptation can be effective.

## Architecture Onboarding

- **Component map:** Input Encoder → TCF Module → MTBT Module → LLM Interface → Output Heads
- **Critical path:** Raw events → TCF → MTBT → LLM input → LLM hidden states → prediction heads. Innovations lie in TCF and MTBT modules.
- **Design tradeoffs:**
  - TCF fusion: Cross-attention (most expressive, more parameters) vs additive (lightweight but uniform) vs concatenation (middle ground). Ablation shows cross-attention best on complex datasets.
  - MTBT: Per-head bias captures multi-scale patterns but increases parameters; shared bias reduces capacity. Logarithmic bucketization stabilizes training across wide time ranges but may lose fine distinctions if bucket count mismatched.
  - Integration: Plug-and-play avoids catastrophic forgetting and is compute-efficient, but may underutilize LLM’s layers compared to full fine-tuning.
- **Failure signatures:**
  - Removing TCF causes accuracy drop on datasets with diverse semantics (e.g., SOF, AMZ), indicating loss of fine-grained time-semantic alignment.
  - Removing MTBT degrades log-likelihood on sparse/long-interval datasets (e.g., US-EQ), showing need for global temporal biases.
  - Inappropriate bucket size: too few buckets on high-frequency data (SOF) hurts RMSE; too many on sparse data (US-EQ) reduces LL and Acc (Table 7).
  - If the frozen LLM is too small (e.g., <1B params) or pretrained on unrelated domains, gains may diminish.
- **First 3 experiments:**
  1. Main comparison: Evaluate TPP-TAL against TPP-LLM on four datasets using LL, Acc, RMSE. Results show substantial improvements (e.g., SOF LL -1.8482 → -0.4748).
  2. Ablation study: Ablate TCF and MTBT modules individually and compare fusion strategies within TCF and bias designs within MTBT. Demonstrates each component’s contribution.
  3. Hyperparameter sensitivity: Vary number of time buckets in MTBT to show performance sensitivity across datasets (Table 7). Identifies dataset-specific optimal bucket count.

## Limitations
- **Dataset and implementation details:** Preprocessing pipelines for each dataset are not fully described, and the baseline TPP-LLM implementation is not open-sourced, making exact reproduction uncertain.
- **Model complexity and generalization:** MTBT’s logarithmic bucketization is sensitive to dataset characteristics, potentially limiting robustness to distributional shifts.
- **Scalability to larger LLMs:** Effectiveness on much larger LLMs or different domains with varying temporal dynamics is unverified.

## Confidence

- **Mechanism 3 (Plug-and-play integration):** Medium
