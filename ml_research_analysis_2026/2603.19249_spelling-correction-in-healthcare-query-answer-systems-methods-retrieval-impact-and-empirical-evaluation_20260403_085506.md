# Spelling Correction in Healthcare Query-Answer Systems: Methods, Retrieval Impact, and Empirical Evaluation

## Quick Facts
- **arXiv ID**: 2603.19249
- **Source URL**: https://arxiv.org/abs/2603.19249
- **Reference count**: 6

## Executive Summary
User-generated health queries suffer from high spelling error rates (61.5% contain at least one error). This study evaluates four spelling correction methods (edit distance, conservative edit distance, context-aware, SymSpell) as preprocessing for medical QA retrieval over a corpus of professionally authored answers. Correcting only the queries yields substantial BM25 improvements (MRR +9.2%, NDCG@10 +8.3%). Conservative edit distance, which restricts corrections to edit-distance-1 changes with corpus frequency ≥5, achieves 86% of the maximum MRR gain while significantly reducing unnecessary changes (8.9% vs. 16.0%), making it the recommended choice for safety-critical healthcare applications. Corpus-only correction provides negligible benefit (+0.5% MRR) and slightly degrades TF-IDF retrieval.

## Method Summary
The experiment uses the TREC 2017 LiveQA Medical dataset (103 queries with relevance judgments) and the MedQuAD corpus (1,935 answer passages). A domain vocabulary is constructed from all corpus words appearing ≥2 times (8,201 terms). Four correction methods are applied: **conservative edit distance** (edit distance =1, corpus frequency ≥5), **standard edit distance** (≤2), **context-aware** (ranks candidates with context bonus, but converges to standard on this corpus), and **SymSpell** (precomputed delete-1/delete-2 dictionaries). Retrieval experiments compare original vs. corrected queries and corpus using BM25 (k1=1.5, b=0.75) and TF-IDF. Evaluation metrics include MRR, Recall@1/5/10, and NDCG@10. A manual error analysis using NIST paraphrases classifies corrections into: correct_fix, partial_improvement, unnecessary_change, harmless_synonym.

## Key Results
- Query correction with standard edit distance improves BM25 MRR by +9.2% and NDCG@10 by +8.3%.
- Conservative edit distance achieves 86% of maximum MRR gain while reducing unnecessary changes (8.9% vs. 16.0%).
- Corpus-only correction yields negligible MRR gain (+0.5%) and slightly harms TF-IDF retrieval.
- SymSpell shows minimal improvement due to limited coverage of medical vocabulary.

## Why This Works (Mechanism)
Spelling errors in user queries cause term mismatch with the professionally written corpus, leading to missed relevant passages. Correcting query tokens to high-frequency corpus terms improves lexical overlap, boosting recall and early precision under BM25. Conservative edit distance limits changes to edit-distance-1 with a frequency threshold, reducing over-correction (e.g., altering short common words) while still capturing most beneficial fixes. Corpus-only correction offers little because the source text is already clean; any changes may even distort term frequencies, harming TF-IDF. The lack of context-aware improvement suggests that in short medical queries, lexical matching alone is sufficient for effective retrieval.

## Foundational Learning
- **Spelling Correction**: String similarity via edit distance; SymSpell uses delete dictionaries for efficiency. Needed to align noisy queries with clean corpus terms.
  - *Quick check*: For misspelling "headake", does the method suggest "headache" (a corpus term)?
- **Retrieval Models**: BM25 (probabilistic) and TF-IDF (vector space). BM25 handles variable passage lengths via length normalization and term saturation.
  - *Quick check*: Index a sample corpus; BM25 scores should differ from TF-IDF for the same query.
- **Evaluation Metrics**: MRR (emphasizes top result), NDCG@10 (graded relevance), Recall@k. Essential for quantifying retrieval quality beyond simple accuracy.
  - *Quick check*: Compute MRR from a ranked list with binary relevance labels.
- **Domain Vocabulary Construction**: Filtering corpus terms by frequency (≥2) to build an 8,201-term lexicon for OOV detection.
  - *Quick check*: Count token frequencies; a term like "hypertension" must appear frequently.
- **Error Analysis Taxonomy**: Four categories (correct_fix, partial_improvement, unnecessary_change, harmless_synonym) to assess correction safety.
  - *Quick check*: Given a correction and a human paraphrase, classify whether the change was necessary or harmful.

## Architecture Onboarding
**Component Map**: Tokenization → OOV Detection → Spelling Correction (query side) → Retrieval Indexing (corpus) → Ranking. Corpus side: Tokenization → (optional correction) → Indexing.

**Critical Path**: Tokenize query → Identify OOV tokens → Apply chosen correction → Retrieve top‑k passages with BM25/TF-IDF → Return ranked list.

**Design Tradeoffs**:
- Standard edit distance (aggressive) vs. conservative (safe): Aggressive yields higher recall but risks over‑correction; conservative mitigates safety concerns with a modest gain reduction.
- Context‑aware correction adds complexity but showed no benefit, indicating lexical matching dominates in short medical queries.
- Query‑only correction is cheap and effective; corpus correction requires re‑indexing and offers negligible benefit.

**Failure Signatures**:
- Unnecessary_change rate >15% indicates over‑correction; switch to conservative edit distance.
- SymSpell modification rate <20% suggests limited medical term coverage; consider vocabulary augmentation.
- Degraded TF‑IDF after corpus correction signals term frequency distortion; avoid corpus correction for TF‑IDF.

## Limitations
- Tokenization rules (hyphens, numbers) are unspecified, affecting vocabulary and OOV detection.
- Tie‑breaking for multiple correction candidates is not defined, leading to variability.
- TF‑IDF parameters (e.g., sublinear tf, normalization) are missing, limiting replication of corpus correction results.
- Error analysis sample size (≤100 corrections) and annotator agreement are unreported, weakening confidence in safety metrics.

## Confidence
- **High**: Query correction improves BM25 retrieval (consistent across methods and metrics).
- **Medium**: Conservative edit distance achieves 86% of max MRR gain with reduced unnecessary changes (depends on tie‑breaking and manual analysis sample).
- **Low**: SymSpell minimal improvement claim (based on a single dataset/implementation).
- **Medium**: Corpus‑only correction negligible benefit (empirical but may vary with TF‑IDF settings).

## Next Checks
1. **Tokenization Alignment Check**: Tokenize queries and corpus using lowercase split on whitespace/punctuation; verify domain vocabulary size ≈8,201 and inclusion of common medical terms.
2. **Baseline Reproduction Check**: Compute BM25 MRR on original data; target ≈0.633. If off, check relevance judgment alignment and BM25 parameters (k1=1.5, b=0.75).
3. **Correction Rate Diagnostic**: For standard edit distance, measure proportion of queries modified and average tokens changed per query. If >40% modified, correction is aggressive; if <20%, OOV detection may be too strict.
