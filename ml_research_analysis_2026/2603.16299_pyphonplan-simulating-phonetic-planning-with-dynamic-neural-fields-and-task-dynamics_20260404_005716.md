# PyPhonPlan: Simulating phonetic planning with dynamic neural fields and task dynamics

## Quick Facts
- **arXiv ID**: 2603.16299
- **Source URL**: https://arxiv.org/abs/2603.16299
- **Reference count**: 0
- **Primary result**: Open-source toolkit combining dynamic neural fields and task dynamics demonstrates perceptual convergence in a phonetic shadowing simulation, with planning peak positions shifting from baseline (x=3.0) to shadowing (x=1.58) and partially persisting in washout (x=2.74).

## Executive Summary
PyPhonPlan is an open-source Python framework for computational models of phonetic planning, integrating dynamic neural fields (DNFs) with task dynamics. It provides modular components for activation fields (planning, perception, memory), inter-field coupling, gestural inputs, and tract-variable simulations via critically-damped harmonic oscillators. The toolkit is applied to a three-layer perception-planning-memory model of phonetic shadowing, showing that perceptual input drives systematic shifts in planning field peaks. These shifts persist after input removal, indicating interactive, stable dynamics. Tract variable trajectories derived from field peaks confirm corresponding articulatory changes, illustrating the framework’s capacity to model speech planning as a temporally principled, neurally grounded process.

## Method Summary
The framework implements 1D DNFs with local excitation and lateral inhibition to form stable activation peaks. Fields are coupled (e.g., perception excites planning) and receive gestural inputs as time-varying functions. Planning field peaks are extracted as time-varying targets for tract variables, each modeled as a critically-damped harmonic oscillator (damping ratio ζ=1) that generates smooth trajectories to targets. The shadowing simulation uses three fields (perception, planning, memory) with specific coupling weights; perceptual input targets a location at x=1.0, inducing a shift in the planning peak from its baseline at x=3.0. Washout removes input, testing persistence of the new planning state.

## Key Results
- Planning peak shifts from baseline (x=3.0) to first shadowing trial (x=1.58), converging toward the perceptual target.
- After washout, planning peak remains shifted (x=2.74), a -0.26 unit change from baseline, showing partial persistence.
- Tract variable trajectories mirror planning dynamics, confirming that field peak changes produce plausible articulatory motion.

## Why This Works (Mechanism)
Dynamic neural fields provide continuous, stable activation landscapes that can be biased by perceptual input without losing attractor states. Lateral inhibition ensures peaks remain localized, while coupling allows interactive perception-planning dynamics. Critically-damped oscillators translate discrete field peaks into smooth, naturalistic tract-variable trajectories without overshoot, adhering to principles of motor control. The memory field introduces a slowly decaying bias, enabling the system to retain a modified planning state after input cessation. Together, these components yield a temporally coordinated system where perception can subtly reshape motor plans, as seen in shadowing convergence and partial washout retention.

## Foundational Learning
**Dynamic Neural Fields (DNFs)**  
*Why needed*: Create stable, continuous activation representations for phonetic targets that resist noise and allow graded interactions.  
*Quick check*: Does a 1D DNF with local excitation and lateral inhibition produce a single, stationary bell-shaped peak without external input?

**Task Dynamics**  
*Why needed*: Maps symbolic/time-varying targets (field peaks) onto continuous articulatory motion using differential equations grounded in motor control.  
*Quick check*: Does a critically-damped oscillator (ζ=1) reach a target position smoothly without overshoot or oscillation?

**Phonetic Shadowing**  
*Why needed*: Empirical paradigm to test interactive perception-planning coupling; provides a behavioral phenomenon for model validation.  
*Quick check*: Does introducing a competing perceptual target cause the planning peak to shift toward it in simulation?

**Tract Variables**  
*Why needed*: Intermediate representations (e.g., lip aperture, tongue tip constriction) that bridge neural plans and physical articulation; used in speech motor models like TADA.  
*Quick check*: Are tract variable trajectories derived directly from planning field peak positions and velocities?

**Critically-Damped Harmonic Oscillators**  
*Why needed*: Ensure minimal-time, non-oscillatory movement to targets, aligning with observed articulatory smoothness.  
*Quick check*: For a given damping coefficient, does the system’s damping ratio equal 1?

**Gestural Inputs**  
*Why needed*: Provide external perturbations (e.g., heard speech) that drive the perception field and initiate interactive dynamics.  
*Quick check*: Can input functions be manually specified as time-varying signals to activate the perception field at desired times?

## Architecture Onboarding
**Component map**  
Perception Field → Planning Field ↔ Memory Field → Tract Variable Oscillators → Articulatory Output  
(plus: inter-field coupling weights, gestural input functions)

**Critical path**  
Gestural input excites Perception Field → coupled excitation shifts Planning Field peak → Planning Field peak becomes time-varying target for Tract Oscillator → oscillator generates smooth tract-variable trajectory.

**Design tradeoffs**  
- 1D fields trade biological richness for analytical clarity and stability; scaling to higher dimensions risks instability and loss of interpretability.  
- Manual input timing simplifies implementation but sacrifices autonomous temporal coordination (e.g., oscillator-based syllable timing).  
- Direct peak-to-oscillator mapping avoids complex inverse dynamics but lacks full articulator-to-tract-variable transformations of models like TADA.

**Failure signatures**  
- Field peaks split or drift (instability from poor inhibition/excitation balance).  
- Tract trajectories show overshoot or ringing (underdamped oscillators, ζ<1).  
- No planning shift occurs (insufficient coupling strength or input magnitude).  
- Washout fails to show partial persistence (memory field time constant too short or no self-excitation in planning).

**First three experiments**  
1. Replicate shadowing simulation: verify planning peak shift from x=3.0→1.58 on first trial and washout shift to x=2.74.  
2. Parameter sweep onPlanning-Perception coupling weight: find threshold for convergence and check for over-shift or instability.  
3. Extend planning field to 2D (e.g., lip aperture + tongue tip constriction): introduce a simple second dimension with cross-dimensional inhibition; test if the system maintains stable peaks and produces coordinated 2D trajectories.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How can input timing be dynamically generated instead of manually stipulated to improve temporal coordination in DNF models?
- **Basis in paper**: [explicit] "input timing is currently stipulated. Future versions could implement coupled oscillator models [32], conditions of satisfaction for input deactivation [33, 34], or competitive queuing for selection-activation dynamics [35, 36]."
- **Why unresolved**: Manual timing requires ad hoc parameter tuning and does not capture the intrinsic temporal dynamics of speech planning, such as oscillator-based syllable timing or goal satisfaction.
- **What evidence would resolve it**: Implementing one of the suggested timing mechanisms (e.g., coupled oscillators) and demonstrating that the model produces more naturalistic temporal patterns aligned with empirical speech timing data.

### Open Question 2
- **Question**: How can the task dynamics component be extended to include the full articulator-to-tract-variable mapping present in standard models, such as TADA?
- **Basis in paper**: [explicit] "the current task dynamic integration extracts time-varying targets from field peaks but lacks the full articulator-to-tract-variable mapping characteristic of standard models [5]."
- **Why unresolved**: Without this mapping, the toolkit cannot model the transformation from neural activation to muscle-based articulation, limiting physiological interpretability and comparison with articulatory measurements like EMA.
- **What evidence would resolve it**: Integrating the gestural score and muscle control model from TADA into PyPhonPlan, then validating that simulated tract variables produce plausible articulator trajectories consistent with empirical data.

### Open Question 3
- **Question**: How can DNFs be scaled to higher dimensions (2–4) to model multi-dimensional phonetic features while maintaining stability and interpretability?
- **Basis in paper**: [explicit] "DNFs do not scale well to much higher dimensions; while this encourages an interpretable and biophysically-grounded approach, it constrains modelling of high-dimensional problems and requires well-motivated theoretical commitments about which control variables to model."
- **Why unresolved**: Many speech phenomena involve multi-dimensional spaces (e.g., vowel quality in F1/F2, lip aperture and constriction), but 1D models cannot capture interactions across dimensions, limiting the scope of phonetic and phonological questions.
- **What evidence would resolve it**: Developing and testing multi-dimensional DNF architectures, showing they maintain stable dynamics and can simulate known multi-dimensional patterns (e.g., vowel coarticulation), and comparing with empirical data.

## Limitations
- Biological plausibility of DNF equations is not evaluated against neurophysiological data.
- Model parameters and coupling weights lack systematic validation against human articulatory/perceptual datasets; convergence metrics are self-consistent but externally ungrounded.
- Scalability to full phonological inventories, connected speech, or multilingual contexts is unexplored; software performance for large-scale simulations is unreported.

## Confidence
- **Toolkit implementation & modular design**: High (open-source codebase, clear architecture description).
- **Shadowing simulation results**: Medium (internally consistent within model dynamics, but no empirical validation).
- **Broader implications for speech research**: Low (claims about accessibility/reproducibility are potential until adoption/independent replication).
