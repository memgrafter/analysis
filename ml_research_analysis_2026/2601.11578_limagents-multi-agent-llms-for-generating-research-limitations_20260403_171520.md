# LimAgents: Multi-Agent LLMs for Generating Research Limitations
## Quick Facts
- arXiv ID: 2601.11578
- Source URL: https://arxiv.org/abs/2601.11578
- Reference count: 40
- Primary result: LimAgents, a multi-agent LLM framework, improves coverage of research limitations by up to 15.51% over zero-shot baselines, with Llama 3 8B +3 agents achieving 66.45% coverage on 2,700 NeurIPS papers.

## Executive Summary
LimAgents introduces a multi-agent system to automatically generate comprehensive limitation statements for research papers. It employs specialized agents (Extractor, Analyzer, Reviewer, Citation Agent) that process the paper and related literature, a Master that consolidates their outputs, and a Judge that scores quality via LLM-as-Judge. A self-feedback loop allows regeneration when quality is low. Evaluated on 2,700 NeurIPS papers, LimAgents significantly outperforms zero-shot LLMs, with even a small Llama 3 8B model with three agents surpassing zero-shot GPT-4o mini by 17 points. A single feedback iteration improves results; a second harms performance, particularly for smaller models.

## Method Summary
The framework orchestrates four role-specific agents. The Extractor harvests explicit limitation disclosures from the paper; the Analyzer infers methodological gaps not directly stated; the Reviewer adopts a peer-review perspective to critique rigor and validity; the Citation Agent uses retrieval-augmented generation (RAG) on cited and citing papers to enrich the analysis. The Master agent aggregates and synthesizes these contributions into a coherent list. A Judge agent evaluates the output against a ground truth (author statements + OpenReview comments) using pointwise LLM-as-Judge coverage. If the score falls below a threshold, a self-feedback loop triggers regeneration, potentially adjusting the Master's consolidation or prompting specific agents to revise. The study tests different agent counts (3 or 4) and model backbones (Llama 3 8B, GPT-4o mini) on 2,700 NeurIPS papers.

## Key Results
- Zero-shot LLMs produce superficial limitation statements, often echoing the authors' own disclosures.
- LimAgents with 3 agents (Llama 3 8B) achieves 66.45% coverage (+4.41% over its zero-shot baseline), while the 4‑agent GPT-4o mini version reaches 64.94% coverage (+15.51% over zero-shot).
- The 3‑agent Llama system outperforms zero-shot GPT-4o mini by approximately 17 percentage points.
- One feedback round improves output quality; a second round degrades performance, especially for smaller models.

## Why This Works (Mechanism)
Specialization allows each agent to focus on a distinct aspect of limitation generation: explicit extraction, implicit gap analysis, critical review, and external knowledge integration. This division mitigates the tendency of a single monolithic LLM to produce shallow or repetitive outputs. The Master agent's consolidation combines diverse contributions into a comprehensive set, while the Judge provides an automated quality signal that drives the self-feedback loop, enabling iterative refinement. RAG via the Citation Agent brings in broader context from the literature, surfacing limitations that may not be obvious from the paper alone. Together, these elements yield deeper, more varied limitation statements than zero-shot prompting.

## Architecture Onboarding
**Component map (plain text):**  
Paper -> Extractor -> Analyzer -> Reviewer -> Citation Agent -> Master -> Limitations  
Judge -> (coverage score) -> if below threshold: SelfFeedback -> (any agent) -> regenerate  
**Critical path:** The main generation flow runs sequentially through all four agents to produce a draft, which the Master refines. The Judge then scores the output; if the score is insufficient, the self‑feedback loop re‑invokes relevant agents (often the Master or earlier agents) to revise. The process may iterate once before finalizing.  
**Design tradeoffs:**  
- More agents increase coverage but incur higher computational cost and longer latency.  
- Feedback rounds improve quality up to a point; excessive rounds can degrade performance, especially with smaller models.  
- Model size: smaller models benefit more from the structured multi-agent scaffolding, while larger models may achieve comparable results with fewer agents.  
- RAG retrieval scope (cited vs citing papers, depth) balances relevance and noise.  
**Failure signatures:**  
- Performance drop after the second feedback iteration, particularly with Llama 3 8B.  
- Agent outputs conflicting or contradictory limitations.  
- Citation Agent retrieving irrelevant papers leading to off‑topic suggestions.  
- Judge mis‑alignment with human quality (over‑/under‑scoring).  
**Three first experiments:**  
1. **Baseline comparison:** Zero‑shot generation vs single‑agent (all roles combined) to gauge benefit of role separation.  
2. **Agent count study:** Compare 3‑agent (Extractor, Analyzer, Reviewer) vs 4‑agent (add Citation Agent) configurations on both model backbones.  
3. **Ablation analysis:** Systematically remove each agent type to quantify its impact on coverage and identify essential components.

## Limitations
- Ground truth combines author statements and OpenReview comments; may miss implicit or post-publication limitations.
- Evaluation relies on LLM‑as‑Judge coverage; its alignment with human judgments of usefulness or depth remains unknown.
- Corpus is limited to NeurIPS papers; findings may not generalize to other disciplines or publication venues.

- **Cross‑venue generalization:** Test LimAgents on a diverse set of conferences/journals (e.g., ACL, Nature, arXiv) to measure consistency of coverage gains.
