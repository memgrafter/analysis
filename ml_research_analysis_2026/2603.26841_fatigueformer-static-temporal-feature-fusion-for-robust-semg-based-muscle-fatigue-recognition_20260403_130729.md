# FatigueFormer: Static-Temporal Feature Fusion for Robust sEMG-Based Muscle Fatigue Recognition

## Quick Facts
- **arXiv ID:** 2603.26841  
- **Source URL:** https://arxiv.org/abs/2603.26841  
- **Reference count:** 40  
- **Primary result:** State-of-the-art fatigue recognition with F1-scores of 97.85% (20% MVC), 98.66% (60% MVC), 98.60% (80% MVC) and 60.41% cross-subject F1, outperforming baselines by >10% in low-MVC conditions.

## Executive Summary
Accurately recognizing muscle fatigue from surface electromyography (sEMG) is challenging due to noise and signal variability that change with contraction intensity (MVC level). FatigueFormer introduces a semi-end-to-end framework that separately processes static statistical features (grouped by fatigue-sensitive trends) and temporal sequences via parallel Transformer encoders, fusing their complementary representations. Cross-feature attention and a residual refinement path enhance stability across low- and high-MVC conditions. Evaluated on 30 participants performing isometric contractions at 20–80% MVC, it achieves near-perfect F1-scores and strong cross-subject generalization, with attention visualizations offering interpretable insights into fatigue dynamics.

## Method Summary
Raw sEMG is filtered (20–450 Hz band-pass, 50 Hz notch) and segmented into 0.5 s windows (0.25 s stride). For each window, 31 handcrafted time/frequency/time-frequency/wavelet/nonlinear features are extracted. Features are categorized into increasing‑type (positive fatigue trend) and decreasing‑type (negative trend) via linear regression (p < 0.05) against fatigue progression. Two parallel branches process these groups:  

- **Static encoder:** For a single window, feature vectors are tokenized (with a [CLS] token) and embedded. An independent Transformer (no positional encoding) models intra-window interactions, with a residual MLP path adding a stable baseline representation.  
- **Temporal encoder:** Sequences of 5 consecutive windows for each feature group are embedded, processed by a Transformer with positional encoding, and then engage in bidirectional cross‑feature attention. Temporal pooling yields a sequence‑level representation.  

Both branch outputs are projected to 2 D, concatenated, and passed through an MLP to produce a joint representation for classification. Auxiliary linear heads on the projected branch outputs, trained with loss weights λₛ = λₜ = 1, provide multi‑scale supervision. The model is trained with Adam (lr = 1e‑4) and early stopping.

## Key Results
- F1-scores: **97.85%** at 20% MVC, **98.66%** at 60% MVC, **98.60%** at 80% MVC.
- Baseline models are outperformed by **>10%** F1 in low‑MVC (20%) conditions.
- Cross‑subject, cross‑intensity (Cross‑MVC + L5SO) test: **60.41%** F1.

## Why This Works (Mechanism)

### Mechanism 1: Semi-End-to-End Stabilization
- **Claim:** A semi-end-to-end framework that separately processes static statistical features and temporal sequences via parallel encoders stabilizes performance across varying MVC levels by preventing noise‑dominated raw signals from directly destabilizing feature learning.  
- **Mechanism:** Handcrafted, fatigue‑sensitive statistical features (e.g., RMS, MF) provide a noise‑resilient, physiologically grounded foundation. These static descriptors compress raw sEMG into compact representations that suppress random fluctuations. A dedicated static encoder models intra‑window feature interactions. In parallel, a temporal Transformer processes sequences of these feature vectors to capture long‑range fatigue evolution. Fusion of these complementary pathways yields robustness: the static branch anchors learning in stable, interpretable features, while the temporal branch refines predictions with dynamic context.  
- **Core assumption:** Fatigue‑sensitive statistical features exhibit consistent, monotonic trends (increasing or decreasing) with fatigue progression across subjects, providing a distributionally stable input representation compared to raw sEMG.  
- **Evidence anchors:**  
  - Abstract: “deliberately combines saliency‑guided feature separation with deep temporal modeling… separately capture static and temporal feature dynamics, fusing their complementary representations to improve performance stability across low‑ and high‑MVC conditions.”  
  - Section 3.2: Statistical significance analysis (Pearson correlation, regression slope, p < 0.05) categorizes features into increasing/decreasing groups.  
  - Corpus: Weak direct evidence; neighbor papers focus on other sEMG applications but do not address the specific static‑temporal separation mechanism.  
- **Break condition:** If the statistical feature extraction fails to capture monotonic fatigue trends for a new population or muscle group (i.e., the “increasing/decreasing” grouping becomes inconsistent or non‑physiological), the static encoder’s input distribution shifts, likely degrading cross‑MVC generalization.

### Mechanism 2: Cross‑Feature Attention and Residual Refinement
- **Claim:** Cross‑feature attention between increasing‑ and decreasing‑type feature groups, coupled with a residual refinement path, enhances model stability by explicitly modeling their complementary physiological roles while preventing noise amplification in low‑SNR conditions.  
- **Mechanism:** The temporal encoder applies bidirectional cross‑attention, allowing the sequence of increasing‑type features to attend to the sequence of decreasing‑type features and vice versa. This captures coordinated physiological shifts. The static encoder uses a residual path where original feature vectors are processed by an MLP in parallel with the Transformer; this MLP path provides a stable, low‑capacity baseline representation that is added to the Transformer’s output. Under low‑MVC (high noise), the MLP path dominates, mitigating overfitting to transient fluctuations. Under high‑MVC (low noise, strong correlations), the Transformer’s complex feature interactions are better utilized.  
- **Core assumption:** Increasing and decreasing feature groups represent relatively independent physiological subspaces (e.g., amplitude vs. spectral/entropy changes) that provide complementary evidence for fatigue state, and their interaction patterns are consistent MVC‑level dependencies rather than noise artifacts.  
- **Evidence anchors:**  
  - Section 3.3: “Cross‑feature attention is applied bidirectionally… This process yields… which encode complementary temporal interactions.” “The MLP path serves two purposes: (1) it mitigates noise amplification under low‑MVC, low‑SNR conditions… (2) it provides a stable baseline representation for residual refinement.”  
  - Section 4.3 (ablation): Removing cross‑attention or the residual MLP path causes consistent performance degradation across all MVC levels, confirming their stabilizing roles.  
  - Corpus: Weak direct evidence; neighbor papers do not investigate this specific form of cross‑group attention or residual stabilization for fatigue recognition.  
- **Break condition:** If the predefined feature grouping is invalid for a new sEMG context (e.g., different muscle, pathology), cross‑feature attention could force inappropriate interactions, harming performance. The residual path’s benefit is contingent on the MLP providing a sufficiently stable baseline; if the static features themselves are highly non‑linear with fatigue in a new domain, the MLP may underfit.

### Mechanism 3: Multi‑Scale Supervision for Complementary Representations
- **Claim:** Multi‑scale supervision via auxiliary prediction heads on the static and temporal branches’ intermediate representations regularizes the model, encouraging the two encoders to learn distinct, complementary fatigue representations rather than collapsing into redundant solutions, which is critical for robust fusion across MVC conditions.  
- **Mechanism:** Separate linear classification heads are attached to the projected outputs of the static (`f'_static`) and temporal (`f'_temp`) branches before final fusion. Each head is trained with its own cross‑entropy loss alongside the main fused classifier’s loss. This forces each encoder to develop representations that are individually discriminative of fatigue states. The static encoder, excelling at high‑MVC, learns strong instantaneous feature correlations. The temporal encoder, critical for low‑MVC, learns robust sequential dynamics. Their outputs remain complementary, leading to a more informative fused representation `f_joint`.  
- **Core assumption:** Fatigue recognition benefits from two distinct, non‑redundant information sources: (1) the instantaneous distribution of handcrafted features within a window (static), and (2) the temporal evolution of those features across windows (temporal). These sources have different signal‑to‑noise characteristics across MVC levels.  
- **Evidence anchors:**  
  - Section 3.4: “This multi‑scale supervision strategy regularizes each feature space and encourages the two branches to learn complementary, fatigue‑sensitive representations.”  
  - Section 4.3 (ablation): “Removing multi‑scale supervision reduces performance across all contraction levels, demonstrating that the auxiliary heads provide effective gradient regularization and encourage the two branches to learn complementary representations.”  
  - Corpus: Weak direct evidence; neighbor papers use multi‑task or multi‑branch learning for different purposes (e.g., gesture decoding, multi‑muscle coordination) but not specifically for static‑temporal fusion in fatigue.  
- **Break condition:** If the true underlying fatigue dynamics for a new task are best captured by a single, unified timescale (e.g., very rapid fatigue onset with no stable “static” window), the enforced separation may force the model to learn suboptimal, artificial representations, harming generalization.

## Foundational Learning
- **Concept: Transformer Self‑Attention & Cross‑Attention**  
  *Why needed here:* The entire temporal encoder and the static encoder’s interaction modeling rely on multi‑head attention mechanisms. Understanding how queries, keys, and values compute weighted sums over sequences is essential to grasp how the model captures long‑range dependencies and feature‑group interactions.  
  *Quick check:* How does positional encoding in the temporal encoder (for time‑order) differ conceptually from the lack of positional encoding in the static encoder (for feature‑index order), and why is this appropriate?

- **Concept: sEMG Signal Properties & Fatigue Manifestations**  
  *Why needed here:* The model’s design is predicated on known physiological phenomena: amplitude increase (increasing‑type features like RMS) and median frequency decrease (decreasing‑type features like MF) during fatigue. Understanding signal‑to‑noise ratio (SNR) challenges (e.g., low MVC = low amplitude, high relative noise) explains why different model components are needed for different MVC levels.  
  *Quick check:* Why might the same sEMG feature (e.g., RMS) show an increasing trend with fatigue at high MVC, but be too noisy to be reliably monotonic at very low MVC?

- **Concept: Semi‑End‑to‑End vs. Fully End‑to‑End vs. Feature‑Based Learning**  
  *Why needed here:* FatigueFormer’s core innovation is its hybrid approach. The learner must understand the trade‑offs: handcrafted features offer stability/interpretability but limited expressiveness; raw end‑to‑end learning offers expressiveness but is brittle to noise and subject variability. This architecture deliberately combines their strengths.  
  *Quick check:* What is the primary risk of a fully end‑to‑end CNN‑LSTM model on raw sEMG for low‑MVC fatigue detection, and how does feeding it statistical features instead mitigate that risk?

## Architecture Onboarding
**Component map:**  
Raw sEMG → Filtering → Windowing → Feature Extraction (31 features, grouped into increasing/decreasing) → Parallel processing:  
- Static branch: Feature vectors (per window) → Tokenizer (embedding + [CLS]) → Transformer (no PE) → [CLS] token + Residual MLP → f_static.  
- Temporal branch: Sequences of 5 windows for each group → Projection → Transformer (with PE) → Bidirectional cross‑feature attention → Temporal pooling → f_temp.  
Fusion: Project f_static, f_temp to 2 D each → Concatenate → MLP → joint representation f_joint → Classifier. Auxiliary heads on projected f_static and f_temp.

**Critical path:** The dual‑branch processing and fusion is the core novel path; failure in either branch’s ability to learn its designated representation (static intra‑window or temporal inter‑window) degrades overall performance, as shown by ablations.

**Design tradeoffs:**  
- *Stability vs. Expressiveness:* Handcrafted features (stability) vs. raw data learning (expressiveness); design chooses a middle ground: features are handcrafted, but their interactions and temporal dynamics are learned.  
- *Branch Capacity:* Using identical Transformer architectures for both branches simplifies design but may not be optimal; the static branch might benefit from a shallower network, while the temporal branch’s depth is critical.  
- *Computational Cost:* Dual‑encoder design and cross‑attention increase parameters (~11 M) vs. a single‑stream model. The feature extraction engine’s efficiency (40× speedup) is a necessary counter‑balance for real‑time feasibility.  
- *Supervision Strategy:* Multi‑scale loss adds complexity but prevents branch collapse. The fixed λ weights (λₛ=λₜ=1) are a simple default; subject‑specific tuning might yield gains.

**Failure signatures:**  
- *Symptom:* Performance plummets specifically at 20% MVC compared to 80% MVC.  
  *Likely cause:* Temporal encoder failing to capture subtle dynamics. Check temporal attention maps for diffuse, uninformative patterns. Verify temporal window length T=5 is sufficient.  
- *Symptom:* Poor cross‑subject generalization (low L5SO F1).  
  *Likely cause:* Static features not sufficiently subject‑invariant. Check if feature extraction pipeline is robust to electrode shift/impedance. Investigate if the residual MLP path in the static encoder is effectively stabilizing.  
- *Symptom:* Model predictions are unstable across training runs (high variance in F1).  
  *Likely cause:* Training instability, possibly from the Transformer without dropout or from loss weighting imbalance. Check gradient norms of the two branches; imbalance may require tuning λₛ, λₜ.

**First 3 experiments:**  
1. **Component Isolation Ablation:** Train the full model vs. `w/o Temporal Encoder` vs. `w/o Static Encoder` across all MVC levels. Validate the claimed specialization: temporal removal hurts low MVC most; static removal hurts high MVC most.  
2. **Attention Visualization Sanity Check:** Generate temporal attention rollout maps and static self‑attention maps for a few test samples. Verify (a) temporal attention shifts from early to later windows as MVC increases, (b) static self‑attention patterns change across MVC levels, and (c) cross‑attention magnitudes are lower than self‑attention.  
3. **Feature Trend Validation:** On a held‑out subset of your own (or provided) data, reproduce the statistical significance analysis (Sec 3.2). Compute Pearson correlation and regression slopes for all 31 features against fatigue labels. Confirm that the majority of features assigned to “increasing” and “decreasing” groups show the expected sign with p < 0.05.

## Open Questions the Paper Calls Out
1. **How does FatigueFormer generalize to dynamic, non‑isometric contractions?**  
   *Basis:* The dataset and experimental protocol only include isometric contractions at fixed angles. *Why unresolved:* Dynamic contractions introduce greater signal variability and non‑stationarities; the model’s robustness in such conditions remains unknown. *Needed evidence:* Collect a diverse dataset of dynamic sEMG recordings across various movements and intensities, apply FatigueFormer with appropriate temporal segmentation, and report performance compared to baselines.

2. **Can the predefined grouping of features into increasing‑ and decreasing‑type based on statistical trends be replaced by a data‑driven, adaptive grouping?**  
   *Basis:* Features are manually categorized using regression slope significance. *Why unresolved:* Fixed grouping may not capture complex, context‑dependent feature relationships; learning grouping could improve representation. *Needed evidence:* Replace the static grouping with a learned clustering module (e.g., attention‑based feature grouping), compare performance and attention patterns against the original design.

3. **Do subjective RPE‑based labels for fatigue states introduce noise that affects model training and interpretability?**  
   *Basis:* Fatigue states are defined by Borg’s RPE scale, which is subjective and participant‑dependent. *Why unresolved:* Subjective labels may not align perfectly with actual muscle fatigue, leading to inconsistent training signals; objective measures could provide more consistent ground truth. *Needed evidence:* Simultaneously record objective fatigue metrics (e.g., force decline, median frequency shift), relabel data based on these criteria, retrain models, and compare performance and attention visualizations.

4. **What is the theoretical mechanism by which the residual MLP path in the static encoder reduces noise amplification under low‑MVC, low‑SNR conditions?**  
   *Basis:* The residual path is claimed to mitigate noise amplification but no theoretical analysis is provided. *Why unresolved:* Understanding the stabilization effect could inform the design of robust architectures for noisy biosignals. *Needed evidence:* Conduct controlled experiments with synthetic sEMG signals at varying SNR levels, ablate the residual path, analyze gradient magnitudes, attention entropy, or derive theoretical bounds on noise sensitivity.

5. **Can domain adaptation or few‑shot personalization techniques further improve FatigueFormer’s cross‑subject generalization?**  
   *Basis:* Cross‑subject performance (60.41% F1) is substantially lower than within‑subject results, with challenges due to distribution shift. *Why unresolved:* The model’s robustness to inter‑subject variability is limited; adaptation could narrow the gap. *Needed evidence:* Integrate domain adversarial training, meta‑learning, or fine‑tuning with a small amount of subject‑specific data, and evaluate on the same cross‑subject protocol to quantify improvement.

## Limitations
- The self‑collected dataset is not publicly available; external verification requires a new, costly data acquisition effort.  
- The core increasing/decreasing feature grouping (derived from one cohort) may not generalize to other muscles, populations, or pathologies.  
- Hyperparameters (embedding dimension = 256, temporal window length = 5, loss weights = 1) were used without sensitivity analysis; optimal values may differ for new datasets.

## Confidence
- **Mechanism Efficacy** (semi‑end‑to‑end design, cross‑attention, residual path, multi‑scale loss): **High** (supported by strong internal ablations).  
- **Physiological Assumptions** (monotonic feature trends, MVC‑dependent noise): **Medium** (based on a single dataset; limited external corpus support).  
- **Cross‑Subject Generalization** (robustness to subject variability): **Low** (single split; performance drops significantly in cross‑subject tests).
