# CaReFlow: Cyclic Adaptive Rectified Flow for Multimodal Fusion

## Quick Facts
- **arXiv ID:** 2602.19140
- **Source URL:** https://arxiv.org/abs/2602.19140
- **Reference count:** 40
- **Primary result:** Achieves state-of-the-art performance on multiple benchmarks: CMU-MOSI (Acc7 50.6, Acc2 89.8), CH-SIMS-v2 (Acc5 57.9), UR-FUNNY and MUStARD (gains >3 and >2.5 points over best baselines).

## Executive Summary
CaReFlow tackles the modality gap in multimodal affective computing by reformulating it as a distribution mapping problem solved via rectified flow. The method introduces three synergistic innovations: one-to-many mapping to expose each source modality sample to the global target distribution, adaptive relaxed alignment to impose sample- and label-aware constraints, and cyclic rectified flow to preserve modality-specific information through backward reconstruction. These components yield significant performance improvements—up to 4 points over prior art—and visualizations confirm a substantial reduction in feature-space modality discrepancy. The framework also enables efficient one-step inference, avoiding the recursive sampling required by diffusion models.

## Method Summary
CaReFlow maps source modality features (audio, visual) into the language modality space using rectified flow, which learns straight ODE trajectories. Training minimizes a combined loss comprising the downstream task loss, a forward rectified flow loss (L_f) that aligns distributions, and a backward rectified flow loss (L_b) that reconstructs original source features. The forward loss employs one-to-many mapping: each source point is paired with multiple target points drawn from the entire target pool (including cross-sample pairs at ratio β). An adaptive margin η modulates the loss: η = 0 for same-sample pairs (strict) and η = ε + ||y_i−y_j||² for others (relaxed), using label distance as a semantic proxy. The backward loss enforces cyclic consistency, ensuring the transformed representation retains source-specific cues. At inference, a single forward Euler step (or two) maps each modality to the language domain; the aligned features are then fused (e.g., concatenated) and passed to a task predictor.

## Key Results
- **CMU-MOSI:** Acc7 = 50.6, Acc2 = 89.8, surpassing the previous SOTA (DLF) by >1 point.
- **CH-SIMS-v2:** Acc5 = 57.9, representing a gain of >4 points.
- **UR-FUNNY & MUStARD:** Outperform the best baselines by >3 and >2.5 points, respectively.

## Why This Works (Mechanism)

### Mechanism 1: One-to-many mapping exposes source to global target distribution
- **Claim:** One-to-many mapping exposes each source modality data point to the overall target distribution, mitigating the issue of insufficient paired data and enabling robust distribution transformation.
- **Mechanism:** Instead of constructing one-to-one pairs from the same sample, the forward rectified flow randomly samples multiple target points from the global target distribution p_m2 for each source point. This is implemented by including cross-sample pairs (at a ratio β) during training (Eq. 2), thus allowing a single source point to learn from the diversity of the entire target distribution.
- **Core assumption:** The global target distribution is sufficiently structured to guide transformation; aligned pairs need not be sample-specific.
- **Evidence anchors:** The abstract states that CaReFlow "leverage[s] the 'one-to-many mapping' strategy … allows each data point of the source modality to observe the overall target distribution." Section 3.3.1 explains that "rectified flow randomly selects many data pairs from two distributions … enables the data points from the source modality to access the global distribution information of the target modality." Corpus analysis shows low similarity (average FMR = 0.506) and zero citations for neighboring works, indicating this specific mechanism is novel in the immediate literature.
- **Break condition:** If the global target distribution is highly heterogeneous (e.g., language embeddings spanning multiple affective categories without supervision), one-to-many mapping might introduce noise, causing the source distribution to overgeneralize and lose discriminative detail.

### Mechanism 2: Adaptive relaxed alignment enforces stricter constraints for semantically correlated pairs
- **Claim:** Adaptive relaxed alignment achieves precise mapping for pairs with high semantic correlation while avoiding forcing unrelated points together, without requiring recursive training.
- **Mechanism:** A margin η_m1,m2 modulates the rectified flow loss (Eq. 7). For pairs from the same sample (η = 0), the loss is strict (standard squared error). For pairs from different samples/categories, a relaxed margin (η = ε + ||y_i−y_j||²) permits larger error, preventing the model from being forced to align semantically unrelated points.
- **Core assumption:** Label distance (||y_i−y_j||²) is a valid proxy for semantic similarity in feature space; samples with similar labels have more alignable distributions.
- **Evidence anchors:** Section 3.3.1 states the method "enforces stricter rectification for pairs belonging to the same sample, while applying a relaxed constraint for pairs from different samples or categories." Section 4.3 (Ablation) shows removing adaptive relaxed alignment (W/O Adaptive Relaxed Alignment) causes performance drops, implying its contribution.
- **Break condition:** If label semantics are not smoothly embedded in the feature space (e.g., categorical labels with no ordinal relationship), using ||y_i−y_j||² as a similarity measure could misguide alignment. In binary sentiment, setting different/same category distance = 1 may be too coarse.

### Mechanism 3: Cyclic rectified flow prevents information loss via backward reconstruction
- **Claim:** Cyclic rectified flow (forward + backward) prevents loss of modality-specific information by ensuring transformed features can reconstruct original source features.
- **Mechanism:** After forward mapping X_m → X_m,l, a backward rectified flow is trained to map X_m,l back to X_m (Eq. 11). The backward loss L_b updates the forward drift force (via X_m,l gradients), encouraging X_m,l to retain information necessary for reconstruction.
- **Core assumption:** Information loss during distribution mapping is the primary reason for degraded fusion; reconstruction consistency preserves modality-specific discriminative cues.
- **Evidence anchors:** The abstract mentions "cyclic rectified flow to prevent information loss via backward mapping … ensure the transferred features can be translated back to the original features." Section 3.3.2 notes it "ensures that the multimodal representations can learn sufficient modality-specific information." Section 4.3 (Ablation) shows removing cyclic flow (W/O Cyclic Information Flow) causes significant performance declines.
- **Break condition:** If the source modality (X_m) has high entropy or noisy features, the cyclic constraint might force X_m,l to preserve irrelevant details, harming target-domain alignment. The balance between forward and backward losses (α_f, α_b) is critical.

## Foundational Learning
- **Rectified Flow & Straight-Line ODEs**: Why needed: CaReFlow’s core is mapping distributions via learned straight trajectories, which differs fundamentally from stochastic diffusion and enables single-step inference. Quick check: How does rectified flow’s training objective (minimizing MSE between predicted and true velocity) differ from score-based diffusion’s score matching? Why does rectified flow enable faster sampling?
- **Contrastive Learning for Modality Alignment**: Why needed: CaReFlow is often contrasted with contrastive methods; one-to-many mapping conceptually relates to constructing many positive pairs but operates within a continuous ODE framework. Quick check: What is the key limitation of standard contrastive learning (within-sample pairs) that one-to-many mapping addresses? How does adaptive relaxed alignment differ from contrastive learning’s uniform treatment of positives?
- **Ordinary Differential Equation (ODE) Solver Discretization**: Why needed: CaReFlow uses Euler steps for inference; understanding discretization error and why a straight flow reduces the number of steps is crucial for efficiency claims. Quick check: If the learned flow path is perfectly straight, how many Euler steps are theoretically needed to go from t = 0 to t = 1? Why does the paper use two steps empirically?

## Architecture Onboarding
Component map: Unimodal Feature Extractors (frozen) -> Drift Force Network (V_forward) -> Language-aligned feature (X_m,l) -> Fusion Network (concatenation + MLP) -> Task Predictor. Additionally, V_backward maps X_m,l back to the original source feature for the cyclic loss.

Critical path:
1. Precompute frozen unimodal features using pre-trained encoders (e.g., BERT for text, CNN for audio/video).
2. Train forward and backward drift force networks with the combined loss: downstream task loss + α_f · L_f (forward rectified flow with adaptive margins) + α_b · L_b (backward rectified flow using only same-sample pairs).
3. Freeze the drift networks; extract transformed features for all samples.
4. Train the fusion network and task predictor on the downstream task loss only.

Design tradeoffs:
- Simplicity vs. expressiveness: Using MLPs for drift networks and a simple concatenation fusion keeps parameters low (~185 M) but may limit modeling of complex multimodal interactions compared to tensor or graph fusion.
- Causality vs. information: Detaching inputs to V ensures distribution mapping does not corrupt unimodal features; yet the backward loss updates V via X_m,l gradients, balancing target alignment with source reconstruction.
- One-to-many noise: The relaxed alignment (η>0) for cross-sample pairs introduces label-based granularity; this requires meaningful label distances and may fail for tasks with unstructured labels.

Failure signatures:
1. Modality-specific collapse: α_b too high forces V to focus solely on reconstruction, leaving transformed features close to the source and failing to close the modality gap.
2. Alignment collapse: α_f too low or β (cross-pair ratio) too high leads to poor forward training; X_m,l never approaches the language distribution.
3. Label-space mismatch: For ambiguous or noisy labels, the Euclidean label distance may misguide the adaptive margin, pushing semantically similar pairs apart.

First 3 experiments:
1. Ablation study (Table 3): Remove distribution alignment, cyclic flow, adaptive alignment, or one-to-many mapping individually to quantify each component’s contribution on CMU-MOSI and CH-SIMS-v2.
2. Hyperparameter sweep (Figure 6): Vary β (cross-pair ratio), Euler steps, α_f, α_b on CH-SIMS-v2 to identify robust ranges.
3. Fusion comparison (Table 5): Replace the default fusion with tensor, graph, or low-rank fusion while keeping CaReFlow fixed, to assess whether gains can be further improved.

## Open Questions the Paper Calls Out
- **Open Question 1:** How do the three core components of CaReFlow—one-to-many mapping, adaptive relaxed alignment, and cyclic rectified flow—interact and contribute relatively to the overall performance gain, given that their ablations are evaluated in isolation? The paper presents separate ablation studies but does not investigate their combined or interactive effects. The model is trained with a joint loss, implying potential dependencies that remain unanalyzed.
- **Open Question 2:** Does the adaptive relaxed alignment mechanism provide different benefits for modality pairs from the same sample versus the same category (but different samples), and is the label-distance-based margin (Eq. 8) the optimal weighting scheme? While the design is explicit, the evaluation does not stratify performance based on the type of pair. It is unclear if the label-distance heuristic effectively captures semantic similarity for relaxation across all tasks or if a learned similarity metric would be superior.
- **Open Question 3:** Can the CaReFlow framework be effectively applied when there is no linguistically dominant modality, such as in purely visual‑acoustic tasks or with >2 modalities, and does the assumption of mapping to a single "target" distribution limit its generalizability? All experiments use MAC datasets where language is a core modality; the paper does not test scenarios where language is absent or where all modalities are equally important.

## Limitations
- **Reproducibility gaps:** Exact unimodal encoder architectures, full hyperparameter values (β, ε, α_f, α_b), optimizer settings, and label-distance computation for classification tasks are unspecified, hindering exact replication.
- **External validation:** Neighboring works show low relatedness (average FMR = 0.506) and zero citations, indicating limited community vetting of the proposed mechanisms.
- **Theoretical assumptions:** Reliance on Euclidean label distance as a semantic proxy may fail for non‑ordinal or noisy labels; the cyclic constraint’s sensitivity to source‑modality noise remains untested.

## Next Checks
1. **Break-condition stress test:** Train on a variant of CMU‑MOSI where language embeddings are scrambled across affective categories to maximize target heterogeneity; measure performance drop versus standard MOSI to confirm one-to-many mapping’s sensitivity to target distribution structure.
2. **Label-distance ablation:** Replace the margin η = ε + ||y_i−y_j||² with (a) a fixed binary same/different margin, (b) a label co‑occurrence matrix, and (c) a learned contrastive metric; evaluate on CH‑SIM‑S‑v2 to identify the optimal similarity proxy.
3. **Cyclic loss sensitivity sweep:** On UR‑FUNNY, vary α_b ∈ {0.01, 0.1, 1, 10} while fixing α_f=10; track reconstruction loss L_b, alignment loss L_f, and accuracy to pinpoint regimes where increasing α_b helps or harms performance.
