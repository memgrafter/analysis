# Quantifying non deterministic drift in large language models
## Quick Facts
- **arXiv ID**: 2601.19934
- **Source URL**: https://arxiv.org/abs/2601.19934
- **Reference count**: 1
- **Primary result**: Baseline behavioral drift persists even at temperature 0.0: gpt-4o-mini yields distinct outputs in ~24% of exact repeats (Jaccard ~0.89), while llama3.1-8b varies in ~9% (Jaccard ~0.97); near-universal drift occurs at temperature 0.7.

## Executive Summary
This paper investigates baseline behavioral drift—the variability in outputs when all decoding parameters are held constant—in large language models. The authors perform repeated-run experiments on two models: gpt-4o-mini via OpenAI’s API and llama3.1-8b locally using vLLM. They test five prompt categories (underspecified summaries, underspecified advice, light constraints, style prompts, hard constraints) under three modes (exact repeats, perturbed inputs, reuse) and two temperature settings (0.0 and 0.7). Drift is quantified via unique output fraction and pairwise Jaccard similarity.

The results reveal that non-determinism is inherent even at temperature 0.0: gpt-4o-mini produced distinct outputs in approximately 24% of exact repeats (average Jaccard 0.89), while llama3.1-8b varied in about 9% (average Jaccard 0.97). Perturbations exacerbate drift, whereas reuse mode slightly reduces it. At temperature 0.7, drift becomes nearly universal, with unique fractions around 0.99 and Jaccard scores between 0.47 and 0.71. The API-served model exhibits systematically higher baseline drift. These findings highlight that LLM inference is not fully deterministic, challenging strict reproducibility and necessitating careful experimental design.

## Method Summary
The experiment uses two model setups: gpt-4o-mini (snapshot 2025-05-01) via OpenAI Chat Completions API, and llama3.1-8b base loaded locally with vLLM and Hugging Face Transformers 4.36 in bfloat16 on a single NVIDIA A100. Five manually curated prompt categories (underspecified summaries, underspecified advice, light constraints, style prompts, hard constraints) yield two datasets: a “gapfill” set (20 prompts per category, 100 total) and a “small battery” (5 per category, 25 total). For each prompt, the model is invoked multiple times: 30 repeats for gapfill, 20 for small battery. Three prompting modes are used: (1) exact: identical prompt; (2) perturbed: synonym substitution or rephrasing; (3) reuse: previous model output included in the next prompt. Decoding settings are fixed: max_tokens=512, top_p=1.0, and temperature either 0.0 or 0.7. Local inference uses fixed random seeds; the API does not expose seeding, so retries (up to 3) handle transient errors. Runs resulting in API errors or content refusals are discarded. Drift metrics computed are: unique output fraction (distinct outputs / total runs), average pairwise Jaccard similarity of tokenized outputs, and word count statistics.

## Key Results
- Even at temperature 0.0, drift is present: gpt-4o-mini produced distinct outputs in ~24% of exact repeats (mean Jaccard ~0.89), while llama3.1-8b varied in ~9% (mean Jaccard ~0.97).
- At temperature 0.7, drift is nearly universal: unique fractions ~0.99, Jaccard similarity ~0.47–0.71.
- Perturbing inputs increases drift; reuse mode marginally reduces it. The API-served model exhibits systematically higher baseline drift.

## Why This Works (Mechanism)
The paper does not experimentally isolate the root causes of baseline drift; however, the observed patterns align with known sources of nondeterminism in LLM inference. Hardware-level floating-point operation ordering on GPUs, dynamic request scheduling in cloud services, and tie-breaking during sampling even at temperature 0.0 can introduce variability. The higher drift for the API model likely reflects infrastructure heterogeneity and lack of seed control. The slight reduction under reuse suggests that incorporating the previous output stabilizes the context, reducing branching in token probabilities. Persistence of drift at temperature 0.0 underscores that full determinism is unattainable under typical inference setups.

## Foundational Learning
- **Temperature**: A scaling factor applied to model logits before softmax; higher values increase randomness in token selection. *Why needed*: The study manipulates temperature to assess its impact on drift and demonstrates that drift persists even at 0.0. *Quick check*: If temperature = 0.0, which token is typically chosen? (The one with highest logit probability, yielding deterministic output unless ties exist.)
- **Top-p (Nucleus) Sampling**: A stochastic decoding method that samples from the smallest set of tokens whose cumulative probability exceeds p, discarding the rest. *Why needed*: The paper fixes top_p=1.0 to disable truncation, isolating temperature’s effect. *Quick check*: What is the effect of setting top_p=0.9? (It restricts sampling to the top tokens covering 90% of probability mass.)
- **Jaccard Similarity**: A set-based metric equal to the size of the intersection divided by the size of the union of two sets (e.g., word tokens). *Why needed*: It quantifies lexical overlap between repeated outputs, providing a drift measure complementary to unique fraction. *Quick check*: If two outputs share all words, Jaccard = 1; if they share none, Jaccard = 0.
- **Infrastructure-Induced Non-Determinism**: Variability introduced by hardware (e.g., non-associative floating-point reductions on GPUs) or service-level factors (e.g., request scheduling, batch composition) even when software seeds are fixed. *Why needed*: Explains why the API model shows higher baseline drift and why local drift is not zero at T=0.0. *Quick check*: Name one reason a GPU might produce different results across runs with identical inputs and seeds. (Answer: Atomic operations or non-deterministic kernel execution order.)

## Architecture Onboarding
**Component map**:  
Local pipeline: Prompt -> vLLM server (Transformers, bfloat16) -> Llama 3.1 8B model -> Output (max 512 tokens)  
API pipeline: Prompt -> OpenAI Chat Completions endpoint (gpt-4o-mini-20250501) -> Output (max 512 tokens)  
An experiment controller orchestrates repeats and modes.

**Critical path**: (1) prepare prompt, (2) submit to model with fixed decoding parameters, (3) receive raw output, (4) store output, (5) repeat for required iterations (30 or 20), with mode-specific modifications (perturbation or reuse). The generation step (2) is where inherent nondeterminism manifests; the controller must log all outputs accurately.

**Design tradeoffs**:
- API vs local: API simplifies access but lacks seed control and may introduce service variability; local allows strict seeding but requires hardware and setup.
- Temperature choices: 0.0 minimizes drift but still shows baseline; 0.7 maximizes diversity but yields near-total drift.
- Repeat count: more repetitions improve drift estimation but increase API cost and time; the study uses 20–30 repeats as a compromise.
- Prompt category selection: five categories cover diverse scenarios but the exact prompts are undisclosed, limiting reproducibility.

**Failure signatures**:
- For llama3.1-8b at T=0.0, a unique fraction significantly above the reported 9% (e.g., >20%) suggests misconfigured seeds, nondeterministic library versions, or GPU settings.
- For gpt-4o-mini, widely varying drift metrics across time windows may indicate API backend changes or queuing effects.
- If Jaccard similarity is extremely low even at T=0.0, check tokenization consistency (e.g., whitespace vs subword) or output truncation.

**Three first experiments**:
1. Determinism baseline: Run a fixed prompt 50 times on llama3.1-8b with T=0.0 and fixed seed; confirm unique fraction ~0.09 and Jaccard ~0.97. Investigate any deviation.
2. Tokenization check: Compute Jaccard using both whitespace splitting and the model’s tokenizer; compare values to determine sensitivity and align with paper’s method.
3. API drift monitoring: Submit the same prompt to gpt-4o-mini at T=0.0 in rapid batches; track drift metrics per batch to detect temporal instability.

## Limitations
- Undisclosed prompt set: the exact prompts used are not provided, making independent replication difficult and obscuring the influence of prompt design on drift.
- API-side nondeterminism: the study cannot control or measure rate limiting, request queuing, or version drift, which may inflate baseline drift for gpt-4o-mini.
- Jaccard tokenization: the method for tokenizing outputs (e.g., whitespace, lowercasing, subwords) is unspecified, leaving ambiguity in the reported similarity scores.

## Confidence
- Baseline drift at T=0.0: Medium
- gpt-4o-mini > llama3.1-8b drift: Medium
- Perturbation/reuse effects: Low
- High-T drift (0.7): High
