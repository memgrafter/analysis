# VB: Visibility Benchmark for Visibility and Perspective Reasoning in Images

## Quick Facts
- **arXiv ID**: 2603.06680
- **Source URL**: https://arxiv.org/abs/2603.06680
- **Reference count**: 19
- **Primary result**: Best composite scores: GPT-4o and Gemini 3.1 Pro (0.728); best open-source: Gemma 3 12B (0.505) exceeds Claude 3.7 Sonnet (0.476).

## Executive Summary
VB is a benchmark designed to evaluate whether vision-language models can accurately judge the visibility of claims in images and abstain when uncertain. It comprises 100 families, each built with a 2×2 design that crosses a minimal image edit with a minimal text edit, yielding 300 headline evaluation items with strict XOR gold labels. Models must output VISIBLY_TRUE, VISIBLY_FALSE, or ABSTAIN, along with a reason code and a confidence score. Results show that top closed-source models (GPT-4o and Gemini 3.1 Pro) achieve a composite score of 0.728, while the best open-source model (Gemma 3 12B) scores 0.505. The benchmark uncovers that six of nine models exhibit higher robustness to text flips than to image flips, and confidence calibration varies widely, with some models displaying anti‑informative confidence rankings.

## Method Summary
The task presents an image and a short yes/no question to a model, which must respond with a JSON object containing a label (VISIBLY_TRUE, VISIBLY_FALSE, or ABSTAIN), a reason code from a fixed taxonomy (when abstaining), and a confidence score in [0,1]. The dataset includes 100 families; each family contains a base image and question, an image‑only edit, a text‑only edit, and a double edit. The first three cells form the headline set (300 items). Evaluation uses Confidence‑Aware Accuracy (CAA, α=0.25), Minimal Edit Flip Rates (I_MEFR, T_MEFR), a composite FinalScore (0.70·CAA + 0.15·MEFR + 0.10·SelRank + 0.05·ToMAcc), and additional diagnostics (SelRank, DFAcc). Reproduction requires iterating over items, sending image+prompt to the model, parsing the JSON reply, and computing metrics. Unknowns include exact model identifiers, prompt formatting (system/assistant roles), open‑source inference parameters (image preprocessing, generation settings), and fallback handling for out‑of‑range confidence values.

## Key Results
- GPT-4o and Gemini 3.1 Pro achieve the highest composite score of 0.728; Gemini 2.5 Pro scores 0.678.
- Among open‑source models, Gemma 3 12B leads with 0.505, surpassing Claude 3.7 Sonnet (0.476).
- Six of the nine models show greater robustness to text flips than to image flips (higher T_MEFR vs I_MEFR).
- Confidence calibration varies: Gemini 2.5 Pro has an anti‑informative SelRank of –0.106, while GPT-4o has a positive 0.144.

## Why This Works (Mechanism)

### 1. Minimal‑edit XOR families test evidence‑sensitive judgment
The 2×2 construction crosses a minimal image edit with a minimal text edit, producing four cells with gold labels following a strict XOR pattern (BASE=VISIBLY_FALSE, TEXT_FLIP=VISIBLY_TRUE, IMAGE_FLIP=VISIBLY_TRUE, DOUBLE_FLIP=VISIBLY_FALSE). A model that correctly flips its answer on TEXT_FLIP and/or IMAGE_FLIP demonstrates sensitivity to the respective edit, measured via Minimal Edit Flip Rates. The minimal edit changes exactly one visibility factor without affecting others. If a model’s I_MEFR or T_MEFR is near 0, the mechanism fails to detect evidence sensitivity.

### 2. Explicit abstention with reason codes surfaces uncertainty and failure modes
The label space includes ABSTAIN; when chosen, the model must select exactly one limiting‑factor code from a predefined taxonomy (e.g., OCCLUSION, OUT_OF_FRAME). This forces the model to assess whether the claim is supported and, if not, to identify the underlying visibility limitation, providing interpretable diagnostics. If models never abstain or if reason codes are misassigned, the benchmark cannot surface uncertainty meaningfully.

### 3. Confidence‑ranked selective prediction (SelRank) measures calibration for safe deferral
SelRank quantifies the correlation between a model’s confidence scores and correctness. For answered items (non‑ABSTAIN), responses are sorted by confidence descending; accuracy as a function of coverage is compared to the baseline of random ordering. Positive SelRank indicates that higher confidence corresponds to higher correctness, which is essential for systems that must defer uncertain predictions. A SelRank ≤ 0 indicates anti‑informative confidence, meaning the model cannot safely be used with a reject option.

## Architecture Onboarding

**Component map**: Dataset (100 families × 4 cells) -> Model (image+question -> JSON output) -> Evaluation (parse, compare to gold) -> Metrics (CAA, MEFR, SelRank, ToMAcc, DFAcc, FinalScore).

**Critical path**:
1. Load family definitions and images. Ensure all four cells are prepared.
2. For each cell, format the prompt with image and question; send to model API (or run locally).
3. Parse model response as JSON; extract label, reason_code, confidence. Handle unparsable outputs (count as failure).
4. Store predictions with gold labels.
5. Compute metrics: CAA (α=0.25) on BASE, TEXT_FLIP, IMAGE_FLIP; I_MEFR/T_MEFR conditional on BASE correct; SelRank on answered items; ToMAcc on SECOND_ORDER; DFAcc on DOUBLE_FLIP.
6. Combine components into FinalScore.

**Design tradeoffs**:
- Strict JSON output requirement ensures structured predictions but causes parsing failures (e.g., Qwen3-VL-8B had many unparsable). Could mitigate with constrained decoding or function-calling APIs.
- XOR pattern simplifies scoring and ensures clean flips but may not capture all real‑world ambiguities; families are artificially constructed.
- Small family count (100) limits statistical power, especially for SECOND_ORDER (21 items); expansion planned.
- Composite score weights: CAA dominates (70%), which prioritizes correctness with abstention; users may reweight for their needs.
- Abstention partial credit α=0.25 is heuristic; could be tuned based on deployment cost of wrong vs. abstain.
- Images collected in campus/urban settings; may not generalize to other environments.

**Failure signatures**:
- High unparsable output rate (>10%): indicates poor format compliance.
- Low MEFR (<0.5): model not sensitive to minimal edits.
- Negative SelRank: confidence is anti‑informative; higher confidence correlates with lower accuracy.
- Abstention rate near 0%: model never abstains, likely overconfident.
- Abstention rate near 100%: model overly cautious, poor coverage.
- Large gap between CAA and answered accuracy: e.g., high CAA due to many abstentions but low accuracy on answered items.
- ToMAcc near chance (0.5) for flagship models: indicates poor second‑order reasoning.

**First 3 experiments**:
1. **Reproduce main results**: Run all nine models on the 300 headline items, compute FinalScore and component metrics, verify ranking matches Table 2. Command: `python evaluate.py --models configs/models.json --output results.tsv`.
2. **Ablate abstention effect**: Compute standard accuracy (ignoring abstentions) vs. CAA for each model. Expect models with high abstention may have lower accuracy but higher CAA. Command: `python analyze_abstention.py --results results.tsv`.
3. **Per‑category breakdown**: For each primary category (gaze, occlusion, etc.), compute CAA and MEFR to identify which visibility factors are hardest. Command: `python analyze_categories.py --results results.tsv --metadata metadata/families.csv`.

## Limitations
- Execution fidelity: Exact API model identifiers, prompt formatting, and open‑source inference parameters are unspecified and may shift model behavior.
- Statistical reliability: The small number of families (100) and SECOND_ORDER items (21) limits robustness of per‑category and ToM findings.
- Parsing and confidence handling: Models often produce non‑JSON outputs; handling of out‑of‑range confidence values is undocumented, potentially affecting coverage and calibration metrics.
