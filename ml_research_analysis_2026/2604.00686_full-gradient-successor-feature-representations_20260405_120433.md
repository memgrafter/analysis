# Full-Gradient Successor Feature Representations

## Quick Facts
- **arXiv ID:** 2604.00686
- **Source URL:** https://arxiv.org/abs/2604.00686
- **Reference count:** 40
- **Primary result:** FG-SFRQL eliminates semi-gradient bias, achieving convergence guarantees and superior sample efficiency in multi-task reinforcement learning with successor features.

## Executive Summary
FG-SFRQL addresses instability in multi-task reinforcement learning with Successor Features by replacing semi-gradient TD updates with full-gradient updates. Standard SFRQL suffers from semi-gradient bias—the target is treated as constant—leading to convergence issues under nonlinear function approximation. FG-SFRQL computes the full Mean Squared Bellman Error (MSBE) gradient with respect to both online and target network parameters, yielding a true gradient descent on the MSBE. Theoretically, the authors prove almost-sure convergence to a stationary point under standard assumptions. Empirically, FG-SFRQL demonstrates higher sample efficiency and better transfer performance than semi-gradient baselines (SFRQL, DQN, FG-DQN) across discrete (Four-Rooms) and continuous (Reacher, PointMaze) domains, with especially large gains in the challenging PointMaze-Large environment.

## Method Summary
FG-SFRQL learns successor feature representations using two neural networks: an online network ψ_θ that predicts the expected future feature counts for state-action pairs, and a target network ψ_θ' that provides a stable bootstrapping target. The loss is the mean squared Bellman error: L(θ,θ') = E[(ψ_θ(s,a) - (r + γ ψ_θ'(s', a*)))^2], where a* is the action selected by the current policy at s'. Unlike semi-gradient methods, FG-SFRQL differentiates this loss through both networks, obtaining gradients ∂L/∂θ and ∂L/∂θ'. The online parameters are updated using the combined full gradient, while the target network is updated slowly (e.g., Polyak averaging) to maintain stability. This full-gradient approach removes the bias introduced by treating the target as constant and aligns the optimization with the true MSBE objective.

## Key Results
- Eliminates semi-gradient bias by using full-gradient updates through both online and target networks.
- Provides an almost-sure convergence proof to a stationary point of the aggregate Bellman error.
- Outperforms semi-gradient baselines (SFRQL, DQN, FG-DQN) in sample efficiency and transfer performance on Four-Rooms, Reacher, and PointMaze, with especially large gains in PointMaze-Large.

## Why This Works (Mechanism)
The core limitation of semi-gradient TD is that the gradient of the MSBE ignores the dependence of the bootstrapping target on the network parameters—this introduces bias and can cause divergence in nonlinear settings. FG-SFRQL’s full-gradient computation accounts for this dependence by backpropagating error through the target network as well. Consequently, the update direction corresponds to the true gradient of the MSBE, which is a proper loss function. This yields unbiased gradient estimates (given an unbiased sample) and satisfies conditions under which stochastic gradient descent is known to converge to stationary points. Moreover, the inclusion of target gradients stabilizes learning by aligning the update with the underlying Bellman fixed point, leading to faster convergence and better sample efficiency. The theoretical analysis leverages stochastic approximation theory to establish almost-sure convergence under i.i.d. sampling and linear function approximation assumptions; while these assumptions are idealized, they provide a foundation for understanding the method’s stability.

## Foundational Learning
- **Successor Features (SF):** ψ(s,a) estimates expected cumulative future features; needed because a single set of SFs can be combined with any task weight vector to derive optimal behavior for that task, enabling multi-task RL. Quick check: How can a policy be optimal for many reward functions using SF?
- **Mean Squared Bellman Error (MSBE):** The squared difference between a value estimate and its Bellman target; minimizing MSBE corresponds to satisfying the Bellman equation. Quick check: Why does minimizing MSBE lead to optimal value functions?
- **Semi-gradient TD:** Updates using gradient only of the prediction part, omitting gradient through the bootstrap target; computationally simpler but biased. Quick check: In semi-gradient TD(0), what part of the loss gradient is ignored?
- **Full-gradient TD:** Includes gradient through the target, yielding the true gradient of the MSBE; reduces bias at the cost of additional computation. Quick check: How does differentiating through the target network change the update?
- **Neural network function approximation:** Non-linear models that can handle high-dimensional state spaces; introduce non-convexity and instability, necessitating tricks like target networks and replay buffers. Quick check: What challenges arise when using deep networks for RL?
- **Target network:** A delayed copy of the online network used to generate bootstrapping targets, reducing moving target instability. Quick check: Why does a target network improve stability in DQN-like algorithms?

## Architecture Onboarding
**Component map:**
ReplayBuffer -> Sample -> OnlineNetwork(ψ_θ) & TargetNetwork(ψ_θ') -> compute MSBE loss -> Compute full gradient (∂L/∂θ, ∂L/∂θ') via backprop through both -> Update online parameters (θ ← θ - α (∂L/∂θ + λ ∂L/∂θ')) -> Periodically update target (θ' ← τ θ + (1-τ) θ').

**Critical path:**
1. Initialize online and target networks.
2. For each environment step, store transition (s,a,r,s') in replay buffer.
3. Sample minibatch from buffer.
4. Compute online predictions ψ_θ(s,a).
5. Compute next-state target action a* (e.g., greedy w.r.t. ψ_θ·w for sampled task weight w) and then target values r + γ ψ_θ'(s',a*).
6. Compute MSBE loss.
7. Perform backpropagation through both networks to obtain gradients.
8. Apply gradient step to online parameters.
9. Every C steps, update target network by Polyak averaging.

**Design tradeoffs:**
- Full-gradient adds computational overhead roughly double the backprop compared to semi-gradient (must backprop through target network), but reduces bias and improves stability.
- Target network update frequency τ trades off stability (small τ) vs responsiveness (large τ). Too slow may hinder learning speed; too fast may reintroduce instability.
- The choice of λ (weight of target gradient) could further adjust bias-variance; the paper may use λ=1 (full gradient includes both equally) but scaling may be needed.

**Failure signatures:**
- Diverging loss or exploding gradients, often due to large learning rates or aggressive target gradient weight.
- High variance in episodic returns across seeds, indicating instability.
- Poor transfer performance on new tasks, suggesting underfitting or overfitting to training tasks.
- Slow convergence or plateauing early, possibly from insufficient representation capacity or improper target network softness.

**Three first experiments:**
1. **Four-Rooms convergence:** Train FG-SFRQL and SFRQL on the classic Four-Rooms gridworld with a set of dense reward tasks; measure cumulative reward over training steps and compare sample efficiency.
2. **Multi-task transfer in Reacher:** Learn successor features on a distribution of Reacher goals; after training, evaluate zero-shot transfer to unseen goal locations by combining learned ψ with the new goal’s feature vector; compare average return to baselines.
3. **Ablation on full-gradient:** Remove the gradient through the target network (i.e., revert to semi-gradient) while keeping all other hyperparameters identical; analyze the effect on MSBE, training stability, and final performance across the three domains.

## Limitations
- The convergence proof assumes i.i.d. data and linear function approximation, conditions rarely met in deep RL with nonlinear networks and temporal correlations.
- Empirical evaluation is confined to relatively small-scale tasks (gridworld and low-dimensional control); scalability to high-dimensional or image-based domains remains unknown.
- The study omits comparisons to newer successor feature methods (e.g., SF-DQN) and other multi-task RL algorithms, and does not analyze the computational overhead of full-gradient backpropagation.

## Confidence
- Elimination of semi-gradient bias: **High**
- Convergence to a stationary point (under stated assumptions): **Medium**
- Superior sample efficiency and transfer in tested domains: **High**
- Generalization to broader, more complex domains (e.g., visual RL): **Medium**
