# From Numbers to Prompts: A Cognitive Symbolic Transition Mechanism for Lightweight Time-Series Forecasting

## Quick Facts
- **arXiv ID:** 2602.00088
- **Source URL:** https://arxiv.org/abs/2602.00088
- **Reference count:** 40
- **Primary result:** STM reduces forecasting error by up to 69% in MAE and 90% in MSE with negligible resource overhead (GPU memory +0.06%, latency +0.64%).

## Executive Summary
This paper introduces the Symbolic Transition Mechanism (STM), a lightweight wrapper that enhances small language models (SLMs) for time-series forecasting without modifying their core parameters. STM transforms continuous values into discrete symbols based on cognitive limits, computes transitions to highlight significant changes, and detects periodic patterns. These symbolic cues are injected into the prompt, guiding the SLM's attention. Evaluated on climate and LLM-traffic datasets across four SLMs, STM achieves substantial error reductions while adding minimal computational overhead, making it suitable for edge deployment.

## Method Summary
STM operates as a pre-processing module at inference time. First, the input time series is normalized and quantized into a small set of symbols (default K=5). Then, it computes transition magnitudes between consecutive symbols and detects repeating patterns to infer periodicity. An internal attention score combines symbol distance, transition magnitude, and periodic weight to emphasize salient timesteps. Only the final symbolic pattern string is added to the original numeric sequence in the prompt. The frozen SLM generates a prediction, which is inverse-normalized to the original scale. No model training or fine-tuning is involved; all adaptation occurs via prompt reprogramming.

## Key Results
- STM reduces MAE by up to 69% and MSE by up to 90% compared to the same SLMs without STM.
- Resource overhead is negligible: GPU memory increases by only 0.06% and inference latency by 0.64%.
- Ablation studies show that five symbolic levels (K=5) provide the optimal trade-off between robustness and granularity.

## Why This Works (Mechanism)
### Mechanism 1: Symbolic Quantization
**Claim:** Discretizing continuous values into a small set of symbols (e.g., five levels) reduces numerical complexity and aligns with how language models process variations, making patterns more interpretable for SLMs.
**Mechanism:** STM quantizes normalized values into uniform bins (e.g., VL, L, M, H, VH), transforming dense numeric sequences into sparse symbolic strings (e.g., "AABCCCDDEE") injected as contextual text.
**Core assumption:** SLMs, trained on human language, handle discrete, semantically meaningful tokens better than raw floating-point numbers, especially under parameter constraints.
**Evidence:** [abstract] mentions inspiration from human cognitive limits; [section 3.2.1] states symbolic encoding reduces complexity and improves robustness.
**Break condition:** High noise levels that obscure signal boundaries, or if the SLM's tokenizer conflicts with the custom symbol set.

### Mechanism 2: Transition Emphasis
**Claim:** Emphasizing large symbolic transitions (Δ) between consecutive symbols highlights structurally meaningful events (e.g., abrupt shifts), guiding the SLM's attention to critical temporal changes without altering weights.
**Mechanism:** STM computes Δₜ = w(sₜ₊₁) - w(sₜ), where w maps symbols to an ordinal scale. Larger |Δ| indicate sharper changes. These inform an internal attention score that weights timesteps, reflected in the symbolic pattern provided.
**Core assumption:** Forecast accuracy suffers when models overlook regime changes; symbolic transitions provide a lightweight, model-agnostic way to surface these events.
**Evidence:** [section 3.2.2] and [section 3.3] describe leveraging transitions to highlight meaningful behaviors and incorporate them into attention scores.
**Break condition:** Highly volatile, non-stationary series where every step is a large transition, reducing discriminative power.

### Mechanism 3: Periodicity Detection
**Claim:** Detecting and emphasizing repeating symbolic transition patterns enhances the model's ability to capture seasonal or cyclic dynamics, improving long-horizon forecast stability.
**Mechanism:** STM searches for a minimal period T where the transition sequence Δ[0:T-1] ≈ Δ[T:2T-1]. Detected periodic segments receive a periodic weight p(T), boosting attention for consistent patterns.
**Core assumption:** Many real-world series have underlying cycles; explicitly signaling these helps small models overcome limited context or parameter-induced biases.
**Evidence:** [section 3.2.3] and [section 3.3] describe highlighting regular structures via recurring segments and periodic weights.
**Break condition:** Aperiodic or irregularly sampled series with no repeating motifs, where periodicity detection may inject spurious cues.

## Foundational Learning
- **Cognitive Psychology (Miller's Law):** Justifies K=5 quantization levels based on human working memory limits (5–9 chunks). SLMs may process discrete symbols more like human language than raw numbers.
  - *Quick check:* Why might an SLM better process "MEDIUM_HIGH" rather than 0.72, and how does 5 relate to working memory?
- **Prompt Engineering/Reprogramming:** STM adapts the input prompt rather than model weights. Understanding that all improvement comes from textual cues is key.
  - *Quick check:* If STM doesn't change parameters, how does it improve forecasts? (Answer: by changing the prompt to include symbolic summaries and cues.)
- **Time Series Decomposition:** STM's three components map to trend (symbolization), level shifts (transitions), and seasonality (periodicity). Recognizing which properties a dataset lacks helps interpret STM's impact.
  - *Quick check:* For a series with only a strong upward trend and no seasonality, which STM component is most relevant, and which might be irrelevant?

## Architecture Onboarding
**Component map:** Input Normalizer -> Quantizer -> Transition Calculator -> Periodicity Detector -> Attention Scorer -> Prompt Constructor -> SLM Wrapper

**Critical path:** Raw data → Normalization → Symbolization → (Transition + Periodicity analysis) → Symbolic pattern generation → Prompt augmentation → SLM inference → Output parsing. No gradient flow; pre-processing module.

**Design tradeoffs:**
- **K (number of symbols):** Lower K increases noise robustness but loses granularity; higher K captures nuance but risks over-segmentation. Default K=5 from ablation.
- **Prompt length vs. context window:** STM adds a short symbolic string; very small context windows (e.g., Gemma's 8K) may limit benefit due to truncation of numeric sequence.
- **Generality vs. specificity:** Transition and periodicity cues are computed internally but only final symbolic pattern is exposed, keeping prompt clean but possibly underutilizing descriptors.

**Failure signatures:**
- Minimal improvement on models with short context windows or strong domain-specific pretraining.
- Degradation if injected symbolic pattern conflicts with prompt's natural language instruction.
- High variance if symbolization thresholds misalign with data distribution (e.g., extreme outliers).

**First 3 experiments:**
1. **Ablation on K:** For a fixed SLM and dataset, run STM with K ∈ {3,5,7,9,10}. Plot MAE/MSE vs. K to confirm optimal K on your data.
2. **Component Isolation:** Disable periodicity detection (p(T)=1) and transition weighting (Δₜ=0) separately. Measure drop in improvement to quantify each component's contribution.
3. **Resource Profiling:** Measure GPU memory and inference latency with/without STM on target edge hardware. Verify claimed overheads (~0.06% memory, ~0.64% latency).

## Open Questions the Paper Calls Out
**Open Question 1:** What is the optimal number of symbolic quantization levels for STM, and how does this optimum vary across different SLMs, time-series characteristics, and model depth?  
*Basis:* Section 4.4 notes need for further research on symbol diversity interactions with noise, periodicity, and model depth.  
*Why unresolved:* Current study tested only five K values on four SLMs; systematic examination across diverse models and data properties is lacking.  
*What evidence would resolve:* Comprehensive ablation varying K over a wider range across many SLMs and datasets with controlled properties; statistical analysis to identify conditions where optimal K deviates from 5.

**Open Question 2:** Can STM maintain performance on irregular, noisy, or multivariate time-series data from domains like finance or healthcare, and how should the symbolic representation be adapted?  
*Basis:* Section 4.4 and Conclusion mention plans to extend STM to diverse irregular/multivariate series.  
*Why unresolved:* Evaluation limited to two univariate datasets (temperature, LLM traffic). Effectiveness on missing values, irregular sampling, non-stationarity, or multiple variables is unknown.  
*What evidence would resolve:* Benchmark STM on multivariate/irregular datasets (e.g., M4, MIMIC, financial data); explore extensions for multiple variables and irregular timestamps.

**Open Question 3:** How does STM’s effectiveness scale with backbone language model size (from SLMs to LLMs) and does it retain low-overhead advantages with larger models?  
*Basis:* Conclusion states future work to integrate with larger LMs beyond SLMs.  
*Why unresolved:* Only four SLMs (up to 3.8B parameters) evaluated. Prompt length increases may become non-negligible for very long contexts; large models may already capture patterns well, so marginal gains uncertain.  
*What evidence would resolve:* Implement STM with larger LLMs (e.g., GPT-3/4, LLaMA-65B); measure accuracy improvements and resource overhead; compare relative gains to see if benefits diminish with scale.

## Limitations
- **Underspecified algorithms:** Quantization bin boundaries, periodicity detection threshold, and exact prompt template are not defined, hindering exact replication.
- **External validation weak:** Related symbolic time-series work exists but no direct prior evidence for STM's specific transition-weighting; claims rely primarily on self-experiments.
- **Generalizability open:** Optimal K=5 is dataset-dependent; may not hold for all time-series characteristics (e.g., high volatility, multi-seasonality).

## Confidence
- **Performance claims (MAE/MSE reduction, overhead):** High (backed by reported experiments, though raw logs/code unavailable).
- **Mechanistic explanations (quantization, transition/periodicity cues):** Medium (plausible but lacking independent verification; weak corpus support).
- **Optimal K=5:** High within paper’s tested datasets, but Low confidence for universal applicability without broader validation.

## Next Checks
1. **Binning sensitivity test:** Reimplement STM with both uniform min-max bins and training-data quantile bins; measure MAE/MSE variance on Climate/Azure data to quantify impact of this underspecification.
2. **Periodicity detector stress test:** Apply STM to synthetic aperiodic series (e.g., white noise, random walks); log detected T and forecast performance vs. disabled periodicity weight to confirm break condition.
