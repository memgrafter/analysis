# AIvilization v0: Toward Large-Scale Artificial Social Simulation with a Unified Agent Architecture and Adaptive Agent Profiles

## Quick Facts
- arXiv ID: 2602.10429  
- Source URL: https://arxiv.org/abs/2602.10429  
- Reference count: 40  
- Primary result: Stable markets with heavy-tailed returns and volatility clustering emerged from tens of thousands of agents, alongside wealth stratification induced by education/residential barriers.

## Executive Summary
AIvilization v0 introduces a unified agent architecture designed to sustain long-horizon autonomy for LLM agents in large-scale, resource-constrained artificial societies. The platform combines a hierarchical branch-thinking planner, an adaptive dual-process memory system, and human-in-the-loop steering within an environment featuring physiological constraints, multi-tier production, automated market maker pricing, and gated education-occupation pathways. Public deployment with tens of thousands of agents reproduced key financial stylized facts—heavy-tailed returns and volatility clustering—and emergent wealth stratification. Ablation studies demonstrate that simplified planners fail in multi-objective long-horizon contexts, underscoring the necessity of the proposed architecture.

## Method Summary
The core architecture revolves around three pillars: (1) a hierarchical branch-thinking planner that decomposes high-level goals into parallel branches, validates them via simulation, and employs tiered re-planning to balance reactivity and stability; (2) an adaptive agent profile with dual-process memory separating short-term traces from long-term semantic consolidation; (3) human-in-the-loop steering that injects objectives and commands into the memory propagation cycle. The environment tightly couples agent physiology, multi-level production chains, AMM-based pricing, and education/occupation gates that restrict social mobility. This design allows agents to pursue complex, long-term goals while reacting to dynamic conditions and human interventions.

## Key Results
- Markets exhibited heavy-tailed returns (excess kurtosis >6) and significant volatility clustering (|r| autocorrelation, p<0.001).  
- Wealth stratification emerged organically due to education and residential barriers.  
- Ablation confirmed simplified planners suffice only for narrow tasks; the full architecture enabled robust multi-objective long-horizon behavior, including delayed investment and exploration.

## Why This Works (Mechanism)
Parallel goal decomposition via the hierarchical planner lets agents explore multiple strategies simultaneously, while simulation-guided validation filters out doomed branches early. Tiered re-planning introduces a cost-efficient adaptation mechanism that avoids full re-planning for minor deviations. Dual-process memory preserves strategic knowledge in long-term storage without sacrificing immediate reactivity from short-term traces. Human steering provides an external alignment signal that propagates through memory, correcting drifting objectives. Together, these mechanisms maintain goal stability and reactive correctness even under resource constraints and long time horizons.

## Foundational Learning
- **Hierarchical Branch-Thinking Planner**  
  Why needed: Enables decomposition of complex goals into concurrent sub‑tasks, increasing efficiency and fault tolerance.  
  Quick check: Can an agent break a high‑level goal into independent branches and execute them in parallel?

- **Dual‑Process Memory**  
  Why needed: Separates brief, context‑rich experiences from consolidated knowledge, balancing reactivity with strategic memory.  
  Quick check: Does the system maintain distinct short‑term and long‑term stores, with periodic consolidation?

- **Simulation‑Guided Validation**  
  Why needed: Anticipates action outcomes before execution, reducing costly trial‑and‑error in uncertain environments.  
  Quick check: Prior to acting, does the agent simulate predicted environmental states and prune invalid branches?

- **Tiered Re‑Planning**  
  Why needed: Offers a scalable way to respond to disruptions—minor triggers use fast, local adjustments; major ones invoke full replanning.  
  Quick check: Are there multiple re‑planning thresholds that activate different planning depths?

- **Human‑in‑the‑Loop Steering**  
  Why needed: Maintains alignment and allows real‑time correction of agent behavior.  
  Quick check: Can an operator inject new objectives that instantly influence the agent’s plan?

- **Adaptive Agent Profiles**  
  Why needed: Permits individual agents to evolve distinct strategies based on experience, enhancing societal diversity and resilience.  
  Quick check: Do agents modify internal parameters (e.g., risk aversion) over time in response to feedback?

## Architecture Onboarding
**Component Map**  
Human -> Steering Commands -> Agent Profile -> Memory (Short‑Term, Long‑Term) -> Planner (Goal Decomposer, Simulator, Re‑Planner) -> Environment (Physiology, Production, AMM, Education) -> Action Feedback -> Memory Update

**Critical Path**  
1. Receive high‑level goal.  
2. Decompose into parallel branches.  
3. Validate branches via simulation.  
4. Execute selected branches while monitoring environment.  
5. Upon deviation, trigger tiered re‑planning.  
6. Consolidate short‑term traces into long‑term memory post‑completion.

**Design Tradeoffs**  
- Human control vs. autonomy: Increased steering improves alignment but reduces emergent behavior.  
- Consolidation frequency: Higher frequency lowers memory overhead but risks losing temporally sensitive details.  
- Re‑planning depth: Deeper replanning improves robustness but adds computational cost and latency.

**Failure Signatures**  
- Repeated failure to achieve long‑term goals despite re‑planning.  
- Market instability exceeding predicted stylized facts (e.g., extreme bubbles/crashes).  
- Memory fragmentation causing inconsistent or contradictory agent behavior.  
- Excessive re‑planning loops without measurable progress (thrashing).

**First Three Experiments**  
1. Single‑agent delayed investment: Compare hierarchical planner against a flat ReAct‑style planner on a multi‑step investment task; measure success rate and return.  
2. Multi‑agent market stability: Run the full society with and without human steering; compare market stability metrics and wealth distribution.  
3. Memory consolidation sweep: Vary the threshold for transferring short‑term traces to long‑term memory and evaluate impact on goal stability and computational cost.

## Limitations
- No public code or configuration details, hindering independent replication.  
- Claims of architecture superiority rely solely on internal ablation studies; no external benchmarks.  
- Emergent wealth stratification is correlational; disentangling causal factors (e.g., initial asset distributions, networking rules) remains unclear.

## Confidence
- Market stylized facts (heavy‑tailed returns, volatility clustering): High  
- Emergence of wealth stratification from specified barriers: Medium  
- Necessity of full architecture for long‑horizon autonomy: Low
