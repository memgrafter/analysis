# Near-Optimal Regret for Distributed Adversarial Bandits: A Black-Box Approach

## Quick Facts
- **arXiv ID:** 2602.06404
- **Source URL:** https://arxiv.org/abs/2602.06404
- **Reference count:** 40
- **Primary result:** The paper achieves a minimax regret of Θ̃(√((ρ⁻¹/² + K/N)T)) for distributed adversarial bandits via a black-box reduction that decouples learning and communication, with a matching lower bound; it extends to distributed linear bandits with Õ(√((ρ⁻¹/² + 1/N)dT)) regret and O(d) communication per round via volumetric spanners.

## Executive Summary
This paper tackles the problem of distributed adversarial bandits, where multiple agents cooperate to minimize the global average regret while only observing local losses and communicating via gossip. The authors introduce a novel black-box reduction that separates the learning process from communication by using blocks of rounds where action distributions are fixed. Within each block, agents execute accelerated gossip to mix information from previous blocks and incorporate minimal uniform exploration to bound variance. This reduces the problem to standard adversarial bandits with delayed feedback. The main theoretical result establishes a minimax regret of Θ̃(√((ρ⁻¹/² + K/N)T)), where ρ is the spectral gap of the gossip matrix, significantly improving prior bounds. A matching lower bound shows optimal decomposition into communication and bandit costs. The framework extends to distributed linear bandits, achieving Õ(√((ρ⁻¹/² + 1/N)dT)) regret with only O(d) communication per round using volumetric spanners.

## Method Summary
The proposed method (Algorithm 1 for multi-armed bandits and Algorithm 3 for linear bandits) operates in blocks of B rounds. At the start of each block, each agent queries a delayed-feedback bandit algorithm A for a distribution over actions. This distribution is mixed with a small uniform component (exploration α = 1/T) to ensure bounded importance weights. Agents then play actions according to this mixed distribution for all B rounds while simultaneously running B accelerated gossip iterations on the accumulated loss estimates from the previous block. At the end of the block, the consensus estimate of the global average loss from the previous block is fed to algorithm A, which now has a one-block delay. The use of two alternating instances of a base online convex optimization (OCO) algorithm (like FTRL) within A handles the constant delay. The block length B is chosen as O(√(ρ⁻¹ log(KT)/√ρ)) to balance gossip mixing accuracy and delay, where ρ is the spectral gap of the gossip matrix. For linear bandits, the action set is approximated by a small volumetric spanner of size O(d) to reduce communication to O(d) per round. The method is a black-box reduction: any bandit algorithm robust to constant delay can be plugged in, inheriting its guarantees.

## Key Results
- **Minimax regret for distributed adversarial bandits:** Θ̃(√((ρ⁻¹/² + K/N)T)), improving the previous Õ(ρ⁻¹/³(KT)²/³) bound.
- **Matching lower bound:** Shows optimal decomposition into communication cost (ρ⁻¹/⁴√T) and bandit cost (√(KT/N)).
- **Distributed linear bandits:** Regret Õ(√((ρ⁻¹/² + 1/N)dT)) with only O(d) communication per round via volumetric spanners.

## Why This Works (Mechanism)
### Mechanism 1: Block-Based Decoupling of Learning and Communication
- **Claim:** By freezing action distributions over blocks of length B and executing B rounds of accelerated gossip within each block, agents ensure that the local approximation of the global average loss vector at the end of the block is accurate, enabling a reduction to bandits with delayed feedback.
- **Mechanism:** Agents play a fixed distribution \(p_\tau\) for all rounds in block \(\tau\). While playing, they buffer local loss estimates and simultaneously run B gossip steps to mix the estimates from the previous block. At block’s end, they obtain a high‑precision estimate of the global average loss from block \(\tau-1\) (\(z_B^\tau\)) and feed it to the bandit algorithm with one‑block delay.
- **Core assumption:** Accelerated gossip with parameters \(\kappa\) and B (chosen as in Eq. (4)) drives the consensus error between local estimate and the true global average loss to \(\leq 2B/(T^5 K^5)\) with high probability. This holds because uniform exploration (\(\alpha=1/T\)) keeps importance weights bounded by \(KT\), ensuring the norms involved in gossip are controlled.
- **Evidence anchors:**
  - [abstract]: “decouples learning from communication using a block‑based approach: agents fix action distributions over blocks, execute accelerated gossip to mix information from previous blocks, and incorporate minimal uniform exploration to bound variance.”
  - [section 3, Algorithm 1 and Lemma 1]: Formal description and bound on gossip error.
  - [corpus]: The corpus contains works on distributed bandits (e.g., Yi and Vojnovic 2023) but does not address the exact block‑based reduction; therefore corpus evidence for this specific mechanism is weak.
- **Break condition:** If block length B is chosen too small relative to \(\rho^{-1}\), the gossip mixing error remains large (exponential decay not sufficient), causing the reduction to fail and regret to degrade. Also if uniform exploration \(\alpha\) is too small, importance weights may blow up, breaking the boundedness assumption.

### Mechanism 2: Minimal Uniform Exploration to Bound Variance
- **Claim:** Adding a \(\Theta(1/T)\) uniform exploration component to the action distribution ensures that the probability of any action is at least \(1/(KT)\) at all times, which in turn guarantees that the importance‑weighted loss estimates have bounded \(\ell_2\)‑norm by \(KT\).
- **Mechanism:** In each block, the distribution played is \(p_\tau = (1-\alpha) p_\tau^1 + \frac{\alpha}{K} \mathbf{1}\), where \(p_\tau^1\) is the output of the bandit algorithm and \(\alpha=1/T\). This uniform mixing ensures no action probability is too small.
- **Core assumption:** The uniform exploration term is small enough (\(1/T\)) that it does not significantly affect worst‑case regret, yet large enough to provide uniform lower bound on probabilities. The analysis uses that \(p_\tau(k) \geq 1/(KT)\) for all \(k\).
- **Evidence anchors:**
  - [abstract]: “incorporate minimal uniform exploration to bound variance.”
  - [section 3, Line 4]: \(p_\tau = (1-\alpha) p_\tau^1 + \alpha/K \mathbf{1}\) with \(\alpha=1/T\).
  - [proof of Lemma 1]: The boundedness of \(p_\tau(\cdot)\) is used to bound the \(\ell_2\)-norm of local estimates (\(\leq KT\)) and hence gossip error.
  - [corpus]: The idea of uniform exploration for variance control appears in other bandit settings but the specific \(1/T\) schedule is tailored here; corpus evidence is indirect.
- **Break condition:** If exploration \(\alpha\) is too large (e.g., constant), the regret bound would worsen (communication cost unaffected but bandit cost increases). If \(\alpha\) is too small (e.g., \(1/\sqrt{T}\)), some probabilities may become exponentially small, causing the influence of large importance weights to break the gossip mixing guarantee.

### Mechanism 3: Black‑Box Reduction to Delayed Bandit Feedback
- **Claim:** The block‑based structure naturally induces a constant one‑block delay in the feedback provided to the bandit algorithm. This allows any adversarial bandit algorithm robust to constant delay to be used as a black box, inheriting its guarantees (including adaptive ones).
- **Mechanism:** At the end of block \(\tau\), the agent receives \(z_B^{\tau+1}\) (average of local estimates from block \(\tau\)) and passes it to its instance of A. However, A was queried for \(p_\tau^1\) at the beginning of block \(\tau\). So when \(z_B^{\tau+1}\) arrives, it is used to update A for the next block (\(\tau+1\)). Algorithm 2 uses two alternating instances of B to handle the constant delay.
- **Core assumption:** The bandit algorithm A (or underlying OLO B) can handle a constant delay \(d=1\) block. Its regret bound with delay \(d\) applies.
- **Evidence anchors:**
  - [abstract]: “creates a reduction to standard bandits with delayed feedback.”
  - [section 3, paragraph after Algorithm 1]: “This construction yields a black‑box reduction from distributed bandits with local gossip to standard adversarial bandits with delayed feedback.”
  - [Theorem 2 and Lemma 3]: The regret bound transfers via Lemma 3: if A has bounded delay regret \(R_{\text{del}}\), then overall regret \(\leq R_{\text{del}} + O(1)\).
  - [section 4]: Extension to adaptive bounds using delayed‑bandit algorithms with small‑loss or best‑of‑both‑worlds guarantees.
  - [corpus]: The delayed feedback model is studied in e.g. Cesa‑Bianchi et al. (2019); our reduction plugs into that framework, but the specific block‑gossip coupling is novel. Corpus evidence for delayed bandits exists but not for the distributed reduction.
- **Break condition:** If the delay is not constant (e.g., due to variable block lengths or communication failures), the delay‑robustness of A may be insufficient. Also, if the base algorithm B requires resets or has memory beyond one step, the alternating instance trick may fail.

## Foundational Learning
- **Concept: Gossip protocols and spectral gap \(\rho\)**  
  Why needed: The communication cost in regret scales with \(\rho^{-1/2}\); understanding how \(\kappa\) and B relate to \(\rho\) is crucial for parameter setting.  
  Quick check: What is the relationship between the mixing coefficient \(\kappa\) and the spectral gap \(\rho\) in accelerated gossip? (Ans: \(\kappa = 1/(1+\sqrt{(1-\sigma^2)/2})\) where \(\sigma^2 = 1-\rho\).)

- **Concept: Online Convex Optimization (OCO) and Follow‑the‑Regularized‑Leader (FTRL)**  
  Why needed: The black‑box reduction uses OCO algorithms (FTRL) as the base learner B. Understanding FTRL’s regret guarantees, strong convexity, and stability is essential to analyze the bound.  
  Quick check: Why does 1‑strong convexity of \(\psi\) w.r.t. \(\ell_2\)-norm imply a Lipschitz argmin map? (Reference Lemma 10.)

- **Concept: Volumetric spanners**  
  Why needed: In distributed linear bandits, we need to reduce communication from \(K\) to \(O(d)\) per round. Volumetric spanners provide a basis for the action set with bounded coefficients.  
  Quick check: What property of a volumetric spanner ensures that any action can be approximated with \(\ell_2\) coefficient norm \(\leq 1\)? (Definition 5.1: existence of \(\lambda(k)\) with \(\|\lambda(k)\|_2 \leq 1\).)

- **Concept: Importance weighting in bandits**  
  Why needed: The estimator \(\tilde{\ell}_t(k) = \ell_t(k) / p_t(k)\) if action \(k\) is played, else 0. This is used to form unbiased loss estimates. Boundedness requires uniform exploration.  
  Quick check: How does the \(1/T\) uniform exploration guarantee that \(p_t(k) \geq 1/(KT)\)? (Because mixture with \(1/K\) ensures.)

## Architecture Onboarding
- **Component map:**
  Agent(i) -> Local instances: A (delayed bandit, two alternating B instances) and gossip state z; Communicates with neighbors via W (gossip matrix). Global parameters: B, κ, α, β; for linear: volumetric spanner S.
  The flow: Agent -> queries A -> gets p^1 -> mixes with uniform -> plays actions; concurrently runs gossip on previous block estimates; at block end sends consensus to A (delayed). A updates B instances.

- **Critical path:**
  1. Start block τ: query A for p^1_τ(i).
  2. Compute p_τ(i) = (1−α)p^1_τ(i) + α/K·1.
  3. For t in block: play action per p_τ, observe local loss, compute estimate pℓ_t.
  4. Simultaneously: run B gossip rounds on running sum of pℓ from block τ−1.
  5. After B rounds: set z_{τ+1}^{-1} = average of current block estimates; send z_B^{τ+1} to A (if τ≥2).
  6. A uses z_B^{τ+1} to update the instance that asked for p_τ (one‑block delay). Two instances alternate.
  7. Repeat.

- **Design tradeoffs:**
  - Block length B: Larger B reduces number of blocks but increases delay and might require more gossip rounds for precision? Actually B is fixed by theory: B = O(√(ρ⁻¹ log(KT)/√ρ)). Tradeoff: too small B → insufficient mixing; too large B → higher delay but fewer blocks. Practitioners might adjust if ρ is known.
  - Exploration α (and β): Larger α improves mixing error bound but increases regret. 1/T is minimax optimal. In linear bandits, β balances second-order term.
  - Gossip matrix W: Choose a doubly-stochastic matrix with large spectral gap ρ to minimize communication cost. For a given graph, Metropolis-Hastings is a common choice.

- **Failure signatures:**
  - Regret higher than theory: likely due to insufficient mixing. Check consensus error max_i ‖z_B^τ(i) − s z_τ‖; if large, B may be too small or ρ overestimated.
  - Importance weights explode: Check p_τ(i, At(i)) never falls below α/K = 1/(KT). If it does, mixing was implemented incorrectly. Also monitor magnitude of pℓ_t; should be ≤ KT.
  - Off‑by‑one delay error: In trivial loss setting (all arms equal), regret should be near zero. If not, indexing is wrong.
  - Communication overhead: In linear case, if not using spanner, per-round communication becomes O(K) instead of O(d). Verify that only |S| numbers are sent.

- **First 3 experiments:**
  1. **Mixing error validation:** Run Algorithm 1 with a fixed action distribution (e.g., uniform) and random loss estimates. Measure consensus error after B gossip steps for various B and ρ. Verify exponential decay and match Lemma 1’s bound.
  2. **End‑to‑end regret scaling:** Use a simple delayed‑robust base algorithm (e.g., Exp3) as A. Test on a small graph (ring of 4 nodes) with adversarial losses. Vary N, K, and graph connectivity (thus ρ) and confirm regret scales as √((ρ⁻¹/² + K/N)·T).
  3. **Linear bandit communication saving:** Implement volumetric spanner construction (e.g., Bhaskara et al.’s method). Verify |S| ≤ 3d and per‑round communication is O(d). Compare communication load against naive approach (sending K‑dimensional vectors). Then test end‑to‑end regret against the claimed bound.

## Limitations
- Precise parameterization (block length B, κ) involves hidden constants; mis‑specification may break the exponential mixing guarantee.
- The linear‑bandit extension relies on volumetric spanners (Prop. 5.2) whose construction is not concretely provided; without an explicit algorithm the O(d) communication claim is uncertain.
- Uniform exploration α=1/T is extremely small, leading to huge importance weights in finite‑time simulations, causing numerical instability.

## Confidence
- **Black‑box reduction to delayed feedback:** High.
- **Minimax optimality claim (Θ̃(√((ρ⁻¹/² + K/N)T))):** Medium (depends on unverified lemmas and constants).
- **Linear bandit extension (Õ(√((ρ⁻¹/² + 1/N)dT)) with O(d) communication):** Low (due to reliance on volumetric spanners without explicit construction).
