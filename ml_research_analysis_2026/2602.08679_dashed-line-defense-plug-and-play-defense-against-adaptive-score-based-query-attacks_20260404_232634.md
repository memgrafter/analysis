# Dashed Line Defense: Plug-And-Play Defense Against Adaptive Score-Based Query Attacks

## Quick Facts
- **arXiv ID:** 2602.08679  
- **Source URL:** https://arxiv.org/abs/2602.08679  
- **Reference count:** 20  
- **Primary result:** DLD achieves 71.9% under‑attack accuracy against worst‑case adaptive attacks on ImageNet (WideResNet), surpassing prior plug‑and‑play defenses (AAA 36.8%, RND 55.7%) while preserving predicted labels.

## Executive Summary
Score‑based query attacks (SQAs) exploit black‑box model scores to generate adversarial examples. Existing plug‑and‑play defenses fail under adaptive tactics that adjust query strategies. Dashed Line Defense (DLD) is a post‑processing method that inserts a non‑continuous, staircase‑like loss mapping between the true margin loss and the observed loss presented to the attacker. This mapping creates ambiguous intervals where a “worse” true loss can appear better (or vice versa), misleading both minimization and maximization steps in zeroth‑order optimization. Theoretically, under a global robustness assumption, the attack success probability decays exponentially with the interval size τ. On ImageNet, DLD attains 71.9% under‑attack accuracy against adaptive attacks (reverse, simulated annealing) on WideResNet‑50, far exceeding AAA and RND. DLD preserves the model’s predicted labels and functions as a plug‑and‑play module without retraining.

## Method Summary
DLD modifies only the top two class scores after model inference. Given logits, it computes the margin loss \(L = f_{y_0} - \max_{y \neq y_0} f_y\). A deterministic function \(D_{\text{post}}(L)\) partitions the loss space into intervals of length τ. Within each interval, a fixed subset \(S\) (e.g., the first 2% and every other 2% thereafter) of inputs is mapped to a lower branch \(L_{\text{low}}(L) = L - h\tau\) and the remainder to an upper branch \(L_{\text{high}}(L) = L + (1|h| - h)\tau\)? Actually the paper defines two branches; we adjust top1 to be \(f_{y_0}' = f_{y_1} + D_{\text{post}}(L)\). All other scores are unchanged, so \(\arg\max_y f_y' = \arg\max_y f_y\). The mapping is non‑continuous and creates local traps that confuse the attacker’s loss comparisons. Default parameters: τ=6, h=0.3, S composed of alternating small intervals.

## Key Results
- DLD attains 71.9% under‑attack accuracy against reverse‑tactic Square Attack on WideResNet‑50, versus 36.8% for AAA‑sine and 55.7% for RND.
- Theoretical bound (Theorem 4.1) shows success probability ≤ \(p^{\lfloor(\tau-\epsilon)/\epsilon\rfloor}\) (exponential in τ), where p is the fraction of intervals mapped to \(L_{\text{high}}\).
- DLD maintains label preservation and demonstrates consistent robustness across multiple architectures (WideResNet, RegNet‑Y, MaxViT‑T) and adaptive attack strategies.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** DLD introduces ambiguity in the observed loss‑to‑true‑loss relationship via a non‑continuous, staircase‑like mapping (\(D_{\text{post}}\)), creating local optimization traps that mislead both minimization and maximization steps.  
**Mechanism:** The loss space is divided into intervals of length τ. Based on a subset S, an input with true loss L is assigned to either a lower branch (observed loss lower) or an upper branch (observed loss higher). Within the same interval, a sample that is truly better (smaller L) may map to the upper branch and appear worse, while a truly worse sample may map to the lower branch and appear better. An attacker using a greedy zeroth‑order optimizer cannot reliably decide which candidate to accept.  
**Core assumption:** The attacker accepts/rejects candidates solely on observed loss comparisons.  
**Evidence anchors:** Abstract; Section 4.2 (formal definition and properties); absence of such non‑continuous mappings in prior defenses.  
**Break condition:** Attacker reliably determines the branch (e.g., via repeated queries on the same input in randomized DLD).

### Mechanism 2
**Claim:** DLD bounds attack success probability exponentially in the interval size τ against a standard, non‑adaptive score‑based query attacker with unlimited queries.  
**Mechanism:** Under a global robustness assumption (model changes by ≤ ϵ per generator step), each accepted candidate reduces true loss by less than ϵ. To reach an adversarial example (margin < ϵ), the attacker must accept a sequence of \(\lfloor(\tau-\epsilon)/\epsilon\rfloor\) samples all mapping to \(L_{\text{high}}\) (so observed loss decreases). The probability of such a sequence is \(p^{\lfloor(\tau-\epsilon)/\epsilon\rfloor}\), where p is the chance of \(L_{\text{high}}\).  
**Core assumption:** The victim model is \((r, \epsilon/2)\)-globally robust (Assumption 4.1); generator moves ≤ r; initial margin ≥ τ.  
**Evidence anchors:** Section 4.3 (Theorem 4.1 statement and proof sketch).  
**Break condition:** Model violates global robustness, allowing larger per‑step loss drops.

### Mechanism 3
**Claim:** DLD degrades adaptive attack tactics (direction reversal, simulated annealing) more effectively than prior monotonic defenses because its mapping simultaneously confounds both minimization and maximization logic.  
**Mechanism:** Prior defenses (e.g., AAA) have monotonic intervals that mislead either minimization or maximization but not both. An adaptive attacker can detect stagnation and flip direction to bypass. DLD’s pattern has no reliably favorable interval: within an interval, \(L_{\text{low}}\) decreases while \(L_{\text{high}}\) increases relative to true loss. This forces frequent, unproductive direction reversals and renders heuristic exploration ineffective.  
**Core assumption:** Attacker adapts based on observed loss trends (e.g., reverses after t stagnations).  
**Evidence anchors:** Section 4.1 (AAA vulnerability analysis); Section 4.4 (adaptive tactics); Section 5.2 (Table 1 DLD worst‑case > others).  
**Break condition:** Perfectly tuned simulated annealing that eventually accepts almost all candidates; empirical results (SA tactic) still favor DLD.

## Foundational Learning
- **Zeroth‑Order Optimization (ZOO):** SQAs are ZOO processes—they estimate gradients or search directions using only loss queries. Understanding ZOO explains why the loss mapping is the attack surface and how ambiguity disrupts gradient estimation.  
  *Quick check:* How does a ZOO attacker use successive loss queries to decide whether a candidate \(x_{\text{new}}\) is better than \(x_{\text{current}}\)?

- **Global Robustness (Lipschitz Stability):** Assumption 4.1 (\((r, \epsilon/2)\)-global robustness) bounds how much true loss can change per step. This is critical for Theorem 4.1’s exponential bound, as it ensures the attacker needs many steps to reach an adversarial example.  
  *Quick check:* If a model is \((\delta, \epsilon)\)-globally robust, what does that imply about the score difference for a class y when inputs \(x_1\) and \(x_2\) are within \(\delta\)?

- **Post‑processing vs. Pre‑processing Defenses:** DLD is a post‑processing defense: it modifies output scores after inference but before returning them, preserving the predicted label. Pre‑processing (e.g., RND) alters inputs and may change predictions. Post‑processing enables plug‑and‑play deployment without retraining or label alteration.  
  *Quick check:* Why might a pre‑processing defense like RND reduce accuracy on benign inputs, while DLD does not?

## Architecture Onboarding

### Component Map
Input (clean sample x₀, model f) → DLD Module (compute margin loss L; apply Dₚₒₛₜ(L) using τ, h, S; adjust top score to second_best + Dₚₒₛₜ(L)) → Output (perturbed scores f'(x) with same argmax as f(x))

### Critical Path
1. Run model to obtain logits for x.  
2. Identify top‑1 class score \(c_1\) and top‑2 score \(c_2\).  
3. Compute margin loss \(L = c_1 - c_2\).  
4. Apply deterministic function \(D_{\text{post}}\) based on interval τ and subset S to get transformed loss \(L'\).  
5. Set new top‑1 score \(c_1' = c_2 + L'\); leave all other scores unchanged.  
6. Return modified logits.

### Design Tradeoffs
- **τ (interval length):** Larger τ increases defense strength (higher pⁿ bound) but distorts confidence scores more.  
- **|S| (proportion of Lₕᵢ𝓰ₕ):** Smaller |S| increases ambiguity (reduces p) but makes Dₚₒₛₜ more continuous, weakening defense against direction‑reversal attacks; |S|≈0.5 is a robust default.  
- **h (branch separation):** Controls vertical gap between branches; larger h increases observed loss difference but may affect global robustness parameters (δ, ε+2τ).  

### Failure Signatures
- **Parameter misuse:** τ too small relative to the attacker’s noise budget allows easy interval jumps.  
- **Implementation bug:** Modifying more than the top score changes the predicted label, violating plug‑and‑play guarantee.  
- **Adaptive overfitting:** Tuning only for known tactics (reverse) may leave vulnerability to novel heuristics.

### First 3 Experiments
1. **Baseline replication:** Apply DLD (τ=6, h=0.3, S as defined) to a pretrained WideResNet‑50. Run standard Square Attack (ℓ∞=0.05, queries = 2500). Expected under‑attack accuracy ≈ 70% (Table 1, DLD‑determine).  
2. **Adaptive stress test:** Run reverse‑tactic Square Attack (t=23). Expected DLD accuracy > 70% while AAA‑sine drops to ~ 41.5%. Confirms resilience to direction reversal.  
3. **Parameter sensitivity:** Vary the ratio of intervals in S from 0.005 to 0.99 with step = 0.04, τ=6. Plot accuracy vs. ratio for standard, reverse, and SA tactics; expect sharp drop only when ratio < 0.015 (reverse effective) and ratio > 0.9 (weak defense).

## Open Questions the Paper Calls Out
- **How can DLD’s theoretical guarantees be extended beyond the global robustness assumption to models that may only satisfy local smoothness?**  
  Verifying global robustness is computationally expensive; if the assumption fails, the exponential success bound may not hold. Deriving bounds under weaker assumptions (e.g., local Lipschitz) and empirical validation on models that violate Assumption 4.1 would resolve this.

- **Can more sophisticated adaptive attacks that explicitly learn DLD’s periodic non‑continuous loss mapping break the defense?**  
  Heuristic attacks (reverse, SA) may not capture the deterministic structure. An attacker that probes the mapping to avoid traps could achieve higher success. Evidence: design an attack that infers the Lₕᵢ𝓰ₕ/Lₗₒ𝘸 branch by repeated queries on fixed inputs and demonstrate significantly higher success rates.

- **How does DLD generalize across diverse datasets and architectures, and can its hyperparameters (τ, h, S) be set automatically?**  
  Experiments are limited to ImageNet and three models; different data distributions and model depths may shift the optimal trade‑off. Evaluation on multiple datasets (e.g., CIFAR‑10, ImageNet‑C) and model families, plus an adaptive parameter selection method (e.g., based on validation attacks), would resolve this.

- **Does combining DLD with training‑time defenses like adversarial training yield synergistic robustness, or do they interfere?**  
  Adversarial training alters the loss landscape; interaction with DLD’s post‑processing is unclear. Training models with standard adversarial training, then applying DLD, and measuring robustness against a suite of adaptive SQAs compared to each alone would provide evidence.

## Limitations
- The theoretical guarantee relies on a strong global robustness assumption that is unlikely to hold exactly for large neural networks.  
- Empirical evaluation is confined to ImageNet and three architectures; broader generalization is not demonstrated.  
- While label preservation is proven, the impact of DLD on score calibration for downstream tasks (e.g., uncertainty estimation) remains unevaluated.

## Confidence
- **Ambiguity via non‑continuous loss mapping:** High confidence (clear algorithmic description, ablation showing superiority over monotonic defenses).  
- **Theoretical exponential bound (Theorem 4.1):** Medium confidence (proof sound but depends on strict global robustness assumption).  
- **Superiority against tested adaptive attacks (reverse, SA):** High confidence (empirical results across three models).  
- **Superiority against unseen adaptive strategies:** Low confidence (only heuristic tactics evaluated).  
- **Plug‑and‑play claim (label preservation):** Medium confidence (mathematically argued but not tested on diverse downstream pipelines).

## Next Checks
1. **Relax global robustness assumption:** Empirically estimate model Lipschitz constants and test whether DLD’s success probability still decays exponentially with τ.  
2. **Novel adaptive attack:** Construct an attacker that actively probes Dₚₒₛₜ’s branch mapping by repeated queries around the current best sample and measure attack success rate.  
3. **Score calibration impact:** Evaluate DLD’s effect on misclassification detection and out‑of‑distribution detection using reliability diagrams and AUROC.
