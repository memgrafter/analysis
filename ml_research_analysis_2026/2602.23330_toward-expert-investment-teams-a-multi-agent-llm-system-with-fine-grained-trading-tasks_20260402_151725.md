# Toward Expert Investment Teams:A Multi-Agent LLM System with Fine-Grained Trading Tasks

## Quick Facts
- **arXiv ID:** 2602.23330  
- **Source URL:** https://arxiv.org/abs/2602.23330  
- **Reference count:** 40  
- **Primary result:** Fine-grained task decomposition significantly improves risk-adjusted returns (Sharpe ratio) compared to coarse-grained designs in a multi-agent LLM trading system applied to Japanese equities.

## Executive Summary
The paper tackles a key limitation in existing multi-agent LLM trading systems: the use of coarse, abstract role instructions that do not align with real-world investment analyst workflows, leading to suboptimal performance and poor interpretability. The authors propose replacing these with fine-grained, concrete sub-tasks—such as providing pre-calculated technical indicators (e.g., MACD, RSI) instead of raw price series—to better mimic professional analysis. Backtesting on Japanese stocks (2023–2025) shows that the fine-grained design substantially improves Sharpe ratios across most portfolio sizes. Ablation studies reveal the Technical Agent as the primary driver of performance, while analysis of agent outputs indicates that fine-grained prompts foster more domain-specific terminology and better semantic alignment between lower-level analysts and higher-level managers. Finally, combining the system’s outputs with a market index (TOPIX 100) yields superior risk-adjusted returns due to low correlation, demonstrating the value of meticulous prompt design via task decomposition.

## Method Summary
The study compares fine-grained versus coarse-grained prompt designs in a hierarchical multi-agent LLM trading system. The system comprises seven agents: four Level-1 analysts (Technical, Quantitative, Qualitative, News), two Level-2 aggregators (Sector, Macro), and a Level-3 portfolio manager (PM). The backtest uses TOPIX 100 constituents from September 2023 to November 2025, with data from Yahoo Finance, EDINET, Ceek.jp News, and FRED. Models (GPT‑4o, temperature 1.0) are invoked monthly; each agent outputs a 0–100 score and a Japanese rationale. Fine-grained agents receive pre‑computed metrics (e.g., normalized MACD, ROE, sector‑adjusted ratios), while coarse-grained agents receive raw data (price series, financial line items). The PM synthesizes scores into final rankings, and long‑short equal‑weight portfolios (N ∈ {10,20,30,40,50}) are constructed monthly. Performance is measured primarily by Sharpe ratio, supplemented by textual analyses (log‑odds, cosine similarity) to assess interpretability and semantic alignment.

## Key Results
- Fine-grained task decomposition significantly improved Sharpe ratios compared to coarse-grained baselines for 4 out of 5 portfolio horizons (N=10–50).  
- Ablation experiments showed that removing the Technical Agent caused the largest Sharpe degradation in the fine-grained setting (e.g., ΔSharpe ≈ –0.66 for N=50), whereas removing other agents sometimes improved performance, suggesting they introduced noise.  
- Fine-grained prompts generated more domain-specific terminology and increased semantic similarity (cosine) between Technical and Sector agents, enhancing information flow.  
- Portfolio optimization that combined the multi-agent strategy with TOPIX 100 achieved superior risk-adjusted returns due to low correlation between the strategy and the index.

## Why This Works (Mechanism)
### Mechanism 1: Fine‑Grained Task Decomposition Improves Risk‑Adjusted Returns
- **Claim:** Replacing abstract role instructions with concrete, pre‑specified analytical sub‑tasks (e.g., “evaluate momentum via MACD”) improves risk‑adjusted returns by reducing output ambiguity and aligning with real‑world investment workflows.
- **Mechanism:** LLMs follow structured procedural prompts more faithfully than high‑level objectives; domain‑standard metrics serve as semantic anchors that mitigate the model’s tendency to produce superficial or truncated reasoning.
- **Evidence:** Backtests show fine‑grained agents outperform coarse‑grained counterparts in 4 of 5 tested horizons (Section 6.1).  
- **Core assumption:** LLMs can reliably execute well‑defined financial calculations when given concrete input formats.
- **Break condition:** LLM ignores structured inputs or the specified metrics become irrelevant in a shifted market regime.

### Mechanism 2: Enhanced Interpretability via Terminology Alignment
- **Claim:** Fine‑grained prompts improve interpretability and information flow by inducing domain‑specific vocabulary that is propagated through the agent hierarchy.
- **Mechanism:** Pre‑specifying tasks cues the LLM to generate outputs containing specialized terms (e.g., “momentum,” “volatility”), which higher‑level agents then reuse, creating a traceable reasoning chain.
- **Evidence:** Fine‑grained settings produce more nuanced analytical terms, and higher‑level agents inherit vocabulary from lower‑level agents (Section 6.3.1). Cosine similarity between Technical and Sector agents increases significantly under fine‑grained prompts (Δ=0.022) but not coarse‑grained (Section 6.3.2).
- **Core assumption:** Lexical consistency reflects meaningful signal propagation rather than superficial mimicry.
- **Break condition:** LLM generates plausible but semantically disconnected jargon, or manager agents disregard subordinate outputs regardless of terminology.

### Mechanism 3: The Technical Agent as Primary Performance Driver
- **Claim:** The performance gain from fine‑grained decomposition is largely driven by the Technical Agent, whose signals are effectively transmitted in the hierarchy.
- **Mechanism:** Detailed technical indicator specifications (e.g., normalized MACD, RSI, KDJ) allow the Technical Agent to produce evaluative scores that the Sector Agent can synthesize; coarse prompts yield vague price descriptions that are less actionable.
- **Evidence:** In fine‑grained ablation, removing the Technical Agent causes a large Sharpe drop (e.g., –0.66 for N=50), while coarse‑grained “w/o Technical” sometimes improves performance (Section 6.2). Semantic similarity between Technical and Sector agents rises only under fine‑grained prompts.
- **Core assumption:** Technical analysis contributes unique alpha in the Japanese TOPIX 100 market during 2023–2025.
- **Break condition:** Market regimes where technical indicators fail (e.g., low liquidity) or the Sector Agent overrides technical inputs regardless of alignment.

## Foundational Learning
**Concept: Domain‑Driven Task Decomposition**  
- *Why needed here:* The system mimics human investment teams; understanding standard analyst workflows (e.g., how fundamental analysts calculate valuation multiples, how technicians derive signals) is prerequisite to defining fine‑grained tasks.  
- *Quick check question:* What are the typical steps in a sell‑side equity analyst’s monthly stock review process, and which steps can be operationalized as discrete LLM tasks?

**Concept: LLM Prompt Engineering for Structured Output**  
- *Why needed here:* Agents must output JSON‑formatted scores and Japanese rationales; fine‑grained prompts must balance specificity (e.g., “use normalized MACD histogram”) with constraints (e.g., output ≤ 50 Japanese characters).  
- *Quick check question:* How does constraining an LLM’s output format (JSON, character limit) trade off against reasoning flexibility, and what prompt elements enforce compliance?

**Concept: Hierarchical Multi‑Agent Information Synthesis**  
- *Why needed here:* The bottom‑up (analyst→sector→PM) and top‑down (macro→PM) flows create potential for signal dilution; understanding how textual outputs propagate is key to diagnosing performance.  
- *Quick check question:* In a hierarchical LLM agent system, what are the risks of information loss at each aggregation layer, and how can prompt design mitigate them?

## Architecture Onboarding
**Component map:**  
Technical Agent → Quantitative Agent → Qualitative Agent → News Agent → Sector Agent → PM Agent  
Macro Agent → PM Agent  
Data Pipeline (prices → indicators; financials → metrics; news → text; macro → scores)

**Critical path:**  
1. Data preprocessing: Calculate all numerical inputs (MACD, RoC, sector averages) before agent invocation—agents do not compute raw metrics.  
2. Parallel analyst execution: Technical/Quant/Qual/News agents run concurrently per stock.  
3. Sector aggregation: Sector Agent consumes all four analyst outputs plus sector context.  
4. Parallel macro execution: Macro Agent runs independently per month.  
5. PM synthesis: PM Agent consumes Sector and Macro outputs to produce final scores.  
6. Portfolio construction: Rank stocks by final score; select top N for long and bottom N for short, equal‑weighted, rebalanced monthly.

**Design tradeoffs:**  
- *Fine‑grained vs. coarse prompts:* Fine‑grained improves performance/interpretability but requires deep domain knowledge and increases preprocessing complexity. Coarse‑grained is simpler but yields noisier signals.  
- *Natural language vs. structured communication:* JSON and Japanese rationale aid interpretability and semantic analysis but may constrain LLM reasoning depth; machine‑oriented token systems could improve efficiency but reduce transparency.  
- *Hierarchical vs. flat structure:* Hierarchical flow mirrors institutions and allows semantic alignment checks but risks information loss at each layer; flat systems may preserve raw signals but become less controllable.

**Failure signatures:**  
1. Low semantic similarity: Cosine similarity between Sector Agent and subordinate agents (especially Technical) below ~0.4 (vs. paper’s ~0.42 fine‑grained) indicates poor information propagation.  
2. Ablation sensitivity: Removing Technical Agent causes Sharpe ratio drop > 0.4 in fine‑grained setting; if removal improves performance, signals are noise.  
3. Output format violations: Agents producing non‑JSON or exceeding rationale length suggest prompt confusion or insufficient constraints.  
4. Sector context mismatch: Sector Agent fails to adjust scores relative to sector averages (e.g., high‑ROE stock not flagged if sector average is higher).  
5. Macro override anomalies: PM Agent drastically lowers scores despite strong sector reports when macro is “Risk‑Off”—if not aligned with economic logic, integration rules are flawed.

**First 3 experiments:**  
1. **Reproduce fine‑vs‑coarse Sharpe comparison:** Configure both prompt variants for Technical and Quantitative agents; run backtest on TOPIX 100 (2023–2025) with N=30; expect fine‑grained Sharpe > coarse‑grained with p<0.05 (Mann‑Whitney).  
2. **Conduct leave‑one‑out ablation:** Systematically remove each analyst agent (Technical, Quant, Qual, News) in fine‑grained setting; verify “w/o Technical” shows largest Sharpe degradation (e.g., ΔSR < –0.4 for N≥30).  
3. **Measure semantic propagation:** For 50 backtest trials, compute cosine similarity (text‑embedding‑3‑small) between Sector Agent outputs and each analyst’s output; expect Technical similarity >0.41 in fine‑grained vs. <0.40 in coarse‑grained.

## Open Questions the Paper Calls Out
**Open Question 1:** Is the performance gain fundamentally due to fine‑grained task decomposition itself or to inadvertent linguistic patterns that align with LLM preferences?  
*Basis:* The authors state (Section 7.2): “it is not yet fully clear whether the performance gains are fundamentally attributable to fine‑grained task decomposition itself. One alternative explanation is that certain vocabulary patterns may be more easily adopted by the preference of LLMs to influence downstream agents.” The experiment varies prompt granularity but cannot fully disentangle structural task design from lexical priming.  
*Resolution would require:* Controlled experiments that systematically vary task descriptions while holding vocabulary constant across granularity levels, or comparisons across LLMs with known linguistic biases.

**Open Question 2:** How robust is the fine‑grained approach across extended market regimes (e.g., bull, bear, high volatility) beyond the limited backtesting window?  
*Basis:* The backtest period is restricted to September 2023–November 2025 (27 months) due to LLM knowledge cutoff (Section 3.1), and the authors note (Section 7.2) that “financial markets exhibit strong regime shifts over longer horizons, and therefore, longer‑term validation is necessary.” The short window may not capture diverse economic cycles.  
*Resolution would require:* Longer backtests using time‑aware LLMs or synthetic data that respect temporal consistency, with performance segmented by clearly defined market regimes (e.g., NBER recession dates or volatility thresholds).

**Open Question 3:** Do the findings generalize to other financial markets (e.g., US equities) and different LLM architectures?  
*Basis:* The study focuses exclusively on Japanese TOPIX 100 stocks and uses GPT‑4o (Section 3.1 & 7.2). The authors speculate general validity but acknowledge (Section 7.2) that “the scope of this analysis is sufficient” only because of their industrial focus and model knowledge of the Japanese market. Market microstructure, data availability, and LLM training biases vary across regions and models.  
*Resolution would require:* Replication studies using comparable multi‑agent setups on other major markets (e.g., S&P 500) with multiple state‑of‑the‑art LLMs, comparing Sharpe ratios and ablation patterns.

**Open Question 4:** Why do some specialist agents (e.g., Quantitative, Qualitative) degrade performance when included in the fine‑grained setting, as indicated by positive Sharpe differences upon their removal?  
*Basis:* Ablation results (Table 2a) show that removing Quantitative, Qualitative, or Macro agents often improves Sharpe ratios (positive differences), while removing the Technical agent harms performance. This suggests these agents introduce noise or redundancy in the fine‑grained coordination. The paper does not diagnose whether this stems from conflicting signals, poor integration with the Sector Agent, or inherent noisiness of textual outputs.  
*Resolution would require:* Fine‑grained analysis of agent outputs (e.g., inter‑agent score correlations, textual consistency checks) and experiments with alternative aggregation logic in the Sector Agent to pinpoint the source of degradation.

**Open Question 5:** Does task granularity affect the correlation structure among multiple agent strategies, thereby influencing the diversification benefits observed in portfolio optimization?  
*Basis:* The portfolio optimization (Section 6.4) combines six agent strategies due to their low correlation with TOPIX 100, but it treats strategies as heterogeneous without examining whether fine‑grained task design itself alters inter‑strategy correlations. It remains unclear if the low correlation arises from data‑source heterogeneity or from prompt granularity.  
*Resolution would require:* Compute correlation matrices between agent strategy returns under both fine‑grained and coarse‑grained settings; test whether granularity systematically reduces pairwise correlations and improves risk‑parity portfolio performance.

## Limitations
- Data access: Raw EDINET/Ceek.jp datasets and exact extraction pipeline are not public, risking misalignment in replication.  
- Prompt fidelity: Appendix B may omit minor details; exact wording and JSON formatting are critical for faithful reproduction.  
- LLM non‑determinism: The paper aggregates 50 independent trials; scaling this financially and computationally is challenging.  
- Universe definition: Unclear whether TOPIX 100 constituents are fixed or rebalanced monthly, potentially affecting investment universe consistency.

## Confidence
- **Mechanism 1 (Fine‑grained tasks → higher Sharpe):** Medium. Backtest shows consistent improvement but lacks out‑of‑sample and alternative market tests.  
- **Mechanism 2 (Improved interpretability via terminology):** Low. Semantic similarity is correlational and may reflect superficial jargon adoption rather than meaningful signal propagation.  
- **Mechanism 3 (Technical Agent as key driver):** Medium. Ablation effect is strong but could conflate with regime‑specific technical alpha.
