# DeformTrace: A Deformable State Space Model with Relay Tokens for Temporal Forgery Localization

## Quick Facts
- **arXiv ID:** 2603.04882
- **Source URL:** https://arxiv.org/abs/2603.04882
- **Reference count:** 15
- **Primary result:** DeformTrace achieves SOTA on LA V-DF (97.1% mAP@0.5, 93.3% mAR@100) and A V-Deepfake1M (92.0% mAP@0.5, 86.2% mAR@50) with 20.8M parameters and 104ms inference.

## Executive Summary
Temporal Forgery Localization (TFL) in audio-visual deepfakes faces challenges of ambiguous boundaries, sparse forgeries, and long-range decay in standard State Space Models (SSMs). DeformTrace proposes a hybrid SSM-Transformer architecture with three novel components: Deformable Self-SSM (DS-SSM) for dynamic temporal sampling, a Relay Token Mechanism to mitigate long-range decay, and Deformable Cross-SSM (DC-SSM) for query-specific cross-sequence interaction. These innovations enable precise localization while maintaining efficiency. Evaluated on LA V-DF and A V-Deepfake1M, DeformTrace sets new state-of-the-art with 97.1% mAP@0.5 on LA V-DF and 92.0% mAP@0.5 on AV-Deepfake1M, while using significantly fewer parameters (20.8M vs. 49.7M in UMMAFormer) and achieving faster inference (104ms vs. 857ms). The method demonstrates a superior performance-efficiency trade-off for TFL.

## Method Summary
DeformTrace processes untrimmed audio-visual streams using frozen pre-trained Raven backbones to extract multi-scale features. The encoder employs a Deformable Self-SSM (DS-SSM) that replaces fixed temporal receptive fields with dynamically sampled points predicted by an MLP, enabling flexible context aggregation. Relay tokens are periodically inserted into the sequence to partition it into subspaces, allowing local state updates to be aggregated and broadcast, thus combating long-range decay. The decoder, based on a DETR-style set prediction framework, uses Deformable Cross-SSM (DC-SSM) where each forgery query predicts offsets to sample context from the encoder output, forming a query-specific subspace processed by an SSM; only the final token is retained, focusing the representation on forgery-relevant information. Auxiliary losses (L_enh, L_coop) regularize relay tokens. The hybrid design combines SSM linear complexity with Transformer attention for global patterns, achieving high accuracy with low computational cost.

## Why This Works (Mechanism)

### DS-SSM for Ambiguous Boundary Localization
Deformable Self-SSM (DS-SSM) replaces fixed temporal receptive fields with dynamic sampling. For each token at a reference time, an MLP predicts multi-scale temporal offsets, and bilinear interpolation samples features at these deformable points. This adapts to ambiguous forgery boundaries by gathering context from semantically relevant locations. Evidence: The paper states that DS-SSM "better captures semantically relevant context beyond local fixed windows" (p.2). Break condition: If forgery cues are extremely short, the overhead may outweigh benefits and introduce noise.

### Relay Token Mechanism for Mitigating Long-Range Decay
Relay Token Mechanism inserts learnable global tokens periodically into the sequence, partitioning it into subspaces. Within each subspace, local SSM states pass information to the relay token, which is then broadcast to other subspaces. This creates a sparse pathway to mitigate exponential decay in standard SSMs. Evidence: The paper reports a clear gain (+1.6% mAP, +1.0% mAR) when adding relay tokens in ablation (p.4). Break condition: Performance peaks at N_r=8; too few or too many tokens degrade accuracy.

### DC-SSM for Sparse Forgery Sensitivity
Deformable Cross-SSM (DC-SSM) partitions the global state space into query-specific subspaces. Each decoder query predicts offsets to sample from the encoder context; the sampled sequence is processed by an SSM, but only the final token is retained. This prevents the state from being polluted by non-forgery context and enhances sensitivity to sparse forgeries. Evidence: Standalone DC-SSM yields a large gain (+6.4% mAP) over vanilla SSM baseline (Table 4, Line 3). Break condition: Requires accurate query proposals; ineffective if forgeries are dense or queries inaccurate.

## Architecture Onboarding

### Component Map
Input (audio-visual stream) -> Feature Extraction (frozen Raven backbones, multi-scale sequences) -> Encoder: DS-SSM (with relay tokens) + Deformable Self-Attention + FFN -> Context sequence X^E -> Decoder: DC-SSM + MHSA + Deformable Cross-Attention + FFN + offset MLP (M layers) -> Final queries and proposals.

### Critical Path
The core innovation path is: (a) DS-SSM with dynamic sampling for precise encoder context, (b) Relay tokens inserted within DS-SSM to propagate long-range information, (c) DC-SSM in decoder for query-specific, forgery-focused context retrieval. Misimplementation in any of these three breaks the claimed benefits.

### Design Tradeoffs
- **Deformable sampling vs. complexity**: MLP overhead balanced by SSM linearity.
- **Relay tokens (N_r)**: Tradeoff between combating decay and over-fragmentation; optimal N_r proportional to N_q.
- **Hybrid vs. pure SSM**: Attention needed for global patterns; pure SSM may fail on sparse, global patterns.

### Failure Signatures
1. **No relay gain**: Ablating relay tokens shows no performance drop (check N_r tuning, loss weights λ₁, λ₂).
2. **DS-SSM instability**: Offset predictions cause out-of-bounds sampling or NaN (monitor offset distribution, clamp coordinates).
3. **DC-SSM query collapse**: Queries attend to similar contexts (monitor offset diversity per query).

### First 3 Experiments
1. **Ablation Core Components**: Reproduce Table 4. Start with vanilla SSM baseline, add DS-SSM only, DC-SSM only, then both, finally full with relay+losses. Isolate contributions.
2. **Relay Token Sensitivity**: Vary N_r ∈ {0,1,2,4,8,16,32} on AV-Deepfake1M validation. Expect peak at N_r=8; performance drops for extremes.
3. **Visualization of Deformable Sampling**: For test forgeries, visualize DS-SSM offsets (smoothness) and DC-SSM query offsets (diversity around anchors). Check if offsets are temporally consistent and queries focus differently.

## Open Questions the Paper Calls Out
1. **Generalization to unseen forgeries/cross-dataset?** Only LA V-DF and AV-Deepfake1M are evaluated; no tests on novel forgery techniques or other benchmarks, leaving transferability uncertain.
2. **Theoretical explanation for Relay Token decay mitigation?** Mechanism introduced empirically; no analysis of its effect on SSM state space dynamics (e.g., spectral properties) is provided.
3. **Robustness to audio-visual misalignment?** Input requires temporally aligned streams; no mechanism for misalignment is described, which is common in real-world videos.

## Limitations
- FB-SSM scan merging details underspecified, hindering exact replication.
- Deformable attention modules (from TadTR) lack precise hyperparameters such as number of sampling points and heads.
- Raven backbone feature extraction pipeline and pretrained weight accessibility remain ambiguous.
