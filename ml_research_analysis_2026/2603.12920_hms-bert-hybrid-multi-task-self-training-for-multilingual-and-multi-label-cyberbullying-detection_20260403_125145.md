# HMS-BERT: Hybrid Multi-Task Self-Training for Multilingual and Multi-Label Cyberbullying Detection

## Quick Facts
- **arXiv ID:** 2603.12920
- **Source URL:** https://arxiv.org/abs/2603.12920
- **Reference count:** 27
- **Primary result:** Achieves macro F1-score of 0.9847 on multi-label cyberbullying detection and 0.6775 accuracy on the main three-class task.

## Executive Summary
HMS-BERT is a framework for multilingual, multi-label cyberbullying detection that addresses the limitations of monolingual and single-task approaches. It combines a multilingual BERT (mBERT) backbone with handcrafted linguistic features and jointly optimizes a fine-grained multi-label classifier and a coarse-grained three-class classifier. To handle low-resource languages, an iterative self-training strategy with confidence-based pseudo-labeling transfers knowledge from English to Chinese. Evaluated on four public datasets, the model demonstrates state-of-the-art performance, with ablation studies confirming the contribution of each component.

## Method Summary
The method uses `bert-base-multilingual-cased` as a shared encoder. Input text is processed in two parallel streams: one through mBERT to obtain contextual embeddings, and another to extract handcrafted features (e.g., punctuation frequency, sensitive word indicators). The mBERT `[CLS]` token embedding is concatenated with the handcrafted feature vector and fed into two task-specific heads: a multi-label head (sigmoid activation) for overlapping abuse subtypes and a main head (softmax activation) for Hate/Offensive/Normal classification. The total loss is a weighted sum of binary cross-entropy for the multi-label task and cross-entropy for the main task, with weight λ=0.7. For cross-lingual transfer, the model is first trained on labeled English data (HateXplain). Then, an iterative self-training loop adds high-confidence pseudo-labeled samples from unlabeled Chinese data (SCCD) to the training set, with the confidence threshold decaying from 0.9 to 0.85 over three iterations.

## Key Results
- Macro F1-score of 0.9847 on the multi-label abuse detection task.
- Accuracy of 0.6775 on the main three-class (Hate/Offensive/Normal) classification task.
- Ablation studies confirm that feature fusion, joint multi-task optimization, and self-training each provide measurable performance gains.

## Why This Works (Mechanism)
### Mechanism 1: Feature Fusion for Multilingual Cues
The model fuses mBERT's contextual embeddings with handcrafted linguistic features (e.g., punctuation frequency, sensitive word flags). This hybrid representation leverages mBERT's cross-lingual semantic transfer while incorporating deterministic, language-agnostic heuristics that capture explicit abuse cues potentially missed by purely contextual models. The two streams are concatenated before classification. The core assumption is that these handcrafted features are sufficiently language-normalizable to complement mBERT. Evidence includes the architecture description and ablation showing performance drops when they are removed. A break condition occurs if features are not truly language-agnostic, introducing noise that degrades transfer.

### Mechanism 2: Joint Multi-Task Optimization
A shared mBERT backbone feeds two parallel output heads: a multi-label head (sigmoid) for overlapping abuse subtypes and a main head (softmax) for the three coarse classes. The total loss combines their losses with λ=0.7, prioritizing the multi-label task. This encourages the shared representation to capture both nuanced and general aggression cues. The core assumption is that the tasks share underlying patterns. Evidence is provided by the loss equations and the benefit shown in ablation. A break condition arises if the tasks conflict (e.g., an "Offensive" sample with no specific subtype), potentially destabilizing training if λ is misaligned.

### Mechanism 3: Confidence-Based Self-Training for Cross-Lingual Transfer
Starting from a model trained on labeled English data, the framework iteratively pseudo-labels unlabeled Chinese data. Samples with prediction probability above a confidence threshold τ (initially 0.9, decaying to 0.85) are added to the training pool, and the model is retrained. This bootstraps cross-lingual knowledge transfer using mBERT's initial alignment. The core assumption is that high-confidence pseudo-labels are sufficiently accurate to provide a useful training signal. Evidence is the algorithm description and support from literature on self-training for low-resource settings. A break condition is error accumulation if initial cross-lingual transfer is too weak, leading to noisy pseudo-labels that reinforce incorrect patterns.

## Foundational Learning
- **Concept: Multilingual Contextual Embeddings (mBERT)**
  - **Why needed:** mBERT maps semantically similar text across English and Chinese into a shared vector space, enabling zero-shot transfer before task-specific fine-tuning.
  - **Quick check:** Why might mBERT’s cross-lingual transfer be less effective for Chinese cyberbullying compared to English, even though both are in the training corpus?

- **Concept: Multi-Label Classification with Sigmoid Activation**
  - **Why needed:** Cyberbullying subtypes often co-occur; sigmoid outputs allow independent probabilities per label, modeling overlaps unlike softmax’s mutual exclusivity.
  - **Quick check:** How does binary cross-entropy loss with sigmoid differ from categorical cross-entropy with softmax in a multi-label setting?

- **Concept: Self-Training via Pseudo-Labeling**
  - **Why needed:** Labeled Chinese data is scarce; pseudo-labeling leverages unlabeled text by iteratively adding high-confidence predictions to the training set.
  - **Quick check:** What are two risks of self-training with pseudo-labels, and how does the confidence decay mechanism mitigate one of them?

## Architecture Onboarding
- **Component map:** Input -> Preprocessing -> Tokenizer (mBERT) -> mBERT Encoder -> Handcrafted Feature Extractor -> Feature Fusion (concatenation) -> Dual-Task Heads -> Loss Calculator -> Backpropagation. For self-training: Inference on unlabeled data -> Confidence-based selection -> Augment labeled pool -> Retrain.
- **Critical path:** Raw text undergoes preprocessing and tokenization. mBERT generates `[CLS]` embedding; handcrafted features are extracted. Their concatenation feeds two heads (multi-label and main). Joint loss guides training. In self-training rounds, pseudo-labeled samples are selected and added, then the model is retrained.
- **Design tradeoffs:** mBERT size (12-layer) balances capacity and speed; fixed λ=0.7 prioritizes multi-label learning but may neglect main task; confidence threshold τ starts high (0.9) for quality but decays (to 0.85) to expand data, with fixed decay possibly not adapting to noise.
- **Failure signatures:** Significant multi-label F1 drop when removing handcrafted features; lower Chinese vs. English main-task accuracy; training loss divergence after adding pseudo-batches; higher MAE/MSE without self-training.
- **First 3 experiments:**
  1. Baseline: Fine-tune mBERT on labeled English only (no fusion, no self-training).
  2. Ablation: Remove self-training but keep feature fusion and multi-task.
  3. Ablation: Remove multi-label branch, train only on main task with same data.

## Open Questions the Paper Calls Out
- **How does cross-lingual transfer performance vary across other low-resource languages, and which linguistic factors most affect it?** The paper evaluates only English and Chinese, leaving broader generalizability unexamined.
- **Can adaptive confidence thresholding in self-training improve robustness compared to the fixed decay strategy?** The paper uses heuristic decay and suggests more sophisticated strategies are needed.
- **Are handcrafted linguistic features necessary, or can they be replaced by end-to-end learned features from mBERT?** The framework fuses them, but their necessity versus automated alternatives is not investigated.
- **How sensitive is the multi-task loss weighting (λ=0.7) to dataset and language characteristics, and would dynamic weighting improve joint optimization?** Static λ may not balance tasks optimally across diverse settings.

## Limitations
- Unspecified rule-based mapping from HateXplain annotations to the three main classes.
- Incomplete definition of handcrafted features, particularly the sensitive word lexicon for both languages.
- Missing dataset split details and random seeds, hindering reproducibility.
- Exceptionally high reported F1-score raises concerns about reproducibility and potential overfitting.

## Confidence
- **Fusion claim (handcrafted features enhance detection):** Medium confidence. Ablation shows benefit, but language-agnosticity of features is unverified.
- **Joint optimization claim (dual heads improve both tasks):** Medium confidence. Design is plausible, but potential task conflict is not addressed.
- **Self-training claim (pseudo-labeling enables cross-lingual transfer):** Low confidence. Reliance on high-confidence pseudo-labels risks error accumulation; no noise analysis provided.
