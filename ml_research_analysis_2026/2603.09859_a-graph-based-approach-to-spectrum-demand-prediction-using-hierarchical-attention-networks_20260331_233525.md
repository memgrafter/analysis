# A Graph-Based Approach to Spectrum Demand Prediction Using Hierarchical Attention Networks

## Quick Facts
- **arXiv ID:** 2603.09859
- **Source URL:** https://arxiv.org/abs/2603.09859
- **Reference count:** 25
- **Primary result:** HR-GAT reduces median MAE by 21% compared to eight baseline models across five Canadian cities.

## Executive Summary
This paper introduces HR-GAT, a hierarchical graph attention network for predicting fine-grained spectrum demand to enable dynamic spectrum sharing. By constructing a multi-resolution graph from geospatial tiles and applying attention across scales, the model overcomes spatial autocorrelation issues that plague traditional machine learning approaches. Validated across five Canadian cities, HR-GAT achieves significant accuracy improvements and generalizes to unseen cities, with its demand proxy showing strong correlation with actual operator traffic.

## Method Summary
The method aggregates diverse geospatial features (census, roads, buildings) onto Bing Maps tiles at three zoom levels. These tiles form a hierarchical graph where nodes represent tiles and edges connect neighbors at the same resolution and parent-child across resolutions. A graph attention network processes this structure to predict spectrum demand per tile. The target variable is a "deployed bandwidth" proxy derived from publicly available cell tower data, validated against proprietary traffic measurements.

## Key Results
- Median MAE reduced by 21% versus eight baseline models.
- Cross-validation: median MAE 10.93, RMSE 29.30, R² 0.91.
- Leave-one-city-out test: median MAE 18.74 on unseen city.
- Demand proxy R² = 0.727 against operator traffic data.

## Why This Works (Mechanism)
HR-GAT’s effectiveness stems from three interconnected mechanisms. First, its hierarchical multi-resolution graph explicitly captures spatial dependencies at multiple geographic scales—from city-wide to street-level—addressing the limitation of single-resolution graphs that cannot optimally represent all spatial contexts. This is achieved by embedding each node as a weighted combination of features from three zoom levels and establishing both intra-zoom (adjacent tiles) and inter-zoom (parent-child) edges, enabling cross-scale message passing. Second, the graph attention mechanism dynamically assigns importance weights to neighboring nodes, allowing the model to focus on the most relevant spatial influences rather than assuming uniform contributions, which is critical for heterogeneous urban demand patterns. Third, the validated demand proxy—constructed from publicly observable infrastructure using a propagation model—provides a reliable and privacy-preserving target that correlates strongly (R²=0.727) with actual traffic, enabling supervised learning without proprietary data. Together, these elements allow HR-GAT to generalize well across cities and outperform baselines that ignore spatial hierarchy or use fixed aggregation.

## Architecture Onboarding
**Component map**: Data Ingestion & Gridding → Graph Builder → HR-GAT Network. Proxy Validator runs separately for validation.
**Critical path**: Raw geospatial data → Feature aggregation per tile (all zooms) → Hierarchical graph construction (nodes/edges) → Feature matrix X & Adjacency matrix A → Train/Val/Test split → HR-GAT forward pass (attention + aggregation) → Loss computation → Backpropagation → Model selection.
**Design tradeoffs**:
- Resolution depth (3 zooms) vs. computational cost (more nodes/edges).
- Fixed Gaussian edge weights vs. learnable edges (stability vs. adaptability).
- Single proxy target vs. multi-task demand indicators.
**Failure signatures**:
- Spatial leakage in validation folds (adjacent tiles split across sets).
- Edge explosion from inter-zoom links causing memory issues.
- Proxy mismatch (low OLS R² in training cities) capping performance.
**First 3 experiments**:
1. Replicate proxy validation (OLS) on Ottawa; confirm R² > 0.72.
2. Single-city baseline: Train HR-GAT on Toronto; verify it outperforms Plain GAT and XGBoost.
3. Ablation: Remove inter-zoom edges; compare MAE to full HR-GAT.

None.

## Limitations
- Proxy generalizability assumed across cities but only validated on Ottawa.
- Model is static; temporal dynamics are not explicitly addressed.
- Incremental contribution of hierarchical design versus standard GNNs is not fully isolated.

## Confidence
- **High**: The demand proxy’s strong correlation (R²=0.727) with actual traffic in Ottawa is well-supported.
- **Medium**: The claimed 21% MAE reduction is backed by cross-validation across five cities, but potential confounders in baselines exist.
- **Low**: The assertion that the hierarchical graph construction is the primary performance driver is weakly evidenced; gains might stem from general GNN expressiveness.

## Next Checks
