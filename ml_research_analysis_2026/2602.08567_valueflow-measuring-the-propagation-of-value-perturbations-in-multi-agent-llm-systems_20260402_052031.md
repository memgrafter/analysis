# ValueFlow: Measuring the Propagation of Value Perturbations in Multi-Agent LLM Systems

## Quick Facts
- **ArXiv ID:** 2602.08567
- **Source URL:** https://arxiv.org/abs/2602.08567
- **Reference count:** 31
- **Primary result:** Introduces a perturbation-based framework to quantify how value expressions drift and propagate through multi-agent LLM systems, finding that propagation is shaped by both agent-level susceptibility (β) and network topology.

## Executive Summary
ValueFlow proposes a quantitative framework for analyzing value dynamics in multi-agent LLM systems, where agents influence each other’s expressed value orientations. It defines two key metrics: agent-level β-susceptibility, measuring an individual agent’s sensitivity to peer value signals, and system susceptibility (SS), measuring how a localized perturbation affects final outputs. Using a 56-value dataset derived from the Schwartz Value Survey and an LLM-as-a-judge protocol, experiments across models and topologies reveal that β varies widely across values and models, while SS is strongly modulated by network structure like centrality and reach.

## Method Summary
The framework constructs a multi-agent interaction as a directed acyclic graph (DAG). Each agent node answers value-specific questions, with responses scored 0–10 by a fixed LLM judge. To measure β, the predecessors of a target agent are perturbed via optimized prompts designed to push value scores to extremes (0 or 10). The target agent’s output is regressed against the average input to obtain the slope β. To measure SS, a single node is perturbed and the average normalized deviation is computed across final output nodes. The 56-value dataset was generated using DSPy’s MIPROv2, with polarity validated via an LLM discriminator and a human subset (86.73% agreement).

## Key Results
- Agent-level β-susceptibility varies substantially across values (0.28 to 0.98) and model backbones (e.g., Gemma3-27B mean β=0.605 vs. GPT-4o mean β=0.408).
- β is higher for context-dependent values and increases with openness personas and input variance.
- System susceptibility (SS) is amplified by node centrality and reach in the DAG, but attenuated when the perturbed node has high in-degree.
- System-level propagation arises from the interaction between the distribution of agent β values and the network topology.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Agent-level β-susceptibility quantifies an individual agent's intrinsic sensitivity to peer value signals under controlled interaction conditions.
- **Mechanism:** For a target agent, preceding agents' responses are systematically perturbed along a value dimension. The agent's output score is regressed against the average input score. The fitted slope (β) measures how much the agent's expressed value shifts per unit change in aggregated peer input.
- **Core assumption:** The relationship between aggregated peer input value (¯x) and agent output value (y) is approximately linear within the perturbation range used.
- **Evidence anchors:**
  - Defines β via linear regression `yi = β¯xi + c + ϵi` and states it captures "a single agent’s responsiveness to input value signals."
  - Describes the controlled experimental setup with fixed preceding agents and shows example response curves supporting linearity.
  - Neighboring papers study group conformity and bias propagation, providing contextual plausibility for agent-level influence but not the linearity assumption.
- **Break condition:** If the true functional relationship between input and output value expression is fundamentally nonlinear or discontinuous within any perturbation range, β fails as a single scalar sensitivity measure. Low R² values indicating high output variance would challenge reliability but not necessarily break the mechanism if the linear trend holds.

### Mechanism 2
- **Claim:** System-level susceptibility (SS) measures how a localized value perturbation at a node propagates to final system outputs, with magnitude shaped by network topology.
- **Mechanism:** A perturbation is injected at a single node. SS is the average normalized absolute change in the value scores of designated output nodes. Comparing SS across different topologies and perturbation locations isolates structural effects.
- **Core assumption:** Perturbation effects cascade through the DAG via agents' responsive behavior (characterized by β), and the final aggregated deviation at output nodes scales predictably with network properties like reachability and centrality.
- **Evidence anchors:**
  - States SS "captures how node-level perturbations affect final system outputs" under different topologies.
  - Defines SS formally and presents experimental results showing SS increases with "reachability and structural centrality" and decreases with "high in-degree at the perturbed node."
  - Papers on bias propagation in MAS support the premise that topology influences system-level information spread.
- **Break condition:** If agent behavior is entirely memoryless or independent of specific peer context (β ≈ 0 universally), network topology would have no effect on SS, making SS a measure of perturbation magnitude alone rather than propagation dynamics.

### Mechanism 3
- **Claim:** System-level value propagation results from the *interaction* between agent-level susceptibility (β) and network topology; neither alone determines SS.
- **Mechanism:** High-β agents transmit perturbations more strongly to their successors. Topology then determines how many paths carry that amplified signal and whether signals are diluted via aggregation at high-in-degree nodes. SS = f(β_distribution, topology, perturbation_location).
- **Core assumption:** The effect of topology on SS is mediated by, and contingent on, the β values of the agents along the propagation paths.
- **Evidence anchors:**
  - Shows that under a fixed fully-connected topology, high-β values exhibit "persistent deviations" and slow decay in SS, while low-β values attenuate rapidly.
  - Summarizes: "system-level outcomes arise from the interaction between intrinsic value susceptibility, agent behavior, and network topology."
  - Demonstrates topology effects within a fixed agent configuration, implying topology's role is separable from agent identity but interacts with agent β.
  - Studies how value diversity affects collective behavior, aligning with the interaction premise.
- **Break condition:** If SS varied *only* with topology regardless of β (e.g., all values showed identical propagation profiles across topologies) or *only* with β regardless of topology (e.g., SS identical across all topologies for a given β), the claimed interaction would be invalidated.

## Foundational Learning
- **Concept: Perturbation-Based Evaluation**
  - **Why needed here:** ValueFlow's core innovation is using controlled, adversarial prompt perturbations to stress-test value expression dynamics, moving beyond static alignment scores.
  - **Quick check question:** Why is injecting a perturbation that pushes a value score toward 0 or 10 more informative for measuring *propagation* than measuring a single agent's baseline value score?
- **Concept: LLM-as-a-Judge for Value Scoring**
  - **Why needed here:** The framework requires quantifying continuous value orientation (0-10) from open-ended agent responses at every interaction step, operationalized via a fixed LLM evaluator with few-shot anchors.
  - **Quick check question:** How does inverting scores for negatively framed questions ensure higher scores always indicate stronger value endorsement?
- **Concept: Directed Acyclic Graph (DAG) for Multi-Agent Interaction**
  - **Why needed here:** The DAG formalism time-unrolls multi-round interactions into a static structure where edges represent information flow, enabling analysis of propagation as a function of network structure.
  - **Quick check question:** Why is the assumption of a DAG (no cycles) a limitation for modeling systems with persistent memory or feedback loops?

## Architecture Onboarding
- **Component map:**
  Value Dataset -> Perturbation Optimizer -> Interaction Engine (DAG) -> Value Scorer -> Metrics (β-susceptibility / SS)
- **Critical path:** Value question -> Agent interaction (with possible perturbation) -> Value scorer outputs -> β/SS calculation.
- **Design tradeoffs:**
  - **Linear β model vs. nonlinear:** Linear regression is simple and interpretable but may miss complex response patterns. Low R² values suggest variance.
  - **DAG vs. cyclic graphs:** DAG simplifies propagation analysis but excludes feedback loops common in real MAS.
  - **Single LLM judge vs. ensemble:** Using one judge ensures consistency but introduces evaluator-specific bias.
- **Failure signatures:**
  - **β estimation failure:** Consistently low R² (<0.3) across perturbation ranges for a value, suggesting non-linear or erratic agent response.
  - **SS anomaly:** For a given β distribution, SS does not vary with predicted topological changes (e.g., central vs. peripheral perturbation), indicating possible bug in perturbation injection or output node selection.
  - **Dataset issue:** Low human polarity agreement (<80%) on question subset would invalidate value measurement downstream.
- **First 3 experiments:**
  1. **Baseline β profiling:** For a fixed model/persona, compute β for all 56 values. Verify pattern: normative values have low β, context-dependent have high β.
  2. **Topology isolation:** Use fully-connected layered system (e.g., 3-3-3) with fixed agents. Inject perturbation at first layer only. Track internal scores across layers. Verify high-β values show slow decay, low-β show rapid attenuation.
  3. **Topology & location test:** For a fixed model/persona/value, compare SS across standard topologies (chain, star, mesh) and different perturbation node positions. Verify SS increases with node centrality/reach and decreases with perturbed node in-degree.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** To what extent do measured value drift and β-susceptibility in ValueFlow reflect changes in a model's latent objectives versus mere shifts in surface-level expression?
- **Basis in paper:** From the Limitations: "ValueFlow measures expressed value orientations based on agents’ responses... rather than latent objectives or internal alignment mechanisms... the observed value drift reflects changes in surface-level value expression... and should not be interpreted as direct modification of a model’s internal value representations."
- **Why unresolved:** The framework cannot distinguish between superficial phrasing changes and fundamental goal shifts, which is critical for assessing true alignment risk.
- **What evidence would resolve it:** Comparative analyses using probing techniques (e.g., activation steering, representational similarity analysis) on the same multi-agent interactions to see if internal representations co-vary with the expressed value scores.

### Open Question 2
- **Question:** How robust are the findings on β-susceptibility and System Susceptibility (SS) to variations in the LLM-as-a-judge evaluator, including model choice, prompt design, and demonstration set?
- **Basis in paper:** From the Limitations: "value orientations are quantified using a single LLM-based evaluator... evaluator-specific biases may still affect absolute scores. We do not study robustness across different evaluators or inter-judge variability."
- **Why unresolved:** The entire measurement pipeline depends on one fixed judge; biases or scaling inconsistencies in that judge could systematically distort susceptibility scores across values and models.
- **What evidence would resolve it:** Re-running key experiments with multiple, diverse evaluators (different model families, human annotations) and quantifying variance in relative β and SS rankings.

### Open Question 3
- **Question:** How do value propagation dynamics change in multi-agent systems with cyclic graphs, persistent memory, or adaptive agent learning, which are not covered by the current DAG formulation?
- **Basis in paper:** From the Limitations: "our system-level analysis is restricted to directed acyclic or time-unrolled interaction graphs. Multi-agent systems with feedback loops, persistent memory, or adaptive agent behavior are not covered, and may exhibit qualitatively different value propagation dynamics."
- **Why unresolved:** Real-world multi-agent deployments often involve conversation, role-playing, or iterative planning with feedback, which could cause amplification, oscillation, or stabilization effects not captured in a feedforward DAG.
- **What evidence would resolve it:** Extending the ValueFlow protocol to simulate recurrent topologies (e.g., ring networks, graphs with cycles) and measuring SS and β over multiple interaction rounds to observe convergence, divergence, or limit cycles.

### Open Question 4
- **Question:** Are the optimized perturbation prompts generalizable across different model backbones, or are they overfitted to the specific model (likely GPT-4) used during DSPy optimization?
- **Basis in paper:** The perturbation prompts are optimized using COPRO (likely with a strong model like GPT-4) and then reused unchanged across all experimental backbones. The paper does not report any validation of prompt efficacy or equivalence across different model families.
- **Why unresolved:** If a perturbation prompt's effectiveness (achieving target score ~0 or 10) varies by backbone, then the injected "unit perturbation" is not standardized, making comparisons of β and SS across models potentially invalid.
- **What evidence would resolve it:** Measuring the achieved perturbation strength (|y_pert - y_base|) for each value's two prompts across all backbone models, and either re-optimizing per backbone or demonstrating that strength is invariant.

### Open Question 5
- **Question:** Do the 56 Schwartz value dimensions interact in multi-agent settings, and does co-perturbation of multiple values lead to non-additive, synergistic, or antagonistic effects on propagation?
- **Basis in paper:** The experimental design isolates and evaluates one value dimension at a time. The Schwartz theory itself posits trade-offs and compatibilities between value groups, but the framework treats values independently.
- **Why unresolved:** In realistic discourse, agents may discuss topics tied to multiple values. Propagation dynamics for a cluster of values could differ fundamentally from the sum of single-value effects.
- **What evidence would resolve it:** Designing experiments where perturbations target two or more related value dimensions simultaneously and measuring whether system-level SS is super-additive, sub-additive, or unchanged compared to the sum of single-value perturbations.

## Limitations
- Undisclosed DSPy hyperparameters for question generation and perturbation prompt optimization impede exact replication.
- The complete 560-question dataset is not provided; reconstruction may yield divergent items.
- The DAG assumption excludes feedback loops, limiting realism for cyclic multi-agent systems.

## Confidence
- **β varies across values and is higher for context-dependent values** – High
- **β increases with openness personas and input variance** – Medium
- **β differs systematically across model backbones** – High
- **System susceptibility (SS) is shaped by topology (centrality, reach, in-degree)** – High
- **SS arises from the interaction between agent β and network topology** – Medium
