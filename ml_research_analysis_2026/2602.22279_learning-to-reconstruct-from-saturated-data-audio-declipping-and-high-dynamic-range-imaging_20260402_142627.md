# Learning to reconstruct from saturated data: audio declipping and high-dynamic range imaging

## Quick Facts
- arXiv ID: 2602.22279
- Source URL: https://arxiv.org/abs/2602.22279
- Reference count: 40
- Primary result: Self-supervised framework matches fully supervised performance on audio declipping and HDR imaging using only clipped data for training.

## Executive Summary
This paper tackles nonlinear inverse problems: reconstructing signals (audio, images) from saturated (clipped) measurements without access to ground-truth clean data. The core contribution is a self-supervised learning framework based on an amplitude invariance (scale invariance) assumption of the signal distribution. It combines a measurement consistency loss that preserves unsaturated entries with an equivariance loss that enforces scaling invariance, using a bias-free U-Net architecture to maintain homogeneity. Theoretical analysis provides conditions under which the signal set can be identified from saturated measurements alone. Experiments on audio (GTZAN, MAESTRO) and high-dynamic range imaging show performance close to fully supervised methods, and improved generalization to mismatched distributions.

## Method Summary
The method trains a reconstruction network f_θ from only clipped measurements y = η(x), where η is the clipping operator. The loss has two components: Measurement Consistency (LMC) ensures that the network output matches the input on unsaturated entries (those not clipped), preventing trivial solutions. Equivariance to Scaling (LEI) enforces f_θ(η(g·f_θ(y))) ≈ g·f_θ(η(y)) for random positive scalings g, reflecting the prior that the signal distribution is invariant to amplitude changes. A bias-free U-Net is used because its homogeneity property (f_θ(g y) = g f_θ(y)) guarantees the equivariance condition for small amplitudes. At inference, the final estimate x̂ is obtained by blending: unsaturated pixels retain y, saturated ones are replaced by f_θ(y). The framework is supported by theory showing that a scale-invariant signal set can be uniquely identified from its saturated measurements under mild conditions.

## Key Results
- On GTZAN audio: self-supervised SDR 10.48 dB vs. supervised 11.69 dB; PESQ 2.20 vs. 1.94 supervised.
- On HDR images: self-supervised PSNR 35.04 dB vs. supervised 36.67 dB; NIQE 4.10 vs. 4.04 supervised.
- Self-supervised model shows better generalization to mismatched training-test distributions (e.g., music vs. voice) than supervised approaches.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** A scale-invariant signal set (a cone) can be uniquely identified from its saturated measurements η(X) alone, given enough observations and mild priors.
- **Mechanism:** The clipping operator η preserves all unsaturated signals (those with ∥x∥_∞ < µ). The conic extension of these preserved signals via positive scaling recovers the entire set X if X is a cone.
- **Core assumption:** The true signal distribution support X is invariant to positive scaling (i.e., a cone).
- **Evidence anchors:** [abstract] "assuming that the signal distribution is approximately invariant to changes in amplitude"; [section 3.2] Definition 1 and Proposition 2.
- **Break condition:** Identification fails if X is not scale-invariant or if transformations that commute with η (e.g., rotations/translations) are used instead.

### Mechanism 2
- **Claim:** The self-supervised loss combining Measurement Consistency (MC) and Equivariance to Scaling (EI) enables learning a reconstruction function f_θ from only clipped measurements.
- **Mechanism:** LMC enforces correctness on unsaturated entries; EI enforces f_θ(η(gx)) ≈ g f_θ(η(x)) for random scalings g, leveraging amplitude invariance to learn reconstruction in saturated regions.
- **Core assumption:** The signal set is approximately scale-invariant, so f_θ should be equivariant to scaling.
- **Evidence anchors:** [abstract] "We provide sufficient conditions... and a self-supervised loss... combines a measurement consistency loss with an equivariance loss"; [section 4.1] Equations 7 and 11.
- **Break condition:** If amplitude invariance is severely violated, EI misguides learning; if network architecture breaks homogeneity (e.g., includes biases), EI cannot be properly enforced.

### Mechanism 3
- **Claim:** Using a bias-free neural network (e.g., ReLU without bias layers) is critical to preserve the scale-equivariance property required by EI, especially for low-amplitude signals.
- **Mechanism:** A bias-free network with piecewise‑linear activations is homogeneous: f_θ(g y) = g f_θ(y) for all g > 0. This ensures that as g → 0, f_θ(g y) → 0, matching unsaturated behavior. Biases break homogeneity, causing systematic underestimation of low‑amplitude inputs.
- **Core assumption:** The reconstruction function must be homogeneous to respect the scale‑equivariance constraint.
- **Evidence anchors:** [abstract] "using a bias‑free U‑Net"; [section 4.2.2] Explanation and Figure 3.
- **Break condition:** Introducing biases breaks homogeneity, leading to failure on small‑amplitude signals.

- **Why needed here:** Unlike rotations/translations, scaling invariance is shown necessary and sufficient for identifying the signal set from saturated measurements (Proposition 1 shows other transformations fail).
- **Quick check question:** Why do rotations/translations not help with clipped data? *(Answer: They commute with element‑wise clipping, providing no new information.)*

## Architecture Onboarding
### Component map
y (clipped measurement) -> compute binary saturation mask b (b_j=1 iff |y_j|=µ) -> bias-free U-Net f_θ(y) -> blend output: x̂ = (1-b)⊙y + b⊙f_θ(y)

### Critical path
1. Forward pass: compute f_θ(y) for a batch.
2. MC gradient: loss LMC computes MSE only on unsaturated entries (where b_j=0); gradients flow through those entries.
3. EI gradient: for each sample, draw scalings g ~ p_g, compute g·f_θ(y) and f_θ(η(g·f_θ(y))), minimize squared difference to enforce equivariance; gradients affect saturated regions indirectly.
4. Blending: at inference, x̂ uses y for unsaturated and f_θ(y) for saturated, guaranteeing measurement consistency.

### Design tradeoffs
- λ (EI weight): too low gives weak constraint on saturated regions; too high may override MC.
- p_g support [g_min, g_max]: too narrow limits training range; too wide may cause gradient explosion.
- Masking: hard blending ensures MC but may reduce gradient signal near mask boundaries; softer blending could help at risk of inconsistency.
- Network capacity vs data size: U-Net captures local correlations; for high saturation, larger capacity or iterative schemes may be needed.

### Failure signatures
- Biased network: underestimates low‑amplitude signals.
- Mis‑scaled g range or λ: training instability (NaNs).
- Non‑conic true data: performance degrades but may not reach supervised levels.
- MC loss alone: trivial solution f_θ(y)=y, no learning in saturated zones.

### First 3 experiments
1. **MNIST toy:** Train on scaled versions of one digit with random matrix A; verify that without A recovery is impossible, with A the network learns to invert clipping, and that a biased network fails on low dynamic range inputs.
2. **Synthetic subspaces:** Generate vectors from random k‑dimensional subspaces; sweep k (dimension) and v (saturation proportion). Expect SDR to decrease as k or v increases, matching theoretical prediction.
3. **GTZAN audio:** Compare self-supervised vs. supervised (5% data) vs. social sparsity. Validate self‑supervised approaches supervised performance, generalizes better to mismatched test, and that ablations (LMC alone, bias) hurt performance.

## Open Questions the Paper Calls Out
1. **Extending to affine transformations:** Can the self‑supervised loss be extended to include transformations like x → a x + b1? The paper suggests this but does not implement or evaluate it.
2. **Sensitivity to scale invariance violations:** How does performance degrade when the true signal distribution deviates from the scale‑invariance assumption? No controlled ablation experiments were conducted.
3. **Choice of scaling distribution p_g:** The distribution used in the equivariance loss is set empirically; its impact on learning and potential for automatic determination is unknown.
4. **Generalization to other nonlinearities:** Can the amplitude‑equivariance approach handle other nonlinear forward models (e.g., quantization, asymmetric clipping, phase retrieval)? Only clipping was tested.

## Limitations
- The exact U‑Net architecture (channel counts, normalization, skip connections) and HDR simulation pipeline details (camera response function, quantization) are not fully specified.
- Audio data preprocessing (normalization, segmentation into 1‑second chunks) and compatibility with the U‑Net downsampling depth (needs power‑of‑2 lengths) are ambiguous.
- The interaction between the loss components and the output blending (whether blended output is used in EI) and the number of scaling samples per batch are not described, as are full training details (validation split, early stopping).

## Confidence
- Scale-invariant identification: **High** (theoretical analysis solid under cone assumption, though real‑world adherence uncertain)
- Self‑supervised loss: **Medium** (experiments show competitive results, but hyperparameter sensitivity and missing details reduce certainty)
- Bias‑free network: **High** (ablation clearly shows failure with bias; homogeneity is essential)

## Next Checks
1. **Synthetic subspace experiment:** Generate signals from random subspaces of varying dimension and saturation levels; verify that SDR decreases with increasing dimension or saturation as predicted by Theorem 1.
2. **Bias ablation:** Train a bias‑free model and a biased model on the same data; compare low‑amplitude reconstruction error and overall metrics; expect significant degradation with bias.
3. **Non‑conic data test:** Train on scale‑invariant GTZAN but evaluate on a fixed‑dynamics dataset (e.g., TIMIT speech). A sharp drop in performance would confirm reliance on scale invariance; minimal drop would challenge the assumption.
