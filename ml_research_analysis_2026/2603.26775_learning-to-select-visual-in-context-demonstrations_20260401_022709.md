# Learning to Select Visual In-Context Demonstrations

## Quick Facts
- **arXiv ID**: 2603.26775
- **Source URL**: https://arxiv.org/abs/2603.26775
- **Reference count**: 40
- **Primary result**: LSD significantly reduces MAE on objective visual regression tasks by learning diverse, boundary-defining demonstrations but fails to improve over kNN on subjective preference tasks.

## Executive Summary
The paper addresses the suboptimality of unsupervised kNN retrieval for visual in-context learning in multimodal LLMs, particularly for complex factual regression where kNN selects redundant examples. It introduces LSD (Learning to Select Demonstrations), which uses reinforcement learning with a Dueling DQN agent to actively select demonstrations that balance visual relevance with output diversity. A key empirical finding reveals a task-dependent dichotomy: LSD substantially outperforms kNN on objective, factual regression benchmarks (e.g., age, image quality prediction) by implicitly covering the full label range, but offers no gain—and sometimes harm—on subjective preference tasks. This illuminates when learned selection is strictly necessary.

## Method Summary
LSD reframes demonstration selection as a sequential decision-making problem. A query-centric Transformer decoder encodes the query image and candidate demonstration embeddings into a state vector. A Dueling DQN agent then selects actions (indices of demonstrations) to maximize a reward based on negative mean absolute error (MAE) from the MLLM’s prediction. Efficient FAISS-based approximate nearest-neighbor search handles large candidate pools during both training and inference. The policy is trained via RL, enabling it to learn heuristics—such as selecting boundary examples that span the output distribution—that unsupervised kNN, which relies solely on embedding similarity, cannot discover.

## Key Results
- On objective factual regression datasets (UTKFace, KonIQ-10k, KADID-10k), LSD reduces MAE compared to kNN baselines by selecting a diverse set of relevant examples that better define the regression space.
- Analysis confirms LSD’s policy emerges as label-aware and diversity-seeking, generalizing robustly to unseen MLLMs and similar objective tasks.
- For subjective preference tasks (AVA, SCUT-FBP5500), unsupervised kNN retrieval remains superior; LSD shows neutral or negative performance, including worse-than-random results in cross-dataset transfer.

## Why This Works (Mechanism)
LSD succeeds on objective tasks because RL optimization for downstream performance (negative MAE) incentivizes the agent to explore beyond visual similarity. It learns to pick demonstrations that actively cover the label distribution—e.g., selecting extreme or boundary cases—which ensures the MLLM receives a representative sample of the output range. This addresses kNN’s tendency to retrieve visually near-duplicates with similar labels. The failure on subjective tasks suggests that human preference landscapes may not benefit from such enforced diversity; instead, examples similar to the query in subjective feature space (captured by kNN) are more predictive of MLLM performance, possibly because subjective judgments are noisier or more context-sensitive.

## Foundational Learning
- **In-Context Learning (ICL)**: ICL enables MLLMs to adapt from few demonstrations without weight updates. *Why needed*: LSD optimizes demonstration selection for ICL performance. *Quick check*: Confirm that changing demonstration content alters MLLM outputs on a fixed query.
- **k-Nearest Neighbors (kNN) Retrieval**: Unsupervised method selecting demos by embedding similarity. *Why needed*: Primary baseline; its limitations motivate learned selection. *Quick check*: Implement kNN with image embeddings and verify it picks visually similar but label-redundant examples.
- **Dueling DQN**: Deep RL architecture separating value and advantage streams for stable action evaluation. *Why needed*: LSD’s core RL algorithm for sequential selection. *Quick check*: Compare convergence of Dueling DQN vs. vanilla DQN on a simple multi-step selection task.
- **Query-Centric Transformer Decoder**: Encodes query and candidate pool into a state representation. *Why needed*: Captures relationships between query and candidates for informed decisions. *Quick check*: Ablate the decoder and measure performance drop in LSD.
- **FAISS Indexing**: Library for efficient similarity search in high-dimensional spaces. *Why needed*: Scales retrieval to large candidate pools during RL training and inference. *Quick check*: Benchmark FAISS vs. brute-force search time as pool size increases.
- **Reward Shaping (Negative MAE)**: Directly ties selection policy to downstream task error. *Why needed*: Avoids reliance on proxy losses that may not correlate with MLLM performance. *Quick check*: Replace MAE with L2 norm reward and observe changes in selected demonstration diversity.

## Architecture Onboarding
Component map: Query Image -> Query-Centric Transformer Encoder -> State Vector -> Dueling DQN Agent -> Action (Demo Index) -> FAISS Retrieval -> Selected Demonstrations (set of K) -> MLLM (with Query + Demos) -> Prediction -> MAE (vs. Ground Truth) -> Reward (Negative MAE)

Critical path: The Transformer encoder processes the query image and all candidate demo embeddings to produce a state. The Dueling DQN agent then selects one demo index as an action; this repeats sequentially until K demos are chosen. The selected set is fed to the MLLM, whose prediction error computes the reward for RL training.

Design tradeoffs: RL training enables adaptive, performance-driven policies but incurs high computational cost; kNN is cheap but static. The diversity reward improves coverage for objective tasks but may be detrimental for subjective tasks where similarity is more important. FAISS enables scaling but requires indexing overhead.

Failure signatures: Performance collapse on subjective tasks (AVA, SCUT-FBP5500); negative cross-dataset transfer (e.g., age-trained policy harms beauty prediction); poor generalization when candidate pool distribution shifts significantly; high variance if reward signal is noisy.

First three experiments:
1. Replicate core UTKFace experiment (K=8): verify LSD reduces MAE vs. kNN and random selection.
2. Test order invariance: randomly shuffle LSD-selected demonstrations for UTKFace and a subjective task (e.g., SCUT-FBP5500); measure MAE change.
3. Cross-dataset transfer: train LSD on UTKFace, evaluate on KonIQ-10k (objective) and AVA (subjective); expect transfer gain only on the objective task.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: What specific characteristics of a visual regression task determine whether a learned selection policy (like LSD) will outperform unsupervised kNN retrieval?
- Basis in paper: [explicit] The paper uncovers a "crucial, task-dependent dichotomy" where LSD significantly beats kNN on objective, factual regression tasks (UTKFace, KonIQ-10k, KADID-10k) but not on subjective preference tasks (AVA, SCUT-FBP5500). The authors state this "illuminates when learned selection is strictly necessary."
- Why unresolved: The paper identifies the dichotomy but does not define the precise boundary or underlying features (e.g., label distribution, perceptual ambiguity, dataset structure) that causally determine which strategy is optimal. The assumption is that "objective" vs. "subjective" is the key, but this is not formally quantified or tested across a broader spectrum.
- What evidence would resolve it: A systematic ablation study or meta-analysis across a wider, more diverse set of regression tasks, where tasks are characterized by metrics like label entropy, inter-annotator agreement, or semantic diversity. This would allow for a predictive model of when learned selection is beneficial.

### Open Question 2
- Question: Why does the LSD agent's learned diversity heuristic, which is beneficial on objective tasks, lead to neutral or negative performance on subjective tasks like SCUT-FBP5500, even causing worse-than-random results in cross-dataset transfer?
- Basis in paper: [inferred] The cross-dataset generalization experiment shows that an LSD agent trained on UTKFace (age prediction) performs significantly worse than random on SCUT-FBP5500 (facial beauty). The paper hypothesizes "conflicting objectives" (e.g., age diversity might introduce noise for beauty scoring) but does not validate this.
- Why unresolved: The exact mechanism of this "negative transfer" is speculative. It is unclear if the diversity is actively harmful or simply unhelpful, and whether the failure is due to mismatched label semantics (age vs. beauty) or a deeper incompatibility between the diversity-seeking policy and the true, unknown factors driving subjective human judgment.
- What evidence would resolve it: Controlled experiments on datasets with known, manipulable label distributions (e.g., synthetic or semi-synthetic datasets where "ground truth" beauty is defined by a combination of objective features and random noise). Analyzing the MLLM's internal outputs (e.g., confidence, token distributions) when fed with diverse vs. redundant demonstrations on subjective tasks could reveal if diversity introduces harmful variance.

### Open Question 3
- Question: Is the ordering of selected demonstrations truly irrelevant for MLLM in-context learning, or does the finding that shuffling does not hurt performance on UTKFace fail to generalize to other datasets or MLLMs?
- Basis in paper: [inferred] The paper conducts an analysis on UTKFace (K=8) and finds that randomly shuffling the LSD agent's selected set yields nearly identical MAE, concluding the agent primarily learns to select an optimal *set*. However, this is tested on only one dataset and one model (Gemma).
- Why unresolved: The sensitivity to demonstration order is a well-known phenomenon in LLMs. The result may be specific to the UTKFace task (a relatively simple, objective regression), the MLLM used, or the K=8 shot count. It is not tested on the subjective tasks where kNN performs best, leaving open the possibility that order matters critically in other regimes.
- What evidence would resolve it: Repeating the permutation experiment across all five benchmark datasets and across multiple MLLMs. If order consistently matters for subjective tasks or certain model architectures, it would indicate that LSD's policy is incomplete and that a separate ordering strategy is needed.

### Open Question 4
- Question: What architectural or training differences between MLLMs cause some (e.g., Phi-3.5-vision) to be largely resistant to performance gains from a transferred LSD policy, while others (e.g., Qwen 2.5 7B) show clear benefits?
- Basis in paper: [inferred] The cross-model transfer matrix (Tab. 6, Fig. 10) shows that a policy trained on InternVL2-8B transfers well to Gemma and Qwen but not to Phi-3.5-vision, where cross-policies only match kNN. The paper suggests "different MLLM architectures may rely on fundamentally different internal mechanisms for in-context learning" but provides no analysis.
- Why unresolved: The paper does not investigate correlations between MLLM architecture (e.g., vision encoder type, LLM backbone, tokenization) and sensitivity to demonstration diversity. This limits the theoretical understanding of *why* learned selection works and prevents designing universally effective selectors.
- What evidence would resolve it: An analysis correlating transfer performance gains with model characteristics (e.g., parameter count, pretraining data, vision-language alignment objective). Probing the models' attention patterns or hidden states when processing diverse vs. similar demonstrations could reveal if some models fail to integrate heterogeneous contextual information.

## Limitations
- The precise cause of the objective/subjective task dichotomy is unknown; it is unclear whether label noise, human preference heterogeneity, or other factors drive LSD’s failure on subjective tasks.
- LSD’s policy is not fully interpretable; while it exhibits emergent label-awareness and diversity, the exact decision logic (e.g., how it trades off relevance vs. diversity) remains a black box with limited ablations.
- The computational overhead of RL training and FAISS indexing is not quantified against kNN’s simplicity, leaving deployment cost-benefit unclear for new tasks.

## Confidence
- **Performance dichotomy (factual vs. subjective regression)**: High (consistent across 5 datasets and multiple MLLMs).
- **LSD learns label-aware, diverse selection**: Medium (analysis shows emergent behavior, but causality inferred not proven via controlled interventions).
- **Transfer robustness to unseen MLLMs/objective tasks**: High for within-domain transfer; Low for cross-domain subjective generalization.
- **Order irrelevance for selected demonstrations**: Medium (tested only on UTKFace with Gemma; generalizability to other settings uncertain).

## Next Checks
1. Test LSD on a wider range of regression tasks with quantifiable characteristics (label entropy, annotator agreement) to identify precise predictors of when learned selection outperforms kNN.
2. Conduct policy introspection via controlled ablations: systematically mask or noise components of the query-centric state (image embeddings, label histograms) to measure their impact on diversity and relevance in selected demonstrations.
3. Perform a compute-accuracy trade-off analysis: measure RL training time, inference latency, and memory overhead of LSD versus kNN across varying candidate pool sizes (1k, 10k, 100k) to establish practical scalability thresholds.
