# A Fusion of context-aware based BanglaBERT and Two-Layer Stacked LSTM Framework for Multi-Label Cyberbullying Detection

## Quick Facts
- **arXiv ID:** 2602.22449
- **Source URL:** https://arxiv.org/abs/2602.22449
- **Reference count:** 40
- **Primary result:** A hybrid BanglaBERT-Large and two-layer stacked LSTM model achieves 94.31% accuracy on multi-label Bangla cyberbullying detection, exceeding prior SOTA by 0.67%.

## Executive Summary
This research addresses the challenge of multi-label cyberbullying detection in Bangla social media text, where a single comment can exhibit multiple overlapping abuse types (e.g., bully, threat, religious). The proposed solution is a hybrid neural architecture that fuses the deep contextual understanding of BanglaBERT-Large with the sequential dependency modeling of a two-layer stacked Long Short-Term Memory (LSTM) network. Evaluated on a public Bangla dataset using 5-fold cross-validation and oversampling to handle class imbalance, the model achieves state-of-the-art performance with 94.31% accuracy, an F1-score of 88.37%, and a Hamming loss of 0.0569. The work highlights the importance of tailoring NLP models to language-specific features like Bangla's complex morphology and code-mixing.

## Method Summary
The method involves a hybrid deep learning pipeline. Input Bangla text undergoes language-specific preprocessing (removal of non-Bangla characters, stopwords, normalization). The cleaned text is tokenized using BanglaBERT's WordPiece tokenizer and padded to a fixed length. The core architecture passes token embeddings from a fine-tuned BanglaBERT-Large model (24-layer Transformer, 1024-dimensional hidden state) into a two-layer unidirectional LSTM stack (256 hidden units per layer, dropout 0.3). The final hidden state of the LSTM is used by a classifier head with dropout and a dense layer with sigmoid activation to produce independent probability scores for five binary abuse labels. To address severe multi-label class imbalance, the training data is oversampled by duplicating minority-class samples. The model is trained with binary cross-entropy loss, the AdamW optimizer (learning rate 1e-5, weight decay 0.01), gradient clipping, and warmup. Performance is evaluated via standard multi-label metrics (accuracy, F1, Hamming loss, MCC) on a held-out test set and through 5-fold cross-validation.

## Key Results
- Achieves 94.31% accuracy on the test set, a 0.67% absolute improvement over the previous state-of-the-art.
- Reports a macro-averaged F1-score of 88.37% and a Matthews Correlation Coefficient (MCC) of 80.31%.
- Attains a low Hamming loss of 0.0569, indicating strong multi-label classification performance.

## Why This Works (Mechanism)
### Mechanism 1: Contextual Embedding via BanglaBERT-Large
BanglaBERT-Large generates context-aware token representations that capture nuanced semantic and abusive intent in Bangla text. Its 24-layer Transformer encoder with multi-head self-attention computes weighted interactions across all tokens, disambiguating meaning based on surrounding context—crucial for Bangla's rich inflectional morphology and informal social media dialects. This provides a deep semantic foundation that static embeddings cannot.

### Mechanism 2: Sequential Dependency Modeling via Stacked LSTM
The two-layer stacked LSTM captures long-range temporal and syntactic dependencies in the comment sequence. The first layer learns local patterns between adjacent tokens; the second integrates these to model longer-range dependencies (e.g., sarcasm, escalating threats). This explicit modeling of sequential progression complements BERT's bidirectional context.

### Mechanism 3: Fusion Architecture for Complementary Strengths
By feeding BanglaBERT's final-layer contextual embeddings as input to the LSTM stack, the model creates a feature space where deep semantic understanding and sequential dynamics are jointly optimized. This serial fusion bridges BERT's lack of explicit sequence modeling and LSTM's lack of deep semantic context, which are non-overlapping weaknesses.

## Foundational Learning
- **Concept: Multi-Label Classification**
  - **Why needed here:** A single Bangla comment can express multiple simultaneous abuse types (e.g., "bully" + "threat"). Single-label models force artificial exclusivity, missing overlapping harm.
  - **Quick check:** Given a comment with a religious slur and a threat, why would a model that only predicts one label fail in a real moderation system?

- **Concept: Class Imbalance in Multi-Label Data**
  - **Why needed here:** The dataset is skewed (e.g., "Bully" in 5497 samples vs. "Spam" in 752). Imbalance biasing the model toward majority classes hurts recall on rare but critical types.
  - **Quick check:** If you oversample a minority-class sample in a multi-label dataset, what happens to the label vector of the duplicated sample, and why does this affect majority-class counts too?

- **Concept: Bangla NLP Specificities**
  - **Why needed here:** Bangla has complex morphology, optional schwa deletion, and code-mixing (Banglish). Standard embeddings fail; BanglaBERT is pre-trained on large Bangla corpora to handle these.
  - **Quick check:** Why might a model trained only on English cyberbullying data fail on Bangla text, even if translated word-for-word?

## Architecture Onboarding
Raw Bangla text -> Preprocessing (cleaning, Bangla tokenization) -> BanglaBERT-Large Encoder (contextual embeddings) -> Two-Layer Stacked LSTM (sequential modeling) -> Final Hidden State -> Dropout (0.3) -> Dense Layer (5 units) -> Sigmoid Activation -> Thresholding (0.5) -> Multi-Label Predictions

**Critical path:** Text is converted to token IDs and attention masks, processed by BanglaBERT to extract the final hidden state for each token, this sequence is fed into the two-layer LSTM, the final hidden state of the second LSTM is classified.

**Design tradeoffs:**
- **BERT-Large size:** High context capture (1024-d, 24 layers) but computationally heavy.
- **Unidirectional LSTM:** Chosen to maintain sequential causality (past→future) for modeling abuse progression, unlike bidirectional.
- **Oversampling:** Applied only on training set to balance labels but risks overfitting to duplicated samples, evidenced by high train accuracy (99.53%) vs. validation (93.42%).

**Failure signatures:**
1. Poor minority-class recall (e.g., low F1 for "Sexual" or "Threat").
2. Significant train-validation accuracy gap indicating overfitting.
3. LIME explanations highlighting irrelevant tokens or stopwords, suggesting spurious correlations.

**First 3 experiments:**
1. Train a standalone BanglaBERT (no LSTM) with identical settings to verify it matches the reported ~93.92% baseline.
2. Train the BERT-LSTM on original (imbalanced), undersampled, and oversampled training sets; compare metrics to confirm oversampling's benefit and monitor for overfitting.
3. Perform a learning rate sweep (e.g., 1e-6 vs. 1e-4) to validate the optimized choice (1e-5 in paper) and ensure stable convergence.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can the BanglaBERT-LSTM framework be extended to effectively handle multilingual and code-mixed cyberbullying text for broader real-world deployment?
- **Open Question 2:** Does the current oversampling strategy for multi-label data adequately balance per-label distributions without introducing synthetic noise, and what advanced multi-label sampling techniques could further improve robustness?
- **Open Question 3:** Is the two-layer stacked LSTM configuration optimal for capturing sequential dependencies in Bangla cyberbullying text, or would alternative LSTM architectures (e.g., different depths, bidirectional variants) yield better performance?
- **Open Question 4:** Would optimizing the classification threshold per label (instead of the fixed 0.5) improve multi-label detection accuracy, particularly under the dataset’s class imbalance?

## Limitations
- Exact BanglaBERT-Large checkpoint and oversampling procedure are not specified, blocking full reproducibility.
- Large train-validation gap (99.53% vs. 93.42%) indicates potential overfitting from oversampling.
- Model may underperform on Romanized Bangla (Banglish) or novel slang, as preprocessing removes non-Bangla characters and the pre-training corpus likely lacks such variations.
- Reported improvements over prior SOTA are modest (~0.6–0.7%) with no statistical significance testing.

## Confidence
- **Fusion architecture (BERT + stacked LSTM):** Medium – Ablation shows benefit, but gains are small and dataset-specific.
- **Reported metrics (94.31% accuracy, 88.37% F1):** Low – Reproduction hindered by missing details; train-val discrepancy raises concerns.
- **Capture of Bangla linguistic nuances:** Medium – Plausible given BanglaBERT’s pre-training, but not explicitly probed.
- **Oversampling effectiveness:** Low – Risks overfitting; no evidence of balanced per-label improvement.
- **5-fold cross-validation robustness:** Medium – Standard approach, but fold stratification for multi-label data is unclear.
