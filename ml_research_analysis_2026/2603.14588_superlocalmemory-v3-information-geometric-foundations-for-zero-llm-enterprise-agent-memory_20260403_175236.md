# SuperLocalMemory V3: Information-Geometric Foundations for Zero-LLM Enterprise Agent Memory

## Quick Facts
- **arXiv ID:** 2603.14588  
- **Source URL:** https://arxiv.org/abs/2603.14588  
- **Reference count:** 40  
- **Primary result:** Information‑geometric memory system (Fisher–Rao retrieval, sheaf consistency, Langevin lifecycle) gains +12.7 pp average on LoCoMo vs. engineering baselines, reaching 75 % accuracy in a zero‑LLM configuration.

## Executive Summary
Agent memory systems have lacked rigorous foundations, relying on heuristics like cosine similarity and exponential decay. This paper introduces a mathematically grounded alternative built on three pillars: a retrieval metric derived from the Fisher information of diagonal Gaussians, a memory lifecycle modeled as Riemannian Langevin dynamics with a provable stationary distribution, and a cellular sheaf model that detects irreconcilable contradictions via first cohomology. Evaluated on the LoCoMo benchmark, the full system yields a 12.7‑point gain over baselines (up to 19.9 pp on hard dialogues) and satisfies EU AI Act data‑sovereignty requirements by operating entirely locally.

## Method Summary
SuperLocalMemory V3 uses a four‑channel retrieval pipeline and three mathematical layers. Ingestion extracts embeddings, metadata, entities, and facts, then applies a sheaf consistency check and entropy gate before storing in SQLite. Retrieval classifies the query, looks up the user profile, and scores memories in parallel via Fisher‑Rao (variance‑weighted), BM25, entity‑graph spreading activation, and temporal proximity. Results fuse with Weighted Reciprocal Rank Fusion, expand scenes, optionally discover multi‑hop bridges, and re‑rank with a cross‑encoder. The lifecycle evolves low‑dimensional memory states asynchronously using Riemannian Langevin dynamics on the Poincaré ball, with drift guided by a potential function combining recency, frequency, and relevance. Zero‑LLM mode uses only local embedding and reranking models.

## Key Results
- Average gain of 12.7 percentage points over engineering baselines across six LoCoMo conversations, with up to 19.9 pp on challenging dialogues.
- Zero‑LLM configuration achieves 75 % accuracy without cloud dependency; cloud augmentation reaches 87.7 %.
- System architected to satisfy EU AI Act data‑sovereignty requirements by design.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Variance‑weighted retrieval via the Fisher information metric outperforms cosine similarity by adapting to per‑dimension statistical precision, especially in sparse embedding regions.
- **Mechanism:** Each memory embedding is augmented with a per‑dimension variance vector. Retrieval uses a Mahalanobis‑like score where distances are inversely weighted by variance (Eq. 16). This approximates the Fisher–Rao geodesic on the diagonal Gaussian manifold, contracting neighborhoods around high‑confidence (low‑variance) dimensions and expanding around uncertain ones.
- **Core assumption:** Embedding dimensions are not equally reliable; local neighborhood statistics (variance) reflect semantic distinctiveness.
- **Evidence anchors:** [abstract] “retrieval metric from the Fisher information of diagonal Gaussians, providing a Riemannian metric that weights dimensions by statistical precision”; [section 5.2] formalizes the diagonal Gaussian manifold, derives the O(d) scoring formula, and introduces the graduated ramp for cold‑start.
- **Break condition:** If variance estimation is consistently inaccurate (e.g., all embeddings have near‑constant signal magnitude), the Fisher weighting degenerates to cosine. The diagonal covariance assumption also ignores cross‑dimensional dependencies, which may hurt in correlated embedding spaces.

### Mechanism 2
- **Claim:** Sheaf cohomology detects irreconcilable contradictions across memory contexts by algebraically measuring the failure of local assignments to glue globally.
- **Mechanism:** Memory contexts (vertices) and shared entity edges form a graph. A sheaf assigns embedding spaces to vertices and linear restriction maps to edges. The first cohomology group H¹ measures non‑zero edge discrepancies (δf ≠ 0) that cannot be resolved by any global assignment. A scalar contradiction score κ > τ triggers a supersedes relation.
- **Core assumption:** Genuine contradictions manifest as non‑trivial cohomology classes in the memory sheaf, not as mere similarity mismatches.
- **Evidence anchors:** [abstract] “cellular sheaf model where non‑trivial first cohomology classes precisely correspond to irreconcilable contradictions”; [section 5.4] defines the memory sheaf, coboundary operator, and contradiction score; integrates with ingestion pipeline.
- **Break condition:** If the context graph is dense and fully connected (|E| = Θ(|V|²)), the O(|E|d) cohomology computation becomes quadratic and may not scale. Poorly designed restriction maps could yield false positives/negatives.

### Mechanism 3
- **Claim:** Riemannian Langevin dynamics on the Poincaré ball provides a principled, parameter‑free memory lifecycle with a provable stationary distribution, replacing heuristic decay.
- **Mechanism:** Each memory’s state ξ(t) evolves via an SDE whose drift incorporates the potential U (importance: recency, frequency, relevance) and whose diffusion is scaled by the Poincaré metric’s conformal factor. The Fokker‑Planck equation yields a unique stationary distribution ρ∞ ∝ (1−‖ξ‖²)⁻ᵈ exp(−U/T), concentrating low‑importance memories near the boundary (effective forgetting).
- **Core assumption:** Memory importance can be encoded in a potential function U such that high‑importance memories should be retained (drift toward origin) and low‑importance memories should drift outward and be forgotten.
- **Evidence anchors:** [abstract] “memory lifecycle modeled as Riemannian Langevin dynamics with a provable stationary distribution, eliminating hand‑tuned decay”; [section 5.3] presents the SDE, discretization, and potential function; Theorem 6.3 proves existence and uniqueness of ρ∞.
- **Break condition:** If U is poorly specified (e.g., missing key importance signals), the stationary distribution may not align with human judgment of salience. The hyperbolic “forgetting boundary” requires numerical projection; unstable discretization could cause numerical drift or premature forgetting.

## Foundational Learning
- **Concept: Information Geometry (Fisher Information Metric)**
  - Why needed: Provides the mathematical foundation for uncertainty‑aware retrieval; the Fisher metric is the unique invariant Riemannian metric on statistical manifolds (Čencov’s theorem).
  - Quick check: Why does the Fisher–Rao distance weight dimensions by inverse variance, and how does this differ from Euclidean distance?
- **Concept: Stochastic Differential Equations on Manifolds (Langevin Dynamics)**
  - Why needed: Governs memory lifecycle; the Riemannian Langevin equation incorporates manifold curvature, leading to a Gibbs‑like stationary distribution.
  - Quick check: What is the role of the conformal factor λξ in the Poincaré ball Langevin SDE, and how does it affect the forgetting mechanism?
- **Concept: Sheaf Cohomology (First Cohomology Group)**
  - Why needed: Algebraically detects when local memory assignments (per context) cannot be consistently glued into a global assignment, i.e., contradictions.
  - Quick check: In the memory sheaf construction, what does a non‑trivial element of H¹(G, F) represent about the set of memories?

## Architecture Onboarding

**Component map:**  
Embedding → Metadata/Entity/Fact Extraction → Sheaf Consistency → Entropy Gate → SQLite Persistence (Ingestion)  
Query Classification → Profile Lookup → [Fisher‑Rao | BM25 | Entity Graph | Temporal] → WRRF Fusion → Scene Expansion → Bridge Discovery (if multi‑hop) → Cross‑Encoder Reranking → Top‑k (Retrieval)  
Low‑d State (d=8) ← Access Counts → Langevin Updates (Lifecycle)

**Critical path:** For a query: classification → parallel channels → fusion → bridge (if multi‑hop) → reranking. Cold‑start memories use cosine until 10 accesses; sheaf runs only on ingestion; Langevin runs asynchronously.

**Design tradeoffs:**
- Zero‑LLM Mode A vs. accuracy: Eliminates cloud dependency but loses LLM‑based answer synthesis; retrieval remains strong (74.8 % vs. 60.4 % raw).
- Channel diversity vs. cost: Four channels increase recall but multiply compute; WRRF weights were grid‑searched; entity and temporal channels have modest impact on some queries.
- Mathematical guarantees vs. engineering complexity: Fisher–Rao adds O(d) variance computation; sheaf cohomology adds O(|E|d) store‑time check; Langevin adds a maintenance process.

**Failure signatures:**
- Low recall on sparse/high‑dimensional queries: May indicate insufficient Fisher variance discrimination; check graduated ramp activation (naccess < 10?).
- Contradictions not flagged: Sheaf threshold τ too high or restriction maps too permissive; inspect κ scores and coboundary matrix.
- Memory churn: Langevin potential U mis‑specified; check if radial drift matches desired lifecycle states (active/warm/cold/archived).
- Cross‑encoder dependency: Removing or substituting the reranker drops accuracy ~30 pp; confirm model identity (BGE‑reranker‑v2‑m3 for Mode A).
- Judge inconsistency: Varied LLM‑as‑Judge scores; ensure exact prompt and model (GPT‑4.1‑mini) are used.

**First 3 experiments:**
1. **Ablation study:** Disable one component at a time (Fisher off, sheaf off, all math off, BM25 off, entity off, temporal off, cross‑encoder off) to isolate contributions. Expect cross‑encoder largest, Fisher next; math layers combined +7.6 pp avg.
2. **Fisher vs. Cosine comparison:** Run full system with/without math layers across six LoCoMo conversations. Expect +12.7 pp avg improvement, largest on hardest conversations (conv‑44: +19.9 pp).
3. **Scale analysis (planned):** Vary memory count N from 10³ to 10⁵; measure NDCG@10, contradiction detection rate, lifecycle stability. Predict cosine retrieval degrades while Fisher‑Rao and sheaf maintain advantage.

## Open Questions the Paper Calls Out
- **Q1:** Does the sheaf cohomology consistency layer significantly improve retrieval accuracy and contradiction detection in enterprise deployments with high rates of cross‑context contradictions? *Basis:* LoCoMo contains few genuine contradictions; the layer’s value should emerge in multi‑context scenarios. *Needs:* Deploy in contradiction‑rich environments and measure impact.
- **Q2:** Does the Fisher‑information‑weighted retrieval metric provide a sustained accuracy advantage after memories have enough access history for stable variance estimation? *Basis:* The graduated ramp activates over 10 accesses; on LoCoMo (naccess=0) Fisher reduces to cosine. *Needs:* Longitudinal experiments tracking retrieval quality as a function of memory access count.
- **Q3:** Can the full covariance Fisher information metric be computed efficiently for high‑dimensional embeddings and does it yield significantly better retrieval quality than the diagonal approximation? *Basis:* Diagonal version used due to O(d³) cost of full covariance. *Needs:* Implement and compare both on datasets with cross‑correlations.
- **Q4:** How do the information‑geometric retrieval, sheaf consistency, and Langevin lifecycle layers scale in performance and resource usage as memory count grows from thousands to hundreds of thousands? *Basis:* Theoretical analysis predicts advantages at scale, but empirical validation is pending. *Needs:* Systematic scale experiments measuring latency, memory footprint, and retrieval quality.
- **Q5:** Does the Riemannian Langevin dynamics for memory lifecycle effectively balance retention and forgetting in non‑stationary environments where importance patterns change over time? *Basis:* Evaluation on static LoCoMo may not capture drift. *Needs:* Simulate changing access patterns and compare to heuristic decay.

## Limitations
- Graduated ramp logic may deactivate Fisher weighting on benchmark data, yet results still show improvement, suggesting a mismatch between theory and implementation.
- Sheaf cohomology threshold (τ = 0.45) and heuristic restriction maps lack validation on contradiction‑rich data; contributions on LoCoMo are minimal (‑1.7 pp).
- Langevin dynamics implementation may deviate from the Poincaré ball theory (e.g., missing conformal factor), weakening guarantees about the stationary distribution.
- Incomplete documentation of hyperparameters and ingestion pipeline steps hinders faithful replication.
