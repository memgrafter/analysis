# Precision-Varying Prediction (PVP): Robustifying ASR systems against adversarial attacks

## Quick Facts
- **arXiv ID:** 2603.22590
- **Source URL:** https://arxiv.org/abs/2603.22590
- **Reference count:** 0
- **Primary result:** A training-free, model-agnostic defense that uses numerical precision variation to both significantly degrade adversarial audio attack success (increasing WER/SER) and detect adversarial examples with AUROC >0.90, while minimally impacting benign performance.

## Executive Summary
Automatic Speech Recognition (ASR) systems are vulnerable to adversarial audio attacks—small, imperceptible perturbations that cause transcription errors. This paper introduces Precision-Varying Prediction (PVP), a novel defense that exploits the observation that adversarial examples (AEs) are less stable than benign inputs when the model's numerical precision (FP32, FP16, BF16) is changed during inference. PVP has two complementary components: (1) **Stochastic precision sampling**, which randomly selects a precision for each inference call, probabilistically breaking attacks optimized for a fixed precision; and (2) **Precision-diversity detection**, which compares transcriptions from multiple precisions, computing a stability score that separates AEs from benign inputs via a lightweight Gaussian classifier. Evaluated across multiple ASR architectures and attack types, PVP substantially harms attack success rates (e.g., raising Word Error Rate for AEs from near 0% to over 50%) while preserving benign accuracy (<1% change), and achieves strong detection performance (AUROC >0.90). However, the defense is circumvented by adaptive attacks that explicitly optimize for precision invariance.

## Method Summary
PVP is a post-training, inference-time defense requiring no model modifications or retraining. For robustness, the system randomly samples a compute precision (FP32, FP16, or BF16) for each input during prediction. For detection, the model is queried with all three precisions to generate *K* transcriptions. A precision-diversity score *D(x)* is computed as the average pairwise Word Error Rate (WER) between these transcriptions. A single Gaussian distribution (mean µ, variance σ²) is fitted on *D(x)* scores from a small set of benign reference samples (e.g., 200). At deployment, an input is classified as adversarial if its *D(x)* deviates significantly from the benign mean (e.g., > µ + 3σ). The approach is evaluated using CTC, seq2seq, Transformer, and Whisper ASR models on LibriSpeech, against Carlini & Wagner (C&W) and psychoacoustic attacks, with an adaptive multi-precision attack used to test limits.

## Key Results
- **Robustness:** Stochastic precision sampling increases WER/SER for C&W and psychoacoustic AEs dramatically (often from ~0% to 10-60%) across ASR models, while benign WER/SER changes by less than 1%.
- **Detection:** The precision-diversity detector achieves AUROC values generally above 0.90 for both attack types, matching or outperforming prior detectors like Noise Flooding and Temporal Dependency.
- **Failure case:** An adaptive attack optimized to succeed across all precisions completely bypasses both the stochastic sampling robustness and the diversity-based detection, achieving near 0% SER.

## Why This Works (Mechanism)
### Differential Precision Sensitivity
Adversarial examples (AEs) exhibit greater output instability across numerical precision configurations (FP32, FP16, BF16) than benign inputs. The perturbation is finely tuned to fool the model under a specific precision (e.g., FP32). Changing precision alters floating-point rounding, scaling, and intermediate representations, disrupting the attack's delicate alignment with the model's loss landscape. Benign inputs occupy more robust regions of the input space, producing consistent transcriptions despite numerical variability. This observed sensitivity forms the core assumption enabling both PVP strategies.

### Stochastic Precision Sampling for Robustness
By randomly selecting a precision at each inference, the system introduces a randomized computational barrier. An AE crafted for a fixed "source" precision (e.g., the model's training precision) now has only a 1/*K* probability of encountering that "weak" precision during deployment. Consequently, its expected success rate degrades substantially, while benign inputs remain largely unaffected due to their inherent stability.

### Precision-Diversity for Detection
Querying the model with multiple precisions yields *K* transcriptions. For benign inputs, these transcriptions are similar (low pairwise dissimilarity). For AEs, success varies across precisions, leading to high dissimilarity. The average pairwise WER forms the precision-diversity score *D(x)*. Fitting a Gaussian to *D(x)* scores from benign references allows thresholding: scores far in the right tail indicate an unstable, likely adversarial input.

## Architecture Onboarding
**Component Map:**  
Input Audio -> Multi-Precision Inference Runner (samples/uses K precisions) -> ASR Model Core (frozen, multiple dtype states) -> K Transcriptions -> Transcription Comparator (pairwise WER) -> Precision-Diversity Scorer (average -> D(x)) -> Gaussian Classifier (benign fit -> threshold) -> Detection Decision.

**Critical Path:** The detection path requires running the model *K* times per input (once per precision), which dominates compute cost. The robustness path requires only one precision sample per input but depends on the random sampling policy.

**Design Tradeoffs:**
- **K (number of precisions):** Higher *K* (e.g., 3: FP32, FP16, BF16) improves detection separation and robustness but linearly increases latency. *K=3* is used as a default.
- **Benign calibration set size:** Must be large enough (paper uses 200) to reliably estimate Gaussian (µ, σ²) but not so large as to be impractical for a new deployment.
- **Similarity metric:** WER is used but is computationally expensive; edit distance or embedding similarity could trade some accuracy for speed.
- **Threshold selection:** The Gaussian threshold (e.g., µ + 3σ) trades false positive rate against false negative rate and requires a held-out benign validation set.

**Failure Signatures:**
- **High benign diversity:** If the ASR model is inherently unstable across precisions (e.g., some seq2seq models), benign *D(x)* will have high variance, causing many false alarms.
- **Adaptive attack success:** An attack explicitly minimizing diversity across precisions (via the multi-precision objective) will produce AEs with low *D(x)*, evading detection, and will also succeed under random precision sampling.
- **Model-specific sensitivity:** Some architectures (e.g., large pretrained Transformers/Whisper) may show lower precision sensitivity, leading to reduced detection AUROC.

**First 3 Experiments:**
1.  **Benign Cross-Precision Validation:** Run a small benign set (e.g., 50 LibriSpeech samples) through the target ASR model under FP32, FP16, and BF16. Compute *D(x)* for each sample. Verify mean *D(x)* is low and variance is reasonable. Fit a Gaussian and check for approximate normality.
2.  **Robustness Sanity Check (C&W Attack):** Generate 10-20 classic C&W AEs for the model (using a standard implementation). Evaluate them under (a) matched precision (should have ~0% WER), (b) each mismatched precision (should show increased WER), and (c) stochastic precision sampling (should show intermediate/high WER). This confirms the core premise.
3.  **Detection Pilot Test:** Using the Gaussian from Experiment 1, compute *D(x)* for 50 benign samples and 50 classic C&W AEs. Calculate a crude accuracy or AUROC. If separation is poor (<0.80), diagnose by checking benign variance, AE robustness to precision, or *K* value.

## Open Questions the Paper Calls Out
### Open Question 1
How can PVP be effectively combined with uncertainty-based defenses to robustify ASR systems against adaptive adversarial attacks? The paper concludes that future work could combine PVP with uncertainty-based defenses like DistriBlock, using precision–diversity and uncertainty to hinder adaptive attacks. This is unresolved because adaptive attacks that optimize across multiple precisions completely bypass both the stochastic robustness and diversity detection.

### Open Question 2
Does the precision-diversity detection approach generalize to diverse ASR architectures, languages, and acoustic domains beyond the English LibriSpeech data evaluated? The paper claims PVP is "model-agnostic" but tests only four English ASR models on LibriSpeech. No experiments on non-English languages, diverse accents, or noisy real-world environments are presented.

### Open Question 3
What is the underlying mechanism causing adversarial examples to exhibit higher sensitivity to numerical precision changes compared to benign inputs? The paper hypothesizes this differential stability but provides no empirical analysis of model internals (e.g., gradients, activations) to explain *why* this occurs.

### Open Question 4
Can alternative transcript similarity metrics (beyond WER) improve precision-diversity detection, particularly for models like Whisper where AUROC was lower? The paper notes Whisper showed reduced detection performance and suggests other sequence dissimilarity metrics could be used but does not explore them.

## Limitations
- **Generality and adaptive attack vulnerability:** The core premise of precision sensitivity is shown to break under a multi-precision adaptive attack, which fully recovers attack success. The evaluation is also limited to four ASR models and two attack types on LibriSpeech.
- **Gaussian assumption for detection:** The detector's simplicity relies on a unimodal Gaussian fit of benign diversity scores. This assumption may not hold for all models (e.g., the Transformer showed lower AUROC) or datasets, potentially increasing false positives.
- **Reproduction uncertainties:** Critical hyperparameters for the psychoacoustic attack and C&W attack are unspecified. The reference ASR model used for the shared Gaussian fit is not identified. The exact method for computing WER between two transcriptions (without a ground-truth reference) is ambiguous.

## Confidence
- **AE precision sensitivity:** Medium. Empirical support across models/attacks is positive, but broken by adaptive attacks and not deeply explained mechanistically.
- **Stochastic precision robustness:** Medium. Effective against non-adaptive attacks but nullified by adaptive ones; effect size is model-dependent.
- **Precision-diversity detection:** Medium. AUROC >0.90 for most models, but lower for Whisper, and fully bypassed by adaptive attacks; relies on Gaussian fit assumption.

## Next Checks
1.  **Generality test:** Evaluate precision sensitivity and detection AUROC on at least two additional ASR architectures (e.g., Conformer, Wav2Vec2) and with a third attack type (e.g., dynamic time warping-based) to expand evidence beyond the paper's four models.
2.  **Gaussian validation:** Collect a large benign diversity distribution (n>1000) from multiple datasets. Perform normality tests (e.g., Shapiro-Wilk) and compare Gaussian-based thresholding against non-parametric (e.g., percentile) thresholding to assess robustness of the detection model's assumptions.
3.  **Adaptive attack stress test:** Implement the paper's multi-precision C&W attack with an explicit diversity minimization term. Measure the degradation in both robustness (WER/SER on AEs) and detection (AUROC) to quantify the worst-case failure mode and identify any residual robustness/detection gaps.
