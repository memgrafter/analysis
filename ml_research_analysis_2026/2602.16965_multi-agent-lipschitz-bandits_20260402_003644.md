# Multi-Agent Lipschitz Bandits
## Quick Facts
- **arXiv ID:** 2602.16965
- **Source URL:** https://arxiv.org/abs/2602.16965
- **Reference count:** 40
- **Primary result:** Communication-free decentralized multi-player stochastic bandits over a continuous Lipschitz action space with hard collisions achieve optimal regret rate \(\tilde{O}(T^{(d+1)/(d+2)})\) and horizon‑independent coordination cost \(O(N^2)\).

## Executive Summary
We consider a decentralized multi-player stochastic bandit problem where each of \(N\) players selects an action in a continuous space \([0,1]^d\) partitioned into cells, receiving a reward that is 1‑subgaussian with mean determined by an unknown Lipschitz function. Multiple players occupying the same cell in a round collide and receive zero reward. The goal is to minimize collective cumulative regret with no communication among players and coordination cost independent of the time horizon. The proposed algorithm breaks the challenge into four phases: (1) uniform sampling of cell centers to obtain rough confidence intervals on cell maxima; (2) a maxima‑directed search using a fine probe grid inside candidate cells to tighten estimates and avoid bias toward cell centers; (3) a decentralized “Musical Chairs” protocol to assign each player to a distinct high‑value cell using only shared randomness (public dither); and (4) each player independently runs a single‑player Lipschitz bandit algorithm within their assigned cell. The coordination cost incurred during Phases I–II and seating is \(O(N^2)\), and the long‑term learning regret matches the single‑player minimax rate \(\tilde{O}(T^{(d+1)/(d+2)})\) without any reward gap assumptions. The framework extends to distance‑threshold collisions via a packing reduction.

## Method Summary
The protocol is modular and communication‑free. It first allocates a fixed budget \(T_0\) for uniform sampling of cell centers, constructing confidence intervals for the maximum reward of each cell that account for Lipschitz smoothness and collision statistics. Players then form an active set of cells potentially containing the top‑\(N\) maxima. In Phase II, each player allocates a fixed budget \(T_1\) to sample a finely spaced \(\eta\)-net within every active cell, accumulating enough successes (non‑collisions) to refine the maxima estimates with width at most \(\varepsilon\). A public dither (or an \(\varepsilon\)-uniqueness property) ensures that all players select the same set of \(N\) target cells. The decentralized Musical Chairs procedure then seats each player on a distinct target cell in expected \(O(N)\) rounds. Finally, each player runs a standard Lipschitz bandit algorithm (e.g., Zooming) solely inside their assigned cell for the remaining rounds. The total regret decomposes into a coordination term (constant in \(T\)) and a learning term whose order matches the optimal single‑player rate.

## Key Results
- Regret rate \(\tilde{O}(T^{(d+1)/(d+2)})\) matching the single‑player minimax bound.
- Coordination cost independent of \(T\): expected \(O(N^2)\) rounds for identification and seating.
- Gap‑free optimality: no reward gap between the top‑\(N\) cells and the rest is required; success relies on either an \(\varepsilon\)-unique instance or a carefully tuned public dither.
- Extension to distance‑threshold collisions via a packing reduction yields the same rate in terms of the packing parameters.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Using a fine grid of probe points inside candidate cells avoids the center‑maximum bias and yields tight confidence intervals for the true cell maxima, even when the reward function has sharp peaks near cell boundaries.
- **Mechanism:** In Phase II, each player samples from an \(\eta\)-net within each active cell for a fixed duration \(T_1\). The Lipschitz property ensures that the maximum reward over the continuous cell is closely approximated by the maximum over the net points. By accumulating enough successful (non‑colliding) observations at each probe point, the algorithm constructs upper and lower confidence bounds that contain the true cell maximum with high probability and with width \(\le \varepsilon\).
- **Core assumption:** The reward function is \(L\)-Lipschitz; collisions can be overcome by sufficient sampling budget because the per‑probe success probability is bounded away from zero when active sets are reasonably small.
- **Evidence anchors:**  
  - Abstract: “maxima‑directed search… refine estimates to bracket true cell maxima, avoiding center bias.”  
  - Section 7 (Phase II) and Proposition 7.2 showing refined brackets with width \(\le \varepsilon\).  
  - Corpus does not directly address this maxima‑directed probe technique; it is novel to this paper.
- **Break condition:** If \(L\) is too large or \(T_1\) is insufficient, the confidence intervals may not achieve the desired width; also, if the active set \(M_{\text{act}}\) grows with \(K\), the success probability can become too small.

### Mechanism 2
- **Claim:** A decentralized version of Musical Chairs seats all \(N\) players on distinct target cells in expected \(O(N)\) rounds, incurring only a horizon‑independent coordination cost.
- **Mechanism:** Players repeatedly and independently sample uniformly from the common set of \(N\) high‑value cells. A player becomes seated if it is the unique chooser of an unoccupied cell in that round. The expected number of newly seated players per round (drift) is quadratic in the number of unseated players (\(\Delta(u) = \frac{u^2}{N}(1-1/N)^{u-1}\)), leading to linear expected total time.
- **Core assumption:** All players share the same target set (consensus from Phase II e.g., via \(\varepsilon\)-uniqueness or public dither); collisions only occur within cells (partition model).
- **Evidence anchors:**  
  - Abstract: “Musical Chairs seats players on distinct high‑value cells without communication… efficient \(O(N)\) expected time.”  
  - Section 8 (Phase II\(_{1/2}\)) and Theorem 8.1 deriving \(\mathbb{E}[T_{\text{MC}}]=O(N)\).  
  - Corpus: Related work cites Musical Chairs in finite‑arm multi‑player bandits, but the analysis for the continuous‑space setting with Lipschitz‑identified targets is new.
- **Break condition:** If target set size is not exactly \(N\) or if players have inconsistent views of the target set, seating can take much longer or fail; the drift formula relies on independent uniform sampling.

### Mechanism 3
- **Claim:** Modular decoupling—first solving coordination with a fixed, horizon‑independent budget, then allowing independent single‑player Lipschitz bandit learning—achieves collective regret matching the single‑player minimax rate \(\tilde{O}(T^{(d+1)/(d+2)})\).
- **Mechanism:** The protocol invests a predetermined amount of time (\(T_0+T_1+T_{\text{MC}}\)) in Phases I–II\(_{1/2}\) to identify the best \(N\) cells and assign one player per cell. Once collision‑free occupancy is established, the problem factorizes into \(N\) independent Lipschitz bandit problems, each solved with standard algorithms (e.g., Zooming) achieving the optimal rate.
- **Core assumption:** After seating, the physical separation of cells guarantees no further collisions; the Lipschitz property holds throughout the domain.
- **Evidence anchors:**  
  - Abstract: “multi‑phase modular protocol… coordination cost independent of \(T\)… regret \(\tilde{O}(T^{(d+1)/(d+2)})\) plus \(T\)-independent coordination cost… matching single‑player minimax rate.”  
  - Section 5 overview and Theorem 10.1 decomposing regret into coordination and learning terms.  
  - Corpus: general multi‑agent bandit works but this exact decoupling is a contribution of this paper.
- **Break condition:** If coordination fails (e.g., Phase II does not produce a common top‑\(N\) set), multiple players may end up in the same cell, causing collisions and increasing regret beyond the bound. Decoupling also requires that within‑cell Lipschitz constant scales with cell size \(h\).

## Foundational Learning
### Lipschitz continuity
- **Why needed:** Provides smoothness so that the reward at any point can be bounded using the reward at a nearby sampled point; this justifies approximating the cell maximum via a finite grid and yields geometric error terms (\(L\cdot\)diameter) in confidence bounds.
- **Quick check:** If \(|\mu(x)-\mu(y)| \le L\|x-y\|_2\), what is the maximum possible error in estimating \(\mu^*(C)\) using only center samples, and how does sampling on an \(\eta\)-net reduce that error?

### Stochastic multi‑armed bandits (MAB)
- **Why needed:** The core problem is sequential decision‑making with unknown reward distributions; the regret framework and concentration tools (Hoeffding, Chernoff) are used throughout to analyze each phase. The single‑player Lipschitz bandit itself extends MAB to continuous spaces.
- **Quick check:** For \(K\) discrete arms, what is the minimax order of expected regret over \(T\) rounds? How does introducing Lipschitz smoothness change the rate?

### Musical Chairs protocol
- **Why needed:** Provides a simple, communication‑free solution to the decentralized coordination problem where \(N\) agents must occupy \(N\) distinct arms (cells). Its analysis yields an expected \(O(N)\) seating time, which is crucial for the coordination cost to be horizon‑independent.
- **Quick check:** For \(N\) players and \(N\) target cells, what is the expected number of rounds until all players are seated? Which term in the drift formula ensures linear scaling?

## Architecture Onboarding
### Component Map
Agents -> Phase I module (uniform cell‑center sampler, collision detector, success counter, coarse confidence builder) -> Phase II module (active set manager, probe‑net generator, probe sampler, per‑probe success counter, refined confidence builder) -> Consensus module (public dither) -> Seating module (Musical Chairs state machine, uniform target‑set sampler, collision detector, seating decision) -> Phase III module (single‑player Lipschitz bandit, e.g., Zooming). Shared data structures include confidence bounds per cell/probe, active sets, target set, and per‑round collision indicators.

### Critical Path
1. Run Phase I for \(T_0\) rounds → coarse brackets for all cells.  
2. Each agent constructs its active set \(S_{\text{act}}^{(0)}\) using safe elimination.  
3. Run Phase II for \(T_1\) rounds → refined brackets for all active cells.  
4. Apply public dither to refined LCBs → select common \(N\)-cell target set (consensus).  
5. Execute Musical Chairs → assign each agent to a unique target cell (seating).  
6. For remaining horizon \(T' = T - (T_0+T_1+T_{\text{MC}})\), each agent runs a single‑player Lipschitz bandit inside its cell.

### Design Tradeoffs
- *Probe fineness \(\eta\) vs. time \(T_1\):* Smaller \(\eta\) yields tighter bounds (width \(\sim L\eta + 2r_1\)) but increases number of probes per cell (\(\propto (h/\eta)^d\)), requiring larger \(T_1\). The choice \(\eta \propto \varepsilon/L\) balances width and sampling cost.
- *Internal precision (\(\varepsilon_{\text{int}}\)) vs. dither gap (\(\eta_{\text{ditch}}\)):* The dither must dominate the maximum cross‑player LCB fluctuation (\(4r_1\)). Setting \(\varepsilon_{\text{main}} = \varepsilon_{\text{int}} + \eta_{\text{ditch}}\) requires careful calibration; too tight \(\varepsilon_{\text{int}}\) inflates \(T_1\), too small \(\eta_{\text{ditch}}\) risks consensus failure.
- *Data reuse across epochs:* Reusing Phase II probe data avoids repeated identification costs but, in the worst‑case Lipschitz instance, the cumulative identification regret can dominate learning unless the near‑optimality dimension \(d^*\) is less than \(d\). This introduces a trade‑off between adaptivity and worst‑case performance.

### Failure Signatures
- *Phase I under‑coverage:* \(T_0\) too small → many cells have few successes → confidence intervals too wide → active set may incorrectly discard optimal cells.
- *Phase II probe starvation:* For some (cell, probe) triple, successes \(s_{j,C,z}(T_1) < b\) → empirical mean not concentrated → refined bracket may not contain true \(\mu^*(C)\) → top‑\(N\) selection error.
- *Consensus breakdown:* Without \(\varepsilon\)-uniqueness or sufficient dither gap, players’ top‑\(N\) sets may differ → Musical Chairs targets may not be common → risk of multiple players seating in same cell, causing collisions in Phase III.
- *Musical Chairs mis‑seating:* Target set size \(\neq N\) or players use inconsistent target lists → seating time blows up (expected time \(> O(N)\)), increasing coordination regret.
- *Post‑seating collisions:* If assigned cells overlap (seating failure) or distance‑threshold model not properly reduced, collisions occur during Phase III, violating decoupling assumption.

### First 3 Experiments
1. **Phase I bracket validity:** Fix \(d=1\), \(h=0.1\), known Lipschitz \(\mu\) (e.g., \(\mu(x)=\sin(10x)\)). Run Phase I with various \(T_0\); verify that \(\text{LCB}^{(0)} \le \mu^*(C) \le \text{UCB}^{(0)}\) holds simultaneously for all cells with probability \(\ge 1-\delta_I\). Measure coverage rate over many seeds.
2. **Phase II maxima‑directed advantage:** Construct a 1‑D instance where two cells have higher center value in one but a sharp boundary peak makes the other truly optimal (Example 7.6). Compare identification accuracy of a center‑only ranking vs. the Phase II probe grid. Show that only the probe grid recovers the correct top‑\(N\) set without reward gap.
3. **Full‑system scaling:** Implement complete protocol for \(N=3\), \(d=2\) with a known Lipschitz function. Vary \(T\) from \(10^3\) to \(10^6\). Plot cumulative regret and break into identification (Phase I+II), seating (Phase II\(_{1/2}\)), and learning (Phase III) components. Verify: (a) coordination cost saturates at \(O(N^2)\); (b) total regret scaling \(\sim T^{(d+1)/(d+2)}\); (c) Musical Chairs expected seating time \(\propto N\). Also test the distance‑threshold reduction by comparing to a direct continuous collision model.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Is Assumption 13.21 (public stratified coverage) necessary for any decentralized algorithm to achieve gap‑free \(\tilde{O}(T^{(d+1)/(d+2)})\) regret?
- **Basis in paper:** [inferred] The gap‑free upper bound (Corollary 10.2) explicitly uses this assumption; the paper does not discuss whether it can be removed.
- **Why unresolved:** The assumption imposes a strong public scheduling requirement; it is unclear if it is fundamental or merely an artifact of the analysis.
- **What evidence would resolve it:** A lower bound proving that without such a schedule the regret must exceed \(\tilde{O}(T^{(d+1)/(d+2)})\), or a constructive algorithm that attains the same rate without the assumption.

### Open Question 2
- **Question:** How can the algorithm be extended to handle unknown Lipschitz constant \(L\) and unknown collision geometry (e.g., cell size \(h\) in the partition model or distance threshold \(\rho\))?
- **Basis in paper:** [inferred] The protocol uses \(L\) and \(h\) explicitly in confidence radii and probe design; no adaptation is considered.
- **Why unresolved:** In practice these parameters are rarely known a priori; adaptivity would greatly increase the framework’s applicability.
- **What evidence would resolve it:** An algorithm that automatically learns \(L\) and the collision parameters on the fly while preserving the optimal regret rate (up to poly‑logarithmic factors).

### Open Question 3
- **Question:** For the distance‑threshold collision model, can we achieve regret with respect to the true \(\rho\)-separated optimum instead of the packing‑based benchmark \(\text{OPT}_{\text{pack}}(r, \sigma, N)\)?
- **Basis in paper:** [explicit] Section 11 states: “Uniformly relating the true \(\rho\)-separated optimum to \(\text{OPT}_{\text{pack}}(r, \sigma, N)\) would require a covering guarantee… the model‑mismatch term per round can be \(\Omega(N L r)\), which is not negligible.”
- **Why unresolved:** The packing benchmark may be significantly smaller than the global optimum if the safe balls do not cover high‑reward regions; thus the current regret bound might be overly pessimistic or misaligned with the natural objective.
- **What evidence would resolve it:** An algorithm that employs a covering argument to directly approximate the \(\rho\)-separated optimum, or a lower bound showing that the packing benchmark is inherently optimal under the collision constraints.

## Limitations
- Active set size may scale with \(K\); if near‑optimality dimension \(d^*\) is large, Phase II time can dominate learning.
- Public dither consensus requires dither gap \(> 4r_1\); miscalibration breaks Musical Chairs and may cause collisions later.
- Packing parameters \((r,\sigma)\) for distance‑threshold collisions lack guidance; suboptimal \(\sigma\) causes collisions or inflates the learning term \((L\sigma)^{d/(d+2)}\).
- The protocol needs known Lipschitz constant \(L\) and cell side \(h\); unknown parameters introduce additional uncertainty and overhead.
- Universal constants in the single‑player Lipschitz regret bound are unspecified, requiring empirical estimation for concrete implementations.
