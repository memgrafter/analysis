# Evaluating Test-Time Adaptation For Facial Expression Recognition Under Natural Cross-Dataset Distribution Shifts

## Quick Facts
- arXiv ID: 2603.19994  
- Source URL: https://arxiv.org/abs/2603.19994  
- Reference count: 0  
- Primary result: Test-Time Adaptation improves FER accuracy under cross-dataset shifts by up to 11.34%, with method choice depending on target label noise and domain gap.

## Executive Summary
This paper addresses the degradation of Facial Expression Recognition (FER) models under natural cross-dataset distribution shifts. The authors evaluate a suite of Test-Time Adaptation (TTA) methods on three widely used FER datasets: AffectNet, FERPlus, and RAF-DB. Using ViT-L/16 backbones fine-tuned on a source dataset, they adapt the model to a target dataset at test time by updating only LayerNorm parameters in streaming batches. Distributional shift is quantified via an MMD-based similarity score between source and target features.

Key results show that TTA can substantially improve accuracy, with SHOT achieving a gain of 11.34% when adapting from FERPlus to AffectNet. The relative performance of methods varies with target characteristics: entropy minimization (TENT, SAR) works best on cleaner targets, prototype adjustment (T3A) excels under larger domain gaps, and feature alignment (SHOT) provides the largest improvements for noisier targets. Continual adaptation methods consistently underperform. Effectiveness is strongly correlated with the pre-adaptation MMD similarity and the severity of label noise in the target.

## Method Summary
The study employs ViT-L/16 backbones initialized from a facial expression pre-trained checkpoint (FMAE-IAT). Each source dataset (AffectNet, FERPlus, RAF-DB) is used to fine-tune a separate model using AdamW with cosine learning rate decay. For cross-dataset evaluation, a fine-tuned source model is deployed on a target dataset's test set in streaming batches of 16 samples. At test time, selected TTA methods update only the LayerNorm parameters of the ViT using a learning rate of 1e-3. Methods include entropy minimization (TENT, SAR), feature alignment (SHOT), prototype adjustment (T3A), and continual variants (CoTTA, RoTTA). Accuracy is reported as top-1 percentage, and the distributional shift is quantified by an MMD-based similarity score computed from features extracted from the ViT.

## Key Results
- TTA yields gains up to 11.34% (SHOT on FERPlus→AffectNet).
- Entropy minimization (TENT, SAR) performs best when the target is relatively clean.
- Prototype-based adjustment (T3A) excels with larger domain gaps (lower MMD similarity).
- Feature alignment (SHOT) delivers largest improvements for noisier target datasets.
- Continual adaptation (CoTTA, RoTTA) underperforms other TTA approaches.
- TTA effectiveness correlates with pre-adaptation distributional distance and target label noise severity.

## Why This Works (Mechanism)
The varying success of TTA methods stems from how they balance domain alignment and robustness to label noise. Entropy minimization assumes high-confidence predictions are correct, which holds for cleaner targets but fails under noisy labels. Feature alignment (SHOT) aligns target features to source statistics without relying on pseudo-labels, offering noise robustness. Prototype-based adaptation (T3A) refines class centroids using low-entropy samples, bridging larger domain gaps where initial prototypes are poor. Continual methods accumulate errors from noisy batches, harming performance. The MMD similarity provides a pre-adaptation diagnostic of domain gap, guiding method selection.

## Foundational Learning
- **Test-Time Adaptation (TTA)**: Adapting a model at inference using unlabeled target data. *Why needed*: Deploy models without retraining. *Quick check*: Update only certain parameters (e.g., BN/LN) with entropy minimization.
- **Domain Shift**: Change in data distribution between source and target. *Why needed*: Models degrade under shift. *Quick check*: Compare dataset statistics or feature distributions.
- **Maximum Mean Discrepancy (MMD)**: A distance measure between distributions using kernel embeddings. *Why needed*: Quantify domain shift without labels. *Quick check*: Compute mean of kernel features for each set, then squared difference.
- **Entropy Minimization**: Encourage low entropy predictions on unlabeled target. *Why needed*: Leverage clustering assumption. *Quick check*: Minimize average -∑ p log p over batch.
- **Prototype-Based Adaptation**: Use class centroids from source or target for alignment. *Why needed*: Provide robust class representations. *Quick check*: Compute mean feature per class, assign pseudo-labels based on nearest centroid.
- **Feature Alignment**: Align target feature distribution to source (e.g., via adversarial learning or moment matching). *Why needed*: Reduce domain discrepancy. *Quick check*: Add a discriminator or MMD loss between source and target features.

## Architecture Onboarding
- **Component map**: Source Dataset -> Fine-tuned ViT-L/16 (with LayerNorm) -> TTA Module (updates LayerNorm) -> Target Predictions
- **Critical path**:  
  1. Fine-tune ViT on source dataset.  
  2. For each target batch: forward pass, compute adaptation loss (e.g., entropy, SHOT loss), backward to update only LayerNorm.  
  3. Predict with updated model.  
- **Design tradeoffs**:  
  - Entropy methods (TENT, SAR): simple, fast, but sensitive to label noise.  
  - SHOT: robust to noise, requires source feature statistics and careful hyperparameters.  
  - T3A: balances noise via confidence filtering, good for medium gaps.  
  - Continual methods: aim to preserve source knowledge but may overfit to batch noise.  
- **Failure signatures**:  
  - Accuracy drops during adaptation → entropy method on noisy target.  
  - High batch-to-batch variance → poor pseudo-label quality.  
  - Memory/CPU spikes → continual methods with parameter buffers.  
- **First three experiments**:  
  1) Baseline: Evaluate source model on target without adaptation.  
  2) Apply TENT on a clean target (e.g., pair with high MMD similarity).  
  3) Apply SHOT on a noisy target (e.g., AffectNet as target).

## Limitations
- Fine-tuning hyperparameters (learning rates, weight decay) are not fully specified, hindering exact replication of source models.
- MMD similarity computation details (feature layer, kernel bandwidth, normalization) are omitted, affecting reproducibility of the distributional distance metric.
- TTA-specific thresholds (e.g., confidence for pseudo-labels, entropy filters) are not reported, requiring guesswork or grid search.
- Random seeds and variance reporting are missing, limiting statistical assessment of results.
