# Neural Proposals, Symbolic Guarantees: Neuro-Symbolic Graph Generation with Hard Constraints

## Quick Facts
- **arXiv ID:** 2602.16954
- **Source URL:** https://arxiv.org/abs/2602.16954
- **Reference count:** 40
- **Primary result:** A neuro-symbolic framework that guarantees chemical validity and explicit constraint satisfaction by combining a neural proposal system with an SMT solver, achieving 100% validity and superior performance on constrained generation tasks.

## Executive Summary
Purely neural molecular graph generation lacks explicit controllability and formal constraint guarantees. This paper introduces NSGGM, a neuro-symbolic approach that decomposes molecules into motif tokens with interfaces, uses a lightweight neural autoregressive model to propose scaffold sequences and refine interactions, and employs a CPU-efficient SMT solver to assemble full graphs under hard chemical validity and user-defined constraints. This division of labor ensures correctness by construction while maintaining competitive distributional metrics on standard unconstrained benchmarks. Under hard logical and scaffold constraints, NSGGM significantly outperforms neural baselines in constraint satisfaction and uniqueness, with perfect validity maintained. The authors also release a Logical-Constraint Molecular Benchmark to rigorously test explicit rule compliance.

## Method Summary
NSGGM first decomposes training molecules into a vocabulary of motif tokens (cycles and tree fragments) via a cycle-based decomposition and tree mining, characterizing each token with interface slots (element type, valency, residual capacities). A neural proposal module—comprising a GNN encoder, a Transformer decoder, and a refinement network—generates sequences of motif tokens and predicts blueprint details (interface variants, merge types, parent-child relationships). At inference, the system constructs a blueprint from the neural output and encodes assembly as an SMT problem with hard constraints for chemical validity (element consistency, valency caps, edge-slot matching) and user-specified logical formulas. An SMT solver (Z3) finds a satisfying assignment or reports UNSAT; a valid molecular graph is then reconstructed. The approach is evaluated on unconstrained benchmarks (GuacaMol, MOSES, QM9) and a new Logical-Constraint Molecular Benchmark, demonstrating perfect validity and high constraint satisfaction rates.

## Key Results
- 100% validity on unconstrained benchmarks (GuacaMol, MOSES, QM9) with competitive distributional metrics (e.g., FCD 86.1 on GuacaMol).
- Significantly higher constraint satisfaction rates and uniqueness compared to neural baselines (MOLER, GENMOL) under hard logical and scaffold constraints.
- Perfect validity maintained even under complex user constraints, with the Logical-Constraint Benchmark providing a rigorous test for explicit rule compliance.

## Why This Works (Mechanism)
**Mechanism 1:** Decomposing molecules into motif tokens with explicit interface slots enables structured, reusable components for assembly. The system uses a cycle-based decomposition to partition graphs into overlapping cycles and tree components, assigning interface characterizations (element type, valency, residual capacities) to each token, creating a blueprint of slotted primitives. Core assumption: Molecules can be represented as compositions of recurring motifs with sufficiently informative interfaces. Evidence: [abstract] "reapproaches molecule generation as a scaffold and interaction learning task with symbolic assembly"; [section 3.1] details decomposition algorithm. Break condition: Ambiguous interfaces may cause solver failure or invalid graphs.

**Mechanism 2:** A lightweight neural autoregressive model proposes scaffold token sequences and refines interaction signals, providing data-driven priors for plausible generation. A VAE with GNN encoder on motif graphs samples a latent code conditioning a Transformer decoder to generate token sequences; a refinement network predicts blueprint characterizations, merge types, and parent-child relationships. Core assumption: Distribution of valid graphs captured by motif sequences; neural guidance biases assembly toward plausible compositions. Evidence: [abstract] "lightweight neural autoregressive model proposes scaffolds and refines interaction signals"; [section 3.3] describes VAE, encoder, decoder, refinement network. Break condition: Poor neural proposals lead to low validity or UNSAT; ablations show FCD degradation without neural guidance.

**Mechanism 3:** SMT-based symbolic assembly enforces hard chemical validity and user constraints by construction. Given a blueprint, the system encodes assembly as an SMT problem with merge variables and constraints for element consistency, valency caps, edge-sharing, etc. The solver finds a model satisfying all hard constraints or returns UNSAT; soft constraints encourage connectivity. Core assumption: Exact constraint satisfaction efficiently solvable via SMT; symbolic constraints capture chemical rules. Evidence: [abstract] "CPU-efficient SMT solver assembles full graphs while enforcing chemical validity, structural rules, and user-specific constraints"; [section 3.2] formal definition and SMT encoding. Break condition: Contradictory user constraints yield UNSAT; blueprint inconsistent with training data may fail.

## Architecture Onboarding
Component map: Decomposition module -> Neural proposal module (VAE encoder + Transformer decoder + refinement network) -> SMT assembly module -> User constraint interface.
Critical path: Input graph -> decomposition -> vocabulary building -> train VAE -> at inference: sample latent -> decode token sequence -> refine interfaces -> assemble via SMT -> output graph.
Design tradeoffs: Neural component provides flexibility and data-driven priors; symbolic component ensures validity but may limit expressiveness. Split allows each to excel in its domain but introduces pipeline complexity and potential mismatch between neural proposals and solver feasibility.
Failure signatures: UNSAT from solver indicates impossible constraints; high invalid rate if neural guidance removed; poor distributional metrics if neural model underfits.
First 3 experiments: 1) Unconstrained generation benchmark (GuacaMol, MOSES, QM9) for distributional fidelity and validity. 2) Logical constraint satisfaction benchmark with synthetic rules for explicit constraint compliance. 3) Scaffold-constrained generation to evaluate controllability under fixed subgraph requirements.

## Open Questions the Paper Calls Out
**Open Question 1:** How can neuro-symbolic frameworks balance the trade-off between neural prior flexibility and symbolic solver guarantees for complex, under-specified user intents? Basis in paper: Authors state "we hope it motivates future works that better balance flexibility with verification and interpretability" in the conclusion. Why unresolved: NSGGM relies exclusively on hard constraints, which cannot capture ambiguous preferences or soft requirements, limiting applicability in open-ended design scenarios. What evidence would resolve it: Developing hybrid models that incorporate soft probabilistic constraints alongside hard guarantees, evaluated on benchmarks requiring nuanced control (e.g., multi-objective optimization with verifiable thresholds).
**Open Question 2:** What techniques can enable non-expert chemists to specify complex hard constraints for molecular generation without requiring SMT logic expertise? Basis in paper: User constraints must be encoded in SMT formulas (Section 3.2), implying users need formal methods knowledge, creating a usability barrier. Why unresolved: Without accessible constraint-specification tools, formal guarantees remain confined to users with specialized training. What evidence would resolve it: Implementing and validating user-friendly interfaces (e.g., natural language or visual editors) that compile high-level chemical rules to SMT, supported by user studies measuring correctness and efficiency.
**Open Question 3:** How can the neural proposal component of NSGGM be improved to increase satisfaction rates for logical constraints with very low training-data coverage, as seen with φ3 (25% rate)? Basis in paper: Section 4.2 notes low satisfaction despite symbolic enforcement, while baselines fail entirely, indicating neural guidance limitations. Why unresolved: The neural model may not effectively explore constrained regions outside the training distribution, reducing efficiency for rare specifications. What evidence would resolve it: Enhancing neural training with constraint-aware objectives (e.g., reinforcement learning from solver feedback) or data augmentation, and measuring improvements on the Logical-Constraint Benchmark with varying support levels.

## Limitations
- Decomposition hyperparameters (support threshold τ, top-K blueprint variants) unreported, hindering exact replication.
- Neural training details (epochs, β-VAE weight, loss weighting, learning rate schedule) unspecified.
- Scaffold predicate definitions (SMARTS patterns or isomorphism checks) absent, preventing independent verification of constraint benchmarks.
- SMT soft constraint weights and precise handling of aromatic bond orders/valency caps unclear.
- Baseline comparison setup (sampling budgets, conditioning mechanisms for MOLER/GENMOL) ambiguous.
