# Predictive Uncertainty in Short-Term PV Forecasting under Missing Data: A Multiple Imputation Approach

## Quick Facts
- **ArXiv ID**: 2603.15564
- **Source URL**: https://arxiv.org/abs/2603.15564
- **Reference count**: 40
- **Primary result**: Multiple imputation with Rubin’s rule improves 95% prediction interval coverage from 70.7–85.1% to 83.7–93.6% while keeping point prediction error comparable.

## Executive Summary
This paper addresses predictive uncertainty in short-term photovoltaic (PV) power forecasting when historical PV observations are missing. Existing methods typically use single imputation, which treats imputed values as true and thus underestimates predictive variance, leading to under-calibrated prediction intervals. The authors propose a model-agnostic framework that combines stochastic multiple imputation (MI) with Rubin’s rules to propagate missing-data uncertainty. In experiments on a dataset with ~29.5% simulated missing PV values, single imputation produced 95% interval coverages between 70.7% and 85.1% across four machine learning models, indicating significant under-coverage. The MI approach raised coverage to 83.7–93.6%, achieving near-nominal calibration without degrading point prediction accuracy (NRMSE 0.121–0.136). The results demonstrate that ignoring imputation uncertainty leads to overly narrow intervals, and that the proposed MI framework enhances calibration while preserving accuracy, with uncertainty primarily arising from missing test inputs.

## Method Summary
The method proceeds in two phases: imputation and prediction aggregation. First, missing PV power values are imputed using a stochastic k-nearest neighbor sampler (kNNSampler) that approximates the conditional distribution Pr(P_t | I_t) by sampling from observed PV values with irradiance closest to the current I_t. This generates B imputed versions of both the training and test datasets. Second, for each imputed dataset a base predictor (e.g., Random Forest, kNN, MLP, Lasso) is trained. For each test instance, the B models produce predictions and their training residual variances. These are combined using Rubin’s rules: the final predictive mean is the average of the B predictions; the total variance is the within-imputation variance plus (1 + 1/B) times the between-imputation variance. This total variance reflects both model noise and uncertainty due to missing data. Prediction intervals are then constructed assuming a normal or gamma distribution. The framework is model-agnostic and can be applied to any regression model.

## Key Results
- Single imputation (SI) yields 95% interval coverages of 70.7%–85.1% (normal distribution), indicating severe under-coverage due to ignored imputation uncertainty.
- Multiple imputation (MI) with Rubin’s rule improves coverage to 83.7%–93.6% across four machine learning models, achieving near-nominal calibration.
- Point prediction accuracy, measured by normalized root mean square error (NRMSE), remains comparable between SI and MI (0.121–0.136).

## Why This Works (Mechanism)
### Mechanism 1: Single imputation collapses uncertainty
- **Claim**: Single imputation leads to under-calibrated intervals because it treats imputed values as fixed, ignoring their sampling variability.
- **Mechanism**: The trained model sees imputed values as true, so its estimated residual variance captures only model noise, not the uncertainty from estimating missing values.
- **Evidence**: Single imputation (B=1) yields coverages 70.7–85.1% vs. nominal 95%; between-imputation variance term is zero in Rubin’s rule.
- **Break condition**: If imputation uncertainty is negligible (e.g., extremely sparse missingness or perfect imputation), under-coverage may not appear.

### Mechanism 2: Multiple imputation adds between-imputation variance
- **Claim**: MI with Rubin’s rule improves calibration by explicitly modeling and adding between-imputation variance to the predictive distribution.
- **Mechanism**: B imputed datasets create variability in predictions; Rubin’s rule inflates total variance = WV + (1+1/B)*BV to account for missing-data uncertainty.
- **Evidence**: MI (Setup 3) yields coverages 83.7–93.6% vs. SI’s 70.7–85.1%.
- **Break condition**: If B is too small or imputation model mis-specified, coverage may remain off.

### Mechanism 3: Test-input missingness dominates
- **Claim**: Uncertainty from missing test-time inputs is larger than from missing training data.
- **Mechanism**: Missing test inputs directly affect a specific prediction, while missing training data averages out over many points.
- **Evidence**: Coverage increase from SI train/MI test vs. MI train/MI test is small (e.g., RF: +9.7 pp vs. +1.1 pp).
- **Break condition**: If training missingness is extremely high or test missingness minimal, dominance could reverse.

## Architecture Onboarding
### Component map
Raw data → missingness masks → stochastic imputation (B draws) → B models → B test predictions → Rubin aggregation → interval

### Critical path
The core steps are: (1) generate B imputed training sets using kNNSampler; (2) train B models; (3) for each test instance, impute missing inputs B times and obtain B predictions; (4) combine predictions and residual variances via Rubin’s rules; (5) construct final intervals.

### Design tradeoffs
- **B value**: Larger B reduces Monte Carlo error but increases compute; paper suggests B=5 suffices.
- **Imputation method**: kNNSampler is model-agnostic and consistent; more complex methods (e.g., neural nets) may capture nonlinearities but risk overfitting.
- **Interval distribution**: Normal yields better calibration but may produce negative bounds; gamma respects non-negativity but was under-calibrated in experiments.

### Failure signatures
- **Low coverage even with MI**: Check between-imputation variance BV; if BV ≈ 0, imputation may be too deterministic (e.g., k too large, sampling not stochastic). Increase stochasticity or B.
- **Degraded NRMSE with MI**: Imputation may introduce bias; verify k selection, feature scaling, and hyperparameter tuning (avoid overfitting to a single imputed set).
- **Gamma intervals anti-conservative or negative**: Normal intervals may be preferred; if normal intervals also under-cover, revisit Rubin’s rule implementation and imputation variance estimation.
- **Computational explosion**: Parallelize imputation rounds; reduce B if needed.

### First 3 experiments
1. **Baseline replication**: Run Setup 1 (SI train & test) with Random Forest; expect under-coverage ~74–85%.
2. **Core test**: Run Setup 3 (MI train & test) with B=5; expect coverage ~83–93%.
3. **Sensitivity**: Compare B=5 vs. B=10 for coverage and runtime; paper suggests minimal difference.

## Limitations
- The study uses a single dataset with simulated block missingness; the exact missing pattern is undisclosed, limiting reproducibility.
- Hyperparameters (e.g., k in kNNSampler, model tuning) are not reported, so results may vary with different choices.
- The gamma predictive interval distribution was poorly calibrated, reducing applicability where non-negativity is essential.
