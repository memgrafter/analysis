# Beyond Exposure: Optimizing Ranking Fairness with Non-linear Time-Income Functions

## Quick Facts
- arXiv ID: 2602.03345
- Source URL: https://arxiv.org/abs/2602.03345
- Reference count: 40
- Primary result: DIDRF algorithm jointly optimizes fairness (Income Fairness) and effectiveness (cNDCG) using marginal income gains and second-order Taylor expansion, outperforming baselines in simulations with non-linear time-income functions.

## Executive Summary
This paper critiques Exposure Fairness for ignoring contextual factors like time, which cause provider income to decay non-linearly with ranking position. It proposes Income Fairness, a framework that models provider welfare via a given time-income function f(t). The DIDRF algorithm is introduced to optimize this fairness metric alongside ranking effectiveness (cNDCG). DIDRF approximates income loss using marginal gains and a second-order Taylor expansion, enabling efficient re-ranking. Extensive simulations across diverse f(t) functions show DIDRF achieves significantly lower unfairness and higher cNDCG than state-of-the-art baselines. Ablation studies confirm the importance of second-order terms, and the algorithm maintains O(|D|log|D|) runtime.

## Method Summary
DIDRF formulates fairness as minimizing the maximum normalized income loss across providers relative to an ideal ranking. Given a time-income function f(t), it computes marginal income gains (differences in f(t) between positions) and augments them with a second-order Taylor term to capture curvature in f(t). The resulting optimization problem is solved via a constrained greedy re-ranking that balances these fairness-oriented marginal gains against effectiveness metrics like cNDCG. This approach allows tractable optimization even with non-linear f(t).

## Key Results
- DIDRF consistently achieves lower Income Fairness unfairness and higher cNDCG than baselines (MCFair, FARA) across varied synthetic time-income functions.
- Ablation studies show disabling second-order Taylor terms degrades performance, especially for steep non-linear f(t).
- Algorithmic complexity is O(|D|log|D|), supporting practical deployment.

## Why This Works (Mechanism)
Income Fairness directly targets provider welfare by modeling how income decays non-linearly with position over time via f(t). DIDRF’s use of marginal income gains provides a first-order signal for re-ranking, while the second-order Taylor expansion accounts for curvature in f(t), preventing suboptimal swaps that first-order methods would miss. ## Foundational Learning
- **Exposure Fairness**: Fairness metric based on linear position exposure; baseline concept DIDRF extends. *Why needed*: Sets contrast for Income Fairness. *Quick check*: Does it model time decay? (No)
- **Income Fairness**: Proposed fairness framework using f(t) to model non-linear income. *Why needed*: Aligns fairness with actual provider welfare. *Quick check*: Requires specification of f(t).
- **Time-Income Function f(t)**: Maps ranking position to expected income, often monotonically decreasing. *Why needed*: Quantifies positional impact on earnings. *Quick check*: Must be provided or estimated.
- **Marginal Income Gains**: Difference f(t_i) - f(t_j) between positions i and j. *Why needed*: First-order driver for re-ranking decisions. *Quick check*: Computed pairwise during optimization.
- **Second-Order Taylor Expansion**: Approximates income loss using second derivative of f(t). *Why needed*: Captures non-linearities beyond marginal gains. *Quick check*: Included as curvature correction term.
- **Fairness-Utility Trade-off**: Balancing Income Fairness and cNDCG. *Why needed*: Real systems require both quality and fairness. *Quick check*: Controlled via constraint parameter in DIDRF.

## Architecture Onboarding
**Component Map**: Time-Income Function f(t) -> Marginal Gain Calculator -> Taylor Approximation Module -> Constrained Optimizer -> Re-ranked List

**Critical Path**: 1. Input f(t) and initial ranking. 2. Compute marginal income gains for all provider-position pairs. 3. Form second-order Taylor approximations of income loss for potential swaps. 4. Solve constrained optimization to minimize max normalized loss while maximizing cNDCG. 5. Output final ranking.

**Design Tradeoffs**:
- Accuracy vs. Complexity: Second-order terms improve fairness capture but add minor overhead; overall O(|D|log|D|) remains efficient.
- Generality vs. Assumptions: Framework works for any f(t) but critically depends on f(t) being accurate and static.
- Fairness vs. Utility: Explicit constraint balances both; λ parameter tunes strictness.

**Failure Signatures**:
- Unfairness remains high if f(t) is misspecified or drifts over time.
- cNDCG collapses if fairness constraint is overly restrictive relative to λ.
- Runtime exceeds O(|D|log|D|) if implementation has hidden constants or poor data structures.

**First Three Experiments**:
1. **Synthetic Baseline Test**: Generate data with known f(t) (e.g., exponential decay), run DIDRF vs. random and exposure-based baselines, report unfairness and cNDCG.
2. **Ablation Analysis**: Run DIDRF with second-order terms disabled; compare performance on steep vs. shallow f(t) to quantify second-order contribution.
3. **Scaling Verification**: Measure wall-clock time and memory for |D| = 10^3, 10^4, 10^5; fit empirical complexity to verify O(|D|log|D|).

## Limitations
- Validation solely via simulations; real-world robustness with messy, incomplete income data is unverified.
- Method assumes a known, fixed f(t); no guidance on estimation or sensitivity to misspecification.
- No formal statistical fairness guarantees; evaluation relies on empirical reduction of a proposed metric.
