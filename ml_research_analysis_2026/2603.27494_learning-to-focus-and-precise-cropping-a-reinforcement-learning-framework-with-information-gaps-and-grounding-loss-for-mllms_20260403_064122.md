# Learning to Focus and Precise Cropping: A Reinforcement Learning Framework with Information Gaps and Grounding Loss for MLLMs

## Quick Facts
- **arXiv ID**: 2603.27494
- **Source URL**: https://arxiv.org/abs/2603.27494
- **Reference count**: 40
- **Primary result**: Achieves state-of-the-art accuracy on HR-Bench and V* benchmarks with 80.6% on HR-Bench 8K using only 1024 tokens, and reduces inference time to 2.8s vs. 12.4s for DeepEyes.

## Executive Summary
Existing agent-based multimodal large language models (MLLMs) often fail to effectively use cropped image regions for fine-grained reasoning, defaulting to low-resolution global inputs. This paper introduces a two-stage reinforcement learning framework to address this. The first stage creates an "information gap" by downsampling the global image while preserving cropped regions at high resolution, compelling the model to rely on crop details. The second stage adds a grounding reward derived from sparse bounding box annotations to improve cropping precision. The approach achieves new state-of-the-art results on HR-Bench and V* benchmarks under strict visual token budgets (e.g., 80.6% overall on HR-Bench 8K with 1024 tokens). It also markedly improves inference efficiency and cropping accuracy, demonstrating the value of explicit focus mechanisms.

## Method Summary
The proposed method consists of two reinforcement learning stages. In stage one, the agent is trained to select crop regions while the global image is deliberately downsampled, creating an information gap that forces dependence on the high-resolution crops. This encourages the model to learn to extract fine-grained details from crops rather than relying on global context. In stage two, a grounding reward is incorporated using sparse bounding box annotations to incentivize precise alignment between selected crops and relevant objects. The overall training combines task-specific rewards (e.g., answer accuracy) with the grounding reward, optimizing the cropping policy for both performance and localization. The framework is designed to operate under tight token budgets by limiting the number of visual tokens processed.

## Key Results
- **SOTA performance**: Achieves 80.6% accuracy on HR-Bench 8K with only 1024 tokens, surpassing prior methods.
- **Efficiency**: Reduces inference time to 2.8s compared to 12.4s for DeepEyes on HR-Bench 8K.
- **Cropping precision**: Grounding loss improves cropping IoU by 5–9% over baselines.

## Why This Works (Mechanism)
The mechanism hinges on two complementary forces. First, the information gap (downsampled global + high-res crops) removes crutch-like global details, compelling the model to attend to and reason over the cropped regions. This directly addresses the failure mode where models ignore crops. Second, the grounding reward provides a supervised signal that aligns crop regions with object boundaries, sharpening localization. Together, they ensure that the cropping policy produces both useful and precise regions, leading to better fine-grained reasoning and token efficiency.

## Architecture Onboarding
Component map: Global Encoder -> Cropping Policy -> Crop Extractor -> Feature Fusion -> MLLM Decoder; Reward Model (Grounding) -> Policy Update.  
Critical path: (1) Downsample global image and encode; (2) Policy network selects crop region based on current state; (3) Extract high-resolution crop; (4) Encode crop and fuse with global features; (5) MLLM decoder generates answer; (6) Compute reward (task accuracy + grounding IoU); (7) RL update (e.g., PPO) of policy.  
Design tradeoffs: Downsampling reduces token count but loses global context; cropping adds detail but may miss relevant areas; grounding loss improves precision but requires sparse annotations; two-stage training balances exploration (stage 1) and precision (stage 2).  
Failure signatures: Attention maps remain focused on global features; crops have low IoU with ground truth; performance collapses on images without salient objects; high variance when bounding boxes are scarce.  
First three experiments: 1) Reproduce main results on HR-Bench 8K (1024 tokens) to verify accuracy and inference time. 2) Ablate the information gap by using high-resolution global images and measure impact on accuracy and crop usage. 3) Ablate the grounding loss to isolate its effect on cropping IoU and overall performance.

## Limitations
- No analysis of scalability to higher resolutions or varying token budgets.
- Pre-cropping design may fail for images without obvious salient objects.
- Requirement for sparse bounding box annotations limits broad applicability.

## Confidence
