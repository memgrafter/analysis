# Sensivity of LLMs' Explanations to the Training Randomness:Context, Class & Task Dependencies
## Quick Facts
- arXiv ID: 2603.08241
- Source URL: https://arxiv.org/abs/2603.08241
- Reference count: 14
- Primary result: Explanation stability (MCWME) varies systematically with task type, class characteristics, and syntactic context.

## Executive Summary
This paper investigates how training randomness affects the stability of explanations generated by transformer language models (RoBERTa, CamemBERT) via Layer-wise Relevance Propagation (LRP). Using both controlled synthetic datasets and real-world text classification corpora, the authors fine-tune hundreds of models with different random seeds and quantify explanation consistency with the Mean Correlation With Mean Explanation (MCWME) metric. The results show that task type exerts the strongest influence (e.g., InfOpinion tasks yield lower stability than arXiv tasks), class characteristics have a medium impact (absence of clear discriminant words reduces stability), and syntactic context produces only a minor effect (shuffling words slightly lowers stability). The study highlights that explanation variability is not merely noise but depends on the nature of the task and data.

## Method Summary
The methodology involves generating synthetic datasets (e.g., 10-word sentences differing by a single name, shuffled versions, and variants with random class words) and using two real-world datasets: ArXiv abstracts and InfOpinion articles. For each dataset, 200 instances of a pre‑trained model (RoBERTa‑base for English, CamemBERT‑base for French) are fine‑tuned with different random seeds, keeping hyperparameters fixed (learning rate 2e-5, batch size 16, 1 epoch). A subset of *m* models (target *m* = 100) is selected whose test accuracies are statistically equivalent (one‑way ANOVA *p* ≥ 0.05). For every test text that receives the same predicted label from all selected models (compatible texts), LRP explanations are computed for each model. MCWME is then obtained by leave‑one‑out averaging: for each model, the correlation between its explanation and the mean of the others is computed (Pearson), and these correlations are averaged across models and texts. Comparisons across conditions (e.g., shuffled vs. ordered sentences, different classes, different tasks) use paired statistical tests to assess the impact on explanation sensitivity.

## Key Results
- Task type: InfOpinion (MCWME ≈ 0.95) is significantly less stable than ArXiv (MCWME ≈ 0.98).
- Class characteristics: Classes without a clear discriminant word yield much lower stability (MCWME ≈ 0.7) compared to classes with such words.
- Syntactic context: Shuffling word order leads to a slight reduction in MCWME, indicating a small effect relative to task and class factors.

## Why This Works (Mechanism)
The sensitivity of LRP explanations to training randomness arises because different random seeds lead the fine‑tuning process to converge to distinct local minima in the loss landscape. These minima correspond to different internal representations and gradients, which in turn affect the relevance propagation paths computed by LRP. Task complexity modulates this effect: complex tasks with subtle cues (e.g., distinguishing information from opinion) offer many equally good solutions, so model parameters vary more widely, increasing explanation variability. Simpler tasks with obvious lexical triggers (e.g., arXiv categories) push models toward similar solutions, enhancing stability. Class-specific discriminant words provide strong, consistent gradient signals that anchor LRP attributions; without such anchors, the explanations rely on noisier patterns, amplifying the impact of weight differences. Syntactic structure introduces regularities (e.g., positional patterns) that offer secondary stability; shuffling disrupts these, but the effect remains modest compared to lexical and task influences.

## Architecture Onboarding
**Component Map**  
Data Preparation -> Model Training (200 random seeds) -> Model Selection (ANOVA) -> Compatible Text Filter -> LRP Engine (Captum) -> Explanation Vectors -> MCWME Computation (Pearson + averaging) -> Comparative Statistics

**Critical Path**  
The main workflow proceeds from fine‑tuning many models, through statistical filtering, to explanation generation and finally to stability aggregation. Any bottleneck (e.g., insufficient compatible texts) directly impacts the reliability of MCWME.

**Design Tradeoffs**  
- Number of models (*m*) vs computational load: Larger *m* improves stability estimates but increases training and inference cost.
- Strictness of equivalence criterion: A tighter accuracy bound yields more comparable models but reduces the number of retained models.
- Choice of LRP variant: Different propagation rules (epsilon, alpha‑beta) may produce different stability values, affecting generality.
- Synthetic vs real data: Controlled datasets isolate factors but may lack realism; real tasks introduce confounding variables.

**Failure Signatures**  
- Very few compatible texts after model selection (e.g., <30), leading to high variance in MCWME.
- Significant spread in accuracies among the selected models (standard deviation >0.5%), indicating imperfect equivalence.
- Inconsistent MCWME trends across different random seeds of the same condition.
- Outlier MCWME values for certain texts that dominate the average.

**First Experiments**  
1. Run LRP on a single model using a handcrafted sentence (e.g., “The movie was great”) and verify that words with obvious sentiment receive higher relevance.
2. With 10 models per dataset, compute MCWME on a small test set to confirm the pipeline and estimate the expected range and variance of the metric.
3. Replicate the shuffled‑vs‑ordered comparison on one synthetic dataset to observe the expected small effect before scaling to the full 200‑model suite.

## Limitations
- The exact procedure for constructing the 10k 10‑word synthetic sentences (templates vs. corpus sampling) is unspecified, hindering exact replication.
- Key LRP implementation details (e.g., epsilon rule, normalization) are omitted, which may affect stability measurements.
- The model equivalence criterion (ANOVA *p* ≥ 0.05) is permissive; residual accuracy differences could bias stability comparisons across conditions.

## Confidence
- Task type effect: Medium
- Class characteristics effect: Medium
- Syntactic context effect: Low
