# Rationale-Grounded In-Context Learning for Time Series Reasoning with Multimodal Large Language Models

## Quick Facts
- **arXiv ID:** 2601.02968
- **Source URL:** https://arxiv.org/abs/2601.02968
- **Reference count:** 40
- **Key outcome:** RationaleTS achieves 69.76% F1 and 77.32% AUC on Finance dataset, outperforming GPT-5 (66.53% F1, 74.90% AUC) via explicit reasoning priors.

## Executive Summary
Multimodal large language models often fail at time series reasoning because they lack structured rationales linking temporal observations to outcomes, leading to superficial pattern matching. This paper proposes rationale-grounded in-context learning to address this by generating label-conditioned reasoning paths ("rationales") and retrieving them using a hybrid temporal-semantic similarity. The method, RationaleTS, first builds a rationale base via abducing structured observations from training samples, then uses a frozen TabPFN encoder for temporal patterns and a text-embedding model for semantic context to retrieve relevant rationales for in-context inference. Evaluated on Finance, Traffic, and Power datasets, RationaleTS achieves state-of-the-art performance, with ablation studies confirming the importance of both retrieval components and efficiency gains from using fewer tokens.

## Method Summary
RationaleTS employs a three-stage pipeline: (1) Abductive rationale generation—generate bulleted "Observation→Implication" reasoning paths from ground-truth labeled charts using GPT-5, building a rationale base; (2) Hybrid retrieval—compute temporal similarity via TabPFN on tabularized series and semantic similarity via text embeddings on chart summaries, combine with λ=0.8, and retrieve top-5 rationales; (3) In-context inference—feed query chart plus retrieved rationales to GPT-4o-mini with system prompt to produce step-by-step reasoning and final prediction. The approach is tested on multivariate time series classification tasks across Finance, Traffic, and Power datasets, showing strong gains in accuracy and efficiency over baseline methods that use raw charts or labels directly.

## Key Results
- RationaleTS achieves 69.76% F1 and 77.32% AUC on the Finance dataset, significantly outperforming GPT-5 (66.53% F1, 74.90% AUC).
- Ablation confirms both temporal and semantic retrieval components are essential; removing either degrades performance.
- RationaleTS attains higher accuracy with fewer input tokens (~25k) compared to baselines using raw charts (~160k tokens).

## Why This Works (Mechanism)
The method works by explicitly inducing structured reasoning paths from evidence to outcomes (rationales), which are then retrieved based on similarity to the query. By combining temporal embeddings (capturing pattern similarity) with semantic embeddings (capturing conceptual context), the retrieval mechanism surfaces the most relevant rationales for in-context reasoning. This explicit rationale prior allows the model to connect observations to outcomes more effectively than relying on raw pattern matching alone.

## Foundational Learning
- **TabPFN Encoder**: A frozen neural network for temporal pattern similarity. **Why needed**: Captures structural time series similarities without fine-tuning. **Quick check**: Verify fixed output dimensionality and that embeddings are stable across runs.
- **Text Embedding (text-embedding-3-large)**: Converts chart summaries and rationales to semantic vectors. **Why needed**: Enables semantic retrieval beyond raw temporal patterns. **Quick check**: Confirm cosine similarity is bounded and embeddings are dense.
- **Hybrid Similarity**: Weighted sum of temporal and semantic similarities. **Why needed**: Balances pattern matching with contextual relevance. **Quick check**: Vary λ to see impact on retrieval HitRate.
- **Rationale Structure**: Bulleted "Observation→Implication" format. **Why needed**: Provides a clear reasoning path for in-context learning. **Quick check**: Sample rationales to ensure they follow the expected structure.
- **GPT-4o-mini In-Context Prompting**: Uses retrieved rationales as examples to guide reasoning. **Why needed**: Leverages structured examples for better generalization. **Quick check**: Inspect model output for explicit reasoning citations.

## Architecture Onboarding

**Component Map**
TabPFN Encoder -> Temporal Embedding; Text Embedding -> Semantic Embedding; Hybrid Similarity -> Retrieval; GPT-5 -> Rationale Base; GPT-4o-mini -> In-Context Inference.

**Critical Path**
Training: Generate rationales → Store rationale base. Inference: Query embedding → Hybrid retrieval → Prompt GPT-4o-mini with chart + rationales → Output prediction.

**Design Tradeoffs**
- **GPT-5 vs GPT-4o-mini**: High-quality rationales (GPT-5) are crucial; using weaker models may reduce performance.
- **Temporal vs Semantic Retrieval**: Balancing λ trades off pattern matching vs contextual relevance; λ=0.8 is tuned but may not generalize.
- **Rationale Granularity**: Bulleted "Observation→Implication" paths are concise but may miss complex reasoning.

**Failure Signatures**
- **Poor rationale quality**: Vague or hallucinated observations; not temporally grounded.
- **Retrieval mismatch**: Top rationales have correct labels but irrelevant content.
- **MLLM ignores rationales**: Model defaults to chart-only reasoning despite provided examples.

**First Experiments**
1. Generate rationales for a small training subset; manually inspect for quality and structure.
2. Test hybrid retrieval on a validation set; compute HitRate for different λ values.
3. Run in-context inference on a single query; verify model outputs explicit reasoning referencing rationales.

## Open Questions the Paper Calls Out
- **Cross-domain rationale transfer**: Can rationales learned from one domain improve reasoning in another? Requires testing same rationale base on different datasets.
- **Rationale reliability**: How factually correct and complete are automatically generated rationales? Needs human evaluation.
- **Beyond classification**: Does the approach generalize to anomaly detection or multi-step forecasting? Not yet tested.
- **Optimal rationale structure**: Is the "Observation→Implication" format best, or could alternative structures improve retrieval and reasoning?

## Limitations
- **GPT-5 dependency**: Performance may degrade without access to GPT-5 for rationale generation.
- **Encoding ambiguities**: TabPFN's expected input format for multivariate, variable-length series is underspecified.
- **Retrieval sensitivity**: Fixed λ=0.8 may not generalize across domains; tuning is dataset-specific.

## Confidence
- **High**: Efficacy of three-stage pipeline, retrieval evaluation metrics, and ablation findings on similarity components.
- **Medium**: State-of-the-art claims, due to potential GPT-5 or preprocessing issues.
- **Low**: Exact TabPFN input formatting and rationale generation prompt details, as these are underspecified.
