# When Shared Knowledge Hurts: Spectral Over-Accumulation in Model Merging

## Quick Facts
- **arXiv ID:** 2602.05536
- **Source URL:** https://arxiv.org/abs/2602.05536
- **Reference count:** 40
- **Primary result:** Singular Value Calibration (SVC) fixes spectral over-accumulation in model merging via a training-free, data-free post-processing step, yielding large consistent improvements (e.g., Task Arithmetic average accuracy +13.0% on ViT-B/32 8-task: 68.9→81.9).

## Executive Summary
Naive model merging via simple weight addition repeatedly aggregates contributions from shared knowledge across tasks, inflating singular values in dominant spectral subspaces while suppressing task-specific directions. This spectral imbalance degrades performance on individual tasks. The paper introduces Singular Value Calibration (SVC), a training-free, data-free post-process that quantifies over-counting per subspace by projecting each task’s update onto the merged column-space basis, aggregates these into a calibration factor, and rescales singular values while preserving directions. SVC delivers substantial gains across vision and language benchmarks and enhances other strong baselines, achieving state-of-the-art merging with minimal overhead.

## Method Summary
SVC is applied after a base merging method (e.g., Task Arithmetic) as a layer-wise correction. For each layer, it computes the SVD of the merged task matrix ΔW_merge to obtain left singular vectors {u_r} (column-space basis) and singular values σ_r. Each individual task update ΔW^i is projected onto this basis to yield subspace responses a_r^i = (u_r)^⊤ ΔW^i. The projection coefficient s_r^i = ⟨a_r^merge, a_r^i⟩ / ‖a_r^i‖² measures how much the merged response over- or under-counts task i’s contribution in subspace r. These coefficients are aggregated into a calibration factor γ_r = K / Σ_i max(α, s_r^i), which rescales the singular values to σ̃_r = γ_r σ_r (suppressing if γ_r < 1). The corrected matrix is reconstructed as ΔW̃_merge = Σ_r σ̃_r u_r v_r^⊤ and added to the pretrained weights. The process is training-free, data-free, and operates independently per layer.

## Key Results
- SVC boosts Task Arithmetic average accuracy by 13.0% on ViT-B/32 8-task (68.9 → 81.9), and yields large gains on 8–14 vision datasets and multiple language benchmarks (BERT, T5, LLMs).
- SVC enhances strong baselines like TIES-Merge and Dare, achieving state-of-the-art merging performance with negligible computational overhead beyond one-time SVDs.
- The method consistently corrects spectral over-accumulation, particularly in top subspaces, leading to a more balanced singular value spectrum and better preservation of task-specific knowledge.

## Why This Works (Mechanism)
When multiple fine-tuned task matrices share aligned spectral directions (singular vectors), naive addition constructively aggregates their contributions along those shared subspaces. This over-counting inflates the singular values of the merged matrix in dominant subspaces, as shown by Lemma 3.2: the merged response coefficient s_r^i = 1 + Σ_{j≠i} ⟨a_r^j, a_r^i⟩ / ‖a_r^i‖² exceeds 1 when cross-task inner products are positive. The inflation concentrates in top-r subspaces with largest initial singular values, creating an imbalanced spectrum that biases the model toward shared knowledge and suppresses task-specific components residing in smaller singular directions, ultimately harming individual task performance.

The merged column-space basis {u_r} (left singular vectors of ΔW_merge) provides a common coordinate system to diagnose over-counting. Projecting each task’s update onto u_r yields a_r^i, and the ratio s_r^i = ⟨a_r^merge, a_r^i⟩ / ‖a_r^i‖² directly quantifies amplification (s_r^i > 1) or attenuation (s_r^i < 1) per subspace. Positive alignment between tasks leads to s_r^i > 1, indicating over-accumulation. Using left singular vectors is crucial because they capture the full row-wise effect on all input directions; replacing them with right singular vectors (row-space) drastically degrades performance, as confirmed by Table 3.

Inflated top singular values dominate the merged spectrum, effectively shrinking the relative influence of smaller singular values during forward passes. This spectral imbalance means subspaces carrying unique task information are underutilized, causing degraded accuracy on individual tasks. SVC counters this by rescaling σ_r toward a more balanced state via γ_r, which suppresses over-accumulated subspaces (γ_r < 1) while preserving directions. Theoretical analysis (Eq. 15) shows that when cross-terms are positive, σ_r exceeds the ideal singular value (σ_r^i)*, and calibration narrows this gap Δ = σ_r - (σ_r^i)*, especially in leading subspaces as seen in Figs. 2 and 4.

## Architecture Onboarding
**Component map (plain text flow):**  
Input (W_pre, {W_i}) → Compute base ΔW_merge (e.g., via Task Arithmetic) → For each layer: SVD(ΔW_merge) → Project all ΔW^i onto left singular vectors {u_r} to get a_r^i → Compute s_r^i = ⟨a_r^merge, a_r^i⟩ / ‖a_r^i‖² → Aggregate γ_r = K / Σ_i max(α, s_r^i) → Rescale σ_r ← γ_r σ_r → Reconstruct ΔW̃_merge → Output W_merge = W_pre + ΔW̃_merge.

**Critical path:**  
SVD of the merged matrix → project all task matrices onto the left singular vectors → compute per-task projection coefficients s_r^i → aggregate calibration factors γ_r → rescale singular values → reconstruct the corrected matrix. This is a post-hoc, layer-wise process with no data or gradient dependencies.

**Design tradeoffs:**  
- **α parameter:** Balances suppression-only (α=1) vs. potential amplification (α<1). Lower α can boost under-accumulated subspaces but risks disturbing spectral balance. Default α=1/K is safe; α=1 is most stable for pure suppression.  
- **Column-space vs. row-space:** Must use left singular vectors (u_r) as the projection basis; using right singular vectors (v_r) yields unreliable or harmful corrections.  
- **PEFT compatibility:** For 1D task vectors (e.g., IA³), SVD is undefined; a vector-form calibration (Eq. 24) uses the same projection principle on scalar directions.  
- **Computational overhead:** SVD on large matrices (e.g., LLM layers) dominates cost, but it is a one-time offline operation (Table 4).

**Failure signatures:**  
- Setting α << 1 may cause γ_r > 1, amplifying subspaces where s_r^i is small and potentially degrading performance (Fig. 5).  
- Using right singular vectors (row-space) instead of left singular vectors leads to inconsistent or detrimental corrections (Table 3).  
- Uniform aggregation in γ_r assumes equal importance of all tasks; for heterogeneous sets, per-task calibration (γ_r = 1/max(α, s_r^i)) may be preferable.  
- SVD instability on very low-rank or degenerate ΔW_merge; truncated SVD with reasonable rank mitigates this.

**First 3 experiments:**  
1. **Projection mismatch diagnosis:** For a given layer and a few subspaces r, compute s_r^i across tasks before SVC. Verify that s_r^i > 1 correlates with large σ_r and that positive cross-terms concentrate in top subspaces (replicate Fig. 3).  
2. **SVC on Task Arithmetic:** Apply SVC to a TA merge on a small subset (e.g., 3 vision tasks). Measure average accuracy gain and visualize the singular value spectrum before/after calibration to confirm top-subspace suppression and tail preservation.  
3. **Column-space ablation:** Implement the row-space variant (using v_r) and compare performance against the column-space version on at least two base methods (e.g., TA, TIES). Confirm significant drop (replicate Table 3).

## Limitations
- SVD on large weight matrices (e.g., LLMs) is computationally heavy, even as an offline step.
- Projection onto column-space assumes linear task interactions; non-linearities in the network may weaken the analysis.
- Uniform aggregation in γ_r ignores task-specific importance, possibly leading to suboptimal calibration for heterogeneous task sets.

## Confidence
- Over-accumulation exists and harms merging: **High** (theory + broad empirical evidence)
- SVC mitigates it and improves performance: **High** (consistent gains across vision/language benchmarks)
- SVC generalizes to any training-free merging method: **Medium** (validated on TA, TIES, Dare; needs more extensive validation)
