# Adaptive Batch Sizes Using Non-Euclidean Gradient Noise Scales for Stochastic Sign and Spectral Descent

## Quick Facts
- arXiv ID: 2602.03001
- Source URL: https://arxiv.org/abs/2602.03001
- Reference count: 40
- Primary result: Adaptive batch schedules using dual-norm GNS match constant-batch baselines in validation loss while reducing optimizer steps by up to 66% for Signum and Muon.

## Executive Summary
Modern deep learning often uses large constant or manually tuned batch sizes, which are brittle and reduce sample efficiency beyond the critical batch size. While adaptive batch sizes via gradient noise scale (GNS) provide a principle, existing GNS assumes Euclidean geometry, mismatching popular non-Euclidean optimizers like signSGD (ℓ∞) and specSGD (Schatten-∞). This paper derives non-Euclidean GNS metrics that naturally align with the dual norms of these optimizers: ℓ1 for sign-based updates and nuclear (S1) for spectral updates. To estimate these metrics efficiently in distributed training, they leverage local mini-batch gradients across data-parallel ranks, augmenting the AllReduce with minimal overhead. Experiments on a 160M Llama model and vision tasks show that using the geometry-correct GNS enables adaptive batch schedules that match constant-batch baselines while reducing optimizer steps by up to 66% for Signum and Muon. The method consistently preserves validation loss while significantly improving training step efficiency, demonstrating the importance of aligning batch adaptation with optimizer geometry.

## Method Summary
The authors generalize the critical batch size analysis to non-Euclidean optimizers by recognizing that the key error term in expected one-step loss improvement is measured in the optimizer's dual norm. For signSGD, this yields an ℓ1-based GNS: \(B_{\ell1} = \frac{\|\sigma\|_1^2}{\|\nabla L\|_1^2}\), where \(\sigma\) is the per-coordinate gradient standard deviation; for specSGD, a nuclear (S1) GNS: \(B_{S1} = \frac{\|C_{\text{row}}^{1/2}\|_{S1}^2}{\|\nabla L\|_{S1}^2}\), with \(C_{\text{row}}\) the row-wise covariance. To estimate these in data-parallel training, each rank computes local statistics from its mini-batch gradient: element-wise squared gradients for ℓ1, and local Gram matrices for S1. These are averaged across ranks via an additional AllReduce (or ReduceScatter in FSDP) to obtain global variance/covariance estimates. The adaptive schedule maintains exponential moving averages (EMAs) of noise (\(N_k\)) and signal (\(M_k\)) dual-norm squares, updating the batch size periodically: \(B_{k+1} = \max(N_k / (\theta^2 M_k), B_k)\), with a warm-up period and learning rate scaling \(\omega_{k+1} = \omega_k \sqrt{B_{k+1}/B_k}\). This approach aligns batch growth with the optimizer's sensitivity to noise in its native geometry.

## Key Results
- Adaptive batch sizes using ℓ1/S1 GNS match constant-batch baselines in validation loss while reducing optimizer steps by up to 66% for Signum and Muon.
- The method preserves validation performance across diverse tasks: language modeling (Llama 160M/1B) and vision (SimpleViT, ResNet-18).
- Using Euclidean (ℓ2) GNS for sign-based optimizers leads to inferior step efficiency, confirming the necessity of geometry-aligned noise scales.

## Why This Works (Mechanism)
**Mechanism 1**  
Claim: Adaptive batch sizes for sign-based and spectral optimizers require a gradient noise scale measured in the optimizer's dual norm (ℓ1 for signSGD/Signum, nuclear/S1 for specSGD/Muon), not the Euclidean (ℓ2) norm.  
Mechanism: The paper generalizes critical batch size analysis by bounding the expected dual norm of the gradient estimation error. For signSGD, the error in the update direction is bounded by the ℓ1 norm of component-wise standard deviations scaled by \(1/\sqrt{B}\); for specSGD, by the nuclear norm of row-wise covariance scaled similarly. GNS is defined as squared ratio of this error to the dual norm of the true gradient, aligning batch size with update geometry.  
Core assumption: The descent lemma holds for the primal norm (ℓ∞ or S∞), and the derived error bounds are valid approximations.  
Evidence anchors: [section 3] Derivation of ℓ1 GNS (Eq. 13) and S1 GNS (Eq. 17) from key inequality (Eq. 9). [corpus] Neighboring papers focus on Euclidean or adaptive gradient methods, indicating a gap addressed here.

**Mechanism 2**  
Claim: Non-Euclidean GNS metrics can be estimated efficiently in distributed training by leveraging local mini-batch gradients across data-parallel ranks, adding minimal overhead to AllReduce.  
Mechanism: In data-parallel training, each rank j computes local gradient \(g_j\). For ℓ1 GNS, compute per-element squares \((g_j)^2\); for S1 GNS, compute local Gram matrices \(G_j G_j^\top\). These are averaged via an additional AllReduce (or ReduceScatter in FSDP) to obtain unbiased estimators of per-coordinate variance \(\sigma^2\) and row-wise covariance \(C_{\text{row}}\). GNS is then computed as ratio of dual norm of noise estimate (\(\|\sigma\|_1\) or \(\|C_{\text{row}}^{1/2}\|_{S1}\)) to dual norm of global gradient (\(\|g\|_1\) or \(\|G\|_{S1}\)).  
Core assumption: Local mini-batch gradients are i.i.d. conditional on parameters, requiring random data partitioning and no cross-rank correlation.  
Evidence anchors: [section 4.1] Equations for \(\hat{\sigma}_k\) (Eq. 20) and \(\hat{C}_{\text{row},k}\) (Eq. 21), final computable GNS (Eq. 22). [section 4] Implementation details for DDP/FSDP hooks.

**Mechanism 3**  
Claim: Exponential moving averages (EMAs) on noise (\(N_k\)) and signal (\(M_k\)) components, combined with periodic updates and learning rate scaling proportional to \(\sqrt{B}\), stabilize the adaptive schedule and preserve validation performance.  
Mechanism: EMAs smooth stochastic fluctuations in GNS estimates. Batch size updates every F steps: \(B_{k+1} = \max(N_k / (\theta^2 M_k), B_k)\). Learning rate scales as \(\omega_{k+1} = \omega_k \sqrt{B_{k+1}/B_k}\). A warm-up period prevents early aggressive increases.  
Core assumption: EMAs track underlying signal and noise levels effectively; \(\theta\) encodes desired noise-to-signal ratio; \(\sqrt{B}\) scaling preserves update direction magnitude.

## Foundational Learning
**Concept: Dual Norms**  
Why needed: The optimizer's update direction (e.g., sign(g) for signSGD) is steepest descent in the primal norm (ℓ∞). The error in this direction is naturally measured by the dual norm (ℓ1) when bounding expected inner product with true gradient.  
Quick check: For ℓ∞ norm on \(\mathbb{R}^d\), the dual norm is ℓ1. Why? Because the dual norm \(\|x\|_* = \sup_{\|y\|\leq 1} \langle x, y \rangle = \|x\|_1\) when primal is ℓ∞.

**Concept: Gradient Noise Scale (GNS)**  
Why needed: GNS quantifies the ratio of gradient estimation error variance to squared gradient norm, defining the critical batch size where increasing batch yields diminishing returns. It's the principled metric for adaptive batch sizing.  
Quick check: How does Euclidean GNS (\(B_{\ell^2}\)) differ structurally from Manhattan (ℓ1) GNS for signSGD? Euclidean GNS uses variance summed (\(\|\sigma\|_2^2\)) over squared ℓ2 gradient; ℓ1 GNS uses sum of standard deviations (\(\|\sigma\|_1^2\)) over squared ℓ1 gradient. This reflects that signSGD is sensitive to per-coordinate noise magnitudes, not aggregate squared noise.

**Concept: Stochastic Generalized Steepest Descent**  
Why needed: Unifies SGD, signSGD, specSGD under \(x_{k+1} = x_k - \eta_k p_k\) with \(p_k = \arg\max_{\|p\|\leq 1} \langle g_k, p \rangle\). Clarifies that primal norm defines step geometry, dual norm governs noise sensitivity.  
Quick check: When \(\|\cdot\|\) is Schatten-∞ (max singular value) for matrix parameters, what update does this produce? \(p_k = \text{sign}(\text{SVD}(g_k))\) in the direction of maximal singular vectors, i.e., spectral sign descent: update = \(-\eta \text{ sign}(g_k)\) in operator sense (sign of singular values).

## Architecture Onboarding
**Component map:**  
Data-parallel backend (DDP/FSDP) -> GNS estimator module (computes local stats) -> EMA buffers (track \(N_k\), \(M_k\)) -> Batch size scheduler (updates \(B_k\), LR scaling) -> Optimizer (signSGD/Signum/specSGD/Muon). GNS estimator hooks into backend to access local gradients before AllReduce.

**Critical path:**  
1. Forward/backward pass -> compute local gradient \(g_j\).  
2. Hook before gradient AllReduce: compute local stats (\((g_j)^2\) or \(G_j G_j^\top\)).  
3. Perform standard gradient AllReduce.  
4. Perform additional AllReduce for local stats to get global averages.  
5. Compute global GNS estimate using global gradient.  
6. Update EMAs \(N_k\), \(M_k\) if step mod F = 0.  
7. Update batch size \(B_{k+1}\) and LR multiplier \(\omega_{k+1}\).  
8. Next step uses new \(B_{k+1}\) and scaled LR.

**Design tradeoffs:**  
- Memory vs accuracy: ℓ1 GNS requires storing \((g_j)^2\) (2× gradient memory). S1 GNS needs \(m \times m\) Gram matrix per GPU (O(\(m^2\)) memory); wide layers may need block approximations.  
- Update frequency (F): Small F gives responsive adaptation but higher communication and EMA noise; large F stabilizes but delays reaction.  
- \(\theta\) parameter: Smaller \(\theta\) grows batch faster but risks exceeding critical batch size, harming generalization; larger \(\theta\) slows growth.

**Failure signatures:**  
- Divergence or loss spikes: Batch grew too aggressively; check if GNS estimate is too low (underestimation due to few local samples).  
- Stagnant batch size: EMAs not rising; verify local stats computed before gradient modification (e.g., clipping) and that \(\theta\) is not too large.  
- Oscillating batch size: EMAs too sensitive (\(\beta_N\), \(\beta_M\) too low) or \(\theta\) near 1; increase \(\beta\) or decrease F.

**First 3 experiments:**  
1. Baseline replication: Train ResNet-18/CIFAR-10 with constant batch (B=256) using Signum. Establish baseline accuracy and steps. Run adaptive with ℓ1 GNS; expect similar accuracy with ≥50% fewer steps.  
2. GNS alignment ablation: Same adaptive setup but use Euclidean (ℓ2) GNS instead of ℓ1. Expect significantly worse step efficiency or final accuracy, confirming geometry alignment necessity.  
3. Overhead profiling: Measure wall-clock overhead of extra AllReduce for local stats (squared gradients/Gram matrices) on 8+ GPUs. Expect <5% step time increase.

## Open Questions the Paper Calls Out
1. How can the non-Euclidean GNS framework be extended to preconditioned and stateful optimizers (e.g., AdamW, Muon) that maintain exponential moving averages of gradients or second moments? The current derivation assumes vanilla signSGD/specSGD without memory.
2. When different parts of a model use different optimizers (e.g., 2-D parameters with specSGD/Muon and 1-D parameters with AdamW), how should the various non-Euclidean GNS metrics be combined to produce a single adaptive batch size schedule? The paper computes GNS solely from 2-D parameter groups, but no principled aggregation rule exists.
3. Can the GNS derivation be generalized beyond the quadratic loss approximation to account for arbitrary Hessian structures, and would this yield tighter critical batch size constants that improve practical schedules? The analysis relies on a quadratic model with identity Hessian; realistic loss landscapes have varying curvature.

## Limitations
- Hyperparameter sensitivity: Optimal \(\theta\), EMA decays (\(\beta\)), and warm-up schedules are task-dependent and not systematically studied.
- Implementation ambiguities: Handling of 1D parameters (biases, LayerNorm) in GNS estimation is unspecified; memory-accuracy trade-offs for S1 GNS on wide layers lack practical guidance.
- Loose theoretical bounds: Derived error bounds are acknowledged as loose, so the practical GNS metric may not perfectly reflect true critical batch size under non-i.i.d. data or correlated gradients.

## Confidence
- Core Theory (Dual-Norm GNS Derivation): Medium. Mathematical extension is sound but relies on loose constants and specific norm assumptions.
- Estimation Efficiency (Distributed Hook): Medium. Leverages standard primitives correctly, but unvalidated under model parallelism (tensor/pipeline).
- Empirical Efficacy (Step Reduction): Medium-High. Results on Llama and vision are compelling, but reproduction threatened by unspecified baseline hyperparameters.
