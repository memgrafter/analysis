# Uncovering Memorization in Timeseries Imputation models: LBRM Membership Inference and its link to attribute Leakage

## Quick Facts
- **arXiv ID**: 2603.24213
- **Source URL**: https://arxiv.org/abs/2603.24213
- **Reference count**: 26
- **Primary result**: Time series imputation models leak sensitive data via membership and attribute inference attacks. LBRM (Loss-Based Reference Model) compares target and reference model reconstruction losses using DTW, achieving AUROC up to 0.90 and TPR@top25% up to 92% vs naive (~0.5, ~40%). ## Executive Summary
Time series imputation models, which reconstruct missing values, may inadvertently memorize sensitive training data, leading to privacy leakage. This paper introduces two novel attacks: LBRM, a membership inference attack that compares a target model’s reconstruction loss to an unbiased reference model using Dynamic Time Warping (DTW); and a Continuous Wavelet Transform (CWT)-based attribute inference attack that detects whether a sensitive peak was present in a masked window. Evaluated on attention-based and autoencoder architectures across two datasets, LBRM substantially outperforms a naive loss baseline (e.g., AUROC 0.90 vs 0.5). The attribute attack achieves high recall and precision on target models. Crucially, LBRM scores computed on visible segments strongly correlate with attribute inference precision on unseen regions (correlation up to 0.71), and selecting the top 25% of series by LBRM score improves attribute inference precision by 10–15 percentage points. This demonstrates that membership leakage predicts broader structural leakage, highlighting the need for privacy-aware imputation.

## Method Summary
The paper studies privacy risks in time-series imputation via two attacks. In the membership inference attack (LBRM), a reference model trained on public data (or a different distribution) provides an unbiased estimate of reconstruction difficulty. For a given time series, a window is masked; the target and reference models reconstruct, and DTW losses are computed. The ratio of target to reference loss indicates membership: low ratios mean the target overfits. The attribute inference attack masks a contiguous window, queries the target model to reconstruct, and applies CWT across multiple scales to detect peaks that persist across scales, indicating a true peak in the original. The correlation analysis computes LBRM scores on a visible portion of each series, ranks all series, selects the top q% (e.g., 25%), and then evaluates attribute inference precision on an unseen window of those selected series, measuring both the boost and Pearson correlation.

## Key Results
- LBRM achieves AUROC up to 0.90 and TPR@top25% up to 92%, far surpassing a naive loss baseline (~0.5 and ~40%).
- CWT-based attribute inference attains recall 0.87–0.92 and precision 0.75–0.80 on target models versus evaluation models.
- LBRM scores on visible windows correlate with AIA precision on unseen windows (r up to 0.71, p<0.05); top-25% selection yields 10–15 pp precision increase.

## Why This Works (Mechanism)
### Mechanism 1: LBRM Membership Inference via Reference Model Comparison
- **Claim**: LBRM accurately identifies training set membership by comparing a target model’s reconstruction loss to that of an unbiased reference model, overcoming limitations of naive loss-based attacks.
- **Mechanism**: For a time series *x*, a window of width *U_width* is masked. The target model *T* and reference model *R* reconstruct the full series. Dynamic Time Warping (DTW) losses *LT(x)* and *LR(x)* are computed between each reconstruction and the original *x*. The ratio *R(x)=LT(x)/LR(x)* is small when *T* overfits (memorizes) because it reconstructs *x* better than *R*. Membership is inferred if *R(x) ≤ θ*, with *θ* calibrated on non-members.
- **Core assumption**: *R* has comparable imputation skill to *T* but has not seen the private data (e.g., trained on a different distribution). Thus, a systematic advantage for *T* on a sample indicates memorization.
- **Evidence anchors**:
  - [abstract] Introduces LBRM comparing target and reference model reconstruction losses using DTW, achieving AUROC up to 0.90.
  - [section 3.1] Explains that *Model R* serves as an unbiased benchmark; significant discrepancy indicates memorization.
  - [section 3.2] Details the DTW loss computation and ratio *R(x)*.
  - [corpus] The neighbor paper “A new membership inference attack that spots memorization in generative and predictive models: Loss-Based with Reference Model algorithm (LBRM)” confirms the novelty of reference-based comparison.
- **Break condition**: If *R* inadvertently memorizes the same private data (e.g., due to data overlap), the loss ratio loses discriminative power.

### Mechanism 2: Attribute Inference via Multi-Scale Peak Detection
- **Claim**: An attacker can infer the presence and location of a sensitive peak within a masked window by exploiting the target model’s reconstruction and applying Continuous Wavelet Transform (CWT) for robust peak detection.
- **Mechanism**: The adversary masks a contiguous window *W* in a partially observed series, queries the model *M* to obtain a full reconstruction *y*, and applies CWT across multiple scales on *y[W]*. Peaks that persist across scales are detected; their presence is taken as evidence of a true peak in the hidden segment.
- **Core assumption**: The imputation model has memorized local temporal structures (e.g., peaks) from training data, so its reconstruction of a masked window reflects the actual underlying pattern rather than generic smoothing.
- **Evidence anchors**:
  - [abstract] Describes the attribute attack detecting peaks via CWT, with recall 0.87–0.92 and precision 0.75–0.80.
  - [section 4.3] Outlines the three-step attack: query construction, imputation, CWT-based peak inference.
  - [section 4.4.2] Explains how CWT provides robustness by analyzing ridges across scales.
  - [corpus] Neighbors on attribute inference (e.g., “Disparate privacy vulnerability…”) show feasibility in other domains, but time-series peak detection is novel.
- **Break condition**: Strong generalization (e.g., via dropout, differential privacy) prevents the model from encoding specific peak patterns, causing reconstructions to be indistinguishable from random.

### Mechanism 3: Membership Leakage Predicts Attribute Leakage
- **Claim**: The LBRM membership score computed on the visible portion of a time series strongly correlates with attribute inference precision on its unseen portion. Thus, membership leakage signals broader structural leakage.
- **Mechanism**: For each series, compute *R(x)* on a masked window within the attacker-visible segment. Rank all series by *R(x)* and select the top *q*% (e.g., 25%). When attribute inference is later performed on a different, unseen window of those selected series, precision increases significantly (by 10–15 percentage points) compared to attacking all series.
- **Core assumption**: Memorization is not window-isolated; if a model overfits to a particular time series, it internalizes multiple temporal patterns across the sequence. Hence, an overfitting signal on one segment indicates vulnerability elsewhere.
- **Evidence anchors**:
  - [abstract] Reports correlation up to 0.71 (*p*<0.05) between LBRM scores and AIA precision, and a 10–15 pp precision boost with top-25% selection.
  - [section 4.6] Presents the correlation analysis, Table 7, and Figure 3, showing consistent gains across architectures.
  - [section 5] Concludes that LBRM identifies globally vulnerable sequences.
  - [corpus] The corpus lacks direct evidence linking MIA and AIA; this correlation is a novel contribution of the paper.
- **Break condition**: If memorization is highly localized (e.g., only specific short patterns), LBRM scores on one window may not predict leakage on others, weakening correlation.

## Foundational Learning
- **Concept: Membership Inference Attack (MIA)**
  - *Why needed*: Central attack vector; understanding its goal (determining training set membership) and typical signals (e.g., loss differences) is prerequisite.
  - *Quick check*: What distinguishes a membership inference attack from an attribute inference attack, and why are both privacy risks?

- **Concept: Time Series Imputation**
  - *Why needed*: The target models reconstruct missing values; their behavior under masking drives both attacks.
  - *Quick check*: Why might time series imputation models be more susceptible to subtle memorization than, say, image classifiers?

- **Concept: Dynamic Time Warping (DTW)**
  - *Why needed*: LBRM uses DTW to compute reconstruction losses; DTW aligns sequences non-linearly, accommodating temporal distortions.
  - *Quick check*: How does DTW’s alignment property make it preferable to pointwise MSE for comparing imputed series?

- **Concept: Continuous Wavelet Transform (CWT)**
  - *Why needed*: The attribute attack uses CWT for scale-robust peak detection within reconstructed windows.
  - *Quick check*: Why does analyzing a signal at multiple scales improve peak detection in noisy reconstructions?

## Architecture Onboarding
**Component map**: LBRM module -> Correlation module -> AIA module

**Critical path**: To reproduce core results:
1. Train target models on private data and reference models on public data (or without private samples) for SAITS, Transformer, iTransformer, and autoencoder.
2. For membership: Run LBRM and naive loss on test sets (members/non-members), compute AUROC and TPR@top25% (Tables 3–4).
3. For attribute inference: Perform sliding-window attack on target vs. evaluation models, compute per-window precision/recall (Table 6).
4. For correlation: Compute LBRM score per series on visible window, rank, select top-25%, run AIA on unseen window, compare precision (Figure 3), and compute Pearson correlation (Table 7).

**Design tradeoffs**:
- **Reference model selection**: Using a public dataset avoids data leakage but may introduce distribution shift. Using a model trained on a subset of the private data (without the test sample) gives better performance match but is less realistic.
- **Masking window size**: In LBRM, *U_width* (e.g., 48) balances capturing enough signal vs. reconstruction difficulty. In AIA, window size (e.g., 24) affects peak detection granularity.
- **DTW computational cost**: DTW is slower than pointwise losses; approximations may be needed for large datasets.
- **CWT scale choice**: The set of scales (e.g., {1..4}) impacts robustness; too narrow may miss peaks, too broad may increase false positives.

**Failure signatures**:
- LBRM AUROC ≈ 0.5 indicates no discriminative power; likely causes: reference model memorizes too, or target model is heavily regularized.
- AIA precision for target ≈ evaluation model suggests no peak memorization; could be due to insufficient training or effective privacy mechanisms.
- Near-zero correlation between LBRM scores and AIA precision contradicts the memorization linkage; may indicate experimental error or that memorization is highly localized.

**First 3 experiments**:
1. **MIA benchmark**: Replicate Tables 3 and 4. For each architecture and scenario, compute AUROC and TPR@top25% for LBRM and naive loss. Expect large improvements for LBRM.
2. **AIA validation**: Replicate Table 6. Run sliding-window attack on target and evaluation models, report average recall and precision. Expect significant gaps.
3. **Correlation demonstration**: Replicate Figure 3 and Table 7. For each architecture, compute LBRM per series, select top-25%, evaluate AIA on unseen windows, and measure precision boost. Also compute Pearson correlation between LBRM score and AIA precision.

## Open Questions the Paper Calls Out
- **Open Question 1**: Does LBRM generalize to non-attention models (e.g., LSTM, TCN) and does the MIA-AIA correlation hold for them?
- **Open Question 2**: How robust is LBRM to reference model quality and architecture mismatches?
- **Open Question 3**: Can AIA infer other sensitive structural attributes (e.g., valleys, anomalies) besides peaks, and does LBRM-based selection improve AIA for these?

## Limitations
- Missing experimental details: training hyperparameters (learning rates, optimizer, masking ratio), data extraction/normalization methods, and precise DTW/CWT implementations (e.g., CWT scales, peak detection thresholds).
- Ambiguous data splitting and the claim of "different distributions" between public and private sets when splitting the same dataset.
- Unclear definition of visible/unseen window sizes and positions in correlation analysis, hindering replication.

## Next Checks
1. **Full replication**: Reproduce all key results (Tables 3–4, 6, 7; Figure 3) using a publicly shared codebase that includes every hyperparameter, data split, preprocessing step, and attack implementation. Any deviation must be documented and explained.
2. **Reference model ablation**: Train reference models with varying degrees of distribution shift—from identical domain (disjoint data) to completely different datasets—and measure LBRM AUROC. This tests the core assumption that R must be memorization-free yet skill-comparable; degradation when R overlaps with P would confirm the break condition.
3. **AIA robustness sweep**: Systematically vary CWT scales (e.g., widths 1–8) and peak detection thresholds (prominence, distance) on both synthetic peaks (with controlled noise) and real test series. Plot precision-recall curves to verify that the reported operating point is not a cherry-picked artifact and to identify stable parameter regimes.
