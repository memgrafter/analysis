# Parameter-Efficient Domain Adaptation of Physics-Informed Self-Attention based GNNs for AC Power Flow Prediction

## Quick Facts
- **arXiv ID:** 2602.18227  
- **Source URL:** https://arxiv.org/abs/2602.18227  
- **Reference count:** 30  
- **Primary result:** LoRA-based adaptation with selective head unfreezing achieves near full fine-tuning accuracy on HV grids while reducing trainable parameters by 85.46% and maintaining physical feasibility.

## Executive Summary
This paper addresses the problem of transferring a physics-informed graph neural network (GNN) for AC power flow prediction from medium-voltage (MV) to high-voltage (HV) grids. Full fine-tuning is parameter-inefficient and offers limited control over the stability–plasticity trade-off. The authors propose a parameter-efficient domain adaptation method that applies Low-Rank Adaptation (LoRA) to the attention projections (query, key, value) of a self-attention GNN while selectively unfreezing the prediction head. Combined with a Kirchhoff consistency loss, this approach adapts to the target domain with minimal trainable parameters. Experiments across multiple grid topologies show that LoRA+PHead attains near full fine-tuning accuracy (target RMSE gap 2.6×10⁻⁴) with an 85.46% parameter reduction, while preserving physical feasibility (comparable physics residual). However, source-domain retention degrades modestly.

## Method Summary
The task is domain adaptation for AC power flow prediction: given a source model trained on MV grid data, adapt it to HV grids with limited target samples. The source model is an 8-layer edge-aware self-attention GNN with hidden dimension 8, per-head dimension 32, and 8 attention heads. Training uses a combined loss of root mean squared error (RMSE) for voltage magnitude and angle predictions and a physics residual loss L_PF that enforces Kirchhoff’s laws. The model is trained with AdamW (learning rate 1e-4, weight decay 1e-3) for 100 epochs on 90,030 MV samples.

For adaptation to HV, the base GNN weights are frozen. LoRA is applied to the query, key, and value projection matrices in each attention layer, using rank r=2 and scale α=8. Additionally, the prediction head (the final output layer) is unfrozen to allow task-specific adjustments. The same loss and optimizer are used on 45,030 HV samples. This selective fine-tuning reduces the number of trainable parameters dramatically compared to full fine-tuning, where all parameters are updated.

Evaluation metrics include target-domain RMSE (voltage magnitude and angle), physics residual L_PF, source retention R_ret (MV RMSE after adaptation relative to zero-shot), and the fraction of trainable parameters relative to full fine-tuning.

## Key Results
- LoRA+PHead achieves near full fine-tuning accuracy on HV grids with a target RMSE gap of 2.6×10⁻⁴, while reducing trainable parameters by 85.46%.
- The physics residual loss remains comparable to full fine-tuning (LPF 1.21 vs 1.11), indicating maintained physical feasibility.
- Source-domain retention drops by 4.7 percentage points (17.9% vs 22.6%), showing a modest loss of prior knowledge.

## Why This Works (Mechanism)
Parameter-efficient adaptation via LoRA and selective head unfreezing balances stability and plasticity. Freezing the base GNN preserves the rich physical inductive biases learned from the MV source domain, preventing catastrophic forgetting of fundamental power flow relationships. LoRA’s low-rank updates to the attention projections allow controlled adaptation of the model’s internal representations to the HV distribution shift, requiring minimal new parameters. Unfreezing the prediction head enables the model to adjust its output mapping to the new voltage magnitude and angle ranges typical of HV grids. The Kirchhoff consistency loss further constrains the adapted model to solutions that obey physical laws, which is crucial because HV grids have different susceptance and impedance ranges. Together, these mechanisms ensure that the model adapts effectively with a small number of trainable parameters while maintaining physical plausibility and avoiding overfitting to the limited HV data.

## Architecture Onboarding
Component map: Input (node features, edge features) -> Edge-Aware Self-Attention GNN (8 layers, each with LoRA on Q/K/V projections) -> Prediction Head (unfrozen) -> Output (voltage magnitude, angle). Physics residual loss computed from outputs and graph structure.

Critical path: Node and edge features are fed into the first GNN layer. Each layer performs edge-aware self-attention: node features are transformed via Q, K, V (with LoRA adapters), attention scores are computed, messages are aggregated, and node features are updated. The final node embeddings are passed through the prediction head to produce predictions. The loss combines RMSE and L_PF (computed using Kirchhoff’s laws from predicted voltages and network parameters).

Design tradeoffs: 
- LoRA rank: Lower rank (e.g., r=1) reduces parameters further but may limit adaptation capacity; higher rank increases capacity but also parameters. The paper uses r=2.
- Freezing base vs. head: Freezing more layers preserves source knowledge better but may limit adaptation. Unfreezing the head provides a good trade-off by allowing output mapping adjustment while keeping feature extractor stable.
- Physics loss weight λ_PF: Heavier weight enforces physical consistency but might hinder accuracy if too high. The exact value is not reported.

Failure signatures:
- High L_PF (>6) indicates the model violates physical laws, often due to insufficient adaptation capacity (e.g., LoRA-only without head unfreezing).
- In few-shot settings (β≤5%), under-adaptation appears as plateaued HV RMSE early; increasing LoRA rank or unfreezing more layers can help.
- Poor source retention (R_ret < 15%) suggests over-adaptation, possibly from too high λ_PF or unfreezing too many layers.
