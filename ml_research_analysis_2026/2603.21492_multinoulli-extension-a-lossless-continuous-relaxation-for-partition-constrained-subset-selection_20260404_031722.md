# Multinoulli Extension: A Lossless Continuous Relaxation for Partition-Constrained Subset Selection

## Quick Facts
- **ArXiv ID:** 2603.21492
- **Source URL:** https://arxiv.org/abs/2603.21492
- **Reference count:** 40
- **Primary result:** Introduces a lossless continuous relaxation (Multinoulli Extension) for partition‑constrained subset selection; Multinoulli‑SCG achieves (1‑e^‑α) or derived approximation with O(1/ε²) queries; online variants attain O(√T) regret; empirical evaluations show orders‑of‑magnitude query reduction.

## Executive Summary
Partition‑constrained subset selection arises in fair or grouped decision making, but existing methods for near‑submodular objectives suffer from high query complexity and dependence on problem parameters. This paper proposes the Multinoulli Extension (ME), a new continuous relaxation that represents each partition by a multinoulli prior. ME provides a lossless rounding scheme: for any monotone set function, sampling without replacement from these priors yields an expected objective value exactly equal to the continuous relaxation’s value. Building on this, the authors develop stochastic continuous greedy algorithms for both offline (Multinoulli‑SCG) and online (Multinoulli‑OSCG, Multinoulli‑OSGA) settings. For offline problems, Multinoulli‑SCG attains the same approximation ratios as distorted local‑search—(1‑e^‑α) for α‑weakly DR‑submodular or a derived expression for (γ,β)‑weakly submodular functions—while requiring only O(1/ε²) function evaluations, a dramatic improvement over prior O(1/ε⁶) or O(1/ε³) complexities. In online settings, the algorithms achieve O(√T) regret against the best fixed feasible solution, a first for partition‑constrained weakly submodular maximization. Experiments on video summarization, Bayesian design, and target tracking confirm that the proposed methods match or surpass state‑of‑the‑art utility while using orders of magnitude fewer queries.

## Method Summary
The core of the approach is the Multinoulli Extension (ME). For a ground set partitioned into communities {V_k} with individual budgets B_k, ME defines a continuous domain Ω = Π_k Δ^{|V_k|}, where each block corresponds to a multinoulli distribution over elements of V_k. The relaxation value F(p_1,…,p_K) is the expected set function value after rounding without replacement according to these distributions. For monotone f, rounding is lossless: E[f(S)] = F(p). Gradients and Hessians of F can be computed via expectations over sampled elements, enabling stochastic optimization.

In the offline algorithm (Multinoulli‑SCG), one starts at the zero vector and iterates T times. At each step, a stochastic gradient estimate is obtained using a path‑integrated differential estimator that samples second‑order terms. Then a discrete subset S^{(t)} is found that maximizes the linear approximation ⟨∇F(x^{(t)}), Σ_k (1/B_k)·1_{S∩V_k}⟩. The continuous point is updated by moving toward the scaled indicator of S^{(t)}. After the loop, the final continuous solution is rounded (Algorithm 1) to produce a feasible set.

For online settings, two algorithms are given. Multinoulli‑OSCG maintains Q online linear maximization oracles over Ω. At each round, each oracle outputs a direction v_t^{(q)}; the algorithm builds a candidate point by accumulating these directions, rounds to obtain S_t, observes f_t(S_t), and feeds gradient estimates back to the oracles. Multinoulli‑OSGA simplifies to stochastic gradient ascent on F or its auxiliary variant, with a projection onto Ω after each step. Both achieve O(√T) regret against the best fixed solution in hindsight, with approximation ratios matching the offline guarantees when weak‑submodularity parameters are known.

## Key Results
- **Lossless continuous relaxation:** Multinoulli Extension yields exact expectation preservation for any monotone set function under partition constraints.
- **Improved offline query complexity:** Multinoulli‑SCG attains (1‑e^‑α) or derived approximation with only O(1/ε²) function evaluations, drastically reducing complexity compared to prior O(1/ε⁶) or O(1/ε³).
- **First online regret guarantee:** Multinoulli‑OSCG and Multinoulli‑OSGA achieve O(√T) regret against the tight approximation ratios for partition‑constrained weakly submodular maximization.

## Why This Works (Mechanism)
The Multinoulli Extension framework provides a lossless continuous relaxation by representing each partition V_k with a multinoulli prior p_k ∈ Δ^{|V_k|}. The rounding procedure (Algorithm 1) draws exactly B_k elements without replacement from the distribution defined by p_k, ensuring that the expected value of the selected subset equals F(p_1,…,p_K) for any set function f, provided f is monotone. This property holds regardless of submodularity; the relaxation itself does not introduce any gap.

For offline optimization, Multinoulli‑SCG uses a stochastic continuous greedy method. A key component is the path‑integrated differential estimator, which estimates the gradient of F by sampling pairwise second‑order terms and requires only O(1/ε²) evaluations to achieve an ε‑additive approximation relative to the continuous optimum. The algorithm iteratively selects a discrete direction S^{(t)} that maximizes the linearized objective, updates the continuous point by moving toward the indicator of S^{(t)}, and finally rounds. The combination of a lossless relaxation and a careful greedy update preserves the (1‑e^‑α) or derived approximation guarantee while avoiding the high query costs of prior distorted local‑search methods.

In online settings, the algorithms maintain O(√T) regret by mimicking the continuous greedy updates in an online fashion. Multinoulli‑OSCG employs Q linear maximization oracles that act as meta‑actions; each oracle’s output contributes to constructing the next point. Feedback from observed losses updates all oracles, yielding a no‑regret guarantee. Multinoulli‑OSGA takes a simpler approach via stochastic gradient descent on the ME (or its auxiliary variant) with projection. Both approaches rely on the weak‑submodularity of f_t and the online learning guarantees of the underlying oracles. The use of an auxiliary gradient with a weighting function can tighten the approximation ratio but requires knowledge of the weak‑submodularity parameters.

## Architecture Onboarding
### Component Map
Inputs (ground set V, partition {V_k}, budgets {B_k}, set function f or sequence {f_t}) → Multinoulli Extension F (Definition 1) → Stochastic gradient estimator (path‑integrated differential) → Update rule: continuous greedy (offline) / meta‑action oracles (online) / gradient ascent (OSGA) → Rounding without replacement (Algorithm 1) → Selected subset S (offline) or online subsets {S_t} with feedback to oracles.

### Critical Path
**Offline (Multinoulli‑SCG):**  
1. Initialize x^{(1)} = 0.  
2. For t = 1 to T:  
   a. Estimate gradient g^{(t)} at x^{(t)} using L second‑order samples.  
   b. Find discrete subset S^{(t)} maximizing ⟨g^{(t)}, Σ_k (1/B_k)·1_{S∩V_k}⟩.  
   c. Update x^{(t+1)} = x^{(t)} + (1/T)·(Σ_k (1/B_k)·1_{S^{(t)}∩V_k}).  
3. Round x^{(T+1)} via Algorithm 1 (multiple attempts) to obtain final set.

**Online (Multinoulli‑OSCG):**  
- Maintain Q linear maximization oracles E^{(q)} over Ω.  
- For each time t:  
  * Obtain directions v_t^{(q)} from each oracle.  
  * Build candidate x_t^{(q+1)} = x_t^{(q)} + (1/Q)·v_t^{(q)}.  
  * Round x_t^{(Q+1)} to select S_t.  
  * Observe f_t(S_t) and compute gradient estimate g_t.  
  * Feed g_t to all oracles for updates.  

**Online (Multinoulli‑OSGA):**  
- Initialize x_1 ∈ Ω.  
- For each t:  
  * Compute (auxiliary) gradient estimate g_t of F (or F^a) at x_t.  
  * Update x_{t+1} = argmin_{x∈Ω} ||x_t + η g_t - x||^2.  
  * Round x_t to select S_t.

### Design Tradeoffs
- **Multinoulli‑SCG:** Superior query complexity O(1/ε²) but needs Hessian estimation (O(nr) storage) and projection onto a product of simplices (potentially costly QP). Memory scales with nr, limiting large‑scale use.
- **Multinoulli‑OSCG:** Uses Q linear oracles, incringing O(Q·r) memory. Oracle regret O(√{nrT}) but total queries can be high (O(r n² T²)). More flexible with weak‑submodularity parameters.
- **Multinoulli‑OSGA:** Simplest per‑iteration cost, no oracles. Without auxiliary gradient, ratio weaker (α²/(1+α²)). Auxiliary variant requires α or (γ,β) to set weight w(z), breaking parameter‑free claim. Step‑size η trades off regret (O(r/η + nTη)).

### Failure Signatures
- **High gradient variance:** Batch size L too small → noisy gradient estimates. Monitor ‖g_t - ∇F(x_t)‖ and increase L.
- **Projection bottleneck:** Large partition sizes make projection onto Π_k Δ^{|V_k|} slow; prefer independent per‑partition Euclidean projections.
- **Assumption violation:** If f is not weakly submodular, approximation guarantees fail. Compute empirical submodularity ratios to detect.
- **Rounding errors:** Incorrect Algorithm 1 (e.g., sampling with replacement, not filling complements) causes budget violations and biased value.
- **Online non‑stationarity:** Drift in f_t beyond weak‑submodularity can cause regret to exceed O(√T); consider adaptive step sizes or tracking.

### First Experiments
1. **Video summarization** (Section VII‑A1): Against greedy and distorted local search on DPP objectives with partition constraints (1 frame per 25). Multinoulli methods achieve top‑2 utility with 2–4 orders of magnitude fewer queries.
2. **Coverage maximization** (Section VII‑A2): On a submodular coverage instance where standard greedy stalls at 1/2‑approximation, Multinoulli‑SCG recovers the optimum, confirming Theorem 3 tightness (α=β=γ=1).
3. **Bayesian A‑optimal design** (Section VII‑A3): On UCI datasets (Housing, Ionosphere, etc.) partitioned into 10 groups, Multinoulli‑SCG/SGA outperform baselines in utility while using far fewer queries, demonstrating effectiveness on weakly submodular objectives.

## Limitations
- Lossless rounding guarantee holds only for monotone functions; non‑monotone may break expectation preservation.
- Approximation guarantees rely on f being α‑weakly DR‑submodular or (γ,β)‑weakly submodular; these parameters may be unknown and the properties may not hold in practice.
- Gradient estimator variance can necessitate large batch sizes L, affecting efficiency in high‑dimensional settings.
- Projection onto the product of simplices can become computationally expensive for large partitions.
- Online algorithms need weak‑submodularity parameters (α, γ, β) for tight ratios; obtaining them is non‑trivial.
