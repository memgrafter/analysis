# SKILL0: In-Context Agentic Reinforcement Learning for Skill Internalization

## Quick Facts
- **ArXiv ID:** 2604.02268
- **Source URL:** https://arxiv.org/abs/2604.02268
- **Reference count:** 40
- **Primary result:** Achieves 87.9% success on ALFWorld (+9.7% over AgentOCR) and 40.8% accuracy on Search-QA (+6.6%), while using <0.5k tokens per step at inference without skill retrieval.

## Executive Summary
SKILL0 addresses the limitations of inference-time skill augmentation—such as retrieval noise, token overhead, and lack of true skill acquisition—by internalizing skills into the model parameters. It introduces an in-context reinforcement learning (ICRL) framework that provides skills as visual context during training but removes them entirely at inference, forcing the policy to transfer skill knowledge into its weights. A dynamic curriculum prunes skills based on their on-policy helpfulness, gradually reducing the skill budget to zero. Skills and interaction history are rendered as compact images, and a self-generated compression ratio further reduces token cost. On ALFWorld and Search-QA, SKILL0 significantly outperforms skill-augmented baselines while achieving low token usage, demonstrating effective zero-shot autonomous behavior.

## Method Summary
SKILL0 uses a pre-trained vision-language model (Qwen2.5-VL-3B/7B). It maintains a SkillBank of markdown skill files categorized by task type. At each training step, the Dynamic Curriculum Manager selects a subset of skills based on a current budget. The Visual Renderer converts the interaction history and selected skills into a single RGB image using semantic color coding. The policy network processes this image to produce both an action and a compression ratio. The environment returns a task reward; a composite reward adds λ·ln(compression) on success to encourage higher compression. Training employs PPO with KL divergence penalty to a reference model for stability. Every d steps, the curriculum re-evaluates each skill’s helpfulness (∆k) on a dedicated validation sub-task, discards those with non-positive ∆k, ranks the rest, and selects the top M(s) skills. The skill budget M(s) decays linearly across three stages from all skills down to zero, thus transitioning the policy from context-dependent execution to fully internalized, zero‑shot operation.

## Key Results
- On ALFWorld with Qwen2.5‑VL‑3B, SKILL0 reaches 87.9% success, improving over AgentOCR by 9.7 percentage points.
- On Search‑QA, SKILL0 achieves 40.8% accuracy, a 6.6 percentage point gain.
- Inference uses less than 0.5k tokens per step, matching or exceeding the performance of skill‑augmented baselines without requiring any retrieval overhead.

## Why This Works (Mechanism)

### Mechanism 1: In‑Context Reinforcement Learning (ICRL) Drives Internalization
**Claim:** ICRL internalizes skills by forcing the policy to rely on in‑context skill guidance during training while removing it at inference.
**Mechanism:** The agent is trained with skills provided in its visual context, and the RL objective optimizes actions based on this augmented context. As the curriculum systematically withdraws skills, the policy must eventually produce correct actions without them, thereby transferring skill knowledge into its parameters.
**Core assumption:** Reinforcement learning can consolidate context‑dependent behavior into parametric knowledge if the context is removed during later training stages.
**Evidence anchors:**
- Abstract states: “skills are provided as in‑context guidance during training rollouts but removed entirely at inference, so that RL optimization directly drives the transition from context‑dependent execution to autonomous behavior.”
- Section 3.2 details the ICRL training loop where skills are present during rollout but the curriculum withdraws them.
**Break condition:** If performance drops sharply when skills are removed at inference, internalization failed; the model may have learned to ignore skills or overfit to their presence.

### Mechanism 2: Dynamic Curriculum Prunes Unhelpful Skills
**Claim:** A dynamic curriculum that prunes skills based on on‑policy helpfulness ensures only beneficial skills remain, preventing noise and encouraging true internalization.
**Mechanism:** Every d steps, the system evaluates each skill’s helpfulness ∆k (accuracy with skill minus without) on a dedicated validation sub‑task. Skills with ∆k ≤ 0 are discarded. Remaining skills are ranked by ∆k, and only the top M(s) are retained for the next curriculum stage, where M(s) linearly decays to zero.
**Core assumption:** A skill’s validation helpfulness ∆k is a reliable predictor of its training utility for the current policy; removing unhelpful skills reduces context noise and forces learning of the residual knowledge.
**Evidence anchors:**
- Abstract: “Dynamic Curriculum then evaluates each skill file’s on‑policy helpfulness, retaining only those from which the current policy still benefits within a linearly decaying budget.”
- Section 3.3 and Algorithm 1 formalize the filter, rank, select steps.
- Section 4.3, Figure 6 shows that ∆k rises then falls, indicating skills become less needed as internalization progresses.
**Break condition:** If ∆k is unstable or misaligned with actual task performance (e.g., a skill seems helpful in validation but harms training), the curriculum may prematurely discard useful skills or retain harmful ones.

### Mechanism 3: Visual Rendering with Self‑Generated Compression Minimizes Token Cost
**Claim:** Rendering text history and skills into a compact visual context, with a self‑generated compression ratio, drastically reduces token overhead while preserving necessary structural information for decision‑making.
**Mechanism:** The textual context is rendered into an RGB image. A vision encoder compresses this image into visual tokens V_t. The policy jointly outputs an action a_t and a compression ratio c_t ≥ 1.0. A composite reward r_comp = ln(c_t) on success incentivizes higher compression. Decoding cost is thus bounded by image size, not text length.
**Core assumption:** A vision encoder can effectively parse rendered text layouts to extract semantic and structural information needed for policy learning, and that compression can be dynamically optimized without critical information loss.
**Evidence anchors:**
- Section 3.1: “Context Rendering… maps the textual interaction context… to a compact RGB image… significantly reducing token overhead while preserving the structural information.”
- Section 4.2, Table 1 shows SKILL0 uses <0.5k tokens/step vs. 2.21k for SkillRL.
**Break condition:** If the rendered image loses critical information or the compression head outputs near‑constant 1.0, efficiency gains vanish or performance degrades.

## Architecture Onboarding
**Component map:** SkillBank -> Visual Renderer -> Policy Network (Qwen‑VL) -> RL Trainer; Dynamic Curriculum Manager sits alongside and periodically updates the active skill subset fed into Renderer.

**Critical path:**
1. Curriculum Manager selects current skill subset S(s) based on budget.
2. For each query: Visual Renderer converts interaction history h_t and S(s) into image V_t.
3. Policy Network takes V_t and outputs (action a_t, compression ratio c_t).
4. Environment returns reward r_t; composite reward r̃ = r_t + λ·ln(c_t) on success.
5. After a group of rollouts, RL Trainer computes advantages and updates policy via PPO.
6. Every d steps, Curriculum re‑evaluates skills’ helpfulness ∆k and updates S(s) for next stage.

**Design tradeoffs:**
- Compression ratio vs. fidelity: Higher c_t lowers token cost but may obscure text; reward ln(c_t) on success balances this.
- Curriculum stage granularity: More stages (higher N_S) gives smoother transition but higher validation overhead.
- Validation sample size: Smaller d gives more responsive curriculum but costs more compute; paper uses d=10.

**Failure signatures:**
- Skill collapse: Validation accuracy without skill remains low or drops while with skill stays high → internalization failed.
- Compression collapse: Model outputs c_t≈1.0 always → fails to reduce token cost.
- Curriculum instability: Active skill set changes wildly between evaluations → ∆k noisy or validation set unrepresentative.

**First 3 experiments:**
1. **Visual rendering sanity check**: Compare policy performance using rendered visual context vs. raw text context (same skills) to confirm vision encoder effectively extracts information.
2. **Curriculum ablation**: Run with Fixed Full (all skills always), [6,6,6] (slow decay), [0,0,0] (no skills ever) vs. proposed [6,3,0]; measure skill‑free inference performance.
3. **Helpfulness monitoring**: Plot ∆k for each sub‑task during training; expect a rise‑then‑fall pattern as skills get internalized (replicating Figure 6).

## Open Questions the Paper Calls Out
- **Automate SkillBank creation and grouping for new domains.** Manual process limits scalability; an unsupervised pipeline to discover and cluster skills from raw data is needed.
- **Replace fixed linear curriculum with an adaptive, on‑policy withdrawal schedule.** The static schedule may misalign with agent learning; a controller adjusting budget based on performance could yield gains.
- **Does visual compression discard essential skill information and what is the optimal ratio?** Compression trade‑off is unexplored; ablations across skill complexities are required to identify degradation thresholds.

## Limitations
- SkillBank contents and validation sub‑task splits are not released, hindering exact replication.
- PPO hyperparameters (e.g., clip ϵ, KL penalty β, learning rate) and vision encoder compression implementation details are unspecified and require tuning.
- Evaluation is limited to ALFWorld and Search‑QA with Qwen2.5‑VL; generalization to other models or tasks remains unknown.
- The helpfulness metric ∆k may be noisy with small validation sets, risking premature skill discarding.
- Token count measurements rely on rendered image encoding; actual inference cost depends on implementation choices not fully detailed.

## Confidence
- ICRL internalization: **Medium** (plausible from design but lacks direct ablation)
- Dynamic curriculum: **High** (algorithm clearly described and ablations confirm benefit)
- Visual compression: **Medium** (efficiency demonstrated but fidelity at extreme compression not fully characterized)
- Overall zero‑shot performance: **High** (strong empirical gains despite reproducibility constraints)

## Next Checks
1. **Curriculum ablation**: Train with static skill budgets (always‑all, fixed linear decay) and compare zero‑shot success to dynamic curriculum.
2. **Compression fidelity test**: Render visual context at varying resolutions and forced compression ratios; measure token count and task success to verify the claimed <0.5k tokens/step without significant accuracy loss.
3. **Skill internalization proof**: After training, evaluate the policy on held‑out tasks both with and without skill context; a small performance gap (e.g., <2%) confirms successful knowledge transfer.
