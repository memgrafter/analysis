# Out of Sight but Not Out of Mind: Hybrid Memory for Dynamic Video World Models

## Quick Facts
- **ArXiv ID:** 2603.25716  
- **Source URL:** https://arxiv.org/abs/2603.25716  
- **Reference count:** 40  
- **Primary result:** HyDRA significantly improves video generation consistency for dynamic subjects that exit and re-enter the frame, achieving PSNR 20.357, SSIM 0.606, and DSCGT 0.849 on HM-World, and outperforms WorldPlay by PSNR +5.502.

## Executive Summary
Video world models often fail to maintain consistency for dynamic subjects that leave and later re-enter the camera frame, resulting in frozen or distorted appearances. This paper introduces the Hybrid Memory paradigm, which requires models to simultaneously act as precise archivists for static backgrounds and vigilant trackers for dynamic subjects. The authors present HM-World, a dataset of 59K clips with deliberate exit-entry events, and propose HyDRA, a memory architecture featuring a 3D-convolution-based memory tokenizer and a spatiotemporal affinity-driven retrieval mechanism. HyDRA yields large gains over state-of-the-art methods on HM-World: PSNR rises from 18.696 to 20.357, SSIM from 0.517 to 0.606, and it achieves the highest scores on the proposed Dynamic Subject Consistency metrics (DSCctx 0.827, DSCGT 0.849). It also surpasses the commercial model WorldPlay by a substantial margin (PSNR +5.502).

## Method Summary
HyDRA extends a video diffusion transformer (Wan2.1-T2V-1.3B) with three core components. First, a camera encoder (MLP) injects camera trajectory conditions into latent features. Second, a memory tokenizer compresses context frame latents into compact tokens using a 3D convolution (kernel 2×4×4), capturing spatiotemporal patterns including long-duration motion. Third, the standard self-attention in DiT blocks is replaced by Dynamic Retrieval Attention: for each target query, it computes spatiotemporal affinity with memory tokens, selects the top-K most relevant tokens, and concatenates them with a local window of keys/values for attention. Training uses Flow Matching with an L2 loss for 10K iterations on 32 GPUs (batch size 32). The method specifically decouples static background preservation (handled by the base model’s context) and dynamic subject tracking (handled by retrieval-augmented attention). Evaluation on HM-World employs PSNR, SSIM, LPIPS, and the DSC metrics.

## Key Results
- PSNR improved from 18.696 to 20.357, SSIM from 0.517 to 0.606 over the baseline.
- Achieves the highest Dynamic Subject Consistency scores: DSCctx 0.827 and DSCGT 0.849.
- Outperforms the commercial model WorldPlay by a large margin (PSNR +5.502).

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The 3D-convolution-based memory tokenizer creates motion-aware representations by performing spatiotemporal interaction on latent memories before retrieval, which is critical for tracking hidden dynamic subjects.
- **Mechanism:** The Memory Tokenizer (T_mem) applies a 3D convolution (kernel T×H×W) to raw memory latents (Z_mem), producing compressed tokens (M) with an expanded spatiotemporal receptive field. This allows the tokens to encode long-duration motion information rather than just static or frame-wise features.
- **Core assumption:** Standard latent representations are insufficient for disambiguating a subject's reappearance after an out-of-view interval because they entangle static background with dynamic subject motion. Explicit spatiotemporal processing in the tokenizer separates these cues.
- **Evidence anchors:**
  - [abstract] "...compresses memory into tokens and utilizes a spatiotemporal relevance-driven retrieval mechanism."
  - [section 4.2] "By employing 3D convolutions, the tokenizer expands the spatiotemporal receptive field to capture long-duration motion information... This enriched representation is crucial for optimizing the retrieval process and ensuring consistent generation."
  - [section 5.3, Table 4] Reducing the temporal kernel dimension from T=2 to T=1 causes a significant PSNR drop (~1.3) and DSCGT drop (~0.014), demonstrating the necessity of temporal interaction for performance.
  - [corpus] Corpus evidence is weak; neighboring papers address memory or video consistency but do not validate this specific 3D tokenization design for hybrid memory.
- **Break condition:** If the dynamic subject's motion during the out-of-view period is highly complex (e.g., non-linear, occluded by other objects), the tokenizer's fixed receptive field may fail to compress the correct motion state, leading to retrieval of irrelevant cues and distorted re-entry.

### Mechanism 2
- **Claim:** The spatiotemporal affinity-driven retrieval mechanism (Dynamic Retrieval Attention) selectively attends to the most relevant historical motion cues for each specific target frame, preventing noise from irrelevant memory tokens from degrading generation.
- **Mechanism:** For each target query (q_i), the method computes affinity (S_i,j) with every temporal slice of memory tokens (k_mem,j) via spatial pooling and channel-wise inner product. It then selects Top-K tokens with highest affinity. These are concatenated with a local window from the target sequence for final attention.
- **Core assumption:** A static, geometry-based (e.g., Field-of-View overlap) memory filtering is insufficient because it does not account for feature-level similarity and cannot adapt to the specific denoising needs of each frame. Dynamic affinity computes a fine-grained, data-driven relevance score.
- **Evidence anchors:**
  - [section 4.3] "We compute a spatiotemporal affinity metric... Based on these affinities, we employ a Top-K selection strategy..."
  - [section 5.3, Table 6] Dynamic affinity outperforms FOV overlap retrieval across all metrics (e.g., Subject Consistency 0.926 vs 0.908).
  - [supplementary A.2, Fig. 3 & 4] FOV overlap selects a fixed, often incorrect set of memory frames (empty shots), while dynamic affinity selects diverse, subject-containing frames at different timesteps/layers.
  - [corpus] Corpus shows related work on memory retrieval (e.g., Context-as-Memory [37] uses FOV overlap), but no direct evidence for this specific dynamic affinity formulation.
- **Break condition:** If the visual appearance of the dynamic subject changes drastically between the out-of-view and re-entry phases (e.g., lighting change, partial occlusion during exit), the feature affinity might degrade, causing mismatched retrieval and inconsistent reappearance.

### Mechanism 3
- **Claim:** The Hybrid Memory paradigm (requiring simultaneous static background consistency and dynamic subject motion continuity) is addressed by decoupling the memory processing: static areas are preserved via the base model's context, while dynamic subjects are managed by the retrieval-augmented attention.
- **Mechanism:** The architecture does not explicitly segment static vs. dynamic pixels. Instead, the Dynamic Retrieval Attention module is applied within the DiT blocks, allowing it to *selectively* pull in historical cues for regions where motion continuity is needed (i.e., where a dynamic subject might reappear). The base model's inherent capacity handles static regions without heavy retrieval.
- **Core assumption:** The model's self-attention layers can inherently maintain static consistency if provided sufficient context frames. The primary challenge is augmenting this process with targeted, motion-specific memory for dynamic entities that exit the frame.
- **Evidence anchors:**
  - [abstract] "Hybrid Memory... requires models to simultaneously act as precise archivists for static backgrounds and vigilant trackers for dynamic subjects."
  - [section 3.1] "Hybrid memory... requires the model to simultaneously anchor the static background while tracking the dynamic subjects... reappear at a plausible location with a consistent motion state."
  - [section 5.2, Table 2 & 3] HyDRA achieves high Background Consistency (0.932) *and* the best DSC scores (0.827/0.849), indicating success on both static and dynamic fronts.
  - [corpus] Corpus contains papers on static scene consistency (e.g., RELIC [11]) and separate dynamic tracking, but the specific "hybrid" formulation is novel per paper claims.
- **Break condition:** If multiple dynamic subjects (≥3) with intersecting, complex trajectories exit and re-enter simultaneously, the Top-K retrieval may not allocate enough capacity to all subjects, causing some to be forgotten or incorrectly merged.

## Foundational Learning

- **Concept: Spatiotemporal Decoupling**  
  - **Why needed here:** Hybrid Memory fundamentally requires the model to separate the camera's ego-motion (which changes the background view) from the independent subject trajectory (which must persist unchanged in world coordinates). Without this, a subject re-entering from a different camera angle would be perceived as a new, inconsistent object.  
  - **Quick check question:** Given a context frame sequence and camera poses, how would you mathematically define the world-coordinate position of a subject at frame *t* if its last observed pixel position was at frame *k*?

- **Concept: Memory Compression & Retrieval**  
  - **Why needed here:** Processing entire historical video frames at every generation step is computationally infeasible and introduces noise. The paper uses a tokenizer to compress and a Top-K affinity search to retrieve. Understanding this trade-off between information completeness and noise filtering is key.  
  - **Quick check question:** What are the risks of setting the retrieved token count (K) too low vs. too high in the Dynamic Retrieval Attention?

- **Concept: Diffusion Transformer (DiT) with Modified Attention**  
  - **Why needed here:** HyDRA is built as a modification to a standard DiT-based video diffusion model. The engineer must understand the base architecture (causal VAE, Flow Matching, DiT blocks) to correctly insert the custom Dynamic Retrieval Attention and projector modules.  
  - **Quick check question:** In a standard DiT block, what are the inputs/outputs of the self-attention layer? How does HyDRA's Dynamic Retrieval Attention change this input structure?

## Architecture Onboarding

- **Component map:**  
  1. **Input:** Context frames (X_ctx), Camera trajectory for context & target (P={P_ctx, P_tgt}), Noisy target latents (z_t).  
  2. **Base Backbone:** 3D VAE (encoder/decoder) + Diffusion Transformer (DiT) with N blocks. Each block has Cross-Attention (for text?), FFN, and *replaces* standard Self-Attention with Dynamic Retrieval Attention.  
  3. **Camera Injection:** Camera Encoder (MLP) processes c_cam → broadcast/spatially added to latent features (Eq. 2).  
  4. **Memory Path:** Context latents from VAE encoder → Memory Tokenizer (3D Conv) → Memory Tokens (M).  
  5. **Dynamic Retrieval Attention (per DiT block):** Target latent query (q_i) → spatial downsample → compute affinity with all M time slices → Top-K select (K_sel, V_sel) → concat with local window (K_loc, V_loc) → standard attention (Eq. 6).  
  6. **Output:** Predicted velocity (v_t) → integrate → clean latent → VAE decode → X_tgt.

- **Critical path:** The most crucial path for hybrid memory is: **Context Frames → VAE Encoder → Memory Tokenizer (3D Conv) → Memory Tokens (M) → (During target frame denoising) Dynamic Retrieval Attention (using M) → Modified DiT output**. Failure here directly causes subject inconsistency.

- **Design tradeoffs:**  
  - *Tokenizer Kernel (T×H×W):* Larger H/W captures finer spatial details but increases token count/compute. Larger T captures longer motion but risks over-smoothing. [Table 4] shows T=1 (no temporal conv) catastrophically fails; spatial size is robust.  
  - *Retrieved Token Count (K):* Too few (K<10) loses critical cues; too many (K>15) may add noise/compute without benefit. [Table 5] shows stability between 10-15.  
  - *Local Window Size:* Included to maintain local coherence. Too small may lose structural integrity; too large may reduce the relative impact of retrieved global memory. Paper sets to 5.

- **Failure signatures:**  
  - **Subject freezing/distortion after re-entry:** Likely cause: Memory Tokenizer temporal kernel too small (T=1) or retrieved token count too low (K=5) → insufficient motion info retrieved.  
  - **Hallucinated extra subjects:** Likely cause: Dynamic affinity retrieving tokens from wrong temporal slices (e.g., from another subject's trajectory) due to appearance similarity.  
  - **Static background becomes inconsistent:** Likely cause: Base model capacity overwhelmed; camera injection may be insufficient, or memory retrieval is interfering with static processing (retrieval is not selective enough).  
  - **Complete subject vanishing:** Likely cause: Affinity computation fails to assign any significant score to tokens containing the subject (e.g., subject was too small or motion too subtle in context).

- **First 3 experiments:**  
  1. **Ablation: Tokenizer Temporal Kernel.** Train three models with T=1, T=2 (ours), T=3. Evaluate on HM-World test set with DSCGT and PSNR. Expected: T=1 fails significantly; T=2 & T=3 similar, confirming need for >1 temporal interaction.  
  2. **Ablation: Retrieval Method.** Compare Dynamic Affinity vs. FOV Overlap vs. Random Retrieval (baseline). Use same token count K=10. Expected: Dynamic > FOV > Random on DSC metrics. Visual inspection should show FOV selecting empty/irrelevant frames.  
  3. **Qualitative Stress Test.** Generate videos with 2-3 subjects exiting/re-entering in overlapping patterns. Compare HyDRA (K=10) vs. Baseline (no retrieval). Expected: Baseline shows frozen/distorted subjects; HyDRA maintains consistency for all subjects if K is sufficient.

## Open Questions the Paper Calls Out

1. How can hybrid memory models be made robust to multiple dynamic subjects and severe occlusions during out-of-view intervals?
2. How can hybrid memory models generalize to unconstrained real-world video without relying on synthetic datasets and known camera poses?
3. Does the synthetic nature of HM-World limit the transferability of hybrid memory models to real-world dynamics, and how can this domain gap be bridged?
4. Can the dynamic retrieval attention mechanism be made adaptive, for instance by learning the number of retrieved tokens or the local context window, to handle varying scene complexities?
5. How can future world models explicitly decouple camera ego-motion from independent subject trajectories to improve hybrid memory performance?
