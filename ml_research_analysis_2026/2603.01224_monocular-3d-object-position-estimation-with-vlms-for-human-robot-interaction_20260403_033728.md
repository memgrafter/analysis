# Monocular 3D Object Position Estimation with VLMs for Human-Robot Interaction

## Quick Facts
*   **arXiv ID**: 2603.01224
*   **Source URL**: https://arxiv.org/abs/2603.01224
*   **Reference Count**: 16
*   **Primary Result**: Fine-tuned LLaVA-v1.5 achieves a median 3D position MAE of 13 mm, a five-fold improvement over a non-finetuned VLM baseline.

## Executive Summary
This work addresses the lack of Vision-Language Models (VLMs) capable of monocular 3D object position estimation, a key requirement for human-robot interaction. The authors fine-tune the LLaVA-v1.5 (7B) model using QLoRA, introducing a custom regression head and a conditional routing mechanism. This approach aims to specialize the model for precise 3D coordinate prediction from a single wrist-mounted camera image while preserving its broader visual and language understanding capabilities. The model is trained on a large, heterogeneous dataset collected from a real Doosan robot arm. Results show significant accuracy improvements, with a median absolute error of 13 mm per coordinate, suggesting viability for robotic manipulation tasks like grasping.

## Method Summary
The core method involves parameter-efficient fine-tuning of the LLaVA-v1.5-7B model. A custom regression head is added to the vision encoder's output to predict 3D object coordinates. To prevent catastrophic forgetting of the VLM's general capabilities, a conditional routing mechanism is employed, which dynamically selects whether to use the existing vision-language projection layers or route activations directly to the new regression head. Training uses the QLoRA technique for efficiency on a dataset exceeding 100,000 images captured by a wrist-mounted camera on a Doosan robot arm. The dataset features varied objects and lighting conditions, with ground-truth 3D positions derived from the robot's forward kinematics and known object geometry.

## Key Results
*   Median per-coordinate absolute error (MAE) on the test set is **13 mm**.
*   Median Euclidean distance error is **27 mm**.
*   Approximately **25%** of predictions achieve a per-coordinate error within 10 mm, a threshold considered acceptable for robotic grasping or pushing.

## Why This Works (Mechanism)
The conditional routing mechanism allows the model to specialize for the 3D regression task without severely degrading its pre-trained vision-language representations. By learning to route activations away from the standard VLM projection layers when specific visual features for 3D geometry are detected, the model preserves general interpretive abilities while developing a dedicated pathway for metric spatial prediction. Fine-tuning the entire model (via QLoRA) on a large, real-world robotic dataset calibrates these pathways to the specific camera intrinsics, robot morphology, and object distributions present in the training data.

## Architecture Onboarding
**Component Map**: Input Image -> Pre-trained Visual Encoder (CLIP-ViT) -> [Conditional Router] -> (Path A: Standard Projection Layers -> Language Model Backbone) OR (Path B: Custom Regression Head) -> 3D Coordinate Output

**Critical Path**: The conditional router's decision point is critical. Its activation determines whether the visual features follow the standard VLM processing path (Path A) or are diverted to the specialized regression pathway (Path B) to produce the final 3D coordinates.

**Design Tradeoffs**:
1.  *Specialization vs. Generality*: The routing mechanism trades off some peak 3D accuracy to maintain broader VLM capabilities. A simpler single-regression-head model might achieve higher 3D accuracy but would likely forget pretrained knowledge.
2.  *Routing Complexity vs. Overfitting*: Introducing a learned router adds parameters and complexity. An overly complex router could overfit to the specific dataset's visual patterns and camera-object distributions, harming generalization.
3.  *Data Source Fidelity*: Using robot kinematics and known object models for ground truth is efficient but may propagate small model or calibration errors into the training labels, creating a ceiling on achievable performance.

**Failure Signatures**:
1.  **Router Misclassification**: The model consistently uses the standard VLM path (Path A) for images containing target objects, outputting language or classification tokens instead of coordinates.
2.  **General Capability Degradation**: Post-fine-tuning, the model fails at basic VQA or captioning tasks it previously handled, indicating catastrophic forgetting despite the routing mechanism.
3.  **Object-Category Failure**: Errors spike dramatically for object categories visually or geometrically distinct from the training set (e.g., very small, reflective, or transparent objects).

**First Three Experiments**:
1.  **Router Ablation**: Train a version without the conditional router (all features forced through the regression head) and compare 3D accuracy and performance on a held-out VQA benchmark against the proposed model.
2.  **Cross-Platform Zero-Shot Test**: Evaluate the model trained *only* on Doosan wrist-camera data on images from a fundamentally different setup (e.g., a fixed-base robot with a ceiling-mounted camera), measuring error degradation.
3.  **Routing Activation Visualization**: For a sample of test images, extract and visualize the router's activation scores. Correlate high regression-path activation with image features like object size, texture, or lighting to hypothesize what triggers specialization.

## Limitations
*   **Generalization**: Performance is unknown on other robot morphologies, camera placements, or unseen object categories, as the dataset is sourced from a single robot arm.
*   **Baseline Comparison**: Improvement is measured only against a non-finetuned VLM; no comparison with specialized monocular 3D/ depth estimation architectures is provided.
*   **Task Validation**: The assumed 10 mm error threshold for grasping/pushing lacks empirical validation within a closed-loop robotic control system.

## Confidence
*   **Performance Claims (MAE 13 mm, 27 mm Euclidean)**: **Medium** – Metrics are reported, but test set diversity and ground-truth measurement uncertainty are not detailed.
*   **Method Specialization Without Forgetting**: **Low** – No quantitative evaluation of retained general VLM capabilities (e.g., captioning, VQA) post-fine-tuning is provided.
*   **Dataset Scale (100k+ images)**: **High** – The specific robot (Doosan) and camera type (wrist-mounted) are noted, though the source is a single platform.

## Next Checks
1.  Test on at least two distinct robotic platforms (e.g., fixed base arm, mobile manipulator) and unseen object domains to measure cross-robot/category generalization.
2.  Compare against a strong non-VLM monocular 3D estimator (e.g., MiDaS-depth + known camera extrinsics) to isolate the contribution of the VLM-based approach.
3.  Integrate the predictor into a real robotic grasping/pushing pipeline and measure task success rate relative to the 10 mm error threshold to validate practical utility.
