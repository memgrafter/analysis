# DANCE: Doubly Adaptive Neighborhood Conformal Estimation

## Quick Facts
- arXiv ID: 2602.20652
- Source URL: https://arxiv.org/abs/2602.20652
- Reference count: 40
- Primary result: DANCE improves efficiency-robustness trade-off in conformal prediction for CLIP-based image classification via a doubly adaptive neighborhood approach.

## Executive Summary
Conformal prediction for pre-trained vision-language models like CLIP often yields overly conservative sets using standard logit scores. DANCE addresses this with a doubly adaptive neighborhood method, employing two nonconformity scores in a task-adapted kernel space derived from Recursive Feature Machines (RFM). A rank-based k-NN score enforces size control, while a density-based contrastive score enhances semantic grouping; their intersection yields final sets. Across 11 image classification datasets, DANCE achieves superior efficiency-robustness trade-offs, with nominal coverage (~0.93–0.96) and low computational overhead (RFM fitting ≤12 min, inference ~0.08s).

## Method Summary
DANCE constructs conformal prediction sets by first transforming the pre-trained model's feature space using RFM to create a task-adapted kernel that better captures semantic relationships. In this space, for each test point, two scores are computed: a rank-based k-NN score that ranks the test point's distance to training neighbors to limit set size, and a density-based contrastive score that compares local density estimates to promote coherent semantic groups. Initial prediction sets are derived from each score at a chosen significance level. The final set is the intersection of these two sets, balancing size efficiency and conditional robustness. This doubly adaptive approach leverages both rank and density information in a tailored feature space.

## Key Results
- For ViT-B/16 at α=0.05, average set size 4.96 and class-conditional coverage violation (CCV) 5.364.
- At α=0.1, set size 2.49 with CCV 8.44, maintaining marginal coverage approximately 0.93–0.96.
- Computational efficiency: RFM fitting time ≤12 minutes, inference time ~0.08 seconds per sample.

## Why This Works (Mechanism)
The doubly adaptive design mitigates individual score weaknesses: the rank-based k-NN score directly controls set size via neighbor ranks but may ignore semantic boundaries, while the density-based contrastive score aligns with semantic density but can yield large sets. Their intersection enforces both constraints. Crucially, RFM adapts the kernel to the classification task, ensuring that distance metrics in the transformed space reflect task-relevant semantics, making both scores more effective. This synergy allows DANCE to achieve small sets without sacrificing conditional coverage robustness.

## Architecture Onboarding
**Component Map**:  
Input Features -> RFM Transformation -> Task-Adapted Kernel Space -> Rank-based k-NN Score & Density-based Contrastive Score -> Score Intersection -> Final Prediction Sets

**Critical Path**:  
1. Extract features from pre-trained model (e.g., CLIP) for training and test data.  
2. Fit RFM on training features to learn task-adapted kernel matrix.  
3. For each test point, compute kernel-induced distances to all training points.  
4. Compute k-NN score: rank of test point's nearest neighbor distance.  
5. Compute contrastive score: difference between local density at test point and neighbor densities.  
6. Determine initial sets from each score using calibration quantiles.  
7. Intersect sets to produce final prediction set.

**Design Tradeoffs**:  
- **RFM Complexity vs. Adaptation**: Deeper RFM yields better kernel adaptation but increases fitting time; balance based on dataset size.  
- **k in k-NN**: Smaller k produces tighter sets but more variance; larger k smooths but may be conservative.  
- **Intersection vs. Union**: Intersection reduces set size but risks coverage drops if scores disagree; union improves coverage at size cost.  
- **Kernel Bandwidth in Contrastive Score**: Affects density estimation sensitivity; requires tuning for dataset characteristics.

**Failure Signatures**:  
- **Non-CLIP Backbones**: If model features lack semantic alignment, RFM adaptation may fail, leading to poor set quality.  
- **High-Dimensional Features**: Distance metrics degrade with dimensionality, harming both scores' effectiveness.  
- **Severe Distribution Shift**: Test data outside training manifold breaks neighborhood assumptions, increasing coverage violations.  
- **Small Calibration Sets**: Insufficient data for reliable score calibration, causing set size instability.

**First Experiments**:  
1. **Baseline Replication**: Implement DANCE on a small dataset (e.g., CIFAR-10) with CLIP-ViT-B/16; compare set size and coverage to standard conformal prediction using logits.  
2. **Ablation Analysis**: Disable each score (use only k-NN or only contrastive) to measure impact on efficiency and robustness; verify intersection benefit.  
3. **Cross-Model Portability**: Apply DANCE to a different pre-trained model (e.g., BLIP) on the same dataset; assess performance degradation relative to CLIP.

## Open Questions the Paper Calls Out
The paper does not explicitly enumerate open questions. However, the limitations and discussion point to several unresolved issues:
- The generalizability of DANCE to non-CLIP vision models remains untested.
- Theoretical understanding of conditional coverage guarantees for the intersection-based approach is limited.
- Scalability to very large datasets and models is not fully validated.

## Limitations
- **Generalizability Uncertainty**: Validation restricted to CLIP backbones; unknown if approach transfers to other model architectures (e.g., CNNs, non-VLMs).  
- **Theoretical Guarantees Uncertainty**: Limited details on formal conditional coverage proofs; assumptions and parameter sensitivity not fully elaborated.  
- **Scalability & Cost Validation**: Reported timings lack independent verification on larger datasets (e.g., full ImageNet) or larger models (e.g., ViT-L/14).
