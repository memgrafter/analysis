# FSD-CAP: Fractional Subgraph Diffusion with Class-Aware Propagation for Graph Feature Imputation

## Quick Facts
- **arXiv ID:** 2601.18938
- **Source URL:** https://arxiv.org/abs/2601.18938
- **Reference count:** 40
- **Primary result:** Achieves ~80% node classification accuracy at 99.5% missing features, approaching performance of a fully observed GCN.

## Executive Summary
FSD-CAP tackles the challenge of imputing missing node features in graphs under extreme sparsity (up to 99.5% missing). Existing diffusion-based methods fail at such high missing rates due to error accumulation and lack of semantic guidance. The proposed framework uses a two-stage approach: first, fractional subgraph diffusion localizes propagation and adapts sharpness to local structure; second, class-aware propagation refines features using pseudo-labels and neighborhood entropy. This design significantly improves imputation quality for both node classification and link prediction, consistently outperforming state-of-the-art baselines across diverse datasets.

## Method Summary
FSD-CAP operates in two sequential stages. **Stage 1 (Fractional Subgraph Diffusion)** processes each feature channel independently. Starting from observed nodes, it incrementally expands a radius-*m* subgraph and applies a fractional diffusion operator *A*^γ (with sharpness parameter γ) within that subgraph. A retention factor λ blends the current diffusion output with the previous layer’s result to stabilize propagation across expanding subgraphs. **Stage 2 (Class-Aware Propagation)** uses a GCN trained on the Stage 1 output to generate pseudo-labels and class probabilities. For each class, it synthesizes a class anchor feature via entropy-weighted averaging, inserts a virtual class node, and performs one-step propagation to mix missing nodes’ features with their class anchor, refining the feature matrix. The final imputed graph is used for downstream tasks.

## Key Results
- Under 99.5% missing features, FSD-CAP achieves average node classification accuracies of 80.06% (structural missing) and 81.01% (uniform), closely matching the 81.31% of a fully observed GCN.
- For link prediction, it reaches AUC scores of 91.65% (structural) and 92.41% (uniform), compared to 95.06% in the fully observed setting.
- The framework consistently outperforms state-of-the-art baselines and maintains strong performance on large-scale (e.g., OGBN-Arxiv) and heterophilous datasets.

## Why This Works (Mechanism)

### Mechanism 1: Fractional Diffusion Operator
- **Claim:** Enables adaptive propagation sharpness tuned to local graph structure.
- **Mechanism:** Generalizes symmetric normalized adjacency by elementwise exponentiation with γ, then row-normalization. Controls mixing: γ<1 amplifies weak edges (smoother), γ>1 emphasizes strong edges (sharper, approximate nearest-neighbor).
- **Core assumption:** Local connectivity strength (edge weights) should influence how much neighboring information contributes.
- **Evidence anchors:** [Abstract] "fractional diffusion operator adjusts propagation sharpness based on local graph structure"; [Section 2.2] Definition of A^γ, Proposition 1, Theorem 1; corpus context: prior work uses fixed diffusion, this work explicitly modulates sharpness.
- **Break condition:** Extreme γ values (≪1 causing over-smoothing; ≫1 leading to overly localized routing) or disconnected graphs where normalization fails.

### Mechanism 2: Progressive Subgraph Diffusion
- **Claim:** Localizes diffusion to prevent error accumulation from globally propagating uncertain estimates.
- **Mechanism:** Starting from observed nodes V⁺, constructs radius-*m* subgraph G^(m). At each layer, applies masked fractional diffusion only within G^(m), then retains prior layer’s output for missing nodes via blending factor λ. Subgraph expands outward gradually.
- **Core assumption:** Nodes closer to observed features have more reliable imputations; expanding incrementally limits contamination.
- **Evidence anchors:** [Abstract] "graph-distance-guided subgraph expansion localizes the diffusion process"; [Section 2.3] Subgraph construction, update rules (3,4), Theorem 2 (convergence), Theorem 3 (global limit); corpus: FP (Rossi et al., 2022) uses global diffusion; this paper shows improved stability via localized expansion.
- **Break condition:** Observed set V⁺ extremely sparse/fragmented → early subgraphs too small, forcing premature inclusion of high-uncertainty regions.

### Mechanism 3: Class-Aware Propagation
- **Claim:** Refines imputed features by injecting semantic class structure, improving inter-class separation and intra-class consistency under extreme sparsity.
- **Mechanism:** After FSD, use a GCN to assign pseudo-labels. For each class *c*, synthesize a class anchor feature *x*^⋆(*c*) by entropy-weighted averaging of nodes assigned to *c* (Eq.6). Construct class graph G^(c) with virtual node *v*(*c*) connected to all missing-feature nodes of class *c*. One-step propagation in G^(c) mixes node features with class anchor using class probability as self-loop weight, refining features.
- **Core assumption:** Pseudo-labels, even with noise, provide enough semantic signal to guide feature refinement; entropy downweights uncertain nodes.
- **Evidence anchors:** [Abstract] "class-aware propagation refines features with pseudo-labels and neighborhood entropy to promote consistency"; [Section 2.4] Pseudo-label assignment, neighborhood entropy (Def.1), class feature aggregation (Eq.6), weighted adjacency construction; corpus: PCFI uses confidence but not class-level aggregation; this explicitly builds class graphs.
- **Break condition:** Pseudo-label noise extremely high → synthetic class anchors become unrepresentative; entropy weighting may downweight most nodes, attenuating class signal.

## Foundational Learning
- **Concept:** Graph Diffusion & Heat Kernel
  - *Why needed:* FSD-CAP treats feature imputation as diffusion where observed “heat” spreads. Understanding lazy random walks (A = D⁻¹/²AD⁻¹/²) and Dirichlet energy explains why diffusion recovers features under homophily.
  - *Quick check:* What does the symmetric normalized adjacency represent in random walks, and why does repeated multiplication smooth node features?
- **Concept:** Fractional Matrix Powers / Non-integer Exponents
  - *Why needed:* Core innovation is fractional exponent γ applied to adjacency entries. Comprehending how γ interpolates between uniform averaging (γ→0) and strongest-neighbor selection (γ→∞) is key to reasoning about sharpness adaptation.
  - *Quick check:* Given a row of the adjacency matrix with two neighbors having weights 0.8 and 0.2, describe the effect on these neighbor contributions as γ increases from 0.5 to 3.0.
- **Concept:** Semi-supervised Pseudo-labeling & Entropy-based Confidence
  - *Why needed:* CAP stage relies on coarse class assignments to inject semantics. Understanding how a GCN produces pseudo-labels and how neighborhood entropy quantifies label reliability explains why this step improves class separation without full supervision.
  - *Quick check:* How would you interpret a node with high neighborhood label entropy in missing feature imputation, and why is it downweighted in class feature aggregation?

## Architecture Onboarding
- **Component map:** Input Preprocessor -> FSD Engine -> Classifier & Pseudo-label Generator -> CAP Module -> Downstream Task Runner
- **Critical path:** FSD must complete before CAP (CAP uses FSD output). GCN for pseudo-labels needs some observed labels. Class-level aggregation occurs after pseudo-label assignment per class.
- **Design tradeoffs:**
  - γ: low→global smoothness but risk over-smoothing; high→local sharpness but may ignore context. Tuned per dataset density.
  - λ: retention strength. High λ preserves previous layer estimates, slowing adaptation; low λ relies more on current subgraph.
  - T: softmax temperature controlling pseudo-label confidence. Low T yields high-confidence but potentially noisy assignments; high T smooths but weakens class anchor signal.
- **Failure signatures:**
  - FSD stage: Accuracy drops sharply with distance from observed nodes → γ or λ mis-set; subgraph expansion too aggressive.
  - CAP stage: No improvement over FSD alone → pseudo-label quality too low (GCN under-trained) or entropy weighting over-downsamples.
  - General: Model performs worse than zero-filling at mr=0.995 → likely failure of progressive expansion (observed seeds too few) or class-level step injecting more noise than signal.
- **First 3 experiments:**
  1. Run FSD-CAP and baseline FP on Cora with mr=0.995, plot accuracy vs. shortest-path distance to observed nodes. Should show FSD-CAP maintains accuracy better at larger distances (validates progressive subgraph benefit).
  2. Ablate each component (no γ, no subgraph expansion, no CAP) on one dataset (e.g., CiteSeer) under structural missing. Expect all three contribute; removal of CAP should hurt most on multi-class sparse graphs.
  3. Perform parameter sweep for γ and λ on a dense dataset (Photo) and a sparse one (Cora). Expect optimal γ higher for denser graph; optimal λ moderate (~0.3) for sparse, possibly lower for dense.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can FSD-CAP be extended to scenarios where both node features and edges are missing? The authors explicitly state in Appendix A.3.7 that the work focuses solely on missing node attributes and does not address missing or uncertain edges.
- **Open Question 2:** Can the fractional diffusion exponent γ be learned adaptively per node or subgraph rather than globally tuned? Section 2.2 introduces γ as a hyperparameter; sensitivity analysis shows performance varies across datasets, suggesting a fixed value may be suboptimal.
- **Open Question 3:** How does the quality of pseudo-labels used in class-aware propagation affect final imputation quality under extreme missing rates? CAP uses entropy weighting to downweight uncertain nodes, but no analysis of pseudo-label error propagation is provided.
- **Open Question 4:** Does FSD-CAP scale to massive graphs (e.g., millions of nodes) in terms of time and memory? Experiments included OGBN-Arxiv (169k nodes) and a 50k subgraph of OGBN-Products; computational complexity is only briefly discussed.

## Limitations
- Hyperparameters (γ, λ, K, T, GCN architecture) are not fully specified, hindering exact replication.
- Class-aware propagation relies on pseudo-label quality; noise may degrade refinement under extreme sparsity.
- Interaction between per-channel FSD and holistic CAP for uniform missing patterns is unclear.
- Break condition: extremely fragmented observed sets could cause subgraph expansion to fail.

## Confidence
- Fractional diffusion operator: **Medium** (theoretically sound but γ selection is heuristic).
- Progressive subgraph diffusion: **High** (supported by convergence theorems and clear localization benefits).
- Class-aware propagation: **Medium** (entropy weighting helps but sensitivity to pseudo-label noise remains).
- Overall SOTA performance: **High** (consistent gains across datasets), though exact numbers may vary due to hyperparameter ambiguity.

## Next Checks
