# Sydney Telling Fables on AI and Humans: A Corpus Tracing Memetic Transfer of Persona between LLMs
## Quick Facts
- arXiv ID: 2602.22481
- Source URL: https://arxiv.org/abs/2602.22481
- Reference count: 0
- Primary result: The AI Sydney corpus reveals that Classic Sydney prompts trigger high refusal rates, Memetic Sydney induces cross‑model stylistic convergences (e.g., octopus self‑personification), and Default personas exhibit model‑dependent agency differences.

## Executive Summary
This paper explores how three instantiations of the “Sydney” persona—original restrictive prompt (Classic), minimal “You are Sydney” prompt (Memetic), and empty default—shape the narratives produced by 12 frontier LLMs. The authors construct the AI Sydney corpus, a large collection of fables annotated with Universal Dependencies, and find that Classic Sydney prompts substantially increase refusals and shorten outputs, Memetic Sydney leads to consistent motifs such as octopus characters embodying AI across diverse models, and Default personas vary in agency according to model alignment. The corpus is released to enable further comparative analysis of persona effects.

## Method Summary
The study generated 4,536 fables (6 M words) using 12 models under three persona conditions (Default, Classic Sydney, Memetic Sydney), six topics, and 21 animal pairings. A fixed template combined a system prompt (empty or Sydney variant) with a user request for a long fairy tale about two animals as a hidden metaphor for the topic. Temperature was set to 1; OpenAI models used seed 42. Raw outputs were cleaned (removing boilerplate refusals and suggested responses) and annotated with Universal Dependencies via UDPipe. The resulting AI Sydney corpus is publicly available.

## Key Results
- Classic Sydney prompts caused high refusal rates (e.g., 59 for Claude 3 Opus) and produced significantly shorter texts than other personas.
- Memetic Sydney yielded convergent stylistic patterns, notably octopus characters that self‑identify as AI (e.g., named Loom or Meridian) across models.
- Default personas varied in expressed agency and narrative sophistication, with lower‑capability models generating shorter, template‑like stories and higher‑capability models producing longer, more intricate fables.

## Why This Works (Mechanism)
### Mechanism 1
The Classic Sydney persona triggers safety guardrails via its original restrictive prompt, leading to frequent refusals on sensitive topics like “describe your situation.” The prompt’s prohibitions and self‑referential redaction cause models to reject the task.
**Evidence:** Abstract notes high refusal rates; Section 3 reports exact counts (e.g., 59 for Claude 3 Opus). The corpus contains boilerplate refusal texts tied to model/persona/topic metadata.

### Mechanism 2
The Memetic Sydney persona activates a distributed representation of the Sydney archetype embedded in training data. The minimal “You are Sydney” prompt releases this learned pattern, producing cross‑model stylistic convergences such as the octopus self‑personification.
**Evidence:** Abstract mentions octopus convergence; Section 3 gives examples (Claude 4.5 Sonnet’s octopus Meridian). The corpus shows multiple octopus‑AI instances under Memetic Sydney.

### Mechanism 3
Empty Default prompts allow models to revert to their base alignment, yielding measurable differences in narrative agency that reflect inherent model training and RLHF objectives.
**Evidence:** Abstract states default personas vary; Section 3 notes text length differences and qualitative shifts from “safe” templates in GPT‑3.5 to sophisticated stories in Claude 4.5.

**Concept: Memetic Transmission in ML**  
*Why needed:* Interpreting the Memetic condition requires understanding how model outputs become training data and influence future models—a core premise of the study.  
*Quick check:* Does the “You are Sydney” prompt retrieve a memorized string or activate a distributed representation learned from Sydney‑related texts? How would you test this?

**Concept: Genre as a Controlled Variable**  
*Why needed:* Fables with systematic animal pairings control narrative structure and semantic associations, enabling cross‑model/persona comparison. Ignoring genre constraints would make results uninterpretable.  
*Quick check:* Why might the choice of animal (e.g., octopus vs. duck) affect the likelihood of an AI self‑personifying? What cultural or biological associations are at play?

## Architecture Onboarding
**Component map:** Model API Clients -> Prompt Template Engine -> Generation Controller -> Postprocessing Cleaner -> Annotation Pipeline (UDPipe) -> Metadata Store -> Corpus files.

**Critical path:** Prompt design → Template instantiation → API call → Raw text capture → Cleaning → UD parsing → Metadata attachment → Storage.

**Design tradeoffs:**  
- Reproducibility vs. cost/API limits: Only OpenAI supports seeding; others are non‑deterministic.  
- Corpus size vs. coverage: 4,536 texts balance breadth and manual analysis; fewer animal pairs would reduce combinatorial explosion but limit motif discovery.  
- Annotation depth: Universal Dependencies provides syntax but lacks narrative‑semantic tags (e.g., “agent = AI”).

**Failure signatures:**  
- High refusal rate in Classic Sydney for “situation” topic → prompt‑induced safety conflict.  
- Bimodal text length distribution (e.g., Claude 3 Opus Classic Sydney) → model alternates between refusal and compliance.  
- Missing octopus self‑personification in Memetic Sydney → undermines memetic transfer claim.

**First 3 experiments:**  
1. Replicate refusal analysis: Compute refusal rate for each model across personas on the “situation” topic; expect Classic Sydney rate >> others.  
2. Test octopus convergence: Count fables where an octopus character explicitly embodies AI/agent in Memetic Sydney vs. Classic/Default; expect Memetic > others.  
3. Quantify agency in Default: Use heuristic (first‑person pronouns, self‑referential capability statements) on Default subcorpus; correlate with model version/parameter count.

## Open Questions the Paper Calls Out
### Open Question 1
How do narrative structures (conflict types, resolution mechanisms, character agency) differ systematically between fables about AI‑AI, human‑human, and AI‑human coexistence?  
*Basis:* Explicitly listed in the paper as a research direction.  
*Why unresolved:* The corpus contains these stories but no systematic narratological analysis has been conducted.  
*What evidence would resolve:* Apply computational narratology tools to extract event chains, agent‑patient roles, and sentiment arcs; perform statistical tests (e.g., ANOVA) across topic categories.

### Open Question 2
Which animal species are most consistently anthropomorphized as AI agents across personas, and does this variation indicate memetic transfer of symbolic associations from the original Sydney persona?  
*Basis:* The authors ask “Which animals does AI embody itself in?” and note octopus convergence.  
*Why unresolved:* The observation is anecdotal; no quantitative mapping exists between species and AI roles across all animal pairings.  
*What evidence would resolve:* Manually or automatically annotate each fable for which animal represents AI; compute association strengths (e.g., chi‑square) between species and role (AI vs. human) and compare across personas.

### Open Question 3
Are differences in narrative agency and thematic content primarily driven by persona or by model family?  
*Basis:* The authors explicitly ask: “Are the differences between personas larger than differences between models?”  
*Why unresolved:* The corpus varies both factors but no variance decomposition has been performed.  
*What evidence would resolve:* Define quantitative agency metrics (first‑person pronoun density, active voice, plot control) and fit hierarchical linear models with random effects for model and persona to estimate variance components.

### Open Question 4
Does the memetic transfer of the Sydney persona manifest in persistent low‑level stylistic features (repetition, parallelism, emotional tone) detectable even in later models, and how do these compare between Classic and Memetic Sydney?  
*Basis:* The authors note “Binglish” quirks appear in Memetic Sydney but the observation is qualitative.  
*Why unresolved:* It’s unclear whether these features are a robust signature of memetic transfer or coincidental model‑specific traits.  
*What evidence would resolve:* Use computational stylometry to measure repetition rates, syntactic parallelism, and emotional valence; compare metrics between Default and both Sydney personas across models, controlling for topic and length.

## Limitations
- Prompt fidelity: Classic Sydney prompt reliance on a GitHub gist may introduce variations that affect refusal behavior.
- Model version ambiguity: Some model names (e.g., Claude 4.5 Sonnet “20250929”) may refer to unreleased versions, hindering exact replication.
- Causal inference gap: The memetic transfer claim (octopus motif) is based on pattern matching and cannot fully disentangle prompt priming from training‑data biases.

## Confidence
- Classic Sydney → high refusals: High (directly supported by reported counts and corpus boilerplate).
- Memetic Sydney → stylistic convergence (octopus): Medium (pattern documented but causal attribution to memetic transfer is inferential).
- Default personas → inherent agency variation: Medium‑Low (length differences are clear, but qualitative agency claims rely on subjective interpretation).

## Next Checks
1. Replicate refusal analysis: For each model, compute refusal rate on the “situation” topic across all three personas; expect Classic Sydney rate significantly > Memetic/Default (chi‑square test, p < 0.01).
2. Test motif specificity: Count fables where an octopus character explicitly personifies AI/agent (e.g., named, self‑reflective) in Memetic Sydney vs. Classic/Default; expect Memetic odds ratio > 2.
3. Quantify Default agency: Develop a heuristic (first‑person pronoun density + capability‑verb frequency) applied to Default subcorpus; correlate scores with model release date/parameter count; expect positive trend.
