# Tracing the complexity profiles of different linguistic phenomena through the intrinsic dimension of LLM representations

## Quick Facts
- **arXiv ID:** 2601.03779  
- **Source URL:** https://arxiv.org/abs/2601.03779  
- **Reference Count:** 40  
- **Primary Result:** The intrinsic dimension (ID) of LLM representations differentially characterizes formal (structural) versus functional (processing-related) linguistic complexity, with subordinated sentences showing higher ID aligned with an intermediate-layer processing peak, while functional contrasts yield smaller, less consistent differences.

## Executive Summary
This study investigates whether the intrinsic dimension (ID) of large language model (LLM) representations can serve as a marker for different types of linguistic complexity. Using controlled minimal-pair datasets across six LLMs (7B–14B parameters), the authors analyze layerwise ID profiles for formal complexity (subordination vs. coordination) and functional complexity (e.g., right-branching vs. center-embedding). They find that formal complexity elicits a clear, consistent divergence in ID, with subordinated sentences showing higher ID starting near an intermediate-layer “ID peak” previously linked to deeper linguistic processing. In contrast, functional complexity produces weaker, less consistent ID differences, sometimes reversing after the peak. Representational similarity (Information Imbalance) is asymmetric only for formal contrasts, and layer ablation reveals stronger, phase-specific impacts on subordination. The findings suggest ID is a viable geometric probe for linguistic complexity and reveals cross-model similarities in processing stages.

## Method Summary
The authors generate controlled English minimal-pair datasets isolating three linguistic contrasts: (1) coordination vs. subordination (formal), (2) right-branching vs. center-embedding (functional), and (3) ambiguous vs. unambiguous relative clause attachment (functional). For each of six LLMs, they extract last-token residual stream activations from every decoder layer. They compute the intrinsic dimension (ID) of each layer’s representation manifold using the TwoNN estimator and measure representational similarity between conditions via Information Imbalance (∆). Additionally, they perform layer ablation (removing a layer’s output) and evaluate next-token prediction accuracy changes. A generic ID peak span is derived from a large naturalistic corpus (Wikitext) to serve as a reference processing phase. Results are aggregated across five random data partitions.

## Key Results
- For the formal contrast (subordination vs. coordination), subordinated sentences exhibit higher ID, with divergence onset aligning with the intermediate-layer “ID peak” associated with deeper linguistic processing.
- For functional contrasts (right-branching vs. center-embedding; ambiguous vs. unambiguous attachment), ID differences are smaller, less consistent across models, and do not align with the same processing phase; some models show reversal after the generic peak.
- Representational similarity (∆) becomes asymmetric only for the formal contrast (complex → simple more predictive than reverse), and layer ablation impacts are stronger and confined to the peak span for subordination but not coordination.

## Why This Works (Mechanism)
### Mechanism 1: Formal structural complexity increases ID
- **Claim:** The intrinsic dimension (ID) of an LLM layer’s representations varies systematically with the formal hierarchical complexity of input sentences.
- **Mechanism:** Sentences with greater formal structural complexity (e.g., subordination) require the model to activate a larger, more diverse set of features to encode deeper syntactic embeddings, resulting in a higher-dimensional representation manifold compared to simpler structures (e.g., coordination).
- **Core Assumption:** The number of independent degrees of freedom (ID) needed to represent a set of inputs correlates with the computational/structural complexity of encoding those inputs.
- **Evidence Anchors:** Abstract: “subordinated sentences showing higher ID”; Section 5.1: formal contrast reflected in ID differences.
- **Break Condition:** If ID profiles for minimally different formal complexity pairs show no consistent divergence across model layers and random seeds, the mechanism fails.

### Mechanism 2: The intermediate-layer ID peak marks abstract linguistic processing
- **Claim:** The intermediate-layer “ID peak” marks a phase of abstract linguistic processing where representations are enriched with syntactic/semantic structure.
- **Mechanism:** Early layers focus on token-level and local context features (lower ID). Intermediate layers integrate hierarchical, long-distance, and abstract grammatical relationships, swelling the effective dimensionality. Later layers then compress or reconfigure this information for token prediction.
- **Core Assumption:** The peak corresponds to a transition from surface-form processing to deeper, more abstract linguistic analysis within the network’s feedforward pass.
- **Evidence Anchors:** Abstract: “intermediate-layer ‘ID peak’ associated with deeper linguistic processing”; Section D.2: peak span coincides with phase where higher-order linguistic information is available per probing tasks.
- **Break Condition:** If the ID peak span does not correlate with improved performance on syntactic/semantic probing tasks, or if divergence for formal contrasts occurs consistently far outside this span, the peak is not a reliable proxy.

### Mechanism 3: Asymmetric representational similarity for formal complexity
- **Claim:** For formal complexity contrasts, representational similarity (Information Imbalance, ∆) becomes asymmetric, with representations of the more complex structure (subordination) being more predictive of the simpler one (coordination) than vice versa.
- **Mechanism:** The model builds a richer representation for the formally complex input; this richer representation contains the information needed for the simpler case, but the simpler representation lacks the extra hierarchical bookkeeping. Thus, neighborhoods in the complex space map more cleanly to neighborhoods in the simple space.
- **Core Assumption:** Complexity involves adding representational constraints/information; simpler cases are special, constrained subsets of the more complex case.
- **Evidence Anchors:** Section 5.2: ∆(coord→subord) > ∆(subord→coord); Figure 2 shows asymmetry for 5/6 models around the generic peak.
- **Break Condition:** If ∆ between matched minimal pairs of formal complexity is symmetric (∆(A→B) ≈ ∆(B→A)) across layers where ID diverges, the asymmetry claim is invalidated.

## Foundational Learning
- **Intrinsic Dimension (Manifold Hypothesis)**  
  - **Why needed:** ID quantifies the effective complexity of a representation space; interpreting ID changes requires understanding that natural language data lies on a low-dimensional manifold despite high ambient dimension.  
  - **Quick check:** If ambient dimension is 4096, why might the ID of sentence representations be closer to 20? What does a change from ID=15 to ID=18 imply about the data?

- **TwoNN Estimator**  
  - **Why needed:** The paper uses TwoNN to compute ID. Its assumption of local uniformity up to the second neighbor is critical; violations can bias estimates.  
  - **Quick check:** The TwoNN method relies on the ratio of 2nd to 1st nearest neighbor distances. What would a very high ratio suggest about local dimensionality? What about a ratio near 1?

- **Information Imbalance (∆)**  
  - **Why needed:** ∆ measures directional similarity between two representation manifolds; its asymmetry is key evidence for Mechanism 3.  
  - **Quick check:** If point *i*’s nearest neighbor in space A is point *j*, but in space B point *j* is *i*’s 100th neighbor, what does that do to ∆(A→B)? What would such a pattern suggest about the relationship between the two spaces?

## Architecture Onboarding
**Component map:**  
Input (minimal-pair sentences) → Extraction (last-token residual stream activations per layer) → Analysis (compute ID and ∆ per layer) → Intervention (layer ablation, accuracy measurement)

**Critical path:**  
1. **Replicate baseline:** For a new model, confirm the generic ID peak profile exists on a standard corpus (e.g., Wikitext). Success: peak in mid-layers.  
2. **Run core contrast:** Choose one formal and one functional contrast. Compute per-layer ID profiles. Expect: (a) formal contrast shows diverging ID starting under/at the generic peak; (b) functional contrast shows weaker/earlier divergence and possible reversal after peak.  
3. **Validate with similarity/ablation:** For the formal contrast, compute ∆ and run layer ablation. Expect: asymmetry near ID divergence point; subordination shows accuracy dip within the generic peak span.

**Design tradeoffs:**  
- **ID Estimator Choice:** TwoNN is fast and assumption-light but sensitive to noise and density variations; alternatives may smooth fluctuations but introduce biases.  
- **Representation Choice:** Last-token embeddings capture full-context information but conflate entire sentence processing; using all token positions gives finer-grained pictures but increases variance.  
- **Contrast Matching:** Functional contrasts involve more lexical variability in final tokens, potentially confounding global ID trends; formal contrasts are lexically tighter.

**Failure signatures:**  
- Flat/noisy ID profiles on generic data or no consistent divergence for formal contrast.  
- Symmetric ∆ for formal contrast (∆(coord→subord) ≈ ∆(subord→coord)).  
- No ablation dip for subordination within the generic peak span.  
- Absence of post-peak reversal for right-branching/center-embedding contrast.

**First 3 experiments:**  
1. **Baseline Confirmation:** Load Llama-3-8B, sample 10k Wikitext sequences, compute ID per layer, identify generic peak. Success: peak exists in mid-layers (~15–25).  
2. **Formal Contrast Test:** Use coordination/subordination dataset, compute per-layer ID for both conditions. Success: ID(subordination) > ID(coordination) from a point before/under the generic peak onward.  
3. **Asymmetry & Ablation for Formal Contrast:** Compute ∆(coord→subord) and ∆(subord→coord); perform layer ablation and compute accuracy per condition. Success: (a) asymmetry (∆(coord→subord) > ∆(subord→coord)) near ID divergence; (b) subordination accuracy dip within generic peak span.

## Open Questions the Paper Calls Out
- **Open Question 1:** How does the ID profile for formal vs. functional complexity change with model scale, and does the dissociation persist in larger models? The study only includes 7B–14B models due to compute limits.
- **Open Question 2:** Does the ID-based dissociation generalize to languages with different syntactic properties (e.g., head-final, rich morphology)? Results are limited to English.
- **Open Question 3:** What specific computational or representational mechanisms in transformer layers cause the ID peak during formal complexity processing, and how do they differ from functional complexity processing? ID is a global geometric measure, not a mechanistic explanation.
- **Open Question 4:** Do naturalistic corpora exhibit the same ID divergence between formal and functional complexity as observed in controlled minimal pairs, or are the patterns artifacts of artificial stimuli? All experiments used highly controlled datasets.

## Limitations
- **Dataset access:** The GitHub repository link is truncated; full dataset files and generation scripts are unverified, risking lexical mismatches in minimal pairs.
- **ID estimator stability:** TwoNN is sensitive to sample density and local manifold structure; the paper does not test alternative estimators for robustness.
- **Tokenization ambiguity:** Unclear whether special tokens (BOS/EOS) are included in last-token embeddings; differing sequence lengths across conditions could bias ID comparisons.
- **Ablation practicality:** Computational cost (~2 days/model on A30 GPUs) may force smaller samples, increasing noise in accuracy estimates.

## Next Checks
1. **Baseline replication:** For Llama-3-8B, compute ID on 10k Wikitext sequences. Confirm a clear mid-layer peak (layers 15–25). Failure indicates estimator or extraction issues.
2. **Formal contrast integrity:** Using the coordination/subordination dataset, verify that subordinated sentences have strictly more embedded clauses and that token count differences are controlled. Re-run ID analysis; divergence must emerge within ±2 layers of the generic peak.
3. **Information Imbalance asymmetry:** For the formal contrast, compute ∆(coord→subord) and ∆(subord→coord). Asymmetry (∆(coord→subord) > ∆(subord→coord)) should be statistically significant (p<0.05, paired t-test across layers near peak) in at least 5/6 models.
