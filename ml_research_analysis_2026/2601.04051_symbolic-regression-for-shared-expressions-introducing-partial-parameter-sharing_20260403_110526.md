# Symbolic Regression for Shared Expressions: Introducing Partial Parameter Sharing

## Quick Facts
*   **arXiv ID:** 2601.04051
*   **Source URL:** https://arxiv.org/abs/2601.04051
*   **Reference Count:** 40
*   **Primary Result:** Introduces a hierarchical parameter sharing scheme for symbolic regression with multiple categorical variables, achieving comparable fit to prior methods while halving the number of individual parameters and enabling zero-shot generalization to new category combinations.

## Executive Summary
This paper extends symbolic regression (SR) to datasets influenced by multiple categorical variables (e.g., photometric filter and observational dataset for supernovae). Prior SR methods for such problems either required excessive data per category combination or failed to share information across categories. The authors propose a hierarchical parameter structure with three sharing levels: fully-shared (global), partially-shared (varying with one category while held constant across another), and non-shared (specific to a full category combination). This structure reduces the total number of free parameters, separates category-agnostic from category-specific effects, and lowers data requirements. On a synthetic test, the method succeeded with as few as one data point per combination when others were sufficient. Applied to supernovae light curve data, it achieved high fit quality (R² up to 0.993) with roughly half the parameters of previous approaches and allowed expressions to generalize to unseen filter-dataset pairs.

## Method Summary
The core method modifies the symbolic regression search space by introducing three new terminal types into the expression grammar: a `1` (fully-shared scalar), `C1`...`Cn` (partially-shared vectors, one per categorical factor), and `CI` (non-shared matrix for all category interactions). An expression's parameters `P` are thus a structured set `{p_shared, p_partial,U, p_partial,L, p_interaction}`. The parameter optimization (solving a nonlinear least-squares problem) exploits the sparsity pattern of the Jacobian matrix that arises from this structure, enabling efficient computation. The multi-objective fitness function balances predictive error (1-R²), expression complexity, and crucially, the *number of individual scalar parameters* to drive the search toward compact, shared models. Two main variants are explored: `novel` (allows all sharing levels) and `predictive` (excludes non-shared `CI` terms to force zero-shot generalizability).

## Key Results
*   **Parameter Efficiency:** On a supernovae dataset, the `novel` approach achieved an R² of ~0.993 using ~15 individual parameters, compared to 18-30 parameters in prior separate/flattened baselines.
*   **Low Data Requirements:** In a controlled synthetic experiment, successful model recovery occurred with only 1 data point in 7 out of 12 category combinations, provided total data met minimum thresholds and covariate coverage was sufficient.
*   **Zero-Shot Generalization:** The `predictive` variant, which omits interaction-specific parameters, could be evaluated for category combinations not seen during training, demonstrating the model's ability to compose effects from individual categories.

## Why This Works (Mechanism)

### Mechanism 1
*   **Claim:** Introducing partially-shared parameters reduces the total number of individual parameters compared to using only non-shared parameters.
*   **Mechanism:** For problems with two categorical variables `U` and `L` with `|U|` and `|L|` levels, parameters are organized into three sharing levels: one fully-shared scalar, up to `|U|` partially-shared parameters (constant across `L`), up to `|L|` partially-shared parameters (constant across `U`), and `|U|*|L|` non-shared parameters. A single partially-shared parameter replaces `|L|` (or `|U|`) non-shared parameters.
*   **Core assumption:** The true underlying function contains additive effects that are either global, dependent primarily on one category, or specific to the combination of categories.
*   **Evidence anchors:**
    *   [abstract]: Reports halving parameters on the supernovae dataset (15 vs. 30).
    *   [section 2.1]: Figure 2.1 visually shows one partially-shared parameter replacing four non-shared ones.
    *   [section 3.3, Table 3.3]: Shows expressions with ~14-15 parameters achieving R² ≈ 0.99.
*   **Break condition:** If the true function requires distinct *functional forms* (not just parameter values) for different category combinations, the fixed, shared expression structure may fail to fit accurately regardless of parameter count.

### Mechanism 2
*   **Claim:** The hierarchical sharing structure lowers the minimum data required per category-value combination by enabling parameter identification through shared information.
*   **Mechanism:** A single data point from a specific `(U=u, L=l)` combination informs the non-shared parameter for `(u,l)`, all partially-shared parameters for category `U=u` and `L=l`, and the shared parameter. This interconnectedness, reflected in the sparsity pattern of the Jacobian (Figure 2.2), allows global data to support local fitting.
*   **Core assumption:** The experimental design provides sufficient diversity in the independent variables across all category combinations to maintain a full-rank Jacobian despite sparse local data.
*   **Evidence anchors:**
    *   [section 2.2]: Discusses computational complexity reduction from O(nk) to O(nm) due to Jacobian sparsity, linking structure to efficiency.
    *   [section 3.1 (synthetic test), Table 3.1]: Shows successful refitting with as few as 1 data point in most combinations when total data ≥ ~20 and minimum per-parameter conditions are met.
    *   [abstract]: States the method required as few as one data point per combination.
*   **Break condition:** If a category combination has zero data points, its non-shared parameters are completely unidentifiable. The method breaks if minimum data requirements (one point for each non-shared parameter's combination, one additional point per category level for each partially-shared parameter) are violated.

### Mechanism 3
*   **Claim:** Partial parameter sharing enables zero-shot generalization to unseen category-value combinations and disentangles category effects for interpretability.
*   **Mechanism:** By excluding non-shared `CI` parameters (`predictive` variant), the final expression contains only terms built from fully-shared (`1`) and partially-shared (`C_U`, `C_L`) parameters. Such an expression can be evaluated for a new `(U=u_new, L=l_new)` pair because all constituent parameters (`p_partial,U[u_new]`, `p_partial,L[l_new]`) are defined from the training on other combinations involving `u_new` and `l_new`.
*   **Core assumption:** The response to a new category combination is deterministically composed of the effects captured by the global and category-specific terms; unique interaction effects are negligible or non-existent.
*   **Evidence anchors:**
    *   [abstract]: Mentions enabled zero-shot generalization.
    *   [section 3.3]: Explicitly states the `predictive` variant is designed for this purpose.
    *   [section 3.3, Table 3.3]: Example expressions use `C_band` and `C_dataset` to annotate effects, demonstrating disentanglement.
*   **Break condition:** If the true function for a new combination critically depends on a unique interaction effect (a missing `CI` term), zero-shot predictions will be inaccurate. The approach also fails if a completely new category *value* (not just combination) appears, as parameters for that value are undefined.

## Architecture Onboarding
*   **Component map:** Expression Generator (GP with new terminals) -> Parameter Identifier (sparse Jacobian solver) -> Objective Evaluator (error + complexity + *individual param count*) -> Selection -> Simplifier (algebraic rules respecting sharing levels) -> (repeat).
*   **Critical path:** Modification of the terminal set in the genetic programming engine must be matched by a parameter identifier that understands the hierarchical structure and an evaluator that correctly counts individual scalar parameters. The simplifier must apply algebraic reductions (e.g., `C1 * 1 -> C1`) without violating the sharing semantics.
*   **Design tradeoffs:**
    *   **Expressivity vs. Data Efficiency:** Including non-shared (`CI`) parameters increases maximum possible fit but multiplies data requirements. The `predictive` variant sacrifices peak fit for generalizability.
    *   **Search Space Complexity:** New terminal types expand the space. The implementation starts new expressions with only the shared `1` terminal, using mutation to introduce partial/interaction terms to manage initial complexity.
    *   **Complexity Metric:** Must count *individual scalars* (e.g., 12 values for `CI`) not symbolic nodes (1 `CI` node) to correctly penalize interaction terms.
*   **Failure signatures:**
    *   **Poor OOD generalization:** `predictive` variant fails on held-out `(U,L)` pairs indicates critical missing interaction effects (`CI` terms are necessary).
    *   **Failure with sparse data:** Synthetic test (Table 3.1 pattern) fails with fewer than the theoretical minimum points (`1 + |U| + |L| + |U|*|L|` for full identifiability) or with poor covariate coverage.
    *   **No Pareto dominance:** If the `novel` variant does not dominate the `flattened` and `separate` baselines in the error-parameter space, the assumed hierarchical effect structure does not match the data.
*   **First 3 experiments:**
    1.  **Replicate synthetic data requirement test:** Use the paper's synthetic function (Eq 2.3). Systematically remove all data points from random `(U,L)` combinations and verify refitting success/failure aligns with the stated minimum data conditions (1 point for non-shared, 1 per category level for partial, etc.).
    2.  **Reproduce supernovae Pareto frontier:** Run all 5 variants (`separate`, `flattened`, `sharing`, `novel`, `predictive`) on the supernovae dataset. Reproduce Figure 3.1, confirming `novel` Pareto-dominates baselines at intermediate parameter counts (~6-12) and `predictive` finds low-parameter solutions.
    3.  **Conduct zero-shot evaluation:** Train `novel` and `predictive` on a subset of category combinations (e.g., 5 of 6 filter-dataset pairs). Evaluate on the held-out combination. Compare errors to `separate` (which has no parameters for the new combo, predicting NaN) and `novel` (which would require a new `CI` value). This tests the practical utility of the `predictive` variant.

## Limitations
*   The hierarchical additive sharing structure assumes category effects are separable; it may fail for true higher-order interactions beyond pairwise.
*   Evaluation is limited to a single real-world dataset (supernovae), restricting claims about general applicability.
*   Interpretability benefits are presented anecdotally through example expressions; no objective metrics or user studies validate the claim of "clearer interpretability."
