# MolQuest: A Benchmark for Agentic Evaluation of Abductive Reasoning in Chemical Structure Elucidation

## Quick Facts
- **arXiv ID:** 2603.25253  
- **Source URL:** https://arxiv.org/abs/2603.25253  
- **Reference count:** 40  
- **Primary result:** State-of-the-art LLMs achieve only ~50% structure accuracy in agentic molecular elucidation, with most below 30%, revealing critical strategic planning deficits in dynamic scientific reasoning.

## Executive Summary
MolQuest addresses a key gap in evaluating large language models for dynamic, multi-step scientific reasoning by introducing an agent-based benchmark for molecular structure elucidation. The task is framed as an interactive problem where models must strategically plan and request spectral experiments (NMR, MS) to iteratively hypothesize and refine structures, using authentic data extracted from chemical literature. Results show that even top models like Gemini 3 Flash reach only 51.5% accuracy, with the majority below 30%, highlighting a fundamental gap in proactive, resource-aware reasoning beyond static pattern matching. The interactive paradigm reveals a "scaffold vs. crucible" bifurcation: some models improve with interaction while others degrade, exposing strategic planning deficits masked by conventional one-shot evaluations.

## Method Summary
MolQuest is an evaluation-only framework where LLMs act as autonomous agents within a virtual laboratory. The environment is a state machine managing per-molecule state (messages, acquired data, simulated costs). Agents operate in two configurations: **Agent mode** (dynamic, sequential tool calls with state updates) and **Baseline mode** (static one-shot with all data provided). The dataset contains 530 validated molecules (150–500 Da) with authentic experimental data—¹H NMR, ¹³C NMR, MS—extracted from post-2025 literature via a human-in-the-loop pipeline, preserving real artifacts (noise, peak overlap, missing signals). A tool suite of 14 simulated instruments (e.g., `Measure_MW`, `Get_1H_NMR`) allows agents to request specific measurements. Final predictions are evaluated using structure accuracy (exact SMILES match), validity, Tanimoto similarity, formula conservation, calibration error (RMSCE), and efficiency metrics (average interaction rounds, accuracy per token).

## Key Results
- Maximum structure accuracy by any model (Gemini 3 Flash) is only 51.5%, with most models below 30% in Agent mode.
- Interactive evaluation reveals a bifurcation: some models (e.g., Qwen3 Max) improve significantly in Agent mode (+10.56%), while others (e.g., Kimi K2 Thinking) degrade (-9.25%), indicating divergent strategic planning capabilities.
- Efficiency metrics show widespread failure in resource-aware reasoning, with models exhibiting "interaction traps" (excessive redundant queries) or "premature commitment" (insufficient data gathering), and low formula conservation rates (e.g., DeepSeek v3.1 at 23.71%) reflecting neglect of mass-balance constraints.

## Why This Works (Mechanism)
1. **Interactive Paradigm exposes strategic planning deficits** by reframing elucidation as sequential decision-making under partial observability. Agents must execute a "Plan–Request–Reason" loop, forcing explicit information-seeking rather than passive pattern matching. Core assumption: scientific discovery is an active, iterative hypothesis-driven process.
2. **Authentic, noisy data** from literature preserves real experimental artifacts (noise, peak overlap, missing signals), testing robustness beyond synthetic benchmarks that overestimate capabilities.
3. **Simulated cost structure** creates economic constraints that evaluate efficiency and value-of-information assessment. Metrics like Accuracy per 1M Tokens quantify the trade-off between correctness and resource use, modeling real experimental constraints.

## Foundational Learning
- **Abductive Reasoning (Inference to the Best Explanation):** Needed because the core task is to infer the most probable molecular structure from observed spectral effects, not to apply rules or generalize. *Quick check:* Given C₈H₁₀O₂ with ¹H NMR: singlet δ 2.1 (3H), broad singlet δ 12.0 (1H), what single structural feature must be present, and what are two possible scaffold classes?
- **Constraint Satisfaction Problem (CSP):** Needed because elucidation is formally a CSP: the molecular structure is the variable assignment; spectral data and chemical rules are constraints. Acquiring new spectra adds constraints, narrowing solutions. *Quick check:* How does a ¹³C NMR showing 6 distinct signals for C₈H₁₀O₂ change possible structures? What specific constraint does this add?
- **Calibration and Metacognition:** Needed because agents must accurately gauge certainty to decide when to stop or seek more data. Poor calibration leads to overconfidence or inefficiency. *Quick check:* If a model predicts with 95% confidence but is wrong, and another predicts correctly with 60% confidence, which is more reliable for automation? What does a low RMSCE indicate?

## Architecture Onboarding
**Component map:** Agent (LLM) generates actions → Environment (State Machine) executes tool calls via Tool Suite → returns data and updates state → Agent reasons and repeats → terminates with FINAL_RESULT → Evaluator scores accuracy, validity, similarity, calibration, efficiency.

**Critical path:**  
1. Initialization: set sample_id, inject empty state.  
2. Acquisition Loop: agent calls tool; environment retrieves data from database; state updates.  
3. Reasoning Cycle: agent integrates new data, revises hypotheses, plans next step.  
4. Termination: agent outputs FINAL_RESULT; evaluator locks run and computes metrics.

**Design tradeoffs:**  
- Real data vs. scalability: Literature extraction is costly (530 molecules) but preserves authenticity; synthetic data would scale but lose noise.  
- Open-ended action space vs. control: 14 tools offer flexibility but produce diverse, hard-to-analyze trajectories; restricted sets would simplify but reduce ecological validity.  
- Outcome-based vs. process-based evaluation: Current metrics focus on final SMILES; analyzing reasoning quality requires separate process metrics or human annotation.

**Failure signatures:**  
- Hesitation Loop: high average rounds (>6) with low accuracy (<15%); redundant data requests without convergence.  
- Premature Commit: very low average rounds (<3.5) with low accuracy; early guess without core discriminative data.  
- Constraint Violator: low formula conservation (<50%); predicted SMILES ignores measured molecular formula.

## Open Questions the Paper Calls Out
1. **How to automatically assess intermediate reasoning quality?** Current evaluation is outcome-based; need fine-grained metrics for hypothesis–evidence coherence and action optimality, validated via expert annotations.  
2. **What causes the "scaffold vs. crucible" bifurcation?** Unclear whether differences stem from architecture, training data, or state maintenance; requires ablations and representation probing.  
3. **Do limitations generalize to other scientific domains?** Conclusions are limited to organic chemistry; analogous benchmarks in materials or genomics are needed to test transfer.  
4. **Can adaptive interaction protocols remediate deficits?** No existing methods directly train LLMs for cost-aware exploration; RL/imitation learning on MolQuest could close the gap.
