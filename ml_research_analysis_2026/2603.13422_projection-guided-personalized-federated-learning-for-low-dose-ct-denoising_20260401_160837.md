# Projection Guided Personalized Federated Learning for Low Dose CT Denoising

## Quick Facts
- **arXiv ID:** 2603.13422
- **Source URL:** https://arxiv.org/abs/2603.13422
- **Reference Count:** 40
- **Primary Result:** ProFed achieves state-of-the-art LDCT denoising by performing dual-level personalization in projection space, outperforming 11 federated baselines and SCAN-PhysFed by +1.42 dB PSNR on Mayo Clinic 2016.

## Executive Summary
ProFed introduces a personalized federated learning framework for low-dose CT denoising that addresses protocol-dependent noise heterogeneity across institutions. Unlike conventional image-space methods, it performs dual-level adaptation in the projection (sinogram) space, where noise originates. The method combines an anatomy-aware network (fusing image and synthetic report features) with a protocol-aware network (using Low-Rank Adaptation) and enforces multi-constraint projection losses (forward, backward, cycle consistency). On the Mayo Clinic 2016 dataset, ProFed achieves 42.56 dB (CNN) and 44.83 dB (Transformer) PSNR, generalizing to unseen client protocols with 39.17 dB PSNR. Ablations confirm that projection-space personalization alone contributes a +1.40 dB gain over image-space approaches.

## Method Summary
ProFed is a federated learning system for LDCT reconstruction that personalizes at both the anatomy and protocol levels within the projection domain. Each client possesses a local model with a shared encoder-decoder backbone and two adaptation modules: an anatomy-aware network that extracts patient-specific features from the CT image and a synthetic medical report (via BioBERT), and a protocol-aware network (LoRA) that conditions on scanner metadata (e.g., kVp, mAs). These are fused via a gated modulation to adjust the decoder's instance normalization. Training uses a composite loss: image reconstruction (L1), heteroscedastic noise modeling, and three projection-space consistency losses enforcing alignment with raw sinograms via differentiable Radon transforms. The server aggregates shared parameters (encoder, decoder, protocol net) weighted by uncertainty estimates from Monte Carlo dropout, while anatomy networks remain local.

## Key Results
- ProFed (CNN) achieves 42.56 dB PSNR and ProFed (Transformer) 44.83 dB PSNR on Mayo 2016, surpassing 11 federated baselines and SCAN-PhysFed by +1.42 dB.
- It generalizes to unseen client protocols with 39.17 dB PSNR, demonstrating robustness to distribution shift.
- Ablation shows projection-space personalization alone yields a +1.40 dB improvement over image-space personalization.

## Why This Works (Mechanism)

### Mechanism 1: Projection-Space Personalization
- **Claim:** Personalizing in projection (sinogram) space better separates protocol-dependent noise from anatomy than image-space methods because noise originates in raw CT measurements.
- **Mechanism:** In the sinogram, protocol noise (e.g., from dose variations) and anatomical structures exhibit distinct patterns across viewing angles. ProFed uses sinogram data for physics-based supervision via multi-constraint losses, anchoring reconstructions to physical measurements.
- **Break condition:** If sinogram measurements are corrupted, missing, or unreliable (e.g., hardware faults), projection-space losses fail, degrading performance.

### Mechanism 2: Dual Adaptation Networks
- **Claim:** Combining anatomy-aware (image + BioBERT on synthetic reports) and protocol-aware (LoRA on metadata) networks enables effective personalization to both patient-specific and scanner-specific variations.
- **Mechanism:** The anatomy network captures patient anatomy; the protocol network adapts to scanner settings. A gated modulation balances their contributions based on anatomy feature reliability.
- **Break condition:** Poor anatomy feature extraction (e.g., from ambiguous reports) causes misweighting in the gate, leading to suboptimal fusion.

### Mechanism 3: Multi-Constraint Projection Losses
- **Claim:** Forward, backward, and cycle consistency losses enforce alignment with CT measurements, providing stronger supervision than image-domain losses alone.
- **Mechanism:** Differentiable Radon transform and filtered backprojection compute: forward loss (match predicted sinogram to measured), backward loss (match reconstruction to back-projected data), cycle loss (ensure consistency under forward-backward projection).
- **Break condition:** If projection operators are implemented inaccurately or sinogram noise is extreme (ultra-low dose), losses may not correlate with image quality, causing overfitting to projections.

## Architecture Onboarding
- **Component map:** 
  LDCT image I → Encoder Eθ → latent z
  Protocol vector p → Protocol-aware Hβ (LoRA) → (γp, βp)
  Anatomy feature a (from I + synthetic report + BioBERT) → Anatomy-aware Hα → (γa, βa)
  Gating FC_g(a) → g
  Fuse: γ = g·γa + (1-g)·γp, β = g·βa + (1-g)·βp → modulate decoder
  Decoder Dϕ(modulated) → reconstructed image Î
  Forward: RΘ(Î) vs sinogram R; Backward: RΘ†(R) vs Î; Cycle: RΘ(RΘ†(R)) vs R
  Uncertainty: MC-dropout on validation set → uk
- **Critical path:**
  1. Offline precompute anatomy features: extract image features with RED-CNN/Uformer, generate synthetic reports via BLIP, encode with BioBERT, fuse via MLP.
  2. Per federated round: server broadcasts global model (Eθ, Dϕ, Hβ); each client trains locally for E epochs using L_total = λ_recon L_recon + λ_het L_het + λ_proj(λ_f L_forward + λ_b L_backward + λ_c L_cycle).
  3. Clients compute uncertainty uk via MC-dropout; server aggregates shared layers with weights wk ∝ Nk/(uk+ε).
- **Design tradeoffs:**
  - Projection losses add computational cost (differentiable transforms) but improve physics-guided supervision.
  - LoRA minimizes protocol adaptation overhead (rank r=8).
  - Gated fusion balances reliability but introduces hyperparameters (gate structure, weighting).
  - Uncertainty weighting requires validation data per client.
- **Failure signatures:**
  - Poor performance on clients with incomplete protocol metadata → protocol-aware network weakness.
  - High uncertainty weights for some clients → domain shift not handled by current personalization.
  - Discrepancy between projection losses and PSNR → inaccurate projection operators or extremely noisy sinograms.
- **First 3 experiments:**
  1. **Benchmark comparison:** Run ProFed and 11 baselines on Mayo 2016 (8 training clients), report PSNR/SSIM per client and average.
  2. **Ablation study:** Sequentially remove projection domain, dual adaptation components, and uncertainty weighting to quantify contributions (Tables 4, 5).
  3. **Unseen client generalization:** Evaluate on 4 new protocol configurations and unseen patients to test robustness to distribution shift (Table 3).

## Open Questions the Paper Calls Out
- **Open Question 1:** How can protocol parameters be inferred directly from sinogram measurements without relying on metadata?
  - **Basis:** Limitations state future work could explore more robust protocol inference directly from sinogram measurements.
  - **Why unresolved:** ProFed depends on DICOM header metadata, which may be incomplete or inconsistently formatted across institutions.
  - **Resolution evidence:** Develop a sinogram-based protocol inference module integrated into ProFed and evaluate on datasets with simulated missing/corrupted metadata.
- **Open Question 2:** Does a self-supervised anatomy encoder trained on CT volumes capture finer anatomical variations compared to the BioBERT-based approach?
  - **Basis:** Limitations suggest a dedicated self-supervised encoder trained directly on CT volumes could capture finer variations.
  - **Why unresolved:** Current method uses BioBERT on synthetic descriptions from image captioning, which may not fully represent complex 3D anatomy.
  - **Resolution evidence:** Replace BioBERT pathway with a self-supervised encoder (e.g., contrastive learning on CT volumes) and compare reconstruction quality and generalization.
- **Open Question 3:** How robust is ProFed to variations in sinogram data quality, such as noise, sparsity, or missing projections common in real-world CT acquisitions?
  - **Basis:** Inferred; ProFed assumes access to clean sinograms but does not test under degraded sinogram conditions.
  - **Why unresolved:** Evaluation uses Mayo dataset with presumably high-quality sinograms; real-world scenarios involve different scanner models and hardware issues.
  - **Resolution evidence:** Conduct experiments with intentionally degraded sinograms (e.g., Poisson noise, reduced angles) and measure PSNR/SSIM degradation trends vs. baselines.
- **Open Question 4:** Can ProFed be adapted for unpaired or self-supervised learning settings where only low-dose CT images are available, without full-dose references or sinogram measurements?
  - **Basis:** Inferred; ProFed relies on paired LDCT/NDCT data and sinograms but mentions compatibility with self-supervised extensions.
  - **Why unresolved:** Paired data is scarce in federated medical imaging, and sinogram sharing may be restricted due to privacy or proprietary formats.
  - **Resolution evidence:** Modify ProFed to use unpaired losses (e.g., image-cycle consistency, adversarial training) and evaluate on datasets with only LDCT scans.

## Limitations
- Projection operator implementation (differentiable Radon/backprojection) is underspecified, risking replication errors and numerical instability.
- Key hyperparameters (loss weights, MC-dropout settings, LoRA dimensions) are not reported, hindering performance reproducibility.
- Anatomy features rely on synthetic reports from image captioning, which may not capture real clinical text diversity and could introduce bias.
- Evaluation is confined to the Mayo Clinic 2016 dataset; generalizability to other CT systems and patient populations is unverified.
- Neighbor literature provides minimal direct support for the core mechanism (projection-space personalization), as most related work targets PET or general denoising.

## Confidence
- **Projection-space personalization superiority:** Medium. Internal ablation shows +1.40 dB gain, but external validation is lacking and results depend on accurate physics-based operators.
- **Dual adaptation (anatomy + protocol) effectiveness:** Medium. Ablation confirms additive benefit, but gating robustness to noisy anatomy features is not fully explored.
- **Multi-constraint projection losses:** Medium. Incremental improvement in ablation is shown, yet sensitivity to operator fidelity and extreme low-dose noise is unclear.
- **Uncertainty-weighted aggregation:** Low–Medium. Not directly ablated; contribution is confounded with other components and requires validation.
- **State-of-the-art performance and generalization:** High on Mayo 2016, but confidence drops for broader generalization due to single-dataset evaluation.

Report mean PSNR ± std over 3 random seeds to establish robust ranges that stay within 0.5 dB of reported numbers.

Compare PSNR/SSIM against the top 3 baselines from the paper; a consistent >1 dB gap would strengthen the claim of protocol-agnostic personalization.
