# Cross-Modal Computational Model of Brain-Heart Interactions via HRV and EEG Feature

## Quick Facts
- arXiv ID: 2601.06792
- Source URL: https://arxiv.org/abs/2601.06792
- Reference count: 13
- Primary result: Cross-modal regression from ECG features to EEG features yields only 40% multiclass accuracy, indicating ECG cannot surrogate EEG for cognitive load monitoring; however, unimodal ECG classification with synthetic HRV achieves high accuracy (up to 96.9%).

## Executive Summary
This study investigates whether ECG-derived features can replace EEG for cognitive load monitoring. Using a cross-modal XGBoost regression model to map HRV and Catch22 ECG features to EEG-derived cognitive features, the authors find that while unimodal ECG classification (with synthetic HRV augmentation) performs well (up to 96.9% accuracy), the cross-modal regression fails (40% accuracy, near chance). This suggests ECG and EEG capture largely orthogonal information regarding brain states. Synthetic HRV improves robustness within the ECG modality but does not bridge the representational gap. The binary task (listening vs. memory) remains challenging even with EEG features, highlighting limitations of the feature sets for that contrast.

## Method Summary
The analysis uses OpenNeuro ds003838, containing synchronized 64-channel EEG and ECG from 86 subjects performing a digit-span memory task (5/9/13-digit loads and passive listening). After preprocessing (filtering, epoching, artifact rejection), ECG features include time-domain HRV metrics (meanNN, SDNN, RMSSD, SD1, SD2) and Catch22 descriptors. EEG features include Catch22 per channel and spectral bandpower. Synthetic HRV is generated via PSV-SDG, which modulates an IPFM model with sympathetic/vagal oscillators conditioned on real ECG's sliding-window SD1/SD2. For unimodal ECG classification, classifiers (RF, XGB) are trained on combined real and synthetic ECG features. For cross-modal regression, an XGBoost regressor maps ECG features to EEG Catch22 features; then an EEG-trained classifier predicts memory load from the regressed features. Evaluation uses multiclass (3 loads) and binary (listening vs memory) accuracy.

## Key Results
- Unimodal ECG classification (real+synthetic HRV+Catch22) achieved high multiclass accuracy: Random Forest 0.933, XGBoost 0.969.
- Cross-modal regression (ECG → EEG feature space) followed by classification yielded only 40% multiclass accuracy, marginally above chance (33%).
- Binary classification (listening vs. memory) remained limited for both EEG (max 0.609) and ECG (max 0.556), indicating the contrast is not strongly encoded.

## Why This Works (Mechanism)
The study reveals three key mechanisms. First, the failure of cross-modal regression (40% accuracy) demonstrates that ECG features cannot be mapped into the EEG-representable cognitive feature space for memory load discrimination; this suggests EEG and ECG capture largely orthogonal information about brain states. Second, synthetic HRV generated by PSV-SDG enriches the ECG feature distribution and improves unimodal ECG classification robustness, but since the synthesis is conditioned only on autonomic statistics (SD1/SD2) and not on EEG features, it does not aid cross-modal mapping. Third, the persistently low binary classification accuracy even with EEG features implies that the specific contrast between passive listening and any memory task may not be strongly represented in standard spectral or Catch22 features, pointing to a potential task definition or feature limitation.

## Architecture Onboarding
**Component map**: Data (OpenNeuro ds003838) -> Preprocessing (MNE/NeuroKit2: filtering, epoching, artifact rejection) -> Feature Engineering (ECG: HRV + Catch22; EEG: Catch22 + bandpower) -> Synthetic Data (PSV-SDG generation) -> Cross-Modal Pipeline (XGBoost regression: ECG -> EEG features; then classification) -> Evaluation (accuracy, F1, confusion).
**Critical path**: Feature Extraction → Cross-Modal Regression → Classification.
**Design tradeoffs**: 
- Used tree-based models (RF, XGB) for interpretability and performance on small tabular data; a deep network might capture complex mappings but risks overfitting.
- Kept HRV feature set small (5 dimensions) to avoid curse of dimensionality, possibly starving the model of information.
- Synthetic data augmented input (ECG features) rather than guiding regression target, which helped unimodal ECG but not cross-modal.
**Failure signatures**:
- Cross-modal multiclass accuracy ~40% (chance 33%), with class-specific recall as low as 0.08 for Nine-Memory.
- Binary task accuracy max ~0.61 even with EEG, indicating the contrast is not well-separated.
**First 3 experiments**:
1. Replicate unimodal ECG classification: Train RF/XGB on combined real+synthetic ECG features for 3-class memory load; expect RF ~0.93, XGB ~0.97.
2. Replicate cross-modal regression: Train XGB regressor from HRV to EEG Catch22; then classify using EEG-trained RF; expect ~40% accuracy.
3. Ablation: Regression target dimensionality - instead of 22-dim EEG Catch22, regress to a single meta-feature (e.g., band-power ratio) to test if simpler target improves cross-modal accuracy.

## Open Questions the Paper Calls Out
1. What alignment techniques (e.g., CCA, contrastive learning) can effectively bridge the representational gap between ECG HRV and EEG cognitive features to improve cross-modal classification accuracy above chance?
2. Can PSV-SDG be modified to produce synthetic data that specifically enhances cross-modal mapping performance to EEG feature space, rather than only improving unimodal robustness?
3. Does the low cross-modal accuracy generalize across diverse cognitive load paradigms beyond memory tasks, such as sustained attention or affective tasks?
4. Which specific EEG catch22 features are most poorly predicted by ECG HRV features, and can additional ECG-derived metrics or feature selection improve their prediction accuracy?

## Limitations
- The cross-modal regression approach fails to capture EEG-representable cognitive information from ECG features, limiting the feasibility of ECG as an EEG surrogate.
- Binary cognitive state classification remains weak even with EEG, suggesting the task definition or feature sets may not align with physiological distinctions.
- The study relies on a single dataset (ds003838) focused on digit-span memory; generalizability to other paradigms or populations is untested.

## Confidence
| Claim | Confidence |
|-------|------------|
| ECG features cannot be used as a surrogate for EEG in cognitive load monitoring (based on cross-modal regression) | High |
| Synthetic HRV augmentation improves unimodal ECG classification robustness | High |

## Next Checks
1. Implement Canonical Correlation Analysis (CCA) or contrastive learning in the cross-modal pipeline and evaluate if multiclass accuracy significantly exceeds 40%.
2. Redesign PSV-SDG with a cross-modal loss (e.g., minimize feature-space discrepancy to EEG features) and test if synthetic HRV improves cross-modal accuracy.
3. Replicate the entire pipeline on at least two additional public datasets with different cognitive tasks (e.g., n-back, Stroop) to assess consistency of the orthogonality finding.
