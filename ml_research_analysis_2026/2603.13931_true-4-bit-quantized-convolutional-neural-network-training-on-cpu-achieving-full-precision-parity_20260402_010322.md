# True 4-Bit Quantized Convolutional Neural Network Training on CPU: Achieving Full-Precision Parity
## Quick Facts
- arXiv ID: 2603.13931  
- Source URL: https://arxiv.org/abs/2603.13931  
- Reference count: 18  
- Primary result: Achieves 92.34% test accuracy on CIFAR-10 with a VGG-style model using true 4-bit weights, matching full-precision baseline within 0.16% and attaining 8× memory compression.

## Executive Summary
Training deep neural networks from scratch at true 4-bit weight precision on commodity CPUs without sacrificing accuracy has been a long‑standing challenge. Existing solutions often depend on GPUs or suffer large performance gaps. This paper introduces a method that combines tanh‑based soft weight clipping, symmetric quantization with dynamic per‑layer scaling, and straight‑through estimators, all implemented within standard PyTorch operations. On CIFAR‑10, a VGG‑style model (~3.25M parameters) reaches 92.34% test accuracy, essentially matching the full‑precision baseline of 92.5% (gap 0.16%), while maintaining exactly 15 unique weight values per layer and reducing memory by 8×. The approach also yields 70.94% on CIFAR‑100 and has been validated on a OnePlus 9R smartphone (83.16% in 6 epochs), demonstrating that high‑accuracy, low‑memory training is feasible on everyday CPUs.

## Method Summary
The method quantizes weights to 4 bits during training using a symmetric grid of 15 levels. The scaling factor *s* for each layer is computed dynamically as *s = max(|W|)/7* based on current full‑precision weights. After every optimizer step, weights are passed through a smooth tanh‑based clipping: *W ← 3.0·tanh(W/3.0)*, which bounds magnitudes without hard discontinuities. Gradients flow through the discrete quantization operation via the straight‑through estimator (STE). Training uses AdamW (weight decay 5e‑4, gradient clipping max norm 0.5) and a cosine annealing learning rate schedule over 150 epochs, together with standard CIFAR data augmentation (random crop, horizontal flip, normalization). All operations are CPU‑friendly and rely only on vanilla PyTorch.

## Key Results
- CIFAR‑10 VGG‑style: 92.34% test accuracy (full‑precision baseline 92.5%, gap 0.16%) with exactly 15 unique weight values per layer.  
- CIFAR‑100: 70.94% test accuracy.  
- Memory compression: 8× over FP32; mobile validation on OnePlus 9R: 83.16% accuracy in 6 epochs.

## Why This Works (Mechanism)
The combination of soft clipping, dynamic scaling, and STE enables stable optimization under aggressive 4‑bit constraints. Tanh clipping replaces hard thresholding with a smooth nonlinearity, preserving gradient magnitude near the bound and preventing abrupt changes to the weight distribution that would otherwise destabilize the dynamic scale factor. Dynamic per‑layer scaling continuously adapts the quantization step size to the current range of weights, ensuring that the 15‑level grid is fully utilized and avoiding saturation (many weights mapping to the same level). The STE provides an error‑free gradient path for updating full‑precision weights despite the discrete forward pass. Together, these mechanisms maintain a near‑continuous optimization trajectory that converges to a solution nearly indistinguishable from full‑precision training.

## Foundational Learning
1. **Quantization-Aware Training (QAT)**  
   Simulates low‑precision arithmetic during training to adapt model parameters to discrete values.  
   *Why needed*: Directly quantizing a full‑precision model causes large accuracy drops due to quantization errors; QAT allows the model to learn weights resilient to discretization.  
   *Quick check*: Perform a forward pass with quantized weights; loss should not increase dramatically compared to full‑precision.

2. **Straight‑Through Estimator (STE)**  
   Backpropagates gradients through non‑differentiable operations (e.g., rounding) by substituting the identity gradient.  
   *Why needed*: Rounding has zero gradient almost everywhere; STE supplies a surrogate gradient to update full‑precision weights.  
   *Quick check*: Compute ∂loss/∂W for a quantized weight tensor; gradients should be non‑zero and of reasonable magnitude.

3. **Dynamic Per-Layer Scaling**  
   Adjusts quantization step size per layer: *s = max(|W|)/7*.  
   *Why needed*: A fixed global scale would either clip large weights or underuse levels for small weights, harming accuracy; dynamic scaling adapts to each layer’s distribution.  
   *Quick check*: Monitor the number of distinct quantized weight values; it should be close to 15 for every layer throughout training.

4. **Tanh-Based Soft Weight Clipping**  
   Applies *W ← α·tanh(W/α)* (α=3) after each optimizer step, smoothly bounding weights to [-α, α].  
   *Why needed*: Hard clipping causes a discontinuous gradient at the boundary, destabilizing training under aggressive quantization; tanh clipping yields a gradual gradient decay.  
   *Quick check*: Inspect weight histograms; extreme values beyond ±α should be absent, and the distribution should be concentrated within the bound.

5. **Symmetric Quantization**  
   Uses a zero‑centered grid with equal positive and negative ranges.  
   *Why needed*: Simplifies implementation and avoids asymmetric bias; well‑suited for weights after tanh clipping which naturally become symmetric.  
   *Quick check*: Verify that for every positive quantization level there is a corresponding negative level.

## Architecture Onboarding
- **Component map**:  
  Data Augmentation (random crop, flip, normalization) → Model (Conv2d + BatchNorm2d + ReLU) with Quantized Weights (4‑bit symmetric, dynamic per‑layer scale) → Loss (Cross‑entropy) → Backward (STE through quantization) → Optimizer (AdamW) → Tanh Clipper (post‑step) → Repeat.

- **Critical path**:  
  Forward pass uses quantized weights based on current full‑precision weights and dynamic scale; loss computed; gradients backpropagated via STE; optimizer updates full‑precision weights; tanh clipping applied before next iteration. The ordering is strict—e.g., clipping must occur after the optimizer step, not before.

- **Design tradeoffs**  
  - *Soft vs hard clipping*: Tanh clipping provides smoother gradients and better stability at the cost of slightly altered weight magnitudes near the bound; hard clipping is simpler but prone to gradient shocks.  
  - *Dynamic per‑layer scaling*: Improves accuracy by adapting to each layer’s range, with negligible overhead (computing max(|W|) per forward).  
  - *4‑bit symmetric grid*: Maximizes compression but reduces representational capacity; may not generalize to all architectures.

- **Failure signatures**  
  - Fewer than 15 distinct weight values in a layer → scaling or clipping mis‑implemented.  
  - NaN loss → gradient explosion, possibly from omitted tanh clipping, too high learning rate, or missing gradient clipping.  
  - Accuracy drop aligned with SGDR restarts (especially on CIFAR‑100) → scheduler‑induced overshoot; consider monotonic cosine decay.  
  - Large train‑test accuracy gap → overfitting; may need stronger augmentation or weight decay.

- **Exactly 3 first experiments**  
  1. *Quantization sanity check*: After 10 epochs, extract weights from each convolutional layer, count unique values; must be exactly 15 per layer.  
  2. *Stability check*: Train with the default learning rate and with a reduced learning rate (e.g., 0.1×); plot loss curves to ensure smooth convergence without NaNs for both.  
  3. *Baseline comparison*: Complete 150 epochs on CIFAR‑10 and report final test accuracy; expected ≥92.0% (within reported variation).
