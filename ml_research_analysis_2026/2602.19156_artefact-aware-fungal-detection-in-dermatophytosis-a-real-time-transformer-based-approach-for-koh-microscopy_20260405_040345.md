# Artefact-Aware Fungal Detection in Dermatophytosis: A Real-Time Transformer-Based Approach for KOH Microscopy

## Quick Facts
- **arXiv ID**: 2602.19156
- **Source URL**: https://arxiv.org/abs/2602.19156
- **Reference count**: 38
- **Primary result**: An artefact-aware RT-DETR model detects fungal hyphae in KOH microscopy with 97.37% recall and 100% image-level sensitivity, distinguishing hyphae from confounding debris.

## Executive Summary
This study addresses a key challenge in dermatophytosis diagnosis: automated detection of fungal hyphae in potassium hydroxide (KOH) microscopy images cluttered with clinical artefacts (e.g., skin debris, bubbles). The authors develop an artefact-aware transformer model, RT-DETR, trained on 2,540 high-resolution, multi-class annotated images to explicitly differentiate hyphae from non-hyphal objects. The system achieves near-perfect recall at the object level and flawless sensitivity at the image level across 254 test samples, demonstrating robustness in low-contrast, artefact-rich fields. While promising as a real-time screening tool, the work relies on a single-source dataset without external validation or latency benchmarks, limiting immediate clinical generalizability.

## Method Summary
The authors curated a dataset of 2,540 high-resolution KOH microscopy images, annotating both fungal hyphae and confounding artefacts (e.g., hairs, fibres, bubbles) with bounding boxes. They adapted the Real-Time Detection Transformer (RT-DETR), a transformer-based object detector, for this binary classification task. The model was trained to jointly detect hyphae (positive) and various artefacts (negative contexts), enabling it to learn distinguishing features amidst clutter. Training employed standard object detection losses (classification, box regression) with data augmentation to improve robustness. Inference outputs object-level detections, which are aggregated for image-level positive/negative diagnosis.

## Key Results
- **Object-level detection**: Recall 0.9737, precision 0.8043, AP@0.50 93.56% on test set.
- **Image-level diagnosis**: 100% sensitivity (all positives detected), 98.8% accuracy over 254 test samples, with zero false negatives.
- **Robustness**: Model maintains performance in low-contrast fields and amidst diverse artefacts, though precision is moderate, indicating some false positives from ambiguous debris.

## Why This Works (Mechanism)
The paper does not explicitly detail the internal mechanism beyond stating the model's artefact-awareness stems from multi-class training. The RT-DETR architecture likely uses transformer attention to weigh relevant image regions, while learning to separate hyphae (thin, septated, branching structures) from artefacts (varied textures, shapes) through discriminative feature representation. The high recall suggests the model effectively learns hyphae features, while moderate precision indicates residual confusion with certain artefacts not fully captured in training.

## Architecture Onboarding
**Component map**: Input Image -> CNN Backbone -> Transformer Encoder-Decoder -> Detection Head (Class/Box FFN) -> Hyphae/Artefact Bounding Boxes

**Critical path**: Transformer decoder cross-attention over encoder features using learned object queries, refined iteratively for final classification and box regression.

**Design tradeoffs**: RT-DETR prioritizes inference speed over peak accuracy; artefact-aware training trades some precision for high recall. The model may sacrifice specificity to avoid missing hyphae.

**Failure signatures**: (1) False negatives in extremely low-contrast or overlapping hyphae; (2) False positives on unseen artefacts (e.g., novel fibre types); (3) Degraded performance with out-of-distribution microscope optics or staining.

**First three experiments**:
1. **Cross-device robustness**: Test on images from 3+ different microscope models to quantify optical variability impact.
2. **Lighting/stress variation**: Evaluate under simulated poor illumination and defocus to probe low-contrast sensitivity.
3. **Artefact hold-out**: Remove one artefact class from training, then test on that class to measure generalisation to unseen debris.

## Limitations
- Single-source dataset (2,540 images) limits generalisability to diverse clinical settings.
- Image-level evaluation on only 254 test samples may inflate performance; perfect sensitivity is atypical and may not replicate.
- No external validation; real-world clinical performance remains unevidenced.
- Real-time claim unsupported by latency or throughput measurements.
- Artefact variety in training likely insufficient to cover all possible clinical debris.
- No comparison with human experts or confidence intervals, reducing clinical interpretability.

## Confidence

- **Image-level sensitivity** (100%) and **accuracy** (98.8%): **Low** – unusually perfect results on small test set.
- **Real-time operation**: **Low** – no empirical timing provided.
- **Robustness to artefacts/low contrast**: **Medium** – claimed but not stress-tested externally.
