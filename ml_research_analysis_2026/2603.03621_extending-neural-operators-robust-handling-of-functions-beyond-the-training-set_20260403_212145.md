# Extending Neural Operators: Robust Handling of Functions Beyond the Training Set

## Quick Facts
- **arXiv ID:** 2603.03621
- **Source URL:** https://arxiv.org/abs/2603.03621
- **Reference count:** 40
- **Primary result:** Kernel-based operator extension enables neural operators to handle unseen input functions on manifolds, achieving stable H¹ errors (5–17%) with Matérn/Wendland kernels; Gaussian kernels fail due to ill-conditioning.

## Executive Summary
Neural operators learn mappings between function spaces but typically generalize poorly to inputs outside the training distribution. This paper introduces a framework that extends a pre-trained neural operator to arbitrary input functions using kernel approximation in a Reproducing Kernel Hilbert Space (RKHS). The method expresses any target function as a linear combination of kernel basis functions centered at sampled points, then applies the trained operator to each basis and sums the results. Theoretical error bounds link the extension accuracy to kernel approximation error and operator learning error. The authors analyze kernel choices (Matérn, Wendland, Gaussian), showing that smoothness-equivalent kernels yield well-conditioned systems and stable performance, while Gaussian kernels suffer from severe ill-conditioning. Additionally, a separable factorization of kernel integrals reduces computational cost, enabling Sobolev-supervised training on large point clouds. Experiments on elliptic PDEs over 2D manifolds confirm the theory: Matérn and Wendland kernels achieve relative H¹ errors of 5–17% with coefficient ℓ¹-norms below 10³ and Gram matrix condition numbers below 10⁶, whereas Gaussian errors blow up as resolution increases.

## Method Summary
The core method consists of two stages. First, a neural operator \(S_{\theta,k}\) is trained to map radial basis kernel functions \(k(\cdot,x_i)\) (e.g., Matérn, Wendland) to their corresponding pseudo-Green’s functions \(g(\cdot,x_i)\), i.e., solutions of \(L g = k\). The operator uses a separable geometric neural network architecture with Sobolev loss to supervise both function values and surface gradients. Second, for a new input function \(f\) (e.g., a source term for an elliptic PDE), the algorithm samples points \(X\) on the manifold, then solves a regularized kernel system \((A+\lambda I)\alpha = f(X)\) to obtain coefficients \(\alpha_i\) such that \(f \approx \sum_i \alpha_i k(\cdot,x_i)\). The extended operator output is \(\tilde{u}(x) = \sum_i \alpha_i S_{\theta,k}[k(\cdot,x_i)](x)\). Manifolds are handled by restricting the ambient kernel to the surface; the theory quantifies a smoothness penalty of \((d-m)/2\). Separable factorization of the kernel \(\kappa(x,y)\approx k_1(x)k_2(y)\) reduces the computational complexity of integral layers from \(O(N^2)\) to \(O(N)\), making large-scale training feasible.

## Key Results
- Extension accuracy: Relative H¹ errors of 5%–17% across manifold test cases using Matérn and Wendland kernels.
- Kernel choice matters: Matérn and Wendland yield well-conditioned Gram matrices (condition numbers <10⁶) and coefficient ℓ¹-norms <10³; Gaussian kernels exhibit exploding condition numbers (>10¹¹) and error blowup as resolution increases.
- Separable factorization enables efficient Sobolev training with >10× speedup and memory reduction, allowing operation on point clouds with thousands of points.

## Why This Works (Mechanism)
The extension’s success rests on three pillars.

1. **Kernel superposition leverages linearity.** The trained neural operator \(S_{\theta,k}\) is linear in its input because it was trained on kernel functions. Using the representer theorem, any \(f\) in the RKHS \(\mathcal{H}^k\) can be approximated as \(f(x) \approx \sum_i \alpha_i k(x,x_i)\). Then \(S_{\theta,k}[f] \approx \sum_i \alpha_i S_{\theta,k}[k(\cdot,x_i)]\). This extends the operator to any \(f \in \mathcal{H}^k\) provided (a) the true operator \(S\) is bounded (\(\|S(f)\|_{\mathcal{H}^1} \le C_1 \|f\|_{\mathcal{H}^1}\)) and (b) the neural operator accurately approximates \(S\) on each kernel (\(\|S_{\theta,k}[k(\cdot,x)] - S[k(\cdot,x)]\|_{\mathcal{H}^1} < \delta\)). Theorem 1.1 formalizes this: \(\|S^e[f]-S[f]\|_{\mathcal{H}^1} \le C_1\epsilon + C_2\delta\). The \(\delta\)-term dominates when \(\|\alpha\|_{\ell^1}\) is large, as observed with Gaussian kernels (Table 3).

2. **Kernel choice controls smoothness via native Sobolev spaces.** The native space of a kernel determines which function derivatives are stably approximated. Matérn (\(k(x,y)=\sum_{i=0}^{\nu} a_i (\|x-y\|/\sigma)^\nu B_{\nu-i}(\|x-y\|/\sigma)\)) and Wendland kernels have native spaces norm-equivalent to Sobolev spaces \(\mathcal{H}^s\) (Table 1). Consequently, for sufficiently smooth \(f\), interpolation errors for derivatives decay with the fill distance \(h_{X_N}\): \(\|s_\lambda^{(h)}-f\|_{\mathcal{H}^{|a|}} \le \tilde{C} h_{X_N}^{\ell-|a|} \|f\|_{\mathcal{H}^k}\) (Theorem 2.1). On an \(m\)-dimensional manifold embedded in \(\mathbb{R}^d\), restricting an ambient kernel reduces effective smoothness by \((d-m)/2\) (Theorem 1.2). Gaussian kernels lack Sobolev equivalence, leading to severe ill-conditioning and large gradient errors, especially at high resolution (Table 6).

3. **Separable factorization reduces computational cost.** The integral operator layers in geometric neural operators involve pairwise interactions, costing \(O(N^2)\). By approximating \(\kappa(x,y) \approx k_1(x)k_2(y)\), the computation factorizes into node-wise gather-scatter operations, reducing cost to \(O(N)\). Combined with Sobolev loss that enforces gradient accuracy (Equation 48), this yields efficient training: a 10× speedup on an A40 GPU and the ability to handle \(N=5,000\) points (Section 4.1). The approach remains accurate so long as the true kernel integral is well-approximated by a separable product; strong directional dependencies could degrade performance.

## Foundational Learning
- **Reproducing Kernel Hilbert Space (RKHS)**  
  *Why needed:* Guarantees that the minimizer of the kernel ridge regression problem lies in the span of kernel functions at data points, enabling finite expansions for function approximation. This underpins the kernel approximation step \(f \approx \sum_i \alpha_i k(\cdot,x_i)\).  
  *Quick check:* "Why does \(\min_{s\in\mathcal{H}^k} \sum (f(x_i)-s(x_i))^2 + \lambda\|s\|_{\mathcal{H}^k}^2\) yield a solution of the form \(\sum_i \alpha_i k(x,x_i)\)?" (Answer: Representer theorem.)

- **Sobolev Spaces \(\mathcal{H}^s\)**  
  *Why needed:* They characterize the smoothness required for derivative error bounds (Theorem 2.1/2.2) and are tied to kernel Fourier decay. The theory links kernel parameters (e.g., Matérn \(\nu\)) to Sobolev orders, ensuring that both function values and gradients are controlled by sampling density.  
  *Quick check:* "How does the Sobolev exponent \(s\) relate to the kernel’s Fourier decay \(\hat{\Phi}(\omega) \sim (1+\|\omega\|^2)^{-s}\)?" (Answer: The kernel is the inverse Fourier transform of a function decaying like \((1+\|\omega\|^2)^{-s}\).)

- **Neural Operator Architecture**  
  *Why needed:* The baseline operator \(S_{\theta,k}\) (Equation 1) comprises lifting (\(P\)), pointwise MLPs (\(\sigma_i, W_i\)), integral layers (\(K_i\)), and projection (\(Q\)). Understanding these components is essential to see where the kernel superposition fits: the trained operator acts on kernel functions to produce pseudo‑Green’s functions.  
  *Quick check:* "In Equation 1, what is the purpose of each component \(P\), \(\sigma_i\), \(W_i\), \(K_i\), and \(Q\)?" (Answer: \(P\) lifts the input to a latent space; \(\sigma_i,W_i\) are local MLPs; \(K_i\) performs integral convolutions; \(Q\) projects to output space.)

## Architecture Onboarding
- **Component map:**  
  New input \(f\) → Sample points \(X\) on manifold → Solve regularized kernel system \((A+\lambda I)\alpha = f(X)\) → Obtain coefficients \(\alpha_i\) → Extender: query pre‑trained \(S_{\theta,k}\) on each kernel \(k(\cdot,x_i)\) and sum → Output \(\tilde{u}\) on evaluation points.  
  Preprocessing: Manifold point clouds → compute local metric \(g_{ij}\), tangent basis → restrict kernels to manifold.

- **Critical path:**  
  1. Train \(S_{\theta,k}\) on dataset \(\{(k(\cdot,x_i), S[k(\cdot,x_i)])\}_{i=1}^{N_{\text{train}}}\).  
  2. For new \(f\), choose evaluation points \(X\) (any resolution).  
  3. Solve \((A+\lambda I)\alpha = f(X)\) with \(A_{ij}=k(x_i,x_j)\).  
  4. Compute \(\tilde{u}(x)=\sum_i \alpha_i S_{\theta,k}[k(\cdot,x_i)](x)\).  
  5. Optionally compute surface gradients \(\nabla_{\mathcal{M}}\tilde{u}\) via autograd through projection \(Q_\theta\).

- **Design tradeoffs:**  
  - *Kernel selection:* Matérn/Wendland provide better conditioning and gradient control than Gaussian; larger \(\sigma\) improves conditioning but may oversmooth and reduce locality.  
  - *Sampling density:* More points \(N\) reduce approximation error \(\epsilon\) but increase Gram matrix condition number and cost; regularization \(\lambda\) must be tuned.  
  - *Separable vs edge‑based:* Separable factorization reduces memory (\(O(N)\) vs \(O(N^2)\)) and speeds training, but may limit expressiveness for anisotropic kernels.  
  - *Manifold handling:* Using an ambient kernel restriction avoids designing intrinsic kernels but incurs a smoothness penalty \((d-m)/2\); sampling must be dense in the intrinsic metric.

- **Failure signatures:**  
  - \(\|\alpha\|_{\ell^1}\) exploding with \(N\) (e.g., Gaussian kernels, Table 3) → ill‑conditioning due to too small \(\sigma\) or inappropriate kernel.  
  - H¹ error dominated by gradient term (Tables 5–6) → kernel not smooth enough or manifold sampling too sparse (fill distance large).  
  - Training loss stagnates → neural operator capacity insufficient or kernel training set not diverse.  
  - Out‑of‑memory during training → not using separable factorization for \(N > 5,000\); consider subsampling edges or switching to node‑based operations.

- **First experiments:**  
  1. **Baseline replication:** Train on manifold B (sphere) with Matérn \(\nu=3/2\), \(\sigma=10\), \(N_{\text{train}}=5,000\); evaluate extension H¹ error for \(N_{\text{test}}=10,000\). Expect \(\approx 6\%\) error (Table 2).  
  2. **Kernel conditioning test:** Build Gram matrices for Gaussian, Matérn (\(\nu=3/2\)), Wendland (\(k=2\)) at \(N = 1250, 2500, 5000, 10000\). Record condition numbers; expect Gaussian \(>10^{11}\), others \(<10^4\) (Table 4).  
  3. **Separable efficiency benchmark:** Compare wall‑clock time and memory for edge‑based vs separable architectures during training on manifold A with \(N=5,000\). Expect >10× speedup and ability to fit in GPU memory (Section 4.1).

## Open Questions the Paper Calls Out
- **Nonlinear operators:** How can the kernel‑based extension be generalized to nonlinear operators? The current method relies on linearity; no theory or experiments for nonlinear cases are provided.  
- **Systematic hyperparameter selection:** What method exists for choosing kernel type and bandwidth to guarantee stability and accuracy across diverse manifolds? Selection is currently ad‑hoc.  
- **Theoretical bounds under weaker assumptions:** Do the error bounds (Theorems 1.1, 1.2) hold for unbounded operators or kernels whose native spaces are not Sobolev‑equivalent? Many physical operators violate these assumptions.  
- **Robustness to real‑world point clouds:** How does the method perform on noisy, incomplete, or unevenly sampled point clouds? Experiments so far use only clean synthetic manifolds.

## Limitations
- Exact manifold geometries (shapes A, B, C) and point‑cloud sampling procedures are unspecified, hindering exact replication.  
- Surface gradient implementation details (local coordinate charts, GMLS parameters) are missing; ∇ₘ errors may vary with implementation.  
- Theoretical bounds assume smooth embeddings and uniform sampling; performance on irregular or sparse point clouds is not fully explored.  
- Separable factorization’s accuracy for non‑separable or strongly anisotropic kernels is not evaluated; potential expressiveness loss remains.

## Confidence
- **Kernel superposition extension:** **High** – The error bound \(\|S^e[f]-S[f]\|_{\mathcal{H}^1} \le C_1\epsilon + C_2\delta\) is derived and strongly supported by empirical results across kernels, resolutions, and manifolds (Tables 2–6). The break condition for Gaussian kernels is clearly evidenced.  
- **Kernel choice controls smoothness via native Sobolev spaces:** **Medium** – Equivalence of Matérn/Wendland kernels to Sobolev spaces is well‑established, but the manifold smoothness penalty (Theorem 1.2) relies on restrictive geometric assumptions; verification is limited to three radial shapes.  
- **Separable factorization reduces cost while maintaining accuracy:** **Medium** – A 10× speedup and comparable training losses are reported, but no edge‑based baseline or anisotropic kernel tests are presented; the full accuracy–efficiency trade‑off remains unquantified.
