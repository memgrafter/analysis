# QuadAI at SemEval-2026 Task 3: Ensemble Learning of Hybrid RoBERTa and LLMs for Dimensional Aspect-Based Sentiment Analysis

## Quick Facts
- **arXiv ID:** arXiv:2603.07766
- **Source URL:** https://arxiv.org/abs/2603.07766
- **Reference count:** 11
- **Primary result:** Hybrid RoBERTa combined with LLM in-context learning and ensemble learning reduced RMSE to 0.6344 and achieved a Pearson correlation of 0.7773 on the Laptop development set.

## Executive Summary
Dimensional aspect-based sentiment analysis (DimABSA) requires predicting continuous valence (positivity) and arousal (intensity) scores for each aspect in a text. This paper presents a system for SemEval-2026 Task 3 that leverages a hybrid RoBERTa encoder with dual regression and classification heads, large language model (LLM) in-context learning, and prediction-level ensemble fusion. The hybrid architecture stabilizes continuous predictions by combining a direct regression output with an expected value from discretized sentiment bins. A multi-LLM consensus data-cleaning step refines few-shot examples, and an ensemble combiner (weighted average or ridge stacking) merges the encoder and LLM outputs. On the Laptop development set, the ensemble significantly outperforms individual models, demonstrating the value of f complementary error patterns. Despite not submitting test results due to time constraints, the work provides a strong foundation for DimABSA.

## Method Summary
The proposed pipeline processes each (text, aspect) pair in three stages. First, a **Hybrid RoBERTa** model fine-tunes a RoBERTa-base encoder with two parallel heads: a regression head predicts continuous valence and arousal, while a classification head predicts probabilities over discrete bins for each dimension; the final prediction averages the regression output with the expected value from the classification probabilities. Second, an **LLM in-context learning** pipeline clusters training examples by VA similarity using HDBSCAN, employs three LLMs (Gemini, Claude, GPT-5.2) to vote on and remove outlier instances with inconsistent labels, retrieves semantically similar clean examples via sentence embeddings, and queries Gemini to generate VA scores. Third, an **ensemble combiner** fuses the Hybrid RoBERTa predictions, the LLM predictions, and optionally VADER lexical features using simple averaging, weighted averaging (weights tuned on the development set), or ridge stacking with out-of-fold predictions to avoid leakage. The final output is a valence-arousal pair for each aspect.

## Key Results
- The Hybrid RoBERTa alone reduced MSE to 0.5419 and RMSE to 0.7361 on the Laptop development set.
- Ensemble learning (weighted average or ridge stacking) lowered RMSE to 0.6344 and improved mean Pearson correlation to 0.7773.
- The LLM alone achieved RMSE 0.695; the hybrid alone had RMSE 0.7361, showing that ensemble fusion yields complementary gains.

## Why This Works (Mechanism)
**Mechanism 1: Hybrid RoBERTa stabilizes continuous VA predictions.** The dual-head architecture combines a regression head’s direct output with an expected value derived from a classification head’s bin probabilities. The classification loss provides a smoother training signal than pure regression, reducing prediction variance. Evidence: The abstract and Section 3.1 detail the averaging formula and show improved stability over a regression-only baseline. A break condition occurs if bin boundaries mismatch the natural VA distribution, causing noisy expected values.

**Mechanism 2: Multi-LLM consensus data cleaning improves few-shot quality.** Training instances are clustered by VA similarity; three LLMs judge whether any instance’s labels are inconsistent with its cluster peers. Instances flagged as outliers by all three are removed, ensuring higher-quality few-shot examples for the final Gemini prompt. Evidence: Section 3.2 describes the workflow and prompt; the cleaning step is intended to mitigate spurious labels. A break condition arises if LLMs systematically misjudge sentiment, potentially discarding valid examples.

**Mechanism 3: Prediction-level ensemble fusion leverages complementary errors.** Base model predictions (Hybrid RoBERTa, LLM, and optional VADER features) are combined via averaging or ridge stacking. The ensemble reduces RMSE because the encoder and LLM make independent errors on different instances; their prediction errors partially cancel when averaged. Evidence: Section 4.3 (Table 4) shows ensemble RMSE 0.6344 vs. hybrid 0.7361 and LLM 0.695. A break condition is high prediction correlation between base models, which diminishes gains.

## Architecture Onboarding
**Component map:** Input (text + aspects) → Aspect-specific input generation → Hybrid RoBERTa (encoder + regression/classification heads) ↔ LLM pipeline (clustering → multi-LLM cleaning → semantic retrieval → Gemini prompting) → VADER lexical scorer → Ensemble combiner (average/weighted/ridge) → Final VA predictions

**Critical path:** For a new instance: (1) generate aspect context; (2) run Hybrid RoBERTa inference; (3) compute VADER scores; (4) perform LLM ICL (retrieve examples, call Gemini API); (5) combine predictions via ensemble. LLM ICL is the latency bottleneck.

**Design tradeoffs:**  
- *Hybrid RoBERTa:* Bin count and averaging weight trade nuance vs. stability; classification loss weight α must balance regression/classification.  
- *LLM ICL:* No training cost but high inference latency and API expense; example selection and data cleaning add complexity.  
- *Ensemble:* Simple average is robust but suboptimal; weighted/ridge stacking can improve but requires careful cross-validation; VADER features risk noise if lexical cues conflict with context.

**Failure signatures:**  
- Hybrid: Large discrepancy between regression and classification outputs indicates poor binning or weight w.  
- LLM ICL: High variance across runs suggests unstable few-shot selection or over-aggressive data cleaning.  
- Ensemble: Minimal improvement over best base model implies highly correlated errors; ridge coefficients near equal weights suggest limited stacking benefit.

**First 3 experiments:**  
1. Hyperparameter sweep for Hybrid RoBERTa: vary num_bins (7, 11, 31), classification loss weight α, and averaging weight w; select configuration minimizing dev RMSE.  
2. LLM ICL ablation: compare zero-shot, random few-shot, semantically selected few-shot, with and without multi-LLM data cleaning; measure RMSE and correlation.  
3. Ensemble method comparison: test simple average, weighted average, and out-of-fold ridge stacking (with/without VADER); verify no data leakage and inspect ridge coefficients.

## Open Questions the Paper Calls Out
1. How do alternative ensemble methods (e.g., stacking with more base models, voting) compare to the proposed fusion approaches?  
2. Can automated hyperparameter optimization (e.g., Optuna) improve the hybrid model’s configuration beyond manual search?  
3. Does the fixed averaging weight w=0.5 generalize across domains and aspect types, or should it be learned dynamically?  
4. Why do VADER lexical features fail to improve performance, and how can lexical knowledge be better integrated?  
5. How does the system perform on official test sets and in multilingual settings (e.g., Chinese), and what are the cross‑lingual transfer challenges?

## Limitations
- The exact method for incorporating aspect terms into RoBERTa inputs (e.g., special tokens, concatenation) is unspecified.
- Discretization details (uniform vs. quantile bins, bin count per dimension, bin center calculation) are not fully described.
- LLM pipeline specifics (Gemini version, prompt template, number of few‑shot examples K, output parsing) are missing.
- Training hyperparameters for the hybrid model (learning rate, batch size, epochs, early stopping) are unknown.
- The stacking procedure’s folds and regularization tuning are unclear, raising leakage risks.

## Confidence
- Hybrid RoBERTa stabilizes predictions: **Medium**
- Multi‑LLM consensus cleaning improves ICL quality: **Low to Medium**
- Ensemble fusion of encoder and LLM reduces error: **High**
