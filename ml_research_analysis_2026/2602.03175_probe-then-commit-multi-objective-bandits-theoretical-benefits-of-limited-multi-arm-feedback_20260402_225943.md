# Probe-then-Commit Multi-Objective Bandits: Theoretical Benefits of Limited Multi-Arm Feedback

## Executive Summary
This paper investigates the probe-then-commit (PTC) paradigm for multi-objective bandits, where an agent can probe several arms per round to observe vector outcomes but can only commit to one. The authors propose PTC-P-UCB, an algorithm that selects probes to maximize hypervolume-inspired frontier coverage and commits via either marginal hypervolume gain or scalarization. Theoretical analysis yields bounds showing that the dominated hypervolume frontier error scales as Õ(K_P d/√(qT)) and scalarized regret as Õ(L_φ d √(K/(q)T)), quantifying a 1/√q improvement from using q>1 probes. The method also adapts to variance in multi-modal settings. Simulations confirm that modest probe counts accelerate frontier learning and reduce regret.

## Method Summary
PTC-P-UCB proceeds in rounds. At the start of each round, it selects q arms to probe by solving an optimization that maximizes expected hypervolume coverage of the current Pareto frontier estimate. After observing the vector outcomes for these probes, it updates statistical models (e.g., empirical means and confidence intervals) for each arm's objectives. The algorithm then chooses one arm to commit: either by selecting the arm with the highest marginal increase in hypervolume or by scalarizing the objectives into a single value (using a weight vector) and applying a UCB-style rule. This design balances exploration (via probe selection) and exploitation (via commitment), leveraging the hypervolume indicator to guide efficient frontier approximation.

## Key Results
- Theoretical guarantees: dominated hypervolume frontier error Õ(K_P d/√(qT)) and scalarized regret Õ(L_φ d √(K/(q)T)), proving a 1/√q improvement from probing multiple arms.
- Multi-modal probing yields variance-adaptive gains, effectively reducing the impact of heteroscedastic noise.
- Simulations confirm accelerated frontier learning and regret reduction with modest q.

## Why This Works (Mechanism)
The probe selection in PTC-P-UCB maximizes hypervolume coverage, which directly reduces uncertainty about the Pareto frontier by focusing on arms that are likely to expand it. This efficient information gathering tightens confidence intervals faster, leading to the 1/√q improvement because each round collects q samples. The commitment strategies then exploit this improved knowledge: marginal hypervolume gain directly optimizes frontier quality, while scalarization provides a flexible way to incorporate preferences. Variance adaptation arises because probing multiple arms allows the algorithm to average noise in a data-dependent manner, effectively using an empirical noise scale that adapts to heteroscedasticity.

## Architecture Onboarding
Component map: Arm Models -> Probe Selector -> Commitment Mechanism -> Action

Critical path: (1) Initialize models; (2) For each round: select q probes via Probe Selector; observe outcomes; update Arm Models; choose commit arm via Commitment Mechanism; receive reward; (3) Repeat for T rounds.

Design tradeoffs:
- Probe selection: exact hypervolume maximization is computationally heavy; simpler heuristics trade accuracy for speed.
- Commitment: marginal hypervolume gain is frontier-aware but may be unstable; scalarization is stable but requires weight specification.
- Probe count q: larger q improves learning per round but reduces commitment frequency; optimal q depends on problem size.

Failure signatures:
- High hypervolume error due to poor probe coverage.
- Consistent suboptimal commits from scalarization bias.
- Runtime blow-up for large K due to probe selection optimization.
