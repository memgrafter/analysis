# Overcoming the Modality Gap in Context-Aided Forecasting

## Quick Facts
- arXiv ID: 2603.12451
- Source URL: https://arxiv.org/abs/2603.12451
- Reference count: 40
- Primary result: DoubleCast, trained on the verified CAF-7M dataset, shows strong context utilization and superior performance on both synthetic and real-world forecasting benchmarks.

## Executive Summary
Context-aided forecasting (CAF) seeks to enhance time series predictions by incorporating textual context, but existing models often fail because the provided context is of low quality. This paper introduces a semi-synthetic data augmentation pipeline: an LLM generates plausible contextual scenarios for time series windows, and a forecaster verifies that each context actually improves the Continuous Ranked Probability Score (CRPS). This yields CAF-7M, a corpus of 7 million context-augmented windows with a rigorously verified test set. The authors also propose DoubleCast, an alignment-based model that conditions the Chronos time series foundation model on text via a dual-attention decoder. Training DoubleCast on CAF-7M produces measurable context utilization: on the test set it achieves a normalized CRPS of 0.231 and a win rate of 0.71 against Chronos, with performance degrading sharply when context is removed or swapped. After fine-tuning on the real-world ChatTime benchmark, DoubleCast surpasses both Chronos and ChatTime, confirming effective transfer. The findings underscore that improving dataset quality is a key bottleneck for progress in CAF.

## Method Summary
The construction of CAF-7M begins with real time series windows. For each window, the authors prompt a large language model to generate a plausible textual scenario that could explain the observed pattern. To guarantee that the generated context is truly complementary, a verification step is applied: a frozen Chronos forecaster makes predictions with and without the context, and only contexts that reduce CRPS are retained. This filtering is performed on the test set due to computational limits; the training set is unfiltered but large (7 million windows). DoubleCast extends Chronos by adding a separate text encoder (e.g., T5) and a dual-attention decoder. The decoder contains two cross-attention layers—one attending to the time series embeddings and another to the text embeddings—allowing the model to fuse information from both modalities at each forecasting step. The model is trained to predict the future distribution given the past window and context, using a probabilistic loss such as CRPS. After pre-training on CAF-7M, DoubleCast is fine-tuned on the ChatTime benchmark to evaluate transfer to real data.

## Key Results
- On the CAF-7M test set, DoubleCast achieves a normalized CRPS of 0.231 and a win rate of 0.71 against Chronos, demonstrating effective context utilization.
- Ablation experiments reveal that removing the context or replacing it with an irrelevant one leads to large performance drops, confirming the model's dependence on complementary context.
- After fine-tuning on ChatTime, DoubleCast outperforms both Chronos and the prior state-of-the-art ChatTime model, showing successful transfer from synthetic to real-world data.

## Why This Works (Mechanism)
DoubleCast’s success rests on two pillars: (1) the high-quality context in CAF-7M, enforced by CRPS-based verification that filters out ineffective or noisy scenarios; and (2) the dual-attention decoder, which explicitly fuses text and time series representations at each decoding step without prematurely merging modalities. The strong time-series features from the frozen Chronos backbone provide a robust foundation, while the alignment mechanism allows the model to directly condition predictions on relevant contextual cues. This combination enables the model to both recognize and apply complementary signals effectively.

## Foundational Learning
- **Semi-synthetic data augmentation**: LLM-driven generation of textual scenarios paired with real time series. *Why needed*: Large-scale paired CAF data does not naturally exist; this approach creates a controllable training corpus. *Quick check*: Describe how an LLM prompt might convert a time series window into a plausible context.
- **Forecaster verification (CRPS-based filtering)**: Using a forecaster to measure whether a context improves predictive performance. *Why needed*: Ensures that only complementary contexts are kept, preventing noise from degrading model learning. *Quick check*: Given two probabilistic forecasts (with and without context) and ground truth, compute CRPS differences to decide retention.
- **Dual-attention decoder**: Decoder with two cross-attention pathways, one over time series embeddings and one over text embeddings. *Why needed*: Allows the model to jointly attend to both modalities without merging them prematurely, preserving modality-specific information. *Quick check*: Illustrate how the two attention outputs are combined within a decoder block (e.g., summation followed by feed-forward).
- **Context utilization ablation**: Testing model performance with context removed or swapped. *Why needed*: Diagnoses whether the model genuinely uses the context or ignores it. *Quick check*: Design an experiment where you feed an empty context and measure the CRPS change relative to using the original context.
- **Transfer learning from synthetic to real**: Fine-tuning a model pre-trained on CAF-7M on a real-world CAF benchmark. *Why needed*: Assesses whether synthetic data can provide a useful prior for actual applications. *Quick check*: Compare performance before and after fine-tuning on the target benchmark.

## Architecture Onboarding
**Component Map**  
Time Series Window -> Chronos Encoder -> Time Embeddings -> Dual-Attention Decoder  
Text Context -> Text Encoder -> Text Embeddings -> Dual-Attention Decoder  
Dual-Attention Decoder -> Forecast Distribution  

**Critical Path**  
1. The input time series window is processed by the Chronos encoder, producing a sequence of time embeddings.  
2. The input text is encoded by a separate text encoder into a sequence of text embeddings.  
3. The decoder, starting from a learned start token, iteratively generates the forecast horizon. At each step, two cross-attention layers attend to the time embeddings and text embeddings respectively. Their outputs are merged (e.g., by addition) and passed through a feed-forward network to produce the next output token or distribution parameters.  
4. The process repeats until the full horizon is covered, yielding a probabilistic forecast.

**Design Tradeoffs**  
- *Foundation model locking*: Leveraging Chronos gives strong time-series features but limits flexibility; the conditioning mechanism must adapt to a frozen encoder.  
- *Dual-attention complexity*: Adding a second cross-attention increases parameters and memory consumption but is necessary for explicit alignment.  
- *Verification cost*: Fully verifying all 7M training windows is infeasible; accepting some noise in the training set may reduce the upper-bound performance.

**Failure Signatures**  
- *No context effect*: If ablating (removing) the context does not change performance, the model is ignoring the context—likely a data quality or architectural issue.  
- *Attention misalignment*: When contexts contain temporally specific events (e.g., “spike in the last two days”) but attention weights are diffuse across the horizon, forecasts become smeared, indicating insufficient fine-grained temporal grounding.  
- *Poor transfer*: Minimal or no gain on real-world benchmarks suggests a domain shift between synthetic and real contexts.

**First Experiments**  
1. *Baseline training*: Train DoubleCast on a small subset (e.g., 100k windows) of CAF-7M and evaluate on the verified test set to confirm expected CRPS improvement over Chronos.  
2. *Context ablation*: Run the trained model on the test set under three conditions: (a) no context, (b) random context, (c) original context. Quantify the CRPS differences to assess context reliance.  
3. *Attention probing*: Construct test inputs with phrases having explicit temporal scope (e.g., “increase begins at step 5 and ends at step 8”). Visualize dual-attention weights to check whether the decoder attends to the relevant forecast steps at corresponding decoding positions.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How can the cost of verification be reduced to enable creation of a fully verified training set?  
- **Basis**: Future work includes reducing the cost of the verification procedure to generate a fully verified training set (Sec. 6). The limitations note that verifier-based filtering is applied only to the test set due to prohibitive computational expense.  
- **Why unresolved**: The training portion of CAF-7M is unfiltered, potentially containing contexts that are not truly complementary. This could limit model performance and obscure the relationship between dataset quality and model capabilities.  
- **What evidence would resolve it**: A scalable verification approach (e.g., using a smaller forecaster, a learned proxy, or more efficient sampling) that maintains the CRPS-based quality filter at a fraction of the cost. Empirical validation should show that training a model on such a fully verified set yields measurable gains in context utilization and real-world transfer compared to the partially verified baseline.

### Open Question 2
- **Question**: How can the diversity of LLM-generated contexts be substantially increased?  
- **Basis**: Future work includes developing methods to increase the diversity of generated contexts (Sec. 6). The limitations state that generating textual scenarios at massive scale can exhibit limited diversity (e.g., repetitive phrasing or overuse of common event templates), which reduces the effective information content.  
- **Why unresolved**: Low diversity may cause models to latch onto superficial patterns rather than learning genuine complementary signals, undermining the usefulness of the large-scale dataset.  
- **What evidence would resolve it**: Introduction of diversity-enhancing techniques (mixture-of-prompts, retrieval augmentation, explicit diversity constraints) and measurement of improvements using lexical/semantic diversity metrics. Crucially, models trained on the improved dataset should show stronger context utilization (e.g., larger CRPS drop when context is removed) and better performance on out-of-domain benchmarks.

### Open Question 3
- **Question**: How can forecasting models achieve explicit fine-grained temporal alignment between textual context and forecast steps?  
- **Basis**: Inferred from the limitations: DoubleCast does not explicitly enforce fine-grained, time-local grounding between specific phrases and forecast steps; when contexts contain multiple time-scoped events or precise temporal localization, cross-attention may diffuse the signal across the horizon (Sec. 5).  
- **Why unresolved**: Many useful contexts specify exactly when an effect starts and ends (e.g., “disruption during the first two days”). Without binding these references to precise forecast indices, models may misapply the context, leading to inaccurate or smeared predictions.  
- **What evidence would resolve it**: Architectures that incorporate structured temporal representations (e.g., event-time tags, time-aligned token routing, or explicit temporal cross-attention masks). Evaluation on a curated test set with precisely timed scenarios would demonstrate improved alignment (e.g., higher stepwise CRPS in affected regions) compared to baselines lacking such mechanisms.

### Open Question 4
- **Question**: Which architectural designs are most effective for exploiting high-quality context in CAF models?  
- **Basis**: The paper notes that while dataset scale is critical, model architecture plays an equally decisive role; further work is needed to disentangle exactly why implicit alignment methods like Time-LLM fail to exploit high-quality context (Sec. 4.2).  
- **Why unresolved**: It is unclear which architectural choices (fusion mechanism, placement of conditioning, text encoder selection) are necessary to convert complementary context into improved forecasts. Understanding this could accelerate progress beyond simply scaling datasets.  
- **What evidence would resolve it**: Systematic ablation studies on a fixed high-quality dataset (e.g., CAF-7M test set) comparing variants of alignment-based models (cross-attention depth, gating, fusion timing) and implicit methods (prompt reprogramming). Diagnostic metrics (attention alignment, sensitivity to context removal) would reveal the key factors driving effective context use, leading to concrete design guidelines or a new state-of-the-art architecture.

## Limitations
- The semi-synthetic pipeline may not fully capture real-world context complexity, risking domain shift when transferring to actual tasks.
- Evaluation on real-world data is limited to a single benchmark (ChatTime), so generalizability remains uncertain.
- Verification of contexts is computationally expensive; the training set remains unfiltered, which could contain non-complementary contexts and limit ultimate performance.

## Confidence
