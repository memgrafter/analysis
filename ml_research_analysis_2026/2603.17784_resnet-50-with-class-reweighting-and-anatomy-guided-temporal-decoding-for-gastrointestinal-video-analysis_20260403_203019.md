# ResNet-50 with Class Reweighting and Anatomy-Guided Temporal Decoding for Gastrointestinal Video Analysis

## Quick Facts
- arXiv ID: 2603.17784
- Source URL: https://arxiv.org/abs/2603.17784
- Reference count: 7
- Primary result: Improved temporal mAP from 0.3801 to 0.4303 (mAP@0.5) and 0.4020 (mAP@0.95) on the challenge test set.

## Executive Summary
This paper addresses the challenge of gastrointestinal video analysis, which suffers from severe class imbalance and requires precise temporal event detection. The authors propose a two-stage system: a ResNet-50 frame classifier trained with clipped class-wise positive weighting to ensure rare pathologies are learned without destabilizing optimization; and a temporal decoding pipeline that incorporates anatomy-guided techniques including ground-truth-style event composition, majority vote smoothing of anatomy labels, pathology gating based on allowed anatomies, and a conservative hysteresis decoder. Experiments on the challenge test set show significant gains in temporal mean average precision (mAP), raising mAP@0.5 from 0.3801 to 0.4303 and mAP@0.95 to 0.4020.

## Method Summary
The task is multi-label classification of gastrointestinal video frames, predicting 17 classes (5 anatomies and 12 pathologies). Frames are resized to 336×336 and processed by a ResNet-50 backbone followed by a sigmoid output layer. Training uses binary cross-entropy loss with per-class weights w_c = N_neg,c / N_pos,c, clipped to the interval [1, 50] to prevent extreme gradients. Frame-level predictions are transformed into temporally consistent events via a post-processing pipeline: (1) anatomy vote smoothing (majority over a window of radius 1) yields a discrete anatomy label a_t; (2) pathology gating sets the probability of pathology m to zero if a_t is not in its allowed anatomy set A_m; (3) a conservative hysteresis decoder binarizes each pathology time series; (4) active label set S_t at each frame is assembled from a_t and the active pathologies; (5) events are created by splitting whenever S_t differs from S_{t-1}, mimicking the ground truth event definition. The final output is a JSON file of event segments.

## Key Results
- Temporal mAP@0.5 improved from 0.3801 to 0.4303.
- Temporal mAP@0.95 reached 0.4020.
- The system effectively handled severe class imbalance and improved temporal localization.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: Clipped class-wise positive weighting enables rare pathology learning without destabilizing training.
- **Mechanism**: For each class c, weight w_c = N_neg,c/N_pos,c increases loss contribution from rare classes. Clipping to [1,50] prevents gradient explosion.
- **Core assumption**: Rare classes suffer from weak gradients due to low frequency; bounded up-weighting amplifies signal safely.
- **Evidence**: Abstract mentions "clipped class-wise positive weighting ...", Section 2.1 defines weighting and clipping; class reweighting is a common technique.
- **Break condition**: Inappropriate clip bounds (too low/high) fail; method assumes frequency dictates importance and that rarity reflects clinical relevance.

### Mechanism 2
- **Claim**: GT-style framewise event composition aligns predictions with ground truth fragmentation, improving temporal mAP.
- **Mechanism**: Start a new event whenever active label set S_t differs from S_{t-1}, mimicking official GT event definition.
- **Core assumption**: Evaluation matches events defined by constant label sets; prior smoother predictions caused mismatch even with accurate frames.
- **Evidence**: Abstract cites "GT-style framewise event composition"; Section 2.2 identifies GT fragmentation mismatch; baseline had fewer, longer segments.
- **Break condition**: If GT uses additional rules (e.g., minimum duration), this may over-fragment; accuracy depends on clean frame-level labels.

### Mechanism 3
- **Claim**: Anatomy-guided refinement (vote smoothing + pathology gating) reduces false positives and stabilizes boundaries.
- **Mechanism**: 
  - Vote smoothing: majority anatomy class in window (radius 1) yields stable a_t.
  - Pathology gating: set p^(m)_t = 0 if a_t ∉ A_m (allowed anatomies).
- **Core assumption**: Anatomies are temporally consistent; pathologies are anatomically constrained.
- **Evidence**: Abstract mentions "anatomy vote smoothing, and anatomy-based pathology gating"; Section 2.3/2.4 formal definitions; Section 4 reports "reduced anatomically implausible false positives."
- **Break condition**: Over-smoothing (larger r) blurs transitions; incomplete A_m suppresses true positives; relies on accurate anatomy prediction.

## Foundational Learning
### Concept 1: Multi-label classification with sigmoid outputs
- **Why needed here**: The frame classifier predicts 17 labels per frame, many co-occurring (e.g., stomach + ulcer). Sigmoid yields independent probabilities.
- **Quick check**: Why is softmax inappropriate? Softmax forces probabilities to sum to 1, implying mutual exclusivity, which does not hold here.

### Concept 2: Loss weighting for class imbalance
- **Why needed here**: The dataset is severely imbalanced; rare pathologies have few positive frames. Unweighted loss ignores them.
- **Quick check**: What does clipping the class weights prevent? Extreme weights causing gradient explosion and training instability.

### Concept 3: Temporal event detection from frame-level predictions
- **Why needed here**: The challenge evaluates temporal localization of events, not just frame accuracy.
- **Quick check**: What is hysteresis decoding? Two thresholds: high to activate, low to deactivate, reducing flicker. Why insufficient alone? It ignores anatomy and GT-style fragmentation.

## Architecture Onboarding
### Component map
Raw video frame -> resize to 336×336 -> ResNet-50 -> 17-dimensional sigmoid scores -> post-processing (anatomy vote smoothing -> pathology gating -> hysteresis decoding -> GT-style event composition) -> JSON events.

### Critical path
1. For each frame: resize → ResNet-50 → probabilities.
2. Extract top-1 anatomy → vote smoothing (radius 1) → a_t.
3. For each pathology m: apply gating by zeroing probability if a_t not in A_m.
4. Apply hysteresis decoder to each gated pathology time series to obtain binary active labels per frame.
5. Form active label set S_t = {a_t} ∪ {m | active at t}.
6. Scan timeline: when S_t ≠ S_{t-1}, close previous event (if any) and start a new event with label set S_t.
7. Output events as JSON.

### Design tradeoffs
- **Clipped weighting vs focal loss**: Clipping is simpler and more stable; focal loss down-weights easy examples but can be unstable for extremely rare classes.
- **Vote window size**: Radius 1 chosen to smooth noise without blurring transitions; larger windows risk over-smoothing.
- **Hysteresis thresholds**: Conservative thresholds (higher activation, lower deactivation) generalize better but may miss short events.
- **Gating prior**: Manual definition of A_m; incomplete sets reduce sensitivity, permissive sets increase false positives.

### Failure signatures
- Training divergence: check clipping bounds and learning rate.
- Low frame mAP on rare classes: verify weights applied correctly; consider data augmentation.
- Temporal mAP significantly lower than frame mAP: likely event alignment mismatch; use debugging JSON to compare GT-style fragmentation.
- Anatomically implausible pathology detections: review A_m sets and anatomy accuracy (confusion matrix).
- Over-fragmented events: hysteresis thresholds too sensitive; add minimum event duration.

### First 3 experiments
1. Frame-level baseline: Train ResNet-50 without class weighting or temporal steps. Measure frame mAP to establish visual model strength.
2. Temporal decoding ablation: Using the best frame model, first apply only hysteresis decoder → record mAP. Then add vote smoothing, then gating, then GT-style composition sequentially; record incremental gains.
3. Class weighting sensitivity: Train with varying w_max (e.g., 10, 50, 100) and no clipping. Plot recall for rare pathology classes and training loss curves to find optimal clipping range.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: Does end-to-end temporal training (direct event prediction) outperform the current frame-classify-then-decode pipeline in temporal mAP?
- **Basis in paper**: "Future improvements could include end-to-end temporal training..." (Discussion).
- **Why unresolved**: The current two-stage approach may lose temporal context during decoding; end-to-end could optimize directly for event boundaries and avoid fragmentation mismatches.
- **What evidence would resolve it**: Train a video-level architecture (e.g., 3D CNN or transformer) that ingests clip contexts and outputs event segments, then compare temporal mAP@0.5 and mAP@0.95 against the published baseline on the challenge test set.

### Open Question 2
- **Question**: Can a jointly trained Hidden Markov Model (HMM) with learned transition probabilities outperform the fixed hysteresis decoder?
- **Basis in paper**: The authors tested an HMM/Viterbi decoder with temperature scaling but rejected it for the "simpler and more stable" hysteresis pipeline (Discussion), implying untapped potential.
- **Why unresolved**: The HMM was likely used as a post-processor with fixed transitions; learned transitions might better capture anatomy-pathology temporal dynamics while maintaining stability.
- **What evidence would resolve it**: Implement an HMM where emission probabilities come from the ResNet-50 frame classifier and transition probabilities are learned from training video sequences, then evaluate whether it improves temporal mAP over the hysteresis decoder on validation videos.

### Open Question 3
- **Question**: How does the anatomy vote smoothing window radius *r* impact the trade-off between over-smoothing true anatomical transitions and suppressing noise?
- **Basis in paper**: The authors fixed *r*=1 without ablation, noting larger windows "might over-smooth" (Discussion), but the optimal size is unknown.
- **Why unresolved**: The choice of *r*=1 was practical but arbitrary; a systematic evaluation could reveal class-specific or video-length-dependent optimal settings.
- **What evidence would resolve it**: Conduct an ablation study varying *r* (e.g., 0, 1, 2, 3) on validation data, measuring per-anatomy boundary F1-score, temporal mAP, and over-smoothing metrics (e.g., segment length distribution).

### Open Question 4
- **Question**: Why did aggressive temporal decoders (e.g., larger hysteresis thresholds) improve training-set temporal mAP but fail to generalize to unseen test videos?
- **Basis in paper**: The authors observed: "more aggressive temporal decoders could improve training-set temporal mAP, but these gains did not consistently transfer to unseen videos" (Discussion).
- **Why unresolved**: This suggests overfitting to training temporal patterns or distribution shift between training and test videos; the cause (e.g., segment length bias, annotation style) is unanalyzed.
- **What evidence would resolve it**: Compare training vs. test video statistics (e.g., segment duration distribution, anatomy transition frequency) and perform error analysis to identify where aggressive decoding introduces false positives/negatives on test videos.

### Open Question 5
- **Question**: Can data-driven anatomical priors (instead of fixed gating rules) improve pathology detection by capturing nuanced co-occurrences and exceptions?
- **Basis in paper**: The anatomy gating used fixed sets *A_m* per pathology (Methods Eq. 9), with no learning from data; the authors suggest "more advanced anatomical priors" as future work (Discussion).
- **Why unresolved**: Fixed priors may be too rigid (e.g., some pathologies appear in multiple anatomies); learned priors could adapt to dataset-specific patterns and reduce false positives from implausible detections.
- **What evidence would resolve it**: Learn a mapping from anatomy context (e.g., neighboring anatomy labels) to pathology validity probabilities using training data (e.g., via logistic regression or a small neural net), then compare pathology mAP with fixed gating on the test set.

## Limitations
- Missing specifications: the anatomy gating prior \(A_m\), hysteresis decoder thresholds, and exact label mapping are not detailed.
- Incomplete training hyperparameters: optimizer choice, learning rate schedule, augmentation strategies, batch size, and number of epochs are omitted.
- Risk of over-smoothing or over-fragmentation due to fixed window size and event composition rules, which may not generalize across datasets.

## Confidence
- Clipped class-wise positive weighting: Medium
- GT-style event composition: Medium
- Anatomy-guided refinement: Medium
- Overall mAP improvement: Medium

## Next Checks
1. **Temporal decoding ablation**: Using a fixed frame-level model, add each decoding step (hysteresis, vote smoothing, gating, GT composition) one by one on a validation split to quantify incremental mAP impact.
2. **Weight clipping sensitivity**: Train with varying maximum clip values (e.g., 10, 50, 100, no clip) and evaluate rare-class recall, loss stability, and overall mAP to validate the chosen bound.
3. **Anatomy gating prior analysis**: Define alternative plausible \(A_m\) sets from medical knowledge or data statistics, then measure changes in false positive/negative rates to check robustness of the reported reduction.
