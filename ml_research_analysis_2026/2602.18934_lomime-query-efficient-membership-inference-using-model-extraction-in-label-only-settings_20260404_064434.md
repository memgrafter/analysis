# LoMime: Query-Efficient Membership Inference using Model Extraction in Label-Only Settings

## Quick Facts
- **arXiv ID:** 2602.18934  
- **Source URL:** https://arxiv.org/abs/2602.18934  
- **Reference count:** 40  
- **Primary result:** LoMime reduces query cost of label‑only membership inference attacks to approximately 1% of training samples while matching state‑of‑the‑art accuracy and AUC.

## Executive Summary
Membership inference attacks (MIAs) in label‑only black‑box settings typically require a large number of queries to the target model, making them computationally expensive. LoMime addresses this problem by decoupling the attack into two phases: first, it extracts a functionally similar surrogate model using a query‑efficient active sampling strategy combined with synthetic data perturbations; second, it performs an unsupervised membership inference on the surrogate by analyzing decision boundary distances calibrated via random samples. This amortizes the query cost, enabling an adversary to attack many victim samples after a one‑time extraction. Evaluations on Purchase, Location, and Texas Hospital datasets show that with a query budget equivalent to testing roughly 1% of the training samples, LoMime achieves membership accuracy and AUC within ±1% of attacks directly on the target model, effectively matching state‑of‑the‑art label‑only MIAs at a fraction of the query overhead. Against common defenses, DP‑SGD reduces leakage most significantly but degrades model utility, while dropout and L2 regularization have limited impact.

## Method Summary
LoMime operates in two distinct phases. **Phase 1 – Model extraction:** Starting from a small auxiliary dataset \(D_A\), the adversary iteratively augments the pool of candidate queries using binary feature flips (AUTOLYCUS‑style) and then selects the most informative samples via a combination of entropy sampling, gradient‑based clustering, and loss‑based ranking (adapted from MARICH). The selected samples are queried from the target model \(M\) to expand the labeled query set \(D_S\), and the surrogate model \(S\) is retrained on the accumulated data. This process repeats until the query budget \(n_q\) is exhausted or a desired surrogate fidelity is reached. **Phase 2 – Membership inference:** For the trained surrogate \(S\), the attacker generates a set of uniform random synthetic samples. For each, the minimal \(\ell_2\) perturbation needed to flip the predicted label (i.e., decision boundary distance) is approximated using a hard‑label boundary attack. The maximum of these distances defines a threshold \(\tau\). When evaluating a target sample \(x_i\), the same boundary distance is computed; if it falls below \(\tau\), \(x_i\) is classified as a member. This calibration step is unsupervised and requires no access to the target’s training or non‑member labels. The overall pipeline thus achieves query amortization: the extraction cost is incurred once, after which membership predictions for arbitrarily many samples cost zero additional queries.

## Key Results
- LoMime achieves membership inference accuracy and AUC within ±1% of direct attacks on the target model while using a query budget equivalent to testing only ~1% of the training samples.
- It matches state‑of‑the‑art label‑only MIAs in performance but with significantly lower query overhead, demonstrating effective amortization.
- Among evaluated defenses, DP‑SGD most substantially reduces leakage at the expense of model utility; dropout and L2 regularization have only marginal effects on attack success.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Query‑efficient model extraction via active sampling and synthetic data produces a surrogate model that retains the target’s membership leakage signal.
- **Mechanism:** The extraction optimizes mutual information between target and surrogate predictions while maximizing input‑space diversity. It uses entropy‑based and loss‑based selection from a perturbed auxiliary dataset to approximate the target’s decision boundary with fewer queries than per‑sample label‑only MIA.
- **Core assumption:** Membership leakage is encoded in the geometry of the decision boundary; a surrogate with high label fidelity will exhibit similar leakage behavior.
- **Evidence anchors:** Abstract mentions “active sampling, perturbation‑based selection, and synthetic data” to extract a “functionally similar surrogate S.” Section 3.1 details the MARICH‑based stages (entropy sampling, gradient clustering, loss‑based selection) that build the query set \(D_S\). The correlation between fidelity and attack performance in Table 2 provides indirect support.
- **Break condition:** Surrogate fidelity \(F_M^S\) falls below a dataset‑specific threshold (e.g., <0.85 for Purchase/Texas), leading to significant degradation in attack AUC compared to direct MIA on \(M\).

### Mechanism 2
- **Claim:** Unsupervised calibration of the decision‑boundary distance threshold eliminates the need for member/non‑member ground truth during the attack phase.
- **Mechanism:** For each synthetic random sample \(x_i\) (from \(X_{\text{random}}\)), the attacker computes \(d_{\text{boundary}}(x_i) = \min\|\delta\|_2\) such that \(S(x_i+\delta) \neq S(x_i)\). The threshold \(\tau\) is set to the maximum distance observed: \(\tau = \max_{x \in X_{\text{random}}} d_{\text{boundary}}(x)\). A target sample is predicted as a member if its distance is ≤ \(\tau\).
- **Core assumption:** The maximum distance over a uniform random feature‑space sample distribution approximates the “width” of the decision boundary and serves as a universal separator; training members tend to lie closer to the boundary than random non‑members.
- **Evidence anchors:** Section 3.2 explicitly defines \(d_{\text{boundary}}(\cdot)\) and the calibration of \(\tau\) (Eqs. 8‑11). The abstract states the threshold “is calibrated in an unsupervised manner … without requiring labels or training data from \(M\).”
- **Break condition:** Random synthetic samples are out‑of‑distribution relative to \(D_M\) or \(S\)’s training manifold, causing \(d_{\text{boundary}}\) misestimation and poor τ calibration. This is suggested by high variance in attack accuracy on the Texas dataset.

### Mechanism 3
- **Claim:** Query amortization via one‑time extraction enables scalable membership inference across many victim samples at a total cost comparable to testing ~1% of the training set.
- **Mechanism:** The total query budget \(n_q\) is spent upfront to train \(S\). Once \(S\) is obtained, offline MIA on any number of target samples (arbitrary \(D_{\text{mem}}\)) requires zero additional queries to \(M\).
- **Core assumption:** The adversary needs to evaluate membership for a large number of samples (\(|D_{\text{mem}}| \gg |D_M|\)), so the fixed extraction cost is outweighed by the saved per‑sample queries.
- **Evidence anchors:** Abstract: “With a query budget equivalent to testing ≈1% of training samples, LoMime achieves membership inference accuracy and AUC within ±1% of attacks on the target model.” Section 4.3 compares to Choquette‑Choo et al. [26] (≈10,000 queries per sample) and shows LoMime’s comparable AUC with far fewer total queries when \(D_{\text{mem}}\) > 100.
- **Break condition:** \(D_{\text{mem}}\) is very small (e.g., <10 samples), making direct per‑sample attacks cheaper than full extraction. Also fails if extraction fidelity is too low, necessitating \(n_q > |D_M|\) to match prior attack performance.

## Foundational Learning
- **Model extraction as variational optimization** – LoMime’s extraction adapts MARICH, which maximizes mutual information \(I(\Pr(M(Q),Q) \| \Pr(S(Q),Q))\). This objective explains the active learning design. *Quick check:* Why does maximizing mutual information between target and surrogate on the query set lead to a surrogate that replicates the target’s decision boundaries?
- **Decision boundary geometry and adversarial perturbations** – The MIA relies on computing \(d_{\text{boundary}}(x_i) = \min\|\delta\|_2\) s.t. \(S(x_i+\delta) \neq S(x_i)\). Understanding how minimal perturbations cross the boundary and why members lie closer is crucial. *Quick check:* Why would training samples tend to be closer to the decision boundary than random non‑members in an overfitted model?
- **Active learning for query efficiency** – The extraction minimizes query budget by selecting informative samples via entropy, gradient clustering, and loss‑based ranking. *Quick check:* How does selecting queries where the current surrogate is uncertain (high entropy) accelerate fidelity improvement compared to random sampling?

## Architecture Onboarding
- **Component map:** Auxiliary Data (DA) and Target Model (M) → Extraction Engine → Surrogate S (trained on DS) ; Surrogate S → Calibration Module → Threshold τ ; Threshold τ + Membership Dataset (Dmem) → Inference Module → Membership Predictions ; Fidelity Evaluator monitors surrogate fidelity (FSM) throughout.
- **Critical path:** Initialize \(S_0\) on \(D_A\) labeled by \(M\). Repeat until query budget exhausted: augment \(D_A\) → \(D_Q\); entropy select \(Q_t^{\text{entropy}}\); gradient‑cluster → \(Q_t^{\text{grad}}\); loss‑based refinement → \(Q_t^{\text{loss}}\); query \(M\); update \(D_S\); retrain \(S\). After extraction: generate \(X_{\text{random}}\); compute \(d_{\text{boundary}}(\cdot)\) for each; set \(\tau = \max d_{\text{boundary}}\); for each \(x \in D_{\text{mem}}\) compute \(d_{\text{boundary}}(x)\) and predict member if ≤ \(\tau\).
- **Design tradeoffs:**  
  - Synthetic data generation (AUTOLYCUS) avoids needing a public dataset but may yield less diverse queries than real data, possibly requiring more iterations.  
  - Threshold calibration with uniform random samples may misestimate \(\tau\) for high‑dimensional or sparse data where random points are out‑of‑distribution.  
  - Active learning hyperparameters (\(\alpha, \rho, \gamma_1, \gamma_2\)) are dataset‑specific; improper tuning risks query waste or low fidelity.
- **Failure signatures:**  
  - Low surrogate fidelity \(F_M^S\) (<0.8) despite high query budget indicates extraction stuck in a local region.  
  - High attack AUC on \(S\) but low on \(M\) suggests the surrogate overfits synthetic queries and does not transfer leakage.  
  - \(\tau\) yields extreme values (near 0 or huge) because random samples are out‑of‑distribution or the boundary solver fails.  
  - Excessive runtime from many extraction iterations; monitor queries per iteration and consider increasing batch size or augmentation factor.
- **First experiments:**  
  1. **Fidelity vs. Query Budget Sweep** – Train surrogates with \(n_q \in \{1\text{K}, 10\text{K}, 100\text{K}, 1\text{M}\}\) on each dataset. Plot \(F_M^S\) and test accuracy vs. \(n_q\) to identify the saturation point and validate non‑linear improvement trends.  
  2. **Threshold Calibration Sanity Check** – For a trained \(S\), generate 1,000 uniform random samples. Compute \(d_{\text{boundary}}\) distribution, check for outliers, and ensure \(\tau\) is not driven by a few malformed samples. Optionally compare \(\tau\) against \(d_{\text{boundary}}\) for a held‑out set of known members/non‑members to evaluate separation.  
  3. **Defense Evasion Test** – Train the target model \(M\) with DP‑SGD (\(\epsilon \in \{20, 500\}\)) and L2 regularization (\(\lambda=0.005\)) on the Location dataset. Extract \(S\) and run the full LoMime pipeline. Replicate Table 3 to confirm expected utility loss and limited attack degradation, verifying pipeline integration with defended models.

## Open Questions the Paper Calls Out
1. **Adaptation to high‑dimensional data** – How to extend LoMime to images and sequences while maintaining query efficiency? Current binary feature flips and perturbations are tailored to tabular data; spatial or temporal augmentations are needed.
2. **Persistent performance gap on Texas Hospital dataset** – The AUC lags behind target attacks by ~5% even with large budgets. Is this due to dataset sparsity/imbalance or limitations of the active sampling strategy? No per‑class or subspace analysis is provided.
3. **Robust defenses beyond those evaluated** – Which modern privacy‑preserving techniques (e.g., PATE, adversarial regularization, certifiable robustness) can mitigate LoMime’s leakage without severely degrading utility? DP‑SGD helps but harms accuracy; better trade‑offs are unknown.
4. **Fully synthetic initialization** – Can LoMime operate with zero auxiliary real data? Synthetic‑only query generation may be inefficient or produce unrealistic samples that hinder extraction. Generative models or Bayesian optimization could explore this regime.

## Limitations
- The assumption that surrogate leakage transfers to the target is not strongly validated; it may break down when surrogate fidelity \(F_M^S\) is low.
- Unsupervised threshold calibration using uniform random samples may be invalid for high‑dimensional or sparse data, leading to τ misestimation.
- Active sampling hyperparameters (\(\alpha, \rho, \gamma, B\)) are dataset‑specific and lack theoretical guidance, requiring empirical tuning.

## Confidence
- Amortization advantage (scalable to large \(D_{\text{mem}}\)): **High**
- Extraction preserves leakage signal: **Medium**
- Unsupervised threshold calibration: **Medium**
- Overall attack matches SOTA label‑only MIAs: **High**

## Next Checks

2. **Calibration robustness** – Replace uniform \(X_{\text{random}}\) with in‑distribution synthetic data (e.g., generated by a VAE trained on \(D_M\)); compare stability of \(\tau\) and resulting attack accuracy.
3. **Active sampling ablation** – Disable each active component (entropy sampling, gradient clustering, loss selection) individually; measure impact on surrogate fidelity and final attack AUC to quantify each component’s contribution.
