# Quantized Evolution Strategies: High-precision Fine-tuning of Quantized LLMs at Low-precision Cost

## Quick Facts
- **arXiv ID:** 2602.03120
- **Source URL:** https://arxiv.org/abs/2602.03120
- **Reference count:** 9
- **Primary result:** QES enables full-parameter fine-tuning of INT4 quantized LLMs at inference-level memory, achieving 18.00% accuracy on the Countdown task versus 5.25% for the prior SOTA quantized zeroth-order method.

## Executive Summary
Post-Training Quantization (PTQ) drastically reduces LLM memory footprint for deployment but produces static models that are extremely difficult to fine-tune, as standard backpropagation requires high-precision weights that are unavailable in the discrete, quantized parameter space. Quantized Evolution Strategies (QES) resolves this by facilitating full-parameter fine-tuning directly within the quantized domain. It introduces two synergistic innovations: (1) an accumulated error feedback loop, inspired by Delta-Sigma modulation, that preserves the continuity of high-precision gradient signals across discrete weight updates to prevent optimization stagnation, and (2) a stateless seed replay mechanism that reconstructs necessary optimizer state on-the-fly from a limited buffer, reducing memory consumption to the level of low-precision inference. On the Countdown arithmetic reasoning benchmark, QES dramatically outperforms the prior state-of-the-art quantized zeroth-order method, QuZO, and matches the performance of a memory-intensive full-precision oracle while using orders of magnitude less memory.

## Method Summary
QES operates within the framework of Evolution Strategies (ES), a derivative-free optimization family, to navigate the discrete quantized weight space. Its first innovation, accumulated error feedback, maintains a high-precision "shadow" parameter trajectory. At each step, the discrete update applied to the physical quantized weights is subtracted from the ideal continuous update, and this error is accumulated and added to subsequent gradient estimates. This temporal error integration, analogous to Delta-Sigma modulation's noise shaping, prevents the gradient signal from being corrupted by quantization discretization, allowing the shadow parameters to follow a high-precision learning trajectory. The second innovation, stateless seed replay, eliminates the need to store full optimizer states (e.g., momentum buffers) for every parameter. Instead, it stores only a short, fixed-length window of random seeds used to generate perturbations. During the replay phase, it re-generates perturbations using these seeds and the *current* quantized weights to approximate the historical perturbation signs, enabling state reconstruction with memory proportional to the model size, not the optimizer state size.

## Key Results
- On the Qwen2.5-1.5B model quantized to INT4, QES achieves 18.00% test accuracy on the Countdown task, vastly outperforming QuZO (5.25%) and the base model (3.50%).
- QES matches the performance of a "full-residual oracle" that has access to high-precision residuals, while using only inference-level memory (O(model size)), demonstrating its ability to maintain high-precision learning dynamics within the quantized constraint.
- The method's memory advantage is empirically validated, showing a dramatic reduction compared to baselines that require storing high-precision optimizer states.

## Why This Works (Mechanism)
The core challenge is that updating quantized weights via a zeroth-order method like ES introduces a fundamental temporal misalignment: the perturbation sign used to estimate a gradient at step *t* was generated based on the weight configuration at step *t-1*, but the physical weights have since moved to a new discrete lattice point. This causes the gradient estimate to be systematically biased. QES's accumulated error feedback corrects this by adding the historical quantization error (the difference between the ideal continuous update and the actual discrete jump) to future gradient estimates. This error, once introduced, is perpetually carried forward in the shadow parameter's memory, effectively canceling out the bias over time and preserving the temporal consistency of the gradient signal. Stateless seed replay then solves the memory problem: since the perturbation signs are binary (±1), storing the random seeds that generated them is far cheaper than storing the full floating-point perturbation vectors or optimizer states. By replaying these seeds with the *current* weights, QES approximates the historical gating function (whether a parameter's update would have been blocked by its quantization boundary), which is sufficient for reconstructing the necessary residual terms with high fidelity under the observed condition of sparse parameter updates and few boundary hits.

## Architecture Onboarding
**Component Map:**  
Quantized Model Weights -> Perturbation Generation (Seed Replay) -> Forward Pass (Quantized) -> Loss Evaluation -> Gradient Estimate Calculation -> Accumulated Error Feedback -> Shadow Parameter Update -> Discrete Weight Projection -> (Loop) & Stateless Seed Buffer (K-length)

**Critical Path:**  
1.  Initialize quantized model and shadow parameters (high-precision copy).  
2.  For each iteration: generate perturbations using a seed from a small buffer.  
3.  Compute perturbed losses using the current quantized model.  
4.  Estimate the gradient via ES formula using loss differences.  
5.  Add accumulated historical error to this gradient estimate.  
6.  Compute the ideal continuous update for the shadow parameters.  
7.  Project the updated shadow parameters onto the nearest quantized lattice points to get new physical weights.  
8.  Compute new quantization error (ideal - discrete) and add it to the error accumulator.  
9.  Periodically, use stored seeds and current weights to replay and verify/adjust the error accumulator's integrity.

**Design Tradeoffs:**  
- **Memory vs. Fidelity:** Seed replay window size *K* trades memory for reconstruction accuracy of historical perturbation signs. Larger *K* improves state reconstruction but increases memory linearly.
- **Stability vs. Discretization:** Accumulated error feedback stabilizes learning on coarse lattices (e.g., INT4) but its dynamics may become unstable or oscillatory if the quantization step size (Δ) is too large (e.g., 1-bit) or if the learning rate is poorly tuned relative to Δ.
- **Universality vs. Efficiency:** The method assumes sparse updates (small update ratio) and few boundary hits (low ρ). This holds for typical fine-tuning regimes but may break under aggressive regularization or very coarse quantization, forcing a trade-off between allowed quantization levels and reliable convergence.

**Failure Signatures:**  
- **Exploding/Vanishing Gradients:** Symptom of unstable error feedback if the accumulated error term becomes misaligned with the true gradient direction, often preceding divergence.
- **Stagnation at Plateau:** If the boundary hit ratio (ρ) becomes high, the stateless replay's approximation fails, causing the shadow parameters to drift from the true continuous trajectory, leading to a stall in loss reduction.
- **Memory Leak:** A bug in the seed buffer management (e.g., incorrect windowing) would cause memory to grow unbounded, defeating the core memory-saving purpose.

**First 3 Experiments:**  
1.  **Generalization Test:** Apply QES to a different model architecture (e.g., Llama-3-8B) quantized to INT4 and fine-tune on a standard instruction-following dataset (e.g., UltraFeedback) to assess performance beyond synthetic reasoning.
2.  **Component Ablation:** Run QES on Countdown with either the accumulated error feedback disabled (replaced with naive gradient combination) or the stateless seed replay disabled (replaced with full state storage) to isolate each component's contribution to final accuracy and convergence speed.
3.  **Quantization Stress Test:** Evaluate QES on the same model/task with increasingly coarse quantization (INT8 -> INT4 -> INT2 -> binary) to identify the practical lower bound of bit-width for stable convergence and measure the resulting boundary hit ratio (ρ).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Can QES be effectively extended to more aggressive and non-uniform quantization paradigms, such as binary networks (1-bit) or floating-point formats like FP4?
- **Basis in paper:** [explicit] The authors state in Section 6: "While this paper validated QES on standard linear integer quantization (INT4, INT8, W8A8), it should be possible to extend it to more aggressive and non-uniform quantization paradigms, such as binary networks and floating-point formats (e.g., FP4)."
- **Why unresolved:** The method's core mechanism—accumulated error feedback—relies on a discrete lattice with a defined granularity (∆). Extremely coarse (1-bit) or non-uniform formats may fundamentally alter the error accumulation dynamics or boundary conditions, potentially breaking the temporal equivalence guarantee.
- **What evidence would resolve it:** Empirical validation of QES on models quantized to 1-bit or FP4, measuring convergence stability and final performance on reasoning tasks compared to INT4/INT8. Theoretical analysis of the error feedback loop's stability under different quantization step sizes and non-linear mappings would also be needed.

### Open Question 2
- **Question:** Can the stateless seed replay mechanism's fixed window size (K) and decay factor (γ) be adaptively tuned during optimization to automatically balance memory savings and reconstruction fidelity, removing the need for manual hyperparameter selection?
- **Basis in paper:** [explicit] The authors propose in Section 6: "An adaptive algorithm could be created that automatically tunes K and the decay rate γ based on real-time convergence stability or available hardware resources."
- **Why unresolved:** The current implementation uses fixed K and γ. The paper shows performance is sensitive to these values (Table 2). An adaptive scheme would require detecting when the replay-induced approximation error becomes detrimental to the gradient estimate, which is non-trivial without storing the true state.
- **What evidence would resolve it:** Development and testing of an algorithm that monitors metrics (e.g., gradient variance, consistency between consecutive updates) to dynamically adjust K and γ. Experiments would compare its performance and robustness against the fixed-K baseline across diverse model scales and tasks.

### Open Question 3
- **Question:** Does QES maintain its performance advantage and low-memory benefits when applied to complex, large-scale fine-tuning tasks beyond the synthetic Countdown arithmetic task, such as instruction following, coding, or general chat alignment?
- **Basis in paper:** [inferred] The paper's evaluation is exclusively on the Countdown task (Section 4.1). While this task isolates reasoning capability, it is a narrow, synthetic benchmark. The success on "arithmetic reasoning" is stated, but generalizability to the diverse objectives of standard LLM fine-tuning (e.g., safety, helpfulness, nuanced coding) is not established.
- **Why unresolved:** Countdown has a verifiable, binary reward signal. Real-world fine-tuning often involves noisier, sparser, or more subjective rewards (e.g., from a reward model or human preference). The interaction between QES's error accumulation and such reward landscapes is unknown.
- **What evidence would resolve it:** Conducting comprehensive evaluations on established fine-tuning benchmarks (e.g., MT-Bench, HumanEval, TruthfulQA) using quantized versions of models like Llama or Qwen. Memory usage profiles and convergence curves compared to baselines like QuZO would be critical.

### Open Question 4
- **Question:** What are the fundamental theoretical limits of QES's "temporal equivalence" guarantee (Θ_t+1 = Θ_t + αĝ_t) when applied to very deep networks or models with highly non-smooth loss landscapes, where the assumption of sparse parameter updates might break down?
- **Basis in paper:** [inferred] The stateless replay approximation (Algorithm 2) relies critically on two empirical observations: (1) the update ratio is small (~10^-2) and (2) the boundary hit ratio (ρ) is negligible (Table 3). The paper argues this makes the approximation error "vanishingly small." However, this is an empirical observation on a specific model family and task. For deeper architectures, different training phases, or coarser quantization (e.g., INT2), the frequency of parameters hitting quantization boundaries during the replay window could increase, violating the core approximation.
- **Why unresolved:** The analysis assumes W_τ ≈ W_t. If many parameters frequently cross boundaries, the replayed gating (using W_t) will differ from the original gating (using W_τ), causing the reconstructed residual ẽ to diverge from the true e. This would break the guarantee that the physical weights track the ideal continuous trajectory within ±∆/2.
- **What evidence would resolve it:** A systematic study measuring the boundary hit ratio (ρ) and its impact on final performance as a function of model depth, quantization bit-width, and training iteration. A theoretical analysis deriving conditions under which the approximation error remains bounded would provide a firmer foundation.

## Limitations
- Evaluation is confined to a single arithmetic task (Countdown) and one model (Qwen2.5-1.5B), raising questions about generalizability to other architectures and diverse tasks.
- No ablation study isolates the contributions of accumulated error feedback versus stateless seed replay, obscuring which component drives performance gains.
- Theoretical understanding of error feedback stability across discrete quantization steps remains informal, relying on an analogy to Delta-Sigma modulation without rigorous analysis.

## Confidence
- **High:** QES significantly outperforms QuZO on the reported Countdown benchmark (empirical numbers provided); memory usage claim is supported by matching an inference-level oracle.
- **Medium:** The proposed mechanisms (error feedback, seed replay) are plausibly effective but lack validation beyond the single experimental setting; convergence properties in quantized spaces are not formally proven.
- **Low:** Expectations for strong performance across broader model families (e.g., Llama, GPT-style), quantization bit-widths (e.g., INT2, INT8), and non-reasoning tasks are unsupported by current evidence.
