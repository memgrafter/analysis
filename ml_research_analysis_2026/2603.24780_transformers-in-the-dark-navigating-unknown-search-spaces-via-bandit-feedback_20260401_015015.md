# Transformers in the Dark: Navigating Unknown Search Spaces via Bandit Feedback

## Quick Facts
- arXiv ID: 2603.24780
- Source URL: https://arxiv.org/abs/2603.24780
- Reference count: 40
- Primary result: Fine-tuning a pretrained LLM on academic paper search trajectories yields superior performance over vanilla LLM and LLM with external search, improving max-reward hit rate from 0.262 to 0.548.

## Executive Summary
This paper investigates whether large language models and transformer architectures can inherently perform tree-structured search without external search modules. The authors introduce a controlled framework called "unknown tree search with bandit feedback," isolating the model's decision-making by providing search space expansions and value estimates externally. Theoretically, they prove that transformers can exactly implement various search strategies using constant-depth architectures. Empirically, transformers trained from scratch successfully imitate reference algorithms across metrics like max-reward hit rate and generalize to longer horizons. Most importantly, fine-tuning a pretrained LLM (Qwen3-8B) on academic paper search trajectories significantly outperforms both the vanilla LLM and LLM augmented with external search, demonstrating that targeted training can internalize search capabilities and that transformers possess the architectural capacity to implement structured search.

## Method Summary
The study addresses navigating an unknown tree-structured search space using only bandit feedback (noisy reward estimates for selected nodes). The task involves selecting unvisited child states at each step to maximize the reward of the final leaf. Experiments use synthetic trees (varying branching factor, depth, goal states) and a real-world Academic Paper Search task (based on OpenAlex). Key metrics include max-reward hit rate and discounted cumulative gain. For training from scratch, transformers are trained via behavior cloning on trajectories generated by reference algorithms (uniform/greedy leaf sampling, path sampling with UCT) using a structured tokenization format. For LLM-based experiments, a pretrained Qwen3-8B model is fine-tuned with LoRA on UCT-generated trajectories. Hyperparameters include AdamW optimizer with specific learning rate schedules, rotary positional embeddings, and a vocabulary of value and structural tokens. The reproduction plan involves generating datasets, training models with given architectures, and evaluating against reference policies.

## Key Results
- Transformers trained from scratch imitate reference search strategies nearly perfectly on simple tasks (max-reward hit rate approaching 1.0), though behavioral divergence (KL) is higher for path-based methods like UCT.
- Models generalize to longer horizons and deeper trees, but performance degrades when test distributions exceed training depths or branching factors.
- Fine-tuning a pretrained LLM (Qwen3-8B) on academic paper search trajectories yields a max-reward hit rate of 0.548, surpassing the vanilla LLM (0.262) and LLM with external search (0.461).

## Why This Works (Mechanism)
The success of transformers in performing tree search can be attributed to three key mechanisms. First, transformers can simulate tree-traversal policies (e.g., UCT) by maintaining and querying visit counts and reward statistics via positional embeddings and hard attention over the trace. The hidden tree structure is implicitly encoded in the sequence of visited states, allowing the model to reconstruct parent-child links. Second, the model aggregates noisy bandit feedback (rollout estimates) into stable internal value estimates by summing rewards and counting visits for each state token across non-contiguous positions. Third, structured tokenization schemes (Leaf-Based, Tree-Based) convert the search decision into a next-token prediction task, where the trace format explicitly marks iterations, frontier states, and candidate children, reducing the cognitive load on the model. Theoretical constructions confirm that constant-depth transformers can implement these mechanisms, and empirical results validate their effectiveness in practice.

## Architecture Onboarding
**Component map:** Input Encoder → Positional Encoding (RoPE) → Multiple Transformer Blocks (self-attention + MLP) → Output Head (linear layer over final token). The encoder maps tokens (state IDs, value tokens, structural markers) to embeddings; positional encoding captures sequential order; blocks compute attention over the trace; head produces logits over action vocabulary.

**Critical path:** (1) Tokenize current search trace τ_t, (2) embed tokens and add positional encodings, (3) process through ℓ transformer blocks to compute attention patterns that isolate frontier states and aggregate inherited rewards, (4) apply output head to final token representation to obtain logits for next state selection.

**Design tradeoffs:** Increasing model depth may improve simulation of complex policies but risks overfitting and hurting generalization. Tokenization choices (Leaf-Based vs Tree-Based) trade off sequence length linearity against expressiveness for path-based strategies. Behavior cloning optimization may not directly maximize search metrics like max-reward hit rate.

**Failure signatures:** High KL divergence from reference algorithm (especially for path-based methods), sharp performance drop on deeper trees or longer horizons, inability to generalize to more goals or higher wall densities, failure to learn complex policies like UCT without sufficient capacity or data diversity.

**First 3 experiments:** (1) Train a scratch transformer on uniform leaf sampling traces to establish baseline performance. (2) Test generalization by evaluating a model trained on depth-6 trees on depth-8 trees. (3) Fine-tune a pretrained LLM (Qwen3-8B) on academic paper search trajectories and compare against zero-shot LLM and LLM+UCT baselines.

## Limitations
- Theoretical proofs assume idealized hard attention and exact arithmetic, which may not hold in practical soft-attention transformers.
- Training details for scratch transformers (number of epochs, batch size, convergence criteria) are unspecified, hindering faithful reproduction.
- The Academic Paper Search task construction (child generation, start-target pair selection) is incompletely described, limiting exact replication.

## Confidence
- Transformers can implement search algorithms theoretically: Medium
- Scratch-trained transformers imitate reference algorithms: Medium
- Fine-tuned LLM outperforms baselines on academic search: Medium
