# The Rashomon Effect for Visualizing High-Dimensional Data

## Quick Facts
- **arXiv ID:** 2604.00485
- **Source URL:** https://arxiv.org/abs/2604.00485
- **Reference count:** 40
- **Primary result:** Multiple distinct embeddings can equally preserve the essential structure of high-dimensional data (the Rashomon set); this work defines that set for dimension reduction and introduces methods to align embeddings with external knowledge or extract stable nearest-neighbor relationships to produce more robust and interpretable visualizations.

## Executive Summary
The paper investigates the non-uniqueness of dimension reduction (DR) embeddings, formalizing the "Rashomon set" as the collection of low-loss embeddings that preserve data structure. It introduces three practical methods to navigate this set: (1) PCA-informed alignment to rotate embeddings toward principal component axes without harming local neighborhoods, (2) concept-alignment regularization to order an embedding axis by an external variable like class labels, and (3) extraction of "common knowledge" by identifying nearest-neighbor relationships that are stable across many Rashomon embeddings, which is then used to build a consensus embedding with improved cluster quality and downstream performance. Experiments across multiple datasets and DR algorithms demonstrate that these techniques enhance interpretability and robustness while maintaining structural fidelity.

## Method Summary
The framework starts with a base parametric DR method (e.g., ParamPaCMAP). To align embeddings, a regularization term is added to the DR loss but applied only to *non-nearest-neighbor* pairs, preserving the base method's local structure. For PCA alignment, the term minimizes the cosine difference between non-NN direction vectors in the embedding and a PCA reference. For concept alignment, it forces the standardized coordinate difference along a chosen axis to match standardized label differences. To extract common knowledge, many embeddings are generated from the Rashomon set (loss ≤ 1.05× minimum). From a calibration subset, statistics (mean, variance) of pairwise distances are computed for all candidate high-dimensional neighbors. A scoring function Ψ combines a pair's distance in a test embedding with its variance across the set; the lowest-scoring k neighbors per point form a refined k-NN graph. Finally, a new DR embedding is trained on this refined graph, yielding a consensus representation.

## Key Results
- The Rashomon set for DR is formally defined via a graph-weight similarity or a loss-threshold criterion.
- PCA and concept alignment successfully steer global layout or axis ordering while keeping local metrics (soft Jaccard distance) stable.
- Common knowledge extraction from stable nearest-neighbor relationships produces embeddings with significantly higher k-NN accuracy, silhouette score, and SVM accuracy compared to single-instance embeddings.
- Improvements are consistent across datasets (MNIST, USPS, scRNA-seq) and base DR methods (PaCMAP, UMAP, t-SNE variants).

## Why This Works (Mechanism)

### Mechanism 1: PCA-Informed Alignment
- **Claim:** PCA-informed alignment can steer a dimension reduction (DR) embedding toward principal component axes while preserving local neighborhood structure.
- **Mechanism:** A regularization term is added to the DR loss that minimizes the cosine similarity between the direction vectors of *non‑nearest‑neighbor (non‑NN)* point pairs in the DR embedding and their counterparts in a PCA embedding. By excluding NN pairs, the local structure governed by the original DR objective remains unaffected, while the global layout rotates/translates to align with PCA.
- **Core assumption:** The local neighborhood structure (defined by high-dimensional kNN) is already optimally preserved by the base DR loss; aligning only distant pairs prevents distortion of this local structure.
- **Evidence anchors:**
  - [abstract] "PCA-informed alignment to steer embeddings toward principal components, making axes interpretable **without distorting local neighborhoods**."
  - [section 4.1] "We exclude nearest‑neighbor pairs from this alignment term because LDR already governs the local structure... By restricting alignment to non‑NN (more distant) pairs, we steer only the global layout... so that the local structure will not be impacted."
- **Break condition:** If the alignment weight (λPCA) is set too high relative to the base DR loss, even non‑NN pairs may exert enough force to distort local neighborhoods, increasing the soft Jaccard distance or other local structure metrics (observed in Appendix H with high missingness/label weight).

### Mechanism 2: Concept‑Alignment Regularization
- **Claim:** Concept‑alignment regularization can align an embedding axis with an external, user‑defined concept (e.g., class labels) without significantly degrading the DR's structural preservation.
- **Mechanism:** A loss term penalizes the squared difference between the standardized coordinate difference along a chosen embedding axis (e.g., horizontal) and the standardized difference in the concept labels, but only for non‑NN pairs. This encourages the embedding to order points along that axis according to the concept while leaving local relationships to the base DR loss.
- **Core assumption:** The concept variation is primarily a global, axis‑aligned phenomenon that can be injected without conflicting with the local manifold structure captured by the base DR method.
- **Evidence anchors:**
  - [abstract] "concept‑alignment regularization that aligns an embedding dimension with external knowledge, such as class labels..."
  - [section 4.2] "This formulation encourages the embedding to preserve meaningful variation along an interpretable direction while remaining flexible in other dimensions."
- **Break condition:** If the concept label is noisy, sparse (high missingness), or contradictory to the intrinsic data manifold, a high λAxis will force the embedding to prioritize the concept, causing a measurable increase in L_DR and degradation of cluster coherence (evidenced in Figure 27 and Appendix H).

### Mechanism 3: Common Knowledge Extraction
- **Claim:** By sampling multiple embeddings from the Rashomon set, one can identify nearest‑neighbor (NN) relationships that are stable and trustworthy across all high‑quality embeddings, and using these to reconstruct a new NN graph yields an embedding with improved local and global structure.
- **Mechanism:** A scoring function Ψ_ij(y) = d_ij(y) + λ·σ*_ij (or a capped version) is defined for a candidate NN pair (i,j). It combines the pair's distance in a specific embedding (d_ij) with the standard deviation (σ*_ij) of that distance across a calibration set of Rashomon embeddings. Low average Ψ across a test set indicates the pair is consistently close (stable low distance, low variance). The top‑k lowest‑scoring pairs for each point form a refined, trustworthy k‑NN graph, which is then used as input to a DR method to generate a consensus embedding.
- **Core assumption:** A NN pair that is consistently close across many embeddings within the Rashomon set (i.e., low Ψ) is more likely to reflect a true manifold relationship than a pair that is frequently distant or high‑variance, which likely represents an artifact of a specific embedding's optimization.
- **Evidence anchors:**
  - [abstract] "extraction of common knowledge from stable nearest‑neighbor relationships... to construct refined embeddings with improved local structure."
  - [section 5] "We aim to identify pairs that consistently appear as neighbors... If Ψ is low, the pair is most likely a trustworthy (stable and close) pair within the kNN of i." Theorem 5.1 provides a concentration bound for comparing pair margins.
- **Break condition:** If the base Rashomon set is too narrow (e.g., all embeddings from similar initializations or a single DR method with low true multiplicity), the estimated σ*_ij may not capture meaningful variance, and the "stable" pairs may simply be those favored by that method's bias, not true manifold neighbors. The method also assumes the high‑dimensional kNN graph is a reasonable candidate set; if the initial k is too small, true manifold neighbors may be excluded.

- **k‑Nearest Neighbors (k‑NN) Graph Construction:** The entire framework—from defining the Rashomon set via graph weight matrices to extracting common knowledge—relies on a fixed high‑dimensional k‑NN graph as the reference for candidate neighbor relationships. The choice of k influences which pairs are considered.
  - *Quick check:* Why is a large initial m (for candidate neighbors) used in common knowledge extraction before selecting a final k?

  - *Quick check:* If you increase λAxis in concept alignment, what happens to the base DR loss (L_DR) and why does that matter for staying in the Rashomon set?
- **Consensus / Ensemble Methods:** Goal 3 is a consensus method: aggregating information (NN relationships) from multiple model outputs (embeddings) to produce a more robust result.
  - *Quick check:* How is this consensus method different from simply averaging the coordinate matrices of multiple embeddings?

## Architecture Onboarding
- **Component map:**
  Base DR Engine -> Alignment Module (optional) -> Rashomon Set Generator -> Graph Scorer -> Common Knowledge Extractor -> Consensus Reconstructor
- **Critical path:** Generate diverse Rashomon set (S) → Calibrate scorer on subset of S → Score/test on remaining S → Build refined graph → Re‑run DR on refined graph. *Note: The alignment steps (1‑2) are alternative paths to Goal 1/2; the common knowledge path (3‑6) is Goal 3.*
- **Design tradeoffs:**
  - **Computational Cost vs. Robustness:** More embeddings in S improve reliability of σ_ij estimates but increase runtime linearly (parallelizable). The paper suggests ~5 embeddings may suffice.
  - **Alignment Strength (λ) vs. Fidelity:** Higher λ increases interpretability/alignment but risks leaving the Rashomon set (higher L_DR, distorted local structure). Requires loss curve inspection.
  - **Graph Sparsity (k):** Larger final k retains more global structure but risks including less trustworthy pairs; smaller k yields purer local neighborhoods but may over‑aggregate.
- **Failure signatures:**
  - **Local Structure Degradation:** A significant rise in soft Jaccard distance or drop in silhouette/SVM accuracy after alignment or consensus reconstruction indicates local neighborhoods were harmed.
  - **Concept Misalignment:** For concept alignment, if the embedding's chosen axis does not monotonically correlate with the concept when visualized (e.g., mixed colors), λAxis may be too low or the concept may not align with any manifold direction.
  - **Graph Fragmentation:** The refined k‑NN graph may have many points with fewer than k reliable neighbors, leading to disconnected components in the final embedding.
- **First 3 experiments:**
  1. **PCA Alignment Sanity Check:** Run PaCMAPparam on MNIST with and without PCA alignment (λPCA=0.1). Visually confirm clusters rotate toward PCA layout. Quantitatively check that Triplet PCA score increases while soft Jaccard distance and L_DR remain nearly unchanged (Table 1, Figure 3).
  2. **Common Knowledge Extraction Efficacy:** On USPS, generate a Rashomon set of 5 PaCMAPparam embeddings. Extract a common 10‑NN graph and reconstruct. Measure improvement in k‑NN accuracy, silhouette score, and SVM accuracy over the original single embedding (Figure 5).
  3. **Sensitivity to Supervision (Missingness):** For concept alignment on MNIST, vary the percentage of points with available labels (missingness ratio) and λAxis. Plot L_DR and Jaccard distance. Expect sharp degradation when both are high (Figure 27), demonstrating the break condition.

## Open Questions the Paper Calls Out
- **Open Question 1:** What formal criterion can detect when concept alignment (e.g., with class labels) conflicts with the data manifold, beyond simple LDR increases?
  - *Basis in paper:* The authors note in the Discussion (Page 9) that formalizing detection of contradictory alignment is future work.
  - *Why unresolved:* The paper only suggests monitoring LDR but does not provide a threshold or theoretical guarantee for manifold preservation.
  - *What evidence would resolve it:* Derive a bound relating alignment regularization to a manifold distortion measure (e.g., intrinsic dimensionality change), and verify on datasets with known manifold properties.
- **Open Question 2:** What is the smallest Rashomon set size that yields stable common knowledge extraction, and how does this depend on dataset characteristics?
  - *Basis in paper:* Experiments use 235 embeddings and claim "as few as five are sufficient" (Page 7) without exploring the lower bound or scalability.
  - *Why unresolved:* No analysis of how Rashomon set size affects the reliability of the extracted nearest‑neighbor graph or consensus embedding quality.
  - *What evidence would resolve it:* Systematically vary the number of embeddings (1 to 100) across datasets of varying size and dimensionality, and measure the stability of soft Jaccard distance and downstream metrics.
- **Open Question 3:** When do the loss‑based and graph‑based Rashomon set definitions produce different sets of valid embeddings, and which is more aligned with human intuition of structure?
  - *Basis in paper:* The paper defines both (Section 3) but only states they "exhibit similar behavior" for low‑loss embeddings, without examining discrepancies.
  - *Why unresolved:* The definitions are theoretically distinct: one bounds loss, the other bounds graph weight similarity. Their relationship remains unclear.
  - *What evidence would resolve it:* For a range of DR methods and datasets, compute both Rashomon sets under identical thresholds and compare their memberships, especially for embeddings with moderate loss but different global layouts.
- **Open Question 4:** Can the proposed methods be extended to non‑parametric DR (e.g., t‑SNE) and online settings where embeddings are updated incrementally?
  - *Basis in paper:* The definitions are said to apply to non‑parametric methods (Page 3), but all experiments use parametric methods. The Discussion mentions computational cost but not adaptation.
  - *Why unresolved:* Regularization terms assume differentiability; common knowledge extraction assumes a fixed batch of embeddings. Adapting to non‑parametric or streaming contexts is nontrivial.
  - *What evidence would resolve it:* For non‑parametric DR, apply alignment via post‑hoc rotation/scaling of embeddings. For online settings, develop incremental consensus algorithms and test on streaming data with concept drift.

## Limitations
- **Hyperparameter gaps:** Default training parameters (epochs, LR, batch size) for each DR method are unspecified; reproduction relies on original implementations or inferred best practices.
- **Graph construction details:** The high‑dimensional *m*-NN graph's metric, *m* value, and ANNOY parameters are not explicitly stated; the candidate pair set size critically impacts common knowledge extraction.
- **Rashomon set validity:** The 5% loss‑threshold (≤ 1.05× min loss) for selecting embeddings is heuristic; no guarantee this captures a "diverse" set across all DR methods.

## Confidence
- **Mechanism 1 (PCA alignment):** High. Clear exclusion of NN pairs, quantitative stability shown, rationale aligns with local/global separation principles.
- **Mechanism 2 (Concept alignment):** Medium. Evidence is qualitative (visual axis ordering) and relies on the assumption that concepts are linearly orderable along an axis; break conditions are shown but generalizability to arbitrary concepts is unclear.
- **Mechanism 3 (Common knowledge extraction):** Medium. Strong empirical gains reported, but core assumption—that stable NN relationships across a Rashomon set reflect true manifold neighbors—is supported mainly by heuristic scoring (Ψ) without a theoretical guarantee that such consensus beats a single well‑tuned embedding.
