# EEG-Titans: Long-Horizon Seizure Forecasting via Dual-Branch Attention and Neural Memory

## Quick Facts
- **arXiv ID:** 2601.13748
- **Source URL:** https://arxiv.org/abs/2601.13748
- **Reference count:** 17
- **Primary result:** Achieves 99.46% average segment-level sensitivity on CHB-MIT with a baseline false positive rate of 0.371 per hour; extends context to 300 seconds to reduce false alarms for artifact-prone subjects (e.g., CHB15 FPR/h from 3.87 to 0.00).

## Executive Summary
EEG-Titans introduces a novel dual-branch temporal backbone for long-horizon seizure forecasting from scalp EEG. The architecture combines a sliding-window attention branch for short-term anomaly detection with a neural memory pathway (Titans MAG) that maintains a stable long-context reference. Input EEG is first tokenized via a ShallowConvNet, which extracts spectro-spatial features mimicking classical filter-bank CSP pipelines. The model operates under a strict chronological holdout protocol on the CHB-MIT dataset, using patient-specific thresholds and post-processing (sliding Top-K mean, 30-minute refractory period). It achieves near-perfect segment-level sensitivity (99.46%) while maintaining a moderate baseline false positive rate (0.371/h). Notably, for artifact-heavy subjects, increasing the context window from 60 to 300 seconds drastically reduces false alarms without sacrificing sensitivity, demonstrating the neural memory’s role in suppressing transient noise.

## Method Summary
The task is long-horizon seizure forecasting: predicting pre-ictal states (35 to 5 minutes before seizure onset) from multi-channel scalp EEG in a causal, online manner. Inputs are 5-second non-overlapping windows from the CHB-MIT database (18 bipolar channels, 256 Hz), preprocessed with notch (60 Hz) and band-pass (0.5–100 Hz) filters. Seizure clusters are labeled with a 1.5-hour safety margin. The model comprises three stages: (1) a **ShallowConvNet spatial tokenizer** that applies temporal convolution (~156 ms band-pass), spatial convolution (channel mixing), square-law nonlinearity, average pooling, log-transform, and a 1×1 projection to produce a token sequence; (2) a **Titans Memory-as-a-Gate (MAG) temporal backbone** with two parallel branches—a local branch using causal sliding-window attention to capture short-term patterns, and a global branch updating a persistent neural memory state via an element-wise adaptive decay gate—whose outputs are fused by a learned gate; (3) a linear classification head producing probabilities. During inference, a sliding window of model outputs is aggregated via a Top-K mean, and alarms are triggered if this score exceeds a patient-specific threshold, with a 30-minute refractory period. Training uses chronological splits (first N‑1 seizure clusters for training, last for testing) and binary cross-entropy loss. Patient-specific thresholds are tuned on non-overlapping validation data to maximize sensitivity within acceptable false positive constraints.

## Key Results
- Average segment-level sensitivity of **99.46%** across 18 CHB-MIT subjects under a sensitivity-oriented evaluation.
- Baseline false positive rate of **0.371 per hour** with a 30-minute refractory period.
- For artifact-prone subject **CHB15**, extending the context window from 60 to 300 seconds reduces FPR/h from **3.87 to 0.00** while sensitivity increases from **90.34% to 99.86%**.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The dual-branch temporal backbone simultaneously captures short-term pre-ictal anomalies and long-term contextual trends without quadratic computational cost.
- **Mechanism:** The local branch uses causal, window-restricted self-attention to detect transient discriminative patterns. The global branch maintains a compact neural memory state updated via an adaptive decay gate σ(θ), which accumulates slower-evolving pre-ictal dynamics. A learned gate fuses these complementary representations.
- **Core assumption:** Pre-ictal brain states involve both brief electrophysiological events and gradual, progressive changes over minutes; separating these temporal scales improves robustness to noise.
- **Evidence anchors:**  
  [abstract]: "employs a dual-branch architecture that combines sliding-window attention for short-term anomalies with a neural memory pathway for long-term context."  
  [section 2.2]: Describes the MAG block (Eqs. 4–9), causal masking (Eq. 5), and fusion gate (Eq. 8).  
  [corpus]: Weak direct support; neighboring papers (e.g., STAN, LookAroundNet) use extended-window attention but not an analogous neural memory pathway. FMR scores are moderate (0.485–0.574) and not directly comparable.
- **Break condition:** If pre-ictal dynamics are entirely transient (no long-term evolution), the memory branch may introduce latency or propagate early noise, potentially degrading performance relative to pure attention.

### Mechanism 2
- **Claim:** The neural memory component (Memory-as-a-Gate) lowers false positive rates by providing a stable long-context reference that suppresses isolated, non-coherent activations inconsistent with a progressive pre-ictal trajectory.
- **Mechanism:** The persistent memory state `h_t` is updated with a learnable feature-wise decay (Eq. 4), allowing retention of salient long-range information while attenuating abrupt, artifact-like deviations. During fusion (Eq. 9), the gate `g_t` down-weights the local attention output `z_attn` when it conflicts with the memory context `z_mem`.
- **Core assumption:** False positives often arise from transient artifacts or background fluctuations lacking sustained, coherent evolution; a slowly updating memory acts as a consistency filter.
- **Evidence anchors:**  
  [section 3.4 (Ablation)]: "EEG-Titans achieves the lowest FPR/h, improving upon the attention-only temporal baseline (0.371 vs. 0.522)."  
  [section 4.2]: "memory-augmented backbone reduces FPR/h relative to attention-only and LSTM-based baselines, suggesting that memory provides a stabilizing reference."  
  [corpus]: No direct evidence; neighboring works (REST, LookAroundNet) focus on efficiency or wider context, not learnable memory decay.
- **Break condition:** If artifacts are prolonged and structured (e.g., sustained muscle noise), the memory may integrate them as "context," potentially increasing false positives unless the decay mechanism can distinguish artifact coherence from pre-ictal coherence.

### Mechanism 3
- **Claim:** The ShallowConvNet spatial tokenizer enables effective spectro-spatial feature extraction from raw EEG, providing a strong, discriminative token sequence that allows the temporal backbone to focus on consistency rather than low-level feature discovery.
- **Mechanism:** Temporal convolution acts as a learnable band-pass filter; spatial convolution learns channel mixtures analogous to CSP; log-variance pooling yields a log-power feature map, which is then projected to tokens. This mimics classical FBCSP pipelines but is trainable end-to-end.
- **Core assumption:** Discriminative pre-ictal signatures are encoded in spectral power patterns and specific spatial projections (e.g., focal epileptiform discharges), capturable by shallow convolutions without deep hierarchies.
- **Evidence anchors:**  
  [section 2.2]: "ShallowConvNet is explicitly designed to capture spectral–spatial patterns... can be viewed as a trainable approximation of classical pipelines such as FBCSP."  
  [section 3.4 (Ablation)]: "All variants achieve high sensitivity (>98%), indicating that the ShallowConvNet spatial tokenizer produces discriminative spectro-spatial representations."  
  [corpus]: DBConformer (paper_id 105067) uses a dual-branch convolutional transformer for EEG decoding, supporting the utility of shallow spatial processing, but does not replicate the specific ShallowConvNet design.
- **Break condition:** If pre-ictal signatures involve high-frequency, non-stationary phenomena beyond the temporal kernel’s receptive field (~156 ms) or require deeper hierarchical abstractions (e.g., complex wave sequences), ShallowConvNet may under-extract features.

## Foundational Learning
- **Concept: Sliding-window causal attention**  
  *Why needed here:* Enables the local branch to detect short-term anomalies while respecting temporal causality (no future access), essential for real-time forecasting.  
  *Quick check question:* Why is a causal mask (Eq. 5) necessary in the local attention branch, and what would happen if it were omitted?
- **Concept: Neural memory with adaptive decay**  
  *Why needed here:* Provides a fixed-cost mechanism for long-context retention, avoiding LSTM degradation and Transformer quadratic scaling; the learnable decay gate (σ(θ)) allows per-feature retention control.  
  *Quick check question:* How does the element-wise decay in Eq. 4 differ from a fixed exponential moving average, and why might per-dimension control help with artifacts?
- **Concept: Chronological hold-out evaluation**  
  *Why needed here:* Prevents temporal leakage between train/test seizures, ensuring the model generalizes forward in time—a critical safety constraint for clinical deployment.  
  *Quick check question:* Why is leave-one-subject cross-validation potentially invalid for seizure forecasting, and what specific leakage does chronological splitting avoid?

## Architecture Onboarding
- **Component map:** Raw EEG -> ShallowConvNet -> Titans MAG -> Linear Classifier -> Probability -> Sliding Top-K / Refractory Decision
- **Critical path:** Input EEG segment -> ShallowConvNet (spatial filtering/tokenization) -> Titans MAG block(s) (temporal modeling) -> linear classifier -> probability -> Top-K/refractory decision
- **Design tradeoffs:**  
  - **Context window size:** Longer windows improve long-context modeling and artifact rejection but increase memory/computation and may dilute short-term signals.  
  - **Memory dimension (`d_model`):** Larger memory increases capacity but also parameter count and risk of overfitting on limited seizure data.  
  - **Patient-specific thresholds:** Necessary due to inter-subject EEG variability but reduces out-of-the-box usability; requires validation data per subject.
- **Failure signatures:**  
  - **High FPR/h in artifact-heavy subjects** (e.g., CHB15 baseline): Indicates memory branch may be integrating artifact coherence or local attention too sensitive to bursts.  
  - **Sensitivity drop with extended context in some subjects?** (Not observed in CHB15, but possible if context dilutes brief pre-ictal signatures).  
  - **Consistently high sensitivity + high FPR across many subjects:** Suggests tokenizer or fusion gate failing to suppress non-coherent activations.
- **First 3 experiments:**  
  1. **Tokenizer sanity check:** Freeze Titans backbone; train only ShallowConvNet on a small subset. Verify it learns spectral–spatial filters (e.g., via weight visualization) and achieves >80% segment accuracy—confirms tokenizer provides separable features.  
  2. **Memory benefit isolation:** Compare Titans (MAG) vs. LSTM vs. attention-only (same tokenizer). Expect FPR/h reduction with Titans, especially on subjects with known artifacts (CHB15). Use patient-specific thresholds fixed across models for fair comparison.  
  3. **Context window sensitivity:** For artifact-prone subjects (e.g., CHB15), systematically vary context length (60 s → 300 s). Expect non-monotonic FPR: decrease as context helps reject bursts, but potential later increase if context becomes too large and includes irrelevant history. Validate that sensitivity does not drop sharply.

## Limitations
- Critical hyperparameters (`d_model`, number of MAG blocks, dropout, etc.) are not reported, blocking exact replication.
- Patient‑specific threshold selection details are vague: no explicit FPR constraint during grid search and unclear how validation clusters are created.
- The dramatic FPR reduction from extending context to 300 s is demonstrated only for CHB15; generalization to other subjects or whether retraining is required is unknown.
- Evaluation is limited to CHB‑MIT; transferability to other EEG datasets or clinical settings remains untested.

## Confidence
- Dual-branch backbone captures short- and long-term pre-ictal dynamics: **Medium**
- Neural memory lowers false positive rate: **Medium**
- ShallowConvNet tokenizer provides effective spectro-spatial features: **High**
- Long-context extension reduces false alarms for artifact-prone subjects: **Medium**

## Next Checks
1. **Tokenizer sanity verification** – Freeze the Titans backbone and train only the ShallowConvNet on a subset of CHB-MIT. Visualize learned temporal/spatial filters; expect band-pass and channel-mixing patterns analogous to FBCSP and >80% segment accuracy.
2. **Memory benefit isolation** – Replicate the ablation comparing Titans (MAG), LSTM, and attention-only models with identical tokenizer and hyperparameters. Use the same patient-specific thresholding procedure; measure FPR/h on CHB15 and other high-FPR subjects. Titans should show the lowest FPR, particularly where artifacts dominate.
3. **Context window generalization** – For all subjects with high baseline FPR (e.g., CHB15, CHB12), run inference with both 60 s (12 tokens) and 300 s (60 tokens) contexts. If the model is length-fixed, retrain with the longer context. Verify that sensitivity remains >95% while FPR/h drops significantly (e.g., >50%) across multiple artifact-prone subjects, not just CHB15.
