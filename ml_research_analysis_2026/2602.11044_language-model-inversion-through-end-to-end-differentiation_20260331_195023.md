# Language Model Inversion through End-to-End Differentiation

## Quick Facts
- **ArXiv ID**: 2602.11044  
- **Source URL**: https://arxiv.org/abs/2602.11044  
- **Reference count**: 40  
- **Primary result**: DLMI, an end-to-end differentiable method for language model inversion, achieves near-perfect longest-common-subsequence (LCS) ratios for low-difficulty targets and substantially outperforms prior baselines across all difficulties and prompt lengths.

## Executive Summary
The Language Model Inversion (LMI) problem seeks a prompt that causes a frozen language model to generate a specific target output. Existing methods are inefficient and prior evaluations used flawed protocols assuming a single optimal prompt. This paper introduces DLMI, a method that enables end-to-end differentiation through the language model by representing prompts as sequences of token distributions (SDoTs) via a soft embedding layer and a Gumbel-Softmax gradient estimator with decoupled, learnable temperatures. Teacher Forcing is used during optimization to stabilize training. DLMI dramatically outperforms baselines (REINFORCE, GBDA, SODA) across a spectrum of target difficulties (controlled by rank *k*) and prompt lengths (*N*=10,80), nearly solving low-difficulty cases and maintaining a wide margin at high difficulty. The learnable temperature mechanism and longer prompts are identified as key to its success. Gradient analysis confirms the estimator’s superior bias-variance trade-off.

## Method Summary
DLMI reframes the discrete prompt optimization problem as continuous. The soft prompt is parameterized by logits *Z* ∈ ℝ<sup>*N*×|V|</sup>, which are turned into token distributions using Gumbel-Softmax with per-token temperature τ<sub>*i*</sub> = ε + τ₀(1+tanh(Φ<sub>*i*</sub>)), where Φ are learnable parameters. For each optimization step, multiple samples are drawn by adding Gumbel noise to *Z* and applying softmax scaled by τ, then projecting through the embedding matrix to obtain soft prompt embeddings. These are concatenated with hard embeddings of the target tokens (teacher forcing) and fed into the frozen LM. The loss is the cross-entropy between the LM’s predictions for the target positions and the true target tokens. The gradients with respect to *Z* and Φ are averaged over samples and used to update both via Adam. After optimization, the prompt token IDs are obtained by an argmax over *Z*. Evaluation uses greedy decoding to generate outputs, which are compared to the target via longest-common-subsequence (LCS) ratio.

## Key Results
- DLMI achieves LCS ratios near 1.0 for low-difficulty targets (*k*≤5) and maintains >0.6 even at the hardest difficulty (*k*=21), while REINFORCE, GBDA, and SODA drop below 0.3.
- The decoupled, learnable temperature parameters are critical: they reduce gradient variance and bias, enabling efficient convergence; fixed-temperature variants perform poorly at high *k*.
- Using longer prompts (*N*=80) yields substantial improvements over shorter prompts (*N*=10), demonstrating the importance of prompt capacity for inversion.

## Why This Works (Mechanism)
The core insight is to treat the prompt as a continuous, differentiable entity rather than a discrete sequence. The soft embedding allows gradients to flow through the embedding matrix, while the Gumbel-Softmax estimator provides a low-variance, low-bias gradient estimate for the discrete sampling process. The decoupled learnable temperatures give the optimizer fine-grained control over the exploration-exploitation trade-off for each prompt token, adapting to the optimization landscape. Teacher forcing supplies the model with the exact target tokens after the prompt, creating a stable training signal that focuses the optimization solely on the prompt. This combination yields an efficient, end-to-end trainable pipeline for LMI.

## Foundational Learning
**Language Model Inversion (LMI)**  
*Why needed*: Defines the core task—recovering a prompt that elicits a desired output from a frozen LM—central to understanding the paper’s objective.  
*Quick check*: Given an LM and a target string, can you formulate the optimization problem to find a prompt?

**Gumbel-Softmax (GS) Trick**  
*Why needed*: Enables differentiation through discrete sampling by relaxing the one-hot argmax with a soft approximation, essential for gradient-based optimization of discrete prompts.  
*Quick check*: Explain how adding Gumbel noise to logits and applying softmax with temperature yields a differentiable sample.

**Teacher Forcing**  
*Why needed*: Stabilizes training by feeding ground-truth tokens (the target) into the model during optimization, preventing error accumulation and focusing gradients on the prompt.  
*Quick check*: In sequence modeling, what is teacher forcing and what are its trade-offs?

**Decoupled Learnable Temperature**  
*Why needed*: Standard GS uses a single temperature; per-token adaptation allows the optimizer to balance gradient variance and bias individually, which is critical for handling diverse token positions in the prompt.  
*Quick check*: How would you modify GS parameters to allow each token position to have its own temperature?

**Token Embeddings and Soft Prompts**  
*Why needed*: Soft prompts are represented as weighted combinations of token embeddings, bridging discrete vocabulary and continuous optimization.  
*Quick check*: How do you convert a distribution over tokens into an embedding vector?

## Architecture Onboarding
**Component Map**  
*Z* (logits matrix) → softmax with τ (via GS) → p<sub>soft</sub> (token distribution) → linear combination using embedding matrix *W*<sub>*E*</sub> → soft prompt embedding *E*<sub>prompt</sub> → concatenation with hard target embeddings *E*<sub>target</sub> → add positional embeddings → frozen LM *f*<sub>θ</sub> → output logits → cross-entropy loss. Φ (temperature parameters) influence τ, which affects the gradient flow to *Z*.

**Critical Path**  
1. Initialize *Z* and Φ.  
2. For each optimization step:  
   a. Sample Gumbel noise *g*.  
   b. Compute per-token τ<sub>*i*</sub> from Φ.  
   c. Compute *p* = softmax((*Z* + *g*)/τ).  
   d. Get *E*<sub>prompt</sub> = *p* @ *W*<sub>*E*</sub>.  
   e. Concatenate with *E*<sub>target</sub> (detached).  
   f. Add positional embeddings, run through LM.  
   g. Extract relevant logits (positions predicting target tokens).  
   h. Compute CE loss, average over samples.  
   i. Backpropagate and update *Z*, Φ.  
3. After optimization, derive prompt IDs from argmax of *Z*.

**Design Tradeoffs**  
- Soft vs. hard prompt: soft embeddings provide gradient flow but introduce bias; the GS estimator mitigates this but requires temperature tuning.  
- Decoupled temperature vs. global temperature: per-token flexibility improves performance but adds parameters; the tanh parameterization ensures positivity.  
- Teacher forcing vs. free generation: teacher forcing gives a stable training signal but may create distribution shift at test time; however, since the prompt is optimized to work with teacher forcing, it still generalizes.

**Failure Signatures**  
- **High gradient variance**: indicates temperatures too low; check if τ<sub>*i*</sub> become very small. Might cause noisy updates.  
- **Vanishing gradients**: temperatures too high; check if τ<sub>*i*</sub> explode.  
- **Prompt copying target**: if the learned prompt contains many tokens from the target, teacher forcing may be overfitting; monitor token overlap.  
- **Poor LCS despite low training loss**: possibly due to mismatch between training (teacher forced) and evaluation (autoregressive); could indicate over-reliance on teacher forcing.

**First Three Experiments**  
1. Run DLMI on a single easy target (*k*=1) with *N*=10 and verify LCS approaches 1.0, establishing baseline functionality.  
2. Ablate the learnable temperature by fixing τ to a constant (e.g., 0.1 or 1.0) and compare convergence speed and final LCS across *k* to demonstrate its importance.  
3. Compare DLMI with and without teacher forcing on a moderately difficult target (*k*=11) to quantify TF’s contribution.

## Limitations
- Incomplete specification of key hyperparameters (ε in temperature formula, exact loss details, positional embedding handling) hinders exact replication.  
- Experiments are confined to the SmolLM family of small models; it remains unclear whether DLMI’s advantages hold for larger language models.  
- The teacher forcing component is not isolated in ablation studies, so its independent contribution to performance gains is uncertain.
