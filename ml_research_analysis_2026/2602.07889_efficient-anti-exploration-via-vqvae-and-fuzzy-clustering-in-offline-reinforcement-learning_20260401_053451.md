# Efficient Anti-exploration via VQVAE and Fuzzy Clustering in Offline Reinforcement Learning

## Quick Facts
- **arXiv ID:** 2602.07889
- **Source URL:** https://arxiv.org/abs/2602.07889
- **Reference count:** 40
- **Primary result:** Proposes a multi-codebook VQVAE and FCM-based anti-exploration method that achieves 6.1% higher average normalized score than prior SOTA on Gym tasks, best mean score 142.7 on Maze2d/Adroit, reduces GPU memory to 0.2 GB, and attains nearly 100% codebook vector use rate.

## Executive Summary
Offline reinforcement learning learns policies from fixed datasets without environment interaction, but suffers from overestimation on out-of-distribution state-action pairs. Traditional grid-based anti-exploration methods face dimension disaster and information loss in continuous spaces. This paper introduces an approach that uses a multi-codebook Vector Quantized Variational Autoencoder (VQVAE) to discretize continuous (state, action) pairs into integer label sequences, enabling efficient counting via a Counting Bloom Filter (CBF). A Fuzzy C-Means (FCM) clustering mechanism updates the VQVAE codebooks to improve their utilization. On the D4RL benchmark, the method outperforms the previous state-of-the-art GPC-SAC by 6.1% on Gym tasks, achieves a leading mean score of 142.7 on Maze2d and Adroit, reduces GPU memory consumption from 1.3 GB to 0.2 GB, and reaches approximately 100% codebook vector usage through FCM.

## Method Summary
The system combines an entropy-regularized SAC agent with a custom pseudo-counting module. The VQVAE encodes concatenated state-action vectors into a latent space, splits it into H subspaces, and quantizes each subspace using an independent codebook of size N. This yields a tuple of discrete labels. The labels are hashed into a Counting Bloom Filter to obtain an approximate pseudo-count n(s,a). During SAC training, a penalty term p(s,a)=β ln(t)/√(n(s,a)) is subtracted from Q-values in the critic target, discouraging out-of-distribution actions. The VQVAE is trained jointly with a reconstruction loss (MSE on actions), codebook loss, and commitment loss. Concurrently, codebook vectors are refined using FCM: fuzzy membership degrees are computed between the pre-quantization latent vectors and all codebook vectors; each codebook update is a weighted average scaled by a usage-rate-dependent factor α. The training loop alternates between batch sampling, pseudo-count retrieval, SAC updates, and VQVAE/FCM updates. The multi-codebook design avoids the curse of dimensionality of grids, while FCM ensures high codebook utilization.

## Key Results
- 6.1% higher average normalized score than GPC-SAC on D4RL Gym tasks.
- Best mean score 142.7 on Maze2d and Adroit environments.
- GPU memory consumption reduced to 0.2 GB (from 1.3 GB); codebook vector use rate nearly 100% via FCM.

## Why This Works (Mechanism)
The multi-codebook VQVAE provides a compact discrete representation of continuous state-action pairs, sidestepping the exponential explosion of grid discretization. By partitioning the latent space into independent subspaces, each codebook covers a distinct region, enabling fine-grained discretization with moderate total codebook size. The Counting Bloom Filter yields memory-efficient approximate counts for label tuples, naturally handling collisions in high-dimensional discrete spaces. FCM updates codebooks using soft membership degrees and an α term that amplifies updates for underutilized vectors, preventing dead codes and promoting near-full coverage. The penalty derived from pseudo-counts scales inversely with count, effectively downweighting rarely seen tuples and stabilizing off-policy evaluation. Together these components mitigate OOD overestimation while maintaining low memory footprint.

## Architecture Onboarding
**Component Map:**  
Data (s,a) -> VQVAE Encoder -> Latent Split (H subspaces) -> Multi-codebook Quantization -> Label Sequence (l1,...,lH) -> Hash to Counting Bloom Filter -> Pseudo-count n(s,a) -> Penalty p(s,a) -> Subtracted from Q-target in SAC Critic Update; VQVAE Decoder reconstructs a; FCM updates codebooks using pre-quantization latents and membership degrees.

**Critical Path:**  
1. Sample batch from dataset.  
2. For each (s,a), forward through VQVAE encoder and quantizers to obtain label sequence.  
3. Query CBF with the label sequence to get n(s,a).  
4. Compute penalty p(s,a)=β ln(t)/√(n(s,a)).  
5. Update SAC critic: minimize mean squared error between Q(s,a) and r+γ(min Q_target(s',a') - p(s',a')).  
6. Update SAC actor via policy gradient with entropy term.  
7. Update VQVAE: reconstruction loss (action MSE) + codebook loss + commitment loss; then compute fuzzy memberships and apply FCM codebook updates (scaled by α).

**Design Tradeoffs:**  
- *Number of subspaces H*: Larger H increases discretization granularity but raises the count space size exponentially (N^H); H balances expressivity and memory.  
- *FCM vs hard clustering*: Soft memberships prevent dead codes but add computational overhead; α scaling further biases updates toward underused codes.  
- *CBF size*: Smaller memory increases collisions, causing overestimated counts (weaker penalty); larger memory reduces collisions but consumes more memory.  
- *VQVAE training schedule*: Joint online updating adapts to data distribution but risks instability; pretraining and freezing yields stable counts at the cost of possible mismatch.

**Failure Signatures:**  
- Codebook use rate remains low (<50%) after many updates → α scaling may be too small or membership calculation incorrect.  
- CBF counters saturate or all cluster near zero → penalty vanishes or blows up, respectively; adjust count size or hash functions.  
- VQVAE reconstruction loss plateaus at a high value → insufficient codebook capacity or training instability.  
- SAC critic loss diverges or actor does not improve after adding penalty → penalty magnitude (β) may be inappropriate.

**First Three Experiments:**  
1. Train VQVAE alone on a D4RL dataset (e.g., halfcheetah-medium) and verify reconstruction loss decreases and codebook usage exceeds 80%.  
2. Initialize CBF with a small dataset, manually inject known frequencies, and check that retrieved counts track true frequencies within expected error bounds.  
3. Run the full algorithm on halfcheetah-medium-v2 for a few hundred gradient steps; compare the normalized score to a baseline SAC without penalty to confirm the anti-exploration effect.
