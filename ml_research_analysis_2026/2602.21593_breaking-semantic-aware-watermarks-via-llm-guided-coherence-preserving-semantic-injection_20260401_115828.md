# Breaking Semantic-Aware Watermarks via LLM-Guided Coherence-Preserving Semantic Injection

## Quick Facts
*   **arXiv ID:** 2602.21593
*   **Source URL:** https://arxiv.org/abs/2602.21593
*   **Reference Count:** 12
*   **Primary Result:** Proposes a Coherence-Preserving Semantic Injection (CSI) attack that achieves an 81% attack success rate against the SEAL semantic watermark while causing significantly less semantic drift (24.1% lower FID) than unconstrained regeneration.

## Executive Summary
This paper identifies a critical vulnerability in content-aware semantic watermarking systems like SEAL. The authors introduce the Coherence-Preserving Semantic Injection (CSI) attack, which leverages large language models (LLMs) to generate semantically coherent prompt edits. These edits alter the specific attributes that the watermark detector uses for verification while preserving the global meaning and visual coherence of the original image. By deterministically reusing the original diffusion noise schedule, the attack cleanly isolates the effect of semantic changes on the watermark signal. The result is a highly effective evasion technique with an 81% attack success rate against SEAL, far surpassing prior attacks, and a demonstrated ability to maintain image quality.

## Method Summary
The CSI attack operates in three core stages. First, an LLM is prompted to generate multiple candidate text edits for the original image caption, with explicit constraints to preserve global semantic "anchors" (main objects) while injecting a target attribute change. Second, for each candidate prompt, the attacker regenerates an image using the exact latent noise and noise schedule extracted via DDIM inversion from the original watermarked image. This deterministic regeneration binds the new image semantics to the original watermark-embedded signal. Third, a Consistency-Based Hierarchical Filtering (CHF) pipeline progressively screens candidates using text embedding similarity (anchor preservation), visual caption similarity (coherence), and a final watermark-specific noise-image similarity score to select the final set of attack images that are both coherent and likely to evade detection.

## Key Results
*   Against the SEAL semantic watermark, the CSI attack achieves an **81% Attack Success Rate (ASR)**, while prior baseline attacks (RPM, LFA) fail with 0–7% ASR.
*   CSI significantly reduces semantic drift compared to unconstrained regeneration, achieving a **24.1% lower Fréchet Inception Distance (FID)**.
*   The attack successfully manipulates the core detection statistic of SEAL (e.g., patch-match count), shifting its distribution far beyond the detection threshold.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** LLMs generate semantically coherent prompt edits that preserve global image semantics while altering local attributes targeted by the watermark.
**Mechanism:** The LLM acts as a black-box proposer within a constrained meta-prompt. Given the original caption, a set of extracted global semantic anchors (e.g., primary objects), and a target attribute to inject, the LLM outputs a batch of candidate edits. The meta-prompt enforces anchor retention and grammatical coherence, leveraging the LLM's structured reasoning to perform fine-grained semantic edits without global drift.
**Evidence Anchors:** The abstract states LLMs enable "locally fine-grained but globally coherent semantic alterations." Section 2.1 describes crafting a meta-prompt for "semantically coherent prompt candidates."

### Mechanism 2
**Claim:** Reusing the original diffusion noise schedule during regeneration binds the edited image to the watermark's embedded signal, making attack success dependent on semantic alignment.
**Mechanism:** The attacker performs DDIM inversion on the watermarked image to extract its exact initial latent noise (`z_T`) and the full noise schedule `{ϵ_t}`. Regenerating an image from any new prompt using this fixed `(z_T, {ϵ_t})` produces a result whose watermark detection score is determined by the semantic consistency between the new prompt/image and the noise-embedded signal. This removes stochasticity from the generation process.
**Evidence Anchors:** The abstract notes the attack "alters watermark-relevant attributes while preserving global image semantics under embedding-space constraints." Section 2.1 details using "DDIM inversion and noise copying to save the watermark-consistent noise semantics."

### Mechanism 3
**Claim:** The Consistency-Based Hierarchical Filtering (CHF) pipeline efficiently identifies candidate prompts that both preserve anchor semantics and maintain the watermark-specific noise-image alignment.
**Mechanism:** Candidate prompts undergo sequential, cost-escalating filters: 1) **Textual filter** compares anchor token embeddings; 2) **Visual anchor filter** checks BLIP caption alignment of the regenerated image; 3) **CSW filter** measures cosine similarity between the regenerated image embedding and the copied noise embedding. Only prompts passing all thresholds (`τ_text`, `τ_vis`, `τ_csw`) yield final attack images.
**Evidence Anchors:** The abstract mentions alignment that "enforces visual-semantic consistency while selectively perturbing watermark-relevant semantics." Section 2.2 formally defines the filtering thresholds and the final attack set `X_attack`.

## Foundational Learning
*   **Concept: Content-aware Semantic Watermarking (e.g., SEAL)**
    *   *Why needed here:* It is the primary target defense. Understanding how it binds a watermark to image semantics (via noise-content consistency) explains why naive semantic attacks fail and why CSI's coherence preservation is necessary.
    *   *Quick check:* How does SEAL's verification differ from noise-only watermarks like Tree-Ring, and why does that difference necessitate a coherence-preserving attack?
*   **Concept: Diffusion Model Inversion & Noise Copying**
    *   *Why needed here:* It is the technical linchpin that makes the attack deterministic. Exact noise reuse ensures that any change in the detector's output is attributable solely to the semantic edit, not generative randomness.
    *   *Quick check:* What is the purpose of DDIM inversion in CSI, and why is copying the original `{ϵ_t}` schedule critical?
*   **Concept: Text-Image-Noise Embedding Alignment**
    *   *Why needed here:* CSI uses cosine similarity in a shared embedding space (CLIP/BLIP) as the quantifiable proxy for "semantic coherence" and "watermark semantic binding." This metric operationalizes the attack's constraints and filtering criteria.
    *   *Quick check:* Why might embedding-space similarity be a more appropriate constraint for this attack than pixel-level metrics (e.g., PSNR)?

## Architecture Onboarding
*   **Component map:** Input Analyzer -> LLM Prompt Generator -> Embedding Encoders -> Diffusion Regenerator -> Hierarchical Filter (CHF) -> (Watermark Verifier for evaluation only).
    *   The Analyzer extracts `x0`, `t0`, and global anchors `G`.
    *   The Generator produces candidate prompts `t'` from `(t0, G, attack intent)`.
    *   Encoders compute embeddings for text, regenerated images, and noise.
    *   The Regenerator uses `SD_regen(z_T, t', {ϵ_t})`.
    *   CHF applies thresholds on `s_text`, `s_vis`, and `Δ_csw`.
*   **Critical path:** `x0` (watermarked image) → Analyzer → `(t0, G)` → LLM Generator → `P` (candidate prompts) → CHF (text filter) → `C` (passed candidates) → Diffusion Regenerator (with `z_T`, `{ϵ_t}` from `x0`) → `x'_i` → CHF (visual & CSW filters) → `X_attack`.
*   **Design tradeoffs:**
    *   LLM creativity (temperature) vs. anchor preservation coherence.
    *   Filter threshold tuning (`τ_csw` most critical) for balancing attack validity and recall.
    *   Generality of noise reuse assumption (depends on target watermark's verification protocol).
*   **Failure signatures:**
    *   High FID (>200): Global semantic drift, likely failing visual anchor filter.
    *   Low ASR (<20%): Edits fail to perturb watermark-relevant semantics (`Δ_csw` too high) or CHF over-filters.
    *   Incoherent BLIP captions: Visual anchor filter failure; regenerated `x'_i` does not match prompt.

## Open Questions the Paper Calls Out
*   **Open Question 1:** How can semantic watermarking schemes be redesigned to be robust against LLM-driven coherence-preserving semantic injections? The paper exposes the vulnerability in SEAL but does not propose defensive modifications.
*   **Open Question 2:** To what extent does the efficacy of the CSI attack depend on the choice of large language model used for semantic manipulation? The study only uses GPT-4o-mini.
*   **Open Question 3:** How sensitive is the CSI attack to imperfections in noise inversion and the availability of the original noise schedule during the attack? The evaluation assumes ideal conditions with perfect DDIM inversion and noise copying.
*   **Open Question 4:** Is the CSI attack transferable to semantic watermarking schemes that use different semantic encoders (e.g., CLIP-based) instead of BLIP? Experiments are limited to SEAL, which uses BLIP.

## Limitations
*   Unspecified hyperparameters: LLM temperature, exact CHF thresholds (`τ_text`, `τ_vis`, `τ_csw`), and meta-prompt wording require empirical tuning.
*   Missing implementation details: Exact BLIP/CLIP model versions, embedding dimensions, and anchor extraction method are not fully specified.
*   Attack assumption dependency: The method's determinism relies on the target watermark's verification using the exact same noise schedule; this may not hold for all content-aware watermarks.

## Confidence
*   **LLM-driven coherent semantic edits:** Medium confidence. Mechanism is plausible but depends on unspecified prompt engineering and thresholds.
*   **Noise reuse deterministically binds watermark signal:** High confidence. DDIM inversion and noise copying are standard techniques aligned with SEAL's described verification.
*   **Consistency-Based Hierarchical Filtering (CHF) effectiveness:** Medium confidence. Logic is sound, but impact of unspecified thresholds and embedding choices is unclear.
