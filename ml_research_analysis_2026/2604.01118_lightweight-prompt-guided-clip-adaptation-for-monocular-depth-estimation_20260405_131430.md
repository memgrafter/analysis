# Lightweight Prompt-Guided CLIP Adaptation for Monocular Depth Estimation
## Quick Facts
- arXiv ID: 2604.01118
- Source URL: https://arxiv.org/abs/2604.01118
- Reference count: 30
- Primary result: MoA-DepthCLIP improves δ1 accuracy on NYU Depth V2 from 0.390 to 0.745 and reduces RMSE from 1.176 to 0.520 compared to DepthCLIP, while adding only ~0.1M trainable parameters (~0.1% of ViT-B/32).

## Executive Summary
MoA-DepthCLIP adapts the CLIP vision-language model for monocular depth estimation using a lightweight Mixture-of-Adapters (MoA) and a global scene context vector. The method freezes most of the CLIP ViT backbone, inserts a small number of MoA modules at selected layers, and adds a hybrid prediction head that combines depth bin classification and regression. A composite loss with cross-entropy, L1, and SILog terms encourages accurate metric depth. On NYU Depth V2, the approach achieves a 90% relative improvement in δ1 accuracy over the DepthCLIP baseline while adding only 0.1M trainable parameters, demonstrating highly parameter-efficient transfer of semantic knowledge to geometric tasks.

## Method Summary
The architecture builds on a frozen CLIP ViT-B/32 backbone. At layers 2, 5, 8, and 11, a Mixture-of-Adapters (MoA) module is inserted: each token is routed via a gating network to a weighted combination of K=4 bottleneck experts, and the output is added residually to the original token. The final four transformer blocks are selectively fine‑tuned. A global semantic context vector is constructed by encoding a fixed set of indoor scene prompts with the frozen CLIP text encoder, averaging the ℓ2‑normalized embeddings, and broadcasting this vector to the spatial dimensions of the visual feature map; it is then concatenated to the features. Two prediction heads consume the fused features: a classification head predicts a distribution over N=128 fixed depth bins, and a regression head directly outputs continuous depth. The final depth estimate combines both outputs. Training minimizes a composite loss: λ_cls·CE + λ_reg·L1 + λ_silog·SILog (λ_cls=1, λ_reg=1, λ_silog=0.5) using AdamW for 30 epochs.

## Key Results
- δ₁ accuracy improved from 0.390 (DepthCLIP) to 0.745 (MoA-DepthCLIP) on NYU Depth V2.
- RMSE reduced from 1.176 to 0.520, a 56% error reduction.
- The approach adds only ~0.1M trainable parameters (≈0.1% of the ViT-B/32 backbone), demonstrating extreme parameter efficiency.

## Why This Works (Mechanism)
### Mechanism 1: Mixture‑of‑Adapters for Spatial Specialization
Inserting lightweight MoA modules into a frozen CLIP ViT backbone enables token‑specific adaptation while preserving pre‑trained semantic knowledge. For each token, a gating MLP produces routing probabilities over K=4 experts, each a two‑layer bottleneck MLP. The expert outputs are summed with weights and added to the original frozen token via a residual connection. Modules are placed sparsely at layers 2,5,8,11, allowing localized refinement of features without destabilizing global representations. Core assumption: CLIP’s features need only minor, spatially‑varying adjustments to encode geometry. Evidence: The paper’s architecture description (Section 3.1) and Table 1 ablations showing that adding MoA to a composite‑loss baseline yields substantial gains. Break condition: Monitor gating entropy (Eq. 4); low entropy signals expert collapse, and increasing K beyond 4 yields no improvement.

### Mechanism 2: Global Scene Context Vector
A fixed global context vector derived from frozen CLIP text embeddings provides a high‑level indoor scene prior that stabilizes depth prediction. A set of indoor scene prompts (e.g., “a photo of a kitchen”) is encoded by the text encoder; their ℓ2‑normalized embeddings are averaged to produce a single vector `c`. This vector is broadcast spatially and concatenated to the visual feature map before the prediction heads. Core assumption: A generic, parameter‑free scene prior is sufficient and more robust than learned per‑image prompts. Evidence: Abstract and Section 3.2; the approach is simpler than prompt‑learning methods yet effective. Break condition: If the prompt set is misaligned with the target distribution (e.g., outdoor scenes), performance degrades; concatenation could also introduce noise if `c` is uninformative.

### Mechanism 3: Hybrid Classification‑Regression Head with Composite Loss
A dual‑head output with both depth bin classification and direct regression, supervised by a composite loss, synergizes coarse layout learning and fine‑grained metric accuracy. The classification head predicts a distribution over N=128 fixed bins (weighted sum yields binned depth), while the regression head outputs continuous depth. Loss L = λ_cls·CE + λ_reg·L1 + λ_silog·SILog (λ_cls=1, λ_reg=1, λ_silog=0.5). The SILog term enforces scale invariance. Core assumption: Classification provides stable coarse structure, regression captures details, and the loss balance is effective. Evidence: Section 3.4 and Table 1 ablations showing the largest δ₁ jump when the composite loss is introduced. Break condition: Imbalanced λ weights can cause training instability; e.g., high λ_silog may dominate due to variance term.

## Foundational Learning
- **Vision Transformer (ViT) token processing**: The MoA modules operate on token representations; understanding residual connections, layer placement (early vs. late layers), and gradient flow when freezing most of the backbone is essential. Quick check: If you freeze the backbone but add adapters, gradients only flow through unfrozen parameters; early‑layer adaptation may affect low‑level features, late layers high‑level semantics.  
- **Parameter‑Efficient Fine‑Tuning (PEFT)**: Adapters (including MoA) are bottleneck modules that add few parameters. The Mixture‑of‑Adapters introduces a gating network to route tokens to multiple experts, enabling specialization without large parameter overhead. Quick check: How does deterministic routing (Eq. 3) differ from stochastic routing (e.g., AdaMix), and why might deterministic be more stable for dense prediction?  
- **Depth estimation loss functions**: The composite loss combines Cross‑Entropy for bins, L1 for regression, and Scale‑Invariant Logarithmic (SILog) loss to handle scale ambiguity. SILog penalizes relative errors and is crucial for metric depth. Quick check: Why use both classification and regression losses? What types of errors does each mitigate (e.g., classification reduces boundary errors, regression reduces scale drift)?

## Architecture Onboarding
Component map:  
RGB image → CLIP ViT‑B/32 backbone (frozen) with MoA modules at layers 2,5,8,11 (last 4 blocks fine‑tuned) → [global context vector `c` concatenated to spatial feature map] → two prediction heads (classification over 128 bins, regression for continuous depth) → fused depth output.

Critical path: The performance boost primarily stems from (1) swapping to a strong vision backbone (CLIP ViT), (2) integrating the composite loss, and (3) adding MoA modules. Training stability relies on proper loss weighting and monitoring gating entropy.

Design tradeoffs:  
- *Parameter efficiency vs. accuracy*: MoA adds ~0.1M params versus full fine‑tuning (~86M), but still lags behind state‑of‑the‑art non‑CLIP methods.  
- *Fixed bins (N=128) vs. adaptive bins*: Fixed bins simplify but may not cover extreme depth ranges; adaptive bins could improve extreme cases at cost of complexity.  
- *Deterministic vs. stochastic gating*: Deterministic routing (used here) eases inference but might limit expert diversity compared to stochastic routing.  
- *Global context vs. learned prompts*: Fixed context vector is parameter‑free but less adaptive; learned prompts could generalize better but add parameters.

Failure signatures:  
- **Expert collapse**: Gating entropy (Eq. 4) near zero indicates one expert dominates, reducing specialization. Remedy: add load‑balancing loss or adjust initialization.  
- **Regression neglect**: If L_cls dominates, the regression head may be ignored, leading to discretized outputs; track loss magnitudes and adjust λ_reg.  
- **Context mismatch**: Using indoor prompts on outdoor data degrades performance.  
- **Training instability**: Excessive λ_silog can cause divergence due to the variance term.

First 3 experiments for verification:  
1. Reproduce the DepthCLIP baseline (ViT‑B/32, 10 bins, no MoA, no composite loss) and confirm δ₁ ≈ 0.417, RMSE ≈ 1.176.  
2. Add the composite loss to the baseline (keep 10 bins, no MoA) and measure improvement in δ₁/RMSE (expected large jump).  
3. Insert MoA modules (K=4) at layers {2,5,8,11} with composite loss; monitor gating entropy to detect expert collapse and verify incremental improvement.

## Open Questions the Paper Calls Out
1. **Generalization to outdoor scenes** – The method is evaluated only on indoor NYU Depth V2. It is unclear whether the MoA‑DepthCLIP framework transfers to outdoor datasets (e.g., KITTI) or if the fixed indoor scene context vector becomes a liability.  
2. **Dynamic prompt selection** – The current approach uses a static, averaged prompt embedding. Incorporating an attention‑based mechanism to select or weight prompts per image could improve robustness and accuracy.  
3. **Optimal MoA placement** – The choice of layers {2,5,8,11} is based on empirical intuition. A systematic study of alternative insertion strategies (early‑only, late‑only, uniform) could uncover better trade‑offs between adaptation and parameter efficiency.  
4. **Learned vs. fixed prompts** – Replacing the fixed global context with a small set of learnable prompt tokens (prompt tuning) might yield better depth estimates by allowing the model to refine the semantic prior.  
5. **Loss weight sensitivity** – The composite loss uses fixed weights (λ_cls=1, λ_reg=1, λ_silog=0.5) without justification. Adaptive weighting schemes could improve training stability and final accuracy.

## Limitations
- Missing details: exact prompt set and depth binning scheme for N=128 are unspecified, hindering full reproduction.
- Evaluation limited to indoor NYU Depth V2; outdoor generalization and comparisons to non‑CLIP SOTA are absent.
- Lack of empirical analysis on MoA behavior (e.g., gating entropy, expert collapse) and on the contribution of the global context vector.

## Confidence
- MoA efficiency: **Medium** – architecture is clear but training dynamics and potential expert collapse are not analyzed.
- Global context contribution: **Low to Medium** – no ablation study isolates its impact; claim rests on assumption.
- Hybrid head & composite loss: **Medium** – ablations show improvement, but weight sensitivity is unexplored.
- Overall reported performance: **Medium** – large improvements are promising, but missing details limit verification.
