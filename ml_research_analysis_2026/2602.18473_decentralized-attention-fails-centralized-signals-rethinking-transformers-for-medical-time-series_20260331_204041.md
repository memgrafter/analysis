# Decentralized Attention Fails Centralized Signals: Rethinking Transformers for Medical Time Series

## Quick Facts
- **arXiv ID:** 2602.18473
- **Source URL:** https://arxiv.org/abs/2602.18473
- **Reference count:** 40
- **Primary result:** TeCh framework with CoTAR module outperforms previous SOTA (Medformer) on multiple MedTS datasets, achieving up to 12.13% higher average of six metrics while using only 33% memory and 20% inference time, and shows robustness to channel noise.

## Executive Summary
The paper argues that Transformers' decentralized attention is mismatched to medical time series (MedTS) signals, which originate from centralized biological sources (e.g., brain for EEG, heart for ECG). To address this, they propose TeCh, a framework with two main innovations: (1) CoTAR, a module that replaces attention with a global core token that aggregates and redistributes information, enabling linear-complexity centralized interaction; (2) adaptive dual tokenization that separately processes temporal and channel embeddings. Evaluated on five MedTS datasets under subject-independent protocols, TeCh consistently surpasses Medformer, achieving significant improvements in accuracy and efficiency, and demonstrates superior robustness to channel noise.

## Method Summary
TeCh processes multivariate medical time series (T×C) by first applying adaptive dual tokenization: temporal tokens are created by patching the time dimension and flattening across channels, while channel tokens treat each channel’s full series as a token. These two sets of tokens are processed independently by separate stacks of Transformer encoders that use the proposed CoTAR module instead of standard attention. CoTAR replaces pairwise attention with a single learnable core token: each token computes a representation, a softmax-weighted sum aggregates these into the core token, and the core is broadcast back to all tokens. All operations are MLP-based, reducing complexity from O(S²) to O(S). The final representations from both branches are average-pooled, summed, and fed to a linear classifier. Training includes a set of data augmentations (temporal flip, channel shuffle, masking, jitter, dropout) applied randomly per sample. The framework is evaluated on three EEG and two ECG datasets with subject-independent splits, using six classification metrics, memory, and inference time.

## Key Results
- TeCh outperforms Medformer (previous SOTA) on all five MedTS datasets, with up to 12.13% higher average of six metrics (accuracy, precision, recall, F1, AUROC, AUPRC) on APAVA.
- TeCh uses only 33% memory and 20% inference time compared to Medformer.
- CoTAR shows superior robustness to channel noise relative to standard attention, confirming its alignment with centralized MedTS characteristics.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Transformers' decentralized attention mismatches the centralized nature of medical time series signals.
- **Mechanism:** Standard attention allows every token to directly interact with all others in a pairwise manner, forming a decentralized graph. MedTS, however, originates from a unified biological source (e.g., brain for EEG, heart for ECG) and exhibits central coordination. The mismatch dilutes the principal patterns and impairs channel dependency modeling.
- **Core assumption:** MedTS signals possess an inherent centralized organization that should be reflected in the model's interaction structure.
- **Evidence anchors:** 
  - [abstract] "MedTS signals are inherently centralized, whereas the Transformer’s attention is decentralized"
  - [Section 1] "MedTS signals typically originate from a centralized biological source... For example, EEG rhythms emerge from thalamo–cortical circuits..."
  - [corpus] Weak; neighboring works retain standard attention and do not address the centralized mismatch.
- **Break condition:** If signal sources are truly decentralized or channel dependencies are negligible (e.g., multi-sensor IoT), the centralized assumption fails and CoTAR may not help.

### Mechanism 2
- **Claim:** CoTAR replaces attention with a centralized proxy token, enabling efficient linear-complexity channel interaction aligned with MedTS centralization.
- **Mechanism:** CoTAR introduces a learnable global core token. Each channel token is projected and aggregated into the core via a weighted sum (softmax). The core is then broadcast back to every token. All operations use MLPs, avoiding quadratic pairwise computations. The star-shaped communication mirrors physiological central control.
- **Core assumption:** A single aggregated token can capture and redistribute essential cross-channel context without significant loss.
- **Evidence anchors:**
  - [abstract] "we propose CoTAR (Core Token Aggregation-Redistribution), a centralized MLP-based module tailored to replace the decentralized attention."
  - [Section 4.1] "CoTAR introduces a global core token that acts as a proxy to facilitate the inter-token interaction, thereby enforcing a centralized aggregation and redistribution strategy... reduces the computational complexity from quadratic to linear."
  - [corpus] Weak; no retrieved prior work adopts a similar core-token proxy for MedTS. Closest are works using fixed auxiliary tokens but they remain coupled with quadratic attention.
- **Break condition:** If channel interactions are highly non-linear and cannot be compressed into one vector, CoTAR may underfit. Also, extremely many channels (>1000) may require scaling the core dimension.

### Mechanism 3
- **Claim:** Adaptive dual tokenization (separate temporal and channel embeddings) allows TeCh to flexibly capture both temporal and channel dependencies, adapting to dataset-specific patterns.
- **Mechanism:** The raw matrix X∈R^{T×C} is transformed into: (a) Temporal tokens: split time into P patches of length L, flatten each patch across channels → (P, D). (b) Channel tokens: flatten each channel’s full series → (C, D). Both are processed by independent Transformer stacks (with CoTAR). Their outputs are average-pooled, summed, and classified. Hyperparameters M (temporal encoders) and N (channel encoders) can be tuned or zeroed.
- **Core assumption:** Temporal and channel dependencies are best modeled at distinct granularities, and a combined representation improves robustness across heterogeneous MedTS.
- **Evidence anchors:**
  - [abstract] "TeCh framework employs adaptive dual tokenization to separately process temporal and channel embeddings, allowing flexible modeling of both dependency types."
  - [Section 4.2] "We form a temporal token by aggregating one or multiple timestamps across channels... Then, following iTransformer, we form a token by aggregating the whole series across all timestamps of a channel."
  - [corpus] Strong; iTransformer introduced channel-wise tokens, while many Transformers use temporal patching. TeCh uniquely combines both and adapts M,N.
- **Break condition:** If one dependency dominates and the other branch adds noise, fixed M,N may misbalance; careful validation is needed. Dual branch also doubles parameters relative to a single branch.

## Architecture Onboarding
- **Component map:** Input X ∈ R^{T×C} → Adaptive Dual Tokenizer → temporal tokens E ∈ R^{P×D} and channel tokens H ∈ R^{C×D} → Temporal Encoder Stack (M blocks with CoTAR) processes E; Channel Encoder Stack (N blocks) processes H → Fusion: average pool each stack’s output → ˜O_te, ˜O_ch; sum them → Classifier: linear layer (W_y, b_y) → logits Ŷ ∈ R^{K}
- **Critical path:** X → augmentation → dual tokenization → parallel encoder stacks → average pooling → sum → linear projection → loss → backprop.
- **Design tradeoffs:**
  - Centralization vs expressive power: CoTAR reduces quadratic cost but may lose fine-grained pairwise interactions; best when a global summary suffices.
  - Dual branch vs efficiency: Using both branches doubles memory/parameters; setting one to zero adapts to dataset characteristics.
  - Core token dimension D_c: Default D/4 balances capacity and cost; larger D_c reduces bottleneck but increases parameters.
- **Failure signatures:**
  - Performance drop on data with strong local pairwise channel couplings not captured by a single core token.
  - Training instability (NaNs, exploding gradients) in CoTAR’s MLP layers.
  - High variance across seeds when dual branch is enabled without sufficient data.
  - In robustness tests, rapid degradation with channel noise suggests the core token aggregates noise; check weighting.
- **First 3 experiments:**
  1. Benchmark comparison: Evaluate TeCh vs ten baselines on five MedTS datasets under subject-independent splits; TeCh outperforms SOTA (e.g., +12% avg on APAVA) with lower memory/time.
  2. Ablation on dual tokenization: Compare no tokenization, temporal only, channel only, and both. Combining both yields best accuracy/F1 on most datasets, validating adaptivity.
  3. Robustness to channel noise: Add Gaussian noise to last channel of PTB; CoTAR degrades slower than attention, confirming centralized resilience.

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** How can the optimal tokenization strategy (Temporal, Channel, or Dual) be automatically determined for an unseen MedTS dataset?
- **Basis:** The TeCh framework requires manual selection of M (temporal encoders) and N (channel encoders) per dataset. No automatic tuning mechanism is provided.
- **Why unresolved:** Manual tuning is resource-intensive and may not generalize to new signals; a data-driven method is needed.
- **What evidence would resolve it:** A meta-learning or validation metric that predicts optimal M and N from dataset statistics and validates on a held-out set.

### Open Question 2
- **Question:** Does CoTAR's centralized attention mechanism generalize to other centralized physiological signals such as fMRI or EMG?
- **Basis:** The authors state: "We posit that such a centralized architecture could also inform the modeling of signals originating from centralized sources, e.g., fMRI." (Section 5.4)
- **Why unresolved:** No experiments on fMRI or other modalities; unclear if centralization assumption holds for all MedTS.
- **What evidence would resolve it:** Empirical evaluation of TeCh on multiple fMRI and EMG datasets under subject-independent protocols, with comparison to standard attention.

### Open Question 3
- **Question:** What is the physiological meaning of the core token learned by CoTAR, and can its features be used as interpretable biomarkers?
- **Basis:** The core token is visualized to be centrally located in embedding space and interpreted as "a latent summary of temporal coherence," but no direct clinical correlation is established.
- **Why unresolved:** Interpretability is crucial for medical AI; linking core token to known physiological markers would increase clinical utility.
- **What evidence would resolve it:** Statistical analysis (e.g., regression, correlation) between core token projections and ground-truth clinical scores (e.g., disease severity, cognitive tests) across multiple datasets.

### Open Question 4
- **Question:** Can CoTAR's linear complexity be preserved while allowing more expressive channel interactions than a single core token, such as hierarchical or dynamic cores?
- **Basis:** CoTAR uses a fixed-size core token aggregated globally; the paper does not explore variants with multiple cores or learnable aggregation weights.
- **Why unresolved:** A single core token may oversimplify complex channel dependencies, especially in heterogeneous MedTS.
- **What evidence would resolve it:** Design extensions (e.g., grouping channels into multiple core tokens, adaptive core token generation) and test on datasets with high channel diversity, measuring performance vs. computational cost.

## Limitations
- Major uncertainties hindering faithful reproduction include unspecified encoder block details (norm order, dropout rates, FFN expansion), ambiguous augmentation protocols (selection probabilities, branch application), unclear position embedding design (learnable vs. fixed), and the core token dimension (fixed at D/4?).
- The paper's core claims have medium confidence due to weak direct evidence for the centralization mismatch and theoretical limits for extreme channel counts.
- Performance and efficiency results may not be directly reproducible without clarifying these implementation details.

## Confidence
- **Claim 1:** Transformers' decentralized attention mismatches centralized MedTS signals. -> Medium confidence
- **Claim 2:** CoTAR's core token enables efficient linear-complexity channel interaction aligned with MedTS centralization. -> Medium confidence
- **Claim 3:** Adaptive dual tokenization flexibly models both temporal and channel dependencies. -> High confidence
