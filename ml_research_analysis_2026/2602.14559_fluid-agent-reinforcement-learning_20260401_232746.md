# Fluid-Agent Reinforcement Learning

## Quick Facts
- **arXiv ID:** 2602.14559  
- **Source URL:** https://arxiv.org/abs/2602.14559  
- **Reference count:** 40  
- **Primary result:** Joint-return optimizers (e.g., VDN, MAPPO) learn dynamic population control in fluid-agent environments, while per-agent optimizers do not; fluid teams outperform fixed-size groups in variable tasks and adapt behavior (e.g., level inheritance, policy switching) to environmental demands.

## Executive Summary
This paper introduces fluid-agent reinforcement learning, where agents can spawn new agents during execution, formalized as Partially Observable Fluid Stochastic Games (POFSG). Theoretical results prove existence of Nash and subgame-perfect equilibria. Empirical evaluations on adapted multi-agent benchmarks (Predator–Prey, Level-Based Foraging) and a new PuddleBridge environment demonstrate that algorithms optimizing joint return adapt team size to task difficulty (e.g., more prey), whereas per-agent optimizers fail to spawn strategically. Fluid agents also optimize spawned characteristics (e.g., level inheritance) and exhibit conditional policy switching in PuddleBridge, yielding superior performance in variable environments.

## Method Summary
The authors define fluid-agent environments where the action space includes a `spawn` move that adds a new agent if the population is below a ceiling. New agents inherit parent level (in Level-Based Foraging) and appear at random empty cells. Observations combine spatial data (grid/map) with non-spatial features (agent ID, coordinates, previous joint action, parent indicator, counts). Rewards incorporate capture reward `P`, per-alive step cost `c_step`, and spawn cost `c_spawn` (shared among alive agents). Two payoff variants are studied: Size-Inverse Payoff (SIP) divides `P` by current population, Size-Constant Payoff (SCP) does not. Training uses standard MARL algorithms: IQL (independent), VDN (value decomposition), independent PPO, and MAPPO (centralized critic, optionally with global state). Hyperparameters and network architectures (CNNs for grid-worlds, MLPs for vector observations) are provided. Evaluation metrics include normalized joint return, alive agent count, and task-specific success rates.

## Key Results
- Joint optimizers (VDN, MAPPO) dynamically adjust population size in response to environmental demands (e.g., more prey), while per-agent optimizers (IQL, independent PPO) do not.
- Under Size-Constant Payoff, joint optimizers spawn more agents to maximize total reward; under Size-Inverse Payoff, they limit population to avoid dilution.
- Fluid-agent teams outperform fixed-size counterparts in variable tasks (e.g., varying prey counts) and optimize spawned agent characteristics (e.g., level inheritance in Level-Based Foraging).
- In PuddleBridge, policies learn to switch between fluid and non-fluid behaviors based on gate conditions.

## Why This Works (Mechanism)
Joint-return optimization internalizes the externality of each agent’s contribution to team reward, making spawning beneficial when it increases total return. In contrast, per-agent optimization (e.g., independent Q-learning) fails to account for how additional agents affect others’ rewards, especially under SIP. The spawn action provides a direct lever for population control, and the inclusion of parent indicators and previous joint actions in observations enables coordination on when to spawn. The theoretical POFSG framework guarantees equilibria where such strategies can be stable.

## Architecture Onboarding
**Component map**  
Environment → Observations (spatial + non-spatial) → Networks (CNN/MLP) → Action selection (move/spawn) → Transition/reward → Replay buffer → Loss computation → Network update  
Critic (MAPPO) uses concatenated observations or global state; VDN uses per-agent Q-networks with additive mixing.

**Critical path**  
1. Episode initialization: sample initial population and ceiling.  
2. Step: agents select actions (including spawn) based on observations.  
3. Environment updates: handle spawns (new agent with inherited level/random position), movement, rewards.  
4. Store transitions (obs, action, reward, next_obs) in buffer.  
5. Periodically sample minibatches and update:  
   - Value methods: TD loss on Q-networks.  
   - Policy methods: PPO-style clipped surrogate loss.  
6. Evaluate every checkpoint: run 1000 test episodes with maximum ceiling, record normalized joint return, alive count, success.

**Design tradeoffs**  
- CTDE (MAPPO) vs. DTDE (IQL): CTDE enables better coordination but requires global information; DTDE scales but may converge to suboptimal policies.
- Spawn cost sharing: distributes cost across alive agents, incentivizing population growth only when beneficial.
- Observation design: including parent indicator and previous joint action is likely necessary for coordination; omitting may cause failure to learn spawning.
- Network architecture: CNNs capture spatial structure in grid-worlds; MLPs suffice for vectorized features (LBF). Incorrect flattening of convolutional outputs breaks concatenation with non-spatial features.

**Failure signatures**  
- Population exceeds ceiling or never grows: spawn condition bug or insufficient exploration.
- No spawning observed: ε_spawn schedule too restrictive or reward structure misimplemented.
- Joint return does not improve with training: network architecture mismatch (e.g., forgetting to concatenate non-spatial features after conv).
- PuddleBridge stacking fails: bottom agent not locked or top agent cannot move puddle→puddle.

**First 3 experiments**  
1. Train IQL and VDN on Predator–Prey with SCP; plot alive agents vs. prey count across checkpoints to verify dynamic scaling by joint optimizer.
2. Ablate parent indicator in Predator–Prey observations; expect drop in spawn coordination for joint optimizers.
3. Run MAPPO on PuddleBridge with varying gate open probability; check if policy switches between fluid and non-fluid modes (measured by spawn frequency).

## Limitations
- Unspecified distributions for initial population and population ceiling sampling may affect reproducibility and results.
- Exact encoding of non-spatial features (e.g., parent indicator) is ambiguous, risking inconsistent implementations.
- Training duration and checkpoint frequency are vague; reported curves may correspond to billions of timesteps but exact numbers are unclear.
- PuddleBridge gate condition distribution is not stated, limiting assessment of policy switching robustness.
- Spawn cost application timing (pre- vs. post-spawn) is ambiguous and could alter population dynamics.

## Confidence
- **Existence of Nash/subgame-perfect equilibria in POFSG**: High (rigorous proofs).  
- **Joint optimizers learn dynamic population control**: Medium (empirical results depend on undefined hyperparameters).  
- **Per-agent optimizers fail to spawn strategically**: Medium (reward implementation critical).  
- **Fluid agents outperform fixed-size groups in variable tasks**: Medium (task variability not fully characterized).  
- **Optimization of spawned agent characteristics (level inheritance)**: Low (limited evidence, potential confounders).  
- **Policy switching in PuddleBridge based on gate conditions**: Low (gate distribution unknown).
