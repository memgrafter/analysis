# MAGPI: Multifidelity-Augmented Gaussian Process Inputs for Surrogate Modeling from Scarce Data

## Quick Facts
- arXiv ID: 2603.22050
- Source URL: https://arxiv.org/abs/2603.22050
- Reference count: 40
- Primary result: Proposes MAGPI, a multifidelity Gaussian process method that augments high-fidelity inputs with low-fidelity surrogate predictions, achieving higher predictive accuracy and lower computational cost than existing multifidelity methods on test problems.

## Executive Summary
MAGPI tackles the challenge of building accurate surrogate models for expensive high-fidelity simulations when only scarce high-fidelity data is available but cheaper low-fidelity data is abundant. The method constructs a high-fidelity Gaussian process whose input space is augmented with predictions from multiple lower-fidelity surrogate models, which can be any regressor (e.g., KNN, linear models). This design avoids the Markovian limitation of autoregressive multifidelity methods and allows nonlinear combination of all low-fidelity information. Evaluations on three test problems show MAGPI significantly outperforms Kennedy O'Hagan, NARGP, and single-fidelity kriging in terms of RMSE, R², and log-marginal likelihood, while also reducing computational cost by enabling efficient low-fidelity surrogates.

## Method Summary
MAGPI first trains a sequence of low-fidelity surrogate models, starting from the lowest fidelity and proceeding upward. For each fidelity level l (except the highest), the model h_l is trained on features that include the original inputs and predictions from all lower-fidelity models h_{l+1} through h_K. The highest-fidelity model is a Gaussian process trained on augmented features formed by concatenating the high-fidelity inputs with predictions from all lower-fidelity models. The GP uses an ARD kernel and a linear mean function for extrapolation. Hyperparameters are optimized by maximizing the marginal likelihood. During prediction, a new input x is processed by evaluating all low-fidelity models and forming the augmented feature vector, which is then fed to the high-fidelity GP to obtain the posterior mean and variance.

## Key Results
- Achieved higher predictive accuracy (lower RMSE, higher R²) and higher log-marginal likelihood than Kennedy O'Hagan, NARGP, and single-fidelity kriging on three test problems.
- For an analytical 1D test, MAGPI's RMSE was over 50% lower than that of NARGP.
- Demonstrated superior extrapolation in a chemical kinetics problem and interpolation in a CFD flow field, while reducing computational cost by permitting efficient low-fidelity surrogates like KNN.

## Why This Works (Mechanism)

### Mechanism 1: Input Augmentation for Nonlinear Combination of Low-Fidelity Information
- **Claim:** MAGPI improves high-fidelity surrogate accuracy by using low-fidelity model predictions as additional input features to a single high-fidelity Gaussian process (GP).
- **Mechanism:** For each training input, the method constructs a feature vector that concatenates the original input with the outputs of all trained low-fidelity surrogate models (from lowest to near-highest fidelity). This augmented feature space is then used as the input to the high-fidelity GP, allowing the GP kernel to capture nonlinear relationships between the high-fidelity output and *all* low-fidelity information simultaneously. This avoids the Markovian limitation of autoregressive methods (e.g., NARGP), where only the immediate lower-fidelity model's output is used.
- **Core assumption:** The high-fidelity output can be expressed as a nonlinear function of the original inputs *and* the true (but unknown) low-fidelity outputs. By replacing true low-fidelity outputs with surrogate predictions in the features, the method assumes these surrogates are sufficiently accurate to provide useful, low-noise signal.
- **Evidence anchors:** The abstract states that MAGPI "uses low-fidelity data to define additional features that augment the input space of the learned model... enables nonlinear combination of all low-fidelity information." Section 3.1 defines the feature construction (eq. 11) and Algorithm 1 implements the recursive training. Experimental results show MAGPI achieving lower RMSE than NARGP, consistent with the benefit of using all low-fidelity information.
- **Break condition:** If low-fidelity surrogates are highly inaccurate (e.g., due to poor model choice or insufficient low-fidelity data), the augmented features may inject more noise than signal, degrading high-fidelity GP performance relative to single-fidelity training.

### Mechanism 2: Computational Efficiency via Flexible Low-Fidelity Surrogates
- **Claim:** MAGPI reduces computational cost by permitting the use of non-GP, computationally cheap low-fidelity surrogate models (e.g., KNN, linear regression), avoiding the cubic scaling of GP training on large low-fidelity datasets.
- **Mechanism:** The method decouples low-fidelity model training from the high-fidelity GP. Low-fidelity models are trained offline first on potentially massive datasets using any chosen regression algorithm. Their predictions are then evaluated once on the (small) high-fidelity input set to form the augmented feature matrix Φ₁. The high-fidelity GP is trained only on these N₁ augmented feature vectors, incurring O(N₁³) cost, where N₁ is small.
- **Core assumption:** The chosen low-fidelity surrogate model can be trained and queried efficiently on large datasets, and its predictions are deterministic and noise-free for feature construction. The paper explicitly states: "we relax the requirement that the low-fidelity surrogate models are GPs."
- **Evidence anchors:** The abstract mentions "reducing computational cost by permitting efficient low-fidelity surrogates like KNN." Section 3.2 provides a complexity analysis showing offline training cost is O(N₁³ + Σ τₗ_train), where τₗ_train for low-fidelity models can be sub-cubic. In the CFD problem (Section 4.4), the authors use KNN for low-fidelity models because GP training on low-fidelity data was "prohibitively expensive."
- **Break condition:** If a low-fidelity model is extremely slow to train or query (e.g., a large DNN), the offline cost saving may be negated. The method also assumes the low-fidelity model's domain of validity covers the high-fidelity input space; extrapolation by a poor low-fidelity surrogate harms the augmented features.

### Mechanism 3: Informative Linear Mean for Extrapolation
- **Claim:** MAGPI enhances extrapolation capability for the high-fidelity surrogate by using an informative linear mean function in the high-fidelity GP, which centers the prior on a combination of inputs and low-fidelity predictions.
- **Mechanism:** The high-fidelity GP's mean function is specified as a linear combination of the original inputs and *all* low-fidelity surrogate outputs (eq. 14). This creates an adaptive prior that "leans" on the low-fidelity models' trends, providing better initial guesses outside the sparse high-fidelity training domain than a constant or zero mean.
- **Core assumption:** A linear combination of inputs and low-fidelity outputs is a reasonable first-order model for the high-fidelity output, especially in extrapolation regions where high-fidelity data is absent. The hyperparameters (α, β, γ) are learned via marginal likelihood maximization.
- **Evidence anchors:** Section 3.1 explains that "This informative prior allows the learned model to extrapolate beyond scarce high-fidelity training data into areas where low-fidelity training data is still plentiful." In the chemical kinetics problem (Section 4.3), which involves extrapolation to higher temperatures (650K–850K) with no high-fidelity data, MAGPI shows improved accuracy and calibrated uncertainty compared to baselines.
- **Break condition:** If the true high-fidelity function's extrapolation behavior is highly nonlinear relative to the low-fidelity models' trends, the linear mean may be insufficient. Oscillations in predictions (mentioned in the conclusion) could be a symptom of misspecification here.

### Multifidelity Modeling Paradigms
- **Why needed:** To contrast MAGPI with cokriging (joint multi-output GP) and autoregressive (Markovian) methods. Understanding their limitations (quadratic hyperparameters, Markov property, linear coregionalization) clarifies MAGPI's design rationale.
- **Quick check:** What is the "Markovian property" in autoregressive multifidelity methods, and why does it limit the flow of information from the lowest-fidelity model to the highest?

### Kernel Trick and Feature Space
- **Why needed:** MAGPI implicitly uses a kernel that operates on the augmented feature vector ϕ₁(x). Understanding that a kernel on [x, h₂(x), ..., h_K(x)] corresponds to a nonlinear function of the original input x is key.
- **Quick check:** If you use an RBF kernel on the augmented features, what kind of nonlinearities in the original input space does this allow the GP to capture that a standard RBF on x alone cannot?

## Architecture Onboarding

### Component Map
- **Low-Fidelity Surrogate Warehouse**: A collection of trained models h₂,...,h_K that can be any regressor (GP, KNN, DNN, etc.).
- **Feature Augmentation Engine**: For each fidelity level l (from K down to 2), constructs the design matrix Φₗ by concatenating Xₗ with predictions from all higher-index (lower-fidelity) surrogates h_{l+1}(Xₗ) through h_K(Xₗ). For the highest fidelity, constructs Φ₁ from X₁ and predictions from h₂ through h_K.
- **High-Fidelity GP Module**: A standard GP regression module that takes (Φ₁, y₁), a kernel function k(·,·;θ), and a mean function µ(·;θ). It optimizes hyperparameters θ (including mean function parameters) by maximizing marginal likelihood.
- **Prediction Pipeline**: For a new test point x', recursively compute ϕ₁(x') = [x'ᵀ, h₂(x'), ..., h_K(x')]ᵀ using the trained low-fidelity models, then query the high-fidelity GP's posterior mean and variance.

### Critical Path
**Offline:**
1. Train the lowest-fidelity model h_K on its dataset D_K.
2. For l = K-1 down to 2: train h_l on features Φ_l = [X_l, h_{l+1}(X_l), ..., h_K(X_l)].
3. Form Φ₁ = [X₁, h₂(X₁), ..., h_K(X₁)] from the high-fidelity data.
4. Train the high-fidelity GP on (Φ₁, y₁) by maximizing marginal likelihood.

**Online:**
1. For test x', compute low-fidelity predictions h₂(x'), ..., h_K(x') in order.
2. Construct ϕ₁(x') = [x'ᵀ, h₂(x'), ..., h_K(x')]ᵀ.
3. Query the high-fidelity GP to obtain posterior mean and variance.

### Design Tradeoffs
- **Low-fidelity model choice**: GPs provide uncertainty but are costly for large Nₗ; KNN/DNN are cheap but lack native uncertainty. Tradeoff: offline cost vs. quality of low-fidelity features.
- **High-fidelity kernel**: RBF/ARD is standard but may oscillate; more expressive kernels (e.g., spectral mixture) might help but increase optimization difficulty.
- **Mean function**: Linear mean aids extrapolation but may underfit complex trends; constant mean simpler but less informative for extrapolation. The mean's form directly affects the prior in low-data regions.

### Failure Signatures
- **Oscillatory predictions**: Observed in Figures 1 and 6; likely due to kernel hyperparameters overfitting or misspecified mean function.
- **Poor uncertainty calibration**: If ±2σ coverage deviates from nominal (e.g., 92.4% for 95% CI), variance estimates are unreliable, often from kernel mismatch or ignored low-fidelity surrogate noise.
- **Degraded performance vs. single-fidelity**: If low-fidelity surrogates are very poor or irrelevant, augmentation may add noise; check by comparing RMSE to single-fidelity kriging on same HF data.

### First 3 Experiments
1. **Synthetic 1D function verification**: Replicate the analytical test (Section 4.2) with functions having low correlation between fidelities and nonlinear combination. Validate that MAGPI's RMSE is significantly lower than NARGP/KOH and that the GP mean captures the shape without excessive oscillations. Tune the linear mean's β parameters.
2. **Low-fidelity model ablation**: On a simple 2D problem, compare MAGPI using (a) perfect low-fidelity models (true functions), (b) accurate GPs, (c) KNN, and (d) linear regression as low-fidelity surrogates. Measure impact on high-fidelity RMSE and log-ML.
3. **Scaling test with massive low-fidelity data**: Generate a problem with N₁=20 (high-fidelity) and N₂=100,000 (low-fidelity). Time the offline training of MAGPI using KNN for h₂ vs. a GP-based autoregressive method (NARGP) that must train a GP on 100k points. Expected: MAGPI+KNN trains in seconds/minutes; NARGP with GP may be infeasible.

## Limitations
- Only three test cases are reported, raising questions about generalization to diverse multifidelity scenarios.
- Hyperparameter optimization details (initialization, tolerance, iterations) are omitted, hindering exact replication.
- The method assumes low-fidelity surrogates are sufficiently accurate; performance may degrade if they are poorly chosen or trained on insufficient data.

## Confidence
- **High**: The input augmentation mechanism and recursive training algorithm are precisely defined and implementable.
- **Medium**: Claims of improved accuracy (RMSE, R², log-ML) on the presented test problems, as results are shown but without statistical tests or multiple random splits.
- **Low**: Broad statements about extrapolation superiority and computational savings, due to limited problem variety and lack of raw data for independent verification.
