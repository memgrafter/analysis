# On Theoretically-Driven LLM Agents for Multi-Dimensional Discourse Analysis

## Quick Facts
- **arXiv ID**: 2602.13713
- **Source URL**: https://arxiv.org/abs/2602.13713
- **Reference count**: 3
- **Primary result**: RAG-enhanced multi-agent system achieved Macro F1 0.67 vs. zero-shot baseline 0.38 (≈30-point gain) on classifying pragmatic rephrase functions in political debates.

## Executive Summary
This paper investigates whether grounding LLM-based discourse analysis in formal argumentation theory can improve the detection of pragmatic rephrase functions (e.g., generalization, intensification) beyond surface-level paraphrase identification. The authors implement a multi-agent system (MAS) where agents retrieve theoretical knowledge from a curated corpus of argumentation literature (using RAG) and collaboratively classify utterances into the D-I-S-G-O taxonomy. On a political debate dataset, the theoretically-grounded MAS substantially outperforms an identical zero-shot MAS, with the largest gains for the Generalization and Intensification categories. The results suggest that embedding domain-specific theoretical frameworks intoagent deliberation is critical for capturing nuanced pragmatic functions in argumentative discourse.

## Method Summary
The study compares two configurations of a three-agent framework (Classifier, Disagreeing, Broker) on a political debate corpus annotated with D-I-S-G-O rephrase functions. The experimental condition augments each agent with retrieval from a knowledge base of argumentation theory texts (e.g., Inference Anchoring Theory). The control condition uses identical prompts without retrieval. Performance is evaluated via Macro F1 and Matthews Correlation Coefficient (MCC). No statistical testing or hyperparameter sensitivity analysis is reported.

## Key Results
- RAG-enhanced MAS achieved Macro F1 0.67 and MCC 0.64; zero-shot MAS scored 0.38 F1 and 0.24 MCC.
- Category-specific F1 gains were highest for Generalization (+0.48) and Intensification.
- The full MAS+RAG configuration’s gain (+0.40 F1) exceeded the sum of isolated RAG (+0.27) and MAS (+0.11) contributions, suggesting synergistic interaction.

## Why This Works (Mechanism)
The system’s advantage stems from injecting explicit argumentation theory—specifically concepts around how utterances functionally relate within an inference structure—into the LLMs’ context. This theoretical grounding allows agents to distinguish subtle pragmatic rephrase functions (e.g., *Generalizing* vs. *Simplifying*) that are ambiguous from surface text alone. The multi-agent structure creates a deliberation loop where the Disagreeing Agent challenges initial classifications by referencing retrieved theoretical constraints, and the Broker synthesizes these critiques into a final decision. This process mirrors scholarly discourse analysis, where theoretical consistency is enforced through peer review-like critique.

## Foundational Learning
- **Argumentation Theory (IAT)**: Provides formal models of how utterances anchor inferences; needed to define rephrase functions beyond lexical similarity. *Quick check*: Does the RAG knowledge base explicitly cite IAT concepts like “anchoring” and “rephrase grounds”?
- **Pragmatic Rephrase Taxonomy (D-I-S-G-O)**: Categorizes functional roles of rephrasing (Disambiguation, Inference, Simplification, Generalisation, Other); needed to operationalize theory into labels. *Quick check*: Are category definitions tied to specific theoretical predicates (e.g., Generalization = expansion of inferential scope)?
- **RAG for Theoretical Grounding**: Retrieves relevant theory excerpts to augment LLM prompts; needed to compensate for LLMs’ limited implicit knowledge of niche argumentation frameworks. *Quick check*: Are retrieval queries designed to match D-I-S-G-O labels (e.g., “theoretical definition of Generalisation in rephrasing”)?
- **Multi-Agent Deliberation**: Uses specialized agents (Classifier, Disagreeing, Broker) to simulate critical discourse; needed to enforce theoretical consistency through debate. *Quick check*: Does the Disagreeing Agent explicitly invoke retrieved theory to contradict the Classifier?

## Architecture Onboarding
**Component map**:  
Input -> Classifier Agent (with RAG) -> Disagreeing Agent (with RAG) -> Broker Agent (with RAG) -> Output label

**Critical path**:  
1. RAG retrieves theory excerpts based on input utterance.  
2. Classifier proposes D-I-S-G-O label.  
3. Disagreeing Agent critiques by cross-referencing retrieval and suggesting alternatives.  
4. Broker synthesizes critiques and retieves additional theory if needed to resolve conflict.  
5. Final label selected.

**Design tradeoffs**:  
- *Pros*: Theoretical consistency via retrieval; synergy from agent debate.  
- *Cons*: Increased latency/cost from multiple LLM calls per instance; risk of retrieval noise.

**Failure signatures**:  
- Low inter-annotator agreement (κ=17-48%) on “Other” and “Generalising” suggests theoretical boundaries are unstable.  
- Disagreeing Agent generates critiques unrelated to retrieved theory (hallucination).  
- Broker defaults to Classifier’s initial label when agents agree, negating deliberation benefit.

**First experiments**:  
1. **Ablate RAG per agent**: Run MAS with RAG disabled for individual agents to isolate which role (Classifier vs. Disagreeing) benefits most from theory.  
2. **Swap theory source**: Replace IAT-based RAG with general argumentation texts (e.g., Walton’s fallacies) to test theory specificity.  
3. **Streamline to two agents**: Remove Broker and let Disagreeing Agent directly override Classifier to measure Broker’s added value.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How can a specialized, high-quality annotated corpus for manipulative rephrases (e.g., straw man fallacy) be constructed, and how would a RAG-enhanced MAS perform on this more complex task?
- **Basis in paper**: [explicit] The authors state future work will create "a high-quality, annotated gold-standard corpus specifically for this task" (detection of manipulative rephrase) and then adapt their framework.
- **Why unresolved**: The current study uses a corpus focused on non-malicious rephrase functions (D-I-S-G-O). The detection of fallacious manipulation requires a different, presumably rarer and more nuanced set of annotations and theoretical distinctions.
- **What evidence would resolve it**: A newly created, reliably annotated corpus of manipulative rephrases (grounded in fallacies like straw man) and a replicated experiment showing the MAS's performance (F1, MCC) on this new, more challenging dataset.

### Open Question 2
- **Question**: What specific mechanisms within the multi-agent architecture (e.g., the Disagreeing Agent's critiques, the Broker's synthesis) are primarily responsible for the observed synergistic performance gain when combining RAG with MAS, beyond the sum of their individual effects?
- **Basis in paper**: [inferred] The paper notes the full MAS+RAG configuration's gain (+0.40 F1) exceeds the sum of the RAG (+0.27) and MAS (+0.11) isolated contributions, suggesting synergy. However, the interaction dynamics and critical reasoning steps that produce this synergy are not analyzed.
- **Why unresolved**: The current evaluation only provides end-task classification metrics. It does not perform an ablation or process-tracing study to identify which agent interactions or deliberation patterns are most beneficial when RAG knowledge is present.
- **What evidence would resolve it**: A qualitative analysis of agent conversation logs or a quantitative ablation study (e.g., removing specific agents or interaction rules) that correlates specific collaborative behaviors with correct classifications in the RAG-enhanced system.

### Open Question 3
- **Question**: To what extent is the low inter-annotator agreement (κ=17-48%) for categories like 'Other' and 'Generalising' due to ambiguous theoretical boundaries versus insufficient annotation guidelines, and how can the D-I-S-G-O taxonomy be refined to improve reliability?
- **Basis in paper**: [explicit] Table 2 reports very low Cohen's κ scores (e.g., 17% for 'Other', 39% for 'Generalising'), indicating substantial disagreement among human annotators.
- **Why unresolved**: The paper establishes the corpus as a gold standard but acknowledges the modest agreement. It does not investigate the sources of this disagreement (e.g., unclear category definitions, contextual dependencies) or propose concrete refinements to the annotation scheme to improve future data quality.
- **What evidence would resolve it**: An error analysis of annotator disagreements, identifying specific linguistic or contextual features that caused confusion. This could lead to a revised, more operationalized annotation guideline and a second-round annotation study measuring improved κ.

### Open Question 4
- **Question**: Does the theoretical grounding provided by RAG generalize to different argumentation theories (beyond IAT and the cited rephrase studies) or to out-of-domain discourse genres (e.g., social media comments, scientific debates)?
- **Basis in paper**: [inferred] The RAG knowledge base is explicitly curated from a specific set of theoretical texts on rephrasing and Inference Anchoring Theory. The dataset is limited to political debates. The authors' future work mentions "expand[ing] the theoretical scope," implying this is an open question.
- **Why unresolved**: The experiment's success is tied to a specific theory-genre pairing. It is unknown if the performance gain is robust to changing the theoretical source material or applying the system to discourse with different rhetorical styles, norms, or rephrase manifestations.
- **What evidence would resolve it**: Re-running the comparative experiment with: (a) a RAG knowledge base built from a different, conflicting argumentation theory, or (b) on a completely new annotated corpus from a non-political genre (e.g., online product reviews, academic peer review), measuring whether the performance gap persists or changes.

### Open Question 5
- **Question**: Can the theoretically-grounded MAS approach be effectively scaled and made cost-efficient for large-scale, real-time analysis of online discourse streams (e.g., monitoring social media for manipulative rephrasing)?
- **Basis in paper**: [explicit] The introduction and conclusion frame this as a long-term goal: "scalable, theoretically informed computational tools" and applying agents to "misinformation detection...online." The paper uses a small, static dataset (401 instances).
- **Why unresolved**: The current experimental setup is a retrospective analysis on a fixed corpus. Real-time deployment would require handling high-volume, streaming data, making sequential decisions with latency constraints, and potentially updating the RAG knowledge dynamically. The cost and latency of the multi-agent, RAG-augmented LLM calls per instance are not addressed.
- **What evidence would resolve it**: A pilot deployment study measuring throughput (instances/second), cost per analyzed post, and accuracy on a streaming benchmark (e.g., a live-filtered sample of Twitter/X data requiring rephrase function labeling), compared against a simpler zero-shot baseline.

## Limitations
- Corpus metadata (size, diversity, annotation scheme details for D-I-S-G-O) is unreported, limiting assessment of generalizability and annotation reliability.
- No statistical significance testing or confidence intervals provided for the ~30-point F1 gain; effect robustness is unclear.
- The design of the "theoretically-driven" RAG (e.g., query formulation, chunking strategy) is not described, hindering replication and analysis of *why* gains occurred.
