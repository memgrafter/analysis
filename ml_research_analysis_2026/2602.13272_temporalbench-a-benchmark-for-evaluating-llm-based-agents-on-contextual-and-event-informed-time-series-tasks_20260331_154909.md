# TemporalBench: A Benchmark for Evaluating LLM-Based Agents on Contextual and Event-Informed Time Series Tasks

## Quick Facts
- arXiv ID: 2602.13272
- Source URL: https://arxiv.org/abs/2602.13272
- Reference count: 40
- Primary result: High numerical forecasting accuracy does not reliably indicate robust contextual or event-aware temporal reasoning in LLM-based agents.

## Executive Summary
This paper introduces TemporalBench, a benchmark designed to evaluate whether LLM-based agents' strong performance on time-series forecasting tasks reflects genuine temporal understanding or merely numerical extrapolation, particularly under contextual and event-driven conditions. The benchmark employs a four-tier task taxonomy (T1–T4) across four real-world domains, systematically controlling access to future targets and contextual information to isolate distinct temporal competencies: historical structure interpretation, context-free forecasting, contextual reasoning, and event-conditioned prediction. Key findings reveal that high accuracy on numerical forecasting tasks (T2/T4) does not translate to robust reasoning with context (T3), with performance often dropping to single digits. Agent orchestration yields inconsistent benefits and can introduce noise, while domain-specific temporal modeling stabilizes numerical predictions but fails to improve higher-order reasoning. Event descriptions are not consistently leveraged as actionable constraints, highlighting a gap between contextual awareness and conditional reasoning.

## Method Summary
TemporalBench constructs tasks from four real-world time-series datasets (FreshRetailNet, MIMIC-IV, PSML, Causal Chambers) by injecting synthetic events and partitioning history/future to enforce controlled access. Each task instance includes a historical time-series, optional textual context, and for T4, future event descriptions, framed as multiple-choice or numerical forecasting questions. Ground-truth labels are derived via rule-based logic using robust statistics (e.g., median, MAD) to ensure objectivity. The benchmark evaluates multiple LLM-based agents (TimeSeriesScientist, AgentScope, MetaGPT, CAMEL) and a single-LLM baseline across backbone models. Metrics include accuracy for qualitative tasks and MAE/sMAPE for numerical forecasts, enabling disentanglement of temporal competencies.

## Key Results
- Numerical forecasting accuracy (T2/T4) does not reliably correlate with contextual or event-aware reasoning (T3/T4); high T2/T4 scores coexist with very low T3 accuracy.
- Performance degrades sharply from T1 (historical structure) to T3 (contextual reasoning), with T3 often in single digits across all agents and domains.
- Agent orchestration introduces noise in simple temporal interpretation tasks; domain-specific tools stabilize numerical prediction but do not transfer to qualitative reasoning; event narratives are superficially integrated without forming actionable temporal constraints.

## Why This Works (Mechanism)

**Mechanism 1: Agent orchestration introduces reasoning noise for direct temporal interpretation**
- Claim: Multi-step agent frameworks often harm performance on tasks requiring straightforward temporal pattern extraction (T1/T2) because decomposition dilutes the direct mapping from numerical sequences to temporal properties.
- Core assumption: Agent benefits are task-dependent; they aid high-level reasoning but can disrupt low-level pattern matching.
- Evidence: Abstract states orchestration provides inconsistent benefits and can introduce noise; section 3.2.2 notes single-LLM baselines frequently match/exceed general-purpose agents on qualitative tasks.

**Mechanism 2: Domain-specific modeling stabilizes numbers but not reasoning**
- Claim: Specialized time-series agents (e.g., TimeSeriesScientist) improve numerical consistency via statistical operations but lack abstractions to map context to temporal semantics, so higher-order reasoning (T3) remains unaffected.
- Core assumption: Numerical prediction and contextual reasoning rely on disjoint capabilities; optimizing one does not transfer.
- Evidence: Abstract notes domain-specific modeling stabilizes numerical prediction but fails to improve higher-level reasoning; section 3.2.2 shows stable error metrics on T2/T4 but no advantage on qualitative tasks.

**Mechanism 3: Event descriptions not translated into actionable constraints**
- Claim: Agents receive event narratives but lack mechanisms to ground them in precise temporal modifications (e.g., shifting means), leading to superficial integration and no consistent T4 qualitative improvement.
- Core assumption: Effective event-conditioned reasoning requires explicit language-to-temporal-parameter mapping.
- Evidence: Abstract states event descriptions are not consistently translated into actionable constraints; section 3.2.4 finds qualitative accuracy does not consistently benefit from event narratives.

## Foundational Learning

**Time-Series Structural Properties (Trend, Volatility, Seasonality)**
- Why needed: T1 tasks directly test interpretation of these intrinsic properties; without understanding them, agents cannot extract temporal structure from raw sequences.
- Quick check: Given a numerical sequence with an upward trend and increasing volatility, can you identify both properties without external context?

**LLM Agent Orchestration Patterns**
- Why needed: The benchmark compares single-LLM vs multi-agent frameworks; understanding common agent designs (role-playing, tool use) is key to interpreting orchestration effects.
- Quick check: What are two common failure modes in multi-agent systems when generating structured numerical outputs?

**Contextual vs. Context-Free Temporal Reasoning**
- Why needed: The core thesis separates pure forecasting (T2) from reasoning under context (T3); this distinction is fundamental to the benchmark's design and diagnosing failures.
- Quick check: How does providing a textual description of a promotion change the interpretation of retail sales time-series compared to just the numbers?

## Architecture Onboarding

**Component map:**
Input Parser → Reasoning Engine → Output Validator. Optional: Temporal Feature Extractor between Parser and Engine.

**Critical path:**
Raw time-series → Input Parser → (Temporal Feature Extractor) → Reasoning Engine → Output Validator → Evaluation. Key decisions: single-LLM vs agent framework; augmentation use; output constraint enforcement.

**Design tradeoffs:**
- Raw serialization vs structured features: Raw tokens preserve exact values but obscure patterns; features/visualizations highlight structure but may lose granular details.
- Agent complexity vs controllability: More agent steps enable decomposition but increase noise and horizon control failures.
- Domain-specific tools vs generality: Specialized tools stabilize numerical prediction but add little to abstract reasoning.

**Failure signatures:**
- Horizon length mismatch: Agent outputs wrong number of future steps.
- Numerical instability: Forecasts show scale drift or extreme values.
- Context neglect: T3/T4 performance similar to T2 despite context, indicating failure to ground language.
- Capability fragmentation: High scores on structural/interaction tasks but low on slicing/comparison in T3.

**First 3 experiments:**
1. Baseline replication: Run single-LLM and each agent framework on all T1-T4 tasks with a common backbone (e.g., gpt-4o) to replicate the degradation pattern and orchestration inconsistency.
2. Error distribution analysis: Categorize failures (format, horizon, numerical) across agents to isolate bottlenecks in reasoning vs execution control.
3. History length sensitivity: Truncate historical input to varying lengths and measure T1-T4 performance to check if agents robustly leverage longer context.

## Open Questions the Paper Calls Out

**Open Question 1: Unified agent architectures for all temporal competencies**
- Question: Can agent architectures be unified to achieve high, consistent performance across T1–T4, closing the gap between numerical forecasting and contextual reasoning?
- Basis: Paper finds strong numerical forecasting does not translate to robust contextual reasoning; performance degrades from T1 to T3.
- Why unresolved: Current agents show fragmented strengths; T3 accuracy remains low even when T2/T4 is high.
- What evidence would resolve: New agent design with >50% T3 accuracy while maintaining competitive T2/T4 across all domains.

**Open Question 2: Mechanisms for converting event descriptions to temporal constraints**
- Question: What mechanisms enable agents to reliably convert natural language event descriptions into precise temporal constraints, improving event-conditioned forecasting (T4)?
- Basis: Event descriptions are not consistently translated into actionable constraints, revealing a gap.
- Why unresolved: Agents fail to leverage event semantics to adjust predictions; T4 qualitative accuracy does not consistently benefit.
- What evidence would resolve: Ablation studies showing specific event encoding strategies (e.g., explicit constraint prompting) yield significant and consistent T4 gains, with causal use analysis.

**Open Question 3: Enforcing output constraints without compromising reasoning**
- Question: How can agent frameworks enforce output constraints (e.g., correct horizon, format, numerical plausibility) without compromising reasoning depth?
- Basis: Error analysis shows many errors arise from output control failures, especially horizon violations.
- Why unresolved: Current agents lack robust mechanisms to guarantee structured outputs, limiting deployment.
- What evidence would resolve: Architectures with explicit validation modules or constrained decoding that reduce output errors (<10% horizon violations) while preserving/improving accuracy.

## Limitations
- Unknown prompt specifications: Exact prompt templates and output parsing rules are not detailed, hindering exact replication.
- Agent implementation opacity: Configuration details for agent frameworks (tool integration, memory policies) are omitted, obscuring orchestration noise sources.
- Generalizability caveat: Findings are based on four domains; unclear if T1–T3 degradation pattern holds for other temporal scenarios (e.g., high-frequency financial data).

## Confidence
- Benchmark design: High
- Mechanistic claims: Medium-Low
- Generalizability: Low

## Next Checks
1. Prompt ablation study: Systematically vary time-series formatting (raw values vs statistical summaries) and context phrasing to quantify impact on T1–T4 accuracy, isolating template sensitivity.
2. Agent replication with open-source implementations: Rebuild each agent framework using only the paper’s high-level description, then run on a fixed subset (e.g., 20 T3 instances) to verify orchestration benefit inconsistency.
3. Cross-domain transfer test: Evaluate a single-LLM baseline on an external time-series benchmark with contextual tasks (e.g., Monash Forecasting) to check if the T1–T3 performance gap persists outside TemporalBench’s domains.
