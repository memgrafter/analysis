# Grid Spatial Understanding: A Dataset for Textual Spatial Reasoning over Grids, Embodied Settings, and Coordinate Structures

## Quick Facts
- **arXiv ID:** 2603.17333  
- **Source URL:** https://arxiv.org/abs/2603.17333  
- **Reference count:** 40  
- **Primary result:** Models excel at cardinal grid spatial tasks but collapse on egocentric ones; VLMs show no advantage; fine-tuning small models matches frontier performance.

## Executive Summary
This paper introduces Grid Spatial Understanding (GSU), a text-only benchmark for evaluating large language models (LLMs) on spatial reasoning tasks involving navigation, object localization, and structure composition within grid coordinate systems. Across models from 7B to frontier sizes, the authors find that LLMs handle fixed cardinal reference frames well but struggle dramatically with egocentric frames (e.g., Llama-8B instructor accuracy drops from 0.69 to 0.06). Vision-language models (VLMs) do not consistently outperform text-only counterparts, while frontier models (GPT-4o, Gemini-3-Pro) achieve near-perfect results. Notably, fine-tuning small models with synthetic reasoning traces yields performance comparable to frontier models, demonstrating that targeted training can supply the missing spatial reasoning capabilities.

## Method Summary
GSU comprises three purely textual tasks: Navigation (following or generating movement instructions on a 2D grid), Object Localization (describing an object’s location relative to a viewer under allocentric or egocentric frames), and Structure Composition (identifying shapes from sets of 3D voxel coordinates). All data are synthetically generated with controllable difficulty via path length, distractor density, and shape complexity. Evaluation metrics include exact match for navigation and spatial term overlap for location and shape descriptors, alongside color, shape, and count overlaps. The study evaluates a range of models via few-shot prompting and further fine-tunes smaller models (FlanT5, Llama-8B) with LoRA on 3,000 examples augmented with step-by-step reasoning traces.

## Key Results
- Egocentric spatial reasoning is extremely challenging for base LLMs (e.g., Llama-8B instructor accuracy drops from 0.69 on cardinal to 0.06 on egocentric).
- Vision-language models do not consistently outperform text-only models on textual grid spatial tasks.
- Frontier models (GPT-4o, Gemini-3-Pro) achieve near-perfect scores; fine-tuned small models (FlanT5, Llama-8B via LoRA) reach comparable performance.

## Why This Works (Mechanism)
### Mechanism 1
Models perform well on cardinal tasks by relying on pre-trained statistical patterns aligned with global coordinate systems, but fail on egocentric tasks because they cannot dynamically reorient their internal reference frame. The internal spatial map is likely fixed (e.g., +Y as forward) and lacks training for iterative head-rotation updates. Evidence includes the stark performance drop for Llama-8B (0.69 → 0.06) and the explanatory equivalence described in section 4.1. If models had seen extensive egocentric trajectories during pre-training or if prompts explicitly chained frame transformations, the failure might be mitigated.

### Mechanism 2
Vision-language models do not gain a consistent spatial reasoning advantage when tasks are presented in rich text, suggesting that visual processing does not enhance abstract spatial reasoning circuits that operate on textual coordinates. Visual signals may be redundant or distracting when spatial relations are fully specified. Evidence: Pixtral outperforms Mistral on some tasks but Qwen outperforms Qwen-VL on others, showing no clear correlation. The advantage would likely emerge if tasks required interpreting ambiguous visual scenes where text falls short.

### Mechanism 3
Small models (<1B-8B) can match frontier performance on these discrete, symbolic tasks via targeted fine-tuning, indicating that the required reasoning is learnable from task-specific data without massive scale. The tasks are rule-governed and have a small answer space, making them memorizable or induceable. Fine-tuning effectively programs these rules into model weights. Evidence: FlanT5 achieves 0.99 on navigation instructor and 100% on allocentric localization; Llama-8B via LoRA reaches 0.96 instructor and 84% egocentric localization. Performance would degrade for larger models only if tasks became less deterministic or required integrating diverse spatial concepts.

## Foundational Learning
#### Coordinate Systems & Axial Reasoning
- **Why needed:** All tasks require interpreting (x,y,z) or (x,y) tuples as positions in a 2D/3D grid, calculating differences, and mapping deltas to directional terms.
- **Quick check:** If an object is at (3,5) and you are at (0,0) facing +Y, what spatial directions describe the object relative to you?

#### Frames of Reference (Allocentric vs. Egocentric)
- **Why needed:** The core challenge is distinguishing between fixed (cardinal) and agent-relative (egocentric) spatial language, especially updating the latter after rotations.
- **Quick check:** You face East (+X). What is 'forward'? Now you turn right. What is 'forward' now?

#### Spatial Composition & Shape Lexicon
- **Why needed:** Structure Composition requires mapping sets of voxel coordinates to shape categories (column, row, cube) and describing their relative layouts.
- **Quick check:** What shape is formed by blocks at (0,0,0), (0,0,1), (0,0,2), (1,0,0), (1,0,1), (1,0,2)?

## Architecture Onboarding
**Component map:** Dataset Generator -> Prompt Engine -> Model Interface -> Metric Calculator -> Analysis Dashboard

**Critical path:** Define task configuration → Generate test/train sets → Choose prompt design (reasoning trace vs. pure I/O) → Run baseline prompts → Identify weak tasks (Egocentric Nav) → Apply fine-tuning with synthetic reasoning chains → Re-evaluate → Analyze error modes (heading consistency, shape conflation).

**Design tradeoffs:**  
- *Simplicity vs. Generalizability:* Grids isolate spatial reasoning but omit real-world noise (partial observability, continuous space); tradeoff: clean signal for mechanism isolation vs. risk of overfitting to grid-logic quirks.  
- *Prompt Reasoning Traces:* Providing a step-by-step example boosts performance on state-updating tasks but increases prompt complexity and may bias output format.  
- *Fine-tuning Data Size:* 3k examples suffice; more yields diminishing returns; tradeoff: compute cost vs. marginal gain.  
- *Coordinate Representation:* "Text" and "Set" formats generally outperform "Plain" or "Dict" (but Qwen prefers Dict); choose based on model family.

**Failure signatures:**  
- *Egocentric Navigation:* Model computes new heading but reverts to cardinal logic for subsequent steps; performance plummets on sequences >2 steps.  
- *Allocentric Object Localization:* "Forward/backward flip"—target described as behind reference when it is between viewer and reference.  
- *Structure Composition:* Outputs vague descriptions ("a large structure") or flattens 3D shapes ("square" for cube); fails to count blocks correctly or group into cohesive shapes.  
- *VLM vs. LLM:* No systematic advantage; sometimes VLMs underperform same-sized LLMs (e.g., Qwen7B > QwenVL7B on Navigation).

**First 3 experiments:**  
1. **Cardinal vs. Egocentric Baseline:** Run 1-shot prompts on 2D Navigation Follower/Instructor for both frames. Expect >0.85 accuracy for Cardinal, <0.15 for Egocentric in 7B models. Validates core difficulty.  
2. **VLM Parity Check:** Compare Pixtral-12B vs. Mistral-7B on Object Localization (Egocentric, +Y heading). Expect similar Os scores (~0.4-0.5), confirming vision's non-impact.  
3. **LORA Fine-tuning Impact:** Take Llama-8B (lowest Egocentric Nav Instructor), LORA-train on 3k examples with reasoning traces. Expect jump from ~0.06 to >0.60 accuracy, matching frontier model range.

## Limitations
- Dataset generation specifics (exact sampling distributions for directions, step lengths, grid bounds) are undocumented, hindering faithful reproduction of train/test splits and difficulty curves.  
- Prompt engineering details (complete variant-specific templates, method for generating synthetic reasoning traces) are unspecified, introducing implementation variability.  
- Generalizability of frame-switching learning is unknown: models may memorize cardinal patterns rather than learning the general principle; breakpoint for increased complexity (e.g., implicit switches) is unclear.

## Confidence
- Egocentric failure delta: **High**  
- VLM parity: **Medium**  
- Small-model fine-tuning success: **Medium**
