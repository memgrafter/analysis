# Label-Free Cross-Task LoRA Merging with Null-Space Compression

## Quick Facts
- arXiv ID: 2603.26317
- Source URL: https://arxiv.org/abs/2603.26317
- Reference count: 40
- Primary result: NSC achieves state-of-the-art average normalized performance of 92.0% on 20 dense vision tasks, 92.3% on six NLI benchmarks, and 82.7% on VLM tasks, while being computationally efficient and label-free.

## Executive Summary
Model merging aims to combine independently fine-tuned LoRA adapters into a single multi-task model without retraining. Existing entropy-based merging methods are restricted to classification tasks, fail on regression, and become inefficient for long-sequence LLMs/VLMs due to their reliance on per-token computations. This paper introduces Null-Space Compression (NSC) merging, a label-free approach that exploits the null-space ratio of the LoRA down-projection matrix as an interference signal. NSC minimizes this ratio over unlabeled data using only precomputed Gram-inverses of small rank‑r matrices, drastically reducing computational cost and enabling application to heterogeneous tasks. Extensive experiments on vision (NYUD‑v2, PASCAL‑Context, Taskonomy), NLI (LLAMA‑3 8B), and VLM (VQA, captioning) benchmarks show NSC outperforms prior methods, with average normalized scores of 92.0%, 92.3%, and 82.7% respectively, while scaling efficiently to long sequences.

## Method Summary
Given a set of LoRA adapters fine‑tuned on different tasks, NSC operates in two phases. First, for each adapter it extracts the down‑projection matrix \(W_\text{down}\) and precomputes the Gram matrix \(G = W_\text{down}^\top W_\text{down}\) and its inverse for a small rank \(r\); these are constant regardless of the data. Second, NSC defines an objective that measures the total null‑space ratio of the weighted sum of adapters over a batch of unlabeled data. The null‑space ratio quantifies the proportion of each adapter’s output that lies in the null‑space of its down‑projection, serving as a proxy for interference. Merge coefficients \(\alpha_i\) are optimized (e.g., via gradient descent) to minimize this objective, requiring only forward passes through the adapters and the precomputed inverses—no labels needed. The final merged LoRA is \(\sum_i \alpha_i \Delta_i\), which is then applied to the base model. Because the Gram inverses are tiny (\(r\times r\)), the method scales to long sequences and heterogeneous tasks.

## Key Results
- Average normalized performance: 92.0% over 20 dense vision tasks (NYUD‑v2, PASCAL‑Context, Taskonomy), surpassing entropy‑based baselines.
- On six NLI benchmarks with LLAMA‑3 8B, NSC achieves 92.3% average, exceeding AdaMerging and other methods.
- For vision‑language tasks (VQA, captioning), NSC reaches 82.7% average, matching or exceeding AdaMerging’s full‑token variant while using only single‑token computational cost.

## Why This Works (Mechanism)
The core insight is that the null‑space of a LoRA adapter’s down‑projection matrix represents directions that the adapter does not actively use. When two adapters are merged, overlapping information in the column spaces causes interference; by contrast, placing the combined update’s redundant components into the null‑spaces of the individual adapters preserves each task’s essential subspace while minimizing mutual disruption. The null‑space ratio—computed efficiently via Gram‑inverses—captures how much of the merged update lies in these unused subspaces. Minimizing it over unlabeled data drives the merge coefficients toward a combination that respects each adapter’s unique information footprint, thereby reducing interference without requiring task labels. This heuristic proves effective across classification, regression, and generative tasks, and the reliance on low‑rank matrices makes it scalable.

## Foundational Learning
- **LoRA (Low‑Rank Adaptation)**  
  *Why needed*: Enables efficient fine‑tuning of large models by learning low‑rank updates instead of full parameters.  
  *Quick check*: Given a weight matrix \(W\in\mathbb{R}^{d\times k}\), LoRA approximates \(\Delta W = BA\) with \(B\in\mathbb{R}^{d\times r}\) and \(A\in\mathbb{R}^{r\times k}\). What does \(r\) control? (Answer: the rank of the update, thus number of trainable parameters.)

- **Model Merging**  
  *Why needed*: Combines knowledge from multiple specialized models into a single model without retraining, enabling multi‑task capability.  
  *Quick check*: How does weighted merging differ from naive averaging of LoRA adapters? (Answer: Each adapter is scaled by a learned coefficient \(\alpha_i\) that balances task interference.)

- **Null Space**  
  *Why needed*: The null space of a matrix contains vectors mapped to zero; in LoRA merging it indicates directions not used by an adapter, which can be exploited to reduce interference.  
  *Quick check*: For a matrix \(M\) with singular values \(\sigma_1\ge\cdots\ge\sigma_n\), which singular values correspond to the null space? (Answer: Those exactly zero; in practice near‑zero values are treated as null.)

- **Gram Matrix and Inverse**  
  *Why needed*: The Gram matrix \(G = M^\top M\) captures inner products of columns; its inverse enables efficient computation of projection metrics without explicit SVD, crucial for scalability.  
  *Quick check*: Given a low‑rank matrix \(M\) of size \(m\times r\) (\(r\ll m\)), why is \(G\) (\(r\times r\)) small and easier to invert? (Answer: Its dimension depends only on rank \(r\), not on \(m\).)

- **Label‑Free Optimization**  
  *Why needed*: Many merging methods rely on labeled data; a label‑free approach allows merging for regression or tasks without clear metrics, broadening applicability.  
  *Quick check*: What does it mean to optimize merge coefficients on unlabeled data? (Answer: Use data to compute a proxy for model interference without ground‑truth labels.)

## Architecture Onboarding
**Component Map**  
Pre-trained Model & LoRA Adapters → Compute Down‑Projection Matrices → Compute Gram‑Inverses → Define Null‑Space Objective → Optimize Coefficients α on Unlabeled Data → Obtain Merged LoRA Adapter.

**Critical Path**  
The system first precomputes Gram‑inverses for each adapter’s down‑projection (one‑time cost). Then, for each batch of unlabeled data, it evaluates the null‑space ratio contribution of the current merged candidate using the precomputed inverses. An optimizer updates α to minimize the total ratio; this loop iterates until convergence. Finally, the adapters are merged with the learned α and applied to the base model. The critical dependency is the accuracy of the precomputed inverses and the representativeness of the unlabeled data.

**Design Tradeoffs**  
- *Efficiency vs. Accuracy*: Smaller rank \(r\) and precomputation lower runtime but coarsely approximate null‑space; larger \(r\) improves fidelity at higher cost.
- *Label‑Free vs. Potential Performance*: Avoids label scarcity but the null‑space ratio is heuristic; supervised merging could be stronger when labels exist.
- *Generality vs. Task‑Similarity*: NSC handles heterogeneous tasks, yet merging highly dissimilar tasks may require more diverse unlabeled data to avoid negative transfer.

**Failure Signatures**  
- High null‑space ratio after optimization, indicating inability to find a low‑interference merge.
- Downstream performance drop compared to individual adapters (negative transfer).
- Unstable coefficient updates (divergence/oscillation) suggesting ill‑conditioned Gram inverses or poor hyper‑parameters.
- Large variance when using different unlabeled sets, revealing data‑dependency issues.

**First Experiments**  
1. **Metric Correlation**: Compute null‑space ratio of adapter pairs and correlate with actual interference (performance drop from naive merging) on a single vision task to validate the proxy.
2. **Baseline Comparison**: Apply NSC to merge classification and regression adapters and compare against AdaMerging (entropy‑based) on both task types using normalized performance.
3. **Scalability Test**: Vary sequence length (512‒8192 tokens) for LLM/VLM adapters and measure NSC’s runtime/memory vs. AdaMerging to confirm efficiency claims.
