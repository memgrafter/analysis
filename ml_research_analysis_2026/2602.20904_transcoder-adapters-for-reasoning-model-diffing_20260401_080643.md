# Transcoder Adapters for Reasoning-Model Diffing

## Quick Facts
*   **arXiv ID:** 2602.20904
*   **Source URL:** https://arxiv.org/abs/2602.20904
*   **Reference count:** 40
*   **Primary result:** Sparse transcoder adapters recover 50-90% of reasoning fine-tuning accuracy gains, with behavioral changes (e.g., hesitation) traceable to a tiny fraction of features.

## Executive Summary
This paper introduces a method to isolate the computational changes a model undergoes during reasoning training. Instead of comparing models directly, the authors train lightweight "transcoder adapters" alongside a frozen base model to reconstruct the activations and outputs of its reasoning-distilled counterpart. This creates a sparse, interpretable approximation of the difference in MLP computation. Analysis reveals that only a small subset of adapter features (8%) are directly linked to reasoning behaviors, and an even smaller fraction (2.4%) controls hesitation-like tokens. Ablating these features drastically shortens responses while largely preserving accuracy, demonstrating the method's power for targeted mechanistic analysis of fine-tuning effects.

## Method Summary
The core method involves training a sparse autoencoder (a transcoder) on the difference between a base model and its reasoning-trained variant. The base model's MLP layers are frozen. For each layer, a small set of adapter features is learned in parallel to reconstruct the target model's residual stream activations and final logits. The adapter's features are then analyzed to understand which computations are added or modified by the reasoning training. The "faithfulness" of an adapter is measured by the accuracy it recovers when used in place of the target model's MLPs.

## Key Results
*   Adapters are faithful, recovering 50-90% of the accuracy gains from reasoning training while matching response lengths.
*   Only ~8% of adapter features are directly correlated with reasoning behaviors across benchmarks.
*   Hesitation tokens (e.g., "wait") are controlled by just 2.4% of features (~5,600); ablating them reduces response length by over 50% with minimal accuracy loss on three of four benchmarks.

## Why This Works (Mechanism)
The method works by treating the fine-tuned model's behavior as a sparse perturbation of the base model's computation. By training adapters to reconstruct the target's outputs while the base model is frozen, the adapters learn to activate only for the specific input patterns and internal states that the reasoning training introduced. The high recovery rate (50-90%) indicates that the reasoning distillation primarily modifies existing computational pathways in a way that can be additively approximated, rather than requiring entirely new, irreducible mechanisms. The extreme sparsity of features linked to behaviors like hesitation suggests that fine-tuning can concentratedly adjust a small, specific circuit within the model.

## Architecture Onboarding
*   **Component Map:** Input -> Base Model (Frozen MLPs) -> [Parallel Adapter Features per Layer] -> Reconstructed Target Activations/Logits -> Loss (vs. Target Outputs)
*   **Critical Path:** The reconstruction loss gradients flow back into the adapter features only. The frozen base model provides a fixed computational backbone; the adapters must learn to "edit" its outputs by activating on specific internal states the base model produces.
*   **Design Tradeoffs:** Sparsity vs. Faithfulness: Higher sparsity (fewer features) may miss important changes, lowering recovery. Probe Sensitivity vs. True Sparsity: The 2.4% hesitation feature attribution depends on the quality of the token-level probe/annotation; a noisy probe could misattribute effects.
*   **Failure Signatures:** 1) Adapter recovery rate drops near 0%, indicating the training change is not a sparse additive perturbation. 2) High feature overlap between "reasoning" and "non-reasoning" probes, suggesting the adapter hasn't cleanly isolated the change. 3) Ablating "critical" features has no effect on behavior, indicating misattribution.
*   **First Three Experiments:**
    1.  Train a transcoder adapter between a base language model and its SFT (Supervised Fine-Tuned) variant on a generic instruction-following dataset. Compare recovery rate and feature sparsity to the reasoning-distilled case.
    2.  For the top 100 features attributed to "hesitation" tokens, perform a causal intervention: manually clamp the feature activation to zero during generation and measure changes in output text and accuracy.
    3.  Replace the linear probe used for feature attribution with a more complex probe (e.g., a small neural network) and re-run the analysis to see if the percentage of features linked to hesitation tokens significantly changes.

## Limitations
*   Analysis is on a single model pairing (one base model, one reasoning-distilled variant); generalizability to other architectures, scales, or fine-tuning methods (SFT, DPO) is unknown.
*   "Faithfulness" (50-90% accuracy recovery) does not prove causal equivalence; adapters might approximate outputs without capturing true mechanistic changes.
*   The low percentage of features linked to hesitation (2.4%) may be an artifact of specific probe design and annotation thresholds rather than true sparsity.

## Confidence
*   **High:** The adapter training framework successfully reconstructs target model outputs within the tested pair, demonstrating a viable diffing technique.
*   **Medium:** Claims about extreme feature sparsity (8% reasoning, 2.4% hesitation) heavily depend on probe design and interpretation thresholds; methodology could over- or under-identify critical features.
*   **Low:** Generalizability to other model comparisons (e.g., safety-aligned, multimodal) and the causal necessity of identified features beyond the specific hesitation behavior.

## Next Checks
1.  Test transcoder adapters on at least three additional model pairs (e.g., different base models, alternative reasoning training methods like R1-distillation) to assess recovery consistency and feature overlap.
2.  Replicate the hesitation-token analysis using independent probing methods (e.g., automated concept activation vectors, counterfactual interventions) to confirm the 2.4% feature attribution is not probe-specific.
3.  Apply the same adapter-diffing pipeline to a non-reasoning fine-tuning task (e.g., sentiment tuning) to evaluate whether the "sparse critical features" pattern persists, testing method scope.
