# Mitigating Hallucination in Financial Retrieval-Augmented Generation via Fine-Grained Knowledge Verification
## Quick Facts
- **arXiv ID:** 2602.05723
- **Source URL:** https://arxiv.org/abs/2602.05723
- **Reference count:** 0
- **Primary result:** RLFKV improves faithfulness in financial RAG by verifying atomic knowledge units against retrieved documents, achieving gains of +3.0 points (Qwen3: 86.5→89.5) and +1.6 points (LLaMA3: 80.0→83.6) on FDD datasets.

## Executive Summary
Financial retrieval-augmented generation (RAG) systems often hallucinate, especially with time-sensitive data. This paper proposes RLFKV, a reinforcement learning framework that decomposes model responses into atomic financial knowledge units—structured as quadruples (entity, metric, value, timestamp)—and verifies each unit’s consistency with the retrieved documents. A fine-grained faithful reward derived from incorrect units provides a stable optimization signal, while an informativeness reward preserves output depth. Experiments on financial datasets show consistent faithfulness improvements and faster convergence compared to binary response-level rewards.

## Method Summary
RLFKV operates after retrieval, using a base model to generate responses conditioned on the query and retrieved documents. A fixed evaluation model decomposes each response into atomic quadruples and independently verifies every unit against the source documents. The faithful reward (`rf`) is a smoothed penalty on the count of incorrect units, offering a continuous learning signal instead of a binary outcome. To prevent the model from collapsing to terse outputs, an informativeness reward (`ri`) ensures the number of generated units at least matches that of the base model. The combined reward guides policy updates via Group Relative Policy Optimization (GRPO) with a KL constraint relative to the reference model.

## Key Results
- Faithfulness gains: +3.0 points (Qwen3: 86.5→89.5) and +1.6 points (LLaMA3: 80.0→83.6) on FDD/FDD-ANT.
- Fine-grained reward yields more stable optimization and converges faster (within 2k training steps) compared to binary rewards.
- Ablating the informativeness reward reduces output length by 1.4–1.5 informativeness points but does not drastically drop faithfulness.

## Why This Works (Mechanism)
### Mechanism 1
Fine-grained rewards based on atomic knowledge unit verification provide stable optimization signals that more effectively reduce hallucinations than binary response-level rewards.
- **Mechanism:** The framework decomposes each generated response into minimal financial fact units (entity, metric, value, timestamp). Each unit is independently verified against retrieved documents. The reward is computed from the count of incorrect units via a smoothed penalty function (`rf = 1 / e^(η·min(score, γ))`), creating a continuous learning signal. This contrasts with a binary reward (1/0 for whole response correctness), which offers no gradient for partially correct responses.
- **Core assumption:** Atomic units provide a sufficiently granular and faithful representation of response correctness such that optimizing unit-level correctness aligns the entire response with retrieved documents.
- **Evidence anchors:** abstract; section 3.1 (quadruple definition and verification); section 4.3 (stable optimization, faster convergence).
- **Break condition:** If the atomic decomposition fails to capture all factual assertions (e.g., misses a temporal clause), the reward signal becomes incomplete and optimization may not target all error modes.

### Mechanism 2
The informativeness reward (`ri`) prevents reward hacking (e.g., generating overly terse, safe responses) by maintaining informational depth relative to the base model.
- **Mechanism:** A binary reward (`ri = 1 if k >= k0 else 0`) is applied, where `k` is the number of knowledge units in the policy's response and `k0` is the count from the base model (`π0`). This creates a pairwise constraint ensuring the optimized model does not reduce output substance.
- **Core assumption:** The base model's unit count (`k0`) is a reasonable proxy for adequate informativeness; preserving or exceeding it prevents trivial solutions.
- **Evidence anchors:** abstract; section 3.2 (formal definition); section 4.2 (ablation results showing informativeness drop).
- **Break condition:** If the base model (`π0`) is abnormally verbose or sparse, `k0` sets a poor benchmark, either failing to prevent hacking or unnecessarily penalizing concise improvements.

### Mechanism 3
The financial quadruple structure `(entity, metric, value, timestamp)` is a causally effective representation for atomic knowledge in time-sensitive financial domains.
- **Mechanism:** This structure enforces completeness: a fact is only considered an atomic unit if all four elements are present. It specifically targets the two core characteristics of financial text: strict temporal sensitivity and quantitative orientation. For example, extracting `(Kweichow Moutai, basic earnings per share, 70.86 yuan, As of March 31, 2025)` forces explicit linking of value and time.
- **Core assumption:** Most hallucinations in financial RAG involve incorrect or missing temporal or numerical assertions; capturing these as separate, mandatory units makes verification precise.
- **Evidence anchors:** section 3.1.1 (completeness constraint); section 4.4 (error analysis showing 55% time omissions, 28% time inaccuracies, 17% numerical errors).
- **Break condition:** If financial assertions in the domain frequently cannot be decomposed into clean quadruples (e.g., qualitative assessments like "strong growth"), the verification may miss non-quantitative hallucinations or force invalid decompositions.

## Architecture Onboarding
**Component map:** Retriever -> Base Model (π0) -> Evaluation Model (Decomposer & Verifier) -> Reward Calculator -> RL Optimizer (GRPO) -> Policy Model (π)

**Critical path:** 1. Input query `q` and retrieved documents `D`. 2. Generate response `y` using current policy `π`. 3. Decompose `y` into atomic units `{ui}`. 4. Verify each `ui` against `D` to get correctness scores `{si}`. 5. Compute faithful reward `rf` from sum of incorrect units. 6. Compute number of units `k`, compare to base model's `k0` to get informativeness reward `ri`. 7. Combine rewards, compute group-relative advantage, perform GRPO update on `π`.

**Design tradeoffs:**
- Fine-grained rewards add significant computational overhead (two extra LLM inferences per sample) versus binary rewards. Tradeoff: reward precision vs. training throughput.
- Static `k0` from base model is simple but may not be optimal if the base is unusually verbose/terse; a dynamic baseline could adapt but adds complexity.
- Using a larger, fixed evaluator ensures stability but risks evaluator hallucinations introducing noise into the reward signal.

**Failure signatures:**
- High "Time Omission" errors (55% per analysis): Indicates decomposition or verification fails to capture timestamps from documents; inspect decomposition prompts.
- Reward collapse (all `rf` near 1 despite poor generations): Likely decomposition produced few units or verifier incorrectly marked all correct; audit `{ui}` and `{si}`.
- Informativeness decay (`k` steadily decreases below `k0` despite `ri`): The `ri` penalty may be too weak to counteract brevity pressure; increase its weight.

**First 3 experiments:**
1. Unit Extraction sanity check: Manually inspect 50 decompositions of model outputs; calculate percentage of valid `(entity, metric, value, timestamp)` quadruples; target >90%.
2. Reward sensitivity test: For a fixed response and documents, artificially flip 1, 2, 3... units to incorrect; plot `rf` vs. error count; verify smooth, monotonic decrease.
3. Ablation validation: Train with only `rf` (without `ri`). Measure output unit count `k` versus baseline. Then train with scaled `ri` (e.g., 0.25×, 0.5×) to find minimal effective weight that prevents brevity without dominating `rf`.

## Open Questions the Paper Calls Out
### Open Question 1
How can the reward function be refined to specifically reduce temporal omissions and numerical inaccuracies, which account for the majority (83%) of remaining errors in RLFKV? The current fine-grained reward treats all knowledge units equally without special weighting for temporal or numerical components, despite their error prevalence. Evidence to resolve: Ablation studies with augmented reward components that penalize missing timestamps or imprecise values more heavily, evaluated on error type breakdowns.

### Open Question 2
To what extent do inaccuracies in the evaluation model (Qwen3-32B) used for atomic knowledge unit decomposition and verification propagate errors to the RLFKV reward signal, and how can this be mitigated? If the evaluator hallucinates or mis-decomposes units, the reward signal becomes corrupted, potentially leading to misguided policy updates. Evidence to resolve: Human evaluation or cross-evaluator consistency checks on decomposition and verification outputs, combined with sensitivity analysis of RLFKV performance to evaluator accuracy.

### Open Question 3
Is the financial quadruple structure (entity, metric, value, timestamp) comprehensive enough to capture all relevant atomic knowledge units in financial texts, particularly for qualitative or forward-looking statements? Financial narratives often include qualitative assessments or projections that may not neatly map to a metric-value pair with a timestamp, potentially leading to incomplete verification. Evidence to resolve: Annotation studies applying the quadruple schema to diverse financial documents, measuring the proportion of statements that fit versus those that require extension or alternative representations.

### Open Question 4
Does the use of GPT-4o as an automatic evaluator for faithfulness and informativeness introduce biases that affect the validity of the reported performance improvements? GPT-4o may have inherent tendencies or knowledge gaps that skew scores, especially in time-sensitive financial data. Evidence to resolve: Comparative evaluation with human annotators on a subset, or using multiple LLM evaluators to measure score variance, to establish robustness of the metric.

## Limitations
- Atomic decomposition may miss some factual assertions, yielding incomplete reward signals.
- The fixed evaluator (Qwen3-32B) might itself hallucinate, adding noise to verification.
- Evaluation on only FDD and FDD-ANT datasets limits generalizability across financial domains or languages.
- Training requires two extra LLM inferences per sample, greatly increasing computational overhead.
- Static `k0` from base model may be poorly matched if the base is unusually verbose or terse.

## Confidence
- Fine-grained reward stability and effectiveness: High (ablation shows consistent gains and faster convergence).
- Informativeness reward preventing brevity: Medium (ablation confirms length drop but optimal weighting and sensitivity remain unclear).
- Quadruple structure's causal role: Medium (error analysis justifies focus on time/number, but qualitative assertions may be missed).
