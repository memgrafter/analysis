# MisSpans: Fine-Grained False Span Identification in Cross-Domain Fake News
## Quick Facts
- arXiv ID: 2601.04857
- Source URL: https://arxiv.org/abs/2601.04857
- Reference count: 40
- Primary result: Introduces a benchmark for fine-grained span-level misinformation detection; all 15 evaluated LLMs perform poorly on span identification (best zero-shot Exact F1: 0.302) and type classification (best zero-shot F1: 0.455), with explanation generation being relatively easier (best zero-shot similarity: 0.796).

## Executive Summary
MisSpans addresses the limitation of coarse-grained misinformation detection by introducing a benchmark for fine-grained span-level analysis across multiple domains. It defines three tasks: locating false spans (MisSpansIdentity), categorizing them (MisSpansType), and generating rationales (MisSpansExplanation). Based on 280 paired real-fake news stories with expert annotations (agreement F1 >0.85), the paper evaluates 15 LLMs in zero- and one-shot settings. Results show all models struggle with precise span identification and type classification, while explanation generation is relatively easier. Reasoning-enhanced models generally excel at identity but underperform on type/explanation; one-shot helps only large models, often harming smaller ones. The work underscores the difficulty of precise span-level misinformation tasks and highlights the need for better adaptation strategies.

## Method Summary
The study constructs a dataset of 280 real-fake news story pairs (1,749 sentences) from FakeNewsAMT across seven domains. Annotators, guided by strict guidelines, identify the shortest false span in each fake sentence using the real article as reference, classify each span into one of four types (Inconsistency, No mention, Others, True), and produce template-based explanations. The annotation process includes iterative calibration and cross-review to ensure consistency (pairwise F1 >0.85). For evaluation, 15 LLMs are prompted in zero-shot and one-shot settings (with a single example from the same domain). Model outputs are parsed strictly; metrics include Exact/Relaxed F1 for identity, Accuracy/F1 for type, and ROUGE-L/sentence similarity for explanations. Gold spans are provided for downstream tasks to isolate task-specific difficulty.

## Key Results
- Span identification remains challenging: best zero-shot Exact F1 is 0.302, Relaxed F1 0.411.
- Type classification peaks at zero-shot F1 0.455.
- Explanation generation achieves best zero-shot similarity 0.796 (ROUGE-L 0.374).
- Reasoning-oriented models outperform on identity but underperform on type and explanation compared to non-reasoning counterparts.
- One-shot prompting benefits only large models; smaller models often degrade, indicating poor example transfer.

## Why This Works (Mechanism)
### Mechanism 1: Constrained span selection and comparative reference
By requiring annotators to select the shortest possible false span and using only the real article as reference (no external knowledge), the annotation process forces precise localization and reduces ambiguity. Iterative cross-review calibrates judgment, yielding high agreement. Core assumption: shortest spans uniquely identify falsehoods, and real news provides unambiguous comparison. Evidence: guidelines specify "shortest text span" and iterative calibration; neighboring work shows no comparable comparative span annotation. Break condition: structural divergence between real/fake or multiple minimal spans can reduce consistency.

### Mechanism 2: Task decomposition into orthogonal dimensions
The three tasks (identity, type, explanation) separate localization, categorical reasoning, and semantic justification. Performance patterns differ across model types: reasoning models excel at identity but lag on type/explanation, while non-reasoning models show opposite trends. This indicates separable capabilities. Evidence: abstract and section 4.2–4.4 report divergent performance. Core assumption: capacities are non-redundant. Break condition: if one task reaches ceiling, discriminative power diminishes.

### Mechanism 3: One-shot prompting's limited benefit
Fine-grained span tasks are hard to learn from a single example due to boundary precision and taxonomy mapping. Larger models abstract rules; smaller ones overfit to example content, harming performance. Core assumption: few-shot transfer scales with model capacity and task abstraction. Evidence: abstract, section 4.2–4.4 all note one-shot helps only large models and degrades small ones. Break condition: curated boundary examples or chain-of-thought might improve small-model transfer.

## Foundational Learning
- **Span-level vs. document-level evaluation:** Fine-grained detection is needed because fake news often mixes true and false details; document-level labels cannot capture partial falsehoods. Quick check: If a fake news sentence contains both true and false details, a document-level classifier would label the whole document as fake, obscuring the mix.
- **Inter-annotator agreement for span tasks:** Span tasks use pairwise F1 (not Cohen's Kappa) because boundaries vary and negative examples are absent; Exact vs Relaxed F1 measure precision vs recall. Quick check: Exact match requires identical boundaries; Relaxed counts any overlap. What does each emphasize?
- **Reasoning-enhanced vs. instruction-tuned LLMs:** Reasoning models are trained for stepwise inference; instruction-tuned models follow direct commands. Quick check: Why might a reasoning model underperform on a straightforward classification? Possibly because it over-thinks or misapplies reasoning patterns.

## Architecture Onboarding
Component map: Data collector (FakeNewsAMT subset) -> Sentence splitter -> Two-phase annotator interface (independent + cross-review) -> Consistency validator -> Metrics calculator (Exact/Relaxed F1, classification F1, similarity) -> LLM testing harness (zero/one-shot prompts)
Critical path: Annotation consistency is the bottleneck. Preliminary 30-story calibration must achieve stable agreement before full annotation. Cross-validation on final set targets specific disagreement types (spanning vs split).
Design tradeoffs: Exact vs Relaxed evaluation (precision vs recall); gold spans as input for downstream tasks (avoids cascaded errors but assumes perfect identity); template-based explanations (improves consistency at cost of expressiveness).
Failure signatures: Low relaxed but high exact F1 (boundary disagreement); reasoning models underperforming on Type (overthinking); one-shot degrading small models (distraction by example content); domain-specific crashes (tech domain higher span density).
First 3 experiments: 1) Replicate inter-annotator agreement on new sample; 2) Analyze model span length bias; 3) Test rule-based baseline (e.g., TF-IDF differences) to establish non-LLM floor.

## Open Questions the Paper Calls Out
### Open Question 1: Interaction of model size, reasoning, and domain features
How do model size, reasoning capabilities, and domain-specific textual features interact to influence performance? Unresolved because evaluation didn't isolate these factors or study interactions. Resolution: controlled experiments varying model size/architecture with domain-stratified analysis.

### Open Question 2: Domain adaptation strategies for smaller models
What prompting or fine-tuning strategies enable effective domain adaptation, especially for smaller LLMs? Unresolved because only zero/one-shot tested; one-shot often harms small models. Resolution: compare few-shot, chain-of-thought, and fine-tuning on MisSpans.

### Open Question 3: Fine-tuning on MisSpans
Does fine-tuning on MisSpans improve performance, and what methodologies are best? Unresolved because no fine-tuning experiments done. Resolution: conduct fine-tuning experiments (full-model vs parameter-efficient) using provided splits.

### Open Question 4: Multilingual extension
Can MisSpans be extended to multiple languages, and does cross-lingual transfer work? Unresolved because dataset is English-only. Resolution: create multilingual versions or evaluate multilingual models.

## Limitations
- Dataset size (280 pairs) may underrepresent cross-domain diversity.
- High expert agreement may not generalize to non-expert or crowdsourced annotations.
- Evaluation limited to zero/one-shot without fine-tuning; does not establish supervised upper bound.
- Missing domain partition of stories hinders replication of per-domain results.
- Ambiguous specification of proprietary model versions may impair reproducibility.

## Confidence
- Annotation reliability via constrained spans: Medium (strong agreement but break conditions insufficiently tested)
- Task decomposition revealing separable capabilities: High (consistent divergence across model types)
- One-shot limitations scaling with model size: High (pattern explicit across tasks and models)
- Overall difficulty of span-level tasks: High (empirical results robust across 15 LLMs)

## Next Checks
