# Do Neurons Dream of Primitive Operators? Wake-Sleep Compression Rediscovers Schank's Event Semantics

## Quick Facts
- **arXiv ID:** 2603.25975
- **Source URL:** https://arxiv.org/abs/2603.25975
- **Reference count:** 18
- **Primary result:** A wake-sleep MDL system automatically discovers a library of event primitives that achieves near-optimal compression, covers 100% of events on synthetic and ATOMIC data, and uncovers richer mental/emotional primitives beyond Schank’s original set.

## Executive Summary
The paper examines whether Roger Schank’s long–standing set of semantic primitives can be derived automatically using information–theoretic compression pressure. The authors adapt the wake–sleep library learning framework to the domain of event state transformations, beginning with only four generic operators and employing the Minimum Description Length (MDL) principle to iteratively specialize and compose operators into a compact library. On synthetic data generated from Schank’s primitives, the discovered library attains Bayesian MDL within 4% of the optimal hand‑coded baseline while explaining all events (Schank’s set explains 81%). On the ATOMIC commonsense dataset, Schank’s primitives cover merely 10% of events, while the learned library covers 100%. The system rediscovers variants of core Schankian operators (e.g., MOVE_PROP_has ≈ ATRANS, CHANGE_location ≈ PTRANS, SET_knows ≈ MTRANS) and reveals dominant mental/emotional primitives (CHANGE_wants, CHANGE_feels, CHANGE_is) absent from Schank’s taxonomy. Compound operators such as “mail” = ATRANS ◦ PTRANS also emerge. These results suggest that event primitives are derivable from first principles via compression and that naturalistic event modeling requires richer, particularly mental/emotional, operators than historically proposed.

## Method Summary
The method combines wake–sleep learning with MDL to induce a library of event operators. Starting from four generic state transformation operators, the system alternates between a wake phase (inferring programs that reconstruct observed events using the current library) and a sleep phase (updating the library by specializing or composing operators based on usage) to minimize the total description length. MDL balances the complexity of the library against the encoding cost of events under that library. This iterative process gradually builds a compact library of reusable primitives. The approach is evaluated on synthetic data (generated from Schank’s primitives) and real‑world commonsense events from ATOMIC.

## Key Results
- On synthetic data, the learned library achieves Bayesian MDL within 4% of Schank’s hand‑coded primitives and explains 100% of events (Schank: 81%).
- On ATOMIC, the learned library explains 100% of events; Schank’s primitives explain only 10%.
- The system rediscovers core Schankian operators (e.g., MOVE_PROP_has ≈ ATRANS, CHANGE_location ≈ PTRANS, SET_knows ≈ MTRANS) and uncovers prevalent mental/emotional primitives (CHANGE_wants, CHANGE_feels, CHANGE_is). Compound operators like “mail” = ATRANS ◦ PTRANS are also discovered.
- These findings indicate that event primitives are information‑theoretically derivable and that mental/emotional operators are essential for modeling naturalistic events.

## Why This Works (Mechanism)
The wake–sleep MDL framework uses compression as an inductive bias: a library that can compactly represent many events (high reuse) is preferred. In the wake phase, the system searches for programs (operator sequences) that reconstruct each event; the combined length of the library and these program encodings is the MDL score. In the sleep phase, the library is updated by abstracting frequent operator subsequences into new primitives or merging similar ones, thereby reducing total description length. This iterative optimization aligns with the MDL principle that the best model is the one yielding the shortest encoding of the data. The emergence of Schank‑like operators and additional mental/emotional primitives occurs naturally because such operators lead to high compression on both synthetic and ATOMIC data.

## Foundational Learning
- **Minimum Description Length (MDL)**: Governs the trade‑off between library complexity and encoding cost, driving the search for a compact yet expressive set of primitives. *Why needed*: Provides an objective, unsupervised criterion for primitive selection. *Quick check*: Does total description length monotonically decrease or stabilize across iterations?
- **Wake‑Sleep Algorithm**: An EM–style procedure where wake infers programs given the library, and sleep updates the library based on inferred usage statistics. *Why needed*: Enables alternating optimization of latent program assignments and the library itself. *Quick check*: Does library coverage improve without explosion in size?
- **Event Semantics & Primitive Operators**: The theory that complex events decompose into a small set of primitive state changes (e.g., Schank’s ATRANS, PTRANS). *Why needed*: Supplies the conceptual target and a baseline for evaluation. *Quick check*: Are the learned operators interpretable as fundamental actions or transfers of properties, locations, or knowledge?
- **Library Learning**: Inducing reusable components from data, a core problem in program synthesis. *Why needed*: Allows building a combinatorial repertoire from a minimal seed set. *Quick check*: Does the library size remain bounded while enabling reconstruction of all events?
- **Compression as Inductive Bias**: The principle that models which compress data well are likely to capture underlying structure. *Why needed*: Replaces hand‑crafted primitives with a formal, information‑theoretic objective. *Quick check*: Is compressed representation correlated with successful coverage on held‑out events?

## Architecture Onboarding
Component map (plain text):  
Raw Events -> Wake Phase (Program Inference using current Library) -> Sleep Phase (Library Update via Abstraction/Merging) -> MDL Evaluation (Description Length Calculation) -> Convergence Check -> Final Library

Critical path: The system starts with generic operators, then iterates wake → sleep → MDL evaluation until convergence, yielding the final primitive library used for evaluation.

Design tradeoffs:
- **Library size vs coverage**: MDL balances small library against high coverage; too strong a compression bias yields under‑fitting, too weak yields over‑fitting.
- **Search depth in wake**: Deeper search yields better program decompositions but increases computational cost; the paper likely uses bounded depth.
- **Initial operator generality**: More generic starting operators may allow discovering richer primitives but may require more iterations or finer abstraction thresholds.

Failure signatures:
- **MDL increases**: Indicates a bad library update step (e.g., inappropriate abstraction threshold).
- **Coverage plateaus below 100%**: The library lacks necessary primitives; abstraction may be too aggressive or the initial operators insufficient.
- **Library explosion**: Too many operators are retained; MDL weighting is insufficient or merging criteria too lenient.

First three experiments:
1. **Synthetic reconstruction test**: Verify that the system rediscovers Schank’s primitives on data generated from them.
2. **ATOMIC coverage evaluation**: Measure the percentage of ATOMIC events that can be expressed using the learned library and compare with Schank’s set.
3. **Ablation on initial operators**: Assess robustness by varying the number and type of generic starting operators (e.g., 2 vs 4) and observing impact on final library quality and coverage.

## Open Questions the Paper Calls Out
The paper does not explicitly list separate open questions; its discussion points toward future work such as testing on additional datasets, human validation of discovered primitives, and sensitivity analysis.

## Limitations
- Synthetic data is oversimplified, limiting real‑world applicability of the findings.
- The claim of 100% coverage on ATOMIC may be inflated due to a larger library size, making direct comparison with Schank’s smaller primitive set unfair.
- Operator mappings (e.g., MOVE_PROP_has ≈ ATRANS) are heuristic and lack systematic validation.

## Confidence
- **Method discovery (wake‑sleep MDL pipeline)**: Medium (described but implementation details sparse).
- **Performance (synthetic data)**: Medium; on ATOMIC: Low (risk of overfitting).
- **Rediscovery/novelty of operators**: Medium for approximating Schankian primitives; Low for mental/emotional primitives (lack of broader evidence).
- **Theoretical implication (MDL yields universal primitives)**: Low (speculative, depends on prior choices).
