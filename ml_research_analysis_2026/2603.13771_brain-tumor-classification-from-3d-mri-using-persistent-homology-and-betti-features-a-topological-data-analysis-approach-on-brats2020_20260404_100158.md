# Brain Tumor Classification from 3D MRI Using Persistent Homology and Betti Features: A Topological Data Analysis Approach on BraTS2020

## Quick Facts
- **arXiv ID:** 2603.13771
- **Source URL:** https://arxiv.org/abs/2603.13771
- **Reference count:** 30
- **Primary result:** Random Forest with selected Betti features achieved 89.19% accuracy; B1+B2 (42 features) reached 90.50% precision on BraTS2020.

## Executive Summary
This study proposes a Topological Data Analysis (TDA) approach for brain tumor grade classification (LGG vs. HGG) using 3D FLAIR MRI. Persistent homology extracts multi-scale topological descriptors (Betti curves) from the tumor region, which are then fed to a Random Forest classifier after feature selection. On the BraTS2020 dataset, the method achieves high accuracy (89.19%) and precision (90.50%) without deep learning, demonstrating that compact topological features can effectively capture tumor morphology.

## Method Summary
The pipeline begins with preprocessing 3D FLAIR volumes (240×240×155) by extracting central slices (30–90) and normalizing intensities to [0,255]. A cubical sublevel filtration is applied over 100 uniformly spaced thresholds, generating a nested sequence of binary volumes. Persistent homology computes Betti numbers (β₀, β₁, β₂) at each threshold, yielding three 100-length curves that are concatenated into a 300-dimensional feature vector per patient. Feature selection using Random Forest importances reduces dimensionality (e.g., to 14 or 42 features). Final classification uses Random Forest or XGBoost classifiers, evaluated via an 80:20 train-test split.

## Key Results
- Random Forest with selected Betti features attained **89.19% accuracy** on BraTS2020.
- The B1+B2 feature subset (42 features) achieved **90.50% precision**.
- Feature selection reduced dimensionality from 300 to as few as 14 features while **improving performance**.

## Why This Works (Mechanism)
### Mechanism 1
**Claim:** Persistent homology extracts topological features that distinguish between LGG and HGG by encoding multi-scale shape characteristics of the tumor.  
**Mechanism:** A cubical sublevel filtration thresholds the 3D FLAIR MRI volume, creating a nested sequence of binary volumes. For each threshold, the topology (connected components, loops, cavities) is computed. The resulting Betti curves (β₀, β₁, β₂ over 100 thresholds) capture how topological structures appear and disappear as intensity increases. HGG tumors often exhibit more cavities (necrosis) and irregular boundaries (loops) than LGG, leading to systematically different Betti curves.  
**Core assumption:** Tumor grade correlates with topological complexity in the FLAIR-enhanced region.  
**Evidence anchors:**  
- Abstract: "Persistent homology captures intrinsic geometric and structural characteristics of the data through Betti numbers, which describe connected components (Betti-0), loops (Betti-1), and voids (Betti-2)."  
- Section 3.1–3.4 details the cubical filtration and Betti curve extraction; Figure 3 visualizes median Betti curves showing class separation.  
- Neighboring papers (e.g., "3D-TDA -- Topological feature extraction from 3D images for Alzheimer's disease classification") similarly use Betti features for medical classification.  
**Break condition:** If LGG and HGG produce overlapping Betti curve distributions (e.g., due to poor segmentation, noise, or preprocessing artifacts), the topological features would lack discriminative power.

### Mechanism 2
**Claim:** Feature selection based on tree-based importance scores reduces dimensionality and improves classification accuracy by discarding redundant or noisy topological descriptors.  
**Mechanism:** From the initial 300-dimensional Betti feature vector, a preliminary ensemble model (Random Forest or XGBoost) assigns an importance score to each feature. Only features with importance above a threshold τ are retained. This removes features that contribute little to the classification task, reducing overfitting and computational cost while preserving discriminative information. The paper shows that using as few as 14 features (for B0+B1+B2) or 42 features (for B1+B2) yields higher accuracy than the full set.  
**Core assumption:** Feature importance scores from a tree-based model reliably indicate predictive relevance.  
**Evidence anchors:**  
- Abstract: "Feature selection reduced dimensionality from 300 to as few as 14 features while improving performance."  
- Section 3.5 describes the feature selection procedure; Tables 2 and 3 report that selected feature sets consistently improve accuracy and precision compared to using all features.  
- Standard machine learning practice supports feature selection to combat the curse of dimensionality.  
**Break condition:** If the importance metric misranks features (e.g., due to multicollinearity), feature selection might discard truly informative descriptors, degrading performance.

### Mechanism 3
**Claim:** Ensemble tree classifiers (Random Forest, XGBoost) effectively model nonlinear relationships between topological features and tumor grade, leading to high classification accuracy.  
**Mechanism:** The Betti feature space, though low-dimensional, may contain complex interactions. Tree ensembles build multiple decision trees that partition the feature space via axis-aligned splits, capturing nonlinear decision boundaries. Random Forest reduces variance through bagging, while XGBoost sequentially corrects errors with gradient boosting. Their hyperparameters (e.g., number of trees, depth) control model capacity to avoid overfitting on the limited BraTS2020 dataset.  
**Core assumption:** The relationship between topological descriptors and tumor grade is learnable by tree-based models with the chosen hyperparameters.  
**Evidence anchors:**  
- Abstract: "Random Forest classifier combined with selected Betti features achieves an accuracy of 89.19%."  
- Section 3.6 outlines the classifiers; Table 3 shows Random Forest with selected B1+B2 achieves 89.19% accuracy and 90.50% precision.  
- Related work combines topological features with machine learning, but the paper specifically demonstrates superiority of Random Forest with feature selection.  
**Break condition:** If the classes are not separable by piecewise-constant splits or if the feature space is too noisy, tree ensembles may underperform; also, poor hyperparameter choice could cause overfitting.

## Foundational Learning
### Concept: Persistent Homology and Betti Numbers
**Why needed here:** It is the core mathematical framework that transforms a 3D MRI volume into a set of topological descriptors (Betti curves). Without understanding homology groups and how they quantify connected components, loops, and cavities, one cannot interpret the feature extraction process.  
**Quick check question:** *What do Betti-0, Betti-1, and Betti-2 represent in the context of a 3D MRI volume?*

### Concept: Cubical Filtration
**Why needed here:** The paper uses cubical complexes (voxel grids) rather than simplicial complexes for efficiency on image data. The sublevel filtration creates a nested sequence of binary volumes from the grayscale MRI, enabling computation of topology at multiple intensity thresholds.  
**Quick check question:** *How does a sublevel filtration generate a sequence of cubical complexes from a 3D MRI volume?*

### Concept: Feature Selection with Ensemble Models
**Why needed here:** The raw Betti curves yield 300 features; selecting a compact subset is crucial for improving accuracy and computational efficiency. Understanding how tree-based importance scores are computed and used for selection is essential to replicate the reported results.  
**Quick check question:** *Why might applying feature selection improve the performance of a Random Forest classifier on this task?*

## Architecture Onboarding
### Component Map
Input: 3D FLAIR MRI volume (155×240×240) -> Preprocessing: slice extraction and intensity normalization -> Cubical Filtration (100 thresholds) -> Persistent Homology (Betti curves) -> Feature Vector (300-D) -> Feature Selection (Random Forest importance) -> Selected Feature Vector -> Classification (Random Forest or XGBoost) -> Output: LGG/HGG prediction.

### Critical Path
The pipeline is linear: MRI → cubical filtration → persistence → Betti curves → feature vector → feature selection → classifier training → evaluation. No branching; each step depends on the previous.

### Design Tradeoffs
- **Filtration thresholds (N_f):** More thresholds increase resolution and dimensionality but also computational cost; paper uses N_f=100.
- **Feature selection threshold (τ):** Balances sparsity vs. information retention; determined empirically.
- **Classifier choice:** Random Forest vs. XGBoost; paper found Random Forest with feature selection performed best.
- **Volume cropping:** Using central slices reduces memory but risks losing peripheral tumor regions; justified by slice redundancy.

### Failure Signatures
- All Betti curves are nearly identical across samples → indicates failure in filtration or homology computation (e.g., thresholds not covering intensity range).
- Feature selection removes >90% of features or leaves only one → importance scores may be unreliable; check performance on full set for comparison.
- Test accuracy near 50% (random) → either topological features are not discriminative (verify Betti curve separation) or classifier is misconfigured.
- Memory errors during homology computation → cubical filtration on full 155 slices may be too heavy; ensure volume cropping is applied.

### First 3 Experiments
1. **Betti curve visualization:** Compute Betti curves for a few LGG and HGG volumes. Plot them to confirm class separation (as in Figure 3). If curves overlap heavily, revisit intensity normalization or filtration range.
2. **Feature selection sanity check:** Run the feature selection step on a small subset (e.g., 20 samples). Verify that the number of selected features is reasonable (not zero or all) and that selected features come from different Betti curves.
3. **Baseline classifier comparison:** With a fixed small feature set (e.g., all 300 features), train both Random Forest and XGBoost with default hyperparameters on a tiny dataset (10 samples per class). Check that both can achieve >70% accuracy on training data, confirming that features contain some signal. Then scale up.

## Open Questions the Paper Calls Out
### Open Question 1
**Could incorporating multi-modal MRI sequences (T1, T1ce, T2) alongside FLAIR improve classification accuracy beyond the current 89.19%?**  
Basis: The study exclusively uses FLAIR volumes. No experiments with other modalities or multimodal fusion are reported.  
Why unresolved: The contribution of complementary information from other sequences to topological descriptors remains unknown.  
Evidence needed: Systematic evaluation of Betti features extracted independently from each BraTS2020 modality and from combined filtrations, followed by performance comparison.

### Open Question 2
**What specific tumor substructures (e.g., edema, necrotic core, enhancing tumor) are encoded by the most informative Betti features selected by the Random Forest?**  
Basis: Feature selection reduced 300 features to as few as 14, improving performance, but no analysis links selected features to anatomical subregions.  
Why unresolved: The interpretability promise of TDA is not fully leveraged; clinical meaning of discriminative topological features is not elucidated.  
Evidence needed: Correlating the temporal patterns (birth/death thresholds) of top-ranked Betti features with expert tumor segmentations (BraTS ground truth labels) via statistical mapping or visualization.

### Open Question 3
**Does the proposed TDA framework generalize to other brain tumor datasets (e.g., BraTS2021, institutional cohorts) with different acquisition protocols, preprocessing, or tumor grade distributions?**  
Basis: All experiments are confined to BraTS2020 training set with a fixed 80:20 split; no external validation.  
Why unresolved: Robustness to scanner variability, different skull-stripping methods, and dataset shift is not assessed.  
Evidence needed: Applying the identical pipeline (trained on BraTS2020) to hold-out datasets like BraTS2021 or independent hospital data and reporting performance.

### Open Question 4
**Would hybridizing topological Betti features with deep learning representations (e.g., CNN embeddings) yield superior accuracy and robustness compared to either approach alone?**  
Basis: The conclusion states future work will explore integrating topological descriptors with deep learning.  
Why unresolved: The synergy between global topology and local texture patterns is untested.  
Evidence needed: Designing architectures that concatenate Betti features with CNN bottleneck features and comparing against pure-TDA and pure-CNN baselines.

### Open Question 5
**Is the fixed uniform thresholding strategy (100 thresholds over [0,255]) optimal for capturing discriminative tumor topology, or could adaptive, data-driven filtrations improve performance?**  
Basis: The method uses simple linear sublevel filtration with uniform thresholds; no justification or ablation for the number/distribution of thresholds.  
Why unresolved: Tumor intensity distributions vary between LGG/HGG; uniform thresholds might miss critical transitions.  
Evidence needed: Comparing classification performance using Betti curves from uniform thresholds vs. quantile-based thresholds, persistence-based threshold selection, or multi-parameter filtrations.

## Limitations
- **Topological Interpretability Assumption:** Betti curves show empirical separation, but the paper does not establish a biological causal link between tumor grade and topological complexity.
- **Feature Selection Opaqueness:** The exact threshold τ for feature importance is undisclosed, and the rationale for specific feature counts (e.g., 42) is not justified, limiting reproducibility.
- **Class Imbalance Handling:** With 293 HGG vs. 76 LGG samples, no explicit class weighting or resampling is used; reported metrics may be inflated by the majority class.

## Confidence
- **Mechanism 1 (TDA feature discriminativity):** Medium confidence. Evidence from median Betti curve plots supports separability, but lack of biological grounding and potential noise sensitivity temper certainty.
- **Mechanism 2 (Feature selection efficacy):** Medium-High confidence. Standard tree-based importance is widely used, but unreported τ and possible multicollinearity bias leave some doubt.
- **Mechanism 3 (Classifier suitability):** Medium-High confidence. Random Forest/XGBoost are solid for nonlinear problems, but hyperparameter sensitivity on limited data is a risk.

## Next Checks
1. **Topological separability stress test:** Recompute Betti curves on a held-out slice or after adding synthetic noise to verify LGG/HGG separation persists robustly.
2. **Feature selection parameter sweep:** Systematically vary τ to produce feature sets from 10 to 100 dimensions; report accuracy vs. feature count curves to confirm optimality of reported counts.
3. **Balanced performance audit:** Retrain with stratified 5-fold cross-validation using class weights (`balanced`) and report mean ± std metrics to assess overfitting due to imbalance.
