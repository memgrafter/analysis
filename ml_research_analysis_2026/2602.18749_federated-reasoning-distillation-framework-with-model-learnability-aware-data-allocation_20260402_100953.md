# Federated Reasoning Distillation Framework with Model Learnability-Aware Data Allocation

## Quick Facts
* arXiv ID: 2602.18749
* Source URL: https://arxiv.org/abs/2602.18749
* Reference count: 40
* Primary result: Up to 13.8% accuracy improvement on MATHInstruct and CoT-Collection over state-of-the-art baselines, with theoretical O(1/√T) convergence and stable performance in one-shot and zero-shot settings.

## Executive Summary
Federated learning (FL) of large language models (LLMs) with small client models (SLMs) faces bidirectional learnability gaps—where SLMs struggle to learn from LLMs and LLMs fail to improve from SLMs—and difficulty in transferring reasoning capabilities across domains. This paper introduces LaDa, a framework that addresses these challenges through a learnability-aware data filter and a domain-adaptive reasoning distillation method. The filter dynamically selects high-reward samples from a shared public dataset based on each model pair's evolving capacity, using an exploration-exploitation mechanism. The distillation aligns reasoning path distributions via contrastive learning, transferring logical patterns rather than token sequences. Extensive experiments on MATHInstruct and CoT-Collection show up to 13.8% accuracy gains over baselines across four scenarios. Theoretical analysis proves O(1/√T) convergence, and LaDa maintains stable improvements in both one-shot and zero-shot settings.

## Method Summary
LaDa operates within a federated knowledge distillation setting where a server hosts an LLM and clients host SLMs, all sharing a public dataset. The core components are: (1) a model learnability-aware data filter on each client and server that predicts per-sample reward via loss reduction trajectories, balancing exploitation of known high-reward samples with exploration of uncertain ones using two neural networks (ExploitNet and ExploreNet); (2) a domain adaptive reasoning distillation module that, for each selected sample, generates reasoning paths from LLM and SLM and applies a DPO-inspired contrastive loss to align the SLM's distribution with the LLM's on reasoning structure, while the server aggregates overlapping samples to update the LLM. The system runs in rounds: clients select batches, compute distillation losses to update SLMs, send rewards and overlapping sets to server, which updates the LLM. This bidirectional loop adapts to changing learnability and transfers reasoning patterns robustly.

## Key Results
* Up to 13.8% accuracy improvement on MATHInstruct and CoT-Collection datasets over state-of-the-art baselines.
* Theoretical guarantee of O(1/√T) convergence for the federated optimization.
* Consistent performance gains in both one-shot and zero-shot settings across four experimental scenarios.

## Why This Works (Mechanism)

### Mechanism 1: Adaptive Data Allocation for Bidirectional Learnability
- **Claim:** LaDa addresses the bidirectional model learnability gap by dynamically allocating high-reward samples matched to each LLM-SLM pair's evolving capacity.
- **Mechanism:** A model learnability-aware data filter uses an exploration-exploitation framework (ExploitNet + ExploreNet) to predict per-sample reward based on loss reduction trajectories. Rewards combine round-level and batch-level performance changes, guiding selection of samples that yield meaningful knowledge transfer for both SLM learning from LLM and LLM learning from SLMs.
- **Core assumption:** The loss variation on a sample correlates with its learnability value for a specific model pair; sequential decision-making under non-stationary model states can be framed as an exploration-exploitation problem.
- **Evidence:** [abstract] explicitly states addressing "bidirectional model learnability gap" with a "model learnability-aware data filter"; [section IV.B] details reward definition and filter architecture; neighbor paper "Small Models Struggle to Learn from Strong Reasoners" supports existence of learnability gap.
- **Break condition:** If model capacities change drastically mid-training or if the reward signal becomes decorrelated with actual downstream task performance.

### Mechanism 2: Contrastive Reasoning Distillation for Domain-Agnostic Transfer
- **Claim:** LaDa enables domain-agnostic reasoning transfer by aligning joint probability distributions of reasoning paths via contrastive distillation, rather than imitating token sequences.
- **Mechanism:** Uses a DPO-inspired loss where LLM-generated reasoning path is treated as preferred and SLM's as non-preferred. By minimizing the contrastive loss, the SLM aligns its token probability distribution with the LLM's on reasoning structure, allowing adaptation to local data distributions. For LLM learning from SLMs, overlapping samples use weighted loss summation.
- **Core assumption:** Reasoning ability is encoded in the joint probability distribution over reasoning tokens; contrasting good vs bad reasoning paths transfers core logical patterns more robustly than sequence-level cross-entropy.
- **Evidence:** [abstract] mentions "domain adaptive reasoning distillation method using contrastive learning"; [section IV.A] formally defines the losses; [section VI.C] ablation shows large performance drops when removing this component.
- **Break condition:** If the contrastive preference pairs are consistently misaligned or if local data distribution is too divergent.

### Mechanism 3: Stable Convergent Optimization in Heterogeneous FL
- **Claim:** The bidirectional optimization and filtering loop converges stably, enabling sustained performance gains across heterogeneous model collaborations.
- **Mechanism:** Theoretical analysis models the system as a bilevel optimization with client updates as inner-loop and server update as outer-loop. Under standard assumptions (bounded gradients, i.i.d. data, etc.), the paper proves an O(1/√T) convergence rate. The adaptive filter's exploration-exploitation is treated as a stochastic gradient selection mechanism that does not alter the convergence bound.
- **Core assumption:** Stochastic gradients from filtered samples have bounded variance; the filter's adaptive selection does not introduce bias that violates standard FL convergence assumptions.
- **Evidence:** [section V] provides full convergence analysis; [section VI.E] empirical convergence curves show stable improvement over 5 rounds; neighbor paper "Trust-free Personalized Decentralized Learning" provides context.
- **Break condition:** If exploration becomes too aggressive (λ too high) leading to high-variance updates, or if model heterogeneity violates bounded derivative assumptions.

## Architecture Onboarding
### Component Map
Server (LLM f_ψ, filter U_s) <-> Clients (SLM g_ϕk, filter U_k, reference policy ϕ_refk) via Shared Public Dataset D_p, with Reasoning Distillation Module.

### Critical Path
At each round t, each client's filter U_k selects a batch D_{t,b}^k from D_p based on predicted rewards. The SLM and LLM generate reasoning responses for these samples. The client computes L_mard_client to update its SLM. The server receives overlapping high-reward sample sets from all clients (and its own selected set) and computes L_mard_server to update the LLM. Observed rewards from this batch are used to update the filters (ExploitNet and ExploreNet). This loop repeats.

### Design Tradeoffs
- Filter complexity (two networks) vs. communication overhead.
- Conservative hyperparameters (α, λ) for zero-shot vs. aggressive for one-shot.
- Weighting overlapping samples on server (Eq. 4) balances aggregated knowledge vs. client-specific contributions.

### Failure Signatures
- Divergence of ϕ_k from ϕ_refk if β in Eq. 3 is too high, leading to catastrophic forgetting.
- Filter collapse to constant selection if exploration (λ) is zero, failing to adapt to changing learnability.
- Server performance drop if non-overlapping client samples contain noise, indicating weak sample filtering at client side.

### First 3 Experiments
1. Ablation - Remove filter: Train without U_k, using all D_p. Expect significant drop (per Tab. V), confirming filter's role.
2. Ablation - Replace L_mard with CE Loss: Use standard cross-entropy on final answers. Expect major reasoning capability loss, proving contrastive distillation on paths is critical.
3. Vary λ (exploration strength): Set λ=0 (no exploration). Expect faster initial improvement but poorer final convergence as filter gets stuck in suboptimal sample pools, demonstrating need for adaptive exploration.

## Limitations
- Domain generalizability limited to two instruction-following datasets; uncertain for other reasoning domains (e.g., code, biomedical QA).
- Reward–learnability correlation assumption may break under distribution shift or non-stationary data.
- Theoretical assumptions (bounded gradients, i.i.d. client data) may not hold in real-world heterogeneous FL; empirical validation over only 5 rounds is short-term.

## Confidence
- Bidirectional learnability gap addressed via adaptive filter: Medium
- Domain-agnostic reasoning transfer via contrastive distillation: Medium
- Stable convergence with O(1/√T): Medium

## Next Checks
1. Cross-domain transfer: Apply LaDa to at least two additional reasoning tasks (e.g., theorem proving, program synthesis) and compare against baselines.
2. Ablate exploration component: Remove ExploreNet (λ=0) and replace U_k with random sampling, greedy loss selection, and standard UCB to isolate the benefit of the proposed exploration-exploitation design.
3. Reward signal robustness: Correlate the defined reward (Eqs.5-7) with alternative learnability proxies (e.g., gradient norm, prediction entropy) across rounds; measure performance when substituting a different proxy.
