# HART: Data-Driven Hallucination Attribution and Evidence-Based Tracing for Large Language Models

## Quick Facts
- **arXiv ID:** 2603.05828
- **Source URL:** https://arxiv.org/abs/2603.05828
- **Reference count:** 27
- **Primary result:** HART achieves a Recall@1 of 0.8024 on the Qwen dataset for hallucination evidence retrieval, substantially outperforming BM25 (0.1074) and demonstrating high classification accuracy for hallucination types (83.32%) and error mechanisms (79.13%).

## Executive Summary
HART addresses the critical challenge of hallucination in large language models by formalizing hallucination tracing as a structured four-stage task: span localization, mechanism attribution, evidence retrieval, and causal tracing. It introduces the first fine-grained dataset with joint annotations for hallucination types, error mechanisms, and counterfactual evidence. The framework employs a two-stage semantic retrieval system using FAISS indexing and Cross-Encoder reranking to align hallucinated fragments with factual evidence. Evaluations show significant improvements over baseline retrieval methods and provide a causal evidence alignment paradigm for interpretable hallucination analysis.

## Method Summary
HART decomposes hallucination tracing into four sequential stages. First, hallucinated spans within an LLM-generated text are localized. Second, each span is classified by hallucination type (4 classes) and underlying error mechanism (5 classes) using separate BERT-based classifiers. Third, a query generator creates diverse search queries from the span and its context, which are used to retrieve candidate evidence from a large factual corpus via FAISS (dense vector search). Finally, a Cross-Encoder reranks these candidates to select the most semantically aligned counterfactual evidence. The output is a trace tuple linking each hallucination span to its predicted type, mechanism, and aligned evidence. The system is supervised by a novel span-level dataset where each hallucination is annotated with these three elements, enabling end-to-end training and evaluation.

## Key Results
- HART achieves Recall@1 of 0.8024 on the Qwen dataset, far surpassing BM25 (0.1074) and DPR.
- Hallucination type classification accuracy reaches 83.32%, and error mechanism attribution accuracy reaches 79.13%.
- The two-stage retrieval (FAISS + Cross-Encoder) is essential, with significant gains over single-stage dense or sparse methods.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Formalizing hallucination tracing as a four-stage structured task enables systematic causal attribution from hallucination spans to external evidence.
- **Mechanism:** The pipeline decomposes the problem into (1) span localization, (2) hallucination type classification, (3) error mechanism attribution, and (4) evidence retrieval. This decomposition allows specialized models per stage, culminating in an interpretable trace connecting a hallucination to its origin and factual correction.
- **Core assumption:** Hallucinations are decomposable into localized errors with distinct types and mechanisms, and external factual evidence can be semantically aligned with hallucinated fragments.
- **Evidence anchors:**
  - [abstract]: "HART formalizes hallucination tracing as a structured modeling task comprising four stages: span localization, mechanism attribution, evidence retrieval, and causal tracing."
  - [section]: Section 3.4.1 defines the four stages; Algorithm 1 shows the integrated pipeline.
  - [corpus]: Neighboring papers focus on internal representation or subsequence associations, not a staged attribution pipeline, indicating a gap HART addresses.

### Mechanism 2
- **Claim:** Two-stage semantic retrieval (FAISS indexing + Cross-Encoder reranking) achieves high recall and precision in aligning hallucinated fragments with factual evidence at scale.
- **Mechanism:** First, hallucinated fragments are encoded as queries and matched against a FAISS index of evidence embeddings for efficient approximate nearest neighbor search. Then, a Cross-Encoder jointly encodes each query-candidate pair and produces a refined matching score, which reranks the top candidates to capture finer semantic and factual contrasts.
- **Core assumption:** Embedding-based similarity is sufficient for initial recall, but cross-encoder interaction is necessary to distinguish subtle factual inconsistencies and achieve high-precision attribution.
- **Evidence anchors:**
  - [abstract]: "The framework uses semantic embedding retrieval with FAISS indexing and Cross-Encoder reranking to align hallucinated fragments with factual evidence."
  - [section]: Section 3.3 details the retrieval workflow: evidence corpus construction, semantic encoding, FAISS indexing, and Cross-Encoder reranking.
  - [corpus]: Baselines like BM25 and DPR are single-stage; the corpus does not show prior work combining FAISS and Cross-Encoder specifically for hallucination evidence tracing.

### Mechanism 3
- **Claim:** A span-level dataset with joint annotations for hallucination types, error mechanisms, and counterfactual evidence provides necessary supervision for end-to-end hallucination tracing and evaluation.
- **Mechanism:** By annotating each hallucinated span with a hallucination type, an error mechanism, and a set of semantically aligned opposing evidence, the dataset enables models to learn the mapping from error patterns to factual grounds. This supports training of classifiers and the retrieval system and allows holistic evaluation.
- **Core assumption:** Such multi-dimensional annotations are reliably obtainable via an LLM-assisted human pipeline, and the curated evidence sets truly represent counterfactual information.
- **Evidence anchors:**
  - [abstract]: "we develop the first structured dataset tailored for hallucination tracing, in which hallucination types, error mechanisms, and sets of counterfactual evidence are jointly annotated."
  - [section]: Section 3.2 describes the dataset construction process, including the dual-layer annotation schema and evidence selection optimization.
  - [corpus]: Existing datasets like RAGTruth annotate unsupported statements but lack explicit error mechanisms and counterfactual evidence; HART's dataset is the first to provide such comprehensive annotations.

## Foundational Learning
- **Concept:** Span-level hallucination annotation  
  - *Why needed here:* HART operates on exact substrings of hallucinated content; without precise spans, localization fails and downstream stages cannot be applied.  
  - *Quick check question:* Given the sentence "The capital of Australia is Sydney, which is Australia's largest city by area," identify the hallucinated span(s).

- **Concept:** Semantic embedding retrieval  
  - *Why needed here:* The evidence retrieval stage maps hallucinated fragments and evidence texts into a shared embedding space to find semantically similar counterfactual information.  
  - *Quick check question:* Why might "Canberra" and "Sydney" have similar embeddings despite being contradictory facts about the capital?

- **Concept:** Cross-Encoder reranking  
  - *Why needed here:* After coarse retrieval, the Cross-Encoder deeply compares query and evidence texts to refine rankings, ensuring top evidence is not only similar but factually opposing.  
  - *Quick check question:* How does a Cross-Encoder differ from a bi-encoder (e.g., Sentence-BERT) in computational cost and precision for retrieval?

## Architecture Onboarding
- **Component map:**  
  Input (LLM text + hallucination spans) -> Span Localization -> Hallucination Type Classifier & Error Mechanism Classifier (parallel) -> Query Generator -> FAISS Coarse Retrieval -> Cross-Encoder Reranking -> Evidence Selection -> Trace Formatter -> Output (trace tuples).
- **Critical path:** Span -> Context -> (Type & Mechanism classifiers in parallel) -> Query set -> FAISS retrieval -> Cross-Encoder reranking -> Evidence selection -> Trace tuple.
- **Design tradeoffs:**  
  - Efficiency vs. precision: FAISS enables sublinear search but relies on embedding quality; Cross-Encoder improves precision but is computationally heavier.  
  - Query diversity vs. redundancy: Multiple queries increase hit chance but may retrieve overlapping results.  
  - Decoupled classifiers: Separate models allow specialization but increase inference overhead.
- **Failure signatures:**  
  - Span mislocalization (wrong boundaries propagates errors downstream).  
  - Retrieval miss (true evidence absent from top-k due to embedding issues).  
  - Classifier confusion (similar types/mechanisms mispredicted).  
  - Cross-encoder bias (overfitting to surface patterns, preferring lexically similar but factually incorrect evidence).
- **First 3 experiments:**  
  1. **Dataset verification**: On a small annotated subset, compute inter-annotator agreement and noise rate to validate annotation quality.  
  2. **Classifier training**: Train type and mechanism classifiers on 70% of the dataset, validate on 10%, and report accuracy/loss curves; check for overfitting.  
  3. **Retrieval ablation**: Test combinations of (a) dense embedding only, (b) + Cross-Encoder, (c) + multi-query on a held-out set; measure Recall@k, MRR, and nDCG.

## Open Questions the Paper Calls Out
- **Open Question 1:** How can HART be extended to model multi-hop causal chains where a hallucination results from multiple interdependent evidence pieces or reasoning steps?  
  *Basis in paper:* [explicit] The conclusion states future work will explore "multi-hop evidence causal chain modeling."  
  *Why unresolved:* Current HART retrieves single evidence pieces; multi-hop requires tracking evidence chains across hops.  
  *What evidence would resolve it:* A dataset with multi-hop hallucination annotations and a retrieval method that can chain evidence across steps.

- **Open Question 2:** Does HART's semantic retrieval fail for hallucinations that are semantically close to correct facts but differ in critical details, and how can it be improved?  
  *Basis in paper:* [inferred] The retrieval framework assumes "semantic proximity preservation" and "semantic separability" but does not analyze edge cases where hallucinations are subtle perturbations.  
  *Why unresolved:* No evaluation on factually similar hallucinations; embedding spaces may conflate such cases.  
  *What evidence would resolve it:* A controlled test set of hallucinations that are minor lexical/semantic variants of true facts, measuring retrieval precision.

- **Open Question 3:** How does span localization error propagate through HART's pipeline, and can the system be made robust or jointly optimize span boundaries?  
  *Basis in paper:* [inferred] HART treats span localization as a given first stage but does not analyze sensitivity to span boundary mistakes.  
  *Why unresolved:* Real-world use requires automatic span detection; errors there could cascade.  
  *What evidence would resolve it:* Experiments with intentionally perturbed span boundaries and a joint model that simultaneously localizes and attributes hallucinations.

- **Open Question 4:** Does the dataset construction using web-search-enabled LLMs introduce a bias toward certain hallucination types, limiting HART's generalizability to other models or domains?  
  *Basis in paper:* [inferred] The dataset was built using Claude Sonnet 4.5 with web search and ChatGPT 5.1 for evidence selection, which may favor hallucinations detectable via web search.  
  *Why unresolved:* The hallucination distribution might not reflect all LLMs or domains; HART's performance on out-of-distribution hallucinations is not tested.  
  *What evidence would resolve it:* Comparative analysis of hallucination types across diverse LLMs and domains; testing HART on independently constructed datasets.

## Limitations
- Dataset and evidence corpus are unreleased; key construction details (e.g., redundancy penalty λ, Wikipedia dump version) are missing.
- Critical hyperparameters (context window size w, query count k, classifier architectures, training schedule) are unspecified.
- Annotation quality lacks metrics (inter-annotator agreement, noise threshold τ), raising concerns about label reliability.
- The pipeline is vulnerable: span mislocalization propagates errors to all downstream stages, potentially collapsing the causal trace.

## Confidence
- **Four-stage formalization** (span localization → type/mechanism classification → evidence retrieval): *Medium*. The decomposition is well-described but no direct ablation proves its necessity; errors likely cascade.
- **Two-stage retrieval** (FAISS + Cross-Encoder): *High*. Large gains over BM25/DPR (Recall@1 0.8024 vs. 0.1074) support effectiveness, though full component ablation is not reported.
- **Joint-annotation dataset**: *Medium*. Novelty is evident, but without access or agreement statistics, its supervision quality remains unverified.
- **Reported accuracies** (type 83.32%, mechanism 79.13%): *Medium*. Numbers are plausible but reproducibility is hindered by missing splits/hyperparameters.

## Next Checks
1. **Span error propagation test:** Deliberately perturb span boundaries (±N tokens) on a validation set and measure degradation in Joint SR@1 to quantify cascade risk.
2. **Reranking ablation:** Remove the Cross-Encoder or replace it with a bi-encoder; compare Recall@k against the full pipeline to isolate each stage’s contribution.
3. **Hyperparameter sensitivity sweep:** Vary context window (w = 20, 50, 100 tokens) and query count (k = 1, 3, 5) on a fixed dev split; report stability of recall and classification accuracy.
