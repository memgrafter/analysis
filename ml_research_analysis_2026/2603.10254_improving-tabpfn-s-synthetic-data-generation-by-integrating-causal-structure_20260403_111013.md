# Improving TabPFN's Synthetic Data Generation by Integrating Causal Structure
## Quick Facts
- arXiv ID: 2603.10254
- Source URL: https://arxiv.org/abs/2603.10254
- Reference count: 40
- Primary result: Integrating causal structure via DAG-aware conditioning significantly improves TabPFN's synthetic data quality and causal fidelity compared to vanilla ordering.

## Executive Summary
TabPFN's autoregressive synthetic data generation is sensitive to feature ordering, producing spurious correlations when the order conflicts with the underlying causal graph. The authors address this by proposing DAG-aware conditioning (generating each variable conditioned only on its causal parents, using a topological order) and a hybrid CPDAG-based strategy for partial causal knowledge. Evaluations across multiple benchmarks and six CSuite datasets show that DAG-aware conditioning consistently improves structural fidelity (lower CMD), distributional alignment (lower kMTVD), privacy preservation (NNAA), and treatment effect preservation (ATE error). The CPDAG approach yields moderate gains when sufficient edges are oriented, though its effectiveness depends on V-structure placement. Results demonstrate that aligning generation order with causal structure enhances reliability, especially with limited data.

## Method Summary
The method modifies TabPFN's autoregressive generation by replacing the default conditioning on all preceding features with conditioning based on known causal structure. For a complete directed acyclic graph (DAG), each variable is generated conditioned only on its causal parents, using a topological ordering to ensure ancestors precede descendants. For partial causal knowledge represented as a completed partially directed acyclic graph (CPDAG), a hybrid strategy is used: if a variable is "fully directed" (has at least one directed adjacent edge and no undirected edges), it is conditioned on its causal parents; otherwise, it falls back to conditioning on all predecessors in a prioritized ordering that places fully directed variables first. This prevents the model from conditioning on descendants or unrelated variables, thereby avoiding spurious correlations introduced by arbitrary column orders.

## Key Results
- DAG-aware conditioning significantly improves structural fidelity (CMD) in 24 out of 35 configurations and reduces ATE error in 26 out of 42 configurations compared to vanilla TabPFN with original feature order.
- The CPDAG-based hybrid strategy provides moderate improvements when enough edges are oriented (e.g., minimal CPDAG with V-structures), but can degrade performance if oriented edges are sparse or misplaced.
- Vanilla TabPFN exhibits high sensitivity to feature order; using an order conflicting with the causal graph induces spurious correlations (absolute Pearson’s ρ up to ≈0.15) and inflates ATE error, while a topological order largely mitigates these issues.

## Why This Works (Mechanism)
- **Mechanism 1**: TabPFN’s autoregressive generation conditions each variable on all preceding features in a fixed global order. If a collider (variable with multiple parents) appears before its parents, the model conditions on the collider when generating its parents, inducing a spurious dependence between otherwise independent causes. Permutation-averaging during inference does not remove this sequential dependency.
- **Mechanism 2**: DAG-aware conditioning replaces the predecessor set with the true parent set from a known DAG and uses a topological order. This ensures each variable is generated given only its direct causes, respecting the true conditional independencies and preventing the introduction of spurious edges in the synthetic joint distribution.
- **Mechanism 3**: The hybrid CPDAG strategy leverages partially oriented edges: for variables with at least one directed edge and no undirected edges (fully directed), it conditions on their causal parents; for others, it falls back to predecessor conditioning with an ordering that prioritizes fully directed variables. This exploits orientable parts of the graph (e.g., V-structures) while avoiding commitment to ambiguous edges, but benefits depend on the fraction of oriented edges and their placement.

## Foundational Learning
- **Autoregressive tabular generation**: Why needed? TabPFN generates features sequentially; understanding how the fixed ordering defines conditioning context is key to diagnosing spurious correlation problems. Quick check: How does generating a variable conditioned on a descendant rather than a parent create spurious marginal correlations?
- **Causal graphs (DAGs and CPDAGs)**: Why needed? The solution requires aligning generation with causal structure; DAGs provide complete parent sets, while CPDAGs represent partial knowledge from causal discovery. Quick check: What distinguishes a CPDAG from a full DAG, and why does this matter for conditioning?
- **Collider (V-structure) bias**: Why needed? Colliders illustrate how conditioning on a common effect induces dependence between independent causes, a core failure mode when generation order misaligns with causality. Quick check: Why does generating X←Z→Y in the order (Z, X, Y) make X and Y appear correlated even if they are marginally independent?

## Architecture Onboarding
- Component map: Input dataset + causal graph/CPDAG -> Preprocessing (compute generation ordering) -> For each variable in order: select conditioning set (parents if oriented; predecessors otherwise) -> Query TabPFN (transformer) to sample next column -> Output synthetic dataset.
- Critical path: 1) Acquire/assume causal structure (DAG or CPDAG). 2) Compute a valid generation ordering (topological for DAG; σ prioritizing fully directed variables for CPDAG). 3) For each variable, select conditioning set per strategy. 4) Autoregressively sample all rows using TabPFN. 5) Evaluate synthetic data quality (CMD, kMTVD, NNAA) and causal metrics (ATE error).
- Design tradeoffs: DAG-aware requires a complete correct DAG (rare in practice) but has the best theoretical properties; CPDAG tolerates partial knowledge but performance scales with oriented edge fraction and V-structure placement; vanilla needs no causal input but is highly order-sensitive.
- Failure signatures: Elevated CMD indicating distorted dependency structure; non-zero correlations between empirically independent variables (e.g., in custom SCM pairs); severe ATE error, especially on collider-containing datasets; for CPDAG, no improvement when PC-discovered graphs have low orientation or when REX orientations are inaccurate.
- First 3 experiments: 1) Order sensitivity baseline: Run vanilla TabPFN on a collider SCM with original, topological, and reverse topological orders; verify CMD and spurious correlations vary dramatically. 2) DAG-aware validation: Apply DAG-aware conditioning on the collider SCM and CSuite datasets; confirm near-zero spurious correlations and lower CMD/kMTVD vs. vanilla. 3) CPDAG stress test: Apply PC-stable discovered CPDAGs on datasets with known low orientation (e.g., CMC); observe when improvements occur (enough edges oriented) versus degradations.

## Open Questions the Paper Calls Out
- How can ordering strategies for incomplete causal knowledge be made robust to V-structure placement?
- How do different causal discovery algorithms impact the quality of synthetic data generated by TabPFN with causal conditioning?
- What evaluation metrics are suitable for synthetic data from SCMs with non-monotonic dependencies (e.g., multiplicative equations)?
- Does integrating causal structure into autoregressive generation improve synthetic data quality for other neural architectures beyond TabPFN?
- How do other causal estimands (e.g., individual treatment effects) and downstream tasks respond to causal conditioning in synthetic data?

## Limitations
- Exact random seeds for train-test splits and resampling are not provided, potentially causing minor metric variations.
- Simglucose preprocessing details are incomplete and rely on external code, risking dataset divergence from the paper’s version.
- PC-stable often discovers CPDAGs with low orientation rates and direction precision, limiting the hybrid strategy’s practical benefit; many real-world partial causal graphs may be too sparse to help.

## Confidence
- Mechanism 1 (ordering sensitivity causes spurious correlations): High
- Mechanism 2 (DAG-aware conditioning improves quality and causal fidelity with a correct DAG): High; confidence drops to Medium/unknown under DAG misspecification (not tested).
- Mechanism 3 (CPDAG hybrid yields moderate improvements when enough edges are oriented): Medium; effectiveness is highly variable and depends on graph structure.

## Next Checks
- **Seed sensitivity analysis**: Repeat main experiments across at least 10 random seeds; compute mean and variance of CMD, kMTVD, NNAA, and ATE error; verify effect sizes remain statistically significant.
- **DAG misspecification robustness**: Systematically perturb the true DAG (random edge flips, additions, removals) at increasing rates; evaluate DAG-aware conditioning’s performance decay relative to vanilla; identify the perturbation threshold where benefits vanish.
- **Real-world CPDAG utility**: On three datasets from the Cause-Effect Pairs benchmark, learn CPDAGs from limited data (N=50, 100) using PC-stable; apply the hybrid generation and compare privacy (NNAA) and treatment effect preservation against vanilla to gauge practical value under realistic partial causal knowledge.
