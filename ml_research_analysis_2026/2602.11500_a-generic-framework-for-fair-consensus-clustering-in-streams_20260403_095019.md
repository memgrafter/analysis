# A Generic Framework for Fair Consensus Clustering in Streams

## Quick Facts
- arXiv ID: 2602.11500
- Source URL: https://arxiv.org/abs/2602.11500
- Reference count: 40
- Primary result: A fairness-agnostic streaming framework that uses uniform sampling to achieve constant-factor approximations for fair consensus clustering with sublinear space.

## Executive Summary
The paper addresses fair consensus clustering in streaming settings, where input clusterings arrive sequentially and memory is limited. Previous offline approaches required storing all inputs, which is infeasible for large-scale data. The core method proposes a new generic framework that integrates closest fair clustering with cluster fitting, using uniform sampling to maintain only a small subset of inputs. The approach is fairness-agnostic, applicable to any fairness constraint for which an efficient approximate closest fair clustering subroutine exists. Primary results include a (γ+1.995)-approximation for streaming 1-median fair consensus and a (1.0151γ+1.99951)-approximation for streaming k-median fair consensus, both with high probability. For specific two-color fairness cases, the framework yields improved ratios: 3.01461 for equi-proportionate, 19.25621 for p:1, and 35.49781 for p:q.

## Method Summary
The framework operates in two phases: candidate generation and selection. During the stream, it uniformly samples a logarithmic number of clusterings to store in two memory structures. After the stream, it rebuilds these clusterings and generates candidate fair clusterings by (1) applying a γ-approximate closest fair clustering oracle to each sampled input, and (2) for every triple of sampled inputs, solving fair correlation clustering on a majority-vote graph. A second independent sample of clusterings is used to evaluate candidates, selecting the one minimizing the empirical objective. For k-median, the process extends using monotone faraway sampling and coreset construction to handle multiple centers efficiently, achieving sublinear space while maintaining approximation guarantees.

## Why This Works (Mechanism)

### Mechanism 1: Candidate Set Generation via Two-Phase Framework
- **Claim:** Combining closest fair clustering (to each input) and cluster-fitting (on triples) into a candidate set yields a better approximation than using either alone, even offline.
- **Mechanism:** The algorithm builds a candidate set 𝓕 containing two types of fair clusterings: (1) For each input clustering Cᵢ, compute a γ-close fair clustering Fᵢ. (2) For every triple of inputs {Cᵢ, Cⱼ, Cₖ}, construct a graph G where edges are labeled based on majority pairwise agreements, then compute a fair correlation clustering on G (called eₜ). The final output is the candidate minimizing the median objective.
- **Core assumption:** The closest fair clustering subroutine provides a γ-approximation, and the fair correlation clustering subroutine provides an η-approximation.
- **Evidence anchors:** Lemma A.1 proves one candidate in 𝓕 achieves approximation r = max(..., (1+3(η+1)α), ...), directly linking candidate quality to subroutines. The abstract and section 3 describe the framework.
- **Break condition:** If the candidate set omits a region where the optimal fair clustering lies—e.g., if no sampled triple's majority-vote graph sufficiently represents the optimal consensus structure—the guarantee fails.

### Mechanism 2: Fairness-Agnostic Black-Box Integration
- **Claim:** The framework applies to any fairness constraint for which an efficient approximate closest fair clustering subroutine exists.
- **Mechanism:** The core algorithm calls a γ-close fair clustering subroutine as an oracle. The approximation analysis treats the subroutine's ratio γ as a parameter; the final bound is expressed in terms of γ. The fairness constraint's specifics do not appear elsewhere.
- **Core assumption:** There exists a polynomial-time algorithm that, given any clustering D, outputs a fair clustering N such that dist(D,N) ≤ γ·dist(D,N*), where N* is the closest fair clustering to D.
- **Evidence anchors:** The abstract states the framework is fairness-agnostic. Definition 2.2 defines closest fair clustering. The corpus indicates diverse fairness definitions.
- **Break condition:** If the chosen fairness constraint has no efficient constant-factor approximation for closest fair clustering, the framework cannot instantiate with a finite γ.

### Mechanism 3: Streaming Sublinear Space via Uniform Sampling
- **Claim:** Storing only O(n log m) clusterings (for 1-median) or O(k² n polylog(mn)) (for k-median) suffices to achieve a constant-factor approximation with high probability.
- **Mechanism:** The stream is processed by maintaining two small memory structures: M₁ stores all triples for a uniformly random sample of O(log m) input clusterings. M₂ stores another independent random sample of O(ε⁻² log m) clusterings for evaluation. Uniform sampling ensures statistical representation.
- **Core assumption:** Uniform random sampling preserves the structure needed to approximate the global median objective; specifically, the sampled evaluation set W is a (k, ε)-coreset.
- **Evidence anchors:** The abstract states the space bounds. Section 4 and 6 detail the sampling and coreset constructions.
- **Break condition:** If the stream order is adversarial in the generalized insertion-only model for k-median, or if the input distribution is skewed and the sample misses critical clusterings, the probabilistic guarantee may not hold.

## Architecture Onboarding
**Component map:**
Sampling Scheduler -> Stream Ingestion -> Reconstructor -> Candidate Generator -> ClusterFitting -> Evaluator -> (for k-median: k-Median Extender)

**Critical path:**
Pre-stream: set sampling indices. During stream: store sampled triples in M₁ and M₂. Post-stream: reconstruct sampled clusterings, generate candidates via oracles, evaluate using second sample, output best candidate. For k-median: add monotone faraway sampling, coreset construction, brute-force search over k-tuples.

**Design tradeoffs:**
- Space vs Confidence: Smaller samples reduce space but increase risk of missing key clusterings; compensated by high-probability bounds and multiple samples.
- Generality vs Optimality: Black-box oracles yield generic bounds that may be loose; tightening requires problem-specific improvements.
- Offline vs Streaming: Offline uses all inputs; streaming approximates via sampling, sacrificing some approximation for space.

**Failure signatures:**
- Sampling failure: Sampled sets contain no clusterings from good regions; detectable if all candidates yield similar objective values on evaluation set.
- Oracle failure: Subroutines return poor approximations; directly blows up final ratio.
- Memory overflow: Sample sizes underestimated; monitor actual sizes of M₁, M₂, etc.

**First 3 experiments:**
1. Vary sample sizes for M₁ and measure approximation vs. space to confirm logarithmic trade-off.
2. Implement closest fair clustering oracles for two specific fairness definitions (e.g., proportionate vs. statistical parity) and compare achieved ratios to generic bound.
3. Test scalability with large stream (m=1e6, n=1000, k=10) and adversarial stream where good clusterings are rare; verify failure probability.

## Open Questions the Paper Calls Out
- **Question 1:** Can we design a streaming algorithm for k-median fair consensus in the generalized insertion-only model (arbitrary order)? Basis: Authors state extension only works for insertion-only model. Why unresolved: Current k-median relies on contiguity property. Evidence needed: New algorithm with sublinear space and constant approximation in generalized model.
- **Question 2:** Can space complexity for k-median be improved to O(kn polylog(mn))? Basis: Authors mention improving space usage. Why unresolved: Current O(k²) dependence from sampling and candidate enumeration. Evidence needed: Algorithm with O(kn) space preserving constant approximation, or lower bound.
- **Question 3:** Can approximation ratios for specific fairness constraints be tightened below current streaming bounds? Basis: Authors state tightening guarantees as open direction. Why unresolved: Generic framework may be loose; tighter analysis or improved subroutines needed. Evidence needed: Better upper bound or matching lower bound.
- **Question 4:** Can the additive gap between fair consensus and closest fair clustering be reduced below 1.92 (offline) or 2 (streaming)? Basis: Inferred from generic bounds γ + 1.92. Why unresolved: Gap from triangle inequalities and worst-case analysis. Evidence needed: Algorithm with smaller additive gap or hardness proof.

## Limitations
- The framework depends on efficient γ-approximate closest fair clustering and η-approximate fair correlation clustering oracles; their existence is not guaranteed for all fairness definitions.
- It assumes a contiguity property (all triples for a clustering appear consecutively); real streams may violate this, causing reconstruction errors.
- Uniform sampling may miss rare optimal clusterings, especially with small samples, leading to probabilistic failures.
- The generic approximation ratios include large additive constants (~2) that may be pessimistic in practice.

## Confidence

- Approximation ratios: High (proven), but tightness: Low (constants may be pessimistic).
