# Validation of a Small Language Model for DSM-5 Substance Category Classification in Child Welfare Records
## Quick Facts
- **arXiv ID:** 2603.06836
- **Source URL:** https://arxiv.org/abs/2603.06836
- **Reference count:** 0
- **Primary result:** A locally hosted 20B-parameter LLM achieved near-perfect agreement (Cohen’s κ = 0.94–1.00) and high precision (92–100%) for five common DSM-5 substance categories, but performed poorly (precision 35–56%) on two low-prevalence categories (hallucinogen, inhalant) in child welfare narratives.

## Executive Summary
This study validates a two-stage classification pipeline using a small, open-source language model run locally to identify specific DSM-5 substance types from unstructured child welfare investigation narratives. Building on prior binary detection work, the model classifies records into seven substance categories with structured evidence extraction. Validation via expert review of 900 cases showed excellent reliability and precision for five common categories (alcohol, cannabis, opioid, stimulant, sedative/hypnotic/anxiolytic), but struggled with two rare, polysemous categories (hallucinogen, inhalant). The approach demonstrates that a resource-constrained, locally deployed model can achieve high-stakes administrative classification when lexical signals are unambiguous, with outputs stabilized via low-temperature sampling and made auditable through verbatim evidence extraction.

## Method Summary
The study implemented a two-stage pipeline on narratives from a Midwestern U.S. state child welfare database (2013–2024). Stage 1, a pre-validated binary classifier, filtered records for potential substance-related problems (SRP). Stage 2 used a 20-billion-parameter open-source model (4-bit quantized, run locally on dual A6000 GPUs, temperature=0.2, 8k context) with a fixed prompt to classify SRP-positive records into seven DSM-5 categories. The prompt required JSON outputs specifying a status ("Present"/"Absent") and verbatim text mentions per category. Validation used stratified random sampling: 700 substance-positive cases (100 per category), 100 SRP-absent, and 100 SRP-present/unclassified cases (N=900). Human expert reviewers assessed model outputs against source text, calculating per-category precision, Cohen’s κ, and PABAK. Test-retest reliability was measured across ~15,000 records in two independent runs.

## Key Results
- Five high-prevalence categories (alcohol, cannabis, opioid, stimulant, sedative/hypnotic/anxiolytic) achieved almost perfect inter-method agreement (Cohen’s κ = 0.94–1.00) and high precision (92–100%).
- Two low-prevalence categories (hallucinogen, inhalant) had poor performance (precision 35–56%) due to lexical ambiguity and contextual dependence.
- Test-retest agreement was high across all categories, ranging from 92.1% (stimulant) to 99.1% (alcohol, cannabis), indicating stable outputs under low-temperature sampling.

## Why This Works (Mechanism)
### Mechanism 1: Lexical Specificity Enables High-Precision Pattern Matching
The model reliably classifies substances when terminology is specific and unambiguous (e.g., "methamphetamine," "heroin," "Xanax"). It matches surface-level lexical patterns to category definitions, minimizing need for deep contextual reasoning. This breaks down for polysemous terms (e.g., "gas," "spray," "acid") common in non-substance contexts, causing misclassifications in rare categories.

### Mechanism 2: Verbatim Evidence Extraction Supports Transparent Validation
The prompt requires the model to extract verbatim text phrases supporting each classification. Human reviewers could verify decisions against source text, creating an audit trail. This isolates errors to either misclassification or faulty evidence extraction, with 90.5% of extracted phrases validated as correct and 92.8% confirmed verbatim.

### Mechanism 3: Low-Temperature Sampling Stabilizes Outputs
A temperature setting of 0.2 constrained the probabilistic decoding space, yielding highly reproducible classifications across runs. Test-retest agreement of 92.1–99.1% demonstrates that this setting effectively controls stochastic variation for this multi-label classification task, though it may limit contextual nuance for ambiguous cases. Assumption: This stability holds for the specific distribution of lexical clarity present in the high-prevalence categories; performance on more ambiguous or novel phrasing remains unknown.

## Foundational Learning
- **Concept: Multi-label text classification**
  - **Why needed here:** Each narrative may reference zero or more substance categories; the model must evaluate all seven labels independently per document.
  - **Quick check:** How would you modify a binary classification prompt to output multiple independent status fields in a structured format like JSON? For this study, the prompt instructs the model to output a JSON object with seven keys (one per substance), each containing its own "Present"/"Absent" status and list of verbatim mentions.

- **Concept: Lexical ambiguity in domain-specific text**
  - **Why needed here:** Terms like "inhalant" (nasal route vs. substance) or "acid" (cleaner vs. LSD) are polysemous; classification hinges on contextual disambiguation.
  - **Quick check:** Give two examples from child welfare records where a term common in non-substance contexts might lead to a false positive hallucinogen or inhalant classification. Example 1: "The home reeked of paint fumes and gasoline" might trigger a false positive for "inhalant" if the model ignores the non-substance context of "fumes." Example 2: " Used acid to clean the toilet" might trigger a false positive for "hallucinogen" if the model does not recognize "acid" as hydrochloric or other cleaning agents.

- **Concept: Validation metrics for imbalanced multi-class data**
  - **Why needed here:** Low-prevalence categories (hallucinogen, inhalant) can distort metrics; precision, recall, Cohen’s κ, and PABAK must be interpreted together to avoid prevalence bias.
  - **Quick check:** Why report both Cohen’s κ and PABAK? What does a large gap between them indicate about classification performance? Cohen’s κ accounts for chance agreement and is sensitive to prevalence; PABAK (prevalence-adjusted bias-adjusted kappa) corrects for extreme imbalance. A large gap (e.g., high κ, low PABAK) suggests performance is biased by the prevalence of the majority class, potentially masking poor performance on rare classes.

## Architecture Onboarding
Data Ingestion -> Stage 1 Filter (SRP binary classifier) -> Stage 2 Classifier (20B LLM with fixed prompt, JSON output with "status" and "mentions") -> Post-processing (parse JSON, store classifications). Validation Pipeline (stratified sampler, human review interface, metric calculation) runs parallel on subsets. Infrastructure: local GPU server (dual A6000), 4-bit quantized model, temperature=0.2, 8k context.

Critical path: Raw narrative -> Stage 1 (SRP present?) -> if YES -> Stage 2 prompt -> JSON output -> storage.

Design tradeoffs:
- Local vs. Cloud: Local ensures data confidentiality but limits model size/updates; cloud eases maintenance but risks PHI leakage.
- Two-stage vs. Single-stage: Two-stage reduces compute waste but propagates Stage 1 errors; a unified multi-label prompt might catch borderline cases but increases complexity.
- Evidence extraction: Required for transparency but increases output size/parsing complexity; omitting it risks auditability.

Failure signatures:
- Low precision in rare categories: Likely due to lexical ambiguity causing false positives/negatives.
- Low extraction precision (<90%): Model generating non-verbatim or irrelevant phrases (hallucination).
- Test-retest discordance >5%: Temperature too high, prompt unstable, or context truncation.
- JSON parse errors: Prompt deviation, token limit exceeded, or schema non-compliance.

First 3 experiments:
1. Prompt stress-test on edge cases: Curate 50 narratives with ambiguous terms (e.g., "paint fumes," "acid for cleaning," "prescribed Xanax") and evaluate classification consistency across 5 runs to identify terms causing systematic errors.
2. Extraction verification drill: For 100 model-positive cases, verify every "mentions" phrase is verbatim *and* necessary for the classification; quantify over-extraction and under-extraction.
3. Stage 1 error propagation analysis: Take 100 records where Stage 1 said SRP=absent but human review found substance mentions; re-run Stage 2 to estimate recall loss from Stage 1 false negatives and compare to a unified prompt approach.

## Open Questions the Paper Calls Out
1. What specific prompt engineering, exemplar selection, or rule-based filtering strategies can most effectively improve classification precision for low-prevalence substance categories like hallucinogens and inhalants? The paper’s proposed remedies are speculative and untested.
2. What are the per-substance recall rates (sensitivity) for each DSM-5 category, and how do they compare to the overall substance-related problem (SRP) recall? Recall was only assessed at the SRP level.
3. How does the inter-method reliability (κ) of the LLM classifier for specific substance types compare to the natural inter-rater reliability between human experts performing the same classification? Human-human agreement on this task was not measured.
4. To what extent do the validation results generalize to child welfare systems in other jurisdictions with different documentation styles, regional terminology, or population characteristics? External validity was not tested.
5. How does the probabilistic nature of LLM inference, exemplified by the temperature parameter, trade off against classification stability and accuracy? The relationship between temperature, accuracy, and stability was not systematically investigated.

## Limitations
- Model and raw data are inaccessible ("gpt-oss:20b" identity and state child welfare records are not publicly shareable), blocking exact replication.
- Poor performance on hallucinogen/inhalant categories is likely due to polysemous terms (e.g., "acid," "inhalant" as nasal route), but specific error patterns are unclear without full error analysis.
- Two-stage pipeline risks Stage 1 error propagation; recall for rare categories may be underestimated if Stage 1 misses borderline SRP cases.

## Confidence
- **Mechanism 1 (lexical specificity enables high precision):** High confidence. Strongly supported by category-level metrics (κ 0.94–1.00) and authors' explicit reasoning that unambiguous terms drive success.
- **Mechanism 2 (evidence extraction enables auditability):** High confidence. Directly validated via human review (90.5% valid extractions) and verbatim match rate (92.8%).
- **Mechanism 3 (temperature 0.2 ensures stable outputs):** Medium confidence. Test-retest agreement (92.1–99.1%) supports this for the tested dataset, but stability may not generalize to more ambiguous or fine-grained tasks where lexical signals are weaker. Unknown whether higher temperatures could improve recall for rare categories at the cost of precision/stability.

## Next Checks
1. **Prompt stress-test on ambiguous terms:** Curate 50 narratives with polysemous words (e.g., "paint fumes," "prescribed Xanax") and run 5 inference passes each. Flag terms causing inconsistent classifications to refine prompt disambiguation rules.
2. **Extraction verification drill:** For 100 model-positive cases, manually verify every extracted phrase is both verbatim *and* necessary for the classification. Quantify over-extraction (irrelevant phrases) and under-extraction (missing key phrases).
3. **Stage 1 error propagation analysis:** Take 100 records where Stage 1 reported SRP=absent but human review found substance mentions. Re-run Stage 2 on these to estimate recall loss from Stage 1 false negatives, and compare to a unified single-prompt approach.
