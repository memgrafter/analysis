# NRR-Phi: Text-to-State Mapping for Ambiguity Preservation in LLM Inference

## Quick Facts
- arXiv ID: 2601.19933
- Source URL: https://arxiv.org/abs/2601.19933
- Reference count: 37
- Primary result: Mean state entropy 1.087 bits on 68 ambiguous sentences, preserving interpretive multiplicity versus collapsed baselines (H=0).

## Executive Summary
Large language models often collapse ambiguous inputs into single interpretations early in inference, discarding valid alternatives. NRR-Phi introduces a text-to-state mapping framework (ϕ) that transforms ambiguous text into a state space explicitly preserving multiple interpretations. The pipeline uses rule-based conflict detection via linguistic markers, hybrid interpretation extraction (rule-based segmentation plus LLM enumeration), and state construction with weighted representations. Empirical evaluation on 68 ambiguous sentences across five categories shows the mapping achieves a mean state entropy of 1.087 bits, significantly higher than collapse-based baselines. Cross-lingual portability was demonstrated with Japanese markers, and downstream NRR operators adhering to design principles maintain this multiplicity without collapse.

## Method Summary
The ϕ mapping operates in three stages. First, a deterministic rule-based scanner (ψ_conflict) checks for predefined conflict markers (e.g., adversative conjunctions “but”, hedging expressions “maybe”) and sets a binary flag if any are found. Second, interpretation extraction combines a rule-based splitter (ψ_rule) that segments text at detected markers with an LLM-based enumerator (ψ_LLM) prompted to list all plausible meanings; duplicate interpretations are merged using cosine similarity over sentence embeddings (τ = 0.85). Third, each interpretation is embedded, context-encoded, and assigned a weight w_i = conf_i × (1 + β × 1[conflict]), forming a set-based state S of weighted vectors. The state entropy H(S) measures preserved multiplicity. Downstream NRR operators (δ, κ, π) process this state while adhering to principles like scale equivariance and relative preservation to avoid collapse.

## Key Results
- Mean state entropy of 1.087 bits across 68 ambiguous sentences, while collapse baselines yield H=0.
- 0% collapse for NRR operators adhering to design principles, versus up to 17.8% collapse for violating operators.
- Cross-lingual portability confirmed: Japanese conflict markers successfully trigger the pipeline.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Linguistic markers (explicit adversatives, hedges) reliably signal that an input text contains multiple coexisting interpretations.
- **Mechanism:** A deterministic rule-based scanner (`ψ_conflict`) matches tokens/phrases from a predefined taxonomy (e.g., "but", "however", "maybe", Japanese "kedo") against the input. Detection of any marker sets a binary flag `f` that triggers the multi-interpretation extraction pipeline.
- **Core assumption:** Surface-level lexical cues are valid, sufficient indicators for the presence of interpretive multiplicity for the targeted ambiguity categories (adversative, hedging).
- **Evidence anchors:**
  - [abstract] "combines rule-based segmentation for explicit conflict markers (adversative conjunctions, hedging expressions)"
  - [section 3.3] Formal definition of `ψ_conflict` and marker taxonomy `M_conf`.
  - [corpus] Weak. Neighbors discuss ambiguity handling broadly but do not specifically validate marker-based detection as a primary signal for *preservation*.
- **Break condition:** Markers are absent (false negative) for implicitly ambiguous sentences (epistemic, lexical, structural), or over-trigger on non-ambiguous text (false positive). The paper's own results (Table 2) show `H=0` for rule-based on epistemic/lexical/structural, confirming the break condition for those categories.

### Mechanism 2
- **Claim:** A hybrid extraction pipeline (`ψ_interp`) that merges rule-based segmentation (for explicit markers) with LLM-based enumeration (for implicit ambiguity) yields a comprehensive set of distinct interpretations.
- **Mechanism:** 1) Rule-based stage splits text at detected markers into segments, each tagged with a context label (e.g., "pre-adv", "hedge-scope"). 2) LLM stage is prompted to list all possible meanings for the full text. 3) A `Merge` function deduplicates near-identical interpretations using cosine similarity (τ=0.85) over sentence embeddings.
- **Core assumption:** LLMs can reliably enumerate *plausible* alternative interpretations for implicit ambiguity when prompted, and semantic similarity thresholds can effectively identify and remove redundancies across the two extraction streams without losing distinct meanings.
- **Evidence anchors:**
  - [section 3.4] Equations 5-8 define `ψ_rule`, `ψ_LLM`, and `Merge` with similarity threshold `τ`.
  - [section 5.5] Empirical results show LLM extraction successfully yields `|S|>1` and `H>0` for epistemic (mean `H=1.673`), lexical (`H=1.007`), and structural (`H=0.968`) categories where rule-based failed.
  - [appendix C] Sample outputs demonstrate distinct interpretations extracted (e.g., lexical "duck" as noun/verb).
- **Break condition:** LLM prompt fails to elicit all valid interpretations (incomplete enumeration), or `Merge` threshold `τ` is too high/low, causing over-merging (loss of distinct interpretations) or under-merging (retaining near-duplicates). The paper notes LLM variability (Claude vs. Gemini extraction counts) as an instability factor.

### Mechanism 3
- **Claim:** Assigning initial weights `w_i = conf_i * (1 + β * 1[conflict])` and storing interpretations as unnormalized vectors in a state set `S` preserves a manipulable superposition where relative weight ratios encode the probability-like distribution, enabling subsequent NRR operators to transform the state without forcing premature collapse.
- **Mechanism:** Each extracted interpretation `(interp_i, ctx_i, conf_i)` is embedded (`v_i`), context-encoded (`c_i`), and given an initial weight. The weight is boosted by factor `(1+β)` if the input had any conflict marker detected. The state `S` is the set of these tuples. Entropy `H(S)` is computed from normalized weights for evaluation, but internal weights remain unnormalized.
- **Core assumption:** This lightweight, heuristic weight assignment sufficiently reflects the relative plausibility of interpretations such that the state's entropy is a meaningful measure of preserved multiplicity, and that the unnormalized weight representation is compatible with downstream NRR operators (δ, κ, π) which are designed to preserve relative structure.
- **Evidence anchors:**
  - [section 3.5] Equations 10-13 define `ψ_state` construction, including the weight formula.
  - [section 5.6] Combined results show overall mean `H=1.087` across 68 sentences, compared to `H=0` for collapse baselines.
  - [appendix D] Design Principle 1 (Relative Structure Preservation) and empirical validation (Table 7, δv2) show subsequent operators can maintain/increase entropy from this initial state.
- **Break condition:** Weight assignment is arbitrary or poorly calibrated (e.g., `β` mis set), leading to extremely skewed initial distributions (`max(w_i) >> sum(others)`) where `H≈0` despite multiple interpretations. The paper acknowledges "weight calibration... is heuristic" as a limitation.

## Foundational Learning
- **Concept: Non-Collapsing State Representation**
  - *Why needed here:* The entire NRR framework replaces a single output vector with a set of interpretation tuples `{(v_i, c_i, w_i, m_i)}`. The engineer must understand that `w_i` are not normalized probabilities internally; entropy is a metric computed from normalized ratios, not a constraint on absolute values. This set-based, weighted superposition is the core data structure that enables deferred commitment.
  - *Quick check question:* If a state has interpretations with weights `[0.9, 0.05, 0.05]`, what is its entropy? (Answer: ~0.57 bits). If an operator multiplies all weights by 2, what happens to the entropy? (Answer: Nothing; normalized distribution is identical.)

- **Concept: Hybrid Extraction Tradeoff (Determinism vs. Coverage)**
  - *Why needed here:* The system's ability to find multiple interpretations hinges on choosing between a reproducible, narrow rule-based split and a stochastic, broad LLM enumeration. The engineer must grasp that this is a fundamental design tradeoff: rules guarantee the same segments for the same marker patterns but cannot find implicit ambiguity; LLMs cover more cases but introduce non-determinism and cost.
  - *Quick check question:* For the sentence "I think the bank is closed," which extraction method would handle the lexical ambiguity of "bank"? Why wouldn't the rule-based method work here? (Answer: LLM-based. Rule-based only looks for markers like "but" or "maybe"; "bank" polysemy is implicit.)

- **Concept: NRR Operator Principles (Especially Scale Equivariance & Relative Preservation)**
  - *Why needed here:* The initial state `S` from `ϕ` is useless if subsequent processing collapses it. The engineer must understand that operators like `δ` (dampening) must act on relative weights, not absolute values, to preserve entropy. Principle 2 (Scale Equivariance) is mathematically key: operations should be invariant to multiplying all `w_i` by a constant.
  - *Quick check question:* Why is an operator that does `w'_i = w_i - 0.1` (uniform subtraction) dangerous? Why is `w'_i = w_i * 0.9` (uniform scaling) safe? (Answer: Subtraction distorts relative ratios and can zero out small weights, causing collapse. Scaling preserves all ratios, leaving the normalized entropy unchanged.)

## Architecture Onboarding
**Component map:**  
Input Text -> ψ_conflict (rule scanner) -> f (marker flags).  
Input Text + f -> ψ_rule (segmenter) + ψ_LLM (prompted LLM) -> Raw interpretations I_rule, I_LLM.  
I_rule, I_LLM -> Merge (similarity deduplication) -> Consolidated interpretations I.  
I -> ψ_state (embedding, context encode, weight assign) -> Initial State S_new.  
S_new + previous S_prev -> NRR Pipeline (ρ? -> τ -> δ -> κ -> π) -> Processed State S' and Output o via Π.  
External dependencies: Tokenizer, Embedding model (e.g., Sentence-BERT), LLM API/Model for ψ_LLM, Conflict marker lexicon.

**Critical path:** Text -> ψ_conflict -> (if has_conflict) ψ_rule AND ψ_LLM -> Merge -> ψ_state -> NRR operators. The "AND" for rule and LLM extraction is critical; omitting either fails on certain ambiguity types (Table 2).

**Design tradeoffs:**
- **Determinism vs. Coverage:** Rule-based ψ_rule is fast/reproducible but limited to explicit markers. LLM-based ψ_LLM covers implicit cases but is slow, costly, and non-deterministic. The hybrid design accepts this cost for completeness.
- **Deduplication Aggressiveness:** Similarity threshold τ in Merge. Too high (τ→1) = over-deduplication (losing distinct interpretations). Too low (τ→0) = under-deduplication (clutter with paraphrases). Paper uses τ=0.85 based on common practice.
- **Weight Heuristic vs. Learned:** w_i = conf_i * (1+β) is a simple heuristic. A learned weight predictor could improve entropy fidelity but adds training complexity and breaks the "model-agnostic" claim of ϕ.

**Failure signatures:**
1. **Low/Zero State Entropy (H≈0):** After ϕ, |S|=1. Indicates either: ψ_conflict missed markers, ψ_LLM returned one interpretation, or Merge over-merged. Check category of input (epistemic? lexical?) and LLM prompt efficacy.
2. **Duplicate Interpretations in S:** High |S| but low H due to near-identical v_i. Indicates Merge threshold τ too low or embedding model not distinguishing.
3. **Collapse After NRR Operator:** H(S') << H(S) after a transition (e.g., δ with large λ). Violates Principle 1. Check operator parameterization (use validated δv2 not δv1).
4. **Cost/Latency Spike:** If ψ_LLM is invoked unnecessarily on simple adversative sentences. Optimize: only call LLM if ψ_rule yields |I_rule|==1 and f suggests potential deeper ambiguity? (Paper doesn't specify this optimization.)

**First 3 experiments:**
1. **Baseline Entropy Reproduction:** Run the 68-sentence test set through the ϕ pipeline (with a fixed LLM, e.g., Claude). Verify mean H≈1.087 and category-specific H as in Tables 3 & 4. This validates the core claim against the paper's baseline.
2. **Marker Coverage & False Negative Check:** Construct 20 sentences with clear adversative/hedging markers but simple literal meaning (e.g., "It's hot, but I like it."). Measure ψ_conflict detection rate vs. ψ_rule extraction quality (|I_rule| should be 2). This tests the break condition for the rule-based stage.
3. **Cross-LLM Consistency for Implicit Ambiguity:** For 10 epistemic/lexical/structural sentences, run ψ_LLM with 3 different LLMs (ChatGPT, Gemini, Claude). Measure variance in |S| and H. This quantifies the LLM-dependence limitation noted in section 5.4 & 7.3. High variance suggests the need for ensemble ψ_LLM or prompt tuning.

## Open Questions the Paper Calls Out
- **Question 1:** Under what conditions does preserving interpretive multiplicity via ϕ provide a net benefit (e.g., in downstream task accuracy, coherence, or user satisfaction) compared to early collapse, and what are the associated computational costs? The paper validates entropy preservation but does not measure impact on task performance or quantify inference overhead beyond basic complexity notes.
- **Question 2:** How can confidence weights for interpretations be calibrated more reliably than the current heuristic (w = conf × (1+β·1[conflict])) to better reflect true plausibility and improve entropy properties? The paper acknowledges this heuristic as a limitation and suggests learned calibration could help.
- **Question 3:** To what extent can the conflict detection marker taxonomy (ψ_conflict) be generalized to languages beyond English and Japanese, and what are the minimal marker sets required for effective ambiguity detection in typologically diverse languages? The paper demonstrates portability for a few Japanese markers but does not systematically evaluate other languages.
- **Question 4:** Can the ϕ mapping be natively integrated into LLM architectures (e.g., modifying attention or representation layers) rather than as a preprocessing/postprocessing step, and does such integration improve efficiency or stability of non-collapsing inference? The paper lists this as future work; current implementation treats ϕ as an external pipeline.

## Limitations
- Unavailable reproduction details: exact 68-sentence test set, β weight parameter, embedding model choice, and LLM inference settings (temperature, version) are not specified, blocking exact replication.
- Scalability & cost: LLM-based ψ_LLM invocation per input is computationally expensive and non-deterministic, undermining practical deployment.
- Generalization scope: Framework is validated only on 5 specific ambiguity categories (adversative, hedging, epistemic, lexical, structural); performance on other ambiguity types (e.g., pragmatic, syntactic) is unknown.
- Weight heuristic fragility: entropy fidelity relies on an uncalibrated heuristic; poor β choice could yield skewed distributions (H≈0) despite multiple interpretations.

## Confidence
- Mechanism 1 (marker detection): Medium – Rule-based detection is well-specified for explicit markers, but corpus support is weak and false negatives for implicit ambiguity are acknowledged.
- Mechanism 2 (hybrid extraction): Medium-High – Empirical results show LLM extraction succeeds where rules fail, but LLM variability limits reliability.
- Mechanism 3 (state weighting): Medium – Entropy gains are demonstrated, but the weight heuristic is admitted as a limitation; no ablation on β is provided.
- Foundational Learning & Architecture: High – Component interactions and design principles are rigorously defined in the text.
