# A Lightweight Multi-View Approach to Short-Term Load Forecasting
## Quick Facts
*   **arXiv ID:** 2602.09220
*   **Source URL:** https://arxiv.org/abs/2602.09220
*   **Reference count:** 22
*   **Primary result:** A 30k-parameter model using single-value SVD embeddings and a scaled lag set achieves 1.27%–5.56% MAPE, significantly outperforming state-of-the-art transformers (4.35%–13.10%) on four load forecasting datasets.

## Executive Summary
This paper tackles short-term load forecasting, where complex transformer models often overfit on temporal data. It proposes a lightweight multi-view approach that drastically reduces parameters by using a scaled time-range input with a small, curated set of key lags (e.g., previous day, week) and single-value embeddings via singular value decomposition (SVD). An embedding dropout mechanism applied to exogenous features prevents over-reliance on any single view, enhancing robustness on noisy and holiday periods. Evaluated on four datasets, the SVD variant (~30k parameters) achieves substantially lower MAPE than baselines like TFT and TiDE, demonstrating that extreme parameter efficiency can coexist with state-of-the-art accuracy in this domain.

## Method Summary
The method constructs an input matrix from a fixed set of strategically selected historical lags (e.g., `t-1y, t-1w, t-1d`) for the target series and all exogenous features (temperature, dew point, etc.). Each feature value at each lag is projected to a low-dimensional embedding. The core innovation is the "single-value" SVD variant, where the embedding dimension `d=1`, forcing an extreme compression: each feature's value is scaled by a learned weight and shifted by a bias (`z = w_f * x_f + b_f`). These embeddings are aggregated (summed or concatenated) across features for each lag, forming a sequence fed to a transformer. Crucially, during training, a dropout mask randomly zeros out the embeddings of all exogenous features with probability `p=0.2`, forcing the model to distribute reliance and enabling post-hoc feature isolation for interpretability. A transformer encoder processes the embedded sequence, and a two-layer decoder generates the final forecast.

## Key Results
*   **SVD variant dominance:** The `d=1` embedding model (~30k parameters) drastically outperforms state-of-the-art baselines (TFT, TiDE, N-BEATS, SARIMAX) on all four datasets for 1-day and 2-day horizons.
*   **Robustness on challenging periods:** Performance degradation on holidays and under artificially induced noise is smaller for the proposed model compared to baselines, attributed to the embedding dropout mechanism.
*   **Parameter efficiency:** The model achieves superior accuracy with orders of magnitude fewer parameters than typical transformer-based forecasters, addressing the overfitting problem.

## Why This Works (Mechanism)
### Mechanism 1
*   **Claim:** A scaled time-range input with strategically selected lags (e.g., previous day, week) reduces computational parameters while preserving predictive power by focusing on temporally relevant information.
*   **Mechanism:** Instead of using a full, equally-spaced historical sequence, the input is constructed from a small, fixed set of specific lagged values (e.g., `t-1y, t-1w, t-1d, t-12h, ...`). This drastically reduces the sequence length fed into the transformer (`|L|`), maintaining efficient `O(L^2)` attention while targeting known seasonal and short-term patterns.
*   **Core assumption:** Older or less relevant historical points contribute noise or redundancy, and key periodicities (daily, weekly, yearly) can be captured by a small, curated set of reference points.
*   **Evidence anchors:** Paper defines the lag set in Eq. 5-6 and states it "reduces considerably the number of parameters by inputting the model only ten data points for each time series."
*   **Break condition:** If the true underlying dependencies require a different or more granular set of lags than the predefined `L` (e.g., a non-standard seasonality), performance would degrade as critical information is omitted.

### Mechanism 2
*   **Claim:** Single-value embeddings via SVD (dimensionality `d=1`) achieve extreme parameter efficiency (`~30k`) while maintaining accuracy by compressing feature representations to their most salient singular dimension, reducing redundancy.
*   **Mechanism:** Each feature's lagged value is projected to a `d=1` embedding (`z_f = W_f x_f + b_f`). This is a linear projection to a scalar, implicitly enforcing that the essential information for forecasting a feature at a specific lag can be distilled without significant loss, minimizing the embedding parameter count (`F * d`).
*   **Core assumption:** Inter-feature interactions and non-linearities are adequately captured by subsequent transformer layers, making high-dimensional per-lag feature embeddings unnecessary.
*   **Evidence anchors:** Paper calls it "Single-Value Decomposition: a special case of the concatenative method, where `d=1`" and highlights the 30k parameter count.
*   **Break condition:** If the relationship between a feature's value and the target is highly non-linear or context-dependent in a way that cannot be captured by a linear projection to `d=1`, the model's capacity would be insufficient, leading to underfitting.

### Mechanism 3
*   **Claim:** Embedding dropout (stochastic dropping of exogenous feature embeddings) prevents over-reliance on specific covariates, improving robustness to noisy/sparse data and enabling interpretability via feature isolation.
*   **Mechanism:** During training, each exogenous feature's embedding `z_f` is multiplied by a Bernoulli mask `r_f ~ Bernoulli(p)`. This forces the model to distribute learned dependencies across multiple features and prevents any single exogenous view from dominating. At inference, ablating all but one feature isolates its contribution.
*   **Core assumption:** The model has a tendency to latch onto a few strong exogenous signals (e.g., temperature), which harms generalization when those signals are noisy, missing, or distributionally shifted (e.g., holidays).
*   **Evidence anchors:** Paper states the mechanism "prevents over-reliance on specific features and enhances interpretability." Section 7 and Figure 1 demonstrate feature isolation. Section 8 discusses robustness results.
*   **Break condition:** If the true forecasting problem is primarily driven by a single, highly reliable exogenous feature, dropout would unnecessarily disrupt a strong signal, potentially harming baseline performance on clean data.

## Foundational Learning
*   **Concept: Time Series Seasonality and Periodicity**
    *   **Why needed here:** The scaled time-range design (`t-1y, t-1w, t-1d`) is built on capturing dominant seasonal cycles. Understanding these patterns is prerequisite to evaluating whether the chosen lags are sufficient.
    *   **Quick check:** Given an hourly load series, what are the top 3 periodicities you would expect, and how would you verify them from a plot or autocorrelation function?
*   **Concept: Singular Value Decomposition (SVD) for Dimensionality Reduction**
    *   **Why needed here:** The "single-value" embedding method conceptualizes each feature-lag pair as being compressed to its primary direction of variance (first singular vector/value). This is the core mechanism for parameter reduction.
    *   **Quick check:** If you applied SVD to a matrix of historical load values (`timesteps x features`), what would the magnitude of the first singular value tell you about the data's structure?
*   **Concept: Embedding Dropout as Feature-Level Regularization**
    *   **Why needed here:** This is a non-standard dropout applied to the embedding vectors of exogenous features, not to neuron activations. It's key for the paper's robustness and interpretability claims.
    *   **Quick check:** How does dropout on an embedding vector (e.g., `[0.2, -0.5, 1.1]`) differ in effect from dropout applied later in a fully-connected layer, in terms of what information is removed?

## Architecture Onboarding
*   **Component map:** Input Preparation -> Feature Projection (with SVD/dropout) -> Embedding Aggregation -> Transformer Encoder -> Transformer Decoder (2-layer loop) -> Output Projection
*   **Critical path:** Specific Lag Extraction -> Scalar Feature Embedding -> Sequence Formation -> Encoder Contextualization -> Autoregressive Decoding -> Linear Forecast.
*   **Design tradeoffs:**
    *   **Lag Selection (`L`):** Predefined, static set (simple, efficient) vs. learned or adaptive selection (more flexible, complex).
    *   **Embedding Dim (`d`):** `d=1` (SVD variant, minimal params) vs. `d>1` (additive/concatenative, more capacity). Trade-off is between parameter efficiency and model expressiveness.
    *   **Aggregation:** Additive (`sum`) vs. Concatenative (`concat`). Affects parameter count and how feature interactions are initially modeled.
*   **Failure signatures:**
    *   Spiking MAPE on holidays/noisy sets: Indicates insufficient robustness from embedding dropout or that key signals are not captured by the chosen lags.
    *   REM dataset's high error (5.56% vs. others ~1-2%): Suggests model lacks sufficient data to populate the embedding space; a data scarcity failure mode.
    *   Concatenative method underperforming SVD on CND: May indicate higher-dimensional concatenation introduces noise or overfitting when exogenous features are less informative.
*   **First 3 experiments:**
    1.  **Lag Sufficiency Ablation:** Replace the curated lag set `L` with a full recent seasonal sequence (e.g., last 168 hours). Measure MAPE change and parameter count increase.
    2.  **SVD Dimension Sensitivity:** Train the model with embedding dimensions `d = [1, 2, 4, 8]` on the smallest dataset (REM). Expect `d=1` to match or outperform higher `d`.
    3.  **Dropout Robustness Isolation:** Train the model with embedding dropout disabled (`p=0`). Evaluate MAPE on artificially corrupted (noisy) test sets and holiday periods. Expect a substantial performance drop.

## Open Questions the Paper Calls Out
*   **Open Question 1:** How can the embedding dropout mechanism be extended into a dynamic, data-driven weighting system that adapts the contribution of each feature view during inference?
    *   **Basis in paper:** The authors state in Section 8: "In future work, we plan to explore a dynamic weighting of the embedding."
    *   **Why unresolved:** The current dropout is a stochastic regularizer applied during training, not a learned, context-dependent weighting at inference time. A dynamic system could better handle fluctuating feature relevance.
    *   **What evidence would resolve it:** Development and evaluation of a learned attention or gating mechanism over embeddings, with ablation studies showing improved robustness on noisy/holiday datasets.
*   **Open Question 2:** To what extent can the proposed single-value embedding and scaled time-range input architecture generalize to time series domains with weak or irregular periodicity, such as financial tick data or event logs?
    *   **Basis in paper:** The authors conclude in Section 9 that extending to other domains "may require further adjustments... therefore the model would likely benefit from a policy specifically tailored to handle variable seasonality."
    *   **Why unresolved:** The method's design heavily leverages the strong daily/weekly/annual cycles of electricity load. Its core component—a predefined set of lags—may be ineffective for data lacking such fixed, dominant seasonalities.
    *   **What evidence would resolve it:** Systematic experimentation on diverse, non-calendar-driven benchmarks comparing the fixed scaled time-range input against learned lag selection strategies.
*   **Open Question 3:** How does the performance of the lightweight model degrade when exogenous forecasts (e.g., weather) are used instead of true values, and can the model's embedding dropout mechanism provide intrinsic robustness to such exogenous forecast errors?
    *   **Motivation in paper:** The authors acknowledge in Section 8 that they "assumed that exogenous variables were perfectly accurate. In practice, this assumption is unrealistic... the experiments conducted on noisy data indicate that this limitation does not significantly impair performance." The "noisy" test, however, involved corrupting training data, not using sequential forecasts of exogenous variables at test time.
    *   **Why unresolved:** The noise experiment added static corruption but did not simulate the sequential error propagation that occurs when forecasting future weather or calendar states. Robustness to *temporal* errors in exogenous inputs remains open.
    *   **What evidence would resolve it:** A controlled experiment where future exogenous variables are replaced with their own forecasts (from simple or imperfect models). Performance would be compared to the perfect-exogenous baseline, measuring dropout's impact on this degradation.
*   **Open Question 4:** Can pretraining the model's embedding space on a large, general load dataset improve performance and convergence on small, dataset-specific regimes like the single-year REM dataset?
    *   **Motivation in paper:** The authors note in Section 8 that "Scores on the REM dataset are significantly higher... could potentially be addressed by pretraining the model on an alternative dataset."
    *   **Why unresolved:** This is a suggested remedy for data scarcity but not tested. The REM dataset's higher error suggests the embedding space for temporal lags may be poorly estimated.
    *   **What evidence would resolve it:** An experimental protocol where the model is first trained on a large public load dataset, then fine-tuned on REM. Performance would be compared against training from scratch.

## Limitations
*   **Architectural ambiguity:** Critical details of the transformer (decoder structure, output aggregation) are underspecified, risking implementation drift.
*   **Feature definition gap:** The "school period" indicator is undefined, potentially affecting results on private datasets.
*   **Generalizability constraint:** Validation is limited to two public datasets (IESO, CND); performance on private HQ/REM cannot be independently verified.

## Confidence
*   **Scaled Lag Selection (Mechanism 1):** Medium. Evidence is paper-internal; neighbors use different multi-resolution strategies.
*   **Single-Value SVD Embeddings (Mechanism 2):** Low. Highly novel parameterization with no external validation; break condition (non-linear relationships) is a significant risk.
*   **Embedding Dropout for Robustness (Mechanism 3):** Medium. Paper provides ablation evidence, but the break condition (single-reliable-feature scenarios) remains untested.
