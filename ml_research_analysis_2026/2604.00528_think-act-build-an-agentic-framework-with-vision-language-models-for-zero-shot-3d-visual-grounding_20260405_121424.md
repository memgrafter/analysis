# Think, Act, Build: An Agentic Framework with Vision Language Models for Zero-Shot 3D Visual Grounding

## Quick Facts
- **arXiv ID**: 2604.00528
- **Source URL**: https://arxiv.org/abs/2604.00528
- **Reference count**: 40
- **Primary result**: TAB achieves state-of-the-art zero-shot 3D visual grounding on ScanRefer (71.2% Acc@0.25) and Nr3D (68.0% overall) using only open-source models, surpassing prior zero-shot methods and some fully-supervised baselines.

## Executive Summary
The paper introduces Think, Act, Build (TAB), a novel agentic framework for zero-shot 3D visual grounding that operates directly on raw RGB-D video streams. TAB decouples semantic reasoning (handled by a Vision-Language Model) from geometric reconstruction (handled by deterministic multi-view geometry). A key innovation, Semantic‑Anchored Geometric Expansion, overcomes multi‑view coverage deficits by projecting a centroid derived from a VLM‑tracked clip across unobserved frames. The agentic loop with fallback strategies ensures robustness against intermediate failures. On ScanRefer and Nr3D benchmarks, TAB sets a new zero‑shot state‑of‑the‑art.

## Method Summary
TAB processes an RGB‑D video sequence and a natural language query without any 3D‑specific training. First, a VLM (Qwen3‑VL) parses the query and filters frames via coarse (object detection) and fine (scene semantics) stages to select a reference view with a precise target mask. The agent then performs Semantic Temporal Expansion: it uses the VLM to verify and track a short clip around the reference, accumulating masks. From this clip, a 3D centroid is back‑projected using camera intrinsics/extrinsics and depth. Next, Multi‑View Geometric Expansion projects this centroid into every other frame, checks field‑of‑view and occlusion, and prompts SAM to extract masks. The aggregated point cloud yields the final 3D bounding box. An agentic controller monitors each step and applies dynamic adjustments (e.g., lowering thresholds) to handle failures.

## Key Results
- **ScanRefer**: 71.2% Acc@0.25, exceeding prior zero‑shot methods and some fully‑supervised approaches.
- **Nr3D**: 68.0% overall accuracy, setting a new zero‑shot benchmark.
- **Ablation**: Both Semantic Temporal Expansion and Multi‑View Geometric Expansion are necessary; removing either degrades performance significantly.

## Why This Works (Mechanism)

### Mechanism 1: Decoupled Reasoning and Reconstruction
- **Claim**: TAB achieves SOTA by decoupling semantic reasoning (VLM) from geometric reconstruction (deterministic multi‑view geometry), avoiding dependence on static 3D point clouds.
- **Mechanism**: The VLM agent analyzes the query, filters frames, selects a reference view with a target mask, and collects a short VLM‑verified clip (Semantic Temporal Expansion). The geometric module then back‑projects masked pixels into 3D using calibrated camera parameters and depth, and finally computes a bounding box. This separation exploits VLM strengths in high‑level semantics and trusts geometry for precise localization.
- **Core assumption**: The VLM correctly identifies the target object in 2D; the RGB‑D stream and camera parameters are accurately calibrated.
- **Break condition**: VLM misidentification or corrupted depth leads to an irrecoverable error; no fallback exists for completely wrong target selection.

### Mechanism 2: Semantic‑Anchored Geometric Expansion
- **Claim**: This mechanism overcomes multi‑view coverage deficits by anchoring a 3D centroid from a short VLM‑tracked clip and projecting it across all frames.
- **Mechanism**: Semantic Temporal Expansion (STE) yields a continuous clip `V_sem` with verified masks. A centroid `P_centroid` is computed from the back‑projected points of `V_sem`. Multi‑View Geometric Expansion (MGE) projects `P_centroid` into every other frame using camera extrinsics/intrinsics, checks field‑of‑view and depth‑based occlusion, and uses the projected 2D point as a prompt to SAM for mask extraction. This ensures coverage even when the VLM fails on extreme views.
- **Core assumption**: The centroid from the short clip is stable and representative; camera calibration and depth are accurate enough for reliable projection.
- **Break condition**: Biased centroid (e.g., due to depth noise or self‑occlusion) or inaccurate camera parameters cause misaligned prompts, yielding irrelevant or no masks.

### Mechanism 3: Agentic Loop with Fallbacks
- **Claim**: The Think‑Act‑Build agentic loop with expert skill blueprint and dynamic fallbacks provides robustness absent in static pipelines.
- **Mechanism**: The agent interprets the expert skill, iteratively reasons (Think) and invokes tools (Act). After each tool call, it observes the result. If a step fails (e.g., zero candidate images, invalid point cloud), predefined fallbacks trigger: thresholds may be relaxed, non‑critical steps skipped, or the state reverted to the last successful parameter (Threshold Consistency). This self‑correction allows completion of tasks that would otherwise abort.
- **Core assumption**: Most failures stem from overly conservative parameters rather than insurmountable data issues; lowering thresholds can recover the correct trajectory.
- **Break condition**: Failures due to corrupted or missing sensory data (e.g., no depth, complete occlusion) cannot be recovered by parameter adjustments.

## Architecture Onboarding
- **Component map**: Expert Skill -> VLM Agent -> Tool Library (Grounding DINO, SAM3, geometric utils) -> Input Handler (RGB‑D, poses) -> Intermediate Buffers (image registry, V_sem, V_geo) -> Output Module (bbox). Agent maintains context memory and fallback state manager.
- **Critical path**: Parse query → Coarse Filter (object detection) → Fine Filter (scene semantics) → Score/rank → Select reference view (segmentation + marker) → Reference target isolation → Semantic Temporal Expansion (VLM verify + segmentation) → Candidate segmentation → Initial reconstruct → Geometric Multi‑View Expansion (centroid projection + visibility check) → Final reconstruct → Bbox calculation. Fallbacks may adjust thresholds or skip steps.
- **Design tradeoffs**:
  - Threshold tuning: Higher thresholds reduce false positives but risk missing targets; dynamic adjustment lowers threshold if needed.
  - Model choice: Open‑source models ensure reproducibility but may lag behind proprietary ones.
  - Coverage vs. precision: STE is strict to maintain identity (short clip), MGE projects to all frames but may include false positives if occlusion check fails.
  - Depth reliance: Accurate depth is assumed; consumer‑grade noise could corrupt centroid and projection.
  - Agent complexity: Dynamic loop adds overhead but improves robustness in noisy streams.
- **Failure signatures**:
  - Zero images after Coarse Filter → detection threshold too high or detector issue.
  - Zero images after Fine Filter → scene constraints too strict; fallback skips fine filter.
  - Temporal expansion terminates early (few frames) → VLM verification fails (occlusion, ambiguity).
  - Centroid extraction yields NaN or outlier → depth corruption or segmentation failure.
  - MGE returns fewer frames than expected → projection inaccuracy; check cameras and depth.
  - Final point cloud too sparse → insufficient view coverage; increase expansion limit.
  - Agent repeatedly retries → ambiguous query or corrupted data; abort.
- **First 3 experiments**:
  1. Ablate STE and MGE separately to confirm synergy (Table 3).
  2. Vary detection threshold (0.3, 0.5, 0.7) to study recall‑precision tradeoff and dynamic adjustment efficacy.
  3. Force a high threshold (0.9) to trigger dynamic adjustment and verify automatic lowering to 0.3 and successful completion.

## Open Questions the Paper Calls Out
- **Depth robustness**: How does TAB perform with noisy or missing depth, given its reliance on accurate depth for back‑projection and Z‑buffer checks?
- **Calibration sensitivity**: Can TAB tolerate inaccuracies in camera intrinsics/extrinsics, which are common in SLAM‑derived poses?
- **Long‑term occlusions**: How does the pipeline handle objects that are occluded for many frames or reappear after a long gap, given the 32‑frame expansion cap?
- **Benchmark ambiguity**: Even after manual refinement, ScanRefer/Nr3D queries may retain multiple valid interpretations—what is the inter‑annotator agreement on the refined set?

## Limitations
- Propagation of depth or calibration errors corrupts centroid projection and final bounding box.
- VLM misidentification in highly cluttered scenes remains a risk despite fallbacks.
- Dynamic adjustment heuristics may fail on systematic data issues or missing modalities.
- Evaluation is confined to ScanNet; cross‑dataset generalization is unproven.
- Hyperparameters (frame limits, occlusion thresholds) likely require per‑dataset tuning.

## Confidence
- **Decoupling architecture**: High — SOTA results directly validate the split.
- **Semantic‑Anchored Expansion**: High — Ablations show large drops when STE or MGE disabled.
- **Agentic robustness**: Medium — Fallbacks are described and illustrated, but isolated contribution not measured; overall gains may be confounded.
