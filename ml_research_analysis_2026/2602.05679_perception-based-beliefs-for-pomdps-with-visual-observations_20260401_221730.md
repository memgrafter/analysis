# Perception-Based Beliefs for POMDPs with Visual Observations

## Quick Facts
- **arXiv ID**: 2602.05679
- **Source URL**: https://arxiv.org/abs/2602.05679
- **Reference count**: 40
- **Primary result**: PBP-HSVI achieves higher cumulative discounted rewards than DQN and PSRL baselines, approaching oracle performance across multiple vision-based POMDP benchmarks, and shows robustness to visual corruption.

## Executive Summary
The paper addresses the intractability of traditional belief-based solvers for partially observable Markov decision processes (POMDPs) with high-dimensional visual observations. It introduces Perception-Based Beliefs (PBP), a framework that uses an image classifier to map visual observations directly to state distributions, enabling belief updates without enumerating the vast observation space. To handle classifier errors, PBP incorporates uncertainty quantification methods (threshold-based or weighted) that adjust belief updates. When integrated with solvers like HSVI or POMCP, PBP scales to large vision tasks, demonstrating superior performance and robustness compared to deep reinforcement learning baselines.

## Method Summary
PBP solves Vision POMDPs (VPOMDPs) by factorizing the observation model, assuming visual observations depend only on a state's visual component (Assumption 1). A perception model (trained image classifier) approximates the posterior Pr(s_v|z_v). During belief updates, Bayes' rule rewrites the observation likelihood O_v(z_v|s_v) using this posterior, a uniform prior, and the marginal Pr(z_v). This avoids explicit enumeration of visual observations. The resulting belief update combines this visual factor with the non-visual observation likelihood. To mitigate perception errors, uncertainty quantification (TUQ or WUQ) modulates the influence of the perception output based on an uncertainty score (e.g., entropy). The approach is modular: any belief-based POMDP solver can be adapted by replacing its standard belief update with PBP's factorized version and using a planning model derived from a dataset for sampling visual observations.

## Key Results
- PBP-HSVI significantly outperforms DQN and PSRL on benchmarks (e.g., FlowerGrid: PBP-HSVI 52.3 vs DQN 34.5, Oracle 57.8).
- PBP demonstrates slower performance degradation under visual corruption (e.g., salt-and-pepper noise) compared to baselines.
- Weighted Uncertainty Quantification (WUQ) improves robustness across environments without per-environment tuning.
- Computation time is dominated by the underlying solver (HSVI runs ~400–500 seconds), with perception overhead being negligible.

## Why This Works (Mechanism)
### Mechanism 1: Factorized Belief Update
- **Claim**: Replaces intractable O(z|s) with a perception model f(s_v|z_v) that maps high-dimensional images to state distributions, enabling belief updates without enumerating observation space.
- **Mechanism**: Uses Bayes' rule: O_v(z_v|s_v) ≈ f(s_v|z_v)·Pr(z_v)/Pr(s_v). With uniform prior Pr(s_v), update simplifies to Eq. 4 (pure vision) or Eq. 5 (mixed), factoring out the visual component. Planner then operates on small-state belief.
- **Core assumption**: Vision-factorizability (Assumption 1) — visual observations depend only on vision state components s_v.
- **Evidence anchors**: Abstract states mapping to state distributions; Section 4.1 derives Eq. 5 and Theorem 1 proves exact recovery with perfect f; neighbors like ESCORT also target efficiency but PBP uniquely decouples perception.
- **Break condition**: If Assumption 1 fails, perception model becomes biased, leading to incorrect beliefs; no optimality guarantee.

### Mechanism 2: Uncertainty Quantification for Robustness
- **Claim**: UQ increases robustness by adjusting belief updates when perception model is unreliable.
- **Mechanism**: Two methods: (i) Threshold-based UQ (TUQ, Eq. 6) discards predictions above uncertainty threshold ε; (ii) Weighted UQ (WUQ, Eq. 7) interpolates between perception output and uniform prior based on uncertainty score u_f(z_v). Both avoid overconfident wrong predictions.
- **Core assumption**: Uncertainty function u_f(z_v) correlates with prediction error; e.g., high entropy indicates higher misclassification risk.
- **Evidence anchors**: Abstract mentions handling classifier imprecision; Section 4.2 defines TUQ/WUQ and fallback to uniform belief; neighbors incorporate uncertainty but PBP integrates directly into belief pooling.
- **Break condition**: If u_f is uncalibrated (overconfident on corrupted images), UQ fails to detect errors, injecting wrong beliefs; WUQ's smoothness helps but not perfectly.

### Mechanism 3: Modular Solver Integration
- **Claim**: PBP is a modular framework that plugs into any belief-based POMDP solver, transferring scalability gains.
- **Mechanism**: Solver operates on planning model M̂ using approximation Ō_v from D_plan for observation sampling, but belief update uses perception model (with UQ) on real observations during planning/acting. For point-based solvers, replace O in backup and sampling; for particle filters, modify weight update or POMCP's rejection sampling.
- **Core assumption**: Underlying solver's convergence preserved if belief updates remain consistent (Theorem 1 approx).
- **Evidence anchors**: Abstract states solver doesn't need to reason over high-D observations; Section 4.3 overview, Algorithm 1 for POMCP, C.1 for HSVI; neighbors hybridize but PBP retains classic solver interfaces.
- **Break condition**: If perception error structure is adversarial or solver highly sensitive to belief inaccuracies, performance degrades; POMCP scalability bottleneck remains.

## Architecture Onboarding
- **Component map**: Perception Model (DNN classifier f(s_v|z_v) + uncertainty u_f(z_v)) -> Belief Updater (implements Eq. 5/6/7) -> POMDP Planner (HSVI/POMCP modified); datasets D_perc, D_plan, D_act feed into components.
- **Critical path**: Offline: Train f on D_perc, calibrate with temperature scaling. Planning: Planner queries belief update for (b_t, a, z_v, z_¬v); updater uses f and u_f to compute b_{t+1} via Eq. 5/6/7; planner uses b_{t+1} for backup/sampling. Acting: Execute action a from policy(b_t); get observation z; compute b_{t+1} same way.
- **Design tradeoffs**: TUQ simple but needs threshold tuning; WUQ parameter-free but may over-discount useful signal. HSVI stronger guarantees but slower; POMCP scales worse due to particle inefficiency. Higher perception accuracy generally better, but robust UQ mitigates moderate corruption.
- **Failure signatures**: Belief collapse: support(f(s_v|z_v)) ∩ support(Pr(s'|b_t,a)) empty -> uniform fallback (log frequency). Overconfident classifier: high accuracy but low uncertainty on corrupted images -> TUQ/WUQ ineffective. Planner stagnation: b_t becomes uniform too often -> value estimates degenerate.
- **First 3 experiments**: (1) Belief soundness test: With perfect f, verify PBP's b_{t+1} matches standard Eq. 1 on small VPOMDP. (2) Baseline comparison: Run PBP-HSVI vs DQN/PSRL/Oracle on clean benchmarks; expect PBP-HSVI near Oracle. (3) Robustness sweep: Add increasing noise to D_act; plot value vs noise probability; expect PBP with WUQ to degrade slower than baselines.

## Open Questions the Paper Calls Out
1. **Assumption 1 violation impact**: How does PBP perform when visual observations depend on non-vision state components? No empirical evaluation provided.
2. **Fallback belief improvement**: Can the uniform fallback when perception and transition supports don't overlap be improved to preserve performance under severe perception errors?
3. **Scaling particle methods**: What optimizations are needed for tPBP-POMCP to scale to larger problems and match HSVI performance? Current poor performance attributed to implementation inefficiency.
4. **Automatic UQ selection**: How to automatically choose best UQ method (threshold, weighting, uncertainty metric) for a given VPOMDP without manual tuning? Optimal method varies across environments.

## Limitations
- **Vision-factorizability assumption**: PBP requires visual observations to depend only on state's visual component; violations bias beliefs and break optimality guarantees.
- **UQ calibration sensitivity**: Uncertainty measures must correlate with classifier error; overconfidence on corrupted images limits robustness.
- **Reproducibility gaps**: Missing precise dataset splits and HSVI hyperparameters hampers exact replication.

## Confidence
- **Scalability via factorized update (Mechanism 1)**: High — Theorem 1 proves correctness with perfect perception; experiments show visual bottleneck eliminated.
- **Robustness through UQ (Mechanism 2)**: Medium — WUQ degrades more smoothly than TUQ but requires tuning and fails under overconfidence.
- **Modular solver integration (Mechanism 3)**: High — Detailed modifications provided; no integration failures reported.
- **Empirical superiority**: High — PBP-HSVI consistently outperforms baselines and approaches oracle across benchmarks.
