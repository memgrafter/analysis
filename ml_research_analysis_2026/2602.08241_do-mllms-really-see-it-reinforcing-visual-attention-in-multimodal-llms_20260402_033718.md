# Do MLLMs Really See It: Reinforcing Visual Attention in Multimodal LLMs

## Quick Facts
- arXiv ID: 2602.08241  
- Source URL: https://arxiv.org/abs/2602.08241  
- Reference count: 40  
- Primary result: SAYO (RL-trained MLLM with visual attention reward) achieves average 64.03 on ten benchmarks, a 4.39-point gain over Qwen3-VL-8B and outperforms larger models like InternVL3.5-38B.

## Executive Summary
Multimodal LLMs (MLLMs) often suffer from unstable visual attention during chain-of-thought (CoT) reasoning, causing early misalignments to propagate and degrade accuracy. To address this, the authors propose SAYO, an RL framework that reinforces region-level visual attention via a reward computed from high-entropy tokens. Training with GRPO on Qwen3-VL and InternVL3.5-8B using GQA and Refocus datasets yields substantial improvements across ten benchmarks, with SAYO-Qwen-8B averaging 64.03 (+4.39 over base) and exceeding much larger models. Ablations confirm the attention reward’s role and the importance of entropy-based token selection, demonstrating that stabilizing visual attention can unlock latent reasoning abilities.

## Method Summary
SAYO augments a base MLLM with a reinforcement learning training loop. For each rollout, the model generates a CoT response. The reward r combines a visual attention component rv and a format reward rf. rv is computed as tanh(log(aq+ε)/(vq+ε)), where aq is the average attention from selected high-entropy tokens (top 30% by token-level entropy) to tokens representing the target visual region, and vq is the average attention to all visual tokens. The target region tokens are derived from bounding box annotations in the training data. The policy is optimized with GRPO, using a KL divergence penalty to stay close to the reference model. Training uses 4 epochs, rollout size 16, and a learning rate of 5e-6 on a mix of GQA and Refocus datasets. At inference, the policy continues to produce CoT with reinforced visual grounding.

## Key Results
- SAYO-Qwen-8B achieves an average score of 64.03 across ten benchmarks, a 4.39-point improvement over Qwen3-VL-8B and surpasses InternVL3.5-38B.
- Gains are consistent across math-heavy (MathVision, We-Math) and chart/real-world tasks (ChartQA, MME-RealWorld).
- Ablations show that removing entropy selectivity or using random tokens drastically reduces performance, confirming the reward design’s efficacy.

## Why This Works (Mechanism)
MLLMs often fail when early visual misalignment goes uncorrected throughout CoT reasoning. By explicitly rewarding attention from high-entropy tokens to the correct visual region, SAYO forces the model to verify its uncertain steps against the image. The entropy-based selection identifies steps where the model is unsure, making the credit assignment targeted. The normalized attention ratio (Ra) provides a smooth, bounded signal that encourages focusing on relevant regions while avoiding overfitting. Over RL iterations, the policy learns to stabilize its visual grounding, reducing error propagation and unlocking stronger reasoning that was previously latent due to unstable attention.

## Foundational Learning
**Visual Attention Alignment**  
- *Why needed*: Enables the model to link textual concepts with image regions, a core requirement for multimodal understanding.  
- *Quick check*: For a sample QA, visualize attention maps between text and image tokens; verify that key words attend to relevant objects.

**Chain-of-Thought (CoT) Reasoning**  
- *Why needed*: Intermediate reasoning steps can correct errors, but early misalignments can cascade.  
- *Quick check*: Perturb an intermediate step in a generated CoT; observe whether the final answer changes dramatically.

**Reinforcement Learning with GRPO**  
- *Why needed*: Optimizes non-differentiable reward (e.g., region-level attention) while preventing policy collapse via KL constraints.  
- *Quick check*: Implement a minimal GRPO update on a synthetic task; confirm estimate superiority over REINFORCE.

**Entropy-Guided Token Selection**  
- *Why needed*: Identifies tokens where the model is uncertain, focusing learning on the most beneficial steps.  
- *Quick check*: Compute token-level entropy from output logits; ensure selected tokens cluster around reasoning steps requiring visual grounding.

**Region-Level Supervision via Bounding Boxes**  
- *Why needed*: Provides a granular, object-level signal for attention, finer than image-level rewards.  
- *Quick check*: Map a given bounding box to visual token indices; verify that the resulting token set covers the intended object.

## Architecture Onboarding
**Component Map**  
Input (image, question) -> Vision Encoder -> Visual Token Sequence -> Language Model (CoT generation) -> Final Layer Attention Extraction -> Entropy Selector (top-30%) -> Target Region Token Mapping -> Ra Computation -> Reward Fusion (rv + rf) -> GRPO Optimization -> Updated Model Policy

**Critical Path** (training iteration)  
1. Sample a batch from GQA/Refocus.  
2. Rollout: generate CoT responses for each sample.  
3. Compute token-level entropies; select high-entropy tokens (top 30%).  
4. Extract attention weights from final layer for those tokens.  
5. Compute aq (attention to target region tokens) and vq (attention to all visual tokens).  
6. Calculate rv = tanh(log(aq+ε)/(vq+ε)) and combine with format reward rf.  
7. Compute GRPO loss (reward minus baseline plus KL penalty).  
8. Backpropagate and update policy.

**Design Tradeoffs**  
- Choosing final layer attention only vs. multi-layer: final layer captures integrated reasoning but may miss early grounding; multi-layer could increase complexity.  
- Entropy threshold (30%): arbitrary; may vary across tasks; adaptive selection could improve robustness.  
- Normalization via tanh: bounds reward but may compress signal; alternatives like sigmoid or no saturation exist.  
- KL penalty strength: too low risks divergence; too high slows learning; 1e-3 was used empirically.

**Failure Signatures**  
- Ra reward does not increase during training → likely misaligned bounding box → token mapping.  
- Training loss unstable or NaN → KL coefficient inadequate or entropy selection inconsistent.  
- Model ignores image and relies on language → rv signal too weak relative to rf.  
- Overfitting to format reward (e.g., exact phrase copying) → poor generalization on held-out benchmarks.

**First Experiments**  
1. Validate visual token mapping: process a test image, reconstruct its spatial patch layout, and manually map a bounding box to token indices.  
2. Compute entropy selection: run a single rollout, extract logits, calculate per-token entropy, and confirm that the top 30% selection yields plausible uncertain tokens.  
3. Run a minimal GRPO step: compute rv and rf for one sample, perform a single update, and check that gradients flow through the attention extraction pipeline.

## Open Questions the Paper Calls Out
**Open Question 1**  
How does the choice of entropy-based token selection threshold (e.g., top 30%) affect SAYO's performance across diverse visual reasoning tasks, and is there an optimal adaptive mechanism?

**Open Question 2**  
To what extent do SAYO's performance gains on mathematical reasoning tasks result from improved visual grounding versus inherited capabilities from the base model, and can this be disentangled?

**Open Question 3**  
Does rewarding attention from only the final transformer layer limit SAYO's ability to learn multi-stage visual attention policies, and would incorporating multi-layer supervision improve performance?

**Open Question 4**  
How does SAYO transfer to sequential visual reasoning tasks (e.g., video understanding or multi-image contexts) where attention must be dynamically allocated over time?

**Open Question 5**  
What is the sensitivity of SAYO's training stability and final performance to reinforcement learning hyperparameters (e.g., KL coefficient, rollout count), and are there optimal configurations across model scales?

## Limitations
- **Mapping ambiguity** – Converting bounding boxes to token ranges depends on the model’s image processor specifics; the paper does not fully specify this alignment, risking mis-targeted rewards.  
- **Entropy handling** – Normalization (per-sample vs. batch) and tie-breaking for top-30% selection are not explicitly defined; the source distribution (policy logits?) is implied but unclear.  
- **Causal attribution** – While ablations show the reward’s importance, disentangling the effects of entropy-selectivity from the attention target’s design remains difficult.

## Confidence
- Performance gains (High): Benchmark numbers are clearly reported and evaluated.  
- Reward design effectiveness (Medium): Ablations support it, but reproduction hinges on unresolved details.  
- Credit assignment fix (Low): The proposed mechanism is plausible but not directly validated (e.g., attention heatmaps before/after).
