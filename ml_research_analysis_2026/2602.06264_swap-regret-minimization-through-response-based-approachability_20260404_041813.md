# Swap Regret Minimization Through Response-Based Approachability

## Quick Facts
- **ArXiv ID:** 2602.06264  
- **Source URL:** https://arxiv.org/abs/2602.06264  
- **Reference count:** 40  
- **Primary result:** Efficient algorithms for linear swap regret minimization: O(d√T) for centrally symmetric convex bodies, O(d^{3/2}√T) for arbitrary convex bodies; matching lower bound Ω(d√T) for symmetric bodies; extension to polynomial‑dimension swap deviations and profile swap regret.

## Executive Summary
We consider the online problem of minimizing linear swap regret against an adversary when the learner’s actions lie in a general convex set P ⊂ ℝ^d. Prior work by Gordon et al. achieved the optimal O(d√T) rate but required an inefficient ellipsoid method each round. This paper leverages the response‑based approachability framework of Bernstein & Shimkin (2015) to design an efficient algorithm. The core idea is to recast linear swap regret as an approachability problem in ℝ^{d×(d+1)} and maintain a cumulative vector that remains close to the target set by solving a bilinear minimax game each iteration.

The main results are threefold. First, after preprocessing the John ellipsoid of P, the algorithm attains O(d√T) linear swap regret when P is centrally symmetric, and O(d^{3/2}√T) for arbitrary convex bodies. Second, a matching Ω(d√T) lower bound is proved for centrally symmetric sets, establishing optimality and separating the symmetric case from the simplex (which enjoys O(√T d log d)). Third, the methodology extends seamlessly to polynomial‑dimension swap deviations (including profile swap regret), yielding the strongest efficiently computable equilibrium concept known.

## Method Summary
The algorithm (Algorithm 2) consists of an offline preprocessing phase and an online loop. Preprocessing: compute the John ellipsoid of P, i.e., the maximum‑volume ellipsoid contained in P, and obtain an invertible linear map A such that the transformed set P′ = AP is in John’s position (the ellipsoid is the Euclidean unit ball). Transform the loss set L′ = A^{-⊤}L and the best‑response b′ accordingly. In the online phase, maintain a cumulative matrix U_t ∈ ℝ^{d×(d+1)} initialized to 0. At each round t:

1. Compute an (approximate) equilibrium (p′_t, ℓ′_t) of the bilinear zero‑sum game  
   min_{p′∈P′} max_{ℓ′∈L′} ⟨U_{t-1}, ℓ′ ⊗ p′, ℓ′⟩.
2. Define s′_t = (ℓ′_t ⊗ b′(ℓ′_t), ℓ′_t).
3. Play p_t = A^{-1}p′_t, then observe loss ℓ_t.
4. Set ℓ′_t = A^{-⊤}ℓ_t, compute κ′_t = (ℓ′_t ⊗ p′_t, ℓ′_t), and update  
   U_t = U_{t-1} + (κ′_t - s′_t).

The invariance ⟨U_{t-1}, κ_t - s_t⟩ ≤ 0 holds by construction, and telescoping yields  
   ∥U_T∥_F ≤ 2 T · AppLoss_T · max_{φ∈End(P)} ∥φ∥_F,  
where AppLoss_T = min_{s∈S} ∥\bar{κ}_T - s∥_F. Using the geometry of P′ (John’s decomposition) one bounds ∥(ℓ′⊗p′,ℓ′)∥_F and ∥φ∥_F, giving the stated rates. Approximation errors ϵ_t add ≤ ϵ_t T to regret, so choosing ϵ_t = O(1/√t) preserves the √T rate.

## Key Results
- O(d√T) linear swap regret for centrally symmetric convex bodies; O(d^{3/2}√T) for arbitrary convex bodies.

## Why This Works (Mechanism)
The success of the method rests on three pillars.

**Response‑based approachability reduction.** Following Bernstein & Shimkin (2015), the linear swap regret problem is transformed into an approachability instance in ℝ^{d×(d+1)}. Define the feasible set K = conv{(ℓ ⊗ p, ℓ) : ℓ ∈ L, p ∈ P} and the target set S = conv{(ℓ ⊗ b(ℓ), ℓ) : ℓ ∈ L}, where b(ℓ) = argmin_{p∈P}⟨ℓ,p⟩. The empirical average \bar{κ}_T lies in the convex hull of the actions, while \bar{s}_T ∈ S is the best affine response. The difference \frac{1}{T}U_T = \bar{κ}_T - \bar{s}_T encodes regret. The bilinear minimax game solved each round enforces the invariance ⟨U_{t-1}, κ_t - s_t⟩ ≤ 0, which guarantees that the squared norm of U_T grows at most linearly, yielding a √T scaling. The final regret is at most 2T · AppLoss_T · max_{φ∈End(P)} ∥φ∥_F, where End(P) is the space of affine endomorphisms of P.

**Preconditioning via John’s ellipsoid.** After applying the transformation A, the set P′ satisfies John’s theorem: there exists a decomposition ∑_i c_i ξ_i ⊗ ξ_i = I_d with ∑_i c_i ξ_i = 0 and ξ_i ∈ P′. This decomposition allows tight norm bounds. For any affine map M(p′) = a′ + B′p′ with M(P′) ⊆ P′, one shows ∥M∥_F ≤ √d + ∥a′∥_2. Moreover, the generator (ℓ′⊗p′,ℓ′) of K has norm at most √(d+1). When P is centrally symmetric, the translation term a′ vanishes, giving ∥M∥_F ≤ √d, and the ∥a′∥_2 term is zero. For non‑symmetric P, a lopsided John ellipsoid can force ∥a′∥_2 = Θ(d) and ∥(ℓ′⊗p′,ℓ′)∥_F = Θ(d), leading to a √d penalty in the regret.

**Extension to polynomial‑dimension deviations.** For a feature map m: P → ℝ^D (with the first d coordinates equal to p itself), define Φ_m = {M m(p) : M ∈ ℝ^{d×D}}. The Φ_m‑regret is minimized by the same framework, now with s_t = ℓ_t ⊗ m(b_m(ℓ_t)) and κ_t = ℓ_t ⊗ m(p_t). Crucially, to keep the game bilinear, one must optimize over mixed strategies μ ∈ Δ(P) instead of pure p, because pure‑strategy Φ_m‑regret is PPAD‑hard for non‑linear m. The minimax becomes min_{μ∈Δ(P)} max_{ℓ∈L} ⟨U, ℓ ⊗ (E_{p∼μ}[m(p)]), ℓ⟩. Norm bounds involve max_p ∥m(p)∥ and max_{ℓ∈L} ∥ℓ∥, producing an overall O(√k T) rate up to factors of d, where k = dim(span Φ_m).

## Foundational Learning
- **Approachability Theory (Blackwell 1956, Bernstein & Shimkin 2015)** – Provides the general framework where a vector process is forced to approach a convex target set in Euclidean norm. Here it connects cumulative swap regret (U_T) to the distance of the empirical vector \bar{κ}_T from the approachable set.  
  *Quick check question:* How does the bilinear minimax guarantee the invariance ⟨U_{t-1}, κ_t - s_t⟩ ≤ 0?

- **John’s Ellipsoid and Convex Geometry (John 1948)** – Guarantees a maximum‑volume ellipsoid inside a convex body and describes the contact points with weights. Used to find A such that AP is in John’s position, enabling the decomposition ∑ c_i ξ_i ⊗ ξ_i = I_d essential for norm bounds.  
  *Quick check question:* Why does the simple containment B_2 ⊆ P ⊆ √d B_2 not suffice to bound ∥M∥_F, whereas John’s position does?

- **Bilinear Zero‑Sum Games and Minimax Theorems** – Each iteration reduces to solving a bilinear minimax game. The minimax theorem ensures equilibrium strategies exist and satisfy the invariance. Efficient computation relies on linear optimization oracles for P and its polar.  
  *Quick check question:* Why must the algorithm use mixed strategies (Δ(P)) for polynomial‑dimension swap deviations? (Pure‑strategy regret for non‑linear Φ is PPAD‑hard.)

- **Polar Sets and Normalization** – The assumption ⟨p, ℓ⟩ ≤ 1 for all p∈P, ℓ∈L implies L ⊆ P^∘, the polar body. This normalization is used to bound ∥ℓ∥_2 via the John decomposition of P.  
  *Quick check question:* If ⟨p, ℓ⟩ ≤ C instead of 1, how do the regret bounds scale? (Answer: all norms scale linearly with C.)

- **External Regret Minimization (FTRL/OGD)** – The traditional Gordon et al. template reduces Φ‑regret to external regret over a high‑dimensional comparator set. Understanding FTRL’s \tilde{O}(√dT) baseline contextualizes why the O(d√T) rate is optimal for End(P).  
  *Quick check question:* Why does dim(End(P)) = d(d+1) suggest an \tilde{O}(d√T) external regret bound via FTRL? (Standard convex online learning gives \tilde{O}(√DT) for D‑dimensional comparators.)

## Architecture Onboarding
- **Component map:**  
  Preprocessing (compute John ellipsoid of P → obtain A) → Transformed sets (P′ = AP, L′ = A^{-⊤}L, b′) → Main loop: solve minimax (min_{p′∈P′} max_{ℓ′∈L′} ⟨U_{t-1}, ℓ′⊗p′,ℓ′⟩) → Play p_t = A^{-1}p′_t → Observe ℓ_t → Update U_t ← U_{t-1} + (κ′_t - s′_t).
- **Critical path:** (1) John ellipsoid computation (offline) gives a transformation that yields norm bounds ∥(ℓ′⊗p′,ℓ′)∥_F = O(√d) (symmetric) or O(d) (general). (2) Per‑iteration equilibrium solve maintains the approachability invariance. (3) Cumulative update of U_t telescopes to produce sub‑linear regret.
- **Design tradeoffs:**  
  • Central symmetry vs. generality: symmetry yields O(d√T); without it the bound is O(d^{3/2}√T).  
  • Precision vs. speed: using an ϵ_t‑approximate equilibrium adds ≤ ϵ_t T to regret; choosing ϵ_t = O(1/√T) retains √T rate but may increase solver runtime.  
  • Profile vs. linear swap: no extra cost in base algorithm; polynomial deviations require mixed strategies and a feature map m, increasing per‑iteration complexity.
- **Failure signatures:**  
  • Poor John ellipsoid: inaccurate computation leads to large norms for (ℓ′⊗p′,ℓ′) and weakened guarantees.  
  • Approximate equilibrium error: if ϵ_t does not decay fast enough, total added regret becomes O(ϵ T), possibly dominating √T term.  
  • Non‑convertible sets: if P is not full‑dimensional or L is not contained in P^∘, the normalization ⟨p,ℓ⟩ ≤ 1 fails and norm bounds break.
- **First three experiments:**  
  1. **Euclidean ball test:** Run Algorithm 2 on P = B_2 for d ∈ {2,5,10,20} and T up to 10^5. Verify average linear swap regret scales as Θ(d√T).  
  2. **Simplex symmetry gap:** Run on the probability simplex Δ_d (non‑symmetric). Expect scaling Θ(d^{3/2}√T) per Corollary 3.12; compare with Blum‑Mansour’s O(√T d log d) to confirm separation.  
  3. **Quadratic polynomial deviations:** For P = B_2 and m(p) = (p, p⊗p) (D = d + d^2), implement Algorithm 3. Check that Φ_m‑regret grows like O(d^{3/2}√T), consistent with norm analysis.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Can a computationally efficient algorithm achieve O(d√T) linear swap regret for all convex bodies (not just centrally symmetric), thereby matching the rate of Gordon et al. (2008)?
- **Basis in paper:** [explicit] "Another interesting question we leave open is whether the O(d√T) rate attained by Gordon et al. [2008] can be matched by a computationally efficient algorithm; our Theorem 1.1 leaves a √d gap." (Section 6, Conclusions) Theorem 1.1 provides O(d√T) for centrally symmetric bodies and O(d^{3/2}√T) for general bodies, while Gordon’s algorithm achieves O(d√T) for general bodies but is computationally inefficient.
- **Why unresolved:** The only computationally efficient algorithm for general convex bodies attains O(d^{3/2}√T) regret (Corollary 3.12), leaving a √d gap compared to the information‑theoretic optimum Ω(d√T) (for symmetric bodies) and the inefficient O(d√T) algorithm. It is unknown whether this gap is inherent or can be closed by a more clever efficient algorithm.
- **What evidence would resolve it:** Either an efficient algorithm with O(d√T) regret for all convex bodies (e.g., via a new approach or improved analysis) or a proof that any efficient algorithm must incur at least Ω(d^{3/2}√T) regret on some family of convex bodies.

### Open Question 2
- **Question:** What are tight information‑theoretic lower bounds on polynomial‑dimension swap regret (e.g., with feature maps of dimension k) as a function of k and T?
- **Basis in paper:** [explicit] "Another interesting question is to obtain stronger lower bounds for a set of swap deviations with polynomial dimension, such as low‑degree polynomials." (Section 6, Conclusions)
- **Why unresolved:** The paper presents an O(√k T) upper bound (Theorem 4.4) for polynomial‑dimension swap regret, but no non‑trivial lower bounds are known beyond the linear case (k = d). The optimal dependence on k (and whether the √k factor is necessary) remains open.
- **What evidence would resolve it:** Constructing explicit adversaries and convex sets that force any efficient algorithm to incur Ω(√k T) (or perhaps higher) polynomial‑dimension swap regret in expectation, or proving that O(√k T) is optimal by matching upper and lower bounds.

### Open Question 3
- **Question:** Can the O(d√T) barrier on swap regret be improved in the high‑dimensional regime where the horizon T is not significantly larger than the dimension d?
- **Basis in paper:** [explicit] "Finally, our focus has been on the regime where T is significantly larger than the dimension. It is possible that one can improve over the O(d√T) barrier in the high dimensional regime by leveraging recent advances [Dagan et al., 2024, Peng and Rubinstein, 2024]." (Section 6, Conclusions)
- **Why unresolved:** The lower bound of Ω(d√T) (Theorem 5.1) only holds for T ≥ Ω(d^4). For smaller T (e.g., T = Θ(poly(d))), it is plausible that better dependence on d can be achieved, but no nontrivial lower bounds exist in that regime and the paper’s algorithm does not address it.
- **What evidence would resolve it:** Designing algorithms with o(d√T) regret for moderate T (e.g., T = O(d^c) for some c) or proving that the Ω(d√T) barrier persists even when T is as small as Θ(d).

## Limitations
- **Per‑iteration minimax equilibrium:** The algorithm requires solving a bilinear minimax game exactly (or up to ε_t) each round via linear oracles. No concrete polynomial‑time subroutine is provided; reducing to no‑regret dynamics may add overhead and risk precision decay.
- **Central symmetry gap:** For non‑symmetric convex bodies the regret degrades to O(d^{3/2}√T); the analysis (Lemma D.1) might be loose and no matching lower bound exists, so the true optimal rate for general bodies is unknown.
- **Polynomial‑dimension deviation norms:** For feature maps like m(p) = (p, p⊗p), the bound depends on max_p ∥m(p)∥ and max_{φ} ∥φ∥_F, which can be Θ(d^{3/2}), weakening guarantees; the claimed “strongest efficiently computable equilibrium” is not formally quantified.
