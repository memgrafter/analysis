# Enhancing SHAP Explainability for Diagnostic and Prognostic ML Models in Alzheimer Disease

## Quick Facts
- **arXiv ID**: 2603.06758
- **Source URL**: https://arxiv.org/abs/2603.06758
- **Reference count**: 40
- **Primary result**: A multi-level SHAP robustness framework shows high cross-task consistency (Spearman ρ = 0.61–0.94) and stable domain contributions in Alzheimer's ML models, with cognitive markers dominating explanations.

## Executive Summary
This study tackles the lack of robust SHAP explanations for Alzheimer's disease ML models by introducing a multi-level framework that evaluates within-model coherence, cross-stage stability, and cross-task consistency between diagnosis and prognosis. Using AutoML on the large NACC dataset, models are trained for both tasks, and explainability robustness is quantified via correlation, overlap, and domain contribution metrics. Results demonstrate that SHAP values are highly consistent across tasks and dominated by cognitive/functional features, enabling more trustworthy clinical interpretations.

## Method Summary
The authors leverage the NACC-UDS dataset (53,318 participants, 195,196 visits) with rigorous preprocessing: filtering features with >50% missing, median/mode imputation, scaling cognitive scores, and encoding categoricals. A subject-level 80-20 train-test split prevents longitudinal leakage. PyCaret AutoML trains binary/multiclass classifiers for diagnostic (NC, MCI, AD) and prognostic (4-year progression) tasks, using 10-fold CV with SMOTE inside training folds, random grid search for tuning, and final model retraining. SHAP values and permutation feature importance are computed, and stability is assessed through Spearman/Kendall correlations, Jaccard@10/20, sign consistency, mean absolute SHAP shift, and domain contribution ratios.

## Key Results
- Cognitive and functional markers (e.g., MEMORY, JUDGMENT) consistently dominate SHAP explanations across models.
- Cross-task SHAP consistency is high: Spearman ρ = 0.61–0.94, 100% sign stability, mean absolute SHAP shift <0.03.
- Domain-level contributions are stable, with genetic features showing slightly higher relevance in prognosis versus diagnosis.

## Why This Works (Mechanism)
The framework quantifies SHAP robustness through multiple complementary metrics that measure agreement in feature ranking (correlation), set overlap (Jaccard), directional consistency (sign), and clinical interpretability (domain contributions). By evaluating these across disease stages and tasks, it ensures explanations are not artifacts of a specific model or dataset split but reflect stable, clinically plausible patterns—thus bridging the gap between complex ML outputs and trustworthy medical insights.

## Foundational Learning
- **SHAP**: Game-theoretic method for instance-level feature attribution; needed to explain individual predictions; quick check: compute SHAP values for a test sample using `shap.Explainer`.
- **AutoML (PyCaret)**: Automated model selection/tuning; needed for fair, reproducible model comparisons across tasks; quick check: run `compare_models` on a toy dataset.
- **SMOTE**: Synthetic minority oversampling for imbalanced data; needed to prevent model bias toward majority classes; quick check: apply SMOTE and verify balanced class distribution.
- **Spearman correlation**: Rank-based metric; needed to compare feature importance orders; quick check: compute on two ranked lists using `scipy.stats.spearmanr`.
- **Jaccard overlap**: Set similarity index; needed to assess top-k feature agreement; quick check: calculate intersection over union of top 10 features.
- **Domain contribution ratios**: Summed absolute SHAP per feature group; needed to map explanations to clinical domains; quick check: aggregate SHAP values by predefined feature categories.

## Architecture Onboarding
NACC Data -> Preprocessing (filtering, imputation, encoding) -> Subject-level Split -> PyCaret AutoML (CV with SMOTE) -> Model Finalization -> SHAP/Feature Importance Calculation -> Stability Metrics Computation.

**Critical path**: Enforce subject-level split to prevent data leakage → use consistent SHAP background dataset → align feature sets across tasks for valid comparisons.

**Design tradeoffs**: AutoML provides efficiency but obscures feature selection logic; SHAP offers local explanations but is computationally intensive for large models/instances.

**Failure signatures**: Overlapping subject IDs in train/test splits; divergent feature sets across tasks due to AutoML; high SHAP variance with different random seeds or background samples.

**First experiments**:
1. Audit train/test splits to confirm no shared participant IDs.
2. Log feature sets retained after each AutoML run to compare across diagnostic/prognostic scenarios.
3. Retrain models with 5 random seeds, compute variance in stability metrics (e.g., Spearman ρ) to assess sensitivity.

## Open Questions the Paper Calls Out
- How does this SHAP robustness framework generalize to other neurological diseases or multi-modal data (e.g., imaging, genomics)?
- What is the clinical utility of stable SHAP rankings if individual prediction explanations still vary across models?
- Does AutoML's inherent feature selection variability undermine the validity of cross-task SHAP comparisons, and how can feature set alignment be enforced?
- Unknown: The impact of different SHAP background dataset sizes or sampling strategies on the reported stability metrics.
- Assumption: The observed domain contribution stability (e.g., genetics in prognosis) holds across diverse populations and disease spectrums beyond the NACC cohort.

## Limitations
- AutoML's internal feature selection may cause varying feature sets across tasks (e.g., 37 vs 77 features), undermining cross-task SHAP comparisons.
- Hyperparameter search details ("random grid search") and SMOTE implementation per fold are unspecified, risking inconsistent model stability.
- Longitudinal leakage remains a threat if subject-level split enforcement is inadequately documented.

## Confidence
- Cross-task SHAP consistency (ρ = 0.61–0.94): High.
- Domain contribution stability (genetic relevance in prognosis): Medium.
- Framework reproducibility (preprocessing, AutoML pipeline): Low.

3. Quantify SHAP variance across 5 random seeds; report confidence intervals for stability metrics.
