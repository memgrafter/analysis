# Grandes Modelos de Linguagem Multimodais (MLLMs): Da Teoria à Prática

## Quick Facts
- **arXiv ID**: 2602.12302
- **Source URL**: https://arxiv.org/abs/2602.12302
- **Reference count**: 0
- **Primary result**: Two-stage MLLMsent framework (image captioning with MLLM followed by fine-tuned text-only LLM sentiment classification) achieves superior robustness and accuracy over end-to-end multimodal classification.

## Executive Summary
This paper serves as a comprehensive tutorial on Multimodal Large Language Models (MLLMs), covering core concepts like Transformer architectures, CLIP alignment, and fusion strategies, alongside practical implementation guides using LangChain and LangGraph. A key experimental contribution is the MLLMsent framework for visual sentiment analysis, which demonstrates that a two-stage pipeline—generating image captions via an MLLM and then classifying sentiment with a fine-tuned text-only LLM—outperforms direct end-to-end multimodal classification. The authors also show how retrieval-augmented generation (RAG) and few-shot prompting can enhance domain-specific tasks such as bird species identification, with full code and tutorials publicly available to support reproducibility.

## Method Summary
The paper outlines a reproduction task comparing two approaches for visual sentiment analysis using the PerceptSent dataset. In the end-to-end method, an MLLM (e.g., GPT-4o-mini or DeepSeek-VL) directly receives an image and a classification prompt to predict sentiment. The two-stage approach first generates captions for all images using an MLLM, then fine-tunes a text-only LLM (ModernBERT-large) on these captions with sentiment labels. Fine-tuning employs AdamW, class weighting for imbalance, K-fold cross-validation, and TensorBoard logging, with validation F1-score guiding early stopping. Evaluation metrics include F1-score, accuracy, precision, and recall. The provided GitHub repository includes scripts for data loading, caption generation, and training.

## Key Results
- Provides a thorough tutorial on MLLM fundamentals (Transformer, CLIP, fusion) and practical pipelines with LangChain/LangGraph.
- The two-stage MLLMsent framework significantly improves accuracy and robustness in visual sentiment analysis compared to end-to-end classification.
- RAG and few-shot prompting effectively boost performance on domain-specific tasks like bird species identification; implementations are open-source.

## Why This Works (Mechanism)
The paper empirically validates the two-stage approach's superiority but does not deeply analyze the underlying mechanisms. Potential factors include: (1) the decoupling of visual perception (captioning) and textual sentiment reasoning allowing each component to specialize; (2) the fine-tuned text-only LLM may better handle nuanced sentiment expressions in captions than an MLLM that must jointly process visual and textual tokens; and (3) caption generation might filter out irrelevant visual details, focusing on salient emotional cues. However, these hypotheses require targeted ablation studies to confirm.

## Architecture Onboarding
Component map: Image -> [MLLM Captioning] -> Caption CSV -> [Text LLM Fine-tuning] -> Sentiment Classifier  
Critical path: The pipeline's core flow involves transforming an image into a textual caption via an MLLM, then using that caption as input to a fine-tuned text-only LLM for sentiment prediction. This separation allows independent optimization of vision-to-text conversion and text-based sentiment analysis.  
Design tradeoffs: The two-stage design trades off end-to-end simplicity for potentially higher accuracy and robustness; however, it introduces latency from sequential processing and dependency on caption quality. End-to-end models are faster but may suffer from multimodal hallucinations and less specialized reasoning.  
Failure signatures: Common failures include: (1) poor caption generation (irrelevant or incomplete descriptions) due to MLLM limitations; (2) fine-tuning issues such as overfitting, data leakage, or class imbalance; (3) mismatched label spaces between captioning and sentiment tasks.

## Open Questions the Paper Calls Out
- Why does the two-stage approach achieve superior robustness and accuracy compared to direct end-to-end multimodal classification in visual sentiment analysis? The paper reports the result but does not investigate whether it stems from caption quality, classifier specialization, or architectural decoupling.
- How can multimodal hallucinations in VQA be systematically mitigated? The paper proposes Content Guided Refinement and Visual Attention Refinement but lacks empirical validation across benchmarks.
- What architectural or training modifications can enhance cross-lingual knowledge transfer in MLLMs? The paper identifies degradation in non-English languages but does not explore solutions like multilingual pre-training or adapters.
- To what extent can computationally efficient MLLMs (quantized, distilled) maintain robustness and accuracy compared to large-scale models? The paper notes trends toward efficiency but does not empirically compare robustness under noisy conditions or domain shifts.

## Limitations
- Exact train/validation/test splits for the PerceptSent dataset are not disclosed, risking variability in reproduction results.
- Caption generation parameters (prompt text, temperature, max tokens) are incompletely specified, affecting caption consistency.
- The evaluation relies on specific model choices (DeepSeek-VL, GPT-4o-mini, ModernBERT-large), limiting generalizability claims.

## Confidence
