# Deep Reinforcement Learning and The Tale of Two Temporal Difference Errors

## Quick Facts
- **arXiv ID:** 2603.21921
- **Source URL:** https://arxiv.org/abs/2603.21921
- **Reference Count:** 20
- **Primary Result:** The explicit (bootstrapped target minus prediction) and implicit (difference between successive predictions) TD errors are not numerically equivalent in deep RL with function approximation, and the choice between them significantly impacts the stability and performance of algorithms that use TD errors for auxiliary quantities like average reward or advantage.

## Executive Summary
The temporal difference (TD) error has two mathematically distinct interpretations that are equivalent only under restrictive conditions in tabular reinforcement learning. This paper shows analytically that with deep neural network function approximation—due to nonlinear activations, batch updates, and non-unit feature norms—the two formulations decouple, yielding increasingly different numerical values as network nonlinearity grows. Empirically, the divergence has practical consequences: using the explicit TD error to update an average-reward estimate in differential and reward-centering Q-learning causes instability and poor performance on Atari Breakout and Pong, while the implicit TD error yields stable, high returns. In actor-critic methods (A2C), the implicit TD error provides a viable and slightly superior advantage function estimate compared to the standard explicit version on MuJoCo HalfCheetah. The work underscores that the choice of TD error interpretation is a critical, often overlooked, design decision in deep RL algorithm development.

## Method Summary
The authors combine analytical derivations with empirical comparisons across three algorithm families: differential Q-learning, reward-centering Q-learning, and Advantage Actor-Critic (A2C). For each, they implement variants that use either the explicit TD error ($\delta_e = r + \gamma \hat{V}(s') - \hat{V}(s)$) or the implicit TD error ($\delta_i = (\hat{V}_{t+1}(s) - \hat{V}_t(s))/\alpha$) for auxiliary updates (average-reward $\bar{R}$ or advantage $A$). Experiments are conducted on Atari Breakout and Pong (discrete control) and MuJoCo HalfCheetah (continuous control), with network architectures ranging from linear function approximation to large convolutional networks. Hyperparameter sweeps are performed for step sizes $\alpha$ (critic learning rate) and $\eta$ (auxiliary update scaling). The primary metric is the absolute difference $|\delta_e - \delta_i|$, tracked alongside episodic return and, for average-reward methods, the stability of $\bar{R}$.

## Key Results
- The absolute difference between explicit and implicit TD errors increases with network nonlinearity and size, as measured on Atari Breakout.
- In differential DQN on Breakout, updating $\bar{R}$ with the explicit TD error leads to divergence and low returns, while the implicit TD error yields stable learning and high scores.
- For reward-centering on Pong, implicit TD updates achieve higher final scores; explicit updates can be stable but require much smaller auxiliary step size $\eta$.
- In A2C on HalfCheetah, using the implicit TD error as the advantage estimate provides a slight but consistent improvement in returns and learning stability over the explicit TD error.

## Why This Works (Mechanism)

### Mechanism 1: Non-Equivalence in Deep Function Approximation
- **Claim:** The numerical equivalence between explicit and implicit TD errors breaks down in deep RL due to network nonlinearities and batch updates.
- **Mechanism:** In tabular RL, a single (s,a) update makes the two formulations algebraically identical. With linear function approximation $\hat{Q} = w^T x$, the implicit error is $\delta_i = \delta_e \cdot (x^T x)$, equaling $\delta_e$ only if the feature norm squared $||x||^2 = 1$. In deep networks, nonlinear activations $\sigma(\cdot)$ introduce gradient terms $\nabla_w \sigma(...)$ that decouple the errors. Batch updates further introduce cross-sample inner products $\sum_{k \neq j} x_k^T x_j$, making equality require the unlikely condition $\frac{1}{B}\sum_k x_k^T x_j = 1$ for all $j$ in a batch of size $B$.
- **Core Assumption:** Learned network features do not have unit norm per sample—a condition virtually never met in practice.
- **Evidence Anchors:**
  - [abstract]: "...increasingly-nonlinear deep RL architectures can cause these interpretations of the TD error to yield increasingly different numerical values."
  - [section 3.1]: Linear case derivation $\delta_i = \delta_e x^T x$.
  - [section 3.3]: Batch condition $\frac{1}{B}\sum_k x_k^T x_j = 1$ required for equality.
- **Break Condition:** The divergence $|\delta_e - \delta_i|$ diminishes as learning converges ($\delta_e, \delta_i \to 0$) or if the network's Jacobian and batch feature covariances accidentally satisfy the restrictive equality conditions.

### Mechanism 2: Instability in Average-Reward Updates
- **Claim:** Using the explicit TD error to update the average-reward estimate $\bar{R}$ in differential/reward-centering RL introduces instability via a compounded error term.
- **Mechanism:** Convergence theory for tabular differential RL uses an *implicit*-TD formulation for $\bar{R}$ updates. Switching to explicit $\delta_e$ yields $\bar{R}_{t+1} = \bar{R}_t + \eta \alpha \delta_e = \bar{R}_t + \eta \alpha (\delta_i + \epsilon_t)$, where $\epsilon_t = \delta_e - \delta_i$. The error $\epsilon_t$ corrupts $\bar{R}$. Critically, $\bar{R}$ is then used in the bootstrapped target for subsequent $\delta_e$ calculations, creating a feedback loop: $\delta_e_t$ depends on corrupted $\bar{R}_{t-1}$ from $\epsilon_{t-1}$. Over $n$ steps, the error compounds: $\bar{R}_n = \bar{R}_0 + \eta \sum_t \alpha_t \delta_i^{(t)} + \eta \sum_t \alpha_t \epsilon_t$.
- **Core Assumption:** The $\bar{R}$ update uses a TD error that itself depends on the previous $\bar{R}$ estimate, creating coupled, non-stationary dynamics.
- **Evidence Anchors:**
  - [section 4.1]: Derivation of update rule and compounded error term $\sum \alpha_t \epsilon_t$.
  - [section 4.1, Figure 2]: Empirical divergence of $\bar{R}$ with explicit updates on Breakout vs. stability with implicit.
  - [abstract]: "...using the interpretation of the TD error as the difference between a bootstrapped target and a prediction can result in unstable average-reward estimates."
- **Break Condition:** Instability is mitigated if $\epsilon_t$ is consistently small (i.e., $|\delta_e - \delta_i| \approx 0$), which occurs with linear approximators and unit-norm features, or if $\eta \alpha$ is made vanishingly small (reducing learning speed).

### Mechanism 3: Implicit TD as Advantage Estimate
- **Claim:** The implicit TD error provides a viable and sometimes superior advantage function estimate $A(s,a)$ for actor-critic algorithms compared to the standard explicit TD error.
- **Mechanism:** In A2C, the advantage should reflect how much better an action is than the average state value. The explicit $\delta_e = r + \gamma V(s') - V(s)$ is a *semi-gradient* estimate. The implicit $\delta_i = (V_{t+1}(s) - V_t(s))/\alpha$ measures the *actual change* in the value estimate for state $s$ after the parameter update. A positive $\delta_i$ means the outcome was better than the *previous* estimate $V_t(s)$, directionally consistent with a positive advantage. Proposition 4.1 formalizes this consistency.
- **Core Assumption:** The critic's update $\Delta w = \alpha \delta_e \nabla V(s)$ produces a meaningful revision $V_{t+1}(s)$ that is a better estimate of $V^\pi(s)$.
- **Evidence Anchors:**
  - [section 4.3]: Proposition 4.1 and proof.
  - [section 4.4, Figure 3c]: Slightly higher returns on HalfCheetah with implicit advantage.
- **Break Condition:** The implicit estimate becomes poor if the critic update is noisy or $\alpha$ is poorly tuned, causing $V_{t+1}(s)$ to fluctuate wildly relative to $V_t(s)$, decoupling $\delta_i$ from the true advantage.

## Foundational Learning
- **Concept: Temporal Difference (TD) Error Definitions**
  - *Why needed here:* The entire paper hinges on distinguishing two formulations: $\delta_e$ (bootstrapped target minus current prediction) and $\delta_i$ (change in prediction after an update). Understanding both is essential.
  - *Quick check:* Write $\delta_e$ for Q-learning: $\delta_e = r + \gamma \max_{a'} Q(s',a') - Q(s,a)$. Derive $\delta_i$ from the parameter update perspective.

  - *Why needed here:* The core result—equivalence breaking—depends on moving from tabular (identity features) to parameterized (linear/deep) value functions. Gradient update dynamics are central.
  - *Quick check:* For a linear $Q(w) = w^T x(s,a)$, show how update $w \leftarrow w + \alpha \delta_e x$ leads to $\delta_i = \delta_e \cdot (x^T x)$.

## Architecture Onboarding

### Component Map
Replay Buffer -> (Sample Batch) -> Critic Network (Q/V) -> Compute $\delta_e$ -> Critic Loss -> Parameter Update (w'=w - α∇L) -> Compute $\delta_i$ = (Q(s,a,w') - Q(s,a,w))/α -> [Auxiliary Update: $\bar{R} \leftarrow \bar{R} + \eta \alpha \delta_i$ or Advantage = $\delta_i$] -> (Actor Update if applicable). Target Network periodically updates to stabilize $\delta_e$ target.

### Critical Path
1. **Data Collection:** Agent interacts, stores transitions $(s,a,r,s')$ in replay buffer.
2. **Sampling:** Random minibatch of size $B$ drawn.
3. **Explicit TD Error:** $\delta_e^j = r^j + \gamma \max_{a'} Q_{tgt}(s'^j,a') - Q(s^j,a^j)$ computed for each sample $j$ using target network.
4. **Critic Update:** Gradient descent on loss $L = \frac{1}{B}\sum_j \text{smoothL1}(\delta_e^j)$ updates critic parameters $w \to w'$.
5. **Implicit TD Error:** For each sample $j$, perform a forward pass with $w'$ on $(s^j,a^j)$ to get $Q'(s^j,a^j)$, then $\delta_i^j = (Q'(s^j,a^j) - Q(s^j,a^j))/\alpha$.
6. **Auxiliary Update:** Average $\delta_i$ over batch: $\bar{\delta}_i = \frac{1}{B}\sum_j \delta_i^j$. Use $\bar{\delta}_i$ to update $\bar{R}$ (differential/centering) or as advantage estimate (A2C). Standard algorithm continues using $\bar{\delta}_e$ for critic target.

### Design Tradeoffs
- **Implicit vs. Explicit for Auxiliary Quantities:** Implicit ($\delta_i$) is theoretically aligned with convergence proofs and empirically more stable but requires a second forward pass through the critic after the parameter update, increasing compute by ~50%. Explicit ($\delta_e$) is cheaper but risks instability, necessitating careful tuning of auxiliary step size $\eta\alpha$.
- **Step Size Sensitivity:** The magnitude of $|\delta_e - \delta_i|$ scales with critic learning rate $\alpha$ (for linear case, $\delta_i = \delta_e \cdot x^T x$ where $x$ changes with $w$). Larger $\alpha$ may increase divergence. For $\bar{R}$ updates, $\eta\alpha$ must be small enough to avoid destabilizing $\bar{R}$ but large enough to track the true average reward.
- **Network Architecture:** Simpler networks (fewer layers, linear/ReLU) may reduce $|\delta_e - \delta_i|$ but limit representational capacity. No universal optimal architecture; trade-off must be empirically validated per task.

### Failure Signatures
1. **Diverging $\bar{R}$ Estimate:** $\bar{R}$ grows unbounded or oscillates wildly early in training. **Action:** Switch from explicit to implicit $\delta_i$ for $\bar{R}$ updates. Reduce $\eta\alpha$.
2. **No Performance Difference:** Explicit and implicit variants perform similarly, especially in A2C. **Diagnostic:** Check measured $|\delta_e - \delta_i|$; if very small ($<10^{-3}$), the architecture may be insufficiently nonlinear or batch size too small. Increase network size/depth.
3. **Noisy Policy Gradient in A2C:** High-variance returns despite stable critic loss. **Action:** Compare $\delta_e$ and $\delta_i$ variance/magnitude. If $\delta_i$ is consistently smaller/less noisy, it may provide a lower-variance advantage.

## Limitations
- Unspecified random seeds, Atari preprocessing details, and exact update ordering hinder exact replication.
- Theoretical analysis assumes conditions (unit-norm features, linearity) that rarely hold; applicability to modern architectures (transformers, normalization) is unquantified.
- Empirical evaluation is narrow: only three environments and three algorithm families, limiting generalizability of conclusions about implicit TD error benefits.

## Confidence
- **Non-equivalence of explicit/implicit TD errors in deep RL** (High): Rigorous derivation and consistent measurements showing divergence grows with nonlinearity.
- **Instability of explicit TD error in average-reward updates** (Medium): Demonstrated on Breakout and Pong across hyperparameter sweeps, but may depend sensitively on $\eta\alpha$ ratios.
- **Implicit TD error as viable advantage estimator** (Medium-Low): Theoretical directional consistency holds; empirical gain is small and only observed on HalfCheetah, requiring broader validation.
