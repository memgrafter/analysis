# STRAP-ViT: Segregated Tokens with Randomized -- Transformations for Defense against Adversarial Patches in ViTs

## Quick Facts
- arXiv ID: 2603.12688
- Source URL: https://arxiv.org/abs/2603.12688
- Reference count: 40
- Primary result: STRAP-ViT achieves robust top-1 accuracies within 2-3% of clean baseline accuracies across ImageNet and CalTech-101, with ≤2.2% clean accuracy drop.

## Executive Summary
Adversarial patches can hijack Vision Transformer self-attention, leading to confident misclassifications by corrupting the class token. STRAP-ViT is a novel, training-free defense that detects tokens overlapping the adversarial patch using Jensen-Shannon Divergence (JSD) from a clean reference distribution, and applies randomized composite transformations to those tokens during inference. Evaluated on ViT-B/16 and DinoV2 across ImageNet and CalTech-101 against multiple state-of-the-art patch attacks, STRAP-ViT attains robust accuracies close to clean model performance (within 2-3%) while minimally impacting clean accuracy. The method is model-agnostic, computationally lightweight, and robust to adaptive attacks.

## Method Summary
STRAP-ViT is a plug-and-play inference-time module inserted immediately after a ViT's patch embedding and positional encoding. It operates in two phases: (1) **Token Segregation**: For each token embedding at a chosen layer, compute the Jensen-Shannon Divergence (JSD) between its softmax distribution and a pre-computed clean reference distribution (position- and layer-conditional). Flag the top-K tokens with highest JSD as anomalous. (2) **Randomized Transformation**: Apply a random composition of three transformations (Lp-projection, affine contraction, simplex transform via softmax) to each flagged token. The transformed tokens, along with unaltered others, are then fed into the remaining ViT blocks. The hyperparameter K is set to cover at least 50% of the expected patch area (typically 2–8 tokens), balancing robustness and clean accuracy. No additional training is required; only clean data is used offline to build reference distributions.

## Key Results
- Robust accuracy within 2-3% of clean baseline (e.g., 78.8% vs. 80.5% clean on ImageNet with 40×40 patch).
- Significantly outperforms prior defenses across multiple patch attacks (Adversarial Patch, LAVAN, GDPA, RP2).
- Clean accuracy drop ≤2.2% for K values up to 8 tokens.

## Why This Works (Mechanism)
The defense effectiveness rests on three pillars:

### Mechanism 1: Anomalous Token Detection via Jensen-Shannon Divergence
Tokens overlapping an adversarial patch exhibit channel distributions distinct from clean tokens, measurable as elevated JSD from a clean reference distribution. The reference distribution is pre-computed per token position and layer from clean data. During inference, each token’s embedding is mapped to a probability simplex (temperature-scaled softmax) and its JSD to the reference is computed. A threshold (or top-K selection) isolates tokens that are statistically anomalous. The key assumption is that such a distributional gap reliably separates patch-affected tokens, even across attacks. However, an adaptive attacker could craft a patch whose token distributions mimic the clean reference, thereby evading detection.

### Mechanism 2: Randomized Composite Token Transformation
Flagged tokens are disrupted by applying a random sequence of three differentiable transformations: (T1) Lp-projection (bounds channel energy), (T2) affine contraction (shrinks representation), and (T3) simplex transform (reweights channels via softmax with temperature). The randomness in subset selection and order prevents the attacker from optimizing a patch that survives all possible compositions. Each transformation targets a different aspect of the adversarial signal; their combination is intended to sufficiently corrupt the patch’s influence without harming benign tokens. The core assumption is that the space of possible transformations is large enough to outpace an attacker’s ability to invert them during patch generation.

### Mechanism 3: Hyperparameter K as Coverage Guarantee
Only a small number of tokens (K, typically 2–8) need to be transformed because ViT tokens spatially correspond to image patches. The authors empirically determined that covering ≥50% of the adversarial patch’s area suffices to neutralize its effect on the class token. Since each token covers a local region, K tokens can cover a substantial fraction of even a 40×40 patch. This sparse transformation minimizes clean accuracy loss while ensuring robustness, as only tokens with high JSD (likely overlapping the patch) are altered.

## Architecture Onboarding
STRAP-ViT is inserted as a preprocessing step before the first Transformer block.

**Component map:**  
Input image → PatchEmbed → tokens Z^(0) → Positional Encoding → Z^(1) → **STRAP-ViT module** → ˜Z^(1) → Transformer blocks {B_1,...,B_L} → Classifier Head

**Critical path:**
1. For each token z_t in Z^(1) (excluding class token if present? Actually ViT includes class token; but paper says tokens overlapping patch, likely all spatial tokens), compute p_t = softmax(z_t / T).
2. Compute √JSD(p_t || q_t) where q_t is the pre-computed clean reference for layer and position.
3. Select top-K tokens with highest √JSD (or those exceeding a threshold τ).
4. For each selected token, sample a random non-empty subset and order of the three transformations and apply them sequentially to obtain ˜z_t.
5. Replace selected tokens with ˜z_t; keep others as z_t.
6. Form ˜Z^(1) and continue forward through ViT.

**Design tradeoffs:**
- **K vs. clean accuracy:** Larger K increases chance of transforming benign tokens, reducing clean accuracy. Smaller K risks insufficient patch coverage.
- **Reference distribution construction:** Requires clean data; more images improve fidelity but add offline cost. Must be layer- and position-specific.
- **Transformation randomness:** Greater diversity improves adaptive attack resistance but may increase variance in clean performance.

**Failure signatures:**
- Clean accuracy drop >2%: Likely K too high or transformations too aggressive.
- Robust accuracy near no-defense baseline: Detection failing (τ mis-set, JSD not separating) or transformations too weak.
- High run-to-run variance: Random transformations causing unstable predictions; increase sample count or use deterministic composition.

**First 3 experiments:**
1. **Clean baseline calibration:** Test STRAP-ViT on clean validation set for K=2,4,8 to find minimal K with ≤0.5% accuracy drop.
2. **JSD threshold calibration:** Using clean validation tokens, compute JSD distribution to set τ for a desired false-alarm rate (e.g., 1%). Ensure flagged clean tokens ≤ α%.
3. **Patch coverage validation:** For attacked images with known patch location, overlay top-K token indices on the image and compute fraction of patch pixels covered by the union of those token receptive fields. Adjust K if median coverage <50%.

## Open Questions the Paper Calls Out
The authors identify several unresolved issues:

1. **Adaptation to LVLMs:** Can STRAP-ViT be effectively applied to Large Vision-Language Models, which have multimodal tokens and attention? The paper only evaluates unimodal ViTs.
2. **Optimal K selection:** How does K interact with diverse patch geometries (size, shape, location)? The heuristic of covering ≥50% of the patch area may not be universally sufficient; an adaptive K strategy could improve the trade-off.
3. **Optimality of transformations:** Are the randomized composite transformations provably effective against an unrestricted attacker who can anticipate the transformation distribution? The adaptive attack in the paper is limited; a formal analysis or stronger empirical attack is needed.
4. **Theoretical coverage bound:** What is the minimal number of tokens that must be transformed to guarantee neutralization of a patch of given size and norm? The 50% heuristic lacks theoretical grounding.
5. **Vulnerability via reference leakage:** Since detection relies on a fixed clean reference distribution, an attacker could craft patches that produce tokens mimicking the clean reference, bypassing detection. Evaluating on out-of-distribution data and against JSD-stealthy attacks is needed.

## Limitations
- **Unknown reference construction:** Details on how many clean images are needed, whether references are dataset/model/layer-specific, and whether positional encodings are included are missing.
- **Unspecified transformation defaults:** Exact parameter values (Lp-radius *r*, affine γ, simplex temperature *T*) and randomization scheme (distribution over subsets/orders) are not provided.
- **Ambiguous threshold calibration:** The relationship between the anomaly threshold τ (calibrated for false-alarm rate α) and the hyperparameter K is unclear; it is not specified whether K overrides τ or vice versa.

## Confidence
The evidence supporting the mechanisms is mixed:
- **JSD-based token detection:** Low confidence. The claim is largely internal and lacks external validation; break condition (adversarial mimicry of reference distribution) is a significant vulnerability.
- **Randomized composite transformations:** Medium confidence. The paradigm is supported by prior work on randomized smoothing, but the specific composition and its synergistic effect are novel and not theoretically proven.
- **K as coverage guarantee:** High confidence. Strong empirical evidence across models and attacks shows that covering ~50% of the patch with a few tokens suffices, with minimal clean accuracy loss.

## Next Checks
To address the unknowns and strengthen confidence, we propose the following validation steps:

1. **Reference Distribution Stability Test:** Compute q_{ℓ,t} using varying numbers of clean images (e.g., 100, 500, 1000) and measure stability of per-token √JSD scores on a held-out clean set. Identify the minimum number of images required for stable reference estimation.
2. **Transformation Parameter Sensitivity Sweep:** For a fixed K and attack/model, systematically vary key parameters (Lp-radius *r*, affine γ, simplex temperature *T*) and measure robust accuracy and clean accuracy drop. Determine parameter ranges that maintain ≥95% of peak robust accuracy with ≤1% clean drop.
3. **Coverage Validation via Spatial Mapping:** For attacked samples with known patch locations, visualize top-K selected tokens and compute the fraction of patch pixels covered by their receptive fields. Confirm the ≥50% coverage claim empirically and adjust K if needed for different patch sizes/models.
