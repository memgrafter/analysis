# Decoder-only Conformer with Modality-aware Sparse Mixtures of Experts for ASR

## Quick Facts
- arXiv ID: 2602.12546
- Source URL: https://arxiv.org/abs/2602.12546
- Reference count: 0
- Primary result: 113M decoder-only model achieves 2.8% WER on LibriSpeech test-clean vs 3.2% for 139M encoder-decoder baseline

## Executive Summary
Decoder-only Conformer with Modality-aware Sparse MoE tackles the challenge of performing ASR using a single-stack architecture without alignment modules or pretraining. By embedding modality-aware sparse Mixture-of-Experts in a decoder-only Conformer—routing speech and text tokens through disjoint expert pools and applying hybrid-causality attention—the model achieves superior WER to a strong encoder-decoder baseline on LibriSpeech (2.8% vs 3.2% test-clean) with fewer active parameters, and improves multilingual performance on Common Voice 16.1 from 12.2% to 10.6%. Training uses CTC loss on speech positions and label-smoothed cross-entropy on text positions, combined with a load-balancing loss for MoE.

## Method Summary
The model uses a 17-layer decoder-only Conformer with modality-aware sparse MoE: two disjoint expert pools (8 speech, 8 text experts) per layer, hard top-1 routing per token based on modality, and hybrid-causality attention (bidirectional for speech, causal for text). Input is 80-dim log-Mel spectrograms, processed by 4× subsampling (two stride-2 2D convs), then projected to hidden size. Each layer's FFN is replaced by MoE; speech experts are 1024-dim, text experts are 1024-dim. Training uses CTC loss (weight 0.3) on speech positions only and label-smoothed CE (epsilon=0.1) on text positions, plus load-balancing loss (weight 0.1). Adam optimizer, LR 1.5e-3, warmup 25k steps, batch size 50 min, SpecAugment, word dropout (0.125).

## Key Results
- LibriSpeech test-clean: 2.8% WER vs 3.2% for 139M encoder-decoder baseline
- LibriSpeech test-other: 5.6% vs 6.0% WER
- Common Voice 16.1 (5 languages): 10.6% WER vs 12.2% baseline
- Model: 113M parameters (fewer active parameters than baseline)
- Ablation shows loss of 0.5% WER when removing MoE

## Why This Works (Mechanism)
Modality-aware routing ensures speech and text tokens activate separate expert pools, avoiding interference between continuous and discrete features. Hard top-1 routing improves efficiency and sparsity. Hybrid-causality attention matches each modality's requirements (bidirectional for speech feature integration, causal for autoregressive text prediction). Combining CTC and CE losses enables end-to-end alignment-free training within the decoder-only stack.

## Foundational Learning
- **Modality-aware sparse MoE:** Why needed? Separates speech vs text processing in a unified stack; quick check: monitor per-expert utilization to ensure balanced routing.
- **Hard top-1 routing:** Why needed? Enforces sparsity and specialization; quick check: verify router output is one-hot per token.
- **Hybrid-causality attention:** Why needed? Allows speech features to attend bidirectionally while text remains causal; quick check: confirm mask shapes per token modality.
- **CTC loss on speech positions:** Why needed? Aligns continuous speech features to labels without external aligners; quick check: ensure CTC is computed only on speech-token representations.
- **Label-smoothed CE:** Why needed? Stabilizes training on discrete text tokens; quick check: confirm smoothing is applied to label distribution.

## Architecture Onboarding

### Component Map
Input -> 2D Conv Subsampling (4×) -> Linear Projection -> Modality-aware Sparse MoE Conformer Stack (17 layers) -> Output

### Critical Path
Speech feature extraction (subsampling + linear projection) -> MoE routing per modality -> Hybrid-causality attention -> Multi-task loss (CTC + CE)

### Design Tradeoffs
- Modality-aware vs shared MoE: specialization vs parameter efficiency; current design trades parameters for performance.
- Hard vs soft routing: faster, sparser, but requires careful load balancing; chosen for efficiency.
- Hybrid-causality: matches modality needs but complicates attention implementation.

### Failure Signatures
- Routing collapse: top-1 expert gets >90% of tokens; imbalance persists after adjusting load-balancing loss.
- CTC instability: speech-position gradients vanish or CTC loss diverges.
- Suboptimal speech subsampling: loss of temporal resolution impacts CTC alignment.

### First Experiments
1. Train model without MoE to confirm CTC + CE loss works on unified stack.
2. Add MoE, monitor per-expert utilization to detect routing collapse.
3. Enable hybrid-causality attention, verify bidirectional mask for speech and causal mask for text.
