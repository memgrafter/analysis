# CompassAD: Intent-Driven 3D Affordance Grounding in Functionally Competing Objects

## Quick Facts
- **arXiv ID:** 2604.02060
- **Source URL:** https://arxiv.org/abs/2604.02060
- **Reference count:** 20
- **Primary result:** CompassNet attains state-of-the-art results on the CompassAD benchmark, improving aIoU by 4.02 (Test-Seen) and 3.54 (Test-Unseen) over prior work, and demonstrates effective robotic grasping in confusing multi-object scenes using monocular RGB.

## Executive Summary
The paper introduces the task of intent-driven 3D affordance grounding in cluttered multi-object scenes where functionally competing objects share identical affordance types. Existing methods struggle with cross-object semantic leakage and insufficient discrimination. To address this, the authors formalize the task and release the CompassAD benchmark, comprising 6,422 scenes and 88,964 query-answer pairs covering 30 confusing object pairs across 16 affordance types. Their solution, CompassNet, employs an Instance-bounded Cross Injection (ICI) module to constrain language-geometry alignment within object boundaries and a Bi-level Contrastive Refinement (BCR) module for region- and point-level discrimination between confusable surfaces. CompassNet achieves state-of-the-art performance on CompassAD, notably improving aIoU by over 3.5 points on both seen and unseen query splits. Real-world robotic deployment further validates the method, showing successful grasping using only monocular RGB input.

## Method Summary
Given a multi-object point cloud and a natural language query, the task is to predict a per-point affordance mask on the correct object while disambiguating functionally competing alternatives and abstaining when no suitable object exists. The proposed CompassNet leverages a Uni3D point encoder (512-dimensional features) and a RoBERTa text encoder. The Instance-bounded Cross Injection (ICI) module first groups points into instance-specific functional regions via radius-graph connected components. Cross-attention between these region features and query tokens occurs only within the same object instance, preventing semantic diffusion across objects. The enhanced region features are then propagated back to points via gated inverse-distance weighting to amplify query-relevant activations. The Bi-level Contrastive Refinement (BCR) module adds two contrastive losses: TG-Softmax aligns text features with region representations weighted by affordance coverage, while TP-HardNeg ensures positive affordance points are more similar to the query than the hardest negative points within a batch. The total loss combines a heatmap loss with region relevance and the two contrastive terms. Training uses AdamW with differentiated learning rates and a batch size of 96 for 15 epochs.

## Key Results
- CompassNet reaches an aIoU of 18.20 on Test-Seen and 15.36 on Test-Unseen, surpassing prior work by 4.02 and 3.54 respectively.
- The method demonstrates improved discrimination in confusing pairs, validated through an ablation study that shows both ICI and BCR contribute significant gains.
- Real-world robotic experiments confirm that the model can guide grasping of the intended object using only monocular RGB input in cluttered scenes.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Instance-bounded Cross Injection (ICI) prevents cross-object semantic leakage by constraining language-geometry interactions within object boundaries.
- **Mechanism:** ICI first groups points into instance-specific functional regions via radius-graph connected components. Cross-attention between these region features and query tokens occurs only within the same object instance, preventing query semantics from diffusing across objects. Enhanced region features are then propagated back to points via gated inverse-distance weighting, amplifying query-relevant activations while suppressing irrelevant ones.
- **Core assumption:** Object instances are reasonably separable in 3D space; instance grouping can accurately delineate object boundaries.
- **Evidence anchors:**
  - [abstract] "Instance-bounded Cross Injection (ICI) constrains language-geometry alignment within object boundaries to prevent cross-object semantic leakage."
  - [section 4.1] Describes instance-bounded grouping, region-language cross-attention restricted to same-instance regions, and gated propagation.
  - [corpus] Neighbors focus on single-object or unambiguous scene affordance; none explicitly address cross-object leakage in confusing pairs, indicating this is a novel constraint.
- **Break condition:** Under severe occlusion or tight stacking, instance grouping may merge multiple objects, violating the boundary constraint and allowing semantic leakage.

### Mechanism 2
- **Claim:** Bi-level Contrastive Refinement (BCR) sharpens discrimination between confusable surfaces by imposing contrastive supervision at region and point granularities.
- **Mechanism:** BCR uses two losses: (1) TG-Softmax aligns text features with region representations weighted by affordance coverage, pulling regions matching the query closer; (2) TP-HardNeg ensures positive affordance points are more similar to text than the hardest negative points within a batch, explicitly challenging ambiguous point-level activations.
- **Core assumption:** Confusable objects share geometrically similar surfaces; multi-level contrastive signals can disentangle them based on subtle functional region differences.
- **Evidence anchors:**
  - [abstract] "Bi-level Contrastive Refinement (BCR) enforces discrimination at both geometric-group and point levels, sharpening distinctions between target and confusable surfaces."
  - [section 4.2] Details TG-Softmax for region-text alignment and TP-HardNeg for point-level hard negative mining.
  - [corpus] Related affordance works use standard segmentation losses; contrastive learning for multi-object disambiguation is not evident in the retrieved neighbors.
- **Break condition:** If confusing pairs are visually and geometrically indistinguishable (e.g., identical tools), region and point features may lack sufficient discriminatory signal even with contrastive losses.

### Mechanism 3
- **Claim:** Query-dependent instance selection emerges from the combination of boundary-aware grounding and multi-granularity discrimination.
- **Mechanism:** ICI isolates candidate objects via instance grouping, allowing the model to compute object-query correlations without interference. BCR then refines within each object by enhancing regions/points consistent with the query. The final affordance map inherits the object mask of the highest-correlated instance, effectively selecting the target object solely from implicit intent.
- **Core assumption:** Intent-driven queries contain sufficient semantic cues to differentiate between functionally competing objects when combined with geometric context.
- **Evidence anchors:**
  - [section 3.1] Formalizes task: predicting query-dependent affordance mask on correct object among confusing pairs.
  - [section 5.2] Qualitative results show different queries on same scene activate different objects (e.g., chair seat vs. bed surface).
  - [corpus] Corpus neighbors assume explicit object names or unique affordance; CompassAD’s implicit intent setting is not covered.
- **Break condition:** If the query is underspecified (e.g., "use this") or multiple objects fully satisfy the intent with identical functional parts, the model cannot reliably select a single target.

## Foundational Learning

### Concept: Instance Segmentation in 3D Point Clouds
- **Why needed here:** ICI relies on accurate instance grouping to enforce boundary constraints. Without grouping points into correct objects, cross-modal interactions cannot be properly bounded.
- **Quick check question:** How would radius-graph connected components fail to separate instances in a scene with tightly packed objects?

### Concept: Multimodal Contrastive Learning
- **Why needed here:** BCR uses contrastive objectives to force the model to learn fine-grained distinctions between confusable regions/points, which standard regression losses may not achieve.
- **Quick check question:** Why is a hard-negative point-level contrastive loss (TP-HardNeg) necessary beyond a region-level loss (TG-Softmax)?

### Concept: Implicit Intent Grounding
- **Why needed here:** The task requires mapping natural language intent (e.g., "cut the apple") to the correct object without explicit category names, relying on contextual and functional understanding.
- **Quick check question:** What makes "prepare thin vegetable slices" disambiguate knife from scissors better than simply "cut"?

## Architecture Onboarding

### Component map
Uni3D point encoder → point features; RoBERTa text encoder → query tokens. ICI: instance grouping (radius-graph) → region pooling → region-language cross-attention (within same instance) → gated region-to-point propagation → query-enhanced point features. BCR: text adapter, region & point projectors → TG-Softmax (region-text contrast) & TP-HardNeg (point-text contrast). Final loss combines heatmap loss, group relevance loss, TG loss, TP loss.

### Critical path
1. Input point cloud → Uni3D → per-point features F.
2. Text query → RoBERTa → text tokens T.
3. F + instance IDs → ICI: group points into regions → region features G → cross-attention with T → enhanced regions Ĝ → propagate to points → query-enhanced point features F'.
4. F' + T → BCR: compute region/point similarities → apply TG-Softmax and TP-HardNeg contrastive losses.
5. Final affordance prediction from F' (supervised with heatmap loss).

### Design tradeoffs
- **ICI grouping vs. flexibility:** Radius-graph is simple and fast but brittle under occlusion or poor point density. Assumes objects are spatially separated; fails for stacked items.
- **BCR computational cost:** Adds two projection heads and contrastive computations during training but zero inference overhead (loss-only). Tradeoff: longer training time for better discrimination.
- **Background token:** Absorbing query-irrelevant attention prevents forced alignment but may dilute signal if too many non-affordance regions exist.

### Failure signatures
- **Cross-object leakage:** Model activates affordance on wrong object in confusing pair (e.g., scissors blade for "cut apple" query). Evidenced by ablation (w/o ICI causes aIoU drop).
- **No activation on valid queries:** Model predicts near-zero affordance for scenes where target exists, often when query semantics are not captured.
- **Over-activation on negative queries:** Model hallucinates affordance on no-object scenes, indicating failure to abstain.
- **Occlusion sensitivity:** Poor instance grouping merges objects, breaking ICI’s boundary assumption.

### First 3 experiments
1. **Ablation study:** Remove ICI or BCR components to validate contributions. Key check: Does removing ICI cause more cross-object errors? Does removing TG-Softmax or TP-HardNeg degrade discrimination?
2. **Seen vs. Unseen query split:** Evaluate language generalization. Key check: Does performance drop significantly on Unseen queries? If yes, model may overfit to query phrasing rather than semantic intent.
3. **Real-world robotics deployment:** Test on monocular RGB input with partial-view point clouds. Key check: Does affordance prediction remain accurate enough to guide grasping in confusing scenes? Failure indicates synthetic-to-real gap or reliance on complete geometry.

## Open Questions the Paper Calls Out

### Open Question 1
- **Question:** To what extent can intent-driven 3D affordance grounding resolve ambiguities in scenes with functionally competing objects beyond the controlled setting of CompassAD?
- **Basis in paper:** The paper explicitly poses: "Can we achieve 3D affordance grounding in cluttered multi-object scenes with implicit intents?" and introduces CompassAD/CompassNet as a first solution.
- **Why unresolved:** The task is newly formalized and evaluated on a curated benchmark with predefined confusing pairs and spatial arrangements; real-world scenes may exhibit greater clutter, dynamic layouts, and unseen object-affordance associations not captured in the current dataset.
- **What evidence would resolve it:** Evaluation on more diverse, in-the-wild multi-object scenes (e.g., homes, workplaces) with arbitrary co-occurrences and natural language instructions, measuring generalization to novel confusing pairs and spatial configurations not seen during training.

### Open Question 2
- **Question:** How can instance segmentation be made robust to severe occlusion or tight stacking of objects, where the current instance-bounded grouping fails?
- **Basis in paper:** The limitation section states: "our method assumes object instances are reasonably separable in 3D space. Under severe occlusion or tight stacking, instance-bounded grouping may span multiple objects, weakening the boundary constraints that ICI relies on."
- **Why unresolved:** The proposed ICI module critically depends on accurate instance boundaries to prevent cross-object semantic leakage; failure under occlusion leads to ambiguous affordance grounding.
- **What evidence would resolve it:** A modified ICI module that incorporates occlusion reasoning (e.g., through completion, multi-view fusion, or learned grouping) evaluated on a synthetically or real-world occluded version of CompassAD with performance metrics under varying occlusion degrees.

### Open Question 3
- **Question:** Can the benchmark and model scale to a broader, more diverse taxonomy of affordance types and object categories beyond those inherited from existing datasets?
- **Basis in paper:** The authors note: "the object and affordance categories in CompassAD are bounded by existing 3D affordance datasets. Leveraging generative 3D models to synthesize diverse scenes beyond current annotations is a promising direction for future work."
- **Why unresolved:** CompassAD covers 16 affordance types and 105 object categories limited by prior dataset annotations; real-world functionality is far richer and may involve novel affordances or object combinations not represented.
- **What evidence would resolve it:** An extended benchmark incorporating generative data (e.g., via text-to-3D models) for rare or novel affordance-object pairs, with experiments showing whether CompassNet or an upgraded version can generalize zero-shot to these new categories.

### Open Question 4
- **Question:** Does the method's reliance on geometric similarity for discriminating confusing pairs limit its applicability to pairs that share affordances but have minimal shape resemblance?
- **Basis in paper:** The design of BCR emphasizes "sharpening distinctions between target and confusable surfaces" and the confusing pairs are selected to be "visually or geometrically similar." This suggests an implicit assumption that geometric cues are primary for disambiguation.
- **Why unresolved:** In some scenarios, functionally competing objects may look dissimilar (e.g., a 'chair' and a 'stool' both affording sitting but with different structures); the current contrastive learning may overfit to geometric patterns and fail when geometry is less discriminative than contextual or semantic cues.
- **What evidence would resolve it:** Ablation studies on a hold-out set of confusing pairs with low shape similarity (e.g., measured by shape descriptors) but identical affordance types, comparing performance against pairs with high similarity to quantify the drop and identify needed architectural adjustments (e.g., stronger language grounding, context integration).

## Limitations
- Exact hyperparameters (loss weights, temperatures, coverage exponent, grouping radius, etc.) are not provided, blocking faithful replication of training dynamics.
- Instance grouping via radius-graph connected components fails under heavy occlusion or tight stacking, violating the boundary assumption of ICI.
- Real-world robotic deployment is only qualitatively demonstrated; systematic quantitative evaluation and analysis of the sim-to-real gap are lacking.

## Confidence
- **ICI boundary constraint:** Medium confidence. Ablation shows a ~3 aIoU drop without ICI, supporting its role, but dependence on accurate instance segmentation and lack of occlusion robustness reduce certainty.
- **BCR multi-granular discrimination:** Medium confidence. Contrastive losses yield clear gains in ablations, yet hyperparameter sensitivity and generalizability to unseen affordance types remain open.
- **SOTA performance on CompassAD:** High confidence. Consistent improvements on both seen and unseen splits are reported, though external validation on other datasets is needed.
- **Real-world robotic grasping:** Low confidence. Only a few demo scenes are shown; no systematic success rates or failure mode analysis are provided.

## Next Checks

2. **Occlusion Stress Test:** Create controlled versions of CompassAD with synthetic occlusions/stacking; measure ICI grouping accuracy and resulting aIoU to quantify failure thresholds.
3. **Cross-Dataset Generalization:** Apply the trained CompassNet (with original hyperparameters) to a public affordance grounding dataset (e.g., WorldAfford) without fine-tuning; evaluate transfer performance to check overfitting to CompassAD.
