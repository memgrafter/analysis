# Topological descriptors of foot clearance gait dynamics improve differential diagnosis of Parkinsonism

## Quick Facts
- arXiv ID: 2603.06212
- Source URL: https://arxiv.org/abs/2603.06212
- Reference count: 29
- Primary result: Topological features (Betti curves) achieved 83% accuracy and an AUC of 0.89 for distinguishing idiopathic Parkinson's disease (IPD) from vascular Parkinsonism (VaP) in the medicated state.

## Executive Summary
This study presents a novel application of Topological Data Analysis (TDA) to foot clearance gait dynamics to differentiate idiopathic Parkinson's disease (IPD) from vascular Parkinsonism (VaP). By extracting topological descriptors—Betti curves, persistence landscapes, and silhouettes—from time-delay embedded foot clearance time series, and using them as features for a Random Forest classifier, the authors achieved high accuracy. In the medicated state, Betti curves alone yielded 83% accuracy and an AUC of 0.89. The method's sensitivity to levodopa and improvement with multiple gait variables underscore its ability to capture medication-modulated nonlinear gait patterns beyond traditional linear metrics.

## Method Summary
The pipeline transforms each foot clearance variable (e.g., minimum toe clearance, maximum heel strike) into a topological signature via persistent homology. First, a one-dimensional gait time series is embedded into a two-dimensional point cloud using Takens' delay embedding with dimension 2 and delay 1. Second, Vietoris-Rips filtration computes the birth and death of topological features (connected components H0 and loops H1) across scales, producing persistence diagrams. Third, Betti curves—counting features as a function of filtration scale—are extracted on a 25-point grid for H0 and H1 separately and concatenated into a 50-dimensional vector per variable. For multi-variable classification, these vectors are concatenated. Finally, a Random Forest classifier is trained using leave-one-out cross-validation (LOOCV) to distinguish IPD from VaP. The study evaluates performance on data from 15 IPD, 14 VaP, and 15 controls, both off and on medication.

## Key Results
- Using Betti curves from a single foot clearance variable (MinTC or MaxTLSW), the classifier achieved up to 0.89 AUC for IPD vs VaP in the medicated state.
- Combining multiple variables (e.g., MinTC + MaxTLSW) further improved performance, with AUC 0.89 in On state and 0.76 in Off state.
- Topological features showed sensitivity to levodopa: classification performance was significantly better in the On state compared to Off, indicating medication-induced reorganization detectable topologically.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Topological descriptors from persistent homology capture nonlinear structural patterns in foot clearance time series that are discriminative for Parkinsonism subtypes but invisible to conventional linear gait metrics.
- **Mechanism:** Time-delay embedding (d=2) transforms 1D signals into 2D point clouds. Vietoris-Rips filtration tracks the birth/death of H0 (connected components) and H1 (loops) across a scale parameter. Betti curves summarize the count of persistent features per homology dimension as a function of filtration scale, encoding how gait dynamics evolve.
- **Core assumption:** Pathological gait dynamics (IPD vs VaP) produce measurably different topological "shapes" in reconstructed phase space (e.g., loop structures indicating rhythmic patterns, component counts indicating stability) that are robust to stride-to-stride variability.
- **Evidence anchors:** The paper reports 83% accuracy and AUC 0.89 using Betti curves; section 2.2.1 defines Betti curves formally.
- **Break condition:** If foot clearance time series have insufficient temporal resolution (<~30 observations per cycle) or excessive noise, the d=2 embedding may fail to reconstruct meaningful topology, causing descriptors to reflect noise.

### Mechanism 2
- **Claim:** Combining topological descriptors from multiple foot clearance variables improves discrimination because each variable encodes complementary biomechanical constraints affected differently by the underlying pathologies.
- **Mechanism:** IPD (dopaminergic deficit) and VaP (cerebrovascular lesions) disrupt distinct phases of gait (e.g., mid-swing vs late swing). Concatenating Betti curve vectors from variables like MinTC (minimum clearance during mid-swing) and MaxTLSW (peak clearance in late swing) creates a higher-dimensional topological signature where discriminative patterns are distributed.
- **Core assumption:** The pathological "topological fingerprint" is multi-dimensional; some dimensions are more salient in one subtype than the other.
- **Evidence anchors:** Section 4.2 shows combinations (MinTC+MaxTLSW) outperform single variables (Off AUC 0.76 → On AUC 0.89).
- **Break condition:** If both subtypes affect all foot clearance variables similarly (e.g., globally reduced clearance), concatenation adds noise without separation.

### Mechanism 3
- **Claim:** The framework is sensitive to levodopa because topological features capture medication-induced reorganization of gait dynamics, which differ between IPD (strong response) and VaP (weak response).
- **Mechanism:** Levodopa normalizes basal ganglia output in IPD, leading to more regular phase space trajectories (fewer fragmented H0 components, more persistent H1 loops). In VaP, non-dopaminergic damage limits this reorganization. Betti curves quantify these changes in persistence profiles.
- **Core assumption:** Dopamine-responsive reorganization manifests as a change in the multiscale topological structure, not merely mean/variance shifts.
- **Evidence anchors:** Abstract and section 5.2 explicitly state that medication-induced changes extend beyond amplitude to include nonlinear structure and variability.
- **Break condition:** If a patient subset shows atypical levodopa responses (e.g., VaP responder, IPD non-responder), the topological shift may not align with clinical subtype, reducing diagnostic accuracy unless individual response is modeled.

## Foundational Learning

- **Concept: Time-Delay Embedding (Takens' Theorem)**
  - *Why needed here:* The 1D foot clearance time series is embedded into a higher-dimensional point cloud (d=2) to reconstruct the system's phase space dynamics, a prerequisite for persistent homology.
  - *Quick check:* Why is d=2 chosen instead of a higher dimension? (Because the gait cycle has ~36 strides; higher d would require exponentially more data to avoid sparsity.)

- **Concept: Persistent Homology (Vietoris-Rips Filtration)**
  - *Why needed here:* Computes the birth/death of topological features (connected components, loops) across a filtration scale, producing persistence diagrams from which Betti curves are derived.
  - *Quick check:* What does a long-persistence H1 feature likely represent? (A robust cyclic pattern in the dynamics, e.g., a consistent stride-to-stride loop.)

- **Concept: Random Forest with Leave-One-Out Cross-Validation (LOOCV)**
  - *Why needed here:* The small cohort (n≈29) requires a robust validation strategy; LOOCV maximizes training data per fold. Random Forest handles high-dimensional, correlated topological feature vectors without strong distributional assumptions.
  - *Quick check:* Why not use logistic regression? (Because topological descriptors may have complex non-linear interactions; RF captures these without manual engineering.)

## Architecture Onboarding

**Component map:** Foot clearance time series -> TakensEmbedding(d=2, τ=1) -> VietorisRipsFiltration -> PersistenceDiagram -> BettiCurve(n_bins=25) -> FeatureConcatenation (per variable or multi-variable) -> RandomForestClassifier -> LOOCV evaluation.

**Critical path:** Time series → Embedding → Persistence → Betti Curve → Feature aggregation → Random Forest → LOOCV. The descriptor extraction (embedding, persistence, curve) is the novel module.

**Design tradeoffs:**
- **BC vs PL/SL:** Betti curves chosen for robustness on shorter/noisier series; persistence landscapes and silhouettes offer finer multiscale detail but may overfit on small datasets. Tradeoff: stability vs sensitivity.
- **Embedding parameters:** Fixed d=2, τ=1 for all variables; tradeoff: generality vs optimal per-variable tuning (tuning may overfit).
- **Feature aggregation:** Concatenation assumes additive contributions; could explore weighted combinations or variable selection.
- **Classifier:** Random Forest chosen for interpretability and small-data performance; may not capture complex interactions as well as deep networks.

**Failure signatures:**
- **Low persistence values:** All Betti curve values near zero across scales → likely failed embedding or meaningless data.
- **High variance in LOOCV:** Unstable performance across left-out subjects → indicates poor feature generalizability or subgroup effects.
- **Descriptor mismatch:** Persistence landscapes/silhouettes performing catastrophically (AUC ~0.11) → too noise-sensitive for ~36-point series.
- **No medication effect:** No performance difference between Off/On → topological features insensitive to levodopa; re-check state labeling or extraction.

**First 3 experiments:**
1. Replicate single-variable Betti curve classification for each foot clearance variable in the On state; confirm AUC >0.9 for CO vs PD and >0.75 for IPD vs VaP.
2. Test embedding dimension sensitivity (d=2,3,4) for the best variable (MinTC or MaxTLSW); expect d=2 to be optimal or most stable given the short series.
3. Validate levodopa sensitivity contrast: for the top IPD/VaP classifier (e.g., MinTC Betti curves), compare Off vs On performance using a paired test (e.g., Wilcoxon signed-rank on LOOCV predictions per subject); expect significant improvement in On state.

## Open Questions the Paper Calls Out

1. **Generalization to larger and more diverse populations:** The study's small sample (15 IPD, 14 VaP, 15 controls) and lack of external validation limit generalizability. Resolution requires multi-center validation with hundreds of participants across demographics and disease stages.
2. **Alternative TDA descriptors:** The study focused on Betti curves, persistence landscapes, and silhouettes; other topological representations like persistence images or persistence entropy might improve discrimination. Resolution: extract and compare those descriptors on the same dataset.
3. **Intra-individual levodopa variability:** Group-level analysis only; individual heterogeneity in levodopa response and its effect on topological features remain unknown. Resolution: longitudinal within-subject studies correlating topological changes with clinical response measures.
4. **Differentiation of other parkinsonian syndromes:** The pipeline was only tested for IPD vs VaP; applicability to other syndromes (e.g., MSA, PSP) is unclear. Resolution: collect data from those syndromes and evaluate classification performance.

## Limitations

- Small cohort (n=29) with limited statistical power and high risk of overfitting.
- Proprietary sensor preprocessing (Physilog®) prevents exact replication.
- No external validation; reported performance may be dataset-specific.

## Confidence

- **TDA captures discriminative nonlinear patterns:** Medium (strong internal LOOCV but small sample, no external validation).
- **Multi-variable combinations improve discrimination:** Medium (reported gains without statistical testing; concatenation may overfit).
- **Sensitivity to levodopa:** Medium (group-level improvement but potential confounders; no individual responder analysis).

## Next Checks

1. **Embedding parameter sensitivity:** Vary Takens embedding dimension (d=2–4) and delay (τ=1–2) on the existing dataset; assess stability of IPD/VaP classification AUC.
2. **Benchmark against standard nonlinear features:** Extract sample entropy, detrended fluctuation analysis, and Poincaré metrics from the same foot clearance series; compare performance using identical Random Forest/LOOCV.
3. **External replication:** Apply the exact Betti curve pipeline (d=2, τ=1, 25 bins, Random Forest) to an independent Parkinson’s gait dataset (e.g., mPower); expect AUC >0.75 if findings generalize.
