# TACIT: Transformation-Aware Capturing of Implicit Thought

## Quick Facts
- **arXiv ID:** 2602.07061
- **Source URL:** https://arxiv.org/abs/2602.07061
- **Reference count:** 21
- **Primary result:** TACIT uses rectified flow in pixel space to solve mazes with 10 deterministic Euler steps, achieving a 192× loss reduction and 22.7× L2 improvement, and exhibits a sharp phase transition with 100% simultaneous solution emergence.

## Executive Summary
TACIT introduces a diffusion transformer framework for language-free visual reasoning, specifically maze-solving, by directly transforming unsolved maze images into solved ones in pixel space via rectified flow. Trained on 1 million synthetic maze pairs, it dramatically outperforms baselines in training efficiency (192× loss reduction) and solution accuracy (22.7× L2 improvement) while requiring only 10 deterministic inference steps. Crucially, analysis of the transformation dynamics reveals a sharp phase transition: the solution remains invisible for the first 68% of the process and then emerges abruptly and simultaneously across all spatial regions within a 2% window (t=0.70–0.72). This simultaneous emergence rules out sequential path construction and suggests a holistic reasoning mechanism akin to human insight. The work demonstrates that carefully designed diffusion models can capture interpretable, gestalt-like reasoning in visual tasks.

## Method Summary
TACIT is a diffusion transformer (DiT) trained on 64×64 RGB maze image pairs (unsolved → solved). The training objective uses rectified flow: for a pair (x₀, x₁) and timestep t∼U[0,1], the interpolated state xₜ = (1−t)x₀ + t x₁ is input to the model, which predicts the velocity v = x₁ − x₀. The loss is MSE between predicted and target velocity. The architecture comprises patch embedding (convolution with stride 8), 2D sinusoidal positional encodings, timestep embedding (sinusoidal + MLP), and 8 transformer blocks with adaptive layer normalization (adaLN) conditioning on the timestep. At inference, deterministic Euler integration over 10 steps (Δ t=0.1) transforms x₀ into x₁. The dataset consists of 1M pairs generated via randomized DFS for maze layouts and BFS for shortest paths, spanning five logical grid sizes (11–31). Minimum viable reproduction involves implementing the dataset generator, building the exact model, training with Adam (LR=1e-4, batch 256) for 100 epochs, and validating loss reduction and the emergence pattern. Key unknowns include the learning rate schedule and the exact distribution of maze sizes.

## Key Results
- 192× reduction in training loss and 22.7× improvement in L2 distance to ground truth compared to baselines.
- Inference requires only 10 deterministic Euler steps; with 5 steps it already achieves >0.96 IoU.
- Sharp phase transition: solution invisible for t < 0.68, then 100% of path pixels appear simultaneously within t=0.70–0.72 (2% width), ruling out sequential construction.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Rectified flow enables deterministic inference with interpretable intermediate states by eliminating stochastic noise injection.
- **Mechanism:** The model learns a velocity field that directly transforms the problem image to the solution image along a linear interpolation path. During inference, Euler integration follows this deterministic path, producing clean intermediate images that represent meaningful transformations rather than noisy permutations.
- **Core assumption:** Operating in pixel space with rectified flow preserves discrete structural information (e.g., wall boundaries) and yields linearly interpretable trajectories.
- **Evidence anchors:**
  - [abstract]: "operates entirely in pixel space using rectified flow, enabling direct visualization of the reasoning process at each inference step. Only 10 Euler steps required, far fewer than typical diffusion models."
  - [section 3.2]: "Rectified flow eliminates stochastic noise injection, making the transformation deterministic and the intermediate states meaningful rather than noisy. The intermediate state x_t is a clean blend of input and output."
  - [corpus]: Weak evidence; neighbor papers discuss tacit knowledge in human-AI interaction but not flow matching mechanics.
- **Break condition:** If noise is reintroduced (e.g., via DDPM-style diffusion), intermediate states become semantically void, and inference requires many more steps for denoising.

### Mechanism 2
- **Claim:** A sharp phase transition with 100% simultaneous solution emergence across all spatial regions indicates holistic gestalt perception rather than sequential algorithmic construction.
- **Mechanism:** The transformer's self-attention mechanism from the first layer allows all patch tokens to interact globally. The learned velocity field encodes a global structural relationship between entrance and exit, causing the solution path to crystallize atomically at a critical timestep (t≈0.70) rather than growing incrementally.
- **Core assumption:** That simultaneous emergence across all path segments rules out any form of sequential or local-first processing (e.g., BFS/DFS).
- **Evidence anchors:**
  - [abstract]: "solution remained invisible for 68% of the transformation (t < 0.68), then emerged abruptly and simultaneously across all spatial regions within 2% of the process (t = 0.70–0.72). This 100% simultaneous emergence rules out sequential path construction."
  - [section 6.3]: "100% of samples (20/20) exhibit simultaneous emergence—all path segments appear at the same timestep t* = 0.70. This pattern... suggests the model has learned to see maze solutions as complete patterns that 'pop out' rather than being traced step by step."
  - [corpus]: No direct evidence; corpus neighbors focus on tacit knowledge elicitation, not phase transitions in neural dynamics.
- **Break condition:** If solution pixels appear in a spatially sequential order (e.g., from entrance outward), it would indicate algorithmic reasoning instead of holistic perception.

### Mechanism 3
- **Claim:** Bilateral learning with equal salience for maze endpoints enables efficient parallel credit assignment, avoiding the computational cost of sequential search.
- **Mechanism:** The architecture lacks a privileged starting point; entrance and exit are treated symmetrically due to global attention. The model learns the solution as a holistic topological relationship, allowing gradient signals to propagate simultaneously across all path pixels during training, accelerating convergence.
- **Core assumption:** That this circular world model (no inherent directionality) reduces learning complexity compared to directional search algorithms.
- **Evidence anchors:**
  - [section 5.5]: "The model appears to learn solutions bilaterally—perceiving the entire maze simultaneously rather than constructing paths sequentially from entrance. The model’s implicit world model appears almost circular: beginning and end are poorly defined, and the solution exists as a holistic relationship between them."
  - [section 7.3]: "The holistic perception that characterizes the trained model... is architecturally enabled but experientially acquired. The attention mechanism provides the capacity for global perception, but the skill emerges through exposure."
  - [corpus]: Assumption based on analogy to human expertise in neighbor papers (e.g., "Demystifying Tacit Knowledge in Graphic Design"); no direct empirical evidence.
- **Break condition:** If the model shows directional bias (e.g., solutions consistently initiate from the entrance), it would indicate sequential processing rather than bilateral perception.

## Foundational Learning
- **Concept:** Flow Matching / Rectified Flow  
  - *Why needed here:* It defines the training objective that maps problem to solution states via a deterministic velocity field, enabling noise-free intermediate representations.  
  - *Quick check:* How does rectified flow's linear interpolation (x_t = (1-t)x_0 + t x_1) differ from diffusion's noising process, and why does this matter for interpretability?
- **Concept:** Diffusion Transformers (DiT)  
  - *Why needed here:* The backbone architecture that processes image patches with self-attention, enabling global spatial reasoning for transformation tasks.  
  - *Quick check:* What is the role of adaptive layer normalization (adaLN) in conditioning the transformer on the continuous timestep t?
- **Concept:** Phase Transitions in Dynamical Systems  
  - *Why needed here:* To interpret the abrupt solution emergence (t=0.70) as a computational analog of cognitive insight, implying a fundamental shift in the model's internal state.  
  - *Quick check:* What does a transition width of just 2% (from 0 to 99.6% recall) suggest about the smoothness of the learned flow?

## Architecture Onboarding
- **Component map:** Input image (64×64×3) → patch embedding (convolution to 64×384 tokens) → add 2D sinusoidal positional encodings → concatenate timestep embedding (sinusoidal + MLP to 384-dim) → 8 transformer blocks (each: adaLN → multi-head self-attention, 6 heads, 64 dim → adaLN → MLP, 1536 dim) → final adaLN → linear projection to pixels (384→192 per patch) → reshape to image → velocity output.
- **Critical path:** Image tokenization → position + timestep injection → transformer feature extraction → velocity prediction → Euler integration (10 steps) from x_0 to x_1.
- **Design tradeoffs:**
  - Pixel space vs. latent space: Pixel space chosen for direct interpretability; latent space would offer compression but require decoders for visualization.
  - Rectified flow vs. DDPM: Rectified flow provides deterministic, straight trajectories; DDPM offers flexible paths but with noisy intermediates requiring many steps.
  - Euler steps: 10 steps balance efficiency and accuracy; fewer steps risk undersampling, more steps improve pixel precision with diminishing returns.
- **Failure signatures:**
  - No phase transition: gradual, linear increase in solution recall across timesteps.
  - Sequential emergence: path pixels appearing in order from entrance to exit in intermediate states.
  - High training loss (>1e-4 after 100 epochs) or poor L2 distance (>0.01) indicating failure to learn transformation.
  - Artifacts: intermediate states show disconnected path fragments, wall corruption, or color bleeding.
- **First 3 experiments:**
  1. Train on 10,000 maze pairs for 5 epochs; verify loss drops by at least 10× and visualize 3 inference trajectories for solution emergence pattern.
  2. Ablate Euler steps (1, 5, 10, 20) on 20 held-out mazes; measure IoU and PSNR to confirm 5 steps yield >0.96 IoU.
  3. Segment solution paths into start/middle/end regions; compute first-appearance timesteps to validate 100% simultaneous emergence (t* variance ≈0).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Can TACIT's flow matching framework be successfully applied to other visual reasoning benchmarks (e.g., Raven's Progressive Matrices, ARC challenges) and exhibit similar interpretable reasoning dynamics, such as the sharp phase transition and simultaneous emergence?
- **Basis in paper:** [explicit] In the Future Directions section (Section 7.7), the authors propose testing "Alternative Domains" by applying TACIT to other visual reasoning benchmarks (RAVEN, ARC) to assess the generality of flow matching for reasoning tasks.
- **Why unresolved:** The current evaluation is limited exclusively to maze-solving, a specific type of spatial path planning. It remains unknown whether the observed phenomena—particularly the eureka-like phase transition and holistic emergence—are unique to mazes or reflect a general computational principle of visual reasoning.
- **What evidence would resolve it:** Train TACIT on RAVEN and ARC datasets using identical hyperparameters and architecture. During inference, record intermediate states and analyze for presence of phase transitions (onset time, transition width) and simultaneous emergence across spatial regions. Compare these metrics to those obtained on mazes; if similar patterns persist, it would support generality.

### Open Question 2
- **Question:** How can we define and measure solution validity beyond pixel-level error, ensuring that generated paths are structurally correct (connected, wall-free, optimal)?
- **Basis in paper:** [explicit] The Limitations section (7.6) states: "Evaluation Metrics. While L2 distance captures pixel-level accuracy, it may not fully reflect solution validity. Future work should incorporate path verification metrics (connectivity, correctness)."
- **Why unresolved:** L2 distance can be low even if the predicted solution is invalid (e.g., path disconnected, crossing walls, or not shortest). Without proper verification metrics, it is difficult to assess true reasoning quality or compare models fairly.
- **What evidence would resolve it:** Develop and standardize path verification metrics: (1) connectivity check (does the red path connect entry and exit without broken segments?), (2) validity check (does the path stay within traversable cells and avoid walls?), and (3) optimality check (is it the shortest path?). Integrate these into evaluation and correlate with L2. Benchmark multiple models including TACIT to establish a more comprehensive assessment.

### Open Question 3
- **Question:** How does scaling up image resolution and model capacity affect TACIT's performance, efficiency, and the observed phase transition characteristics?
- **Basis in paper:** [explicit] Section 7.6 lists "Scale" as a limitation: "The 64×64 resolution and relatively small model (50M parameters) limit complexity. Scaling to larger images and models may reveal additional capabilities or limitations."
- **Why unresolved:** The maze-solving demonstrations are confined to small 64x64 images and a 20M parameter model. It is unclear whether the efficiency (10 Euler steps), the silent phase duration (68%), and the simultaneous emergence persist at larger scales, or if new phenomena emerge (e.g., longer phase transitions, need for more steps).
- **What evidence would resolve it:** Train TACIT on higher resolution mazes (e.g., 128x128, 256x256) with proportionally increased model sizes (e.g., 4×, 16× parameters). Measure training loss, L2, number of Euler steps needed for high IoU, and phase transition metrics (onset time, width). Compare to base model to determine scaling trends.

### Open Question 4
- **Question:** Does training TACIT to also perform the reverse transformation (solution → problem) yield a bidirectional understanding that could enhance robustness or provide symmetrical reasoning patterns?
- **Basis in paper:** [explicit] Future Directions (Section 7.7) includes "Bidirectional Flow: Training the reverse direction (solution→problem) would test whether the model learns genuine bidirectional understanding rather than unidirectional mapping."
- **Why unresolved:** The current model is trained solely on forward transformation (unsolved → solved). Without reverse training, we do not know if the learned representation is asymmetric or if bidirectional training could improve generalisation or reveal additional structure (e.g., the reverse might also show a phase transition).
- **What evidence would resolve it:** Train a TACIT model on paired data in both directions (i.e., use both (x0, x1) and (x1, x0) during training). Alternatively, train separate forward and reverse models. Evaluate both directions on held-out mazes, comparing accuracy, sample efficiency, and inference dynamics (phase transition properties). Symmetry in performance and dynamics would indicate bidirectional understanding.

### Open Question 5
- **Question:** What hierarchical representations are learned by TACIT's transformer blocks, and how do they correspond to the three-phase training dynamics (constraint learning, topology acquisition, precision refinement)?
- **Basis in paper:** [explicit] Future Directions (Section 7.7) states: "Probing Internal Representations: Analyzing activations at different transformer blocks could reveal hierarchical reasoning—e.g., early blocks detecting local features, later blocks integrating global path information." Additionally, Section 5.2 describes three training phases.
- **Why unresolved:** The training loss curve shows distinct phases, but we lack direct evidence linking these phases to changes in internal representations. It is hypothesized that early epochs learn constraints (walls), mid-epochs learn topology (connectivity), and late epochs refine details, but this has not been verified by probing activations.
- **What evidence would resolve it:** During training, at various checkpoints, extract activations from each transformer block for a set of mazes. Use techniques like dimensionality reduction (t-SNE, PCA), representational similarity analysis (RSA), or linear probes to characterize what information is encoded at each block. Test if early blocks primarily encode wall locations and local structure, while later blocks encode global path connectivity. Correlate these representational changes with the loss phases.

## Limitations
- Findings restricted to synthetic mazes; real-world generalizability unknown.
- Phase transition analysis based on only 20 samples; statistical robustness unproven.
- Cognitive "insight" analogy lacks behavioral or neuroscientific validation.
- Key training details (learning rate schedule, dataset distribution) omitted, hindering exact replication.

## Confidence
- **Rectified flow determinism:** High
- **Simultaneous emergence as holistic reasoning:** Medium
- **Bilateral learning/circular world model:** Low
