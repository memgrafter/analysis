# Detecting Hallucinations in Retrieval-Augmented Generation via Semantic-level Internal Reasoning Graph

## Quick Facts
- **arXiv ID:** 2601.03052
- **Source URL:** https://arxiv.org/abs/2601.03052
- **Reference count:** 40
- **Primary result:** Achieves F1 scores of 76.61% and 81.84% on RAGTruth (Llama-7B/13B) with +3.07% / +5.78% SOTA gains; reaches 82.17% and 89.71% on Dolly-15k (Qwen2.5-3B/7B), outperforming LRP4RAG.

## Executive Summary
This paper tackles faithfulness hallucinations in retrieval-augmented generation (RAG), where outputs conflict with provided context despite being factually correct. The authors extend layer-wise relevance propagation (LRP) to the semantic level, constructing an internal reasoning graph from attribution vectors between contextual and response semantic fragments. A lightweight pre-trained language model (ALIGNSCORE) classifies each fragment’s fidelity, and a dynamic threshold decides if the response is hallucinated. Evaluations on RAGTruth and Dolly-15k show consistent state-of-the-art improvements, and perturbation tests indicate the graph captures model reasoning faithfully.

## Method Summary
The method first decomposes the retrieved context and the generated response into semantic fragments. It then applies LRP at the embedding level to compute attribution vectors that quantify how each context fragment contributes to each response fragment. These attributions are aggregated to form a reasoning graph where edges represent influence strengths. Each response fragment is fed to ALIGNSCORE, which predicts its fidelity (faithful vs. hallucinated). A dynamic threshold, tuned on validation data, aggregates fragment-level scores to label the entire response as hallucinated or not.

## Key Results
- RAGTruth benchmarks (Llama-7B/13B): F1 scores 76.61% / 81.84%, improving over prior SOTA by 3.07% and 5.78%.
- Dolly-15k benchmarks (Qwen2.5-3B/7B): F1 scores 82.17% / 89.71%, surpassing the previous LRP4RAG method.
- Perturbation experiments (e.g., removing high‑attribution edges or shuffling fragments) significantly degrade performance, supporting the graph’s faithfulness to the model’s reasoning.

## Why This Works (Mechanism)
Semantic-level LRP provides fine‑grained attributions between meaning units rather than token‑level scores, making the reasoning process more interpretable and robust to surface variations. The graph explicitly captures cross‑references between context and response, allowing the fidelity classifier to focus on misaligned fragments. The dynamic threshold adapts to the distribution of fragment scores in each dataset, reducing sensitivity to noise. Together, these elements enable detection of subtle hallucinations that token‑level methods miss.

## Architecture Onboarding
**Component Map:**  
Context Input -> Semantic Fragment Extractor -> LRP Attribution Module -> Reasoning Graph Builder -> Fidelity Classifier (ALIGNSCORE) -> Fragment Score Aggregator -> Dynamic Threshold -> Hallucination Decision

**Critical Path:**  
Extract fragments from context & response → compute LRP attributions → construct graph → classify each response fragment → aggregate scores → apply threshold → final label.

**Design Tradeoffs:**  
- Using a fixed pretrained classifier (ALIGNSCORE) vs. training a task‑specific model: saves data & compute but may not fully adapt to RAG‑specific hallmarks.  
- Graph complexity: richer edges improve faithfulness capture but increase memory and risk of over‑fitting; authors simplify by thresholding weak edges.  
- Dynamic threshold: improves per‑dataset calibration but requires validation data and may drift on highly shifted distributions.

**Failure Signatures:**  
- Low precision when context contains noise or irrelevant passages, causing spurious high attributions.  
- ALIGNSCORE bias toward generic/over‑lapping phrases leading to false negatives on subtle hallucinations.  
- Threshold mis‑calibration on domains with notably different fragment score distributions (e.g., highly technical text).

**First Three Experiments:**  
1. **Human‑Alignment Check:** Sample reasoning graphs and ask human annotators to judge whether edges reflect plausible reasoning steps; compare against random baselines.  
2. **Layer Sensitivity:** Run LRP using different layers (early, middle, late) to study impact on graph stability and detection performance.  
3. **Threshold Sensitivity:** Vary dynamic‑threshold parameter (e.g., percentile) on held‑out data to measure robustness to small distribution shifts.

## Limitations
- The fidelity classifier’s robustness and transferability beyond the tested RAG settings remain uncertain.  
- Reported gains are specific to RAGTruth and Dolly‑15k; generalization to other models, domains, or longer generations is not established.  
- Graph faithfulness is validated indirectly via perturbations; the claim that the graph perfectly mirrors the model’s true internal reasoning is still inferential.
