# Beyond the Class Subspace: Teacher-Guided Training for Reliable Out-of-Distribution Detection in Single-Domain Models

## Quick Facts
- **arXiv ID:** 2603.11269
- **Source URL:** https://arxiv.org/abs/2603.11269
- **Reference count:** 39
- **Primary result:** Teacher-Guided Training (TGT) reduces far-OOD FPR@95 by up to 12.87 percentage points for distance-based scorers while preserving classification accuracy.

## Executive Summary
Single-domain models suffer from Out-of-Distribution (OOD) detection failures due to Domain-Sensitivity Collapse (DSC), where supervised training compresses features into a low-rank class subspace, discarding domain-shift signals. This paper proposes Teacher-Guided Training (TGT), which distills class-suppressed domain residuals from a frozen multi-domain teacher (DINOv2) into a student model during training. TGT rebalances feature variance without inference overhead, substantially improving OOD detection across eight single-domain benchmarks for distance-based scorers while maintaining in-distribution accuracy.

## Method Summary
TGT trains a student model (e.g., ResNet-50) on single-domain data using two concurrent objectives: standard classification (cross-entropy) and an auxiliary domain supervision. The domain target is derived from a frozen multi-domain teacher (DINOv2). For each input, the teacher’s features are projected onto their orthogonal complement relative to the teacher’s class-discriminative subspace (constructed from per-class means), yielding a class-suppressed residual `udom` that primarily encodes domain and style cues. An auxiliary MLP head in the student predicts this residual via a cosine similarity loss. The combined loss `L = L_CE + λ * L_domain` encourages the student to preserve class-discriminative information while enriching its representation with domain-sensitive structure in directions that would otherwise collapse. After training, the teacher and auxiliary head are discarded; the student backbone is used with any standard post-hoc OOD scorer.

## Key Results
- TGT yields substantial far-OOD FPR@95 reductions for distance-based scorers on ResNet-50: MDS by 11.61 pp, ViM by 10.78 pp, and kNN by 12.87 pp (average across eight benchmarks).
- In-domain OOD detection (held-out classes) improves modestly, but absolute FPR@95 remains high (>59% on average), indicating an unsolved challenge.
- Classification accuracy is largely preserved (±0.5%), though a notable 4.1 pp drop occurs on the fine-grained Yoga dataset.
- TGT increases effective rank (e.g., Colon: 5.2 → 12.1) and reduces variance concentration in top-(C−1) principal components, confirming geometry repair.

## Why This Works (Mechanism)

### Mechanism 1
**Claim:** Under Domain-Sensitivity Collapse (DSC), distance- and logit-based OOD scores lose sensitivity to domain shift because feature variance concentrates in a low-rank class subspace, suppressing domain cues.
**Mechanism:** Supervised single-domain training drives within-class variance toward zero, concentrating all meaningful variance into a ≤(C−1)-dimensional class-discriminative subspace. Directions orthogonal to this subspace (where domain-shift signals reside) are attenuated. Distance-based scores (MDS, kNN) are dominated by high-variance class directions, while logit-based scores (MSP, Energy) suffer from head insensitivity because the classifier’s row space aligns with the class subspace.
**Core assumption:** The dataset is single-domain (domain features are class-invariant) and the model is trained with cross-entropy, inducing neural-collapse-like geometry.
**Evidence anchors:**
- [abstract]: "supervised training compresses features into a low-rank class subspace and suppresses domain-shift signal"
- [section 3.1]: Theorem 1 formally shows that when OOD separation lies in low-variance directions, the Wasserstein distance between ID and OOD score distributions is bounded by small terms (ε + 4τ²).
- [corpus]: Related work on neural collapse [20] and representation rank collapse [12] supports the geometric premise, though DSC’s specific OOD failure mode is novel.
**Break condition:** The mechanism fails if the representation retains high effective rank (r_eff ≈ d) or within-class variance (ρ_within ≫ 0), which occurs when intra-class diversity is intrinsically high (e.g., Rock, Garbage datasets).

### Mechanism 2
**Claim:** Teacher-Guided Training (TGT) counteracts DSC by distilling class-suppressed domain residuals from a frozen multi-domain teacher, restoring domain-sensitive geometry without inference overhead.
**Mechanism:** A frozen multi-domain teacher (DINOv2) provides features that capture domain shifts but lack class discrimination for the single-domain task. TGT computes the teacher’s class-suppressed residual by projecting out its class-discriminative subspace (centered class means) and centering. An auxiliary domain head in the student predicts this residual via cosine loss, while the student also performs standard classification. This injects domain-aware structure into the student’s orthogonal complement, increasing effective rank and rebalancing variance.
**Core assumption:** The teacher’s class-discriminative subspace is well-separated from domain signals, so its residual primarily encodes domain and style cues. The student’s supervised training would otherwise suppress these cues.
**Evidence anchors:**
- [abstract]: "distills class-suppressed domain residuals from a frozen multi-domain teacher"
- [section 4.1]: Equation (7) defines udom(x) = (I − P_cls)(u(x) − µ), where P_cls projects onto the teacher’s class subspace.
- [section 5.2]: TGT increases effective rank (e.g., Colon: 5.2 → 12.1) and reduces far-OOD FPR@95 by double digits for distance-based scorers.
**Break condition:** If the teacher lacks domain diversity (e.g., trained on similar single-domain data) or if λ is too low, the residual may not provide sufficient domain signal to repair DSC.

### Mechanism 3
**Claim:** The teacher residual is approximately orthogonal to the student’s class subspace, making the classification and domain objectives complementary rather than conflicting.
**Mechanism:** The student’s supervised training drives its features into a class-aligned subspace. The teacher residual, constructed by removing the teacher’s class directions, lies in the orthogonal complement of the teacher’s class subspace. Because both models classify the same classes, their class subspaces are roughly aligned. Thus, the residual targets directions the student would otherwise collapse, enriching the representation with domain sensitivity while classification loss preserves class separability.
**Core assumption:** The teacher’s and student’s class-discriminative subspaces are approximately aligned due to shared classification objectives, despite architectural differences.
**Evidence anchors:**
- [section 4.1]: P_cls is built from teacher class means; the residual is orthogonal to this subspace by construction.
- [section 3.3]: After TGT, null-space energy (∥P⊥z∥²) shows stronger separation between ID and OOD, and effective rank increases universally.
- [section 5.3]: TGT gains are smaller when student and teacher share architecture (DINOv2 fine-tuning), suggesting that orthogonality/complementarity drives the benefit.
**Break condition:** If the teacher’s class subspace is not aligned with the student’s (e.g., due to extreme distribution shift), the residual may interfere with class learning, harming accuracy.

## Foundational Learning

### Concept 1: Out-of-Distribution (OOD) Detection
- **Why needed:** The paper targets OOD detection—identifying inputs from distributions not seen during training. In single-domain settings, OOD includes both in-domain (new classes within the same visual domain) and out-of-domain (entirely different domains) shifts, both of which are challenging due to DSC.
- **Quick check:** What are the two OOD evaluation splits used in the paper, and why does out-of-domain OOD fail more severely under DSC?

### Concept 2: Neural Collapse and Representation Geometry
- **Why needed:** DSC is a manifestation of neural collapse in single-domain training. The paper quantifies collapse via effective rank (r_eff) and within-class variance fraction (ρ_within). Understanding these metrics is key to diagnosing DSC.
- **Quick check:** What is neural collapse? How is effective rank computed, and why does r_eff ≈ C indicate severe DSC?

### Concept 3: Knowledge Distillation with Modified Targets
- **Why needed:** TGT is a knowledge distillation variant where the student learns from a class-suppressed teacher residual rather than logits or full features. This modification is central to injecting domain sensitivity.
- **Quick check:** In standard KD, what does the student mimic? How does TGT alter the distillation target, and why is this change necessary?

## Architecture Onboarding

**Component map:**  
Student backbone (ResNet-50) -> Student features z -> Auxiliary domain head h -> Domain prediction  
Teacher (frozen DINOv2) -> Teacher features u  
Precomputed teacher statistics (μ_c, μ) -> Projection matrix P_cls -> Teacher residual udom  
Loss combination: L_CE + λ * L_domain -> Training signal

**Critical path:**  
1. **Precomputation:** Compute teacher class means μ_c and global mean μ from training set. Construct P_cls = U(UᵀU + εI)⁻¹Uᵀ where U = [μ₁−μ, ..., μ_C−μ].  
2. **Per-batch forward:**  
   - For each image x, compute u = T(x) (no gradient).  
   - Compute udom = (I − P_cls)(u − μ).  
   - Student forward: z = f_θ(x).  
   - Classification: logits → L_CE.  
   - Domain: h_z = h(z) → L_domain = 1 − cos(ℓ₂-norm(h_z), ℓ₂-norm(udom)).  
3. **Backward:** L = L_CE + λ * L_domain → update student parameters and h.  
4. **Deployment:** Discard teacher and domain head; use student backbone with any post-hoc OOD scorer.

**Design tradeoffs:**  
- **λ (lambda):** Balances classification and domain supervision. Higher λ increases domain signal but risks classification degradation. Paper uses λ=1.0; ablation (Figure 2) shows optimal λ varies by method/dataset (often 1.0–1.5).  
- **Teacher choice:** Must be multi-domain to provide diverse domain cues. DINOv2 is used; a single-domain teacher would fail.  
- **Auxiliary head capacity:** Two-layer MLP with hidden size = student feature dimension (2048 for ResNet-50). Simpler heads may underfit; deeper heads may overfit.  
- **Normalization:** Both h(z) and udom are ℓ₂-normalized before cosine loss, focusing on direction over magnitude.

**Failure signatures:**  
- **No OOD improvement:** Measure effective rank (r_eff) of student features. If TGT does not increase r_eff (vs. CE), the domain signal is not being incorporated. Check λ and teacher residual variance.  
- **Accuracy drop >2%:** λ likely too high; reduce λ or ensure teacher class means are well-estimated (sufficient samples per class).  
- **Teacher residual degenerate:** If udom has near-zero norm, P_cls may be poorly estimated (e.g., too few training classes). Ensure C ≥ 3 and sufficient samples per class.

**First 3 experiments:**  
1. **Baseline OOD failure:** Train ResNet-50 with CE on a single-domain dataset (e.g., EuroSAT). Evaluate MDS and kNN FPR@95 for out-of-domain OOD. Expect high FPR@95 (>50%).  
2. **Geometry repair:** Compute r_eff and ρ_within (within-class variance fraction) for CE and TGT models. Expect TGT to increase r_eff (e.g., +20–120) and reduce variance concentration in top-(C−1) PCs.  
3. **TGT efficacy:** Train with TGT (λ=1.0) and re-evaluate OOD. Expect substantial reduction in far-OOD FPR@95 for distance-based scorers (e.g., MDS −11.61 pp avg). Also verify classification accuracy is preserved (±0.5%).

## Open Questions the Paper Calls Out

**Open Question 1**  
Why does TGT yield inconsistent gains for logit-based OOD scorers (e.g., MSP, Energy) compared to distance-based scorers, and why are improvements smaller when fine-tuning DINOv2 versus ResNet-50?  
*Basis in paper:* Section 5.3 states: "The weaker TGT gains on DINOv2 are consistent with limited teacher–student complementarity... teacher residual targets can be highly aligned with the student’s representation, reducing the novelty of the auxiliary supervision." The paper also notes in Section 5.2 that logit-based scorers can worsen on specific benchmarks (e.g., Fashion out-of-domain).  
*Why unresolved:* The paper attributes DINOv2’s smaller gains to shared architecture and pre-training alignment but does not quantify *how much* geometric information is actually transferred versus reinforced. The scorer-specific effects are observed empirically but lack a theoretical analysis linking TGT’s variance redistribution to the sensitivity of different score functions.  
*What evidence would resolve it:* Controlled ablation studies varying teacher–student similarity (e.g., different teacher architectures, random initialization) while measuring (a) the change in feature effective rank and (b) the sensitivity of each scorer’s score distributions to domain shift. A formal analysis of how score function Lipschitz constants interact with the residual supervision objective would clarify why distance-based scores benefit uniformly.

**Open Question 2**  
Can the class-suppressed teacher residual (udom) be adaptively tailored per dataset or per training stage to maximize OOD detection performance, rather than using a fixed cosine-similarity auxiliary loss?  
*Basis in paper:* TGT uses a static cosine alignment loss (Ldomain) with fixed λTGT=1.0 and class projections computed from frozen teacher means. The lambda ablation (Section G) shows performance is method- and dataset-dependent, suggesting the current formulation may not be optimal for all regimes. The paper’s future work mentions "designing adaptive teacher residual targets."  
*Why unresolved:* The paper does not explore whether the residual target itself could be improved—e.g., by weighting directions by their domain-discriminative power, or by adjusting the projection strength over training epochs. The fixed objective may be suboptimal for datasets with mild DSC (Rock, Garbage) or for architectures with different collapse dynamics.  
*What evidence would resolve it:* Experiments with adaptive objectives: (1) learnable projection weights in the residual computation, (2) curriculum-based λ scheduling, or (3) residuals augmented with synthetic domain shifts. Success would be measured by consistent FPR@95 gains across a wider range of λ values and datasets, especially those with mild DSC.

**Open Question 3**  
What fundamental geometric changes in the representation are *necessary and sufficient* to guarantee reliable in-domain OOD detection (held-out classes within the same domain), given that TGT reduces but does not eliminate high absolute FPR@95?  
*Basis in paper:* Section 5.2 notes: "absolute in-domain FPR@95 remains high across all methods... in-domain OOD detection in the single-domain setting should be regarded as largely unsolved." TGT improves in-domain OOD (Table 2) but leaves FPR@95 >59% on average for ResNet-50. The paper states TGT "does not eliminate" the inherent feature overlap.  
*Why unresolved:* The paper identifies DSC as a cause of far-OOD failure but does not theoretically characterize the *minimum* geometric separation required for in-domain OOD. It is unclear whether current TGT-induced changes (effective rank gain, variance redistribution) are sufficient, or if more radical representation alterations (e.g., explicit modeling of intra-class variance) are needed.  
*What evidence would resolve it:* A theoretical lower bound on in-domain OOD detectability as a function of within-class variance (ρwithin) and class separation. Empirically, systematically varying intra-class diversity (e.g., via augmentation strength) and measuring the resulting feature geometry and in-domain OOD performance would identify the critical geometric thresholds.

**Open Question 4**  
Does TGT’s distillation of domain-sensitive residuals inadvertently harm fine-grained classification accuracy on datasets with highly similar classes (e.g., Yoga poses), and can this trade-off be mitigated?  
*Basis in paper:* Table S5 shows Yoga classification accuracy drops by 4.1 pp with TGT. The paper speculates: "the domain-residual auxiliary loss may conflict with the fine-grained class boundaries." This is the only dataset with notable degradation.  
*Why unresolved:* The paper does not investigate *why* TGT harms Yoga specifically. Is it because the domain residual encodes cues that are actually class-discriminative (e.g., pose subtleties are treated as "domain" by the teacher)? Or is the λTGT=1.0 weight too high for a low-C (C=4) dataset? The interaction between class-collapse severity (Yoga has ρwithin=0.651 but reff/C=1.13) and auxiliary loss target alignment is unexplored.  
*What evidence would resolve it:* Analysis of (a) the teacher residuals on Yoga: do they correlate with class boundaries? (b) The evolution of within-class variance during TGT training: does it decrease too much? (c) Tuning λ per dataset: would lower λ recover accuracy without sacrificing OOD gains? Visualization of feature space (e.g., t-SNE) comparing CE vs. TGT for Yoga vs. other datasets would reveal whether domain and class signals interfere.

## Limitations
- **Teacher-student subspace alignment assumption:** The mechanism hinges on the teacher's class subspace aligning with the student's. This is plausible but not rigorously validated; misalignment could cause interference.
- **Generalization beyond ResNet-50 & DINOv2:** Results are shown for ResNet-50 students with a DINOv2 teacher. Performance with other architectures (e.g., ConvNeXt) or different multi-domain teachers (e.g., CLIP) is unclear.
- **Break condition datasets:** The paper notes DSC is less severe on datasets with high intra-class diversity (Rock, Garbage). TGT's relative gains on such datasets are minimal, but the exact boundary where DSC dominates vs. where other factors prevail is not systematically mapped.

## Next Checks
1. **Subspace alignment measurement:** Compute the principal angles between the teacher's class subspace (spanned by μ_c−μ) and the student's learned class subspace (from its final linear layer weights) for CE vs. TGT models. Expect smaller angles after TGT.
2. **Teacher diversity ablation:** Replace DINOv2 with a single-domain teacher (e.g., an ImageNet-pretrained ResNet-50) and repeat TGT. If gains vanish, it confirms the need for a multi-domain teacher.
3. **Ablate projection in udom:** Train TGT without the (I−P_cls) projection, using raw teacher features (u−μ) as domain target. If OOD gains drop significantly, it confirms the class-suppression step is critical.
