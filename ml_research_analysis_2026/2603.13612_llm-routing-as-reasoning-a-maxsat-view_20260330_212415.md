# LLM Routing as Reasoning: A MaxSAT View

## Quick Facts
- **arXiv ID**: 2603.13612
- **Source URL**: https://arxiv.org/abs/2603.13612
- **Reference count**: 36
- **Primary result**: LLM routing under language feedback can be understood as weighted MaxSAT optimization, with high-precision recommendations and stable implicit robustness priors in no-feedback scenarios.

## Executive Summary
This paper frames LLM routing as a MaxSAT optimization problem, where language feedback induces hard and soft constraints over model attributes. Empirical analysis on a 25-model benchmark demonstrates that language feedback produces high-precision recommendation sets, while no-feedback scenarios reveal a stable set of preferred models explained by implicit robustness priors. A sparse logistic model fitted on no-feedback cases achieves high AUC and recovers the most frequently selected models, supporting the MaxSAT interpretation of the routing mechanism.

## Method Summary
The paper models LLM routing as a weighted MaxSAT optimization problem, where language feedback induces hard and soft constraints over model attributes. The empirical analysis uses a 25-model benchmark to evaluate routing behavior under language feedback and no-feedback conditions. For the no-feedback case, a sparse logistic regression model is trained to identify metadata predicates that explain model selection, achieving high AUC and recovering the most frequently chosen models.

## Key Results
- Language feedback produces high-precision recommendation sets under the MaxSAT routing framework.
- No-feedback scenarios reveal a stable set of preferred models, explained by implicit robustness priors rather than random selection.
- A sparse logistic model fitted on no-feedback cases achieves 0.88+ AUC and recovers 8/8 of the most frequently selected models.

## Why This Works (Mechanism)
The MaxSAT framework provides a principled way to represent and optimize routing decisions under uncertainty and conflicting requirements. By encoding language feedback as hard and soft constraints, the router can systematically identify models that best satisfy user needs. The no-feedback behavior emerges from implicit robustness priors, where the system consistently selects a subset of models that perform well across diverse inputs, as validated by the logistic regression model.

## Foundational Learning
- **MaxSAT Optimization**: Weighted constraint satisfaction for routing under uncertainty; needed to formalize routing as a reasoning problem; quick check: verify constraint encoding matches language feedback semantics.
- **Logistic Regression for Model Selection**: Sparse feature learning to identify robustness priors; needed to validate implicit selection patterns; quick check: confirm AUC > 0.88 on held-out data.
- **Language Feedback as Constraints**: Hard/soft constraint generation from natural language; needed to bridge user intent and model attributes; quick check: ensure constraint satisfaction aligns with recommendation precision.
- **Robustness Priors**: Implicit model selection based on consistent performance; needed to explain no-feedback behavior; quick check: verify top models are stable across diverse inputs.
- **Model Attribute Encoding**: Discrete representation of model capabilities; needed for constraint formulation; quick check: confirm attribute coverage of routing scenarios.

## Architecture Onboarding

### Component Map
Feedback Processor -> Constraint Generator -> MaxSAT Solver -> Model Selector -> Recommendation Engine

### Critical Path
1. Language feedback is parsed and converted to hard/soft constraints
2. Constraints are fed to MaxSAT solver to find optimal model assignments
3. Selected models are ranked and returned as recommendations

### Design Tradeoffs
- Hard vs. soft constraints: precision vs. flexibility in recommendations
- Model attribute granularity: specificity vs. generalizability of constraints
- No-feedback handling: robustness priors vs. random selection

### Failure Signatures
- Constraint unsatisfiability: no models meet hard requirements
- Soft constraint dominance: recommendations skewed by non-critical preferences
- Logistic model underfitting: inability to explain model selection patterns

### First Experiments
1. Vary language feedback prompt specificity and measure impact on recommendation precision
2. Test MaxSAT solver scalability with increasing model pool size and constraint complexity
3. Perform ablation on model attribute features to identify most influential for routing

## Limitations
- Analysis limited to a 25-model benchmark; may not generalize to larger, more diverse model pools
- "Robustness priors" interpretation plausible but not directly validated; correlation does not imply causation
- Language feedback quality assumed consistent; variations in prompt phrasing could shift constraint satisfaction and outcomes
