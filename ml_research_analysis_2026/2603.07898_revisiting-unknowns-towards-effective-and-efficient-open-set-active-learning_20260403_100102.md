# Revisiting Unknowns: Towards Effective and Efficient Open-Set Active Learning
## Quick Facts
- **arXiv ID:** 2603.07898
- **Source URL:** https://arxiv.org/abs/2603.07898
- **Reference count:** 40
- **Primary result:** Proposes E²OAL, a detector-free open-set active learning framework that outperforms SOTA, achieving 97.52% accuracy on CIFAR-10 (30% mismatch), 72.10% on CIFAR-100, and 64.02% on Tiny-ImageNet, while maintaining high query precision.

## Executive Summary
Open-set active learning (OSAL) seeks to query the most informative samples from an unlabeled pool that contains both known and unknown classes, while minimizing the querying of unknowns. Existing methods typically rely on separate detectors and fail to exploit the supervisory signal inherent in labeled unknown samples. This paper introduces E²OAL, a unified, detector-free framework that addresses these gaps. It leverages label-guided clustering in a frozen contrastive feature space to discover latent structures among labeled unknowns, uses a Dirichlet-calibrated auxiliary head for better uncertainty modeling, and employs a two-stage query strategy balancing purity and informativeness with adaptive precision control. Evaluations on standard benchmarks show consistent superiority over state-of-the-art approaches.

## Method Summary
Per active learning round, E²OAL executes three main stages. First, it performs adaptive class estimation: all labeled samples (known and unknown) are embedded using a frozen pre-trained encoder (e.g., CLIP), and K-Means clustering is run over a range of candidate unknown class counts (ˆu). The optimal ˆu is selected via ternary search maximizing a structure-aware F1-product score that aligns clusters with known labels. Second, the model is trained with a dual-head output: a primary head uses standard cross-entropy on known classes, while an auxiliary head (parameterizing a Dirichlet distribution via evidential deep learning) is trained on all (k + ˆu) classes, including inferred pseudo-clusters for unknowns. Third, querying proceeds in two stages: a logit-margin purity score from the auxiliary head estimates the likelihood a sample belongs to a known class; a 3-component GMM fits these scores, and a candidate pool is adaptively sized by expanding until its bottom-`|B|` mean posterior matches a calibrated target precision ˆp*. From this pool, samples are ranked by a Jensen-Shannon-based informativeness metric that favors moderately uncertain instances, and the top-`|B|` are queried. The target precision adapts based on the previous round’s observed query precision.

## Key Results
- **Accuracy:** Achieves 97.52% on CIFAR-10 (30% mismatch), 72.10% on CIFAR-100, and 64.02% on Tiny-ImageNet, consistently outperforming prior SOTA.
- **Precision:** Maintains high query precision, effectively filtering out unknown-class samples during selection.
- **Efficiency:** Training and query overhead remain comparable to existing OSAL methods, with no separate detector required.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Label-guided clustering in a frozen contrastive feature space uncovers the latent class structure of labeled unknown samples, providing pseudo-labels that improve known-class learning.
- **Mechanism:** All labeled samples are embedded via a frozen pre-trained encoder. K-Means clustering is performed for candidate unknown class counts (ˆu). The optimal ˆu is found via ternary search maximizing a structure-aware F1-product score, which aligns clusters with known labels while preserving coherence. Inferred pseudo-clusters for unknowns act as auxiliary categories.
- **Core assumption:** The contrastive feature space preserves semantic boundaries such that unknown class instances naturally group, and this structure is discoverable via clustering when guided by known labels.
- **Evidence anchors:**
  - [abstract]: "uncovers the latent class structure of unknowns through label-guided clustering in a frozen contrastively pre-trained feature space, optimized by a structure-aware F1-product objective."
  - [section 3.2]: Details Algorithm 1, ternary search, Hungarian matching, and F1-product.
  - [corpus]: Neighbors discuss open-set detection but not this specific clustering mechanism; evidence is primarily from the paper itself.
- **Break condition:** If the pre-trained feature space is not semantically aligned (e.g., task-agnostic features fail to separate instances from different unknown categories), clustering would produce incoherent pseudo-labels, harming rather than helping training.

### Mechanism 2
- **Claim:** A Dirichlet-calibrated auxiliary head jointly models known and inferred unknown categories, improving confidence calibration and known-class discrimination by breaking softmax translation invariance.
- **Mechanism:** The auxiliary head outputs evidence vectors `e` parameterizing a Dirichlet distribution `Dir(α)` with `α = (e + γ) / (γ + 1)`, where `γ > 0` is a learned smoothing constant. Training uses composite loss `L_CE + L_EDL` (`L_EDL = L_NLL + L_KL`), encouraging high confidence on true labels while regularizing toward a uniform prior. This yields calibrated probabilities and implicitly separates known/unknown evidence.
- **Core assumption:** Overconfidence in softmax outputs, especially for unknowns, degrades open-set active learning; modeling uncertainty via Dirichlet distributions with a translation-aware formulation provides better calibration and decision boundaries.
- **Evidence anchors:**
  - [abstract]: "employs a Dirichlet-calibrated auxiliary head that jointly models known and unknown categories, improving both confidence calibration and known-class discrimination."
  - [section 3.3]: Derives Eq. (1)-(5), explains gradient mismatch and EDL integration.
  - [corpus]: Neighbors focus on detection or active learning but not Dirichlet calibration for OSAL; evidence is internal.
- **Break condition:** If the true posterior distributions of known/unknown classes are not well-approximated by Dirichlet assumptions (e.g., multi-modal uncertainties), the calibration may become mis-specified, leading to poor purity estimates.

### Mechanism 3
- **Claim:** A two-stage query strategy using a logit-margin purity score and a Jensen-Shannon informativeness metric, with adaptive precision-controlled candidate pooling, balances purity and informativeness without manual threshold tuning.
- **Mechanism:** Stage 1: Compute `S_purity(x) = max_{c∈C_k} o_c - max_{c∈C_û} o_c` from auxiliary head logits. Fit a 3-component GMM to these scores across `D_U`; the high-purity component's posterior probability ranks samples. Expand a candidate pool until its bottom-`|B|` mean posterior matches a *calibrated* target precision `ˆp*`, which adapts from previous round's observed precision. Stage 2: From the pool, select top-`|B|` by `S_info(x) = JS(p||u) * JS(p||p_max)`, favoring moderately uncertain samples.
- **Core assumption:** A high-purity candidate set can be dynamically sized to meet a target precision, and within it, samples with moderate uncertainty (diverging from both uniform and one-hot) are most informative for open-set learning.
- **Evidence anchors:**
  - [abstract]: "a logit-margin purity score estimates the likelihood of known classes... a JS informativeness metric prioritizes partially ambiguous yet reliable samples... adaptive precision control."
  - [section 3.4]: Details Eq. (6)-(8), GMM pooling, and adaptive precision update.
  - [corpus]: Neighbors like EAOA/BUAL use similar purity-informativeness trade-offs but with detectors; the adaptive GMM pooling is novel per paper.
- **Break condition:** If the distribution of `S_purity` is not well-modeled by a 3-component GMM (e.g., multi-modal unknowns), candidate pooling may include too many unknowns or exclude informative knowns. Also, if the target precision `p*` is set far from the achievable range, adaptation may oscillate.

## Foundational Learning
- **Concept: Contrastive Pretraining & Frozen Features**
  - **Why needed here:** The label-guided clustering relies on a feature space where semantic similarity is preserved across both known and unknown categories. Frozen contrastive pre-training (e.g., CLIP, MoCo) provides such a space without requiring fine-tuning on the limited labeled pool.
  - **Quick check question:** What property of contrastive learning makes its features suitable for zero-shot clustering of unseen categories?
- **Concept: Evidential Deep Learning (EDL) & Dirichlet Calibration**
  - **Why needed here:** To assign meaningful confidence scores in open-set conditions, the model must distinguish between low evidence (unknowns) and high evidence (knowns). EDL's Dirichlet-based framework provides a mathematically grounded way to model epistemic uncertainty via evidence vectors.
  - **Quick check question:** Why does the standard softmax fail to provide well-calibrated uncertainties for out-of-distribution samples, and how does the Dirichlet parameterization address this?
- **Concept: Jensen-Shannon Divergence for Informativeness**
  - **Why needed here:** In OSAL, traditional uncertainty metrics (e.g., entropy) can be misleading because unknowns often have high uncertainty but low learning value. The product of JS divergences to uniform and peak distributions specifically highlights samples that are *ambiguously* classifiable (moderate uncertainty), which are more likely to be known-class samples that are informative for the model.
  - **Quick check question:** Why would a sample with maximum entropy (uniform prediction) not be preferred under this metric, and what does that imply about the type of uncertainty being targeted?

## Architecture Onboarding
- **Component map:**
  Frozen Encoder -> Label-guided Clustering Module -> Target Model (ResNet) with Dual Heads (Primary CE head, Auxiliary Dirichlet head) -> Logit-Margin Purity Scorer -> GMM Pooling & Adaptive Precision Controller -> JS Informativeness Scorer -> Query Selector
- **Critical path:** Each AL round: (a) Cluster labeled pool → estimate ˆu → train model with Dirichlet auxiliary head; (b) Score all unlabeled with `S_purity` → GMM pool → adjust ˆp* → rank pool by `S_info` → query.
- **Design tradeoffs:**
  - Frozen features vs. training cost: No feature fine-tuning saves compute but may limit dataset-specific adaptability.
  - GMM simplicity vs. flexibility: 3-component GMM is lightweight but may fail under complex purity distributions.
  - Adaptive precision: Eliminates `k` hyperparameter but relies on stable `¯p*` estimates; volatile early rounds may cause mis-calibration.
- **Failure signatures:**
  - Clustering: F1-product score stagnates or decreases with increasing ˆu → feature space not semantically structured.
  - Calibration: Auxiliary head confidence remains high for obvious unknowns → Dirichlet `γ` not learned properly or EDL regularization insufficient.
  - Query precision: `¯p*` drifts far from `p*` despite adaptation → GMM mis-specifies purity regimes or `S_purity` uninformative.
- **First 3 experiments:**
  1. **Validate class estimation:** On a held-out labeled set with known unknowns, measure alignment between inferred clusters (Algorithm 1) and true unknown class labels (using NMI or F1). Expect monotonic improvement in score until optimal ˆu.
  2. **Ablate calibration:** Train auxiliary head with only `L_CE` vs. `L_CE+L_EDL`. Compare reliability diagrams (expected vs. observed accuracy) on a validation set containing unknowns. Expect significantly better calibration with EDL.
  3. **Test adaptive precision:** Run with fixed `p*` values (0.4, 0.5, 0.6, 0.7) and plot test accuracy vs. round. Expect a sweet spot (e.g., 0.6) but minimal performance drop across values, demonstrating robustness. Also plot `¯p*` evolution to verify convergence toward `p*`.

## Open Questions the Paper Calls Out
- How does the quality and type of pretrained contrastive features affect E²OAL's performance in open-set active learning, particularly for domains beyond natural images?
- What is the minimum number and distribution of initially labeled unknown samples required for reliable class estimation and effective learning in E²OAL?

## Limitations
- The frozen contrastive feature space may not preserve unknown class structure, risking poor pseudo-labels.
- The Dirichlet assumption might misrepresent uncertainty, leading to mis-calibration.
- The adaptive precision controller could oscillate if early observed precision is noisy.
- Hyperparameters for primary head training and GMM fit are not fully specified.
- Validation relies solely on internal experiments without external corroboration.

## Confidence
- Clustering-based unknown pseudo-labeling: **Medium** (depends on feature semantics; breakable).
- Dirichlet-calibrated auxiliary head: **Medium** (EDL theory supports but open-set applicability uncertain).
- Adaptive two-stage query: **Medium** (empirical success but GMM simplification and adaptation logic fragile).
