# Fine-Grained Post-Training Quantization for Large Vision Language Models with Quantization-Aware Integrated Gradients

## Quick Facts
- **arXiv ID:** 2603.17809
- **Source URL:** https://arxiv.org/abs/2603.17809
- **Reference Count:** 40
- **Primary Result:** QIG improves 3-bit weight-only quantization accuracy of LLaVA-onevision-7B by 1.60%, reducing the full-precision gap to 1.33%, with negligible overhead.

## Executive Summary
Post-training quantization (PTQ) for large vision-language models (LVLMs) traditionally uses coarse modality-level sensitivity estimates, failing to capture significant token-level variation within vision, text, and special tokens. This paper introduces Quantization-aware Integrated Gradients (QIG), which computes token-wise sensitivity scores by attributing the error between full-precision and quantized model outputs. These scores guide a fine-grained reweighting during the calibration optimization (Channel-wise Equalization). Across multiple LVLMs and bit-widths (e.g., W3A16, W4A8), QIG consistently outperforms modality-balanced baselines like MBQ, yielding notable accuracy gains (up to +1.60%) with minimal additional computational cost (<2.5 GPU minutes).

## Method Summary
The method addresses the mismatch between coarse sensitivity modeling and fine-grained quantization error. During calibration, for each linear layer, it computes a Quantization-aware Integrated Gradient (QIG) score for every input token. QIG integrates gradients of the output difference (full-precision vs. quantized) along a path from a quantized input baseline to the original input, directly measuring each token's contribution to the quantization error. Raw scores are stabilized via IQR clipping and normalized into importance coefficients (λ_i). These coefficients reweight the per-token reconstruction error in the standard Channel-wise Equalization (CWE) objective, steering scale optimization to better preserve sensitive token representations. The process requires no extra data beyond the standard calibration set.

## Key Results
- Under 3-bit weight-only quantization, QIG improves LLaVA-onevision-7B's average accuracy by 1.60%, closing the gap to full-precision to 1.33%.
- Across multiple LVLMs (LLaVA-onevision, InternVL2) and quantization settings (W4A8, W3A16), QIG consistently outperforms modality-balanced (MBQ) baselines on benchmarks including VizWiz, MMMU, ChartQA, AI2D, and ScienceQA.
- The added computational overhead is negligible, requiring less than 2.5 GPU minutes on an A800 for a 7B model.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Modality-level sensitivity modeling is insufficient for LVLM quantization because token-level sensitivity varies significantly within each modality and across layers.
- **Mechanism:** Quantization error propagation depends on individual token contributions. Tokens within the same modality (vision, text, special) exhibit different sensitivities due to their roles and positions in the sequence. Coarse modality-level reweighting fails to capture this granular variation, leading to suboptimal scale optimization.
- **Core assumption:** Token interactions and transformer dynamics cause intra-modality sensitivity heterogeneity, as visualized in activation distributions.
- **Evidence anchors:**
  - Token variability causes uneven quantization effects; perturbation-based sensitivity at token-level outperforms modality-level.
  - Table 1 shows token-level perturbation gains.
### Mechanism 2
- **Claim:** Quantization-aware Integrated Gradients (QIG) provides a token-wise sensitivity score that directly correlates with the quantization-induced output error.
- **Mechanism:** QIG integrates gradients of the difference between full-precision and quantized model outputs along a path from a quantized input baseline to the original input. This attribution isolates each token's contribution to the *quantization error* rather than the task output itself, producing a sensitivity measure aligned with PTQ objectives.
- **Core assumption:** Attribution methods like Integrated Gradients can reliably decompose the output difference caused by quantization noise.
- **Evidence anchors:**
  - QIG is defined as attributing `f(x, w) - f(x, w_q)`.
  - Ablation in Table 4 shows QIG's specific baseline and objective configuration yields best results.
### Mechanism 3
- **Claim:** Reweighted reconstruction error optimization using QIG-derived token coefficients improves quantization accuracy by prioritizing sensitive tokens during calibration.
- **Mechanism:** In the Channel-wise Equalization (CWE) objective, each token's reconstruction error is multiplied by its normalized QIG importance coefficient (`λ_i`). This biases the scale search to better preserve representations of tokens that most contribute to the quantization error gap.
- **Core assumption:** The reconstruction error in CWE is a valid proxy for downstream performance, and weighting per-token errors based on QIG scores steers optimization toward solutions that maintain accuracy.
- **Evidence anchors:**
  - Reweighted objective: `∑ λ_i ||...||²`.
  - Table 2 shows QIG > MBQ consistently across models and bitwidths.
  - Table 5 shows combining QIG with Hessian-based methods also improves results.

## Architecture Onboarding
- **Component map:**
  Calibration Data Loader -> Quantization Module -> QIG Computation Engine -> Sensitivity Stabilizer -> Scale Optimizer (CWE) -> Quantized Model Export
- **Critical path:**
  Calibration set -> For each layer: collect `x, x_q` -> compute per-token QIG -> IQR clip & normalize -> reweighted CWE optimization -> export quantized layer. QIG is computed *during* calibration using the same data as CWE; no extra data needed.
- **Design tradeoffs:**
  - Accuracy vs. Compute: QIG adds ~2 GPU minutes vs. MBQ; 32-step integration is a fixed cost per layer.
  - Granularity vs. Stability: Token-level weighting is more granular but sensitive to outliers; IQR clipping trades completeness for robust scores.
  - Generality vs. Specificity: QIG is defined for joint weight-activation PTQ but adaptable to weight-only; baseline `x_q` is quantized input for WA, zero for weight-only.
- **Failure signatures:**
  - No accuracy gain vs. MBQ: IQR clipping too aggressive, unrepresentative calibration data, or minimal token variability.
  - Degraded text-heavy task performance: QIG may over-weight vision tokens; check `λ_i` distribution.
  - Unstable `λ_i` across seeds: High variance in QIG scores; consider increasing integration steps or calibration samples.
  - High GPU time: Misimplementation causing repeated full forward passes per token instead of vectorized path integration.
- **First 3 experiments:**
  1. Reproduce modality-balanced baseline (MBQ) on LLaVA-onevision-7B (W3A16) to achieve ~70.44% avg.
  2. Implement core QIG pipeline for a single transformer block: 32-step integrated gradients on `E(x) = ||f(x,w) - f(x,w_q)||`, compute raw token scores, apply IQR clipping, normalize to `λ_i`, run reweighted CWE. Validate `∑λ_i ≈ 1` and visualize position-varying `λ_i`.
  3. Apply QIG to InternVL2-8B under W3A16 and W4A8; confirm ≥+0.5% avg gain over MBQ across VizWiz/MMMU/ChartQA/A2D ScienceQA. Debug if not.

## Limitations
- **Data dependence:** QIG’s token importance scores assume calibration data reflects test distribution; robustness to distribution shifts is unknown.
- **Compute overhead:** 32‑step path integration adds ~2.5 GPU minutes per model; cost for very large LVLMs unexplored.
- **Heuristic stabilization:** IQR clipping lacks theoretical justification; token score variance across seeds not reported.
- **Generalizability:** Only evaluated on 7B/8B models; unclear if benefits scale with model size or architecture changes.

## Confidence
- Token heterogeneity (within-modality variation): High (perturbation gains in Tab 1, Fig 2).
- QIG error attribution (direct correlation with quantization error): Medium (ablation favors design in Tab 4, but attribution reliability untested).
- Reweighted CWE (improved optimization via token coefficients): High (consistent cross-model gains in Tab 2, 5, negligible overhead).
