# SAGE: Sustainable Agent-Guided Expert-tuning for Culturally Attuned Translation in Low-Resource Southeast Asia

## Quick Facts
- **arXiv ID:** 2603.19931
- **Source URL:** https://arxiv.org/abs/2603.19931
- **Reference count:** 40
- **Primary result:** SAGE achieves state-of-the-art translation for 7 low-resource Southeast Asian languages while using 97.1% less training data and reducing energy consumption by 95.2%.

## Executive Summary
SAGE tackles the twin challenges of translating low-resource Southeast Asian community dialogues: the scarcity of culturally attuned, high-quality parallel data and the unsustainable computational cost of training on massive noisy web corpora. It introduces a reinforcement learning (RL) agent that autonomously curates a small, high-value subset from a large noisy pool, guided by a semantic reward derived from a tiny expert-constructed reference set. This curated set is then used to efficiently fine-tune open-source LLMs via LoRA. Across English and seven Southeast Asian languages, SAGE sets new state-of-the-art performance on BLEU-4 and COMET-22 metrics, demonstrating that intelligent, expert-guided data selection yields superior and environmentally sustainable translation compared to training on the full noisy dataset.

## Method Summary
SAGE frames data curation as a Markov Decision Process (MDP). A lightweight BERT-based RL agent iteratively scores all remaining sentence pairs in a large noisy corpus (~50M pairs) and selects the top-scoring pair to add to a growing curated set. The agent’s policy is optimized via Group Relative Policy Optimization (GRPO), which compares groups of selection trajectories and updates parameters to prefer higher-reward sequences. The reward signal is the average cosine similarity (using LaBSE embeddings) between the selected target sentence and a small expert reference set of ~2,000 high-quality, culturally appropriate translations per language. After curating a compact subset (~3% of the original), SAGE fine-tunes a pre-trained LLM (e.g., Qwen-3-8B) using LoRA, which learns low-rank adaptation matrices while freezing the base model, drastically reducing computational and energy demands.

## Key Results
- SAGE achieves new state-of-the-art BLEU-4 and COMET-22 scores across all seven evaluated low-resource Southeast Asian languages.
- The method uses only 2.9% of the original noisy training data on average (97.1% reduction).
- Energy consumption during training is reduced by 95.2% compared to a baseline trained on the full noisy dataset.
- Performance consistently exceeds models trained on the full noisy corpus and random subsets of the same size, validating the efficacy of expert-guided curation.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** The RL agent autonomously selects a compact, high-value subset from a large noisy corpus, drastically reducing data usage while preserving cultural and domain alignment.
- **Mechanism:** Curation is modeled as an MDP where at each step the agent scores all remaining candidate pairs and adds the top one to the curated set. The policy is optimized via GRPO, which samples groups of selection trajectories and updates parameters to maximize the likelihood of higher-reward sequences over lower-reward ones using a pairwise preference loss.
- **Core assumption:** Sentences semantically similar to a small set of expert translations are more likely to be culturally appropriate and useful for fine-tuning the translation model on the target community domain.
- **Evidence anchors:** Abstract and Section 3.2.2 detail GRPO; Section 4.1.1 describes the ~50M noisy pool vs. 2k expert pairs per language.
- **Break condition:** If the expert reference fails to cover the true distribution of the community domain (e.g., due to cultural or topic bias), the agent may overfit to narrow similarity patterns and select a non-representative subset.

### Mechanism 2
- **Claim:** The semantic reward signal derived from the expert reference directly encodes cultural attunement, guiding the agent to prioritize data that preserves local linguistic nuances.
- **Mechanism:** For a candidate target sentence *y*, the reward equals the mean cosine similarity between the LaBSE embedding of *y* and the embeddings of all expert target sentences, creating a dense signal favoring sentences sharing semantic/stylistic features with the expert set.
- **Core assumption:** Multilingual embeddings (LaBSE) effectively capture semantic similarity across diverse languages and are sensitive to domain- and culture-specific expressions.
- **Evidence anchors:** Abstract and Section 3.2.1 define the reward (Equation 4); Section 4.1.1 notes the expert set’s focus on community dialogues in healthcare and civic engagement.
- **Break condition:** The embedding model may have biases toward high-resource languages or fail to discriminate subtle cultural idioms; a very small expert set (<100 pairs) may yield a noisy reward signal.

### Mechanism 3
- **Claim:** LoRA fine-tuning efficiently transfers the curated data’s cultural alignment to a large base LLM with minimal additional parameters, enabling high performance on low-resource hardware and low energy consumption.
- **Mechanism:** LoRA freezes the pre-trained weight matrix *W₀* and learns two low-rank matrices *B* (d×r) and *A* (r×k) such that the update Δ*W* = *BA*. Only these adapters are trained, reducing memory and computational costs while maintaining performance comparable to full fine-tuning.
- **Core assumption:** The parameter changes required to adapt the model to a new domain have low intrinsic rank.
- **Evidence anchors:** Abstract and Section 3.3 present LoRA (Equation 6); Table 2 shows SOTA results with only 3% of original data using rank *r*=64.
- **Break condition:** If the domain shift requires high-rank updates (e.g., formal vs. colloquial registers), LoRA may underfit, necessitating higher rank or full fine-tuning.

## Architecture Onboarding
- **Component map:**
  Dnoisy (large noisy corpus) -> RL Agent (policy network) + Reward Module (LaBSE similarity to Dexp) -> Dcur (curated subset) -> LoRA adapters (low-rank matrices) -> Base LLM (frozen weights) -> Fine-tuned Model -> Evaluation
- **Critical path:**
  1. Pre-compute LaBSE embeddings for all expert target sentences.
  2. Initialize curated set Dcur = ∅, candidate pool = Dnoisy.
  3. While |Dcur| < K: agent scores each candidate, selects top pair, adds to Dcur, removes from pool.
  4. For each selection, compute reward via LaBSE similarity to expert set.
  5. After each full curation episode, update agent policy via GRPO using the selection trajectory.
  6. Insert LoRA adapters into Base LLM; train on Dcur with standard language modeling loss.
  7. Evaluate fine-tuned model on test set.
- **Design tradeoffs:**
  - Expert set size: More pairs improve reward signal but increase annotation cost; diminishing returns after ~1,000 pairs.
  - LoRA rank: Higher rank yields better adaptation but increases memory; r=64 chosen as a sweet spot.
  - Curation budget K: Smaller K reduces training time/carbon footprint but risks insufficient coverage; paper uses 3% of Dnoisy.
  - GRPO group size: Larger groups improve gradient stability at cost of agent training time.
- **Failure signatures:**
  - Agent selects an overly homogeneous subset (e.g., all short sentences); monitor length and lexical diversity of Dcur.
  - LoRA underfitting: training loss plateaus early; consider increasing rank or data size.
  - Reward hacking: Agent exploits artifacts of LaBSE (e.g., repeated phrases); inspect top-selected sentences for superficial similarity.
  - Per-language performance drop: If expert set lacks representation for a language, its translation quality may degrade; track per-language metrics.
- **First 3 experiments:**
  1. **Full-data baseline:** Fine-tune Base LLM on entire Dnoisy (no curation) to establish reference performance and energy use.
  2. **Random curation baseline:** Randomly sample same-sized subset from Dnoisy and fine-tune with LoRA; isolates effect of intelligent selection.
  3. **Heuristic reward ablation:** Replace expert semantic reward with a generic quality estimation model (e.g., COMET-QE), keeping the RL agent; tests importance of expert-derived signal.

## Limitations
- **Expert set representativeness:** The ~2k-pair expert set may not fully cover the target community domain’s linguistic/cultural diversity, risking reward signal bias and non-representative curation.
- **Embedding sensitivity:** LaBSE’s ability to capture nuanced, low-resource cultural idioms is unverified; it may prioritize high-resource language patterns, weakening the semantic reward’s cultural fidelity.
- **LoRA rank adequacy:** The fixed rank (r=64) assumes low intrinsic rank for domain adaptation; larger domain shifts might require higher ranks, risking underfitting.

## Confidence
- **Efficiency claims (97.1% less data, 95.2% less energy):** High – Directly measured against baselines; dependent on reproducible hardware/power metrics.
- **Cultural attunement via expert-guided curation:** Medium – Relies on expert set quality and LaBSE’s cross-lingual semantic fidelity; lacks intrinsic cultural validation (e.g., native speaker evaluation).
- **Generalizability to other low-resource language pairs:** Low – Evaluated only on 7 Southeast Asian languages; performance may drop for typologically distant families (e.g., African, Indigenous American) due to embedding/agent transfer issues.

## Next Checks
1. **Expert set ablation:** Systematically vary expert set size (500, 1k, 2k, 5k) and diversity (healthcare/civic/other domains) to identify performance saturation points and failure modes in agent selection.
2. **Embedding model comparison:** Replace LaBSE with language-specific encoders (e.g., tuned AfroXLMR for Southeast Asian languages) or multimodal cultural similarity models; measure impact on curated set diversity and final COMET scores.
3. **LoRA rank sensitivity test:** For a subset of languages, train LoRA at ranks r={16, 32, 64, 128} and compare against full fine-tuning on Dcur to quantify adaptation capacity limits and energy trade-offs.
