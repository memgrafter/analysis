# Fairness under Graph Uncertainty: Achieving Interventional Fairness with Partially Known Causal Graphs over Clusters of Variables

## Quick Facts
- **arXiv ID:** 2602.23611
- **Source URL:** https://arxiv.org/abs/2602.23611
- **Reference count:** 40
- **Primary result:** Proposed C-IFair method uses cluster causal graphs to identify valid adjustment sets under graph uncertainty and employs a scalable barycenter MMD penalty, achieving a superior fairness-accuracy trade-off compared to baselines, particularly in high-dimensional settings and with admissible features.

## Executive Summary
This paper tackles interventional fairness when the full variable-level causal graph is unknown, a common real-world challenge. Instead of requiring precise edge orientations, the authors propose operating over a coarser *cluster causal graph*—where variables are grouped—and infer a cluster CPDAG (completed partially directed acyclic graph) from data. From this cluster CPDAG, a graphical algorithm enumerates all possible adjustment cluster sets that could validly block back-door paths for any true cluster DAG compatible with the CPDAG. To enforce fairness, a prediction model is trained with a penalty on the worst-case discrepancy (measured via kernel MMD) between interventional outcome distributions across different sensitive attribute values. A key innovation is a barycenter decomposition that reduces the MMD sum’s computational complexity from quadratic to linear in the number of sensitive values, and the use of random Fourier features for kernel approximation. Experiments on synthetic and real datasets demonstrate that C-IFair provides a better fairness-accuracy trade-off than methods requiring full graphs or ignoring admissible features.

## Method Summary
C-IFair proceeds in several stages. First, given a user-specified partition of variables into clusters (e.g., based on domain knowledge), a cluster CPDAG is inferred from observational data using the CLOC algorithm, which extends the PC algorithm to clusters and produces directed edges, undirected edges, independence arcs (marginal, conditional, never), and connection/separation marks. Second, an adjustment set enumeration algorithm takes the cluster CPDAG and the sensitive cluster `A`. It identifies all possible parent sets of `A` via local triplet compatibility checks, then expands each into a full adjustment cluster set `Z_m` by propagating constraints along annotated arcs. If no valid set is found, the graph is refined by splitting clusters involved in connection marks into singletons and re-inferring a finer cluster CPDAG. Third, a propensity model estimates the joint score `π_{a,x_ad}(Z)` for all admissible feature values `x_ad`. Finally, a predictor (e.g., an MLP) is trained by minimizing prediction loss plus a fairness penalty: the maximum over adjustment sets of the sum over admissible `x_ad` of the pairwise MMD between interventional distributions `P(Ŷ|do(A=a),do(X_ad=x_ad))`, approximated via IPW and a barycenter trick to scale with the number of sensitive values.

## Key Results
- **Cluster-level graph inference** simplifies the causal discovery problem in high dimensions, enabling identification of valid adjustment sets even when variable-level structures are uncertain.
- **Barycenter MMD estimator** reduces computational complexity from `O(N_A²)` to `O(N_A)` for the fairness penalty, making the method scalable to many sensitive attribute values.
- **Empirical evaluations** on synthetic and real-world datasets show C-IFair achieves a better fairness-accuracy trade-off than baselines (e.g., Full, Unaware, ϵ-IFair), particularly when the graph is uncertain or when admissible features are present.

## Why This Works (Mechanism)

### Mechanism 1: Valid adjustment cluster sets from cluster CPDAG
**Claim:** Valid adjustment cluster sets can be identified from a cluster CPDAG using its annotated structure (independence arcs and marks), enabling interventional distribution estimation even when variable-level structures are unknown.  
**Mechanism:** The algorithm enumerates possible parent sets of the sensitive cluster `A` by orienting undirected edges incident to `A`, respecting constraints from `A⟨U,A,V⟩` arcs (Theorem 3.5). It then completes these sets via a queue-based propagation (Algorithm 1) that expands conditioning sets based on local triple annotations (`marg`, `cond`, `never`, and marks). This constructs sets `Z₁,...,Zₘ` such that for any true cluster DAG compatible with the CPDAG, at least one set `d`-separates all back-door paths from `A` to `Y` (via cluster-level `d`-separation, Definition 3.4).  
**Core assumption:** The cluster partition is admissible (no directed cycles induced, Assumption 3.2) and the cluster CPDAG is correctly inferred (faithfulness, Assumption 3.3). The cluster-level `d`-separation rules correctly characterize variable-level path obstruction.  
**Evidence anchors:**  
- Abstract: "graphical algorithm to enumerate adjustment cluster sets, at least one of which enables the identification of interventional distributions for the true cluster DAG compatible with the cluster CPDAG."  
- Section 3.2.2: "Collider-structure compatibility" and "No back-path condition" in Theorem 3.5 provide necessary and sufficient conditions for possible parent sets.  
- Corpus: Neighbors like "Interventional Fairness on Partially Known Causal Graphs" target adjustment set identification under partial graph knowledge but use variable-level CPDAGs; this work extends to clusters.  
**Break condition:** If no `Zₘ` validly `d`-separates back-door paths for any cluster DAG in the MEC (i.e., all candidates fail in Algorithm 1), the method falls back to graph refinement by splitting clusters with connection marks into singletons, reverting to a variable-level CPDAG.

### Mechanism 2: Scalable fairness penalty via barycenter MMD
**Claim:** The unfairness penalty is made computationally tractable by replacing the sum over pairwise MMDs between all interventional distributions with a sum over barycenter MMDs, reducing complexity from `O(N_A²)` to `O(N_A)`.  
**Mechanism:** For fixed admissible feature values `x_ad`, the sum over sensitive value pairs `∑_{a,a'} MMD(P_{a}, P_{a'})` (where `P_a = P(Ŷ|do(A=a),do(X_ad=x_ad))`) is equal to `2N_A ∑_a MMD(P_a, \bar{P})` where `\bar{P}` is the barycenter (mixture) of all `P_a` (Appendix B.1). This exploits that MMD is a metric in the RKHS. The estimator for each `μ̂_a` (kernel mean embedding of `P_a`) uses inverse probability weighting (IPW) with a learned joint propensity score `π_{a,x_ad}(Z)` (Eq. 11), and random Fourier features (RFF) approximate the kernel to reduce per-MMD cost from `O(n²)` to `O(n d_RFF)`.  
**Core assumption:** The joint propensity score `π_{a,x_ad}(Z)` is correctly modeled and positivity holds (`π>0` a.s.). The RFF approximation error is acceptable. The MMD metric properly captures distributional discrepancies relevant to fairness.  
**Evidence anchors:**  
- Abstract: "computationally efficient barycenter kernel maximum mean discrepancy (MMD) that scales favorably with the number of sensitive attribute values."  
- Section 3.3.1: explicitly states the complexity reduction from `O(N_A²)` to `O(N_A)` via barycenter decomposition and from `O(n²)` to `O(n d_RFF)` via RFF.  
- Corpus: Kernel MMD is standard in distribution testing (Gretton et al., 2012, cited), but its barycenter use for fairness scaling is novel here; neighbors like "Causal Fairness-Guided Dataset Reweighting" use reweighting, not MMD barycenters.  
**Break condition:** If the joint propensity score model is poorly specified or IPW weights are unstable (extreme variances), the estimated `μ̂_a` becomes high-variance, degrading the penalty's reliability. The method includes weight stabilization (clipping/smoothing) as a safeguard.

### Mechanism 3: Graph refinement for unidentifiable cases
**Claim:** When cluster CPDAG annotation leaves some adjustment sets unidentifiable (due to connection marks and undirected edges), refining the graph by splitting ambiguous clusters into singleton nodes restores identifiability at manageable cost.  
**Mechanism:** If Algorithm 1 returns `FAIL` because a triplet's `cond` arc with connection marks prevents definite `d`-separation (Condition 2 of Definition 3.4 requires true descendants, unidentifiable from CPDAG), the method iteratively splits clusters appearing in connection marks into individual variables. The cluster CPDAG is re-inferred using CLOC on this finer partition, which reduces undirected edges and clarifies descendant relationships. This increases `d` but keeps graph inference cheaper than full variable-level CPDAG due to smaller cluster degrees.  
**Core assumption:** Splitting clusters that appear in connection marks resolves the specific unidentifiability. The refined partition remains admissible or the resulting variable-level CPDAG is sufficiently accurate for adjustment. The cost of re-running CLOC is negligible compared to full PC inference.  
**Evidence anchors:**  
- Abstract: "Refinement can also help reduce the number of undirected edges and adjustment sets M."  
- Section 3.2.3: "To provide a safeguard against such unidentifiable cases, Algorithm 1 explicitly returns FAIL... we refine the cluster CPDAG by splitting clusters that appear in connection marks into singleton nodes."  
- Section E.5: Empirical comparison shows CLOC (used after splitting) is faster and more accurate than naive PC-then-cluster.  
**Break condition:** If after splitting all clusters (reverting to variable-level) the CPDAG still has many undirected edges incident to `A`, the number of adjustment sets `M` may explode, making the worst-case MMD penalty computationally expensive or statistically noisy. The method then defaults to using all `M` sets, which could over-penalize.

## Foundational Learning
- **Concept: Cluster Causal DAGs and CPDAGs**  
  *Why needed here:* The entire method operates on a cluster-level causal graph (nodes = variable clusters) whose inference (via CLOC) is the key to handling high-dimensional settings. Understanding cluster DAG construction (edges based on any inter-cluster variable-edge) and the enriched annotations (independence arcs, marks) is essential to grasp how causal constraints are represented coarsely.  
  *Quick check:* Given a cluster triplet `⟨X, Z, Y⟩` with `A⟨X,Z,Y⟩ = cond` and a connection mark `⊕{C}`, what does this imply about the existence of a variable-level collider path `Xi→Zk←Yj` with a child in `C`?

- **Concept: Cluster-level d-separation**  
  *Why needed here:* This extends standard `d`-separation to cluster graphs using arc annotations. It determines when a cluster set `Z` blocks paths between clusters, defining valid adjustment sets. Without this, one cannot interpret the cluster CPDAG's constraints for causal effect identification.  
  *Quick check:* In a cluster triplet `⟨U,A,V⟩` where `U` and `V` are non-adjacent, if `A⟨U,A,V⟩ = never`, does `U→A←V` constitute a valid collider structure in any compatible DAG?

- **Concept: Kernel Mean Embedding and MMD**  
  *Why needed here:* The fairness penalty measures discrepancy between interventional distributions via MMD in RKHS. The barycenter trick and RFF approximation are crucial for scalability. Understanding the embedding `μ = E[ϕ(Ŷ)]` and its empirical estimator with IPW weights is central to the loss computation.  
  *Quick check:* Why does approximating the feature map `ϕ` with random Fourier features reduce the computational cost of MMD from quadratic to linear in sample size?

- **Concept: Inverse Probability Weighting (IPW) for Interventional Distributions**  
  *Why needed here:* Interventional distributions `P(Ŷ|do(A=a),do(X_ad=x_ad))` are identified via adjustment (Eq. 5). IPW (Eq. 10) provides an estimator from observational data using the joint propensity score `π_{a,x_ad}(Z)`. This is the workhorse for estimating `μ̂_a` in the MMD penalty.  
  *Quick check:* What is the role of the joint propensity score `π_{a,x_ad}(Z) = P(A=a, X_ad=x_ad | Z)` in the IPW estimator for `P(Ŷ|do(...))`?

## Architecture Onboarding
- **Component map:**  
  Data -> Cluster CPDAG Inference (CLOC) -> Adjustment Set Enumeration (Algorithm 1) -> Propensity Model -> MMD Penalty Module -> Training Loop  
  (Refinement loop: if Algorithm 1 returns FAIL, split clusters -> re-run CLOC -> re-enumerate)
- **Critical path:** Observational data are partitioned into clusters. CLOC infers a cluster CPDAG with annotations. Algorithm 1 enumerates adjustment cluster sets `Zₘ`. A propensity network is trained to estimate `π̂_{a,x_ad}(Z)`. The predictor `h_θ` is trained with a loss combining prediction error and the worst-case MMD penalty computed over `Zₘ` using IPW and RFF.
- **Design tradeoffs:**  
  - *Cluster size vs. graph fidelity:* Larger clusters → fewer nodes → faster/more reliable CPDAG inference, but coarser representation may hide variable-level colliders, leading to more adjustment sets `M` or refinement.  
  - *MMD computational cost vs. fairness granularity:* More RFFs (`d_RFF`) → better kernel approximation but slower; more `x_ad` values → more MMD terms but necessary for admissible features.  
  - *Refinement cost vs. adjustment set count:* Splitting clusters reduces `M` by removing undirected edges/connection marks, but increases node count for subsequent CLOC runs (still cheaper than full PC).
- **Failure signatures:**  
  - High Structural Hamming Distance (SHD) between learned and true cluster DAGs → unreliable `Zₘ`.  
  - Very large `M` (number of adjustment sets) → worst-case MMD penalty becomes high-variance and slow.  
  - IPW weights with extreme variance → unstable gradient for fairness penalty; inspect weight distribution.  
  - Algorithm 1 returns `FAIL` without refinement succeeding → causal effect identification impossible under current partition.
- **First 3 experiments:**  
  1. **Synthetic data validation:** Run on linear/nonlinear synthetic DAGs with known ground truth. Check RMSE and unfairness vs. baselines; accuracy-fairness trade-off curves as `λ` varies; `M` and refinement frequency.  
  2. **Real-world benchmarks:** Apply to Adult, German, OULAD using provided/assumed causal graphs. Check AUC and unfairness vs. baselines; visualize `P(Ŷ=1|do(A=a))` differences.  
  3. **Admissible features ablation:** Add `X_ad` clusters to synthetic DAGs. Check whether C-IFair still outperforms baselines (especially ϵ-IFair) when `|X_ad|>0`; inspect refinement rates.

## Open Questions the Paper Calls Out
- **Extension to cluster MPDAGs:** How can cluster CPDAGs be extended to incorporate additional domain knowledge (e.g., as in variable-level MPDAGs) to further reduce causal uncertainty? The authors note this is highly non-trivial.
- **Theoretical guarantees under inadmissible partitions:** What are the guarantees when the cluster partition introduces directed cycles? Empirical robustness is observed but theory is lacking.
- **Worst-case adjustment set enumeration:** What is the worst-case number of adjustment cluster sets `M` as a function of graph properties? Can approximate algorithms avoid full enumeration while preserving worst-case fairness guarantees?
- **Robustness to graph estimation errors:** How do errors in cluster CPDAG inference (e.g., from finite-sample CI tests) affect the fairness-accuracy trade-off? Can the method be made robust to such misspecifications?

## Limitations
- Requires an admissible cluster partition and accurate CLOC inference; errors propagate to adjustment sets.
- Propensity score estimation for joint `(A, X_ad)` may be unstable in high dimensions, affecting IPW weights.
- The MMD-based fairness metric, while scalable, may not align with specific legal fairness definitions (e.g., it captures overall distribution shift, not discrete outcome disparities).
- No guidance on selecting the cluster partition; user-defined clusters significantly impact performance.
- Worst-case adjustment set count `M` can be large, making the max penalty noisy even with Mellowmax.

## Confidence
- **Adjustment set enumeration (Mechanism 1):** Medium. Theoretical guarantee holds if cluster CPDAG is correct; empirical support exists but sensitivity to partition and inference errors is unknown.
- **Barycenter MMD scaling (Mechanism 2):** High. Derivation is solid; RFF and barycenter tricks are well-founded; largely independent of causal assumptions.
- **Graph refinement heuristic (Mechanism 3):** Medium. Heuristic safeguard; may sometimes fail or increase cost; limited theoretical backup.
- **Overall method robustness to partition inadmissibility:** Low. Empirical robustness noted but no theoretical characterization.
