# The Error of Deep Operator Networks Is the Sum of Its Parts: Branch-Trunk and Mode Error Decompositions
## Quick Facts
- arXiv ID: 2602.21910
- Source URL: https://arxiv.org/abs/2602.21910
- Reference count: 40
- Primary result: DeepONet approximation error is dominated by branch network limitations, leading to gradient imbalance, spectral bias, and mode coupling effects.

## Executive Summary
The paper investigates practical limitations of DeepONets for operator learning by decomposing the approximation error into trunk (basis) and branch (coefficient) components. Using a modified DeepONet with a fixed SVD basis, it shows that for large inner dimensions, the branch network dominates the total error. Key findings include: (1) gradient descent suffers from severe gradient imbalance, learning only the largest modes while neglecting small modes; Adam mitigates this and improves generalization; (2) the branch network exhibits spectral bias, with high-frequency modes having higher loss; (3) architectural coupling—using a shared branch network (unstacked) versus separate networks (stacked)—improves generalization of small modes but impairs large modes; (4) mode coupling in parameter space is detrimental for well-approximated modes but beneficial for poorly approximated ones, and wider networks reduce harmful coupling. Real-world implications include the use of adaptive optimizers, careful basis selection, and network width tuning.

## Method Summary
The study employs a modified DeepONet where the trunk network is replaced by the scaled left singular vectors of the training solution matrix (SVD decomposition). This isolates branch error, which approximates the right singular vectors. Data consists of PDE solutions (KdV, advection-diffusion, Burgers) on fixed grids, with initial conditions from low-dimensional subspaces. The branch network (MLP) is trained to predict coefficients, with variations: stacked (separate networks per mode) vs unstacked (shared network). Training uses various optimizers (GD, Adam, AdaGrad) and loss reweighting. Error decomposition yields trunk error (basis misalignment) and branch error (coefficient mismatch). Branch error further splits into mode-specific losses weighted by singular values. Analysis includes spectral bias via frequency estimation of right singular functions and mode coupling via gradient inner products.

## Key Results
- Branch error ε_B dominates total error for inner dimensions N ≥ 50 across tested PDEs, while trunk error ε_T becomes negligible.
- Gradient descent learns only the largest ~10 modes; small-mode test losses exceed base (zero-coefficient) levels. Adam and AdaGrad mitigate gradient imbalance, improving small-mode fitting.
- Branch network exhibits spectral bias: modes corresponding to high-frequency right singular functions (ρᵢ) have higher unweighted loss Lᵢ, especially for KdV and Burgers; advection-diffusion shows weaker correlation due to low-rank structure.
- Unstacked (shared branch) architecture improves generalization of small/intermediate modes compared to stacked (separate networks), but stacking yields lower training loss for large modes. Wider networks reduce detrimental mode coupling (negative γ) in the parameter space.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** Gradient descent (GD) optimizers experience severe gradient imbalance, learning only the largest singular value modes and neglecting smaller ones.
- **Mechanism:** The total loss ε decomposes into weighted mode losses σ²ᵢLᵢ. Because singular values σᵢ decay rapidly, gradients ∇θL ∝ Σ σ²ᵢ∇θLᵢ are dominated by terms with large σᵢ. The optimizer therefore makes meaningful updates primarily for those modes, leaving small modes with losses near their base (zero-coefficient) values.
- **Core assumption:** The singular value spectrum of the training data matrix exhibits a steep decay, creating a multi-scale loss landscape.
- **Evidence anchors:** [section 6.3.1] Empirical results show GD reduces loss for only the first ~10 modes while small-mode losses exceed base levels. [section 6.3.2] Manual re-weighting (e<0) improves small-mode fitting at the cost of overfitting. [abstract] "Gradient descent suffers from severe gradient imbalance, learning only the largest modes while neglecting small modes."
- **Break condition:** Use of adaptive optimizers like Adam or explicit loss re-weighting (e<0) mitigates imbalance, allowing smaller modes to be learned.

### Mechanism 2
- **Claim:** Architectural coupling via a shared branch network (unstacked DeepONet) improves generalization of poorly approximated (small) modes compared to separated mode networks (stacked DeepONet).
- **Mechanism:** When all mode coefficients are predicted by a single network with shared hidden layers (unstacked), the shared parameters must represent features useful across modes. This implicit multi-task regularization prevents overfitting to any single mode, especially those with small singular values that are otherwise prone to overfitting.
- **Core assumption:** The tasks of approximating different mode coefficients share an underlying representational structure; parameter sharing acts as a regularizer.
- **Evidence anchors:** [section 6.4.2] Direct comparison: stacked DeepONet achieves lower training loss for large modes but overfits small modes (test loss near base); unstacked has slightly higher training loss but better test loss for small/intermediate modes. [abstract] "Architectural coupling—using a shared branch network (unstacked) versus separate networks (stacked)—improves generalization of small modes but impairs large modes." [remark 6] Connects to multi-task learning literature.
- **Break condition:** If mode-specific architectures (stacked) are used without explicit regularization, small-mode test performance degrades despite low training loss.

### Mechanism 3
- **Claim:** The branch network exhibits spectral bias: high-frequency right singular functions (ρⱼ) have higher approximation error, even after accounting for singular value weighting.
- **Mechanism:** For the modified DeepONet with fixed SVD basis, the branch network must learn the mapping pⱼ ↦ Vⱼⱼ (right singular vectors). Neural networks have a known bias toward low-frequency components, so the high-frequency components of these target functions ρⱼ are learned more slowly and remain inaccurate, contributing disproportionately to the mode loss Lⱼ.
- **Core assumption:** The right singular functions ρⱼ (columns of V) vary in frequency content; higher frequency implies harder learnability for standard MLPs.
- **Evidence anchors:** [section 6.4.1] For KdV and Burgers, estimated frequencies f(ρⱼ) correlate with unweighted mode losses Lᵢ,te: low-frequency modes have lower test loss. [fig. 7] Visual correlation between scaled σ⁻⁰·²ⱼ, frequency estimates, and Lᵢ,te. [abstract] "The branch network exhibits spectral bias, with high-frequency modes having higher loss."
- **Break condition:** If all ρⱼ have similar frequency spectra (e.g., advection-diffusion case), the spectral bias pattern weakens; other factors like overfitting dominate.

## Foundational Learning
### DeepONet Branch-Trunk Decomposition
- **Why needed here:** The paper's analysis relies on expressing total approximation error as ε = ε_B + ε_T, isolating branch (coefficient) and trunk (basis) errors.
- **Quick check question:** Given matrices T (trunk outputs) and B (branch outputs), how do you compute the branch matrix B* that minimizes ε? (Answer: B* = (T⁺A)ᵀ, where T⁺ is Moore-Penrose inverse.)

### Singular Value Decomposition (SVD) of Training Data
- **Why needed here:** SVD A = ΦΣVᵀ provides optimal trunk basis (Φ₁) and mode coefficients (V₁). Modified DeepONet uses scaled left singular vectors σᵢϕᵢ as trunk, making branch targets rows of V₁.
- **Quick check question:** If A tr = Φ₁Σ₁V₁ᵀ, what is the optimal branch matrix B* for trunk matrix T = Φ₁C? (Answer: B* = (C⁻¹Σ₁V₁ᵀ)ᵀ if C invertible; specifically C=Σ₁ simplifies analysis.)

### Gradient Dynamics in Multi-Scale Loss Landscapes
- **Why needed here:** Loss weighting by σ²ᵢ creates multi-scale optimization. Understanding why GD fails for small modes and why adaptive optimizers succeed is central.
- **Quick check question:** Write gradient ∇θL for standard loss. How does σ²ᵢ affect gradient contribution from mode i? (Answer: ∇θL = (1/(nm)) Σ σ²ᵢ ∇θLᵢ, so small σ²ᵢ leads to negligible gradient contribution.)

## Architecture Onboarding
### Component Map
Data matrix A: n×m matrix of true solutions evaluated at n spatial points for m initial conditions. Trunk network: in modified DeepONet, fixed basis tₖ = σₖϕₖ (scaled left singular vectors). Branch network: MLP outputting N coefficients bₖ(p). Stacked variant: N separate MLPs each outputting one coefficient. Unstacked variant: single MLP with N outputs. Loss decomposition: Branch error ε_B = ||T(Bᵀ - T⁺A)||_F² = Σ σ²ᵢ ∥bᵢ - vᵢ∥². Mode loss tracker: during training compute Lᵢ = ∥bᵢ - vᵢ∥² (train) and Lᵢ,te (test).

### Critical Path
1. Generate training data: sample m initial conditions from subspace, solve PDE, collect solutions on fixed grid → form A tr.
2. Compute SVD of A tr to obtain Φ₁, Σ₁, V₁. Set trunk T = Φ₁Σ₁.
3. Initialize branch network.
4. Train branch network to minimize L tr = (1/(n m_tr)) ∥Σ₁B trᵀ - Σ₁V₁ᵀ∥_F². Monitor mode losses Lᵢ,tr.
5. Evaluate on test data: compute test mode losses Lᵢ,te and total error δ.

### Design Tradeoffs
- Inner dimension N: larger N reduces trunk error but increases branch error, total error U-shaped.
- Architecture coupling: Unstacked improves small-mode generalization but slightly harms large-mode training; stacked lowers training loss for large modes but overfits small modes.
- Optimizer: Adam/AdaGrad mitigate gradient imbalance; plain GD fails beyond ~10 modes unless loss re-weighted.
- Width: wider branch networks reduce harmful mode coupling and improve overall loss.

### Failure Signatures
- Branch error dominance: total error δ_B >> δ_T for large N (Fig. 2).
- Small-mode neglect: under GD, unweighted mode losses Lᵢ > base loss (||vᵢ||²=1) for i > ~10.
- Intermediate-mode bump: weighted mode losses σ²ᵢLᵢ peak at intermediate i (Fig. 3).
- Overfitting pattern: stacked shows large gap between low training loss and high test loss for small modes (Fig. 8).

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** How does the branch-trunk error decomposition and the dominance of branch error change for operator learning tasks involving hyperbolic PDEs with discontinuities or in higher spatial dimensions?
- **Basis in paper:** Conclusion states they only considered low-dimensional spatial problems and it's unclear how analysis would change when trunk error becomes more pronounced.
- **Why unresolved:** Empirical analysis focused on smooth 1D solutions; discontinuities or higher dimensions could increase trunk error.
- **What evidence would resolve it:** Extend experiments to hyperbolic PDEs (e.g., Euler) and higher dimensions (2D/3D), measure trunk vs branch error across inner dimensions.

### Open Question 2
- **Question:** Does the mode decomposition analysis hold for standard DeepONets with learned trunk networks and when training and testing grids differ?
- **Basis in paper:** Modified DeepONet fixes trunk to SVD basis, requiring same grid; authors assume findings transfer but do not verify.
- **Why unresolved:** Fixed basis eliminates trunk learning dynamics; varying grids introduce interpolation errors; standard DeepONets may alter mode coupling and spectral bias.
- **What evidence would resolve it:** Apply decomposition to standard DeepONets via post-hoc SVD on learned trunk outputs; train with different grids (using interpolation) and compare mode loss distributions.

### Open Question 3
- **Question:** What causes inconsistent spectral bias signal across PDEs, and how reliable are current frequency estimation methods?
- **Basis in paper:** Frequency estimation (TV norm, Laplacian energy) correlates with losses for KdV/Burgers but not advection-diffusion; latter's low rank may cause overfitting.
- **Why unresolved:** Frequency metrics are heuristic; lack ground truth frequencies for multivariate functions; unclear if observed losses truly due to spectral bias.
- **What evidence would resolve it:** Develop robust frequency metrics calibrated on synthetic data with known frequencies; controlled experiments varying PDE spectral properties to isolate frequency effects after controlling for singular value decay and rank.

### Open Question 4
- **Question:** Can architectural or algorithmic modifications mitigate detrimental mode coupling (negative γ) while preserving beneficial coupling?
- **Basis in paper:** Identifies detrimental coupling for small widths; unstacked helps small modes but hurts large; wider networks reduce harmful coupling.
- **Why unresolved:** Paper demonstrates phenomenon but provides no solutions; trade-off between architectures; no active management of coupling (e.g., gradient surgery).
- **What evidence would resolve it:** Implement multi-task learning techniques (gradient projection, uncertainty weighting) in DeepONet training; measure coupling strength γ and mode losses across configurations.

## Limitations
- The analysis uses a modified DeepONet with fixed SVD trunk; standard DeepONets with learned trunk may exhibit different error decomposition and dynamics.
- Assumes rapid singular value decay in training data; slower decay could alter branch error dominance and optimization behavior.
- Frequency estimation methods (TV norm, Laplacian energy) are approximate and not universally validated; may not reliably capture spectral content of right singular functions.

## Confidence
- **Gradient imbalance (Mechanism 1):** High – robust empirical evidence from optimizer comparisons and loss reweighting.
- **Architectural coupling (Mechanism 2):** Medium – trade-offs observed but multi-task learning analogy is indirect.
- **Spectral bias of branch (Mechanism 3):** Medium – correlations exist but frequency metrics are approximate and inconsistent across PDEs.
