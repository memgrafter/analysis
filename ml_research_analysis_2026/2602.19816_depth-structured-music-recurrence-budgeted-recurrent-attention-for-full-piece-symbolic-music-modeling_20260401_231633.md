# Depth-Structured Music Recurrence: Budgeted Recurrent Attention for Full-Piece Symbolic Music Modeling

## Quick Facts
- arXiv ID: 2602.19816
- Source URL: https://arxiv.org/abs/2602.19816
- Reference count: 38
- Primary result: Two-scale DSMR matches full-memory recurrent perplexity (5.96 vs. 5.98) while using ~59% less GPU memory and ~36% higher throughput.

## Executive Summary
The paper introduces Depth-Structured Music Recurrence (DSMR) to enable full-piece symbolic music generation on limited hardware. DSMR streams entire compositions left-to-right using stateful recurrent attention with a per-layer memory horizon budget. Its two-scale variant allocates long memory windows to lower layers and short windows to others, preserving long-range context while reducing memory. On the MAESTRO piano dataset, two-scale DSMR attains perplexity nearly identical to a full-memory baseline (5.96 vs. 5.98) with significant memory savings (59%) and throughput gains (36%). Additional analyses show strong layer substitutability when only a subset of layers retain memory, and that learned memory-usage gates do not reliably indicate which layers should keep memory.

## Method Summary
DSMR builds on Transformer-XL with segment-level recurrence. Each Transformer layer maintains a cached key/value memory with a per-layer horizon `m(ℓ)`; the sum of horizons across layers is fixed as `M_tot`. During training, a piece is processed in ordered segments: for each layer, the truncated memory from the previous segment is concatenated with the current segment’s KV states, attention is computed, the current KV is appended to memory, and the memory is truncated to `m(ℓ)`. Cached states are detached (stop-gradient) to prevent gradient flow across segments. In the primary two-scale schedule, the lowest layer (layer 0) receives a long horizon (e.g., 31,744 tokens) and the remaining layers receive a uniform short horizon (e.g., 3,734 tokens each), summing to the total budget of 95,232 tokens. This arranges long-range memory primarily in shallower layers. The method was evaluated on the MAESTRO piano dataset with event-based tokenization (vocabulary size 393), using segment length 1024 and a model with 18 layers, hidden size 1024, and 16 attention heads. Training employed Adam with a warmup learning rate schedule, and performance was measured by validation perplexity.

## Key Results
- Two-scale DSMR matches the full-memory recurrent baseline in perplexity (5.96 vs. 5.98) while reducing GPU memory consumption by 59% (from ~15.5 GB to ~6.3 GB) and increasing throughput by 36% (from ~7618 to ~10339 tokens/s).
- When only a fixed number `B` of layers retain memory (binary-horizon schedules), the exact placement of those layers (sliding, uniform, random) has little effect on perplexity (e.g., 6.51, 6.52, 6.53 for `B=3`), indicating that memory-carrying layers are largely substitutable.
- Learned memory-usage gates, which differentiate layers during training, do not provide a transferable method for selecting which layers should retain memory; gate-guided selection yields perplexity 6.53, not better than heuristic choices (6.51–6.52).

## Why This Works (Mechanism)
### Mechanism 1: Budgeted memory distribution
- **Claim:** Distributing layer-wise memory horizons under a fixed recurrent-state budget enables full-piece training on limited hardware while preserving long-range context.
- **Mechanism:** DSMR truncates cached KV states per layer according to a horizon schedule `m(ℓ)`, with `∑m(ℓ)=M_tot`. The two-scale instantiation assigns a long horizon to a few lower layers and a short uniform horizon to the others, concentrating long-range access where it is most beneficial.
- **Core assumption:** Lower layers are more effective at capturing long-term musical structure; not all layers need full history.
- **Evidence:** Two-scale DSMR attains perplexity 5.96 vs. full-memory 5.98 with 59% less memory; the paper formalizes horizon schedules in Section 3.4 and demonstrates performance degradation when `M_tot` is reduced below a threshold.
- **Break condition:** If reducing `M_tot` further causes a steep perplexity increase, the budget has become insufficient for essential dependencies.

### Mechanism 2: Layer substitutability under binary horizons
- **Claim:** Under schedules where only B layers retain full memory, performance depends mainly on B, not on which layers are chosen.
- **Mechanism:** When a subset of layers zero their horizons, the model can redistribute the functional role of long-range context; replacing the affected layers' capabilities via the remaining memory-carrying layers yields similar perplexity.
- **Core assumption:** No single depth is indispensable for long-range information flow; the network can compensate.
- **Evidence:** Binary-horizon experiments with `B=3` show nearly identical perplexities for sliding, uniform, and random placements (6.51–6.53).
- **Break condition:** If a particular subset (e.g., very deep or very shallow) consistently underperforms across seeds, substitutability would not hold universally.

### Mechanism 3: Limitations of learned memory gates
- **Claim:** Learned memory-usage gate values do not reliably guide layer selection for memory retention; they reflect training-time credit assignment rather than intrinsic memory needs.
- **Mechanism:** Attaching learnable gates to memory-carrying layers causes depth-wise differentiation, but selecting top-B layers by mean gate value and retraining does not improve over heuristic placements (PPL 6.53 vs. 6.51–6.52).
- **Core assumption:** Gate magnitudes are epiphenomena of optimization and not transferable indicators of memory utility.
- **Evidence:** Gate-guided selection matches heuristics but does not beat them; Section 6.1 argues theoretically that shallow layers benefit most from long context, which gates do not explicitly encode.
- **Break condition:** If gate rankings correlate consistently with optimal schedules after modifications, gates could become a viable automated tool.

## Foundational Learning
- **Transformer-XL segment-level recurrence**: Needed because DSMR’s streaming training relies on cached KV states across segments to approximate full-sequence attention without storing the entire sequence. Stop-gradient on cached states prevents gradient flow across segment boundaries during backpropagation through time.

- **Recurrent memory horizon and budget constraint**: The core innovation is per-layer horizon allocation under a fixed total `M_tot`. This directly determines memory footprint and the trade-off between context length and computational efficiency.

## Architecture Onboarding
**Component map:**  
Input tokenizer → segment splitter → recurrent Transformer layers (each with: layer norm, masked multi-head attention, feed-forward) → per-layer KV cache with horizon truncation → horizon scheduler (two-scale, binary, etc.) → optional memory gates → output logits.

**Critical path:**  
During training, each piece is processed left-to-right in segments. For each layer: (1) concatenate truncated memory from previous segment with current segment’s KV, (2) compute attention, (3) append current KV to memory, (4) truncate memory to `m(ℓ)`, (5) pass memory to next segment with stop-gradient. The horizon schedule determines `m(ℓ)`.

**Design tradeoffs:**  
- Memory vs. quality: Decreasing `M_tot` improves throughput but risks losing long-range dependencies.  
- Depth placement: Allocating long memory to lower vs. higher layers; two-scale shows lower-layers focus benefits for music.  
- Schedule type: Binary selective retention (only some layers keep memory) vs. continuous distribution across all layers; continuous redistribution generally yields better performance.

**Failure signatures:**  
- Perplexity plateaus at a high value when `M_tot` is too small.  
- Training instability if memory truncation causes abrupt context loss at segment boundaries.  
- Gate-guided layer selection failing to outperform heuristics suggests unreliable learned importance.

**First 3 experiments:**  
1. Two-scale vs. full-memory: Direct comparison of perplexity, GPU memory, and throughput between the two-scale configuration and an untruncated recurrent baseline.
2. Binary-horizon variants: Fix the number of memory-carrying layers (e.g., B=3) and compare sliding, uniform, and random placements to test layer substitutability.
3. Gate-guided selection: Train a model with learnable memory gates, rank layers by average gate value, retrain using only the top-B layers, and compare perplexity to heuristic selections.

## Open Questions the Paper Calls Out
1. Does DSMR improve perceptually measurable long-range structural coherence in generated music? Teacher-forced perplexity may not reflect structural quality; no listening tests were conducted. Evidence: controlled listening tests or automatic structure metrics could resolve.
2. Are the findings on layer substitutability and optimal depth placement consistent across diverse musical genres and ensemble textures? Experiments were only on MAESTRO piano; other genres may exhibit different hierarchical dependencies. Evidence: replication on multiple symbolic music datasets.
3. How does DSMR’s optimal horizon schedule vary with model scale (number of layers and hidden dimension)? Only one model size (L=18, d=1024) was tested. Evidence: systematic scaling experiments across depths and widths under matched budgets.
4. How does DSMR compare to non-recurrent long-context mechanisms (e.g., sparse attention, linear attention) under similar hardware constraints? The paper only benchmarks against recurrent references. Evidence: implementing DSMR’s schedule with alternative attention backbones and comparing perplexity, throughput, and generation quality.

## Limitations
- Evaluation limited to the MAESTRO piano dataset; generalizability to other symbolic music types or domains is unknown.
- Model architecture and budget fixed (Transformer-XL, L=18, d=1024); scaling to different capacities may change trade-offs.
- Some reproducibility details missing (e.g., exact first segment length range, tokenization parameters, training duration), which could hinder exact replication.

## Confidence
- Two-scale DSMR matches full-memory perplexity with ~59% memory saving: **High**
- Layer substitutability under binary-horizon schedules: **Medium**
- Learned memory-usage gates are not transferable for layer selection: **Medium**

## Next Checks
1. Cross-dataset validation: Apply two-scale DSMR to other symbolic corpora (e.g., Lakh MIDI, MuseData) to assess generalizability of memory-quality trade-offs.
2. Depth and budget scaling: Systematically vary Transformer depth (L) and total memory budget (M_tot) to map performance landscapes; confirm whether layer substitutability persists across scales.
3. Gate consistency analysis: Train multiple models with different random seeds and possibly regularized gates; evaluate correlation between gate scores and optimal layer selection across seeds.
