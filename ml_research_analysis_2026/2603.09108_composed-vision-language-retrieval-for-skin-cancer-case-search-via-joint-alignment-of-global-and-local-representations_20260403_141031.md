# Composed Vision-Language Retrieval for Skin Cancer Case Search via Joint Alignment of Global and Local Representations

## Quick Facts
- arXiv ID: 2603.09108  
- Source URL: https://arxiv.org/abs/2603.09108  
- Reference count: 0  
- Primary result: Achieved SOTA Accuracy@1 79.3% and mAP 81.7% on Derm7pt for composed vision‑language retrieval of skin cancer cases.

## Executive Summary
The paper tackles composed vision‑language retrieval for skin cancer case search, where a query consists of a dermoscopic image and associated clinical text (derived from the 7‑point checklist). The goal is to retrieve biopsy‑confirmed target images sharing the same diagnosis. The proposed solution employs a transformer‑based framework that fuses the image and text at multiple hierarchical levels, creating composed query representations. Similarity between the query and a target image is computed via a joint global‑local alignment mechanism. Local alignment aggregates discriminative region features using multiple spatial attention masks, while global alignment compares pooled representations. Their weighted combination (β=0.6) emphasizes local cues while preserving global consistency. Evaluated on the public Derm7pt dataset (888 images, 3 classes), the model surpasses prior methods, demonstrating the value of multi‑scale, region‑aware alignment for medical image retrieval.

## Method Summary
The architecture uses a Swin Transformer backbone to extract multi‑level feature maps (low, middle, high) from the reference image and a pretrained BERT to encode text tokens into embeddings. At each level, a cross‑modal Transformer (decoder‑like) takes image patches as queries and text tokens as keys/values to produce fused image‑text features X^qτ. For similarity scoring, local alignment learns k (e.g., 8) spatial attention masks α_j(·) that weight the feature maps; the masked features are spatially pooled (ρ) to yield region descriptors, and the summed cosine similarity across all levels gives S_local. Global alignment computes cosine similarity between globally average‑pooled features at each level, yielding S_global. The final score is S = β·S_local + (1‑β)·S_global with β=0.6. Training uses the Adam optimizer (lr=1e‑4, weight decay=1e‑5) with early stopping; evaluation employs 5‑fold cross‑validation, reporting Accuracy@K and mAP.

## Key Results
- Accuracy@1 = 79.3% and mAP = 81.7% on Derm7pt (5‑fold CV), setting a new state‑of‑the‑art.
- Outperforms prior approaches: ResNet50‑CosSim (77.6% Acc@1, 80.4% mAP) and DAHNET (80.6% mAP).
- Qualitative results show clinically coherent top‑ranked retrievals, indicating effective use of local discriminative cues.

## Why This Works (Mechanism)
Skin cancer diagnosis relies on both global context (lesion size, location) and fine‑grained local features (e.g., atypical pigment network, streaks). The cross‑modal transformer composes the image and text into hierarchical representations that retain spatial semantics. Learning multiple spatial attention masks per level allows the model to highlight several diagnostically relevant regions rather than a single point, capturing subtle, multi‑regional cues that differentiate melanoma from benign lesions. Global alignment ensures overall image coherence and prevents matches based on irrelevant background. By favoring local similarity (β=0.6), the model emphasizes these critical details while still maintaining global consistency, leading to improved retrieval accuracy. The Swin Transformer’s multi‑scale features further support robust alignment across varying lesion sizes and structures.

## Architecture Onboarding
**Component map**:  
Input (Image, Text) → Swin Transformer → Multi‑level features (L/M/H)  
Text → BERT → Token embeddings  
For each level: CrossModalTransformer (Image queries + Text K/V) → Composed features X^qτ  
Local alignment: α_j linear layers → Spatial masks → Masked features → ρ pooling → Region descriptors → S_local  
Global alignment: Global average pooling on X^qτ → Pooled vectors → S_global  
Final score: S = β·S_local + (1‑β)·S_global → Loss (unspecified) → Training

**Critical path**: The core computation flows from backbone feature extraction through cross‑modal fusion to dual alignment modules, culminating in a combined similarity score that drives ranking.

**Design tradeoffs**  
- β: Higher β increases reliance on local patterns but risks ignoring global context.  
- k (number of masks): More masks capture more regions but increase parameter count and may require more data.  
- Backbone: Swin offers hierarchical features but is heavier than a ResNet.  
- Cross‑modal fusion at every level vs. single level: Multi‑level fusion improves multi‑scale alignment at the cost of computational overhead.

**Failure signatures**  
- Attention masks collapse to uniform or border‑focused weights, indicating poorly learned local alignment.  
- Large training‑validation performance gap suggests overfitting, especially given the small dataset.  
- Dimension mismatches between visual and textual features cause runtime errors.  
- Training fails to converge or yields random retrieval if the loss function is omitted or mis‑specified.

**First experiments**  
1. **β ablation**: Train models with β ∈ {0.0, 0.3, 0.6, 1.0} to quantify the impact of local vs. global alignment.  
2. **Mask visualization**: For selected queries, plot the k spatial masks to verify they highlight clinically relevant structures (e.g., streaks, atypical networks).  
3. **Loss comparison**: Evaluate contrastive loss with varying margins and triplet loss to identify the most stable training objective on this dataset.
