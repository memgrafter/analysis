# Capable but Unreliable: Canonical Path Deviation as a Causal Mechanism of Agent Failure in Long-Horizon Tasks

## Quick Facts
- **arXiv ID:** 2602.19008  
- **Source URL:** https://arxiv.org/abs/2602.19008  
- **Reference count:** 32  
- **Primary result:** Stochastic drift from a canonical solution path (shared tool set in successful runs) causes agent failure; successful runs adhere more to the canonical set than failed runs within the same model-task pair (Jaccard gap +0.060, p<0.0001).

## Executive Summary
This paper investigates why language agents fail on long-horizon tool-use tasks despite having the capability to solve them. It identifies stochastic drift—random deviations from a latent "canonical solution path" that represents the convergent set of tools used in successful runs—as a causal mechanism of failure. Using a natural experiment from the Toolathlon benchmark (22 models, 108 tasks, 3 runs each), the authors analyze 515 model-task units where the same model both succeeds and fails. They find that successful runs exhibit significantly higher adherence to the canonical tool set than failed runs (mean Jaccard gap +0.060, p<0.0001). The drift is gradual: the adherence gap emerges only after 50% of the trajectory, and each off-canonical tool call increases the probability of subsequent off-canonical calls by 22.7 percentage points, creating a compounding effect. Interventions that restart drifted runs based on mid-trajectory adherence improve success rates by +8.8 percentage points. The results suggest that reliability, not just capability, limits agent performance in complex tasks.

## Method Summary
The study exploits a natural experiment within the Toolathlon benchmark, where each model-task combination is run multiple times with independent stochastic seeds. For model-task pairs that exhibit mixed outcomes (some runs succeed, some fail), the authors define a "canonical solution path" per task as the set of tools invoked in more than 50% of successful runs, excluding the target model's family to avoid circularity (cross-family leave-one-out, CF-LOO). Adherence is measured by the Jaccard similarity between a run's tool set and the canonical set. The primary analysis compares mean adherence between successful and failed runs within the same mixed-outcome unit via paired statistical tests. To probe the mechanism, they examine adherence trajectory over time (percentile of tool calls) and estimate the conditional probability of an off-canonical call following another off-canonical call using trajectory-level fixed effects. Robustness checks vary the canonical path definition (thresholds, inclusion of generic tools, length residualization) and hold across all model families. The intervention effect is simulated by flagging runs in the bottom adherence tercile at 75% completion and hypothetically replacing them with runs whose adherence matches the average of successful runs.

## Key Results
- Successful runs adhere more to the canonical tool set than failed runs within the same model-task pair (mean Jaccard gap +0.060, 95% CI [+0.043, +0.077], p<0.0001).
- Drift is gradual: the adherence gap is statistically zero up to 50% of the trajectory and becomes significant at 75% and 100%; each off-canonical tool call increases the probability that the next call is off-canonical by 22.7 percentage points (p<0.0001).
- A mid-trajectory monitor that restarts the bottom tercile of runs by adherence at 75% completion would improve overall success rates by an estimated +8.8 percentage points.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Agent failure in long-horizon tasks is often a *reliability failure* caused by stochastic drift from a task's latent canonical solution path, not a capability failure.
- **Mechanism:** Every well-defined tool-use task has an emergent *canonical solution path*—a convergent set of tool invocations (the "canonical tool set") shared across ≥50% of successful runs. Stochastic LLM sampling occasionally generates trajectories that deviate from this path. Deviations shift the agent's information state, making subsequent canonical selections less likely and compounding over the trajectory until failure occurs.
- **Core assumption:** Run-level stochasticity is exogenous to potential outcomes (i.e., the random seed does not systematically predict success/failure). This is plausible given independent runs on identical inputs.
- **Evidence anchors:** The main result table shows a robust, positive within-unit adherence gap; weak direct support from corpus.
- **Break condition:** The mechanism does not explain *always-fail* units (consistently wrong path), where the issue is likely a fundamental capability gap.

### Mechanism 2
- **Claim:** Canonical path deviation is a *gradual* and *cumulative* process, not caused by a single early-branching decision.
- **Mechanism:** The adherence gap between successful and failed runs is statistically zero through the first 50% of the trajectory and only emerges significantly later. Each off-canonical tool call modestly degrades the information state, increasing the probability of subsequent off-canonical calls in a compounding manner.
- **Core assumption:** Trajectory progression is a continuous Markovian process where current tool choice probabilistically depends on the recent history. The analysis assumes the 50% checkpoint is a valid null test for early-branching.
- **Evidence anchors:** Figure 1A shows the time-series of the adherence gap; difference-in-differences test fails the parallel trends assumption, falsifying early branching.
- **Break condition:** The gradual pattern could be an artifact of the Jaccard metric if early deviations are quickly corrected via different tool sequences that still hit canonical tools later. Sequence-based metrics showed weaker effects, supporting the set-based finding.

### Mechanism 3
- **Claim:** Off-canonical tool calls are *self-reinforcing*, creating a positive feedback loop that accelerates drift.
- **Mechanism:** Conditional on a tool call being off-canonical, the probability the *next* call is also off-canonical increases by 22.7 percentage points (ˆβ=+0.227, p<0.0001) relative to following a canonical call. This more than doubles the baseline off-canonical rate (18.1%). This compounding is stronger in runs that ultimately fail.
- **Core assumption:** Consecutive tool calls (t, t+1) are conditionally independent given the immediate prior call's canonical status, after controlling for trajectory-level fixed effects. This isolates the micro-level "drift impulse."
- **Evidence anchors:** Repeated-treatment regression specification with trajectory fixed effects (n=35,045 pairs) and split by eventual outcome.
- **Break condition:** The effect might saturate or reverse in very long trajectories if agents possess implicit recovery mechanisms. The paper notes retry behavior is fixed (~47%), not adaptive.

## Foundational Learning

- **Concept: Canonical Solution Path**
  - *Why needed here:* It is the central construct—the latent "correct" region of the problem space. Understanding it as an *empirical consensus* (tools used >50% in successful runs across models) is key, not a ground-truth plan.
  - *Quick check question:* If a task has multiple disjoint successful strategies (e.g., web-search vs. direct API), how does the canonical path definition behave, and what does that imply for the adherence signal?

- **Concept: Natural Experiment & Within-Unit Design**
  - *Why needed here:* This is the identification strategy. It isolates *stochastic drift* by holding model capability and task difficulty constant (same model, same task, different runs). Without this, the observed correlation between adherence and success could be confounded.
  - *Quick check question:* Why does the existence of *mixed-outcome units* (same model succeeds and fails on same task) enable causal inference that a single-run benchmark cannot?

- **Concept: Mid-Trajectory Intervention Point**
  - *Why needed here:* The gradual drift finding implies interventions must happen *during* execution, not just at initialization (prompting). The paper identifies ~75% completion as the earliest point where drift is statistically detectable.
  - *Quick check question:* If an intervention restarts runs based on low adherence at 75%, what assumptions are made about the counterfactual—what would the restarted run have done?

## Architecture Onboarding

- **Component map:** Trajectory Recorder -> Adherence Monitor -> Decision & Restart Trigger  
- **Critical path:** Task Start → Agent executes (tools logged by Trajectory Recorder) → Checkpoint (75%) → Adherence Monitor computes Jaccard (using precomputed canonical paths) → If adherence in bottom tercile → Abort current run & spawn new run → Continue  
- **Design tradeoffs:**
  - *Checkpoint timing:* Earlier checkpoints risk false positives; later checkpoints may leave insufficient time for recovery. Paper finds 75% as first significant gap.
  - *Threshold sensitivity:* Strict thresholds (bottom 10%) yield higher per-run lift (+13.1pp) but fewer interventions; looser thresholds (bottom 33%) give moderate lift (+8.8pp) with broader coverage.
  - *Canonical path source:* Using all successful runs risks circularity; cross-family LOO (CF-LOO) is more robust but requires ≥3 cross-family successes; fallback to LOO (exclude target model) if CF-LOO unavailable.
- **Failure signatures:**
  - High within-unit adherence variance (mixed-outcome units show larger std dev than always-succeed/fail).
  - Low canonical path strength (tasks with mean Jaccard among successes <0.6 yield noisy adherence signals).
  - Always-fail units (no successes) indicate capability gaps, not drift; adherence monitoring is unlikely to help.
- **First 3 experiments:**
  1. Reproduce core correlation: For held-out mixed-outcome units, confirm successful runs have higher CF-LOO canonical path adherence than failed runs (target gap +0.060).
  2. Validate gradual drift timing: Measure adherence gap at 25%, 50%, 75%, 100%; expect gap non-significant at ≤50% and significant at 75%+.
  3. Simulate restart intervention: For trajectories flagged at 75% (bottom tercile adherence), replace with a hypothetical "recovered" run with adherence equal to the mean of successful runs; estimate lift (target +8.8pp).

## Open Questions the Paper Calls Out

1. **What is the information-theoretic mechanism that causes each off-canonical tool call to increase the probability of subsequent off-canonical calls by 22.7 percentage points?**  
   *Basis:* The authors state that a formal information-theoretic account is left to future work.  
   *Why unresolved:* The paper establishes the empirical compounding pattern but does not explain the underlying information dynamics (e.g., how tool deviations corrupt the agent's context state or reduce mutual information with the goal).  
   *Resolution evidence:* A formal model deriving the drift coefficient from first principles, perhaps quantifying how off-canonical actions alter the KL divergence between the agent's belief state and the canonical solution manifold.

2. **Does experimentally manipulating canonical path adherence causally improve success rates, and by how much?**  
   *Basis:* The current evidence is observational; the reported +8.8pp lift is a counterfactual estimate, not an experimental effect.  
   *Why unresolved:* No direct intervention has been performed in the Toolathlon environment.  
   *Resolution evidence:* A controlled intervention where, for mixed-outcome units, the bottom tercile of runs are restarted or prompted toward canonical tools at 75% completion, with success compared to control runs.

3. **Why do some tasks (e.g., `imagenet`, `train-ticket-plan`) exhibit negative within-unit adherence effects?**  
   *Basis:* Table 6 shows 13/67 tasks have negative effects, but the paper does not analyze these outliers.  
   *Why unresolved:* The gradual drift mechanism predicts a positive effect; negative tasks may have multi-modal solutions, poorly defined canonical paths, or confounding factors.  
   *Resolution evidence:* Qualitative case studies of negative-effect tasks to determine whether multiple valid solution paths exist, whether canonical paths are poorly defined (e.g., low consensus among successes), or whether task-specific dynamics reverse the drift pattern.

4. **Does canonical path adherence predict success in always-fail units, or is the mechanism specific to the stochastic boundary of mixed-outcome units?**  
   *Basis:* The causal estimate is restricted to mixed-outcome units (22.5% of dataset); the authors note a monotonic gradient across all unit types but do not test causality in always-fail units.  
   *Why unresolved:* Always-fail units may represent capability gaps where even perfect adherence cannot recover success; the gradient is descriptive, not causal.  
   *Resolution evidence:* A within-unit analysis in always-fail units comparing adherence of runs that come closest to success vs. those that fail utterly, or a quasi-experimental design using tasks where some models always fail but show adherence variation.

## Limitations

- Data accessibility: Toolathlon trajectories are not openly hosted, hindering replication.
- Canonical path definition: The >50% threshold and CF-LOO exclusion are arbitrary and may not generalize to other benchmarks or domains.
- Scope: The mechanism only explains mixed-outcome units (reliability failures); it does not address always-fail cases (capability gaps). Additionally, the Jaccard set-based metric may obscure sequence effects that could alter the interpretation of gradual drift.

## Confidence

- Stochastic drift causes failure: **High** – strong within-unit design, large sample (n=515), robust significance.
- Gradual accumulation of drift: **Medium** – relies on percentile bucketing; needs validation with sequence-aware metrics.
- Self-reinforcement of off-canonical calls: **High** – large conditional effect (22.7pp, p<0.0001) with trajectory fixed effects.
- Mid-trajectory restart lift: **Medium** – simulation result based on counterfactual; experimental validation pending.

## Next Checks

1. **Core replication:** Acquire Toolathlon data, compute CF-LOO canonical paths, and confirm the within-unit adherence gap (+0.060) via paired t-test/bootstrapping.
2. **Sequence-aware gradual drift check:** Replace Jaccard with longest common subsequence or edit distance and re-evaluate the gap’s emergence timing to rule out set-based artifacts.
3. **Cross-benchmark intervention test:** Implement the 75%-completion restart monitor (bottom 33% adherence) on a distinct long-horizon benchmark (e.g., AgentBench) to verify generalizability of the +8.8pp lift.
