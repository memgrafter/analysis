# CONE: Embeddings for Complex Numerical Data Preserving Unit and Variable Semantics

## Quick Facts
- **ArXiv ID:** 2603.04741
- **Source URL:** https://arxiv.org/abs/2603.04741
- **Reference count:** 40
- **Primary result:** CONE achieves F1 87.28% on DROP QA (up to 9.37% improvement over SOTA) and up to 25% Recall@10 gain on column/tuple matching tasks.

## Executive Summary
Standard language models treat numbers as textual tokens, failing to capture magnitude, units, and context. CONE addresses this by introducing a composite embedding structure that jointly encodes numerical values (including ranges and Gaussian distributions), their units, and attribute names within a hybrid transformer encoder. The approach preserves numerical distance semantics and distinguishes semantically distinct but numerically identical values. Evaluated on the DROP QA benchmark, CONE achieves an F1 score of 87.28%, improving by up to 9.37% over state-of-the-art baselines. For column and tuple matching retrieval across large-scale datasets, it gains up to 25% Recall@10, demonstrating superior handling of complex numerical semantics.

## Method Summary
CONE’s architecture builds on BioBERT with two key innovations. First, numerical fusion embeddings replace the standard token representation for numerals: the contextual embedding from the transformer is summed with a pre-computed magnitude-aware embedding (e.g., DICE) that encodes the numeric value via a functional mapping; the combined vector is refined by a lightweight transformer before replacing the original token embedding. This preserves numerical order and interval properties. Second, for table-related tasks, CONE constructs composite embeddings for cells, columns, and tuples by concatenating the contextual embeddings of the attribute name, the numerical value (or its range/Gaussian components), and the unit into fixed slots, then projects the concatenation via a tied linear autoencoder with a masked reconstruction loss. This yields a fixed-size vector that keeps each component’s contribution distinct. The model is pre-trained on tabular data with a masked numeral prediction objective, which regresses the log-magnitude and classifies the number type, thereby imbuing the encoder with numeracy.

## Key Results
- DROP QA F1: 87.28% (up to +9.37% vs. SOTA).
- Column/tuple matching Recall@10: up to 25% gain over SOTA models.
- Numerical distance preservation: Pearson correlation r=0.989 between absolute differences and embedding cosine distances for scalars 0–1000; far superior to BioBERT (r≈0.07).

## Why This Works (Mechanism)

### Mechanism 1: Numerical Fusion Embeddings Preserve Magnitude
Standard token embeddings lack explicit magnitude encoding. CONE’s numerical fusion module sums the encoder’s contextual embedding of a numeral token with a precomputed magnitude embedding (e.g., from DICE). This fused representation is processed by a small transformer to refine number-specific reasoning. As a result, embedding distances reflect numerical proximity. Evidence: on scalars 0–1000, CONE achieves a Pearson correlation of 0.989 between absolute difference and cosine distance, while BioBERT’s correlation is near zero. Ablation removing the magnitude component (CONE1) drastically degrades this correlation.

### Mechanism 2: Composite Embedding Structure Disambiguates Polysemy
Semantically distinct numerical instances (e.g., “5 years” vs. “5 kg”) must be separated despite identical magnitudes. CONE concatenates contextual embeddings of attribute name, value, and unit into reserved slots and projects via a tied autoencoder, preserving contributions in separate subspaces. This ensures that distances decompose when other components are fixed. Evidence: BioBERT conflates “Age” and “Follow-up” (cosine 0.9998), while CONE reduces similarity to 0.83 by respecting attribute and unit differences. Ablations show that removing any component (attribute, value, or unit) harms column/tuple matching performance (>10% Recall@10 drop on CIUS/CancerKG).

### Mechanism 3: Masked Numeral Prediction Induces Numeracy
To teach the encoder accurate numeric semantics, CONE pre-trains with a masked numeral prediction task: given corrupted input, the model regresses the original log-magnitude and classifies the number type (integer, decimal, etc.). This forces the model to encode both magnitude and context. Evidence: CONE outperforms baselines on list maximum, decoding, and addition tasks across ranges up to 10^6, achieving the lowest RMSE on addition. Without this objective, magnitude relationships are not preserved.

## Foundational Learning

- **Tokenization Handling for Numerals**: Standard subword tokenizers split multi-digit numbers (e.g., "28,600" → "28", "600"), which destroys the magnitude as a single concept. CONE overrides tokenization to treat each numeral as one token, enabling a unified magnitude embedding.

- **Embedding Space Distance Preservation**: Numerical semantics require that the vector geometry reflect true distances (e.g., absolute difference for scalars, intersection-over-union for ranges). CONE’s fusion and composite design aim to align embedding distances with these metrics.

## Architecture Onboarding

**Component map (flow):**  
Tokenizer override → Encoder (BioBERT-base) → Numerical Fusion Module → Composite Builder → Aggregation (sum for column/tuple)

**Critical path:**  
Tokenization → Encoder forward pass → Identify numeral indices → Fuse with magnitude embeddings → Update token representations → Serialize tables → For each cell, build composite embedding (Algorithm 2) → Aggregate cell embeddings for column/tuple vector.

**Design tradeoffs:**
- Fixed-slot concatenation vs. dynamic composition: slots simplify downstream indexing but require padding/masking for missing components.
- Magnitude source: Uses DICE; could swap for other numeric embeddings but DICE is deterministic and corpus-independent.
- Training objective: Masked numeral prediction forces numeracy but requires numeric-rich corpus; failure if data lacks explicit numeric contexts.

**Failure signatures:**
- High cosine similarity between semantically different numerical attributes (e.g., Age vs. Follow-up) indicates unit/attribute disambiguation failed.
- Poor correlation (r, ρ) between analytic and embedding distances for scalars/ranges suggests magnitude encoding is broken.
- Ablation: Removing numerical fusion (CONE1) or composite structure (CONE2) causes >10% Recall@10 drop on CIUS/CancerKG.

**First 3 experiments:**
1. **Distance correlation validation:** Sample 1000 random numbers/ranges/gaussians; compute pairwise analytic distances (AbsDiff, dCL, dW2) and embedding cosine distances; report Pearson/Spearman. Expect r>0.98 for scalars, r>0.99 for ranges.
2. **Masked numeral prediction loss curve:** Train on tabular data with masked numerals; plot L_num (Eq. 9) vs. steps. Should converge smoothly, indicating model learns to regress magnitude.
3. **Column matching retrieval:** Index all column composite embeddings (Algorithm 2) from a dataset (e.g., WebTables). For a held-out query column ("Age" with numeric values), retrieve top-10 by cosine. Verify semantically similar columns (other age-like attributes) rank highest, while numerically overlapping but semantically distant columns (e.g., "Follow-up") are lower.

## Limitations
- Magnitude encoding relies on DICE, which may not generalize to unconventional number formats (e.g., scientific notation) or extremely large magnitudes.
- Composite embedding assumes fixed slots; missing components (unit or attribute) are zero-padded, potentially harming representation quality in sparse tables.
- Pre-training with masked numeral prediction requires numeric-rich corpora; performance may degrade on domains with few explicit numbers.

## Confidence
