## Executive Summary
This work studies adversarial bandit optimization where losses are linear but subject to additive perturbations with a global budget \(C\). The authors propose a modified SCRiBLe algorithm that shrinks the feasible decision set to accommodate the worst‑case perturbation budget. A key technical contribution is a novel regret decomposition that isolates the linear component, the deviation due to perturbations, and an error term from the set shrinkage.

This yields an expected regret bound of \(O(d\sqrt{T} + d\sqrt{T}C + dC)\). When \(C=0\), they achieve a high‑probability bound of \(O(d\sqrt{T}\ln T + \text{lower‑order terms})\), improving the prior dimension dependence from \(O(d^2\sqrt{T})\). A lower bound of \(\Omega(C)\) demonstrates that the dependence on the perturbation budget is unavoidable. The analysis avoids lifting techniques, simplifying earlier approaches. The paper does not include empirical evaluation, and several questions remain about high‑probability optimality and extension beyond linear losses.

## Method Summary
(Reproduction notes were not provided.) The algorithm builds on SCRiBLe but incorporates a shrunk feasible set scaled by the global perturbation budget \(C\). At each round, the learner selects a decision from this set, observes a loss linearly corrupted by an adversary within the cumulative budget, and updates the set. The regret analysis relies on a decomposition into three terms: the standard linear regret, a deviation term capturing the effect of perturbations, and an error term from set shrinkage.

## Key Results
- Expected regret: \(O(d\sqrt{T} + d\sqrt{T}C + dC)\).
- For \(C=0\), high‑probability regret: \(O(d\sqrt{T}\ln T + \frac{\ln T}{\sqrt{T\ln(\ln T/\gamma)}} + \ln(\ln T/\gamma))\), improving the dimension term from \(O(d^2\sqrt{T})\) to \(O(d\sqrt{T}\ln T)\).
- Lower bound \(\Omega(C)\) proves the C‑dependence cannot be eliminated.

## Why This Works (Mechanism)
The mechanism hinges on two intertwined ideas. First, the feasible set is shrunk by a factor related to \(C\); this pre‑emptively accounts for the worst‑case additive perturbations, ensuring that the true loss lies within a predictable range. Second, the regret is decomposed into a linear part (handled by the SCRiBLe updates), a deviation part that bounds the cumulative effect of the bounded perturbations, and an error term from the set shrinkage. By balancing these, the analysis avoids lifting to a higher‑dimensional space and achieves tighter dimension dependence. The global budget \(C\) directly influences the shrink factor, leading to the additional \(d\sqrt{T}C\) and \(dC\) terms, while the lower bound confirms that any algorithm must incur at least linear cost in \(C\).

## Architecture Onboarding
- **Component Map:** Input parameters (d, T, C) → Construct initial shrunk feasible set → Each round: Sample action from set → Observe perturbed linear loss → Update set via SCRiBLe rule → Track regret terms.
- **Critical Path:** The algorithm starts by defining a feasible set scaled by \(1/(C+1)\) (or similar). At each step, it samples a point, receives feedback, and updates the set using a linear optimization oracle. The regret analysis runs in parallel to bound the cumulative loss.
- **Design Tradeoffs:** Smaller shrunk sets reduce deviation but increase linear regret; larger sets reduce linear regret but risk larger deviation. Projection complexity must be balanced against the benefit of avoiding lifting.
- **Failure Signatures:** If \(C\) is underestimated, the set may become infeasible leading to high regret. Large \(d\) amplifies the \(\sqrt{d}\) factor from concentration; if \(T\) is small, logarithmic terms dominate.

## Limitations
- The algorithm requires prior knowledge of the global perturbation budget \(C\); performance under mis‑specification is unknown.
- The high‑probability bound for \(C=0\) carries extra logarithmic factors, so the optimal \(O(d\sqrt{T})\) rate with high confidence remains open.
- Results are restricted to linear losses with globally bounded additive perturbations; non‑linear, non‑smooth, or unbounded settings are not covered.

## Confidence

- **\(\Omega(C)\) lower bound:** High (standard adversary argument).
