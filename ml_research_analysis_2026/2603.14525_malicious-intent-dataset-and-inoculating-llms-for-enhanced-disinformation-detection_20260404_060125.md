# MALicious INTent Dataset and Inoculating LLMs for Enhanced Disinformation Detection

## Quick Facts
- arXiv ID: 2603.14525
- Source URL: https://arxiv.org/abs/2603.14525
- Reference count: 29
- Primary result: IBI improves zero-shot disinformation detection by an average of 9% over strong baselines, with gains up to 25% for Estonian.

## Executive Summary
The paper introduces MALINT, a human-annotated English corpus of disinformation labeled with five malicious intent types, created in collaboration with expert fact-checkers. It proposes Intent-Based Inoculation (IBI), a two-stage LLM prompting technique that first analyzes malicious intent and then leverages that analysis to detect disinformation. Evaluations across five English datasets and six languages demonstrate that IBI yields consistent improvements, averaging a 9% F1 gain over strong zero‑shot baselines, with particularly large gains in low‑resource languages like Estonian (+25%). The study also benchmarks fine‑tuned small language models on intent classification, achieving up to 82.1% weighted F1 on multilabel tasks.

## Method Summary
The authors construct MALINT, a dataset of 1,600 articles annotated for disinformation and multilabel malicious intents (UCPI, CPV, UIOA, PSSA, PASV). Using this resource, they design IBI: a two‑step prompting framework where an LLM first produces a conservative, structured analysis of the input text’s intents; this output is then combined with a “threat” warning and fed into a second prompt to produce the final disinformation label. For small language models (SLMs), fine‑tuning on MALINT is employed for intent classification. The evaluation compares IBI against zero‑shot baselines (VaN, Z‑CoT, DeF‑Spec) across multiple test sets, including genre (news vs. social), temporal (post‑cutoff), and multilingual (six languages) splits.

## Key Results
- IBI improves zero‑shot disinformation detection F1 by an average of 9% across five English datasets and six languages, with up to 25% gain for Estonian.
- Fine‑tuned SLMs achieve up to 82.1% weighted F1 on multilabel intent classification, while LLMs show strengths in specific binary intent categories.
- The largest gains are observed on longer news articles; improvements on short social media posts are more modest.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Analyzing explicit malicious intent categories improves an LLM's ability to detect disinformation by making hidden persuasion tactics cognitively salient, akin to a "threat" component in inoculation theory.
- **Mechanism:** The IBI prompt first forces the model to perform a structured, multilabel analysis of the input text against a predefined intent taxonomy (UCPI, CPV, etc.). This act of deliberate classification is hypothesized to "inoculate" the model by making it consciously aware of specific harmful goals (e.g., "undermining institutions"), which then biases its subsequent disinformation judgment toward recognizing content designed for those goals.
- **Core assumption:** The model's internal representation of "disinformation" is enhanced when it first explicitly maps text features onto a framework of malicious intent, rather than making a monolithic true/fake judgment.
- **Evidence anchors:**
  - **[abstract]** "inoculating LLMs... proposes intent-based inoculation (IBI), an LLM prompting technique that first analyzes malicious intent and then uses that analysis to detect disinformation."
  - **[section 4.2]** Details the two-stage IBI design: `XT = (T, KI, GA)` for intent analysis, followed by `ZT = (T, θ, AI(T), GI)` for detection, where `θ` is the threat warning.
  - **[section 4.4, Table 8]** Shows consistent F1 improvements (~9% avg) across 5 datasets, 5 LLMs, and 3 prompting baselines when using IBI.
- **Break condition:** If the intent taxonomy `I` does not cover the actual intent in a given text, the "threat" signal is misdirected and the refutational preemption (`AI(T)`) provides irrelevant or misleading context, potentially harming detection performance.

### Mechanism 2
- **Claim:** The structured, conservative "refutational preemption" output from the intent analysis step provides a high‑precision, condensed summary of persuasive threats that reduces cognitive load during the final detection decision.
- **Mechanism:** The first‑stage prompt (`GA`) instructs the model to be conservative ("answer No when not fully sure") and output a structured dictionary of `{intent: Yes/No}` pairs. This creates a low‑noise, high‑level abstraction of the text's malicious goals, which is then appended to the second‑stage prompt. This scaffolding offloads the effort of identifying *what* makes the text malicious from the final detection step, allowing the model to focus on *how* those identified intents manifest as disinformation.
- **Core assumption:** LLMs suffer from "reasoning fatigue" or context window limitations when performing complex multi‑axis analysis in a single step; decomposing the task improves final accuracy on the primary objective.
- **Evidence anchors:**
  - **[section 4.2, Figure 5 & 6]** Shows the explicit separation: first prompt demands a conservative binary decision per intent with rationale; second prompt consumes that output.
  - **[section 4.4]** Notes the largest gains on longer "news articles" (vs. social posts), where more text provides more intent evidence for the first stage to extract, supporting the idea of effective pre‑processing.
  - **[corpus]** The MALINT annotation guidelines (Appendix A) emphasize conservative, fact‑checker‑style analysis, which the prompts mimic.
- **Break condition:** For very short texts (e.g., tweets) with insufficient context, the first‑stage analysis may produce an empty or incorrect `AI(T)` (e.g., all "No"), providing no useful signal for step two, potentially nullifying benefits or adding noise.

### Mechanism 3
- **Claim:** The intent taxonomy, derived from real‑world disinformation campaigns observed by IFCN‑accredited fact‑checkers, provides a cross‑lingual and cross‑topical "schema" that generalizes beyond the training distribution of the LLM's pretraining data.
- **Mechanism:** The categories (UCPI, CPV, UIOA, PSSA, PASV) are abstract goals, not topic‑specific claims. An LLM's pretraining likely includes discussions of "political views" or "anti‑science," but the IBI framework forces it to apply these high‑level concepts to novel disinformation texts. This schema, validated by expert fact‑checkers, acts as a stable, transferable feature space that remains applicable even for content published after the model's knowledge cutoff or in different languages.
- **Core assumption:** Malicious intent is a more stable and portable concept for detection than surface‑level topical or linguistic features, which vary by culture, time, and platform.
- **Evidence anchors:**
  - **[section 2.2]** The intent categories were "refined in collaboration with fact‑checking experts" and are based on "current disinformation landscape" reports (e.g., EU DisinfoLab).
  - **[section 4.4, Table 6]** Shows IBI's strongest gains in low‑resource languages (Estonian +25%), where topical/linguistic cues might be sparse, but intent schemas can transfer.
  - **[section 4.3]** Experiments on "post‑cutoff" data (unseen during pretraining) also show gains, suggesting the schema works beyond the model's memorized examples.
  - **[corpus]** The neighbor paper "PolyTruth" (FM R=0.51) also focuses on multilingual detection, implying the field sees transferability as key.
- **Break condition:** The taxonomy is Eurocentric/liberal‑democracy‑centric (e.g., "Western democracies" in definitions). In autocratic states or different cultural contexts, the same content might be framed as "patriotic" rather than "undermining institutions," causing the schema to misclassify the intent or fail to map, reducing efficacy.

## Foundational Learning
- **Concept: Disinformation Detection as Binary Classification**
  - **Why needed here:** The core task IBI aims to improve. Engineers must understand the baseline problem (real vs. fake) and its limitations (e.g., reliance on stylistic cues, topic‑specific knowledge).
  - **Quick check question:** Why might a model trained on 2020 COVID‑19 misinformation struggle with 2024 election disinformation, even if the text quality is similar?

- **Concept: Inoculation Theory (McGuire, 1964)**
  - **Why needed here:** Provides the psychological/theoretical foundation for IBI. The "threat" (θ) and "refutational preemption" (`AI(T)`) are direct applications. Without this, IBI is just a two‑step prompt with no theoretical rationale for its structure.
  - **Quick check question:** What is the difference between "threat" and "refutational preemption" in the context of the IBI prompt design?

- **Concept: Multilabel vs. Multiclass Classification**
  - **Why needed here:** Malicious intent is **multilabel** (an article can have UCPI *and* PSSA). Engineers implementing the intent analysis stage must use appropriate loss functions (e.g., BCEWithLogitsLoss) and evaluation metrics (weighted F1), not softmax‑based multiclass.
  - **Quick check question:** In MALINT, if an article is labeled with both `UCPI` and `CPV`, should the model output be `[1, 0, 0, 1, 0]` or a single class like "UCPI_CPV"? What does the paper use?

## Architecture Onboarding

### Component map
Input Text (T) -> LLM Call 1 with XT -> Intent Analysis Output AI(T) -> LLM Call 2 with ZT -> Final Disinformation Label ŷ

### Critical path
The inference pipeline requires two sequential LLM calls: first to produce the structured intent analysis (AI(T)), second to generate the final binary decision (ŷ). The path fails if either call fails or AI(T) is malformed.

### Design tradeoffs
- **Context Length vs. Depth:** Two LLM calls double latency and cost. Deep analysis of long articles is possible in step 1, but step 2 must re‑include the full T, potentially hitting context limits.
- **Taxonomy Rigidity vs. Coverage:** Fixed 5‑intent schema is simple and validated but may miss emerging intent types; a dynamic taxonomy would require a different architecture, losing theoretical grounding.
- **API Cost vs. Performance:** Using powerful models for both steps is expensive; a tradeoff is using a fine‑tuned SLM for the intent analysis (where SLMs performed well) and a large LLM only for final detection.

### Failure signatures
1. **Low Intent Agreement:** AI(T) shows high variance across runs or systematically misses one intent category (e.g., never predicts PASV), indicating poor prompt calibration or model weakness.
2. **No Improvement on Short Texts:** IBI performance matches or is worse than baseline on social media posts (ECTF), as the first stage lacks context to produce useful AI(T).
3. **Degradation on Out‑of‑Schema Content:** Performance drops on texts whose primary goal is pure financial fraud or state propaganda not framed as "undermining institutions," as the intent labels don't capture the goal.

### First 3 experiments
1. **Validate Intent Analysis Stage Alone:** On the MALINT test set, run only the first‑stage prompt (XT) for all 5 LLMs. Compute multilabel F1 (from Table 4) and per‑intent binary F1 (from Table 3). Confirm that LLMs can perform the intent task with reasonable accuracy.
2. **Replicate Main Result on MALINT:** Implement the full IBI pipeline for one LLM (e.g., GPT‑4o Mini) using the VaN baseline. Compare F1 (disinformation detection) with and without IBI on the MALINT test set (expected: ~5% gain, Table 7). This is the minimal proof‑of‑concept.
3. **Test Break Condition – Short Texts:** Run IBI vs. baseline on the ECTF dataset (social posts). Record F1 difference. Hypothesis: IBI gain will be smaller (~3% in Table 8) or negative for some models, confirming the context‑length sensitivity.

## Limitations
- The intent taxonomy is Eurocentric/liberal‑democratic and may misclassify intent in autocratic or culturally distinct contexts.
- IBI's two‑stage design shows limited benefit for short texts (e.g., social media posts) where the first‑stage analysis lacks sufficient context.
- Gains depend on the correctness and coverage of the intent analysis; content whose primary goal falls outside the predefined schema can see degraded performance.

## Confidence
- IBI improves zero‑shot detection accuracy: **High**
- Intent taxonomy generalizes across languages and time: **Medium**
- Two‑stage "inoculation" mechanism causally responsible for gains: **Low‑to‑Medium**
- Fine‑tuned SLMs perform well on intent classification: **High** (as reported)

3. **Component Ablation on Latency‑Sensitive Data:** For long‑article datasets, compare full IBI against ablations (remove threat, remove AI(T), single‑step CoT) to measure contribution of each component and cost trade‑offs.
