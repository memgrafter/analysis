# IndoBERT-Relevancy: A Context-Conditioned Relevancy Classifier for Indonesian Text
## Quick Facts
*   **arXiv ID:** 2603.26095
*   **Source URL:** https://arxiv.org/abs/2603.26095
*   **Reference count:** 2
*   **Primary result:** Fine-tuned IndoBERT Large achieves F1-score of 0.948 and accuracy of 96.5% on a context-conditioned relevancy classification task for Indonesian text.

## Executive Summary
This paper introduces a classifier for determining if a given Indonesian text is relevant to a specified topic (context), addressing challenges from extreme register variation (formal news vs. informal social media) and implicit topical expression. The core contribution is a meticulously constructed dataset of 31,360 pairs built iteratively: starting with formal news, adding informal social media to cover lexical disjointness, and finally generating synthetic texts that express relevance without explicit keywords to teach implicit reasoning. A fine-tuned IndoBERT Large model with inverse-frequency class weighting on this dataset yields robust performance (F1 0.948) across 188 topics, demonstrating effective handling of Indonesia's linguistic diversity.

## Method Summary
The method is a failure-driven, iterative data construction and model training pipeline. Stage 1 trains a model on formal news article titles and their manually labeled topic relevance. Evaluation reveals poor recall on informal text. Stage 2 addresses this by collecting and labeling 7,884 informal social media posts, significantly improving recall. Stage 2 still fails on texts relevant to a topic but containing zero obvious keywords. Stage 3 generates 4,678 synthetic social media-style texts using GPT-4o-mini constrained to avoid obvious topic keywords, filling this implicit relevance gap. The final model is IndoBERT Large fine-tuned on the combined dataset with a loss weighted inversely to class frequency (relevant: ~2.5x) to counteract the natural 65.9%/34.1% class imbalance.

## Key Results
*   Final model F1-score: **0.948**, Accuracy: **96.5%**.
*   Adding informal data (Stage 2) improved recall from 84.5% to 91.4% (+7% absolute).
*   Class weighting produced a near-symmetric confusion matrix (83 FN, 84 FP), indicating balanced precision and recall (~94.8% each).

## Why This Works (Mechanism)
### Mechanism 1: Iterative Data Expansion for Register Variation
*   **Claim:** Training on formal news alone yields a model that fails on informal text due to lexical disjointness. Systematically adding real informal data causally improves robustness and recall.
*   **Mechanism:** The Stage 1 model learns lexicon-dependent patterns from the formal domain. Explicit diagnosis on informal text shows low recall. Adding representative informal posts exposes the model to slang and variant expressions, forcing it to learn register-invariant semantic representations of relevance rather than surface-form matches.
*   **Evidence Anchors:** [section 4.2] describes the immediate problem revelation; [section 6.1] Table 4 quantifies the F1 gain of +0.062 and recall as the primary improving metric from Stage 1 to Stage 2.
### Mechanism 2: Constrained Synthetic Data for Implicit Relevance
*   **Claim:** Generating synthetic texts relevant to a topic but explicitly forbidden from using obvious keywords causally teaches the model to recognize implicit, context-driven connections, improving recall on pragmatically relevant examples.
*   **Mechanism:** Natural informal data often contains at least one keyword. The synthetic constraint ("without using any obvious topic keywords") creates training examples that rely solely on contextual cues and world knowledge (e.g., discussing noodle prices for "inflation"), filling a specific data gap where real examples are rare.
*   **Evidence Anchors:** [section 4.3] details the GPT-4o-mini instruction; [section 6.4] Table 6 shows correct classification of implicit examples with high confidence after Stage 3.
### Mechanism 3: Inverse-Frequency Class Weighting for Balanced Errors
*   **Claim:** Applying sample weights inversely proportional to class frequency in the loss function causally balances precision and recall by preventing the model from collapsing to a majority-class ("not relevant") predictor.
*   **Mechanism:** The natural distribution is heavily skewed (65.9% not relevant). Without weighting, gradient descent minimizes loss by learning a conservative, high-precision/low-recall model. Weighting amplifies error signals from the minority "relevant" class, forcing the model to assign non-trivial probabilities to borderline cases.
*   **Evidence Anchors:** [section 5.2] states the weighting gives "~2.5 times more weight to errors on relevant texts"; [section 6.5] Table 5 shows a nearly symmetric confusion matrix (83 FN, 84 FP), empirically confirming the balance.

## Foundational Learning
*   **Concept: Context-Conditioned Classification**  
  *Why needed here:* Relevancy is a relational judgment between a context (topic) and a text. The same text can be relevant to one context but not another. The model must compose both inputs, not classify the text in isolation.  
  *Quick check:* If you swap the context for a given text, should the prediction change? If yes, the task is context-conditioned.
*   **Concept: Register Variation and Lexical Disjointness**  
  *Why needed here:* Indonesian exhibits a wide formality spectrum where the same topic (e.g., fuel prices) can be expressed with almost no shared vocabulary across registers (formal news vs. social media slang). The model must learn semantics from non-overlapping surface forms.  
  *Quick check:* Can you list 3-5 ways to say "fuel price increased" in Indonesian that share no keywords with "Pertamina menaikkan harga bensin"?
*   **Concept: Class Imbalance in Binary Relevance Tasks**  
  *Why needed here:* For any given topic, most random text snippets are irrelevant. The natural prior is strongly skewed toward the negative class. Without mitigation, models learn to always predict "not relevant" to maximize accuracy.  
  *Quick check:* If you sample 100 documents for a specific topic and find 5 relevant, 95 irrelevant, what accuracy does a naive "always predict not relevant" model achieve? What is its recall?

## Architecture Onboarding
*   **Component map:** Input Formatter -> IndoBERT Large Encoder -> [CLS] Pooling -> Linear Classification Head -> Sigmoid
*   **Critical path:**
    1.  Format each pair as `[CLS] <context> [SEP] <text> [SEP]`.
    2.  Tokenize with IndoBERT tokenizer, truncate/pad to 256 tokens.
    3.  In training loop, compute per-sample loss using `nn.BCEWithLogitsLoss(weight=inverse_freq_weight)`.
    4.  Monitor validation F1; stop early if no improvement for 2 epochs.
*   **Design tradeoffs:**
    *   **Synthetic vs. Real Data:** Synthetic implicit data is cheap and targets a specific gap but risks unnatural examples or distributional shift. The "no keywords" constraint is a key quality control.
    *   **Sequence Length:** 256 tokens suits headlines/social posts but truncates longer relevant paragraphs. Increasing length raises memory cost linearly.
    *   **Model Size:** IndoBERT-Large provides capacity but its pre-training may still lack coverage for extreme slang; targeted data augmentation is necessary.
*   **Failure signatures:**
    *   **High accuracy, low recall:** Likely omitted class weighting or severe imbalance in validation set.
    *   **Poor performance on slang/code-mixed text:** Insufficient informal data in training mix.
    *   **High confidence on irrelevant texts with keyword overlap:** Model is keyword-reliant; likely missing implicit training examples (Stage 3) or hard negatives.
*   **First 3 experiments:**
    1.  **Baseline sanity check:** Train on Stage 1 (formal only). Evaluate on held-out formal vs. informal sets. Expect high formal performance, low informal recall.
    2.  **Implicit gap probe:** Test Stage 2 model on 100 *de novo* human-written social media posts about covered topics that contain zero obvious keywords (e.g., price complaints). Expect high false negative rate.
    3.  **Component validation:** Ablate class weighting by retraining final model (Stage 3 data) with uniform loss weights. Compare precision-recall balance; expect recall to drop significantly and errors to become asymmetric.

## Open Questions the Paper Calls Out
*   **OQ1:** How well does the model generalize to entirely novel topics outside its 188 training contexts and 12 domains? (Basis: Section 8 limitations; training data confined to specific domains).
*   **OQ2:** To what extent does reliance on LLM-generated synthetic data for implicit references introduce biases affecting performance on authentic, highly implicit Indonesian social media? (Basis: Section 8 acknowledges synthetic data may not capture real-world diversity and noise).
*   **OQ3:** Did the reactive, failure-driven data construction miss systematic failure modes (e.g., specific registers, topic clusters, or reasoning types) not revealed by aggregate metrics? (Basis: Methodology addresses observed failures but may not proactively capture edge cases or complex intersections of challenges).
*   **OQ4:** How robust is performance across the full spectrum of Indonesian linguistic diversity, including regional dialects, code-mixing (Indonesian-English), and evolving online slang not in the 8-week collection window? (Basis: Section 8 notes language evolution and limited collection period).
*   **OQ5:** Could alternative loss functions or sampling strategies for class imbalance yield better precision-recall trade-offs or calibration than inverse-frequency weighting? (Basis: Paper uses one specific weighting technique but does not compare to focal loss, oversampling, etc.).

## Limitations
*   **Synthetic Data Underspecification:** The exact GPT-4o-mini prompt and parameters for Stage 3 generation are not fully detailed, risking unreproducible distributional shifts.
*   **Informal Data Sourcing Gaps:** The specific 40 "high-volume" topics and scraping methodology for the 8-week social media collection are not enumerated, limiting full replication of the informal data stratum.
*   **No External Validation:** Zero citations and neighboring papers on unrelated tasks indicate the approach lacks independent testing or comparison in the broader research community.

## Confidence
*   **Mechanism 1 (Iterative Data Expansion):** High. Directly supported by staged ablation metrics (recall +7%) and explicit failure diagnosis.
*   **Mechanism 2 (Constrained Synthetic Data):** Medium. Internal evidence shows Stage 3 F1 gain, but lacks human validation of synthetic example quality or naturalness.
*   **Mechanism 3 (Inverse-Frequency Weighting):** High. Directly tied to a documented implementation choice and a symmetric confusion matrix (83 FN, 84 FP).

## Next Checks
1.  **Human Evaluation of Synthetic Implicit Data:** Sample 200 Stage 3 pairs for human judgment on label correctness and text naturalness. Target: >90% label agreement and >85% naturalness rating.
2.  **Zero-Shot Generalization Test:** Evaluate final model on a held-out set of *new* Indonesian registers (e.g., parliamentary transcripts, regional news) covering the 188 topics. Target: F1 drop <0.05 relative to in-distribution test.
3.  **Class Weighting Implementation Audit:** Retrain the Stage 3 model with uniform loss weights. Compare resulting precision-recall balance to the weighted model. Expect significant recall drop (>5%) and asymmetric confusion matrix.
