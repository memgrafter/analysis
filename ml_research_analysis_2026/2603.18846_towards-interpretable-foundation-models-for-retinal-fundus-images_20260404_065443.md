# Towards Interpretable Foundation Models for Retinal Fundus Images
## Quick Facts
- arXiv ID: 2603.18846
- Source URL: https://arxiv.org/abs/2603.18846
- Reference count: 35
- Primary result: Dual-IFM achieves performance comparable to much larger foundation models (e.g., RETFound with 16× more parameters) while providing inherent local and global interpretability for retinal fundus images.

## Executive Summary
This paper introduces Dual-IFM, a foundation model for retinal fundus images that prioritizes inherent interpretability. It combines a BagNet architecture to generate class evidence maps for local explanations and a learned 2D projection layer (t-SimCNE) for global visualization of the representation space. Pretrained on over 800,000 unlabeled fundus images, Dual-IFM with only 18.3 million parameters matches or exceeds the performance of state-of-the-art models with up to 303 million parameters across multiple downstream disease classification tasks. The model's explanations are shown to be more clinically relevant (higher precision) and its 2D embeddings exhibit better clustering quality than post-hoc methods like t-SNE.

## Method Summary
Dual-IFM employs a BagNet backbone (ResNet-50 without the final pooling layer) to maintain spatial feature maps. A 1×1 convolutional classification head is attached to produce per-class activation maps, which are globally averaged to yield predictions, ensuring that each spatial location's contribution to a class is explicit. For pretraining, the model uses a three-stage contrastive learning pipeline (t-SimCNE): Stage 1 trains the full model with an NT-Xent loss on 128-dimensional projections (SimCLR-style); Stage 2 freezes the encoder and learns a 2D projection head with a Euclidean similarity loss; Stage 3 fine-tunes the entire model end-to-end with the 2D loss. The learned 2D projection provides a direct, semantically meaningful visualization of the entire dataset. Downstream, the model can be evaluated via linear probing on frozen features or fine-tuned with the classification head, optionally incorporating a sparsity constraint on the evidence maps to encourage focused explanations.

## Key Results
- Dual-IFM (18.3M parameters) matches or exceeds RETFound (303M parameters) on 5 out of 7 out-of-distribution retinal disease datasets in linear probing, with AUROC scores ranging from 0.655 to 0.928.
- The learned 2D embedding space achieves an average k-NN AUROC of 0.76, outperforming post-hoc t-SNE/PCA applied to features from standard models.
- Class evidence maps attain a precision of 0.674 in highlighting clinically relevant diabetic retinopathy lesions on the IDRiD dataset, significantly higher than RETFound's LRP method (0.384).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: BagNet provides local interpretability through class evidence maps that are faithful to the decision-making process.
- **Mechanism**: The model attaches a 1×1 convolutional layer to the encoder's spatial feature map, producing per-class activation maps. The final prediction is computed by globally averaging these maps, making each spatial location's contribution to a class explicit.
- **Core assumption**: That the classification decision can be decomposed into contributions from local patches without requiring global context, and that the 1×1 convolution adequately maps features to class-specific scores.
- **Evidence anchors**:
  - [abstract]: "local interpretability for individual images through class evidence maps that are faithful to the decision-making process."
  - [section]: Section 2.3: "The convolutional classifier provides explicit class evidence maps that directly highlight the regions of the image that contributed to the model’s predictions."
  - [corpus]: Weak: neighboring works such as "Interpretable Few-Shot Retinal Disease Diagnosis with Concept-Guided Prompting of Vision-Language Models" and "FGR-Net: Interpretable fundus image gradeability classification based on deep reconstruction learning" explore interpretability via concept prompting or reconstruction, but not via BagNet's spatial averaging.
- **Break condition**: If the top-activated patches do not overlap with clinically relevant lesions (e.g., low precision on IDRiD) or if performance degrades on tasks requiring integration of distant cues, the spatial averaging assumption fails.

### Mechanism 2
- **Claim**: t-SimCNE enables global interpretability by learning a parametric 2D projection that preserves semantic structure for direct visualization.
- **Mechanism**: The projection head is trained with a contrastive loss in 2D (Euclidean similarity) to pull together embeddings of augmented views of the same image and push apart others. This forces the encoder to produce features that, when projected, retain semantic relationships in a 2D plane, which can be directly plotted.
- **Core assumption**: That a 2D projection can sufficiently capture the structure of high-dimensional representations for visualization, and that optimizing the contrastive loss in 2D does not harm the encoder's representational quality for downstream tasks.
- **Evidence anchors**:
  - [abstract]: "global interpretability for entire datasets through a 2D projection layer that allows for direct visualization of the model's representation space."
  - [section]: Section 2.1 describes the decomposition into encoder and 2D projection head and states that optimizing the objective yields representations useful for downstream tasks. Section 3.2 shows that the 2D embeddings reveal continuous transitions of disease grades.
  - [corpus]: Limited: no neighbor directly evaluates a learned 2D projection for global interpretability; "OCTCube-M" uses multimodal contrastive learning but not for 2D visualization.
- **Break condition**: If the 2D embeddings show poor clustering (e.g., low k-NN AUROC) or if linear probing performance drops compared to a model with a higher-dimensional projector, the 2D constraint is too severe.

### Mechanism 3
- **Claim**: Large-scale SSL pretraining with Dual-IFM's interpretable architectures yields parameter-efficient models that match or exceed larger foundation models in performance.
- **Mechanism**: The 800k+ retinal images provide diverse data for SSL to learn robust features. BagNet's local processing encourages localized feature learning, while t-SimCNE's 2D constraint organizes these features semantically. Together they enable a compact model (18.3M parameters) to achieve performance comparable to much larger models (e.g., 303M parameters).
- **Core assumption**: That the interpretability-induced architectural constraints do not limit representational capacity when trained at scale, and that dataset diversity compensates for fewer parameters.
- **Evidence anchors**:
  - [abstract]: "Our model reaches a performance range similar to that of state-of-the-art foundation models with up to 16× the number of parameters, while providing interpretable predictions on out-of-distribution data."
  - [section]: Section 3 (Tables 1 and 2) reports linear probing and fine-tuning results where Dual-IFM matches or exceeds RETFound on 5/7 datasets. Section 4 notes that Dual-IFM surpassed RETFound despite having far fewer parameters and half the inference time.
  - [corpus]: Emerging work on efficient retinal models (e.g., "A Disease-Specific Foundation Model Using Over 100K Fundus Images") supports the feasibility of compact models, but does not address dual interpretability.
- **Break condition**: If on complex or diverse downstream tasks the performance gap with larger models widens, or if the interpretability features degrade when scaling up data or model size, the synergy may not hold.

## Foundational Learning
### Self-supervised contrastive learning
- **Why needed here**: The paper pretrains on 800k unlabeled retinal images using contrastive SSL (t-SimCNE) to learn transferable representations without manual annotations, which is essential given the cost of medical labeling.
- **Quick check question**: In SimCLR-style contrastive learning, how are positive and negative pairs constructed, and what loss function is typically used?

### BagNet architecture
- **Why needed here**: BagNet is the backbone that inherently provides local interpretability via class evidence maps. Understanding its spatial averaging mechanism (1×1 conv + global average pooling) is key to seeing why the explanations are faithful.
- **Quick check question**: Why does applying a 1×1 convolution to spatial feature maps followed by global average pooling yield spatially interpretable activation maps for each class?

### Linear probing
- **Why needed here**: Linear probing evaluates the quality of pretrained representations by training a linear classifier on frozen features, isolating representation learning from downstream adaptation. The paper uses it to compare Dual-IFM to baselines across multiple datasets.
- **Quick check question**: What does a high linear probing AUROC indicate about a pretrained model's representations?

## Architecture Onboarding
- **Component map**:
  - Encoder: CNN (e.g., ResNet-50 without final FC) producing spatial feature maps.
  - Projection head: MLP that maps pooled features to 2D for global visualization (used after pretraining).
  - Classification head: 1×1 convolution on the encoder's feature map, followed by per-class global average pooling, producing class scores for downstream tasks.
  - Training stages: (1) SimCLR-style with 128D projector; (2) dimensionality annealing to 2D with encoder frozen; (3) end-to-end fine-tuning with lower LR.
  - Optional: Sparcity constraint on activation maps during fine-tuning.

- **Critical path** (pretraining):
  1. Input image → random augmentations (two views).
  2. Each view passes through encoder → spatial feature map.
  3. Global average pooling → feature vector.
  4. Projection head (128D or 2D) → embedding.
  5. Contrastive loss (NT-Xent for stage1, Euclidean for stage2/3) computed over batch.
  6. Backpropagation; repeat for three stages.
  Fine-tuning path:
  1. Input image (augmentations optional) → encoder → feature map.
  2. 1×1 convolution → per-class activation maps.
  3. Global average pooling per map → class scores.
  4. Cross-entropy loss (optionally with sparsity regularizer).
  5. Backpropagation; early stopping.

- **Design tradeoffs**:
  - BagNet computational cost: Small receptive fields yield large feature maps, increasing memory usage; trade-off between interpretability and efficiency.
  - 2D projection information loss: Forcing 2D may discard subtle distinctions; three-stage training mitigates but cannot fully recover high-dimensional structure.
  - Model size vs. data: Smaller model (18.3M) reduces parameters but relies on large-scale pretraining (800k images) to generalize; with less data, performance may drop.
  - Visualization quality vs. downstream performance: Using Euclidean similarity improves 2D clustering but may slightly harm linear probing; the paper chooses NT-Xent in stage1 to prioritize representations.

- **Failure signatures**:
  - Class evidence maps are noisy or non-localized (low precision on IDRiD).
  - 2D embeddings show overlapping clusters or no clear disease progression (k-NN AUROC << 0.76).
  - Linear probing AUROC drops significantly compared to SimCLR or ImageNet baselines.
  - Fine-tuning yields lower performance than linear probing (overfitting), especially on small datasets.
  - Training crashes due to memory overflow from BagNet's large spatial tensors.

- **First 3 experiments**:
  1. Linear probing on seven out-of-distribution datasets (APTOS, DeepDRiD, IDRiD, Messidor, Glaucoma, PAPILA, FIVES) with logistic regression, reporting AUROC and comparing to ImageNet, SimCLR, and RETFound baselines.
  2. Fine-tuning with 5-fold cross-validation on the same datasets, using the classification head, to assess task-specific adaptation.
  3. Interpretability evaluation: (a) Global: compute k-NN AUROC for 2D embeddings and compare to post-hoc t-SNE/PCA on baseline models; (b) Local: compute precision of top-10 activated patches on IDRiD and compare to RETFound's LRP heatmaps.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question**: How does the Dual-IFM framework generalize to other medical imaging modalities (e.g., OCT) and multimodal settings (e.g., combining fundus images with metadata) while preserving both local and global interpretability?
- **Basis in paper**: [explicit] "Future work could extend to additional modalities (e.g. OCT and metadata) ... The inherent interpretability would also make it uniquely suited for a multimodal setting."
- **Why unresolved**: The paper only evaluates Dual-IFM on color fundus photography; its applicability to other modalities and combinations is untested.
- **What evidence would resolve it**: Pretraining and evaluating Dual-IFM on OCT datasets and multimodal combinations, measuring both performance and interpretability metrics (e.g., class evidence map precision, embedding clustering quality).

### Open Question 2
- **Question**: How do alternative self-supervised learning objectives (e.g., MAE, DINO) impact the trade-off between downstream task performance and interpretability in BagNet-based foundation models?
- **Basis in paper**: [explicit] "in addition to other SSL objectives that could improve performance from pretraining."
- **Why unresolved**: The paper only uses t-SimCNE (a contrastive method); other SSL approaches have not been explored in this interpretable architecture.
- **What evidence would resolve it**: Train Dual-IFM or similar BagNet models with different SSL objectives and compare linear probing/fine-tuning performance and interpretability metrics (e.g., fidelity of class evidence maps, quality of 2D embeddings).

### Open Question 3
- **Question**: What is the impact of the CNN backbone architecture on the quality of local and global interpretability in Dual-IFM?
- **Basis in paper**: [explicit] "and different CNN-backbones to explore both local and global interpretability"
- **Why unresolved**: The paper uses a specific BagNet-33 backbone; other architectures (e.g., ResNet, EfficientNet) may affect interpretability differently.
- **What evidence would resolve it**: Replace the backbone with other CNN families, retrain the model, and evaluate class evidence map precision and 2D embedding clustering across downstream tasks.

### Open Question 4
- **Question**: Does aligning the learned 2D projection layer with fine-tuned representations enhance the global interpretability visualization for downstream tasks?
- **Basis in paper**: [explicit] "Further improvement of the 2D visualization is possible by aligning the projector to the representations of the model after fine-tuning"
- **Why unresolved**: The authors used the projector from pretraining without alignment; the potential benefit remains unknown.
- **What evidence would resolve it**: Align the projector after fine-tuning (or during) and compare the k-NN AUROC and qualitative clustering of the 2D embeddings against the unaligned version.

### Open Question 5
- **Question**: How reliable are the class evidence maps from Dual-IFM in highlighting clinically relevant lesions for retinal diseases beyond diabetic retinopathy, such as glaucoma and AMD?
- **Basis in paper**: [inferred] The paper only evaluated class evidence map precision on DR (IDRiD dataset); other diseases were not assessed.
- **Why unresolved**: The generalizability of the local interpretability method to other pathologies is uncertain.
- **What evidence would resolve it**: Evaluate the precision/recall of top-activated patches against expert annotations for glaucoma and AMD datasets, similar to the DR evaluation.

## Limitations
- Critical implementation details (projection head architecture, t-SimCNE loss specifics, data augmentations, sparsity regularization value, patient-level splits, linear probing hyperparameters) are missing, hindering faithful reproduction.
- Evaluation is limited to diabetic retinopathy and glaucoma datasets; the model's generalizability to other retinal pathologies (e.g., AMD, macular edema) remains unverified.
- Interpretability metrics rely on automatic measures (precision of patches, k-NN AUROC) without clinical validation from ophthalmologists.
