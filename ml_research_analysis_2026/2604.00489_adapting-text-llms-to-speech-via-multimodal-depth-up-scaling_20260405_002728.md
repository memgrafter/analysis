# Adapting Text LLMs to Speech via Multimodal Depth Up-Scaling

## Quick Facts
- **arXiv ID:** 2604.00489
- **Source URL:** https://arxiv.org/abs/2604.00489
- **Reference count:** 0
- **Primary result:** Inserting trainable layers into a frozen text LLM and training only those on speech data achieves ASR performance comparable to full fine-tuning while preserving over 75% more text capability and allowing full recovery by dropping the added layers.

## Executive Summary
Adapting large language models (LLMs) pre-trained on text to speech-based tasks like ASR through standard fine-tuning causes catastrophic forgetting of their original text abilities. This paper introduces **multimodal depth up-scaling**, a method that inserts new, trainable transformer layers into a frozen pre-trained text LLM. Only these added layers are trained on speech data, while the base model's weights remain untouched. On SmolLM2 models (360M and 1.7B) trained on 48k hours of ASR data, this approach matches or surpasses full fine-tuning in ASR word error rate (WER) when using E-Branchformer layers, reduces degradation on a suite of text benchmarks by over 75%, and enables exact recovery of the original text model by simply skipping the added layers at inference. The work demonstrates a parameter-efficient pathway for speech adaptation that protects the core linguistic knowledge of the base LLM.

## Method Summary
The procedure begins with a pre-trained text-only decoder LLM (SmolLM2). The tokenizer vocabulary is expanded to include speech tokens (e.g., semantic and acoustic units), and the embedding matrix is resized; new token embeddings are trained while original text embeddings are frozen. **Multimodal depth up-scaling** is then performed: a number of new transformer (or E-Branchformer) layers are inserted into the model's architecture at specified positions (e.g., interleaved or top-heavy). Critically, all parameters from the original LLM are frozen. The new layers are initialized with a **function-preserving** strategy (e.g., zeroing output projections) so the model behaves identically to the original before training. Only the parameters of the added layers and the new speech token embeddings are trained on the ASR objective (predicting transcripts from speech tokens). At inference, the system processes speech inputs by running the full stack (original + added layers). For text inputs, the added layers are "dropped" (skipped), routing data directly between original layers to recover the exact pre-trained text model's computation.

## Key Results
- Depth up-scaling with interleaved placement and E-Branchformer layers matches or exceeds full fine-tuning ASR WER on the 1.7B model while using 60% fewer trainable parameters.
- Text task degradation on a suite of 8 benchmarks is reduced by over 75% compared to full fine-tuning when added layers are kept.
- Dropping the added layers at inference fully recovers the pre-trained model's zero-shot instruction-following and text benchmark performance, which full fine-tuning permanently damages.

## Why This Works (Mechanism)
### Mechanism 1: Freezing Prevents Forgetting
- **Claim:** Freezing all original LLM layers and training only newly inserted layers prevents catastrophic forgetting of text capabilities.
- **Mechanism:** The original text-optimized weights remain completely unmodified during speech training. The new layers learn to transform the frozen representations into speech-relevant ones, while the original computational path for text inputs remains unchanged and recoverable via layer dropping.
- **Evidence:** The methodology explicitly freezes original parameters {f_i} and trains only added layers {g_j}. Results show exact text performance recovery after dropping added layers, confirming the base model's functions are preserved.
- **Break condition:** If the frozen base model's representations lack latent structure useful for speech, added layers may fail to compensate, leading to poor ASR.

### Mechanism 2: Function-Preserving Initialization
- **Claim:** Zero-initializing output projections in added layers (or setting W_Merge=[I;0] in E-Branchformer) ensures they act as identity functions at start, enabling stable adaptation.
- **Mechanism:** Starting from an identity mapping means training begins from the original model's exact behavior. Gradients can then gradually specialize the new layers without conflicting with the frozen base model's learned functions.
- **Evidence:** Ablation in Table 2 shows this initialization (e.g., for E-Branchformer) yields lower WER (2.3) than random W_Merge (2.5). Theoretical derivation in Section 3.3 proves the identity property.
- **Break condition:** Incorrect implementation (e.g., bias terms not handled) or architectural constraints that prevent identity representation could cause instability.

### Mechanism 3: E-Branchformer Architecture for Speech
- **Claim:** Using E-Branchformer as the inserted layer improves ASR over standard transformer layers by better capturing local acoustic patterns.
- **Mechanism:** E-Branchformer combines global self-attention (long-range context) with a local convolutional branch (via cgMLP). This dual-branch structure provides an inductive bias more suited to speech's fine-grained acoustic details than pure attention.
- **Evidence:** Table 2 shows E-Branchformer reduces WER relative to standard transformer layers for both model sizes (e.g., 1.7B: 2.3 vs 2.4 clean WER).
- **Break condition:** If speech data lacks strong local patterns (e.g., very noisy), the convolutional branch may add noise or minimal benefit.

## Architecture Onboarding
- **Component map:**
  Text Token IDs → Frozen Base Text LLM → [Added Trainable Layers (m)] → Output Logits
  Speech Token IDs → Frozen Base Text LLM → [Added Trainable Layers (m)] → Output Logits
  (At inference for text: Frozen Base Text LLM → Output Logits, skipping added layers)

- **Critical path:**
  1. Load pre-trained text LLM, freeze all parameters.
  2. Expand tokenizer vocabulary with speech tokens; resize embedding layer; initialize new token embeddings.
  3. Insert m new layers (transformer or E-Branchformer) at chosen positions (e.g., after every k original layers).
  4. Apply function-preserving initialization to added layers (zero-init output projections or W_Merge=[I;0]).
  5. Train only added layer parameters and new embeddings on speech data (ASR transcripts).
  6. For speech inference: use full model. For text inference: skip added layers entirely.

- **Design tradeoffs:**
  - **Layer Placement:** Interleaved placement gives best ASR but most text degradation when kept; top-heavy (TOP) placement best preserves text but yields worse ASR.
  - **Added Architecture:** E-Branchformer adds ~15% more parameters than standard transformer but improves WER via local processing. Standard transformer is simpler.
  - **Trainable Budget:** More added layers (higher m) increases ASR capacity but also training cost and potential text degradation if not dropped.

- **Failure signatures:**
  1. **Poor ASR despite training:** Likely due to incorrect function-preserving initialization (added layers not starting as identity), causing unstable updates or representation corruption.
  2. **Severe text degradation even after dropping layers:** Indicates original layers were not truly frozen or layer-dropping logic is flawed; the model should recover exactly.
  3. **No improvement over LoRA on small model:** Base model capacity may be insufficient; more added layers or a larger base model may be needed.

- **First 3 experiments:**
  1. **Validate identity initialization:** Forward a text batch through the model with added layers before any training. Output logits must be identical (tolerance ~1e-6) to the frozen base model's logits.
  2. **Test layer-drop recovery:** After minimal training (e.g., 100 steps), evaluate text benchmarks with added layers dropped. Scores must match the exact pre-trained baseline (no degradation).
  3. **Compare placement/architecture on subset:** Train on 1% data for 1-2 epochs with INTERLEAVED vs TOP placement and Standard vs E-Branchformer. Expect: INTERLEAVED yields lower WER; TOP yields higher text accuracy; E-Branchformer yields lower WER than Standard.

## Open Questions the Paper Calls Out
- Does multimodal depth up-scaling generalize to speech tasks beyond ASR (e.g., spoken QA, speech translation) and to languages with different phonetic/morphological properties?
- What specific architectural components of E-Branchformer (e.g., convolutional branch vs. merge module) make it more effective than standard transformer layers when used as inserted layers?
- Does the advantage of depth up-scaling hold for significantly larger base LLMs (e.g., 7B+) and different architectural families (e.g., decoder-only vs. encoder-decoder)?
- What is the theoretical explanation for the reversed ranking of layer placement strategies between ASR performance (INTERLEAVED best) and text preservation (TOP best)?

## Limitations
- Details on the OWSM v3.2 dataset preprocessing and exact speech token generation models are unspecified, hindering faithful reproduction.
- The precise implementation of E-Branchformer's function-preserving initialization (matrix shapes, conditional local branch) is underspecified.
- Experiments are limited to two small SmolLM2 models (360M, 1.7B); generalizability to larger models or other architectures is unproven.

## Confidence
- **Forgetting prevention via frozen base + layer-drop:** High (clear mechanism, strong empirical recovery).
- **Function-preserving initialization:** Medium (ablation shows benefit but implementation details missing).
- **E-Branchformer advantage over standard transformer:** Medium (consistent but marginal WER improvements).
- **Scalability to larger models/other tasks:** Low (no evidence provided).
