# ITLC at SemEval-2026 Task 11: Normalization and Deterministic Parsing for Formal Reasoning in LLMs

## Quick Facts
- arXiv ID: 2603.02676
- Source URL: https://arxiv.org/abs/2603.02676
- Reference count: 40
- Primary result: Top-5 rankings across all subtasks with reduced content effects

## Executive Summary
This paper addresses content effects in large language model reasoning by introducing a method that transforms syllogistic arguments into canonical logical representations and applies deterministic parsing to determine validity. Evaluated on the SemEval-2026 Task 11 multilingual benchmark, the approach achieves top-5 rankings across all subtasks while substantially reducing content effects. The method demonstrates perfect accuracy with zero bias in English-only validity inference and maintains strong performance in multilingual settings through English-pivot normalization, offering a competitive alternative to complex fine-tuning or activation-level interventions.

## Method Summary
The approach combines normalization and deterministic parsing to improve formal reasoning in LLMs. Normalization transforms syllogistic arguments into canonical logical representations by standardizing premise structure, logical connectives, and argument patterns. This process converts diverse linguistic formulations into consistent logical forms that eliminate surface-level variations. Deterministic parsing then applies rule-based evaluation to assess argument validity, systematically checking for logical fallacies, consistency with established inference rules, and proper application of syllogistic reasoning principles. The method leverages multilingual capabilities through English-pivot normalization, where non-English arguments are translated to English before canonical transformation, ensuring consistent processing across languages while maintaining performance parity.

## Key Results
- Achieved top-5 rankings across all SemEval-2026 Task 11 subtasks
- Demonstrated perfect accuracy with zero bias in English-only validity inference
- Substantially reduced content effects compared to baseline LLM reasoning approaches

## Why This Works (Mechanism)
The method succeeds by addressing the fundamental challenge of content effects through structural standardization and rule-based evaluation. By transforming arguments into canonical logical representations, the approach removes linguistic variability and cultural biases that typically influence LLM reasoning. Deterministic parsing provides consistent, rule-based evaluation that bypasses the probabilistic reasoning inherent in LLMs, eliminating susceptibility to content-based reasoning errors. The English-pivot normalization strategy enables effective multilingual processing while maintaining logical consistency across languages, as the canonical transformation occurs at a structural level that transcends surface linguistic differences.

## Architecture Onboarding

Component Map: Syllogistic Input -> English-Pivot Translation -> Canonical Normalization -> Deterministic Parsing -> Validity Output

Critical Path: Input Argument → Translation (if needed) → Canonical Transformation → Rule-Based Validity Check → Output Decision

Design Tradeoffs:
- Complexity vs. Performance: Added translation and normalization steps increase processing time but improve accuracy
- Multilingual Support vs. Resource Requirements: English-pivot approach simplifies multilingual handling at potential translation quality cost
- Rule-Based Rigor vs. Flexibility: Deterministic parsing ensures consistency but may miss nuanced reasoning patterns

Failure Signatures:
- Translation artifacts causing canonicalization errors
- Canonicalization failures on highly idiomatic or culturally-specific arguments
- Rule-based parsing missing valid but non-standard logical structures
- Performance degradation with extremely long or complex arguments
