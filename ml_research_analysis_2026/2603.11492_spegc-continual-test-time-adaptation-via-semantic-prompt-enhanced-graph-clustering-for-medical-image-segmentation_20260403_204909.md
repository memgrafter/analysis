# SPEGC: Continual Test-Time Adaptation via Semantic-Prompt-Enhanced Graph Clustering for Medical Image Segmentation

## Quick Facts
- **arXiv ID:** 2603.11492
- **Source URL:** https://arxiv.org/abs/2603.11492
- **Reference count:** 40
- **Primary result:** Achieves state-of-the-art average Dice Similarity Coefficient (DSC) of 84.37% (retinal OD/OC) and 78.27% (polyp) with only 1.27% degradation over long-term continual test-time adaptation.

## Executive Summary
The paper presents SPEGC, a method for continual test-time adaptation (CTTA) in medical image segmentation. SPEGC enables a pre-trained model to adapt to an unending stream of target domains without catastrophic forgetting or error accumulation. Its core innovations are a Semantic Prompt Feature Enhancement (SPFE) module that injects global context via decoupled commonality/heterogeneity prompts, and a Differentiable Graph Clustering Solver (DGCS) that refines a similarity matrix using optimal transport to obtain a high-order structural representation. Evaluated on retinal fundus and polyp segmentation benchmarks, SPEGC surpasses prior work by notable margins and exhibits exceptional stability in long‑term CTTA scenarios.

## Method Summary
Given an unlabeled test image, SPEGC first extracts features using a pre-trained ResNet‑50 backbone. To mitigate noise under domain shift, the SPFE module samples low‑uncertainty foreground nodes (via MC Dropout) and enhances them by retrieving prompts from two learned pools: a commonality pool (via reverse‑attention to capture shared semantics) and a heterogeneity pool (via standard attention for domain‑specific variations). The enhanced node features from the current image and the previous *N* images are stored in a queue, forming a pseudo‑batch. From this batch, DGCS constructs an initial similarity matrix, applies density‑weighting, and reformulates edge sparsification as an entropy‑regularized optimal transport problem. The resulting refined matrix *S*<sup>*</sup> encodes a robust high‑order graph structure. The segmentation head then produces predictions; two unsupervised losses—graph consistency (*L*<sub>G</sub>) and clustering (*L*<sub>C</sub>)—supervise cluster‑level alignment and preservation of common semantics. All parameters (backbone, prompts, projections) are updated online via backpropagation using *L* = *L*<sub>G</sub> + λ*L*<sub>C</sub>. After the update, a deterministic forward pass yields the final segmentation for the current image.

## Key Results
- On retinal fundus segmentation (OD/OC), SPEGC reaches **84.37%** average DSC, improving over the previous SOTA by **1.49%** (82.88%).
- On polyp segmentation, it achieves **78.27%** average DSC, a **2.07%** gain over prior methods (76.20%).
- Under long‑term CTTA (multiple sequential domains), SPEGC degrades by only **1.27%** and maintains **83.10%** average DSC, demonstrating robustness to error accumulation and forgetting.

## Why This Works (Mechanism)
SPEGC’s success rests on three synergistic mechanisms. **Semantic Prompt Feature Enhancement (SPFE)** counters local feature vulnerability by injecting global context. It maintains two learnable prompt pools—commonality (PCO) via reverse‑attention to encode cross‑domain shared semantics, and heterogeneity (PHE) via standard attention for domain‑specific variations. The prompts are added to low‑uncertainty foreground nodes, yielding robust features. The design is substantiated by equations (e.g., Eq. 3, 7, 17) and ablation (Table 4), though direct corpus support is limited. **Differentiable Graph Clustering Solver (DGCS)** converts a noisy raw similarity matrix into a refined high‑order structure. Node densities weight edges, and edge sparsification is cast as an optimal transport problem with marginal constraints selecting exactly *k* edges. Entropy‑regularized Sinkhorn iterations solve it differentiably, producing a soft matrix *S*<sup>*</sup> approximating global consistency. The mathematics is fully detailed (Eqs. 9–14) but not previously validated in the corpus. **Cluster‑level supervision** via *L*<sub>G</sub> (KL divergence between predictions of linked nodes) and *L*<sub>C</sub> (clustering of commonality prompts) enforces structural consistency and preserves shared knowledge, directly tackling error accumulation and forgetting. Strong empirical evidence (Table 3) shows minimal degradation, though inaccurate graphs or contaminated prompts could invert benefits.

## Architecture Onboarding
**Component map:**  
Unlabeled test image → Backbone (ResNet‑50) → SPFE (uncertainty sampling, prompt retrieval from PCO/PHE) → enhanced node features → Feature queue (stores last *N* images) → pseudo‑batch → DGCS (raw similarity, density weighting, optimal transport via Sinkhorn) → refined matrix *S*<sup>*</sup> → Segmentation head → predictions → Losses (*L*<sub>G</sub>, *L*<sub>C</sub>) → total loss *L* → backpropagation updates all parameters (backbone, prompts, projections, head)

**Critical path (per test image):**
1. Extract features and sample low‑uncertainty foreground nodes (MC Dropout).
2. Enhance nodes via SPFE prompts.
3. Enqueue features; maintain pseudo‑batch of size *N*+1.
4. Build graph from pseudo‑batch; apply DGCS to obtain *S*<sup>*</sup>.
5. Forward through segmentation head to get predictions.
6. Compute *L*<sub>G</sub> (KL between predictions of linked nodes) and *L*<sub>C</sub> (commonality prompt clustering).
7. Backpropagate *L* = *L*<sub>G</sub> + λ*L*<sub>C</sub> and update all parameters with SGD.
8. After update, run deterministic forward on current image for final output; dequeue oldest if necessary.

**Design tradeoffs:**
- *Computational cost*: Affinity matrix scales quadratically with pseudo‑batch size; a larger queue improves context but increases memory and FLOPs. The authors choose *N*=3 as a compromise.
- *Hyperparameter sensitivity*: Cluster count *Z* controls sparsity budget; too small merges distinct semantics, too large fragments. Prompt count *M* trades capacity for memory. λ balances *L*<sub>G</sub> and *L*<sub>C</sub>.
- *Prompt decoupling vs. complexity*: Separate PCO/PHE adds parameters and *L*<sub>C</sub> but explicitly separates shared and domain‑specific knowledge. Ablations confirm its necessity.
- *Differentiability vs. fidelity*: Entropy regularization in optimal transport enables end‑to‑end training but yields soft assignments that approximate strict sparsity.

**Failure signatures:**
- Steady performance drop across the continual stream (error accumulation).
- *L*<sub>G</sub> or *L*<sub>C</sub> diverging or plateauing at high values.
- *S*<sup>*</sup> becoming overly sparse or dense (detectable via edge entropy statistics).
- Predictions reverting to source‑domain bias, fragmenting, or losing fine details.

**First 3 experiments (reproduction checks):**
1. **Baseline replication:** Run SPEGC on a single source‑target pair (e.g., retinal domain A→B) and verify that average DSC matches Table 1 within statistical variance.
2. **Component ablation:** Reproduce Table 4 by systematically removing SPFE components (commonality/heterogeneity prompts) and DGCS; quantify each contribution.
3. **Hyperparameter sweep:** Vary *Z* (e.g., 16, 32, 48, 64) and *M* (e.g., 4, 8, 12) to observe performance trends; confirm that defaults (*Z*=48, *M*=8) are near‑optimal and gauge sensitivity.

## Open Questions the Paper Calls Out
- **Graph sparsification / OT approximations:** How can DGCS reduce its O(*V*²) computational cost while preserving adaptation performance? The authors acknowledge this limitation and suggest exploring more efficient graph sparsification or optimal transport solvers.
- **Generalizability across modalities:** How well does SPEGC transfer to other medical imaging tasks (e.g., MRI, CT, ultrasound) beyond retinal fundus and polyp segmentation? Experiments are currently limited to two specific benchmarks.
- **Prompt disentanglement and hyperparameter effects:** Does the decoupled prompt design truly separate common and domain‑specific features? How do key hyperparameters (*M*, *Z*) affect this disentanglement and adaptation stability? The paper provides no direct evidence.
- **Failure modes of cluster‑level supervision:** Under what conditions does DGCS‑derived cluster supervision fail to prevent error accumulation, and how does it compare to pixel‑level losses in robustness to initial prediction errors? The claim of superior robustness is empirical but not theoretically bounded.

## Limitations
- **Insufficient implementation details:** Critical hyperparameters and procedural choices (e.g., exact node count, foreground thresholding, queue recomputation policy, τ, Sinkhorn iterations, prompt initialization) are omitted, hindering exact replication.
- **Quadratic computational cost:** Explicit graph construction scales poorly with high‑resolution or 3D volumes, limiting clinical applicability.
- **Limited modality coverage:** Validation is restricted to retinal fundus and polyp datasets; generalizability to diverse medical imaging scenarios remains unproven.
