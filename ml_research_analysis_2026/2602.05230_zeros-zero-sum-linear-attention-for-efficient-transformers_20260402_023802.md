# ZeroS: Zero-Sum Linear Attention for Efficient Transformers

## Quick Facts
- **arXiv ID:** 2602.05230
- **Source URL:** https://arxiv.org/abs/2602.05230
- **Reference count:** 40
- **Primary result:** ZeroS achieves linear complexity O(N) while matching or exceeding standard softmax attention on language modeling, in-context learning, associative recall, and time series forecasting.

## Executive Summary
ZeroS introduces Zero-Sum Linear Attention, a modification to linear attention mechanisms that removes the constant zero-order term (1/t) from the softmax decomposition and reweights the remaining zero-sum residuals. This enables stable negative weights and contrastive operations within a single layer while preserving O(N) complexity. Theoretically, it expands the representable function class beyond convex combinations. Empirically, ZeroS matches or surpasses softmax attention on multiple benchmarks, including WikiText-103 (perplexity 24.61 vs. 24.78), MAD in-context tasks (73.5% vs. 74.5% for Transformer), and time series forecasting. The approach is simple to integrate and maintains linear-time efficiency.

## Method Summary
ZeroS modifies the standard attention mechanism by decomposing the softmax into zero-order, first-order, and higher-order residuals. It removes the zero-order term (1/t) and reweights the first-order and higher-order residuals via learned gates σ₁ᵗ and σₕᵗ, producing zero-sum attention weights. To restore directional sensitivity lost in linear attention, ZeroS multiplies these weights by the cosine similarity of normalized queries and keys (radial-angular decoupling). The attention computation is implemented with prefix sums to maintain O(N) complexity and O(d²) memory. The method integrates seamlessly into transformer architectures by replacing multi-head attention without altering other components.

## Key Results
- **WikiText-103:** ZeroS achieves test perplexity 24.61 (vs. Transformer 24.78) and ZeroS-SM variant reaches 24.17.
- **MAD in-context tasks:** ZeroS averages 73.5% accuracy, comparable to Transformer's 74.5% and far above standard linear attention (62.3%).
- **MQAR (associative recall):** ZeroS maintains consistent performance across varying sequence lengths, unlike other linear methods that degrade with longer contexts.
- **Time series forecasting:** Outperforms recent linear attention variants (GLA, AFT) on multiple datasets.

## Why This Works (Mechanism)
### Mechanism 1
Removing the constant 1/t term from softmax yields zero-sum attention weights that can take negative values. This expands the representable set from convex combinations to zero-sum spans, enabling contrastive operations (e.g., v₁ - v₂) within a single layer. Stability is maintained via bounded logits and gated residuals. Theoretically, Proposition 3.1 and Corollary 3.2 show that zero-sum spans strictly contain convex deviation sets, leading to expressivity gains. This mechanism addresses the limitation of linear attention's uniform weight dilution and convexity constraint.

### Mechanism 2
Separate gating of first-order (δᵢ/t) and higher-order (εᵢ) residuals via learned scalars σ₁ᵗ and σₕᵗ allows step-dependent control over different interaction orders. This dynamic reweighting enhances flexibility, letting the model amplify or suppress linear vs. nonlinear token interactions based on context. The decomposition into orthogonal softmax components is meaningful and stable, and the t-dependent gates introduce necessary coupling between the current step and history.

### Mechanism 3
Radial-angular decoupling multiplies zero-sum radial weights by cosine similarity from normalized queries/keys. This restores the angle-flipping effect lost in linear attention (which relies on positive feature maps). The product rₜ,ᵢ cosθ mimics softmax's exp(∥q∥∥k∥cosθ) without positivity constraints, allowing sign changes when cosθ is negative, thus improving directional modeling.

## Foundational Learning
- **Softmax Attention as Convex Combination**: Standard attention weights are non-negative and sum to 1, forming a convex combination of values. This limits expressivity (e.g., cannot compute subtraction in one layer).  
  *Why needed?* Highlights the core limitation that ZeroS overcomes.  
  *Quick check*: Why can't a single softmax layer compute v₁ - v₂? (Answer: coefficients must be non-negative and sum to 1.)

- **Linear Attention Approximations**: Kernel-based methods (e.g., ϕ(q)ϕ(k)ᵀ) reduce attention to O(N) by factorizing the QK product. They often suffer from expressivity loss.  
  *Why needed?* ZeroS maintains O(N) complexity while improving expressivity.  
  *Quick check*: How does linear attention achieve O(N) complexity, and what trade-offs does it typically incur?

- **Expressivity and Affine Spans**: Convex spans are subsets of affine (zero-sum) spans. Zero-sum weights allow subtraction, expanding representable functions.  
  *Why needed?* Theoretically justifies ZeroS's gain.  
  *Quick check*: Describe the set of outputs possible with convex weights vs. zero-sum weights for two vectors v₁, v₂.

- **Radial-Angular Decoupling**: Separating magnitude (radial) and direction (angular) components can restore properties of softmax.  
  *Why needed?* Compensates for linear attention's loss of sign information.  
  *Quick check*: What effect does cosine similarity have in softmax attention that linear attention misses?

- **Gating Mechanisms**: Learned gates (e.g., sigmoid) control contributions of different terms, providing adaptability.  
  *Why needed?* Enables dynamic, context-dependent weighting.  
  *Quick check*: Why gate first-order and higher-order residuals separately rather than with a single gate?

## Architecture Onboarding
Component map: Input → compute uᵢ and sᵢ → accumulate prefix sums (E, P, F, G, H) → at each step t, compute gates σ₁ᵗ, σₕᵗ from xₜ → combine scans to get rₜ,ᵢ → multiply by ˆqₜ cosθ → add residual → output.

Critical path: During the forward pass, the model computes per-token features uᵢ and deviation logits sᵢ = - (1/√d) uᵢ ¯uᵢᵤ using a smoothed cumulative average ¯uᵢ. It maintains running prefix sums (Eₜ, Pₜ, Fₜ, Gₜ, Hₜ) updated in O(d²) per step. At step t, it computes the gates σ₁ᵗ = sigmoid(g₁ᵗ) and σₕᵗ = sigmoid(gₕᵗ) from the current hidden state, combines the prefix sums to obtain the zero-sum radial weight rₜ,ᵢ, then multiplies by the cosine similarity between normalized query and key (with RoPE). The result is added to a residual connection.

Design tradeoffs:
- Zero-order term: Typically removed; optionally retained in first layer via σ₀ᵗ but generally decreases expressivity.
- Gating: Two gates (σ₁, σₕ) balance flexibility and parameter count; more gates risk overfitting.
- Normalization: LayerNorm is crucial; without it, performance drops on algorithmic tasks.
- Complexity: O(N d²) time, O(d²) memory; prefix sums avoid full matrix multiplication. Compares favorably to O(N²) softmax and some O(N) variants.

Failure signatures:
- Numerical instability: Unbounded negative weights or logits cause NaNs. Monitor max |rₜ,ᵢ| and gates; use gradient clipping.
- Causality violation: Off-by-one errors in prefix sums leak future information. Validate by checking that only past tokens influence current output and that sum of rₜ,ᵢ across i ≈ 0.
- Loss of magnitude information: Normalization might discard useful signal; tasks that rely on magnitude may suffer.
- Ablation sensitivity: Removing the angular component (cosθ) or radial gating drastically reduces accuracy on MAD tasks.

First 3 experiments:
1. **WikiText-103**: Replace MHA with ZeroS in a GPT-2 style model (~46M params). Expect test perplexity ≤ 24.78 (vanilla Transformer) and ≤ 24.17 for ZeroS-SM.
2. **MAD Benchmark**: Evaluate on in-context learning tasks (e.g., In-Context Recall, Noisy Recall). ZeroS should exceed standard linear attention (~62.3%) and approach Transformer (74.5%).
3. **MQAR (Multi-Query Associative Recall)**: Test across sequence lengths (e.g., 512 to 4096). ZeroS accuracy should remain stable, not degrading at longer contexts, unlike some linear methods.

## Open Questions the Paper Calls Out
- **Large-scale model training**: The authors did not evaluate ZeroS on billion-parameter LLMs due to resource constraints. It is unclear if benefits persist at scale.
- **Non-causal attention**: ZeroS is primarily evaluated on autoregressive tasks. Its effectiveness on bidirectional tasks (e.g., MLM, vision transformers) remains unknown.
- **Fused kernel implementation**: The current multi-scan approach may not achieve the full practical O(N) advantage. A dedicated CUDA kernel could significantly improve real-world efficiency and latency.

## Limitations
- **Reproducibility blockers**: Exact model architectures, hyperparameter schedules, and random seeds are not specified, hindering faithful replication.
- **Task-specific expressivity trade-off**: Zero-sum weights may harm tasks requiring strictly convex combinations; ablations show performance drops in some settings when convexity is removed.
- **Unverified practical gains**: Theoretical O(N) complexity does not automatically translate to wall-clock speedups against optimized softmax kernels (e.g., FlashAttention-2); no fused implementation exists.

## Confidence
- **Core mechanism (zero-sum weights, O(N) complexity):** High
- **Benchmark superiority claims (WikiText/MAD/MQAR):** Medium (due to reproduction ambiguities)
- **Universal matching/exceeding softmax:** Low (break conditions suggest limitations)

## Next Checks
