# Losses that Cook: Topological Optimal Transport for Structured Recipe Generation
## Quick Facts
- **arXiv ID:** 2601.02531
- **Source URL:** https://arxiv.org/abs/2601.02531
- **Reference Count:** 15
- **Primary Result:** A mixed training objective combining cross-entropy, topological (Sinkhorn), and Dice losses yields a 67.5% reduction in critical generation errors (missing ingredients, step mismatches) and is preferred by human evaluators in 62% of cases, with notable gains in ingredient recall and quantity/time precision.

## Executive Summary
Standard maximum likelihood training for recipe generation, which uses token-level cross-entropy loss, produces linguistically fluent outputs but suffers from factual inaccuracies such as missing ingredients, incorrect quantities, or incoherent procedural steps. This paper introduces two novel, complementary loss functions to address this: a topological loss that aligns the geometric structure of predicted and reference ingredient lists in the model's embedding space via Sinkhorn divergence, and a Dice loss that emphasizes exact token-set overlap for critical numeric parameters. When combined with the standard loss in a carefully weighted composite objective, these losses significantly improve multi-faceted recipe correctness—including ingredient completeness, quantity plausibility, and temporal accuracy—over strong cross-entropy baselines, as measured by both automated metrics and human evaluation.

## Method Summary
The authors fine-tune a 4-billion parameter Qwen3 model using LoRA adapters. The core innovation is a composite training loss: `L_total = 0.6 * L_CE + 0.2 * L_Dice + 0.2 * L_Topo`. The standard cross-entropy (`L_CE`) maintains linguistic fluency. The Dice loss (`L_Dice`) maximizes F1-like set overlap between generated and reference token sequences, proving highly effective for sparse but critical numeric tokens (times, temperatures). The novel topological loss (`L_Topo`) operates only on the ingredient section. It constructs a "soft" point cloud from the predicted ingredient token probability distribution (a weighted average of token embeddings) and a "hard" point cloud from the gold ingredient token embeddings. It then minimizes their Sinkhorn divergence (with entropic regularization ε=0.05), which encourages the predicted set of ingredient vectors to preserve the same semantic and structural relationships as the reference set (e.g., similar ingredients remain proximate). Training uses the RECIPE-NLG dataset (pasta, rice, sandwiches) augmented with 235 curated QA pairs. Evaluation relies on a suite of recipe-specific metrics (Ingredient Recall, Quantity Precision, Action/Step Edit Distances, Time/Temp Precision) computed by extracting structured data from generated text with a separate Qwen3-based NER pipeline.

## Key Results
- The mixed loss model achieves the best overall trade-offs, significantly improving Ingredient Recall (IR) and Quantity Precision (QP) while matching the lowest Action and Step Edit Distances (AD, SD).
- Dice loss alone yields the strongest Time and Temperature Precision (TiP, TeP), demonstrating its suitability for sparse numeric token recovery.
- Human evaluators prefer the mixed-loss model over the CE baseline in 62% of comparisons, and it reduces critical errors (missing ingredients, step mismatches) by 67.5%.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The topological loss improves ingredient recall and procedural coherence by aligning the geometric structure of predicted and reference ingredient lists in the model's embedding space.
- **Mechanism:** For the ingredient section, the loss converts predicted token probabilities into a soft average embedding (`emb_soft = P · E`) and retrieves hard embeddings for gold tokens (`emb_hard`). Minimizing the Sinkhorn divergence between these two point clouds encourages the model to generate a set of ingredient tokens whose collective embedding geometry matches the reference. This holistic penalty goes beyond token-wise accuracy to enforce semantic and set-level structural correctness (e.g., generating "olive oil" instead of an unrelated fat).
- **Core assumption:** The pretrained embedding space encodes meaningful culinary semantics (e.g., ingredient categories, pairings), so aligning point cloud shapes correlates with factual correctness.
- **Evidence anchors:**
  - [abstract] "introduce a topological loss that represents ingredient lists as point clouds in embedding space, minimizing the divergence between predicted and gold ingredients."
  - [section 2.3.1] Formal definition of soft/hard embeddings and Sinkhorn computation.
- **Break condition:** If the base model's embeddings do not cluster semantically related ingredients, the topological signal is weak or misaligned.

### Mechanism 2
- **Claim:** Dice loss excels at time/temperature precision by optimizing for set-level token overlap, which is highly effective for sparse, high-impact numeric tokens.
- **Mechanism:** Dice loss directly maximizes the F1 score between the set of predicted tokens and the set of gold tokens in the full sequence. This creates a strong, direct incentive for the model to include exact numeric and unit tokens (e.g., "180°C", "20 minutes"), even if they are rare, without requiring them to be in the correct sequential context.
- **Core assumption:** Critical numeric parameters are discrete, sparse tokens whose presence/absence is a primary determinant of recipe executability; set-overlap is a suitable proxy for their accuracy.
- **Evidence anchors:**
  - [abstract] "Dice loss alone excels at time/temperature precision."
  - [section 3.2] "Dice loss yields stronger gains... with notable improvements in QP, TeP, and TiP."
- **Break condition:** If numeric correctness requires complex relational reasoning (e.g., "twice as long" or unit conversion) beyond simple token recovery, Dice loss may be insufficient.

### Mechanism 3
- **Claim:** The mixed objective (CE + Topological + Dice) yields synergistic gains by holistically balancing ingredient structure (Topological), numeric accuracy (Dice), and linguistic fluency (CE).
- **Mechanism:** The composite weighting (0.6 CE + 0.2 Dice + 0.2 Topological) allows each component to regularize distinct failure modes: CE preventsdegenerate or ungrammatical text; Topological Loss aligns the ingredient set's semantic structure; Dice Loss sharpens recall of sparse numeric tokens. Their gradients are combined additively, targeting orthogonal dimensions of recipe quality.
- **Core assumption:** The three loss components target largely independent aspects of the generation problem, so their combination does not cause destructive gradient interference.
- **Evidence anchors:**
  - [abstract] "mixed loss yields competitive trade-offs with synergistic gains in quantity and time."
  - [section 3.2] Combined model achieves best R1, BS, QP, and TiP while matching best edit distances.
- **Break condition:** If the loss gradients conflict significantly (e.g., topological alignment pushes for one ingredient wording while numeric precision requires another), the fixed weighting may fail to find a balanced optimum.

## Foundational Learning
- **Concept: Optimal Transport / Sinkhorn Divergence**
  - *Why needed here:* The topological loss uses Sinkhorn divergence as a differentiable measure of distance between two point clouds (predicted vs. gold ingredient embeddings). This is the core computational mechanism for enforcing geometric alignment.
  - *Quick check question:* How does adding entropic regularization (ε) to the optimal transport problem make the loss differentiable and computationally feasible for gradient-based training?
- **Concept: Embedding Space Geometry**
  - *Why needed here:* The entire topological mechanism assumes the pretrained model's token embedding space encodes meaningful culinary semantics. The loss operates directly in this space; its success hinges on this structure.
  - *Quick check question:* Why use a weighted average of embeddings (soft embeddings) for the predicted ingredient list instead of just taking the argmax token embeddings?
- **Concept: Recipe-Specific Constraints & Metrics**
  - *Why needed here:* Standard NLG metrics (ROUGE, BERTScore) are insufficient for recipes. The paper defines distinct metrics (IR, QP, AD, SD, TiP, TeP) that measure executability, requiring an understanding of recipe structure.
  - *Quick check question:* Why would a recipe with a high ROUGE score still be unusable? Give an example based on the paper's error categories.

## Architecture Onboarding
- **Component map:**
  Input Prompt -> LLM backbone (Qwen3-4B) -> Token Logits -> [For training: Loss module] -> LoRA adapters (applied to attention layers) -> Backpropagation.
  Loss module composites: `L_CE` (on all tokens) + `L_Topo` (on ingredient-section logits) + `L_Dice` (on all tokens).
  Embedding extractor accesses model's `E` matrix to compute `emb_soft = P · E` for topological loss.
  Post-generation: NER pipeline (Qwen3-4B-based) extracts `{quantity, unit, time, temperature, action}` -> Metric calculator computes IR, QP, AD, SD, TiP, TeP.
- **Critical path:**
  1. Forward pass on a training batch: prompt -> LLM -> token logits for full sequence.
  2. Isolate logits corresponding to the *ingredient section* (delimited in the training data).
  3. For `L_Topo`: Compute softmax probabilities `P` over ingredient-section logits. Compute `emb_soft = P · E`. Look up `emb_hard` as embeddings of gold ingredient tokens (method ambiguous: per-token or averaged per-ingredient?).
  4. Compute `L_Topo = Sinkhorn(emb_soft, emb_hard, ε)`.
  5. For `L_Dice`: Compute set overlap between predicted and gold token sequences (one-hot) over the full sequence.
  6. Combine: `L_total = 0.6*L_CE + 0.2*L_Dice + 0.2*L_Topo`.
  7. Backpropagate `L_total` and update LoRA parameters.
- **Design tradeoffs:**
  - *Computational overhead:* `L_Topo` requires Sinkhorn iterations (O(n²) in number of ingredient tokens), increasing memory/time vs. CE-only. May necessitate smaller batch sizes.
  - *Hyperparameter sensitivity:* The Sinkhorn regularization ε (paper uses 0.05) and loss weights (0.6/0.2/0.2) are heuristic; different datasets/cuisines likely require retuning.
  - *Fluency vs. correctness:* High weight on custom losses risks degrading linguistic quality (ROUGE/BERTScore). The chosen 0.6 CE weight is a balancing act.
  - *Embedding dependency:* Performance relies on the base model's embedding space already capturing culinary semantics. If not, `L_Topo` provides poor signal.
- **Failure signatures:**
  - *Topological loss ineffective:* No improvement in Ingredient Recall (IR) or Action/Step Edit Distances (AD, SD) over CE baseline.
  - *Dice loss overfitting:* Massive gains in TiP/TeP but significant drop in IR or ROUGE, indicating the model is "cheating" by copying numeric tokens unnaturally.
  - *Mixed loss instability:* Training loss diverges or oscillates, suggesting gradient conflict; reduce custom loss weights or implement gradient normalization.
  - *Metric extraction failures:* The NER pipeline fails to parse generated steps (e.g., "cook until al dente"), producing noisy QP/AD/SD scores that do not reflect generator quality.
- **First 3 experiments:**
  1. **Baseline replication:** Fine-tune Qwen3-4B with LoRA using only `L_CE`. Reproduce the baseline metrics in Table 1 (e.g., IR ~36%, AD ~37.8) to validate the data pipeline and base setup.
  2. **Ablation - Topological alone:** Train with `L = 0.6 * L_CE + 0.4 * L_Topo`. Expect improved IR and AD/SD but possibly weaker TiP/TeP compared to Dice-including models.
  3. **Mixed loss replication:** Train with `L = 0.6 * L_CE + 0.2 * L_Dice + 0.2 * L_Topo`. Verify achievement of the reported best QP and TiP while maintaining low AD/SD. Tune ε if `L_Topo` is unstable.

## Open Questions the Paper Calls Out
- **Open Question 1:** How well does the topological loss generalize to recipes from non-Western cuisines and with complex dietary restrictions?
  - *Basis in paper:* Future work includes scaling to "broader cuisines and dietary constraints."
  - *Why unresolved:* Training only on pasta/rice/sandwiches; may not capture ingredient relationships in, e.g., Asian or vegan recipes.
  - *What evidence would resolve it:* Test on diverse datasets (e.g., Recipe1M global subset) with metrics disaggregated by cuisine type and dietary constraint satisfaction.
- **Open Question 2:** Is the performance gain from the topological loss consistent across different model architectures and embedding spaces?
  - *Basis in paper:* Limitations note dependence on embedding geometry; experiments show positive trends on 3B and 1.5B models but hyperparameters may need retuning.
  - *Why unresolved:* Embedding topology varies by architecture (e.g., RoBERTa vs. GPT); Sinkhorn divergence may not align equally.
  - *What evidence would resolve it:* Evaluate on at least 5 architectures (decoder-only, encoder-decoder, etc.) with fixed ε, reporting metric improvements and training stability.
- **Open Question 3:** Can we design recipe evaluation metrics that are robust to paraphrasing and formatting, reducing reliance on brittle NER extraction?
  - *Basis in paper:* Limitations state automated extraction is "brittle to paraphrase, formatting deviations."
  - *Why unresolved:* Current metrics may penalize models for creative but correct outputs; noisy scores hinder fair assessment.
  - *What evidence would resolve it:* Develop embedding-based or constraint-based metrics; correlate with human judgments on paraphrased recipes to establish validity.

## Limitations
- **Implementation Ambiguity:** The exact construction of the "point cloud" for the topological loss is unspecified (e.g., which tokens are included, how per-ingredient vs. per-token embeddings are aggregated), hindering faithful reproduction.
- **Evaluation Bottleneck:** The recipe-specific metrics depend on a separate NER extraction pipeline (using Qwen3-4B), whose prompt, fine-tuning, and parsing logic are not detailed. Its potential brittleness could bias all reported quantitative results.
- **Embedding Assumption:** The core mechanism assumes the base model's token embeddings encode meaningful culinary semantics, but this is not verified. If false, the topological loss provides weak or misaligned signal.

## Confidence
- **Topological loss improves ingredient recall and procedural coherence:** **Medium** (empirical evidence present but relies on precise, unspecified implementation and embedding geometry).
- **Dice loss excels at time/temperature precision:** **High** (consistent, explicable gains on sparse numeric tokens across experiments).
- **Mixed objective yields synergistic trade-offs:** **Medium** (achieves best reported results but with heuristically chosen fixed weights; generalization to other settings is unproven).
- **Overall 67.5% reduction in critical errors:** **Medium** (dependent on the potentially noisy NER-based metric pipeline).
