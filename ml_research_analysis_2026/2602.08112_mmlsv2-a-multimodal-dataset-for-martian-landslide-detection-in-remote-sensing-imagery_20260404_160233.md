# MMLSv2: A Multimodal Dataset for Martian Landslide Detection in Remote Sensing Imagery

## Quick Facts
- **arXiv ID:** 2602.08112
- **Source URL:** https://arxiv.org/abs/2602.08112
- **Reference count:** 35
- **Primary result:** MMLSv2 introduces a multimodal Martian landslide dataset with spatial-block partitioning, achieving mIoU 0.81–0.83 on the baseline test split and 0.70–0.73 on a geographically isolated test set; multimodal inputs consistently improve performance over RGB-only (mIoU 0.711 → 0.814).

## Executive Summary
MMLSv2 is a new multimodal dataset for Martian landslide segmentation, comprising 664 georeferenced 128×128 patches with seven aligned bands (RGB, DEM, slope, thermal inertia, grayscale) and corresponding binary masks. The dataset employs a spatial-block partitioning strategy to prevent spatial data leakage between training and evaluation splits and includes a geographically isolated test set of 276 images from a disjoint region of Valles Marineris to assess spatial generalization. Benchmark experiments with standard segmentation models (U-Net, DeepLabV3+, etc.) show stable convergence and significant gains from multimodal fusion. Performance on the isolated test set drops noticeably, confirming its utility for evaluating robustness, though fragmented, elongated, and small-scale landslides remain challenging.

## Method Summary
The dataset consists of 128×128 patches extracted from high-resolution Martian imagery (CTX) and derived products (DEM from MOLA/HRSC, slope, thermal inertia from THEMIS). Splits are generated via a spatial-block strategy: spatially adjacent patches are grouped into 2×2 blocks and assigned wholesale to a single split to prevent leakage, while sampling blocks to balance foreground ratios. The base split contains 465 training, 66 validation, and 133 test images. An additional isolated test set of 276 images from a separate subregion is held out for evaluating spatial generalization. Baseline models are standard segmentation architectures trained with Adam optimizer (lr=0.001), cross-entropy loss, random flip/rotation augmentations, and a step learning rate scheduler for 100 epochs. All seven bands are concatenated as input channels. Performance is evaluated using mean Intersection-over-Union (mIoU) and per-class IoU.

## Key Results
- Multimodal input yields substantial gains: mIoU increases from 0.711 (RGB-only) to 0.814 using all seven bands, with each added band group contributing incremental improvement.
- Baseline models achieve mIoU of 0.81–0.83 on the standard test split, demonstrating effective learning from the multimodal data.
- Evaluation on the geographically isolated test set causes a consistent performance drop (mIoU 0.70–0.73 across models), confirming increased difficulty and the set’s value for probing spatial generalization.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** Spatial-block partitioning prevents spatial information leakage between training and evaluation sets.
- **Mechanism:** Grouping spatially adjacent 128×128 patches into 2×2 spatial blocks and assigning all patches within a block to the same split ensures that no two adjacent patches are distributed across different subsets. This eliminates the risk that a model learns from the context of a training patch and is evaluated on its immediate neighbor, which would artificially inflate performance.
- **Core assumption:** Spatially contiguous patches are highly correlated in appearance and geomorphological context; distributing them across splits violates the independence assumption of held-out evaluation.
- **Evidence anchors:** [abstract] "spatial-block partitioning strategy to prevent data leakage"; [section 2.4] Detailed description of the 2×2 grouping scheme (Equation 2) and its purpose: "preventing adjacent patches from being distributed across different subsets."
- **Break condition:** If the underlying terrain or landslide processes exhibit abrupt, sub-patch scale heterogeneity, adjacent patches may be uncorrelated, making the spatial grouping overly conservative and potentially reducing statistical efficiency of the splits.

### Mechanism 2
- **Claim:** Multimodal band combination (RGB + DEM + Slope + Thermal Inertia + Grayscale) improves segmentation performance by providing complementary, non-redundant geophysical cues.
- **Mechanism:** Each band encodes a different physical property (e.g., optical texture, topography, thermophysical signature). The model learns to weight and fuse these complementary signals, where weaknesses in one modality (e.g., optical ambiguity) are compensated by strengths in another (e.g., slope distinctiveness), leading to more robust foreground delineation.
- **Core assumption:** The seven bands contain partially independent information about landslide presence; their joint distribution is more separable than any single-band distribution.
- **Evidence anchors:** [abstract] "Multimodal inputs consistently improved performance, with mIoU increasing from 0.711 (RGB-only) to 0.814 using all seven bands."; [section 4.2, Table 4] Progressive mIoU gains (0.711 → 0.762 → 0.805 → 0.812 → 0.814) with each added band group, indicating complementary contributions.
- **Break condition:** If a particular band (e.g., thermal inertia) is misregistered, has different noise characteristics, or its geophysical signature is not actually discriminative for landslides in this region, its inclusion could introduce harmful noise or require more sophisticated fusion than simple concatenation.

### Mechanism 3
- **Claim:** The geographically isolated test set acts as a robust probe for spatial generalization by introducing a distribution shift in geomorphological context.
- **Mechanism:** By holding out an entire subregion of Valles Marineris, the isolated test set contains landslide morphologies, spatial configurations, and background terrains that are systematically different from the training distribution. Performance degradation on this set indicates the model's reliance on memorized region-specific patterns rather than learning invariant landslide characteristics.
- **Core assumption:** Landslide expression (size, shape, texture relationships) varies significantly across subregions within Valles Marineris due to differing geological controls, slope angles, or degradation states.
- **Evidence anchors:** [abstract] "Evaluation on the isolated test set caused a noticeable performance drop (mIoU 0.70–0.73), confirming increased difficulty and its utility for assessing robustness."; [section 2.3 & 4.2, Table 3] Explicit definition of the geographic holdout and the consistent mIoU drop (~0.1) across all models, with foreground IoU dropping most sharply; [section 3 & Fig 4] Qualitative description and visualization showing "stronger structural differences, irregular geometries" in the isolated split.
- **Break condition:** If the isolated region is not truly representative of a new geomorphological context (e.g., it's just a noisier or differently annotated part of the same distribution), the performance drop may not reflect a meaningful generalization gap.

## Foundational Learning
- **Concept: Semantic Segmentation for Geomorphological Mapping**
  - *Why needed here:* The task is pixel-wise binary classification (landslide vs. background). Engineers must understand that the loss function (cross-entropy) operates per-pixel, that class imbalance (few landslide pixels) is extreme (e.g., average 21-35% foreground), and that evaluation metrics like mIoU are sensitive to this imbalance.
  - *Quick check question:* If a model predicts "background" for every pixel in a patch with 1% landslide coverage, what would its background IoU, foreground IoU, and mIoU be? (This tests understanding of error propagation in imbalanced segmentation.)
- **Concept: Multimodal Data Fusion via Early Concatenation**
  - *Why needed here:* The dataset provides seven geographically aligned raster bands. The baseline approach is channel-wise concatenation, treating all bands equally. An engineer must grasp that this assumes all bands are on comparable scales and that the architecture's first layer can learn cross-modal filters.
  - *Quick check question:* If the DEM band has values in meters (range 0-10,000) while RGB is 0-255, what preprocessing step is essential before concatenation to prevent the DEM from dominating the gradient signal?
- **Concept: Spatial Generalization and Domain Shift in Remote Sensing**
  - *Why needed here:* The isolated test set is the primary tool for evaluating robustness. Engineers need to conceptualize "domain" as a specific geographic region with its own lighting, geology, and image acquisition parameters. A drop in performance indicates the model has not learned domain-invariant features.
  - *Quick check question:* Would you expect the performance drop on the isolated test set to be larger for a model that heavily relies on texture features (from RGB) versus one that heavily relies on topographic features (from DEM)? Why?

## Architecture Onboarding
- **Component map:** Input (7 bands, 128×128) -> Normalization (per-band) -> Segmentation Model (in_channels=7) -> Output (1, 128×128, sigmoid)
- **Critical path:** 1) Implement dataloader reading provided GeoTIFF patches and masks; 2) Modify a standard segmentation model's first layer to accept 7 channels; 3) Train on training split with Adam (lr=0.001), CE loss, augmentations; 4) Checkpoint best validation mIoU; 5) Evaluate on standard test and isolated test.
- **Design tradeoffs:**
  - *Patch size (128×128):* Fixed by dataset. Too small for large landslide context; too large for memory. Must use this size.
  - *Fusion strategy:* Baseline is simple concatenation. More complex fusion (e.g., modality-specific encoders) could help but increases parameters and may overfit on limited training patches (465 images).
  - *Loss function:* Paper uses standard cross-entropy. Given extreme class imbalance (many patches have <1% foreground), a weighted loss or focal loss might improve foreground recall but could destabilize training. Start with the baseline.
- **Failure signatures:**
  - *Systematic failure on fragmented/elongated landslides:* Predictions appear as speckled noise or broken segments instead of coherent thin lines.
  - *Poor calibration on isolated test set:* mIoU drops >0.1, especially foreground IoU, indicating learned regional biases.
  - *Training instability or early convergence:* If model quickly reaches ~0.85 mIoU on training but <0.75 on validation, it is overfitting to region-specific features, likely because spatial-block partitioning was not correctly implemented, causing leakage.
- **First 3 experiments:**
  1. **Reproduce baseline RGB-only U-Net:** Train U-Net with only first 3 bands on standard splits. Verify ~0.71 mIoU on standard test. Establishes minimal pipeline and quantifies multimodal benefit.
  2. **Full multimodal U-Net:** Train same U-Net with all 7 bands. Validate mIoU increases to ~0.81. Check per-band contribution by ablating DEM, slope, etc., as in Table 4.
  3. **Isolated test evaluation:** Take model from Experiment 2 and run on isolated test set. Measure mIoU drop. If drop <0.05, suspect data leakage bug in splitting logic (e.g., isolated region patches inadvertently included in training).

## Open Questions the Paper Calls Out
- **Q1:** To what extent can dedicated architectural tuning and specialized training strategies improve the performance ceiling of current segmentation models on MMLSv2 beyond the reported baseline?
  - *Basis:* The experimental setup uses uniform hyperparameters without architecture-specific tuning; results are baselines, not upper bounds.
  - *Why unresolved:* True impact of tailored optimization (loss functions, augmentations, schedulers) on this multimodal, imbalanced task is unknown.
  - *What evidence would resolve:* Systematic benchmark where each architecture is individually optimized via autoML or expert search, comparing to uniform baseline.
- **Q2:** Do advanced multimodal fusion techniques (e.g., attention mechanisms, cross-modal feature interaction) provide significant performance improvements over simple channel concatenation for Martian landslide segmentation?
  - *Basis:* Multimodal information is integrated via direct band concatenation; advanced fusion (multi-branch, modality-aware) is unexplored.
  - *Why unresolved:* Optimal method to fuse heterogeneous sources, especially for challenging small/fragmented landslides, is unknown.
  - *What evidence would resolve:* Controlled ablation comparing concatenation against fusion strategies (attention, gating, multimodal transformers) while holding architecture/training constant.
- **Q3:** What specific geomorphological or image characteristics of the isolated test region cause the pronounced performance degradation, and can these be used to define more targeted generalization metrics?
  - *Basis:* Isolated test shows lower average foreground ratio (21.83% vs. ~33%) and a noticeable mIoU drop; authors note increased "fragmented, elongated, and small-scale landslides" but do not analyze causal factors.
  - *Why unresolved:* Performance drop is attributed to "spatial generalization" without isolating whether it stems from morphology, background terrain, imaging conditions, or combination; hinders robust model development.
  - *What evidence would resolve:* Comparative analysis quantifying morphological (size, aspect ratio, compactness), contextual (slope distribution, terrain roughness), and spectral differences between base and isolated regions, correlated with per-sample model error rates.
- **Q4:** How transferable are models trained on MMLSv2's Martian landslides to terrestrial or other planetary landslide datasets, and what domain shifts are most prohibitive?
  - *Basis:* Dataset is explicitly Martian (Valles Marineris); paper evaluates only in-distribution and out-of-distribution (isolated Martian split) generalization; no cross-planetary tests.
  - *Why unresolved:* Utility of MMLSv2 for pre-training or model development beyond Mars is unknown; assumptions about analogies between Martian and terrestrial landslides are unstated.
  - *What evidence would resolve:* Zero-shot or fine-tuning experiments on terrestrial landslide datasets (e.g., Semantic Drone Dataset) and other planetary bodies, measuring performance drops and analyzing failing modalities/features.
- **Q5:** Does the proposed spatial-block partitioning strategy (2×2 blocks) optimally balance spatial independence and foreground representation, or would alternative spatial grouping or split ratios yield more robust evaluation?
  - *Basis:* Partitioning uses "a 2×2 grouping scheme" to prevent leakage and balance foreground ratios; no comparison to other block sizes or stratification methods.
  - *Why unresolved:* Choice of block size (2×2) is ad hoc; different contexts/patch sizes might require different grouping scales; impact on measured generalization is unclear.
  - *What evidence would resolve:* Experimental ablation creating splits with varying block sizes (e.g., 1×1, 3×3, 4×4) or alternative spatial clustering, evaluating if model performance variance on test split is reduced and if isolated test remains consistently challenging across schemes.

## Limitations
- **Input normalization:** Exact per-band normalization (mean/std vs. min-max) is unspecified; using raw values likely harms convergence and comparability.
- **Model hyperparameters:** Baseline architecture details (e.g., U-Net depth, filter counts, dropout) are omitted; reimplementations may vary, affecting performance ceilings.
- **Isolated test validity:** Assumption that the held-out region represents a truly distinct geomorphological domain (vs. noisier annotations) is not empirically verified.

## Confidence
- **Spatial-block partitioning mechanism prevents leakage:** High confidence. Strategy is explicitly defined and logically sound.
- **Multimodal fusion benefit:** High confidence. Supported by strong quantitative gains (Table 4) with each added band group.
- **Isolated test as generalization probe:** Medium confidence. Performance drop is documented, but the reason (true domain shift vs. annotation artifact) remains an assumption.

## Next Checks
1.  **Normalization Audit:** Train baseline RGB-only model using band-specific mean/std normalization over training set. Compare convergence speed and final mIoU against model using raw, unscaled bands. Significant difference confirms this as a critical, unstated parameter.
2.  **Leakage Stress Test:** Intentionally corrupt spatial-block partitioning by randomly assigning patches to splits. Train model; if it achieves >0.85 mIoU on standard test and minimal drop (<0.05) on isolated test, this flags potential leakage in original splits' design or implementation.
3.  **Feature Distribution Shift:** Compute and compare per-band mean/variance, texture metrics (e.g., GLCM), and slope histograms between training region and isolated test region. Significant statistical differences would provide empirical evidence supporting the claim of a meaningful geomorphological domain shift.
