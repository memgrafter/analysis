# Nüwa: Mending the Spatial Integrity Torn by VLM Token Pruning

## Quick Facts
- **arXiv ID:** 2602.02951
- **Source URL:** https://arxiv.org/abs/2602.02951
- **Reference count:** 40
- **Primary result:** Achieves state-of-the-art results on 13 benchmarks, maintaining ~95% performance on VQA tasks and 47% retention on grounding tasks with 88.9% token reduction, while reducing TFLOPs by 89% and prefill time by 62%.

## Executive Summary
Vision-language models (VLMs) rely on dense visual token sequences to perform tasks requiring spatial reasoning, such as visual grounding. However, existing token pruning strategies that reduce computational cost often degrade grounding performance by collapsing the global spatial reference frame encoded by positional embeddings. Nüwa addresses this with a two-stage, training-free pruning framework. The first stage operates immediately after the vision encoder: it partitions tokens into grid regions, selects high-salience anchor tokens, and aggregates nearby features while preserving spatial proximity. The second stage runs inside the LLM at an intermediate layer, where it discards vision tokens based on their semantic relevance to the textual query. Across 13 benchmarks using LLaVA-1.5-7B, Nüwa drastically cuts token count (88.9% reduction) and FLOPs (89%) with minimal impact on VQA (~95% retention) and substantial grounding retention (47%), outperforming prior pruning methods.

## Method Summary
Nüwa is an inference-time pruning method requiring no additional training. **Stage 1** (post-vision encoder): the token grid is partitioned into $M \times M$ non-overlapping regions. Within each region, tokens are ranked by salience $S(t) = \alpha_{\text{cls}} \cdot \|k_i\|^2$ (CLS-attention score times key-norm squared); the top-$n$ are retained as candidate anchors. "Pillar Tokens" (top 25% by L2-norm) are preserved unchanged. The remaining "Collector" tokens are aggregated into a single token via a weighted sum, where weights combine semantic similarity (to the CLS token) and spatial proximity (distance within the grid, threshold $\tau$). **Stage 2** (inside the LLM at layer $\ell$): a text query vector $\bar{q}$ is computed as the average of all text token embeddings. Each vision token (projected to the LLM space) is scored by cosine similarity to $\bar{q}$; the top-$K$ are kept, all others are dropped. For LLaVA-1.5-7B (32 layers), the typical configuration targets an average of 64 tokens: Stage 1 outputs $T_1 = 7A/4 = 112$ tokens, Stage 2 prunes to $T_2 = A/4 = 16$ at layer $\ell=16$. The final token set is used for autoregressive decoding.

## Key Results
- Maintains ~95% performance on VQA tasks (e.g., GQA, MMB, VQAv2) with aggressive token reduction.
- Achieves 47% retention on visual grounding benchmarks (RefCOCO series) while reducing tokens by 88.9%.
- Reduces TFLOPs by 89% and prefill latency by 62% on LLaVA-1.5-7B.

## Why This Works (Mechanism)
### Mechanism 1: Spatial Reference Frame Collapse
Existing global semantic pruning (e.g., based on attention or similarity) discards tokens without preserving their original 2D relationships, thereby collapsing the global coordinate system essential for spatial grounding. Position reconstruction experiments (replacing position embeddings with a linear mapping that restores continuity) recover grounding performance, confirming that the root cause is loss of positional integrity. Methods like VisionZip and FastV, which compress or sparsify position embeddings non-linearly, cause catastrophic grounding failure.

### Mechanism 2: Region-Based Anchor Selection and Proximity-Guided Aggregation
Nüwa’s Stage 1 intentionally preserves spatial continuity. Grid separation creates local neighborhoods; alignment selects high-salience tokens (CLS-attention × key-norm) as anchors. Aggregation merges neighbor Collector tokens using a weight that decays with spatial distance, while high-norm Pillar Tokens remain as fixed spatial anchors. The design assumes that object-centric representations emerge at mid-level vision stages (OCC peak) and require cohesive local neighborhoods to maintain spatial cues. Ablations show that removing grid partitioning or mis-setting the proximity threshold $\tau$ drastically harms grounding, validating the mechanism.

### Mechanism 3: Text-Guided Pruning After Multimodal Alignment
Stage 2 exploits that by the middle of the LLM, the global spatial frame has already been established by Stage 1. Further pruning should thus be guided by the specific query’s semantics. A simple average-pooled text query vector $\bar{q}$ scores vision tokens; the top-$K$ are retained. This aligns the token set with the task (e.g., VQA vs. grounding). Experiments show Stage 2 alone gives modest gains, but combined with Stage 1 it yields the full benefit; pruning too early or too aggressively destroys performance, confirming that spatial integrity must precede semantic relevance filtering.

## Architecture Onboarding
**Component map:**  
Vision encoder (CLIP ViT) → Separation (grid partition into $M \times M$ regions) → Alignment (select top-$n$ per region by salience $S(t) = \alpha_{\text{cls}} \|k_i\|^2$) → Aggregation (Pillar Tokens unchanged; Collector tokens aggregated with weight = $\text{ReLU}(\text{semantic\_sim}) \cdot P_{ij}$, spatial proximity) → LLM (with text tokens) → Stage2 pruning (at layer $\ell$: compute $\bar{q} = \text{avg}(\text{text embeddings})$; retain top-$K$ vision tokens by cosine similarity) → Decoder (autoregressive generation)

**Critical path:**  
Vision tokens must survive Stage 1 with spatial continuity → enter LLM → after ~1/3 of layers, Stage 2 prunes by text relevance → remaining layers decode. A failure at Stage 1 kills grounding; at Stage 2 mainly hurts efficiency.

**Design tradeoffs:**  
- Region size $M$ and per-region selection $n$: coarser regions preserve broader context but fewer anchors; smaller regions risk losing large objects.
- Spatial proximity threshold $\tau$: too narrow isolates aggregates; too broad merges distant semantics. Optimal ~0.25–0.26 of max distance.
- Stage 2 budget $K$: typically 10–20% of Stage 1 tokens; must balance efficiency vs. information retention.

**Failure signatures:**  
- Grounding plummets while VQA stable: lost spatial anchors (check OCC metric after Stage 1).
- Both metrics drop: Stage 2 pruned too many or selected wrong tokens (check text-vision similarity heatmap).
- High visual attention entropy after Stage 1: features too diffuse/unstructured.

## Open Questions the Paper Calls Out
- **Open Question 1**: Can aggressive vision token pruning fully preserve visual grounding performance (~100% retention) while reducing tokens by >80%? The current 47% retention with 88.9% reduction indicates a remaining gap.
- **Open Question 2**: Is the static average-pooled text query optimal for Stage 2 pruning, or should query representations be dynamic across layers/tasks?
- **Open Question 3**: Can adaptive region partitioning (beyond fixed $M \times M$ grid) further improve spatial integrity preservation for diverse images, especially cluttered scenes?

## Limitations
- **Hyperparameter ambiguity**: Exact values for grid size $M$, per-region selections $n$, and spatial threshold $\tau$ are inferred, not explicitly stated for each model/token budget.
- **Pruning layer specification**: The exact LLM layer for Stage 2 (e.g., layer 16 for LLaVA-1.5-7B) is deduced from FLOPs calculations, not directly confirmed.
- **Generalization scope**: Evaluation primarily on LLaVA variants; limited evidence for Qwen2.5-VL and other architectures; computational overhead of salience/aggregation metrics not thoroughly benchmarked.

## Confidence
- **Core mechanism (spatial reference frame loss)**: High – supported by position reconstruction experiments and clear break conditions in baselines.
- **Method effectiveness (two-stage preservation)**: Medium – ablations validate component necessity, but hyperparameter sensitivity (e.g., $\tau$, $M$) is not fully mapped.
- **Scalability/robustness across models**: Low – results provided for three model families, but configuration details for non-LLaVA models are sparse; efficiency gains may not hold for different vision encoders.
