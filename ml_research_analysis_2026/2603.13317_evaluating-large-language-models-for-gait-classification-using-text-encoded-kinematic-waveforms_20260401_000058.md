# Evaluating Large Language Models for Gait Classification Using Text-Encoded Kinematic Waveforms

## Quick Facts
- **arXiv ID**: 2603.13317
- **Source URL**: https://arxiv.org/abs/2603.13317
- **Reference count**: 13
- **Primary result**: A supervised K-Nearest Neighbors classifier achieved the highest multiclass gait classification performance (MCC=0.88), while the best-performing LLM (GPT-5 with reference grounding) reached multiclass MCC=0.70 and binary MCC=0.68, with confidence filtering raising its multiclass MCC to 0.83 on a high-confidence subset.

## Executive Summary
This study evaluated whether general-purpose large language models (LLMs) can classify gait patterns when kinematic waveforms are represented as textual numeric sequences, comparing them to traditional machine learning approaches. A supervised K-Nearest Neighbors classifier served as the top-performing benchmark. The leading LLM, GPT-5, leveraged explicit normal gait statistics as reference data to achieve competitive but inferior multiclass performance. Performance was highly sensitive to the availability of reference statistics and could be improved by filtering for high-confidence predictions. The computationally efficient o4-mini model matched larger LLMs in capability. Findings indicate that zero-shot LLMs, when appropriately grounded, can approach simple anomaly detectors but remain unsuitable for diagnostic use, better serving exploratory analysis.

## Method Summary
The research compared a supervised K-Nearest Neighbors classifier, a class-independent one-class support vector machine (SVM), and multiple LLMs (GPT-5, o4-mini) on a gait classification task. Continuous kinematic waveforms from a dataset were encoded as structured text sequences (numeric strings). LLMs were prompted to predict gait classes, optionally supplemented with statistical reference data derived from normal gait samples. Predictions included self-reported confidence levels (high/medium/low), enabling analysis of confidence versus accuracy. The primary evaluation metric was the Matthews Correlation Coefficient (MCC) for multiclass and binary classification.

## Key Results
- Supervised KNN achieved the highest multiclass MCC (0.88).
- GPT-5 with reference grounding attained multiclass MCC=0.70 and binary MCC=0.68, outperforming the one-class SVM (binary MCC=0.60).
- The efficient o4-mini model performed comparably to larger LLMs.
- When restricted to high-confidence predictions, GPT-5's multiclass MCC increased to 0.83 on the filtered subset, though coverage was reduced.

## Why This Works (Mechanism)
LLMs can classify gait patterns from text-encoded waveforms because their pretraining exposes them to numerical sequences and patterns, enabling recognition of anomalous distributions when provided with a reference baseline. The injection of normal gait statistics grounds the model's judgment, mitigating ambiguity in the textual representation. Confidence filtering enhances practical reliability by selecting predictions where the model's internal certainty correlates with correctness, as demonstrated by the performance boost on high-confidence subsets.

## Foundational Learning
- **Gait Kinematics**: The continuous joint angle and timing signals that define walking patterns. *Why needed*: It is the primary signal being classified. *Quick check*: List three key kinematic parameters (e.g., knee flexion angle at heel strike) from a sample waveform.
- **Text Encoding of Time Series**: Converting continuous numeric vectors into tokenizable strings (e.g., comma-separated values). *Why needed*: Adapts non-textual data for LLM processing. *Quick check*: Transform a 5-point hip angle trajectory into a plain-text sequence.
- **Reference Grounding**: Providing statistical summaries (mean, variance) of normal gait as contextual data. *Why needed*: Anchors the LLM's decision-making in domain norms, boosting accuracy. *Quick check*: Calculate the mean stance-phase duration from a set of healthy gait cycles.
- **LLM Prompt Engineering**: Designing structured textual instructions to elicit classification and confidence. *Why needed*: Directs the model's focus and output format. *Quick check*: Draft a prompt that asks for a gait type and a confidence rating given a numeric sequence and reference stats.
- **Confidence Elicitation**: Obtaining qualitative self-assessments (high/medium/low) from the LLM about its predictions. *Why needed*: Offers a proxy for prediction uncertainty. *Quick check*: Modify a prompt to explicitly request a confidence level alongside the class label.

## Architecture Onboarding
**Component Map**: Raw Kinematic Waveform -> Text Encoder -> Reference Statistics Aggregator -> Prompt Composer -> LLM Inference Engine -> Classification Output + Confidence Rating

**Critical Path**: The quality of the text encoding and the inclusion of relevant reference statistics are the most influential factors; errors or omissions here cascade to the LLM's inference.

**Design Tradeoffs**: Text encoding simplicity versus temporal information loss; LLM scale and capability versus inference cost and latency; reliance on reference data versus generalizability to unseen conditions.

**Failure Signatures**: Severe performance degradation when reference statistics are omitted; very low prediction coverage under strict confidence filtering; inconsistent performance across different waveform patterns or datasets.

**First Experiments**:
1. Systematically vary the text encoding format (e.g., CSV, JSON, normalized token sequences) to measure its effect on LLM classification accuracy and robustness.
2. Replicate the core experiment using diverse open-source LLM families (e.g., Llama, Mistral) to isolate architectural and tokenization influences.
3. Develop and apply statistical calibration methods (e.g., temperature scaling) to the LLM's self-reported confidence scores and evaluate calibration error on held-out gait data.

## Open Questions the Paper Calls Out
- **Question**: What alternative input representations can best preserve the spatio-temporal structure of kinematic waveforms for LLM processing to close the performance gap with supervised ML?  
  *Basis*: The authors state that "targeted improvements in how continuous biomechanical signals are represented for LLM processing may be a more promising avenue for enhancing performance than increasing model scale alone," highlighting representational mismatch as key.  
  *Why unresolved*: The study tested only one representation (structured text tokens); other encodings were not explored.  
  *What evidence would resolve it*: Systematic comparison of different input encodings (e.g., raw time-series, learned embeddings, graph representations) on the same gait classification task, measuring impact on LLM performance and computational cost.

- **Question**: How do LLM-based gait classification performance and robustness vary across different model architectures and training regimes, beyond the OpenAI models evaluated?  
  *Basis*: The authors note that "as only OpenAI models were evaluated, this finding should be interpreted within this specific model family and task context," indicating limited generalizability.  
  *Why unresolved*: The study exclusively used OpenAI's commercial LLMs; differences in other LLM families could yield different results.  
  *What evidence would resolve it*: Direct replication using a diverse suite of LLMs (e.g., Llama, Mistral, Claude) to assess consistency and identify architectural factors.

- **Question**: Can techniques be developed to ensure that LLM-generated biomechanical justifications faithfully represent the model's decision-making process, preventing misleading trust in clinical contexts?  
  *Basis*: The conclusion emphasizes that "these explanations cannot be assumed to faithfully reflect the model’s internal decision process and may inadvertently encourage overtrust if interpreted uncritically."  
  *Why unresolved*: Potential unfaithfulness was identified but no verification methods or faithful explanation designs were tested.  
  *What evidence would resolve it*: Development and validation of faithfulness metrics for LLM explanations in gait analysis (e.g., perturbation tests, comparison with supervised model saliency maps) and domain expert assessment of justification alignment.

- **Question**: Can LLM self-reported confidence scores be statistically calibrated to provide reliable uncertainty estimates that generalize to more complex, real-world gait assessment scenarios?  
  *Basis*: The authors found that "performance varies systematically across confidence categories" but note that self-reported confidence is an "informative but imperfect proxy" and was not statistically calibrated.  
  *Why unresolved*: Confidence was elicited qualitatively without probability calibration; reliability in complex scenarios is unknown.  
  *What evidence would resolve it*: Apply calibration techniques (e.g., temperature scaling) to LLM outputs, evaluate calibration error on held-out complex gait data, and correlate confidence with correctness in real clinical datasets.

## Limitations
- LLM performance dropped sharply without explicit normal gait statistics, limiting applicability in scenarios lacking such reference data.
- Representing continuous kinematic waveforms as numeric strings likely discards important temporal structure, possibly understating LLM potential with optimized encodings.
- Evaluation appears confined to a single dataset; performance across diverse gait pathologies, sensor modalities, or demographic groups remains untested.
