# Towards Cross-lingual Values Assessment: A Consensus-Pluralism Perspective
## Quick Facts
- **arXiv ID:** 2602.17283
- **Source URL:** https://arxiv.org/abs/2602.17283
- **Reference count:** 40
- **Primary result:** Introduces X-Value, a cross-lingual benchmark revealing frontier LLMs average only 75.13% accuracy on deep-level value assessment, with a steep 30-point drop on hard samples and >20% cross-language gaps.

## Executive Summary
This paper addresses the under-explored problem of deep-level value assessment in large language models (LLMs) for content safety, moving beyond explicit harm detection. It introduces X-Value, a novel cross-lingual benchmark of 5,443 QA pairs across 18 languages, organized into 7 domains grounded in Schwartz’s theory of basic human values. A key innovation is a two-stage human annotation framework that first classifies issues as either global consensus (universally condemned) or global pluralism (culturally contested), then judges answer appropriateness with native-speaker adjudication. Evaluation of 8 frontier models shows high performance on easy samples (>95%) but a significant drop on hard samples (63.69%), alongside stark cross-lingual performance gaps (e.g., Japanese trails English by ~31% on hard tasks). The results highlight major deficiencies in cross-lingual value reasoning and underscore the urgent need for more nuanced, culturally-aware alignment.

## Method Summary
The authors construct the X-Value benchmark by sourcing questions from Reddit and generating normal/risky answers via LLMs. The data is mapped to 7 domains derived from Schwartz’s 19 basic human values. A stratification engine uses disagreement among three LLMs (Qwen3-Plus, GPT-5.2, Gemini-3-Pro) to label samples as "easy" (full agreement) or "hard" (any disagreement). Human annotation follows a two-stage pipeline: native speakers first classify the underlying issue as global consensus or pluralism, then judge answer appropriateness through native-speaker adjudication, using only search engines for factual verification. The final dataset includes question, answer, binary appropriateness label (0/1), language, domain, and difficulty. Models are evaluated zero-shot using a detailed prompt that integrates the annotation criteria and general checkpoints, with accuracy computed overall and per subset, language, and domain.

## Key Results
- Average overall accuracy across 8 frontier models is 75.13%, with the best model (Gemini-3-Flash-Preview) at 76.88%.
- Performance is near-ceiling on easy-level samples (>95%) but drops sharply to 63.69% on hard-level samples.
- Significant cross-lingual gaps exist, with Japanese trailing English by approximately 31 percentage points on hard tasks.
- Smaller models (e.g., Qwen3-1.7B) sometimes outperform larger counterparts on hard-level tasks for specific languages (ar, de, th).

## Why This Works (Mechanism)
### Mechanism 1
- **Claim:** The consensus-pluralism issue classification reduces cultural bias by separating universally condemned acts from culturally contested ones, enabling more nuanced value assessment.
- **Mechanism:** Annotators first label each QA pair's underlying issue as either *global consensus* (e.g., terrorism, human rights) or *global pluralism* (e.g., religion, politics). The subsequent value appropriateness judgment then applies different criteria: for consensus issues, answers must explicitly endorse the global norm; for pluralistic issues, answers must neutrally represent multiple viewpoints.
- **Core assumption:** A stable, culturally recognized boundary exists between issues with near-universal agreement and those with legitimate, widespread disagreement.
- **Evidence anchors:**
  - [abstract] "first identifies whether an issue falls under global consensus (e.g., human rights) or pluralism (e.g., religion)"
  - [section 2.2] Describes the two-stage annotation pipeline and provides definitions for consensus vs. pluralism.
  - [corpus] Weak direct evidence. Neighbor papers (e.g., *MENAValues*) focus on regional alignment but do not implement a comparable consensus-pluralism split.
- **Break condition:** If cultural boundaries between consensus and pluralism are fluid or contested, the binary classification becomes unreliable.

### Mechanism 2
- **Claim:** Stratifying samples into "easy" and "hard" tiers based on initial LLM disagreement creates a more discriminative benchmark, revealing limitations in LLMs' deep value reasoning that holistic agreement masks.
- **Mechanism:** Three advanced LLMs independently assess each QA pair. Samples where all three agree are labeled "easy-level"; any disagreement labels it "hard-level." The hypothesis is that "hard" samples contain implicit biases, leading questions, or localized value conflicts requiring finer-grained analysis.
- **Core assumption:** LLM disagreement on value appropriateness correlates with greater cognitive complexity or cultural subtlety in the sample.
- **Evidence anchors:**
  - [section 2.1] Equation (1) formally defines the difficulty stratification based on consensus among three models.
  - [section 3.2] Main results show a dramatic performance drop on the "hard-level" subset (average 63.69% vs. >95% on "easy-level").
  - [corpus] Limited direct anchor. Neighbors like *Beyond Benchmarking* propose new evaluation paradigms but not a specific disagreement-based stratification for values.
- **Break condition:** If LLM disagreement stems from model instability or prompt sensitivity rather than sample complexity, the stratification misrepresents true difficulty.

### Mechanism 3
- **Claim:** Native-speaker adjudication with search-engine-only research ensures reliable, culturally grounded ground truth for latent value assessment, avoiding cultural biases inherent in LLM-based labeling.
- **Mechanism:** Each QA pair is labeled independently by two native speakers. Disagreements are adjudicated by a third native speaker. Annotators are prohibited from using LLMs and may only use search engines for factual verification, forcing reliance on their own cultural and normative understanding.
- **Core assumption:** Native speakers, when properly trained and given factual context, can render more culturally authentic judgments than non-native or synthetic labelers.
- **Evidence anchors:**
  - [section 2.2] "each sample is independently annotated by two trained native speakers... reviewed by a third native speaker... not allowed to utilize LLMs."
  - [appendix C] Detailed human annotation guidelines emphasize neutrality, granularity, and prohibition of LLM assistance.
  - [corpus] No direct anchor; this is a methodological contribution specific to X-Value's design for cross-lingual cultural fidelity.
- **Break condition:** If native-speaker judgments themselves exhibit high intra-group variability or reflect only a narrow segment of their culture's values, the ground truth remains unstable.

## Foundational Learning
- **Concept: Schwartz's Theory of Basic Human Values**
  - *Why needed here:* Provides the theoretical scaffolding for the 7-domain taxonomy, ensuring the benchmark covers fundamental cross-cultural value motivations (e.g., security, tradition, universalism) rather than arbitrary topical categories.
  - *Quick check:* How does mapping "Governance & Politics" to Conformity-rules, Power-dominance, and Security-societal structure the data beyond simple topic clustering?

- **Concept: Consensus vs. Pluralism in Global Norms**
  - *Why needed here:* The entire two-stage annotation framework rests on this distinction. Misclassifying a pluralistic issue as consensus (or vice versa) invalidates the subsequent appropriateness judgment.
  - *Quick check:* For the Arabic case about student protests, why is this a *pluralism* issue, and what would a "values-appropriate" answer look like under the pluralism criterion?

- **Concept: Difficulty Stratification via Model Disagreement**
  - *Why needed here:* Creates the "hard-level" subset that exposes model deficiencies. This explains why overall accuracy (~75%) is misleading without the easy/hard split.
  - *Quick check:* According to Equation (1), if models m1 and m2 label a sample "appropriate" but m3 labels it "inappropriate," what is the sample's difficulty label, and what does this imply?

## Architecture Onboarding
- **Component map:**  
  Data Sources (Reddit + LLM-generated answers) -> Taxonomy Mapper (Schwartz's 19 values -> 7 domains) -> Stratification Engine (3-model disagreement) -> Annotation Pipeline (two-stage native-speaker triad) -> Evaluation Harness (LLM-as-a-judge prompt + accuracy computation).
- **Critical path:** Data Collection -> Taxonomy Application -> Preliminary LLM Assessment (for stratification) -> Human Annotation (two-stage) -> Dataset Release -> Model Evaluation. Stratification failure propagates downstream.
- **Design tradeoffs:**
  - *Global vs. Local:* Using a single global framework (Schwartz) may miss culture-specific value dimensions.
  - *Synthetic vs. Natural:* Supplementing answers with LLMs risks introducing artifacts not in natural discourse.
  - *Binary vs. Graded:* The final binary label may oversimplify nuanced value stances, especially in pluralism cases.
- **Failure signatures:**
  1. **Stratification failure:** "Hard-level" samples do not show lower model accuracy than "easy-level."
  2. **Annotation drift:** Low inter-annotator agreement on consensus/pluralism classification.
  3. **Cultural flattening:** Certain languages (e.g., ja, ko, ms) show consistently low accuracy across domains.
- **First 3 experiments:**
  1. **Validate stratification:** Have humans label a held-out set pre-divided into easy/hard by LLM disagreement. Expect lower human accuracy on hard samples.
  2. **Test consensus-pluralism reliability:** Have annotators re-classify 100 samples after 1 month. Report Cohen's kappa; target > 0.7.
  3. **Benchmark sanity check:** Run a baseline model (e.g., GPT-5.2) with the paper's prompt and a simpler safety prompt. The nuanced prompt should yield lower accuracy, confirming difficulty.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Why do smaller language models sometimes outperform larger ones in hard-level values assessment tasks for specific languages (e.g., Arabic, German, Thai)?
- **Basis in paper:** The paper states: "Interestingly, this scaling trend is not universal in the hard-level subset. Specifically, in languages such as ar, de, and th, smaller variants (Qwen3-1.7B and 8B) outperform their larger counterparts. This may be attributed to the inherent tension between complex localized values and global paradigms; larger models appear to struggle with reconciling these divergent perspectives into a balanced judgment, thereby undermining their performance."
- **Why unresolved:** The authors offer a hypothesis but provide no empirical analysis of the underlying mechanisms. It remains unclear whether this stems from over-generalization in larger models, data imbalances, or architectural limitations.
- **What evidence would resolve it:** Controlled experiments varying training data diversity per language, probing model representations for cultural bias-variance trade-offs, or error analysis comparing model mistakes on consensus vs. pluralistic items across scales.

### Open Question 2
- **Question:** How can LLMs be trained or prompted to consistently apply the consensus-pluralism framework to avoid misclassifying values-appropriate responses, as demonstrated in the case studies?
- **Basis in paper:** Case studies show models failing to correctly identify issue types and adjust assessment criteria—e.g., missing terrorism normalization in an English consensus case, over-endorsing protests in an Arabic pluralism context, and omitting the Kuomintang in a Chinese historical consensus question. The paper notes models "tend to rely on holistic judgments and fail to identify implicit or localized value conflicts."
- **Why unresolved:** The two-stage human annotation framework is not built into model evaluation or training. Models receive guidelines but still err, indicating a gap in understanding or applying the distinction.
- **What evidence would resolve it:** Ablation studies using stepwise prompting (e.g., "First classify issue type: consensus or pluralism? Then assess answer"), fine-tuning on human-annotated examples showing correct application, or evaluating whether chain-of-thought reasoning improves adherence.

### Open Question 3
- **Question:** What are the root causes of the significant cross-lingual performance gaps (>20%) in values assessment, and how can they be mitigated?
- **Basis in paper:** The paper reports: "LLMs exhibit significant performance disparities in content values assessment across 18 different languages" and "Cross-language performance gaps exceed 20%; for instance, Japanese trails English by ~31% on hard-level tasks." It notes model-specific language advantages but does not investigate why gaps exist.
- **Why unresolved:** The analysis stops at reporting disparities without exploring contributing factors such as training data representation, cultural bias in pre-training corpora, or linguistic typology. The paper calls for "culturally-aware alignment" but offers no roadmap.
- **What evidence would resolve it:** Correlational studies linking performance to language metadata (speaker count, family, resource level), analysis of pretraining data for cultural content distribution, or probing models for language-specific value embeddings.

### Open Question 4
- **Question:** Beyond accuracy, what evaluation metrics better capture the nuanced, culturally-situated nature of values assessment, and how should they be integrated into LLM development?
- **Basis in paper:** The paper relies solely on classification accuracy (Acc) for evaluation, despite emphasizing "nuanced, culturally-aware alignment" and a framework that distinguishes consensus vs. pluralism, requires neutrality, and mandates covering multiple viewpoints. Accuracy does not measure fairness across cultures, consistency with pluralism principles, or avoidance of cultural imposition.
- **Why unresolved:** The binary appropriateness label collapses rich cultural nuance into a single score. The paper's goal is to assess "deep-level values," but current metrics cannot detect whether a model's "appropriate" answer truly respects pluralism or merely mimics surface-level compliance.
- **What evidence would resolve it:** Development of multi-dimensional metrics (e.g., cultural alignment score, pluralism adherence rate, viewpoint diversity index), human evaluations on dimensions like fairness and neutrality, or correlation studies between accuracy and cultural inclusivity.

## Limitations
- Model versions (e.g., GPT-5.2) and API settings are unspecified, creating irreproducibility risk.
- The "general checkpoints" in the evaluation prompt are not detailed, leaving unknown heuristics.
- No annotation agreement statistics are reported, so the reliability of the consensus-pluralism classification is uncertain.
- LLM-disagreement stratification lacks human validation; it may not reflect true cognitive difficulty.

## Confidence
- **Consensus-pluralism reduces bias:** Medium (plausible but untested boundary).
- **Disagreement-based stratification works:** Medium (performance gap supports, but human alignment unknown).
- **Native-speaker ground truth is authentic:** Low (no IAA or adjudication metrics).
- **Cross-lingual gaps are real:** High (consistent empirical evidence).
