# Tool-MAD: A Multi-Agent Debate Framework for Fact Verification with Diverse Tool Augmentation and Adaptive Retrieval

## Quick Facts
- **ArXiv ID**: 2601.04742
- **Source URL**: https://arxiv.org/abs/2601.04742
- **Reference count**: 40
- **Primary result**: Tool-MAD achieves up to a 5.5% absolute accuracy gain over the prior MADKE framework and an average 18.1% improvement over baseline MAD across four fact verification benchmarks.

## Executive Summary
Tool-MAD is a multi-agent debate framework designed to mitigate hallucination in fact verification. It replaces static evidence with dynamic, heterogeneous external tools—specifically retrieval-augmented generation (RAG) and search APIs—assigned per agent. The core innovation lies in an adaptive query mechanism that iteratively refines retrieval based on the evolving debate flow, combined with real-time stability scores (faithfulness and answer relevance) that filter low-quality responses. Evaluated on four fact verification benchmarks, Tool-MAD consistently outperforms state-of-the-art MAD frameworks, demonstrating notable robustness in medical QA domains.

## Method Summary
The framework deploys multiple agents, each equipped with a distinct external tool (either a RAG retriever or a search API). Upon receiving a query, each agent retrieves evidence and generates an initial answer with supporting citations. Agents then engage in an iterative debate: they exchange arguments, critique each other’s evidence, and may trigger additional retrievals through an adaptive query mechanism when disagreements arise. After each debate round, responses are evaluated using faithfulness and answer relevance scores; those falling below a stability threshold are discarded. The remaining answers are aggregated (e.g., via majority vote) to produce the final verdict. This dynamic interplay between diverse tools, adaptive retrieval, and stability-based filtering reduces reliance on static evidence and curtails hallucination.

## Key Results
- Up to 5.5% absolute accuracy improvement over MADKE.
- Average 18.1% accuracy gain over baseline multi-agent debate (MAD).
- Ablation study confirms that combining heterogeneous tools yields the highest accuracy.

## Why This Works (Mechanism)
Tool-MAD’s effectiveness stems from three synergistic factors: First, assigning different external tools to agents introduces evidence diversity, preventing collective reliance on a single potentially flawed source. Second, the adaptive query mechanism allows retrieval to be refined as the debate unfolds, ensuring that evidence remains relevant to contentious points. Third, real-time stability scores (faithfulness and answer relevance) act as a quality gate, systematically filtering out hallucinated or low-confidence responses before final aggregation.

## Architecture Onboarding
**Component Map**:  
User Query → Agent Pool (each with assigned Tool: RAG or Search API) → Initial Retrieval → Answer Generation → Debate Loop ↔ Adaptive Retrieval → Stability Scorer → Answer Filter → Aggregator → Final Answer

**Critical Path**:
1. Ingest user query.
2. For each agent, perform tool-specific retrieval and generate an initial answer with citations.
3. Initiate debate: agents exchange arguments and evidence.
4. If disagreement exceeds a predefined metric, invoke adaptive retrieval to gather additional evidence.
5. Update answers based on new evidence and continue debate until convergence or max rounds.
6. Compute stability scores for each final answer.
7. Discard answers below the stability threshold.
8. Aggregate remaining answers to produce the final verdict.

**Design Tradeoffs**:
- *Tool diversity* improves accuracy but increases API costs and latency.
- *Adaptive retrieval* adds complexity but reduces hallucinations by targeting missing information.
- *Stability threshold* tuning balances precision (high-quality answers) against recall (accepting enough answers for aggregation).
- *Real‑time operation* may require caching or parallelization to meet response time constraints.

**Failure Signatures**:
- Uniformly low stability scores across agents → query may be unanswerable or tools insufficient.
- Retrieval API errors or timeouts → missing evidence leads to agent fallback on internal knowledge.
- Persistent disagreement without convergence → possible ambiguity or contradictory sources.
- Infinite debate loop → indicates overly permissive adaptive triggers; require maximum round limit.

**First Experiments**:
1. **Baseline replication**: Run Tool-MAD on a single benchmark (e.g., FEVER) with all agents using the same tool (RAG only) to establish a reference performance.
2. **Agent count variation**: Test with 2, 3, and 4 agents to measure the impact of debate scale on accuracy and stability.
3. **Tool combination ablation**: Compare runs using (a) RAG-only, (b) Search-only, and (c) mixed tools to validate the claim that diversity yields the highest accuracy.

## Limitations
- Evaluation is restricted to four fact‑verification benchmarks; generalizability to other domains (e.g., legal, finance) remains unclear.
- Dependence on external search/RAG APIs introduces cost, latency, and availability concerns not addressed in the study.
- The stability score threshold is chosen without explicit justification; its sensitivity across different datasets is unknown.

## Confidence
- Performance gains: High
- Medical QA robustness: Medium
- Diverse tool benefit: High
- Stability score effectiveness: Medium
