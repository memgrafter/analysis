# Parameter-Free Dynamic Regret for Unconstrained Linear Bandits

## Quick Facts
- **arXiv ID:** 2603.25916  
- **Source URL:** https://arxiv.org/abs/2603.25916  
- **Reference count:** 12  
- **Primary result:** Achieves expected dynamic regret Õ(√d(1+S_T)T) in unconstrained adversarial linear bandits without prior knowledge of the number of comparator switches S_T.

## Executive Summary
The paper tackles dynamic regret minimization for unconstrained adversarial linear bandits where the comparator sequence can switch an unknown number of times S_T. The core contribution is a parameter‑free algorithm that attains Õ(√d(1+S_T)T) expected dynamic regret, matching the optimal dependence on S_T and resolving a long‑standing open problem. The method combines a uniform sampling framework with a scale/direction decomposition and a geometric grid of hyperparameter guesses, enabling on‑the‑fly tuning of the switching budget. The analysis assumes an oblivious comparator and linear loss functions.

## Method Summary
The algorithm orchestrates multiple base algorithm instances in parallel. Each instance factors its decision w = vβ into a scale v ∈ ℝ and a unit direction β ∈ ℝ^d. A scale learner (comparator‑adaptive full‑information OCO) handles the one‑dimensional linear loss, while a direction learner (Luo et al., 2022) addresses bandit feedback on the sphere. To avoid knowing S_T, the direction learner is instantiated with a geometrically spaced grid of guesses Ŝ ∈ S. A uniform sampling coordinator draws an instance index I_t each round; the chosen instance’s action is played, observes the bandit loss ⟨ℓ_t,w_t⟩, and updates both learners with transformed feedback (scale learner receives full‑information linear loss; direction learner receives a scalar bandit loss). Non‑selected instances receive zero loss. The ensemble’s expected dynamic regret matches the best instance up to a logarithmic overhead, yielding the scalar‑free bound.

## Key Results
- Expected dynamic regret: Õ(√d(1+S_T)T) without prior knowledge of S_T.  
- Optimal linear dependence on the switching number S_T.  
- Resolves the open problem of parameter‑free dynamic regret in unconstrained linear bandits.

## Why This Works (Mechanism)
### Mechanism 1: Uniform Sampling for Algorithm Combination
- **Claim:** Uniformly sampling among base algorithms and rescaling the comparator yields an expected dynamic regret that matches the best base algorithm up to a constant additive overhead.  
- **Mechanism:** In each round, an index I_t is drawn uniformly from {1,…,N}. The action of algorithm I_t is executed. The loss ⟨ℓ_t,w_t⟩ is observed; the selected algorithm receives the true (or a full‑information representation) loss, while others receive zero. This implicitly averages the iterates in expectation. For any fixed algorithm n, the ensemble’s regret is bounded by the regret of algorithm n against the comparator scaled by N, plus the regrets of all other algorithms against the zero comparator.  
- **Core assumption:** Each base algorithm is comparator‑adaptive: its regret relative to the zero comparator satisfies R_T(0)=O(1) uniformly in T. This ensures non‑selected algorithms contribute only a constant per round.  
- **Evidence:** Uniform sampling as an interface appears in Algorithm 1 and Proposition 2.1; related reduction ideas exist in the “Dynamic Regret Reduces to Kernelized Static Regret” paper (ID 6424), but the specific coordination for bandit feedback is novel.  
- **Break condition:** If any R_T(0) grows with T (e.g., Ω(√T)), the additive term becomes super‑constant, degrading the combined rate.

### Mechanism 2: Scale/Direction Decomposition for Bandit Feedback
- **Claim:** Factoring w_t = v_t β_t reduces bandit feedback to a full‑information subproblem for the scale learner, while a direction learner handles bandit updates on the unit ball.  
- **Mechanism:** After observing the scalar bandit loss g_t = ⟨ℓ_t,w_t⟩, set the direction loss as ℓ_t^β = ⟨ℓ_t,β_t⟩ = g_t/v_t. The scale learner then receives the linear loss v ↦ ℓ_t^β·v (full‑information), and the direction learner receives the scalar ℓ_t^β (bandit).  
- **Core assumption:** The scale learner must have comparator‑adaptive guarantee for static linear losses in ℝ (R_T(0)=O(1)), and the direction learner must achieve near‑optimal switching regret under bandit feedback on the unit ball (e.g., Luo et al., 2022). The linearity of losses is essential.  
- **Evidence:** Explicitly mentioned in the abstract; detailed in Section 3 (Algorithm 2, Proposition 3.1).  
- **Break condition:** v_t could approach zero, making ℓ_t^β undefined or unstable. Non‑linear losses break the decomposition entirely.

### Mechanism 3: Geometric Grid for Unknown Switching Number
- **Claim:** Running copies of a switching‑adaptive algorithm with geometrically spaced guesses for S_T, and selecting among them via uniform sampling, yields parameter‑free dynamic regret that matches Õ(√d(1+S_T)T) without knowing S_T.  
- **Mechanism:** Define grid S = {2^n ∧ 2^T : n=0,…,⌈log₂ T⌉} ∪ {0}. For each Ŝ∈S, instantiate a direction learner using Ŝ as its hyperparameter. All instances share the uniform sampling coordinator. Because S_T lies between two consecutive grid values (Ŝ ≤ S_T ≤ 2Ŝ), the instance with Ŝ closest to S_T incurs regret Õ(√d(1+S_T)T). The uniform sampling adds only O(N) overhead, where N = |S| = O(log T), which is absorbed in Õ‑notation.  
- **Core assumption:** The direction learner’s regret scales linearly with (1+Ŝ)T and degrades gracefully when Ŝ is misspecified; the geometric grid guarantees a constant‑factor cover of S_T.  
- **Evidence:** The grid is given in Equation 1 and Theorem 3.2 proves the parameter‑free guarantee.  
- **Break condition:** If the dependence on Ŝ is super‑linear or the grid too sparse, the constant‑factor approximation may be lost.

## Foundational Learning
### Dynamic Regret
- **Why needed:** The paper’s objective is to bound ∑⟨ℓ_t,w_t−u_t⟩ where u_t may change over time; the bound depends on the switching complexity S_T.  
- **Quick check:** If the comparator is constant (u_t=u), dynamic regret reduces to static regret; in bandits the optimal rate is typically Õ(√dT) for linear losses.

### Comparator‑Adaptive Guarantee
- **Why needed:** The uniform sampling combination relies on each base algorithm having uniformly bounded regret against the zero comparator (R_T(0)=O(1)), ensuring non‑selected algorithms add only constant overhead.  
- **Quick check:** For a comparator‑adaptive algorithm, R_T(u) usually scales as O(||u||√T) or similar; R_T(0)=O(1) implies the algorithm can handle large comparators without extra cost relative to zero.

### Scale/Direction Decomposition
- **Why needed:** It transforms bandit feedback into a full‑information subproblem for the scale learner, enabling the use of a comparator‑adaptive scale algorithm and achieving R_T(0)=O(1) for the base.  
- **Quick check:** Which learner (scale or direction) receives full‑information feedback? Answer: The scale learner receives a linear loss v ↦ ℓ_t^β·v, i.e., full‑information in the scalar v.

## Architecture Onboarding
### Component map
Uniform Sampling Coordinator → (samples I_t, aggregates w_t = v_t^{(I_t)} β_t^{(I_t)}) → Bandit environment returns ⟨ℓ_t,w_t⟩ → Loss Feedback Processor computes g_t, ℓ_t^β → Feedback sent to selected base instance I_t (scale learner + direction learner); all other instances receive zero loss. Grid Manager instantiates the parallel base instances with geometrically spaced Ŝ values.

### Critical path
1. **Prediction:** Coordinator draws I_t ~ Uniform(N); each base i outputs (v_t^{(i)}, β_t^{(i)}); set w_t = v_t^{(I_t)} β_t^{(I_t)}.
2. **Feedback acquisition:** Environment reveals bandit loss ⟨ℓ_t,w_t⟩.
3. **Feedback construction:** Compute g_t = ⟨ℓ_t,w_t⟩ / v_t^{(I_t)} and ℓ_t^β = ⟨ℓ_t,β_t^{(I_t)}⟩. For instance I_t, send linear loss v ↦ ℓ_t^β·v to scale learner and scalar ℓ_t^β to direction learner; all others get zero loss.
4. **Updates:** All learners update with their respective losses.
5. **Loop:** Return to step 1 for next round.

### Design tradeoffs
- **Uniform sampling overhead:** Introduces a factor N in comparator norm; grid size N=O(log T) keeps overhead logarithmic (absorbed in Õ‑notation).
- **Decomposition restriction:** Only works for linear losses and unconstrained ℝ^d; extension to constrained sets is non‑trivial.
- **Computational cost:** All N base algorithms predict each round, leading to O(N d) time; for Luo et al.’s direction learner the cost may be O(T log T), higher than O(d log T) in full‑information settings.

### Failure signatures
- **Adaptive comparator violation:** The analysis assumes u_t is oblivious; an adaptive u_t that depends on the algorithm’s randomness breaks the bound (Section 3.1).
- **Non‑constant R_T(0):** If the scale learner’s zero‑comparator regret grows with T (e.g., Ω(√T)), the additive (N‑1)·O(√T) dominates.
- **Grid coverage failure:** Sparse grid or S_T far from any guess loses the constant‑factor guarantee; geometric base 2 is essential.
- **Numerical instability:** Scale learner allowing v_t → 0 causes division by zero and excessive variance in ℓ_t^β; regularization (e.g., minimum v_t) may be needed.

### First 3 experiments
1. **Uniform sampling validation:** Compare the ensemble’s dynamic regret against a single algorithm with perfect knowledge of S_T across different S_T values; verify the same √(1+S_T)T scaling up to logarithmic factors.
2. **Grid adaptivity test:** Run the algorithm with unknown S_T and plot regret against the theoretical bound; also benchmark against fixed‑S_T algorithms with deliberately misspecified S_T (half or double the true value).
3. **Computational scaling study:** Measure wall‑clock time per round as a function of T and d; confirm runtime growth O(N d) with N≈log₂ T and identify bottleneck in the direction learner for large d/T.

## Open Questions the Paper Calls Out
### Open Question 1
- **Question:** Can we achieve Õ(√d(1+PT)T) dynamic regret without prior knowledge of PT (path length)?
- **Basis:** Section 4 asks whether guarantees can scale with PT instead of the coarser S_T.
- **Why unresolved:** Proposed method adapts to S_T; PT is a different complexity requiring new techniques.
- **What evidence would resolve:** A parameter‑free algorithm with Õ(√d(1+PT)T) bound that does not take PT as input.

### Open Question 2
- **Question:** Can we achieve parameter‑free dynamic regret against a fully adaptive adversary (adaptive losses and comparator)?
- **Basis:** Section 4 suspects the oblivious comparator assumption may be removable.
- **Why unresolved:** Obliviousness is used to move max_t ||u_t|| outside expectation; adaptive comparator breaks this.
- **What evidence would resolve:** Proof of Õ(√d(1+S_T)T) dynamic regret for adaptive comparator sequences, possibly via almost‑sure loss estimates or a new decomposition.

### Open Question 3
- **Question:** Can we achieve optimal S_T dependence with per‑round computation O(d log T) instead of O(T log T)?
- **Basis:** Section 4 notes the current corralling approach incurs O(T log T) per‑round cost.
- **Why unresolved:** Reducing complexity while preserving optimal S_T adaptation is challenging.
- **What evidence would resolve:** A bandit algorithm with O(d log T) per‑round time that still attains Õ(√d(1+S_T)T) without knowing S_T.

### Open Question 4
- **Question:** Can the uniform sampling and scale/direction decomposition be extended to constrained action sets for parameter‑free dynamic regret?
- **Basis:** Section 4 mentions difficulty with irregular geometries in decoupling scale and direction.
- **Why unresolved:** The factorization w = vβ exploits the unconstrained ℝ^d; maintaining feasibility and combining guarantees under convex constraints is non‑trivial.
- **What evidence would resolve:** A reduction from constrained to unconstrained linear bandits or a new combination technique that works with convex constraints while preserving optimal S_T adaptation.

## Limitations
- The guarantee holds only for an obliviously chosen comparator sequence; an adaptive comparator can violate the bound.
- The analysis requires each base algorithm to have constant comparator‑adaptive regret (R_T(0)=O(1)); if the scale learner’s R_T(0) grows with T, the overall rate degrades.
- The approach is restricted to linear losses and the unconstrained action set ℝ^d.
