# Single molecule localization microscopy challenge: a biologically inspired benchmark for long-sequence modeling

## Quick Facts
- arXiv ID: 2603.11296
- Source URL: https://arxiv.org/abs/2603.11296
- Reference count: 40
- Primary result: State space models achieve at most 73% detection accuracy on simulated SMLM data with heavy-tailed blinking, with performance significantly degrading as temporal discontinuity increases.

## Executive Summary
The paper introduces SMLM-C, a biologically-inspired benchmark for evaluating long-sequence models on sparse, stochastic spatiotemporal point processes derived from single-molecule localization microscopy (SMLM). The benchmark comprises ten simulations of dSTORM and DNA-PAINT modalities, generating sequences up to 10,000 frames with ground truth emitter positions. Using a controlled subset varying only in average off-time (temporal discontinuity), the authors evaluate two state space models (S5 and Mamba-2). Results show that performance degrades substantially as off-time increases; Mamba-2 consistently outperforms S5 in the long off-time regime but at higher computational cost. The highest detection accuracy achieved is 73%, indicating fundamental challenges in modeling heavy-tailed blinking dynamics with current SSMs.

## Method Summary
SMLM-C simulates realistic SMLM data with known emitter trajectories and localization noise. The core task is to predict the true emitter positions from a sequence of observed localizations (points in space-time). The authors focus on a controlled subset where only the average off-time (µoff) — the duration an emitter is dark between fluorescence bursts — varies across conditions (e.g., 100, 500, 1000 frames). Two state space models are evaluated: S5 (structured diagonal SSM) and Mamba-2 (selective SSM). Both process the input sequence of localization events (encoded as a temporal sequence of features) and output a set prediction via an MLP decoder. Performance is measured by detection accuracy (correctly identifying emitters).

## Key Results
- SMLM-C benchmark: 10 simulations covering dSTORM and DNA-PAINT, sequences up to 10,000 frames.
- Performance degrades with increasing temporal discontinuity: detection accuracy drops from ~72% (µoff=100) to ~62-70% (µoff=1000).
- Mamba-2 consistently outperforms S5 in the long off-time regime, though with higher computational cost; maximal accuracy is 73%.

## Why This Works (Mechanism)
The paper identifies three mechanisms that help SSMs handle the SMLM task and explains their limitations:

1. **Temporal Integration via State Propagation**  
   SSMs aggregate information over long sequences by maintaining a hidden state that persists across time. This allows the model to associate temporally disjoint localization events belonging to the same emitter. However, when off-times become very long, the fixed-capacity state decays and loses evidence, leading to performance drops.

2. **Input-Dependent State Modulation for Sparse Regimes**  
   Selective SSMs like Mamba-2 modulate state transitions based on the current input. This may help the model ignore non-informative frames (no localizations) and strengthen updates when a localization arrives, mitigating the effect of long silent periods. Mamba-2’s advantage in long off-time regimes suggests this mechanism is beneficial.

3. **Model Capacity and Expressivity**  
   Larger model variants (more parameters, hidden/state dimensions) achieve better performance because they provide greater representational capacity to model complex blinking dynamics and disentangle overlapping trajectories. However, even the largest models only reach 73% accuracy, indicating inherent limitations.

## Architecture Onboarding
The models (S5, Mamba-2) process sequences of localization events and output predicted emitter positions. The overall pipeline:

Input sequence (localizations per frame) -> Embedding layer -> SSM core -> Final hidden state -> MLP decoder -> Set of position coordinates

**Component map** (plain text):
Input -> Embedding -> SSM (S5 or Mamba-2) -> Aggregated representation -> MLP decoder -> Output set

**Critical path**: The input localization sequence is embedded into a continuous vector per frame. The SSM processes these embeddings sequentially, updating its hidden state at each step. After the last frame, the final hidden state (or a pooled context vector) is fed to an MLP that predicts multiple (x,y) positions, representing the set of emitters present in the sequence.

**Design tradeoffs**:
- *S5* uses fixed diagonal state matrices, offering computational efficiency but lacking input adaptation.
- *Mamba-2* uses input-dependent state transitions, improving performance on long gaps at the cost of higher compute and memory.
- Larger state/hidden dimensions increase capacity but also resource usage.

**Failure signatures**:
- Accuracy drops sharply as average off-time increases, indicating the models cannot retain information over very long gaps.
- Mamba-2 shows slower degradation than S5, but both plateau below 75% accuracy even at moderate µoff=1000.
- Failures manifest as missed detections (false negatives) and spurious detections (false positives), especially when multiple emitters overlap.

**Three first experiments**:
1. Train both S5 and Mamba-2 on the µoff=100 condition and verify they achieve ~70% detection accuracy, establishing baseline capability.
2. Evaluate on increasing µoff values (500, 1000) and plot accuracy to reproduce the degradation curve and Mamba-2’s relative stability.
3. Ablate the input-dependent mechanism in Mamba-2 (e.g., by fixing state transitions) to quantify the contribution of selectivity in the long off-time regime.

## Open Questions the Paper Calls Out
The paper does not explicitly list open questions; however, the introduced benchmark and analysis suggest several avenues for future work, such as extending to real experimental data and exploring architectural improvements for heavy-tailed temporal patterns.

## Limitations
- Simulations only cover dSTORM and DNA-PAINT; real-world challenges (e.g., drift, heterogeneous noise) remain unvalidated.
- Only two SSM variants tested; relative performance against other long-sequence architectures (Transformers, GNNs) is unknown.
- Mechanistic claims (e.g., benefit of selectivity) are inferred from aggregate results, not isolated via targeted ablations.

## Confidence

3. **Architecture comparative sweep**: Evaluate a diverse set of long-sequence models (Transformer variants, TCNs, LSTMs, GNNs) on SMLM-C to contextualize SSM gains and cost-performance trade-offs.
