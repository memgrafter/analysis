# EfficientPosterGen: Semantic-aware Efficient Poster Generation via Token Compression and Accurate Violation Detection

## Quick Facts
- **arXiv ID:** 2603.00155
- **Source URL:** https://arxiv.org/abs/2603.00155
- **Reference count:** 40
- **Primary result:** 10× token reduction (10.33K tokens vs. 125.25K), 94% layout detection accuracy, improved PaperQuiz scores (152.74 vs. 142.81).

## Executive Summary
Automated academic poster generation faces challenges of low information density, excessive token consumption, and unreliable layout verification. EfficientPosterGen introduces three innovations to address these: Semantic-aware Key Information Retrieval (SKIR) selects high-value content via a semantic contribution graph; Visual-based Context Compression (VCC) renders text into images to shift information to visual modality, drastically reducing token usage; and Agentless Layout Violation Detection (ALVD) uses a deterministic color-gradient algorithm for reliable overflow and sparsity checks without MLLMs. The system achieves a 10× token reduction, 94% layout detection accuracy, and superior downstream performance on PaperQuiz while maintaining competitive visual and textual quality.

## Method Summary
The pipeline begins by parsing the input paper into text segments, figures/tables, and a hierarchical section tree. SKIR then groups paragraphs by perplexity, constructs a directed semantic contribution graph where edges represent perplexity reduction (i.e., semantic influence), computes PageRank on the reversed graph with a diversity penalty based on section tree LCA, and selects a budgeted subset of segments (γ). VCC renders these selected segments as images (DPI=96) grouped by top-level section, feeds them to an MLLM with a bullet-point generation prompt, and obtains concise content along with a font-size configuration. A binary-tree layout engine estimates panel bounding boxes from the bullet points. ALVD analyzes each panel image by partitioning it into strips, computing color gradients, activating strips above the median gradient, defining candidate content regions via Cartesian product of activated horizontal and vertical strips, and checking for overflow (bounding box exceeds panel) or sparsity (activated area ratio below τ_s). If violations are detected, the system triggers a regeneration loop via VCC with adjusted parameters (e.g., reduced font size or text length).

## Key Results
- **Token efficiency:** Ours-Qwen uses 10.33K tokens vs. PosterAgent-Qwen's 125.25K (≈10× reduction).
- **Layout reliability:** ALVD achieves 94% accuracy on overflow/sparsity detection (N=512, τ_s=0.5) with ~186ms latency.
- **Downstream quality:** PaperQuiz score of 152.74 vs. 142.81 for PosterAgent, with competitive CLIP visual similarity and perplexity-based textual coherence.

## Why This Works (Mechanism)

### Mechanism 1: Semantic-aware Key Information Retrieval (SKIR)
**Claim:** SKIR improves information density by selecting high-contribution content segments.  
**Mechanism:** It constructs a directed semantic contribution graph from paper segments, where an edge from segment i to j exists if i reduces the perplexity of j (modeled as mutual information). PageRank is applied to the reversed graph to quantify transitive influence, and a diversity penalty based on the lowest common ancestor (LCA) in the section tree prevents over-selection from narrow sections.  
**Core assumption:** High perplexity reduction between segments signifies that one segment is semantically instrumental to understanding the other, capturing narrative importance beyond self-contained relevance.  
**Evidence anchors:**  
  - [abstract] "constructs a semantic contribution graph to model inter-segment relationships and selectively preserves important content."  
  - [section 3.2] Details the perplexity-based edge definition (Eq. 3), graph construction (Eq. 4), and diversity-aware selection with LCA penalty (Eq. 6, Algorithm 1).  
  - [corpus] Related work (e.g., P2P, PosterAgent) struggles with low information density; SKIR directly addresses this by modeling contribution. Corpus evidence for the specific graph+PageRank+LCA mechanism is weak; this is a novel design.  
**Break condition:** If the perplexity-based contribution scores become noisy (e.g., due to domain-specific language not well modeled by the base LM), the graph edges may not reflect true semantic importance, leading to poor segment selection.

### Mechanism 2: Visual-based Context Compression (VCC)
**Claim:** VCC reduces token consumption while preserving semantic readability for MLLM-based generation.  
**Mechanism:** Selected text segments are rendered into high-DPI images (grouped by section) and fed to the MLLM as visual inputs instead of raw text, shifting information to the visual modality where MLLMs can process it with fewer tokens.  
**Core assumption:** MLLMs can accurately extract and reason over textual content presented in high-DPI images, enabling effective token compression without significant information loss.  
**Evidence anchors:**  
  - [abstract] "renders selected text segments into images to shift textual information into the visual modality, significantly reducing token usage."  
  - [section 3.3] Defines compression ratio (Eq. 7) and describes the rendering process and MLLM prompt for bullet-point generation.  
  - [section 5.2 Task 2] Quantifies the trade-off: at DPI=96, GPT-5 achieves CR=1.4× with 7.4% edit distance, Qwen-VL achieves CR=2.12× with 8.9% edit distance.  
**Break condition:** If rendered text is too low-DPI, OCR fidelity drops, causing the MLLM to misinterpret or hallucinate content. If too high-DPI, token savings vanish. The sweet spot is model-dependent.

### Mechanism 3: Agentless Layout Violation Detection (ALVD)
**Claim:** ALVD provides reliable, low-overhead verification of panel overflow and sparsity without MLLMs.  
**Mechanism:** For each panel image, it partitions into N horizontal and vertical strips, computes color gradient magnitudes (e.g., Sobel) along each strip, activates strips above the median gradient, forms a Cartesian product of activated strips to define candidate content regions, and checks if the minimum bounding rectangle exceeds panel boundaries (overflow) or if the activated area ratio is below a threshold (sparsity).  
**Core assumption:** Text and figure content regions exhibit high color variation (edges), while empty panel areas have low variation; the activated strip intersection reliably approximates the true content bounding box.  
**Evidence anchors:**  
  - [abstract] "deterministic color-gradient-based algorithm that reliably detects content overflow and spatial sparsity without auxiliary MLLMs."  
  - [section 3.4] Presents Algorithm 2 in full, with Figure 3 illustrating the gradient, activation, and Cartesian product steps.  
  - [section 5.2 Task 3] Reports 94% accuracy on a manually curated ternary dataset (overflow/sparse/valid) with N=512, τ_s=0.5, and ~186ms latency.  
  - [section D] Shows ALVD (94%) outperforms MLLM-based (62–73%) and EasyOCR (71%) detectors, with 33–49× speedup.  
**Break condition:** If panel backgrounds have high-frequency textures or gradients (e.g., patterned fills), the median-based strip activation may fire on non-content areas, causing false positives for overflow or false negatives for sparsity.

## Foundational Learning

### Semantic Contribution Graphs & PageRank
**Why needed here:** SKIR's core innovation is modeling which paper segments are most *instrumental* to understanding others, not just self-contained importance. This requires understanding graph-based centrality measures for transitive influence.  
**Quick check question:** *If segment A contributes strongly to B, and B contributes strongly to C, how does PageRank on the reversed graph help prioritize A over C for selection, and why is an LCA diversity penalty necessary?*

### Visual Token Compression Trade-offs
**Why needed here:** VCC's effectiveness hinges on the non-linear relationship between image resolution (DPI), visual token count (from MLLM vision encoder), and OCR fidelity. A practitioner must understand how to navigate this trade-off.  
**Quick check question:** *Why does increasing DPI eventually reduce the compression ratio (CR < 1), and what does the edit distance metric reveal about the information loss at sub-optimal DPI settings?*

### Gradient-Based Content Region Detection
**Why needed here:** ALVD replaces MLLM reasoning with deterministic signal processing. Understanding how gradient magnitude correlates with content edges is key to diagnosing failures.  
**Quick check question:** *How does the Cartesian product of activated horizontal and vertical strips (I_x × I_y) create a conservative estimate of the content area, and why is the minimum enclosing rectangle used for overflow detection instead of the union of strips?*

## Architecture Onboarding

**Component map:**  
Input Parser (MinerU) -> SKIR -> VCC -> Layout Engine -> ALVD -> (Feedback to VCC)

**Critical path:** SKIR (info extraction) -> VCC (token-efficient summarization) -> Layout Engine (structure guess) -> ALVD (deterministic check) -> (optional) VCC regeneration. The path is linear with a feedback loop only from ALVD to VCC.

**Design tradeoffs:**  
- **SKIR β/γ:** High β (sparse graph) risks missing connected insights; low β adds noise. High γ (more segments) increases token cost but may improve coverage. Optimal (β=0.5, γ=0.5) balances per-token info gain.  
- **VCC DPI:** Low DPI (high compression) risks MLLM misreading; high DPI loses efficiency. DPI=96 is a sweet spot for GPT-5/Qwen-VL as per OCR eval.  
- **ALVD N/τ_s:** Fine strips (high N) amplify noise; coarse strips (low N) miss boundaries. High τ_s mislabels moderately dense panels as sparse. N=512, τ_s=0.5 optimizes for human-like perception.

**Failure signatures:**  
- **Poster text is generic/verbose:** SKIR failed (γ too high or β too low), dumping low-value segments.  
- **MLLM hallucinates poster facts:** VCC DPI too low; OCR errors propagated.  
- **Poster has overflowing text or huge blanks:** ALVD thresholds mis-set or panel has textured background causing false gradient activations.  
- **Regeneration loop never terminates:** ALVD gives false positives (e.g., textured background) or VCC cannot satisfy constraints (e.g., too much content for font-size-downscaling).

**First 3 experiments:**  
1. **SKIR Sanity Check:** Run SKIR on a sample paper. Inspect the semantic contribution graph: do edges connect Introduction→Methodology and Methodology→Results? Verify high-PageRank segments are core contributions (e.g., method description, key results), not lit review.  
2. **VCC Fidelity Test:** Render a sample paragraph at DPI=96. Run the MLLM (Qwen-VL) on the image vs. the raw text. Compare the extracted bullet points for semantic equivalence. Compute edit distance between OCR'd text and original.  
3. **ALVD Validation:** Generate a panel with known overflow (text past bottom margin) and known sparse (single title). Confirm ALVD flags them correctly with N=512, τ_s=0.5. Then, add a faint grid pattern to the panel background; check for false-positive overflow detection.

## Open Questions the Paper Calls Out
1. **Robustness to unconventional papers:** How robust is SKIR to academic papers with unconventional section structures or high proportions of non-text elements (e.g., equations, algorithms, figures)? The paper’s experiments use standard PDFs; performance on visually rich or structured-content papers is unknown.
2. **Generalizable DPI settings:** What are the generalizable principles for setting the DPI in VCC to achieve optimal token compression without significant information loss across diverse MLLMs and typography styles? The paper shows DPI=96 as a sweet spot for two models, but acknowledges trade-offs.
3. **ALVD on complex backgrounds:** Is the color-gradient-based ALVD algorithm effective for layout verification in posters with complex backgrounds, watermark effects, or integrated images that affect color distribution? The evaluation dataset uses simple, uniformly colored panels.
4. **Cross-lingual and domain adaptation:** Can the EfficientPosterGen framework be adapted for generating posters in languages other than English or for non-academic purposes like event posters or advertisements? The pipeline may be tuned for English academic content.

## Limitations
- **Hyperparameter generalizability:** Optimal β, γ, λ for SKIR and N, τ_s for ALVD were tuned on a single dataset; performance may drop on papers with different structures or domains.
- **Layout engine opacity:** The binary-tree layout algorithm adapted from [24] is not fully specified, making exact replication difficult.
- **MLLM dependency:** VCC’s compression–fidelity trade-off is tied to specific MLLMs (GPT-5, Qwen-VL); other models may not replicate the reported edit distances.
- **Failure modes:** SKIR graphs can become noisy if perplexity estimates are poor; VCC may hallucinate at low DPI; ALVD may trigger false positives on panels with textured backgrounds or gradients.

## Confidence
- **SKIR:** Medium. Novel graph-based selection is theoretically sound but lacks extensive cross-domain validation; effectiveness hinges on quality of language model perplexity.
- **VCC:** Medium. Empirical compression results are convincing, yet the approach is model- and DPI-sensitive; break condition shows potential fidelity loss.
- **ALVD:** High. Deterministic algorithm with strong experimental results (94% accuracy, 186 ms latency) and clear, interpretable thresholds; robust to many real-world layouts.

## Next Checks
1. **SKIR generalization test:** Apply the fixed SKIR pipeline to a held-out corpus of papers from at least three distinct domains (e.g., biology, physics, social sciences). Evaluate information density via human annotation or downstream PaperQuiz scores, and report variance across domains.
2. **VCC cross-model and DPI study:** Replicate VCC with three additional MLLMs (e.g., LLaVA‑1.6, Claude 3.5 Sonnet, Gemini 1.5) across DPI values ranging from 72 to 192. Measure compression ratio, OCR edit distance, and MLLM extraction accuracy to define a robust operating region.
3. **ALVD robustness stress test:** Generate synthetic panel images with systematic background patterns (grid, stripes, photographic textures). Compute false positive/negative rates for overflow and sparsity detection at the proposed N=512, τ_s=0.5, and propose adjusted thresholds if needed.
