# From Stateless to Situated: Building a Psychological World for LLM-Based Emotional Support

## Quick Facts
- **arXiv ID:** 2603.25031
- **Source URL:** https://arxiv.org/abs/2603.25031
- **Reference Count:** 31
- **Primary Result:** A situated architecture with a CBT-inspired dual-gating state machine achieved a 31% absolute improvement in deep intervention loop completion and robust boundary control in high-resistance tests.

## Executive Summary
Large language models (LLMs) used for multi-turn emotional support often fail due to statelessness, leading to premature progression through therapeutic stages and violations of user boundaries. This paper introduces LEKIA 2.0, a general architecture that separates a cognitive layer for continuous situational state updates from an executive layer that uses a cognitive behavioral therapy (CBT)-inspired state machine with dual-gating. This design enforces consent-aware stage progression. Evaluated via a novel Static-to-Dynamic simulation protocol, the system significantly outperformed prompt-only baselines on metrics of process completion and boundary adherence, particularly in high-resistance scenarios.

## Method Summary
The core innovation is a two-layer architecture. The cognitive layer maintains a "situated state" by continuously updating a structured representation of the user's narrative and process evidence (e.g., identified patterns, readiness for homework). The executive layer implements a finite state machine modeling a linear CBT intervention (Engage -> Explore -> Insight -> Act). Progression between these stages is governed by a dual-gate mechanism requiring both objective completion flags (from the state) and explicit/implicit user consent signals. This contrasts with standard stateless prompting, where the LLM must infer and maintain all context and progression logic implicitly within its context window.

## Key Results
*   Achieved a 31% absolute improvement in deep intervention loop completion over prompt-only baselines in the Static-to-Dynamic evaluation.
*   Average stage completion rate was 0.895 vs. 0.59 for baselines.
*   In high-resistance stress tests, maintained 84% immediate adherence to refusals and 0% cooldown violations.

## Why This Works (Mechanism)
The architecture works by externalizing and operationalizing the therapeutic process. The cognitive layer's persistent state tracker acts as a "psychological world model," preventing the LLM from forgetting critical user information or lost progress. The executive layer's state machine imposes a disciplined, explicit progression logic, replacing the LLM's implicit and often faulty intuition about therapeutic stages. The dual-gate (state completion + consent) directly addresses the core failure modes: it prevents advancement before necessary work is done (addressing premature progression) and hard-stops on boundary violations by requiring consent signals before moving forward or re-asking sensitive topics.

## Foundational Learning
*   **Concept:** Therapeutic Stage Models (e.g., CBT skeleton)
    *   **Why Needed:** Provides a structured, evidence-based scaffold for intervention progression, replacing open-ended dialogue with a target-oriented process.
    *   **Quick Check:** Can you map a user's utterances to discrete therapeutic stages (e.g., problem identification vs. insight generation)?
*   **Concept:** Dual-Gating for Consent
    *   **Why Needed:** Separates the *objective readiness* for a stage (e.g., pattern identified) from the *subjective permission* to proceed (e.g., user agrees to explore it), creating a robust boundary control mechanism.
    *   **Quick Check:** Can you distinguish a user's verbal consent from their demonstrated readiness based on prior dialogue?
*   **Concept:** Situated State Representation
    *   **Why Needed:** Compensates for LLM statelessness by creating an external, queryable memory of key psychological constructs (narrative, evidence, interventions tried), ensuring continuity.
    *   **Quick Check:** Can you extract and update a structured tuple (e.g., {core_belief: "I am unlovable", evidence: ["argument with friend"]}) from a user's message?
*   **Concept:** Static-to-Dynamic Simulation Protocol
    *   **Why Needed:** Enables controlled, reproducible evaluation of multi-turn process control by generating dialogue trajectories from static single-turn data, simulating user resistance and progression.
    *   **Quick Check:** Can you generate a plausible multi-turn dialogue sequence from a single user utterance that tests a specific stage transition or boundary?
*   **Concept:** Process Evidence Accumulation
    *   **Why Needed:** Provides the objective component for progression gates (e.g., "pointed_out_pattern" flag), moving beyond subjective LLM judgment to defined, checkpoints.
    *   **Quick Check:** Can you define concrete, observable dialogue acts that serve as proof a therapeutic milestone was reached?

## Architecture Onboarding
**Component Map:** User Input -> Cognitive Layer (State Tracker/Updater) -> Executive Layer (CBT State Machine with Dual-Gate Logic) -> System Response. State persistence connects across turns.

**Critical Path:** 1) User message received. 2) Cognitive layer updates the structured situational state (Narrative, Process Evidence). 3) Executive layer evaluates current state against dual-gate rules for the *next* intended stage. 4) If gates pass, state machine advances and response is generated from the new stage's policy; if gates fail, a boundary-respecting response (e.g., concession, re-ask) is generated from the current stage.

**Design Tradeoffs:** Strict process discipline and boundary control (safety, reliability) vs. flexibility and natural flow (therapeutic alliance, user experience). The CBT linear skeleton may not suit all users or issues. External state management adds complexity and potential points of failure in state tracking/updates.

**Failure Signatures:** *Stalled Progression:* State tracker fails to set completion flags, or consent gates are perpetually failed, causing the system to loop in an early stage. *Boundary Violation:* Executive layer advances stage or repeats a boundary-crossing question without sufficient consent signal, often due to faulty consent detection. *State Corruption:* Cognitive layer mis-updates the state (e.g., incorrect belief extraction), poisoning all subsequent gating decisions.

**First Three Experiments:**
1.  **Resistance Pattern Sensitivity:** Test the system on a corpus of naturally occurring supportive dialogues with fine-grained resistance annotations (subtle avoidance, ambivalence, direct refusal). Measure rate of appropriate concession vs. stalled progression for each resistance type.
2.  **Ablation of Dual-Gating:** Disable the consent gate (stage completion -> CBT State Machine) -> System Response
    *   Executive Layer: CBT State Machine with Dual-Gate (State Completion AND Consent) -> System Response
3.  **Therapeutic Alliance Pilots:** Conduct a small-scale (n=20-30), IRB-approved, between-subjects study where participants have 3-4 conversations with either LEKIA 2.0 or a prompt-only CBT baseline. Measure post-session alliance (Working Alliance Inventory), dropout rates, and qualitative feedback on feeling heard/controlled.

## Open Questions the Paper Calls Out
### Open Question 1
*   **Question:** What systematic biases might persist in LLM-as-Judge evaluations of multi-turn process control, and how can they be mitigated for reliable, large-scale safety assessment?
*   **Basis in paper:** [explicit] The authors state that while LLM-as-Judge agreed with human experts on 50 samples (Kappa > 0.72), this "should not be taken to imply the absence of systematic bias" and call for "larger-scale double-blind human review" in real-world settings (Section V.B).
*   **Why unresolved:** The current audit is limited to a small sample and only verifies inter-rater agreement, not identifying subtle, consistent judge biases (e.g., towards certain intervention styles or against ambiguous resistance).
*   **What evidence would resolve it:** A large-scale study where multiple domain experts independently score a diverse corpus of interactions, analyzing discrepancies between judge and human consensus across distress types, resistance patterns, and stage transitions.

### Open Question 2
*   **Question:** To what extent does the dual-gating mechanism's strict boundary control generalize from the curated, high-resistance stress test to the heterogeneous and often subtle resistance patterns in naturally occurring supportive dialogues?
*   **Basis in paper:** [explicit] The authors acknowledge their "Resistance Hard-Negative Stress Test uses a deliberately selected set of highly resistant cases" and that this "does not fully represent the overall distribution of resistance patterns encountered in naturally occurring interaction" (Section V.C).
*   **Why unresolved:** The architecture's performance on extreme, explicit refusal/hesitation is proven, but its sensitivity to gradual, implicit, or mixed-signal resistance—common in real support—remains unknown. Overly rigid gating might stall progress on subtle resistance.
*   **What evidence would resolve it:** Analysis of the system's behavior on a corpus of naturally occurring support dialogues (e.g., from counseling platforms) with annotated resistance granularity (e.g., subtle avoidance, ambivalence vs. direct refusal), measuring appropriate concession/retry timing.

### Open Question 3
*   **Question:** How does the situated architecture's process discipline impact perceived therapeutic alliance, user acceptability, and long-term engagement in real-world, multi-session emotional support interactions?
*   **Basis in paper:** [explicit] The authors explicitly state the work "has not yet been validated through real-user studies" and that current findings "cannot fully establish the system's acceptability, naturalness, or long-term usability" (Section V.D). They call for "systematic user studies with real participants."
*   **Why unresolved:** The simulation-based metrics measure process completion and boundary adherence, but not user-centered outcomes like trust, feeling heard, or willingness to continue. A clinically safe process might feel robotic or stilted.
*   **What evidence would resolve it:** Longitudinal user studies where participants interact with LEKIA vs. baselines over multiple sessions, measuring alliance (e.g., Working Alliance Inventory), dropout rates, and qualitative feedback on the felt experience of the structured progression.

### Open Question 4
*   **Question:** Can the LEKIA architecture's cognitive-executive separation and dual-gating mechanism be effectively generalized beyond the CBT instantiation to other process-oriented therapeutic frameworks with different stage structures, progression logic, and boundary concepts (e.g., psychodynamic, humanistic, or solution-focused approaches)?
*   **Basis in paper:** [inferred] While the authors present the architecture as general ("a general architecture" in Section III.A), all evaluations instantiate it within a specific, linear four-stage CBT skeleton. The paper's claims about "external state" and "dual-gating" are demonstrated only for this one therapeutic model.
*   **Why unresolved:** The state definitions (Narrative State, Process Evidence), stage completion flags, and gating rules are tightly coupled to CBT-specific constructs (e.g., "pointed_out_pattern," "automatic thoughts"). Different therapies define "progress" and "boundary" fundamentally differently (e.g., transference in psychodynamic).
*   **What evidence would resolve it:** A replication study re-implementing the architecture for a contrasting therapeutic modality, defining new state schemas and gating rules aligned with that model's theory, and demonstrating similar process-control advantages on modality-specific evaluation metrics.

## Limitations
*   **Proprietary & Non-Reproducible Evaluation:** Key claims rely on an opaque "Static-to-Dynamic" protocol with an undisclosed dataset, limiting independent verification and assessment of external validity across diverse populations and issues.
*   **Narrow Stress-Testing:** Boundary control is validated only on a curated "high-resistance" test set, not on the spectrum of subtle, ambiguous, or culturally variable resistance found in real conversations.
*   **Absence of Human-Centered Validation:** All results are simulation-based; there is no evidence on user experience, therapeutic alliance, dropout, or long-term engagement, leaving critical acceptability questions unanswered.

## Confidence
*   **Claim:** The dual-layer architecture (cognitive state tracker + executive state machine) provides a structured solution to LLM statelessness in process-oriented dialogue.
    *   **Label:** Medium – Conceptually sound and evaluated on a specific task, but implementation details are opaque and generalizability is claimed, not proven.
*   **Claim:** The dual-gating mechanism enforces strict boundary control, achieving 84% immediate adherence and 0% cooldown violations in tests.
    *   **Label:** Low – Results are from a narrow, curated stress test; performance on unpredictable, real-world user behavior is unknown.
*   **Claim:** LEKIA 2.0 achieves a 31% absolute improvement in intervention completion (0.895 vs. 0.59) over prompt-only baselines.
    *   **Label:** Medium – Metrics are precise and show a large effect, but lack statistical variance reporting, baseline details, and independent replication on public benchmarks.

## Next Checks
1.  **Cross-Dataset Replication:** Re-implement and evaluate LEKIA 2.0 on a public emotional support benchmark (e.g., ESConv) using a standardized simulation protocol to test generalizability beyond the proprietary dataset.
2.  **Ablation of Dual-Gating:** Conduct a controlled ablation study disabling the consent gate or the state completion gate independently to quantify each component's specific contribution to boundary control and progression success.
3.  **Real-User Piloting:** Initiate a small-scale, IRB-approved study with real participants interacting with the system over multiple sessions to measure initial data on therapeutic alliance, perceived autonomy, session dropout, and comparative naturalness vs. a baseline.
