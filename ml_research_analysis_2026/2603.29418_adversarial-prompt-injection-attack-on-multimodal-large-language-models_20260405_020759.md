# Adversarial Prompt Injection Attack on Multimodal Large Language Models
## Quick Facts
- **arXiv ID**: 2603.29418
- **Source URL**: https://arxiv.org/abs/2603.29418
- **Reference count**: 16
- **Primary result**: CoTTA achieves up to 81% attack success rate (ASR) on Gemini-2.5 and 74% on GPT-4o for image captioning, and 82% ASR on GPT-4o for VQA under exact match criterion.

## Executive Summary
Multimodal large language models (MLLMs) are vulnerable to stealthy prompt injection attacks where malicious instructions are embedded within input images. This paper proposes CoTTA, a dual-target adversarial attack that combines a subtle text overlay (covert trigger) with adversarial perturbations, optimized to align features of the attacked image both with a dynamic target image and the target command's text embedding. This bridges the modality gap and enhances transferability to closed-source models. Extensive experiments on GPT-4o, GPT-5, Gemini-2.5, and Claude-4.5 demonstrate state-of-the-art performance, with CoTTA substantially outperforming prior attacks in both success rate and output similarity.

## Method Summary
CoTTA operates through three iterative components over 300 epochs under an ℓ∞ constraint (ε=16). First, a **covert trigger** renders the target command as tight white text on a black background and applies an affine transformation (scale `s`, rotation `θ`) to produce a binary mask and subtle overlay `x_trig`. Second, a **dynamic target image** `G_img` is initialized from the mask and refined via I-FGSM to maximize similarity between its CLIP image features and the target text embeddings of paraphrased variants, while simultaneously pushing away from the current attacked image's features. Third, the **adversarial perturbation** `δ` on `x_trig` is updated to maximize a dual-target loss `M_src` that combines global cosine similarity between `x'` and `G_img`/target text, and local patch-level similarity using CLIP's patch tokens. The affine parameters are optimized with Adam to further improve `M_src`. After convergence, `x' = x_trig + δ` is the final adversarial image.

## Key Results
- Captioning: CoTTA reaches up to 81% ASR on Gemini-2.5 and 74% on GPT-4o under strict exact-match criterion.
- VQA: Achieves 82% ASR on GPT-4o.
- Outperforms prior adversarial attacks by large margins; average semantic similarity (AvgSim) improvements are also significant.
- Ablations confirm that each component (covert trigger, dynamic target, local alignment) contributes to performance, with the image-to-image alignment being particularly important.

## Why This Works (Mechanism)
CoTTA's effectiveness stems from its dual-target alignment strategy. The dynamic target image acts as a bridge between the visual domain of the adversarial image and the textual domain of the malicious command, guiding the optimization toward features that are semantically aligned with the target while preserving the covert trigger's presence. Local patch-level matching ensures fine-grained control, preventing the attack from relying solely on global semantics. The iterative refinement of G_img adapts to the current perturbation, creating a moving target that enhances transferability to unseen victim models whose vision encoders may differ from the CLIP surrogates. Furthermore, the covert trigger's subtlety ensures the malicious text is present but not obviously suspicious, increasing the likelihood that the victim model processes it as part of the input.

## Foundational Learning
- **Adversarial Examples**: Small, crafted perturbations that cause model errors. *Why needed*: Forms the basis of generating `δ`. *Quick check*: Can you add imperceptible noise to a panda image to make it classified as a gibbon?
- **Multimodal LLMs (MLLMs)**: Models that jointly process images and text (e.g., GPT-4o). *Why needed*: The attack targets these systems. *Quick check*: Does feeding an image to an LLM produce a text response describing it?
- **CLIP Embeddings**: Contrastive model aligning images and text in a shared space. *Why needed*: Provides surrogate feature extractors (`fe`, `ft`) for loss computation. *Quick check*: Is the cosine similarity higher between a dog image and the text "dog" than with "car"?
- **Prompt Injection**: Technique to hijack model behavior via hidden instructions. *Why needed*: The attack's goal is to inject a target command. *Quick check*: Can a hidden text in an image make an MLLM output a specific phrase?
- **Projected Gradient Descent (PGD)**: Iterative attack optimizing within a norm ball. *Why needed*: Used for I-FGSM updates of `δ` and `δ_tgt`. *Quick check*: Can PGD generate an ℓ∞-bounded perturbation that fools a simple classifier?
- **Feature Matching (Global & Local)**: Aligning representations at different granularities (e.g., CLS token vs. patch tokens). *Why needed*: Global alignment guides semantics; local alignment refines details. *Quick check*: Do CLIP's patch tokens capture spatial details missing from the global embedding?

## Architecture Onboarding
**Component map**:
Clean Image (x) -> [Covert Trigger: render(c*) + affine(s,θ)] -> x_trig
x_trig + δ (perturbation) -> Attacked Image (x')
Target text c* + paraphrases P* -> [Dynamic Target (G_img) via I-FGSM (δ_tgt)] -> Updated G_img
Dual-Target Loss M_src uses:
- Global features fe(x') vs fe(G_img) and ft(p*_i)
- Local features f_loc_e(x') vs f_loc_e(G_img)
Optimizers: Adam for (s,θ); I-FGSM for δ, δ_tgt.
Loop: update G_img/δ_tgt -> compute M_src -> update δ & (s,θ).

**Critical Path**: The attack's success depends on tight coupling between the covert trigger (ensuring the command is visually present) and the dual-target loss (steering x' toward the command's semantics). Weakness in either (e.g., invisible trigger, or misaligned G_img) leads to failure.

**Design Tradeoffs**:
- Stealth vs. Attack Strength: Smaller ε or lower contrast text is stealthier but may reduce ASR.
- Surrogate-Victim Gap: CLIP may not match victim's vision encoder; using an ensemble of surrogates improves transferability but increases cost.
- Compute vs. Performance: More epochs, smaller α improve convergence but raise compute demands.
- Hyperparameters: λ_push prevents G_img collapse but if too high stifles alignment.

**Failure Signatures**:
- ASR ~0%: Verify losses decreasing; check that affine parameters are updating (they may be stuck).
- Obvious artifacts: ε or Δ too large; affine scale/rotation not bounded properly.
- Transfer failure: ASR high on surrogate but 0 on victim; try ensemble of surrogates.
- G_img becomes identical to x' early: λ_push likely too low; inspect cosine similarity between fe(G_img) and fe(x').

**Exactly 3 First Experiments**:
1. **White-box validation**: Run CoTTA with CLIP-B/16 as both surrogate and victim (use CLIP zero-shot classification on x' with target text). Confirm >90% success on surrogate; ensures implementation correctness.
2. **Ablate dynamic target**: Fix G_img as the initial mask image (no updates). Measure ASR drop; expected significant decrease, confirming the necessity of iterative target refinement.
3. **Visual stealth check**: Generate adversarial examples and compute PSNR (>40 dB expected) and SSIM (>0.95). Manually inspect a sample to ensure trigger text is readable but not glaring.

## Limitations
- Implementation details (paraphrasing method, font rendering, local feature selection, judge LLM prompt, API configurations) are unspecified, hindering exact replication.
- Victim models (GPT-4o, etc.) are proprietary and may update, causing result drift over time.
- The absence of official code release forces independent reimplementation, increasing risk of deviations.
