# Toward High-Fidelity Visual Reconstruction: From EEG-Based Conditioned Generation to Joint-Modal Guided Rebuilding

## Quick Facts
- arXiv ID: 2603.19667
- Source URL: https://arxiv.org/abs/2603.19667
- Reference count: 8
- Primary result: JMVR achieves state-of-the-art performance on the THINGS-EEG dataset, with Pixel Correlation 0.236, SSIM 0.372, CIELab EMD 12.413, and Depth EMD 0.982, demonstrating superior spatial and chromatic fidelity.

## Executive Summary
Current EEG-based visual reconstruction methods often force EEG features into alignment with text or image semantic spaces, losing critical spatial and chromatic details. This paper proposes the Joint-Modal Visual Reconstruction (JMVR) framework, which treats EEG and text as independent modalities within a joint latent space to preserve EEG-specific information. JMVR combines a multi-scale EEG encoder, image augmentation, joint-modal attention, and diffusion-step gating to dynamically balance semantic and perceptual contributions. Evaluated on the THINGS-EEG dataset, JMVR outperforms six baselines across multiple fidelity metrics, setting a new state-of-the-art.

## Method Summary
JMVR builds on a Diffusion Transformer (DiT) backbone with four integrated components. (1) A multi-scale EEG encoder processes raw EEG signals via a dual-branch design: a spatiotemporal branch using 1D convolutions and channel attention captures fine-grained dynamics, while a pyramid multi-scale pooling branch extracts hierarchical temporal features for global semantics. (2) Image augmentation applies edge (Canny), saturation (HSV), and depth (Depth-Anything-v2) transforms to target images; the augmented views are encoded by a pre-trained VAE to produce enhanced latents. (3) A Joint-Modal Attention block operates inside DiT layers, applying modality-specific layer normalization and linear projections to EEG, text, and image tokens before concatenating them for joint self-attention, thus preserving native feature distributions. (4) Diffusion-step gating modulates the residual outputs from each modality using timestep-dependent sinusoidal weights (λ_txt(τ) and λ_eeg(τ)), enabling text to dominate early denoising (global structure) and EEG to refine late stages (fine details). The model is trained end-to-end on THINGS-EEG with a diffusion loss.

## Key Results
- Achieves state-of-the-art performance on THINGS-EEG, surpassing six baselines.
- Significantly improves spatial fidelity: SSIM 0.372 and Pixel Correlation 0.236.
- Demonstrates strong color and depth alignment: CIELab EMD 12.413 and Depth EMD 0.982.

## Why This Works (Mechanism)
JMVR’s superiority arises from three synergistic mechanisms:

1. **Independent Modality Learning**: By treating EEG and text as separate modalities in a joint latent space, JMVR avoids condensing EEG-specific details into pre-aligned text embeddings. The Joint-Modal Attention block uses modality-specific layer normalization and linear projections, then concatenates tokens for self-attention, enabling bidirectional information flow while preserving native feature distributions. Evidence: The formulation in Section 3.3 and ablations showing performance drops when modality-specific parameters are removed.

2. **Multi-Scale EEG Encoding**: The dual-branch encoder simultaneously captures fine-grained spatiotemporal variations (via 1D convolutions and channel attention) and coarse global semantics (via Pyramid Multi-Scale Pooling), overcoming the limited receptive field of single-scale approaches. Evidence: Ablations in Table 2 reveal that removing the PMSP branch degrades DeepEMD (spatial) and LabEMD (color) metrics.

3. **Diffusion-Step Gating**: A dynamic weighting scheme modulates text and EEG influences across diffusion timesteps using sinusoidal schedules (λ_txt(τ) decays while λ_eeg(τ) increases). This aligns modality contributions with the coarse-to-fine generative process, letting text guide early global structure and EEG handle late-stage perceptual details. Evidence: Section 3.4 describes the mechanism; ablations without gating reduce overall performance, especially on fine-detail metrics.

## Architecture Onboarding
- **Component map**: Input Encoders (EEG → multi-scale encoder; text → coarse/fine CLIP encoders; image → augmentations → VAE) → Core Block (JMVR Block within DiT: modality-specific layernorm/scale-shift, joint self-attention on concatenated tokens, modality-specific MLP) → Diffusion Step Gating (timestep-conditioned λ_txt, λ_eeg).
- **Critical path**: EEG → multi-scale encoder → EEG embedding; text → coarse/fine embeddings; image → augmentations → VAE → enhanced latent. All fed into DiT blocks. Inside each block, condition_latent (coarse text + diffusion step + EEG) modulates image latent via adaLN; cognition_latent (fine text + EEG) interacts via joint attention; gating adjusts residuals per timestep.
- **Design tradeoffs**: Decoupling vs. alignment stability (shared projections risk detail loss but simplify training); encoder complexity (multi-scale adds parameters but captures fine details); gating schedule design (simple sinusoidal may be suboptimal versus learned but risks overfitting).
- **Failure signatures**: High LabEMD (>15) indicates poor color fidelity—check EEG encoder or augmentation; high DeepEMD (>1.5) indicates poor spatial layout—inspect multi-scale encoder and gating; channel attention analysis shows no parietal/temporal redistribution when text is added—joint-modal learning may be failing.
- **First 3 experiments**: (1) Ablate multi-scale encoder (use only spatiotemporal branch)—expect degradation in DeepEMD and LabEMD. (2) Ablate diffusion-step gating (fixed λ_txt=λ_eeg=1)—expect overall drop, especially in fine-detail metrics. (3) Ablate image augmentation (remove edge/saturation/depth)—expect sharp increase in LabEMD and DeepEMD.
