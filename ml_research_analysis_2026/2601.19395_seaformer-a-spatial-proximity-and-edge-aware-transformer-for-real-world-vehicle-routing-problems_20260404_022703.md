# SEAFormer: A Spatial Proximity and Edge-Aware Transformer for Real-World Vehicle Routing Problems

## Quick Facts

- ArXiv ID: `2601.19395`
- Source URL: https://arxiv.org/abs/2601.19395
- Reference count: 40
- Primary result: SEAFormer is the first neural method to solve 1,000+ node real-world VRP instances effectively, achieving ≥15% lower objective than SOTA on large-scale problems while ensuring 100% feasibility.

## Executive Summary

SEAFormer addresses real-world Vehicle Routing Problems (RWVRPs) that include complex sequence-dependent constraints such as delivery time windows, vehicle recharging, and asymmetric travel costs—challenges that existing neural methods fail to handle. It introduces a transformer architecture with two key innovations: Clustered Proximity Attention (CPA) reduces attention complexity from O(n²) to O(n) via spatial clustering around the depot, and a lightweight edge-aware module captures pairwise edge features through residual fusion. Evaluated on four RWVRP variants (VRPTW, EVRPCS, VRPRS, A VRP), SEAFormer is the first neural solver to effectively handle 1,000+ node instances, achieving at least 15% lower objective than state-of-the-art on large-scale problems while maintaining 100% feasibility. It also sets new SOTA on standard VRPs, e.g., a 0.62% gap on 1,000-node CVRP, and scales up to 7,000 nodes with superior performance.

## Method Summary

SEAFormer employs a dual-stream transformer encoder. The Clustered Proximity Attention (CPA) reduces computational complexity from O(n²) to O(n) by transforming node coordinates into a polar system relative to the depot, generating multiple diverse spatial partitions via a score mixing radial and angular proximity, applying boundary smoothing, and performing attention within fixed-size clusters. A lightweight edge-aware module explicitly models pairwise edge attributes (e.g., distance, energy, traffic) through residual fusion over the K nearest neighbors, increasing parameters by only 7.5%. The decoder combines a precomputed static heatmap derived from edge embeddings with a sequential attention mechanism that tracks variant-specific state (battery, time, load, etc.) to navigate sequence-dependent constraints. Training uses the POMO paradigm with multiple optimal rollouts, and the model is progressively trained on increasing problem sizes (100 → 500 → 1,000 nodes).

## Key Results

- First neural method to solve 1,000+ node RWVRP instances.
- On large-scale RWVRPs, achieves ≥15% lower objective than prior SOTA with 100% feasibility.
- Sets state-of-the-art on standard VRPs (e.g., 0.62% gap on 1,000-node CVRP).
- Scales to 7,000 nodes with superior performance.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** CPA reduces computational complexity from O(n²) to O(n) while preserving spatial routing structure necessary for high-quality solutions.
- **Mechanism:** Transforms node coordinates to polar representation relative to depot; computes a partitioning score mixing radial and angular proximity with coefficient α; generates R diverse partitions (α varies from 0 to 1); applies boundary smoothing to keep nearby nodes together; computes attention only within each fixed-size cluster.
- **Core assumption:** Optimal VRP routes exhibit spatial patterns (similar angles, similar distances, or both) that can be captured through polar-based clustering, and multiple clustering perspectives prevent getting stuck in local optima.
- **Evidence anchors:**
  - [abstract] "Clustered Proximity Attention (CPA) exploits locality-aware clustering to reduce the complexity of attention from O(n²) to O(n) while preserving global perspective"
  - [section 3] Full technical description of polar transformation (Equation 1), partitioning score (Equation 2), deterministic-yet-diverse partitioning (Equation 3), boundary smoothing (Equation 4), and localized attention (Equation 5)
  - [corpus] "Distance-aware Attention Reshaping" paper (FMR 0.609) shows neighborhood attention approaches exist, but CPA's problem-specific polar clustering is unique to routing
- **Break condition:** If optimal routes for real-world VRPs do not follow spatial clustering patterns or require global pairwise attention across all nodes that cannot be approximated by local clusters.

### Mechanism 2
- **Claim:** The lightweight edge-aware module enables handling of sequence-dependent constraints by explicitly modeling pairwise edge attributes.
- **Mechanism:** For each node pair (within K nearest neighbors), combines edge features (distance, energy, traffic) with node embeddings via residual fusion: H_e = X_e + σ(BN(W₁H_i + W₂H_j + W₃X_e)), using SILU activation and batch normalization.
- **Core assumption:** Edge-specific attributes (asymmetric costs, energy consumption rates) are essential for RWVRP feasibility and optimality, and cannot be adequately represented through node-level embeddings alone.
- **Evidence anchors:**
  - [abstract] "lightweight edge-aware module captures pairwise features through residual fusion, enabling effective incorporation of edge-based information"
  - [section 4] Equation 7 showing residual fusion architecture that increases parameters by only 7.5% while capturing relational patterns
  - [corpus] "EFormer: An Effective Edge-based Transformer" (FMR 0.469) validates the importance of edge-based representations in VRP solving
- **Break condition:** If edge-level constraints prove less critical than node-level features across RWVRP variants, or if the computational overhead of maintaining edge embeddings outweighs benefits.

### Mechanism 3
- **Claim:** Dual-path decoder combines global edge preferences with sequential state tracking to navigate sequence-dependent constraints effectively.
- **Mechanism:** Before decoding, generates static heatmap MLPₑ(H_e) ∈ ℝ from edge embeddings; during autoregressive decoding, maintains variant-specific state (battery, time, range) in query vector q_t = [h_t; c_t; ξ_t]; combines sequential attention logits with heatmap row via ℓ_t = ℓ_seq_t + H_{i_t,:}; applies proactive masking to ensure feasibility.
- **Core assumption:** Separating global edge guidance (heatmap) from sequential decision-making (attention with state) allows both scalability and accurate constraint handling that pure autoregressive or non-autoregressive methods cannot achieve.
- **Evidence anchors:**
  - [abstract] "dual-path decoder combines edge-aware guidance (heatmap) with sequential node selection (attention)"
  - [section 4] Equation 10 showing logit fusion, and Equation 9 showing variant-specific state representation in query
  - [corpus] Non-autoregressive methods (e.g., GLOP) use heatmaps but fail on sequence-dependent constraints; SEAFormer's state-aware sequential component addresses this limitation
- **Break condition:** If either global edge guidance or sequential state tracking alone suffices for RWVRPs, or if the fusion strategy creates conflicting signals that degrade performance.

## Architecture Onboarding

### Component Map
Inputs → Encoder-Node (CPA, L=6) → Encoder-Edge (EAM, K=50) → Heatmap Generation (MLP) → Decoder (stateful sequential + heatmap fusion) → Output (node sequence)

### Critical Path
1. Preprocessing: Convert Cartesian → polar coordinates relative to depot; compute distance matrix for nearest neighbors.
2. CPA encoding: For each of R rounds (default R=4), compute partitioning score with α = t/(R-1), sort nodes, apply circular shift for smoothing, partition into clusters of size M (M=50 default), compute attention within each cluster → aggregate to get spatially-aware node embeddings.
3. Edge encoding: For each node, find K nearest neighbors (excluding self), compute residual fusion (Equation 7) for each edge.
4. Heatmap generation: Apply tanh(MLPθ(·)) to all edge embeddings to get static preference matrix.
5. Decoding loop: Start at depot; for t=1 to n: compute sequential attention logits over Ut (unvisited, feasible nodes); add heatmap row for current node; sample next node (greedy or SGBS); update vehicle state (load, battery/time, etc.); apply masking for next step.

### Design Tradeoffs
- Cluster size (M): Larger M → fewer clusters → less overhead but weaker locality; smaller M → stronger locality but more boundary effects. Default M=50 balances.
- Partitioning rounds (R): More rounds → more diverse spatial perspectives → better coverage but memory grows linearly (O(RnM)). Default R=4.
- Edge K-nearest: Larger K captures more edge information but increases memory quadratically. Diminishing returns beyond K=50.
- Smoothing: Without smoothing, hard cluster boundaries separate nearby nodes; with smoothing, transition zones keep neighborhoods intact but add a step. Always use smoothing.
- Heatmap fusion weight: Currently additive; could be learned but simple addition proved stable.

### Failure Signatures
- Memory overflow: During training, if batch size × POMO size × (n/M)² exceeds GPU memory; reduce batch/POMO or increase M.
- Poor convergence on RWVRPs: If solutions are infeasible, check proactive masking logic; edge module may be underpowered (increase K or embedding dimension).
- Degradation on asymmetric problems (A VRP): If gap >3% vs. baselines, edge module likely insufficient; increase K or edge embedding dimension.
- Overfitting to single clustering pattern: If performance sensitive to random seed, increase R to enforce diverse spatial views.
- SGBS not improving over greedy: Heatmap may be noisy; ensure edge module properly trained, or increase beam width.

### First 3 Experiments
1. **Baseline sanity check:** Train SEAFormer on 20-node CVRP for 100 epochs; should reach <0.5% gap in <1 minute. Compare with POMO baseline to verify implementation correctness.
2. **CPA scalability test:** Train on 500-node CVRP with CPA; memory should be ~5-10GB (batch=32, POMO=100). Attempt same with standard O(n²) attention → expect OOM.
3. **Component ablation on VRPTW-100:** Remove edge module → expect gap increase by >5%; remove CPA → expect OOM or severe degradation. Verify both components contribute uniquely.

## Open Questions the Paper Calls Out

### Question 1
- **Question:** Can a unified neural model trained via multi-task learning effectively solve multiple RWVRP variants without performance degradation compared to variant-specific models?
- **Basis in paper:** The conclusion states: "future work may explore multi-task learning across RWVRPs to develop a unified model trained once."
- **Why unresolved:** Current training requires separate models per variant, which is computationally expensive and does not leverage shared structure; it is unclear whether a single model can handle diverse constraints equally well.
- **What evidence would resolve it:** Train a single model on a mixture of RWVRP instances, evaluate its performance on each variant relative to SEAFormer, and analyze transfer effects; measure any negative transfer or interference.

### Question 2
- **Question:** How can Clustered Proximity Attention (CPA) be adapted for multi-depot VRP (MDVRP) while preserving its O(n) complexity and spatial clustering benefits?
- **Basis in paper:** The conclusion suggests "extensions to the MDVRP setting"; Appendix N discusses potential adaptations such as using multiple depots as reference points.
- **Why unresolved:** CPA assumes a single central depot for polar clustering; MDVRP introduces multiple depots requiring new partitioning strategies that maintain efficiency and solution quality.
- **What evidence would resolve it:** Design CPA variants for MDVRP (e.g., depot-specific clustering, unified coordinate system), implement them, and benchmark on MDVRP datasets against state-of-the-art methods.

### Question 3
- **Question:** What search strategies beyond greedy decoding and SGBS can effectively utilize the edge-aware heatmap to further improve solution quality on large-scale RWVRPs?
- **Basis in paper:** The conclusion mentions "heatmap-guided search strategies beyond greedy decoding."
- **Why unresolved:** SEAFormer currently only combines heatmap with greedy or SGBS; the potential of advanced search methods (e.g., MCTS, evolutionary algorithms) to exploit the heatmap remains unexplored.
- **What evidence would resolve it:** Integrate the heatmap into alternative search frameworks (e.g., use it as a heuristic in MCTS or as a prior in population-based search) and compare performance on large RWVRP benchmarks.

## Limitations

- Several hyperparameters and implementation details remain unspecified (e.g., cluster size M selection per problem scale, neighbor selection criterion for asymmetric A-VRP, handling of edge embeddings for non-neighbor pairs, aggregation strategy for multiple CPA partitions, VRPTW time-window generation specifics, optional node fusion mechanism, proactive masking inconsistency between equation and text, POMO training specifics).
- Some described mechanisms lack full empirical validation in the paper (e.g., exact contribution of edge module on different variants, sensitivity to heatmap fusion weight, potential signal conflict between global and sequential paths).

## Confidence

- CPA: **Medium** – algorithm described but hyperparameters (M, R) and aggregation unclear.
- Edge-aware module: **Medium** – residual fusion defined but neighbor selection and optional node handling uncertain.
- Decoder: **Medium** – fusion idea plausible but lacks ablation on weighting and possible signal conflict.
