# Borderless Long Speech Synthesis

## Quick Facts
- **arXiv ID:** 2603.19798
- **Source URL:** https://arxiv.org/abs/2603.19798
- **Reference count:** 4
- **Primary result:** Any2Speech framework improves global coherence and acoustic scene modeling for long-form speech synthesis via hierarchical annotation and Chain-of-Thought reasoning.

## Executive Summary
Existing text-to-speech (TTS) systems struggle to capture global context such as emotional arcs, multi-speaker interactions, and acoustic scenes because they typically synthesize sentence-by-sentence or rely on plain text dialogues. This paper introduces Any2Speech, a framework that moves beyond these limitations. Its core innovations include a "Labeling over filtering/cleaning" data strategy that retains expressive, real-world "dirty" audio (achieving >90% data utilization), a top-down Global-Sentence-Token annotation schema to model complex scenes, Chain-of-Thought reasoning for explicit prosody planning, Dimension Dropout for robust instruction following, and a Native Agentic architecture where the annotation schema serves as a Structured Semantic Interface. Together, these components create a wide-band control channel, enabling an LLM agent to convert any input modality into structured generation commands. The system demonstrates improved global coherence and acoustic scene modeling compared to prior approaches, though standard automated metrics are inadequate for such long-form, multi-dimensional synthesis, leaving quantitative benchmarking for future work.

## Method Summary
Any2Speech builds upon the VibeVoice-7B continuous-tokenizer backbone, which natively supports long audio generation. The training pipeline adopts a "Labeling over filtering/cleaning" strategy: instead of discarding overlapping speech, interruptions, and background noise, every audio sample is annotated at three hierarchical levels using free-form natural language captions: Global (scene metadata, emotional arcs, acoustic environment), Sentence (per-utterance tone, intent, background state), and Token (phoneme-level details). During inference, the model follows a two-stage Chain-of-Thought process: it first generates an explicit "Think" prosody plan (sentence-level and token-level details) based on the "Instruct" constraints (user-supplied speaker identity, scene format) and the input text, then synthesizes the audio tokens. Dimension Dropout randomly masks Think dimensions during training to improve robustness to incomplete instructions. The Global-Sentence-Token schema doubles as a Structured Semantic Interface: an upstream LLM agent converts arbitrary inputs (text, video, etc.) into commands conforming to this schema, which the synthesis engine executes. This architecture enables borderless long speech synthesis with rich global context.

## Key Results
- "Labeling over filtering/cleaning" data strategy preserves >90% of expressive, real-world audio data by annotating instead of discarding complex samples.
- Chain-of-Thought reasoning and Dimension Dropout markedly improve instruction following under complex, multi-dimensional conditions.
- The system demonstrates superior global coherence and acoustic scene modeling compared to prior TTS systems, though standard automated metrics are insufficient for evaluation.

## Why This Works (Mechanism)

**Mechanism 1: Labeling over Filtering + Hierarchical Annotation**  
The authors reverse the common practice of data cleaning; they label every audio sample, including those with overlaps, background noise, and multi-speaker interactions, creating a three-level annotation: Global (scene, emotional arc, acoustic environment), Sentence (per-utterance tone, intent, background state), and Token (phonetic details). By learning to map these free-form natural language captions directly to audio tokens, the model treats "noise" as controllable dimensions. This preserves the full expressive distribution (>90% data utilization) and enables precise control over complex scenes.  
*Break condition:* Inconsistent or incomplete annotations lead to unreliable mappings, harming controllability and quality for complex scenes.

**Mechanism 2: Chain-of-Thought Prosody Planning**  
The Global-Sentence-Token annotations are partitioned into Instruct (user constraints) and Think (model's prosody plan). At inference, the model first enters a planning phase, generating a sentence-by-sentence Think plan (emotion, intonation, pacing) based on the Instruct and input text. Only then does it synthesize audio. This explicit, inspectable reasoning step decouples prosody decisions from audio generation, reducing local variations and enhancing cross-sentence coherence.  
*Break condition:* An inaccurate or inconsistent Think plan (due to ambiguous Instruct or insufficient training) causes jarring emotional jumps or poor pacing.

**Mechanism 3: Native Agentic Architecture via Structured Semantic Interface**  
The three-layer annotation schema forms a layered control protocol stack (Global: session layer, Sentence: transport layer, Token: physical layer). An LLM agent processes any input modality and outputs commands in this schema, which the synthesis engine executes faithfully. This design creates a wide-band control channel that preserves semantic richness, unlike narrow-band text-only TTS interfaces, enabling the system to accept diverse inputs (e.g., video) and generate borderless long-form speech.  
*Break condition:* If the LLM agent cannot reliably map non-text inputs into the schema, or the engine cannot interpret the full command space, the system collapses to inferior sentence-level synthesis.

## Architecture Onboarding

**Component map:** Data Pipeline (Labeling over filtering → Global-Sentence-Token annotation) → Model Backbone (VibeVoice-7B + CoT module + Dimension Dropout) → Agent Interface (LLM Agent ↔ Structured Semantic Interface) → Synthesis Engine → Evaluation (listening tests, inadequate automated metrics)

**Critical path:**  
1. Collect/annotate data with Global-Sentence-Token schema, preserving expressive "dirty" samples.  
2. Train VibeVoice-7B on annotated data with CoT and Dimension Dropout modifications.  
3. At inference, upstream LLM processes user input → outputs Global-Sentence-Token commands → synthesis engine generates long audio with explicit prosody planning.

**Design tradeoffs:**  
- *Data purity vs. expressiveness:* Discarding "dirty" data simplifies training but loses richness; labeling preserves complexity but requires more annotation and model capacity.  
- *Latency vs. coherence:* CoT adds a planning step, increasing inference time—acceptable for content creation but problematic for real-time interaction.  
- *Schema rigidity vs. flexibility:* Free-form natural-language captions allow nuance but may introduce variability; the fixed layer structure provides necessary organization.

**Failure signatures:**  
- *Incoherent emotional arcs:* Abrupt emotion jumps across sentences indicate Think planning or cross-sentence reasoning failure.  
- *Poor instruction following:* Model ignores specific cues (stress, intent) suggests inadequate Dimension Dropout training or schema misalignment.  
- *Scene modeling collapse:* Missing background sounds points to Global layer representation issues or lack of diverse "dirty" data exposure.  
- *Agent interface breakdown:* LLM-generated commands non-conforming to schema cause default generic outputs.

**First 3 experiments:**  
1. *CoT ablation:* Train a baseline without CoT on same data. Compare global coherence via human evaluation on multi-sentence emotional arc tasks.  
2. *Dimension Dropout robustness:* Provide partial Instruct commands (e.g., only Global) and measure fidelity to missing dimensions inspected in Think.  
3. *Agent modality extension:* Use LLM to convert a short video clip into Global-Sentence-Token commands, then synthesize. Evaluate scene/emotion alignment against text-only baseline.

## Open Questions the Paper Calls Out
The paper explicitly acknowledges that quantitative benchmarking for long-form, multi-dimensional speech synthesis remains future work, as standard automated metrics (e.g., CLAP, DNSMOS) are inadequate. No other open questions are listed.

## Limitations
- Incomplete specification of the Global-Sentence-Token annotation schema (syntax, grammar, tag set) hinders reproducibility.
- Missing training details: exact model modifications for CoT, hyperparameters, dataset composition, and preprocessing pipeline.
- No quantitative benchmarks; evaluation relies solely on subjective listening tests.
