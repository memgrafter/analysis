# XMACNet: An Explainable Lightweight Attention based CNN with Multi Modal Fusion for Chili Disease Classification

## Quick Facts
- **arXiv ID:** 2603.06750
- **Source URL:** https://arxiv.org/abs/2603.06750
- **Reference count:** 33
- **Primary result:** XMACNet achieves 99.2% accuracy, 95.8% F1-score, and 98.3% AUC on a 12,000-image chili disease dataset, with 7M parameters and 28ms inference time.

## Executive Summary
XMACNet is a multi-modal CNN for chili leaf disease classification that fuses RGB imagery with computed vegetation indices (NDVI, NPCI, MCARI) using an EfficientNetV2-S backbone and a self-attention module. The model is lightweight (7M parameters) and designed for edge deployment in precision agriculture. It incorporates explainability via Grad-CAM++ and SHAP to visualize decision rationale. Trained on a dataset of 12,000 real images augmented with 6,000 synthetic images from StyleGAN2, XMACNet outperforms baselines like ResNet-50 and Swin Transformer. The approach demonstrates high accuracy and interpretability, addressing both performance and trustworthiness in agricultural AI.

## Method Summary
The proposed architecture processes two parallel inputs: an RGB image and a three-channel "index image" containing NDVI, NPCI, and MCARI maps computed from the same leaf. The RGB stream uses a pre-trained EfficientNetV2-S backbone to extract features, while the index stream uses a shallow CNN to produce feature maps of matching dimensions. These features are concatenated and refined with a 1×1 convolution. A lightweight self-attention module is applied to the fused representation to capture global context. After global average pooling, a fully connected layer produces class probabilities for six disease categories. Training uses Adam optimizer, cross-entropy loss, and standard augmentations, plus StyleGAN2-generated synthetic images to handle class imbalance.

## Key Results
- 99.2% test accuracy, 95.8% F1-score, 98.3% AUC on a 6-class chili disease dataset.
- Outperforms ResNet-50, MobileNetV2, and Swin Transformer while using only 7M parameters and 28ms inference.
- Explainable visualizations (Grad-CAM++, SHAP) highlight disease-relevant regions, supporting trustworthy deployment.

## Why This Works (Mechanism)
### Fusion of RGB and Vegetation Indices
The model integrates standard RGB visual features with biochemical stress signals encoded in NDVI, NPCI, and MCARI. The index branch processes these computed maps, which emphasize chlorophyll degradation and pigment changes often invisible in RGB. Channel-wise concatenation with RGB features forces the network to learn cross-modal relationships, improving discrimination of disease-specific patterns. Evidence: The authors state the indices highlight differences in chlorophyll content, and the architecture explicitly processes both streams.

### Self-Attention for Global Context
After fusion, a lightweight self-attention module computes spatial and channel-wise attention weights over the fused feature map. This allows the model to dynamically focus on relevant regions (e.g., scattered lesions) and suppress background noise, enhancing feature discrimination without significant computational overhead. Evidence: The paper notes the attention introduces minimal overhead but improves performance under complex backgrounds.

### Synthetic Data Augmentation with StyleGAN2
To address dataset scarcity and class imbalance, the authors trained a StyleGAN2-ADA model on the original 12k images to generate 6k additional synthetic samples. These realistic augmentations expand the training distribution, forcing the model to learn invariances to variations in disease appearance and improving generalization. Evidence: The high accuracy compared to baselines trained on the same augmented data suggests effectiveness.

## Architecture Onboarding
**Component map:**  
RGB image -> EfficientNetV2-S backbone -> RGB feature map  
Index image (NDVI, NPCI, MCARI) -> Small CNN branch -> Index feature map  
Fusion: Channel-wise concatenation of RGB and index features -> 1×1 convolution -> Self-attention block -> Global average pooling -> Fully connected layer -> Softmax classifier

**Critical path:** The index branch computation is most error-prone. Incorrect formulas, normalization, or missing NIR data will corrupt the index maps, undermining fusion. Always validate index outputs visually (e.g., healthy leaves should show high NDVI contrast).

**Design tradeoffs:**  
- Accuracy vs. Edge Suitability: The 7M parameter count results from using EfficientNetV2-S and a shallow index branch; removing attention or fusion would reduce size but sacrifice performance.  
- Modality Reliance: The model assumes availability of NIR information to compute meaningful indices. Using standard RGB-only cameras would require alternative index estimation or a different design.

**Failure signatures:**  
1. Symptom-blindness: Grad-CAM++ highlights leaf edges/background instead of lesions → model uses context cues, not symptoms → check index branch output.  
2. Synthetic overfitting: Training accuracy >99.5% but test accuracy drops >5% on real-only images → possible GAN artifacts.  
3. Index corruption: Performance at baseline levels when index branch is zeroed or channels shuffled → fusion provides no signal.

**First 3 experiments:**  
1. Ablate index branch: Replace index input with zeros/random noise. Expect ~4-8% accuracy drop.  
2. Ablate attention: Remove self-attention block. Expect ~1-2% accuracy drop.  
3. Explainability sanity check: Run Grad-CAM++ on 20 correctly classified disease images. Expect >90% of heatmaps to localize to visible lesions.

## Open Questions the Paper Calls Out
1. Can vegetation indices (NDVI, NPCI, MCARI) be effectively learned directly from RGB images without NIR data, while preserving or improving classification performance for chili diseases?
2. Does the use of StyleGAN2-generated synthetic data introduce subtle biases or distribution shifts that harm robustness to real-world field variations, compared to training on real-only data with standard augmentation?
3. How robust are the Grad-CAM++ and SHAP explanations to input perturbations and model instabilities, and do they consistently align with expert agronomic annotations across all six disease classes?
4. Does XMACNet's multi-modal fusion (RGB + vegetation indices) provide consistent benefits across all disease types, or is the performance gain primarily driven by a subset of diseases where spectral indices are most discriminative?

## Limitations
- Vegetation indices require NIR data, but the dataset appears RGB-only; unclear how indices were derived, questioning physiological relevance.
- Self-attention module design details (dimensions, heads) are missing, hindering faithful replication.
- Synthetic data quality is not quantitatively assessed; potential for GAN artifacts or mode collapse.
- Explainability is presented qualitatively without systematic evaluation of faithfulness or alignment with expert masks.
