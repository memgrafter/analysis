# Towards interpretable models for language proficiency assessment: Predicting the CEFR level of Estonian learner texts

## Quick Facts
- arXiv ID: 2602.13102
- Source URL: https://arxiv.org/abs/2602.13102
- Reference count: 24
- Primary result: Feature-selected models achieved ~0.9 accuracy on a contemporary exam test set and ~0.8 balanced accuracy on older exams, with reduced genre bias and open-source deployment.

## Executive Summary
This paper tackles the need for interpretable and generalizable automated assessment of Estonian L2 writing proficiency across CEFR levels A2–C1. The authors analyze a learner corpus to pre-select linguistic features (lexical, morphological, surface, error-based) that reliably predict proficiency and are robust across text genres. After rigorous filtering (monotonic progression, significant between-level differences, low within-level genre variation), classifiers are trained and evaluated on both a contemporary multi-genre test set and an older exam dataset from 7–10 years prior. The best models reach ~0.9 accuracy on the current test set and maintain ~0.8 accuracy on the older set, demonstrating temporal durability. These models have been integrated into an open-source Estonian language learning environment (ELLE).

## Method Summary
The study uses 720 exam writings (2017–2020) split into 600 training and 120 test texts, plus 398 older exams (2010) as a temporal test set. From raw texts, 148 features are extracted using Stanza (tokenization, lemmatization, POS-tagging) and custom tools (lexical diversity, morphological frequencies, surface indices, error counts). A four-criterion filter selects "relevant" features: (1) significant between-level differences (Welch’s ANOVA, p<0.0003), (2) monotonic progression across CEFR levels, (3) Spearman correlation ≥0.2 with proficiency, (4) no significant within-level text-type variation. Multiple classifiers (LR, SVM, RF, etc.) are trained with StandardScaler and univariate feature selection (SelectKBest or sequential). The best pipeline, chosen via 10-fold CV, is tested on the two held-out sets. Models using pre-selected features show lower genre bias than all-feature models and generalize across time.

## Key Results
- Feature-selected models (e.g., Mix-SVM-kbest-23) achieve ~0.9 accuracy on a contemporary test set covering multiple genres (personal letters, narratives, arguments).
- On an older exam set (7–10 years prior), models reach ~0.8 balanced accuracy despite measurable increases in text complexity over time.
- Pre-selection reduces classification variation across text genres while preserving accuracy, enhancing interpretability and generalizability.
- The most effective models are implemented in the open-source ELLE Writing Evaluator.

## Why This Works (Mechanism)
### Mechanism 1: Feature selection reduces task-dependent noise
Strict criteria (between-level significance, monotonicity, genre invariance) remove predictors tied to specific writing prompts (e.g., personal letter vs. argument). This filters out noise that would cause genre bias, ensuring models capture stable proficiency signals. Evidence: LexRel models showed smaller classification variation across text types than LexAll models on test set 1; within-level ANOVA guided exclusion of genre-sensitive features.

### Mechanism 2: Monotonic progression aligns with cumulative proficiency
Features that consistently increase or decrease from A2→C1 (e.g., lexical diversity, case usage) reflect the expected unidirectional development of language competence. Non-monotonic features are discarded unless they have no genre variation and differ significantly from all other levels. Evidence: ~1/3 of features showed monotonic trends and performed best; exceptions like adverb TTR were retained only under strict conditions.

### Mechanism 3: Temporal validation ensures durable signals
Testing on older exams (2010) separated from training (2017–2020) verifies that models capture core proficiency markers stable over time, not ephemeral exam trends. Despite newer texts being more complex, models maintained ~0.8 accuracy, indicating robustness. Evidence: LexRel models outperformed LexAll on test set 2 for B1 recall; surface models achieved 0.843 balanced accuracy.

## Foundational Learning
- **CEFR descriptor alignment**: Knowing what CEFR levels measure (lexical range, grammatical accuracy, text length) is essential to judge feature relevance. Quick check: Which should increase monotonically: noun case diversity, sentence length, or spelling error rate? Answer: noun case diversity and sentence length; spelling error rate should decrease.
- **Feature engineering for morphologically rich languages**: Estonian’s 14 cases and rich inflection require lemmatization and morphological analysis; surface forms inflate type counts and obscure development. Quick check: Why might lemma-based TTR be more valid than word-form TTR for lexical diversity in Estonian L2? Because inflections increase word-form types without reflecting true vocabulary growth.
- **Supervised classification validation**: Proper evaluation (holdout sets, cross-validation, balanced accuracy) underpins claims of generalizability. Quick check: What does a drop in C1 recall from 0.93 (contemporary test) to 0.67 (older test) imply? The model may be overfitted to contemporary C1 characteristics; temporal drift exists.

## Architecture Onboarding
- **Component map**: Raw texts -> Stanza preprocessing -> Feature extraction (lexical, morphological, surface, error) -> Feature selection filter -> Training pipeline (StandardScaler -> feature selection -> classifier) -> Evaluation -> Deployment in ELLE.
- **Critical path**: 
  1. Preprocess corpus with Stanza.
  2. Compute all 148 features.
  3. Apply statistical tests (Welch’s ANOVA, Spearman) to identify relevant features per category.
  4. For each feature category, train pipelines with relevant vs. all features; select top 5 by CV accuracy.
  5. Validate top models on test set 1 (genre diversity) and test set 2 (temporal shift).
  6. If generalizability inadequate, revise feature criteria.
  7. Combine best categories into mixed model; repeat validation.
  8. Conduct permutation importance to prune redundant features.
  9. Integrate best model into ELLE.
- **Design tradeoffs**:
  - Interpretability vs. accuracy: Relevant features sacrifice slight accuracy for robustness and explainability.
  - Feature redundancy: Highly correlated diversity metrics (RTTR, CVV) may inflate importance; pruning simplifies.
  - Tool dependency: Error features rely on external tools with ~70% precision; noisy.
  - Genre coverage: Training limited to exam genres; real-world texts may need recalibration.
- **Failure signatures**:
  - Genre bias: Recall disparity >0.2 between text types at same level in test set 1 indicates task-dependent leakage.
  - Temporal decay: Accuracy drop >0.1 on test set 2, especially for C1, suggests shifted proficiency markers.
  - Non-monotonic traps: Features that dip then rise (e.g., rare-word % at B1) cause misclassifications if not filtered.
  - Error tool mismatch: Different error distributions in production degrade error feature reliability.
- **First 3 experiments**:
  1. Train `MorphAll-RF-kbest-41` on only B2 narratives; evaluate on held-out B2 personal vs. semi-formal letters. Expect recall variance >0.2, confirming task dependence.
  2. Compare distributions of top 10 features (e.g., lemma count, plural nominal %) between 2010 test set and 2017–2020 train; compute Cohen’s d to quantify shift.
  3. Remove `RTTR` from `Mix-SVM-kbest-23`; retrain and test on both test sets. Accuracy change <0.02 indicates redundancy.

## Open Questions the Paper Calls Out
1. **Generalization to non-exam texts**: Can exam-trained models assess authentic learner writing (e.g., forums, journals) with similar accuracy? The paper notes this requires separate testing.
2. **Binary vs. multiclass classification**: Would pairwise (adjacent level) classifiers improve discrimination of intermediate levels (B1/B2) which had lower F1-scores in multiclass?
3. **Syntactic and discourse features**: Do deeper linguistic features (parsing, cohesion) add predictive value beyond the current set? The paper suggests experiments with such features.
4. **Temporal complexity increase**: Why did learner texts become more complex over 7–10 years? Understanding this could help adapt models to prevent temporal drift.

## Limitations
- Exact train/test splits undisclosed; reconstruction may introduce variance.
- Grammar corrector code (Luhtaru et al., 2024) unavailable, hindering exact error feature computation.
- Classifier hyperparameters unspecified; defaults may not match paper’s optimal pipeline.
- Syllable counting method undefined; SMOG index questionable for short texts.
- Corpus limited to exam genres; real-world learner texts may require recalibration.
- Assumes CEFR scale stability across years without external validation.

## Confidence
- Feature selection reduces genre bias: **Medium** (supported by within-level ANOVA and LexRel vs. LexAll comparison, but replication blocked by missing data).
- Temporal robustness (7–10 year shift): **Medium‑Low** (~0.8 accuracy suggests durability, but C1 recall drop from 0.93 to 0.67 indicates possible drift).
- Interpretability via permutation importance: **Medium** (method sound, but without exact code transparency is partial).

## Next Checks
