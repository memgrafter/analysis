# Achieving Optimal Static and Dynamic Regret Simultaneously in Bandits with Deterministic Losses

## Quick Facts
- **arXiv ID:** 2602.07418
- **Source URL:** https://arxiv.org/abs/2602.07418
- **Reference count:** 40
- **Primary result:** For oblivious adversaries with deterministic losses and a known number of switches *S*, DynASORe achieves simultaneous `eO(√(AT))` static regret and `eO(√(SAT))` dynamic regret with high probability, separating the adaptive and oblivious settings.

## Executive Summary
This paper addresses a fundamental gap in multi-armed bandits: achieving optimal static and dynamic regret simultaneously against an oblivious adversary. While individual optimal algorithms exist for each benchmark, prior work showed impossibility under adaptive adversaries. Here, the authors demonstrate that for deterministic losses and a known number of switches *S*, the situation differs sharply. They first extend an impossibility result to deterministic losses, then introduce DynASORe, an algorithm that uses Blackwell approachability to dynamically hedge between a conservative strategy minimizing static regret and an exploratory strategy detecting changes while harvesting negative static regret. With gap-dependent exploration and second-order mirror descent, DynASORe attains the desired guarantees, establishing a clear separation between adaptive and oblivious adversaries in multi-objective bandits.

## Method Summary
The core of DynASORe is a meta-algorithm that, at each epoch, selects between two sub-strategies: a conservative `×` (based on an EXP3-IX-style estimator) and an exploratory `◦` (using gap-dependent exploration via `ExpEst` to detect switches). The selection is governed by a weight vector `θ` updated each epoch via mirror descent with a hybrid regularizer. For the `×` strategy, losses are estimated using an exponential-weight update with implicit exploration; for `◦`, the algorithm actively probes arms to estimate cumulative gaps and identify change points. The constructed regret vectors `ˆℓ_{k,×}` and `ˆℓ_{k,∘}` combine the observed performance with a bias toward dynamic regret control. The meta-update minimizes a Bregman divergence subject to constraints, ensuring feasibility. A warm-up version (Algorithm 1) for *A*=2 simplifies the `×` strategy to always pulling arm 1 and uses explicit exploration in `◦` with a fixed sub-optimal arm. The full algorithm (Algorithm 2) scales to general *A* but requires careful handling of the EXP3-IX estimator and the constrained mirror descent projection.

## Key Results
- Impossibility extends to deterministic losses under adaptive adversaries: no algorithm can simultaneously achieve optimal static and dynamic regret.
- DynASORe guarantees `SReg = eO(√(AT) log(T/δ))` and `DReg = eO(√(SAT) log(T/δ))` with high probability against oblivious adversaries when *S* is known.
- The result establishes a separation between adaptive and oblivious settings for multi-objective bandits and introduces techniques for model selection across benchmarks with different switching numbers.

## Why This Works (Mechanism)
DynASORe succeeds by hedging via Blackwell approachability: the meta-weights `θ` balance the two sub-strategies over epochs. The `×` strategy ensures low static regret by remaining conservative, while `◦` uses gap-dependent exploration (`ρ ≈ √(SA/T)`) to detect switches early and accumulate negative static regret (exploiting the deterministic loss structure). The second-order mirror descent update with a hybrid regularizer (negative entropy plus additional terms) controls both static and dynamic regret by carefully biasing the vector `ˆv_k` toward the dynamic benchmark. The constraint `1-θ_{A+1} ≥ Aγ` forces enough probability mass on exploratory actions to guarantee switch detection. The deterministic nature of losses allows `ExpEst` to pinpoint switches immediately upon observing a loss change, making the dynamic regret control efficient.

- **EXP3-IX estimator:** An importance-weighted estimator with implicit exploration for adversarial bandits. *Why needed:* Provides low static regret in the `×` strategy. *Quick check:* Test EXP3-IX on a static loss environment; regret should scale as `O(√(AT))`.
- **Gap-dependent exploration:** Exploration probability scaled by inverse estimated gap `Δ`. *Why needed:* Minimizes exploration cost while ensuring switch detection. *Quick check:* In a two-arm setting with gap `Δ`, verify sampling probability roughly `ρ/Δ`.
- **Mirror descent with Bregman divergence:** An optimization method using a regularizer `ψ`; here a hybrid regularizer combines entropy and quadratic terms. *Why needed:* Enables the constrained update that controls both regrets. *Quick check:* Solve a simple mirror descent update with negative entropy regularizer over the simplex.
- **Switch detection in deterministic losses:** Because losses are fixed, observing a change in a pulled arm’s loss reveals a switch immediately. *Why needed:* Allows `ExpEst` to estimate cumulative gaps without delay. *Quick check:* Simulate a deterministic loss sequence with one switch; after pulling an arm whose loss flips, detection should be instantaneous.

## Architecture Onboarding
**Component map:**  
Environment (deterministic losses, *S* switches) -> Losses per round -> DynASORe (meta-weights `θ` -> strategy sampler -> sub-strategy execution (`×` or `◦`) -> loss observation -> estimator (`EXP3-IX` or `ExpEst`) -> regret vector construction `ˆℓ` -> mirror descent update with hybrid `ψ` and constraint -> new `θ`).  
**Critical path:** Per epoch: sample strategy `i_k` from `θ_k`; execute strategy to gather losses; compute `ˆℓ_{k,×}` and `ˆℓ_{k,∘}`; form `ˆv_k`; update `θ` via constrained mirror descent.  
**Design tradeoffs:**  
- `×` minimizes static regret but ignores switches; `◦` explores to detect switches but incurs exploration loss.  
- Gap-dependent exploration `ρ` trades off detection speed vs. exploration cost; too large harms static regret, too small slows dynamic regret.  
- Hybrid regularizer `ψ` balances entropy (for simplex constraints) and second-order terms (for tighter dynamic regret control); overly aggressive second-order terms may break convexity.  
**Failure signatures:**  
- Static regret >> `√(AT)`: likely misimplementation of `×` (e.g., incorrect EXP3-IX estimator) or meta-update not reinforcing `×` sufficiently.  
- Dynamic regret >> `√(SAT)`: `◦` exploration too infrequent (`ρ` too small) or `ExpEst` failing to detect switches (e.g., incorrect gap estimation).  
- Infeasible `θ` (negative components, `Σθ≠1`, or `1-θ_{A+1} < Aγ`): mirror descent projection incorrect; using Euclidean projection instead of Bregman projection violates analysis.  
**Three first experiments:**  
1. Replicate the warm-up (Algorithm 1) for *A*=2 with deterministic losses and *S* switches; verify average static regret `O(√T)` and dynamic regret `O(T^{3/4})`.  
2. Implement the `×` strategy using Neu’s EXP3-IX estimator (`ˆℓ_t(a) = 1_{a_t=a} c_t(a)/(q_t(a)+γ) + γ ˆc_{t-1}(a)`) on a no-switch environment; confirm `O(√(AT))` static regret.  
3. Test `◦` alone on a deterministic switching environment with *S* known; check that `ExpEst` correctly identifies all switch times and dynamic regret scales as `O(√(SAT))`.

## Limitations
- The EXP3-IX estimator for the `×` strategy is not fully defined (missing `ˆc_t(a)` recursion); the implementation must infer from Neu [2015].
- The mirror descent update (Equation 21) requires solving a constrained Bregman projection; no closed form is given, and approximate projections may break guarantees.
- Handling of non-integer epoch lengths at the horizon end is unspecified; naive clipping could affect scaling.
