# Linear Regression with Unknown Truncation Beyond Gaussian Features
## Quick Facts
- **arXiv ID:** 2602.12534  
- **Source URL:** https://arxiv.org/abs/2602.12534  
- **Reference count:** 40  
- **Primary result:** First polynomial‑time algorithm for truncated linear regression with an unknown survival set (a union of ≤ k intervals) under sub‑Gaussian features, achieving ε‑accurate recovery of the regressor \( w^* \).

## Executive Summary
The paper studies truncated linear regression where each sample \((x, y)\) is observed only if the response \(y\) lies in an unknown set \(S^*\) (a union of at most \(k\) intervals). This setting invalidates ordinary least squares and prior work either assumed \(S^*\) known or required Gaussian features and incurred super‑polynomial runtimes. The authors present the first algorithm whose runtime is polynomial in the dimension \(d\), the number of intervals \(k\), and the inverse accuracy \(1/\varepsilon\), assuming only sub‑Gaussian feature distributions. The two‑phase approach first learns \(S^*\) via a novel efficient positive‑only learning algorithm that exploits smoothness between the observed response distribution and an auxiliary distribution; second, it runs projected stochastic gradient descent on a perturbed negative log‑likelihood objective, using a warm‑start and a projection set derived from the set estimate. Under mild assumptions—bounded survival probability, sub‑Gaussian features, and identifiability—the method returns an estimate \(\hat{w}\) with \(\|\hat{w} - w^*\| \le \varepsilon\) with high probability, and both sample complexity and total runtime are polynomial in all parameters.

## Method Summary
The algorithm (Algorithm 1) proceeds in three stages. (1) **Warm‑start**: Draw \(\operatorname{poly}(d)\) truncated samples and compute an ordinary least squares estimate \(\hat{w}\); sub‑Gaussian concentration guarantees \(\|\hat{w} - w^*\| = O(1)\) with high probability. (2) **Set learning**: Using \(\hat{w}\), construct an auxiliary distribution \(D_y(\hat{w})\) that is smooth with respect to the true positive response distribution \(D_y(w^*)\). Apply a positive‑only PAC learner for unions of ≤ k intervals (Algorithm 3) to obtain an estimate \(S\) of the survival set. (3) **Parameter estimation**: Define a projection set \(P = B(\hat{w}, \Theta(1))\) (ensuring \(w^* \in P\) with high probability). Run projected stochastic gradient descent on the perturbed negative log‑likelihood \(\mathcal{L}_S\), using a gradient sampler (Algorithm 4) that provides unbiased estimates up to tolerance \(\zeta = O(\sqrt{\varepsilon})\). The final output is the average of multiple independent PSGD runs (Algorithm 5). The overall sample complexity and runtime are polynomial in \(d\), \(k\), \(1/\varepsilon\), and \(\log(1/\delta)\), and the algorithm achieves \(\|\hat{w} - w^*\| \le \varepsilon\) with probability \(1-\delta\) under the stated assumptions.

## Key Results
- First polynomial‑time algorithm for truncated linear regression with unknown survival set under sub‑Gaussian features; runtime \(\operatorname{poly}(d, k, 1/\varepsilon)\).
- Guarantees \(\|\hat{w} - w^*\| \le \varepsilon\) with high probability assuming bounded survival probability, sub‑Gaussian features, and identifiability.
- Improves the prior Gaussian‑specific runtime from \(d^{\operatorname{poly}(k/\varepsilon)}\) to \(\operatorname{poly}(dk/\varepsilon)\).
- Introduces a novel positive‑only PAC learner for unions of intervals under a smoothness condition, of independent interest.

## Why This Works (Mechanism)
### Mechanism 1: Efficient set learning from positives under smoothness
The algorithm learns the unknown survival set \(S^*\) from only positive samples by exploiting smoothness between the true positive response distribution \(D_y(w^*)\) and an auxiliary distribution \(D\) (taken as \(D_y(\hat{w})\)). Algorithm 3 sorts the positive samples, considers the \(n-1\) gaps between consecutive positives, counts auxiliary samples in each gap, discards the \(r = \lceil (k-1)/\varepsilon \rceil\) gaps with the most auxiliary points, and returns the union of the remaining intervals. This greedy procedure runs in \(O(n \log n)\) time. The core assumption is that \(D\) is \((s,q)\)-smooth w.r.t. \(D_y(w^*)\); this holds for any \(w\) with \(\|w - w^*\| \le O(1)\) (Lemma 3.4). If no such smooth auxiliary exists or if \(k\) is too large relative to \(\varepsilon\), the sample complexity becomes exponential as in prior work [KTZ19]. If \(S^*\) contains more than \(k\) intervals, the guarantee fails.

### Mechanism 2: Strong convexity enables efficient PSGD
The perturbed negative log‑likelihood \(\mathcal{L}_S(w)\) is defined over the projection set \(P\). Under the assumptions and for a set estimate \(S\) satisfying \(\mathbb{E}_{D_{\text{obs}}}[p_{S^* \triangle S}(x)] \le \varepsilon\), Lemma D.6 shows that the Hessian of \(\mathcal{L}_S\) is lower bounded by a constant \(\Omega(1)\) on \(P\). Combined with a warm‑start guarantee that \(w^* \in P\) (Corollary D.9), \(\mathcal{L}_S\) is strongly convex on \(P\). Consequently, projected stochastic gradient descent (Algorithm 5) with step size \(\eta_t = 1/(\kappa t)\) converges to \(w_{\min} = \arg\min_{w \in P} \mathcal{L}_S(w)\), and the error \(\|w_{\min} - w^*\|\) is controlled by \(\varepsilon\) (Lemma D.11). If \(\varepsilon\) is too large, the strong convexity constant may vanish, causing PSGD to fail.

### Mechanism 3: Warm‑start ties the components together
A constant‑error warm‑start \(\hat{w}\) (obtained by OLS on truncated data) serves two crucial purposes. First, it defines the projection set \(P = B(\hat{w}, \Theta(1))\); Lemma D.8 ensures \(\|\hat{w} - w^*\| \le O(1)\) with \(\operatorname{poly}(d)\) samples, so \(w^* \in P\) with high probability. Second, the auxiliary distribution for set learning is taken as \(D_y(\hat{w})\). Lemma 3.4 proves that for any \(w\) within constant distance of \(w^*\), \(D_y(w)\) is \((s,q)\)-smooth w.r.t. \(D_y(w^*)\) with \(q = O(\|w - w^*\|^2) = O(1)\). Hence the warm‑start provides a suitable smooth auxiliary, enabling the efficient set learner. If features are not sub‑Gaussian, OLS may not concentrate, leading to a large \(\|\hat{w} - w^*\|\); then \(P\) may exclude \(w^*\) and the smoothness parameter \(q\) becomes large, breaking the polynomial sample guarantee of the set learner.

## Foundational Learning
### Truncated Linear Regression
*Why needed:* The paper addresses the model where each sample \((x,y)\) is observed only if \(y\) lies in an unknown survival set \(S^*\) (a union of ≤ k intervals). This truncation invalidates ordinary least squares and requires specialized estimation techniques.  
*Quick check:* What is the survival set and why does its unknown status make estimation of \(w^*\) challenging?

### Positive‑Only PAC Learning
*Why needed:* The first phase must learn \(S^*\) using only positive examples (samples where \(y \in S^*\)). Traditional classification requires negative examples; the algorithm must exploit additional structure (smoothness) to succeed.  
*Quick check:* Why is learning unions of intervals from positive examples alone information‑theoretically impossible without extra structure?

### Smoothness Condition
*Why needed:* Smoothness between an auxiliary distribution \(D\) and the true positive response distribution \(D_y(w^*)\) allows the greedy positive‑only set learner to correctly identify \(S^*\) with polynomial samples.  
*Quick check:* State the \((s,q)\)-smoothness definition and interpret it informally.

### Sub‑Gaussian Random Vectors
*Why needed:* Sub‑Gaussianity of the covariates \(x\) ensures concentration of the warm‑start OLS estimate, controls the smoothness parameter, and provides tail bounds needed throughout the analysis.  
*Quick check:* What does it mean for a random vector \(x\) to be \(\sigma\)-sub‑Gaussian? Give an example.

### Projected Stochastic Gradient Descent (PSGD)
*Why needed:* The second phase minimizes the perturbed negative log‑likelihood \(\mathcal{L}_S\). PSGD with projection onto a strongly convex set \(P\) ensures convergence to an \(\varepsilon\)-accurate solution even with biased gradient estimates.  
*Quick check:* What two properties of \(\mathcal{L}_S\) and the projection set \(P\) guarantee that PSGD finds an \(\varepsilon\)-accurate estimate of \(w^*\)?

## Architecture Onboarding
**Component map:**  
Warm‑start Module (computes \(\hat{w}\) via OLS) → Projection Set Constructor (defines \(P\)) → Set Learner (Algorithm 3) → Gradient Sampler (Algorithm 4) → PSGD Engine (Algorithm 5) → Aggregation (selects final iterate). The auxiliary oracle \(D\) is built from the warm‑start and used by the Set Learner and Gradient Sampler.

**Critical path:**  
1. Collect \(n_{\text{warm}}\) truncated samples, compute \(\hat{w}\) (Equation 7), and define projection set \(P\).  
2. Build auxiliary oracle \(D\) (samples \(x\) from truncated model, outputs \(z \sim N(\langle\hat{w}, x\rangle, 1)\)).  
3. Run Set Learner (Algorithm 3) with positive samples \(D_y(w^*)_+\) and auxiliary \(D\) to obtain \(S\).  
4. For \(i = 1\) to \(K\): run PSGD (Algorithm 5) with \(S\) and \(P\), using Gradient Sampler (Algorithm 4) with tolerance \(\zeta = \sqrt{\varepsilon}/2\); obtain average iterate \(\bar{w}_i\).  
5. Return the \(\bar{w}_i\) that is within \(2\zeta/3\) of at least \(3/5\) of the iterates.

**Design tradeoffs:**  
- Warm‑start sample size \(n_{\text{warm}}\): larger reduces \(\|\hat{w} - w^*\|\), tightening \(P\) and lowering smoothness parameter \(q\), but uses more samples.  
- Set learning sample size \(n_{\text{set}}\): scales as \(\tilde{O}((\varepsilon s)^{-2q}(k + \log 1/\delta))\); better warm‑start (smaller \(q\)) reduces it.  
- Set accuracy \(\varepsilon\): must be small enough to ensure strong convexity of \(\mathcal{L}_S\); too large degrades final recovery.  
- Gradient tolerance \(\zeta\): set \(\zeta = O(\sqrt{\varepsilon})\) balances bias and per‑gradient runtime; smaller \(\zeta\) increases cost of truncated Gaussian sampling.  
- PSGD iterations \(T\): must overcome bias and variance; scales roughly as \(O(\kappa^{-1}\mu^2/\zeta^2 \cdot \log T)\), with \(\kappa\) dependent on \(\varepsilon\); often dominates total runtime.

**Failure signatures:**  
- Warm‑start failure: if \(n_{\text{warm}}\) too small, \(\|\hat{w} - w^*\|\) large → smoothness parameter \(q\) increases → set learner requires exponential samples.  
- Set learner failure: insufficient \(n_{\text{set}}\) or poor smoothness yields high set error \(E_{D_{\text{obs}}}[p_{S^*\triangle S}] > \varepsilon\) → \(\mathcal{L}_S\) not strongly convex on \(P\) → PSGD converges to suboptimal point.  
- Gradient sampler bias: \(\zeta\) not \(O(\sqrt{\varepsilon})\) → bias dominates final error.  
- PSGD divergence: \(T\) too small relative to condition number \(\kappa\) and error tolerance → iterate not \(\varepsilon\)-close to \(w_{\min}\).  
- Assumption violations: non‑sub‑Gaussian features or tiny survival probability \(\alpha\) break warm‑start concentration and smoothness.

**First three experiments:**  
1. **Warm‑start concentration:** For varying \(d\), \(\sigma\), and \(\alpha\), draw \(n_{\text{warm}} = \operatorname{poly}(d)\) truncated samples, compute \(\hat{w}\), and measure \(\|\hat{w} - w^*\|\). Verify with high probability the error is bounded by an \(O(1)\) constant (Lemma D.8).  
2. **Set learning under smoothness:** Fix \(w^*\) and a warm‑start \(\hat{w}\) with constant error. Construct \(D_y(w^*)\) and \(D_y(\hat{w})\). Run Algorithm 3 with varying \(n_{\text{set}}\) and \(k\). Estimate the set error \(E_{D_{\text{obs}}}[p_{S^*\triangle S}]\) and runtime; confirm polynomial dependence on \(k/\varepsilon\) and smoothness parameter \(q\).  
3. **End‑to‑end recovery:** Generate synthetic truncated linear regression data with known \(S^*\) (union of \(k\) intervals) and sub‑Gaussian features. Run full Algorithm 1 with parameters respecting theoretical bounds. Compare final \(\|\hat{w} - w^*\|\) and total runtime against predicted polynomial scaling; also test heavy‑tailed features to observe expected degradation.

## Open Questions the Paper Calls Out
1. Does the framework extend to truncated generalized linear models (e.g., Poisson, logistic) with unknown survival sets?  
2. Can positive‑only learning of unions of intervals scale to richer concept classes in constant dimensions (e.g., unions of boxes)?  
3. Is sub‑Gaussianity necessary, or can results hold for heavier‑tailed features (e.g., sub‑exponential)?  
4. What is the optimal sample complexity dependence on the number of intervals \(k\) for unknown survival set learning?  
5. Can the smoothness condition be replaced by a more natural or weaker assumption for positive‑only interval learning?

## Limitations
- The set‑learning step relies on a smoothness condition that only holds when the warm‑start \(\hat{w}\) is \(O(1)\)-close to \(w^*\); a small survival probability \(\alpha\) can cause an exponential blow‑up in sample complexity due to factors involving \(1/\alpha^2\).  
- The projection set radius scales as \(1/(\rho^2 \alpha)\); if \(\alpha\) is very small the set becomes large, weakening strong convexity and slowing PSGD.  
- The algorithm assumes \(S^*\) is exactly a union of at most \(k\) intervals and that \(k\) is known; misspecification (e.g., more intervals) breaks the theoretical guarantee.  
- Sub‑Gaussian feature distributions are essential; heavier‑tailed covariates violate the concentration needed for the warm‑start and smoothness properties.
