# TIACam: Text-Anchored Invariant Feature Learning with Auto-Augmentation for Camera-Robust Zero-Watermarking

## Quick Facts
- arXiv ID: 2602.18863
- Source URL: https://arxiv.org/abs/2602.18863
- Reference count: 37
- Primary result: Achieves state-of-the-art bit accuracy on real-world camera-robust zero-watermarking (e.g., 99.1% for 30-bit messages under screen-camera recapture).

## Executive Summary
TIACam addresses the challenge of extracting watermarks from images degraded by real-world camera captures (screen-camera, print-camera, screenshots) without modifying the original image. Its core innovation lies in learning an invariant feature space that separates semantic content from appearance-based distortions. This is achieved through a three-part framework: a learnable auto-augmentor that generates realistic camera-like distortions; a text-anchored feature learner that aligns image and text representations to enforce semantic consistency; and a zero-watermarking head that binds binary messages to the invariant features. On standard benchmarks, TIACam significantly outperforms prior methods, demonstrating high bit accuracy (>95%) even under complex degradations like perspective warping and Moiré interference.

## Method Summary
TIACam comprises three modules trained in an adversarial loop. (1) The auto-augmentor (`T_aug`) uses six differentiable operators (geometric, photometric, noise, filtering, compression, Moiré) to generate challenging, realistic distortions. It is trained to maximize feature dissimilarity while maintaining perceptual fidelity. (2) The invariant feature extractor (`f_θ`) refines CLIP image embeddings into distortion-invariant representations, enforced via cross-modal adversarial alignment with text captions using a discriminator (`D_ψ`). (3) The zero-watermarking head (`Ψ`, `C`) binds binary messages to the invariant feature space via a learned reference codebook, without altering image pixels. Training alternates between updating the discriminator, the augmentor (gradient ascent), and the feature extractor (gradient descent). Once the feature space stabilizes, watermark registration optimizes `Ψ` and `C` per image-message pair, and extraction uses dot products in the frozen invariant space.

## Key Results
- Screen-camera recapture: 99.1% (30-bit), 98.2% (100-bit) bit accuracy.
- Print-camera recapture: 96.6% (30-bit), 95.1% (100-bit).
- Screenshot scenarios: 97.4% (30-bit), 95.2% (100-bit).
- Feature invariance: Cosine similarity between clean and distorted features remains high (0.94–0.98), surpassing self-supervised baselines.

## Why This Works (Mechanism)
**Mechanism 1: Learnable Auto-Augmentor.** The auto-augmentor (`T_aug`) is a sequence of six parameterized neural operators that generate realistic, differentiable camera-like distortions. It is trained adversarially against the feature extractor: the augmentor updates its parameters to maximize feature dissimilarity (`L_inv`) while respecting a perceptual fidelity constraint (`L_sem`), forcing it to discover distortions that are both semantically valid and maximally disruptive. Core assumption: The space of camera degradations can be modeled by a differentiable pipeline, and robustness-inducing distortions are those that maximally challenge the current feature extractor. Evidence: [abstract] and [section 3.1] describe the modules and min-max objective; corpus shows limited direct support, relying on paper's own design. Break condition: If augmentor parameters collapse to trivial values or produce physically implausible outputs (e.g., non-invertible warps), the loop fails.

**Mechanism 2: Text-Anchored Invariant Feature Learner.** This component aligns image features with corresponding text descriptions via cross-modal adversarial training. A frozen CLIP image encoder and a trainable feature extractor `f_θ` produce embeddings that must fool a discriminator `D_ψ` into believing they match the positive text anchor `T⁺` rather than a negative `T⁻`. Additionally, `f_θ` must resist distortions from `T_aug`. The text anchor provides a stable semantic target, forcing the representation to capture "what the image is about" rather than appearance details. Core assumption: Textual descriptions are invariant to visual degradations and sufficiently aligned with image content. Evidence: [abstract], [section 3.2] on Information Bottleneck; [section 4.2] shows high cosine similarity and strong text-image alignment. Break condition: Noisy or irrelevant text anchors mislead the adversarial signal, potentially causing semantic collapse or feature homogenization.

**Mechanism 3: Zero-Watermarking in Invariant Space.** Watermark messages are bound to the invariant feature space, not pixels. During registration, a small head `Ψ` and a learnable codebook `C` are optimized so that dot products `σ(Ψ(f_θ(x))·Cⁱ)` match the binary message `Wⁱ`. For extraction from a distorted image `x'`, the frozen `f_θ` and `Ψ` are applied; the invariance ensures `f_θ(x') ≈ f_θ(x)`, enabling reliable recovery. Core assumption: The invariant feature is discriminative enough to uniquely encode messages via directional codes without interference. Evidence: [abstract], [section 3.3] formalizes registration/extraction; [section 4.3] reports high bit accuracy (e.g., 99.1% for 30-bit). Break condition: Feature collapse (many images map to similar vectors) causes codebook interference; insufficient invariance for a specific unseen distortion leads to bit errors.

## Foundational Learning
- **Cross-Modal Adversarial Alignment:** Needed to force the image feature extractor to ignore distortion-specific nuisances by aligning with stable text semantics. Quick check: If text anchors are misaligned (describe different objects), does invariance degrade?
- **Learnable Data Augmentation via Adversarial Training:** Hand-crafted distortions are limited; adversarial augmentor discovers a more comprehensive set of challenging degradations. Quick check: Is `T_aug` learning realistic patterns (e.g., Moiré fringes) or random noise? Check visualizations.
- **Information Bottleneck for Invariance:** Theoretical framework: invariant feature should maximize mutual information with text anchor (semantic relevance) while minimizing mutual information with raw image (nuisance). Operationalized via losses. Quick check: Does the feature retain enough information for classification (linear probe) while being distortion-insensitive? Check Table 8.

## Architecture Onboarding
Component map: Inputs (image x, positive text T⁺, negative text T⁻) -> T_aug produces distorted x̂ -> CLIP image encoder (E_img) and text encoder (g_τ) -> f_θ (residual MLP) outputs features F (from x) and F' (from x̂) -> Discriminator D_ψ (Transformer) classifies (F, E⁺) as real vs. (F, E⁻) or (F̂, E⁻) as fake; f_θ also feeds Ψ and C for watermark registration.

Critical path: (1) Pretrain each T_aug module on synthetic distortions (MSE/SSIM). (2) Three-way adversarial loop: Update D_ψ to distinguish image-text pairs; update T_aug (gradient ascent) to maximize L_inv - λ_sem L_sem; update f_θ (gradient descent) to minimize λ_adv L_adv + L_inv. (3) After f_θ stabilizes, freeze it and optimize per-image Ψ and C for a given watermark message via binary cross-entropy.

Design tradeoffs:
- Augmentor realism vs. training stability: More complex modules increase realism but risk unstable gradients; mitigated by pretraining and parameter clamping.
- Semantic invariance vs. feature distinctiveness: Strong text anchoring may collapse features of similar-caption images; balanced by instance-level discriminator and adversarial push from augmentor.
- Zero-watermarking capacity vs. robustness: Longer messages require finer feature separation, conflicting with smoothness needed for invariance; accuracy drops from ~98% (30-bit) to ~95% (100-bit).

Failure signatures:
- Semantic collapse: Linear probe accuracy on clean images drops significantly.
- Augmentor failure: x̂ shows unrealistic artifacts; feature similarity cos(F, F') does not improve.
- Watermark registration failure: Low bit accuracy on clean images during registration.
- Invariance failure on specific distortions: Sharp drop in bit accuracy for certain artifact types (e.g., heavy Moiré).

First 3 experiments:
1. Validate auto-augmentor outputs: After pretraining, qualitatively and quantitatively (SSIM vs. synthetic ground truth) check that x̂ resembles camera recapture artifacts.
2. Measure feature invariance baseline: Freeze f_θ, compute average cosine similarity cos(f_θ(x), f_θ(x̂)) across held-out set per distortion type; should exceed 0.9.
3. End-to-end watermark extraction on synthetic pipeline: Run registration and extraction on images distorted by full T_aug; target >95% bit accuracy for 30-bit messages.

## Open Questions the Paper Calls Out
- **Extension to non-content-preserving distortions:** How to handle heavy occlusions or semantic alterations that break text-anchored assumption? Basis: Section S8 notes failure when >2/3 content occluded. Evidence needed: Vary occlusion ratios, develop new modules (inpainting, multimodal compensation).
- **Generalization of auto-augmentor:** To unseen cameras, conditions, or distortion types beyond six modules? Basis: Introduction notes real-world distortions are environment-dependent and non-linear. Evidence needed: Test on diverse real camera captures, analyze which modules fail.
- **Dependence on text anchor quality:** Sensitivity to noisy, irrelevant, or absent captions? Basis: Assumes clean paired text from Visual Genome/Flickr30k. Evidence needed: Ablate text quality (noise, wrong captions, no text) and measure invariance and bit accuracy.
- **Adversarial security:** Vulnerabilities to attacks that mimic invariant features or remove watermarks? Basis: Paper only addresses natural distortions, not adversarial attacks. Evidence needed: Conduct adversarial attacks (PGD, FGSM) on feature extractor or decoder, measure success rates.

## Limitations
- Hyperparameters (λs, learning rates) and training schedules are not fully specified, hindering exact replication.
- Auto-augmentor's realism is not directly validated against real recaptured images; evidence relies on final performance.
- Sensitivity to text anchor quality (e.g., caption errors) is unexplored, potentially affecting robustness in practice.

## Confidence
- Auto-augmentor discovers realistic distortions: Medium (invariance gains suggest effectiveness, but no distortion-level validation).
- Text-anchored invariant feature learning: High (cosine similarity 0.94–0.98 and strong linear probe accuracy directly support semantic preservation).
- Zero-watermarking robustness in feature space: High (bit accuracy >95% consistently across three scenarios).
- Overall state-of-the-art claim: Medium (paper asserts outperformance but lacks detailed comparative numbers in excerpt).

## Next Checks
1. Quantify augmentation realism: Compute Fréchet Inception Distance between T_aug outputs and held-out real recaptured images; conduct human evaluation for perceptual plausibility.
2. Ablate text anchoring: Remove cross-modal adversarial loss, retrain, and measure changes in feature invariance (cosine similarity) and bit accuracy to isolate semantic alignment contribution.
3. Test generalization to unseen distortions: Apply extreme out-of-distribution degradations (heavy Gaussian blur, severe color jitter, non-uniform lighting) not covered by augmentor modules and report bit accuracy.
