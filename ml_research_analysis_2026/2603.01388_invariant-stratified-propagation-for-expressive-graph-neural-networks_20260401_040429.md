# Invariant-Stratified Propagation for Expressive Graph Neural Networks

## Quick Facts
- **arXiv ID:** 2603.01388
- **Source URL:** https://arxiv.org/abs/2603.01388
- **Reference count:** 40
- **Primary result:** Introduces Invariant-Stratified Propagation (ISP) to hierarchically process nodes by graph invariants, extending 1-WL expressiveness and achieving state-of-the-art performance on graph classification, node classification, and influence estimation.

## Executive Summary
Graph neural networks (GNNs) are typically constrained by the 1-Weisfeiler-Lehman (1-WL) test and rely on uniform neighbor aggregation, which fails to capture structural heterogeneity in graphs. This paper proposes Invariant-Stratified Propagation (ISP), a novel approach that stratifies nodes hierarchically based on graph invariants such as degree and coreness. By processing nodes in a specific order, ISP reveals structural distinctions invisible to standard GNNs. ISP-WL extends the 1-WL test with triangle-based gap encoding, while ISP-GNN implements this efficiently via learned attention mechanisms. Across graph classification (e.g., 97.9% on MUTAG), node classification (e.g., +18% on Texas), and influence estimation (e.g., MAE 0.135 on Jazz IC) tasks, ISP consistently achieves state-of-the-art results. The method maintains linear complexity on sparse graphs and exhibits resistance to oversmoothing, making it both expressive and scalable.

## Method Summary
ISP introduces two key innovations: invariant-based stratification and triangle-augmented message passing. First, graph invariants (e.g., degree, core) are computed for each node and used to create a hierarchical ordering (strata). During propagation, nodes only aggregate information from neighbors in the same or lower strata, respecting the order and breaking symmetry. ISP-WL theoretically extends 1-WL by encoding gaps between nodes via shared triangles, enhancing expressiveness. The practical ISP-GNN implementation replaces handcrafted gap encoding with a learned attention mechanism that weights neighbor contributions efficiently. This design preserves linear complexity on sparse graphs and mitigates oversmoothing because information flow is constrained by the stratification hierarchy.

## Key Results
- Graph classification: 97.9% accuracy on MUTAG, setting a new state-of-the-art.
- Node classification: +18% improvement on the Texas dataset compared to prior methods.
- Influence estimation: MAE 0.135 on the Jazz IC benchmark, outperforming existing approaches.

## Why This Works (Mechanism)
Stratification orders nodes by invariant values, ensuring that information propagates from structurally simpler to more complex nodes. This ordered flow uncovers subtle differences in local topology that uniform aggregation misses. Triangle-based gap encoding (in ISP-WL) allows the update rule to consider not just immediate neighbors but also the relationships between them, effectively simulating higher-order WL tests. The attention mechanism in ISP-GNN learns to weight these contributions adaptively while keeping computational costs low. Because nodes within a stratum remain relatively homogeneous, repeated propagation does not collapse all features into a uniform representation, thereby resisting oversmoothing.

## Architecture Onboarding
**Component Map:**  
Input Graph → Invariant Computation → Hierarchical Stratification → Ordered Propagation (per stratum) → Attention-based Aggregation → Prediction Head

**Critical Path:**  
1. Compute graph invariants (degree, core, etc.) for all nodes.  
2. Sort nodes into hierarchical strata based on invariant thresholds.  
3. Perform message passing: for each stratum in ascending order, nodes aggregate features from neighbors in the same or earlier strata using attention.  
   Repeat this propagation for multiple layers.  
4. Apply a readout function (e.g., sum, mean, or attention pooling) to produce graph-level or node-level outputs.  
5. Train the model end-to-end with task-specific loss.

**Design Tradeoffs:**  
- *Handcrafted vs. learned invariants:* Fixed invariants are simple and interpretable but may miss task-relevant structures; learning them could improve adaptability at the cost of complexity.  
- *Stratification depth:* More strata can capture finer structural distinctions but increase computational overhead for ordering and bookkeeping.  
- *Attention complexity:* Attention scales quadratically with neighbor degree; however, sparsity and stratification keep it manageable on sparse graphs.  
- *Complexity claim:* Linear time holds for sparse graphs; on dense graphs, invariant computation and attention may become bottlenecks.

**Failure Signatures:**  
- Accuracy drops on graphs where chosen invariants fail to differentiate semantically important roles (e.g., regular lattices).  
- Runtime or memory usage increases dramatically on dense graphs, contradicting the linear complexity claim.  
- Oversmoothing reappears when stacking many layers, suggesting the stratification mitigation is insufficient.  
- High sensitivity to minor changes in invariant definitions or thresholds, indicating brittleness.

**First Experiments:**  
1. **Reproduction on MUTAG:** Train ISP-GNN and verify it reaches ~97.9% accuracy, matching the paper’s result.  
2. **Invariant Ablation:** Systematically remove one invariant (e.g., coreness) and measure accuracy on Texas node classification to assess each invariant’s contribution.  
3. **Depth Scaling:** Vary the number of propagation layers and plot performance and feature entropy to check for oversmoothing and validate resistance claims.

## Limitations
- The method relies on handcrafted invariants; these may not capture all relevant structural nuances and make performance sensitive to the chosen set.  
- Linear complexity is only guaranteed for sparse graphs; overhead from invariant computation and attention could degrade scalability on dense graphs.  
- Experimental evaluation is limited to small/medium benchmark datasets; the approach lacks validation on large-scale graphs (e.g., OGB) or real-world applications, raising questions about practical scalability.
