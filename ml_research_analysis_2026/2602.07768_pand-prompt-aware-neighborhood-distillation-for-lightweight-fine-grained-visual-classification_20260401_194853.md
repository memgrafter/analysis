# PAND: Prompt-Aware Neighborhood Distillation for Lightweight Fine-Grained Visual Classification

## Quick Facts
- **arXiv ID:** 2602.07768
- **Source URL:** https://arxiv.org/abs/2602.07768
- **Reference count:** 0
- **Primary result:** With a ResNet-18 student, PAND achieves 76.09% top-1 accuracy on CUB-200, a 3.4% absolute improvement over VL2Lite.

## Executive Summary
PAND is a two-stage framework for distilling knowledge from large Vision-Language Models (VLMs) into lightweight networks for fine-grained visual classification. It addresses key limitations of prior VLM distillation: reliance on static hand-crafted prompts and global feature alignment. First, Prompt-Aware Semantic Calibration (PSC) learns task-specific continuous prompts to generate precise semantic anchors. Second, Neighborhood-Aware Structural Distillation (NSD) enforces consistency in local decision structure (neighbourhood relationships) between teacher and student. On four FGVC benchmarks, PAND consistently outperforms state-of-the-art, with a ResNet-18 student achieving 76.09% on CUB-200 (3.4% above VL2Lite). Ablations confirm both stages contribute synergistically.

## Method Summary
PAND decouples training into two sequential stages using a frozen CLIP (ConvNeXt-XXL) as teacher. **Stage-PSC** optimizes continuous context tokens (N=16) via cross-entropy loss while keeping all VLM parameters fixed, tailoring the text embedding space to the target dataset and producing a fixed set of per-class text features (semantic anchors). **Stage-NSD** freezes the teacher and these anchors; it then trains a lightweight student (e.g., ResNet-18, MobileNet-V2) with a combined loss: a base loss (VL2Lite-style) aligns global features and logits, and NSD aligns local neighbourhood structures. NSD, for each sample, compares the teacher’s and student’s distributions of relative margins between the ground-truth and the top-K non-ground-truth classes (K=3) via Jensen-Shannon divergence. This design stabilizes prompt learning (by isolating it from noisy student gradients) and transfers fine-grained discriminatory logic.

## Key Results
- **SOTA on FGVC:** ResNet-18 student achieves 76.09% top-1 accuracy on CUB-200-2011, surpassing VL2Lite by 3.4%.
- **Broad improvement:** Consistent gains on Oxford-IIIT Pet, Stanford Dogs, and FGVC-Aircraft.
- **Ablation synergy:** Both PSC (+1.85%) and NSD (+3.24%) improve over the baseline; combined yields +3.42% (slightly super‑additive).
- **Visualization:** t-SNE plots show superior class separation and compact intra‑class clusters.

## Why This Works (Mechanism)
**Mechanism 1: Adaptive prompts produce discriminative semantic anchors.**  
Stage-PSC optimizes continuous context tokens (CoOp style) while freezing the VLM, tailoring the text embedding space to fine-grained inter‑class variations. This yields a stable, high‑quality set of class text features that serve as precise targets for subsequent distillation. Evidence: Ablation shows a significant gain (+PSC). Failure if learned prompts do not enhance discrimination on a frozen VLM (e.g., low linear probe accuracy).

**Mechanism 2: Neighbourhood distillation transfers local decision logic.**  
NSD aligns the student’s relative confidence among the teacher’s most confusing classes (top‑K non‑ground‑truth) with the teacher’s. This teaches the student fine‑grained distinctions that global alignment misses. Evidence: NSD alone outperforms PSC alone; sensitivity analysis (Fig. 2) validates λ_NSD≈0.5; feature visualisations confirm better neighbour matching. Failure if λ_NSD or K is mis‑set or if neighbourhood selection is noisy.

**Mechanism 3: Two‑stage decoupling ensures optimisation stability.**  
By training PSC first with only prompts updated, then freezing the resulting anchors for NSD, noisy gradients from the randomly initialised student are prevented from corrupting the delicate prompt learning. Evidence: Full PAND exceeds the sum of its parts (synergy). Failure if prompts from PSC are weak or the two‑stage shift prevents the student from overcoming the fixed anchor.

## Foundational Learning
- **Vision‑Language Models (VLMs) like CLIP**  
  Dual‑encoder models trained contrastively; classification is performed by matching image embeddings to text embeddings of class prompts. *Why needed:* PAND uses a frozen VLM as teacher; its text encoder produces semantic anchors. *Quick check:* How does optimising continuous context tokens (instead of fixed hand‑crafted prompts) change the textual representation space for fine‑grained classes?

- **Knowledge Distillation (KD) & Relational Distillation**  
  KD transfers knowledge from a large teacher to a small student by matching output distributions (e.g., KL divergence). Relational distillation aligns relationships (e.g., similarities) among samples or logits. *Why needed:* PAND extends relational distillation to VLMs via neighbourhood structure in logit space. *Quick check:* What is the key difference between standard KD (minimising KL on logits) and neighbourhood‑based relational KD (minimising JS on neighbourhood distributions)?

- **Fine‑Grained Visual Classification (FGVC)**  
  Task of distinguishing between visually similar sub‑categories (e.g., bird species) with small inter‑class differences and large intra‑class variation. *Why needed:* FGVC demands sensitivity to subtle parts and local structures, motivating adaptive prompts and neighbourhood distillation. *Quick check:* Why might global feature alignment (e.g., MSE between feature maps) fail for distinguishing two similar dog breeds?

## Architecture Onboarding
**Component Map:**  
Teacher VLM (frozen CLIP ConvNeXt‑XXL) → Stage‑PSC Module (learnable context tokens) → fixed text features F_txt → Student model (ResNet‑18/MobileNet‑V2) → Stage‑NSD Loss Module (computes L_base + L_NSD using teacher logits from F_txt and student logits).

**Critical Path:**  
1. Initialise context tokens randomly.  
2. **Stage‑PSC (200 epochs):** Freeze VLM encoders; forward images to image encoder, prompts to text encoder; compute cross‑entropy loss; optimise only context tokens via SGD (lr=0.002, momentum=0.9). Save final F_txt.  
3. **Stage‑NSD (300 epochs):** Freeze teacher and F_txt. For each batch, compute teacher logits (frozen image encoder + F_txt) and student logits. Compute total loss L_total = L_base (VL2Lite‑style) + λ_NSD L_NSD. Optimise student backbone + head via AdamW (lr=1e‑4, weight decay 1e‑4) with cosine annealing (temperature τ=2.0).

**Design Tradeoffs:**  
- **Two‑stage vs Joint Training:** Decoupling prevents noisy student gradients from destabilising prompt learning, but increases training time and storage.  
- **Neighbourhood size (K):** Small K (paper uses 3) focuses on most confusing neighbours but may be brittle; larger K captures broader structure but risks dilution.  
- **Loss weight (λ_NSD):** Balances global alignment (L_base) and local structure (L_NSD). Must be tuned; optimal near 0.5 on CUB, but over‑constraint degrades performance.

**Failure Signatures:**  
- Stage‑PSC failure: Learned text features yield low linear probe accuracy (<80% on CUB) → prompts not discriminative.  
- Stage‑NSD failure: L_NSD near zero or unstable; λ_NSD>0 degrades performance → neighbourhood selection or JS computation flawed.  
- Synergy failure: Full PAND does not significantly exceed the better single component → decoupling not delivering multiplicative benefit.  
- Visualisation failure: t‑SNE shows no improvement in intra‑class compactness or inter‑class separation.

**First 3 Experiments:**  
1. **Replicate Ablation (Table 2):** Train Baseline (VL2Lite), +PSC, +NSD, Full PAND on CUB‑200 with ResNet‑18. Verify accuracy hierarchy: 72.67 → 73.52 → 75.91 → 76.09.  
2. **Sweep λ_NSD (Fig 2):** Train full PAND with λ_NSD ∈ {0,0.1,0.3,0.5,0.7,1}. Confirm peak near 0.5 and degradation at higher values.  
3. **Neighbourhood Visualisation:** For confusing samples, extract top‑5 non‑ground‑truth logits from teacher, VL2Lite student, and PAND student. Check that PAND better matches teacher’s relative ordering (e.g., via Kendall’s τ).

## Open Questions the Paper Calls Out
1. **Why haven’t task‑adaptive prompts been integrated into VLM distillation before?** Introduction identifies this gap; no ablation compares decoupled vs joint training with gradient isolation. Resolution: train an end‑to‑end variant and compare stability/accuracy.
2. **Is the two‑stage decoupling strictly necessary?** Claimed to avoid noisy gradients, but no empirical validation against warm‑up or gradual unfreezing. Evidence needed from alternative training schedules.
3. **How does NSD performance vary with neighbourhood size K?** Fixed K=3 without justification; optimal K may differ across datasets/student architectures. Systematic sensitivity analysis required.
4. **Are PSC and NSD benefits additive or synergistic?** Combined gain (+3.42%) barely exceeds larger individual (+NSD, +3.24%); interaction not isolated. Evidence: measure semantic anchor quality and neighbourhood consistency under component combinations.
5. **Can PAND generalise beyond FGVC and CLIP teachers?** Framework relies on text embeddings and logit‑based neighbourhoods; applicability to detection, segmentation, or non‑VLM teachers (e.g., CNN) is untested.

## Limitations
- **Base loss details missing:** Exact formulations and dynamic schedules for L_cls, L_vis, L_txt from VL2Lite are unspecified, hindering faithful replication.
- **Hyperparameter ambiguity:** Specific λ_NSD used in main results is unknown (sensitivity peak 0.5 yields 76.41% but reported 76.09%); dynamic base λ adjustments are vague.
- **Generalisation untested:** Evaluation limited to four FGVC datasets with a single CLIP teacher; performance on other VLMs or tasks is unproven.

## Confidence
- **Adaptive prompts yield discriminative anchors** → Medium (supported by ablation and prompt‑learning literature, but causal link to distillation is inferred, not isolated).
- **Neighbourhood distillation transfers local structure** → Medium‑High (strong internal evidence; extension to VLMs novel but lacks external validation).
- **Two‑stage decoupling ensures stability** → Low (implementation rationale without comparative experiments; alternative stabilisation methods not tested).
