# A Lightweight Library for Energy-Based Joint-Embedding Predictive Architectures

## Quick Facts
- **arXiv ID:** 2602.03604
- **Source URL:** https://arxiv.org/abs/2602.03604
- **Reference count:** 24
- **Primary result:** A modular, lightweight library for self-supervised representation learning and world modeling, achieving 91% linear probing accuracy on CIFAR-10, 97% planning success on Two Rooms, and demonstrating the critical role of regularization in preventing collapse.

## Executive Summary
EB-JEPA introduces an accessible, open-source library for Joint-Embedding Predictive Architectures (JEPAs) that lowers the barrier to entry for self-supervised representation learning and world modeling. The library encapsulates an energy-based learning objective that operates in latent space, avoiding pixel reconstruction pitfalls, and incorporates regularizers (VICReg or SIGReg) to prevent representation collapse. It provides three progressive, self-contained examples—image representation learning (view invariance), video prediction (temporal dynamics), and action-conditioned planning—each designed to train on a single GPU within hours. Key results include 91% linear probing accuracy on CIFAR-10, improved multi-step video prediction on Moving MNIST, and 97% planning success in a navigation task. Extensive ablations confirm that all regularization components are essential for stable training.

## Method Summary
EB-JEPA implements Joint-Embedding Predictive Architectures using an energy-based formulation where the model learns to predict target representations from context representations in a shared latent space. The core components are an encoder that maps observations to latent vectors, a predictor that maps context (and optionally actions) to a predicted target representation, and a projector that transforms representations for regularization. The loss combines a prediction error (e.g., mean squared error between predicted and true target representations) with a regularization term (VICReg or SIGReg) applied to the projected embeddings to prevent collapse. The library supports multi-step rollout training to improve long-horizon consistency and includes planners (MPPI/CEM) for action-conditioned world models. All implementations are lightweight and modular, enabling quick experimentation on modest hardware.

## Key Results
- **Image representation:** Linear probing achieves 91% accuracy on CIFAR-10 using a ResNet-18 backbone.
- **Video prediction:** Multi-step latent rollout training improves Average Precision on downstream object detection in Moving MNIST.
- **Action-conditioned planning:** World models attain 97% success rate on the Two Rooms navigation task using MPPI planning; ablations show that removing any regularizer (especially IDM) collapses performance to near zero.

## Why This Works (Mechanism)
### Mechanism 1: Latent-Space Prediction as Learned Energy Function
- **Claim:** The model learns representations by minimizing prediction error in a shared latent space, avoiding pixel reconstruction pitfalls.
- **Mechanism:** An encoder \(f_{th}\) maps input \(x\) to representation \(z\). A predictor \(g_{phi}\), optionally conditioned on actions \(u\), takes context representations and predicts the target representation \(z'\). The scalar energy is the prediction loss \(\|g_{phi}(...) - z'\|^2\). Minimizing this shapes the latent space so semantically consistent inputs (e.g., augmented views of the same image) have low energy.
- **Core assumption:** Predicting in a compressed latent space focuses learning on semantically meaningful features while ignoring irrelevant pixel-level details.
- **Evidence anchors:**
  - [abstract] "JEPAs learn to predict in representation space rather than pixel space, avoiding the pitfalls of generative modeling."
  - [section 3] Unified energy formulation Eq. (5): \(E(x, x', a) = L_{pred}(g_{phi}(f_{th}(x), q_{\theta}(a)), f_{th}(x'))\).
  - [corpus] Related LeJEPA work provides theoretical grounding for provable properties of this energy-based setup.
- **Break condition:** If the predictor capacity is insufficient relative to the encoder, or if the context window is too small, the model cannot learn meaningful temporal or action-conditioned mappings, leading to high prediction error and poor representations.

### Mechanism 2: Regularization-Driven Collapse Prevention
- **Claim:** Explicit representation regularizers (VICReg/SIGReg) prevent the degenerate solution where all inputs map to a constant vector.
- **Mechanism:** Regularization is applied to embeddings \(r = h_{\theta}(z)\) from a learned projector. For VICReg: variance term encourages each feature dimension to have batch standard deviation near target \(\gamma\); covariance term decorrelates features. For SIGReg: enforces Gaussianity along random 1D projections. These terms counteract the trivial minimizer of prediction loss (constant \(z\)).
- **Core assumption:** Collapse is the dominant failure mode for joint-embedding methods without negative sampling or stop-gradients, and must be actively suppressed via diversity-promoting penalties.
- **Evidence anchors:**
  - [section 3] Detailed definitions of \(L_{var}\), \(L_{cov}\), and \(R_{SIGReg}\).
  - [section 5] Ablation tables (4, 2) show catastrophic performance drop (e.g., 1% success in planning) when any regularizer (especially IDM) is removed.
  - [figure 2] SIGReg shows stable performance across hyperparams; VICReg requires careful tuning, implying regularization is critical but sensitive.
- **Break condition:** Regularizer weights (\(\alpha, \beta, \delta, \omega\)) set to zero or too low relative to prediction loss; or projector design that cannot express sufficient diversity (e.g., no nonlinearities, bottleneck too narrow).

### Mechanism 3: Multi-Step Rollout Training for Temporal Consistency
- **Claim:** Training with multi-step latent rollouts reduces exposure bias and improves long-horizon predictive performance.
- **Mechanism:** During training, beyond single-step loss \(L_1\), additional losses \(L_k\) for \(k>1\) are computed by recursively applying the predictor: \(\hat{z}^{t+1} = g_{phi}(\hat{z}^{t-v:t}, u^{t-v:t})\). This aligns training with autoregressive inference, forcing the predictor to handle its own errors over multiple steps.
- **Core assumption:** Single-step teacher-forced training creates a distribution shift at inference when predictions are fed back, degrading long-horizon quality.
- **Evidence anchors:**
  - [section 4] Eq. (9)-(11) define multi-step rollout losses.
  - [figure 3b] "Training with k-step recursive predictions achieves significantly better Average Precision... with a Pareto optimum around k=4 rollout steps."
  - [section 5] Video-JEPA experiments show improved moving MNIST detection via multi-step training.
- **Break condition:** \(K\) (number of rollout steps) too large relative to predictor stability; gradient signal vanishes after too many recursive steps, causing training instability or divergence.

## Foundational Learning
- **Concept: Energy-Based Models (EBMs)**
  - *Why needed here:* The entire JEPA framework is framed as learning an energy function \(E(x, x')\) that measures compatibility in latent space. Understanding EBMs clarifies why prediction loss defines the energy and why collapse is a risk.
  - *Quick check question:* If you minimized only \(\|g_{phi}(f(x)) - f(x')\|^2\) without regularization, what degenerate solution would the model find, and why would it minimize the loss?
- **Concept: Self-Supervised Representation Collapse**
  - *Why needed here:* Recognizing the collapse problem—where encoders output constant or rank-deficient representations—is essential to motivate the heavy reliance on regularization in this library.
  - *Quick check question:* Why doesn't the predictive objective alone prevent collapse, and how do variance/covariance regularizers address this?
- **Concept: Joint-Embedding Principle**
  - *Why needed here:* JEPAs operate in a space where inputs and targets are embedded by separate or shared encoders without ever reconstructing the original input. This distinguishes them from autoencoders/MAE.
  - *Quick check question:* What is the key architectural difference between a JEPA and a masked autoencoder (MAE) that leads to different learned feature properties?

## Architecture Onboarding
- **Component map:**  
  x, x' -> Encoder f -> z (context), z' (target)  
  (z, u) -> Predictor g -> z_pred  
  z -> Projector h -> r  
  z' -> Projector h -> r'  
  (r, r') -> Regularizer R (VICReg/SIGReg) -> reg_loss  
  ||z_pred - z'||^2 -> pred_loss  
  Total loss = pred_loss + reg_loss  
  Action a -> Encoder q -> u (for world models)  
  Planner: minimizes E(x, x', a) over a using MPPI/CEM.

- **Critical path:**  
  1. Start with Image-JEPA (identities for predictor/gradient, no action encoder). Verify linear probe accuracy ~90% on CIFAR-10.  
  2. Progress to Video-JEPA: replace predictor with temporal model (GRU/ResUNet), add multi-step rollout loss.  
  3. Build AC-Video-JEPA: add action encoder and IDM/similarity regularizers; integrate MPPI planner.

- **Design tradeoffs:**  
  - **Projector design:** Larger output dimension favors VICReg; bottleneck (large→small) helps SIGReg. Omitting projector hurts performance ~3 points.  
  - **Regularizer choice:** SIGReg has single λ, easier tuning; VICReg has α, β requiring more search but can match performance.  
  - **Rollout steps K:** Higher K improves long-horizon skill but risks gradient instability; optimal K depends on environment complexity (e.g., K=4 for Moving MNIST).  
  - **Planner cost:** Cumulative cost over horizon outperforms terminal-only cost (+8% success).

- **Failure signatures:**  
  - **Collapse:** Linear probe accuracy near random (10% on CIFAR-10), loss curves show prediction loss dropping but regularization loss also vanishes.  
  - **Temporal error accumulation:** Video predictions degrade rapidly after 1-2 steps if K too low or predictor capacity insufficient.  
  - **Planning failure:** Success rate remains low despite good video prediction, likely due to missing IDM regularizer (causes success collapse to 1% per Table 4).

- **First 3 experiments:**  
  1. **Reproduce Image-JEPA:** Train ResNet-18 + VICReg on CIFAR-10. Check that variance and covariance losses remain >0 throughout training; confirm linear probe accuracy >90%.  
  2. **Test Regularizer Ablation:** Train with α=0, then β=0, then δ/ω=0 (for video/world). Expect significant performance drop (>40% AP or success) to validate each component's necessity.  
  3. **Validate Multi-step Rollout:** For video model, compare single-step (K=1) vs multi-step (K=4) training. Measure multi-step rollout AP; expect improvement per Figure 3b.

## Limitations
- Benchmarks are limited to small-scale datasets (CIFAR-10, Moving MNIST, Two Rooms); generalizability to complex real-world data is unknown.
- Regularizer hyperparameters (α, β, δ, ω) require careful tuning, with VICReg being particularly sensitive, potentially hindering accessibility.
- Projector design choices (dimensions, nonlinearities) lack systematic analysis, and their impact on collapse prevention is not fully mapped.

## Confidence
- **Performance** (91% linear probe CIFAR-10, 97% planning success): Medium.
- **Mechanisms** (latent prediction, regularization, multi-step rollout): Medium.
- **Library usability** (modular, single-GPU training): High.
