# Exa-PSD: a new Persian sentiment analysis dataset on Twitter

## Quick Facts
- **arXiv ID:** 2602.20892
- **Source URL:** https://arxiv.org/abs/2602.20892
- **Reference count:** 0
- **Primary result:** RoBERTa model fine-tuned on Exa-PSD achieves a Macro F-score of 79.87% on the test set.

## Executive Summary
This paper introduces Exa-PSD, the first general Persian sentiment analysis dataset sourced from Twitter that explicitly captures informal language such as ironies and colloquialisms. The dataset comprises 12,000 tweets manually annotated by five native Persian speakers into positive, neutral, and negative classes, with final labels determined by majority agreement. After a targeted preprocessing pipeline, the authors fine-tune two pre-trained Persian language models—ParsBERT and a Twitter-adapted RoBERTa—on the dataset. The Twitter-domain RoBERTa model yields the best performance, demonstrating the viability of robust Persian sentiment analysis on social media text and providing a valuable resource for future research.

## Method Summary
The authors collected Persian tweets via the Twitter API and annotated them using five native speakers through the Utag platform. To ensure label reliability, each tweet was independently labeled, and only tweets with at least three agreeing annotations were retained, yielding 11,000 training and 1,000 test samples. Preprocessing involved removing mentions and URLs, fixing half-space errors and normalizing numbers (using Hazm), stripping non-Persian characters, and separating punctuation. Two models were fine-tuned: ParsBERT (a BERT variant pre-trained on formal Persian text) and RoBERTa (pre-trained from scratch on 50M Persian tweets). For ParsBERT, the tokenizer was updated to include emojis and numeric tokens. Both models were fine-tuned with a classification head using identical hyperparameters (batch size 32, learning rate 5e-5, two epochs, dropout 0.1) and evaluated via Macro F-score, per-class precision/recall, and Cohen’s Kappa.

## Key Results
- The best model (RoBERTa) achieved a Macro F-score of **79.87%** on the test set.
- Inter-annotator agreement, measured by Cohen’s Kappa, averaged **66.1** (substantial).
- RoBERTa consistently outperformed ParsBERT, attributed to its pre-training on Persian Twitter data.

## Why This Works (Mechanism)

### Mechanism 1
- **Claim:** A manually annotated dataset with multiple native Persian speakers improves label reliability for informal, colloquial Twitter text despite inherent ambiguity.
- **Mechanism:** Five native annotators independently label each tweet; final label requires majority agreement (≥3/5). This mitigates individual bias. Cohen’s Kappa (mean 66.1) quantifies consistency.
- **Core assumption:** Native speakers share a stable interpretation of sentiment in short Persian tweets, and majority voting filters truly ambiguous cases.
- **Evidence anchors:** Annotation process described (Utag, separate tagging, meetings to align); Kappa reported in Table 3; dataset statistics in Table 4.

### Mechanism 2
- **Claim:** Fine-tuning a transformer-based model pre-trained on large Persian corpora, especially one adapted to social media, yields higher sentiment classification accuracy.
- **Mechanism:** Two pre-trained models—ParsBERT (news/novels) and RoBERTa (50M Persian tweets)—are fine-tuned on Exa-PSD by adding a classification head and training with low learning rate (5e-5) for two epochs. RoBERTa’s domain-specific pre-training better captures informal patterns.
- **Core assumption:** Pre-trained knowledge generalizes to the task, and domain adaptation (Twitter pre-training + task fine-tuning) aligns representations with Persian social media.
- **Evidence anchors:** Models and results in abstract/section 5 (Table 5); pre-training details in section 4.2; fine-tuning setup in section 4.3.

### Mechanism 3
- **Claim:** Targeted preprocessing that corrects Persian-specific orthographic noise and removes Twitter-irrelevant metadata improves input quality without stripping sentiment-bearing informal cues.
- **Mechanism:** Four-step cleaning: (1) remove mentions/URLs, (2) fix half-spaces and normalize numbers (Hazm), (3) remove non-Persian characters, (4) separate punctuation. This reduces vocabulary sparsity and irrelevant tokens.
- **Core assumption:** Twitter noise (mentions, URLs) and common typographical errors are non-predictive for sentiment; removal yields cleaner token sequences.
- **Evidence anchors:** Preprocessing steps listed in section 4.1; example of half-space fix; tweet length distribution in Figure 1.

## Architecture Onboarding
- **Component map:** Twitter API collection -> Raw tweet storage -> Preprocessing pipeline -> Multi-annotator labeling (Utag) -> Majority-vote filtering -> Train/test split -> Tokenizer adaptation (optional) -> Model fine-tuning (Classification head + Transformer) -> Evaluation (F1, confusion matrix)
- **Critical path:** Annotation quality -> dataset quality -> model fine-tuning -> final performance. Any flaw in annotation propagates downstream.
- **Design tradeoffs:** 
  - Dataset size vs. annotation cost: 12k tweets is modest; more data improves robustness but costs more annotator time.
  - Tokenizer update vs. stability: Adding emojis/Twitter tokens to ParsBERT improves coverage but risks misalignment with original pre-training.
  - Model complexity: RoBERTa (6 layers) is smaller/faster than base BERT, likely chosen due to dataset size/resource constraints.
- **Failure signatures:**
  - Data-level: Low Cohen’s Kappa (<0.6) indicates unreliable labels; class imbalance (neutral dominant in Table 4) may bias model.
  - Model-level: Confusion matrix (Figure 3) shows lower recall for neutral class, suggesting difficulty with ambiguous/mixed-sentiment tweets.
  - Preprocessing-level: Over-aggressive cleaning could remove sentiment cues (e.g., emoticons, colloquial spellings).
- **First 3 experiments:**
  1. Train a simple baseline (e.g., SVM on TF-IDF) on raw, un-preprocessed tweets to establish lower bound and quantify preprocessing impact.
  2. Fine-tune ParsBERT with and without updated tokenizer (adding emojis/numbers) to measure Twitter-specific token contribution.
  3. Fine-tune a general-Persian RoBERTa (e.g., Wikipedia pre-trained) on Exa-PSD vs. paper’s Twitter-pre-trained RoBERTa to isolate domain effect.

## Open Questions the Paper Calls Out
- How can irony and sarcasm in Persian Twitter text be effectively detected and incorporated to improve performance? (Conclusion notes irony’s prevalence and future work potential.)
- What specific features cause the model to struggle with classifying "neutral" tweets, especially those with agency news or neutral idioms? (Discussion notes lower neutral accuracy due to such content.)
- Can the annotation process be improved to achieve higher inter-annotator agreement, and would a multi-label or probabilistic scheme yield a more reliable gold standard? (Kappa=66.1 is moderate; strict majority voting discards ambiguous data.)
- How can future Persian Twitter sentiment datasets be sustainably collected and updated given restrictive API policies? (Paper notes post-study API changes may preclude similar collection.)
- To what extent do architectural choices (e.g., model depth, pre-training corpus) versus fine-tuning procedures determine the performance ceiling? (RoBERTa’s advantage attributed to Twitter pre-training but not disentangled from architecture.)

## Limitations
- Moderate inter-annotator agreement (κ=66.1) indicates persistent label ambiguity.
- Preprocessing implementation details (e.g., half-space fixing logic) are not fully specified, risking replication divergence.
- Dataset size (12k tweets) is modest; no ablation studies for preprocessing or tokenizer updates are provided.

## Confidence
- Annotation reliability (majority-vote filtering with κ=66.1): **Medium**
- RoBERTa advantage from Twitter-domain pre-training: **Medium**
- Preprocessing preserves informal cues without over-cleaning: **Low**
