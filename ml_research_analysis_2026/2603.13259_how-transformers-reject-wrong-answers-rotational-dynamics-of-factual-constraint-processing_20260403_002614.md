# How Transformers Reject Wrong Answers: Rotational Dynamics of Factual Constraint Processing

## Quick Facts
- arXiv ID: 2603.13259
- Source URL: https://arxiv.org/abs/2603.13259
- Reference count: 7
- Primary result: Divergence between correct and incorrect factual answers occurs via rotational (isometric) separation in representation space, with active suppression of the correct answer, emerging around 1.6B parameters.

## Executive Summary
The paper investigates how transformer language models internally differentiate between correct and incorrect factual answers—a dynamic that is not well understood across network depth. To address this, the authors introduce forced-completion probing: for a given query, they run forward passes with a known correct single-token continuation and an incorrect single-token continuation, then track five geometric measurements across all layers of models ranging from 1.5B to 13B parameters.

Key findings reveal a distinctive pattern: the representations diverge rotationally—displacement vector norms remain nearly identical (ratio ~1.00) while their angular separation increases (cosine similarity drops to 0.62–0.69). Moreover, when processing an incorrect answer, the model actively suppresses the correct one, as evidenced by the commitment ratio collapsing to as low as 0.08, far below the neutral value of 0.5. These phenomena are absent in the smallest 1.5B model but emerge robustly at 1.6B parameters, pointing to a scale-dependent phase transition in factual constraint processing.

## Method Summary
The authors assembled a dataset of 300 queries spanning three categories—Deep Constraint (182), Control (66), and Neutral (52)—each with one correct and one incorrect single-token answer and annotated "deep" and "surface" keyword spans. Using four decoder-only models (LLaMA-2 13B, Mistral 7B, StableLM-2 1.6B, Qwen2 1.5B), they performed three forward passes per query (query-only, query+correct token, query+incorrect token) with `output_hidden_states=True` and `output_attentions=True`. Hidden states at the last token position were extracted for every layer (including the embedding layer). Five metrics were computed: (M1) trajectory similarity (cosine between correct and incorrect hidden states), (M2) displacement vectors from the query state and their norm ratio η and angular separation ρ, (M3) linear probe accuracy via L2-regularized logistic regression with 5-fold stratified cross-validation, (M4) commitment ratio κ as the normalized probability of the correct token after unembedding (with final normalization applied), and (M5) attention allocation ratio α comparing attention to deep vs. all tokens. Statistical comparisons used Mann-Whitney U tests with Benjamini-Hochberg FDR correction.

## Key Results
- **Rotational divergence**: Displacement norms are near-identical (η ≈ 1.00) while angular separation ρ increases across layers, yielding cosine similarities as low as 0.62–0.69. This indicates that models encode the distinction directionally without changing the magnitude of the shift.
- **Active suppression**: On the incorrect continuation path, the commitment ratio κ collapses to as low as 0.08, far below 0.5, demonstrating that the model downweights the correct answer.
- **Scale threshold**: Both effects are absent in the 1.5B Qwen2 model but appear robustly in the 1.6B StableLM-2 model, suggesting a phase transition in factual processing capability around 1.6B parameters.

## Why This Works (Mechanism)
The rotational signature likely arises because transformer normalization layers (RMSNorm/LayerNorm) stabilize activation norms, forcing the model to encode information in the directional components of the residual stream. The consistent norm across correct and incorrect paths suggests an isometric transformation—a rotation—that preserves magnitude while reorienting the representation. Active suppression, reflected by the plummeting commitment ratio, may be implemented by the unembedding layer adjusting logits to reduce the probability of the correct token when the context implies an incorrect answer. The emergence of both phenomena only in larger models hints that sufficient capacity is required to develop this nuanced geometric strategy for representing and rejecting false facts.

## Foundational Learning
- **Forced-completion probing**
  - *Why needed*: To compare internal representations for the same query under different forced answer tokens, isolating the effect of correctness.
  - *Quick check*: Do both conditions share the identical query prefix? Yes.
- **Displacement vectors**
  - *Why needed*: To quantify how the hidden state moves away from the query-only representation in response to a continuation.
  - *Quick check*: Are displacement vectors computed per layer as \(d = h_{\text{cont}} - h_{\text{query}}\)? Yes.
- **Rotational divergence**
  - *Why needed*: To identify that the model encodes factual distinctions via directional changes while preserving norm magnitude.
  - *Quick check*: Is the norm ratio η close to 1 while the cosine between displacements (1-ρ) decreases? Yes.
- **Commitment ratio (κ)**
  - *Why needed*: To measure the model's explicit preference for the correct token after unembedding, indicating active suppression when low.
  - *Quick check*: Does κ near 0 indicate strong suppression of the correct token on the incorrect path? Yes.
- **Linear probing**
  - *Why needed*: To assess whether information about correctness is linearly decodable from each layer's residual state.
  - *Quick check*: Should probe accuracy be above chance (e.g., >0.55) to confirm signal? Yes, particularly for DC vs CTRL.

## Architecture Onboarding
**Component map**: Dataset → Tokenization → Forward Pass → Hidden State Extraction → Metric Computation → Probe Training → Statistical Analysis.

**Critical path**: 1) Prepare dataset with queries, answer tokens, keyword spans. 2) For each query, run three forward passes (query-only, correct, incorrect). 3) Extract last-token hidden states for all layers. 4) Compute M1–M5 metrics. 5) Train logistic regression probes per layer with 5-fold CV. 6) Compare across models and categories using statistical tests.

**Design tradeoffs**:
- Single-token answers simplify alignment but restrict the study to short factual answers; multi-token answers would require more complex alignment.
- Final normalization before unembedding is necessary for proper probability scaling, but differences in norm types (RMSNorm vs LayerNorm) across models may affect κ values.
- Linear probes are efficient and interpretable but may not capture nonlinear representations; deeper probes could improve accuracy but risk overfitting on 600 examples.
- Computing attention allocations relies on accurate character-to-token mapping; heuristic fallbacks may introduce noise.

**Failure signatures**:
- Displacement norm ratio η deviating substantially from 1 (e.g., <0.9 or >1.1) indicates numerical instability or tokenization mismatch.
- Probe accuracy near 0% or 100% suggests data leakage or memorization; a healthy peak around 0.7–0.85 is expected for DC vs CTRL.
- Commitment ratio κ consistently near 0.5 across layers implies the unembedding probabilities were not correctly computed (e.g., missing final norm).
- Attention allocation α showing no difference between correct/incorrect paths despite annotated keywords points to span-mapping errors.

**Three first experiments**:
1. **Tokenization verification**: Tokenize a sample query with correct and incorrect answers; confirm the answer token is a single identical ID and that the last token position aligns with the answer.
2. **Displacement geometry sanity check**: For one example, compute η(ℓ) and ρ(ℓ) across layers; expect η≈1 and increasing ρ for larger models, otherwise inspect casting and vector alignment.
3. **Probe baseline test**: Train a linear probe on the NEU category; accuracy should be ~0.5, confirming that the signal is specific to factual constraints and not superficial artifacts.

## Open Questions the Paper Calls Out
1. **Is rotational divergence specific to factual constraint processing?**
   - Basis in paper: The authors ask whether the observed rotational geometry generalizes to other categorical distinctions.
   - Why unresolved: Only factual queries in transport, medical, and financial domains were tested; other binary tasks were not examined.
   - What evidence would resolve it: Apply forced-completion probing to diverse binary tasks (e.g., subject-verb agreement, sentiment polarity) and compare displacement geometries.

2. **Does the mechanism persist during natural generation?**
   - Basis in paper: The paper explicitly states that bridging from forced-completion to autoregressive generation is a necessary next step not attempted.
   - Why unresolved: The method measured static states after a single forced token, not the dynamic token-by-token selection process.
   - What evidence would resolve it: Track the same geometric metrics during autoregressive decoding on similar factual queries, analyzing states immediately before each generated token.

3. **What is the exact parameter threshold for emergence?**
   - Basis in paper: The authors claim a phase transition around 1.6B but note the need for more systematic evaluation across dozens of scales.
   - Why unresolved: Only four models were compared (1.5B–13B), with a gap between the 1.5B and 1.6B models that could be due to architecture or insufficient sampling.
   - What evidence would resolve it: Evaluate a dense sequence of model sizes (e.g., 0.5B, 1.0B, 1.2B, 1.4B, 1.6B, 2.0B) from the same family with identical training data.

4. **How do architectural differences modulate emergence?**
   - Basis in paper: The paper suggests architectural differences (e.g., RMSNorm vs LayerNorm) might explain why the 1.5B model shows no phenomena.
   - Why unresolved: Model comparisons confound scale with architecture and training data; no controlled ablations were performed.
   - What evidence would resolve it: Conduct experiments on model variants with identical parameter counts but swapped architectural features (e.g., replace RMSNorm with LayerNorm).

## Limitations
- **Dataset non-disclosure**: The exact 300-query dataset (prompts, tokens, annotations) is not public; manual reconstruction can introduce variance in query distribution and token frequency.
- **Architectural confound**: The scale threshold might stem from architectural differences (e.g., Qwen2 1.5B vs StableLM-2 1.6B) rather than parameter count alone, limiting generalizability.
- **Probe specificity**: Linear probes may capture superficial lexical or positional cues instead of true "factual constraint processing"; the NEU control helps but may not fully disentangle confounds with only 600 examples.

## Confidence
- Rotational (isometric) divergence: **High**
- Active suppression (κ_min collapse): **Medium**
- Scale-dependent phase transition: **Low**

Replication of the primary patterns (η≈1, rising ρ, κ_min collapse for >1.6B) with statistical significance would validate the core findings despite different wording.

Verify that character-span annotations map to identical token ID sequences for correct and incorrect runs. Recompute attention allocation α using the verified spans; a significant change would indicate sensitivity to span mapping.
3. **Architectural Ablation via Parameter-Matched Models**: Identify a model family with releases at 1.5B, 1.6B, and 1.8B parameters (e.g., a LLaMA or Mistral variant). Run the protocol on all three sizes. If phenomena emerge strictly between 1.5B and 1.6B within the same architecture, it supports a sharp phase transition; if they correlate with an architectural change (e.g., new activation), the conclusion must be revised.
