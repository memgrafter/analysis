# Contrastive Learning for Multi Label ECG Classification with Jaccard Score Based Sigmoid Loss
## Quick Facts
- arXiv ID: 2602.10553
- Source URL: https://arxiv.org/abs/2602.10553
- Reference count: 32
- Primary result: Micro F1 score of 0.5028 achieved on real-world multi-label ECG classification using a modified SigLIP framework with Jaccard-based sigmoid loss.

## Executive Summary
This study addresses multi-label ECG classification using real-world hospital data, overcoming limitations of prior CLIP-based models that are single-label and rely on public datasets. The core method employs SigLIP with a modified Jaccard score-based sigmoid loss to handle label similarities among co-occurring ECG findings. Using a 1D ResNet-18 encoder and Qwen3-8B language model, along with increased embedding dimension (256) and random cropping, the model achieves a micro F1 score of 0.5028. This represents a significant gain from the modified loss (F1 from 0.0681 to 0.3082 over standard SigLIP) and benefits from medical knowledge in the language model (Qwen3-8B F1 0.3082 vs Gemma3-4B 0.2686). Per-label analysis shows high performance for atrial fibrillation (F1 0.8833) and low for ventricular tachycardia (F1 0.0000). Cross-institution tests indicate robustness with F1 mildly decreasing to 0.4841. The approach outperforms a ResNet-based multi-label classifier (F1 0.3799).

## Method Summary
The method adapts the SigLIP (sigmoid loss for language-image pre-training) framework to the multi-label ECG domain. Instead of the standard sigmoid cross-entropy loss, the authors introduce a Jaccard score-based sigmoid loss that accounts for similarities among co-occurring ECG findings, aiming to improve label representation. The encoder is a 1D ResNet-18 processing ECG signals, and the text encoder is a large language model (Qwen3-8B or Gemma3-4B) that processes medical reports or findings. The embedding dimension is set to 256 (higher than typical) to capture more nuanced features, and random cropping is applied as data augmentation. Training uses a contrastive approach where ECG and text embeddings are aligned in a shared space. The modified loss function is the key innovation, designed to handle the multi-label nature and label correlations present in real-world ECG data.

## Key Results
- Modified Jaccard sigmoid loss dramatically improves micro F1 from 0.0681 to 0.3082 over standard SigLIP.
- Final micro F1 of 0.5028, with per-label F1 ranging from 0.8833 (atrial fibrillation) to 0.0000 (ventricular tachycardia).
- Cross-institution test shows mild degradation to F1 0.4841, indicating some robustness; the approach also outperforms a ResNet-based multi-label classifier (F1 0.3799).

## Why This Works (Mechanism)
The Jaccard score-based sigmoid loss reweights the loss contribution for each ECG-text pair based on the Jaccard similarity of their label sets. **Assumption:** This encourages the model to learn embeddings where similarity in the embedding space correlates with label set overlap, directly addressing label co-occurrence and inter-dependencies in multi-label ECG data. The contrastive SigLIP framework then aligns these embeddings across modalities, with the modified loss providing a more appropriate training signal for the multi-label case than standard binary cross-entropy per label.

## Foundational Learning
The approach builds on contrastive vision-language pre-training (e.g., CLIP, SigLIP) by adapting its sigmoid loss formulation to the multi-label setting. Foundational concepts include:
- Contrastive learning: learning a shared embedding space where similar (ECG-text) pairs are attracted and dissimilar pairs are repelled.
- SigLIP: replaces the softmax-based contrastive loss with a sigmoid-based pairwise loss, which is more scalable and better for multi-positive training.
- Multi-label representation: extending binary classification to sets of labels, here using a Jaccard-based similarity metric to capture label set relationships.
**Unknown:** Exact theoretical justification for why Jaccard similarity in label space should directly optimize the embedding similarity metric used.

## Architecture Onboarding
- **Encoder (ECG):** 1D ResNet-18. Standard choice for 1D signal processing; depth provides feature hierarchy, but adaptation from 2D image pretraining is not discussed.
- **Text Encoder:** LLM (Qwen3-8B or Gemma3-4B). Leverages medical textual knowledge for generating embeddings from reports/findings. High parameter count may aid semantic capture but increases computational cost.
- **Embedding Dimension:** 256 (higher than common 512 or 768? Context needed). Hypothesis: larger dimension captures more nuanced ECG-text alignments.
- **Data Augmentation:** Random cropping applied to ECG signals. Standard for 2D images; effect on 1D temporal ECG data not analyzed.
- **Critical Path:** ECG ResNet → embedding → alignment with LLM text embedding via modified loss.
- **Design Tradeoff:** Using an LLM as text encoder provides rich semantics but is computationally heavy versus a smaller, trained text encoder. High embedding dimension may increase memory but could improve capacity.
- **Failure Signatures:** Not specified. Potential: poor performance on rare labels (e.g., ventricular tachycardia F1=0.0000) suggests representation collapse or insufficient samples for those conditions.
- **First Experiments:** Not specified. Likely: ablation of loss function (standard vs. Jaccard sigmoid), choice of LLM, embedding dimension.

## Limitations
- Low absolute micro F1 (0.5028) may limit clinical utility; error profile for critical labels unreported.
- Severe per-label variability (e.g., ventricular tachycardia F1=0.0000) suggests poor handling of rare labels or dataset imbalance.
- Cross-institution evaluation limited to one external site; generalizability across diverse hospitals unproven.
- Use of large LLMs (Qwen3-8B) raises deployment feasibility concerns in resource-constrained clinical settings.
- The mechanism of Jaccard loss improvement over standard multi-label losses is not thoroughly dissected; could be due to reweighting or specific label correlation handling.

## Confidence
- High: Relative improvement from modified Jaccard loss (0.0681 → 0.3082) and outperformance of ResNet baseline (0.3799).
- Medium: Absolute F1=0.5028 for real-world deployment; language model benefit (Qwen3-8B vs Gemma3-4B) attributed to medical knowledge but could be due to scale.
- Medium: Cross-institution robustness claim (single test site); generalizability unproven.
- Low: Mechanism behind Jaccard loss effectiveness; failure analysis for low-F1 labels not provided.
