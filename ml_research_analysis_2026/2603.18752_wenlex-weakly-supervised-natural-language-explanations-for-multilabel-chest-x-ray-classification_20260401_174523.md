# WeNLEX: Weakly Supervised Natural Language Explanations for Multilabel Chest X-ray Classification
## Quick Facts
- **arXiv ID:** 2603.18752  
- **Source URL:** https://arxiv.org/abs/2603.18752  
- **Reference count:** 40  
- **Primary result:** A weakly supervised framework that generates faithful and plausible natural language explanations for multilabel chest X-ray classification, achieving strong faithfulness (CLEV F1 9.615) and simulatability (0.354) with only 5 ground-truth NLEs per diagnosis, improving classifier AUC by 2.21% in the in-model setting, and enabling audience-adaptive explanations.

## Executive Summary
WeNLEX introduces a framework for generating natural language explanations (NLEs) for multilabel chest X-ray classifiers. It tackles the trade-off between faithfulness (does the NLE reflect the model’s true reasoning?) and plausibility (is the NLE clinically coherent?) through two key mechanisms: (1) **faithfulness via feature-space reconstruction**—generated NLEs are rendered into synthetic images that must match the original image’s features in the classifier’s latent space; (2) **plausibility via distribution alignment**—a small clinician NLE database (as few as 5 per diagnosis) guides the generator’s style without full supervision. The framework also adapts to different audiences (e.g., laypersons) by swapping this database. Results show robust faithfulness and simulatability, a 2.21% AUC gain when the classifier is trained jointly with the generator, and successful style transfer to simpler language while preserving core faithfulness metrics.

## Method Summary
WeNLEX uses a frozen multilabel DenseNet-121 classifier (MBE) and a frozen PubMedBERT text generator adapted via parameter-efficient modules (Vision-to-Adapter and Soft Prompt) to condition on image features, the full prediction vector, and the diagnosis label being explained. A trainable Text-to-Image module converts each generated NLE into a synthetic image. The training objective combines three losses: (1) **Plausibility loss** (MMD) aligns the distribution of generated NLE embeddings with a small set of clinician NLE embeddings; (2) **Reconstruction loss** (L2) minimizes the distance between original image features (from a frozen MBE copy) and the average features of synthetic images created from all generated NLEs for that input; (3) **Classification loss** (BCE) ensures synthetic images preserve the original diagnosis predictions. For in-model training, the classifier is jointly optimized with the generator. The framework enables audience adaptation by retraining the generator to match a different NLE distribution (e.g., simplified) while keeping the faithfulness constraints fixed.

## Key Results
- Achieves CLEV F1-score of 9.615 and simulatability (ˆy|NLE) of 0.354 using only 5 ground-truth NLEs per diagnosis.
- In-model training improves classifier AUC by 2.21% (from 65.13 to 67.34) compared to a standard classifier.
- A layman version maintains key faithfulness metrics (Δp within ~2–3 points) while increasing readability from college to 10th-grade level.

## Why This Works (Mechanism)
**Mechanism 1: Faithfulness via Feature-Space Reconstruction**  
- **Claim:** Generated NLEs are faithful because they describe visual patterns that, when rendered, activate the classifier similarly to the original image.  
- **Mechanism:** For each predicted diagnosis, the NLE generator produces an explanation `ê`. A trainable Text-to-Image module converts `ê` into a synthetic image `x̂`. A frozen copy of the MBE extracts features from `x̂`. The Reconstruction Loss minimizes the L2 distance between the original image’s features and the *average* of all `features(x̂)` for that input. This forces each `ê` to capture evidence that, collectively, reconstructs the classifier’s full reasoning.  
- **Break condition:** If the Text-to-Image module is too weak to generate images containing the specific visual features described, the loss becomes uninformative and NLEs may become abstract or rely on low-level textures.

**Mechanism 2: Plausibility via Distribution Matching**  
- **Claim:** Plausible (clinically sound, coherent) NLEs are produced by aligning the distribution of generated NLE embeddings with a small set of clinician-authored NLEs.  
- **Mechanism:** A frozen text encoder creates embeddings for a small clinician NLE database (e.g., 5 per diagnosis). The generator’s NLE embeddings are trained to match this distribution using Maximum Mean Discrepancy (MMD) or adversarial learning (WGAN-GP). MMD is simpler and yields better results.  
- **Break condition:** If the clinician database lacks diversity (e.g., repetitive phrasing), the generator may mode-collapse, producing generic or repetitive text that matches the distribution but lacks clinical specificity.

**Mechanism 3: Audience Adaptation via Database Swapping**  
- **Claim:** Explanations adaptable to different target audiences are produced by simply swapping the small NLE database used for plausibility alignment.  
- **Mechanism:** The generator is retrained to match the distribution of a new database where the same diagnostic concepts are expressed in a different style (e.g., lay language via GPT-4o). The faithfulness constraints (tied to the vision classifier) remain unchanged.  
- **Break condition:** If the target audience’s language requires a fundamentally different reasoning chain or set of salient features, style transfer alone may distort the reasoning and harm faithfulness.

## Foundational Learning
- **Concept: Weakly Supervised Distribution Matching**  
  - **Why needed:** Avoids costly per-image NLE supervision; learns from a small set of NLEs *per diagnosis label* by aligning distributions (MMD/adversarial) rather than token-level cross-entropy.  
  - **Quick check:** Minimizing MMD between `embed(G)` (generator sentences for "pneumonia") and `embed(H)` (small human set) incentivizes `G` to cover the same semantic/linguistic space as `H`, not to copy specific sentences.

- **Concept: Faithfulness via Counterfactual Reconstruction (Feature-Space)**  
  - **Why needed:** Standard metrics (BLEU) measure plausibility, not whether the NLE reflects the model’s reasoning. Reconstruction in the classifier’s feature space enforces self-consistency: a model that sees *only* the NLE (via rendered image) should behave like the original.  
  - **Quick check:** Why average synthetic features from all pathology-specific NLEs? Because the original image features encode evidence for *all* predicted pathologies combined; averaging approximates this combined evidence.

- **Concept: Multimodal Parameter-Efficient Fine-Tuning (PEFT) with Soft Prompts**  
  - **Why needed:** The frozen text-only generator must ingest image features, the full prediction vector, and the diagnosis text. PEFT (Vision-to-Adapter, Soft Prompt) learns small pathways to inject these signals without altering the pretrained Transformer.  
  - **Quick check:** Why not concatenate new modalities directly to text embeddings? The encoder wasn’t pretrained to interpret such concatenated vectors; PEFT maps new signals into the model’s expected input manifold.

## Architecture Onboarding
**Component map:**  
MBE (DenseNet-121) -> NLE Generator (frozen PubMedBERT + Vision-to-Adapter + Soft Prompt) -> NLE Text  
NLE Text -> Text-to-Image (CNN) -> Synthetic Image  
Synthetic Image -> MBE (frozen copy) -> Features  
Clinician NLE Database -> NLE Encoder (frozen PubMedBERT) -> Clinician Embeddings  
NLE Generator -> NLE Encoder -> Generated Embeddings  
Generated Embeddings and Clinician Embeddings -> Plausibility Loss (MMD)  
Features and Original Features -> Reconstruction Loss (L2)  
MBE output for synthetic image -> Classification Loss (BCE)

**Critical path (post-hoc training):**  
1. For batch `x`, get predictions `ŷ` and `features(x)` from frozen MBE.  
2. For each positive/uncertain diagnosis in `ŷ`, generate `ê` using the adapted NLE Generator.  
3. Compute Plausibility Loss (MMD) between batch of `ê` embeddings and pre-loaded clinician NLE embeddings for those diagnoses.  
4. Convert each `ê` to `x̂` via Text-to-Image; get `features(x̂)`.  
5. Compute Reconstruction Loss: L2( avg(`features(x̂)`), `features(x)` ).  
6. Get MBE prediction for each `x̂`; compute Classification Loss (BCE) against original `ŷ` for that diagnosis.  
7. Weighted sum of steps 3,5,6 updates only PEFT modules and Text-to-Image.

**Design tradeoffs:**  
- **MMD vs. WGAN-GP:** MMD is simpler, more stable, and outperformed adversarial (Table 1). WGAN-GP introduces a fragile discriminator.  
- **Reconstruction layer:** `denseblock2` (dim 401408) was chosen via ablation for best faithfulness-diversity trade-off. Higher layers hurt diversity; lower layers are more expensive.  
- **MBE copy for in-model:** A frozen copy prevents instability; the real classifier updates only via backprop through `T2I` and generator. The copy is synced every 1000 steps.

**Failure signatures:**  
- **Low CLEV / ˆy|NLE:** Check MMD convergence, database diversity, generator degeneracy.  
- **High Self-BLEU / Low diversity:** Mode collapse; likely from overly strong plausibility loss or weak reconstruction.  
- **Low AUC (in-model) vs. baseline:** Joint optimization may harm classification; verify loss weighting and conflicting gradients.  
- **Layman version low ˆy|NLE:** Style shift may have moved NLEs beyond the simulant’s (CheXagent’s) semantic understanding.

**First 3 experiments:**  
1. **Loss component ablation:** Train post-hoc models with only (a) MMD, (b) Reconstruction, (c) Classification losses. Compare to Table 1 (models 3,4,5) to isolate contributions and tradeoffs.  
2. **Database size sensitivity:** Train with 2, 5, 10, 20 clinician NLEs per diagnosis. Confirm performance plateaus around 5 and that 2 NLEs causes collapse (higher Self-BLEU, lower ˆy|NLE).  
3. **Layman adaptation:** Retrain using GPT-4o simplified database. Inspect 10 NLEs for 3 diagnoses, compute readability (textstat), and run simulatability metrics. Verify readability drops (~grade 10) and faithfulness metrics remain within ~2–3 points of medical version.

## Open Questions the Paper Calls Out
**Open Question 1:** What is the minimum number of ground-truth NLEs per diagnosis required? The paper tested 2–20 but not 1 or 0. Could fewer or zero NLEs work with adaptations?  
**Open Question 2:** How does the periodic update (every 1000 steps) of the frozen classifier copy in the in-model setting impact training stability and performance? Is this heuristic optimal?  
**Open Question 3:** Do the automatically simplified layman NLEs (via GPT-4o) match human-written lay explanations in understandability and clinical fidelity? The paper only measures readability and CheXbert-based plausibility.  
**Open Question 4:** Why does joint training improve classification AUC by 2.21%? Possible reasons include regularization or better feature sharing, but the mechanism is unanalyzed.

## Limitations
- **Underspecified details:** Text-to-Image architecture (exact transposed conv parameters) and automatic loss weighting (Cipolla et al.) are not fully described, blocking exact replication.  
- **Unverified core assumptions:** (1) The MBE’s feature space disentangles pathology evidence; (2) 5 clinician NLEs capture the plausible distribution; (3) Style is fully separable from reasoning for audience adaptation. Break conditions exist but are untested.  
- **Metric dependency:** Simulatability relies on CheXagent, whose clinical fidelity is unknown.

## Confidence
- **Faithfulness via feature reconstruction:** Medium. Ablations show benefit, but Text-to-Image limitations could degrade results.  
- **Plausibility via MMD distribution matching:** High. Consistently outperforms adversarial and boosts CXBS plausibility.  
- **Adaptability to audiences:** Medium. Layman version improves readability but reduces simulatability; style shift may not preserve reasoning.  
- **Reported quantitative gains (CLEV 9.615, ˆy|NLE 0.354, AUC +2.21%):** Medium-High. Metrics are clear but absolute simulatability is low; replication is hindered by unknowns.

## Next Checks
1. **Text-to-Image replication:** Implement exact transposed conv parameters (kernel/stride/padding) to output 224×224, train from scratch, and measure generated image quality (FID) and downstream CLEV/ˆy|NLE.  
2. **Reconstruction design ablation:** Compare using average synthetic features vs. individual NLE features; test feature extraction from different DenseNet blocks (denseblock1–3, classifier) on the faithfulness-diversity trade-off.  
3. **Audience adaptation stress test:** For the layman model, conduct clinical expert evaluation of NLE accuracy; test with only 2 NLEs/diagnosis in the style database; measure simulatability using a layperson-focused simulator (e.g., GPT-4 as layperson).
