# Differentiable Time-Varying IIR Filtering for Real-Time Speech Denoising

## Quick Facts
- **arXiv ID:** 2603.02794  
- **Source URL:** https://arxiv.org/abs/2603.02794  
- **Reference count:** 0  
- **Primary result:** A 1.01M‑parameter real‑time denoising model that achieves PESQ 2.14, POLQA 3.50, SI‑SDR 13.71 dB, MOS‑Overall 2.64 with 21 ms latency.

## Executive Summary
TVF is a lightweight neural architecture for real‑time single‑channel speech denoising. It predicts time‑varying coefficients for a cascade of 35 differentiable IIR biquad filters, combining the interpretability and stability of classic DSP with the adaptivity of deep learning. The model processes 48 kHz audio in 21 ms frames, using a CNN‑GRU backbone to output filter parameters that are applied in a serial Direct Form I implementation. Trained on the Valentini‑Botinhao dataset with dynamic mixing, TVF achieves state‑of‑the‑art perceptual quality (PESQ 2.14, POLQA 3.50, MOS‑Overall 2.64) and comparable SI‑SDR (13.71 dB) to larger models while maintaining strict latency constraints. The system’s core innovation lies in its time‑varying linear filtering, which avoids unnatural artifacts common in unconstrained neural waveform models.

## Method Summary
The method uses a neural backbone to predict parameters for a differentiable IIR filter cascade. Input audio at 48 kHz is divided into non‑overlapping 1024‑sample frames (21 ms). Per frame, a 513‑bin STFT magnitude spectrum is computed. Two 1D convolutional layers (stride 2, kernel 5) followed by a 2‑layer GRU (256 hidden units) process the spectrum and produce 105 outputs, which are scaled to physical ranges: gain in [–20, 20] dB, quality in [0.1, 2.0], and center frequencies with hybrid linear (below 1 kHz) / logarithmic spacing. These parameters define 35 biquad sections (1 low‑shelf, 33 band‑pass, 1 high‑shelf) arranged in a serial cascade. During training, a systolic vectorization collapses the nested recurrence into a parallel operation, accelerating computation; inference uses a serial Direct Form I implementation to keep latency at 21 ms. The loss combines multi‑scale logarithmic spectral distance with a scaled time‑domain MSE. Training uses Adam (lr = 1e‑3, batch 64) for 100 epochs on data generated by dynamically mixing clean speech and noise at SNRs {–5, 0, 5, 10, 20, 40, 100} dB. A static PEQ baseline with global average pooling (non‑causal) serves for comparison.

## Key Results
- Achieves PESQ 2.14, POLQA 3.50, SI‑SDR 13.71 dB, MOS‑Overall 2.64 on the Valentini‑Botinhao test set.
- Surpasses the static PEQ baseline and matches DFNet3 on perceptual metrics while using fewer parameters (1.01 M vs. 2.31 M).
- Maintains 21 ms latency and shows effective spectral adaptation to non‑stationary noise.

## Why This Works (Mechanism)

### Mechanism 1
A lightweight neural backbone predicts time‑varying biquad coefficients, enabling adaptive spectral shaping while maintaining a fully interpretable, linear filtering operation. The backbone processes frame‑wise magnitude spectra to output gain, quality, and center frequency for 35 filters; these are mapped to IIR coefficients (`b_i`, `a_i`) to construct a cascade. The core assumption is that the inductive bias toward linear time‑domain filtering prevents unnatural artifacts, especially in data‑scarce scenarios.

### Mechanism 2
A systolic‑vectorized implementation of the biquad cascade enables efficient training, while a serial Direct Form I implementation maintains low inference latency. The vectorized formulation collapses the \(K \times N\) nested recurrence (K filters, N frames) into a depth \(N+K-1\) parallel operation during training; inference uses a standard serial loop to avoid the 35‑frame algorithmic latency. This design relies on exact equivalence between the two computation paths for gradient flow.

### Mechanism 3
Temporal smoothing via a GRU ensures continuous evolution of filter coefficients over time, preventing sudden frequency response discontinuities that could cause audible clicks or pumping artifacts. The GRU’s hidden state provides memory across frames, causing its outputs to change gradually. This mechanism assumes that smooth coefficient trajectories are sufficient to avoid perceptible transients in a linear IIR cascade operating at 48 kHz with 21 ms frames.

## Architecture Onboarding

**Component map:**  
Input Parser → Spectral Extractor → Neural Backbone → Parameter Mapper → Biquad Cascade → Output Reassembler

**Critical path:**  
Audio frame → (Parallel CNN/GRU) → 105 parameters → 35× Direct Form I biquads (serial) → Output frame. The GRU hidden state persists across frame boundaries.

**Design tradeoffs:**  
- Interpretability vs. Flexibility: Linear IIR filters are interpretable and stable but cannot perform phase reconstruction like complex STFT masks, limiting waveform fidelity (SI‑SDR).  
- Training Speed vs. Inference Latency: Systolic vectorization accelerates training by ~35× but adds 35‑frame look‑ahead; serial inference meets 21 ms latency.  
- Parameter Count vs. Performance: 1.01 M parameters (mostly GRU) vs. DFNet3’s 2.31 M. TVF trades parameter efficiency for perceptual quality.  
- Band Spacing: Linear spacing below 1 kHz (high resolution for speech fundamentals) vs. logarithmic/wider above (efficiency). This is a fixed design choice, not learned.

**Failure signatures:**  
- Clicks/Pops: Abrupt parameter changes (GRU failure) or numerical instability in Direct Form I (check state propagation).  
- Speech Attenuation/Bleeding Noise: Poor gain calibration across bands; gains stuck at extremes.  
- High‑Frequency Degradation: Over‑attenuation of high‑frequency speech, possibly due to high‑shelf filter settings.  
- Training Divergence: If final layer not initialized near 0 dB gain, model may fail to learn “pass‑through” behavior early.

**First 3 experiments:**  
1. **Baseline Sanity Check:** Run the static PEQ baseline on a known clean+noise file. Verify it applies a fixed frequency response and improves PESQ over unprocessed.  
2. **Temporal Smoothness Test:** Input a pure sine wave swept across frequency. Visualize predicted gain vs. frequency over time. Should show smooth trajectories without sudden jumps.  
3. **Latency Verification:** Measure round‑trip latency of the serial biquad cascade for a 1‑second impulse. Confirm it is ~21 ms (1024 samples @ 48 kHz) and not inflated by state handling.

## Open Questions the Paper Calls Out

1. **How does TVF’s performance compare to state‑of‑the‑art denoisers when trained on large‑scale datasets?**  
   *Basis:* The paper’s conclusion explicitly mentions future work on larger datasets.  
   *Why unresolved:* The current study uses the small Valentini‑Botinhao dataset (~19 hours), not the thousands of hours typical for SOTA.  
   *Resolving evidence:* Train TVF on a large corpus (>1000 hours) and evaluate against SOTA models trained on comparable data.

2. **How can the trade‑off between noise suppression and speech preservation be refined through loss function and architecture optimization?**  
   *Basis:* The paper notes future work on optimizing architecture and loss.  
   *Why unresolved:* The present loss uses fixed weighting (time‑domain MSE scaled by 5e‑4); the optimal balance for perceptual quality remains unknown.  
   *Resolving evidence:* Systematically vary loss components (e.g., multi‑resolution spectral, adversarial terms) and architectural choices, measuring impacts on SI‑SDR, PESQ, and MOS.

3. **Can TVF be effectively extended to stereo and multi‑channel audio processing?**  
   *Basis:* The paper’s conclusion explicitly proposes exploring multi‑channel extensions.  
   *Why unresolved:* The current model processes only single‑channel audio; spatial cues and inter‑channel dependencies are unaddressed.  
   *Resolving evidence:* Adapt TVF to predict channel‑dependent or spatially‑aware filter coefficients, test on multi‑channel datasets (e.g., CHiME), and report performance and complexity.

## Limitations
- Exact filter band specifications (center frequencies, bandwidths) are not fully detailed due to the hybrid linear/log spacing description, hindering precise replication.  
- Evaluation details (POLQA version, SIGMOS model, any preprocessing such as resampling or clipping) are unspecified, potentially affecting reported metric values.  
- Generalization to highly non‑stationary or impulsive noise is uncertain, as the Valentini‑Botinhao dataset primarily contains stationary noises.

## Confidence
- **High Confidence:** Architecture description (backbone, biquad cascade, Direct Form I) is explicit and coherent; the 21 ms latency claim directly follows from the frame size.  
- **Medium Confidence:** Reproduction of reported metrics depends on unknown loss/eval details and potential implementation drift; the GRU smoothing mechanism is plausible but not exhaustively validated for all transient scenarios.  
- **Low Confidence:** Extrapolating performance to real‑world, highly non‑stationary noise environments; the hybrid band‑spacing rationale is described but not quantitatively justified against alternatives.
