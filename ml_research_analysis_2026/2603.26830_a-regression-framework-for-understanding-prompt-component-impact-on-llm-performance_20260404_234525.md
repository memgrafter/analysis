# A Regression Framework for Understanding Prompt Component Impact on LLM Performance
## Quick Facts
- **arXiv ID:** 2603.26830
- **Source URL:** https://arxiv.org/abs/2603.26830
- **Reference count:** 40
- **Primary result:** The IAMs regression framework explains 72% (Mistral-7B) and 77% (GPT-OSS-20B) of performance variation, revealing that misinformation via incorrect examples significantly degrades performance and that higher-order interactions can soften this negative impact.

## Executive Summary
The paper introduces IAMs (Interpretable Attribution of Prompt Components via Regression), a framework that quantifies the impact of individual prompt components on large language model (LLM) performance using stratified regression. By decomposing prompts into mutually exclusive strata and encoding component inclusion as binary features, the authors fit linear models to predict a performance metric (DCPMI) on an arithmetic task. Applied to Mistral-7B and GPT-OSS-20B, first-order models explain over 70% of variance, while forward-selected interaction models uncover complex synergies, such as the softening effect of multiple false examples. The framework also employs adjusted Shapley values for model-agnostic attribution, validated by high correlation with regression coefficients.

## Method Summary
The authors stratify a prompt into 12 disjoint sets: one static query ("3+2=") and 11 variable strata (7 instruction choices and 10 example query-answer pairs). They generate all 8,192 subprompts by combining one element from each stratum. For each subprompt and each model, they compute the DCPMI score, defined as the ratio of the token probability for "5" in the subprompt to that in the query-only prompt. The design matrix `X` is constructed via one-hot encoding of each stratum’s components, optionally extended with interaction terms (up to 4th order among the example strata). Regression models (first-order, L1-regularized, and forward-selected with hierarchical constraints) are fit to explain DCPMI variation. The forward-selection algorithm adds main effects first, then interactions only if lower-order terms are present, using Bonferroni-corrected p-value thresholds. The framework’s validity is checked by correlating first-order coefficients with adjusted Shapley values.

## Key Results
- First-order linear models explain 72% (Mistral-7B) and 77% (GPT-OSS-20B) of performance variation.
- Including incorrect examples (misinformation) as components consistently reduces model performance.
- Higher-order interaction models reveal that combining multiple false examples can soften the negative impact of individual misinformation (positive interaction terms).

## Why This Works (Mechanism)
### Mechanism 1: Stratified Regression Quantifies Component Effects
The framework partitions the prompt into mutually exclusive strata (e.g., instruction, examples). Each component within a stratum is encoded as a binary dummy variable (1 if included, 0 if omitted). A linear regression `y = β0 + Σ βl,j xl,j + ε` then estimates the average change in the performance metric (DCPMI) attributable to each component, holding others constant. This decomposition assumes that component effects are approximately additive and linear on the DCPMI scale, and that the strata definition respects the prompt’s logical independence. Evidence: The first-order models achieve high R² (0.72–0.77), confirming that main effects capture most variation. The approach breaks down if true effects are highly nonlinear or if strata force unnatural splits that overlap semantically.

### Mechanism 2: Hierarchical Forward-Selection Uncovers Interactions
To identify synergistic effects (e.g., the softening of misinformation), the authors employ a forward-selection algorithm that respects hierarchy: main effects must be present before interactions containing them are considered. Starting from an intercept-only model, they iteratively add first-order terms that meet a Bonferroni-corrected significance threshold. For each interaction level `g = 2,3,4`, they then consider all `g`-way interactions among already-selected lower-order terms from the example strata, adding those that pass the corrected threshold. This yields parsimonious models where, for instance, a positive second-order interaction between two false examples indicates that their combined negative impact is less than the sum of individual impacts (softening). The hierarchical constraint ensures interpretability and controls false discoveries. The method would miss meaningful higher-order interactions that lack corresponding main effects (non‑hierarchical true model) or be overly conservative if many tests inflate the Bonferroni penalty.

### Mechanism 3: Adjusted Shapley Values for Categorical Components
Standard Shapley values allocate contribution fairly across all feature coalitions, but in IAMs, components from the same stratum are mutually exclusive (only one can appear due to one‑hot encoding). The adjustment modifies the coalition count `k_i` in the Shapley formula to consider only feasible coalitions where the component can appear. This respects the categorical constraint while still providing a model‑agnostic, game‑theoretic attribution. The resulting adjusted Shapley values correlate extremely highly (r = 0.969–0.997) with first-order regression coefficients, confirming that the linear model’s additive assumption is approximately valid and that the adjustment correctly accounts for the one‑hot structure. The method would become inaccurate if additional, unmodeled constraints on component combinations exist or if the number of strata/combinatorial possibilities makes the Shapley computation intractable.

## Foundational Learning
- **Multiple Linear Regression & L1 Regularization** – IAMs fits `y = Xβ + ε`. With many potential predictors (including interactions), L1 regularization (LASSO/elastic‑net) performs feature selection by driving irrelevant coefficients to zero, improving generalization and interpretability. *Quick check:* Why does L1 help even when we have evaluated all subprompts? It guards against overfitting to noise and selects a parsimonious set of truly influential components.

- **One‑Hot Encoding for Categorical Predictors** – Prompt components within a stratum are categorical (e.g., different instructions). One‑hot creates a binary variable per level (except a reference), allowing the regression to estimate separate effects for each specific choice relative to omission. *Quick check:* If stratum `p1` has `{instr_A, instr_B}` and we include a dummy for `instr_A`, what does its coefficient represent? The average DCPMI change when `instr_A` is used instead of the baseline (no instruction from that stratum, i.e., empty string).

- **Statistical Interaction in Regression** – Interaction terms (products of binary variables) capture non‑additive synergies between components. For example, the "softening" effect arises when the interaction coefficient for two false examples is positive, meaning their combined impact is less damaging than the sum of their individual harms. *Quick check:* If β_A = -0.5, β_B = -0.5, and β_AB = +0.8, the predicted combined effect of A and B (relative to neither) is -0.5 -0.5 +0.8 = -0.2 (still negative but less severe than -1.0). This softening is indicated by the positive interaction term.

## Architecture Onboarding
- **Component map:** Prompt Stratification Config -> Subprompt Generator -> LLM Scorer -> Design Matrix Builder -> Regression Engine -> Analyzer/Visualizer
- **Critical path:** The workflow is linear: define strata → generate all subprompt combinations → score each subprompt with the LLM → build the binary (and interaction) design matrix → fit the regression model (or run forward selection) → extract coefficients/Shapley values and produce visualizations.
- **Design tradeoffs:**
  - *LASSO vs. Forward‑Selection:* LASSO automates selection but may arbitrarily choose one among correlated predictors and does not enforce hierarchy. Forward‑selection respects hierarchy (interactions only if main effects present) and uses statistical tests, yielding more theory‑consistent models but requires tuning significance thresholds.
  - *Score choice:* DCPMI (continuous) provides richer signal but needs open‑model token probabilities; binary correctness works with closed‑model APIs but discards gradated information.
  - *Interaction order:* Including higher‑order interactions (up to 4th) captures complex combinatorial effects like softening but exponentially increases parameters (e.g., 375 interactions among 10 examples), raising overfitting risk and computational cost.
- **Failure signatures:**
  - *Poor first‑order fit:* Low adjusted R² and high residuals in the main‑effects model suggest strong interactions are present.
  - *No interactions selected:* If either LASSO or forward‑selection yields only main effects despite low first‑order R², the interaction structure may be too noisy or nonlinear to be captured by polynomial terms.
  - *Inconsistent Shapley vs. coefficients:* A low correlation between adjusted Shapley values and first‑order coefficients would indicate a violation of the additivity assumption or a mis‑specification of the Shapley adjustment.
  - *All coefficients share the same sign:* A dominance of uniformly negative (or positive) coefficients suggests the baseline prompt is atypical or that most components have a uniform impact, limiting interpretative nuance.
- **First three experiments:**
  1. **Baseline Query Only:** Run the bare query "3+2=" through the LLM and compute the DCPMI baseline. This establishes the intercept reference.
  2. **First‑Order Component Sweep:** For each variable stratum, run subprompts that include only that component (plus the query). Manually compute the DCPMI change to approximate each component’s main effect before full regression.
  3. **Pairwise Interaction Spot‑Check:** Choose two components (e.g., two false examples), run the four subprompts (neither, A only, B only, both), and compute the interaction contrast `score(A&B) - score(A) - score(B) + score(neither)`. Compare this empirical estimate to the interaction coefficient from a model with just those two predictors.

## Open Questions the Paper Calls Out
1. **Generalization across models and tasks:** How do prompt component effects vary with different LLM architectures, sizes, and beyond the single arithmetic task studied?
2. **Applicability to closed‑source LLMs:** Can IAMs be effectively used when only output text (no token probabilities) is available, and what scoring strategies work best?
3. **Mechanism of the softening effect:** What underlying causes make multiple false examples reduce the individual harm of misinformation? Is it a form of saturation, redundancy, or a shift in model attention?

## Limitations
- The exact string formatting of instructions and examples is unspecified, making exact tokenization-sensitive replication fragile.
- The forward‑selection procedure’s Bonferroni correction thresholds (α_g) are not detailed, hindering precise reproduction of the interaction models.
- The study is limited to two open‑source models and one arithmetic query; conclusions may not generalize to other models, sizes, or tasks.

## Confidence
- *Misinformation drastically reduces performance:* **High** (consistent strong evidence across models and analyses).
- *Positive instructions have model‑specific effects:* **Medium** (depends on model and exact specification; some variation observed).
- *GPT‑OSS‑20B is more prompt‑sensitive than Mistral-7B:* **Medium** (based on R² and coefficient spread, but limited to these two models).
- *Higher‑order interactions soften misinformation:* **Medium** (observed in forward‑selection results but stability untested; could be sensitive to α thresholds).

## Next Checks
1. **Empirical main‑effect verification:** Compute the average DCPMI for each component when used alone and compare to the reported first‑order coefficients to validate direction and magnitude.
2. **Interaction stability under α variation:** Re‑run the forward‑selection with different Bonferroni thresholds and check whether the softening interactions (positive estimates among false examples) persist and which terms are consistently selected.
3. **Shapley‑coefficient correlation:** Implement the adjusted Shapley calculation as described, compute values for all main effects, and verify that the Pearson correlation with first‑order regression coefficients exceeds 0.95, confirming the modeling assumption.
