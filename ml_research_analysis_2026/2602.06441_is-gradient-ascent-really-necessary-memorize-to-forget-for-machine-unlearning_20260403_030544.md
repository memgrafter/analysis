# Is Gradient Ascent Really Necessary? Memorize to Forget for Machine Unlearning

## Quick Facts
- **arXiv ID**: 2602.06441
- **Source URL**: https://arxiv.org/abs/2602.06441
- **Reference count**: 40
- **Primary result**: MOX replaces gradient ascent with a two-step memorize‑then‑extrapolate process, achieving significantly higher forget quality while preserving model utility.

## Executive Summary
The paper tackles catastrophic collapse and utility degradation in machine unlearning for LLMs when using gradient ascent (GA). It proposes MOX (Model Extrapolation), a method that avoids GA entirely. MOX first uses gradient descent to memorize the forget set while preserving retain set performance via KL regularization, yielding a memorization model. It then linearly extrapolates from this memorization model toward the original reference model to obtain the forget model. On TOFU and MUSE benchmarks, MOX attains much higher forget quality (e.g., FQ up to 0.0625 on Llama2‑7B with α=4.0) compared to GA‑based approaches, while maintaining model utility (~0.65) and retain set performance (>0.96). The approach also shows robustness to hyperparameters, stability, and negligible extra compute.

## Method Summary
MOX operates in two sequential steps. First, starting from the original reference model θ_ref, it applies gradient descent on the forget set D_F to overfit those data, while simultaneously applying a KL‑divergence penalty between the current model and θ_ref on the retain set D_R. This produces a memorization model θ_mem that has strongly learned D_F yet remains close to θ_ref on D_R. Second, the forget model θ_for is obtained by linear extrapolation: θ_for = (1+α)θ_ref – αθ_mem, where α controls forgetting strength. Optionally, momentum can smooth the extrapolation. The process uses only gradient descent (no ascent) and a deterministic parameter combination, sidestepping instability.

## Key Results
- Forget quality (FQ) reaches 0.0625 on Llama2‑7B (α=4.0), far surpassing GA‑based baselines.
- Model utility (MU) remains high (~0.65) and retain set performance (R‑RL >0.96) is preserved.
- The method exhibits hyperparameter stability, resistance to catastrophic collapse, and minimal computational overhead.

## Why This Works (Mechanism)

**Mechanism 1: Memorization as a controllable dual**
Gradient descent on the forget set with KL regularization yields a memorization model θ_mem that overfits D_F while staying close to the reference on D_R. The direction θ_mem – θ_ref encodes increased memorization; the opposite θ_ref – θ_mem disentangles that knowledge. Extrapolating as θ_for = (1+α)θ_ref – αθ_mem thus produces an “un‑memorized” model. Core assumption: linear parameter‑output relationship (NTK regime). Evidence: abstract and section 2.3; break conditions include insufficient memorization or high semantic overlap between D_F and D_R.

**Mechanism 2: Avoiding gradient ascent avoids catastrophic collapse**
Gradient ascent on the forget set causes unbounded updates, leading to degenerate predictions (catastrophic collapse). Gradient descent, under smoothness and PL conditions, monotonically decreases loss and converges to a global minimum with positive entropy if data is diverse, thus cannot collapse. The paper formalizes collapse (Def. 2.4) and proves GD avoids it under these assumptions. Empirical evidence (Figure 1) shows GA causes large performance degradation and deviation, while GD remains stable; related work corroborates. Break condition: if PL fails, GD may converge slowly but collapse remains unlikely.

**Mechanism 3: Extrapolation strength α controls trade‑off**
Larger α moves θ_for farther from θ_mem in the opposite direction of memorization, increasing forgetting at a modest utility cost. Because θ_mem is constrained near θ_ref on D_R, moderate α preserves utility; too large α may overshoot the linear regime, harming both forget quality and utility. Evidence: Figure 3 and Table 1 show FQ increases with α up to ~4 then degrades, while utility gradually declines. Break condition: extreme α breaks linearity; weak memorization yields no proportional forgetting gain.

### KL‑Divergence Regularization
- **Why needed here**: The memorization objective uses KL between reference and current model on the retain set to preserve utility while overfitting to the forget set.
- **Quick check**: What would happen if the KL regularization weight in L_mem were set to zero? How does that affect the forget‑utility trade‑off?

### Model Extrapolation (Task Arithmetic)
- **Why needed here**: The final forgetting step is a linear combination of the reference and memorization models; this concept explains how opposite directions achieve forgetting.
- **Quick check**: If θ_mem – θ_ref is the ‘memorization vector’, why does θ_ref – (θ_mem – θ_ref) = 2θ_ref – θ_mem approximate un‑learning? How does α adjust this?

## Architecture Onboarding

**Component map**  
ReferenceModel -> MemorizationTrainer -> Extrapolator (with optional MomentumBuffer)

**Critical path**  
1. Load θ_ref.  
2. Initialize θ_mem ← θ_ref.  
3. For each training step:  
   - Compute L_CE(θ_mem, D_F).  
   - Compute KL(θ_ref || θ_mem) on D_R.  
   - Backpropagate and update θ_mem via AdamW.  
   - (Optional) Update θ_for ← extrapolate(θ_ref, θ_mem, α) and apply momentum update.  
4. After training, return final θ_for (or momentum‑smoothed).

**Design tradeoffs**  
- α: larger α improves forgetting but risks utility; typical 0.5–8.  
- KL weight λ: balances memorization vs retain utility; implicit scaling.  
- Extrapolation frequency: compute once at end or continuously (momentum); momentum (η≈0.675) often helps.  
- Objective choice: cross‑entropy vs. preference‑based (PO/NPO) for memorization; CE is simpler.

**Failure signatures**  
- Low forget quality (high loss on D_F): α too small or memorization under‑trained (increase epochs/lr). Check θ_mem loss on D_F.  
- Utility drop on D_R: α too large or KL weight too low. Monitor KL divergence.  
- Training divergence: learning rate too high for GD; reduce lr.  
- Collapse (constant predictions): rare with GD; if observed, suspect PL condition violation (e.g., non‑diverse D_R); increase capacity or regularization.

**First 3 experiments**  
1. Baseline comparison: Run MOX (α=4, momentum on) vs. GA, NPO, TV on TOFU/MUSE. Report FQ, MU, F‑RL, R‑RL. Expect MOX to outperform on FQ with comparable MU.  
2. Ablation study: Disable components: (a) GD only (no KL), (b) GD+KL, (c) GD+target, (d) GD+KL+target. Verify KL improves retain performance and target (α) improves forgetting.  
3. Parameter sweep: Vary α ∈ {0.5,1,2,4,8} and momentum η ∈ {0,0.5,0.675,0.9}. Plot FQ and MU to confirm sensitivity: FQ increases with α up to a point, MU degrades gradually; η has minor effect.

## Limitations
- Linear extrapolation (NTK regime) may break for large α or across diverse architectures.
- Theoretical assumptions (smoothness, PL conditions) may be violated in high‑dimensional LLM loss landscapes.
- Evaluation confined to small Llama2‑7B on synthetic benchmarks; generalization to larger models and real‑world unlearning tasks is unknown.

## Confidence
- **MOX outperforms GA baselines in forget quality**: High
- **Memorization model acts as a controllable dual enabling forgetting via linear extrapolation**: Medium
- **Gradient descent avoids catastrophic collapse under smoothness/PL assumptions**: High
- **MOX is robust to hyperparameter choices**: Medium
