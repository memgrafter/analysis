# When Perplexity Lies: Generation-Focused Distillation of Hybrid Sequence Models

## Quick Facts
- **arXiv ID**: 2603.26556
- **Source URL**: https://arxiv.org/abs/2603.26556
- **Reference count**: 40
- **Primary result**: Cross-architecture distillation using generation-based evaluation (GenDistill) with Hybrid-KDA yields models that retain 86-90% teacher accuracy on knowledge benchmarks while reducing KV cache memory by up to 75% and improving time-to-first-token by 2-4× at 128K-token contexts.

## Executive Summary
The paper identifies a critical flaw in evaluating distilled sequence models: perplexity-based metrics often obscure large gaps in actual generation quality. To address this, the authors propose Hybrid-KDA, a hybrid architecture combining transformer attention with the linear sequence mixer KDA, and GenDistill, a multi-stage distillation pipeline guided by generation-based evaluation. Systematic ablations on a 0.6B parameter model show that perplexity consistently underestimates teacher-student gaps and can even reverse design rankings. The optimal recipe consists of knowledge distillation with completion-only masking, teacher-aligned instruction data, and frozen attention layers during post-training. The resulting model achieves near-teacher accuracy (86–90%) on knowledge benchmarks while delivering substantial efficiency gains: up to 75% reduction in KV cache memory and 2–4× faster time-to-first-token at 128K contexts. However, long-context performance remains a significant gap, and the scalability of the recipe to larger models is an open question.

## Method Summary
GenDistill is a three-stage pipeline. First, the student model undergoes standard knowledge distillation on a mixture of teacher-aligned instruction data, combining logits and hidden-state losses. Crucially, they use completion-only masking, where loss is computed only on generated tokens (the completion) and not on the instruction prompt. Second, post-training is performed with attention layers frozen, allowing only the linear mixer and other components to adapt. Evaluation is generation-centric, focusing on accuracy on knowledge QA and efficiency metrics (KV cache size, latency) across long contexts. The Hybrid-KDA architecture interleaves multi-head self-attention layers with KDA (a linear sequence mixer) within each block, aiming to balance the transformer's expressiveness with the mixer's linear complexity for long sequences.

## Key Results
- Perplexity consistently underestimates teacher-student performance gaps and can invert design rankings, making it an unreliable metric for generation quality.
- The optimal distillation recipe comprises: knowledge distillation with completion-only masking, teacher-aligned instruction data, and freezing attention layers during post-training.
- The best Hybrid-KDA model retains 86–90% teacher accuracy on knowledge benchmarks, reduces KV cache memory by up to 75%, and speeds up time-to-first-token by 2–4× at 128K-token contexts.

## Why This Works (Mechanism)
Generation-based evaluation directly optimizes for output quality, avoiding the mismatch that perplexity introduces (e.g., favoring high likelihood on generic text over creative or accurate generations). The recipe components each contribute: completion-only masking focuses learning on the generation task rather than instruction following; teacher-aligned data ensures the student sees distributions similar to the teacher; freezing attention layers preserves the transformer's learned representations while allowing the linear mixer to adapt to the new architecture, thus maintaining knowledge retention. The hybrid design leverages attention for complex, local interactions and the linear mixer for efficient long-range dependencies, yielding both quality and efficiency.

## Foundational Learning
- **Knowledge Distillation**: Transfers knowledge from a large teacher to a compact student via a loss that matches teacher logits or hidden states. *Why needed*: Enables smaller models to approximate larger models' performance. *Quick check*: Loss typically includes KL divergence between teacher and student output distributions.
- **Hybrid Sequence Models**: Combine transformer attention with linear sequence mixers (e.g., KDA, Mamba) to balance expressiveness and computational efficiency. *Why needed*: Pure transformers scale quadratically; linear mixers offer O(L) complexity for long sequences. *Quick check*: Architecture contains both attention and state-space components.
- **Linear Sequence Mixers**: Parameterized state-space models that process sequences with linear complexity. *Why needed*: Achieve competitive performance with transformers while being more efficient for long contexts. *Quick check*: Hidden state update is linear in sequence length, often with a diagonal or low-rank structure.
- **Perplexity vs Generation Evaluation**: Perplexity measures likelihood of held-out text but may not correlate with generation quality; generation evaluation assesses actual outputs (e.g., accuracy, human ratings). *Why needed*: Distilled models may have similar perplexity but diverge in useful generation capabilities. *Quick check*: Compare model outputs directly on task-specific metrics.
- **KV Cache Optimization**: Caching key-value vectors in transformer attention to avoid recomputation during auto-regressive generation. *Why needed*: Reduces memory and computation for long contexts. *Quick check*: Cache size scales with number of layers, heads, and context length; reducing cache directly lowers memory footprint.

## Architecture Onboarding
**Component Map**:  
Token Embeddings -> [Transformer Attention Layer (frozen during post-training) -> KDA Layer] * N -> LayerNorm -> LM Head

**Critical Path**:  
During inference, input tokens pass through each hybrid block: attention computes contextual representations using cached KV for previous tokens, then KDA updates the state linearly; final hidden state produces next-token logits. The KV cache is stored per attention layer, while KDA maintains a compact state.

**Design Tradeoffs**:  
- Efficiency vs. Quality: Linear mixers reduce memory/computation but may lose fine-grained retrieval; attention preserves detail but increases cache.
- Freezing Attention: Preserves teacher knowledge but limits student adaptation to new data distribution.
- Completion-only Masking: Focuses learning on generation but ignores instruction-following nuances.

**Failure Signatures**:  
- Poor long-context performance (e.g., >50% drop on LongBench) due to limited training sequence length (4K).
- Perplexity improvements that do not translate to generation quality gains.
- Degradation on knowledge benchmarks if attention layers are not frozen appropriately.

**First Three Experiments**:
1. Compare Hybrid-KDA against pure Mamba2 and transformer baselines using GenDistill, measuring generation accuracy and efficiency at varying context lengths.
2. Ablate masking strategies: full masking (loss on all tokens) vs. completion-only masking, evaluating impact on knowledge retention and generation quality.
3. Test frozen vs. fine-tuned attention layers during post-training, tracking accuracy and convergence speed.

## Open Questions the Paper Calls Out
### Open Question 1
- Question: Does the GenDistill recipe—specifically knowledge distillation with completion-only masking, teacher-aligned instruction data, and frozen attention layers—maintain its relative effectiveness and retention of teacher capabilities when scaled to model sizes between 1B and 7B parameters?
- Basis in paper: [explicit] The authors state in the conclusion: "The key open question is whether these specific recipe recommendations, not just the evaluation gap, hold at larger scales where models have greater capacity and training dynamics may shift. Validating the recipe at 1B–7B parameters, and extending it with dedicated long-context training, are the most pressing directions for future work."
- Why unresolved: The systematic ablations were conducted only on a 0.6B parameter model, and existing baselines operate at different scales (e.g., 7B), preventing controlled comparisons. It is unclear if the identified critical design choices generalize due to potential changes in optimization dynamics, capacity limits, or scaling laws.
- What evidence would resolve it: Replicate the full GenDistill pipeline (including the three-stage distillation and generation-based evaluation) on teacher models of 1B, 3B, and 7B parameters (e.g., Qwen3 variants), comparing student generation quality across the same design axes (objective, masking, freezing, dataset) to determine if the optimal recipe remains consistent.

### Open Question 2
- Question: What targeted modifications to the GenDistill pipeline are necessary to close the substantial long-context performance gap observed on benchmarks like LongBench and RULER, where distilled hybrid models retain only a fraction of teacher accuracy (e.g., 58% on LongBench)?
- Basis in paper: [explicit] The authors acknowledge: "Long-context quality remains an open gap: distillation on 4K-token sequences does not transfer, with Hybrid KDA retaining only 58% of teacher accuracy on LongBench (Appendix L)." They also suggest directions such as "targeted long-context training stages, on-policy distillation, and dataset composition strategies."
- Why unresolved: The current pipeline uses a maximum sequence length of 4K tokens during distillation, which fails to transfer to contexts ranging from 8K to 128K tokens in evaluation. The underlying reasons—such as the inability of linear mixers to handle precise positional retrieval or the lack of training signals for long-range dependencies—remain unclear, and proposed solutions are untested.
- What evidence would resolve it: Design and implement additional distillation stages or data mixtures that explicitly include longer sequences (e.g., 16K–128K tokens), possibly with curriculum learning, and evaluate resulting models on long-context benchmarks to quantify improvement and identify effective strategies (e.g., on-policy distillation, specific dataset ratios).

### Open Question 3
- Question: How do alternative linear sequence mixers (e.g., Gated DeltaNet, RWKV-7) compare to KDA and Mamba2 in terms of generation quality, efficiency, and distillation compatibility within the GenDistill framework?
- Basis in paper: [explicit] In the limitations section: "Our architecture comparison is also limited to KDA and Mamba2; other expressive linear mixers (e.g. Gated DeltaNet, RWKV-7) were not evaluated."
- Why unresolved: The paper establishes KDA as superior to Mamba2 for generation tasks, but this finding may not generalize to other state-of-the-art linear architectures that differ in gating mechanisms, state updates, or parameterizations. Without comparison, it is unknown if KDA is the optimal choice or if other mixers offer better trade-offs.
- What evidence would resolve it: Substitute KDA and Mamba2 in the Hybrid architecture with other linear mixers (e.g., Gated DeltaNet, RWKV-7), run the full GenDistill pipeline or ablations on key stages, and generate comparative results using generation-based evaluation across the same benchmark suite to determine relative strengths and weaknesses.

## Limitations
- Evaluation is limited to knowledge QA and long-context benchmarks; generalizability to other tasks (e.g., dialogue, code) and modalities is unknown.
- Generation-based evaluation metrics are not fully specified, raising potential bias and reproducibility concerns.
- Efficiency gains are context-length dependent; benefits may diminish for shorter sequences or on different hardware.

## Confidence
- Perplexity misleads rankings: **High** (systematic ablations across design axes).
- Hybrid-KDA + GenDistill effectiveness: **Medium** (validated on single 0.6B model; limited external replication).
- Optimal recipe (masking, data, frozen attention): **High** (ablations isolate factors with consistent outcomes).
- Accuracy/memory/speed gains: **Medium** (settings-specific, context-dependent).
