# DariMis: Harm-Aware Modeling for Dari Misinformation Detection on YouTube

## Quick Facts
- **arXiv ID:** 2603.22977
- **Source URL:** https://arxiv.org/abs/2603.22977
- **Reference count:** 40
- **Primary result:** Introduces DariMis, the first manually annotated Dari-language YouTube misinformation dataset, showing a structural coupling between misinformation and harm that enables triage; a pair-input BERT model improves misinformation recall by 7.0 pp over concatenation.

## Executive Summary
This paper presents DariMis, the first manually annotated dataset for Dari-language YouTube misinformation, comprising 9,224 videos labeled with both Information Type (Misinformation, Partly True, True) and Harm Level. Analysis reveals a strong correlation: 55.9% of Misinformation carries at least Medium harm, compared to 1.0% of True content, enabling harm-aware content triage. The core method is a pair-input BERT architecture that processes title and description as separate segments to explicitly model headline-body inconsistency—a primary misleading signal. This approach yields a significant +7.0 percentage point gain in Misinformation recall (60.1% → 67.1%) relative to single-field concatenation, despite a negligible macro F1 improvement (+0.09 pp). A Dari-specialized model (ParsBERT) achieves the best test performance (76.60% accuracy, 72.77% macro F1), while XLM-RoBERTa-base collapses on minority classes, highlighting model sensitivity to class imbalance and language specificity.

## Method Summary
The authors collect and manually annotate Dari-language YouTube videos to construct the DariMis dataset, labeling each video for Information Type and Harm Level. For classification, they implement two BERT-based architectures: a baseline that concatenates title and description into a single input sequence, and a proposed pair-input model that encodes title and description as two separate segments within a single BERT instance. The pair-input design allows the model to explicitly learn representations of inconsistency between a video’s headline (title) and body (description), a hallmark of deceptive content. Models are trained to predict both information type and harm level, with evaluation focusing on per-class metrics, especially recall for the safety-critical Misinformation class.

## Key Results
- **Dataset & coupling:** DariMis is the first Dari YouTube misinformation dataset; 55.9% of Misinformation has ≥Medium harm vs. 1.0% of True content, demonstrating a exploitable structural link for triage.
- **Pair-input recall gain:** The separate-segment BERT model improves Misinformation recall by 7.0 pp (60.1% → 67.1%) over concatenation, with virtually no change in macro F1 (+0.09 pp).
- **Model performance:** ParsBERT (Dari/Farsi-specialized) achieves best test results (76.60% accuracy, 72.77% macro F1); XLM-RoBERTa-base fails on minority classes, showing collapse in per-class metrics.

## Why This Works (Mechanism)
The pair-input architecture works because misinformation in Dari YouTube content frequently exhibits inconsistency between the sensationalized title and the more nuanced or contradictory description. By preserving title and description as separate segments within BERT, the model can better capture this discrepancy through cross-segment attention, treating headline-body inconsistency as a primary linguistic signal of deception. This contrasts with concatenation, which merges the two fields and may dilute or obscure such relational patterns. The effectiveness is further amplified by using a Dari-specialized pretrained model (ParsBERT), which captures language-specific semantics and cultural context crucial for detecting nuanced misinformation in a low-resource language.

## Architecture Onboarding
Component map: Title -> BERT (segment A) -> [CLS]_A; Description -> BERT (segment B) -> [CLS]_B -> Concat([CLS]_A, [CLS]_B) -> Fully connected layers -> Output (Information Type, Harm Level).  
Critical path: The two input fields are processed in parallel within a single BERT instance using segment embeddings, their [CLS] tokens are concatenated, and the joint representation is fed to the classification head.  
Design tradeoffs: Pair-input adds minor computational overhead versus simple concatenation but explicitly models inter-field inconsistency; ParsBERT provides Dari-specific performance at the cost of reduced cross-lingual transferability compared to XLM-R.  
Failure signatures: XLM-RoBERTa-base shows collapse on minority classes (Misinformation, Partly True), indicated by near-zero recall for these classes in ablation studies.  
First experiments:

2) Port the pair-input architecture to a comparable low-resource language misinformation dataset (e.g., a regional language on YouTube) to test generalizability of the inconsistency signal.  
3) Simulate a harm-aware triage scenario: use model harm predictions to prioritize videos for human review, measuring reduction in missed harmful misinformation versus increase in false positives.

## Limitations
- No reported inter-annotator agreement for DariMis annotations, undermining label reliability and dataset robustness.
- Generalizability is restricted to Dari-language YouTube content; no cross-lingual or cross-platform validation is provided.
- The recall improvement for misinformation (+7.0 pp) comes with negligible macro F1 gain (+0.09 pp), suggesting potential trade-offs in overall metric optimization.

## Confidence
- Dataset novelty (first Dari YouTube misinformation dataset): High.
- Structural coupling between Information Type and Harm Level: Medium (dependent on annotation quality and lacking external validation).
- Pair-input BERT recall improvement: Medium (modest bootstrap bounds, negligible macro F1 gain).
- ParsBERT achieving best test performance: High (clear metrics reported).
- XLM-RoBERTa-base minority-class collapse: High (demonstrated in ablations).
