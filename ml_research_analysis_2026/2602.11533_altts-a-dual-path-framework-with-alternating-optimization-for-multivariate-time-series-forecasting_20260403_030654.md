# AltTS: A Dual-Path Framework with Alternating Optimization for Multivariate Time Series Forecasting

## Quick Facts
- arXiv ID: 2602.11533
- Source URL: https://arxiv.org/abs/2602.11533
- Reference count: 40
- Primary result: Achieves state-of-the-art or second-best performance in 49 of 56 evaluation slots (MSE/MAE), with largest gains on long-horizon forecasts.

## Executive Summary
AltTS addresses a critical optimization conflict in multivariate time series forecasting: joint training of autoregressive (AR) and cross-relation (CR) components mixes high-variance CR gradients into AR updates, destabilizing long-horizon prediction. The framework decouples modeling into two parallel paths—a linear AR predictor (RLinear) and a Transformer-based CR module with a masked self-attention that suppresses intra-series links—and coordinates them via alternating optimization. This separation isolates gradient noise, leading to more stable training and superior accuracy across seven benchmarks and four prediction horizons.

## Method Summary
AltTS first normalizes each input window using reversible instance normalization (RevIN). The AR path applies a separate linear layer per channel to capture within-series temporal patterns, producing an AR forecast. The CR path flattens variables into tokens, embeds them, and processes them with a Transformer encoder using Cross-Relation Self-Attention (CRSA); CRSA employs a diagonal attention mask to zero out intra-series links, ensuring only cross-variable interactions are modeled. The CR output is then projected back to per-channel forecasts. Final predictions sum the denormalized outputs from both paths. Training uses two independent AMSGrad optimizers and alternates between updating AR parameters (CR frozen) and CR parameters (AR frozen), typically with a 10:2 inner-step ratio. This block-coordinate approach prevents gradient entanglement and allows each path to adapt at its own pace.

## Key Results
- State-of-the-art or second-best in 49 of 56 benchmark-horizon combinations (MSE/MAE).
- Largest improvements on long horizons; e.g., ETTh1 horizon 720: MSE 0.435 vs. 0.510 under joint training.
- Ablations confirm alternating optimization consistently reduces error versus joint training, especially for longer horizons.

## Why This Works (Mechanism)
Three interconnected mechanisms explain AltTS’s effectiveness:

1. **Gradient entanglement reduction**: In joint training, the loss gradient for AR parameters mixes contributions from both AR and CR residuals. Because CR updates are inherently noisier (due to intermittent cross-variable signals), their high variance contaminates the AR gradient covariance, making AR updates unstable and harming long-horizon accuracy where errors compound. Alternating optimization blocks separate these gradients, eliminating the cross-covariance term and providing cleaner AR updates.

2. **Architectural decoupling**: The AR path uses a simple linear predictor (RLinear) dedicated to within-series dynamics. The CR path uses a Transformer with CRSA masking (diagonal −∞) to explicitly forbid intra-series attention, forcing it to model only cross-variable interactions. This prevents the CR module from redundantly learning AR patterns, which would otherwise blur the distinction and reintroduce entanglement.

3. **Optimization isolation**: By freezing one path while updating the other, AO ensures that the gradient used for each block depends only on its own parameters and the current (fixed) state of the other. This removes the covariance between parameter blocks from the update direction, stabilizing convergence. The AR path, being low-curvature and fast-converging, benefits most from this noise isolation, which is crucial for accurate long-horizon forecasts.

## Foundational Learning
- **Autoregressive vs. Cross-variable dynamics**: AR captures stable, persistent within-series temporal patterns; CR captures intermittent, often noisier instantaneous links between series. This distinction is key: spurious cross-correlations can mislead long-horizon AR modeling if not decoupled.

- **Gradient variance as an instability metric**: Stochastic gradient variance indicates noisiness of updates and sensitivity to step size. A shared optimizer cannot optimally set a learning rate for both low-variance (AR) and high-variance (CR) blocks; the latter’s noise will degrade the former’s updates.

- **Block-coordinate descent (BCD)**: An optimization scheme that partitions parameters into blocks and optimizes each separately while holding others fixed. It can guarantee monotone descent under certain conditions and is valuable when blocks have different convergence rates or gradient statistics.

## Architecture Onboarding
- **Component map**: Input (D×L) → RevIN → [AR path: RLinear] → y_AR; and RevIN → [CR path: Linear embed → Transformer(CRSA) → Channel-linear] → y_CR; then Denorm(y_AR) + Denorm(y_CR) → Output (D×H).

- **Critical path**: Success hinges on three design points: (1) CRSA’s diagonal mask ensures the CR path exclusively models cross-variable interactions; (2) Alternating optimization physically separates gradient computation, isolating noise; (3) The AR path’s linear simplicity provides a low-variance anchor essential for long-horizon stability.

- **Design tradeoffs**:
  - Linear AR sacrifices nonlinear temporal patterns for stability and fast convergence; a more complex AR might reintroduce entanglement.
  - AO cycle ratio (e.g., AR:CR = 10:2) is a new hyperparameter; too few CR updates underfits cross-variable signals, too many risks stale AR updates.
  - Separate optimizers add overhead but allow distinct learning rates, crucial for managing differing gradient variances.

- **Failure signatures**:
  - AR path collapse: if AR output contributes little, CR may have learned AR despite masking (check AR-only vs. full model performance).
  - CR path instability: high validation loss during CR update phases suggests overfitting or inappropriate learning rate.
  - Stale alternation: oscillating validation loss with long AO cycles indicates one block optimized on outdated parameters of the other.
  - Dataset dependence: on highly channel-independent data (e.g., Electricity), AO may bring no gain or even degrade performance.

- **First 3 experiments**:
  1. Replicate gradient variance plots: Train joint and AO models; compute rolling variance of gradients for AR and CR parameters; expect AO flattens CR variance and keeps AR variance low.
  2. Ablate CRSA mask: Remove diagonal attention mask while keeping AO; evaluate on long-horizon benchmarks (e.g., ETTh1 720); expect significant performance drop.
  3. AO cycle sensitivity: Vary inner update counts (e.g., AR:CR = 5:1, 1:1, 1:5); monitor validation loss; verify paper’s 10:2 ratio is near-optimal.

## Limitations
- Hyperparameter values (learning rates, Transformer dimensions, regularization strengths) are not fully disclosed, hindering exact replication.
- RevIN implementation ambiguity: whether normalization statistics are shared between AR and CR paths may affect stability and results.
- The core assumption that CR updates are inherently noisier may fail on strongly coupled systems with consistent cross-variable signals.

## Confidence
- Gradient entanglement mechanism: High (theoretically derived, empirically supported by gradient variance plots).
- CRSA masking for decoupling: Medium (ablations validate, but external corpus evidence is sparse).
- Alternating optimization stability: High (consistent gains across 49/56 slots and theoretical covariance reduction).
