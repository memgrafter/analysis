# Grammar of the Wave: Towards Explainable Multivariate Time Series Event Detection via Neuro-Symbolic VLM Agents
## Quick Facts
- **arXiv ID**: 2603.11479
- **Source URL**: https://arxiv.org/abs/2603.11479
- **Reference count**: 10
- **Primary result**: SELA (GPT-5) zero-shot F1@0.5 83.33% (easy) and 79.31% (hard), approaching human performance and surpassing supervised baselines.

## Executive Summary
This paper introduces Event Logic Trees (ELT) to transform natural-language event descriptions into hierarchical temporal-logic structures for Knowledge-Guided Time Series Event Detection (K-TSED). A neuro-symbolic VLM agent framework, SELA, uses ELT as a shared scaffold to guide active visualization, iteratively instantiating signal primitives and producing both detected intervals and explainable trees. On the new real-world energy benchmark KITE, SELA with GPT-5 achieves zero-shot F1@0.5 scores of 83.33% (easy) and 79.31% (hard), significantly outperforming previous VLM methods and supervised baselines, and nearing human performance. Ablation studies confirm ELT’s critical role in reducing VLM hallucination and enabling precise localization.

## Method Summary
SELA comprises two cooperating agents: a Logic Analyst that parses an event description into an ELT schema, and a Signal Inspector that instantiates leaf primitives by interactively querying the signal visualization (zoom, markers). The central Logic Engine enforces schema axioms and recursively propagates confidence scores via fuzzy logic operators, which encode temporal constraints (SEQ, SYNC, GUARD). This closed-loop process grounds linguistic semantics in active signal inspection, yielding both event intervals and an explainable tree. The method operates zero-shot without task-specific training.

## Key Results
- On KITE-easy, SELA (GPT-5) achieves F1@0.5 = 83.33%, F1@0.9 = 44.79%.
- On KITE-hard (complex compositions), SELA achieves F1@0.5 = 79.31%, F1@0.9 = 68.96%, substantially outperforming supervised TS classifiers and prior VLM approaches.
- Ablation: Removing ELT structure causes performance collapse on hard events; active visualization alone is insufficient, demonstrating ELT’s necessity for compositional reasoning.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: Event Logic Tree (ELT) schema provides a structured, logic-based intermediate representation that decomposes unstructured event descriptions into hierarchical, quantifiable, and topologically elastic patterns, grounding semantics to signal morphology.
- **Mechanism**: ELT parses natural language into a tree of primitive nodes (channel-specific semantic predicates) and composite nodes (temporal-logic operators: `SEQ`, `SYNC`, `GUARD`, `OR`). This structure enforces compositional semantics and recursive confidence propagation. It separates schema definition from data instantiation, enabling topological elasticity (time warping) while Axioms 1-3 ensure logical validity (constructive composition, temporal compactness, physical exclusivity).
- **Core assumption**: Human event descriptions implicitly contain compositional temporal-logic structures that can be explicitly modeled via a tree grammar.
- **Evidence anchors**:
  - Abstract: "ELT to transform natural-language event descriptions into hierarchical temporal-logic structures"
  - Section 4: Definitions of Node Schema, Axioms, and Instantiation; Table 2 shows operator formalizations.
  - Corpus: Existing symbolic representations (SAX, Logical-Shapelets, STL) fail desiderata D1-3; ELT explicitly addresses all three (Table 1).
- **Break condition**: If the input event description lacks compositional structure or physical channel exclusivity is violated irreconcilably (Ψ=1 persistently), ELT cannot form a valid schema.

### Mechanism 2
- **Claim**: The neuro-symbolic VLM agent collaboration (Logic Analyst + Signal Inspector) uses ELT as a shared cognitive scaffold to guide active visualization, mitigating VLM hallucination by grounding linguistic semantics in iterative signal inspection under logical constraints.
- **Mechanism**: The Logic Analyst constructs an initial ELT schema from the description. The Signal Inspector then incrementally instantiates leaf primitives by querying the visualization interface (zoom, markers) to examine signal morphology. Each instantiation updates the tree with intervals and semantic coherence scores (µ). Composite node scores are computed recursively via fuzzy logic operators (Eqs. 3-6), which enforce temporal gates and collision penalties. This closed-loop process lets VLMs reason about "what to look for" (schema) and "where to look" (active viz), with ELT's structured output providing verifiable evidence chains.
- **Core assumption**: VLMs equipped with active visualization tools and a structured reasoning plan (ELT) can outperform zero-shot numeric or static-figure baselines by focusing attention and constraining hypothesis space.
- **Evidence anchors**:
  - Abstract: "iteratively instantiate signal primitives via active visualization, yielding both detected intervals and explainable trees"
  - Section 5: "SELA... comprising two types of agents: Logic Analyst... Signal Inspector... iteratively optimize the schema structure by observing the visualization"
  - Section 7.2: Ablation shows SELA drastically outperforms VL-Time (static viz) and Numeric inputs; ELT guidance is critical in KITE-hard.
- **Break condition**: If VLM perception fails to map semantic predicates (τ) to signal morphologies in the active visualization (e.g., due to noise, non-prototypical patterns), µ scores become uniformly low and propagation fails to yield a confident root node.

### Mechanism 3
- **Claim**: The recursive fuzzy logic computation with operational completeness (Allen’s algebra) ensures that ELT can represent any compositional temporal-logic structure in event descriptions while maintaining semantic coherence and boundary precision through differentiable penalties.
- **Mechanism**: Bottom-up confidence propagation (`µ_parent = op(µ_children)`) with product T-norm combines morphological confidence with relational validity. `SEQ`, `SYNC`, `GUARD` implement soft constraints (causality gates, IoU penalties, boundary spill penalties) that respectively enforce precedence, alignment, and containment. Proposition 1 proves these operators cover all 13 Allen relations via inverses and parameterizations, ensuring expressiveness. This allows the system to handle elastic durations (D3) while penalizing semantic gaps (Axiom 2) and channel collisions (Axiom 3).
- **Core assumption**: Semantic coherence (µ) can be meaningfully quantified by VLMs comparing linguistic predicate embeddings against signal segment embeddings, and these scores compose meaningfully via fuzzy operators.
- **Evidence anchors**:
  - Section 4.4: Proposition 1 and proof sketch; Eqs. 3-6 define operator-specific penalties.
  - Section 4.2: Axioms 2 & 3 directly control temporal gaps (δ) and channel collisions (Ψ, ϵ).
  - Section 7.3: Ablation: without ELT (w/o ELT), performance collapses on KITE-hard, indicating logic structure is necessary for complex compositions.
- **Break condition**: If the event's temporal logic exceeds the expressivity of the core operator set (e.g., requires non-compositional operators not covered by Allen’s algebra inverses) or if semantic coherence scores are too sparse/noisy for reliable product-based composition, the fuzzy logic propagation becomes uninformative.

## Foundational Learning
- **Allen's Interval Algebra**
  - **Why needed**: ELT's temporal operators (`SEQ`, `SYNC`, `GUARD`) are parameterizations of Allen's 13 interval relations; Proposition 1 relies on mapping between them. Understanding before/after/overlap/containment is essential to grasp how ELT models event composition.
  - **Quick check**: How would you represent "event A starts exactly when event B ends" using ELT operators and Allen's relations?

- **Neuro-Symbolic Integration**
  - **Why needed**: SELA combines neural perception (VLM interpreting signal visualizations) with symbolic reasoning (ELT tree structure and logic operators). This integration is the core mechanism for explainability and grounding.
  - **Quick check**: What are the two distinct roles of the neural component vs. the symbolic component in SELA's pipeline?

- **Active Visualization for Time Series**
  - **Why needed**: SELA's Signal Inspector uses dynamic zooming and marker placement to overcome precision loss inherent in static time series figures (as used by VL-Time). This tool-use paradigm is critical for localized morphological analysis.
  - **Quick check**: Why might a static time series plot be insufficient for precise event boundary detection, and how does active zoom mitigate this?

## Architecture Onboarding
**Component map**:
Logic Analyst Agent -> Central Logic Engine <- Signal Inspector Agent; Data Layer (time series) -> Central Logic Engine -> Unified Interface (visualization) -> Signal Inspector; Logic Analyst also interacts with Unified Interface for schema sanity checks.

**Critical path**:
1. User provides (multivariate time series X, event description L).
2. Logic Analyst parses L → ELT schema; submits Schema Artifact.
3. Engine validates schema against Axioms 1-3.
4. Signal Inspector, guided by schema, iteratively: (a) calls zoom/markers to inspect signal; (b) calls `instantiate` to propose primitive intervals with µ; (c) engine updates tree and shows propagated root confidence.
5. Inspector refines until saturation; final event intervals Y extracted from instantiated tree.

**Design tradeoffs**:
- *Precision vs. Recall*: ELT's `µ` thresholds and operator penalties (κ in SYNC, σ in GUARD) trade off strictness for capturing elastic variations.
- *Interpretability vs. Automation*: The agentic loop provides explainability (instantiated tree) but requires more turns (~5.2) than end-to-end prediction.
- *Generalization vs. Domain Specificity*: ELT operators are domain-agnostic, but the semantic coherence scorer `M_τ` relies on VLM's pre-trained signal-text alignment, which may vary by domain (energy vs. healthcare).

**Failure signatures**:
- Schema level: persistent channel collisions (`Ψ=1`), Axiom 2 violations (large temporal gaps), or composites with fewer than two children (`|N|<2`).
- Instantiation level: all `µ` scores near random (~0.5); root confidence remains low across iterations.
- Agent behavior: Signal Inspector ignores ELT structure, proposes intervals randomly; Logic Analyst produces flat schema (no composites) for complex descriptions.

**First 3 experiments**:
1. **Schema Parsing Sanity Check**: Feed the "Buildup" description from Section 1 to Logic Analyst. Verify output schema includes `SEQ`/`SYNC` composites, primitives assigned to `Volume` and `Pressure` channels, and satisfies Axiom 1.
2. **Primitive Instantiation Drill**: Given a fixed ELT with one primitive ("Volume remains stable"), use Signal Inspector on a provided KITE sample. Can it correctly identify the plateau interval? Check if `µ` > 0.8 and interval aligns with ground truth.
3. **End-to-End on KITE-easy**: Run full SELA (GPT-5) on 3 KITE-easy samples. Measure turn count, root confidence trajectory, and final F1@0.5. Compare against VL-Time baseline to visualize ELT's benefit.

## Open Questions the Paper Calls Out
1. **Cross-model Generalization**: How does SELA perform across different Vision-Language Model architectures beyond GPT-4.1 and GPT-5? The paper only tests these two models; it is unknown if ELT's benefits hold for open-source VLMs.
2. **Active Visualization Tooling**: Can the active visualization toolset be optimized or expanded to improve accuracy and reduce reliance on ELT for complex events? The study uses basic zoom/markers; richer tools might help.
3. **Robustness to Description Noise**: How robust is ELT schema parsing to ambiguous, incomplete, or contradictory natural language descriptions? The paper assumes well-structured expert descriptions.
4. **Cross-Domain Transfer**: To what extent does the ELT framework transfer to other domains (e.g., healthcare, finance) where event semantics and signal characteristics differ? KITE is limited to energy production pressure data.

## Limitations
- **Replicability barrier**: Results rely on proprietary GPT-5; independent verification with open-source VLMs is difficult.
- **Single-benchmark evaluation**: KITE is the only dataset; generalizability to other time series domains remains unproven.
- **VLM perceptual brittleness**: The method’s core assumes VLMs can accurately map semantic predicates to signal morphologies; performance likely degrades on noisy or atypical patterns, but breakpoints are unstudied.

## Confidence
- **ELT structure enables compositional reasoning and mitigates hallucination**: **High** (strong ablation evidence and theoretical grounding).
- **Active visualization + ELT guidance yields precise localization**: **Medium** (benefit shown but depends on VLM perception; no failure-mode analysis).
- **SELA approaches human performance and generalizes zero-shot**: **Low** (evaluated only on one new dataset; no cross-domain validation).

## Next Checks
