# MM-DeepResearch: A Simple and Effective Multimodal Agentic Search Baseline

## Quick Facts
- arXiv ID: 2603.01050
- Source URL: https://arxiv.org/abs/2603.01050
- Reference count: 40
- Key outcome: Develops cost-effective multimodal deep research agents that achieve strong benchmark performance without expensive online search APIs

## Executive Summary
This paper addresses the challenge of building multimodal deep research agents capable of explicit reasoning, multi-tool invocation, and cross-modal information synthesis. The authors tackle key issues including the scarcity of search-intensive multimodal QA data, lack of effective search trajectories, and high costs of training with online search APIs. They propose a comprehensive framework that enables effective deep research agents to be developed without relying on expensive online search APIs, achieving strong performance across multiple benchmarks and improving over both non-agentic and agentic MLLMs on tasks requiring multimodal search and reasoning.

## Method Summary
The approach introduces Hyper-Search, a hypergraph-based QA generation method that connects visual and textual nodes to produce search-intensive multimodal QA pairs. DR-TTS decomposes tasks by tool type, trains specialized experts, and recombines them to explore high-quality search trajectories. An offline multimodal search engine enables cost-effective reinforcement learning by pre-collecting corpus and supporting both information-based and knowledge-based search. The training pipeline involves two stages: SFT on search tool trajectories as cold start, followed by agentic multi-turn RL using the offline search engine.

## Key Results
- MM-DeepResearch achieves superior performance across multiple benchmarks compared to non-agentic and agentic MLLMs
- The framework successfully generates 3K search-intensive multimodal QA pairs using hypergraph construction
- Specialized tool expert training via DR-TTS synthesizes 10K search tool trajectories for effective exploration

## Why This Works (Mechanism)

### Mechanism 1
- Claim: Hypergraph construction enables the generation of search-intensive multimodal QA pairs by modeling native relationships among web images, webpage content, and their connections.
- Mechanism: Nodes (image and text) are expanded using modality-specific strategies (image reverse search, image visual search, text node expansion, image node expansion). Hyperedges connect parent nodes to newly generated nodes, capturing cross-modal retrieval relationships. QA generation is performed at hyperedge and cross-hyperedge levels to produce questions requiring multi-turn and multi-tool search.
- Core assumption: Web information can be effectively modeled as a hypergraph where images and texts are nodes, and retrieval relationships are hyperedges.
- Evidence anchors:
  - [abstract] "models and connects visual and textual nodes within and across modalities"
  - [section] "Each node expansion induces a hyperedge ed,k that connects the parent node with all newly generated nodes"
  - [corpus] "Found 25 related papers (using 8)" - weak corpus evidence for hypergraph novelty

### Mechanism 2
- Claim: Decomposing search tasks by tool type and training specialized experts improves per-tool proficiency and reduces learning complexity.
- Mechanism: Search-related tasks are categorized by required search tools. Each category is used to train a specialized expert via reinforcement learning without cold start. Tool experts are then recomposed to jointly explore search trajectories via tree search.
- Core assumption: Specialized training for each tool type is more effective than joint training of all tools from the start.
- Evidence anchors:
  - [abstract] "decomposes search-involved tasks into several categories according to search tool types, and respectively optimize specialized search tool experts"
  - [section] "Direct performing tree search with a pre-trained agentic foundational MLLM often leads to suboptimal performance"
  - [corpus] "Agentic search requires large language models (LLMs) to perform multi-step search" - supports need for specialized training

### Mechanism 3
- Claim: Offline search engine enables cost-effective reinforcement learning by pre-collecting multimodal corpus and supporting both information-based and knowledge-based search.
- Mechanism: Large-scale multimodal corpus (textual and visual) is pre-collected and indexed. Text-based retrieval uses text-only embeddings, multimodal retrieval uses multimodal embeddings. This eliminates need for repeated online API calls during training.
- Core assumption: Pre-collected corpus can adequately simulate real-world search environments for effective RL training.
- Evidence anchors:
  - [abstract] "build an offline search engine supporting multiple search tools, enabling agentic reinforcement learning without using costly online search APIs"
  - [section] "Compared with online search engines, our offline search engine provides faster tool responses and reduces tool-interactive training time"
  - [corpus] "Limited evidence for offline search engine effectiveness" - corpus lacks specific studies on offline vs online performance

## Architecture Onboarding

- Component map:
  - Input: Query image + textual evidence
  - Hypergraph builder: Constructs nodes and hyperedges from web sources
  - QA generator: Generates search-intensive questions and answers
  - Tool experts: Specialized models for each search tool type
  - Tree search: Explores search trajectories using recomposed tool experts
  - Offline search engine: Pre-collected corpus with retrieval capabilities
  - SFT trainer: Fine-tunes model on search trajectories
  - RL trainer: Optimizes model using offline search engine

- Critical path: Input → Hypergraph construction → QA generation → Tool expert training → Tree search → Trajectory extraction → SFT/RL → Evaluation
- Design tradeoffs: Pre-collecting offline corpus vs. using online APIs (cost vs. freshness), specialized vs. joint tool training (complexity vs. performance), hyperedge vs. traditional graph (expressiveness vs. computational cost)
- Failure signatures: Poor QA quality (insufficient node expansion), tool misuse (inadequate expert training), high latency (inefficient offline indexing), suboptimal trajectories (faulty tree search)
- First 3 experiments:
  1. Validate hypergraph construction by checking node expansion coverage and hyperedge quality
  2. Test specialized tool expert training by comparing per-tool performance vs. joint training baseline
  3. Evaluate offline search engine retrieval quality vs. online search API on held-out queries

## Limitations
- The effectiveness of specialized tool expert training versus joint training remains unclear, as does whether the recomposition strategy reliably finds optimal search trajectories across diverse task types
- The approach relies heavily on the quality of hypergraph construction and offline corpus, with limited evidence about how well the offline corpus captures the diversity and freshness of real-world search environments
- The paper doesn't address potential scalability issues when extending to more search tools or handling highly specialized domains

## Confidence
- High confidence: The core architectural framework (Hyper-Search + DR-TTS + offline search) is technically sound and addresses real cost barriers in agentic search training
- Medium confidence: Performance claims on benchmarks, as the paper lacks detailed ablation studies on individual components
- Low confidence: Generalizability to domains beyond the benchmarked tasks and long-term effectiveness as web content evolves
