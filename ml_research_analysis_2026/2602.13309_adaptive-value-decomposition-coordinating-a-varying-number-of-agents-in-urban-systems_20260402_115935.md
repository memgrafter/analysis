# Adaptive Value Decomposition: Coordinating a Varying Number of Agents in Urban Systems
## Quick Facts
- **arXiv ID**: 2602.13309
- **Source URL**: https://arxiv.org/abs/2602.13309
- **Reference count**: 40
- **Primary result**: AVD significantly outperformed baselines in cumulative rentals per episode (e.g., 8445 in London with 4 agents) and showed strong zero-shot generalization to unseen agent populations.

## Executive Summary
Urban systems such as bike-sharing involve multiple agents that must cooperate while operating asynchronously and with dynamically changing populations. Standard multi-agent reinforcement learning (MARL) methods struggle with these conditions due to assumptions of fixed agent numbers, synchronous actions, and parameter sharing leading to action homogenization. This paper introduces Adaptive Value Decomposition (AVD), a framework that combines a hypernetwork-based mixing network for variable agent cardinality, a lightweight mitigation mechanism (dispersed initialization and stochastic perturbations) to reduce homogenization, and a centralized training with decentralized execution (CTDE) strategy tailored to semi-MARL asynchronous settings. Experiments on bike-sharing datasets from London and Washington, D.C. demonstrate that AVD substantially outperforms state-of-the-art baselines like VDN+ and QMIX in cumulative rentals per episode. The method also exhibits strong zero-shot generalization to agent populations not seen during training, and ablation studies validate the contribution of each component.

## Method Summary
AVD extends the CTDE paradigm to handle a varying number of agents by employing a hypernetwork that generates mixing weights and biases conditioned on a global state embedding. The hypernetwork uses Multi-Head Attention (MHA) to process the set of agent embeddings and row-wise MLPs to produce monotonic mixing parameters, ensuring that decentralized greedy execution remains optimal regardless of the number of active agents. To counter action homogenization—a side effect of parameter sharing—AVD initializes agents in spatially dispersed clusters and injects Gaussian noise into agent embeddings during execution, promoting diversity without destabilizing cooperation. For semi-MARL scenarios where agents act asynchronously (each agent triggers a new decision only after its prior action completes), AVD collects step-level transitions and trains the value decomposition network on these tuples, preserving the monotonicity guarantee under asynchronous execution.

## Key Results
- AVD achieved cumulative rentals of 8445 in London (4 agents), beating VDN+ (8277) and QMIX (8234).
- Zero-shot evaluation on agent populations not seen during training (e.g., 3 agents when trained with 4) maintained performance, demonstrating adaptability.
- Ablation of the dispersion and perturbation mechanism showed a significant drop in both diversity and performance, confirming its necessity.

## Why This Works (Mechanism)
### Mechanism 1
- **Claim**: AVD adapts to a dynamically changing number of active agents using a hypernetwork-based mixing network.
- **Mechanism**: The mixing network uses Multi-Head Attention (MHA) and row-wise MLPs to process a variable set of agent embeddings and generate mixing weights/biases in a state-dependent, monotonic manner. The MHA captures inter-agent semantic relationships regardless of cardinality, while row-wise operations make the network agnostic to the number of agents.
- **Core assumption**: The global state representation (concatenated environment state and agent embeddings) provides sufficient information for the hypernetwork to generate appropriate mixing parameters for any subset of agents.
- **Evidence anchors**:
  - [abstract]: "featuring hypernetwork-based value decomposition for variable agents"
  - [section 4.1]: Describes the MHA and row-wise MLP architecture enabling variable agent handling.
  - [Key Results]: Zero-shot evaluation on unseen agent counts (e.g., 3 vs. 4) demonstrates successful adaptation.
- **Break condition**: If the state representation fails to capture critical inter-agent dependencies for a novel agent cardinality, the monotonic mixing may produce invalid decompositions, leading to suboptimal joint action selection.

### Mechanism 2
- **Claim**: AVD mitigates action homogenization induced by parameter sharing via dispersed initialization and stochastic perturbations.
- **Mechanism**: At episode start, agents are initialized in spatially dispersed clusters to ensure diverse starting observations. During execution, Gaussian noise is injected into agent embeddings (post-MHA) to introduce mild stochasticity, encouraging divergent action selection among agents with otherwise similar representations.
- **Core assumption**: Behavioral homogeneity primarily stems from agents receiving highly similar observations/representations; injecting controlled diversity at these points will improve collective performance without destabilizing learned cooperation.
- **Evidence anchors**:
  - [abstract]: "a lightweight mitigation mechanism with dispersed initialization and stochastic perturbations"
  - [section 4.1.3]: Details both dispersed initialization (spatial clustering) and embedding perturbation.
  - [Key Results]: Ablation of dispersion and perturbation causes significant performance drop, confirming its necessity.
- **Break condition**: Excessive perturbation noise could overwhelm learned value estimates, causing erratic exploration and degrading coordinated performance, especially in low-signal environments.

### Mechanism 3
- **Claim**: The CTDE training-execution strategy accommodates asynchronous decision-making in semi-MARL by learning from step-level transitions where agents act independently upon action completion.
- **Mechanism**: During execution, agents act asynchronously: an agent selects a new action only when its previous action completes; otherwise, it continues. Training uses these asynchronously generated step-level transitions `(s_t, a_t, s_{t+1}, r_t)` to update the centralized value decomposition networks. The monotonic mixing constraint ensures that decentralised, asynchronous action selection still converges to cooperative optimality.
- **Core assumption**: The step-level transition tuples, generated under asynchronous execution, are valid samples for learning the optimal joint policy under the semi-MARL formulation, and the value decomposition's monotonicity preserves the `decentralised execution` guarantee despite asynchronous action timing.
- **Evidence anchors**:
  - [abstract]: "a CTDE training-execution strategy for semi-MARL"
  - [section 4.2]: Formalizes the semi-MARL process and the asynchronous action selection rule.
- **Break condition**: If action durations are highly stochastic or the environment state changes rapidly between an agent's decision and execution, the outdated action could lead to significant coordination errors that the value decomposition cannot correct.

## Foundational Learning
- **Concept: Value Decomposition (VDN, QMIX)**
  - **Why needed here**: AVD builds upon the centralised training, decentralised execution (CTDE) paradigm and value decomposition networks. Understanding how individual agent Q-values are combined into a global Q-tot with monotonicity constraints (QMIX) is foundational to assessing AVD's adaptive mixing network.
  - **Quick check question**: How does the monotonicity constraint in QMIX ensure that decentralised greedy action selection yields a optimal joint action?
- **Concept: Semi-MARL / Asynchronous MARL**
  - **Why needed here**: The paper's setting explicitly involves agents with heterogeneous action durations, defining a semi-MARL problem. This requires understanding how standard synchronous MARL assumptions break down and how training data is collected under asynchronous execution.
  - **Quick check question**: In a semi-MARL setting, what distinguishes a valid step-level transition tuple `(s_t, a_t, s_{t+1}, r_t)` from one in synchronous MARL?
- **Concept: Parameter Sharing & Action Homogenization**
  - **Why needed here**: AVD's mitigation mechanism directly addresses a side-effect of the common MARL practice of sharing agent policy parameters for scalability. Understanding why parameter sharing leads to homogeneous actions in spatially correlated environments is key.
  - **Quick check question**: Why are agents with shared policies more likely to produce identical or highly similar actions when they make decisions concurrently under similar local observations?

## Architecture Onboarding
- **Component map**:
  1. **Agent Network (Shared)**: Processes `s_agent` (agent-specific states) and `s_env` (broadcast global state) via MHA and MLP to produce per-agent Q-values `Q_v(s, a)` and agent embeddings.
  2. **Mixing Network**: Takes the same `s_agent` and `s_env`, uses its own MHA and row-wise MLPs to generate state-dependent mixing weights `|w_v|` and biases `b_v` for the current active agent set.
  3. **Perturbation Module**: Adds Gaussian noise to the agent embeddings from the Agent Network *before* they are used for Q-value computation.
  4. **CTDE Execution Loop**: Manages asynchronous action selection—agents act only when idle—and collects step-level transitions.
  5. **Replay Buffer & Trainer**: Stores transitions and optimises `Q_tot` vs. target network Bellman error.
- **Critical path**:
  Global State -> Agent Network (with perturbation) -> Per-Agent Q-values & Embeddings -> Mixing Network (using same state) -> Weighted sum (|w_v|*Q_v + b_v) -> Q_tot -> Loss & Update
- **Design tradeoffs**:
  - Hypernetwork complexity vs. generalisation: The MHA+MLP hypernetwork is more computationally flexible than a fixed architecture (like QMIX's MLP) but introduces more parameters that could overfit to specific agent cardinalities seen during training.
  - Perturbation strength vs. stability: Noise magnitude must be sufficient to break symmetry but small enough to not derail learning from coherent policies. The paper uses a fixed small Gaussian (N(0,I)), which is a simple heuristic not adapted to learning progress.
  - Dispersion strategy: The clustering-based initialization is domain-specific (using station geo-coordinates). Generalising this to other domains requires defining appropriate "task-relevant locations."
- **Failure signatures**:
  - Dynamic agent failure: Performance degrades sharply when test-time agent count exceeds training-time max, or when agent count changes very rapidly, indicating the hypernetwork fails to generalise its mixing parameter generation.
  - Homogenization persists: If agent actions remain highly correlated (e.g., all moving to the same station) despite the mitigation mechanism, the perturbation may be too weak or the dispersion initialization ineffective for the specific demand pattern.
  - Asynchronous breakdown: If the Bellman update using step-level transitions leads to unstable learning (e.g., high variance in TD errors), the semi-MARL formulation may be violating the Markov assumption required for standard RL.
- **First 3 experiments**:
  1. **Variable Agent Cardinality Test**: Train with a fixed `|V_tau| ≡ 4` and evaluate with `|V_tau| ≡ 2` and `|V_tau| ≡ 6` (unseen during training) to confirm the hypernetwork's out-of-distribution generalisation for agent number.
  2. **Ablation of Mitigation Mechanism**: Train two AVD variants: with and without the dispersed initialization + perturbation. Compare their action diversity metrics (e.g., pairwise action distance) and cumulative rentals to validate the mechanism's contribution.
  3. **Zero-Shot Cardinality Transfer**: Train AVD with `|V_tau| ≡ 4` and directly test with `|V_tau| ≡ 3` (as in the paper). This is a stronger test of generalisation than training with 3 agents, as it evaluates if learned coordination patterns scale down.

## Limitations
- Hypernetwork generalization to agent cardinalities far outside the training range remains uncertain.
- The fixed Gaussian perturbation magnitude may be suboptimal across different environments and could lead to under- or over-perturbation.
- The theoretical justification for using step-level transitions in semi-MARL lacks strong validation under high stochasticity or rapid state changes.

## Confidence
- Dynamic Agent Adaptation (Hypernetwork): Medium
- Action Homogenization Mitigation: Medium-High
- Semi-MARL Asynchronous Strategy: Low

## Next Checks
1. Extreme Cardinality Stress Test: Train AVD with a fixed agent count (e.g., 4) and directly evaluate on a drastically higher count (e.g., 12-15) without intermediate training. Monitor collapse in `Q_tot` monotonicity and performance vs. baselines.
2. Adaptive Perturbation Ablation: Replace fixed Gaussian noise with a learnable perturbation module (e.g., perturbation magnitude as a function of state similarity). Compare final performance and action diversity metrics against the fixed-noise version across multiple random seeds.
3. Markovian Violation Analysis: Intentionally introduce high-variance, environment-driven action durations (e.g., random completion delays) in the bike-sharing simulator. Measure the increase in TD error variance for AVD versus a synchronous MARL baseline retrained for asynchronous execution.
