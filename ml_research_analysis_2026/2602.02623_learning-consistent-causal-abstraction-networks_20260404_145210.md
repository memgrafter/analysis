# Learning Consistent Causal Abstraction Networks

## Quick Facts
- **ArXiv ID:** 2602.02623  
- **Source URL:** https://arxiv.org/abs/2602.02623  
- **Reference count:** 0  
- **Primary result:** SPECTRAL solves local CLCA learning via closed‑form ADMM updates, and a transitive‑reduction search recovers full CANs with near‑perfect true positive rates and zero false positives on synthetic chain, star, and tree topologies.

## Executive Summary
The paper tackles the problem of learning a consistent causal abstraction network (CAN) from a collection of Gaussian structural causal models. It breaks the global network recovery into independent edge‑wise tasks, each solving a feasibility problem for a linear causal abstraction (CLCA). The proposed SPECTRAL algorithm reformulates that feasibility problem using an augmented Lagrangian and ADMM with a splitting of orthogonality constraints, yielding closed‑form updates on Stiefel manifolds. SPECTRAL avoids non‑convex optimization in the CLCA matrix and handles both positive‑definite and semidefinite covariances. A search procedure exploits transitivity to minimize the number of local checks. On synthetic data, SPECTRAL matches prior methods in local learning accuracy while being cheaper, and the full pipeline achieves almost perfect recovery of sparse CAN structures with no false positives.

## Method Summary
The goal is to recover a CAN (a sheaf of Gaussian SCMs linked by CLCA maps) from observational covariances. The solution comprises two modules. First, a **search procedure** builds a candidate edge set by checking a necessary eigenvalue condition (Theorem 2.1) on pairs of covariances and taking the transitive closure. It then iterates over candidate edges in ascending sub‑diagonals, validating each by solving a local CLCA feasibility problem. Second, the **SPECTRAL** algorithm addresses the local problem: given a pair of covariances and a known binary partition matrix, it seeks a matrix \(V \in \mathrm{St}(\ell,h)\) that satisfies the CLCA equations. SPECTRAL uses ADMM with a splitting variable on the Stiefel manifold, providing closed‑form updates for \(V\) (via a linear system) and for auxiliary variables (via polar decomposition). Multiple restarts mitigate non‑convexity. The output is a binary adjacency matrix representing the transitive reduction (the learned CAN) and the associated CLCA matrices.

## Key Results
- SPECTRAL attains comparable Frobenius distance and KL divergence to state‑of‑the‑art baselines on local CLCA tasks, with lower computational cost.
- For full CAN recovery on 10‑node chain, star, and tree topologies, the search procedure yields true positive rates approaching \(1\) as the number of restarts increases, and maintains zero false positives—even when global sections contain semidefinite covariances.
- The method handles both positive‑definite and semidefinite covariances, extending prior work limited to the definite case.

## Why This Works (Mechanism)

### Mechanism 1: Decomposition into edge‑specific tasks
The global objective (P1) is separable across edges; each local subproblem depends only on the CLCA matrix for that edge. This reduces a combinatorial network search to independent lower‑dimensional optimizations. If the CAN is consistent and compositionality holds, the global solution can be reconstructed via transitive reduction.

### Mechanism 2: SPECTRAL’s closed‑form ADMM updates
The local feasibility problem (SP1) is reformulated by splitting the orthogonality constraints. An augmented Lagrangian yields alternating updates: a closed‑form solution for \(V\) from a linear system (Lemma 3.1), and Stiefel‑manifold projections for auxiliary variables via proximal maps (polar decomposition). This avoids direct non‑convex optimization and converges under standard ADMM assumptions.

### Mechanism 3: Transitivity‑aware search
Instead of brute‑force checking all \(\mathcal{O}(N^2)\) pairs, the algorithm first applies Theorem 2.1 only to consecutive dimensions and then computes the transitive closure to populate a candidate set \(\mathbf{P}\). It then validates only edges in \(\mathbf{P}\) that are not implied by already accepted edges, updating \(\mathbf{P}\) by removing those implied. This exploits the fact that the true CAN is the transitive reduction of the poset defined by the CLCA relation.

## Foundational Learning
- **Gaussian Structural Causal Models (SCMs):** These are the underlying models, each represented by a zero‑mean Gaussian measure \(\chi_i \sim \mathcal{N}(0,\Sigma_i)\). The covariances \(\Sigma_i\) encode causal strengths and serve as the primary observational data.  
  *Quick check:* What geometric condition on the eigenvalues of \(\Sigma_\ell\) and \(\Sigma_h\) must hold for a CLCA to exist (Theorem 2.1)?  

- **Constructive Linear Causal Abstraction (CLCA) & Semantic Embedding Principle (SEP):** A CLCA is a linear map \(V_{\ell h} = B_{h\ell} \odot V\) with \(V \in \mathrm{St}(\ell,h)\) that abstracts a finer model \(\ell\) to a coarser model \(h\). SEP demands that embedding then abstracting reproduces the original high‑level causal knowledge, ensuring consistency across abstraction levels.  
  *Quick check:* If \(V \in \mathrm{St}(\ell,h)\), how does the row space of \(V\) relate the columns of \(\Sigma_\ell\) to those of \(\Sigma_h\) (see Eq. 5)?  

- **Network Sheaf of Causal Knowledge & Consistency:** A CAN is a sheaf whose sections are the SCMs and whose restriction maps are CLCAs. Consistency requires that compositions of restrictions commute around loops and that the combinatorial Laplacian has a non‑trivial kernel, which enables the existence of global sections.  
  *Quick check:* What does Corollary 2.3 imply about the spectra of covariances in a valid global section, and why does this allow semidefinite covariances?

## Architecture Onboarding

**Component map:**  
Input (set of Gaussian measures with covariances) → Search procedure (builds candidate edge set \(\mathbf{P}\)) → SPECTRAL local solver (validates edges, returns \(\mathbf{A}\) and CLCA matrices) → Output (adjacency matrix \(\mathbf{A}\) and \(\{\hat{V}_{\ell h}\}\))

**Critical path:**  
1. Precompute eigen‑decompositions of all \(\Sigma_i\).  
2. For subdiagonal \(k=1\) to \(N-1\): for each pair \((i,i+k)\) not in \(\mathbf{P}\), apply Theorem 2.1; set \(\mathbf{P}_{i,i+k}=1\) if condition holds, then compute transitive closure of \(\mathbf{P}\).  
3. Initialize \(\mathbf{A}=0\). For subdiagonal \(k=1\) to \(N-1\): for each \((i,i+k)\) with \(\mathbf{P}_{i,i+k}=1\), run SPECTRAL; if convergence (residuals \(<10^{-3}\)) within \(K_{\max}=1000\), set \(\mathbf{A}_{i,i+k}=1\). After processing each subdiagonal, update \(\mathbf{P} \gets \mathbf{P} \setminus\) edges implied by the new \(\mathbf{A}\) via transitive closure.  
4. Output \(\mathbf{A}\) and solved CLCA matrices.

**Design tradeoffs:**  
- **ntrials (restarts) vs. TPR:** More restarts increase chance of escaping non‑convex minima, raising TPR, but cost grows linearly.  
- **Residual tolerance vs. FPR:** Looser tolerance may accept approximate CLCAs, potentially increasing false positives; paper uses \(10^{-3}\).  
- **Search vs. brute‑force:** Transitive‑reduction search drastically reduces checks compared to \(\mathcal{O}(N^2)\) brute force, but worst‑case dense graphs still require many local solves.

**Failure signatures:**  
- High false positive rate: SPECTRAL converged but \(V\) is not a valid CLCA (e.g., fails constructiveness); likely due to loose residual threshold or numerical issues with semidefinite \(\Sigma\).  
- Low true positive rate: SPECTRAL failed to converge for a true edge within restarts/iterations; indicates difficult local geometry or insufficient restarts.  
- No edges learned (\(\mathbf{A}=0\)): Theorem 2.1 failed for all pairs; could mean no consistent CAN exists under Gaussian SEP, or data is non‑Gaussian.

**First three experiments:**  
1. **Baseline replication:** Run SPECTRAL and three baselines from [10] on synthetic positive‑definite pairs \((\ell,h)\in\{(12,2),(12,4),(12,6)\}\) and compare Frobenius distance and KL divergence (Fig. 1).  
2. **Local solver robustness:** Solve single‑edge tasks with varying ranks of \(\Sigma_h\) and \(\Sigma_\ell\), including semidefinite \(\Sigma_h\), verifying convergence and solution accuracy.  
3. **Full CAN recovery:** Generate 10‑node synthetic CANs with chain, star, and tree topologies having global sections; run the full search with ntrials \(=10\) and \(=100\); record TPR and FPR (Fig. 2).

## Open Questions the Paper Calls Out
- **Sparsest CAN topology:** How to learn the sparsest CAN for a given topology that yields the same CLCAs and admits global sections? The current approach does not address sparsity or enforce topology‑driven global sections.
- **Identifiability of CLCA:** What identifiability conditions exist for recovering the true CLCA matrix \(V\) from observational Gaussian data alone? The paper only guarantees structural consistency with priors; identifiability from covariances remains open.
- **Counterfactual consistency:** How to achieve counterfactual consistency in CAN learning without abundant interventional data? The present objective does not enforce counterfactual constraints; it is unclear whether observational data suffice or interventions are necessary.

## Limitations
- The experimental data generation details from [10] are not provided, hindering exact replication of local learning results.
- Binary partition matrices \(B_{h\ell}\) are assumed known; in practice they must be learned, adding a layer of difficulty.
- Theorem 2.1 provides only a necessary condition for CLCA existence, potentially admitting false positives under noise or non‑Gaussianity.
- SPECTRAL’s ADMM has no convergence proof; success relies on multiple restarts to overcome non‑convexity.
- The search procedure presumes a unique transitive reduction; ambiguous posets could break reconstruction.
